Just a style, but this is far easier to read if you said:

```
	if (width > utf8_strwidth(what) + 1)
		len = width - (utf8_strwidth(what) + 1);

```

because you are essentially doing:

```
	if (A > B)
        	x = A - B;

```

Or even

```
	len = width - (utf8_strwidth(what) + 1);
        if (len < 0)
        	len = 0;

```
