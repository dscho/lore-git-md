Because it removes useless indentation :)

This is what they do in the Linux kernel, you tell me which looks better:

a)

```
	if (function1())
		goto leave;
	if (function2())
		goto leave;
	if (function3())
		goto leave;
	if (function4())
		goto leave;
	good_stuff();
```

leave:
	final_stuff();

or b)

```
	if (!function1()) {
		if (!function2()) {
			if (!function3()) {
				if (!function4()) {
					good_stuff();
				}
			}
		}
	}
	final_stuff();

```
