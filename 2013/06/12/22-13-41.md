> When 'git rm' fails, it now displays a single message
> with the list of files involved, instead of displaying
> a list of messages with one file each.
>

> 	(use --cached to keep the file, or -f to force removal)
>
> ```
>

> ```

> 	    foo.txt

>
> ```
