The current loop does

```
	while (...) {
		if (!not .idx file)
			continue;
		process .idx file;
	}

```

and is reordered to

```
	while (...) {
		if (!.idx file) {
			process .idx file;
		}
	}

```

This makes it easier to add new extension file processing.
