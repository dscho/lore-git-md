The most important part of the coding guidelines is to match the
style to existing code when writing a new one:

```
    $ git grep '^[a-z_]* ()' -- *.sh | wc -l
    132
    $ git grep '^[a-z_]*()' -- *.sh | wc -l
    55

```

We have acquired quite a few violators, but that is no reason to add
more.
