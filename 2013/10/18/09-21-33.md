arguments". It's not that bad because I'm trying to run `git log
--merge` on an already resolved conflict. Still, I don't think I

git init .
> a

git branch other
echo "1" >a
git commit -m"add 1" a
git checkout other
echo "2" >a
git commit -m"add 2" a
git merge master
git add a
git log --merge -- a
