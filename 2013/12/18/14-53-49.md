**Thread**: [thread](./14-53-45.thread.md#:~:text=2013/12/18/14-53-49)

All the changes follow the pattern

```
  if (!starts_with(foo, "bar"))
    return;
  foo += 3;

```

which is turned into

```
  if ((foo = skip_prefix(foo, "bar")) == NULL)
    return;

```
