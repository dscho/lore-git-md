The order of elements in COMPREPLY doesn't matter, it will be sorted
anyway:

```
$ _foo () { COMPREPLY=("foo" "bar" "baz") ; }
$ complete -F _foo foo
$ foo <TAB>
bar  baz  foo
```


I don't know who does the sorting (Bash or readline), and I don't know
any way to disable it.
