This thread discusses improving the bug report template in `git bugreport` by adding `>` prefixes to instructional lines, making it clearer which parts are prompts versus user responses. The change was originally proposed by Felipe Contreras and is now being carried forward by Kristoffer Haugsbakk in version 2 of the patch.

The v2 changes include updating the test (which wasn't present in v1), rewriting the commit message for conciseness, and adjusting the subject line for better style. The modification is straightforward - it only adds formatting to existing text in `builtin/bugreport.c` while maintaining all content. The corresponding test in `t/t0091-bugreport.sh` has been updated to verify the new output format.

The patch appears ready with proper sign-offs and attribution. The change is small but improves usability by making the template's structure more obvious to both bug reporters and those reading the reports.
