This is a test infrastructure patch that follows up on a previous fix for file descriptor handling in Git's test helpers. Jeff King (Peff) is responding to SZEDER Gábor's explanation of why using file descriptor 7 for stderr redirection was problematic - it clobbered the test script's original stderr, preventing BUG() messages from appearing in test output.

Peff agrees with the proposed switch to fd 6 (the test script's original stdin) since test helpers shouldn't be reading from stdin anyway. He suggests adding a master comment documenting the purpose of various file descriptors in the test suite, noting the limited portable range (fds 0-9) and the challenge of making such documentation discoverable.

The exchange shows consensus on the technical solution while raising a broader documentation concern about test suite file descriptor usage.
