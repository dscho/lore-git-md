**Thread**: [thread](./17-32-44.thread.md#:~:text=2021/02/09/17-32-45)

Some tests in this script are formatted using a very old style:

```
        test_expect_success \
            'title' \
            'body line 1 &&
            body line 2'

```

Update the formatting to the modern style:

```
        test_expect_success 'title' '
            body line 1 &&
            body line 2
        '

```
