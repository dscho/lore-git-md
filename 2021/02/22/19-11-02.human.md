This is a test infrastructure patch from Jeff King (Peff) that builds on SZEDER Gábor's earlier work to modernize error reporting in test helpers. The thread has already settled on switching from file descriptor 7 to 6 for stderr redirection when handling BUG() output in test helpers.

Peff's patch focuses on improving how we test these error conditions. Rather than directly manipulating file descriptors in the test scripts, he proposes using Git's sub-test framework (`run_sub_test_lib_test_err`) to verify BUG() output. This makes the tests more robust and readable by avoiding complex shell quoting and file descriptor magic. The patch converts two test cases - one for `test_must_fail` and one for `test_bool_env` - to use this approach.

The changes are non-controversial and align with the thread's direction toward more maintainable test infrastructure. Junio has already reviewed and endorsed the overall approach, with the main outstanding item being documentation of the file descriptor conventions. Peff's patch doesn't block that documentation work - it's an independent improvement to how we test the error cases.

This continues the project's broader effort to modernize test infrastructure, following similar changes elsewhere in the test suite. The patch is well-scoped and demonstrates the kind of incremental improvement that typically gets positive reception on the list.
