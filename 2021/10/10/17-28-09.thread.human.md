This thread is about fixing a fragile test in Git’s test suite. The test, in `t/t3420-rebase-autostash.sh`, incorrectly used `! grep dirty file3` to check that a file was clean after `git rebase --quit`. The problem was that `grep` fails if the file doesn’t exist at all, which could hide other test failures. The fix replaces this with `test_path_is_missing file3`, which properly asserts the file’s absence.

The patch was originally proposed five years ago, resurfaced by SZEDER Gábor, and has since been endorsed by Phillip Wood, who confirmed the change is correct. Todd Zullinger spotted a minor typo in the commit message ("Thighten" → "Tighten"), which will need fixing before merging. Junio C Hamano has now queued the patch, meaning it’s on track for inclusion. The fix is straightforward, touching only test logic and carrying no risk to production code. The only remaining step is correcting the typo.
