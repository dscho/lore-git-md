This is a test fix for `t3420-rebase-autostash.sh`. The patch addresses a subtle issue where tests checking the interaction between `git rebase --quit` and autostash were incorrectly using `grep` to verify that a file’s dirty contents were gone. The problem: the file in question shouldn’t exist at all after `--quit`, so `grep` fails not because the content is missing, but because the file itself is missing. The fix replaces `! grep dirty file3` with `test_path_is_missing file3`, making the test’s intent clearer and avoiding spurious errors. The change is minimal—one line in the test script—and follows the pattern established by an earlier fix (2745817028) for similar issues. The commit message is concise and explains both the problem and the solution well.
