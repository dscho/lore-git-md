I've been using unions to workaround APIs like free(3)
for many years:

static inline void deconst_free(const void *ptr)
{
```
	/* this initializer is a C99-ism */
	union { const void *in; void *out; } deconst = { .in = ptr };

	free(deconst.out);
```

}
