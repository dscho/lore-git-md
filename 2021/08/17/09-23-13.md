Actually I am not sure that it makes sense to test an exit code
smaller than 0, as POSIX exit codes are between 0 and 255 (included).

For example:

```
$ bash -c 'exit -1'; echo $?
255

$ dash -c 'exit -1'; echo $?
```

dash: 1: exit: Illegal number: -1
2
