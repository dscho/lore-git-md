If user.name's  value has a . as the last character of the last part
of the name, git is removing it from commit operations. But git-config
shows the .

example:

in .gitconfig:

[user]
    name = Daniel P.


`git config user.name`:

user.name=Daniel P.


from `git show`:

Author: Daniel P <danpltile@gmail.com>
