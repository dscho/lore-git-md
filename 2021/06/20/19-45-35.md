**Thread**: [thread](./19-45-35.thread.md#:~:text=2021/06/20/19-45-35)

If you try to switch to a branch (e.g. `master`), but get the case wrong, e.g:

```
    git switch MASTER
    git checkout MASTER
    git switch Master
    git checkout Master

```

etc. then it autocorrects the case (bad idea but ok), but it also
enables the `--detach` flag! In other words

    git switch Master

acts like

    git switch -d master

Very unexpected!
