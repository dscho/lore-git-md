I also &&-chain the `local` declaration:

```
    local ops val &&
    if test "$#" -le 2

```

By making it easy to see the `&&` upfront, when new code is inserted,
there is a better chance that the &&-chain will be kept intact:

```
    local ops val &&
    my new code &&
    if test "$#" -le 2

```
