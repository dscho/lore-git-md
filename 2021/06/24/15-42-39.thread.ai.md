Thread summary:

Bug in `git stash` with intent-to-add files persists since Git 2.32.0 (2021), still present in 2.52.0. When users create new files, mark them with `git add --intent-to-add`, then attempt to stash`, Git incorrectly rejects with "not uptodate" error. Originally reported by Claas Augner with clear reproduction steps, now confirmed by Jille Timmermans. Affects real-world workflows as seen in lint-staged project (GitHub issue #990). Root cause appears to involve how `stash` handles intent-to-add files, though no specific fix proposed yet.
