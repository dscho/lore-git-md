This thread documents the implementation of signed commit support in `git fast-export/import`, covering Christian Couder's v5-v6 patch series that revives Luke Shumaker's 2021 work. The core functionality includes signed commit handling with `--signed-commits` (offering abort/verbatim/strip modes), GPG format support, and memory-safe parsing. The series has undergone thorough review from Jeff King, Junio Hamano, and Eric Sunshine, with Phillip Wood identifying and fixing a memory leak in v5.

The most recent patch (v6) makes a final naming improvement, renaming `--signed-tags=warn` to `--signed-tags=warn-verbatim` for consistency with the existing `warn-strip` pattern, while maintaining backward compatibility. Documentation has been carefully polished throughout the series, with explicit defaults, security notices, and BNF syntax fixes. All technical issues are resolved, coding style is fully compliant, and CI tests are passing. The series is now ready for final inclusion, having also laid groundwork for future attestation signature support during import - a separate feature validated by Patrick Steinhardt for git-filter-repo use cases.
