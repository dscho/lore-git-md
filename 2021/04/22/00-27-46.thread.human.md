This thread documents the implementation of signed commit support for git fast-export/import, reviving and completing Luke Shumaker's 2021 work through Christian Couder's v5 patch series. The solution now provides full parity between commit and tag signature handling, with new --signed-commits options matching the existing --signed-tags behavior (abort, verbatim, warn-verbatim, strip, warn-strip). The implementation includes foundational cleanups, core functionality from Shumaker's original work, and refinements addressing memory safety and documentation.

Key contributors include Christian Couder as the series shepherd, Jeff King who approved the technical approach, and Eric Sunshine who verified test coverage. Junio Hamano flagged critical buffer safety issues in earlier versions which were fully addressed in v5. The series has now reached production-ready status with comprehensive test coverage and careful handling of backward compatibility through environment variables and legacy mode preservation.

In his final review, Junio Hamano commended the completion of this long-standing feature while suggesting an independent future enhancement - allowing importers to add their own signatures to attest to imported content. This idea is noted as potential follow-up work, not affecting the current series which is now considered complete and ready for merging. The work successfully revives Shumaker's original vision while adding necessary polish and safety measures.
