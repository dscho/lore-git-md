This thread documents the implementation of signed commit support in `git fast-export/import`, covering Christian Couder's v5 series that revives Luke Shumaker's 2021 work. The series implements core functionality with `--signed-commits` (offering abort/verbatim/strip modes), GPG format support, and memory-safe parsing, with comprehensive test coverage. Key reviewers including Jeff King, Junio Hamano, and Eric Sunshine helped refine the technical approach, buffer safety, and tests. Phillip Wood identified and fixed a final memory leak, making the series production-ready.

The discussion has validated a direction for future work on attestation signatures during import, though no implementation has been proposed yet. Most recently, Elijah Newren and Junio Hamano noted that while the documentation describes the various behavior modes for signed commit handling, it should explicitly state that 'abort' is the default - matching both sensible design and the behavior of `--signed-tags`. This minor documentation clarification, requiring no code changes, is the last polish on an otherwise complete feature implementation. The thread shows the project's attention to both technical robustness and clear user-facing documentation.
