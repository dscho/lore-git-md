This thread continues the work to add signed commit support to `git fast-export/import`, reviving and extending Luke Shumaker's 2021 patches. Christian Couder has been shepherding the series, now at v5, which includes preparatory cleanups and the core implementation.

The latest patch refines the naming of the `--signed-tags=warn` option to `warn-verbatim` for better consistency with the existing `warn-strip` option. This makes the behavior more self-documenting while maintaining backward compatibility through a deprecated `warn` synonym. The change is well-tested, with new cases verifying both forms work correctly while preserving signatures.

The series as a whole implements comprehensive signed commit handling, with:
- New `--signed-commits` option mirroring `--signed-tags`
- Multiple signature handling modes (abort, strip, warn-verbatim)
- Support for both GPG and GPG-SHA256 formats
- Thorough test coverage in t9350
- Careful attention to backward compatibility

Key reviewers including Jeff King and Eric Sunshine have provided positive feedback, with Junio Hamano noting earlier buffer safety concerns that have since been addressed. The v5 series appears ready with all known issues resolved, though some follow-up questions remain about signature validation in fast-import. This naming refinement is a final polish before potential merging.
