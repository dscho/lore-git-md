Well, blame Pasky for not describing 'ctags' in more detail.  Value of
tag is its weight, so instead of

```
 	mkdir ctags
	echo Linux > ctags/Linux

```

one should use

```
 	mkdir ctags
	echo 1 > ctags/Linux

```

Admittedly gitweb should be more defensive about invalid input...
