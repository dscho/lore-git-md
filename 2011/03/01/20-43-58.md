I'd say grep for "rmdir" is Git's source code, and replace the calls
with a wrapper that does roughly

rmdir_wrapper(dir) {
```
	rmdir(dir);
	if (stat(dir, &buf))
		chmod(dir, buf.st_mode | 0777);
```

}
