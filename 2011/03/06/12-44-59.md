A mailing list has now been created for developers and users of cgit.
Release announcements for cgit will still be (cross)posted to the git
mailing list (speak up if this is considered rude), while cgit-related
patches and discussions should go to the new list.

* To post to the list (subscription not required), send the message to
cgit@hjemli.net
```
* To subscribe to the list, send an email with subject "subscribe" to
cgit-request@hjemli.net
* Archives are available at http://hjemli.net/pipermail/cgit/
* Listinfo is available at http://hjemli.net/mailman/listinfo/cgit
```
