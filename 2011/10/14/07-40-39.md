**Thread**: [thread](./../04/10-19-59.thread.md#:~:text=2011/10/14/07-40-39)

Until now, a request for an http password looked like:

```
  Username:
  Password:

```

Now it will look like:

```
  Username for 'example.com':
  Password for 'example.com':

```
