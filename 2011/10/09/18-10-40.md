Ok, this seems like two different needs.

- For the former, see GIT-VERSION-GEN in git.git for inspiration.
- For the latter, I'd recommend something like

```
	git update-index -q --refresh &&
	git diff-index --quiet HEAD ||
	{
		echo >&2 fail
		exit 1
	}

```
