Tag is a pointer to a commit (if to say simply)

e.g. in my repo
$ git show-ref --tags --abbrev=7
-->8--
676f194 refs/tags/v2.6.7
b23c481 refs/tags/v2.6.8
-->8--

so

$ git diff v2.6.7..v2.6.8
is equivalent to
$ git diff 676f194..b23c481

etc
