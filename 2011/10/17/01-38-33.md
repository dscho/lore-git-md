The following shows the problem for me:

#!/bin/bash
mkdir super sub
cd sub
git init
touch a
git add a
git commit -m 'file' a
git pack-refs --all
cd ../super
git init
git new-workdir ../sub sub
git-gui


git-gui shows "sub/a" in the list of Unstaged Changes. Note that the 
"git pack-refs" call is needed to get the failure.
