**Thread**: [thread](./../26/17-05-48.thread.md#:~:text=2011/10/27/16-46-53)

Without this patch,

    git clone foo .

results in this:

```
    Cloning into ....
    done.

```

With it:

```
    Cloning into '.'...
    done.

```
