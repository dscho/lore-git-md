source set, I can do this:

```
	$ git init
	$ cp $git_src/COPYING a
        $ tr 'A-Za-z' 'N-ZA-Mn-za-m' <a >b
	$ git add a b
        $ git commit -m ab
        $ git mv a c; git mv b a; git mv c a
        $ git diff --stat -M -B HEAD
         b => a | 0
         a => c | 0
         2 files changed, 0 insertions(+), 0 deletions(-)
```
