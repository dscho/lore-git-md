Or, if the patch produced by "git diff" doesn't do it:

git commit -am foo
git format-patch -1
git reset HEAD^

> (on other machine)
> % git apply foo.patch


In one command:

git diff | ssh other-machine 'cd /path/to/repo && git apply'
