Style.

```
	LC_ALL=... svn log ... |
        LC_ALL=... perl -w -e '
        	...
	'

```

When you end a line with '|', the shell knows that you haven't finished
talking to it, so there is no need for the trailing bs-lf there.  Indent
the downstream of the pipe to the same level as the upstream.
