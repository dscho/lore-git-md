While developing in a particular repo, I constantly have to push to
two compile machines. I just dropped a Makefile into the top of my
working tree:

all: push
amend:
```
	git amend -a
	git --no-pager diff @{1}
	make push
```

push:
	make -j 2 mac win
mac:
	git push mac
win:
	git push win
