I found a issue about git log --grep.

On OS X,
$ git log --oneline --grep=コミット |wc -l

It's ok.

On cygwin
$ git log --oneline --grep=コミット
fatal: command line, 'コミット': illegal byte sequence
It's not ok.
This message is produced by iconv().
