I used to use:

```
  make -k -j30
  grep 'failed [^0]' test-results/*

```

but these days I use the "prove" tool, which has much nicer output. You
can get Makefile support for it with:

```
  GIT_PROVE_OPTS = -j30
  DEFAULT_TEST_TARGET = prove

```

in your config.mak.
