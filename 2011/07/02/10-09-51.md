In an ideal world, it would involve two patches.

```
 1. first, restructure the code without changing output
 2. then, change output

```

Or:

```

```

separately.

builtin/revert.c (see v1.7.3-rc0~26^2~3, Introduce advise() to print
hints, 2010-08-11).
