Hi,

if you have:

0---0---0---X---A---B---C---D---E master
```
          \
             0---0 release

```

then you could do

$ git rebase --onto release X master

to get this:

0---0---0---X---A---B---C---D---E master
```
          \
             0---0---A'---B'---C'---D'---E' release

```

IOW, it rebases everything between X (w/o X itself) and master (which is 
E, including E) onto release.

Or, with

$ git rebase --onto release X C

you would get:

0---0---0---X---A---B---C---D---E master
```
          \
             0---0---A'---B'---C' release

```
