**Thread**: [thread](./11-56-10.thread.md#:~:text=2011/08/01/22-14-20)

If --no-checkout is specified, then the bisection process uses:

	git update-ref --no-deref HEAD <trial>

at each trial instead of:

	git checkout <trial>
