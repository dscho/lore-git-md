It seems "git archive --format=tgz HEAD" is broken on Windows:
```
$ git archive --format=tgz HEAD > j.tgz
$ gunzip -c j.tgz > j.tar && echo ok
```

$ git archive --format=tar HEAD | gzip -cn > j.tgz
