I think I fixed it like this:

  git config core.ignorecase false

then backup the LOG.txt file and:

```
  git rm Text/Log.txt
  git rm Text/LOG.txt
  git commit

```

then copy the LOG.txt file back again and add and commit it. Seems to be
okay now.
