This thread discusses a cleanup patch for git-gui that removes outdated Tcl compatibility code. The patch, from Mark Levedahl, simplifies the `_open_stdout_stderr` function by eliminating a workaround for older Tcl versions (pre-8.4.7) that didn't support modern stderr redirection syntax. The change reduces 21 lines of conditional logic to just 2 lines, removing a fallback path that would execute commands twice in some cases.

Johannes Schindelin is reviewing the patch to confirm it's still relevant, noting it might follow up on previous cleanup work (commit 7145c65) that missed this case. The simplified version has been tested on current Linux, Cygwin and Git for Windows Tcl implementations, all of which now support the modern syntax as git-gui requires Tcl ≥8.5. The change affects how git-gui constructs command execution pipelines but maintains the same functionality while being more maintainable.
