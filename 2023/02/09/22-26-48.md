In HTML, if there is a base tag like `<base href="/a/b">`, a relative 
URL like
`c/d` will be resolved by the browser as `a/c/d` and not as `a/b/c/d`. 
But with
a base tag like `<base href="/a/b/">` it will result in `a/b/c/d`.
