> I think this is one of the ambiguous cases. If $GIT_DIR is "=", then
> "test" cannot tell if you meant:
>
> ```
>   var1=-d

>
> ```
>

>
> ```
>   var1="="

>
> ```

>

>   2
>
> ```
>

> here).
