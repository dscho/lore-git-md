These can be converted to use test_must_fail by using a sub-shell
as Junio demonstrated:

```
	(
		FAKE_LINES="1 squash 3 2" &&
		export FAKE_LINES &&
		test_must_fail git rebase -i HEAD~3
	) &&

```
