To clarify, this only appears to affect shell aliases (i.e. ones that  
start with !).

   git config alias.foo 'ls-files'

Works fine from a subdir

   git config alias.foo '!git ls-files'

Doesn't behave right from a subdir.

-Kevin Ballard
