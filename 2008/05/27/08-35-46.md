it seems that git grep doesn't do word boundaries as described:

$ cat bar
foo bar baz
```
$ grep "\<bar\>" *
foo bar baz
$ git grep "\<bar\>" *
$ git grep -w "\<bar\>" *
$ git grep -w "bar" *
```

bar:foo bar baz
```
$ git grep -E "\<bar\>" *
$ git grep -E "\bbar\b" *
$
```
