Now the test "no changes are a nop" checks additionally, 
that HEAD is commit I and a symbolic ref for branch2.

The new test fails on a situation like this, for example:
$ git branch -v
* (no branch) cac536e I
```
   branch1     1599c04 H
   branch2     cac536e I
   master      cb54291 E

```
