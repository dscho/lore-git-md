Another glitch.  What should we do when stat(path) fails but the file
cannot be read?

I think the sequence actually should be:

```
	fd = lock_file();
        if (fd < 0)
        	error out;
	orig_fd = open(path, O_RDONLY);
        if (orig_fd < 0) {
		if (errno != ENOENT)
			die("unable to open %s", path);
		copy;
	}
	return fd;
```
