maybe like this?

```
	if (!no_commit) {
		char **argv[6] = { "commit", "-n" };
		int argc = 2;
		if (signoff)
			argv[argc++] = "-s";
		if (!edit) {
			argv[argc++] = "-F";
			argv[argc++] = defmsg;
		}
		argv[argc] = NULL;
		execv_git_command(argv);
	}

```

It duplicates what execl_git_cmd does, but other places already work
similar (eg. cmd_describe, when --contains is given), and IMHO it's
nicer than the if-else chain.
