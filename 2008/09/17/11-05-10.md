That means that you also need to pass the "man-pages" suffix for the
tags and branches.

git svn clone file:///path/to/repo \
```
	-T trunk/man-pages \
	-b branches/*/man-pages \
	-t tags/*/man-pages

```

Might require a more recent git-svn version, not sure about that.
