**Thread**: [thread](./07-28-16.thread.md#:~:text=2008/09/08/07-28-16)

To reproduce: expand a tree like this, then collapse A:

+A
```
 +B
   C
   D

```

The result is:

-A
```
   C
   D

```

I.e. sub-nodes expanded from the last sub-node of the item
being collapsed are not removed.
