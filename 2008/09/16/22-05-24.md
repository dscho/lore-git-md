expect to have the following structure to my checked out repository:

```
    [root-dir]
        .git
        <checked-out-files>

```


haven't managed to get the desired layout.  I guess that I'm missing

```
$ git svn init file:///home/mtk/man-pages-rep/ -t tags -T trunk -b branches
$ git svn fetch

```
