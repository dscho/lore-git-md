> BTW. what is best way of checking if given revision is parent-less?


I think count the number of parents is quite sane.

In sequencer I have:
```
	count_parents() {
		git cat-file commit "$1" | sed -n -e '1,/^$/p' | grep -c '^parent'
	}

```
