Yes, and I still have. is_standalone does that:

# check if no other options are set
is_standalone () {
```
	test $# -eq 2 -a "$2" = '--' &&
	test -z "$ONTO" &&
	test -z "$PRESERVE_MERGES" &&
	test -z "$STRATEGY" &&
	test -z "$VERBOSE"
```

}

which is called on --continue/--abort/--skip before the saved options are
loaded again.
