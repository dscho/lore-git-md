Usage: cvs diff [-lR] [-k kopt] [format_options]
```
    [[-r rev1 | -D date1] [-r rev2 | -D date2]] [files...]
        -l      Local directory only, not recursive

```

It shows the diff for all files in the current directory, nothing
deeper, nothing higher.
