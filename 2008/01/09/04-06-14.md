No, as of 34cc60ce2b48f6037997543ddbab1ed9903df4a8 you can use SSL and 
SMTP-Auth.

[sendemail]
```
         smtpserver = smtp.gmail.com
         smtpuser = <user>@gmail.com
         smtppass = <password>
         smtpssl = true

```

Can you suggest changes to the documentation if these options are unclear?
