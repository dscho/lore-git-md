**Thread**: [thread](./23-39-40.thread.md#:~:text=2008/08/18/23-57-33)

The following syntax:

```
        char foo[] = {
                [0] = 1,
                [7] = 2,
                [15] = 3
        };

```

is a c99 construct which some compilers do not support even though they
support other c99 constructs. Use an alternative.
