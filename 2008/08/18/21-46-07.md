+An alternative is to use davfs2, a driver that allows mounting a WebDAV

+
+  $ apt-get install davfs2
+  $ mkdir -p /mnt/webdav
+  $ mount -t davfs http://<servername>/ /mnt/webdav
+  $ ls /mnt/webdav
+  $ umount /mnt/webdav
