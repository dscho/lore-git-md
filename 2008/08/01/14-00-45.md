**Thread**: [thread](./14-00-45.thread.md#:~:text=2008/08/01/14-00-45)


The command line

	$ git clone --mirror $URL

is now a short-hand for

```
	$ git clone --bare $URL
	$ (cd $(basename $URL) && git remote add --mirror origin $URL)

```
