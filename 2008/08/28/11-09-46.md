After this patch, if one does, for example

git log -1 --pretty=format:"%as %h" e83c5163316f89bfb

one gets

2005-04-07 e83c516

and if one does

git log -1 --pretty=format:"%cs %h" e83c5163316f89bfb

one gets

2005-04-07 e83c516
