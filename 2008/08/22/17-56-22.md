> > +     if (value[0] == '~' && value[1] == '/') {
> > ```

>
> Might you want to check that strlen(value) is at least 2?

No.

```
    swtich (strlen(value)) {
    case 0:
        /* value[0] == '\0' => value[0] != '~'
           value[1] will never be dereferenced, because of lazy && */
    case 1:
       /* value[0] != '\0'
          if (value[0] == '~')
              value[1] == '\0' => value[1] != '/' */
    default:
       /* ... */
    }

```

So no invalid memory dereferences.
