Yes, it's fast-import. In particular, trying to rename a file whose name
contains spaces:

```
  R "file 1.txt" file 2.txt
                ^
                unquote_c_style() eats that space, thus fast-import
                fails with:

                fatal: Missing space after source: R "file 1.txt" file 2.txt

```
