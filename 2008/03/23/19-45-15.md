Hmm, I take it back. Git is doing the right thing, but it is a quirk of
the shell that it counts the first argument as the "name of the script"
even though the script actually comes from "-c".

```
  $ sh -c 'echo $0' foo
  foo
  $ echo 'echo $0' | sh
  sh

```
