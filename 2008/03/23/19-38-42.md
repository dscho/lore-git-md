If you want to use positional parameters, you have to invoke the shell
explicitly. Try:

```
  [alias]
    atag = !sh -c 'git tag -a -m "$0" "$0"'

```

As an aside, this should be "$1" but it looks like we don't pass the
shell a proper argv[0].
