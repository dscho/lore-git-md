I really hate this patch.

Why do we even _care_ about uname?

Wouldn't something like this be a lot easier to maintain in the longer run?

```
    for d in \
            "$SVN_HTTPD_MODULE_PATH" \
            /usr/lib/apache2/modules \
            /usr/libexec/apache2 \
    ; do
            if test -d "$d"
            then
                    SVN_HTTPD_MODULE_PATH="$d"
                    break
            fi
    done
```
