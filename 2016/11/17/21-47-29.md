That's weird.
Either get rid of the if() and actually use status:

```
	status = copy_fd(fd, STDOUT_FILENO);

	close(fd);
	return status ? -1 : 0;

```

or get rid of status and use the if:

```
	if (copy_fd(fd, STDOUT_FILENO)) {
		close(fd);
		return -1;
	}

	close(fd);
	return 0;

```

I'd recommend the shorter variant ;)
