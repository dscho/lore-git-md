What Jacob prefers is this:

---------------------------------------------
```
        if (cond)
                simple;
        else if (cond)
                simple;
        else
                simple;
```

---------------------------------------------
```
        if (cond) {
                simple;
        } else if (cond) {
                no;
                longer;
                simple;
        } else {
                simple;
        }
```

---------------------------------------------

That is, as long as all arms of if/else if/.../else cascade is
simple, {} is used nowhere in the cascade, but once even one of them
requires {} then all others gain {}.
