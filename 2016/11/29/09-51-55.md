
"$progresscanv create rect -1 0 0 $h -fill lime"
```
    (procedure "makewindow" line 201)
    invoked from within
```

"makewindow"
    (file "/..../bin/git-exe/bin/gitk" line 12434)

The fix is to change lime with {lime green}
