After expansion, I don't think the shell will do any further processing
except for whitespace splitting. E.g.:

```
  $ debug() { for i in "$@"; do echo "got $i"; done; }
  $ sep=';'
  $ space=' '
  $ debug foo${sep}bar
  got foo;bar
  $ debug foo${space}bar
  got foo
  got bar

```

I don't mind quoting it to make it more obvious, though.
