Here's the subshell version. I'm a little embarrassed not to have
thought of it sooner (though the other one was a fun exercise).

```
	test_env () {
		(
			while test $# -gt 0
			do
				case "$1" in
				*=*)
					eval "${1%%=*}=\${1#*=}"
					eval "export ${1%%=*}"
					shift
					;;
				*)
					"$@"
					exit
					;;
				esac
			done
		)
	}

```
