"middle", but different beginning?

  +refs/pull/*/head:refs/remotes/pull/*

  refs/pull/123/head -> pull/123

but could be:

  {refs -> }/pull/123{head -> }

I actually think that _isn't_ an improvement, but I wonder if there is a
format that would be.
