Correct.

```
#make a fresh clone of your repo to the local disc:
git clone "repo_your_repo_name" temp_repo

# go into that repo
```

cd temp_repo

```
# Tell Git to rename the folder in the Git repo:
git mv Android android

#Commit
```

git commit -m "mv Android android"

#Push back
git push origin
