Actually, I think we can have improved encapsulation and maintain
readability like this:

```
    case "$1" in
    ...
    -g) env="$2"; shift;  shift ;;

    esac

    ...
    test_expect_success "..." '
        if test -n "$env"
        do
            test_when_finished "unset GIT_DIR"
            GIT_DIR="$env"
            export GIT_DIR
        fi
        ...
    '
```
