Maybe, roughly:

```
    cp.stdout = -1;
    start_command(&cp);
    do {
        int r = xread(cp.stdout, buf, MAX_IO_SIZE);
    } while (r >=0);
    finish_command(&cp);

```

xread does use a poll() for you so it is not active polling,
but only reading when data is available.
