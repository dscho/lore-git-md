you could put this in your config:

```
  [remote local]
    url = .
    fetch = dev
  [branch "pro"]
    remote = local
    rebase = true

```

When you're wish to incorporate your latest changes in "dev" into
"pro(duction)",

```
  $ git checkout pro #assuming you're not already on "pro"
  $ git pull

```

Repeat ad nauseum.
