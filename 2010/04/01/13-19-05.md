Thank you Ilari,

The filter approach seems to work nicely.

git config --global filter.maclinefeed.smudge 'tr \\n \\r'
git config --global filter.maclinefeed.clean 'tr \\r \\n'

With suitable filter and -crlf settings in .gitattributes,
