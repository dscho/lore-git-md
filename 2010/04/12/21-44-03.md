> tree then stash will discard the working tree file with no way to
> recover the changes.
>
> This can might be done in one of a number of ways.
>
> git rm file
> vi file              # edit a new version
> git stash
>
> or with git mv
>
> git mv file newfile

> git stash

no easy recovery.
