It seems to work for me:

```
$ mkdir s
$ cd s
$ git init
$ echo a > a
```

```
$ git add a
$ git commit -m i
$ cd ..
$ git clone -s s c
```

```
$ cd c
$ git repack -a
$ mv .git/objects/info/alternates .git/objects/info/alternates.orig
$ git branch
```
