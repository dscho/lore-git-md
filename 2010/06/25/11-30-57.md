By the way, a common pitfall is to mis-treat the void *baton argument as
the wrong type of baton.  That is, code of the form

```
    f(void *baton) {
        foo_baton_t *fb = baton;
    }

```

instead of

```
    f(void *baton) {
        bar_baton_t *bb = baton;
    }

```
