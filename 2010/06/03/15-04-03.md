Then, you can the url.<url>.insteadof mechanism:

[url "<actual url base>"]
```
      insteadOf = <other url base>

       For example, with this:

```

[url "git://git.host.xz/"]
      insteadOf = work:

you can clone it with: git clone work:project.

See git-clone and/or git-config man page for more information.
