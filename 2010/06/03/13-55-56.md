**Thread**: [thread](./13-55-54.thread.md#:~:text=2010/06/03/13-55-56)

Support instaweb's --reuse-config using instaweb.overwrite
variable in gitconfig.

To use --reuse-config always
```
	[instaweb]
		overwrite = false

```
