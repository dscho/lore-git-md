sometimes do), then your HEAD would likely to be detached already when you
run rebase.  IOW, I would expect that 

```
	git checkout HEAD^0

        git rebase -i HEAD~2

```

would be a lot more natural thing to do, and in that case you do not need
to say HEAD^0 there.
