> Could you detail a bit more your problem description?


A normal commit description would be:
```
   <subject>

   <description>

   <signed-off-by>

```

You get the "running subject" effect if instead you do:
```
   <subject>
   <description>
   <signed-off-by>

```

I.e, if you omit an empty line after the subject line.
