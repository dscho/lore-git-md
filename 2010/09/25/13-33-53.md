**Thread**: [thread](./13-33-49.thread.md#:~:text=2010/09/25/13-33-53)

This change ensures that git rev-parse --flags complies with its documentation,
namely:

   "Do not output non-flag parameters".

Previously:
```
   $ git rev-parse --flags HEAD
   <sha1 hash of HEAD>
   $

```

Now:
```
   $ git rev-parse --flags HEAD
   $

```
