script is simply creating .lock files too fast for Windows to keep up.
Simply trying again fixes the problem for me.

+++ b/git-svn.perl
@@ -3676,8 +3676,10 @@ sub rev_map_set {

+   for(; !sysopen($fh, $db_lock, O_RDWR | O_CREAT) && $tries>=0; $tries--) { }
