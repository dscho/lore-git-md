= New =

1. A few git tips you didn't know about (157)
Very useful tips, even for git masters
http://mislav.uniqpath.com/2010/07/git-tips/

2. Why aren't you using git-flow? (29)
Introducing git-flow; a bunch of Git extensions for Vincent Driessen's
branching model.
http://jeffkreeftmeijer.com/2010/why-arent-you-using-git-flow/

3. Continuous Deployment, Code Review and Pre-Tested Commits on Digg4 (12)
How the digg team uses an array of tools to achieve fast, continous,
and stable deployment.
http://about.digg.com/blog/continuous-deployment-code-review-and-pre-tested-commits-digg4

4. Making GitHub More Open: Git-backed Wikis (12)
GitHub now features git-backed wikis using git and GitHub's markup library.
http://github.com/blog/699-making-github-more-open-git-backed-wikis
