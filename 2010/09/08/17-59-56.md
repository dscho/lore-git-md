fmt-merge-msg'. It controls the number of shortlog entries to display
in merge commit messages.

+	cat >expected <<-EOF &&
+	Merge branch ${apos}left${apos}

+	* left: (5 commits)
+	  Left #5
+	  Left #4
+	  Left #3

+

+	* left:

+	  Left #3
+	  Common #2
+	  Common #1
+	EOF
+
+	git -c merge.log=5 fmt-merge-msg <.git/FETCH_HEAD >actual &&
+	test_cmp expected actual
+'
