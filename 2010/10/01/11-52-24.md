FWIW a more generally useful function would have to look something
like this:

test_exit_status () {
```
	want_code=$1
	shift
	"$@"
	exit_code=$?
	if test $exit_code = $want_code
	then
		return 0
	else
		echo >&2 "test_exit_status $want_code: command had status $exit_code: $*"
		return 1
	fi
```

}
