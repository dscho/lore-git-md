I think it does:

```
  $ git init tmp && cd tmp
  $ echo content >tracked
  $ git add tracked
  $ mkdir untracked

  $ git status --untracked-files=normal
  # On branch master
  #
  # Initial commit
  #
  # Changes to be committed:
  #       new file:   tracked
  #

  $ >untracked/file
  $ git status --untracked-files=normal
  # On branch master
  #
  # Initial commit
  #
  # Changes to be committed:
  #       new file:   tracked
  #
  # Untracked files:
  #       untracked/

```
