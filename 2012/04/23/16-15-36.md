Missed a spot.  I'd do

```
	if (ret < 0 || putchar('\n') == EOF)
		return -1;
	return ret + 1;

```

And likewise, for the fprintf version:

```
	if (ret < 0 || putc('\n', fp) == EOF)
		return -1;
	return ret + 1;

```
