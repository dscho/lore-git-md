This doesn't work: it is syntax error:

  Can't declare scalar assignment in "my"
  
It has to be either

 +	(my $filter = $project) =~ s/\.git$//;

or

```
 +	my $filter = $project;
 +	$filter =~ s/\.git$//;

```
