This is not limited to "if".  An easy rule of thumb is to write the
control structure _without_ using semicolon.

That is:

```
	if test ...
        then
            ...
	else
	    ...
	fi

	while test ...
        do
        	...
	done

```

not

```
	if test ...; then
            ...
	else ...;
        fi

        while test ...; do
	    ...
	done

```
