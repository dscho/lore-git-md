Not so fast.

	exec cmd1 && cmd2
and
```
	exec cmd1
	exec cmd2

```

are far from equivalent: If cmd1 fails, the first version never runs
cmd2, but the second version runs cmd2 upon rebase --continue.

The updated documentation should not say that the two are "equivalent".
