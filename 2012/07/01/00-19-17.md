> > > ```
> > >     if test -e "$GIT_DIR/MERGE_RR"
> > >     then
> > >         files=$(git rerere remaining)

> > done (either the user edited the paths in the editor, or some
> > third-party mechanism resolved the conflicts already) does not make
> > much sense, methinks.
