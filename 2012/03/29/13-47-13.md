tags/v1.1

tags/debian/v1.1-1
tags/debian/v1.1-2

branches/user1/workitem1
branches/user1/workitem2
branches/user2/workitem1
branches/user2/workitem2

and tags like this:

1.0  (notice I don't want to keep the v1.0, drop the v)
1.1
debian/1.0-1
debian/1.1-1
debian/1.1-2

However, if I run

git svn clone \
```
   -T trunk \
   -t tags \
   -b branches \
   https://flactag.svn.sourceforge.net/svnroot/flactag \
   flactag-git1

```
