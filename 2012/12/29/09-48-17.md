Something like the patch below, which does speed things up. But not
nearly as much as I'd hoped:

```
  [before]
  $ best-of-five git rev-list --count --all
  real    0m4.197s
  user    0m4.112s
  sys     0m0.072s

  [after]
  $ best-of-five git rev-list --count --all
  real    0m3.782s
  user    0m3.708s
  sys     0m0.064s

```

Only about a 10% speedup (versus ~75% with uncompressed commits).
