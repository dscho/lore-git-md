**Thread**: [thread](./19-43-35.thread.md#:~:text=2012/02/09/19-43-36)

Use the "!" prefix to ignore tags of the given pattern.
This has precedence over other matching patterns.
For example,

```
  $ git tag -l \!*-rc? v1.7.8*
  v1.7.8
  v1.7.8.1
  v1.7.8.2
  v1.7.8.3
  v1.7.8.4
  $ git tag -l v1.7.8* \!*-rc?
  v1.7.8
  v1.7.8.1
  v1.7.8.2
  v1.7.8.3
  v1.7.8.4

```

This is equivalent to,

```
  $ git tag -l v1.7.8* | grep -v '\-rc.'
  v1.7.8
  v1.7.8.1
  v1.7.8.2
  v1.7.8.3
  v1.7.8.4

```
