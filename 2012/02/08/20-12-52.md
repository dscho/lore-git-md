**Thread**: [thread](./../05/22-28-07.thread.md#:~:text=2012/02/08/20-12-52)

This filters the list for tags of the given object.
Example,

```
   john$ git tag v1.0-john v1.0
   john$ git tag -l --points-at v1.0
   v1.0-john

```
