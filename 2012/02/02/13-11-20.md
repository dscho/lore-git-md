I found the cause and the solution here:
http://www.nntp.perl.org/group/perl.module.build/2008/02/msg1214.html

I've changed
  use Exporter 'import'
to
```
  BEGIN {
   require Exporter;
   *{import} = \&Exporter::import;
   }
```

in I18N.pm.

The test now passes (GETTEXT_LOCALE=1):
