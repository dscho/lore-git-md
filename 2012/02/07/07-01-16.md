**Thread**: [thread](./../05/22-28-07.thread.md#:~:text=2012/02/07/07-01-16)

This filters the list for annotated|signed tags of the given object.
Example,

```
   john$ git tag -s v1.0-john v1.0
   john$ git tag -l --points-at v1.0
   v1.0-john

```
