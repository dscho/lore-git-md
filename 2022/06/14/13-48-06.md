This is an interesting suggestion. It changes callers a bit, but not
too much. The pattern currently is:

```
	if (branch_checked_out(name, &path)) {
		/* do something */
		free(path);
	}

```

but would become

```
	if ((path = branch_checked_out(name))) {
		/* do something */
	}

```

Sounds good to me.
