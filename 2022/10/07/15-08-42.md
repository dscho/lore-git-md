**Thread**: [thread](./../04/16-06-28.thread.md#:~:text=2022/10/07/15-08-42)

The strvec "argv" is used to build a command for run_command_v_opt(),
but never freed.  Use a constant string array instead, which doesn't
require any cleanup.
