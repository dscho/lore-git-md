Align "branch -d" with the intuitive use of "-" as a short-hand
for "@{-1}", like in "checkout", "rebase" and "merge" commands.

```
$ git branch -d -      # short-hand for: "git branch -d @{-1}"
$ git branch -D -      # short-hand for: "git branch -D @{-1}"

So I can do:
```


```
$ git checkout work_to_review
$ git checkout -
$ git merge - # or git rebase -
$ git branch -d -
```
