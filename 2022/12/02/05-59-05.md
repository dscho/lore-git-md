```
        if test -z "$ceol"; then
          CEOL="-c core.eol=$ceol"
        else
          CEOL=""
        fi
        git $CEOL checkout -- crlf_false_attr__$f.txt &&

The original reasoning (for not looking at the return code) was that
if the checkout fails, the test suite will fail further down anyway.
