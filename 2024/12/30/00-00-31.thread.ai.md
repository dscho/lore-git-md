Zsh's ksh emulation mode doesn't support this indirect expansion, causing raw variable names to appear instead of config options.

Confirmed working on Bash 3.2.57 and Zsh 5.0.8. The implementation includes a demonstration program showing correct handling of variables containing spaces in both shells. Changes are limited to git-completion.bash, modifying 6 existing indirect expansions while adding the helper function.
