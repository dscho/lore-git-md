This is the 8th iteration of a feature series adding remote object metadata queries to `git cat-file --batch-command`, building on Calvin Wan's earlier work. The series enables clients to request object information (currently just sizes) from protocol v2 servers without downloading full objects, with security hardening from prior iterations now complete.

The implementation refactors fetch-pack packet writing, moves fetch initialization, advertises the object-info capability, adds transport layer support, and implements the `remote-object-info` command for `cat-file`. Changes since v7 include better error handling with `strtoul_ul()`, test reorganization, and performance improvements to string list lookups. The series includes comprehensive tests covering security edge cases across different transports.

All major technical issues have been resolved through review feedback from Patrick Steinhardt, Jonathan Tan, and others. The remaining discussion centers on philosophical questions about interface stability for experimental features, but the implementation itself appears ready for merging. This represents a security-sensitive enhancement to Git's remote object query capabilities while minimizing attack surface.
