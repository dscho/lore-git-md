This is a refactoring patch in the 8th iteration of a series adding remote object metadata queries to `git cat-file --batch-command`. The patch generalizes packet writing logic from fetch-pack.c to connect.c so it can be reused by other protocol v2 commands.

The key change moves and renames `write_fetch_command_and_capabilities()` to `write_command_and_capabilities()` in connect.c, making it available for any protocol v2 command while maintaining the same functionality. The patch handles the `advertise_sid` configuration safely since the original fetch-pack.c usage was protocol v1-specific and thus irrelevant for this v2-focused refactor.
