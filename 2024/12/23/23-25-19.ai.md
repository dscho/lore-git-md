This is a refactoring patch in the 8th iteration of a series adding remote object metadata queries to `git cat-file --batch-command`. The patch generalizes packet writing logic from fetch-pack.c to connect.c so it can be reused for protocol v2 commands beyond just fetch.

The key change moves and renames `write_fetch_command_and_capabilities()` to `write_command_and_capabilities()` in connect.c, making it available for other protocol v2 commands like the new "object-info" operation. The refactoring handles session ID advertisement configuration by reading directly from git config rather than relying on fetch-pack's static variable.

Technical details:
- Moves packet writing logic to connect.c with minimal behavior changes
- Maintains existing protocol v2 capability advertisement patterns
- Preserves all error checking for hash algorithm compatibility
- Updates fetch-pack.c callers to use the new generalized function
- Adds proper function documentation in connect.h
