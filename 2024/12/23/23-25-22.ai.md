This is the 5th patch in an 8-iteration series implementing remote object metadata queries for `git cat-file --batch-command`. The feature allows clients to request object information (currently just sizes) from protocol v2 servers without downloading full objects, with security hardening from prior iterations now complete.

The patch introduces client-side support in `fetch-object-info.[ch]` for the object-info capability, building on server-side work from Calvin Wan. Key aspects include:
- New `fetch_object_info()` function that handles protocol v2 negotiation and packet exchange
- Strict protocol version enforcement (v1 attempts error out)
- Support for the "size" feature with proper error handling
- Integration with the transport layer to enable the feature in fetch-pack operations
- The implementation uses ref-filter conventions for unsupported fields
- Adds comprehensive test coverage across git://, file:// and http:// transports
- Generalizes packet writing logic for reuse
- Documents wire format in commit messages
- Finalizes error reporting patterns

The series appears ready for integration, with all major technical concerns addressed across prior iterations. This patch completes the core client-side implementation, with the security-conscious protocol v2 implementation enabling batched object metadata queries while minimizing attack surface by allowing size verification before download.
