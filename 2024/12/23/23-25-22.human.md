This is the 5th patch in an 8-iteration series implementing remote object metadata queries for `git cat-file --batch-command`. The patch adds client-side support for requesting object information (currently just sizes) from protocol v2 servers without downloading full objects - a security-conscious feature that lets clients verify object sizes before download.

The implementation introduces new `fetch-object-info.[ch]` files to handle the protocol interaction, with careful error checking and packet handling. The client requires explicit server capability advertisement (controlled by `transfer.advertiseobjectinfo`) and fails cleanly if the server doesn't support the feature. The patch includes thorough transport layer integration across git://, file:// and http:// protocols.

This version represents the polished final state of the client implementation, with all major technical concerns addressed across prior iterations. The only remaining discussion point is a philosophical difference between Christian Couder and Patrick Steinhardt about format string stability for experimental features, but they agree this doesn't block merging. The series appears ready for integration after extensive review from core contributors.
