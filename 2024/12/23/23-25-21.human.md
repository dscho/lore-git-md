This is a feature patch in the security-hardened series enabling remote object metadata queries via `git cat-file --batch-command`. It's the 4th of 6 patches in the 8th iteration of this work.

The patch modifies the server-side advertisement of object-info capabilities, allowing clients to discover what metadata components (currently just "size") a server supports before making requests. The advertisement respects a new `transfer.advertiseobjectinfo` config (defaulting to off for security) and passes supported features (currently only "size") in the capability string.

This is a well-polished piece of the larger effort, with clear sign-off from key reviewers (Jonathan Tan and Christian Couder) who have been involved throughout the series. The implementation follows established protocol v2 patterns and maintains the conservative security posture established in earlier iterations - capabilities are off by default and must be explicitly enabled. The patch appears ready for integration as part of the complete series.
