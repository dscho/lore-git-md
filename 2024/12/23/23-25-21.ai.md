This is a feature patch in the ongoing series to enable remote object metadata queries via `git cat-file --batch-command`. The patch focuses on server-side capability advertisement for the new object-info feature.

The change modifies `serve.c` to advertise supported object-info features (currently just "size") when the server has the capability enabled via `transfer.advertiseobjectinfo` config. This allows clients to determine whether the server supports object-info queries before attempting them. The implementation follows the security-conscious approach established in prior iterations, keeping the feature disabled by default.

Key technical details:
- Adds feature advertisement string ("size") to protocol v2 capability negotiation
- Maintains default-off behavior via `transfer.advertiseobjectinfo` config
- Builds on Calvin Wan's original work with help from Jonathan Tan and Christian Couder
- Part of the final polishing phase (v8) where all major technical issues were resolved in earlier iterations

The patch is well-contained and aligns with the series' goal of enabling secure, batched object metadata queries without full downloads. It represents one of the last pieces needed before this feature can be integrated.
