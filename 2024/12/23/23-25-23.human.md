This is the final patch in an 8-part series adding remote object metadata query support to `git cat-file --batch-command`. The feature allows querying object sizes from remote repositories without downloading the full content, building on Calvin Wan's earlier protocol v2 work.

The patch introduces a new `remote-object-info` command for `git cat-file --batch-command` that can query multiple object sizes in a single request. It handles the remote protocol negotiation and implements the command for git://, file:// and http:// transports. The implementation includes comprehensive tests across all supported protocols.

Key technical points:
- Uses protocol v2's object-info capability (requires server support)
- Currently only supports size queries (object type support is planned)
- Batches multiple object queries to reduce round trips
- Maintains security by failing if server doesn't support the capability
- Includes extensive test coverage for edge cases and error conditions

The series has gone through 8 iterations with thorough review from Jonathan Tan, Christian Couder, and others. All major design questions have been resolved, and this final version represents polished, production-ready code. The implementation provides a secure way to verify object sizes before download while minimizing network overhead.
