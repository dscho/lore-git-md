This is the 8th iteration of a feature series adding remote object metadata queries to `git cat-file --batch-command`, building on Calvin Wan's earlier work. The series enables clients to request object information (currently just sizes) from protocol v2 servers without downloading full objects, with security hardening from prior iterations now complete.

The v8 changes focus on final polish: introducing proper strtoul error handling, splitting out test infrastructure into a preparatory commit, optimizing string list lookups, adding documentation links, and fixing minor formatting issues. The implementation remains focused on object size queries, deferring object type support to a follow-up series.

Key technical points:
- Maintains strict protocol v2 requirement (v1 attempts error out)
- Uses ref-filter conventions for unsupported fields
- Adds comprehensive test coverage across git://, file:// and http:// transports
- Generalizes packet writing logic for reuse
- Documents wire format in commit messages
- Finalizes error reporting patterns

The series appears ready for integration, with all major technical concerns addressed across 7 prior iterations. The remaining discussion between Christian Couder and Patrick Steinhardt about format string stability for experimental features represents a policy question rather than a blocking issue. The implementation provides a security-conscious way to verify object sizes before download while minimizing attack surface.
