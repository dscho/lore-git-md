This is a refactoring patch in the 8th iteration of a series that enables remote object metadata queries via `git cat-file --batch-command`. The patch moves initialization of fetch-pack variables from inside the state machine to just before it, preparing for a future change that will introduce an alternative initial state.

The change is mechanical and well-explained: three variables related to fetch behavior (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) are moved out of the `FETCH_CHECK_LOCAL` case to run unconditionally before the state machine starts. The commit message notes this doesn't change behavior since the code was already running first in the state machine.

The patch has received review from Jonathan Tan and Christian Couder (both noted in the Helped-by trailers) and appears to be a straightforward preparatory step for the larger feature. As part of a mature series that has gone through 8 iterations with thorough review, this change seems uncontroversial and ready for integration.
