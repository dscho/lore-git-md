This thread documents the systematic removal of legacy features in Git 3.0, focusing on reference naming conventions, command deprecation, and remote configuration changes. The effort has progressed through multiple iterations, with particular attention to backward compatibility and clear user guidance. The infrastructure is now complete, including build system flags (`WITH_BREAKING_CHANGES`), warning systems for deprecated features, and comprehensive CI validation.

Patrick Steinhardt has been the primary driver of this effort, with Junio Hamano providing historical context and user experience suggestions. The latest refinement came from Jakub Wilk, who noted an important distinction in the documentation between the mere presence of legacy "branches/" and "remotes/" directories (which were in default templates until recently) versus their active use in modern workflows (which is likely minimal). Patrick has agreed to incorporate this more precise wording into the documentation, either by accepting Jakub's patch or making the change himself. This follows Junio's validation of Jakub's observation, showing the maintainers' commitment to accurate communication about these breaking changes.
