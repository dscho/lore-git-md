This thread began as a bug report about keyboard unresponsiveness during `git add --patch` on Windows, which Johannes Schindelen (Git for Windows maintainer) confirmed as a known issue fixed in the upcoming v2.49.0 release. The discussion then shifted to the broader topic of release scheduling coordination between Git core and Git for Windows.

Johannes provided extensive industry references advocating against Friday releases, implicitly supporting Git for Windows' Monday schedule. In the latest exchange, Junio Hamano (Git maintainer) responds by asking for a more direct statement of preference rather than indirect arguments, maintaining a light tone but signaling he's looking for concrete proposals. While both sides acknowledge Friday releases may be suboptimal, there's no clear path yet for aligning the projects' schedules - Git core currently releases on Fridays while Git for Windows targets Mondays. The original technical issue remains resolved for the next Git for Windows release, with the thread now focused on maintainer coordination between the related but independent projects.
