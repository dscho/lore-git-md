This is the second patch in a 13-part series introducing a new `git url-parse` builtin command. The patch defines a new `url_parse()` function in urlmatch.[ch] that handles all Git URL formats including SCP-style URLs (like `hostname:~user/repo`).

Key technical points:
- The function shares the same interface as `url_normalize()` and uses the same `url_info` struct, making it easy to integrate with existing code
- It supports the same URL formats as Git's internal parsing in connect.c, including special handling for SSH/Git protocols and SCP-style syntax
- The implementation includes protocol detection (SSH, Git, file) and normalization of SCP-style URLs into a consistent form
- A new `enum protocol` is introduced to classify URL types

The patch appears to be a clean implementation that builds on the preparatory refactoring from patch 1. It maintains the same parsing behavior as Git's existing URL handling while making the functionality available more broadly. The code follows Git's style conventions and includes appropriate comments explaining the SCP-style URL handling.
