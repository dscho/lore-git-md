This is the first patch in a 13-part series introducing a new `git url-parse` command. It's a straightforward refactoring that moves the `url_is_local_not_ssh()` helper function from connect.c to url.[ch], where it more logically belongs as part of the URL handling infrastructure.

The change is mechanical and well-contained:
- Removes the function from connect.c and connect.h
- Adds it to url.c and url.h
- Updates remote.c to include the new url.h header

The patch appears clean and correctly implements the stated goal of making this URL-related function more widely available. This is a typical preparatory refactoring before introducing new functionality that will need to use this helper. The series overview suggests this will be used by the upcoming `url-parse` plumbing command.

Since this is just moving code without changing behavior, it's unlikely to be controversial. The test coverage mentioned in the cover letter presumably comes in later patches that exercise the new command.
