This is patch 7/13 in the `git url-parse` series, adding a string-to-enum converter for URL components. The patch introduces `get_component_or_die()`, which maps command-line arguments ("path", "host", etc.) to the `enum url_component` values defined in earlier patches.

The function follows the same error-handling pattern as `parse_or_die()` from patch 4, terminating with `die()` on invalid input. It provides the missing link between user-facing component names and the internal enum that the `extract()` function (added in patch 6) expects. This is a straightforward plumbing piece that enables the actual command-line interface to be built in subsequent patches.

The implementation covers all enum variants from patch 5's `enum url_component` (URL_PATH, URL_HOST, etc.) with direct string comparisons. The error message follows Git's typical style for invalid input cases. This patch continues the series' clean, incremental approach - each patch adds one well-defined capability while maintaining the overall architecture.
