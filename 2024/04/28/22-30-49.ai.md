This is the first patch in a 13-part series introducing a new `git url-parse` command. The patch performs a mechanical refactoring to move the `url_is_local_not_ssh()` helper function from connect.[ch] to url.[ch], where it will be more widely accessible for the new URL parsing functionality.

The change is straightforward - the function implementation moves from connect.c to url.c, its declaration moves from connect.h to url.h, and remote.c gains an include of url.h since it uses this function. The patch maintains the exact same behavior while making the function available to more parts of the codebase.

This appears to be a clean preparatory refactoring for the larger series. The commit message clearly explains the motivation (the function will be used in more places) and the change itself is a simple file relocation with no functional modifications. The patch follows Git's standard style and includes the necessary header adjustments.

As the first step in the series, this establishes the foundation for the subsequent patches that will build out the URL parsing infrastructure. The change is low-risk since it doesn't modify behavior, just organization. Reviewers would likely look for whether this is the right home for the function and whether any other callers need updating, but the limited scope suggests this is a solid starting point for the feature.
