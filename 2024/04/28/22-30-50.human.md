This is the second patch in a 13-part series introducing a new `git url-parse` builtin command. The series aims to expose Git's internal URL parsing logic as a plumbing command.

This patch defines the core `url_parse()` function in urlmatch.[ch] that will power the new command. The function handles all Git URL formats including SCP-style URLs (like `hostname:~user/repo`), matching Git's internal parsing behavior. It builds on the existing URL normalization infrastructure and uses the same data structures, making it easier to integrate with other parts of Git.

The implementation appears to be a careful adaptation of the parsing logic from connect.c, suggesting it should maintain compatibility with existing Git behavior. The patch includes support for various protocols (SSH, Git, file) and special handling for SCP-style syntax. The function signature matches `url_normalize()` for consistency.

As part of a larger plumbing effort, this patch looks like solid infrastructure work - it's focused, maintains existing behavior, and provides the foundation for the user-facing command to come in later patches.
