This is a documentation patch completing the `git url-parse` builtin series. The patch adds the man page for the new command, which parses Git URLs and extracts their components.

The documentation clearly explains the command's purpose - to handle Git's various URL formats (including SCP-style) that standard parsers can't process. It provides examples showing how to extract specific components like hostname and paths, as well as validate URLs without output.

The man page follows Git's standard format with NAME, SYNOPSIS, DESCRIPTION, OPTIONS, and EXAMPLES sections. The examples demonstrate both basic usage (extracting a single component) and edge cases like SCP-style path handling. The `--component` option is well-documented with all supported component types listed.

This completes the technical implementation from earlier patches with user-facing documentation, following Git's typical pattern for new commands. The documentation appears thorough and matches the functionality described in the cover letter and previous patches.
