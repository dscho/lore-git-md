This is patch 5/13 in a series introducing a new `git url-parse` builtin command. The patch defines an enum that enumerates all the URL components that users will be able to extract from Git URLs (protocol, user, password, host, port, and path), plus a URL_NONE case for when no specific component is requested.

The enum is a straightforward addition that follows naturally from the series' goal of exposing Git's URL parsing logic. It provides the foundation for the command-line interface that will let users select which URL components they want to extract. The implementation looks clean and aligns with the series' incremental approach - this patch builds on the URL parsing infrastructure introduced in earlier patches while setting up for the actual component extraction that will come later.

As part of a well-structured series with clear motivation (enabling external tools to reliably parse Git's various URL formats), this patch appears uncontroversial and ready for review. The next patches will presumably use this enum to implement the actual component selection and output functionality.
