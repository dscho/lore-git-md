This is patch 11/13 in the series introducing a new `git url-parse` builtin command. The patch implements the core functionality of extracting and printing URL components based on user selection.

The patch validates and parses each input URL (using the infrastructure from previous patches), then extracts the requested component (protocol, host, path etc.) using the new `extract()` helper. The extracted string is printed to stdout and properly freed. The implementation handles the case where no component is requested (URL_NONE) by skipping extraction.

The patch builds logically from the previous validation work in patch 10, now actually producing output the command was designed for. It maintains the series' clean separation of concerns and follows Git's memory management patterns (allocating with xstrndup in extract(), freeing results).

This appears to be a straightforward implementation of the component extraction feature promised in the cover letter. The next patches will likely add tests and documentation to complete the feature. The series continues to show careful, incremental development with each patch adding one well-defined capability.
