This is a feature proposal introducing a new `git url-parse` builtin command that exposes Git's internal URL parsing logic as a plumbing command. The 13-patch series comes from Matheus Moreira and aims to help scripts reliably parse Git's various URL formats (including non-standard ones like SCP-style URLs).

The motivation is that Git accepts many URL formats that standard parsers can't handle, making it difficult for scripts to reliably extract components (like hostnames) from Git URLs. The new command would let scripts delegate parsing to Git itself rather than trying to reimplement Git's URL logic.

Key aspects:
- Moves existing URL parsing helpers into shared headers
- Adds a new `builtin/url-parse.c` implementing the command
- Supports extracting specific URL components via command-line options
- Includes comprehensive documentation and tests
- Targets scripts that want to programmatically work with Git URLs
