This is patch 5/13 in the series introducing a new `git url-parse` builtin command. The patch adds an enumeration of URL components that the command will be able to extract from Git URLs.

The enum defines all the standard URL parts (protocol, user, password, host, port, path) plus a special `URL_NONE` value for cases where no specific component is requested. This provides the foundation for the command's component selection mechanism that will be implemented in later patches.

The implementation is straightforward and follows the series' pattern of building up the command's capabilities incrementally. The enum values align with the URL parsing infrastructure introduced in earlier patches, particularly the `url_info` struct that holds the parsed components.

This patch appears to be a simple but necessary building block for the overall feature. It doesn't yet implement any user-facing functionality - that will come in subsequent patches that use this enum to select which components to output. The series continues to show careful, incremental development with each patch adding a well-defined piece of the puzzle.
