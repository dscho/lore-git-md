This is patch 11 in a 13-part series introducing a new `git url-parse` builtin command. The series exposes Git's internal URL parsing logic as a standalone plumbing command, addressing the challenge of reliably parsing Git's various URL formats (including SCP-style URLs that standard parsers can't handle).

This particular patch implements the core functionality - extracting and printing the requested URL components. It:
1. Takes the user-specified component (via `-c/--component`) and converts it to an enum value
2. For each input URL, parses it and extracts the requested component using the `extract()` helper
3. Prints each extracted component on its own line, with proper memory cleanup

The implementation is straightforward and follows the plumbing command pattern seen elsewhere in Git. It builds on the infrastructure established in earlier patches (URL parsing, component enum, error handling) to deliver the main use case - letting scripts reliably extract specific parts of Git URLs.

The patch appears well-contained and properly handles memory allocation (freeing both the extracted strings and parsed URL info). As the series progresses toward completion, this represents a key piece that ties together the preparatory refactoring with the actual user-facing functionality.
