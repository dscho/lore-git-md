This is patch 7/13 in the series introducing a new `git url-parse` builtin command. The patch adds a helper function `get_component_or_die()` that converts string names of URL components ("path", "host", etc.) to their corresponding enum values defined in earlier patches.

The function provides a clean way to map user-facing component names to the internal enum used by the URL parsing machinery. It follows the same "or_die" pattern established in patch 4 for error handling, failing immediately with a descriptive message if an invalid component name is provided. This maintains consistency with the series' plumbing-style approach.

The implementation is straightforward and complete, covering all URL components defined in the enum from patch 5. This appears to be a building block for the command-line interface that will let users specify which URL component they want to extract. The series continues its careful, incremental approach with each patch adding a well-defined piece of functionality.
