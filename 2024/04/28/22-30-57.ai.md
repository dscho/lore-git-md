This is patch 9/13 in the series introducing a new `git url-parse` builtin command. The patch adds command-line option parsing to the skeleton implementation, using Git's standard parse-options.h infrastructure that was set up in the previous patch.

The change is straightforward - it calls parse_options() with the options and usage strings defined earlier in the series, removing processed options from argv before the main command logic (to be added in later patches) handles the remaining arguments (which will be the URLs to parse).

As part of the incremental build-up approach of this series, this patch:
- Completes the CLI interface foundation started in patch 8
- Prepares for the actual URL parsing implementation that will follow
- Maintains the series' clean separation of concerns
- Follows Git's standard pattern for builtin commands

The patch is mechanical and uncontroversial, being a necessary step toward the full implementation. It doesn't yet add any functionality beyond option parsing, which will be used by subsequent patches to control the URL component extraction behavior.
