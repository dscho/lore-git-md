Atomic push exit code propagation fix series by Jiang Xin and Patrick Steinhardt, now maintained by Patrick, has received final ack from Junio C Hamano and is ready for merging. The series addresses the long-standing issue where git-receive-pack failures during atomic pushes weren't properly reported back to the client. The comprehensive solution includes protocol changes (introducing ERROR_SEND_PACK_BAD_REF_STATUS in send-pack.h), transport layer fixes in send-pack.c and transport.c, and extensive test modernization across t5504-fetch-receive-strict.sh, t5543-atomic-push.sh, and t5548-push-porcelain.sh. Key technical improvements in the final v5 version include proper heredoc escaping, protocol-level error codes, clean connection closure via flush packet on failures, and complete test coverage for both local and HTTP transports. The collaboration between Jiang Xin (initial work), Patrick Steinhardt (implementation and test infrastructure), Eric Sunshine (test infrastructure review), and Junio C Hamano (final confirmation) has produced a robust solution that maintains backward compatibility while fixing all edge cases of atomic push error propagation, including receive-pack failures after successful ref updates. The series is now considered complete and will be merged into the main Git codebase.
