Atomic push exit code propagation fix series by Jiang Xin and Patrick Steinhardt, now maintained by Patrick. Addresses silent failure case where git-receive-pack errors during atomic pushes weren't properly reported back to pusher. Core issue: when ref updates succeed but receive-pack fails with non-zero exit, client incorrectly treats as success. Technical solution introduces ERROR_SEND_PACK_BAD_REF_STATUS (value 1) to distinguish ref status errors, modifies transport.c for consistent protocol behavior while detecting ref push failures, ensures graceful connection closure on atomic push failures.
