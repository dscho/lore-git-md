This thread centers on adding long option names for Git's `-S` and `-G` search functionality in `git log`. The proposed names in version 2 are `--patch-modifies` (for `-S`) and `--patch-grep` (for `-G`), chosen to emphasize that these options search patch content rather than reflecting implementation details. The patch is technically complete, updating documentation, tests, and core diff handling across multiple files while maintaining backward compatibility.

The naming discussion has evolved through two versions. Initial feedback on v1 raised concerns about alternatives like `--grep-in-patch` and `--pickaxe-grep`, particularly regarding consistency with existing `--pickaxe-*` options. The current proposal attempts to strike a balance with the `--patch-` prefix, though some may still prefer different naming approaches. While the implementation appears solid—with thorough updates to error messages, test coverage, and documentation—the thread remains open to further discussion about whether these are the clearest possible names before finalizing the change.
