This is a feature patch in the `git cat-file --batch-command` remote object info series, now in its 7th iteration. The patch focuses on advertising server capabilities for object information queries.

The change modifies `serve.c` to properly signal which object-info features the server supports, currently just "size" (with type handling deferred to future work). The advertisement respects the `transfer.advertiseobjectinfo` config, which remains disabled by default for security-conscious deployments. The patch builds on Calvin Wan's original work and incorporates feedback from Jonathan Tan and Christian Couder.

Key technical details:
- The `object_info_advertise()` function now populates a `strbuf` with supported features when advertising capabilities
- Server-side capability advertisement remains configurable via `transfer.advertiseobjectinfo`
- Only the "size" feature is advertised in this initial implementation
- The change maintains backward compatibility while enabling the new remote query functionality

This patch represents a core piece of the protocol negotiation needed for the larger feature, with all design decisions having been thoroughly discussed in prior iterations. The implementation is clean and focused, with clear documentation of the default-off security posture.
