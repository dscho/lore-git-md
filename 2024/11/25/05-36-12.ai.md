This is a refactoring patch in the 7th iteration of a series adding remote object info support to `git cat-file --batch-command`. The patch generalizes the packet writing logic in fetch-pack.c to be reusable for other protocol v2 operations beyond just fetch.

The key change moves `write_fetch_command_and_capabilities()` from fetch-pack.c to connect.c as the more generic `write_command_and_capabilities()`, making it available for other commands to use. The function now takes the command name as a parameter rather than hardcoding "fetch". The patch carefully preserves all existing capability advertisement behavior including session IDs, server options, and hash algorithm negotiation.

The refactoring includes handling the `transfer.advertisesid` config directly in connect.c rather than through fetch-pack's static variable, with analysis showing this is safe since the protocol v1-specific checks can be dropped. The implementation maintains all existing functionality while making the code more reusable for future protocol v2 commands.
