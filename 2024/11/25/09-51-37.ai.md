This is a code style review from Patrick Steinhardt on the 2nd patch of the 7th iteration of the remote object info series. The patch refactors packet writing logic from fetch-pack.c to connect.c for broader protocol v2 reuse.

Patrick points out two minor style issues: First, the patch unnecessarily includes "string-list.h" in connect.h when a forward declaration of `struct string_list` would suffice, noting this helps keep compilation times down. Second, he observes that the function documentation comment uses Go-style naming (starting with the function name) rather than Git's typical style.

These are small polish items on a patch that has already received extensive technical review from multiple contributors (Jonathan Tan and Christian Couder). The feedback comes from a protocol expert (Patrick Steinhardt) who has been closely involved in reviewing this series, and aligns with Git's code style conventions. The changes requested are straightforward to implement and don't affect the patch's functionality or the series' overall direction, which has already reached consensus.
