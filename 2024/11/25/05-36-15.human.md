This is a feature patch adding client-side support for remote object info queries to `git cat-file --batch-command`, part of a series now in its 7th iteration. The patch implements the transport layer plumbing needed to request object metadata from protocol v2 servers without downloading full objects, building on Calvin Wan's earlier server-side work.

The key technical decision here is that the client now strictly requires server support for the object-info capability, with no fallback to fetching objects when the capability is unavailable. This matches the maintainer consensus that server upgrades will make fallback unnecessary. The implementation handles the protocol negotiation and packet exchange for object size requests (type queries are deferred to future work).

The patch introduces new files `fetch-object-info.{c,h}` to encapsulate the protocol logic, with thorough error handling and integration with Git's existing transport infrastructure. It updates the fetch-pack state machine to handle object-info requests and adds appropriate protocol version checks in transport-helper.c. The changes are well-contained and maintain backward compatibility while enabling the new feature.

With all technical and design questions resolved in previous iterations, this appears ready for integration. The implementation shows careful attention to security and protocol correctness, with comprehensive test coverage in the series' other patches.
