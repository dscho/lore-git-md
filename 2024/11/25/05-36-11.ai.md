Code style cleanup in preparation for remote object info support. This is the first patch in the 7th iteration of a series adding protocol v2 object metadata queries to `git cat-file --batch-command`.

The patch moves variable declarations inside for loops where they are used, improving scoping and readability. It touches two files:
- `builtin/cat-file.c`: Moves declarations of loop counters `i` and `size_t i` inside their respective for loops across three functions (`dispatch_calls`, `free_cmds`, `batch_objects_command`)
- `fetch-pack.c`: Similarly moves a loop counter declaration inside the for loop for server options handling

The changes are mechanical and uncontroversial, with Christian Couder providing the initial suggestion. This cleanup precedes the substantive protocol v2 work in subsequent patches. The patch follows Git's coding style guidelines and maintains existing functionality while making the code more maintainable.
