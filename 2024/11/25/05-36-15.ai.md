This is a feature patch implementing client-side support for remote object info queries in protocol v2, part of a series now in its 7th iteration. The patch adds the core transport layer plumbing to request object metadata (currently just sizes) from servers that advertise the object-info capability, with no fallback to fetching full objects if unsupported.

The implementation introduces new files `fetch-object-info.[ch]` containing the protocol handling logic, plus transport layer changes to integrate the feature. The client will error out if the server lacks object-info support, following maintainer consensus that server upgrades will make fallback mechanisms unnecessary. The patch includes thorough error handling and maintains Git's security-conscious approach to protocol features.

Key technical details include:
- New `fetch_object_info()` function implementing the protocol exchange
- Transport layer changes to route object-info requests through existing connection infrastructure
- Strict protocol version checking (v2 only)
- Server capability advertisement checks before attempting requests
- Memory management for returned object size data
- Integration with the existing packet reader/writer infrastructure

The patch shows careful attention to code organization and style, with clear separation between protocol handling and transport integration. With all design questions resolved in previous iterations and positive reviews from protocol experts, this appears ready for integration as part of the larger series.
