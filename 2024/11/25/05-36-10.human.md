This is a feature patch series adding remote object info support to `git cat-file --batch-command`, now in its 7th iteration. The series builds on Calvin Wan's earlier work to enable querying object metadata from protocol v2 servers without full downloads.

The key change in v7 is the removal of the "fetch and inspect" fallback mechanism - now the command will error out if the server doesn't support the object-info capability, rather than falling back to downloading objects. This aligns with maintainer Junio Hamano's preference for protocol consistency over implementation pragmatism.

The 6-patch series refactors fetch-pack packet writing, moves fetch initialization, advertises the object-info capability, adds transport layer support, and implements the new `remote-object-info` command for `cat-file`. It includes comprehensive tests covering security edge cases and protocol version handling.

The implementation appears well-structured with thorough test coverage. All technical and style issues raised in previous iterations have been addressed, and the thread shows consensus among core contributors (Junio Hamano, Patrick Steinhardt, Taylor Blau, Christian Couder) on the final design. The series is now ready for integration pending final patch submission.

This represents a useful security-hardened feature for efficiently querying remote object metadata, particularly in large repositories where full downloads would be expensive. The removal of the fallback mechanism makes the behavior more predictable while maintaining the security properties established in earlier iterations.
