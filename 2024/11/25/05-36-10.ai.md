This is a feature patch series adding remote object info support to `git cat-file --batch-command`, now in its 7th iteration. The series implements client-side support for querying object metadata from protocol v2 servers without full downloads, building on Calvin Wan's prior work.

The key change in v7 is the removal of the "fetch and inspect" fallback mechanism that was present in earlier versions. The client now strictly requires server support for the object-info capability and will error out if unavailable, following maintainer consensus that server upgrades will make fallback unnecessary. The series includes comprehensive test updates to verify this new behavior across git://, file:// and http:// transports.

Technical implementation remains focused on object size queries, with object type handling deferred to future work. The series refactors fetch-pack packet writing, moves fetch initialization logic, advertises the object-info capability, and adds transport layer support before implementing the actual `remote-object-info` command for `cat-file`. Test coverage in t1017 is thorough, exercising security edge cases and protocol version requirements.

The patches show careful attention to code style and documentation updates, with Christian Couder and Junio Hamano having reviewed earlier versions. With all technical and design questions now resolved, this appears ready for integration pending final maintainer approval. The implementation aligns well with Git's security-conscious approach to protocol features while providing a useful optimization for remote repository queries.
