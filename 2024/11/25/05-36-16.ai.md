This is the final patch in a feature series adding remote object info support to `git cat-file --batch-command`. The patch implements the client-side `remote-object-info` command that allows querying object metadata from protocol v2 servers without full downloads.

The implementation handles multiple object IDs per command to reduce network overhead, with comprehensive test coverage across git://, file:// and http:// transports. The command currently only supports size queries (not object types or deltas) and requires explicit server capability advertisement. The patch includes thorough documentation updates and error handling for unsupported cases.

Key technical details:
- New `remote-object-info` command in `builtin/cat-file.c` that batches object info requests
- Transport layer integration via `fetch-object-info.[ch]` (added in earlier patches)
- Server capability checking via `transfer.advertiseobjectinfo` config
- Default format changed to `%(objectname) %(objectsize)` for remote queries
- Tests verify both successful queries and proper error cases (missing objects, unsupported filters, protocol requirements)

The implementation is clean and well-tested, with all design questions resolved in earlier iterations. This appears ready for integration as the final piece of the remote object info functionality.
