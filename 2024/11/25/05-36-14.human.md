This is a feature patch in the `git cat-file --batch-command` remote object info series, now in its 7th iteration. The patch focuses on advertising server capabilities for object metadata queries.

The change modifies `serve.c` to advertise which object-info features the server supports (currently just "size") when the capability is enabled. This lets clients know what they can query without needing to fetch objects first. The patch maintains the default behavior where object-info is disabled unless explicitly configured, following Git's security-conscious approach to new protocol features.

The implementation is straightforward - it extends the existing `object_info_advertise()` function to populate a `strbuf` with supported features when advertising is enabled. This builds on prior work by Calvin Wan and incorporates feedback from Jonathan Tan and Christian Couder, as seen in the sign-offs.

As part of the larger series that has now resolved all technical and design questions, this patch appears ready for integration. It's a small but important piece that enables clients to make informed decisions about whether to use the new remote object query capability.
