This is the 5th patch in a 6-part feature series adding remote object information querying to `git cat-file --batch-command`. The patch implements the client-side transport layer support for fetching object metadata without full downloads.

The key technical components are:
- New `fetch-object-info.[ch]` files implementing the protocol v2 client logic
- Integration with the transport layer to handle both direct object info requests and fallback to full fetches
- Support for the "size" capability when querying object metadata
- Comprehensive error handling and protocol version checking

The implementation:
- Creates a new `fetch_object_info()` function that handles the protocol v2 exchange
- Adds transport layer plumbing to support the new capability
- Implements fallback behavior when servers don't support object-info
- Includes thorough error checking and protocol version validation
- The patch builds on the refactoring work from earlier in the series (generalized packet writing in connect.c)
- Maintains security by requiring protocol v2 and validating server capabilities
- Uses existing transport infrastructure for the fallback path
- Adds the necessary Makefile and header file changes

Reviewers (Christian Couder, Jonathan Tan) have already approved the technical approach in previous iterations. The v6 changes focus on final style refinements and documentation improvements. This patch is now in its final form with all major technical concerns addressed.

The implementation positions this as a robust foundation for future extensions (like objecttype support) while providing immediate value through the size query capability. The comprehensive test coverage in t1017 ensures security and correct behavior across different server configurations.
