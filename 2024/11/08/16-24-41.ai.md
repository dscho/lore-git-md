This is the final patch in a feature series adding remote object information querying to `git cat-file --batch-command`. The patch implements the user-facing `remote-object-info` command that allows querying object sizes from remote repositories without downloading the full content.

The command supports multiple OIDs per invocation to reduce round trips, falling back to full fetches when the server doesn't support the object-info capability. The implementation:
- Adds the new command to `builtin/cat-file.c` with special handling for batch/buffer modes
- Implements transport integration via the new `fetch_object_info()` API from earlier patches
- Includes comprehensive tests covering git://, file://, and http:// transports
- Documents the command and current limitations (no objecttype/deltabase support yet)

The series has been through 6 iterations with thorough review from Christian Couder, Jonathan Tan, and Taylor Blau. Junio Hamano has indicated readiness to merge pending final style polish. This v6 addresses all remaining feedback with:
- Better organization of small changes in earlier commits
- Detailed descriptions of connect.c refactoring
- Fixed indentation issues
- Final loop variable scoping improvements

The implementation is production-ready with extensive test coverage in t1017 for security and edge cases. Two open design questions remain (protocol v1 behavior and objecttype support) but these don't block merging as they concern edge cases rather than core functionality.
