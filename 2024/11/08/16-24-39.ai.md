This is a feature patch that completes the server-side capability advertisement for the remote object-info query functionality. As part of the larger series adding `git cat-file --batch-command` remote object queries, this patch modifies `serve.c` to properly advertise the "size" capability when object-info is enabled.

The key change is making the `object_info_advertise()` function populate the `value` strbuf with "size" when the feature is enabled, allowing clients to know what specific capabilities are supported. The patch maintains the conservative default of keeping object-info disabled unless explicitly configured via `transfer.advertiseobjectinfo`.

This version incorporates feedback from Jonathan Tan and Christian Couder, with the final implementation cleanly separating the advertisement decision from the capability string construction. The change is minimal but important for the client-side functionality to work properly, as it allows clients to verify server support before attempting remote queries.

The patch is well-contained, touching only `serve.c` with a straightforward 4-line change that:
1. Removes the UNUSED annotation from the value parameter
2. Adds logic to populate the capability string when advertising is enabled
3. Explicitly lists "size" as the supported capability

This represents the final piece needed for the server-side implementation before the client-side functionality can be fully utilized. The patch is part of a series that has already undergone extensive review and is now in its final polishing stage.
