Feature patch adding remote object info querying to `git cat-file --batch-command`. This is the final patch in a 6-part series that has undergone extensive review and is now ready for merging.

The patch introduces a new `remote-object-info` command that lets users query object metadata from remote repositories without downloading the full objects. The command supports multiple OIDs per request to reduce network overhead. When the remote server supports the object-info capability (via `transfer.advertiseobjectinfo`), it returns just the requested metadata. Otherwise, it falls back to fetching the full objects.

Key implementation details:
- Uses protocol v2 for the remote queries
- Default output format is `%(objectname) %(objectsize)` (object type support is planned for future)
- Includes comprehensive tests covering git://, file:// and http:// transports
- Handles both capability-aware servers and fallback cases
- Supports buffered mode and NUL-delimited input

The patch builds on significant refactoring work in earlier patches of the series to generalize packet writing and transport handling. It represents the culmination of work originally started by Calvin Wan, now shepherded through multiple iterations by Eric Ju with input from Jonathan Tan, Christian Couder, and others.

With all technical issues resolved and only minor formatting tweaks addressed in this final version, the series has Junio Hamano's indication of readiness for merging. The implementation includes extensive test coverage and appears robust.
