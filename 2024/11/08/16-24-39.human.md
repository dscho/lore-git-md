This is the fourth patch in a 6-part series adding remote object information querying to `git cat-file --batch-command`. The patch focuses on server-side capability advertisement.

The change modifies `serve.c` to advertise the object-info feature to clients, specifically indicating support for the "size" capability. This allows clients to determine whether the server supports object-info queries before attempting them. The advertisement is controlled by the `transfer.advertiseobjectinfo` config, which remains disabled by default for security.

The patch is straightforward and well-contained, with Calvin Wan as the original author and Eric Ju carrying it forward through the series. It builds on prior protocol v2 work and has been reviewed by Jonathan Tan and Christian Couder. The implementation is now in its final form after addressing all feedback in previous iterations.

This is a key enabling piece for the overall feature, though most of the interesting work happens in the transport layer (patch 4/6) and user-facing command (patch 6/6). The change is small but important for the security model - keeping the capability opt-in prevents servers from unexpectedly exposing object information.
