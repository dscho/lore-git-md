This is a refactoring patch in a series adding remote object info querying to `git cat-file --batch-command`. Patch 2/6 generalizes the packet writing code from fetch-pack.c into a reusable `write_command_and_capabilities()` function in connect.c.

The change moves protocol v2 command initialization logic to a shared location, making it available for both fetch operations and the new object-info command. The key technical aspects are:
- Extracting the fetch-specific packet writing into a generic version that takes any command name
- Moving the function to connect.c where it can be used by other commands
- Handling the `advertise_sid` config safely in the new location
- Maintaining all existing protocol v2 capabilities (agent, session-id, server-options, object-format)

The patch has been through multiple rounds of review (with help from Jonathan Tan and Christian Couder) and addresses all previous feedback. It's a clean refactoring that enables the subsequent patches to implement the remote object info functionality while keeping the protocol handling code in one place. The implementation looks solid and well-tested as part of the larger series.
