This is the 5th patch in a 6-part series adding remote object information querying to `git cat-file --batch-command`. The series is now in its 6th iteration with all technical issues resolved and only minor style refinements remaining before merging.

The patch implements the transport layer support for querying object metadata from remote servers without full downloads. It introduces new files `fetch-object-info.[ch]` that handle the protocol v2 exchange, falling back to full fetches if needed. The key components are:

1. A new `fetch_object_info()` function that manages the protocol exchange
2. Support for requesting object information with the 'size' feature
3. Fallback to full fetch when the server doesn't support object-info
4. Integration with the existing transport infrastructure

The implementation includes comprehensive error handling and maintains security by requiring protocol v2. This represents the core transport machinery needed to support the user-facing `remote-object-info` command added in patch 6/6.
