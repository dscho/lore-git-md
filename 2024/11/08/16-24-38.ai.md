This is a refactoring patch in the 6th iteration of a series adding remote object info querying to `git cat-file --batch-command`. The patch moves initialization code for fetch-pack's state machine from inside the first state (FETCH_CHECK_LOCAL) to before the state machine begins, preparing for future extensions that may use different initial states while still needing these variables initialized.

The changes are mechanical and behavior-preserving, just relocating three variable initializations:
- `allow_unadvertised_object_request` flag setting
- `use_sideband` configuration
- `args->deepen` conditional setting

The patch has already been reviewed by Jonathan Tan and Christian Couder, with Junio Hamano indicating the series is ready for merging pending final style polish. This version (v6) represents the production-ready state of the series, with all technical and style feedback addressed. The change is part of broader architectural work to support secure remote object metadata queries via protocol v2.
