The changes affect low-level hashing operations like checksum validation and file writing.

While some structural cleanups remain for future work, this patch completes the core unification of hash variants, reducing API complexity while preserving safety.

The changes are part of a broader effort to make Git's hash algorithm handling more maintainable, particularly as work continues on SHA-256 interoperability.
