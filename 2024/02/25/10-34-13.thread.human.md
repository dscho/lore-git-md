This thread introduces a new feature to enable OAuth bearer authentication in `git-send-email`, addressing a gap where Perl's Authen::SASL module doesn't support OAuthBEARER and XOAUTH2 mechanisms. The patch implements these authentication types manually with proper TLS enforcement and error handling per RFCs 5801 and 7628.

The implementation adds core functions to generate and handle OAuth authentication strings, including `generate_oauthbearer_string()` and `smtp_bearer_auth()` for the SMTP command sequence. It comes with thorough documentation updates showing example configurations for Gmail and Office 365, though it requires proper credential helper setup to supply the bearer tokens. The patch has already gone through one revision (v2), fixing formatting and minor code issues from the initial submission, and includes a Tested-by from the git-credential-oauth maintainer. The changes appear well-considered, with clear RFC references and robust error handling, including dummy requests on auth failure to prevent information leakage.
