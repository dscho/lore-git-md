This thread is about Patrick Steinhardt's 23-part series refactoring how version information is embedded in Git's documentation. The current patch (part 6) moves version and date injection from command-line arguments to generated configuration files (asciidoc.conf and asciidoctor-extensions.rb) using GIT-VERSION-GEN, while maintaining the same output. The changes include adding .gitignore entries, removing direct git calls from Documentation/Makefile, and adding rules to generate config files from templates.

Renato Botelho noted that contrib/subtree/Makefile depends on these files and should trigger their build, though this appears to be a follow-up consideration rather than a critique of the current changes. The series as a whole represents a significant build system cleanup to centralize version information handling across Git's documentation.
