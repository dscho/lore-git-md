This is a feature patch implementing client-side support for remote object info queries in `git cat-file --batch-command`, part of Calvin Wan and Eric Ju's ongoing series to enable fetching object metadata without full downloads. The patch focuses on the transport layer implementation.

The patch adds a new `fetch-object-info.[ch]` module that handles the protocol v2 exchange for object info requests, including capability checking, request formatting, and response parsing. Key aspects:
- Enforces protocol v2 requirement (dies on v1 attempts)
- Implements fallback to full fetches when object-info isn't supported
- Uses `quiet` and `no_progress` flags to reduce verbosity during fallback
- Includes comprehensive test coverage
- Adds transport layer plumbing to connect the new functionality

The implementation builds on the server-side capability added in a2ba162cda and integrates with the existing fetch-pack machinery. Notable technical details:
- New `fetch_object_info()` function handles the protocol exchange
- `send_object_info_request()` formats requests with size capability
- Transport layer handles both direct object-info and fallback paths
- Object data is retrieved either from packets or downloaded packfiles

The patch has received thorough review from Jonathan Tan and Christian Couder, with all major technical concerns addressed. It represents a key piece of the end-to-end functionality for remote object queries, complementing the server capability advertisement patch earlier in the series.
