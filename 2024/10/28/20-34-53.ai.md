This is a refactoring patch in the `git cat-file --batch-command` remote object info series, moving initialization code in fetch-pack.c to prepare for supporting multiple initial states. The change relocates three variable initializations from inside the FETCH_CHECK_LOCAL state to just before the state machine begins, maintaining identical behavior while making the code more flexible for future extensions.

The patch moves:
1. `allow_unadvertised_object_request` flag setting
2. `use_sideband` configuration
3. `args->deepen` conditional setting

These were previously initialized in the first state (FETCH_CHECK_LOCAL) but are now set unconditionally before the state machine starts. The change is purely structural - no functional difference is introduced, as confirmed by the commit message. This prepares for a follow-up patch that will introduce an alternative initial state while still needing these same initializations.

The patch carries sign-offs from both the original author (Calvin Wan) and current series maintainer (Eric Ju), along with help acknowledgments from Jonathan Tan and Christian Couder. It's a straightforward mechanical change that has already been reviewed as part of the larger series.
