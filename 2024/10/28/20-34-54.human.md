This is a feature patch that enables servers to advertise object-info capabilities to clients, part of the ongoing effort to support remote object metadata lookups without full downloads. The patch modifies `serve.c` to advertise the "size" capability when `transfer.advertiseobjectinfo` is enabled, allowing clients to determine if the server supports this feature before attempting queries.

The change is minimal but important - it moves the capability advertisement from a simple boolean to including the specific supported features (currently just "size"). This follows the pattern of other Git capabilities where servers declare what they can actually provide. The patch carries sign-offs from both the original author (Calvin Wan) and current maintainer (Eric Ju), along with help tags from reviewers Jonathan Tan and Christian Couder.

This is patch 3/6 in a series that's nearing completion, with all major technical concerns addressed in previous iterations. The series as a whole adds secure remote object info queries to `git cat-file --batch-command`, with this patch handling the server-side capability advertisement piece.
