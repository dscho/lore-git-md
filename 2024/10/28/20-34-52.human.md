This is a refactoring patch that generalizes protocol v2 command writing in preparation for remote object info support. It's the first in a 6-part series adding `git cat-file --batch-command` integration for querying remote object metadata.

The patch moves and renames `write_fetch_command_and_capabilities()` from fetch-pack.c to connect.c as the more generic `write_command_and_capabilities()`, making it reusable for other protocol commands beyond just fetch. The function handles common protocol v2 setup like capability negotiation, session IDs, and hash algorithm verification.

This is a mechanical change with no behavior differences - the same code now lives in a more central location and takes the command name as a parameter. The patch has already been reviewed by Jonathan Tan and Christian Couder, with all feedback addressed in previous iterations. It serves as infrastructure for the subsequent patches that will add the actual remote object info functionality.
