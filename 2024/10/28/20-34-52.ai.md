This is a refactoring patch that generalizes protocol v2 command writing infrastructure as part of the remote object info feature series. The patch moves and renames `write_fetch_command_and_capabilities()` from fetch-pack.c to connect.c as the more generic `write_command_and_capabilities()`, making it reusable for other protocol commands beyond just fetch.

The refactored function handles the common protocol v2 preamble for any command - writing the command name, agent/session IDs, server options, and object format negotiation. This prepares for the new "object-info" command while keeping the existing fetch functionality unchanged. The implementation remains security-conscious, maintaining hash algorithm verification and capability checking.

Key changes:
- Moves the function to connect.c/h for broader accessibility
- Adds string-list.h include to connect.h for server_options parameter
- Updates all callers to pass the explicit "fetch" command name
- Preserves all existing error checking and capability handling

The patch carries forward sign-offs from both the original author (Calvin Wan) and current maintainer (Eric Ju) of the series, with help from Jonathan Tan and Christian Couder. This foundational change enables the subsequent patches to implement the remote object info functionality while keeping protocol handling centralized.
