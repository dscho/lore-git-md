This is a code style cleanup patch in the `git cat-file --batch-command` series, addressing a review comment about variable scoping. The change moves loop counter declarations inside their respective `for` loops rather than declaring them at function scope when they're only used within the loop. 

The patch makes three changes in `builtin/cat-file.c`:
1. Moves `int i` inside the `dispatch_calls()` loop and changes it to `size_t` to match the type of `nr`
2. Moves `size_t i` inside the `free_cmds()` loop
3. Moves `int i` inside the `batch_objects_command()` loop and changes it to `size_t` to match `ARRAY_SIZE`

This is a straightforward improvement that tightens variable scoping and makes the code more readable by reducing unnecessary variable declarations at function scope. The change was suggested by Christian Couder and carries his Helped-by tag. As a pure style change with no functional impact, it helps clean up the codebase while the larger feature series moves toward completion.
