This is a refactoring patch in a series adding remote object info support to `git cat-file --batch-command`. It's the second of six patches in v5 of the series, which builds on Calvin Wan's earlier work.

The patch moves initialization of fetch-pack variables (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) from inside the `FETCH_CHECK_LOCAL` state to just before the state machine begins. This prepares for a future change where the state machine might start in a different initial state while still needing these variables initialized. The change is purely mechanical with no behavior difference - it just relocates the initialization code to a more logical location since these variables are needed regardless of the starting state.

The patch has already been reviewed by Jonathan Tan and Christian Couder, who provided help shaping it, and carries both Calvin Wan's and Eric Ju's sign-offs. It's a straightforward preparatory change that helps enable the larger feature being developed in this series.
