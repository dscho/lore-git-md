This is a feature patch that enables servers to advertise object-info capabilities to clients, part of the ongoing effort to support remote object metadata lookups without full downloads. The patch modifies `serve.c` to conditionally advertise the "size" capability when `transfer.advertiseobjectinfo` is enabled, allowing clients to determine if the server supports object size queries before attempting them.

The change is minimal but important - it moves the capability advertisement from a silent boolean to an explicit string-based feature list (currently just "size"), while maintaining the default disabled state for security. The patch carries sign-offs from both the original author (Calvin Wan) and current maintainer (Eric Ju), plus acknowledgments from reviewers Jonathan Tan and Christian Couder who helped shape earlier versions.

This is patch 3/6 in a series that has already undergone significant review, with the main architectural decisions settled in prior iterations. The implementation here is straightforward and focused, touching only the server-side advertisement while leaving the actual protocol handling to other patches in the series. The thread context shows this capability advertisement was a known missing piece that completes the end-to-end functionality.
