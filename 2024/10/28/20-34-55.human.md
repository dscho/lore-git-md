This is a feature patch implementing client-side support for remote object info queries, part of the ongoing effort to enable metadata lookups without full object downloads. The patch builds on Calvin Wan's earlier server-side implementation and is now being shepherded by Eric Ju.

The patch adds transport layer plumbing to request object metadata (currently just sizes) from protocol v2 servers, falling back to full fetches when the capability isn't supported. Key components include:

- A new `fetch-object-info.[ch]` module handling the protocol exchange
- Transport layer integration that checks capabilities and processes responses
- Fallback behavior that downloads full objects when metadata queries fail
- Protocol v2 enforcement (rejecting v1 attempts)
- Comprehensive error handling and edge case coverage

The implementation shows careful attention to security and backward compatibility. It maintains the series' focus on incremental rollout - starting with size queries while leaving room for future extensions like object type support. Review feedback from Jonathan Tan and Christian Couder has been incorporated, addressing both technical correctness and code organization.

This patch completes the client-side plumbing needed for the final `git cat-file --batch-command` integration (coming in patch 6/6). The series appears well-structured and ready for consideration, with only minor documentation refinements remaining before potential merging.
