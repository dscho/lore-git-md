Git commit message attribution discussion (revisiting 2024 thread between Kristoffer Haugsbakk and Jeff King). Topic: comparing bracketed annotation lines (e.g. `[kh: Added tests]`) versus formal trailers (e.g. `Comment: Added tests`) for non-code contributions when combined with Signed-off-by lines.

Technical context: Junio Hamano's 2023 email established that bracketed lines become "non-trailer values" discarded by `git interpret-trailers`, while formal trailers persist through parsing. Haugsbakk argues signoff order already handles attribution, making brackets redundant. Jeff King previously raised practical concerns about avoiding forged signoffs when adding commit messages.

Open questions: Should Git standardize on one approach? Do brackets provide any advantage given their parsing behavior? How to balance attribution clarity with commit message hygiene? Discussion remains active with no clear consensus yet.
