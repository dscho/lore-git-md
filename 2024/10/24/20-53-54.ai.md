This is the first patch in a 6-part series implementing remote object info queries via `git cat-file --batch-command`. The patch refactors packet writing code in fetch-pack.c to make it reusable for both fetch operations and the new object-info command.

The key change generalizes `write_fetch_command_and_capabilities()` into `write_command_and_capabilities()`, allowing it to handle any protocol v2 command (not just "fetch"). This prepares the infrastructure for the new "object-info" command while maintaining all existing fetch functionality. The patch also adds a new `send_object_info_request()` function that will be used by the remote object info feature.

Technical details include:
- The refactored function now takes a `command` parameter instead of hardcoding "fetch"
- Protocol v2 capability negotiation remains unchanged
- New helper function `send_object_info_request()` handles the object-info specific packet formatting
- All existing fetch call sites are updated to pass "fetch" explicitly
- The patch maintains backward compatibility while enabling the new feature
- Christian Couder and Jonathan Tan provided guidance on the refactoring

This foundational change enables the subsequent patches to implement the remote object info functionality while keeping the packet writing logic DRY. The patch shows careful attention to maintaining existing behavior while extending the code's capabilities.
