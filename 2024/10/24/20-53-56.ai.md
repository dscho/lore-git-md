This is the third patch in a 6-part series implementing remote object info queries via `git cat-file --batch-command`. The patch focuses on server-side capability advertisement.

The change modifies `serve.c` to advertise object-info capabilities to clients when enabled via `transfer.advertiseobjectinfo` config. The key addition is advertising the "size" capability when object-info is enabled, allowing clients to detect server support before making requests. The patch maintains the default disabled state for security but provides the plumbing for servers to opt-in.

This is a straightforward capability advertisement patch that builds on the prior infrastructure work. It carries sign-offs from both the original author (Calvin Wan) and current submitter (Eric Ju), with acknowledged help from Jonathan Tan and Christian Couder. The change is minimal (4 lines) and focused solely on the advertisement mechanism, leaving the actual object-info handling to later patches in the series.

The patch appears ready for inclusion, having addressed prior review feedback about capability advertisement design. It properly separates the advertisement mechanism from the actual implementation that follows in subsequent patches.
