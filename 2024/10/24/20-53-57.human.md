This is the fourth patch in a 6-part series implementing remote object info queries via `git cat-file --batch-command`. The patch adds client-side transport support for efficiently retrieving object metadata from remote servers without full downloads.

The implementation builds on Calvin Wan's earlier server-side work, adding a new `fetch_object_info()` function in transport.c that handles protocol v2 communication with servers supporting the object-info capability. Key features include:

- Server capability negotiation to check for object-info support before making requests
- Fallback to full fetches when the server lacks the capability
- Protocol v2 enforcement (failing gracefully for v1/v0)
- Size information retrieval via the 'size' feature
- Memory management for the returned object data

The patch touches several transport-related files (fetch-pack.c, transport.c, transport-helper.c) to wire up the new functionality while maintaining existing behavior. It includes thorough error handling and follows Git's established patterns for protocol communication.

Review feedback from Jonathan Tan and Christian Couder has been incorporated, and the patch carries both authors' sign-offs. This appears to be a well-constructed addition to Git's remote object query capabilities, with careful attention to protocol details and backward compatibility.
