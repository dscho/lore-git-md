This is the final version of a 6-patch series implementing `git cat-file --batch-command` support for querying remote object metadata without full downloads, building on Calvin Wan's earlier work. The series adds a `remote-object-info` command that uses protocol v2 to efficiently retrieve object information from servers that support the capability.

The implementation includes comprehensive security hardening from prior iterations, with server-side protections (format string validation, request limits) and client-side protocol v2 enforcement. The final patch (6/6) focuses on documentation improvements and test organization, factoring out shared test helpers into a new `lib-cat-file.sh` while maintaining thorough test coverage across different transports.

Key technical points in this final version:
- Added prominent WARNING in documentation about future format changes when object type support is added
- Fixed remaining style issues in fetch-pack.c (arrow operator spacing)
- Improved grammar and formatting in documentation
- Consolidated test helper functions from t1006 and t1017 into lib-cat-file.sh
- Maintained all security measures from earlier versions

The series appears ready for maintainer consideration, having addressed all major review feedback from Christian Couder and others. Two open questions remain about user-facing behavior (protocol v1 handling and objecttype support), but these don't block the technical implementation. The comprehensive test suite and careful attention to security make this a robust addition to Git's remote object query capabilities.
