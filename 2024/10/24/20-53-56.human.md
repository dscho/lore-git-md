This is the third patch in a 6-part series adding remote object info capabilities to Git. The patch focuses on server-side advertisement of the new feature.

The change modifies `serve.c` to advertise object-info capabilities when the server is configured with `transfer.advertiseobjectinfo`. The advertisement includes a "size" capability, allowing clients to know the server can provide object size information. This enables clients to decide whether to use the new remote query feature or fall back to full downloads.

The patch carries sign-offs from both the original author (Calvin Wan) and current submitter (Eric Ju), with acknowledged help from Jonathan Tan and Christian Couder. It's a straightforward change that completes the server-side signaling portion of the larger remote object info feature.

As part of a well-reviewed series that has already addressed major technical and security concerns, this patch appears ready for consideration. The implementation follows the project's pattern for capability advertisement while maintaining the conservative default of requiring explicit server configuration to enable the feature.
