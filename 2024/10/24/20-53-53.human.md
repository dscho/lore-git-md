This is the final patch series adding `remote-object-info` support to `git cat-file --batch-command`, completing a feature that allows querying object metadata from remote servers without full downloads. The series builds on Calvin Wan's earlier work and has undergone multiple rounds of review.

The implementation now includes all refinements from the review process:
- Added a prominent warning in documentation about future format changes when object type support is added
- Factored out shared test helpers into a new `lib-cat-file.sh` file
- Fixed various code style issues (comment formatting, variable scoping, arrow operator spacing)
- Maintained comprehensive test coverage across different transport protocols

The series remains focused on object size queries for now, with object type support planned for future work. Two open questions about protocol v1 handling and object type behavior are noted for discussion, but these don't block the current implementation.

Review feedback from Christian Couder and others has been fully incorporated, and the series appears ready for maintainer consideration. The changes since v3 are minor documentation and test organization improvements. This represents the culmination of a well-reviewed effort to add secure remote object querying capabilities to Git's object inspection tools.
