This is the final patch in a security-hardened series adding remote object info querying to `git cat-file --batch-command`. The patch implements the user-facing `remote-object-info` command that allows querying object metadata from remotes without full downloads.

The implementation follows multiple rounds of review addressing security concerns, protocol handling, and code quality. Key features include:
- Support for batching multiple OIDs in a single command to reduce network overhead
- Protocol v2 requirement with fallback to full fetch when unsupported
- Comprehensive transport protocol testing across git://, file:// and http://
- Current limitation to object size queries (type support planned for future)

Eric Ju incorporates final review feedback from Christian Couder, including:
- Adding a prominent WARNING about future format changes when object type support is added
- Moving shared test helpers into a new `lib-cat-file.sh` file
- Minor grammatical fixes in documentation

The series appears ready for maintainer consideration, having addressed all major technical concerns through multiple review iterations. The implementation demonstrates careful attention to security, with protocol enforcement, strict response parsing, and transport layer hardening.
