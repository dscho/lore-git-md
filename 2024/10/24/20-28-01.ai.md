This is the final patch in a security-hardened series implementing remote object info queries via `git cat-file --batch-command`. The patch adds the `remote-object-info` command that allows querying object metadata from remotes without full downloads, completing the feature with all review feedback incorporated.

Eric Ju addresses Christian Couder's review comments from the previous version:

1. Adds a prominent WARNING notice about future format changes when object type support is added, cautioning users not to rely on the current `%(objectname) %(objectsize)` default format in scripts.

2. Factors out test helper functions (`echo_without_newline` etc.) that were duplicated from t1006-cat-file.sh into a new shared `lib-cat-file.sh` file, rather than just adding a TODO comment as originally suggested.

3. Makes the minor wording change from "print the info" to "printing the info" for grammatical consistency.

The implementation remains functionally unchanged from the previous version - it still enforces protocol v2, supports multiple OID batching, and falls back to full fetches when the server lacks the capability. The test suite in t1017-cat-file-remote-object-info.sh provides comprehensive coverage of the feature across different transports.

With these final documentation and test organization improvements, the series appears ready for maintainer consideration. The changes demonstrate responsiveness to review feedback while maintaining the security-focused design that has characterized this effort throughout its development.
