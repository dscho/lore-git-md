This is the first patch in a 6-part series that adds remote object info querying to `git cat-file --batch-command`. The patch refactors packet writing code in `fetch-pack.c` to make it reusable for both fetch operations and the new object-info command.

The key change generalizes `write_fetch_command_and_capabilities()` into `write_command_and_capabilities()`, allowing it to handle any protocol v2 command. This prepares the infrastructure for the remote object info feature while maintaining existing fetch functionality. The patch also introduces `send_object_info_request()` which will be used by later patches to send object info queries.

The refactoring is clean and focused, with Calvin Wan and Jonathan Tan providing guidance. The changes maintain backward compatibility while enabling the new functionality. This foundational work sets up the protocol handling that the rest of the series will build upon.
