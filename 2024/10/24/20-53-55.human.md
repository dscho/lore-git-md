This is a refactoring patch in a 6-part series implementing remote object info queries via `git cat-file --batch-command`. The patch moves initialization of fetch-pack variables from inside the state machine to just before it, preparing for future changes where different initial states will need the same setup.

The change is mechanical - no behavior changes, just moving three variable initializations (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) out of the `FETCH_CHECK_LOCAL` case to before the state machine loop. This makes the codebase more maintainable by centralizing initialization that will be needed regardless of which state the machine starts in.

The patch has already been reviewed by Jonathan Tan and Christian Couder, with their sign-offs indicating approval. It's a straightforward preparation step for the larger feature being introduced in the series.
