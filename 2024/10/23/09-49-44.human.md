This is a review follow-up in the security-hardened remote object info series, which adds a `remote-object-info` command to `git cat-file --batch-command` for querying object metadata from remotes without full downloads. Christian Couder provides final polish on the 6/6 implementation patch.

The review focuses on documentation clarity:
1. Suggests rewording a sentence about printing object info for better flow
2. Strongly recommends adding a clear WARNING about the default format changing when objecttype support is added (currently only objectsize is supported)
3. Notes that test helper functions were copied from t1006-cat-file.sh and suggests adding a TODO about potential future refactoring into a shared library

These are minor documentation and code organization nits on an otherwise complete and well-tested feature. The series has already incorporated extensive review feedback and appears ready for merging, with Christian giving his approval aside from these final small suggestions. The warning about format changes is particularly important as it affects backward compatibility when the feature expands.
