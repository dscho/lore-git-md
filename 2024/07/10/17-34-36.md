It sounds like you're writing about Git for Windows, which is maintained separately at https://github.com/git-for-windows/git/.  You'd probably want to report this there, since the utility you're describing isn't a part of core Git.

I will just say that it sounds like you have some sort of corporate proxy which is intercepting and tampering with the request, because I'm pretty sure Git for Windows is using TLS for updates and therefore must have provided a valid domain to curl.  If so, you'll want to try without that proxy first, since if it _is_ the cause, obviously the Git for Windows project won't be able to fix it.
