Christian Couder's promisor-remote/Large Object Promisor (LOP) series in v4 introduces protocol v2 support through a "promisor-remote" capability, with server-side advertisement via `promisor.advertise` (default false) and client-side acceptance control via `promisor.acceptFromServer` (now expanded from "None"/"All" to include "KnownName" and "KnownUrl" matching modes). The capability format handles urlencoded remote names with optional URLs.

Implementation spans:
- Server-side capability handling in `promisor-remote.c` with new functions
- Client-side response processing in `connect.c` including new strvec_find_index() helper
- Enhanced should_accept_remote() logic for name/URL matching
- Comprehensive t5710 test coverage for all config combinations
- Security-maintaining design where proxy configurations remain client-controlled

The series builds on prior standardization efforts including:
- String handling improvements via exported `redact_non_printables()`
- ASCII check replacements with `isprint()`
- Memory management refinements using `strbuf_detach()`
- Preserved special space character handling
