This is a feature patch in a series adding remote object info support to `git cat-file --batch-command`. The patch focuses on server-side capability advertisement for the new remote object info feature.

The patch modifies `serve.c` to advertise supported object-info features (currently just "size") when the server is configured with `transfer.advertiseobjectinfo`. The advertisement allows clients determine whether to query the server for object info or fall back to fetching objects directly. The key change is modifying the `object_info_advertise()` function to populate a strbuf with supported features ("size") when advertising is enabled, while maintaining the existing default-disable behavior.

This is part of the larger security-hardened remote object info feature that's been through multiple refinement rounds. The patch carries sign-offs from Calvin Wan (original author) and Eric Ju (current submitter), with help from Jonathan Tan and Christian Couder noted in the commit message. The change is relatively straightforward but important for the client-server negotiation protocol, building on the security foundations established in earlier iterations of the series.
