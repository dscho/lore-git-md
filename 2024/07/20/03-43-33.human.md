This is a refactoring patch in a series adding remote object info support to `git cat-file --batch-command`. It's the second of six patches, moving initialization code in `fetch-pack.c` to prepare for future changes.

The patch relocates some variable setup code from inside the `FETCH_CHECK_LOCAL` state to just before the state machine begins. This is a mechanical change with no behavior difference - the same variables get initialized at the same time, but now the initialization will apply regardless of which state the machine starts in. The change anticipates a future patch that will introduce an alternative starting state while still needing these same initializations.

The patch comes with sign-offs from Calvin Wan (the original author) and Eric Ju (the submitter), plus acknowledgments from Jonathan Tan and Christian Couder for their review help. The change is straightforward and uncontroversial, focused purely on code organization in service of the larger feature being developed.
