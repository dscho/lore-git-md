This is a feature patch adding client-side support for remote object info queries to `git cat-file --batch-command`, part of a 6-patch series. The patch implements the transport layer plumbing needed to request object metadata from protocol v2 servers without full downloads, building on Calvin Wan's earlier server-side work.

The key addition is a new `fetch_object_info()` function in transport.c that handles the protocol v2 communication, including capability negotiation and response parsing. The implementation enforces security constraints like format string validation and request limits. The client will fall back to full objects if the server doesn't support the feature.

Notable technical details include:
- New `object_info_args` struct to encapsulate request parameters
- Protocol v2 requirement (v1 attempts error out)
- Server capability checking before making requests
- Support for size queries (with objecttype handling left for future work)
- Memory management for transport resources and response data

The patch appears well-structured with thorough error handling. It follows the established pattern of the series by maintaining security constraints while providing the needed transport plumbing. The implementation builds cleanly on existing protocol infrastructure and includes appropriate fallback behavior.
