This is a refactoring patch that's part of a larger series adding remote object info support to `git cat-file --batch-command`. The patch generalizes the packet-writing function in fetch-pack.c to handle capabilities for any protocol v2 command, not just "fetch". 

The change renames `write_fetch_command_and_capabilities()` to `write_command_and_capabilities()` and makes it take the command name as a parameter. This prepares the codebase for the upcoming remote object info feature, which will use the same capability-writing logic but for a different command. The patch maintains all existing functionality while making the code more reusable.

The change is straightforward and mechanical, with the main work being parameterizing the command name. It's signed off by both Calvin Wan (the original author of the series) and Eric Ju (who is carrying it forward), with help from Jonathan Tan and Christian Couder. The patch appears well-contained and low-risk, serving as a foundation for the more substantial changes that follow in the series.
