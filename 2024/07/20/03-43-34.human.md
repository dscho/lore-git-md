Security feature patch adding server-side capability advertisement for remote object info queries. This is patch 3/6 in a series implementing secure remote object metadata access via `git cat-file --batch-command`. The patch modifies `serve.c` to advertise supported object-info features (currently just "size") when the server is configured with `transfer.advertiseobjectinfo`.

The change allows clients to determine what object-info capabilities a server supports before attempting queries. The implementation builds on Calvin Wan's earlier work with help from Jonathan Tan and Christian Couder, and maintains the series' security focus by keeping the feature disabled by default (requiring explicit server configuration).

This is a straightforward infrastructure piece in the larger security-hardened remote query system. The patch follows the series' established pattern of careful capability negotiation while keeping the initial feature set minimal (only size queries for now). The series appears well-vetted with multiple rounds of review from security-conscious contributors.
