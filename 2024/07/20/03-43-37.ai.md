This is the final patch in a feature series adding remote object info support to `git cat-file --batch-command`. The patch implements the `remote-object-info` command that allows querying object metadata from remote repositories without full downloads, building on Calvin Wan's earlier work.

The implementation:
- Adds `remote-object-info <remote> <oid>...` command to batch-command mode
- Supports multiple OIDs per command to reduce network overhead
- Falls back to downloading objects if server lacks object-info capability
- Currently only supports object size queries (objecttype handling is future work)
- Includes extensive test coverage across git://, file://, and http:// transports
- Handles edge cases like malformed OIDs and protocol version requirements

Key technical changes:
- New `parse_cmd_remote_object_info()` function in builtin/cat-file.c
- Transport layer integration via `fetch_object_info()`
- Memory management helpers in object-file.c
- Comprehensive test suite in t1017 covering various scenarios

The patch appears well-structured with thorough test coverage, completing the series' goal of adding secure remote object queries. It addresses prior review feedback and maintains consistency with Git's existing protocol architecture. The remaining limitations (objecttype support) are noted as future work rather than blockers.
