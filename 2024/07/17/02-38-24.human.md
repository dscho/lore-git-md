This is the final patch in a series adding remote object info support to `git cat-file --batch-command`. The feature allows querying object metadata from remote servers without downloading full objects, building on twelve prior refinement rounds.

The patch implements the `remote-object-info` command for `git cat-file --batch-command`, which can take multiple object IDs at once to reduce round trips. It works across git://, file://, and http:// transports when the server advertises support via `transfer.advertiseobjectinfo`. The implementation includes security hardening like strict protocol v2 requirements and format string validation.

In response to Karthik Nayak's review, Peijian Ju addresses several technical issues in the implementation:
- Memory management improvements including proper cleanup of allocated resources
- Simplifying the command handling by creating a dedicated `parse_cmd_remote_info` function
- Adding test coverage for NUL-delimited input and edge cases
- Clarifying documentation about currently unsupported format fields (objecttype, objectsize:disk, deltabase)

The patch appears functionally complete, with some remaining polish needed around test coverage and memory management that will be addressed in v2. The implementation has benefited from extensive review from multiple contributors including Jeff King, Junio Hamano, and Jonathan Tan.
