`rebase --exec` doesn't obey --quiet and end up printing a few messages
about the cmd being executed:

```
  git rebase HEAD~3 --quiet --exec "printf foo >/dev/null"
  Executing: printf foo >/dev/null
  Executing: printf foo >/dev/null
  Executing: printf foo >/dev/null

```

Let's fix that.
