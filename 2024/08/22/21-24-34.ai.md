Security feature completing the remote object info series. This is the final patch in a series implementing `git cat-file --batch-command` integration for securely querying object metadata from remote repositories without full downloads. The implementation builds on Calvin Wan's earlier work and incorporates extensive security hardening from multiple rounds of review.

The v2 iteration addresses all feedback from the initial review, with particular attention to memory management cleanup, expanded test coverage, and code structure. Key technical elements remain unchanged: strict protocol v2 requirements, server-side request limits (8KB URLs, 10k objects/request), and comprehensive security constraints including format string allow-listing. The implementation now properly handles NUL-delimited input and includes tests for protocol fallback behavior and malformed OID handling.

Reviewers including Jeff King, Junio Hamano, and Jonathan Tan have contributed security and style improvements throughout the series. The final patch focuses on robust command parsing and multi-OID support while maintaining the established security model. Remaining limitations (like objecttype handling) are documented as future work rather than blockers, making this ready for final consideration. The thorough test suite in t1017 exercises all major functionality and edge cases.
