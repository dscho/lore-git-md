This is a version update for a security-hardened feature adding remote object info support to `git cat-file --batch-command`. The series, originally started by Calvin Wan and now completed by Peijian Ju, enables querying object metadata from remote repositories without full downloads.

The v2 iteration addresses all feedback from the initial review, maintaining the strict security constraints (protocol v2 requirement, request limits, format validation) while improving the implementation. The final patch adds the `remote-object-info` command with comprehensive test coverage for edge cases and transport variations.

Notable aspects include:
- Server-side capability advertised via `transfer.advertiseobjectinfo`
- Client-side support across git://, file://, and http:// transports
- Multiple-OID batching to reduce network overhead
- Fallback to full object download when server lacks capability

The series appears technically complete with all major concerns resolved, though some non-blocking questions remain about protocol v1 behavior and future objecttype support. The implementation has been reviewed by multiple domain experts including Jeff King (security), Junio Hamano (style), and Jonathan Tan (transport layer).
