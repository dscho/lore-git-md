This thread addresses a bug in gitk where the external diff feature fails to properly handle renamed files between commits. The proposed fix, now in its fourth iteration, introduces a new `check_for_renames_in_diff` procedure that parses Git's rename markers to correctly identify file paths regardless of selection order. The solution is implemented purely in gitk's Tcl script with minimal changes (43 lines added, 2 modified).

The patch series has evolved through several versions, with v1/v2 including an experimental GUI toggle that was later removed based on feedback. Johannes Sixt, the gitk maintainer, has been actively involved, providing specific style recommendations about using present tense in behavior descriptions and imperative mood for commit messages. Tobias Boesch, the patch author, has been responsive to this guidance, as seen in his latest acknowledgment email where he confirms he'll update the commit messages accordingly. While the technical solution appears sound and narrowly focused, Johannes hasn't yet completed his final review of v4. The thread remains open pending this maintainer sign-off, but all substantive technical discussion appears resolved.
