This thread documents the completion of Rust bindings for Git's C library, implemented through two crates (`libgit-sys` for FFI bindings and `libgit` for idiomatic Rust wrappers). The v9 series marks the conclusion of this foundational work, which remains contained in `contrib/` without impacting Git's core functionality.

The implementation is now complete with all technical and stylistic issues resolved. The `libgit-sys` crate provides comprehensive FFI bindings to `libgit.a`, including symbol visibility management and full exposure of the configset API through safe wrappers. The final patch in v9 completes the higher-level `libgit` crate, introducing proper Rust ownership semantics via RAII patterns and safe methods for config operations. The build system integrates both crates and maintains Rust 1.63+ compatibility.

Key participants Junio C Hamano, Josh Steadmon, and Phillip Wood have reviewed the series, with all feedback addressed across iterations. Phillip Wood in particular provided crucial input on memory management that shaped the final API design. The work has maintainer approval and has been validated through real-world use in the JJ version control system. While future expansion of the Rust API surface is anticipated, the current implementation provides a solid foundation for Rust integration with Git's C codebase.
