This thread introduces Rust bindings for Git's C library through two crates: `libgit-sys` (low-level FFI bindings) and `libgit` (higher-level Rust API). The work has progressed through several versions, with the latest patch completing the build system integration by adding Makefile support for building and testing the Rust crates through Git's standard build workflow.

The implementation provides two layers: a foundational FFI` layer exposing Git's config API with proper memory management, and an idiomatic Rust wrapper crate with RAII semantics. The final patch adds `libgitrs` and `libgitrs-sys` Makefile targets along with an `INCLUDE_LIBGIT_RS` build flag, making the Rust components buildable through Git's standard Makefile while keeping them optional. The work maintains Rust 1.63+ compatibility and includes thorough test coverage at both abstraction layers.

All changes remain contained in `contrib/`, leaving core Git functionality unaffected. The implementation appears production-ready, with the versioning strategy being the only outstanding issue noted for follow-up work. The series represents a significant step in Git's Rust integration efforts while maintaining the project's build system conventions.
