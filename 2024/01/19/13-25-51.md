This bug exists in possibly all git versions.

```
$ git init
$ touch a.txt
$ ln -s a.txt d
$ git add .
```

$ git commit -m + .
[master (root-commit) f6b4468] +
```

 create mode 100644 a.txt
 create mode 120000 d
```

$ ls -la

