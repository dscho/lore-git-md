Feature completion for remote object info queries. This is the final review feedback on the series implementing `git cat-file --batch-command` support for querying remote object metadata without full downloads. Toon Claes points out that test variable names using "_sha1" should be updated to "_oid" for hash-agnostic correctness, as the functionality works with both SHA-1 and SHA-256 repositories. The observation is minor but technically sound, and aligns with Git's ongoing effort to be hash-algorithm agnostic. The patch author Eric Ju has already addressed all major review feedback in previous iterations, making this series functionally complete with comprehensive test coverage. The remaining naming nit does not block merging but would be a straightforward improvement.
