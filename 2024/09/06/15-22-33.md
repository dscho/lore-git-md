Yeah, I can render trailer information when using your examples but *only* if I disable signing my tags. Here's what my global Git configuration looks like:

[tag]
```
  gpgSign = true
  sort = version:refname

```

...and here's a better example to demonstrate:

mkdir demo
cd demo
git init

touch one.txt
git add .
git commit --message "Added one"
git tag 0.0.0 --message "Version 0.0.0" --trailer A:0

touch two.txt
git add .
git commit --message "Added two"
git tag 0.0.1 --message "Version 0.0.1" --no-sign --trailer A:1

Notice how Version 0.0.0 creates a signed tag but Version 0.0.1 forces the tag to not be signed. I can then run the following:

git tag --list \
```
        --format="%(refname:short)|%(taggerdate:short)|%(taggername)|%(subject)|%(trailers:key=A)" \
       | column -s "|" -t

```

...to produce this output:

0.0.0  2024-09-06  Brooke Kuhlmann  Version 0.0.0
0.0.1  2024-09-06  Brooke Kuhlmann  Version 0.0.1  A: 1
