This is the final patch in a security-hardened series adding remote object info querying to `git cat-file --batch-command`. The patch implements the new `remote-object-info` command, allowing clients to fetch object metadata from remotes without downloading full objects.

The implementation is now complete with all review feedback addressed, including Toon Claes' suggestion to use hash-agnostic "_oid" variable names in tests rather than "_sha1". The series has undergone extensive review from multiple domain experts (Jeff King for security, Jonathan Tan for transport layer, Christian Couder for style refinements) and maintains robust security constraints like protocol v2 enforcement and strict response parsing.

With comprehensive test coverage and maintainer approval of the implementation quality, this feature is ready for merging once the v3 submission is made. The remaining open questions (protocol v1 handling, future objecttype support) are documented as non-blocking future work. This represents a significant addition to Git's remote object inspection capabilities while maintaining strict security boundaries.
