[PATCH] diffcore-rename: fix BUG() with -B --follow options

Bug report from Olaf Hering identified a BUG() assertion failure in diffcore-rename.c when running `git log -B --follow` on specific paths. Jeff King bisected the issue to commit 9db2ac5616 ("diffcore-rename: accelerate rename_dst setup", 2020-12-11) which optimized rename destination setup. Elijah Newren (original author of the problematic commit) has proposed a fix via pull request, acknowledging the delayed response. The bug manifests in pair tracking during rename detection when both break detection (-B) and follow (-follow) options are used together. The fix addresses incorrect handling in this specific case while maintaining the optimization's benefits for other diff operations. No other contributors have yet reviewed or tested the proposed solution. The issue appears isolated to this combination of diff options triggering the assertion failure.
