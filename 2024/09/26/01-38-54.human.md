This is a feature patch adding client-side support for remote object info queries to `git cat-file --batch-command`. It's part of a 6-patch series that enables querying object metadata from remote servers without full downloads, building on prior server-side work.

The patch implements the transport layer plumbing needed to request object information from protocol v2 servers. Key aspects include:

- Adds a `fetch_object_info()` function in transport.c that handles the protocol negotiation and response parsing
- Enforces protocol v2 requirement (v1 attempts will die with an error)
- Supports requesting object sizes via the 'size' capability
- Falls back to full object download if the server doesn't support object-info
- Includes security measures like format string validation and request limits

The implementation builds on refactoring work in earlier patches of the series and has received positive review feedback from multiple contributors (Jonathan Tan, Christian Couder). The patch appears well-structured with thorough test coverage in t1017.

This is a significant step toward more efficient remote object queries, though currently limited to size information. The series as a whole looks ready for maintainer consideration, having addressed all major review feedback while leaving some non-blocking questions about future extensions.
