This is part 3 of a 6-patch series adding remote object info support to `git cat-file --batch-command`. The patch enables servers to advertise their object-info capabilities to clients via the `transfer.advertiseobjectinfo` config, with "size" being the currently supported capability.

The change modifies `object_info_advertise()` in serve.c to:
1. Keep the existing config check for `transfer.advertiseobjectinfo`
2. Add a new `strbuf_addstr()` call to advertise the "size" capability when enabled
3. Maintain the same default behavior (disabled by default)

This builds on prior work by Calvin Wan and incorporates feedback from Jonathan Tan and Christian Couder. The patch is straightforward and well-contained, focusing just on the advertisement mechanism while leaving other aspects (like actual object info fetching) to later patches in the series.

As part of the larger security-hardened remote object info feature, this change helps clients determine server capabilities before making requests, allowing them to fall back to full fetches when needed. The series has already received positive review feedback and appears ready for integration.
