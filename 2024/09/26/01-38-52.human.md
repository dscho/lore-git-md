This is a refactoring patch in a 6-part series adding remote object info support to `git cat-file --batch-command`. The patch moves initialization code in `fetch-pack.c` from inside the state machine's first state to just before the state machine begins, preparing for future changes that may use different initial states.

The change is mechanical and behavior-preserving, relocating three variable initializations (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) that were in the `FETCH_CHECK_LOCAL` state block to before the state machine loop. This ensures they'll be set regardless of which state the machine starts in, which will be needed by a later patch in the series that introduces an alternative initial state for remote object info queries.

The patch has been reviewed by Jonathan Tan and Christian Couder, and carries Calvin Wan's sign-off as the original author of this preparatory change. It's a straightforward infrastructure adjustment that enables the more interesting remote object info functionality coming in subsequent patches.
