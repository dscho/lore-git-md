This is a refactoring patch that generalizes fetch-pack's packet writing logic to support both fetch operations and the new remote-object-info command. It's the first in a 6-part series implementing secure remote object info support in `git cat-file --batch-command`.

The patch extracts the packet-writing logic from `write_fetch_command_and_capabilities()` into a more generic `write_command_and_capabilities()` that can handle any protocol v2 command. It also adds a new `send_object_info_request()` function that uses this to construct object-info requests. The changes are mechanical and well-contained, with the bulk being parameterization of the existing fetch-specific code.

The patch comes with sign-offs from both the original author (Calvin Wan) and the current submitter (Eric Ju), plus help acknowledgments from Jonathan Tan and Christian Couder. The implementation appears solid, building on established protocol v2 patterns while keeping the security constraints from earlier iterations intact.

This foundational change enables the subsequent patches to implement the actual remote object info functionality while maintaining consistent protocol handling. The series as a whole has already received positive feedback from multiple reviewers and appears ready for maintainer consideration.
