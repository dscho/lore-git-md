Feature patch completing the remote object info series for `git cat-file --batch-command`. This final patch adds the `remote-object-info` command that allows querying object metadata from remote repositories without downloading full objects, building on Calvin Wan's earlier work.

The implementation supports batching multiple OIDs in a single request to reduce network overhead, with fallback to full fetches when the server lacks the object-info capability. The command currently only supports size queries (not object types) and requires protocol v2. The patch includes extensive tests covering git://, file://, and http:// transports, error cases, and buffer/non-buffer modes.

Key technical points:
- New `remote-object-info <remote> <oid>...` command in `git cat-file --batch-command`
- Server capability advertised via `transfer.advertiseobjectinfo` config
- Client-side transport support with protocol v2 negotiation and response parsing
- Security measures like format string validation and request limits
- Comprehensive test coverage in t1017-cat-file-remote-object-info.sh

The series has received thorough review from multiple contributors (Jonathan Tan, Christian Couder, Toon Claes) and appears ready for merging. The implementation is clean separation of concerns between transport layer, protocol handling, and the cat-file command interface.
