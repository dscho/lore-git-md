This is the final patch in a 6-part series implementing remote object info queries via `git cat-file --batch-command`. The series adds a `remote-object-info` command that allows querying object metadata from remotes without full downloads, building on Calvin Wan's prior work.

The patch implements the actual `remote-object-info` command in `builtin/cat-file.c`, which:
- Taking multiple OIDs per command to reduce network overhead
- Falling back to full fetches when the server lacks object-info capability
- Enforcing protocol v2 requirements
- Supporting buffered and null-delimited modes
- Key technical details:
  - New `get_remote_info()` function handles the remote communication
  - Uses transport layer's `fetch_object_info()` from earlier patches
  - Maintains existing batch command processing flow while adding special handling for remote queries
  - Adds comprehensive tests covering git://, file:// and http:// transports
  - Currently only supports object size queries (objecttype handling is future work)

The implementation appears robust with thorough test coverage across protocols and edge cases. Review feedback from Jonathan Tan and Christian Couder has been incorporated, and the series has received positive reviews. This final patch completes the feature implementation while maintaining the hardening measures from earlier iterations.

The main limitations are the current lack of objecttype support (which fails explicitly rather than silently) and the protocol v2 requirement. These are noted as future work rather than blockers. The patch series as a whole represents a well-structured addition to Git's remote query capabilities.
