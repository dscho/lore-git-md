This is a feature patch in the remote object info series, focusing on server-side capability advertisement. The patch modifies `serve.c` to advertise the "size" capability when `transfer.advertiseobjectinfo` is enabled, allowing clients to discover server support for object size queries.

Key technical details:
- The `object_info_advertise()` function now populates a `strbuf` with "size" when the feature is enabled, indicating the server can provide object size information
- Maintains backward compatibility by keeping the feature disabled by default unless explicitly configured
- Builds on prior work by Calvin Wan with help from Jonathan Tan and Christian Couder

The change is straightforward but important for the overall feature - it provides the signaling mechanism that lets clients know when they can use the more efficient remote object info queries rather than falling back to full object downloads. The patch follows the series' security-conscious approach by keeping the feature opt-in via configuration.

This is patch 3/6 in the v3 series, which has already addressed most review feedback in previous iterations. The change is well-contained and appears ready for integration, with clear commit message attribution and sign-offs from both the original author and current contributor.
