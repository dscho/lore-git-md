This is a refactoring patch in a series adding remote object info support to `git cat-file --batch-command`. It's the second of six patches, building on prior work by Calvin Wan that established secure remote object metadata queries.

The patch moves initialization of several fetch-pack variables from inside the state machine's first state (FETCH_CHECK_LOCAL) to just before the state machine begins. This prepares for a future change where the state machine might start in a different initial state while still needing these same variables initialized. The change is purely mechanical - no behavior is altered, just the location of the initialization code.

The patch has been reviewed and signed off by Calvin Wan (the author of the original work) and Eric Ju (the series author), with help from Jonathan Tan and Christian Couder. It's a straightforward preparatory change that makes the code more flexible for the remote object info functionality being added in later patches of the series.
