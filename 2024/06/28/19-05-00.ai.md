This is part 3 of a 6-patch series implementing remote object-info functionality, focusing on server capability advertisement. The patch modifies the server-side to advertise object-info features to clients, specifically indicating support for size queries when enabled via `transfer.advertiseobjectinfo` config.

The key change is in `serve.c` where the `object_info_advertise()` function now populates a `strbuf` with supported capabilities ("size" in this case) when advertising is enabled. This allows clients to know what object-info components the server can provide before making requests. The implementation maintains the default opt-in behavior through the existing `transfer.advertiseobjectinfo` config.

The patch builds on the series' security foundations while adding the necessary protocol handshake for feature negotiation. It's a straightforward change that completes the server-side signaling portion of the remote object-info functionality, with Calvin Wan as primary author and Eric Ju carrying the series forward. The change is well-contained and follows the established pattern for capability advertisement in Git's protocol v2.
