This is part 3/6 of a series implementing remote object-info functionality, specifically focusing on server capability advertisement. The patch enables servers to advertise which object-info features they support (currently just "size") via the `transfer.advertiseobjectinfo` config, allowing clients to make informed decisions about whether to query the server.

The change modifies `serve.c` to pass through a `strbuf` parameter where previously it was unused, populating it with supported capabilities when object-info is enabled. This builds on the security-hardened foundation established in earlier iterations of the series, maintaining the conservative default of disabled advertisement unless explicitly configured.

The patch appears straightforward and well-contained, with sign-offs from Calvin Wan (original author) and Eric Ju (series submitter), plus help from Jonathan Tan and Christian Couder noted in the trailers. As part of a larger effort to enable efficient remote object metadata queries, this piece handles the server-side capability signaling cleanly while keeping the security-conscious defaults from prior work.
