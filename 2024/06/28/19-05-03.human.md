This is the final patch in a series adding remote object info support to `git cat-file --batch-command`. The feature allows querying object metadata from remote servers without full downloads, building on extensive security hardening from prior patches.

The patch introduces a new `remote-object-info` command that takes a remote URL and one or more object IDs, fetching their metadata efficiently in batches. Key aspects:
- Works across git://, http://, and file:// transports
- Currently only supports object size queries (object type support is planned)
- Includes comprehensive tests covering protocol versions, error cases, and buffer modes
- Maintains all security measures from earlier patches (format validation, request limits)

The implementation handles both buffered and non-buffered modes, with the buffered version queueing requests until a flush command. The patch appears well-structured with thorough test coverage, completing the series' goal of secure remote object metadata queries.

This represents production-ready functionality that could be particularly useful for tools needing to inspect remote objects without downloading them. The remaining open questions about protocol version fallback and object type support don't block merging, as the current implementation cleanly errors in those cases.
