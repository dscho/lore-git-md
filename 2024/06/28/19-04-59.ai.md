This is a refactoring patch in a series adding remote object info support to `git cat-file --batch-command`. It moves initialization code in `fetch-pack.c` to prepare for supporting multiple initial states in the fetch state machine.

The patch relocates three variable initializations from inside the `FETCH_CHECK_LOCAL` state to just before the state machine begins. This is a mechanical change with no behavior difference, but enables future patches to introduce alternative initial states while maintaining these common initializations. The moved code handles:
1. Enabling reachable SHA1 requests by default for protocol v2
2. Setting sideband usage
3. Marking deep fetches based on depth arguments

The change is straightforward and well-motivated, with sign-offs from Calvin Wan (original author) and Eric Ju (series submitter), plus help tags from Jonathan Tan and Christian Couder. The patch maintains the existing security properties while cleaning up the state machine structure in preparation for the remote object info functionality.
