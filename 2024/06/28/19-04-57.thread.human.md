This thread is about a security-hardened patch series that adds `git cat-file --batch-command` support for querying object metadata from remote repositories without downloading the objects themselves. The series, now at version 18, is functionally complete and ready for integration into Junio's `next` branch.

The implementation introduces the `remote-object-info` command, allowing clients to fetch metadata like object size from remotes using the `object-info` protocol v2 capability. Key features include strict input validation, dynamic allow-lists for metadata fields, and robust handling of edge cases like missing objects or unsupported format placeholders. The series has undergone extensive review and testing, with all major technical and security concerns resolved. Pablo Sabater's recent confirmation to Junio Hamano explicitly states the series is ready for `next` once two minor nits (a bounds-checking fix and cover letter attribution) are addressed. CI results are clean, and the code is considered stable for its initial scope of size-only queries.
