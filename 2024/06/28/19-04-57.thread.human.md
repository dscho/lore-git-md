This thread introduces client-side support for requesting object information (currently just sizes) from Git servers that support the object-info capability, building on server-side functionality added earlier. The series is now at part 5 of 6, with Eric Ju as the core author.

The implementation adds new fetch-object-info.[ch] files to handle the protocol interactions, explicitly requiring protocol version 2 and erroring out if the server doesn't advertise the capability. Calvin Wan provided review feedback suggesting clearer error messaging ("unsupported protocol version" rather than "wrong") and some code simplification in the response parsing logic, which Eric Ju has acknowledged will be addressed in the upcoming v9 revision. The patch has seen constructive review from multiple contributors including Jonathan Tan and Christian Couder.

The functionality appears well-structured, with proper memory management (xcalloc for results) and error checking throughout. While currently limited to object size requests, the foundation is laid for potential future expansion of the object-info capability. With the minor wording and code structure improvements identified during review being incorporated, this appears to be on track for merging once the series is complete.
