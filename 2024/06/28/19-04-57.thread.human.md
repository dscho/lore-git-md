This thread implements a security-hardened `git cat-file --batch-command` feature allowing users to query object metadata (like size) from remote repositories without downloading full objects. The series, now at version 17, is complete and ready for merging after addressing all technical and design issues raised during review.

The core functionality centers on the new `remote-object-info` command, which batches multiple object queries into a single network request while enforcing strict input validation (10,000-object limit, 8KB URL length) and protocol v2 compliance. Key improvements in recent versions include dynamic validation of format placeholders against server-advertised capabilities, memory leak fixes in the transport helper subsystem, and elimination of a critical refactoring flaw identified by Junio Hamano in v15. The implementation now supports all transport protocols (`git://`, `file://`, `http://`) and includes 699 lines of new tests covering edge cases and error conditions.
