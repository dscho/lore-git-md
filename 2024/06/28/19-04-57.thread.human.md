This thread is about a security-hardened patch series that adds full `git cat-file --batch-command` support for querying object metadata from remotes without downloading the objects themselves. The series, now at its 18th iteration, is effectively complete and has been queued for the `next` branch, meaning it’s under final integration testing before graduating to the main codebase.

The core functionality allows Git clients to request object metadata (currently just size, with type support designed for future expansion) from remote repositories using the `object-info` protocol v2 capability. The implementation includes a new `remote-object-info` command, strict security measures like batch limits and input validation, and robust handling of edge cases such as missing objects or unsupported format placeholders. Key contributors include Pablo Sabater, who drove the series through its final stages, and Junio C Hamano, who resolved the last design question—whether to force a server-side existence check even for `%(objectname)`-only requests—by insisting on robustness over efficiency.

All technical and design issues have been addressed, including fixes for silent failures, type inconsistencies, and macro formatting. The series is now functionally complete for its initial scope (size-only queries) and has passed CI testing. Minor cosmetic nits, such as documentation caveats and translation context, remain but are expected to be polished before the final merge.
