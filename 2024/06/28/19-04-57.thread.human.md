This thread is implementing client-side support for the object-info protocol feature, which enables querying object metadata (like sizes) without downloading full objects. The series is now at version 8, indicating extensive review and refinement.

The latest patch (5/6) adds core client functionality in new `fetch-object-info.{c,h}` files, handling request construction, server communication, and response parsing. It supports both stateful and stateless RPC modes with robust error handling, though currently only implements the "size" attribute. The server must explicitly advertise this capability via `transfer.advertiseobjectinfo`.

Eric Ju provided minor suggestions to improve error messaging and simplify response parsing logic. The implementation builds carefully on existing protocol infrastructure while leaving room for future attribute additions. With this being the 8th iteration and the technical approach appearing sound, the series seems to be converging toward readiness for merging.
