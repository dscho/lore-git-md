This thread documents the development of a security-hardened feature allowing remote object information queries via `git cat-file --batch-command`. The 6-patch series, building on Calvin Wan's prior work, implements a new `remote-object-info` command that lets clients query object metadata from remote servers without full downloads while enforcing strict security measures.

The implementation requires protocol v2 and includes multiple safeguards: server-side request limits (8KB URL size, 10k objects/request), strict response parsing, and an opt-in server configuration (`transfer.advertiseobjectinfo`). While currently limited to size queries, the design anticipates future support for object types, with documentation warning about potential format changes. The feature gracefully falls back to full fetches when servers lack the capability.

After multiple review rounds addressing both technical and stylistic concerns, the series appears ready for maintainer consideration. Christian Couder provided thorough feedback on documentation, test organization (resulting in new shared test helpers in lib-cat-file.sh), and code style (comment formatting, variable scoping). Taylor Blau and other reviewers have indicated the technical implementation meets expectations. The final patch maintains the series' security focus while providing the polished user-facing command interface, with all major review feedback incorporated.
