This thread is about a long-running security-hardened series that adds `git cat-file --batch-command` support for querying object metadata from remotes without full downloads. The series is now at **v20** and has been queued for the `next` branch, meaning it’s in the final stages before merging into the main codebase.

The core feature lets Git clients ask remote repositories for object metadata (currently just size, with type support planned later) using the `object-info` protocol v2 capability. The implementation is robust, with strict input validation, memory safety checks, and dynamic adaptation to server capabilities. It’s been through extensive review and testing—747 lines of new tests cover all major transports, edge cases, and security scenarios.

The change is mechanical, with no behavior impact, and prepares the code for future protocol extensions.
