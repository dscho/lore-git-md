This thread is about the finalization of a Google Summer of Code (GSoC) project implementing `git cat-file --batch-command` support for querying object metadata from remotes without full downloads. The series, now at **version 18**, is technically complete and queued for `next` after resolving all outstanding design, security, and robustness issues.

The core feature, `remote-object-info`, allows clients to query object metadata (currently size, with type support designed for future expansion) from remote repositories via the `object-info` protocol v2 capability. The implementation includes strict security measures (batch limits, URL length checks, dynamic allow-lists) and handles edge cases like missing objects or unsupported placeholders gracefully. Pablo Sabater addressed the last review feedback from Junio, clarifying placeholder behavior (unsupported fields are omitted entirely), reformatting the `EXPAND_DATA_INIT` macro for future extensibility, and fixing silent failure modes in `parse_cmd_remote_object_info()`. The series now explicitly fails when only `%(objectname)` is requested, avoiding unnecessary remote queries while preventing misleading output.

With all prior concerns resolved and CI confirming readiness, the series is poised for integration. Pablo’s follow-up patches (12/13 and this final one) were critical in closing the last usability and robustness gaps, particularly around silent failures and placeholder handling. The implementation is now functionally complete for its initial scope (size-only queries) and awaits graduation to `next`.
