This thread discusses a security-focused 6-patch series that adds remote object metadata query support to `git cat-file --batch-command`, building on Calvin Wan's earlier protocol v2 work. The implementation carefully refactors fetch-pack and transport layers to enable querying object info from remotes without full downloads, with security controls like capability advertisement being disabled by default.

The series has undergone thorough review from Christian Couder (documentation and tests), Jonathan Tan (transport layer), and Taylor Blau (general readiness). Karthik Nayak provided additional transport.c review, noting some documentation gaps and flag usage that needed clarification - all of which have now been addressed. The implementation includes comprehensive test coverage across different transports and handles edge cases securely.

In the latest review, Karthik raises two final points: he questions the temporary output format that will need changing when object type support is added, suggesting it might be better to implement type support first to avoid future breakage. He also notes an incidental whitespace change in unmodified code. These appear to be the last remaining polish items before the series could be merged, with no fundamental objections remaining. The work represents a well-reviewed addition to Git's remote object inspection capabilities, with particular attention paid to security and protocol robustness.
