This thread documents the development of a new `remote-object-info` feature that allows clients to query object sizes from Git servers without downloading full objects. The series, now at version 11, implements both client and server components with full security hardening.

The core functionality enables `git cat-file --batch-command` to use a new `remote-object-info` command that works across git://, file://, and http:// transports when servers advertise support via `transfer.advertiseobjectinfo`. The latest patch focuses on server-side capability advertisement, modifying `object_info_advertise()` in serve.c to properly signal "size" capability availability to clients.

Key contributors include Calvin Wan (original server-side work), Eric Ju, and Jonathan Tan, with significant security hardening input from Jeff King. The implementation spans protocol handling, transport layer changes (including generalized packet-writing infrastructure), and user-facing commands. Recent refinements have addressed documentation, test organization, and fetch-pack state machine initialization in preparation for future protocol v2 work.

All technical issues appear resolved, with the last patch completing the server advertisement piece. The series has received Reviewed-by tags from multiple established contributors and incorporates all feedback from the extensive review process. While future expansion to additional object info types is possible, the current implementation appears complete and ready for merging.
