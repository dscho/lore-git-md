Commit DAG Revision Naming
==========================

Both node B and C are a commit parents of node A.

```
    G   H   I   J
     \ /     \ /
      D   E   F
       \  |  /
        \ | /
         \|/
          B     C
           \   /
            \ /
             A

```


```
    A = rev    = rev^0
    B = rev^   = rev^1     = rev~1
    D = rev^^  = rev^1^1   = rev~2
    G = rev^^^ = rev^1^1^1 = rev~3

```

Is there a way to name node C, E, F, H, I or J?
Is A also called rev~0?
