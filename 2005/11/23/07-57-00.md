Are you saying this setup
```
	foodir/somefile.c     <--file
	newdir/               <--directory

```

with this command
	git-mv foodir/ newdir

	newdir/foodir/somefile.c  <-- directory

	newdir/somefile.c         <-- file

	newdir/foodir/somefile.c  <-- file
