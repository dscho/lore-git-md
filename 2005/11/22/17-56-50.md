I don't know if you missed it, but hierarchical config keys were 
introduced by b17e659dd4007cb1d3eb5ac32b524c0c5ab59601:

[remote.origin]
```
	url = master.kernel.org:/pub/scm/git/git.git
	pull = master:origin

```

is parsable by

	git-config-set --get remote.origin.url

now.
