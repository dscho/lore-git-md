+------------

+$ git add .

+

+------------
+$ git checkout -b private
+$ edit/compile/test

+$ git commit -a -s <3>
+$ git checkout master <4>
+$ git pull . private <5>
+

+<2> revert your botched changes in selected path "foo.c".
+<3> commit everything as you have tested.
