How can we cat the latest committed state of a file to stdout?

I hacked this:

```
	#!/bin/bash
	ID=`git-ls-files -s | grep $1 | cut -d ' ' -f 2`
	TMP=`git-unpack-file $ID`
	cat $TMP
	rm $TMP

```

but its really ugly!   It must be easier than this?
