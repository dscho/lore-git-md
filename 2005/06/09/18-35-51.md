It would be nice if somebody were motivated enough to create a command 
that functions like:

	git relink repoA repoB repoC repoD... repoX

which would examine

```
	repoA/.git
	repoB/.git
	repoC/.git
	repoD/.git

```

and verify (updating, if necessary) that each of the A/B/C/D repos are 
hardlinked to repoX.
