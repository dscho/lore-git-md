> cleaner (if somewhat slower) to me.
>
> So, something like
>
> ```
> 	git filter-branch --index-filter 'git ls-files |
> 		while read name; do
> 			perl -pi -e "s/[ \009\015]*$//" "$name"
> 		done
> 		git add -u' cleaned-up-origin
>
> ```
