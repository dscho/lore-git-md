**Thread**: [thread](./03-42-37.thread.md#:~:text=2007/06/05/03-42-37)

"git-svn dcommit" ends up making an arbitrary decision when pushing
back merges.  Allow the user to specify which one is used, albeit in a
rather hack-ish way.
