Or :

```
  [remote "jc"]
    url = git://...
    fetch = refs/heads/*:remotes/jc/*
    remote ("include"? "next"?) = origin

```

(I mean: it can be allowed to mix url/fetch and remote).

And:

```
  [remote "jc"]
    fail = all-fail
    remote = origin
    remote = backup

```

IOW: the fetch fails only if all fetches fail (with default
being "fail = first").
