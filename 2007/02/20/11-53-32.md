Ha, I did it by

$ perl -pi.bup -e \
```
 's/strncmp\( *("[^"]*"), *([^"]*), *[0-9]* *\)/prefixcmp\($2, $1\)/g' \
 $(git ls-files)

```

and

$ perl -pi.bup -e \
```
 's/strncmp\( *([^"]*), *("[^"]*"), *[0-9]* *\)/prefixcmp\($1, $2\)/g' \
 $(git-ls-files)

```

Of course, I missed the two ,ofs ones, but a git grep -n strncmp brought 
these up.
