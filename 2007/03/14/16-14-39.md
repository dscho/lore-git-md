Please:

```
        test_expect_success '...
                echo ... &&
                git add . &&

I recall somebody on the list had a buggy shell that cannot
handle "a && ! b" and tweaked a few tests to work around it.
In that case...

```
	echo ... &&
        git add . &&
	{
        	git diff-index ...; test $? != 0
	}

```
