The <revspec> can be a tag. So you can easily create a wrapper script
to allow such things as

```
$ ./deploy.sh v1.2.3
$ ./deploy.sh HEAD
$ ./deploy.sh master
$ ./deploy.sh <sha1>
```


(note: for this to work with the git:// protocol, git-daemon needs
--enable=upload-archive)
