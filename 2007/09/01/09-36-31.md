**Thread**: [thread](./09-36-31.thread.md#:~:text=2007/09/01/09-36-31)

Allow port specification in ssh:// URLs in the
usual notation:
	ssh://[user@]host.domain[:<port>]/<path>

This allows git to be used over ssh-tunneling
networks.
