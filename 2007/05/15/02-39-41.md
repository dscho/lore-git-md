<shameless plug>

You can use Guilt:

```
$ guilt-init
$ guilt-import-commit <the bad commit hash>^..
$ $EDITOR .git/patches/$branch/series
	# remove the offending line from the series file
```

```
$ guilt-push -a
$ rm -rf .git/patches/$branch

</shameless plug>
```
