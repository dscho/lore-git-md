>
> * -- * -- G -- B
> ```

With GIT, you could create:


* -- * -- G --- B
```
           \     \
             ---- 1 -- 2 -- 3

```

Or perhaps :

* -- * -- G --- B
```
           \     \
             ---- G* -- 1 -- 2 -- 3

```

How do the history viewers handle this situation?
