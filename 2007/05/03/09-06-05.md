I'd suggest using platform-optimized memchr:

static inline char *xstrndup(const char *s, int len)
{
```
    char *p = memchr(s, 0, len);
    int n = p ? p - s: len;
    p = xmalloc(n + 1);
    memcpy(p, s, n);
    p[n] = '\0';
    return p;
```
