>
> But --early-output does not imply --topo-order, I guess...


Look here in Linus' patch:

```diff
+			if (!prefixcmp(arg, "--early-output")) {
+				int count = 100;
+				switch (arg[14]) {
+				case '=':
+					count = atoi(arg+15);
+					/* Fallthrough */
+				case 0:
+					revs->topo_order = 1;
+					revs->early_output = count;
+					continue;
+				}
+			}

```

So yes, --early-output does imply --topo-order.
