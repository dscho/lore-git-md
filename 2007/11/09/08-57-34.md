Benoit Sigoure schrieb:
> Off topic question: why do you guys always do this instead of doing, 
> say, this:
>
> INTERACTIVE=false
>
> case $1 in
> ```
>   --interactive|-i)
>     INTERACTIVE=:
>     ... ;;
> ```
>
> esac
> if $INTERACTIVE; then
>   git_editor "$TODO" || die ...
> fi


Because in some shells 'false' is not a built-in.

But then this might do it without the extra process:

```
	INTERACTIVE="! :"	# false

	case $1 in
	--interactive|-i)
	    INTERACTIVE=:
	    ... ;;
	esac
	if $INTERACTIVE; then
	  git_editor "$TODO" || die ...
	fi

```
