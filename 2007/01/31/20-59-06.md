I think it requires GNU Emacs 21.  If you'are using Emacs 20, try
changing this:

```
            (overlay-put ovl 'face (list :background
                                         (cdr (assq 'color (cddddr info)))))

```

to

```
            (overlay-put ovl 'face (cons 'background-color
                                         (cdr (assq 'color (cddddr info)))))

```
