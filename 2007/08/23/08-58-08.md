yet another note:  I used expr "z$http_only" on purpose.  Look what
happens here:

```
	$ httpd_only=substr
	$ expr "$httpd_only" : "\/"
	expr: syntax error

```

Once more, Solaris is more exacting:

```
	$ /usr/bin/expr "/" : "\/"
	expr: syntax error

```

(This works fine with GNU expr.)

So better use "z$variable" because (up to now) there is no operator that
starts with a 'z'.
