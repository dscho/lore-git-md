The problem is that git-cherry-pick only oves a single comit,
so if I have a stack, it's annoying.

It's more like:
```
	git checkout HEAD^0 &&
	for i in `git-rev-list --reverse ..debug_hack`; do
		git-cherry-pick $i
	done &&
	git branch -D debug_hack &&
	git checkout -b debug_hack
```
