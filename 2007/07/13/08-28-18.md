This would be a bug in Email::Valid as it complains that the second
address fails the rfc822 check, however rfc822 says that the "display
name" before the '<' is optional.

> > I'd probably do:

> > 	if ($have_email_valid) {
> > 		$address =~ s/^<(.*)>$/$1/;
> > ```
