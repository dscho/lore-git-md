This is the final patch in Tian Yuchen’s v10 series migrating global configuration variables into `struct repo_config_values`. It moves the `object_creation_mode` enum from a global variable into the repository-specific configuration structure, completing the series’ goal of eliminating nine globals.

The patch relocates the `enum object_creation_mode` definition higher in `environment.h` so it is visible to `struct repo_config_values`, initializes the per-repository value to `OBJECT_CREATION_MODE` in `repo_config_values_init()`, and updates the configuration parser in `git_default_core_config()` to write directly to the repository’s configuration instance. The sole caller in `object-file.c` is updated to access the value via `repo_config_values(repo)->object_creation_mode`.
