This is part seven of Tian Yuchen’s nine-patch v10 series that moves more global configuration variables into `struct repo_config_values` as part of the ongoing `the_repository` removal effort.

Patch 7/9 migrates the `push_default` enum from a global variable to a field inside `struct repo_config_values`. The enum itself is kept in `environment.h` (rather than its ideal home in `remote.h`) to avoid a circular-dependency chain (`remote.h → hash.h → repository.h → environment.h`). A `NEEDSWORK` comment flags this as a future cleanup item. The configuration parser in `environment.c` now updates the per-repository structure directly, and all callers in `builtin/push.c` and `remote.c` access the value via `repo_config_values(the_repository)->push_default`.

The patch is a straightforward refactoring with no user-visible behavior change. It addresses the last known technical blocker from earlier rounds (the destructor signature mismatch) and is CI-clean. The only loose end is the deferred enum-placement cleanup, which the author has documented and left for follow-up. Reviewers can focus on whether the temporary placement in `environment.h` is acceptable for now.
