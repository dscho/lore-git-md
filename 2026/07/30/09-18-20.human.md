This is the seventh patch in Kristoffer Haugsbakk’s already-merged 11-patch documentation series for `git interpret-trailers`. The patch adds a concrete failure-case example that illustrates the strict key format (ASCII alphanumeric + hyphen only) introduced in the previous commit. By showing what happens when invalid keys (e.g., “Skapad-på” and “Hash-in-v6.11”) appear in the input, it reinforces the rule and explains why the entire block is rejected even when one valid trailer (“Reviewed-by”) is present. The example also serves as a mini-tutorial on trailer-block detection logic, making the man page more pedagogical without changing any code behavior.
