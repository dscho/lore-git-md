This is the sixth patch in Kristoffer Haugsbakk’s already-merged 11-patch documentation series for `git interpret-trailers`. It explicitly documents the strict key format—ASCII alphanumeric characters plus hyphens only—that was confirmed as intentional behavior after Brendan Jackman’s bug report about silent failures with keys containing periods. The change adds a single sentence to the DESCRIPTION section, filling a gap that previously forced users to infer the rule from examples or spelunk the source code. The commit message notes that the previous patch (5/11) set up the right context for this clarification, and the footnote explains why the examples alone were insufficient (they never show digits in keys). No controversy or follow-up is expected; this is a straightforward, uncontroversial improvement.
