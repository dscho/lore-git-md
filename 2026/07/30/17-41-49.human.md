This is the third patch in Siddharth Shrimali’s seven-patch RFC v2 series introducing `git repack --drop-filtered` for partial clones. It extends the promisor-object repack machinery so that callers can exclude a set of objects from the rebuilt promisor pack.

The patch adds a `to_drop` oidset parameter to `repack_promisor_objects()`. When the set is non-NULL, the `write_oid()` callback skips any object whose OID is in the set, effectively rebuilding the promisor pack without those objects. All existing callers continue to pass NULL, so there is no behavior change yet. The plumbing is now in place for the `--drop-filtered` option (added in patch 1) to pass the set of oversized promisor blobs that should be removed.

The change is minimal and mechanical: three files touched, 18 lines added, 3 lines modified. The commit message is clear and the code is straightforward. This is a refactoring patch that prepares the infrastructure; the actual drop logic appears in later patches. No controversy or open questions are evident here.
