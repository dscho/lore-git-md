This is the fifth patch in Siddharth Shrimali’s seven-patch RFC v2 series that adds `--drop-filtered` to `git repack`. It is the payoff commit: it turns the earlier enumeration and plumbing into actual object removal.

The patch wires the `drop_oids` set—computed in `enumerate_promisor_blobs()`—into `repack_promisor_objects()`, so the rebuilt promisor pack excludes the filtered blobs. It also makes `--drop-filtered` imply `-d` on a real run, ensuring the old promisor packs (which still contain the dropped blobs) are deleted. Without this implication the blobs would survive in redundant packs, defeating the purpose. The existing repack machinery’s write-before-delete and fsync guarantees keep the operation crash-safe. `--dry-run` remains unchanged, listing candidates without touching anything.

Tests verify that a real `--drop-filtered` run removes the promisor blob locally while leaving smaller blobs untouched. The commit message is clear and the diff is minimal: only 23 lines changed across three files. This patch completes the core functionality; the remaining two patches in the series add the drop log and documentation updates.
