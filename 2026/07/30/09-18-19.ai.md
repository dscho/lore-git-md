This is the sixth patch in Kristoffer Haugsbakk’s already-merged 11-patch documentation series for `git-interpret-trailers`. It adds a single sentence to the DESCRIPTION section that explicitly states the strict key format: ASCII alphanumeric characters and hyphens only. The change plugs the gap that originally prompted the bug report—users silently failed when they tried keys containing periods (e.g., “My-6.11-Version”) because the format was undocumented. The commit message cites the earlier patches in the series as providing the necessary context, so this patch is a minimal, targeted clarification rather than a standalone explanation.
