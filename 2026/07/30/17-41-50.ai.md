This is patch 4/7 of the RFC v2 series introducing `git repack --drop-filtered` for partial clones. It implements the core enumeration logic that identifies which promisor blobs exceed the user-specified size threshold and are therefore safe to drop.

The patch adds `enumerate_promisor_blobs()` in `repack-filtered.c`, which walks all promisor objects via `odb_for_each_object()` with the `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY` flag, collects blobs into an oidset, and applies the filter using the new `list_objects_filter__filter_oidset()` helper (introduced in patch 2/7). The enumeration is wired into `cmd_repack()` so that `--dry-run` prints the candidate OIDs, while real drops are deferred to later patches. Safety is guaranteed by construction: every object visited is a promisor object (recoverable from the remote), and `OBJECT_INFO_SKIP_FETCH_OBJECT` prevents lazy fetches during enumeration.

The test coverage is thorough: it verifies that only promisor blobs exceeding the threshold are listed, that locally created blobs are never candidates, and that `--dry-run` leaves objects untouched.
