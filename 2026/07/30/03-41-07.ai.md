This is the first patch in Junio C Hamano’s two-patch series that tightens safety around `git stash drop` and `git stash pop`. It adds a `stash_idx` field to `struct stash_info` and populates it in `get_stash_info()` so that later code can distinguish positional selectors (`stash@{4}`) from time-based ones (`stash@{2.days.ago}`). The field is set to 0 for the default latest stash, to the numeric index for valid positional selectors, and to -1 for invalid or non-positional references. The change is purely internal plumbing; no user-visible behavior changes yet. The patch touches only `builtin/stash.c` and is a straightforward, well-motivated refactoring that prepares for the safety check in patch 2/2.
