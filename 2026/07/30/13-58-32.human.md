This is the third patch in Harald Nordgren’s **v24 `git branch --delete-merged` series**, which is now ready for merging. This patch adds a `DELETE_BRANCH_SKIP_UNMERGED` flag to the branch deletion API, allowing bulk callers (like the upcoming `--delete-merged` subcommand) to silently skip unmerged branches instead of failing with an error. The change is minimal and targeted: it modifies `check_branch_commit()` and `delete_branches()` to suppress the "not fully merged" error and advice when the flag is set, while preserving the existing behavior for all current callers (e.g., `git branch -d`).

The patch is part of a **flags-based refactoring** (patches 2-4/7) that replaces boolean arguments with an `unsigned int flags` parameter, eliminating local caching to ensure flags remain the single source of truth. This patch specifically enables the `--delete-merged` subcommand to handle unmerged branches gracefully without disrupting the traditional `git branch -d` workflow. The implementation is **low-risk** and **well-tested**, with no behavioral changes for existing users. The series as a whole addresses a real workflow pain point—safe automated local branch cleanup—with comprehensive safety checks, per-branch opt-out, and `--dry-run` preview functionality.
