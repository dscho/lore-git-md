This is the third patch in Kristoffer Haugsbakk’s four-part documentation series (`kh/doc-replay-config`) that standardizes how the `replay.refAction` configuration and `--ref-action` command-line option are documented. The series is now in its fourth iteration and is purely about aligning man-page formatting with Git’s established conventions.

This specific patch converts the bullet-list presentation of `--ref-action` in `git-replay(1)` into a nested description list, matching the style already applied to the `replay.refAction` configuration variable in the previous patch. The change is mechanical: replace asterisks with double semicolons and adjust indentation. The commit message explains that the transformation is identical to the one already performed for the config variable, so the rationale carries over without repetition.

The patch is uncontroversial and has already received positive feedback on the structural choice. Junio Hamano explicitly approved the description-list approach in earlier rounds, and Toon Claes cited `Documentation/config/branch.adoc` as precedent. No substantive objections remain, and the series is listed in Junio’s 2025-07-10 “What’s cooking” report as “Will merge to 'next'”, so it is on track for integration.
