This is the second patch in Kristoffer Haugsbakk’s four-part documentation series (v4) that standardizes how the `replay.refAction` configuration variable is presented in Git’s man pages. The patch converts the existing bullet-point list in `Documentation/config/replay.adoc` into a nested description list (`;;` delimiter) for stylistic consistency with other Git documentation, removes unnecessary indentation, and replaces the inline-verbatim command reference with a conditional cross-link to `git-replay(1)`—avoiding a self-link when the documentation is viewed as part of that man page itself. The only change from v3 is a minor phrasing tweak suggested by Toon Claes, replacing "See `--ref-action` for ... for details" with "See `--ref-action` in linkgit:git-replay[1] for details" to eliminate a redundant "for" and improve sentence flow.

The series as a whole is a straightforward documentation cleanup, following Git’s established conventions for config-variable presentation. All substantive feedback from Junio Hamano, Patrick Steinhardt, and Toon Claes has been addressed, and the topic (`kh/doc-replay-config`) is marked "Will merge to 'next'" in Junio’s latest "What’s cooking" report. This patch is uncontroversial and ready for integration.
