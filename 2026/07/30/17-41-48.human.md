This is the second patch in Siddharth Shrimali’s seven-part RFC v2 series introducing `git repack --drop-filtered` for partial clones. It adds a new helper function, `list_objects_filter__filter_oidset()`, to the list-objects-filter API.

The helper lets callers apply a filter spec to an existing oidset without walking the object graph. In this series it is used by `--drop-filtered` to determine which promisor blobs exceed the configured size threshold, but the function is generic and could be reused elsewhere. Currently only `blob:limit=N` filters are supported; the implementation duplicates the size check rather than reusing the existing filter machinery, which is marked NEEDSWORK for future refactoring. The helper avoids lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` when reading object info.

The patch is small (61 lines), well-scoped, and clearly motivated. It does not change user-visible behavior yet—it simply exposes the new API that later patches will wire up. The commit message explains why the duplication is necessary and flags the refactoring opportunity. This looks like a sensible, low-risk addition that directly supports the series’ goal.
