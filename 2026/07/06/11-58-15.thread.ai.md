Core problem or goal: The legacy shell-script `git subtree` (`git-subtree.sh`) and the new Rust rewrite (`git-subtree` crate) use incompatible on-disk formats. Running the shell script on a repository that has been processed by the Rust tool risks silent data corruption. This patch adds a safety check to the shell script to detect Rust-tool usage and bail out with a fatal error, directing users to the new tool.

Current status: Patch 1/2 under review. No prior version mentioned. The patch adds a new helper function `reject_if_v2_config` to `contrib/subtree/git-subtree.sh` and calls it in the `cmd_add`, `cmd_split`, and `cmd_merge` entry points. The check uses `git rev-parse --verify` to probe for the Rust tool's configuration file (`.git-subtree/config`). The change is forward-compatible but not backward-compatible: once a repository adopts the Rust tool, the shell script will refuse to run.
