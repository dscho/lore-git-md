This is the second patch in Harald Nordgren’s five-patch series implementing `git history squash`. It adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. The patch updates the existing fixup and split callers to pass NULL so they continue to work unchanged.

The change is a straightforward plumbing tweak that enables the `--reedit-message` feature introduced later in the series. By allowing the caller to override the commit message, `commit_tree_ext()` can now seed the editor with a template built from multiple folded commits, matching the behavior of `git rebase -i`’s squash. The patch itself is mechanical and does not alter any user-visible behavior.
