This is a small documentation patch from Patrick Steinhardt, part of a larger series (v3 1/9). It adds a GitLab CI status badge to the project's `README.md` to make the GitLab CI pipeline more discoverable, mirroring the existing GitHub CI badge. The change is trivial—just one line added—and the motivation is clear: the Git project uses both CI systems, but only the GitHub one was previously linked. The patch is well-motivated and uncontroversial; it’s a straightforward improvement to project visibility. If you care about CI transparency or contribute via GitLab, this is worth a quick glance.
