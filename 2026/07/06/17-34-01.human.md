This is a test fix targeting platform compatibility. The patch addresses a flaky test in `t0213-trace2-ancestry.sh` that fails under user-mode emulation (e.g., QEMU) because the process name reported in the `cmd_ancestry` trace2 event reflects the emulator ("qemu-riscv64") rather than the expected Git command ("test-tool" or "git").

The change modifies the detection logic for the `TRACE2_ANCESTRY` prerequisite: instead of just checking whether the `cmd_ancestry` event is emitted, it now verifies that the event correctly reports "test-tool" in the ancestry of a test-tool process spawned from another test-tool process. This ensures the tests skip when process names are unreliable, such as under emulation.
