This is the first patch in Harald Nordgren’s five-part series introducing the `git history squash` subcommand. It is a pure refactoring: it extracts a small helper function, `first_parent_tree_oid()`, that centralizes the logic for resolving the tree of a commit’s first parent (or the empty tree for a root commit). The helper is then used in three places in `builtin/history.c` that previously repeated the same parse-and-copy dance.

The patch is mechanical and well-contained. It changes no behavior, only moving code around to eliminate duplication. The commit message is clear and the diff is easy to follow. This is a sensible cleanup that prepares the file for the larger changes that follow in the series. There is nothing controversial here; it looks like a routine preparatory step.
