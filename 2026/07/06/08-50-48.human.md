This is the fourth patch in Harald Nordgren’s v7 series implementing `git history squash`. The patch extracts three static helpers from the sequencer (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) so that the upcoming `git history squash --reedit-message` feature can build the same editor template that `git rebase -i` uses for squash commits.

The extracted functions are straightforward: one adds the “This is a combination of N commits” banner, another adds the “This is the 1st/Nth commit message” (or “will be skipped”) header above each message, and the third computes how much of the subject line to comment out for a `fixup!`, `squash!`, or `amend!` commit. The patch moves these helpers from static functions in `sequencer.c` to public declarations in `sequencer.h` and updates the existing rebase code to call them. No behavior changes; this is pure refactoring to enable code reuse in the next patch.
