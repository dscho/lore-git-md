This is the final patch in Harald Nordgren’s five-part series implementing `git history squash`, a new subcommand that folds a commit range into its oldest commit while preserving descendant history. This patch delivers the `--reedit-message` feature, allowing users to combine the messages of all folded commits in an editor session.

The implementation now mirrors `git rebase -i`’s squash behavior exactly. When `--reedit-message` is given, the editor opens with a template that lists every folded message under its own header, following autosquash rules: a `fixup!` message is fully commented out under a “will be skipped” banner, while a `squash!` or `amend!` keeps its body with only the marker subject commented so the remark can be reworded. The patch extracts three sequencer helpers (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) to ensure both commands build the identical template from one source.

The documentation is updated to clarify the template format and autosquash handling, and the test script grows by 115 lines to verify the template construction, marker handling, and empty-message abort. This patch completes the series; all prior feedback—including Junio’s request for template consistency and Phillip Wood’s usability concerns—has been addressed. The series is now ready for Junio’s final assessment.
