This is the third and final patch in the v6 series adjusting Git's build system for Rust integration on macOS, specifically targeting CI verification for the `git-credential-osxkeychain` helper. The patch ensures the macOS credential helper is automatically built and tested during standard CI runs by wiring it into `contrib/Makefile` when running on Darwin.

The change introduces an `OS_CONTRIB` variable in `contrib/Makefile` that conditionally includes `credential/osxkeychain` when the system is macOS. The helper is then added to the `all`, `test`, and `clean` targets, ensuring it is built, tested, and cleaned alongside other contrib utilities. The `contrib/credential/osxkeychain/Makefile` is also updated to define a `test` target that depends on building the helper, guaranteeing the binary is available for testing.

This patch addresses a gap in automated testing for macOS contrib utilities, preventing build or symbol-linking regressions from slipping through CI. The implementation is minimal and scalable, touching only the `contrib/` directory's Makefiles and introducing no new dependencies or platform assumptions. The change is implicitly covered by existing build tests and maintains backward compatibility.

Key technical details include the `OS_CONTRIB` variable, the conditional inclusion of the credential helper based on the `uname_S` value, and the use of `$(foreach)` to iterate over `OS_CONTRIB` in the `all`, `test`, and `clean` targets. The patch is part of the broader Rustification effort, ensuring the macOS credential helper—now built with Rust components—is reliably tested in CI. The series is unblocked and ready for integration, with this patch completing the CI verification goal.
