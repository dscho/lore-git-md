This thread is about a small but useful diagnostic improvement in Git's setup code. Gatla Vishweshwar Reddy sent a patch that fixes two error paths in `setup.c` where `chdir()` failures were calling `die()` instead of `die_errno()`, which meant users lost the system error message (like "Permission denied") when Git failed to change directories during startup. The fix is simple: switch to `die_errno()` to preserve and display the error.

Junio has already queued the patch for merging, calling it a "good change" and only reminding the author about the etiquette of sending follow-up versions as replies to the original. There’s been no substantive review feedback because the change is mechanical and clearly improves error reporting without altering behavior. The patch touches only `setup.c` and doesn’t introduce new symbols, tests, or configuration options. It’s a standalone fix, not part of a larger series, and should land in an upcoming release.
