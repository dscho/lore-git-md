This is the **second patch in the v4 series introducing `greplint.pl`**, a test-suite linter that converts bare `grep` assertions to `test_grep`. This specific patch is a **bugfix** addressing three pre-existing test suite issues where `grep` assertions were missing file arguments, causing them to read from empty stdin instead of the intended files. The fixes are minimal (one-line changes in three test scripts) and restore the intended behavior without altering test logic.

The bugs were discovered during the `greplint.pl` conversion effort, which revealed that these assertions were effectively no-ops—since `grep` with no file argument reads stdin, and stdin was empty, the assertions always succeeded. The patch corrects the file arguments to match the context (e.g., `out` in `t2402-worktree-list.sh`, `actual` in `t7507-commit-verbose.sh`, and `packlist` in `t7700-repack.sh`). All three tests continue to pass after the fix, confirming the intended behavior was sound.

This patch is **uncontroversial and ready for merging**, as it only fixes latent bugs without introducing new logic or edge cases. It directly supports the series’ goal of ensuring `greplint.pl` conversions do not preserve or mask pre-existing test bugs. The changes are mechanical and self-explanatory, with no dependencies on other patches in the series. Files touched: `t/t2402-worktree-list.sh`, `t/t7507-commit-verbose.sh`, and `t/t7700-repack.sh`.
