Core problem or goal
Add a safeguard to the existing shell-script `git-subtree` (in `contrib/`) to detect and reject repositories that have been modified by a forthcoming Rust rewrite of the same command. The Rust rewrite will use a config file to store downstream project metadata and will not be backward-compatible; mixing the two implementations could create unparseable history.

Under review; v1 posted. No prior versions.

- New config key: `subtree.rust-rewrite` (presence triggers the error).
- New error message: “This repository appears to have been used with the new git-subtree Rust rewrite.”
- Test coverage: one new test case verifies the error is triggered when the config key exists.
