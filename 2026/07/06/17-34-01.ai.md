This is a test fix targeting platform compatibility, specifically for user-mode emulation environments like QEMU.

The patch addresses a failure in the `t0213-trace2-ancestry.sh` test script, which was introduced in commit 3c8c638df6 to verify Git's Trace2 ancestry tracking. The tests expect the `cmd_ancestry` event to report process names like "test-tool" and "git", but under user-mode emulation (e.g., `qemu-riscv64`), `/proc/<pid>/stat` reports the emulator's name ("qemu-riscv64") instead of the guest process. This causes tests 2-5 to fail despite the functionality working correctly on native hardware.

The fix modifies the detection logic for `TRACE2_ANCESTRY` support to require that the ancestry event includes the expected process name ("test-tool"). This ensures the tests skip when process names are unreliable, such as under emulation. The change is minimal: it updates the test prerequisite check to spawn `test-tool` from itself and verify the child's ancestry contains "test-tool".
