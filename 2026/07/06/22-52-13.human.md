This is the third and final patch in the v6 series adjusting Git’s build system for Rust components on macOS. It adds CI verification for the `git-credential-osxkeychain` helper by wiring it into `contrib/Makefile` on macOS.

The patch introduces an `OS_CONTRIB` variable that conditionally includes `credential/osxkeychain` when running on Darwin. This ensures the helper is built, tested, and cleaned as part of the standard `make all`, `make test`, and `make clean` workflows in `contrib/`. Previously, only `diff-highlight` and `subtree` were tested in CI, leaving `git-credential-osxkeychain` untested despite being a critical macOS utility. The change is minimal and scalable, touching only the `contrib/` directory’s Makefiles.

The patch is well-motivated: it closes a gap in automated testing for a platform-specific contrib utility, preventing build or linking regressions from slipping through CI. The implementation is clean and follows existing patterns in `contrib/Makefile`. No new tests are introduced, but the change ensures the helper is implicitly covered by existing CI workflows. This is a straightforward, low-risk improvement that complements the earlier patches in the series.
