This thread is about a small but important test fix for Git’s Trace2 ancestry tracking. The issue surfaces in user-mode emulation environments like QEMU, where `/proc/<pid>/stat` reports the emulator’s name ("qemu-riscv64") instead of the guest process ("test-tool" or "git"). This causes the `t0213-trace2-ancestry.sh` test to fail even though the underlying functionality works correctly on native hardware.

The patch, submitted as an initial fix, tweaks the test prerequisite logic to require that the ancestry event includes the expected process name ("test-tool"). This ensures the tests skip gracefully when process names are unreliable, such as under emulation. The change is minimal and well-justified, focusing only on test behavior in edge cases without touching core Git functionality. Given its narrow scope and clear motivation, it’s likely to be uncontroversial and merged without much discussion.
