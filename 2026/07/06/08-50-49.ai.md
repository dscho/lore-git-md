This is the final patch in Harald Nordgren’s `git history squash` series (v7 5/5). It implements the `--reedit-message` flag to let users combine the messages of every commit in the squashed range, matching the editor template that `git rebase -i` shows for a squash.

The patch extracts the sequencer’s `add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len` helpers so both commands build the identical template. A `fixup!` message is fully commented out under a “will be skipped” header, while a `squash!` or `amend!` keeps its body with only the marker subject commented. The documentation is updated to explain this behavior and the autosquash-style formatting.

Code changes are confined to `builtin/history.c` (73 insertions), `Documentation/git-history.adoc` (12 insertions), and the test script `t/t3455-history-squash.sh` (115 insertions). The new `build_squash_message` helper walks the range in reverse topo-order, gathers each commit’s message, and constructs the template that is then passed to `commit_tree_ext`. Three new tests verify the template format, autosquash marker handling, and empty-message abort.
