This is a small bugfix patch for the `` `git rm` `` command. The change replaces a plain `die()` call with `die_errno()` when `remove_file_from_index()` fails, so that the error message includes the system error string (e.g., "Permission denied") instead of just the path. The patch touches only one line in `builtin/rm.c` and is self-contained. The commit message is minimal but sufficient for the scope. Given that it is a clear correctness improvement with no downsides, it looks like a straightforward candidate for merging.
