This is the third patch in a six-part series that introduces `greplint.pl`, a new test-suite linter for Git. This patch extracts the shell parsing infrastructure from `chainlint.pl` into a shared module (`lib-shell-parser.pl`) so that `greplint.pl` (introduced in a later patch) can reuse it. The extraction is purely mechanical—no functional changes are made to `chainlint.pl`, and its self-tests continue to pass.

The shared module provides three classes: `Lexer` (tokenizes POSIX shell scripts), `ShellParser` (parses shell commands), and `ScriptParser` (identifies test definitions). `ScriptParser`’s `check_test()` method is a no-op in the shared module; `chainlint.pl` overrides it with its own implementation (`ChainlintParser`) to check for broken `&&` chains. This design keeps the shared code generic while allowing downstream tools to add their own lint rules.

The patch moves ~500 lines of code from `chainlint.pl` to `lib-shell-parser.pl` and updates `chainlint.pl` to load the shared module at runtime. The change is straightforward and well-contained, touching only the two files mentioned. Since the extraction doesn’t alter behavior, it poses no risk to existing functionality. The shared parser will enable future lint tools (like `greplint.pl`) to avoid duplicating complex shell parsing logic.
