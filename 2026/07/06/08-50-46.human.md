This is the second patch in Harald Nordgren’s five-part series implementing `git history squash`. The patch extends `commit_tree_ext()`—a helper used by several history-editing commands—so it can accept an optional `message_template` parameter. When provided, the template overrides the commit message from the original commit, allowing the caller to seed the editor with a custom message.

The change is mechanical and focused: the function signature gains a `const char *message_template` parameter, and the logic is updated to use it when non-NULL. Existing callers (`cmd_history_fixup` and `split_commit`) pass NULL, so their behavior is unchanged. The patch prepares the plumbing for the `--reedit-message` flag introduced later in the series, which will build a template from all the commits being squashed. No user-visible behavior changes yet; this is purely infrastructure.
