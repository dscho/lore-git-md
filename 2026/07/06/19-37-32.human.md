Junio C Hamano has accepted Gatla Vishweshwar Reddy’s patch to switch two `chdir()` error paths in `setup.c` from `die()` to `die_errno()`. The change is purely diagnostic: when Git fails to change directory during repository setup, the error message will now include the system error string (e.g., “Permission denied”) instead of silently discarding it. The patch is mechanical, confined to two lines, and requires no tests or documentation updates. Junio’s terse “Will queue” signals that the patch is uncontroversial and ready for integration.
