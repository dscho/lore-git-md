This is a test modernization patch targeting the `t1410-reflog.sh` test script. The patch addresses a common but subtle issue in shell-based test scripts: when Git commands are piped directly to `wc -l`, the exit code of the Git command is lost because only the exit code of the last command in the pipeline (`wc -l`) is preserved. This can mask failures in the Git command itself, potentially allowing tests to pass even when the underlying operation failed.

The fix is mechanical and straightforward: instead of piping Git's output directly to `wc -l`, the patch redirects the output to a temporary file first, then counts the lines from that file. This preserves the exit code of the Git command, ensuring that test failures are properly detected. The patch touches eight locations in `t1410-reflog.sh`, replacing each pipeline with a two-step process using temporary files named `reflog_output` and `reflog_main_output`.

The patch itself is well-scoped, focusing only on the exit-code preservation issue and not mixing in unrelated changes. The use of temporary files is a standard and safe approach for this kind of test modernization.
