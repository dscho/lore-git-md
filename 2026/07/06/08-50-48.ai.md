This is a refactoring patch in Harald Nordgren’s `git history squash` series (v7, 4/5). It extracts three static helpers from the sequencer’s squash-message logic—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—so that the upcoming `git history squash --reedit-message` feature can build the same editor template that `git rebase -i` uses for squash. The patch is purely internal plumbing; no user-visible behavior changes. The extracted functions are small, focused, and documented in `sequencer.h`, making them reusable for any future command that wants to present a squash message in the same style. This is a clean, well-motivated refactoring that directly supports the series’ goal of template consistency.
