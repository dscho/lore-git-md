This is a build system fix for the Meson build. Mike Gilbert reports a race condition in the Git build process where `hook-list.h`—a generated header—is not created before `builtin/bugreport.c` tries to include it, causing compilation to fail. The patch moves the `hook-list.h` custom target from `libgit_sources` to both `libgit_sources` and `builtin_sources` so that the header is generated early enough for all consumers.

The commit message is clear and links to both a Gentoo bug report and the commit that introduced the problem. The fix itself is minimal: it simply ensures the header is generated before any code that needs it is compiled. This looks like a straightforward, well-motivated bugfix that should resolve the build failure without side effects.
