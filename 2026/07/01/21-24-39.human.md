This is the first patch in a four-part bugfix series that standardizes help-flag exit codes across Git's parse-options infrastructure. This patch is a minor test prerequisite adjustment: it adds a check to skip Subversion-related tests in `t1517-outside-repo.sh` if the SVN Perl modules are not installed.

The change is straightforward and well-motivated. The upcoming patches in the series will make `git svn` exit 0 (instead of 129) when `--help` is used, so the test script needs to know whether `git svn` is even available before deciding whether to expect success or failure. The new `SVN` prerequisite is a stripped-down version of the check used in `t/lib-git-svn.sh`, ensuring consistency with the rest of the test suite.

This patch does not affect any user-facing behavior or core Git functionality. It is purely test infrastructure, preparing the ground for the substantive changes that follow. The implementation is clean and follows established patterns in the test suite. There is no controversy here; this is a routine prerequisite addition.
