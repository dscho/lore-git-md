Subject: [PATCH] meson: fix build race in generating hook-list.h
Series version: standalone patch
Originating author: D. Ben Knoble
Thread type: bug fix

Core problem or goal
Restore `hook-list.h` to the `builtin_sources` list in `meson.build` so the header is generated before `builtin/bugreport.c` is compiled, eliminating a race condition that causes build failures when the header is missing. The issue was introduced by commit `2eb541e8f2a9` ("hook: move is_known_hook() to hook.c for wider use"), which made `bugreport.c` depend on the header without ensuring its prior generation.

Current status
Patch sent; no prior iterations. Adrian Ratiu confirms the fix resolves the build failure and approves it with "LGTM". Patrick Steinhardt reinforces the correctness of the approach, noting the fix aligns with the expected dependency structure. The patch remains unchanged from the original submission and is ready for merging.

Key technical details
- Files touched: `meson.build` only
- Subsystem: Meson build system
- New/renamed symbols: none
- Old-vs-new behavior: header is now generated in the correct order, preventing build failures; the `custom_target` for `hook-list.h` is moved earlier in the file and added to both `libgit_sources` and `builtin_sources` to enforce dependencies
- On-disk format: unchanged
- Test coverage: none added; the fix is build-system internal
