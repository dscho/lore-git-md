Core problem or goal
Restore `hook-list.h` to the `builtin_sources` list in `meson.build` so the header is generated before `builtin/bugreport.c` is compiled, eliminating a race condition that causes build failures when the header is missing. The issue was introduced by commit `2eb541e8f2a9` ("hook: move is_known_hook() to hook.c for wider use"), which made `bugreport.c` depend on the header without ensuring its prior generation.
