This is the eighth patch in Johannes Schindelin’s 13-patch series fixing Coverity-flagged resource leaks and error-path bugs in Git. It plugs a memory leak in `get_superproject_working_tree()` (submodule.c) where the current working directory (`cwd`), allocated via `xgetcwd()` at the start of the function, is not freed on two early-return paths: when Git is not inside a work tree, and when `strbuf_realpath()` fails to resolve the `../` path. The fix adds a cleanup label (`out`) that frees `cwd` before returning, ensuring proper resource cleanup. The change is mechanical, well-scoped, and uncontroversial, fitting neatly into the broader Coverity-driven cleanup effort. No user-visible behavior changes; the patch is purely about internal correctness.
