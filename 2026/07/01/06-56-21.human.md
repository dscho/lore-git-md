This is a **CI/build system** follow-up to the macOS CI hang thread. Patrick Steinhardt confirms he will send a formal patch to add a GitLab CI status badge to the project’s `README.md`, following Junio C Hamano’s explicit endorsement of the idea.

The change is purely cosmetic: a one-line addition that places a GitLab CI badge alongside the existing GitHub badge, linking directly to the pipelines page for the `master` branch on GitLab’s official mirror. Junio called the proposal "nice" and framed it as a low-cost way to improve visibility of GitLab CI results, which he had previously noted were harder for maintainers to discover than GitHub’s. The patch will address the last open question about CI policy in the thread; the original two-patch series (Apache timeout increase and test isolation) is already merged for Git 2.55, and this follow-up is uncontroversial. Expect the badge to land soon.
