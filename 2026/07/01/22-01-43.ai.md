This is a build system patch for the Rustification effort, specifically targeting the macOS credential helper and introducing support for universal (multi-architecture) Rust builds. The patch is the second iteration of a series that has already reached consensus on the core approach after earlier debate about build system design patterns.

The change does two things: first, it ensures the `git-credential-osxkeychain` helper is properly linked with Rust libraries when Rust support is enabled (replacing the earlier `RUST_LIBS` variable approach with direct use of `$(RUST_LIB)`). Second, and more significantly, it adds native Makefile support for macOS Universal Binaries by allowing users to specify multiple target triples in the `RUST_TARGETS` environment variable. When multiple targets are provided, the build system uses `lipo` to combine them into a single universal static library.

The implementation is clean and declarative, using Make pattern rules to compile each target-specific library slice and then combining them. The patch includes proper error handling for non-macOS platforms and maintains backward compatibility for single-target builds. The commit message provides clear documentation of the new `RUST_TARGETS` variable and its usage.
