This is a bugfix patch, the ninth in Johannes Schindelin’s 13-patch series that plugs resource leaks and error-path bugs flagged by Coverity. It targets the `` `git worktree add` `` command.

When `` `git worktree add` `` fails while creating the new branch (line 948 in `builtin/worktree.c`), the function currently returns -1 immediately, leaking four allocations made earlier: `path` (from `prefix_filename`), `opt_track`, `branch_to_free`, and `new_branch_to_free`. The patch redirects the error return through the existing cleanup block at the end of the function so all four buffers are freed before the function exits. The change is mechanical and does not alter user-visible behavior. Eric Sunshine has already reviewed the first eight patches in the series; this one is equally straightforward and should be uncontroversial.
