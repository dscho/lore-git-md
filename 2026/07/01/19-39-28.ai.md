This is a build system fix for the Meson build. The patch restores `hook-list.h` to the `builtin_sources` list in `meson.build` to ensure the header is generated before `builtin/bugreport.c` is compiled, preventing a race condition that causes build failures when the header is missing.

The issue was introduced by commit `2eb541e8f2a9` ("hook: move is_known_hook() to hook.c for wider use"), which moved the header generation logic but did not account for its dependency in the builtin sources. The fix is straightforward: move the `custom_target` definition for `hook-list.h` earlier in the file and add it to `builtin_sources` so the build system knows to generate it before compiling `bugreport.c`.

The patch is minimal, well-motivated, and includes a link to the Gentoo bug report documenting the failure. It touches only the Meson build configuration and does not affect the Makefile or other build systems. The change is unlikely to be controversial, as it addresses a clear build breakage.
