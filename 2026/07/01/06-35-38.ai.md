This is a three-patch bugfix series from Jeff King targeting memory leaks in Git’s commit-graph Bloom filter code. The leaks only surface when the test suite is run with `GIT_TEST_COMMIT_GRAPH_CHANGED_PATHS=1`, so they are not visible under normal test conditions. The series, combined with two other recent fixes (one from Peff himself and one from Kaartic Sivaraam), will eliminate most of the leaks that would appear if the `linux-TEST-vars` CI jobs were run with leak-checking enabled. The remaining leaks—those tied to OpenSSL SHA-1 builds—are explicitly deferred to a future series. Each patch is small (8 lines total) and touches only the Bloom-filter slab initialization (`bloom.c`), the revision-walk keyvec handling (`revision.c`), and the line-log range-copy logic (`line-log.c`).
