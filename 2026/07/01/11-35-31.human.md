This is the fourth patch in Patrick Steinhardt’s 11-patch v8 series introducing the `git history drop` subcommand. It modernizes the flags passed to the recently renamed `reset_working_tree()` function by converting them from `#define` macros to an `enum` and updating their names to match the new function name.

The change is purely mechanical: every flag (`RESET_HEAD_*`) is renamed to `RESET_WORKING_TREE_*` and the `flags` field in the `reset_working_tree_options` struct is now typed as the new `enum reset_working_tree_flags`. All callers in `builtin/rebase.c`, `reset.c`, and `sequencer.c` are updated to use the new names. The patch is bisectable and introduces no behavior changes.

This is a refactoring step that prepares the reset API for later patches in the series, which will make HEAD updates optional and add dry-run support. The conversion to an enum follows current Git coding practices and improves type safety. No controversy or open questions are evident; the patch is a straightforward cleanup.
