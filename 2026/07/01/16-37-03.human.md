This is a test infrastructure patch, part of the larger `paint_down_to_common()` optimization series (v5, 2/10). The patch introduces `test_trace2_data_singular`, a helper function that improves diagnostic output for trace2 data assertions in Git's test suite.

The new helper verifies that a trace2 event appears exactly once and reports clear, actionable errors when expectations are not met. For example, instead of silently failing when a value mismatch occurs, it now outputs the expected and actual values, making debugging easier. The diagnostics are written to file descriptor 4, consistent with other test helpers like `test_grep`.

This change is a direct response to reviewer feedback on the series, where silent failures in trace2 assertions made debugging difficult. The implementation is straightforward: it uses `sed` to extract the value from the trace2 event, checks for existence and uniqueness, and compares the value against the expected one. The patch touches only `t/test-lib-functions.sh` and adds 36 lines of shell script.

The patch is well-motivated and uncontroversial. It does not change any Git behavior but makes future test failures in this area much easier to diagnose. Given that the entire series is approved and ready to merge, this patch is a small but valuable piece of the puzzle.
