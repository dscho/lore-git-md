This is a build system patch for the ongoing Rustification effort, specifically targeting macOS Universal Binary support for the `git-credential-osxkeychain` helper. The patch expands on earlier work by Shardul Natu and Koji Nakamaru to enable multi-architecture Rust builds on macOS through the `RUST_TARGETS` environment variable.

The implementation introduces a clean Makefile pattern rule to compile target-specific Rust library slices (e.g., `aarch64-apple-darwin` and `x86_64-apple-darwin`), then uses `lipo` to combine them into a single Universal static library when multiple targets are specified. This avoids complex shell scripting while maintaining compatibility with single-target builds. The patch also ensures the osxkeychain helper is properly linked against Rust libraries when Rust support is enabled.

The solution addresses Junio Hamano's earlier architectural concern about variable proliferation by using conditional compilation blocks (`ifndef NO_RUST`) rather than introducing new variables. The commit message provides clear examples of how to use the new `RUST_TARGETS` feature and documents platform requirements (macOS-only for multi-target builds). This appears to be a well-crafted, consensus-driven solution that advances Rust integration without disrupting existing build workflows.
