This is the ninth patch in Patrick Steinhardt’s 11-patch v8 series introducing the `git history drop` subcommand. It exposes the previously static `replay_result_queue_update()` function in `replay.h` so that it can be reused in a later patch.

The change is a straightforward refactoring: the function, which appends a reference update to a `replay_result` struct, was already fully implemented in `replay.c`; this patch merely moves its declaration to the header file. The motivation is to avoid code duplication in patch 11, where `git history drop` will need to queue reference updates during the replay phase. Christian Couder suggested this approach during review of an earlier iteration.

The patch itself is small (9 lines added, 4 removed) and mechanical. It does not alter behavior or introduce new functionality, but it is a necessary preparatory step for the drop subcommand’s ref-update logic. The series as a whole is now technically complete, with all prior feedback addressed, including the critical ref-resolution dispute that stalled v7. This patch is uncontroversial and appears ready for merging.
