This is the fifth patch in Johannes Schindelin’s 13-patch series fixing Coverity-identified leaks and error-path bugs in Git. It plugs a memory leak in `run_diff_files()` (diff-lib.c) that occurs when the loop skips a conflicted index entry (`ce_stage(ce)`) after allocating a `combine_diff_path` structure (`dpath`) but before the code reaches the normal cleanup block. The fix adds a `free(dpath)` call on the error path that was previously missed, ensuring the structure is released when `changed < 0` triggers an early `continue`. The change is minimal (two lines: initialize `dpath` to NULL and free it on error) and follows the pattern established in an earlier commit (b4b1550315c) that demonstrated the need for explicit cleanup. No user-visible behavior changes; the patch is purely about internal correctness. The leak was flagged by Coverity and the fix is uncontroversial.
