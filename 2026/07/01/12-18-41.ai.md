This is a refactoring patch that generalizes `write_fetch_command_and_capabilities()` into a more reusable `write_command_and_capabilities()` function. It is the seventh patch in the GSoC v15 series implementing `git cat-file --batch-command` support for remote object metadata queries.

The patch changes the function signature to accept an arbitrary command string (e.g., "fetch", "object-info") instead of hardcoding "fetch". This prepares the codebase for future protocol commands by making the function reusable. The implementation is mechanical: the function body is updated to use the passed-in command string, and all callers in `fetch-pack.c` are updated to pass "fetch" explicitly. The function is also renamed and its documentation in `connect.h` is updated to reflect its broader purpose.

This is a clean, well-motivated refactoring that directly supports the series' goal of protocol command reuse. The patch is small (12 lines changed) and focused, with no behavior changes. It builds on the preparatory work in patch 6/13 (function relocation) and will be used in patch 10/13 to implement the `object-info` command.
