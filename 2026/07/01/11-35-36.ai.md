This is a refactoring patch in Patrick Steinhardt’s `git history drop` series (v8, 9/11). It exposes the static helper `replay_result_queue_update()` so that later patches can reuse it to append reference updates to the replay result.

The change is minimal and mechanical: the function is moved from `replay.c` to `replay.h` with no logic changes, and its signature is adjusted to match the new visibility. This is a preparatory step for patch 11/11, which will use the helper to deduplicate ref-update logic between the replay and history code paths. The commit message credits Christian Couder’s suggestion, and the patch itself is uncontroversial — it simply makes an existing internal API available for broader use within the series. No behavior changes or new functionality are introduced.
