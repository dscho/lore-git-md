This patch **consolidates the `min_generation` termination check** into `paint_queue_get()`, alongside the existing stale-entry and side-exhaustion checks. It moves the `last_gen` timestamp into the `paint_state` struct, ensuring `commit_graph_generation()` is called exactly once per dequeued commit. The change is **mechanical and correctness-preserving**, with no behavior change—it merely reorganizes the code to share the generation value across termination conditions and the monotonicity BUG assertion.

Key details:
- **Files touched**: `commit-reach.c` only.
- **Struct changes**: Adds `min_generation` and `last_gen` to `paint_state`.
- **Function changes**: `paint_queue_get()` now handles the generation cutoff and BUG assertion, eliminating redundant calls to `commit_graph_generation()` in the main loop.
- **Behavior**: The `min_generation` check fires earlier (inside `paint_queue_get()`), but the loop exit condition remains logically identical. The BUG assertion now triggers only when `min_generation` is set, matching the original intent.
- **Performance**: No measurable impact; the change is purely structural.
