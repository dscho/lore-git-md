This is a **documentation** follow-up in the macOS CI hang thread. Patrick Steinhardt sends the promised patch to add a GitLab CI status badge to the project’s `README.md`, following Junio C Hamano’s explicit endorsement of the idea as a low-cost way to improve visibility of GitLab CI results.

The patch is trivial: it adds a single line beneath the existing GitHub CI badge, linking to the pipelines page for the `master` branch on GitLab’s official mirror. The change is uncontroversial and directly addresses the maintainer’s earlier concern that GitLab CI results were not easily discoverable. With Junio’s blessing already secured, this patch is effectively a formality and will almost certainly be merged for Git 2.55 alongside the earlier CI fixes.

No new technical or policy issues are introduced. The thread’s original two-patch series (Apache timeout increase and test isolation) is already merged, and this follow-up is purely about documentation. The still-on-hold third patch (enabling `GIT_TEST_LONG` for GitLab CI) remains separate and unaffected by this change.
