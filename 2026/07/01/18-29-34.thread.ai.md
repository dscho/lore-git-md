Core problem or goal
Git for Windows’s `git gui` fails to start when the user’s home directory contains non-ASCII characters (e.g., accented letters from EntraID/AzureAD profiles). The root cause is an encoding mismatch: `git-gui.tcl` uses Tcl’s default system encoding (ANSI code page) to capture the output of `cygpath -m`, which emits UTF-8. The proposed fix replaces the `safe_exec` call with `safe_open_command` and explicitly sets `-encoding utf-8` to match `cygpath`’s output.

Current status
Patch proposed; fix confirmed to resolve the issue on Windows 11 25H2 Pro (Czech locale). No prior versions or iterations reported. The patch touches only the encoding conversion in `git-gui.tcl` (line 403) and leverages existing patterns (`git_redir`, `_parse_config`) elsewhere in the codebase.
