This is the third patch in Johannes Schindelin’s 13-patch Coverity-driven cleanup series. It plugs a file-descriptor leak in `download_https_uri_to_file()` (defined in `bundle-uri.c`) that occurs when the `git-remote-https` child process fails: the `child_out` stream is never closed if `finish_command()` returns an error. The fix is a one-line reordering that moves the `fclose(child_out)` call before the `return 1` so it executes unconditionally on the error path. The patch is mechanical, uncontroversial, and covered by the existing test suite.
