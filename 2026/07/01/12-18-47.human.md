This is the final patch in the GSoC v15 series implementing `git cat-file --batch-command`'s `remote-object-info` feature. It replaces the static allow-list for format placeholders with dynamic validation based on what the server actually advertises, making the client future-proof for new metadata attributes like `%(objecttype)`.

The patch moves the hardcoded list of allowed atoms (`objectname`, `objectsize`) into a runtime-populated `string_list` in `struct expand_data`. When the client requests object info from a remote, it first checks which options the server supports (via the `object-info` capability), then builds an allow-list of placeholders that map to those options. For example, if the server advertises `object-info=size type`, the client will allow `%(objectsize)` and `%(objecttype)` but reject any other atoms.

Key changes:
- Adds a `remote_allowed_atoms` field to `struct expand_data` and initializes it in `EXPAND_DATA_INIT`
- Introduces a mapping table (`remote_atom_map`) that translates protocol options (`size`, `type`) to placeholder atoms (`objectsize`, `objecttype`)
- Modifies `get_remote_info()` to accept an external `object_info_options` list instead of creating its own
- Filters the requested options in `fetch_object_info()` to only those the server supports
- Updates `parse_cmd_remote_object_info()` to populate the allow-list after fetching data
- Ensures `batch_object_write()` is called even when some placeholders are unsupported (returning empty strings)

The patch is clean and well-motivated, addressing the last major architectural concern from earlier reviews: static allow-lists would break as servers add new metadata attributes. The implementation is careful about memory management (clearing the `string_list` in cleanup paths) and maintains backward compatibility. The mapping table makes it easy to add new attributes in the future.

This completes the series, which is now ready for merging. The dynamic allow-list is a necessary improvement for long-term maintainability, and the patch integrates smoothly with the rest of the feature.
