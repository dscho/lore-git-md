This thread is a 12-patch series from Johannes Schindelin (Dscho) that fixes resource leaks and error-path bugs flagged by Coverity Scan after its recent resumption. The series is now at v2, with several patches revised or added to address maintainer and reviewer feedback, and the first five patches of the original v1 withdrawn—either because they were already fixed upstream or because they needed rework.

Junio Hamano, the maintainer, has given the series a strong green light, stating he will queue it for merging. Most patches have already received Reviewed-by tags from Patrick Steinhardt, Jeff King (Peff), and Eric Sunshine, with the fixes described as straightforward and correct. The changes are purely internal, plugging memory, file-descriptor, and process-handle leaks without altering user-visible behavior. Key fixes include ensuring proper cleanup in error paths, preventing undefined behavior (like closing invalid file descriptors), and removing redundant allocations that were never freed.

The ninth patch, just summarized, plugs a memory leak in `imap-send.c` by releasing a strbuf buffer that was previously left unfreed. Like the rest of the series, it’s a mechanical fix with minimal risk. The only loose end is an orthogonal bug in `read_one_dir()` involving uninitialized slots, which Dscho plans to address separately. With Junio’s approval and most patches already reviewed, this series is on track to be merged soon.
