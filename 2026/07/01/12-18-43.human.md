This is the ninth patch in the GSoC v15 series implementing `git cat-file --batch-command` support for remote object metadata queries. It enables servers to advertise which `object-info` features they support (currently just `size`) via the `object-info` capability in protocol v2.

The patch updates both the server-side implementation and the protocol documentation. In `serve.c`, the `object_info_advertise()` function now populates the capability value with "size" when advertising is enabled, allowing clients to know what metadata the server can provide. The documentation in `gitprotocol-v2.adoc` is clarified to specify that object IDs must be full (not short), that `obj-size` is optional in responses, and that servers return only the object ID (with no size) for unrecognized objects.

This is a well-motivated protocol design patch that addresses earlier review feedback about forward compatibility. The changes are minimal and focused, with clear documentation updates that resolve ambiguity about server behavior. The patch demonstrates good attention to detail in both the implementation and the specification.
