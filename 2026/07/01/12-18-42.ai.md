This is a refactoring patch in the ongoing `git cat-file --batch-command` remote-object-info series (GSoC v15, patch 8/13). It prepares the `do_fetch_pack_v2()` state machine for future extension by moving variable initialization out of the `FETCH_CHECK_LOCAL` state and into the function prologue.

The change is mechanical and risk-free: six lines of initialization code are relocated from inside the first state case to just before the state machine loop begins. This ensures the variables (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) are set regardless of which state the machine starts in, which will be needed in a later patch that introduces a new initial state. The commit message explicitly notes there is no behavior change, and the diff confirms the moved code is identical.

The patch carries Helped-by trailers from Jonathan Tan and Christian Couder, indicating substantive review, and is co-signed by Calvin Wan (original author), Eric Ju, and Pablo Sabater (series integrator). This is a clean, well-motivated preparatory step in a security-hardened feature series that is now ready for merging.
