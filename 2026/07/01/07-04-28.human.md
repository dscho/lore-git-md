This is the tenth patch in Johannes Schindelin’s 13-patch series fixing Coverity-identified resource leaks and error-path bugs in Git. It plugs a memory leak in the IMAP-send code (`imap-send.c`).

The patch is a one-line addition: `strbuf_release(&msgbuf.buf)` is called alongside the existing libcurl cleanup in `curl_append_msgs_to_imap()`. The leak occurs because the `msgbuf` strbuf grows across loop iterations to accumulate message data but was never released before the function returned. Coverity flagged this as CID 1671507 ("Resource leak"). The fix is mechanical and uncontroversial, matching the style of the earlier patches in the series. No user-visible behavior changes; the patch is purely about internal correctness.
