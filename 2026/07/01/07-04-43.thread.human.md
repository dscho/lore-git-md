This thread is about a small but critical fix to Git’s CI configuration. Johannes Schindelin identified that Dockerized GitHub Actions jobs fail consistently in private repositories due to default PID limits on hosted runners, producing "cannot create async thread" errors during test execution. The patch raises these limits (`--pids-limit=16384`, `--ulimit=nproc=16384`, `--ulimit=nofile=32768`) only for private repositories, based on benchmarking that shows 16k is the sweet spot—higher values slow down test runs significantly.

The fix is narrowly targeted: it modifies only the container options in `.github/workflows/main.yml` and leaves public repositories untouched. Schindelin’s motivation is practical—enabling private testing of Microsoft’s Git changes—and the commit message provides clear evidence for the chosen limits. Junio’s review was limited to commit message wording (resolved in v2), and there’s been no technical pushback. The patch is uncontroversial and ready for integration, with no open questions remaining.
