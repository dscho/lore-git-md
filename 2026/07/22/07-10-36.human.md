This is the core implementation patch of Harald Nordgren’s long-running `git branch --delete-merged` series, now in its 20th iteration and **ready for merging**. The patch adds the new `--delete-merged` subcommand to `git branch`, enabling safe, automated cleanup of local branches whose work has already landed on their upstream.

The command deletes local branches only when their tip is reachable from one of the specified upstreams (e.g., `--delete-merged origin/main --delete-merged origin/next`), and supports optional positional patterns (e.g., `topic-*`) to limit deletion scope. It incorporates multiple safety mechanisms: checked-out branches are spared, branches with missing upstreams are preserved, and branches that push to their upstream (e.g., `main` tracking `origin/main`) are kept to avoid false positives after a pull. The implementation also includes **order-independent stacked-branch protection**, ensuring no branch is deleted out from under unmerged work—even in complex dependency chains like `b1→b2→b3`.

The patch is **well-tested**, with 200+ lines of new integration tests covering edge cases like self-referential upstreams, missing upstreams, and the new order-independent protection logic. The commit message and documentation are thorough, explaining both the behavior and the rationale behind each safety check. The code itself is clean and follows Git’s conventions, with clear variable names and modular helper functions.

This is a **feature patch** that addresses a real workflow pain point—automated branch cleanup—without introducing backward-incompatible changes. The series has been unblocked after resolving the last correctness issue (order dependency in stacked-branch protection), and Junio C Hamano has confirmed the design is sound. The only follow-up work is extending the protection logic to `git branch -d` for consistency, which will be implemented after the series lands. If you care about branch management or have ever wished for a safer way to prune merged branches, this is worth reviewing.
