This is the second patch (2/2) in Son Luong Ngoc’s v3 series fixing `git rebase --update-refs` edge cases with symbolic references. It extends the symref handling introduced in patch 1 to cover non-branch targets (tags, notes, etc.) and prevents duplicate updates when multiple aliases point to the same ref.

The patch adds two key safeguards: (1) it checks both the literal symref name and its resolved target against the list of checked-out branches, preventing cross-worktree conflicts, and (2) it deduplicates updates by tracking resolved targets in the todo list, ensuring that multiple aliases to the same branch don’t cause compare-and-swap failures. The implementation touches `sequencer.c` and `branch.c`, and the test suite (`t3404-rebase-interactive.sh`) now covers non-branch symrefs, symref chains, and cross-worktree scenarios.

All review feedback from Phillip Wood has been addressed. The patch is technically complete, with clear commit messages and thorough test coverage. It complements patch 1 by handling the remaining edge cases while maintaining the existing behavior for concrete branches. The series is now ready for maintainer consideration.
