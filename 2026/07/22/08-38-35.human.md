This is a small bugfix patch targeting the `git-p4.py` script, which is part of Git's Perforce interoperability tooling in `contrib/`. The patch modifies the `extractLogMessageFromGitCommit` function to skip commit metadata (author, tree, parent SHAs, etc.) and return only the commit message body.

The motivation is straightforward: the current implementation incorrectly returns the entire commit object, including headers, when only the message body is needed. The fix is contained to a single function in `git-p4.py` and involves adjusting how the commit data is parsed to skip past the headers. The change is minimal—nine lines added, three removed—and the commit message clearly states the problem and solution.

This is not part of any larger series or ongoing effort; it’s a standalone fix for a specific script. The patch looks well-scoped and addresses a real (if minor) issue in a peripheral part of the codebase. If you use `git p4` and care about the log message extraction behavior, this patch is worth a quick look. Otherwise, it’s unlikely to affect core Git functionality.
