Core problem or goal
The `extractLogMessageFromGitCommit` helper in `contrib/git-p4.py` currently returns the entire raw commit object (headers + message) when it should return only the commit message body. This causes Perforce-to-Git import operations to include unwanted metadata (author, tree, parent SHAs, etc.) in the imported commit messages.
