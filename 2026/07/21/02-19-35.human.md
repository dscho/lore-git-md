This is Junio’s latest “What’s cooking in git.git” report for July 2026 (#09), the regular digest that tells busy readers what is in flight, what has graduated, and what is stalled.

The fifth batch of topics has just graduated to `master`, so the report is unusually long.  The highlights:

- **Graduated to `master`**: 16 topics covering everything from Rust interface clean-ups (`bc/rust-hash-cleanups`), reftable tombstone performance (`kk/reftable-tombstone-quadratic-fix`), repository discovery refactoring (`ps/setup-split-discovery-and-setup`), Coverity NULL-safety fixes (`js/coverity-fixes-null-safety`), and documentation synopsis-style updates (`jc/relnotes-2.55-rust-fix`, `wy/doc-myfirstcontribution-trim-quotes`).  The `the_repository` removal effort continues with `ps/copy-wo-the-repository` and `ps/refspec-wo-the-repository`.

- **In `next` (cooking)**: 20+ topics.  The most user-visible are:
  - `hn/url-push-tracking` – when the push remote is a URL, Git now uses the fetch refspec of the uniquely matching configured remote to update the remote-tracking branch (e.g., `@{push}`).
  - `hn/bisect-reset-when-found` – a new `--reset-when-found[=<where>]` option for `git bisect` that automatically resets to the original branch or the found culprit.
  - `pw/rebase-fixup-fixes` – two bugs in `git rebase --autosquash` that caused incorrect commit counts and skipped editor invocations have been fixed.
  - `tb/send-pack-no-ref-delta` – `git send-pack` now honors the `no-ref-delta` capability, avoiding `REF_DELTA` encoded packfiles when the server asks for it.
  - `pz/fetch-submodule-errors-config` – a new `fetch.submoduleErrors` configuration and `--submodule-errors` option to make submodule fetch errors non-fatal.
  - `hn/history-squash` – the experimental `git history squash` command to fold a range of commits into a single commit, with descendants replayed on top.

- **Stalled**: three topics (`kh/doc-trailers`, `sn/rebase-update-refs-symrefs`, `jt/config-lock-timeout`) have been waiting for rerolls or responses for weeks and are at risk of being discarded.

- **New**: three topics entered the queue:
  - `bc/rust-hash-cleanups` (Rust interface memory fixes, already marked “Will merge to `next`”),
  - `ja/doc-synopsis-style-yet-more` (another batch of man-page synopsis conversions, expecting a reroll),
  - `hn/url-push-tracking` (the URL-valued push tracking feature, waiting for a response).

The report also lists the usual assortment of small fixes, test modernizations, and refactoring patches.  Nothing looks controversial; the main action is in the new features and the ongoing `the_repository` removal.
