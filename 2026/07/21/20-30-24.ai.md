This is a refactoring patch targeting the `show-branch` command. Gatla Vishweshwar Reddy sends v10 of a standalone patch that converts `git show-branch` from using the shared `object.flags` field for per-commit state to a dedicated commit-slab (`commit_rev_flags`). The patch removes the previous 27-branch limit entirely by dynamically growing arrays and computing the slab stride at runtime as `(ref_name_cnt + 63) / 64`. The `UNINTERESTING` bit remains in `object.flags` for revision-walking compatibility.

The v10 patch directly addresses the critical regression Junio C Hamano identified in v9: the missing `init_commit_name_slab(&name_slab)` call that caused a division-by-zero crash. Gatla restores the initialization before `repo_config()` and confirms manual testing across all modes (`master`, `-a`, `--merge-base`, `--independent`, `--reflog`, `--list`, `--topics`) and the full test suite. The patch also retains all the behavioral fixes from earlier iterations: `has_only_rev_flag_bit()` in `show_independent()`, `has_subset_rev_flags()` in `join_revs()`, and correct propagation of `UNINTERESTING` to parents.

Key technical details include the new slab-based helpers (`get_rev_flags_ptr`, `peek_rev_flags_ptr`, `or_rev_flag_bit`, `test_rev_flag_bit`, `has_all_rev_flags`, `has_only_rev_flag_bit`, `has_subset_rev_flags`), dynamic allocation of `ref_name[]`, `rev[]`, and `reflog_msg[]` arrays, and removal of the hardcoded `MAX_REVS` limit from both code and documentation. Three new tests in `t/t3202-show-branch.sh` verify correct operation with 30+ branches, including `--independent` and `--merge-base` modes. The patch touches `builtin/show-branch.c`, `Documentation/git-show-branch.adoc`, and the test script.

The patch looks technically sound and addresses all prior feedback. The regression fix is minimal and targeted, and the author’s manual testing regimen suggests thorough verification. No new behavioral concerns are raised in this iteration, and the patch is now likely ready for integration once Junio confirms the fix.
