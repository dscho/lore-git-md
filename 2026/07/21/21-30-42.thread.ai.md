Core problem or goal
Fix a regression (introduced in ca62f524c1, 2023) where `git submodule update --remote` fails to match the submodule’s configured remote when URL aliases (`url.<base>.insteadOf`) are in use. The `.gitmodules` file stores the unexpanded alias (e.g., `local:path`), but the submodule’s remotes report the resolved URL (e.g., `/full/path`), causing the lookup to fail and fall back to the default remote.
