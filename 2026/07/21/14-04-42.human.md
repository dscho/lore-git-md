This is a feature patch adding a `--[no-]edit` option to `git rebase --continue`. The patch allows users to skip the editor prompt when continuing a rebase after resolving conflicts, either via the command-line flag (`--no-edit` or `--edit`) or a new configuration option `rebase.noEdit`. The flags apply only to the current `--continue` invocation, not to subsequent commits in the same rebase.

The motivation is clear: users who frequently rebase may want to accept the existing commit message without manual intervention, and this patch provides a straightforward way to do so.
