This is the sixth patch in K Jayatheerth’s seven-part GSoC series adding new path-related keys to `git repo info`. The patch introduces `path.grafts.absolute` and `path.grafts.relative` keys, which expose the location of the grafts file—even when the file does not exist.

The thread has settled the main design question: Junio C Hamano explicitly endorses the current behavior (returning the path unconditionally) as intentional and useful, matching the precedent set by `git rev-parse --git-path`. K Jayatheerth agrees and asks whether a v3 is still needed. Unless new objections surface, the patch appears ready to proceed as-is. The only remaining open question in the series is whether `path.index` keys should return an empty string in bare repositories, but that is unrelated to this patch.
