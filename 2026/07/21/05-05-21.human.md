Taylor’s review is **highly technical and actionable**, tracing the regression to specific changes in `find_pack_entry()` and `do_oid_object_info_extended()`. He demonstrates how the current behavior forces Git to check loose objects in earlier backends (e.g., quarantine) even when the object exists in a pack in a later backend (e.g., the main object store), which is particularly costly on NFS. His proposed fix (a two-phase lookup: all packs first, then all loose objects) would restore the old performance but explicitly breaks the ODB abstraction’s goal of treating backends as independent and opaque.
