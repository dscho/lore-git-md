This is a documentation and error-message cleanup patch, the first in Ted Nyman’s three-patch v3 series fixing race conditions in Git’s HTTP transport. It corrects the `--index-pack-arg` option’s documentation and error messages in `git-http-fetch` to reflect that the option is repeatable (one `--index-pack-arg=<arg>` per argument) rather than singular (`--index-pack-args=<args>`). The change touches only the man page and two error messages in `http-fetch.c`; no code logic is altered. This patch was split out from the functional changes at Junio C Hamano’s request to keep the subsequent bugfix patches clean. The motivation is purely cosmetic, but it removes a minor source of confusion for users of the low-level `--packfile` mode.
