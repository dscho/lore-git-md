This thread is about a bugfix patch from Éric NICOLAS that addresses a regression in `git submodule update --remote`. The issue occurs when URL aliases (`url.<base>.insteadOf`) are used: the `.gitmodules` file stores the unexpanded alias (e.g., `local:path`), but the submodule’s remotes report the resolved URL (e.g., `/full/path`), causing the lookup to fail and fall back to the default remote. The patch modifies `repo_remote_from_url()` in `remote.c` to resolve aliases before comparing URLs and includes a test case in `t/t7460-submodule-update.sh`.
