This thread is about a bugfix for a regression in `git submodule update --remote` when URL aliases (`url.<base>.insteadOf`) are used. The issue, introduced in early 2025, caused submodules to fail to match their configured remotes because the `.gitmodules` file stored unexpanded aliases while the remotes reported resolved URLs. Éric NICOLAS authored the fix, which was merged to `master` after Junio C Hamano reviewed and queued it.

The patch modifies `remote.c` to resolve aliases before comparing URLs, ensuring submodules with aliased URLs correctly match their remotes instead of falling back to the default logic. The test coverage verifies the fix with a global `insteadOf` alias and edge cases like remote renaming. Jacob Keller, who encountered the same regression in practice, has now reviewed and endorsed the fix with a `Reviewed-by`, confirming it resolves a real-world issue he had observed. No open questions remain, and the patch is fully integrated.
