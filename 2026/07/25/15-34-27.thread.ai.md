Subject: [PATCH 0/2] checkout -m: refine autostash conflict handling
Series version: v1 (initial)
Originating author: Harald Nordgren
Thread type: patch series

Core problem or goal
Refine `git checkout -m` behavior when autostash is involved by (1) making the sequencer’s autostash apply logic explicitly report conflicts instead of silently failing, and (2) skipping the autostash retry loop when no tracked local changes exist, while also improving the visual separation of autostash conflict advice from the branch-switch confirmation message.

Current status
Under review; v1 posted. Junio C Hamano has accepted patch 2/2 as-is and signaled intent to queue it for integration (branch not yet specified). Patch 1/2 remains under review; Phillip Wood has been explicitly solicited for input due to his prior "leftoverbits" comment cited in the cover letter.

Key technical details
- Files touched: `sequencer.c`/`sequencer.h` (autostash plumbing), `builtin/checkout.c` (retry logic and advice formatting), `builtin/commit.c`, `builtin/merge.c` (return-code adjustments).
- New behavior: `apply_save_autostash_oid()` and `apply_save_autostash_ref()` now accept a `conflicted` output parameter that is set to `true` when stash apply fails; existing callers pass `NULL` to preserve current behavior.
- Fast-path: `merge_working_tree()` now checks `has_unstaged_changes()` or `has_uncommitted_changes()` before invoking `unpack_trees()`; if no tracked changes exist, the autostash retry loop is skipped entirely. The new `allow_autostash` parameter (passed from `switch_branches()`) controls this check.
- Advice output: autostash conflict message is visually separated from the branch-switch confirmation by a blank line printed to stderr when `conflicted` is set.
- Test coverage: new test in `t/t7201-co.sh` verifies both the no-tracked-changes fast-path and the improved advice layout.
- Base commit: `9a0c4701dcd5` on `master`.
- Symbols: `apply_save_autostash_oid()`, `apply_save_autostash_ref()`, `conflicted` parameter, `allow_autostash` parameter.
