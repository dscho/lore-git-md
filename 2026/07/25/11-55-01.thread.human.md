The series is feature-complete, with all prior review feedback addressed, and touches only four files to add end-to-end support for object type metadata: server capability advertisement, client request logic, protocol extension, and client-side parsing. The final patch unifies the default format for all queries, ensuring consistent output across transport protocols and confirming that mixing `info` and `remote-object-info` commands produces identical results.
