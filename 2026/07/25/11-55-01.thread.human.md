This thread is the third iteration of a Google Summer of Code patch series by Pablo Sabater that extends `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The goal is to let clients request and display object type metadata from the server, completing the last piece of metadata guaranteed to match between client and server after a fetch. The series is feature-complete at v3, with all prior review feedback addressed and the architectural refactoring finalized.

The key change replaces the old `struct object_info` with a dedicated `struct fetch_object_info_results` that holds only the fields the caller requests (currently size and type), avoiding sentinel values and boolean flags. The design uses a single array of lightweight structs where the caller controls which fields are populated, aligning with the protocol’s transmission of raw strings like `"blob"` or `"1234"`. Junio and Peff helped refine this approach, and Pablo implemented it across eight patches, covering everything from server capability advertisement to client-side parsing and test updates.
