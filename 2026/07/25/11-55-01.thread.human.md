This GSoC feature patch series by Pablo Sabater extends `git cat-file --batch-command` to support the `%(objecttype)` placeholder for remote-object-info queries, completing the last piece of metadata guaranteed to match between client and server after a fetch. The series is now at v1, with all review feedback addressed, and consists of five patches that add server capability advertisement, client request logic, protocol extension, and client-side parsing/display for object type metadata.

The key change in this final exchange is Pablo’s agreement to reorder the patches in the next iteration (v2) for better narrative clarity. Specifically, the dynamic request logic (currently patch 3) will move to the front of the series, allowing the type-specific patches to follow as incremental additions. This reordering is advisory and doesn’t affect functionality, as all patches already compile and pass tests. The series remains narrowly scoped to object type, with other metadata (disk size, delta base, object mode) explicitly excluded as unreliable or context-dependent.
