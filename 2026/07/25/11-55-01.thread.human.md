This GSoC feature series by Pablo Sabater extends `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries, completing the last piece of metadata guaranteed to match between client and server after a fetch. The v1 series is now complete, addressing all review feedback, and a v2 will be posted shortly with patch reordering for clarity—moving the dynamic client request logic to the front—and possibly an optional test for handling malformed server responses.
