This GSoC feature series by Pablo Sabater extends `git cat-file --batch-command` to support the `%(objecttype)` placeholder when querying remote repositories, completing the last piece of metadata guaranteed to match between client and server after a fetch. The five-patch v1 series builds directly on Eric Sunshine’s recently merged remote-object-info work, adding server capability advertisement, client request logic, protocol extensions, and client-side parsing—all narrowly scoped to object type.

The series is now complete and under active review. Chandra Pratap has provided detailed feedback across all patches, identifying a potential out-of-bounds array access in patch 2 (a robustness concern) and suggesting test improvements in patches 1 and 4. The final patch, which unifies the default format string for local and remote queries, received minor documentation wording suggestions and a proposal to retain (and update) an existing test rather than delete it. No fundamental objections have been raised, and the core functionality appears uncontroversial. The series remains under review with no maintainer decision yet.
