Subject: [PATCH] remote.c: plug memory leaks in `rewrites_release()`
Series version: standalone patch
Originating author: Junio C Hamano
Thread type: bugfix

Core problem or goal
Plug memory leaks in the `rewrites_release()` function in `remote.c`, which is responsible for freeing memory associated with URL alias settings (`url.<real>.insteadOf` and `url.<real>.pushInsteadOf`). The current implementation fails to free nested allocations within the `struct rewrites` data structure and makes unnecessary copies of configuration strings.

Current status
Under review; CI confirmation received. The patch is a minimal, focused fix (6 insertions, 3 deletions) that touches only `remote.c`. All CI jobs pass on the `seen` integration branch with this patch applied (excluding the unrelated `tn/packfile-uri-concurrency` topic). Junio has since re-merged the excluded topic and initiated a new CI run, but results are pending.

- Files touched: `remote.c`
- Functions: `rewrites_release()`
- Data structures: `struct rewrites` (tracks URL alias settings)
- Symbols: `url.<real>.insteadOf`, `url.<real>.pushInsteadOf` (configuration keys)
- Leak sources: nested allocations within `struct rewrites`, unnecessary copies of alias URLs
