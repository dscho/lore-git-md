This is the second part of a refactoring series targeting the ongoing `the_repository` removal effort. Tian Yuchen migrates three more global configuration variables (`minimum_abbrev`, `default_abbrev`, and `assume_unchanged`) into the repository-scoped `repo_config_values` structure, along with `pack_size_limit_cfg` from the pack-objects code.

The series is tightly scoped: each patch moves one variable, updates its accessors to take a `struct repository *`, and adds explicit checks for `repo != the_repository` where the calling code already enforces a no-`the_repository` rule (notably in the merge-ort subsystem). The commit messages are clear and the changes are mechanical, following the established pattern of earlier `the_repository` removal patches.

No new behavior is introduced; this is pure refactoring. The patch looks well-crafted, with thorough coverage of the call sites and no obvious omissions. If you follow the `the_repository` removal effort, this is a routine but necessary step.
