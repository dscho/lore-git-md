This is a bugfix patch from Junio C Hamano that plugs memory leaks in Git's remote URL alias handling.

The patch fixes the `rewrites_release()` function in `remote.c` to properly free all allocated memory when cleaning up the in-core data structure that tracks `url.<real>.{insteadOf,pushInsteadOf}` configuration settings. The current code fails to free both the `instead_of` strings and the individual `rewrite` structs themselves. Additionally, the patch stops making unnecessary copies of alias URLs (which are borrowed from configuration callbacks) since they weren't being freed anyway.

The commit message notes these aren't new leaks, but they became more visible due to recent tests added in Emily Shaffer's `en/submodule-insteadof-remote-match` topic. The fix is straightforward and surgical - just six lines changed in one file, with clear reasoning about why each change is needed.

This looks like a well-crafted, low-risk fix that addresses a real (if minor) issue. The patch is self-contained and doesn't appear likely to cause regressions or controversy.
