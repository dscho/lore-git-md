This is a Google Summer of Code (GSoC) feature patch series extending the `git cat-file --batch-command` remote-object-info functionality to support the `%(objecttype)` placeholder. The series builds directly on the recently merged "cat-file: add remote-object-info to batch-command" work (Eric's v21 series, referenced as `Based-on`).

The five patches add end-to-end support for object type queries: the server now advertises the "type" capability, the client dynamically requests all supported object-info options (including type), the protocol is extended to transmit type data, and the client parses and displays it. The final patch unifies the default format string in `cat-file` to avoid duplication. Key files touched are `protocol-caps.c`, `fetch-object-info.c`, `serve.c`, and the man pages for `git-cat-file` and Git protocol v2. The test suite (`t1017` and `t5701`) is updated to cover the new capability.

The motivation is clear: object type is the last piece of metadata that is guaranteed to be identical on client and server after a fetch, making it a natural candidate for remote-object-info. The commit message explicitly rules out other metadata (disk size, delta base, object mode) as unreliable or context-dependent, so this series is scoped narrowly to type. The implementation appears mechanical and follows the established pattern from the predecessor series. CI passed on GitHub.
