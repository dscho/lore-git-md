This is the second patch in Harald Nordgren’s two-patch series refining `git checkout -m` autostash behavior. It implements the advertised fast-path and advice-layout improvements.

The patch updates `merge_working_tree()` to check—before any unpack_trees() call—whether there are tracked local changes (`has_unstaged_changes()` or `has_uncommitted_changes()`). If not, the autostash retry loop is skipped entirely, avoiding a redundant unpack_trees() failure. The new `allow_autostash` parameter (passed from `switch_branches()`) controls this check.

On the advice side, the patch uses the conflict flag returned by `apply_save_autostash_ref()` to print a blank line to stderr immediately before the “Switched to branch” confirmation. This visually separates the autostash conflict message from the branch-switch message, making the output less jarring. The new test in `t/t7201-co.sh` verifies both the fast-path (no retry when no tracked changes exist) and the improved advice layout.
