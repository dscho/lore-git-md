Series is at v4, feature-complete, with all prior review feedback addressed and the architectural refactoring finalized. The refactoring replaces `struct object_info` with a dedicated `struct fetch_object_info_results` that holds only the fields the caller requests (currently size and type), avoiding sentinel values and boolean flags. The design uses a single array of lightweight structs where the caller controls which fields are populated, aligning with the remote-object-info protocol’s transmission of raw strings (e.g., `"blob"`, `"1234"`). Junio and Peff have confirmed that sentinel values like `OBJ_NONE` are unsuitable for fields like `size` and that a separate bit is preferable for signaling unknown objects.
