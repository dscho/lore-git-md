This is a two-patch series refining the behavior of `git checkout -m` when autostash is involved. The series targets a leftover edge case from a previous discussion (linked in the cover letter) about autostash retries and conflict advice clarity.

The first patch teaches the sequencer’s autostash apply logic to explicitly report conflicts when they occur, rather than silently failing. This surfaces the conflict state to the caller so it can decide whether to retry or bail. The second patch updates `git checkout -m` to skip the autostash retry loop if there are no tracked local changes to begin with, and it also tweaks the advice output so the autostash conflict message is visually separated from the subsequent branch-switch confirmation.

Files touched include `sequencer.c`/`sequencer.h` (core autostash plumbing), `builtin/checkout.c` (the retry logic and advice formatting), plus minor adjustments in `builtin/commit.c` and `builtin/merge.c` to accommodate the new return codes. The test suite (`t/t7201-co.sh`) gains a new test case that verifies the no-tracked-changes fast-path and the improved advice layout. The series is based on `master` at commit `9a0c4701dcd5`.
