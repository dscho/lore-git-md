This is a bugfix patch from Junio C Hamano that plugs memory leaks in the remote configuration handling.

The patch fixes the `rewrites_release()` function in `remote.c` to properly free all allocated memory associated with the `struct rewrites` data structure, which tracks URL alias settings like `url.<real>.insteadOf` and `url.<real>.pushInsteadOf`. The current implementation only frees the top-level structure but misses several nested allocations. Additionally, the patch stops making unnecessary copies of configuration strings (the alias URLs) since they are never modified, eliminating another source of leaks.

The commit message notes these leaks are not new but were exposed by recent tests in Emily Shaffer's `en/submodule-insteadof-remote-match` series. The changes are minimal (6 insertions, 3 deletions) and focused on the cleanup function and configuration handling logic. The patch touches only `remote.c` and appears to be a straightforward fix with no behavior changes beyond plugging the leaks.
