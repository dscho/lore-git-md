This is the third patch in Pablo Sabater’s five-patch GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The patch replaces the hard-coded "size" request in `send_object_info_request()` with a loop that dynamically sends every option remaining in the `object_info_options` list. The commit message explains that the list has already been filtered to only include options the server supports, so the loop is safe. The change is minimal (seven lines added, four removed) and touches only `fetch-object-info.c`. It prepares the client to request object type metadata from the server, though the server does not yet advertise the capability (that is handled in patch 1). The patch looks like a clean, mechanical extension of the existing remote-object-info infrastructure.
