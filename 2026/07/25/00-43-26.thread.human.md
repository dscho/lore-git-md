This thread is about a small but important bugfix from Junio C Hamano that plugs memory leaks in Git’s URL alias handling (`url.<real>.insteadOf` and `url.<real>.pushInsteadOf`). The leaks were exposed by Emily Shaffer’s recent submodule work and occur in `rewrites_release()`, which failed to free nested allocations inside the `struct rewrites` data structure.

Junio posted a first version that tried to avoid copying configuration strings, assuming they would persist, but Jeff King (Peff) pointed out that this assumption was unsafe—configurations can be discarded during operations like repository discovery. Junio revised the patch to explicitly copy and free strings, matching the safer pattern used elsewhere in Git. Peff has now reviewed the second version and confirmed it’s correct, clearing the way for integration. All CI runs have passed, and there are no remaining objections or open questions. The patch is ready to move forward.
