This is a test infrastructure patch, part of a four-patch series from Taylor Blau. It extends the `test-tool pack-deltas` helper to add a `--list-deltas` mode that inspects a pack index file and prints each delta object's type (REF_DELTA or OFS_DELTA) along with its base object ID or pack offset. The motivation is to support upcoming tests for a `--no-ref-delta` option in `git pack-objects`; the new mode lets tests distinguish between the two delta types without open-coding a pack parser.

The patch touches `t/helper/test-pack-deltas.c` and updates `t/t5300-pack-object.sh` to exercise the new functionality in two existing test cases. The implementation walks the pack, decodes each object header, and prints the delta information in a simple text format.
