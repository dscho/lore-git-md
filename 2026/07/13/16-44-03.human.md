This is a refactoring patch in Pablo Sabater’s **v11 series** implementing visual root indentation for `git log --graph`. It is the sixth of seven patches and **prepares the codebase for future graph-related configuration options** by extracting the `log.graphcolors` reading logic from `graph_init()` into a new helper function, `graph_read_config()`.

The change is **purely mechanical**: nine lines are added and four removed in `graph.c`, with no behavior change or new edge cases. The new `graph_read_config()` function takes a `struct rev_info *` parameter and is called by `graph_init()`, which remains the public entry point. This refactoring is explicitly motivated as preparation for the next patch (7/7), which introduces the `log.graphIndent` configuration option for the indentation feature.

The patch is **stable and uncontroversial**; it has not changed since its introduction in v7 and is ready for final review. No substantive feedback has been raised on this specific patch, and its inclusion in the series is a straightforward step toward cleaner configuration handling.
