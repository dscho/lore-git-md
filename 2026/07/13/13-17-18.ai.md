This is the first patch in Phillip Wood’s 10-patch v2 series addressing the sequencer’s incorrect copying of notes from dropped commits during rebase. This specific patch restores test coverage for the "apply" backend, which was lost when the default rebase backend switched from "apply" to "merge".

The change is minimal: it replaces the `-m` flag (which forces the merge backend) with `--apply` in a single test in `t3400-rebase.sh`. This ensures the test suite continues to verify that `git rebase --apply` correctly copies notes, complementing the existing test that covers the default (merge) backend. The patch is a pure test maintenance update with no behavior change, serving as a prerequisite for the later patches that introduce the core fix and expand test coverage for edge cases.

The motivation is clear: without this patch, the test suite would lack coverage for the apply backend’s note-copying behavior, leaving a blind spot for regressions in that code path. The patch is well-scoped and uncontroversial, addressing a straightforward gap in test coverage.
