This thread is a two-patch bugfix series from Ted Nyman that fixes race conditions in Git’s HTTP transport when multiple processes fetch the same packfile URI into a shared object database. The patches modify `http.c`, `fetch-pack.c`, and related documentation to ensure packfile URI downloads write to unique temporary files and handle `.keep` file races correctly. Tests for both regressions have been added to the test suite.

The series was initially held up by a message-threading issue Junio C Hamano spotted, which Taylor Blau later resolved by adjusting his Mutt workflow. Jeff King’s recent email adds historical context about patch-sending workflows but doesn’t engage with the technical content of the patches. No substantive technical review has been provided yet, so the series remains under review with no changes since the initial submission. The only open question is whether the fixes themselves will draw scrutiny from reviewers.
