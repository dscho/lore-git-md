This thread is about a two-patch series from Ted Nyman that fixes race conditions in Git’s HTTP transport when multiple processes fetch the same packfile URI. The bugs could corrupt temporary packfiles or cause spurious failures in shared object databases. The patches touch the HTTP transport layer and fetch-pack logic, adding regression tests for concurrent downloads and `.keep` file handling.

The series was initially held up by a message-threading issue—Junio C Hamano noted that the cover letter’s `Message-ID` wasn’t properly chaining the patches, breaking tools like `b4 am`. That’s now resolved: Ted confirmed the corrected `Message-ID`, and Taylor Blau (a co-worker) later explained the root cause—a quirk in his Mutt-based workflow that rewrote headers when resending patches. The procedural blocker is gone, but the patches themselves are still awaiting substantive technical review. No changes were made to the code after the initial submission.
