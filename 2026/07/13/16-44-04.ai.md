This is the **final patch (7/7)** in Pablo Sabater’s **v11 series** implementing **visual root indentation for `git log --graph`**. It adds an **opt-out mechanism** for users who prefer the traditional unindented graph layout, via both a **command-line flag** (`--[no-]graph-indent`) and a **configuration variable** (`log.graphIndent`).

The patch is **mechanically straightforward** and **ready for review**. It introduces two new bit fields in `struct rev_info` (`no_graph_indent` and `graph_indent_set`) to control indentation, updates `graph_read_config()` to read the `log.graphIndent` configuration, and modifies the graph-rendering logic in `graph.c` to respect the opt-out setting. The default remains **indented** (`log.graphIndent=true`), preserving the new behavior unless explicitly disabled. Documentation (`Documentation/config/log.adoc`, `Documentation/rev-list-options.adoc`) and tests (`t4218-log-graph-indentation.sh`) are updated to cover the new options, including edge cases for configuration overrides.

The **only change since v10** is the bit-packing of the two boolean fields in `struct rev_info`, addressing Mirko Faina’s mechanical feedback. This is a **purely internal** improvement with no user-visible impact. The rest of the patch is unchanged from v10, which Mirko reviewed and approved with an LGTM.

The patch **completes the series** and resolves the last remaining usability concern: users who dislike the indentation can now disable it entirely. The implementation is **clean and non-invasive**, touching only the graph-rendering code and configuration plumbing. The three new tests verify the opt-out behavior works as expected, including the interaction between command-line flags and configuration variables.

This patch is **ready for final review** and, if approved, will allow the series to proceed to `next`. No further changes are expected. The only loose end is the **redundant-indentation edge case** (marked NEEDSWORK in v8), which is documented but not addressed in this revision.
