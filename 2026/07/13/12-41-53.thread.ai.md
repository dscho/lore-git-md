Subject: [PATCH] fast-export: align help text with man page and Git conventions
Series version: standalone patch (no series)
Originating author: Christian Couder
Thread type: patch (cleanup, documentation)

Core problem or goal
Align the `git fast-export -h` usage string with the man-page SYNOPSIS and with the standard Git convention for revision arguments. Currently the help text shows `[<rev-list-opts>]` while the man page shows `[<options>] | 'git fast-import'`. The patch unifies both to `[<options>] [<revision-range>] [[--] <path>...]`, matching the pattern used by most other Git commands (e.g., `git log`, `git rev-list`). It also removes `fast-export` from the list of commands that trigger a test failure due to mismatched help vs. documentation.
