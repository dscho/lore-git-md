This is patch 7/9 in v3 of Patrick Steinhardt’s ODB abstraction series. The function is a prerequisite for the "packed" backend’s upcoming support for bitmap-optimized object filtering: it ensures objects are correctly attributed to their source and avoids redundant enumeration when multiple sources are present. The implementation is straightforward, reusing the existing `open_bitmap_for_source()` helper and `load_bitmap()` logic. The patch touches only `pack-bitmap.c` and `pack-bitmap.h`, adding 14 lines with no functional changes to existing behavior. This is a refactoring patch that prepares the bitmap subsystem for the ODB-mediated filtering mechanism introduced later in the series.
