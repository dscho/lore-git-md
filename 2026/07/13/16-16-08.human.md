This is the final patch in Pablo Sabater’s **v10 series** implementing **visual root indentation for `git log --graph`**. The patch adds an **opt-out mechanism** so users who prefer the traditional unindented graph can disable the feature via either a **command-line flag** (`--[no-]graph-indent`) or a **configuration variable** (`log.graphIndent`). The default remains indented.

There is no engagement with the patch’s behavior, edge cases, or design rationale.
