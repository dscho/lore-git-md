Thread identity: patch series introducing `--no-ref-delta` option to `git pack-objects`; second patch in a four-patch series from Taylor Blau.

Core problem or goal: enable `git pack-objects` to produce packs without `REF_DELTA` entries, which reference base objects by full object ID. This is useful for consumers (e.g., `receive-pack`) that want to avoid building an object ID index when retaining the pack. The option preserves `OFS_DELTA` (offset-based deltas) and, when combined with `--no-delta-base-offset`, disables all deltas entirely, skipping delta search.

Current status: under review; this is the second iteration of the series (v2 implied by context, though not explicitly stated in the summary). The patch disables delta reuse and bitmap reuse under `--no-ref-delta` as a conservative measure, with the next patch in the series planning to re-enable reuse in safe cases.
