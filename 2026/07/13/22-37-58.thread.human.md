Ted Nyman sent a patch series to fix race conditions in Git’s HTTP transport when multiple processes concurrently fetch the same packfile URI. The races can corrupt temporary pack files or cause resume requests to fail. The series has two patches: the first modifies the HTTP layer to use unique temporary files for each download, avoiding cross-process coordination but potentially causing redundant downloads; the second makes `.keep` file handling more tolerant of concurrent processes.

Junio C Hamano raised a design concern about the inefficiency of redundant downloads in the first patch, suggesting a coordination mechanism might be preferable. Ted argued that unique tempfiles are simpler and more robust for the immediate bugfix, proposing to defer efficiency improvements to a follow-up. Taylor Blau reviewed the first patch and gave a surface-level approval, noting only a minor cleanup (removing an unnecessary `NULL` assignment) but not engaging with the broader design trade-off. The series is still under review, with the core design question unresolved.
