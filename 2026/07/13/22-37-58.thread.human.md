This thread is a two-patch bugfix series from Ted Nyman addressing race conditions in Git’s HTTP transport when multiple processes concurrently fetch the same packfile URI. The races can corrupt temporary pack files or cause resume requests to fail. The series targets the packfile URI feature, which offloads large packfiles to external storage.

The first patch modifies the HTTP layer to use unique temporary files for each packfile URI download, avoiding cross-process coordination.
