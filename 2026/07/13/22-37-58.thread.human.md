This thread is about Ted Nyman’s v2 patch series fixing race conditions in Git’s HTTP transport when multiple processes fetch the same packfile URI or dumb HTTP pack. The series aims to prevent corruption of temporary pack files while preserving resumable downloads, addressing feedback from the v1 series that abandoning resumability was premature.

The key change in v2 uses deterministic staging paths and `pwrite(2)` to allow concurrent processes to write identical bytes at identical offsets without corrupting the pack file. Junio C Hamano reviewed the first patch and, while still uneasy about the `pwrite` approach ("somehow makes me feel dirty"), did not reject it outright. He approved the documentation clarifications and the long-standing `--index-pack-args` typo fix but suggested splitting the typo fix into a separate preliminary patch to keep the functional changes clean. The Windows/MINGW workaround for file finalization was noted but accepted. No new technical objections were raised, and the series remains on track for further review.

Ted Nyman, Taylor Blau, and Jeff King (Peff) have all engaged with the series, with Peff’s feedback on preserving resumability and improving clarity in Patch 2 directly addressed in v2. The only remaining open question is a minor mechanical cleanup in `release_http_pack_request()`. The series is now considered ready for serious review, with the next step being the suggested patch split for the typo fix.
