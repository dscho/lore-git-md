This is a documentation and usage consistency patch for `git fast-export`.

Christian Couder aligns the command’s help text (`git fast-export -h`) and its man-page SYNOPSIS with the pattern used by most other Git commands. The new form—`[<options>] [<revision-range>] [[--] <path>...]`—explicitly lists the three argument groups that `fast-export` already accepts: its own options, a revision range, and optional paths. The change removes the command from the list of known mismatches in `t/t0450/adoc-help-mismatches`, so CI now passes. The patch is small, mechanical, and clearly motivated by the desire for uniformity across the command set.
