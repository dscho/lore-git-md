This is the **final patch in Phillip Wood’s 10-patch systemic overhaul** of the sequencer’s handling of dropped commits during rebase. It introduces the core behavioral fix: **notes and post-rewrite hooks no longer receive misleading information about commits that are dropped** due to empty changes, fixup sequences, edit commands, or other edge cases (including external merge strategy failures and command execution failures, addressed in earlier patches).

The patch adds `PICK_RESULT_DROPPED` to the `enum pick_result` introduced in patch 9/10 and modifies `pick_one_commit()` to skip `record_in_rewritten()` for dropped commits. This prevents the sequencer from copying notes from dropped commits to the current HEAD, resolving the original bug reported by Uwe Kleine-König. The change also ensures that post-rewrite hooks (e.g., `post-rewrite`) no longer receive incorrect mappings for dropped commits, as verified by the new test in `t5407-post-rewrite-hook.sh`.

A known limitation is documented in the code comment: the "edit" command still erroneously records dropped commits as rewritten when `rebase --continue` is run. This is flagged for a separate fix. The patch also moves the initialization of `drop_commit` to ensure it is set when rewording a fast-forwarded commit, a small but necessary correctness fix.

Test coverage is expanded in two files:
- `t3400-rebase.sh`: verifies that notes are not copied from dropped commits when using the "apply" backend (restored in patch 1/10).
- `t5407-post-rewrite-hook.sh`: confirms that the post-rewrite hook receives accurate mappings for fixups and commits that become empty, including cases where commits are dropped mid-rebase.

The patch is **well-motivated and minimal**, touching only the logic that records rewritten commits. The commit message clearly explains the behavioral change, the edge cases addressed, and the known limitation. Uwe Kleine-König’s `Tested-by` trailer confirms the fix resolves the original regression. This is the culmination of a **substantive, tested-level series** that addresses both the immediate bug and the systemic issues in the rebase machinery.
