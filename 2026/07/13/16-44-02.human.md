This is the fifth patch in Pablo Sabater’s **v11 series** implementing visual root indentation for `git log --graph`. The patch introduces **four-level wrapping** for cascading visual roots, preventing excessive horizontal indentation that could obscure ancestry relationships in filtered views (e.g., `--author`).

The change modifies `graph_update()` to reset the `visual_root_cascade` flag when the indentation depth reaches a multiple of four, forcing the next commit to indent normally if it is not itself a visual root. The indentation calculation in `graph_output_commit_line()` is updated to use modulo arithmetic (`(depth - cascade) % 4 * 2`), ensuring consistent wrapping. The patch includes a new test in `t4218-log-graph-indentation.sh` that verifies the wrap behavior with a ten-commit sequence of orphaned roots, including the ambiguous case where a non-root commit would otherwise align with a wrapped root.

This is a **usability refinement** that resolves a prior objection about symmetry-induced ambiguity in the graph output. The four-level wrap was endorsed by Mirko Faina and Chandra Pratap in earlier revisions, and the implementation is straightforward, touching only `graph.c` and the test suite. The patch is **ready for final review** and has no known issues. If the series lands, this will be a minor but noticeable improvement for users who frequently filter `git log --graph` output.
