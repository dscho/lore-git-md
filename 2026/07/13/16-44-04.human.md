This is the final patch in Pablo Sabater’s **v11 series** implementing **visual root indentation for `git log --graph`**, a user-visible feature that indents commits with excluded parents to clarify ancestry relationships. This patch adds an **opt-out mechanism** via the `--[no-]graph-indent` command-line flag and the `log.graphIndent` configuration variable, addressing feedback from earlier revisions that some users might prefer the original unindented output.

The implementation is straightforward: two new boolean fields (`no_graph_indent` and `graph_indent_set`) are added to `struct rev_info` as bit fields, packing them efficiently to address Mirko Faina’s mechanical feedback from v10. The configuration is read in `graph_read_config()` (introduced in patch 6/7), and the command-line options are parsed in `revision.c`. The default remains **indented** (`log.graphIndent=true`), preserving the new behavior unless explicitly disabled. Documentation is updated in `Documentation/config/log.adoc` and `Documentation/rev-list-options.adoc`, and three new tests in `t4218-log-graph-indentation.sh` verify the opt-out behavior.

The patch is **well-crafted and complete**: it handles configuration precedence (command-line overrides config), includes proper error checking (e.g., `--[no-]graph-indent` requires `--graph`), and integrates cleanly with the rest of the series. The only prior feedback (bit-packing) has been addressed, and the patch has already received an **LGTM from Mirko Faina** in v10. With this addition, the series is now **feature-complete** and ready for final review.
