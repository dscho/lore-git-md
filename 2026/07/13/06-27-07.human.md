This is a brief follow-up in the "What's cooking" thread. Michael Montalbo, the author of the stalled `mm/diff-process-hunks` topic, replies to Junio’s report to say he will send a reroll of the series this week.

The topic introduces a new `diff.<driver>.process` configuration that lets users plug in a long-running external process to decide which lines Git considers changed. The external process supplies raw hunks, while Git itself still handles all output formatting (word diff, color, blame, etc.). The series touches the diff core, xdiff, sub-process API, and userdiff config, and adds a small integration in `git blame` to consult the external process when detecting no-hunk changes. It has been stalled since mid-June; the reroll should address whatever feedback held it up.
