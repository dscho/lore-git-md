Core problem or goal
Add a `no-ref-delta` capability to Git’s pack protocol. The sender (`send-pack`) can be instructed by the receiver (`receive-pack`) to omit `REF_DELTA` entries from the generated pack, simplifying pack processing for receivers that do not want to build an object ID index upfront.
