This is the **third patch in the v10 series** implementing visual root indentation for `git log --graph`. It introduces the **lookahead buffer** infrastructure that the rest of the series depends on.

The patch adds a two-slot lookahead buffer to `struct git_graph` and provides helper functions (`graph_pop_lookahead`, `graph_get_lookahead_room`, `graph_push_lookahead`) to manage it. The buffer is populated by `get_revision()` in `revision.c`, which now pre-fetches up to two commits ahead when a graph is active. This allows the graph renderer to safely inspect future commits without peeking at `rev_info` internals or risking incomplete simplification. The `graph_is_interesting()` function is updated to treat commits in the lookahead buffer as interesting, ensuring they are included in the graph layout.

This is a **pure infrastructure patch** with no user-visible behavior change. It is well-motivated by the architectural challenge of determining visual root status without breaking the revision walk. The implementation is clean and follows the design approved in earlier iterations. The only potential concern is the added complexity in `get_revision()`, but the helper functions keep the logic modular and the commit message clearly explains the purpose. This patch is **ready for final review** and looks like a solid foundation for the visualization logic that follows.
