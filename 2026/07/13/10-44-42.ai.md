This is the final patch in Pablo Sabater’s **v10 series** implementing **visual root indentation for `git log --graph`**. It adds an **opt-out mechanism** for users who prefer the traditional unindented graph layout.

The patch introduces two ways to disable indentation: a **command-line flag** (`--[no-]graph-indent`) and a **configuration variable** (`log.graphIndent`). The default remains **indented** (`log.graphIndent=true`). The implementation is straightforward: the flag and config variable set a `no_graph_indent` field in `struct rev_info`, which the graph renderer checks before applying indentation. The patch also updates the documentation (`Documentation/config/log.adoc` and `Documentation/rev-list-options.adoc`) and adds **three new tests** in `t4218-log-graph-indentation.sh` to verify the opt-out behavior.
