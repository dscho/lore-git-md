This thread is about a small but useful test infrastructure improvement from Taylor Blau. He’s adding a `--list-deltas` mode to the `test-tool pack-deltas` helper so that upcoming tests for a `--no-ref-delta` option in `git pack-objects` can reliably tell whether an object is a REF_DELTA or an OFS_DELTA without having to parse the pack file themselves. The patch itself is a single commit that touches only the test helper and one existing test script; it’s straightforward and hasn’t drawn any review comments yet. If you’re working on pack-objects or delta compression, this will soon give you a handy way to inspect delta types in your test cases.
