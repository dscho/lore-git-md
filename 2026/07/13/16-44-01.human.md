This is the fourth patch in Pablo Sabater’s **v11 series** implementing **visual root indentation for `git log --graph`**, a user-visible feature that indents commits with excluded parents to clarify ancestry relationships in graph output. This patch introduces the **core visualization logic**, relying on the lookahead buffer (added in patch 3/7) to determine whether a commit is a visual root before rendering.

The patch adds a new `is_visual_root` flag to `struct git_graph` and a new `GRAPH_PRE_ROOT` state to print an extra row connecting indented roots to their children. It handles three key cases: visual roots with children (requiring the `GRAPH_PRE_ROOT` state), childless visual roots (rendered directly), and cascading visual roots (where adjacent roots increase indentation depth, but the last root in a sequence is not indented). Merge parents are explicitly excluded from indentation to avoid visual clutter.

The implementation is **well-motivated** and **thoroughly tested**: the new `t4218-log-graph-indentation.sh` test file (514 lines) covers edge cases for single roots, cascading roots, merge parents, boundary commits, and filtering options (`--first-parent`, `--left-right`, `--max-count`, `--grep`/`--author`). The commit message clearly explains the problem (unrelated commits appearing vertically adjacent) and the solution (indentation with lookahead-based detection).

This patch is **ready for final review** and has no known issues. The lookahead buffer architecture was approved by Junio Hamano and Kristofer Karlsson in earlier revisions, and the visualization logic addresses all prior usability concerns. The only remaining work is reconciliation with Kristofer Haugsbakk’s `kk/prio-queue-get-put-fusion` topic, which is deferred to a follow-up. If the series lands, this patch will be the most visible part of the feature.
