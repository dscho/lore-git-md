Thread identity: Bugfix for a race condition in `fetch-pack`'s packfile URI feature (Git protocol v2). Series version: single patch (no versioning). Originating author: Ted Nyman.

Core problem or goal: Fix a race where concurrent fetches can fail even when `index-pack` succeeds, due to `fetch-pack` rejecting the `"pack<TAB><hash>"` response (indicating the `.keep` file already existed) for packs downloaded via packfile URIs. The fix ensures both `"keep"` and `"pack"` responses are accepted, with `.keep` file cleanup only applied to files created by the current process.
