This is the final patch in Pablo Sabater’s **v10 series** implementing **visual root indentation for `git log --graph`**. It adds an **opt-out mechanism** so users can disable the new indentation behavior if they prefer the old style.

The patch introduces two ways to turn off indentation: a command-line flag (`--no-graph-indent`) and a configuration variable (`log.graphIndent`). The flag takes precedence over the config, and both require `--graph` to be active. The default is still indentation on, matching the rest of the series. Documentation is updated in `log.adoc` and `rev-list-options.adoc`, and the new test file (`t4218-log-graph-indentation.sh`) verifies that the opt-out works in all three modes: flag, config, and the default.

This patch directly addresses the last usability concern raised in earlier rounds. It is small, self-contained, and ready for review. If the rest of the series is approved, this one should be too.
