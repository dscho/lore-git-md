This is the first patch in Patrick Steinhardt’s **v2 12-patch series** making Git’s ODB optimizations pluggable. It is a **test infrastructure improvement** that replaces the current brittle `GIT_TRACE2_EVENT`-based checks in `t/t7900-maintenance.sh` with a new `test_maintenance_tasks` helper. The helper parses trace2 region events to directly verify which maintenance tasks (e.g., `commit-graph`, `geometric-repack`) were executed, rather than relying on the exact command-line arguments of spawned Git processes.

The patch is **purely mechanical** and **behavior-preserving**: it changes only how tests assert which tasks ran, not what the code under test does. The new helper is more robust because it decouples test assertions from implementation details (e.g., the exact `git repack --geometric=2` command), making the test suite less likely to break when command-line arguments change. All existing test cases are updated to use the new helper, and the patch leaves some tests using `test_subcommand` where the exact command invocation is still relevant.

This addresses Junio C Hamano’s feedback on the v1 series, which flagged the `GIT_TRACE2_EVENT` checks as fragile. The change is uncontroversial and focused on test reliability, with no impact on user-visible behavior or the broader ODB abstraction effort. The patch is a prerequisite for the rest of the series, which depends on stable test coverage to validate the refactoring of ODB optimization logic.
