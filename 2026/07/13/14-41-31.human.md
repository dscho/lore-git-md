This is the seventh patch in Patrick Steinhardt’s nine-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. The patch introduces `prepare_bitmap_git_for_source()`, a new function that opens a bitmap exclusively for a given object source. This is a prerequisite for the "packed" backend’s upcoming ability to use bitmaps for object filtering, ensuring objects are correctly attributed to their source and avoiding redundant enumeration.

The change is small (14 lines added) and focused: it adds the new function to `pack-bitmap.c` and declares it in `pack-bitmap.h`. The implementation reuses existing helpers (`open_bitmap_for_source()` and `load_bitmap()`) and follows the same error-handling pattern as `prepare_midx_bitmap_git()`. The motivation is clear: without this function, the "packed" backend would risk misattributing objects or re-enumerating the same bitmap across multiple sources.

This patch is uncontroversial and well-motivated. It directly addresses a technical requirement for the ODB filtering mechanism introduced later in the series, and the implementation is straightforward. No review feedback has surfaced on this specific patch, but its role in the series is critical—it enables the backend-specific bitmap handling that the final patch (9/9) will leverage to replace `git cat-file`’s direct backend coupling with ODB-mediated filtering. The patch is ready for integration.
