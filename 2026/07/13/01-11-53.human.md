This is a test infrastructure patch, part of a small series (1/4) from Taylor Blau. It extends the `test-tool pack-deltas` helper to add a `--list-deltas` mode that reports whether each delta in a pack is a `REF_DELTA` or `OFS_DELTA`, along with its base object ID or pack offset. The motivation is to support upcoming tests for a new `--no-ref-delta` option in `git pack-objects`; the commit message is clear and the change is narrowly scoped to that goal.

The patch itself is straightforward: it adds a new option, implements the listing logic by walking the pack index, and updates two existing tests in `t5300-pack-object.sh` to verify that the helper correctly identifies `REF_DELTA` and `OFS_DELTA` entries. The code is clean and the commit message explains why the new capability is needed without over-promising.

There is no controversy here; this is a well-crafted, incremental addition to the test tooling that will make the next patch in the series easier to review. If you care about pack-objects internals or delta encoding, this patch is worth a quick skim; otherwise it can safely be skipped until the feature patch itself lands.
