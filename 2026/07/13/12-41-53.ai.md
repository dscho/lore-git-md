This is a documentation and usage-string cleanup patch for `git fast-export`.

The patch aligns the command’s help output (`git fast-export -h`) with its man-page SYNOPSIS and with the standard Git convention for describing revision arguments. Currently the help text shows `[<rev-list-opts>]` while the man page shows `[<options>] | 'git fast-import'`. The patch changes both to `[<options>] [<revision-range>] [[--] <path>...]`, which matches the pattern used by most other Git commands (e.g., `git log`, `git rev-list`). It also removes `fast-export` from the list of commands that trigger a test failure due to mismatched help vs. documentation.

The files touched are the man page (`Documentation/git-fast-export.adoc`), the usage string in `builtin/fast-export.c`, and the test file `t/t0450/adoc-help-mismatches`. The change is purely textual and does not alter the command’s behavior. CI passed on the author’s branch.
