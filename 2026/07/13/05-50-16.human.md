This is the second patch in Patrick Steinhardt’s RFC v4 series to reorganize Git’s source tree by moving all `libgit.a` components into a new `lib/` directory. The patch is a **pure refactoring**—no functional changes, just a mechanical relocation of roughly 700 files (core subsystems like object handling, refs, diff, merge, and platform compatibility shims) into `lib/` while updating every build-system file (`Makefile`, `meson.build`, `CMakeLists.txt`, `config.mak.uname`) and CI workflow to match.

The commit message restates the trade-offs: the move breaks `git log --follow` history, forces rebases of in-flight topics, and creates merge conflicts for downstream forks, but Patrick argues these are one-time costs that buy permanent improvements in root-directory clutter and clearer library boundaries. The patch also incorporates the Windows build fix from Ramsay Jones that was merged in v4, so the tree builds cleanly on all platforms.
