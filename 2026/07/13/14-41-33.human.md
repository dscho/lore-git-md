This is the final patch in Patrick Steinhardt’s nine-patch series introducing object filters to `odb_for_each_object()`. It completes the refactoring of `git cat-file --batch-all-objects` by replacing its direct, backend-specific bitmap handling with the new ODB-mediated filtering mechanism.

The patch removes 69 lines of intricate, backend-aware logic from `builtin/cat-file.c` and replaces them with 7 lines that delegate filtering to the ODB layer via `odb_for_each_object_ext()`. The old code manually managed bitmaps, iterated over packs, and reached into the "files" source internals; the new code simply passes the object filter to the ODB layer and lets the backend optimize the enumeration. This eliminates tight coupling between the command and the "packed" backend, a key goal of the ODB abstraction effort.

Three helper functions (`batch_one_object_packed`, `batch_one_object_bitmapped`, and the old bitmap-handling branch in `batch_each_object`) are removed, along with the now-unused `pack-bitmap.h` include. The change is purely internal: no user-visible behavior changes are expected, and the diffstat (7 insertions, 69 deletions) reflects the simplification.

Junio C Hamano reviewed the equivalent patch in v1 and called it "very nice," praising the clean diffstat. All substantive review feedback has been addressed in earlier patches, and this patch itself has no open questions. The series is now ready for integration, pending Junio’s final review.
