Thread identity: Bugfix series for packfile URI download race conditions in Git's HTTP transport. Series version: v6 (final). Originating author: Ted Nyman. Thread type: patch series (bugfix), now complete and ready for final review.

Core problem or goal: Fix race conditions in Git's HTTP transport when multiple processes concurrently fetch the same packfile URI or dumb HTTP pack into a single object database, preventing corruption while preserving resumable downloads. The series provides a unified solution for both packfile URIs and dumb HTTP using deterministic staging paths and read-write mode without append, split into six focused commits for clarity and bisectability.
