This is the second patch in Tian Yuchen’s v11 series migrating global configuration variables into `struct repo_config_values`. It moves the `excludes_file` global (which tracks the path to the global ignore file) into the repository-scoped structure and replaces direct access with a proper getter, `repo_excludes_file()`.

The patch is a clean refactoring with no behavior change: the lazy-loading fallback to the XDG default path (`$XDG_CONFIG_HOME/git/ignore`) is now handled inside the getter rather than in `setup_standard_excludes()`. Memory management is correct—`excludes_file` is freed via the new `repo_config_values_clear()` destructor introduced in patch 1/10. The commit message is clear and the diff is minimal, touching only `dir.c`, `environment.c`, and `environment.h`.

This patch is part of the ongoing `the_repository` removal effort and builds directly on the infrastructure added in patch 1/10. It is technically sound, addresses all prior feedback, and is ready for integration. Reviewers who care about ignore-file handling or repository-scoped configuration should note the new getter; everyone else can treat this as a routine libification step.
