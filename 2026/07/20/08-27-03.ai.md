This is the fourth patch in Harald Nordgren’s `git history squash` series (v10, 4/5). It refactors the sequencer’s squash-message helpers into reusable functions and moves the `todo_item_flags` enum to `sequencer.h` so other commands can produce the same template format as `git rebase -i --autosquash`.

The patch extracts three static helpers from `sequencer.c` and exposes them in `sequencer.h`: `add_squash_combination_header` (the “This is a combination of N commits” banner), `add_squash_message_header` (the “This is the 1st/Nth commit message” or “will be skipped” header), and `squash_subject_comment_len` (determines whether to comment out a `fixup!`/`squash!`/`amend!` subject). It also makes the `TODO_REPLACE_FIXUP_MSG` flag public so callers can distinguish `amend!` from plain `fixup!` when reading the output of `todo_list_rearrange_squash()`.

No behavior changes; this is pure code motion. The patch is ready to merge and enables the next patch (5/5) to give `git history squash --reedit-message` the same template as `git rebase -i --autosquash`.
