This is the first patch in a two-part series fixing push tracking after remote renames. It’s a mechanical refactoring that passes a `struct repository *` parameter to the `tracking_for_push_dest()` helper in `remote.c`. The parameter is marked `UNUSED` for now, but the change prepares the code for the next patch, which will use the repository to look up remotes by URL. The patch touches only `remote.c` and is part of the ongoing `the_repository` removal effort. No behavior changes; it’s purely plumbing.
