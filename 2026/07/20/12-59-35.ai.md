This is a **contributor housekeeping** reply from the maintainer regarding the `contrib/fast-import/import-zips.py` script.

Junio C Hamano responds to Chris Packham’s inquiry about updating the 13-year-old Python 2 script to Python 3. He declines to take the changes into `contrib/` in `git.git`, preferring instead to remove unmaintained scripts from the directory entirely. His position is that `contrib/` should not serve as a repository for code that the project itself cannot or will not maintain, especially when a maintained fork exists elsewhere. He suggests replacing the script with a pointer to Chris’s GitHub repository as a more sustainable alternative, avoiding the need for the project to act as a gatekeeper for code it lacks the expertise or interest to support.

The response leaves no ambiguity about the project’s stance on this specific script but does not address the broader question of AI-assisted contributions. The thread is now effectively closed unless Chris or another contributor proposes a patch to remove the script or add a pointer to the fork.
