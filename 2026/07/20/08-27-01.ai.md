This is the second patch in Harald Nordgren’s `git history squash` series (v10, 2/5). It adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. This plumbing change enables the `--reedit-message` feature introduced later in the series.

The patch is a straightforward refactoring with no user-visible behavior change. It modifies three existing callers (`commit_tree_with_edited_message`, `cmd_history_fixup`, and `split_commit`) to pass NULL, preserving their current behavior. The change is minimal and focused, touching only the function signature and a few lines of logic to conditionally use the template. This is a necessary preparatory step for the `--reedit-message` implementation in patch 5/5, which will supply a constructed template to combine messages from multiple commits. The patch is ready to merge and carries no controversy or unresolved feedback.
