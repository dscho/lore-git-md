This is a documentation patch, part of Jean-Noël Avila’s ongoing effort to convert Git man pages to the new AsciiDoc synopsis style. This email is the author’s reply to Junio C Hamano’s surface-level review comment on the fourth patch in the v1 series, which converted `git request-pull`’s man page.

Jean-Noël acknowledges the inconsistency in the number of dashes used to delimit AsciiDoc listing blocks (five, six, five, five in this patch; nine in an earlier one) and cites the Asciidoctor specification, which requires exactly four dashes for delimited listing blocks. He proposes adopting a uniform rule of four dashes and will update the series accordingly in the reroll. The change is purely stylistic and does not affect the rendered output or functionality of the man pages.

The files touched remain `Documentation/git-request-pull.adoc` and, by reference, `Documentation/git-imap-send.adoc`. No new symbols, behavior changes, or on-disk format changes are introduced. The patch is still part of the larger synopsis-style conversion effort, and the reroll will address both this issue and the earlier inconsistency in backtick usage for conceptual terms in `git format-patch`.
