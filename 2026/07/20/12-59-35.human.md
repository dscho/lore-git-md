This is a **contributor housekeeping** discussion about the future of the `contrib/fast-import/import-zips.py` script.

Junio C Hamano responds to Chris Packham’s offer to submit a Python 3 update for the 13-year-old script. Junio declines to take on maintenance responsibility for this part of `contrib/`, explaining that he prefers to remove unmaintained scripts rather than act as a gatekeeper for code he neither uses nor understands. He suggests replacing the script with a pointer to a maintained fork—such as Chris’s GitHub repository—if the project still wants to provide users with a reference. No technical objections to the Python 3 changes themselves are raised; the decision is purely procedural.
