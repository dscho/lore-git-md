This is the second patch in Harald Nordgren’s five-part series introducing `git history squash`. It is a pure plumbing change that adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. This enables the `--reedit-message` feature in the final patch of the series.

The patch is small (16 lines changed) and mechanical: it adds the parameter, updates the function’s logic to prefer the template when provided, and passes NULL from the existing `fixup` and `split` callers to maintain their current behavior. There are no user-visible changes, and the commit message clearly states the motivation—allowing a caller to seed the commit message from more than a single commit.

This is a well-crafted refactoring that prepares the ground for the `--reedit-message` feature without introducing any risk. The series as a whole is functionally complete and ready for integration, with Junio’s “Will replace” sign-off on v7 and all feedback addressed in v9 and v10.
