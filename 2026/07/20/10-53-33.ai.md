This is the second patch in the v8 series refactoring `trust_executable_bit` and `has_symlinks` as part of the `the_repository` removal effort. It updates the performance-critical `ce_mode_from_stat()` helper to accept a `struct repository *` parameter, preparing it for repository-scoped configuration access in later patches.

The patch modifies the function signature and all call sites (in `apply.c`, `builtin/update-index.c`, `diff-lib.c`, and `read-cache.c`) to pass the appropriate repository instance. The boolean expressions inside `ce_mode_from_stat()` are reordered to evaluate `S_ISREG(mode)` first, optimizing for the common case where the filesystem supports symlinks and executable bits. A clarifying comment is added to document the function’s purpose and filesystem limitation handling.

The `UNUSED` annotation for the `repo` parameter (introduced in v7 to resolve a build-breaking issue) remains in place here but will be removed in patch 3/4 once the parameter is actively used by the new getter functions. This two-phase approach keeps the function `static inline` in `read-cache.h` while avoiding compiler warnings during the transition.

The patch is a mechanical refactoring with no behavioral changes, touching five files and 20 lines. It lays the groundwork for the repository-scoped configuration migration in patches 3/4 and 4/4, where the `repo` parameter will be used to access the migrated flags. The reordering of boolean expressions and the added documentation improve clarity without affecting functionality. The series remains uncontroversial and on track for integration.
