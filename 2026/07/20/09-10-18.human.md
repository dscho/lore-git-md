This is the first patch in the v3 series adding the `--reset-when-found` option to `git bisect`. It prepares the plumbing for the feature by making `bisect_reset()` optionally quiet.

The patch adds a `quiet` parameter to `bisect_reset()` that, when set, passes `--quiet` to the underlying `git checkout` command, suppressing its usual progress and branch-status output. All existing callers pass `0` (false), so the behavior remains unchanged for now. The change is mechanical: the function signature is updated, the `checkout` command is split into parts to insert `--quiet` conditionally, and the call sites are adjusted to pass the new parameter.

This is a refactoring patch with no user-visible effect. It exists solely to support the next patch, which will use the quiet parameter when automatically resetting after a bisect completes. The implementation is straightforward and uncontroversial, touching only `builtin/bisect.c` with no cross-subsystem impact. The patch is well-motivated by the series' goal and ready for review.
