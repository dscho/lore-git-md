This is a **contributor housekeeping** note about a third-party tool in Git's `contrib/` area.

Chris Packham noticed that `contrib/fast-import/import-zips.py` — a script that turns a collection of zip files into a Git repository — had not been touched in over a decade and was still Python 2. He modernized it to Python 3 with some AI-assisted help and published the result in his own GitHub repository. The new version is GPL-2.0 licensed (matching Git’s `COPYING` file), but Chris is unsure whether the original script had an explicit license or whether AI-generated changes would be acceptable for inclusion in Git’s `contrib/` directory. He offers to rework the changes into a patch series if there is interest, but for now the updated script lives only on his GitHub page.
