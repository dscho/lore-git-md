This is the tenth iteration of Harald Nordgren’s `git history squash` series, a new subcommand that folds a commit range into its oldest commit while preserving descendant history. The series is now functionally complete and addresses the last minor feedback from v9: **reflog message accuracy**, **rev-list option sanitization**, and **documentation clarity**.

The key changes in v10 are mechanical but important for robustness. The reflog message now records the full revision expression (e.g., `squash: updating start..HEAD ^keep` instead of truncating to the first argument), preserving the user’s intent. The rev-list option sanitization now preserves the `boundary` walk invariant, ensuring the command behaves predictably even when users pass `--boundary` or similar options. The documentation for `amend!` and `--reedit-message` has been tightened to avoid ambiguity, explicitly stating that `amend!` messages replace the target’s message only when targeting the oldest commit in the range.

The series remains structurally unchanged from v9. Patch 1/5 refactors `first_parent_tree_oid()` to centralize logic; Patch 2/5 adds a `message_template` parameter to `commit_tree_ext()`; Patch 3/5 implements the core `squash` subcommand with range validation, merge handling, and ref-handling; Patch 4/5 shares sequencer helpers for squash-message construction; and Patch 5/5 implements `--reedit-message` with autosquash-style grouping. The test suite continues to cover edge cases like interior merges, ref handling, and `amend!` message selection.

This version is ready for integration. Junio’s "Will replace" sign-off on v7 and the resolution of all technical feedback in v9 and v10 signal that the series is on track for the next release. The only unresolved discussion—whether `--reedit-message` should be the default—is a minor usability tweak and does not block merging. The architectural vision of using `git history squash` as a faster backend for `git rebase --autosquash` remains a project-level aspiration, with this series as a foundational piece.
