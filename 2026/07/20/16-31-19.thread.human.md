This thread began when Chris Packham updated the 13-year-old `contrib/fast-import/import-zips.py` script from Python 2 to Python 3, using AI assistance, and asked whether the project would accept the changes back into `contrib/`. The maintainer, Junio C Hamano, has now replied that he would rather remove unmaintained scripts from `contrib/` entirely than take on responsibility for maintaining them. He suggested replacing the script with a pointer to Chris’s GitHub repository, where the updated version can live without requiring the project to act as a gatekeeper. The thread is effectively closed unless someone proposes a patch to remove the script or add the pointer. The broader question of AI-assisted contributions was not addressed.
