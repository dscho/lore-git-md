This is the cover letter for a seven-patch series introducing object filters to `odb_for_each_object()`. The goal is to make `git cat-file --batch-all-objects` work with pluggable object databases by removing its dependency on internal details of the packed backend, particularly for handling bitmapped objects.

The series touches the object database (ODB) subsystem, the pack-bitmap code, and the `git cat-file` built-in. Patch 1 improves object lookup in the packed backend during enumeration, patch 2 marks an object filter as `const`, and patches 3-5 refactor the pack-bitmap code to support aborting iteration and iterating over object sources. Patch 6 introduces the object filters to `odb_for_each_object()`, and patch 7 updates `git cat-file` to use these filters.

The motivation is clear: enabling pluggable ODBs requires abstracting away backend-specific logic, and this series is a step toward that goal. The changes are focused and appear well-scoped, though the pack-bitmap refactoring (patches 3-5) looks like the most complex part. The series is built on the current development cycle and includes Patrick Steinhardt’s recent ODB work, suggesting it’s up-to-date with ongoing efforts.

If you care about pluggable ODBs or the internals of object enumeration, this series is worth following. The refactoring seems thoughtful, but the pack-bitmap changes might draw scrutiny from reviewers familiar with that subsystem.
