This is the third patch in Patrick Steinhardt’s seven-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. It prepares the pack-bitmap subsystem for integration into the generic ODB enumeration infrastructure by making `for_each_bitmapped_object()` respect early-abort semantics.

The patch modifies `pack-bitmap.c` and its callers to propagate non-zero return values from the `show_reach` callback up through the call stack. Previously, `for_each_bitmapped_object()` ignored callback return values, which would become a latent bug once the function is exposed via `odb_for_each_object()`. The change affects two existing callers (`builtin/pack-objects.c` and `builtin/rev-list.c`), which are updated to return 0 instead of 1 to maintain their current behavior. The patch also refactors `show_objects_for_type()` to return an integer and adds a loop over object types in `for_each_bitmapped_object()` to handle early aborts cleanly.

Files touched: `pack-bitmap.c`, `pack-bitmap.h`, `builtin/pack-objects.c`, and `builtin/rev-list.c`. Key symbols: `for_each_bitmapped_object()`, `show_objects_for_type()`, `show_reach`. The patch is mechanical and well-scoped, addressing a clear technical debt that would otherwise block the ODB abstraction goals. No on-disk format changes or new test failures are introduced. This is a prerequisite for patch 7/7, which lifts bitmapped object iteration into the packed backend.
