Core problem or goal
Extend Git’s existing `post-worktree-remove` hook so it fires not only when worktrees are explicitly removed (`git worktree remove`) but also when they are pruned (`git worktree prune`). The change ensures the hook runs once per pruned worktree (including duplicates) and receives the worktree path when available, or an empty string when the path cannot be determined.

- Hook signature: unchanged; the hook receives the worktree path (or empty string) as its sole argument
