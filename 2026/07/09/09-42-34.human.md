This is the seventh patch in Johannes Schindelin’s eleven-patch bugfix series (`js/coverity-fixes-v2`) that plugs NULL-dereference holes found by Coverity. This one targets the `replay` command: when the user passes a non-commit object (tree, blob, or tag that doesn’t peel to a commit) as the `--onto` argument, `peel_committish()` now explicitly checks the return value of `repo_peel_to_type()` and dies with a clear error message instead of silently returning NULL and risking a crash later. The change is a single NULL guard plus a descriptive `die()` call, and it touches only `replay.c`. Like the rest of the series, it’s a defensive programming fix with no new behavior or on-disk format changes, so existing tests should be enough to verify it doesn’t break normal operation.
