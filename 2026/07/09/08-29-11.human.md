This is part of the ongoing `the_repository` removal effort. Patrick Steinhardt sends a seven-patch series that refactors the refs subsystem and adjacent worktree code to stop using the global `the_repository` variable. The patches are mechanical but touch 25 files, including core commands like `git branch`, `git checkout`, and `git worktree`.

The motivation is straightforward: these changes were originally part of a discarded attempt to make refdb initialization eager, but they stand alone as incremental progress toward eliminating the global repository state. The series also includes a small detour into `worktree.c` to pass repository parameters explicitly, which was necessary to avoid initialization-order problems in the earlier eager-refdb work.

There are minor merge conflicts with the current `seen` branch, but Patrick provides a two-line resolution in the cover letter. The patches themselves look clean and well-scoped; each one addresses a single function or file and updates callers accordingly. No new behavior is introduced, so this is pure refactoring with no user-visible impact.
