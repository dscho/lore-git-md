This is the cover letter for a seven-patch series introducing object filters to `odb_for_each_object()`. The goal is to enable `git cat-file --batch-all-objects` to work with pluggable object databases by removing its dependency on internal details of the "packed" backend, particularly for handling bitmapped objects efficiently.

The series touches the object database (ODB) subsystem, specifically the packed backend and pack-bitmap code. Key changes include improving object lookup during enumeration, making object filters `const`, allowing early abortion of bitmapped object iteration, and introducing a new function to open bitmaps for a single source. The final patch modifies `builtin/cat-file.c` to use the new filtering mechanism via the object database, replacing direct backend-specific logic.

This is part of the ongoing ODB abstraction effort led by Patrick Steinhardt, which aims to restructure Git’s object storage layer to support alternative backends. The series is built on the current development cycle (Git 2.56) with Patrick’s `ps/odb-drop-whence` topic merged in. Files modified include `builtin/cat-file.c`, `pack-bitmap.c`, `odb/source-packed.c`, and headers defining the ODB interface.

The patch set appears well-structured, with a clear progression from low-level backend improvements to user-facing changes. The commit messages and code changes suggest thorough attention to edge cases, particularly around bitmap handling and iteration control. This is likely to be of interest to contributors working on ODB backends, performance optimizations, or pluggable storage systems.
