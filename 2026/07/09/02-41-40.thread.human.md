This thread introduces a new Git configuration feature, `includeIf worktree:<pattern>`, allowing conditional inclusion of config files based on the working tree's path. The series, now at version 7, is authored by Chen Linxuan and consists of three patches: a preparatory refactoring, the core implementation, and this final patch adding test coverage and documentation.

The feature addresses a gap in multi-worktree setups by enabling path-based config inclusion that respects symlinks, similar to the existing `gitdir:` behavior. The implementation is clean, reusing existing helpers and adding thorough test coverage for edge cases like symlinked paths, case sensitivity, and bare repositories. Documentation includes clear usage examples and comparisons with related features like `extensions.worktreeConfig`.

Key reviewers Patrick Steinhardt and Junio C Hamano provided feedback on earlier versions, which has been addressed in this iteration. The series appears ready for serious review, with no outstanding technical objections or open questions. If accepted, this would provide a useful tool for users managing multiple worktrees with different configuration needs.
