This is the third patch in Johannes Schindelin’s 12-patch series widening size fields in Git’s delta and pack machinery to `size_t` for 64-bit Windows correctness. It targets the delta-cache accounting trio in `builtin/pack-objects.c`: the global counters `delta_cache_size` and `max_delta_cache_size`, and the helper function `delta_cacheable()` that guards cache admission. All three are currently `unsigned long`, which is 32-bit on 64-bit Windows, risking silent wrap when summing many large cached deltas. The patch widens them to `size_t`, matching the `size_t` return type of `DELTA_SIZE()` that already feeds into these counters. The change is internally consistent: the arithmetic operations remain safe because the incoming values are already `size_t`, and the sole caller (`try_delta()`) still passes `unsigned long` parameters, which safely promote to `size_t`. This patch is a prerequisite for removing the `cast_size_t_to_ulong()` shims in `try_delta()` once the delta-creation functions are widened later in the series. The diff is confined to four lines in a single file, making it a small, mechanical type-widening step with no behavior or on-disk format changes.
