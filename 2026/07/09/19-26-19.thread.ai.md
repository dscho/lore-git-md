Core problem or goal
Replace the subprocess call to `git apply` in the `git add -e` (interactive edit) command with a direct invocation of Git’s internal `apply_all_patches()` API to eliminate fork overhead, keep the operation in-process, and improve code clarity.

Current status

A new test in `t/t3702-add-edit.sh` explicitly verifies subdirectory operation. All 58 tests in `t3700-add.sh` and the expanded `t3702` (now 5 tests) pass. The patch is now blocked only on final review confirmation of the subdirectory fix.
