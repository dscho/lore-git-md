This is the fourth patch in Johannes Schindelin’s 12-patch series widening size fields in Git’s delta and pack machinery to `size_t` for 64-bit Windows compatibility. The patch fixes a silent truncation in `free_unpacked()`: the function sums two `size_t` values (`sizeof_delta_index()` and `SIZE(n->entry)`) but returns an `unsigned long`, which is only 32 bits on Windows. The change is mechanical—just widening the return type and the local `freed_mem` variable to `size_t`—and touches only `builtin/pack-objects.c`. The caller (`find_deltas()`) still uses `unsigned long` for its own accounting, so the truncation persists there, but this patch removes one layer of it. The fix is uncontroversial and clearly motivated by real-world Windows issues.
