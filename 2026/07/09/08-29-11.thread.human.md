This thread is Patrick Steinhardt’s eight-patch series removing implicit uses of the global `the_repository` variable from Git’s refs subsystem and worktree code. The series is part of the long-running effort to make repository handling explicit throughout Git. So far, six patches have been posted and reviewed without controversy; the seventh, just arrived, mechanically updates the last remaining callsites in built-in commands (`branch.c`, `builtin/branch.c`, `builtin/check-ref-format.c`, `builtin/checkout.c`, `builtin/merge.c`, `builtin/worktree.c`) and `refs.c`, replacing `the_repository` with explicit `struct repository *` parameters in function signatures and callers. The only behavioral change was an en-passant fix for a latent bug in the packed-refs backend where `core.packedRefsTimeout` settings were incorrectly shared across repositories. The series is under active review, with no objections raised and no open questions; minor merge conflicts with `seen` are documented and resolvable. If the final patch follows the same pattern, the series should land cleanly in the current cycle.
