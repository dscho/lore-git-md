This thread is about Patrick Steinhardt’s eight-patch series to remove more uses of Git’s global `the_repository` variable, focusing on the refs subsystem and worktree code. The goal is to make repository handling explicit by passing `struct repository *` parameters instead of relying on the global. A latent bug in the packed-refs backend—where `core.packedRefsTimeout` was incorrectly shared across repositories—was fixed early in the series, and a behavioral regression in the timeout initialization (introducing a 0 ms default instead of 1000 ms) was caught by Junio and resolved in v2.

The series is now in Junio’s `seen` and `jch` integration branches and is expected to graduate to `master` in the next cycle. It touches 25 files, including the packed and files ref backends, worktree internals, and built-in commands like `branch` and `checkout`. The changes are mechanical but thorough, updating function signatures and call sites to use explicit repository parameters. Junio’s review was substantive, catching the timeout regression, while Toon Claes and Christian Couder provided surface-level approvals, signaling the series is clear to proceed. No open questions remain, and the integration conflicts with the `seen` branch have been resolved. The series is part of the ongoing effort to remove `the_repository`, with no on-disk format changes or new test failures.
