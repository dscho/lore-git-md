This is a review comment on the first patch of Patrick Steinhardt’s `the_repository` removal series. Junio C Hamano identifies a subtle initialization issue: in the new per-repository struct fields, `timeout_value` is zero-initialized by `xcalloc()`, whereas the old static variable defaulted to 1000 ms. When the config key is unset, the new code will use 0 ms, which is almost certainly not the intended behavior. The fix is straightforward—explicitly initialize `timeout_value` to 1000 in `packed_ref_store_init()`—but the oversight is a real bug that would regress timeout handling. The review is substantive: it catches a behavioral change that slipped through the refactoring.
