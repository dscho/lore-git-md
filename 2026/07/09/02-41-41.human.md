This is the first patch in a three-part feature series introducing `includeIf worktree:<pattern>` support to Git’s config system. The patch refactors the existing `include_by_gitdir()` function into a more generic `include_by_path()` helper, decoupling it from the `git_dir` field in `struct config_options`. The change is purely preparatory: it does not alter behavior but enables the upcoming `worktree:` condition to reuse the same path-matching logic with a different path (the worktree root instead of the gitdir). The diff is confined to `config.c` and is mechanical, replacing internal references to `opts->git_dir` with an explicit `path` parameter. The commit message clearly explains the motivation and the refactoring’s scope. This is a clean, well-justified refactoring that sets the stage for the feature without introducing risk.
