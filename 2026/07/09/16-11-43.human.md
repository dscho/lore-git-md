This is part seven of Tian Yuchen’s nine-patch refactoring series (v9) that moves more global configuration variables into `struct repo_config_values`. This patch migrates the `push_default` enum—used by `git push` to decide what to push when no refspec is given—from a global variable into the per-repository configuration structure.

The patch keeps the enum definition in `environment.h` (instead of its more logical home in `remote.h`) to avoid a circular-dependency tangle (`remote.h → hash.h → repository.h → environment.h`). A `NEEDSWORK` comment flags this as a future cleanup item. The configuration parser in `environment.c` is updated to store the value in the repository-specific structure, and callers in `builtin/push.c` and `remote.c` now read it via `repo_config_values(the_repository)->push_default`. No user-visible behavior changes; the patch is purely preparatory for libification.
