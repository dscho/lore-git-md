This is the eighth patch in Tian Yuchen’s nine-patch v9 series migrating global configuration variables into `struct repo_config_values`. It moves the `autorebase` enum (which controls whether new branches default to auto-rebasing) from a global variable into the repository-specific structure.

The patch is a straightforward refactoring: the `enum rebase_setup_type` definition is relocated higher in `environment.h` so it can be referenced by `struct repo_config_values`, the global `autorebase` variable is removed, and all callers now read the value via `repo_config_values(the_repository)->autorebase`. The default state `AUTOREBASE_NEVER` is initialized in `repo_config_values_init()`, and configuration parsing in `git_default_branch_config()` writes directly to the repository’s instance. No user-visible behavior changes; the patch is purely preparatory for libification.

The change is clean, CI-tested, and follows the established pattern from earlier patches in the series. The only minor housekeeping note is the relocation of the enum definition, which is necessary to avoid circular includes but could eventually be moved to a more logical header (e.g., `branch.h`) in a future cleanup. This patch is ready for `next` alongside the rest of the series.
