Subject: [PATCH 0/8] refs: remove more uses of `the_repository`
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series (refactoring)

Core problem or goal
Eliminate implicit uses of the global `the_repository` variable in the refs subsystem and related worktree code, continuing the long-running effort to make repository handling explicit throughout Git. The series touches 25 files, systematically replacing `the_repository` with explicit `struct repository *` parameters in function signatures and call sites. A latent bug in the packed-refs backend is fixed en passant: the `core.packedRefsTimeout` configuration was previously stored in function-static variables, causing only the first repository's setting to be used; this is now per-repository via `struct packed_ref_store` fields.

Current status
Under review; v1 posted 2026-05-15. No prior versions of this exact series exist, though the patches were extracted from an earlier, abandoned attempt to make refdb initialization eager. The series is based on the start of the Git 2.56 cycle with Patrick’s `ps/refs-writing-subcommands` topic already merged in. Minor conflicts with `seen` are documented and resolvable with the provided diff.
