This thread is about Patrick Steinhardt’s seven-patch series introducing object filters to `odb_for_each_object()`, a key step in Git’s ongoing ODB abstraction effort. The goal is to let `git cat-file --batch-all-objects` work with pluggable object databases by removing its tight coupling to the packed backend’s internals, while also fixing inefficiencies in object lookups during enumeration.

The series is under active review, with v1 posted and no prior versions. Junio C Hamano has praised the final patch (7/7) for its clean diffstat and requested only a clearer commit message to better explain the problem being solved. Justin Tobler reviewed four of the seven patches, raising questions about edge cases and style, but all technical concerns have now been resolved. The only remaining open question is a design choice in patch 6/7: whether backends should be required to support a subset of object filters or if the current design (allowing backends to ignore filters) is intentional. Patrick has accepted Justin’s style suggestions for patch 4/7, leaving only cosmetic changes before the series is ready for Junio’s integration.

Key changes include refactoring bitmap opening logic to prioritize local bitmaps over multi-pack index bitmaps, improving object lookup efficiency, and enabling early termination of bitmapped object iteration. The series touches the ODB, packed backend, and pack-bitmap subsystems, with no expected end-user behavioral changes or on-disk format modifications. Once Patrick posts a v2 with the minor tweaks to patch 4 and addresses the design question in patch 6, the series is likely to be accepted.
