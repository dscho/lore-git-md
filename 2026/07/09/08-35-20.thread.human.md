This thread is about Patrick Steinhardt’s nine-patch series (v4) that introduces object filters to `odb_for_each_object()`, a key step in Git’s ongoing ODB abstraction effort. The goal is to let `git cat-file --batch-all-objects` work with pluggable object databases by removing its dependency on internal details of the packed backend, while also fixing an inefficiency in object lookups during enumeration.

The series has now cleared review. Junio C Hamano, the maintainer, has given his sign-off, calling the collaboration "great" and signaling the series is ready for integration. All prior feedback has been addressed: Jeff King’s cleanup patch (removing an unused return value), Taylor Blau’s performance clarification, and the design resolution for traversal API consistency. The only remaining loose end is a minor follow-up from Taylor Blau to split the callback type for bitmapped object iteration, but this is planned as a separate series and doesn’t block the current work.

Key changes include making object filters `const`, renaming variables for clarity, improving object lookup efficiency, and refactoring `git cat-file` to use ODB-mediated filtering. The final patch (9/9) replaces 69 lines of backend-specific logic with just 7 lines of ODB API calls, a change Junio praised in an earlier review. The series is built on Git 2.56 with Patrick’s `ps/odb-drop-whence` topic merged, and all participants—Justin Tobler, Taylor Blau, Jeff King, and Toon Claes—have confirmed the latest version looks good. Expect this to land in `next` soon.
