This version of the series (v4) is a minor update to Patrick Steinhardt’s nine-patch effort to make `git cat-file --batch-all-objects` work with pluggable object databases. The goal is to remove its dependency on internal details of the packed backend, a key step in the ongoing ODB abstraction work. The series also fixes an inefficiency in `odb_for_each_object()` where object lookups during enumeration redundantly traverse indices, risking incorrect pack selection and performance degradation.

All substantive review feedback has been addressed in prior versions. v4 is a cosmetic-only update, fixing trivial commit message typos in patches 7 and 8 (function name mismatches) noted by Toon Claes. The series remains technically unchanged from v3, which incorporated Jeff King’s cleanup patch (removing an unused `int` return from `add_object_entry()`), Patrick’s `const` filter parameter patch, a mechanical rename of bitmap-opening functions, and the new `prepare_bitmap_git_for_source()` function. Junio C Hamano reviewed the final patch in v1, calling it “very nice” for its 7-insertion/69-deletion diffstat that replaces backend-specific logic with ODB-mediated filtering. Justin Tobler, Taylor Blau, Jeff King, and Toon Claes reviewed earlier versions, raising questions about design and performance—all resolved in v3 and v4. Taylor’s latest reply to the v3 cover letter (“Thanks, this version looks good to me”) and Jeff’s similar acknowledgment signal no remaining objections.

The series is now ready for Junio’s final review and integration. The only open item is a minor nit about mixing unrelated changes in patch 1, but this doesn’t block progress. A follow-up from Taylor Blau is planned to split the callback type used by `for_each_bitmapped_object()` from `show_reachable_fn`, introducing an abortable callback type for bitmapped object iteration while aligning the non-bitmap path with `void`-returning callbacks. Jeff King endorsed this as a “nice cleanup,” though its safety will need confirmation during implementation. The series is built on Git 2.56 with Patrick’s `ps/odb-drop-whence` topic merged and touches the ODB, packed backend, pack-bitmap, and `git cat-file`/`pack-objects`/`rev-list` subsystems. No on-disk format changes are introduced.
