This is a refactoring patch in the ODB abstraction series. It marks the object filter parameter in `for_each_bitmapped_object()` and related functions as `const` to reflect that the filter is never modified during iteration. The change is mechanical: three function signatures in `pack-bitmap.c` and one in `pack-bitmap.h` are updated, with no behavior change.

The patch is the second in Patrick Steinhardt’s seven-patch series introducing object filters to `odb_for_each_object()`. It prepares the bitmap subsystem for the later patches that will use these filters to mediate object enumeration through the ODB interface rather than directly through the packed backend. The commit message is minimal but sufficient for the change; the broader motivation is explained in the cover letter. This is a clean, uncontroversial step in the ODB abstraction effort.
