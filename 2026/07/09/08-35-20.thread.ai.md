Subject: [PATCH 0/7] Introduce object filters to odb_for_each_object()
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series

Core problem or goal
Enable `git cat-file --batch-all-objects` to work with pluggable object databases by removing its dependency on internal details of the "packed" backend, specifically for efficient handling of bitmapped objects. This is a step in the ongoing ODB abstraction effort to restructure Git’s object storage layer to support alternative backends. The series also addresses an inefficiency in `odb_for_each_object()` where object lookups during enumeration redundantly traverse indices, risking incorrect pack selection and degrading performance.

Current status
Under review; v1 posted. No prior versions. Built on Git 2.56 with Patrick’s `ps/odb-drop-whence` topic merged.

Key technical details
- Subsystems: object database (ODB), packed backend, pack-bitmap
- Files: `builtin/cat-file.c`, `pack-bitmap.c`, `pack-bitmap.h`, `odb/source-packed.c`, ODB interface headers, `builtin/pack-objects.c`, `builtin/rev-list.c`
- New/renamed symbols: object filters made `const` in `for_each_bitmapped_object()` and related functions; `store` variable renamed to `source` in `odb/source-packed.c` for clarity; new function `open_bitmap_for_source()` to open bitmaps for a single source; reversed loop order in `open_pack_bitmap_1()` to iterate over sources first, then attempt to load a bitmap for each source (previously: search all sources for a multi-pack index bitmap, then all sources for a packfile bitmap); altered bitmap precedence—local bitmaps now take precedence over multi-pack index bitmaps in alternates; improved object lookup during enumeration; early abortion of bitmapped object iteration via non-zero return value propagation in `for_each_bitmapped_object()` and `show_objects_for_type()`; callers in `builtin/pack-objects.c` and `builtin/rev-list.c` updated to return 0 instead of 1 to preserve existing behavior
- Behavior: replaces direct backend-specific logic in `cat-file` with ODB-mediated filtering; eliminates redundant index traversals in `odb_for_each_object()` by using already-available index data for object lookups; enables early termination of bitmapped object iteration
- On-disk format: no changes
