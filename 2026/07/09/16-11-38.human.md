This is part two of Tian Yuchen’s nine-patch refactoring series (v9) that continues the libification effort by moving global configuration variables into `struct repo_config_values`. Patch 2/9 migrates the `excludes_file` global—a dynamically allocated string holding the path to the global ignore file—into the per-repository configuration structure.

The patch introduces a proper getter, `repo_excludes_file()`, that encapsulates the lazy-loading fallback to the XDG default path (`$XDG_CONFIG_HOME/git/ignore`). Memory management is handled via the newly added `repo_config_values_clear()` destructor, which frees the heap-allocated string during repository teardown. The change is mechanical and does not alter user-visible behavior; it simply relocates the variable and updates the single caller in `dir.c` to use the getter instead of the global.

This patch is a re-split of work already merged in the prior `excludes_file` series but is included here for clarity and to establish the memory-management pattern that the rest of the series follows. The commit message is clear and the diff is minimal, touching only `dir.c`, `environment.c`, and `environment.h`. No open questions or regressions remain for this specific patch.
