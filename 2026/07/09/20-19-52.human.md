This is the third patch in Patrick Steinhardt’s seven-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. The patch enables early termination of bitmapped object iteration by making `for_each_bitmapped_object()` respect non-zero return values from its callback, a prerequisite for exposing this logic via the generic ODB interface.

Justin Tobler’s review is substantive but narrowly focused. He confirms the patch’s goal is sound and the implementation is correct, but raises curiosity about the historical purpose of the return values in `builtin/pack-objects.c` and `builtin/rev-list.c` (both previously returned 1, now return 0). These were likely vestigial or intended to signal object creation, but since the return values were ignored, the change is safe and aligns the code with the new early-abort semantics. No technical concerns are raised; the patch is ready to advance once Patrick clarifies the historical context or confirms the values were indeed unused. The diff is small (25 insertions, 13 deletions) and mechanical, touching only `pack-bitmap.c`, its header, and two built-in commands.
