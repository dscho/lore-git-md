This is the final patch in Johannes Schindelin’s eleven-patch bugfix series (`js/coverity-fixes-v2`) that plugs NULL-dereference holes identified by Coverity. It targets the shallow subsystem, where `write_one_shallow()` could crash when printing a verbose message about removing a graft entry whose commit object is missing from the object store. The fix is a one-line change: instead of dereferencing the potentially-NULL commit pointer `c` to get the OID, the code now uses the OID from the graft entry itself, which is always valid. The patch is minimal, well-explained, and uncontroversial; it completes the series without introducing new behavior or tests.
