This is the seventh patch in Johannes Schindelin’s eleven-patch Coverity-driven bugfix series (`js/coverity-fixes-v2`). It plugs a NULL-dereference hole in the `replay` subsystem: when `git replay --onto <object>` is given a non-commit (tree, blob, or tag that does not peel to a commit), `peel_committish()` silently returns NULL, which would later be dereferenced. The patch adds an explicit NULL check and calls `die()` with a clear error message instead. The change is confined to `replay.c`, touches only the `peel_committish()` helper, and does not alter any on-disk format or user-visible behavior beyond the new error message. No new tests are included, but the fix is narrow enough that existing replay tests should continue to pass.
