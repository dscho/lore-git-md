This twelve-patch bugfix series by Johannes Schindelin (Dscho) addresses NULL-dereference vulnerabilities identified by Coverity across eleven files in Git’s codebase. The fixes target edge cases in diff, remote, reftable, mailsplit, bisect, replay, revision, pack-bitmap, and shallow subsystems, along with a latent bug in `oid_to_hex()`’s static buffer handling. The series has evolved through two iterations, with all feedback from Junio C Hamano incorporated in the latest version (`v2`).

The patches add defensive guards or early checks to prevent crashes from dereferencing NULL pointers or invalid file descriptors. For example, the latest patch (now included in the series) fixes a NULL-dereference in `reftable/stack.c` where a partial initialization failure could lead to passing a NULL filename to `open()`. Other fixes include handling NULL commits in bisect functions, guarding against missing base MIDX bitmaps, and replacing `oid_to_hex()`’s static buffer with a stack-allocated alternative to avoid clobbering. The changes are purely defensive, with no user-visible behavior changes beyond error messages for edge cases.

Junio has reviewed and approved most of the series, including the first seven patches, while the remaining patches address his feedback—such as adding a regression test for `revision.c` and clarifying edge cases in `bisect_start()`. The series is now uncontroversial and ready for integration, with no open questions or loose ends. Taylor Blau was CC’d for incremental MIDX expertise but has not yet reviewed the relevant patch. The fixes are low-risk, well-motivated, and align with Git’s defensive programming goals.
