This thread is a bugfix series by Johannes Schindelin (Dscho) addressing eleven NULL-dereference vulnerabilities identified by Coverity across various Git subsystems. The patches add defensive checks to prevent crashes in edge cases like repository corruption, failed initializations, or missing objects, without altering normal behavior. The series has been under review and was generally uncontroversial until Junio C Hamano's latest review of the final patch.

Junio's review of the shallow.c fix uncovered a latent bug in the same code path: the use of `oid_to_hex()`'s rotating static buffer could cause the hex string to be clobbered before it's used in verbose logging. He proposed replacing it with a stack-allocated buffer and `oid_to_hex_r()` to ensure correctness. This is a substantive improvement that doesn't change the patch's defensive purpose but eliminates a subtle correctness risk. The series will likely need a v3 update to incorporate this fix before merging. No other objections or open questions have been raised.
