This is a small Rust-related bugfix series from brian m. carlson, addressing memory issues in Git’s Rust hash code that interfaces with the C hashing layer.

The series follows up on Jeff King’s recent leak fixes in the C hashing code. Here, brian fixes two problems: the Rust code now initializes the hash context before cloning it, and properly discards the context when done. Both patches touch only `src/hash.rs`, adding 11 lines and removing 2. The commit messages are brief but clear about the memory-safety motivation.

No controversy is evident; these are straightforward correctness fixes in the Rust portion of the codebase. If you care about memory hygiene in the Rust/C boundary, this series is worth a quick look.
