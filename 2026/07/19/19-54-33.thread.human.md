This thread is about converting the man pages for four Git commands (`git imap-send`, `git format-patch`, `git send-email`, and `git request-pull`) to the project’s new AsciiDoc synopsis style. The changes are purely presentational, with no impact on behavior or functionality. Jean-Noël Avila posted the initial version (v1) of the series, which is now under review.

Junio C Hamano identified two minor stylistic inconsistencies in the v1 patches: one regarding backtick usage for conceptual terms in `git format-patch` and another about the number of dashes used to delimit AsciiDoc listing blocks in `git request-pull`. Jean-Noël has acknowledged both issues and committed to addressing them in a reroll. The second issue was clarified in this latest email, where Jean-Noël cited the Asciidoctor specification, which requires exactly four dashes for delimited listing blocks, and proposed adopting this rule uniformly.

The series is now awaiting the reroll, which will resolve both stylistic inconsistencies. No technical concerns have been raised, and the changes remain documentation-only. This effort is part of Jean-Noël’s broader project to standardize the AsciiDoc synopsis style across all Git man pages.
