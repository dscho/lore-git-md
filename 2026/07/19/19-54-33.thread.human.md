This thread is about a documentation-only patch series from Jean-Noël Avila that converts the man pages for `git imap-send`, `git format-patch`, `git send-email`, and `git request-pull` to Git’s new AsciiDoc synopsis style. The changes are purely presentational—no behavior or CLI interface is altered.

The first version of the series was posted and reviewed by Junio C Hamano, who identified two minor stylistic inconsistencies: backtick usage for conceptual terms in `git format-patch` and the number of dashes used to delimit AsciiDoc listing blocks in `git request-pull`. Jean-Noël acknowledged both issues and committed to a reroll adopting a uniform four-dash rule (per Asciidoctor specification) and correcting the backtick usage. Junio accepted this plan, so the reroll is expected shortly and will address only these stylistic fixes. The series remains under review but is otherwise uncontroversial and part of the ongoing effort to standardize Git’s man page markup.
