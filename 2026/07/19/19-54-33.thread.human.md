This thread is a documentation-only patch series from Jean-Noël Avila converting the man pages for four Git commands (`git imap-send`, `git format-patch`, `git send-email`, and `git request-pull`) to the project’s new AsciiDoc synopsis style. The series is now complete with the fourth patch, which updates `git request-pull` in the same mechanical way as the earlier patches—replacing the old `[verse]` block with the new `[synopsis]` block and adjusting formatting for consistency.

The changes are purely presentational, with no impact on behavior, option semantics, or CLI interfaces. All four patches have been posted as part of v1, and the series is now awaiting review for consistency with prior conversions and for any accidental markup errors. No substantive feedback has been received yet, and there are no open technical questions or objections at this stage. This effort is part of the larger ongoing project to standardize Git’s documentation formatting, led by Jean-Noël Avila.
