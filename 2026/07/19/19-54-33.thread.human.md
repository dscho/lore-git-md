This thread is about Jean-Noël Avila’s patch series converting the man pages for four Git commands (`git imap-send`, `git format-patch`, `git send-email`, and `git request-pull`) to the project’s new AsciiDoc synopsis style. The changes are purely presentational, with no impact on behavior or functionality.

The series is now complete at version 1 and under initial review. Junio C Hamano has raised two minor stylistic points: an inconsistency in backtick-quoting within the `git format-patch` man page and, in the latest email, a variation in the number of dashes used to delimit AsciiDoc code blocks in the `git request-pull` examples. Neither issue affects the rendered output or correctness of the documentation. No other feedback has been received yet.

The work is part of a larger, ongoing effort to standardize the formatting of Git’s man pages. Earlier batches have already converted more commonly used commands, and this series focuses on less-frequently used ones. The series remains under review, with no technical objections raised so far.
