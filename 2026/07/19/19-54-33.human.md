This is a documentation patch series, part of the ongoing effort to convert all Git man pages to a consistent AsciiDoc synopsis style. Jean-Noël Avila sends the fourth batch in this campaign, this time tackling four less frequently used commands: `git imap-send`, `git format-patch`, `git send-email`, and `git request-pull`.

The series touches seven files, flipping the synopsis and option blocks from the old ad-hoc markup to the new standardized format. The diffstat shows a near-even swap of lines (292 added, 281 removed), so the changes are largely mechanical. No new behavior is introduced; this is purely about presentation.

The cover letter notes that these commands are “less common,” so the patches are bundled into a single PR rather than sent as micro-updates. The base commit is current (08621c32), and the series is already available as a GitGitGadget pull request for anyone who wants to preview the rendered output.

If you care about man-page consistency or are a downstream packager who wants to avoid merge conflicts in the Documentation/ directory, this series is worth a quick skim. Otherwise, it’s safe to ignore—no code paths are altered, and the end-user experience remains unchanged.
