This is Junio’s biweekly "What’s cooking in git.git" report for July 2026, summarizing the state of 60+ in-flight topics across the integration branches. It is the authoritative snapshot of what is queued, what graduated, and what stalled, aimed at contributors who need to know where their patches stand or what to review next.

The report is organized into four sections: New Topics (just queued in ‘seen’), Graduated to ‘master’ (topics that reached the main branch since the last report), Stalled (topics that have not seen activity for weeks and may be dropped), and Cooking (topics in ‘next’ or ‘seen’ that are actively being reviewed or revised).

Notable graduations include a batch of Coverity fixes (js/coverity-fixes, js/coverity-fixes-null-safety), Windows credential helper fixes (js/wincred-fixes), and a long-awaited ANSI SGR sideband fix (mm/sideband-ansi-sgr-colon-fix). The test suite also saw a major modernization push: expensive tests are now skipped on resource-constrained platforms, and a new ‘greplint’ linter enforces the use of the ‘test_grep’ helper (ps/t-fixes-for-git-test-long, mm/test-grep-lint).

On the performance front, ‘git status’ now avoids quadratic insertion when enumerating untracked files (sc/wt-status-avoid-quadratic-insertion), and the merge-base computation can terminate early when one side’s commits are exhausted (kk/merge-base-exhaustion). The reftable backend received hardening fixes for corrupted tables (ps/reftable-hardening), and the commit-graph’s topo-level slab is now propagated to all layers of a split chain (kk/commit-graph-topo-levels-fix).

Several large refactoring efforts are in flight. The object database housekeeping logic is being made pluggable (ps/odb-pluggable-housekeeping), the ref and worktree subsystems are being weaned off the global ‘the_repository’ variable (ps/refs-wo-the-repository, ps/copy-wo-the-repository), and repository discovery is being split into a clean two-phase process (ps/setup-split-discovery-and-setup). The experimental ‘git history’ command gained a ‘squash’ subcommand to fold a range of commits (hn/history-squash), and ‘git replay’ can now linearize history (tc/replay-linearize).

New user-facing features include ‘git bisect --auto-reset’ (hn/bisect-auto-reset), ‘git branch --delete-merged’ (hn/branch-delete-merged), and ‘git fetch --submodule-errors’ (pz/fetch-submodule-errors-config). The ‘gitweb’ frontend now correctly shortens hashes even when the index line carries a trailing file mode (tl/gitweb-shorten-hashes-with-modes), and ‘git repo info’ exposes more repository paths (kj/repo-info-more-path-keys).

The report also lists a handful of stalled topics that may be dropped if no new activity appears, including a long-awaited documentation update for ‘git interpret-trailers’ (kh/doc-trailers) and a rebase fix for symref aliases (sn/rebase-update-refs-symrefs).

Overall, the tree is in good shape: the fourth batch of topics has already graduated to ‘master’, and the ‘next’ branch is cooking a mix of performance improvements, refactorings, and new features. Contributors should focus their review efforts on the “Needs review” topics in the Cooking section, particularly those touching the object database, refs, and rebase/sequencer logic.
