This is a completion script enhancement for `git send-email`. The patch adds filesystem path completion to the existing revision completion, so that users can tab-complete patch filenames (e.g., `0001-*.patch`) alongside commit hashes. The commit message demonstrates the problem with a concrete example: typing `git send-email 0<Tab>` in a directory containing `0001-bitmap-drop-bitmap-next-set-region.patch` currently expands to an unrelated 40-hex ref instead of the patch file. The fix introduces a new helper `__gitcomp_file_append()` that appends filesystem candidates to the existing completion list, preserving the existing revision completion logic. A regression test verifies that both patch files and 40-hex refs are offered when they share a prefix. The change is confined to `contrib/completion/git-completion.bash` and the test suite (`t/t9902-completion.sh`).
