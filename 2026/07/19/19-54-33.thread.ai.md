Core problem or goal
Convert the man pages for four Git commands (`git imap-send`, `git format-patch`, `git send-email`, `git request-pull`) to the project’s new AsciiDoc synopsis style. The changes are purely presentational: no behavior, option semantics, or CLI interface is altered.

Junio C Hamano identified two minor stylistic inconsistencies in v1: (1) backtick usage for conceptual terms in `git format-patch` ("base commit", "prerequisite patch" to remain in plain quotes; constant strings `base-commit:`, `prerequisite-patch-id:` to be backtick-quoted) and (2) non-uniform dash count in AsciiDoc delimited listing blocks (resolved to four dashes per Asciidoctor specification). Jean-Noël Avila has acknowledged both and committed to a reroll. The reroll is now imminent and will adopt the uniform four-dash rule and correct backtick usage. The series remains under review pending the reroll.
