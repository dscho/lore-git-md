This is Junio's "What's cooking in git.git" report for July 2026 (#08), summarizing the current state of integration branches and in-flight topics. The report is a snapshot of Junio's integration tree, showing which topics are in `seen`, `next`, or have graduated to `master`, along with their review status and any open discussion points.

Key technical details for follow-up:
- **Graduated to `master`**: Several topics have been merged, including fixes for UTF-8 precomposition on macOS (`ih/precompose-flex-array`), hash algorithm leak fixes (`jk/hash-algo-leak-fixes`), Coverity fixes (`js/coverity-fixes`), and test suite optimizations (`ps/t-fixes-for-git-test-long`). The `wincred` credential helper also received fixes for OAuth token handling (`js/wincred-fixes`).
- **New topics needing review**:
  - `tl/gitweb-shorten-hashes-with-modes`: Fixes object ID shortening in gitweb's commitdiff view when index lines have trailing file modes.
  - `kj/repo-info-more-path-keys`: Extends `git repo info` with more path keys (e.g., `path.git-prefix`, `path.grafts`).
  - `sk/userdiff-swift`: Adds userdiff patterns for Swift.
  - `ps/odb-move-loose-object-writing`: Refactors loose object writing logic into the loose ODB backend.
  - `pw/rebase-fixup-fixes`: Fixes bugs in `git rebase` handling of skipped `fixup`/`squash` commands.
  - `tc/last-modified-bloom`: Optimizes `git last-modified` using Bloom filters (expecting a reroll due to feedback).
  - `hn/bisect-auto-reset`: Adds `--auto-reset` to `git bisect` to automatically reset after completion.
- **Stalled topics**: `kh/doc-trailers` (documentation updates for `git interpret-trailers`) and `sn/rebase-update-refs-symrefs` (symref handling in `git rebase --update-refs`) are stalled, awaiting rerolls.
- **Performance/optimization topics**:
  - `sc/wt-status-avoid-quadratic-insertion`: Optimizes `git status` by avoiding quadratic insertion for untracked paths.
  - `tb/send-pack-no-ref-delta`: Teaches `git send-pack` to honor the `no-ref-delta` capability.
  - `kk/merge-base-exhaustion`: Optimizes merge-base computation by early termination when one side's commits are exhausted.
- **Refactoring/cleanup**:
  - `ps/copy-wo-the-repository` and `ps/refspec-wo-the-repository`: Remove dependencies on `the_repository` global in `copy.c` and `refspec.c`.
  - `rs/tempfile-wo-the-repository`: Refactors tempfile/lockfile APIs to avoid `the_repository`.
  - `ps/refs-wo-the-repository`: Refactors ref subsystem to pass repository pointers explicitly.
- **Experimental features**:
  - `hn/history-squash`: Adds a `squash` subcommand to the experimental `git history` command to fold commit ranges.
  - `ps/cat-file-remote-object-info`: Adds `remote-object-info` to `git cat-file --batch-command` for querying object metadata from remote servers.
- **Controversial/blocked topics**:
  - `ps/libgit-in-subdir`: Moves `libgit.a` sources into a `lib/` directory but was ejected due to merge conflicts.
  - `mm/diff-process-hunks`: Introduces `diff.<driver>.process` for external hunk providers but conflicts with `mm/line-log-limited-ops`.

Notable points of contention or discussion:
- `tc/last-modified-bloom` received feedback from Jeff King about Bloom filter implementation details, requiring a reroll.
- `ps/cat-file-remote-object-info` introduces a new protocol v2 feature (`object-info`) for querying object metadata without downloading objects, which may require server-side support.
- `hn/branch-delete-merged` adds a `--delete-merged` option to `git branch`, which could be controversial due to its potential for accidental data loss.

The report also highlights several topics that are "Waiting for response" from authors, indicating areas where discussion has stalled or feedback is needed. The `seen` branch contains many topics that are still under active review, while `next` holds topics considered stable enough for wider testing.
