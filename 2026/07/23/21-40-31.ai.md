This is the second patch in the v3 series fixing a bug in `git mv` where it emits misleading errors when the destination directory does not exist. The patch adds an early existence check for the destination directory (and its intermediate components) during the checking phase, enabling `--dry-run` to detect these failures before they reach the `rename(2)` syscall.

The implementation uses `stat()` to check the destination's leading directory, aligning with `rename(2)`'s behavior by following symlinks: a symlink to a directory is accepted, while a symlink to a file is rejected. If the directory is missing or a path component is not a directory, the patch reuses the existing "destination directory does not exist" message for ENOENT/ENOTDIR errors, and introduces a new "destination is not a directory" message for non-directory components. Other `stat()` errors fall through to `rename(2)`, preserving existing error reporting.

The patch touches `builtin/mv.c` and adds comprehensive test coverage in `t/t7001-mv.sh`, including cases for missing directories, non-directory path components, symlinks (both to files and directories), and `--dry-run` detection. The test suite now explicitly verifies that symlinks to directories are accepted while symlinks to files are rejected, and that intermediate path components are validated.

This is a well-motivated, user-facing fix with thorough test coverage and clear commit message. The implementation addresses all substantive feedback from Junio C Hamano, including switching from `lstat()` to `stat()` and explicitly handling non-directory destinations. The only acknowledged limitation is a TOCTOU race (the directory could disappear between the `stat()` check and `rename(2)`), which is considered "the best we can do" for now. The patch introduces one new translatable string ("destination is not a directory") but reuses existing messages where possible, minimizing l10n impact.

The series appears ready for final review, with no remaining technical objections. Key details: `builtin/mv.c`, `t/t7001-mv.sh`, `--dry-run`, error messages "destination directory does not exist" and "destination is not a directory".
