This is a brief follow-up in the `git repack --drop-filtered` RFC thread. The author (Siddharth Shrimali) acknowledges Junio’s **blocking review feedback** on patch 1/7: the current validation for `--drop-filtered`’s incompatibility with `--write-bitmap-index` (`-b`) happens too late in the control flow, after `write_bitmaps` may have been set by either the command line or configuration. This makes it impossible to distinguish between a user explicitly requesting bitmaps (which should be rejected) and bitmaps enabled by default (which should be silently disabled). The author agrees the check must be restructured in v2 to handle these cases separately.

No new implementation is proposed yet, but the response confirms the issue is understood and will be addressed before the next iteration. The rest of the series (patches 2–7) remains unchanged for now, though v2 will also incorporate **safety guards** (merge/rebase/cherry-pick checks and index validation) and **API reorganization** as previously scoped. The thread is still in design iteration; no integration branch has been assigned.
