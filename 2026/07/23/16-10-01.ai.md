This is a maintainer follow-up in the ongoing `git clone --revision` segfault thread. Junio retracts his earlier suggestion that the fix might belong in `guess_remote_head()`: after further reflection he confirms that a `struct ref` with a NULL `.peer_ref` is legitimate when the fetch does not store the result in any remote-tracking ref. The fix therefore stays in `update_remote_refs()` as a one-line NULL check before dereferencing `remote_head_points_at->peer_ref->name`. The only remaining action item is a regression test, which the author has not yet provided. The patch itself is now conceptually approved; the thread is waiting on test coverage.
