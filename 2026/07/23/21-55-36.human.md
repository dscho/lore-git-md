This is a brief follow-up to Junio’s "What’s cooking" report about Patrick Steinhardt’s `ps/cat-file-remote-object-info` series. The patch set, which adds a `remote-object-info` batch-command to `git cat-file` for fetching object metadata (like size) from a remote server without downloading the object, is now effectively ready for integration.

Karthik Nayak reviewed the series and gave it a thumbs-up, noting only two minor nits that Pablo Sabater (the reply’s author) considers too small to warrant a reroll. Unless new issues surface, the series looks good to proceed. It remains marked "Needs review" in Junio’s report, but this reply suggests it is now unblocked.
