This is a documentation patch, the first in Jean-Noël Avila’s four-patch v2 series converting the man pages for `git imap-send`, `git format-patch`, `git send-email`, and `git request-pull` to the project’s new AsciiDoc synopsis style. The series is part of the ongoing effort to standardize all Git documentation on a consistent markup format.

The patch mechanically updates `git-imap-send.adoc` and `Documentation/config/imap.adoc`, replacing the old `[verse]` block with a `[synopsis]` block, backtick-quoting all option terms and config keys, and switching AsciiDoc listing fences from four dashes to the project-standard four. No behavior, option semantics, or CLI interface is altered—only the presentation layer.

The diff is small (22 lines changed across two files) and uncontroversial. The two stylistic issues Junio C Hamano raised in v1—backtick usage and fence length—are already resolved in this reroll, so the patch is ready for final review. Given the author’s track record on this conversion effort, it looks likely to graduate to `next` once reviews are complete.
