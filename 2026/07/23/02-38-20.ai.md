This is Junio’s "What’s cooking" report for July 2026 (#10), summarizing the state of Git’s integration branches.

The report lists 11 topics that graduated to `master` in the seventh batch of the cycle. Highlights include: Christian Couder’s `fast-export` synopsis cleanup; Toon Claes’s `includeIf` conditions that key off the worktree path; Patrick Steinhardt’s ODB-transaction conversion of `receive-pack`; Patrick’s Bloom-filter acceleration for `odb_for_each_object()`; and Phillip Wood’s rebase fix that stops recording dropped commits as rewritten (so their notes no longer leak to unrelated commits).

New topics still under review:
- Hugo Santos’s `hs/rebase-continue-edit` adds `--[no-]edit` to `rebase --continue` and a `rebase.noEdit` config knob.
- Toon Nyman’s `tn/stash-avoid-sparse-index-expansion` skips sparse-index expansion when pathspecs are wholly in-cone, plus a bounds-safety fix in the pathspec helper.
- Elijah Newren’s `en/submodule-insteadof-remote-match` makes submodule remote matching respect `url.*.insteadOf` aliases.
- Taylor Blau’s `tb/send-pack-no-ref-delta` teaches `send-pack` to honor the `no-ref-delta` capability.
- Toon Nyman’s `tn/packfile-uri-concurrency` prevents concurrent appends to partial packs during packfile-URI downloads.
- Junio’s own `jc/exclude-first-parent-seen` fixes `--exclude-first-parent-only` when the first parent is already SEEN.

The “Cooking” section shows 20+ topics in `next` or awaiting review. Notable items:
- Patrick Steinhardt’s `ps/odb-move-loose-object-writing` moves loose-object writing logic into the loose backend, a step toward pluggable ODBs.
- Phillip Wood’s `pw/rebase-fixup-fixes` corrects two bugs in rebase’s handling of skipped fixup/squash commands.
- Han-Wen Nienhuys’s `hn/bisect-reset-when-found` adds `--reset-when-found` to jump back after bisect succeeds.
- Han-Wen’s `hn/history-squash` extends the experimental `git history` command with a `squash` subcommand to fold a range.
- Taylor Yao’s `ty/migrate-trust-executable-bit` migrates `core.trustExecutableBit` into the per-repo config structure.
- Patrick Steinhardt’s `ps/cat-file-remote-object-info` adds a `remote-object-info` batch-command that fetches object metadata (size) from a remote server without downloading the object itself.

Stalled topics include Khaled’s doc trailers series and Jörg’s config-lock timeout patch, both awaiting rerolls.
