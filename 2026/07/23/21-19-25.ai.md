This is the third patch in Jean-Noël Avila’s v2 documentation series converting the `git send-email` man page and its associated config documentation (`config/sendemail.adoc`) to the project’s new AsciiDoc synopsis style. The patch is purely presentational, touching only markup formatting in two files: `Documentation/git-send-email.adoc` and `Documentation/config/sendemail.adoc`.

The changes follow the established conversion pattern: replacing `[verse]` with `[synopsis]` in the SYNOPSIS block, removing single-quote formatting from the command name, backtick-quoting all option terms (e.g., `--annotate` becomes `` `--annotate` ``), converting placeholders to `_<placeholder>_` form, and updating prose references to commands and tools (e.g., `mbox(5)` → `` `mbox`(5) ``). The config documentation is similarly updated, with all configuration key terms now consistently backtick-quoted (e.g., `sendemail.identity` → `` `sendemail.identity` ``).

No behavior, option semantics, or CLI interface is altered. The patch is part of the ongoing “Documentation synopsis-style conversion” effort, and this reroll (v2) addresses the two stylistic issues Junio C Hamano identified in v1: backtick usage in conceptual vs. literal terms and uniform four-dash fences in AsciiDoc delimited blocks. The diffstat for this patch alone is balanced (127 insertions, 127 deletions), reflecting the mechanical nature of the conversion.
