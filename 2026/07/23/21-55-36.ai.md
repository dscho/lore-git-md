This is a brief follow-up to Junio’s "What’s cooking" report about Patrick Steinhardt’s `ps/cat-file-remote-object-info` series. Pablo Sabater reports that Karthik Nayak reviewed the 13-patch series and found it ready, noting only two minor nits that do not warrant a reroll. The series adds a `remote-object-info` batch-command to `git cat-file` that lets clients fetch object metadata (currently just size) from a remote server via protocol v2 without downloading the object itself. The client dynamically filters format placeholders based on the server’s advertised capabilities, returning empty strings for unsupported fields. Pablo’s message signals that the topic is now effectively Ack’d and can proceed unless new issues surface.
