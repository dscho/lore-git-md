This thread fixes a segmentation fault in `git clone --revision=<ref>` when used with servers like Azure DevOps that advertise more refs than the client requested under protocol v0. The crash occurs because the code dereferences a NULL pointer in `update_remote_refs()`; the fix adds a simple NULL check to prevent this.

Adrian Friedli reported the bug, provided a reproduction case, and submitted the one-line fix along with a regression test. Junio Hamano reviewed the patch, confirmed the fix location, and requested the test, which Adrian added. Junio has now given his final approval, praising the expanded commit message that clarifies the protocol v0-specific nature of the issue and the root cause. The patch is ready to merge, with no further changes or discussion expected.
