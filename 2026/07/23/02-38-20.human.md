This is Junio’s biweekly “What’s cooking in git.git” report for July 2026, summarizing the state of the integration branches. The digest below highlights what has graduated to `master`, what is newly cooking, and what remains stalled or under review.

---

The seventh batch of topics for the upcoming release has graduated to `master`. Among the highlights: `git fast-export` and `git fast-import` now have standardized usage strings and SYNOPSIS sections; `git submodule update` regains the `-i` shorthand for `--init`; `git receive-pack` switches to ODB transactions, making it backend-agnostic; `git rev-list --no-walk` fixes a pathspec-filtering regression; and `git cat-file --batch-all-objects` now uses the generic `odb_for_each_object()` interface with object filters, allowing backends to optimize traversals with reachability bitmaps.

---

New topics in this cycle include:

- **hs/rebase-continue-edit** teaches `git rebase --continue` the `--[no-]edit` option and a `rebase.noEdit` configuration to skip the editor after conflict resolution.
- **tn/stash-avoid-sparse-index-expansion** optimizes `git stash push` by skipping sparse-index expansion for pathspecs wholly inside the cone, and fixes a potential out-of-bounds read in the expansion check.
- **en/submodule-insteadof-remote-match** corrects submodule remote-matching logic to resolve `url.*.insteadOf` aliases before comparing URLs.
- **td/fsmonitor-darwin-cookie-flush** flushes pending FSEvents on macOS before waiting for the cookie file, avoiding premature timeouts on busy systems.
- **jc/exclude-first-parent-seen** fixes `--exclude-first-parent-only` traversals to stop after the first parent even when it has already been marked SEEN.

All of these are marked “Needs review” except **tn/stash-avoid-sparse-index-expansion**, which Junio intends to merge to `next`.

---

Under “Cooking” (topics in `next` or about to graduate):

- **hn/url-push-tracking** lets `@{push}` work when the push remote is specified as a URL by using the fetch refspec of the uniquely matching configured remote.
- **hn/bisect-reset-when-found** adds `--reset-when-found[=<where>]` to `git bisect`, automatically running `git bisect reset` to jump back to the original state or to the found culprit.
- **ps/odb-move-loose-object-writing** moves loose-object writing logic from `object-file.c` to `odb/source-loose.c`, making the loose backend more self-contained.
- **pw/rebase-fixup-fixes** fixes two bugs in `git rebase` when skipping `fixup`/`squash` commands: incorrect commit counts in the template message and failure to open the editor when the final command in a chain containing `fixup -c` is skipped.
- **tb/send-pack-no-ref-delta** teaches `git send-pack` to honor the `no-ref-delta` capability, avoiding REF_DELTA encoded packfiles when requested.
- **hn/branch-delete-merged** introduces `git branch --delete-merged` to remove local branches already merged into their tracked remote-tracking branches, with a `--dry-run` option and per-branch opt-out via `branch.<name>.deleteMerged`.
- **ps/cat-file-remote-object-info** adds a `remote-object-info` command to `git cat-file --batch-command`, allowing clients to request object metadata (currently size) from a remote server without downloading the object.

---

Stalled topics include **kh/doc-trailers** (documentation improvements for `git interpret-trailers`) and **jt/config-lock-timeout** (configurable retry for `config.lock`), both awaiting rerolls.

---

In short: the integration pipeline is active, with a steady stream of small fixes, documentation updates, and backend refactorings. The most user-visible new feature is `git branch --delete-merged`; the most architecturally significant is the ongoing ODB abstraction work. Busy readers can safely skip the stalled topics and focus on the “New Topics” and “Cooking” sections for what is likely to land soon.
