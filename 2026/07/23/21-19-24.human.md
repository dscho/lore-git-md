This is a documentation patch, part of Jean-Noël Avila’s ongoing effort to convert all Git man pages to the project’s new AsciiDoc synopsis style. This specific patch (2/4 in the v2 series) updates the `git-format-patch` man page and two included files (`diff-options.adoc` and `format-patch-caveats.adoc`) to use consistent markup: backtick-quoting for option terms, `_<placeholder>_` for placeholders, and four-dash fences in delimited blocks.

The changes are purely presentational—no behavior, CLI interface, or option semantics are altered. The patch addresses the two stylistic issues Junio C Hamano raised in v1: backtick usage (conceptual terms like “base commit” remain in plain quotes; literal strings like `base-commit:` are now backtick-quoted) and uniform four-dash fences. The diffstat is nearly balanced (148 insertions, 149 deletions), reflecting the mechanical nature of the conversion.

This patch is uncontroversial and ready for final review. Given the author’s track record on this conversion effort and the absence of outstanding concerns, it is likely to graduate to `next` once reviews are complete. If you follow Git’s documentation modernization, this is a routine update; if you only care about user-visible changes, you can safely skip it.
