This is the v3 submission of a two-patch bugfix series for `git mv`, addressing a misleading error when the destination's parent directory does not exist. The series is now complete: the first patch improves the error message to include both source and destination paths, and the second adds an early existence check for the destination directory (and its intermediate components) to enable `--dry-run` detection.

The v3 iteration resolves all substantive feedback from Junio C Hamano. The key change is switching from `lstat()` to `stat()` to align with `rename()`'s behavior, explicitly checking for non-directory destinations (reporting "destination is not a directory") and invalid intermediate path components (reporting "destination directory does not exist"). The implementation now handles symlinks correctly: a symlink to a directory is accepted, while a symlink to a file is rejected. The TOCTOU race remains acknowledged but unresolved, as it is considered "the best we can do" for now.

Files touched are `builtin/mv.c` and `t/t7001-mv.sh`. The test suite now covers missing directories, non-directory path components, symlinks (both to files and directories), and `--dry-run` detection. The series introduces no new symbols, but the improved error message ("renaming '%s' to '%s' failed") is a new translatable string. The l10n impact is minor, and the author has flagged whether to reuse the existing "does not exist" message for the non-directory case.

This is a well-scoped, user-facing fix with thorough test coverage and clear commit messages. The series is unlikely to be controversial and appears ready for final review. The only remaining loose end is the TOCTOU race, which is explicitly acknowledged and not blocking. Key details: `builtin/mv.c`, `t/t7001-mv.sh`, `--dry-run`, error messages "destination directory does not exist" and "destination is not a directory".
