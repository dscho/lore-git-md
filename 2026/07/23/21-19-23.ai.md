This is the first patch in Jean-Noël Avila’s v2 documentation series converting four Git command man pages to the project’s new AsciiDoc synopsis style. It updates `git-imap-send` and its associated config documentation (`Documentation/config/imap.adoc`).

The patch mechanically replaces the old `[verse]` synopsis block with the new `[synopsis]` style, backtick-quotes all option and config-key references, and standardizes AsciiDoc listing blocks to use four-dash fences. No behavior, CLI interface, or rendered output is altered—this is purely a markup cleanup. The changes align with the feedback Junio C Hamano gave on v1, ensuring consistent backtick usage and uniform delimiters.

The patch touches only two files (`Documentation/git-imap-send.adoc` and `Documentation/config/imap.adoc`) and is uncontroversial. It is part of the ongoing documentation synopsis-style conversion effort, which has already converted more commonly used commands. Given the author’s track record and the mechanical nature of the changes, this patch is likely to graduate to `next` once reviews are complete.
