This is the first patch in a two-patch bugfix series for `git mv`. It addresses a misleading error message that occurs when `git mv` fails due to a missing destination directory. Currently, the error blames the source file (e.g., "renaming 'src' failed: No such file or directory"), even when the source exists and the destination's parent directory is missing. The patch modifies the error message to include both the source and destination paths, making it clear which part of the operation failed. The change is minimal—just one line in `builtin/mv.c`—and introduces a new translatable string for the improved error format. This patch has already been approved by Junio C Hamano ("Makes sense") and is uncontroversial. It is a straightforward, user-facing improvement with no behavioral changes beyond the error message itself.
