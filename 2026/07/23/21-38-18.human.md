This is the author's reply to Junio C Hamano's substantive review of the second patch in the `git mv` bugfix series. Lucas Zamboni Orioli addresses both edge cases Junio raised: paths that exist but are not directories (e.g., symlinks or regular files), and intermediate path components that are not directories (e.g., `a/b/c` where `a/b` is a file). The fix switches from `lstat()` to `stat()` to match `rename()`'s symlink-following behavior, and now explicitly checks whether the resolved path is a directory. Two new error conditions are introduced: "destination directory does not exist" (for `ENOENT` or `ENOTDIR`) and "destination is not a directory" (for non-directory types). The author is open to consolidating the messages to reduce l10n impact.

The patch remains well-motivated and narrowly scoped to the directory existence check; the TOCTOU race and the series' two-patch structure are unchanged. This reply clears the technical feedback and leaves only the l10n string decision and the previously requested indentation style fix as open items before the series can graduate to `next`.
