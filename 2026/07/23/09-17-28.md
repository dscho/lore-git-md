These should not use `git` in a $( ) subshell to avoid a case of "ignore
failure in upstream of pipe". Note that

```
	local file=$(git rev-parse ...) &&
	test_path...

```

would be wrong, too, for the same reason. But

```
	local file
	file=$(git rev-parse ...) &&
	test_path...

```

works as desired.
