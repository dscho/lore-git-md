This is the final patch in Christian Couder’s seven-part refactoring series for `git fast-import`. It replaces the hand-written, single-line usage string with a `struct option` array, bringing the command’s `-h` and `--help-all` output into alignment with its SYNOPSIS documentation and with the rest of Git’s commands.

The patch removes the incomplete, hard-coded usage string that omitted many options and did not respect `--help-all`. In its place, it defines a full `struct option` array that groups options into logical sections (Common, Marks, Submodule rewrite, Signing, and Advanced), marks hidden options with `PARSE_OPT_HIDDEN`, and uses the new `OPT_HIDDEN_GROUP` macro introduced earlier in the series. The SYNOPSIS line in `Documentation/git-fast-import.adoc` is tweaked to match the new usage pattern, and the command is removed from the `t0450/adoc-help-mismatches` test.

No parsing logic is changed—this patch only affects the help text displayed by `-h` and `--help-all`. The actual option parsing remains handled by the existing `parse_one_option()` and `parse_one_feature()` functions, leaving full libification for future work. The patch touches three files: the documentation, the builtin, and the test suite. CI passed, indicating no regressions.
