This is a performance patch for `git fast-import`, part of a five-patch series by Patrick Steinhardt. It reduces syscall overhead when responding to `cat-blob` commands by replacing three separate `write(3p)` calls with a single `writev(3p)` call via the new `writev_in_full()` helper.

The patch targets a real bottleneck: frontends like `git-filter-repo` issue `cat-blob` commands in bulk, and the syscall overhead adds up. Benchmarking on linux.git with 100,000 objects shows a 4% speedup (1.320s → 1.270s). The change is confined to `builtin/fast-import.c` and is straightforward: it packs the header line, blob payload, and trailing newline into an `iovec` array and sends them in one go.

The commit message is clear and includes both the motivation and benchmark results. No test failures or edge cases are mentioned, but the patch looks well-scoped and unlikely to introduce regressions. If you care about `git fast-import` performance—especially in filter-heavy workflows—this is worth a look.
