This GSoC patch series from K Jayatheerth is adding seven new path-related keys to `git repo info` to expose filesystem locations of repository components in a scriptable format. The series is now halfway through, with four of seven patches posted.

The latest patch introduces `path.hooks.absolute` and `path.hooks.relative` keys that expose the hooks directory location, respecting Git's `core.hooksPath` configuration. Like previous patches, it follows the established pattern of using Git's internal path resolution functions while keeping the implementation clean and well-tested. The tests verify both default and custom hooks paths, which is important for external tool integration.
