This thread is a Google Summer of Code project by K Jayatheerth adding seven new path-related keys to the `git repo info` command, exposing filesystem locations of repository components (like the object database, hooks directory, and index file) in a scriptable format. The series is now at version 2, with the third of seven patches posted—this one implements `path.objects.absolute` and `path.objects.relative` to show the object database location, respecting the `GIT_OBJECT_DIRECTORY` environment variable.

So far, only mechanical issues have been addressed: Junio C Hamano pointed out two minor problems in the first version of patch 7/7 (include order and commit title), both fixed in v2. The rest of the series remains technically unreviewed, with no feedback yet on the design or naming choices. The implementation follows a consistent pattern across patches, using Git’s internal path-formatting helpers and testing edge cases like bare repositories and environment overrides. The main open question is whether the key names (e.g., `path.objects` vs. `path.objectdir`) align well with existing Git terminology. The series is self-contained and doesn’t depend on other in-flight work.
