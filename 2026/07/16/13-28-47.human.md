This is the sixth patch in Siddharth Shrimali’s RFC series introducing `git repack --drop-filtered` for partial clones. It implements the actual object removal: when `--drop-filtered` is given without `--dry-run`, the enumerated promisor blobs are excluded from the rebuilt promisor pack and the old packs containing them are deleted (via implied `-d`). The patch is crash-safe because it reuses Git’s existing repack machinery, which writes the new pack before removing the old ones and fsyncs the directory.

The change is straightforward: `builtin/repack.c` now passes the `drop_oids` oidset to `repack_promisor_objects()` on a real run, and `enumerate_promisor_blobs()` in `repack-filtered.c` no longer prints or clears the set—ownership moves to the caller. The test script gains a new case that verifies the large promisor blob is gone while the small one remains. The earlier restriction that `--drop-filtered` required `--dry-run` is lifted, and the dry-run code path is kept for listing candidates.

This patch completes the core functionality; the remaining patch (7/7) will add the drop log for better error messages. The series is still marked RFC, so the implementation may evolve, but the safety guarantees (only promisor objects, no locally created objects, crash-safe repack) are now in place.
