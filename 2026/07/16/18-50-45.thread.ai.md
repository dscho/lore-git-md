Core problem or goal: Replace O(n²) `string_list_insert()` calls (which maintain sorted order but trigger O(n) array shifts per insertion) with a single O(n) `string_list_append()` pass followed by one O(n log n) sort and deduplicate operation per list (`s->untracked` and `s->ignored`).
