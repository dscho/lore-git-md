This is Junio’s biweekly "What’s cooking in git.git" report for July 2026, summarizing the current state of integration branches and in-flight topics. It’s the project’s heartbeat: a snapshot of what has graduated to `master`, what is cooking in `next`, what is stalled, and what has been discarded.

The report shows 12 topics graduating to `master` since the last update, including Patrick Steinhardt’s `ps/history-drop` (adding a `drop` subcommand to the experimental `git history` command), Jeff King’s Bloom-filter leak fixes (`jk/bloom-leak-fixes`), and a handful of smaller fixes and cleanups. These are now part of the upcoming release and can be ignored unless you’re tracking regressions.

In `next` (the integration branch for topics that look ready but are still being cooked together), 30+ topics are listed. The most substantial are:

- **`ps/odb-for-each-object-filter`** (Patrick Steinhardt): Teaches `odb_for_each_object()` to accept object filters, allowing backends to optimize traversals using reachability bitmaps. This is part of the ongoing ODB abstraction effort and is a building block for future pluggable backends.
- **`ps/refs-wo-the-repository`** (Patrick Steinhardt): Removes the last uses of the global `the_repository` variable from the ref subsystem, continuing the long-running `the_repository` removal effort.
- **`ps/odb-pluggable-housekeeping`** (Patrick Steinhardt): Refactors `git gc` and `git maintenance` to make object database housekeeping pluggable, moving files-backend logic into the files ODB source. This is another step toward alternative ODB backends.
- **`pw/rebase-drop-notes-with-commit`** (Phillip Wood): Fixes a bug in rebase where dropping a commit would incorrectly copy its notes to an unrelated commit. This is a correctness fix for the sequencer.
- **`mm/diff-process-hunks`** (Matthias Aßhauer): Introduces `diff.<driver>.process`, allowing an external long-running process to act as a hunk provider. This is a powerful extension point for tools that want to control what Git considers "changed" without reimplementing diff output formatting.
- **`hn/history-squash`** (Hannes Nuus): Adds a `squash` subcommand to `git history` to fold a range of commits into one, with descendants replayed on top. This is part of the experimental `git history` command set.

Several topics are marked as needing review or waiting for response, including Johannes Schindelin’s Coverity fixes (`js/coverity-unchecked-returns-fix`), Jeff King’s diff segfault fix (`jk/diff-relative-cached-unmerged`), and a new `fetch.submoduleErrors` configuration (`pz/fetch-submodule-errors-config`) that makes submodule fetch errors non-fatal.

The stalled section lists topics that have seen no activity for weeks, such as Karthik Nayak’s trailer documentation update (`kh/doc-trailers`) and a rebase symref alias fix (`sn/rebase-update-refs-symrefs`). These may be discarded unless new interest arises.

Two topics were ejected for causing too many conflicts: `ps/libgit-in-subdir` (moving `libgit.a` sources into a `lib/` directory) and `mm/diff-process-hunks` (due to conflicts with `mm/line-log-limited-ops`).

The report also lists discarded topics, notably Kristoffer Haugsbakk’s prio-queue optimization (`kk/prio-queue-cascade-sift`), which was retracted after review feedback.

For a busy reader, the key takeaways are:
- The ODB abstraction and `the_repository` removal efforts continue to make progress with multiple topics in `next`.
- The experimental `git history` command is growing new subcommands (`drop`, `squash`).
- External diff process support (`diff.<driver>.process`) is a notable new feature that may interest tool integrators.
- Several correctness fixes (rebase notes, diff segfaults, reftable tombstones) are in flight.
- The report is a good place to check if a topic you care about is still alive or has been discarded.
