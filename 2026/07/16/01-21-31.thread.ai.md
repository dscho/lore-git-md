Originating author: K Jayatheerth (GSoC contributor). Thread type: feature patch series. Current version: 1 (complete; all seven patches posted).

Core problem or goal: Expose filesystem locations of repository components (e.g., hooks directory, index file, grafts file, superproject working tree, object database, and the relative path from the top-level working tree to the current directory) in a user-facing, scriptable format via `git repo info`. The new keys mirror existing internal Git struct fields (e.g., `the_repository->gitdir`, `the_repository->objectdir`, `startup_info->prefix`) but avoid requiring direct access to Git’s internals. Each key supports suffix-based formatting (e.g., absolute vs. relative paths) where applicable.

- Behavior: Keys return filesystem paths (absolute or relative) for repository components, matching internal Git struct fields. The `path.git-prefix` key returns the relative path from the top-level working tree to the current directory, including a trailing slash (empty string at the root).
