This is a refactoring and documentation cleanup series for `git fast-import`, led by Christian Couder. The main goal is to standardize the command’s usage string and align it with its man-page SYNOPSIS, removing it from the list of commands with mismatched help text. Along the way, the series modernizes parts of the codebase: it introduces a new `OPT_HIDDEN_GROUP` macro for parse-options, improves the API documentation, starts libifying `builtin/fast-import.c` by moving global variables into a `struct fast_import_state`, and switches the usage string to use `struct option`.

The series is well-structured and incremental. The first three patches lay groundwork (new macro, better docs), the next three begin the libification effort, and the final patch delivers the headline improvement. CI tests pass, and the commit messages are clear. There is no behavior change—this is purely internal cleanup and consistency work—so it should be uncontroversial. If you care about `fast-import` internals or parse-options hygiene, this series is worth a skim; otherwise, it’s safe to ignore unless you’re tracking the ongoing effort to remove global state.
