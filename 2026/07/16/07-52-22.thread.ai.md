Core problem or goal
Reduce kernel-level contention in Git's sideband protocol implementation by replacing two `write(3p)` syscalls per pktline (header + payload) with a single `writev(3p)` call. The target scenario is high-load forges (e.g., GitLab) serving precomputed packfiles from cache, where semaphore saturation in the pipe write path has been observed.
