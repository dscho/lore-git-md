Thread type: user support / platform compatibility issue

Core problem or goal
A user reports that pressing Ctrl+C in a Vagrant SSH session terminates the entire session instead of interrupting the current command, but only when using Git Bash (not PowerShell). The issue is confirmed to be Git for Windows-specific, with a suspected link to the bundled SSH implementation in Git Bash, matching GitHub issue #3716.

Current status
Open support discussion; no decisions, no merge status, no versioning. The user has confirmed the issue persists with the latest Git for Windows release (2.55.0.windows.3). Johannes Schindelin has proposed a workaround (installing native Windows OpenSSH and opting out of Git for Windows' bundled SSH during reinstallation) but no resolution has been reached. The thread remains in diagnostic mode with no code changes or patches proposed.
