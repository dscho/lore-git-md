This is the sixth patch in Christian Couder’s seven-patch series refactoring `git fast-import` to reduce global variables and prepare for libification. It moves two more command-state globals (`seen_data_command` and `allow_unsafe_features`) into the `struct fast_import_state` introduced in the previous patch. The change is purely mechanical: every access site is already inside a function that receives the `state` parameter, so the patch simply replaces the global names with `state->` dereferences. The only minor adjustment is moving the `fast_import_state_init()` call earlier so the `--allow-unsafe-features` option can be recorded directly into the struct. No behavior changes are intended, and the patch keeps the codebase on the well-trodden path of prior libification efforts like `struct apply_state`.
