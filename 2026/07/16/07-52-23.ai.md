This is a performance patch targeting `git fast-import`, part of a 5-patch series. It replaces three separate `write(3p)` calls in the `cat-blob` response path with a single `writev(3p)` call, reducing syscall overhead when frontends like `git-filter-repo` issue bulk `cat-blob` commands.

The patch modifies `builtin/fast-import.c` in the `cat_blob()` function, introducing an `iovec` array to bundle the header line, blob payload, and trailing newline into one scatter-gather I/O operation. The commit message includes a microbenchmark showing a 4% speedup (1.320s → 1.270s) when processing 100,000 objects in `linux.git`, with system time dropping from 0.161s to 0.132s.

The change is narrowly scoped to the fast-import subsystem and does not affect other Git commands. The implementation uses `writev_in_full()`, a helper introduced earlier in the series (likely in a prior patch), and includes proper error handling for the writev call. The patch is well-motivated, includes measurable performance data, and appears to be a clean optimization with no behavioral changes.
