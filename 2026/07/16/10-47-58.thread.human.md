This thread is about a small but important regression fix. In May 2026, commit `dd4bc01c0a` accidentally broke path filtering for `git rev-list --no-walk <commit> -- <path>`, causing it to ignore the path filter and output all commits instead of only those that modified the specified files. Kristofer Karlsson submitted a minimal patch that restores the correct behavior, adding three new tests to prevent future regressions.

The fix has been verified by Peter Colberg, who originally reported the issue and confirmed the patch resolves his real-world use case. Junio C Hamano, the maintainer, has reviewed the fix and stated he will queue it for integration. There are no open questions or objections, and the patch is expected to graduate to `next` and then `master` soon, as it addresses a clear, recent regression with minimal risk.
