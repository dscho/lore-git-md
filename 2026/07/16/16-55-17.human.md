This is the final patch in Christian Couder’s seven-part refactoring series for `git fast-import`. It replaces the hand-rolled, single-line usage string with a full `struct option` array that the parse-options API can render. The new usage output now matches the SYNOPSIS in the man page, shows all supported options (including hidden ones when `--help-all` is used), and groups them into logical sections (Common, Marks, Submodule rewrite, Signing, Advanced). The patch also removes `fast-import` from the `t0450/adoc-help-mismatches` test, confirming the fix. No behavior change is intended; the actual option parsing is left for future work. The patch is clean, well-motivated, and passes CI.
