This is a performance patch targeting the `wt-status` subsystem, specifically addressing a quadratic-time inefficiency in how untracked and ignored paths are collected.

The patch replaces repeated `string_list_insert()` calls—which maintain sorted order but can trigger O(n) array shifts on each insertion—with a single `string_list_append()` pass followed by one sort and deduplicate operation per list. The change reduces the overall complexity from O(n²) to O(n log n) while preserving the existing behavior of producing sorted, duplicate-free lists. The commit message clearly explains the trade-off: the author considered but rejected a more aggressive optimization that would rely on `fill_directory()`'s pre-sorted output, opting instead for the safer approach that explicitly removes duplicates.
