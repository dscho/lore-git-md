This is a maintainer merge notice for a two-patch bugfix series targeting the `wincred` credential helper on Windows. Junio C Hamano has merged Johannes Schindelin’s backport of two critical fixes that were previously released in Git for Windows v2.55.0(3). The patches address memory corruption during credential erasure and silent loss of OAuth tokens during storage, both of which were caused by miscalculations in buffer allocation and string-handling functions in `contrib/credential/wincred/git-credential-wincred.c`.

The changes are minimal (six lines modified across two functions), platform-specific, and carry no cross-platform risk. No test coverage was included, which is typical for `contrib/` code. The series is now in `master` and will be part of the next Git release. This resolves the upstreaming of fixes that have already been validated in the Git for Windows fork.
