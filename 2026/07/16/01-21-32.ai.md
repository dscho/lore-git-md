This is the first patch in a seven-part GSoC feature series adding new path-related keys to the `git repo info` command. It introduces `path.toplevel.absolute` and `path.toplevel.relative`, which expose the repository’s top-level working tree directory in a scriptable format. The implementation is straightforward: it uses `repo_get_work_tree()` to fetch the path and applies the existing `format_path()` helper with `PATH_FORMAT_CANONICAL` or `PATH_FORMAT_RELATIVE` to produce absolute or relative paths, respectively. In bare repositories, both keys return an empty string.
