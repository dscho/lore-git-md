The patch updates the function signature and adjusts the `strvec_pushl()` calls to conditionally include the `--quiet` option. No callers set the flag yet, so the behavior remains unchanged in this patch. The changes are confined to `builtin/bisect.c`, with no new symbols or on-disk format changes.
