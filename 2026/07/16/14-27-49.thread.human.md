This thread is about a two-patch series from Johannes Schindelin (Dscho) that backports critical bugfixes for the `wincred` credential helper from Git for Windows to upstream Git. The fixes address two memory corruption issues on Windows: one causing process termination during credential erasure, and another silently losing OAuth tokens during storage due to heap corruption. Both bugs were already fixed in Git for Windows v2.55.0(3) and are now upstreamed.

The series was small and uncontroversial, touching only `contrib/credential/wincred/git-credential-wincred.c` with minimal changes (10 lines across two functions). Junio C Hamano has now merged the patches into `master`, meaning they will be included in the next Git release. No test coverage was added, which is typical for `contrib/` code, and the changes are Windows-specific with no cross-platform impact. This completes the upstreaming of fixes that had already been validated in the Git for Windows fork.
