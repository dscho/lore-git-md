This is the third patch in K Jayatheerth’s seven-part GSoC series adding path-related keys to `` `git repo info` ``. It introduces ``path.objects.absolute`` and ``path.objects.relative``, which expose the location of the object database directory in both absolute and relative forms, respecting the ``GIT_OBJECT_DIRECTORY`` environment override.

The implementation is straightforward: two new getter functions in ``builtin/repo.c`` call ``repo_get_object_directory()`` and pass the result through ``format_path()`` with the appropriate ``PATH_FORMAT_*`` flag. Documentation and tests are included, covering both the standard case and the environment-override scenario. The patch follows the established pattern from the first two patches, so it looks consistent and well-scoped.

No substantive review feedback has appeared yet, but the patch is unlikely to be controversial—it simply surfaces an existing internal value in a scriptable way. If reviewers have suggestions, they will probably focus on naming consistency (e.g., whether “objects” is the best term) rather than the implementation itself.
