The v3 series from first-time contributor Siddharth Shrimali is now complete (7/7 patches) and addresses all prior feedback: the bitmap validation edge case is fixed, documentation softens “guaranteed recoverable” to acknowledge remote risks, and the merge/rebase/cherry-pick checks plus index validation are now framed as UX optimizations rather than correctness measures. Junio’s latest review is purely mechanical—three small blocking issues (SYNOPSIS mismatch, missing newline in the usage string, and test script style) need trivial fixes before the series can be queued.
