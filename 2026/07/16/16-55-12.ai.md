This is a documentation patch, part 2/7 of Christian Couder’s seven-patch series refactoring `git fast-import`’s usage string and beginning its libification. The patch adds a new “Option flags” subsection to `Documentation/technical/api-parse-options.adoc` that documents the per-option flags (e.g., `PARSE_OPT_HIDDEN`, `PARSE_OPT_OPTARG`) that can be set in the `flags` field of `struct option`. These flags control behaviors like whether an option’s argument is optional, whether the option is hidden from `-h` but still shown with `--help-all`, and whether the option participates in shell completion. The documentation explicitly distinguishes these per-option flags from the global flags passed to `parse_options()` itself, and it describes each flag’s purpose and typical use case. The patch is purely additive, touching only the AsciiDoc file, and is a straightforward improvement to the parse-options API documentation. It is well-motivated and uncontroversial, serving as a necessary foundation for later patches in the series that introduce new flags and reorganize option groups.
