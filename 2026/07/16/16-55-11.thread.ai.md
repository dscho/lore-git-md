Core problem or goal
The parse-options API currently lacks a way to group hidden options (those visible only with `--help-all`) without also displaying the group header in the short help output (`-h`). This patch introduces `OPT_HIDDEN_GROUP` to allow grouping of internal or advanced options that should remain hidden unless explicitly requested.

- Subsystem: parse-options API
