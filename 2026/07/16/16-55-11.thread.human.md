This thread introduces a small but useful improvement to Git's command-line option parsing. Christian Couder has sent a seven-patch series beginning with this change, which adds `OPT_HIDDEN_GROUP` to the parse-options API. The goal is to let developers group hidden options—those only visible with `git cmd --help-all`—without cluttering the standard help output with group headers for options the user didn't ask to see.

The implementation is minimal and focused: the new macro simply marks a group as hidden, and the usage formatter now skips these groups unless full help is requested. Tests confirm the group appears only in `--help-all` output, not in the default short help. So far, the patch touches only the parse-options subsystem and its test suite, so there's no risk of broader breakage.

No reviews or objections have appeared yet, so the series is still in its early stages. If you're working on a command that uses hidden options, this change could help keep your help text cleaner once it lands.
