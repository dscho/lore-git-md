This thread is a seven-patch series from Christian Couder refactoring `git fast-import` to modernize its usage string and reduce reliance on global variables, part of broader efforts to libify Git's codebase. The series introduces new parse-options infrastructure (like `OPT_HIDDEN_GROUP`) and encapsulates global state in a `struct fast_import_state`, following established patterns from prior work like `builtin/apply.c`.

The first six patches laid the groundwork: documenting parse-options flags, localizing loop counters, and moving globals into the new struct. The just-posted final patch replaces the hand-written usage string with a `struct option` array, aligning `-h` and `--help-all` output with the SYNOPSIS documentation and grouping options into logical sections (Common, Marks, Submodule rewrite, etc.). This removes the command from the `t0450/adoc-help-mismatches` test, as the help text now matches the documentation. No behavior changes are intended—only the help display is affected.

The series is under review with no substantive feedback yet, though CI passed. The approach mirrors prior libification work, suggesting it’s uncontroversial. Open questions include whether the remaining globals will be addressed in follow-up work and whether reviewers will request adjustments to the new usage grouping or hidden-option handling. For now, the series is a clean, incremental step toward libification.
