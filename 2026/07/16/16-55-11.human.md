This is a refactoring patch to the parse-options API, part of a seven-patch series. It introduces `OPT_HIDDEN_GROUP`, a new macro that lets developers group hidden command-line options so they appear together in `--help-all` output but stay invisible in the default `git <cmd> -h` help.

The motivation is straightforward: when a command has many hidden options (or options that belong to a distinct category), there’s no clean way to group them without exposing the group header in the regular help. The patch adds the macro, tweaks the usage formatter to skip hidden groups when `full` is false, and updates the test helper to demonstrate the feature. The test suite is expanded to verify that hidden groups and options appear only with `--help-all`.

The implementation is small and focused: four lines of new code in the header, a two-line reordering in the formatter, and a few lines of test scaffolding. The commit message is clear and the tests look thorough. This feels like a well-crafted, uncontroversial improvement to the option-parsing infrastructure.
