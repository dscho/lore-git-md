This is a small refactoring patch in Christian Couder’s seven-part series to modernize `git fast-import`. Patch 4/7 moves the loop counter `i` from being a function-wide `unsigned int` into the scope of each `for` loop that uses it, so the counter’s type can match the bounds of the loop it controls.

The change is purely mechanical: one declaration is removed from the top of `cmd_fast_import()`, and the four loops are updated to declare `i` locally with the most appropriate type (`int`, `unsigned int`, or `size_t`). The patch touches only `builtin/fast-import.c` and makes no functional or behavioral changes. It is a clean, low-risk step toward the series’ larger goal of reducing global state and improving code clarity.
