This is a pull request for `git-gui`, the graphical user interface for Git. Johannes Sixt (the `git-gui` maintainer) submits three small, independent changes to Junio for integration into the main Git repository.

The first change, by Alexander Shopov, updates the Bulgarian translation (`po/bg.po`) to cover all 562 translatable strings. The second, also by Shopov, widens the commit-message text field in the GUI (`lib/option.tcl`) so users can see more of their message without scrolling. The third, by Harald Nordgren, silences the `msgfmt --statistics` output during the build (`Makefile`), making `make -s` truly quiet.

Two of the four commits are merge commits (from Shopov’s and Nordgren’s forks), and Sixt has already integrated them into his own `master` branch. The diff touches only the `git-gui` subtree: `Makefile`, `lib/option.tcl`, and `po/bg.po`. No core Git code or tests are modified. The changes are cosmetic and localized, so they should not affect other parts of the system.
