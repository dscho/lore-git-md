This is the second patch in Tian Yuchen’s four-patch v6 series, part of the ongoing `the_repository` removal effort. It moves the `ce_mode_from_stat()` helper from `read-cache.h` (where it was a static inline) to `read-cache.c` so it can later access repository-scoped configuration variables without exposing them in the header. The patch is purely preparatory: it changes no behavior, but it is a necessary step before the subsequent patches can migrate `trust_executable_bit` and `has_symlinks` out of global scope. The redundant `extern` declarations for those globals are removed as part of the same cleanup. Reviewers have already acknowledged the approach; this patch is uncontroversial and should proceed alongside the rest of the series.
