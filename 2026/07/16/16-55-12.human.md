This is a documentation patch, part two of Christian Couder’s seven-patch series refactoring `git fast-import` and modernizing the parse-options API. It fills a long-standing gap in the technical documentation by adding a dedicated “Option flags” subsection to `api-parse-options.adoc`. The new section lists and explains every per-option flag (e.g., `PARSE_OPT_HIDDEN`, `PARSE_OPT_NOARG`, `PARSE_OPT_CMDMODE`) that can be set in the `flags` field of `struct option`, making them discoverable without digging into `parse-options.h`. The patch also clarifies the distinction between these per-option flags and the global `parse_options()` flags, and explicitly describes how `PARSE_OPT_HIDDEN` affects `-h` versus `--help-all` output. No code behavior changes; the patch is purely additive to the documentation.
