This is a two-patch bugfix series targeting the `wincred` credential helper, authored by Johannes Schindelin. The patches address memory corruption and silent credential loss when handling credentials and OAuth tokens on Windows. Both issues were discovered and fixed in Git for Windows v2.55.0(3), and this series backports those fixes to upstream Git.

The changes are confined to `contrib/credential/wincred/git-credential-wincred.c`, modifying six lines across two functions. The commit messages are terse but clear about the symptoms: one patch prevents memory corruption during credential erasure, the other prevents silent loss of OAuth tokens during storage. No test coverage is included in the series, which is typical for `contrib/` code where testing infrastructure is minimal.

This is platform-specific work with no cross-platform impact; the fixes are only relevant to users of the `wincred` helper on Windows. The series is small, focused, and appears to address real bugs with minimal risk. It is not part of any larger ongoing effort, though it continues the pattern of Git for Windows fixes being upstreamed after validation in the downstream fork.
