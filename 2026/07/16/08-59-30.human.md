This is a **translation (l10n) and build system** update for `gitk`, the Git repository browser GUI. Johannes Sixt, the `gitk` maintainer, sends a pull request to Junio with three small changes: an updated Bulgarian translation (329 translated messages) by Alexander Shopov, a new Spanish translation by "basuradeluis", and a tweak to the Makefile so that `make -s` (silent mode) actually suppresses output.

The patch touches only `po/bg.po`, `po/es.po`, and the top-level `Makefile`. There is no new functionality, no behavior change, and no risk to the core Git codebase. The changes are routine housekeeping for a mature, stable tool. If you care about `gitk` translations or build verbosity, this is worth a quick glance; otherwise, it can safely be ignored.
