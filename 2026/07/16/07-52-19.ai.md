This is a platform-compatibility patch introducing a `writev(3p)` wrapper for systems that lack the syscall. It is the first patch in a five-part series by Patrick Steinhardt, laying groundwork for a subsequent commit that will add the first caller of `writev`. The wrapper is implemented in `compat/writev.c` and provides a fallback that iterates over the `iovec` array, writing each segment sequentially using Git’s existing `xwrite` wrapper. The patch updates all three build systems (Makefile, CMake, and Meson) to conditionally compile the wrapper when `NO_WRITEV` is defined, which the patch sets for Windows in `config.mak.uname`. The implementation mimics the POSIX specification by checking for integer overflow in the total `iov_len` sum and returning `EINVAL` if detected. Johannes Schindelin is credited with help.
