This patch introduces `OPT_HIDDEN_GROUP` to the Git parse-options API. It is the first patch in a seven-patch series from Christian Couder.

The patch addresses a gap in the current option-grouping mechanism: hidden options (those not shown by `git cmd -h` but visible with `git cmd --help-all`) cannot be grouped without also showing the group header in the short help output. The new `OPT_HIDDEN_GROUP` macro creates a group that appears only when hidden options are displayed, allowing better organization of internal or advanced options.

The implementation is straightforward: the macro adds `PARSE_OPT_HIDDEN` to the group’s flags, and the usage formatter is adjusted to skip hidden groups when `full` help is not requested. The patch also extends the `test-tool parse-options` helper with hidden options and adds a test case that verifies the group appears only in `--help-all` output.

Files touched: `parse-options.c`, `parse-options.h`, `t/helper/test-parse-options.c`, and `t/t0040-parse-options.sh`. The change is confined to the parse-options subsystem and its test suite.
