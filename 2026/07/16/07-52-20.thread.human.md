This thread is about a five-patch series from Patrick Steinhardt that reintroduces `writev(3p)` support to Git’s low-level I/O layer. The first patch, summarized here, adds generic wrapper functions—`writev_in_full()` and `writev_or_die()`—to mirror existing helpers like `write_in_full()` and `write_or_die()`. These new functions handle partial writes, retry on `EINTR`/`EAGAIN`, and adjust the `iovec` array to track remaining data, but they aren’t yet used by any callers. This is foundational work for later patches in the series, which will likely integrate the wrappers into Git’s I/O operations. So far, the thread only includes the initial patch, so there’s no discussion or feedback yet.
