This thread is about a small but well-reviewed performance cleanup in Git’s `wt-status` subsystem. Sahitya Chandra, a first-time contributor, posted a patch that replaces a quadratic-time pattern in `wt_status_collect_untracked()`—where repeated `string_list_insert()` calls could trigger O(n) array shifts—with a single O(n) append pass followed by one O(n log n) sort and deduplicate operation. The patch is tiny (6 insertions, 2 deletions) and touches only `wt-status.c`, preserving the existing sorted, duplicate-free output.

Two established reviewers, Patrick Steinhardt and Jeff King (Peff), have engaged substantively. Patrick initially endorsed the approach but suggested using `string_list_sort_u()` for simplicity; Peff later confirmed the quadratic-time behavior is likely theoretical (because `fill_directory()` already returns sorted input) but supported the patch for its clarity and maintainability. Both agreed benchmarks weren’t needed. The only remaining feedback was Peff’s surface-level tweak to the commit message, which Sahitya has accepted and will incorporate into v3. The patch now appears ready for integration, with all substantive feedback addressed and no open technical questions.
