This is a test infrastructure patch series, now at v2 in response to review. The author, Shlok Kulshreshtha, acknowledges two oversights in the initial submission: the `message_body()` helper in `t7509-commit.sh` and an inline variant in `t3404-rebase-interactive.sh` both used the same exit-code-masking pattern (`git cat-file commit | sed`) that the series was designed to eliminate. Both have now been converted to use the new `commit_body()` helper, bringing the total number of replaced instances to 62.

The series remains a clean, well-motivated refactoring: it introduces a reusable shell function to extract commit message bodies in tests, fixes a subtle correctness issue (pipeline exit-code masking), and consolidates four near-identical spellings of the same idiom into a single call. The changes are mechanical and confined to the test suite; no user-visible behavior is affected. Junio Hamano’s review feedback was narrow and actionable, and the author has addressed it fully. The v2 update is a straightforward completeness fix and does not alter the series’ core value.
