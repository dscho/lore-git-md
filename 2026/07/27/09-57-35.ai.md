This is a **bugfix** for a crash in `git cat-file --batch-command`. Jeff King (Peff) confirms the issue—a NULL dereference in `print_object_or_die()` when the `contents` command is issued without `%(objecttype)` in the format string—and traces it to a missing type metadata fetch in the `--batch-command` code path. Peff suggests the proper fix involves saving and restoring `data->info.typep` around the `contents` command to avoid over-fetching.
