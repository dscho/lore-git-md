This thread is about a small but important bugfix in Git’s pack-bitmap subsystem, authored by David Lin. The patch corrects an off-by-one error in `find_objects()` that caused objects at position zero in the base bitmap to be incorrectly excluded, leading to redundant work—either reloading reachability bitmaps or unnecessarily adding objects to the not-mapped list. The fix is minimal, touching only `pack-bitmap.c` and its test file, and has been thoroughly reviewed.

Taylor Blau provided substantive feedback on the initial version, confirming the fix’s correctness and suggesting improvements to the test coverage, which were incorporated into `v2`. Junio C Hamano has accepted the patch for integration, marking it as "Will queue" for the `seen` branch. The patch is now considered ready for inclusion, with no open questions or further changes expected unless integration testing uncovers unexpected issues. The regression was introduced in commit 11d45a6e6a, and this fix restores the intended behavior without altering the resulting object set.
