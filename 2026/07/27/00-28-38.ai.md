This is the first patch in Ted Nyman’s v6 series fixing packfile URI race conditions in Git’s HTTP transport. It is a **documentation and error-message cleanup** that corrects the spelling of `--index-pack-arg` (singular) in `git-http-fetch`’s man page and in the two error messages that enforce the option’s dependency on `--packfile`.

The change is purely textual: the plural `--index-pack-args` is replaced with the singular `--index-pack-arg` to match the actual command-line interface, which accepts one argument per `--index-pack-arg` option. The man page now also clarifies that the first instance specifies the command and subsequent instances specify its arguments.

No code behavior changes; the patch is a follow-up to Taylor Blau’s earlier review of the same typo in v1 and v4. It has been carried forward unchanged since v5 and is uncontroversial. The files touched are `Documentation/git-http-fetch.adoc` and `http-fetch.c`.
