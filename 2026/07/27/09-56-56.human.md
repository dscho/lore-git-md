This is the second patch in Shlok Kulshreshtha’s v2 **test infrastructure** series introducing the `commit_body()` helper. It mechanically replaces ~61 duplicated `git cat-file commit <rev> | sed -e '1,/^$/d'` patterns across 12 test scripts with calls to the new helper, plus removes one local wrapper (`message_body()` in `t7509-commit-authorship.sh`) that did the same thing.

The patch is a clean, well-scoped refactoring. Every conversion preserves byte-identical output and—critically—fixes the exit-code hole that motivated the series (noted in the prior bugfix `b6b276974e`). Two sites needed minor adjustments: `t7600-merge.sh` now greps the stripped body instead of the raw commit object, and `t3900-i18n-commit.sh` writes the body to a file before piping to `iconv` to keep the `&&`-chain intact. All converted scripts pass in full, and deliberate `git cat-file` failures now correctly fail tests that previously passed.

No open questions remain; this is the final piece of the series and looks ready for review. The files touched are the same 12 test scripts listed in the cover letter (`t3404`, `t3405`, `t3408`, `t3434`, `t3900`, `t4150`, `t7500`, `t7501`, `t7502`, `t7509`, `t7600`, `t7604`, `t7614`). The key name introduced is `commit_body()`; the temporary file `.commit` is an internal implementation detail.
