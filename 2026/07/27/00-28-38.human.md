This is a documentation and error-message patch, the first in Ted Nyman’s six-patch v6 series fixing packfile URI race conditions in Git’s HTTP transport. It corrects the `--index-pack-arg` option name in `git-http-fetch`’s man page and error messages, replacing the obsolete plural `--index-pack-args` form. The change is purely textual: the option has always been repeatable (one `--index-pack-arg` per argument), but the documentation and error messages incorrectly described it as singular and plural, respectively.

The patch touches only two files: `Documentation/git-http-fetch.adoc` and `http-fetch.c`. The man page now explains that `--index-pack-arg` can be given multiple times, and the error messages in `http-fetch.c` now refer to the correct option name. This is a minor but necessary cleanup that aligns the documentation with the actual behavior, making it easier for users and scripts to understand how to pass arguments to `index-pack` when using `--packfile` mode.

This patch has been stable since v1 of the series and has already received positive review feedback from Taylor Blau and others. It is uncontroversial and ready for merging. While it doesn’t fix any bugs itself, it paves the way for the rest of the series by ensuring the documentation is accurate before the more complex behavioral changes land.
