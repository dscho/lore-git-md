This is a bugfix for the pack-bitmap subsystem, specifically addressing an off-by-one edge case in `find_objects()`.

The patch corrects a logic error introduced in commit 11d45a6e6a, where the code checks `pos > 0` to determine if an object is already represented in the base bitmap. This check incorrectly excludes objects at position zero, causing unnecessary work: either reloading the object's individual reachability bitmap or redundantly adding it to the not-mapped list. The fix changes the condition to `pos >= 0`, treating position zero as valid.

The test update in `t/t5333-pseudo-merge-bitmaps.sh` adds an assertion for the expected bitmap hit count, covering the boundary condition.
