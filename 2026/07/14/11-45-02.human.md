This is a refactoring patch from the final v17 iteration of the `remote-object-info` feature series. It moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` to enable reuse by the upcoming `remote-object-info` command. The relocation is mechanical: the function body is unchanged, and the patch adds a forward declaration of `struct string_list` in `connect.h` since the function only uses it as a pointer. This is a preparatory step for patch 7/10, which generalizes the function to support arbitrary protocol commands. The change is uncontroversial and aligns with Git’s established patterns for code organization. Helped-by trailers credit Jonathan Tan and Christian Couder for design input.
