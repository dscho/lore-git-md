This is the sixth patch in Pablo Sabater’s seven-patch series implementing visual root indentation for `git log --graph`. The patch is a small, mechanical refactoring that moves the `log.graphcolors` configuration reading logic from `graph_init()` into a new helper function, `graph_read_config()`. The change is purely internal and has no user-visible behavior.

The motivation is to prepare for future graph-related configuration options, such as the `log.graphIndent` option introduced in patch 7/7. By isolating configuration reading in a dedicated function, the patch keeps `graph_init()` focused on initialization and makes it easier to add new settings later. The implementation is straightforward: the new `graph_read_config()` function is called at the start of `graph_init()`, preserving the existing initialization order. The patch touches only `graph.c`, adding 9 lines and removing 4.

This patch has been stable since v7 and has no unresolved feedback. It is uncontroversial and ready for final review. The only dependency is on the series’ earlier patches, which provide the context for why this refactoring is useful. The commit message clearly explains the purpose as preparatory work for patch 7/7.
