This is an announcement for a new Git for Windows release, version 2.55.0(3). Johannes Schindelin reports that this update includes Git Credential Manager v2.9.0 and, more critically, fixes heap overflows in the `wincred` credential helper (tracked under GHSA-rxqw-wxqg-g7hw). The security fix is the headline change here, making this a must-install for Windows users.

The release comes just twelve days after the previous Git for Windows version (2.55.0(2)), suggesting this is a targeted security update rather than a routine feature drop. All standard distribution formats are provided: installers for both x64 and ARM64, portable builds, MinGit variants, and tarballs, each with SHA-256 checksums for verification.

Note that this is a Git for Windows release, not an upstream Git release. The version number (2.55.0) matches the upstream Git release it is based on, but the build number (3) and the fixes are specific to the Windows fork. Users who rely on Git for Windows should upgrade promptly to address the credential-helper vulnerability.
