This is the seventh patch in Johannes Schindelin’s 11-patch series fixing unchecked return values flagged by Coverity. It targets a silent failure mode in the transport-helper subsystem: when `dup()` fails in `get_exporter()`, the code currently proceeds with `fastexport->out = -1`, which the child-process machinery misinterprets as a request to create a new pipe. The result is that fast-export output is sent to an unread pipe instead of back through the helper’s input fd. The fix adds a simple error check that propagates the failure upward, preventing the silent mis-wiring. The patch is mechanical, well-motivated, and uncontroversial.
