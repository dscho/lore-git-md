This is the first patch in René Scharfe’s 5-patch series introducing repository-aware variants of the tempfile and lockfile APIs as part of the `the_repository` removal effort. It adds `repo_create_tempfile_mode()` and its convenience wrapper `repo_create_tempfile()`, which take an explicit `struct repository *` parameter instead of implicitly using `the_repository`. The implementation is a thin layer: the new functions delegate to the existing `create_tempfile_mode()` internals, passing the supplied repository to `adjust_shared_perm()`. The patch touches only `tempfile.c` and `tempfile.h`, adding 18 lines and removing 1. No callers are converted yet; this is purely the API scaffolding. The change is mechanical and confined to plumbing, with no user-visible behavior change.
