This is a small, targeted bugfix patch in the seventeenth iteration of the `remote-object-info` feature series. It corrects a type mismatch in `fetch-pack.c` where `hash_algo_by_name()` (which returns `unsigned int`) was being assigned to an `int` variable. The fix changes the variable to `const unsigned int` to match the function's return type and adds `const` since the value is never modified.

The change is purely mechanical and localized to a single line, with no behavior impact. This addresses minor technical debt introduced during earlier refactoring in the series. The patch is uncontroversial and follows Git's established practice of type safety and const-correctness. It was previously identified as patch 14/14 in v16 of the series and has been carried forward into v17 as patch 4/13 (note the renumbering due to patch splitting in v16). The fix is part of the broader effort to ensure memory safety and type correctness across the series, which is now ready for merging to `next`.
