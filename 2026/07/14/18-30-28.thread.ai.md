Subject: [PATCH] show-branch: use commit-slab for per-commit state instead of object.flags

Core problem or goal
Refactor `builtin/show-branch.c` to stop using the shared `object.flags` field for per-commit state, replacing it with a dedicated commit-slab (`commit_rev_flags`). This eliminates the risk of flag-bit collisions with other subsystems and aligns the code with Git’s canonical pattern for per-commit data storage.
