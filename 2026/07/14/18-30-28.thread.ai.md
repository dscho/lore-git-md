Subject: [PATCH v2] show-branch: use commit-slab for per-commit state instead of object.flags
Series version: v3 (standalone patch, supersedes v2 by Gatla Vishweshwar Reddy and an earlier RFC by Meet Soni)
Originating author: Gatla Vishweshwar Reddy
Thread type: refactoring patch

Core problem or goal
Refactor `builtin/show-branch.c` to eliminate its reliance on the shared `object.flags` field for per-commit state, replacing it with a dedicated commit-slab (`commit_rev_flags`) that uses a configurable stride of `uint64_t` words. This removes the risk of flag-bit collisions with other subsystems, aligns the code with Git’s canonical pattern for per-commit data storage, and lifts the previous 27-branch limit to 64 branches (with a path forward for dynamic stride to support even more branches). The `UNINTERESTING` bit remains in `object.flags` for revision-walking compatibility.

Current status
Under review. This is the third iteration of the patch, addressing Junio C Hamano’s and Jeff King’s (Peff) conceptual feedback on v2: the slab now uses a configurable stride (initialized to 1, providing 64 bits), the `UNINTERESTING` bit is kept in `object.flags`, and all bit operations use `UINT64_C(1)` for correct 64-bit shifts. The patch preserves existing behavior, passes all tests, and is ready for re-review. No merge status reported; the patch remains in the review phase.

Key technical details
- Files touched: `builtin/show-branch.c` only
- New symbols: `commit_rev_flags` slab (configurable stride of `uint64_t` words), `get_rev_flags_ptr()`, `or_rev_flag_bit()`, `test_rev_flag_bit()`, `has_all_rev_flags()` helpers
- Old behavior: direct access to `commit->object.flags` for per-commit state, limited to 27 branches due to 32-bit storage
- New behavior: slab-based storage with configurable stride (64 bits by default), lifting the branch limit to 64, with infrastructure for dynamic stride to support more branches. The `UNINTERESTING` bit remains in `object.flags` for revision-walking compatibility.
- Test coverage: unchanged (existing tests continue to pass)
