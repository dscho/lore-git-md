This is the **lookahead buffer implementation** in Pablo Sabater’s **v12 series** adding visual root indentation to `git log --graph`. This is patch **3/7**, the architectural core of the series, and it introduces a **two-slot lookahead buffer** in `struct git_graph` to safely peek ahead during revision traversal.

The patch adds **84 lines** across `graph.c`, `graph.h`, and `revision.c`, implementing a FIFO queue (`lookahead[2]`) that is populated by `get_revision()` via `next_commit_to_show()` (introduced in patch 2/7). The buffer ensures commits are fully simplified before inspection, addressing the key technical challenge of determining whether a commit is a visual root without breaking parent-child relationships. The patch wires the buffer into `graph_is_interesting()`, treating buffered commits as "interesting" to maintain correct graph topology, and introduces three new helper functions: `graph_pop_lookahead()`, `graph_get_lookahead_room()`, and `graph_push_lookahead()`, each guarded by BUG assertions to enforce buffer invariants.

The implementation is **mechanically sound** and **architecturally approved** by Junio Hamano and Kristofer Karlsson. It excludes the `--reverse` branch to avoid side effects and couples only to `next_commit_to_show()` (patch 2/7), which ensures commits are fetched from the correct source (revision walk or saved list for `--max-count-oldest`). The patch is **prerequisite for patch 4/7** (visualization logic) and has been stable since v7, with no changes in v12. The commit message clearly explains the motivation (peeking two commits ahead for visual root detection) and the implementation strategy (pre-fetching in `get_revision()`).

No user-visible behavior changes are introduced; this is **pure infrastructure**. The patch is **low-risk** and **uncontroversial**, with all prior feedback addressed in earlier revisions. The only interaction with other subsystems is the coupling to `next_commit_to_show()`, which is itself a mechanical refactoring (patch 2/7). The lookahead buffer is the **critical enabler** for the indentation feature, and its design has been finalized since v7.
