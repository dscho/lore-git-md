This is an **announcement email for Git for Windows**, not a patch or technical discussion for the upstream Git project. Johannes Schindelin announces the release of Git for Windows 2.55.0(3), a bugfix update to the Windows-specific distribution of Git.

The update includes Git Credential Manager v2.9.0 and fixes heap overflows in the `wincred` credential helper (tracked under GHSA-rxqw-wxqg-g7hw). The changelog is minimal, focusing on security and credential management. Download links and SHA-256 checksums are provided for all variants (64-bit, ARM64, 32-bit, portable, MinGit, and BusyBox-based builds).

This email is purely informational for users and packagers of Git for Windows. It does not propose changes to upstream Git, nor does it require review or discussion on the Git mailing list. The fixes are specific to the Windows port and its bundled credential helper.
