This is patch 6/10 in the v12 series migrating global configuration variables into `struct repo_config_values` as part of the ongoing libification effort. It moves the `apply_default_whitespace` and `apply_default_ignorewhitespace` variables—used by `git apply` to store default whitespace settings—into the repository-scoped configuration struct, eliminating their global declarations.

The patch updates `git_apply_config()` to accept a `struct repository *` parameter (removing its reliance on `the_repository`), adds the two fields to `struct repo_config_values`, and ensures proper memory management by freeing old values via `FREE_AND_NULL()` in the config parser and the `repo_config_values_clear()` destructor. The `init_apply_state()` function is updated to use the repository-scoped values, and a cached `repo_config_values()` call avoids redundant lookups. The style fix from v12 (moving the `cfg` declaration to the start of the block in `init_apply_state()`) is included, resolving the `-Wdeclaration-after-statement` warning.

This is a clean, mechanical refactoring with no user-visible behavior changes. The patch is CI-clean and addresses all prior feedback, including the style nit from Junio.
