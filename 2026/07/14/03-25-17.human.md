This is the second patch in Tian Yuchen’s v12 series (10 patches total) that continues the `the_repository` removal effort by migrating global configuration variables into `struct repo_config_values`. This patch moves the `excludes_file` global variable into the repository-specific configuration struct and introduces a proper getter, `repo_excludes_file()`, to encapsulate the lazy-loading fallback logic that assigns the XDG default path when the variable is NULL.

The patch is a clean refactoring with no user-visible behavior changes. It touches `dir.c`, `environment.c`, and `environment.h`, replacing direct access to the global `excludes_file` with calls to the new getter. The getter caches the result of `repo_config_values(repo)` and handles the XDG default path assignment, preserving the existing logic while centralizing memory management. The `excludes_file` field is properly freed during repository teardown via the `repo_config_values_clear()` destructor introduced in patch 1/10.
