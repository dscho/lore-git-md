This is an announcement for **Git for Windows 2.55.0(3)**, a bugfix release of the Windows-specific distribution of Git. Johannes Schindelin reports that the update includes Git Credential Manager v2.9.0 and fixes heap overflows in the `wincred` credential helper (GHSA-rxqw-wxqg-g7hw). The changes are limited to security and credential management improvements and do not affect upstream Git. Download links and checksums are provided for all build variants. No action or discussion is needed on the Git mailing list, as this is purely informational for users and packagers of Git for Windows.
