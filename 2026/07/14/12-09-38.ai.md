This is the **final patch (7/7)** in Pablo Sabater’s **v12 series** implementing **visual root indentation for `git log --graph`**, introducing an **opt-out mechanism** via the `--[no-]graph-indent` flag and `log.graphIndent` configuration. The patch is **mechanically finalized** and **ready for review**, with no unresolved technical or usability questions.

The patch adds two new user-facing controls:
- **`log.graphIndent`** (config variable): Defaults to `true`, enabling indentation. Users can disable it globally with `git config log.graphIndent false`.
- **`--[no-]graph-indent`** (command-line flag): Overrides the config setting for a single invocation. The flag requires `--graph` and errors if used without it.

The implementation is **minimal and robust**:
- Two boolean fields (`no_graph_indent` and `graph_indent_set`) are packed into `struct rev_info` as bitfields, avoiding memory bloat.
- The config is read in `graph_read_config()` (introduced in patch 6/7), preserving the existing initialization order.
- Indentation logic in `graph.c` (`graph_needs_pre_root_line()` and `graph_output_commit_line()`) checks `graph->revs->no_graph_indent` to skip indentation when disabled.
- Documentation updates (`Documentation/config/log.adoc` and `Documentation/rev-list-options.adoc`) clearly describe the new options and their interaction.

**Test coverage** is thorough:
- Three new tests in `t4218-log-graph-indentation.sh` verify:
  1. `--no-graph-indent` disables indentation.
  2. `log.graphIndent=false` disables indentation.
  3. `--graph-indent` overrides `log.graphIndent=false`.
- Tests use the `lib_test_check_graph` helper (introduced in patch 1/7) to validate exact graph output.

**Mechanical feedback from v11** is fully addressed:
- Fixed typos in `Documentation/rev-list-options.adoc` ("deafault" → "default", "graph.indent" → "log.graphIndent").
- Corrected a boolean check in `revision.c` (`revs->graph_indent_set > 0` → `revs->graph_indent_set`).
- Updated a test comment to clarify the default state ("log.graphIndent unset" instead of "graph.indent true").

The patch is **low-risk** and **self-contained**, touching only `graph.c`, `revision.c`, and documentation. It depends on the **lookahead buffer** (patch 3/7) and **visual root detection logic** (patch 4/7) but does not modify their behavior. The **four-level wrap** (patch 5/7) and **configuration refactoring** (patch 6/7) are prerequisites but are already stable.
