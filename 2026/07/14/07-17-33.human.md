This is a short follow-up exchange in the ongoing review of Patrick Steinhardt’s ODB abstraction series. Jeff King (Peff) and Taylor Blau agree that the current inconsistency between `traverse_bitmap_commit_list()` (which allows early termination via callback return values) and `traverse_commit_list()` (whose callbacks return `void`) should be addressed, but not as part of this series. Instead, Taylor proposes a targeted cleanup: splitting the callback type used by `for_each_bitmapped_object()` from `show_reachable_fn`, preserving the abortable behavior for bitmapped object iteration while making `show_reachable_fn` return `void`. This avoids large-scale refactoring and keeps the two traversal functions consistent without changing the non-bitmap machinery. Peff notes that the feasibility depends on whether any callbacks actually rely on the abort feature, but the tone is collaborative and forward-looking. The exchange confirms that the design question is resolved and that Taylor has a follow-up series ready to implement the change. No new objections or technical concerns are raised.
