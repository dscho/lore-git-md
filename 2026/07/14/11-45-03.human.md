This is a refactoring patch that generalizes an existing function to support multiple Git wire protocol commands. The patch renames `write_fetch_command_and_capabilities()` to `write_command_and_capabilities()` and adds a `command` parameter, replacing the hardcoded "fetch" string with a format placeholder. This is a purely mechanical change that enables the function to be reused by other protocol commands, such as the `remote-object-info` feature introduced elsewhere in this series.

The patch updates the function signature, modifies the call sites in `fetch-pack.c` to pass "fetch" explicitly, and expands the documentation in `connect.h` to clarify the function's purpose. The core logic remains unchanged, and the changes are localized to three files. This refactoring is uncontroversial and has been stable across the last two iterations of the series (v16 and v17), with Helped-by trailers crediting Jonathan Tan and Christian Couder for design input.

This patch is part of the larger effort to implement `git cat-file --batch-command remote-object-info`, which allows querying object metadata from remotes without downloading full objects. The generalization here is a preparatory step for integrating the `object-info` command into the same protocol infrastructure used by `fetch`.
