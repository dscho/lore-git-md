This is a small refactoring patch from René Scharfe targeting the `strbuf` API, specifically the `strbuf_getwholeline()` function. The patch removes a redundant `strbuf_reset()` call in the `HAVE_GETDELIM` code path. René explains that the reset is unnecessary because `getdelim(3)` doesn’t care about the buffer’s prior contents or length, and the function already handles buffer initialization or reset on both success and error paths. The change is confined to a single line deletion in `strbuf.c` and carries no behavior change—it’s purely a cleanup to eliminate an extra operation. Given René’s track record of sending precise, mechanical cleanups, this looks like a safe and uncontroversial improvement.
