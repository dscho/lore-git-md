This is the ninth patch in the seventeenth iteration of a security-hardened feature series that adds `remote-object-info` support to `git cat-file --batch-command`. The patch enables servers to advertise their support for the `object-info` capability, controlled by the `transfer.advertiseobjectinfo` configuration (disabled by default).

The implementation updates both the protocol documentation and the server-side code. In `gitprotocol-v2.adoc`, the patch clarifies protocol requirements by explicitly mandating full object IDs (no short OIDs), fixes a parenthesis mismatch, defines `obj-size` as a numeric field, and documents that servers return only the object ID (with no metadata) for unrecognized objects. The server-side change in `serve.c` populates the capability value with "size" when `transfer.advertiseobjectinfo` is enabled, following the documented space-separated attribute list format.

This is a preparatory patch that directly enables the client-side functionality introduced in later patches. The changes are mechanical and align with the series' security-focused design, including the default-disabled configuration and strict protocol documentation. The patch carries `Helped-by` trailers from Jonathan Tan and Christian Couder, indicating substantive review input. No behavioral changes occur until clients explicitly request the `object-info` capability.
