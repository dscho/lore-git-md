This is part of a refactoring series (v12, patch 6/10) that continues the ongoing `the_repository` removal effort by migrating global configuration variables into `struct repo_config_values`. The series as a whole is now complete and ready for `next`, addressing all prior feedback.

This specific patch migrates the `apply_default_whitespace` and `apply_default_ignorewhitespace` variables—used by `git apply` to store default whitespace handling settings—into `struct repo_config_values`. The patch updates `git_apply_config()` to accept a `struct repository *` parameter instead of relying on the global `the_repository`, and ensures proper memory management by freeing the old values before reassigning them in the config parser. The destructor (`repo_config_values_clear()`) is extended to free these fields, maintaining consistency with the rest of the series.

The patch also includes the style fix requested in earlier reviews: the declaration of `struct repo_config_values *cfg` in `init_apply_state()` is now at the start of the block, avoiding the `-Wdeclaration-after-statement` warning. This is a minor but necessary adjustment to comply with Git’s C coding guidelines.
