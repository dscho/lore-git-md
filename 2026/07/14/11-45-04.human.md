This is a refactoring patch in the security-hardened `git cat-file --batch-command` series that adds remote object metadata querying. This is the eighth of ten patches in the seventeenth iteration of the series, which is now complete and ready for merging.

The patch moves the initialization of three variables (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) from the `FETCH_CHECK_LOCAL` state to the function prologue of `do_fetch_pack_v2()` in `fetch-pack.c`. This is a purely mechanical change that ensures the variables are set regardless of the initial state, which becomes necessary when a later patch introduces an alternative initial state for the `remote-object-info` command. The moved code block is identical before and after, and the change has no impact on behavior.

The patch is authored by Calvin Wan but carries sign-offs from Eric Ju and Pablo Sabater, reflecting the collaborative nature of this series. Helped-by trailers credit Jonathan Tan and Christian Couder for design input. This refactoring is uncontroversial and stable, appearing identically in both the sixteenth and seventeenth versions of the series.

This change is preparatory work for the core `remote-object-info` command implementation that appears later in the series. By moving these initializations out of the state-specific block, the code becomes more robust when new initial states are introduced, while maintaining the exact same behavior for existing callers. The patch demonstrates the series' careful attention to code structure and maintainability.
