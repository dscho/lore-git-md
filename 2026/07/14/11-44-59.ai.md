This is a test infrastructure refactoring patch that extracts three utility functions (`echo_without_newline`, `echo_without_newline_nul`, and `strlen`) from `t/t1006-cat-file.sh` into a new shared library file `t/lib-cat-file.sh`. The change is purely mechanical, moving the functions verbatim with no behavior modification. This is the third patch in the seventeenth iteration of a security-focused series that implements `git cat-file --batch-command` support for querying remote object metadata.

The patch enables code reuse in later patches, particularly for the `remote-object-info` command implementation. It follows Git's established practice of centralizing test helpers (e.g., `lib-loose.sh`) and has no impact on core functionality. The extracted functions are simple shell utilities for string manipulation, and their relocation is uncontroversial. This preparatory step was incorporated into Pablo Sabater's v17 resend after being authored by Eric Ju. The series is now technically complete and ready for merging to `next`.
