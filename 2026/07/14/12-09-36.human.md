This is the fifth patch in Pablo Sabater’s **v12 series** implementing visual root indentation for `git log --graph`. The patch introduces a **four-level wrap** for cascading commits, preventing indefinite indentation and resolving symmetry-induced ambiguity in edge cases.

The change modifies `graph_update()` to reset the `visual_root_cascade` flag when the visual root depth reaches a multiple of four, forcing the next commit to indent normally if it is not itself a visual root. The indentation calculation in `graph_output_commit_line()` now uses `(depth - cascade) % 4` to ensure consistent wrapping. The patch also handles an ambiguous case where a non-root commit would otherwise align vertically with a wrapped root by forcefully indenting the wrapped commit one additional level.

The commit message clearly explains the motivation (avoiding visual clutter in filtered views like `--author`) and the edge case (ambiguous vertical alignment). The **magic number 4** is justified as the minimum wrap level that balances clarity and compactness. The new test in `t4218-log-graph-indentation.sh` verifies the wrap with a ten-commit sequence of orphaned roots, including the ambiguous case.
