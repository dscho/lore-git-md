This is a refactoring patch that moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` as part of the `remote-object-info` feature series. The patch is the sixth of ten in the seventeenth iteration (v17) of this security-focused effort.

The move is preparatory: the function will be generalized in the next patch to support arbitrary protocol commands (not just "fetch"), making it reusable for the new `remote-object-info` command. The relocation to `connect.c` is logical since that file already contains similar protocol-handling functions. The patch uses a forward declaration of `struct string_list` in `connect.h` to avoid including the full header, since the function only uses it as a pointer.

The change is purely mechanical—no behavior is modified. The function body is moved verbatim, and the only additions are the forward declaration in the header and the function prototype. Helped-by trailers credit Jonathan Tan and Christian Couder for design input, indicating this was a coordinated architectural decision rather than an ad-hoc refactor.

This patch is uncontroversial and stable; it appeared identically in v16 (as patch 6/13) and has not changed in v17. The series as a whole is now ready for merging to `next`, with all substantive review feedback addressed.
