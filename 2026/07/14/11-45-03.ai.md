This is patch 7/10 in the seventeenth iteration of a security-hardened feature series that adds `remote-object-info` support to `git cat-file --batch-command`. The patch refactors `write_fetch_command_and_capabilities()` in `connect.c` to make it more generic, enabling reuse by both the existing fetch command and the new `object-info` command introduced later in the series.

The change is purely mechanical and preparatory: the function is renamed to `write_command_and_capabilities()`, its signature is updated to accept an arbitrary command string, and the hardcoded "fetch" string is replaced with a format placeholder. The patch also expands the function's documentation in `connect.h` to clarify its purpose. Call sites in `fetch-pack.c` are updated to pass "fetch" explicitly, maintaining existing behavior. Helped-by trailers credit Jonathan Tan and Christian Couder for design input.

This refactoring is uncontroversial and stable, appearing identically in both v16 and v17 of the series. It directly enables the `remote-object-info` command implementation in patch 10/10 by allowing the same function to construct protocol requests for both fetch and object-info operations. The patch touches only three files (`connect.c`, `connect.h`, and `fetch-pack.c`) and makes no behavioral changes.
