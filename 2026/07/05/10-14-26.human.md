This is an announcement for **Guilt v0.37.1**, a third-party tool that layers a Mercurial Queues-like workflow on top of Git.

Guilt is a collection of POSIX shell scripts that let users manage patch stacks in a Git repository. The project had been unmaintained for some time, but Frediano Ziglio has taken over as maintainer with the blessing of the previous maintainer, Jeff. Development has moved to GitHub, and the release includes prebuilt binaries and updated documentation.

The new version adds several small features: a `guilt rename` command, a `guilt goto` command, and new `-n` (number) and `-m` (missing) options for `guilt series`, plus a `-C` (context) option for `guilt push`. It also fixes bugs in `guilt delete`, improves reflog messages, and optimizes several internal operations. The project remains committed to POSIX shell and broad platform compatibility (Linux, FreeBSD, Darwin, SunOS).

This is not a patch to Git itself, so it won’t appear in Git’s integration branches. If you use Guilt, the update is worth a look; if you don’t, it’s just a heads-up that the tool is active again.
