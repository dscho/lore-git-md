This is the seventh patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs a memory leak in `get_superproject_working_tree()` (in `submodule.c`) where the current working directory buffer (`cwd`) allocated by `xgetcwd()` was not freed on two early-return paths: when Git is not inside a work tree, and when `strbuf_realpath(&one_up, "../", 0)` fails. The fix redirects both early returns through a new `out:` label that releases `cwd` (and the `sb` and `one_up` strbufs) before returning. The patch is small, mechanical, and clearly correct; it carries no user-visible behavior change and is ready for merging.
