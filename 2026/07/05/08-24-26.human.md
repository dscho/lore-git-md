This is the ninth patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs a memory leak in the IMAP upload code (`imap-send.c`): the `msgbuf` strbuf that accumulates each message across loop iterations was never released. The fix adds a single `strbuf_release(&msgbuf.buf)` call alongside the existing libcurl cleanup. The change is mechanical, well-scoped, and carries no risk of regression. Junio has already indicated he will queue the entire series, and this patch is uncontroversial.
