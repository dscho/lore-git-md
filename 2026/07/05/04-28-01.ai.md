This is a small feature patch introducing a short synonym `--sstat` for the existing `--compact-summary` option in `git diff`. The patch comes from Junio C Hamano, the project maintainer, and is motivated by his personal workflow preference: he finds `--compact-summary` (which combines the functionality of `--stat` and `--summary`) more useful than `--stat` alone and wants a shorter way to invoke it.

The change is minimal: it adds `--sstat` as a hidden alias for `--compact-summary` in the diff option parser, updates the documentation to list the new synonym, and adds test coverage for the new option in the existing test scripts `t4000-diff-format.sh` and `t4013-diff-various.sh`. Two new test files are created to verify the output format of `git diff-tree` with `--sstat`.

The patch touches the `diff.c` source file, the `diff-options.adoc` man page, and the test suite. The implementation reuses the existing `diff_opt_compact_summary` callback, so there is no new logic beyond the alias registration. The commit message includes a before-and-after comparison of `format-patch` output to illustrate the difference between `--stat --summary` and `--compact-summary` (now `--sstat`), though the patch itself does not modify `format-patch`.

This is a user-visible feature addition, but it is backward-compatible and does not change existing behavior. The new option is hidden (marked with `PARSE_OPT_HIDDEN`), meaning it will not appear in help output by default, which may limit its discoverability. The patch is self-contained and does not appear to be part of a larger series.
