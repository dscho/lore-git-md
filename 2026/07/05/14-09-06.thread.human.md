Trevor Gross’s patch series proposing a `-x` flag for `git rebase -i` to append "(cherry picked from commit ...)" lines—mirroring `git cherry-pick -x`—has sparked a fundamental design debate. The thread began with Junio C Hamano’s high-weight objection that the feature misaligns with `git rebase`’s core purpose of *moving* history (rewriting commits to a new base) rather than *duplicating* it (as `git cherry-pick` does). This tension remains unresolved, and the series is still under review with no merge status.

The latest turn comes from Jeff King (Peff), who deepens the design critique. Peff argues that the `-x` flag’s utility is inherently undermined in a rebase workflow, where original commits are discarded, rendering the origin annotation meaningless. Instead, he proposes an alternative: extending `git cherry-pick` with an interactive mode (`cherry-pick -i`) to allow mid-operation todo list edits, leveraging the fact that `cherry-pick` already uses the sequencer backend and generates a todo file (`.git/sequencer/todo`). This approach would address the user pain point—lacking a native way to record commit origins during cherry-picks—without conflating rebase and cherry-pick semantics. Peff also highlights a behavioral inconsistency: `cherry-pick -x` applies globally via a sequencer option, while Trevor’s patch allows per-command `-x` flags in the rebase todo list, suggesting harmonization by having `cherry-pick -x` auto-populate the todo file with `-x` flags.

The thread now faces a fork in the road. Trevor must either defend the rebase-centric design (e.g., by demonstrating use cases where origin annotations remain useful despite rebasing) or pivot toward Peff’s `cherry-pick -i` proposal, which would require a separate patch series. Matt Hunter’s earlier substantive review also remains open, noting a pre-existing uninitialized memory bug in `do_pick_commit()` exposed by Trevor’s patch—a fix that may need to be split into its own patch to avoid conflating it with the feature work. The series’ future hinges on resolving these design and technical loose ends.
