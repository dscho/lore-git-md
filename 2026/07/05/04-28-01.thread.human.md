This thread introduces a small but convenient feature to Git: a shorter synonym `--sstat` for the existing `--compact-summary` option in `git diff`. The patch comes directly from Junio Hamano, the project maintainer, who wants a quicker way to invoke the combined `--stat` and `--summary` output in his own workflow.

The change is minimal and backward-compatible. It adds `--sstat` as a hidden alias (so it won’t clutter help output) in the diff option parser, updates the documentation, and includes test coverage to verify the new option works as expected. The implementation reuses existing logic, so there’s no new behavior—just a new name for an existing feature. The patch touches `diff.c`, the man page, and a couple of test scripts, but doesn’t affect any other commands like `format-patch`.

Since this is a maintainer-driven feature with no open questions or objections, it’s likely to be merged soon. The only minor caveat is that the option is hidden, which might limit its adoption, but that’s intentional to avoid cluttering the interface. No further discussion or changes appear needed.
