This is the third patch in Johannes Schindelin’s 12-patch v2 series fixing Coverity-identified resource leaks and error-path bugs in Git. It plugs a file-descriptor leak in `download_https_uri_to_file()` (in `bundle-uri.c`) by ensuring the `child_out` file handle is closed when `finish_command(&cp)` fails. The fix is a one-line change: moving the `fclose(child_out)` call before the `return 1` statement so that it executes unconditionally on the error path. The patch is mechanical, well-scoped, and carries no user-visible behavior changes—purely an internal correctness fix. It touches only the bundle URI download logic, which is used when fetching bundle lists over HTTPS, and is unlikely to interact with other subsystems. The series as a whole has strong maintainer approval (Junio stated he will queue it), and this patch in particular is straightforward and uncontroversial.
