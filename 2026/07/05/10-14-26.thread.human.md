This is an announcement for **Guilt v0.37.1**, a third-party tool that brings a Mercurial Queues-like workflow to Git. Guilt, a collection of POSIX shell scripts, had been unmaintained for years but has now been revived under new maintainership (Frediano Ziglio) with the previous maintainer's blessing. Development has moved to GitHub, where the code, documentation, and prebuilt binaries are now hosted.

The new release introduces several improvements, including new commands (`guilt rename`, `guilt goto`) and options (`guilt series -n/--number`, `-m/--missing`; `guilt push -C/--context`), along with enhancements to `guilt delete`, reflog messages, patch name handling, and performance. The project remains committed to its original design: a POSIX shell implementation using standard system tools, ensuring cross-platform compatibility (Linux, FreeBSD, Darwin, SunOS).

While Guilt is not part of the Git project itself, the announcement is shared on the Git mailing list due to its relevance to users who rely on patch-stack workflows. This release appears to be a well-maintained update to a long-standing but niche tool in the Git ecosystem.
