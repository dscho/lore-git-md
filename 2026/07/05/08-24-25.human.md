This is the eighth patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs four memory leaks in `git worktree add` that occur when `run_command()` fails while creating a new branch.

The function allocates four strings (`path`, `opt_track`, `branch_to_free`, and `new_branch_to_free`) early on, but if the `run_command(&cp)` call at line 948 fails, it returns -1 immediately without freeing them. The fix redirects the error return through the existing `cleanup:` block at the end of the function, ensuring all four allocations are released. The change is mechanical—just two lines added—and carries no user-visible behavior change. It touches only `builtin/worktree.c` and is covered by existing tests.
