This is the first patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs a resource leak in `load_one_loose_object_map()` (`loose.c`) by ensuring the `FILE *fp` handle is closed on all error paths. The v2 revision replaces the unsafe `errno`-based error detection (`return errno ? -1 : 0`) with an explicit `ferror(fp)` check (`ret = ferror(fp) ? -1 : 0`), addressing Junio C Hamano’s correctness concern from the v1 review. The patch also consolidates cleanup code into a single `err:` exit path, reducing near-duplicate code. No user-visible behavior changes; the fix is purely internal and covered by existing tests. The revised version carries strong maintainer approval and is queued for merging.
