This is the sixth patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs two memory leaks in `read_one_dir()` (in `dir.c`), a low-level function that parses untracked-cache extensions. When the function returns early due to malformed input, it now frees the `ud.untracked` and `ud.dirs` arrays that were allocated just before the error. The fix is minimal: two `free()` calls added to the existing error paths. No new tests are needed because the leaks are purely internal and the existing untracked-cache tests already exercise the code. Jeff King (Peff) independently confirmed the leak’s existence and the fix’s correctness, so this patch is uncontroversial and ready to merge.
