This is a build-system issue report from a user. Kurt Mielke reports that Git 2.55.0 fails to build on AlmaLinux 10 because the build process now requires `cargo` (the Rust package manager), which is not installed by default. Git 2.54.0 built successfully without it.

The user worked around the problem by setting `NO_RUST=1` during the build, which disables Rust support. They suggest that Rust should not be a default dependency, noting that they have no commands in their `PATH` beginning with "rus" (implying no Rust toolchain is present).

This is not a patch or a review—it’s a user support request. The report is clear and includes the error message, the workaround, and the system context. It may prompt discussion about whether Rust should be a mandatory build dependency or if the build system should better detect its absence and degrade gracefully. For now, the issue is straightforward: Git 2.55.0 introduced a new build-time dependency that breaks builds on systems without Rust installed.
