This is the first patch in Johannes Schindelin’s v2 series of Coverity-driven leak fixes. It plugs a file-descriptor leak in `load_one_loose_object_map()` in `loose.c` by ensuring the `FILE *fp` is always closed on error. The v2 revision replaces the unsafe `errno`-based error detection (`return errno ? -1 : 0`) with an explicit `ferror(fp)` check (`ret = ferror(fp) ? -1 : 0`), addressing Junio C Hamano’s correctness concern. The patch also consolidates the cleanup code into a single exit path, reducing duplication. It is a small, mechanical fix with no user-visible behavior change, and carries strong maintainer approval—Junio has already stated he will queue the series for merging.
