This is the tenth patch in Johannes Schindelin’s twelve-part v2 series fixing resource leaks and error-path bugs flagged by Coverity in Git’s codebase. The series as a whole has strong maintainer approval and is headed for merging.

This patch plugs a memory leak in the reftable backend’s `reftable_table_refs_for_unindexed()` function. When `reftable_buf_add()` fails, the cleanup path only releases the table iterator, leaving both the allocated `filter` struct and its internal `oid` buffer unreleased. The fix adds four lines to the `out:` label that free the `filter->oid` buffer and the `filter` itself, ensuring all resources are properly released. Coverity flagged this as CID 1671512.

The change is mechanical and well-scoped, touching only `reftable/table.c`. It carries no user-visible behavior changes and is covered by existing tests. The patch is part of a broader Coverity-driven cleanup effort that has already seen several patches reviewed and approved by Patrick Steinhardt, Jeff King, and Eric Sunshine. Junio C Hamano has stated he will queue the entire series for merging, so this patch is effectively ready to land.
