Trevor Gross’s `git rebase -i -x` patch series (v1) introduces a `-x` flag for `pick`, `reword`, and `edit` commands to append "(cherry picked from commit ...)" lines, mirroring `git cherry-pick -x`. The series remains under review, with Junio C Hamano’s high-weight substantive objection to the feature’s conceptual alignment with `git rebase` (moving vs. duplicating history) still unresolved. No merge status recorded.

**Core problem or goal**: Users performing cherry-picks during interactive rebases lack a native way to record commit origin, forcing them to use `exec git cherry-pick -x`, which disrupts the rebase flow. The patch integrates this functionality directly into rebase todo commands, reusing `TODO_RECORD_ORIGIN` logic from `git cherry-pick`.

**Current status**: v1 posted; under review. The thread’s future hinges on whether the author can reconcile the feature with rebase’s core semantics or propose an alternative design. Matt Hunter’s review surfaced a **pre-existing uninitialized memory bug** in `do_pick_commit()` that Trevor’s patch exposes (but does not introduce). The fix (`struct todo_item item = { 0 }`) is correct, but the commit message should clarify that it addresses latent technical debt rather than a regression. This may warrant splitting the initialization fix into a separate patch to avoid conflating it with the feature work.

**Key technical details**:
- Files touched: `rebase-interactive.c`, `sequencer.c`, `t/t3404-rebase-interactive.sh`.
- New flag: `-x` for `pick`, `reword`, and `edit` commands in rebase todo list, parsed as an argument (e.g., `pick 123456 -x`).
- Behavior: Appends "(cherry picked from commit ...)" to commit messages, reusing `TODO_RECORD_ORIGIN` logic. Fast-forwards skip the message (documented difference from `git cherry-pick -x`).
- Edge cases: Struct initialization (`struct todo_item item = { 0 }`) fixes a latent bug in `do_pick_commit()`; error handling for malformed todo lines (e.g., `pick -xabcdef 123456`) remains unresolved; parsing ambiguity between `-x` as a flag vs. argument persists.
- Test coverage: Verifies flag works with all three commands and checks output format.
