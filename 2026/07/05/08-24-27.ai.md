This is the tenth patch in Johannes Schindelin’s v2 twelve-patch series that plugs resource leaks and error-path bugs flagged by Coverity.
It fixes a memory leak in the reftable backend: when `reftable_table_refs_for_unindexed()` calls `reftable_buf_add()` and that call fails, the function jumps to the `out:` label, which only cleans up the table iterator (`ti`) but leaves both the `filter` allocation and the `filter->oid` buffer unreleased.
The patch adds four lines to the `out:` block that release `filter->oid` and free `filter` if it is non-NULL, ensuring all resources are properly cleaned up on the error path.
