This is a small feature patch from Junio C Hamano that adds a short synonym `--sstat` for the existing `--compact-summary` option in `git diff`. The new option is intended to make the command easier to type, as Junio notes he now uses `--compact-summary` frequently in place of the older `--stat` or `--stat --summary` combinations.

The patch updates the documentation to list `--sstat` alongside `--compact-summary`, adds the new option to the diff option parser (marked as hidden to avoid cluttering help output), and extends the test suite to verify the option works in various contexts. The diff output itself is unchanged—`--sstat` behaves identically to `--compact-summary`, producing a condensed summary of file creations, deletions, and mode changes.

This is a straightforward quality-of-life improvement with no behavioral changes. The patch is well-contained, touching only the diff subsystem, and includes test coverage for the new option. Given Junio’s role as maintainer and the minimal scope, this is likely to be uncontroversial and merge quickly.
