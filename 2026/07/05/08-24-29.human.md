This is the final patch in Johannes Schindelin’s 12-patch v2 series fixing Coverity-flagged resource leaks and error-path bugs in Git. It targets Windows-specific code and resolves a handle-leak and use-after-free in the process termination logic.

The patch pins down ownership of the process `HANDLE` passed to `exit_process()` and `terminate_process_tree()`: both functions now unconditionally close the handle on every return path. This removes the inconsistency where `exit_process()` leaked the handle on early returns (when `GetExitCodeProcess()` failed or the process was still active) while `terminate_process_tree()` always closed it. The fix also deletes a redundant `CloseHandle(h)` call in `mingw_kill()` that was causing a double-close on error paths, which Coverity flagged as CID 1437238 (“use-after-free”).

The change is minimal (two lines added, three removed) and touches only Windows compatibility code (`compat/mingw.c` and `compat/win32/exit-process.h`). It carries no user-visible behavior change and is purely an internal correctness fix. The patch is part of a well-reviewed series that Junio C Hamano has already stated he will queue for merging.
