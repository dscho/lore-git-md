This is the second patch in Johannes Schindelin’s 12-patch v2 series addressing Coverity-identified resource leaks and error-path bugs in Git. The patch fixes a latent bug in `loose.c`’s `write_one_object()` function where an unconditional `close(fd)` on the error path could attempt to close `fd = -1` if `open()` failed, triggering undefined behavior per POSIX and potentially confusing sanitizer builds. The fix is a simple guard: `if (fd >= 0) close(fd)`.

The patch touches only `loose.c`, changing a single line in the error-handling path of `write_one_object()`. This fix is purely internal and does not affect user-visible behavior or on-disk formats.
