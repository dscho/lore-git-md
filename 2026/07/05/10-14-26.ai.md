This is an **announcement** for **Guilt v0.37.1**, a third-party tool that provides a Mercurial Queues-like workflow for Git.

The email announces a new minor release of Guilt, a collection of POSIX shell scripts that emulate Mercurial Queues (MQ) functionality within Git. The project had been unmaintained for some time but has been revived under new maintainership (Frediano Ziglio) with the blessing of the previous maintainer (Jeff). Development has moved to GitHub, where the code, documentation, and prebuilt binaries are now hosted.

Key changes in this release include new commands (`guilt rename`, `guilt goto`) and options (`guilt series -n`/`--number`, `-m`/`--missing`; `guilt push -C`/`--context`), along with improvements to `guilt delete`, reflog messages, patch name handling, and performance optimizations. The project remains committed to its original design principles: POSIX shell implementation, reliance on standard system tools, and cross-platform compatibility (Linux, FreeBSD, Darwin, SunOS).

This is not a patch or contribution to the Git project itself—Guilt is a separate tool—but the announcement is posted to the Git mailing list due to its relevance to Git users who may rely on or be interested in patch-stack workflows. The release appears to be a well-maintained update to a niche but long-standing tool in the Git ecosystem.
