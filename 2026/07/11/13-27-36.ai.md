This is the first patch in the **ready-to-merge v6 series** optimizing `paint_down_to_common()` for one-sided histories. It adds a **new technical document** (`Documentation/technical/paint-down-to-common.adoc`) explaining the algorithm, generation-number regions, termination conditions, and edge cases (e.g., date-ordering fallback) in detail. The document is **175 lines** and covers use cases (merge-base computation vs. ancestry checks), the paint-walk algorithm, INFINITY vs. finite generation regions, termination logic (stale entries, generation cutoff, single-result optimization), and the commit-date fallback for v1 commit-graphs.

The patch also updates `Makefile` and `meson.build` to include the new document in the build system and adds a cross-reference in `commit-reach.c`. **No code changes** are made to the algorithm itself; this is purely documentation. The document is **comprehensive** and will serve as a reference for future maintainers, addressing a long-standing gap in Git’s technical documentation for merge-base computation.
