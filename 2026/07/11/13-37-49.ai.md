This is the v9 revision of Pablo Sabater’s feature series implementing cascading indentation for visual roots in `git log --graph`. The series is now complete and addresses the last major design gap identified in v8: filters like `--author` and `--grep` that exclude commits *after* enqueuing (via `simplify_commit()`/`get_commit_action()`) leave parent pointers intact, causing the lookahead buffer to miss visual roots until the next commit is processed—too late to indent.

The fix in v9 is straightforward and targeted: `graph_is_visual_root_candidate()` now iterates over each parent and calls `graph_is_interesting()` (which internally uses `get_commit_action()`) to determine if the parent is excluded by the filter. This generalizes the logic to handle any filter that operates via `simplify_commit()`, not just those that explicitly NULL out parent pointers. The change is minimal—only a few lines in `graph.c`—and preserves all existing behavior for boundary commits, merge parents, and octopus merges. Two new test cases in `t4218-log-graph-indentation.sh` verify the fix works for `--author` and `--grep`.

The rest of the series is unchanged from v8: patch 1/4 (test infrastructure cleanup) is already merged; patch 2/4 introduces `next_commit_to_show()` to unify lookahead buffer population; patch 3/4 implements the two-slot lookahead buffer; and patch 4/4 contains the visualization logic with cascading indentation. The architectural foundation—a lookahead buffer populated by a single helper function—remains robust and compatible with Jeff King’s planned removal of `revs->commits` and Kristofer Haugsbakk’s `kk/prio-queue-get-put-fusion` topic.

The series is now technically complete and addresses all known edge cases. Junio Hamano and Phillip Wood’s final reviews of patches 2/4 and 3/4 are still pending, but the core logic (patch 4/4) is now stable and well-tested. The redundant-indentation edge case (marked NEEDSWORK in v8) remains, but it is documented and deemed acceptable. This version is likely ready for `next` once the remaining reviews are complete.
