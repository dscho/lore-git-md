This is the third patch in Junio C Hamano’s six-part documentation series clarifying contributor guidance. It adds a new section to `Documentation/MyFirstContribution.adoc` explaining when and how contributors should carry over `Reviewed-by:` and `Acked-by:` trailers from previous patch iterations.

The patch introduces clear, actionable rules: `Acked-by:` trailers may be carried forward if the new version contains only minor changes (e.g., typo fixes or style tweaks) that do not affect the reviewed logic, while `Reviewed-by:` trailers should generally *not* be carried over unless the patch is resent unchanged. The guidance also advises contributors to explicitly mention in their cover letter when significant changes require re-review.

This update directly addresses a recurring source of confusion for newcomers—how to handle trailers across patch iterations—while reinforcing the social signals these trailers represent. The rules are well-scoped and align with existing project practices, making them uncontroversial. The patch is purely additive, touching only documentation, and does not introduce new commands, options, or code behavior. Future discussion may focus on minor wording tweaks or edge cases (e.g., what constitutes a "significant" change), but the core guidance is likely to be accepted as-is.
