This is a documentation patch, part of Junio C Hamano’s six-patch series clarifying contributor guidance. It updates `Documentation/MyFirstContribution.adoc` to explain when and how contributors should carry over `Reviewed-by:` and `Acked-by:` trailers from one iteration of a patch to the next.

The patch adds a new subsection, “Handling trailers in subsequent versions,” that gives concrete rules: carry forward an `Acked-by:` if the changes are minor and do not alter the reviewed logic, but drop it if the logic changes significantly. For `Reviewed-by:`, the rule is stricter—only carry it over if the patch is resent unchanged. The guidance is aimed at helping contributors signal to the maintainer which parts of a series have already received favorable review, reducing redundant work.

The change is straightforward and uncontroversial, reflecting existing practice rather than inventing new policy. It directly addresses a recurring point of confusion for newcomers and should make the review process slightly more efficient. No code or command behavior is affected; this is purely about improving documentation clarity.
