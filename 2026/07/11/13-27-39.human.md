This is the fourth patch in the **ready-to-merge v6 series** optimizing `paint_down_to_common()` for one-sided histories. It adds **regression tests** for the side-exhaustion optimization, ensuring the algorithm correctly handles cases where one merge-base candidate is an ancestor of another.

The patch introduces `t6099-merge-base-side-exhaustion.sh`, a new test script that verifies two key behaviors:
1. **Redundant candidate removal**: When multiple merge-base candidates exist (e.g., `B` and `C` in the test graph), and one is an ancestor of another, the optimization must not prematurely terminate before `remove_redundant()` filters out the ancestor. The test confirms only the shallowest candidate (`B`) is returned.
2. **Commit-graph dependency**: The side-exhaustion optimization relies on finite generation numbers. The test validates that without a commit-graph (where all generations are `INFINITY`), the optimization does not fire, and the correct result is still produced.

The test graph is a diamond topology with an extra path (`A -> e2 -> e1 -> C` and `X -> f2 -> f1 -> C`), designed to trigger the edge case where one side of the walk (`A` or `X`) exhausts its commits before the other. The test runs in all commit-graph modes (`--full`, `--no-commit-graph`) and checks both `merge-base --all` and the single-result variant.

This patch is **pure test coverage** with no code changes. It complements the performance-focused `t6099` tests in the series and the edge-case tests in `t6600` (added in patch 3/10). The test is deterministic, leak-sanitized, and exercises the exact scenario the optimization targets: asymmetric histories where one side is much deeper than the other. No new infrastructure is introduced; it reuses existing helpers like `test_commit` and `test_merge`.

The patch is **fully reviewed** and addresses a specific concern raised during earlier iterations: that the side-exhaustion optimization might interact poorly with `remove_redundant()`. The test confirms the safety net works as intended. This is a **low-risk, high-value addition** that hardens the series against regressions.
