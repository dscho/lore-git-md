This is a test fixup for the recently introduced `fetch.submoduleErrors` configuration option. Ramsay Jones reports that the patch series `pz/fetch-submodule-errors-config` (specifically commit `df9481e6d6`) introduced a regression in the test suite: several tests in `t/t5526-fetch-submodules.sh` use `grep` directly instead of the test helper `test_grep`, which can cause false negatives if the pattern is not found. The fixup replaces all instances of `grep` with `test_grep` and adjusts the negation case (`! grep`) to the idiomatic `test_grep !`.

The change is mechanical and confined to the test file; it does not alter the behavior of the feature itself. The patch is part of a cooking topic (`pz/fetch-submodule-errors-config`) currently in Junio’s `seen` branch, so it is still under review and not yet merged. Ramsay’s message is a courtesy heads-up to Junio rather than a request for discussion.
