Core problem or goal
The recently introduced `fetch.submoduleErrors` configuration option added a regression in the test suite: several tests in `t/t5526-fetch-submodules.sh` use raw `grep` instead of the test helper `test_grep`, risking false negatives when patterns are not found. The fixup replaces all `grep` calls with `test_grep` and adjusts negated cases (`! grep`) to the idiomatic `test_grep !`.
