This is a **substantive review comment** on patch 3/8 (formerly 3/7) in Patrick Steinhardt’s ODB abstraction series. Jeff King (Peff) chimes in to explain the historical context behind the `return 1` in `add_object_entry_from_bitmap()`: it was originally modeled after `add_object_entry()`, which once had callers that cared about whether an object entry was created. That behavior became obsolete in 2006, but the return value lingered. Peff suggests that `add_object_entry()` itself could now be cleaned up to drop its unused return value, though the bitmap variant must retain its callback-compatible signature. The comment is purely explanatory and does not block the patch, but it flags a small follow-up refactoring opportunity. The patch itself remains ready to proceed.
