This is a **test infrastructure improvement** that adds better diagnostics to Git’s test suite. The patch introduces `test_trace2_data_singular()`, a new helper in `t/test-lib-functions.sh` that checks Trace2 data events for an exact match and provides clear error messages when the check fails.

The existing `test_trace2_data` helper is a simple `grep` that silently exits on failure, offering no feedback about whether the event was missing, duplicated, or had the wrong value. The new helper addresses this by verifying the event appears exactly once and reporting mismatches in a structured way (e.g., "expected: 999, actual: 0"). Errors are written to file descriptor 4, matching the style of other test diagnostics like `test_grep`.

This is part of the larger `paint_down_to_common()` optimization series (v6), where it will be used to assert deterministic step counts in performance tests. The change is small (36 lines) and self-contained, touching only the test library. It’s a clear improvement for debugging test failures, though not critical to the series’ core functionality. The patch is ready to merge and has no known objections.
