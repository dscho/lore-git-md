This is the sixth and final patch in Junio C Hamano’s six-part documentation series clarifying contributor guidance. It focuses on the writing style for "What's cooking" report entries, which summarize in-flight topics for the mailing list.

The patch updates `Documentation/SubmittingPatches` to explicitly describe the tense and voice used in "What's cooking" entries. Unlike commit messages (which use present-tense observations and imperative mood for changes), "What's cooking" entries are written in past or present perfect tense with passive voice, treating the change as already completed. The patch adds a clear tip for contributors, illustrating the difference with an example: "The XYZ subsystem has been updated to..." rather than the imperative style used in commit messages.

This is a straightforward documentation improvement that codifies existing practice. The change is uncontroversial and directly addresses a recurring source of confusion for contributors who draft cover letters. It complements the rest of the series by providing consistent, practical guidance for every stage of the patch submission process. The patch is well-explained and fits neatly into the broader effort to make contributor documentation more precise and actionable.
