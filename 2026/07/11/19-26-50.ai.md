This is the sixth and final patch in Junio C Hamano’s six-part documentation series clarifying contributor guidance. It focuses on the writing style for "What's cooking" report entries, which summarize in-flight topics for the mailing list.

The patch updates `Documentation/SubmittingPatches` to explicitly describe the tense and voice used in "What's cooking" summaries: past or present perfect tense in passive voice (e.g., "The XYZ subsystem has been updated to..."), contrasting with the present-tense observations and imperative-mood instructions used in commit messages. The change adds a new "TIP" section that spells out this distinction, replacing a more generic instruction with concrete style guidance. The patch also tidies up the surrounding text, breaking up a dense paragraph for better readability.

This is a purely documentation change, touching only `Documentation/SubmittingPatches`. It introduces no new commands, options, or code behavior, and has no dependencies on other patches. The guidance is uncontroversial, as it codifies the existing style used in Junio’s reports rather than proposing a change. The patch is well-motivated: the style difference between commit messages and "What's cooking" entries has been a recurring source of confusion for contributors, and this clarification should reduce the need for maintainer edits to proposed topic summaries.
