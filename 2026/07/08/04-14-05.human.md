This is a refactoring patch that removes redundant transaction validation from the "files" ODB backend. It is the fourth patch in Justin Tobler’s v2 series (11 patches total) converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`.

The patch deletes a check in `odb_transaction_files_begin()` that prevented starting a new transaction if one was already in flight. The generic ODB transaction layer already enforces this rule, so the duplicate check in the "files" backend is unnecessary. The change is purely mechanical: four lines removed from `object-file.c` and a comment updated in `object-file.h` to remove the now-obsolete "If a transaction is already pending" clause.

This patch is part of the ODB abstraction effort led by Patrick Steinhardt. It follows the pattern established in earlier patches of the series: consolidating transaction logic in the generic layer to avoid backend-specific duplication. The commit message is clear and the diff is minimal, reflecting the straightforward nature of the change. No behavioral change is introduced, and the patch is uncontroversial given the prior agreement on the series direction.
