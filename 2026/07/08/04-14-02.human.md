This is the first patch in Justin Tobler’s v2 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It is a straightforward refactoring: the function `prepare_loose_object_transaction()` is renamed to `odb_transaction_files_prepare()` to reflect that it will soon be used for both loose objects and packfiles. The change is mechanical—only the name and three call sites in `object-file.c` are updated—and introduces no behavioral differences. The commit message explains the motivation clearly: the new name better matches the function’s expanded future role in the "files" ODB transaction backend. This patch is uncontroversial and a necessary foundation for the rest of the series.
