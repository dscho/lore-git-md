This is the first patch in Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It is a pure refactoring: the patch renames `prepare_loose_object_transaction()` to `odb_transaction_files_prepare()` to better reflect its role in preparing the "files" ODB backend’s transaction state. The function lazily creates a temporary object directory when the first loose object is written, and the new name aligns with the broader ODB abstraction effort (the function will later handle packfiles as well).

The change is mechanical: three call sites in `object-file.c` are updated, and the function’s signature and behavior remain unchanged. This patch is uncontroversial and was already reviewed by Patrick Steinhardt in earlier iterations. It sets the stage for the subsequent patches that introduce error propagation and environment-variable plumbing. No behavioral changes or new interfaces are introduced here.
