This is the first patch in Jeff King’s v2 seven-patch series refactoring the `git_hash_*()` API. It establishes the foundation for the rest of the series by ensuring all callers use the `git_hash_init()` wrapper instead of calling `algop->init_fn()` directly. The patch is purely mechanical: it replaces every direct call to the low-level `init_fn()` hook with the public wrapper and adds a Coccinelle semantic patch (`tools/coccinelle/hash.cocci`) to enforce this invariant going forward. The files touched span core object-writing code (`csum-file.c`, `object-file.c`, `hash.c`), built-ins (`fast-import`, `index-pack`, `receive-pack`, `submodule--helper`), test helpers, and the new Coccinelle rule. No behavior changes are introduced; the goal is purely to standardize usage so that future logic (such as idempotency checks) can be added to the wrapper without missing any callers. The patch is ready for integration, with no technical objections remaining after v1 feedback was addressed.
