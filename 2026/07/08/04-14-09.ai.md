This is the eighth patch in Justin Tobler’s v2 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It introduces the `odb_transaction_env()` interface, which lets child processes access the transaction’s staging area by inheriting environment variables.

The patch adds a new `env` callback to the `struct odb_transaction` vtable and implements it for the “files” backend. The callback uses `tmp_objdir_env()` to populate a `strvec` with the same environment variables that `tmp_objdir` used, so any child process spawned by `git-receive-pack` (e.g., `git-index-pack` or `git-unpack-objects`) will automatically write objects into the transaction’s temporary directory. The generic `odb_transaction_env()` helper simply delegates to the backend’s callback if the transaction exists.

No behavior changes are claimed; the patch is purely plumbing. It touches `object-file.c`, `odb/transaction.c`, and `odb/transaction.h`, adding about 40 lines. The interface is straightforward and matches the pattern already established by the `commit` and `write_object_stream` callbacks. This is a prerequisite for the final three patches in the series, which actually switch `receive-pack` over to transactions.
