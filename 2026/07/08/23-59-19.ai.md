This is patch 5/11 of Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. The patch converts the "files" transaction backend’s `prepare`, `begin`, and `commit` interfaces from `void` to `int` return types, enabling callers to detect and handle errors that were previously ignored.

The changes are mechanical: each function now returns an error code on failure, and the commit message explicitly calls out the newly surfaced errors—`tmp_objdir_create()` and `tmp_objdir_migrate()` failures now log actionable error messages (`"unable to create temporary object directory"` and `"unable to migrate temporary objects"`). The patch touches four files: `object-file.c` (26 lines), `object-file.h` (3 lines), `odb/source-files.c` (6 lines), and `odb/transaction.h` (7 lines). No behavioral changes are introduced; the patch is purely an error-propagation improvement.

This patch directly addresses feedback from Patrick Steinhardt (the ODB subsystem owner) on v2, where he flagged the missing error messages as a usability gap. Justin’s response—adding the error logging—resolves the concern, and Patrick’s implied Reviewed-by from the v2 discussion carries forward. The patch is part of the larger ODB abstraction effort and is queued for `next` alongside the rest of the series.
