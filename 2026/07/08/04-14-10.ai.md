This is the ninth patch in Justin Tobler’s v2 ODB transaction series (11 patches total), introducing `enum odb_transaction_flags` and the `ODB_TRANSACTION_RECEIVE` flag to preserve `git-receive-pack`’s existing object-directory behavior when switching from `tmp_objdir` to ODB transactions.

The patch adds a flags parameter to the ODB transaction interface (`odb_transaction_begin()`, `odb_transaction_begin_or_die()`, and backend callbacks) and implements the `ODB_TRANSACTION_RECEIVE` flag in the "files" backend. When set, the flag causes the transaction to eagerly create its temporary directory (matching `receive-pack`’s current behavior) and use the "incoming" prefix (instead of the default "bulk-fsync"). The flag is documented as a temporary measure; the commit message notes that ideally all transactions would behave uniformly, but this preserves compatibility while the transition is in progress.

Files touched: 13, with the heaviest changes in `object-file.c` (29 lines) and `odb/transaction.h` (15 lines). The patch is mechanical and non-behavioral: it only adds the plumbing for flags, leaving the actual `receive-pack` conversion for the next patch. No test coverage is added; the existing test suite will exercise the new plumbing once the conversion is complete. The series remains queued for `next`.
