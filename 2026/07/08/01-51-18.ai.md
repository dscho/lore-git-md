This is a bugfix patch targeting the `merge --abort` command. It addresses a data-loss edge case where the autostash (created by `merge --autostash`) is deleted before `git reset --merge` succeeds, meaning if the reset fails (e.g., due to a locked index), the stash is permanently lost.

The patch modifies `builtin/merge.c` to read the `MERGE_AUTOSTASH` ref without deleting it upfront, lets `cmd_reset()` handle the merge state cleanup (which includes persisting the autostash), and only applies the autostash if the reset succeeds.
