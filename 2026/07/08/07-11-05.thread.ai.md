Core problem or goal
Move the `core.sharedRepository` configuration setting from a global variable into the per-repository `struct repo_settings` so that every function that needs the setting must explicitly receive a `struct repository *` parameter. This is a mechanical step in the ongoing project-wide effort to eliminate implicit reliance on the global `the_repository`.
