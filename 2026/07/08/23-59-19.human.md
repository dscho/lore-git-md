This is part 5 of Justin Tobler’s 11-patch series converting `git-receive-pack` from `tmp_objdir` to ODB transactions. The patch propagates previously ignored errors in the “files” transaction backend (`odb_transaction_files_prepare`, `odb_transaction_files_begin`, and `odb_transaction_files_commit`) so callers can handle failures explicitly. The changes are mechanical: converting `void` functions to `int`, adding error returns for `tmp_objdir_create` and `tmp_objdir_migrate` failures, and plumbing the error codes through the call chain. No behavior changes; the patch only surfaces errors that were already occurring but silently swallowed. Patrick Steinhardt’s earlier review identified the missing error messages as a usability gap, and Justin addressed it by adding descriptive `error()` calls. The patch is uncontroversial and ready for `next`.
