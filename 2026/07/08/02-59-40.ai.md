This is a test infrastructure bugfix series targeting the HTTP daemon test helpers. The cover letter explains that two CGI scripts in `t/lib-httpd/`—`apply-one-time-script.sh` and `http-429.sh`—keep state in the shared `HTTPD_ROOT_PATH` using non-atomic shell operations (`test -f` followed by `rm` or `touch`). Because Apache serves requests concurrently, and a single Git operation can open multiple requests to the same endpoint (e.g., a partial fetch that lazily retrieves a promisor object while the first response is still being served), these scripts can race: both requests pass the `test -f` check, one removes the marker, and the other fails, causing an HTTP 500 error. The series fixes this by replacing the non-atomic checks with atomic operations: `mv` for the one-shot marker and `mkdir` for the first-request election.

The series is structured as three patches. Patch 1 fixes `apply-one-time-script.sh` and adds a new test (`t5567-one-time-script.sh`) that directly exercises the helper without a web server, making the race deterministic. Patch 2 makes `http-429.sh` atomic in the same way. Patch 3 documents the atomic idioms in `t/README`, linking to Git’s own lockfile machinery and `make_symlink()` as precedents. The changes are confined to the test infrastructure (`t/` directory) and are motivated by a real, observed flake in `t5616.47` on macOS CI runners, where the race caused a fetch to fail with an HTTP 500 error.

The commit messages are detailed and include a reproduction case, making the problem and solution clear. The fixes are minimal and targeted, addressing only the concurrency issue without changing the scripts’ behavior under sequential execution. The new test is a strong addition, as it provides a deterministic way to verify the fix. The documentation patch (patch 3) is a nice touch, as it generalizes the pattern for future test helpers. The series looks well-crafted and addresses a real, if narrow, problem in the test suite. It is unlikely to be controversial, as the fixes are mechanical and the motivation is concrete.
