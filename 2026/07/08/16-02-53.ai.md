This is patch 2/9 of Tian Yuchen’s v8 series migrating global configuration variables into `struct repo_config_values`. It moves the `excludes_file` global (the path to the global ignore file) into the repository-scoped structure and introduces a proper getter, `repo_excludes_file()`, that encapsulates the lazy-loading fallback to the XDG default path.

The patch is a re-split of work already merged in the prior `excludes_file` series, but included here for clarity and to establish the memory-management pattern that the rest of the series follows. The key change is the addition of `excludes_file` to `struct repo_config_values` and the corresponding cleanup in `repo_config_values_clear()`, which ensures the heap-allocated string is freed when the repository is torn down. The diff touches `dir.c` (where the lazy-loading logic was previously hard-coded), `environment.c` (the getter and config-parsing logic), and `environment.h` (the structure definition and declaration).

No user-visible behavior changes; this is purely refactoring to eliminate a global and centralize memory management. The patch is CI-clean and the memory leak Junio identified in v7 has been fixed in this iteration. The `NEEDSWORK` comment about submodule support for `excludes_file` remains, but it is carried over from the prior series and is not a blocker.
