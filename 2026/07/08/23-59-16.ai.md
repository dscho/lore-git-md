This is a mechanical refactoring patch in the ODB transaction series. It renames `fsync_loose_object_transaction()` to `odb_transaction_files_fsync()` to align with the naming convention used by other "files" ODB transaction helpers. The patch also reorders the conditional logic to improve clarity: the early return for missing transaction or object directory is now explicit, and the `git_fsync()` call is no longer nested inside the same condition.

The change is purely internal; there is no behavior change. The commit message explains the motivation (consistency with other helpers) and the minor restructuring (improved readability). Patrick Steinhardt, the ODB subsystem owner, reviewed the patch in an earlier iteration and explicitly accepted the conditional reordering despite the minor duplication it introduces. The patch touches only `object-file.c` (10 lines added, 6 removed) and is part of the larger effort to make `git-receive-pack` ODB-backend-agnostic.
