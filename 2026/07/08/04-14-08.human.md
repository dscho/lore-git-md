This is the seventh patch in Justin Tobler’s v2 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It plugs a silent failure path: the ODB transaction layer now propagates commit errors from the backend (e.g., the “files” backend failing to migrate its temporary object directory) up to the caller. The change is mechanical—converting `odb_transaction_commit()` from `void` to `int` and forwarding the backend’s return code—but it is a prerequisite for the next patch, where `receive-pack` will actually handle those errors. No behavioral change yet; the patch simply makes the error visible.
