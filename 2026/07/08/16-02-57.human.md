This is the sixth patch in Tian Yuchen’s v8 series migrating global configuration variables into `struct repo_config_values`. It moves the `apply_default_whitespace` and `apply_default_ignorewhitespace` variables—used by `git apply` to control default whitespace handling—into the repository-scoped configuration struct.

The patch updates `git_apply_config()` to accept a `struct repository *` parameter (removing its reliance on `the_repository`), initializes the new fields in `repo_config_values_init()`, and ensures they are freed in `repo_config_values_clear()`. Callers in `apply.c` now access the values through `repo_config_values(repo)-><field>`. The memory leak fix introduced in earlier patches (freeing old values before re-assignment) is extended here to these fields, ensuring robust cleanup.

This is a clean, mechanical refactoring with no user-visible behavior changes. It continues the established pattern from the series and directly addresses the memory management concern Junio raised in v7. The patch is technically solid and ready for integration.
