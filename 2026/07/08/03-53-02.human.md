This is the sixth patch in Jeff King’s seven-patch v2 series refactoring the `git_hash_*()` API. The series as a whole makes `git_hash_discard()` idempotent and standardizes hash API usage across the codebase; this patch applies the new idempotency guarantee to the HTTP transport layer.

The patch removes the `hash_ctx_valid` flag that was introduced in commit a2d8ea5a76 (July 2026) to track whether the hash context had been finalized and therefore needed discarding. With `git_hash_discard()` now safe to call multiple times, the flag becomes redundant. The change touches only `http.c` and `http.h`, deleting four lines of code and simplifying the cleanup logic in `release_http_object_request()`. No behavior change is expected—this is a pure refactoring that leverages the idempotency introduced earlier in the series.

The patch is small, mechanical, and uncontroversial; it was already reviewed in v1 and received no substantive feedback beyond cosmetic approval. It is ready for integration alongside the rest of the series.
