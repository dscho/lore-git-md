This thread is about a small but clear regression fix in Git's submodule subsystem. Dominique Martinet identified that the `-i` shorthand flag for `git submodule update`—which triggers initialization of submodules—has been broken since Git v2.49. The issue stems from a readability refactoring in the shell script wrapper that now passes `-i` directly to the C helper, but the helper never recognized the short form. The fix is a one-line addition to the option-parsing array in `builtin/submodule--helper.c`, restoring the expected behavior.

The patch is minimal and uncontroversial, addressing a documented regression (commit 3ad0ba722744) with a targeted change. While the `-i` flag isn’t mentioned in the help text, the author argues for consistency since it previously worked. There’s no indication of prior discussion or review yet, but the fix is straightforward and unlikely to draw objections. The practical impact is limited—most users rely on the documented `--init` long option—but it’s a clean correctness fix for those who used the shorthand.
