This is the eighth patch in Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It adds plumbing for child processes (`git-index-pack`, `git-unpack-objects`) to inherit the transaction’s staging area via environment variables.

The patch introduces `odb_transaction_env()`, a new interface that populates a `strvec` with the environment variables a child process needs to access the transaction’s object directory. The "files" backend implements this by calling `tmp_objdir_env()` on its temporary object directory, preserving the existing behavior where child processes see the quarantine area as an alternate object store. No user-facing behavior changes; this is purely internal infrastructure for the later `receive-pack` conversion.

Files touched: `object-file.c` (14 lines), `odb/transaction.c` (8 lines), and `odb/transaction.h` (17 lines). The changes are mechanical and well-contained, adding a single callback (`env`) to the `odb_transaction` vtable and a convenience wrapper (`odb_transaction_env()`) that dispatches to the backend. The implementation is straightforward: the "files" backend delegates to the existing `tmp_objdir_env()` helper, and the generic layer handles NULL transactions gracefully.

This patch is part of the ODB abstraction effort led by Patrick Steinhardt. It directly enables patch 11/11, which replaces `tmp_objdir` usage in `receive-pack` with the new transaction interfaces. The series is functionally complete and queued for `next`; this patch has no unresolved feedback and is ready for integration.
