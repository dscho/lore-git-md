This is the third patch in Justin Tobler’s v2 series refactoring `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It eliminates the standalone `flush_loose_object_transaction()` helper by inlining its hardware-flush and directory-migration logic directly into `odb_transaction_files_commit()`. The change is purely mechanical: the same two steps (fsync a temporary file to ensure durability, then call `tmp_objdir_migrate()`) are now performed inside the commit function rather than in a separate routine. No behavior changes; only code organization. The patch touches only `object-file.c` (64 lines, 28 insertions, 36 deletions) and is a straightforward cleanup that reduces indirection in the transaction lifecycle.
