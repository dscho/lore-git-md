This is part of the `the_repository` removal effort. Patch 15/16 in a series moves the `core.sharedRepository` configuration setting from global access into the per-repository settings structure (`struct repo_settings`). The change touches `environment.c` and `repo-settings.c`, replacing direct reads of the global config with calls to `repo_config_get_maybe_bool()` that respect the repository context. The commit message notes that this is a mechanical step in the larger goal of eliminating implicit reliance on `the_repository`.

The patch itself is small and focused: it removes the global variable `shared_repository` and updates the single function `adjust_shared_perm()` to take a `struct repository *` parameter so it can look up the setting in the correct repository’s config. No behavior change is claimed, only a refactoring of where the setting is stored. The author is a first-time contributor; the patch has not yet received review.
