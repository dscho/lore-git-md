This thread fixes race conditions in Git's HTTP daemon test helpers that can cause HTTP 500 errors during concurrent requests. Michael Montalbo's v3 patch series replaces non-atomic shell operations with atomic alternatives (`rm` without `-f` and `mkdir`) in two CGI scripts (`apply-one-time-script.sh` and `http-429.sh`), eliminating races where concurrent requests could both fail or incorrectly return 429 errors. The series also adds a new test (`t5567-one-time-script.sh`) and updates documentation in `t/lib-httpd.sh` to explain the safe idioms.

Junio C Hamano previously reviewed the series and marked it ready for integration, though he's now seeking additional review from contributors with HTTP test expertise. Patrick Steinhardt provided feedback on earlier versions, focusing on documentation placement and editorial improvements, all of which have been addressed. His latest reply endorses the series as "good enough" for merging, though he notes the commit messages are verbose—this is purely stylistic and doesn't affect the technical content.

The series is complete, self-contained to the test infrastructure, and addresses a real flake observed in CI. No open questions remain, and the patches are ready for `next`.
