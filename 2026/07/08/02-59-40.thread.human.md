This thread is a v2 patch series from Michael Montalbo that fixes race conditions in Git’s HTTP daemon test helpers. The issue stems from two CGI scripts in `t/lib-httpd/` using non-atomic shell operations (`test -f` followed by `rm` or `touch`) to manage shared state, which can race under concurrent Apache requests—causing HTTP 500 errors in tests like `t5616.47` on macOS CI runners. The series replaces these with atomic operations (`mv` for one-shot markers, `mkdir` for first-request election) to eliminate the races.

Junio C Hamano reviewed the v1 and provided substantive feedback on patches 1 and 2, which Michael addressed in v2. The updates clarify the commit messages and code comments, explicitly stating the rationale for the atomic operations (including the `"permanent"` case in patch 2) and retaining the existing locale behavior in `apply-one-time-script.sh` as a deliberate choice. Patch 3, the documentation update, was unchanged in v2 after Junio called it a "nice finishing touch." The series is now complete, with no open questions or objections, and targets only the test infrastructure (`t/` directory). It’s ready for integration.
