This thread fixes race conditions in Git’s HTTP daemon test helpers that could cause intermittent HTTP 500 errors during concurrent requests. The series, now at v4, replaces non-atomic shell operations in two CGI scripts (`apply-one-time-script.sh` and `http-429.sh`) with atomic alternatives—`rm` (without `-f`) for one-shot markers and `mkdir` for first-request election—to eliminate races when Apache serves multiple requests to the same endpoint. Michael Montalbo authored the patches, with Junio C Hamano and Patrick Steinhardt reviewing earlier versions.

All substantive feedback has been addressed. Junio praised the technical approach in v2, and Patrick called the series “good enough” in v3. The v4 revision only rewrites commit messages to reduce verbosity, with no code changes. The final patch adds documentation to `t/lib-httpd.sh` explaining the atomic idioms and safe patterns for future contributors.
