The core issue is that two CGI scripts in the test suite (`apply-one-time-script.sh` and `http-429.sh`) used non-atomic shell operations to manage shared state, which could race under concurrent Apache requests—causing HTTP 500 errors in CI. The fixes replace these with atomic operations (`rm` without `-f` and `mkdir`), add a new test to exercise the race deterministically, and document the safe idioms in `t/lib-httpd.sh`. The changes are confined to the test infrastructure and don’t affect user-visible behavior.
