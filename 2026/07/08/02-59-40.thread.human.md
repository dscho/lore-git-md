This thread fixes race conditions in Git's HTTP daemon test helpers that can cause HTTP 500 errors during concurrent requests. Michael Montalbo's v3 patch series replaces non-atomic shell operations in two CGI scripts (`apply-one-time-script.sh` and `http-429.sh`) with atomic alternatives like `rm` without `-f` and `mkdir`. The changes are confined to the test infrastructure (`t/` directory) and include a new deterministic test (`t5567-one-time-script.sh`) that forces the race using FIFOs.

Junio C Hamano, who previously reviewed v2 and marked the series as ready for integration, has now called for additional review of v3. All substantive feedback from earlier versions has been addressed: patch 1 simplified its logic by switching from `mv` to `rm` for one-shot markers, patch 2 fixed a latent race in `http-429.sh` and a correctness issue in "permanent" mode, and patch 3 relocated documentation to `t/lib-httpd.sh` for better context. Patrick Steinhardt provided feedback on earlier versions, particularly around documentation placement and error handling, but no open questions remain. The series is complete and poised for `next`, pending further review from HTTP test experts.
