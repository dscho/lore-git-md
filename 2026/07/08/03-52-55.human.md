This is the third patch in Jeff King’s seven-patch series refactoring the `git_hash_*()` API. The patch improves documentation in `hash.h` to steer contributors toward the public wrapper functions (`git_hash_init()`, `git_hash_clone()`, etc.) and away from the low-level function pointers in the `git_hash_algo` struct. It also adds practical usage notes—such as the requirement to initialize the destination context before calling `git_hash_clone()` and the obligation to finalize or discard a hash context to avoid resource leaks—that surfaced during the author’s work on the series.

The changes are purely documentary: 32 lines added, 11 removed in `hash.h`. No code behavior changes, and the patch is uncontroversial. It complements the Coccinelle semantic patch introduced in patch 1, which will eventually enforce wrapper usage at compile time, by giving readers immediate guidance. The patch is ready for integration and has no open review feedback.
