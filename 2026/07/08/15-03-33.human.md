This is a two-patch bugfix series targeting the bundle-URI protocol implementation. It addresses a real usability issue where misconfigured servers advertising invalid bundle-URI data (empty URIs) cause Git clients to fail with confusing "expected 'packfile'" errors during clone operations.

The series combines both client-side resilience and server-side validation. The first patch (from Toon Claes) modifies the client to properly drain the protocol stream after encountering invalid bundle-URI lines, preventing stale data from breaking subsequent protocol exchanges. This is a clean solution that maintains error reporting while allowing operations to continue, which aligns with the optional nature of bundle-URIs. The second patch (from Justin Tobler) adds server-side validation to prevent Git servers from advertising empty URIs in the first place.
