This is patch 9/11 of Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. The patch introduces `enum odb_transaction_flags` and the `ODB_TRANSACTION_RECEIVE` flag to preserve `receive-pack`’s existing behavior (eager directory creation and "incoming" prefix) during the transition.

The change is plumbing-only: it adds a flags parameter to the ODB transaction interface (`odb_transaction_begin`, `odb_transaction_begin_or_die`, and backend callbacks) and implements the `ODB_TRANSACTION_RECEIVE` flag in the "files" backend. When the flag is set, the backend eagerly creates the temporary directory with the "incoming" prefix, matching `receive-pack`’s current behavior. All existing call sites are updated to pass `0` (no flags), so there is no behavioral change in this patch.

The patch touches 13 files, with the core logic in `object-file.c` (29 lines) and `odb/transaction.h` (15 lines). The commit message documents the flag as a temporary measure and notes that future work could unify the behavior (eager creation, consistent prefix) across all transactions. Patrick Steinhardt’s prior feedback about tight coupling between `odb/transaction.h` and `odb/source.h` (due to the enum) remains unresolved but is deferred to a follow-up series.
