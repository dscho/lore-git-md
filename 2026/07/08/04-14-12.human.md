This is the final patch in Justin Tobler’s v2 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It applies the infrastructure built in the previous ten patches by replacing the direct `tmp_objdir` calls in `builtin/receive-pack.c` with the new `odb_transaction` interfaces.

The patch removes the global `tmp_objdir` variable and introduces a local `struct odb_transaction *` that is passed through the call chain (`unpack`, `execute_commands`, `run_receive_hook`, `set_connectivity_errors`). Every place that previously called `tmp_objdir_env()` now calls `odb_transaction_env()`, and the final `tmp_objdir_migrate()` is replaced with `odb_transaction_commit()`. The transaction is started with the `ODB_TRANSACTION_RECEIVE` flag, preserving the existing behavior of eager directory creation and the “incoming” prefix.

The commit message notes one small behavioral change: the temporary directory is now set as the primary ODB in the main process instead of an alternate. This is non-regressive because `receive-pack` only needs access to the newly written objects and does not care about the exact ODB setup. The patch is purely mechanical, touching only `builtin/receive-pack.c` (35 insertions, 33 deletions), and completes the series’ goal of making `receive-pack` ODB-backend-agnostic. All feedback from v1 has been addressed, and the series is queued for `next`.
