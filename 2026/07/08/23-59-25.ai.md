This is the final patch in Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It replaces the global `tmp_objdir` variable with a local `struct odb_transaction *` that is created at the start of the unpack phase (`odb_transaction_begin` with the `ODB_TRANSACTION_RECEIVE` flag) and committed just before reference updates (`odb_transaction_commit`). The temporary directory is no longer added as an alternate; instead, the transaction’s object directory becomes the primary ODB in the main process, preserving quarantine semantics.

The patch touches only `builtin/receive-pack.c`, removing the `#include "tmp-objdir.h"` and the global `tmp_objdir` variable. Every call site that previously referenced `tmp_objdir` is updated to use the new `odb_transaction` interfaces (`odb_transaction_env`, `odb_transaction_commit`). The behavioral change is non-regressive: objects are still staged in an "incoming" directory and migrated to the main object store only after pre-receive hooks and connectivity checks pass, matching the existing behavior. Error handling is consistent with the rest of the series: failures during transaction begin or commit are surfaced as command errors.

This patch is the culmination of the series and is ready for integration; all prior patches (1–10/11) have been reviewed and are queued for `next`. The only deferred issues—header dependency concerns and a latent transaction-leak in `odb_transaction_commit`—are acknowledged and slated for follow-up work. The series as a whole advances the ODB abstraction effort led by Patrick Steinhardt.
