This is a bugfix for the submodule subsystem. The patch restores support for the `-i` shorthand flag in `git submodule update --init`, which has been broken since Git v2.49 due to a mismatch between the shell script and the C helper.

The issue stems from commit 3ad0ba722744, which improved variable readability in `git-submodule.sh` but inadvertently exposed a gap in `submodule--helper.c`: while the shell script passes `-i` to the helper, the helper itself only recognizes `--init` and rejects the short form. The fix is a one-line change in `builtin/submodule--helper.c`, adding `'i'` as an alias for the `--init` option.

The patch is minimal, well-motivated, and clearly fixes a regression. The commit message explicitly cites the breaking commit and includes a `Fixes:` trailer, making it easy to track. While the `-i` shorthand isn’t documented in the help text, the author notes it previously worked, so this is a straightforward restoration of lost functionality. No controversy is expected.
