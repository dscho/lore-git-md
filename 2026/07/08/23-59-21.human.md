This is a refactoring patch in the ODB transaction subsystem, part of Justin Tobler’s larger series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. Patch 7 of 11 changes `odb_transaction_commit()` and its backend callback from `void` to `int` so backends can signal commit failures—such as when the "files" backend cannot migrate its temporary object directory into the permanent ODB.

The change is mechanical: the function now returns the backend’s error code instead of discarding it. A latent issue is noted in the thread context: the transaction is freed *before* returning any backend error, which leaks the transaction object. This leak predates the series but becomes more visible with the error-return conversion. Justin acknowledges it and plans to fix it in a follow-up by introducing a separate `odb_transaction_release()` function.

The patch itself is small (11 lines changed) and uncontroversial; the error-propagation improvement is a prerequisite for the final patch in the series, which converts `git-receive-pack` to use transactions. Patrick Steinhardt, the ODB subsystem owner, has already signaled strong approval of the series as a whole. This patch is queued for `next` pending integration.
