This is the third patch in Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It eliminates the `flush_loose_object_transaction()` helper by embedding its logic directly into `odb_transaction_files_commit()`.

The change is purely mechanical: the hardware-flush (`fsync`) and directory-migration (`tmp_objdir_migrate`) steps that were previously in the helper are now performed inline inside `odb_transaction_files_commit()`. The commit message explains that the helper’s name was misleading—it did more than just “flushing”—and that future patches will use the transaction directory to stage packfiles, not just loose objects. Moving the logic into the commit function better reflects its role in the transaction lifecycle.

No behavior changes; the patch only reorganizes code. It touches a single file (`object-file.c`) and removes 36 lines while adding 28. The motivation was clarified in response to Patrick Steinhardt’s feedback on v2, and the patch carries his implied Reviewed-by. This is a routine refactoring step in the larger ODB abstraction effort.
