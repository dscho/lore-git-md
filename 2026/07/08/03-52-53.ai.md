This is the second patch in Jeff King’s seven-patch v2 series refactoring the `git_hash_*()` API. The patch mechanically converts all remaining direct calls to hash algorithm vtable functions (`update_fn`, `final_fn`, `final_oid_fn`, `clone_fn`, `discard_fn`) into their corresponding `git_hash_*` wrapper functions. The conversion is enforced by a new Coccinelle semantic patch (`tools/coccinelle/hash.cocci`) that covers all five wrapper functions, ensuring future consistency. Two files are modified: `builtin/submodule--helper.c` (8 lines changed) and `t/helper/test-synthesize.c` (29 lines changed, including dropping a now-unused `algo` parameter from `write_uncompressed_zlib()`). The patch is purely mechanical and introduces no behavior changes; it simply removes the need to pass around the `algo` pointer separately, relying instead on the `algop` field already stored in the `git_hash_ctx` struct. This aligns with the series’ goal of standardizing the API and paves the way for the idempotent `git_hash_discard()` implementation in patch 4. No technical objections remain; the patch is ready for integration. Key symbols: `git_hash_update()`, `git_hash_final()`, `git_hash_final_oid()`, `git_hash_clone()`, `git_hash_discard()`, Coccinelle rule `tools/coccinelle/hash.cocci`.
