This is the eighth patch in Justin Tobler’s v3 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It adds plumbing so that child processes (like `git-index-pack` and `git-unpack-objects`) can inherit the transaction’s staging area via environment variables.

The patch introduces `odb_transaction_env()`, a new interface that backends implement to populate a `strvec` with the environment variables needed for child processes to access the transaction’s object directory. The “files” backend implements this by calling `tmp_objdir_env()`, which is the same mechanism `tmp_objdir` used. No behavior changes; this is pure infrastructure for the final conversion in patch 11/11.

The diff is small (39 lines across three files) and mechanical: add the `env` callback to the `struct odb_transaction` vtable, implement it for the files backend, and expose a public wrapper. The commit message clearly states the motivation—child processes need access to uncommitted objects—and the implementation is straightforward.

This patch is uncontroversial and already carries Patrick Steinhardt’s Reviewed-by from earlier iterations. It’s a necessary step toward the series’ goal and looks ready for `next`.
