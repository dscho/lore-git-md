This is a maintainer response to a bugfix patch for the submodule subsystem.

Junio acknowledges the regression introduced in Git v2.49 by commit 3ad0ba722744 and confirms that the `-i` shorthand for `git submodule update --init` has been broken since then, with no prior reports. He briefly considers an alternative fix—modifying the shell script to pass `--init` instead of `-i` to `submodule--helper`—but ultimately endorses Dominique Martinet’s original approach of teaching `submodule--helper` to recognize the short option. The rationale is that users should not be running `submodule--helper` directly, so adding the alias there is cleaner and more consistent with how other short options are handled.

The patch is now effectively accepted and will be applied. No further discussion or changes are expected. This is a minimal, uncontroversial fix for a documented regression, though its practical impact remains limited due to the option’s undocumented status. The thread is now closed.
