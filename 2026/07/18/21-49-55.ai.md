This is patch 6/13 of the GSoC v20 `git cat-file --batch-command` remote-object-info series, a refactoring step that moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` to enable broader reuse. The patch is mechanical: the function is relocated verbatim, a forward declaration for `struct string_list` is added to `connect.h`, and the original function is removed from `fetch-pack.c`. No behavior changes are introduced.

The move prepares for patch 7/13, which will generalize the function into `write_command_and_capabilities()` by adding a `command` parameter, allowing it to be reused for non-fetch protocol v2 operations like `object-info`. The forward declaration in `connect.h` is safe because the function only uses `struct string_list` as a pointer, avoiding the need to include the full header.

This patch is uncontroversial and has been reviewed in previous iterations. The only change since v19 is the build fix in patch 5/13 (changing `hash_algo` from `int` to `const unsigned int`), which ensures this patch compiles cleanly when the function is moved to `connect.c`. The series remains on track for `next`, with this patch serving as a prerequisite for the generalization work in patch 7/13.
