Subject: [PATCH] branch: clarify error message when deleting the current branch
Series version: standalone patch
Originating author: René Scharfe
Thread type: user-facing error message improvement

Core problem or goal
The error message from `git branch -d` when attempting to delete the currently checked-out branch is generic ("used by worktree at ..."). Users cannot tell whether the branch is locked due to a regular worktree, an ongoing `git bisect`, `git rebase`, or another internal operation. The patch replaces the generic message with a specific one that names the actual reason (e.g., "for bisect" or "for rebase").
