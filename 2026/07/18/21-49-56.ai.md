This is a refactoring patch in the `git cat-file --batch-command` remote-object-info series (v20, 7/13). It generalizes the `write_fetch_command_and_capabilities()` function into `write_command_and_capabilities()` by adding a `command` parameter, allowing it to be reused for non-fetch protocol v2 operations like `object-info`. The change is mechanical: the function is renamed, its signature updated to accept a command string, and all callers in `fetch-pack.c` are adjusted to pass `"fetch"` explicitly. No behavior changes are introduced.

The patch prepares the transport layer for the upcoming `object-info` command implementation (patch 12/13) by enabling the same capability-advertisement logic to be shared across multiple protocol v2 operations. The updated function signature and documentation in `connect.h` clarify its purpose, and the `ensure_server_supports_v2()` call is now parameterized to validate the requested command rather than hardcoding `"fetch"`.

This is a low-risk, preparatory refactor with no functional impact. It remains uncontroversial and ready for integration.
