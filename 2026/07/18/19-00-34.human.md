This is a build fix for the `remote-object-info` series, now at v19 and queued for `next`. The patch addresses a signed/unsigned comparison warning that breaks the build when `write_fetch_command_and_capabilities()` is moved from `fetch-pack.c` (which suppresses sign-compare warnings) to `connect.c` (which does not). The issue stems from `hash_algo_by_ptr()` returning an `unsigned int`, while the local `hash_algo` variable is declared as `int`.

Pablo Sabater acknowledges the problem and agrees to adjust the preparatory patch in `fetch-pack.c` before the function is relocated. The fix is mechanical—changing `hash_algo` to `unsigned int`—and has no behavioral impact, but it is critical for the series to compile cleanly. Given the series is already in `next`, this change should be incorporated before graduation to `master`. The discussion confirms the fix is straightforward and uncontroversial.
