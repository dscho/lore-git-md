This thread improves the error message when trying to delete a branch that `git bisect` is using. René Scharfe’s v2 patch, now cooking in Junio’s `next` branch, replaces the generic "used by worktree" message with a specific one for bisect ("for bisect"). The change is small and focused, addressing only the bisect case for now while deferring other scenarios (like rebase or worktrees) to future work.

The patch has broad support: Junio marked it ready for `next`, and Phillip Wood, who previously raised usability concerns about potential confusion when `git status` shows a different branch than the error message, now explicitly endorses the v2 patch as a clear improvement. Toon Claes also reviewed it positively, seeing it as a step toward a broader API for branch-safety checks. The main loose end is how to handle the "in use by a rebase" case—Junio prefers a technical message like "for rebase with merges," while Phillip Wood has suggested more detailed or user-friendly phrasing. For now, though, the bisect-specific fix is uncontroversial and on track for integration.
