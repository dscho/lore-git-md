This is a refactoring patch in the security-hardened `git cat-file --batch-command` series, now at its twentieth iteration and queued for `next`. The patch moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` to enable broader reuse in future protocol v2 operations, such as the `object-info` command introduced later in the series.

The change is mechanical: the function is relocated verbatim, a forward declaration for `struct string_list` is added to `connect.h`, and the original implementation is removed from `fetch-pack.c`. The patch prepares for a subsequent commit (7/13) that generalizes the function into `write_command_and_capabilities()` by adding a `command` parameter. No behavior changes are introduced, and the patch is uncontroversial.
