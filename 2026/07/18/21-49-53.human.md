This is a refactoring patch in the twentieth iteration of the `git cat-file --batch-command` remote-object-info series, now queued for `next`. The patch prepares for a later move of `write_fetch_command_and_capabilities()` from `fetch-pack.c` to `connect.c` by eliminating the static `advertise_sid` variable.

The change replaces the static variable with local reads of the `transfer.advertisesid` configuration in both `find_common()` and `write_fetch_command_and_capabilities()`. The default value (0) matches the original static initialization. The patch also folds the `server_supports("session-id")` check from `do_fetch_pack()` into the condition in `find_common()` to align with the v2 protocol's inline check pattern. No behavior changes are introduced; the patch is purely preparatory and mechanical.

This is the fourth patch in the 13-patch series, authored by Calvin Wan and carried forward by Pablo Sabater. The series as a whole enables secure, metadata-only object queries from remotes and is technically complete, with only minor cosmetic nits remaining before graduation to `master`. The patch itself is uncontroversial and well-motivated by the upcoming function relocation.
