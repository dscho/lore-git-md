This is patch 5/9 in Patrick Steinhardt's ODB abstraction refactoring series. It adds support for setting the mtime when writing objects, a prerequisite for converting `force_object_loose()` to use the generic `odb_source_write_object()` interface in a later patch.

The patch introduces a new `mtime` parameter (a `const time_t *`) to the ODB write and freshen interfaces, plumbing it through the entire stack: `odb_source_write_object()`, `odb_source_freshen_object()`, and all four ODB backends (files, in-memory, loose, packed). When the pointer is non-NULL, backends set the object's mtime to the specified value; when NULL, they fall back to the current time. The loose backend's `write_loose_object()` and `check_and_freshen_file()` helpers are updated to respect the new parameter, and the packed backend's `freshen_object()` callback gains mtime support for packfiles. The in-memory backend and the packed backend's `write_object()` callback (which cannot write objects) mark the parameter as unused.

The patch touches 11 files, with the bulk of the changes being mechanical plumbing. No behavior changes are expected; this is purely preparatory work for the upcoming conversion of `force_object_loose()`. The series remains part of the broader ODB abstraction effort, and this patch specifically enables the loose object backend to preserve pack mtimes when loosening objects during repack.
