This is the core client-side implementation patch for the `object-info` protocol v2 capability in the GSoC v19 series. It introduces `fetch-object-info.c`, a new source file that handles the client logic for querying object metadata (currently size only) from a remote Git server without downloading the full object.

The patch adds a dedicated function, `fetch_object_info()`, that constructs and sends an `object-info` command to the server, parses the response, and populates an array of `struct object_info` with the results. The implementation is strict: it requires protocol v2 and the `object-info` capability, validates the server's advertised attributes, and enforces bounds-checking on the response (e.g., rejecting malformed OIDs or unexpected attribute counts). A new `unrecognized` flag in `struct object_info` marks objects the server does not recognize, and the client silently omits unsupported placeholders (e.g., `%(objecttype)`) rather than failing.

The transport layer is extended with a new `fetch_object_info` vtable entry, implemented for both smart transports (`fetch_object_info_via_pack`) and transport helpers (`fetch_object_info_helper`). The patch also updates `Makefile` and `meson.build` to include the new source file. Calvin Wan is listed as the original author, with Eric Ju and Pablo Sabater contributing to the final version. The commit message notes that the request is buffered in memory (not streamed) and that the implementation is designed for extensibility beyond the current size-only scope.
