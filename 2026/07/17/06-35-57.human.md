This is the second patch in the v7 series that migrates `trust_executable_bit` and `has_symlinks` configuration flags into repository-scoped storage as part of the `the_repository` removal effort. The patch updates the performance-critical `ce_mode_from_stat()` helper to accept a `struct repository *` parameter, enabling it to access repository-scoped configuration while preserving its `static inline` status for performance.

The change is mechanical: the function signature is updated to take a repository pointer, and all callers (in `apply.c`, `builtin/update-index.c`, `diff-lib.c`, and `read-cache.c`) are adjusted to pass the appropriate repository instance. The patch also reorders boolean expressions to evaluate `S_ISREG(mode)` first, preparing for the overhead of replacing global variable accesses with getter functions. A descriptive comment is added to clarify the function’s purpose and handling of filesystem limitations.

This patch directly addresses Junio C Hamano’s design-level concern from v6, where he objected to relocating `ce_mode_from_stat()` from `read-cache.h` to `read-cache.c`. By keeping the function `static inline` in the header and adding the repository parameter, the patch preserves potential performance benefits while enabling repository-scoped configuration access. The change is uncontroversial and aligns with the series’ broader goal of eliminating global state.

The patch touches five files and introduces no behavioral changes. It is a preparatory step for the subsequent patches that migrate the configuration flags themselves. The reordering of boolean expressions and added comment improve readability without altering functionality. The patch appears well-crafted and ready for inclusion, with all prior feedback addressed.
