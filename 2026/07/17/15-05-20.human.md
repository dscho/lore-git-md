This is the tenth patch in the nineteenth iteration of a security-hardened feature series that adds `git cat-file --batch-command` support for querying object metadata from remotes. The series is now queued for `next` and targets the `serve.c` file to advertise the `object-info` capability.

This patch enables servers to advertise which object metadata attributes they support—currently only `size`—when the `transfer.advertiseobjectinfo` configuration is enabled. The change is minimal: the `object_info_advertise` function now appends `"size"` to the `value` strbuf if the feature is advertised, allowing clients to dynamically determine what queries are possible without falling back to full fetches. The patch is authored by Calvin Wan but carries sign-offs from Eric Ju and Pablo Sabater, reflecting collaborative refinement.

The commit message is clear and concise, explaining the purpose (client awareness of server capabilities) and the immediate scope (size-only support). No test coverage is included here, but the broader series adds extensive tests in `t/t1017-cat-file-remote-object-info.sh` to verify the feature works end-to-end. The patch itself is straightforward and unlikely to introduce regressions, as it only appends a static string to an output buffer when explicitly configured.
