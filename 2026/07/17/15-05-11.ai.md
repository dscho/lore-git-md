This is a bugfix patch in the GSoC `git cat-file --batch-command` remote object info series (v19). It plugs a memory leak in `transport-helper.c` where `data->name`—allocated during `transport_helper_init()`—was not being freed if the helper process had not yet started when `disconnect_helper()` was called. The fix moves the `FREE_AND_NULL(data->name)` call outside the conditional block so it executes unconditionally on disconnect. The change is mechanical, one-line, and preserves existing behavior while fixing the leak. This is a prerequisite cleanup for the larger series, which is now queued for `next`.
