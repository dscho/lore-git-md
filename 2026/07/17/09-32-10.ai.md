This is a test infrastructure patch, the second in Patrick Steinhardt’s nine-patch series refactoring the loose object backend for the ODB abstraction effort.

The patch introduces a small wrapper function, `cl_assert_write_object()`, in the in-memory unit-test backend (`t/unit-tests/u-odb-inmemory.c`). The wrapper encapsulates the call to `odb_source_write_object()` so that the next patch in the series can change the write interface without requiring edits to every test case. Twenty-five direct calls are replaced with the wrapper, making the diff almost entirely mechanical.

No behavior changes are introduced; the patch is purely preparatory. It touches only the in-memory test backend and is a clean, localized refactoring that keeps the test suite in sync with the evolving ODB write interface.
