Core problem or goal
Add a built-in userdiff driver for the Swift programming language so that `git diff` and `git log -p` produce meaningful hunk headers and word-level diffs for `.swift` files without requiring manual `.gitattributes` configuration.

- New symbols: `builtin_swift_patterns` (funcname and word_regex entries).

- On-disk format: none; purely in-memory regex compilation.
- Test coverage: 13 test cases covering classes, structs, enums, protocols, extensions, actors, attributes, modifiers, generics, failable initializers, and operator functions.
