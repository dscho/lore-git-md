This is the second patch in K Jayatheerth’s seven-patch GSoC series that extends `git repo info` with path-related keys. It adds `path.superproject-working-tree.absolute` and `path.superproject-working-tree.relative`, exposing the superproject’s working-tree location in a scriptable, config-like format. The implementation is clean: it reuses the existing `get_superproject_working_tree()` helper, formats the result with `format_path()`, and returns an empty string when not inside a submodule. Documentation and tests are complete, covering both absolute and relative paths, submodule contexts, and the standalone-repository edge case. No substantive review has landed yet, so the naming (`superproject-working-tree` vs. alternatives like `superproject.root`) and suffix semantics remain open for discussion. The patch is mechanically solid and ready for technical feedback.
