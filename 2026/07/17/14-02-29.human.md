This is a feature patch adding a built-in userdiff driver for the Swift programming language. The patch is self-contained, well-motivated, and includes thorough test coverage.

The patch teaches Git to recognize Swift declarations (functions, classes, structs, enums, protocols, extensions, actors, initializers, and subscripts) in diff hunk headers, replacing the generic heuristic that currently names the enclosing type instead of the changed function. The funcname pattern is built directly from Swift’s declaration grammar, covering attributes, modifiers, failable initializers, generics, and operator functions. The word regex handles Swift identifiers, literals (hexadecimal, octal, binary, integer, floating-point), and operators.

The commit message clearly explains the motivation, the design choices, and the edge cases covered (or intentionally omitted). The patch adds 13 new test fixtures in `t/t4018/` that exercise all the supported declaration forms, and the author reports that all tests pass, including the builtin_drivers check. The implementation touches only `Documentation/gitattributes.adoc` and `userdiff.c`, making it a clean, focused addition.
