This is a small refactoring patch in the nineteenth iteration of the `git cat-file --batch-command` remote object info series. It tightens variable scope by declaring loop counters inside `for()` statements where they are only used within the loop, and updates the types of those counters from `int` to `size_t` to match the types of the values they iterate over (object counts, array sizes).

The patch touches two files: `builtin/cat-file.c` (the main focus) and `fetch-pack.c` (a mechanical update). In `cat-file.c`, it also changes the `nr` parameter of `dispatch_calls()` from `int` to `size_t`, since all callers already pass a `size_t` value. The changes are purely internal and do not alter behavior.

This is a cleanup patch that improves code hygiene and readability. It is uncontroversial and well-motivated, aligning with Git's preference for tight variable scope and type consistency.
