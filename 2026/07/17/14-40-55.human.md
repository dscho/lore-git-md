This is a follow-up to Sahitya Chandra’s performance patch for the `wt-status` subsystem, now posted as v2. The patch replaces a loop of quadratic-time `string_list_insert()` calls with a single `string_list_append()` pass followed by one sort and deduplicate operation per list (`s->untracked` and `s->ignored`). The change is small (6 insertions, 2 deletions) and touches only `wt_status_collect_untracked()` in `wt-status.c`.

The motivation has shifted since v1: the commit message no longer claims this is a real-world performance bottleneck, but instead presents the patch as an improvement to code clarity and maintainability. Both Patrick Steinhardt and Jeff King agreed the original quadratic-time behavior was likely theoretical, and Peff endorsed the change for making the code’s complexity more transparent. The patch now uses `string_list_sort_u()` as Patrick suggested, and Sahitya explicitly acknowledges the conservative design choice of deduplicating even if `fill_directory()`’s output is already unique.

No benchmarks were added, and the patch preserves the existing behavior of producing sorted, duplicate-free lists. The patch looks ready for further review or integration; it is well-motivated, narrowly scoped, and addresses the feedback from the previous round.
