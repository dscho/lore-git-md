This is a refactoring patch in the `remote-object-info` series (GSoC v19, 4/13). It removes the static `advertise_sid` variable in `fetch-pack.c` to prepare for moving `write_fetch_command_and_capabilities()` to `connect.c` in a later patch. The change is mechanical: the static variable is replaced with local initializations in `find_common()` and `write_fetch_command_and_capabilities()`, and the `server_supports("session-id")` check in `do_fetch_pack()` is folded into the condition in `find_common()` to match the v2 protocol's inline check pattern.

The patch is authored by Calvin Wan but carries sign-offs from Eric Ju and Pablo Sabater, reflecting collaborative work on the series. No behavior changes are introduced; the commit message confirms the default value (0) matches the original static initialization. This is a clean preparatory step for the larger refactoring goal, with no functional impact on the series' security or protocol features. The change aligns with the series' broader focus on stateless RPC design and code reuse.
