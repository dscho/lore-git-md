This is the fifth patch in K Jayatheerth’s seven-patch GSoC series adding path-discovery keys to `git repo info`.  It introduces `path.index.absolute` and `path.index.relative`, exposing the location of the index file in both absolute and relative-to-cwd formats.  The implementation uses `repo_get_index_file()` and respects the `GIT_INDEX_FILE` environment override, exactly mirroring the existing behavior of `git rev-parse --git-path index`.  Documentation and tests are included; the patch is mechanically clean and ready for technical review.  No substantive feedback has been posted yet, so the naming (`path.index` vs. `path.index-file`) and the choice of suffixes remain open for discussion.
