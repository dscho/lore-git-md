This is the fourth patch in K Jayatheerth’s seven-patch GSoC series that extends `git repo info` with path-related keys. It adds the `path.hooks.absolute` and `path.hooks.relative` keys, exposing the hooks directory location in a scriptable way while respecting the `core.hooksPath` configuration. The implementation is straightforward: it uses `repo_git_path_replace()` to resolve the hooks path and `format_path()` to produce absolute or relative output. Tests verify both the standard `.git/hooks` fallback and the `core.hooksPath` override, and the documentation is updated to list the new keys. The patch is mechanically clean, well-tested, and ready for technical review; the only open question is whether reviewers will prefer a different key name (e.g., `path.hookdir` instead of `path.hooks`) for consistency with existing Git terminology.
