This is the fifth patch in Patrick Steinhardt’s nine-patch refactoring series that moves loose-object writing logic into the ODB abstraction layer. The patch adds support for setting the mtime when writing objects, which is needed so that `force_object_loose()` can preserve the original pack’s timestamp when loosening objects before repacking. Without this, the loose object would get the current time, which could cause it to be incorrectly pruned later.

The change is mechanical: a new `const time_t *mtime` parameter is threaded through the entire ODB write stack, from the top-level `odb_source_write_object()` down to each backend’s implementation (`source-loose.c`, `source-files.c`, `source-inmemory.c`, and `source-packed.c`). If the pointer is NULL, backends continue to use the current time; if it is set, they apply the specified timestamp. The patch also updates the `freshen_object()` callbacks to accept the same parameter, ensuring that freshening an object can preserve its mtime as well.

Eleven files are touched, but the changes are straightforward interface plumbing with no behavior change in the default case. The series remains a pure refactoring, continuing the ODB abstraction effort.
