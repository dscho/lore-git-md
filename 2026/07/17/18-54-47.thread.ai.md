Core problem or goal
The `git history fixup` command (introduced in Git 2.46, 2026) does not properly isolate index modifications to the current worktree. When run in one worktree, it leaves spurious staged changes in other worktrees that share the same repository, corrupting their index state without any user action in those worktrees.
