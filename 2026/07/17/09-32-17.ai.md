This is the final patch (9/9) in Patrick Steinhardt’s ODB abstraction refactoring series. It completes the relocation of loose-object writing logic from `object-file.c` into `odb/source-loose.c`, making the loose backend fully self-contained.

The patch exposes two transaction-related helper functions (`odb_transaction_files_prepare` and `odb_transaction_files_fsync`) that were previously static in `object-file.c`, then moves the entire loose-object writing machinery—including the `start_loose_object_common`, `write_loose_object_common`, `end_loose_object_common`, `create_tmpfile`, and `close_loose_object` helpers—into the loose backend. The only remaining loose-object function in `object-file.c` is now `odb_source_loose_write_stream`, whose TODO comment still notes that it should eventually move as well. A single reference to `the_repository` is replaced with the source’s repository handle, continuing the `the_repository` removal effort.

The diff shows a net deletion of ~379 lines from `object-file.c` and a corresponding addition of ~357 lines in `odb/source-loose.c`, with only minor header adjustments. No behavior changes are introduced; this is pure code relocation. The patch is well-motivated by the series’ goal of consolidating loose-object logic and is built on the preparatory refactorings in earlier patches.
