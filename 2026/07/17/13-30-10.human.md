This is the second patch in K Jayatheerth’s seven-part GSoC series adding path-related keys to `` `git repo info` ``. It introduces `path.superproject-working-tree.absolute` and `path.superproject-working-tree.relative`, which expose the superproject’s working-tree root when the current repository is an initialized submodule, and return an empty string otherwise. The implementation reuses Git’s existing `get_superproject_working_tree()` helper and the `format_path()` utility with `PATH_FORMAT_CANONICAL` or `PATH_FORMAT_RELATIVE` to produce the two variants. Tests cover both the absolute and relative cases inside a submodule and verify the empty-string behavior in a standalone repository. The patch is mechanically clean, well-documented, and ready for substantive review of the key naming and overall design.
