This is the seventh patch in Patrick Steinhardt’s nine-patch series refactoring the loose-object backend as part of the ODB abstraction effort. It prepares `force_object_loose()` to be moved out of `object-file.c` by rewriting it to use the generic `odb_source_write_object()` interface instead of the loose-backend–specific `write_loose_object()`. The patch is a straightforward mechanical conversion: the function now passes the pre-computed object buffer, type, and mtime through the generic write path, and the compatibility-object-ID handling is lifted into the same call. No behavior changes are introduced; the patch exists solely to enable the subsequent commit that will relocate the logic into the loose backend’s own file. The diff is small (19 lines) and the rationale is clear, making this a low-risk step in the larger refactoring.
