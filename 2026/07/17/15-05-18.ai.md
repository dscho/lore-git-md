This is a refactoring patch in the `git cat-file --batch-command` remote object info series (GSoC v19, 8/13). It moves variable initialization out of the `FETCH_CHECK_LOCAL` state in `do_fetch_pack_v2()` to a point before the state machine begins, ensuring the variables are set regardless of the initial state. The change is mechanical and preparatory: a later patch in the series will introduce an alternative initial state, and this patch ensures the necessary variables are initialized in both cases. No behavior changes are introduced; the commit message explicitly notes this is a no-op move. The patch is authored by Calvin Wan, with help from Jonathan Tan and Christian Couder, and carried forward by Pablo Sabater and Eric Ju. It touches only `fetch-pack.c` and is part of the broader effort to enable stateless RPC for remote object metadata queries.
