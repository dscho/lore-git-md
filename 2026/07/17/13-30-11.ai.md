This is the third patch in the seven-patch `git repo info` path-key series (v2). It adds `path.objects.absolute` and `path.objects.relative` keys to expose the object database directory location, respecting the `GIT_OBJECT_DIRECTORY` environment override. The implementation uses `repo_get_object_directory()` and the existing `format_path()` helper with `PATH_FORMAT_CANONICAL` or `PATH_FORMAT_RELATIVE` flags, mirroring the pattern established in patches 1/7 and 2/7.

The patch touches `builtin/repo.c` (adding two new getter functions and registering the keys), `Documentation/git-repo.adoc` (documenting the new keys), and `t/t1900-repo-info.sh` (adding tests for standard and overridden object directory paths). The tests verify that the keys return the expected paths and respect the environment variable, including edge cases like creating a custom object directory. The code is mechanically clean and follows the series' established structure.

This patch continues the series' goal of making repository component paths scriptable without requiring direct access to Git internals. The `path.objects` keys are likely uncontroversial in principle, but reviewers may suggest naming adjustments (e.g., `path.objectdir` instead of `path.objects`) for consistency with existing Git terminology. The series remains under review, with no substantive feedback yet on the design or implementation beyond Junio's earlier mechanical comments on patch 7/7.
