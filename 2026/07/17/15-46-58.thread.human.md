Toon Claes's six-patch series optimizing `git last-modified` by reusing Bloom filters is now complete and under final review. The series achieves a 3.7× speedup (60.7 ms → 16.2 ms) without `--show-trees` and a 1.95× speedup (61.9 ms → 31.8 ms) with it on the ziglang/zig repository, bringing performance nearly to parity with `git log` while fully supporting wildcard pathspecs like `*.c`.

All prior feedback has been addressed: the public API was refactored to use boolean returns for clarity, unintended behavioral changes in Bloom filter statistics were reverted, the `--show-trees` correctness bug was fixed, and missing trailers for Jeff King were added. The final patch in the series resolves a critical edge case where `prepare_revision_walk()` clears `bloom_filter_settings`, breaking wildcard pathspec lookups—this is now fixed by restoring the settings pointer afterward. Junio C Hamano's latest review suggests adding a test to verify this edge case, noting that while the fix is correct, the failure mode is subtle and would benefit from explicit coverage. The series is otherwise ready for integration, with no remaining technical blockers.
