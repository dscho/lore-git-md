This is the third patch in Patrick Steinhardt’s nine-patch refactoring series that moves loose-object writing logic into the ODB abstraction layer. The focus here is narrow: centralize object-hash computation inside `odb_write_object_ext()` so that every backend can rely on the same code path. The patch deletes the now-redundant `write_object_file_prepare()` helper, updates all four ODB backends (files, in-memory, loose, packed) to accept a `const struct object_id *` instead of a writable pointer, and adjusts the in-memory unit-test wrapper to call `hash_object_file()` before invoking the backend. No behavior changes are introduced; the diff is purely mechanical and prepares the ground for the next patch, which will lift the object-existence check out of the loose backend.
