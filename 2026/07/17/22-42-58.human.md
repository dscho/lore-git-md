This is the first patch in the v2 series introducing `--auto-reset` to `git bisect`. Junio C Hamano reviews the preparatory refactoring that replaces `print_file_to_stdout()` with `print_fd_to_stdout()`, allowing the bisect run output to be read from the already open file descriptor instead of reopening the file by name.

The change is small and uncontroversial: it avoids potential issues with file accessibility by name and aligns with Git’s preference for minimizing file operations. Junio notes the shift from `O_WRONLY` to `O_RDWR` to enable seeking, and while he briefly considers whether seeking could fail in edge cases, he concludes the risk is negligible and accepts the patch as-is. The refactoring has no user-visible impact and is a necessary foundation for the `--auto-reset` feature in later patches.

This patch touches only `builtin/bisect.c` and is ready for integration. No test failures or behavioral changes are introduced, and the commit message clearly explains the motivation. The review is surface-level but sufficient for a straightforward refactoring.
