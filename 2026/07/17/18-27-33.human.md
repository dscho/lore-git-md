This is the second patch in Harald Nordgren’s three-patch series adding the `--auto-reset` option to `git bisect`. It is a small, targeted refactoring that adds a `quiet` parameter to the `bisect_reset()` function so that the upcoming `--auto-reset` feature can suppress the noisy checkout output when restoring the original HEAD. No behavior changes yet—every caller still passes `0`—so the patch is purely preparatory and should be uncontroversial. The change is confined to `builtin/bisect.c` and is covered by the existing test suite.
