The Swift userdiff driver for Git is ready to graduate. Shlok Kulshreshtha’s patch adds built-in support for Swift in `git diff` and `git log -p`, replacing generic heuristics with language-aware patterns for function declarations and word boundaries. The patch has been queued in `next` after addressing all substantive feedback from its first version, including regex optimizations and test fixes. Johannes Sixt, who reviewed the initial submission, has now explicitly approved the updated version, and Junio C Hamano has marked it as technically complete.

The implementation touches `userdiff.c` and `Documentation/gitattributes.adoc`, and includes 13 test cases in `t/t4018/` covering Swift’s various declaration forms. A minor suggestion to add a word-level diff test in `t/t4034-diff-words.sh`—raised by Swift user Michael Montalbo—was declined by Sixt as disproportionate effort for a microproject, and the thread has since closed without further discussion. The patch is now in the standard integration testing phase and is expected to graduate to `master` in the current cycle.
