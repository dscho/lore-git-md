This thread is about adding built-in Git diff support for Swift files. Shlok Kulshreshtha submitted a patch that teaches Git to recognize Swift syntax in diffs, eliminating the need for manual `.gitattributes` setup. The patch is technically complete but currently parked in Junio’s `seen` branch, awaiting real-world validation from Swift developers on the list before it can move forward.

Johannes Sixt (Hannes) provided a detailed review earlier, flagging minor test ambiguities (duplicate placeholder tokens in test files) and suggesting regex optimizations. In the latest email, Hannes walks back one of those suggestions—he no longer recommends replacing a generic `[a-z]+` pattern with an explicit list of Swift keywords, as the original version works fine and there’s no evidence of performance issues. The other feedback (cleaning up test fixtures) still stands, and Shlok is expected to post a v2 addressing it.

The only remaining blocker is validation: Junio wants confirmation from active Swift users that the regexes accurately capture real-world Swift syntax. Until that happens, the patch stays in `seen`. No other objections or open questions remain.
