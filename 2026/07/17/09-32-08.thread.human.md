This thread is a patch series from Patrick Steinhardt refactoring Git’s loose object backend to make it fully self-contained as part of the ongoing ODB abstraction effort. The series moves all loose-object writing logic from `object-file.c` into `odb/source-loose.c`, centralizes object hash computation and mtime handling in the generic ODB layer, and eliminates direct calls to `write_loose_object()`. It’s a pure refactoring with no behavior or on-disk format changes, but it depends on two recent topics and requires an evil merge to resolve a conflict in the packed backend’s transaction handling.

The series was posted in full as v1 and is under review, but SZEDER Gábor just reported a build-breaking issue: the evil merge needed to resolve a function signature mismatch in `odb/source-packed.c` was applied when `jt/receive-pack-use-odb-transaction` was merged into Junio’s `jch` branch, but Patrick’s series was based on a version that didn’t include that resolution. As a result, none of the nine patches compile. This is a mechanical problem, not a technical disagreement, but it will require a v2 to fix. No other reviews have been posted yet, so the only open question is whether additional feedback will surface once the build issue is resolved.
