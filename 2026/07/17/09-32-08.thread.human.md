This thread is a nine-patch refactoring series by Patrick Steinhardt that moves Git’s loose object backend logic out of `object-file.c` and into `odb/source-loose.c`, making it fully self-contained as part of the ongoing ODB abstraction effort. The series is now complete with the final patch (9/9), which relocates the remaining loose-object writing machinery—including transaction helpers and stream-writing internals—into the loose backend, leaving only one loose-object function in `object-file.c` with a TODO comment for future relocation.

The refactoring is purely structural, with no behavior or on-disk format changes, and includes preparatory steps like centralizing object hash computation, lifting object-existence checks out of the loose backend, and adding mtime support to the ODB write interface. The series also fixes a memory leak in `force_object_loose()` and updates the in-memory test backend to support the new interfaces. It builds on two recent topics (`jt/receive-pack-use-odb-transaction` and `jk/git-hash-cleanups`) and requires an evil merge to resolve a conflict in the packed backend’s transaction handling.

No reviews have been posted yet, so the series remains under initial review. While the patches are presented as a well-structured refactoring, reviewers may raise questions about the transaction interface changes, the impact on other ODB backends, or the performance implications of the new mtime plumbing. The series is part of Patrick Steinhardt’s broader ODB abstraction effort, which aims to enable pluggable object storage backends.
