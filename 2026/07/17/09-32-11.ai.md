This is the third patch in Patrick Steinhardt's 9-patch refactoring series for the ODB abstraction effort. It centralizes object hash computation in the generic `odb_write_object_ext()` function, eliminating duplicate logic across the four ODB source backends (files, in-memory, loose, packed).

The patch removes the now-redundant `write_object_file_prepare()` helper from `object-file.c` and updates all backend implementations to expect a precomputed `const struct object_id *` instead of computing the hash themselves. This change enables the next patch in the series, which will lift the object existence check out of the loose backend into the generic layer. The in-memory unit-test backend (`t/unit-tests/u-odb-inmemory.c`) gains a call to `hash_object_file()` in its test wrapper to maintain correctness.

No behavior changes are introduced; this is a pure refactoring that touches 9 files. The patch appears clean and well-scoped, continuing the series' goal of making the ODB layer more modular. Reviewers may focus on whether the new `const` qualifier on the `oid` parameter is consistently respected across all backends and whether the test wrapper's hash computation is correctly placed.
