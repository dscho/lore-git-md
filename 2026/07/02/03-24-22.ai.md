This is a **platform-compatibility follow-up** to the already-merged Apache timeout patch. Michael Montalbo notes that the upstream Apache bug report (bug 70131) is hidden behind a login wall, which limits visibility for future Git contributors debugging similar CI hangs. To preserve the diagnostic context, he submitted a public patch to Apache’s GitHub mirror that documents the issue in detail.

The email is brief and factual, linking to the external pull request. It does not propose any changes to Git itself, but it provides useful historical context for anyone investigating HTTP/2 stalls or `curl 18` errors in the future. The patch’s existence is worth noting in the digest, but it does not require further action from the Git project.
