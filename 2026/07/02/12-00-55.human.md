This is the second patch in Toon Claes’s nine-patch series that makes `GIT_TEST_LONG` tests reliable and efficient in CI. It fixes a specific test in `t0021-conversion.sh` that writes a 2 GB file and round-trips it through clean/smudge filters. On 64-bit systems the test is broken: instead of failing cleanly it hangs in CI, and the failures are unreliable (often ENOMEM). The patch simply adds `SIZE_T_IS_64BIT` to the test prerequisites, so the test is skipped on 64-bit platforms where it cannot work correctly. The change is a one-line diff in the test script and is uncontroversial.
