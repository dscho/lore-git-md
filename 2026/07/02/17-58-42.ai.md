This is the v6 iteration of a feature addition that teaches `git replay` a `--linearize` option to flatten merge commits, producing a linear history. The series is now technically complete and addresses all prior feedback, including the regression in `--linearize` behavior when replaying a single branch containing merge commits. The author has fully aligned with Johannes Schindelin’s technical direction, restoring the `replayed_base` parameter to ensure all replayed commits are flattened into a single linear topology.

The series consists of three patches: two refactoring patches (one new, one carried over and reworked) and the core implementation patch. The new patch (2/3) moves the logic for resolving the replay base outside `pick_regular_commit()`, improving clarity and maintainability. The core patch (3/3) implements `--linearize` by skipping merge commits and reparenting subsequent commits onto the previous non-merge commit, ensuring a single linear history even when multiple branches are involved. The commit message and documentation have been drastically extended to explain the behavior, edge cases, and differences from `git rebase --no-rebase-merges`. Test coverage is now thorough, including scenarios for replaying multiple divergent branches, handling merge commits, and verifying the behavioral difference from `git rebase`.

The interface design debate remains unresolved but is no longer blocking. The series continues to use `--linearize` as a standalone flag, diverging from `git rebase`'s `--rebase-merges=<mode>` syntax. The author and Johannes Schindelin argue that `--linearize` better describes the predictable, all-or-nothing flattening behavior, while Patrick Steinhardt’s requirement for explicit justification of any divergence from `git rebase`'s syntax has been met in the commit message. The behavioral difference between `git replay --linearize` and `git rebase --no-rebase-merges` is now documented and tested, and the regression fix ensures correct behavior when replaying a single branch containing merge commits.
