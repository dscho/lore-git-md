This is the sixth patch in Toon Claes’s nine-patch series making `GIT_TEST_LONG` tests reliable and efficient for CI. It refactors `t7900-maintenance.sh` to clean up the 2 GB repository immediately after the test finishes, reducing peak disk usage and preventing the data from being repacked by later tests.

The patch moves the expensive test into a dedicated sub-repository (`expensive-repo`) that is deleted via `test_when_finished`. It also disables auto-maintenance inside the sub-repository to avoid races with the manual maintenance commands the test runs. The change is purely mechanical: the test logic is unchanged, but the repository is now isolated and ephemeral. No new prerequisites, options, or behavior are introduced. The patch is authored by Patrick Steinhardt and is part of the broader effort to make `GIT_TEST_LONG` tests CI-friendly.
