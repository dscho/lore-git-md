This is a substantive design discussion about the commit-message template for `git history squash --reedit-message`. Phillip Wood and Junio C Hamano are converging on a minimalist template format that omits fully discarded messages (like `amend!` commits) while retaining a numbered list of commit subjects for context. Phillip clarifies that `amend!` commits replace only their target commit’s message, so unrelated commits (like the first in the example) should still appear in the template. The proposed layout shows the editable message body (from `amend!` or `squash!` commits) below a summary of all squashed commits, with minimal separators to reduce visual clutter. This exchange resolves the last open question about the template’s structure before the series is merged. The discussion is technical but focused on usability, and the outcome will likely be reflected in a final tweak to the `build_squash_message()` helper.
