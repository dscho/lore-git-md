This is the fifth patch in Toon Claes’s nine-patch series making `GIT_TEST_LONG` tests reliable and efficient for CI. It targets a single test in `t7508-status.sh` that creates and adds files larger than 4 GiB. Because Git tracks object sizes in a `size_t`, the test fails (and hangs in the `linux32` CI job) on 32-bit systems. The fix is minimal: the test now gains the `SIZE_T_IS_64BIT` prerequisite, so it is skipped on platforms where `size_t` cannot represent the required file sizes. The change is uncontroversial and directly addresses a known CI hang.
