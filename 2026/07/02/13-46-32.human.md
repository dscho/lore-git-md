This is an **announcement for Git for Windows 2.55.0(2)**, a hotfix release targeting a critical NTLM authentication regression. The update restores optional NTLM support, which was accidentally disabled in the previous 2.55.0 release, giving users a temporary reprieve before NTLM is permanently dropped later this year. The release also notes that Windows 8.1 support will end after this version, following upstream MSYS2’s deprecation plans.

The fix is narrow but important for users relying on NTLM authentication (common in enterprise environments). No other changes are mentioned, and the update is available in all standard Git for Windows variants (installer, portable, MinGit, and ARM64 builds). The tone is matter-of-fact, reflecting the urgency of the regression while acknowledging the planned deprecation of NTLM.

For most Git users, this is a niche concern—unless they’re on Windows and using NTLM, they can safely ignore it. The announcement is primarily relevant to packagers and enterprise admins who need to test the hotfix before wider deployment. The provided checksums ensure integrity for those downloading the binaries.
