This is a build system bugfix for the Meson build. Patrick Steinhardt confirms the analysis in D. Ben Knoble’s patch: the `hook-list.h` header must be generated before both `hook.c` and `builtin/bugreport.c` are compiled, but the current `meson.build` only lists it as a dependency for the libgit sources, not the builtin sources. This creates a race condition that can cause build failures when the header is missing.

The patch moves the `custom_target` definition for `hook-list.h` earlier in `meson.build` and adds it to both `libgit_sources` and `builtin_sources`, ensuring the header is generated in the correct order. Patrick’s reply includes a reproduction case (`ninja -C build git.p/builtin_bugreport.c.o`) that demonstrates the failure, and he explicitly endorses the fix as correct.

This is a straightforward, well-motivated fix for a clear regression introduced by commit `2eb541e8f2a9`. It touches only the Meson build configuration, has no effect on the Makefile or other build systems, and has already received a tested, surface-level review from Adrian Ratiu. The patch looks ready to merge.
