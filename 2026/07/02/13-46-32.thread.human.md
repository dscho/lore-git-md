This is a brief announcement about **Git for Windows 2.55.0(2)**, a hotfix release from Johannes Schindelin. The update reverses a premature disabling of NTLM authentication support that was introduced in the previous 2.55.0 release, restoring it as an opt-in feature until its planned deprecation in 2026. The release also marks the last version to support Windows 8.1, aligning with the MSYS2 project’s timeline.

This is purely a Git for Windows packaging change—no upstream Git code is affected. The email includes download links and checksums for all build variants but doesn’t invite discussion or imply further action. If you’re not using Git for Windows, this update doesn’t impact you.
