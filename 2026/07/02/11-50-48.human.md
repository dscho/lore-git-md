This is a **build system patch** for the ongoing Rustification effort, specifically addressing macOS Universal Binary support for Rust components. Patrick Steinhardt raises substantive questions about the patch's scope and implementation in this review.

The patch combines two changes: linking the macOS credential helper with Rust libraries, and adding Universal Binary support via the `RUST_TARGETS` environment variable. Patrick argues these should be split into separate commits, as they address unrelated concerns. He also requests clearer motivation for Universal Binaries—what they are and why Git needs them—suggesting the commit message lacks sufficient context for non-macOS developers.

On the technical side, Patrick questions whether `lipo` (the tool used to combine architectures) is universally available on macOS, and whether treating only the Rust library as universal is sufficient. He points out that if the rest of Git isn’t built as a Universal Binary, the Rust components alone won’t provide meaningful multi-architecture support. This review is substantive, as it challenges the patch’s design assumptions rather than just its implementation details.

The thread context shows this is the second iteration of the patch, with prior feedback from Junio Hamano already incorporated. However, Patrick’s concerns suggest the patch may need further refinement before merging. If resolved, this would be a useful addition for macOS users needing multi-architecture builds, but the current version appears incomplete in its justification and scope.
