This is a build system fix for the Meson build, addressing a race condition that causes intermittent build failures. The patch ensures `hook-list.h` is generated before `builtin/bugreport.c` is compiled by explicitly listing the header in both `libgit_sources` and `builtin_sources` in `meson.build`.

Patrick Steinhardt confirms the issue and the fix in his reply. The problem arises because `hook-list.h` is required by both `hook.c` (in `libgit_sources`) and `builtin/bugreport.c` (in `builtin_sources`), but the build system only enforced the dependency for the former. This leads to failures when `bugreport.c` is compiled before the header is generated. The fix moves the `custom_target` definition for `hook-list.h` earlier in the file and adds it to both source lists, ensuring the header is available when needed.
