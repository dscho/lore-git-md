This is the seventh patch in Toon Claes’s nine-patch series making `GIT_TEST_LONG` tests reliable and efficient for CI. It is a small, mechanical change that replaces ad-hoc string checks for the `GIT_TEST_LONG` environment variable with the `test_bool_env` helper introduced earlier in the series.

The patch touches two files: `ci/lib.sh` and `t/test-lib.sh`. In `ci/lib.sh`, it changes the exported value from `YesPlease` to `true` so that `test_bool_env` can parse it consistently. In `t/test-lib.sh`, it updates both the command-line option parser (`--long-tests`) and the `EXPENSIVE` prerequisite to use `test_bool_env GIT_TEST_LONG false` instead of a bare string check. The result is that setting `GIT_TEST_LONG=false` now reliably disables the long tests, which was not guaranteed before.

The change is uncontroversial and aligns with the series’ goal of making `GIT_TEST_LONG` behavior predictable. No new functionality is introduced; this is purely plumbing. The patch is ready to merge once the rest of the series lands.
