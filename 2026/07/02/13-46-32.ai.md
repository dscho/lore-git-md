This is a **Git for Windows** release announcement, not a patch to the Git project itself. Johannes Schindelin announces Git for Windows 2.55.0(2), a hotfix release addressing a premature disabling of NTLM authentication support in the previous 2.55.0 release.

The fix temporarily re-enables optional NTLM support, which had been mistakenly disabled entirely. This is framed as a preview of the planned deprecation of NTLM later in 2026, when it will be removed without an opt-in option. The announcement also notes that Windows 8.1 support will be dropped after this release, following the MSYS2 project’s lead.

No changes to the upstream Git codebase are involved—this is purely a Git for Windows packaging update. The email includes checksums for all available download variants (64-bit, ARM64, 32-bit, portable, MinGit, and busybox builds). The tone is matter-of-fact, with no controversy or follow-up discussion implied.
