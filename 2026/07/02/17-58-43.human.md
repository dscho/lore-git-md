This is the first patch in the v6 series that fixes the `--linearize` regression in `git replay`. It introduces a small refactoring to improve code clarity in `replay.c` by extracting the logic for storing commits in the `replayed_commits` map into a new helper function, `put_mapped_commit()`. The existing `mapped_commit()` function is also renamed to `get_mapped_commit()` to pair with the new helper.

The change is purely mechanical and preparatory for the regression fix in patch 2/3. It does not alter behavior but makes the code easier to follow by separating the "get" and "put" operations on the `replayed_commits` map. The patch is well-contained, touching only `replay.c`, and the commit message clearly explains the motivation. This is a clean refactoring that should not introduce new issues.
