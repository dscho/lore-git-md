This is a build system fix for the Meson build. The patch, originally sent by Mike Gilbert and now acked by Adrian Ratiu, restores `hook-list.h` to the `builtin_sources` list in `meson.build` to ensure the header is generated before `builtin/bugreport.c` is compiled. This eliminates a race condition that caused build failures when the header was missing.

The issue was introduced by commit `2eb541e8f2a9` ("hook: move is_known_hook() to hook.c for wider use"), which moved the header generation logic but did not account for its dependency in the builtin sources. Adrian acknowledges the oversight and agrees the fix is correct.

The patch is minimal, touching only `meson.build`, and addresses a clear build breakage documented in a Gentoo bug report. It moves the `custom_target` definition for `hook-list.h` earlier in the file and adds it to both `libgit_sources` and `builtin_sources` to ensure proper generation order. The fix is straightforward and unlikely to be controversial.
