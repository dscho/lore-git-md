This is a design discussion about the commit-message template for `git history squash --reedit-message`. Phillip Wood and Junio C Hamano are converging on a minimalist template format that reduces visual clutter while preserving essential context.

The current proposal shows only the commit subjects in a numbered list (e.g., `# 1. Base subject`) for commits whose messages will be discarded (including those replaced by `amend!` or `fixup!` commits), followed by the editable message body for the squashed commit. For commits whose messages are preserved (e.g., the base commit or those modified by `squash!`), the full message is included, separated by a divider like `# -------------------------------------`. Phillip’s example clarifies that `amend!` commits do not affect unrelated commits—only their target’s message is replaced.

This discussion is the last open design question for the `git history squash` series, which is otherwise complete and ready for final review. The template tweak is minor and would only affect the `build_squash_message()` helper. No fundamental changes to the feature’s behavior are expected.
