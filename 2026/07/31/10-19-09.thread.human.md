This thread is a feature request from Thomas Nemeth for a Git configuration option to suppress warnings about trailing blank lines at the end of files. Thomas uses Vim and prefers keeping a trailing newline for easier code block selection, but finds the red-highlighted warnings in Git diffs annoying. Johannes Sixt (Hannes) responded by questioning the necessity of the feature and suggesting an alternative: using the existing `core.whitespace` configuration with `-blank-at-eof` to suppress the warning.

Thomas has since acknowledged that Hannes’s workaround achieves the desired effect, though it disables the `blank-at-eof` check entirely rather than introducing a dedicated option. The thread has reached a natural pause, with no further technical proposal or maintainer engagement. While the original request hasn’t been formally resolved or withdrawn, the immediate issue is addressed for Thomas via `core.whitespace`. The thread remains open-ended, but unless other users express similar needs or the limitations of `core.whitespace` become a recurring issue, it may not see further development.
