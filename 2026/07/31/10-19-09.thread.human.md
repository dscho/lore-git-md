Thomas Nemeth requested a Git configuration option to suppress warnings about trailing blank lines at the end of files, motivated by Vim workflow preferences. The existing `core.whitespace=-blank-at-eof` setting (suggested by Johannes Sixt) already achieves this suppression but disables all "blank-at-eof" checks globally, not just for trailing newlines. Junio C Hamano later responded, clarifying that Git currently lacks a targeted way to suppress these warnings without affecting other whitespace checks. He left the door open for a future implementation but emphasized the need for a well-designed proposal, raising questions about the mechanism, naming, and scope (e.g., whether to allow only one trailing blank line or multiple). No patch or further discussion has emerged, and the thread remains dormant. The request is effectively stalled until someone submits a concrete design or implementation.
