This thread began as a feature request from Thomas Nemeth for a Git configuration option to suppress warnings about trailing blank lines at the end of files, motivated by Vim workflow ergonomics. The discussion clarified that Git already supports suppressing warnings for *any* trailing blank line via `core.whitespace=-blank-at-eof`, which Thomas acknowledged as sufficient for his needs. Junio C Hamano noted that a stricter interpretation—enforcing *exactly one* trailing blank line—remains unsupported but saw no active demand for it. Johannes Sixt contributed a Vim-specific workaround (using line-wise visual mode) to avoid the issue entirely, reinforcing that the problem can be resolved without Git changes. The thread has since wound down, with Thomas’s recent reply marking it as resolved from his perspective. No patch or technical proposal was submitted, and no maintainer has expressed intent to implement the feature. The broader question of whether Git should enforce exactly one trailing blank line remains open but unaddressed.
