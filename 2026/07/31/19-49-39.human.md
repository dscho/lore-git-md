This is the final patch in Pablo Sabater’s six-part GSoC series extending `` `git cat-file --batch-command` `` to support the `%(objecttype)` placeholder in remote-object-info queries. The patch unifies the default format string so that both local and remote queries now use `%(objectname) %(objecttype) %(objectsize)` instead of the temporary workaround that excluded `%(objecttype)` from remote queries.

The change is mechanical: it removes the conditional override in `builtin/cat-file.c` that forced a different default for remote queries, updates the documentation to reflect that `%(objecttype)` is now supported, and adjusts the test suite to expect the new unified format. The protocol documentation in `gitprotocol-v2.adoc` is also updated to clarify that both size and type are supported attributes.

The patch is straightforward and uncontroversial, completing the series’ goal of making object type metadata available end-to-end. All review feedback from v1 has been addressed, and the series is now ready for maintainer consideration.
