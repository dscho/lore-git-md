This thread is about a small but useful documentation improvement to the `git-refs(1)` man page. Kristoffer Haugsbakk proposed a two-patch series to reorganize a warning about ref migration limitations into a more visible admonition block and add a cross-reference to `git-maintenance(1)`. Junio C Hamano reviewed and approved the series, which is now queued in `seen` and expected to graduate to `next` shortly.

The only discussion since approval has been a minor stylistic exchange between Kristoffer and Patrick Steinhardt about whether the admonition block should use `CAUTION` or `WARNING`. Patrick noted that `WARNING` is technically more appropriate for the described risk (inconsistent state from concurrent writers), but this is a subjective preference and does not affect the series' readiness. Kristoffer had already clarified that the indentation in the admonition block was intentional and consistent with other man pages. No changes are needed, and the series remains on track for integration.
