This is a Google Summer of Code feature patch series (v2) extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The series now consists of six patches, up from five in v1, due to splitting out a test portability fix and reordering the patches for better narrative flow.

The core goal remains unchanged: object type is the last piece of metadata guaranteed to match between client and server after a fetch, so the series adds end-to-end support for querying it remotely. The implementation follows the established pattern from Eric Sunshine’s recently merged v21 series, touching `protocol-caps.c`, `fetch-object-info.c`, `serve.c`, and the `git-cat-file` man page. The default format string in `cat-file` is now unified to `%(objectname) %(objecttype) %(objectsize)` for both local and remote queries, removing a temporary workaround from the predecessor series.

Key changes in v2 include moving the "request all supported options dynamically" patch to the front of the series (now patch 1), replacing `wc -c <file | xargs` with Git’s `test_file_size` helper for test portability (patch 2), and restoring a test that mixes `info` and `remote-object-info` commands to verify the unified format (patch 6). The series also splits a test in `t1017` to separately verify that unsupported placeholders return empty strings, and updates documentation to reflect the new default format. All review feedback from v1 has been addressed, including style nits, macro usage, and test restructuring.

The series is narrowly scoped to object type, with the commit message explicitly ruling out other metadata (disk size, delta base, object mode) as unreliable or context-dependent. The implementation appears mechanical and well-tested, with expanded coverage in `t1017` and `t5701`. No open questions remain from the review discussion; the only deferred item is an optional robustness test for malformed server responses, which is not a blocker. The series is now complete and ready for maintainer consideration.
