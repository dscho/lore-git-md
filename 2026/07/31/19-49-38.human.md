This is the fifth patch in Pablo Sabater’s six-patch GSoC series (v2) that extends `git cat-file --batch-command` to support the `%(objecttype)` placeholder for remote-object-info queries. The series builds directly on Eric Sunshine’s recently merged v21 work and is now complete, addressing all review feedback from v1.

This patch teaches the server to advertise the new “type” capability. The change is a one-line update to `serve.c`: the `object_info_advertise()` function now appends both “size” and “type” to the advertised capabilities string. The rest of the patch is test coverage: the existing test that verified an unsupported placeholder returns an empty string is updated to confirm `%(objecttype)` now works, and a new test checks that truly unsupported placeholders (`%(objectmode)`, `%(objectsize:disk)`, etc.) still return empty strings. The test helper variables (`hello_type`, `tree_type`, etc.) are added once at the top and reused throughout the script.

The patch is mechanical and uncontroversial; it simply flips the switch that lets the client know the server can supply object types. No open questions remain, and the series is ready for maintainer consideration.
