This is a feature request for a new configuration option. Thomas Nemeth asks for a way to suppress Git’s warning about trailing blank lines at the end of files. He explains that he intentionally keeps one blank line at EOF to make block selection and pasting easier in Vim, but still wants to remove other trailing whitespace. Currently, `git diff` shows these blank lines as additions (marked in red), which he finds distracting.

The request is narrowly scoped: a config knob that would let users opt out of the warning for exactly one trailing blank line, while preserving all other whitespace checks. There is no patch attached, so this is purely an RFC at this stage. The thread has not yet attracted any replies, so there is no indication whether the idea has support or what implementation challenges might arise.
