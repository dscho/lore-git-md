This is a documentation patch series (two patches) from Kristoffer Haugsbakk that reorganizes and improves the `git-refs(1)` man page.

The series moves a warning about ref migration limitations—currently buried in the prose—into a visible admonition block directly under the relevant command synopsis. This makes the warning harder to overlook for users considering a ref storage migration. The second patch adds a missing `linkgit` cross-reference to `git-maintenance(1)` in the same warning text, improving navigation.

The changes are purely presentational: no code or behavior is altered. The commit messages are clear and the rationale is sound—ref migration is a significant operation and the warning deserves prominence. The patches touch only the AsciiDoc source for `git-refs(1)` and are part of Kristoffer’s ongoing documentation cleanup work. No controversy or technical risk is apparent.
