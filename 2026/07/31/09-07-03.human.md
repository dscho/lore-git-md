This is the second patch in Kristoffer Haugsbakk’s two-part documentation series improving the `git-refs(1)` man page. It adds a proper `linkgit` cross-reference to `git-maintenance(1)` in the cautionary admonition block that was moved under the `migrate` subcommand in patch 1/2.

The change is a single-line AsciiDoc tweak: replacing the plain-text mention of `git-maintenance(1)` with `linkgit:git-maintenance[1]`, which will render as a clickable hyperlink in the HTML version and a proper cross-reference in the man page. This is a standard documentation hygiene improvement that makes navigation easier for users.

The patch is uncontroversial, well-motivated, and consistent with Git’s documentation conventions. It completes the series’ goal of making the ref-migration warning more visible and more useful. No code or behavior is affected; the only file touched is `Documentation/git-refs.adoc`.
