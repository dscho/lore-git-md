This is the third patch in Junio C Hamano’s four-part `git add --resolved` series (v3). It introduces `remove_file_from_index_with_flags()`, a new helper in `read-cache.c` that extends the existing `remove_file_from_index()` to support `ADD_CACHE_PRETEND` (dry-run) and `ADD_CACHE_VERBOSE` (reporting) flags. The patch is a refactoring that consolidates flag-handling logic previously duplicated in `update_callback()`, making the codebase more maintainable and paving the way for the `--resolved` feature’s `--dry-run` and `--verbose` modes.

The implementation is straightforward: the new helper checks the provided flags, prints a removal message if `ADD_CACHE_VERBOSE` is set (regardless of `ADD_CACHE_PRETEND`), and skips the actual index update if `ADD_CACHE_PRETEND` is set. The only caller updated in this patch is `update_callback()`, which previously handled these flags manually. The change is purely internal—no user-facing behavior is altered, and the patch includes no new tests or documentation.

This is a well-motivated refactoring that addresses a clear inconsistency: `add_file_to_index()` already supports these flags, but `remove_file_from_index()` did not. The patch is small, focused, and unlikely to be controversial. Reviewers should verify that the flag logic is correct (e.g., that `ADD_CACHE_VERBOSE` works even when `ADD_CACHE_PRETEND` is set) and that no other callers of `remove_file_from_index()` would benefit from the new helper. The patch is a prerequisite for the `--resolved` feature’s `--dry-run` and `--verbose` support, which will be implemented in the next patch in the series.
