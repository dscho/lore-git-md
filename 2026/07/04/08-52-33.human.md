This is the first patch in Pablo Sabater’s v7 series implementing cascading indentation for visual roots in `` `git log --graph` ``. It is a test infrastructure refactoring that moves the duplicated `check_graph` helper from `t4215-log-skewed-merges.sh` and `t6016-rev-list-graph-simplify-history.sh` into `t/lib-log-graph.sh`, renaming it to `lib_test_check_graph`.

The patch is purely mechanical: it cuts the function from both test scripts and pastes it into the shared library, then updates every call site to use the new name. No behavior changes; the only difference is that the helper is now available to other test scripts. This paves the way for the new `t4218-log-graph-indentation.sh` file introduced in patch 3/3, which will reuse the same helper.

Karthik Nayak already approved this refactoring in an earlier iteration, and the patch is unchanged from v6. It is a clean, uncontroversial change that reduces code duplication and makes the test suite slightly more maintainable. No further review is needed.
