This is the v7 submission of Pablo Sabater’s feature series implementing cascading indentation for visual roots in `` `git log --graph` ``. The series now consists of three patches and replaces the v6 peek-based abstraction with Kristofer Karlsson’s lookahead buffer design, which Junio Hamano has already approved in principle.

The core change is architectural: instead of peeking at the revision walker’s internal queue, the graph code now maintains a two-entry lookahead buffer populated by `get_revision_internal()`. This ensures that commits are fully simplified before the graph layer inspects them, eliminating the fragility that blocked earlier versions. The lookahead buffer is small, deterministic (timestamps are tweaked to guarantee stable output), and compatible with Jeff King’s planned removal of `revs->commits` and Kristofer Haugsbakk’s `kk/prio-queue-get-put-fusion` topic.

Patch 1/3 is unchanged from v6: it moves the `check_graph` helper from two test scripts into `t/lib-log-graph.sh` so the new test file can reuse it. Patch 2/3 introduces the lookahead buffer in `graph.c` and `revision.c`, replacing the now-obsolete peek functions (`revision_has_more_commits`, `revision_peek_next_commit`). Patch 3/3 implements the actual visualization logic, indenting visual roots (except the first) by two characters per level and connecting them to their children with an edge on a new row.

The series addresses all three `test_expect_failure` cases from v6, and the test coverage has grown to include skewed merges and history simplification. One documented edge case remains: redundant indentation when filtered parents are present. This is marked NEEDSWORK but is considered acceptable for now. Junio’s concern about test brittleness (exact output matching) is still open, but the lookahead buffer’s deterministic behavior should mitigate it.

Files touched are `graph.c`, `graph.h`, `revision.c`, `revision.h`, `t/lib-log-graph.sh`, `t4215-log-skewed-merges.sh`, the new `t4218-log-graph-indentation.sh`, and `t6016-rev-list-graph-simplify-history.sh`. New symbols include `struct git_graph.lookahead[2]`, `GRAPH_PRE_ROOT` state, and the `is_visual_root` flag. The series removes the v6 peek functions entirely.

This version is technically sound, resolves the architectural fragility, and is ready for final review. The remaining loose ends—documentation of visualization rules, the redundant-indentation edge case, and test brittleness—are known and do not block merging. Junio and Phillip Wood’s review of the visualization logic in patch 3/3 is the next step.
