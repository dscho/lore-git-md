This is the v7 reroll of Pablo Sabater’s feature series adding cascading indentation to `git log --graph` for visual roots. The series is now three patches long and implements the lookahead-buffer redesign that Junio Hamano and Kristofer Karlsson agreed on after v6.

The core idea remains: when a commit’s parents are filtered out (making it a “visual root”), the graph now indents it by two characters per level so it cannot be mistaken for a child of the commit above. The first visual root stays flush left; subsequent ones cascade inward, producing output like

```
  * A
* B1
 \
  * B2
* C1
* C2
```

The key architectural change in v7 is the replacement of the v6 peek-based abstraction with a two-slot lookahead buffer inside `struct git_graph`. `get_revision_internal()` now populates this buffer, ensuring that commits are fully simplified before `graph.c` inspects them. This eliminates the fragility of peeking at unsimplified commits and removes the need for the helper functions (`revision_has_more_commits()`, `revision_peek_next_commit()`) that were introduced in v6. The three failing test cases from v6 now pass in Kristofer’s prototype, and the series includes comprehensive tests for skewed merges and history simplification.

Patch 1/3 is unchanged from v6: it moves the `check_graph` helper from two test scripts into `t/lib-log-graph.sh` so the new test file can reuse it. Patch 2/3 implements the lookahead buffer and modifies `graph_is_interesting()` to treat lookahead commits as “interesting” regardless of their `SHOWN` flag. Patch 3/3 contains the main visualization logic, updated to consume commits from the lookahead buffer.

The series touches `graph.c`, `graph.h`, `revision.c`, and three test files. It introduces new state (`lookahead[2]`, `GRAPH_PRE_ROOT`, `is_visual_root`, `visual_root_depth`) and removes the peek functions that were added in v6. The NEEDSWORK edge case from v6—redundant indentation when filtered parents are present—is still documented but left for future work.

This version looks technically sound: the lookahead buffer resolves the architectural fragility that blocked v5 and v6, and the test coverage is thorough. Junio and Phillip Wood have not yet signed off on the visualization logic in patch 3/3, but the series is otherwise ready for final review. If those approvals arrive, it should be on track for `next`.
