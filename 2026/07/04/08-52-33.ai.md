This is the first patch in Pablo Sabater’s v7 series implementing cascading indentation for visual roots in `` `git log --graph` ``. It is a test infrastructure refactoring that moves the `check_graph` helper function from two test scripts (`t4215-log-skewed-merges.sh` and `t6016-rev-list-graph-simplify-history.sh`) into `t/lib-log-graph.sh`, renaming it to `lib_test_check_graph`. The change is purely mechanical: no new functionality is introduced, and all existing test cases are updated to use the new helper.

The patch touches three files: `t/lib-log-graph.sh` (adds the new helper), `t4215-log-skewed-merges.sh` (replaces 14 calls to `check_graph` with `lib_test_check_graph`), and `t6016-rev-list-graph-simplify-history.sh` (replaces 9 calls). The helper’s signature and behavior are unchanged; it still accepts a here-document of expected graph output and optional arguments to pass to `` `git log --graph` ``.

This refactoring was previously reviewed and approved by Karthik Nayak in an earlier iteration of the series. It is a prerequisite for the new test file (`t4218-log-graph-indentation.sh`) introduced in patch 3/3, which will reuse the helper to verify the cascading indentation behavior. The patch is uncontroversial and ready for merging.
