This is the first patch in the converged v4 series refining Git's build system for Rustification on macOS. It fixes a parallel build race condition in the `git-credential-osxkeychain` helper by adding `$(RUST_LIB)` as a prerequisite to its build rule, ensuring Cargo builds `libgitcore.a` before linking. The change is wrapped in `ifndef NO_RUST` blocks to maintain backward compatibility when Rust is disabled.

The patch is a targeted, well-motivated bugfix. The commit message clearly explains the race condition (parallel builds failing when `make -j` is used from a clean tree) and the solution (adding the missing prerequisite). The implementation is minimal: it adds the dependency and guards Rust-related definitions to avoid breaking non-Rust builds. No new build variables or user-facing changes are introduced, and the fix is implicitly covered by existing build tests.

This patch is uncontroversial and ready for integration. It directly addresses the race condition without altering behavior or introducing platform-specific assumptions. The second patch in the series (Universal Binary support) builds on this foundation but is logically independent.
