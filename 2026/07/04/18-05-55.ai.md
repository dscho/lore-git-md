This is the second patch in the converged v4 series adjusting Git's build system for Rustification on macOS. It introduces support for macOS Universal Binaries (multi-architecture builds) when Rust is enabled, addressing a key distribution and CI packaging need for macOS users.

The patch allows users to specify multiple Rust target triples (e.g., `aarch64-apple-darwin x86_64-apple-darwin`) via the new `RUST_TARGETS` environment variable. The build system compiles separate static libraries for each target, then combines them into a single Universal Binary using `lipo` (part of Xcode Command Line Tools). This bridges the gap between Apple's C toolchain (which natively supports multi-architecture builds via `-arch` flags) and Cargo (which requires separate invocations per target triple). The result is a universal static archive (`libgitcore.a`) that the C linker can seamlessly integrate with universal C object files to produce universal Git executables.

Key technical details include the new `RUST_TARGETS` variable, the internal `$(RUST_MEMBER_LIBS)` build variable, and declarative pattern rules for compiling target-specific library slices. The patch assumes `lipo` is available on macOS (a reasonable assumption given its inclusion in Xcode Command Line Tools since at least 2005). It maintains backward compatibility by defaulting to the system's default Rust target when `RUST_TARGETS` is unspecified, and it includes safeguards to error out if multiple targets are specified on non-macOS platforms.

The commit message clearly explains the technical rationale and design choices, addressing earlier feedback about platform assumptions and build system clarity. All substantive review concerns have been resolved, including Junio's style tweaks (removing `@` from `mkdir` and replacing `[` with `test`). The patch is part of a two-patch series that also fixes a parallel build race condition in the macOS credential helper; together, these changes enable reliable, multi-architecture Rust builds on macOS without altering on-disk formats or requiring new tests.
