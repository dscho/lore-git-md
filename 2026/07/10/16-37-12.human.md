This is the first patch in Justin Tobler’s 11-patch v4 series converting `git-receive-pack` from `tmp_objdir` to ODB transactions. It is a pure refactoring patch: it renames the internal function `prepare_loose_object_transaction()` to `odb_transaction_files_prepare()` to better reflect its expanded future role, where it will also handle packfile writes in the same temporary directory. The change is mechanical (three call sites updated) and has no behavioral impact. The commit message clearly explains the motivation: the function will soon manage both loose objects and packfiles, so the new name is more accurate.

The patch is part of the ODB abstraction effort led by Patrick Steinhardt, and it carries Patrick’s Reviewed-by trailer from earlier iterations. It touches only `object-file.c` and is uncontroversial. This is a typical early-series plumbing patch that sets the stage for later functional changes. The series as a whole is now functionally complete, with all prior feedback addressed, and is queued for `next`. If you are tracking the ODB abstraction work, this patch is worth noting for the naming change, but it does not introduce new behavior or raise any open questions.
