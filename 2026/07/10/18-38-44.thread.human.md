This thread is about a small but necessary build-system fix to address a sparse compilation error introduced when source files were moved into a new `lib/` directory. The issue was a one-line Makefile tweak to update a path reference for `pack-revindex.c`, and it’s now resolved.

Ramsay Jones reported the regression and provided the fix, while Johannes Schindelin confirmed its correctness and suggested squashing it into the original patch if the branch were re-rolled. Junio C Hamano initially queued the fix separately in the `seen` branch, but Patrick Steinhardt has now agreed to incorporate it directly into the next version of his `ps/libgit-in-subdir` series. The change is uncontroversial and purely procedural—no further discussion or testing is needed.

The fix is part of Patrick’s larger effort to reorganize Git’s codebase by consolidating library sources into a dedicated `lib/` directory. That branch remains in `seen` and is still subject to rewriting before graduation.
