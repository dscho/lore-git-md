This thread is about a small but important build system fix for a sparse compilation error. The issue arose when a recent refactoring moved several source files into a new `lib/` directory, but the Makefile wasn't updated to reflect the new path for `pack-revindex.c`. Ramsay Jones submitted a one-line patch to the Makefile, adding the missing `lib/` prefix to the target path, which resolves the sparse error when building with `DEVELOPER=1`.

The fix is part of Patrick Steinhardt’s ongoing `ps/libgit-in-subdir` branch, which aims to reorganize the codebase by consolidating library sources. Ramsay suggests squashing this fix into the original patch if the branch is re-rolled. Since this is a straightforward build system correction with no test or documentation changes, it’s uncontroversial and likely to be merged as-is. The patch specifically helps the NonStop port and other environments where sparse checking is enabled.
