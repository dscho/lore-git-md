This is the sixth patch in Justin Tobler’s 11-patch series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. The series is part of the broader ODB abstraction effort led by Patrick Steinhardt.

This patch refactors `odb_transaction_begin()` to propagate backend errors—such as failures to create the temporary object directory—rather than silently returning `NULL`. The function now returns an `int` error code and writes the transaction into an out-parameter. A convenience wrapper, `odb_transaction_begin_or_die()`, is added for call sites that don’t need to handle errors explicitly. The patch also updates existing callers to handle the new error-returning interface, including those that may already have an inflight transaction (e.g., `cache_tree_update()` and `add_files_to_cache()`).

The changes are mechanical and focused: the core logic remains unchanged, but error handling is now explicit. The patch touches eight files, with the heaviest changes in `odb/transaction.c` and `odb/transaction.h`. All prior feedback on this patch (including the safety concern about guarding `odb->transaction` assignment) has been addressed, and the patch carries Patrick Steinhardt’s Reviewed-by. The series is queued for `next` and is functionally complete.
