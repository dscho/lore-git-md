The series maintains all security measures from previous versions, including dynamic capability-based validation (the client filters requested format placeholders against what the server advertises) and strict protocol v2 enforcement. The default format remains `%(objectname) %(objectsize)`, with empty strings returned for unsupported fields like `%(objecttype)` or `%(objectsize:disk)`.
