This is a small refactoring patch in Patrick Steinhardt’s eight-part series introducing object filters to `odb_for_each_object()`. It marks the `filter` parameter in `for_each_bitmapped_object()` and related functions as `const` because the filter is never modified by these functions. The change is mechanical and affects only the function signatures in `pack-bitmap.c` and `pack-bitmap.h`, touching four lines in total.

The patch is part of the broader ODB abstraction effort, which aims to restructure Git’s object storage layer to support pluggable backends. This specific change is a cleanup that improves code clarity and safety by enforcing immutability where it is already respected. It has no behavioral impact and is unlikely to be controversial.

Given the series’ overall goal and the thorough review feedback already incorporated in v2, this patch looks like a straightforward, well-justified step. It is one of the smaller, preparatory changes that pave the way for the more substantial backend refactoring in later patches.
