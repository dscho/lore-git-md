This is a build system fix for a sparse compilation error introduced by a recent refactoring. Commit 9759608622 moved several source files into a new `lib/` directory but missed updating the Makefile rule that silences a `memset` warning for `pack-revindex.c`. The patch adds the missing `lib/` prefix to the target path (`lib/pack-revindex.sp`), resolving the sparse error that occurs when building with `DEVELOPER=1`.

The change is minimal (one line in `Makefile`) and directly addresses the regression. It is part of Patrick Steinhardt’s ongoing `ps/libgit-in-subdir` branch, which aims to reorganize the codebase by consolidating library sources into a dedicated directory. Ramsay Jones requests this fix be squashed into the original patch if the branch is re-rolled.

This is a platform compatibility and build system patch, targeting the NonStop port and other environments where sparse checking is enabled. The fix is uncontroversial and likely to be merged as-is. No test or documentation changes are involved.
