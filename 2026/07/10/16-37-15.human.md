This is a refactoring patch in Justin Tobler’s ODB transaction series (v4, 4/11). It removes redundant validation from the "files" backend’s `odb_transaction_files_begin()` function. The generic ODB transaction layer already ensures only one transaction can exist at a time, so the backend’s duplicate check is unnecessary. The change is mechanical: four lines deleted from `object-file.c` and a comment updated in `object-file.h`. No behavior changes; the patch simply eliminates dead code.

The patch is uncontroversial and carries forward Patrick Steinhardt’s Reviewed-by from earlier iterations. It’s part of the broader ODB abstraction effort, which aims to make Git’s object storage pluggable. This specific change cleans up the interface between the generic transaction layer and the files backend, reducing coupling. The series as a whole is queued for `next` and appears ready for integration.
