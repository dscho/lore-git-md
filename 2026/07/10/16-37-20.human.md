This is the ninth patch in Justin Tobler’s v4 series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It introduces `enum odb_transaction_flags` and the `ODB_TRANSACTION_RECEIVE` flag to preserve the subtle behavioral differences between `git-receive-pack`’s temporary directory handling and the default ODB transaction behavior.

The patch adds a `flags` parameter to the ODB transaction interface (`odb_transaction_begin()`, `odb_transaction_begin_or_die()`, and the backend-specific `begin_transaction` callbacks) and updates all call sites to pass `0` (no flags). In the "files" backend, the `ODB_TRANSACTION_RECEIVE` flag triggers two changes: the temporary directory is created eagerly (matching `git-receive-pack`’s current behavior) and the directory prefix is set to "incoming" (instead of the default "bulk-fsync"). The patch also adds a `prefix` field to `struct odb_transaction_files` to support this.

The commit message clearly explains the motivation and the NEEDSWORK comment acknowledges that the flag-based approach is a temporary measure; ideally, all transactions would use the same eager-creation and prefix behavior, but that change is deferred to follow-up work. The patch is mechanical and uncontroversial, carrying Patrick Steinhardt’s Reviewed-by from earlier iterations. No behavior changes are introduced; the series remains a pure refactoring.
