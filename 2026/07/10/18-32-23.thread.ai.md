Thread identity
Subject: [PATCH] Cygwin: fix IPv6-style SCP URL handling regression
Series version: standalone patch (v2 pending)
Originating author: Ramsay Jones
Thread type: bugfix

Core problem or goal
Fix a five-year-old regression on Cygwin where stricter path validation introduced in the 2019 security releases (v2.23.1) misinterprets IPv6-style SCP URLs (e.g., `[::1]:repo`) as invalid paths because `[` is treated as a potential Windows drive letter. The regression causes test failures in `t5500-fetch-pack.sh` and `t5601-clone.sh` and has been papered over with test skips since 2024.

Current status
Under review. The patch’s core fix (Cygwin-specific `is_valid_path()` and `offset_1st_component()` in `git-compat-util.h`) remains viable, but the contested `#ifdef DUMMY` block in `connect.c` will be preserved or replaced with `#ifdef GIT_WINDOWS_NATIVE` to avoid breaking Git for Windows UNC path support (commit `ebb8d2c90fb0`). Ramsay now plans to revisit the failing tests and may mark them as Cygwin-specific skips (`!CYGWIN`) rather than attempting to fix mixed forward/back-slash URL handling in config files. No merge status reported; no maintainer decision yet. Patrick Steinhardt’s suggestion to add Cygwin to Git’s CI matrix remains unresolved, with Ramsay expressing uncertainty about resource allocation versus user base size.

Key technical details
- Files touched: `git-compat-util.h` (Cygwin-specific path validation), `connect.c` (URL parsing logic), `t5500-fetch-pack.sh` and `t5601-clone.sh` (test coverage restoration or Cygwin-specific skips).
- New/renamed symbols: Cygwin-specific `is_valid_path()` and `offset_1st_component()` implementations.
- Behavior change: IPv6-style SCP URLs are now correctly parsed on Cygwin without being misinterpreted as drive letters; UNC path support on Git for Windows is preserved. No changes for other platforms.
- On-disk format: none.
- Test coverage: restores previously skipped IPv6 URL tests on Cygwin or converts them to Cygwin-specific skips.

Open questions and loose ends
- Whether to preserve the `#ifdef DUMMY` block in `connect.c` or replace it with `#ifdef GIT_WINDOWS_NATIVE` to maintain Git for Windows UNC path support. Resolution pending Ramsay’s v2.
- Whether to mark the failing tests (`t5500-fetch-pack.sh` and `t5601-clone.sh`) as Cygwin-specific skips (`!CYGWIN`) or attempt to fix mixed forward/back-slash URL handling in config files. Ramsay leans toward skips.
- Patrick Steinhardt’s suggestion to add Cygwin to Git’s CI matrix: unresolved, with Ramsay noncommittal about resource allocation versus user base size.
