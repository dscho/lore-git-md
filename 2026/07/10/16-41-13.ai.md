The function's core logic remains unchanged: it still validates server support for the command, writes the command name to the request buffer, and appends agent and session-id capabilities if supported. The only behavioral difference is that callers now explicitly specify which command to advertise.

The diff touches three files: `connect.c` (implementation), `connect.h` (declaration and documentation), and `fetch-pack.c` (call sites). The `fetch-pack.c` changes are minimal, updating the two existing call sites to pass "fetch" as the command string. The documentation in `connect.h` is expanded to clarify the function's purpose and parameters, though it does not yet mention the specific commands it will support beyond "fetch".
