This is the third patch in Patrick Steinhardt’s eight-patch v2 series introducing object filters to `odb_for_each_object()`. The series is part of the ongoing ODB abstraction effort to enable pluggable object databases.

This patch enables early termination of bitmapped object iteration by propagating non-zero return values from the `show_reach` callback through `for_each_bitmapped_object()` and `show_objects_for_type()`. Currently, these functions ignore the callback’s return value, which would become a latent bug once the logic is lifted into the generic `odb_for_each_object()` infrastructure (where callbacks are expected to support early abortion). The change is minimal and targeted: `show_objects_for_type()` is converted from `void` to `int`, and its return value is checked in `for_each_bitmapped_object()`. Two existing callers in `builtin/pack-objects.c` and `builtin/rev-list.c` are updated to return 0 instead of 1 to preserve their current behavior.

The patch is well-motivated and clearly explained. It addresses a real technical debt that would otherwise surface when the bitmap iteration logic is generalized. The diff is small (31 insertions, 13 deletions) and focused, touching only the core bitmap iteration machinery and its immediate callers. No new edge cases are introduced, and the change is backward-compatible with existing behavior. Review feedback from v1 has already been incorporated, and the patch appears ready for integration.
