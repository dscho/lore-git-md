This is a refactoring patch that moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` as part of the ongoing `remote-object-info` feature series. The patch is the sixth in the v16 series of 13 patches, and it prepares the codebase for generalizing this function in a subsequent commit (patch 7/13) to support additional protocol commands beyond `fetch`.

The change is mechanical: the function is relocated verbatim, with no behavior modifications. The only adjustment is a forward declaration of `struct string_list` in `connect.h` to avoid including the full header, since the function only uses it as a pointer. The patch includes `Helped-by` trailers crediting Jonathan Tan and Christian Couder for their input on the design.

This refactoring is a necessary step toward enabling the `remote-object-info` command, which will reuse the same capability-writing logic. The move to `connect.c` is logical, as that file already contains similar protocol-related functions like `server_supports()`. The patch maintains the series' focus on code organization and reusability, with no user-visible changes at this stage. All prior review feedback about function placement and header hygiene has been addressed.
