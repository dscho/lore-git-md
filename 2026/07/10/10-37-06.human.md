This is the third patch in Pablo Sabater’s **v8 series** implementing cascading indentation for visual roots in `` `git log --graph` ``. It introduces a **two-slot lookahead buffer** in `struct git_graph` to allow the graph renderer to peek ahead two commits without relying on fragile peeks into `rev_info` internals.

The patch adds the buffer itself (`lookahead[2]` and `lookahead_nr`), three helper functions (`graph_pop_lookahead`, `graph_get_lookahead_room`, `graph_push_lookahead`), and updates `get_revision` to populate the buffer via `next_commit_to_show` (introduced in patch 2/4). The buffer is deterministic: commits are pre-fetched, marked SHOWN, and then popped in order. An assertion in `graph_pop_lookahead` guards against NULL entries, and `ARRAY_SIZE` ensures the buffer size is maintainable. The patch also updates `graph_is_interesting` to treat commits in the lookahead buffer as interesting parents, preserving correct graph topology.

This is a **refactoring patch** with no behavior change; the lookahead buffer is not yet used for indentation (that comes in patch 4/4). The implementation is clean, defensive, and compatible with the rest of the series. It directly addresses the v7 bug where the buffer source varied depending on command-line options, breaking tests. The patch is ready for final review and looks technically sound.
