This is the second patch in Harald Nordgren’s `git history squash` series (v8 2/5). It adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. The patch updates the existing fixup and split callers to pass NULL so they continue to work unchanged.

This is a plumbing change that enables the `--reedit-message` feature in a later patch by allowing the caller to override the commit message with a template built from multiple folded commits. There is no user-visible behavior change, and the patch is uncontroversial. It is ready to merge as part of the larger series.
