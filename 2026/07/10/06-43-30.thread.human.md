This thread introduces a small but useful enhancement to Git's configuration system: two new `includeIf` conditions, `worktree` and `worktree/i`, that let users include configuration files based on the realpath of the current worktree's working directory. The feature is part of a two-patch series by Chen Linxuan and addresses a long-standing gap for users working with multiple worktrees, where the existing `gitdir` condition (which matches on the `.git` directory path) is often unintuitive or cumbersome.

The implementation is straightforward, reusing an existing helper function and adding thorough test coverage for edge cases like bare repositories, symlinked paths, and case sensitivity. The documentation includes clear examples showing how the new conditions differ from `gitdir` and `extensions.worktreeConfig`.
