This thread is about a small but practical improvement to Git's `contrib/b4` tooling. Chen Linxuan submitted a patch to add a `change-id` trailer to the `.b4-cover-template` file, which allows the b4 tool (version 0.15.2+) to properly parse the sent tag it generates. Without this line, users encounter a critical error when trying to reroll or compare patch versions. The fix is straightforward—a single-line addition that mirrors the existing `base-commit` trailer—and touches only the template file, requiring no new symbols, CLI options, or on-disk changes.

Patrick Steinhardt has reviewed and approved the patch, noting it as an oversight in the original template. There’s been no further discussion or objections, and the change is now ready for merging. Since this is a contributor housekeeping patch with no substantive technical debate, it should land quietly in the next cycle.
