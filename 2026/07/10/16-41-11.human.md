This is a refactoring patch in the ongoing `remote-object-info` feature series (v16, patch 5/13). It eliminates the static `advertise_sid` variable in `fetch-pack.c` as preparation for moving the `write_fetch_command_and_capabilities()` function to `connect.c` in a later patch.

The change addresses the critical refactoring flaw Junio Hamano identified in v15, where a local `advertise_sid` variable was introduced without removing the file-scope global one, leaving the code in an inconsistent state. This version completely removes the static variable and replaces it with local variables in both `find_common()` and `write_fetch_command_and_capabilities()`, each initialized via `repo_config_get_bool()`. The configuration check is now performed where the value is actually used, and the v0/v1 protocol check (`!server_supports("session-id")`) is moved into `find_common()` where it belongs.

The patch is mechanical and well-scoped, with no intended behavior change. It cleans up the code structure while maintaining the same functionality, and the commit message clearly explains the motivation and implementation approach. This is a necessary preparatory step for the larger series and resolves a previously identified technical debt issue.
