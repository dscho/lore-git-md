This is a small but practical contributor housekeeping patch from Chen Linxuan.

The patch adds a missing `change-id` trailer to Git’s in-tree `.b4-cover-template` file. Without it, b4 0.15.2 fails when trying to read the `sent/<change-id>-vN` tag it just created, because the tag message (derived from the rendered cover letter) lacks the `change-id` field that b4’s own parsing logic expects. The fix is a one-line addition that brings the project template in sync with b4’s default template.

The motivation is clear: a real-world failure that blocks reroll and comparison workflows. The patch is narrowly scoped and unlikely to be controversial. It’s a good example of the kind of small, well-motivated fix that keeps tooling interoperability smooth.
