This is the tenth patch in Justin Tobler’s 11-patch series converting `git-receive-pack` from `tmp_objdir` to ODB transactions. The series is now in its fourth iteration and is functionally complete, with all prior feedback addressed.

This patch removes a redundant call to `tmp_objdir_env()` in `update_shallow_ref()`. The function was previously used to populate child process environment variables with the temporary object directory’s path, but this is no longer necessary because `update_shallow_ref()` is only called after `tmp_objdir_migrate()` has already moved the objects into the main object store. The change is a straightforward cleanup: one line removed from `builtin/receive-pack.c`, with no behavior change or risk of regression. The patch is uncontroversial and aligns with the series’ goal of eliminating `tmp_objdir` usage in favor of ODB transactions.

The series as a whole is a refactoring effort to advance ODB-backend agnosticism, and this patch is a small but logical part of that transition. All 11 patches have been reviewed by Patrick Steinhardt (the ODB subsystem owner) and are queued for `next`. If you’ve been following the series, this patch is a minor but necessary step in the migration.
