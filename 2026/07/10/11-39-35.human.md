This is the eleventh patch in Dscho’s twelve-patch Coverity-driven bugfix series (`js/coverity-fixes-v2`). It plugs a NULL-dereference in `shallow.c` that can crash Git when a shallow graft entry references a commit object that is missing from the object store (e.g., after a partial fetch or repository corruption). The fix is a one-line change: instead of printing the OID from the potentially-NULL `commit` struct, the code now prints the OID from the `commit_graft` struct, which is always valid. The patch is small, well-explained, and uncontroversial; it follows the same defensive pattern as the rest of the series and is ready for integration.
