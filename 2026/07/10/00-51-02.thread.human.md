Here’s the human-readable summary of the Git mailing list thread based on Junio’s "What's cooking" report for July 2026:

The thread is Junio’s latest integration report, giving a snapshot of what’s queued for the next Git release. Two topics have already graduated to `master` and will ship in the next version: a cleanup of Git’s hash infrastructure (`jk/git-hash-cleanups`) and a fix for handling advanced ANSI color codes in sideband output (`mm/sideband-ansi-sgr-colon-fix`).

The bulk of the activity is in `next`, where several large efforts are cooking. Patrick Steinhardt’s pluggable object database (ODB) work continues with two series: one refactoring `git gc` and maintenance to be backend-agnostic, and another adding object filters to `odb_for_each_object()` for faster traversals. The ref subsystem is also seeing major changes, with a series removing `the_repository` usage and another introducing new `git refs` subcommands for safer ref manipulation. Performance fixes are landing too, including a one-line fix for quadratic behavior in `unpack-trees` and optimizations to the priority queue used by revision walks.

Reftable is getting attention as well: Karthik Nayak fixed a quadratic slowdown with tombstones, and Patrick added hardening against corrupted tables. New user-facing features include `--linearize` for `git replay` and a `git history drop` subcommand to surgically remove commits. Smaller but important fixes are also in the queue, like NULL-safety improvements from Johannes Schindelin and a commit-graph bugfix from Karthik.

A few topics are stalled or controversial. Documentation for `git interpret-trailers` is stuck on terminology debates, while an HTTP redirect fix is marked for discard due to unresolved edge cases. Rust integration remains contentious, with a macOS universal build series blocked on Meson/Rust integration concerns. Taylor Blau’s repacking work combining geometric and cruft packs needs a reroll for MIDX retention logic.

The report also highlights long-term RFCs, like splitting repository discovery from setup and refactoring `receive-pack` to use ODB transactions. Test infrastructure is improving too, with disk usage reductions in long-running tests and a new linter to catch bare `grep` assertions. The main open questions revolve around the ODB/ref abstractions, reftable safety tradeoffs, and the ongoing Rust debate—all of which are likely to generate more discussion in future threads.
