This is the fourth patch in Harald Nordgren’s `git history squash` series (v8 4/5). It refactors the sequencer’s squash-message helpers into reusable functions so that `git history squash --reedit-message` can produce the same editor template as `git rebase -i --autosquash`.

The patch extracts three static helpers from `sequencer.c`—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—and exposes them in `sequencer.h`. It also moves the `todo_item_flags` enum to the header so callers can distinguish an `amend!` commit (TODO_REPLACE_FIXUP_MSG) from a plain `fixup!`. No behavior changes; the rebase code now calls the exported helpers instead of its own static versions.

The refactoring is clean and uncontroversial. It is a prerequisite for the next patch, which implements `--reedit-message` in `git history squash` and reuses `todo_list_rearrange_squash()` to group `fixup!`/`squash!`/`amend!` commits under their targets exactly as rebase does.
