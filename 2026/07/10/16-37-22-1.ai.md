This is the final patch in Justin Tobler’s 11-patch v4 series converting `git-receive-pack` from `tmp_objdir` to ODB transactions. It replaces the last direct `tmp_objdir` usage with the new ODB transaction subsystem, completing the infrastructure refactoring for ODB-backend agnosticism. The patch touches only `builtin/receive-pack.c` (68 lines changed), swapping out `tmp_objdir` calls for their ODB transaction equivalents (`odb_transaction_begin`, `odb_transaction_env`, `odb_transaction_commit`). The quarantine semantics remain identical: incoming objects are staged in a temporary "incoming" directory and migrated into the object database prior to reference updates.

The patch is mechanical and well-scoped. It removes the global `tmp_objdir` variable, introduces a local `struct odb_transaction *transaction`, and updates all relevant functions (`unpack`, `unpack_with_sideband`, `execute_commands`, `set_connectivity_errors`, `run_receive_hook`) to accept the transaction as a parameter. The `ODB_TRANSACTION_RECEIVE` flag (introduced in patch 9/11) ensures the "files" backend preserves receive-pack’s quarantine behavior (eager directory creation and "incoming" prefix). Error handling is consistent with the rest of the series: `odb_transaction_begin` returns an error code, and `odb_transaction_commit` propagates failures to the caller.

This patch carries Patrick Steinhardt’s Reviewed-by from v3 and addresses all prior feedback. The series is now functionally complete, with all 11 patches queued for `next` pending integration. The only deferred items are design-level questions (header dependency and explicit abort calls), which do not affect this patch’s correctness. Test coverage relies on the existing `receive-pack` test suite, which exercises the quarantine flow and child processes (`git-index-pack`, `git-unpack-objects`). No behavioral changes are introduced.
