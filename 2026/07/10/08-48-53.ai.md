This is the first patch in Patrick Steinhardt’s v2 eight-patch series introducing object filters to `odb_for_each_object()`. It targets the packed object database backend (`odb/source-packed.c`) and addresses an inefficiency in object enumeration: when iterating through objects with a specific prefix, the code redundantly traverses indices to locate objects even though the necessary pack and offset data is already available from the enumeration step. The patch replaces the generic `odb_source_read_object_info()` with direct calls to `packed_object_info()`, using the index-provided pack and offset data for object lookups. This change eliminates redundant index traversals, improves performance, and prevents a subtle correctness issue where an object might be looked up in the wrong packfile if it exists in multiple packs. The patch also renames the `store` variable to `source` for clarity and updates the condition `if (opts->flags)` to `if (opts->flags || data->request)` to ensure the pack is populated for `packed_object_info()`. The change is confined to `odb/source-packed.c` and does not affect user-facing behavior. Review feedback from v1 confirmed that the new lookup behavior is semantically correct and that the condition change is safe. This patch is a foundational step for the series, enabling more efficient and correct object enumeration in preparation for the ODB-mediated filtering introduced later.
