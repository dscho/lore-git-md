This is the first patch in Harald Nordgren’s `git history squash` v8 series, a pure refactoring that extracts a helper function to centralize the logic for resolving a commit’s first-parent tree (or the empty tree for a root commit). The patch touches only `builtin/history.c`, replacing three nearly identical blocks of code with calls to the new `first_parent_tree_oid()` helper. No behavior change is introduced; this is strictly a code hygiene improvement to reduce duplication and make future changes easier. The helper is immediately used in the same file by `commit_tree_with_edited_message()`, `commit_became_empty()`, and `split_commit()`. This patch is uncontroversial and ready to merge as part of the larger series.
