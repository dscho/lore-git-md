This is a refactoring patch in the `remote-object-info` security series (v16, patch 2/13). It moves loop counter declarations (`int i`) inside their respective `for()` statements and changes the type from `int` to `size_t` where appropriate, matching the type of the loop bound (e.g., `nr`, `ARRAY_SIZE()`).

The changes are mechanical and localized: `builtin/cat-file.c` (three loops in `dispatch_calls()`, `free_cmds()`, and `batch_objects_command()`) and `fetch-pack.c` (one loop in `write_fetch_command_and_capabilities()`). The patch improves readability by keeping the counter declaration close to its use and avoids signed/unsigned comparison warnings by using `size_t` for array indexing. No behavior change is intended.

This is preparatory cleanup for the larger series, which remains on track for merging with all prior feedback addressed. The patch itself is uncontroversial and aligns with Git’s coding style.
