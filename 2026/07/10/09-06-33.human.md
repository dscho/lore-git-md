This is the second patch in Harald Nordgren’s `git history squash` series, now in its eighth iteration. The patch adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. The existing fixup and split callers are updated to pass NULL so they continue to work unchanged.

This is a plumbing change that enables the `--reedit-message` feature introduced later in the series. It has no user-visible behavior change and is uncontroversial. The patch is small (16 lines), focused, and ready to merge.
