This is the final patch in Harald Nordgren’s `git history squash` series (v8 5/5), implementing the `--reedit-message` feature to let users interactively combine commit messages from the entire squashed range. The patch completes the series by adopting the same editor template format as `git rebase -i --autosquash`, including grouping `fixup!`, `squash!`, and `amend!` commits under their targets rather than showing them in commit order.

The implementation reuses three sequencer helpers (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) and the `todo_list_rearrange_squash` function to build a template that exactly matches rebase’s autosquash behavior. A new `build_squash_message` helper walks the range in reverse topo-order, gathers each commit’s message, and constructs the template with appropriate commenting: `fixup!` messages are fully commented out, `squash!` keeps its body with only the marker subject commented, and `amend!` replaces its target’s message unless a `squash!` already folded into that target. The template is passed to `commit_tree_ext` only when `--reedit-message` is given, preserving the default behavior of reusing the oldest commit’s message.

The documentation expands to clarify the template format and behavior, and the test script adds 210 lines covering message gathering, autosquash grouping, `fixup!`/`squash!`/`amend!` handling, and empty-message abort. This patch is uncontroversial and ready to merge; the only remaining discussion point for the series is whether `--reedit-message` should be the default, but that is a minor usability tweak that does not block integration.
