This is the seventh patch in Patrick Steinhardt’s eight-patch v2 series introducing object filters to `odb_for_each_object()`. It is a core piece of the ODB abstraction effort, enabling backends to optimize object enumeration by skipping excluded objects when possible.

The patch adds a new `filter` field to the `odb_for_each_object_options` struct, allowing callers to pass object filters to backends. Backends may use these filters to skip excluded objects (e.g., via reachability bitmaps), but are not required to do so—callers must still re-apply the filter to ensure strict semantics. This design choice avoids imposing artificial limits on future backends while still enabling optimizations where possible.

The "packed" backend implementation uses the new `prepare_bitmap_git_for_source()` function (introduced in patch 6/8) to open bitmaps exclusively for the current source, preventing misattribution of objects. The patch also introduces a `bitmapped_for_each_object()` callback that wraps the original callback, ensuring objects covered by the bitmap are yielded with the correct object info. To avoid duplicates, the backend skips packs already covered by the bitmap during the non-bitmap enumeration phase.
