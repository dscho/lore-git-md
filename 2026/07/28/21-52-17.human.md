This is the second patch in Junio C Hamano’s four-patch series introducing `git add --resolved`. It adds a new helper function, `remove_file_from_index_with_flags()`, to `read-cache.c` and updates the `update_callback()` function to use it.

The patch addresses an asymmetry in the index API: `add_file_to_index()` already supports flags like `ADD_CACHE_PRETEND` and `ADD_CACHE_VERBOSE`, but `remove_file_from_index()` does not. Callers that remove files from the index (such as `update_callback()`) currently have to manually handle pretend mode and verbose reporting. The new helper encapsulates this logic, making the API more consistent and reducing code duplication.

The implementation is straightforward: the helper checks the provided flags, prints a removal message if `ADD_CACHE_VERBOSE` or `ADD_CACHE_PRETEND` is set, and skips the actual index update if `ADD_CACHE_PRETEND` is set. The patch updates `update_callback()` to use the new helper, replacing manual flag checks with a single call.

This is a refactoring patch with no user-visible behavior change. It prepares the ground for the third patch, which implements the `--resolved` option for `git add` and will use the new helper to support `--dry-run` and `--verbose` modes.
