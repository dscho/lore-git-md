This is the second patch in Tian Yuchen’s v2 series migrating global configuration variables into `repo_config_values` as part of the `the_repository` removal effort. It moves the `assume_unchanged` global from `environment.h` into the repository-scoped `repo_config_values` struct, updating all direct references in `builtin/update-index.c` and `read-cache.c` to use the repository-specific instance. The global variable is removed entirely, and the `repo_config_values` struct is initialized with `assume_unchanged = 0` in `repo_config_values_init()`.

The patch is mechanical and follows the same pattern as the first patch in the series (which migrated `pack_size_limit_cfg`). No getter function is introduced for `assume_unchanged` due to its limited call sites, and backward compatibility is maintained by accessing the value via `the_repository` where needed. The changes touch four files: `builtin/update-index.c` (where `CE_VALID` is set during cache entry creation), `environment.c` (where the variable is initialized and configured via `core.ignorestat`), `environment.h` (where the global is removed), and `read-cache.c` (where `CE_VALID` is managed during index refresh and stat cache updates).

The patch is infrastructure-only, with no intended behavior change, and is positioned as a stepping stone for future libification efforts. The `core.ignorestat` configuration (`git_config_bool(var, value)`) now directly updates `cfg->assume_unchanged` instead of the global variable. The `CE_VALID` flag logic in `read-cache.c` is updated to use the repository-scoped value, ensuring that `assume_unchanged` behavior remains consistent with the repository’s configuration.

No new tests are proposed, but the mechanical nature of the changes suggests existing tests should suffice. The patch builds directly on the prior `repo_config_values` work and complies with the v2 design constraint (no silent fallbacks to `the_repository` when `repo != the_repository`). The series remains uncontested so far, with no review feedback yet on this patch. Key symbols modified: `repo_config_values.assume_unchanged`. Subsystems affected: index updates (`update-index.c`, `read-cache.c`) and configuration handling (`environment.c`).
