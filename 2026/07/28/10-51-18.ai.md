This is a reply to a surface-level review of the first patch in Fabian Pottbäcker’s three-patch series adding scp-style URL support to `git config --url`. The series as a whole is a small, self-contained feature targeting scripting convenience by making `--url` accept the same scp-style SSH URLs (`host:path`) that nearly every other Git command already supports.

Fabian acknowledges Ben Knoble’s observation about the copy-paste error in the comments for FTP and SSH default-port normalization: the comments read “Skip http :21” and “Skip http :22” instead of “Skip ftp :21” and “Skip ssh :22”. The code logic is correct, but the comments are misleading. Fabian has already prepared a fix on a local branch (`config_url_scp_syntax_v1..config_url_scp_syntax`) and plans to roll it into a v2 if no further feedback arrives. He also provides a `Fetch-It-Via` line for reviewers who want to pull the branch directly from his GitLab fork.

No substantive technical discussion has emerged yet; the thread remains focused on this single nit. The rest of the series (patches 2 and 3) is unaffected.
