This is a user support thread about a platform compatibility issue in Git for Windows, not a patch or development discussion.

Johannes Schindelin follows up on Moksh Goyal’s report that Ctrl+C in a Vagrant SSH session terminates the entire session when using Git Bash (but not PowerShell). Moksh confirms the issue persists even with the latest Git for Windows (2.55.0.windows.3). Johannes suggests installing the native Windows OpenSSH client and then reinstalling Git for Windows while opting out of the bundled SSH, which may work around the problem.

The thread remains focused on diagnosing a Git for Windows-specific quirk, likely tied to the previously linked GitHub issue (#3716). No Git core code is implicated, and the discussion is purely about environment configuration. If Moksh tries the workaround, the next step may be to report back on whether it resolves the issue.
