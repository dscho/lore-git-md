This is a **platform compatibility bugfix** for macOS, addressing a memory leak in the system regex engine (TRE) when processing invalid UTF-8 sequences. The v2 patch refines the approach introduced in v1, now organizing the workaround in a cleaner, more maintainable way under `compat/darwin/` and using a platform-specific header to override `regexec_buf()`.

The core issue remains severe: a single `git grep` over files containing binary data (e.g., PDFs) can leak gigabytes of memory, risking kernel watchdog panics. The fix splits input buffers at invalid multibyte sequences and searches each valid segment separately, avoiding the leaking path entirely while preserving all genuine matches. The implementation is now more modular, with the Darwin-specific logic isolated in `compat/darwin/regexec.c` and conditionally included via `compat/darwin.h`. This follows the project’s pattern for platform overrides and keeps the default inline implementation as the fallback.

Key improvements in v2 include treating the workaround as indefinite (no assumption about future macOS fixes), better documentation of `mbrtowc()` return values, and expanded test coverage. The tests now verify matches before, after, and between invalid bytes, check offsets after invalid sequences, and ensure correct anchoring of `^`/`$` at true line boundaries. The patch also restricts positive invalid-UTF-8 matching tests to macOS builds, as system regex implementations differ in handling invalid multibyte input, while allowing the no-false-anchor test to run on all multibyte regex platforms.

The patch is well-motivated, thoroughly tested, and addresses Junio’s structural concerns from v1 by adopting a more modular approach. It integrates cleanly across all build systems (Makefile, Meson, CMake) and includes detailed reproduction steps in the commit message. **Worth attention from macOS users and reviewers familiar with regex internals or platform-specific workarounds.** The fix is narrowly scoped to affected macOS builds and avoids behavioral regressions, making it a safe, targeted solution.
