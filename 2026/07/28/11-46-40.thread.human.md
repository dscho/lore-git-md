This thread is about a build system bug in Git’s Rustification effort. William Pursell reported that the Makefile hardcodes the path to the Rust static library (`target/release/libgitcore.a`) while the `cargo build` step ignores the `CARGO_TARGET_DIR` environment variable. When users set a custom `CARGO_TARGET_DIR`, the linker fails because it can’t find the library. The issue is isolated to two lines in the Makefile (962 and 3036) and doesn’t affect runtime behavior—just build-time reliability.
