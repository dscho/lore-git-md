This is Junio’s “What’s cooking” report for mid-July 2026, giving a snapshot of the integration branches.
The main news is that the eighth batch of topics has graduated to ‘master’, and Junio has tightened the criteria for moving topics to ‘next’ to avoid premature stabilization.

Graduated to ‘master’ (highlights)
- Rust interface cleanups (bc/rust-hash-cleanups) – plug two memory leaks in the Rust/C hash glue.
- the_repository removal – three topics (ps/copy-wo-the-repository, ps/refs-wo-the-repository, ps/refspec-wo-the-repository) continue the long-running effort to eliminate the global repository variable.
- ps/shift-root-in-graph – ‘git log --graph’ now indents root commits so they don’t visually attach to unrelated commits above them.
- pw/rebase-drop-notes-with-commit – when a commit is dropped during rebase, its notes are no longer copied to an unrelated commit.
- sc/wt-status-avoid-quadratic-insertion – ‘git status’ is now O(n log n) instead of O(n²) when listing untracked files.
- td/ref-filter-memoize-contains – ‘git branch --contains’ and friends are now much faster when run against many refs.

New topics worth a quick look
- sk/test-commit-body-helper – a new test helper `commit_body` simplifies extracting commit messages in tests; replaces several manual pipelines.
- jk/cat-file-batch-wo-type-fix – fixes a segfault in ‘git cat-file --batch-command’ when ‘contents’ is requested without ‘type’.
- tc/merge-default-to-upstream-leakfix – plug a small leak in the merge.defaultToUpstream code path.
- cl/regexec-macos-leak – works around a macOS TRE regex library leak on invalid UTF-8.
- dl/pack-bitmap-position-zero – fixes a boundary case in reachability bitmap traversal that skipped the object at position zero.
- jc/add-resolved – new ‘git add --resolved’ stages conflict-resolved paths while leaving unrelated local changes unstaged; aborts if conflict markers remain.

Stalled topics (no activity in the last report)
- tb/repack-geometric-cruft – ‘git repack --geometric --cruft’ is still waiting for a response to Junio’s request for a re-roll.
- hn/checkout-track-fetch – the ‘--track=fetch’ mode for ‘git checkout’ will be discarded unless someone steps up to address the design concerns.
- za/completion-hide-dotfiles – path completion now hides dotfiles by default; stalled on a bikeshed about whether the dot should be shown when the user types it.
- kh/doc-trailers and kh/doc-replay-config – documentation improvements that will be discarded unless the author responds to review comments.

Cooking in ‘next’ (highlights)
- ps/odb-make-creation-pluggable – the on-disk setup of the object database is now pluggable, a prerequisite for alternative backends.
- ps/cat-file-remote-object-info-type – extends the remote-object-info batch command to support the ‘%(objecttype)’ placeholder.
- rs/branch-delete-bisect-warning – ‘git branch -d’ now reports when a branch cannot be deleted because it is part of an active bisect.
- jk/ci-static-analysis-image-bump – the static-analysis CI job now runs on Ubuntu 24.04, fixing a Coccinelle performance regression.
- ps/odb-pluggable-housekeeping – ‘git gc’ and ‘git maintenance’ housekeeping is now backend-agnostic, moving the logic into the files ODB source.
- tc/replay-linearize – ‘git replay --linearize’ drops merge commits, mimicking ‘git rebase --no-rebase-merges’; kicked back to ‘seen’ after Junio requested a rebase to resolve conflicts.

If you only follow one or two areas, the the_repository removal topics, the pluggable ODB work, and the new ‘git add --resolved’ option are the most likely to affect future development.
