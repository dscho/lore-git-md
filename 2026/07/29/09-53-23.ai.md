This is a **substantive review** of the first patch in Pablo Sabater’s GSoC series extending `git cat-file --batch-command` to support `%(objecttype)` in remote-object-info queries. The reviewer, Chandra Pratap, raises two technical points:

1. **Style nit and grep-ability**: The patch wraps an error message string (`"object-info: protocol error, expected to get oid, not '%s'"`) across two lines, which Chandra argues is unnecessary (the original line is not overly long) and harms grep-ability. This is a **surface-level** concern but worth addressing for consistency.

2. **Test portability**: The test uses `wc -c <file | xargs` to compute file size, which Chandra suggests replacing with Git’s `test_file_size` helper for better portability. This is a **substantive** improvement to the test suite, though it does not affect the core functionality.

The review is constructive and focused on code quality rather than design. No objections to the patch’s intent or implementation are raised. The series remains under review, with this feedback likely to be incorporated in a future iteration.
