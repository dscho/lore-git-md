This is the fifth patch in brian m. carlson’s six-patch RFC series that proposes restricting Git 3.0 to lowercase-only hex object IDs. The patch replaces an open-coded, non-table-driven hex-parsing loop in `object-name.c` with a call to the existing `hexval()` helper, which is already table-driven and constant-time. The change is purely mechanical: it removes ten lines of hand-rolled logic and replaces them with three lines that delegate to `hexval(c, HEX_KIND_OID)`, preserving the exact same behavior (including the case-conversion side effect that lower-cases any uppercase hex digits). No new test failures are introduced, and the patch is explicitly preparatory for the stricter parsing that will follow in patch 6.
