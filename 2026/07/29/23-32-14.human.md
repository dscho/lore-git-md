This is the fifth patch in brian m. carlson’s six-patch RFC series that proposes restricting Git 3.0 to lowercase-only hex object IDs.  The patch itself is a small, focused refactoring: it replaces an open-coded hex-digit parser in `object-name.c` with the existing `hexval()` helper.  The change is purely internal—no behavior is altered yet—but it paves the way for the final patch, which will enforce the lowercase-only rule.  The commit message explains that the new version is both faster (table-driven) and more maintainable, and it removes a non-constant-time implementation that had no compensating advantage.  This looks like a clean, uncontroversial cleanup that simply prepares the codebase for the actual breaking change.
