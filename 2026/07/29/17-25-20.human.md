This is a feature addition introducing `` `git add --resolved` ``, authored by Junio C Hamano. The patch series is now at v2, incorporating two follow-up fixes identified during review: a logic correction in option incompatibility handling and a missing test script entry in the Meson build file, both pointed out by Michael Montalbo. Additionally, Junio added a performance optimization to the conflict-marker detection helper, which now exits early for binary files.

The series remains structurally unchanged from v1: four patches that refactor conflict-marker detection, introduce a helper for index removal with flags, implement the core ``--resolved`` option, and clean up whitespace. The new option allows users to stage only paths whose conflict markers have been removed, avoiding accidental staging of unrelated local changes. This directly addresses a workflow pain point Junio describes—maintainers frequently resolve conflicts while also having unrelated local changes in their working tree.

The implementation is clean and well-motivated. The conflict-marker logic is consolidated into a single helper in ``merge-ll.c``, replacing duplicate implementations in ``diff.c`` and ``rerere.c``. The new ``remove_file_from_index_with_flags()`` helper in ``read-cache.c`` supports ``--dry-run`` and ``--verbose`` flags, making index removals as straightforward as additions. The test coverage in the new ``t/t2207-add-resolved.sh`` script appears thorough, covering refusal to stage files with remaining markers, success when all markers are removed, handling of deletions, pathspecs, and option incompatibility with ``-u`` and ``-A``.

The follow-up fixes address the only substantive issues raised during review, and the performance tweak is a sensible optimization. The series is now technically complete and ready for deeper review. The feature is user-facing and introduces a new command-line option, so expect discussion around edge cases like partially resolved conflicts and interaction with ``--patch`` mode. The patches are self-contained and do not depend on other ongoing efforts.
