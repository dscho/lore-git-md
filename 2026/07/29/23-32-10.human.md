This is the first patch in brian m. carlson’s six-part RFC series proposing a breaking change for Git 3.0: restricting hex object IDs to lowercase only. The patch lays the groundwork by introducing a new `hex_kind` enum and a second lookup table (`hexval_lc_table`) that rejects uppercase hex digits. The existing `hexval()` function is modified to accept the enum, but for now all callers continue to use `HEX_KIND_MIXED`, so behavior is unchanged. Files touched include `hex-ll.c`/`hex-ll.h`, `color.c`, and `pkt-line.c`. The patch is purely preparatory—no functional change yet—and is clearly motivated by the larger goal of enforcing lowercase-only parsing in future commits.
