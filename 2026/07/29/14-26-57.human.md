This is a brief design discussion exchange in the ongoing `git rebase --update-refs` symref bugfix thread. Junio C Hamano concedes the point after Phillip Wood provides concrete evidence that TopGit, an external tool, actively relies on Git's ability to set HEAD to a symref outside `refs/heads/` (specifically `refs/top-bases/...`) and uses `git rebase` as part of its workflow.

The exchange resolves the immediate design tension: Junio no longer questions whether `git rebase` should handle symrefs pointing outside `refs/heads/`, acknowledging that real-world tools depend on this flexibility. This clears the way for the current patch series (v3) to proceed without narrowing its scope, and the author, Son Luong Ngoc, is now expected to send a v4 incorporating only minor refinements rather than a fundamental redesign. The latent `head_ref` buffer clobbering bug remains unaddressed and is still a candidate for a follow-up patch.
