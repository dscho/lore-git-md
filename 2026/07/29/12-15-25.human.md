This is a brief follow-up in Pablo Sabater’s GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The series is now at version 1, with all patches posted and follow-up fixes addressing earlier review feedback.

The email responds to Chandra Pratap’s suggestion on the fourth patch, which updates the test in `t1017` to verify that the "type" capability is now supported by the server. Chandra proposed restructuring the test to better separate concerns: one test to confirm that `%(objecttype)` works as expected, and another to ensure that unsupported placeholders (like `%(objectmode)` or `%(deltabase)`) still return empty strings. Pablo agrees with the proposal, noting that while the current test suite already covers unsupported placeholders, consolidating those checks into a single test would improve clarity and maintainability. He plans to implement the change in the next revision.

This is a minor but sensible improvement to test design, reflecting the series’ ongoing refinement. The core functionality—adding object type metadata to remote-object-info queries—remains unchanged and uncontroversial. The series is under active review, with no major objections or merge status reported.
