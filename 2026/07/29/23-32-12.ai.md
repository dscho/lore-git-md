This is the third patch in brian m. carlson’s six-patch RFC series that prepares Git 3.0 to enforce lowercase-only hex object IDs. It extends the `hex_to_bytes()` helper—used whenever Git converts a hex string into raw bytes—to accept an `enum hexkind` parameter (`HEX_KIND_MIXED` or `HEX_KIND_LOWER`). Every caller is updated to pass `HEX_KIND_MIXED`, so the patch is purely mechanical and does not change runtime behavior. The files touched (`index-pack.c`, `diagnose.c`, `hex-ll.c`/`hex-ll.h`, `http-push.c`, `notes.c`, and `object-file.c`) are all low-level plumbing that parse object IDs from disk, network, or diagnostic output. The patch is a prerequisite for later commits that will flip the switch to `HEX_KIND_LOWER` in specific contexts, gated behind the Git-3.0-breaking-changes mode.
