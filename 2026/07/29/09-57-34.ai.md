This is a surface-level review of the third patch in Pablo Sabater’s GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder. The patch refactors `fetch-object-info.c` to dynamically request all supported object-info options (currently "size" and "type") instead of hardcoding "size" alone.

Chandra Pratap’s feedback is purely stylistic: a grammar nit in the code comment ("no need to check" should be a separate sentence) and a suggestion to use the `for_each_string_list_item()` macro instead of an explicit loop. Neither comment affects functionality or correctness; both are minor readability improvements. The patch itself is mechanical and uncontroversial, preparing the client to parse the "type" field from the server response once the server-side capability is in place. No substantive issues or objections have been raised here.
