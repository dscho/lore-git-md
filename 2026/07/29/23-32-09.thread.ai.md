Thread identity: RFC patch series proposing a breaking change for Git 3.0: restricting hex object IDs to lowercase only. Originating author: brian m. carlson. Thread type: design discussion / RFC.

Core problem or goal: Git currently emits lowercase hex object IDs but accepts both uppercase and lowercase in parsing, creating potential compatibility and security issues for external tools that assume hex uniqueness. The series aims to enforce lowercase-only parsing in Git 3.0, making the behavior consistent and predictable. The first three patches introduce infrastructure (new `hex_kind` enum, `hexval_lc_table`, updated `hexval()`, `hex2chr()`, and `hex_to_bytes()` functions) without altering runtime behavior yet.

Current status: RFC stage; no prior versions. The series is complete in implementation but explicitly seeks feedback on whether the project wants this change at all. No maintainer decisions or merge status yet; under initial review. The first three patches are preparatory and do not change behavior.
