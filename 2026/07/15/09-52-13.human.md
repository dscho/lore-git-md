This is a refactoring patch from the security-hardened `git cat-file --batch-command` series, now in its eighteenth and final iteration. The patch eliminates a static `advertise_sid` variable in `fetch-pack.c` to prepare for moving the `write_fetch_command_and_capabilities()` function to `connect.c` in a later patch.

The change addresses a critical refactoring issue Junio Hamano identified in v15: the code previously declared a local `advertise_sid` variable in `write_fetch_command_and_capabilities()` without removing the file-scope global one, leaving the codebase in an inconsistent state. The fix removes the static variable entirely and replaces its usage with local variables initialized via `repo_config_get_bool()` in both `find_common()` and `write_fetch_command_and_capabilities()`. The patch also moves the `!server_supports("session-id")` check from `do_fetch_pack()` into `find_common()`, ensuring the variable is properly initialized regardless of protocol version.

This is a mechanical, localized change that doesn't alter behavior but improves code hygiene and maintainability.
