This is a bugfix patch from Jeff King (Peff) that addresses a segfault in `git diff` when using `--relative` and `--cached` together on unmerged paths outside the current directory.

The issue occurs because `diff_unmerge()` returns NULL for paths outside the prefix, but the caller in `do_oneway_diff()` proceeds to call `fill_filespec()` without checking for NULL, causing a crash. The fix is minimal: add a NULL check before calling `fill_filespec()`. Peff traces the regression back to 76399c0195 (2011) and notes that a similar issue for non-cached diffs was already fixed in 8174627b3d (2021).

The patch includes a test case that piggybacks on existing tests for `--relative`, verifying that `--relative --cached` now correctly ignores unmerged paths outside the prefix. Peff also mentions a potential follow-up optimization (checking paths earlier in `oneway_diff()`), but opts for the smallest fix to avoid regressions, noting that the existing comment about advancing `o->pos` may be outdated.

The change touches `diff-lib.c` and adds a test to `t/t4045-diff-relative.sh`. The fix is clearly motivated, well-explained, and backed by a regression test. No controversy is evident.
