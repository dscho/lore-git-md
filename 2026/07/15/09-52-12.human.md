This is a small, targeted bugfix patch in the GSoC `remote-object-info` series, now at v18. The patch corrects a type mismatch in `fetch-pack.c`: `hash_algo_by_name()` returns an `unsigned int`, but the variable receiving its result was declared as a plain `int`. The fix changes the variable to `const unsigned int` to match the function’s return type and adds `const` since the value is never modified.

The change is purely mechanical and localized to a single line. It addresses a type-safety issue without altering behavior, and the commit message clearly explains the rationale.
