This is the sixth patch in Johannes Schindelin’s 11-patch series fixing unchecked return values flagged by Coverity. The patch adds a missing error check in the `git_pread()` compatibility shim (`compat/pread.c`) to prevent silent corruption when the initial `lseek(fd, 0, SEEK_CUR)` call fails on a non-seekable descriptor like a pipe.

The fix itself is uncontroversial and mechanically sound: if the first `lseek()` returns `-1`, the function now returns `-1` immediately, avoiding a subsequent `lseek(fd, -1, SEEK_SET)` call that would either fail or corrupt the file position. The patch does not change behavior, only hardens the error path.
