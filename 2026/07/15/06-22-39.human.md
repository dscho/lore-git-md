This is the final patch in Patrick Steinhardt’s nine-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. It refactors `git cat-file --batch-all-objects` to use the new ODB-mediated filtering mechanism instead of reaching into the packed backend’s internals.

The patch replaces 69 lines of backend-specific logic with just 7 lines of ODB API calls, removing direct dependencies on `pack-bitmap.h` and eliminating two helper functions (`batch_one_object_packed` and `batch_one_object_bitmapped`). The new implementation passes the caller’s object filter through `odb_for_each_object_options` and delegates filtering to the backend, which can now optimize using bitmaps when available. This is the payoff for the series: `git cat-file` no longer needs to know whether objects come from loose files, packfiles, or bitmaps, and the packed backend can apply filters efficiently without exposing its internals.

Junio C Hamano previously reviewed this patch in an earlier version and called it “very nice,” praising the clean diffstat. The refactoring is purely internal; no user-visible behavior changes are expected. All review feedback has been addressed in prior versions, and this v4 update is cosmetic only (commit message typos). The series is now ready for integration, pending Junio’s final review.
