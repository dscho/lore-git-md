This is the third patch in Tian Yuchen’s four-patch v5 series that migrates the `trust_executable_bit` and `has_symlinks` configuration flags into `struct repo_config_values` as part of the ongoing `the_repository` removal effort.

The patch moves the global `trust_executable_bit` variable into the repository-specific `repo_config_values` struct and introduces a new getter function, `repo_trust_executable_bit()`, that callers use instead of the old global.  Every site that previously read the global now receives the repository pointer (either passed in or falling back to `the_repository`) and calls the getter.  The default value (1) is set in `repo_config_values_init()`, and the config parser (`git_default_core_config`) writes to the repository’s copy rather than the global.  No behavior changes are introduced; the patch is purely mechanical plumbing.  The files touched are `apply.c`, `environment.c`, `environment.h`, and `read-cache.c`.
