This is patch 7/9 in Patrick Steinhardt’s ODB abstraction series, now updated to version 4. The patch introduces `prepare_bitmap_git_for_source()`, a function that opens a bitmap exclusively for a given packed object source. This is a small but necessary refactoring to enable the "packed" backend to use bitmaps for object filtering in later patches, a key step in the ongoing ODB abstraction effort.

The change is purely mechanical and uncontroversial.
