This is the ninth and final iteration of Harald Nordgren’s `git history squash` feature, a new subcommand that folds a commit range into its oldest commit while preserving descendant history. The series is now functionally complete, addressing all prior feedback and resolving the last open technical concern: **`amend!` message handling**.

The key change in v9 is that the default squashed commit message now incorporates the body of the last `amend!` commit targeting the oldest folded commit, while ignoring `amend!` markers for later commits. This resolves the internal inconsistency raised by Matt Hunter, where the command previously processed `amend!` semantics for validation but ignored their messages for message construction. The implementation now aligns with user expectations: if an `amend!` marker targets the oldest commit, its message replaces the default message, just as it would in `git rebase -i --autosquash`.

The series also includes minor test improvements, such as new helper functions (`stage_file`, `commit_with_message`, `check_commit_count`, `check_log_subjects`, `check_log_messages`) to improve readability and reduce duplication. These follow the pattern established in the `delete-merged` topic.

**Patches in the series**:
1. **Refactoring**: Extracts `first_parent_tree_oid()` helper to centralize logic for resolving a commit’s first-parent tree. No behavior change.
2. **Plumbing**: Adds a `message_template` parameter to `commit_tree_ext()` to support `--reedit-message`. No user-visible behavior change.
3. **Core implementation**: Introduces the `git history squash` subcommand, including range validation, merge handling, ref-handling, and `rev-list` option sanitization. The command now rejects only `fixup!`/`squash!`/`amend!` markers whose targets lie outside the range, allowing multiple markers for the same in-range commit to fold together.
4. **Code sharing**: Refactors sequencer helpers (`add_squash_combination_header`, `add_squash_message_header`, `squash_subject_comment_len`) and the `TODO_REPLACE_FIXUP_MSG` flag for reuse by both `git rebase -i` and `git history squash`. No behavior change.
5. **`--reedit-message`**: Implements the feature to let users interactively combine commit messages from the entire squashed range, using a template that exactly matches `git rebase -i --autosquash`. The template groups `fixup!`/`squash!`/`amend!` commits under their targets and fully comments out `fixup!` messages while retaining `squash!`/`amend!` bodies.

**Key names introduced**: `squash` (subcommand), `--update-refs=head`, `--reedit-message`, `ADVICE_HISTORY_UPDATE_REFS`, and internal helpers (`resolve_squash_range`, `reject_dangling_fixups`, `find_interior_ref`, `build_squash_message`).
