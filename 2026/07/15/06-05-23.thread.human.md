This thread is about a one-patch bugfix from Jeff King (Peff) that fixes a long-standing segfault in `git diff --relative --cached` when dealing with unmerged paths outside the current directory. The crash, a NULL pointer dereference in `do_oneway_diff()`, dates back to 2011 and was partially addressed in 2021 for non-cached diffs, but the `--cached` case remained broken.

Peff’s fix is minimal: a NULL check before `fill_filespec()` ensures the command safely ignores unmerged paths outside the `--relative` prefix instead of crashing. The patch includes a regression test in `t/t4045-diff-relative.sh` and touches only `diff-lib.c`. Junio C Hamano, the maintainer, has now reviewed the patch and confirmed it is correct. His feedback explains why the fix works (no filepair is queued, so the path is safely skipped) and implicitly endorses the approach. No objections or changes were raised, and the test case was accepted without comment. The patch is now effectively ready for merging, with no open questions or loose ends remaining.
