This thread began with a fix for a long-standing segfault in `git diff --relative --cached` when operating on unmerged paths outside the current directory. Jeff King (Peff) identified the root cause—a NULL pointer dereference in `do_oneway_diff()`—and submitted a one-patch fix, followed by two small refactorings to improve code clarity in the same code path. The entire three-patch series was reviewed and approved by Junio Hamano and is now queued for integration in `next`.

The only remaining loose end was a Coverity static-analysis warning about a potential NULL dereference in the second refactoring patch. Peff clarified that the warning is a false positive, as the code’s logic ensures the dereferenced pointer cannot be NULL under normal operation. In this latest email, Peff proposes a fourth, optional patch: a `BUG()` assertion in `oneway_diff()` to explicitly document the invariant that at least one of the `idx` or `tree` parameters must be non-NULL. The patch is purely defensive and does not change behavior, but it would help static analyzers and human readers understand the code’s assumptions. Junio and Peff have treated the discussion lightly, with no substantive objections—just a question of whether the assertion is worth adding. The series remains ready for integration regardless of this final patch.
