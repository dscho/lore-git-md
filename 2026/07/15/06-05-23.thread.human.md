This thread is a straightforward bugfix for a segfault in `git diff` when combining `--relative` and `--cached` on unmerged paths outside the current directory. Jeff King (Peff) identified the root cause: `diff_unmerge()` returns NULL for such paths, but the caller in `do_oneway_diff()` doesn’t check for NULL before calling `fill_filespec()`, leading to a crash. The fix is minimal—a NULL check before `fill_filespec()`—and includes a test case to verify the behavior.

The regression dates back to 2011 (commit 76399c0195), with a related issue for non-cached diffs already fixed in 2021 (commit 817427b3d). Peff considered a follow-up optimization (checking paths earlier in `oneway_diff()`) but opted for the smallest fix to avoid introducing new risks. The patch touches `diff-lib.c` and adds a test to `t/t4045-diff-relative.sh`. There’s no controversy or open discussion—just a clean, well-explained fix with test coverage.
