This is the **v3 cover letter** for Phillip Wood’s 9-patch series fixing the sequencer’s handling of dropped commits during rebase. The series is a **bugfix** targeting the sequencer subsystem, specifically preventing `git rebase` from incorrectly copying notes from dropped commits to the current HEAD.

The core issue is that when a commit is dropped (e.g., because its changes are already upstream), the sequencer currently records it as "rewritten," which triggers note copying and confuses post-rewrite hooks. The series addresses this by introducing an `enum pick_result` to distinguish dropped commits from successful picks, ensuring they are not recorded as rewritten. The fix is narrow but systemic: it also resolves related edge cases involving external merge failures, command execution failures, and fixup sequences.

The v3 iteration drops one patch (previously 2/10) after Andrei Rybak’s review flagged a misleading commit message, and incorporates Oswald Buddenhagen’s surface-level feedback on grammar and punctuation. The remaining patches are unchanged in substance but have clearer commit messages. Key changes include:
- **Patch 1/9**: Restores test coverage for the "apply" backend in `t3400-rebase.sh`.
- **Patches 2–3/9**: Fix error handling for external merge strategies and command execution failures.
- **Patches 4–7/9**: Refactor `pick_one_commit()` to simplify control flow.
- **Patch 8/9**: Converts `do_pick_commit()`’s return type to an enum.
- **Patch 9/9**: Adds `PICK_RESULT_DROPPED` to the enum and modifies the sequencer to skip recording dropped commits as rewritten.

The series is **approved by Junio C Hamano** and marked ready for `next` after minor typofixes are squashed. Test coverage is expanded in `t3400-rebase.sh`, `t3404-rebase-interactive.sh`, and `t5407-post-rewrite-hook.sh`, including new tests for external merge failures and command execution failures. A known limitation (the "edit" command still records dropped commits as rewritten) is documented and flagged for a separate fix.

This is a **well-crafted, tested-level contribution** that directly addresses technical debt in the rebase machinery. The refactoring is incremental and justified, and the core fix is minimal and targeted. The series supersedes Uwe Kleine-König’s earlier patch and stands on its own as a complete solution.
