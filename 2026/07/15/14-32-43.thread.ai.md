Subject: [PATCH v2 0/2] mv: fix misleading error for missing destination directory
Series version: v2 (two-patch series)
Originating author: Lucas Zamboni Orioli (via GitGitGadget)
Thread type: bugfix patch series

Core problem or goal
`git mv` emits a misleading error when the destination's parent directory does not exist, incorrectly blaming the source file (e.g., "renaming 'src' failed: No such file or directory"). The series fixes this in two commits: the first improves the error message by naming both source and destination paths, and the second adds an early existence check for the destination directory to enable `--dry-run` detection.

Current status
Under review; v2 posted. The series is narrowly scoped to `builtin/mv.c` and `t/t7001-mv.sh`. The first commit improves error message clarity (no TOCTOU risk), while the second introduces the early directory existence check (TOCTOU race acknowledged but unresolved). Both commits are now on-list; the author followed reviewer feedback by splitting the work and improving the error message format.

Key technical details
- Files touched: `builtin/mv.c`, `t/t7001-mv.sh`
- New behavior: error message now includes both source and destination paths (e.g., "renaming A -> B failed: no such file or directory"); early `lstat` check for destination directory existence enables `--dry-run` detection
- Old behavior: misleading error blaming source file; `--dry-run` could not detect missing destination directories
- New symbols: none (internal logic changes only)
- Test coverage: two new tests in `t/t7001-mv.sh` covering basic failure case and `--dry-run` detection
- Edge cases handled: directory moves, sparse entries, out-of-cone destinations, trailing slashes in destination path
- On-disk format: unchanged
- l10n impact: new translatable string for the improved error message (first commit)

Open questions and loose ends
- TOCTOU race: the destination directory could disappear between the `lstat` check and the `rename(2)` syscall (raised by Ben Knoble; no proposed fix yet)
- Use of `lstat` (not `stat`) for directory existence check (still unresolved)
- Interaction with sparse-checkout and worktree modes (mentioned as areas for follow-up discussion)
- Whether the two commits should remain separate or be squashed (author's v2 keeps them split; no new feedback on this point)
