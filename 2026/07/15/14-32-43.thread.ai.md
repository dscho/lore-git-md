Subject: [PATCH v2 0/2] mv: fix misleading error for missing destination directory
Series version: v2 (two-patch series)
Originating author: Lucas Zamboni Orioli (via GitGitGadget)
Thread type: bugfix patch series

Core problem or goal
`git mv` emits a misleading error when the destination's parent directory does not exist, incorrectly blaming the source file (e.g., "renaming 'src' failed: No such file or directory"). The series splits the fix into two commits: the first makes the error message unambiguous by naming both source and destination paths, and the second adds an early existence check for the destination directory to enable `--dry-run` detection.

Current status
Under review; v2 posted. The series is narrowly scoped to `builtin/mv.c` and `t/t7001-mv.sh`. The first commit addresses error message clarity (no TOCTOU risk), while the second introduces the early directory existence check (TOCTOU race acknowledged but unresolved). The author followed reviewer feedback by splitting the work into two commits and improving the error message format.

Key technical details
- Files touched: `builtin/mv.c`, `t/t7001-mv.sh`
- New behavior: error message now includes both source and destination paths (e.g., "renaming A -> B failed: no such file or directory"); `--dry-run` detects the missing directory in the second commit
- Old behavior: misleading error blaming source file
- New symbols: none (internal logic change only)
- Test coverage: two new tests in `t/t7001-mv.sh` covering basic failure case and `--dry-run` detection
- Edge cases handled: directory moves, sparse entries, out-of-cone destinations, trailing slashes in destination path; TOCTOU race noted but not addressed in the second commit
- On-disk format: unchanged
- l10n impact: new translatable string for the improved error message

Open questions and loose ends
- TOCTOU race: the destination directory could disappear between the `lstat` check and the `rename(2)` syscall in the second commit (raised by Ben Knoble; no proposed fix yet)
- Use of `lstat` (not `stat`) for directory existence check (still unresolved)
- Interaction with sparse-checkout and worktree modes (mentioned as areas for follow-up discussion)
- Whether the two commits should remain separate or be squashed (author's v2 keeps them split)
