Subject: [PATCH] mv: fix misleading error for missing destination directory
Series version: standalone patch (v2 forthcoming)
Originating author: Lucas Zamboni Orioli (via GitGitGadget)
Thread type: bugfix patch

Core problem or goal
`git mv` emits a misleading error when the destination's parent directory does not exist, incorrectly blaming the source file (e.g., "renaming 'src' failed: No such file or directory"). The patch will be split into two commits: the first makes the error message unambiguous by naming both source and destination paths, and the second adds an early existence check for the destination directory to enable `--dry-run` detection.

Current status
Under review; v2 planned. The patch is narrowly scoped to `builtin/mv.c`, with the first commit addressing error message clarity and the second introducing the early directory existence check. The TOCTOU race in the second commit remains unresolved but is acknowledged.

Key technical details
- Files touched: `builtin/mv.c`, `t/t7001-mv.sh`
- New behavior: error message now includes both source and destination paths (e.g., "renaming A -> B failed: no such file or directory"); `--dry-run` will detect the missing directory in the second commit
- Old behavior: misleading error blaming source file
- New symbols: none (internal logic change only)
- Test coverage: two new tests in `t/t7001-mv.sh` covering basic failure case and `--dry-run` detection (to be updated for the split commits)
- Edge cases handled: directory moves, sparse entries, out-of-cone destinations, trailing slashes in destination path; TOCTOU race noted but not addressed in the second commit
- On-disk format: unchanged
- l10n impact: new translatable string for the improved error message

Open questions and loose ends
- TOCTOU race: the destination directory could disappear between the `lstat` check and the `rename(2)` syscall in the second commit (raised by Ben Knoble; no proposed fix yet)
- Interaction with sparse-checkout and worktree modes (mentioned as areas for follow-up discussion)
- Use of `lstat` (not `stat`) for directory existence check (still unresolved)
- Commit structure: whether the two commits should be squashed or remain separate (implied by the author's plan but not yet confirmed by reviewers)

Participant positions
