Subject: [PATCH v2 0/2] mv: fix misleading error for missing destination directory
Series version: v3 (two-patch series)
Originating author: Lucas Zamboni Orioli (via GitGitGadget)
Thread type: bugfix patch series

Core problem or goal
`git mv` emits a misleading error when the destination's parent directory does not exist, incorrectly blaming the source file (e.g., "renaming 'src' failed: No such file or directory"). The series fixes this in two commits: the first improves the error message by naming both source and destination paths, and the second adds an early existence check for the destination directory (and its intermediate components) to enable `--dry-run` detection.

Current status
Under review; v3 posted, addressing all substantive feedback. The series is effectively approved by Junio C Hamano pending final review of v3. The first patch (error message clarity) remains approved ("Makes sense"). The second patch (early directory existence check) now fully resolves Junio's feedback: it uses `stat()` instead of `lstat()` to align with `rename()`'s behavior, explicitly checks for non-directory destinations (reporting "destination is not a directory"), and validates intermediate path components (reporting "destination directory does not exist"). The TOCTOU race remains acknowledged but unresolved, as it is considered "the best we can do" for now. No remaining technical objections; ready for integration.

Key technical details
- Files touched: `builtin/mv.c`, `t/t7001-mv.sh`
- New behavior: error message now includes both source and destination paths (e.g., "renaming A -> B failed: no such file or directory"); early `stat()` check for destination directory existence enables `--dry-run` detection and explicitly handles non-directory destinations, invalid intermediate components, and symlinks (accepts symlinks to directories, rejects symlinks to files)
- Old behavior: misleading error blaming source file; `--dry-run` could not detect missing destination directories
- New symbols: none (internal logic changes only)
- Test coverage: new tests in `t/t7001-mv.sh` covering missing directories, non-directory path components, symlinks (both to files and directories), `--dry-run` detection, directory moves, sparse entries, out-of-cone destinations, trailing slashes in destination path, and non-directory intermediate components in destination path
- Edge cases handled: symlinks (accepted if pointing to directories, rejected if pointing to files), regular files, non-directory intermediate components, trailing slashes
- On-disk format: unchanged
- l10n impact: new translatable string for the improved error message (`"renaming '%s' to '%s' failed"` in the first patch) and one new string for non-directory destinations (`"destination is not a directory"` in the second patch); reuses existing "destination directory does not exist" message for ENOENT/ENOTDIR errors

Open questions and loose ends

- Interaction with sparse-checkout and worktree modes (mentioned as areas for follow-up discussion; no actionable feedback yet)
- Whether the two commits should remain separate or be squashed (author's v3 proposal keeps them split; no new feedback on this point)
