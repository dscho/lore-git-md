This is the final patch in Harald Nordgren’s `git history squash` series, implementing the `--reedit-message` feature. The patch completes the feature by letting users interactively combine commit messages from the entire squashed range, using a template that exactly matches `git rebase -i --autosquash`. This addresses the last open technical concern from earlier iterations—ensuring the command’s behavior aligns with user expectations for `fixup!`, `squash!`, and `amend!` commits.

The implementation reuses sequencer helpers (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) and the `TODO_REPLACE_FIXUP_MSG` flag, which were extracted in an earlier patch to ensure consistency with `git rebase -i`. The template groups `fixup!`/`squash!`/`amend!` commits under their targets (rather than showing them in commit order), fully comments out `fixup!` messages while retaining `squash!`/`amend!` bodies, and replaces the target’s message with the `amend!` message unless a `squash!` already folded into that target. The test suite verifies these behaviors, including edge cases like multiple `fixup!` commits for the same target and `amend!` messages that replace their target’s message.

This patch is well-crafted, thoroughly tested, and directly addresses prior feedback about template consistency and `amend!` message handling. The architectural vision of using `git history squash` and `git replay` as a faster backend for `git rebase --autosquash` is now a project-level aspiration, and this patch is a foundational piece of that effort.
