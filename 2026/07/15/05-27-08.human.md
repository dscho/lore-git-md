This is the eighth patch in Patrick Steinhardt’s nine-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. The patch itself is a straightforward backend implementation that adds a `filter` field to the `odb_for_each_object_options` struct, allowing callers to pass object filters to backends for optimization. The "packed" backend uses this to skip excluded objects via bitmaps, avoiding redundant enumeration of packs already covered by a bitmap.
