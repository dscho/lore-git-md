This is the first patch in the eighteenth and final iteration of a security-hardened feature series implementing `git cat-file --batch-command` support for querying remote object metadata. The series is now queued for merging to `next` after resolving all prior technical and administrative issues.

This patch fixes a memory leak in the transport helper subsystem. The `disconnect_helper()` function currently only frees `data->name` when the helper process has fully started (`if (data->helper)`). If the transport is disconnected before the helper starts, `data->name`—allocated in `transport_helper_init()`—is never freed. The fix moves `FREE_AND_NULL(data->name)` outside the conditional block so it executes unconditionally during disconnect. The change is minimal (one line moved) and addresses a clear correctness issue without altering behavior.
