This thread is a small bugfix series for Gitweb that corrects how object IDs are displayed in commitdiff index lines. Travor Liu identified that the regex matching object IDs was running before the mode-handling code, causing full, unlinked hashes to appear instead of the usual shortened, clickable ones. The initial v1 submission included two patches: the first reordered the logic in `gitweb/gitweb.perl` to strip the mode first, and the second added a regression test in `t9502` to verify the fix for the `100644` mode case.

Junio C Hamano reviewed the series and suggested procedural improvements—squashing the test into the first patch and using `test_grep`/`test_grep !` instead of raw `grep` to align with an ongoing test-script hygiene effort. Travor Liu has now agreed to these changes and will submit a v2 with the adjustments. The fix itself remains uncontested, and the thread is now waiting for the updated version. No substantive objections or deeper technical discussion have emerged.
