This is the second patch in a two-part bugfix series for gitweb. It adds a regression test to verify that gitweb correctly shortens and hyperlinks object IDs in commitdiff index lines even when Git includes a trailing file mode (e.g., `index <old>..<new> 100644`).

The test creates a simple file modification, generates a commitdiff view in gitweb, and checks that the output shows the expected shortened, linked hashes followed by the mode and file-type annotation. It also confirms that the full, unlinked form of the object IDs does not appear. The test is minimal but sufficient to catch the specific bug addressed by the series.

This patch is straightforward and uncontroversial. It complements the first patch, which reorders the logic in `gitweb/gitweb.perl` to fix the rendering issue. The series as a whole is well-motivated and narrowly scoped, targeting a visible but low-risk bug in gitweb’s output formatting.
