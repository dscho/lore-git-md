This is a refactoring patch in the now-complete `remote-object-info` feature series, which is queued for merging to `next`. This is the seventh of ten patches in the eighteenth and final iteration (v18) of the series.

The patch generalizes the `write_fetch_command_and_capabilities()` function in `connect.c` to support arbitrary protocol v2 commands, not just "fetch". The function is renamed to `write_command_and_capabilities()` and gains a new `command` parameter that specifies the protocol operation (e.g., "fetch" or "object-info"). The change is a straightforward refactoring: the function body is updated to use the new parameter, and call sites in `fetch-pack.c` are adjusted to pass "fetch" explicitly. The patch also updates the function's documentation in `connect.h` to clarify its purpose.

This is a preparatory step for the final patch in the series (10/10), which introduces the `remote-object-info` command. The refactoring enables the new command to reuse the same capability-advertisement logic as `fetch`, avoiding code duplication. The change is mechanical and localized, with no behavior changes.
