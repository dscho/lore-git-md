This thread is about a patch from Tian Yuchen that advances two long-running Git efforts: libification and the removal of the `the_repository` global. The patch moves the global `fetch_if_missing` variable into `struct repository`, making it a per-repository flag that controls whether missing objects trigger lazy fetches from promisor remotes. The change is mechanical but touches 15 files, including core plumbing like `odb.c` and built-ins like `fsck` and `index-pack`, which required special handling for early option parsing.

The patch preserves existing behavior (the flag defaults to `1`, or enabled) and includes safeguards like a `BUG()` check in `revision.c` to enforce that `--exclude-promisor-objects` can only be used when `fetch_if_missing` is disabled. Tian’s work aligns with the established pattern of eliminating globals in favor of repository-specific state, and no test failures or behavioral changes are expected. So far, there’s been no review feedback, so the patch’s correctness and design haven’t been independently verified yet.
