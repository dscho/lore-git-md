This thread is about a patch that moves Git’s global `fetch_if_missing` flag into `struct repository`, part of the ongoing effort to eliminate global state. The author, Tian Yuchen, posted a second version addressing all prior feedback, including a critical correctness fix in `setup.c` and a pragmatic decision to retain `the_repository` in `index-pack.c` and `revision.c` to avoid unintended behavior changes.

Junio C Hamano has now raised a subtle but important edge case: when `git index-pack` runs outside a repository (and thus uses `the_repository`), the patch could inadvertently enable lazy fetches in scenarios where they were previously suppressed. This happens because the patch only sets `repo->fetch_if_missing = 0` when `repo` is non-NULL, leaving the flag at its default (enabled) in repository-less invocations. The current code unconditionally disables the flag in these cases, so the patch risks altering behavior. No other objections remain, but this issue will need to be addressed before the patch can be merged. The series is otherwise ready for pickup once this edge case is resolved.
