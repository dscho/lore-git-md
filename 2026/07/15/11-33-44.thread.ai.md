Core problem or goal
Fix a latent bug in `t/t7614-merge-signoff.sh` where the exit code of `git cat-file` is lost in a pipe to `sed`, potentially masking crashes or failures. The goal is to ensure the test harness checks the exit codes of both commands by replacing the pipe with an intermediate file and an `&&`-chain. Follow-up work has been scoped to introduce a helper function (`commit_body()` or similar) for the "cat-file + strip header" pattern and to clean up unnecessary backslash-escaping in `sed` commands, but these are explicitly decoupled from the current patch.

The author has acknowledged Junio’s follow-up suggestions and proposed addressing them in a separate patch after the current one lands. The patch remains narrowly scoped to the test script and does not affect Git's core functionality.

Key technical details
- File modified: `t/t7614-merge-signoff.sh`
- Commands involved: `git cat-file commit HEAD` and `sed -e "1,/^$/d"`
- Pattern replaced: `git cmd | sed` → `git cmd >file && sed file`
- Test cases affected: three test cases testing `--signoff`, no `--signoff`, and `--signoff --no-signoff` behavior
- New symbols or files: none (intermediate file `commit` is local to the test script)
