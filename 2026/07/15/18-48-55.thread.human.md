This thread is about a regression in Git 2.55.0 where `git rev-list --no-walk` stopped respecting path-filtering arguments like `-- ':!drivers/gpu/drm/'`. Peter Colberg reported the issue, pinpointing the cause to commit `dd4bc01c0a8f`, which refactored revision-walking logic but accidentally dropped a call to `process_parents()` that enforces path filters.

Kristofer Karlsson, the author of the problematic commit, has now acknowledged the bug and proposed a fix. He confirms the regression with a minimal test case and suggests restoring the `try_to_simplify_commit()` call in the `REV_WALK_NO_WALK` case of `get_revision_1()`. This would directly address the root cause without broader changes. The fix is likely to be uncontroversial, as it aligns with the original behavior and includes a clear reproduction case. The next steps will likely involve formal patch submission with test coverage, and discussion about whether to backport the fix to maintenance branches. The technical direction appears settled, with the main open questions now procedural.
