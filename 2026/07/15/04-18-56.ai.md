This is a refactoring patch targeting `builtin/show-branch.c`. Gatla Vishweshwar Reddy’s v4 patch completes the conversion from using `commit->object.flags` for per-branch state to a dedicated commit-slab (`commit_rev_flags`) with a configurable stride of `uint64_t` words. The key change from v3 is the restoration of the exact-bit-set check in `show_independent()` via the new `has_only_rev_flag_bit()` helper, fixing the behavioral regression Junio identified: a commit is now considered independent only if it is reachable from exactly one tip, not merely if the i-th bit is set. The patch lifts the previous 27-branch limit to 64 branches (with infrastructure for dynamic stride to support even more) and keeps the `UNINTERESTING` bit in `object.flags` for revision-walking compatibility. All bit operations use `UINT64_C(1)` for correct 64-bit shifts, and the slab is initialized and cleared in `cmd_show_branch()`. The patch touches only `builtin/show-branch.c`, reuses the `init_commit_rev_flags_with_stride` infrastructure from the 2025 variable-length bitset slab series, and preserves existing behavior except for the now-fixed regression. Test coverage remains unchanged, but the fix ensures the current test suite will not miss the regression. The patch is ready for maintainer sign-off once reviewers confirm the exact-bit-set logic is correct.
