This is the first patch in Patrick Steinhardt’s v2 series removing `the_repository` from the refs subsystem. It fixes a latent bug in the packed-refs backend: the `core.packedRefsTimeout` configuration was previously stored in function-static variables, meaning only the first repository’s setting would ever be used. The patch moves these variables into `struct packed_ref_store` so that each repository can have its own timeout value. The change is small (13 lines added, 6 removed) and touches only `refs/packed-backend.c`. Junio’s earlier review caught a behavioral regression in v1 (zero-initialized timeout instead of the 1000 ms default), which this version fixes by explicitly setting the default in `packed_ref_store_init()`. The patch is uncontroversial, well-motivated, and ready for merging as part of the ongoing `the_repository` removal effort.
