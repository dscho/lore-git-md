This is a refactoring patch (part 2 of 4 in v5) that moves the `ce_mode_from_stat()` helper function from `read-cache.h` to `read-cache.c`. The change is preparatory work for the larger goal of migrating `trust_executable_bit` and `has_symlinks` configuration flags into repository-scoped storage as part of the `the_repository` removal effort.

The patch itself is mechanical: it relocates the function implementation while preserving its logic and adds a descriptive comment. The removal of the `extern` declarations for `trust_executable_bit` and `has_symlinks` from the header is a clean-up side effect, as these globals are now only needed in the `.c` file. The commit message explains that this move is necessary to allow future repository-specific configuration access, though the current patch introduces no behavioral changes.

This is a well-scoped, uncontroversial step in the series. The function is already static in practice (being inlined in the header), so moving it to the `.c` file doesn’t affect its usage. The patch looks clean and aligns with the project’s preference for small, focused refactorings. Reviewers are unlikely to object to this change, though the broader series may attract discussion about the mingw compatibility layer adjustments mentioned in the cover letter.
