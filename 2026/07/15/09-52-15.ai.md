This is patch 7/10 in the final v18 series that implements `git cat-file --batch-command` support for querying remote object metadata. The patch refactors `write_fetch_command_and_capabilities()` in `connect.c` into a more generic `write_command_and_capabilities()` function, allowing it to support arbitrary Git wire protocol commands (e.g., "fetch", "object-info") rather than hardcoding "fetch".

The change is a straightforward mechanical refactoring: the function signature gains a `command` parameter, the hardcoded "fetch" string is replaced with the parameter, and call sites in `fetch-pack.c` are updated to pass "fetch" explicitly. The patch also expands the function's documentation in `connect.h` to clarify its purpose. No behavior changes are introduced; this is purely preparatory work for patch 10/10, which adds the `remote-object-info` command.

The patch carries Helped-by trailers for Jonathan Tan and Christian Couder, indicating their design input. It is part of a larger security-hardened series that has undergone 18 iterations, with all substantive issues (including bounds-checking, memory leaks, and type mismatches) resolved in earlier patches. This specific change was first introduced in v16 and remains functionally identical in v18, demonstrating stability through multiple review cycles.

The refactoring enables the final patch in the series to reuse the same protocol-handling logic for the new `object-info` command, avoiding code duplication. The series is now queued for merging to `next` after Junio Hamano's confirmation in the v18 cover letter.
