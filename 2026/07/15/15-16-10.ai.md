This is the second patch in Harald Nordgren’s five-part `git history squash` series (v9). It introduces a plumbing change to support the `--reedit-message` feature in the final patch.

The patch modifies `commit_tree_ext()` in `builtin/history.c` to accept an optional `message_template` parameter. When this parameter is non-NULL, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. The change is purely internal—no user-visible behavior changes—and enables the `--reedit-message` feature in patch 5/5 by allowing the caller to supply a custom message template.

The patch updates all existing callers (`cmd_history_fixup` and `split_commit`) to pass NULL, ensuring backward compatibility. The diff is small (10 insertions, 6 deletions) and focused, touching only the function signature and the message-selection logic. This is a clean, uncontroversial refactoring that prepares the ground for the `--reedit-message` implementation.
