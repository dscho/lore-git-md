This is a refactoring patch in Harald Nordgren’s `git history squash` series (v9, 4/5). It extracts three static helpers from `sequencer.c`—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—and moves the `todo_item_flags` enum into `sequencer.h`, making them reusable by other commands. The immediate goal is to let `git history squash --reedit-message` produce the same template format as `git rebase -i --autosquash`, ensuring visual and behavioral consistency.

The patch is pure code motion: no behavior changes, just exposing existing logic. The extracted helpers handle the "This is a combination of N commits" banner, the numbered headers above each kept or skipped message, and the decision whether to comment out a `fixup!`/`squash!`/`amend!` subject. The `TODO_REPLACE_FIXUP_MSG` flag (now in the public enum) lets callers distinguish `amend!` from plain `fixup!` when reading the output of `todo_list_rearrange_squash`.

This is uncontroversial and ready to merge; it was already flagged as such in the thread summary. The patch is a prerequisite for the final patch in the series, which implements `--reedit-message`.
