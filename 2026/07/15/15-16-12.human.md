This is a refactoring patch in Harald Nordgren’s `git history squash` series (v9, 4/5). It extracts three static helpers from `sequencer.c`—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—and moves the `todo_item_flags` enum into `sequencer.h` so that other commands can produce the same template format as `git rebase -i --autosquash`. The immediate consumer is the upcoming `--reedit-message` feature in `git history squash`, which will reuse these helpers to build an editor template that exactly matches the interactive rebase experience.

The patch is pure code motion: no behavior changes, just exposing existing logic for reuse. It is uncontroversial and ready to merge.
