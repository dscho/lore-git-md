This is a refactoring patch in the `remote-object-info` series, now at v18 and queued for `next`. The patch moves the initialization of three variables (`allow_unadvertised_object_request`, `use_sideband`, and `args->deepen`) from the `FETCH_CHECK_LOCAL` state to the function prologue of `do_fetch_pack_v2()` in `fetch-pack.c`. The change is purely mechanical: the same assignments are executed, but now unconditionally before the state machine begins, rather than inside the first state.

The motivation is forward compatibility: a later patch in the series will introduce an alternative initial state for the `remote-object-info` command, and these variables must be set regardless of which state the machine starts in. The commit message explicitly states there is no behavior change in the current code path.
