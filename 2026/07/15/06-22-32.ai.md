This is patch 2/9 in the v4 series introducing object filters to `odb_for_each_object()`. It is a small, mechanical refactoring that marks the `filter` parameter in `for_each_bitmapped_object()` and its helper functions (`filter_bitmap()`, `can_filter_bitmap()`) as `const`. The change is uncontroversial and aligns the code with the fact that the filter is never modified by these functions.

The patch touches `pack-bitmap.c` and `pack-bitmap.h`, updating function signatures and declarations to use `const struct list_objects_filter_options *` instead of `struct list_objects_filter_options *`. This is a pure type-safety improvement with no behavior change. The diff is minimal (4 insertions, 4 deletions) and was previously reviewed by Taylor Blau in v2, who noted it as a minor stylistic improvement. The change is now part of the series and has no unresolved feedback.

This patch is a prerequisite for later patches in the series (notably patch 8/9, which exposes `can_filter_bitmap()` for backend use) and is ready for integration. It is part of the broader ODB abstraction effort led by Patrick Steinhardt, which aims to enable pluggable object databases by removing backend-specific assumptions from core Git commands like `git cat-file`. The series as a whole is under final review, with no remaining technical objections.
