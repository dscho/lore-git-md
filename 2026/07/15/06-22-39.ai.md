This is the final patch (9/9) in Patrick Steinhardt’s nine-patch series introducing object filters to `odb_for_each_object()`, part of the ongoing ODB abstraction effort. The patch refactors `git cat-file --batch-all-objects` to use the new ODB-mediated filtering mechanism, eliminating its direct dependency on the packed backend’s internals.

The change replaces 69 lines of backend-specific logic with 7 lines of ODB API calls, removing the need for `git cat-file` to manually manage bitmaps or iterate over packs. The diff deletes two helper functions (`batch_one_object_packed` and `batch_one_object_bitmapped`) and the `pack-bitmap.h` include, while adding a `filter` field to the `odb_for_each_object_options` struct and passing it through to the ODB layer. The new implementation uses `odb_for_each_object_ext()` with an object filter, delegating the filtering logic to the backend (which can now optimize via bitmaps if available).

This is a clean, well-motivated refactoring that aligns with the series’ goal of making object enumeration backend-agnostic. The commit message clearly explains the coupling problem and how the patch resolves it. Junio C Hamano previously praised the implementation in v1 as "very nice," and all review feedback has been addressed in prior versions. The patch is ready for integration, pending Junio’s final review and the planned follow-up to split the callback type for bitmapped object iteration. No behavioral changes are expected for end users.
