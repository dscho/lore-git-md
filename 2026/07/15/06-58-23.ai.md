This is the sixth patch in Johannes Schindelin’s 11-patch series addressing unchecked return values identified by Coverity. The patch adds a missing error check in the `git_pread()` compatibility shim (`compat/pread.c`) for the initial `lseek(fd, 0, SEEK_CUR)` call, which saves the current file offset. Without this check, a non-seekable descriptor (e.g., a pipe) would cause `lseek()` to return `-1`, leaving `current_offset` set to an invalid value and leading to either a failed `lseek(fd, -1, SEEK_SET)` call or silent file position corruption.
