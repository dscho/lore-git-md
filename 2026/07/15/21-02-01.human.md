This is the eighth patch in the nine-patch `diff.<driver>.process` RFC series (v5). It teaches `git diff --stat` (and related summary formats `--numstat`, `--shortstat`) to consult the external diff process, so the counts reflect the tool's view of which lines changed rather than Git's builtin line diff. A file the tool reports as equivalent now contributes no stat line, matching the empty patch that `git diff` already produces for it.

The patch is a targeted plumbing change in `diff.c`: `builtin_diffstat()` now calls `diff_process_fill_hunks()` before running its own xdiff, and skips the xdiff entirely if the tool reports `DIFF_PROCESS_EQUIVALENT`. This keeps the inserted and deleted counts at zero so the file is pruned from the stat output, just as it is pruned from the patch output. The stat path does not apply textconv, so the tool receives the raw blob content (unlike the patch path, which sends textconv'd content), and the patch documents this asymmetry clearly in `gitattributes(5)`.

The test coverage is thorough: 130 new lines in `t/t4080-diff-process.sh` exercise counts from the tool's hunks (`--numstat`, `--shortstat`), an equivalent file producing no stat line, `--stat --exit-code`, the raw non-textconv content the tool receives, a multi-file mix of equivalent and changed files, and a mode-only change that keeps the file in the stat output even when the tool reports the content as equivalent. The patch also moves the summary formats out of the "not yet wired" group in the documentation and into the list of features that consult the tool's hunks, noting that `--dirstat=lines` follows these counts while the default `--dirstat` does not.

This is a well-crafted, low-risk change that completes the integration of the diff process with Git's summary formats. The implementation is careful to preserve existing behavior (e.g., mode-only changes, raw vs textconv content) and the documentation updates are clear and precise. The patch is ready for merging once the series as a whole receives final maintainer sign-off.
