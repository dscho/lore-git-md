This is a security inquiry about a potential vulnerability in Git for Windows. The author, Martin Berner, notes that Git for Windows bundles libssh2 1.11.1, which may be affected by CVE-2026-55200. He asks whether this is accurate and, if so, when a patched build might be released.

The email is not a patch or a technical contribution but a question directed at the Git for Windows maintainers (primarily Johannes Schindelin). It does not affect upstream Git itself, since Git for Windows is a separate fork that carries Windows-specific patches. The inquiry is narrowly scoped to the Windows distribution and its dependency chain (libcurl → libssh2). No actionable code or proposed fix is included.
