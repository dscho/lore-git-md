This thread is a security inquiry about whether Git for Windows is affected by CVE-2026-55200 due to its bundling of libssh2 1.11.1. The question was raised by Martin Berner, who asked if the vulnerability was relevant and when a patched build might be released.

Johannes Schindelin, the Git for Windows maintainer, has now responded, clarifying that while Git for Windows does include libssh2 1.11.1, the library is only used indirectly through libcurl, and there are no code paths in Git that expose libssh2 functionality. As a result, he considers the vulnerability non-critical for Git for Windows and does not plan to rush a patched release. He also noted that Git for Windows relies on MSYS2 for dependencies, and MSYS2 currently only provides libssh2 1.11.1, which is the latest upstream version. Schindelin’s reply was direct, particularly in response to the phrasing of Berner’s question, which he felt implied an expectation of immediate work without offering assistance—a dynamic he cautioned against.

No patch or code change has been proposed, and the thread remains a security inquiry rather than a remediation effort. The key takeaway is that Git for Windows is not exposed to CVE-2026-55200 in practice, and no immediate action is planned. Future updates to libssh2 in Git for Windows will depend on upstream releases and MSYS2 packaging.
