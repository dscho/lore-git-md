This thread began as a security inquiry into whether Git for Windows was affected by CVE-2026-55200 due to its bundling of libssh2 1.11.1. The question has been resolved: Johannes Schindelin confirmed that while Git for Windows does include libssh2 1.11.1 via MSYS2, the library is only used indirectly through libcurl, and there is no code path in Git’s usage that would expose the vulnerability. Martin Berner, the original reporter, acknowledged the explanation and closed the loop.

Todd Zullinger added context by linking to an open GitHub issue in the libssh2 repository requesting a new release to distribute recent security fixes, including CVE-2026-55200. While this doesn’t change the thread’s conclusion—no action is required for Git for Windows—it provides a way to track upstream progress on a future libssh2 release. The thread remains closed, with no further discussion or changes anticipated.
