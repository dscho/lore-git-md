This is patch 10 of Patrick Steinhardt’s 11-patch series making Git’s object database (ODB) optimizations pluggable. The patch fixes signedness issues in three ODB-related functions—`too_many_loose_objects()`, `find_base_packs()`, and `odb_optimize()`—to prevent compiler warnings when the code is moved from `builtin/gc.c` to the new `odb/source-files.c` in the next patch.

The changes are mechanical and defensive: `too_many_loose_objects()` now bails early if the limit is non-positive, `find_base_packs()` casts the pack size to `uintmax_t` before comparing it to the unsigned limit, and `odb_optimize()` casts `gc_auto_pack_limit` to `unsigned long` when comparing it to `keep_pack.nr`. The logic remains identical to the original code paths; only the types are adjusted to avoid `-Wsign-compare` warnings. The patch is a prerequisite for the final relocation of the ODB optimization helpers into their new home, ensuring the code compiles cleanly in its new context.
