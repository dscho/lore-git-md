This is a brief follow-up in the resolved security inquiry about Git for Windows and CVE-2026-55200. Todd Zullinger adds context about libssh2’s release process, pointing to an open GitHub issue requesting a new upstream release to help distributions package the recent security fixes. The issue was filed two months ago, after an earlier CVE but before CVE-2026-55200 and others were disclosed.

The message is purely informational and does not change the thread’s conclusion: Git for Windows is not exposed to the vulnerability, and no immediate action is needed. Todd’s link provides a way for interested readers to track when libssh2 might publish a new release, which could eventually flow into MSYS2 and then into Git for Windows. The tone is neutral and collaborative, offering additional transparency without demanding any response.
