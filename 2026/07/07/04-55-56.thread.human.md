This thread is a cleanup and refactoring series from Jeff King (Peff) that makes the `git_hash_*()` API safer and more consistent. The series addresses a subtle footgun in the existing code: `git_hash_discard()` was not idempotent, meaning callers had to track whether a hash context had already been finalized or discarded to avoid leaving it in an inconsistent state. The seven-patch series (now at v2) fixes this by adding an `active` flag to the `git_hash_ctx` struct, standardizes usage of the hash API by replacing direct calls to low-level hooks with wrapper functions, and adds defensive runtime checks to catch misuse early.

The changes touch 26 files across core object-writing code, built-ins, and test helpers, but introduce no user-visible behavior changes or on-disk format modifications.
