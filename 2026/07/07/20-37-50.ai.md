This is a **build system patch series** for the Rustification effort, specifically targeting the macOS credential helper (`git-credential-osxkeychain`). The v7 series from Shardul Natu is **functionally identical to v6**, which is already queued in Junio’s integration branches (status: under review, likely in `pu` or `next`). No further action is needed for v7; Junio will proceed with v6 as previously planned.

The series resolves three key issues: (1) a **parallel build race condition** in `git-credential-osxkeychain` by explicitly linking against `$(LIB_FILE)` and `$(RUST_LIB)` instead of `$(GITLIBS)`, avoiding a duplicate `main()` symbol conflict with `common-main.o`; (2) **Universal Binary support** for Rust components on macOS via the `RUST_TARGETS` environment variable, combining static libraries for `aarch64-apple-darwin` and `x86_64-apple-darwin` into a single Universal Binary using `lipo`; and (3) **CI verification** for the macOS credential helper by integrating it into `contrib/Makefile`’s test suite when `TEST_CONTRIB_TOO=yes` is set.

The patch touches `Makefile`, `contrib/Makefile`, and `contrib/credential/osxkeychain/Makefile`, introducing build variables like `RUST_TARGETS`, `$(RUST_MEMBER_LIBS)`, and `OS_CONTRIB`. It enforces macOS-only usage of `RUST_TARGETS` and maintains clean no-op behavior when `NO_RUST=1` is specified. The series is **build-time only**, with no on-disk format changes or new runtime behavior. Test coverage is implicit via existing build tests, and the CI verification patch ensures the credential helper is tested in standard macOS CI runs.

All blocking issues—including Junio’s earlier concern about duplicate `main()` symbols—are resolved in v6/v7. The only remaining open question is Patrick Steinhardt’s suggestion to unify the Rust artifact directory structure under `target/$BUILD_CONFIG/` (e.g., `target/release/x86_64-apple-darwin/`), but this is not a blocker and may be addressed in a follow-up. The series is **ready for integration** and likely to graduate to `next` in the current cycle unless Junio revisits the artifact layout topic.
