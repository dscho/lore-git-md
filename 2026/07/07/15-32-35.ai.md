This is the third patch in Patrick Steinhardt’s 11-patch series making Git’s object database (ODB) optimizations pluggable. It extracts the repack and prune logic from `cmd_gc()` into a new helper function, `maintenance_task_odb()`, as a pure refactoring step. The patch touches only `builtin/gc.c`, moving 79 lines (49 added, 30 removed) without changing behavior. The loose-object warning is also relocated into the new function, though the commit message notes this timing change is not expected to have practical impact.

The patch is a straightforward code reorganization that prepares the ground for later commits in the series, which will move this logic into the ODB abstraction layer. No new symbols or on-disk formats are introduced here; the focus is on making the existing optimization code reusable by future ODB backends. The change is well-scoped and aligns with the series’ goal of modularizing ODB housekeeping.
