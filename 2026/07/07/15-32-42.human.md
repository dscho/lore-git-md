This is a bugfix patch in Patrick Steinhardt’s 11-part series making Git’s object database (ODB) optimizations pluggable. It cleans up signedness issues in three ODB-related helpers—`too_many_loose_objects()`, `find_base_packs()`, and `odb_optimize()`—so they compile cleanly when moved from `builtin/gc.c` to the new `odb/source-files.c` file in the next patch.

The fixes are small and surgical: early returns for negative limits, casts to unsigned types, and a comment preserving the quirky legacy rounding behavior. No behavior changes—just warning suppression in preparation for the code relocation. The patch is clearly motivated and well-scoped; if you care about the ODB abstraction effort, this is a minor but necessary step.
