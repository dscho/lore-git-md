This is the second patch in Patrick Steinhardt’s 11-patch series making Git’s object database (ODB) optimizations pluggable. It’s a small but deliberate refactoring that reorders maintenance tasks in `` `git gc` `` to group all object-database optimizations together.

The patch moves worktree pruning and rerere garbage collection earlier in the sequence so that the subsequent object optimizations (repack, prune, etc.) run as a contiguous block. The commit message acknowledges the theoretical edge case where pruning worktrees first could make objects unreachable that would otherwise have been kept alive, but dismisses it as negligible in practice. This change is purely internal and has no user-visible effect—it’s laying the groundwork for the later patches that extract the ODB optimizations into a modular backend.
