This is a documentation patch from Junio C Hamano, the Git maintainer. It fixes an incomplete sentence in the Git 2.55.0 release notes about Rust support.

This isn’t part of a larger series; it’s a standalone correction to an existing release note. The commit message explains the motivation clearly, and the fix itself is straightforward. If you’re tracking the Rustification effort or preparing for Git 3.0, this update is worth noting.
