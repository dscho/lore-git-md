This is a small but important documentation update to the Git 2.55.0 release notes. Junio C Hamano has clarified the project's Rust support timeline, addressing confusion caused by an earlier vague phrasing. The new text makes it explicit that Git 2.55 builds with Rust by default (with an opt-out option), and that Rust will become mandatory starting with Git 3.0. This change doesn't alter any code or build behavior—it simply provides the missing clarity about when the transition will happen.

The patch is part of the broader Rustification effort, though it's purely informational. Junio noted in the commit message that he typically avoids updating historical documents, but made an exception here because the original wording had already caused confusion among users and distributors. The update aligns with the project's established roadmap and should be uncontroversial.
