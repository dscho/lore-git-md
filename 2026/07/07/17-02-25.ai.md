This is the final patch in the v7 Rustification build system series, adding CI verification for the macOS credential helper (`git-credential-osxkeychain`). The patch wires the helper into `contrib/Makefile` so that it is built and tested during standard CI runs on macOS when `TEST_CONTRIB_TOO=yes` is set.

The change is straightforward: it adds `credential/osxkeychain` to the `OS_CONTRIB` variable when running on Darwin, then includes it in the `all`, `test`, and `clean` targets of `contrib/Makefile`. The `osxkeychain/Makefile` itself gains a new `test` target that depends on building the helper, ensuring the build and link steps are exercised. This closes a gap where the helper was previously excluded from automated testing, despite being a critical component for macOS users.

The patch is well-motivated and uncontroversial. It touches only build infrastructure (`contrib/Makefile` and `contrib/credential/osxkeychain/Makefile`) and introduces no new behavior or on-disk changes. The conditional inclusion (`ifeq ($(uname_S),Darwin)`) ensures the change is macOS-specific, and the existing `TEST_CONTRIB_TOO` mechanism provides the necessary CI coverage. This is a minor but important housekeeping improvement for the Rustification effort, ensuring future regressions in the macOS credential helper are caught early. The series as a whole is now complete and ready for integration.
