This is the first patch in Jeff King’s 7-patch series refactoring the `git_hash_*()` API. It mechanically converts all direct calls to `algop->init_fn()` into the wrapper function `git_hash_init()`, using a new Coccinelle semantic patch (`tools/coccinelle/hash.cocci`) to enforce consistency. The patch touches 21 files across core object-writing code (`csum-file.c`, `object-file.c`, `http.c`), built-ins (`fast-import`, `index-pack`, `receive-pack`), and test helpers.

The change is purely syntactic: no behavior or on-disk format is altered. The motivation is to prepare the codebase for future logic that will be added to `git_hash_init()` (specifically, an `active` flag to make `git_hash_discard()` idempotent). The Coccinelle rule ensures that no direct `init_fn()` calls remain, preventing future regressions. The patch is small, focused, and clearly motivated by the series’ overall goal.
