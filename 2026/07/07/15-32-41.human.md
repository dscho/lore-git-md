This is the ninth patch in Patrick Steinhardt’s 11-patch series making Git’s object database (ODB) optimizations pluggable. It refactors the "files" ODB backend’s optimization helpers—`too_many_loose_objects()`, `too_many_packs()`, `find_base_packs()`, and `estimate_repack_memory()`—to accept an explicit `struct odb_source_files *` parameter instead of relying on the global `the_repository`. The patch is a mechanical step toward moving the entire optimization logic into `odb/source-files.c` in the next patch, continuing the ODB abstraction effort.

The changes are confined to `builtin/gc.c` and touch only the internal interfaces; no new behavior or user-facing features are introduced. The patch removes implicit global state, replacing it with an explicit source parameter passed through the existing `odb_optimize()` and `odb_optimize_required()` entry points. This keeps the refactoring self-contained and prepares the codebase for the upcoming backend-agnostic optimization API.

The patch looks clean and well-scoped: it preserves all existing logic while eliminating a layer of global state, which is exactly what the series aims to do.
