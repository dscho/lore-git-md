This is a security inquiry response about Git for Windows and its bundled libssh2 dependency. Johannes Schindelin, the Git for Windows maintainer, replies to Martin Berner’s question about CVE-2026-55200.

Johannes clarifies that in Git for Windows, libssh2 is only used indirectly through libcurl, and Git’s usage of libcurl does not trigger any code path that would expose libssh2 functionality. He therefore considers the issue non-critical and not urgent enough to warrant an immediate release. He also notes that Git for Windows relies on MSYS2 for its dependencies, and MSYS2 currently only provides libssh2 1.11.1, which is also the latest version listed on libssh2’s official site.

The tone is direct, particularly in response to the phrasing of the original question ("when can a patched build be expected"), which Johannes interprets as entitled. He explains the dependency chain and the lack of newer libssh2 releases without committing to a timeline for an update. No patch or code change is proposed here—this is purely a maintainer’s assessment of the situation. If the CVE details later show a real impact on Git for Windows, expect further discussion about dependency updates or mitigations.
