This is the second patch in Jeff King’s seven-patch series refactoring the `git_hash_*()` API. It mechanically converts all remaining direct calls to the hash-algo vtable’s `update_fn()`, `final_fn()`, `final_oid_fn()`, `clone_fn()`, and `discard_fn()` into the corresponding `git_hash_*()` wrapper functions.

The patch touches three files: `builtin/submodule--helper.c`, `t/helper/test-synthesize.c`, and the new Coccinelle semantic patch (`tools/coccinelle/hash.cocci`). The Coccinelle rule enforces that every call to the vtable’s function pointers is replaced by the wrapper, eliminating the need to pass around the `algo` pointer separately. In `test-synthesize.c`, this allows dropping an unused `algo` parameter from `write_uncompressed_zlib()`.

No behavior changes are introduced; the patch is purely a refactoring that paves the way for the later idempotent `git_hash_discard()` change. The Coccinelle rule is comprehensive, covering all five vtable functions, and will prevent future regressions by making the wrappers the only allowed interface.
