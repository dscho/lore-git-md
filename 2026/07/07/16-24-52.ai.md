This is a follow-up in the resolved security inquiry about Git for Windows and CVE-2026-55200. Todd Zullinger adds context about libssh2's release process, not a patch or new vulnerability.

Todd acknowledges Johannes Schindelin’s explanation that Git for Windows bundles libssh2 1.11.1 because it is the latest version available from MSYS2 and upstream. He then provides a link to a two-month-old GitHub issue in the libssh2 repository requesting a new release to distribute recent security fixes, including CVE-2026-55200. The issue remains open, so no newer libssh2 release has been cut since 1.11.1.

The email is purely informational and does not change the thread’s conclusion: Git for Windows is not exposed to the vulnerability, and no immediate action is required. It does, however, offer a way for interested parties to monitor upstream progress on a libssh2 release that would include the fixes. No code, configuration, or build-system changes are proposed or discussed.
