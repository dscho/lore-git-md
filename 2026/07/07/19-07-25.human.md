This is the first patch in the v7 series introducing `--linearize` to `git replay`. It’s a refactoring patch that extracts the logic for storing a commit in the `replayed_commits` map into a new helper function, `put_mapped_commit()`, and renames the existing lookup function from `mapped_commit()` to `get_mapped_commit()` for symmetry.

The change is purely internal and touches only `replay.c`. It reduces duplication (the map-insertion code was previously open-coded in `replay_revisions()`) and makes the code slightly more readable. The BUG message in the new helper has been tweaked to remove the trailing newline, addressing a minor style nit from earlier reviews. No behavior changes are introduced; this is preparation for the `--linearize` implementation that follows in patch 3.
