This is the **final patch (13/13)** in Patrick Steinhardt’s refactoring series to separate repository discovery from setup in Git’s core code. The patch is a clean-up step: after the previous patch (12/13) removed the last external callers of `set_git_work_tree()`, this patch marks the function as `static` in `setup.c` and removes its declaration from `setup.h`.

The change is purely mechanical—two lines removed from the header, one line added in the implementation—and has no behavioral impact. It completes the series’ goal of consolidating worktree configuration into `init_db()` and eliminating indirect setup logic. The function’s removal from the public API reflects its now-internal role, aligning with the broader effort to reduce scattered state and improve code clarity.

This patch is uncontroversial and likely to be merged as-is, assuming the rest of the series lands. It’s a small but symbolic step toward the architectural vision of self-contained repository setup phases. No further discussion is expected unless earlier patches in the series raise issues.
