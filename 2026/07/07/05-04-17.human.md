This is the second patch in Jeff King’s seven-part series refactoring the `git_hash_*()` API. It mechanically converts all remaining direct calls to the hash-algo function pointers (`update_fn`, `final_fn`, `final_oid_fn`, `clone_fn`, and `discard_fn`) into calls to the corresponding `git_hash_*()` wrapper functions. The patch touches three files: `builtin/submodule--helper.c`, `t/helper/test-synthesize.c`, and the new Coccinelle semantic patch in `tools/coccinelle/hash.cocci`.

The key change is that callers no longer need to pass the `algo` pointer explicitly; the wrapper functions implicitly use the `algop` field stored in the `git_hash_ctx` struct. This eliminates redundant parameter passing and ensures that the algorithm pointer always matches the context. The Coccinelle rule added in this patch enforces the new convention, preventing future regressions.

The patch is a straightforward refactoring with no behavior changes. It builds on the foundation laid in patch 1 (which standardized `git_hash_init()` usage) and prepares the codebase for patch 4, which will make `git_hash_discard()` idempotent.
