This is a documentation patch correcting a factual error in the Git 2.55 release notes. The original text stated that Rust support would be enabled by default "in some future version of Git," but the actual plan is to make Rust mandatory in Git 3.0. Michael Montalbo points out the discrepancy and provides a corrected version that explicitly names Git 3.0 as the milestone.

The change is small and uncontroversial—it aligns the release notes with the project's previously announced roadmap. The patch is already marked "LGTM" by Junio C Hamano, indicating it is likely to be merged as-is. If you follow Git's Rustification effort, this is a minor but useful clarification.
