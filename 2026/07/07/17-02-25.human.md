This is the final patch in the v7 series adjusting Git’s build system for Rust components on macOS. It ensures the `git-credential-osxkeychain` helper is automatically built and tested in standard CI runs on macOS.

The patch wires up `contrib/credential/osxkeychain` in `contrib/Makefile` by adding it to the `all`, `test`, and `clean` targets when running on macOS (Darwin). It also adds a `test` target to `contrib/credential/osxkeychain/Makefile` that depends on building the helper, ensuring it is compiled and linked during `make test` with `TEST_CONTRIB_TOO=yes`. This closes a gap where the helper was previously excluded from CI verification, preventing future build or symbol-linking regressions from slipping through.

The change is minimal and well-scoped, touching only the build system without altering runtime behavior or on-disk formats. It complements the earlier patches in the series, which fixed a parallel build race condition and added Universal Binary support for Rust libraries. The patch is uncontroversial and aligns with the series’ goal of improving CI reliability for macOS-specific components. No further discussion or objections are expected.
