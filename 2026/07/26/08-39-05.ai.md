This is the second patch in a two-patch CI/build system series from Jeff King. It updates the Ubuntu image version used in Git's static-analysis CI jobs from `ubuntu-22.04` to `ubuntu-latest`, ensuring the jobs run with a newer version of Coccinelle (1.3.0 or later) that resolves a known performance issue. The change affects both GitHub Actions (`.github/workflows/main.yml`) and GitLab CI (`.gitlab-ci.yml`) configurations.

The patch is straightforward: it replaces the pinned `ubuntu-22.04` image with `ubuntu-latest` in both CI files. The commit message explains the rationale: the original pin to `ubuntu-22.04` was a workaround for Coccinelle's absence in `ubuntu-20.04`, but newer Ubuntu versions include the tool, making a pinned version unnecessary. Jeff tested the change on GitHub CI but not on GitLab, though the change is minimal and unlikely to introduce issues.

This patch, combined with the first in the series (which silences a Coccinelle false positive in `bloom.c`), removes a prior in-code workaround for the Coccinelle performance issue. The series is self-contained, targets only the static-analysis job, and introduces no functional changes to Git itself. The files touched are `.github/workflows/main.yml` and `.gitlab-ci.yml`; no new symbols or behavioral changes are introduced. The patch is under review as part of v1 of the series.
