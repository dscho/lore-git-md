This is a CI/build system patch series from Jeff King (Peff) that bumps the Ubuntu image version used in Git's static-analysis CI jobs to pick up a newer version of Coccinelle.

The series consists of two patches. The first is a preparatory cleanup in `bloom.c` that silences a false positive from Coccinelle's `CHECK_ASSERTION_SIDE_EFFECTS` rule by adjusting how an assertion macro is written. This is a minor refactoring with no functional change, and Peff cc'd Elijah Newren as the original author of the affected code. The second patch updates the Ubuntu image version in both GitHub Actions (`.github/workflows/main.yml`) and GitLab CI (`.gitlab-ci.yml`) configurations from `ubuntu-22.04` to `ubuntu-24.04`.

The motivation is to avoid a known performance issue in Coccinelle that was previously worked around in code (as discussed in a thread started by Toon Claes). While the workaround is already in place, Peff argues that running newer versions of development tools is generally preferable. The change affects only the static-analysis CI job, not the broader test matrix. No behavioral changes to Git itself are introduced.
