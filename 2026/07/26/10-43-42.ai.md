This is the sixth patch in the seven-patch v3 series adding path-related keys to `` `git repo info` ``. It introduces `path.grafts.absolute` and `path.grafts.relative`, exposing the location of the repository’s grafts file in both absolute and relative forms. The implementation uses `repo_get_graft_file()` and `format_path()`, respects the `GIT_GRAFT_FILE` environment override, and returns the path unconditionally—even if the file does not exist or the repository is bare—matching the settled design for `path.index` and `path.hooks` and following the precedent set by `git rev-parse --git-path`. The patch touches `builtin/repo.c`, `Documentation/git-repo.adoc`, and `t/t1900-repo-info.sh`, adding two new keys and corresponding tests that verify both the standard path and the environment-override behavior. No functional changes from v2; only the documentation now explicitly states the unconditional-return behavior. The patch is mechanically clean, well-tested, and ready for review.
