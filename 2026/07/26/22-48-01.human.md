This is a test infrastructure patch series from Shlok Kulshreshtha, following up on a suggestion Junio made while reviewing an earlier patch (now merged as b6b276974e). The goal is to add a reusable `commit_body` helper to the test library and convert the 60-odd existing call sites that manually extract a commit’s message body with `git cat-file` and `sed`.

The first patch adds the helper to `t/test-lib-functions.sh` and documents it in `t/README`. The second patch mechanically replaces the scattered one-off pipelines with the new helper. The conversion is mostly straightforward, though two sites needed special handling, and a handful of others were left alone because they weren’t actually extracting a commit body (they were parsing email headers, hand-built objects, or patch files).

The series is cleanly motivated: it eliminates code duplication, fixes the same exit-code masking bug that the earlier t7614 patch addressed, and makes the test suite slightly more maintainable. All touched scripts still pass, and a deliberate `git cat-file` failure now correctly fails a test that previously passed, confirming the fix is effective. The patches look well-crafted and ready for review.
