This is the second patch in a two-part CI/build system series from Jeff King. It updates the Ubuntu image version used for Git's static-analysis CI jobs from `ubuntu-22.04` to `ubuntu-latest`, ensuring the jobs run with a newer Coccinelle version (1.3.0 or later) that resolves a known performance issue. The change affects both GitHub Actions (`.github/workflows/main.yml`) and GitLab CI (`.gitlab-ci.yml`) configurations.

The motivation is straightforward: older Coccinelle versions (like 1.1.1 in Ubuntu 22.04) exhibit severe performance problems that can cause CI timeouts. The fix for this was introduced in Coccinelle 1.3.0, which is available in newer Ubuntu images. Jeff notes that pinning to a specific Ubuntu version was originally necessary because Coccinelle wasn't available in Ubuntu 20.04, but that limitation no longer applies. Using `ubuntu-latest` simplifies maintenance and avoids future version-specific issues.

The patch itself is minimal, changing only the image references in the CI configurations. Jeff tested the GitHub Actions update but didn't verify the GitLab CI change, though he notes the risk is negligible given the simplicity of the modification. This patch complements the first in the series, which silences a Coccinelle false positive in `bloom.c` by refactoring an assertion macro—removing the need for a prior workaround.

The series is well-motivated and addresses a real pain point in the CI pipeline. The changes are confined to the static-analysis job and don't affect Git's functionality or broader test matrix. Given Jeff's track record and the thoroughness of the commit message, this looks like a solid, uncontroversial improvement.
