This is the first patch in the v6 series introducing `diff.<driver>.process`, a long-running subprocess protocol for external diff tools. It lays the documentation foundation by clarifying the limitations of the existing `diff.<driver>.command` mechanism in `gitattributes(5)`.

The patch adds a concise but thorough explanation of what an external diff driver *cannot* do: it only replaces the textual patch output, so features like word diff, function context (`-W`), `--color-moved`, and syntax coloring do not apply to its output. More importantly, it documents that summary formats (`--stat`, `--numstat`, `--shortstat`, `--dirstat`), `git blame`, and `git log -L` bypass the driver entirely and continue using Git's builtin diff. This sets clear expectations for users and establishes the motivation for the process driver introduced later in the series, which will address these gaps.

The change is minimal (10 lines) and targeted: it does not yet mention the process driver, but by documenting the command driver's limitations, it implicitly motivates the need for a more integrated solution. The prose is clear and direct, avoiding technical jargon while precisely describing the behavior. This patch is uncontroversial and serves as a necessary prerequisite for the rest of the series.
