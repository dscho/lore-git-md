This is a CI/build system patch from Jeff King (Peff). It updates the Ubuntu image version used in Git’s static-analysis CI jobs to pick up a newer version of Coccinelle, the semantic patch tool. The immediate motivation is to avoid a performance regression in Coccinelle that was previously worked around in the codebase (see the linked thread), but Peff frames it as a general hygiene improvement—running newer dev tools is preferable to older ones.

The series consists of two patches. The first is a small cleanup in `bloom.c` to silence a false positive from Coccinelle’s `CHECK_ASSERTION_SIDE_EFFECTS` rule. Peff flags this as a necessary precursor and cc’s Elijah Newren, who originally authored the code. The second patch updates the image version in both GitHub Actions (`.github/workflows/main.yml`) and GitLab CI (`.gitlab-ci.yml`) configurations.

The change is straightforward and low-risk: it touches only CI configuration files and a single line in `bloom.c`. There’s no behavior change for end users, and the series is explicitly marked as non-urgent. If the new image version proves stable, this looks like a sensible maintenance update.
