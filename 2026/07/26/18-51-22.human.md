This is the third patch in the nine-part `diff.<driver>.process` RFC series (v6). It adds plumbing to Git’s configuration system so that users can specify an external diff tool via the new `diff.<driver>.process` configuration key.

The patch is minimal: it extends the `userdiff_driver` struct with two fields (`process` and `process_owned`) and teaches `userdiff_config()` to populate them from Git config. No behavior changes yet — this is purely infrastructure that later patches will use to launch and communicate with the external process. The change is inert at this stage, but it is a necessary building block for the rest of the series.
