This is the third patch in the nine-patch `diff.<driver>.process` RFC series (v6). It adds plumbing to the userdiff configuration system to support the new `diff.<driver>.process` setting, which will later be used to launch and manage the long-running subprocess that injects diff hunks into Git's pipelines.

The patch is minimal and inert: it extends the `userdiff_driver` struct with `process` and `process_owned` fields (mirroring the existing pattern for `command` and `textconv`) and teaches `userdiff_config()` to populate them from Git configuration. No behavior changes occur yet; this is purely preparatory work for later patches that will wire up the subprocess protocol. The change is straightforward and follows established patterns in the codebase.
