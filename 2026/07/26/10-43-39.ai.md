This is the third patch in the v3 series adding path-related keys to `` `git repo info` ``. It implements ``path.objects.absolute`` and ``path.objects.relative``, which expose the repository’s object database directory in both absolute and relative forms, respecting the ``GIT_OBJECT_DIRECTORY`` environment override.

The patch is a straightforward extension of the established pattern: two new getter functions (``get_path_objects_absolute`` and ``get_path_objects_relative``) call ``repo_get_object_directory()`` and pass the result through ``format_path()`` with the appropriate flag. Documentation and tests are included, covering both the default case and an environment-override scenario. The implementation is clean, well-tested, and ready for review; the only likely discussion points are stylistic (e.g., whether ``path.objectdir`` would be a more idiomatic name).
