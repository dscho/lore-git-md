This is the third patch in the seven-part v3 series adding path-related keys to `` `git repo info` ``. It introduces ``path.objects.absolute`` and ``path.objects.relative``, which expose the location of the object database directory in both absolute and relative forms, respecting the ``GIT_OBJECT_DIRECTORY`` environment override.

The implementation is straightforward: two new getter functions in ``builtin/repo.c`` call ``repo_get_object_directory()`` and pass the result through ``format_path()`` with either ``PATH_FORMAT_CANONICAL`` or ``PATH_FORMAT_RELATIVE``. The patch updates the documentation and adds two new tests—one for the default case and one that verifies the override works.

There is nothing controversial here; the patch is mechanically clean, well-tested, and follows the established pattern of the series. Reviewers may still suggest minor naming tweaks (e.g., ``path.objectdir`` instead of ``path.objects``), but the functionality itself looks solid and ready for integration.
