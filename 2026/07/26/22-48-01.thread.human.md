This thread is about a small but useful cleanup in Git’s test suite. Shlok Kulshreshtha is introducing a new shell helper, `commit_body()`, to replace about 60 duplicated instances of the pattern `git cat-file commit <rev> | sed -e '1,/^$/d'` that currently mask exit codes. The change was prompted by a recent bugfix in `t7614` where Junio Hamano noted this exit-code hole.

The series is now under review in its second version. The initial v1 missed two call sites—one in `t7509-commit.sh` and another in `t3404-rebase-interactive.sh`—both of which still use the problematic pattern. Shlok has confirmed these will be fixed in v2 by converting them to use the new helper, bringing the total number of test scripts touched to 13. Junio’s feedback was purely about completeness, and the author has addressed it directly. The core motivation and design remain unchanged: this is a mechanical cleanup with no user-visible impact, consolidating duplicated code and fixing a latent bug in the test suite. Expect v2 to land soon, as there are no open design questions or objections.
