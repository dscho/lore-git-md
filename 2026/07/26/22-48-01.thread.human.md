This thread introduces a small but useful improvement to Git's test infrastructure. Shlok Kulshreshtha has proposed a new shell helper, `commit_body()`, to replace about 60 duplicated instances of a pattern that extracts the message body from a commit object. The current idiom—`git cat-file commit <rev> | sed -e '1,/^$/d'`—masks exit codes, which recently caused a bug in `t7614` that Junio Hamano fixed in commit `b6b276974e`. The new helper avoids this pitfall by writing the commit object to a temporary file, stripping the header, and cleaning up, all while preserving exit codes.

The series is straightforward: the first patch adds the helper and its documentation, while the second mechanically converts 11 test scripts to use it. The conversion is clean, collapsing four equivalent spellings of the idiom into a single call. Two test scripts required minor adjustments to avoid reintroducing exit-code issues, but the changes are minimal and well-justified. All converted tests pass, and the series is currently under review. No objections or open questions have been raised yet, and the work is purely internal to the test suite, with no user-visible impact. If this lands, it will make the test suite slightly more robust and maintainable.
