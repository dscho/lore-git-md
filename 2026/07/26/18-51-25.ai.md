This is the sixth patch in the `diff.<driver>.process` RFC series (6/9). It unifies the bypass mechanism for external diff tools under `--no-ext-diff` and disables the new process driver in `git format-patch`.

The patch replaces the boolean `--ext-diff` option with a callback that sets both `allow_external` (for the legacy `diff.<driver>.command`) and `no_diff_process` (for the new `diff.<driver>.process`). This ensures a single flag controls both external diff mechanisms, with `--ext-diff` overriding `--no-ext-diff` if both are given. It also unconditionally disables the process driver in `git format-patch` to guarantee generated patches use Git's builtin diff algorithm, making them reliably applicable by recipients without the external tool.

Documentation updates clarify that `--no-ext-diff` and `--diff-algorithm` now bypass the process driver entirely, and that whitespace-ignoring options (`-w`, `-b`, etc.) also skip it. The test suite adds coverage for the new bypass behaviors, including verification that `format-patch` does not invoke the external tool.

The implementation is clean and the rationale (consistent user experience, reliable patch generation) is sound.
