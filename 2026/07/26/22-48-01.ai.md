This is a test infrastructure patch series introducing a new helper function for the Git test suite. The series adds `commit_body()`, a shell function that extracts the message body from a commit object, and converts 60 existing call sites across 11 test scripts to use it.

The motivation comes from a recent bugfix in `t7614` (now merged as `b6b276974e`) where Junio Hamano noted that the pattern of using `git cat-file commit` piped to `sed` to strip headers recurs throughout the test suite and masks exit codes. This series factors that pattern into a reusable helper, eliminating the exit-code hole while also cleaning up duplicated code.

Patch 1/2 adds the helper to `t/test-lib-functions.sh` with documentation in `t/README`. The implementation follows Junio's suggested sketch exactly: it writes the commit object to a temporary file, strips the header with `sed`, and cleans up. Patch 2/2 performs the mechanical conversion of existing call sites, collapsing four equivalent spellings of the same idiom into a single function call. Two sites required special handling, which is explained in the commit message.

The series is well-scoped and thoroughly verified: all touched test scripts pass in full, and a deliberate `git cat-file` failure now properly fails tests that previously masked the error. The changes are purely internal to the test suite and have no user-visible impact. Key files touched include `t/test-lib-functions.sh`, `t/README`, and 11 test scripts (`t3405`, `t3408`, `t3434`, `t3900`, `t4150`, `t7500`, `t7501`, `t7502`, `t7600`, `t7604`, `t7614`). The helper function `commit_body()` is now available for future test scripts to use.
