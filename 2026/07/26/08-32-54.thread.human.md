This thread is about a small but practical improvement to Git’s CI setup: bumping the Ubuntu image used for static-analysis jobs from 22.04 to the latest version (24.04) to pick up a newer Coccinelle release, which should speed up the static-analysis runs. Jeff King sent the initial patch series, which also includes a minor cleanup in `bloom.c` to silence a Coccinelle false positive that was previously worked around with compiler flags. Junio Hamano has already signaled approval in principle, calling the patches “interesting,” so the series is likely to be merged soon.

Patrick Steinhardt chimed in to endorse the change, calling it a “great” and nearly cost-free improvement. He also raised a broader point: Git now has many Coccinelle semantic patches (`.cocci` files), some of which may no longer be useful because the code migrations they target—like `refs` or `the_repository`—are long complete. He suggested auditing and pruning these obsolete rules as a potential follow-up to further speed up Coccinelle runs, though he hasn’t measured the impact. This is a speculative idea rather than a critique of the current patch, so it doesn’t block the series. The thread remains under review, with no open questions or objections.
