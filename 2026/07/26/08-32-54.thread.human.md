This thread is about updating Git’s static-analysis CI job to use a newer Ubuntu image (`ubuntu-latest`, resolving to 24.04), which provides a newer Coccinelle version (1.3.0+) and eliminates a known performance issue. The change also includes a preparatory cleanup in `bloom.c` to silence a Coccinelle false positive triggered by an assertion macro under GCC 15.

The series (v1) is under review and has received positive feedback from Junio C Hamano, who called the patches "interesting" and thanked the author, and Patrick Steinhardt, who endorsed the CI image bump as a "great" improvement. The patches touch `bloom.c` (replacing an assertion macro with an explicit `if/else` cascade) and the CI configuration files (`.github/workflows/main.yml` and `.gitlab-ci.yml`), with no functional changes to Git itself.

The main discussion now centers on a follow-up idea raised by Patrick: auditing and pruning obsolete Coccinelle semantic patches (`.cocci` files) to further speed up Coccinelle runs. Junio has proposed a process improvement—adding clear exit criteria to each rule when introduced—to make future audits easier, suggesting some rules might already be misclassified in the documentation. No objections or merge status updates have been raised, and the series remains under review. Elijah Newren, the original author of the bloom filter code, has not yet responded.
