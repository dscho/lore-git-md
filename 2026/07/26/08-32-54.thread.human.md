This thread is about a small but practical CI improvement: bumping the Ubuntu image used in Git’s static-analysis CI jobs from `ubuntu-22.04` to `ubuntu-latest` (currently `ubuntu-24.04`). The change lets Git’s CI use a newer Coccinelle version (1.3.0+), which eliminates a known performance issue that had previously required an in-code workaround. Jeff King (Peff) sent the two-patch series, which also includes a preparatory cleanup in `bloom.c` to silence a Coccinelle false positive triggered by an assertion macro under GCC 15 with `-O2`.

The series is under review and looks ready to move forward. Junio C Hamano, the maintainer, has already weighed in with a positive response, calling the patches “interesting” and thanking Peff for the thorough background work. No objections or requests for changes have been raised, and Elijah Newren—who originally wrote the bloom filter code—hasn’t responded yet but was cc’d on the cleanup. The patches touch only the CI configuration files and `bloom.c`, with no functional changes to Git itself, so the risk is low. Unless unexpected feedback surfaces, this should land in Junio’s integration branches soon.
