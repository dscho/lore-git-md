This is the first patch in a two-part refactoring series from Jeff King (Peff) that tidies up the diff plumbing code following his recently accepted bugfix for the `git diff --relative --cached` segfault. The patch removes a stale comment in `diff-lib.c` that incorrectly claimed the callback must advance `o->pos` to skip index entries. That requirement was removed in 2010 by da165f470e, which moved the bookkeeping into `unpack_trees()`. The change is purely documentary and has no effect on behavior.

The patch is small (three lines removed) and directly addresses a historical inconsistency uncovered while investigating the original bug. Peff’s commit message is precise, citing the exact commit that made the comment obsolete. This is a textbook example of a well-motivated cleanup: the stale comment could mislead future readers, and removing it improves code clarity without risk. The patch is part of the same diff plumbing context as the earlier bugfix, so it is unlikely to introduce new issues.

Junio has not yet responded to this series, but his earlier review of the bugfix did not raise concerns about these cleanups. The patch is uncontroversial and should be a straightforward addition to the original fix, assuming Junio agrees the cleanup is worthwhile. Integration status remains under review.
