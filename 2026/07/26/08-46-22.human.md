This is the first patch in a two-part refactoring series from Jeff King (Peff) that tidies up the diff plumbing code following his recently accepted bugfix for a `git diff --relative --cached` segfault. The patch removes a stale comment in `diff-lib.c` that incorrectly claimed the callback must advance `o->pos` to skip index entries. That requirement was removed in 2010 (da165f470e), but the comment lingered.

The change is purely documentary and touches only three lines. It’s a clean, well-motivated cleanup that aligns the comment with the actual code flow. No behavior changes, no new symbols, and no risk of regression. Junio has already accepted the original bugfix this builds on, so this patch is unlikely to be controversial. It’s currently under review alongside its companion patch.
