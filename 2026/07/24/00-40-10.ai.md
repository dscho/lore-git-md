This is the second patch in a three-patch series adding scp-style URL support to `git config --url`. The series aims to make `git config --url` consistent with other Git commands by accepting scp-style SSH URLs (e.g., `host:path`), which are already widely used elsewhere in Git.

This patch focuses on test coverage. It extends the existing `t1300-config.sh` test suite to verify that `git config --url` behaves identically to `git config --get-urlmatch` for the same inputs. The changes are purely additive: each test case that previously checked `--get-urlmatch` now has a corresponding `--url` variant. The patch touches only the test file (`t/t1300-config.sh`) and adds 14 lines, all of which mirror existing test logic.

The patch is straightforward and uncontroversial. It does not introduce new behavior or edge cases; it merely ensures that the upcoming `--url` feature (introduced in patch 3) is tested against the same scenarios as `--get-urlmatch`. The commit message is clear, and the changes are mechanical and well-scoped. No open questions or loose ends are apparent from the patch itself.

The series as a whole remains under review, with no feedback yet on this or the other patches. The next patch (3/3) will switch `git config --url` to use the shared `url_parse` function, which already handles scp-style URLs elsewhere in Git.
