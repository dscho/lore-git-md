This is the final patch in Patrick Steinhardt’s five-part series making on-disk object database (ODB) structures pluggable. It introduces a new `create_on_disk` callback in the ODB source interface, allowing each backend to define its own directory layout while keeping the top-level `objects/` directory mandatory for repository discovery. The patch moves the creation of backend-specific directories (`objects/pack`, `objects/info`) from the generic `create_object_database()` function into the "files" backend’s implementation, making the codebase ready for future backends with custom layouts.

The change touches three files: `odb/source-files.c` (adds the callback), `odb/source.h` (declares the new interface), and `setup.c` (replaces hardcoded directory creation with a call to the backend’s callback). The patch is mechanical and well-scoped, completing the series’ goal of decoupling ODB setup from repository initialization. No user-visible behavior changes are introduced, but this is a foundational step for the ongoing ODB abstraction effort. The implementation looks clean, with clear commit messages and no obvious gaps in the callback’s error handling.
