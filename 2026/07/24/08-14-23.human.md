This is the first patch in Ted Nyman’s v4 series fixing race conditions in Git’s HTTP transport. It is a **documentation and error-message cleanup** that corrects the spelling of the `--index-pack-arg` option (singular) in both the `git-http-fetch` man page and the error messages in `http-fetch.c`.

The patch is purely textual: it updates the documentation to describe the repeatable per-argument form (`--index-pack-arg=<arg>` can be given multiple times) and fixes the error messages that previously referred to the non-existent plural `--index-pack-args`. No code behavior changes; this is a follow-up to Junio C Hamano’s review feedback on the v2 series.

The change is small and uncontroversial, touching only two files (`Documentation/git-http-fetch.adoc` and `http-fetch.c`). It prepares the ground for the subsequent patches by ensuring the documentation and error messages match the actual command-line interface. The patch is ready for review and should be a straightforward merge.
