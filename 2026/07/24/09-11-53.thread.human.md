This thread is about a small but impactful build-system fix from Teemu Nyman. The patch addresses a Coccinelle static-analysis performance issue that was causing the `separate_loop_index` rule to time out on the `seen` integration branch. The problem was a single loop index variable reused across two loops in `builtin/branch.c`, which Coccinelle 1.1.1 struggled to analyze efficiently. The fix is straightforward: declare each loop index in its own `for` loop instead of sharing one at function scope.

The change is minimal—just three lines in `builtin/branch.c`—and preserves the function's behavior while dramatically improving performance. The author reports the Coccinelle check now completes in 0.06 seconds (down from a six-hour timeout), and the full `coccicheck` run finishes in 47 seconds. All 190 tests in `t3200-branch.sh` pass. The patch is based on `hn/branch-delete-merged` and appears to be a well-scoped, low-risk fix for a real CI bottleneck. No review feedback has been posted yet, so the patch is still under initial consideration.
