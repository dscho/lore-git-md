This is the first patch in Ted Nyman’s v4 series fixing packfile URI download race conditions in Git’s HTTP transport. It is a **documentation and error-message cleanup** with no behavioral changes.

The patch corrects the `--index-pack-arg` option name in both the `git-http-fetch` man page and the error messages in `http-fetch.c`. The current documentation and code incorrectly refer to the plural `--index-pack-args`, but the implementation actually accepts one `--index-pack-arg=<arg>` per argument passed to `index-pack`. The man page now describes the repeatable per-argument form, and the error messages use the singular form to match the code.

This change was split out from the main series at Junio C Hamano’s request during the v2 review. It is uncontroversial and purely textual, touching only `Documentation/git-http-fetch.adoc` and `http-fetch.c`. The patch is ready for merging and serves as a clean baseline for the two subsequent bugfix patches.
