This is the sixth patch in Harald Nordgren’s **final, unblocked v21 series** introducing `git branch --delete-merged`. The patch adds a **per-branch opt-out mechanism** via the `branch.<name>.deleteMerged=false` config key, allowing users to exempt specific branches from automated cleanup while still permitting explicit deletion via `git branch -d`.

The implementation is **minimal and targeted**: it checks the config key during candidate filtering in `delete_merged_branches()`, skips opted-out branches with a non-quiet message, and ignores the setting for traditional `git branch -d` (which continues to use the normal merge check). The patch updates `Documentation/config/branch.adoc` and `Documentation/git-branch.adoc` to document the new key and adds two new tests in `t/t3200-branch.sh`:
1. Verifies the opt-out prevents deletion via `--delete-merged` and produces the expected skip message.
2. Confirms `git branch -d` ignores the opt-out and deletes the branch normally.

**Key technical details**:
- The config check uses `repo_config_get_bool()` and is performed after the `--forked` filter and merge check but before stacked-branch protection.
- The skip message is only printed if `--quiet` is not set.
- The `check_branches` helper (introduced in an earlier patch) verifies branch state via `git for-each-ref`, ensuring the tests are robust against ref iteration order.
