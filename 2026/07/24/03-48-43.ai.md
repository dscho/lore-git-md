This is the fourth patch in Patrick Steinhardt’s five-patch series making Git’s on-disk object database (ODB) structures pluggable. The patch introduces a helper function, `odb_source_type_to_name()`, that maps ODB source types (e.g., `ODB_SOURCE_LOOSE`, `ODB_SOURCE_PACKED`) to human-readable strings like `"loose"` or `"packed"`. These strings are then used in the existing downcasting macros to improve error messages when a type mismatch occurs.

The change is small and mechanical: it adds a lookup table in `odb/source.c`, declares the new function in `odb/source.h`, and updates the four downcasting macros in `odb/source-*.h` to use the new function. The patch touches no other subsystems and has no user-visible behavior change; it is purely a developer-facing improvement to error reporting. The commit message is concise and the rationale is clear: better error messages make debugging easier when a downcast fails.

This patch is a typical refactoring step in a larger infrastructure series. It prepares the ground for the final patch (5/5), which will use the new mapping function to implement pluggable directory creation. The series as a whole is part of the ongoing ODB abstraction effort, and this patch is a straightforward, uncontroversial piece of that work.
