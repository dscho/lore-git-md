This is the second round of review in Phillip Wood’s two-patch bugfix series for `rebase -i` edge cases. Junio C Hamano reviews the first patch, which fixes an incorrect commit count in the template message when fixup/squash commands are skipped.

He suggests adding a check for `p[1] != '\0'` to avoid miscounting trailing newlines in legacy files. Phillip’s original patch also removes trailing newlines when writing the command list, but Junio’s observation ensures the reading logic remains robust against older Git versions that might leave orphaned newlines.
