This is a feature patch series introducing scp-style URL support to `git config --url`.

The series adds a small but useful scripting convenience: `git config --url` can now parse scp-style SSH URLs (e.g., `host:path`) in addition to the existing explicit schemes (`ssh://`, `ftp://`, etc.). The motivation is consistency—nearly every other Git command already accepts scp-style URLs, but `git config --url` was a holdout. The use case is scripting tools that want to extract or manipulate remote URLs stored in Git configuration, especially when those URLs come from user-facing "clone" buttons on hosting services that default to scp-style syntax.

The series is three patches long. The first patch normalizes default ports for SSH and FTP in the URL-matching code, ensuring that `host:22` and `host` are treated identically. The second adds missing test coverage for `git config --url` (mirroring existing tests for `--get-urlmatch`). The third patch switches `git config --url` to use the shared `url_parse` function, which already handles scp-style URLs elsewhere in Git. The changes are confined to `builtin/config.c`, `urlmatch.c`, and the test suite; no new dependencies or subsystems are introduced.

The commit messages are clear and the code looks straightforward. The author explicitly notes that this is a narrow change—it does not attempt to extend `fmt_ident` or add automatic identity switching based on remotes, which would be a much larger effort. The series appears well-scoped and uncontroversial.
