This is the second patch in Harald Nordgren’s seven-part `git branch --delete-merged` series, which is now unblocked and ready for merging. The patch refactors `delete_branches()` and `check_branch_commit()` to replace separate boolean `force` and `quiet` parameters with a single `unsigned int flags` argument and an enum (`DELETE_BRANCH_FORCE`, `DELETE_BRANCH_QUIET`). The change is purely mechanical—there is no behavior change—and is motivated by the need to add more flags in later patches (e.g., `DELETE_BRANCH_SKIP_UNMERGED`, `DELETE_BRANCH_NO_HEAD_FALLBACK`).

The implementation directly tests the flags at each use site, eliminating any risk of stale cached values. This resolves a maintenance issue identified in earlier reviews: the previous version cached the `force` and `quiet` parameters in local variables, creating two sources of truth. The new version ensures the flags remain the single source of truth throughout the function. The patch touches only `builtin/branch.c` and is well-tested, with no regressions expected.

This is a low-risk refactoring that paves the way for the rest of the series. The flags-based API will be used in patches 3–7 to implement the `--delete-merged` subcommand, per-branch opt-out, and `--dry-run` functionality. The series as a whole is well-crafted, thoroughly tested, and addresses a real workflow pain point with careful attention to safety and edge cases.
