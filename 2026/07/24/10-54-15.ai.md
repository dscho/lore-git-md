This is a refactoring patch in the GSoC `git cat-file --batch-command` remote-object-info series, now at v21 and queued for `next`. The patch prepares for a later move of `write_fetch_command_and_capabilities()` from `fetch-pack.c` to `connect.c` by eliminating the static `advertise_sid` variable.

The change replaces the global `advertise_sid` flag with local reads via `repo_config_get_bool()` in both `find_common()` and `write_fetch_command_and_capabilities()`. The flag is initialized to 0 (matching its default) and the redundant server capability check in `do_fetch_pack()` is folded into the condition in `find_common()`, aligning the v0/v1 and v2 code paths. The patch is mechanical and does not alter behavior; it is a prerequisite for the function relocation in patch 5/13.

The commit message is clear and the rationale is sound: removing the static variable avoids introducing a new global when the function moves to a different file.
