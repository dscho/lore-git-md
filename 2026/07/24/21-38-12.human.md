This is the first patch in Ted Nyman’s v4 series fixing packfile URI download race conditions. It is a **documentation and error-message cleanup** with no behavioral changes, split out at Junio C Hamano’s request to serve as a clean baseline for the subsequent bugfix patches.

Taylor Blau reviews the patch and confirms the correction is accurate: the `--index-pack-arg` option has always been singular in the code, but the documentation and error messages incorrectly used the plural `--index-pack-args`. The patch updates the `git-http-fetch` man page to describe the repeatable per-argument form and fixes the error messages in `http-fetch.c` to match. Taylor notes that the original documentation’s claim about URL-encoded space-separated arguments was never true, so removing it is an improvement. He suggests a minor clarification in the man page to explicitly state that the first `--index-pack-arg` specifies the command to run, with subsequent instances specifying arguments, but does not insist on it.

The review is **surface-level**, focusing only on documentation wording and historical accuracy. No objections are raised, and the patch remains uncontroversial and ready for merging. The rest of the series (patches 2 and 3) addresses the core race-condition bugfixes and will build on this clean baseline.
