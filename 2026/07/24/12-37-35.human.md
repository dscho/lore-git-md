This is a bugfix patch for `git clone`. The author, Adrian Friedli, has updated the patch to include a regression test after Junio requested one. The test confirms that the segfault occurs specifically with Git protocol version 0 when a server (like Azure DevOps) advertises more refs than the client requested via `--revision`. The fix itself remains a simple NULL check in `update_remote_refs()` to prevent dereferencing a NULL `peer_ref`. With the test now included, this patch looks ready for merging—it addresses a real crash, has a clear reproduction case, and matches the maintainer’s earlier conceptual approval.
