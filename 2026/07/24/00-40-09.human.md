This is the first patch in a three-part feature series adding scp-style URL support to `git config --url`. The patch normalizes default ports for SSH (22) and FTP (21) in Git's URL-matching code, ensuring that URLs like `ssh://host:22/path` and `ssh://host/path` are treated identically. This is a preparatory step for the main change in patch 3, which will enable `git config --url` to parse scp-style SSH URLs (`host:path`).

The patch touches `urlmatch.c` and adds unit tests in `t/unit-tests/u-urlmatch-normalization.c`. The changes are mechanical and well-tested: the new unit tests mirror existing patterns for HTTP and HTTPS, and the logic in `urlmatch.c` follows the same structure as the existing port-normalization code. The commit message is concise but clear, and the code itself is straightforward.

This patch looks uncontroversial and well-crafted. It doesn’t introduce new behavior on its own but lays the groundwork for the scp-style URL support that follows.
