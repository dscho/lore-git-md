This is the final patch in Patrick Steinhardt’s five-part series making on-disk object database (ODB) structures pluggable. It introduces a new `create_on_disk` callback in the ODB source interface so that each backend can create its own directory layout (e.g., `objects/pack/` and `objects/info/` for the traditional “files” backend) while the top-level `objects/` directory remains the only mandatory, backend-agnostic requirement. The patch moves the hard-coded directory creation from `setup.c` into the files backend’s implementation, making the codebase ready for future backends that may use entirely different on-disk structures.
