This thread is about a small but useful quality-of-life improvement: adding scp-style SSH URL support (e.g., `host:path`) to `git config --url`. The change, proposed by Fabian Pottbäcker in a three-patch series, aligns the command with nearly every other Git command that already accepts this syntax, making it more convenient for scripts that extract or manipulate remote URLs from Git configuration.

The series is currently under review, with no prior versions or substantive feedback yet. The implementation touches `builtin/config.c` and `urlmatch.c`, extends existing tests, and switches to Git’s shared `url_parse` function. The on-disk format remains unchanged, and the change is narrowly scoped to avoid tangling with larger efforts like identity switching.

Ben Knoble’s review of the first patch spotted a minor but visible issue: the comments for FTP and SSH default-port normalization incorrectly copy the HTTP comment ("Skip http :21" and "Skip http :22" instead of "Skip ftp :21" and "Skip ssh :22"). While the code logic is correct, the misleading comments should be fixed before the patch lands. This is a classic nit—trivial to address but worth correcting for clarity. The rest of the series remains unaffected. No other feedback has been posted yet, so the discussion is still in its early stages.
