This thread is a small, three-patch series from Fabian Pottbäcker that adds scp-style SSH URL support (e.g., `host:path`) to `git config --url`, aligning it with nearly every other Git command that already accepts this syntax. The change is motivated by scripting convenience, particularly for tools that extract or manipulate remote URLs from Git configuration.

The series is currently under review as v1, with no prior versions. The implementation touches `builtin/config.c` and `urlmatch.c`, extends existing tests in `t/t1300-config.sh`, and adds new unit tests in `t/unit-tests/u-urlmatch-normalization.c`. The behavior change is straightforward: `git config --url` now parses scp-style SSH URLs in addition to explicit schemes like `ssh://` or `ftp://`. The on-disk format remains unchanged, and the series has no external dependencies.

The only feedback so far has been a surface-level nit from Ben Knoble, who pointed out a copy-paste error in the comments for FTP and SSH default-port normalization. The comments incorrectly read "Skip http :21" and "Skip http :22" instead of "Skip ftp :21" and "Skip ssh :22", though the code logic is correct. Fabian has acknowledged the issue and prepared a fix, which he plans to include in a v2 if no further feedback arrives. The rest of the series remains uncontested.
