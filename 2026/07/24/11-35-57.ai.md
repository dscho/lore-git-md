This is a surface-level review of the first patch in Fabian Pottbäcker’s three-patch series adding scp-style URL support to `git config --url`. Ben Knoble points out a minor but visible issue: the comments added for FTP and SSH default-port normalization incorrectly copy the HTTP comment ("Skip http :21" and "Skip http :22" instead of "Skip ftp :21" and "Skip ssh :22"). The code logic itself is correct, but the comments would mislead future readers. This is a classic nit: a trivial, non-functional flaw that should be fixed before the patch lands, but one that does not affect behavior or require deeper discussion. The rest of the series remains untouched by this observation.
