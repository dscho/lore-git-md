This is a refactoring patch in the large `git cat-file --batch-command` remote-object-info series, now at its 21st iteration and queued for `next`. This specific patch (4/13) prepares for a later move of `write_fetch_command_and_capabilities()` from `fetch-pack.c` to `connect.c` by eliminating the static `advertise_sid` variable.

The change is mechanical: the static variable, which was set in `fetch_pack_config()` and used in three places, is replaced with local reads via `repo_config_get_bool()` in each function. The patch also folds a redundant server-capability check into an existing condition in `find_common()`, aligning the v0/v1 and v2 code paths. The default value is initialized to 0, matching the original behavior.

This is a clean, low-risk refactoring that touches only `fetch-pack.c` and makes no functional changes. It’s a necessary step for the later relocation of the function and fits well with the series’ overall goal of enabling remote object metadata queries.
