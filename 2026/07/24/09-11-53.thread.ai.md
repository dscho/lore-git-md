Core problem or goal: resolve a pathological performance regression in Coccinelle 1.1.1 static analysis triggered by reusing a single loop index variable declared at function scope across two separate loops in `delete_merged_branches()`. The regression causes the static-analysis job on the `seen` integration branch to hit its six-hour timeout. Jeff King (Peff) has proposed an alternative: upgrade the CI job's Coccinelle version to 1.3.0+ (available in Ubuntu 25.10), which includes a fix (commit 58619b8fe) for the exponential slowdown.
