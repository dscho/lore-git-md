This is a surface-level review of the first patch in Fabian Pottbäcker’s three-patch series adding scp-style URL support to `git config --url`. Ben Knoble points out a minor but obvious copy-paste error in the code comments: the FTP and SSH port-stripping blocks are labeled “Skip http :21” and “Skip http :22” instead of referencing their actual protocols. The rest of the patch—logic, tests, and structure—is untouched; this is purely a documentation nit.

The series as a whole remains uncontroversial and well-scoped: it brings `git config --url` into line with the rest of Git’s URL-parsing behavior, a change motivated by scripting convenience. The error Ben flags is trivial to fix and does not affect functionality, so the patch is still on track for eventual merging.
