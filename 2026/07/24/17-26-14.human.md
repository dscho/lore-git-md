This is a review by Junio C Hamano of the first patch in Patrick Steinhardt’s five-part series making Git’s on-disk object database (ODB) structures pluggable. The patch fixes a latent bug in loose-object map loading: the function was ignoring the ODB source passed to it and always loading the map from the common `objects/` directory instead of the source-specific path. Junio’s review is brief but positive, agreeing that the change is logical and improves consistency by using the repository associated with the loose object source rather than the passed-in repository parameter.

The fix itself is small and mechanical, confined to `loose.c`. It removes the redundant repository parameter, retrieves the repository from the source’s ODB, and simplifies path construction. This is preparatory work for the rest of the series, which will remove hardcoded assumptions about directory layouts and defer ODB creation until after the backend is known. There are no user-visible behavior changes or test updates in this patch, and Junio does not raise any concerns or suggest further changes. The review is surface-level, focusing on the correctness of the approach rather than deeper technical implications.
