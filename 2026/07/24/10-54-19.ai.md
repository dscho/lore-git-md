This is a refactoring patch in the **GSoC v21 remote-object-info series**, now cooking in `next`. It mechanically moves variable initialization from the `FETCH_CHECK_LOCAL` state to the top of `do_fetch_pack_v2()`, so the same setup applies regardless of which state the state machine starts in.
