This thread is about Patrick Steinhardt’s five-patch series to make Git’s on-disk object database (ODB) structures pluggable, part of the larger ODB abstraction effort. The goal is to decouple backend-specific directory creation (like `objects/pack` or `objects/info`) from the generic repository setup code, allowing future ODB backends to define their own on-disk layouts without modifying core logic. The series also fixes latent bugs in loose-object map loading and removes hardcoded assumptions about initialization order.

The series is under active review, with Junio C Hamano providing feedback on the first three patches. The first two patches—addressing loose-object map loading and initialization order—received mixed feedback: the first was deemed correct with minor interface improvements, while the second drew substantive discussion about design robustness, particularly around unconditional downcasting and whether a more backend-agnostic approach (like adding a `load object map` method to the ODB source interface) would be preferable. The third patch, which defers ODB creation until after the ref database is set up, was reviewed by Junio in the latest email; he confirmed its logic and intent, seeing it as a necessary step toward pluggable backends. No merge status has been reported, and the series remains in the review phase.

Key technical changes include new functions like `loose_object_map_load()`, backend-specific directory creation helpers, and a `create_on_disk` callback in the ODB source interface. The series also introduces the `APPLY_REPOSITORY_FORMAT_SKIP_ODB_CREATION` flag to allow partial repository initialization and renames `create_object_directory()` to `create_object_database()`. While the changes are internal and don’t alter the on-disk format of existing repositories, they lay the groundwork for future ODB backends. Open questions include clarifying commit message wording and addressing Junio’s suggestion for a more robust design to avoid downcasting. So far, only Junio and Patrick have participated in the discussion, with Junio’s feedback shaping the series’ direction.
