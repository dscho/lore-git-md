This is a CI/build system patch targeting a Coccinelle static-analysis performance issue.

The patch fixes a pathological slowdown in Coccinelle 1.1.1 when running the `separate_loop_index` rule from `tools/coccinelle/strvec.cocci`. The problem occurs in `builtin/branch.c` in the `delete_merged_branches()` function, where a single loop index declared at function scope is reused across two separate loops. Coccinelle spends hours attempting to match this pattern, causing the static-analysis job on the `seen` integration branch to hit its six-hour timeout.

The fix is mechanical: declare each loop index in its respective `for` loop instead of sharing one declared at function scope. This change avoids triggering the expensive Coccinelle rule while preserving the function's behavior. The author reports that the fix reduces the Coccinelle check from a timeout to 0.06 seconds, and the full `coccicheck` run completes in 47 seconds. All 190 tests in `t3200-branch.sh` pass with the change.

The patch applies on top of `hn/branch-delete-merged` and touches only `builtin/branch.c`, changing three lines. The commit message clearly explains the problem, the solution, and the performance impact, and includes test results. This looks like a well-motivated, narrowly scoped fix for a real CI pain point.
