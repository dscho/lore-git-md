This is a refactoring patch in the long-running `git cat-file --batch-command` remote-object-info series, now at v21 and queued for `next`. The patch generalizes `write_fetch_command_and_capabilities()` into `write_command_and_capabilities()` so it can be reused for commands beyond `fetch`, such as the new `object-info` protocol operation.

The change is mechanical: the function is renamed, its signature gains a `const char *command` parameter, and the hardcoded `"fetch"` string is replaced with the passed-in command. The patch updates the two call sites in `fetch-pack.c` to pass `"fetch"` explicitly, preserving existing behavior. Documentation in `connect.h` is expanded to clarify the function’s purpose.

This refactoring is a prerequisite for later patches in the series that introduce the `object-info` command, and it aligns with the series’ goal of minimizing code duplication in the protocol layer. The patch itself is small (12 lines added, 8 removed) and does not alter functionality. It has been reviewed in prior iterations and is now part of the series’ final polish before graduation to `master`.
