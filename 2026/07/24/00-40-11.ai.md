This is the third and final patch in a small feature series that adds scp-style URL support (e.g., `host:path`) to `git config --url`. The series goal is to bring this command into consistency with nearly every other Git command that already accepts this syntax, motivated by scripting convenience for tools that extract or manipulate remote URLs from Git configuration.

This patch switches the URL-parsing logic in `git config --url` from `url_normalize` to the shared `url_parse` function, which already handles scp-style URLs elsewhere in Git. The change is minimal: one line in `builtin/config.c`, plus documentation and test updates. The documentation now clarifies that `--url` supports all URL formats (including scp-style), unlike the config-file URL syntax used in `http.<url>.*` options. The tests verify that both `--get-urlmatch` and `--url` now accept scp-style URLs, including edge cases like missing paths or non-matching schemes.

The patch is straightforward and well-scoped. It does not introduce new dependencies or subsystems, and the test coverage mirrors existing patterns for `--get-urlmatch`. The commit message and code changes are clear, and the series as a whole appears uncontroversial. This is the mechanical capstone of the series, following the normalization and test-coverage patches.
