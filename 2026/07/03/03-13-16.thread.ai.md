Core problem or goal
Add `includeIf.worktree:<pattern>` and `includeIf.worktree/i:<pattern>` conditions to Git’s config system, allowing conditional config inclusion based on the working tree’s realpath. This closes a usability gap in multi-worktree setups where `gitdir`-based patterns are awkward because they require knowledge of Git’s internal `.git/worktrees/` directory structure.

Current status
Series is at v6 and effectively ready for merging. All prior feedback from Junio C Hamano, Patrick Steinhardt, and Phillip Wood has been addressed. The preparatory refactoring in patch 1/6 (generalizing `include_by_gitdir()` to `include_by_path()`) and the core implementation in patch 2/6 (adding the new condition keywords, documentation, and tests) are uncontroversial. Junio’s latest reply endorses the current documentation structure and test patterns, suggesting only a minor follow-up for documentation consolidation rather than blocking the series. The updated glob pattern (`**`) for cross-platform compatibility is now considered final.
