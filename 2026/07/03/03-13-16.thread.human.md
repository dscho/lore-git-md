These new conditions allow users to include configuration files conditionally based on the working tree’s realpath, addressing a long-standing usability gap in multi-worktree setups where `gitdir`-based patterns were cumbersome.

The series has evolved through six iterations, incorporating feedback from Junio C Hamano, Patrick Steinhardt, and Phillip Wood. The first patch refactors `include_by_gitdir()` into a generic `include_by_path()` helper, while the second implements the core functionality with comprehensive tests.
