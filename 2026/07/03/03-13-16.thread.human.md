This thread introduces a new Git configuration feature: `includeIf.worktree:<pattern>` and its case-insensitive variant, allowing conditional config inclusion based on the working tree's realpath. The series, now at version 6, is authored by Toon Claes and aims to improve usability in multi-worktree setups where existing `gitdir`-based patterns are cumbersome.

The current v6 iteration addresses all prior feedback from Junio C Hamano, Patrick Steinhardt, and Phillip Wood, incorporating Windows CI fixes, improved documentation, and expanded test coverage. The series touches `config.c`, updates documentation, and adds tests, with no on-disk format changes. The preparatory patch in this email refactors the existing `include_by_gitdir()` function into a more generic `include_by_path()` helper, setting the stage for the new worktree condition without altering current behavior.

All substantive reviews from the previous version have been addressed, and there are no open objections or unresolved questions. The series appears ready for integration, with the refactoring in this patch being a straightforward and uncontroversial step toward the final implementation.
