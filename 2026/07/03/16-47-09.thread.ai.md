Core problem or goal
Extend `git repo info` to support category-based prefix queries (e.g., `git repo info layout` returns all keys under the `layout.*` namespace). The change addresses usability friction as the number of supported metadata keys grows, eliminating the need for external filtering (e.g., `grep`) of `--all` output.
