This is a **platform compatibility** follow-up in the ongoing **Rustification build system** thread. D. Ben Knoble responds to Patrick Steinhardt’s question about whether `lipo` (the macOS tool for creating Universal Binaries) can be safely assumed to be available on macOS systems.

Knoble’s research indicates that `lipo` has been part of Xcode since at least 2005 (Xcode 2.1), when Apple introduced Universal Binaries for the PowerPC-to-Intel transition. For the modern Universal Binary 2 format (supporting Apple Silicon), Xcode 12 (released in 2020) is likely the minimum required version, though Apple’s official documentation does not specify a precise version. The tool is included in the Xcode Command Line Tools, which are a standard part of macOS development environments.

The response does not address whether `lipo` is *always* present (e.g., on minimal macOS installations without Xcode), but it establishes that the tool has been stable and widely available for over two decades. This suggests that requiring `lipo` for Rust Universal Binary support is a reasonable assumption for Git’s build system, at least for developers targeting macOS. No further action or patch changes are proposed in this email—it is purely informational, providing context for Patrick’s earlier concern.
