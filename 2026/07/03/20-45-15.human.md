This is a brief, uncontroversial maintainer endorsement in the memory-leak cleanup thread. Junio C Hamano agrees with Patrick Steinhardt and Jeff King that Git’s CI matrix is unnecessarily large: while compiling with both clang and gcc is useful for catching different warnings, running the full test suite with both compilers rarely uncovers behavioral differences. He supports reducing the matrix by dropping redundant compiler-specific test jobs, freeing up CI cycles for more meaningful coverage (e.g., the proposed `linux-TEST-vars-leaks` job). The discussion remains procedural and aligns with the earlier consensus to consolidate jobs and rename `linux-TEST-vars` to `linux-exotic-flags`. No technical objections or new proposals are introduced; the original patch series (fixing `format-patch` and test harness leaks) is unaffected and still ready for merging.
