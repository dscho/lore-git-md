This is the test coverage patch (3/3) for Souma's series teaching `git history` to sign rewritten commits. It adds GPG-gated regression tests in `t3451-history-reword.sh`, `t3452-history-split.sh`, and `t3453-history-fixup.sh` to verify that the `reword`, `split`, and `fixup` subcommands respect the `commit.gpgsign` configuration and the `-S/--gpg-sign`/`--no-gpg-sign` command-line flags.

The tests follow a consistent pattern: each defines a helper function (`test_reword_gpg_sign`, `test_split_gpg_sign`, `test_fixup_gpg_sign`) that accepts a configuration value (`true`/`false`) and optional command-line flags, then runs the subcommand and checks whether the rewritten commit and its replayed descendants are signed. The helper functions use `test_must_fail` when the expected outcome is *not* to sign, and the test cases cover all combinations of config-driven signing, command-line overrides, and flag precedence (e.g., `--no-gpg-sign` overriding `commit.gpgsign=true`). The tests are marked with the `GPG` prerequisite, so they run only when GPG is available.

The patch is mechanical and thorough: it exercises every subcommand, every configuration path, and every flag combination, and it verifies both the rewritten commit and its replayed descendants. No edge cases or loose ends are left uncovered.
