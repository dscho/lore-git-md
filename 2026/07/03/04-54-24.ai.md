This is the fifth patch in a **test infrastructure improvement** series (6/6 in v3) that mechanically converts bare `grep` assertions in Git's test suite to `test_grep`. The series is now ready for merging after addressing all prior feedback, including audits of `# lint-ok` exemptions and fixes for pre-existing test bugs.

This patch performs the bulk conversion across ~340 test files, replacing ~2800 `grep` assertions with `test_grep`. The conversion is driven by `greplint.pl` (introduced in the next patch) but includes manual adjustments for edge cases where bare `grep` was intentionally tolerating missing files—something `test_grep` explicitly rejects with a `BUG`. Key adjustments in this patch:
- **`t1400-update-ref.sh`**: Guards `.git/packed-refs` checks with a `REFFILES` prerequisite to avoid `BUG` under the reftable backend.
- **`t7450-bad-git-dotfiles.sh`**: Retains bare `grep` for `git~2` (NTFS 8.3 short name) with an explanatory comment, as the file’s presence is platform-dependent.

The patch also reorders pre-existing `! test_grep` calls to `test_grep !` to preserve diagnostic output on failure. The conversion skips `grep` used as data filters (e.g., `grep -vf` or with redirects), which are annotated with `# lint-ok` and left for future work. The commit message includes a reproducible script for regenerating the changes, ensuring transparency and maintainability.

**Files touched**: Primarily test scripts (`t/*.sh`, `lib-*.sh`), with no changes to core Git functionality. The patch is purely mechanical except for the two edge-case adjustments noted above. **Key symbols**: `test_grep` (replaces `grep` in assertions). **Test coverage**: Validates the conversion does not break existing tests, with safeguards like `test_grep`'s file-existence checks.

This patch is a critical step in the series, enabling the linter to enforce consistency while avoiding false positives. The shared shell parser infrastructure (introduced in an earlier patch) ensures the conversion is robust. No open technical concerns remain; the series is poised for graduation to `next`.
