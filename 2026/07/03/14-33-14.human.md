This is a follow-up to a feature request about programmatic commit editing during interactive rebase. The thread has already been resolved by pointing to the existing `GIT_SEQUENCE_EDITOR` mechanism, but this email adds a small but useful clarification.

Matt Hunter thanks Brian m. carlson for the `GIT_SEQUENCE_EDITOR` tip and notes that `--autosquash` no longer requires `--interactive` mode. He cites commit `f8f87e082798` ("Merge branch 'ak/rebase-autosquash'") as the change that made this possible. This means Brian’s alias example (`srebase`) could now be simplified to `GIT_SEQUENCE_EDITOR=true git rebase --autosquash` without the `-i` flag, though the original example still works.

The observation is minor but practical: it updates the thread’s shared knowledge about Git’s current behavior and removes a now-unnecessary flag from the suggested workflow. No new questions or design points are raised; the thread remains closed.
