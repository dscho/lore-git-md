This is a **refactoring** patch that extracts Git’s test-suite shell parser into a shared module. It is the third installment in Michael Montalbo’s six-patch series introducing `greplint.pl`, a linter that converts bare `grep` assertions to `test_grep`.

The patch moves the 500-line `Lexer`, `ShellParser`, and `ScriptParser` classes from `t/chainlint.pl` into a new file `t/lib-shell-parser.pl`. `chainlint.pl` then loads the shared module via `do()` and defines a minimal `ChainlintParser` subclass that overrides `check_test()` to implement the existing &&-chain lint rule. The change is purely mechanical: `chainlint.pl` continues to produce identical output, and its self-tests still pass.

By factoring out the shell tokenizer and parser, the patch enables `greplint.pl` (added in a later patch) to reuse the same infrastructure for identifying command boundaries and here-documents. This avoids code duplication and ensures both linters interpret shell syntax consistently. The shared module also leaves the door open for future lint rules that need shell-aware parsing.
