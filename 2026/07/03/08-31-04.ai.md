This is a **bugfix clarification** targeting the `git rm` command's pathspec behavior.

Patrick Steinhardt replies to Евгений Плискин’s report to explain that the observed recursion is not a bug but documented behavior. The key detail is that `git rm` treats its arguments as *pathspecs*, not simple shell globs. The `*` wildcard in a pathspec matches directory separators by default, meaning `*.json` will match JSON files in any subdirectory. This behavior is explicitly described in `gitglossary(7)` under "pathspec," where it notes that `*` and `?` can match directory separators and that patterns like `Documentation/*.jpg` will recurse into subdirectories.
