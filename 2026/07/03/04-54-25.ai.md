This is the final patch in a **test infrastructure** series introducing `greplint.pl`, a linter that enforces the use of `test_grep` over bare `grep` assertions in Git’s test suite. The patch completes the series by adding the linter itself, its test fixtures, and integration into the build system.

The linter reuses the shared shell parser (`lib-shell-parser.pl`) from `chainlint.pl` to tokenize test bodies, avoiding false positives from `grep` used in heredocs, command substitutions, or quoted strings. It flags two anti-patterns:
1. Bare `grep` used as a test assertion (where `test_grep` should be used for better diagnostics).
2. `! test_grep` (where `test_grep !` is preferred, since `test_grep` only prints diagnostics on failure, and negation inverts that decision).

Key technical details:
- **Detection logic**: The linter tracks command position and pipeline state to distinguish assertion `grep` from filter `grep` (e.g., `grep | wc -l` or `x=$(grep ...)`). It skips `grep` in pipelines, redirects, or command substitutions.
- **Line number accuracy**: For double-quoted test bodies with backslash-continuation lines, it adjusts reported line numbers to match the source file, accounting for lines consumed by the lexer.
- **Suppression mechanism**: A `# lint-ok` comment on the source line exempts `grep` from linting (e.g., for platform-specific paths or files that may not exist).
- **Test coverage**: Fixtures under `t/greplint/` validate detection of bare `grep` in various contexts (after `&&`, `;`, in subshells, etc.), correct skipping of filters, and handling of `lint-ok` annotations.

The patch also wires `greplint.pl` into the Makefile with three new targets:
- `test-greplint`: Runs the linter on all test scripts (`$(T)`, `$(THELPERS)`, `$(TPERF)`).
- `check-greplint`: Validates the linter against its fixtures, diffing actual output against expected.
- `clean-greplint`: Removes temporary files.

The series is now technically complete, addressing all prior feedback. The linter’s shared parser infrastructure enables future lint rules, and its integration into the test suite ensures `test_grep` usage is enforced going forward. This patch is ready for merging as part of the broader effort to improve test reliability.
