This is a feature patch from a GSoC contributor, adding category-based prefix querying to `` `git repo info` ``. The command currently requires exact key names or dumps everything with `--all`; the patch lets users request all keys under a namespace (e.g., `` `git repo info layout` `` returns both `layout.bare` and `layout.shallow`). The implementation replaces the old `bsearch` with a linear scan that stops as soon as it leaves the matching prefix block, justified by the small size of the key array. Documentation and tests are included. The patch is clean, well-explained, and looks ready for review.
