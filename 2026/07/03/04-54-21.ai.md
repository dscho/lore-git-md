This is a **bugfix patch** in the `greplint.pl` series (2/6), targeting the test suite. It corrects three instances where `grep` assertions in the test scripts were missing file arguments, causing them to read from empty stdin instead of the intended files. The fixes are trivial (adding the missing filenames) but critical: without them, the assertions were effectively no-ops, silently passing even when the intended checks would have failed.

The affected tests are:
- `t2402-worktree-list.sh`: A `! grep` assertion meant to verify the absence of a prunable annotation was not reading from the `out` file, matching the preceding `grep` on the same file.
- `t7507-commit-verbose.sh`: A misplaced quote caused the entire `diff --git actual` string to be treated as a pattern, leaving no file argument. The fix splits it into pattern `diff --git` and file `actual`.
- `t7700-repack.sh`: A `! grep` assertion checking for an object ID in a packlist was missing the `packlist` file argument, mirroring the redirect on the preceding line.

All three tests now pass with the corrected arguments, confirming the fixes align with the intended behavior. The changes are minimal (one line each) and uncontroversial, addressing latent bugs that could have masked test failures. This patch is a prerequisite for the broader `greplint.pl` effort, as the linter’s `test_grep` helper explicitly rejects missing file arguments with a `BUG`, making these fixes necessary for the automated conversion to work.

The commit message is clear and specific, naming the files, quoting the problematic lines, and explaining the impact. No new edge cases or follow-up work are introduced here—this is purely a correctness fix. Expect this to merge alongside the rest of the series.
