This is a documentation patch from Junio C Hamano proposing to clarify the test suite requirements in `Documentation/SubmittingPatches`. The change emphasizes that contributors should run the full test suite (`make test`) from the top-level directory after any code change, not just individual test scripts.

The patch comes in response to Jeff King's observation that shell portability issues (like the unquoted parameter expansions discussed in the thread) would be caught by `make test` but might be missed when running single test scripts directly. Junio suggests adding this reminder explicitly in the documentation, noting that the importance of full test suite validation warrants repeating the point.

This is a small but meaningful documentation improvement that codifies a best practice already followed by experienced contributors.
