This is a website improvement suggestion from Johannes Schindelin, proposing to make kernel.org responsive (mobile-friendly) like GitGitGadget's site recently became. The email notes that the same contributor who updated GitGitGadget (Rito) has already created a prototype responsive version of kernel.org and is offering to help implement it.

The proposal is straightforward and well-motivated, with a working demo available for review. As this touches kernel.org rather than Git itself, it's primarily of interest to Konstantin Ryabitsev (Linux Foundation infrastructure) and others involved in maintaining kernel.org's web presence. The Git community might have opinions about consistency with Git-related pages hosted on kernel.org, but the actual implementation would be a kernel.org decision.
