This is patch 7/10 in Patrick Steinhardt's performance optimization series targeting write contention in `git-upload-pack`. The patch focuses on the sideband subsystem, converting its packet writing from two separate `write()` calls (one for header, one for data) to a single `writev()` call via the new infrastructure introduced earlier in the series.

The change reduces syscalls by roughly 50% (from ~133k to ~67k) when sending pktlines by batching the header and data writes together. The implementation uses the new `writev_or_die()` wrapper that handles platform-specific edge cases and maintains the existing error handling behavior. The patch preserves all existing functionality including band selection and packet framing while eliminating the syscall overhead.

This is a straightforward mechanical conversion that builds on the series' core `writev()` infrastructure (patches 1-6). Johannes Sixt has already validated the platform-specific behavior of the underlying `writev()` wrappers, and Junio has approved the overall approach. The patch demonstrates measurable performance gains with minimal risk, as it doesn't introduce new logic - just a more efficient way to execute the same operations.
