This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the current state of patches in the Git project's integration branches. The report covers patches that have graduated to 'master', new topics being proposed, ongoing work in 'next' and 'seen', and discarded topics.

Several notable patches have recently graduated to 'master':
- Aditya Ratiu's configurable hooks feature allowing hooks to be defined in Git config files
- brian m. carlson's SHA-1/SHA-256 interoperability work written in Rust
- Multiple send-email improvements including client certificate support and SASL handling
- Various documentation and test modernization patches

New topics being proposed include:
- Johannes Schindelin's work to auto-correct misspelled subcommand names
- Justin Tobler's fast-import improvements for resigning invalidated commits
- Patrick Steinhardt's build infrastructure changes moving tools to a "tools/" directory
- Multiple patches continuing the `the_repository` removal effort

Ongoing work includes:
- Improvements to the line-log feature's compatibility with diff options
- Linux support for the fsmonitor daemon
- Adrian Ratiu's parallel hooks execution work
- Taylor Blau's incremental repacking improvements using MIDX/bitmaps

The report also notes several patches that have been discarded, including Johannes Schindelin's original sideband sanitization work which has been superseded by Junio's rebooted version.

This status update shows active development across many areas of Git, with particular focus on configuration flexibility (hooks, send-email), performance (MIDX, fsmonitor), and modernization (tests, documentation). The Rust interoperability work and `the_repository` removal continue to be major ongoing efforts.
