This is a refactoring patch that extracts revert message formatting logic from `sequencer.c` into a new shared function, as part of the ongoing `git replay --revert` feature development. The patch moves the message generation code used by `git revert` into `sequencer_format_revert_message()`, making it reusable by the new `git replay` functionality.

The changes include:
1. Creating a new helper function that handles both regular reverts and revert-of-revert cases
2. Updating `refer_to_commit()` to take explicit parameters rather than relying on global state
3. Maintaining all existing behavior while making the code more modular

The patch has already gone through several rounds of review, with Phillip Wood providing detailed feedback that's been incorporated. It's part of a well-reviewed series that's nearing readiness for merging, with the technical implementation now complete. The refactoring follows established patterns in the codebase and helps pave the way for the new `git replay` revert functionality.
