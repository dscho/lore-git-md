This is the second patch in Phillip Wood's 3-part series continuing the `the_repository` removal effort, specifically targeting the worktree subsystem. The patch simplifies warning output in `git worktree add` when encountering an invalid HEAD reference.

The change removes code that was reading and displaying the contents of ".git/HEAD" when warning about invalid references, since this approach doesn't work with the reftable backend (where HEAD isn't stored as a file) and provides questionable value even with the files backend. The warning message is now more concise, just stating that HEAD points to an invalid reference.

The patch also modernizes the related test in t2400-worktree-add.sh by replacing direct `grep` calls with `test_grep` for better test output, and updates the test expectations to match the simplified warning message. The changes appear behavior-preserving while making the code more backend-agnostic.

This continues the series' pattern of removing implicit assumptions about repository storage while tightening interfaces. The commit message clearly explains the motivation and the change fits well with the broader `the_repository` removal effort.
