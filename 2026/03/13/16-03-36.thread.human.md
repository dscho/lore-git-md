Kristoffer Haugsbakk has completed work on a new `git format-rev` command that provides flexible formatting of Git revisions from standard input. After five iterations of the patch series, the command is now feature-complete with thorough test coverage and documentation.

The command offers two main modes: one that processes revision hashes line-by-line, and another that scans freeform text for commit references. Key features include robust stream handling with NUL-termination support, safe interactive operation, and the ability to display notes. The implementation builds on refactored infrastructure from `git name-rev` while adding new formatting capabilities.

The series received substantive technical review from Phillip Wood, who provided feedback on stream safety and NUL-handling, and style-related suggestions from René Scharfe. The documentation has been carefully refined through multiple versions, with the final iteration improving clarity around NUL-handling behavior and simplifying examples.

This fills a gap in Git's tooling by providing better stdin-processing capabilities than existing commands like `git log` or `git show`, particularly for scenarios involving mixed input or order preservation.
