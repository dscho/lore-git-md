Kristoffer Haugsbakk's patch series to add `--format` support to `git name-rev` is nearing completion, with the implementation already addressing technical concerns around memory management, test coverage, and edge case handling. The feature is modeled after `git log --format` and includes support for notes display via a new `%N` format specifier.

D. Ben Knoble spotted a minor documentation gap in the v2 iteration - while the code properly handles `--notes` with `%N`, this interaction wasn't mentioned in the man page updates. Haugsbakk promptly acknowledged this as an unintentional oversight and indicated plans to include the documentation in a future version. The exchange shows the typical Git review process at work, where even well-implemented features receive careful scrutiny for completeness before merging.

With the technical implementation already solid and only this documentation polish remaining, the series appears ready for final review and potential merging once the man page updates are included. The changes maintain backward compatibility while adding useful formatting capabilities, particularly for processing commits that can't be easily handled through `git log` or `git show`.
