This thread began as a cross-project coordination effort to improve kernel.org's mobile responsiveness, led by Johannes Schindelin and contributor Rito Rhymes. Rito, who previously implemented mobile-friendly designs for GitGitGadget and gitweb, has submitted a 6-patch series addressing various aspects of kernel.org's responsive design. The discussion moved to the Git mailing list due to kernel.org lacking its own public mailing list, despite being fundamentally a kernel.org infrastructure change.

The technical work has progressed well, with Patch 1 already merged to fix mobile text sizing via viewport meta tags. The remaining patches systematically address CSS issues, horizontal overflow problems, and table handling - each narrowly scoped to improve mobile usability while preserving desktop layouts. No technical objections have been raised against the patches themselves.

Junio Hamano has now weighed in on the communication aspect, taking a neutral stance about hosting this discussion on the Git list. While personally not objecting, he notes it may seem off-topic for some Git developers and emphasizes that the final decision about appropriate discussion venues rests with kernel.org's Konstantin Ryabitsev. The thread remains active as we await kernel.org's review and potential merge of the complete patch set, with the Git list continuing to be CC'd for continuity.
