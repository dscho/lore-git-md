This thread began as a cross-project effort to improve kernel.org's mobile responsiveness, led by Johannes Schindelin and contributor Rito Rhymes. Rito previously implemented similar improvements for GitGitGadget and gitweb, and has now submitted a 6-patch series for kernel.org. The patches address various mobile display issues through viewport adjustments, CSS breakpoints, and scrollable content areas - with Patch 1 already merged.

The discussion transitioned from technical coordination to a brief debate about appropriate venues, as kernel.org lacks its own public mailing list. Junio Hamano noted the topic might seem off-topic for Git developers while acknowledging the practical need for coordination, ultimately deferring to kernel.org maintainer Konstantin Ryabitsev. In the latest email, Rito Rhymes has acknowledged these concerns and signaled willingness to move the discussion elsewhere if needed, while maintaining the cooperative spirit of the effort. The technical work stands complete, awaiting kernel.org's decision on both the patches and future coordination channels.
