This thread coordinates cross-project efforts to improve mobile usability across Git and kernel.org infrastructure. It began with Johannes Schindelin introducing Rito Rhymes, who successfully implemented responsive designs for GitGitGadget and gitweb (now merged into Git). The discussion has now shifted to kernel.org, where Rito has submitted a 6-patch series to make the site mobile-friendly, starting with this foundational viewport meta tag patch.

The current patch cleanly addresses the most basic mobile rendering issue by setting proper viewport dimensions, enabling subsequent CSS adjustments to work correctly. This follows Rito's proven approach of incremental improvements, already validated through prior Git-related work. While fundamentally a kernel.org change, the Git community remains engaged given kernel.org's role hosting Git mailing list archives. The series awaits kernel.org's review, with no technical objections raised yet. A follow-up patch for mobile navigation remains pending initial acceptance of this core series.
