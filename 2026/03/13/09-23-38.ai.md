This is version 3 of a feature patch series that adds conditional stashing support to `git checkout` and `git switch`, now implementing flag unification as suggested by the maintainer. The patch reworks the `-m` flag to use autostash behavior rather than doing a three-way merge, while maintaining backward compatibility.

The key changes in this version:
- Replaces the three-way merge implementation in `checkout -m` with autostash-based conflict resolution
- Adds a new `checkout_would_clobber_changes()` helper that performs dry-run merge conflict detection
- Updates documentation to reflect the new autostash behavior for `-m`
- Expands test coverage to verify the unified behavior (18 test cases in t7201-co.sh)
- Preserves backward compatibility while changing the underlying mechanism
- Handles conflict style configuration properly during stash application

The implementation builds on existing autostash infrastructure from the sequencer, now used for both explicit `--autostash` and the unified `-m` behavior. The patch touches multiple components including checkout logic, documentation, and test infrastructure, with particularly thorough test coverage of the new unified behavior.

This version addresses Junio C Hamano's feedback by unifying the `-m` and `--autostash` concepts while maintaining the expected user experience. The author has experimentally implemented the unification approach and seeks validation on the conceptual direction before finalizing.
