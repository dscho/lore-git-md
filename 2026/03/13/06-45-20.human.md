This is the ninth patch in Patrick Steinhardt's v4 series optimizing write operations in Git's networking stack. The patch removes the `hashfd_throughput()` function from the csum-file interface, replacing its single use in `pack-objects.c` with a direct call to the more flexible `hashfd_ext()` function.

The change is straightforward: instead of having a dedicated function for progress-metered hashfile creation, the patch inlines the configuration (8KB buffer size and progress reporting) at the call site. This makes the behavior more explicit while eliminating a function that was only used in one place. The modification maintains the same progress reporting behavior that was present before.

This is a clean-up patch that follows naturally from the earlier introduction of `hashfd_ext()` in the series. It doesn't change any functionality but simplifies the API surface by removing a now-redundant helper function. The patch is well-contained and clearly explained in the commit message.
