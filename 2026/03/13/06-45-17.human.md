This is patch 6/10 in Patrick Steinhardt's performance optimization series, which has already been approved for merging in its v4 state. The series reduces write syscalls in high-concurrency scenarios by implementing `writev()`-based buffering across multiple Git subsystems.

This particular patch introduces generic wrapper functions for the `writev()` system call, similar to Git's existing `write_in_full()` and `write_or_die()` helpers. The new `writev_in_full()` handles partial writes and error conditions while maintaining the existing behavior patterns of Git's I/O wrappers, and `writev_or_die()` provides the fatal-error variant that dies on failure.

The implementation carefully handles edge cases like partial writes across iovec boundaries and maintains consistency with Git's existing error handling patterns. Johannes Sixt has already validated the platform-specific behavior, including the zero-byte write case. This infrastructure underpins the performance improvements in the rest of the series while providing a consistent interface for future use.
