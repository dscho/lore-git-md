Test modernization patch finalizing shell portability requirements for partial clone test helper.

Junio Hamano identifies one remaining shell portability issue in Siddharth Shrimali's v2 patch for the `delete_object` helper in `t0410-partial-clone.sh`. While the patch already incorporated all previous feedback (hash independence via `test_oid_to_path`, proper variable scoping with `local`, and removal of redundant checks), it missed quoting the right-hand side of `local` assignments to ensure compatibility with all shell implementations, particularly older versions of `dash`.

The suggested fix is straightforward - adding quotes around `$1` and `$2` in the `local` declarations. This matches Git's test-lint requirements and follows established patterns in the test suite. Junio notes this would have been caught by running `make -C t test-lint`, which checks for such portability issues.
