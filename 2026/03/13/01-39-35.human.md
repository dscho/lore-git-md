This is a v6 patch series adding signature handling capabilities to `git fast-import`, specifically implementing a `sign-if-invalid` mode that allows re-signing commits with invalid signatures. The series builds on previous work that enabled stripping invalid signatures.

The key changes in v6:
- Fixed a test that was incorrectly using the `openpgp-signing` branch when it should reference `ssh-signing`
- Updated warning messages to clarify they're about "replacing" signatures rather than "signing"
- Added parentheses in a conditional statement for operator precedence clarity

The series maintains the limitation of not supporting interoperability mode signatures (with an explicit NEEDSWORK comment), as reconstructing the compatibility structure would require additional work. Justin Tobler is open to addressing this later if preferred.

The implementation appears solid with thorough test coverage for OpenPGP/X.509/SSH signatures. The series has evolved through multiple iterations with improvements based on feedback, particularly around API design and documentation clarity. With these final test fixes and wording improvements, the series looks ready for merging.
