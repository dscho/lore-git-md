This is a follow-up discussion about the internationalization (i18n) of error messages in the reference-transaction hook patch. Justin Tobler points out that the strings "preparing" and "prepared" in the error messages should potentially be marked for translation, similar to other hook-related messages in the codebase.

The original patch from Eric Ju (with contributions from Patrick Steinhardt and Justin Tobler) added a new "preparing" phase to Git's reference-transaction hook mechanism. While the core functionality has already been reviewed and approved by Junio Hamano, this follow-up email identifies a minor oversight in the implementation - the hook phase names in error messages weren't wrapped in translation markers (_()).

This is a small but important detail for consistency with Git's internationalization practices. The change would allow these error messages to be translated like other Git messages when localized versions are available. The patch appears otherwise ready for integration, with this being one of the final polish items before it moves through Git's standard workflow (seen -> next -> master).
