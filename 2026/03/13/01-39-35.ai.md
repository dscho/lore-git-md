This is a v6 patch series adding signature handling capabilities to `git fast-import`, specifically implementing a `sign-if-invalid` mode that allows re-signing commits with invalid signatures. The series builds on previous work that enabled stripping invalid signatures.

The key changes in v6:
- Fixed a test that incorrectly referenced the `openpgp-signing` branch when it should use `ssh-signing`
- Updated warning message wording to clarify signature replacement rather than creation
- Added parentheses in a conditional statement to clarify operation order

The series maintains the limitation of not supporting interoperability mode signatures (with explicit NEEDSWORK comment) and consists of three cleanly separated patches:
1. A cleanup removing an unused forward declaration
2. Refactoring of signing infrastructure to support default key fallback
3. The main implementation adding `sign-if-invalid` mode

Technical details:
- New `sign-if-invalid[=<keyid>]` mode matches `git commit --gpg-sign` syntax
- Uses enhanced `sign_buffer()` with flags parameter
- Comprehensive test coverage for OpenPGP/X.509/SSH signatures
