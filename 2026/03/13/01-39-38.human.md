This is the final patch in a v6 series adding signature handling capabilities to `git fast-import`, specifically implementing a `sign-if-invalid` mode that allows re-signing commits with invalid signatures. The series builds on previous work that enabled stripping invalid signatures.

The patch introduces a new `sign-if-invalid[=<keyid>]` mode for `--signed-commits` that will verify commit signatures and replace invalid ones with newly created signatures using either a specified key or the default signing key. Valid signatures remain unchanged. The implementation shares infrastructure with the existing `strip-if-invalid` mode but adds the signing capability.

Key technical aspects:
- New `SIGN_SIGN_IF_INVALID` enum value and parsing logic that handles optional key IDs
- Consolidated warning infrastructure between sign/strip modes with updated messages
- Explicit failure for interoperability mode (with NEEDSWORK comment)
- Comprehensive test coverage for OpenPGP/X.509/SSH signatures
