This is a test fix for the `git fast-import` signature handling series. Justin Tobler responds to Jeff King's bug report about a Windows CI failure where a test incorrectly references GPG-signed data while only having the GPGSSH prereq. The issue is straightforward - the test should use the `ssh-signing` branch rather than `openpgp-signing` to match its prerequisites.

The fix is minor and comes late in the review cycle for this otherwise-approved series. It doesn't affect the core functionality, which has already been vetted through multiple iterations. The series implements a new `sign-if-invalid` mode for `git fast-import` that can re-sign commits with invalid signatures, building on earlier work to consolidate signing infrastructure.

This exchange shows the project's attention to test correctness even for edge cases, with prompt acknowledgment from the author. The fix will likely be included in a follow-up version before the series is merged.
