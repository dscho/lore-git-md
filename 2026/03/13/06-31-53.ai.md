This is a review ack for the final patch in a merged series enhancing `git fast-import`'s signature handling capabilities. Patrick Steinhardt approves the improved warning message wording in Justin Tobler's implementation of the `sign-if-invalid` mode, which completes the feature addition started in earlier versions of the series.

The patch being reviewed introduces clear, consistent warning messages when replacing invalid commit signatures during fast-import operations. The messages now properly distinguish between signature replacement (the new behavior) versus creation (which this mode does not handle). The implementation shares infrastructure with the existing `strip-if-invalid` mode while adding the new signing capability through a consolidated API.

Patrick's brief but positive feedback confirms the series has addressed all outstanding concerns, particularly around message clarity. This marks the successful conclusion of a multi-iteration effort to expand fast-import's signature handling, building on Christian Couder and Justin Tobler's earlier work. The merged implementation provides a foundation for potential future extensions like tag signature support or additional signing modes.
