This thread reports a missing feature in Git's bash completion for `git range-diff`. While completion scripts properly include diff-merges options (`--diff-merges`, `--no-diff-merges`, `--remerge-diff`) for `git log` and `git show`, these same completion options are curiously absent for `git range-diff`. The current `range-diff` completion only offers `--creation-factor`, `--no-dual-color`, and basic diff options.

The issue has existed since Git 2.53.0 when these diff-merges options were introduced. The patch doesn't propose a specific solution but clearly identifies this inconsistency in completion behavior between related commands. This would be a straightforward fix to align `range-diff`'s completion with that of `log` and `show`.
