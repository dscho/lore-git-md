This is a refactoring patch that consolidates signing logic in Git's GPG interface. It's part of a v6 series enhancing `git fast-import`'s signature handling capabilities, specifically implementing a `sign-if-invalid` mode.

The patch moves default key fallback logic from `sign_commit_to_strbuf()` in commit.c into the more general `sign_buffer()` function in gpg-interface.c, introducing a new `SIGN_BUFFER_USE_DEFAULT_KEY` flag. This change makes the signing infrastructure more reusable while maintaining the same behavior. The implementation is clean and straightforward, touching only the necessary call sites in builtin/tag.c, commit.c, and send-pack.c.

The change enables future work (like the fast-import signature handling in the next patch) to reuse this consolidated signing logic. The patch appears well-tested and has evolved through multiple iterations with maintainer feedback, including a style clarification for bitwise operations. It's a solid technical improvement that follows Git's incremental development model.
