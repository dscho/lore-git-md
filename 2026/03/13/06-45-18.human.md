Performance optimization in the sideband subsystem. This is patch 7/10 in Patrick Steinhardt's final v4 series addressing write contention in `git-upload-pack`, now approved for merging.

The patch refactors `send_sideband()` to use `writev()` for sending pktlines, combining what were previously two separate `write()` calls (one for the header, one for data) into a single syscall. This cuts the number of syscalls roughly in half (from ~133k to ~67k) when sending sideband data, reducing kernel contention under high concurrency. The change builds on the new `writev_or_die()` infrastructure introduced earlier in the series.

The implementation maintains all existing protocol semantics while being careful to handle both banded and non-banded packets correctly. Jeff King originally suggested this optimization, which has now been validated through testing and review. This is one of several coordinated changes across Git's I/O subsystems that together significantly improve performance in server environments.
