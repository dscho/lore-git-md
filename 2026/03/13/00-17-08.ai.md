This is a follow-up in the `git fast-import` signature handling series, addressing a test issue reported by Jeff King. The bug report identified that a test marked with GPGSSH prereq was incorrectly trying to export commits from the `openpgp-signing` branch (which requires GPG support) rather than the `ssh-signing` branch (which matches the GPGSSH prereq). Justin Tobler confirms this is a bug and will fix it in the next version of the patch series.

The issue is purely about test setup and doesn't affect the core functionality being developed - the series implements `sign-if-invalid` mode for commit signatures in `git fast-import`. The test fix will ensure proper execution on Windows CI systems where the test was failing due to referencing the wrong branch. This comes as a final polish before the already-approved series gets merged, showing the project's attention to cross-platform correctness even for edge cases.
