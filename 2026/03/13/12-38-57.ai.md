The discussion has already reached maintainer consensus that `gui.gcwarning=false` will disable all automatic maintenance in git-gui, creating a slight divergence from CLI behavior.

Johannes pushes back against Wolfgang's concern about unlikely edge cases where users might have configured maintenance but never run it. The response maintains the project's preference for simplicity over hypothetical edge cases, noting that the CLI faced similar tradeoffs when introducing auto-GC.
