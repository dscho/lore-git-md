This is patch 5/10 in Patrick Steinhardt's performance optimization series, which introduces a POSIX-compatible `writev()` wrapper for systems that don't have the system call natively. The series aims to reduce lock contention in `git-upload-pack` during high-concurrency scenarios.

The patch adds a compatibility implementation of `writev()` for Windows (where the system call is unavailable) while using the native version on Unix-like systems. The wrapper carefully handles edge cases like buffer size overflow (returning EINVAL as specified by POSIX) and partial writes. The implementation is integrated with Git's build system (Makefile and meson) and includes proper header declarations.

This is a foundational piece for the larger series, enabling the subsequent patches to use `writev()` for batched I/O operations across all platforms. The implementation has been reviewed and validated by Johannes Sixt for platform-specific behavior, particularly around edge cases like zero-byte writes. The patch is well-contained and follows Git's established patterns for platform compatibility code.
