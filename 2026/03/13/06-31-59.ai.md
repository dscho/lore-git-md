This is a final approval for the merged `git fast-import` signature handling series. Patrick Steinhardt confirms satisfaction with the v6 patches that Junio C Hamano has already indicated he will merge. The series adds `sign-if-invalid` mode to complement existing signature handling in fast-import, building on earlier work by Christian Couder and Justin Tobler.

The implementation consolidates signing logic into a reusable `sign_buffer()` API while maintaining clear separation between signature creation and re-signing operations. The final version addressed all review feedback, including Jeff King's catch of an incorrect test branch reference and Patrick's approval of the clarified warning messages about signature replacement (not creation). The test suite now provides comprehensive coverage for OpenPGP, X.509, and SSH signature scenarios.

This marks the successful conclusion of a multi-iteration effort that demonstrates Git's collaborative development model - the feature evolved through careful review rounds, with domain experts like Patrick and Jeff providing key improvements. The merged code enables `git fast-import --signed-commits=sign-if-invalid[=<keyid>]` with syntax matching `git commit --gpg-sign`, while explicitly limiting re-signing to previously-signed-but-invalid commits. Future work could extend this to unsigned objects or tags, but those remain separate efforts.
