[Cross-project coordination] Proposal to extend responsive web design from GitGitGadget to kernel.org, led by Johannes Schindelin and contributor Rito Rhymes. Rito implemented mobile-friendly designs for GitGitGadget and gitweb (merged into Git's master) and submitted a 6-patch series for kernel.org responsive improvements. The effort transitioned from private discussions with Konstantin Ryabitsev (Linux Foundation infrastructure lead) to public coordination on this thread due to kernel.org lacking its own public mailing list.

Current patch series (all technical work complete, awaiting kernel.org review):
- Patch 1 (merged): Viewport meta tag (width=device-width, initial-scale=1.0) fixing mobile "tiny text"
- Patch 2: CSS fixes for Oswald font with global `line-height: 1.1` for headings
- Patch 3: Mobile breakpoint CSS adjustments below 848px (banner, Tux logo, heading sizes)
- Patch 4: Overflow fixes for extras/footer via flexbox and breakpoints at 550px/400px
- Patch 5: Core content area fixes with scrollable tables and preformatted blocks
- Patch 6: Final mobile responsiveness for docutils tables in releases/signature pages

Konstantin Ryabitsev formalized the contribution process by adding CONTRIBUTING.md to kernel.org's website repository (second code contribution in 15 years) and directed Rito to rebase the series on latest master and submit through proper channels. Rito Rhymes confirms in this final email that they will follow Konstantin's instructions to complete the handoff through kernel.org's newly established contribution process. Junio C Hamano previously noted the discussion may appear off-topic to Git developers but took no position on venue. This concludes Git mailing list involvement, with all technical work on the complete 6-patch series (addressing viewport scaling, CSS overflow, and responsive table handling) now transitioning to kernel.org's channels. The exchange demonstrates successful cross-project coordination to improve shared infrastructure, with all parties maintaining constructive engagement throughout.
