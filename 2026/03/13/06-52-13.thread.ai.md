[Cross-project coordination] Proposal to extend responsive web design from GitGitGadget to kernel.org, led by Johannes Schindelin and contributor Rito Rhymes. Rito previously implemented mobile-friendly designs for GitGitGadget and gitweb (merged into Git's master branch), and has submitted a 6-patch series for kernel.org responsive improvements. The effort transitioned from private discussions with Konstantin Ryabitsev (Linux Foundation infrastructure lead) to public coordination on this thread due to kernel.org lacking its own public mailing list and Git community's stake in kernel.org's usability as host of Git mailing list archives.

Current patch series status:
- Patch 1 (merged): Added viewport meta tag (width=device-width, initial-scale=1.0) fixing mobile "tiny text" issue
- Patch 2: Addressed CSS issues with Oswald font's tall letterforms by introducing global `line-height: 1.1` for headings while maintaining desktop layout
- Patch 3: Solves horizontal overflow below 848px viewport width with mobile breakpoint CSS adjustments to banner (removed side borders, reduced Tux logo size, adjusted heading sizes and list padding)
- Patch 4: Fixes overflow in extras and footer sections below 848px by converting extras to wrapping flexbox, stacking blogroll/social blocks full-width, and making donor logos wrap naturally with progressive refinements at 550px/400px breakpoints
- Patch 5: Prevents horizontal overflow in core content areas through: auto-width protocols/latest sections with adjusted margins, horizontally scrollable releases table (with date cells kept readable via `nowrap`), flexible-width main content areas, and horizontally scrollable preformatted blocks (`pre` and `.literal-block`) with touch scrolling support
- Patch 6 (new): Finalizes mobile responsiveness by addressing docutils tables in releases and signature pages, making them horizontally scrollable while preserving single-line cell contents via `white-space: nowrap` and handling border rendering during scrolling states

The complete series demonstrates Rito's responsive design expertise through careful attention to mobile usability details while maintaining clear separation between mobile-specific rules and desktop layout preservation. Each patch builds on the last with narrowly scoped CSS changes (flexbox, media queries, overflow handling) that preserve desktop layout while fixing mobile-specific issues. The Git list remains CC'd for continuity, though this is fundamentally a kernel.org infrastructure change. No technical objections raised - awaiting kernel.org's review and potential merge of the complete series. The work systematically addresses all major responsive design elements identified in the original coordination thread, from viewport meta tags through to table handling, providing concrete improvements for kernel.org's mobile experience.
