This is patch 5/10 in Patrick Steinhardt's performance optimization series addressing lock contention in `git-upload-pack`. The patch introduces a POSIX-compliant `writev()` wrapper for systems that lack this syscall, particularly Windows.

The wrapper provides cross-platform compatibility by:
1. Defining a `git_iovec` struct and `git_writev()` function when `NO_WRITEV` is set
2. Implementing overflow checking per POSIX spec (EINVAL for `ssize_t` overflow)
3. Falling back to sequential `xwrite()` calls when needed
4. Maintaining the same error semantics as native `writev()`

The patch includes build system integration (Makefile, meson.build) and marks Windows/MINGW as requiring the compatibility wrapper. The implementation has been validated by Johannes Sixt for edge case handling, including zero-byte writes. This foundational piece enables the subsequent performance optimizations that reduce write syscalls in high-concurrency scenarios.
