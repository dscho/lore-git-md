This is a refactoring patch that extracts revert message formatting logic from `sequencer.c` into a shared helper function, as part of the ongoing `git replay --revert` feature development. The patch moves the message generation code used by `git revert` into a new `sequencer_format_revert_message()` function that can be reused by both the sequencer and the upcoming replay command.

The key changes include:
1. Extracting the complete revert message formatting logic (handling "Revert" vs "Reapply" cases and commit references) from `do_pick_commit()` into the new helper function
2. Updating `refer_to_commit()` to take explicit `repository` and `use_commit_reference` parameters instead of reading from `replay_opts`, making it more self-contained
3. Adding the new function to `sequencer.h` with thorough documentation of its behavior and parameters

The refactoring maintains all existing behavior while making the logic reusable. This is a clean technical preparation for the `git replay --revert` functionality, following Phillip Wood's suggestion to consolidate the message formatting logic. The patch shows careful attention to interface design and documentation, with no behavior changes beyond the refactoring itself.
