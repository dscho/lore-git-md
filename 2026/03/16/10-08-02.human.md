Build system refactoring patch from Patrick Steinhardt, part of his series introducing precompiled headers and tooling reorganization. This is the 7th of 8 patches in v2 of the series.

The patch splits compatibility sources into their own static library ("compat") in preparation for precompiled header support. This is necessary because some compatibility sources intentionally avoid including git-compat-util.h, which would break when precompiled headers implicitly include it. The change moves all platform-specific compatibility code (Windows, macOS, Cygwin implementations) and fallback functions (like poll.c, basename.c) into this separate library while keeping core functionality in the main git library.

The implementation maintains all existing functionality while enabling selective precompiled header usage. The meson build system is updated to handle the new library structure, with careful attention to platform-specific cases and conditional compilation. This is a mechanical but important change that enables the performance improvements coming in the final patch of the series.

The patch follows the established pattern of the series - well-structured, clearly explained, and focused on enabling the next step (PCH support) without introducing new functionality. It demonstrates the careful consideration of edge cases that characterizes Patrick's build system work.
