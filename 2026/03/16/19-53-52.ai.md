This refactoring moves all formatting logic - including commit references - into a single reusable function with explicit repository and boolean parameters, rather than relying on `replay_opts`. The implementation now processes reverts in chronological (newest-first) order to match `git revert` behavior and drops empty revert commits by default, aligning with `git cherry-pick`.
