This is part 4/8 of Patrick Steinhardt's build system improvement series, focusing on tooling reorganization. The patch moves the Unicode data update script from `contrib/` to the new `tools/` directory, continuing the series' goal of consolidating developer-facing build infrastructure.

The `update-unicode.sh` script is used to refresh Git's internal Unicode character data when new Unicode standards are released. Patrick argues this belongs in `tools/` rather than `contrib/` since it's essential for maintaining core functionality rather than being optional contributor material. The change is purely organizational - the script and its supporting files are moved verbatim with no functional modifications.

This patch follows the series' established pattern of relocating build-related scripts while maintaining their exact contents. It's a straightforward piece of the larger infrastructure cleanup that has already been discussed and reviewed in the thread's earlier messages. The change aligns with the project's ongoing effort to better separate core development tools from optional/contrib material.
