This is the first patch in Patrick Steinhardt's 8-part series reorganizing Git's build infrastructure. It introduces a new top-level "tools/" directory to house essential build-related tooling that was previously scattered, particularly in "contrib/". The patch creates the directory structure with a README explaining its purpose and updates the Makefile and meson.build to recognize the new location.

The change addresses a long-standing inconsistency where critical build tools were mixed with optional/experimental content in contrib/. The patch is purely organizational at this stage - it creates the directory but doesn't yet move any tools into it (that comes in subsequent patches). The changes are minimal and straightforward: adding directory exclusions to the Makefile's SOURCES_CMD and including the new directory in Meson's build configuration.

This foundational change sets up the structure for the more substantive tool relocations that follow in the series. The patch appears well-motivated and uncontroversial, with clean implementation that maintains compatibility with both build systems. As the first in a carefully structured series, it does exactly what's needed to enable the more complex changes that come later.
