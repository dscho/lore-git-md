This is the second patch in a documentation series converting the `git-interpret-trailers` man page to the project's standard synopsis style. The patch focuses on normalizing and expanding the options section.

Kristoffer Haugsbakk brings the options documentation up to current standards by:
- Adding missing negated options (like `--no-in-place` and `--no-only-trailers`)
- Standardizing to the "stuck form" for option syntax (e.g. `--where=<placement>`)
- Reordering options to follow current conventions
- Documenting default behaviors that were previously implicit
- Adding clarification about `--no-trailer` resetting the trailer list
- Including the previously undocumented `--divider` option

The changes are mechanical and follow patterns established in prior documentation conversions (referencing commit 806337c7). The patch maintains all existing functionality while making the documentation more complete and consistent. Review feedback from Jean-Noël Avila and Junio C Hamano has already been incorporated in this v2 version of the series.

This continues the project-wide effort to standardize documentation formatting, with particular attention to making option behaviors and defaults explicit. The changes are purely about documentation quality - no command behavior is altered.
