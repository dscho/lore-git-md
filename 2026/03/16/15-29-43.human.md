This is the second patch in a 2-part series that's part of the ongoing ODB (object database) abstraction effort. The patch converts 22 call sites across 11 files to use the new `odb_source_files_try()` helper function introduced in patch 1, rather than the unsafe `odb_source_files_downcast()`.

The changes allow Git to gracefully handle object sources that aren't files-based (like packfiles or loose objects) when iterating through the source chain. Each converted site now checks for NULL returns from `odb_source_files_try()` before accessing files-specific members, skipping non-files sources rather than crashing. The patch touches core object access paths in files like `packfile.c`, `loose.c`, and `object-file.c`, plus several builtin commands.

The implementation looks clean and mechanical, following established patterns from similar refs backend work. A new unit test verifies the helper function's behavior. The author notes that some display and optimization functions will still need follow-up work to properly account for non-files sources.
