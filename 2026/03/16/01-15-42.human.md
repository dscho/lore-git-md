Test cleanup patch improving isolation in ignore-file tests.

This is the second version of Mirko Faina's patch to fix test isolation issues in `t0008-ignores.sh`. The problem stems from leftover test artifacts - specifically `.gitignore` files and directories - that affect subsequent tests when run verbosely. The patch now takes a two-pronged approach: improving cleanup after the symlink test and adding proactive cleanup before the large-file test.

The changes are straightforward and well-motivated. The symlink test now removes all artifacts it creates (`subdir`, `.gitignore`, `err`, `actual`), while the large-file test starts by removing any pre-existing `.gitignore` files. This follows the discussion on the first version where Junio C Hamano emphasized thorough test isolation.

The commit message is much improved from v1, clearly explaining both the symptom (unexpected warning message) and the solution (dual cleanup approach). The patch demonstrates good attention to test hygiene and shows the contributor responding to feedback - a positive sign for a relatively new participant.
