This is part 5/8 of Patrick Steinhardt's build system improvement series, focusing on reorganizing build infrastructure scripts into a new "tools/" directory. The patch moves several key build-related scripts from the top-level directory to "tools/", including:

- Script generators (generate-cmdlist.sh, generate-configlist.sh, generate-hooklist.sh, generate-perl.sh, generate-python.sh, generate-script.sh)
- Build helper scripts (check-builtins.sh, detect-compiler)

The changes update all references to these scripts across the build systems (Makefile, CMake, Meson) to point to their new locations. This is a mechanical change that maintains exact functionality while cleaning up the project structure. The patch follows the series' overall goal of consolidating build infrastructure into a dedicated directory, separating it from optional contrib/ material.

This continues the work started in earlier patches of the series, with all technical aspects already reviewed in previous iterations. The changes are straightforward path updates with no behavioral impact, making this a low-risk infrastructure improvement.
