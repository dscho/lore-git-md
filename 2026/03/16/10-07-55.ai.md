This is a build system improvement series from Patrick Steinhardt, consisting of two main components: reorganization of build tooling into a new "tools/" directory and the introduction of precompiled header support in Meson for faster builds.

The series is now in its second iteration, with minor adjustments made based on feedback. The first 5 patches consolidate various build-related scripts and tools (Coccinelle rules, coverage-diff.sh, update-unicode.sh, and build generators) from their scattered locations into the new "tools/" directory. This follows up on Patrick's earlier cleanup of the "contrib/" directory.

The last 3 patches implement precompiled header support, specifically for git-compat-util.h, which provides a measured 40% build speed improvement. The implementation uses Meson's forced inclusion approach (-include) and includes documentation about the design choices. The changes maintain compatibility across build systems (Makefile, CMake, Meson) and platforms.

Key technical points in v2 updates include simplifying the precompiled header specification from an array to a single file and adding commit message documentation about the implicit inclusion behavior. The series appears ready for merging, with all technical concerns addressed and only minor workflow impact questions (particularly around Coccinelle usage) remaining open but not blocking progress.
