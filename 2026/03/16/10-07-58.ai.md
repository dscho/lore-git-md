This is a build system refactoring patch, part of Patrick Steinhardt's series to reorganize Git's developer tooling. The patch moves the `coverage-diff.sh` script from `contrib/` to the new `tools/` directory, continuing the series' goal of separating essential infrastructure from optional contrib material.

The script provides test coverage analysis for Git's codebase, making it more appropriately classified as core developer tooling rather than optional contrib content. The change is purely organizational - the script's functionality remains identical, just relocated to better reflect its purpose. This follows the pattern established in earlier patches of the series for similar build-related tools.

As with other patches in this series, the change is straightforward with no expected impact on functionality. The patch maintains the script's exact content while updating its location in the project structure. This is one of several similar relocations that together create a cleaner separation between core build infrastructure and optional contrib components.
