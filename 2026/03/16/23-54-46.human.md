This is the second patch in Jiang Xin's five-part series introducing AI-assisted workflows for Git's localization (l10n) process, focused on documentation improvements. The patch adds a new `po/AGENTS.md` file that provides optimized instructions specifically tailored for AI agents performing translation-related tasks, while keeping the human-readable guidance in `po/README.md`.

The key points are:

1. The new documentation separates AI-specific instructions from human-readable content, allowing for more concise and targeted guidance. This separation leads to measurable performance improvements - 82% fewer API turns and 76% faster execution time when updating translation templates (`po/git.pot`).

2. The file includes both background knowledge (language codes, PO file headers) and specific task instructions. A notable optimization is telling AI agents to simply run `make po/git.pot` without pre-checking file existence or verifying output, which reduces unnecessary steps.

3. The patch maintains a clear principle that AI is optional and that human translators remain ultimately responsible for quality control. The documentation emphasizes that AI output should always be treated as draft material requiring human review.

This appears to be a well-considered addition that builds on the series' goal of making translation workflows more efficient while preserving human oversight.
