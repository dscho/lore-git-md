This is the final patch in Patrick Steinhardt's build system improvement series, implementing precompiled header (PCH) support for git-compat-util.h in the Meson build system. The patch demonstrates a 40% build speed improvement by precompiling the frequently-included header (which expands to over 23,000 lines) once rather than reprocessing it in every compilation unit.

The implementation uses Meson's c_pch option to force-include the precompiled header via compiler flags (-include), with tools/precompiled.h serving as the single-entry point that includes git-compat-util.h. This approach was chosen after discussion on the mailing list about GCC's PCH limitations and the need to maintain compatibility with the reftable backend's design constraints.

The patch builds on the preparatory work in earlier patches that split platform-specific code into a separate compat library (patch 7/8) and adjusted git-compat-util.h's sign-compare warning infrastructure for PCH compatibility. With all technical concerns addressed and documentation added about the design choices, this appears ready for merging as part of the complete series.
