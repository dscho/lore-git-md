This is a localization (l10n) patch from Jiang Xin, part of a series introducing AI-assisted workflows for Git's translation process. The patch adds a `.gitattributes` file to automate location filtering in PO files, which helps produce cleaner diffs and save repository space.

The patch standardizes on two filter types: `gettext-no-location` (default, strips both filenames and line numbers) and `gettext-no-line-number` (keeps filenames but removes line numbers, requiring gettext 0.20+). It excludes legacy unmaintained PO files from filtering to avoid discrepancies. Four PO files (ca.po, es.po, ga.po, ru.po) were batch-modified to match the filter output format.

The documentation in `po/README.md` is reorganized to better separate human and AI processes, moving filter setup instructions to a new "Preparing a XX.po file for commit" section. This appears to be a well-considered change that builds on previous discussion, with Johannes Sixt having explicitly agreed to the filter naming approach. The implementation shows measurable improvements - 82% fewer API turns and 76% time reduction in the update-pot process.

This patch represents a mature iteration of the proposal that has successfully addressed technical feedback while maintaining the practical needs of translation workflows. The changes focus on making AI assistance more efficient while preserving human oversight for quality control.
