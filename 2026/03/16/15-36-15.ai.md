This is a refactoring patch that extracts Git's autocorrection logic into reusable components, part of Jiamu Sun's series to add subcommand autocorrection support. The patch moves the config parsing and prompt/delay handling from help.c into new autocorrect.{c,h} files, making the functionality available to other parts of Git.

The key changes are:
- Creates new autocorrect.c with the core logic for parsing help.autocorrect config values and handling user confirmation prompts
- Defines a clean public API in autocorrect.h with constants for the different autocorrection modes (IMMEDIATELY, PROMPT, NEVER, SHOW)
- Updates help.c to use the new API instead of its local implementation
- Adds the new files to both Makefile and meson.build build systems

The refactoring maintains all existing behavior while making the autocorrection system available for reuse by other commands. This is a preparatory step for the subsequent patches in the series that will add subcommand autocorrection to commands like `git remote` and `git notes`. The implementation is clean and well-contained, with proper separation of concerns between the config parsing, prompt handling, and the actual autocorrection logic that will be added in later patches.
