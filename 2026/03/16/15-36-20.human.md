This is a feature patch that implements subcommand autocorrection in Git's parse-options API, part of Jiamu Sun's ongoing series. The patch adds fuzzy matching for mistyped subcommands (like `git remtoe` instead of `git remote`) using Damerau-Levenshtein distance with length-based thresholds.

The implementation:
- Skips optional subcommands (marked with PARSE_OPT_SUBCOMMAND_OPTIONAL)
- Uses standard edit distance weights (1,1,1,1) for predictable matching
- Scales allowed edits based on input length (0 edits for 0-2 chars, 1 for 3-5, 2 for 6+)
- Shows a warning and confirmation prompt when autocorrecting
- Falls back to the standard "unknown subcommand" error if no good match exists

The patch builds on previous work that extracted autocorrection logic into reusable components (autocorrect.{c,h}) and integrates cleanly with the existing subcommand parsing infrastructure.
