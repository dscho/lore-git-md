This is the first patch in a five-part series introducing AI-assisted workflows for Git's localization (l10n) process, focused on simplifying location filtering in PO files. The patch adds a `.gitattributes` file to standardize how Git handles location comments in translation files.

The change introduces two filter types for PO files:
1. `gettext-no-location` (default) - removes both filenames and line numbers from location comments
2. `gettext-no-line-number` - keeps filenames but removes line numbers (requires gettext 0.20+)

The patch explicitly excludes legacy unmaintained PO files (el.po, is.po, etc.) from filtering to avoid index mismatches. It also modifies four actively maintained PO files (ca.po, es.po, ga.po, ru.po) to match the filtered output format, ensuring clean diffs. The accompanying documentation reorganization separates human and AI workflows, moving filter setup instructions to a dedicated section.
