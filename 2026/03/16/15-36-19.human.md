This is a refactoring patch in Jiamu Sun's subcommand autocorrection series, now in its fourth iteration. The patch focuses on cleaning up the config resolution API for the autocorrection feature.

The key change here is moving from a direct config callback approach to a higher-level `autocorrect_resolve()` function that handles the config reading internally. This better encapsulates the config handling logic and prevents external misuse of the callback. The patch also separates the alias resolution logic from autocorrect config handling, making the code paths more distinct.

The implementation maintains all existing behavior while improving the API design. The changes touch three files:
- `autocorrect.c` gains the new resolution function while making the callback static
- `autocorrect.h` simplifies its public interface
- `help.c` is updated to use the new API and splits out alias handling
