This is a refactoring patch that extracts Git's autocorrection logic into reusable components, part of Jiamu Sun's series to add subcommand autocorrection support. The patch moves config parsing and prompt/delay handling from help.c into new autocorrect.{c,h} files, making the functionality available to other parts of Git that want to implement similar behavior.

The changes are mechanical but well-structured:
- Creates new autocorrect.c/h with the core logic (config parsing and confirmation prompts)
- Updates Makefile and meson.build to include the new files
- Simplifies help.c by removing the now-duplicated code
- Maintains all existing behavior while making the infrastructure more modular

This is the second patch in a 10-part series that has already gone through several rounds of review. The implementation looks clean and focused, with clear separation of concerns. The patch follows Git's coding style and includes proper header file guards and documentation. As part of a larger effort that has already addressed all major technical concerns, this appears ready for merging.
