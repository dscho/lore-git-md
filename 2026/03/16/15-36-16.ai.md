This is a refactoring patch in Jiamu Sun's subcommand autocorrection series, moving TTY detection from help.c to autocorrect.c as part of the effort to extract and centralize autocorrection logic. The change relocates the interactive session check (verifying both stdin and stderr are TTYs) into the config resolution function where it logically belongs, rather than having it in the help command's unknown command handler.

The patch is a straightforward code movement with no behavior change - it just shifts where the TTY check happens during config processing. The implementation is clean, maintaining all existing functionality while improving the separation of concerns. This continues the series' pattern of methodically extracting autocorrection logic into reusable components, with each patch focusing on one clear architectural improvement.

Key technical details:
- Moves isatty(0) && isatty(2) check from help.c to autocorrect_resolve_config()
- Preserves all existing behavior including fallback to AUTOCORRECT_NEVER for non-interactive sessions
- Keeps the same config parsing flow (try parse_autocorrect() first, fall back to git_config_int())
- Maintains the same special case for values <0 or ==1 mapping to AUTOCORRECT_IMMEDIATELY

This change is part of the broader effort to make the autocorrection infrastructure more modular and reusable across different parts of Git. The patch follows the series' established pattern of clean, focused refactoring steps.
