This is the final patch in Patrick Steinhardt's build system improvement series, implementing precompiled header (PCH) support for the Meson build system. The patch focuses on `git-compat-util.h`, which is included by nearly every compilation unit in Git and currently takes significant time to process (over 23,000 lines when preprocessed).

The implementation uses Meson's built-in PCH support to compile `git-compat-util.h` once and reuse it across all builds, achieving a measured 40% speedup in full builds. The approach uses GCC/Clang's `-include` directive to implicitly include the precompiled header in all compilation units. A new `tools/precompiled.h` file is added as the PCH entry point, containing just the single line `#include "git-compat-util.h"`.

This patch builds on the previous work in the series that reorganized build tooling and split platform-specific code into a separate library to enable clean PCH support. The changes maintain compatibility across all build systems (Makefile, CMake, Meson) and platforms while delivering significant performance benefits. The series appears ready for merging, with all technical concerns addressed in this v2 iteration.
