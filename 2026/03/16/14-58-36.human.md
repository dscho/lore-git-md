This is a coordination update in the cross-project effort to make kernel.org's website responsive. Konstantin Ryabitsev (Linux Foundation infrastructure lead) responds to Rito Rhymes' willingness to move the discussion elsewhere by adding a CONTRIBUTING.md file to the kernel.org website repository - the first such documentation in 15 years. 

The email marks a clear transition point where future discussion should move to kernel.org's own contribution process rather than continuing on the Git list. Konstantin instructs Rito to rebase the already-completed 6-patch responsive design series (previously discussed on the Git list) and submit it through the new channel. 

This concludes the Git mailing list's involvement in the topic, with the technical work now properly routed to kernel.org's maintainers. The exchange demonstrates how infrastructure shared across projects can sometimes require temporary coordination on one project's list before establishing more appropriate long-term channels.
