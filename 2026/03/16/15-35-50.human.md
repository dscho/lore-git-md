This is a refactoring patch series that introduces a Coccinelle rule to detect and fix instances where `struct strbuf` is passed by value rather than by pointer. The series has now been reviewed and accepted by maintainer Junio C Hamano for inclusion.

The patch series was motivated by Jeff King's earlier identification of this anti-pattern in `write_worktree_linking_files()`. While that specific case was already fixed separately, Deveshi Dwivedi proposed a more systematic solution by creating a Coccinelle semantic patch to catch all such cases. The series consists of two parts: a detection rule and a fix for the one remaining instance found in `builtin/stash.c`.

Junio's brief response indicates the patches meet the project's quality standards and will be queued for merging. This is a straightforward code quality improvement that helps prevent subtle bugs - passing `strbuf` by value is both wasteful (due to copying) and potentially dangerous (as callers and callees operate on different copies). The fact that only one additional case was found suggests good project hygiene around this pattern already.
