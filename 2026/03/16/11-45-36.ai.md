This is a follow-up in a user support thread about Git command syntax, not a patch submission. Kristoffer Haugsbakk responds to John Emmas's earlier question about a non-existent `--format` option at the Git top level.

The reply clarifies that `--format` is only available as a subcommand-specific parameter (like in `git log`), not as a top-level Git option. It also probes whether the user might actually need source code formatting (suggesting `git-clang-format` as a third-party solution) rather than output formatting.

The exchange remains a basic support question that would be better suited to a user forum than the development mailing list. No technical changes are proposed - this is purely an informational response correcting a common misunderstanding about Git's command structure. The thread still doesn't belong on the Git development list, though the reply is technically accurate and helpful for the original asker.
