This Build system reorganization - moving build scripts to tools/

This is the fifth patch in Patrick Steinhardt's 8-part series reorganizing Git's build infrastructure. The series introduces a new "tools/" directory for build-related scripts and adds precompiled header support in Meson.

This specific patch moves several build-related scripts from the top-level directory into the new "tools/" location. The scripts being relocated include:
- `check-builtins.sh`
- `detect-compiler`
- Various generator scripts (`generate-cmdlist.sh`, `generate-configlist.sh`, etc.)

The changes are mechanical updates to the build systems (Makefile, CMake, Meson) to reference the new locations. All functionality remains identical - this is purely an organizational change to consolidate build tooling in one place rather than scattering it across the repository.

The patch follows logically from the earlier introduction of the "tools/" directory in patch 1/8. It's part of Patrick's ongoing effort to clean up Git's build infrastructure, following his previous work reorganizing the "contrib/" directory. The changes are well-contained and unlikely to be controversial, though they will require updates to any developer workflows that directly reference these scripts.
