This is the fifth and final patch in Jiang Xin's v4 series introducing AI-assisted workflows for Git's localization (l10n) process, focusing specifically on translation review. The patch adds comprehensive documentation in `po/AGENTS.md` detailing how AI agents should review PO file translations using the `git-po-helper` tool.

The review workflow addresses a key challenge: translation diffs often lose context, making accurate AI review difficult. The solution uses `git-po-helper compare` to extract complete msgid/msgstr pairs with full context, and `git-po-helper msg-select` to split large reviews into manageable batches. The documentation provides a detailed 8-step workflow with shell scripts for batch processing and result merging, plus a JSON format for reporting issues.

Key technical details show measurable improvements: a 96/100 review score in testing with the Qwen model, processing 63 entries in 22 API turns. The implementation handles resume support, batch sizing heuristics, and preserves glossary references for terminology consistency. The JSON output format includes severity scoring (0-3) and suggested corrections.
