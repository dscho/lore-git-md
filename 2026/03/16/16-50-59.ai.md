The patch converts 13 instances across the test file to use the preferred helper functions without altering test behavior. This continues the thread's focus on mechanical test infrastructure improvements rather than changes to the underlying rerere functionality.

The maintainer indicates these issues don't necessarily require a v4 resubmission but notes the missing sign-off is grounds for one. This feedback serves as both a specific correction and a gentle reminder about the project's contribution norms for new participants.
