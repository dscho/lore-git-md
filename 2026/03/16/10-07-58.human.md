This is part 3 of Patrick Steinhardt's 8-patch series reorganizing Git's build infrastructure. The patch moves the `coverage-diff.sh` script from `contrib/` to the new `tools/` directory, continuing the effort to separate essential developer tooling from optional contrib material.

The script provides test coverage analysis for the Git codebase, making it more appropriately categorized as core build infrastructure rather than an optional contribution. The change is straightforward - a simple file relocation with no functional modifications. This follows the pattern established in earlier patches of the series to consolidate build-related tooling.

As with the rest of the series, this appears to be a well-justified cleanup that improves the project's organization. The patch maintains all existing functionality while making the codebase's structure more logical.
