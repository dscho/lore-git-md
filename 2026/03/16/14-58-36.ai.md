This is a coordination update in the cross-project effort to make kernel.org's website responsive. Konstantin Ryabitsev (Linux Foundation infrastructure lead) responds to Rito Rhymes' willingness to move the discussion elsewhere by formalizing the contribution process. He has added a CONTRIBUTING.md file to the website repository (noting this is only the second code contribution in 15 years) and directs Rito to rebase the 6-patch responsive design series on latest master and submit through the proper channels. 

The technical work remains unchanged from the previously summarized series that addresses mobile viewport scaling, CSS overflow issues, and responsive table handling. This email effectively concludes the Git mailing list's involvement in the topic, with future discussion and review to happen through kernel.org's newly documented contribution path. The exchange demonstrates successful cross-project coordination to improve shared resources, with all parties maintaining a constructive tone throughout.
