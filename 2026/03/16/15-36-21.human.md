Feature patch enabling subcommand autocorrection for `git remote` and `git notes`. This is part 8/10 of Jiamu Sun's series to add subcommand autocorrection support to Git's parse-options API.

The patch modifies the parse-options handling to enable autocorrection for commands with optional subcommands by adding the new `PARSE_OPT_SUBCOMMAND_AUTOCORR` flag. It demonstrates the feature by applying it to `git remote` and `git notes`, removing their manual error handling for unknown subcommands since the parse-options infrastructure will now handle this automatically.

The implementation is clean and focused - it adds the new flag, updates the subcommand handling logic in parse-options.c, and simplifies the builtin commands by removing redundant error checking. The changes follow the pattern established earlier in the series, maintaining consistency with the extracted autocorrection logic.
