Test infrastructure question about expensive test frequency.

Mirko Faina follows up on their recently submitted test fix with a broader question about Git's test practices. They note that the test failure they fixed involved interaction between two tests that had existed since 2021 and 2024 respectively, and wonder how often such expensive tests actually get run if this issue went unnoticed for so long. They speculate that GitHub's CI might not run these tests either.

This isn't a patch submission but rather a contributor seeking to understand the project's testing practices. The question touches on an important aspect of Git's development - the balance between comprehensive test coverage and practical CI runtime constraints. While the immediate test isolation issue is resolved, this follow-up could prompt discussion about test suite maintenance and CI configuration.
