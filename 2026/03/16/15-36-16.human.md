This is a refactoring patch in Jiamu Sun's series adding subcommand autocorrection support to Git's parse-options API. The patch moves TTY detection for autocorrection prompts from help.c to autocorrect.c, where it logically belongs as part of config resolution.

The patch maintains all existing functionality while cleaning up the code organization - help.c no longer needs to handle the TTY check, and autocorrect.c now fully owns the config resolution logic.
