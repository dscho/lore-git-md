Performance improvement for MIDX repacking with bitmaps.

This is Taylor Blau's patch series (v3) improving Git's multi-pack-index (MIDX) repacking functionality, now ready for merging into the 'next' branch. The 17-commit series enables reachability bitmaps during MIDX compaction and implements incremental repacking optimizations, building on earlier work in this area.

The series includes several preparatory refactors to the MIDX writing code - introducing helper functions like `midx_pack_perm()`, extracting common operations, and cleaning up the pack ordering requirements. These changes pave the way for the main feature: more efficient MIDX compaction that can leverage existing bitmaps. The implementation comes with test updates and documentation fixes to match the new behavior.

Jeff King (Peff) reviewed an earlier version, identifying minor issues like outdated comments and interface concerns, which have now been addressed in v3. The changes appear well-contained to the MIDX subsystem, with no expected user-visible behavior changes beyond the performance improvements. This represents another step in the ongoing effort to optimize Git's handling of repositories with many packfiles.
