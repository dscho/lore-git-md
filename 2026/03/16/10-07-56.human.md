This is the first patch in Patrick Steinhardt's 8-part series reorganizing Git's build infrastructure. It introduces a new `tools/` directory to house essential build-related tooling that was previously scattered, particularly in `contrib/`. The patch creates the directory structure with a README explaining its purpose and updates the Makefile and meson.build to recognize the new location. 

This is part of a larger effort to separate core build infrastructure from truly optional `contrib/` material. The patch is straightforward - it just sets up the directory skeleton without yet moving any tools, which will come in subsequent patches. The changes are minimal and mechanical, updating build system exclusions and adding the new subdirectory to meson's build tree.

As the first step in a well-structured series, this patch does exactly what it needs to: establish the new directory with clear intent while leaving the actual tool migrations for dedicated follow-up patches. The approach shows good patch series hygiene by keeping the scope tightly focused.
