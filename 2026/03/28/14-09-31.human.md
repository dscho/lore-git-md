This is part 1/5 of a refactoring series in the ongoing `the_repository` removal effort. Shreyansh Paliwal continues converting branch-related helper functions to explicitly take a `struct repository*` parameter instead of relying on the global `the_repository`.

The patch focuses on making four branch helper functions repository-aware:
- `copy_branchname()`
- `check_branch_ref()`
- `validate_branchname()`
- `validate_new_branchname()`

The changes are mechanical but wide-ranging, touching call sites across several builtin commands (branch, checkout, worktree, merge) and requiring updates to function signatures in branch.h. The v2 iteration incorporates Patrick Steinhardt's feedback by making `struct repository*` the first parameter in all modified functions, following codebase conventions.

The patch appears well-executed with thorough updates to all call sites. It's a typical incremental step in the long-running effort to eliminate global state, building on previous work (jw/object-name-bitset-to-enum) and following established patterns from René Scharfe's earlier conversions. The changes are straightforward with no behavior modifications, just making repository context explicit.
