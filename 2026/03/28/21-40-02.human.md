This is a feature patch series adding TypeScript support to Git's built-in userdiff patterns. The series comes from Dhruv Arora as part of Google Summer of Code (GSoC).

The main patch adds a new pattern to recognize TypeScript syntax in `userdiff.c`, handling function declarations, class definitions, arrow functions, and method definitions along with common modifiers like `export`, `async`, and `static`. Three test files are included to verify the pattern matches various TypeScript constructs: class methods, exported default classes, and exported functions.

The second patch appears to be a minor cleanup, sorting the pattern and tests (though the exact changes aren't visible in the cover letter). The implementation looks focused and well-scoped, with clear test coverage for the main syntax cases. As a GSoC contribution, this follows the typical pattern of adding support for a new language to Git's diff highlighting capabilities.
