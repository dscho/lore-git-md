Test modernization patch that improves reliability of blame tests. This is part 1 of a 2-patch series from Trieu Huynh submitted under the Google Summer of Code program.

The patch modifies t8003-blame-corner-cases.sh to avoid piping git-blame output directly to grep, which can mask git's exit code. Instead, it redirects output to temporary files first before checking contents with test_grep. This ensures test failures from git crashes would be properly reported rather than hidden by the pipe.

The changes are mechanical but important for test reliability - each git-blame invocation now writes to an 'actual' file first. The patch maintains all existing test assertions while making them more robust. This appears to be a straightforward improvement with no obvious downsides, following established test patterns seen elsewhere in the codebase.
