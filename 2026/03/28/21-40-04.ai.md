This is the second patch in Dhruv Arora's series adding TypeScript support to Git's userdiff patterns, following up on the initial implementation. The patch makes three key improvements:

1. Fixes the pattern ordering in userdiff.c by moving the TypeScript entry to its correct alphabetical position between Scheme and TeX patterns. This resolves test failures caused by the out-of-order placement.

2. Adds three new test files demonstrating the pattern matching various TypeScript constructs: class methods, exported default classes, and exported async functions. The tests verify the pattern correctly identifies the function/class names (marked as "RIGHT") that should be highlighted in diffs.

3. Refines the pattern itself to:
   - Properly handle the `default` keyword in exports
   - Fix the variable declaration case to only match at line start
   - Remove incorrect matching of variable declarations as functions/classes

The changes maintain the same overall approach as the first patch while addressing specific edge cases revealed during testing. The test coverage now includes more complex TypeScript syntax like async/await and class member declarations. This appears to be the final polishing of the feature before potential merging.
