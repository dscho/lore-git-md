This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite. The patch continues the series' pattern of replacing direct command output piping with temporary files and `test_grep` assertions to prevent exit code masking.

The changes focus on t6411-merge-filemode.sh, which tests for file mode handling during merges. The patch updates two test cases that previously piped `git ls-files` output directly to grep, converting them to use temporary files and `test_grep` instead. This ensures any failure in `git ls-files` would be properly detected rather than potentially hidden by the pipe.

The modifications are straightforward mechanical conversions that maintain the same assertions (checking for 100755 file modes) while improving test reliability. Like the rest of the series, this patch follows the established pattern seen in t8003 and other test files, demonstrating consistency with prior test modernization work. The changes are limited to test infrastructure with no impact on Git's actual merge or file mode handling behavior.
