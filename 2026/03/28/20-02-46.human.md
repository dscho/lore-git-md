This is a test modernization change from Trieu Huynh as part of their GSoC project, continuing the series to improve test reliability by avoiding command piping that can mask exit codes. 

The patch updates t4153-am-resume-override-opts.sh to replace a direct pipe between `git cat-file` and `grep` with temporary file output and `test_grep`. This ensures any failure in `git cat-file` would be properly detected rather than hidden by the pipe. The test verifies signoff behavior in `git am` operations by checking commit messages for expected signature lines.

Like others in the series, this is a mechanical but worthwhile improvement following the established pattern seen in previous patches (t0100, t2206, etc.). The change maintains the same assertions while making the test more robust. The patch is cleanly focused on the test infrastructure improvement without modifying any actual Git command behavior.
