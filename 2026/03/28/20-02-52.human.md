This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite reliability. It's patch 13/16 in a series that systematically replaces direct command output piping with temporary files and `test_grep` to prevent exit code masking.

The patch updates t3412-rebase-root.sh, modifying two test cases that check for conflicted files during rebase operations. Instead of piping `git ls-files -u` directly to grep (which would hide Git's exit code), it now writes to a temporary file and uses `test_grep` to verify the output. This follows the same pattern seen in previous patches in the series.

The changes are mechanical and focused - they don't modify test behavior, just make failures more detectable. The patch continues the series' consistent approach across different test files, this time touching rebase conflict detection tests. Like the rest of the series, it appears to be a straightforward improvement to test robustness.
