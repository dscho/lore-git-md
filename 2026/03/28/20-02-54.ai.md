This is a test modernization patch from Trieu Huynh, part of their ongoing GSoC project to improve Git's test suite reliability. The patch continues the series' pattern of replacing direct command output piping with temporary files and `test_grep` to prevent masking Git command exit codes.

The change modifies t0100-previous.sh to rewrite a test case that checks merge commit messages. Instead of piping `git cat-file` output directly to grep (which would hide any `git cat-file` failures), it now writes the output to a temporary file and uses `test_grep` to verify the expected "Merge branch" message. This matches the approach taken in previous patches in the series (t1400, t2206, etc.) and follows the established pattern from t8003.

The patch is mechanically straightforward - it's a simple transformation of one test case with no behavior changes to Git itself. The modification improves test reliability while maintaining all existing assertions. Like others in the series, this appears to be a clean, focused improvement to test infrastructure.
