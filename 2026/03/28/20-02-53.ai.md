This is a test modernization patch from Trieu Huynh, part of their ongoing GSoC project to improve Git's test suite. The patch continues the established pattern of replacing direct command output piping with temporary files and `test_grep` assertions to prevent exit code masking.

The change modifies t1400-update-ref.sh to handle refs/bisect testing more reliably checking for the presence of a bisect ref. Instead of piping `git for-each-ref` directly to grep (which would mask git's exit code), it now writes the output to a temporary file and uses `test_grep` to verify the expected content. This matches the approach taken in previous patches in the series (t0100, t2206, t7004, etc.).

The modification is straightforward and mechanical - it touches only one test case in t1400 that deals with worktree-specific bisect refs. The test continues to verify the same behavior (that bisect refs are worktree-local) but does so in a more robust way that won't miss git command failures. Like the rest of the series, this is a pure test infrastructure improvement with no impact on Git's actual functionality.
