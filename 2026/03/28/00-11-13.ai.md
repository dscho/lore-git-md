This is the third and final patch in Pablo Sabater's v6 series adding a `--graph-lane-limit` feature to `git log --graph`. The patch focuses on visual polish by introducing a '~' character to indicate truncated lanes when the graph exceeds the specified column limit.

The implementation adds the truncation marker in all relevant graph output functions (`graph_output_padding_line`, `graph_output_pre_commit_line`, etc.), ensuring users can clearly see where lanes have been hidden. The '~' was chosen as it doesn't conflict with existing graph characters. The documentation is updated to reflect this visual indicator, and the test suite is modified to expect the new output format.

This completes the series' three-phase structure (core behavior -> user option -> visual polish) as suggested by Johannes Sixt. With all technical feedback from prior versions addressed and the maintainer now focused on cultural onboarding rather than code changes, this feature appears ready for inclusion. The patch maintains the series' thorough test coverage while adding the final user-visible element to make truncation behavior obvious.
