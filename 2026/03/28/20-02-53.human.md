This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite reliability. The patch continues the pattern seen in previous patches of the series, converting a direct pipe to grep into a temporary file plus test_grep assertion in t1400-update-ref.sh.

The change specifically updates a test case that verifies worktree-specific refs in refs/bisect/. The original test piped `git for-each-ref` output directly to grep, which could mask Git's exit code if the command failed. The new version writes the output to a file first, then uses test_grep to check for the expected ref, preserving any error codes from the Git command.

This follows the same mechanical but important improvement seen in the series' prior patches (t0100, t2206, etc.) - a straightforward change that makes the test more robust by ensuring failures aren't silently ignored. The patch maintains all existing assertions while just changing how they're verified. Like the rest of the series, it's a focused reliability improvement with no behavior changes to Git itself.
