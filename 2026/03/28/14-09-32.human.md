This is a refactoring patch that's part of the ongoing `the_repository` removal effort. It's the first in a 5-part series from Shreyansh Paliwal that makes branch name helper functions explicitly repository-aware by adding `struct repository*` parameters.

The patch focuses on `copy_branchname()` and related functions in refs.c, which previously relied on the global `the_repository`. The changes propagate through several callers in builtin commands (branch, checkout, worktree), making them pass repository context explicitly. The modifications are mechanical but wide-ranging, touching multiple files while maintaining existing behavior.

This version (v2) incorporates feedback from Patrick Steinhardt to place the repository parameter first in function signatures, following codebase conventions. The changes build on previous work (jw/object-name-bitset-to-enum) and represent incremental progress in the long-running effort to eliminate global state from Git's codebase. The patch appears well-structured and focused, with clean diffs that suggest careful attention to detail.
