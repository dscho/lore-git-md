This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite. It's patch 8/16 in a series that systematically replaces direct command piping in tests with temporary files and `test_grep` assertions, ensuring Git command failures aren't masked by pipe behavior.

The patch updates t4150-am.sh to modify a test case that verifies multi-line email headers in `git am`. The original test piped `git cat-file` output directly to grep, which could hide Git command failures. The new version writes the output to a temporary file first, then uses `test_grep` to check for expected content - a pattern seen in earlier patches in the series.

This change follows the same mechanical but important improvement seen throughout the series: better test reliability without modifying actual Git behavior. The transformation is straightforward and consistent with prior work, making it easy to review. As with other patches in the series, this appears to be a clean, focused improvement to test infrastructure.
