This is a test modernization patch from Trieu Huynh, part of a 2-patch GSoC series. The patch updates t8003-blame-corner-cases.sh to avoid suppressing Git's exit codes by redirecting `git blame` output to temporary files rather than piping it directly. This ensures test failures from crashes or errors in Git commands won't be masked by the pipe.

The changes are mechanical but important for test reliability - each `git blame` command that previously piped to `grep` now writes to a temporary file first, then checks the file with `test_grep`. The patch maintains all existing test assertions while making the test suite more robust by properly checking command exit statuses.

The changes are straightforward and well-contained, touching only the test file. This appears to be a quality-of-life improvement for the test suite rather than fixing any specific bug. As part of a GSoC project, it shows good attention to test hygiene details.
