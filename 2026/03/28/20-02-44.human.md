This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite. The patch continues their series that replaces direct command piping in tests with temporary files and `test_grep` to properly capture Git's exit codes.

The change modifies t6006-rev-list-format.sh to test rev-list format placeholders more reliably. Instead of piping `git rev-list` output directly to grep (which could mask Git failures), it now writes to a temporary file and uses `test_grep` to verify the output. The test checks that "%S" isn't yet a valid placeholder by looking for the literal "%S" in the output.

This follows the same pattern seen in their earlier patches (t0100, t2206, t7004 etc.) - a straightforward, mechanical change that improves test reliability without modifying any actual Git behavior. The patch appears clean and focused, continuing the consistent approach established in the series. No functional changes to Git itself - just better test hygiene.
