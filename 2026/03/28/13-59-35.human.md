This is a test improvement patch from Trieu Huynh, part of their Google Summer of Code (GSoC) work. The change modifies t6101-rev-parse-parents.sh to properly capture the exit code of `git rev-parse` commands in the test suite.

Currently, the test pipes `git rev-parse` output directly to grep, which means if `git rev-parse` fails, the test would only see grep's exit code. The patch changes this to first redirect output to a temporary file, then use `test_grep` to check the contents, ensuring any failure in `git rev-parse` itself will be caught.

This is a small but thoughtful change that follows Git's test suite best practices. The commit message clearly explains the motivation (avoiding unnoticed crashes) and the solution. The patch is cleanly focused on just this one test case, suggesting it may be part of a larger effort to modernize test patterns across the suite.
