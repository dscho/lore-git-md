This is a test modernization patch from Trieu Huynh, part of their Google Summer of Code project to improve Git's test suite. The patch updates t2206-add-submodule-ignored.sh to avoid piping Git command output directly to grep, which could mask command failures. Instead, it redirects output to temporary files and uses test_grep for assertions.

The changes are mechanical but important for test reliability, particularly in submodule tests where some operations run in nested repositories. The patch handles this by writing temporary files outside inner repos (as '../actual') to prevent accidental staging. It follows the same pattern seen in previous patches in the series, converting direct grep checks to use test_grep while maintaining all test assertions.

This continues the consistent, incremental improvement approach seen throughout the series. The changes are focused solely on test infrastructure - no Git functionality is modified. The patch appears well-executed and maintains the test's original coverage while making it more robust.
