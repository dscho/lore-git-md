Siddharth Asthana's implementation of dynamic mailmap toggling for `git cat-file --batch-command` is finalized and ready for merging. The feature adds a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) to control name/email rewriting dynamically during operation, addressing GitLab Gitaly's need to modify mailmap behavior in long-running processes without restarting.

Technical implementation includes lazy-loaded mailmap data caching (loaded on first use and preserved when disabled), restructured dispatch logic in `builtin/cat-file.c` with unified `parse_cmd_mailmap` function using `git_parse_maybe_bool()`, and comprehensive test coverage in `t/t4203-mailmap.sh`. The interface is documented with the subtle difference from Git config syntax where the argument cannot be omitted to mean "true" and empty strings are interpreted as "false".

Junio Hamano has approved the implementation and test coverage while suggesting final documentation polish to focus on user-visible behavior rather than implementation details. The revised documentation will emphasize the core functionality (toggling mailmap application) and one-time data loading behavior while de-emphasizing internal caching mechanics. All review feedback from Patrick Steinhardt (boolean parsing), Karthik Nayak (documentation structure), and Jean-Noël Avila (AsciiDoc formatting) has been incorporated. The changes remain well-contained to `builtin/cat-file.c` and its tests, with consensus established on both technical implementation and documentation. The series is now fully complete and ready for merging into Git's mainline.
