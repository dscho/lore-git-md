This is a test modernization patch from Trieu Huynh, part of their Google Summer of Code project to improve Git's test suite. The patch updates t2206-add-submodule-ignored.sh to avoid piping Git command output directly to grep, which could mask exit codes if Git crashes. Instead, it redirects output to temporary files (written as '../actual' to avoid staging in nested repos) and uses test_grep to verify the output.

The changes are mechanical but important for test reliability, following the same pattern seen in previous patches in the series. This particular test file deals with submodule behavior when adding and checking status of ignored submodules. The patch maintains all existing assertions while making them more robust by properly checking Git's exit status.

This continues the consistent approach seen across the series, with special handling for nested repository cases where temporary files must be written outside inner repos to avoid accidental staging. The changes are focused on test infrastructure improvements without modifying Git's functionality.
