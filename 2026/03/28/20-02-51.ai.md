This is a test modernization change from Trieu Huynh as part of their GSoC project, continuing the series to improve test reliability by avoiding command piping that could mask exit codes. The patch updates t3701-add-interactive.sh to redirect Git command output to temporary files rather than piping directly to grep, ensuring test failures aren't silently ignored.

The changes follow the established pattern seen in previous patches in the series: replacing `git cmd | grep` patterns with `git cmd >actual && test_grep pattern actual`. This affects two test cases in the interactive add tests - one verifying filemode changes during partial staging, and another checking staged vs unstaged changes. The modifications are mechanical and maintain all existing assertions while making the tests more robust.

The patch maintains consistency with the series' approach, showing the same transformation applied to the interactive add tests as was done for other test files. No special handling was needed here beyond the standard pattern, unlike some earlier patches that dealt with nested repositories. This continues the incremental improvement of Git's test suite reliability.
