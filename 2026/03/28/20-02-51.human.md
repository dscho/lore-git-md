This is a test modernization patch from Trieu Huynh as part of their GSoC project, continuing the series to improve test reliability by avoiding command piping that could mask exit codes. 

The patch updates t3701-add-interactive.sh to redirect `git show` and `git diff` output to temporary files rather than piping directly to grep. This ensures test failures won't be hidden by pipe behavior. The changes follow the established pattern seen in previous patches, converting direct grep checks to use `test_grep` against captured output files.

The modifications touch two test cases that verify interactive add behavior with file modes, ensuring the tests continue to check both content and mode changes while being more robust about detecting command failures. Like others in the series, this is a mechanical but worthwhile improvement to test infrastructure reliability.
