This is a feature patch adding dynamic mailmap toggling to `git cat-file --batch-command`. Currently, mailmap support can only be enabled when starting the process, which is limiting for long-running processes like those used by GitLab's Gitaly service.

The patch introduces two new subcommands - `use-mailmap` and `no-use-mailmap` - that allow toggling mailmap processing mid-operation. The mailmap data is loaded lazily on first use and kept in memory when disabled, avoiding repeated disk reads when re-enabling. The implementation adds the new command handlers while maintaining backward compatibility with existing usage.

The changes are well-contained, touching just the cat-file command implementation and its documentation. The patch includes thorough test coverage of the new functionality, including verification that it works correctly with buffered output. The commit message clearly explains the motivation (GitLab's caching needs) and the solution approach.
