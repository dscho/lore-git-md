Siddharth Asthana proposed adding dynamic mailmap toggling to `git cat-file --batch-command` to better support long-running processes like GitLab's Gitaly service. The initial implementation introduced separate `use-mailmap` and `no-use-mailmap` subcommands, with tests verifying behavior in different modes.

Junio C Hamano has now weighed in, acknowledging the feature's usefulness but suggesting a simpler interface - a single `mailmap` command accepting `yes`/`no` parameters instead of two separate commands. He also raised an implementation question about whether cached mailmap data should be cleared when disabled. The feedback is constructive, focusing on API clarity rather than rejecting the concept outright. The thread now awaits the author's response addressing these points, which will likely shape the next version of the patch.
