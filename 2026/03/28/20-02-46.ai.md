This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test reliability. The patch modifies t4153-am-resume-override-opts.sh to avoid masking Git command exit codes by replacing a direct pipe to grep with temporary file output and test_grep.

The change follows the established pattern seen in previous patches in this series - converting `git cmd | grep` patterns to first write output to a file, then using test_grep to verify the content. In this case, it updates a test that verifies signoff behavior in `git am`, ensuring any failure in `git cat-file` would now be properly detected rather than potentially hidden by the pipe.

The modification is straightforward and mechanical, matching the approach taken in earlier patches for t0100, t2206, and others. The patch maintains the same test assertions while improving failure detection, continuing the series' focus on making the test suite more robust by eliminating problematic command piping patterns.
