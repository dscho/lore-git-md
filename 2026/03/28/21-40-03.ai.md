This is a feature patch adding TypeScript support to Git's built-in userdiff patterns, part of Dhruv Arora's GSoC contribution. The patch introduces a regex pattern in userdiff.c that recognizes common TypeScript syntax constructs including function declarations (with optional export/async modifiers), class definitions, and variable assignments with const/let/var.

The pattern follows Git's existing userdiff infrastructure and handles typical TypeScript syntax like `export class`, `async function`, and arrow function assignments. The implementation is straightforward, adding the new pattern alongside similar ones for other languages like Ruby and Rust. While the pattern appears comprehensive for basic cases, real-world TypeScript usage may reveal additional edge cases that could be addressed in follow-up patches.

This is the first of two patches in the series, with the subsequent one organizing the pattern alphabetically and adding test cases. As a self-contained GSoC contribution, this looks like a well-scoped addition that fills a gap in Git's language support - TypeScript was previously missing dedicated patterns despite being widely used in the ecosystem.
