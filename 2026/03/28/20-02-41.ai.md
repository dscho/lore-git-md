This is a test modernization change from Trieu Huynh's GSoC patch series, specifically targeting the merge-rename test file t6423. The patch follows the established pattern seen in earlier parts of the series - replacing a direct pipe to grep with temporary file output and test_grep assertions to preserve Git's exit codes.

The change modifies one test case in t6423-merge-rename-directories.sh that was checking file modes after a merge. The original test piped `git ls-files` output directly to grep, which could mask a Git command failure. The new version writes the output to a temporary file first, then uses test_grep to verify the expected mode bits (100755) appear in the output.

This is a mechanical but important reliability improvement that matches the approach used in other test files (t0100, t2206, t7004) earlier in the series. The change maintains the same test assertions while making the test more robust by properly propagating Git command failures. Like the other patches in the series, this focuses narrowly on test infrastructure without modifying any Git command behavior.
