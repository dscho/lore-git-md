This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite. The patch continues the series' pattern of replacing direct command output piping with temporary files and `test_grep` assertions to properly capture Git command exit codes.

The specific change modifies t4140-apply-ita.sh to test Git's handling of intent-to-add files during patch application. The key modification replaces a `git diff | grep` pipe with a two-step process: first writing the diff output to a temporary file, then using `test_grep` to verify the expected pattern. This ensures any failure in `git diff` itself would be caught rather than potentially masked by the pipe.

The change follows the same mechanical but important pattern seen in previous patches in the series (t0100, t2206, t7004, etc.), maintaining consistency across the test suite modernization effort. The patch is narrowly focused on test infrastructure reliability without modifying any actual Git command behavior.
