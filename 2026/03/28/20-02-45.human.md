This is a test modernization patch from Trieu Huynh, part of their Google Summer of Code project to improve Git's test suite. It's patch 6 in a 16-part series that systematically replaces direct command piping in tests with temporary files and `test_grep` to ensure Git's exit codes aren't masked.

The patch modifies t5304-prune.sh to change how it verifies that loose objects are gone after repacking. Instead of piping `git count-objects` directly to grep (which would hide any failure in the Git command itself), it now writes the output to a file and uses `test_grep` to check the content. This follows the same pattern seen in earlier patches in the series (t0100, t2206, t7004 etc.) and matches the established approach from t8003.

The change is mechanical but important - it makes the test more reliable by properly surfacing any failures in the Git commands being tested. The patch appears clean and focused, continuing the consistent approach seen across the series. No behavior of Git itself is changed - this is purely a test infrastructure improvement.
