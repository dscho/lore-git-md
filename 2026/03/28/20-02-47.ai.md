This is a test modernization patch from Trieu Huynh, part of their ongoing Google Summer of Code (GSoC) project to improve Git's test suite. The patch continues the series' pattern of replacing direct command output piping with temporary files and `test_grep` assertions to ensure Git command failures aren't masked.

The specific change updates t4150-am.sh, which tests for `git am` functionality. The patch modifies a test case that verifies multi-line email headers in commit messages. Previously, it piped `git cat-file` output directly to grep, which could hide Git command failures. The new version writes the output to a temporary file first, then uses `test_grep` to check for the author email and message content patterns.

This follows the same mechanical but important improvement pattern seen in earlier patches in the series (t0100, t2206, t7004, etc.). The change maintains all existing assertions while making the test more robust by properly propagating Git command exit codes. Like the other patches in the series, this is a focused reliability improvement that doesn't modify any actual Git behavior - it just makes the test suite more dependable.
