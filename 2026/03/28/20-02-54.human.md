This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test suite. It's patch 15/16 in a series that addresses a common issue where piping Git command output directly to other commands (like grep) can mask Git's exit code, potentially hiding test failures.

The specific change here modifies t0100-previous.sh to replace a direct pipe to grep with a temporary file and `test_grep` call. The test verifies merge behavior with `@{-1}` syntax, and the update ensures any failure in `git cat-file` would now be properly reported rather than potentially being hidden by the pipe. 

This follows the same pattern seen throughout the series - mechanical but important changes that make the test suite more reliable. The patch is small and focused, just converting one test case while maintaining all existing assertions. Like the rest of the series, it's a basic infrastructure improvement rather than modifying any Git behavior.
