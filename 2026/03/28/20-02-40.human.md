This is a test modernization patch from Trieu Huynh, part of a 16-patch GSoC series improving test reliability by eliminating command piping that could mask Git's exit codes. 

The patch updates t7004-tag.sh to redirect Git command output to temporary files rather than piping directly to grep, ensuring test failures won't be hidden. Two test cases are modified to use `test_grep` on the captured output instead of piping to grep. The changes follow an established pattern seen in other test files (like t8003) and are purely mechanical - no behavior changes beyond making test failures more detectable.

This is the first patch in a well-scoped series that systematically applies this reliability improvement across the test suite. The approach is straightforward and consistent with prior work in this area, making it easy to review. The changes are low-risk since they only affect test infrastructure without modifying actual Git behavior.
