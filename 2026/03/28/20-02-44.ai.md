This is a test modernization patch from Trieu Huynh, part of their GSoC project to improve Git's test reliability. The patch continues the series' pattern of replacing direct command piping with temporary files + test_grep to properly capture Git command exit codes.

The change modifies t6006-rev-list-format.sh to update one test case checking rev-list format placeholders. Instead of piping `git rev-list` output directly to grep (which could mask Git failures), it now writes to a temporary file and uses test_grep to verify the output contains "%S". This matches the approach taken in prior patches for t0100, t2206, and others.

The modification is straightforward and mechanical - just converting one test case to the more robust pattern. Like the rest of the series, it improves test reliability without changing any Git behavior. The patch follows the established style seen in earlier parts of the series, making it easy to review alongside the other test modernization changes.
