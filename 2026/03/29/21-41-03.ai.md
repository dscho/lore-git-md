This is a feature patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, introducing a new `--checksum-only` flag for MIDX writes. The patch allows writing new MIDX layers without immediately modifying the MIDX chain file, giving callers more control over when the chain is updated.

The key change is the new `MIDX_WRITE_CHECKSUM_ONLY` flag that, when combined with `--incremental`, causes `git multi-pack-index write` to:
1. Write the new MIDX layer to the multi-pack-index.d directory
2. Print its checksum to stdout
3. Skip updating the multi-pack-index-chain file

This enables atomic updates where callers can assemble multiple layers before committing the final chain. The patch includes documentation updates, implementation in midx-write.c, and tests verifying both successful operation and the required `--incremental` constraint.

The change fits into the larger repacking strategy by allowing the repack machinery to build up a new MIDX chain incrementally before atomically switching to it. The implementation is careful to maintain existing behavior when the flag isn't used, and the new tests cover both the happy path and error cases. This is a focused, well-tested addition to the MIDX infrastructure that enables the more complex repacking behavior in later patches.
