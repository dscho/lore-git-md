This is a feature patch in Taylor Blau's series introducing incremental MIDX/bitmap-based repacking. Patch 15/16 exposes the new incremental repacking mode via a `--write-midx=incremental` option for `git repack`, completing the user-facing interface for this multi-year effort.

The patch adds configuration knobs (`repack.midxSplitFactor` and `repack.midxNewLayerThreshold`) to control the MIDX layer compaction behavior, with sensible defaults. It integrates the incremental mode with geometric repacking by setting layer thresholds that determine which packs are considered for repacking. The implementation carefully handles edge cases like kept packs and no-op repacks.

A comprehensive test suite verifies the new functionality across various scenarios: layer threshold behavior, geometric progression preservation, multi-layer compaction, and cleanup of stale MIDX chains. The tests demonstrate how the incremental strategy maintains logarithmic scaling by only rewriting newer layers while leaving older, larger layers mostly untouched.

This represents the culmination of Taylor's work to improve Git's scalability for large repositories, building on previous refactoring of repack.c and MIDX layer compaction. The series appears well-tested and ready for final review, with this patch providing the last piece needed for users to benefit from the new incremental repacking strategy.
