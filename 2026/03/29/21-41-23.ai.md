This is a bugfix patch in Taylor Blau's incremental MIDX/bitmap-based repacking series. It addresses a memory leak in the packfile revindex handling that was discovered while implementing the new MIDX bitmap writing functionality.

The patch fixes a long-standing issue where in-memory revindexes (used when on-disk .rev files are unavailable) were never freed. The leak becomes apparent with the new test cases being added in the series. The fix is straightforward - adding a `FREE_AND_NULL()` call in `close_pack_revindex()` to properly clean up the `p->revindex` field.

This is a small but important cleanup that ensures proper resource management as part of the larger MIDX/bitmap work. The change is mechanical and low-risk, affecting only the packfile subsystem's memory management. It demonstrates the careful attention to edge cases and resource cleanup that characterizes this series. The patch follows the project's pattern of fixing discovered issues even when they predate the current work.
