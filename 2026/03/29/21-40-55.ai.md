This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series. It improves the handling of retained MIDX files by replacing hand-rolled arrays with `string_list` structures.

The patch modifies two functions that clean up stale MIDX files while preserving certain ones - `clear_midx_files_ext()` and `clear_incremental_midx_files_ext()`. Previously these used manual array management with separate length tracking, requiring linear lookups. The new version uses Git's `string_list` abstraction, which provides built-in string handling and lookup capabilities.

Key changes include:
- Replacing the `keep` array and `keep_nr` counter with a single `string_list keep` field in `struct clear_midx_data`
- Using `string_list_has_string()` for lookups instead of manual iteration
- Simplifying memory management through `STRING_LIST_INIT_DUP`/`STRING_LIST_INIT_NODUP` and `string_list_clear()`
- Removing manual allocation/free cycles in favor of string_list's memory handling

While the performance impact is likely negligible given the small number of files involved, the change makes the code more maintainable by using Git's standard string handling utilities. The patch fits cleanly into the larger series by improving the MIDX file management infrastructure that the incremental repacking strategy relies upon.
