This is a refactoring patch in Taylor Blau's ongoing series to improve Git's repacking strategy for large repositories. It's part 10 of 16 in the incremental MIDX/bitmap-based repacking effort.

The patch extracts the pack-writing logic from `write_midx_included_packs()` into a new helper function `repack_fill_midx_stdin_packs()`. This helper handles the `--stdin-packs` argument setup, command execution, and writing pack names to stdin when running `git multi-pack-index write`. The change is purely organizational - no behavior changes - but prepares for a future patch that will need to capture the MIDX checksum from stdout.

The code remains clean and focused, following the series' pattern of careful refactoring before adding new features. The patch touches only repack-midx.c and maintains all existing functionality while improving the code structure for upcoming changes in the series.
