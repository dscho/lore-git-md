This is a bugfix patch in Taylor Blau's ongoing series to improve MIDX/bitmap-based repacking. It addresses a memory leak in the packfile revindex handling that was discovered while implementing incremental MIDX repacking.

The patch fixes a case where Git would keep allocated memory for in-memory revindexes (used when packs lack on-disk *.rev files) without properly freeing it. The leak wasn't previously noticed because the test suite didn't check for this case until the new MIDX work exposed it. The fix is straightforward - adding a `FREE_AND_NULL()` call in `close_pack_revindex()` to clean up the revindex memory.

This is a small but important cleanup that prevents resource leaks in the packfile subsystem. It's part of the larger effort to make MIDX-based repacking more robust, particularly for large repositories where memory management matters. The change is well-contained and clearly motivated by the upcoming MIDX bitmap work in the series.
