Feature addition to `git cat-file`'s batch mode, implementing the simplified mailmap toggling interface.

This patch from Siddharth Asthana finalizes the dynamic mailmap control for `git cat-file --batch-command` by implementing the simplified interface suggested by Junio C Hamano. The new `mailmap` subcommand accepts `yes`/`no` arguments to toggle mailmap processing on the fly, replacing the previous dual-command approach. The implementation maintains mailmap data caching when disabled to avoid reload costs, addressing GitLab's Gitaly service needs where long-running processes must toggle mailmap without restarting.

The changes touch three main areas: documentation updates explaining the new subcommand, the dispatch logic in `builtin/cat-file.c` (now with a single `parse_cmd_mailmap` function), and expanded test coverage in `t/t4203-mailmap.sh`. The tests verify mid-stream toggling works in both buffered and unbuffered modes, with correct size reporting for mailmap-transformed output. The patch appears cleanly implemented with no obvious technical issues, completing the refinement cycle from the initial proposal through to this production-ready version.
