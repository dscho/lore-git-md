This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series. It renames an internal helper function from `midx_contains_pack_1()` to the more descriptive `midx_layer_contains_pack()` and exposes it in midx.h for use by subsequent patches in the series.

The key change is making this single-layer check available to callers, while keeping the existing recursive `midx_contains_pack()` function (which checks all layers in the MIDX chain) unchanged. The new name better reflects the function's purpose - checking pack membership within a specific MIDX layer rather than the entire chain.

This is a small but meaningful step in the larger incremental repacking work, preparing for a future patch that needs to distinguish between packs in the tip MIDX layer versus older layers. The change is straightforward with no behavior modifications, just improved naming and visibility of an existing capability. The patch touches only midx.c and midx.h, maintaining the same binary search implementation for pack lookup but making it reusable in new contexts.
