This is the final patch in Taylor Blau's 16-part series introducing incremental MIDX/bitmap-based repacking. The series represents the completion of a multi-year effort to improve Git's repacking strategy for large repositories.

The patch relaxes a previous restriction that required `--write-midx=incremental` to be used with `--geometric`. Now, incremental MIDX repacking can operate in an append-only mode without geometric repacking. In this mode, each repack simply adds a new MIDX layer containing the freshly written packs while preserving all existing layers unchanged. This provides a simpler alternative to the full geometric compaction strategy when needed.

The implementation introduces a new `repack_make_midx_append_plan()` function that builds a plan consisting of a WRITE step for new packs followed by COPY steps for existing MIDX layers. The existing compaction logic remains available when `--geometric` is used. The documentation is updated to clearly describe both modes of operation, and tests are added to verify the append-only behavior.

This change makes the incremental MIDX feature more flexible while maintaining all the benefits of the geometric compaction strategy when desired. The patch appears well-integrated with the rest of the series and includes appropriate test coverage. As the final piece of this major architectural improvement, it helps ensure the new repacking strategy can be adopted in a variety of repository maintenance scenarios.
