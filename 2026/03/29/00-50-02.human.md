Maintainer feedback on dynamic mailmap toggling for `git cat-file`.

Junio C Hamano responds to Siddharth Asthana's patch adding mailmap toggling to `git cat-file --batch-command`. While not rejecting the feature outright, Junio suggests a simpler implementation approach - using a single `mailmap` command that takes a yes/no parameter rather than separate `use-mailmap`/`no-use-mailmap` commands. He notes this would reduce boilerplate code and make the interface more intuitive.

Junio also raises an important technical question about whether cached mailmap data should be flushed when disabled, which wasn't addressed in the original proposal. This suggests the patch may need revision to clarify memory management behavior before proceeding.

The feedback indicates the core functionality is sound but the interface could be refined. Siddharth will likely need to send a v2 addressing these points, particularly the command structure and cache behavior. The use case (GitLab's Gitaly service needing dynamic mailmap control) remains valid and uncontentious.
