This is part 7 of Taylor Blau's 16-patch series introducing incremental MIDX/bitmap-based repacking. The patch refactors how the repack machinery tracks the object database (ODB) source by moving the storage from `repo->objects->sources` into the `existing_packs` struct.

The change serves two purposes: first, it prepares for the incremental MIDX work by making the ODB source available where it will be needed to read existing MIDX/chain data. Second, it future-proofs the code for potential support of multiple object sources in repack operations. The patch is purely structural - the actual source used remains the same (still taken from the first source in the list) - but centralizes access through the `existing_packs` structure that already manages other pack-related state.

The changes touch three files: `builtin/repack.c` updates two call sites to use the new location, `repack.c` adds the source assignment during pack collection, and `repack.h` adds the new field to the struct. This appears to be a straightforward preparatory change that follows the series' pattern of careful refactoring before introducing new functionality.
