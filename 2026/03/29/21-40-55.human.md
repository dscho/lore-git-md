This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series. It simplifies the manual array management in MIDX file cleanup functions by switching to Git's `string_list` utility.

The patch replaces two functions (`clear_midx_files_ext` and `clear_incremental_midx_files_ext`) that previously used hand-rolled arrays to track which MIDX files to keep during cleanup. The new version uses `string_list` instead, which:
- Eliminates the need to pass array lengths separately
- Provides built-in string comparison and sorting
- Handles memory management automatically
- Makes the code more idiomatic to Git's codebase

While the performance impact is negligible (the arrays are typically small), this change makes the code more maintainable and consistent with Git's conventions. The patch is part of the larger MIDX repacking effort but stands as a clean, focused improvement to the code structure.
