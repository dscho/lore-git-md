Feature patch adding `--include-untracked` support to `git stash create`.

This RFC patch from Shabbir Bhojani extends `git stash create` to support the `--include-untracked` flag, matching the existing functionality in `git stash push`. The change allows creating stash entries that include untracked files without modifying the working directory - a workflow the author found useful when their development tools reacted poorly to the working directory changes caused by regular stash operations.

The implementation:
- Adds the new flag to the `create_stash` function
- Skips the tracked changes check when the flag is set
- Passes the flag through to `do_create_stash`
- Includes tests verifying the behavior
- Updates documentation to reflect the new option

The patch appears well-constructed with:
- Clear commit message explaining both the technical change and user motivation
- Comprehensive test coverage
- Documentation updates
- Clean implementation following existing patterns

This seems like a reasonable quality-of-life improvement, particularly for users who want to snapshot their working state (including untracked files) without disturbing their editor/IDE. The RFC tag suggests the author is open to feedback on the approach before finalizing the change.
