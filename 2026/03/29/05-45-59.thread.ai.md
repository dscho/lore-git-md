[PATCH] builtin/repo: remove implicit the_repository dependency in get_layout_*()

This patch by Naorem Ngathoiba Singh (GSoC participant) continues the `the_repository` removal effort by refactoring `get_layout_bare()` and `get_layout_shallow()` in `builtin/repo.c` to take an explicit `struct repository *` parameter instead of relying on the global `is_bare_repository()` macro. The change supports multi-repository compatibility by eliminating implicit global state access. This is the author's first technical patch after withdrawing an earlier documentation patch (which had example identifier confusion). The current change is small, focused, and correctly motivated - exactly the incremental type of improvement needed for the ongoing `the_repository` removal project. While the commit message could be more detailed about the specific function changes (it currently focuses somewhat on the withdrawn doc patch), the technical implementation appears sound and aligns with the project's architectural direction toward removing global state dependencies.
