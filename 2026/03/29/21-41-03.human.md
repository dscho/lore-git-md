This is a feature patch in Taylor Blau's series on incremental MIDX/bitmap-based repacking, introducing a new `--checksum-only` flag for MIDX writes. The flag allows writing a new MIDX layer without immediately updating the chain file, giving callers more control over atomic updates.

The patch adds the flag to both `write` and `compact` subcommands of `git multi-pack-index`, requiring it to be used with `--incremental`. When enabled, it writes the new MIDX layer to disk, prints its checksum, but leaves the chain file untouched. This is particularly for the repacking strategy that wants to assemble multiple new layers before atomically updating the chain.

The implementation touches the MIDX writing logic to conditionally skip chain file updates when the flag is set, while maintaining all other functionality. It includes tests verifying the new behavior - both successful cases where the chain remains unchanged after a checksum-only write, and error cases when the flag is misused without `--incremental`.

This appears to be a well-constructed plumbing change that provides the necessary building block for the larger repacking strategy, with careful attention to atomicity and error handling. The patch follows the series' pattern of incremental improvements to the MIDX infrastructure.
