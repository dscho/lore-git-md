This is a refactoring patch in Taylor Blau's 16-part series on incremental MIDX/bitmap-based repacking. The patch extracts the pack-writing logic from `write_midx_included_packs()` into a new helper function `repack_fill_midx_stdin_packs()`.

The change cleanly separates the concerns of:
1. Setting up the MIDX write command (remaining in the original function)
2. Actually executing the command with pack names piped to stdin (moved to the new helper)

The motivation is to prepare for a future change where this helper will be reused to capture the MIDX checksum from stdout when using `--checksum-only` mode. The patch maintains identical behavior while improving code organization - a typical preparatory refactoring in a larger series.

The change is focused on `repack-midx.c` and as noted in the commit message, introduces no functional changes. It follows the series' careful attention to maintainability as the MIDX repacking functionality grows in complexity. This continues the pattern seen in earlier patches of breaking down complex operations into smaller, more focused helper functions.
