This is part 12 of Taylor Blau's 16-patch series introducing incremental MIDX/bitmap-based repacking, a major scalability improvement for large repositories. The series builds on previous work refactoring Git's repack machinery.

This patch converts the `--write-midx` (`-m`) flag from a simple boolean to a callback that can accept optional mode arguments. It introduces an enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states, updating all boolean checks accordingly. The change maintains backward compatibility while preparing for future additions - currently just passing `-m` uses the default mode, but the infrastructure is now in place to support different MIDX-writing strategies.

The patch shows careful attention to detail, with thorough updates to all affected code paths and a new dispatcher function `repack_write_midx()` that will select the appropriate MIDX-writing implementation based on the mode. This is a preparatory change for the incremental MIDX strategy that will be introduced later in the series. The work continues the series' pattern of clean, well-structured refactoring that builds incrementally toward the final feature.
