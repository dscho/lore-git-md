This is a refactoring patch in Taylor Blau's ongoing series to improve Git's repacking strategy for large repositories. It's part 9 of 16 in the incremental MIDX/bitmap-based repacking effort.

The patch extracts common MIDX command preparation logic into a new helper function `repack_prepare_midx_command()`. This function handles the boilerplate setup for both `write` and `compact` subcommands of `git multi-pack-index`, including progress reporting and bitmap options. The patch leaves subcommand-specific arguments (like `--stdin-packs`) to be handled by the caller.

This is a clean, mechanical refactor with no behavior changes - the kind of preparatory work that makes the subsequent patches implementing the actual repacking strategy easier to read and maintain. The change touches only `repack-midx.c`, moving code around rather than adding new functionality. It's a typical intermediate step in a larger series, factoring out shared logic before introducing new callers in later patches.
