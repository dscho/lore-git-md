This is a refactoring patch in Taylor Blau's series on incremental MIDX/bitmap-based repacking. It renames an internal helper function from `midx_contains_pack_1()` to the more descriptive `midx_layer_contains_pack()` and exposes it in the midx.h header. The key difference is that this function checks only a single MIDX layer, whereas the existing `midx_contains_pack()` recursively checks the entire chain.

The change is purely mechanical with no behavior modification - it's preparation for a subsequent patch that will need to check pack membership in just the tip layer rather than the full chain. The patch touches only midx.c and midx.h, with straightforward renaming and header exposure. This continues the series' pattern of careful, incremental refactoring to support the larger architectural changes around MIDX handling.
