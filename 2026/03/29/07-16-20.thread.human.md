This RFC patch series from Shabbir Bhojani proposes adding `--include-untracked` support to `git stash create`, allowing developers to create stash entries containing untracked files without modifying the working directory. This addresses workflow issues where development tools (particularly IDEs and editors) can react poorly to working directory changes from regular stash operations.

The implementation follows existing stash subsystem patterns, adding the new flag to relevant functions and including comprehensive test coverage in t3903-stash.sh along with matching documentation updates. The patch demonstrates good hygiene with clear commit messages and thorough testing.
