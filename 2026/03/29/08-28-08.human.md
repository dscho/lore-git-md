Feature addition to `git cat-file`'s batch mode, now implementing the simplified mailmap toggling interface.

Siddharth Asthana's patch adds a `mailmap` subcommand to `git cat-file --batch-command`, allowing dynamic toggling of mailmap processing during a long-running batch operation. This addresses GitLab's Gitaly use case where cached `git cat-file` processes need to switch mailmap behavior without restarting. The implementation follows Junio C Hamano's suggestion to use a single `mailmap` command with `yes`/`no` arguments rather than separate enable/disable commands.

The patch maintains mailmap data in memory when disabled to avoid reload costs when re-enabled, while updating the command dispatch table in `builtin/cat-file.c` to handle the new subcommand. Test cases verify the mid-stream toggling works correctly, including in buffered mode. The changes are cleanly contained to the batch command subsystem with no unexpected side effects.

This appears ready for merging - it solves a real use case with a straightforward implementation, has thorough test coverage, and incorporates maintainer feedback effectively. The thread shows good collaboration between contributor and maintainer to refine the interface.
