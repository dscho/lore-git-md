Maintainer feedback on mailmap toggling patch.

Junio C Hamano responds to Siddharth Asthana's patch adding dynamic mailmap toggling to `git cat-file --batch-command`. While acknowledging the usefulness of the feature for GitLab's Gitaly service, Junio suggests simplifying the interface by using a single `mailmap` command that takes a `yes`/`no` parameter rather than separate `use-mailmap` and `no-use-mailmap` commands. He also raises a question about whether cached mailmap data should be flushed when disabled, pointing out this isn't addressed in the current design.

The maintainer's feedback focuses on API design clarity and implementation details rather than rejecting the concept. His suggestion would reduce code duplication in the command dispatch table and potentially make the interface more intuitive. This appears to be a constructive review pointing toward incremental improvement rather than fundamental objections to the feature itself. The thread is now waiting for the author to respond with either a revised implementation or justification for the current approach.
