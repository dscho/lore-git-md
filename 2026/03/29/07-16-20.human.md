Feature patch adding `--include-untracked` support to `git stash create`.

Shabbir Bhojani proposes adding the `--include-untracked` flag to `git stash create`, matching functionality already available in `git stash push`. The motivation comes from workflow needs - the author wants to snapshot working directory state (including untracked files) without the working directory cleanup/restore cycle that `stash push` performs, which can trigger unwanted rebuilds in development tools.

The implementation:
- Adds the flag parsing to `create_stash()`
- Skips the tracked changes check when the flag is set
- Passes the flag through to `do_create_stash()`
- Includes tests verifying the behavior with and without the flag
- Updates documentation to reflect the new option

The patch appears well-constructed with clear commit message, tests, and documentation updates. The change is relatively small and focused, touching only the stash subsystem. The rationale is practical and the implementation approach seems sound. This would be a useful addition for users who want to create stashes without disturbing their working directory state.
