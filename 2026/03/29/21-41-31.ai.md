This is the final patch in Taylor Blau's 16-part series introducing incremental MIDX/bitmap-based repacking. The patch relaxes a previous restriction that required `--write-midx=incremental` to be used with `--geometric`, allowing the incremental MIDX repacking mode to work independently.

When used without `--geometric`, the behavior becomes append-only: a new MIDX layer is created containing the freshly written packs and appended to the existing chain (or starts a new chain), while existing layers remain unchanged. This contrasts with the geometric mode which performs compaction of adjacent layers. The implementation introduces a new `repack_make_midx_append_plan()` function to handle this case, while continuing to use the existing compaction plan when `--geometric` is active.

The patch updates documentation to clarify both modes of operation and replaces the test that enforced the old restriction with one verifying the new append-only behavior. This change makes the incremental MIDX feature more flexible, allowing simpler use cases where geometric compaction isn't needed while maintaining all the existing functionality when it is.

This completes Taylor's multi-year effort to improve Git's repacking strategy for large repositories, with the series now ready for final review. The work touches `builtin/repack.c`, `repack-midx.c`, documentation, and tests, with careful attention to maintaining backward compatibility and adding appropriate test coverage.
