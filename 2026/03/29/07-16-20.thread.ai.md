RFC patch series introducing `--include-untracked` support for `git stash create`. Authored by Shabbir Bhojani, this adds functionality to create stash entries containing untracked files without modifying the working directory - addressing workflow issues where development tools react poorly to working directory changes from regular stash operations.

Implementation details:
- New `--include-untracked` flag added to `create_stash` function
- Tracked changes check bypass when flag is active
- Flag propagation to `do_create_stash`
- Test coverage in t3903-stash.sh verifying behavior
- Documentation updates in Documentation/git-stash.txt

Technical approach follows existing patterns in the stash subsystem. The patch demonstrates good hygiene with clear commit message, comprehensive tests, and matching documentation.
