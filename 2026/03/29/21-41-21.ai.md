This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series (12/16). It converts the `--write-midx` flag from a boolean to an enum-based callback option, preparing for future expansion of MIDX writing modes.

The patch introduces a new `repack_write_midx_mode` enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states, replacing the previous boolean `write_midx` flag. It adds an `OPT_CALLBACK` handler that preserves backward compatibility while allowing for future mode extensions. The core change is extracting `write_midx_included_packs()` into a dispatcher function `repack_write_midx()` that will select the appropriate MIDX-writing implementation based on the mode.

This is a mechanical change that doesn't yet introduce new functionality - the default mode maintains existing behavior. The work touches `builtin/repack.c`, `repack-midx.c`, and `repack.h`, updating all boolean checks to use the new enum values. The patch follows the series' pattern of careful refactoring, with clean separation of concerns that will enable the incremental MIDX strategy in subsequent patches.
