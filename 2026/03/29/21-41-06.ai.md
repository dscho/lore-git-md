This is a feature patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, introducing customizable base layers for MIDX writes and compactions. The patch adds a new `--base` option to both `git multi-pack-index write` and `compact` subcommands, allowing callers to specify which existing MIDX layer should serve as the base for new incremental writes.

The key changes allow:
1. Writing new MIDX layers based on any ancestor in the chain (not just the immediate parent)
2. Creating root layers with no parent via `--base=none`
3. For `write`, requiring `--checksum-only` when using `--base` to ensure atomic chain updates
4. For `compact`, allowing base specification without restrictions since compaction atomically replaces ranges

The implementation adds the option parsing, validates the specified base exists in the chain, and updates the MIDX writing logic to honor the custom base. New tests verify the behavior for both valid and invalid cases, including error handling for missing base layers.

This flexibility will be used by the incremental repacking machinery when it needs to replace bottommost layers or build new chains from intermediate points. The patch maintains all existing invariants while expanding the MIDX API to support more sophisticated repacking strategies.
