This is a feature patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, adding support for custom base layers in MIDX writes and compactions. The patch introduces a new `--base` option that allows specifying which existing MIDX layer should serve as the base for new incremental writes or compactions.

The key changes allow:
1. Writing new MIDX layers based on any ancestor in the chain (not just the tip)
2. Creating root layers with no parent (using `--base=none`)
3. Compacting MIDX ranges while preserving a custom base layer

The implementation enforces that `--base` requires `--checksum-only` for writes to maintain chain invariants, since non-atomic writes could otherwise produce invalid chains. For compaction operations, no such restriction exists since the operation is already atomic.

The patch includes thorough test coverage for both subcommands, verifying:
- Error cases (invalid base checksums, missing required flags)
- Correct behavior when creating root layers
- Preservation of chain structure when using intermediate bases
- Compatibility with existing incremental write/compact operations

This change provides the flexibility needed for the incremental repacking strategy to properly maintain MIDX chains when replacing bottom layers or performing partial compactions. The implementation builds on the series' existing MIDX chain management infrastructure while introducing the minimal new surface area required to support these use cases.
