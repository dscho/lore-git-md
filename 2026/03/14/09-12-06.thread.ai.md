Summary of git@vger.kernel.org thread "simplify diverged message in branch status output":

Harald Nordgren proposes removing the singular/plural conditional (Q_()) for the "diverged branch" status message in remote.c, since the singular case (1 commit) is impossible when branches diverge - there will always be at least 1 commit on each side. The patch replaces Q_() with simple _() translation, keeping only the plural form. This is a safe cleanup as the code paths reaching this message always have both ours and theirs commit counts >=1 when branches diverge. The change is small and focused, touching only the message formatting logic in one function, and maintains the same behavior while removing dead code.
