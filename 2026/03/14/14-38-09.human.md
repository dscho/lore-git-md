This is a cover letter for a five-patch documentation series in the l10n (localization) category, the third iteration of Jiang Xin's effort to integrate AI-assisted workflows into Git's translation process. The series provides comprehensive guidelines for using AI tools while maintaining human oversight, with performance benchmarks showing significant efficiency improvements (82% reduction in steps, 76% time savings).

The v3 changes address CI issues (trailing whitespace), streamline documentation by removing redundant examples, and simplify the GETTEXT JSON format to use a single `msgstr` array instead of separate singular/plural fields. The review workflow is also simplified to use a single pending file rather than multiple batch files.

The series splits AI-specific documentation into a new po/AGENTS.md while keeping human-focused guidance in po/README.md. It includes:
1. A .gitattributes file for location filtering
2. Optimized update-pot instructions
3. AI workflows for updating PO files
4. Translation guidelines
5. Review procedures with quality scoring
