This is a cover letter for a 7-patch series improving `git format-patch --commit-list-format` (formerly called `--cover-letter-format`). The series comes from Mirko Faina and builds on previous work from their `mf/format-patch-cover-letter-format` branch.

The main goals are to:
1. Improve user interaction with the commit list formatting feature
2. Remove ambiguous uses of the configuration variable
3. Add a new format preset option
4. Rename the option from `--cover-letter-format` to `--commit-list-format` for clarity

The series includes both refactoring (patches 1-2, 5) and user-facing changes (patches 3-4, 6-7). The changes touch documentation, the pretty-printing code, and the format-patch implementation itself, with corresponding test updates.

The work appears focused and well-structured, with preparatory refactoring coming before the behavioral changes. The commit messages reference previous discussions and build logically on each other. The series looks like a thoughtful iteration on existing functionality rather than introducing radical new concepts.
