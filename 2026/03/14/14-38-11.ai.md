This is the second patch in Jiang Xin's five-part l10n (localization) series introducing AI-assisted workflows for Git's translation process. The patch adds a new po/AGENTS.md file containing optimized instructions specifically tailored for AI agents handling translation housekeeping tasks, separating these from the human-oriented po/README.md.

The key technical contribution is the creation of AGENTS.md with:
- Specialized instructions for generating/updating po/git.pot (Task 1)
- Background on language codes and PO file headers
- Clear separation of AI-specific workflows from human processes
- Performance benchmarks showing significant improvements (82% fewer turns, 76% faster execution)

The patch demonstrates measurable efficiency gains from this separation, with benchmark data showing the Qwen model completing tasks in 3 turns (down from 17) and 8 seconds (down from 34) when using AGENTS.md versus the general README.md. The documentation maintains that human translators remain ultimately responsible for reviewing and approving all AI-generated content.

This builds on the v3 series' overall improvements by further streamlining the AI interaction model while keeping the human oversight framework intact. The patch appears well-executed and aligns with the series' goal of optimizing translation workflows without compromising quality control. As with the rest of the series, some philosophical questions about AI-generated content remain open, but the technical implementation looks solid.
