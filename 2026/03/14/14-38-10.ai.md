This is the first patch in Jiang Xin's v3 series introducing AI-assisted workflows for Git's localization (l10n) process, focusing on infrastructure improvements. The patch adds a `.gitattributes` file to standardize location filtering for PO files and reorganizes the related documentation in `po/README.md`.

The `.gitattributes` file implements two filter strategies for PO files: one that strips both filenames and line numbers (`gettext-no-file-no-location`) and another that preserves filenames while removing line numbers (`gettext-no-location`). The file explicitly lists which languages use which filter, with some commented out for future use. This replaces the previous manual setup where contributors had to configure filters individually.

The patch moves the location filtering documentation from the "Updating a XX.po file" section to a new "Preparing a XX.po file for commit" section in `po/README.md`, separating the concerns of updating translations versus preparing them for commit. The new section provides clearer instructions for contributors to check and set up the appropriate filters based on the language they're working with.

This change supports the broader goal of the series by standardizing the PO file handling infrastructure, which is particularly important for the AI-assisted workflows being introduced. The patch maintains backward compatibility with manual workflows while providing a more consistent foundation for automated processing. The implementation appears clean and well-documented, with clear explanations of the filter strategies and their purpose.
