This is a cross-project coordination update regarding responsive design improvements for kernel.org, building on Rito Rhymes' prior work on GitGitGadget and gitweb. The discussion has shifted from private emails to this public Git mailing list thread due to kernel.org lacking its own public development forum.

Junio C Hamano weighs in cautiously, noting that while he personally doesn't object to hosting the discussion here, he recognizes that kernel.org website changes are fundamentally off-topic for the Git development list. He defers to Konstantin Ryabitsev (Linux Foundation infrastructure lead) for final decision-making about appropriate venues, suggesting there may be better places for kernel.org-specific discussions among its user community.

The exchange highlights the practical challenge of coordinating infrastructure improvements that span multiple projects (Git, kernel.org) with different governance and communication norms. While Rito's responsive design work is technically solid - as evidenced by the already-merged gitweb patches - the thread now faces a process question about where such cross-cutting discussions should live. Junio's response maintains Git's traditional focus while acknowledging the real-world need to sometimes accommodate adjacent work.
