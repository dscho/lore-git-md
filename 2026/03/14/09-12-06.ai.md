This is a small refactoring patch that simplifies a message in the branch status output. Harald Nordgren removes the singular/plural conditional (Q_()) for the "diverged branch" message, since the singular case (1 commit) is impossible in practice there will always be at least 1 commit on each side when branches diverge.

The change affects `remote.c` where Git formats the status message shown when local and remote branches have diverged. The patch replaces the Q_() wrapper (which handles singular/plural forms) with a simple _() for translation, keeping only the plural form of the message. This is a safe change because the code paths that reach this message always have both `ours` and `theirs` commit counts >= 1 when branches diverge.

The commit message explains the rationale clearly - the singular case was unnecessary. This appears to be a straightforward cleanup with no behavior change, just removing dead code. The patch is small and focused, touching only the message formatting logic in one function.
