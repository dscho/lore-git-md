This is a style discussion thread about comparison operator ordering in `builtin/add.c`. The exchange follows up on a GSOC participant's patch that proposed changing `0 <= var` to `var >= 0` to match what they believed was the project's preferred style.

Tian Yuchen points out that the file currently uses only `<` comparisons, not `>`, making the proposed change inconsistent with the surrounding code. They reference the CodingGuidelines which state both styles are valid as long as they're consistent within a given section. This contradicts the original patch's claim of "following common coding style."

The thread highlights how even minor style changes can generate discussion in the project, especially when they don't clearly improve consistency. Junio's earlier intervention established that while `var >= 0` is preferred when starting fresh, existing code patterns matter when modifying files. The discussion remains technical and constructive, focused on interpreting and applying documented conventions rather than personal preferences.
