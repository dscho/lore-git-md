This is a small refactoring patch targeting the translation (l10n) subsystem. Harald Nordgren simplifies a message in `remote.c` that informs users when their branch has diverged from its upstream counterpart.

The change removes the `Q_()` macro (which handles singular/plural forms) in favor of a simpler `_()` macro with only the plural form. This works because the message will always show commit counts greater than zero when branches have diverged, making the singular case impossible in practice. The patch is straightforward and maintains the same user-facing behavior while reducing translation complexity.

The commit message clearly explains the rationale, and the diff shows this is a mechanical change with no functional impact. This appears to be a clean, uncontroversial improvement to the codebase's internationalization support.
