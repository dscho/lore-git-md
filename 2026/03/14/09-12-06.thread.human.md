This thread documents a straightforward cleanup of the branch status message formatting in remote.c. Harald Nordgren noticed that the code was using a pluralization wrapper (Q_()) for "diverged branch" messages, even though the singular case can never occur - divergence requires at least one commit on each side, making the total always at least two. His patch simply replaces Q_() with _() for the plural form.

Junio C Hamano reviewed the change and suggested improving the commit message to better explain why the singular case is impossible (since both 'ours' and 'theirs' counts are positive integers). With that clarification made, Junio has now accepted the patch and added his Signed-off-by, indicating it will be included in an upcoming release. The change is a small but sensible cleanup that removes dead code while maintaining identical behavior, following the project's typical pattern for uncontroversial refactorings.
