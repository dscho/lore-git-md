This thread began with Harald Nordgren's patch to clean up a redundant singular case in remote.c's diverged branch status messages, which Junio reviewed and merged. The change replaced Q_() with _() since the singular case was impossible (divergence requires at least two commits). Phillip Wood later noted that while correct for English, some languages like Polish have more complex pluralization rules that ngettext() (via Q_()) handles better.

Junio has now expanded the discussion, acknowledging Phillip's point about broader i18n implications. He found several other messages with numeric placeholders that use _() instead of Q_(), suggesting this might be a wider pattern worth examining. However, his tone indicates this is more an observation about technical debt than an urgent issue - the original change remains correct for English and most languages, and the dead code removal was still valuable. The thread illustrates how even small cleanups can reveal deeper internationalization considerations in a codebase as widely used as Git's.
