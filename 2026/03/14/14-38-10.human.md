This is the first patch in Jiang Xin's v3 series introducing AI-assisted workflows for Git's localization (l10n) process. The patch focuses on improving the handling of PO file location comments through Git attributes.

The change adds a new `po/.gitattributes` file that defines two filter types for PO files: one that strips both filenames and line numbers (`gettext-no-file-no-location`), and another that preserves filenames while removing line numbers (`gettext-no-location`). The filters are selectively applied to specific language files rather than all PO files, avoiding issues with legacy or inconsistently formatted files.

The patch also reorganizes the `po/README.md` documentation, moving the location-stripping instructions to a new "Preparing a XX.po file for commit" section. This separation helps prevent AI tools from mixing up translation updates with commit preparation steps.

This is a well-structured technical improvement that builds on Git's existing l10n infrastructure. The selective filtering approach shows careful consideration of backward compatibility, and the documentation changes improve clarity. As part of the larger AI-assisted translation effort, this foundational change helps standardize how location information is handled across different contributors' workflows.
