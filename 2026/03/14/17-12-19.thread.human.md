This thread introduces a Coccinelle rule to detect when `struct strbuf` is incorrectly passed by value rather than by pointer - a common anti-pattern in Git's codebase. The patch comes from Deveshi Dwivedi, responding to feedback from Jeff King during an earlier worktree-related review.

The proposed rule already identified two problematic cases: one in `worktree.c` (already being fixed) and another in `builtin/stash.c` (a new finding). The change is purely mechanical, maintaining Git's convention that `strbuf` should always be passed by pointer. While the rule can automatically update function signatures, callers would still need manual adjustment.

This appears to be a well-scoped contribution that follows Git's established patterns for using Coccinelle to enforce coding standards. The two real-world findings suggest the rule would provide concrete value in preventing subtle API misuse. The author has submitted this as an RFC to gather feedback before formal submission.
