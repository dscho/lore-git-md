This thread discusses a proposed Coccinelle semantic patch to detect when `struct strbuf` is incorrectly passed by value rather than by pointer, which violates Git's coding conventions. The rule originated from Jeff King's review feedback on Deveshi Dwivedi's worktree fix, and has since been refined to target function signatures more comprehensively.

Jeff King reviewed the semantic patch, approving its approach while noting the output could benefit from clearer explanatory context. The current implementation catches two violations - one already being fixed in the worktree code, and another in `builtin/stash.c`'s `save_untracked_files()` function. Dwivedi has confirmed they will submit both the Coccinelle rule and the remaining stash.c fix, continuing Git's practice of using automated tools to maintain code consistency. The interaction shows the project's careful review process for even straightforward mechanical changes.
