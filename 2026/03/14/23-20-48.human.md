This is patch 5/7 in Mirko Faina's series improving `git format-patch --commit-list-format`. The patch focuses on improving readability aspect of the commit list in cover letters by adding line wrapping for long commit message lines.

The change modifies `generate_commit_list_cover()` in `builtin/log.c` to use Git's existing text-wrapping functionality (`strbuf_add_wrapped_text`) when outputting commit messages. This ensures that unusually long lines in commit messages (which can occur despite conventions against them) will be properly wrapped to the standard email width (MAIL_DEFAULT_WRAP) rather than appearing as single long lines in the output.

The implementation is straightforward - it introduces a new `wrapped_line` strbuf alongside the existing `commit_line`, applies the wrapping function, and ensures proper cleanup of both buffers. The change is small (7 lines added, 1 removed) and focused purely on the output formatting, without altering any surrounding logic.
