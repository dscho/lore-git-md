This is the second patch in a 6-part series implementing responsive design improvements for kernel.org, following Rito Rhymes' earlier work on GitGitGadget and gitweb. The patch addresses a specific CSS issue where the Oswald font's tall letterforms cause wrapped heading text to visually overlap with content above it, particularly noticeable on mobile devices.

The change introduces a global `line-height: 1.1` rule for all headings to prevent text overlap, while adjusting banner margins to maintain the original desktop layout. The implementation is focused and well-explained, with the commit message clearly describing both the problem (Oswald font's ascenders/descenders causing overlap) and the solution (line-height adjustment with compensatory margin changes).

This continues the series' pattern of targeted, incremental improvements to kernel.org's mobile rendering that preserve the existing desktop experience. The patch demonstrates Rito's characteristic attention to detail in responsive design, building on their proven approach from previous Git-related web projects. As with the rest of the series, this change is technically sound and unlikely to be controversial, though it remains subject to kernel.org maintainers' review.
