This is the first patch in a series implementing responsive design improvements for kernel.org, following Rito Rhymes' successful work on GitGitGadget and gitweb. The patch focuses on establishing proper mobile rendering by adding a viewport meta tag to kernel.org's base template.

The change is straightforward but foundational - it sets the viewport width to match the device width and initial scale to 1.0. This fixes the immediate "tiny text" problem on mobile devices where pages were previously rendering at desktop width, forcing users to zoom and pan. The patch notes this enables proper vertical scrolling and serves as the baseline for subsequent CSS adjustments in the series.

The implementation is clean - a single line addition to the base template that will affect all pages. This matches Rito's demonstrated approach of making targeted, incremental improvements rather than sweeping redesigns. The commit message clearly explains both the problem and how this change addresses it.

As the first patch in the series, this sets up the necessary precondition for the follow-up CSS fixes (patches 2-6) to work. The change is low-risk since it doesn't modify any existing layout logic - it just tells mobile browsers to use the device width rather than assuming a desktop viewport. The series appears well-structured, with this foundational change coming first before the more involved layout adjustments.
