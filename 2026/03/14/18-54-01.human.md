This is a brief follow-up in the cross-project discussion about kernel.org's responsive design improvements. Rito Rhymes, who has been leading the technical work on making kernel.org mobile-friendly, acknowledges Junio C Hamano's concerns about the discussion potentially being off-topic for the Git mailing list. 

Rito expresses understanding of the need to avoid distractions and notes that the Git list may not be the ideal venue for website-related reviews. The email defers to Konstantin Ryabitsev (Linux Foundation infrastructure lead) to determine the appropriate communication channel going forward, showing willingness to move the conversation elsewhere if needed.

The exchange highlights the practical challenge of coordinating infrastructure improvements that affect Git (like mailing list archives) when no dedicated forum exists for kernel.org development discussions. The technical work itself appears complete and uncontroversial, with the remaining question being purely about communication logistics.
