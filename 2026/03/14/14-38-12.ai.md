This is the third patch in Jiang Xin's five-part series introducing AI-assisted workflows for Git's localization (l10n) process. The patch focuses specifically on documenting the AI instructions for updating language-specific PO files (e.g., `po/zh_CN.po`).

The key addition is a new "Task 2" section in `po/AGENTS.md` that provides optimized instructions for AI agents to update PO files. The documentation specifies that the AI should directly execute `make po-update PO_FILE=po/XX.po` without pre-checking file contents or post-processing the results, leaving all verification and translation work to human maintainers.

Benchmark data shows significant efficiency improvements from this focused documentation approach - an 82% reduction in conversation turns (from 22 to 4) and 76% faster execution time (38s down to 9s) when using the Qwen model. The patch maintains the series' consistent theme of keeping humans firmly in control while streamlining AI-assisted workflows.

This continues the pattern seen in previous patches of separating AI-specific documentation (in AGENTS.md) from human-facing instructions (in README.md). The implementation appears technically sound and well-measured, with clear performance benefits demonstrated through empirical testing. As with the rest of the series, this patch does not address the outstanding legal/DCO concerns raised earlier by brian m. carlson, focusing instead on the technical documentation improvements.
