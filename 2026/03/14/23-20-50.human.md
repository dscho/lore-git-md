This is the final patch in a 7-part series improving `git format-patch --commit-list-format` (formerly `--cover-letter-format`). The patch makes the command more user-friendly by allowing custom format strings to be specified without requiring the "log:" prefix, as long as they contain a placeholder (like `%s`).

The change is small but meaningful - it removes a minor friction point when using custom formats. The implementation is straightforward, just checking for a '%' character to detect format strings. The patch includes tests verifying both the new behavior (accepting format strings without prefix) and maintaining the existing validation (rejecting plain strings without placeholders).

This completes the series' goal of improving commit list formatting usability. The earlier patches renamed the option, added line wrapping, and introduced a new "modern" preset format. This final tweak makes the custom format feature more intuitive to use. The series appears well-considered, with thorough test coverage and clear documentation updates.
