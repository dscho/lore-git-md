This is the second patch in a 6-patch series improving kernel.org's mobile responsiveness. It addresses a specific CSS issue where wrapped headings using the Oswald font could visually overlap with text above them, particularly noticeable on mobile devices.

The patch makes three targeted changes to `main.css`:
1. Adjusts the banner heading margins to compensate for a new line-height setting
2. Adds right margin to the banner navigation list to maintain desktop layout
3. Sets a consistent line-height for all headings to prevent overlap

The changes preserve the existing desktop appearance while fixing mobile rendering issues that became apparent after the viewport adjustments in patch 1. The commit message clearly explains the problem (Oswald font's tall characters causing overlap) and the solution (global line-height policy with compensatory spacing adjustments).

This appears to be a well-considered follow-up to the foundational viewport change, demonstrating Rito Rhymes' methodical approach to responsive design - fixing specific issues while maintaining backward compatibility. The patch is focused and clearly motivated, with changes limited to the CSS file.
