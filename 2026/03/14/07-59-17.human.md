This is the first patch in a series implementing responsive design improvements for kernel.org, following Rito Rhymes' successful work on GitGitGadget and gitweb. The patch adds a basic but crucial mobile-friendly foundation by introducing a viewport meta tag to kernel.org's base template.

The change addresses a fundamental mobile usability issue where pages currently render at desktop width on phones, forcing users to zoom and pan horizontally to read content. The simple addition of `<meta name="viewport">` ensures pages scale properly to device width, enabling normal vertical scrolling. This is a prerequisite for the subsequent CSS adjustments in patches 2-6 that will refine the layout.

The patch is cleanly focused - just one line added to the base template - and comes with a clear explanation of the problem it solves. As the first step in a coordinated effort between Git and kernel.org infrastructure teams, it demonstrates Rito's characteristic approach of starting with foundational fixes before building up more complex responsive behaviors. The change is low-risk while enabling significant mobile usability improvements.
