This is a status update on two experimental `git replay` features currently under consideration for merging into Git's 'next' branch.

Christian Couder provides feedback on two related `git replay` topics from Junio Hamano's "What's cooking" report. First, he approves Toon Claes' patch enabling replay down to the root commit, noting that a separate series will address the silent failure case when using "topic" instead of "main..topic" syntax. Second, he reviews Siddharth Asthana's `--revert` mode addition, confirming that version 6 of the patch has resolved previous concerns and that Phillip Wood had also approved it pending those fixes.

Both changes represent incremental improvements to the experimental `git replay` command, which has been seeing active development. The root commit support expands the range of history that can be replayed, while the revert mode adds a new operation type alongside the existing pick and replay modes. These changes appear ready for integration, with known issues either deferred to follow-up work or already addressed in the current versions.
