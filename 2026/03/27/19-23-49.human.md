This is a refactoring patch in Ezekiel Newren's series improving type safety in Git's xdiff subsystem. The patch focuses specifically on `xdl_bogo_sqrt()`, changing its parameter and return types from `long` to `uint64_t` to better reflect the mathematical constraints (square roots of negative numbers being undefined) and to handle larger inputs safely. The change requires corresponding updates to call sites where the result is cast back to `long` when needed.

This is part of the third iteration of a focused cleanup effort that has already received maintainer approval in principle. The patch demonstrates careful attention to type safety while maintaining the broader goal of improving code clarity in the xdiff implementation. The changes are mechanical but meaningful, touching four files to ensure consistent type usage. As with the rest of the series, this is no intended behavior change - just clearer, more robust code.
