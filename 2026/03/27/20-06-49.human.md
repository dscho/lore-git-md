This is a test case patch (part 3/5) in Taylor Blau's series addressing geometric repacking issues with MIDX bitmaps. The patch adds a failing test that demonstrates a specific problem where once-cruft objects (previously unreachable objects that become reachable again) above the geometric split point can prevent bitmap generation.

The test creates a scenario where:
1. A commit is made unreachable (via reset and reflog expiration)
2. The object is packed into a cruft pack
3. The object is then made reachable again (via a new reference)
4. A geometric repack fails to properly include this object in the new pack, breaking bitmap generation

The test is marked as `test_expect_failure` since the fix will come in the next patch. This is a common pattern in Git development - first demonstrate the failure, then fix it. The test is well-constructed to isolate the specific edge case the series aims to address.

This patch builds on the series' earlier work (v1 identified the reachability problem, v2 added strmap refactoring) and has already received positive reviews from key contributors like Derrick Stolee, Jeff King, and Patrick Steinhardt. The test case will help verify that the upcoming fix properly handles this edge case of objects transitioning between cruft and reachable states during geometric repacking.
