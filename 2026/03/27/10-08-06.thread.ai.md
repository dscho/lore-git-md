[PATCH v4] read-cache: use istate->repo for trace2 and repo info

This patch series by Jayesh Daga completes the conversion of trace2 logging in read-cache.c from using the global `the_repository` to using the repository pointer from index state (`istate->repo`), as part of René Scharfe's ongoing `the_repository` removal effort. Version 4 focuses narrowly on converting the four remaining trace2 call sites in read-cache.c (do_read_index(), read_index_from(), do_write_index(), do_write_locked_index()), dropping ancillary repo info plumbing from v3 to maintain tight scope.

Key technical details:
- All trace2 calls now use istate->repo directly without intermediate variables
- Relies on INDEX_STATE_INIT() guarantee rather than BUG() checks
- Follows Derrick Stolee's preference for segfaults over BUG() on NULL repo
- Maintains test suite coverage
- No fallback paths to `the_repository`
