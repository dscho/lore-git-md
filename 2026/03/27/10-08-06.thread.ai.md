[PATCH v2] read-cache: use istate->repo for trace2 in do_read_index

This patch series continues the `the_repository` removal effort by converting trace2 logging in read-cache.c from the global `the_repository` to using istate->repo. Version 2 incorporates maintainer feedback by removing the fallback to `the_repository` entirely and replacing it with a BUG() check to enforce that istate->repo is never NULL (as guaranteed by INDEX_STATE_INIT()). This stricter approach helps catch violations early and aligns with the project's direction of eliminating global state dependencies.

The changes focus on two trace2_data_intmax() calls in do_read_index() that report index version and cache entry count. The commit message explains the value of making repository context explicit and preventing trace2 event misattribution in multi-repo scenarios. An obsolete TODO comment about fixing this has been removed.
