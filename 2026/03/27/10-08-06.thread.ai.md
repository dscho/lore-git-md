[PATCH] read-cache: use istate->repo for trace2 in do_read_index

This patch series continues the `the_repository` removal effort by modifying trace2 logging in read-cache.c to use istate->repo instead of the global variable. The initial patch from Jayesh Daga (GSoC participant) changed two calls in do_read_index(), maintaining fallback to `the_repository` when istate->repo is NULL. Derrick Stolee's review questions whether NULL istate->repo should be allowed at all, suggesting this might indicate a bug rather than an expected case. He recommends testing without the fallback and identifies additional `the_repository` uses in read-cache.c that could be converted in a logical sequence.

Key technical details:
- Current patch modifies trace2 calls in do_read_index() to use istate->repo
- Review identifies related conversions needed in refresh_index(), tweak_untracked_cache(), and do_write_index()
- Open question whether istate->repo should ever be NULL (test suite should verify)
- Follow-up work should group changes: first trace2 cases, then other straightforward conversions where istate is available
