[PATCH v3] read-cache: use istate->repo for trace2 and repo info

This series continues the `the_repository` removal effort by converting trace2 logging in read-cache.c to use istate->repo instead of the global `the_repository`. Version 3 expands scope from v2 to convert all trace2 calls in the file and adds new repo info plumbing for git_dir path access.

Core changes:
- Converts all 4 trace2 call sites in read-cache.c (do_read_index(), read_index_from(), do_write_index(), do_write_locked_index()) to use istate->repo
- Adds new repo info key "paths.git_dir" to access repository path via `git repo info`
- Implements new `get_paths_git_dir()` helper in builtin/repo.c
- Adds test verification matching `git rev-parse --git-dir` output
- Removes intermediate variables and obsolete TODO comments
- Drops BUG() check from v2, relying on INDEX_STATE_INIT() guarantee
- Tightens commit messages per Junio's v2 feedback

Technical consensus from v2 remains:
- No fallback paths to `the_repository`
- Direct istate->repo access without intermediate variables
- Test suite verification required
- Phased approach continues with straightforward cases first
