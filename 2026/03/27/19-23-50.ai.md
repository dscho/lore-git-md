This is a refactoring patch in Ezekiel Newren's ongoing xdiff cleanup series, focusing on type safety improvements. The patch converts parameters and local variables in `xdl_clean_mmatch()` and `xdl_cleanup_records()` from `long` to more precise `ptrdiff_t` types, which better reflect their usage for array indexing and pointer arithmetic. 

The changes are straightforward - three `long` declarations become `ptrdiff_t` with no logic changes. This follows the series' pattern of using exact-width types where appropriate, particularly for operations involving memory offsets and array bounds. The patch maintains the v3 series' tight focus on type safety after broader structural changes were dropped from earlier versions.

For future reference, this touches the xdiff subsystem's record cleanup logic, specifically the functions that analyze and optimize diff hunks. The `ptrdiff_t` changes ensure correct behavior with large files by avoiding potential integer overflow/underflow in array indexing operations. The patch builds on prior work in the series to make the xdiff code more robust while keeping its behavior identical.
