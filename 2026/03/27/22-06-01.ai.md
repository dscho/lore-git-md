The reply also highlights a key architectural tradeoff - while Wesley's proposal would simplify some common cases, it would reduce flexibility that power users currently have with the more general `core.sshCommand` approach. brian's arguments strengthen the case that the proposed feature might not justify its complexity given existing solutions, particularly since Jeff King has already shown how namespace handling can be achieved through `includeIf` patterns.

This continues the thread's pattern of maintainers and experienced contributors demonstrating that the motivating use cases can be addressed through established mechanisms, while the original author maintains that Git-level configuration would provide better workflow ergonomics.
