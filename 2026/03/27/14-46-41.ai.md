This is a build system fix for Adrian Ratiu's parallel hook execution series. Patrick Steinhardt points out that the v5 10/12 patch moving `is_known_hook()` to `hook.c` needs a corresponding update to the Meson build configuration. The hook-list.h dependency was incorrectly listed under builtin sources but now needs to be moved to libgit sources since the function is no longer in builtin/hook.c.

The proposed change is straightforward - it moves the custom target for generating hook-list.h from the builtin_sources list to libgit_sources in meson.build. This ensures the hook.c file gets rebuilt when the hook list changes, maintaining build correctness. The patch is a mechanical adjustment with no functional impact beyond fixing the build dependency chain.

This is a minor but necessary follow-up to keep the parallel hooks series building correctly with both Makefile and Meson. The core functionality remains unchanged, and the series as a whole continues to have maintainer approval for its technical approach.
