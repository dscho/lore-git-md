This is a build system follow-up patch in Adrian Ratiu's parallel hook execution series. The patch addresses a minor but important build dependency issue caught by Patrick Steinhardt in the previous version. 

The core change moves the hook-list.h dependency from builtin_sources to libgit_sources in meson.build, since the is_known_hook() function was moved from builtin/hook.c to hook.c in the previous patch. This ensures the build system correctly rebuilds affected files when the hook list changes. 

Adrian confirms the issue and plans to incorporate Patrick's suggested fix in the next version of the series, noting that the Makefile build caught this issue while Meson did not. The change is purely mechanical with no functional impact on the parallel hooks feature itself, which continues to have maintainer approval. 

This is the kind of small but necessary adjustment that often surfaces during final review of a larger series - catching build system details that need to stay in sync with code movements. The patch maintains the series' momentum toward inclusion.
