Refactoring patch in the parallel hook execution series, addressing build system integration. Patrick Steinhardt points out that moving `is_known_hook()` from `builtin/hook.c` to `hook.c` (as done in v5 10/12) requires a corresponding update to the Meson build configuration. His follow-up patch moves the `hook-list.h` dependency generation from `builtin_sources` to `libgit_sources` to match the new location of the function.

This is a straightforward build system adjustment that keeps the Meson build in sync with the code reorganization. The change is uncontroversial and aligns with the series' goal of making hook utilities more widely available across the codebase. Since the core parallel hook execution functionality already has maintainer approval, this build tweak should integrate smoothly.
