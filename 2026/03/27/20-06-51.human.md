This is a technical patch in Taylor Blau's v3 series addressing pack-objects behavior during geometric repacking, specifically when MIDX bitmap generation fails due to packs not being closed under reachability. The patch introduces a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs while excluding their direct contents.

The key change is the introduction of a new pack state that allows commits in excluded packs to still serve as starting points for reachability traversal, while still excluding their direct contents from the output pack. This solves a specific edge case where objects could be missed during repacking if they were only reachable through excluded packs. The patch includes thorough documentation updates, code changes to implement the new state, and comprehensive test coverage.

The changes are well-motivated by the geometric repacking scenario where packs above the split point may not have full object closure. Reviewers including Derrick Stolee, Jeff King, and Patrick Steinhardt have approved the approach, and all feedback from previous iterations has been addressed. The patch appears ready for merging as part of the larger series.

For readers following the geometric repacking work, this patch provides an important correctness fix for handling edge cases around object rescue during repacking operations. The solution maintains clean separation of concerns while adding the necessary flexibility to handle once-cruft objects that become reachable again.
