This is a refactoring patch in a series improving Git's xdiff subsystem. The fifth patch in the v3 series focuses on making the action-setting logic in `xdl_cleanup_records()` more readable by replacing nested ternary operators with explicit if/else statements. The change is purely about code clarity - it doesn't modify behavior or performance. The patch converts two complex conditional expressions that determine whether to DISCARD, KEEP, or INVESTIGATE diff records into clearer multi-branch conditionals. This follows the series' theme of improving maintainability in the xdiff code while preserving functionality. The patch has already received maintainer feedback in previous iterations and appears ready for merging as part of the completed refactoring effort.
