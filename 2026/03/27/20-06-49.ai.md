This is a test case addition as part of Taylor Blau's v3 patch series addressing pack-objects issues during geometric repacking. The patch demonstrates a failure scenario where once-cruft objects above the geometric split point prevent MIDX bitmap generation.

The test creates a repository with:
1. A reachable commit and an unreachable commit
2. The unreachable commit is made cruft (via reset, tag deletion, and reflog expiration)
3. The cruft object is then repacked into a cruft pack
4. The same object is later made reachable again (via update-ref)
5. A geometric repack with bitmap generation is attempted

The test is marked as `test_expect_failure` since the current code cannot handle this case - the once-cruft object above the geometric split prevents proper bitmap generation. The test will be fixed by subsequent patches in the series that introduce the "excluded-open" pack state to properly handle such objects.

This is a focused, well-constructed test that clearly demonstrates the edge case the series aims to fix. It follows the pattern of the existing tests in t7704 while targeting the specific interaction between cruft packs, geometric repacking, and bitmap generation that the series was designed to address. The test setup is thorough yet minimal, making the failure mode clear.
