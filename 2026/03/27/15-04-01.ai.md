This is a response in the ongoing thread about per-remote SSH configuration options, where the author Wesley Schwengle counters Johannes Sixt's (Hannes) argument that SSH Host aliases provide sufficient functionality.

The response suggests the SSH-only solution doesn't fully address the use case of maintaining portable repository configurations that work consistently across different users' environments. Wesley hints at a "why not both" philosophy, implying the Git-level configuration could coexist with SSH mechanisms rather than replacing them.

This moves the discussion forward by clarifying specific limitations of the SSH-only approach that the original patch series aimed to address - particularly around configuration portability and the user experience of shared repository setups.
