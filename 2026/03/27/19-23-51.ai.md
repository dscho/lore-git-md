This is a refactoring patch in Ezekiel Newren's ongoing xdiff cleanup series, specifically focusing on improving clarity in the record cleanup logic. The patch simplifies the limit calculations in `xdl_cleanup_records()` by introducing explicit per-file limit variables (`mlim1` and `mlim2`) and removing redundant conditions. 

The key changes are:
- Separates the limit calculations for each file upfront rather than recalculating them in the loops
- Eliminates the redundant `!need_min` check that was previously part of the INVESTIGATE condition
- Maintains the same logic flow but with clearer variable naming and initialization

The patch continues the series' focus on type safety and readability improvements without changing behavior. It builds on prior work that introduced more precise types (`ptrdiff_t`, `size_t`) and follows the maintainer-approved direction from earlier iterations. The changes are localized to xdiff/xprepare.c and specifically target the record cleanup logic that helps determine which diff records can be discarded or need further processing.

For future reference, this patch introduces the explicit `mlim1`/`mlim2` variables that replace the previous inline limit calculations, and removes the now-unnecessary `!need_min` condition that was made redundant by the variable initialization logic. The changes align with the series' goal of making the xdiff code more maintainable through clearer type usage and simplified control flow.
