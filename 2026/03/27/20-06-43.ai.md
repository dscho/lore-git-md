This is a bugfix patch from Taylor Blau addressing a memory leak in the pack-objects subsystem. It's the first of five patches in his v3 series dealing with geometric repacking and MIDX bitmap generation issues.

The patch fixes a leak in `read_stdin_packs()` where a `release_revisions()` call was missing for a `rev_info` struct. While the current code doesn't actually leak in practice (as evidenced by clean SANITIZE=leak test runs), this is still a proper cleanup that follows Git's memory management conventions. The change is straightforward - just adding the missing cleanup call before the function returns.

This is being careful to maintain proper resource management in code that handles pack objects, which is particularly important given the series' focus on geometric repacking correctness. The patch demonstrates good attention to detail, though it's worth noting the leak wasn't actively causing problems. This appears to be a proactive cleanup rather than fixing an observed issue.
