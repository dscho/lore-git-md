This is the fourth patch in Taylor Blau's v3 series addressing pack-objects issues during geometric repacking when MIDX bitmap generation fails due to packs not being closed under reachability. The patch introduces a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs while excluding their direct contents.

The key technical addition is a new pack state that allows commits in excluded packs to serve as traversal starting points while still excluding their direct contents. This solves a reachability problem where objects could be missed during geometric repacking if they were only reachable through excluded packs. The patch adds a `pack_keep_in_core_open` flag to mark these special packs and modifies the traversal logic to handle them appropriately.

The changes include thorough documentation updates explaining the new '!' pack prefix behavior, refactoring of the pack handling code to use type-safe enums, and comprehensive test coverage demonstrating both the new functionality and backward compatibility. The tests verify that objects can be properly rescued from once-cruft packs that become reachable again, while maintaining the expected behavior for traditional excluded packs.

Review feedback from v2 has been fully addressed, with Derrick Stolee, Jeff King, and Patrick Steinhardt having approved the approach. The patch represents a well-considered solution to a subtle but important edge case in pack-objects' reachability handling, with careful attention to both correctness and code quality. The changes are focused and well-explained, building on the series' earlier work while introducing the minimal new concepts needed to solve the problem.
