Refactoring patch in the xdiff subsystem, part of a series to improve type safety and readability. This is patch 3/6 in the third iteration of Ezekiel Newren's focused cleanup of `xdl_cleanup_records()`.

The patch converts parameters and local variables in `xdl_clean_mmatch()` and `xdl_cleanup_records()` from `long` to more precise `ptrdiff_t` types, which better reflect their use for array indexing and size calculations. The changes are purely internal - no behavior changes - and continue the series' theme of making the xdiff code more type-safe and self-documenting.

This follows maintainer feedback from earlier versions and addresses build warnings that surfaced under DEVELOPER=1 mode. The series appears to be in its final polishing stage, with Junio Hamano having already approved the general direction. The changeset is small and focused, touching only 3 lines across two functions in xdiff/xprepare.c.
