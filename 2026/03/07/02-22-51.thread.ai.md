Junio Hamano's "What's cooking in git.git" report tracks the state of in-flight Git topics across integration branches (maint, master, next, seen). Key developments include Patrick Steinhardt's ODB abstraction series (19 patches restructuring object source API for pluggable backends) now in 'next' and Johannes Schindelin's sideband sanitization work split into two tracks - immediate fixes ('jc/neuter-sideband-fixup') and stricter Git 3.0 controls ('jc/neuter-sideband-post-3.0'). Adrian Ratiu's configuration-based hooks (ar/config-hooks) progresses while parallel execution support (ar/parallel-hooks) remains under review. Performance work includes ps/upload-pack-buffer-more-writes (reducing upload-pack lock contention) and tb/incremental-midx-part-3.2 (MIDX compaction with bitmaps). New features like ab/clone-default-object-filter (configurable clone filters) and lc/rebase-trailer (--trailer support) advance. Documentation updates and platform fixes (macOS/Windows) continue. Controversial topics persist: bc/sha1-256-interop-02 (Rust interoperability) and en/xdiff-cleanup-3 (xdiff preparation for Rust) remain in progress, while js/neuter-sideband is superseded. The report reflects Git's dual focus on architectural changes (ODB abstraction) and incremental improvements, managed through the branch workflow that stages topics from 'seen' through 'next' to 'master'.
