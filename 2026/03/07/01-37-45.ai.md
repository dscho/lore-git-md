This is the final documentation patch in a series that improves Git's line-log functionality (`git log -L`) by routing its output through the standard diff pipeline. The patch updates the documentation to reflect that `-L` now supports various diff options that were previously unavailable, including `--word-diff`, `--color-moved`, pickaxe options (`-S`, `-G`), and others.

The documentation changes in `Documentation/line-range-options.adoc` clarify which diff options now work with `-L` while maintaining backward compatibility notes. The patch completes the series that has already:
1. Fixed a crash when combining `-L` with pickaxe options
2. Rerouted the output through `builtin_diff()`
3. Added comprehensive test coverage

Junio Hamano has expressed enthusiasm for the direction of this work, noting it reduces deviations from Git's standard diff machinery while maintaining backward compatibility. The series is well-structured with thorough attention to edge cases and testing coverage. While some limitations remain (non-patch diff formats still don't work with `-L`), this represents significant progress in unifying the line-log feature with Git's core diff functionality.
