This is the final documentation update in a series that improves Git's line-log functionality (`git log -L`). The patch updates the documentation to reflect that `-L` now works with standard diff options like `--word-diff`, `--color-moved`, pickaxe options (`-S`, `-G`), and others, since the output is now routed through Git's standard diff pipeline.

The series as a whole fixes a long-standing limitation where `-L` bypassed the normal diff machinery, causing many diff features to be unavailable. The changes maintain backward compatibility while adding support for previously unsupported options. The documentation patch completes the series by properly documenting these newly enabled features.

The implementation appears thorough, with careful attention to edge cases and comprehensive test coverage in earlier patches.
