This is a documentation patch completing a series that improves Git's line-log functionality (`git log -L`). The series routes line-log output through the standard diff pipeline, enabling previously unsupported features like `--word-diff`, `--color-moved`, pickaxe options (`-S`, `-G`), and various formatting options to work with `-L`.

This final patch updates the documentation to reflect the newly supported features. It adds a note to `Documentation/line-range-options.adoc` clarifying that patch formatting options (`--word-diff`, `--color-moved`, `--no-prefix`, whitespace handling) and pickaxe options now work with `-L`. The change is straightforward and aligns with the technical implementation in the earlier patches of the series.

The patch follows the series' goal of making line-log functionality more consistent with Git's standard diff behavior while maintaining backward compatibility. It completes the documentation side of the feature, which was identified as an open question in earlier patches. The change is well-contained, touching only the documentation file to match the capabilities now provided by the core implementation changes.
