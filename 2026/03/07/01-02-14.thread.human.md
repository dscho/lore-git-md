This thread documents the successful completion of a series improving Git's line-log functionality (`git log -L`). The core issue was that line-log output bypassed Git's standard diff machinery via a hand-rolled `dump_diff_hacky()` function, causing many diff features (like `--word-diff` and pickaxe options) to be unavailable with `-L` and producing incomplete output missing headers and context.

Michael Montalbo's four-patch series systematically addressed this by first fixing a crash when combining `-L` with pickaxe options in repositories with renamed files, then routing line-log output through the standard `builtin_diff()` pipeline. This enabled proper diff formatting and unlocked previously unsupported features while maintaining performance. The changes were well-tested across various diff options and edge cases, with documentation clearly noting both supported and unsupported formats.

Maintainer Junio C Hamano expressed enthusiasm for the direction, particularly appreciating how the changes reduced deviations from Git's core diff architecture. Kristoffer Haugsbakk later fixed minor documentation formatting issues post-merge. The series represents a clean technical improvement that maintains backward compatibility while expanding functionality, with all discussion points resolved and patches merged.
