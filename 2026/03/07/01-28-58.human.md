This is the final patch in a series that improves Git's line-log functionality (`git log -L`) by routing its output through the standard diff pipeline. The series enables previously unsupported diff features like `--word-diff`, `--color-moved`, pickaxe options (`-S`, `-G`), and others to work with `-L`.

The core change replaces the hand-rolled `dump_diff_hacky()` function with standard diff machinery, which brings several benefits but also changes the output format to include previously missing elements like index lines and funcname context. This may affect tools that parse `-L` output. The series maintains backward compatibility while adding comprehensive test coverage for the new functionality.
