This is the final documentation patch in a series that improves Git's line-log functionality (`git log -L`). The series routes line-log output through Git's standard diff pipeline, enabling previously unsupported features like `--word-diff`, `--color-moved`, pickaxe options (`-S`, `-G`), and various formatting options to work with `-L`.

This specific patch updates the documentation to note these newly supported features. It adds a clear explanation that patch formatting options (word-diff, color-moved, whitespace handling) and pickaxe options now work with line-log ranges. The change is straightforward and well-contained, adding just 4 lines to the line-range-options documentation.

The patch follows naturally from the technical changes in the series (which removed a hacky diff implementation in favor of using Git's standard diff machinery) and provides the necessary user-facing documentation to explain the new capabilities. It's a clean, focused addition that completes the feature series.
