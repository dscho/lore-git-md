This is a documentation patch aimed at improving discoverability of how to create custom Git commands. 

The patch adds cross-references in the "GIT COMMANDS" section of git(1) to point readers to information about creating command aliases (via git-config) and installing custom subcommands (via PATH environment variable). The motivation is that this information currently exists but is not easy to find when users look for it in the commands section.
