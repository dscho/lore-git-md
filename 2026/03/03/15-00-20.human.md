This is a platform compatibility patch from Patrick Steinhardt, part of his larger series optimizing `git-upload-pack` performance under high concurrency. The patch introduces a `writev()` compatibility layer for systems (notably Windows) that lack this POSIX system call.

The change adds a fallback implementation that emulates `writev()` by making multiple `write()` calls when needed, similar to existing compatibility wrappers like `git_pread()`. The implementation includes proper error handling and uses the new `cast_size_t_to_ssize_t()` helper from earlier in the series for safe type conversion.

This is infrastructure work enabling the subsequent performance optimizations in the series, particularly the planned use of `writev()` for more efficient packet writing in `sideband.c`. The patch follows Git's established patterns for platform compatibility, with appropriate build system changes to enable the wrapper on Windows and MINGW environments.

The change is well-contained and follows the project's conventions for such compatibility layers, with clear documentation of the motivation and platform considerations. As part of a performance-focused series that has already received positive feedback from key reviewers, this patch appears ready for inclusion.
