Current status: Kristoffer Haugsbakk confirmed removal will occur in Git 2.52 or later (correcting Junio's earlier mention of Git 3.0), with deprecation warnings present since Git v2.51.1. Two replacement options are established: `git log --stat` for summary view (now endorsed by Antoine Cousson as his preferred alternative) and `git log --raw --no-merges` for exact output matching whatchanged. Key technical details: Both commands use the same diff machinery with different defaults. `git whatchanged` implicitly shows file modifications without merge commits, while `git log` requires explicit flags. The `--raw` output provides exact compatibility but includes hexadecimal object names that Junio described as "ugly hexadecimal gibberish." `--stat` output (now preferred by Antoine) shows modification statistics in a more readable format. This is part of Git's interface consolidation where redundant commands are removed in favor of configurable `git log`.
