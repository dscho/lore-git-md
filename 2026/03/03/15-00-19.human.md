This is a preparatory patch in Patrick Steinhardt's performance optimization series targeting lock contention in `git-upload-pack`. The patch introduces a new helper function `cast_size_t_to_ssize_t()` that safely converts between size_t and ssize_t types, with an overflow check to prevent platform-specific issues.

The function follows the same pattern as the existing `cast_size_t_to_int()` in the same file, adding bounds checking before type conversion. This is a small but important building block for the larger series, which aims to reduce write syscalls during high-concurrency operations by improving buffering in the packfile transfer path.

The patch is straightforward and uncontroversial - it's clearly motivated by the needs of the following patch in the series (which will use this helper) and maintains consistency with Git's existing type conversion patterns. As with the rest of the series, it shows Patrick's thorough approach to platform compatibility and edge case handling.
