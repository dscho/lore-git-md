This is part of Jiang Xin's ongoing effort to improve Git's localization (l10n) workflow with optional AI assistance, specifically focusing on documentation for AI-assisted .po file handling.

The patch adds a new `po/AGENTS.md` file that provides optimized instructions for AI agents performing translation-related housekeeping tasks, separating these from the human-focused `po/README.md`. The key motivation is efficiency - benchmark data shows this separation reduces the number of AI interactions needed to update `po/git.pot` by 82% and cuts execution time by 76%.

The document establishes clear guidelines for AI agents: they should directly run `make po/git.pot` without pre-checks or post-validation, while emphasizing that human translators remain ultimately responsible for linguistic quality and cultural appropriateness. It includes background on PO file structure and language codes to help agents understand the workflow context.
