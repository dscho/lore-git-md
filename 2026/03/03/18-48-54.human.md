This is a documentation patch that has evolved through several iterations to better explain Git's support for external `git-*` commands in PATH. The thread began with Omri Sarig proposing to document this long-standing but under-documented feature where executables named `git-<command>` in PATH can be invoked as `git <command>`. After Junio Hamano suggested moving the documentation to the Environment Variables section and clarifying the precedence rules (external commands override aliases), the patch was revised twice with minor formatting fixes.

Now D. Ben Knoble is responding to Junio's latest suggestion about improving discoverability of both alias and external command features. Knoble expresses approval for this change, which would make these extensibility mechanisms more visible to users reading the main Git manual page.
