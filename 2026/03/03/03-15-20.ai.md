This is Junio Hamano's monthly "What's cooking in git.git" report, providing a comprehensive status update on all active development topics in the Git project. The report organizes patches into three categories: graduated to master', new topics, and cooking' (in-progress work).

Several notable topics have recently graduated to master:
- Aditya Garg added HTTP 401/403 test coverage for netrc authentication
- Justin Tobler cleaned up object-file.c code using container_of()
- Kristoffer Haugsbakk improved documentation for git-am and git-patch-id
- Patrick Steinhardt optimized shallow push handling in receive-pack
- Phillip Wood fixed mergetool doc building in meson builds
- New topics include:
  - Junio is rebooting the sideband sanitization work to prevent terminal corruption
  - Patrick Steinhardt is working on CI fixes for GitLab environment size limits
  - A series enhancing OIDmap cleanup functionality
  - Multiple small test cleanups and typo fixes

The cooking section highlights several significant ongoing efforts:
- Patrick Steinhardt's large-scale ODB (object database) source API restructuring
- The fsmonitor daemon implementation for Linux
- Configurable hook commands via git config
- Parallel hook execution support
- MIDX (multi-pack-index) compaction work from Taylor Blau
- SHA-1/SHA-256 interoperability work from brian m. carlson
- The report also notes several discarded topics that were superseded by other work or deemed not ready.

This report serves as the canonical reference for Git's development status, showing what changes are imminent for the next release (in next'), what's still being discussed (in seen'), and what has recently been merged to the main branch. The breadth of activity demonstrates Git's continued active development across areas ranging from core object storage to user-facing features and documentation.
