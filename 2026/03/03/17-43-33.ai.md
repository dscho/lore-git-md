This is a documentation patch that adds information about Git's support for external commands to the official documentation. The patch is the third iteration (v3) of a series that has already seen consensus on the approach.

The patch documents Git's long-standing but previously under-documented behavior where executables named `git-<command>` in the user's PATH can be invoked as if they were built-in Git commands. The documentation explains that these external commands take precedence over aliases and receive arguments passed through unchanged, while built-in commands still take priority. The implementation of this feature lives in `execv_dashed_external()` in git.c.

The v3 revision fixes a minor whitespace issue (spaces instead of tabs) that was present in v2. The content follows Junio Hamano's earlier suggestion to place this documentation in the "Environment Variables > System" section of git.adoc, alongside other PATH-related documentation. The patch is purely additive and uncontroversial, simply making existing behavior more discoverable without proposing any implementation changes.
