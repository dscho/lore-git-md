This is a documentation patch that adds explicit coverage of Git's support for external `git-*` commands in PATH. The patch follows up on Junio Hamano's suggestion to move the explanation from a standalone section to the "Environment Variables > System" part of `git.adoc`, where it fits alongside other PATH-related documentation.

The text explains that when Git doesn't find a built-in command, it looks for an executable named `git-<command>` in PATH and runs it with the original arguments. The documentation also notes this lookup happens before alias expansion. This behavior has existed for years in `execv_dashed_external()` but wasn't prominently documented until now.

The patch is straightforward and uncontroversial - it simply documents existing behavior that was previously only mentioned in passing in command help text. The v2 revision addresses Junio's feedback about placement while keeping the same core content. This makes the feature more discoverable for users who want to extend Git with their own commands without requiring changes to the Git binary itself.
