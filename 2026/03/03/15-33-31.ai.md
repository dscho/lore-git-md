This is the fourth patch in a five-part series introducing AI-assisted workflows for Git's localization (l10n) process, specifically focused on translating PO files. The series comes from Jiang Xin, the Chinese translation maintainer.

The patch adds comprehensive documentation in po/AGENTS.md detailing how AI agents should handle PO file translation, including:
- A structured workflow for batch processing translations
- JSON format specifications for efficient machine processing
- Quality checklists and validation steps
- Performance metrics showing significant efficiency gains (82% reduction in update-pot steps, 76% time reduction in update-po)

Key technical aspects include:
- The introduction of a GETTEXT JSON format for batch processing
- git-po-helper commands for splitting, comparing and concatenating translation files
- Detailed instructions for handling fuzzy entries, placeholders, and special characters
- Validation scripts to ensure msgid integrity and proper PO formatting

The documentation emphasizes that human translators remain the final authority, with AI providing assistance rather than replacing human review. Benchmark data shows the Qwen model successfully translated 127 entries (91 fuzzy + 36 untranslated) with 100% success rate in testing.

This appears to be a well-structured addition to the localization infrastructure, with clear technical specifications and measurable performance benefits. The patch builds on previous infrastructure changes in the series while maintaining backward compatibility with existing workflows.
