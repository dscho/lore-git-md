This is a platform compatibility patch from Patrick Steinhardt, part of his v2 series optimizing `git-upload-pack` performance by reducing write syscall contention. The patch introduces a `writev(3p)` compatibility wrapper for systems (notably Windows) that lack this POSIX system call.

The wrapper implements scatter-gather I/O by iterating through the iovec array and writing each buffer segment individually via `xwrite()`, accumulating the total bytes written. It handles partial writes and errors appropriately, using the new `cast_size_t_to_ssize_t()` helper from an earlier patch in the series for safe size conversions. The implementation is added to Git's compatibility layer with appropriate build system changes to enable it on Windows/MinGW where `writev` is unavailable.

This infrastructure work enables the subsequent performance optimizations in the series that will use `writev()` to combine header and data writes in the sideband protocol. The patch follows Git's standard pattern for platform compatibility shims, similar to existing wrappers like `git_pread()`. Testing on NonStop (which does support `writev`) and other platforms confirms the approach works across Git's supported environments.
