This is a documentation patch continuing the discussion about improving visibility of Git's external command and alias features. D. Ben Knoble responds positively to Junio Hamano's suggestion to add cross-references in the "GIT COMMANDS" section of git.adoc that would help users discover both alias configuration and external command functionality.

The proposed change would mention aliases (pointing to gitconfig documentation) and external commands (pointing to the environment variables section) right in the introductory paragraph of the GIT COMMANDS section, making these extensibility features more discoverable than their current placement in deeper documentation. This builds on Omri Sarig's earlier patch documenting the external command mechanism itself.

The thread shows consensus that these features - long supported but poorly documented - deserve more prominent visibility. Knoble's reply indicates agreement with Hamano's direction, suggesting this documentation improvement is likely to proceed once the wording is finalized. The change is purely additive and touches only Documentation/git.adoc, following Git's documentation standards.
