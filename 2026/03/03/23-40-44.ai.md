This is a bugfix patch addressing submodule fetching behavior that incorrectly assumed all submodule remotes are named "origin". The patch is the final version in a series that has undergone thorough review, with all previous feedback addressed.

The core change adds a new `get-default-remote` subcommand to `submodule--helper` that properly detects a submodule's default remote name instead of hardcoding "origin". This fixes cases where `git fetch --recurse-submodules` would fail for submodules with differently-named remotes. The implementation maintains backward compatibility by falling back to "origin" if default remote detection fails.
