This is a documentation patch that follows up on an earlier discussion about documenting Git's support for external commands. The original patch proposed adding a dedicated section to `git.adoc` explaining how Git can run external executables prefixed with "git-" from the user's PATH as if they were built-in commands. Maintainer Junio Hamano suggested moving this documentation under the "Environment Variables > System" section instead, noting that while the behavior was mentioned in passing in other help text, it deserved more prominent documentation.

In this follow-up, author Omri Sarig confirms they've revised the patch per Junio's suggestion, placing the documentation in the Environment Variables section. They've expanded the explanation slightly to include details about argument passing and precedence over aliases, while remaining open to feedback on the level of detail. The patch remains purely additive, filling a documentation gap for this long-standing but under-documented feature of Git's command dispatch system.
