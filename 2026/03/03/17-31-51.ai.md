This is the first patch in Derrick Stolee's v4 series improving environment handling in `git for-each-repo`. The patch focuses on testing the command outside a repository context, which is its typical real-world usage (e.g., for background maintenance).

The key changes modify `t/t0068-for-each-repo.sh` to:
1. Set `TEST_NO_CREATE_REPO=1` to prevent automatic test repo creation
2. Switch all test cases to use `--global` config instead of local repo config
3. Update test expectations to account for the global config context
4. Move the NULL config test to use `.gitconfig` instead of local config

The patch reveals that `for-each-repo` still relies on `the_repository` for config queries when run outside a repo context, similar to `builtin/config.c`. This dependency will need to remain until a better solution for repo-less config handling is implemented.

The test changes have been validated through discussion in previous iterations, with Junio Hamano confirming the isolation approach using `GIT_CEILING_DIRECTORIES` is correct. The patch maintains all existing test coverage while better reflecting real-world usage patterns.
