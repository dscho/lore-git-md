This is a test modernization series focused on improving t3700 (the test script for `git add`). The two patches aim to make the tests more robust by properly handling exit codes and using modern test helpers.

The first patch addresses a common test anti-pattern where Git's exit code gets suppressed in shell pipelines. It breaks these pipelines to properly capture exit status and simplifies some `wc -l` counting logic. This follows Git's test suite best practices for reliable failure detection.

The second patch converts all remaining `grep` and `! grep` calls to use the `test_grep` helper, which provides better failure diagnostics. This is part of the ongoing test modernization effort to replace direct shell commands with test helper functions that give more informative output when tests fail.

The series has gone through three iterations, with v3 splitting the changes into two focused patches per Junio's suggestion. The author has addressed feedback about commit message formatting and scope separation. The changes are mechanical but important for test reliability - they don't modify any test logic, just make failures more detectable and debuggable.
