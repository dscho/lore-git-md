This is the first patch in a five-part series introducing AI-assisted workflows for Git's localization (l10n) process, specifically focused on .po file handling. The patch adds infrastructure component to simplify location filtering in translation files.

The patch introduces a new `po/.gitattributes` file that configures Git filters to automatically strip location information from PO files when committing. This produces cleaner diffs and saves repository space. Two filter types are defined: one that strips both filenames and line numbers (used by most languages) and another that preserves filenames while removing line numbers (used by Chinese, Indonesian, and Catalan).

The accompanying changes to `po/README.md` reorganize the documentation, moving the location-stripping instructions to a new "Preparing a XX.po file for commit" section. This separation helps prevent AI tools from mixing these steps with the actual translation update process.

The implementation is careful to avoid applying filters to legacy or unmaintained PO files where the filtering could cause discrepancies between the index and working tree. Contributors still need to manually configure the filter drivers as documented.

This is a well-structured technical foundation for the AI-assisted translation workflows that follow in the rest of the series. The patch addresses previous feedback by clearly documenting the filter types and their language-specific applications.
