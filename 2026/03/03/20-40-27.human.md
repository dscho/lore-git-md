This is a test modernization patch series that improves Git's test suite by addressing two issues in t3700 (the test file for `git add` functionality).

The first patch fixes a common anti-pattern where Git's exit codes were being suppressed in pipelines (e.g. `git ... | grep ...`). The author now properly separates these into discrete steps to ensure test failures are properly detected. It also simplifies some `wc -l` counting logic.

The second patch converts all remaining `grep` and `! grep` calls to use Git's `test_grep` helper, which provides better failure diagnostics. This is part of the ongoing effort to modernize the test suite with more robust helpers.

The series has gone through three iterations, with v3 incorporating Junio's feedback to split the changes into two focused patches - one for exit code fixes and another for grep modernization. The changes are straightforward and uncontroversial, touching only test infrastructure with no behavior changes to the actual `git add` command being tested.
