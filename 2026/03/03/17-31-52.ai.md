Refactoring patch in the `for-each-repo` environment handling effort.

This is the second patch in Derrick Stolee's v4 series improving environment variable handling for repository operations. It extracts a new `sanitize_repo_env()` helper from `prepare_other_repo_env()`, separating the concerns of (1) stripping repository-specific environment variables from (2) setting GIT_DIR for a new repository. The helper will be used in a follow-up change where only the environment cleaning is needed without forcing a specific GIT_DIR.

The patch incorporates feedback from Jeff King (Peff) on naming and documentation - the helper was renamed from `clear_local_repo_env()` to better reflect its purpose, and the documentation now clearly explains the relationship between the two functions. The implementation preserves the existing behavior for GIT_CONFIG_* variables while cleaning other repository-specific settings.

This change is part of a broader effort to improve repository isolation and environment handling, particularly for cases like `git for-each-repo` that need to operate without assuming a repository context. The series has seen thorough review with no outstanding technical concerns, and this iteration addresses all previous feedback.
