This is part 4 of a 5-patch series introducing AI-assisted workflows for Git's localization (l10n) process, specifically focused on translating PO files. The series is from Jiang Xin, the Chinese translation maintainer.

This patch adds detailed AI agent instructions for translating PO files to the new po/AGENTS.md document. It provides a comprehensive workflow with shell scripts for extracting, batching, translating, validating, and merging translations. The process supports both git-po-helper (using a JSON format for batch processing) and traditional gettext tools.

Key technical details include:
- A batch translation approach that reduces interaction turns (86 → 56) while maintaining similar execution time
- Quality checklist covering accuracy, terminology consistency, placeholder handling, and other translation requirements
- Validation steps to ensure msgid integrity and proper PO file formatting
- Benchmark results showing the Qwen model successfully translating 127 entries (91 fuzzy + 36 untranslated) with 100% success rate

The documentation emphasizes that human translators remain in control, with AI providing assistance that must be reviewed before submission. The patch appears well-structured and thorough, with clear separation between the technical implementation details and the human review requirements.

This is part of the ongoing effort to modernize Git's localization workflow while maintaining quality standards. The series has addressed all technical feedback from the maintainer in v2 iteration, though some philosophical/legal questions about AI-generated content remain open.
