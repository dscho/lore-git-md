This is the first patch in Patrick Steinhardt's performance optimization series targeting lock contention in `git-upload-pack`. The patch removes a leftover debug message ("flushed.") that was inadvertently being sent to clients during packfile transfers since 2006. 

The message was originally added in commit b1c71b7281 but was never meant to be visible to end users - it was appearing in client output during clones. Patrick demonstrates this with a reproduction showing the message appearing in a Linux repository clone. The removal of this debug output is a preparatory change for subsequent buffering optimizations in the series.

This is a straightforward cleanup that eliminates an unintended side effect while maintaining existing behavior. The patch is well-motivated and clearly explained, with the change being obviously correct. As the first in a larger series addressing high-concurrency scenarios, it sets the stage for more substantial performance improvements to come.
