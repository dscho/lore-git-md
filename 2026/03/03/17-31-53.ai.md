This is the third patch in Derrick Stolee's v4 series improving environment handling in `git for-each-repo`, focusing on worktree support. The patch ensures the command works correctly when run from a worktree by properly handling environment variables and adding comprehensive test coverage.

The key changes include:
- Using the new `sanitize_repo_env()` helper (introduced in patch 2) to clean environment variables before running commands in child repositories
- Adding worktree-specific test cases that verify correct behavior when running from a worktree
- Moving configuration from local repo config to global config to properly test repository-less scenarios
- Testing environment variable handling including `GIT_CONFIG_PARAMETERS` and `GIT_CONFIG_GLOBAL`

The test suite now covers:
- Basic worktree operation
- Environment variable inheritance
- Global config handling
- Repository-less execution
- Edge cases around config propagation

The implementation builds on the established approach from earlier patches, with all major technical questions already resolved in previous iterations. This patch focuses specifically on worktree support while maintaining the series' goals of environment isolation and test reliability. The changes are well-contained and the test coverage is thorough, demonstrating the command's behavior in various worktree scenarios.

This continues the series' pattern of careful, incremental improvements to `git for-each-repo`'s environment handling, with each patch building on the last while maintaining backward compatibility and test reliability. The worktree support completes one of the key use cases for the command.
