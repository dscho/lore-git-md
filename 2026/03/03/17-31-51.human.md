This is the first patch in Derrick Stolee's v4 series improving environment handling in `git for-each-repo`. The patch focuses on testing the command outside of a repository context, which is a common real-world use case (like for background maintenance).

The key changes modify the test/t0068-for-each-repo.sh` test script to:
1. Set `TEST_NO_CREATE_REPO=1` to prevent automatic test repo creation
2. Use `--global` for all test config settings instead of local repo config
3. Update test expectations to account for the global config context

The patch reveals that `for-each-repo` still relies on `the_repository` global when handling config queries outside a repo context, similar to `builtin/config.c`. This dependency will need to remain until a better solution exists for config handling without a repository.

The changes are well-motivated by real-world usage patterns and carefully preserve all test coverage while adapting to the new global context. This is part of a larger effort to improve environment isolation in `for-each-repo`, with subsequent patches building on this foundation.
