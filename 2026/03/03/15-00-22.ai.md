Performance optimization in the sideband subsystem, part of Patrick Steinhardt's larger series reducing write syscalls in high-concurrency scenarios. This patch specifically targets `send_sideband()` to combine pktline writes using the new `writev_or_die()` wrapper introduced earlier in the series.

The change replaces two separate write syscalls (one for the pktline header, one for data) with a single `writev()` call that bundles both components in an iovec array. The implementation maintains all existing functionality including band selection and packet length calculations while cutting the syscall count roughly in half (from ~133k to ~67k writes when cloning the Linux repo).

The patch builds on infrastructure from previous patches in the series, particularly the platform-compatible `writev_or_die()` wrapper that handles partial writes and error conditions consistently. It touches only `sideband.c`, modifying the packet-sending loop to construct iovec structures while preserving the existing control flow and error handling.

Jeff King suggested this optimization approach, and the implementation follows the pattern established earlier in the series for batched writes. The change is mechanical but effective, demonstrating measurable performance gains in high-load scenarios without introducing new edge cases or platform dependencies.
