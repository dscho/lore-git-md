This is a bugfix patch in an ongoing thread about Windows-specific issues with `.git` directory validation. Phillip Wood identifies the root cause of test failures on Windows: the patch makes `stat("nul")` fail where it was previously ignored, breaking `test_cmp()` which uses `GIT_DIR=/dev/null git diff --no-index`. 

The core issue stems from Windows translating `/dev/null` to `nul`, and the new validation code treating stat failures as fatal errors. Phillip suggests special-casing `nul` in the setup code or `mingw_stat()`, while noting the need to verify behavior on POSIX platforms too. 

This reply advances the thread by pinpointing the Windows-specific failure mode, though Phillip defers to Windows experts for the actual fix.
