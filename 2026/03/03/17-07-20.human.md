This is a documentation patch adding clearer explanation of Git's support for external commands. Omri Sarig follows up on Junio Hamano's suggestion to document how Git looks for external `git-*` commands in PATH, moving the explanation from a standalone section to the Environment Variables documentation where it fits more naturally.

The patch now describes not just the basic lookup behavior (where Git will run any executable named `git-<command>` found in PATH when `<command>` isn't a built-in), but also clarifies that these external commands take precedence over aliases and receive the same arguments as built-ins would. This fills a documentation gap - while the behavior was technically mentioned in the `--list-cmds` and `--no-external-commands` help text, it wasn't prominently explained anywhere.

The discussion shows consensus on the value of documenting this extensibility feature, with only minor debate about optimal placement in the docs. The maintainer suggested the Environment Variables section as more appropriate than a dedicated section, and the author incorporated that feedback while slightly expanding the explanation. This is a straightforward, non-controversial improvement to Git's documentation.
