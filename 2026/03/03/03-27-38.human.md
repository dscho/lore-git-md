This is a discussion about path formatting options for the new `git repo-info` command, part of an ongoing effort to provide better repository metadata access. Ayush Jha responds to Lucas Seiki Oshiro's concerns about output cleanliness when using `--all` with multiple path formats.

Ayush proposes treating path format variants (absolute/relative) as "virtual" fields that are excluded from `--all` output by default, only appearing when explicitly requested. This would maintain clean `--all` output while still allowing scripts to request specific formats when needed, avoiding global state flags.

The thread shows the project's careful balancing act between plumbing command simplicity and user-facing flexibility. Junio Hamano has previously indicated a preference for the simpler global flag approach, but Ayush's suggestion offers a middle ground that might satisfy both camps. The discussion remains technical and constructive, with participants clearly trying to find the most maintainable solution.
