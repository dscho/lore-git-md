This is a review comment on a patch from Justin Tobler's repository statistics series, which adds comprehensive object store metrics to `git repo`. The series is now in its fifth iteration and has been acked by Junio Hamano for merging.

Patrick Steinhardt notes that while the helper function `print_keyvalue()` introduced in this patch (which consolidates repetitive key-value printing code) doesn't completely eliminate the risk of mismatched keys and values, it does significantly improve code readability. The helper function standardizes the output formatting for all repository statistics metrics, including reference counts, object type counts, and size measurements (both inflated and on-disk).

The comment comes late in the series' evolution - this was originally patch 2/6 in v3, and the series has since progressed to v5 with all planned functionality implemented. Patrick's brief but positive feedback suggests the change meets his approval, though he notes a minor remaining readability concern about potential key-value mismatches.
