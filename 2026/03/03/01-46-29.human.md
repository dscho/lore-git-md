This is the final patch in a documentation series from GSoC contributor Lorenzo Pegorari, standardizing command name formatting in the pack protocol documentation. It's part of a three-patch set that has already been reviewed and approved, with Junio Hamano providing initial feedback on the approach.

The patch makes purely presentational changes to `gitprotocol-pack.adoc`, normalizing how command names like `upload-pack` and `git-upload-pack` are formatted. It replaces unmarked command names with single-quoted versions (which render as italics in the final documentation) for consistency. The changes are mechanical but improve readability by making command names visually distinct from surrounding text.

This is a small but thoughtful documentation improvement that follows the project's conventions. The series as a whole demonstrates good attention to detail - each patch tackles a specific aspect of documentation polish (pronouns, structure, and now formatting) in a focused way. With all feedback addressed and no outstanding issues, this looks ready to merge.
