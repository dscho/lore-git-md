This is a discussion about path formatting in the `git repo-info` command, part of an ongoing series to add path-related fields. Ayush Jha responds to Lucas Seiki Oshiro's concerns about output cleanliness when using `--all` with multiple path formats.

Ayush proposes treating path format variants (absolute/relative) as "virtual" fields that would be excluded from `--all` output by default, only appearing when explicitly named. This would maintain clean `--all` output while still allowing scripts to request specific formats when needed, avoiding global state flags. The suggestion builds on earlier discussions about whether to use global flags (Junio Hamano's preference) versus per-field format modifiers (Tian Yuchen's proposal). Ayush's approach attempts to reconcile these by making format variants opt-in rather than always visible.

The thread continues to explore the tradeoffs between plumbing command simplicity and flexible output formatting, with this email focusing specifically on how to handle the `--all` flag without creating overly verbose output.
