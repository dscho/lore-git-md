This is a refactoring patch in Kristoffer Haugsbakk's series to add `--format` support to `git name-rev`. The patch originally aimed to standardize brace usage in `builtin/name-rev.c` but inadvertently introduced some inconsistent formatting of pointer arithmetic (`p+1` vs `p + 1`). 

Junio C Hamano noted the inconsistency in his review, pointing out that while the brace changes were correct, the patch partially fixed spacing around pointer arithmetic without addressing all instances. Kristoffer acknowledges this in his reply, explaining that clang-format unexpectedly modified some lines, and plans to revert those changes in the next version to maintain consistency.

The exchange is typical of Git's meticulous code review process - even small mechanical changes receive careful scrutiny for style consistency. The patch remains on track for inclusion, with Kristoffer demonstrating responsiveness to review feedback. This preparatory cleanup will enable the more substantial format-specifier functionality in patch 2/2 of the series.
