This is a technical follow-up in the `git checkout -m` autostash feature series, implementing an optimization suggested by Phillip Wood and approved by Junio C Hamano. The patch removes the redundant dry-run check in `unpack_trees()` when performing the actual checkout attempt first, only creating a stash if the checkout fails due to local changes. This change simplifies the control flow while maintaining the same behavior.

The author (Harald Nordgren) confirms the implementation passes all existing tests but notes this could mean either the optimization works correctly or that test coverage isn't exhaustive enough to catch potential edge cases. The change builds on the series' earlier work that unified conflict resolution behavior between `git checkout -m` and autostash operations while adding customizable conflict marker labels.

This appears to be the final implementation tweak before the feature is ready for merging, following resolution of all major technical concerns around submodule handling, error paths, and now the dry-run optimization. The patch maintains backward compatibility and integrates with the series' other improvements like silent stash creation and custom label support.
