This is the final patch in a bugfix series improving `git apply`'s error reporting, specifically addressing binary patch and garbage patch cases. The patch extends the consistent error reporting format ("error: corrupt patch at <file>:<line>") to binary patch parsing failures and garbage patch detection, completing the work started in earlier patches of this series.

The changes modify three error paths in `apply.c` to include the input file context, matching the pattern established in previous patches. The implementation adds test coverage in `t4100-apply-stat.sh` and `t4103-apply-binary.sh` to verify the new error messages, including cases for corrupt binary data, unrecognized binary formats, and patches containing only garbage lines.
