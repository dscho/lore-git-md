This is the first patch in a feature series (v6) that adds customizable conflict marker labels to `git stash apply`. The patch introduces three new options (`--ours-label`, `--theirs-label`, `--base-label`) that allow users to specify custom labels for conflict markers instead of the default "Updated upstream" and "Stashed changes" text.

The implementation adds the new options to the command-line interface and documentation while maintaining backward compatibility. A new test case in t3903-stash.sh verifies the custom labels appear correctly in conflict markers. The changes are focused and well-contained, touching only the stash subsystem's documentation, command parsing, and test coverage.

This functionality will be used by the later patches in the series when implementing autostash behavior for `git checkout -m`, where branch-specific labels will provide better context in merge markers. The patch appears technically sound with clear documentation and no obvious issues in the implementation.
