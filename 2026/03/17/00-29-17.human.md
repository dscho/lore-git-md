This is a small preparatory patch in Derrick Stolee's series enhancing the `git backfill` command for partial clones. The change is straightforward: it adds an include for `object-name.h` to `revision.h` to resolve a hidden dependency where `REV_INFO_INIT` uses `DEFAULT_ABBREV` from that header. 

This is typical housekeeping - ensuring headers properly declare their dependencies rather than relying on transitive includes. The patch is clean and focused, just adding one line to make the dependency explicit. It's the first of five patches that together will allow `git backfill` to handle revision arguments and pathspecs for more targeted blob downloads in blobless clones.

As an isolated change, this doesn't affect functionality but sets up the infrastructure needed for the more substantial revisions to come in the series. The commit message clearly explains the technical rationale without needing additional context.
