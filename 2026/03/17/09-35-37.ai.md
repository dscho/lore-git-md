This is part 2 of a 4-patch series implementing silent autostash creation during branch switching with conflicts. The patch adds a `silent` parameter to the autostash creation internals and introduces a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message.

The changes are straightforward plumbing work to support the series' goal of making `git checkout -m` automatically stash local changes when switching branches with conflicts. The implementation:
- Adds a `silent` parameter to `create_autostash_internal()`
- Moves the status message to stderr when not silent
- Introduces `create_autostash_ref_silent()` as a silent variant of the existing ref-based autostash creation
- Maintains backward compatibility with existing callers

The patch is a clean extension of the sequencer's autostash infrastructure, with no behavior changes for existing callers. It enables the subsequent patches in the series to perform silent stashing during checkout operations while preserving the current behavior for other autostash users like rebase`. The change is well-contained and follows the established pattern of the sequencer code.
