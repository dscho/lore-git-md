This is a test improvement patch that fixes a subtle issue in the test suite. The problem addressed is that piping `git status` output directly into `grep` would mask the exit code of the Git command if it failed. The patch modifies several tests in t2203-add-intent.sh to first capture the raw status output in temporary files before filtering it with grep, ensuring test failures are properly detected.

The changes are mechanical but important - each instance where `git status` was piped to grep has been replaced with a two-step process writing to an intermediate file. This affects tests checking status output in regular, porcelain, and porcelain-v2 formats. The patch maintains all existing test assertions while making the tests more robust by properly checking Git command success.

The fix is straightforward and clearly correct - it doesn't change any test behavior, just makes failure detection more reliable. This is the kind of small but valuable test suite improvement that experienced contributors often send to harden the test suite against false negatives.
