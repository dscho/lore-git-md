This is part 2 of a 4-patch series improving `git checkout -m` conflict resolution with autostash behavior. The series has gone through multiple iterations based on maintainer feedback, with this version focusing on architectural refinements.

The current patch adds silent autostash creation capability to the sequencer infrastructure. It introduces a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message, while maintaining the existing verbose behavior for other callers. The implementation:
- Adds a `silent` parameter to the internal autostash creation function
- Moves the status message to stderr when not silent
- Preserves all existing functionality while adding the new silent option

This change supports the series' goal of making branch switching with conflicts (`checkout -m`) automatically stash and restore local changes without cluttering output. The patch is cleanly focused and follows the project's style, with the new function properly declared in sequencer.h. It's a straightforward addition that enables the more user-friendly behavior planned for the checkout command in later patches.
