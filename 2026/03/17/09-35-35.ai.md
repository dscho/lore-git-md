This is version 6 of a feature patch series that enhances `git checkout -m` to use autostash behavior when switching branches with conflicts. The series has evolved through multiple iterations based on maintainer feedback, now focusing on architectural improvements to the checkout and stash subsystems.

The key changes in this version are primarily error handling improvements in the checkout logic, adding proper lock file rollback in error paths. The core functionality remains the same as v5: when `git checkout -m` encounters conflicts during branch switching, it will now automatically stash local changes, attempt the merge, and reapply the stash if successful. The series also introduces new stash labeling options (`--ours-label`, `--theirs-label`, `--base-label`) to provide better conflict marker context.

The implementation touches multiple components:
- `builtin/checkout.c` for the main merge/checkout logic
- `builtin/stash.c` for the new labeling options
- `sequencer.c` for autostash handling
- Extensive test coverage in t7201-co.sh (18 test cases) and t3903-stash.sh
