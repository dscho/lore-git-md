This is a refactoring patch from René Scharfe that replaces uses of `prio_queue` in LIFO (last-in-first-out) mode with the more specific `commit_stack` data structure. The change affects three files: `builtin/name-rev.c` and two negotiation implementations (`default.c` and `skipping.c`).

The patch makes the code's intent clearer by using a dedicated stack structure rather than repurposing a priority queue with a NULL compare function. It also provides type safety (working specifically with commits` rather than generic objects) and saves some memory by eliminating the tie-breaking counter that `prio_queue` maintains for each element.

The changes are mechanical and straightforward - replacing `prio_queue` initialization, push/pop operations, and cleanup with their `commit_stack` equivalents. The behavior remains identical since both implementations provide LIFO ordering in this configuration. The patch follows René's typical style of small, focused improvements to code clarity and type safety.
