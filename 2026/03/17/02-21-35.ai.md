This is the final patch in the series that improves Git's line-log functionality (`git log -L`). The patch updates the documentation to reflect that `-L` now supports various diff formatting and pickaxe options after the core changes in previous patches.

The documentation changes note that patch formatting options like `--word-diff`, `--color-moved`, `--no-prefix`, and whitespace handling (`-w`, `-b`) now work with `-L`, as do pickaxe options (`-S`, `-G`). This comes after the series routed line-log output through Git's standard diff pipeline instead of the previous `dump_diff_hacky()` approach.

The patch maintains the existing documentation about unsupported formats (like `--raw` and `--stat`) while adding the new capabilities. This aligns with the maintainer's guidance to clearly document both what works and what doesn't with the improved `-L` functionality. The change is straightforward and completes the documentation updates needed for the series.
