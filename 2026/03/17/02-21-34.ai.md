This is the third patch in a series improving Git's line-log functionality (`git log -L`). The patch adds comprehensive test coverage for the newly enabled diff options that now work with `-L` thanks to the series' core change of routing line-log output through the standard diff pipeline.

The test suite verifies that previously-ignored diff options now function correctly with `-L`, including:
- Formatting options like `--word-diff`, `--no-prefix`, and `--full-index`
- Whitespace handling with `-w` and `-b`
- Output indicators (`--output-indicator-*`)
- Direction reversal with `-R`
- Color-moved detection
- Pickaxe options (`-S`, `-G`)

The tests also cover edge cases like no-newline-at-eof markers and range boundary behavior. The implementation appears thorough, with careful attention to verifying both the presence of expected output (like proper index headers and funcname context) and the absence of artifacts from the old implementation. The test coverage matches the scope of functionality enabled by the series' main change, providing confidence that the integration with the standard diff pipeline works as intended across a wide range of diff options.
