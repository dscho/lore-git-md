Thread identity: Bugfix for commit-graph generation number computation regression introduced by Patrick Steinhardt's commit 024b4c9697, affecting dates after year 2514. Now at v2 with platform-specific handling improvements, incorporating Junio's suggested compile-time check refinement.

Core problem: The commit-graph format stores only 34 bits of commit dates (to save space) while timestamp_t uses 64 bits. When commits were parsed both from commit-graph (34-bit dates) and object database (64-bit dates), generation number calculations could mismatch during commit-graph writes, particularly for dates exceeding 34 bits. The v2 patch adds explicit handling for 32-bit timestamp_t systems, now being refined to use compile-time checks per Junio's suggestion.
