This is the final documentation patch in a series that improves Git's line-log functionality (`git log -L`). The patch updates the documentation to reflect that `-L` now properly supports various diff formatting options after the series routed line-log output through Git's standard diff pipeline.

The change adds a clear note that patch formatting options like `--word-diff`, `--color-moved`, and `--no-prefix` now work with `-L`, along with whitespace handling (`-w`, `-b`) and pickaxe options (`-S`, `-G`). This documentation follows the maintainer's suggested approach of explicitly listing both supported and unsupported formats (the latter was already documented).

The patch is straightforward and uncontroversial, simply documenting the new capabilities enabled by the earlier technical changes in the series. It maintains the existing documentation structure while adding the new information in a clear, concise way. The series as a whole represents a significant improvement to line-log` functionality by making it properly integrate with Git's diff machinery.
