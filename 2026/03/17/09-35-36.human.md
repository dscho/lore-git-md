This is the first patch in a feature series enhancing `git stash apply` with customizable conflict markers. The patch introduces three new options to `git stash apply`: `--ours-label`, `--theirs-label`, and `--base-label`, allowing users to specify custom labels for conflict markers instead of the default "Updated upstream" and "Stashed changes".

The implementation is straightforward, adding the new options to the command-line interface and documentation while maintaining backward compatibility. A new test case verifies the functionality by checking that the custom labels appear correctly in conflict markers. The changes are cleanly contained to the stash subsystem, touching only the documentation, command parsing, and adding one test.

This appears to be a well-crafted patch that solves a specific usability pain point - making conflict markers more descriptive during stash application. The test coverage is appropriate and the documentation updates are thorough. As part of a larger series improving conflict resolution workflows, this foundational change enables better context in merge conflicts when stashes are involved.
