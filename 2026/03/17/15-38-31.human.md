This is a minor typo-fix patch in Patrick Steinhardt's build system improvement series. Kristoffer Haugsbakk points out two small grammatical issues in the commit message for patch 7/8, which splits compatibility sources into a separate static library to prepare for precompiled header support.

The corrections are straightforward: fixing "compileir" to "compiler" (or possibly "compilation") and adding a missing comma after "Like this". These are purely editorial suggestions that don't affect the technical content of the patch. The series is already in its second iteration and has received positive reviews from Phillip Wood, with these minor fixes being the only remaining nits.

The patch itself remains mechanically sound - it reorganizes the build to handle special cases where certain compatibility files intentionally avoid including git-compat-util.h, which will be implicitly included when precompiled headers are introduced in the next patch. The changes are well-motivated and part of a larger effort to achieve 40% build speed improvements through PCH support.
