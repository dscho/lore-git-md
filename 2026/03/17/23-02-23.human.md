Bugfix for the diff-highlight contrib script, addressing an edge case when removing final newlines.

Jeff King fixes an issue in the `diff-highlight` Perl script (a contrib tool that colorizes diffs) where it incorrectly handles diffs that remove a final newline. The script pairs lines for highlighting, but was getting confused when the only difference was the presence/absence of a newline, producing malformed output that could break `interactive.diffFilter`.

The patch adds a check to skip highlighting when the lines are identical (which shouldn't normally happen in minimal diffs, except in this newline case) and includes a test case. The fix is straightforward and well-explained, with Jeff noting there's a more comprehensive solution possible (chomping all input lines) but opting for the minimal fix here.

This is a small but important fix for a corner case in a widely-used contrib tool, coming from one of Git's most experienced contributors. The patch includes both the code change and a test, following Git's standard practices.
