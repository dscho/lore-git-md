This is a feature patch adding a new repository information key to expose the Git directory path programmatically.

The patch introduces a `paths.git_dir` key to `git repo info` that returns the same value as `git rev-parse --git-dir`. This provides a more direct way for tools to access the repository's gitdir path without shelling out to a separate Git command. The implementation adds a new field to the repo info reporting mechanism in `builtin/repo.c` and includes corresponding documentation and tests.

The test case verifies the new key matches the existing `rev-parse` behavior, which is a good practice for maintaining consistency. The patch touches only three files - documentation, implementation, and tests - following Git's typical patch structure.
