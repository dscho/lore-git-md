This enables several previously-unsupported diff features to work with `-L`, including `--word-diff`, `--color-moved`, and pickaxe options.

The change makes line-log output more complete by adding missing index lines, file mode headers, and funcname context. It's a user-visible change that may affect tools parsing `-L` output, but benchmarks show no performance impact. The implementation introduces callback wrappers to filter xdiff output to tracked line ranges while maintaining proper diff formatting.
