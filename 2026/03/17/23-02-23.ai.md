Bugfix for the diff-highlight contrib script, addressing an edge case when removing final newlines.

Jeff King fixes an issue in the diff-highlight Perl script where it would incorrectly highlight identical lines when the only difference was a trailing newline removal. This happens in cases like removing the final newline from a file, producing a diff with identical content lines followed by "\No newline at end of file". The script would try to highlight these as matching pairs, leading to malformed output that could break diff filters.

The fix modifies the `is_pair_interesting()` function to explicitly detect and skip these identical-line cases. A new test case verifies the behavior. The commit message notes this could potentially be addressed more thoroughly by normalizing newline handling throughout the script, but opts for the minimal fix for now.

The patch is small and focused, with clear explanation of both the problem and solution. It includes a regression test and comes from a trusted contributor (Jeff King) who is known for precise fixes in this area. The change is low-risk as it only affects the optional diff-highlight contrib script.
