This is a feature patch adding a new repository information key to expose the Git directory path via `git repo info`.

Jayesh Daga proposes adding a `paths.git_dir` key to `git repo info` that returns the same value as `git rev-parse --git-dir`. The implementation adds a new field handler in builtin/repo.c that calls the existing `repo_get_git_dir()` function, updates the documentation, and includes a test verifying the output matches `rev-parse --git-dir`.

The change is straightforward and well-contained, with clear documentation and test coverage. This provides a programmatic way to access the Git directory path without shelling out to `rev-parse`, which could be useful for tools and scripts that need this information. The patch follows Git's coding style and appears to be a clean addition to the existing repo info infrastructure.
