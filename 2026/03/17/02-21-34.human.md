This is the third patch in a series improving Git's line-log functionality (`git log -L`). The patch adds comprehensive test coverage for the newly enabled diff options that now work with `-L` thanks to the series' core changes.

The tests verify that various diff formatting and filtering options now properly integrate with line-log:
- Basic diff formatting (index lines, file mode headers, funcname context)
- Word-diff variants (`--word-diff`, `--word-diff-regex`)
- Prefix controls (`--no-prefix`, `--src/dst-prefix`)
- Output indicators (`--output-indicator-*`)
- Whitespace handling (`-w`, `-b`)
- Direction reversal (`-R`)
- Color-moved detection
- Pickaxe options (`-S`, `-G`)
- Edge cases (no-newline-at-eof, range boundaries)

The test suite is thorough and well-structured, covering both the happy path and boundary conditions. It demonstrates the expanded capabilities while also documenting expected behavior for future maintenance. The tests follow Git's standard patterns and include comments explaining the verification logic.

This patch builds on the previous two in the series (which fixed crashes and implemented the core diff pipeline integration) by proving the functionality works as intended. The test coverage gives confidence that the changes don't introduce regressions while enabling the new features.
