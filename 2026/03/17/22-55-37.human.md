This is a documentation patch addressing discoverability of cherry-pick conflict information. Florian Best follows up on Phillip Wood's suggestion to improve the cherry-pick man page by adding an example showing how to use `git show CHERRY_PICK_HEAD` during a conflicted cherry-pick operation.

The patch (attached as a GitHub PR) implements the documentation improvement that was agreed upon in the thread. The discussion had concluded that adding a new `--show-current-patch` flag would be redundant since the existing `CHERRY_PICK_HEAD` mechanism already offers equivalent functionality with more flexibility through standard diff options.

This appears to be a straightforward documentation update that cleanly resolves the original concern about discoverability without introducing new code. The patch focuses on the cherry-pick man page's Examples section, making the existing capability more visible to users who encounter conflicts. The change aligns with Git's philosophy of documenting and promoting composable plumbing commands rather than adding specialized porcelain.
