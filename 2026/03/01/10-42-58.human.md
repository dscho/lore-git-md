This is a refactoring patch as part of the ongoing `the_repository` removal effort. The first in a two-part series, it relocates the `editor_program` global variable from environment.c to editor.c where it's actually used.

The change moves the variable's definition and introduces a new helper function `set_editor_program()` to handle configuration. The patch maintains the same initialization timing and error reporting for invalid editor values, ensuring no user experience regression. 

This appears to be a straightforward mechanical change following established patterns for eliminating global state. The patch is cleanly focused - touching only editor.[ch] and environment.[ch] - and comes with a clear commit message explaining the motivation and approach. 

As part of a larger project-wide cleanup, this seems like a solid incremental step that shouldn't introduce controversy. The second patch in the series will tackle the sequence editor's use of `the_repository`.
