This is a UI improvement patch for git-gui, Git's graphical interface. The change adds visual highlighting to comment lines in the commit message editor, making it clear which lines will be stripped out (as comments) when the message is processed.

The patch modifies `git-gui.sh` to add gray highlighting for comment lines, matching the behavior of `wash_commit_message` which strips these lines. The implementation uses Tcl's text widget features to apply styling and updates it whenever the message changes. 

The author notes some uncertainty about the Tcl implementation quality, particularly around duplicating the comment-matching regex from the wash procedure. This suggests the patch might benefit from review by someone more familiar with git-gui's Tcl codebase. The change itself is straightforward and addresses a real usability issue - currently there's no visual indication that comment lines will be removed from the final commit message.
