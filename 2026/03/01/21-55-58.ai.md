Git GUI improvement patch. This is a user interface enhancement for git-gui that visually distinguishes comment lines in commit messages (those that will be stripped by `wash_commit_message`) by displaying them in gray. The patch adds Tcl code to apply a "commit_comment" tag with gray foreground color to matching lines and updates the highlighting whenever the message is modified.

The implementation copies the comment-matching regex from `wash_commit_message` (acknowledging this as a potential code smell) and applies the styling via Tk text widget tags. The author notes their limited Tcl experience and invites feedback on the implementation approach, particularly regarding the regex duplication.

This appears to be a straightforward quality-of-life improvement for git-gui users, making it immediately obvious which parts of their draft commit message won't be included in the final commit. The patch touches only the git-gui.sh file with 19 lines added. While the implementation could potentially be refined (as noted around the regex handling), the core idea seems sound and useful.
