Git GUI improvement patch series introducing visual distinction for commit message comment lines in git-gui. The initial patch adds a "commit_comment" tag with gray foreground color to lines matching the same regex as `wash_commit_message` (acknowledging potential code smell from regex duplication). Implementation is in Tcl via Tk text widget tags in git-gui.sh (19 lines added). Author notes limited Tcl experience and seeks feedback on approach, particularly regarding the regex handling. The change provides immediate visual feedback about which parts of draft commit messages will be stripped, improving user experience for git-gui commit message composition.
