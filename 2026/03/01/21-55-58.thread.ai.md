Git GUI improvement patch series introducing visual distinction for commit message comment lines in git-gui. Wolfgang Faust's initial patch adds a "commit_comment" tag with gray foreground color to lines matching the same regex as `wash_commit_message` (acknowledging potential code smell from regex duplication), implemented in Tcl via Tk text widget tags in git-gui.sh (19 lines added). Johannes Sixt (Hannes) provides detailed feedback on the implementation, suggesting technical improvements: simplifying the regex pattern with -line matching, restructuring the loop to avoid nested list indexing, and reusing computed indices. He endorses the core idea of graying out comment lines rather than highlighting them, confirming this provides better visual feedback about what will be stripped from the final message. Hannes also notes formatting issues with the patch submission and recommends using Gitgitgadget for future contributions. Open questions remain about the best practices for Tcl/Tk text widget tag handling and regex processing in this context. The change would improve git-gui's commit message composition experience by making comment lines immediately distinguishable.
