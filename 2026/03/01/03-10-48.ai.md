This is a Google Summer of Code (GSoC) proposal for improving the new `git repo` command, specifically focusing on the `git repo info` subcommand. The proposal comes from Jayatheerth Kulkarni, an active Git contributor with several merged patches to their name, including fixes for submodule behavior and test modernization.

The proposal outlines four main objectives: (1) implementing category-based querying in `repo info` to replace the current exact-match binary search, (2) removing reliance on the `the_repository` global variable as part of Git's ongoing libification effort, (3) adding comprehensive path resolution features to match `git rev-parse` functionality, and (4) adding support for sparse-checkout and submodule awareness. The work builds on Lucas Oshiro's GSoC 2025 work that introduced the initial `git repo` command.

The proposal demonstrates strong familiarity with Git's internals, particularly around path handling and repository state management. Jayatheerth has already contributed relevant preparatory work, including patches to `builtin/repo.c` and path-related fixes in `dir.c`. The timeline is well-structured across the GSoC period, with clear milestones for each phase of development and buffer time for code review cycles. The proposal is technically sound and addresses an area of active development in Git's evolution toward more structured repository introspection.
