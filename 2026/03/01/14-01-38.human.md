This is a feature patch exposing repository metadata through the `git repo` command. Pushkar Singh adds a new `path.common-dir` field to complement the existing path-related fields in `git repo info`, mirroring what's available via `git rev-parse --common-dir`.

The patch adds a straightforward helper function `get_path_common_dir()` that retrieves the common directory path from the repository and formats it according to the requested path format (absolute, relative, etc.). The implementation follows the same pattern as the existing path-related fields in the command.

The change is small and focused, touching only `builtin/repo.c` to add the new field alongside similar existing ones like `path.git-dir` and `path.toplevel`. The commit message clearly explains the purpose and relationship to existing functionality. This appears to be a well-contained addition that provides structured access to repository metadata that was previously only available through `rev-parse`.
