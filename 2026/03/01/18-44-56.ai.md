This is part 8/12 of Adrian Ratiu's config-based hooks series, implementing out-of-repo hook execution support. The patch enables `git hook run` to work outside a Git directory when hooks are defined in global/system configs, while still excluding filesystem-based hooks (which require a repository).

The key changes allow the hook subsystem to:
1. Operate without a gitdir by using `RUN_SETUP_GENTLY` instead of `RUN_SETUP`
2. Create temporary config caches for out-of-repo invocations that get cleaned up after use
3. Skip filesystem hook lookup when outside a repository
4. Add test coverage showing global hooks work in nongit contexts while filesystem hooks remain restricted

The implementation handles cache lifecycle carefully - in-repo calls use the persistent `r->hook_config_cache` while out-of-repo calls get a temporary cache that's freed after use. This maintains performance for the common case while supporting the new out-of-repo functionality.

The tests demonstrate the new capability by configuring a global hook and verifying it runs from a nongit directory, while also confirming the hook listing works as expected. This builds on the series' earlier config parsing work while keeping the filesystem hook behavior unchanged when outside a repository.
