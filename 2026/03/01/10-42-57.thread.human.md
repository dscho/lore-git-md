Shreyansh Paliwal has started a refactoring effort to remove global state from Git's editor subsystem as part of the ongoing project-wide elimination of `the_repository` variable. The two-patch series focuses on editor.c, which handles Git's text editor integration for commit messages and similar operations.

The first patch, now under discussion, relocates the `editor_program` global variable from environment.c to editor.c where it's actually used, introducing a new `set_editor_program()` helper function to maintain the existing initialization behavior. This follows the project's established pattern for eliminating globals by moving variables to their logical homes and providing controlled access. The change is mechanical and well-contained, touching only editor.[ch] and environment.[ch] while preserving all functionality.

This work aligns with the broader `the_repository` removal project that René Scharfe and others have been driving across the codebase. The second patch in the series will tackle removing `the_repository` usage from the sequence editor functionality. So far the patch appears uncontroversial, with no objections or questions raised in the initial discussion.
