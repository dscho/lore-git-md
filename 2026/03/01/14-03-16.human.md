This is part of an ongoing effort to move repository introspection functionality from `git rev-parse` to a new `git repo info` command. The patch adds structured output for the common directory path via a new `path.common-dir` field, mirroring what `git rev-parse --common-dir` provides but in a more machine-readable format.

The implementation follows the established pattern seen in previous patches in this series, using `repo_get_common_dir()` to get the path and respecting the `--path-format` flag for consistent path representation. The change is small and focused, adding just the new capability with corresponding tests (though the test changes aren't shown in the diff).

The thread context shows this work has consensus as an incremental step toward making `git repo` the canonical place for repository metadata queries. The patch avoids broader unresolved questions about path resolution semantics by deferring to ongoing discussions while providing the mechanical infrastructure.
