This is a test improvement patch that fixes a subtle issue in the performance test suite. The test `p5304-prune.sh` was checking the output of `git count-objects` by piping it to `grep`, which could mask failures if `count-objects` failed but `grep` succeeded. The patch changes this to first write the output to a temporary file, then grep that file, ensuring the exit code of `git count-objects` is properly evaluated.

The change is small but meaningful - it makes the test more robust by properly detecting failures in the `count-objects` command rather than just checking its output. This is the kind of careful attention to detail that helps maintain test reliability. The patch follows Git's coding style and includes a clear commit message explaining the rationale.
