This is a refactoring patch series that's part of the ongoing `the_repository` removal effort, specifically targeting encoding-related global variables. Tian Yuchen is working to migrate `git_commit_encoding` and `git_log_output_encoding` from global state to repository-specific storage.

The series has evolved through three versions based on feedback, with v3 taking a different architectural approach than v2. The key insight is that these encoding settings need eager validation during config parsing, so they're being moved directly into `struct repository` rather than the originally proposed `repo_settings`. The changes touch over 30 files across commit handling, mail operations, and revision walking.

While the core functionality remains the same, the patchset introduces repository-aware versions of encoding-related APIs and updates all callers to pass through the repository context. The author notes this prepares the ground for future config machinery improvements while maintaining current behavior. The series appears well-scoped and follows established patterns for global variable migration in the project.
