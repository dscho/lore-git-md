Gitk UI improvement: This patch series adds a "Links" color option to gitk's Preferences dialog, allowing customization of link colors that were previously hardcoded. The change improves dark theme readability and follows gitk's existing color configuration patterns. Maintainer Johannes Sixt has approved the technical approach and queued the patch after three iterations that addressed feedback about commit message style and contribution conventions. The implementation is straightforward - a 10-line UI addition exposing the previously internal `linkfgcolor` variable. This is a focused quality-of-life improvement that's now cleared all review requirements.
