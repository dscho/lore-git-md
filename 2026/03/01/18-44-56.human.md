This is patch 8/12 in Adrian Ratiu's config-based hooks series, implementing out-of-repo hook execution support. The patch allows `git hook run` to work outside a Git directory when hooks are defined in global/system configs, while still excluding filesystem-based hooks (which require a repository).

The key change is marking the `git hook` command with `RUN_SETUP_GENTLY` instead of `RUN_SETUP`, allowing it to proceed without a Git directory. The implementation handles this by creating temporary config caches for out-of-repo cases that get cleaned up after use. The patch includes tests showing global hooks work in a nongit context while filesystem hooks remain restricted to repositories.

This is a natural extension of the config-based hooks functionality introduced earlier in the series. The implementation follows established patterns for handling out-of-repo cases and maintains the safety of filesystem hooks. Review feedback from Emily Shaffer (now a Jujutsu contributor but still active in Git's hook discussions) appears to have been incorporated through her signed-off-by. The patch keeps the series moving toward its goal of making hooks more flexible while maintaining backward compatibility.
