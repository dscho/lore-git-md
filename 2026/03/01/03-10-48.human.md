This is a GSoC (Google Summer of Code) proposal for improving the new `git repo` command, specifically focusing on the `git repo info` subcommand. The proposal comes from Jayatheerth Kulkarni, an active Git contributor with several merged patches to their name, including fixes in submodule handling and test modernization.

The proposal outlines four main objectives: (1) implementing category-based querying to replace the current exact-match system, (2) removing reliance on the `the_repository` global variable as part of Git's ongoing libification effort, (3) adding comprehensive path resolution features to match `git rev-parse` functionality, and (4) improving support for sparse checkouts and submodule awareness. The work builds on previous GSoC work by Lucas Oshiro that introduced the initial `git repo` command.

Jayatheerth demonstrates solid familiarity with the codebase, having already contributed patches touching `builtin/repo.c` and related subsystems. The proposal includes a detailed 12-week timeline with clear deliverables for each phase, from community bonding through implementation and final documentation. The author's prior contributions (including a patch in Git Rev-News) and demonstrated understanding of Git's internals suggest they are well-prepared for this work. The proposal is thorough and addresses an area of active development in Git's evolution toward better programmatic interfaces.
