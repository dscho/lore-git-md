This is a small utility patch in Adrian Ratiu's config-based hooks series (v3, 04/12). It adds a new helper function to the string-list API that combines lookup and deletion of items in an unsorted string list.

The patch introduces `unsorted_string_list_remove()` which finds and removes the first item matching a given string, optionally freeing its `util` pointer. This is a convenience wrapper around existing functions that will be used in subsequent patches of the series. The implementation is straightforward and follows the pattern of other string-list helpers.

The change is well-contained with proper documentation in the header and implementation files. It has been suggested by Patrick Steinhardt and fits naturally into the ongoing work to modernize Git's hook infrastructure. While small, this utility function helps reduce boilerplate code in the larger series.
