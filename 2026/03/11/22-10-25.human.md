Platform compatibility patch updating Git's IMAP send functionality to use modern OpenSSL APIs, addressing deprecation warnings in OpenSSL 4.0. This is the first of three patches in v2 of the series, which has been restructured based on security feedback from the previous version.

The patch replaces direct access to OpenSSL ASN1_STRING structure fields with proper accessor functions (`GENERAL_NAME_get0_value`, `ASN1_STRING_get0_data`, `ASN1_STRING_length`) that have been available since OpenSSL 1.1.0. The changes maintain the same security checks for embedded nulls in certificate strings that could bypass hostname matching, addressing concerns raised in the v1 discussion.

The update is focused on the subject alternative names verification in `imap-send.c`, keeping the same logic but using the newer API. The patch series shows careful attention to maintaining security while modernizing the code, with no outstanding objections to this particular change in the thread.
