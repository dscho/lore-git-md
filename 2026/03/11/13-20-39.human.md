This is a refactoring series addressing two cases of strbuf overuse in the codebase, following up on Junio's earlier work. The patches clean up string handling in worktree-related functions and list-objects filter parsing.

The first patch changes `write_worktree_linking_files()` to take plain string parameters instead of passing strbufs by value, which was unnecessary for this use case. The second patch rewrites the combine filter parsing in `list-objects-filter-options.c` to use direct string walking with `strchrnul()` rather than splitting into an array of strbufs. The v2 iteration incorporates feedback from Jeff King, simplifying the string handling and fixing edge cases around trailing '+' characters.

The changes are focused and well-explained, with clear commit messages detailing the motivation and implementation.
