This is a build system patch addressing an EditorConfig formatting regression. The thread has already converged on a solution, with Junio Hamano now acknowledging the fix.

The issue stemmed from how EditorConfig interprets glob patterns with path separators, which inadvertently stopped style rules from applying to subdirectories after hook templates were added to the pattern. Patrick Steinhardt's fix splits the configuration into two sections - one for general file patterns and another specifically for hook templates - to work around the glob interpretation quirk.

Phillip Wood reviewed and agreed with both the problem analysis and solution, explicitly endorsing the minor duplication in the config as preferable to more complex glob patterns. Junio's brief reply indicates he's satisfied with the resolution and likely to pick up the patch. The change is small, focused, and uncontroversial, ensuring consistent editor formatting continues to apply throughout Git's source tree.
