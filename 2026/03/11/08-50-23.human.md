Feature: Adding advice for handling uncommitted changes during branch switches

This is the fourth iteration of Arsh Srivastava's GSOC microproject to add a new advice type (`ADVICE_STASH_BEFORE_CHECKOUT`) that helps users when switching branches with uncommitted changes. The patch series has evolved through review feedback, with v4 addressing several key points from maintainers.

The core functionality remains: when users attempt to switch branches with local modifications that would be lost, Git will now suggest using `git stash` to preserve changes, while also clearly warning about the irreversible nature of the `-m` merge option. The advice is configurable via `advice.stashBeforeCheckout` and follows the pattern of existing advice functions.

Notable changes in v4 include:
- Explicit warnings about the risks of `git checkout -m`
- Better integration with existing warnings in `unpack-trees.c`
- Comprehensive test coverage
- Clear differentiation from similar advice like `ADVICE_COMMIT_BEFORE_MERGE`
