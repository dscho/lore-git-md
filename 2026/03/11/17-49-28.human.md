This is the second patch in a 3-part series adding advice for handling uncommitted changes during branch switches, part of a completed GSOC microproject. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when switching branches with local modifications.

The advice now suggests using `git checkout -m` as the primary solution for carrying changes to the new branch, replacing the previous two-step stash/pop recommendation. The implementation adds the new advice enum, config setting, and updates the message in `advice.c` to be more direct. 

This iteration follows extensive review, with v5 incorporating all maintainer feedback - notably Junio C Hamano's guidance on safety messaging and Patrick Steinhardt's input on proper integration. The series demonstrates clean adoption of Git's advice patterns while addressing the specific UX pain point of branch switching with dirty files.

The patch is well-contained, touching only the advice subsystem with clear documentation updates. As part of a mentored GSOC project that went through five review iterations, it represents a polished contribution that aligns with Git's code quality standards.
