This is a test improvement for the CVS interoperability tests. The patch fixes error reporting when CVS initialization fails in `t9200-git-cvsexportcommit.sh`.

Currently, if CVS setup fails (e.g. when CVS isn't installed), the test exits with a generic error. The patch wraps the CVS initialization in a `skip_all` check, which provides a more informative message when CVS isn't available. It also moves the Git repository setup into its own `test_expect_success` block rather than lumping it together with the CVS checks.

The changes are straightforward and improve test robustness - when CVS isn't present, the test will now clearly skip with a meaningful message rather than failing cryptically. The patch follows Git's test conventions by using the standard `skip_all` mechanism for missing dependencies.
