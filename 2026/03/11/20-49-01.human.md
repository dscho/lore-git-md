This is a test infrastructure patch that improves the readability of unit test output by displaying symbolic names for common escape sequences (like `\n`, `\t`) rather than their octal representations (like `\012`). The patch comes from Pablo Sabater as part of a Google Summer of Code project.

The change modifies `print_one_char()` in test-lib.c to recognize and display readable names for standard control characters while maintaining backward compatibility - unrecognized control characters still print in octal format. The patch also updates test cases in test-example-tap.c and t0080-unit-test-output.sh to match the new output format.

Junio C Hamano has reviewed the patch and given his approval, stating "Looking good. Will queue." This version (v2) specifically addresses an issue from v1 where the backslash/quote display format was unintentionally changed - it now preserves the exact previous output format for those cases while still implementing the core readability improvement.

The patch is focused and well-contained, with clear test coverage demonstrating both the new behavior and the preserved backward compatibility. As part of a GSoC project, it shows good attention to detail in addressing feedback while delivering a straightforward quality-of-life improvement for developers debugging test failures involving control characters.
