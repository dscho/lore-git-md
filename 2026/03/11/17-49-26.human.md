This is the final version (v5) of a GSOC microproject adding advice for uncommitted changes during branch switches. The patch series introduces a new `ADVICE_STASH_BEFORE_CHECKOUT` advice that warns users about potential loss of local changes when switching branches, suggesting both stashing and (with appropriate warnings) using `git checkout -m` as alternatives.

The key changes in this version address maintainer feedback from Junio C Hamano and others:
- Split the irreversible merge warning into two lines for better test readability
- Fixed trailing whitespace while preserving warning content
- Maintained the core warning about `-m` merge behavior potentially causing data loss
- Cleaned up the patch series organization, removing redundant patches from earlier versions

The implementation now properly integrates with Git's existing advice system and includes comprehensive test coverage in `t6439-merge-co-error-msgs.sh` and `t7406-submodule-update.sh`. The advice can be disabled via `git config advice.stashBeforeCheckout false`.

This represents the culmination of five review iterations with guidance from Phillip Wood, Patrick Steinhardt, and Karthik Nayak, demonstrating the project's mentoring process. The final version addresses all technical and UX concerns while maintaining clear warnings about the risks of using `-m` for irreversible merges.
