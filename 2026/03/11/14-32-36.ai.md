This is a review comment in the ongoing build system improvements series from Patrick Steinhardt. Phillip Wood acknowledges the significant 40% build speedup from precompiling git-compat-util.h via Meson's PCH support, but questions the placement of the precompiled header file in the tools/ directory. He suggests following Meson's documentation recommendation of using a dedicated "pch" or "precompiled" directory instead of mixing it with build scripts.

The technical context is that this is the final patch in an 8-part series that both reorganizes build tooling into a new tools/ directory and introduces PCH support. The series has already seen review from Junio C Hamano (who raised workflow concerns about Coccinelle relocation) and now Phillip Wood focusing on the Meson implementation details. The key open question here is whether the tools/ directory is the most logical home for the precompiled header or if a more specialized location would be clearer.
