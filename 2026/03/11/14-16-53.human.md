This is a build system patch fixing an EditorConfig regression. Phillip Wood replies to Patrick Steinhardt's earlier patch that addressed how glob patterns in `.editorconfig` were being interpreted after hook template files were added to the matching pattern.

The issue stemmed from EditorConfig's handling of path separators in glob patterns - when a pattern includes a path (like `templates/hooks/*.sample`), it causes all other patterns in that section to only match files in the same directory as the `.editorconfig` file. Patrick's solution splits the configuration into two sections to avoid this behavior while maintaining consistent formatting rules.

Phillip agrees with the approach, noting the alternative (using complex glob patterns with `{,**/}`) would be harder to read and maintain. The exchange is brief and technical, with both contributors clearly understanding the subtle EditorConfig specification details involved. The fix is straightforward and uncontroversial, addressing a specific regression in editor formatting rules.
