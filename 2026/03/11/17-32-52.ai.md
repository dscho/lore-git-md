This is a build system patch addressing an EditorConfig regression. Junio C Hamano acknowledges the fix proposed by Patrick Steinhardt and reviewed by Phillip Wood for the `.editorconfig` file. The issue stemmed from how path separators in glob patterns affected style rule application across subdirectories.

The solution splits the configuration into two sections - one for general file types and another specifically for hook templates - to work around EditorConfig's glob interpretation behavior. Phillip Wood concurs with this approach, agreeing that the minor duplication is preferable to complex, hard-to-maintain glob patterns. The patch maintains consistent editor formatting while keeping the configuration readable.

This appears to be a straightforward technical fix with clear consensus between the involved parties. The change is small in scope, touching only the build system's configuration file, and has received explicit approval from both the original reporter and reviewer.
