Feature: New advice for stashing changes before branch switches

This is the first patch in a 3-part series (v5) that adds a new advice message when users try to switch branches with uncommitted changes. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` which warns about potential overwrites and suggests using `git stash` to preserve changes.

The implementation follows Git's existing advice patterns, with a new function `advise_on_checkout_dirty_files()` that lists affected files and provides stash instructions. The advice can be disabled via `advice.stashBeforeCheckout` config. Documentation is added to `advice.adoc`.

This version incorporates feedback from multiple reviewers (Junio C Hamano, Phillip Wood, Patrick Steinhardt) across previous iterations. The series has evolved through five versions to reach its current state, with v5 specifically addressing test formatting and message clarity. The patch appears well-integrated with existing advice infrastructure and demonstrates careful attention to user experience.
