This is a refactoring patch that removes reliance on the `the_repository` global variable in `builtin/mktree.c`, part of the ongoing `the_repository` removal effort. The patch passes the repository pointer explicitly through the call chain from `cmd_mktree()` down to helper functions `mktree_line()` and `write_tree()`, replacing direct accesses to the global with the passed parameter.

The changes are mechanical but correct - replacing `the_hash_algo` with `repo->hash_algo` and `parse_oid_hex()` with `parse_oid_hex_algop()`. The author notes they initially tried to address a FIXME in t1006-cat-file.sh but found it too complex, instead spotting this simpler cleanup opportunity.

The patch raises two questions in the commit message: one about `oid_to_hex()` still using global state (which is correct - that function still relies on `the_hash_algo` internally), and another about how to properly CC domain experts for review (suggesting previous similar patches may have been missed due to lack of targeted CCs). The changes themselves look straightforward and align with the project's direction to eliminate `the_repository` usage. No tests are modified since this is purely an internal refactoring with no behavior change.
