This thread addresses updates to Git's IMAP send functionality to modernize its use of OpenSSL APIs while maintaining security checks, particularly for certificate hostname validation. The original series drew security concerns when version 1 removed length checks that could allow embedded nulls to bypass validation. Oswald Buddenhagen identified this risk, with Junio C Hamano confirming the importance of maintaining these checks.

The final three-patch series carefully balances modernization with security. Patch 1 updates subject alternative name handling, patch 2 improves common name field access, and this final patch consolidates the hostname validation logic into a single function while preserving all security checks. The implementation now uses modern OpenSSL functions like `ASN1_STRING_get0_data()` but maintains compatibility back to OpenSSL 1.1.0. The thread has reached clear consensus, with all participants agreeing the current version properly handles both API modernization and security requirements. The changes are now ready for merging.
