Test hygiene improvement for CVS-related tests. This is a follow-up to Pablo Sabater's patch that improves error handling in the t9200-git-cvsexportcommit.sh test script. The maintainer (Junio C Hamano) has reviewed and accepted the changes, indicating they will be queued for inclusion. The patch makes two key improvements: it wraps CVS initialization in a proper skip_all check for clearer error reporting when CVS setup fails, and separates Git repository setup into its own test_expect_success block for better test organization.

The changes are straightforward and uncontroversial, focusing on test script quality rather than modifying core functionality. This appears to be part of Sabater's Google Summer of Code work, though the specific context of that project isn't detailed in this exchange. The patch maintains all existing test behavior while making the output more informative when CVS is unavailable.
