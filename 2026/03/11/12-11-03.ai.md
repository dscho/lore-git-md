This is a platform compatibility patch series updating Git's IMAP send functionality to use modern OpenSSL APIs. The changes are motivated by OpenSSL 4.0.0-alpha1's release, which revealed some deprecated code patterns in Git's IMAP implementation.

The series consists of four patches:
1. Updates how subject alternative names are accessed from SSL certificates to use the proper OpenSSL API
2. Similarly updates the common name access pattern
3. Removes redundant string length checks that are now unnecessary with the new APIs
4. Refactors the hostname matching logic for cleaner code

The author notes that all the new APIs being used have been available since OpenSSL 1.1.0 (released 2019), making this a reasonable modernization that shouldn't break compatibility with reasonably current OpenSSL installations. The first two patches are essential fixes for OpenSSL 4.0 compatibility, while the latter two are cleanups enabled by the API changes.

The changes are focused on `imap-send.c` and touch certificate verification logic that's important for secure IMAP connections. The patches appear straightforward and well-motivated, addressing specific deprecation warnings while maintaining the same functionality. The author has included references to the relevant OpenSSL documentation and version history to justify the changes.
