This is a test infrastructure patch improving unit test output readability. Pablo Sabater's v2 patch modifies the test framework to display symbolic names for common escape sequences (like `\n`, `\t`) in test failure output, rather than showing their octal representations (like `\012`). 

The change makes test failures easier to read by humans while maintaining the same functionality. The patch updates `print_one_char()` in test-lib.c to recognize and properly display seven common control characters, falling back to octal for unrecognized ones. It also adds new test cases for escape sequence comparisons and updates the expected output in t0080-unit-test-output.sh.

Notably, v2 reverts an unrelated change from v1 that affected how backslashes and quotes were displayed in test output comparisons. The patch appears well-contained and focused scope, with clear test coverage for the new behavior. As part of the ongoing test infrastructure improvements, this seems like a straightforward quality-of-life enhancement for developers debugging test failures.
