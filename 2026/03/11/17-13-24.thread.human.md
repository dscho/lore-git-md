Pablo has started a discussion about extending their GSoC project on `git cat-file --remote-object-info` to help users of partial clones. The new idea would have the command analyze a tree hash and report which blobs are missing from the local partial clone, sorted by size - giving users to see what they're missing before deciding whether to fetch the objects.

This is currently just a proposal to gauge interest and feasibility. Key questions that will need addressing include whether this functionality belongs in `cat-file` or another command, how it would integrate with existing partial clone behavior, and whether sorting by missing blob sizes provides enough practical benefit to justify the work. The thread is just starting, so these questions remain open for discussion.
