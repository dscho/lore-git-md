Feature: Advice for uncommitted changes during branch switches (GSOC microproject)

This is the final version (v5) of Arsh Srivastava's GSOC microproject to improve user guidance when attempting to switch branches with uncommitted changes. The patch series adds a new advice type `ADVICE_STASH_BEFORE_CHECKOUT` that warns users about potential data loss and suggests both stashing` and using `git checkout -m` (with clear warnings about the risks of the latter).

The implementation builds on the existing advice framework, adding configuration for `advice.stashBeforeCheckout` and integrating with the unpack-trees machinery. Key changes in v5 include splitting the irreversible merge warning into two lines for better test readability, fixing trailing whitespace while preserving warning content, and maintaining the core warning about `-m` merge behavior potentially causing data loss.

The series has gone through five iterations with feedback from multiple reviewers (Junio C Hamano, Phillip Wood, Patrick Steinhardt, and Karthik Nayak). All technical and UX concerns have been addressed, resulting in clean code integration, comprehensive test coverage in `t6439-merge-co-error-msgs.sh` and `t7406-submodule-update.sh`, and clear safety messaging. The final version demonstrates successful GSOC mentoring through responsive patch updates and adherence to Git's quality standards.
