This is a refactoring patch in the ongoing `git fast-import` signature handling series. It generalizes commit signing logic to make it reusable across Git.

The patch moves the `sign_commit_to_strbuf()` helper from commit.c to gpg-interface.c, renaming it to `sign_buffer_with_key()`. This makes the signing functionality available for any buffer, not just commits. The new function maintains the same behavior - it falls back to the default configured signing key when none is provided, and handles the actual signing operation.

This change supports the broader effort to improve signature handling in `git fast-import`, where the same signing logic will be needed for re-signing invalid commits. The patch is cleanly implemented with minimal changes to existing callers in commit.c, just updating them to use the new exported function.

As part of a v4 series building on previously merged work, this continues the architectural improvements to Git's signing infrastructure. The refactoring creates reusable components that could support future extensions like signing unsigned objects or tags.
