This is part of a GSOC microproject adding `ADVICE_STASH_BEFORE_CHECKOUT` advice for uncommitted changes during branch switches. The patch is version 4 of 5 in the series, focusing specifically on the advice message content.

The change simplifies the advice message to recommend using `git checkout -m` as the primary solution for carrying local changes to a new branch, removing the previous multi-step stash/pop instructions and discard option. This follows Junio C Hamano's feedback in earlier versions to emphasize the simpler `-m` approach while still warning about its irreversible nature (though that warning appears in a separate patch in the series).

The implementation adds the new advice type in `advice.h`, integrates it into the advice system in `advice.c`, and documents the config option. The diff shows the refined message format that resulted from multiple review iterations, with Phillip Wood, Patrick Steinhardt, and Karthik Nayak all providing input on earlier versions.

This patch represents the core of the feature - the actual advice shown to users when they attempt to switch branches with uncommitted changes. The surrounding patches in the series handle the triggering logic, test coverage, and integration with the existing checkout workflow. The series has progressed through several rounds of review addressing both technical implementation and UX concerns, with this version appearing to meet all the feedback criteria.
