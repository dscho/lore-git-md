This is a platform compatibility patch updating `imap-send.c` to use newer OpenSSL APIs for accessing certificate subject names. The change is motivated by OpenSSL 4.0's deprecation of `X509_NAME_get_text_by_NID()`.

It includes version-specific handling to maintain compatibility with both pre-4.0 and post-4.0 OpenSSL versions, dealing with const-correctness differences between the versions.

The functional behavior remains the same - verifying that a certificate's common name matches the expected hostname - but the implementation now uses the recommended OpenSSL APIs. The change touches the SSL certificate verification path in Git's IMAP send functionality, which is used when sending patches via IMAP with SSL/TLS encryption.
