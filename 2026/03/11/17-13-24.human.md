This is a GSoC proposal discussion about extending the `git cat-file --remote-object-info` functionality for partial clones. The author, Pablo, suggests adding a feature to identify and list missing blobs within a specific tree, sorted by size, to help users understand what needs to be fetched in partial clone scenarios.

The proposal appears to be at an early brainstorming stage, seeking feedback on whether this would be a worthwhile addition to their planned GSoC project. The idea seems technically plausible and aligned with partial clone use cases, though the implementation details and scope would need to be fleshed out. This could be a useful feature for users managing large repositories with partial clones, as it would provide more visibility into missing objects before fetching.
