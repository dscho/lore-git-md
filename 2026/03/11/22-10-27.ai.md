Platform compatibility patch finalizing OpenSSL API updates for IMAP send functionality. This is the third and final patch in a series addressing OpenSSL 4.0 deprecation warnings while maintaining security checks.

The patch consolidates certificate hostname validation logic into a single `host_matches()` function, moving the ASN1_STRING access and embedded NUL byte checks that were previously duplicated in two callers. The security-conscious implementation preserves the critical check for embedded nulls (which could bypass hostname matching) while using the modern `ASN1_STRING_get0_data()` and `ASN1_STRING_length()` APIs. The NUL check is rewritten to use `memchr()` for clarity, with an added comment explaining its security purpose.

This completes the series' transition from direct field access to proper OpenSSL functions while maintaining all existing validation. The thread has reached consensus on this approach after security concerns were raised in v1, with Junio C Hamano and Oswald Buddenhagen agreeing the current version properly balances modernization with safety. The changes remain compatible with OpenSSL back to version 1.1.0 (2019).
