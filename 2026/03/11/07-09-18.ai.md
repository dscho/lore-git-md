This is a build system patch fixing a regression in Git's EditorConfig file. Patrick Steinhardt identifies that a recent change to include hook templates/*.sample files in the EditorConfig pattern inadvertently broke style application for other subdirectories due to a subtlety in how EditorConfig interprets glob patterns containing path separators.

The patch splits the configuration into two sections - one for general file patterns and another specifically for hook templates - to avoid the glob interpretation issue. This introduces minor duplication but maintains readability. The fix is straightforward and well-explained, with Patrick noting the tradeoff between duplication and complex glob patterns.

The change affects the `.editorconfig` file which controls editor settings like indentation style across the codebase. While small, this ensures consistent formatting continues to apply correctly throughout Git's source tree.
