This thread is about updating Git's IMAP send functionality to use newer OpenSSL APIs for certificate verification, specifically addressing the deprecation of `X509_NAME_get_text_by_NID()` in OpenSSL 4.0. The patch replaces this with `X509_NAME_get_index_by_NID()` and related functions, maintaining compatibility with both older and newer OpenSSL versions while keeping the same certificate verification behavior.

The change is part of a 4-patch series (this being patch 2/4), though the broader goal of the series isn't clear from this individual patch. The implementation appears technically sound, carefully handling the OpenSSL API differences between versions while preserving the existing functionality that verifies SSL certificate common names against expected values when sending patches via IMAP with TLS encryption.
