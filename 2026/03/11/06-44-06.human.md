Bugfix for `git merge-file --object-id` in worktrees. This patch addresses a BUG() that occurs when using `--object-id` in a linked worktree, caused by a redundant `setup_git_directory()` call that became fatal after commit 2816b748e5. The fix guards this setup behind a repository check, maintaining the correct "not a git repo" error while avoiding the worktree issue.

Mathias Rav's v2 incorporates feedback from several reviewers: the check is now more clearly structured with a comment, terminology is updated to consistently use "linked worktree", and the test uses `git -C` instead of a subshell. The patch also verifies identical behavior between the main and linked worktree cases.

The change is small but important for worktree users, and the test coverage gives confidence in the fix. The commit message clearly explains both the problem and solution, referencing the relevant commits that introduced and exposed the issue. This looks ready to merge.
