This is part of Adrian Ratiu's ongoing work to improve Git's hook configuration system, specifically addressing how disabled hooks are displayed in `git hook list` output. The patch is the final one in a 10-part series that has been rebased and is now queued for integration.

The discussion focuses on several technical details of the implementation. Patrick Steinhardt raises concerns about the machine-parsability of the output format when showing both scope and disabled status, suggesting the current parentheses-enclosed format ("hook-name (local, disabled)") may be problematic. Adrian agrees and proposes adopting a tab-separated format similar to `git config --show-scope` as a potential solution.

Other implementation details being refined include:
- Changing `int` to `bool` for disabled status fields
- Using `xstrdup_or_null()` consistently
- Clarifying documentation about "build time" versus "hook cache construction time"
- Improving condition checks for traditional vs configured hooks

The patch represents the culmination of Adrian's work to make hook configuration more transparent and maintainable, with particular attention to how disabled hooks are handled. The series has already addressed several style and implementation concerns raised during review, and this final patch is working through the remaining technical details before integration.
