This is the second patch in a documentation series standardizing the `git-interpret-trailers` man page. It focuses on normalizing and expanding the options section to follow current conventions.

Kristoffer Haugsbakk brings the options documentation in line with several established patterns: adding missing negated options (like `--no-in-place`), using the "stuck form" for option syntax (`--option=value`), and consistently ordering regular/negated option pairs. The patch also documents default behaviors that were previously implied (such as `--no-divider` being the default) and clarifies that `--no-trailer` resets the trailer list.

The changes are mechanical and follow precedents set by similar documentation conversions. The patch touches only the man page (+43/-23 lines) with no functional impact on the command itself. This continues the project's ongoing effort to standardize documentation formatting under Jean-Noel Avila's leadership.
