This is part 3 of a 5-patch series (v4) implementing `ADVICE_STASH_BEFORE_CHECKOUT` advice for handling uncommitted changes during branch switches. The series is a GSOC microproject by Arsh Srivastava.

The patch modifies the existing warning message in `unpack-trees.c` to include information about using `git checkout -m <branch>` as an alternative to stashing, while clearly warning about its risks. The message now explains that `-m` will merge changes directly (not save them) and that unresolved conflicts followed by a `--hard` reset would lose local changes. This replaces the previous approach that added a separate advice function.

The changes remove the now-unused `ADVICE_STASH_BEFORE_CHECKOUT` enum and related functions from `advice.[ch]` and its documentation, since the functionality is being integrated into the existing `ADVICE_COMMIT_BEFORE_MERGE` message. The implementation follows Junio C Hamano's feedback to avoid duplicating warning messages and instead enhance the existing one.

This version addresses all previous feedback from reviewers (Junio, Patrick Steinhardt, Phillip Wood, and Karthik Nayak) about message clarity, safety warnings, and proper integration with existing code. The patch demonstrates the project's mentoring process, with the student contributor successfully incorporating maintainer guidance about both implementation details and communication standards.
