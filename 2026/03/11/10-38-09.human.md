This is a discussion about the final design of the `format.commitListFormat` config option for the cover letter formatting feature in `git format-patch`. The patch series is in its seventh iteration and nearly ready for merging.

Phillip Wood weighs in on Junio Hamano's suggestion to use a boolean-based approach for the config option, where `false` would fall back to shortlog format and `true` would use a default numbered format. While acknowledging Junio's proposal, Phillip expresses mild preference for using named formats ("shortlog" and "numbered") rather than mixing boolean and string types in the config value.

The discussion represents one of the last open questions about this feature - how exactly to structure the config option's values. The technical implementation is otherwise complete, with comprehensive documentation and test coverage. This email shows the project's careful attention to interface design details even in the final stages of a patch series.
