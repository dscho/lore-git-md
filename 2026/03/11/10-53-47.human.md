This is a test infrastructure improvement patch series that makes unit test output more readable by displaying symbolic escape sequence names (like `\n`) instead of octal representations (like `\012`). The patch comes from Pablo as part of a Google Summer of Code project.

The v2 iteration specifically addresses a regression in backslash/quote handling from v1, now preserving the exact output format that existing tests expect (like showing `'\\\\' == '\\''` rather than the v1's changed format). The changes are focused and well-motivated, showing careful attention to backward compatibility while improving developer experience when debugging test failures involving control characters.

The patch modifies `print_one_char()` in test-lib.c to recognize common escape sequences while falling back to octal for unrecognized control characters. Test coverage is added/updated in test-example-tap.c and t0080-unit-test-output.sh. With all feedback addressed in v2, this appears ready for review and merging as a straightforward quality-of-life improvement for test debugging.
