This is a documentation clarification patch in response to a discussion about the `merge-file --object-id` bugfix thread. Kristoffer Haugsbakk points out that the SubmittingPatches documentation already notes the difference between gitk's "Copy commit reference" output (which includes quoted subject lines) and `git show --pretty=reference` format, but suggests Junio's proposed wording could be clearer.

The patch modifies Documentation/SubmittingPatches to more precisely describe gitk's output format as having the subject "enclosed in an extra pair of double-quotes" compared to the standard reference format. Kristoffer agrees with using "but" to contrast the formats but questions whether "extra" is the right term since gitk format simply adds quotes rather than adding to existing ones.
