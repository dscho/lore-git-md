This is the final patch in Patrick Steinhardt's series to abstract object counting as part of the larger ODB (object database) refactoring effort. The patch introduces generic object counting interfaces at the ODB level, replacing the existing `repo_approximate_object_count()` function.

Toon Claes provides a brief review noting only that a comment needs updating to reflect the new interface. This follows his thorough technical reviews of earlier patches in the series, where he identified and helped resolve several implementation details. The patch maintains the existing caching behavior while moving the counting logic into the ODB layer, with packed objects always counted and loose objects only in exact counts (a tradeoff Junio had questioned but accepted).

The changes touch multiple callers including gc, commit-graph, and object-name handling. This completes a significant step in the ODB abstraction work that will enable future pluggable backends.
