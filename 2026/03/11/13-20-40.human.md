This is a refactoring patch from Deveshi Dwivedi that improves the interface of `write_worktree_linking_files()` in the worktree subsystem. The change addresses a potential safety issue where passing strbuf structs by value could lead to dangling pointers if reallocation occurs.

The patch converts the function to take simple `const char*` parameters instead of strbuf structs, since the function only needs the string contents and not the full strbuf functionality. This makes the interface clearer and safer by eliminating the risk of double-free scenarios that could occur with the previous implementation.

This is the first patch in a v2 series that has already incorporated feedback from Jeff King. The changes are focused and well-explained, touching worktree.c and its callers to update the parameter passing. The patch appears ready for inclusion with no outstanding review comments.
