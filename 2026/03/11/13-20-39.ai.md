This is a refactoring patch series addressing two cases of strbuf overuse that Junio Hamano had previously flagged as needing cleanup. The series comes from Deveshi Dwivedi and has already incorporated feedback from Jeff King on v1.

The first patch changes `write_worktree_linking_files()` to take plain string paths rather than passing strbufs by value. The second patch rewrites `parse_combine_filter()` to avoid using `strbuf_split_str()` for splitting filter specs, instead walking the string with `strchrnul()` for better clarity and efficiency. 

Key technical details:
- The worktree change simplifies the interface by removing unnecessary strbuf usage
- The filter parsing change replaces an array of strbufs with direct string manipulation
- v2 incorporates Peff's suggestions to use `strchrnul()` and clean up edge cases
- A test expecting error on trailing '+' was removed since that behavior was incorrect
