Feature: New advice for handling uncommitted changes during branch switches

This is the first patch in a 5-part series (v4) adding a new advice type to help users manage uncommitted changes when switching branches. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` which warns users when their local modifications would be lost during a branch switch and suggests using `git stash` to preserve them.

The implementation follows Git's existing advice patterns, adding:
- A new enum in `advice.h`
- Configuration documentation in `advice.adoc`
- Core implementation in `advice.c` with `advise_on_checkout_dirty_files()`

The advice lists affected files and provides clear instructions: stash changes with `git stash push`, restore them later with `pop`, or discard them with `git checkout -- <file>`. The advice can be disabled via `advice.stashBeforeCheckout` config.
