This is a test infrastructure patch that improves the readability of unit test output by displaying symbolic names for common escape sequences (like `\n`, `\t`) instead of their octal representations (like `\012`). The patch comes from Pablo Sabater as part of a Google Summer of Code project and has now received approval from maintainer Junio C Hamano to be queued for merging.

The changes modify `print_one_char()` in test-lib.c to recognize and display symbolic names for standard control characters including bell (`\a`), backspace (`\b`), tab (`\t`), newline (`\n`), vertical tab (`\v`), form feed (`\f`), and carriage return (`\r`). Unrecognized control characters still print in octal format. The patch follows up on version 1 by specifically preserving the exact output format for backslash/quote cases that was unintentionally changed in the initial version.

The implementation includes new test cases in test-example-tap.c to exercise the escape sequence handling and updates the expected output in t0080-unit-test-output.sh. The changeset is focused and well-contained, touching only the test infrastructure without affecting core Git functionality. The maintainer's quick approval suggests this is a non-controversial improvement that meets Git's standards for test output stability while making failure diagnostics more developer-friendly.
