Test infrastructure update allowing `-E` flag in sed commands. This patch from Junio C Hamano modernizes Git's test suite by permitting the use of `sed -E` (extended regular expressions) in test scripts. The change updates the `check-non-portable-shell.pl` linter to allow `-E` alongside previously permitted flags (`-n`, `-e`, `-f`), bringing it in line with POSIX Issue 8 (2018) standards. 

The patch also fixes a test in `t6030-bisect-porcelain.sh` that had been using `-En` (which previously escaped detection due to the linter's pattern matching) by separating the flags into `-E -n` for clarity. Junio provides historical context, noting that while the original 2019 restriction was based on POSIX Issue 7, the `-E` flag has been standard for years and has been in use in Git's tests since 2022 without issues. 

This is a straightforward maintenance change that aligns the test suite's portability checks with current standards and established practice. The patch demonstrates careful attention to both technical correctness (updating the linter) and developer experience (preventing future "smuggling" of options by making the syntax explicit). The changes are minimal (two files touched) and well-justified by both standards evolution and real-world usage.
