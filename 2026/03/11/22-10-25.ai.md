Platform compatibility patch updating OpenSSL API usage in `imap-send.c` to address deprecations in OpenSSL 4.0. This is the first of three patches in a series that modernizes certificate verification while preserving security checks.

The patch replaces direct access to OpenSSL's ASN1_STRING structure fields with proper accessor functions (`GENERAL_NAME_get0_value`, `ASN1_STRING_get0_data`, `ASN1_STRING_length`) that have been available since OpenSSL 1.1.0. The changes maintain the same security checks for subject alternative names in SSL certificates, including validation that the string length matches the content length (to prevent embedded nulls from bypassing hostname matching).

This update was prompted by OpenSSL 4.0 making the ASN1_STRING structure opaque. The patch series has already gone through security-focused review, with v2 incorporating feedback to maintain defensive checks while modernizing the API usage. The changes are backward compatible to OpenSSL 1.1.0 while fixing deprecation warnings in OpenSSL 4.0.
