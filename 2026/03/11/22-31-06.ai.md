This is the third and final patch in Kristoffer Haugsbakk's documentation series converting the `git-interpret-trailers` documentation to synopsis style. The changes are mechanical formatting updates (+61/-60 lines) that:
- Wrap all config keys and command-line examples in backticks
- Replace single quotes with backticks for code references
- Standardize variable references to use _<var>_ markup
- Add `linkgit:` cross-links where appropriate
- Maintain the existing content while updating its presentation

Notable technical details include:
- The trailer configuration options (`trailer.separators`, `trailer.where`, etc.) now consistently use backtick-wrapping
- Variable references like `<key>` and `<value>` are now marked up with underscores
- The deprecated `trailer.<keyAlias>.command` option is clearly noted as superseded by `.cmd`
- Command-line examples now use consistent `--trailer <key>=<value>` formatting

This completes the standardization of all `git-interpret-trailers` documentation to match the project's synopsis style guidelines. The changes follow established patterns from prior documentation conversions and introduce no behavioral changes to the underlying functionality. As with the rest of the series, this is a straightforward documentation update likely to be accepted without controversy.
