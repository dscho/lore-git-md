This is the second patch in a 3-part series adding advice for branch switching with uncommitted changes, part of a completed GSOC microproject. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when switching branches with local modifications.

The key changes in this version:
- Simplifies the advice message to focus on using `git checkout -m` to carry changes over in one step, rather than the previous two-step stash/pop approach
- Maintains integration with the advice system through `advice.h` enum additions
- Keeps the configurable option (`advice.stashBeforeCheckout`) for silencing the advice

The patch follows the pattern established in the first patch of the series, building on the existing advice infrastructure. The message refinement reflects feedback from earlier iterations that emphasized clarity and safety in guiding users through potentially destructive operations. The implementation remains clean, touching only the advice.c file to update the message format while preserving all the surrounding advice system plumbing.
