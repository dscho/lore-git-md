Feature: New advice for stashing changes during branch switches

This is the first patch in a 5-part series (v4) from Arsh Srivastava, adding a new advice message when users try to switch branches with uncommitted changes that would be lost. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` which warns about the impending loss and suggests using `git stash` to preserve changes.

The implementation follows Git's existing advice patterns, with:
- A new enum in `advice.h`
- Configuration option in `Documentation/config/advice.txt`
- Core logic in `advice.c` that lists affected files and shows stash instructions
- Ability to disable via `advice.stashBeforeCheckout`

The thread shows this has gone through multiple rounds of review, with v4 incorporating feedback about message clarity and safety warnings. The patch appears well-structured with proper documentation and follows Git's coding conventions. This looks ready for merging pending final maintainer approval.
