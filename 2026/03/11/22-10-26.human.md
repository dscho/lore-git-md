It carefully handles constness differences between OpenSSL versions while maintaining the same security checks for certificate common name validation.

The changes preserve the existing hostname matching logic while using modern APIs, addressing both the deprecation warnings and the security concerns raised earlier in the thread about embedded nulls in certificate strings. The implementation now explicitly checks string lengths using `ASN1_STRING_length` alongside the content access, maintaining the defensive validation that was a point of discussion in previous iterations.
