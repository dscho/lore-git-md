This is part 3/5 of a patch series adding advice for handling uncommitted changes during branch switches. The series has gone through several iterations with feedback from Junio Hamano, Patrick Steinhardt, and others.

The patch removes the previously proposed `ADVICE_STASH_BEFORE_CHECKOUT` implementation and instead enhances the existing warning message in `unpack-trees.c` to include information about using `git checkout -m` as an alternative. The updated message now clearly warns that using `-m` will directly merge changes (rather than saving them) and notes the risk of losing changes if conflicts occur and a hard reset is performed.

The changes include:
- Removing the new advice type and its implementation
- Deleting the config documentation for the removed advice
- Modifying the existing checkout warning message to include the `-m` option with clear caveats

This version addresses previous feedback about duplicate functionality and safety concerns by integrating with the existing warning system while maintaining the key educational aspect about the risks of the `-m` option. The patch demonstrates good responsiveness to maintainer guidance while simplifying the implementation approach.
