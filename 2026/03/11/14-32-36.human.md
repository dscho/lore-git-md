Build system improvement with precompiled header support. This is the final patch in Patrick Steinhardt's 8-part series that (1) consolidates build tooling into a new `tools/` directory and (2) adds Meson precompiled header (PCH) support for faster builds. The patch demonstrates a 40% speedup in full builds by precompiling the frequently-included `git-compat-util.h` header. Phillip Wood acknowledges the performance improvement but questions whether the PCH file belongs in `tools/`, suggesting a dedicated `pch/` directory might be more appropriate. The series has seen technical review from Phillip and workflow concerns from Junio about relocating Coccinelle scripts, but appears otherwise uncontroversial. This represents a significant but incremental improvement to Git's build infrastructure.
