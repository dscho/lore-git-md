This is a refactoring patch targeting the IMAP SSL certificate verification code in `imap-send.c`. The patch removes two redundant string length checks when validating hostnames against X.509 certificates.

The changes eliminate checks that verified the length of ASN1_STRING data matched its internal length field. The author argues these checks were only necessary when accessing fields directly, and are now redundant since the code uses proper OpenSSL API accessors (`ASN1_STRING_get0_data`). The patch simplifies the hostname verification logic while maintaining the same security properties.

The modification touches two locations:
1. Subject Alternative Name (SAN) DNS entry validation
2. Common Name (CN) field validation

The patch is part of a 4-part series (position 3/4) though no cover letter was provided to understand the broader context. The changes appear straightforward and focused - removing what the author considers now-unnecessary defensive checks while preserving the core hostname matching functionality. The commit message could benefit from more detail about why these checks were originally added and why they're now safe to remove.
