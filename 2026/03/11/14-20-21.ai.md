Bugfix targeting containerized Git deployments where abnormal exits leave zombie processes. This v2 patch from Andrew Au addresses the zombie process issue when Git runs as PID 1 in containers during transport errors (git-remote-https, ssh). The solution adds symmetric atexit handlers in both transport-helper.c and connect.c to ensure child processes are reaped regardless of exit path, while preserving existing cleanup behavior for normal exits.

The changes are focused on two key files - connect.c gets a new conn_to_reap tracking variable and cleanup_conn_on_exit handler, while transport-helper.c gets the parallel helper_to_reap and cleanup_helper_on_exit. The handlers are registered when child processes start (git_proxy_connect, git_connect, get_helper) and cleared during normal cleanup paths (finish_connect, disconnect_helper) to avoid double-waiting.
