This is a refactoring patch in the ongoing `git fast-import` signature handling series. It generalizes commit signing logic into a reusable helper function that can be used by both `commit.c` and `fast-import.c`.

The patch moves the `sign_commit_to_strbuf()` function from `commit.c` to `gpg-interface.c`, renaming it to `sign_buffer_with_key()`. The new function maintains the same behavior - it signs an arbitrary buffer (not just commits) and falls back to the default configured signing key when none is specified. The implementation is exported via `gpg-interface.h` for use by other components.

This change enables code reuse for the fast-import signature handling work while keeping the signing logic centralized. The patch is part of a v4 series that builds on previously merged signature handling infrastructure, with this particular change focused on architectural cleanup rather than new functionality. The series maintains the current limitation of only handling signed commits while laying groundwork for future extensions.
