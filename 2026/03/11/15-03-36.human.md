This is part 5/6 of Patrick Steinhardt's series to abstract object counting in Git's object database (ODB). The patch introduces generic object counting interfaces at the ODB source level, completing the transition away from repository-specific counting functions.

The key changes in this patch:
- Adds a new `count_objects` callback to the `odb_source` interface
- Implements counting for the files backend by combining packed and loose object counts
- Updates `repo_approximate_object_count()` to use the new interface

Toon Claes provides a brief review, noting the proper use of `odb_source_files_downcast()` for type safety. The implementation builds on previous patches in the series that separated packed and loose object counting logic. 

This continues the ODB abstraction effort that will enable pluggable storage backends. The changes are focused on internal APIs but touch core object counting functionality used by commands like `git gc`. The series has received thorough review from Toon and Junio, with only minor issues identified and addressed.
