This is the first patch in a 3-part series that adds a new advice message for branch switching with uncommitted changes. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when they attempt to switch branches with local modifications that would be overwritten.

The implementation follows Git's existing advice patterns, adding:
- A new enum value in `advice.h`
- Configuration documentation in `advice.adoc`
- A function `advise_on_checkout_dirty_files()` that lists affected files and suggests using `git stash push/pop`

The advice can be disabled via `git config advice.stashBeforeCheckout false`. This is part of a completed GSOC microproject that has gone through five iterations, with all reviewer feedback addressed in this final version. The patch series demonstrates clean integration with existing advice systems and proper handling of irreversible merge warnings.
