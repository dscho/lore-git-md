This is part of a GSOC microproject adding advice for uncommitted changes during branch switches. The patch adds `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when switching branches with local modifications.

The v4 iteration simplifies the advice message to focus on using `git checkout -m` to carry changes over in one step, removing the more verbose stash/discard options that were in earlier versions. This follows Junio's feedback to emphasize the merge option while still warning about its irreversible nature (shown in other patches in the series).

The implementation adds the new advice enum, config key, and integrates with the existing `advise_on_checkout_dirty_files()` function. The thread shows thorough review from multiple contributors (Junio, Phillip Wood, Patrick Steinhardt) addressing both technical implementation and UX concerns over several iterations.

This appears ready for merging pending final maintainer review, with all feedback incorporated and proper test coverage added in companion patches. The advice provides clear safety guidance while keeping the message concise.
