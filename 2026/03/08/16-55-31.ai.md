Bugfix for `git quiltimport` shell script. This patch addresses two shell scripting issues in the quiltimport helper script that could cause problems with patch subjects containing backslashes or spaces.

The main fix replaces `echo` with `printf '%s\n'` when handling patch subjects, since `echo` interprets backslash sequences (e.g. converting "\0" to a NUL byte which `git commit-tree` rejects). The change ensures literal interpretation of patch names and subjects. A secondary improvement adds proper quoting around `$tmp_dir` to handle paths containing spaces.

The changes are straightforward and clearly motivated by real-world edge cases. The patch touches only the shell script implementation without affecting user-visible behavior for normal cases. The fix is small (5 lines changed) and focused, with clear justification in the commit message. This appears to be a solid, uncontroversial improvement to a helper script.
