Bugfix for `git-quiltimport.sh` handling of backslashes and spaces in patch subjects.

This patch addresses two issues in the quiltimport script: first, it fixes a problem where backslash sequences in patch subjects (like "\0") were being expanded by `echo`, potentially creating invalid NUL bytes that `git commit-tree` would refuse. The fix replaces `echo` with `printf '%s\n'` which doesn't interpret escape sequences. Second, it properly quotes `$tmp_dir` to handle paths containing spaces.

The changes are straightforward and clearly motivated by real-world edge cases. The patch touches only the necessary lines in `git-quiltimport.sh` and includes a clear commit message. While small, this fixes legitimate issues that could affect users trying to import patches with special characters in their subjects or working in directories with spaces.
