This is part of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. Patch 2/17 introduces a new "files" source that encapsulates access to both loose objects and packfiles, similar to how the refs backend handles loose refs and packed-refs.

The patch moves all packfile and loose object operations through a new `struct odb_source_files` interface, which will later be made pluggable. It's a mechanical change that updates all callers to use the new indirection while maintaining existing behavior. The changes touch core object access paths across builtins like `cat-file`, `fast-import`, and `grep`, as well as infrastructure like the commit-graph and midx code.

This foundational work is part of the larger ODB abstraction effort that has been under active review, with Justin Tobler and Karthik Nayak providing detailed feedback on earlier iterations. The patch appears well-structured and maintains consistency with the series' architectural vision.
