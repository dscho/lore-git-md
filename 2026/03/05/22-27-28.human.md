This is a documentation patch that adds two new recommendations to Git's SubmittingPatches guide, building on Justin Tobler's original patch. Kristoffer Haugsbakk provides some additional feedback about the wording and placement of the first recommendation regarding checking prior discussions.

The patch is in its final form, with Junio C Hamano having already approved the content and made a small formatting adjustment (adding '+' continuation syntax). The discussion is effectively closed, with the changes ready to be merged. 

The additions formalize two existing best practices: checking for prior related discussions before submitting patches, and allowing time for review feedback before sending new versions. These aim to reduce duplicate work and minimize unnecessary churn from rapid patch rerolls. While uncontroversial, the discussion shows the project's attention to detail in documentation formatting, even for straightforward improvements.

Kristoffer's comment suggests the first recommendation might be slightly redundant for readers who are already consulting the SubmittingPatches document, but doesn't oppose its inclusion.
