This is a refactoring patch that adds type-safe cleanup for oidmap structures, part of a series that has been narrowed down to two conversions (rev-list and odb) after maintainer feedback. The patch introduces a new `oidmap_clear_with_free()` API that uses explicit iteration and a callback pattern rather than relying on struct layout assumptions. The existing `oidmap_clear()` is kept as a backward-compatible wrapper.

Key technical changes:
- Adds `oidmap_free_fn` typedef and `oidmap_clear_with_free()` function that takes a callback
- Implements explicit iteration over entries using `hashmap_iter` rather than `hashmap_clear_`
- Includes new unit tests verifying both callback and non-callback clearing behavior
- Preserves the existing API while removing layout dependencies

The patch shows the pattern that will be used in the rev-list and odb conversions (patch 2/2). The thread context indicates this series is now finalized with maintainer approval, having dropped other proposed conversions (list-objects-filter and sequencer) from scope. The implementation follows Patrick Steinhardt's requested naming convention for the callback function pattern.
