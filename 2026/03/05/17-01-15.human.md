SMTP authentication improvement for `git-send-email`. This is the second version of a patch that enhances OAUTHBEARER support by passing the SMTP server's hostname and port to the Authen::SASL authentication module.

The change is minimal but useful - it adds two parameters to the authentication hash that newer versions (2.2000+) of Authen::SASL can use for OAUTHBEARER authentication. The patch maintains backward compatibility since older versions will safely ignore these additional parameters, similar to how they already handle the existing `authname` parameter.

Aditya Garg has addressed Junio C Hamano's request from the v1 review by explicitly documenting the backward compatibility behavior in the commit message. Testing confirms the change works as intended across Authen::SASL versions. The patch is now just two lines of Perl code that conditionally include the port parameter when defined.

This appears ready for merging - it's a focused improvement that builds on existing SMTP/OAUTHBEARER support without introducing new dependencies or breaking existing configurations. The thread has reached consensus that the change is sound and properly documented.
