This is a platform compatibility patch adding Windows support for timed condition variable synchronization, part of the cross-platform fsmonitor implementation series.

The patch introduces `pthread_cond_timedwait()` to Git's Windows pthread emulation layer, completing the pthread API needed for the fsmonitor daemon's event synchronization. It uses Windows' native `SleepConditionVariableCS()` with millisecond timeout calculation from absolute timespec values, properly handling the ETIMEDOUT case when the deadline passes. The implementation converts between time representations (timespec to milliseconds) and maps Windows error codes to POSIX equivalents.

This is a focused technical addition that enables the fsmonitor daemon's two-phase event synchronization with timeout on Windows, matching Unix behavior. The change is well-contained, touching only the Windows compatibility layer, and follows the established pattern of the existing pthread emulation code. As part of the mature v11 series, it represents the finalization of Windows support for this feature after extensive review.
