Test modernization patch improving failure detection in test scripts. Francesco Paparatto's v2 patch updates `t/t3310-notes-merge-manual-resolve.sh` to use Git's test helpers (`test_cmp` and `test_cmp_rev`) instead of direct command substitutions when comparing revision hashes. This follows up on Junio C Hamano's suggestion and incorporates Eric Sunshine's review feedback from v1.

The changes ensure that `git rev-parse` failures won't be silently ignored and provide better diagnostic output when comparisons fail. The patch touches 18 test cases across the file, replacing patterns like `test "$(git rev-parse A)" = "$(git rev-parse B)"` with more robust alternatives. For simple comparisons against stored values, it uses `test_cmp` with temporary files, while revision comparisons use the specialized `test_cmp_rev` helper.

This is a straightforward improvement that aligns with Git's ongoing test modernization efforts. The changes are mechanical but meaningful - they don't affect test logic, just how failures are detected and reported.
