This is the final implementation of Alan Braithwaite's configurable partial clone filters via URL patterns (`clone.<url>.defaultObjectFilter`), now addressing Junio C Hamano's last round of review feedback. The feature allows setting default partial clone filters that automatically apply when cloning from matching URLs, with command-line `--filter` taking precedence.

Key changes in this version:
- Removed the unnecessary `clone_filter_data` struct in favor of a direct string pointer
- Added NULL check for filter value to handle config entries without values
- Fixed config cascade behavior to avoid redundant processing
- Confirmed URL-based configuration approach matches Git's existing patterns

The implementation provides a clean solution for partial clone users who want consistent filters per repository origin while maintaining Git's safety boundaries by limiting the feature to clone operations. With Junio's feedback incorporated and all technical decisions settled, this appears ready for merging.
