Soutrik Das has proposed a Google Summer of Code project to extend `git cat-file --remote-object-info` functionality, building on prior work by Calvin Wan and Eric Ju that added remote object metadata retrieval via protocol v2. The current implementation only supports querying object sizes; Soutrik aims to add support for object types and potentially other metadata like on-disk size and delta base information.

Christian Couder, a GitLab engineer and GSOC mentor, has provided detailed feedback on the proposal. He corrected some grammatical issues and suggested clearer wording to avoid confusion between metadata types and Git object types. Christian advised against extensive pre-GSOC implementation work beyond a trial rebase to identify challenges. He questioned whether the proposed features - particularly single-object queries - belong in a different command than `cat-file`, noting that `git rev-list` already offers some similar functionality for identifying absent objects. The feedback maintains a mentoring tone while setting clear expectations about scope and process.

The thread currently shows Soutrik as the sole active participant, demonstrating engagement but awaiting more technical discussion. The proposal remains in early stages, with Christian's review providing guidance on how to refine the approach before GSOC selection. Key open questions include the optimal design for bulk versus single-object queries and how to best integrate with Git's existing protocol v2 capabilities.
