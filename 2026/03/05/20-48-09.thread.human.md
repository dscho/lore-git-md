Soutrik Das has proposed a Google Summer of Code project to extend `git cat-file --remote-object-info`, building on prior work by Calvin Wan and Eric Ju. The goal is to enhance protocol v2's ability to retrieve remote object metadata, starting with adding `%(objecttype)` support to complement the existing `%(objectsize)` capability, with potential future work on additional attributes like on-disk size and delta base information.

The proposal represents a meaningful but manageable extension of Git's remote object inspection capabilities, relevant to partial clone optimizations. Soutrik, a new contributor with two small merged patches to their name, has followed up with a polite request for feedback on their application, demonstrating engagement with the project. While no technical details have been added since the initial proposal, the thread shows an author actively looking for mentorship to refine their approach to protocol v2 and object storage layer changes. The project's success will likely depend on finding an experienced mentor familiar with these subsystems.
