Soutrik Das has proposed a Google Summer of Code project to extend `git cat-file --remote-object-info` with additional metadata capabilities, building on prior work by Calvin Wan and Eric Ju. The initial proposal would add object type information to the existing object size query functionality, with potential future extensions for other metadata. 

Christian Couder, a GSOC administrator and GitLab engineer, provided early feedback questioning whether single-object queries belong in `cat-file` versus other commands like `rev-list`, and cautioned against doing too much implementation work before the official GSOC period begins. Karthik Nayak, another GitLab contributor, has now joined the discussion with additional practical concerns. He notes that some proposed features might better fit elsewhere in Git's command set, and emphasizes the need to clarify how the student will handle the project's review cycles within the constrained GSOC timeline. Both reviewers are supportive of the technical direction but want to see more detail on project management and review coordination before finalizing the proposal. The discussion remains active as Soutrik works to refine the scope and address these organizational questions.
