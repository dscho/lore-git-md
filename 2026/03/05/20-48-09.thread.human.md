Soutrik Das has submitted a Google Summer of Code proposal to extend `git cat-file --remote-object-info` to support additional object metadata like type and on-disk size, building on prior work by Calvin Wan and Eric Ju. The proposal is receiving active review from Christian Couder (GSOC admin) and Karthik Nayak (GitLab engineer), who have raised questions about whether single-object queries belong in this command versus alternatives like `git rev-list --objects --all --missing=print`.

In his latest response, Soutrik addresses Christian's feedback by correcting grammatical errors, clarifying terminology around object metadata, and reporting on a trial rebase that revealed some conflicts. He acknowledges the valid concerns about command scope and has removed mention of functionality that duplicates existing `rev-list` capabilities. The question of whether to implement client and server sides in one series or separately remains open, with Soutrik weighing the tradeoffs between focus and review overhead.

Christian and Karthik continue to guide the proposal's technical direction, with Karthik particularly emphasizing the need to address outstanding feedback from the original implementation's v11 patch series. Soutrik demonstrates a collaborative attitude and willingness to learn, though several design questions remain before this could be considered a viable GSOC project. The next steps involve refining the proposal based on mentor feedback and clarifying the implementation approach.
