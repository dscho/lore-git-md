Security patch removing the ambiguous 'default' configuration option for sideband control character handling. This is part of the ongoing series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005).

Junio Hamano removes the 'default' keyword from the `sideband.allowControlCharacters` configuration, arguing it creates a confusing situation where users who explicitly set 'default' would see behavior changes at the Git 3.0 boundary. The patch simplifies the configuration by requiring users to either specify their exact preferences (like 'color' or 'cursor') or rely on the implicit default behavior by not setting the option at all.

The change maintains all other configuration options while removing what the maintainer sees as a problematic middle ground. This aligns with the series' goal of providing clear, predictable control over sideband character handling as the project transitions toward stricter defaults in Git 3.0. The implementation has been production-validated in Git for Windows and Red Hat environments.
