This is a platform compatibility patch adding Windows support for pthread timed waits, part of the larger cross-platform fsmonitor effort. 

Paul Tarjan contributes patch 3/12 in the v11 series, implementing `pthread_cond_timedwait()` for Windows using `SleepConditionVariableCS()`. The function converts the absolute timespec deadline to a relative millisecond value for the native Windows API, with proper error handling for timeouts and other conditions. 

This enables the fsmonitor daemon's two-phase event synchronization on Windows, matching Unix behavior. The implementation is straightforward - computing the timeout delta between current time and deadline, then delegating to the native Windows synchronization primitive. The patch includes proper error code translation between Windows and POSIX conventions.

As part of the mature v11 series, this component has already been reviewed and tested alongside the complete fsmonitor implementation. The change is focused and well-contained, touching only the Windows pthread compatibility layer.
