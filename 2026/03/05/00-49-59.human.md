This is the final patch in a series implementing Linux fsmonitor support, focusing on process management improvements. The patch addresses Junio Hamano's suggestion to generalize the file descriptor handling mechanism.

Paul Tarjan replaces the specific `close_fd_above_stderr` flag with a more flexible `pre_exec_cb` callback in `struct child_process`. The fd-closing logic is now as a standalone function that fsmonitor callers can use. This maintains the same functionality while making the interface more extensible for future needs.

The change shows good responsiveness to maintainer feedback while keeping the implementation clean. With this last piece in place, the Linux fsmonitor implementation appears complete and well-considered, having addressed all technical concerns raised during review.
