This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The series has already been merged after thorough review.

The current patch makes the `begin_transaction()` function pluggable by adding a callback to `struct odb_source`. Justin Tobler raises an architectural question about whether transaction handling logic should live alongside the concrete ODB source implementation rather than being separate. Patrick acknowledges this as a valid consideration but notes the current transaction mechanism has two modes (loose objects vs packfiles) that may need separate handling, suggesting this area needs more work.

The discussion shows the careful attention to architectural details that has characterized the entire series. With this final patch, all core ODB operations are now properly abstracted, completing the foundational infrastructure for alternative backends while maintaining existing files backend behavior.
