Junio C Hamano (the Git maintainer) responds to Norbert Kiesel's request for a `git worktree list --created` feature to sort worktrees by creation time. He notes that Git currently doesn't track worktree timestamps, making the request unfeasible in its current form. His response includes both a practical workaround suggestion (using terminal scrolling for the existing output) and a more constructive alternative - proposing that worktrees could store metadata like the existing `.git/description` file, which could then be exposed via a `--verbose` flag.

This moves the discussion forward by shifting focus from timestamp sorting (which isn't currently possible) to a more general metadata storage mechanism that could enable future features. Junio's tone is characteristically pragmatic, mixing humor with technical suggestions. The response doesn't close the door on the feature entirely, but indicates it would need architectural changes rather than being a simple addition to the listing command.
