This is part of a security-focused patch series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005) in Git's sideband channel. The series has undergone extensive testing in production environments (Git for Windows and Red Hat) over the past year.

Patch 2/7 introduces a configurable escape hatch (`sideband.allowControlCharacters`) that lets users opt out of the new security protections when needed. The default behavior remains secure (filtering control characters), but this allows exceptions for cases where remote servers intentionally use ANSI colors in messages. The implementation includes documentation and test coverage verifying both the default protection and the opt-out behavior.

Junio Hamano is shepherding this series toward merging, having proposed including patches 1-6 in 'next' for further testing while deferring the Git 3.0 default behavior change (patch 7). This represents a pragmatic balance between immediate security needs and backward compatibility, with the technical foundation being laid for future secure-by-default transition.
