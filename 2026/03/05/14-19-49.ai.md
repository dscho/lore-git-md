This patch is part of Patrick Steinhardt's ongoing object database (ODB) abstraction effort, specifically patch 9/17 in the series. It introduces a pluggable `read_object_info()` callback to `struct odb_source`, completing the conversion of core ODB operations to callback-based dispatch.

The patch handles a subtle edge case in object lookup where Git may need to retry reading an object appears to be missing, particularly for packfiles. It introduces a new `OBJECT_INFO_SECOND_READ` flag to indicate this retry case, allowing backends to optimize their behavior - the files backend skips loose object checks on retries since they wouldn't change, while the packfile backend refreshes its state to catch newly added packs.

Key technical changes include:
- Moving object info flags enum from odb.h to odb/source.h since they're now backend-facing
- Adding the new `read_object_info` callback to the source vtable
- Implementing files backend logic that respects the `SECOND_READ` flag
- Updating the core object lookup logic in odb.c to use the new callback

The implementation maintains existing behavior while providing the necessary hooks for future alternative backends. Justin Tobler has reviewed this patch positively, noting it follows the established pattern of the series. This represents another step in the systematic conversion of ODB operations to be fully pluggable.
