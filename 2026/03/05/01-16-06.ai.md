This is the final version of a feature series implementing Linux support for Git's filesystem monitoring (fsmonitor) using inotify, bringing it to parity with existing Windows and macOS implementations. The series has undergone extensive review and testing over multiple iterations, with all feedback addressed.

The implementation provides cross-platform fsmonitor functionality with several key technical components:
- Uses inotify with recursive directory watching and special handling for directory renames
- Maintains watch descriptor mappings using hashmap with proper cleanup
- Implements two-phase event synchronization with timeout
- Detects and handles remote filesystems appropriately
- Shares IPC and settings logic between Unix platforms (macOS/Linux)
- Includes comprehensive test coverage and stress testing

Notable improvements in this final version:
- Replaced khash with strset for simpler code in client handling
- Added pre-exec callback mechanism for child processes
- Fixed Windows build compatibility
- Improved test reliability and process management
- Added 30-second timeout for daemon shutdown
- Finalized all memory leak fixes

The series is now production-ready across all major platforms, with all technical concerns resolved. It has been tested in real-world environments and is currently in Junio's 'seen' branch. This represents the completion of a major cross-platform feature bringing fsmonitor to Linux users.
