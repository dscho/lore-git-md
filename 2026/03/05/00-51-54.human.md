This is a refactoring patch in the cross-platform fsmonitor implementation series. It renames the Darwin-specific settings file to a more generic "unix" name, since the same settings logic will be shared by the upcoming Linux fsmonitor backend. The change updates both the CMake and Meson build systems to use a new `FSMONITOR_OS_SETTINGS` variable for this file, matching the pattern already established for the IPC implementation.

The patch is straightforward - it's a pure rename with corresponding build system updates, maintaining all existing functionality while better reflecting the code's cross-platform nature. This is part of the larger effort to bring Linux fsmonitor support to parity with the existing Windows and macOS implementations, which has been through extensive review and testing. The series is now in Junio's 'seen' branch and appears production-ready.
