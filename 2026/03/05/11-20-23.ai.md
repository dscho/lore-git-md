CI / build system patch completing a series addressing macOS 15 compatibility in GitLab CI. This is the third and final patch in Patrick Steinhardt's series, following two technical patches that implemented workarounds for macOS 15's broken iconv implementation in both Makefile and Meson builds.

The patch updates GitLab's macOS CI runners from the deprecated macos-14-xcode-15 images to macos-15-xcode-16, which is now the stable version. The change affects three parallel test jobs (osx-clang, osx-reftable, and osx-meson) that all use the macOS runners. The update is straightforward - just changing the image name in each job's configuration.

This change depends on the previous two patches in the series, which ensured the builds would work correctly with macOS 15's iconv behavior. The series as a whole maintains CI reliability while keeping up with platform updates, demonstrating the project's attention to build system maintenance across different environments. The thorough approach (first fixing the technical issue, then updating the CI configuration) suggests this is ready for merging.
