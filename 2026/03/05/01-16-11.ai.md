This is a refactoring patch in the fsmonitor cross-platform implementation series. It renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC path logic is not macOS-specific and will be shared with the upcoming Linux implementation. The patch introduces a distinction between `FSMONITOR_OS_SETTINGS` (for shared Unix files) and `FSMONITOR_DAEMON_BACKEND` (for platform-specific files), updating the Makefile, CMake, and Meson build systems accordingly.

Key technical changes include moving the file while keeping its contents identical, adjusting build system logic to properly separate platform-specific vs shared components, and ensuring the settings remain consistent across all build systems. The patch maintains existing functionality while improving code organization for the cross-platform fsmonitor implementation.

This is part of the larger effort to bring fsmonitor support to Linux while maintaining compatibility with existing Windows and macOS implementations. The changes are mechanical build system adjustments that don't affect runtime behavior, keeping the series focused on its goal of clean cross-platform support.
