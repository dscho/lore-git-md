This is part 14/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The patch introduces a new `write_object_stream` callback in the `struct odb_source` vtable, making object writing operations pluggable like the other ODB operations converted earlier in the series.

The change moves the stream-based object writing logic from odb.c into backend-specific implementations, with the files backend wrapping the existing `odb_source_loose_write_stream()` function. The patch follows the established pattern of the series by adding thorough documentation of the new function in source.h while maintaining backward compatibility.

This continues the systematic conversion of core ODB operations to callback-based dispatch, with the series now having converted read, write, iteration, and freshness-checking operations. The implementation appears technically sound and maintains the architectural rigor seen in previous patches. Justin Tobler's continued engagement in the thread suggests the approach remains aligned with the project's direction for ODB abstraction.
