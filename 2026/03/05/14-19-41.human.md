This is the first patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The patch is a preparatory refactoring that splits the `struct odb_source` definition and related functions into a separate header file.

The change moves the `struct odb_source` definition and its allocation/free functions from `odb.h` and `odb.c` into new files `odb/source.h` and `odb/source.c`. This is done in anticipation of future patches that will significantly expand the structure to include function pointers for pluggable backend operations.

The patch is purely mechanical - it doesn't change any functionality, just reorganizes the code to make the subsequent changes cleaner. The commit message explains that this separation keeps the high-level object database interface detached from the low-level object database sources, which will be important as the abstraction evolves.

This is a well-contained first step in a larger architectural effort to make Git's object storage backend pluggable. The patch follows Git's coding style and includes updates to both Makefile and meson.build to handle the new source files.
