This is part 5 of a 7-part security series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005). The patch implements per-URL configuration for sideband control character sanitization, allowing different security policies for different Git servers.

The change lets users configure `sideband.<url>.allowControlCharacters` to override the global setting, mirroring Git's existing `http.<url>.*` pattern. This addresses Junio Hamano's concern about needing different policies for trusted vs untrusted servers. The implementation introduces URL-scoped configuration through a new `sideband_apply_url_config()` function called when transports are created.

The patch maintains backward compatibility while adding granular control. Test coverage verifies that URL-specific settings properly override global defaults, with new tests showing both blocked and allowed control sequences based on configuration. The series has undergone extensive production validation in Git for Windows and Red Hat environments.

This represents a key piece of the security hardening effort, balancing protection against terminal injection attacks with real-world needs like colored hook output. The implementation is clean and well-tested, with clear documentation of the new URL-scoped configuration options.
