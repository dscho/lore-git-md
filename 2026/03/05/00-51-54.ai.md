This is a refactoring patch in the fsmonitor daemon series, specifically reorganizing platform-specific code to better reflect shared Unix components. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` since the settings logic is not macOS-specific and will be reused by the upcoming Linux implementation. 

The change updates both CMake and Meson build systems to use a new `FSMONITOR_OS_SETTINGS` variable for the settings file, matching the pattern already used for IPC files. This maintains consistency in how platform-specific components are handled across the build systems. The actual file contents remain unchanged - this is purely an organizational change to better reflect the code's cross-platform nature.

The patch is part of a larger effort to bring Linux support for fsmonitor using inotify, completing cross-platform parity with existing Windows and macOS backends. This particular change helps consolidate the Unix-specific logic that will be shared between macOS and Linux implementations. The series has already addressed all technical concerns and is production-ready, with this patch representing one of the final organizational cleanups before integration.
