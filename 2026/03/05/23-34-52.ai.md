This is the final patch in a security-focused series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). The patch delays the secure-by-default behavior of sanitizing control characters until Git 3.0, maintaining backward compatibility while committing to future hardening.

The series has evolved through five iterations with production validation in Git for Windows and Red Hat environments. This specific patch introduces conditional compilation (`WITH_BREAKING_CHANGES`) to manage the transition - currently defaulting to permissive behavior (allowing all control characters) while documenting the planned change to only allow ANSI color sequences by default in Git 3.0. The implementation preserves URL-specific configuration through `sideband.<url>.allowControlCharacters` while adjusting test expectations to account for the version-dependent defaults.

Key technical changes include updating documentation to clearly indicate the future behavior change, modifying the default `ALLOW_DEFAULT_ANSI_SEQUENCES` flag based on compilation settings, and adapting tests to work with both current and future behavior via a `TURN_ON_SANITIZING` test prerequisite. The patch maintains all existing configuration options while preparing for the eventual secure-by-default transition.
