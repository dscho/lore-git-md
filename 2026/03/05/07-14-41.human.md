This is a feature request for `git worktree` to support sorting worktrees by creation time. Norbert Kiesel proposes adding a `--created` flag to `git worktree list` to help manage repositories with many worktrees (20+ in their case), where remembering recently added worktrees becomes difficult.

The request is straightforward and addresses a clear usability pain point for users who maintain multiple worktrees. The proposed solution is minimal - just adding a sorting option to the existing command. Norbert offers to implement the feature themselves if the idea is accepted.

This seems like a reasonable quality-of-life improvement that wouldn't introduce much complexity. The worktree subsystem already tracks creation time internally (used for the `worktree.guessRemote` config), so the infrastructure to support this feature likely exists. The main questions would be about the exact UI (whether `--created` is the right flag name) and whether to make it the default sort order when the flag is present.
