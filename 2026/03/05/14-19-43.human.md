Feature: Part of Patrick Steinhardt's ODB abstraction series (3/17)

This patch refactors the "files" backend for Git's object database to follow the project's standard pattern for pluggable backends. Currently, the files backend is implemented as a pointer in `struct odb_source`, but the preferred approach is to embed the generic base structure (`struct odb_source`) within the specialized implementation (`struct odb_source_files`).

The change provides several benefits: it avoids an extra allocation, hides implementation details, enables easy downcasting between types, and makes backend-specific dependencies more explicit through required casts. The patch introduces a new `odb_source_files_downcast()` function to convert between the generic and files-specific types, though currently this always succeeds since only the files backend exists.

The changes are mechanical but widespread, touching 18 files to update all callers that previously accessed the files backend directly. While some direct access remains (which will be addressed in future work), this establishes the proper architectural pattern for the ODB abstraction effort. The patch is part of a larger 17-part series that's already been through review and merged, indicating it meets the project's standards for this foundational change.
