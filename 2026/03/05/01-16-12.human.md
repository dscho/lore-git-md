Part of the cross-platform fsmonitor implementation bringing Linux support. This patch renames the Darwin-specific fsmonitor settings file to a more generic Unix name, reflecting that the same settings logic will be shared across all Unix platforms (including the new Linux implementation). The change updates both the CMake and Meson build systems to use the new FSMONITOR_OS_SETTINGS variable consistently with how the IPC files are handled. This is a straightforward refactoring that maintains existing functionality while preparing for Linux support. The patch has already been through multiple iterations (v10) and is part of a well-tested series that's been verified in production environments.
