This is part of the cross-platform fsmonitor implementation series, specifically patch 5/12 in the ninth iteration. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms (not just macOS). 

The change introduces a distinction between `FSMONITOR_OS_SETTINGS` (for platform-agnostic Unix files) and `FSMONITOR_DAEMON_BACKEND` (for platform-specific implementations), updating the build system files (Makefile, CMake, meson) accordingly. The IPC and settings files will now use the OS_SETTINGS variable while path utilities remain tied to the DAEMON_BACKEND.

This is a straightforward refactoring that prepares for the Linux fsmonitor implementation by generalizing the shared Unix components. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) who worked on related IPC code. The changes are mechanical and well-contained, touching only build system configuration and file organization without modifying any core logic.
