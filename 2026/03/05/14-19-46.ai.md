This is part 6 of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The patch makes the ODB source `free()` operation pluggable by introducing a callback in `struct odb_source`.

The changes move the files backend's cleanup logic into a static `odb_source_files_free()` function that is assigned as the `free` callback when initializing a files source. The public `odb_source_files_free()` function is removed since callers should now use the generic `odb_source_free()` interface. The patch updates both the Makefile and meson.build systems to reflect these changes.

This continues the architectural pattern seen in earlier patches of the series - moving backend-specific operations into callback functions that can be implemented differently by future storage backends. The change is mechanical but important for maintaining consistency as the ODB abstraction evolves. Review discussion in the thread shows careful attention to API boundaries and error handling semantics, though this particular patch didn't generate new review comments.
