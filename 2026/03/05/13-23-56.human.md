This is patch 15/17 in Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The patch makes the `read_alternates()` function pluggable by adding a callback to `struct odb_source`.

Justin Tobler notes that the documentation suggests alternates files could use a "files://" prefix, but this functionality isn't yet implemented. Patrick acknowledges this and agrees to update the comment to clarify. The exchange shows careful attention to API documentation details even for not-yet-implemented features.

The discussion continues the pattern seen throughout this series of methodically converting ODB operations to callback-based dispatch while maintaining clear communication between the author and reviewers about design intentions and future plans. The patch itself is a straightforward addition to the growing set of pluggable operations in the ODB interface.
