This is Junio Hamano's biweekly "What's cooking in git.git" status report, summarizing the state of in-progress patches in the Git project. The report covers patches that have graduated to 'master' and 'next' branches, new topics being proposed, ongoing work still in development, and discarded topics.

Several notable patches have graduated to 'master':
- A new `--auto-advance` flag for `git add -p` allowing revisiting already-processed files
- Removal of `the_repository` dependency in mailmap code
- Fixes for subtree splitting optimization that was losing relevant history
- Default use of geometric repacking strategy in `git maintenance`
- Mobile-friendly improvements to gitweb
- Various `the_repository` removal cleanups across merge-ort, tree-diff, and wt-status code

New topics being proposed include:
- A `git history split` subcommand for splitting commit histories
- Documentation about how users can add custom Git subcommands
- Prevention of recursive lazy-fetching in promisor remotes
- Linux implementation of fsmonitor daemon
- Configuration-based hook definitions and parallel hook execution
- Submodule fetching from configured remote rather than hardcoded 'origin'

Ongoing work includes:
- Sideband control character sanitization improvements
- Object database source API restructuring
- MIDX/bitmap incremental repacking
- SHA-1/SHA-256 interoperability work
- Status comparison against multiple configured branches

The report provides a comprehensive overview of the current development state, showing steady progress on large refactoring efforts like `the_repository` removal while also introducing new features and fixing bugs. The mix of graduated patches and new proposals indicates active development across multiple areas of the codebase.
