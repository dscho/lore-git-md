This is part 15/17 of Patrick Steinhardt's series to make Git's object database (ODB) subsystem support pluggable storage backends. The patch focuses on making the alternates file handling pluggable.

The alternates file (`.git/objects/info/alternates`) allows repositories to share objects with other repositories. This patch moves the alternates reading logic from the core ODB code into the files backend by introducing a new `read_alternates` callback in the `struct odb_source` vtable. The existing implementation is refactored to use this callback interface while maintaining the same behavior.

Key changes include:
- Adding the callback declaration and documentation in `odb/source.h`
- Moving the implementation to `odb/source-files.c`
- Making `parse_alternates()` a public function in `odb.h` since it's now used by the files implementation
- Updating the files backend to implement the new callback

This continues the series' systematic approach of converting ODB operations to callback-based dispatch. The implementation appears clean and well-documented, following the pattern established by previous patches in the series. Justin Tobler has been actively reviewing these changes, and there don't appear to be any outstanding concerns about this particular piece of the abstraction work.
