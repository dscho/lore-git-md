This is the first patch in a two-part RFC series proposing remote group support for `git push`, mirroring the existing `git fetch` functionality. The patch refactors group-handling code from `builtin/fetch.c` into `remote.c` to make it reusable across commands.

The key changes:
- Moves `get_remote_group()`, `add_remote_or_group()`, and the `remote_group_data` struct from being static helpers in fetch.c to being shared utilities in remote.c
- Updates remote.h with the new declarations
- Preserves all existing behavior - this is purely a code movement to enable the push functionality in the next patch

The refactoring appears clean and mechanical, with no functional changes. The commit message clearly explains the motivation (enabling reuse by push.c) and notes this was suggested by Junio Hamano. The patch touches three files but is straightforward - moving code and adjusting visibility.

This is groundwork for the more interesting second patch that will implement the actual push-to-group functionality. The author indicates tests and documentation will follow in future iterations, which is appropriate for an RFC. The patch looks like a solid foundation for the feature.
