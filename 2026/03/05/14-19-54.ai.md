This is patch 14/17 in Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The patch introduces a new `write_object_stream()` callback in the `struct odb_source` vtable, making object writing via streams backend-specific.

The change moves the existing `odb_source_loose_write_stream()` implementation into the files backend while maintaining the same functionality. The callback signature includes the stream, length, and output OID parameters. This follows the series' established pattern of converting core ODB operations to callbacks - the previous patch (13/17) introduced the `write_object()` callback for non-stream writes.

The implementation is straightforward, with the series' characteristic thorough documentation in `source.h` explaining the new callback's contract. The files backend wrapper simply delegates to the existing loose object writing function. No behavioral changes are introduced beyond the architectural restructuring.

This continues the systematic conversion of ODB internals to support pluggable backends while maintaining backward compatibility. The patch maintains the series' high standard for architectural changes and receives consistent technical engagement from Justin Tobler in review discussions.
