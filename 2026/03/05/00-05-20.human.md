This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics. The report covers patches that have graduated to 'master', new topics being introduced, ongoing work in the 'cooking' stage, and discarded topics.

Several notable changes have been merged to 'master':
- The mailmap code has been weaned off the_repository dependency
- "git add -p" gained a new mode allowing revisiting already-handled files
- "git config list" learned to show values interpreted for specific types
- The merge-ort codebase was marked to prevent more the_repository uses
- "git maintenance" now uses the "geometric" strategy by default
- Gitweb has been made mobile-friendly
- Various bugfixes and cleanups across the codebase

New topics being introduced include:
- A "git history split" subcommand (experimental)
- Documentation about adding custom Git subcommands via PATH
- Prevention of recursive lazy-fetch in child fetch processes
- Fsmonitor daemon implementation for Linux
- Improvements to error diagnosis for invalid .git files

Ongoing work includes:
- Sideband control character sanitization improvements
- ODB (object database) source API restructuring
- Parallel hook execution support
- Submodule fetching from default remote
- Incremental MIDX repacking work
- SHA-1/256 interoperability improvements
- "git status" branch comparison configuration

The report also notes several topics that have been discarded or superseded by other work, typically due to lack of review responses or better alternative approaches emerging.

This status update shows Git's development continuing at a steady pace, with a mix of new features, infrastructure improvements, and ongoing large-scale refactoring efforts (particularly around removing the_repository dependencies). The maintainer appears to be actively shepherding patches through the integration branches while also introducing new experimental functionality.
