This is a CI/build system patch series from Patrick Steinhardt updating GitLab CI to use macOS 15 images. The series also includes preparatory work to ensure compatibility with macOS 15's iconv behavior.

The first two patches address an iconv issue that was previously fixed for the Makefile build system but not yet for Meson. The first simplifies the iconv BOM check in Meson, while the second properly detects and handles macOS 15's broken iconv implementation that requires ICONV_RESTART_RESET. These changes mirror the earlier Makefile fix from commit d0cec08d70.

The third patch then updates the GitLab CI configuration to use macOS 15 images, taking advantage of the now-complete iconv workaround. Patrick notes this isn't urgent but is being done proactively ahead of any future deprecation of older macOS versions.

The changes are focused and well-motivated, with clear connections to prior work. The series touches only build system files (.gitlab-ci.yml and meson.build) and maintains consistency between the Makefile and Meson build systems. As a routine infrastructure update from a core contributor, this appears ready for merging once any final review feedback is addressed.
