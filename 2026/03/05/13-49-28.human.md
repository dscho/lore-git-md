This is the final patch in the rebase --trailer series, now in its 8th iteration. The series adds a `--trailer` option to `git rebase` that allows appending trailers to commit messages during rebase operations.

Phillip Wood has taken over the implementation work from Li Chen while maintaining Li's authorship, incorporating feedback from reviewers. The series has reached consensus on all major technical points, including trailer ordering behavior (signoffs will appear after other trailers, matching `git commit` behavior as proposed by Phillip and accepted by Junio Hamano).

The implementation:
- Moves trailer processing logic into shared helper functions in trailer.c
- Uses tempfile+rename for atomic writes
- Validates trailer arguments early
- Works with all rebase modes (interactive/non-interactive) 
- Preserves trailers through conflicts
- Handles fixup/squash commits properly
- Currently limited to the merge backend (rejects --apply)

The series appears ready for merging with only minor documentation and error handling improvements remaining. This represents a significant refactoring of Git's trailer infrastructure to enable in-process manipulation while maintaining backward compatibility.
