Test modernization patch improving failure detection in notes merge tests. Francesco Paparatto's v2 follows up on Eric Sunshine's review of the initial version, addressing the issue where `git rev-parse` failures could be silently ignored in test command substitutions. The patch modifies `t/t3310-notes-merge-manual-resolve.sh` to use Git's test helpers more effectively.

Key changes in v2:
- Replaces direct string comparisons with `test_cmp` when checking against stored expected values (in `pre_merge_*` files)
- Uses `test_cmp_rev` for revision comparisons between refs
- Maintains the same test coverage while providing better failure diagnostics
- Incorporates Eric Sunshine's suggestions to improve developer experience when tests fail

The changes touch 10 test cases across the notes merge test file, consistently applying the more robust testing patterns. This continues Git's ongoing test modernization effort, particularly around making test failures more debuggable. The patch carries Junio C Hamano's Suggested-by tag from the original discussion.
