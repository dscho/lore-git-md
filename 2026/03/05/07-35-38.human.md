Feature request discussion for `git worktree list` sorting options.

Johannes Sixt responds to Norbert Kiesel's proposal for a `--created` flag to sort worktrees by creation timestamp. While acknowledging the use case (managing 20+ worktrees), Hannes suggests this doesn't warrant a dedicated Git feature when existing Unix tools can achieve similar results. He provides a shell pipeline using `cut` and `xargs` with `ls -ldtr` to sort worktree directories by modification time as an alternative solution.

The response indicates skepticism about adding specialized sorting options to the worktree command, preferring to leverage standard Unix tooling. This suggests the proposal may face resistance unless stronger justification is presented for why the shell workaround is insufficient. The thread remains at an early stage with no other participants yet weighing in.
