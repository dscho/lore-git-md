This is part 10/17 of Patrick Steinhardt's series to make Git's object database (ODB) subsystem support pluggable storage backends. The patch introduces a new callback in the ODB` source interface for streaming object contents, continuing the systematic conversion of direct backend access to callback-based dispatch.

The change adds `read_object_stream()` to the `struct odb_source` vtable, implementing it for the files backend to handle both packed and loose objects. The streaming.c code is updated to use this new callback rather than directly accessing packfile and loose object internals. This follows the established pattern of the series - moving backend-specific logic into callbacks while maintaining existing behavior.

Review discussion indicates this is a straightforward continuation of the architectural work, with Justin Tobler approving the implementation. The patch demonstrates the high standard of this ODB abstraction effort, where each change builds carefully on previous work while enabling future pluggable backends.
