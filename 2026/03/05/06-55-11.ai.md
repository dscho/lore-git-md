This is a test patch for the Linux fsmonitor implementation, part of the cross-platform filesystem monitoring series. It adds comprehensive test coverage for the inotify-based backend, specifically targeting edge cases and reliability scenarios.

The patch introduces several key test improvements:
- A smoke test that verifies the filesystem actually delivers inotify events (important for detecting non-functional configurations like older overlayfs)
- A stress test for rapid nested directory creation to exercise race conditions in recursive watching
- Reduced daemon start timeout from 60 to 10 seconds for faster test feedback
- Improved test robustness in CI environments (handles missing procps, empty process groups)
- Proper job control in submodule tests to prevent hangs

The tests specifically validate:
- Event delivery reliability (with timeout handling for problematic filesystems)
- Correct handling of EEXIST races during recursive directory watching
- Process group management in daemon startup/shutdown
- Submodule interaction scenarios

This represents the final test coverage for the Linux fsmonitor implementation, complementing the earlier platform-specific and cross-platform tests in the series. The tests are designed to catch real-world edge cases that were problematic in earlier iterations, particularly around filesystem event reliability and process management.
