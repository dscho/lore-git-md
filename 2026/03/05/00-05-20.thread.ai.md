Junio Hamano's biweekly "What's cooking in git.git" report provides a comprehensive snapshot of Git development activity. The report tracks patches through integration branches (maint, master, next, seen) and highlights notable changes. Recent graduates to master include: a new --auto-advance flag for git add -p, removal of the_repository dependency in mailmap code, fixes for subtree splitting optimization, default geometric repacking in git maintenance, gitweb mobile improvements, and various the_repository cleanups in merge-ort, tree-diff and wt-status code (correcting a typo where "marge-ort" was previously listed as "merge-ort" in the documentation).

New proposals under discussion include: git history split subcommand, documentation for custom subcommands, prevention of recursive lazy-fetching in promisor remotes, Linux fsmonitor daemon implementation, config-based hook definitions with parallel execution, and submodule remotes configuration. Ongoing work spans multiple major efforts: sideband control character sanitization, object database API restructuring, MIDX/bitmap incremental repacking, SHA-1/SHA-256 interoperability, and multi-branch status comparison.

The report shows steady progress on long-term refactoring (the_repository removal) alongside new feature development and bug fixes. Key contributors mentioned include Patrick Steinhardt (ODB API), Taylor Blau (geometric repacking), René Scharfe (the_repository cleanups), and Elijah Newren (merge-ort work). The merge-ort topic (en/merge-ort-almost-wo-the-repository) was merged to 'next' on February 26 with six commits eliminating the_repository uses in merge-ort and replay code. Kristoffer Haugsbakk contributed a documentation fix for the release notes. The mix of graduated patches and new proposals indicates active development across core functionality, performance optimizations, and user-facing features.
