This is a CI/build system patch series from Patrick Steinhardt updating GitLab CI to use macOS 15 images. The series also includes preparatory work to ensure compatibility with macOS 15's iconv behavior.

The main change updates the GitLab CI configuration to use newer macOS 15 runner images, which Apple will soon require as older versions become deprecated. This follows similar work done in January to handle iconv issues on macOS 14/15, though that earlier fix only covered the Makefile build system.

The first two patches extend those iconv workarounds to the Meson build system, which Git is gradually adopting alongside the traditional Makefile. The changes simplify the iconv detection logic and properly handle cases where macOS's iconv requires special reset handling. These are straightforward technical adjustments that match existing Makefile behavior.

The series appears well-motivated and carefully constructed, with each patch focused on a clear objective. Given Patrick's track record with build system changes and the preparatory work already done for Makefile builds, this update seems low-risk. The changes are primarily maintenance to keep CI working rather than introducing new functionality.
