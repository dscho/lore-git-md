This is a technical discussion about patch 11/17 in Patrick Steinhardt's series to make Git's object database (ODB) backend pluggable. The patch focuses on converting the `for_each_object()` functionality to use a callback-based dispatch system.

Karthik Nayak raises two documentation clarifications about the patch:
1. Points out that the function pointer in `struct odb_source` is itself a callback that invokes another callback, which could be clearer in the docs.
2. Notes that references to the `oi` structure in the documentation are slightly misplaced since they belong to the callback function's context rather than the direct operation.

Patrick Steinhardt acknowledges both points:
- Confirms the nested callback nature of the function pointer
- Explains that the `oi` references are carryover from an earlier iteration where the parameter structure was non-const and will be fixed

This exchange continues the pattern seen throughout the series where Karthik provides careful architectural review while Patrick maintains clear explanations of design decisions. The discussion remains focused on documentation precision rather than functional changes, indicating the core implementation is sound.
