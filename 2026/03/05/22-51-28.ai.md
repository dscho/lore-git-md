This is a test modernization effort, specifically improving the `t/t3310-notes-merge-manual-resolve.sh` test script. The patch is version 3 of a series that replaces fragile command substitutions with more robust test helpers.

The changes replace direct `git rev-parse` command substitutions with `test_cmp` and `test_cmp_rev` helpers throughout the test file. This makes test failures more debuggable by showing both expected and actual output when comparisons fail, while maintaining identical test coverage. The patch touches 10 test cases across 60 modified lines, reducing the script by 6 lines overall.

Key technical changes include:
- Replacing `test "$(git rev-parse A)" = "$(git rev-parse B)"` patterns with `test_cmp_rev A B`
- Using `test_cmp` with temporary files when comparing against stored expected values
- Adding proper variable quoting in shell commands
- Maintaining all existing test assertions while making their output more useful

The patch builds on previous test modernization work (commit b3ec5aec23) in the same file and incorporates feedback from Eric Sunshine about proper test helper usage. Francesco Paparatto has addressed all review comments from previous versions, properly squashing the changes into a single clean patch. The changes are narrowly focused on test reliability improvements without altering the underlying notes merge functionality being tested.
