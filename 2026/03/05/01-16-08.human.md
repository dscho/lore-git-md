This is a memory leak fix for the fsmonitor daemon, part of the larger cross-platform filesystem monitoring implementation. The patch addresses a cleanup oversight where cookie tracking data structures weren't properly freed when the daemon shuts down.

The fix adds proper cleanup of the `state.cookies` hashmap in `fsmonitor_run_daemon()`, which tracks filesystem change events. Each cookie entry's name (allocated via `strbuf_detach()`) is freed individually, followed by clearing and freeing the hashmap itself. This plugs a memory leak that would accumulate over the daemon's lifetime.
