This thread addresses a documentation gap in `git stash`'s behavior regarding pathspec interpretation. Aron Sigfridsson noticed that while the gitglossary advises checking individual commands for whether pathspecs are relative to the current directory or toplevel, the `git stash` man page doesn't specify this detail. 

The question is well-posed and points to a real documentation hole that could confuse users working with relative paths in stash operations. This appears to be a straightforward case where adding explicit clarification to the stash documentation would help users understand the command's behavior more precisely. No technical changes to the implementation seem necessary - just improved documentation.
