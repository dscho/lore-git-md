This is a Google Summer of Code (GSOC) proposal from Soutrik Das to extend the `remote-object-info` functionality in `git cat-file` for partial clones. The proposal builds on prior work by Calvin Wan and Eric Ju that introduced a way to query remote repositories for object metadata without fetching the full objects.

The core idea is to enhance partial clone workflows by allowing users to inspect remote objects (size, type, etc.) before deciding whether to fetch them. The proposal has three main goals: (1) rebase and finalize the existing `remote-object-info` implementation, (2) add object type information support, and (3) explore additional metadata like disk size and delta base.

Soutrik has already contributed two small patches to Git (a documentation fix and test modernization) that were merged, demonstrating basic familiarity with the codebase. The proposal includes a detailed 12-week timeline and notes the student's availability (35-40 hours/week). Some open questions are raised about potential user-facing design, like whether to support non-batch mode queries or sorting/filtering capabilities.

The proposal appears well-structured and shows engagement with prior technical discussions, though the actual implementation work would require deeper familiarity with Git's object model and protocol internals. The mentoring team will likely focus on helping refine the scope and technical approach during the community bonding period.
