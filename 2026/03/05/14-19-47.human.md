This is part 7 of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The series is now merged and represents a major architectural milestone in the ODB abstraction effort.

This patch makes the `reprepare()` operation pluggable by introducing a new callback in `struct odb_source`. The `reprepare` function clears backend caches when the repository state changes (e.g., after repacking). The files backend implementation moves its cache-clearing logic into a new `odb_source_files_reprepare()` function.

Review discussion with Justin Tobler questioned whether cache invalidation should be backend-agnostic, with Patrick acknowledging this as a valid concern and sharing a vision for future improvements. The patch maintains existing behavior while preparing for future backend implementations.

This continues the systematic conversion of ODB operations to callback-based dispatch, following the pattern established in earlier patches of the series. The change is mechanical but important for the overall pluggability goal.
