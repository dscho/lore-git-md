This is part of Patrick Steinhardt's ongoing object database (ODB) abstraction effort, specifically patch 11/17 in the series that makes the `for_each_object()` operation pluggable via a callback in `struct odb_source`. The patch converts the files backend's object iteration to use the new callback interface while maintaining existing behavior.

Key technical aspects:
- Adds a new `for_each_object` callback to `struct odb_source` with detailed documentation about expected behavior
- Implements the callback in `odb/source-files.c` for the files backend
- Provides an inline wrapper function `odb_source_for_each_object()` with clear documentation about flags and error handling
- Maintains support for optional population of object info via `object_info` struct
- Handles flags as a bitfield, with backend-specific interpretation

The patch follows the established pattern of the series by moving backend-specific logic into the files while providing a clean interface. Karthik Nayak's review confirms the technical approach while noting some minor documentation refinements needed around error handling. This continues the systematic conversion of ODB operations to the callback-based dispatch model that will enable future pluggable backends.
