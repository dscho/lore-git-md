CI/build system patch from Patrick Steinhardt that completes the macOS 15 iconv workaround for Meson builds. This is the second patch in a 3-part series updating GitLab CI to use macOS 15 images and handle its broken iconv behavior.

The patch adds detection for macOS 15's problematic iconv implementation to Meson's build configuration, mirroring a fix that was previously implemented for Makefile builds (d0cec08d70). The issue occurs when converting strings piece-by-piece in ISO-2022-JP encoding - iconv fails to maintain state between calls, producing corrupted output. The test case included here verifies proper handling of encoding state transitions and sets ICONV_RESTART_RESET if the platform exhibits the bug.

This is a straightforward technical follow-up to ensure Meson builds work correctly on macOS 15, maintaining parity with the Makefile build system. The change is well-contained, adding only the necessary test and conditional define without broader impacts. As with the rest of the series, it appears ready for merging pending any final review feedback.
