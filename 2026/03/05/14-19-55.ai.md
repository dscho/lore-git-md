This is part 15/17 of Patrick Steinhardt's series to make Git's object database (ODB) subsystem pluggable. The patch converts the `read_alternates()` functionality to use a callback in the `struct odb_source` vtable, continuing the systematic refactoring of ODB operations.

The changes move the alternates parsing logic from odb.c to the files backend implementation, adding a new `read_alternates` callback to the source vtable. The core `parse_alternates()` function is made public in odb.h since it's now shared between implementations. The files backend wraps the existing alternates handling code in the new callback interface.

This follows the established pattern of the series - identifying a core ODB operation, extracting it from the monolithic odb.c, and moving it behind a backend-specific callback. The implementation maintains all existing behavior while enabling future alternate backends to implement their own alternates handling.

Justin Tobler has been consistently reviewing this series, and this patch continues the same architectural rigor seen in previous parts. The change is well-documented with clear comments explaining the new callback's contract. This represents steady progress in the multi-year effort to abstract Git's object storage layer.
