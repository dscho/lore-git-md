This is part 13 of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The patch introduces a `write_object()` callback in the `struct odb_source` vtable, making object writing backend-specific while maintaining the existing behavior for the files backend.

The changes move the write operation from a direct call in `odb.c` to a callback dispatch pattern consistent with the series' approach. The files backend implementation simply wraps the existing `odb_source_loose_write_object()` function. The callback signature includes buffer, length, type, and flags parameters, plus out-parameters for the object ID and compatibility ID (for hash algorithm transitions).

This continues the systematic conversion of ODB operations to callback-based dispatch that the series has established. The patch follows the same high standard of architectural rigor seen in previous parts, with thorough documentation of the new callback in `source.h`. Review discussion indicates continued alignment with Justin Tobler and other contributors on the technical direction.

The series remains focused on its goal of abstracting ODB operations to support pluggable backends while maintaining backward compatibility. This patch represents another incremental step in that effort, converting one of the remaining core operations to the new callback model.
