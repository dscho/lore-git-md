This is part 11/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The patch makes the `for_each_object()` functionality pluggable by introducing a new callback in the `struct odb_source` vtable.

The change moves the object iteration logic from odb.c into backend-specific implementations, following the pattern established in earlier patches of the series. The files backend maintains its existing behavior of checking both packed and loose objects, while the new callback interface allows future backends to implement their own iteration strategies.

The patch is part of the ongoing ODB abstraction effort that has seen consistent positive review engagement from Justin Tobler and others. It continues the systematic conversion of core ODB operations to callback-based dispatch while preserving backward compatibility. The implementation appears clean and well-integrated with the series' architectural direction.
