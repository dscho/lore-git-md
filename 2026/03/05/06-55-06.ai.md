This is part of the cross-platform fsmonitor implementation effort, specifically patch 6/12 in the v11 series. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is shared across Unix platforms (not just macOS/Darwin). This matches the approach already used for the IPC code and completes the file reorganization started in patch 5/12.

The change updates both the Meson and CMake build systems to use `FSMONITOR_OS_SETTINGS` for the settings file, maintaining consistency with how the IPC file is handled. The patch carries forward attribution to the original contributors (Eric DeCosta and Marziyeh Esipreh) who worked on the Darwin-specific version.

This is a straightforward refactoring that improves code organization without changing functionality, part of the larger effort to unify fsmonitor support across Windows, macOS, and now Linux. The series has already addressed all technical concerns in previous iterations and this patch represents final cleanup work.
