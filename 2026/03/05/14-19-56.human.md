This is part 16/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The patch makes the `write_alternate()` function pluggable by introducing a new callback in `struct odb_source`.

The change moves the alternates writing logic from odb.c to the files backend implementation, following the series' pattern of converting core ODB operations to callback-based dispatch. The implementation carefully handles locking and file operations to safely update the alternates file while preserving existing entries.

This continues the systematic conversion of ODB internals that we've seen in previous patches, with the same attention to backward compatibility and architectural rigor. The patch maintains the series' high standard of documentation and implementation quality. Review discussion indicates technical alignment with Justin Tobler, who has been consistently engaged throughout this multi-year ODB abstraction effort.
