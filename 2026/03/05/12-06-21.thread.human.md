This thread addresses a focused improvement to `git-send-email`'s SMTP authentication, specifically enhancing OAUTHBEARER support by allowing the SMTP server's hostname and port to be passed to the Authen::SASL Perl module when available (version 2.2000+). Aditya Garg proposed the change, demonstrating through testing that older versions of Authen::SASL safely ignore these new parameters, maintaining backward compatibility.

The discussion reached quick consensus, with Junio C Hamano reviewing and approving the technical approach after verifying the compatibility behavior. The only remaining task was updating the commit message to better document this verification, which Aditya has now completed in v2. The implementation remains minimal - just two lines changed in `git-send-email.perl` to conditionally include the port parameter. This is a straightforward improvement that enhances OAUTHBEARER support while carefully preserving compatibility with existing installations, and is now ready for merging.
