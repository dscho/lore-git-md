This thread introduces a small but useful enhancement to `git-send-email`'s SMTP authentication, adding support for OAUTHBEARER by passing the SMTP server hostname and port to Authen::SASL when available. The patch comes from Aditya Garg, who has previously contributed several improvements to `git-send-email` functionality.

The change is minimal - just two lines added to pass the additional parameters when constructing the authentication hash - but enables compatibility with newer Authen::SASL versions (2.2000+) that can use this information. The patch maintains backward compatibility while taking advantage of the newer library's capabilities when present. Given Aditya's track record with email-related patches and the focused nature of this change, it seems likely to be accepted after any necessary version requirement verification.
