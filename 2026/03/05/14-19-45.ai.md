This patch introduces type safety for the ODB source abstraction as part of Patrick Steinhardt's ongoing ODB backend refactoring series. It adds an `enum odb_source_type` with two values: `ODB_SOURCE_UNKNOWN` (for error detection) and `ODB_SOURCE_FILES` (the current backend). The patch modifies the `odb_source_init()` function to require specifying the source type and adds a type check in the `odb_source_files_downcast()` helper that will BUG()` if the wrong type is provided.

The changes are mechanical but important for future extensibility - they ensure callers can't accidentally downcast a source to the wrong backend implementation once multiple backends exist. The patch updates all relevant files (`source.h`, `source.c`, `source-files.h`, `source-files.c`) to maintain consistency.
