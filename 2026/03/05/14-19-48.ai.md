Part of Patrick Steinhardt's ongoing object database (ODB) abstraction effort, this patch makes the `close()` operation pluggable in the ODB source infrastructure. It follows the established pattern of moving backend-specific logic into callback functions, in this case handling resource cleanup when closing an object database.

The change introduces a new `close` callback in `struct odb_source` and implements it for the files backend to close packfile stores. The high-level `odb_close()` function is simplified to iterate through sources and invoke their close callbacks. This maintains the existing behavior while preparing for future backend implementations that may need different cleanup logic.

The patch continues the series' architectural work to enable pluggable storage backends, with careful attention to maintaining existing functionality. As with previous patches in the series, this represents a well-contained change that moves the ODB abstraction forward while keeping the current files backend working as before. The implementation follows the established pattern of the series and appears technically sound.
