RFC series adding remote group support to `git push`, mirroring existing `git fetch` functionality. Authored by Usman Akinyemi. Core idea: enable pushing to all remotes in a configured group (defined via `remotes.<name>` config) with single command like `git push all-remotes`.

Design decisions resolved:
- `push.default` behavior: all modes work with groups, each remote follows its own configuration
- `--force-with-lease` semantics: same commit expectation applies uniformly
- Core principle: group push behaves identically to sequential individual pushes
- Failure handling: continues pushing after failures with final exit code as bitwise OR of individual results, matching `;` semantics (important for future parallel push support)

Latest implementation discussion:

   2. More efficient approach with N-1 children and final push in parent process (maintains identical behavior when N=1)
