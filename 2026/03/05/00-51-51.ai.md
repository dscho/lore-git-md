This is a platform compatibility patch adding Windows support for `pthread_cond_timedwait()` as part of the cross-platform fsmonitor implementation. 

The patch implements the POSIX `pthread_cond_timedwait()` function for Windows using the native `SleepConditionVariableCS()` API. It converts the absolute timeout from `timespec` to milliseconds, handles the timeout case by returning `ETIMEDOUT`, and properly propagates other errors through the existing `err_win_to_posix()` conversion. The implementation follows the same pattern as the existing `pthread_cond_wait()` in the Windows compatibility layer.

This is patch 3/12 in the v9 series that's implementing Unix-style fsmonitor support. The thread context shows this series is stable in Junio's 'seen' branch with all technical concerns resolved, including memory leak fixes. The pthread compatibility work is a prerequisite for the fsmonitor daemon's cross-platform process management.
