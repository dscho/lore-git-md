This is part 6 of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The series is now merged and represents a major architectural milestone in the ODB abstraction effort.

This particular patch makes the `free()` operation pluggable by introducing a new callback in `struct odb_source`. The changes are mechanical but important for the overall architecture:

1. Moves the files backend's free logic into a static callback function
2. Removes the public `odb_source_files_free()` function since callers should now use the generic `odb_source_free()`
3. Updates the base `odb_source_free()` to dispatch to the backend-specific callback
4. Adds documentation for the new callback field

The patch maintains existing behavior while better isolating backend-specific cleanup code. This follows the pattern established in earlier patches of the series where operations are converted to callback-based dispatch. The change is part of the broader effort to abstract the ODB interface so alternative backends can be implemented in the future.

Review discussion on earlier patches (particularly from Justin Tobler and Karthik Nayak) has been thorough, focusing on architectural boundaries and documentation precision. This patch appears uncontroversial and follows the established pattern from the series.
