This is a refactoring patch in the fsmonitor daemon series, specifically addressing build system organization for cross-platform support. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC path logic is not macOS-specific and will be shared with the upcoming Linux implementation. 

The key change introduces a distinction between `FSMONITOR_OS_SETTINGS` (for shared Unix/Win32 files) and `FSMONITOR_DAEMON_BACKEND` (for platform-specific implementations). This affects the Makefile, CMake, and Meson build systems, ensuring the correct files are included for each platform. The patch maintains all existing functionality while improving the code organization for future platform additions.

This is part of the larger effort to bring Linux fsmonitor support to parity with existing Windows and macOS implementations. The change is well-motivated and cleanly implemented, with appropriate build system updates across all supported build tools (Make, CMake, Meson). The patch carries forward attribution to previous contributors who worked on related IPC code.
