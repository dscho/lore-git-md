This is the first patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The patch is a preparatory refactoring that splits the `struct odb_source` definition and related functions into a new header/source file pair (`odb/source.h` and `odb/source.c`).

The change moves the `struct odb_source` definition and its constructor/destructor functions (`odb_source_new()` and `odb_source_free()`) out of `odb.h`/`odb.c` into the new dedicated files. This is in preparation for future patches that will expand the structure to include function pointers for pluggable backend operations.

The patch is mechanical and well-contained, with no behavior changes. It updates both the Makefile and meson.build to include the new source file. The commit message clearly explains the motivation - keeping high-level ODB interfaces separate from low-level source implementations as the structure grows more complex.

This is part of the ongoing ODB abstraction effort that Patrick Steinhardt has been leading, which aims to make Git's object storage backend pluggable. The series builds on two prerequisite cleanup patches and represents foundational infrastructure work. Reviewers Justin Tobler and Karthik Nayak have been actively engaged in the technical discussions around this architectural change.
