This is a refactoring patch series that introduces a type-safe cleanup mechanism for oidmap structures, part of the ongoing effort to improve memory management patterns in Git's codebase.

The series adds a new `oidmap_clear_with_free()` API that uses explicit callbacks for cleanup, replacing the older boolean-based `oidmap_clear()` which implicitly assumed plain `free()`. The new approach makes memory ownership semantics clearer and works better when oidmap entries are embedded in larger structures. The v3 iteration focuses on converting two key use cases - rev-list's missing_objects and odb's replace_map - after maintainer feedback narrowed the scope from the original proposal.

Patrick Steinhardt, who has been closely involved in reviewing this series, gives his approval to the current version. The implementation now includes comprehensive test coverage and follows the naming conventions requested during review. The rev-list conversion in particular demonstrates the API's value by replacing manual path cleanup with a type-safe callback. With both conversions meeting maintainer requirements and all outstanding feedback addressed, this series appears ready for merging in its two-patch form.
