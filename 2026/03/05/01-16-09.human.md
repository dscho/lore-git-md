This is a platform compatibility patch adding Windows support for `pthread_cond_timedwait()` as part of the cross-platform fsmonitor effort. Paul Tarjan implements the function using Windows' `SleepConditionVariableCS()` API with millisecond timeout calculation from absolute timestamps.

The implementation handles time conversion carefully - getting current time via `gettimeofday()`, converting both current time and deadline to milliseconds, then computing the relative timeout. It properly returns `ETIMEDOUT` if the deadline has passed and converts Windows error codes to POSIX equivalents. The change is straightforward but important for the fsmonitor daemon's event synchronization on Windows, which needs timed waits for its two-phase event handling.

This patch is part of the final polishing for the Linux fsmonitor series (v10/12), addressing one of the last remaining platform-specific requirements. The implementation looks solid and follows the established pattern for Windows pthread emulation in Git.
