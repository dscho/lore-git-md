This patch is part 10/17 of Patrick Steinhardt's series to make Git's object database (ODB) subsystem pluggable. It introduces a new callback `read_object_stream()` to the `struct odb_source` vtable, allowing different storage backends to implement their own streaming object read operations.

The change moves the streaming logic from the core ODB code into backend-specific implementations. The files backend implementation checks both packed and loose objects, similar to the previous centralized behavior. The patch follows the established pattern of the series by:
1. Adding the callback to the vtable interface
2. Implementing it for the files backend
3. Updating the core streaming code to use the callback

Justin Tobler has been actively reviewing this series and has approved previous patches. The implementation appears consistent with the architectural direction of the ODB abstraction effort, maintaining existing behavior while enabling future backend implementations. This represents another step in converting core ODB operations to use pluggable callbacks.
