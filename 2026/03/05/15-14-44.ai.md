This is a follow-up to a feature patch improving SMTP authentication in `git-send-email`. Aditya Garg responds to Junio C Hamano's review feedback about backward compatibility concerns when passing host/port parameters to Authen::SASL for OAUTHBEARER authentication.

The key clarification is that older versions of Authen::SASL will safely ignore the additional parameters, similar to how they handle the existing `authname` parameter that isn't used by all authentication methods. Garg confirms having tested this behavior with older library versions. He also acknowledges Junio's administrative note about proper mailing list submission protocol, committing to direct future patches to the list rather than individual maintainers.

The technical core remains unchanged - this is a two-line modification to `git-send-email.perl` that conditionally includes the port parameter when defined. The exchange highlights Git's meticulous attention to backward compatibility even for seemingly straightforward changes, with maintainers expecting explicit rationale for why new parameters won't break older implementations. Garg's response provides the needed assurance about the safety of the change across Authen::SASL versions.
