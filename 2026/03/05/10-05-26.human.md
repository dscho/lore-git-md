This is the second and final patch in a refactoring series that introduces type-safe cleanup for oidmap structures via a new `oidmap_clear_with_free()` API. The series has been narrowed down to just two conversions (rev-list and odb) after maintainer review.

The patch converts the `missing_objects` map in `builtin/rev-list.c` to use the new API. Previously, the code manually freed entry paths before calling `oidmap_clear()`. Now it uses a dedicated callback (`missing_objects_map_entry_free`) that handles both the path and entry cleanup in one place through `oidmap_clear_with_free()`.

The change is straightforward and well-contained, touching only the rev-list command. The patch includes a new unit test (not shown in the diff) that verifies the API behavior. Maintainers Junio and Patrick have already approved this approach in previous iterations of the series, with Patrick specifically requesting the callback naming convention used here.

This appears ready for merging as part of the final two-patch series, which focuses only on clear-value conversions after other cases were dropped from scope. The patch follows the project's preference for small, focused changes with explicit cleanup semantics.
