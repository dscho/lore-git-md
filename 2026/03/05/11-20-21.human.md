This is a CI/build system patch from Patrick Steinhardt that simplifies the iconv BOM check in Git's Meson build configuration. It's the first of three patches updating GitLab CI for macOS 15 compatibility.

The patch streamlines the test for whether iconv omits byte-order marks (BOM) when converting text encodings. This change mirrors a previous fix for the Makefile build system (d0cec08d70) and ensures both build systems handle iconv behavior consistently.
