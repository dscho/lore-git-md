Platform compatibility patch adding Windows pthread support. This is part 3 of a 12-patch series implementing cross-platform filesystem monitoring (fsmonitor) support, specifically adding `pthread_cond_timedwait()` to the Windows pthread compatibility layer. The implementation uses Windows' `SleepConditionVariableCS()` with millisecond timeout calculation from absolute timestamps.

The patch is straightforward - it converts the absolute timeout specification to a relative millisecond delay for the Windows API, with proper error handling for timeouts and other conditions. This functionality is needed for the fsmonitor daemon's synchronization across platforms. The series as a whole has been through extensive review and testing, with all technical concerns addressed in previous iterations. This particular patch looks clean and focused, implementing a well-defined POSIX API on Windows terms.
