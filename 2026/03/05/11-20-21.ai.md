This is a CI/build system patch from Patrick Steinhardt that simplifies the iconv BOM check in Meson. It's part of a 3-patch series updating GitLab CI for macOS 15 compatibility.

The patch streamlines the Meson build configuration by removing redundant variables and simplifying the type handling for iconv's input pointer. Instead of using a typedef that varies based on iconv version, it casts directly to `void*`. The functional check remains the same - verifying whether iconv emits a UTF-16 BOM when converting from UTF-8 - but the implementation is now more straightforward.

This change follows the same approach as an earlier Makefile fix (d0cec08d70) and helps maintain consistency between the two build systems. The patch appears well-constructed with a clear commit message explaining the rationale. As the first in the series, it sets up the groundwork for subsequent patches that will handle macOS 15's iconv behavior and update the CI configuration.
