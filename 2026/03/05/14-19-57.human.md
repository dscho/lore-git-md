This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The series has systematically converted all core ODB operations to callback-based dispatch while maintaining backward compatibility with the existing files backend.

Patch 17/17 introduces a `begin_transaction()` callback to the `struct odb_source` vtable, completing the transaction interface for atomic object writes. The implementation provides a files-backend specific version that creates temporary staging areas, with objects only persisted when the transaction is committed. This matches the pattern established throughout the series - each operation gets its own callback while maintaining existing behavior.

The patch follows the same high standard as the rest of the series, with thorough documentation and clean integration into the growing callback interface. Justin Tobler has been consistently engaged in reviewing the architectural changes across all patches, indicating strong technical alignment on this multi-year effort to make Git's object storage layer properly abstracted and extensible.

With this final piece in place, the ODB abstraction work appears complete - all core operations now go through the callback interface, paving the way for alternative storage backends while preserving the existing files-based implementation.
