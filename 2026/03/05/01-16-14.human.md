This is a refactoring patch that adds a pre-exec callback mechanism to Git's child process handling, part of the larger fsmonitor cross-platform support effort.

The patch introduces a `pre_exec_cb` function pointer in `struct child_process` that gets called between fork() and exec() in child processes. This provides a clean way to perform child-specific setup that must happen in the child's context, like closing inherited file descriptors. The patch includes a ready-made `close_fd_above_stderr()` callback that closes all file descriptors above stderr (skipping the child-notifier pipe), which is exactly what the fsmonitor daemon needs for proper process isolation.

The implementation is clean and focused, with proper Windows compatibility (the callback is a no-op there since Windows doesn't use fork/exec). The patch is part of the final v10 series that has already addressed all review feedback and is production-ready, with this particular change being one of the last pieces needed for robust process management across all platforms. The callback mechanism is general enough to be useful beyond just fsmonitor, though that's its immediate use case.
