This is the final patch in a security-focused series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005). The patch delays the secure-by-default behavior of sanitizing control characters until Git 3.0, maintaining backward compatibility for now while committing to the security change in the next major version.

The series, primarily developed by Johannes Schindelin and Junio Hamano, introduces configurable sanitization of control characters in sideband communications. This patch specifically adjusts the default behavior to remain permissive (allowing all control characters) in current versions, with the plan to switch to only allowing ANSI color sequences by default in Git 3.0. The implementation uses conditional compilation (`WITH_BREAKING_CHANGES`) to manage this transition.

The patch updates documentation to clearly explain both the current behavior and the planned change, and modifies tests to account for the version-dependent defaults. While the technical foundation for secure handling is already in place (including URL-specific configuration via `sideband.<url>.allowControlCharacters`), this final patch ensures no behavior changes occur until the major version bump.

This represents a careful balance between security and compatibility - the vulnerability is addressed technically while giving users and tooling time to adapt before the stricter defaults take effect. The series has undergone extensive testing, with production validation in Git for Windows and Red Hat environments over several months.
