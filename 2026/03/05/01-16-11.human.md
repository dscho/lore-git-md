This is a refactoring patch in the fsmonitor cross-platform implementation series. It renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC path logic is not macOS-specific and will be shared with the upcoming Linux implementation. The patch introduces a distinction between platform-specific files (handled via `FSMONITOR_DAEMON_BACKEND`) and shared Unix files (handled via `FSMONITOR_OS_SETTINGS`), updating the Makefile, CMake, and Meson build systems accordingly.

The changes are mechanical but important for the overall architecture - they allow the Linux fsmonitor implementation to reuse the Unix IPC code while keeping platform-specific components separate. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) whose work informed this refactoring.

This is part of a mature series (now at v10) that has already addressed extensive review feedback. The build system changes here are straightforward and unlikely to be controversial at this stage. The patch demonstrates good attention to cross-platform consistency by ensuring all three major build systems (Make, CMake, Meson) are updated in parallel.
