This is part of the cross-platform fsmonitor implementation effort, specifically patch 5/12 in the v11 series. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms, not just macOS. It introduces a new `FSMONITOR_OS_SETTINGS` build variable to distinguish between platform-specific files (like listener and health monitoring) and shared Unix files (IPC and settings), while keeping `FSMONITOR_DAEMON_BACKEND` for the truly platform-specific components.

The changes propagate through the build system (Makefile, CMake, meson) to maintain proper file inclusion across platforms. This is a clean refactoring that prepares for the Linux fsmonitor implementation by properly separating concerns between Unix-wide and platform-specific code. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) whose work informed this reorganization.
