This is patch 9/17 in Patrick Steinhardt's series to make Git's object database (ODB) subsystem pluggable, now successfully merged. The series systematically converts core ODB operations to callback-based dispatch while maintaining existing behavior.

This particular patch makes the `read_object_info()` function pluggable by introducing a new callback in `struct odb_source`. The change is more complex than previous conversions because the existing implementation has a two-phase lookup: first trying to read the object, then rechecking after repreparing the ODB if the first attempt fails. The patch introduces a new `OBJECT_INFO_SECOND_READ` flag to handle this case cleanly.

The implementation moves the object info reading logic into the files backend while preserving the existing behavior. The patch follows the established pattern of the series by keeping the high-level flow in `odb.c` while pushing backend-specific logic into callback functions. Justin Tobler has reviewed the patch positively, and it appears to be a well-considered addition to the ongoing ODB abstraction effort.
