This is the final patch in a series introducing Linux fsmonitor support using inotify. The patch converts the pathname deduplication in the fsmonitor daemon from using a khash implementation to the newer strset data structure, which provides a cleaner interface for string sets.

The change was suggested by Patrick Steinhardt and maintains the same functionality while simplifying the code. Since the paths are already interned strings from the batch data, the patch sets strdup_strings=0 to avoid unnecessary string copies. This is a minor cleanup patch that follows through on earlier review feedback, completing the series' transition to more maintainable data structures.

The fsmonitor Linux implementation is now production-ready in Junio's 'seen' branch, with all technical concerns addressed including process isolation, Windows compatibility, container environment reliability, and comprehensive test coverage. This final patch represents the last bit of code polish before the feature is ready for wider use.
