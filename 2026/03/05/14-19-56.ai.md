This is part 16/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The patch introduces a `write_alternate()` callback in the `struct odb_source` vtable, completing the alternates-related operations after the previous patch added `read_alternates()`.

The change moves the alternates writing logic from odb.c to the files backend implementation in odb/source-files.c, following the series' pattern of converting direct operations to callback-based dispatch. The implementation maintains the existing behavior where alternates are written to the `info/alternates` file with proper locking and duplicate checking.

The patch continues the series' high standard of documentation, with clear comments explaining the callback's expected behavior and thorough error handling. Like previous patches in the series, this maintains backward compatibility while enabling future alternate storage backends to implement their own writing mechanism.

Justin Tobler continues to provide consistent technical review engagement, indicating ongoing alignment on the architectural direction. The patch builds cleanly on the previous ODB abstraction work and represents steady progress in the multi-year effort to make Git's object storage fully pluggable.
