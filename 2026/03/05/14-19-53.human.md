This is part 13 of Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The patch makes the `write_object()` function pluggable by introducing a new callback in the `struct odb_source` vtable.

The change follows the established approach of the series - moving backend-specific logic into callback functions while maintaining the existing behavior. Here, writing objects (including freshening existing ones) becomes a backend operation, with the files backend implementing the same logic as before through the new callback. The patch includes thorough documentation of the callback's expected behavior.

This continues the systematic conversion of core ODB operations to callback-based dispatch, following similar conversions for reading objects, querying object info, streaming objects, iterating objects, and freshening objects in previous patches. The implementation maintains the series' architectural rigor and appears well-aligned with the overall goal of enabling alternative storage backends.
