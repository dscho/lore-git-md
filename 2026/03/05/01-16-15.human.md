This is a process management patch in the fsmonitor daemon series, addressing inherited file descriptors and process group issues. It's part of the larger cross-platform fsmonitor implementation that's now in Junio's 'seen' branch.

The patch ensures the fsmonitor daemon properly detaches from its parent process by:
1. Closing all inherited file descriptors above stderr (to prevent hangs when parent processes wait on pipes)
2. Creating a new session with `setsid()` on Unix when running detached (to prevent shell job control from blocking)
3. Using `FreeConsole()` on Windows for similar detachment
4. Silencing stdout/stderr on the implicit spawn path to avoid terminal interference

These changes resolve real-world issues seen in CI systems and interactive shells where the daemon could cause hangs by keeping pipes open or remaining in the shell's process group. The implementation uses a new `pre_exec_cb` mechanism in `struct child_process` for clean file descriptor handling.

This appears to be a well-considered fix addressing concrete problems encountered in testing, with straightforward platform-specific handling. As the 9th patch in a 12-part series that's already received extensive review, it looks ready for integration.
