This is part 15/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to enable pluggable storage backends. The patch makes the `read_alternates()` function pluggable by adding a callback to `struct odb_source`.

The discussion focuses on clarifying the expected format for alternate object database sources in the callback's documentation. Justin Tobler notes that the documentation suggests support for a "backend://" prefix format that isn't yet implemented, prompting Patrick to acknowledge this and commit to updating the comment to better reflect the current state.

This continues the pattern seen throughout the series of carefully evolving the ODB API while maintaining clear documentation about current capabilities versus future directions. The exchange demonstrates the ongoing attention to detail in both implementation and documentation as this foundational refactoring nears completion.
