This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The patch introduces transaction support by adding a `begin_transaction()` callback to the ODB source vtable, completing the core set of operations needed for alternative backends.

The implementation provides transaction semantics for the files backend, allowing objects to be written to a temporary staging area that only becomes permanent when committed. The patch follows the same pattern as previous callbacks in the series - defining the interface in `odb/source.h` and implementing the files-specific version in `odb/source-files.c`.

With this addition, the ODB abstraction now provides callbacks for all fundamental operations: reading/writing objects, managing alternates, and now transactions. The series has systematically converted Git's object storage layer from direct filesystem operations to a clean callback-based interface while maintaining backward compatibility.

The patch maintains the high standard of the series with thorough documentation and clean integration. Justin Tobler's continued engagement in reviewing suggests technical alignment on this architectural direction. This completes the multi-year effort to make Git's object storage properly abstracted and ready for alternative backend implementations.
