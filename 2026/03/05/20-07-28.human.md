This is a documentation clarification request about `git stash`'s pathspec behavior.

Aron Sigfridsson points out an inconsistency in Git's documentation regarding how pathspecs are interpreted by `git stash`. The gitglossary states that commands should document whether their pathspecs are relative to the current directory or toplevel, but this information appears to be missing from `git stash`'s documentation. The email politely asks whether this is intentional or an oversight.

The question is well-formed and points to a genuine documentation hole - the current man page doesn't specify this important detail about pathspec interpretation. This seems like a straightforward documentation improvement opportunity that could likely be addressed with a small patch adding the missing clarification. The tone is constructive and appreciative of the project's work.
