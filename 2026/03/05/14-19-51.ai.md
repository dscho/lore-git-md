This is patch 11/17 in Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The patch makes the `for_each_object()` functionality pluggable by introducing a new callback in the `struct odb_source` vtable.

The changes move the existing object iteration logic from odb.c into the files backend implementation, following the pattern established in previous patches of the series. The new `odb_source_files_for_each_object()` function handles both loose and packed object iteration, maintaining the same behavior as before but now as a backend-specific implementation.

Key technical aspects:
- Adds `for_each_object` callback to the ODB source vtable
- Moves iteration logic from odb.c to odb/source-files.c
- Preserves all existing flags and behavior (local-only, promisor-only, etc.)
- Includes comprehensive documentation of the callback interface
- Follows the series' architectural pattern of moving backend-specific code out of odb.c

The patch continues the systematic conversion of ODB operations to callback-based dispatch, with Justin Tobler continuing to provide positive review feedback. This represents steady progress in the ODB abstraction effort, with no new concerns raised about this particular change. The implementation maintains the high standard seen throughout the series for major architectural changes to core Git infrastructure.
