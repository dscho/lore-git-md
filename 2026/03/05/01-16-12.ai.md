This is a refactoring patch in the fsmonitor cross-platform implementation series, specifically focusing on file organization. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is shared across Unix platforms (not just macOS/Darwin) and updates the build systems accordingly.

The change is straightforward - it moves the settings implementation to a more generically named file while maintaining all functionality. The build system updates ensure both CMake and Meson properly handle the renamed file through the existing `FSMONITOR_OS_SETTINGS` variable, matching the pattern used for the IPC implementation. This is part of the larger effort to bring fsmonitor support to Linux while maintaining existing macOS and Windows functionality, with all technical concerns now resolved in previous iterations of the series. The patch has two "Based-on-patch-by" credits indicating it builds on prior work by other contributors.
