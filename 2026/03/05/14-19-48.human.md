This is patch 8/17 in Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to enable pluggable storage backends. The series has already been merged after thorough review.

The patch introduces a new `close` callback in the `struct odb_source` interface, making it possible for different ODB backends to implement their own resource cleanup logic. The files backend implementation is updated to close its packfile store through this new callback, replacing direct calls in the core ODB code. This continues the pattern seen in earlier patches of moving backend-specific operations into callback functions.

The change is part of the larger architectural effort to abstract the ODB layer, allowing alternative storage backends beyond the traditional filesystem-based approach. Review discussion on earlier patches (particularly with Justin Tobler) has already established consensus on this general direction, so this incremental change is unlikely to generate new controversy. The implementation looks straightforward and maintains existing behavior while improving the pluggability of the system.
