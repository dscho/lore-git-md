Thread identity: Feature request for `git worktree list --created` to sort worktrees by creation timestamp, from Norbert Kiesel.

Core problem: Users managing many worktrees (20+) need to identify recently created ones. Current `git worktree list` output order is unspecified. Hannes' alternative `git worktree list | cut -f1 | xargs ls -ldtr` approach faces Norbert's counterargument that directory mtimes update on file additions, making them unreliable for creation ordering. Discussion reveals deeper questions about whether Git should track worktree creation as first-class metadata.
