This is a security patch in a series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). The patch modifies Git's sideband channel handling to allow ANSI color sequences by default while still blocking other potentially dangerous control characters.

The change comes in response to real-world use cases where `pre-receive` hooks rely on colored output for message urgency. The implementation introduces granular control through `sideband.allowControlCharacters` configuration, which can be set to:
- `default`/`color`: Allow only ANSI colors (new default)
- `false`: Block all control characters except basic whitespace
- `true`: Allow all control characters (legacy behavior)

The patch includes thorough test coverage in `t5409-colorize-remote-messages.sh` verifying both the default behavior (allowing colors but blocking other sequences) and the configurable overrides. Documentation updates clearly explain the new configuration options and their security implications.

This represents a pragmatic middle ground in the ongoing security hardening effort - maintaining compatibility with existing workflows that use colors while still protecting against more dangerous terminal control sequences. The change has already seen extensive real-world validation through deployments in Git for Windows and Red Hat environments.
