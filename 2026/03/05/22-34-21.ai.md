The changes replace direct command substitutions with more robust test helpers (`test_cmp` and `test_cmp_rev`) to make failures more debuggable. The patch was originally sent by Francesco Paparatto with Junio Hamano's Suggested-by tag, but Eric Sunshine notes his review feedback had more direct influence on the specific improvements.

The patch reduces the script by 6 lines while maintaining the same test coverage. Eric Sunshine confirms the changes make the tests more developer-friendly but points out the patch needs to be rebased properly (squashing v1 and v2) before final acceptance.

This continues Git's broader test modernization effort to improve failure diagnosis. The discussion highlights the importance of proper attribution in commit messages and the project's preference for clean patch series where each version stands alone rather than accumulating incremental fixes.
