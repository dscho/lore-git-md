This is a feature patch for `git send-email` that adds support for passing SMTP server hostname and port information to the Authen::SASL authentication module. The change enables compatibility with newer versions of Authen::SASL (2.2000+) which can use this information when constructing OAUTHBEARER authentication strings.

The patch is straightforward - it simply adds two new parameters (`host` and optional `port`) to the SASL authentication configuration. The change appears well-scoped and correctly implemented, with the port parameter only being included when defined. The commit message references the relevant Authen::SASL documentation showing this is a supported feature.

Aditya Garg has been a consistent contributor to `git send-email` improvements, and this patch continues that pattern with a focused, technically sound enhancement. The change should be uncontroversial as it maintains backward compatibility while adding support for newer authentication capabilities.
