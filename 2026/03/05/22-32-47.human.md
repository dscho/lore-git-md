This is the first patch in a two-part RFC series proposing remote group support for `git push`, mirroring the existing `git fetch` functionality. The patch refactors group-handling code from `builtin/fetch.c` into `remote.c` to make it reusable across commands.

The change moves three key components that handle remote group resolution:
1. The `remote_group_data` struct that holds group configuration
2. The `get_remote_group()` config callback that reads `remotes.<name>` entries
3. The `add_remote_or_group()` function that resolves a name to either a group or single remote

This is a straightforward code movement with no behavior changes, preparing for the second patch which will add push group support. The author notes this refactoring was suggested by Junio Hamano, indicating early maintainer alignment on the approach. The patch touches core remote-handling code but is relatively contained, affecting only the three mentioned files. As an RFC, it's clearly marked as seeking design feedback before finalizing.
