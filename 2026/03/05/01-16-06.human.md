This is the final version of a feature series implementing Linux support for Git's filesystem monitoring (fsmonitor) using inotify, bringing it to parity with existing Windows and macOS implementations. The 12-patch series has undergone extensive review and testing over multiple iterations, with all feedback addressed.

The implementation uses inotify rather than fanotify due to privilege requirements, with careful handling of directory watches and rename events. Key technical aspects include recursive directory watching, remote filesystem detection, proper process management, and robust daemon termination. The series also fixes memory leaks in the platform-independent code and deduplicates shared Unix IPC/settings logic.

Notable changes in v10 include:
- Replacing a close_fd_above_stderr flag with a more general pre_exec_callback mechanism
- Converting the final khash usage to strset for simpler code
- Fixing Windows build compatibility
- Adding comprehensive test coverage

The implementation is now production-ready across all major platforms, with all known technical concerns resolved. Paul Tarjan reports successful deployment in large-scale environments, and the series has been stable in Junio's 'seen' branch. This represents the culmination of work originally started in PRs 1352 and 1667, now fully integrated with the current codebase.
