This is part 2 of a 4-patch series improving `git checkout -m` conflict resolution with autostash behavior. The patch focuses on making stash creation silent during branch switching operations.

The change introduces a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message when stashing changes during checkout. This addresses a UX concern where the stash message could be distracting during normal branch switching workflows. The implementation adds a `silent` parameter to the internal stash creation function while maintaining the existing behavior for other callers.

The patch is straightforward and well-contained, touching only the sequencer code that handles autostash operations. It follows the series' goal of making checkout conflict resolution more seamless by reducing unnecessary output. The change appears to be a direct response to maintainer feedback requesting quieter operation during checkout.
