Feature patch adding customizable conflict marker labels to autostash application. This is patch 3/4 in Harald Nordgren's series enhancing `git checkout -m` with autostash behavior. The patch extends the sequencer's autostash machinery to support passing custom labels (`--ours-label`, `--theirs-label`, `--base-label`) through to `git stash apply`.

The key technical changes:
- Adds new parameters to `apply_save_autostash_oid()` for passing label strings
- Introduces `apply_autostash_ref_with_labels()` as the public interface for labeled autostash application
- Maintains backward compatibility by keeping existing functions with NULL labels
- Updates the sequencer.h header with the new function declaration

The implementation routes the existing stash apply machinery through a common internal function that now conditionally adds the label arguments when non-NULL. This enables callers (like the enhanced `-m` checkout) to provide branch-specific labels for conflict markers while preserving the default behavior elsewhere.

The patch is narrowly focused on plumbing the label options through the sequencer's autostash infrastructure without changing any existing behavior. It follows the series' pattern of incremental changes, with the actual label generation and checkout integration coming in other patches. The implementation looks clean and maintains the separation of concerns established in earlier versions.
