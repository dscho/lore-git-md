EditorConfig behavior fix for Git's formatting rules. Taylor Blau identified an unintended side effect of commit 046e1117d5d which added path-specific patterns for sample hooks in `.editorconfig`. The change inadvertently altered how other glob patterns in the same section were processed by EditorConfig implementations (observed in vim-editorconfig).

The patch restores correct behavior by splitting the rules into two distinct sections: one for tree-wide patterns (e.g. `*.c`) and another for path-specific patterns (e.g. `templates/hooks/*.sample`). This ensures C files match formatting rules regardless of their location in the tree, while maintaining the hook-specific settings. The commit includes an explanatory comment to prevent similar issues in future edits.

Technical details: The fix addresses an EditorConfig specification quirk where path-specific patterns can affect interpretation of other patterns in the same section. The change is contained to `.editorconfig` with no impact on other build system components or runtime behavior.
