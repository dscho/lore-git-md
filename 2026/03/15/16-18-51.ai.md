This is the second patch in Phillip Wood's 3-part series to remove `the_repository` usage from worktree functions, part of the broader global variable removal effort. The patch simplifies the warning message in `can_use_local_refs()` when HEAD is invalid or points to an unborn branch.

Previously, the function would read and display the contents of ".git/HEAD" as part of the warning, which was problematic for reftable-backed repositories where HEAD isn't stored in the filesystem. The patch removes this filesystem-specific behavior while maintaining the warning's core functionality. It also updates the test suite to use `test_grep` instead of direct `grep` calls for better test output.

The changes touch `builtin/worktree.c` and the test file `t/t2400-worktree-add.sh`. The patch follows the series' pattern of incrementally removing `the_repository` dependencies while preserving behavior, with test updates confirming the warning still works as intended. This is a straightforward cleanup that aligns with the project's move away from filesystem assumptions in favor of backend-agnostic interfaces.
