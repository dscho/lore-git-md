This is a CI/build system patch that fixes an unintended behavior change in Git's `.editorconfig` file. Taylor Blau noticed that after commit 046e1117d5d added a path-specific pattern for sample hooks, it inadvertently changed how other glob patterns in the same section were interpreted by EditorConfig implementations.

The patch splits the rules into two sections - one for tree-wide patterns (like `*.c`) and another for path-specific patterns (like `templates/hooks/*.sample`). This restores the pre-046e1117d5d behavior where C files would match the formatting rules regardless of their location in the tree. The change is accompanied by a comment explaining the separation to prevent similar issues in the future.

The commit message thoroughly explains the EditorConfig specification quirk that caused this behavior, noting it may be implementation-specific (observed in vim-editorconfig). The fix is straightforward and well-motivated, with a clean diff that clearly shows the structural change to the configuration file.
