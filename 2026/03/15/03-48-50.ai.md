Test fix addressing cleanup in ignore-file test.

This is a small test cleanup patch that fixes an oversight in `t0008-ignores.sh`. The test "symlinks not respected in-tree" creates a subdirectory and symlinks but only cleans up the `.gitignore` file, leaving the `subdir` directory behind. The patch adds `subdir` to the `test_when_finished` cleanup command.

The change is straightforward and clearly correct - it ensures the test cleans up all artifacts it creates. The test itself verifies that symlinked `.gitignore` files in the working tree are not respected (as opposed to those in `.git/info/exclude` which are). This is part of Git's ignore-file handling behavior.

The patch comes from a relatively new contributor (Mirko Faina) and follows standard practices - it's a focused change with a clear commit message and proper sign-off. While minor, it improves test hygiene by preventing leftover directories from potentially affecting subsequent tests.
