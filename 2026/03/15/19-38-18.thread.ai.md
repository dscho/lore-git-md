GSoC proposal for `git evict` command to manage disk space in partial clones. Student Amisha Chhajed (with prior Git contributions including string-list optimizations) proposes adding selective blob removal functionality for objects that can be refetched from promisor remotes. Design includes filtering options: `--outside-cone` (sparse-checkout integration), `--older-than` (staleness), `--large-only` (size-based), and `--tree-depth` (object graph position). Implementation plan involves checking promisor availability via `is_promisor_object()` followed by repacking. 12-week timeline covers core functionality, testing, and documentation. Builds on existing partial clone infrastructure without new concepts.
