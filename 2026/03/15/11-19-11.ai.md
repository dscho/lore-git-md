This is part 2/4 of a feature series enhancing `git checkout -m` with autostash behavior. The patch adds silent mode to autostash creation, addressing Junio's preference for quiet operation during branch switching.

The change introduces a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message, while maintaining the existing verbose behavior for other callers. The implementation:
- Adds a `silent` parameter to the internal `create_autostash_internal()`
- Moves the status message from stdout to stderr when not silent
- Preserves all existing functionality while adding the new silent variant

This is a straightforward plumbing change that enables the next patch to use silent stash creation during checkout operations. The modification touches core sequencer functionality but is well-contained, with clear separation between the new silent variant and existing behavior. The patch follows the series' pattern of incremental improvements to the autostash infrastructure while maintaining backward compatibility.
