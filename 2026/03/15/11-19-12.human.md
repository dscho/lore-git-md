This is the third patch in a 4-part series enhancing `git checkout -m` with autostash behavior and conflict resolution improvements. The patch focuses on adding customizable conflict marker labels to the autostash machinery.

The change introduces new parameters to pass label strings through the autostash application process, enabling callers to specify custom labels for the "ours", "theirs", and "base" sides of conflicts. This builds on the new `--ours-label`, `--theirs-label`, and `--base-label` options added to `git stash apply` in earlier patches.

The implementation adds a new public function `apply_autostash_ref_with_labels()` while maintaining backward compatibility with the existing label-less variants. The patch touches the sequencer's autostash handling code, modifying several internal functions to optionally pass through the label parameters. The changes are straightforward plumbing of the new parameters through the call stack.

This is a well-contained technical change that completes the labeling functionality needed for the series' goal of improving conflict resolution during branch switching. The patch appears ready for merging, with clean separation from the still-pending submodule discussion.
