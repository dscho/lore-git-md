This is the first patch in a feature series enhancing `git checkout -m` with autostash behavior, now adding custom conflict marker labeling capabilities to `git stash apply`. The patch introduces new `--ours-label`, `--theirs-label`, and `--base-label` options that let users specify custom labels for conflict markers instead of the default "Updated upstream"/"Stashed changes" text.

The implementation is cleanly focused - it adds the new options to the command-line interface, documents them in the man page, and includes a test verifying the custom labels appear correctly in conflict markers. The changes are minimal and well-contained, touching only the stash command's documentation while maintaining backward compatibility.

This functionality will be used by subsequent patches in the series to improve the branch-switching conflict experience by showing branch names in conflict markers. The patch appears ready for merging with thorough documentation and test coverage of the new feature.
