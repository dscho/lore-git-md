This is a test cleanup patch addressing the ignore/exclude file handling tests.

The patch fixes a minor oversight in test `t0008-ignores.sh` where the cleanup step for the "symlinks not respected in-tree" test case didn't remove the temporary subdirectory it created. The test creates both a `.gitignore` symlink and a `subdir/.gitignore` symlink to verify how Git handles symlinked ignore files, but was only cleaning up the top-level `.gitignore`. The patch adds `subdir` to the `test_when_finished` cleanup command.

This is a straightforward maintenance improvement - the test behavior isn't changing, just making sure temporary files are properly cleaned up. The change is small and clearly correct, addressing a minor gap in test hygiene. It follows the common pattern seen in other tests where `test_when_finished` is used to clean up test artifacts.
