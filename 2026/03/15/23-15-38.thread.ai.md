Thread identity: bugfix patch for `git apply` error reporting, submitted as part of GSoC.

Core problem: current error messages for corrupt patches only show line numbers without indicating which input file (or stdin) the error occurred in, making debugging difficult when applying multiple patches or reading from stdin.

Solution: modify error messages to include the input source (filename or "<stdin>") alongside line numbers. Implemented by adding `state->patch_input_file` to error message format strings in `apply.c`.

Technical details: changes are in `apply.c` to include input source in error messages. Adds two test cases in `t/t4100-apply-corrupt.sh` verifying the new error format for both file input and stdin scenarios.
