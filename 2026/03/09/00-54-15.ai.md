This is a feature patch in Adrian Ratiu's ongoing hook configuration series, adding config scope visibility to `git hook list`. The patch enables users to see where each configured hook was defined (system/global/local) via a new `--show-scope` flag, similar to `git config --show-scope`.

The implementation stores the config scope during the config callback pass and carries it through to the hook structs. Traditional hooks from the hookdir are unaffected since they don't come from config. The patch includes thorough documentation updates, test coverage verifying the scope display works as expected, and maintains backward compatibility when the flag isn't used.

This builds on Adrian's previous hook configuration work currently in 'next', with the change suggested by Junio Hamano. The implementation follows Git's patterns for configuration handling and includes appropriate BUG() checks for invalid states. The test demonstrates both the new scope display and confirms the output remains unchanged without the flag.
