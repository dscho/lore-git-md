This is a small refactoring patch that addresses a compiler warning in the `remove_path()` function. The warning occurs when building with glibc-2.43, where assigning the result of `strrchr()` to a non-const pointer triggers `-Wdiscarded-qualifiers`.

The patch improves clarity by using separate variables for the original const string and its strdup'd copy, rather than reusing the same pointer for both purposes. The change is straightforward and maintains the same behavior while making the code's intent clearer. The author (Collin Funk) is not one of the project's regular contributors, but this appears to be a clean, focused improvement with no obvious downsides.

The modification touches only the directory handling code in `dir.c`, specifically the path removal logic. While small, it's the kind of incremental quality improvement that helps keep the codebase warning-free across different compiler versions.
