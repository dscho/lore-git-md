This is the final patch series in Adrian Ratiu's work on Git hook configuration, consisting of cleanups and small feature additions to `git hook list`. The series builds on Adrian's prior config-based hook work that is already in the 'next' branch.

The patches introduce two new user-facing features for `git hook list`: a `--show-scope` flag to display where each hook is configured (local, global, etc.), and visibility of disabled hooks marked with "(disabled)". The series also includes various internal improvements - BUG() checks for invalid states, API simplifications, documentation standardization, test coverage of hook execution ordering, and infrastructure preparation for future metadata storage.

Junio Hamano notes in his reply that basing the series on 'next' is not ideal, as it would create dependencies on unrelated topics. Instead, he has rebased the work directly on master plus the relevant config-hooks topic. The series is now queued for integration, marking the completion of this phase of hook configuration improvements.
