This is the final version of Adrian Ratiu's hook configuration series, now queued for integration. The patch set builds on his prior work (already in 'next') that enables configuring hooks via Git config rather than just filesystem paths. This iteration focuses on cleanups and two small but useful user-facing additions to `git hook list`:

1. A `--show-scope` flag to display where each hook's configuration originates (local, global, etc.)
2. Clear marking of disabled hooks in the output

The series also includes various internal improvements: better API design (replacing ad-hoc cleanup functions with standard patterns), documentation standardization, test coverage for hook execution ordering, and infrastructure preparation for future metadata storage. Junio notes that basing on 'next' was problematic (since it would tie this work to unrelated topics) and instead merged the prerequisite patches directly from Adrian's personal branch.

The changes reflect feedback from multiple reviewers: Junio suggested the scope display feature, Patrick Steinhardt proposed both the execution order test and disabled hook visibility, and Eric Sunshine provided final polish on style issues like error message formatting. With all loose ends addressed and CI passing, this appears ready for the next release cycle.
