This is part 9/10 of Adrian Ratiu's series improving Git's hook configuration support, building on work already in the 'next' branch. The patch adds a `--show-scope` option to `git hook list` that displays where each hook was configured (system/global/local), matching the behavior of `git config --show-scope`.

The change stores the config scope during the initial config parsing pass and carries it through to the hook structs. Traditional hooks from the hookdir remain unaffected since they don't come from config. The implementation includes thorough documentation updates and a new test verifying the behavior. Junio Hamano suggested this feature, which maintains backward compatibility - the scope information is only shown when explicitly requested with the new flag.

This continues Adrian's ongoing effort to make Git's hook subsystem more configurable and transparent. The patch is well-structured with clear commit message, proper documentation, and test coverage, following the established patterns from previous work in this area.
