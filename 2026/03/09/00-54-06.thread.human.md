Adrian Ratiu's completed 10-patch series extends Git's hook configuration support with cleanups and small features, building on his prior work to make hooks configurable via Git's configuration system rather than just filesystem paths. The series has been rebased and is now queued for integration after addressing review feedback.

Key additions include a `--show-scope` option for `git hook list` to show where each hook's configuration originates (system/global/local) and display of disabled hooks in the output. The implementation has converged on a tab-separated output style (mirroring `git config --show-scope`) to ensure reliable machine parsing while maintaining human readability. For example, disabled hooks are now marked with a "disabled\t" prefix.

The series includes various code cleanups, moving utility functions to more appropriate locations and replacing custom structures with standard string-list functions. A new `hook_config_cache_entry` struct tracks per-hook data. Tests verify both the execution ordering of hooks and the new output formats.

After review iterations addressing style improvements, documentation clarifications, and build fixes (including one remaining macOS issue), the series appears well-polished with consensus forming around the implementation approach. This represents another step in Adrian's ongoing effort to modernize Git's hook configuration capabilities.
