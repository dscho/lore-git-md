Adrian Ratiu's hook configuration series is nearing completion, with the focus now on finalizing the output format for `git hook list`. The series, which extends Git's hook configuration support with cleanups and small features, has been rebased by Junio and is queued for integration.

The latest discussion centers on how to display hook metadata like scope ("local", "global") and disabled status in the list output. The current parentheses-enclosed format ("hook-name (local, disabled)") risks ambiguity with hook names containing spaces. Adrian proposed adopting the tab-separated format used by `git config --show-scope`, which Patrick Steinhardt agrees would be more parseable while still human-readable. This reflects Git's ongoing balance between usability and machine processing needs.

Patrick and Adrian are aligned on moving to a structured format, though they acknowledge Git's general avoidance of JSON. The change would affect both the scope display (patch 9/10) and disabled hook display (patch 10/10). A build failure identified by SZEDER Gábor remains to be fixed in v2, but other style feedback has already been addressed. With this output format decision being one of the last open questions, the series appears close to final form.
