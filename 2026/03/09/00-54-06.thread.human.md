Adrian Ratiu's 10-patch series modernizing Git's hook configuration subsystem has been approved for merging. This completes his multi-series effort to make hooks configurable through Git's configuration system rather than just filesystem paths. The changes add two user-visible features to `git hook list`: a `--show-scope` flag showing where each hook is configured (system/global/local), and visibility of disabled hooks in the output.

The implementation introduces infrastructure for future metadata storage while cleaning up the codebase - standardizing terminology, improving test coverage of hook execution order, and refactoring memory management. Junio Hamano confirmed all review feedback from earlier versions has been addressed, including build fixes and output format standardization to match `git config --show-scope`'s tab-separated fields. The only remaining issue is an unrelated macOS build breakage.

With no outstanding objections after weekend review, the series will proceed to 'next' and then 'master', marking the culmination of Adrian's work to make hook configuration more flexible and observable. Key contributors Patrick Steinhardt and Eric Sunshine provided technical and style feedback throughout the development process.
