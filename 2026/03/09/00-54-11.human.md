This is a refactoring patch in Adrian Ratiu's ongoing hook configuration series, which is currently in the 'next' branch. The patch replaces a custom hook cleanup function with the more standard `string_list_clear_func()` pattern.

The key change converts `hook_list_clear()` to use `string_list_clear_func()` with a new `hook_free()` helper, making the API cleaner by eliminating NULL function arguments. The patch also moves the callback data free function into the hook struct itself rather than passing it separately during cleanup.

The changes touch hook.c, hook.h, and builtin/hook.c, with most of the complexity coming from ensuring the callback data is properly handled during cleanup. The patch follows Patrick Steinhardt's suggestion to use more standard string list patterns and includes test coverage for the modified functionality.

This is a straightforward internal cleanup that builds on Adrian's prior accepted work, with no behavior changes beyond the implementation details of memory management. The patch series continues Adrian's effort to improve Git's hook configuration subsystem.
