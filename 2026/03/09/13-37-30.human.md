This is a feature patch series (v3) from Adrian Ratiu and Emily Shaffer enabling parallel execution of Git hooks, building on Adrian's prior configurable hooks work. The 9-patch series introduces multiple control points for parallel hook execution while maintaining safety through explicit opt-in requirements.

The series provides several ways to configure parallel execution:
- Global `hook.jobs` config (patch 3)
- Per-hook `hook.<name>.parallel` markers (patch 4)
- Command-line `-j/--jobs` option for `git hook run` (patch 6)
- Per-event `hook.<event>.jobs` overrides (patch 7)
- Output stream handling via `extensions.hookStdoutToStderr` (patches 8-9)

Key technical additions include:
- New unsigned integer config infrastructure (patch 2)
- Runtime control of stdout-to-stderr merging (patch 9)
- Comprehensive tests covering repository operations
- Backward compatibility with existing hooks

The v3 iteration is a minor rebase that drops one commit now in the base series and simplifies some code. The series depends on Adrian's unmerged configurable hooks work and appears ready for review, with successful CI runs and acknowledgments to several key contributors (Emily, Ævar, Junio, Patrick, Phillip, Brian, Peff). 

This represents a significant expansion of Git's hook capabilities, enabling performance improvements through parallel execution while maintaining safety via multiple opt-in requirements. The design accommodates existing tools like git-lfs while providing flexibility for future needs.
