This is the final patch in Adrian Ratiu's series improving Git's hook configuration support, specifically addressing how disabled hooks are displayed in `git hook list`.

The patch modifies the behavior to show disabled hooks in the output of `git hook list` rather than filtering them out entirely. Disabled hooks are now annotated with "(disabled)" in the output, and when using `--show-scope`, they include their configuration scope (e.g., "local, disabled"). The implementation includes:

1. A new `disabled` flag in the hook configuration cache and struct hook
2. Modified output formatting in `builtin/hook.c` to display disabled status
3. Changed behavior to warn rather than error for disabled hooks without commands
4. Updates to `hook_exists()` to properly account for disabled hooks
5. Comprehensive test coverage of the new behavior

The change makes disabled hooks visible while clearly marking their status, which helps users understand their hook configuration at a glance. The patch builds on Adrian's previous work in this series that's already in the 'next' branch, with suggestions from Patrick Steinhardt incorporated. The implementation appears thorough, with careful attention to backward compatibility and clear documentation of behavior changes.
