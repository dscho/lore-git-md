This is a refactoring patch in Adrian Ratiu's ongoing hook configuration series. It restructures the hook configuration cache in `struct repository` to use a named `struct hook_config_cache` rather than a raw `strmap`, and replaces the simple `char *command` util pointer with a proper `struct hook_config_cache_entry`. 

The change is purely internal - no behavior is modified. The refactoring prepares for future additions by providing a proper type to hold additional hook configuration metadata that will be added in subsequent patches. The patch touches hook.c, hook.h and repository.h, updating all related code to use the new structure while maintaining the same functionality.

This continues Adrian's work to improve Git's hook configuration system, building on his previous patches that are already in the 'next' branch. The changes are mechanical but well-contained, with clear commit message explaining the motivation. The patch follows Git's coding style and includes updates to all affected areas of the code.
