This is a CI/build system patch in a series addressing macOS 15 compatibility issues, specifically around iconv behavior. Justin Tobler provides a review of Patrick Steinhardt's second patch, which extends an iconv workaround from the Makefile build to Meson.

The patch adds detection for a macOS 15 iconv bug that mishandles encoding state across multiple conversion calls, particularly with ISO-2022-JP text. Justin confirms the technical approach looks sound but suggests some documentation improvements to make the test's purpose clearer to future readers. He notes the test could be more precise in checking for the specific failure mode (return code 4) rather than any non-zero return.

The review is constructive and technical, focusing on maintainability rather than correctness concerns. Justin's suggestions are minor - adding explanatory breadcrumbs and tightening the error checking - indicating the core solution is well-designed. This continues the thread's pattern of careful platform compatibility work, now ensuring Meson builds get the same macOS 15 fixes previously implemented for Makefile builds.
