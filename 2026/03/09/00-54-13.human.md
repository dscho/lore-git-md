This is a test patch in Adrian Ratiu's ongoing hook configuration series, which is already partially in the 'next' branch. The patch adds test coverage for hook execution ordering, verifying that configured hooks run before legacy hookdir hooks as documented.

The test confirms two behaviors:
1. `git hook list` shows configured hooks ("first", "second") appearing before the hookdir hook
2. `git hook run` executes them in that same order

The patch also includes a minor cleanup removing a duplicate `git hook list -h` test case that was noticed during development. The test follows the series' pattern of thorough coverage for hook-related behaviors.

This continues Adrian's work to modernize Git's hook subsystem with config-based hooks while maintaining backward compatibility. The test helps ensure the documented execution order is preserved as the implementation evolves. The patch is well-contained and follows the project's testing conventions.
