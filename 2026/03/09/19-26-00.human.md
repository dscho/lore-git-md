This is a follow-up discussion in an ongoing refactoring thread about reducing unnecessary strbuf usage. Jeff King (Peff) responds to Deveshi Dwivedi's patch that converted a worktree function from taking a strbuf by value to taking a const char*.

Peff approves the patch ("Nice catch") and suggests it might be worth creating a Coccinelle semantic patch to detect similar cases where strbufs are incorrectly passed by value. He provides a rough sketch of what such a rule might look like, though notes it would only flag the issue rather than automatically fix it. He also mentions potential limitations in Coccinelle's Python integration might make this approach tricky.

The email doesn't raise any concerns about the original patch, which has already been approved by Junio Hamano. Peff's suggestion is framed as a possible future enhancement rather than a required change. The discussion remains technical and constructive, focused on improving static analysis to catch similar patterns elsewhere in the codebase.
