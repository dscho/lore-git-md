This is a refactoring patch from Adrian Ratiu's hook configuration series, moving a utility function from the hook subsystem to the more general string-list module.

The patch relocates `unsorted_string_list_remove()` from hook.c to string-list.[ch], where it logically belongs as a string-list utility. The function provides a convenience wrapper around `unsorted_string_list_lookup()` and `unsorted_string_list_delete_item()`, allowing callers to remove an item by string value rather than by index. The implementation remains functionally identical but gains proper documentation in the string-list.h header.

This change was suggested by Patrick Steinhardt and appears to be preparatory work for the rest of the series, which focuses on hook configuration improvements. The patch is straightforward and low-risk, touching only utility code that isn't specific to hooks. The addition of documentation makes the string-list API more complete and self-documenting.
