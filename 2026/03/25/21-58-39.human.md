This is the final patch in Ezekiel Newren's refactoring series for xdiff diff algorithm internals, focusing on type clarity in the record cleanup logic. The series has narrowed significantly from its original scope to concentrate on non-controversial readability improvements.

The patch converts several `long` parameters and variables to more precise types (`ptrdiff_t` for array indices, `size_t` for sizes/lengths) in `xdl_clean_mmatch()` and `xdl_cleanup_records()`. These changes make the code's intent clearer while maintaining identical behavior. Maintainer Junio Hamano notes the improvement in moving away from platform-native `long` to more semantically meaningful types.

The series appears ready for merging - it addresses a focused technical improvement without broader architectural changes, and has avoided the controversial elements from earlier iterations. The changes are well-contained to xdiff's internal diff calculation logic, making the state transitions in the algorithm more explicit through better type usage.
