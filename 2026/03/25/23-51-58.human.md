This is the final patch in Taylor Blau's series addressing geometric repacking issues with MIDX bitmap generation. The patch focuses on handling packs that aren't closed under reachability during geometric repacks.

The key change modifies how packs above the geometric split point are marked when excluded from the MIDX. Previously these were marked as excluded-closed ('^'), which could cause reachability issues. The patch now marks non-MIDX packs above the split as excluded-open ('!') when `repack.midxMustContainCruft` is false, ensuring pack-objects will traverse through them to maintain object closure.

The change fixes a test case that previously failed, demonstrating it correctly handles once-cruft objects that become reachable through new references. Taylor provides detailed reasoning about edge cases, noting that while extremely rare pre-existing MIDXs might still have issues, the solution covers the common case well.
