This is a build system fix for the `--graph-lane-limit` patch series. SZEDER Gábor points out that the first patch in the series introduces a `graph_needs_truncation()` helper function but doesn't use it, causing a build failure when `DEVELOPER=1` is set (which treats warnings as errors). The function is meant to be used in the second patch implementing the actual graph truncation behavior, but was prematurely added in the infrastructure patch.

The issue is straightforward - the function declaration should move to the second patch where it's actually needed. This is a common split-across-patches issue where infrastructure is set up before being used. The fix would involve moving this function to patch 2/3 where the lane truncation logic is implemented.

The rest of the patch's changes - adding the `graph_max_lanes` field to `struct rev_info`, the option parsing in `revision.c`, and the validation requiring `--graph` - remain correct and properly scoped for this infrastructure patch. This is a minor mechanical adjustment needed to make the series build cleanly.
