This is a test patch in Taylor Blau's series addressing geometric repacking issues with MIDX bitmaps. The patch adds a test case demonstrating a failure scenario where once-cruft objects (previously unreachable objects that become reachable again) above the geometric split point prevent proper bitmap generation.

The test creates a commit that becomes unreachable (via reset and reflog expiration), packs it as cruft, then makes it reachable again through a new reference. When attempting a geometric repack with bitmap generation, this currently fails because the object closure isn't properly maintained - the test is marked as expected to fail, with the fix coming in the next patch.

Key technical details:
- Tests `repack.midxMustContainCruft=false` configuration
- Demonstrates the interaction between cruft packs, geometric repacking, and bitmap generation
- Uses standard test helpers like `test_commit` and `git rev-parse`
- The failure occurs when trying to write a bitmap index after geometric repacking

This is the third of five patches in the series, following the memory leak fix and strmap refactoring, and preceding the core implementation of excluded-open pack support. The test serves both to document the edge case and verify the upcoming fix.
