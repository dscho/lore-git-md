This is the final patch in Ezekiel Newren's refactoring series for xdiff's record cleanup logic. The patch focuses on type clarity, changing several `long` parameters and variables to more specific types that better match their actual usage in the diff algorithm.

- Converting `xdl_clean_mmatch()` parameters from `long` to `ptrdiff_t` for array indexing
- Changing local variables `i` and `nm` to use `ptrdiff_t` and `size_t` respectively
- Adding explicit casts when assigning `rcrec->len1`/`len2` to `nm` variables
- Maintaining the same logic flow while using more precise types

The patch continues the series' theme of improving code clarity without changing behavior. The type adjustments make the intended usage of variables more explicit - `ptrdiff_t` for array indices and `size_t` for sizes/lengths. The explicit casts when working with the `rcrec` lengths help document the expected type conversions.
