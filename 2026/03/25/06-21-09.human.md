This is part 6 of Junio Hamano's 11-patch series to make the Git test suite more robust by enabling "set -e" (exit immediately on errors) during test execution. The current patch focuses on fixing the git-svn test helper script to work with this stricter mode.

The patch modifies two instances in `t/lib-git-svn.sh` where the script checks command exit codes in a way that would break under "set -e". Both cases follow the same pattern: they run a command (first checking if `svn` exists, then testing SVN Perl bindings), then check the exit status afterward. The changes rewrite these to explicitly capture the exit status in a variable first, which is the recommended pattern for "set -e" compatibility.

This is a straightforward mechanical change that maintains the exact same behavior while making the code work with the upcoming stricter test framework. As with other patches in the series, it's a quality improvement that will help catch errors earlier in the test suite. The patch is small (7 lines changed) and since it comes from the maintainer with no outstanding review comments, it's likely to be merged as-is.
