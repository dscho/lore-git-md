This is a refactoring patch from Adrian Ratiu that moves a utility function from the hook subsystem to the more general string-list module. The patch is part of his larger series modernizing Git's hook configuration system, now merged to 'next'.

The change relocates `unsorted_string_list_remove()` from hook.c to string-list.[ch], making it available as a general-purpose utility. The function now includes a `free_util` parameter to match the behavior of similar string-list functions, allowing callers to optionally free the `util` pointer when removing items. All existing call sites in hook.c are updated to pass 0 value for backward compatibility.

The patch includes documentation in string-list.h and maintains the same functionality while improving code organization. This is a straightforward cleanup that follows Git's pattern of moving widely useful functions to more appropriate shared locations. The change has already been reviewed and incorporated into the larger series that's now in 'next', indicating it's a non-controversial improvement.
