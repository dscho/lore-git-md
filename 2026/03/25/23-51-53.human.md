This is the third patch in Taylor Blau's 5-part series addressing pack-objects issues during geometric repacking. The patch adds a test case demonstrating a failure scenario where geometric repacking with MIDX bitmap generation fails due to once-cruft objects (previously unreachable objects that become reachable again) existing above the geometric split point.

The test creates a commit that becomes unreachable (via reset and reflog expiration), packs it as cruft, then makes it reachable again through a new reference. When attempting a geometric repack with bitmap generation, this currently fails because the pack containing the once-cruft object isn't properly handled in the reachability closure. The test is marked as `test_expect_failure` since the fix comes in the next patch.

This test case directly supports the series' goal of fixing MIDX bitmap generation during geometric repacks when packs aren't closed under reachability. As a PLC member and packfile expert, Taylor's test follows Git's standard test patterns while clearly demonstrating the edge case the series aims to fix. The test will be updated to expect success once the subsequent patches implement the "excluded-open" pack state solution.
