Patrick's version simplifies the logic by removing the need to check exit codes while maintaining the same arithmetic operations. The change also includes some formatting improvements - splitting the test_expect_success onto multiple lines and using single quotes consistently.

This is a constructive suggestion that aligns with the series' goal while potentially offering cleaner code. The proposal doesn't change the test's behavior or assertions, just the implementation details of how the arithmetic is performed.
