Feature implementation for `git add -p` adding a 'discard hunk' action, with review feedback from Johannes Schindelin.

Johannes Schindelin provides feedback on Luiz Campos's implementation of the 'x' (discard) action for `git add -p`. The patch allows users to directly discard unwanted changes from the working tree during interactive staging by reverse-applying hunks. Schindelin's review focuses on two specific implementation details while generally approving the approach.

First, he notes that the refactored `reassemble_patch()` code in `add-patch.c` is harder to read due to the conversion from an `if-else` to a `continue`-based flow, though he confirms the logic is correct after careful examination. Second, he suggests optimizing the discard application by detecting empty patches early in `apply_discard_hunks()`, which would eliminate the need for a subsequent loop checking for discard operations in `apply_patch()`.

The review maintains the thread's technical focus on the implementation quality rather than reopening the design discussion about whether `git add` should modify the working tree. Schindelin's comments indicate the patch is nearing readiness, with only minor refinements needed to the existing approach. This positions the patch well for potential inclusion, assuming the suggested improvements are addressed in a follow-up revision.
