This is a follow-up to the ongoing discussion about improving Git's internationalization (i18n) support for pluralized messages. Kaartic Sivaraam reports that the suggestion from Phillip Wood and Junio C Hamano - to systematically fix improper pluralization using ngettext() - has now been officially added to Git's microprojects list for programs like Google Summer of Code and Outreachy.

The microproject, titled "Fix improper pluralization to use ngettext", is documented at git.github.io/SoC-2026-Microprojects. This formalizes the earlier technical discussion into a concrete contribution opportunity, making it easier for new contributors to find and work on these issues. The change involves converting messages with numeric placeholders from simple _() translations to proper plural-aware Q_()/ngettext() calls across the codebase.

This represents a natural progression from the original thread, where Junio had identified several affected files (add-patch.c, archive-zip.c, checkout.c etc.) containing messages needing pluralization support. The microproject provides a clear, bounded scope of work that addresses a real i18n limitation while being accessible to newcomers - exactly the kind of contribution opportunity these programs aim to provide.
