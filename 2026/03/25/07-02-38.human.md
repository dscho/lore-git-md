This is a build system fix for the `--graph-lane-limit` patch series. SZEDER Gábor points out that the first patch in the series introduces a helper function `graph_needs_truncation()` but doesn't actually call it, causing a build failure when `DEVELOPER=1` is set (which treats warnings as errors). 

The issue is purely mechanical - the function is correctly implemented but unused in this initial infrastructure patch. The actual usage comes in patch 2/3 of the series, which implements the graph truncation behavior. This is a common pattern in patch series where infrastructure is set up before being used, but in this case it triggers the unused function warning.

The fix would be to either move the function to patch 2/3 where it's first used, or add a dummy call in patch 1/3 to silence the warning. This is a minor technical issue that doesn't affect the functionality or design of the feature, just the build process with developer warnings enabled. The series otherwise appears ready with all prior review feedback addressed.
