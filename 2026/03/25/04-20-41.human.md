This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the state of various topics in the Git development pipeline. The report covers patches that have graduated to 'master', new topics being proposed, ongoing work in the 'cooking' stage, and discarded topics.

Several notable patches have recently graduated to 'master', including:
- A Coccinelle rule to detect passing strbuf by value (dd/cocci-do-not-pass-strbuf-by-value)
- Leak fixes in transport color config (jk/transport-color-leakfix)
- Fast-import improvements for handling signed commits (jt/fast-import-sign-again)
- A new "split" subcommand for git history (ps/history-split)
- Performance improvements for upload-pack (ps/upload-pack-buffer-more-writes)

New topics proposed include:
- More configurable signed tag/commit handling in fast-import (jt/fast-import-signed-modes)
- Graph output limiting for repositories with many branches (ps/graph-lane-limit)
- Promisor remote auto-configuration based on URL whitelist (cc/promisor-auto-config-url)

Ongoing work in the 'cooking' stage includes:
- Continued efforts to remove the_repository usage (ps/fsck-wo-the-repository, pw/worktree-reduce-the-repository)
- Improvements to git backfill command (ds/backfill-revs)
- Parallel hook execution support (ar/parallel-hooks)
- Linux implementation of fsmonitor daemon (pt/fsmonitor-linux)
- Various test cleanups and modernization efforts

The report also notes several discarded topics that have been superseded by newer approaches. As always, Junio provides detailed status for each topic including whether it's ready for merging, needs review, or is waiting for follow-up work. This comprehensive update helps keep the community informed about the state of Git development.
