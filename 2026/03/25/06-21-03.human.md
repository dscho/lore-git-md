This is a test infrastructure patch series from maintainer Junio C Hamano that aims to catch misspelled test assertions like `test_expect_successo` by making the test framework more strict about command failures. The series enables `set -e` (exit on error) early in the test framework and fixes several tests that previously relied on ignoring command failures.

The motivation comes from a real case where a typo in `test_expect_success` went unnoticed because the test framework silently continued after the unrecognized command. The 11 patches systematically fix affected tests across various parts of the suite, including git-svn, git-cvs, and completion tests. Each patch handles a different test script, making them "set -e clean" by properly handling expected failures.

As this comes from the maintainer and touches foundational test infrastructure, it's likely to be merged after any review feedback. The changes appear focused and mechanical - each patch fixes one test script's interaction with the new strict mode. The series has already been tested against the integration branches and passes the full test suite when merged to 'seen'.
