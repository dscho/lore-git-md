This is a test fix addressing a Windows-specific issue in the test suite. Jeff King responds to Junio Hamano's "What's cooking" report about a test failure in t0061.24 related to child process handling in transport code.

The patch simplifies a test case that was originally designed to verify Git can handle .bat files with spaces in their names when used as GIT_SSH. The test was failing when combined with another in-progress patch that improves child process cleanup. Jeff explains the test's fragility stems from how the fake .bat file interacts with Git's process handling - specifically that the .bat file's command echoing was causing protocol violations that led to killing the process before it could complete its test marker.

Rather than fixing the .bat file behavior, Jeff proposes replacing the GIT_SSH test scenario with a simpler test-tool run-command invocation that still exercises the core functionality (handling arguments with spaces) without the complications of the ssh protocol simulation. He notes this maintains test coverage while being more robust, though acknowledges the original test might be more realistic.

The change is minimal - just 12 lines modified in t/t0061-run-command.sh - but demonstrates careful consideration of both the immediate test failure and the broader implications for process handling changes. Jeff's analysis suggests this is likely safe to proceed with, though he leaves open the possibility of alternative fixes if maintaining the GIT_SSH scenario is preferred.
