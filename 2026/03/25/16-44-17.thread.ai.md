Three competing approaches emerged: Patrick Steinhardt's `repo`-only proposal, Tian Yuchen's `repo && repo->gitdir` suggestion, and Burak's edge case showing neither fully handles invalid `GIT_DIR` scenarios. Patrick now questions whether to proceed with hybrid approach (keeping some `startup_info` checks) or delay conversion until architectural issue can be properly fixed.

Jeff King's 2019 comment on `startup_info->have_repository` provides historical context. Current tests don't cover invalid `GIT_DIR` edge case.
