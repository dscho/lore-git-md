Three competing approaches for validity checks remain under discussion: Patrick Steinhardt's `repo`-only proposal, Tian Yuchen's `repo && repo->gitdir` suggestion, and Burak's demonstrated edge case showing neither fully handles invalid `GIT_DIR` scenarios. Current tests don't cover this edge case. Jeff King's 2019 comment on `startup_info->have_repository` provides historical context.
