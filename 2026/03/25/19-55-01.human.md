This is a feature patch from Adrian Ratiu that adds config scope visibility to `git hook list`. It's part of his larger series modernizing Git's hook configuration system, now merged to 'next'.

The patch introduces a `--show-scope` flag to `git hook list` that displays where each hook was configured (system/global/local), mirroring the output style of `git config --show-scope`. Traditional hooks from the hookdir remain unaffected since they don't come from config. The scope appears as a tab-separated prefix, making it machine-parseable while maintaining backward compatibility when the flag isn't used.

Implementation-wise, the patch:
1. Stores the config scope during the config callback
2. Carries it through the cache to hook structs
3. Adds the display logic in the list command
4. Includes tests verifying both the new output format and backward compatibility

The changes are well-contained, touching mainly `hook.c`, `builtin/hook.c`, and the test suite. The patch follows Git's conventions for config scope handling and maintains the series' focus on robustness. It addresses Junio Hamano's suggestion from earlier in the thread and fits cleanly into the larger hook modernization effort.
