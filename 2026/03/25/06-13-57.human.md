This is a test fix addressing a Windows-specific issue in the `t0061-run-command.sh` test. Jeff King proposes simplifying the test that verifies Git can spawn .bat files with spaces in their paths, which currently fails when combined with an in-progress patch about child process cleanup.

The test previously used a fake SSH helper scenario that was overly complex and fragile - it relied on the .bat file being killed at just the right moment. Jeff's new version uses the `test-tool run-command` helper instead, which directly tests the core functionality (handling spaces in command arguments) without the SSH complications. He notes this achieves the same test coverage while being more reliable.

The change is small (10 lines removed, 2 added) and clearly motivated. Jeff acknowledges an alternative fix (adding `@echo off` to the .bat file) but prefers this approach for its simplicity. The patch looks like a straightforward improvement to test robustness, particularly relevant given the ongoing transport helper changes mentioned in Junio's "What's cooking" report.
