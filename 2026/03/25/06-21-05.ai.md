This is the second patch in Junio C Hamano's 11-part series to make the test suite more strict by enabling "set -e" (The first patch modified the test framework itself; this one starts the test script adjustments.)

The change fixes a specific issue in t0008-ignores.sh where a `grep -v` command was used purely for its output filtering, but its non-zero exit status (when no matches are found) would cause the script to exit under "set -e". The fix adds `|| :` to swallow the exit status while preserving the filtering behavior.

This is a straightforward mechanical change that's typical of the series - small adjustments to make individual tests compatible with the stricter error handling. The patch doesn't introduce new functionality but helps ensure the test suite will work correctly when the framework-level "set -e" change lands. As with the rest of the series, the motivation is to catch typos and silent failures earlier in test execution.
