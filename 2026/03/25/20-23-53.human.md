This is a refactoring patch that extracts revert message formatting logic from `sequencer.c` into a reusable function, as part of the `git replay --revert` feature series. The patch moves the complex message generation for reverts (handling "Revert" vs "Reapply" prefixes and commit references) from `do_pick_commit()` into a new `sequencer_format_revert_message()` function in `sequencer.h`.

The change makes this logic available to the new `git replay --revert` functionality while maintaining all existing behavior for merge commits and repeated reverts. The implementation follows Phillip Wood's suggestion to consolidate the message generation code, and has been refined through six iterations of review. The patch is well-contained, touching only the sequencer files, and includes comprehensive documentation for the new public function.

This is the first of two patches in the final v6 series adding `--revert` support to `git replay`. The refactoring is a clean separation of concerns that will be used by the second patch which implements the actual replay functionality. The series as a whole has received thorough review from core contributors and appears ready for merging.
