This is a refactoring patch in Taylor Blau's series addressing pack-objects issues during geometric repacking. The patch converts the pack handling in `read_packs_list_from_stdin()` from using two separate string_lists (for included and excluded packs) to a single strmap that can track multiple pack "kinds" more flexibly.

The key changes are:
1. Introduces a new `stdin_pack_info` struct to track both the pack pointer and its kind (included/excluded)
2. Moves pack sorting and object entry addition into a new helper function
3. Uses strmap instead of string_list to avoid quadratic behavior when handling duplicate pack entries

The refactoring prepares for future work that will add a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs. The patch maintains all existing functionality while making the code more extensible.

Taylor has incorporated feedback from Patrick Steinhardt on the strmap usage, and the changes appear clean and well-motivated. This is a solid infrastructure improvement that enables the more substantive fixes coming later in the series.
