1. Changing the daemon process wait pattern to explicitly capture the exit status rather than letting it fail
2. Making the final cleanup kill command non-fatal with `|| :` since the process may already be gone

This follows the same conservative pattern seen in earlier patches of the series - carefully preserving existing behavior while making the code resilient to "set -e".
