This is a test infrastructure patch series from Junio C Hamano, the Git maintainer, aimed at improving error detection in the test suite. The series makes the test framework more strict by enabling "set -e" (exit immediately on error) early in the test execution, which will help catch typos like "test_expect_successo" that currently fail silently.

The motivation comes from a real case where a misspelled test directive went unnoticed because the shell continued executing despite the error. The series first modifies the test framework to enable "set -e" and fix one framework-level issue, then provides individual patches for 10 test scripts that needed adjustments to work with this stricter mode. The changes are mostly minor tweaks to command sequences that previously relied on continuing after errors.

The series touches a variety of test areas including CVS/SVN integration, completion testing, and general Git functionality tests. Junio notes that while the core test suite passes with these changes, some external tool integrations (cvs/svn/p4) may still have issues after "test_done" for users with those tools installed. This appears to be a straightforward quality improvement that will make the test suite more robust against typos and silent failures.
