This is a refactoring patch that moves remote group resolution code from fetch.c to remote.c as part of the ongoing effort to add remote group support to `git push`. The patch relocates three key components that handle remote group configuration parsing: the `remote_group_data` struct, `get_remote_group()` config callback, and `add_remote_or_group()` helper function.

The changes are purely mechanical - the code is moved verbatim from builtin/fetch.c to remote.c with no functional modifications. The patch adds the necessary declarations to remote.h to expose these utilities to other parts of the codebase. This prepares for the subsequent patch that will use this shared infrastructure to implement group pushing functionality.

The relocation follows Junio Hamano's suggestion to make this generic remote group handling available more broadly. The author has removed the `UNUSED` macro from the headers as requested in previous review feedback. The patch is well-contained, touching only the three files needed for the code movement and maintaining all existing behavior.

This foundational change enables the actual push-to-group feature while keeping the remote group resolution logic DRY (Don't Repeat Yourself) between fetch and push implementations. The clean separation of concerns here reflects good architectural thinking - the remote group handling is properly abstracted rather than being tied to any specific command.
