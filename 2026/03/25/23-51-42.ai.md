This is a v2 patch series from Taylor Blau addressing pack-objects issues during geometric repacking when MIDX bitmap generation fails due to packs not being closed under reachability. The series introduces a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs.

The key changes in this revision are:
1. Clarified that patch 1 prevents a potential leak rather than fixing an actual one
2. Incorporated Patrick Steinhardt's feedback on patch 2's strmap refactoring
3. Removed an unnecessary NULL check in patch 4 after ensuring the pack pointer will always be valid

The series maintains its original structure:
- Patch 1 fixes a memory leak potential in `read_stdin_packs()`
- Patch 2 refactors pack handling to use strmap
- Patch 3 adds a test demonstrating the failure case
- Patch 4 implements the core fix with excluded-open pack support
- Patch 5 updates repack to use the new functionality

The changes appear well-considered, with Taylor addressing all review feedback from the previous round. The NULL pointer handling in patch 4 was particularly scrutinized, with Taylor concluding a BUG() assertion is the correct approach rather than preserving the check. The series now seems ready for final review, solving a subtle but important edge case in Git's pack handling during geometric repacks.
