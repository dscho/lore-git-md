This is a refactoring patch in Ezekiel Newren's xdiff cleanup series, specifically targeting the `xdl_cleanup_records()` function in `xdiff/xprepare.c`. The patch converts nested ternary operation into a more readable if/else ladder for setting `action1` and `action2` values, while maintaining identical behavior.

The change replaces compact but potentially confusing ternary expressions with explicit conditional logic that clearly shows the three possible states (DISCARD, KEEP, INVESTIGATE) for each record. The patch adds comments to document the final else case (nm >= mlim) that was implicit in the original ternary. This follows the series' theme of improving code clarity in the xdiff subsystem without changing functionality.

As the third patch in a 5-part series, it continues the focused approach established in v2 - addressing specific readability pain points while avoiding the broader structural changes that generated discussion in v1. The changes are mechanical and localized to this one function, making it a straightforward improvement that's unlikely to be controversial.
