This is the final patch in a refactoring series focused on improving type clarity in Git's xdiff subsystem. The patch comes from Ezekiel Newren, who has been working on making the diff algorithm's internal types more precise and unambiguous.

The change switches several variables in `xdl_cleanup_records()` and `xdl_clean_mmatch()` from using `long` to more specific types like `ptrdiff_t` and `size_t`. This better reflects their actual usage in the code - `ptrdiff_t` for array indices and `size_t` for counts/lengths. The patch also adds an explicit cast when assigning from `rcrec->len1/len2` to `nm` to make the type conversion clear.

This follows the pattern established in earlier patches of the series, continuing the focus on code clarity through better type usage. Like the rest of the series, it's a pure refactoring with no behavior changes. The changes are small but meaningful for maintainability, making the code's intent more obvious to future readers.
