This is a bugfix patch in Adrian Ratiu's hook configuration series, specifically addressing an initialization issue in the receive-pack hook handling code. 

The change fixes a case where a strbuf in the `receive_hook_feed_state` struct wasn't properly initialized, though in practice this wasn't causing problems since child states are always initialized when used. Patrick Steinhardt identified this as something that should be fixed for correctness, even though it wasn't actively causing issues.

The patch is straightforward - it adds a single line to initialize the strbuf in the template state. This is part of Adrian's larger effort to modernize Git's hook system, but this particular change stands alone as a simple improvement to code hygiene. The fix is already merged into the 'next' branch along with the rest of the series.
