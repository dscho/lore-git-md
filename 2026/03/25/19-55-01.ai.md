This is a feature patch from Adrian Ratiu that adds config scope visibility to `git hook list` output, part of his ongoing series to modernize Git's hook configuration system. The patch introduces a `--show-scope` flag that displays where each hook was configured (system/global/local), mirroring the behavior of `git config --show-scope`.

The implementation stores the config scope during the config callback and carries it through to the hook structs. The scope appears as a tab-separated prefix in the output, maintaining machine-parseability. Traditional hooks from the hookdir remain unaffected since they don't come from config. The patch includes thorough documentation updates and test coverage verifying both the new scope display and backward compatibility with the existing output format.

This change builds on Adrian's previous work to make hooks more configurable through Git's configuration system. The implementation appears solid, with careful attention to memory management and backward compatibility. The patch has already been through review cycles with feedback from Junio Hamano incorporated, and it's now part of the series merged to 'next'. The scope display provides useful debugging information for users managing hooks across multiple configuration levels.
