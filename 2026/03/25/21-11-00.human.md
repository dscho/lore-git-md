Refactoring patch series targeting Git's xdiff (diff engine) subsystem, now in its second iteration. This is part 3 of Ezekiel Newren's xdiff cleanup effort, following up on previous discussions about restructuring xdiff internals.

The v2 series is a significant departure from v1, focusing narrowly on improving the readability of `xdl_cleanup_records()` rather than the broader structural changes originally proposed. The 5 patches in this version:

1. Remove a local `recs` pointer variable and simplify array indexing
2. Make per-file limits more explicit with separate variables
3. Clarify the logic for setting action flags
4. Simplify INVESTIGATE case handling
5. Use more specific types for clarity

The changes are purely internal - no performance impact or behavioral changes are introduced. The series appears well-focused on its stated goal of making the code easier to follow, with each patch tackling a specific readability issue in the cleanup records function.

This continues Newren's ongoing work on xdiff internals, though the scope has narrowed considerably from the original vision that included Rust interoperability considerations. The maintainer (Junio Hamano) is aware of and tracking this revised approach.
