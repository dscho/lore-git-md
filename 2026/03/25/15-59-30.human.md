This is a documentation patch in Toon Claes' ongoing series to improve the `git replay` plumbing command. The patch standardizes the command's documentation and help text to consistently use the "stuck form" (`--option=value`) syntax as recommended in gitcli(7).

The changes update both the man page (`Documentation/git-replay.adoc`) and the in-code usage message to:
1. Consistently use `--option=value` format instead of `--option value`
2. Reorder the options in the documentation to match their order in the help text
3. Fix a minor grammatical error in the process

This is a straightforward cleanup that follows established Git conventions. The changes are mechanical and uncontroversial, having already incorporated feedback from Kristoffer Haugsbakk in previous iterations. The patch maintains all existing functionality while improving consistency with Git's documentation standards.

This is part of a larger effort to refine the experimental `git replay` command, building on Siddharth Asthana's earlier work. The series is progressing well, with documentation aspects now settled while implementation details for the new `--ref` option continue to be worked out in parallel patches.
