This is a refactoring patch that moves remote group resolution code from `builtin/fetch.c` to `remote.c` as part of a series adding remote group support to `git push`. The change extracts three components that handle parsing `remotes.<name>` config entries and resolving remote groups: `get_remote_group()`, `add_remote_or_group()`, and the `remote_group_data` struct.

The patch is purely mechanical - it moves the code verbatim from fetch.c to remote.c while adding the necessary declarations to remote.h. This enables reuse by other commands (specifically `git push` in the next patch) without duplication. The change was suggested by Junio Hamano and the author has followed the maintainer's guidance on naming and scoping.

This is the first of two patches in v3 of the series (down from three in previous versions). The code movement here lays the foundation for the actual push-to-group functionality that follows. The patch appears straightforward and well-contained, with no functional changes - just relocation of existing code to a more shared location.
