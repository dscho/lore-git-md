This is a 12-patch series from Adrian Ratiu that refines Git's hook configuration support, building on his previous work that's already in the 'next' branch. The series focuses on cleanups and three small but useful user-facing features for `git hook list`:

1. **Config scope display** (`--show-scope`): Shows where each hook's configuration comes from (system, global, local), matching the behavior of `git config --show-scope`.

2. **Disabled hook visibility**: Now shows disabled hooks in the listing (marked with "disabled" or "disabled\t" when combined with scope display).

3. **Hook name validation**: By default rejects unknown hook names, with `--allow-unknown-hook-name` as an escape hatch.

The series also includes several internal improvements:
- Memory management cleanup using string-list APIs
- Style fixes (header sorting, boolean type modernization)
- Documentation standardization
- Test coverage expansion
- Initialization bug fixes
- Infrastructure for future hook metadata storage

This appears to be the final iteration of Adrian's multi-series effort to modernize Git's hook subsystem. The changes are well-scoped and address all feedback from previous rounds, with Patrick Steinhardt and Junio Hamano having reviewed the earlier versions. The patches touch several files but focus on the hook subsystem, with careful attention to backward compatibility and consistent behavior.

The work demonstrates Git's ongoing effort to make hooks more configurable and manageable through Git's configuration system rather than just filesystem paths. The changes are incremental improvements building on established work rather than introducing major new concepts.
