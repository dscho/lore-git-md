This is the first patch in Junio C Hamano's test infrastructure series to make the test suite more strict by enabling "set -e" (exit on error) early in test execution. The patch fixes a framework-level issue where the initial Git binary check would fail under "set -e" due to its non-zero exit status.

The change modifies `t/test-lib.sh` to use a status-capture pattern (`status=0 && cmd || status=$?`) for the Git binary check, which verifies the built Git exits with status 1 (as expected for a bare "git" command). This is the first of several framework adjustments needed to safely enable "set -e" without breaking existing test behavior.

The patch demonstrates the series' core approach - identifying and fixing patterns that previously relied on continuing after errors. While this particular change is mechanical, it's foundational for the stricter error checking the series aims to introduce.
