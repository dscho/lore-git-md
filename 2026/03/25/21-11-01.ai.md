This is the first patch in a refactoring series targeting Git's xdiff subsystem, specifically focusing on improving code clarity in `xdl_cleanup_records()`. The patch comes from Ezekiel Newren, who is known for his work on Git's merge machinery and Rustification efforts.

The change removes a local `recs` pointer variable that was being used to iterate through records in the xdiff file structure, replacing it with direct array indexing of `xdf1->recs[i]` and `xdf2->recs[i]`. This makes the code slightly more straightforward by eliminating an intermediate variable that wasn't providing significant benefit. The patch also removes the unused `recs` pointer from the last two loops where it wasn't being referenced.

This is a pure refactoring with no behavior change - the diff algorithm's output remains identical. The change aligns with the series' goal of making the complex diff record cleanup logic more readable. The patch is small and focused, touching only `xdiff/xprepare.c` with straightforward modifications that should be easy to review.

The patch follows the series' narrowed scope from v1, avoiding the more controversial structural changes that had drawn feedback. It represents a safe, non-disruptive improvement to code maintainability in a critical diff algorithm component.
