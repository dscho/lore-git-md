This is a refactoring patch from Adrian Ratiu, part of his larger series modernizing Git's hook configuration system. The patch simplifies memory management of hook data by replacing a custom cleanup function with the standard `string_list_clear_func()` pattern.

The key change moves from `hook_list_clear()` to using `string_list_clear_func()` with a new `hook_free()` callback. This makes the API more consistent with Git's conventions while maintaining the same functionality. The patch also introduces a `data_free` field in the `struct hook` to track cleanup callbacks, eliminating the need for callers to pass them separately.

Technical details include:
- New `hook_free()` function that handles cleanup of individual hook entries
- Removal of `hook_list_clear()` in favor of standard string_list cleanup
- Addition of `data_free` pointer in `struct hook` to track per-hook cleanup
- Updates to all call sites to use the new pattern
- Documentation updates to reflect the changes
