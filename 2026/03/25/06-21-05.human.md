This is the second patch in Junio C Hamano's 11-part series to make the test suite stricter by enabling "set -e" (exit immediately on errors). The patch fixes a specific test script (t0008-ignores.sh) that would fail under the new stricter mode.

The issue is in a helper function that uses grep to filter test output - grep exits with a non-zero status when it finds no matches, which would cause the test to abort under "set -e". The fix adds "|| :" to swallow the grep exit status since the empty output case is actually valid here. This is a typical pattern when adapting code for "set -e" compatibility.

The change is small and focused - it maintains the existing test behavior while making it work with the upcoming stricter error checking. As part of a maintainer-driven series to improve test reliability, this patch follows the careful approach seen throughout the effort, addressing one specific issue per commit.
