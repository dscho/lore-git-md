This is a feature and refactoring patch series from Adrian Ratiu that builds on his ongoing work to modernize Git's hook configuration system. The 12-patch v3 iteration addresses all feedback from previous rounds and focuses on three small user-facing improvements to `git hook list` while cleaning up the underlying implementation.

The series adds:
1. `--show-scope` option to display where each hook's configuration comes from (system/global/local)
2. Visibility of disabled hooks in the listing
3. Validation against unknown hook names with `--allow-unknown-hook-name` escape hatch

Key technical changes include:
- Memory management improvements using `string_list_clear_func()`
- New `hook_config_cache_entry` struct for per-hook metadata
- Style fixes and boolean type modernization
- Proper initialization of `receive_hook_feed_state` strbuf
- Header sorting and documentation standardization
- Expanded test coverage including hook execution order verification

The changes touch multiple files but are well-scoped, with particular focus on `hook.c`, `builtin/hook.c`, and the test suite. The series has already been through significant review iteration, with Patrick Steinhardt, Junio Hamano, and Eric Sunshine providing feedback that's been incorporated into this version. The implementation appears solid, with careful attention to backward compatibility and clear commit messages explaining each change.

This represents the culmination of Adrian's multi-series effort to make hooks more configurable through Git's configuration system. The changes are now merged to 'next' with some post-merge refinements still in progress. The series demonstrates Git's typical pattern of incremental improvement - building on established infrastructure while maintaining compatibility and adding thoughtful escape hatches for edge cases.
