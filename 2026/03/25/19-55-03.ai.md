This is the final patch in Adrian Ratiu's series to modernize Git's hook configuration system, adding validation for unknown hook names. The patch introduces a safety check that rejects hook names not recognized by Git (like "prereceive" instead of "pre-receive"), with an escape hatch via `--allow-unknown-hook-name` for custom hooks.

The implementation derives the list of known hooks from `hook-list.h` (generated from `githooks.adoc`) and adds the validation to both `git hook run` and `git hook list` subcommands. The Makefile is updated to ensure the header dependency, while the meson build already handles it. The patch includes comprehensive test coverage for both the rejection of unknown hooks and the override flag.

This change builds on the series' earlier work while providing immediate user value by catching common typos.
