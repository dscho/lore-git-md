This is a documentation patch in Lorenzo Pegorari's GSoC series on improving promisor file handling during repacks. It adds comments explaining the debug information stored in `.promisor` files, which record ref names and hashes fetched when a packfile was downloaded.

The patch has received constructive feedback from Junio Hamano (Git's maintainer) about making the documentation more authoritative and stylistically consistent. Junio suggests explicitly referencing commit 5374a290 ("fetch-pack: write fetched refs to .promisor") as the original source of this debug information behavior. He also notes the comment formatting should align asterisks with a space after the leading tab, following Git's style guidelines.

Lorenzo acknowledges the feedback positively, indicating these changes will be incorporated. This is a straightforward documentation improvement that helps future developers understand the purpose of the debug information in `.promisor` files, which is useful for troubleshooting partial clone issues. The patch appears well-motivated and the author is responsive to maintainer feedback.
