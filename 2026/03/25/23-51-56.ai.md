The latter are used as traversal starting points but their objects aren't included in the output. The patch modifies `add_object_entry_from_pack()` to handle this new state and adds new `include_check` callbacks to properly limit the traversal at closed-excluded pack boundaries.

The implementation includes thorough documentation updates explaining the new '!' pack prefix behavior in `--stdin-packs=follow` mode, plus new test cases verifying both the happy path and edge cases like using '!' without follow mode. The changes maintain compatibility with existing geometric repack behavior while fixing the reachability edge case demonstrated in the previous test.
