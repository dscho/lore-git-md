This is a v2 patch series from Taylor Blau addressing pack-objects issues during geometric repacking, particularly when dealing with packs that aren't closed under reachability. The series introduces a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs but missing from the MIDX.

The key changes in this revision are:
1. Clarified that patch 1 prevents a potential leak rather than fixing an active one
2. Incorporated Patrick Steinhardt's feedback on patch 2's strmap refactoring
3. Removed an unnecessary NULL check in patch 4 after confirming the pack pointer will always be valid

The series remains focused on fixing a real-world issue GitHub encountered, where MIDX bitmap generation could fail after geometric repacks in certain edge cases. The solution is carefully constructed to maintain safety while adding the new pack state behavior. Jeff King identified and helped resolve a potential NULL pointer issue in patch 4, which Taylor has addressed by asserting the pack pointer must be valid rather than checking for NULL.

With these refinements, the series appears technically sound and ready for final review. The changes are well-motivated, thoroughly explained, and come with test demonstrating both the failure case and the fix. This should help prevent subtle corruption cases when generating bitmaps after geometric repacks.
