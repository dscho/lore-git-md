This is a refactoring patch that concludes a series improving type clarity in xdiff's record cleanup logic. Maintainer Junio Hamano provides a brief but positive review of the changes, noting that moving from platform-native `long` types to more specific types (`ptrdiff_t` for array indices, `size_t` for sizes) makes sense.

The patch itself makes several focused type adjustments in `xdiff/xprepare.c`:
- Changes `xdl_clean_mmatch()` parameters from `long` to `ptrdiff_t`
- Updates local variables to use `ptrdiff_t` for indices and `size_t` for sizes
- Adds explicit casts when working with `rcrec->len1`/`len2` fields
- Maintains the same logic flow while making type usage more precise

This represents the final patch in a series that has been significantly narrowed from its original scope to focus exclusively on readability improvements in `xdl_cleanup_records()`. The maintainer's positive response suggests this focused approach was well-received compared to the broader structural changes proposed in earlier versions. The changes are purely internal and don't affect behavior, but make the code's intent clearer through better type choices.
