This is a refactoring patch that extracts revert message formatting logic from `sequencer.c` into a reusable function, as part of the `git replay --revert` feature series. The patch moves the complex message generation code from `do_pick_commit()` into a new `sequencer_format_revert_message()` function in `sequencer.h`, making it available for reuse by the upcoming replay command.

The new function handles all aspects of revert message formatting: determining whether to use "Revert" or "Reapply" prefix based on the commit subject, generating the commit reference line ("This reverts commit..."), and properly handling merge commits. It also updates the helper function `refer_to_commit()` to take explicit parameters rather than relying on `the_repository` and `replay_opts`, making it more self-contained.

This is a well-structured change that follows the project's preference for small, focused patches. The extraction is clean and maintains all existing behavior while making the functionality available to other parts of the codebase. The patch has already gone through multiple rounds of review from Phillip Wood and others, with all substantive feedback addressed. This appears to be the final form of this particular piece of the larger `--revert` feature.
