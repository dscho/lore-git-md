This is part 6 of Junio Hamano's test infrastructure patch series to make the test suite more robust by enabling "set -e" (exit immediately on error) early in test execution. The series aims to catch mistakes like misspelled test directives that currently fail silently.

This specific patch modifies the git-svn test infrastructure to work with "set -e". It fixes two instances where the test script checks command exit codes in a way that would break under "set -e". The changes follow the pattern established earlier in the series: wrapping commands in `x=0; cmd ... || x=$?` to safely capture exit statuses without triggering "set -e" failures.

The first change updates the SVN availability check, while the second modifies a Perl script execution check. Both follow the same transformation pattern to maintain the same logic while being "set -e" safe. The patch is straightforward and focused - it doesn't introduce new functionality but adapts existing tests to work with the stricter error checking mode.

This continues the series' careful approach to making the test framework more robust while maintaining backward compatibility. The changes are mechanical but important for the overall goal of catching errors earlier in test execution.
