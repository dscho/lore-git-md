This is part 8 of Junio C Hamano's 11-patch series to make the Git test suite work with "set -e" enabled for better error detection. The patch modifies t9200-git-cvsexportcommit.sh to use the now-standard status-capture pattern (`status=0; cmd || status=$?`) for checking CVS availability, replacing the direct exit code check that would fail under "set -e".

The change is straightforward - it's one of many similar mechanical conversions needed to make tests work with the stricter error handling. This particular test checks for CVS availability before proceeding, and the modification preserves that behavior while making it compatible with the new "set -e" requirement. The patch follows the same conservative pattern seen in earlier parts of the series, carefully maintaining the original test semantics while adapting to the stricter execution environment.

As with other patches in the series, this is a low-risk change that helps move toward the goal of catching test framework typos and errors more reliably. The modification is limited to the test infrastructure and doesn't affect Git's core functionality.
