Maintainer approval for root commit replay support in `git replay`

Junio C Hamano, the Git maintainer, has approved Toon Claes's patch enabling `git replay` to handle root commits (initial commits with no parents). This version 2 of the patch incorporates all previous feedback, including better API boundaries and improved user messaging when replaying root commits.

The maintainer indicates the patch is ready to be queued for inclusion in the `next` integration branch, suggesting it will likely appear in a future Git release. While there may be trivial conflicts with an in-progress `--revert` functionality series from another contributor, Junio considers these easily resolvable.

This marks the successful conclusion of a focused effort to expand `git replay`'s capabilities, demonstrating the project's typical workflow where contributors iterate based on maintainer feedback until reaching a solution that meets the project's standards. The patch is clean, well-contained, and addresses a real limitation in the relatively new `git replay` command.
