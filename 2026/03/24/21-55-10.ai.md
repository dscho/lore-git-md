This is the first patch in a 4-part series extending `git fast-import`'s signature handling capabilities, specifically adding an `abort-if-invalid` mode for commit signatures. The patch introduces a new behavior where the import operation will fail entirely if it encounters an invalid commit signature, complementing the existing `strip-if-invalid` and `sign-if-invalid` modes.

Justin Tobler's changes touch several components: the fast-import implementation, GPG interface plumbing, and documentation. The patch adds the new `SIGN_ABORT_IF_INVALID` enum value and implements the abort behavior in `handle_signature_if_invalid()`. It also includes test coverage in `t9305-fast-import-signatures.sh` that verifies the new mode correctly aborts on invalid signatures while still allowing valid imports to proceed.

The implementation appears clean and focused, with appropriate error handling and documentation updates. The test cases follow the existing pattern in the test file, adding coverage for the new mode alongside the existing signature handling tests. This is a logical extension of the recent work to make fast-import's signature handling more flexible and robust.
