This is a refactoring patch that extracts revert message formatting logic from `sequencer.c` into a reusable function, part of the ongoing `git replay --revert` feature series. The patch moves the message generation code that handles "Revert" and "Reapply" prefixes and commit references into a new `sequencer_format_revert_message()` function in `sequencer.{c,h}`.

The key changes include:
- Extracting the revert message generation logic from `do_pick_commit()` into a standalone function
- Updating `refer_to_commit()` to take explicit `struct repository` and `bool` parameters instead of reading from `replay_opts`
- Adding comprehensive documentation for the new function in `sequencer.h`
- Maintaining all existing behavior while making the code more reusable

This is the first of two patches in v5 of the series, which has already undergone extensive review from Phillip Wood, Patrick Steinhardt, and Junio Hamano. The changes are well-contained and focused on code organization, with no functional changes to the revert message generation itself. The patch follows the project's established patterns and appears ready for merging.
