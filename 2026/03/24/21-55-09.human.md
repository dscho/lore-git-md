This is a feature patch series extending `git fast-import`'s handling of signed objects. Justin Tobler is bringing the `--signed-tags` option into parity with `--signed-commits` by adding three new modes that mirror recent additions to commit signature handling.

The series introduces consistent behavior for both commits and tags when signatures fail verification. The new modes are:
- `abort-if-invalid` - stops the entire operation if a signature is invalid
- `strip-if-invalid` - removes invalid signatures while continuing
- `sign-if-invalid` - replaces invalid signatures with new ones

The changes build on two recent commits (c20f112e51 and ee66c793f8) that added similar functionality just for commits. This series completes the picture by extending those options to tags as well. The implementation touches the fast-import internals, gpg-interface plumbing, and adds substantial test coverage in t9306.

The patches look focused and well-structured, with each commit cleanly implementing one of the new behaviors. The test additions are thorough, covering both the happy paths and error cases. This appears to be a straightforward extension of existing functionality that maintains consistency between how commits and tags are handled during import.
