This is a documentation and user interface patch for the `git repo` subcommands, part of an ongoing series to improve help text output. Mahi Kassa's v3 patch completes the work to make `git repo info -h` and `git repo structure -h` show subcommand-specific help rather than generic top-level usage.

The key technical changes in this iteration:
1. Implements the macro-based approach suggested by Patrick Steinhardt, factoring shared usage strings (`REPO_INFO_USAGE` and `REPO_STRUCTURE_USAGE`) to avoid duplication
2. Restores proper test file formatting with blank lines that were missing in v2
3. Adds the missing Signed-off-by line to satisfy DCO requirements

The patch maintains separate usage arrays for each subcommand while sharing the actual string definitions via macros. Tests verify that help output is properly scoped to each subcommand. All substantive feedback from Derrick Stolee and Patrick Steinhardt has now been addressed, making this version merge-ready pending final maintainer approval. The changes are well-contained to the builtin implementation and its tests with no behavioral side effects beyond the intended help text improvements.
