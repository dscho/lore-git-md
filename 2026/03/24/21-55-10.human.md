This is the first patch in a 4-part series extending `git fast-import`'s signature handling, adding an `abort-if-invalid` mode for commit signatures. The patch comes from Justin Tobler and builds on recent work that added flexible signature handling to fast-import.

The change introduces a new `abort-if-invalid` option for `--signed-commits` that will cause the import to fail immediately if any commit signature fails verification. This provides stricter validation than the existing `strip-if-invalid` and `sign-if-invalid` modes. The implementation touches the fast-import code, GPG interface plumbing, and documentation, with corresponding test updates in t9305.

The patch appears well-structured with clear commit message and thorough test coverage. It maintains consistency with existing signature handling patterns while adding the new abort behavior. This is part of a broader effort to make fast-import's signature handling more robust and consistent between commits and tags.
