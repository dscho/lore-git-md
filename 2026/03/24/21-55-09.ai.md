Feature enhancement for `git fast-import`'s signature handling. This 4-patch series extends the `--signed-commits` and `--signed-tags` options with consistent behavior modes for handling invalid signatures during import operations.

Justin Tobler builds on recent work that added `strip-if-invalid` and `sign-if-invalid` modes to `--signed-commits`. The series introduces three key changes:

1. Adds an `abort-if-invalid` mode to `--signed-commits` that fails the entire import when encountering invalid commit signatures
2. Brings `--signed-tags` to parity by adding all three modes (`strip-if-invalid`, `sign-if-invalid`, and `abort-if-invalid`)
3. Includes comprehensive tests in `t9305` and `t9306` to verify the new behaviors

The changes touch the fast-import implementation, GPG interface plumbing, and documentation. The approach appears well-considered, with each commit focused on a single logical change and test coverage included. This continues the recent trend of making fast-import's signature handling more flexible and consistent between commits and tags.
