This thread continues the long-running effort to eliminate Git's global variables by migrating configuration settings to repository-specific storage. The current focus is moving compression-related settings, with Olamide Caleb Bello leading a series that now covers three key variables: `core.trustctime`, `core.checkstat`, and `core.zlibCompressionLevel`. The latest addition migrates `pack_compression_level`, affecting packfile creation, object streaming, and blob writing operations while maintaining the same validation and default behavior (Z_DEFAULT_COMPRESSION).

The changes follow an established pattern that prevents cross-repository state leakage while preserving eager parsing semantics. The series has received positive technical feedback from reviewers including Karthik Nayak and Phillip Wood, though documentation improvements were requested before the v4 resend. Meanwhile, Junio Hamano has been handling release engineering tasks for 2.54.0-rc2 in parallel.

The work connects to several broader initiatives: René Scharfe's `the_repository` removal, Taylor Blau's object storage optimizations, and the project-wide documentation standardization led by Jean-Noël Avila. With the compression level migration now included, the series touches 69 files across Git's codebase. While these are mostly mechanical changes, they affect performance-sensitive areas, so careful review remains important as the patches progress toward merging.
