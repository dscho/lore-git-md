Feature completion for `git fast-import`'s signature handling. This final patch in Justin Tobler's 4-part series adds the `abort-if-invalid` mode to `--signed-tags`, bringing tag signature behavior to parity with the commit signature handling added earlier in the series.

The patch implements the same abort-on-failure behavior for tags that was already available for commits, completing the set of three consistent modes (`strip-if-invalid`, `sign-if-invalid`, and `abort-if-invalid`) across both commit and tag operations. The implementation follows the established pattern, with the key change being the addition of the abort logic in `handle_tag_signature_if_invalid()` and removal of the previous error that blocked this mode for tags.

Test coverage is thorough, extending the existing test cases to verify the new abort behavior alongside the other modes. The tests confirm that invalid signatures trigger the expected abort while valid signatures continue to pass through. The series as a whole appears well-considered, with clean incremental changes and comprehensive test coverage that builds on recent work to make fast-import's signature handling more flexible and consistent.
