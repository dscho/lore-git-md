Amisha Chhajed has proposed a Google Summer of Code project to add a `git evict` command for managing disk space in partial clones. The command would let users manually remove objects that can be re-fetched from remotes, using filters like --outside-cone and --large-only to select which objects to evict. The implementation would modify Git's repacking logic to skip specified objects and rely on the existing partial clone infrastructure.

Amisha has already made several contributions to Git (including optimizations to string list handling and sparse-checkout improvements) and has prototyped basic eviction functionality. The proposal includes a detailed timeline and demonstrates her understanding of Git's internals, particularly around partial clones and object storage. The mentoring team includes Christian Couder, Karthik Nayak and Justin Tobler - all active in the relevant subsystems.

Key open questions include whether this functionality belongs in `git maintenance` rather than as a new command, and how to handle cases where evicted objects become unavailable on remotes. The latest revision of the proposal adds more implementation details and identifies edge cases that need addressing, like handling different types of partial clones and validating objects as promisor objects before eviction. The student has shown good progress with a working prototype, though some validation logic is still missing.
