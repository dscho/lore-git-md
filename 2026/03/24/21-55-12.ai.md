Feature enhancement for `git fast-import`'s signature handling. This third patch in Justin Tobler's 4-part series adds `sign-if-invalid` mode to `--signed-tags`, completing the parity between tag and commit signature handling in fast-import.

The patch extends the behavior introduced for commits in ee66c793f8 to tags, allowing invalid tag signatures to be replaced with new signatures during import. Key changes include:

1. Adding `signed_tag_keyid` storage alongside the existing `signed_commit_keyid` to support explicit key specification
2. Implementing signature regeneration in `handle_tag_signature_if_invalid()` when `SIGN_SIGN_IF_INVALID` mode is active
3. Updating the option parser to accept key IDs for `--signed-tags`
4. Expanding test coverage in t9306 to verify:
   - Basic `sign-if-invalid` operation
   - Preservation of valid signatures
   - Explicit key ID specification
   - SSH signature handling

The implementation follows the same pattern as the commit signature handling, maintaining consistency between the two code paths. Test coverage appears thorough, including edge cases like tag message modification and explicit key specification. This continues the series' goal of making signature handling in fast-import more flexible and consistent.
