Test infrastructure robustness patch. Junio C Hamano continues his systematic effort to make Git's test suite compatible with `set -e` (exit on error) mode, this time addressing t7450-bad-git-dotfiles.sh. The change fixes a conditional test execution pattern that would incorrectly fail under `set -e` when the `refuse_index` variable is empty.

The patch demonstrates the careful attention needed when auditing test scripts - changing `test -n "$refuse_index" &&` to `test -z "$refuse_index" ||` to properly handle the case where the test should be skipped. This follows the pattern established in Junio's earlier fixes for t4032, t6002, and test-lib.sh, where shell constructs that don't play well with `set -e` are methodically identified and corrected.

This work remains part of the broader initiative to catch silent test failures like the original t4014 typo that used `test_expected_success` instead of `test_expect_success`. Each patch in this series makes incremental progress toward the goal of running the entire test suite with stricter error checking enabled. The changes are surgical and well-explained, showing Junio's deep familiarity with both the test framework and shell scripting edge cases.
