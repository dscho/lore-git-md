Feature enhancement for `git fast-import`'s signature handling. This is the third patch in Justin Tobler's 4-part series to make `--signed-commits` and `--signed-tags` behavior consistent when handling invalid signatures during import operations.

The patch adds a `sign-if-invalid` mode to `--signed-tags`, mirroring the behavior already available for commits. When enabled, this mode will verify tag signatures during import and replace any invalid signatures with newly generated ones using the specified key. The implementation includes:

- New `signed_tag_keyid` variable to store the signing key for tags
- Logic in `handle_tag_signature_if_invalid()` to generate new signatures when invalid ones are detected
- Updated test cases in `t9306-fast-import-signed-tags.sh` covering both PGP and SSH signatures
- Special test case for explicit key ID specification

The patch follows the same careful approach as the previous ones in the series, with thorough test coverage and clear separation of concerns. It completes the parity between commit and tag signature handling in fast-import, leaving only the final patch (presumably documentation updates) remaining in the series.
