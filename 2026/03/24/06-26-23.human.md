This is a follow-up review in the `git repo` subcommand help text improvement thread. Patrick Steinhardt suggests a refinement to Mahi Kassa's patch that introduced separate help text for the `info` and `structure` subcommands. 

Patrick proposes using macros to define the usage strings once and reuse them across both the top-level and subcommand-specific help text, preventing potential divergence between them. His suggested change would define `REPO_INFO_USAGE` and `REPO_STRUCTURE_USAGE` macros that can be included in both the main `repo_usage` array and the subcommand-specific arrays.

The review is constructive and technical, pointing out a maintainability concern with the current approach while providing a concrete solution. Patrick's suggestion would make the same improvement in user experience (showing focused subcommand help) while making the implementation more robust against future inconsistencies. The thread appears to move forward positively, with no major objections to the core concept.
