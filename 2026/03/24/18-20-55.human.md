Test infrastructure patch continuing Junio C Hamano's effort to make the test suite compatible with `set -e` (exit on error) mode. This change fixes t0008-ignores.sh where a `grep` command's non-zero exit status (when no matches are found) would incorrectly trigger an early exit under `set -e`. The fix adds `|| :` to suppress the exit status, preserving the existing behavior where the test continues regardless of whether `grep` finds matches.

This is part of a broader initiative to catch test framework errors like misspelled macros (e.g., the original `test_expected_success` typo) that currently fail silently. The patch demonstrates the careful attention needed - this grep was being used purely for its filtering output, not its exit status, so the change maintains the intended behavior while making it `set -e` safe.
