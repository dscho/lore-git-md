This is a documentation and user interface patch for the `git repo` subcommands, part of an ongoing series to improve help text output. Mahi Kassa's v3 patch completes the work to make `git repo info -h` and `git repo structure -h` show subcommand-specific help rather than the top-level usage.

The patch factors out shared usage strings into macros (`REPO_INFO_USAGE` and `REPO_STRUCTURE_USAGE`) to avoid duplication, as suggested in previous reviews. It also adds tests verifying that each subcommand's help output is properly focused. The changes are cleanly contained to the builtin implementation and its tests.

This version addresses all outstanding feedback from Derrick Stolee and Patrick Steinhardt, including the missing code changes from v2 and the requested whitespace fixes in test files. The patch appears ready for merging once the final procedural requirement (adding a Signed-off-by line) is addressed. The changes are straightforward and improve the user experience by providing more focused help output.
