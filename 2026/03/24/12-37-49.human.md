This is part of the ongoing `the_repository` removal effort, specifically targeting the `sparse_expect_files_outside_of_patterns` configuration variable. The patch moves this sparse-checkout-related setting from a process-wide global variable into `struct repo_config_values`, making it repository-specific.

The change follows the established pattern for migrating repository-dependent globals: the variable is removed from `environment.h`, added to the repository config structure, initialized with a default value (0), and all references are updated to use the repository-specific version. The patch touches three files with straightforward mechanical changes to environment handling and sparse-index operations.

This appears to be a well-contained continuation of the series, maintaining the same approach seen in previous patches for other configuration variables. The change preserves existing behavior while eliminating another case of cross-repository state leakage. The impact is limited to sparse-checkout operations, particularly around the handling of files that exist outside the specified patterns.
