This is the second patch in Justin Tobler's 4-part series extending `git fast-import`'s signature handling. It adds `strip-if-invalid` mode to `--signed-tags`, bringing tag signature handling to parity with commit signature handling that was added in a previous commit (c20f112e51).

The patch implements signature verification for tags during import, stripping invalid signatures while preserving valid ones when `--signed-tags=strip-if-invalid` is used. The changes include:

1. A new `handle_tag_signature_if_invalid()` function that verifies tag signatures using the same infrastructure as commit signatures
2. Updates to `handle_tag_signature()` to support the new mode and properly handle the tag payload
3. Comprehensive tests in t9306 that:
   - Preserve valid OpenPGP, X.509, and SSH signatures
   - Strip invalid signatures when the tag message is modified
   - Handle tags with no signature

The implementation follows the same pattern as the existing commit signature handling, maintaining consistency between the two features. Test coverage is thorough, verifying behavior with different signature types and edge cases. This continues the series' goal of making signature handling in fast-import more robust and consistent.
