This is the second patch in a 4-part series extending `git fast-import`'s signature handling, focusing on tag signatures. The patch adds a `strip-if-invalid` mode to `--signed-tags`, matching functionality that exists for commit signatures.

Justin Tobler builds on prior work that added signature verification to fast-import, now bringing tag handling to parity with commits. The new mode will automatically strip tag signatures that fail verification during import, while keeping valid signatures intact. The implementation includes:

- New `handle_tag_signature_if_invalid()` function that verifies and conditionally strips signatures
- Updates to the tag parsing logic to properly handle the new mode
- Comprehensive test coverage for various signature types (OpenPGP, X.509, SSH)
- Documentation updates to reflect the new capability

The patch appears well-structured with clear commit message and thorough test coverage. It's part of a broader effort to make fast-import's signature handling more consistent and flexible across different object types.
