This is a documentation patch updating references to the deprecated `git config -l` option in the `git-var(1)` man page. It's part of a series (1/3) that systematically replaces mentions of the old `--list` syntax with the newer `git config list` subcommand.

The patch makes two key changes to the `git-var.adoc` file: it removes the parenthetical note about the deprecation and replaces it with a more prominent WARNING admonition, while updating the recommended replacement from `git config -l` to `git config list`. The change is straightforward and aligns with Patrick Steinhardt's earlier work introducing subcommands for `git config`.

The commit message clearly explains the rationale - breaking the "deprecation chain" where one deprecated feature was pointing to another deprecated feature. This is a focused, mechanical change that improves documentation accuracy without affecting any functionality. As the first in the series, it sets the pattern for the subsequent patches to follow.
