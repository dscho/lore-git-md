This is a refactoring patch from Patrick Steinhardt, part 4/6 in his series standardizing flag handling in the object database (ODB) subsystem. The patch converts the `odb_write_object()` flags from an unsigned integer to a properly typed enum (`enum odb_write_object_flags`), following the conventions established in earlier patches of this series.

The changes are mechanical but widespread, touching six files that deal with object writing:
- Defines the new enum in odb.h with existing flags `ODB_WRITE_OBJECT_PERSIST` and `ODB_WRITE_OBJECT_SILENT`
- Updates function signatures in object-file.[ch], odb.[ch], odb/source-files.c, and odb/source.h to use the enum type
- Maintains all existing flag behavior while making the interface more type-safe

This continues Patrick's pattern of careful, systematic improvements to the ODB interface as part of the larger abstraction effort. The patch follows naturally from the earlier documentation of flag conventions (patch 1) and similar conversions for `odb_for_each_object()` (patch 2). The changes are straightforward and unlikely to be controversial, being purely about code hygiene rather than functionality.
