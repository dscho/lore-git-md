This is the third patch in Patrick Steinhardt's six-part series refactoring flag handling in Git's object database (ODB) subsystem. The patch 2 converted `odb_for_each_object()` flags to use an enum, and now this patch renames the flags for `odb_write_object()` to follow the same pattern.

The changes are mechanical but important for consistency: the flags `WRITE_OBJECT_PERSIST` and `WRITE_OBJECT_SILENT` are renamed to `ODB_WRITE_OBJECT_PERSIST` and `ODB_WRITE_OBJECT_SILENT` respectively. This makes the flags clearly tied to their function (`odb_write_object()`) and follows the style guidelines established in patch 1 of the series. The patch updates three files - cache-tree.c, object-file.c, and odb.h - with straightforward substitutions.

As with the rest of the series, this is internal code hygiene work that doesn't change functionality, but improves the codebase's consistency as part of the larger ODB abstraction effort. The changes are well-contained and follow Patrick's characteristic careful approach - each flag reference is updated exactly where needed. The patch appears ready for merging as uncontroversial cleanup.
