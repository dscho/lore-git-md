This is a refactoring patch in the fsmonitor series that renames and reorganizes platform-specific IPC code to better reflect its cross-platform nature. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC path logic is not macOS-specific and will be shared with the upcoming Linux implementation. It introduces a new `FSMONITOR_OS_SETTINGS` variable to distinguish between platform-specific files (like health monitoring and listener implementations) and shared Unix files (like settings and IPC).

The changeset updates the build system files (Makefile, CMakeLists.txt, meson.build) to handle this new separation of concerns, ensuring the IPC code is built for all Unix platforms while maintaining platform-specific implementations for other components. The patch is part of the mature v12 series that has been production-tested for months and brings Linux fsmonitor support to parity with existing Windows and macOS backends.

This refactoring demonstrates the careful architectural consideration in the fsmonitor implementation, separating truly platform-specific code from shared Unix functionality. The build system changes are straightforward and maintain compatibility with all three major build systems (make, CMake, meson). The patch builds on previous work from Eric DeCosta and Marziyeh Esipreh, showing the collaborative nature of this long-running feature development.
