This is patch 6/12 in Jeff King's series addressing C23 const-correctness warnings, specifically around `strchr()` usage. The patch converts the `find_last_dir_sep()` inline function to a macro to avoid const-casting issues while maintaining compatibility with both const and non-const callers.

The change is motivated by C23's stricter `strrchr()` annotations that now flag implicit const removal. While the Windows-specific implementation in `path-utils.h` already handles this differently (with explicit casting), this patch focuses on the main implementation in `git-compat-util.h`. The macro approach preserves type information better than the inline function did, letting the compiler do proper const checking at each call site.
