This is part 2 of Justin Tobler's 6-patch series introducing write operations to Git's object database (ODB) transaction interface, continuing the ODB abstraction effort. The patch makes the transaction begin operation pluggable by using the callback mechanism introduced in an earlier commit (d6fc6fe6f8).

The change is straightforward - it replaces a direct call to `odb_transaction_files_begin()` with the new pluggable `odb_source_begin_transaction()` interface. This allows different ODB backends to provide their own transaction implementations while maintaining the same external API. The patch includes the necessary header change to pull in the ODB source definitions.

As part of the series' progression, this is a mechanical change that builds on the infrastructure split in patch 1. It's a clear step toward the goal of making ODB operations backend-agnostic, though by itself it doesn't change behavior - it enables future flexibility. The commit message clearly explains the context and relationship to prior work.
