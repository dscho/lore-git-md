Maintainer feedback on sparse-checkout backfill patch. Junio C Hamano responds to Trieu Huynh's GSoC patch that fixed `git backfill` to respect sparse-checkout configurations. While acknowledging the change's intent, Junio questions whether the -1 sentinel value truly represents "auto-detection" since the code doesn't actively detect sparse status but rather defaults to sparse mode (which becomes a no-op in non-sparse repos). He notes the current implementation relies on `get_sparse_checkout_patterns()` being harmless when sparse-checkout isn't active, and suggests this might be more accurately described as defaulting to `--sparse` behavior. Junio CCs Derrick Stolee (original author of the sparse-related backfill code) for deeper technical input, indicating this may need clarification or refinement in approach. The test case remains uncontested, but the conceptual framing of the fix is under discussion.
