This is a refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The series contains six cleanups focused on improving flag handling in the ODB subsystem and related code.

The changes standardize how flags are handled across the object database interface:
1. Documents flag handling style in CodingGuidelines
2. Converts `odb_for_each_object()` flags to use an enum
3. Renames and converts `odb_write_object()` flags to use more descriptive names and an enum
4. Similarly updates `odb_has_object()` flags
5. Removes unnecessary headers and forward declarations

The patch touches a wide range of files (28 modified) but makes mostly mechanical changes - renaming flags, converting macros to enums, and cleaning up includes. The changes appear consistent with Patrick's broader work on the ODB layer, though this particular set focuses on code hygiene rather than functional changes.

The series builds on Patrick's recent `odb_find_abbrev_len()` work and targets the current master branch. As with most of Patrick's contributions, the changes are well-structured and carefully explained, though the impact is limited to internal code quality rather than user-visible behavior.
