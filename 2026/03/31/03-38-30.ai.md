This is a refactoring patch that splits the ODB transaction interface into its own header file, part of Justin Tobler's ongoing work on the ODB abstraction effort. The patch moves `struct odb_transaction` and related functions from `odb.{c,h}` to new files `odb/transaction.{c,h}` to better organize the code as the transaction interface grows to support write operations.

The changes are mechanical - moving code between files while maintaining all existing functionality. The patch updates all callers to include the new header, touching several builtin commands (`add`, `update-index`, `unpack-objects`) and core components like the cache-tree and read-cache. The commit message explains this is preparatory work for expanding the interface in subsequent patches.

This is patch 1/6 in a series that will eventually add write operations to the ODB transaction interface. The change appears straightforward and well-contained, with no functional changes - just code reorganization to support the upcoming additions. The patch follows the project's typical pattern of splitting growing interfaces into dedicated files.
