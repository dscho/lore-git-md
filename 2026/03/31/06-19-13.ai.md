This is a feature patch in the fsmonitor series, adding process isolation capabilities to the run-command infrastructure. The patch introduces a new `close_fd_above_stderr` flag in `struct child_process` that, when enabled, makes child processes automatically close all file descriptors above stderr (FD 2) before exec, while preserving the child-notifier pipe used for inter-process communication.

The implementation carefully handles edge cases - it respects system limits via `sysconf(_SC_OPEN_MAX)` but caps at 4096 FDs for safety, and explicitly skips the child-notifier pipe FD. This prevents child processes from accidentally inheriting open file descriptors from the parent (like test harness pipes) while maintaining required IPC channels.
