This is a platform compatibility patch in the fsmonitor series, adding Windows pthread emulation support needed for the Linux inotify implementation. The patch implements `pthread_cond_timedwait()` for Windows using `SleepConditionVariableCS()`, completing the pthread compatibility layer required for cross-platform fsmonitor support.

The implementation handles timeouts by converting between POSIX `timespec` (passed as absolute deadline) and Windows' millisecond-based relative timeout. It properly propagates ETIMEDOUT when the deadline is reached and converts other Windows errors to POSIX error codes. The change is straightforward and follows the existing pattern for pthread emulation on Windows.

This is part of the mature v12 fsmonitor series that has been production-tested for months. The pthread additions enable consistent cross-platform behavior for the fsmonitor daemon's thread synchronization.
