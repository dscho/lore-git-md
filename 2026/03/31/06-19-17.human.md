This is a refactoring patch in the fsmonitor series, converting pathname deduplication from a khash implementation to Git's strset data structure. The change simplifies the code by using a more idiomatic Git API while maintaining the same functionality.

The patch replaces the custom khash string set with a strset in the fsmonitor daemon's client handling code. Since the paths are already interned strings, it avoids unnecessary copies by setting strdup_strings=0. The change was suggested by Patrick Steinhardt and follows the project's preference for using standard Git data structures where possible.

This is part of the v12 iteration of the fsmonitor series, which has been production-tested and addresses all substantive technical feedback. The change is straightforward and low-risk, focusing on code cleanliness rather than behavior modification. The patch demonstrates the series' continued refinement as it approaches finalization.
