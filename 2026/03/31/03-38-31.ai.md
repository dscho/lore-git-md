This is the second patch in Justin Tobler's 6-part series introducing write operations to Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The patch builds on the previous mechanical refactoring that split the transaction struct into its own header.

The change makes the transaction initialization pluggable by using the `begin_transaction()` callback that was recently added to `struct odb_source` (in commit d6fc6fe6f8). Instead of directly calling `odb_transaction_files_begin()`, the code now delegates to the source-provided callback via `odb_source_begin_transaction()`. This is a straightforward change that aligns with the series' goal of making ODB operations more modular and backend-agnostic.

The patch is small (just 2 lines changed) and focused, with a clear commit message explaining the change. It updates the include to use the new `odb/source.h` header instead of `object-file.h`, reflecting the ongoing separation of concerns in the ODB code. This is a typical preparatory patch in a larger refactoring series - not functionally significant on its own, but necessary for the subsequent changes that will build on this pluggable interface.
