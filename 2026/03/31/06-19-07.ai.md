This is a bugfix patch in the long-running fsmonitor series, addressing a memory leak in the daemon's cookie tracking. The patch fixes an oversight where the `state.cookies` hashmap and its allocated strings were not being freed during daemon shutdown.

The fix adds proper cleanup in the `done:` label of `fsmonitor_run_daemon()`, iterating through the hashmap to free each cookie name string before clearing the hashmap itself. This matches the pattern used elsewhere in the codebase for similar structures. The change is straightforward and clearly correct - it follows the established practice for hashmap cleanup in Git.

This patch is part of the v12 iteration of the Linux fsmonitor implementation, which has been through extensive review and production testing.
