This is the fourth patch in Patrick Steinhardt's series to improve reftable portability for libgit2 integration. The patch introduces a platform-agnostic way to get millisecond timestamps in the reftable subsystem.

The change replaces direct `gettimeofday()` calls with a new `reftable_time_ms()` function that uses Git's existing `getnanotime()` (which is already portable) under the hood. This simplifies the timeout handling in `reftable_stack_reload_maybe_reuse()` by removing manual timeval comparisons in favor of direct millisecond arithmetic.

The patch is small and focused, touching only the reftable implementation files. It follows the series' pattern of abstracting platform-specific details behind clean interfaces. The change is purely internal - no user-facing behavior is affected - but it removes another system dependency that could vary across platforms. This brings Git's reftable code one step closer to being fully portable for libgit2's needs.
