This is a small but important refactoring patch in Patrick Stehtardt's series to make Git's reftable implementation portable for libgit2. The change replaces a Git-specific `UNUSED` macro with the reftable-specific `REFTABLE_UNUSED` in the fsck.c file, maintaining consistency within the reftable subsystem.

The patch is straightforward - it changes one line to use the subsystem's own macro for marking unused parameters. While seemingly minor, this is part of the larger effort to decouple reftable from Git-specific internals so the code can be shared with libgit2. The commit message explains why they can't simply move the `UNUSED` definition to a shared header due to mingw-posix.h dependencies.

This is the third patch in a six-part series that's been carefully structured to make the reftable backend more portable. The change is mechanical and low-risk, with no behavior changes - just internal code hygiene as part of the libgit2 integration effort. The series as a whole has been well-received and appears to be the final step before libgit2 can fully adopt Git's reftable implementation.
