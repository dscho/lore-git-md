This is a documentation patch from Patrick Steinhardt, the first in his six-part series standardizing flag handling in Git's object database (ODB) subsystem. The patch adds guidelines to `Documentation/CodingGuidelines` about how flags should be defined and used in function interfaces.

The new section specifies that functions accepting flags should use an enum named after the function (e.g. `enum frobnicate_flags`), with individual flags prefixed by the function name in uppercase (e.g. `FROBNICATE_FOO`). The values should use bit shifts rather than raw numbers. This is a mechanical but important standardization that will make flag usage more consistent and self-documenting across the codebase.

As with all of Patrick's work, the change is carefully considered and well-presented, though purely internal in impact. The patch serves as a foundation for the subsequent ODB changes in the series by establishing the conventions those changes will follow. Given Patrick's central role in the ODB abstraction effort and the non-controversial nature of documentation improvements, this seems likely to be merged without significant discussion.
