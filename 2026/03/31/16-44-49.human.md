This is a documentation review for a feature patch that makes submodule fetch errors configurable. Jean-Noël Avila points out two documentation issues in Paulius Zaleckas's patch that adds the `fetch.submoduleErrors` option.

First, he notes that the syntax for command-line alternatives should use parentheses format `(fail|warn)` rather than angle brackets, following Git's standard synopsis style. Second, he observes that while the config option is documented, the corresponding `--submodule-errors` command-line option is missing from the manual pages.

The feedback is constructive and specific, coming from Git's documentation maintainer who is actively working on standardizing man page formats. The issues raised are minor but important for consistency - exactly the sort of polish the project expects during review. No technical concerns are raised about the underlying functionality, which appears sound based on the thread summary.
