This is a documentation patch review from Junio C Hamano regarding Kristoffer Haugsbakk's series updating references to deprecated `git config` options. Junio identifies a subtle but important issue with the first patch's wording that could mislead users about the scope of the deprecation.

The original patch intended to update `git-var.adoc` by replacing `git config -l` with `git config list` and promoting the deprecation notice to a WARNING admonition. However, Junio points out that the new wording incorrectly suggests the entire `git var -l` command is deprecated, when in fact only its configuration variable listing functionality is deprecated - the logical variables feature remains valid and useful.

Junio explains the distinction between logical variables (which synthesize values from multiple sources) and configuration variables (which come from Git config files). He recommends keeping the original phrasing structure that limits the deprecation to the configuration listing aspect, while still updating the recommended replacement command. This maintains technical accuracy while still accomplishing the series' goal of removing deprecated syntax references.

The review demonstrates Junio's attention to subtle documentation nuances that could impact user understanding. His suggested approach would preserve the patch's core improvement while avoiding potential confusion about `git var -l`'s continued utility for logical variables. This feedback will likely lead to a v2 of the patch with more precise wording.
