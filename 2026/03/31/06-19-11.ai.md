This is a refactoring patch in the fsmonitor series, part of the ongoing effort to bring Linux inotify support to parity with existing Windows and macOS backends. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is not macOS-specific and will be shared across Unix platforms (now including Linux). It updates both the CMake and meson build systems to use a new `FSMONITOR_OS_SETTINGS` variable for platform-specific settings, matching the approach already used for IPC code.

The change is straightforward - a file rename with corresponding build system updates - but it represents an important architectural improvement by properly separating platform-specific components from shared Unix logic. This follows the pattern established earlier in the series for IPC code organization. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) whose work informed this refactoring.
