This is a documentation patch from Patrick Steinhardt, the first in his six-part series standardizing flag handling in the object database (ODB) subsystem. The patch adds a new section to `Documentation/CodingGuidelines` that formally documents Git's preferred style for function flags.

The new guidelines specify that functions accepting flags should:
- Define them in an `enum F_flags` type (where F is the function name)
- Name individual flags with the function prefix in all-caps (e.g. `FROBNICATE_FOO`)
- Use bit shifts for flag values
- Include an example showing the pattern

This is a mechanical but important standardization that will help maintain consistency across the codebase, particularly in Patrick's ongoing ODB abstraction work. The change is purely additive - it introduces no behavior changes but provides clear documentation for future contributors. As with all of his patches, this one is cleanly implemented and well-motivated as part of the larger ODB effort.
