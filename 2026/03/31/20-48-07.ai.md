This is a documentation patch series updating references to the deprecated `git config --list` option, replacing them with the newer `git config list` subcommand. The series comes from Patrick Steinhardt's earlier work that introduced subcommands for `git config`.

Kristoffer Haugsbakk found these references while examining `git-var(1)` and systematically searched for other occurrences across the documentation. The patches touch six different man pages, with each commit focusing on a specific document. The changes are straightforward textual replacements, though one commit (gitcvs-migration.adoc) also includes minor rephrasing for clarity.

The series is well-scoped, focusing only on the `--list` deprecation and not attempting to address other deprecated options. The commit messages clearly indicate which documentation files are being modified, making it easy to review. Since this is purely documentation cleanup with no behavior changes, it should focus on whether the updates accurately reflect the current command syntax and maintain readability.
