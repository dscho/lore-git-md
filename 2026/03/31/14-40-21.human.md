This is the final patch in Justin Tobler's series to make ODB write operations pluggable, completing the object database abstraction effort. The patch introduces a `write_object_stream()` callback in `struct odb_transaction`, allowing different ODB backends to implement their own write strategies. The files backend's implementation (`index_blob_packfile_transaction()`) is wired up as the default.

Patrick Steinhardt suggests two final refinements: renaming the function to better reflect its role (`odb_transaction_files_write_object_stream()`), and documenting that the current implementation only handles blob objects. Justin agrees to both changes, noting that blob-only support is temporary and will be expanded in future work.

The series has undergone thorough review from Patrick (the ODB abstraction effort's primary driver), with all substantive technical concerns addressed in earlier iterations. This final patch represents polished interface work that maintains backward compatibility while establishing the foundation for future storage backends. The changes are well-motivated as part of the larger ODB abstraction project and appear ready for merging.
