This thread explores a proposal for a new `git whoami` command that would display user identity in a cleaner format than the existing `git var GIT_AUTHOR_IDENT` output, which includes a timestamp. Giorgos Gasparis initiated the discussion, suggesting the command as a more user-friendly alternative to querying separate config values. Junio C Hamano pointed out the existing functionality through `git var`, setting a high bar for justifying a new command.

Kristoffer Haugsbakk has now joined the conversation, noting that the proposed output (name and email without timestamp) aligns with examples in Git's own documentation, particularly in `git-interpret-trailers`. He highlights the extra step users currently need to strip timestamps from `git var` output, suggesting there may be merit to a cleaner solution. However, the discussion remains theoretical—no one has yet demonstrated concrete use cases where the existing mechanism fails or shown metrics proving widespread need. The thread is at an impasse until someone either provides stronger validation of the value proposition or submits an implementation patch.
