This is the second patch in Patrick Steinhardt's six-part series standardizing flag handling in Git's object database (ODB) subsystem. The patch focuses on `odb_for_each_object()` and related functions, converting their flag parameters from unsigned integers to properly typed enums.

The change is purely mechanical - updating function signatures in four files (odb.c, odb.h, packfile.c, packfile.h) to use the `enum odb_for_each_object_flags` type instead of `unsigned` for flags. This follows the style guidelines established in patch 1/6 of the series, which documented enum usage patterns for flags.

As part of Patrick's larger ODB abstraction effort, this change improves type safety and makes the interface more consistent. The patch touches core object database code but introduces no behavior changes - it's strictly a code hygiene improvement that helps prepare the codebase for future pluggable backends. The rest of the series will apply similar enum conversions to other ODB functions.
