This is the fourth patch in Patrick Steinhardt's six-part series refactoring flag handling in Git's object database (ODB) subsystem. The series is part of the ongoing ODB abstraction effort to enable pluggable backends.

This patch converts the `odb_write_object()` flags from an unsigned integer to a properly typed enum (`enum odb_write_object_flags`), following the conventions established in earlier patches. The change affects several files across the ODB interface, including object-file.c, odb.h, and related source files. The actual flag values (`WRITE_OBJECT_PERSIST` and `WRITE_OBJECT_SILENT`) remain functionally the same - this is purely a type-safety and code hygiene improvement.

The changes are mechanical and consistent with Patrick's careful, systematic approach to refactoring. As with the rest of the series, this patch makes no functional changes but improves internal code quality in preparation for future ODB work. The patch touches multiple files but each change is straightforward - just updating parameter types and enum declarations.
