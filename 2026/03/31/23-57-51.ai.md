This is the final patch in Patrick Steinhardt's six-part refactoring series improving flag handling in the object database (ODB) subsystem. The patch focuses on code hygiene by cleaning up unnecessary headers and forward declarations in `odb.h`.

The changes remove several includes and forward declarations that are no longer needed after the previous patches in the series. Specifically:
- Drops the `hashmap.h` include which appears unused
- Removes redundant forward declarations for `struct oidmap`, `struct oidtree`, `struct packed_git`, `struct packfile_store`, and `struct multi_pack_index`
- Keeps only the forward declarations that are actually used in the header (`struct cached_object_entry`, `struct packed_git`, `struct repository`, `struct strbuf`, `struct strvec`)

This is a mechanical cleanup that follows naturally from the earlier flag standardization work in the series. The patch is small (12 lines changed) and focused, typical of Patrick's careful, systematic approach to refactoring. As with the rest of the series, there are no functional changes - this is purely about improving code organization and removing cruft as part of the larger ODB abstraction effort.
