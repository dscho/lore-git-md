This is a platform compatibility patch in Patrick Steinhardt's series to make Git's reftable implementation portable for libgit2. The patch introduces memory-mapping abstractions (`reftable_mmap` and `reftable_munmap`) to handle platform differences in mmap implementations, particularly for Windows which doesn't natively support mmap.

The change replaces direct mmap/munmap calls with wrapper functions that can be customized by projects embedding the reftable library. The implementation uses Git's existing `xmmap_gently()` internally but exposes a clean interface that libgit2 can adapt to its own memory-mapping needs. The patch is mechanical and focused - it touches only the reftable subsystem while maintaining identical behavior.

This continues the series' pattern of isolating platform dependency behind reftable-specific abstractions. With this change, the mmap interface becomes properly encapsulated, removing one of the final barriers to libgit2 adoption. The patch appears straightforward and well-contained, with no user-facing impact.
