This is a performance optimization patch for the `git backfill` command, which is part of Git's partial clone functionality. The patch addresses an inefficiency where `backfill` would still scan the object directory even when no objects needed to be downloaded (i.e., when the repository is already up-to-date).

The key changes are:
1. Adding a check to skip the `download_batch` call when the current batch is empty (nr == 0)
2. Adding trace2 instrumentation to track batch requests
3. Including a test case that verifies no batches are requested when running backfill on an already-up-to-date repository
