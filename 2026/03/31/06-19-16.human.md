This is a test patch in the fsmonitor series, adding Linux-specific test coverage for the inotify-based filesystem monitoring implementation. The patch comes from Paul Tarjan as part of the v12 iteration of this long-running series that brings Linux fsmonitor support to parity with Windows and macOS.

The patch adds several important test scenarios:
1. A smoke test that verifies the filesystem actually delivers inotify events (some configurations accept watches but never deliver events)
2. A test for rapid nested directory creation to catch race conditions in recursive watch handling
3. Various test infrastructure improvements like timeout handling, process group management, and robustness in CI environments

The changes demonstrate careful attention to edge cases - particularly around process management and filesystem quirks - that have emerged during the series' long development cycle. The test coverage appears thorough, with specific attention paid to container/overlayfs environments where fsmonitor has historically had issues.

This patch is part of a mature series that has been production-tested for months and has addressed all substantive technical feedback. The implementation is now stable across all platforms, with this test patch helping ensure Linux-specific behaviors are properly validated.
