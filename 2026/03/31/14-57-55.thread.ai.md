git whoami command proposal from Giorgos Gasparis to display combined user.name and user.email configuration. The command would provide a single output showing the current Git identity, addressing a common workflow need when switching between repositories with different identities. Motivation cites widespread use of custom aliases for this purpose, suggesting clear user need. No implementation details or patch provided yet - this is an initial use case proposal seeking feedback on the concept before implementation. The simplicity and alignment with existing config model suggests low technical risk, but actual evaluation would require a patch submission.
