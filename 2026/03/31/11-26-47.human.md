This is a platform compatibility patch from Patrick Steinhardt, part of a series to make Git's reftable implementation portable for libgit2. The patch introduces a `REFTABLE_INLINE()` macro to standardize inline function declarations across compilers, replacing direct `static inline` usage throughout the reftable code.

The change is mechanical but important - it ensures the reftable library (which can be used standalone) doesn't depend on compiler-specific inline support. The patch updates several inline functions in reftable headers that handle big-endian encoding/decoding, memory allocation, and priority queue operations. No behavior changes, just portability improvements.

This is the first of six patches in a series that collectively remove platform-specific assumptions from reftable, enabling libgit2 to reuse Git's implementation. The changes are focused and well-contained, touching only reftable internals. Given Patrick's track record with the reftable backend and the clear motivation, this appears to be a straightforward improvement moving the shared reftable effort forward.
