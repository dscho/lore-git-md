This is a refactoring patch in the fsmonitor series that brings Linux support to parity with existing Windows and macOS implementations. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC path logic is not Darwin-specific and will be shared by the upcoming Linux implementation. 

The key change introduces a distinction between `FSMONITOR_OS_SETTINGS` (for shared Unix files) and `FSMONITOR_DAEMON_BACKEND` (for platform-specific files), updating the build system accordingly across Makefile, CMake, and meson configurations. This prepares the codebase for the Linux fsmonitor backend while maintaining existing functionality.

The patch is part of the mature v12 series that has been production-tested for months. It demonstrates careful attention to cross-platform concerns, with build system changes that cleanly separate shared Unix logic from platform-specific implementations. The changes appear straightforward and well-motivated, continuing the series' pattern of thorough platform support.
