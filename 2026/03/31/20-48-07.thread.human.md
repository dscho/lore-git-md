Kristoffer Haugsbakk's documentation patch series to update references from the deprecated `git config -l` to the newer `git config list` subcommand has nearly completed its review cycle. The comprehensive series updating documentation across multiple man pages received broad approval from maintainer Junio C Hamano, with only one minor correction needed on the first patch.

Junio identified a subtle but important distinction in git-var.adoc - while the configuration variable listing functionality of `git var -l` is indeed deprecated, its logical variables feature remains valid. Kristoffer has now submitted a revised version of patch 1 that maintains this technical accuracy while still updating the command reference, dropping an originally proposed WARNING admonition that would have incorrectly suggested complete deprecation.

The rest of the series (patches 2-8) updating gitcvs-migration.adoc, git-config(1), and other core documentation was approved without changes. Junio particularly noted the clean approach in the final patch updating gitprotocol-v2.adoc and related files. With this last clarification addressing the configuration vs. logical variables distinction, the series appears ready for integration, demonstrating the project's attention to precise documentation that accurately reflects technical behavior.
