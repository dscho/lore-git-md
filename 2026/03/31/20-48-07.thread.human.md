This thread documents a systematic cleanup of Git's documentation to replace deprecated `git config --list` and `-l` options with the newer `git config list` subcommand. Kristoffer Haugsbakk identified these references while examining `git-var(1)` and expanded the work to cover all documentation files. The series now consists of seven patches, each addressing specific man pages.

The changes are straightforward syntax updates, with one notable exception in the tutorial documentation where the author preserved more verbose "man page" phrasing for pedagogical purposes. The patches follow a consistent pattern of one documentation file per commit, with clear explanations of both the required updates and any stylistic improvements. The work builds on Patrick Steinhardt's earlier introduction of the `list` subcommand while remaining tightly scoped to documentation updates with no behavior changes.

With the final patch now covering gitprotocol-v2.adoc, gittutorial.adoc, api-trace2.adoc, and user-manual.adoc, the series completes its goal of updating all identified instances of the deprecated syntax across Git's documentation. The changes improve consistency and accuracy while maintaining readability, particularly in tutorial contexts where more explanation is appropriate.
