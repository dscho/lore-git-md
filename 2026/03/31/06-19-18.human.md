This is a bugfix patch in the mature fsmonitor series that brings Linux support to parity with Windows and macOS. The patch addresses an edge case where fsmonitor's EWAH bitmap could reference out-of-bounds entries when used with split-index mode, causing a BUG assertion.

The fix adds proper bounds checking in two places: `tweak_fsmonitor()` now skips the bitmap assertion when split-index is active (matching existing guards in other code paths), and `fsmonitor_ewah_callback()` replaces its assertion with a silent bounds check. This resolves an issue that was previously worked around in the test suite by disabling split-index testing.

The patch is part of the v12 series that has been production-tested for months and has addressed all substantive technical feedback. It demonstrates the thoroughness of the testing by catching this subtle split-index interaction. The implementation appears technically sound, with the series now complete across all platforms.
