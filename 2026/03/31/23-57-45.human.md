This is a refactoring patch series from Patrick Steinhardt, part of the ongoing object database (ODB) abstraction effort. The series contains six cleanups that didn't fit into his other recent patch series.

The changes focus on standardizing flag handling in the ODB subsystem:
1. Documents flag handling style in CodingGuidelines
2. Converts `odb_for_each_object()` flags to use an enum
3-4. Renames and converts `odb_write_object()` flags to enum
5. Renames `odb_has_object()` flags
6. Drops unnecessary headers and forward declarations

The patches are mechanical and touch many files (28 modified) but each change is small and focused. This appears to be routine maintenance work from one of Git's most active contributors, cleaning up loose ends in the ODB subsystem he's been modernizing. The changes don't introduce new functionality but improve code consistency and documentation.

The series builds on Patrick's recent work (ps/odb-generic-object-name-handling) and targets master. Given the author's track record with ODB changes and the straightforward nature of these cleanups, this series seems likely to be merged without much discussion.
