This is the third patch in Patrick Steinhardt's six-part refactoring series improving flag handling in Git's object database (ODB) subsystem. The series is part of the ongoing ODB abstraction effort to make the backend more pluggable.

This patch focuses on renaming flags for the `odb_write_object()` function to follow the new conventions established in patch 1 (documented in CodingGuidelines). The changes:
- Rename `WRITE_OBJECT_PERSIST` to `ODB_WRITE_OBJECT_PERSIST`
- Rename `WRITE_OBJECT_SILENT` to `ODB_WRITE_OBJECT_SILENT`

The patch updates three files (cache-tree.c, object-file.c, and odb.h) with these mechanical renames. The changes are straightforward and maintain the same bit values, just with more descriptive names that follow the project's new flag naming guidelines (function name prefix in all caps).

This continues the series' pattern of non-controversial internal cleanup work - the changes improve code consistency without altering behavior. The patch follows Patrick's characteristic thoroughness, touching all relevant call sites and maintaining the same careful attention to detail seen in the earlier patches. As with the rest of the series, this appears ready for merging as part of the broader ODB abstraction effort.
