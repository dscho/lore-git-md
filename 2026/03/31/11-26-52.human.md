This is the final patch in Patrick Steinhardt's series to improve reftable portability for libgit2 integration, focusing on platform compatibility. The patch introduces a new "reftable-system.h" header that consolidates system header dependencies, making it easier for projects like libgit2 to provide their own implementations of required functionality.

The change replaces scattered inclusions of standard headers like `<stdint.h>` and `<unistd.h>` with a single point of control through the new header. This is particularly useful for libgit2, which can now override the header to use its own compatibility layer. The patch is mechanical, touching 13 files to update include directives while maintaining all existing functionality.

This completes the series' goal of isolating platform-specific dependencies in the reftable code, representing the last major step before libgit2 can fully adopt Git's reftable implementation. The changes are well-contained to the reftable subsystem with no user-facing impact, continuing the pattern of clean, focused patches seen throughout the series.
