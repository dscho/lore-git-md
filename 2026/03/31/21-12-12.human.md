This is a documentation patch that corrects an over-broad deprecation warning in the `git-var(1)` man page. The original patch (part of a series updating deprecated `git config -l` references) had inadvertently marked *all* uses of `git var -l` as deprecated, when in fact only the configuration-variable listing aspect is deprecated - the logical variables feature remains valid.

Junio C Hamano points out the distinction between logical variables (which synthesize values from multiple sources) and configuration variables (which come from Git config files). He suggests keeping the original phrasing structure while just updating the `git config -l` reference to `git config list`, avoiding the misleading implication that `git var -l` itself is fully deprecated.

The patch will need to be revised to maintain this important technical distinction while still updating the deprecated reference. This is a good example of why careful review is needed even for seemingly straightforward documentation changes - subtle technical distinctions can be easy to overlook.
