This thread introduces and finalizes the write operations interface for Git's object database (ODB) transactions, a key milestone in Patrick Steinhardt's ongoing ODB abstraction effort. Justin Tobler authored the 7-patch v3 series to make ODB writes explicitly use the transaction interface rather than implicit redirection, with Patrick Steinhardt approving all patches after multiple review rounds.

The series mechanically splits `struct odb_transaction` into new `odb/transaction.{c,h}` files, makes transaction initialization pluggable, refines the `odb_write_stream` interface for buffer ownership, splits packfile blob writing into separate hash-and-write phases, eliminates unnecessary seek operations on large blobs, and wires up a `write_object_stream()` callback so future storage backends can implement their own write strategies while maintaining a consistent interface.

Jeff King (Peff) reviewed the series after Steinhardt's approval and caught a file descriptor leak in `odb_source_loose_write_stream()` error paths that Coverity had flagged. Tobler acknowledged the issue and confirmed he will send a v4 to fix it. The exchange is brief and procedural — the review was substantive, the author accepted without debate, and the series is now waiting for an incremental fix. Once resolved, the patchset is nearly ready for merging into the `next` branch, affecting core commands like `git add` and `git update-index`.
