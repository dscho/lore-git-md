This thread finalizes the write operations interface for Git's object database (ODB) transactions, a key milestone in the multi-year ODB abstraction effort. Justin Tobler's 7-patch series (now at v4) transitions ODB to use explicit transaction interfaces rather than implicit redirection, with Patrick Steinhardt (the primary architect of the ODB abstraction) approving the technical direction and Jeff King (Peff) providing critical review that caught resource management issues.

The latest patch (4/7) splits blob writing into two distinct phases - hash computation and actual writing - by introducing a new `hash_blob_stream()` helper. This removes conditional flag handling from the packfile write path, making those writes unconditional while moving the flag check up to `index_fd()`. The change maintains the series' clean separation of concerns while simplifying the interface. The patch also adds infrastructure for streaming from file descriptors and proper cleanup handling.

The series has evolved through careful review, with v4 addressing Jeff King's discovery of a file descriptor leak in loose object error paths. Patrick Steinhardt has approved the technical approach throughout, and with both primary reviewers' concerns now addressed, the series appears ready for merging. These changes affect core object-file operations used by commands like `git add` and `git update-index`, representing a significant step toward enabling pluggable storage backends in Git.
