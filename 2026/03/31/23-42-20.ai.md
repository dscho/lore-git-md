This is patch 4/12 in Jeff King's series addressing C23 const-correctness warnings around `strchr()` usage. The patch focuses on the pager subsystem, specifically handling environment variable parsing in `pager.c`.

The issue arises when splitting and modifying the `PAGER_ENV` configuration. The code needs to write to strings that come from `split_cmdline()`, which returns a `const char**` array. While the strings are actually writable (they're split from the non-const `pager_env` variable, the compiler doesn't know this. The patch adds an explicit cast to silence the warning, with a clear comment explaining why the cast is safe.
