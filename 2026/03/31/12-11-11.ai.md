Feature addition to `git cat-file`'s batch mode, now ready for merging with all feedback addressed.

Siddharth Asthana's patch implements dynamic mailmap toggling for `git cat-file --batch-command`, solving GitLab Gitaly's need to control name/email rewriting in long-running processes without restarting them. The final version introduces a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) and maintains mailmap data in memory once loaded.

The implementation adds a `load_mailmap()` helper function shared between startup and runtime paths, uses `git_parse_maybe_bool()` for robust argument handling, and includes comprehensive tests covering runtime toggling, startup option interactions, boolean variants, and invalid inputs. The changes are well-contained to `builtin/cat-file.c` and its documentation/tests.

This appears to be a well-executed solution to a real-world use case, with careful attention to review feedback from Junio Hamano, Patrick Steinhardt, and Karthik Nayak.
