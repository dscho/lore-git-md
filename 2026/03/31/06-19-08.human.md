This is a platform compatibility patch in the fsmonitor series, adding Windows pthread emulation needed for the Linux inotify support. The patch implements `pthread_cond_timedwait()` for Windows using the native `SleepConditionVariableCS()` API, converting between timespec and millisecond timeout values.

The implementation handles the absolute deadline calculation and error cases properly, including ETIMEDOUT when the timeout expires. This is part of the broader effort to make fsmonitor work consistently across platforms, with Windows requiring additional pthread compatibility layers since it lacks native pthread support.
