This is the final patch in Justin Tobler's series introducing write operations to Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The patch makes the `write_object_stream()` functionality pluggable by adding it as a callback in `struct odb_transaction`.

The change introduces a new `write_object_stream` function pointer in the transaction struct, allowing different ODB implementations to provide their own methods for writing objects. The patch wires up the existing `index_blob_packfile_transaction()` function to serve as the implementation for the files-based backend (`struct odb_transaction_files`). This completes the transition from direct function calls to using the transaction interface for object writes.

Key technical changes include:
- Adding the callback definition to `struct odb_transaction`
- Implementing a wrapper function `odb_transaction_write_object_stream()` that delegates to the callback
- Updating `object-file.c` to use the new interface instead of direct calls
- Wiring up the files backend to use `index_blob_packfile_transaction` as its implementation

This patch builds on the preparatory work in earlier patches (particularly patch 5's stream interface generalization) to finalize the transaction interface for writes. The change is mechanical but important for enabling future ODB backends to implement their own write strategies while maintaining a consistent interface.

The series as a whole represents a significant step in Patrick Steinhardt's ODB abstraction effort, making Git's object storage more modular. This final patch completes the write path transition that began with the earlier refactoring work. Reviewers will likely check that the interface design is flexible enough for future needs while remaining simple and consistent with the rest of the transaction API.
