This thread documents Patrick Steinhardt's series to make Git's reftable implementation portable enough for libgit2 to adopt. The six-patch effort systematically abstracts platform dependencies - inline declarations, timestamp handling, filesystem synchronization, and memory mapping - behind reftable-specific interfaces. 

The final patch introduces a "reftable-system.h" header that consolidates all system header includes, completing the abstraction layer. This mechanical change replaces direct includes of standard headers throughout the reftable subsystem, allowing projects like libgit2 to provide their own implementations. The series maintains identical functionality while isolating platform details, with all changes confined to the reftable directory and verified against both Git and libgit2 test suites.

With these changes, the reftable code now has clean separation between core logic and system dependencies, fulfilling the collaboration goal between Git and libgit2 maintainers. The series appears ready for merging as the last step before libgit2 can fully adopt Git's reftable implementation, building on their prior work standardizing the shared format.
