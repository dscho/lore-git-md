Patrick Steinhardt continues his work to make Git's reftable implementation more portable for libgit2 integration with a fourth patch focusing on time handling. The series has systematically replaced platform-specific code with cross-platform abstractions, and this latest change replaces direct `gettimeofday()` calls with a new `reftable_time_ms()` function that uses Git's existing high-resolution timer.

The patch simplifies timeout logic in the reftable stack by converting from `struct timeval` comparisons to straightforward millisecond arithmetic, while maintaining the same 3-second timeout behavior. This removes another platform dependency and eliminates a custom comparison helper function. The changes are confined to reftable internals with no user-facing impact, and existing tests continue to pass.

This work builds on earlier patches that introduced cross-platform abstractions for inline declarations, file synchronization, and subsystem boundaries. The series represents the final steps before libgit2 can fully adopt Git's reftable code, completing a collaboration between Git and libgit2 maintainers to unify implementations. With this time abstraction in place, only test fixes remain before the portability effort is complete.
