This is a feature patch series introducing write operations to Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The series comes from Justin Tobler, who has been actively involved in this area alongside Patrick Steinhardt.

The main goal is to make object writes within transactions explicit by adding a dedicated `odb_transaction_write_object_stream()` API, moving away from the current implicit approach where transactions reconfigure ODB sources. The series focuses first on streaming large blobs directly into transaction packfiles.

The 6 patches are mostly preparatory refactoring, with one notable behavior change in patch 4: it modifies how packfiles exceeding "pack.packSizeLimit" are handled by checking object sizes upfront to avoid seek operations. The changes touch core object-file handling and transaction infrastructure across multiple files, including splitting the transaction interface into its own header.

The work appears well-structured and focused, with clean commit separation. As part of a larger architectural effort, it lays groundwork for future transaction improvements rather than delivering user-visible features immediately. The changes are technical but limited in scope, suggesting they're likely to proceed smoothly through review.
