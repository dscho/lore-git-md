This is the third patch in Justin Tobler's series introducing write operations to Git's object database transaction interface, part of the ongoing ODB abstraction effort. The patch refactors blob object writing in packfiles by removing the `INDEX_WRITE_OBJECT` flag check and splitting functionality into separate hashing and writing paths.

In this response to Patrick Steinhardt's review, Justin addresses several technical points:
1. He considers but defers updating the `hash_blob_stream()` helper to use `struct odb_writes_stream` since there's no immediate use case
2. He accepts Patrick's suggestion to improve error checking in `hash_blob_stream()`
3. He notes the initialization of `ret` was a leftover from an earlier iteration and will be fixed
4. He confirms that reaching into files backend details will be addressed in future work
5. He acknowledges the need to improve error handling for ODB transaction commits in a future series

The exchange shows productive technical discussion between two key contributors to the ODB abstraction effort, with Justin incorporating feedback while maintaining a clear vision for follow-up work. The patch appears to be on track for merging as part of this foundational series.
