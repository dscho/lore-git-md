Thread identity: Performance optimization for `git backfill` (experimental partial clone command), patch version 1, RFC status.

Core problem: The `git backfill` command was performing object database preparation even when no objects needed downloading, creating unnecessary overhead. This optimization skips the preparation when the batch is empty.

Current status: First version of the patch, marked RFC to solicit feedback on the testing approach. Changes include skipping `download_batch` for empty batches, adding trace2 instrumentation, and a new test case.
