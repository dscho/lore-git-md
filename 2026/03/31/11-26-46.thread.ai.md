Reftable portability improvements for libgit2 integration - a 6-patch series from Patrick Steinhardt addressing platform-specific dependencies in Git's reftable implementation to enable reuse by libgit2. Core changes introduce cross-platform abstractions: `REFTABLE_INLINE` macro standardizing inline declarations (patch 1/6), `time_ms()` for millisecond timestamps (patch 4/6), and mmap/munmap wrappers via new "reftable-system.h" header. Patch 2/6 removes direct `fsync()` dependency by making synchronization behavior depend solely on caller-provided fsync callback. Patch 3/6 enforces subsystem boundaries by replacing Git's `UNUSED` macro with reftable's `REFTABLE_UNUSED` in fsck.c. Latest patch (4/6) abstracts time measurement by introducing `reftable_time_ms()` using Git's `getnanotime()`, replacing direct `gettimeofday()` calls and simplifying timeout handling in `reftable_stack_reload_maybe_reuse()` through millisecond arithmetic.

Changes remain mechanical and focused on reftable subsystem (`reftable/` directory) with no user-facing impact. Each patch isolates platform dependencies behind reftable-specific abstractions while maintaining identical functionality. Test coverage verified against both Git and libgit2 test suites. This series represents the final step before libgit2 can fully adopt Git's reftable code, completing cross-platform alignment effort that began with earlier shared format standardization. Builds on prior collaboration between Git and libgit2 maintainers (Ed Thomson) to unify implementations. Only test fixes remain after this series merges.
