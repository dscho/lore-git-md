This is the fifth patch in a 6-part series refactoring Git's object database (ODB) write operations to use a transaction interface, part of the ongoing ODB abstraction effort led by Patrick Steinhardt.

The patch generalizes packfile writing to work with a new `struct odb_write_stream` interface rather than directly reading from file descriptors. This allows callers to supply object data from arbitrary sources, not just files. The key changes:

1. Replaces direct file descriptor handling in `stream_blob_to_pack()` with stream operations via the new interface
2. Introduces a helper `read_object_fd()` to adapt file descriptors to the stream interface
3. Updates `index_blob_packfile_transaction()` to accept a stream parameter instead of an fd
4. Modifies `index_fd()` to wrap its file descriptor in the new stream adapter

The changes are preparatory work for future storage backends that may need different data sources. The patch maintains all existing functionality while making the code more flexible. It follows logically from the series' earlier patches that split out transaction handling and optimized packfile writes.

This is a well-structured plumbing change that continues the series' progression from mechanical refactoring toward a more abstract interface. The commit message clearly explains the motivation and technical approach. Reviewers will likely focus on the stream interface design and whether it provides enough flexibility for future needs.
