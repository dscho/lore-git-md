This is the fifth patch in Justin Tobler's 6-part series introducing write operations to Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The patch generalizes packfile write operations to use the `odb_write_stream` interface rather than directly reading from file descriptors.

The key change refactors `index_blob_packfile_transaction()` to accept a `struct odb_write_stream` instead of a file descriptor, allowing callers to supply object data from arbitrary sources. The implementation introduces a helper `read_object_fd()` that adapts the existing file-based input to the new stream interface while maintaining the same behavior. This prepares the codebase for future storage backends that may not use file descriptors.

The patch touches core object-file handling code used by commands like `git add` and `git update-index`. It builds on the previous patches in the series that refactored packfile writing and transaction handling. The change is well-contained and maintains backward compatibility while enabling more flexible data sources for object writing.

This work continues the ODB abstraction effort led by Patrick Steinhardt, with Justin Tobler actively contributing to the object storage layer refactoring. The series shows careful progression from mechanical refactoring to interface generalization, with this patch representing a key step in making the packfile write path more flexible for future backends.
