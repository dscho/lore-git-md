This is a feature patch adding dynamic mailmap toggling to `git cat-file --batch-command`, now finalized for merging after incorporating all review feedback. The patch comes from Siddharth Asthana and addresses GitLab Gitaly's need to control mailmap processing in long-running `git cat-file` processes without restarting them.

The implementation introduces a `mailmap` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) to toggle name/email rewriting on the fly. The mailmap data is loaded lazily and cached in memory for performance. The patch includes comprehensive test coverage in `t/t4203-mailmap.sh` verifying the new functionality's interaction with command-line options and various boolean inputs.

The implementation is cleanly structured with clear separation between boolean handling and mailmap operations.
