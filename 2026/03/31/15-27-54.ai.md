This is a follow-up discussion about merging a commit-graph bugfix that addresses a regression with very large commit dates. Junio Hamano responds to Patrick Steinhardt's request to ensure the fix makes it into the next release candidate.

The patch fixes an underflow issue when writing generation data for commits with timestamps beyond year 2514 (exceeding 34 bits), which could cause crashes. While Junio expresses some discomfort with the approach (preferring a safer but uglier conditional compilation solution), he agrees to mark it for merging into the 'next' branch to prevent the regression from appearing in any release.

This exchange confirms the fix will be included in the upcoming rc0, addressing Patrick's main concern. The discussion highlights the project's careful balance between quick regression fixes and ideal technical solutions, with Junio acknowledging the practical need to ship the fix even if the implementation isn't perfect. The patch is part of ongoing commit-graph subsystem work that has been actively maintained for performance and stability.
