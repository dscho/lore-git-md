This is the first patch in a 6-part series introducing write operations to Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort led by Patrick Steinhardt. The patch is a straightforward refactoring that splits `struct odb_transaction` and related functions out of the main `odb.{c,h}` files into new `odb/transaction.{c,h}` files.

The change is purely organizational - no behavior is modified. The commit message explains this is preparatory work for expanding the transaction interface in subsequent patches. The patch updates all necessary includes across the codebase (affecting commands like `git add`, `git update-index`, and `git unpack-objects`) and adds the new files to build systems (Makefile and meson.build).

This is a clean, mechanical change that follows Git's typical pattern of splitting out functionality into dedicated files as interfaces grow. The patch appears well-structured and properly documented, though as the first in a series, its full context will only become clear when combined with the remaining patches.
