Feature proposal for a new `git whoami` command to display user identity. Giorgos Gasparis suggests adding a built-in command that combines the output of `git config user.name` and `git config user.email` into a single line, addressing a common workflow friction point when switching between work and personal repositories. The functionality is currently achievable through aliases, but the proposal argues this would be more convenient as a native command. The email is clear and well-motivated, though it doesn't address potential edge cases like missing configuration or discuss output formatting in detail. This seems like a straightforward quality-of-life improvement that could benefit many users, though its value would depend on how frequently people actually need to check their active identity in practice.
