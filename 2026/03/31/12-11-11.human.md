Feature addition to `git cat-file`'s batch mode, now ready for merging with all feedback addressed.

Siddharth Asthana's patch implements dynamic mailmap toggling for `git cat-file --batch-command`, solving GitLab Gitaly's need to control name/email rewriting in long-running processes without restarting them. The final version introduces a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) to enable or disable mailmap processing mid-operation.

The implementation is clean and well-tested, with several notable aspects: it uses `git_parse_maybe_bool()` for robust argument handling, maintains mailmap data in memory once loaded, and includes comprehensive tests covering runtime toggling, startup option interactions, and invalid inputs. The changes are contained to `builtin/cat-file.c` and its documentation/tests, with no remaining technical issues.

Reviewers (Junio Hamano, Patrick Steinhardt, Karthik Nayak) have all signed off on the implementation after several rounds of feedback were addressed. The patch appears ready for merging and provides a real-world solution for GitLab's Gitaly service while maintaining good performance through in-memory caching.
