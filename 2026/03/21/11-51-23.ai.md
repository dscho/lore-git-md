This is a patch series for git-gui, Git's graphical user interface, focusing on build system improvements and UI tweaks. The series comes from multiple contributors and has been merged by Johannes Sixt, the git-gui maintainer.

The main changes include:

1. Visual improvement: Wolfgang Faust's patch greys out comment lines in commit messages to make them visually distinct from the actual commit message text. This is a small but useful UI polish.

2. Build system work: Patrick Steinhardt contributes several Meson build system fixes, including proper handling of GIT_CEILING_DIRECTORIES and ensuring the askyesno dialog works correctly with Meson. These changes show ongoing effort to modernize git-gui's build infrastructure.

3. Tabstop adjustment: Chris Idema fixes tabstop positioning in the diff display to properly account for the first column of patch text, improving alignment.

The series touches both the TCL code (for the UI changes) and build system files (Makefile, meson.build). The changes appear focused and well-contained, with the Meson-related work being part of the broader effort to support alternative build systems in Git. The patches have already been merged in the git-gui repository, suggesting they've passed review.
