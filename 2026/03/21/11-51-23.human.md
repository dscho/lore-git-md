This is a maintenance pull request for git-gui, the graphical Git interface, focusing on build system improvements and UI tweaks. The series comes from multiple contributors and has been merged by Johannes Sixt, the git-gui maintainer.

The changes include several Meson build system fixes from Patrick Steinhardt, making git-gui work better when built with Meson rather than the traditional Makefile. These address path handling, shell selection, and properly wiring up the "askyesno" dialog script. There's also a UI improvement from Wolfgang Faust that greys out comment lines in commit messages for better visual distinction, and a patch from Chris Idema adjusting tabstops in the display of patch text.

The changes are straightforward and focused - mostly build system plumbing and minor UI polish. The Meson-related work continues the ongoing effort to modernize Git's build system options, while the UI tweaks are small quality-of-life improvements for git-gui users. As these come from the git-gui maintainer and regular contributors, they're likely to be non-controversial and ready for inclusion.
