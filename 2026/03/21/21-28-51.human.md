This is the second patch in a 3-part series addressing promisor file handling during repacks, part of Lorenzo Pegorari's GSoC work. The patch introduces a helper function `copy_all_promisor_files()` that consolidates the contents of multiple `.promisor` files into a single file when repacking.

The function works by reading all existing `.promisor` files line by line and copying only unique lines to the destination file, avoiding duplicates. The implementation uses file I/O operations with `fseek` to check for existing lines, which the author acknowledges may not be the most efficient approach. The patch touches `pack-write.c` and `pack.h`, adding the new function to the public interface.

This is a technical implementation building on the documentation added in patch 1/3, with the actual repack integration presumably coming in patch 3/3. The author seems aware of potential performance concerns with the current line-by-line checking approach and appears open to feedback on better solutions. The patch looks like a straightforward but unoptimized first pass at solving the problem.
