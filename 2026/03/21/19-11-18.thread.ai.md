The original report from Jo Liss identified the crash occurring in `parse_refspec()` when dereferencing `the_hash_algo` while `the_repository->hash_algo` is NULL, triggered by `git ls-remote -h <url>` with global `remote.origin.fetch` set but no repository. K Jayatheerth's initial fix addressed this by having remote-curl initialize a fallback SHA-1 hash algorithm when operating outside a repository.

This creates a chicken-and-egg problem since the `exact_sha1` flag affects ref prefixes sent to the server.
