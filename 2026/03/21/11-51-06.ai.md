This is a maintenance pull request for gitk, Git's graphical repository browser, focusing on internationalization (i18n) improvements and UI color configuration. The changes come from multiple contributors and have been merged by Johannes Sixt, the gitk maintainer.

The patch series includes several distinct but related to gitk's internationalization support and visual appearance:

1. Jiang Xin contributed three patches that standardize the project name in translation files ("Gitk" instead of "Git"), ignore generated POT files, and update PO file headers to properly identify the gitk project.

2. Johannes Sixt added a commit to strip file location information from translation files (reducing noise in diffs) and merged three branches containing other contributors' work.

3. Shannon Barber's change makes gitk respect Git's `color.decorate.*` config settings for head and tag colors in the UI.

4. Wang Zichong added support for configuring link colors through gitk's Preferences dialog.

The changes touch primarily the `po/` directory (translation files) and the gitk script itself, with minor updates to the Makefile and .gitignore. The translation file changes are largely mechanical removals of location comments that made the files harder to maintain, while the functional changes (colors) are small but user-visible improvements to gitk's configurability.

This appears to be routine maintenance work for gitk, with no particularly controversial changes. The translation file cleanup is a positive step for maintainability, and the color configuration changes align gitk more closely with Git's existing configuration system.
