Git-gui maintenance update with merged changes. This is Junio Hamano's confirmation that he has pulled Johannes Sixt's git-gui updates into the main repository. The changes include:

1. UI polish from Wolfgang Faust that visually greys out comment lines in commit messages, making them more distinguishable from the actual message text.

2. Build system improvements from Patrick Steinhardt, with four Meson-related fixes: better handling of GIT_CEILING_DIRECTORIES, standardizing on /bin/sh, and proper integration of the "askyesno" dialog script with Meson. These continue Git's broader build system modernization efforts.

3. A diff display fix from Chris Idema that adjusts tabstop alignment to properly account for the first column of patch text.

The changes span both the TCL-based UI code and build system files (Makefile and meson.build), with one file renamed and a new meson_options.txt added. All patches were already merged in the git-gui repository before being pulled into Git proper, indicating they've passed maintainer review. This is routine maintenance work on Git's graphical interface component.
