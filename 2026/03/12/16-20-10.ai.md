Feature patch adding a "chronological" preset format for git format-patch cover letters. This is part of a well-reviewed series (now at v8) that introduces configurable cover letter formatting.

The patch adds a new "chronological" preset that displays commits in a simple numbered list format like "[1/3] Subject". This provides a middle ground between the default shortlog format and fully custom formats, making it easier for users to get a clean chronological listing without crafting their own spec. The implementation adds a new `CHRONOLOGICAL` constant with the format string and integrates it into `make_cover_letter()` alongside the existing shortlog and custom format handling.

Documentation is updated to mention the new preset option, and tests verify the output format matches expectations. The change is straightforward and builds on the infrastructure from earlier patches in the series, particularly the `generate_commit_list_cover()` function introduced for custom formats.

This represents the final polish on a feature that has undergone extensive review across eight iterations, with all feedback addressed. The implementation is clean separation of concerns - the chronological format is just another preset that flows through the same code paths as custom formats. The patch maintains the "log:" prefix requirement for custom formats while providing this simpler alternative.
