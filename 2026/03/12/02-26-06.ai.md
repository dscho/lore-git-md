This is the fourth patch in a five-part series introducing AI-assisted workflows for Git's localization (l10n) process, specifically focusing on the JSON format used for batch processing PO files with AI models. The patch documents the GETTEXT JSON format specification that `git-po-helper` uses to interface with AI models for translation tasks.

The key change in this revision is a simplification of the JSON format to unify singular and plural translations under a single `msgstr` array field, eliminating the previous split between `msgstr` (string) and `msgstr_plural` (string array). This reduces redundancy and potential model generation errors. The patch also notes an instruction-following issue with some language models that can be addressed by clarifying the workflow steps.

The documentation includes detailed examples showing both singular and plural translations in the new unified format. The JSON specification covers all PO file elements including header comments, metadata, and entry fields (msgid, comments, fuzzy/obsolete flags). This builds on the series' goal of providing comprehensive tooling for AI-assisted translation while maintaining human oversight and compatibility with existing workflows.

The patch is technically sound and aligns with the series' broader effort to improve translation efficiency (demonstrated metrics show 82% step reduction and 76% time savings in v2). While the format change is a minor refinement, it reflects real-world experience with model behavior and simplifies the interface. The documentation remains thorough, though Jiang Xin notes plans to trim some content in v3 for conciseness.
