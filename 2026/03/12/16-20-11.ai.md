This is the final patch in an 8-iteration series adding configurable cover letter formatting to `git format-patch`. The patch introduces the `format.commitListFormat` configuration option, allowing users to specify their preferred commit list format in the `--cover-letter-format` option without needing to pass it on the command line each time.

The implementation follows the established pattern from earlier patches in the series, with the config value taking precedence when no command-line option is provided. The default remains "shortlog" for backward compatibility. The patch includes comprehensive test coverage verifying the config option works with various format strings, including the new "chronological" preset added in v8.

Documentation updates in both the config and command man pages explain the new option's behavior and its relationship to the CLI flag. The implementation cleanly integrates with the existing config handling in `builtin/log.c`, following the same pattern as other format-patch configuration options.

This represents the culmination of a well-reviewed feature that has addressed all feedback across eight iterations, with Junio C Hamano and other reviewers now satisfied with both the implementation and documentation. The series is ready for merging.
