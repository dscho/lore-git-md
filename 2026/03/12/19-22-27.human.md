This is a refactoring patch in the v5 series improving `git fast-import`'s signature handling capabilities. The patch consolidates signing logic by extending `sign_buffer()` to support default key fallback, replacing the specialized `sign_commit_to_strbuf()` helper.

The change moves the default key fallback logic from commit-specific code into the more reusable `sign_buffer()` function in gpg-interface.c. This prepares for reuse by `git fast-import`'s new `sign-if-invalid` mode while maintaining existing behavior for commit and tag signing. The implementation introduces a `SIGN_BUFFER_USE_DEFAULT_KEY` flag to control the fallback behavior.

The patch appears well-constructed with thorough updates to all call sites. It's part of a larger effort that has gone through multiple review iterations, with this version incorporating feedback to improve the design. The change is focused and mechanical, touching only the signing infrastructure without introducing new functionality.
