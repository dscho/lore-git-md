This is the final patch in Patrick Steinhardt's series to abstract object counting as part of the larger ODB (object database) backend effort. The patch introduces a new public API `odb_count_objects()` to replace the older `repo_approximate_object_count()`, with flags to control whether loose objects should be included in the count (either approximately or exactly).

Toon Claes spotted an outdated comment in odb.h that still references the old function name, which Patrick acknowledges and will fix. The thread shows this work has received thorough review from both Toon and Junio C Hamano, with Junio having already queued the series. This completes an important step in making Git's object storage layer more modular by providing a clean interface for counting objects across different backend implementations.
