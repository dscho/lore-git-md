This is the final patch in Patrick Steinhardt's six-part series completing the ODB (object database) abstraction for object counting functionality. The patch introduces a new top-level `odb_count_objects()` interface that replaces the repository-specific `repo_approximate_object_count()` function.

The change provides a backend-agnostic way to count objects across both packed and loose storage, supporting both approximate (sampling-based) and exact counting via flags. The implementation maintains the existing caching behavior from the old function, though Patrick notes the cache may not be strictly necessary. The patch updates three callers in gc.c, commit-graph.c, and object-name.c to use the new interface.

This is a mechanical refactoring that preserves existing behavior while enabling future pluggable backends. The series has been through two iterations with thorough review from Junio C Hamano and others, addressing all feedback. With this patch, the ODB abstraction effort for object counting is complete - a significant step toward making Git's object storage layer more modular.
