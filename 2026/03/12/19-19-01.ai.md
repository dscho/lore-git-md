Platform compatibility patch fixing the GNU/Hurd build. 

Samuel Thibault reports that GNU/Hurd does not have a PATH_MAX limitation, similar to Windows with long path support. The patch modifies the path length handling in the clar test framework's header file to account for this by adding `defined(__GNU__)` to the condition that already handles Windows long paths. 

The change is minimal - just a single line modification in `t/unit-tests/clar/clar.h` that adds the GNU/Hurd case to share the same 4096-byte path limit as Windows with CLAR_WIN32_LONGPATHS. This appears to be a straightforward platform-specific adjustment to accommodate GNU/Hurd's filesystem behavior. The patch follows the pattern already established for Windows, suggesting it's a well-considered change rather than an ad hoc fix.
