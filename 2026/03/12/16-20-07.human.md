This is the final iteration (v8) of a feature patch series adding configurable cover letter formatting to `git format-patch`. The series has evolved through extensive review and now includes a new "chronological" format preset alongside the existing shortlog-style output.

The implementation provides both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options for selecting cover letter formats. The core changes refactor the cover letter generation code in `builtin/log.c` to support multiple output formats while maintaining backward-compatible shortlog behavior. The documentation has been consolidated into the relevant patches and now includes examples of the new chronological format.

Notable technical details:
- The chronological format presents commits in date order rather than grouping by author
- Numbering uses `decimal_width()` for consistent alignment
- Comprehensive test coverage in t4014 and t9902
- Bash completion support added

The series appears production-ready, with all previous feedback addressed and only minor documentation tweaks remaining. The implementation is cleanly structured, separating format generation from the core cover letter logic. This represents a well-executed addition to Git's patch formatting capabilities that should be straightforward to maintain.
