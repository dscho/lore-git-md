This is part of Patrick Steinhardt's ongoing ODB abstraction effort, specifically the second patch in a six-part series to make object counting functionality pluggable. The patch extracts the packed object counting logic from `repo_approximate_object_count()` into a new standalone function `packfile_store_count_objects()`.

The new function handles both regular packfiles and multi-pack-indexes (MIDX), maintaining the existing counting behavior while making the logic reusable for future backend implementations. The changes are mechanical - the counting algorithm remains the same, just moved to a more modular location. The patch touches packfile.c and packfile.h, adding the new public interface while simplifying the original function to use it.

This is a preparatory step for introducing pluggable object counting interfaces in later patches. The change has already been reviewed in v1, with Toon Claes verifying the MIDX handling details, and Junio C Hamano confirming the approach. The patch appears well-contained and focused on its stated goal of code reorganization without behavior changes.
