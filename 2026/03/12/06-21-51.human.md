This is the final patch in Patrick Steinhardt's 8-part series introducing build system improvements, focusing on adding precompiled header (PCH) support to the Meson build. The patch demonstrates a 40% speedup in full builds by precompiling the frequently-included git-compat-util.h header.

The technical discussion has settled key implementation details, with SZEDER Gábor confirming GCC's PCH behavior and Phillip Wood suggesting (but not insisting on) moving the PCH to a dedicated directory rather than the tools/ location Patrick chose. The series appears ready for merging pending final verification of edge cases like reftable sources and Windows/MSVC compatibility.

The changes are part of two parallel infrastructure efforts: consolidating build tooling into a new tools/ directory and optimizing compilation via PCH. While Junio C Hamano raised a workflow concern about relocating Coccinelle scripts earlier in the series, there don't appear to be any remaining technical blockers to this final PCH implementation.
