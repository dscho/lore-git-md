This is a platform compatibility patch series addressing OpenSSL API modernization in Git's IMAP send functionality.

Junio C Hamano approves the v2 version of Beat Bolli's patch series, which updates OpenSSL API usage while maintaining security checks that were initially removed in v1. The key change is preserving validation for embedded NUL characters in hostnames - a security concern raised by Oswald Buddenhagen in the v1 discussion. The diff shows the explicit NUL check using `memchr()` that was added back in v2, which Junio praises as a clearer way to express the security requirement.

The thread has reached consensus on this approach, with all participants (Bolli, Buddenhagen, and now Hamano) agreeing the validation is necessary despite the API modernization. This appears to be the final approval needed for the series, which carefully balances OpenSSL 3.0+ compatibility with maintaining Git's security posture. The changes specifically target the IMAP send subsystem's SSL certificate verification code.
