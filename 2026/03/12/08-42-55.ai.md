This is the second version of Patrick Steinhardt's six-part series introducing generic object counting interfaces for Git's object database (ODB) abstraction effort. The series replaces `repo_approximate_object_count()` with new `odb_source_count_objects()` and `odb_count_objects()` APIs, completing the ODB abstraction for object counting functionality.

The changes in v2 address review feedback from v1, including:
- Fixing an uninitialized `out` pointer in the loose object counting logic
- Correcting a stale comment in odb.h that still mentioned the old `repo_approximate_object_count()`
- Fixing a typo in a commit message

The series maintains the same structure as v1:
1. Header cleanup (stop including "odb/source.h" where not needed)
2. Extracting packed object counting logic from `repo_approximate_object_count()`
3. Moving loose object counting to object-file.c
4. Generalizing the counting interfaces
5. Introducing the new ODB source counting API
6. Adding the top-level `odb_count_objects()` interface

Reviewers Junio C Hamano and Toon Claes identified several technical points in v1, all of which have been addressed in this revision. The changes affect multiple files including object-file.c, odb/source-files.c, and packfile.c, with callers updated in gc.c, commit-graph.c and object-name.c. The series preserves the existing caching behavior while enabling future pluggable backends.

With all identified issues resolved and Junio having indicated technical soundness, this series appears ready for integration into the ongoing ODB abstraction work. The changes are well-contained and maintain backward compatibility while providing the foundation for future backend implementations.
