This is part 5 of Patrick Steinhardt's 6-part series completing the ODB (object database) abstraction for object counting functionality. The patch introduces a generic `odb_source_count_objects()` API that provides backend-agnostic object counting, replacing the direct `packfile_store_count_objects()` calls.

The new interface:
- Counting objects across both packed and loose storage
- Supporting approximate counting (via sampling) or exact enumeration
- A flags parameter to control counting behavior
- Consistent error handling through return codes

The implementation wires up the counting callback in the files-based ODB backend, combining packed object counts (from MIDX/packfiles) with loose object counts (handled separately in patch 4/6). The change updates `repo_approximate_object_count()` to use this new interface while maintaining identical behavior for existing callers.

This is a key piece of the larger ODB abstraction effort, enabling future pluggable backends to implement their own counting logic. The patch follows the established pattern of the series - mechanical refactoring with careful attention to preserving existing behavior. Review feedback from v1 has been addressed, and Junio C Hamano has already reviewed and approved the technical approach.
