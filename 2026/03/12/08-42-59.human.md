This is part 4 of Patrick Steinhardt's ongoing ODB abstraction series, introducing generic object counting interfaces. The patch generalizes the loose object counting functionality from the previous commit to support both approximate and exact counts via a new flag.

The change replaces `odb_source_loose_approximate_object_count()` with a more flexible `odb_source_loose_count_objects()` that takes flags to control counting behavior. The implementation maintains the existing sampling-based approximation (counting one shard and multiplying by 256) when requested, while adding the ability to perform an exact count by iterating through all objects.

The patch touches core object-file handling code, updating callers in `builtin/gc.c` to use the new interface. This is a well-contained change that builds on the series' earlier work to make object counting more flexible for future ODB backends. The implementation looks clean and maintains all existing behavior while adding the new capability.
