This is the third patch in a four-part series adding configurable cover letter formatting to `git format-patch`. The series is now in its eighth iteration (v8) and appears ready for merging, having addressed all feedback.

The current patch introduces a new "chronological" preset format for cover letters, providing a middle ground between the default shortlog format and fully custom formats. The chronological format simply lists commits with their position in the series (e.g., "[1/3] Subject") without additional metadata. This addresses the concern that requiring users to craft custom formats might be cumbersome for simple needs.

Junio C Hamano confirms the implementation looks good, reiterating that the "log:" prefix requirement (for custom formats) remains important for future extensibility. The patch includes thorough test coverage and documentation updates. The changes are minimal and focused - just adding the new preset format string constant and the conditional logic to handle it.

This continues the series that has been carefully reviewed across eight versions, with the author (Mirko Faina) and reviewers (including Junio and Jeff King) converging on a clean design. The chronological format addition in v8 appears to be the final refinement before the feature is ready for merging.
