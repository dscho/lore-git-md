This is the final version of a GSOC microproject improving the error message when branch switching fails due to uncommitted changes. The patch series has gone through multiple iterations based on maintainer feedback, with this version focusing exclusively on recommending `git stash` rather than the previously considered `git checkout -m` approach.

The patch enhances the error message to provide more specific instructions, now suggesting the exact sequence: `git stash` followed by `git checkout <branch>` and then `git stash pop`. This gives users clear, actionable steps to safely move their changes between branches. The changes affect both the core message in `unpack-trees.c` and update test expectations in `t/t6439-merge-co-error-msgs.sh` and `t/t7406-submodule-update.sh`.

This represents a simplification from earlier versions that had proposed more complex advice infrastructure, showing the contributor's responsiveness to maintainer guidance. The final approach ties into Git's existing advice system through the `advice.commitBeforeMerge` configuration. The patch is cleanly focused and demonstrates the project's preference for clear, safe guidance for users over exposing potentially risky advanced options.
