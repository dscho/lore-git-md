This is a bugfix patch addressing zombie process cleanup in Git's network operations, now approved by Junio C Hamano for merging. The patch ensures proper cleanup of child processes (like git-remote-https and ssh) when Git exits abnormally during network operations, preventing zombie accumulation in containerized environments where Git may run as PID 1.

The solution leverages Git's existing `run-command` infrastructure by setting `clean_on_exit` and `wait_after_clean` flags on child processes in `connect.c` and `transport-helper.c`. This replaces the earlier atexit handler approach that risked deadlocks, following Jeff King's suggestion. The implementation sends SIGTERM first, then waits, ensuring prompt termination of children.

Junio notes two minor formatting issues with the patch: an unwanted blank line in the trailer block and inclusion of Copilot's Co-authored-by line (which shouldn't appear in final submissions). These are documentation/process nits that don't affect the technical solution, which Junio describes as "quite simple and clean". The patch is now ready for merging with these minor adjustments.
