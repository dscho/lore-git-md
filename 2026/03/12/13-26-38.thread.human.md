Here's the updated human-readable thread summary:

This thread explores a proposal to unify conflict resolution in `git checkout` and `git switch` by replacing the three-way merge behavior (`-m` flag) with automatic stashing when switching branches. Harald Nordgren's v3 patch series implements maintainer-suggested flag unification but now faces a critical challenge: the current autostash approach doesn't properly handle submodules, which were previously supported by the three-way merge.

Junio Hamano has reviewed the latest implementation and provided detailed feedback on documentation and messaging. He supports the technical direction but wants improvements to the user experience: clearer commit messages explaining this is now a `checkout -m` improvement rather than just autostash addition, more precise documentation about when `-m` applies, and better conflict marker labels that preserve branch name context. He also suggests suppressing stash creation messages until actually needed and splitting out some preparatory changes.

The main outstanding issue remains submodule support - either `git stash` needs to learn submodule handling, or the implementation needs adjustment to preserve submodule update capabilities. Phillip Wood originally flagged this concern, and the discussion now focuses on resolving it while maintaining the unification benefits. The patch appears headed toward acceptance once these final issues are addressed.
