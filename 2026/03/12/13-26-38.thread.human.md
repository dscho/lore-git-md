Harald Nordgren's patch series to add conditional stashing to `git checkout` and `git switch` has progressed to version 3, implementing Junio Hamano's suggestion to unify the `-m` and `--autostash` behaviors. The approach replaces the three-way merge implementation with autostash-based conflict resolution while maintaining backward compatibility, with expanded test coverage and documentation updates.

Phillip Wood has raised important technical concerns about edge cases with submodules. He points out that the current implementation would break submodule handling during branch switches, since `git stash` doesn't support `--recurse-submodules` while the existing `checkout -m` behavior does. Phillip suggests either extending stash to handle submodules (which would require storing submodule states within parent stash commits) or finding an alternative approach to preserve this functionality.

The discussion is now focused on resolving this submodule edge case while maintaining the core goal of intelligent conflict detection during branch switching. Once this is addressed, the series appears ready for final review and potential merging. The thread has seen productive collaboration between the author (Harald), the maintainer (Junio), and domain experts like Phillip Wood who are helping refine the implementation details.
