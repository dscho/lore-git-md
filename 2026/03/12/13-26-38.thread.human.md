Harald Nordgren's patch series to enhance `git checkout -m` with autostash behavior has reached its final form after eight iterations. The series introduces unified conflict resolution by integrating autostash functionality, adds customizable conflict marker labels (including support for empty labels), and implements silent autostash creation. Key changes touch `builtin/checkout.c`, `builtin/stash.c`, and the sequencer internals, with new functions like `apply_autostash_ref_with_labels()` providing the core functionality.

The series received thorough review from Phillip Wood and maintainer input from Junio C Hamano. All technical concerns have now been resolved, including the final two items addressed in this latest exchange: Harald reverted an unnecessary stdout-to-stderr message change and converted a `silent` parameter from integer to boolean type for clarity. With these last tweaks made and all open questions settled, the series is fully ready for merging. The implementation maintains backward compatibility while providing new flexibility for both interactive and scripted workflows.
