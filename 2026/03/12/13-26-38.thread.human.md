This patch series, now in its ninth iteration, enhances `git checkout -m` with autostash behavior and adds customizable conflict marker options to `git stash apply`. Authored by Harald Nordgren with extensive review from Phillip Wood and maintainer Junio Hamano, the changes make branch switching with uncommitted changes more robust while maintaining backward compatibility.

The implementation introduces new label options (`--label-ours`, `--label-theirs`, `--label-base`) standardized across both commands, supports empty labels for scripting use, and adds silent autostash creation for non-interactive contexts. The changes touch multiple components including the checkout and stash commands, sequencer, and xdiff merge logic. After thorough review of technical details like boolean parameter typing and output stream behavior, Junio has confirmed the series is ready for merging.

With 19 comprehensive test cases covering various conflict scenarios and edge cases, the series represents a significant quality-of-life improvement for developers. All feedback from the nine review rounds has been addressed, and there are no remaining open questions. The changes will be particularly valuable for workflows involving frequent branch switching with uncommitted changes.
