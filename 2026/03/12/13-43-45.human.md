This is a test infrastructure patch from Junio C Hamano that follows up on earlier discussion about modernizing sed usage in Git's test suite. The patch allows the `-E` flag (for extended regular expressions) in `check-non-portable-shell.pl`, bringing the linter in line with POSIX Issue 8 standards from 2018.

The thread shows consensus that this change is reasonable, with Ramsay Jones catching a minor documentation mismatch in the linter's error message (now fixed in v2) and brian m. carlson providing historical context about platform support. Patrick Steinhardt weighed in to confirm the approach, though they considered but rejected making the linter more strict about flag parsing.

The change is small and focused - it updates the linter script and one test file (`t6030-bisect-porcelain.sh`) while maintaining Git's standards-compliance. Junio notes this originated from noticing the linter flagging a recent test rewrite, though he acknowledges the change could have gone either way (updating the linter vs. rewriting tests to avoid `-E`). The patch appears ready for merging as part of Git's ongoing test infrastructure maintenance.
