This is a feature patch adding a new "chronological" preset format for Git's cover letter generation, part of a larger series (v8 3/4) that introduces configurable cover letter formatting. The patch provides a simple alternative to custom format strings, showing commits in a numbered list format like "[1/3] Commit subject".

The implementation adds a new `CHRONOLOGICAL` constant with a fixed format string and teaches `make_cover_letter()` to recognize this preset. The documentation is updated to mention the new option alongside the existing "shortlog" format. A new test case verifies the chronological output format works as expected.

This comes after extensive discussion (8 iterations) where the series has already addressed all technical feedback and documentation suggestions. The patch is well-contained, with clean separation from the refactored shortlog generation code (handled in patch 1/4 of the series). The implementation follows the project's established patterns for format handling and includes appropriate test coverage.

The patch appears ready for merging as part of the complete series, which has received approval from Junio Hamano and other key reviewers. The chronological format provides a useful middle ground between the default shortlog output and fully custom formats.
