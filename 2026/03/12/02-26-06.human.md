This is the fourth patch in a five-part series introducing AI-assisted workflows for Git's localization (l10n) process, focused on the documentation of the GETTEXT JSON format used for batch processing translations.

Jiang Xin proposes two refinements to the JSON format documentation in po/AGENTS.md. First, they suggest unifying the msgstr representation to always use an array (even for singular forms) to reduce redundancy and model confusion. Second, they note that some AI models incorrectly skip the verification loop, and propose clarifying the step numbering to prevent this.

The changes are straightforward and address practical issues observed during testing. The JSON format unification in particular seems like a sensible simplification that maintains all necessary information while reducing complexity for AI models processing the data. These appear to be incremental improvements based on real-world usage of the system described in earlier patches.

The patch maintains the series' focus on making AI-assisted translation both efficient (with benchmarked improvements) and reliable (with clear instructions and validation steps). As with the rest of the series, human oversight remains central to the process despite the automation.
