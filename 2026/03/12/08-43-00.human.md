This is part 5 of Patrick Steinhardt's series to abstract Git's object counting functionality as part of the larger ODB (object database) abstraction effort. The patch introduces a new generic `count_objects` callback for ODB sources, which combines packed and loose object counts while respecting the `ODB_COUNT_OBJECTS_APPROXIMATE` flag to toggle between exact and sampling-based counting.

The change builds on previous patches that extracted packed object counting into `packfile_store_count_objects()` and loose object counting into `odb_source_loose_count_objects()`. This patch wires them together through a new interface that will allow future pluggable backends to implement their own counting logic. The implementation maintains existing behavior while making the counting infrastructure more flexible.

The patch touches core object storage code in odb/source-files.c and related headers, updating the packed object counting call in repo_approximate_object_count() to use the new interface. This is a well-structured change that fits cleanly into the ongoing ODB abstraction work, with no behavior changes for existing callers. The series has already been reviewed by Junio C Hamano and others, with all feedback from v1 addressed in this iteration.
