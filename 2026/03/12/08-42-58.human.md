This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort, specifically focusing on object counting functionality. The patch relocates the loose object counting logic from `builtin/gc.c` to `object-file.c` as part of preparing for pluggable ODB backends.

The change extracts the existing heuristic for approximating loose object counts (which scans just one shard directory and multiplies by 256) into a new `odb_source_loose_approximate_object_count()` function. This maintains the same behavior while making the logic reusable across different ODB backends. The patch is mechanical with no functional changes - it just moves code to a more appropriate location in preparation for future work.

This is the third patch in a six-part series that has already been reviewed in v1 and updated based on feedback. Junio C Hamano has confirmed the technical approach is sound. The series is part of a larger architectural effort to make Git's object storage layer more flexible.
