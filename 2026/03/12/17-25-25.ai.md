This is a final review comment from Junio C Hamano on the cover letter formatting feature series, specifically addressing the removal of the "log:" prefix requirement in v8. The discussion centers on whether format names should be prefixed with "log:" to prevent ambiguity and typos.

Junio strongly objects to removing the "log:" prefix, arguing it provides important future-proofing against typos (like "chrnological") and ensures clear namespacing for potential future format additions. He considers this a fundamental design issue, not just a stylistic preference, and states plainly that dropping the prefix is "a bad idea, period."

The author (Mirko Faina) had previously defended removing the prefix in v7, comparing it to other unmerged features that wouldn't work across Git versions. Junio counters that the prefix provides valuable error detection that would catch both typos and attempts to use formats from future Git versions.

This represents the final design decision point in an otherwise complete and well-reviewed series that has already been merged to 'next'. Junio's position here is authoritative as the maintainer, suggesting the prefix requirement should be reinstated despite the series' advanced state. The exchange highlights Git's emphasis on long-term maintainability considerations even for seemingly small interface details.
