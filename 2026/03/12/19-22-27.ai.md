This is a refactoring patch in the v5 series expanding `git fast-import` signature handling capabilities. The patch consolidates signing infrastructure by extending `sign_buffer()` to support default key fallback behavior, replacing the commit-specific `sign_commit_to_strbuf()` helper.

The key change moves the default key fallback logic from `sign_commit_to_strbuf()` in commit.c into `sign_buffer()` in gpg-interface.c, introducing a new `SIGN_BUFFER_USE_DEFAULT_KEY` flag. This makes the signing functionality more generic and reusable across different contexts, including the upcoming fast-import signature handling.

The patch updates all existing callers to use the new flag-based API:
- `builtin/tag.c` and `send-pack.c` continue using explicit keys (flag=0)
- `commit.c` now uses the default key fallback (flag=SIGN_BUFFER_USE_DEFAULT_KEY)

The implementation is clean and maintains backward compatibility while enabling the new fast-import functionality in subsequent patch 3/3. The changes are well-contained, touching only the necessary files with straightforward updates to call sites.
