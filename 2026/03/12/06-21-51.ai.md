This is the final patch in Patrick Steinhardt's 8-part series introducing build system improvements, focusing on implementing precompiled header (PCH) support for `git-compat-util.h` in the Meson build. The patch demonstrates a 40% speedup in full builds by precompiling the 23,000-line header that's included in nearly every compilation unit.

The technical implementation uses Meson`'s c_pch option with `-include` to force PCH inclusion, validated by SZEDER Gábor's confirmation of GCC's PCH behavior with nested includes. Phillip Wood raised a minor concern about the PCH file location (currently in `tools/`), suggesting a dedicated `pch/` directory might be more appropriate. Patrick acknowledges this but considers `tools/` an acceptable location given it already houses build infrastructure.

The patch builds on prior work in the series that relocated build scripts to `tools/`, modified `git-compat-util.h` for PCH compatibility, and reorganized platform-specific sources. While functionally complete, there remain open questions about PCH behavior with reftable sources (which deliberately avoid `git-compat-util.h`) and potential workflow impacts from the Coccinelle relocation that Junio noted earlier in the thread. The changes maintain cross-platform compatibility while delivering measurable performance benefits.
