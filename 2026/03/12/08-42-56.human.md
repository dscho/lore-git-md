This is part 1 of Patrick Steinhardt's six-part series completing the ODB (object database) abstraction for object counting functionality. The patch focuses on header cleanup, specifically reversing the include relationship between "odb.h" and "odb/source.h" to better reflect their logical hierarchy.

The change moves enum and typedef definitions that belong to the generic ODB interface from "odb/source.h" back into "odb.h", while adding explicit includes of "odb/source.h" to the few files that actually need it. This makes the header structure more intentional - most callers shouldn't need to know about the internal `struct odb_source` details. The change was suggested by Justin Tobler during review of the v1 series.

This is a straightforward refactoring that doesn't change behavior, just code organization. It touches several files that interact with the ODB system but is mechanically simple. The patch is part of a larger effort to enable pluggable object storage backends by properly abstracting the ODB interfaces.
