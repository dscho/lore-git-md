Junio C Hamano responds to Harald Nordgren's patch adding `--autostash` support to `git checkout` and `git switch`. While acknowledging the usefulness of automatic stashing during branch switches, Junio suggests a more sophisticated approach than the unconditional stashing proposed in the patch.

He outlines an alternative design that would only stash when necessary - specifically when there are local changes that would conflict with the target branch. This would make the feature more like an improved version of the existing `-m` (merge) option, with several advantages: cleaner merges when possible, preserved work when conflicts occur, and better user control over conflict resolution. Junio also speculates that the underlying detection logic could be reused to improve `git rebase`'s handling of local changes.

The response indicates the patch in its current form may be too simplistic, but provides constructive direction for evolving the concept into a more robust solution. Junio's feedback suggests the feature has merit but needs refinement to align with Git's existing paradigms and provide maximum user benefit.
