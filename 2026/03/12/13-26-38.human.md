This is a feature patch adding `--autostash` support to `git checkout` and `git switch`, bringing them in line with similar functionality already available in `git rebase` and `git merge`. The patch introduces both command-line options (`--autostash`/`--no-autostash`) and a `checkout.autoStash` configuration setting.

The implementation automatically creates a temporary stash before branch switching and applies it afterward, allowing users to switch branches with uncommitted changes. If conflicts occur during stash application, the changes are preserved in the stash for later resolution. The patch includes comprehensive tests covering various scenarios: dirty worktrees, staged changes, conflicts, config overrides, and combinations with other flags like `--merge` and `--force`.

The change appears well-considered, with thorough test coverage and clear documentation updates. The implementation reuses existing autostash infrastructure from the sequencer rather than reinventing the wheel. This seems like a natural extension of Git's existing autostash capabilities that could improve workflow for users who frequently switch branches with uncommitted changes.
