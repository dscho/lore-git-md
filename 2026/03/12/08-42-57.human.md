This is part 2 of Patrick Steinhardt's six-part series completing the ODB abstraction for object counting functionality. The patch extracts the packed object counting logic from `repo_approximate_object_count()` into a new standalone function `packfile_store_count_objects()`. 

The change is a mechanical refactoring with no behavior change, preparing for the introduction of pluggable object counting backends in later patches. The new function handles both regular packfiles and multi-pack-indexes, with the latter being a point Toon Claes specifically reviewed in the v1 iteration. 

This is part of the larger ODB abstraction effort to make Git's object storage layer more modular. The patch touches core packfile handling code and introduces a new public API in packfile.h, but is otherwise straightforward infrastructure work that has already been reviewed and queued by Junio.
