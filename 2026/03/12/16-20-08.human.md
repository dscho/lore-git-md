This is the first patch in a final (v8) series implementing configurable cover letter formatting for `git format-patch`. The patch performs a pure refactoring - it extracts the shortlog-based cover letter generation code from `make_cover_letter()` into a new `generate_shortlog_cover_letter()` function.

The change is straightforward and mechanical, with no behavior modifications. It prepares the codebase for subsequent patches that will introduce customizable formatting options while maintaining backward compatibility with the existing shortlog output. The patch follows Git's style well, keeping the same indentation and line wrapping behavior in the new function.

This is part of a well-reviewed series that has gone through eight iterations and is now ready for merging. The overall feature will allow users to customize cover letter formatting through both command-line options and configuration settings while preserving the current default shortlog output.
