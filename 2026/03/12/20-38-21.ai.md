Maintainer response to a platform compatibility patch for the clar test framework.

Junio C Hamano acknowledges Samuel Thibault's patch fixing the GNU/Hurd build by adding `defined(__GNU__)` to the path length handling in clar.h. He suggests the change might be better handled upstream in the clar framework first before being imported into Git, and proposes a more general reorganization of the path length definitions that could be considered by the clar maintainers. 

The maintainer signs off on the patch (adding his Signed-off-by) while indicating he'll forward it to the clar project. The actual code change remains the same one-line modification to include GNU/Hurd systems alongside Windows in using a 4096-byte path limit when CLAR_WIN32_LONGPATHS is defined. This appears to be a routine platform-specific adjustment that follows established patterns, though Junio's comment suggests there may be future discussion about restructuring this part of the test framework more broadly.
