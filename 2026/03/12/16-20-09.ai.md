This is a feature patch (part 2/4 of a series) that adds customizable cover letter formatting to `git format-patch`. The patch introduces:

1. A new `--cover-letter-format` option that accepts either "shortlog" (the current default) or a custom format string prefixed with "log:". The format can use new `%(count)` and `%(total)` placeholders for patch numbering, with `%(count)` being zero-padded to match `%(total)`'s width.

2. The core implementation in `builtin/log.c` with a new `generate_commit_list_cover()` function that handles custom formats, while keeping the existing shortlog generation in a separate function. The patch maintains backward compatibility while adding flexibility to format patch lists in cover letters. Example usage shows how to create numbered patch lists like "[1/3] Commit summary (Author)".

The implementation includes thorough test coverage in t4014-format-patch.sh and bash completion support. Documentation updates explain the new option and format placeholders. This is part of a well-reviewed series that has gone through 8 iterations, with the design decisions around numbering and format validation now finalized.

Key technical details for future reference:
- New functions: `generate_commit_list_cover()`
- Modified functions: `make_cover_letter()`
- New placeholders: `%(count)`, `%(total)` in `pretty.c`
- CLI option: `--cover-letter-format`
- Tests: new cases in t4014 and t9902
- Documentation: updates to git-format-patch.adoc

The patch cleanly separates the new functionality while maintaining the existing shortlog output as the default, providing a clear migration path for users who want more control over cover letter formatting.
