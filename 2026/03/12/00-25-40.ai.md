This is a platform compatibility patch series addressing OpenSSL API modernization for Git's IMAP send functionality. Junio C Hamano approves the v2 changes from Beat Bolli that preserve security checks while updating deprecated OpenSSL calls.

The key change in this final approval is the explicit preservation of embedded NUL character checks in the hostname validation logic. The patch now uses `memchr()` to scan for NUL bytes in the ASN1 string data before proceeding with wildcard matching, maintaining the security boundary that was debated in earlier rounds. Junio notes this makes the security check more explicit and clearer in its intent.

This concludes the thread with consensus reached - all participants agree the v2 series successfully modernizes the OpenSSL API usage (targeting 3.0+ while maintaining 1.1.0 compatibility) without compromising the security checks that Oswald Buddenhagen had identified as essential in the v1 review. The implementation now properly handles both the API deprecation warnings and the embedded NUL edge case that could have allowed certificate validation bypass.
