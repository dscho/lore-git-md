This is the final patch in Patrick Steinhardt's six-part series completing the ODB abstraction for object counting functionality. The patch introduces a new top-level `odb_count_objects()` interface that replaces the repository-specific `repo_approximate_object_count()` function.

The new API provides a generic way to count objects across all ODB backends while maintaining the existing caching behavior. The implementation preserves the approximate counting approach (sampling loose objects rather than enumerating them) but makes it configurable via flags, with `ODB_COUNT_OBJECTS_APPROXIMATE` matching the old behavior. The patch updates three callers in gc.c, commit-graph.c, and object-name.c to use the new interface.

Key technical details:
- The cache now includes the flags as part of its key to handle different counting modes
- Error handling is improved - callers must now check return values
- The old `repo_approximate_object_count()` function is removed entirely
- Related cache fields in `struct object_database` are renamed for clarity

This completes the series' goal of abstracting object counting behind the ODB interface, enabling future pluggable backends. The changes are mechanical refactorings with no intended behavior changes for existing callers. Junio C Hamano has reviewed and approved the technical approach in previous iterations.
