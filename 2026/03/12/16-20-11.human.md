This is the final patch in an 8-iteration series adding configurable cover letter formatting to `git format-patch`. The patch introduces the `format.commitListFormat` configuration option, allowing users to specify their preferred commit list format in the `--cover-letter-format` option without needing to pass it on the command line each time.

The implementation follows the established pattern for Git config options, with the config value taking precedence over the default "shortlog" format but being overridden by any explicit command-line `--cover-letter-format` option. The patch includes comprehensive tests verifying the config behavior with different format strings and special cases like the new "chronological" preset format added in v8.

Documentation updates explain the config option's behavior and relationship to the command-line option, following Junio C Hamano's final suggestions. The implementation is cleanly integrated with the existing cover letter generation code and maintains backward compatibility.

This patch represents the culmination of a well-reviewed feature that has addressed all feedback across eight iterations, with the config interface design decisions (including empty-value handling) now finalized per Junio's preferences. The series is ready for merging with its comprehensive test coverage and documentation.
