This is a feature patch adding `--autostash` support to `git checkout` and `git switch`, bringing them in line with similar functionality already present in `git rebase` and `git merge`. The patch comes with thorough documentation updates and comprehensive test coverage.

The change allows users to automatically stash local modifications when switching branches, then reapply them after the switch completes. A new `checkout.autoStash` config option enables this behavior by default, with command-line flags (`--autostash`/`--no-autostash`) available to override it. The implementation handles various edge cases including dirty index, conflicting changes, and clean worktrees.

The patch touches multiple components:
- Adds config documentation in `Documentation/config/checkout.adoc`
- Updates man pages for both commands
- Modifies `builtin/checkout.c` to implement the logic
- Adds a new test file `t/t2061-switch-autostash.sh` with 12 test cases
- Updates shell completion script

The implementation appears well-considered, building on existing autostash infrastructure from the sequencer. The test coverage is particularly thorough, verifying behavior with dirty worktrees, staged changes, conflicts, and various flag combinations. This looks like a polished contribution that fills a clear gap in functionality while maintaining consistency with Git's existing autostash behavior.
