This is the final approval for a bugfix addressing zombie processes in containerized Git operations. Junio C Hamano has queued Andrew Au's v4 patch after it received technical approval from Jeff King and addressed documentation formatting issues raised in earlier versions.

The patch fixes a specific issue where network helper processes (like git-remote-https and ssh) would become zombies when Git exits abnormally in container environments. The solution leverages Git's existing `run-command` infrastructure by setting `clean_on_exit` and `wait_after_clean` flags in three key locations where child processes are spawned for network operations. This ensures proper cleanup via SIGTERM-then-wait during any exit path, avoiding both zombie accumulation and potential deadlocks.

The change is minimal (6 lines total) and focused exclusively on transport-layer processes, maintaining the agreed scope from earlier discussion. With all technical concerns resolved and documentation issues fixed, this patch is now on track for inclusion in the next release.
