This thread discusses a platform compatibility issue affecting Git's test framework on GNU/Hurd systems, which - like Windows with long path support - don't impose PATH_MAX limitations. The discussion began with a proposed one-line modification to Git's copy of the clar test framework to handle long paths on GNU/Hurd similarly to how it's done for Windows.

Samuel Thibault discovered that Pino Toscano had already contributed a similar fix to the upstream clar framework in December 2023, making the Git-side patch redundant. Samuel also submitted a pull request to clar's README to improve project discoverability for future contributors. 

Junio C Hamano weighed in, acknowledging that this validates Git's "upstream first" approach and expressing appreciation for Samuel's README improvement. The thread demonstrates Git's careful coordination with external projects during test infrastructure updates, particularly for cross-platform issues. With the needed fix already in upstream clar, no further Git-side changes appear necessary. Patrick Steinhardt's role as a liaison between the Git and clar projects was key in facilitating this smooth resolution.
