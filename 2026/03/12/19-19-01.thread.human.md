This thread discusses a platform compatibility fix for the clar test framework to properly handle path lengths on GNU/Hurd systems which, like Windows, don't impose PATH_MAX limitations. The initial patch from Samuel Thibault adds GNU/Hurd to share Windows' CLAR_WIN32_LONGPATHS behavior in `t/unit-tests/clar/clar.h`.

Junio C Hamano signed off on the patch but suggested the change might be better handled upstream in the clar framework first, proposing a more general reorganization of path length definitions. Patrick Steinhardt, who is involved with both projects, has now responded agreeing with Junio's approach. He's invited Samuel to submit a pull request to the clar project's GitHub and offered to review it, with plans to subsequently handle the Git integration.

The discussion shows this small platform adjustment may lead to broader improvements in how clar handles path lengths across platforms. The Git project appears likely to wait for the upstream clar change before incorporating it, continuing their careful coordination with the clar project during test modernization efforts. While the immediate fix is straightforward, the maintainers are using it as an opportunity to improve the framework's cross-platform design more generally.
