This is the second version of Patrick Steinhardt's patch series completing the ODB abstraction effort for object counting functionality. The series introduces generic counting interfaces through new `odb_source_count_objects()` and `odb_count_objects()` APIs to replace `repo_approximate_object_count()`.

The v2 iteration addresses several minor issues found in review: it properly initializes an output pointer when counting loose objects, fixes a stale comment referencing the old API, and corrects a commit message typo. The changes maintain the series' core technical approach while polishing the implementation details.

The work affects several key areas of Git's object storage layer, including `object-file.c`, `odb/source-files.c`, and `packfile.c`, with updates to callers in `gc.c`, `commit-graph.c` and `object-name.c`. Junio Hamano and Toon Claes provided thorough reviews of the v1 series, with all identified issues now addressed. The changes appear technically sound and ready for integration, marking the completion of ODB abstraction for object counting functionality - an important step toward enabling future pluggable backends.
