Abraham Samuel Adekunle has proposed a Google Summer of Code (GSoC) project to implement prioritized fetching from multiple promisor remotes in Git's partial clone feature. The proposal would add configuration options to specify remote priorities and extend the promisor-remote protocol to allow server-side priority recommendations. This builds on Christian Couder's existing work and addresses real performance needs for users of partial clones.

After three iterations of the proposal, with technical details worked out in earlier discussions, Christian Couder has now confirmed the proposal is ready for formal GSoC submission. With the submission deadline approaching, Christian advised Abraham to submit the current version without further review cycles. The student has demonstrated codebase familiarity through prior contributions (including work on `git add -p`) and the project remains well-scoped with clear benefits, though integrating the new priority logic with Git's existing fetch machinery will be the main technical challenge. The thread has now concluded its pre-submission phase.
