This is a build system modernization patch, part of Patrick Steinhardt's RFC series to begin deprecating autoconf in favor of Meson. The patch updates the INSTALL file to recommend Meson as the preferred build system instead of autoconf, reflecting the project's direction toward Meson adoption.

The changes are straightforward - replacing autoconf/configure instructions with their Meson equivalents in the installation documentation. The patch maintains the same structure and flow while updating the specific commands. This aligns with the series' goal of signaling intent to deprecate autoconf, targeting removal in Git 2.55 (~1.5 years out).

As the first of two RFC patches, this focuses on documentation rather than functional changes. It follows established consensus from previous discussions about moving to Meson, with open questions primarily around timing and packager readiness rather than technical objections. The minimal nature of this change suggests it's meant to start the conversation about concrete steps toward deprecation while giving downstream consumers visibility into the planned transition.
