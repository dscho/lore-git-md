This is a refactoring patch in the fsmonitor series, specifically addressing platform-specific settings logic for Unix systems. The patch responds to review feedback from Patrick Steinhardt about code organization in the filesystem monitoring implementation.

The changes move the Makefile wiring for `fsm-ipc` into the previous commit (patch 5) where the IPC renaming happens, keeping this commit focused purely on the settings logic. It also introduces the `fsmonitor_os` variable earlier in the series to avoid code churn. The author has dropped incidental changes and blank line modifications that were flagged in review, making this a cleaner mechanical change.

This patch is part of the larger effort to unify Unix platform handling in fsmonitor, following the earlier renaming of `fsm-ipc-darwin.c` to `fsm-ipc-unix.c`. The series is currently in Junio's 'seen' branch and appears stable in production use, with this patch addressing the last remaining organizational concerns from reviewers. The only open questions now relate to test reliability and event delivery timing, which are being investigated separately.
