This is a performance optimization patch in Patrick Steinhardt's series reducing write syscalls in `git-upload-pack`. The patch refactors `send_sideband()` in `sideband.c` to use `writev()` for sending pktlines, combining what were previously two separate `write()` calls (one for the header, one for data) into a single syscall. The change cuts the number of syscalls roughly in half (from ~133k to ~67k in the test case).

The implementation uses the new writev_or_die()` infrastructure introduced earlier in the series, with proper handling of both banded and non-banded packet headers. Junio C Hamano has reviewed the change and finds it straightforward" and "looking good", suggesting it's likely to be accepted. The patch maintains all existing functionality while improving performance under high concurrency by reducing kernel contention.

This is part of a larger effort to optimize Git's I/O patterns, particularly in server-side operations like `upload-pack`. The series has already addressed several rounds of feedback, including platform compatibility concerns and integer overflow protection in the writev() wrappers.
