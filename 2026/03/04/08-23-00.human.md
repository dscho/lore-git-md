This is a build system patch proposing the first steps in deprecating autoconf in favor of Meson. Patrick Steinhardt, who has been driving the Meson transition, sends this RFC to update the INSTALL documentation to recommend Meson over autoconf. The change is purely documentation at this stage, modifying the build instructions while keeping the actual autoconf infrastructure intact.

The patch is part of a 2-patch series that aims to signal intent to remove autoconf support in Git 2.55 (roughly 1.5 years out). This first patch focuses on user-facing documentation, while the second will add deprecation warnings to configure.ac. The approach shows awareness of downstream impact, leaving room for timeline adjustments based on packager feedback.

The change itself is straightforward - replacing autoconf commands with their Meson equivalents in the INSTALL file. The patch follows established consensus from previous discussions about moving to Meson, which has already been integrated into the codebase. While technical changes are minimal here, this marks an important step in the build system modernization effort.
