This is a feature patch implementing Linux filesystem monitoring (fsmonitor) using inotify, part of a larger series to bring Linux support to parity with existing Windows and macOS backends. The patch adds path utilities for Linux, including filesystem type detection and mount point resolution.

Patrick Steinhardt raises several technical questions about the implementation details. He notes that the `HAVE_LINUX_MAGIC_H` define needs to be properly wired up in both Makefile and Meson builds. He questions the filesystem type name function's selective coverage (which includes network filesystems but not common local ones like ext4) and suggests better documentation is needed.

The most substantive feedback concerns the mount point finding logic - Patrick doesn't understand why the code scans `/proc/mounts` when `statfs()` should already provide the needed information. This suggests either redundant work or an unstated requirement that isn't obvious from the current implementation. The patch appears technically sound but these questions about design choices will need to be addressed before final acceptance.
