Git GSoC proposal for prioritized fetching from multiple promisor remotes. Proposed by Abraham Samuel Adekunle, who has prior merged contributions (including to `git add -p`). The project would:

1. Add client-side `remote.<name>.priority` configuration to specify preferred fetch order
2. Extend promisor-remote protocol to let servers advertise recommended priorities
3. Implement client logic to choose between server-suggested priorities, local priorities, or config order

Builds on Christian Couder's promisor-remote advertisement work. Includes detailed 3.5-month timeline with implementation phases. Technical challenge will be clean integration with existing fetch machinery. Well-scoped project addressing real performance/cost optimization needs in partial clone scenarios.
