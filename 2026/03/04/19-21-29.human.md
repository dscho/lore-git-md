This is a bugfix series addressing an interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The issue causes crashes when processing renamed files, stemming from a 2019 regression where diffcore_pickaxe() discards diff pairs needed by line-log's rename detection.

The two-patch series takes a phased approach. The first patch fixes the crash by bypassing diffcore_std() and calling diffcore_rename() directly during line-log processing, restoring the pre-regression behavior where pickaxe options were silently ignored. The second patch improves the user experience by actively rejecting this unsupported combination with an error message rather than silently ignoring it.

Changes span line-log.c, builtin/log.c and the test suite. The implementation is clean and focused, with comprehensive tests covering both the crash scenarios and the new error behavior. The series appears ready for merging, having addressed both the technical issue and the UX problem of silent misbehavior.
