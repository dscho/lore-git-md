Bugfix for promisor-remote preventing recursive lazy-fetch during index-pack operations.

Paul Tarjan addresses a recursive fetch problem where `fetch_objects()` spawns a child `git fetch` that could itself spawn additional fetches when processing thin packs with missing REF_DELTA bases. This could lead to unbounded recursion and resource exhaustion, which the author observed in production with 276GB of promisor packs being created in 90 minutes.

The fix is straightforward: propagate the existing `GIT_NO_LAZY_FETCH=1` environment variable to the child fetch process, preventing it from recursing. The patch includes a test that verifies both the environment variable propagation and that only one fetch subprocess is spawned.

This follows the same pattern as a 2022 fix by Han Xin for a similar issue in commit-graph lookups. The change is minimal (a single line adding the environment variable) but important for stability in partial clone scenarios where the server may send thin packs with references to missing objects. The accompanying test provides good coverage of both the behavioral and environmental assertions.
