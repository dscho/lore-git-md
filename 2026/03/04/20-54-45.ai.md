This is a technical follow-up in Patrick Steinhardt's ongoing object database (ODB) abstraction effort. The patch makes the ODB source freeing mechanism pluggable by introducing a callback function in `struct odb_source`.

Justin Tobler's review of patch 6/17 in the series notes the conversion of the files backend's free operation to use the new callback pattern. The changes move responsibility for type downcasting into each backend's implementation while maintaining type safety through the existing `odb_source_files_downcast()` mechanism. The review highlights several positive aspects: the removal of now-unneeded forward declarations, the generic handling of source freeing in the base ODB code, and the clear documentation of callback expectations.

This patch represents a typical step in the ODB abstraction work - converting a previously hardcoded files-backend operation into a pluggable interface while preserving existing behavior. Justin's review confirms the technical soundness of the approach without raising any concerns, suggesting this piece of the larger refactoring is proceeding smoothly. The changes touch key ODB infrastructure files (`odb/source*.{c,h}`) but don't introduce new concepts beyond the callback pattern already established in earlier patches.
