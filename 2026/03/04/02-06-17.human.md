Bugfix for line-log/pickaxe interaction crash. Junio C Hamano confirms that the reported crash when combining `git log -L` (line log) and `-G` (pickaxe) options on repositories with file renames across merges is reproducible on all integration branches (`master`, `next`, `seen`). 

He notes this may be a long-standing issue dating back to the introduction of the `-L` feature, suggesting a bisect could help identify when the bug was introduced. The crash occurs when processing rename chains across merge commits, specifically when the line-log machinery fails to properly track file identity during diff processing with pickaxe active.

This appears to be a genuine bug in core diff machinery rather than a recent regression. No immediate fix is proposed, but Junio's response indicates the issue is now on the project's radar for investigation. The bug's persistence across branches suggests it may require non-trivial analysis of how line-log and pickaxe options interact during complex rename scenarios.
