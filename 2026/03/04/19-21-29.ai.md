This is a bugfix series addressing an interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The issue causes crashes when processing renamed files, stemming from regression a2bb801f6a ("line-log: avoid unnecessary full tree diffs", 2019-08-21).

The series takes a two-phase approach. The first patch fixes the crash by bypassing diffcore_std() and calling diffcore_rename() directly during line-log processing, restoring the pre-a2bb801 behavior where pickaxe options were silently ignored. The second patch improves user experience by actively rejecting this unsupported combination with an error message rather than silently ignoring it.

Changes span line-log.c, builtin/log.c and t/t4211-line-log.sh. The implementation modifies line-log processing to handle renames directly while adding proper error handling in the log command. The test suite is updated with comprehensive tests for both crash scenarios and the new error behavior, replacing previous test_expect_failure cases with proper error condition tests.

Key technical details include the direct call to diffcore_rename() instead of diffcore_std(), the new error handling in builtin/log.c, and thorough test coverage of both the crash scenarios and new error cases. The series appears complete and ready for merging, with no remaining open questions. It successfully resolves both the technical crash issue and the UX problem of silent misbehavior.
