This is the first patch in a two-part bugfix series addressing an interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The issue causes crashes when processing renamed files due to a regression introduced in commit a2bb801f6a ("line-log: avoid unnecessary full tree diffs", 2019-08-21).

The patch fixes the crash by modifying line-log's diff processing to call `diffcore_rename()` directly instead of the full `diffcore_std()`, which was inadvertently discarding diff pairs needed for rename detection when pickaxe options were present. The change restores the pre-regression behavior where pickaxe options were silently ignored during line-log processing.

The fix is accompanied by comprehensive tests that verify the crash is resolved while marking the silent-ignore behavior of pickaxe options as known breakage (to be addressed in the second patch). The test cases cover all three pickaxe variants (-G, -S, --find-object) and include a merge scenario with file renames.

This appears to be a well-crafted fix from first-time contributor Michael Montalbo, with clear commit message explanation and thorough test coverage. The patch targets a specific regression while setting up for the follow-up patch that will properly handle the pickaxe options rather than silently ignoring them.
