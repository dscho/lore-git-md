Bugfix for line-log functionality when combined with pickaxe options. This two-patch series addresses a crash that occurs when using `git log -L` with `-G`, `-S`, or `--find-object` on histories involving renames.

The root issue stems from a 2019 change that made diff processing unconditional, causing pickaxe operations to discard diff pairs needed for rename detection. The first patch fixes the immediate crash by adjusting the diff processing order, while adding tests that reveal the pickaxe options are silently ignored in this context. The second patch makes this limitation explicit by rejecting the unsupported combination entirely with an error message.

The changes are focused and well-motivated, touching just three files with straightforward modifications. The test additions provide clear coverage, transitioning from documenting known breakage to enforcing the new behavior. This appears to be a solid fix for a real edge case that could encounter in practice when analyzing code history.
