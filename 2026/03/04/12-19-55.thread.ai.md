Test modernization effort to improve reliability of command substitution patterns in test scripts. Francesco Paparatto addresses a subtle issue where `git rev-parse` failures could be silently ignored when used directly in test comparisons. The patch modifies `t/t3310-notes-merge-manual-resolve.sh` to store `rev-parse` outputs in variables before comparison, ensuring failures are properly detected. Changes follow Junio C Hamano's suggestion (Suggested-by) and touch 18 lines across 10 test cases.

Eric Sunshine reviews the changes, acknowledging the value of surfacing failures but suggesting two improvements for better developer experience: using `test_cmp` with pre-stored expected values (in files) rather than direct string comparisons, and using the specialized `test_cmp_rev` helper for revision comparisons. These changes would affect all 10 test cases being modified, replacing variable-based comparisons with more informative test helpers. The feedback comes from one of Git's most active reviewers and aligns with ongoing test modernization efforts. The suggestions are likely to be incorporated in a v2 of the patch. The changes remain focused on the test suite's ability to catch `rev-parse` failures while improving failure output.
