This is the first patch in a two-part bugfix series addressing an interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The issue causes crashes when processing renamed files due to a regression introduced in commit a2bb801f6a ("line-log: avoid unnecessary full tree diffs", 2019-08-21).

The patch fixes the crash by modifying line-log's diff processing to call `diffcore_rename()` directly instead of `diffcore_std()`, avoiding interference from pickaxe filtering that was breaking rename detection. The change is focused on line-log.c with accompanying test cases added to t4211-line-log.sh.

Key technical details:
- The crash occurred when pickaxe options discarded diff pairs needed for rename detection
- The fix restores pre-a2bb801 behavior where pickaxe options were silently ignored
- Test cases verify the crash is fixed while marking the silent ignore behavior as known breakage
- The second patch in the series will properly reject the unsupported option combination

The changes are well-contained and the test coverage is thorough, including scenarios with merges and renames. This appears to be a solid technical fix from a first-time contributor, addressing both the immediate crash and setting up for proper error handling in the follow-up patch.
