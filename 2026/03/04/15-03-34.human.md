This is a documentation patch that clarifies Git's support for running external "git-*" commands from PATH. The patch has gone through several iterations with feedback from Junio Hamano and others.

The patch adds documentation for Git's existing behavior where commands like `git foo` will look for an executable named `git-foo` in the user's PATH if `foo` isn't a built-in command. It explicitly documents that these external commands take precedence over aliases, which surprised the author (Omri Sarig) who expected the opposite order.

The current version (v4) improves the wording to be clearer about the lookup order: built-in commands first, then external `git-*` executables in PATH, then aliases. The patch places this documentation in the "Environment Variables" section of git.adoc alongside other PATH-related documentation, following Junio's suggestion.

This is a straightforward documentation improvement that makes an existing but under-documented feature more visible to users. The patch has received positive feedback and appears ready for merging after several rounds of minor wording refinements. The discussion shows consensus that this feature deserves clearer documentation, especially regarding its interaction with aliases.
