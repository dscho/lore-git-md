Bugfix targeting the interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). This is the first patch in a two-part series addressing a regression introduced in a2bb801f6a ("line-log: avoid unnecessary full tree diffs", 2019-08-21).

The patch fixes a crash that occurs when combining line-log with pickaxe options during rename detection. The root cause is that diffcore_pickaxe() discards diff pairs needed by line-log's rename detection, violating assumptions in filter_diffs_for_paths(). The fix bypasses diffcore_std() and calls diffcore_rename() directly, restoring pre-a2bb801 behavior where pickaxe options were silently ignored.

Key technical changes:
- Modifies line-log.c to call diffcore_rename() directly instead of diffcore_std()
- Adds test cases in t4211-line-log.sh verifying the crash is fixed
- Marks the silent-ignore behavior of pickaxe options with line-log as known breakage (test_expect_failure)

The patch confines changes to line-log.c and its test file, adding regression tests for the crash scenario. While it fixes the immediate crash, the second patch in the series will address the silent-ignore behavior by actively rejecting the combination. The test coverage includes scenarios with merges and renames, which were the triggering conditions for the original crash.
