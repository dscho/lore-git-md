This is a Google Summer of Code (GSoC) proposal for implementing prioritized fetching from promisor remotes. The student, Abraham Samuel Adekunle, has previously contributed small patches to Git (including one merged change to `git add -p`) and is now proposing a more substantial project.

The proposal aims to improve how objects are fetched from multiple promisor remotes (used in partial clones) by introducing a configurable priority system. Currently, remotes are queried in config file order, which may not be optimal. The project would:

1. Add a `remote.<name>.priority` config option to let users specify preferred fetch order
2. Allow servers to advertise recommended priorities via the promisor-remote protocol capability
3. Let clients choose whether to use server-suggested priorities, their own priorities, or the default order

The work builds on Christian Couder's prior patches that added promisor-remote protocol capabilities.
