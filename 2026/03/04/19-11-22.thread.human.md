This thread presents a two-patch series from first-time contributor Michael Montalbo fixing an interaction between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The issue stemmed from a 2019 regression where diffcore_pickaxe() would discard diff pairs needed by line-log's rename detection, causing crashes when processing renamed files.

The first patch addressed the immediate stability issue by modifying line-log's diff processing to call diffcore_rename() directly, bypassing the problematic diffcore_std() path. While this restored the pre-regression behavior where pickaxe options were silently ignored, it was only a partial solution. The second patch completes the fix by actively rejecting the unsupported combination with a clear error message, improving the user experience by replacing silent failures with explicit feedback.

The changes are well-contained, touching only line-log.c, builtin/log.c, and the line-log test file. The series includes comprehensive test coverage that verifies both the crash fixes and the new error behavior. The implementation leaves open the possibility of properly supporting this combination in the future while providing a clean interim solution. With both technical and UX issues addressed, this appears ready for merging.
