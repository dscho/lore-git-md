This is the first of two patches in the final version (v31) of Harald Nordgren's long-running effort to make `git status` branch comparisons configurable. The patch is a pure refactoring that extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function, with no behavior changes.

The refactoring prepares for the second patch which will introduce configurable branch comparisons via `status.compareBranches`. The changes are mechanical - the same logic is now in a standalone function that takes its inputs as parameters rather than computing them internally. This makes the code more modular and easier to extend for multiple branch comparisons.

The patch has already gone through extensive review, with Junio Hamano and Jeff King providing feedback over 31 iterations spanning two months (plus earlier work from 2016-2018). With all technical concerns addressed and tests passing, this version has been approved for merging. The changes are focused and well-contained, touching only `remote.c` with straightforward function extraction.
