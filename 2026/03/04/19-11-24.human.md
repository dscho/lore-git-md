This is the second patch in a bugfix series addressing interactions between `git log -L` (line-log) and pickaxe options (-G/-S/--find-object). The first patch fixed a crash when these options together with rename detection; this follow-up explicitly rejects the combination with a clear error message rather than silently ignoring the pickaxe options.

The patch modifies `builtin/log.c` to detect and reject the unsupported combination, replacing the previous silent-ignore behavior. The test changes remove the temporary "known breakage" tests from the first patch and replace them with tests verifying the new rejection behavior for all three pickaxe variants.

This is a clean, focused follow-up that completes the series by making the limitation explicit rather than silent. The commit message clearly states this could be revisited in future work to properly support the combination. The test coverage is thorough and the implementation straightforward.
