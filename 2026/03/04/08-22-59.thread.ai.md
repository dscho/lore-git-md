Build system modernization proposal to begin autoconf deprecation in favor of Meson, targeting removal in Git 2.55 (~1.5 years out). Patrick Steinhardt, a key driver of the Meson transition, submits this RFC series (2 patches) to confirm community alignment with earlier consensus. The first patch updates INSTALL to recommend Meson over autoconf, replacing autoconf/configure instructions with Meson equivalents while maintaining documentation structure. The second patch adds deprecation warnings to configure.ac that make the autoconf build fail by default, with a `--disable-autoconf-deprecation` escape hatch for packagers needing more time. The error message explains the rationale (autoconf's neglected state with unfixed issues), points to Meson as the recommended replacement, and requests feedback from packagers with unmet needs. Technical changes remain minimal at this stage - focused on signaling intent through documentation updates and warning infrastructure rather than functional removal. Open questions center on timing and packager readiness, with acknowledgment that the Git 2.55 target may adjust based on downstream feedback. Follows Meson's established presence in codebase and previous discussions that reached rough consensus on this direction, showing awareness of the need for a gradual transition while making the project's intended path clear.
