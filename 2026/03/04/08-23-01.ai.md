This is the second patch in Patrick Steinhardt's RFC series proposing to deprecate Git's autoconf build system in favor of Meson. The patch adds explicit deprecation warnings to configure.ac that will make the autoconf build fail by default, with instructions to use either the plain Makefile or Meson instead. A `--disable-autoconf-deprecation` flag is provided as an escape hatch for packagers who need more time to transition.

The error message is comprehensive, explaining the rationale (autoconf's neglected state with unfixed bugs and missing features), pointing to Meson as the recommended replacement, and requesting feedback from packagers who have specific needs that neither the Makefile nor Meson can address. The removal is tentatively scheduled for Git 2.55 (~1.5 years away), with acknowledgment that this timeline may adjust based on downstream feedback.

The technical change is minimal - just adding the warning infrastructure - but serves as a concrete step toward the eventual removal that was discussed in prior threads. This follows the first patch which updated INSTALL documentation to recommend Meson. The approach shows awareness of the need for a gradual transition period while making the project's direction clear.
