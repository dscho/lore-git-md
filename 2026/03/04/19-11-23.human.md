Bugfix for `git log -L` (line-log) interaction with pickaxe options (-G/-S/--find-object). This is the first patch in a two-part series addressing a regression introduced in a2bb801f6a ("line-log: avoid unnecessary full tree diffs", 2019-08-21).

The patch fixes a crash that occurs when combining line-log with pickaxe options on a history containing file renames. The root cause is that diffcore_pickaxe() discards diff pairs needed by line-log's rename detection, violating assumptions in filter_diffs_for_paths(). The fix bypasses diffcore_std() to call diffcore_rename() directly, restoring pre-a2bb801 behavior where pickaxe options were silently ignored.

The change is confined to line-log.c with accompanying tests in t4211-line-log.sh that verify the crash is fixed. The tests also document the still-broken behavior where pickaxe options have no effect on line-log output (marked as test_expect_failure for now). This remaining issue will be addressed in the second patch of the series.

The patch appears well-constructed with a clear commit message explaining both the technical problem and solution. The test coverage is thorough, covering all three pickaxe variants (-G, -S, --find-object) and demonstrating the regression scenario with a merge involving renames. This looks like a solid fix for a real bug that could affect users combining these options.
