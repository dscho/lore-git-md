This is a refactoring patch in the ongoing fsmonitor (filesystem monitoring) series, specifically addressing Unix platform support. The patch focuses on deduplicating settings logic by consolidating how Unix platforms handle fsmonitor configuration.

The changes respond to Patrick Steinhardt's review feedback from earlier in the thread. The author (Paul Tarjan) has:
1. Moved Makefile changes for `fsm-ipc` to the preceding commit
2. Removed incidental changes to keep this as a pure refactoring
3. Introduced the `fsmonitor_os` variable earlier in the series to avoid flip-flopping code

The patch maintains the same functionality while cleaning up the implementation. This is part of a larger effort to bring Linux fsmonitor support to parity with existing Windows and macOS implementations, with the series currently in Junio's 'seen' branch. The changes appear well-considered and responsive to review, though Patrick Steinhardt continues to raise questions about test reliability that remain open.
