This is a documentation patch that clarifies Git's support for running external `git-*` commands from PATH. The patch adds a section to `Documentation/git.adoc` explaining how Git looks for and executes external commands prefixed with "git-" when they are not built-in commands.

The documentation explains the lookup order: Git first checks for built-in commands in GIT_EXEC_PATH, then searches PATH for external `git-<command>` executables, and only then considers aliases. Arguments are passed through unchanged to the external command. This behavior has existed in Git's implementation (via `execv_dashed_external()` in git.c) but was not previously well-documented.

The patch is the fourth iteration (v4) of this documentation improvement. Previous versions refined the wording based on feedback from Junio Hamano and others, particularly around clarifying the precedence between external commands and aliases. The current version makes the lookup order explicit and removes some redundant phrasing while maintaining all the key information.

This is a straightforward, non-controversial documentation improvement that makes an existing but obscure feature more discoverable. The patch follows Git's documentation conventions and has already incorporated review feedback from multiple contributors. It appears ready for merging as part of the ongoing effort to better document Git's extensibility features.
