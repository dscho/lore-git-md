This is a Git GUI improvement patch that visually distinguishes commit message comment lines. Wolfgang Faust's updated version addresses Johannes Sixt's feedback on the initial submission.

The patch dims (rather than highlights) comment lines in the commit message editor, making it clear which lines will be stripped by `wash_commit_message`. The implementation uses Tk text widget tags to apply the styling. Key changes from the first version include:
- Renamed from "highlight" to "dim" to better reflect the visual effect
- Simplified the regex pattern using -line matching
- Restructured the code to use a cleaner foreach loop
- Added a +1 char offset to prevent visual flickering when typing at line ends

The change improves the commit message composition experience by providing immediate visual cues about what content will be included in the final commit. Johannes Sixt has already endorsed the core approach of graying out rather than highlighting comments.
