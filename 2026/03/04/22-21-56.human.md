This is a test modernization patch in an ongoing thread about improving reliability of command substitution patterns in test scripts. Eric Sunshine reviews Francesco Paparatto's changes to `t/t3310-notes-merge-manual-resolve.sh` that address silent failures in `git rev-parse` commands used directly in test comparisons.

While agreeing with the general goal of surfacing failures, Eric suggests more developer-friendly alternatives to the proposed variable assignments. He recommends using `test_cmp` (which shows expected/actual values on failure) when comparing against file contents, and `test_cmp_rev` (with its negation support) for direct ref comparisons. These test helper functions would provide better debugging output than simple variable assignments and `test` commands.

The review is characteristically thorough from Eric, who is one of Git's most active and detail-oriented reviewers. His suggestions align with the project's test modernization efforts while improving the patch's utility for future debugging. The changes remain mechanical but would make test failures more actionable.
