This is part of the ongoing fsmonitor Linux support effort, specifically patch 6/12 in the eighth iteration of the series. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the filesystem monitoring settings logic is not macOS-specific but shared across Unix platforms, including the new Linux implementation.

The change updates build configurations (CMake and meson) to use the new `FSMONITOR_OS_SETTINGS` variable for platform-specific settings files, matching the approach already used for IPC files. This is a straightforward renaming patch that follows the earlier consolidation of the IPC implementation from darwin to unix naming. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) whose work informed this shared implementation.

This continues the architectural work to unify Unix platform support while maintaining the ability to have platform-specific components where needed. The change is mechanical but important for the Linux fsmonitor implementation to reuse the existing settings infrastructure.
