This is a refactoring patch in the ongoing fsmonitor (filesystem monitoring) series, specifically part of the effort to bring Linux support to parity with existing macOS and Windows implementations. 

The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is not macOS-specific but rather shared by all Unix platforms. This follows a similar renaming done earlier for the IPC code. The change updates both the CMake and meson build systems to use the new `FSMONITOR_OS_SETTINGS` variable for these shared Unix components, while keeping platform-specific path utilities under `FSMONITOR_DAEMON_BACKEND`.

This is the sixth patch in a 12-part v8 series that has seen extensive review and iteration. The change is straightforward - a file rename with corresponding build system updates - and builds on previous work by Eric DeCosta and Marziyeh Esipreh. The patch appears well-contained and properly integrated with the broader fsmonitor effort, which is now in Junio's 'seen' branch with all major technical concerns addressed.
