This is a test patch for the Linux fsmonitor implementation, addressing reliability concerns with overlayfs. The patch is part of a larger series (v7 08/10) that adds filesystem monitoring support using inotify.

Paul Tarjan explains that the test failures seen in CI are not due to bugs in Git's fsmonitor code, but rather a known limitation in older Linux kernels' overlayfs implementation. The kernel sometimes fails to deliver inotify events even when watches are successfully registered. The patch adds test coverage that detects this situation early, allowing affected tests to be skipped rather than timing out repeatedly.

The discussion reveals that while newer kernels have improved overlayfs support, some configurations still exhibit the issue. The implementation already handles this gracefully by falling back to full scans when events don't arrive, maintaining correctness at the cost of performance. Patrick Steinhardt had raised concerns about test reliability, prompting this clarification about the underlying kernel behavior.

This patch appears to be a well-considered response to real-world testing challenges, providing practical workarounds for known platform limitations while maintaining the fsmonitor feature's robustness.
