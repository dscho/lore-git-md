Bugfix addressing line-log and pickaxe interaction. This is Junio Hamano's review of Michael Montalbo's patch that fixes a crash when combining `git log -L` with pickaxe options (-G/-S/--find-object). The patch works around the issue by bypassing diffcore_std() to preserve rename detection pairs, but Junio questions whether this is the right architectural approach.

Junio suggests two alternative solutions: first, that using `--pickaxe-all` might preserve the needed diff pairs while still applying the pickaxe filter, and second, that line-log should perhaps use its own dedicated diff_options struct rather than reusing the one from the user's command line. He expresses concern that the current approach may be misusing the diffcore infrastructure.

The review indicates the patch solves the immediate crash but leaves open deeper questions about how line-log should properly integrate with diffcore features. Junio's comments suggest the solution might need to be more fundamental than the current workaround, potentially involving changes to how line-log sets up its diff machinery. The thread appears to continue with discussion about the best way to architecturally handle this interaction between line-log's rename tracking and diffcore's filtering capabilities.
