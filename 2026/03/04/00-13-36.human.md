This is a status update on the SHA-1/SHA-256 interoperability effort, which is part of the larger Rustification initiative in Git. brian m. carlson confirms their patch series implementing object mapping between different hash algorithms is ready for merging into Git's `next` branch, pending any last-minute objections.

The 16-patch series (previously reviewed and now at version 2) adds Rust infrastructure for handling object IDs across hash algorithms, including a new binary object map format and various helper functions. Key technical components include Rust wrappers for hashfile operations, object ID handling, and algorithm abstraction layers. The series represents a significant step in brian m. carlson's multi-year effort to enable repositories using different hash algorithms to interoperate.

Junio Hamano had previously indicated this work was a candidate for `next` in his "What's cooking" report. The current email serves as final confirmation from the author that all feedback has been addressed and the series is ready for integration. Given the complexity of the changes and the ongoing debate around Rust in Git, this represents notable progress in a long-running technical effort.
