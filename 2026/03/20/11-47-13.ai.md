This is part 8 of Patrick Steinhardt's 14-patch series refactoring the fsck subsystem to remove `the_repository` dependencies. The patch focuses on the ref-checking functionality in `builtin/fsck.c`.

The change converts the ref processing code to use an explicitly passed repository parameter rather than relying on `the_repository`. The key modifications are:
- Adding a `struct repository *` parameter to `process_refs()`
- Passing this repository through to `fsck_handle_ref()` via the callback data
- Updating `fsck_handle_ref()` to use the passed repository for `parse_object()` instead of `the_repository`
- Modifying the call site in `cmd_fsck()` to pass the repository instance

This is a straightforward mechanical change that follows the pattern established in earlier patches of the series. The patch maintains all existing behavior while removing another instance of implicit global state usage. It's a typical incremental step in the broader `the_repository` removal effort, with Patrick continuing his careful approach of converting one logical piece at a time.
