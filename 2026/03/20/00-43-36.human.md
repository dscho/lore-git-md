This is a test infrastructure patch from Jeff King (Peff) that extends the color attribute decoding in Git's test suite. It's part of his series improving the `diff-highlight` contrib script, though this particular change affects the core test framework.

The patch adds support for decoding "off" variants of ANSI color attributes in `test_decode_color()`, which is used throughout Git's test suite to verify colored output. It specifically handles the negative counterparts to existing attributes: NORMAL_INTENSITY (turns off bold/dim), NOITALIC, and NOREVERSE. The implementation notes that "nobold" and "nodim" share the same ANSI sequence (22), so they're unified under NORMAL_INTENSITY.

While small, this change demonstrates Peff's characteristic attention to detail in test infrastructure. The patch is well-motivated (preparing for future test cases that might need to verify these attributes) and maintains the existing pattern of the function. As Peff notes in the commit message, this isn't meant to be exhaustive coverage of all possible ANSI attributes, just the ones relevant to Git's current needs.

This is a straightforward kind of test infrastructure improvement that's unlikely to be controversial, though it may get some review attention since it touches the shared test library rather than being confined to the diff-highlight contrib area.
