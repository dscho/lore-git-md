This is a test improvement patch in Jeff King's series enhancing the `diff-highlight` contrib script. The patch focuses on better test reliability by properly checking the exit status of the `diff-highlight` command during tests.

Currently, the test pipes `diff-highlight` output through a sanitizing function, which masks the command's exit status. This could hide crashes or unexpected failures. The change introduces temporary files to capture the raw output before sanitizing, allowing the test to detect any abnormal exits from `diff-highlight` itself.

The implementation splits what was previously a single pipeline into two steps: first running `diff-highlight` and saving to a `.hi` file, then applying the header stripping. This maintains all existing test assertions while adding the missing status checking. The change is minimal and focused, touching only the test script's helper function.

This patch continues the series' theme of thorough test improvements for the diff-highlight tool. It's a characteristic Jeff King contribution - small, precise, and addressing a subtle testing gap that could let real bugs slip through. The change is unlikely to be controversial given its straightforward nature and clear benefit to test reliability.
