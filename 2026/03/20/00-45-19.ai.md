This is a test patch in Jeff King's series improving the `diff-highlight` Perl script. The patch adds comprehensive testing for color configuration in the diff highlighting functionality.

The commit explains that while color configuration was added back in 2014, it was never properly tested. This patch adds two test cases:
1. Tests the highlight/reset style used by default colors, verifying bold/italic attributes can be configured and reset properly
2. Tests the normal/highlight color style configuration, showing how foreground colors can be set independently for old/new lines and their highlighted portions

The tests use the new `test_decode_color` helper (added earlier in the series) to make the assertions more readable by using symbolic names like `<BOLD>` and `<MAGENTA>` rather than raw ANSI codes. This continues Jeff's pattern of thorough test coverage - he's not just adding the functionality but ensuring it remains working through automated tests.

The changes are focused and well-contained, touching only the test script. This is patch 6/8 in the series, building on previous infrastructure improvements while setting up for subsequent changes to the color handling code.
