This is part 11 of Patrick Steinhardt's ongoing ODB abstraction series, focusing on simplifying how Git computes common prefixes between object IDs. The patch introduces a more direct way to compare binary object IDs rather than converting to hex strings first.

The key change is replacing the roundabout hex string comparison in `extend_abbrev_len()` with a new `oid_common_prefix_hexlen()` function that works directly with the binary object IDs. This eliminates the need for the `hex` field in `struct min_abbrev_data` and provides a more efficient comparison method that will be reused in later patches.

The change is a straightforward optimization that maintains the same behavior while cleaning up the implementation. It continues the series' pattern of methodical refactoring to make the object name handling code more maintainable and extensible for future backend implementations. Given the mechanical nature of the change and Patrick's track record with this series, this patch is likely to be uncontroversial.
