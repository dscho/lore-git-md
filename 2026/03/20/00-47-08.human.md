This is part of Jeff King and Scott Baker's series improving the `diff-highlight` Perl script, focusing on better integration with tools like `diff-so-fancy`. Patch 7/8 allows module callers to pass in their own color configuration rather than forcing the script to fetch it via `git config` each time.

The change makes the color configuration arrays (`@OLD_HIGHLIGHT` and `@NEW_HIGHLIGHT`) mutable and adds a `load_color_config()` function that lazily loads defaults only if no colors were provided externally. This gives callers two advantages: they can avoid the script's inefficient multiple `git config` calls, and they can source colors from their own configuration system if desired.

The patch maintains backward compatibility path while enabling more efficient integration - a typical Jeff King approach that balances improvement with minimal disruption. The accompanying README update clearly documents the new interface for module users. This is a well-considered change that addresses real performance pain points while keeping the script's core behavior intact.
