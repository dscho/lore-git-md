Feature addition for Signed-off-by line customization. This patch introduces a new config option `user.signoffcomment` that allows adding a parenthetical comment to automatically generated Signed-off-by (S-o-b) lines. The author explains this is useful for consultants who need to indicate client names in their signoffs.

The change adds a new `WANT_SOB_IDENT` enum to distinguish signoff formatting from regular committer identification, modifies the ident formatting logic to optionally include the comment, and updates the sequencer to use this new mode when generating signoffs. The implementation is straightforward, touching only three files with focused changes.

This appears to be a well-motivated, cleanly implemented feature that solves a specific workflow need without introducing complexity. The patch follows Git's coding style and includes appropriate updates to both the low-level ident handling and the higher-level sequencer code that generates signoffs.
