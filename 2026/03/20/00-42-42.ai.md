This is a refactoring patch in the `diff-highlight` improvement series, specifically addressing Perl version requirements. The patch reduces the minimum Perl version for the `DiffHighlight.pm` module from 5.26 back to 5.8, reverting part of a previous project-wide Perl version bump.

The rationale is that this contrib module has different constraints than core Git - it's used by external tools like `diff-so-fancy` that may need to run on older Perl versions, and being in contrib means it doesn't benefit as much from the project's modern Perl features. The change is minimal (just one line modifying the version requirement) but meaningful for compatibility.

Jeff King (Peff) signs off on Scott Baker's patch, suggesting they've coordinated on this change. The patch maintains all existing functionality while expanding the range of systems where the module can run. This aligns with the series' goal of improving `diff-highlight`'s integration with external tools while keeping it robust and widely compatible.
