The change completes the series' goal of making object name handling fully pluggable by:
1. Adding a new `find_abbrev_len` callback to the `odb_source` interface
2. Implementing the callback for the files-based backend to handle both loose and packed objects
3. Removing the now-redundant abbreviation logic from `object-name.c`

The patch maintains exact behavior while relocating the implementation, following the established pattern of the series.
