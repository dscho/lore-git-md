Bugfix for NULL pointer dereference in path-walk.c error handling. The patch addresses a segfault that occurs when lookup_tree() or lookup_blob() fails to find an object, where the code correctly checks for NULL but then incorrectly dereferences the NULL pointer when formatting the error message. The fix changes the error message to use entry.oid (always valid) rather than o->oid (NULL in this case). The change is minimal (one line) and localized to error reporting without affecting path resolution logic. The patch appears correct and ready for maint, though the commit message could note how the issue was discovered (testing/static analysis). Path walking is a sensitive area but this change is low-risk as it only fixes error reporting.
