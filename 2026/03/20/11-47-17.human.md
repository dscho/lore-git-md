Refactoring patch in the `the_repository` removal effort. This is patch 12/14 in Patrick Steinhardt's series to eliminate fsck's dependence on the global repository variable.

The patch focuses on converting object marking functionality in `builtin/fsck.c` to use explicit repository parameters instead of `the_repository`. Key changes include:

1. Introducing a `mark_object_data` struct to pass repository context through callbacks
2. Updating `mark_object()` to use the passed context for operations like `is_promisor_object()` and `odb_has_object()`
3. Modifying `mark_object_reachable()` and related functions to accept repository parameters
4. Adjusting callback signatures in `mark_unreachable_referents()` and `mark_object_for_connectivity()` to pass repository context

The changes are mechanical and focused - each modified function now receives repository state explicitly rather than relying on the global variable. The patch maintains all existing functionality while removing implicit dependencies, continuing the series' pattern of careful, incremental refactoring.
