This is a refactoring patch from Patrick Steinhardt, part of his ongoing ODB abstraction series (patch 8/14). The change makes object name abbreviation handling backend-agnostic by replacing storage-specific lookup functions with the new generic `odb_for_each_object_ext()` interface.

The patch removes the `find_short_packed_object()` function and consolidates both packed and loose object lookups into a single call to `odb_for_each_object_ext()`. This continues the series' pattern of moving storage-specific operations out of `object-name.c` and into the backend interface, a key step toward enabling pluggable object storage backends.

The change maintains identical behavior while making the code more flexible - a hallmark of Patrick's careful refactoring approach. The patch follows the established pattern from previous patches in the series and appears mechanically sound. Given the series' steady progress through review and Patrick's track record with major refactorings, this change is likely to proceed smoothly toward inclusion.
