This is a feature patch adding a new configuration option to customize Signed-off-by lines. The patch introduces a `user.signoffcomment` config that allows appending a parenthetical comment to automatically generated S-o-b lines, addressing a common request from consultants who need to note their client organizations.

The implementation adds a new `WANT_SOB_IDENT` enum value to distinguish S-o-b formatting from regular committer/author identities, and modifies the ident formatting logic in `ident.c` to insert the configured comment when this mode is active. The change is relatively small (26 lines added, 6 modified) and touches three files: `ident.c` for the core implementation, `ident.h` for the new enum, and `sequencer.c` to use the new mode when generating S-o-b lines.

The patch appears well-structured with clear motivation explained in the commit message. The author (Uwe Kleine-König) demonstrates the feature by including their own client affiliation in the S-o-b line of this patch. The change is narrowly scoped to address the stated use case without introducing broader identity formatting complexity.
