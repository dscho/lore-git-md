This is patch 5/14 in Patrick Steinhardt's series to remove `the_repository` dependence from Git's fsck subsystem. The patch focuses on eliminating the last remaining dependency in `fsck.c` by replacing calls to `parse_oid_hex()` (which uses the global state) with `parse_oid_hex_algop()` that takes an explicit hash algorithm parameter.

The changes are mechanical but widespread, touching several built-in commands that use fsck functionality (`fsck`, `index-pack`, `mktag`, `unpack-objects`). The patch updates function signatures in `fsck.h` to include the repository parameter and propagates these changes through the call chain. With this change, `fsck.c` no longer needs the `USE_THE_REPOSITORY_VARIABLE` macro.
