This is part 4/14 of Patrick Steinhardt's series to make object name lookups more extensible, continuing his work on abstracting the object database (ODB) backend. The patch moves logic for iterating through loose objects with a given prefix from object-name.c to object-file.c, where it properly belongs with other object storage implementation details.

The change introduces structured options for object iteration, adding prefix-based filtering directly to the ODB interface. This allows the loose object iteration to work consistently regardless of the backend implementation. The patch also makes the loose object cache private to object-file.c since it's no longer needed externally.

This is a mechanical but important step in the ODB abstraction effort, maintaining existing behavior while making the code more flexible for future backend implementations. The changes are well-contained and follow the established pattern of the series, with Patrick carefully updating all callers (including the object disambiguation code) to use the new interface. Given the thoroughness of the series so far and the positive reception from reviewers like Junio Hamano and Karthik Nayak, this patch appears to be on track for merging.
