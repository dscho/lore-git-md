This is a coding style patch (part 1/2 of a series) from Kristoffer Haugsbakk that standardizes brace usage in `builtin/name-rev.c` to align with Git's coding guidelines. The change enforces consistent brace style for conditional blocks, wrapping both single-line and multi-line blocks in braces when they are part of a multi-arm conditional.

The patch modifies two conditional blocks in the file:
1. In `get_rev_name()`, wrapping the generation check and name formatting logic
2. In `name_rev_line()`, standardizing the hex character detection logic

This is a preparatory change for the main feature in the series (adding `--format` support to `git name-rev`), carrying forward from v1 of the series. The author notes a minor fix to stray formatting in the commit notes compared to v1. The change is straightforward and uncontroversial, following established project conventions for brace style in conditionals.
