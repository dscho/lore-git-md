Bugfix targeting path-walk.c, addressing a NULL pointer dereference in error handling.

The patch fixes a segfault that occurs when `lookup_tree()` or `lookup_blob()` fails to find an object. The current code correctly checks for NULL but then incorrectly tries to dereference the NULL pointer when formatting the error message. The fix changes the error message to use `entry.oid` (which is always valid) rather than `o->oid` (which is NULL in this case).

This appears to be a straightforward and correct fix for a clear bug. The change is minimal (just one line) and well-explained in the commit message. The patch touches a sensitive area (path walking) but the change is localized to error reporting and doesn't affect the actual path resolution logic.
