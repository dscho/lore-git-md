This is a test improvement patch in Jeff King's series enhancing the `diff-highlight` Perl script. The change standardizes how color output is verified in the tests by using Git's existing `test_decode_color` helper rather than raw escape sequences. This makes test output more readable and maintainable, particularly when debugging failures.

The patch replaces hardcoded color escape sequences (like `\033[7m` for reverse video) with symbolic names (`<REVERSE>`) throughout the test file. This follows Git's standard testing practices and will make it easier to add new color tests in the future. The change is mechanical but meaningful - it's part of Jeff's broader effort to improve the script's test coverage and reliability while maintaining compatibility with tools like `diff-so-fancy` that build on it.

As with the rest of the series, this is a focused, well-explained change from a trusted contributor. The patch touches only test code and doesn't introduce any new behavior, so it's low-risk while providing clear maintainability benefits. It fits naturally with the series' goal of making `diff-highlight` more robust.
