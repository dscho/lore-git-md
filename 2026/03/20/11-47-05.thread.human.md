Patrick Steinhardt has kicked off a 14-part series refactoring Git's fsck subsystem to eliminate its dependence on the global `the_repository` variable, part of the ongoing effort to remove this global state from the codebase. The first patch focuses on converting the core traversal functions - `fsck_walk()` and its type-specific helpers - to take an explicit `struct repository *` parameter instead. This mechanical but widespread change updates the function signatures and all their call sites while maintaining identical behavior.

The series is well-established territory for Steinhardt, who has been driving similar architectural cleanups, and the changes align with the project's direction toward more explicit state management. The initial patch lays the groundwork by tackling the fundamental traversal logic used throughout fsck operations. While this is just the series introduction with no reviews yet, the changes appear clean and focused, making this a promising start to a refactoring that should improve maintainability without introducing functional changes. The remaining patches will presumably build on this foundation to convert the rest of the fsck subsystem.
