This is a platform compatibility investigation regarding macOS regex behavior, with Johannes Schindelin (Git for Windows maintainer) joining the discussion to analyze CI failures. The thread has shifted from considering code changes to diagnosing environmental inconsistencies in GitHub Actions runners.

Schindelin reports observing the same REG_ENHANCED-related failures in Git for Windows' CI, noting the breakage correlates with a runner image update (20260317.0174.1) that included a Homebrew bump from 5.0.15 to 5.1.0. His analysis suggests the issue may stem from a clang update in Homebrew that disabled REG_ENHANCED support, though he notes the meson build's special handling of REG_ENHANCED detection might explain why those jobs remain unaffected.

The investigation continues to focus on environmental factors rather than code changes, with Schindelin's findings adding weight to the theory that the problem originates in CI infrastructure updates rather than Git's codebase.
