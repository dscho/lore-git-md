This is a feature patch (v2) from Kristoffer Haugsbakk that adds `--format` support to `git name-rev`, allowing it to output formatted commit information similar to `git log --format`. The patch builds on previous feedback from Junio C Hamano and others.

The key addition is a new `--format` option that lets users specify pretty-printed output for revisions, with support for format specifiers like `%s` (subject) and `%N` (notes). The implementation properly handles edge cases like `--no-name-only` interaction and notes display via `--notes` option. Memory management has been improved using `FREE_AND_NULL()`.

The patch includes comprehensive tests verifying behavior with various format combinations, notes references, and input scenarios (including stdin processing). The author has addressed feedback from v1 while maintaining the core functionality - this looks like a well-considered addition that aligns with Git's existing formatting conventions.

The motivation explains this fills a gap where users need to format commits on demand (rather than walking commit graphs), particularly when processing mixed input containing revisions and arbitrary text. The implementation leverages `name-rev`'s existing ability to handle such mixed input while adding formatting capability.
