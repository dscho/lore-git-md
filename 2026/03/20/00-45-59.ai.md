This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the state of various topics in the Git development pipeline. The report covers patches that have graduated to 'master', new topics under review, ongoing work, and discarded efforts.

Several notable patches have recently graduated to 'master':
- The run-command API was updated to remove its dependency on `the_repository` global variable
- Combined list-object filter options parsing was revamped
- `git rebase` gained `--trailer` support for driving the interpret-trailers machinery
- Editorconfig filename patterns were fixed to properly apply to subdirectories
- Multiple test cleanups modernizing test scripts to use path helper functions

New topics under review include:
- A fix for whitespace correction with new-style empty context lines
- Reducing `the_repository` usage in add-patch.c
- `git backfill` learning to accept revision and pathspec arguments
- A fix for commit-graph generation with dates beyond year 2514
- `git replay` gaining support for replaying down to root commits
- Support for pushing to remote groups (similar to fetch groups)

Ongoing work includes:
- Reference transaction hooks gaining a "preparing" phase
- `git checkout -m` learning to use autostash when switching branches
- `git name-rev` gaining custom format support
- Reducing `the_repository` usage in the worktree subsystem
- Parallel hook execution support
- HTTP transport learning to handle 429 rate limit responses

The report also notes several discarded efforts, including Johannes Schindelin's original sideband sanitization work which has been superseded by Junio's rebased version.

This status update shows continued progress on major initiatives like removing `the_repository` dependencies, improving test infrastructure, and expanding functionality in commands like `replay` and `backfill`. The mix of new features, bug fixes, and technical debt reduction reflects Git's ongoing maintenance and evolution.
