This is a test patch in Adrian Ratiu's series improving Git's hook configuration support. It adds a test case to verify that configured hooks (set via Git config) run before legacy hooks from the `.git/hooks` directory, matching documented behavior. The test sets up two configured hooks and one legacy hook, then checks their execution order via both `git hook list` and `git hook run`.

The patch also fixes a minor test issue by removing a redundant `git hook list -h` invocation in another test case. The change is straightforward and well-contained, with the new test following existing patterns in the test file. This continues the series' focus on improving test coverage for the hook subsystem's behavior.
