This is a performance optimization patch for the `diff-highlight` Perl script in Git's contrib directory, part of Jeff King's ongoing series to improve the tool. The patch reduces process overhead by fetching all color configuration values in a single `git config` call rather than making six separate invocations.

The key change replaces individual `git config --get-color` calls with a single `git config --type=color --get-regexp` that retrieves all `color.diff-highlight.*` settings at once. The results are cached in a package variable to avoid repeated lookups. This maintains the same functionality while being more efficient - the patch demonstrates via trace output that it reduces the number of config processes from six to one.

The optimization is particularly well-motivated since `diff-highlight` runs this config lookup for every diff it processes. The implementation carefully preserves backward compatibility and doesn't affect callers (like `diff-so-fancy`) that provide their own color configurations. The patch shows Jeff King's characteristic attention to both performance and maintainability, with clear commit message explaining the tradeoffs and change rationale.
