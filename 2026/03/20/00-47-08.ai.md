This is a patch in Jeff King's series improving the `diff-highlight` Perl script, which provides syntax highlighting for diffs in Git's contrib directory. Patch 7/8 focuses on making the color configuration more flexible for module callers like `diff-so-fancy`.

The key change allows external users of the `DiffHighlight.pm` module to pass in their own color configurations rather than forcing the module to fetch them via `git config`. This addresses two use cases: when callers want to use different config variables than the defaults, and when they want to avoid the module's inefficient approach of making six separate `git config` calls. The colors are now lazy-loaded only when needed if not provided by the caller.

The patch moves the color configuration arrays (`@OLD_HIGHLIGHT` and `@@NEW_HIGHLIGHT`) to package variables and introduces a new `load_color_config()` function that handles the lazy loading. The README is updated to document this new interface. This is a well-motivated change that maintains backward compatibility while giving more control to module users, particularly important for `diff-so-fancy` which already implements its own config parsing.

This continues Jeff King's pattern of thoughtful, incremental improvements to `diff-highlight`, with clear attention to both functionality and performance. The change is small but meaningful for users of the module, and fits well with the series' overall goal of better integration with `diff-so-fancy`.
