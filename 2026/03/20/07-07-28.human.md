This is a refactoring patch from Patrick Steinhardt that's part of his ongoing ODB abstraction series (patch 2/14). The change modifies the crit-bit tree (cbtree) and oidtree iteration interfaces to allow callback functions to return arbitrary values rather than just CB_CONTINUE/CB_BREAK flags.

The key change is converting the iteration functions to propagate callback return values directly rather than treating them as special flags. This matches Git's common pattern where callbacks return error codes that should bubble up. The patch updates all related code including:
- cbtree.c/h interface changes
- oidtree.c/h to match
- Callers in object-name.c
- Unit tests

The changes are mechanical but improve consistency with Git's error handling patterns. This builds on previous review feedback where Junio Hamano and Karthik Nayak approved the technical direction. The patch maintains all existing functionality while making the interfaces more flexible for future use cases.

As part of Patrick's larger ODB abstraction work, this helps prepare the codebase for alternative storage backends by standardizing iteration behavior. The changes are well-contained and unlikely to be controversial given they've already passed initial review.
