This is a feature patch series (v2) from Kristoffer Haugsbakk that adds `--format` support to `git name-rev`, modeled after `git log --format`. The series builds on previous feedback from Junio C Hamano and others.

The main changes in v2 include:
- Handling of `--no-name-only` with `--format`
- Proper notes display support via `--notes` option
- Memory management improvements using `FREE_AND_NULL()`
- More comprehensive test coverage of edge cases

The implementation now uses a callback for the format option to properly coordinate with `--name-only`, and adds support for displaying notes from specific refs. The tests verify behavior with various combinations of format specifiers, notes references, and negation cases.

Technical details of note:
- Adds `struct format_cb_data` to track format state
- Uses `display_notes_opt` for notes handling
- Includes tests for `%s`, `%N`, and reference formats
- Verifies interaction between `--format` and `--name-only`

The patch appears well-considered, with thorough test coverage and careful attention to edge cases raised in previous reviews. The author has incorporated feedback from v1 while maintaining the core functionality. This continues to look like a useful addition that aligns with Git's existing formatting conventions.
