This is patch 10/14 in Patrick Steinhardt's series refactoring object name handling as part of the ODB abstraction effort. The patch simplifies how Git calculates minimum unique abbreviations for loose object names by eliminating an unnecessary indirection through the disambiguation state machinery.

The change removes the `always_call_fn` flag from `disambiguate_state` and replaces the indirect path through `find_short_object_filename()` with a direct implementation (`find_abbrev_len_loose()`) that operates on the `min_abbrev_data` structure. This makes the code more straightforward by:
- Removing unused disambiguation state logic
- Directly using the ODB iteration interface with a callback that updates abbreviation length
- Eliminating intermediate object ID copying

The patch maintains all existing behavior while making the implementation more focused and easier to follow. It builds on previous work in the series that introduced the `odb_for_each_object()` infrastructure, showing a logical progression toward cleaner separation between disambiguation logic and storage-specific operations.
