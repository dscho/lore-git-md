Platform compatibility investigation for macOS regex behavior, with new insights from Johannes Schindelin about CI runner image changes.

Johannes Schindelin adds important context to the ongoing macOS REG_ENHANCED mystery by analyzing the GitHub Actions runner image versions. He observes that the failures correlate with a runner image update (20260302.0147.1 -> 20260317.0174.1), particularly noting a Homebrew version bump from 5.0.15 to 5.1.0. The key finding is that the failures only appear in `osx-clang` and `osx-reftable` jobs, while `osx-gcc` and `osx-meson` continue to pass - suggesting the issue may stem from a clang/Homebrew interaction rather than macOS itself.

The email provides useful technical details about how meson.build handles REG_ENHANCED detection differently, which explains why the meson-based build isn't affected. This moves the investigation forward by shifting focus from macOS system headers to the specific toolchain versions being used in CI. Johannes indicates he'll continue investigating the clang/Homebrew angle, which seems the most promising lead for explaining the sudden appearance of these failures.
