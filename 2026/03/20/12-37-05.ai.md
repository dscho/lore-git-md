Build system improvement completing an 8-part series from Patrick Steinhardt, with minor feedback from Toon Claes. This final patch implements precompiled header (PCH) support in the build system, specifically for the Meson build, demonstrating significant compilation speed improvements.

The patch builds on prior work that established a new tools/ directory and restructured compatibility code. It creates tools/precompiled.h as a minimal entry point that includes git-compat-util.h, leveraging Meson's c_pch support to force inclusion via compiler flags like GCC's -include. Benchmark results show a 30-40% speedup in build times (main executable build dropping from ~14.5s to ~10.3s).

Toon Claes notes the optimization currently only applies to Meson builds (not Makefile) and suggests this could be mentioned in the commit message, but raises no blocking concerns. The series appears ready for merging with all prior feedback addressed, completing the infrastructure improvements while maintaining compatibility across platforms and with ongoing work like the reftable backend. The changes are minimal (3 lines added) but effectively leverage Meson's built-in PCH support.
