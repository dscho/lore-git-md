The implementation carefully handles cases where some hooks must remain serial (like those needing separate output streams) or when any hook in an event isn't marked parallel.

The patch includes extensive tests demonstrating the behavior under different configurations, using a clever "sentinel" technique to detect whether hooks run in parallel or serial.
