This is a 10-patch series from Adrian Ratiu that builds on his previous work to improve Git's hook configuration system. The series focuses on cleanups, refactorings, and two small but useful additions to `git hook list` functionality.

The key improvements in this version include:
1. Showing the configuration scope (system/global/local) for hooks via a new `--show-scope` flag, using a tab-separated output format similar to `git config --show-scope` for better machine parsing
2. Making disabled hooks visible in `git hook list` output (previously they were silently hidden)
3. Various code cleanups and style fixes based on feedback from Patrick Steinhardt, Junio Hamano, and Eric Sunshine

The changes touch multiple files but are well-contained to the hook subsystem, with thorough test coverage added. The series has already gone through one round of review and addresses all previous feedback, including fixing a build break and adopting the tab-separated output format that emerged as the preferred approach during discussion.

This continues Adrian's ongoing effort to make Git hooks more configurable and manageable through Git's configuration system rather than just filesystem paths. The changes look ready for integration, with the author noting it's now based on the master branch and includes clean CI results (except for a known MacOS issue).
