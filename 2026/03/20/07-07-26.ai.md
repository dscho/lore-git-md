This is a major refactoring patch series from Patrick Steinhardt that continues the object database (ODB) abstraction effort by making object name handling (disambiguation and abbreviation) backend-generic. The series builds on his previous work on object counting and represents a significant step toward enabling alternative storage backends.

The 14-patch v2 series refactors how Git handles:
- Disambiguation of object name prefixes (when a short hash matches multiple objects)
- Calculation of shortest unique abbreviations for object IDs

Key changes in v2 include:
- Documentation improvements for the oidtree iteration callback interface
- Fixes to leftover conversions in the loose object iteration
- Commit message typo fixes

The series systematically moves core functionality from `object-name.c` into the ODB backend interface, allowing different storage backends to implement their own logic. This enables commands like `git commit`, `git log`, and `git rev-parse` to work with alternative backends, though packfile-related operations remain unsupported.

Patrick notes this work enables his MongoDB proof-of-concept (though he clarifies this isn't an endorsement of MongoDB as a production backend). The changes are wide-ranging but maintain behavioral compatibility while making the code more flexible for future backend implementations.
