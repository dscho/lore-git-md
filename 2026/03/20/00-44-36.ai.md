This is a test modernization patch in Jeff King's series improving the `diff-highlight` Perl script. The change updates the test suite to use Git's standard `test_decode_color` helper instead of hardcoding raw ANSI color sequences, making the tests more readable and maintainable.

The patch replaces direct ANSI escape codes (like `\033[7m` for reverse video) with symbolic names (`<REVERSE>`, `<NOREVERSE>`) throughout the test file. This makes test failures easier to diagnose since the output will use human-readable color names rather than raw control characters. The change also future-proofs the tests for any additional color attributes that might be added later.

This is part of Jeff's broader effort to improve `diff-highlight`'s test coverage and integration with Git's test infrastructure. The change is mechanical but meaningful - it follows Git's established testing patterns while making the specific diff-highlight tests more robust. As with the rest of the series, the patch is focused and well-explained, showing Jeff's characteristic attention to test quality.
