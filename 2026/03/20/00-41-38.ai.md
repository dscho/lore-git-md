This is a patch series improving the `diff-highlight` Perl script, which is part of Git's contrib directory and provides syntax highlighting for diffs. The series comes from Jeff King (Peff), a long-time contributor known for precise fixes and thorough testing.

The main motivation is better integration with `diff-so-fancy`, a popular diff formatting tool that uses `DiffHighlight.pm` internally. The series includes several aspects: documentation updates (adding build instructions in the README), test improvements (better color handling and test coverage), and a performance optimization (reducing process overhead when fetching config). 

Notable technical changes include:
- Relaxing the Perl version requirement back to 5.8 (patch 2)
- Adding proper exit status checking in tests (patch 3)
- Introducing negative attribute testing in `test_decode_color` (patch 4)
- Allowing color configuration to be passed to the highlighting module (patch 7)
- Optimizing config fetching to use a single process (patch 8)

The patches build on a previous bugfix from Jeff and show his characteristic attention to both functionality and test coverage. The changes are focused and well-explained, typical of his contributions. While `diff-highlight` is a contrib script rather than core Git functionality, these improvements maintain its quality as a useful tool for those who choose to use it.
