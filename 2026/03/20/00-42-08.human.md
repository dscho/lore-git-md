This is a documentation patch for the `diff-highlight` contrib script, part of a series from Jeff King (Peff) to improve this tool's usability and integration with `diff-so-fancy`. 

The patch updates the README to clarify build steps that changed in 2017 when the script was modularized. It now explicitly states that users must run `make` in the directory to build the script (there's no `make install` target) and mentions the test suite requires building Git first. The changes are straightforward and well-motivated, addressing a real documentation gap that could confuse users trying to use the script directly from source.

As the first patch in an 8-part series, this sets the stage for subsequent technical improvements by ensuring users understand how to properly build and test the tool. Given Peff's reputation for thoroughness and the focused nature of this change, it's likely to be uncontroversial. The patch follows the project's typical pattern of small, incremental improvements with clear commit messages.
