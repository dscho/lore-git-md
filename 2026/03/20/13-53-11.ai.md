This is the final patch in Adrian Ratiu's parallel hook execution series, adding a high-level `hook.<event>.enabled` configuration switch to disable all hooks for a given event. The patch builds on the previous infrastructure for parallel execution while introducing new event-level control.

The key addition is a new config key that acts as a master switch - when `hook.<event>.enabled` is false, no hooks fire for that event regardless of individual hook settings. This complements the existing per-hook `hook.<friendly-name>.enabled` controls. The implementation reuses the `is_friendly_name()` helper from earlier in the series to distinguish event names from friendly names when processing config.

The patch updates `git hook list` output to show event-disabled hooks with an "event-disabled" prefix, prioritizing this status over per-hook disabled states since it's the more relevant information when troubleshooting. The changes touch several areas: config documentation, hook listing display logic, repository lifecycle management (adding a new `event_disabled` string list to track disabled events), and the core execution path to skip disabled events.

Test coverage is thorough, verifying:
- Event-level enable/disable behavior
- Interaction with per-hook disabled states
- Correct display in `git hook list`
- No interference with other events
- Scope display integration

The implementation follows Junio Hamano's suggestion to add this high-level control point, completing the series' layered configuration approach that now includes:
1. Global `hook.jobs` default
2. Per-hook `hook.<name>.parallel` flags 
3. CLI `-j/--jobs` override
4. Per-event `hook.<event>.jobs` settings
5. Per-hook `hook.<name>.enabled` switches
6. New per-event `hook.<event>.enabled` master switch

All foundational patches in the series have maintainer acks, and this final piece appears well-integrated with the existing work. The careful attention to backward compatibility and clear user feedback (through `git hook list` and config warnings) demonstrates thoughtful design.
