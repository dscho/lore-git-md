This is part 5/14 of Patrick Steinhardt's series to make object name lookups more extensible, continuing the object database (ODB) abstraction effort. The patch moves the logic for iterating through packed objects with a given prefix from `object-name.c` to `packfile.c`, completing the relocation of prefix-based iteration started in the previous patch.

The change maintains the same behavior while better separating concerns - `object-name.c` now focuses on disambiguation logic while `packfile.c` handles the storage-specific operations. The patch introduces new helper functions (`for_each_prefixed_object_in_midx` and `for_each_prefixed_object_in_pack`) to implement the iteration logic in its new location.

This is a mechanical but important refactoring that continues the steady progress toward pluggable backends. The changes are well-contained and maintain backward compatibility. Given Patrick's track record with this abstraction work and the positive reception of earlier patches in the series, this appears to be another solid step forward in the ODB abstraction effort.
