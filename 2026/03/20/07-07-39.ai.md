This is patch 13/14 in Patrick Steinhardt's series refactoring object name handling to support pluggable object databases. The patch moves packed object abbreviation length calculation logic from `object-name.c` to `packfile.c` as part of making the ODB backend interface more complete.

The changes:
- Extracts `find_abbrev_len_packed()` and related helper functions from `object-name.c`
- Implements new `packfile_store_find_abbrev_len()` in `packfile.c` with equivalent functionality
- Updates callers to use the new interface
- Maintains all existing behavior while making the code more modular

Key technical details:
- New function `packfile_store_find_abbrev_len()` handles packed/MIDX abbreviation logic
- Removes 123 lines from `object-name.c` while adding 111 to `packfile.c`
- Touches core object ID handling but doesn't change user-visible behavior
- Follows the pattern established in previous patches of moving storage-specific logic to backend implementations

This continues the series' methodical approach to ODB abstraction by completing the move of abbreviation calculation logic out of the generic object name handling code. The changes are mechanical but important for enabling alternative storage backends to implement their own abbreviation strategies.
