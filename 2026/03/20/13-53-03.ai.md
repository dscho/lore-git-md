This is a foundational infrastructure patch (1/9) in Adrian Ratiu's parallel hook execution series. It introduces a new `repo_config_get_uint()` helper function to properly handle unsigned integer configuration values, which will be used for the upcoming `hook.jobs` setting.

The patch adds the full stack of helper functions needed to parse and retrieve unsigned int config values:
- `git_config_uint()` for direct parsing
- `git_configset_get_uint()` for config set lookup
- `repo_config_get_uint()` for repository-specific config
- Underlying `git_parse_uint()` parsing function

The implementation follows Git's existing patterns for other numeric types (int, ulong, int64_t) and includes thorough documentation in the header files. The change is mechanical but necessary - the author notes alternatives like using signed ints or ulongs were considered but rejected as less appropriate for the use case.

This patch has already been acked by maintainer Junio Hamano, indicating it meets Git's standards for config handling infrastructure. It provides the building block that subsequent patches will use to implement parallel hook execution configuration.
