This is a feature patch series (v2) from Kristoffer Haugsbakk that adds `--format` support to `git name-rev`, allowing pretty-printed output similar to `git log --format`. The series builds on previous review feedback and now includes proper handling of notes display and clearer interaction with `--name-only`.

The first patch is a minor coding style fix (adding braces to conditionals in `builtin/name-rev.c`), while the second implements the main functionality. Key improvements in v2 include:
- Better integration with `--name-only` (now properly toggled by `--[no-]format`)
- Notes support via `--notes` option
- Memory management fixes using `FREE_AND_NULL()`
- More comprehensive test coverage

The implementation uses `pretty_print_commit` to handle formatting, with tests showing it can match `git log` output when given the same format strings. The author acknowledges this might not be the final form of the feature and raises questions about whether additional formatting options (like `--abbrev` or `--date`) should eventually be added to `name-rev` or split into a separate command.

The patch appears well-considered, with thorough test coverage and clear responses to previous review feedback. While the author notes this may need further iteration, the current implementation looks like a solid step toward more flexible revision formatting in `name-rev`.
