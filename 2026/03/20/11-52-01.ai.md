This is a completed 10-patch series from Adrian Ratiu that extends Git's hook configuration support with cleanups and small features. The series builds on Adrian's prior work to make hooks configurable via Git's configuration system rather than just filesystem paths.

The key changes include:
1. Adding a `--show-scope` option to `git hook list` to display where each hook's configuration comes from (system/global/local)
2. Showing disabled hooks in `git hook list` output
3. Various code cleanups and refactorings in the hook subsystem

The series has gone through review iterations, with v2 addressing feedback around:
- Switching to a tab-separated output format (mirroring `git config --show-scope`) for better machine parsing
- Fixing build failures from unupdated function calls
- Style improvements and documentation clarifications
- Replacing a custom struct with standard string-list functions

Technical details:
- The scope display now uses tab-separated fields (e.g. "global\tlinter") 
- Disabled hooks are marked with a "disabled\t" prefix
- The implementation uses a new `hook_config_cache_entry` struct to track per-hook data
- Several utility functions were moved to more appropriate locations
- Tests verify the hook execution ordering and new output formats

The series appears well-polished after review, with consensus forming around the output format and implementation approach. It's now rebased on master and queued for integration, pending resolution of one remaining build issue on macOS. This continues Adrian's ongoing effort to improve Git's hook configuration capabilities.
