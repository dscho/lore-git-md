This is part 9/10 of Adrian Ratiu's series improving Git's hook configuration support, now queued for integration. The patch adds a `--show-scope` option to `git hook list` that displays where each hook was configured (system/global/local), mirroring the output style of `git config --show-scope`. The scope appears as a tab-separated prefix for machine-parseable output, while traditional hookdir hooks remain unaffected since they don't come from config.

The implementation stores the config scope during the config callback and carries it through to the hook structs via a new `hook_config_cache_entry` struct. The change is well-contained, with thorough documentation updates and tests verifying both the new scope display and backward compatibility when the flag isn't used. This continues Adrian's pattern of thoughtful, incremental improvements to Git's hook configuration capabilities.
