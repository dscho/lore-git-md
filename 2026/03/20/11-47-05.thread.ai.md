Subject: fsck subsystem refactoring to remove `the_repository` dependence
Series version: v2 (12 patches)
Author: Patrick Steinhardt
Thread type: patch series (architectural refactoring)

Core problem/goal: Remove fsck subsystem's dependence on global `the_repository` by converting functions to take explicit `struct repository *` parameters. Part of broader `the_repository` removal effort and preparatory work for pluggable backend-specific fsck checks. Key structural change in v2: repository pointer now stored in `fsck_options` struct per Junio's feedback, requiring new initialization function for file-static scope cases.

- Core fsck logic in `fsck.c` and `fsck.h`

- Test files covering converted functionality
- Fetch-pack and object-file interaction points
- Configuration parsing infrastructure
- Reflog checking in `builtin/fsck.c`
- Loose/packed object checking paths
- Object marking functionality
- Error reporting mechanisms
- Ref snapshotting functionality (new in patch 6/12)
