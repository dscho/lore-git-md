This is the first patch in a 14-part series refactoring Git's fsck subsystem to remove its dependence on the global `the_repository` variable. The patch focuses on converting `fsck_walk()` and related functions to take a `struct repository *` parameter instead of implicitly using the global.

The changes are mechanical but widespread, touching core fsck functionality in `fsck.c` and updating callers in several built-in commands (`fsck`, `index-pack`, `unpack-objects`). The patch maintains all existing behavior while making the repository dependency explicit. This is a clean, focused change that follows the project's ongoing effort to eliminate global state.

As the opening patch in a well-structured series from an experienced contributor, this looks like solid groundwork for the larger refactoring. The changes are straightforward and unlikely to introduce regressions, though reviewers will likely scrutinize the function signature updates for any potential impacts on external callers.
