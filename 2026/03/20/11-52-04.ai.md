This is a refactoring patch from Adrian Ratiu's hook configuration series, specifically renaming callback function types to use a consistent "hook_" prefix. 

The patch changes the typedef names for hook callback functions from `cb_data_free_fn`/`cb_data_alloc_fn` to `hook_data_free_fn`/`hook_data_alloc_fn` to better reflect their purpose in the hook subsystem. This is a naming consistency improvement suggested by Patrick Steinhardt during review, with no functional changes to the code.

The changes affect both the hook implementation (hook.c) and its public interface (hook.h), updating all related function signatures and documentation. The new names make the types' association with the hook subsystem immediately clear, following Git's convention of prefixing subsystem-specific types. This is part of Adrian's ongoing effort to clean up and standardize the hook API as he extends its configuration support.
