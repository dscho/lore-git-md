This is a feature patch in Adrian Ratiu's ongoing hook configuration series, adding config scope visibility to `git hook list` output. The patch introduces a `--show-scope` flag that displays where each hook was configured (system/global/local), mirroring the tab-separated output style of `git config --show-scope`.

The implementation stores the config scope during the config callback phase and carries it through to the hook structs. Traditional hooks from the hookdir remain unaffected since they don't come from config. The change is backward compatible - without the flag, output remains unchanged. Tests verify both the new scope display and that traditional output format stays stable.

Key technical details:
- Adds `enum config_scope` to hook structs
- Uses uintptr_t packing for scope storage in intermediate cache
- Follows existing `git config --show-scope` output convention
- Touches hook.c, hook.h, builtin/hook.c, and documentation
- Includes comprehensive tests for new behavior

This continues Adrian's work to improve hook configuration visibility, now giving users insight into where hooks are defined. The patch appears well-integrated with prior changes in the series and follows established Git conventions for config scope display.
