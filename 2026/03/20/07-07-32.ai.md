This is a refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series (patch 6/14). The change extracts the object ID prefix parsing logic from `init_object_disambiguation()` into a new standalone `parse_oid_prefix()` function. - Validating hex characters in object ID prefixes
- Converting between hex and binary representations
- Preserving the original algorithm (hash type) if specified
- Writing results to both hex and binary output buffers when provided
