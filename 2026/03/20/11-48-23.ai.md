Bugfix for a NULL pointer dereference in path-walk error handling.

This patch fixes a crash that occurs when Git fails to find a tree or blob object during path traversal. The error reporting code incorrectly tries to dereference a NULL pointer (`o`) when formatting the error message, even though the OID it needs is available in the `entry` struct. The fix is straightforward - use `entry.oid` instead of `o->oid` in the error message.

The bug is reachable through `git backfill` when a tree entry's object is missing from the local object database. The patch is small and focused, with a clear commit message explaining both the problem and solution. While the impact is limited to error reporting (not affecting normal operation), it's an important fix since error paths should be robust.
