This is the second patch in Patrick Steinhardt's 14-part series to remove `the_repository` dependence from Git's fsck subsystem. The patch focuses on converting `fsck_finish()` and its helper function `fsck_blobs()` to take an explicit `struct repository *` parameter instead of relying on the global variable.

The changes are mechanical but widespread, touching several built-in commands (`fsck`, `index-pack`, `unpack-objects`) and core object-file handling code. The patch maintains the same behavior while removing implicit state dependence, which is a key goal of the broader `the_repository` removal effort. 

The implementation looks clean and follows the pattern established in the series - converting one logical piece of the subsystem at a time. Given this is part of a well-structured series from an experienced contributor, it appears to be a solid step toward making the fsck subsystem more modular and backend-agnostic.
