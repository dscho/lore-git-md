This is a test improvement for the `diff-highlight` contrib script, part of Jeff King's ongoing series to enhance this Perl-based diff highlighting tool. The patch adds missing test coverage for color configuration options that were introduced in 2014 but never properly tested.

The patch demonstrates Jeff's characteristic thoroughness - he's adding tests for both color configuration approaches supported by `diff-highlight`: the default highlight/reset style and the alternative normal/highlight style. The tests verify that colors can be configured via Git's color.* settings and that they produce the expected ANSI color sequences in the output.

This is a focused, well-justified addition to the test suite that will help prevent regressions as the color handling code is modified in subsequent patches. The changes are limited to the test script and don't touch the actual highlighting logic, making this a low-risk but valuable improvement to the test coverage.
