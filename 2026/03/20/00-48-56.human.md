Performance optimization for the `diff-highlight` Perl script, part of Jeff King's ongoing series to improve this contrib tool. This patch specifically reduces the number of `git config` processes spawned when fetching color settings, from six separate calls down to one by using `--get-regexp` with the newer `--type=color` option (available since Git 2.18.0).

The change introduces a caching mechanism that fetches all color-related configs in a single pass, then looks them up locally. This is particularly beneficial when no custom colors are configured, as it avoids the overhead of multiple process spawns just to check default values. The optimization doesn't affect external callers like `diff-so-fancy` that pass colors directly to the module.

Jeff includes a handy debugging tip showing how to verify the improvement using `GIT_TRACE=3`. The patch maintains the script's fallback behavior when Git isn't available, preserving compatibility. This is a clean, focused optimization that follows Jeff's typical pattern of thoughtful performance improvements backed by solid testing.
