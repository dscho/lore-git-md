This is part 3/14 of Patrick Steinhardt's ongoing ODB (object database) abstraction series, which aims to make Git's object storage backend-agnostic. The patch introduces a new `struct odb_for_each_object_options` to replace direct flag parameters when iterating over objects.

The change replaces scattered flag parameters with a centralized options structure, making the interface more extensible for future needs (such as prefix-based iteration planned in a subsequent commit). The patch updates all callers across multiple subsystems - including `builtin/cat-file.c`, `builtin/pack-objects.c`, and the commit-graph code - to use the new structure while maintaining identical behavior.

This is a mechanical but well-executed refactoring that follows established patterns from earlier patches in the series. The changes are straightforward and touch only the iteration plumbing, not affecting core functionality. As with the rest of the series, this moves Git incrementally closer to supporting pluggable storage backends while keeping the existing behavior intact.
