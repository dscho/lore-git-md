This is a feature patch from Mirko Faina that renames the `--cover-letter-format` option to `--commit-list-format` in `git format-patch`. The change makes the option name clearer about its purpose (formatting the commit list rather than the cover letter itself) and aligns it with the configuration variable name. 

The patch also makes the option imply `--cover-letter` by default unless `--no-cover-letter` is specified, which is a sensible behavior change since specifying a format for the commit list would naturally suggest wanting a cover letter. The changes include updates to documentation, command-line parsing, and test cases to reflect the new name and behavior.

This is patch 3/8 in a v2 series that builds on Mirko's earlier work improving commit list formatting in format-patch. The series has already incorporated feedback from Kristoffer Haugsbakk and appears well-structured with thorough test coverage. The change is non-controversial and follows Git's established patterns for format string handling.
