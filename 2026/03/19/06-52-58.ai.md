This is a major refactoring patch series from Patrick Steinhardt that makes object name handling (disambiguation and abbreviation) backend-generic in Git's object database (ODB) layer. It's part of the ongoing ODB abstraction effort to enable pluggable storage backends.

The series moves core functionality for handling object names (like `git rev-parse` operations) into the ODB backend interface, allowing different storage backends to implement their own logic for:
- Finding ambiguous object prefixes (when a short hash matches multiple objects)
- Calculating shortest unique abbreviations
- Iterating through objects with a given prefix

The changes touch many parts of Git's object handling code, with significant rewrites to `object-name.c` and additions to the ODB interface. The series builds on Patrick's previous work on object counting and continues his MongoDB proof-of-concept work (though he notes this isn't an endorsement of MongoDB as a production backend).

This is a complex but important infrastructure change that enables future work on alternative storage backends.
