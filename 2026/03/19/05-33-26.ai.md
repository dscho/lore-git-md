This is a build system patch from Patrick Steinhardt, part of an 8-patch series introducing precompiled header support and reorganizing build infrastructure. Patch 7/8 splits platform-specific compatibility sources into their own static library, preparing for the upcoming PCH implementation in patch 8/8.

The change moves all compatibility sources (previously mixed with main library sources) into a separate `compat_sources` list that gets built as a distinct `compat` static library. This isolation is necessary because some compatibility sources intentionally avoid including `git-compat-util.h`, which would break when PCH implicitly includes it for all compilation units. The patch touches 79 lines in meson.build, mostly mechanical relocations of source file paths from `libgit_sources` to the new `compat_sources` list.

The implementation maintains all existing functionality while enabling selective PCH application - the main library will use PCH while the compatibility code won't. This follows Phillip Wood's earlier review about reftable backend considerations. The change is well-contained and clearly motivated, with the commit message explaining both the technical need and the solution approach. As the penultimate patch in a carefully reviewed series, it appears ready for merging.
