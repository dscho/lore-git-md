This is a feature patch from Mirko Faina that improves the usability of `git format-patch --commit-list-format` by making the "log:" prefix optional for custom format strings. The change is part of an ongoing series to enhance commit list formatting in format-patch cover letters.

The patch allows users to omit the "log:" prefix when specifying a custom format string, as long as the string contains a '%' placeholder character. This matches the behavior of `git log --format` and reduces typing for common cases. The implementation checks for the presence of '%' to determine if the string should be treated as a format specifier.

The change includes documentation updates explaining the new behavior and adds test cases to verify both the successful case (format string containing %) and the failure case (plain string without %). The tests ensure backward compatibility is maintained while improving the user experience.

This is the 8th patch in the v2 series, which has already addressed prior feedback and appears ready for merging. The change is straightforward and non-controversial, following Git's established patterns for format string handling. The series as a whole demonstrates careful attention to both implementation quality and user-facing documentation.
