This is part 4/8 of Patrick Steinhardt's build system improvement series, focusing on tooling reorganization. The patch moves the Unicode data update script from `contrib/` to the new `tools/` directory, continuing the series' goal of separating essential build infrastructure from optional contributions.

The `update-unicode.sh` script is used to update Git's internal Unicode data when new versions of the Unicode standard are released. Patrick argues this belongs in `tools/` as it's core developer-facing infrastructure rather than optional contrib material. The change is purely mechanical - moving files with no content modifications - and follows the same pattern as previous patches in the series that relocated other build-related scripts.

This patch maintains the script's functionality while better reflecting its role in Git's development workflow. The relocation is part of a broader cleanup effort to make the distinction between essential tools and optional contributions clearer. As with the rest of the series, this change has been reviewed and appears ready for merging, with no outstanding technical concerns.
