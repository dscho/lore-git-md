This is the third patch in Taylor Blau's series addressing geometric repacking issues with MIDX bitmaps. It adds a test case demonstrating the problem where objects that were once cruft (unreachable) but later become reachable can cause bitmap generation to fail when they reside in packs above the geometric split point.

The test creates a scenario where:
1. A commit is made unreachable (via reset and reflog expiration)
2. It gets packed into a cruft pack
3. The same object is later repacked into a regular pack (simulating it becoming reachable again)
4. A geometric repack is attempted with bitmap generation

The test is marked as `test_expect_failure` since the fix comes in the next patch. This is a standard practice to document the bug before fixing it. The test appears well-constructed to isolate the specific failure case the series aims to address.

This patch is purely additive - it doesn't change any behavior, just documents the issue. The test will be flipped to `test_expect_success` once the full series is applied. The commit message is concise but clear about its purpose as a demonstration of the problem.
