GSoC application from Bilal El Khatabi proposing to migrate path-related queries from `git rev-parse` to the new `git repo info` command. The proposal focuses on a limited set of path fields with clear `rev-parse` equivalents, emphasizing test coverage and documentation. Key considerations include path naming conventions and output format (relative vs absolute paths). Bilal demonstrates familiarity with `builtin/repo.c` and prior mailing list discussions about the `git repo` command family, and mentions having completed a microproject patch. The scope deliberately avoids combining `repo info` and `repo structure` work to maintain focus. Open questions remain about which existing threads or design discussions would provide the best starting points for this work.
