This is part 2/8 of Patrick Steinhardt's build system improvement series, focusing on relocating the Coccinelle infrastructure from `contrib/` to the new `tools/` directory. The patch moves all Coccinelle-related files (semantic patch rules, tests, and supporting scripts) while updating all references in the build system (Makefile, meson.build) and CI scripts.

The rationale is straightforward: Coccinelle is a core part of Git's build infrastructure, used both in CI and by developers to detect antipatterns and enforce coding standards. Its previous location in `contrib/` (traditionally for optional/third-party contributions) was misleading. The mechanical changes are comprehensive but low-risk, touching only paths and documentation references.

This patch follows the series' first step that established the `tools/` directory skeleton. It demonstrates Patrick's characteristic thoroughness - every build system integration point is updated, including the spatchcache script's internal documentation. The changes maintain all existing functionality while better reflecting Coccinelle's role in the project.

While purely administrative, this relocation is part of a larger effort to rationalize Git's build infrastructure organization. The patch has already been reviewed positively in previous iterations, with only minor documentation tweaks (like fixing a "compileir" typo) applied since v2. It's now ready for merging as part of the complete series.
