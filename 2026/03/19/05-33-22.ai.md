This is part 3 of Patrick Steinhardt's 8-patch series reorganizing Git's build infrastructure. The patch moves the `coverage-diff.sh` script from `contrib/` to the new `tools/` directory, continuing the effort to separate essential developer tooling from optional contributions.

The `coverage-diff.sh` script provides test coverage information for the Git codebase, making it clearly part of the core build/test infrastructure rather than an optional contribution. The change is purely mechanical - the script is relocated without modifications. This follows the pattern established in earlier patches of the series, where build-related tools are being consolidated in the new `tools/` directory.

The patch is straightforward with no technical changes to the script itself. It's part of the broader cleanup that began with patch 1/8 establishing the `tools/` directory structure. The relocation makes logical sense given the script's purpose, and the change is minimal - just a file move with no functional impact. The series as a whole has already received positive reviews, with Phillip Wood confirming the changes look good and Kristoffer Haugsbakk providing minor documentation fixes in later patches.
