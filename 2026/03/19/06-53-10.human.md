This is the twelfth patch in Patrick Steinhardt's 14-part series refactoring Git's name handling for object database (ODB) abstraction. The patch moves the logic for computing loose object abbreviation lengths into the ODB backend interface.

The change extracts the loose-object-specific abbreviation calculation from `object-name.c` into a new `odb_source_loose_find_abbrev_len()` function in `object-file.c`. This continues the series' pattern of making object name handling backend-agnostic by moving format-specific logic into the appropriate backend implementation.

The patch introduces a new callback-based approach using `find_abbrev_len_cb()` and leverages the `oid_common_prefix_hexlen()` helper added in the previous patch. This eliminates some redundant hex conversions and simplifies the control flow while maintaining the same behavior. The changes are mechanical but important for the larger goal of making abbreviation calculation work with any object storage backend.

As with previous patches in the series, this appears to be a well-structured change that cleanly separates concerns while maintaining compatibility. This continues the series' steady progress toward making object name handling fully backend-independent.
