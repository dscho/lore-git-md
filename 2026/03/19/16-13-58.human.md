This is a follow-up discussion about a proposed `--cc` option for `get_maintainer.pl`, a Linux kernel development tool that interacts with Git's email workflow. The original patch proposed adding this option to format output for `git send-email --cc`, but this response from Joe Perches expresses skepticism about its usefulness.

The reply argues that the proposed feature isn't particularly valuable, suggesting that users should "just use a script" instead of adding this capability directly to `get_maintainer.pl`. This pushes back against the convenience argument made in the original patch, implying the existing workflow with intermediate scripts is sufficient.

The exchange highlights a difference of opinion about where to draw the line between built-in functionality and external scripting in development tools. While the original patch seemed technically sound, this response questions whether it solves a problem that needs solving at the tool level. The discussion remains civil but shows the kind of pushback that can emerge even for small, well-contained changes when they're perceived as unnecessary complexity.
