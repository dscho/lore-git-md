This is part 5 of Patrick Steinhardt's 14-patch series refactoring Git's object name handling as part of the ODB (object database) abstraction effort. The patch moves the logic for iterating through packed objects with a given prefix from `object-name.c` to `packfile.c`, continuing the pattern established in earlier patches of making object name operations backend-generic.

The change replaces direct packfile iteration in `object-name.c` with calls to the new ODB interface, specifically using the `packfile_store_for_each_object()` function with prefix options. The implementation details for handling multi-pack-indexes and individual packfiles are now encapsulated in `packfile.c` with new helper functions `for_each_prefixed_object_in_midx()` and `for_each_prefixed_object_in_pack()`.

This is a mechanical but important step in the ODB abstraction - it moves more core functionality into the storage backend interface while maintaining the same behavior. The patch follows Patrick's characteristic thorough approach, with careful attention to error handling and maintaining the existing optimization of stopping iteration when ambiguity is detected. As with the rest of the series, this enables future alternative storage backends to implement their own prefix-based iteration logic.
