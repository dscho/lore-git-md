This is part 4/8 of Patrick Steinhardt's build system improvement series, focusing on relocating developer tooling from contrib/ to a new tools/ directory. The patch moves the Unicode data update script (update-unicode.sh) and its associated files to the new location, as this is considered essential build infrastructure rather than optional contrib material.

The change is straightforward - it's a pure file relocation with no functional modifications. The script is used to update Git's internal Unicode data when new standards are released, making it a core development tool. This continues the series' goal of separating essential build tools from optional contributions.

The patch follows the same pattern as previous parts in the series, maintaining all file permissions and contents while just changing the directory structure. It's a mechanical change that has already received positive feedback in earlier reviews of the overall series.
