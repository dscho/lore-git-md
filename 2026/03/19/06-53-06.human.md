This is the eighth patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling to be backend-agnostic, part of the larger ODB abstraction effort. The patch converts `get_short_oid()` - which resolves abbreviated object IDs - to use the new generic `odb_for_each_object()` interface instead of backend-specific functions.

The change removes the now-obsolete `find_short_packed_object()` function and replaces both it and `find_short_object_filename()` with a single call to the ODB iterator. This makes the abbreviated object ID resolution work consistently across all storage backends while maintaining the same behavior. The patch is a natural progression from the previous work that introduced the iteration infrastructure, showing Patrick's systematic approach to this refactoring.

The diff is clean and focused, removing 26 lines of backend-specific code while adding just 6 lines to use the new interface. As with earlier patches in the series, this appears to be a well-executed step toward the goal of making object name handling fully backend-agnostic.
