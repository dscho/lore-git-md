This is a refactoring patch as part of the ongoing `the_repository` removal effort. René Scharfe continues his steady work eliminating global variables from Git's codebase, this time targeting the split-index subsystem.

The patch removes direct usage of `the_repository` and `the_hash_algo` globals in split-index.c, instead using the hash algorithm from the passed-in index_state's repository pointer. The changes are mechanical but important for making the code more explicit about its dependencies. The diff shows straightforward replacements where hash-related operations now use `istate->repo->hash_algo` rather than the global versions.

This follows the established pattern for these conversions - the patch is small, focused, and clearly correct. As with most of René's work, it's a clean improvement with no visible downsides. The commit message is characteristically terse ("Low-hanging fruit..") but the change speaks for itself. This will likely be picked up by Junio without further discussion.
