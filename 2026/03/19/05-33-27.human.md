This is the final patch in Patrick Steinhardt's build system improvement series, implementing precompiled header (PCH) support for the Meson build system. The patch demonstrates a 30-40% speedup in build times by precompiling the frequently-included "git-compat-util.h" header.

The implementation is straightforward - it creates a new "tools/precompiled.h" file that simply includes git-compat-util.h, then configures Meson to use this as a precompiled header via the c_pch option. The approach takes advantage of the fact that nearly every compilation unit includes git-compat-util.h either directly or indirectly.

Benchmarks show significant improvements, with build times dropping from ~14.5s to ~10.3s (a 1.4x speedup). The patch builds on the previous work in the series, particularly the separation of platform-specific compatibility sources into their own static library (patch 7/8) to avoid PCH-related issues with those files.

This change completes the two-pronged goal of the series: reorganizing build infrastructure into a new tools/ directory and adding PCH support. The series has gone through three iterations with all technical concerns addressed, and appears ready for merging.
