This is the first patch in Taylor Blau's series addressing geometric repacking issues with MIDX bitmaps. It's a straightforward memory leak fix in `builtin/pack-objects.c` where a `rev_info` struct wasn't being properly released in the `read_stdin_packs()` function.

The patch adds the missing `release_revisions()` call that was overlooked when the function was originally introduced in 2021 and not caught in a subsequent refactoring. This is a clean, uncontroversial fix that plugs a real leak - exactly the kind of preparatory cleanup you'd expect at the start of a series touching sensitive pack machinery.

As the first of five patches, this serves as groundwork for the more substantial changes to come in patches 3-5 that will introduce the new "excluded-open" pack state handling. The fix is small (just 2 lines) but important for correctness, and comes with a clear commit message explaining both the problem and solution.
