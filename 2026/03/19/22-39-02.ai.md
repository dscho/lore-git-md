This is a Coccinelle semantic patch targeting an outdated strbuf convention in the codebase. The patch adds a rule to detect and fix cases where code defensively checks `strbuf.buf` against NULL, which was necessary in very early versions of Git but has not been true for nearly two decades.

The semantic patch will convert any instances of `SB.buf ? SB.buf : ""` to simply `SB.buf`, since the NULL check is now redundant. This follows Junio's recent cleanup of similar code in rerere.c. The change is mechanical and low-risk, affecting only code that still follows this long-obsolete pattern.

The patch is part of ongoing code hygiene efforts to remove historical artifacts and modernize the codebase. As it comes from the maintainer and touches only Coccinelle rules (not runtime code), it's likely to generate much discussion. The change is small, focused, and clearly motivated by recent cleanup work.
