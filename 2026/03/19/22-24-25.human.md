This is the fourth patch in Taylor Blau's 5-part series addressing pack-objects issues with geometric repacking and MIDX bitmap generation. The patch implements the core fix for the problem where objects reachable through excluded packs were being missed during repacking.

The patch introduces a new "excluded-open" pack state (marked with '!') that tells pack-objects to include objects reachable from these packs while still excluding their direct contents. This solves the specific case where objects transition from cruft to reachable across pack boundaries, which was causing MIDX bitmap generation failures. The implementation carefully extends behavior via opt-in notation without altering defaults.

Key technical changes include:
- Adding a `pack_keep_in_core_open` flag to track excluded-open packs
- Modifying the reachability traversal to walk through commits in excluded-open packs
- Updating documentation to explain the new '!' pack prefix behavior
- Adding tests that verify the new functionality works as expected
