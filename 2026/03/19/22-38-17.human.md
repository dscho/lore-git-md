This is a feature patch in Mirko Faina's series improving `git format-patch --commit-list-format`. The patch introduces a new "modern" preset format for commit lists in cover letters, providing a cleaner alternative to the existing "shortlog" format.

The new preset produces output like "[1/3] commit subject" for each commit, matching what many users would manually specify with `log:[%(count)/%(total)] %s`. This gives a more compact and standardized view of the patch series contents while maintaining all the key information. The change includes documentation updates and test coverage verifying both the new preset and its interaction with configuration settings.

This continues the series' trend of thoughtful usability improvements to commit list formatting. The implementation is straightforward, building on existing infrastructure, and the tests demonstrate clear backwards compatibility with the older formats. As with previous patches in the series, this appears non-controversial and well-aligned with Git's conventions for format string handling.
