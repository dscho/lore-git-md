This is part 4 of Patrick Steinhardt's 14-patch series refactoring Git's object name handling to be backend-generic in the ODB layer. The patch moves logic for iterating through loose objects with a given prefix from object-name.c to object-file.c as part of the ODB abstraction effort.

The key changes are:
1) Moves prefix-based iteration of loose objects into the ODB interface by extending `odb_for_each_object_options` with new `prefix` and `prefix_hex_len` fields
2) Makes the loose object cache private to object-file.c by converting `odb_source_loose_cache()` to file scope
3) Updates the prefix matching callback in object-name.c to work with the new ODB iteration interface

This continues the systematic restructuring of object name resolution to work with pluggable storage backends. The changes maintain existing behavior while moving implementation details into the ODB layer where they can be customized by different backends. The patch follows the series' pattern of careful, incremental refactoring that preserves functionality while improving architectural separation.
