This is the fourth patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling as part of the ODB (object database) abstraction effort. The patch moves logic for iterating through loose objects with a given prefix from `object-name.c` to `object-file.c`, making it backend-aware.

The change allows different object storage backends to implement their own prefix iteration logic while maintaining the same interface. The patch:
1. Extends the `odb_for_each_object_options` struct to support prefix filtering
2. Moves the loose object iteration implementation into `object-file.c`
3. Makes the loose object cache helper function (`odb_source_loose_cache`) file-scoped since it's no longer needed externally
4. Updates the prefix matching callback in `object-name.c` to use the new interface

This is a technical but important step in the ODB abstraction work, continuing Patrick's systematic approach to making object handling backend-agnostic. The patch maintains existing behavior while improving the architecture for future backend implementations. As with the rest of the series, it demonstrates Patrick's characteristic thoroughness in handling edge cases and maintaining clean interfaces.
