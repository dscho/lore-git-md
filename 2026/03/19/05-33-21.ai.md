This is part 2/8 of Patrick Steinhardt's build system improvement series, focusing on relocating the Coccinelle infrastructure from contrib/ to the new tools/ directory. The patch moves all Coccinelle-related files (semantic patches, tests, and supporting scripts) while updating all references in the build system (Makefile, meson.build) and CI scripts. The justification is that Coccinelle has become an integral part of Git's build infrastructure - used in CI for detecting antipatterns and interface misuses - making its placement in contrib/ misleading since that directory is meant for optional contributions rather than core tooling.

The changes are mechanical but wide-ranging, touching multiple build systems. The patch updates paths in the Makefile (including build artifacts and test rules), meson.build configuration, and the run-static-analysis.sh CI script. It also adjusts internal documentation references in the Coccinelle README and spatchcache script. The semantic patch files themselves are moved verbatim, preserving all their functionality.

This relocation is part of a broader effort to reorganize Git's build infrastructure by separating essential tools from optional contrib/ material. The patch maintains all existing Coccinelle functionality while better reflecting its role as a core development tool. The changes have been reviewed positively in previous iterations of the series, with only minor documentation nits addressed since v2.
