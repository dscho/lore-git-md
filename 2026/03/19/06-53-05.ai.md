This is the seventh patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling to be backend-generic as part of the ODB abstraction effort. The patch converts `repo_collect_ambiguous()` from using backend-specific object disambiguation to the new generic `odb_for_each_object()` interface introduced earlier in the series.

The change simplifies the ambiguous object collection logic by:
1. Replacing the disambiguation state machine (`struct disambiguate_state`) with direct iteration using the ODB backend interface
2. Using the new `parse_oid_prefix()` helper from patch 6/14 to validate the input prefix
3. Leveraging the prefix filtering capability of `odb_for_each_object()` to only return matching objects

The patch maintains identical behavior while removing backend-specific code paths (`find_short_object_filename()` and `find_short_packed_object()`). This continues the series' pattern of moving object name operations into the ODB layer to support future pluggable backends. The changes are focused and mechanical, touching only `object-name.c` with no behavioral changes expected.

This patch builds directly on the infrastructure established in previous patches, particularly the ODB iteration interface and prefix parsing. It demonstrates the series' progression from preparatory work to actual backend-generic conversions of specific object name operations.
