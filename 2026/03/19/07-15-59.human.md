This is a small refactoring patch from the Git maintainer Junio C Hamano, cleaning up an outdated workaround in the rerere (reuse recorded resolution) code.

The patch removes special handling for empty strbufs that was added in 2007 when strbuf.buf could be NULL for empty buffers. Since 2007, strbuf has guaranteed that .buf always points to a NUL-terminated string (even when empty), making this defensive coding unnecessary. The code has survived multiple refactorings over 19 years without anyone noticing the obsolete check.

The change is straightforward - it simply removes the conditional checks for NULL buffers when updating hash contexts, since we can now safely assume the buffer exists. This makes the code simpler and more consistent with modern Git conventions. As a maintainer-authored cleanup touching well-tested code, it's likely to be merged without controversy.
