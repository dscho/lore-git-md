This is a refactoring patch in Mirko Faina's series improving `git format-patch --commit-list-format`. The patch adds line wrapping to commit messages in the generated cover letter when they exceed the standard email width (MAIL_DEFAULT_WRAP).

The change is straightforward - it introduces a new strbuf to hold the wrapped text and uses Git's existing `strbuf_add_wrapped_text()` utility to format long commit messages before writing them to the cover letter. The implementation maintains the existing behavior while adding the wrapping capability, cleaning up both buffers properly after each iteration.

This is a natural evolution of the series that improves readability of formatted patches without changing the underlying functionality. The patch follows Git's conventions for string handling and fits well with the surrounding code. As with the rest of the series, it appears uncontroversial and ready for merging.
