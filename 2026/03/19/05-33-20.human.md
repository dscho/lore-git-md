This is the first patch in an 8-part series introducing build system improvements. The patch establishes a new "tools/" directory to house essential build infrastructure that was previously scattered in the "contrib/" directory alongside optional/experimental code. 

Patrick Steinhardt notes that while "contrib/" was meant for non-core components, it had accumulated critical build tools that shouldn't be considered optional. The new "tools/" directory will provide a dedicated home for these, starting with just a README and Meson skeleton in this initial patch. The changes are minimal but foundational - updating the Makefile and meson.build to recognize the new directory while excluding it from source file searches.

This is a straightforward infrastructure change that sets up for more substantive moves of build tooling in subsequent patches. The patch appears clean and well-motivated, with no obvious technical concerns. As the first in a series that has already received positive review feedback, it seems ready to proceed.
