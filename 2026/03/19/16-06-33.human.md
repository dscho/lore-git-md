This is a feature patch adding a new `--cc` option to `get_maintainer.pl`, a script used to identify maintainers for Linux kernel patches. The change allows the script to output a comma-separated list of emails suitable for passing directly to `git send-email`'s `--cc` argument.

The patch is straightforward - it adds a new flag that modifies the output format to be a simple comma-separated list without any additional metadata (names, roles, etc). This makes it easier to pipe the maintainer list directly into `git send-email`. The author notes they've also submitted a complementary patch to Git itself to make `git send-email` recognize when an argument is an executable script and run it automatically.

The implementation looks clean and focused - it adds the new option while maintaining all existing behavior. The commit message clearly explains both the motivation and usage pattern. This appears to be a well-considered quality-of-life improvement for kernel developers who frequently need to email patches to multiple maintainers.
