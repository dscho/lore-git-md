Taylor Blau's v2 patch series (5 patches) addresses pack-objects issues during geometric repacking when MIDX bitmap generation fails due to packs not being closed under reachability. The solution introduces a new "excluded-open" pack state (marked with '!') to properly handle objects reachable through excluded packs while excluding their direct contents.

Key technical components:
- Fixes memory leak in `read_stdin_packs()`
- Refactors pack handling from string_lists to strmap (resolved issues: incorrect `pack_mtime_cmp()` assumption about `->util` contents and flag accumulation using '|=')
- Demonstrates failure case with once-cruft objects becoming reachable
- Implements core fix with `pack_keep_in_core_open` flag
- Modifies `builtin/repack.c` for excluded-open marking
