This is part 6 of Patrick Steinhardt's 14-patch series refactoring Git's object name handling to be backend-generic in the ODB layer. The patch extracts the logic for parsing object ID prefixes into a new standalone function `parse_oid_prefix()`, which will be reused in a subsequent commit.

The extracted function handles:
- Validating hex characters in the input name
- Converting between hex and binary representations
- Optionally storing results in either hex or binary form (via output parameters)
- Setting the hash algorithm for the resulting OID

The change is mechanical - the core logic remains identical to what was previously inline in `init_object_disambiguation()`, just moved to a reusable function. This follows the series' pattern of breaking down object name operations into smaller, more modular pieces that can be used by different ODB backends.

As with the rest of the series, this is a preparatory change that maintains existing behavior while making the code more flexible for future ODB backend implementations. The patch touches only `object-name.c` and follows Patrick's characteristic thoroughness - it includes proper parameter validation and handles both hex and binary output cases cleanly.
