Platform compatibility fix for macOS regex behavior. This is a small patch from Junio C Hamano that addresses a build failure in GitHub's macos-14 CI jobs. The issue stems from commit 54463d32 ("use enhanced basic regular expressions on macOS", 2023-01-08) which assumed all macOS platforms support the REG_ENHANCED flag for regex compilation. The patch makes the REG_ENHANCED usage conditional on its availability.

The change is minimal - just wrapping the REG_ENHANCED flag check in an #ifdef guard in compat/regcomp_enhanced.c. This maintains the enhanced regex behavior where supported while allowing builds to proceed on macOS versions that don't define this flag. The patch appears straightforward and well-motivated by the CI failures, though it would be useful to know exactly which macOS versions lack REG_ENHANCED.
