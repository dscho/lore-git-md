This is a feature patch enhancing `git send-email` to support executable scripts for recipient selection. The change allows passing scripts to --to/--cc/--bcc flags, which will be executed to dynamically generate recipient lists. This mirrors functionality used in the Linux kernel's get_maintainer.pl workflow.

The patch modifies the Perl implementation to detect executable files passed as recipients, running them with the corresponding flag and patch filenames as arguments. It includes thorough test coverage showing both basic script execution and proper argument passing. The implementation handles argument quoting safely via Perl's quotemeta.

The change looks well-considered with clear motivation (supporting maintainer script workflows) and comprehensive tests. The implementation is straightforward, modifying only the recipient processing logic while reusing existing command execution infrastructure. This seems like a useful quality-of-life improvement for users who regularly email patch series to dynamic recipient lists.
