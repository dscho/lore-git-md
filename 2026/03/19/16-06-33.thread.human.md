This thread discusses adding a `--cc` option to the Linux kernel's `get_maintainer.pl` script to format its output as comma-separated emails for use with `git send-email`. The original patch proposed two integration methods: piping the output or having `git send-email` execute the script directly.

While the implementation appears technically sound, Joe Perches has raised concerns about the feature's utility, suggesting existing scripting solutions may be preferable. This indicates the proposal may need to better demonstrate its advantages over current workflows to gain acceptance. The discussion highlights the coordination challenges between Linux kernel and Git tooling when modifying shared workflows.

The core question remains open: whether this change provides enough benefit to justify modifying both `get_maintainer.pl` and potentially `git send-email`, or if the status quo of using intermediate scripts is sufficient. The thread awaits either stronger use cases from the original author or further discussion about alternative approaches.
