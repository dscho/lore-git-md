This is a build system patch from Patrick Steinhardt, part of a series introducing precompiled header support in Meson. The patch splits platform-specific compatibility sources into their own static library to prepare for upcoming precompiled header (PCH) support.

The key change moves all compatibility sources (like Windows-specific code, platform shims, and fallback implementations) from the main libgit library into a separate 'compat' static library. This is necessary because some compatibility sources intentionally avoid including git-compat-util.h, which would be implicitly included via PCH. The change touches many platform-specific files across Windows, macOS, Cygwin, and Linux.

The patch is mechanical but wide-ranging, updating the Meson build configuration to properly organize the split while maintaining all existing functionality. It's part of a larger effort that will demonstrate 30-40% faster builds in the next patch when PCH support is fully implemented. The series has been reviewed by Phillip Wood and others, with only minor documentation nits addressed since v2.

This change shows careful consideration of build system interactions, particularly around platform compatibility code that needs special handling. The separation into a distinct library is a prerequisite for the performance improvements coming in the final patch of the series.
