This is the final patch in Patrick Steinhardt's 8-part series introducing build system improvements, specifically implementing precompiled header (PCH) support for the Meson build system. The patch demonstrates a 30-40% speedup in build times by precompiling git-compat-util.h, which is included in nearly every compilation unit.

The implementation uses Meson's c_pch option to create tools/precompiled.h as the PCH, which simply includes git-compat-util.h. Meson then forces inclusion of this precompiled header in all compilation units via compiler-specific mechanisms (like GCC's -include flag). Benchmark results show the main executable build time dropping from ~14.5s to ~10.3s.

This builds on the preparatory work in patch 7/8 which split platform-specific compatibility sources into a separate static library, ensuring they wouldn't be affected by the PCH's implicit inclusion of git-compat-util.h. The approach carefully maintains compatibility across platforms and with other ongoing efforts like the reftable backend work.

The patch is technically sound and completes the series' goal of speeding up builds while maintaining all existing functionality. With all prior feedback addressed in v3 and no outstanding objections, this appears ready for merging as the culmination of the infrastructure improvements. The changes are minimal (just 3 lines added across two files) but leverage Meson's built-in PCH support effectively.
