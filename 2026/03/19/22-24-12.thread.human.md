Taylor Blau has sent a 5-patch series addressing an edge case in Git's geometric repacking and MIDX bitmap generation. The issue occurs when geometric repacking encounters packs that aren't fully self-contained (missing some parent objects), which can cause MIDX bitmap generation to fail when it finds objects reachable through excluded packs but not present in the MIDX.

The solution introduces a new "excluded-open" pack state (marked with '!') that tells pack-objects to include objects reachable from these packs while excluding their direct contents. The series starts with preparatory cleanups - fixing a memory leak and refactoring pack list handling - then adds a test demonstrating the failure scenario before implementing the core fix. The changes are opt-in via the new notation rather than altering default behavior, minimizing risk to existing workflows.
