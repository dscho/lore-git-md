This is a major refactoring patch series from Patrick Steinhardt that makes object name handling (disambiguation and abbreviation) pluggable across different ODB backends. It's part of the ongoing ODB abstraction effort to support alternative object storage backends.

The series moves core logic for handling object name prefixes from object-name.c into the ODB backend infrastructure. This includes:
- Disambiguating partial object names by listing candidates
- Computing the shortest unique abbreviation for an object ID

These changes enable commands like `git commit`, `git log`, and `git rev-parse` to work with alternative backends. The series builds on previous work introducing generic object counting (ps/object-counting) and represents significant progress toward the ODB abstraction goal.

The patch set is substantial (14 patches touching 19 files) but appears carefully structured, with each commit focused on moving specific functionality. The changes are primarily internal plumbing - no new user-facing features are added, but the groundwork is laid for future backend implementations. Patrick notes this already works with a MongoDB proof-of-concept backend with minimal additional changes.

This is a technical but important series that continues Patrick's long-term effort to make Git's object storage layer more flexible. Reviewers will want to pay particular attention to the performance characteristics of the new generic implementations, since object name handling is performance-sensitive code.
