This is a follow-up discussion about a feature patch that enhances `git send-email` to support executable scripts for recipient selection. Kristoffer Haugsbakk is asking for clarification about how this new feature differs from the existing `--cc-cmd` and similar options.

The original patch (from Jim Cromie) allows passing executable scripts directly to `--to`, `--cc`, or `--bcc` flags, which will be run to dynamically generate recipient lists. Kristoffer notes that these recipients are already be CC'd, suggesting some potential redundancy, and questions how this differs from the existing `--*-cmd` options that also execute commands to get recipient lists.

The question indicates that while the implementation appears solid (as noted in the parent summary), there may be some confusion or overlap with existing functionality that needs clarification. This is a potential point for discussion about whether the new feature is sufficiently distinct from existing mechanisms to warrant inclusion.
