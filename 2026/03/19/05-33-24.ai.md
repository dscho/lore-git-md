This is part 5/8 of Patrick Steinhardt's build system improvement series, focusing on consolidating build infrastructure into a new "tools/" directory. The patch mechanically relocates various build-related scripts from the top-level directory to "tools/", updating all references across the Makefile, CMake, and Meson build systems.

The moved scripts include generator scripts for command lists, config lists, hooks, and language bindings (Perl/Python), along with utility scripts like check-builtins.sh and detect-compiler. The changeset is large but straightforward - it updates paths in build system files while keeping the scripts' functionality identical. 

This continues the series' goal of separating essential build infrastructure from optional contrib/ material. The patch follows the same pattern as previous parts in the series, with Phillip Wood having already confirmed the changes look good in review. No new functionality is introduced - this is an organizational change to make the codebase structure more logical.
