This is the eighth patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling to be backend-generic as part of the ODB abstraction effort. The patch converts `get_short_oid()` - the function that resolves abbreviated object IDs - to use the new generic `odb_for_each_object()` interface rather than backend-specific functions.

The key changes are:
1. Removes the `find_short_packed_object()` function which was specific to the packed object backend
2. Replaces both `find_short_object_filename()` and `find_short_packed_object()` calls with a single `odb_for_each_object_ext()` call that works across all backends
3. Maintains the same behavior including the fallback retry logic when objects are missing
4. Uses the structured `odb_for_each_object_options` introduced in earlier patches to specify the prefix matching parameters

The patch continues the series' pattern of systematically replacing backend-specific code with generic ODB interfaces while preserving existing behavior. This moves Git closer to supporting pluggable storage backends by removing another filesystem-specific implementation detail. The changes are focused in `object-name.c` and build on the infrastructure from previous patches.
