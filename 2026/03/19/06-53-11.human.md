This is the 13th patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling for the ODB (object database) abstraction effort. The series systematically modularizes how Git handles object disambiguation and abbreviation to support pluggable storage backends.

This patch moves the logic for calculating minimum unique abbreviation lengths for packed objects from `object-name.c` to `packfile.c`, introducing a new packfile_store_find_abbrev_len()` function. Like the previous patch that did the same for loose objects, this continues the pattern of moving object name handling into backend-specific implementations.

The changes are substantial but mechanical - 123 lines removed from `object-name.c` and 111 added to `packfile.c` with equivalent functionality. The patch maintains all existing behavior while preparing for future backend flexibility. As with the rest of the series, this appears to be a well-structured, incremental change that moves the ODB abstraction forward without introducing new functionality or behavior changes.

Given Patrick's track record with major refactorings and the careful progression of this series, the patch looks solid. The lack of review comments so far may simply reflect the technical nature of the changes rather than any quality concerns.
