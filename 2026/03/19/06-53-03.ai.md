This is part 5 of Patrick Steinhardt's 14-patch series refactoring Git's object name handling to be backend-generic in the ODB layer. The patch moves logic for iterating through packed objects with a given prefix from `object-name.c` to `packfile.c`, continuing the ODB abstraction effort.

The change replaces direct MIDX and packfile iteration in `object-name.c` with calls to the new `packfile_store_for_each_object()` interface that was introduced in earlier patches. The core matching logic (`match_hash()`) and iteration code is moved to `packfile.c` where it becomes part of the packfile storage backend implementation. The `find_short_packed_object()` function in `object-name.c` is simplified to use the new ODB iteration interface with prefix options.

This is a mechanical refactoring that maintains existing behavior while moving implementation details into the appropriate backend layer. The patch follows the series' pattern of systematically moving object name disambiguation logic out of `object-name.c` and into storage-specific implementations, a key step toward making the ODB backend properly pluggable. The changes are focused and well-contained, touching only the expected files with no surprises.
