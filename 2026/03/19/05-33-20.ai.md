This is the first patch in Patrick Steinhardt's 8-part series reorganizing Git's build infrastructure. It introduces a new "tools/" directory to house essential build-related scripts and tooling that were previously scattered in the "contrib/" directory, which was originally intended only for optional/experimental contributions.

The patch creates the new directory structure with a README explaining its purpose and updates both the Makefile and meson.build to recognize the new location. The changes are minimal at this stage - just establishing the directory skeleton - with actual tool migrations coming in subsequent patches. This follows Patrick's stated goal of separating core build infrastructure from truly optional contrib/ material.

The patch is straightforward infrastructure work with no functional changes yet. It sets the stage for the more substantive moves in later patches while maintaining compatibility with existing build systems. As the first step in a larger reorganization, it's a clean foundation that has already received positive feedback in the thread.
