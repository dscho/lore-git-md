This is a documentation patch in Mirko Faina's ongoing series improving `git format-patch --commit-list-format`. The patch adds documentation for two previously undocumented placeholders - `%(count)` and `%(total)` - that were introduced with the commit list formatting feature.

The changes are straightforward: the patch adds clear explanations of these placeholders to the pretty-formats documentation, noting they are specifically for use with `format-patch`'s commit list formatting. The `%(count)` placeholder shows a patch's position in the series, while `%(total)` indicates the total number of patches.

This is part of a well-structured series that has already addressed prior review feedback. The documentation addition is non-controversial and follows Git's standard patterns for format string documentation. The patch maintains the series' focus on improving usability and completeness of the commit list formatting feature.
