This is a build system improvement series from Patrick Steinhardt, now in its third iteration. The 8-patch series combines two distinct but related changes: reorganizing build infrastructure into a new "tools/" directory and adding precompiled header support to the Meson build system.

The first five patches establish the new "tools/" directory structure, moving various build-related scripts and the Coccinelle infrastructure from "contrib/" to this new location. This follows through on Patrick's earlier promise to clean up the contrib/ directory by separating essential build tools from optional contributions. The changes are mechanical but wide-ranging, touching multiple build systems (Makefile, CMake, Meson).

The last three patches implement precompiled header support in Meson, demonstrating a 30-40% compilation speed improvement. This required some preparatory work in git-compat-util.h and changes to how compatibility sources are compiled (split into a separate static library in patch 7/8). The implementation uses Meson's c_pch option with tools/precompiled.h as the entry point.

The v3 iteration includes minor commit message improvements from Kristoffer Haugsbakk (fixing "compileir" typo and adding a missing comma) and maintains all the technical improvements from v2, where the precompiled header specification was simplified from an array to a single file. Phillip Wood has reviewed the changes positively, particularly the improved commit message explaining the implicit PCH inclusion behavior.

While Junio C Hamano has expressed some concern about potential workflow impacts for Coccinelle users, there are no blocking objections. The series appears ready for merging, with all technical aspects addressed and only minor administrative polish applied since v2. The changes demonstrate careful consideration of cross-platform compatibility and build system interactions, particularly with the reftable backend constraints.
