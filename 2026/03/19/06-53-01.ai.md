This is the third patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling as part of the ODB abstraction effort. The patch introduces a new `struct odb_for_each_object_options` to replace direct flag parameters in object iteration functions, preparing for future extensions like prefix-based iteration.

The change systematically replaces flag parameters with the new options structure across 11 files, including core object database operations (`odb.c`), packfile handling (`packfile.c`), and command implementations (`builtin/cat-file.c`, `builtin/pack-objects.c`). The patch maintains all existing functionality while making the interface more extensible - the structure currently only contains the flags field but can grow to support additional parameters like object prefixes in future patches.

This is a mechanical but important infrastructure change that follows good software engineering practice by introducing the options structure before it's strictly needed. The patch demonstrates Patrick's characteristic thoroughness, updating all callers consistently and including documentation for the new structure. As part of the larger ODB abstraction work, this change helps move Git toward supporting pluggable storage backends with their own object iteration logic.
