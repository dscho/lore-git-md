Feature proposal for `git am` to fetch and apply patches directly from message IDs (e.g. lore.kernel.org URLs). Shreyansh Paliwal suggests adding a `--fetch-mid` option with configurable public-inbox endpoints. Junio C Hamano notes this functionality already exists in the `b4` tool, which can fetch patches by message ID and output in `git am`-compatible format via `b4 am -o-`. The proposal now needs to justify why integrating this into Git core would be better than using the existing external tool. Open questions remain about error handling and private inbox support, but the primary challenge is demonstrating sufficient advantage over the `b4`-based workflow. The `b4` tool provides the key capabilities: fetching from lore.kernel.org by message ID, outputting mbox format, and piping to `git am`. Junio's response implies the bar for core integration is high when a dedicated external tool already solves the problem cleanly.
