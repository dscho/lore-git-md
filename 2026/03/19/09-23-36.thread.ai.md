Feature proposal for `git am` to fetch and apply patches directly from message IDs (e.g. lore.kernel.org URLs). Shreyansh Paliwal suggests adding a `--fetch-mid` option that retrieves patches from configurable public-inbox endpoints (default: `https://lore.kernel.org/git/<message-id>/raw`) before applying them with existing mbox handling. The base URL would be configurable via `am.publicInboxUrl`. Potential future expansion could fetch entire series from cover letter message IDs. Implementation appears straightforward since public-inbox serves patches in `git am`-compatible mbox format. Open questions include error handling for invalid IDs/network failures and whether to support private inbox configurations. This RFC seeks feedback before implementation as a workflow improvement for maintainers and reviewers who frequently apply mailing list patches.
