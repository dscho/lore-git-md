This is the 11th patch in Patrick Steinhardt's 14-part series refactoring Git's object name handling for the ODB abstraction effort. The patch simplifies how Git computes common prefixes between object IDs during abbreviation.

The change introduces a new `oid_common_prefix_hexlen()` function in hash.c that directly compares binary object IDs to find their common prefix length, rather than first converting them to hex strings. This is more efficient and eliminates the need for the `hex` field in `struct min_abbrev_data`. The patch updates the abbreviation logic in `object-name.c` to use this new helper.

This is a clean, focused optimization that builds on the previous infrastructure changes in the series. The patch follows Patrick's characteristic style of methodical refactoring - introducing a better primitive and then simplifying the callers to use it. While not a user-visible change, it improves the code quality and prepares for future patches in the series.
