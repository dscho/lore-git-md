This is a refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series. It extracts the object ID prefix parsing logic from `init_object_disambiguation()` into a new standalone function `parse_oid_prefix()`. 

The change is straightforward - the parsing code that validates hex digits and converts them into binary form is moved to a reusable function that can be called from multiple places. The new function maintains the same behavior but adds flexibility by allowing callers to optionally receive just the hex string, just the binary OID, or both.

This is a preparatory change that enables future patches in the series to reuse this parsing logic elsewhere. The patch follows Patrick's characteristic thorough style - it's a clean extraction with no behavior change, good commit message explaining the motivation, and proper handling of edge cases. As part of the larger ODB abstraction effort, this helps move object name handling toward being backend-agnostic.
