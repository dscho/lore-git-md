This is a Coccinelle semantic patch targeting an old strbuf convention cleanup. Junio Hamano noticed some legacy code still guarding against the possibility of strbuf.buf being NULL for empty strbufs - a convention that hasn't been true in the modern codebase for years.

The patch adds a new rule to the strbuf.cocci file that will automatically convert any `SB.buf ? SB.buf : ""` patterns to just `SB.buf`, since the NULL check is no longer needed. This follows up on Junio's recent rerere.c cleanup work.

The change is straightforward and mechanical - it's the kind of cleanup that typically gets quick acks from reviewers. Since it comes from the maintainer himself and touches only Coccinelle rules (not runtime code), it's likely to be merged without much discussion. The patch is small and focused, doing one clear thing well.
