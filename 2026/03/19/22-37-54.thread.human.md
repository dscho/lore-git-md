This thread examines a puzzling macOS regex compatibility issue that surfaced in CI builds. The core problem involves the REG_ENHANCED flag, which was added to Git in 2023 for macOS regex handling but suddenly started causing failures in some macOS 14 CI jobs. Junio Hamano initially proposed making the flag's usage conditional, but René Scharfe's research revealed the flag was documented as available since macOS 10.12, making its absence in newer versions unexpected.

The situation has taken an interesting turn with Junio's latest observation that the CI failures appear inconsistently - some macOS 14 jobs pass while others fail, all running the same code. This leads him to reconsider the initial approach, as conditionally disabling the flag might hide real problems in regex tests that depend on enhanced mode functionality. The discussion has now moved from proposing a code fix to investigating potential CI environment inconsistencies, as the random failures suggest the issue may lie in the test setup rather than Git's code. Both Junio and René agree further diagnosis is needed to understand why REG_ENHANCED appears unavailable in some macOS 14 environments despite historical documentation indicating it should be present.
