Junio Hamano has submitted a small but important platform compatibility fix for macOS regex behavior. The patch addresses build failures in GitHub's macos-14 CI jobs that occurred after commit 54463d32 introduced enhanced regular expression support on macOS. The issue stems from assuming all macOS platforms support the REG_ENHANCED flag - Junio's fix makes this conditional on the flag's availability.

The change is minimal, just adding an #ifdef guard around the REG_ENHANCED usage in compat/regcomp_enhanced.c. This maintains the improved regex behavior where supported while allowing builds to complete on macOS versions that don't define this flag. While the exact macOS versions affected aren't specified in the patch, the fix appears well-motivated by the concrete build failures observed in CI. Given Junio's role as maintainer and the straightforward nature of the change, this is likely to be merged quickly.
