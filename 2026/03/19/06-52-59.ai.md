This is a refactoring patch from Patrick Steinhardt that modernizes the oidtree code as part of his larger ODB abstraction effort. The oidtree subsystem provides efficient storage for object IDs using a critbit tree structure.

The patch makes several style and clarity improvements:
- Renames `oidtree_iter()` to `oidtree_each_cb()` and related data structures for better clarity
- Updates parameter and variable names to be more descriptive (e.g., `arg` -> `cb_data`)
- Adds comprehensive documentation comments explaining the oidtree API
- Changes `oidtree_contains()` to return a boolean instead of an integer
- Updates the unit tests to use the new boolean return value

These changes are preparatory work for subsequent patches in the series that will modify oidtree functionality. The patch maintains all existing behavior while making the code more maintainable and self-documenting. As the first in a 14-part series, this sets the foundation for more substantial changes to object name handling in the ODB layer.
