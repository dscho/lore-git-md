This thread introduces a Coccinelle semantic patch to clean up an obsolete strbuf pattern in the Git codebase. The patch targets defensive NULL checks of `strbuf.buf` that were needed in early Git versions but have been unnecessary for nearly 20 years. It mechanically converts `SB.buf ? SB.buf : ""` patterns to just `SB.buf`.

The change comes from the maintainer (Junio Hamano) as part of ongoing code modernization efforts, following similar recent cleanup in rerere.c. Since this is a mechanical change to Coccinelle rules rather than runtime code, and aligns with established cleanup direction, it's unlikely to generate controversy. The patch represents a small but meaningful step in removing historical artifacts from the codebase.
