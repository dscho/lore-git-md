Feature patch series finalizing a new `--cover-letter-format` option for `git format-patch`, now ready for merging after five iterations. This provides configurable formatting for cover letter commit lists through both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) interfaces while maintaining backward compatibility with the traditional shortlog-based format.

The implementation introduces new `%(count)` and `%(total)` placeholders in `pretty.c` for patch numbering, refactors the shortlog generation into a dedicated function, and adds strict validation to limit placeholders to cover letter contexts. The series comes with comprehensive test coverage in `t4014-format-patch.sh` and full documentation of both the CLI option and config variable behavior. Key design decisions around the "log:" prefix requirement and numbering format were resolved through discussion with Jeff King and Junio Hamano.

This appears to be a well-executed feature addition with clean separation of concerns - the shortlog generation is properly modularized, the pretty.c changes are minimal and focused, and the documentation is thorough. The author Mirko Faina has addressed all feedback across five versions, and with Junio's approval of the architecture and documentation, this looks ready to merge cleanly into the next release.
