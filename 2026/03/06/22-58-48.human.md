This is the final patch in a series implementing configurable cover letter formatting for `git format-patch`. The patch adds comprehensive documentation for the new `--cover-letter-format` command-line option and corresponding `format.commitListFormat` configuration setting.

The documentation explains:
- The new `commitListFormat` config option in `format.adoc`, noting it accepts the same values as the command-line option and defaults to "shortlog"
- The `--cover-letter-format` option in `git-format-patch.adoc`, detailing the two format types: "shortlog" (default) and custom formats prefixed with "log:"
- Example usage showing how to configure persistent formatting via gitconfig

This completes the feature implementation after six iterations of review and refinement. The series has received approval from both Jeff King (Peff) and Junio Hamano, with the author confirming this v6 is ready for merging. The documentation matches the implementation's behavior exactly, including the strict "log:" prefix requirement for custom formats and the integration with existing cover letter generation.
