This is a refactoring patch in a series implementing customizable cover letter formatting for `git format-patch`. The patch moves the shortlog-based commit summary generation into a dedicated function (`generate_shortlog_cover_letter()`) from where it was previously inline in `make_cover_letter()`.

The change is purely structural - no behavior is modified. The new function maintains all existing shortlog formatting parameters (2/4 indentation, line wrapping, author grouping) while making the code more modular. This prepares for subsequent patches that will introduce alternative formatting options through new config and command-line interfaces.

The patch is part of a well-reviewed series (now at v7) that has addressed all feedback, with Junio C Hamano and Jeff King having approved the approach. The author, Mirko Faina, confirms this version is final. The refactoring here is straightforward and unlikely to be controversial, serving as groundwork for the more substantive changes that follow in the series.
