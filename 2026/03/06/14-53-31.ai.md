This is part 5 of a 7-patch series adding `--trailer` support to `git rebase`, now in its 8th iteration. The series refactors trailer handling to make it reusable across commands while enabling in-process trailer manipulation during rebase.

This specific patch simplifies trailer argument handling in `git commit` and `git tag` by switching from `OPT_PASSTHRU_ARGV` to `OPT_STRVEC` for the `--trailer` option. The change means the trailer arguments no longer need to include the `--trailer=` prefix, allowing removal of the prefix-stripping code in `amend_file_with_trailers()`. The patch maintains all existing functionality while cleaning up the implementation.

The change aligns with the series' broader goal of making trailer processing more direct and efficient by avoiding unnecessary string manipulation. It builds on earlier patches that separated core trailer logic from I/O operations and introduced validation checks. The implementation has been reviewed and accepted by the maintainer, with only minor documentation updates remaining before the series can be merged.
