This is the first patch in a 5-part series implementing configurable cover letter formatting for `git format-patch`. The series is now in its final form (v7) after addressing all feedback.

The patch adds two new placeholders to `pretty.c` for use in commit message formatting:
- `%(count)` - shows the current commit's position in a series, zero-padded to match the total count width (using `decimal_width()`)
- `%(total)` - shows the total number of commits in the series

Both placeholders require a `rev_info` context (enforced via `c->pretty_ctx->rev` check) and will error if used in commands that don't provide this context. The implementation follows Jeff King's design for the zero-padded numbering scheme.

This foundational change enables the subsequent patches to implement flexible cover letter formatting while maintaining backward compatibility. The strict context validation ensures these placeholders can't be misused in commands where the numbering context wouldn't make sense.

The patch is well-contained, adding just 15 lines to `pretty.c` with clear error handling. As part of a mature series that has gone through 7 iterations, it represents production-ready code that has been reviewed by both the maintainer (Junio C Hamano) and domain experts (Jeff King). The implementation cleanly separates the new functionality while preserving existing behavior for other commands.
