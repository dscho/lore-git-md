This is a cleanup patch in a series adding signature handling to `git fast-import`. The first patch removes an unused function declaration from commit.h that was missed when `sign_with_header()` was removed in a previous change (6206089cbd). 

The change is straightforward - just deleting two lines that forward-declared a now-removed function. It's part of a three-patch series that adds a new `re-sign-if-invalid` mode to `git fast-import --signed-commits`, allowing commits with invalid signatures to be re-signed during import (with the ability to specify a signing key). 

This particular patch is uncontroversial housekeeping that prepares for the actual feature implementation in later patches. The series has already gone through one round of review, with all v1 feedback incorporated into this v2 version.
