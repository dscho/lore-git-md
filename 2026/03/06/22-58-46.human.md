This is a feature patch (3/5 in a series) introducing customizable cover letter formatting for `git format-patch`. The patch adds a new `--cover-letter-format` option that allows specifying either the traditional shortlog output ("shortlog") or a custom format string prefixed with "log:".

The custom format supports new placeholders %(count) and %(total) for patch numbering, along with standard pretty-format placeholders like %s (subject) and %an (author name). The implementation includes:
- A new `generate_commit_list_cover()` function that handles the formatted output
- Integration with the existing cover letter generation code
- Comprehensive test cases showing different format string usages
- Bash completion support

The patch maintains backward compatibility by defaulting to shortlog output when no format is specified. This is part of a larger effort to make cover letters more useful by allowing chronological commit listings rather than the author-grouped shortlog format.

The implementation looks clean and well-tested, with clear separation between the new formatting logic and the existing shortlog generation. The series has gone through six iterations with maintainer feedback addressed, and this patch appears ready for merging.
