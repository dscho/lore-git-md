This is the third patch in a series modernizing git-gui's maintenance behavior by removing legacy features now handled by Git's built-in auto maintenance. The patch removes the "Compress Database" menu option and its supporting code, following the earlier removal of the loose objects warning dialog.

The change deletes the `do_gc` procedure from database.tcl along with its menu entry in git-gui.sh, plus cleans up associated translations in 15 .po files. The rationale is that since git-gui now runs auto maintenance on commit (as established in patch 1), manual compression is no longer needed for typical workflows.

Wolfgang Faust notes this patch is more for discussion than a firm proposal, asking whether there might still be valid use cases for manual compression. The change is straightforward mechanically - removing clearly obsolete code - but the author is appropriately cautious about whether the functionality itself is fully redundant. The patch continues the same pattern as the series' earlier changes: removing features superseded by Git's more sophisticated maintenance machinery while aligning git-gui's behavior with the CLI.
