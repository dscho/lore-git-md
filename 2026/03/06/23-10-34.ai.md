This is a small bugfix patch from Junio C Hamano addressing an inconsistency in how `git show -U` handles its argument. The command currently accepts `-U` without a number (which should be invalid) while `-Unan` correctly errors out. The patch tightens the validation in `diff_opt_unified()` to consistently require a numerical argument.

The change is straightforward - it moves the error checking outside the `if (arg)` block and ensures we always validate the argument when present. However, Junio notes this might break existing tests in t4013 that rely on the current lenient behavior, suggesting we may want to leave this as-is despite being technically incorrect.

The patch touches the diff machinery's option parsing but is limited to the `--unified` flag handling. It's a minor behavioral change that would make the interface more consistent, though the potential for breaking existing tests means it may not be worth fixing.
