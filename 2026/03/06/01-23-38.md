Note that Git should not prompt on the command line because of the
following code in `t/lib-credential.sh`:

```
    write_script askpass <<\EOF
    echo >&2 askpass: $*
    what=$(echo $1 | cut -d" " -f1 | tr A-Z a-z | tr -cd a-z)
    echo "askpass-$what"
    EOF
    GIT_ASKPASS="$PWD/askpass"
    export GIT_ASKPASS
```
