This is a patch series that modernizes git-gui's maintenance behavior by leveraging Git's built-in auto maintenance feature. The series removes git-gui's legacy loose object warning dialog and manual "Compress Database" feature, replacing them with the same automatic maintenance that `git commit` performs.

The motivation comes from a 2019 discussion where it was noted that Git's auto maintenance had improved enough to make git-gui's separate GC warnings redundant. The series:
1. Makes git-gui run auto maintenance on commit (similar to the CLI)
2. Removes the now-unnecessary loose objects warning dialog
3. Removes the manual "Compress Database" menu option
4. Cleans up an obsolete Scalar configuration setting related to GC warnings

The changes touch git-gui's TCL code, documentation, and translation files (removing now-unused strings). The implementation appears straightforward - it's essentially deleting legacy code that's been superseded by Git's more sophisticated maintenance machinery. The patch series is well-structured with each commit focused on a single aspect of the cleanup.

This looks like a sensible modernization that aligns git-gui's behavior with the CLI while reducing maintenance burden. The changes are unlikely to be controversial since they follow the consensus from prior discussion and simply remove features that are now redundant.
