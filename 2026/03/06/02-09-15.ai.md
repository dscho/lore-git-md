This is a documentation patch addressing an unspecified behavior in `git stash push` regarding pathspec handling. 

The email points out that `git stash push <pathspec>` currently uses paths relative to the current working directory rather than the repository toplevel, which isn't documented. The author suggests this behavior should be explicitly documented, noting that users can verify the correct relative paths by checking `git status` output.

The observation appears correct based on testing, and the proposed documentation improvement would help users understand the actual behavior. The patch would likely touch the `git-stash` man page to clarify this path resolution behavior. While a simple change, it addresses a real point of potential confusion for users working with partial stashes.
