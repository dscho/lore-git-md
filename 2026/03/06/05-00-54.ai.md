This is a refactoring patch in the `git replay` revert capability series, specifically addressing message formatting consolidation. Siddharth Asthana responds to Phillip Wood's review feedback by agreeing to restructure the revert message generation into a single unified helper function in sequencer.c.

The key technical change moves all revert message formatting logic - including both the header generation and commit reference portions - into a new `sequencer_format_revert_message()` function. This resolves the awkward split that earlier versions had between header generation and commit reference handling. For the `git replay` use case, Asthana confirms they'll call this with `use_commit_reference=false` to get full OID paths, maintaining the plumbing behavior needed for the revert functionality. The implementation cleanly separates the porcelain vs plumbing concerns while keeping all message generation logic in one place.
