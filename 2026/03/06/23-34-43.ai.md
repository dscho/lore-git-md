This is part 4 of a 5-patch series introducing configurable cover letter formatting for `git format-patch`. The series has gone through seven iterations and is now in its final form, with Junio C Hamano and Jeff King having approved the approach.

This patch adds the `format.commitListFormat` configuration option to specify the cover letter commit list format persistently. The option accepts three types of values:
1. Unset: falls back to the traditional shortlog format
2. Set but empty: defaults to "[%(count)/%(total)] %s"
3. Custom format string: must be prefixed with "log:" (e.g. "log:%s (%an)")

The implementation handles config parsing in `git_format_config()` and integrates with the existing cover letter generation logic. It includes comprehensive tests verifying all three configuration scenarios, with proper cleanup handling. The patch maintains backward compatibility while providing the new configuration capability, completing the structural refactoring started earlier in the series.

The changes are well-contained, touching only `builtin/log.c` and the test file, with clear separation between the config parsing and format application. The test coverage is thorough, exercising all configuration variants and edge cases. This represents the final piece of the configurable formatting feature before the documentation updates in the last patch.
