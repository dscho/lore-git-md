This is part 5 of a 7-patch series adding `--trailer` support to `git rebase`, now in its 8th iteration. The series enables in-process trailer manipulation during rebase by refactoring trailer handling to be reusable across commands.

This particular patch simplifies the trailer argument handling in `git commit` and `git tag` by switching from `OPT_PASSTHRU_ARGV` to `OPT_STRVEC` for the `--trailer` option. This means the commands now pass raw trailer values directly to the trailer processing functions rather than requiring the `--trailer=` prefix. The change allows removing some temporary string manipulation code in `amend_file_with_trailers()`.

The patch maintains all existing functionality while cleaning up the implementation. It's a straightforward change that follows naturally from the refactoring work in earlier patches of the series. With this and the remaining documentation updates, the series appears ready for merging.
