This is a feature patch series (v7) finalizing the implementation of configurable cover letter formatting for `git format-patch`. The series was previously in v6 and considered ready for merging, but the author has submitted a v7 with minor changes based on final review feedback.

The series introduces two new ways to customize cover letter generation:
1. A command-line option `--cover-letter-format` that accepts format strings with new `%(count)` and `%(total)` placeholders for patch numbering
2. A configuration option `format.commitListFormat` that provides persistent formatting defaults

Key technical aspects include:
- New `generate_commit_list_cover()` function handling the formatted output
- Refactored `generate_shortlog_cover_letter()` extracted from the original implementation
- Strict validation ensuring placeholders are only used with proper `rev_info` context
- Comprehensive test coverage in `t4014-format-patch.sh` and completion tests

The documentation (patch 5/5) has been updated per Junio C Hamano's suggestions, including:
- Clear examples of format strings using the new placeholders
- Behavior matrix for config vs command-line precedence
- Explanation of the required "log:" prefix for custom formats

The series has gone through six previous iterations with thorough review from Jeff King (Peff) on the numbering implementation and Junio on the overall design. The v7 submission indicates all outstanding feedback has been addressed and the feature is production-ready. The changes appear well-considered, with clean separation between the refactoring (patch 2/5) and new functionality, plus extensive test coverage.

This represents a mature addition to `format-patch` that maintains backward compatibility while providing more flexible cover letter generation options. The implementation is modular and follows established patterns in the codebase, making it likely to be merged in the near future.
