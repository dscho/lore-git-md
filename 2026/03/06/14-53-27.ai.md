This is the first patch of Phillip Wood and Li Chen's series adding `--trailer` support to `git rebase`, now in its 8th iteration. The patch refactors the trailer rewriting logic from `builtin/interpret-trailers.c` to separate the core processing from I/O operations.

The key change extracts the trailer processing into a new `process_trailers()` function that operates on strbufs, while leaving `interpret_trailers()` to handle file I/O. This prepares for moving the core logic to `trailer.c` in a subsequent patch, making it can be reused by other commands like `rebase`.

The refactoring maintains all existing functionality while improving code organization. The patch has been reviewed through multiple iterations and is now in its final form, with both authors having signed off. This is a foundational change enabling the rest of the series which will add trailer support to rebase operations.
