This is the final documentation patch in a 5-part series implementing configurable cover letter formatting for `git format-patch`. The series has gone through seven iterations and is now ready for merging, with all technical requirements met and maintainer feedback addressed.

The patch adds comprehensive documentation for the new `--cover-letter-format` CLI option and its corresponding `format.commitListFormat` configuration variable. It explains that users can now choose between the default shortlog format or specify a `log:`-prefixed format string for custom commit list formatting in cover letters. The documentation includes:

1. Configuration details in `format.adoc` showing how `format.commitListFormat` serves as the default when no CLI option is provided
2. Command-line usage in `git-format-patch.adoc` explaining the format specification syntax and its relationship to the config option
3. Example format strings demonstrating the new placeholder syntax
4) Integration with the existing configuration examples section

The implementation (completed in previous patches) includes strict validation of format strings, maintains backward compatibility with shortlog output, and provides new `%(count)` and `%(total)` placeholders for numbering commits in the series. This documentation patch represents the final piece of the feature, with Junio C Hamano having already approved the architecture and documentation approach in earlier rounds.
