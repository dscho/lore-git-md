This is a cleanup patch in the git-gui maintenance modernization series, specifically targeting Scalar's configuration. The patch removes the now-obsolete `gui.GCWarning` setting from Scalar's documentation and implementation, since git-gui has switched to using Git's built-in auto maintenance instead of its own garbage collection prompts.

The changes include:
1. Removing the `gui.GCWarning` documentation from scalar.adoc
2. Deleting the config setting from scalar.c's recommended configuration
3. Updating the test suite to use `gc.auto` instead of `gui.GCWarning` as a sentinel value

The patch is straightforward and follows logically from the previous changes in the series that removed git-gui's manual GC infrastructure. The test updates are mechanical replacements that maintain the same verification intent while using a different config key. The author notes this should be CC'd to Scalar maintainers once the rest of the series settles, suggesting this is a final cleanup rather than a controversial change.
