This is a cleanup patch in a series adding signature handling to `git fast-import`. The patch removes an unused function declaration from commit.h` that was left behind when `sign_with_header()` was removed in a previous commit (6206089cbd). 

The change is straightforward - just deleting two lines that forward-declared the now-removed function. This is the first of three patches in v2 of the series that adds a `re-sign-if-invalid` mode to `git fast-import` for handling invalid commit signatures during import. The patch was originally authored by Christian Couder but is being sent by Justin Tobler as part of the v2 series.

This is a minor preparatory cleanup that doesn't affect functionality. The removal is safe since the function implementation was already deleted and no callers remain. The patch follows Git's convention of cleaning up artifacts left behind by previous changes.
