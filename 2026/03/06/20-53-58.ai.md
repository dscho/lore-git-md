This is a refactoring patch that extracts commit signing logic into a reusable helper function as part of the `git fast-import` re-signing feature series.

The patch moves the key resolution and signing logic from `sign_commit_to_strbuf()` in commit.c to a new `sign_buffer_with_key()` function in gpg-interface.c. This allows the same signing behavior to be reused by `git fast-import` when re-signing invalid commits, without duplicating the key resolution logic. The new function maintains the same behavior - falling back to the default configured signing key when none is specified.

The changes are straightforward: the existing implementation is moved verbatim to gpg-interface.c with appropriate documentation, and the two call sites in commit.c are updated to use the new function. This is a clean-up that enables the main feature in patch 3/3 of the series while improving code organization. The patch follows Git's typical refactoring style - moving code while preserving behavior, with clear documentation of the new interface.
