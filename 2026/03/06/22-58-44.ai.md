This is part of a feature series implementing configurable cover letter formatting for `git format-patch`, now in its final iteration (v6). The patch adds two new placeholders to `pretty.c` specifically for use in cover letters: `%(count)` (zero-padded patch number) and `%(total)` (total patches in series). 

The implementation enforces that these placeholders can only be used with commands that provide a `rev_info` context (like `format-patch`), throwing an error otherwise. The `%(count)` placeholder uses `decimal_width()` to ensure proper zero-padding alignment with the total patch count, matching the existing numbered patch subject convention. 

This is a foundational piece of the larger cover letter formatting effort, providing the numbering mechanism that will be used in subsequent patches. The implementation is production-ready, having gone through six iterations of review addressing feedback from Jeff King (Peff) and Junio Hamano. The error handling and context requirements reflect careful design to prevent misuse while enabling the intended cover letter customization.
