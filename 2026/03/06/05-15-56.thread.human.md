This thread discusses modernizing git-gui's maintenance behavior by integrating with Git's built-in auto-maintenance feature, replacing the legacy loose object warning dialog and manual "Compress Database" option. The series has evolved through four key technical changes to git-gui's TCL code and Scalar documentation.

Maintainers Johannes Sixt (git-gui) and Junio C Hamano have reached consensus on the design: using `gui.gcwarning=false` as a comprehensive opt-out for all automated maintenance in git-gui, creating slight divergence from CLI behavior where maintenance would still run. Wolfgang Faust raised concerns about edge cases where users who disabled the dialog might still want maintenance, suggesting either assuming most users want maintenance (simpler but potentially breaking) or adding an explanatory dialog (safer but more complex). However, the maintainers have settled on treating the existing setting as a full opt-out, with the Scalar cleanup to be handled separately.

Implementation work remains to add the `gui.gcwarning` check, update documentation, separate the git-gui and Scalar changes into distinct series, and handle translation updates later. The technical direction is now finalized with maintainer alignment, focusing on preserving opt-out semantics while modernizing the maintenance mechanism.
