This thread discusses modernizing git-gui's maintenance behavior by integrating with Git's built-in auto maintenance feature, removing git-gui's legacy GC infrastructure in favor of the same maintenance that `git commit` performs in the CLI. Wolfgang Faust's patch series removes git-gui's loose object warning dialog, manual "Compress Database" option, and Scalar configuration references.

The series has seen positive reception for its technical direction, but two key considerations have emerged. First, Johannes Sixt (git-gui maintainer) raised a practical concern about users who disabled the loose objects warning (gui.gcwarning=false) potentially being surprised by automatic maintenance running through other commands. He suggests treating gui.gcwarning=false as indicating no automatic cleanup is desired. Second, Johannes provided maintainer guidance about separating git-gui changes from Scalar modifications (since they live in different repositories) and avoiding translation file updates in this cleanup series.

The thread now needs to resolve whether to proceed with the current approach or modify it to respect gui.gcwarning=false more strictly. Wolfgang's original proposal was otherwise considered complete, having addressed the technical alignment between git-gui and CLI maintenance behavior while making appropriate GUI-specific adaptations. The Scalar cleanup was noted as a straightforward follow-up that should be handled separately once the main git-gui changes settle.
