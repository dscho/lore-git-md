This is a documentation patch addressing a subtle behavior in `git stash push`'s path handling. Mirko Faina points out that when using pathspecs with `git stash push`, the paths are interpreted relative to the current working directory rather than the repository root, which isn't currently documented. They suggest this behavior should be explicitly mentioned in the stash documentation.

The observation comes from practical testing rather than code analysis, and while the behavior makes sense (matching how most Git commands work), it's indeed not documented. The patch would help users avoid confusion by making this expectation clear in the man pages. The change would be small but useful for anyone using stash with pathspecs.
