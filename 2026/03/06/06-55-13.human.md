This is the final version of Alan Braithwaite's feature to add URL-based partial clone filter configuration (`clone.<url>.defaultObjectFilter`). The patch has gone through multiple rounds of review and now incorporates all feedback from Junio C Hamano and other contributors.

The feature allows users to configure default partial clone filters that automatically apply when cloning repositories matching specific URL patterns. The implementation uses Git's existing urlmatch infrastructure for URL pattern matching, with the most specific match winning. Command-line `--filter` options override the configured defaults.

Key changes in this version:
- Simplified the implementation by removing the intermediate `clone_filter_data` struct
- Fixed config cascade behavior by setting `cascade_fn` to NULL
- Added NULL check for filter value
- Expanded test coverage to verify all edge cases
- Updated documentation to clarify that the bare `clone.defaultObjectFilter` form applies globally while URL-qualified forms take precedence

The patch represents the consensus design from the thread and appears ready for merging. It provides a useful quality-of-life improvement for partial clone users while maintaining Git's security boundaries by limiting the feature to clone operations only.
