This is the third patch in a series modernizing git-gui's maintenance behavior by removing legacy features now handled by Git's built-in auto maintenance. The patch removes the "Compress Database" menu option and its supporting code, following the earlier removal of the loose objects warning dialog.

The change deletes the `do_gc` procedure from database.tcl along with its menu entry in git-gui.sh, plus cleans up associated translations in 15 different language files. The rationale is that since git-gui now runs auto maintenance after each commit (as established in patch 1), manual compression is no longer needed.

The author notes this is more for discussion than a firm proposal, asking whether there might still be valid use cases for manual compression. The patch appears uncontroversial as it follows logically from the series' goal of aligning git-gui's maintenance behavior with the CLI. The implementation is straightforward, removing clearly obsolete code while maintaining all other database-related functionality like statistics and verification.
