This is the final documentation patch in a 5-part series implementing configurable cover letter formatting for `git format-patch`. The series has gone through seven iterations and is now ready for merging, having addressed all feedback from reviewers including Junio C Hamano and Jeff King.

The patch adds documentation for the new `--cover-letter-format` option and its corresponding `format.commitListFormat` config variable. These allow users to customize how commit lists appear in cover letters, either using the traditional shortlog style or a custom format string prefixed with `log:`. The documentation clearly explains the syntax, provides examples, and notes the default behavior (falling back to shortlog format if nothing is specified).

The implementation has been thoroughly reviewed over multiple versions, with key design decisions including strict validation of format strings and clean separation between the new formatting system and the legacy shortlog output. This documentation patch completes the series by making the feature's usage clear to end users, following the standard Git documentation style.
