This is a historical discussion about memory management in Git's mmap compatibility layer, continuing the thread about mmap-related memory leaks.

Ramsay Jones shares an anecdote from 2012 about encountering double-free bugs in Cygwin builds when Git's `NO_MMAP` compatibility layer was enabled. The exchange serves as historical context for the current mmap leak fixes, reinforcing that proper resource management in this area has been a long-standing challenge.

The tone is collegial, with both contributors agreeing that proper fixes are preferable to workarounds like Ramsay's proposed logging solution (which both describe as "gross").
