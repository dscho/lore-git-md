This is a Git GUI patch that adds automatic maintenance runs after commits, mirroring behavior already present in the command-line `git commit`. The change makes `git-gui` run `git maintenance run --auto` between the rerere and post-commit hook phases when `maintenance.auto` is enabled.

The implementation differs slightly from the command-line version by always detaching the maintenance process rather than honoring `maintenance.autoDetach`. The author notes this is intentional since blocking the GUI would be undesirable. The patch is minimal - just 6 lines added to `git-gui/lib/commit.tcl` to insert the maintenance call in the commit sequence.

This appears to be a straightforward quality-of-life improvement for GUI users, bringing feature parity with the CLI. The change is small, focused, and well-explained, though it might benefit from a test case to verify the behavior.
