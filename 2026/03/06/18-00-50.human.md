This is a build system patch in a bugfix series addressing memory leaks in mmap handling. The thread has already established that memory leaks occur when Git's `NO_MMAP` compatibility layer converts mmaps to heap allocations during repository operations like clone and fsck. Jeff King's series fixes the core issues, and this final addition ensures the meson build system aligns with the Makefile by enabling `NO_MMAP` when building with LSan (LeakSanitizer).

Ramsay Jones notes that several platforms historically required `NO_MMAP` but are unlikely to use meson, making this change low-risk. The patch completes the series by ensuring consistent behavior across build systems when sanitizers are active, helping catch similar issues in the future.
