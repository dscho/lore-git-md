This is a build system patch that follows up on Jeff King's series fixing mmap-related memory leaks in pack index handling. It ensures the meson build system matches the Makefile's approach of disabling mmap (`NO_MMAP`) when building with leak sanitizer (LSan), forcing heap allocations that make leaks easier to detect.

The change is straightforward - modifying a single conditional in `meson.build` to apply the same `NO_MMAP` setting for LSan and ASan builds. Jeff notes this maintains consistency between build systems, though meson lacks the Makefile's ability to independently control mmap settings. The patch has been tested to confirm it catches the same leaks addressed earlier in the series.
