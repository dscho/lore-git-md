This is a test infrastructure issue involving credential helper scripts failing to execute due to `/dev/shm` being mounted with `noexec` flags. Jeff King (Peff) provides a detailed technical explanation of why the credential tests are failing with infinite password prompts. The root cause is that the test suite's temporary directory (set to `/dev/shm` in Arch Linux's package configuration) cannot execute helper scripts, causing Git to fall back to terminal prompting when the askpass script fails to run.

Peff confirms brian m. carlson's earlier diagnosis about the `noexec` mount flag being the primary issue, but provides more context about the credential helper mechanism. He explains the expected flow where `GIT_ASKPASS` should provide dummy responses, and how the system falls back to terminal prompting when script execution fails. The email suggests this likely affects many other tests beyond just the credential ones, since many tests rely on executing helper scripts.
