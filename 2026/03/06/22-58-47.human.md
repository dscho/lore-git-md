This is patch 4/5 in a feature series adding configurable cover letter formatting to `git format-patch`. The patch introduces a new `format.commitListFormat` configuration option that allows setting the cover letter format in Git config rather than requiring it to be passed via command line each time.

The config option follows the same format rules as the existing `--cover-letter-format` CLI option (introduced in patch 3/5), with three possible states:
- Unset: falls back to the traditional shortlog format
- Set but empty: uses a default format "[%(count)/%(total)] %s" 
- Set with a value: uses that value (must be "shortlog" or a "log:" prefixed format string)

The implementation adds the config handling to `builtin/log.c` and includes comprehensive test coverage in `t4014-format-patch.sh` that verifies all three states work as expected. The tests demonstrate using the format with commit counts, subjects, and author names.

This is part of a well-structured series that has gone through six iterations and received maintainer approval. The implementation is clean and maintains backward compatibility while adding the new configuration option. The patch follows the established pattern from earlier patches in the series and includes thorough documentation and testing.
