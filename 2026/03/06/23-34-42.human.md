Feature patch adding customizable cover letter formatting to `git format-patch`. This is part 3 of a 5-part series that has gone through 7 iterations of review and is now in final form, ready for merging.

The patch introduces a new `--cover-letter-format` option that allows users to specify either the traditional shortlog-style output ("shortlog") or a custom format string prefixed with "log:". The custom format supports `%(count)` and `%(total)` placeholders for numbering commits in the series, along with standard commit formatting options like `%s` (subject) and `%an` (author name). The implementation cleanly separates the new formatting logic from the existing shortlog generation while maintaining backward compatibility.

Key aspects include:
- New `generate_commit_list_cover()` function that handles custom formatting
- Integration with the existing `make_cover_letter()` infrastructure
- Comprehensive test coverage verifying both the new formatting options and backward compatibility
- Bash completion support for the new option

The patch represents the core functionality of the feature, building on earlier refactoring work in the series. It has been thoroughly reviewed by Jeff King (Peff) and Junio C Hamano, with all feedback addressed across multiple iterations. The implementation is clean separation of concerns while maintaining the project's standards for code quality and test coverage.
