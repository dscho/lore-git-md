This is a feature patch adding new formatting placeholders to `git format-patch`, part of a series implementing customizable cover letter formatting. The patch introduces `%(count)` and `%(total)` placeholders that display the current patch number and total patch count respectively, with `%(count)` being zero-padded to match the width of the total.

The implementation enforces that these placeholders can only be used when a `rev_info` context is available (i.e., in commands like `format-patch` that process commit ranges), throwing an error otherwise. The placeholders will be used in later patches of the series to support flexible cover letter formatting while maintaining the familiar numbering scheme from patch email subjects.

This is the first of five patches in the v6 iteration of the series, which has already gone through extensive review and is now in final form ready for merging. The implementation is clean and focused, with clear error handling for invalid usage contexts. The patch follows Git's established patterns for placeholder handling in `pretty.c`.
