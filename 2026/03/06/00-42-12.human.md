This is a bug report about a failing test in the credentials subsystem. The reporter, Ivan Ivanov, describes an issue where the `t0300-credentials` test enters an infinite loop asking for username/password when building Git on Arch/Artix Linux, despite having all dependencies installed.

The test failure shows that the credential helper scripts aren't working as expected - where the test expects specific username/password values to be returned (`username=foo`, `password=bar`), it's instead getting empty values and falling back to interactive prompting. The test output shows the helper scripts are being invoked but not producing the expected output.

This appears to be a platform-specific issue affecting Arch/Artix Linux builds. The credentials test suite is designed to verify Git's credential helper mechanism, which is used for storing and retrieving authentication details. The failure suggests either an environment issue or a problem with how the test's mock credential helpers are being executed on this particular platform.

The reporter has included detailed logs showing the test failure and the contents of the failing test script, which should help diagnose whether this is a test bug or an actual regression in the credential handling code. The infinite prompting behavior indicates the credential helper chain isn't properly terminating when it should.
