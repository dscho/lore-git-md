This is a feature patch adding configurable cover letter formatting to `git format-patch`. It's part of a well-developed series (now at v7) that has already addressed all technical feedback and received maintainer approval.

The patch introduces a new `format.commitListFormat` config option that controls how commit lists appear in cover letters. It provides three modes:
1. When unset: defaults to the traditional shortlog format
2. When set but empty: uses a default format "[%(count)/%(total)] %s"
3. When set to a custom format: uses that (must be prefixed with "log:" unless it's "shortlog")

The implementation integrates cleanly with the existing cover letter generation code and includes comprehensive tests verifying all config behaviors. This is the final piece of a larger effort to make cover letter formatting more flexible while maintaining backward compatibility.

The series has gone through seven iterations with input from key contributors like Jeff King (Peff) and maintainer Junio C Hamano, who have signed off on both the technical approach and documentation. The author, Mirko Faina, has demonstrated strong attention to detail throughout the review process. This patch appears production-ready with no outstanding issues.
