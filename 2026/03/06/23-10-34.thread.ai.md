This resolves the discrepancy without breaking existing tests or scripts.

The thread has converged on this solution that:

2. Updates documentation to accurately reflect the current behavior
3. Avoids changing the implementation to match previously incorrect docs

This uncontroversial resolution addresses Junio's original discovery while incorporating Yuchen's compatibility analysis.
