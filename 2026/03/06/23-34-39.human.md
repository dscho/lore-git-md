This is the final version (v7) of a feature patch series that adds configurable cover letter formatting to `git format-patch`. The series introduces both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options to customize how patch series cover letters are generated, while maintaining backward compatibility with the existing shortlog-based output.

The implementation provides new `%(count)` and `%(total)` placeholders for patch series numbering, with strict validation to ensure they're only used in appropriate contexts. The changes are well-structured across five patches: core functionality in pretty.c (1/5), refactoring of the cover letter generation (2/5), the new formatting options (3/5-4/5), and comprehensive documentation (5/5).

The series has gone through six previous iterations with thorough review from Jeff King (Peff) and Junio C Hamano, who have approved the technical approach and documentation. All feedback has been addressed, including Junio's suggestions for clearer documentation wording. The author, Mirko Faina, confirms this v7 is the final version ready for merging.

This is a polished implementation that provides useful new functionality for customizing cover letter output while maintaining the existing behavior as the default. The careful attention to backward compatibility, validation, and documentation makes this a solid addition to the format-patch tooling.
