This is the final patch in a thread implementing configurable partial clone filters via URL patterns (`clone.<url>.defaultObjectFilter`). The feature allows setting default object filters for specific repository URLs when cloning, with command-line options (`--filter` and `--no-filter`) taking precedence over the configuration.

The current email addresses Junio Hamano's concern about needing a way to override the configured filter, confirming that `--no-filter` has been implemented to force a full clone regardless of configuration. This was the last remaining open question before the feature could be merged.

The thread saw some debate about whether this belongs in core Git (as implemented) versus the `scalar` tool, with Junio ultimately favoring inclusion in core.
