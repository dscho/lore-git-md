This is part 2/4 in a series modernizing git-gui's maintenance behavior by integrating with Git's built-in auto maintenance feature. The patch removes git-gui's legacy loose object warning dialog and its supporting code, since the automatic maintenance now handles this case.

The change deletes the `hint_gc` procedure from database.tcl along with its configuration option `gui.GCWarning`, removing the code that would previously detect and warn about excessive loose objects. It also cleans up the associated translations and documentation. This follows from the first patch's change to run `maintenance run --auto` after each commit, making the manual warning redundant.

The removal is straightforward and aligns with the series' goal of eliminating duplicate maintenance infrastructure now that git-gui uses the same auto maintenance as the CLI. The patch touches several files but makes no functional changes beyond removing now-unused code paths.
