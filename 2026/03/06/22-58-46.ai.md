Feature patch adding customizable cover letter formatting to `git format-patch`. This is patch 3/5 in the v6 series implementing comprehensive cover letter formatting options, now in final form ready for merging.

The patch introduces a new `--cover-letter-format` option that accepts either "shortlog" (the current default behavior) or a "log:"-prefixed format string. The format string can use standard pretty-print placeholders plus new `%(count)` and `%(total)` placeholders for patch numbering. For example, `--cover-letter-format="log:[%(count)/%(total)] %s (%an)"` produces numbered commit summaries with author names.

Key implementation details:
- Adds `generate_commit_list_cover()` function in `builtin/log.c` to handle custom formats
- Modifies `make_cover_letter()` to accept and process the format parameter
- Includes comprehensive tests in `t4014-format-patch.sh` covering various format scenarios
- Maintains backward compatibility with shortlog output when no format is specified
- Adds completion support in `t9902-completion.sh`

The patch builds on the refactoring in patch 2/5 which cleanly separated shortlog generation into its own function. This modular approach allows the new formatting options to coexist with the existing behavior. The implementation has been through six iterations with all feedback addressed, and the author confirms this version is final.
