This is a feature and cleanup series for git-gui, removing its legacy loose objects warning dialog in favor of Git's built-in auto-maintenance system. The series follows up on a 2019 discussion where it was suggested that git-gui could adopt the same maintenance approach as `git commit` rather than showing its own warning dialog about loose objects. 

The patches:
1. Make git-gui run auto maintenance on commit (similar to the CLI)
2. Remove the old "hint_gc" dialog that warned about loose objects
3. Remove the now-obsolete "Compress Database" feature
4. Clean up a related scalar configuration setting that's no longer needed

The changes are straightforward and align git-gui's behavior with the CLI. The series removes significant amounts of now-unused code and translations while adding just a few lines to trigger maintenance. This appears to be a well-motivated cleanup that follows through on prior consensus. The patch author (Wolfgang Faust) is not a frequent contributor but the changes are focused and clearly explained.
