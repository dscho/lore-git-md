This is a test failure report for the credentials subsystem tests, specifically affecting t0300-credentials, t0301-credential-cache, and t0302-credential-store on Arch/Artix Linux. The reporter, Ivan Ivanov, provides additional details showing the tests are failing in a more widespread manner than initially reported.

The core issue remains that credential helper scripts aren't being executed as expected, causing the tests to fall back to interactive credential entry in an infinite loop. The new information reveals this affects multiple credential test files (0300-0302) while t0303-credential-external succeeds, suggesting a pattern where only tests using local helper scripts fail. The test output shows the credential helpers (like git-credential-verbatim) are properly set up in the test directory and PATH is modified to include them, yet the credential subsystem isn't finding/executing them, instead prompting for credentials interactively. 

The reporter observes the prompts leaking to the primary console and provides the full sequence of credential prompts being generated, showing the test is cycling through various URL patterns. This suggests either the test infrastructure's PATH modification isn't taking effect, or some system credential helper is intercepting the requests before the test helpers can handle them. The fact that t0303 (which tests external helpers) works while the local helper tests fail points to an environment-specific interaction with how local helpers are located and executed.
