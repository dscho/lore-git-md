This is part 2/4 in a series modernizing git-gui's maintenance behavior by integrating with Git's built-in auto maintenance feature. The patch removes git-gui's legacy loose object warning dialog and supporting code, since the new auto maintenance makes this manual prompt unnecessary.

The change deletes the `hint_gc` procedure and related configuration option (`gui.GCWarning`), along with removing the dialog's translated strings from all localization files. The removal is straightforward - the code that previously warned users about loose objects is now redundant since git-gui automatically runs maintenance after each commit (as established in patch 1/4).

This is a clean removal of obsolete functionality that follows through on the series' goal of aligning git-gui's maintenance behavior with the CLI. The patch touches core TCL files, documentation, and translations, but makes no functional changes beyond removing code that's no longer needed.
