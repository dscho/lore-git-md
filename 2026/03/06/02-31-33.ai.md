This is a documentation discussion thread about `git stash` pathspec behavior. The thread was initiated by Aron Sigfridsson questioning whether the `git stash` man page should clarify how pathspecs are interpreted (relative to current directory vs. toplevel). 

Mirko Faina responds that while the behavior isn't explicitly documented, testing shows `git stash push` uses paths relative to current directory, not toplevel. They note this matches the behavior shown in `git status` output. Mirko suggests this could be worth adding to the documentation, though observes that most Git commands don't explicitly state their pathspec interpretation rules either, implying this may be considered obvious behavior.

The exchange highlights a documentation gap but doesn't yet show consensus on whether it warrants a change. No other participants have weighed in yet. The technical detail here is straightforward - `git stash` pathspecs are relative to current directory - but the discussion raises the broader question of when and how Git should document such implicit behaviors.
