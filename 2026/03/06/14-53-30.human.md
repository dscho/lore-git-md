This is the 4th patch in the 8th iteration of a series adding `--trailer` support to `git rebase`, authored by Phillip Wood and Li Chen. The patch refactors trailer handling to avoid forking `git interpret-trailers` by introducing in-process trailer manipulation.

The patch adds `amend_strbuf_with_trailers()` to apply trailers directly to a message buffer using the existing `process_trailers()` infrastructure. It updates `amend_file_with_trailers()` to use this new helper while maintaining the same atomic file-write behavior via tempfile+rename. The changes include:

1. Early validation of trailer arguments in `cmd_commit()` and `cmd_tag()`
2. A new `validate_trailer_args()` function for sanity checking
3. Backward compatibility with existing `--trailer=<trailer>` argument format
4. Proper error handling throughout the trailer application process

The implementation is careful to maintain existing behavior while eliminating the fork/exec overhead. This is part of the larger effort to enable in-process trailer manipulation during rebase operations, with all core functionality now reviewed and accepted by the maintainer. Only minor documentation and error handling improvements remain before the series can be merged.
