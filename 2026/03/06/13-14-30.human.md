Feature patch adding branch name prefixing to `git branch`. This is the first of three patches in v3 of a series that aims to simplify hierarchical branch naming workflows, particularly for backports.

The patch introduces a `--name-prefix` option to `git branch` that can prepend either a static string or the current branch name (via `@{current}` token) to new branch names. The implementation adds a new `add_branch_prefix()` helper function in branch.c and updates the command's documentation and tests. 

Key aspects:
- Supports both static strings ("feature-") and dynamic current-branch references
- Handles recursive prefixing (e.g. "main-test-sub" when on "main-test")
- Includes test coverage in t3200-branch.sh
- Backward compatible when no prefixing is configured

This version represents a significant redesign from v2 based on Junio's feedback, narrowing scope to just `git branch` (dropping checkout/switch support) and using a more flexible string-based approach rather than boolean flags. The implementation looks clean and well-tested, though maintainer feedback on the new design is still pending.
