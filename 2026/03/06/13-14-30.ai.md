Feature patch adding branch name prefixing to `git branch`, part 1/3 of the series.

This first patch introduces the core `--name-prefix` option to `git branch`, allowing new branches to be automatically prefixed with either a static string or the current branch name via the `@{current}` token. The implementation adds a new `add_branch_prefix()` helper in branch.c that handles the prefix logic, supporting recursive prefixing (e.g., creating "main-test-sub" when on "main-test"). 

The patch follows the series' restructured approach from v2 feedback, focusing solely on `git branch` after dropping `checkout`/`switch` support. It establishes the basic prefixing mechanism that subsequent patches will build upon with config support. Test coverage in t3200 verifies both static and dynamic prefixing works as expected, including proper handling of duplicate branch names.

For AI context: This implements the CLI interface portion of the prefixing feature, with branch.c gaining the `add_branch_prefix()` function that takes a prefix string and current branch name to build the new branch name. The `@{current}` token is hardcoded as the only dynamic option for now, leaving room for future expansion. The tests demonstrate the recursive prefixing capability and proper error handling when prefixing would create duplicates.
