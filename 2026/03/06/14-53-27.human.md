This is the first patch in the final iteration of Phillip Wood and Li Chen's series adding `--trailer` support to `git rebase`. The patch refactors the trailer rewriting logic from `interpret-trailers.c` to separate the core processing from file I/O, making it reusable by other commands.

The key change extracts the trailer manipulation logic into a new `process_trailers()` function that operates on strbufs, while leaving `interpret_trailers()` to handle just the file reading and writing. This clean separation enables the subsequent patches to reuse the trailer processing logic in the rebase machinery without duplicating code.

The implementation looks solid, with careful attention to memory management (strbuf cleanup) and maintaining all existing functionality. This is a foundational change for the series, enabling the rebase integration while keeping the trailer handling consistent across commands.
