This is a test case submission for a bugfix targeting the `receive.denyCurrentBranch=updateInstead` behavior with bare repositories containing worktrees. The test demonstrates an edge case where Git incorrectly rejects pushes when the bare repo's HEAD points to an unborn branch, even when the linked worktree is clean.

Runxi Yu provides a minimal reproduction showing that `updateInstead` fails when:
1. A bare repo has a worktree checked out on a separate branch
2. The bare repo's HEAD is pointed to an unborn branch
3. The push targets the worktree's branch (which is clean)

The test is marked as `test_expect_failure` to document the current incorrect rejection with "Working directory has staged changes". The author suspects the issue stems from `builtin/receive-pack.c` comparing the worktree's index against the bare repository's HEAD rather than the worktree's HEAD.
