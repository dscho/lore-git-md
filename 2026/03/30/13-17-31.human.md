This is part 9/18 of Patrick Steinhardt's series to remove `the_repository` global from `setup.c`, continuing the broader `the_repository` removal effort. The patch converts `setup_work_tree()` to take an explicit `struct repository *` parameter instead of implicitly using the global variable.

The change is mechanical in most places, updating 21 callers to pass `the_repository` explicitly. However, the patch also addresses a deeper issue - the function was tracking bogus worktree configuration via a global variable (`work_tree_config_is_bogus`). Since this state should be repository-specific, Patrick moves it into `struct repository` as a new `worktree_config_is_bogus` field.

The patch follows the established pattern of this series - small, focused changes that maintain backward compatibility while incrementally removing global state.
