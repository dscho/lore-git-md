This is the third patch in a refactoring series focused on improving type safety in xdiff subsystem's record cleanup logic. The patch converts several `long` variables to `ptrdiff_t` in `xdl_clean_mmatch()` and `xdl_cleanup_records()` functions, making the type usage more precise for pointer arithmetic and array indexing operations.

The changes are straightforward and mechanical:
- Parameters `i`, `s`, `e` in `xdl_clean_mmatch()` now use `ptrdiff_t`
- Local variables `r`, `rdis0`, `rpdis0`, `rdis1`, `rpdis1` in same function also converted
- Loop variables `i`, `nm`, `mlim` in `xdl_cleanup_records()` updated similarly

This continues the series' theme of using more appropriate types for the operations being performed, following up on earlier patches that addressed similar issues. The changes are purely internal and don't affect functionality, but help prevent potential issues with integer overflow and make the code's intent clearer. The patch is small (6 lines modified) and focused, touching only xdiff/xprepare.c.
