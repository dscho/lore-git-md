Documentation patch finalizing the `git stash` command syntax clarification. Quentin Bernet's v2 patch updates both the man page and built-in help text to accurately reflect that:

1. The `push` subcommand is optional for most options (`-m/--message`, `-u/--include-untracked`, etc.)
2. Pathspecs still require either explicit `push` or `--` disambiguation
3. The documentation now properly matches the actual parser behavior in `builtin/stash.c`

The changes are minimal but precise, fixing inconsistencies between the synopsis and explanation sections. Junio Hamano has approved the approach, noting this completes the documentation side of the discussion while leaving potential parser improvements (like making `git stash -m foo <pathspec>` work as implicit push) as optional future work. This is part of the broader documentation standardization effort led by Jean-Noël Avila.
