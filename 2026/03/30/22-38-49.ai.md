This is a review response in Taylor Blau's incremental MIDX/bitmap-based repacking series. Jeff King (Peff) provides feedback on patch 02/16, which refactors MIDX file cleanup to use `string_list` instead of manual array management.

Peff confirms the correctness of the implementation while noting some subtle points about the string list handling. He suggests a `strset` might be slightly more appropriate for this set-membership use case, but acknowledges the performance difference is negligible given the small number of files involved.

The review is positive overall, with Peff's comments serving more to validate the approach than to request changes.
