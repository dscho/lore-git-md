This is a test cleanup patch in a series addressing `receive.denyCurrentBranch=updateInstead` behavior with worktrees. The patch fixes an oversight in the test infrastructure where temporary repositories ('cloned') and worktrees ('new-wt') created during testing weren't being properly cleaned up, which could cause failures in subsequent tests.

The change is straightforward - it adds a `test_when_finished` block to remove these artifacts after the test completes. This is standard practice in Git's test suite to ensure test isolation. The patch is part of Pablo Sabater's GSoC work building on Runxi Yu's earlier test case that identified incorrect behavior when pushing to bare repositories with worktrees.

This is a minor but necessary improvement to the test infrastructure that supports the larger fix for the worktree/updateInstead interaction. The change is uncontroversial and follows established test suite patterns. It touches only `t/t5516-fetch-push.sh`, adding cleanup for resources that were previously leaked.
