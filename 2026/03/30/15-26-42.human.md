This is a bugfix addressing incorrect behavior in `receive.denyCurrentBranch=updateInstead` when pushing to bare repositories with worktrees. The patch series builds on earlier work by Runxi Yu who identified and documented the issue with a test case, now being fixed by Pablo Sabater.

The core problem occurs when pushing to a bare repository that has worktrees: Git incorrectly rejects the push if the bare repo's HEAD points to an unborn branch, even when the worktree itself is clean. The fix changes `builtin/receive-pack.c` to check the worktree's HEAD rather than the bare repository's HEAD when determining if staged changes exist.
