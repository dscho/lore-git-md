This is the first patch in Ezekiel Newren's v4 refactoring series for the xdiff subsystem, specifically targeting cleanup of `xdl_cleanup_records()`. The patch is a straightforward code simplification that removes a redundant `recs` pointer variable from the function.

The change eliminates the pointer traversal in favor of direct array indexing, making the code slightly more readable by reducing indirection. The patch touches only `xdiff/xprepare.c`, modifying four loops to use `xdf1->recs[i]` and `xdf2->recs[i]` directly rather than maintaining and incrementing a separate pointer. The last two loops didn't use the pointer at all, so its removal there is purely cleanup.

This is a mechanical refactoring with no behavior change - the diff shows 8 lines added and 9 removed, mostly from eliminating the pointer declaration and updates. The patch follows the series' theme of improving clarity in the xdiff record cleanup logic while maintaining all existing functionality. As the simplest change in the series, it serves as a good lead-in to the more substantial type safety improvements that follow in subsequent patches.
