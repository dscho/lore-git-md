This is a refactoring patch as part of the ongoing `the_repository` removal effort. Patrick Steinhardt continues his 18-patch series modernizing `setup.c` by converting `setup_work_tree()` to take an explicit `struct repository *` parameter instead of implicitly using `the_repository`. 

The patch makes two key changes: first, it updates all 21 callers of `setup_work_tree()` to pass `the_repository` explicitly. Second, it moves the `worktree_config_is_bogus` global variable into `struct repository` since tracking this state globally no longer makes sense when working with multiple repositories. The changes are mechanical but widespread, touching blame.c, various builtins, and test infrastructure.

This follows the established pattern in the series - removing implicit state while maintaining backward compatibility through careful signature updates. The patch is well-scoped, with the core logic remaining unchanged while the repository parameter is threaded through. The changes are consistent with Patrick's thorough approach to this large-scale refactoring effort.
