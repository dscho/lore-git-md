This is the fourth version of a refactoring series that moves encoding-related configuration from global variables to repository-specific storage, as part of the ongoing `the_repository` removal effort. The series builds on recent work by Olamide Caleb Bello that introduced `struct repo_config_values` for storing repository-specific configurations.

The key change in this version is adopting `repo_config_values` rather than storing the encodings directly in `struct repository` as suggested in previous iterations. The series now has three patches: updating commit creation APIs to take a repository parameter, modifying pretty-printing functions similarly, and finally migrating the encoding configurations themselves.

The changes are mechanical but widespread, touching 32 files across commit handling, mail operations, revision walking, and builtin commands. The author has maintained fallback paths to `the_repository` for unconverted callers while the transition continues. Test suite passes with sanitizers, suggesting no behavior changes have been introduced.

This appears to be a well-structured series that follows established patterns for global variable migration. The author has incorporated feedback from Phillip Wood about the storage location and clearly understands the architectural constraints.
