Documentation clarification for `fetch --jobs=0` behavior. Johannes Schindelin responds to Patrick Steinhardt's inquiry about why the documentation for `--jobs=0` and `fetch.parallel=0` was left vague, confirming there was no recorded discussion about this decision. He traces the implementation history back to d54dea77dba (2019-10-05), showing that the code has consistently fallen back to `online_cpus()` when these values are 0, a behavior that was noted in the 2.40.0 release notes. The thread now has consensus that documenting this CPU-count fallback is appropriate, though the original vagueness may have reflected an assumption that this behavior was common knowledge. This email provides the final historical confirmation needed to proceed with the documentation update, closing the loop on whether the original omission was intentional. The change remains non-controversial, with Johannes's research confirming there was no hidden rationale for keeping the behavior undocumented.
