This is patch 4/6 in Justin Tobler's series adding repository statistics to `git repo`. The patch enhances the table output format to show OIDs for the largest objects in the repository, addressing a gap from previous versions.

The changes introduce numbered annotations that link table entries to their corresponding object hashes. Each "largest object" entry now includes an index (like `[1]`) that maps to a footnote-style OID display at the bottom of the table. The implementation handles NULL OIDs for empty repositories and maintains the existing output format while adding this new information.

Key technical elements:
- New `annotations` string list in `stats_table` struct to store OID mappings
- Modified table formatting to accommodate index numbers while preserving alignment
- New `stats_table_object_size_addf()` helper that handles both size display and OID annotation
- Updated tests to verify the new annotation behavior

The patch follows the series' pattern of careful, well-tested additions to the repository statistics functionality. It builds on the object tracking infrastructure from earlier patches while keeping the output clean and readable. The changes are focused and maintainable, with clear separation between the new annotation logic and existing table formatting code.
