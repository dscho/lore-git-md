This is a CI/build system patch addressing an issue in GitLab CI pipelines on Windows. Patrick Steinhardt identifies that the `GITLAB_FEATURES` environment variable has grown too large (6.3KB), causing xargs(1) from Git for Windows to hit an assertion failure due to exceeding POSIX argument length limits. The fix simply unsets this variable in `ci/lib.sh` when running under GitLab CI.

The patch is straightforward and well-motivated, with clear evidence showing the environment size problem and its impact. The change is minimal (4 lines added) and focused on the CI infrastructure rather than core Git functionality. As this comes from Patrick Steinhardt, who manages GitLab's Git team, it's likely well-tested against their actual CI environment. The patch appears ready for merging with no obvious downsides or controversy.
