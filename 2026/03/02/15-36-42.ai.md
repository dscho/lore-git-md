This is the first patch in Derrick Stolee's v3 series improving environment handling in `git for-each-repo`. The patch modifies the test script to verify the command works outside a repository context, which is its typical real-world usage pattern (e.g. for background maintenance).

The key changes in this test-only patch are:
1. Setting `TEST_NO_CREATE_REPO=1` to prevent automatic test repository creation
2. Converting all `git config` calls to use `--global` variants
3. Updating test expectations to account for repository-less operation
4. Revealing (but not yet fixing) a dependency on `the_repository` global for config access

The patch maintains test coverage while removing repository dependencies, though it notes the remaining architectural limitation around `the_repository` that will need to be addressed separately. The changes are straightforward test modifications that don't affect the actual command behavior, just its test coverage.

This continues the series' focus on robust environment handling, with this patch specifically ensuring the tests properly exercise the repository-less case that was previously untested. The changes align with feedback from previous rounds to improve test coverage of real-world usage patterns.
