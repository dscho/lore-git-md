This thread documents Git's support for running external `git-*` executables found in PATH as if they were built-in commands. The initial patch from Omri Sarig proposed adding documentation for this feature, with Junio Hamano suggesting moving it to the "Environment Variables" section for better organization.

Through several iterations, the documentation has been refined to clearly explain the lookup order (built-in commands first, then external `git-*` executables, then aliases) and how arguments are passed through. There was some surprise that external commands take precedence over aliases, contrary to what Omri initially expected, and this behavior is now explicitly documented.

The changes are purely additive documentation improvements with no code changes needed, as the underlying behavior in `execv_dashed_external()` has been stable for years. Junio Hamano and D. Ben Knoble have both supported making these long-standing but under-documented features more visible. The technical content has reached consensus, with only minor editorial decisions remaining about cross-references to related documentation that will be handled in a follow-up commit. This straightforward documentation improvement appears ready for merging.
