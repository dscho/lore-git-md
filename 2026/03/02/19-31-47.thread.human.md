This thread documents an effort to improve the visibility of Git's long-standing but under-documented features for command extensibility. The initial patch from Omri Sarig added documentation for running external `git-*` executables from PATH, which Git has supported since at least version 1.5.0. After several iterations incorporating feedback, the documentation now clearly explains the lookup order (built-ins first, then external commands, then aliases) and how arguments are passed.

Junio Hamano suggested further improvements to make these features more discoverable, proposing cross-references in the "GIT COMMANDS" section of the main documentation. D. Ben Knoble has now responded positively to this suggestion, agreeing that mentioning both alias configuration and external command functionality in the introductory paragraph would help users find these extensibility options more easily.

The discussion has reached consensus that this is a straightforward documentation improvement. With Junio's minor wording suggestions about alias precedence already addressed in earlier versions, and now with Knoble's support for the cross-reference additions, the patch appears ready for merging. The change is purely additive and follows Git's documentation standards, touching only Documentation/git.adoc to better explain these long-supported features.
