This thread documents Git's support for running external `git-*` executables from PATH as if they were built-in commands. The initial patch from Omri Sarig proposed adding documentation for this feature, which has existed in Git's implementation (via `execv_dashed_external()` in git.c) but was not well-documented.

Through four iterations, the documentation has been refined with input from Junio Hamano and others. The current version clearly explains the lookup order: built-in commands first, then external `git-*` executables in PATH, and finally aliases. A key clarification was that external commands take precedence over aliases, which surprised the original author but matches Git's actual behavior.

The patch has evolved to place the documentation in the "Environment Variables" section of git.adoc, where it fits naturally alongside other PATH-related documentation. The latest version removes redundant phrasing while maintaining all key information about argument passing and command precedence.

This non-controversial improvement makes an existing feature more discoverable. With multiple rounds of feedback incorporated, including from Junio and D. Ben Knoble, the documentation appears ready for merging as part of Git's ongoing effort to better document its extensibility features. The thread shows clear consensus that both the external command mechanism and aliases deserve more prominent documentation.
