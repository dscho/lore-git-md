This thread documents an existing but previously undocumented Git feature: the ability to run external commands by placing executables named `git-<command>` in the user's PATH. The patch adds a clear explanation of this functionality to the main `git.adoc` man page, covering how Git searches for commands (built-ins first, then external commands, then aliases) and noting that `git help` will show the man page for external commands. The change is purely additive documentation with no behavior modification, following Git's standard documentation conventions. The patch appears well-formed and addresses a genuine gap in the documentation.
