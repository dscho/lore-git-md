This thread documents Git's support for running external `git-*` executables as if they were built-in commands. The initial patch from Omri Sarig proposed adding documentation for this long-standing but under-documented feature, which is implemented in `execv_dashed_external()` in git.c. 

Maintainer Junio Hamano suggested moving the documentation to the "Environment Variables" section, which Omri incorporated in v2 along with additional details about argument passing and command precedence (built-ins first, then external commands, then aliases). The v3 revision, which just landed, fixes a minor whitespace issue while keeping the same content structure. 

The thread shows clear consensus on documenting this behavior, with no technical objections raised. The final patch makes this extensibility mechanism more discoverable by properly documenting the lookup order and argument handling that has been part of Git since at least version 1.5.0.
