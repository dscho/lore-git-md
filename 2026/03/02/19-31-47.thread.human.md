This thread documents Git's support for running external executables prefixed with "git-" in PATH as if they were built-in commands. The initial patch from Omri Sarig proposed adding documentation for this long-standing but under-documented feature, with Junio Hamano suggesting moving it to the "Environment Variables" section where it better fits with other PATH-related documentation.

In subsequent iterations, Omri refined the documentation to clarify the lookup order (built-in commands first, then external `git-*` executables, then aliases) and how parameters are passed through. The latest version addresses minor whitespace issues and incorporates Junio's final review feedback - suggesting simpler wording ("program" instead of "runnable program") and proposing cross-references to alias documentation to help users discover both features. 

The thread shows clear consensus that this is a straightforward documentation improvement with no technical changes needed. The patch references `execv_dashed_external()` in git.c which has handled this functionality since at least Git 1.5.0. With Junio's minor wording suggestions now addressed, the patch appears ready to be merged, making this useful extensibility mechanism more discoverable in the official documentation.
