This is the second patch in Derrick Stolee's v3 improving environment handling in `git for-each-repo`. The patch refactors environment variable management by extracting a new `clear_local_repo_env()` helper from `prepare_other_repo_env()`.

This prepares for a case in the next patch where only the environment clearing is needed when using `-C` for repository discovery.

The implementation carefully preserves GIT_CONFIG_* variables to maintain parent process configuration while clearing other repository state.
