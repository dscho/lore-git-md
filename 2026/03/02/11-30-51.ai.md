This is a UI improvement patch for git-gui, part of an ongoing thread about visually distinguishing commit message comment lines. Johannes Sixt (Hannes) provides detailed feedback on Wolfgang Faust's initial implementation that adds gray highlighting to comment lines that will be stripped from the final commit message.

Hannes suggests several technical improvements to the Tcl/Tk implementation: simplifying the regex pattern by using -line matching, restructuring the loop to avoid nested list indexing, and reusing computed indices. He also notes formatting issues with the patch submission and recommends using Gitgitgadget for future contributions. The core idea - graying out comment lines rather than highlighting them - is endorsed, with Hannes emphasizing this provides better visual feedback about what will be stripped from the final message.

The discussion focuses on implementation details in the Tcl code, particularly around text widget tag handling and regex processing. Hannes' feedback indicates this is a promising direction but needs refinement in the approach to regex handling and index calculation. The change would improve git-gui's commit message composition experience by making it immediately obvious which lines are treated as comments.
