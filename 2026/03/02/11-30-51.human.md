This is a UI improvement patch for git-gui, part of an ongoing discussion about visually distinguishing commit message comment lines. Johannes Sixt (Hannes) responds to Wolfgang Faust's initial patch that added gray highlighting for comment lines that will be stripped from the final commit message.

Hannes generally approves the concept but suggests several technical improvements to the Tcl implementation. He notes the patch formatting was corrupted during submission and recommends using Gitgitgadget for future contributions. The key suggestions include simplifying the regular expression matching logic, restructuring the loop for cleaner indexing, and questioning the need for a "+1 char" offset in the line positioning.

The exchange shows an experienced git-gui maintainer (Hannes) providing constructive feedback to a contributor with self-professed limited Tcl experience. The changes aim to make commit message composition clearer by visually de-emphasizing comment lines that will be automatically removed. The implementation touches git-gui.sh's text widget handling but doesn't affect core Git functionality.
