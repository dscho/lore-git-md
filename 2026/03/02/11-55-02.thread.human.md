This thread addresses a CI build system issue affecting GitLab CI pipelines on Windows. Patrick Steinhardt identified that the `GITLAB_FEATURES` environment variable had grown too large (6.3KB), causing xargs from Git for Windows to fail when processing the lengthy environment. The proposed fix is minimal - unsetting this variable in `ci/lib.sh` when running under GitLab CI. 

The patch is straightforward and well-scoped, coming from GitLab's own Git team lead who would be most familiar with their CI environment's requirements. There are no apparent technical objections or concerns raised, and the change appears ready for merging as a targeted infrastructure fix. The discussion is focused purely on this specific Windows CI issue without broader implications for Git's core.
