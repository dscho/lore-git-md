This is a documentation patch that improves the formatting of conditional text in the `sideband.allowControlCharacters` config documentation. It's part of the ongoing security effort to handle ANSI escape sequence injection in the sideband channel (CVE-2024-32002, CVE-2024-52005).

Junio Hamano makes a small but meaningful change to the documentation structure, duplicating the warning about "unwanted ANSI escape sequences" in both conditional blocks (for current and future default behaviors) rather than having it appear only once after both blocks. This improves readability and makes the text more translation-friendly, as noted in the commit message's reference to a prior discussion about documentation formatting.

The patch doesn't change any functionality - it just makes the documentation clearer by ensuring both conditional paths contain complete thoughts rather than sharing a trailing sentence. This is a typical maintainer-level polish patch that follows up on a larger security series that has already seen extensive discussion and validation.
