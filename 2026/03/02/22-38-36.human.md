This is the final patch in a series converting Git's oidmap cleanup mechanism to use explicit, type-safe callbacks. The patch updates the sequencer subsystem to use the new `oidmap_clear_with_free()` API for its string_entry structures, introducing a `free_string_entry()` helper function.

Junio C Hamano's review notes that while this change provides little immediate benefit (since the string_entry structures are simple), it follows the same future-proofing pattern as the rest of the series - making it easier to handle more complex resource management if the structures evolve later. The change is consistent with the three already-approved conversions in rev-list, list-objects-filter, and odb subsystems.

The series as a whole has been well-received, with Junio approving most patches while raising one remaining question about the cmpfn check in the foundational API change. This final conversion completes the migration to callback-based cleanup while maintaining the project's high standards for type safety and maintainability.
