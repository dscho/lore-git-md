This is a documentation patch clarifying Git's support for external commands. The original patch by Omri Sarig added a dedicated section to `git.adoc` explaining how Git executes external `git-*` commands found in PATH, treating them like built-ins. Junio Hamano (the maintainer) agrees the feature deserves better visibility but suggests the documentation might fit better alongside other environment variables rather than as a standalone section.

Junio notes the behavior is already partially documented in `git help git` (under `--list-cmds`) and `git help help` (via `--no-external-commands`), but acknowledges the current documentation could be more discoverable. He proposes alternative wording that would appear in the Environment Variables section, describing how Git looks for external commands when a built-in isn't found.

The patch appears uncontroversial - it documents existing behavior without changing any functionality. Junio's response suggests the concept is sound but the placement might need adjustment. This is a straightforward documentation improvement that makes an existing feature more accessible to users.
