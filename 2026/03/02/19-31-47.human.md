This is a documentation patch that adds information about Git's support for external commands to the main `git.adoc` man page. 

The patch documents Git can execute any executable in the user's PATH that starts with "git-" as if it were a built-in command. It explains the command lookup order (built-ins first, then external commands, then aliases) and notes that `git help` will show the man page for external commands. The motivation is to make this existing feature more discoverable to users who might want to extend Git with custom commands.

The documentation is clear and well-written, covering the key points about how external commands work and their position in Git's command lookup hierarchy. This seems like a useful addition since the feature wasn't previously documented in the user-facing docs, despite being a long-standing capability. The patch is small and focused, touching only the documentation file with no code changes needed.
