This is patch 4/6 in Justin Tobler's series adding repository statistics to `git repo`. The patch focuses on improving the table output format by adding OID annotations.

The key change is adding OID references to the "Largest objects" section of the table output. Each maximum size entry now includes an index number that links to a footnote showing the full OID of that object. The implementation:

1. Adds a new `annotations` string list to `struct stats_table` to store OID footnotes
2. Introduces `stats_table_object_size_addf()` helper that handles OID annotation logic
3. Modifies table formatting to include index numbers and display annotations after the table
4. Updates tests to verify the new annotation format

The patch maintains backward compatibility while adding the new information. Empty repositories are handled gracefully (no annotations shown for NULL OIDs). The changes affect both the table output formatting and the test expectations in t1901.

This builds on the series' existing infrastructure for tracking largest objects by OID, now making those OIDs visible in the user-facing output. The implementation is clean and maintains the series' focus on comprehensive repository statistics.
