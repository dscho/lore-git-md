This is a feature patch series adding repository statistics to `git repo`. Justin Tobler's v3 iteration builds on previous versions with refinements to handle edge cases and improve code organization.

The series enhances `git repo structure` to track and report:
- Largest objects by type (commits, trees, blobs, tags)
- Commit with most parents
- Tree with most entries

Key improvements in v3 include better handling of zero-sized objects (now properly recorded as largest when no other exists) and code cleanup through new helper functions for printing key-value output. The implementation uses a `struct object_stats` to track metrics and OIDs, with tests in t1901 verifying the new functionality.

The changes address feedback from earlier rounds, particularly around output formatting and edge case handling. Performance remains reasonable (3-6 seconds on typical repos). While some future enhancements like commit diff statistics were discussed, the current scope focuses on raw object-store metrics. The series appears ready for merging after this final polish.
