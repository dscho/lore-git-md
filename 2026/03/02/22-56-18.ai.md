This is a documentation patch that adds information about Git's support for external commands (executables prefixed with "git-" in PATH). The original patch from Omri Sarig proposed adding a dedicated section to `git.adoc` explaining this feature, which allows users to extend Git with custom commands.

Junio Hamano (the maintainer) acknowledges the value of documenting this behavior but suggests a different placement - under "Environment Variables > System" alongside other PATH-related documentation. He notes that while the feature wasn't completely undocumented (being mentioned in `--list-cmds` and `--no-external-commands` help text), making it more discoverable is worthwhile. The thread shows consensus on documenting the existing functionality, with only minor discussion about the optimal location in the documentation structure.

The patch documents behavior implemented in `execv_dashed_external()` in git.c without changing any functionality. This is a straightforward documentation improvement that fills a gap where an important extensibility feature was not prominently explained to users. No technical objections have been raised, and the discussion focuses only on documentation organization.
