This is a feature patch series for `git repo` that adds repository statistics tracking, specifically focusing on identifying largest objects in various categories. The series is in its third iteration and has received approval pending final polish.

The 6-patch series enhances `git repo`'s structure output to track and report:
- Largest objects by type (commits, trees, blobs, tags) including their OIDs and sizes
- Commit with most parents (including OID and count)
- Tree with most entries (including OID and count)

Key technical elements include:
- New `struct object_data` to track OID+value pairs for each metric
- `check_largest()` helper with improved handling of zero-sized objects
- Consolidated printing logic via new `print_object_data()` helper
- Table output formatting with OID annotations
- Comprehensive test coverage in t1901

The changes from v2 include:
- Fixed zero-value object recording in `check_largest()`
- Added helper functions to reduce printf duplication
- Restructured annotation printing for better readability
- Maintained identical output format while improving code structure

The series builds on previous work by Justin Tobler to provide repository statistics, with this iteration focusing specifically on identifying outlier objects. Performance remains stable (3-6s execution time) and the implementation has been refined based on feedback from Junio Hamano and others. The patches are well-tested and appear ready for merging after these final polish changes.
