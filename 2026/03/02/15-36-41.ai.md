This is a bugfix patch series from Derrick Stolee addressing environment handling in `git for-each-repo`, now at version 3. The series improves worktree isolation and repository-less operation by properly managing Git environment variables during child process execution.

The key changes in v3 include:
1. Extracting a new `clear_local_repo_env()` helper from `prepare_other_repo_env()` to consolidate environment management logic
2. Simplifying the implementation in `for-each-repo` to use this new helper
3. Adding tests for config-related environment variable preservation
4. Including a bonus patch that simplifies parameter passing

The series addresses a reported issue where `for-each-repo` wasn't working correctly in worktrees, with the solution focusing on proper environment variable handling. The implementation has evolved through feedback from Jeff King and Phillip Wood, particularly around GIT_CONFIG_* variable filtering and environment propagation.

Key technical points:
- Uses the new `clear_local_repo_env()` helper to properly isolate child processes
- Maintains test coverage for both worktree and repository-less operation
- Handles edge cases around config variable propagation
- Avoids unnecessary defensive checks for variables that naturally propagate

The series demonstrates the project's typical refinement process, with the implementation becoming simpler and more robust through review feedback. The changes touch `builtin/for-each-repo.c`, `run-command.[ch]`, and the test script, with careful attention to maintaining backward compatibility while fixing the isolation issues.
