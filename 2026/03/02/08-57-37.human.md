The change ensures encoding configurations are properly scoped to repository instances rather than being global state. While config parsing still uses `the_repository` temporarily (due to callback machinery constraints), all read paths now properly handle repository-specific encoding settings. The patch updates 19 files to use the new repository-aware accessors `get_commit_output_encoding()` and `get_log_output_encoding()`.

This builds on Olamide Caleb Bello's `repo_config_values` infrastructure and follows René Scharfe's patterns for global variable removal.
