Feature: Refactoring trailer handling for rebase integration.

This is the first patch in the v7 series adding `--trailer` support to `git rebase`. Phillip Wood notes that Li Chen's patch is still missing his sign-off from a previous iteration, but otherwise approves the technical changes. The patch splits the core trailer rewriting logic from file I/O in `interpret-trailers.c`, extracting it into a new `process_trailers()` helper that operates on strbufs. This prepares for sharing the trailer manipulation code with the rebase command while maintaining the existing file handling behavior.

The refactoring keeps the same functionality but reorganizes the code to separate concerns: `interpret_trailers()` now handles just the I/O (reading input, writing output with atomic tempfile+rename for in-place operation), while `process_trailers()` contains the actual trailer parsing and formatting logic. This follows the pattern seen in other Git commands where core logic is separated from file operations to enable reuse. The patch includes straightforward mechanical changes like renaming variables ("sb" to "input") and using `strbuf_write()` for output.

As part of the larger series, this change enables the rebase integration while maintaining the safety of the existing trailer manipulation code.
