This is the fourth version of a refactoring series that moves encoding-related configuration from global variables to repository-specific storage, as part of the ongoing `the_repository` removal effort. The series builds on recent work by Olamide Caleb Bello that introduced `struct repo_config_values` for storing repository-specific configurations.

The patches systematically plumb `struct repository` parameters through various commit creation and pretty-printing APIs, updating over 30 files across the codebase. The changes affect core commands like `commit`, `log`, `rebase`, and `merge`, as well as supporting infrastructure in the sequencer, range-diff, and submodule code. The implementation maintains backward compatibility by falling back to `the_repository` where needed during the transition.

The series appears well-structured and follows established patterns for global variable migration. The author has incorporated feedback from Phillip Wood in previous iterations, showing responsiveness to review. The changes are mechanical but touch many call sites, so careful review of the propagation logic will be needed. This is a solid contribution to the long-term effort to remove global state from Git's codebase.
