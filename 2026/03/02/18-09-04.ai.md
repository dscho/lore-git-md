This is a technical discussion thread about environment handling in `git for-each-repo`, part of Derrick Stolee's patch series to improve repository-less operation and worktree isolation.

Jeff King (Peff) responds to Derrick Stolee's v3 patch series, confirming that extracting environment clearing logic from `prepare_other_repo_env()` into a new `clear_local_repo_env()` helper is the right approach. He notes the v3 implementation now correctly handles all `GIT_CONFIG_*` variables, though points out `GIT_CONFIG` itself is a historical oddity that can be ignored since most commands don't use it.

The discussion clarifies several technical points about environment variable handling: `GIT_CEILING_DIRECTORIES` provides reliable test isolation, `EXEC_PATH_ENVIRONMENT` propagates correctly, and `NO_REPLACE_OBJECTS` is an operation-level setting. Peff had previously caught a compilation regression in patch 3/4 where a variable was removed prematurely, and suggests squashing some documentation to avoid redundancy between the old and new helper functions.
