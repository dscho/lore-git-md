This is a bugfix for the diff machinery, addressing a crash when using `--find-object` outside a Git repository. The patch has already been reviewed and accepted by Junio Hamano for merging.

The issue occurs when `git diff --find-object=<oid>` is run outside a repository - it would crash with a BUG() assertion when trying to resolve the OID. Michael Montalbo's fix adds a check for `startup_info->have_repository` to return a user-friendly error message instead. The change is minimal (just 2 lines in diff.c) and comes with a test case verifying the graceful failure.

Junio has reviewed both the code change and test, stating they look good, and has indicated he will queue the patch. This appears to be a straightforward and uncontroversial fix for an edge case in the diff command's behavior.
