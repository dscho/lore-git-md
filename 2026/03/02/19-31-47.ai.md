This is a documentation patch that adds information about Git's support for external commands to the main `git.adoc` man page.

The patch documents how Git will execute any executable in the user's PATH that is prefixed with "git-" as if it were a built-in command. It explains the command lookup order (built-ins first, then external commands, then aliases) and notes that `git help` will show the man page for external commands. The documentation makes clear this is an existing feature that was previously undocumented.

The change is straightforward and well-motivated - documenting an existing but obscure feature that could be useful for users who want to extend Git with custom commands. The patch follows Git's documentation conventions and adds the new section in a logical place in the man page structure. The commit message clearly states what problem is being solved (undocumented feature) and how this change addresses it.
