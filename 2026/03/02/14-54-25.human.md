This is a bugfix for the histogram diff algorithm (XDF_HISTOGRAM_DIFF) in xdiff, addressing an edge case where shifted change groups during compaction produce redundant diff output containing matching lines from both files. The patch comes from Yee Cheng Chin as version 2, incorporating feedback from Junio Hamano and Phillip Wood.

The issue occurs when the compaction phase shifts and merges change groups, potentially creating new matching groups where both sides now have identical lines. This results in diff output that appears redundant to human readers. The fix detects this situation and re-diffs the affected sections using Myer's algorithm via xdl_fall_back_diff(), while preserving all original diff flags (including --ignore-all-space handling).

The patch includes comprehensive test coverage in t4074-diff-shifted-matched-group.sh, demonstrating both triggering scenarios: when shifting creates new matches (case #1) and when slide-up shifting remains (case #2). The tests also verify that diff flags are preserved during re-diffing. Real-world impact appears minimal (affecting <1% of diffs according to the commit message), but the fix produces more intuitive output when the issue does occur.

The technical approach has been reviewed and approved by both Phillip Wood (who confirmed the need to handle both cases) and Junio Hamano (who suggested minor code organization improvements). The patch appears ready for merging once these final documentation and structure updates are incorporated.
