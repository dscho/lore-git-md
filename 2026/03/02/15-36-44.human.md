This is the third patch in Derrick Stolee's v3 series improving environment handling in `git for-each-repo`. The patch focuses on making the command work correctly when run from a worktree.

The key change is using the new `clear_local_repo_env()` helper (introduced in patch 2) to properly handle environment variables when running commands in worktrees. The test suite is expanded to verify this works by:
- Creating a worktree alongside regular repositories
- Testing that commands run from the worktree properly affect all configured repositories
- Adding coverage for environment variable handling including GIT_CONFIG_* variants

The patch addresses a reported issue where `for-each-repo` wasn't properly handling worktree environments, while maintaining all existing functionality. The test changes demonstrate both the fix and additional edge cases around config and environment variable propagation.

This continues the series' theme of robust environment handling while keeping the command's simple interface. The changes are focused and well-tested, building on the foundation laid in earlier patches.
