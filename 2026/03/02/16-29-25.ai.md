This is a bugfix for the `--find-object` option in `git diff`. The patch addresses a crash that occurs when running `git diff --find-object=<oid>` outside a Git repository. Currently, the command fails with a BUG() assertion when it attempts OID resolution via `repo_get_oid()` without a repository present.

The fix adds a check for `startup_info->have_repository` before attempting to resolve the OID, returning a user-friendly error message instead of crashing. The change is minimal - just 2 lines in diff.c - and includes a test case in t4053-diff-no-index.sh that confirms the command now fails gracefully outside repositories.
