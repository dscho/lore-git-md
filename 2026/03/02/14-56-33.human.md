This is a refactoring patch in the ongoing series to add `--trailer` support to `git rebase`. The patch is part of the 7th iteration of the work by Li Chen with assistance from Phillip Wood.

The change simplifies how trailers are handled in `git commit` and `git tag` by switching from `OPT_PASSTHRU_ARGV` to `OPT_STRVEC` for parsing `--trailer` arguments. This means the trailer values no longer need to be stored with the `--trailer=` prefix, allowing removal of the prefix-stripping code in `amend_file_with_trailers()`.

Phillip Wood has given preliminary approval to this change while noting he'll review the final patch in the series separately. The modification is a clean improvement that removes unnecessary string manipulation while maintaining the same functionality. It's a good example of the careful refactoring needed to make trailer handling reusable across Git commands.

The patch follows the series' pattern of moving trailer processing into core Git functionality rather than relying on external processes. This is part of the broader effort to make trailer manipulation available to more commands while keeping the implementation consistent.
