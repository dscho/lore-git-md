Part of Justin Tobler's repository statistics series (v3), this patch adds tracking of commit parent counts to the `git repo structure` command. The 5th in a 6-part series, it identifies the commit with the most parents (like octopus merges) and displays it alongside other repository metrics.

The implementation extends the existing statistics framework by:
- Adding a `parent_count` field to track maximum parents
- Parsing commit objects during iteration to count parents
- Displaying the count in both table and key-value output formats
- Maintaining the series' consistent handling of OIDs for reference

Test updates verify the new output format, including proper handling of empty repositories. The changes integrate cleanly with the existing statistics collection while adding minimal overhead.

This continues the series' pattern of thorough implementation with comprehensive test coverage. The patch appears ready for merging, with only minor output formatting polish remaining in the overall series.
