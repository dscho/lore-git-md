This is a CI/build system patch addressing an issue in GitLab CI pipelines on Windows. Patrick Steinhardt identifies that the `GITLAB_FEATURES` environment variable has grown too large (6.3KB), causing xargs(1) to hit an assertion failure when processing command lines on Windows/MSYS2 systems. The patch simply unsets this environment variable in the CI setup script to keep the total environment size below system limits. The fix is straightforward and well-explained, with clear evidence-based justification showing the environment size analysis and the specific problematic variable. This appears to be a practical solution to a real-world CI pipeline issue.
