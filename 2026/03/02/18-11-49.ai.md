Documentation patch fixing conditional text structure in the sideband control character configuration documentation. This is part of the ongoing security hardening around ANSI escape sequence injection (CVE-2024-32002, CVE-2024-52005).

The patch addresses a translation issue in the `sideband.allowControlCharacters` documentation by duplicating the warning about unwanted ANSI escape sequences in both conditional blocks (for current and future behavior). This ensures the warning appears regardless of which version's documentation is being built, while keeping the version-specific default behavior descriptions separate. The change follows a pattern discussed in a recent thread about documentation translations.

The patch is minimal and uncontroversial, coming from the maintainer to improve documentation clarity. It doesn't change any functionality - just makes the documentation more robust for translators working with the conditional text. The change aligns with the broader security effort while being a straightforward documentation fix.
