Core problem: Hook API conversion removed optimization where sideband hooks would exit early if no hook existed, causing unnecessary overhead from spinning up async threads. Affects `builtin/receive-pack.c` specifically in three hook-related paths (`run_receive_hook`, `run_update_hook`, `run_update_post_hook`). Broader discussion now includes migration path for remaining legacy `find_hook()` usage and potential further optimizations in hook lookup patterns.
