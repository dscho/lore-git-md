This is the final patch in Derrick Stolee's v3 series improving environment handling in `git for-each-repo`. The patch simplifies parameter passing by removing the redundant `argc` parameter from `run_command_on_repo()` and using `strvec_pushv()` to copy all arguments at once.

The change is straightforward - instead of manually looping through arguments to push them individually, it now passes the whole argv array directly. This matches Git's common pattern for command argument handling and makes the code more concise while maintaining identical behavior. The patch builds on the environment isolation work from earlier in the series but focuses purely on code cleanup rather than functional changes.

This appears to be a mechanical improvement that follows naturally after the more substantive environment handling changes in patches 1-3. The series as a whole has been through several rounds of review with input from Jeff King, Phillip Wood, and Junio Hamano, and this final patch seems uncontroversial - it's the sort of simplification that often emerges after the core functionality is settled.
