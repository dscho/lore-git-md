Security patch for ANSI escape sequence handling in sideband channel, part of the CVE-2024-32002/CVE-2024-52005 fixes. This is the second patch in a 3-part series that has been extensively reviewed and tested in production (Git for Windows and Red Hat) for over a year.

The patch delays the secure-by-default behavior (sanitizing control characters except ANSI colors) until Git v3.0, maintaining backward compatibility with existing pre-receive hooks that use colored output. The change is implemented via conditional compilation (`WITH_BREAKING_CHANGES`) and updates both documentation and tests to reflect the transitional state.

Key technical details:
- Current behavior (pre-v3.0) allows all control characters through by default
- Future v3.0 behavior will only allow ANSI color sequences by default
- Tests use a new `TURN_ON_SANITIZING` prerequisite to handle both modes
- URL-specific overrides remain available via `sideband.<url>.allowControlCharacters`

This represents a compromise between security and compatibility, with Junio's approval after removing the problematic 'default' configuration value. The series is now headed to the `next` branch for broader testing.
