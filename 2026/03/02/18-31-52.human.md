This is a follow-up discussion in the ongoing thread about Derrick Stolee's patch series improving environment handling in `git for-each-repo`. The exchange focuses on test isolation when running outside a repository context.

Junio C Hamano notes his surprise that `GIT_CEILING_DIRECTORIES` wasn't used earlier (since 2021) to prevent Git from discovering parent repositories, as this was exactly the variable's original purpose. Jeff King confirms that the current test approach using `TEST_NO_CREATE_REPO=1` combined with `GIT_CEILING_DIRECTORIES` (from 2021's 614c3d8f2e) provides reliable isolation, even though that wasn't the original intent of the 2021 change.

The discussion validates the testing approach taken in patch 1/4 of the series, which aims to ensure `git for-each-repo` works correctly outside repository contexts. This technical confirmation from two experienced contributors (Jeff King and Junio) suggests the isolation mechanism is sound and the patch is on the right track.
