This is a refactoring patch in Phillip Wood and Li Chen's series to add `--trailer` support to `git rebase`. The patch moves the `process_trailers()` function from `builtin/interpret-trailers.c` to `trailer.c` and exposes it via `trailer.h`, allowing other commands to reuse the trailer manipulation logic without forking `git interpret-trailers`.

The change is straightforward - it extracts the core trailer processing logic while maintaining all existing functionality. The v7 iteration includes a parameter rename from `sb` to `input` for clarity. Phillip Wood has reviewed and approved the technical approach, noting only that Li Chen needs to add their sign-off.

This is part of the larger effort to enable in-process trailer manipulation during rebase operations, avoiding the overhead of forking `git interpret-trailers`.
