This is a regular announcement of the Git Rev News newsletter, a monthly summary of Git project activity aimed at keeping the community informed.

Christian Couder shares that edition 132 of Git Rev News is now available online, highlighting recent developments in the Git project. The newsletter is a collaborative effort, with thanks given to Bruno Brito, Michael Ryzhikov and Shreyansh Paliwal for their contributions to this edition.

The announcement includes a direct link to the newsletter and notes that issue #833 is already open for contributions to the next edition. This follows the project's established pattern of monthly updates and community involvement in their creation.

The Git Rev News serves as a valuable resource for those who want to stay informed about Git development without closely following the mailing list. Each edition typically covers new features, bug fixes, ongoing discussions, and other notable changes in the Git ecosystem.
