This is a bugfix patch that addresses a memory leak in `repo_init()`, part of Adrian Ratiu's larger parallel hooks series. The leak occurs when enabling a v1 extension in a v0 repository format - an edge case that only surfaces in development environments but represents a real issue.

The fix is straightforward: adding a call to `clear_repository_format()` in the error path to properly clean up allocated memory. While this is a small change, it demonstrates good attention to detail in the series by catching and fixing a pre-existing issue that was uncovered during the parallel hooks work.

The patch has a clear commit message explaining both the problem and the solution, and the change itself is minimal and focused - exactly what we want to see for this type of cleanup. As part of a larger series that's already received maintainer approval, this fix helps ensure the foundation is solid before adding new functionality.
