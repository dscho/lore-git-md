Junio provides the technical rationale that naming the enum would only be beneficial if the constants needed to be used outside that struct context, which isn't the case here. Taylor notes that attempting to use the enum type for standalone variables (as suggested in an earlier review comment) would actually introduce an edge case bug with duplicate pack specifications.
