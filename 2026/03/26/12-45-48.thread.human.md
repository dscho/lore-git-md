This thread clarified the documentation for `git stash` to accurately reflect when the `push` subcommand is required. The original documentation incorrectly suggested `push` was needed for most options, when in reality only pathspecs require either `push` or `--` disambiguation. Quentin Bernet submitted a patch (v2) that Junio Hamano approved, which makes this distinction clear in both the man page and built-in help text.

The updated documentation now properly shows that options like `-m` and `-u` work with just `git stash`, while pathspecs need explicit syntax. Quentin confirmed the test suite covers this behavior, addressing Junio's question about implementation alignment. With this verification and the maintainer's approval, the patch is ready for merging as part of Git's ongoing documentation improvements. The discussion also noted - but deferred - a potential parser enhancement to make `git stash -m foo <pathspec>` work as an implicit push, leaving that as possible future work.
