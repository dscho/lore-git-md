This is a feature patch adding new ODB (object database) source vtable entries as part of the ongoing ODB abstraction effort. The patch comes from Aaron Paterson and builds on previous work by Patrick Steinhardt and others to make Git's object storage backend pluggable.

The patch introduces three new vtable methods for ODB sources:
1. `write_packfile` - handles packfile ingestion (replacing direct calls to index-pack/unpack-objects)
2. `for_each_unique_abbrev` - enables object name disambiguation across backends
3. `convert_object_id` - translates between hash algorithms during SHA-1/SHA-256 migration

The changes route object name abbreviation and disambiguation through the vtable interface rather than directly accessing files-backend internals. This allows alternative backends (like the upcoming helper backend mentioned in the commit message) to properly participate in these operations.

The implementation for the files backend handles the existing behavior - using oidtree for loose objects, then MIDX, then regular packs for abbreviation lookups. The packfile writing logic maintains the current index-pack/unpack-objects split based on pack size.
