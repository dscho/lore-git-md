This is a preparatory patch in Justin Tobler's series to extend signature handling in `git fast-import`. The patch refactors error handling for unsupported signing modes in `git fast-export` to fail early during option parsing rather than later when processing objects.

Currently, `fast-export` accepts but later rejects certain signing modes ('strip-if-invalid' and 'sign-if-invalid') when it encounters signed objects. The change moves these checks to happen immediately after parsing the command line options, which is more consistent with how other invalid modes are handled. This also removes duplicate error checks from the commit and tag handling code paths. 

The patch is a clean, focused change that simplifies the code while maintaining the same behavior. It sets up for the main series which will add these signing modes to `fast-import`'s tag handling to match its existing commit signature support. The change is well-contained and clearly motivated as preparatory work for the larger feature.
