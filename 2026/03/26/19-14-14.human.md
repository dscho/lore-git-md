Feature: Final patch in series adding abort-on-invalid mode for signed tags in fast-import.

This is the fifth and final patch in Justin Tobler's series to bring parity between commit and tag signature handling in `git fast-import`. It completes the implementation by adding the 'abort-if-invalid' mode for `--signed-tags`, matching the existing behavior for commits. When enabled, this mode will cause the entire import to fail if any tag signature fails verification.

The implementation is straightforward - it builds on the signature validation infrastructure added in previous patches, simply calling `die()` when an invalid signature is detected. The test coverage is expanded to verify the abort behavior works as expected with both missing and forged signatures. This maintains the series' pattern of thorough testing across different signature types and edge cases.

With this patch, all three signature handling options (strip-if-invalid, sign-if-invalid, and abort-if-invalid) are now available for both commits and tags, providing consistent control over signed object processing during imports. The series appears well-structured and complete, with each patch focused on implementing one mode at a time while maintaining test coverage.
