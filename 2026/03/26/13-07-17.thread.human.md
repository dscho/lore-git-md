This thread continues Patrick Steinhardt's ongoing effort to abstract Git's object storage backend, making it possible to plug in alternative implementations beyond the traditional files-based approach. The current patch introduces three new vtable methods that handle key operations: ingesting packfiles (with automatic choice between index-pack and unpack-objects based on size), iterating object abbreviations for disambiguation, and converting between hash algorithms. These changes properly route object-name.c's logic through the vtable interface rather than directly accessing files-backend internals, extending these features to future non-files backends.

The implementation shows careful attention to maintaining existing behavior while abstracting it behind the interface. The patch also prepares for an upcoming helper backend by adding ODB_SOURCE_HELPER to the source type enum. This work builds on Patrick's prior ps/odb-sources series and addresses his earlier feedback about proper abstraction boundaries. The detailed commit message thoroughly explains both the technical changes and their motivation, particularly in supporting the helper backend series and sqlite-git prototype. So far, the patch has not yet received review feedback on the mailing list.
