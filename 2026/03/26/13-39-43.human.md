This is a feature patch extending the ODB (object database) abstraction effort, part of Patrick Steinhardt's ongoing work to make Git's object storage backend pluggable. Aaron Paterson adds three new vtable methods to support key operations that were previously handled directly by the files backend.

The patch introduces methods for:
1. Packfile ingestion (`write_packfile`) - Handles receiving packfiles, choosing between index-pack and unpack-objects based on size and configuration
2. Object disambiguation (`for_each_unique_abbrev`) - Provides the iteration needed for short SHA-1 prefix matching
3. Hash algorithm conversion (`convert_object_id`) - Supports SHA-1/SHA-256 migration by translating between hash algorithms

The changes route object-name.c's abbreviation/disambiguation logic through the new vtable methods rather than directly accessing files-backend internals. This properly extends these features to non-files backends. The implementation appears thorough, with careful attention to maintaining existing behavior while abstracting it behind the vtable.

The patch also prepares for an upcoming helper backend by adding ODB_SOURCE_HELPER to the source type enum. The commit message is detailed and well-structured, explaining both the technical changes and their motivation (supporting the helper backend series and sqlite-git prototype). This builds on prior work in the ps/odb-sources series and addresses Patrick's feedback about proper abstraction boundaries.
