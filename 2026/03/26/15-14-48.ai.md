This is a feature enhancement for the `git backfill` command, part of Git's partial clone functionality. Derrick Stolee's v3 series finalizes the expansion of `git backfill` to support revision arguments and pathspec filtering, addressing the remaining edge cases from v2.

The series now properly handles unknown arguments by explicitly checking for and rejecting them after `setup_revisions()` parsing, fixing an oversight where unknown options starting with `--` were previously skipped silently. The path manipulation safety has also been refined using `strbuf_strip_suffix()` to properly track slash stripping and restoration when checking pathspec matches.

The 6-patch series maintains all the key functionality from v2:
- Support for revision ranges, time filters (`--since`), and pathspecs
- Optimized prefix pathspec handling via `dir_prefix()`
- Post-filtering for complex wildcard pathspecs
- Test coverage for both valid and invalid argument cases

The implementation enables targeted blob downloads in blobless partial clones, particularly useful for operations like `git blame` and `git log -L` on specific files/directories.
