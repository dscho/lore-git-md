Test modernization patch updating path assertions in t2000 test script.

Zakariyah Ali contributes a straightforward test cleanup patch as part of Google Summer of Code (GSoC). The patch replaces direct shell `test` commands with Git's dedicated test helper functions in `t2000-conflict-when-checking-files-out.sh`. This is part of the ongoing effort to modernize Git's test suite by using more descriptive assertion helpers.

The changes are mechanical replacements that don't affect test behavior but improve failure diagnostics. - Symlink-aware checks to their `_not_symlink` variants
