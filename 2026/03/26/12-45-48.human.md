This is a documentation patch that fixes the grammar in the `git stash` man page and corresponding usage text. Quentin Bernet noticed that the syntax for `git stash push` was incorrectly formatted - the optional flags like `-m` for message were not properly shown as being part of the `push` subcommand. The patch makes two small but important changes to both the documentation and the built-in command's usage text to correctly indicate that flags like `-m` belong to `push` rather than being standalone options. 

The changes are straightforward and clearly correct - they just move the closing bracket in the command syntax to properly group the flags with the `push` subcommand. This helps users understand that flags like `-m` must be used with `push` rather than directly with `stash`. The patch is minimal and focused, touching only the exact lines that needed fixing.
