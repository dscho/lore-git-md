The patch also updated terminology from "shortlog" to "commit list" in the `--cover-letter` description to reflect the customizable nature of this output.

Junio C Hamano provided detailed feedback across multiple iterations, focusing on making the documentation more precise while maintaining clarity. The final point of discussion centered on whether to explicitly document that the config variable alone doesn't imply `--cover-letter`. This exchange highlighted differing philosophies on documentation style - completeness versus conciseness - though both approaches aimed to serve users effectively.

The changes affect both configuration (`format.adoc`) and command (`git-format-patch.adoc`) documentation, and are part of an ongoing series introducing flexible commit list formatting options.
