This is a refactoring patch that adds unsigned integer support to Git's config parsing infrastructure. It's part of Adrian Ratiu's larger series introducing parallel hook execution, where the immediate need is for parsing the new `hook.jobs` config option as an unsigned value.

The patch introduces a new `git_config_uint()` helper and related functions (`git_parse_uint()`, `git_configset_get_uint()`, `repo_config_get_uint()`) to properly handle unsigned integers in configuration. The implementation is clean and follows existing patterns in the config parsing code, with thorough documentation in the header files.

The commit message clearly explains the change and justifies the approach (avoiding casting from int or using oversized ulong). The patch touches multiple files to provide a complete solution, including the core parsing logic in parse.c and the public API in config.h. This is a well-contained infrastructure change that will be used by subsequent patches in the series.
