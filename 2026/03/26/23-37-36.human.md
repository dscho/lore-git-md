The change is straightforward and improves code readability by making the parameter's purpose more obvious. It touches three files (`connect.c`, `connect.h`, and `transport.c`) with simple renaming that maintains all existing functionality. The patch appears well-contained and uncontroversial, serving as a preparatory cleanup before the more substantial SSH configuration changes in the series.
