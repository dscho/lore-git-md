Feature: Adding 'abort-if-invalid' mode to fast-import's signed commit handling.

This patch from Justin Tobler introduces a new 'abort-if-invalid' mode for `git fast-import`'s `--signed-commits` option, which causes the import to fail when encountering invalid commit signatures. This is part of a series bringing parity between commit and tag signature handling in fast-import/fast-export.

The change adds the new mode to the gpg-interface subsystem (both .c and .h files), updates the fast-import implementation to handle the abort case, and includes corresponding documentation and test updates. The test suite now verifies the abort behavior when given a forged commit signature.

This is the second patch in a 5-part series that builds on prior work adding signature modes for commits (c20f112e51, ee66c793f8). The implementation is clean and follows the established pattern, with clear error handling and thorough test coverage. The abort mode provides stricter validation for users who want to ensure all imported commits have valid signatures.
