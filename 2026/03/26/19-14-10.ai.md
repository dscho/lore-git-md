Feature: Early validation for fast-export signing modes.

This is the first patch in Justin Tobler's series to extend signature handling in `git fast-import`. It refactors error handling in `fast-export` to catch unsupported signing modes ('strip-if-invalid' and 'sign-if-invalid') during option parsing rather than deferring the error until object processing. The change removes duplicate checks from both commit and tag handling code paths, centralizing the validation in `parse_opt_sign_mode()`.

The patch is a clean preparatory change that simplifies the code by eliminating redundant error messages and moving validation earlier in the execution flow. This makes the behavior more consistent with how other unknown modes are handled. The change is mechanical but important groundwork for the subsequent patches that will add these modes to `fast-import`'s tag handling.

Key technical details: the patch modifies `builtin/fast-export.c` to add explicit checks in `parse_opt_sign_mode()` while removing the now-redundant checks from `handle_commit()` and `handle_tag()`. The error messages remain functionally equivalent but are now emitted earlier in the process. This change doesn't affect the supported modes (like 'abort' or 'verbatim') - it just fails faster for unsupported ones.
