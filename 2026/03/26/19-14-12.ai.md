Feature: Adding 'strip-if-invalid' mode to signed tag handling in fast-import.

This is the third patch in Justin Tobler's 5-patch series to bring parity between commit and tag handling in `git fast-import`. The patch introduces the 'strip-if-invalid' mode for the `--signed-tags` option, mirroring the behavior already available for commits via `--signed-commits`.

The change allows `fast-import` to verify tag signatures during import and strip invalid signatures while preserving valid ones. The implementation follows the same pattern as commit signature handling, with a new `handle_tag_signature_if_invalid()` function that checks signatures and strips them if verification fails. The patch includes comprehensive test coverage in t9306-fast-import-signed-tags.sh, verifying behavior with OpenPGP, X.509, and SSH signatures.

The changes are well-contained, touching documentation, the fast-import implementation, and tests. The test cases demonstrate the mode works correctly with both kept valid signatures and stripped invalid ones, including cases where signatures are invalidated by message changes. This continues the series' pattern of methodically extending signature handling capabilities while maintaining consistency between commit and tag operations.
