Feature: Extending signed tag handling in fast-import.

This is the fourth patch in Justin Tobler's series to bring parity between commit and tag signature handling in `git fast-import`. The patch adds the 'sign-if-invalid' mode to the `--signed-tags` option, which replaces invalid tag signatures with newly generated ones during import.

The implementation mirrors the existing commit behavior from ee66c793f8, introducing a new `signed_tag_keyid` variable to store the signing key and updating the tag signature verification logic. When an invalid signature is detected, the patch strips the old signature and generates a new one using either the configured key or an explicitly provided key. The test suite is expanded to verify this behavior works with both GPG and SSH signatures, including cases where the tag message is modified to invalidate the original signature.

The changes are well-contained and follow the pattern established in earlier patches. The test coverage is thorough, checking both the default key case and explicit key specification. This continues the series' goal of providing consistent signature handling options between commits and tags in fast-import operations. One remaining patch in the series will presumably complete the parity by adding the 'abort-if-invalid' mode for tags.
