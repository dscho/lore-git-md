This is a test infrastructure patch (part 2/6) in Derrick Stolee's series enhancing `git backfill` with revision and pathspec support. The patch prepares a more complex test repository structure to properly exercise the upcoming functionality.

The changes create a branched repository ("src-revs") with:
- A main branch containing 8 linear commits plus a merge of a side branch
- A side branch adding s/file.{1,2}.txt with two versions (4 new blobs)
- An unmerged "other" branch adding o/file.{1,2}.txt (2 more blobs)
- Deterministic timestamps via test_tick for reliable --since testing
- Renamed d/e/ to d/f/ to create ambiguous pathspec cases

The test repository now has 54 total blobs reachable from --all, allowing meaningful comparison between --all, --first-parent, and --since behaviors. This builds on the existing test setup while adding the necessary complexity to verify the revision and pathspec handling that will be introduced in later patches.
