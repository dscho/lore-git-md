This is the final patch in Derrick Stolee's v3 series enhancing `git backfill` for partial clones. The patch focuses on error handling, specifically rejecting unknown arguments that the command previously ignored silently.

The change adds explicit validation in `builtin/backfill.c` to die with an error message when encountering unrecognized arguments, particularly those starting with `--`. It also includes new test cases verifying this behavior - both for ambiguous non-option arguments (which trigger the revision machinery's warning) and explicit unknown options (now caught by the new validation).

This completes the series' goal of making `git backfill` properly handle all standard revision and pathspec arguments while maintaining robust error checking. The implementation is straightforward and well-tested, addressing feedback from Siddharth Shrimali who originally reported the silent-ignore behavior. With Junio C Hamano's ack still valid and all substantive feedback addressed, this appears ready for integration.
