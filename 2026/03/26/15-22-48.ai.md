This is a refactoring patch that makes git-compat-util.h more ISOC23-compliant by properly marking const return values where appropriate.

The patch changes `git_find_last_dir_sep()` in git-compat-util.h to return a `const char*` instead of `char*`, since the function (which wraps `strrchr()`) doesn't modify the input string. This change then requires explicit casts in scalar.c and submodule.c where the returned pointer is used in contexts that do modify the string (by temporarily writing a NUL terminator).

The changes are straightforward and mechanical - the patch correctly identifies the three places that need updating when the function signature changes. The commit message clearly explains the change and its motivation (ISOC23 compliance and making mutation points explicit). This appears to be a well-contained, low-risk change that improves type safety by properly marking immutable returns as const.
