Feature: Extending signed object handling in fast-import.

This is a 5-patch series from Justin Tobler that expands the signature handling options in `git fast-import`. The core changes bring parity between the `--signed-commits` and `--signed-tags` options by adding three new modes to both: 'strip-if-invalid', 'sign-if-invalid', and the new 'abort-if-invalid' mode that fails the entire import when encountering invalid signatures.

The series builds on recent work (c20f112e51 and ee66c793f8) that initially added these modes only for commits. The first patch is a preparatory change that unifies error handling for unsupported signing modes in `fast-export`. The remaining patches systematically add each mode to `fast-import`'s tag handling, with corresponding test updates in t9306-fast-import-signed-tags.sh.

The changes are well-structured, with each commit focused on a single mode addition. The test coverage appears thorough, expanding the existing signature test infrastructure. This looks like a clean extension of existing functionality that gives users more control over how signed objects are handled during imports. The abort mode in particular could be useful for strict validation scenarios.
