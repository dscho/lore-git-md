This is a feature patch series extending Git's fast-import command with more flexible handling of signed objects. The series brings parity between the `--signed-commits` and `--signed-tags` options by adding three consistent modes for each: `strip-if-invalid`, `sign-if-invalid`, and the new `abort-if-invalid` mode.

Justin Tobler's 5-patch series builds on recent work that added signature handling modes to fast-import. The key additions are:
1. A new `abort-if-invalid` mode that stops the import if signature verification fails (previously only available for commits)
2. Extending the same three modes to tag signatures (previously tags only supported basic verification)
3. A preparatory cleanup to fast-export's handling of unsupported signing modes

The changes are well-contained, touching mainly the fast-import implementation and its documentation, with corresponding test updates. The series appears carefully constructed, with each commit focused on a single logical change and tests added for the new functionality. This continues Git's trend of making signature handling more configurable during repository operations.
