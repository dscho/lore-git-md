Feature: Adding 'strip-if-invalid' mode for signed tags in fast-import.

This is the third patch in Justin Tobler's series to bring parity between commit and tag signature handling in `git fast-import`. The patch introduces the 'strip-if-invalid' mode for the `--signed-tags` option, mirroring the behavior already available for commits via `--signed-commits`.

When enabled, this mode will automatically strip invalid signatures from tags during import while preserving valid ones. The implementation includes thorough test coverage for various signature types (OpenPGP, X.509, SSH) and edge cases like modified tag messages that invalidate signatures. The changes build on previous work (c20f112e51) that added this mode for commits.

The patch follows a clean structure: updating documentation, adding the core logic in `builtin/fast-import.c`, and expanding the test suite. The test cases verify that valid signatures remain intact while invalid ones are properly stripped, with no false positives or negatives. This looks like a well-executed extension of existing functionality that maintains consistency between how Git handles signed commits and tags during imports.
