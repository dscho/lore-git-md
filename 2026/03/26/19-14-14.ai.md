Feature: Final patch in series adding abort-on-invalid mode for signed tags in fast-import.

This is the fifth and final patch in Justin Tobler's series to bring parity between commit and tag signature handling in `git fast-import`. It completes the implementation by adding the 'abort-if-invalid' mode to `--signed-tags`, matching the behavior already available for `--signed-commits`. When this mode is active, the import will immediately abort if any tag signature fails verification.

The changes are straightforward - the patch removes the previous error that blocked this mode and adds the actual abort behavior in `handle_tag_signature_if_invalid()`. The test suite is extended to verify the new mode works as expected, including cases with forged signatures. This maintains the series' pattern of thorough test coverage across signature types (OpenPGP, X509, SSH).

With this patch, all three signature handling modes (strip-if-invalid, sign-if-invalid, and abort-if-invalid) are now consistently available for both commits and tags in fast-import. The implementation appears clean and well-tested, completing the feature set introduced in earlier patches. The series as a whole provides users with more granular control over how signed objects are handled during imports.
