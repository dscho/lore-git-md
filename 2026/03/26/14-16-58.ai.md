This is part 2 of Phillip Wood's 3-patch series continuing the `the_repository` removal effort in the worktree subsystem. The patch simplifies the warning message in `can_use_local_refs()` when HEAD points to an invalid reference by removing the attempt to read and display the contents of ".git/HEAD". This change makes the code work correctly with the reftable backend (which doesn't store HEAD in the filesystem) while still providing a useful warning. The patch also updates the test suite to use `test_grep` instead of raw `grep` for better test failure diagnostics.

The changes are straightforward: the warning message is simplified to just stating the problem without trying to show file contents, and the test expectations are updated to match. The patch maintains the same behavior for users while making the code more robust across different ref storage backends. This continues the series' theme of cleaning up worktree-related code as part of the broader `the_repository` removal effort.
