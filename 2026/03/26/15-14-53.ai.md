This patch adds wildcard pathspec support to `git backfill`'s blob filtering, completing the v3 series' goal of full pathspec handling. Derrick Stolee implements two key changes to enable this:

1. A new `exact_pathspecs` flag in `path_walk_context` distinguishes between simple prefix matches (which use the existing fast path) and complex wildcard/magic pathspecs (which require full matching).

2. A `match_pathspec()` check in `walk_path()` provides actual blob-level filtering for wildcard patterns, replacing the previous behavior of silently downloading all blobs when wildcards were present.

The test case demonstrates the improvement - a wildcard pattern like "d/file.*.txt" now correctly reduces downloaded blobs from 48 to 40, rather than fetching everything. This maintains the series' focus on efficient partial clone operations while expanding supported use cases. The implementation builds on the earlier safety fixes (path handling via `strbuf_strip_suffix()`) and integrates cleanly with the existing prefix optimization work.
