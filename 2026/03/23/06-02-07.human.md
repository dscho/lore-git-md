This is a test infrastructure patch from Jeff King (Peff), part of his v2 series improving the `diff-highlight` Perl script. The patch enhances Git's test color decoding capabilities to handle negative ANSI color attributes (like turning off bold or italic) that weren't previously supported in the test framework.

The change adds decoding for three common "off" variants (22, 23, 27) that correspond to the positive attributes the test suite already handles. This is a small but thoughtful improvement that will allow future tests to verify more complete color handling scenarios. The implementation is clean and maintains the existing pattern of the `test_decode_color` function.

As with all of Peff's work, this is a precise, well-explained change that fits naturally into the larger series. It doesn't introduce any complexity or compatibility concerns, and the commit message clearly states both the scope and limitations of what's being added. This patch is clearly ready to go as part of the series.
