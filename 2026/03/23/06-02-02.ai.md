This is a version 2 patch in Jeff King's series improving the `diff-highlight` Perl script, specifically addressing Perl version compatibility. The patch reverts the script's required Perl version from 5.26 back to 5.8, which was the project-wide minimum before October 2023.

The rationale is well-explained: while most Git scripts moved to Perl 5.26, `diff-highlight` is special because it's a contrib script rarely modified by core developers, and more importantly, it's used as a module by `diff-so-fancy` which still targets Perl 5.8 compatibility. The change is minimal (just one line modifying the version requirement) but shows thoughtful consideration of downstream impacts.

This patch demonstrates Jeff King's characteristic attention to backward compatibility and ecosystem considerations. While simple, it's part of a larger effort to make `diff-highlight` more robust while maintaining its usefulness for existing users and dependent projects. The patch has already been signed off by both the original author (Scott Baker) and Jeff King, suggesting it's ready for inclusion.
