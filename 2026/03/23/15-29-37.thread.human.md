Mahi Kassa's patch series to improve `git repo` subcommand help text has progressed through two versions, with most feedback addressed. The goal is to make `git repo info -h` and `git repo structure -h` show subcommand-specific help rather than generic usage. 

In v1, Derrick Stolee approved the approach while requesting minor style tweaks, and Patrick Steinhardt suggested using shared macros for the usage strings to avoid duplication. Mahi incorporated these changes in v2, or so it seemed - Patrick has now spotted that while the commit message claims to use macros, the actual implementation still contains duplicated strings in the usage arrays. 

This leaves one clear issue to resolve: the patch needs to properly implement the macro refactoring as originally suggested. Once that's fixed, the series should be ready for merging, as all other feedback from both reviewers has been addressed. The changes remain well-scoped to the help text improvements without broader side effects.
