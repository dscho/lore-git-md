This is the final integration notice for Adrian Ratiu's hook configuration series, now queued for merging into Git's master branch. The 10-patch set completes Adrian's multi-series effort to modernize Git's hook subsystem, adding two user-visible features to `git hook list` while cleaning up the underlying implementation.

The changes include showing configuration scope (system/global/local) via a `--show-scope` flag and displaying disabled hooks in the listing output. Junio Hamano confirms the series has addressed all review feedback from v1, including build break fixes, style improvements, and output format standardization to match `git config --show-scope`'s tab-separated fields. The implementation introduces a `hook_config_cache_entry` struct for future metadata storage while removing redundant custom structures. 

With no outstanding objections after weekend review time, Junio plans to merge the series to 'next' shortly. The only known issue is a macOS build breakage (REG_ENHANCED) that appears unrelated to these changes. This represents the culmination of Adrian's work to make hook configuration more flexible and observable through Git's config system rather than just filesystem paths.
