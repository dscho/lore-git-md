This is a documentation and user interface patch for the `git repo` subcommands. Mahi Kassa improves the help text output by making each subcommand (`info` and `structure`) show only its own specific help text rather than the generic top-level usage. The patch:

1. Adds separate usage arrays for `repo info` and `repo structure` with their specific command-line syntax
2. Updates the subcommands to use their respective usage arrays when parsing options
3. Adds tests verifying that `-h` shows only the relevant subcommand's help text
4. Maintains the existing top-level `git repo -h` behavior

The changes are straightforward and well-contained, touching only the builtin implementation and its tests. The commit message clearly explains the change and the tests provide good coverage of the new behavior. This appears to be a quality-of-life improvement for users who want to see focused help for each subcommand.
