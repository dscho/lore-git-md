Performance optimization for `diff-highlight` config fetching. This patch from Jeff King (Peff) reduces the number of `git config` processes spawned by the `diff-highlight` Perl script from six to one by using `git config --type=color --get-regexp` to fetch all color-related config at once. The results are cached to avoid repeated lookups.

The change maintains backward compatibility and doesn't affect callers (like `diff-so-fancy`) that pass colors directly to the module. The optimization is particularly noticeable when no colors are configured, as it eliminates unnecessary config checks. Jeff includes a handy debugging tip using `GIT_TRACE=3` to verify the process reduction.

This is part of a larger series improving `diff-highlight`'s performance, test coverage, and documentation while maintaining compatibility with older Perl versions. The patch follows Jeff's characteristic style - precise, well-explained, and with clear attention to both performance and backward compatibility.
