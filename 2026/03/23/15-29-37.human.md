Feature improvement for the `git repo` subcommands. 

Mahi Kassa's patch improves the help text display for `git repo info` and `git repo structure` subcommands by giving each its own usage array. Currently, both subcommands show the same generic help text from the parent `repo_usage` array. The change makes `-h` output more precise by only showing the relevant options for the specific subcommand being invoked.

The implementation adds two new usage arrays (`repo_info_usage` and `repo_structure_usage`) and updates the subcommands to use them. Tests verify that each subcommand's help output now shows only its own options and doesn't include unrelated subcommand information. The top-level `git repo -h` behavior remains unchanged.

This is a straightforward quality-of-life improvement that follows Git's established patterns for subcommand help text. The patch is small, focused, and comes with appropriate test coverage. The change aligns with Git's general principle of providing clear, context-sensitive help output.
