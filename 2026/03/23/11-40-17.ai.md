This is a feature enhancement for the `git backfill` command, part of Derrick Stolee's ongoing work on partial clone functionality. The patch focuses on optimizing pathspec handling in the command.

The key change in this patch is adding support for prefix pathspecs in `git backfill`, allowing more efficient blob downloads by pruning the tree walk to only relevant directories. The implementation:
- Adds `dir_prefix()` function to path.c (previously static) for shared use
- Modifies the path-walk logic to skip trees that don't match prefix pathspecs
- Clears wildcard/magic pathspecs (to be handled in a future patch)
- Updates tests to verify the reduced blob downloads (from 48 to 40 missing objects for single prefix, 16 for multiple)

The patch maintains backward compatibility by falling back to downloading all blobs when encountering complex pathspecs (wildcards/magic), with plans to properly support these in a follow-up change. The test repository structure (prepared in earlier patches) specifically exercises edge cases around directory prefixes.

This builds on the v2 series' improvements to revision handling and represents a performance optimization for the common case of exact path matching. All patches in the series have been acked by Junio C Hamano, indicating readiness for integration.
