This is a test modernization patch in Jeff King's series improving the `diff-highlight` Perl script. The patch adds comprehensive testing for color configuration options that were introduced in 2014 but never properly tested.

The patch adds two new test cases to verify color configuration handling:
1. Tests the highlight/reset style (using bold/italic attributes) that's used by default colors
2. Tests the normal/highlight color style (using actual colors like red/magenta) that was added in the original 2014 commit

The tests use the symbolic color names (`<BOLD>`, `<RED>`, etc.) that were introduced earlier in the series, making the test output more readable and maintainable than raw ANSI sequences. This continues the test modernization effort seen throughout the series.

The patch demonstrates Jeff's characteristic thoroughness - he's adding tests for functionality that's existed for years but wasn't properly covered, ensuring the upcoming color code changes won't introduce regressions. The test cases are well-structured and cover both major configuration styles the script supports.
