This is a performance optimization and API enhancement patch for the `diff-highlight` Perl script in Git's contrib directory, part of Jeff King's ongoing series to improve this tool. The patch allows external callers of the `DiffHighlight.pm` module to pass in their own color configuration rather than having the module make multiple `git config` calls internally.

The key changes are:
1. Makes the `@OLD_HIGHLIGHT` and `@NEW_HIGHLIGHT` arrays package variables that can be set by callers before processing begins
2. Introduces a new `load_color_config()` function that lazily loads default colors from Git config only if no colors were provided
3. Updates the README to document this new API capability
4. Maintains backward compatibility by falling back to the existing config lookup behavior when no colors are provided

The motivation is twofold: first, to avoid the six separate `git config` calls the module currently makes (a performance win), and second, to support use cases where the calling code already has the color configuration available (like `diff-so-fancy` which might fetch config more efficiently). The implementation is careful backward compatibility - existing standalone usage continues to work while enabling new optimization opportunities for embedded use.

This patch builds on the series' earlier work to modernize and optimize `diff-highlight`, showing Jeff's characteristic attention to both performance and maintainability. The changes are well-contained and properly documented, with clear explanations of the code's behavior in both the commit message and updated README.
