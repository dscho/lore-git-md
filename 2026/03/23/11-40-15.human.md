This is a test infrastructure patch in Derrick Stolee's series enhancing `git backfill` for partial clones. The patch prepares a more complex test repository to support upcoming tests of revision arguments and pathspec filtering.

The changes create a branched repository structure with:
- A main branch containing 8 linear commits plus a merge of a side branch
- A side branch adding two versions of new files (s/file.{1,2}.txt)
- An unmerged "other" branch with additional files (o/file.{1,2}.txt)
- Deterministic timestamps via `test_tick` for reliable `--since` testing
- Renamed directory (d/e -> d/f) to test ambiguous pathspec matching

The test repository now contains 54 total blobs reachable from --all, allowing meaningful comparison between different revision specifications. This setup will be used in later patches to verify that `git backfill` correctly handles revision ranges, pathspecs, and filtering options.

The patch follows the series' high standard for test coverage, with careful attention to exercise edge cases in the upcoming functionality. As part of a fully reviewed and acked series, this infrastructure work is ready for integration.
