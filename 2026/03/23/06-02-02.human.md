This is a documentation and compatibility patch in Jeff King's series improving the `diff-highlight` Perl script. The change reverts the Perl version requirement from 5.26 back to 5.8 for this contrib script, maintaining compatibility with tools like `diff-so-fancy` that depend on it.

The patch comes from Scott Baker but is being forwarded by Jeff King as part of the v2 series. It makes a strong case that this particular script - being in contrib and used by external projects - should maintain broader compatibility than core Git's Perl scripts. The justification notes that diff-highlight doesn't actually need modern Perl features and that forcing a higher version would unnecessarily constrain dependent projects.

This is a straightforward, well-reasoned change that aligns with the series' goal of making `diff-highlight` more robust while keeping it widely usable. The patch itself is minimal (just a one-line version bump) but the commit message provides clear rationale. As with the rest of the series, this shows careful attention to both technical correctness and real-world usability concerns.
