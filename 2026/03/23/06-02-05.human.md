This is a test improvement patch in Jeff King's series enhancing the `diff-highlight` Perl script. The patch fixes a subtle issue where the test harness was losing the exit status of the `diff-highlight` command due to piping its output through a sanitizing function. By using temporary files instead of pipes, the tests can now properly detect if `diff-highlight` crashes or exits unexpectedly.

The change is straightforward - it splits what was previously a single pipeline into two steps, writing the raw output to a temporary file before processing it. This maintains all the existing test coverage while adding the ability to catch process failures. The patch follows Jeff's characteristic attention to detail in test infrastructure, ensuring the tests verify both the expected output *and* proper program behavior.

This is part of a larger effort to improve `diff-highlight`'s reliability and maintainability, particularly for users who integrate it with tools like `diff-so-fancy`. The series as a whole shows Jeff's usual high standard of quality, with each change being well-motivated and carefully implemented.
