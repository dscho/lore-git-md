This is a refactoring patch in Christian Couder's series on URL-based whitelisting for promisor remotes. It extracts control character checking logic into a new `has_control_char()` helper function, which will be reused in later commits. The change is straightforward - it improves code organization without altering behavior. The patch maintains the same warning messages when invalid tokens are detected, just moving the control character check into a dedicated function. This is part of the larger effort to improve promisor remote configuration handling, with this particular change being a preparatory cleanup step.
