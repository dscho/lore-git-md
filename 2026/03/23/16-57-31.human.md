This is a documentation patch in Mirko Faina's series improving `git format-patch --commit-list-format`. It adds missing documentation for two placeholders that were introduced in earlier patches but not yet documented: `%(count)` (the patch's position in the series) and `%(total)` (the total number of patches).

The patch is straightforward - it simply adds two entries to the pretty-formats documentation with clear explanations of when and how these placeholders are used. The wording matches Git's typical documentation style and has already been reviewed by Kristoffer Haugsbakk, who caught a typo in an earlier version ("tatal" -> "total"). 

This is a small but important piece of the larger effort to improve commit list formatting in patch emails. The series as a whole has addressed all prior feedback and appears ready for merging. This particular patch ensures users will have complete documentation for all available placeholders when the feature lands.
