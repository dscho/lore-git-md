This is a test modernization patch in Christian Couder's series introducing URL-based whitelisting for promisor remotes. Patch 12/16 focuses on making test file URIs portable across platforms.

The patch fixes how test script t5710 constructs file:// URIs for local paths. On Windows, paths starting with drive letters (like D:/repo) were being misinterpreted as hostnames rather than paths when used in file:// URIs. The solution introduces $PWD_URL and $ENCODED_PWD_URL helper variables that ensure consistent 3-slash file:/// format across platforms, with proper path encoding for spaces.

This change prepares the test suite for upcoming patches that will normalize URLs before matching, where the Windows path issue would have caused test failures. The patch is mechanical but important - it updates all test cases to use the new helpers while maintaining the same test behavior. The changes are straightforward replacements with no functional impact on the tests themselves.

As part of a larger series that's already had significant review, this test cleanup patch looks like a solid preparatory step that improves cross-platform reliability without introducing new risks.
