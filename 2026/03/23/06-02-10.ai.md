This is a test modernization patch in Jeff King's series improving the `diff-highlight` Perl script. The patch updates the test suite to use Git's standard `test_decode_color` helper instead of hardcoding raw ANSI color sequences.

The change makes test output more readable by converting color codes to symbolic names like `<REVERSE>` and `<NOREVERSE>`, which helps both human reviewers and automated test analysis. It also future-proofs the tests by letting them handle new color attributes without manual byte sequence definitions.

The patch demonstrates Jeff's characteristic attention to test quality - it's a small but meaningful improvement that makes the test suite more maintainable. The change is straightforward and well-contained, touching only the test script while preserving all existing test cases (just converting their expected output format). This aligns with the series' broader goal of improving `diff-highlight`'s robustness and maintainability.
