GSoC draft proposal for extending `git cat-file --remote-object-info` functionality. This RFC seeks feedback on planned work to enhance Git's ability to query object information from remote repositories without full downloads, potentially benefiting partial clone workflows. The proposal comes from a GSoC applicant under mentorship, though specific technical details are not yet provided in this initial submission. The thread represents early-stage discussion before implementation approach is finalized. Key open questions include exact scope of remote object info to be exposed, protocol extensions needed, and integration with existing partial clone mechanisms.
