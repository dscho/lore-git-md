This is a header file cleanup patch from Derrick Stolee, part of a 6-patch series enhancing the `git backfill` command for partial clone functionality. The change adds an explicit include for `object-name.h` to `revision.h` since the `REV_INFO_INIT` macro relies on `DEFAULT_ABBREV` defined there.

This is a straightforward dependency resolution - currently any file using `REV_INFO_INIT` would need to include `object-name.h` themselves, which isn't obvious from just looking at `revision.h`. The patch makes this dependency explicit, following good header hygiene practices. It's a small but sensible change that helps prevent future compilation issues when working with revision initialization.
