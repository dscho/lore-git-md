This is a refactoring patch in Christian Couder's series to improve promisor remote configuration. It continues the cleanup from previous patches by removing the redundant 'accepted' strvec parameter from filter_promisor_remote() and consolidating the data flow through the string_list of accepted remotes.

While this doesn't change user-visible behavior, it makes the code more maintainable by reducing the need to keep multiple representations in sync.

The patch appears to be a straightforward mechanical change that follows naturally from the previous refactoring work in the series.
