This suggests the validation layer isn't intercepting the error case before it reaches the merge machinery, or that changes in the base commit have altered merge-ort's behavior in ways that affect this case. Junio has flagged this as a blocking issue that needs investigation before the series can proceed to master.

The technical implementation had previously earned praise for its clean validation logic, and the series had incorporated all requested documentation improvements. The current failure appears to be an interaction between the new ref validation code and underlying changes in the merge machinery, rather than a flaw in the original design. Toon will need to examine whether the validation needs to happen earlier in the process or if adjustments are needed to accommodate merge-ort's current behavior.
