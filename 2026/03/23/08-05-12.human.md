This is a refactoring patch in Christian Couder's series to improve promisor remote configuration. It prepares for upcoming changes where locally configured promisor remotes may use different names than what servers advertise.

The patch adds a `local_name` field to `struct promisor_info` to track both the server-advertised name and any locally assigned name. It introduces a `promisor_info_internal_name()` helper that returns the appropriate name (local if set, otherwise advertised) and updates several functions to use this helper when accessing configuration.

The changeset is clean and focused - it doesn't modify behavior yet, but sets up the plumbing needed for later patches that will implement auto-generated remote names. The commit message clearly explains the motivation and the temporary nature of these changes. This continues the series' pattern of careful, incremental refactoring before introducing new functionality.
