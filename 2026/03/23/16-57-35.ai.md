This is a feature patch (8/8 in the series) from Mirko Faina that completes the `--commit-list-format` improvements by making the "log:" prefix optional when specifying custom formats on the command line. The change allows users to omit the prefix when the format string contains a placeholder (detected by the presence of a '%' character), while still requiring it for plain strings to avoid ambiguity.

The patch adds documentation explaining the relaxed syntax, implements the detection logic in `builtin/log.c`, and includes two new test cases: one verifying the successful use of a format string without the prefix, and another confirming the command fails appropriately when given a plain string without placeholders. This follows the behavior pattern established in `git log --format`.

As the final patch in the v3 series, it builds on the prior work to rename the option from `--cover-letter-format`, add line wrapping support, and introduce preset formats. With all feedback addressed and comprehensive test coverage added, this appears ready for merging. The change provides a more convenient user experience while maintaining clear error handling for invalid inputs.
