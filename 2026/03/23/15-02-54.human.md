This is patch 3/12 in Patrick Steinhardt's v2 series refactoring Git's fsck subsystem to remove its dependence on the global `the_repository` variable. The patch implements the core structural change suggested by Junio C Hamano in v1's review - storing the repository pointer in the `fsck_options` struct rather than passing it through function parameters.

The change is mechanical but far-reaching, touching fsck callers across several built-in commands (`fsck`, `index-pack`, `mktag`, etc.). Each caller now passes the repository to `fsck_options_init()`, which stores it in the options struct for later use. The patch follows cleanly from patch 2/12 which introduced the initialization function infrastructure.

This is a well-executed step in the larger `the_repository` removal effort, showing Patrick's characteristic thoroughness in architectural refactoring. The changes are systematic and focused, with no behavior modifications beyond the intended state management. The series appears on track for merging after final review.
