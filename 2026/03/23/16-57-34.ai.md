This is a feature patch in Mirko Faina's series improving `git format-patch --commit-list-format`. The patch introduces a new "modern" preset format for commit lists in cover letters, equivalent to the format string "[%(count)/%(total)] %s". This provides a ready-to-use alternative to the existing "shortlog" format.

The changes include documentation updates to advertise the new preset, implementation in builtin/log.c to handle the "modern" case, and test updates to verify the behavior. The preset follows the same pattern as the custom format syntax but provides a more convenient shorthand. The test suite is expanded to cover both the direct use of --commit-list-format=modern and its configuration via format.commitListFormat.

This patch fits into the larger series by completing the format options available to users while maintaining backward compatibility. The implementation is straightforward, building on the existing generate_commit_list_cover() infrastructure. With this addition, the series now offers three ways to format commit lists: the traditional shortlog, the new modern preset, and custom format strings.
