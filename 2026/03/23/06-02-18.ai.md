This is a performance optimization patch for the `diff-highlight` Perl script in Git's contrib directory, part of Jeff King's v2 series improving the script's functionality and test coverage.

The patch reduces the number of `git config` processes spawned by `diff-highlight` from six to one by using Git 2.18+'s ability to fetch multiple color config values with a single `--get-regexp` call. The implementation caches the config values in a package variable to avoid repeated lookups while maintaining backward compatibility with both older Git versions and direct color configuration via `@OLD_HIGHLIGHT`/`@NEW_HIGHLIGHT` arrays (used by tools like `diff-so-fancy`).

Key technical changes:
- Introduces `$cached_config` package variable to store fetched color configs
- Modifies `color_config()` to first check the cache before falling back to individual lookups
- Updates the config key format in `load_color_config()` to match the stripped keys stored in cache
- Preserves the existing fallback behavior when no config is set
- The optimization is particularly noticeable when no colors are configured, as it eliminates six redundant config checks
- Includes a debugging tip using `GIT_TRACE=3` to verify the process reduction

This change exemplifies Jeff King's characteristic attention to both performance and backward compatibility, maintaining the script's existing behavior while significantly reducing its overhead. The patch fits well with the series' broader goals of improving `diff-highlight`'s robustness and maintainability.
