This is a completed patch series from Adrian Ratiu that extends Git's hook configuration support, now queued for integration by Junio Hamano. The series builds on Adrian's prior work to make hooks configurable via Git's configuration system rather than just filesystem paths.

The key user-visible changes are two additions to `git hook list`:
1. A `--show-scope` option displays where each hook's configuration comes from (system/global/local)
2. Disabled hooks are now shown in the output, marked with a "disabled" prefix

The implementation includes several cleanups and refactorings of the hook subsystem, with the most notable being the removal of a redundant struct after Junio's feedback. The output format was adjusted in v2 to use tab-separation (mirroring `git config --show-scope`) for better machine parsing, addressing feedback from Patrick Steinhardt and Junio.

The series appears well-polished after review, with Eric Sunshine's style suggestions incorporated and a build break identified by SZEDER Gábor fixed. Junio is holding it for a few more days to allow for final comments before merging to 'next'. This continues Adrian's ongoing effort to improve Git's hook configuration capabilities, with the infrastructure now in place for potential future metadata additions.
