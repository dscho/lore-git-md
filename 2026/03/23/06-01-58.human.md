This is a documentation patch in Jeff King's series improving the `diff-highlight` contrib script. It updates the README to clarify build instructions that changed when the script was modularized in 2017. The patch adds a new "Build/Install" section explaining users need to run `make` in the directory first, and updates the usage example to reference the built script rather than running it directly. 

The change is straightforward and well-justified - the current documentation doesn't match the actual build process. As with all of Jeff's patches, this is a small but thoughtful improvement that makes the project more approachable for users. The patch is part of a larger series (position 1/8 in v2) that modernizes and optimizes `diff-highlight` while maintaining compatibility with tools like `diff-so-fancy` that depend on it.
