This is a performance and flexibility improvement for the `diff-highlight` Perl script in Git's contrib directory, part of Jeff King's ongoing series to modernize this tool. The patch allows external callers of the `DiffHighlight` module to pass in their own color configuration rather than always fetching it via `git config`.

The change makes the module more efficient by avoiding up to six separate `git config` calls when colors are pre-provided, which is particularly useful for tools like `diff-so-fancy` that use this module. It implements lazy loading of the default config only when needed, maintaining backward compatibility while offering better performance for integrated use cases. The patch includes clear documentation updates explaining the new interface.

This is a well-considered change that follows the series' theme of improving both functionality and performance while maintaining compatibility. The implementation is clean separation of concerns - the module still handles all the highlighting logic while giving callers control over configuration sourcing. As with the rest of the series, this patch shows Jeff's characteristic attention to both practical needs and maintainability.
