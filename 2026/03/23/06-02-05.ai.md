This is a test improvement patch in Jeff King's series enhancing the `diff-highlight` Perl script. The patch fixes a subtle issue in the test framework where piping the output of `diff-highlight` through a sanitizing function was causing the script's exit status to be lost. This could mask crashes or unexpected exits during testing.

The change introduces temporary files (`diff.hi` and `commit.hi`) to capture the raw output before sanitizing, allowing proper exit status checking. This follows the pattern seen elsewhere in Git's test suite where intermediate files are used to preserve exit codes that would be lost in pipes. The implementation is clean and maintains the existing test structure while making it more robust.

This patch demonstrates Jeff's characteristic attention to testing rigor - even for a contrib script like `diff-highlight`, he ensures the test framework properly validates all aspects of behavior. The change is small but meaningful, addressing a real gap in test coverage that could let bugs slip through. As part of the larger series, it contributes to the overall goal of making `diff-highlight` more reliable and maintainable.
