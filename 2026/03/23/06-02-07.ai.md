Test infrastructure patch enhancing Git's color attribute handling in the test suite. This is part of Jeff King's series improving the `diff-highlight` contrib script, but the change itself is a general test-lib improvement.

The patch adds support for decoding negative ANSI color attributes (22, 23, 27) in `test_decode_color()`, which converts numeric color codes to human-readable names in test output. These correspond to "off" variants of existing attributes: normal intensity" (nobold/nodim), "no italic", and "no reverse". The implementation notes that some attributes share codes (22 handles both nobold and nodim) and that this isn't meant to be exhaustive coverage of all possible attributes.

This is a straightforward, well-contained change that improves the test framework's ability to verify color-related behavior. While motivated by the `diff-highlight` work, it's a general improvement that could benefit other color-handling tests. The patch follows Jeff's typical style - minimal, correct, and clearly explained in the commit message. As part of a reviewed series that's already addressed feedback in v2, this appears ready for merging.
