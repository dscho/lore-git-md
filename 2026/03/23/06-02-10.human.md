This is a test modernization patch in Jeff King's series improving the `diff-highlight` Perl script. The patch updates the test suite to use Git's standard `test_decode_color` helper instead of raw color codes, making the tests more readable and maintainable.

The change replaces hardcoded ANSI escape sequences (`\033[7m` for reverse video, `\033[27m` to reset) with symbolic names (`<REVERSE>` and `<NOREVERSE>`) that `test_decode_color` understands. This matches how color handling is tested elsewhere in Git's test suite and makes test failures easier to diagnose since the output will be human-readable rather than showing raw terminal control codes.

The patch is part of a larger effort to improve `diff-highlight`'s test coverage and integration with Git's test infrastructure. It follows Jeff's typical high-quality standards - the change is focused, well-explained, and maintains backward compatibility while making the code more maintainable. The series as a whole has already addressed review comments from v1 and appears ready for merging.
