[PATCH] fetch-pack: move fsck options to function scope

Part of the `the_repository` removal effort. Moves fsck options from global to function scope in `fetch-pack.c` to prepare for repository pointer association. Patrick Steinhardt addresses two issues: (1) potential state accumulation from global reuse, and (2) upcoming need for repository pointer association during initialization. Changes are mechanical - moves fsck options into `do_fetch_pack` and `do_fetch_pack_v2` with proper cleanup via `fsck_options_clear()`. No behavior change intended; groundwork for future repository pointer work. Follows Git style with clear commit message explaining rationale.
