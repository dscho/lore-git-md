This is a test modernization patch in Jeff King's series improving the `diff-highlight` Perl script. The patch adds long-overdue test coverage for configurable colors in `diff-highlight`, which was introduced back in 2014 but never properly tested.

The patch adds two new test cases that verify different color configuration approaches:
1. Testing the highlight/reset style used by default colors
2. Testing the normal/highlight style that was added in the original 2014 commit but never validated

The tests use symbolic color names (like `<BOLD>`, `<ITALIC>`, `<RED>`) rather than raw ANSI codes, making them more readable and maintainable. This aligns with the broader test modernization effort in the series. The patch demonstrates Jeff's characteristic thoroughness - while working on color-related changes, he noticed this untested functionality and took the opportunity to add proper coverage before making further modifications.
