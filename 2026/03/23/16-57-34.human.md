This is a feature patch in Mirko Faina's series improving `git format-patch --commit-list-format`. The series is now in its third iteration and appears merge-ready, with all prior feedback addressed.

The format matches what many projects already use manually, providing a standardized alternative to the existing "shortlog" format. The implementation builds on the series' earlier work that added format string support with placeholders like %(count) and %(total).

It's a straightforward addition that completes the feature set for commit list formatting, giving users both custom format strings and curated presets to choose from. The changes are well-contained and follow Git's established patterns for format string handling.
