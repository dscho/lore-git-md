This is a cover letter for a series of CI/build system improvements from Patrick Steinhardt. The 8-patch series has two main themes:

First, it introduces a new "tools/" directory to consolidate build infrastructure and developer tooling, following up on a previous cleanup of the "contrib/" directory. This involves moving several existing scripts and directories (coccinelle rules, coverage-diff.sh, update-unicode.sh, and various build scripts) from their current locations into the new structure.

Second, it adds precompiled header support to the Meson build system, which provides a ~30% compilation speed improvement. This involves some preparatory work in git-compat-util.h and changes to how compatibility sources are compiled.

The changes are mechanical but wide-ranging, touching build configurations across Makefile, CMake, and Meson build systems. The series appears well-structured with clean commit separation - the first 5 patches handle the tools/ reorganization, while the last 3 implement the precompiled headers optimization. As with most build system changes, this will need careful review to ensure no regressions across platforms and build configurations.
