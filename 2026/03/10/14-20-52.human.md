This is a cleanup patch in Adrian Ratiu's ongoing hook configuration series, specifically addressing how hook lists are cleared. The patch replaces a custom `hook_list_clear()` function with the more standard `string_list_clear_func()` pattern, which requires converting `hook_clear()` to a `hook_free()` function that matches the expected callback signature.

The change makes the API cleaner by eliminating NULL function arguments in calls to clear hook lists. There's a minor tradeoff - the implementation now needs to preserve the internal callback data's free pointer - but the overall result is more idiomatic Git code. Eric Sunshine pointed out a style issue with an `UNUSED` macro in the header that Adrian will fix in v2.

This is a straightforward internal improvement that doesn't affect user-facing behavior. It's part of Adrian's larger effort to modernize and standardize the hook subsystem's implementation while adding configuration capabilities. The patch has already received positive feedback from both Patrick Steinhardt (who suggested the approach) and Eric Sunshine (who caught the style nit). With the promised fix, this should be ready for inclusion.
