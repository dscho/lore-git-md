This is a documentation patch for the final version (v7) of a feature adding configurable cover letter formatting to `git format-patch`. Bert Wesarg points out a minor wording inconsistency in the documentation, suggesting that the description of `format.commitListFormat` should use "Defaults to `shortlog`" rather than "Default to `shortlog`" to match the style used elsewhere in the file.

The patch series itself (authored by Mirko Faina) has already gone through seven iterations and received approval from both Junio C Hamano and Jeff King (Peff). The feature introduces a new `--cover-letter-format` option and corresponding `format.commitListFormat` config setting, allowing users to customize how commit lists appear in cover letters beyond the default shortlog format. The implementation is production-ready with comprehensive test coverage.

Bert's comment is a small polish on the otherwise complete documentation, noting a stylistic inconsistency rather than raising any substantive concerns about the feature. Given the thorough review process this series has undergone, this appears to be one of the final tweaks before merging.
