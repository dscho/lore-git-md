This is a feature patch series adding new advice for handling uncommitted changes during branch switches, part of a GSOC microproject. The v3 iteration follows feedback from Patrick Steinhardt and Phillip Wood.

The series introduces `ADVICE_STASH_BEFORE_CHECKOUT` to warn users when switching branches with local modifications that would be lost. The advice follows Git's existing patterns, with configurable behavior via `advice.stashBeforeCheckout`. The implementation adds the new advice type and documentation while maintaining consistency with similar advice functions like `advise_on_updating_sparse_paths()`.

Key changes in v3:
- Now a clean two-patch series (addressing Phillip Wood's request to split unrelated commits)
- Still missing the actual call site integration in `builtin/checkout.c` (noted by Patrick Steinhardt)
- Planned future work includes making `git checkout -m` the primary recommendation (per Phillip's suggestion)

The patch appears well-scoped and follows Git conventions, though reviewers will want to see the checkout integration in a follow-up. This is a straightforward addition that could help users avoid losing work during branch switches. The GSOC context suggests this a good learning opportunity for the contributor while delivering a small but useful feature.
