[PATCH 0/8] ci/build: introduce tools/ directory and meson PCH support

Thread identity: Patrick Steinhardt (ps@pks.im) proposing build system improvements via an 8-patch series. Thread type: infrastructure/developer tooling.

Core problem/goal: Two parallel improvements - (1) consolidate scattered build/development tooling into a new "tools/" directory (separating essential build infrastructure from optional contrib/ material, following up on prior cleanup), and (2) add precompiled header support to Meson build for faster compilation. Changes span multiple build systems (Makefile, CMake, Meson).

Current status: Complete 8-patch series posted and under review. Patch 1/8 established tools/ directory structure. Patch 2/8 relocated Coccinelle semantic patches from contrib/coccinelle/ to tools/coccinelle/. Patch 3/8 moved coverage-diff.sh from contrib/ to tools/. Patch 4/8 relocates update-unicode.sh from contrib/ to tools/. Patch 5/8 moves core build script generators (generate-*.sh) and helpers (check-builtins.sh, detect-compiler) from top-level to tools/. Patch 6/8 modified git-compat-util.h to prepare for PCH support by moving sign-compare warning suppression outside include guards. Patch 7/8 splits compatibility sources into their own static library. Final patch 8/8 implements Meson precompiled headers for git-compat-util.h, demonstrating 40% speedup in full builds (14.5s -> 10.3s mean time). Junio C Hamano has raised a workflow concern about the Coccinelle relocation potentially disrupting developers if generated patch locations change, but has not objected to the changes outright.

Key technical details:
- tools/ directory now contains relocated Coccinelle infrastructure, coverage-diff.sh, update-unicode.sh, and core build generators
- generate-cmdlist.sh, generate-configlist.sh, generate-hooklist.sh, generate-perl.sh, generate-python.sh, generate-script.sh moved from top-level
- check-builtins.sh and detect-compiler helpers relocated
- git-compat-util.h modified to move sign-compare warning suppression outside include guards for PCH compatibility
- New compat_sources list created in meson.build, built as separate 'compat' static library
- New tools/precompiled.h created as PCH entry point including git-compat-util.h
- Meson c_pch option configured for both libgit and git executable
- Performance improvement: 40% faster builds (23,000+ line header precompiled once)
- All changes maintain original functionality across platforms (Windows, Cygwin, Darwin, Linux)
- Build system references updated in Makefile, CMake, Meson (including contrib/subtree meson.build)
- CI scripts and spatchcache helper updated to new paths
