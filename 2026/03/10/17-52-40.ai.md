This is patch 7/8 in Patrick Steinhardt's series introducing build system improvements, specifically preparing the Meson build for precompiled header (PCH) support. The patch splits compatibility sources into their own static library to handle special cases where certain compatibility files intentionally avoid including git-compat-util.h - which would be implicitly included by PCH.

The technical change moves all compatibility sources (previously mixed with main sources in libgit_sources) into a new compat_sources list. These are then built as a separate static library 'compat' that links with the main 'git' library. The patch carefully preserves all existing functionality while reorganizing the build structure to accommodate PCH requirements.

Key files affected are primarily in the compat/ directory, with changes to meson.build to implement the new library separation. The patch maintains all existing platform-specific handling (Windows, Cygwin, Darwin, Linux) and feature detection while restructuring how these components are built.

This is a preparatory change for the final patch in the series which will introduce the actual PCH support. The separation ensures PCH can be safely enabled for the main library sources while avoiding problematic implicit includes for compatibility code. The change is mechanical but necessary groundwork to enable the performance optimization promised by PCH while maintaining correct compilation behavior.
