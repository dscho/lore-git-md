Final polish patch in a series adding configurable cover letter formatting to `git format-patch`. This addresses a test suite typo where `test_expected_success` was incorrectly used instead of the standard `test_expect_success` macro. The patch itself is trivial - just fixing the test macro name - but is part of the larger effort to provide flexible cover letter formatting through both CLI (`--cover-letter-format`) and config (`format.commitListFormat`) options.

The series has gone through seven iterations and is now in its final form, with all major technical and documentation requirements met. This particular issue was caught by Junio C Hamano during final review. The test in question verifies that the new formatting options (including the `%(count)` and `%(total)` placeholders) work correctly when generating cover letters with subject, author and patch count information.

The broader context is that this series introduces a comprehensive system for customizing cover letter output while maintaining backward compatibility with the traditional shortlog-based format. The implementation includes new functions in `builtin/log.c`, placeholder support in `pretty.c`, and extensive test coverage. All substantive feedback from reviewers has been addressed in previous iterations, leaving only minor polish items like this test fix.
