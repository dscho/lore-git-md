This is part of an ongoing GSOC microproject to add advice for handling uncommitted changes during branch switches. The patch is now at version 3 and shows incremental improvements based on reviewer feedback.

The patch adds `ADVICE_STASH_BEFORE_CHECKOUT` advice that triggers when users attempt to switch branches with local modifications. The key change in v3 is simplifying the advice message to focus on recommending `git checkout -m` as the primary solution, rather than the previous two-step stash/pop approach. The advice remains configurable via `advice.stashBeforeCheckout`.

Reviewers Phillip Wood and Patrick Steinhardt have provided consistent feedback across iterations. While the patch maintains clean scope and follows Git's advice patterns, two key gaps remain from prior reviews: the advice still isn't integrated into the actual checkout workflow (missing call site in checkout.c), and Phillip Wood's recommendation to make `-m` the primary suggestion is only partially addressed here (the message is simplified but doesn't explicitly position `-m` as the preferred option).
