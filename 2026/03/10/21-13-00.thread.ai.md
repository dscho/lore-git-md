Git for Windows security release announcement (downstream, not part of main Git development). Johannes Schindelin announces Git for Windows 2.53.0(2), addressing Windows-specific CVE-2025-66413 in NTLM authentication. The vulnerability could expose NTLMv2 hashes during clone operations with malicious servers. Fix disables NTLM auth by default to prevent credential exposure through weak hashing. Release includes SHA-256 checksums for installers/portable versions across 32-bit, 64-bit and ARM64 architectures. Version follows Git for Windows convention of tracking upstream (2.53.0) with downstream patch level (2). This is a Windows-specific network authentication issue not affecting other platforms.
