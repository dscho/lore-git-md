This is part of an 8-patch series refactoring repository-specific global variables into `struct repo_config_values`, continuing the project's effort to reduce global state and improve repository isolation. 

The patch moves the `check_stat` configuration (which controls how strictly Git checks filesystem metadata like mtime and inodes) from a global variable to per-repository storage in `struct repo_config_values`. This ensures the setting is properly scoped to each repository instance rather than being shared across all repositories in a process. The change touches several files that interact with filesystem stat data, updating them to access the setting via `the_repository` instead of the global.

The patch follows the established approach from the series: small, focused changes that preserve behavior while eliminating cross-repository state leakage. It's a mechanical but important step in the ongoing `the_repository` removal effort. The changes span core files (environment.h/c) and stat handling code (statinfo.c, entry.c), with straightforward updates to call sites. The commit message clearly explains the motivation and maintains the series' consistent pattern.
