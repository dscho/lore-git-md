Performance optimization for `git help`'s configuration listing functionality in `builtin/help.c`. Originated by Siddharth Shrimali with a patch moving a `strbuf` declaration outside nested loops in `list_config_help()` to avoid repeated allocations, instead reusing a single buffer with `strbuf_reset()`. This reduces heap pressure when displaying configuration help and incidentally fixes a memory leak in the `SHOW_CONFIG_HUMAN` case where a `continue` could skip cleanup. Patrick Steinhardt reviewed the change, confirming it correctly addresses both the performance concern and memory leak while suggesting two minor style improvements: removing an empty newline to make the `strbuf_reset()` call more visible, and ensuring statements follow variable declarations per Git's coding style. The modification remains small (4 lines removed, 3 added) but affects performance-sensitive help system code paths. The review indicates the patch is technically sound and ready for inclusion after these style tweaks. The change touches how configuration variable names are processed when generating help output.
