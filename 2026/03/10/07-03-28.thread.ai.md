Performance optimization for `git help`'s configuration listing functionality in `builtin/help.c`. Originated by Siddharth Shrimali with a patch moving a `strbuf` declaration outside nested loops in `list_config_help()` to avoid repeated allocations, instead reusing a single buffer with `strbuf_reset()`. This reduces heap pressure when displaying configuration help and fixes a memory leak in the `SHOW_CONFIG_HUMAN` case where a `continue` could skip cleanup. 

Patrick Steinhardt reviewed the initial version, confirming it addresses both the performance concern and memory leak while suggesting two style improvements: removing an empty newline to make the `strbuf_reset()` call more visible, and ensuring statements follow variable declarations per Git's coding style. The v2 patch from Siddharth Shrimali incorporates both suggested changes while maintaining the minimal diff (4 lines removed, 3 added) that affects performance-sensitive help system code paths.
