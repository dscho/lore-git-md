This is part 7 of an 8-patch series refactoring repository-specific global variables into `struct repo_config_values`, continuing the project's effort to reduce global state and improve repository isolation. The series is part of the ongoing `the_repository` removal effort.

This patch moves the `sparse_expect_files_outside_of_patterns` configuration variable from a global into the per-repository `repo_config_values` struct. This setting controls whether Git expects files outside sparse checkout patterns (used in `clear_skip_worktree_from_present_files()`). The change follows the same pattern as previous patches in the series: removing the global declaration, adding it to the struct, updating initialization in `repo_config_values_init()`, and modifying the config callback to store the value per-repository. The diff touches 3 files (environment.c/h and sparse-index.c) with straightforward mechanical changes.

The patch maintains the same approach seen in earlier parts of the series - careful updates to preserve behavior while eliminating cross-repository state leakage. The changeset is small and focused, modifying only the necessary call sites.
