This is a feature patch series introducing new user guidance for dirty checkouts, part of a GSOC microproject. The main patch adds a new advice type `ADVICE_STASH_BEFORE_CHECKOUT` that triggers when attempting to switch branches with uncommitted changes that would be overwritten.

The core change adds infrastructure parallel to existing advice functions like `advise_on_updating_sparse_paths()`. When enabled (default true), it will list affected files and suggest using `git stash push/pop` to preserve changes. The advice can be disabled via `advice.stashBeforeCheckout` config. The implementation touches `advice.h` (new enum), `advice.c` (implementation and config wiring), and `Documentation/config/advice.adoc` (new config key documentation).
