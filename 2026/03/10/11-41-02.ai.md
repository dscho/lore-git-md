This patch is part of Jiamu Sun's ongoing series to refactor Git's autocorrection functionality into a standalone module. The patch moves TTY checking for autocorrection prompts from help.c to autocorrect.c, consolidating all autocorrection configuration handling in one place.

Key changes:
- Introduces a new `struct autocorr` to bundle the mode and delay parameters
- Moves TTY detection into `autocorr_resolve_config()` where it logically belongs with other config validation
- Simplifies the control flow in `parse_autocorrect()` with explicit returns
- Removes redundant float casting in delay calculation
- Updates callers to use the new struct-based API

The changes maintain all existing behavior while improving code organization. The patch follows the series' pattern of extracting autocorrection logic from help.c into the new autocorrect module, making the functionality more reusable across Git commands.

This appears to be a straightforward refactoring with no behavioral changes, continuing the series' progression toward cleaner separation of concerns. The implementation looks solid, with all config handling now properly centralized in autocorrect.c.
