The core change replaces `atoi()` with `strtol_i()` in `apply.c` to properly validate the `-p` argument, now requiring non-negative integers and failing explicitly on invalid inputs. The patch includes new test cases in `t4120-apply-popt.sh` that verify:
- Successful application with valid numeric input
-p 1`
- Rejection of non-numeric strings `-p malformed`
- Rejection of malformed numbers `-p 2q`
- Rejection of negative numbers `-p -1`

The tests use proper cleanup with `test_when_finished` and the new test file `t4120/patch`.
