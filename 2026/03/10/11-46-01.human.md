Bugfix for `git merge-file --object-id` in worktrees. This patch addresses a regression introduced by two earlier changes: the addition of `--object-id` in 2023 (which added a redundant `setup_git_directory()` call) and a 2025 change that made double initialization of the object directory a BUG(). The fix guards the setup call to prevent triggering the BUG when run in a worktree while maintaining the "not a git repo" error for non-repository cases. The patch includes a new test case verifying the fix works in worktrees.

The change is small and focused - just two lines modified in the command implementation plus a test. The commit message clearly explains the chain of events that led to the bug and why the fix works. This appears to be a straightforward correctness fix that should be uncontroversial. The test coverage looks appropriate, checking both the worktree case and maintaining the existing error behavior.
