This is a platform compatibility patch in Patrick Steinhardt's series optimizing `git-upload-pack` performance through `writev()`-based buffering. The patch introduces a compatibility wrapper for the POSIX `writev()` system call, which will be used in subsequent patches to batch writes and reduce syscall overhead.

The wrapper handles systems that lack native `writev()` support (notably Windows) by implementing the functionality manually - writing each buffer segment sequentially while maintaining the same error semantics as the real syscall. It includes proper overflow checking for the total buffer size (matching POSIX's EINVAL behavior) and integrates with Git's existing `xwrite()` infrastructure.

The changes touch build system files (Makefile, config.mak.uname, meson.build) to conditionally compile the wrapper only when needed, plus new files for the implementation (compat/writev.c) and declarations (compat/posix.h). The implementation is careful to preserve POSIX semantics including partial write handling and proper error returns.

This is a foundational piece for the larger performance work, providing the cross-platform basis for the `writev()` optimizations while maintaining compatibility Git requires. The patch follows Git's standard pattern for such compatibility shims and appears well-researched regarding platform support (citing NonStop documentation and GNU gnulib references).
