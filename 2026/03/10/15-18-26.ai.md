This is the sixth and final patch in Patrick Steinhardt's series to generalize object counting as part of the ODB (object database) abstraction effort. The patch introduces new `odb_count_objects()` and `odb_source_count_objects()` APIs to provide a backend-agnostic way to count objects, replacing the repository-specific `repo_approximate_object_count()` function.

The key changes include:
- Adding the new counting functions to odb.h/odb.c that work across all ODB backends
- Migrating callers in builtin/gc.c, commit-graph.c, and object-name.c to use the new interface
- Preserving the existing caching behavior but extending it to account for counting flags
- Removing the now-obsolete repo_approximate_object_count() implementation from packfile.c

The patch completes the transition to a pluggable backend architecture for object counting while maintaining the same approximate counting semantics. It follows the pattern established in earlier patches of moving logic from repository-specific code into the core ODB infrastructure. The changes are mechanical and focused on internal implementation details rather than user-visible behavior.

This concludes the series that began with header cleanup and progressively extracted and generalized object counting logic. The work enables future alternative ODB backends to implement their own counting mechanisms while providing a consistent interface to callers.
