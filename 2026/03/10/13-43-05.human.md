This is a feature patch adding advice for handling uncommitted changes during branch switches, part of an ongoing GSOC microproject.

Arsh Srivastava's v3 patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when local modifications would be lost during a branch switch. The advice suggests using `git stash push/pop` as the primary solution, with `git checkout -- <file>` as an alternative to discard changes. The implementation follows Git's existing advice patterns with configurable settings.

The patch has seen significant iteration, with reviewers Phillip Wood and Patrick Steinhardt providing guidance on message clarity and integration points. Junio C Hamano has raised new concerns about unconditionally recommending `-m` (merge) due to its irreversible nature, suggesting either stronger caveats or presenting stash as the primary option.

Notably, the patch still lacks the critical checkout.c integration point identified in prior reviews, and the discussion around how to frame the `-m` recommendation remains unresolved. The author appears engaged with the patch still needs work before it can progress. This is a well-intentioned usability improvement that would benefit from addressing the outstanding technical and UX concerns.
