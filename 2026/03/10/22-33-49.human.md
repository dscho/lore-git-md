This is a refactoring patch that's part of a larger series adding signature handling to `git fast-import`. The patch moves and renames a signing helper function from commit.c to gpg-interface.c, making it more generally reusable. 

The change extracts `sign_commit_to_strbuf()` from commit.c, renames it to the more generic `sign_buffer_with_key()`, and moves it to gpg-interface.c where it can be used by both commit.c and fast-import.c. The function handles the same logic - signing a buffer with either a specified key or the default configured key - but is available for broader use.

Junio C Hamano notes this is a sensible restructuring that makes the signing machinery easier to reuse, and approves of the more appropriately named function. The patch is a clean preparation step for the subsequent fast-import signing functionality, with no obvious issues in the implementation.

This is part of a completed three-patch series that has already been merged, with this particular change being a straightforward code reorganization that improves the architecture by centralizing signing logic in gpg-interface.c. The series overall adds the ability for fast-import to re-sign commits with specified keys when processing signed commits.
