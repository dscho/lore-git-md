This is the 7th patch in Patrick Steinhardt's 8-part series introducing build system improvements, focusing on Meson precompiled header (PCH) support and tooling reorganization. The series aims to both consolidate build tools into a new "tools/" directory and enable ~30% faster compilation via PCH.

This particular patch prepares for PCH support by splitting compatibility sources into their own static library. The compatibility files (like nonblock.c, obstack.c, etc.) are moved out of the main libgit sources because they intentionally don't include git-compat-util.h - including it via PCH would cause compilation errors. The change is mechanical but important groundwork, touching nearly every platform-specific section of meson.build to properly segregate the compatibility code.

The patch maintains all existing functionality while enabling the upcoming PCH implementation to work cleanly with the main library sources. It's part of the broader effort to modernize Git's build infrastructure, following Patrick's earlier work on Meson adoption. The changes are well-contained to the build system with no impact on runtime behavior.
