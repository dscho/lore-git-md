This is the final patch in a series introducing a new advice feature for branch switching with uncommitted changes. The patch adds `ADVICE_STASH_BEFORE_CHECKOUT` to warn users when they attempt to switch branches with local modifications that would be overwritten.

The implementation follows Git's standard advice pattern, adding:
- A new enum in `advice.h`
- Configuration documentation in `advice.adoc`
- An implementation in `advice.c` that lists affected files and suggests using `git stash push/pop`

The advice is enabled by default and can be disabled via `advice.stashBeforeCheckout`. This is a straightforward addition that matches existing advice patterns like `advise_on_updating_sparse_paths()`. The patch is cleanly implemented and well-documented, though it hasn't yet received review feedback as it's the newest part of the series.

This completes the GSOC microproject portion of the thread, while the diffstat width calculation fixes (the other part of the series) have already been approved and merged for Git 2.54.0. The advice feature appears ready for review and potential inclusion in a future release.
