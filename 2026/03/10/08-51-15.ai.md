This is a test patch in a series about improving diffstat width calculations with ANSI color codes. It specifically tests that Git correctly handles ANSI escape sequences in the line prefix (like those from `--graph` output) when computing diffstat widths.

The test creates a commit with a long filename, then verifies that:
1. With sufficient terminal width (MIN_TERM_WIDTH), the full filename appears in the colored diffstat output
2. With one column less (MIN_TERM_WIDTH-1), the filename is properly truncated with an ellipsis

The test uses `test_decode_color` to properly handle the ANSI color sequences in the output verification. This is a companion to the earlier patch that fixed the underlying diffstat width calculation bug when ANSI colors are present.
