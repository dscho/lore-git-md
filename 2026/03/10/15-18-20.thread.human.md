This thread covers Patrick Steinhardt's six-part series completing the ODB abstraction work for object counting functionality. The series restructures how Git counts are handled, moving the logic to the ODB layer with new APIs like `odb_count_objects()` while preserving existing caching behavior. Key changes include separating packed and loose object counting, introducing flags for approximate vs exact counts, and updating callers throughout the codebase.

Junio C Hamano has reviewed the series and raised (but ultimately accepted) the performance tradeoffs in the loose object counting strategy, which now scans one full shard directory rather than stopping early. Toon Claes has provided thorough technical review throughout, catching issues like an uninitialized variable and now noting a comment that needs updating in the final patch. The changes affect object-file.c, odb/source-files.c, and several calling sites including gc.c and commit-graph.c.

With Junio having queued the series and only minor documentation updates remaining, this appears to be the final iteration before merging. The work completes an important phase of the ODB abstraction effort, paving the way for future pluggable backends while maintaining performance characteristics of the existing implementation.
