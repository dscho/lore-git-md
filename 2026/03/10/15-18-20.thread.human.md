Patrick Steinhardt's six-part series to abstract Git's object counting functionality behind the ODB interface has now been completed. The work replaces the repository-specific `repo_approximate_object_count()` with new generic APIs (`odb_source_count_objects()` and `odb_count_objects()`) that maintain existing behavior while enabling future pluggable backends.

The series progressed through two versions with input from Justin Tobler and Toon Claes, addressing review feedback about initialization and documentation. Junio Hamano reviewed both iterations and confirmed the technical approach. The changes are mechanical refactorings that preserve behavior while restructuring the code to count objects across packed and loose storage in a backend-agnostic way. The final patch removes the old interface entirely and updates callers in gc.c, commit-graph.c, and object-name.c to use the new API.

Key improvements include configurable counting modes (approximate sampling vs exact enumeration), better error handling, and clearer cache management. The work touches object-file.c, odb/source-files.c, and packfile.c, completing this phase of the ODB abstraction effort without changing observable behavior for existing users. With all feedback addressed and no outstanding concerns, the series is ready for merging.
