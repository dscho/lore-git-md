This is a security release announcement for Git for Windows, not part of the main Git project's development. Johannes Schindelin announces Git for Windows 2.53.0(2), a security update addressing CVE in the Windows-specific NTLM authentication behavior.

The release fixes CVE-2025-66413, where Git for Windows could expose users' NTLMv2 hashes during clone operations with attacker-controlled servers. The fix disables NTLM authentication by default to prevent credential exposure through weak hashing. This is a Windows-specific vulnerability that doesn't affect other platforms.

The announcement includes SHA-256 checksums for various distribution formats (installers, portable versions, MinGit variants) across 32-bit, 64-bit, and ARM64 architectures. The release follows Git for Windows' standard practice of versioning in parallel with upstream Git (2.53.0) while appending its own patch level (2).

For context: This is a downstream security fix specific to the Windows port. The main Git project's mailing list sees these announcements for visibility, though the actual development happens in the Git for Windows fork. The change affects only Windows users performing network operations where NTLM authentication might previously have been attempted.
