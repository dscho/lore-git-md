This is a follow-up in an ongoing thread about adding advice for handling uncommitted changes during branch switches. The patch series is part of a GSOC microproject by Arsh Srivastava to add `ADVICE_STASH_BEFORE_CHECKOUT` advice.

In this email, Arsh responds to Patrick Steinhardt's observation that while the advice infrastructure is set up in `advice.c`, there's no actual call site using it yet in the checkout workflow. The response is more conversational than technical - Arsh expresses appreciation for the review and shares some motivation about how advice helps new developers, but doesn't yet address the technical gap Patrick pointed out.

The thread shows good mentoring engagement, with Patrick providing direct technical feedback and Arsh showing enthusiasm for the project's goals. However, the key next step remains adding the actual integration point in `checkout.c` to trigger this advice when appropriate, which was noted as missing in both v2 and v3 of the series. Junio has also weighed in with design considerations about how strongly to recommend the `-m` option versus stashing.
