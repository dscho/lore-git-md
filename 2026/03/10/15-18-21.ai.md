Refactoring patch in the ODB abstraction effort. This is the first of six patches in Patrick Steinhardt's series to generalize object counting for pluggable object databases. 

The patch reorganizes header file dependencies between "odb.h" and "odb/source.h", moving enum and typedef definitions that belong to the generic ODB interface from the source-specific header into the main ODB header. This makes the include structure more logical since most callers shouldn't need to know about the internal `struct odb_source` implementation details. The change requires adding explicit includes of "odb/source.h" to several files that previously got it transitively through "odb.h".

The patch follows the established pattern of incremental refactoring in the ODB abstraction work, with clear mechanical changes and no functional impact. It was suggested by Justin Tobler and touches core object database infrastructure files including odb.h, odb/source.h, and several callers that need the adjusted includes. The changes are straightforward and unlikely to be controversial, being primarily about code organization rather than behavior.
