This is a refactoring patch that extracts and generalizes commit signing logic for reuse in the fast-import signing feature. The patch moves the `sign_commit_to_strbuf()` helper from commit.c to gpg-interface.c, renaming it to the more generic `sign_buffer_with_key()`. The new function maintains the same behavior - falling back to the configured default signing key when none is specified - but can now operate on any buffer rather than being commit-specific.

The change is part of a larger effort to enable `git fast-import` to re-sign commits with invalid signatures. By making the signing logic more reusable, this patch lays groundwork for that feature while keeping the codebase clean. The implementation looks straightforward - it preserves all existing behavior while making the functionality available to other parts of the codebase. The patch has already been reviewed and merged as part of the v2 series, with this being a follow-up cleanup.
