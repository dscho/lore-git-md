This is the first patch in an 8-part series introducing build system improvements. It creates a new `tools/` directory to house build-related scripts and tooling that currently live in various locations (like `contrib/`), arguing these should be considered core development infrastructure rather than optional components. The patch is purely organizational at this stage - it adds the directory skeleton (README and Meson build file) and excludes it from source file searches, but doesn't yet move any actual tools. 

As the series opener, this sets up the directory structure that subsequent patches will populate by relocating existing build tools. The motivation is sound - separating true "contrib" material from essential build infrastructure - and the implementation is straightforward, touching only build system files to register the new directory. The changes are mechanical and low-risk, though they'll need to be coordinated with the parallel Meson PCH work later in the series. 

Key technical points:
- Adds `tools/` directory with README explaining its purpose
- Updates Makefile and meson.build to recognize the new location
- Follow-up patches will move specific tools here from contrib/, Documentation/, and t/
- Part of broader effort to rationalize build infrastructure organization

The patch appears well-scoped and uncontroversial as a foundation for the rest of the series. Reviewers will likely want to check that the directory naming and placement makes sense before proceeding with the migrations in subsequent patches.
