This is a feature patch in Adrian Ratiu's ongoing hook configuration work, specifically addressing the `git hook list --show-scope` output format. The patch adds scope information (local/global/etc) to hook listings but currently combines the hook name and scope in a single NUL-terminated field when using `-z` mode.

Junio Hamano raises a design question about whether the machine-readable `-z` output should separate the hook name and scope into distinct fields for easier parsing, rather than combining them with parentheses in a single field. Adrian acknowledges this concern and plans to revise the format in v2 of the patch, inviting suggestions for the best approach.
