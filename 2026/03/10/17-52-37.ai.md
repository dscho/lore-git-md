Build system reorganization patch continuing the tools/ directory consolidation effort.

This is patch 4/8 in Patrick Steinhardt's series to reorganize Git's build infrastructure. The patch moves the Unicode data update script from contrib/ to the new tools/ directory, following the same pattern as previous moves in the series (Coccinelle scripts in 2/8, coverage-diff in 3/8). The change is purely organizational - the script's functionality remains identical, just its location changes.

The commit message explains the rationale: update-unicode.sh is core developer tooling (used to refresh Git's internal Unicode tables when new standards are released) and thus belongs in tools/ rather than contrib/. The patch carries no behavioral changes - it's a rename with all supporting files (.gitignore, README) moved alongside the main script.

This continues the series' clean separation between essential infrastructure (moving to tools/) and optional/experimental code (remaining in contrib/). The change is straightforward and unlikely to be controversial, though build system experts like D. Ben Knoble may want to confirm no build dependencies were missed. The patch follows the established pattern from earlier in the series, suggesting the directory structure approach is working as intended.
