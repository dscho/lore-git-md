This is a feature patch series (v3) adding a new advice message for users attempting to switch branches with uncommitted changes. The patch is part of a GSOC microproject and follows up on prior review feedback.

The series introduces `ADVICE_STASH_BEFORE_CHECKOUT` to warn users when their local modifications would be lost during a branch switch. The advice suggests using `git stash` to preserve changes and can be disabled via `advice.stashBeforeCheckout` config. The implementation follows Git's existing advice patterns, with documentation updates in `advice.adoc`.

Key changes in v3:
- The patch is now split into two commits (though the second appears to be a duplicate in the range-diff)
- Still missing the actual call site in checkout.c that would trigger this advice (noted by Patrick Steinhardt in previous reviews)
- Phillip Wood's prior feedback about recommending `git checkout -m` as the first suggestion hasn't been implemented yet (planned for future versions)

The patch remains well-scoped but still has the functional gap of not being wired into the checkout workflow. The author appears responsive to feedback and the thread shows productive collaboration with reviewers Phillip Wood and Patrick Steinhardt. This is a straightforward addition to Git's advice system that would help users avoid losing work during branch switches, though it needs the final integration piece to be complete.
