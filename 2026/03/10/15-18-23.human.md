This is the third patch in Patrick Steinhardt's six-part series abstracting object counting for pluggable object databases. It moves the loose object counting logic from `builtin/gc.c` to a new function in `object-file.c` as part of the ongoing ODB abstraction effort.

The patch extracts the heuristic that estimates loose object counts by sampling one shard directory (objects/17) and multiplying by 256. This estimation is used by `git gc` to determine when repacking is needed. The new `odb_source_loose_approximate_object_count()` function provides the same behavior but makes it available at the ODB source level, preparing for future introduction of pluggable backends.

The changes are mechanical and maintain existing behavior - the counting algorithm remains identical, just relocated to a more modular location. This continues the pattern seen in earlier patches of incrementally moving functionality to the ODB layer without yet introducing new backend capabilities. The patch touches core object database files but doesn't yet expose the new function beyond internal use.
