Build system improvement adding Meson precompiled header support. This is the final patch in Patrick Steinhardt's 8-part series that (1) consolidates build tooling into a new `tools/` directory and (2) adds precompiled header (PCH) support to the Meson build system for faster compilation.

The patch implements PCH for `git-compat-util.h`, which is included by nearly every compilation unit in Git. The header is large (23,000+ lines preprocessed) and currently recompiled for each source file. By precompiling it once and reusing the result, the patch demonstrates a 40% speedup in full builds (14.5s -> 10.3s mean time in benchmarks).

The implementation creates a new `tools/precompiled.h` that simply includes `git-compat-util.h`, then wires it into Meson's `c_pch` option for both the main library and the git executable. This follows the groundwork laid in earlier patches that prepared `git-compat-util.h` for PCH compatibility by moving warning suppressions outside include guards (patch 6/8) and isolating compatibility sources (patch 7/8).

The change is straightforward and well-motivated, with clear performance benefits. As the final piece of the series, it builds on the structural improvements from earlier patches while maintaining cross-platform compatibility. Reviewers will likely focus on verifying the PCH behavior works correctly across all supported compilers and platforms, particularly Windows where PCH implementations can vary.
