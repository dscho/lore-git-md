This is part of a GSOC microproject adding advice for handling uncommitted changes during branch switches. The patch updates the advice message to prioritize `git checkout -m` as the primary suggestion for carrying local changes to a new branch, addressing feedback from Phillip Wood.

The v3 iteration simplifies the advice text to focus on the `-m` option rather than the stash workflow, though reviewers had noted the patch still needs integration with the actual checkout workflow (Patrick Steinhardt's feedback from v2 remains unaddressed). The change maintains the existing advice infrastructure with configurable settings and follows Git's standard advice patterns.

While the patch shows progress in refining the messaging, it remains incomplete without the critical checkout.c integration point. The duplicate commit in the range-diff suggests some version control workflow issues that may need cleaning up in future iterations.
