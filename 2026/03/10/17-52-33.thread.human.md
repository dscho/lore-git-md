Patrick Steinhardt has proposed a series reorganizing Git's build infrastructure, starting with creating a new "tools/" directory to consolidate essential build tooling that was previously scattered, particularly in "contrib/". This first patch establishes the directory structure with a README and updates both Makefile and Meson build configurations to recognize it, setting the stage for subsequent patches to move tools like Coccinelle infrastructure and build generators.

The series also introduces Meson precompiled header (PCH) support, demonstrating 40% faster builds by precompiling git-compat-util.h. The implementation carefully documents design choices and maintains compatibility across platforms, though some questions remain about potential impacts on Junio's Coccinelle workflow and reftable boundary considerations raised by Phillip Wood. The changes have been refined through review, with Patrick addressing feedback in v2 by simplifying the PCH specification and adding documentation about GCC's behavior.

With the technical aspects largely addressed and no blocking objections, the series appears ready for merging pending final verification of PCH behavior across all platforms. The changes represent a thoughtful consolidation of build infrastructure that should improve both development workflow and build performance.
