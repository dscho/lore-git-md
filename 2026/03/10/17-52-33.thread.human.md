This thread covers Patrick Steinhardt's 8-part series restructuring Git's build infrastructure. The changes accomplish two main goals: consolidating scattered build tools into a new `tools/` directory, and adding precompiled header (PCH) support to the Meson build for faster compilation.

The series is now at version 1 with patch 7/8 just posted. So far, patches 1-6 have established the `tools/` directory and moved several build-related scripts there (Coccinelle infrastructure, coverage tools, Unicode updaters, and core build generators). They've also modified `git-compat-util.h` to prepare for PCH support. The latest patch (7/8) reorganizes the Meson build to split compatibility sources into their own static library, ensuring PCH can work with the main sources while maintaining correct behavior for platform-specific compatibility code.

The final patch (8/8) will introduce the actual PCH implementation, promising ~30% faster compilation. While only Patrick has commented so far, this infrastructure work will likely draw review from build system experts like D. Ben Knoble and platform specialists like Johannes Schindelen (Windows) and Ramsay Jones (portability). The changes appear carefully structured to maintain existing functionality while enabling future optimization.
