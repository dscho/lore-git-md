Patrick Steinhardt's build system improvement series is now complete with the addition of precompiled header (PCH) support in the Meson build. The 8-part series accomplishes two main goals: consolidating development tools into a new "tools/" directory and significantly speeding up builds through PCH optimization. 

The final patch demonstrates a 30-40% reduction in build times by precompiling git-compat-util.h, which is included in nearly every source file. This builds on the preparatory work in patch 7/8 that isolated platform-specific code to avoid PCH conflicts. The implementation is minimal (just 3 lines of configuration) but effective, using Meson's built-in PCH support to force-include the precompiled header.

 

All technical concerns raised during review have been addressed in this v3 of the series. Phillip Wood confirmed the Meson PCH behavior looks good, and the approach maintains compatibility with ongoing efforts like the reftable backend work. While Junio Hamano expressed some concern about potential workflow impacts for Coccinelle users (now relocated to tools/), there are no blocking objections. The series achieving its goals without introducing new issues, it appears ready for merging as a solid infrastructure enhancement that will benefit all developers working with the codebase.
