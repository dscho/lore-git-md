Performance optimization patch in Patrick Steinhardt's series reducing write syscalls in `git-upload-pack`. This is patch 8/10 in v3 of the series, introducing a new `hashfd_ext()` function in the csum-file subsystem that generalizes buffer management for hash file operations.

The patch replaces two existing functions (`hashfd()` and `hashfd_throughput()`) with a single configurable interface that takes an options structure. The new function allows specifying both progress reporting and buffer size, with sensible defaults (128KB for normal operation, 8KB when progress reporting is enabled). This change supports the series' broader goal of reducing write syscalls by making buffer sizing more flexible.

The implementation maintains all existing behavior while providing a foundation for future extensions. The patch is straightforward - it reorganizes existing code rather than introducing new logic - and fits cleanly into the larger performance optimization effort.
