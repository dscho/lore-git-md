Feature: new advice for handling dirty files during branch switches

This is version 2 of a patch from Arsh Srivastava (a GSOC participant) that adds a new advice message when users try to switch branches with uncommitted changes. The advice suggests using `git stash` to preserve modifications before switching.

The patch introduces:
- A new `ADVICE_STASH_BEFORE_CHECKOUT` enum in `advice.h`
- Implementation in `advice.c` that lists affected files and shows stash commands
- Documentation for the new `advice.stashBeforeCheckout` config option

This follows the same pattern as other advice messages in Git. Phillip Wood reviewed v1 and suggested making `git checkout -m` (merge option) the primary recommendation rather than stashing, which the author has acknowledged and plans to address in v3. The current version still shows stashing as the main solution, so we can expect another revision.

The implementation looks clean and matches Git's existing advice infrastructure. This is a straightforward quality-of-life improvement that could help new contributors understand how to handle a common workflow situation. The thread shows good mentor-mentee interaction, with Phillip Wood providing constructive feedback that's being incorporated.
