This is the fourth patch in an 8-part series refactoring repository-specific global variables into `struct repo_config_values`, continuing the project's effort to reduce global state and improve repository isolation. The patch moves the `pack_compression_level` configuration setting from a global variable to per-repository storage in `repo_config_values`.

The change updates all usage sites in `builtin/fast-import.c`, `builtin/pack-objects.c`, `environment.c`, and `object-file.c` to access the compression level through the repository-specific struct rather than the global variable. The patch follows the established pattern from previous patches in the series, maintaining the same behavior while eliminating cross-repository state leakage.

The compression level remains initialized to `Z_DEFAULT_COMPRESSION` by default, matching the previous global variable's behavior. The patch touches 5 files with 19 insertions and 10 deletions, updating both the configuration parsing logic and all direct calls to `git_deflate_init()` that previously used the global value.

This work builds on René Scharfe's ongoing `the_repository` elimination effort and aligns with the series' goal of making Git more suitable for library-style usage with multiple active repositories. The patch is mechanically similar to the first three patches in the series, applying the same transformation pattern to another widely-used configuration setting.
