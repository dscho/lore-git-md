This is the fifth patch in Patrick Steinhardt's six-part series on object counting for pluggable object databases (ODB). The patch introduces a generic object counting mechanism at the ODB source level, adding a new `count_objects` callback to the ODB source interface.

The change allows different ODB backends to implement their own counting logic while maintaining a consistent interface. The implementation handles both packed and loose objects, with the packed object counting already moved to packfile.c in earlier patches. The patch preserves the existing approximate counting behavior used by `git gc` while providing flexibility for future backends to implement exact counting.

The changes touch core ODB infrastructure files (odb/source-files.c, odb/source.h) and update the packfile interface to work with the new callback. This continues the series' pattern of behavior-preserving refactoring to support pluggable backends, with no user-visible changes. The patch builds cleanly on the previous work in the series and maintains the same careful attention to error handling and backward compatibility.
