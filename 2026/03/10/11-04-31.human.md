This is a feature patch adding advice for dirty branch switches, part of a GSOC microproject. It follows up on earlier feedback from Phillip Wood.

Arsh Srivastava's v2 patch adds `ADVICE_STASH_BEFORE_CHECKOUT` to help users when they attempt to switch branches with uncommitted changes. The advice lists affected files and suggests using `git stash` to preserve modifications. The implementation follows existing patterns in the advice subsystem, with configurable behavior via `advice.stashBeforeCheckout`.

The patch addresses two of Phillip Wood's prior review comments: it's now a single focused patch (having split out other changes) and recommends `git checkout -m` as the primary solution. The implementation is thorough, adding the enum, advice text, documentation, and following Git's established advice patterns.
