This is the second patch in Patrick Steinhardt's 8-part series reorganizing Git's build infrastructure. The patch moves the Coccinelle semantic patch files from `contrib/coccinelle/` to the new `tools/coccinelle/` directory.

The change reflects Coccinelle's status as a core development tool rather than optional contrib material. The patch updates all references to the old path across the codebase, including:
- Makefile rules for running Coccinelle checks
- CI script paths
- Meson build configuration
- Documentation references
- The spatchcache helper script

The actual semantic patch files (like `the_repository.cocci`, `strbuf.cocci`, etc.) remain unchanged - this is purely a relocation. The patch maintains all existing functionality while better organizing the codebase by moving essential build tools out of `contrib/`.

This is part of a larger effort to consolidate scattered build/development tooling into a dedicated `tools/` directory. The change is mechanical but thorough, updating all affected paths across multiple build systems (Makefile, CMake, Meson). As the second patch in the series, it builds on the initial `tools/` directory creation from patch 1/8.
