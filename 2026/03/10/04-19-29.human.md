This is a documentation and usability improvement patch from Pablo Sabater, addressing a suggestion from Junio C Hamano about cover letter formatting. The patch changes how `git format-patch --cover-letter` lists commits - replacing the current author-grouped shortlog format with a simple numbered list of patches.

The motivation is clear: when there's only one author (a common case), the current author grouping adds no value and makes it harder to reference patches by number in the cover letter discussion. The new format shows each patch with its position in the series (e.g., "[1/2]: commit subject") which is more directly useful.

The implementation removes the shortlog infrastructure from the cover letter generation and replaces it with a straightforward loop that prints each commit subject with its numbering. Tests are updated to expect the new format rather than the old author-grouped one. The documentation is also updated to reflect the change.

This appears to be a well-scoped, focused improvement that does what it says. The patch is cleanly implemented with appropriate test updates, though it does note that the multi-author case (where grouping might still be useful) isn't handled yet. The author suggests this could be added later while keeping the initial change simple.
