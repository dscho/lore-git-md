This is a security release announcement for Git for Windows, not a patch for the main Git project. Johannes Schindelin announces Git for Windows 2.53.0(2), which addresses a specific security vulnerability.

The release fixes CVE-2025-66413, a Windows-specific issue where Git could inadvertently expose users' NTLMv2 hashes during repository cloning from malicious servers. The fix disables NTLM authentication by default to prevent potential credential exposure through brute-force attacks on the weak NTLM hashes.

The announcement includes SHA-256 checksums for various distribution formats (installers, portable versions, and MinGit variants) across different architectures (64-bit, arm64, and 32-bit). This is a targeted security update rather than a feature release, with the sole purpose of addressing this authentication vulnerability in the Windows-specific fork of Git.
