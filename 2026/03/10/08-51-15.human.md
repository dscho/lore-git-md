This is a test patch that verifies correct diffstat width calculation when ANSI color codes are present in the line prefix. It's part of a 5-patch series, though this particular test stands alone as a bugfix for colored output handling.

The test specifically checks that `git log --graph --stat` properly accounts for ANSI escape codes when calculating terminal width for diffstat output. It creates a scenario with colored graph output (using `--graph`) and verifies that the diffstat lines are correctly aligned, even when the terminal width is just barely enough to show the full filename versus when it needs to truncate.

The test is thorough - it checks both the successful case (full filename displayed) and the edge case (filename truncated by one character) to ensure the width calculations work correctly. This addresses a real-world issue where colored graph output could cause misaligned diffstats.

Junio has already signed off on this patch, indicating it's ready for inclusion. While part of a larger series, this test is self-contained and focuses narrowly on the diffstat width calculation bugfix.
