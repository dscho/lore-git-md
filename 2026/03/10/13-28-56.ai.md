This is a feature patch adding new advice for branch switching with uncommitted changes, part of an ongoing GSOC microproject. It's the third iteration (v3) of a two-patch series, though the second patch appears to be a duplicate in the range-diff.

The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when attempting to switch branches with local modifications that would be overwritten. It follows the established advice pattern with:
- New enum in `advice.h`
- Config setting in `Documentation/config/advice.txt`
- Implementation in `advice.c` with `advise_on_checkout_dirty_files()`

The advice lists affected files and suggests using `git stash push/pop` or discarding changes with `git checkout -- <file>`. The implementation matches existing style seen in similar advice functions like `advise_on_updating_sparse_paths()`.

Two key gaps remain from prior reviews:
1. The advice isn't yet integrated into the checkout workflow (missing call site in checkout.c)
2. The message doesn't prioritize `git checkout -m` as the primary suggestion (Phillip Wood's feedback)

The patch maintains clean scope and follows project conventions, but needs these functional additions before being complete. The duplicate commit in v3 suggests some version control workflow issues that may need addressing in future iterations.
