This is the fifth patch in Patrick Steinhardt's six-part series on object counting for the ODB (object database) abstraction effort. The patch introduces a generic object counting mechanism at the ODB source level.

The key change is the addition of a new `count_objects` callback to the `odb_source` interface, allowing different ODB backends to implement their own counting logic. The patch implements this for the files-based backend by combining packed object counts (via `packfile_store_count_objects`) with loose object counts (via `odb_source_loose_count_objects` from the previous patch). The counting behavior can be controlled via `ODB_COUNT_OBJECTS_APPROXIMATE` flag.

The patch updates `repo_approximate_object_count()` to use this new interface rather than directly calling the packed object counter, completing the transition to the backend-agnostic approach. This maintains the existing behavior while providing the infrastructure needed for future pluggable backends to implement their own counting logic.

The changes touch core ODB infrastructure files (odb/source-files.c, odb/source.h) and update the packfile interface (packfile.c, packfile.h) to work with the new callback. This continues the series' pattern of moving object storage logic from command-specific implementations into core ODB infrastructure while preserving identical behavior.
