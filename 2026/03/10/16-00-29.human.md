Performance optimization for `git help`'s configuration listing. Siddharth Shrimali sends a revised version of his patch that moves a `strbuf` buffer declaration outside nested loops in `list_config_help()` to avoid repeated allocations. The change reuses a single buffer with `strbuf_reset()` instead, reducing heap pressure when displaying configuration help. 

The patch also incidentally fixes a memory leak in the `SHOW_CONFIG_HUMAN` case where a `continue` could skip cleanup. Patrick Steinhardt reviewed the initial version and suggested minor style improvements, which have been incorporated in v2 (tightening whitespace and ensuring declarations precede statements). The change is small (3 lines added, 6 removed) but touches performance-sensitive help system code paths. The review indicates the patch is technically sound and ready for inclusion.
