This is the 9/10 patch in Adrian Ratiu's series improving Git's hook configuration support, now rebased and ready for integration. The patch adds a `--show-scope` option to `git hook list` that displays where each hook is configured (local/global/etc), building on the infrastructure from previous patches.

The current implementation shows scope in parentheses after the hook name, but Junio Hamano questions whether this format works well with the `-z` option for machine parsing. Adrian acknowledges this concern and plans to revise the output format in v2 to make the fields more easily separable, while keeping the functionality intact. The patch otherwise looks solid - it's a natural extension of the series' work to make hook configuration more transparent and maintainable.
