This thread covers two related but distinct Git improvements. The first, already merged in Git 2.54.0, fixed how diffstat calculates widths when ANSI color codes are present, with changes to utf8 handling and test coverage. The second is an ongoing Google Summer of Code project by Arsh Srivastava to add advice when users try switching branches with uncommitted changes.

The branch-switching advice feature has progressed through two versions, with v2 incorporating most of Phillip Wood's review feedback. It now cleanly implements `ADVICE_STASH_BEFORE_CHECKOUT` with proper configuration support and documentation. When triggered, it shows which files would be affected and suggests stashing changes. The implementation follows Git's established advice patterns.

One remaining suggestion - to recommend `git checkout -m` (which merges changes) as the primary solution rather than stashing - has been acknowledged but deferred to v3. The collaboration between Arsh and Phillip has been productive, with clear technical direction and incremental improvements. The changes are well-scoped and follow Git's conventions, putting this feature on track for eventual merging once the final review feedback is addressed.
