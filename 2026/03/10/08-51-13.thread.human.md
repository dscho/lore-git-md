The current implementation (v4) integrates the advice into the existing `unpack-trees.c` warning system rather than creating duplicate functionality, following Junio's guidance. It provides clear warnings about the risks of using `git checkout -m` while still presenting it as an option, along with stashing or discarding changes.

Key reviewers including Junio, Patrick Steinhardt, Phillip Wood and Karthik Nayak have provided feedback that shaped the implementation, particularly around message clarity and safety considerations.
