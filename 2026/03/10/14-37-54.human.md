This is a patch series continuation of Adrian Ratiu's work on Git's hook configuration system, now rebased and ready for integration. The series builds on Adrian's prior work to make hooks configurable via Git's configuration system, adding cleanups, small features, and infrastructure improvements.

The 10-patch series includes refactoring and cleanup patches, new features for `git hook list` (showing configuration scope and disabled hooks), defensive programming checks, API simplifications, documentation standardization, and test coverage of hook execution ordering. It also prepares infrastructure for future metadata storage. The series has been rebased by Junio Hamano directly on master plus the relevant config-hooks topic, resolving a previous issue with basing on 'next'.

Key technical changes include replacing a custom wrapper struct with a bare `strmap` (following discussion feedback), adding a `--show-scope` option to display configuration scope with hook names, and cleaning up internal API by using standard string list functions. Junio has provided positive reviews while noting one remaining design question about the output format for machine parsing with `-z`.

The series appears well-polished, with Adrian actively incorporating feedback from Junio, Patrick Steinhardt, and Eric Sunshine. It continues Adrian's ongoing effort to modernize and expand Git's hook configuration capabilities, following naturally from his previous work in this area. The patches look ready for integration pending resolution of the minor remaining output format question.
