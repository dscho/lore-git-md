This is part 2 of Patrick Steinhardt's 6-patch series to generalize object counting for pluggable object databases (ODB), continuing the broader ODB abstraction effort. The patch extracts the logic for counting objects in packfiles into a new `packfile_store_count_objects()` function, preparing for future patches that will make this counting logic pluggable across different ODB backends.

The change moves the counting implementation from `repo_approximate_object_count()` into a reusable helper that handles both regular packs and multi-pack-indexes. This is a mechanical refactoring that doesn't change behavior - it just reorganizes the code to make the next steps in the series cleaner. The patch touches core packfile handling code but maintains backward compatibility, following the incremental approach typical of this long-running abstraction work.

As with most of Steinhardt's ODB abstraction patches, this is well-scoped infrastructure work with a clear commit message explaining the motivation. The change is part of making Git's object storage more flexible for future backends while keeping existing functionality intact. Reviewers familiar with the ODB effort will recognize this as another step in the established pattern of extracting and generalizing core functionality.
