[PATCH] format-patch: simplify cover letter patch listing

Thread identity: Patch series from Pablo Sabater (GSoC participant) implementing a Junio C Hamano suggestion to modify `git format-patch` cover letter generation.

Core problem: Current cover letters group commits by author in shortlog format, which is less useful for single-author series and makes patch references harder to follow. The change replaces this with a simple numbered list format (`[1/2]: subject`) for all series regardless of author count.

Implementation: Removes shortlog generation from `builtin/log.c`, replacing it with direct commit message extraction. Touches `builtin/log.c`, `t/t4014-format-patch.sh`, and documentation. Drops author grouping entirely (though commit suggests this could be re-added later for multi-author cases).

Status: Initial version (v1) of patch. No reviews or discussion yet. Ready for review with updated tests and docs.

Technical details: Changes output format but keeps all other cover letter functionality. Tests verify new numbering format. Documentation updated to reflect new behavior.

Open questions: Whether to preserve author grouping for multi-author series (mentioned as possible future work in commit message).

Participant positions: Patch originates from Junio's suggestion, implemented by Pablo. No other contributors involved yet.
