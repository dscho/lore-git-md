This is a security announcement from Johannes Scharfe regarding Git for Windows 2.53.0(2), a Windows-specific release addressing CVE-2025-66413. The vulnerability could expose NTLMv2 hashes during clone operations when interacting with malicious servers. The fix disables NTLM authentication by default in the Windows port to prevent credential exposure through this weak authentication method. 

The release includes updated installers and portable versions for all supported Windows platforms (32-bit, 64-bit and ARM64), with SHA-256 checksums provided for verification. While this announcement appears on the main Git mailing list for visibility, the actual development and fixes are specific to the Git for Windows fork maintained separately from the core Git project. Windows users performing network operations should update to this release to mitigate the security risk.
