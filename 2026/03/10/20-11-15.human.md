This is a refactoring patch that's part of the `git fast-import` re-signing feature series. It moves signing logic from commit-specific code to a more general location in the GPG interface.

Justin Tobler extracts the `sign_commit_to_strbuf()` helper from commit.c and renames it to the more generic `sign_buffer_with_key()` in gpg-interface.c. The new function maintains the same behavior - it signs an arbitrary buffer using either a specified key or the default configured key - but is now available for use by other parts of Git that need signing functionality.

The change is straightforward and mechanical, with no behavior modifications. The patch updates commit.c callers to use the new interface and adds appropriate documentation in gpg-interface.h. This refactoring enables the subsequent patch in the series to reuse this signing logic in `git fast-import` when re-signing invalid commit signatures.

The patch follows Git's standard approach for moving shared functionality to common locations. It's a clean, focused change that builds on the preparatory work in earlier patches of this series. The implementation looks solid and the commit message clearly explains the motivation and changes.
