This is a refactoring patch as part of the ongoing `the_repository` removal effort, specifically targeting the editor subsystem. The patch moves the `editor_program` global variable from environment.c to editor.c where it's actually used, introducing a new `set_editor_program()` helper function to handle configuration.

The change is mechanical but well-justified - the variable was only used in editor.c despite being declared globally. The patch maintains existing behavior while reducing global state, following the project's direction. Karthik Nayak has already approved this approach in previous discussion, though broader architectural questions about editor configuration (process-wide vs per-repo) remain open.

Key technical details:
- Removes `editor_program` from environment.[ch]
- Adds new `set_editor_program()` helper in editor.[ch]
- Keeps early config parsing behavior (invalid values still caught at startup)
- Part of a 2-patch series (this being the first mechanical step)
- Follows incremental refactoring pattern seen in other `the_repository` removals

The patch appears clean and focused, with no behavior changes beyond the intended scope. It represents progress on the technical implementation while leaving higher-level design questions (like Tian's repo-settings.c proposal) for future discussion. The v2 revision additionally removed an unnecessary environment.h dependency from editor.c as cleanup.
