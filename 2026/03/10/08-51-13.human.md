This is a feature patch introducing new user guidance for handling dirty working trees during branch switches. The patch adds a configurable advice message (ADVICE_STASH_BEFORE_CHECKOUT) that appears when attempting to checkout a different branch with uncommitted changes that would be overwritten.

The core change implements advice similar to existing patterns (like sparse checkout advice) - it lists affected files and suggests using `git stash` to preserve changes. The advice can be disabled via `advice.stashBeforeCheckout` config. The patch includes documentation updates and appears to be part of a GSOC microproject.
