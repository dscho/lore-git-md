Documentation patch for the cover letter formatting feature, addressing final review feedback. This is the fifth and final patch in a series that implements configurable cover letter formatting for `git format-patch`.

Phillip Wood points out that the documentation additions should be moved to earlier patches in the corresponding features are introduced - the config option documentation to patch 4 (which implements `format.commitListFormat`) and the command-line option documentation to patch 3 (which adds `--cover-letter-format`). The current patch 5 contains both, but they should logically live with their implementations.

The documentation itself is complete and has already been approved by Junio C Hamano with minor wording improvements incorporated. It describes:
- The `format.commitListFormat` config variable that defaults to "shortlog"
- The `--cover-letter-format` option that accepts either "shortlog" or a `log:`-prefixed format string
- How the options interact (command-line overrides config)
- Example format strings showing the new `%s` and `%an` placeholders

This represents final polish for the series, which has gone through seven iterations and is otherwise ready for merging. The author (Mirko Faina) has confirmed this is the final version, with all substantive feedback addressed. Phillip's suggestion here is purely about organizational best practices - keeping documentation with the code it documents - rather than indicating any missing functionality.
