This is a refactoring patch series that continues the effort to migrate repository-specific global variables into `struct repo_config_values`. The series builds on previous work that introduced this infrastructure for storing repository-dependent configuration.

The 8 patches move various environment-related globals into `repo_config_values`:
- Trusting ctime for racy checks (`trust_ctime`)
- Filesystem stat checking behavior (`check_stat`)
- Compression levels for zlib and packfiles
- Unicode handling (`precomposed_unicode`)
- Sparse checkout configuration flags
- Object refname ambiguity warnings

The changes touch a wide range of files (20 modified) as these globals are used throughout the codebase. Each patch follows a similar pattern of moving a global into the struct and updating all call sites to access it through the repository instance instead.

This continues the project's broader effort to reduce global state and improve repository isolation, particularly important for library-style usage where multiple repositories may be active in the same process. The changes are mechanical in nature - moving storage locations while maintaining the same behavior.

The series appears well-structured with each patch focusing on a specific set of related variables. The commit messages could benefit from more detailed explanations of why each particular setting belongs in repo-specific storage, but the overall direction aligns with established project goals around the_repository elimination and better encapsulation.
