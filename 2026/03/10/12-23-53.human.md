This is a bugfix patch in a series addressing memory leaks in Git's mmap handling during clone operations. The patch corrects a specific leak in the streaming object reading code where an error path was incorrectly trying to clean up an uninitialized struct field rather than the local mmap variable. The issue was introduced by a 2025 restructuring of the streaming backend by Patrick Steinhardt.

The fix is straightforward - it changes the local variable name in the cleanup code to match where the mmap result is actually stored before being assigned to the struct. Patrick has acknowledged the fix and thanked Jeff King for catching this oversight. The series as a whole has been through thorough review and appears ready for merging, with this being the final piece addressing all known mmap-related leaks in the clone operation path.
