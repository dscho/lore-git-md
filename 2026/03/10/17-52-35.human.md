Build system reorganization: Moving Coccinelle rules to new tools directory.

This is the second patch in Patrick Steinhardt's 8-part series to reorganize Git's build infrastructure. The series introduces a new `tools/` directory for core development tools and adds Meson precompiled header support. This specific patch moves the Coccinelle semantic patch rules from `contrib/coccinelle/` to the new `tools/coccinelle/` location.

The change is straightforward - it updates all references to the old path in Makefiles, CI scripts, and documentation while preserving all the Coccinelle rules themselves. The justification is that Coccinelle is an integral part of Git's build infrastructure (used in CI for static analysis patterns) rather than optional "contrib" material.

The patch appears mechanically sound with comprehensive path updates across all build systems (Makefile, CMake, Meson). It follows logically from the first patch which established the `tools/` directory structure. As part of a larger infrastructure cleanup effort, this change helps properly categorize core versus optional components of Git's build tooling.
