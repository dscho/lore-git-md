This is the fourth patch in Patrick Steinhardt's six-part series on generalizing object counting for pluggable object databases (ODB). The patch builds on the previous work that moved loose object counting logic from `object-file.c` to `builtin/gc.c`.

The key change here generalizes the counting functionality by introducing a new `odb_source_loose_count_objects()` function that can provide either an approximate count (using the existing shard-based heuristic) or an exact count (by iterating through all objects). The behavior is controlled via a new `ODB_COUNT_OBJECTS_APPROXIMATE` flag. The patch updates `builtin/gc.c` to use this new interface while maintaining the same approximate counting behavior for the garbage collection logic.

This continues the ODB abstraction pattern of moving object storage logic into core infrastructure while preserving existing behavior. The changes are well-contained, touching only the object counting functionality without introducing any user-visible changes. The patch maintains the series' focus on internal implementation flexibility for future ODB backends.
