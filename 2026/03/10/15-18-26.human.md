This is the final patch in Patrick Steinhardt's six-part series on generalizing object counting as part of the ODB (object database) abstraction effort. The patch introduces new `odb_count_objects()` and `odb_source_count_objects()` APIs to provide a backend-agnostic way to count repository objects, replacing the existing `repo_approximate_object_count()` function.

The changes move the counting logic into the ODB infrastructure while maintaining the existing caching behavior (though Patrick notes the cache may not be strictly necessary). The patch updates several callers in `builtin/gc.c`, `commit-graph.c`, and `object-name.c` to use the new interface. The implementation combines packed and loose object counts from the files backend, preserving the same approximation heuristics as before.

This completes the series' goal of making object counting work uniformly across different ODB backends, a key step toward enabling pluggable storage backends. The changes are focused on internal implementation with no user-visible behavior changes. The series has seen review input from Justin Tobler and appears ready for consideration.
