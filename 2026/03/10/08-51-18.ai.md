This is the final patch in a series introducing a new advice feature for branch switching with uncommitted changes. The patch adds `ADVICE_STASH_BEFORE_CHECKOUT` to warn users when they attempt to switch branches with local modifications that would be overwritten.

The implementation follows Git's standard advice pattern, adding:
- A new enum in `advice.h`
- Configuration documentation in `advice.adoc`
- An implementation in `advice.c` that lists affected files and suggests using `git stash push/pop` to preserve changes

The advice is enabled by default and can be disabled via `advice.stashBeforeCheckout`. The message format matches existing advice like `advise_on_moving_dirty_paths()`, showing the problematic files and providing clear next steps. The patch appears well-structured and focused, though it hasn't received review feedback yet in the thread.

This completes the series' second feature (the first being the diffstat width calculation fixes already merged for Git 2.54.0). The change is self-contained in the advice subsystem and could be useful for users who accidentally lose work during branch switches. The implementation looks straightforward but would benefit from test coverage showing the advice triggers in appropriate checkout cases.
