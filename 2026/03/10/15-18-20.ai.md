This is a patch series introducing generic object counting for pluggable object databases, part of the ongoing ODB abstraction effort led by Patrick Steinhardt. The series builds on recent work to make the ODB backend more flexible.

The patches restructure how Git counts objects in repositories, moving the logic from packfile-specific implementations to a more generic interface that can work with any ODB backend. Key changes include:

1. Extracting object counting logic from packfile.c into reusable functions
2. Generalizing the counting mechanism to work with any ODB source
3. Introducing new odb_count_objects() and odb_source_count_objects() APIs
4. Updating callers like git-gc and commit-graph to use the new interfaces

The series touches core object database code across multiple files, with most changes concentrated in object-file.c, odb.c, and packfile.c. It introduces new public interfaces in odb.h while deprecating some packfile-specific counting functions.

This appears to be a well-structured series that continues Patrick's ongoing work to abstract Git's object storage layer. The changes are focused and mechanical, following the established pattern of previous ODB abstraction patches. The commit messages clearly explain each step of the refactoring.
