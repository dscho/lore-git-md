This is part 2/6 in Patrick Steinhardt's series to generalize object counting for pluggable object databases, continuing the ODB abstraction effort. The patch extracts the logic for counting packed objects from `repo_approximate_object_count()` into a new `packfile_store_count_objects()` function in preparation for making this behavior pluggable via a new `odb_source_count_objects()` API in subsequent patches.

The changes are mechanical and focused on code organization - the counting logic itself remains unchanged, just moved to a reusable function. The patch touches core packfile handling in `packfile.c` and adds the new function declaration to `packfile.h`. This follows the established pattern in the ODB abstraction work of incrementally extracting functionality into more modular components while maintaining backward compatibility.

The implementation handles both regular packfiles and multi-pack-indexes, with careful attention to error cases (like failed pack index opens). The changes are well-contained and clearly motivated by the larger goal of making object counting backend-agnostic. This appears to be a straightforward refactoring step in the ongoing series.
