This is a release notes update from Junio C Hamano documenting changes queued for Git 2.54.0. It's the 4th patch in a 5-part series (though the other patches aren't shown here).

The update adds several notable changes to the upcoming release notes:
- A new behavior where `git add <submodule>` respects `submodule.<name>.ignore=all` (requiring `-f` to override)
- Internal refactoring moving hook script execution to use the proper hook API instead of direct `run_command()` calls
- A fix for `git log --graph --stat` correctly calculating display width with colored graph output
- Various other minor fixes and cleanups being backported to maintenance branches

The changes appear routine - documenting features, fixes, and internal improvements that have already been reviewed and merged into the integration branches. As a release notes update from the maintainer, this is essentially administrative patch recording what will ship in the next version.
