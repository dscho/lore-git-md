Refactoring patch for submodule helper memory allocation. Siddharth Shrimali updates the submodule_summary_callback() function in builtin/submodule--helper.c to use Git's xmalloc() wrapper instead of raw malloc(), improving error handling consistency. The change also modernizes the allocation syntax by using sizeof(*temp) rather than explicitly naming the struct type, and removes the redundant type cast since void pointers auto-convert in C.

This is version 2 of the patch, incorporating Junio C Hamano's request to expand the commit message explaining the benefits of removing the type cast. The change is small (a single line) and focused, touching only the submodule helper code. Patrick Steinhardt has already acked the technical correctness of both the error handling improvement and style updates. The patch appears ready to merge pending final maintainer approval, with no outstanding technical concerns - a straightforward modernization aligning with Git's standard practices for memory management.
