Performance optimization in the sideband subsystem, part of Patrick Steinhardt's ongoing series to reduce write syscall contention in `git-upload-pack`. This patch converts the sideband packet writing from two separate `write()` calls (one for header, one for data) to a single `writev()` call using the new `writev_or_die()` wrapper introduced earlier in the series.

The change demonstrates a 50% reduction in syscalls (from ~133k to ~67k) when sending pktlines through the sideband channel. The implementation carefully maintains the existing packet framing logic while using the vectorized I/O approach. The patch builds on infrastructure from previous patches in the series, particularly the platform-portable `writev()` wrappers and error handling.

This is a focused optimization that shows measurable improvement while fitting into the series' broader goal of reducing kernel contention during high-concurrency operations. The change is relatively straightforward, swapping the direct writes for the new vectorized`writev_or_die()` call while preserving all the existing packet formatting and sideband logic.
