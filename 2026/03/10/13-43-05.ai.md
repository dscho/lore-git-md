This is a feature patch adding advice for handling uncommitted changes during branch switches, part of an ongoing GSOC microproject.

The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to guide users when switching branches with local modifications. It follows the established advice pattern with:
- New enum in `advice.h`
- Config setting `advice.stashBeforeCheckout`
- Implementation in `advice.c` showing affected files and suggesting `git stash push/pop`
- Documentation in `advice.adoc`

The advice message lists conflicting files and presents three options: stashing changes, discarding them, or using `git checkout -m` (though the latter option's safety is currently under discussion with Junio). The implementation is clean and matches existing advice patterns like `advise_on_updating_sparse_paths()`.

Key unresolved issues from prior reviews remain:
1. The advice isn't yet triggered from checkout.c (Patrick Steinhardt's feedback)
2. Junio C Hamano has raised concerns about unconditionally recommending `-m` due to its irreversible nature, suggesting either stronger caveats or presenting stash as the primary option

The patch appears well-structured but still needs integration with the checkout workflow and resolution of the safety discussion around `-m` recommendations. The author is actively engaging with feedback but hasn't yet addressed these core requirements for merging.
