The patch has gone through thorough review, with Karthik Nayak, Patrick Steinhardt, Kristoffer Haugsbakk, and Junio Hamano all providing feedback that has been incorporated. Version 2 improves terminology (using "linked worktree" consistently), modernizes the test syntax to use `git -C` instead of subshells, and cleans up the commit message. While there's a minor open discussion about commit reference formatting preferences, the technical fix itself appears complete and well-tested.

Junio has noted a broader architectural concern about making `setup_git_directory()` idempotent, but this remains a separate consideration from the immediate bugfix. The patch builds on several prior changes to the merge-file command and worktree handling, and appears ready for merging.
