This is the fourth patch in Patrick Steinhardt's six-part series on generalizing object counting for pluggable object databases (ODB). The patch builds on the previous work that moved loose object counting logic from `object-file.c` to `builtin/gc.c`.

The key change here generalizes the counting functionality by introducing a new `odb_source_loose_count_objects()` function that can provide either an approximate count (using the existing shard-based estimation) or an exact count (by iterating through all objects). The behavior is controlled via a new `ODB_COUNT_OBJECTS_APPROXIMATE` flag in `odb.h`. The patch updates `builtin/gc.c` to use this new interface while maintaining the same approximate counting behavior for the garbage collection threshold check.

The implementation splits the counting logic into two paths: the existing shard-based approximation (now behind the flag) and a new exact count that uses the `odb_source_loose_for_each_object()` callback infrastructure. This continues the ODB abstraction pattern of making functionality more flexible while preserving existing behavior - the only caller in `gc.c` continues to use the approximate mode exactly as before.

The changes touch core object storage infrastructure (`object-file.c`, `odb.h`) and maintain backward compatibility that has been characteristic of this series. No new test coverage is added since this is an internal refactoring that doesn't change observable behavior. The patch follows the established approach of incremental, behavior-preserving changes to support future ODB backends.
