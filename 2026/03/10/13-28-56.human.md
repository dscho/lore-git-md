Feature patch adding advice for dirty branch switches, part of an ongoing GSOC microproject.

This is the first of two patches in v3 of a series adding advice when users attempt to switch branches with uncommitted changes. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` with corresponding documentation and implementation following Git's existing advice patterns. The advice lists affected files and suggests using `git stash` to preserve changes.

The implementation looks clean and well-structured, matching similar advice implementations like `advise_on_updating_sparse_paths()`. However, as noted in the thread context, this version still lacks the critical checkout.c integration point that would actually show the advice to users. Reviewers Phillip Wood and Patrick Steinhardt have provided consistent feedback across versions about prioritizing the `-m` merge option in the advice text and ensuring the call site exists.

This represents incremental progress in a well-mentored GSOC project, with clear remaining work needed before the feature is complete. The patch itself is technically sound but not yet functional without the missing integration.
