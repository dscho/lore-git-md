This is a feature patch adding advice for dirty branch switches, part of an ongoing GSOC microproject. The patch introduces `ADVICE_STASH_BEFORE_CHECKOUT` to help users when attempting to switch branches with local modifications.

The v2 patch from Arsh Srivastava follows Phillip Wood's review feedback by:
1. Splitting unrelated commits into a separate series (done)
2. Focusing solely on the advice implementation
3. Adding documentation and config support

The implementation:
- Adds new enum in `advice.h`
- Implements `advise_on_checkout_dirty_files()` showing affected files
- Suggests `git stash push/pop` workflow
- Documents the config option in `advice.adoc`

One outstanding review suggestion not yet addressed is making `git checkout -m` the primary recommendation instead of stash, which the author acknowledges will come in v3. The current implementation follows Git's existing advice patterns and appears technically sound, with clean separation of concerns. This continues productive collaboration between the GSOC participant and reviewer.
