This is a feature patch proposing a change to `git format-patch`'s cover letter generation. The patch comes from Pablo Sabater as part of Google Summer of Code (GSoC) and implements a suggestion from Junio C Hamano.

The change modifies how cover letters list included patches. Currently, `format-patch` groups commits by author in the cover letter's shortlog format, which Pablo argues is less useful for single-author patch series and makes patch references harder to follow. The patch replaces this with a simple numbered list format like `[1/2]: commit subject` for all patch series, regardless of author count.

The implementation removes the shortlog generation code from `builtin/log.c` and replaces it with direct commit message extraction. Documentation and tests are updated to match the new behavior. While the patch drops author grouping entirely (even for multi-author series), the commit message suggests this could be added back later if desired.

This appears to be a well-scoped change addressing a specific usability pain point. The implementation is straightforward and maintains all existing functionality except the author grouping. The patch includes test updates and documentation changes, suggesting it's ready for review. Since it originates from a maintainer suggestion and doesn't introduce complex new behavior, it seems likely to be uncontroversial.
