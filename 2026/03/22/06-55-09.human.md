This is a feature request and discussion starter about adding a `STRBUF_INIT_CONST` macro to Git's string buffer API. The proposal comes from a new contributor, Mateo Patino, who is considering this as a potential Google Summer of Code (GSoC) project.

The macro would initialize a `strbuf` with a constant string literal while avoiding heap allocation (by setting `alloc` to 0). This idea has surfaced multiple times over the past seven years through various attempts (referenced in the email) but was never merged, despite some interest from core contributors like Patrick Steinhardt.

The email doesn't propose a specific implementation but rather seeks community feedback on whether this feature would still be valuable. The historical context suggests this is a non-trivial change that has generated discussion before, making it a reasonable candidate for a GSoC project where a student could research prior attempts, address concerns, and propose a robust solution.

As a discussion starter, this email is well-researched - it cites multiple previous attempts and acknowledges the complexity. The feature itself seems modest but touches core string handling code, so any implementation would need careful review. The GSoC angle makes this particularly timely, as the project could benefit from focused student work on this longstanding idea.
