Maintainer feedback on backfill argument validation patch.

Junio C Hamano responds to Siddharth Shrimali's v2 patch that aimed to make `git backfill` reject unexpected arguments consistently with other Git commands. While the patch implemented the requested error message and test coverage, Junio points out it doesn't actually match `git bugreport`'s behavior as claimed - bugreport shows a short usage message for unknown arguments rather than the full options list.

Junio also flags the use of "cute quotes" (`...`) in the error message as undesirable, noting this style appears in only 16 existing cases versus over 2000 using straight quotes. He suggests cleaning up existing instances could be a future intern project.

The test coverage is deemed insufficient since it wouldn't catch whether the command shows just the error versus also dumping the full options list. Junio implies the patch needs revision to either:
1. Truly match bugreport's minimal output for unknown arguments, or
2. Justify why backfill should differ in showing full usage details

This maintains Junio's characteristically precise review style, catching subtle behavioral differences while also enforcing project-wide consistency in both code and messaging patterns. The thread remains active with clear direction for the next revision.
