This is the fourth and new test patch in Lorenzo Pegorari's v2 series about promisor file handling during repacks, part of his GSoC work under Eric Sunshine's mentorship. The patch adds test coverage to verify that when repacking promisor packfiles, the debug information from all `.promisor` files is properly consolidated into the first file.

The test creates a partial clone (using `--filter=blob:none`), copies the original promisor file contents, performs a repack, then verifies the post-repack promisor file contains the same debug information as before. This directly tests the behavior implemented in patches 2-3 of the series, where the new `copy_all_promisor_files()` helper ensures debug info preservation.

The test follows Git's standard test patterns and appears well-constructed - it sets up a minimal scenario, performs the operation under test, and verifies the expected outcome. This is exactly the kind of test coverage that was missing in v1, and its addition strengthens the series by providing concrete way to verify the promisor file handling behavior works as intended. The test should help catch any regressions in this area going forward.
