RFC proposal from Mateo Patino (new contributor) for `STRBUF_INIT_CONST` macro to initialize strbuf` with constant strings without heap allocation. This is a GSoC candidate project with prior history: three previous attempts (2019, 2020, 2021) discussed but not merged, most recently noted by Patrick Steinhardt as #leftoverbit in 2025. Technical motivation is optimization for constant strings that won't be modified, but lacks concrete performance data or use cases. Currently gauging maintainer interest given stalled history. Key open: whether this optimization is still worth pursuing or considered a dead end based on past feedback.
