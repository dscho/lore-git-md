This thread addresses a straightforward bugfix for `git branch` where the incompatible combination of `--show-current` (which simply shows the current branch name) and `-v` (which shows verbose ref information) was silently accepted despite producing nonsensical output. The patch, originally from K Jayatheerth, explicitly rejects this combination with an error message.

Junio C Hamano had already acked an earlier version of the patch, indicating the change is conceptually sound. Phillip Wood has now provided some final polishing suggestions: using a standard helper function for the error message, making the test more thorough by checking the exact error text, and cleaning up the Acked-by tag that no longer applies to this iteration. These are minor but worthwhile improvements to bring the patch fully in line with Git's conventions.

The change remains small and focused - just a few lines in `builtin/branch.c` plus a test update. With Phillip's suggested tweaks incorporated, this should be ready for merging as a clean fix for an obvious inconsistency in the command's flag handling.
