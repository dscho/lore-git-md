This thread addresses a straightforward bugfix for `git branch` to prevent an incompatible flag combination. The original patch identified that using `--show-current` with `-v` (verbose) produces nonsensical output, since `--show-current` simply prints the current branch name while `-v` shows additional commit information. 

The fix adds an explicit error check in `builtin/branch.c` to reject this combination with a clear message, along with a test case to verify the behavior. Junio C Hamano has already acked an earlier version of the patch. The author has since improved the commit message to better describe the change (from "remove unnecessary verbose flag" to "reject --show-current with -v"), making the intent clearer. 

With Junio's approval and the patch's limited scope - it simply prevents a meaningless flag combination without altering core behavior - this appears ready for merging. The test coverage ensures the new error case is properly handled.
