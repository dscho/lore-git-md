This is the second patch in a 4-part series improving promisor packfile handling during repacks, part of Lorenzo Pegorari's GSoC project under Eric Sunshine's mentorship. The patch introduces a helper function `copy_all_promisor_files()` that efficiently consolidates the contents of multiple `.promisor` files into one during repacking.

The function uses a strset` (string set) to track seen lines, avoiding O(n²) duplicate checking from the v1 approach. It reads each source `.promisor` file line by line, only writing new unique lines to the destination file. The implementation handles file I/O carefully with proper error checking and memory management.

This is a technical improvement over v1, addressing Eric Sunshine's feedback by using Git's strmap utilities for O(1) duplicate detection rather than the previous linear scan approach. The patch touches `pack-write.c` and `pack.h`, adding the new helper while maintaining the existing promisor file behavior where these files store ref/hash pairs for debugging partial clone issues.

The implementation looks solid, with proper resource cleanup and error handling. This helper will be used in patch 3/4 of the series to properly preserve promisor file contents during repacks. The change is well-contained and demonstrates good responsiveness to prior review feedback.
