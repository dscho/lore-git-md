Junio C Hamano's March 2026 "What's cooking" report provides a comprehensive status update on Git development. The report follows the standard format, tracking topics through integration branches (maint, master, next, seen). Key ongoing work includes Jeff King's diff-highlight improvements (color config and identical line pair handling, with one part already in 'next'), Patrick Steinhardt's architectural refactoring (14 commits removing `the_repository` from `git fsck` and 15 commits making object name handling backend-generic), and Taylor Blau's pack-objects improvements for excluded-but-open packs with --stdin-packs. Multiple contributors are reducing `the_repository` usage across subsystems (worktree, split-index, add-patch). Documentation and test modernization continues with path helper adoption. Completed topics ready for merging include macOS Homebrew clang fixes, `git name-rev` formatting improvements, parallel hook execution support, HTTP 429 rate limit handling, and MIDX compaction. Johannes Schindelin's original sideband sanitization work has been discarded in favor of Junio's rebased version. The report notes that 'next' contains stable candidates for the next release while 'seen' remains experimental, and invites feedback on several in-review topics.
