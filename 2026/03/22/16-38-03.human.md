Bugfix follow-up for `git backfill` argument validation.

Phillip Wood provides a small but useful review comment on Siddharth Shrimali's v3 patch that fixes `git backfill`'s handling of unexpected arguments. The patch itself is already addressed Junio's feedback and appears ready for merging, but Phillip notes a test improvement opportunity.

The suggestion is to replace the direct `grep` and `! grep` calls in the test with `test_grep`, which provides better diagnostics when tests fail. This is a common pattern in Git's test suite modernization effort - using the test helper functions makes failures easier to debug. Phillip specifically notes the syntax change needed (`! grep` becomes `test_grep !`) to maintain the diagnostic behavior.

This is a minor polish on an otherwise complete patch. The core functionality (properly rejecting unexpected arguments with an error message) remains unchanged. The thread shows the typical Git review process where even small patches receive multiple rounds of careful scrutiny from different contributors, with each iteration improving both functionality and maintainability.
