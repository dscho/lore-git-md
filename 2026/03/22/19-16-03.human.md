This is a v2 patch series from Lorenzo Pegorari addressing promisor file handling during repacks, part of their Google Summer of Code (GSoC) work. The series builds on previous feedback from Eric Sunshine to improve how Git preserves the mapping between refs and their packfiles in `.promisor` files when repacking.

The key changes in v2 respond directly to Eric's review: replacing an O(n²) duplicate checking approach with a more efficient strset-based solution, fixing memory leaks in strbuf handling, and maintaining better style compliance. The series now also includes a new test in t7700 to verify the promisor file content preservation behavior.

The patches touch several areas: adding documentation about promisor file contents, introducing a helper function to consolidate promisor file data during repacks, and modifying the repack logic to use this helper. The work addresses a longstanding `NEEDSWORK` comment from commit 5374a290 about properly preserving promisor file contents.

Lorenzo demonstrates good engagement with the review process - the v2 changes show clear responsiveness to Eric's technical guidance. The implementation now appears more robust, with test coverage added where previously missing. This looks like solid progress on a niche but important corner of Git's object storage system.
