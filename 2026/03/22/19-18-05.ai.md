This is the second patch in a 4-part series addressing promisor file handling during repacks, part of Lorenzo Pegorari's GSoC work under Eric Sunshine's mentorship. The patch introduces a new helper function `copy_all_promisor_files()` that efficiently consolidates content from multiple `.promisor` files during repacking.

The function reads all existing `.promisor` files line by line, using a strset` for O(1) duplicate checking (an improvement over the O(n²) approach from v1). It writes only unique lines to the destination file, avoiding redundant entries that might come from multiple packfiles. The implementation handles file I/O carefully with proper error checking and memory management, addressing Eric Sunshine's v1 feedback.

Key technical details:
- Adds the function to `pack-write.c` with corresponding declaration in `pack.h`
- Uses Git's `strset` from `strmap.h` for efficient duplicate detection
- Maintains proper resource cleanup with `strbuf_release` and `strset_clear`
- Includes robust error handling for file operations
- Follows Git's coding style and patterns

The patch demonstrates good responsiveness to prior review feedback, showing clear progress on the series' goal to properly handle promisor file contents during repacks. The implementation looks solid and well-tested, with the algorithmic improvement being particularly notable.
