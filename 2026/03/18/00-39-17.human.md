This is a refactoring patch that converts branch-name interpretation flags from preprocessor constants to an enum type. The change affects several files that handle branch name resolution, including `object-name.c` and `refs.c`.

The patch replaces the `INTERPRET_BRANCH_*` macros (`LOCAL`, `REMOTE`, `HEAD`) with corresponding enum values while maintaining their existing bitmask behavior. The new `interpret_branch_name_allowed` enum is then used consistently across function signatures and struct fields that previously used plain `unsigned` types for these flags.

The change appears to be purely mechanical - it doesn't modify any behavior or add new functionality, but improves type safety by giving these flags a dedicated type. The patch touches core branch-handling code but the changes are straightforward and limited to type signatures. This looks like a clean, focused improvement that follows Git's style of gradually modernizing the codebase.
