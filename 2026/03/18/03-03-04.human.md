Performance improvement for MIDX repacking with bitmaps.

Jeff King (Peff) confirms that Taylor Blau's MIDX optimization series is ready to merge into 'next' after reviewing the v3 changes. The series improves multi-pack-index repacking by enabling reachability bitmaps during compaction, with preparatory refactoring to clean up the MIDX writing code. Peff had previously identified minor issues in v2 (outdated comments and interface concerns), which Taylor addressed in this version. 

This marks the completion of review for this performance-focused series, which builds on earlier MIDX work to better handle repositories with many packfiles. The changes are contained to the MIDX subsystem and don't introduce user-facing behavior changes beyond the expected performance gains. With Peff's sign-off, the path is clear for Junio to merge the topic into the integration branches.
