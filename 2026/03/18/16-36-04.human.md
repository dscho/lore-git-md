This is a follow-up discussion about test case style in Junio's recent whitespace checking fix. D. Ben Knoble weighs in on the thread about whether to use parentheses or braces for command grouping in test cases.

Knoble suggests that braces `{ ... }` would be more efficient than parentheses `( ... )` for command grouping in the test case, particularly avoiding the subshell overhead that's especially costly on Windows. This builds on Junio's earlier acknowledgment that the parentheses in the new test were unnecessary (they had been copied from an existing test where they served a purpose).

The exchange shows the project's attention to both correctness and performance, even in test infrastructure. Knoble's comment adds a platform-specific optimization consideration to the earlier style discussion. While the core functionality of the patch is settled, this thread continues refining the implementation details with input from multiple contributors.
