This is a refactoring patch that moves remote group resolution code from fetch.c to remote.c as part of the ongoing effort to add remote group support to `git push`. The changes are mechanical with no functional impact - the same group resolution logic that was previously in builtin/fetch.c is now available as shared infrastructure in remote.c.

The patch relocates three key components: the `remote_group_data` struct that holds group resolution state, the `get_remote_group()` config callback that parses `remotes.<name>` entries, and the `add_remote_or_group()` function that resolves a name to either a group or single remote. These are now static helpers in fetch.c but become properly exported functions in remote.c with declarations in remote.h.

This change was suggested by Junio Hamano to enable code reuse between fetch and push implementations. The author has followed through by removing the UNUSED macro from headers as requested in previous feedback. The patch serves as groundwork for the subsequent push group functionality while maintaining perfect backward compatibility - existing fetch behavior remains unchanged.

The code movement is clean and straightforward, touching only the three expected files (fetch.c loses the code, remote.c gains it, remote.h gets the new declarations). This is a solid infrastructure preparation step that follows established patterns for making fetch-specific logic available to other commands.
