This is a test patch adding coverage for the `git repo info` command's behavior with linked worktrees and repositories using `--separate-git-dir`. The patch comes from Jialong Wang and adds new test cases to `t1900-repo-info.sh`.

The patch adds two new scenarios to verify that `git repo info` correctly reports repository layout information (specifically `layout.bare` and `layout.shallow`) when:
1. The repository is accessed through a linked worktree
2. The repository was created with `--separate-git-dir`

For each scenario, the tests verify both the default line-oriented output format and the NUL-delimited format (activated with `--format=nul`). The test assertions are straightforward - they check that the output matches expected values for these non-bare, non-shallow repository configurations.
