Refactoring patch converting branch interpretation flags to an enum type, addressing maintainer feedback.

This is version 2 of Jialong Wang's patch to replace the `INTERPRET_BRANCH_*` macro constants with an enum type. The change improves type safety while maintaining the existing bitmask behavior for branch name interpretation flags. The patch follows up on Junio Hamano's review comments by:

1. Renaming the enum from `interpret_branch_name_allowed` to the more accurate `interpret_branch_kind`
2. Keeping the original `INTERPRET_BRANCH_*` names for enum values
3. Fixing formatting issues like line wrapping and declaration style

The changes affect several core files (`object-name.[ch]`, `refs.[ch]`, `builtin/branch.c`) where branch interpretation flags are used. The patch remains focused on type system improvements without modifying behavior, making it a clean, low-risk change. As part of Google Summer of Code work, this demonstrates good responsiveness to maintainer feedback while maintaining the patch's original purpose of making the code more self-documenting.
