Performance optimization in the commit-reachability code.

René Scharfe simplifies the cleanup of remaining bitmaps in the `ahead_behind()` function by using the `deep_clear` function of the bit_arrays commit slab. This avoids unnecessary heap rebalancing operations from the prio_queue when we no longer concerned with commit order during cleanup.

The change replaces a manual cleanup loop that processed commits one by one with a bulk operation that handles all remaining bitmaps at once. The patch is small (11 lines changed) and focused, typical of René's clean, efficient contributions. It maintains the same functionality while being more performant, though the impact would only be noticeable in repositories with very large commit graphs.
