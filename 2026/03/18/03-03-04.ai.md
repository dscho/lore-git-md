Performance improvement for MIDX repacking with bitmaps.

Jeff King (Peff) confirms that Taylor Blau's MIDX optimization series is ready to merge into 'next' after reviewing the changes between v2 and v3. The series improves multi-pack-index repacking by enabling reachability bitmaps during compaction and includes various preparatory refactors of the MIDX writing code. Peff had previously identified minor issues in v2 (outdated comments and interface concerns) which have now been addressed in v3. This represents the last review checkpoint before merging, with no further feedback needed from Peff's perspective.

The changes are contained to the MIDX subsystem and build on Taylor's ongoing work to optimize Git's handling of repositories with many packfiles. The series includes 17 commits that refactor MIDX internals (introducing helpers like `midx_pack_perm()` and clean up pack ordering requirements) while maintaining backward compatibility. Test updates and documentation fixes accompany the core functionality changes. This approval clears the way for Junio to merge the topic into the integration branches as part of the next development cycle.
