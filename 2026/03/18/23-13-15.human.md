This is the final iteration of a feature series adding remote group support to `git push`, mirroring the existing functionality in `git fetch`. The patch series from Usman Akinyemi has progressed through multiple review rounds with Junio Hamano and is now in its final polishing stage.

The implementation allows pushing to all remotes in a configured group (defined via `remotes.<name>` config) with a single command like `git push all-remotes`. The design ensures group pushes behave identically to sequential individual pushes, with proper handling of per-remote configurations like `remote.<name>.push` and `push.default` settings. The series includes comprehensive test coverage and documentation updates.

The architectural decisions have all been resolved, including how `--force-with-lease` semantics and failure handling should work across groups.
