This is a refactoring patch that moves remote group resolution code from `builtin/fetch.c` to `remote.c` as part of the effort to add remote group support to `git push`. The patch extracts three components that handle remote group configuration parsing: the `remote_group_data` struct and the functions `get_remote_group()` and `add_remote_or_group()`. 

The change is purely mechanical - no behavior is altered. The moved code will be reused in the next patch to implement group pushing functionality. Junio Hamano suggested this refactoring approach to avoid duplicating the group resolution logic between fetch and push implementations. The patch follows Git's standard code movement pattern: delete from the original location, add to the new shared location, and update header files. The author has already incorporated maintainer feedback by removing the `UNUSED` macro from headers in this version.

This is the first of three patches in the series, establishing the shared infrastructure needed for the actual push-to-group feature. The clean separation makes the subsequent push implementation patch more focused on its new functionality rather than reimplementing existing group handling.
