This is the final patch in Jean-Noël Avila's documentation standardization series, converting `git-show` and related format documentation to the new AsciiDoc synopsis style. The patch follows the established pattern of adding synopsis blocks, standardizing placeholder syntax (`_<placeholder>_`), and improving option descriptions.

Kristoffer Haugsbakk's review confirms the successful conversion elements while identifying some HTML rendering quirks with the new `[synopsis]` blocks. The discussion reveals some edge cases in the AsciiDoc processing - particularly around verbatim formatting of Git command syntax that include special characters. Avila explains the tradeoffs between different formatting approaches (`++` vs backticks) across AsciiDoc implementations.

The patch maintains the series' high quality, with Avila planning to address the minor issues found (inconsistent backtick usage and cross-references) in a reroll. This continues the project's systematic effort to bring consistency to Git's documentation, with all changes strictly limited to formatting improvements.
