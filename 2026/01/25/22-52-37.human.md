This is patch 2/6 in a completed bugfix series from Karthik Nayak and Jeff King that restores detailed error messages for batched reference updates. The series has already been merged by Junio after going through several iterations (v1-v5) with optimizations from Phillip Wood and style adjustments.

The current patch extends the callback function signature for handling rejected reference updates to include a `details` parameter, which will carry the specific error message when a reference update fails. This is groundwork for the subsequent patches that will actually use these details to restore the lost error reporting functionality. The change touches several callers (`fetch`, `receive-pack`, and `update-ref`) but currently marks the parameter as unused, as the full integration comes later in the series.

The patch is straightforward plumbing work that follows the project's established patterns. It's part of a well-reviewed series that addresses a real regression in debugging capability when reference operations fail. The changes are mechanical but important for the overall solution.
