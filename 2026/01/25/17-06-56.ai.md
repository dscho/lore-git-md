This is a translation (l10n) update for git-gui, the graphical Git interface that ships with Git but is maintained separately. The patch series includes Bulgarian language updates from Alexander Shopov covering 558 strings across both the main translation file (`po/bg.po`) and the glossary (`po/glossary/bg.po`). 

Johannes Sixt (git-gui maintainer) contributes a technical change to ensure all `.po` files are treated as UTF-8 encoded, regardless of their directory location, by updating `.gitattributes`. This encoding fix addresses a consistency issue that could affect future translation work across all languages in git-gui.

The changes are straightforward - no behavior changes to git-gui itself, just translation content updates and a configuration tweak. Junio C Hamano indicates he will merge the pull request, suggesting the changes are uncontroversial and ready for inclusion. This appears to be routine maintenance of git-gui's localization support.
