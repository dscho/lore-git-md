This is a localization (l10n) update for git-gui, the graphical Git interface that is maintained separately from core Git but distributed with it. The patch series includes two main components: an update to the Bulgarian translation files (`po/bg.po` and `po/glossary/bg.po`) by Alexander Shopov, and a technical change by Johannes Sixt (the git-gui maintainer) to ensure all PO files are treated as UTF-8 regardless of their directory location.

The Bulgarian translation now covers 558 strings, with updates to both the main interface strings and the glossary terms. The `.gitattributes` modification is a one-line change that standardizes the encoding handling for translation files across the project. This appears to be routine maintenance work with no controversial changes - just keeping the localized content current and ensuring consistent file handling. Junio Hamano indicates he will merge the changes.
