This is a refactoring patch that introduces a new utility function `string_list_sort_u()` to the string-list API, combining the common pattern of sorting followed by deduplication into a single operation. It's part of a series where patch 1 introduced the function and patch 2 (this one) converts several call sites to use it.

The patch adds the new function to string-list.[ch] and updates six call sites across clone.c, fast-export.c, pack-objects.c, sparse-checkout.c, help.c, and notes.c where the sort+deduplicate pattern was previously done with two separate calls. The changes are mechanical replacements that don't alter behavior, just consolidate the operations.

The implementation is straightforward - `string_list_sort_u()` simply calls the existing `string_list_sort()` followed by `string_list_remove_duplicates()`. The patch includes new test coverage in t/unit-tests/u-string-list.c that verifies the function handles various cases including empty strings, duplicates, and mixed ordering. The tests follow existing patterns in the test file.

This appears to be a clean, focused improvement to the string-list API that simplifies common usage patterns.
