This is a bugfix for the histogram diff algorithm in xdiff, addressing an edge case where shifted change groups during compaction can produce redundant diff output containing matching lines from both files. The patch adds logic to detect when shifting creates new matching groups and re-diffs those sections using Myer's algorithm while preserving all original diff flags.

Junio C Hamano and Phillip Wood are reviewing the implementation details.
