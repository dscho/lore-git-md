This is the third patch in a completed bugfix series (v5 3/6) from Karthik Nayak and Jeff King that restores detailed error messages for batched reference updates. The series addresses a regression where `git update-ref --batch-updates` and related commands lost their detailed error reporting, only showing generic error codes.

The current patch specifically modifies `git update-ref` to output detailed error messages to stderr while maintaining the machine-parsable format on stdout. This gives users actionable error details without breaking existing scripts that parse the output. The changes include updating the `print_rejected_refs` callback to handle the new `details` parameter and significantly expanding the test coverage to verify both the human-readable and machine-readable outputs.

The patch is well-structured with clear commit message explaining the motivation and changes. It builds on infrastructure added in earlier patches of the series (notably the extended signature with `details` parameter in patch 2/6) and includes comprehensive test updates that validate the new behavior across various error cases. The series has already been merged by Junio Hamano in an earlier version and this final iteration incorporates all requested optimizations and style adjustments.
