This is a refactoring patch that introduces a new utility function `string_list_sort_u()` to combine the common pattern of sorting a string list followed by removing duplicates. The patch is part of a series where this is the implementation patch (patch 2/2), following test coverage additions in patch 1/2.

The new function `string_list_sort_u()` wraps the existing `string_list_sort()` and `string_list_remove_duplicates()` operations into a single call, which the author notes is a common pattern seen across the codebase. The patch mechanically converts several call sites in clone.c, fast-export.c, pack-objects.c, sparse-checkout.c, help.c, and notes.c to use the new combined function.

The changes are straightforward and appear to maintain the same behavior as the original two-step operations. The patch includes tests in t/unit-tests/u-string-list.c that verify the new function handles various cases including empty strings, duplicates, and mixed ordering. The test coverage was added in response to Junio Hamano's request before technical review of the implementation.

This seems like a clean, focused improvement that simplifies a repetitive pattern in the code. The patch touches several important commands (particularly pack-objects and sparse-checkout) but the changes are mechanical and well-contained. The test coverage gives confidence that the behavior remains correct.
