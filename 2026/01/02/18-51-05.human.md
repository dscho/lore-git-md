Feature improvement for `git add -p` interactive hunk selection.

This patch enhances the interactive hunk selection interface in `git add -p` to show the previous decision (use/skip) when navigating between hunks. Currently, when moving between hunks with K/J keys, there's no visual indication of prior choices, which can be confusing during review.

The change modifies the prompt strings in `add-patch.c` to include a "(previous decision: use/skip)" indicator when applicable. The implementation handles all interactive patch modes (stage, stash, unstage, etc.) consistently. Test updates in t3701 verify the new behavior.

The patch comes from a GSoC participant and addresses a usability issue reported by Junio C Hamano. This is version 3 of the patch, with changes focused on test updates to match the new prompt format. The implementation looks straightforward and well-contained, touching only the prompt display logic while maintaining all existing functionality.
