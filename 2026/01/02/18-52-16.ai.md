Refactoring patch in the xdiff subsystem, part of a series preparing for Rust interoperability. This is patch 2/10 in Ezekiel Newren's series to restructure xdiff internals for future optimizations.

The patch extracts the core classic diff algorithm from `xdl_do_diff()` into a new standalone function `xdl_do_classic_diff()`. This makes the classic diff implementation more modular and explicit, separating it from the dispatch logic that handles patience and histogram diffs. The new function takes an `xdfenv_t` environment and flags directly rather than the full `xpparam_t`.

Key changes:
- Moves the classic diff implementation (including K vector allocation and Myers algorithm setup) to `xdl_do_classic_diff()`
- Updates the header file with the new function declaration
- Leaves the diff algorithm dispatch logic in the original `xdl_do_diff()`
- Maintains all existing functionality while making the code more modular

The change is part of the groundwork for moving `xdl_cleanup_records()` (mentioned in the commit message) and appears to be preparing for future work where the classic diff implementation might be modified or replaced. The patch is cleanly focused, with no behavior changes - just code reorganization to support the series' goals.
