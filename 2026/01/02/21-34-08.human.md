This is a refactoring patch in preparation for adding push remote tracking information to `git status` output. It's part of a v12 series that has evolved through extensive review, with the maintainer (Junio C Hamano) having approved the technical direction.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This prepares for the next patch which will reuse this logic to show both upstream and push tracking information. The refactoring:

1. Separates the message generation from the tracking info calculation
2. Makes the same messages available for both upstream and push comparisons
3. Preserves all existing behavior while making the code more maintainable

The changes are mechanical and well-contained, touching only `remote.c`. The commit message clearly states this is preparatory work, with the actual feature addition coming in the follow-up patch. Given the thorough review history and maintainer approval, this appears ready for inclusion.
