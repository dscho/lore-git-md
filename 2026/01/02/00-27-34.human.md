This is a performance optimization patch targeting Git's byte-swapping functions in `compat/bswap.h`. Rostislav Krasny proposes simplifying the current implementation by using `memcpy` to avoid undefined behavior from pointer type punning, while also making the code more readable and potentially faster.

The patch compares the existing implementation (which uses multiple bitwise operations) against the proposed version (using `memcpy` and compiler intrinsics where available). Benchmark results show significant improvements in unoptimized builds (-O0) and some gains in optimized builds, particularly with Clang at -O2/-O3 where the new version is nearly twice as fast.

The author notes the current implementation's complexity stems from avoiding undefined behavior with pointer type conversions, while the new approach leverages `memcpy`'s well-defined behavior. The patch appears well-motivated with clear performance justification and maintains compatibility requirements. It touches a focused area (byte swapping utilities) that's widely used in Git's codebase, particularly in hash computation and network operations.
