Refactoring patch in the xdiff subsystem modernization series. This is patch 6/10 in Ezekiel Newren's series preparing the xdiff internals for future optimizations and Rust compatibility.

The patch simplifies the `xdl_trim_ends()` function in xdiff preparation code by replacing pointer arithmetic with direct array indexing. The key changes are:

1. Replaces moving pointers (`recs1++`, `recs2++`) with direct array access using [i] and [nrec-1-i]
2. Extracts the minimal_perfect_hash values into local variables for clarity
3. Changes the return type from `int` to `void` since it always returned 0
4. Uses `size_t` instead of `long` for indices to better match the array sizes
5. Combines the dstart/dend assignments with the comparison logic for better locality

The changes are purely mechanical - the function's behavior remains identical, just expressed differently. This continues the series' theme of making the diff preparation code more straightforward to work with, particularly for future Rust interoperability work. The patch follows the established pattern of the series by focusing on one clear, contained refactoring per commit.
