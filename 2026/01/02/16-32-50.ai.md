This is a refactoring patch that's part of the ongoing `the_repository` removal effort. The patch moves the handling of "core.attributesFile" configuration from global state into `struct repo_settings`, making it repository-scoped rather than process-global.

The change affects how Git looks up attribute files, particularly the global attributes file (typically at `~/.config/git/attributes`). Previously this was stored in a global variable `git_attributes_file`; now it's stored per-repository in `repo->settings.attributes_file_path`. The patch introduces a new accessor function `repo_settings_get_attributesfile_path()` to retrieve this setting.

Key technical changes:
- Removes `git_attr_global_file()` and its global state
- Adds `attributes_file_path` field to `struct repo_settings`
- Updates `bootstrap_attr_stack()` to use repository-specific path
- Modifies `git_attr_val_global()` to use the new accessor
- Cleans up related config handling in environment.c
