This is patch 8/10 in Ezekiel Newren's series refactoring xdiff internals, part of the broader Rustification effort. The patch continues the structural reorganization started in previous patches by moving the `dend` field from `xdfile_t` to `xdfenv_t` (renamed to `delta_end`), following the same rationale as the earlier `dstart` relocation.

The changes are mechanical but touch several xdiff components: the histogram and patience diff algorithms now calculate `dend` values from the environment structure, `xdl_cleanup_records()` updates its iteration bounds, and `xdl_trim_ends()` sets the new `delta_end` field instead of modifying file-specific `dend` values. The patch maintains identical diff behavior while improving code organization for future Rust interoperability work.

This continues the series' pattern of consolidating diff state into the environment structure and cleaning up xdiff internals. The changes appear straightforward but will need verification that they don't subtly alter diff behavior, particularly in edge cases around file boundaries. Reviewers will likely focus on the correctness of the `dend` calculations and the impact on diff algorithm behavior.
