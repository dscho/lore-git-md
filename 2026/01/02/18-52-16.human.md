This is part 2 of a 10-patch series refactoring Git's xdiff subsystem to prepare for future optimizations and Rust interoperability. The series is from Ezekiel Newren, who is also involved in Git's Rustification efforts.

This patch focuses on the classic diff algorithm implementation in xdiff. It extracts the core logic from `xdl_do_diff()` into a new standalone function `xdl_do_classic_diff()`, making the classic diff algorithm more explicit and modular. The change is motivated by upcoming work to move `xdl_cleanup_records()` (which is only used by the classic diff) into xdiffi.c.

The patch is a straightforward refactoring that:
1. Takes the classic diff portion of `xdl_do_diff()` and moves it to a new function
2. Updates the function signature to take just the xdfenv_t and flags it needs
3. Leaves the existing function as a dispatcher that calls the appropriate algorithm
4. Adds the new function to xdiffi.h for visibility

The changes are mechanical and don't modify behavior - they just reorganize the code to be more maintainable and prepare for future changes. As part of a larger series preparing xdiff for Rust interoperability, this patch helps isolate the classic diff algorithm's implementation details.
