This is the final patch (10/10) in Ezekiel Newren's series refactoring xdiff internals to prepare for future optimizations and Rust interoperability. The patch focuses on code organization by moving `xdl_cleanup_records()` and related functions from `xprepare.c` to `xdiffi.c`.

The key change relocates the cleanup functionality that was previously called during preparation phase to be invoked directly from `xdl_do_classic_diff()`. This makes logical sense since only the classic diff algorithm uses these functions. The patch moves:
- `xdl_cleanup_records()` - the main cleanup function
- `xdl_clean_mmatch()` - helper for handling multiple matches
- Several related macros (`XDL_KPDIS_RUN`, `XDL_MAX_EQLIMIT`, etc.)

The implementation remains functionally identical - this is purely a code movement to better organize the diff algorithms. The patch builds on previous changes in the series that introduced the `xoccurrence` vector type and moved diff state into `xdfenv_t`.

This completes the series' goal of separating classic diff preparation from the algorithm itself while maintaining all existing behavior. The changes appear mechanical and well-contained, though reviewers will want to verify the relocation doesn't subtly affect diff output.
