Refactoring patch in the xdiff subsystem preparation series. This is patch 5/10 in Ezekiel Newren's series to restructure xdiff internals for future optimizations and Rust compatibility. The patch modifies two key functions in xdiff/xprepare.c to work with the xdfenv_t structure rather than directly with xdfile_t parameters.

The changes are mechanical but important for the series' goals: `xdl_trim_ends()` and `xdl_cleanup_records()` now take the environment structure `xe` as input and access the file data through it, rather than taking separate `xdf1` and `xdf2` parameters. This prepares for future patches that will add delta tracking fields to xdfenv_t.

The diff shows straightforward conversions where file-specific operations (like accessing recs, nrec, dstart, dend fields) are now done through xe->xdf1 and xe->xdf2. The logic remains identical - this is purely an interface change to support the series' architectural direction. The patch maintains all existing behavior while enabling the planned follow-up work mentioned in the cover letter.
