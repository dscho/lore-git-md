This is patch 6/10 in Ezekiel Newren's series refactoring xdiff internals to prepare for future optimizations and Rust interoperability. The patch focuses on cleaning up the `xdl_trim_ends()` function in xdiff preparation code.

The change replaces pointer arithmetic with direct array indexing when comparing records at the start and end of diff regions. The new version uses local variables to store the minimal perfect hash values being compared, making the control flow more straightforward. The function signature also changes from returning an `int` to `void` since it never actually returns an error.

This appears to be a straightforward refactoring that improves readability without changing behavior. The patch is part of a larger effort to modernize xdiff's internals while maintaining compatibility with both C and future Rust components. The changes align with the series' goal of making the code more maintainable and optimization-friendly.
