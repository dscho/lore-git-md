Performance optimization and modernization of Git's byte-swapping functions in `compat/bswap.h` (initial patch from Rostislav Krasny). The series replaces manual bit-twiddling implementations with `memcpy`-based type punning for better maintainability and consistent behavior while avoiding undefined behavior. Key technical scope: complete network byte order API including new 16-bit variants (`bswap16`, `ntohs`, `htons`, `put_be16`), renamed functions for consistency (`default_swab32` -> `default_bswap32`), and optimized implementations of `get_be32/64`/`put_be32/64` using compiler intrinsics (GCC/Clang `__builtin_bswap*`, MSVC `_byteswap_*`) with portable fallbacks.

Jeff King (Peff) conducted detailed benchmark analysis showing: (1) -O0 results are not meaningful for real use, (2) -O3 speedups appear to be loop optimization artifacts, (3) Clang -O2 shows 1.8x speedup but may be test-case specific, (4) aligned 8-byte reads show no performance difference. Peff concludes the changes improve readability/maintainability but questions real-world performance benefits.
