This is a performance optimization patch in the xdiff subsystem, part of Ezekiel Newren's 10-part series refactoring xdiff internals for future optimizations and Rust compatibility.

The patch removes the line-count estimation logic from xdiff's preparation phase, since all lines must be read and processed anyway. It eliminates the `xdl_guess_lines()` function and related constants (`XDL_GUESS_NLINES1/2`), moving the line classification to happen after all records are read rather than during initial parsing. The change also consolidates the classifier initialization by moving the `memset()` into `xdl_init_classifier()`.

Key technical changes include:
- Removal of heuristic line counting that was previously used to size internal data structures
- Restructuring of `xdl_prepare_ctx()` to process records without classification
- Addition of separate classification passes after all records are loaded
- Deletion of the now-unused `xdl_guess_lines()` utility function

The change appears well-motivated - the previous two-pass approach (estimate then process) added complexity without clear benefit since the full processing was required regardless. This simplification aligns with the series' goal of preparing xdiff for future optimizations while maintaining current functionality. The patch touches core diff preparation logic but doesn't modify the actual algorithm behavior.
