Performance optimization and modernization of Git's byte-swapping functions in `compat/bswap.h`. This patch from Rostislav Krasny replaces manual bit-twiddling implementations with `memcpy`-based type punning for better maintainability and performance, while adding missing 16-bit network byte order conversions.

The changes modernize the code by:
- Replacing direct pointer arithmetic with safer `memcpy` operations in `get_be32()`, `get_be64()`, and related functions
- Adding new `bswap16()` support with compiler intrinsics where available
- Introducing `put_be16()` for API completeness
- Renaming functions for consistency (`default_swab32` -> `default_bswap32`)
- Adding standard network order macros (`ntohs`, `htons`)

Benchmark results show significant speedups, particularly at lower optimization levels (4x faster with -O0 on GCC) while maintaining or improving performance at higher optimization levels. The patch maintains identical external behavior while being more portable and easier to maintain.

This touches fundamental object handling code but uses well-established safe type punning technique. The changes appear thorough and well-tested, with clear performance measurements provided. The patch is likely to be of interest to anyone working with Git's low-level object handling or cross-platform compatibility.
