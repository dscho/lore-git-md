This is the final version (v12) of a feature enhancement for `git status` that shows divergence from both the upstream and push tracking branches. The patch series has evolved through extensive discussion and review, with the current version incorporating feedback from multiple contributors.

The implementation now cleanly uses Git's existing branch tracking mechanisms rather than introducing new configuration, as originally proposed. Key technical points:
- Uses `branch.<name>.pushRemote` when configured, falling back to tracking branch if unset
- Shows push branch comparison only when it differs from the upstream branch
- Maintains optimized ref resolution and memory management from previous versions
- Output format matches existing `git status` conventions with clear separation between upstream and push status

The v12 changes address final review feedback from Phillip Wood, including:
- Standardized message wording between upstream and push comparisons
- Fixed NULL flag passing in ref resolution
- Corrected push advice for different remote branches
- Improved test documentation for edge cases

The test suite has 167 lines of new coverage verifying all scenarios (ahead/behind/diverged states, remote configurations, edge cases). Example output now shows both comparisons when they differ:

```
On branch feature
Your branch is ahead of 'upstream/main' by 1 commit.
Your branch is ahead of 'origin/feature' by 1 commit.
  (use "git push" to publish your local commits)
```

The patch series has received maintainer approval from Junio Hamano for the technical direction and is now in its final polishing stage before potential inclusion. All major technical concerns have been addressed, with only minor consistency refinements remaining from Phillip Wood's review.
