This is a bugfix patch for submodule fetching behavior, part of a series that addresses the hardcoded assumption that submodule remotes are always named "origin". The patch adds a new `get-default-remote` helper command to properly handle submodules with differently-named remotes, fixing cases where `git fetch --recurse-submodules` would fail.

The implementation in builtin/submodule--helper.c introduces the new helper command while maintaining backward compatibility by falling back to "origin" if default remote detection fails. The changes touch submodule-related files and include comprehensive test coverage across multiple test scripts (t5526, t5572, and the renamed t7426).
