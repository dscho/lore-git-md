This is the third patch in a completed bugfix series (v4 6/6) from Karthik Nayak and Jeff King that restores detailed error messages for batched reference updates. The series addresses a regression where `git update-ref --batch-updates` and related commands were only returning generic error codes rather than the specific error details that were previously available.

This particular change modifies `git update-ref` to output detailed error messages to stderr while maintaining the existing machine-parsable output format on stdout. The patch includes extensive test updates that now verify both the machine-readable output and the human-readable error messages for various failure cases (invalid objects, ref conflicts, case sensitivity issues, etc.).

The implementation builds on infrastructure added in earlier patches of the series to propagate error details through the ref transaction system. The changes are focused and well-tested, with clear commit messages explaining both the problem and solution. This patch represents a key piece of the overall fix, ensuring users get actionable error messages while preserving backward compatibility with scripts that parse the machine output.

The series has already been merged by Junio Hamano in its v3 form, with this v4 optimization now completing the work. There are no remaining technical objections to the solution.
