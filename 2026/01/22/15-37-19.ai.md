This is a refactoring patch from Harald Nordgren, part of the v27 iteration of his series to make branch comparison in `git status` configurable. The patch splits out the branch comparison formatting logic from `format_tracking_info()` into a new standalone `format_branch_comparison()` function, preparing for the addition of push remote tracking branch support in subsequent patches.

The changes are purely structural - no behavior is modified. The existing comparison message generation (up-to-date, ahead/behind, diverged states) is moved into the new function while maintaining all current output formatting and advice messages. The refactoring handles the same cases as before: upstream gone, up-to-date, ahead/behind with quick mode, and diverged states, each with their appropriate advice hints.

This is the first of two patches in v27, which addresses a final edge case in the long-running effort to make branch comparisons configurable via `status.compareBranches`. The thread summary indicates this is the final technical iteration, with all implementation issues (including memory leaks) resolved and only documentation remaining outstanding. Junio Hamano has indicated the feature will be included in the next release cycle.
