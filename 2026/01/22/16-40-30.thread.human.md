This thread began with a security professional inquiring about an outdated, vulnerable version of VIM bundled with Git for Windows (specifically CVE-2025-66476 in VIM 9.1.1914). The initial question asked whether users could update VIM independently of Git.

Junio C Hamano, the Git maintainer, has now responded that this is a matter for the Git for Windows project rather than upstream Git. He explains that the core Git project only distributes source code and doesn't handle binary distributions or bundled software. Junio helpfully points the reporter to the Git for Windows issue tracker as the appropriate channel for this concern.

The response clarifies the boundary between upstream Git development and platform-specific distributions, establishing that security updates for bundled components should be directed to the relevant distribution maintainers (in this case, likely Johannes Schindelin and the Git for Windows team). The original question remains open from the Git for Windows perspective, but the upstream Git project has made it's position clear that this falls outside their scope.
