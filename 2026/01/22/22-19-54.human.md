This is the second patch in Amisha Chhajed's RFC series introducing `string_list_sort_u`, a combined sort-and-deduplicate utility for Git's string-list API. The patch mechanically converts several existing call sites that currently perform separate sort and deduplicate operations to use the new combined function instead.

The changes touch multiple commands including clone, fast-export, pack-objects, sparse-checkout, help, and notes - all places where the pattern of sorting followed by deduplication was already being used. Junio Hamano notes this helps by reducing boilerplate and making the deduplication behavior more visible at remaining call sites.

The patch is still in RFC status as the series awaits test coverage for the new function (requested by Junio in previous feedback) before moving to technical review. The conversions appear straightforward but some of the affected areas (like pack-objects and sparse-checkout) are performance-sensitive, so proper testing will be important. This looks like a clean, focused improvement to a common pattern in the codebase.
