This is a refactoring patch that's part of Harald Nordgren's series to add configurable branch comparison in `git status`. The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new standalone function `format_branch_comparison()`. 

The change is purely structural - it moves the message generation code into a separate function while maintaining all existing behavior. This prepares for the next patch in the series which will add push remote tracking branch comparison support. The refactoring makes the code more modular by separating the comparison formatting from the upstream tracking logic.

The patch has already gone through extensive review (this is version 28) and is now merged in Git's integration branches. It touches the branch tracking functionality in `remote.c`, specifically the message generation part that shows how your branch relates to its upstream (ahead/behind/diverged status). The changes are well-contained and focused on improving code organization in preparation for the new feature.
