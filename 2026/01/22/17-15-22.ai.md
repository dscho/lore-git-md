This is an RFC patch proposing a new utility function for Git's string-list API. The patch adds `string_list_sort_u()` which combines sorting and deduplication into a single operation, addressing a common pattern where these operations are currently performed separately.

The change is straightforward - the new function simply calls the existing `string_list_sort()` followed by `string_list_remove_duplicates()`. The implementation is clean and matches the style of the surrounding code. The patch includes proper documentation in the header file explaining the function's behavior and parameters.

The motivation comes from observing that deduplication is almost always preceded by sorting in the codebase, suggesting this combined operation would simplify call sites. The RFC status indicates the author is seeking feedback on whether this is the right approach before proceeding with the series.

This touches core string-list functionality used throughout Git, so careful review of the design is warranted. The follow-up patch in the series will show conversions of existing call sites to use the new function, which should help validate whether the combined operation is universally appropriate or if some cases need to retain separate steps.
