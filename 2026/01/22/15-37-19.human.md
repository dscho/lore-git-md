This is a refactoring patch that's part of Harald Nordgren's long-running effort to make `git status` branch comparisons configurable. The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function, preparing for upcoming changes that will support showing comparisons with push remote tracking branches.

The changes are mechanical - the same logic is now in a separate function with slightly different parameters (notably taking a `branch_name` parameter rather than getting it from the branch struct). This is groundwork for the next patch in the series which will introduce configurable branch comparisons. The patch has already gone through extensive review over 27 iterations, with all technical issues resolved, and is now in its final form pending documentation updates.
