This is a refactoring patch in Amisha Chhajed's RFC series introducing `string_list_sort_u`, a combined sort+deduplicate utility for string lists. The patch mechanically converts existing call sites that perform both operations to use the new combined function.

The changes touch several important subsystems: clone, fast-export, pack-objects, sparse-checkout, help, and notes. Junio Hamano notes approvingly that this consolidation makes the remaining standalone `remove_duplicates()` calls more visible for potential future analysis. However, as established in the thread context, test coverage for the new combined operation is still needed before technical review can proceed.

Key technical details:
- Converts sequential `string_list_sort()` + `string_list_remove_duplicates()` calls to `string_list_sort_u()` in multiple files
- Pack-objects changes affect include/exclude pack processing
- Sparse-checkout modifications impact cone mode pattern handling
- Notes conversion alters notes merging logic
- No behavior change intended - just combining existing operations

The patch appears mechanically sound but awaits the test coverage Junio requested before substantive review. The changes are straightforward substitutions, though some conversions (particularly in pack-objects and sparse-checkout) touch performance-sensitive areas that would benefit from the promised test verification.
