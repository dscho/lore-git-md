This is a platform compatibility patch addressing a bug in macOS's iconv implementation that affects character encoding conversion, specifically for ISO-2022-JP. The issue causes test failures in t3900 when converting commit messages from ISO-2022-JP to UTF-8 on macOS 14/15.

The patch introduces a workaround that resets the iconv conversion state when the output buffer needs to be enlarged, rather than continuing the conversion from where it left off. This avoids corruption that occurs when the macOS iconv implementation loses state during partial conversions. The workaround is gated behind an `ICONV_RESTART_RESET` define, with a follow-up patch promised to add a Makefile knob.

The change is well-motivated by specific test failures and includes a technical explanation of the underlying issue. The approach seems reasonable for a workaround, though it may impact performance slightly by requiring full re-conversions when buffers are resized. The patch is part of a two-patch series, with this being the technical implementation and the next adding build system support.
