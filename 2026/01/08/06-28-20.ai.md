This is the final patch in Kristoffer Haugsbakk's documentation series improving the `git-patch-id` man page. The patch clarifies the interaction between the `--verbatim` and `--stable` options, documenting that `--verbatim` implicitly enables `--stable` and prevents use of `--unstable`.

The change reflects the actual behavior introduced in commit 2871f4d4, which made this design choice to avoid maintenance burden - since users of `--unstable` primarily care about compatibility with old Git versions, and verbatim mode would break that compatibility by not stripping whitespace. The documentation update makes this implicit behavior explicit for users.

This is a straightforward documentation improvement that completes the series' goal of polishing the `git-patch-id` documentation. Like the previous patches in the series, it focuses on accuracy and clarity without changing any functionality. The change is small but meaningful, following the author's established pattern of careful documentation work.
