This is a feature patch series that implements runtime configuration for submodule gitdir paths, now in its final iteration (v8) with all major review comments addressed. The series introduces a new `extensions.submodulePathConfig` extension to handle path encoding for submodule gitdirs, preventing filesystem conflicts and enabling custom layouts while maintaining a unified directory structure in `.git/modules/`.

Josh Steadmon provides final testing validation, confirming the series can replace Google's downstream implementation without user impact. The patch set has received thorough review from Patrick Steinhardt and others, with only two minor polish comments remaining. Junio Hamano has already acked the series, and Patrick Steinhardt gives final approval pending those small tweaks.

Key technical aspects include a four-tier fallback system for path resolution, RFC3986-based encoding with case-folding protection, atomic migration support, and comprehensive test coverage. The implementation touches core submodule handling in `submodule.c`, helper commands in `builtin/submodule--helper.c`, and repository initialization in `setup.c`.
