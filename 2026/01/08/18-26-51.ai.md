This is the final patch in a documentation series improving the `git-patch-id` man page and related code comments. The patch clarifies the interaction between the `--verbatim` and `--stable` options, documenting that `--verbatim` implicitly enables `--stable` and prevents `--unstable`. This behavior was introduced in commit 2871f4d4 but wasn't fully explained in the documentation.

The patch explains the design rationale - that users of `--unstable` mainly need compatibility with old Git versions, and allowing `--verbatim` with `--unstable` would break that compatibility while adding maintenance burden. The change is purely documentation-focused, with no behavior modifications.
