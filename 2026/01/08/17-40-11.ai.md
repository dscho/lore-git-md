This is a platform compatibility patch addressing a bug in macOS 14/15's iconv implementation that affects character encoding conversion. The issue manifests when converting ISO-2022-JP text to UTF-8, causing test failures in t3900 where the conversion gets corrupted mid-stream.

The patch introduces a workaround that resets the iconv state when needing to expand the output buffer, rather than continuing the conversion from where it left off. This avoids corruption when macOS's buggy iconv loses state between partial conversions. The fix is gated behind an `ICONV_RESTART_RESET` define, with a follow-up patch promised to add build system support.

The change is well-motivated by specific test failures and includes a clear technical explanation of both the problem (state loss in macOS's iconv) and solution (full reset on buffer expansion). The patch affects utf8.c's encoding conversion logic but is narrowly scoped to the problematic case. As a platform-specific workaround, it follows Git's typical pattern of accommodating system quirks while maintaining correct behavior.
