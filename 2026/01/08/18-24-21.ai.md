This is a documentation patch series converting the `git-blame` man page to the new synopsis-style format, following up on maintainer feedback. The series is now in its second version, split into two patches as suggested by Jean-Noël Avila (the maintainer driving the documentation standardization effort).

Michael Lyons has implemented the requested changes, including splitting the original patch into separate conversions for the main `git-blame.adoc` file and the included `blame-options.adoc` file. The changes focus on consistent formatting rather than content changes, with particular attention to backtick usage for options (`` `--option` ``), placeholder syntax (`` _<file>_ ``), and improved grammatical clarity in the `--progress` option documentation.

Jean-Noël Avila has reviewed the updated patches and given his approval ("LGTM"), indicating they meet the project's documentation standards. This appears ready for merging as part of the ongoing effort to standardize Git's man page formatting across the project. The changes are mechanical in nature and unlikely to generate further discussion.
