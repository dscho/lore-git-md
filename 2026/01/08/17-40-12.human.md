This is a platform compatibility patch targeting macOS iconv issues. Torsten Bögershausen follows up on a previous commit that introduced a workaround for broken iconv implementations in macOS 14/15 (Sonoma and its successor). The patch enables the workaround only when: (1) running on affected macOS versions, and (2) not using external iconv libraries from MacPorts or Homebrew. The changes modify both the main Makefile and platform-specific configuration to conditionally define `ICONV_RESTART_RESET` when needed.

The patch appears well-scoped and clearly motivated by a specific platform quirk. It follows Git's established pattern for handling similar macOS compatibility issues, though the commit message could be slightly clearer about what symptoms the workaround addresses. This is part of ongoing maintenance for macOS users, particularly those relying on the system iconv rather than third-party replacements.
