Bugfix for `http-backend` error logging. This patch addresses a minor but annoying issue where error messages from `git-http-backend` (like "Not a git repository") would run together without newlines when logged through systems like fcgiwrap and journald. The fix is straightforward: ensure each error message written to stderr ends with a newline.

The patch modifies the `not_found` and `forbidden` functions in `http-backend.c` to explicitly append a newline after printing error messages. The change is small (6 lines added, 2 modified) and clearly motivated by real-world logging problems. While not a critical fix, it improves the readability of error logs in common deployment scenarios. The author correctly notes that the formatting responsibility belongs to Git rather than the wrapper process.
