This is Junio Hamano's regular "What's cooking in git.git" status report, providing an overview of the current state of patches in the Git project's integration branches. The report covers topics that have graduated to 'master', new topics under consideration, and ongoing work in various states of review.

Several notable patches have recently graduated to 'master', including:
- Adrian Ratiu's series converting hook script invocations to use the new hook API
- A fix from brian m. carlson for quoting invalid treeish in checkout error messages
- Elijah Newren's fix for recursive submodule/directory conflicts in merge-ort
- René Scharfe's cleanup of the tag code to remove `the_repository` usage

New topics under review include:
- Michael Lyo's documentation markup update for git-blame
- Jeff King's performance fix for git-cat-file bitmap usage
- Patrick Steinhardt's ongoing work on the packfile store and ODB source refactoring
- Johannes Schindelin's Windows symlink support series (a major effort to upstream Git-for-Windows functionality)
- A new "git history" command proposal from Patrick Steinhardt for history rewriting

The report also notes several topics that are expected to be rerolled or have outstanding review comments, including work on incremental MIDX repacking, Rust interoperability, and submodule gitdir handling. As always, Junio provides clear indicators of which branches contain each topic and whether they are considered stable ('next') or experimental ('seen').

This comprehensive status report gives a valuable snapshot of the project's current development state, with over 50 distinct topics in various stages of the review and integration process. The mix of bugfixes, performance improvements, and new features shows active development across Git's codebase.
