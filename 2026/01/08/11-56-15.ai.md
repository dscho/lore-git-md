This is Junio Hamano's regular "What's cooking in git.git" status report, providing an overview of the current state of topics in the Git development tree. The report covers patches that have graduated to 'master', new topics under consideration, ongoing work, and discarded proposals.

Several topics have recently graduated to 'master', including:
- Adrian Ratiu's series converting hook script invocations to use the new hook API
- A bugfix from brian m. carlson for quoting invalid treeish in checkout error messages
- A test modernization patch from Devesh Singh
- Derrick Stolee's fix for a use-after-free in diff with --name-only and lazy fetching
- Elijah Newren's fix for recursive submodule/directory conflicts in merge-ort
- René Scharfe's macOS iconv workaround and various cleanups

- Michael Lello's documentation markup update for git-blame
- Jeff King's performance fix for git-cat-file bitmap usage
- Elijah Newren's fsck improvement to snapshot refs before object walk

Notable ongoing work includes:
- Ezekiel Newren's xdiff cleanup in preparation for Rust integration
- Johannes Schindelin's Windows symlink support series

This status update provides a comprehensive snapshot of Git's development activity, showing both stable work ready for release and experimental work still under discussion. The breadth of topics - from core functionality to platform-specific fixes to documentation improvements - reflects the project's active maintenance and evolution.
