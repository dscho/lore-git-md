This thread addresses a macOS-specific issue with the iconv library in versions 14 and 15, where it incorrectly omits the byte order mark (BOM) during UTF encoding conversions. Torsten Bögershausen has sent a two-patch series building on René Scharfe's earlier workaround for similar platform quirks.

The first patch adds build system infrastructure with a new ICONV_OMITS_BOM Makefile variable, while the second implements the actual fix in utf8.c to handle macOS case specially. The changes are minimal (21 lines across three files) and follow Git's established pattern for platform-specific adjustments. The series appears ready for merging as a straightforward compatibility fix.
