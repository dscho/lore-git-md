This is a review comment on the test implementation in the submodule gitdir path encoding series. Patrick Steinhardt points out two improvements to Adrian Ratiu's test code in patch 5/11:

1. The test manually sets and unsets a global config using `git config --global`, but could use the more robust `test_config` helper which automatically cleans up after itself.

2. The test could use `test_when_finished` to ensure the config is unset even if the test fails partway through.

Patrick notes this same pattern appears in another test in this patch and in patch 6 of the series. The feedback is focused on test hygiene rather than the core functionality, which has already been acked by Junio Hamano for merging. This is a common type of polish review from experienced contributors like Patrick who pay close attention to test suite best practices.
