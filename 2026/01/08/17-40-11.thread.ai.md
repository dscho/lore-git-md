Thread identity: Platform compatibility patch addressing macOS 14/15 iconv bug affecting ISO-2022-JP to UTF-8 conversion, causing test failures in t3900.

Core problem: macOS's iconv implementation loses state during partial conversions when expanding output buffers, corrupting ISO-2022-JP to UTF-8 conversion mid-stream. This manifests in t3900 test failures.

Current status: Initial patch version proposing a workaround. No reviews or acks yet. Follow-up patch promised to add build system support for the `ICONV_RESTART_RESET` define.

Key technical details: Modifies utf8.c to reset iconv state completely when needing to expand output buffer, rather than continuing partial conversion. Workaround is gated behind `ICONV_RESTART_RESET` define to avoid affecting other platforms. Narrowly targets the macOS bug case while maintaining correct behavior elsewhere.
