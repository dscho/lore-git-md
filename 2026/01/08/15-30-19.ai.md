This is a documentation patch series converting the `git-blame` man page to the new synopsis-style format, following up on Jean-Noël Avila's review of the initial submission. Michael Lyons splits the changes into two patches - one for the main `git-blame.adoc` file and another for the included `blame-options.adoc` - addressing the maintainer's feedback while making some additional tweaks to improve clarity.

The changes standardize formatting across both files, applying the project's documentation conventions for option syntax (`` `--option` ``), placeholders (`` _<file>_ ``), and command output (`` `ignored`/`unblamable` ``). The author notes particular attention was given to the `--progress` option documentation to ensure grammatical correctness while accurately describing the behavior.

This continues the ongoing effort to bring all Git documentation to a consistent style, with Jean-Noël Avila shepherding the process. The split into two patches follows the maintainer's guidance from the initial review, where the first attempt was praised as "very good for a first try" while suggesting refinements. The changes are mechanical formatting improvements with no content modifications.
