This is a platform compatibility patch series addressing issues with iconv on macOS 14/15. The two-patch series from Torsten Bögershausen builds on an earlier workaround by René Scharfe (rs/macos-iconv-workaround) that was already merged into master.

The first patch prepares the codebase by adding necessary infrastructure - it introduces a new Makefile variable ICONV_OMITS_BOM and updates config.mak.uname to set this flag for macOS. The second patch then implements the actual workaround in utf8.c, adding special handling for macOS systems where iconv omits the byte order mark (BOM) when converting between UTF encodings.

The changes are focused and well-contained, touching only three files with 21 lines added total. The commit messages reference the specific macOS versions affected (14/15) and build upon existing platform-specific work in the codebase. This appears to be a straightforward compatibility fix for a known macOS quirk, following the pattern of similar platform-specific adjustments in Git's history.
