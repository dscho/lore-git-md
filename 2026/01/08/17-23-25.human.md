This is a platform compatibility patch series addressing issues with iconv on macOS 14/15. The two patches build on previous work ('rs/macos-iconv-workaround') to handle character encoding conversion problems specific to recent macOS versions.

The first patch prepares the groundwork by adding necessary build system changes and configuration checks. The second patch implements the actual workaround in utf8.c, which handles Git's Unicode conversion operations. The changes touch the Makefile, config.mak.uname, and utf8.c files.

The series appears to be a straightforward technical solution to a specific platform issue, building on established patterns from previous macOS compatibility work. The patches are small and focused, with the second one depending on the first. Given that this targets a known pain point (macOS iconv behavior) and follows prior art, it seems likely to be uncontroversial.
