This is a correction to the Git release announcement regarding a new `git fast-import` option. 

Toon Claes points out that Junio's release notes for Git v2.53.0-rc2 incorrectly described the new fast-import option as `--strip-if-invalid`. The actual option name is `--signed-commits=strip-if-invalid`, which allows `git fast-import` to strip invalid cryptographic signatures from objects rather than failing when encountering them. 

Junio acknowledges the correction with a brief "Thanks for sharp eyes" reply. This is a minor documentation fix to the release notes - the functionality itself was correctly implemented in the code, just mislabeled in the announcement. The option is part of Git's ongoing work to handle cryptographic signatures more robustly, particularly in import/export scenarios.
