This is a documentation patch finalizing the terminology and usage guidance for `git worktree` commands, particularly around pruning missing worktrees. The v3 patch from Sam Bostock has addressed all prior feedback and received approval from both Eric Sunshine and Junio Hamano, making it ready for merging.

The changes standardize on "prune" as the preferred term for removing worktrees whose working directories no longer exist, rather than the previously mixed "expire" terminology. It also clarifies that the `--expire` option only affects these missing worktrees, not all unused ones. The documentation now includes expanded guidance on when to use `prune` versus `remove` or `repair`.

This builds on Julia Evans' earlier documentation clarity work and represents a complete cycle from initial problem identification through multiple iterations to final approval. The patch touches only documentation (help text and man pages) with no behavior changes, making it low-risk. With all open questions resolved and maintainer approval secured, this appears ready to graduate from "seen" to "next".
