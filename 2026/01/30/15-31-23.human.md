This is part of an RFC patch series modernizing `git show-index`, specifically addressing hash algorithm detection behavior. The patch adds a warning when `git show-index` falls back to SHA-1 when run outside a repository, making the implicit assumption explicit.

The change is straightforward - it wraps the existing fallback logic with a warning message that suggests using `--object-format` when needed. The warning helps users understand why SHA-1 is being used and how to override it, which is particularly useful when working with SHA-256 index files. The patch maintains the existing behavior while adding this helpful notification.

The series has been restructured per Junio's feedback, with this patch focusing solely on the warning behavior while a second patch handles i18n support. Discussion continues about whether to add a `--quiet` flag to suppress the warning, but that debate is cleanly separated from this technical change. The implementation is minimal and touches only `builtin/show-index.c`, keeping the scope narrow.
