This is a minor correction to the Git 2.53.0-rc2 release notes. Toon Claes points out that the new `git fast-import` option for handling invalid cryptographic signatures was incorrectly listed as `--strip-if-invalid` in the changelog. The correct option name is `--signed-commits=strip-if-invalid`, which allows stripping invalid signatures from objects rather than failing the import.

Junio acknowledges the correction with his characteristic brevity. This sort of last-minute fix to release notes is common as the community proofreads the changelog before finalizing. The correction itself is straightforward and uncontroversial - it simply ensures the documentation matches the actual implementation.
