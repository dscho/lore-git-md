This is a small correction to the Git v2.53.0-rc2 release notes regarding a new `git fast-import` option. Toon Claes points out that the option name is actually `--signed-commits=strip-if-invalid` rather than `--strip-if-invalid` as stated in Junio's announcement.

The correction is straightforward and uncontroversial - it simply fixes an inaccuracy in the release notes. The option itself (which allows `git fast-import` to strip invalid cryptographic signatures from objects rather than failing) remains unchanged. This appears to be a minor documentation clarification rather than any substantive change to the feature.
