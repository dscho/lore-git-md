This is a refactoring patch that consolidates duplicate logic for iterating over preferred bitmap tips (configured via `pack.preferBitmapTips`) into a new `for_each_preferred_bitmap_tip()` function. The change removes the last external caller of `bitmap_preferred_tips()`, allowing it to be made file-local to pack-bitmap.c.

The patch is part of Patrick Steinhardt's series addressing a bug where exact refname matches in preferred bitmap tips would trigger a BUG(). While this patch doesn't yet fix the bug itself, it lays the groundwork by unifying the iteration logic that will need to be modified in subsequent patches.

The changes have already been reviewed positively by Karthik Nayak and Junio Hamano, with Junio specifically defending the use of small helper functions for readability. The patch appears well-structured and focused, touching only the necessary call sites in pack-objects.c and repack-midx.c while adding the new shared function to pack-bitmap.c.

This is a preparatory step in a larger effort to fix ref iteration behavior, with the actual bug fix coming in later patches of the series. The consolidation makes sense architecturally and has already passed technical scrutiny from multiple reviewers.
