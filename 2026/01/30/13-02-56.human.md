This is a minor correction to the Git 2.53.0-rc2 release announcement. Toon Claes points out that the option name for `git fast-import` was incorrectly listed as `--strip-if-invalid` in the changelog - the actual option is `--signed-commits=strip-if-invalid`. 

The option itself (which allows fast-import to drop invalid cryptographic signatures from objects rather than failing) remains unchanged - this is purely a documentation fix for the release notes. The correction is straightforward and uncontroversial, coming from someone familiar with the fast-import code (Christian Couder, one of the recipients, is a known contributor to fast-import/export functionality).

No further discussion is needed on this point - it's the sort of minor inaccuracy that often gets caught after release announcements go out, and the correction will likely be incorporated into the final release notes.
