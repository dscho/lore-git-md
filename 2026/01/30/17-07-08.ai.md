This is the final approval for a two-patch series modernizing `git show-index`. Junio C Hamano has now queued the patches after Shreyansh Paliwal split the original submission into two focused changes per Junio's earlier guidance.

The first patch adds hash algorithm detection to `git show-index`, warning when the detected algorithm doesn't match the default SHA-1. The second patch wraps error messages in gettext calls for translation support. Both changes touch only `builtin/show-index.c` while maintaining backward compatibility.

The series resolves an earlier discussion about warning suppression between Patrick Steinhardt (who favored explicit `--object-format` specification) and brian m. carlson (who proposed a `--quiet` flag). Junio's approval confirms the maintainer's position aligns with Patrick's approach - users should specify their object format rather than adding new suppression controls.

With this final ack, the technically non-controversial changes are now cleared for merging. The implementation is complete and addresses all feedback, though brian m. carlson's ongoing SHA-256 interoperability work may eventually make these warnings obsolete by encoding hash algorithms in index headers.
