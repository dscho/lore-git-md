This is a bugfix patch in the completed `git last-modified` series from Toon Claes. The patch adds validation to ensure the command's revision argument is a commit-ish object, preventing a BUG() when given a tree object directly (like `HEAD^{tree}`). It also adds test coverage for annotated tags and fixes an ambiguity in tag resolution during testing.

The change introduces `repo_peel_to_type()` to verify the input is commit-ish before proceeding, with a clear error message if not. The test suite is expanded to verify both the new validation (rejecting tree objects) and proper handling of annotated tags (by excluding a test-specific tag that would otherwise create ambiguity).
