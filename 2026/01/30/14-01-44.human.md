This is a refactoring patch that follows up on earlier feedback about path normalization in `path.c`. Pushkar Singh had originally proposed splitting `normalize_path_copy_len()` into three helper functions, but after Junio Hamano's review, this version keeps only the simplest helper (`skip_slashes()`) while reverting the other changes.

The patch extracts the slash-skipping logic into a new `skip_slashes()` function, which is called at three points in the original function where leading slashes need to be skipped. This is the only change that Junio found clearly improved readability. The other proposed helpers (`handle_dot_component()` and `strip_last_component()`) have been dropped per Junio's feedback that they made the code harder to follow.

The patch maintains all existing behavior (verified by the test suite) while making the slash-handling logic slightly more reusable and self-documenting. This appears to be a minimal, focused improvement that addresses Junio's concerns from the previous version. The changes are small and well-contained, touching only `path.c` with no test modifications needed.
