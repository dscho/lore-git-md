This is a performance optimization for the p3400 rebase test setup, now in its fourth iteration. Tian Yuchen's patch replaces the original shell-based commit generation (which spawned multiple processes per iteration) with a more efficient `git fast-import` approach that pre-computes file contents and streams the commits in bulk.

The key improvement is a 26% reduction in setup time (from 29.045s to 21.989s) while maintaining comparable rebase test performance (13.34s vs 12.84s). The patch addresses all substantive feedback from previous rounds, including:
- Using a temporary file for the fast-import stream (per Johannes Sixt and Junio C Hamano's recommendation)
- Proper error handling with `exit 1` in subshells
- Preserving formatting conventions like blank lines

The implementation pre-generates forward and reverse-sorted file contents (`content_fwd` and `content_rev`) to avoid repeated `test_seq`/`sort` calls, then creates 100 commit pairs via fast-import followed by a full repack to ensure consistent object storage. Reviewers have confirmed the technical approach is sound, with Johannes Sixt's v4 review focusing only on minor style polishing.

This optimization appears ready for merging, having addressed all technical concerns while delivering measurable performance benefit to the test that simulates rebasing across a noisy history. The changes are contained to the test script and don't affect production code.
