This is a documentation and code refactoring patch that's part of a series adding `--keys` functionality to `git repo` commands. The patch renames the output format "keyvalue" to "lines" across both the documentation and implementation, as the new name better describes the format's line-based nature without implying key-value pairing is required.

The change affects multiple files:
- Updates man page references to use "lines" instead of "keyvalue"
- Renames the `FORMAT_KEYVALUE` enum to `FORMAT_LINES` in the C code
- Updates test cases to use the new terminology

The patch has gone through several iterations (v1-v5) with input from Junio Hamano and Patrick Steinhardt, and appears ready for integration. The change is straightforward and mechanical, with no functional changes beyond the naming. This is the first of two patches in the final series, with the second patch presumably containing the remaining implementation details.
