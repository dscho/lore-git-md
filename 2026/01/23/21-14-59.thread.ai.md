Jean-Noël Avila's documentation standardization effort continues with parallel work converting multiple Git man pages (`git-submodule`, `git-show`, `git-clone`, `for-each-ref-options`, `pretty-formats.adoc`) to consistent AsciiDoc synopsis-style formatting, with Kristoffer Haugsbakk providing thorough review feedback. The v3 series includes completed conversions of `git-submodule.adoc` and `git-show.adoc` along with final polish on previously converted pages.

Key refinements include: standardizing option presentation to stuck form (`--option=<value>` per gitcli(7) conventions), fixing decoration option rendering (particularly `->` pointer symbols in `pretty-formats.adoc`), converting manual `*NOTE*` markup to proper AsciiDoc `NOTE:` macros, and standardizing placeholder formatting (`_<name>_`). The work introduces synopsis-style block definitions in `asciidoc.conf.in` and maintains cross-toolchain compatibility between asciidoc.py and asciidoctor.

For `git-submodule.adoc`, the conversion now uses proper stuck-form options (e.g. `--branch=<branch>`). The `git-clone.adoc` conversion has been finalized with consistent stuck-form options following Junio Hamano's endorsement of this convention. Remaining work includes addressing rendering nuances like decoration option consistency and potentially developing custom parser extensions for special character handling. The effort remains focused on documentation presentation quality without altering command behavior, with each iteration systematically improving formatting details across the targeted man pages.
