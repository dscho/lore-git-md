This is a technical discussion about object iteration in the ODB abstraction series, specifically addressing patch 06/14 which introduces `packfile_store_for_each_object()`. Taylor Blau raises concerns about the implementation's handling of the `object_info` struct when iterating through packed objects.

The key issue centers on potential fragility in how the patch reuses the request portion of an `object_info` struct across multiple objects while updating the response portion. Taylor suggests this could lead to subtle bugs if future changes to `packed_object_info()` make conditional field assignments. He proposes two alternative approaches: (1) splitting `object_info` into separate request/response structs to make the data flow clearer, or (2) pushing the responsibility for object info requests entirely onto the caller.

This discussion occurs late in a well-reviewed series where most technical decisions have already been settled.
