This is a release announcement for Git for Windows, a separate distribution from the main Git project. Johannes Schindelin announces Git for Windows 2.53.0-rc1, which tracks the upcoming Git 2.53.0 release while adding Windows-specific improvements.

The release includes several notable changes: a fix for Tab key behavior in Git Bash, updated dependencies (cURL 8.18.0, mimalloc 2.2.7), support for Microsoft Edit as a Git editor, and a new version of Git Credential Manager with native ARM64 support. Several bug fixes address installer display issues, I/O handling for Microsoft Store apps, and PDF/DOC diff generation.

The announcement provides SHA-256 checksums for multiple package variants (64-bit, ARM64, portable, MinGit) to verify downloads. As with all Git for Windows releases, this is maintained separately from the main Git project, though it builds upon the same core version (2.53.0-rc1). The changes are specific to the Windows platform and its toolchain.
