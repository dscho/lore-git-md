Jean-Noël Avila has completed a 4-patch series standardizing several Git man pages to the new AsciiDoc synopsis style, focusing on `git-submodule`, `git-clone`, `git-show`, and `pretty-formats` documentation. The changes are purely mechanical formatting improvements, systematically applying consistent patterns for command references, option descriptions, and placeholder syntax throughout the documentation.

Kristoffer Haugsbakk provided thorough technical review of the final patch converting `git-show` and `pretty-formats`, confirming the successful implementation of the new style while identifying some subtle rendering quirks. The discussion revealed challenges around HTML output formatting, particularly with `[synopsis]` blocks and cross-references between documents. Avila explained the technical tradeoffs between different verbatim formatting approaches and committed to addressing the remaining issues in a reroll.

The series represents another high-quality contribution to Git's ongoing documentation standardization effort, maintaining the project's commitment to clear, consistent man pages. With only minor formatting tweaks remaining, the work is ready for integration, continuing the systematic improvement of Git's documentation that Avila has been leading. The changes have no impact on Git's behavior - they simply make the existing documentation more readable and maintainable through consistent application of modern AsciiDoc conventions.
