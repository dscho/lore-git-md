Jean-Noël Avila has completed his 4-patch series standardizing several Git man pages to the new AsciiDoc synopsis style. The work covered `git-submodule`, `git-clone`, `git-show`, and `pretty-formats` documentation, making purely mechanical formatting improvements without changing any behavior. Each patch followed the same high-quality pattern: adding proper synopsis blocks, standardizing placeholder markup with _<placeholder>_ syntax, consistently using backticks for commands, and improving overall formatting consistency.

The series received no objections during review, as it's part of Avila's ongoing, uncontroversial effort to bring uniformity to Git's documentation. The final patch completed the work by handling `git-show` and `pretty-formats`, adding explicit block delimiters for examples and improving option list formatting. With this series now complete, these man pages join the growing set of documentation that follows the project's modern synopsis style standards.
