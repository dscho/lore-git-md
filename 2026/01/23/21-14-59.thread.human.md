Jean-Noël Avila continues his multi-year effort to standardize Git's documentation to a consistent AsciiDoc synopsis style, with parallel work progressing on several man pages including `git-submodule`, `git-show`, `git-clone`, and `for-each-ref-options`. The latest patch focuses on refining `git-show` and related pretty formats documentation, building on previous iterations that addressed other commands.

The changes introduce technical improvements to documentation presentation while maintaining compatibility with both asciidoc.py and asciidoctor toolchains. Key updates include standardized synopsis blocks, consistent placeholder formatting with `_<placeholder>_` notation, backtick-wrapped command names, and clearer hierarchical organization of the pretty formats section. As with all patches in this series, the changes affect only documentation formatting - no command behavior is modified.

Kristoffer Haugsbakk's review feedback continues to shape the effort, with systematic incorporation of precise formatting improvements. The work demonstrates meticulous attention to detail in converting legacy documentation to the new synopsis style while preserving all technical content, part of Avila's broader initiative to bring uniformity to Git's man pages.
