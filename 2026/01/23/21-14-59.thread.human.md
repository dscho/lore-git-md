Jean-Noël Avila's ongoing documentation standardization effort continues to systematically improve Git's man pages, with Kristoffer Haugsbakk providing thorough review feedback. The latest work focuses on refining the `git-clone` and `for-each-ref-options` documentation, building on prior improvements to `git-submodule` and `git-show`.

The changes maintain the project's strict focus on presentation rather than behavior, standardizing AsciiDoc formatting across multiple dimensions: converting shorthand options like `--[no-]reject-shallow` to explicit `--reject-shallow`/`--no-reject-shallow` forms, replacing manual `*NOTE*` markup with proper `NOTE:` macros, and consistently formatting placeholders as `_<when>_`. Haugsbakk's review confirms these changes while noting one remaining inconsistency in how long options are presented (with some using `--option=<value>` and others `--option <value>`), suggesting future alignment with gitcli(7) recommendations.

This collaborative effort exemplifies the project's meticulous approach to documentation quality, with each iteration refining formatting details through Avila's implementation and Haugsbakk's systematic review. The work maintains cross-toolchain compatibility between asciidoc.py and asciidoctor while improving clarity and consistency across Git's documentation.
