This is a bugfix series for the `git last-modified` command, addressing issues when non-commit revisions (like tree OIDs) are passed as input. The series builds on previous work that already fixed memory leaks and improved error handling.

The key fix in v4 adds validation to ensure the input is a commit-ish object, preventing a BUG() when tree OIDs are provided. The error message has been refined to be more specific ("revision argument 'X' is a tree, not a commit-ish") based on maintainer feedback. The series also includes test coverage for this case and cleans up some error message duplication.

The patches show careful attention to detail - each change is small and well-explained, with corresponding test updates. This represents the final hardening of the command after earlier rounds addressed terminology discussions and UX improvements. The implementation now robustly handles all input cases while maintaining clear error messages.
