This is a documentation patch series from Jean-Noël Avila, part of his ongoing effort to convert Git's man pages to a consistent AsciiDoc synopsis style. The series contains 4 patches that:

1. Converts `git-submodule` documentation to the new synopsis format
2. Finalizes the `git-clone` documentation conversion that was started earlier
3. Fixes style issues spotted in `git-clone` and `for-each-ref-options` docs
4. Converts `git-show` documentation to synopsis style

The changes are purely documentation formatting - no behavior is modified. The patches touch several documentation files in the `Documentation/` directory, with the bulk of changes being in `git-submodule.adoc` (369 lines changed) and `pretty-formats.adoc` (164 lines changed). 

This appears to be routine maintenance work as part of the established documentation standardization effort. The commit messages indicate the author is also catching and fixing some inconsistencies from previous conversion work. The changes are mechanical in nature and unlikely to be controversial.
