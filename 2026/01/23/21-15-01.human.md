This is a documentation patch that finalizes the conversion of `git-clone`'s man page to the project's standard synopsis style. It's the second in Jean-Noël Avila's 4-patch series modernizing documentation format.

The patch makes purely mechanical formatting changes to `Documentation/git-clone.adoc`, standardizing how command-line options are presented. It replaces mixed formatting (like `++--server-option=++__<option>__`) with consistent backtick-wrapped option names (like `--server-option=<option>`) and normalizes the presentation of option-value pairs (changing `-o` _<name>_ to `-o <name>`). 

These changes follow the established pattern of Jean-Noël's ongoing documentation conversion effort, bringing this file into alignment with the project's current documentation standards. The patch doesn't introduce any new content or behavioral changes - it's purely about presentation consistency. The changes are straightforward and unlikely to generate discussion, continuing the uncontroversial nature of this documentation modernization work.
