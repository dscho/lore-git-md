This is a documentation patch that concludes a thread about cleaning up the `git-replay` manual page and related linter updates. The work follows patterns previously established for `git shortlog` documentation.

The final state includes two key changes: First, `git-replay.adoc` now properly excludes the "Commit Formatting" section when included via `rev-list-options.adoc` by using a new `git-replay` attribute. Second, the documentation linter has been updated to better handle conditional blocks with multiple attributes, particularly the `ifndef` syntax used in this pattern.

Junio C Hamano initially adjusted the linter to handle the new syntax, and Jean-Noël Avila contributed a final refinement that simplifies the linter by treating conditional blocks (`ifdef`/`ifndef`/`endif`) as block-level constructs rather than trying to parse them as inline elements. This makes the linter more robust against false positives when checking `linkgit:` macro usage in files with complex conditionals.

All parties have signed off on their respective changes, and the work is now complete and merged. This contributes to the ongoing effort to standardize Git's manual pages using consistent AsciiDoc markup patterns.
