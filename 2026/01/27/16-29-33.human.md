This is a bugfix patch from Junio C Hamano addressing an inconsistency in `git switch`'s error messages. The issue occurs when `git switch` can't determine a unique remote tracking branch - currently the error message suggests using `git checkout --track` rather than the equivalent `git switch --track` syntax.

Junio's patch modifies the shared checkout/switch/restore implementation in `builtin/checkout.c` to track which command was invoked and show the appropriate suggestion. The change adds an enum to distinguish between the commands and propagates this information to the error message generation code. While the patch is incomplete (missing tests and some cleanup), Junio clearly states a preference for making the hint match the invoked command rather than always recommending `git switch`.

The change is straightforward and aligns with Git's ongoing effort to properly support the newer `git switch`/`git restore` commands while maintaining backward compatibility. Given Junio's role as maintainer and his explicit preference for this approach, this patch is likely to be accepted once completed with tests.
