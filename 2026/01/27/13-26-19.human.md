This is a bugfix patch in the completed `git last-modified` series from Toon Claes. It addresses a minor but noticeable UX issue where the command was showing two redundant error messages when users provided multiple revisions. 

The patch simplifies the error reporting by removing the less informative "unable to setup last-modified" message, leaving only the clear instruction that the command operates on one revision at a time. This change follows through on the series' broader effort to refine error messaging and user experience.

The technical change is straightforward - replacing an error() call with a simple return of -1 when path population fails. This is part of the final polish for this feature after the main functionality was merged, showing the project's attention to detail even in small quality-of-life improvements. The patch has already gone through several iterations (v5) and represents a mature, well-considered change.
