Junio Hamano's "What's cooking in git.git" report tracks in-flight patches across Git's integration branches (maint, master, next, seen). Current activity includes Jean-Noël Avila's man page conversion to synopsis style and new string_list API helpers, plus xdiff and ODB improvements. Recently graduated topics include Johannes Schindelin's Windows symlink support and CI optimizations. Git 2.53-rc2 was tagged with one reverted regression.

Derrick Stolee's `--maximal-only` rev-list option has reached consensus for merging into 'next'. The feature marks commit graph tips (commits not reachable from others) and was discussed in prior "What's cooking" reports. While there were suggestions to use `git merge-base --independent` or extend to other commands, Stolee confirms these can be deferred. The current implementation addresses the core use case cleanly and appears technically sound, representing a focused addition to Git's graph-theoretical optimization work. This joins Patrick Steinhardt's major ODB refactoring (16-part series introducing `odb_for_each_object()`) as active work, though the ODB changes still need review of mtime-related implications per Taylor Blau's request. Other active topics include Adrian Ratiu's hook API conversion, while configuration handling improvements and shallow clone fixes remain stalled.
