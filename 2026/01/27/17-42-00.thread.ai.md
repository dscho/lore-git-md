Junio Hamano's "What's cooking in git.git" report tracks in-flight patches across Git's integration branches (maint, master, next, seen). Current activity includes Jean-Noël Avila's man page conversion to synopsis style and new string_list API helpers, plus xdiff and ODB improvements. Recently graduated topics include Johannes Schindelin's Windows symlink support and CI optimizations. Git 2.53-rc2 was tagged with one reverted regression.

Active work includes Derrick Stolee's `--maximal-only` rev-list option, Adrian Ratiu's hook API conversion, and Patrick Steinhardt's major ODB refactoring. The latter has generated discussion around Patrick's 16-part series introducing `odb_for_each_object()` to replace specialized enumerators like `for_each_loose_object()`. While Taylor Blau supports the direction, he requests delay for mtime-related changes review, noting potential implications for Git's timestamp-based optimizations. This series is part of Patrick's broader ODB abstraction effort to enable pluggable storage backends. Several topics need rerolls or responses before progressing, while configuration handling improvements and shallow clone fixes remain stalled.
