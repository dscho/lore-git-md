Refactoring patch from the maintainer to improve `git switch`/`checkout`/`restore` command handling. This is the first of two patches that together address confusing advice messages when dealing with ambiguous remote branch names.

The patch introduces an enum to track which of the three commands (`checkout`, `switch`, or `restore`) is being executed, replacing the previous approach of passing usage strings directly. While there's no user-visible change yet, this internal restructuring enables the second patch to provide more accurate advice messages tailored to the specific command the user ran.

The changes are focused on the shared implementation in `builtin/checkout.c`, moving usage strings into the `checkout_main()` function and adding the new enum-based command tracking. This is a clean, mechanical refactoring that maintains all existing behavior while setting up for the improved messaging in the follow-up patch.
