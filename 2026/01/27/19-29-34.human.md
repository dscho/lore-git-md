This is a two-patch series from the Git maintainer Junio C Hamano that improves the advice messages from `git switch` when there are ambiguous remote branch names. The series addresses a specific case where `git switch` fails correctly when multiple remotes have branches with the same name, but gives advice mentioning `git checkout` instead of `git switch`.

The first patch refactors the internal call chain of checkout/switch/restore commands to pass a token identifying which command is being executed. This allows helper functions deeper in the call stack to know which top-level command invoked them. The second patch then uses this information to customize the advice message - when the command is `git switch`, it will now suggest using `git switch --track` rather than `git checkout --track`.

The changes are focused and well-motivated, with test coverage added to verify the improved advice messages. As a maintainer-authored series touching core command plumbing, this is likely to be merged quickly after any review feedback. The changes are non-controversial improvements to user experience when dealing with ambiguous branch names.
