Here's the latest update from Git's development front:

Junio Hamano's "What's cooking" report shows steady progress across multiple fronts. The documentation modernization effort led by Jean-Noël Avila continues with more man pages being converted to the new synopsis style format. On the technical side, significant work is underway with Patrick Steinhardt refactoring object enumeration APIs and Adrian Ratiu converting the hook API - both substantial architectural efforts.

Several important features have recently graduated to the main branch, including Johannes Schindelin's Windows symlink support and CI optimizations that speed up leak checking jobs. The project has also tagged Git 2.53-rc2, though one topic had to be reverted due to a regression.

Notable ongoing work includes Derrick Stolee's new `--maximal-only` option for rev-list and various low-level cleanups in the xdiff library and object database handling. Some topics have stalled and been dropped, including configuration handling improvements and shallow clone fixes that didn't receive follow-up attention. As always, Junio's report provides the essential pulse of the project's development in his characteristically concise style.
