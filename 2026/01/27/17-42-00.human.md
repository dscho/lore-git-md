This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various patches and topics in the Git development pipeline. The report covers new topics, graduated patches, ongoing work, and discarded efforts.

Several new documentation patches are being considered, including conversions of man pages to the modern "synopsis" style (led by Jean-Noël Avila) and API additions like `string_list_sort_u()`. There are also some low-level cleanups in the xdiff library and object database handling.

Notable graduated topics include Windows symlink support (from Git for Windows), CI optimizations to skip slow SVN tests in leak checking, and various documentation fixes. The Windows symlink work in particular represents a significant improvement in functionality for Windows users.

Several substantial ongoing efforts are highlighted:
- A new `--maximal-only` option for `rev-list` to show only unreachable commits
- Hook API modernization to replace direct `run_command()` calls
- Object database enumeration API improvements from Patrick Steinhardt
- Incremental MIDX repacking work from Taylor Blau
- SHA-1/SHA-256 interoperability work from brian m. carlson
- A new `git history` command for rewriting history

The report also lists several topics being discarded due to lack of activity or response to feedback, including some Windows path handling improvements, rebase trailer support, and shallow clone fixes.

This status report is particularly notable for showing the Windows symlink support graduating to master, the continued progress on the object database abstraction work, and the introduction of the `git history` command as a more user-friendly alternative to lower-level history rewriting tools. The volume of documentation modernization patches also stands out as an ongoing theme.
