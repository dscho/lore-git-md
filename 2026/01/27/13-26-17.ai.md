Bugfix patch refining error messaging in `git last-modified`. This is part of a completed series (v5) that has already been merged, now focusing on precise terminology and test coverage.

The patch corrects an error message in `git last-modified` that inaccurately referred to "trees" when the command actually operates on commits. The new message states clearly that only one commit can be processed at a time. The accompanying test is updated to verify both the error message content and its display when multiple commits are provided.

This change reflects the ongoing effort to ensure accurate terminology throughout Git's error messages and documentation. The patch is small but meaningful, demonstrating attention to detail in user-facing communication. Since this is part of an already-merged series, it represents final polishing rather than introducing new functionality.
