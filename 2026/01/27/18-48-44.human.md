This is a documentation patch that concludes a thread about cleaning up the `git-replay` manual page and related linter updates. The work follows a pattern previously established for `git shortlog` documentation.

The patch series had two main components: first, removing an unnecessary "Commit Formatting" section from `git-replay.adoc` by using conditional exclusion when included via `rev-list-options.adoc`, and second, updating the documentation linter to properly handle the new multiple-attribute `ifndef` syntax used in this pattern. 

D. Ben Knoble authored the original `git-replay` documentation change, while Junio C Hamano reviewed it and fixed an initial linter issue. Jean-Noël Avila then contributed a refined linter update to better handle conditional blocks. The final patch confirms that all changes have been merged, with all technical and tooling issues resolved.

This work is part of Jean-Noël Avila's broader effort to standardize Git's manual pages using consistent AsciiDoc markup. The changes work with both AsciiDoc processors (Python and Ruby implementations) and make the linter more robust against false positives when checking `linkgit:` macro usage in files with complex conditionals.
