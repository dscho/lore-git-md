This is a review comment on Junio C Hamano's patch series improving `git switch` advice messages for ambiguous remote branch names. Kristoffer Haugsbakk provides feedback on the second patch, which modifies the advice text to match the command actually used (`checkout` vs `switch`).

The review focuses on the test coverage added in the patch. Kristoffer questions the need for the `git update-ref -d` cleanup step between test cases, noting it doesn't appear necessary for the test to pass. They also suggest the negative `test_grep` assertions (verifying the wrong command doesn't appear) might be overkill and could confuse future readers, proposing to focus just on the positive matches.

Kristoffer considers but ultimately rejects the idea of parameterizing the test helper, recognizing that while it would reduce duplication, it would make the test's purpose less immediately clear when grepping the test file. The review maintains a constructive tone while questioning some implementation choices, suggesting possible simplifications to the test structure.
