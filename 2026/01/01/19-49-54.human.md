This is the final version (v10) of a feature enhancement for `git status` that shows divergence from the push/tracking branch. After 10 iterations and a significant design pivot from the original approach (which proposed a new `status.goalBranch` config), the series now uses Git's existing branch tracking mechanisms as suggested by Ben Knoble and requested by Junio Hamano.

The implementation now checks `branch.<name>.pushRemote` when available, falling back to the tracking branch if unset. The feature shows divergence information in status output only when the target differs from the tracking branch, with example output like 'upstream/main'. The test suite has been thoroughly updated to focus on the pushRemote behavior while maintaining all 12 test scenarios from previous versions.

The author has addressed all technical feedback through the 10 iterations, with optimizations like single ref resolution and consolidated memory management preserved from earlier versions. The thread demonstrates how community feedback shaped the feature from its initial proposal to a solution that aligns with Git's existing patterns. This appears ready for final review and potential merging.
