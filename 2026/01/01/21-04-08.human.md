This is a UI improvement patch for `git add -p` submitted as part of Google Summer of Code (GSoC). The patch addresses a usability issue where users couldn't see their previous hunk selection decisions (use/skip) when navigating between hunks during interactive staging/unstaging operations.

The change modifies the prompt strings in `add-patch.c` to include the user's prior decision ("use" or "skip") before showing the standard selection options. This helps users maintain context as they move between hunks using the K/J navigation keys. The patch was originally reported by Junio C Hamano and has been revised in v2 to better handle the decision display across all interactive patch modes (stage, stash, reset, checkout, etc.).

The implementation is straightforward - it adds a new string insertion point in each prompt format string and fills it with the previous decision when displaying hunks. The changes are mechanical but touch many prompt strings to maintain consistency across all interactive patch operations. The patch appears well-scoped and focused on the specific UI improvement it aims to make.
