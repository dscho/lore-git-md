This is a test patch that converts TODO placeholders into actual tests for skip-worktree behavior. The patch comes from K Jayatheerth as part of Google Summer of Code (GSoC) participation.

The test file t7012-skip-worktree-writing.sh previously had several TODO comments indicating planned test coverage for how various commands interact with skip-worktree entries. This patch implements those tests, covering git-apply (adding, updating, and removing files), git-mv (moving to and from skip-worktree), and git-checkout operations.

The results show that three operations work correctly (marked as test_expect_success): git-apply for adding files, git-mv to skip-worktree, and git-checkout. Two operations fail as expected (marked as test_expect_failure): git-apply for updates/removals and git-mv from skip-worktree. The tests include proper cleanup via test_when_finished blocks and verify both filesystem state and index contents.

The patch is well-structured with clear commit message documentation of what's being tested and the expected outcomes. It follows Git's test script conventions and appears to be a solid contribution that fills in missing test coverage for edge cases around skip-worktree handling.
