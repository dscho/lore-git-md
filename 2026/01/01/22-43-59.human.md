This is the final patch in a documentation series improving the `git reset` man page, focusing on clarifying the pathspec behavior. The patch simplifies the language around `git reset <pathspec>` and `git reset -p`, addressing specific user confusion points.

The changes replace technical terms like "tree-ish" and "hunks" with more accessible language ("commit or tree" and "changes"). It also makes clearer that `git reset` only updates the index, not working tree files, and recommends `git restore` when file updates are needed. The interactive mode description is similarly simplified while maintaining accuracy.

This patch completes a well-coordinated effort between Julia Evans (who provided the pedagogical foundation), D. Ben Knoble (who shepherded the series), and Junio Hamano (who provided technical oversight). The series is now in its final form with all technical concerns addressed, ready for merging. The changes touch only documentation with no behavior modifications.
