This is the final patch in a v3 documentation series improving the `git reset` man page, with contributions from Julia Evans, Junio Hamano, and D. Ben Knoble. The patch focuses on clarifying the pathspec-related behavior of `git reset`, addressing specific user confusion points that emerged from earlier versions.

The changes simplify terminology by replacing "tree-ish" with "commit or tree" and "hunks" with "changes", making the text more accessible. It also corrects a misleading implication that `git reset` updates working tree files - the documentation now explicitly states it only affects the index, and recommends `git restore` when file updates are needed. The interactive mode (`-p`) description is similarly clarified to emphasize its role in selectively unstaging changes.

This patch completes the series' goal of making `git reset` documentation both technically precise and pedagogically clear. With all four patches now in their final form and signed off by both the original contributor (Julia Evans) and the project maintainer (Junio Hamano, the series appears ready for merging. The collaborative process has successfully addressed all identified documentation challenges while maintaining the command's technical accuracy.
