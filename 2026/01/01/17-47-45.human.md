This is Junio C Hamano's monthly "What's cooking in git.git" report, providing a comprehensive overview of the current state of development branches and in-flight topics. The report covers 50+ active topics across various stages of integration, from experimental work in 'seen' to stable patches in 'next' ready for the next release.

Key highlights from this January 2026 report include:

Several notable features are cooking:
- Patrick Steinhardt has implemented Linux filesystem monitoring (fsmonitor) support
- Windows symlink support from Git-for-Windows is being upstreamed in a 19-patch series
- Christian Couder is working on "auto filter" logic for large-object promisor remotes
- Adrian Ratiu converted hook script handling to use the new hook API

Important fixes and improvements:
- Derrick Stolee fixed a use-after-free in diff with lazy fetching
- Elijah Newren corrected recursive submodule/directory conflict handling in merge-ort
- René Scharfe continued the `the_repository` removal effort with tag.c conversions
- Multiple test fixes for flaky tests and platform-specific issues

Documentation work continues with:
- Jean-Noël Avila's ongoing synopsis-style conversion of man pages
- Ben Knoble's improvements to `git-reset` documentation
- The report shows healthy activity across all areas - from core functionality to platform support and documentation. Many topics are marked as ready for 'next' or 'master', while others await review feedback or reworks. Junio notes several topics that may be discarded if they don't gain enough support.

This snapshot reflects Git's continued evolution, with particular focus on platform support (Windows, macOS), performance (ODB abstraction, MIDX improvements), and code quality (the_repository removal, hook API conversion). The breadth of activity demonstrates the project's vitality as it approaches its third decade.
