Documentation patch (part 1/4) reorganizing the `git reset` man page forms. This patch reorders the command synopsis to prioritize the `git reset [mode]` form first, based on user feedback that this is the most commonly used variant. The change makes the documentation flow better by matching the order to how users typically interact with the command, while maintaining all technical accuracy.

The patch moves the branch-head-resetting form to the top of the SYNOPSIS section, followed by the path-based forms. This reflects that resetting HEAD is `git reset`'s unique capability, while the path operations could also be done via `git restore`. The diff shows the straightforward reordering of sections without any content changes beyond their sequence.

This is the first of four patches in a v3 series that has already incorporated Junio Hamano's technical review feedback. The series as a whole aims to improve both the pedagogical clarity and technical precision of the `git reset` documentation, building on Julia Evans' initial work. The patch carries both Evans' and Hamano's sign-offs, indicating their approval of the changes.
