This is the concluding patch in a 10-iteration series that enhances `git status` to show divergence from a push/tracking branch. The feature has evolved significantly from its original design (which proposed a new `status.goalBranch` config) to now using Git's existing branch tracking mechanisms (`branch.<name>.pushRemote` and tracking branches) after feedback from Junio C Hamano and Ben Knoble.

The final implementation shows the push/tracking branch divergence in status output only when it differs from the current branch, with optimized ref resolution and memory management. The test suite has been thoroughly updated to verify the pushRemote-based behavior across various scenarios (ahead/behind states, different remote configurations, edge cases).

The patch appears to have addressed all previous technical concerns while maintaining the feature's utility through Git's standard patterns.
