Bugfix targeting the interactive patch selection UI (`git add -p` and related commands). This is the second version of a Google Summer of Code contribution that improves usability by showing users their previous hunk selection decisions when navigating between hunks.

The patch modifies the prompt strings in all patch mode structs (`add_p`, `checkout_p`, `reset_p`, `stash_p`) to include a decision text placeholder. The display logic in `patch_update_file()` is updated to show either "(previous decision: use)", "(previous decision: skip)", or nothing for new hunks, based on the hunk's `use` field. The changes affect all interactive patch operations (stage, stash, reset, checkout).
