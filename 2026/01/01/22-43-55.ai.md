This is a documentation patch series (v3) updating the `git reset` man page, building on Julia Evans' earlier work to improve clarity and pedagogical approach. The series is now reached its final form after incorporating Junio Hamano's technical review feedback.

The four patches systematically reorganize and clarify the DESCRIPTION section of `git-reset.adoc`. Patch 1 reorders the command forms for better logical flow, patch 2 restructures the introduction, patch 3 clarifies the behavior of `git reset [mode]`, and patch 4 (the focus of this revision) precisely describes the behavior of `git reset <pathspec>`. The key change in v3 is a technical refinement to the description of `git reset -p` behavior, now accurately stating that "The index is modified using the chosen changes" rather than implying directionality.

This represents the culmination of collaborative work between Julia Evans (original pedagogical approach), D. Ben Knoble (series shepherding), and Junio Hamano (technical review). All open questions from previous iterations have been resolved, particularly around the precise behavior of interactive reset (`-p`). The changes are purely documentation improvements with no command behavior modifications. The series is now in its final form and ready for merging.
