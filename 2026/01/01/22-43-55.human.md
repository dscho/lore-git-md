This is a documentation patch series (v3) updating the `git reset` man page, building on Julia Evans' earlier work to improve clarity and technical accuracy. The series has been shepherded by D. Ben Knoble with input from Junio Hamano.

The four patches restructure and clarify the DESCRIPTION section of the man page, with v3 specifically addressing Junio's feedback about the `git reset -p` behavior description. The key change in this version is a more precise explanation of how `reset -p` modifies the index, now stating that "The index is modified using the chosen changes" rather than saying changes are "added" to the index. This better reflects the command's actual behavior where the direction of modification depends on the target commit.

The series appears ready for merging, having addressed all technical concerns raised in previous rounds. It maintains Julia Evans' pedagogical approach while incorporating Junio Hamano's technical refinements. The changes are focused solely on documentation - no command behavior is altered. This represents the culmination of an effort to modernize the `git reset` documentation while preserving consistency with related commands like `git restore`.
