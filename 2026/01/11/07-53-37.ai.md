Test modernization patch in the post-checkout hook test series. This is a follow-up review from Eric Sunshine on Deveshi Dwivedi's patch that introduced a helper function for validating post-checkout hook arguments.

The patch adds a `check_post_checkout` helper to t5403-post-checkout-hook.sh that consolidates the repeated pattern of reading and validating hook arguments (previous HEAD, new HEAD, and flag). While the implementation is technically sound, Eric points out that the function lacks proper documentation about its parameters. He suggests following the pattern seen in test-lib-functions.sh where helper functions include clear "Usage:" comments explaining each argument's purpose.

This is a minor but important documentation improvement for test infrastructure. Eric's review reflects his characteristic attention to detail in test code quality and specifically to making test helpers self-documenting. The feedback doesn't challenge the technical approach but rather ensures the change meets the project's standards for maintainable test code. The suggestion aligns with the broader test modernization effort's goal of improving clarity and reducing cognitive overhead for future maintainers.
