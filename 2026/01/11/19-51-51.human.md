This is a platform compatibility patch addressing an issue with iconv on macOS 14/15. Torsten Bögershausen builds on a previous commit that introduced a workaround for broken iconv implementations by now enabling that workaround specifically for macOS systems where the native iconv is buggy and no alternative (working) libiconv is installed via Homebrew, MacPorts, or Fink.

The patch modifies the Makefile to:
1. Check additional paths for libiconv (including a new default Fink path at /opt/sw)
2. Set a HAS_GOOD_LIBICONV flag when a working libiconv is found
3. Enable the ICONV_RESTART_RESET workaround when no good libiconv is available
4. Update config.mak.uname to mark macOS 14+ as needing this check

This appears to be a well-scoped fix for a specific platform issue, with clear logic to detect available iconv implementations. The changes are focused on the build system without affecting runtime behavior when working alternatives are present. The patch follows Git's established patterns for platform-specific workarounds.
