This is a documentation patch series that has completed its review cycle and received maintainer approval. The two patches convert the `git-blame` man page and its included options file to the new synopsis-style documentation format, following the project's standardization effort led by Jean-Noël Avila.

The series was originally sent by Michael Lyons, who incorporated detailed feedback from Jean-Noël (the documentation maintainer) in v2. Changes included splitting the work into two patches (one for the main file and one for options), standardizing backtick usage for options and placeholders, improving grammar in the `--progress` option description, and ensuring consistent formatting throughout. Jean-Noël has now given his approval ("LGTM"), indicating the patches meet the project's documentation standards.

This is a mechanical conversion that doesn't change the actual content - just the formatting and presentation. The work is part of a larger, ongoing effort to bring all Git documentation to a consistent style. With the maintainer's approval, these patches are now ready to be merged into the main Git repository.
