This is a test modernization patch that updates t1410-reflog.sh to use the preferred test_path_is_* helpers instead of raw test commands. The change replaces four instances where the test was checking for file existence/absence with the more robust test helpers that provide better diagnostics on failure.

The patch is straightforward - it converts:
- `test -f` to `test_path_is_file`
- `! test -f` to `test_path_is_missing`

This aligns with the ongoing effort to modernize Git's test suite by using the standard test helpers rather than raw shell test commands. The changes don't affect test behavior, just improve failure reporting. The patch is small, focused, and follows the established pattern for this type of test modernization.
