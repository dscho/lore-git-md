This thread addresses platform compatibility issues with iconv implementations on macOS, particularly versions 14 and 15. The initial patch introduced a workaround for broken iconv behavior, and this follow-up extends that solution to handle macOS-specific cases more robustly.

The latest patch improves the build system's detection of working libiconv installations from common macOS package managers (Homebrew, MacPorts, and now Fink). When no properly functioning libiconv is found on macOS 14+, it automatically enables the ICONV_RESTART_RESET workaround. The changes maintain backward compatibility while specifically addressing the newer macOS versions where the iconv issues are most problematic.

The solution follows Git's approach to platform-specific workarounds, carefully scoped to only affect the targeted systems. The commit message provides clear rationale and implementation details, making this a straightforward improvement to Git's macOS support.
