This is a platform compatibility patch series addressing iconv issues on macOS 14/15. The two-patch series from Torsten Bögershausen provides a workaround for problems with the system iconv implementation in recent macOS versions.

The first commit prepares the infrastructure by adding build system support to detect and use alternative iconv implementations from package managers like Homebrew, MacPorts, or Fink. The second commit enables the workaround in utf8.c, which handles character encoding conversions. The patches touch the Makefile, config.mak.uname, and utf8.c files.

The series has already gone through one revision based on feedback from René Scharfe, with improvements to the commit message and clarification that the workaround supports various installation locations for third-party iconv libraries. The changes appear focused and well-motivated, addressing a specific platform compatibility issue that could affect users trying to work with non-ASCII encodings on newer macOS systems.
