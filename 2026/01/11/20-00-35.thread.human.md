This thread documents a successful collaboration between GSoC participant Shreyansh Paliwal and experienced Git developers to modernize test #365 in t5500-fetch-pack.sh, which verifies shallow fetch behavior with commit graphs. The original approach using temporary files raised concerns from Junio Hamano about shell portability and exit code masking.

Through two iterations with guidance from Patrick Steinhardt, the solution evolved to use `test-tool pkt-line pack` to properly format protocol input while maintaining test functionality. Junio has now given his approval, praising this as the right approach that handles packet formatting internally. The final solution stores object IDs in shell variables and cleanly separates packet generation from upload-pack invocation.

This thread serves as a model for similar test modernization work, particularly for tests requiring protocol interaction. The collaboration between a new contributor and experienced maintainers demonstrates Git's mentoring process in action, resulting in a robust solution that addresses all original concerns about exit code propagation and portability. With Junio's approval, this approach is now ready to be implemented.
