This is a platform compatibility patch series addressing iconv behavior on macOS 14/15. The two-patch set builds on René Scharfe's earlier workaround for macOS iconv quirks that was already merged into master.

The first patch adds build infrastructure - a new ICONV_OMITS_BOM Makefile variable and corresponding config.mak.uname setting specifically for macOS. The second patch implements the actual workaround in utf8.c to handle cases where macOS's iconv omits byte order marks during UTF encoding conversions. The changes are minimal (just 21 lines across 3 files) and narrowly targeted at this specific platform quirk.

The maintainer (Junio C Hamano) has acknowledged the series and indicates he will apply it on top of master.
