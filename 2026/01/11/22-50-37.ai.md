Junio C Hamano responds to Shreyansh Paliwal's RFC patch that modified test #365 in t5500-fetch-pack.sh to pre-compute object IDs into files before upload-pack interaction. Junio raises two technical concerns: 1) using temporary files for object IDs is unusual compared to shell variables, and 2) the $(<file) construct is non-portable (bash-specific). He notes the changes don't actually address the exit code suppression issue since pipe behavior would still mask failures.

The response suggests the approach may not be solving the intended problem while introducing new portability concerns. Junio's comments indicate this particular change may need rethinking, though the broader GSoC goal of making tests more robust remains valid.
