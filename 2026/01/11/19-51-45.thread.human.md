This thread addresses iconv compatibility issues on recent macOS versions (14/15). Torsten Bögershausen has sent a two-patch series that provides a workaround for problems with the system's iconv implementation. 

The first patch adds build system support to detect and use alternative iconv implementations from package managers like Homebrew, MacPorts, or Fink. The second modifies utf8.c to enable the workaround for character encoding conversions. René Scharfe reviewed the initial version, leading to improved commit messages and clearer documentation about supporting various third-party iconv installation locations.

The changes are narrowly focused on this macOS-specific issue, touching only the Makefile, config.mak.uname, and utf8.c files. The series is now in its second iteration (v2) with no outstanding objections, suggesting it may be ready for merging pending final maintainer review.
