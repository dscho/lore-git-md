This is a platform compatibility patch targeting macOS systems. It extends the workaround for broken iconv implementations introduced in the previous patch (part 1 of this series) to handle macOS 14/15 specifically.

The patch modifies the build system to detect whether a working libiconv is available from common macOS package managers (Homebrew, MacPorts, Fink). If no good libiconv is found, it enables the `ICONV_RESTART_RESET` workaround by default for macOS versions 14+. The changes include:

1. Adding detection for Fink's new default path at `/opt/sw`
2. Setting `HAS_GOOD_LIBICONV` when a known-good libiconv is found
3. Adding `NEEDS_GOOD_LIBICONV` for macOS 14+ in config.mak.uname
4. Only applying the workaround when no good libiconv is available

The patch appears well-scoped and follows Git's established patterns for platform-specific workarounds. It maintains compatibility with existing setups while addressing a specific macOS 14/15 issue. The commit message clearly explains the motivation and scope of changes.
