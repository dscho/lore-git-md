This is a documentation patch completing a two-part test modernization series for the post-checkout hook tests in t5403. The patch adds proper documentation for the `check_post_checkout` helper function that was introduced in the first patch of the series.

The helper function verifies post-checkout hook arguments by reading from a file and comparing against expected values. The new documentation follows test-lib-functions.sh conventions with a "Usage:" comment that clearly explains: (1) function parameters (args-file, old, new, flag), (2) what the function verifies (old/new object IDs and flag value), and (3) the meaning of the flag parameter (1 for branch switch, 0 otherwise).

This change directly addresses the review feedback from Eric Sunshine and Pushkar Singh on the first patch, which noted the helper needed better documentation. The implementation matches the established pattern seen elsewhere in the test suite for documenting helper functions. The patch is small and focused, completing the modernization effort for this test script by ensuring the new helper is properly documented for future contributors.
