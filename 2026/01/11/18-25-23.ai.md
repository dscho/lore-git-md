The discussion confirms this is a legitimate issue affecting real-world deployments (particularly with journald logging) and that the proposed solution is architecturally sound. The patch remains narrowly focused on the two NORETURN functions in http-backend.c, with no changes to the actual error handling logic or HTTP response behavior.
