Platform compatibility patch series addressing iconv issues on macOS 14/15, from Torsten Bögershausen. Two-patch series providing workaround for system iconv problems in recent macOS versions.

Core problem: macOS 14/15 system iconv implementation has issues affecting character encoding conversions, particularly for non-ASCII encodings. Solution detects and uses alternative iconv implementations from package managers (Homebrew, MacPorts, Fink).

Current status: v2 series incorporating feedback from René Scharfe on commit message clarity and support for multiple third-party iconv installation locations. Files touched: Makefile, config.mak.uname, utf8.c.

Key technical details: First patch adds build system infrastructure to detect alternative iconv implementations. Second patch implements the workaround in utf8.c for character encoding conversions. Supports various installation locations of third-party iconv libraries.

Participant positions: René Scharfe reviewed v1, suggested improvements to commit message and installation location handling, which were incorporated in v2. No outstanding objections or requested changes.
