This is a test modernization patch that's part of a two-patch series to improve the post-checkout hook testing in t5403. The patch introduces a new helper function `check_post_checkout()` that consolidates the repetitive pattern of validating post-checkout hook arguments across multiple test cases.

The helper function takes four arguments: the path to the hook's argument file, and the expected values for the previous HEAD, new HEAD, and flag (indicating whether this was a branch switch). It replaces the previous pattern of manually reading and comparing each argument value, making the tests more maintainable and consistent.

The patch touches only the test script (t/t5403-post-checkout-hook.sh) and is purely a refactoring - there are no behavior changes to Git's production code. This appears to be part of the ongoing test modernization effort in the Git project, following established patterns of replacing shell test patterns with helper functions for better maintainability and failure diagnostics.

The changes are mechanical but well-contained, converting all existing test cases that verify post-checkout hook arguments to use the new helper while preserving their original assertions. The helper includes a BUG check to ensure it's called with the correct number of arguments, which helps catch test authoring mistakes early.
