This is the first patch in a 6-part bugfix and test coverage series for `git replay` error handling when given invalid commit-ish arguments. The series has gone through multiple rounds of review (now at v3) with feedback from Elijah Newren, Phillip Wood, and Junio Hamano incorporated.

The patch removes dead code in `builtin/replay.c` related to a removed "guess mode" feature that was never actually implemented. The function `determine_replay_mode()` is renamed to `set_up_replay_mode()` (per Junio's suggestion) to better reflect its actual behavior of setting up replay parameters rather than determining mode. The changes are straightforward cleanup - removing an unused code path that could never be reached since one of `--onto` or `--advance` is mandatory. The patch also consolidates some conditional blocks now that the dead code is gone.

This is a mechanical refactoring that improves code clarity without changing behavior. The series as a whole aims to improve error handling and test coverage for `git replay`, with this first patch laying groundwork by cleaning up the code structure. The subsequent patches will build on this to add better validation and user feedback.
