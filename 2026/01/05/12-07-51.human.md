This is a build system patch adding Linux fsmonitor support to Git's Meson build configuration, complementing the ongoing fsmonitor implementation effort. The patch comes from Patrick Steinhardt in response to Paul Tarjan's v4 Linux fsmonitor patch series.

The change enables the Linux fsmonitor backend in Meson builds when on Linux with pthreads available and the linux/magic.h header present. It mirrors the existing conditions for Windows and macOS fsmonitor backends. The patch is small and straightforward, adding the necessary build flags to support the Linux-specific filesystem monitoring code.

Patrick notes this could be included in Paul's series or sent separately after the main fsmonitor work lands. The tone is collaborative, suggesting this as a natural follow-up to the core implementation. Given Patrick's role as a major contributor to Git's build system and infrastructure, this suggestion carries weight as an important but non-blocking addition to the fsmonitor work.

The patch appears technically sound and well-motivated, addressing a clear gap in the build system support for the new Linux fsmonitor backend. It follows the established pattern for platform-specific fsmonitor configuration while adding the Linux-specific requirements (pthreads and magic.h detection).
