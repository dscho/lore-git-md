This thread began as a bug report from Gusted about two issues with `git last-modified`: a memory safety bug causing crashes when processing refspec paths (like HEAD:LICENSES), and suboptimal error messages for missing paths. The crash has been resolved by commit 05491b90ce on master, which Gusted confirms works in their Forgejo integration. Patrick Steinhardt validated the fix and has now raised the question of whether this memory safety fix should be backported to the upcoming v2.52.1 maintenance release, CC'ing Junio Hamano for input.

The second issue - improving the error messaging when paths are missing (currently showing "unknown revision or path" even with `--` disambiguation) - remains open for future discussion. The thread has now shifted focus to the backport decision, with the technical solution for the crash already implemented and verified in production.
