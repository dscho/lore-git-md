This thread documents a straightforward conversion of the `git-blame` man page to the new synopsis-style format, part of Jean-Noël Avila's ongoing effort to standardize Git's documentation. The patch updates both the main `git-blame.adoc` and its included `blame-options.adoc` file with consistent formatting: wrapping options in backticks, using underscores for placeholders, and applying the standard `[synopsis]` directive. The changes are purely presentational, maintaining all existing content while bringing the formatting in line with current documentation standards. This follows the established pattern seen in other documentation conversions across the project.
