Michael Lyons' two-patch series converting the `git-blame` documentation to the project's standard synopsis-style format has been merged into Git. The series, which splits the conversion between the main `git-blame.adoc` file and its included `blame-options.adoc`, received detailed review from documentation maintainer Jean-Noël Avila. All feedback was addressed in v2, including improved option documentation (particularly for `--progress`) and strict adherence to the project's markup conventions for backticks, placeholders, and command syntax. 

This work continues Jean-Noël's ongoing effort to standardize Git's man pages, following the same pattern successfully applied to `git-log`, `git-diff`, and others. With the maintainer's approval ("LGTM") and Junio's merge, the `git-blame` documentation now matches the project's current style standards. The changes are purely presentational - the content remains the same, just formatted more consistently with other commands' documentation.
