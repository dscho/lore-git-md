This thread documents Michael Lyons' work to convert the `git-blame` man page to the new synopsis-style format, part of Jean-Noël Avila's ongoing effort to standardize Git's documentation. The initial patch was split into two parts following maintainer feedback - one for the main `git-blame.adoc` file and another for the included options file.

The changes are mechanical formatting updates rather than content changes, bringing the documentation in line with project standards: wrapping options in backticks (like `` `-c` ``), using underscores for placeholders (_<file>_), and applying consistent markup. Notable improvements include clearer porcelain format documentation and more precise handling of the `-L` range syntax.

Michael has been responsive to Jean-Noël's maintainer feedback throughout the process. The first patch covering the options file was well-received, and this second patch for the main file appears equally polished. With both parts now submitted following the maintainer's guidance, the series seems ready for final review and merging into the broader documentation standardization effort that has already converted many other man pages.
