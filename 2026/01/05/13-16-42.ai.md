This is the second patch in Patrick Steinhardt's series to fix geometric repacking with promisor remotes, part of his ongoing repack machinery overhaul. The patch refactors the geometric repack calculation logic to make it reusable for upcoming promisor pack handling.

The change extracts the core geometric progression calculation from `pack_geometry_split()` into a new static function `compute_pack_geometry_split()`. This prepares for a future patch that will need to perform similar calculations for promisor packs. The refactoring maintains all existing behavior while making the logic more modular.

Key technical details:
- Moves the split calculation algorithm to a standalone function
- Takes pack array and split factor as parameters rather than using geometry struct directly
- Preserves all overflow checks and error handling
- No functional changes - existing callers continue working as before
- Part of groundwork for promisor pack support in geometric repacking
