Documentation patch (part 4/4) finalizing improvements to the `git reset` man page. This patch focuses on clarifying the command's modes (`--soft`, `--mixed`, `--hard`, etc.) based on user feedback about confusion in the existing documentation.

The changes reorganize and reword the mode descriptions to be more intuitive, with several key improvements: consistently using "index" instead of "index file", better explaining the obscure `--merge` mode by noting its specialized use cases, and restructuring the `--soft`/`--mixed`/`--hard` explanations to first describe working directory impacts (what users most want to understand) before discussing index changes. The patch also adds a practical example for `--soft` showing how to combine commits.

This is the final iteration (v4) of a series that was already technically complete in v3; these changes represent last-minute formatting and explanatory polish identified after merging. The patch maintains all the substantive content from the approved v3 version while making the documentation more approachable.
