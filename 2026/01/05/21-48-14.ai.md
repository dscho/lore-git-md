This is a documentation patch series (v4) for the `git reset` man page, following up on the already-merged v3 series. The changes address post-merge feedback from Jean-Noël Avila regarding formatting consistency.

The v4 changes are minor stylistic tweaks to the already-approved content: adding backticks around "HEAD" references and converting mode descriptions to imperative mood (e.g., "Leave your working directory unchanged" -> "Leave your working directory unchanged"). These changes don't affect the technical content but improve consistency with Git's style guidelines.

D. Ben Knoble is shepherding this series, which builds on Julia Evans' original pedagogical improvements and incorporates feedback from Junio Hamano and Jean-Noël Avila. The series has already gone through three rounds of review and was merged; this v4 iteration addresses purely cosmetic post-merge observations.

The patches maintain all the substantive improvements from v3, including clearer explanations of reset modes, better organization of command forms, and explicit recommendations to use `git restore` for file updates. The current changes are the final polish on a documentation effort that has already resolved all technical concerns through previous iterations.
