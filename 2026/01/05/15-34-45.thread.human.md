This thread discusses a proposal to add Bazel build support to Git, similar to the existing Meson build system. Son Luong Ngoc has implemented a working Bazel configuration in their fork that can run most tests on Linux, but it's currently a single invasive commit adding BUILD files throughout the repository. The author is seeking co-maintainers, as they only plan to support major releases rather than continuous maintenance.

Two potential paths are presented: finding collaborators to maintain Bazel support in-tree, or publishing it as an external overlay via the Bazel Central Registry. The proposal comes amid Git's ongoing build system modernization, which recently added Meson alongside the traditional Makefile. The key open question is whether there's enough community interest and maintenance capacity to justify adding another build system to the core repository.
