This is a documentation patch converting the `git-blame` man page to the new synopsis-style format as part of Jean-Noël Avila's ongoing documentation standardization effort. The changes are purely formatting - no content is modified, only presentation.

The patch updates both the main `git-blame.adoc` file and its included `blame-options.adoc` to use consistent markup conventions:
- Options are now wrapped in backticks (`` `-M` ``) instead of bare hyphens
- Placeholders use _underscores_ (`` _<file>_ ``) rather than angle brackets
- Math and commit references are also underscored for consistency
- The SYNOPSIS section uses the new `[synopsis]` directive

The changes follow the established pattern seen in other documentation conversions, applying mechanical formatting updates without altering the actual command descriptions or behavior. This appears to be a straightforward, well-executed conversion that maintains all existing content while bringing the formatting in line with current standards.

For future reference in this thread: the patch touches Documentation/blame-options.adoc and Documentation/git-blame.adoc, standardizing option formatting (`-option` -> `` `--option` ``), placeholders (`<file>` -> `` _<file>_ ``), and adding synopsis markup. No functional changes to blame behavior or existing documentation content.
