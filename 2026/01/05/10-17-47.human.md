This is the final version of a feature enhancement for `git status` that shows divergence from both upstream and push tracking branches. The 2-patch series by Harald Nordgren has gone through 17 iterations with extensive review from Junio C Hamano, Phillip Wood, and others.

The first patch refactors the branch comparison formatting code to be more modular, separating the message generation from advice logic. This preparatory work fixed several edge cases around quick mode and gone branches, with Junio identifying and helping resolve a critical control flow issue.

The second patch implements the core feature - showing how the current branch relates to its push tracking branch (configured via `branch.<name>.pushRemote`) in addition to the upstream branch. The output clearly indicates when branches diverge from either reference, with appropriate advice messages. For example, it can now show that your branch is up-to-date with upstream/main but ahead of origin/feature.

The series adds comprehensive test coverage, including new tests for the `--no-ahead-behind` quick mode. All technical concerns have been addressed through the review process, with the implementation now handling custom refspecs, various branch states, and maintaining compatibility with existing behavior. The patches are well-structured and ready for merging after this thorough vetting.
