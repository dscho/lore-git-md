[PATCH 0/5] Fix geometric repacking with promisor remotes

Series from Patrick Steinhardt addressing incompatibility between geometric repacking and promisor remotes in his ongoing repack machinery overhaul. Core problem: current geometric repack fails with promisor packs due to conflicting pack-objects flags and lack of promisor pack handling. Final patch completes the solution by implementing separate geometric progression for promisor packs.

Changes in v1:
- First patch modifies pack-objects.c to allow combining --stdin-packs with --exclude-promisor-objects, fixing their previous mutual exclusion
- Second patch refactors geometric repack calculation logic by extracting core algorithm from pack_geometry_split() into reusable compute_pack_geometry_split()
- Third patch refactors promisor object repacking logic by extracting finalization step into separate finish_repacking_promisor_objects() from repack_promisor_objects()
- Fourth patch refactors pack removal logic by extracting core functionality from pack_geometry_remove_redundant() into new remove_redundant_packs() helper that takes direct pack list
- Fifth patch (new) implements separate geometric progression for promisor packs via pack_geometry_repack_promisors() and extends struct pack_geometry
- Adds validation to reject self-contradictory requests involving promisor packs
- Modifies revision walk in read_stdin_packs() to respect promisor exclusions
- Introduces test cases in t5331-pack-objects-stdin.sh and t7703 covering promisor scenarios

Key technical details:
- pack-objects.c modified to handle both --stdin-packs and --exclude-promisor-objects simultaneously
- repack-geometry.c changes include new compute_pack_geometry_split() helper, remove_redundant_packs(), and promisor-specific pack_geometry_repack_promisors()
- repack-promisor.c helpers introduced including finish_repacking_promisor_objects()
- struct pack_geometry extended to track promisor packs separately
- Core repack components updated while maintaining existing non-promisor behavior
- Extracted promisor logic handles closing pack-objects process, reading output, and processing generated packfiles
- Comprehensive test coverage in t7703 verifies promisor pack handling
