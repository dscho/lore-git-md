This is a documentation patch series (v4) for `git reset` man page improvements, following up on the already-merged v3 series. The changes address post-merge feedback from Jean-Noël Avila regarding formatting consistency.

The v4 updates are minor but precise: they standardize the markup around `HEAD` references and switch mode descriptions to imperative mood ("Leave your working directory unchanged" -> "Leave your working directory unchanged"). These changes don't affect the technical content but bring the documentation in line with Git's style conventions.

D. Ben Knoble is shepherding this series, which builds on Julia Evans' original pedagogical improvements and incorporates feedback from Junio Hamano and Jean-Noël Avila. The patches have already gone through three rounds of review and were merged in v3 form; this v4 addresses purely stylistic follow-up observations.

The series represents the final polish on a comprehensive rewrite of `git reset`'s documentation that improved both technical precision and clarity for users. All substantive technical discussions were resolved in earlier versions, making this a straightforward cleanup iteration.
