This is the first of two patches in a series that enhances `git status` to show divergence from both upstream and push tracking branches. The series has gone through 17 iterations with extensive review from Junio C Hamano, Phillip Wood, and others.

The current patch is a refactoring step that extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This prepares for the second patch that will add push tracking information. The refactoring maintains all existing behavior while making the code more modular - it properly handles all edge cases (gone upstream, quick mode, diverged branches) and preserves the exact same output formatting.

Key changes in this version:
- Restores the original condition ordering that checks `!sti` before evaluating quick mode, fixing a regression from earlier versions
- Keeps the `sti` parameter that was previously removed but is needed for correct control flow
- Moves upstream-is-gone handling to the caller while keeping all other comparison logic in the new function

The patch looks clean and well-tested, with all review feedback from previous iterations addressed. It's a straightforward refactoring that doesn't change behavior, just structure, making it a safe preparation for the more substantial second patch.
