This is a patch series from Patrick Steinhardt addressing an incompatibility between geometric repacking and promisor remotes in Git. The series consists of 5 patches that modify how `git repack` handles promisor packs during geometric repacking.

The core issue is that geometric repacking currently fails when used with promisor remotes because it tries to use two mutually exclusive flags (`--stdin-packs` and `--exclude-promisor-objects`) together. Additionally, the current implementation doesn't properly mark merged packs as promisors when their source packs were promisors.

The series:
1. Makes `--stdin-packs` and `--exclude-promisor-objects` work together in `git pack-objects`
2. Refactors the geometric repacking logic to better handle promisor packs
3. Adds proper promisor pack handling during geometric repacks
4. Includes new tests to verify the behavior

The changes touch core packing functionality but seem carefully scoped to address a specific limitation. The inclusion of new test cases suggests the changes have been properly validated. This looks like an important fix for users of both geometric repacking and promisor remotes.
