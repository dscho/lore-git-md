Junio C Hamano responds to a documentation style question about formatting option names in man pages. The original inquiry noted inconsistencies between backticks (`` `--option` ``) and plain (`--option`) usage across different commands' documentation. 

Junio clarifies that the current direction is actually *toward* more consistent use of backticks for option names, as part of the broader documentation standardization effort led by Jean-Noël Avila. He points to existing examples like commit f7316a66 as reference for the preferred style, suggesting that any consistency pass should add backticks where missing rather than removing them.

This is a small but meaningful clarification in the ongoing documentation standardization work, separate from but complementary to the synopsis-style conversion. Junio's response provides clear guidance for contributors looking to help with documentation consistency.
