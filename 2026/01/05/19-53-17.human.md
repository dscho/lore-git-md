This is the first patch in a 6-part bugfix and test coverage series for `git replay` error handling when given invalid commit-ish arguments. The series has gone through multiple rounds of review, with v3 incorporating feedback from Junio Hamano, Phillip Wood, and Elijah Newren.

The patch removes dead code in `builtin/replay.c` related to a removed "guess mode" feature that was never actually implemented. The function `determine_replay_mode()` is renamed to `set_up_replay_mode()` to better reflect its actual behavior (setting up replay parameters rather than determining mode). The dead code removal simplifies the logic by eliminating an else-block that could never be reached since one of `--onto` or `--advance` is now mandatory.

The changes are straightforward and uncontroversial, with the commit message clearly explaining the history behind the dead code and why it can be safely removed. The patch is part of a well-structured series that has already addressed all reviewer feedback in previous iterations.
