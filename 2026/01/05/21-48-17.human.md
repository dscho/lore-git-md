This is the third patch in a v4 documentation series improving the `git reset` man page, following up on the already-merged v3 series with minor formatting and explanatory refinements. The patch focuses on clarifying the description of `git reset [mode]` by reorganizing and rewording the mode explanations for better pedagogical flow.

The changes make several improvements to the mode descriptions: consistently using "index" instead of "index file", reordering `--mixed` to appear first (since it's the default), and restructuring each mode's explanation to first describe working directory impact (what users most care about), then index changes. The `--soft` section now includes a concrete example showing how to combine commits, while `--merge` explicitly notes its niche use cases like cleaning up after `git am -3`.

All technical content remains identical to the approved v3 version; this iteration is purely about improving clarity and consistency in the documentation. The patch carries sign-offs from Julia Evans (who provided the pedagogical foundation), Junio Hamano (who reviewed the technical content), and D. Ben Knoble (shepherding the series). This represents the final polish on a well-collaborated documentation effort.
