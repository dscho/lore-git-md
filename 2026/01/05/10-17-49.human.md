Feature enhancement for `git status` showing both upstream and push tracking branch comparisons. This is the second and final patch in Harald Nordgren's series, implementing the push tracking display after the refactoring done in patch 1.

The patch adds a new comparison in `git status` output when the push destination tracking branch differs from the upstream branch. This helps users track progress against both their integration branch (typically main) and their feature branch's push destination. The output shows the familiar ahead/behind/diverged status for both branches when they differ.

Key implementation details:
- New `get_remote_push_branch()` helper resolves the push tracking reference through the full refspec resolution chain
- Extended `format_tracking_info()` handles both upstream and push comparisons
- Push comparison only shown when it differs from upstream
- Maintains existing advice messages with push advice only when relevant
- Includes comprehensive test coverage (262 new test lines) verifying:
  - All edge cases including `--no-ahead-behind` option
  - Push/upstream divergence scenarios
  - Custom refspec mappings
  - Quick mode operation
  - Output formatting in all states

The patch has gone through 17 iterations with thorough review from Junio C Hamano, Phillip Wood, and others. All feedback has been addressed, including a critical control flow fix identified by Junio. The implementation now meets all technical requirements with comprehensive test coverage and behavior fully aligned with Git conventions.

Example output when tracking origin/main but pushing to origin/feature:
```
On branch feature
Your branch and 'origin/main' have diverged,
and have 3 and 1 different commits each, respectively.
  (use "git pull" if you want to integrate the remote branch with yours)

Your branch is ahead of 'origin/feature' by 1 commit.
  (use "git push" to publish your local commits)
```
