This is a build system proposal for adding Bazel support to Git. Son Luong Ngoc has created an initial implementation that builds libgit and Git using Bazel, Google's open-source build tool, though it's currently a single large commit that would require invasive changes throughout the repository (adding BUILD files similar to Meson's approach).

The author acknowledges this would be a significant maintenance burden, especially keeping up with upstream changes, and is gauging interest in co-maintainers who would help keep it in-tree. Without such interest, they plan to publish it externally via the Bazel Central Registry as an overlay that users could apply before building.

While currently Linux-only and unpolished, the setup already runs most unit and integration tests. The author suggests macOS and Windows support could be added later. This appears to be a serious but exploratory effort - the patch exists and works to some degree, but the author is being upfront about the maintenance challenges and seeking community feedback before deciding how to proceed.
