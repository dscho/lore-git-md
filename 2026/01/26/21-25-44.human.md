This is a documentation patch from Jean-Noël Avila, part of his ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. The patch focuses on converting `git-show` documentation and the pretty formats section to the new style.

The changes include:
- Adding synopsis-style block definitions in asciidoc.conf.in to support the new formatting
- Converting command syntax and option descriptions to use consistent backtick-wrapped formatting
- Using `_<placeholder>_` notation for arguments
- Reorganizing the pretty formats section into a more structured layout with clear section headers

This continues the multi-year documentation standardization work that has been progressing through the Git codebase. The patch maintains the same technical information while improving presentation consistency. It follows the same patterns seen in previous documentation conversions, with Kristoffer Haugsbakk's review feedback incorporated from earlier iterations.

The changes are purely presentational - no command behavior is altered. The patch demonstrates the same meticulous attention to detail seen in Avila's previous documentation standardization work.
