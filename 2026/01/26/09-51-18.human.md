This is part 2/14 of Patrick Steinhardt's ODB abstraction series, a refactoring effort to make Git's object storage layer backend-independent. The patch fixes a type inconsistency in the flags parameter used by object iteration functions.

The change standardizes the flags parameter from using `enum odb_for_each_object_flags` to `unsigned` across four files (object-file.[ch] and packfile.[ch]). This aligns with Git's convention that bitfield parameters should be unsigned. The patch is mechanical and straightforward - it doesn't change any behavior, just makes the type system more consistent.

As part of a larger series that's already gone through several iterations, this patch shows the careful attention to detail that characterizes Patrick's work. The change is small but contributes to the broader goal of cleaning up the object storage interface. Reviewers have already largely approved the approach in previous rounds, so this iteration is likely nearing readiness for merging.
