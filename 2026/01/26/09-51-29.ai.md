This is part of Patrick Steinhardt's ongoing ODB abstraction series (v4 13/14), converting the reachability code to use the new `odb_for_each_object()` interface. The patch refactors `reachable.c` to handle both loose and packed objects through a unified callback-based approach, eliminating separate iteration paths while maintaining the same mtime-based filtering logic for recent objects.

Key technical changes include:
- Replaces `for_each_loose_object()` and `for_each_packed_object()` with a single `odb_for_each_object()` call
- Consolidates object handling into a new `add_recent_object()` callback that processes both packed and loose objects
- Uses the `object_info` struct to carry mtime and type data transparently
- Preserves existing flags for local-only iteration and in-core pack skipping
- Maintains the same SEEN flag checking and pending object addition logic

The conversion demonstrates the ODB abstraction's ability to simplify code by handling storage backend differences internally. The patch follows the series' incremental approach, building on previous infrastructure work while keeping behavioral changes minimal. Reviewers have validated similar conversions in earlier patches, suggesting this should integrate smoothly.
