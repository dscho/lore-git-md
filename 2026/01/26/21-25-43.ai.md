This is a documentation patch continuing Jean-Noël Avila's standardization of Git man pages to AsciiDoc synopsis style, specifically addressing `git-clone` and `for-each-ref-options`. The changes are mechanical formatting improvements rather than content changes, part of the multi-year effort to achieve consistency across documentation.

The patch makes several stylistic adjustments: spelling out both `--reject-shallow` and `--no-reject-shallow` explicitly rather than using `--[no-]` shorthand, converting admonitions from manual `*NOTE*` markup to proper AsciiDoc `NOTE:` macros, and fixing placeholder formatting (e.g., `_<when>_` instead of `_<when__`). It also standardizes option descriptions to use imperative mood ("Do not checkout" rather than "No checkout") and tightens phrasing in several places for conciseness.

The changes demonstrate careful attention to cross-toolchain compatibility between asciidoc.py and asciidoctor, maintaining the semantic meaning while improving presentation. This continues the pattern seen in earlier iterations where Kristoffer Haugsbakk's review feedback has been systematically incorporated into the standardization effort. The patch is narrowly focused on documentation formatting without altering command behavior or introducing new content.
