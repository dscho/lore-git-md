This is patch 6/14 in Patrick Steinhardt's ongoing ODB (object database) abstraction series. It introduces a new function `packfile_store_for_each_object()` that provides a consistent interface for iterating through packed objects, mirroring the loose object iteration API introduced in an earlier patch.

The new function allows callers to iterate through objects in a specific packfile store while optionally requesting object info (like type and size) for each object. This is part of the larger effort to make Git's object storage layer backend-agnostic by introducing abstracted interfaces. The patch maintains all existing functionality including error handling and special flags (LOCAL_ONLY, PROMISOR_ONLY).

The change is mechanical and well-contained, following the established pattern of the series. It builds on the internal helper extracted in the previous patch (5/14) and will be used to implement the unified `odb_for_each_object()` interface in a future patch. The old `for_each_packed_object()` function remains temporarily but is marked for eventual removal.

Reviewers have already validated critical areas like fsck and promisor handling in earlier patches, and this one appears to maintain that same careful approach. The series continues to progress smoothly toward integration, with Junio Hamano having noted only straightforward merge conflicts in previous reviews.
