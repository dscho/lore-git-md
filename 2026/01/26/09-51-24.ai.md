This is patch 8/14 in Patrick Steinhardt's ODB abstraction series, converting `git fsck` to use the new unified object iteration interface introduced in patch 7/14. The change refactors two key parts of fsck's connectivity checking to use `odb_for_each_object()` instead of separate loose and packed object iteration.

The patch simplifies the code by eliminating redundant callback functions - the previous `mark_loose_*` and `mark_packed_*` wrappers are consolidated into single implementations that work with the new unified iterator. The behavior remains identical since the new interface preserves the same object visitation patterns (including potential duplicate visits for objects existing in both loose and packed form).

This is a straightforward mechanical conversion that builds on the infrastructure work from earlier patches in the series. The changes are limited to `builtin/fsck.c` and maintain all existing functionality while reducing code duplication. The patch follows the series' incremental approach, demonstrating how callers can migrate to the new ODB iteration API.
