This is a bugfix for the histogram diff algorithm (XDF_HISTOGRAM_DIFF) in xdiff, addressing an edge case where shifted change groups during compaction can produce redundant diff output containing matching lines from both files. The fix adds logic to detect when shifting creates new matching groups and re-diffs those sections using Myer's algorithm while preserving all original diff flags.

The discussion has clarified that completely disabling group shifting would be worse than the current approach, as it would prevent useful coalescing of changed lines and interfere with the indent heuristic. Phillip Wood notes that histogram diff sometimes produces harder-to-read diffs than patience diff as an inherent characteristic, though this patch specifically targets the redundant output issue rather than general readability.

Junio C Hamano suggests extracting the new logic into a helper function for clarity while confirming the core solution is sound. The patch includes test coverage with three cases verifying the fix across scenarios. While this affects less than 1% of diffs, it fixes clearly undesirable output when the edge case occurs. The implementation appears well-considered, addressing a real issue without introducing new problems.
