This is a documentation patch continuing Jean-Noël Avila's multi-year effort to standardize Git man pages to AsciiDoc synopsis style. It's the second patch in a 4-part series, specifically finalizing the conversion of `git-clone` documentation.

The patch makes mechanical but precise formatting changes to the man page, primarily standardizing how command-line options are presented. It replaces mixed formatting (like `++--server-option=++__<option>__`) with consistent backtick-wrapped options (like `--server-option=<option>`). The changes also standardize the presentation of option-value pairs (e.g., changing `-o` _<name>_ to `-o <name>`).

These changes are purely presentational - they don't alter the actual content or meaning of the documentation, just make it more consistent with the project's evolving style guidelines. The patch follows up on earlier review feedback and demonstrates careful attention to cross-toolchain compatibility between different AsciiDoc processors.

As part of the ongoing documentation standardization effort, this patch exemplifies the project's rigorous approach to man page consistency. The changes are straightforward and unlikely to be controversial, building on established patterns from previous documentation conversions.
