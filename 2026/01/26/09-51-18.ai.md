This is part 2/14 of Patrick Steinhardt's ODB abstraction series (v4), focused on standardizing the type used for object iteration flags. The change aligns with Git's convention that bitfield parameters should use unsigned types, preventing potential sign-extension problems. All modified functions are part of the object database iteration machinery that the series is abstracting.

This is a mechanical change that doesn't affect behavior - it's purely a type system improvement that makes the code more correct and consistent. The patch follows naturally from the flag renaming in part 1/14, continuing the series' systematic approach to standardizing the ODB interface.
