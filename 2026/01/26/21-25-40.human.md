This is a documentation patch series continuing Jean-Noël Avila's ongoing effort to standardize Git man pages to AsciiDoc synopsis style. The 4-patch v2 series converts `git-submodule` and `git-show` documentation while fixing some style issues in `git-clone` and `for-each-ref-options` that were spotted in earlier work.

The changes are mechanical formatting updates that don't affect Git's behavior, focusing on consistent presentation across man pages. Kristoffer Haugsbakk's review of v1 identified specific rendering issues with `[synopsis]` blocks and verbatim formatting, which Avila has now addressed in this revision. The diff shows careful attention to details like quote escaping in format strings and consistent handling of placeholder italics.

This series represents incremental progress in the long-running documentation standardization project. The patches are well-contained and clearly motivated, with the commit messages noting exactly which files are being converted. The discussion around toolchain compatibility (asciidoc vs asciidoctor rendering) demonstrates the meticulous attention needed for these cross-platform formatting changes.
