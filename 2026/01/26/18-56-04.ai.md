This is a refactoring patch that introduces a new utility function `string_list_sort_u()` to combine the common pattern of sorting a string list followed by removing duplicates. It's part of an RFC series from Amisha Chhajed that has already gone through initial review from Junio Hamano, with test coverage now added per maintainer requirements.

The patch adds `string_list_sort_u()` which internally calls the existing `string_list_sort()` and `string_list_remove_duplicates()` functions. It then mechanically converts six call sites across clone.c, fast-export.c, pack-objects.c, sparse-checkout.c, help.c, and notes.c to use the new combined function. The changes are straightforward replacements of the two-step pattern with a single function call.

The implementation includes comprehensive unit tests in t/unit-tests/u-string-list.c that verify the new function handles various cases: empty lists, lists with empty strings, and lists with multiple duplicates. The tests follow the established `clar` unit test framework patterns used elsewhere in Git's test suite.

Junio Hamano has already reviewed an earlier version of this patch, suggesting improvements to the commit message (noting the "sort -u" analogy) and requiring test coverage before technical review. The author has now added the requested tests and incorporated style feedback around loop counters and brace usage. The patch appears ready for broader technical review, particularly around whether combining these operations is the right API design and whether all converted cases actually need deduplication.
