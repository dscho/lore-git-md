Documentation patch finalizing the `git-clone` man page conversion to synopsis style. This is part 2 of Jean-Noël Avila's 4-patch series standardizing documentation formatting, following up on Kristoffer Haugsbakk's review of the initial version.

The patch makes mechanical but precise formatting changes to the `git-clone` man page, focusing on consistent option presentation. It replaces mixed formatting (like `++--server-option=++__<option>__`) with uniform backtick-wrapped options (`--server-option=<option>`), standardizes how command-line options with placeholders are shown (e.g., changing `-o` _<name>_ to `-o <name>`), and ensures all option references use the same quoting style. The changes are purely presentational - no command behavior or meaning is altered.

This continues the project-wide effort to make man pages render consistently across different AsciiDoc toolchains (asciidoc.py vs asciidoctor) while improving readability. The patch demonstrates careful attention to the formatting details that were points of discussion in the v1 review, showing the systematic approach being taken to documentation standardization.
