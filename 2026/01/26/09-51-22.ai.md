This is patch 6/14 in Patrick Steinhardt's ongoing ODB abstraction series. It introduces `packfile_store_for_each_object()`, the packed-object counterpart to the loose-object iteration function from patch 4/14. The new function provides consistent callback semantics across both storage types, taking a `struct object_info` parameter like its loose-object sibling.

The implementation wraps the existing packed iteration logic with a new callback adapter that handles object info requests, maintaining all existing functionality (error handling, promisor object filtering via flags) while preparing for the unified ODB iteration API coming later in the series. The patch follows the established pattern of this refactoring effort: introducing new interfaces without behavior changes, with old functions (`for_each_packed_object()`) retained temporarily for compatibility.

Key technical details include the `packfile_store_for_each_object_wrapper_data` helper struct that bridges between the old packed-git iteration callback signature and the new ODB-style callback, and careful preservation of the flags system (LOCAL_ONLY, PROMISOR_ONLY) through the abstraction layer. The changes touch core packfile handling but are narrowly scoped to iteration mechanics, avoiding deeper behavioral changes at this stage.
