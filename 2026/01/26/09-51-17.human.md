This is the first patch in Patrick Steinhardt's v4 series (14 patches) to abstract Git's object storage layer. The patch performs a mechanical rename of `FOR_EACH_OBJECT_*` flags to have an `ODB_` prefix, preparing for a new `odb_for_each_object()` function that will provide backend-independent object iteration.

The change is straightforward - it updates flag names across 11 files to use the new prefix (`ODB_FOR_EACH_OBJECT_LOCAL_ONLY`, `ODB_FOR_EACH_OBJECT_PACK_ORDER`, etc.) while keeping all the same numeric values and behaviors. The patch is part of a larger architectural effort to make object storage backends pluggable, with this particular change establishing naming consistency before introducing new iteration APIs.

The patch appears well-contained and low-risk, touching only flag names while preserving all existing functionality. It follows the common Git pattern of mechanical refactoring before introducing new features.
