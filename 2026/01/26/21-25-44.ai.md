This is a documentation patch from Jean-Noël Avila, part of the ongoing effort to standardize Git's man pages to AsciiDoc synopsis style. The patch focuses on converting `git-show` documentation and related pretty formats documentation to the new format.

The changes introduce several technical improvements to the documentation presentation:
- Adds synopsis-style block definitions in `asciidoc.conf.in` to support consistent formatting
- Converts command syntax blocks to use the new `[synopsis]` markup
- Standardizes placeholder formatting with `_<placeholder>_` notation
- Updates cross-references to use backtick-wrapped command names
- Restructures the pretty formats section with clearer hierarchical organization

The patch maintains compatibility with both asciidoc.py and asciidoctor toolchains while improving readability. It builds on previous iterations that addressed `git-submodule` and `git-show` documentation, showing the systematic nature of this multi-year standardization effort. The changes are purely presentational - no command behavior is modified.

This continues Jean-Noël Avila's long-running documentation standardization work, incorporating feedback from Kristoffer Haugsbakk and other reviewers. The patch demonstrates meticulous attention to detail in converting legacy formatting to the new synopsis style while preserving all technical content.
