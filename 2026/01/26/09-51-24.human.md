This is part 8/14 of Patrick Steinhardt's ongoing ODB abstraction series, converting `git fsck` to use the new unified object iteration interface introduced in patch 7/14. The patch refactors two key loops in `builtin/fsck.c` that previously used separate `for_each_loose_object()` and `for_each_packed_object()` calls, replacing them with the new `odb_for_each_object()` function.

The changes are straightforward mechanical conversions that maintain the same behavior while reducing code duplication. The patch notes that while the new interface may visit some objects multiple times (if they exist in both loose and packed form), this was already true of the old implementation. The refactoring simplifies the code by eliminating redundant callback functions and consolidating the iteration logic.

This continues the series' pattern of incrementally converting subsystems to use the new ODB abstraction layer, with `git fsck` being a natural candidate given its need to examine all objects. The changes are well-contained and appear to be a clean application of the new API, following the same approach seen in earlier patches of the series.
