git-gui bugfix for diff viewer tab alignment, addressing inconsistent tab rendering in Windows environments. Patch from Chris Idema via GitGitGadget introduces `expand_tabs` procedure in `git-gui/lib/diff.tcl` to convert tabs to spaces using `gui.tabsize`. Johannes Sixt (Git GUI maintainer) initially questioned the issue's existence in Tcl/Tk 8.6 but Chris has demonstrated specific reproduction case showing the problem occurs in Git for Windows 2.52.0.windows.1 on Windows 11 with tabbed C code, confirming Windows Tcl/Tk environment-specific behavior. 

Critical outstanding issue is whether the tab-to-space conversion preserves the "Stage Line/Hunk for Commit" functionality that extracts text from diff widget to create patches. Sixt emphasizes this is not merely a visual concern - the staging mechanism must work correctly with modified display. Chris has not yet tested this interaction, leaving the key maintainer requirement unverified. The patch remains technically sound but cannot proceed without confirmation that staging operations function correctly with space-converted diffs. Thread status now depends on testing this specific technical interaction between display formatting and patch generation logic. Does not affect gitk.
