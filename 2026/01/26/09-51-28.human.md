Part of Patrick Steinhardt's ongoing ODB abstraction series (v4 12/14), this patch refactors cruft pack object enumeration in `builtin/pack-objects.c` to use the new `packfile_store_for_each_object()` interface rather than the older `for_each_packed_object()`. The change simplifies mtime handling by leveraging the object info request mechanism introduced in earlier patches.

The key improvement is eliminating manual mtime lookup logic that previously had to handle both cruft packs (with their special .mtimes files) and regular packs differently. Now the mtime comes directly from the object info callback parameter, making the code more maintainable and consistent with the series' goal of abstracting backend details.

The patch demonstrates the incremental approach of the series - building on previous infrastructure (like the mtime tracking added in patch 11/14) while converting another real-world use case. The change is relatively straightforward, replacing about 20 lines of specialized mtime handling with a cleaner interface while maintaining the same functionality. Reviewers (Taylor Blau, Justin Tobler, Karthik Nayak) have already validated the critical paths in earlier iterations.
