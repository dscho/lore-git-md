This is part 10/14 of Patrick Steinhardt's ongoing ODB abstraction series, converting direct calls to `for_each_loose_object()` and `for_each_packed_object()` to use the new backend-specific iteration functions. The patch refactors two key call sites in `builtin/cat-file.c` and `batch_each_object()` and `commit-graph.c`'s packed object enumeration.

The changes demonstrate the transitional state of the abstraction - while introducing the new `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()` interfaces, the patch acknowledges these still require direct backend knowledge. The `cat-file` changes are particularly notable as they unify loose and packed handling through a new `batch_one_object_oi()` callback that handles both cases via the `object_info` parameter.

The commit-graph conversion splits the packed commit enumeration logic between the legacy callback signature and a new `add_packed_commits_oi()` that uses `object_info`. Both conversions maintain existing behavior while preparing for the eventual removal of the direct iteration functions. The patch follows the series' incremental approach, with Patrick noting some callers will require future refactoring to fully use `odb_for_each_object()`.
