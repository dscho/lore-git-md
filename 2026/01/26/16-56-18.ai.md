Performance optimization for the p3400 rebase performance test.

This RFC patch from Tian Yuchen proposes speeding up the setup phase of the `t/perf/p3400-rebase.sh` test by replacing a slow shell loop with `git fast-import`. The current setup generates 100 commits with large file changes using repeated `git add`/`git commit` cycles, which the author found took ~29 seconds on their test machine.

The new approach precomputes the forward and reversed file contents once, then uses a single `fast-import` stream to create all commits. This reduces the setup time to ~18 seconds - a 38% improvement. The patch maintains the same commit history structure (alternating forward and reversed content) while eliminating redundant process spawning and file operations.

The change is contained to the test script's setup section and doesn't affect the actual performance measurements being run. As an RFC, the author is likely seeking feedback on whether this optimization approach is acceptable before polishing it further. The implementation looks straightforward and the performance benefit is clearly demonstrated.
