This is patch 13/14 in Patrick Steinhardt's ongoing ODB (object database) abstraction series, converting the reachability code to use the new unified object iteration interface. The patch refactors `reachable.c` to replace separate loose and packed object iteration with the new `odb_for_each_object()` API, which now handles both cases through a single callback.

The change simplifies the code significantly by removing 90 lines of redundant iteration code while maintaining the same functionality - tracking object mtimes to determine which objects are recent enough to keep. The new version uses the `object_info` struct introduced in earlier patches to carry mtime and type information through the callback, eliminating manual mtime lookups and type checking.

This continues the series' pattern of incrementally converting subsystems to the ODB abstraction layer while preserving existing behavior. The patch appears well-contained and builds on infrastructure established in previous patches (particularly the mtime tracking from patch 11/14). Review feedback from Taylor Blau and others has been positive, suggesting this is a straightforward step toward the series' goal of abstracting object storage access.
