This is a documentation patch converting the `git-submodule` man page to the new AsciiDoc synopsis style, part of Jean-Noël Avila's ongoing standardization effort. The patch mechanically reformats the documentation while preserving all content, with several notable changes:

The conversion introduces proper synopsis blocks (`[synopsis]`) for command usage patterns and standardizes placeholder formatting with `_<placeholder>_` notation. It transforms inline option lists into structured definition lists (using `;;` separators) and consistently formats command names and options in backticks. The patch also improves cross-references between related commands and options.

Key technical changes include converting the submodule update procedures (checkout/rebase/merge) into a proper definition list and restructuring the `foreach` command's variable documentation. The patch maintains careful attention to rendering compatibility between asciidoc.py and asciidoctor toolchains, particularly for verbatim formatting of shell commands and option strings.

This work follows Kristoffer Haugsbakk's review of the v1 series, with all identified issues addressed. The changes are purely presentational - no submodule behavior is altered - making this a low-risk documentation improvement that advances the project-wide standardization effort.
