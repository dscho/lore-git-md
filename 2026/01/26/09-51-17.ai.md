This is the first patch in Patrick Steinhardt's v4 series (1/14) to abstract Git's object database iteration. The patch performs a mechanical rename of `FOR_EACH_OBJECT_*` flags to use an `ODB_` prefix, aligning them with the upcoming `odb_for_each_object()` function. This is a straightforward refactoring that touches 11 files to update flag names consistently across the codebase.

The changes are purely naming-related - all functionality remains identical. The new flag names are `ODB_FOR_EACH_OBJECT_LOCAL_ONLY`, `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`, etc. This establishes naming consistency before introducing the new iteration API in subsequent patches. The patch follows Git's standard refactoring approach of doing mechanical changes first before behavioral modifications.

As part of the larger ODB abstraction effort, this patch helps prepare for backend-independent object iteration by standardizing the vocabulary around object database operations. The changes are widespread but straightforward, affecting mostly packfile operations and object iteration callbacks. Reviewers have already approved similar mechanical changes in earlier iterations of this series.
