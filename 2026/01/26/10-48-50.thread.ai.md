Refactoring Git's xdiff (diff engine) subsystem to reduce memory usage, continuing the cleanup work started in 'en/xdiff-cleanup-2'. Phillip Wood's series introduces two optimizations: (1) removing the `line_hash` field from `xrecord_t` (used only during initial line processing), reducing structure size by 25-40%, and (2) restructuring `xdlclass_t` to store only essential line data (pointer and size), eliminating unnecessary copying from `xrecord_t`. This second change effectively reverts part of commit 6d507bd41a while maintaining functionality.

Junio C Hamano as maintainer has weighed in, acknowledging these as sensible optimizations but noting they conflict with Elijah Newren's competing 'en/xdiff-cleanup-3' series which takes a more aggressive approach to restructuring classification timing. Phillip's expertise in the diff/merge subsystem lends credibility to these targeted optimizations, which build on prior work splitting hash fields (commit 6a26019c81).
