This is part 5/14 of Patrick Steinhardt's ongoing ODB abstraction series, which aims to make Git's object storage layer backend-agnostic. The patch refactors packed object iteration by extracting the core logic from `for_each_packed_object()` into a new helper function `packfile_store_for_each_object_internal()`. 

The change is a mechanical refactoring that splits the existing packed object iteration into two parts: one that handles the per-packfile-store iteration (the new helper function) and another that manages the alternates preparation and error handling (the original function). This prepares for upcoming changes that will introduce a new backend-agnostic interface for iterating packed objects, similar to the loose object iteration interface introduced in patch 4/14.

The refactoring maintains all existing functionality including flag-based filtering (local/promisor/kept packs) and error handling. The patch appears straightforward and well-contained, with no behavior changes - it's purely restructuring code to support the larger ODB abstraction effort. Given the series has already received substantial review and this is a preparatory change, it seems likely to progress smoothly.
