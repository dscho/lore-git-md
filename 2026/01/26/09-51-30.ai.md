This is the final patch in Patrick Steinhardt's ODB abstraction series (v4 14/14), completing the transition to the new `odb_for_each_object()` interface by removing the now-unused legacy iteration functions. The patch removes `for_each_loose_object()` and `for_each_packed_object()` after all callers have been converted to use the unified interface introduced earlier in the series. It also inlines `packfile_store_for_each_object_internal()` since it now has only one caller, simplifying the callback indirection.

The changes touch four files, removing 97 lines while adding 35, with most modifications in `packfile.c` where the packed object iteration logic is consolidated. The removal of these functions demonstrates the series' success in abstracting object database access - a key goal of the ODB effort. With this patch, the infrastructure for unified object iteration is fully in the codebase, with no remaining direct callers to the old per-storage-type functions.

This cleanup follows the incremental approach seen throughout the series, where new interfaces were introduced and callers migrated before removing old code. Reviewers Taylor Blau, Justin Tobler and Karthik Nayak have previously approved the architectural direction, and the patch maintains all existing behavior flags (local-only iteration, promisor pack handling, kept pack skipping) through the consolidated implementation. The series now appears ready for merging, having systematically updated all relevant subsystems to use the new ODB abstraction layer.
