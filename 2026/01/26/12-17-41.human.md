This is the first patch in a 3-part series from Patrick Steinhardt addressing inconsistencies in object database flag usage, part of his ongoing ODB abstraction work. The patch fixes incorrect flag passing in `builtin/backfill.c` where `OBJECT_INFO_FOR_PREFETCH` flags were being passed to `odb_has_object()` instead of the expected `HAS_OBJECT_*` flags.

The patch explains that while the code currently works by coincidence (due to matching bit patterns), this is fragile and could break. The fix simply removes the incorrect flags entirely since the default behavior of `odb_has_object()` already matches what the code wants (not reprepairing the ODB and not fetching missing objects).

This is a straightforward internal cleanup with no behavior change. The commit message clearly explains the situation and rationale. Given Patrick's deep expertise in the ODB layer and the mechanical nature of this fix, this patch appears uncontroversial.
