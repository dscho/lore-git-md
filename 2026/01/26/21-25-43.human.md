This is a documentation patch from Jean-Noël Avila, part of his ongoing effort to standardize Git's man page formatting. It's the third patch in a 4-part v2 series converting `git-clone` documentation to AsciiDoc synopsis style, with additional minor fixes to `for-each-ref-options`.

The changes are mechanical but precise, focusing on consistency and readability:
- Standardizes option presentation by spelling out both `--reject-shallow` and `--no-reject-shallow` forms explicitly
- Converts ad-hoc note formatting to proper AsciiDoc `NOTE:` macros
- Improves markup for placeholders (like `_<when>_`) and special characters (`_NUL_`)
- Tightens phrasing in option descriptions to use imperative mood consistently
- Fixes minor formatting inconsistencies in option listings

The patch follows the project's documentation standardization patterns, addressing Kristoffer Haugsbakk's earlier review feedback. While purely presentational, these changes improve cross-toolchain compatibility between asciidoc.py and asciidoctor processors. The work demonstrates the project's meticulous approach to documentation quality in this multi-year effort.
