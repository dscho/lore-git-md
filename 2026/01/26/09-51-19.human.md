This is part 3 of Patrick Steinhardt's 14-patch series to abstract Git's object storage layer (ODB). The patch refactors how loose object information is read by extracting a new `read_object_info_from_path()` function that handles the actual reading logic, while keeping the existing `odb_source_loose_read_object_info()` as a thin wrapper that provides the path. 

The key change is removing the intermediate `stat_loose_object()` helper in favor of direct `lstat()` calls where needed. This simplifies the code by eliminating a layer of indirection while maintaining the same functionality. The patch is a straightforward refactoring with no behavior changes - it just reorganizes the code to be more reusable for the upcoming ODB iteration work.

This continues the series' pattern of methodically restructuring the object storage code to support backend-independent operations. The changes here are focused on the loose object handling path, which is one of Git's two primary object storage mechanisms (alongside packfiles). The patch appears well-contained and builds logically on the previous flag renaming and type fixes from earlier in the series.
