This is the final patch in Patrick Steinhardt's ODB abstraction series (v4 14/14), completing the transition to the new object iteration API. The patch removes the now-unused `for_each_loose_object()` and `for_each_packed_object()` functions after all callers have been converted to use the unified `odb_for_each_object()` interface. It also inlines the helper function `packfile_store_for_each_object_internal()` since it only has one remaining caller.

The changes are mechanical cleanup following the substantial refactoring work done in earlier patches. The diff shows deletions across four files (object-file.c/h and packfile.c/h) totaling nearly 100 lines removed. The remaining code is simplified by eliminating the intermediate helper function and callback indirection.

This marks the completion of a major architectural change that unifies object iteration across loose and packed storage backends. The series has seen thorough review from Taylor Blau, Justin Tobler and Karthik Nayak, with Junio Hamano noting earlier that the merge conflicts would be straightforward to resolve. With this final cleanup, the ODB abstraction work appears ready for integration.
