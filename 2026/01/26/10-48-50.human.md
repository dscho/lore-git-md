This is a refactoring patch series targeting Git's xdiff (diff algorithm) internals, building on previous cleanup work in the 'en/xdiff-cleanup-2' series. Phillip Wood proposes two small but meaningful changes to reduce memory usage in the diff calculation code.

The first patch removes the `line_hash` field from `xrecord_t`, which stores information about individual lines during diff calculation. The second removes unused data field from `xdlclass_t`, another internal structure. Both changes shrink these data structures with no behavior change. The author notes these conflict with another in-progress xdiff cleanup series ('en/xdiff-cleanup-3') that moves line classification logic, but suggests an alternative approach if that direction is pursued.

The changes are straightforward and focused - typical of Phillip Wood's contributions which often address subtle behavioral or performance issues. The patch series is small and well-contained, touching only xdiff preparation code. While not earth-shattering, these are the kind of careful, targeted cleanups that help keep Git's performance-sensitive diff code lean. The conflict with another series suggests this might need to wait until the larger xdiff cleanup effort settles, but the changes themselves look sensible.
