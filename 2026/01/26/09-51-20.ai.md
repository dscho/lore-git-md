This is part 4 of Patrick Steinhardt's 14-patch series to abstract Git's object storage layer (ODB). The patch introduces a new `odb_source_loose_for_each_object()` function that provides a unified interface for iterating through loose objects, replacing the existing `for_each_loose_object()` which will be removed later in the series.

The key technical contribution is creating a callback-based iteration API that populates a `struct object_info` consistently with how `odb_source_loose_read_object()` would, while handling flags for filtering (like `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`). The implementation wraps the existing loose object iteration but presents it through the new ODB-agnostic interface, taking care to properly propagate object info requests and handle flag-based filtering.

This change is part of the larger effort to make object storage backends pluggable by standardizing their interfaces. The patch maintains backward compatibility while paving the way for future patches to unify iteration across both loose and packed objects. Review discussion from earlier versions has already addressed the core design, and this iteration appears to incorporate that feedback cleanly.
