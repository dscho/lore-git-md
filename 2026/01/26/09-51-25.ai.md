This is patch 9/14 in Patrick Steinhardt's ODB abstraction series, converting promisor object enumeration to use the new `odb_for_each_object()` interface. The patch updates three call sites that previously used `for_each_packed_object()` with the `PROMISOR_ONLY` flag to instead use the unified iterator.

The changes are mechanical but demonstrate the series' goal of consolidating object iteration patterns. The most significant update is in `packfile.c` where the `add_promisor_object` callback is adapted to the new interface, now taking an `object_info` parameter rather than packed-git specifics. The callback's logic remains largely unchanged, continuing to populate an oidset with promisor objects and their reachable objects.

The patch maintains all existing functionality while reducing code duplication between packed and loose object handling paths. It follows the series' incremental approach, building on the infrastructure introduced in earlier patches. The changes are straightforward and unlikely to be controversial, as they align with the already-reviewed direction of the ODB abstraction work.
