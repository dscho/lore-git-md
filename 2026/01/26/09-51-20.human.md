This is part 4 of Patrick Steinhardt's 14-patch series to abstract Git's object storage layer, introducing a new `odb_source_loose_for_each_object()` function. The patch creates a unified interface for iterating through loose objects, replacing the existing `for_each_loose_object()` with a more flexible callback-based approach that can populate object metadata during iteration.

The new function accepts a `struct object_info` parameter to optionally request object metadata, matching the behavior of direct object reads. This prepares the codebase for future unification with packed object iteration. The implementation handles flag-based filtering (like skipping non-local or promisor objects) and preserves the existing loose object iteration behavior while making it more consistent with the planned ODB abstraction.

This is a well-structured technical change that moves the ODB abstraction effort forward. The patch follows the series' pattern of introducing new interfaces while maintaining backward compatibility, with clear documentation of the transitional nature (`for_each_loose_object()` will be removed later in the series). Reviewers have already engaged with earlier versions, and this iteration appears to incorporate their feedback.
