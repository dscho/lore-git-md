Bugfix for fsmonitor's Watchman hook implementation. This patch addresses two issues in the sample Watchman integration script used by Git's filesystem monitoring feature.

First, it fixes an error handling bug where the script was checking the wrong variable (`$output` instead of `$o`) after calling `watchman_clock()`, causing errors to be silently ignored. Second, it removes a problematic recursive call that could cause the hook to output multiple responses when only one is expected by Git's fsmonitor protocol.

The changes are straightforward and clearly explained in the commit message. The patch updates both the sample hook in `templates/hooks/` and the test helper scripts in `t/t7519/` to maintain consistency. The fixes appear well-considered - the recursive call removal in particular makes sense since the "/" flag already tells Git to do a full scan, making the additional call redundant and potentially harmful.

This is a focused fix that improves the reliability of fsmonitor's Watchman integration without introducing new complexity. The changes are small but meaningful for users relying on this feature.
