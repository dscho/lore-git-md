This is a bugfix patch for git-gui, specifically addressing tab alignment issues in the diff viewer. The patch comes from Chris Idema via GitGitGadget.

The issue stems from Tk's inconsistent handling of tab characters in the git-gui diff display, where tabs weren't rendering properly regardless of tab width settings. The solution introduces a new `expand_tabs` procedure that converts tabs to spaces before rendering, using the configured `gui.tabsize` value. The patch modifies the diff display logic to process each line through this new function while maintaining all existing functionality.

The change is focused and well-contained, touching only the diff display logic in `git-gui/lib/diff.tcl`. The author notes this doesn't address similar tab alignment issues in gitk, keeping the scope narrow. The implementation handles edge cases like CR line endings and maintains the existing tag application system.

The patch appears technically sound with a clear commit message explaining both the problem and solution. It's a straightforward improvement to the git-gui user experience without introducing any obvious complexity or side effects.
