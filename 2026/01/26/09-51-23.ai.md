This is part 7/14 of Patrick Steinhardt's ongoing ODB (object database) abstraction series, introducing a unified object iteration interface. The patch adds `odb_for_each_object()`, which provides a single entry point for iterating through all objects in an ODB, whether they're stored as loose objects or in packfiles.

The new function wraps the existing loose and packed iteration mechanisms introduced in earlier patches (4/14 and 6/14 respectively), maintaining the same callback semantics (including LOCAL_ONLY and PROMISOR_ONLY flag handling) while providing a simpler interface for callers. The implementation carefully preserves all existing behavior, including error propagation and object info population when requested.

Key technical details include:
- The function iterates through all ODB sources (main and alternates)
- It respects the same flags as the lower-level iteration functions
- Callbacks receive populated object_info structs when requested
- Error handling remains consistent with the rest of the ODB API

This continues the series' pattern of building up functionality incrementally while maintaining backward compatibility. The patch includes thorough documentation of the new interface's behavior and edge cases. Reviewers have already approved the architectural approach in previous iterations, and this patch appears to be a straightforward composition of the components introduced earlier in the series.
