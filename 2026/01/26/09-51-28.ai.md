This is part 12 of Patrick Steinhardt's ongoing ODB abstraction series, focusing on converting `builtin/pack-objects.c` to use the new `packfile_store_for_each_object()` interface for cruft pack generation. The patch replaces direct packed object iteration with the ODB abstraction layer's unified interface, specifically handling mtime tracking for garbage collection.

The change refactors how cruft pack objects are enumerated by:
- Removing the manual mtime lookup logic that previously used `for_each_packed_object()`
- Introducing a new `object_info` struct to carry mtime data through the callback
- Using `packfile_store_for_each_object()` to iterate while automatically populating mtimes
- Maintaining the same pack ordering and filtering flags as before

The implementation demonstrates the series' goal of moving callers away from direct packed_git access by:
- Handling both cruft pack .mtimes and regular pack mtimes transparently
- Preserving all existing filtering behavior (local-only, skip kept packs)
- Keeping the same die() behavior on errors

This continues the incremental transition approach seen in earlier patches, with Taylor Blau and others having reviewed the critical paths. The change is relatively mechanical but important for consolidating packed object access through the new ODB interfaces. The next patches in the series will likely continue converting other callers to the unified iteration API.
