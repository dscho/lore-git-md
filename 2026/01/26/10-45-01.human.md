This is a bugfix for git-gui's diff display. The patch addresses an issue where tabs in diffs weren't rendering correctly in the Tk-based git-gui interface, regardless of tab width settings. The solution converts tabs to spaces before rendering, ensuring proper alignment.

The change introduces a new `expand_tabs` procedure that handles the tab-to-spaces conversion, using the configured `gui.tabsize` setting. The fix is applied to diff output but explicitly does not address similar issues in gitk (the separate graphical history viewer).

The patch appears straightforward and well-contained, touching only the diff display logic in git-gui. The commit message clearly explains both what was fixed and what remains unfixed (gitk's tab handling). This seems like a practical improvement for git-gui users who work with tab-indented code.
