This is part 9/14 of Patrick Steinhardt's ongoing ODB abstraction series, converting promisor object enumeration to use the new `odb_for_each_object()` interface. The patch updates three call sites (`packfile.c`, `repack-promisor.c`, and `revision.c`) that previously used `for_each_packed_object()` with the `PROMISOR_ONLY` flag to instead use the unified iterator.

The changes are mechanical but demonstrate the series' goal of consolidating object iteration logic. Each conversion preserves the existing behavior while eliminating redundant callback wrappers. The most involved change is in `packfile.c`, where the promisor object collection logic is updated to work with the new callback signature while maintaining the same tree/commit/tag traversal behavior.

This continues the series' pattern of incrementally migrating subsystems to the new ODB interface after establishing the core infrastructure in earlier patches. The changes are straightforward and maintain the same filtering capabilities, with reviewers Taylor Blau, Justin Tobler and Karthik Nayak having already approved the approach in previous iterations.
