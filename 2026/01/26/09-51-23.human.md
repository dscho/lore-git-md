This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction series (v4 7/14). The patch introduces a new function `odb_for_each_object()` that provides a unified interface for iterating over all objects in the object database, whether they're stored as loose objects or in packfiles.

The new function wraps the existing iteration mechanisms from previous patches in the series (patch 4/14 for loose objects and patch 6/14 for packfiles) while maintaining the same callback semantics and filtering capabilities (LOCAL_ONLY, PROMISOR_ONLY flags). The implementation carefully handles the different storage backends while preserving all existing functionality.

This continues the series' pattern of incremental refactoring - first introducing the lower-level iteration functions for each storage type, then building the unified interface on top. The patch includes thorough documentation of the new function's behavior and error handling. Reviewers Taylor Blau, Justin Tobler and Karthik Nayak have been validating the critical paths in previous patches, suggesting this change follows the established pattern.

The series remains technically consistent with its approach of read-only `object_info` parameters and clear documentation of pending conversions. This patch moves the ODB abstraction effort forward by providing callers with a single, clean interface for object iteration regardless of storage backend.
