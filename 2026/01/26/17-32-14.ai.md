This is a bugfix for the histogram diff algorithm (XDF_HISTOGRAM_DIFF) in xdiff, addressing an edge case where shifted change groups during compaction produce redundant diff output containing matching lines from both files. The discussion has moved from technical implementation details to broader considerations about the diff algorithm's behavior.

Phillip also shares an observation that histogram diff sometimes produces harder-to-read diffs than patience diff, though this appears to be an inherent characteristic rather than a bug.

The core solution remains sound - using Myer's algorithm to re-diff shifted groups when they produce suboptimal output.
