This is a feature patch series introducing a new `odb_for_each_object()` API as part of Patrick Steinhardt's ongoing ODB abstraction effort. The series (v4, 14 patches) standardizes object iteration across Git's storage backends, enabling future pluggable storage implementations.

The key change is the introduction of `odb_for_each_object()`, which provides a unified way to iterate through objects regardless of whether they're stored loose or packed. The series systematically converts existing callers like `fsck`, `pack-objects`, and reachability calculations to use this new API while maintaining all existing behavior. 

Notable technical changes in v4 include:
- Making the object_info` parameter read-only to prevent stale data issues
- Adding mtime support for object info requests (with clear documentation about its limitations)
- Preserving the `LOCAL_ONLY` flag in `pack-objects` for consistency
- Marking remaining TODOs for future work on object filtering

The series has undergone extensive review from Taylor Blau and others, with most technical concerns addressed. The mtime handling remains the primary open design question - Patrick favors keeping backend-specific logic contained within backends, while Taylor has suggested a more generalized approach. This difference appears to be the last major blocker before the series can be merged.

This represents a significant step in the ODB abstraction work, replacing direct backend access with a clean interface that will support alternative storage implementations. The changes are well-contained and the series appears ready for integration pending resolution of the mtime discussion.
