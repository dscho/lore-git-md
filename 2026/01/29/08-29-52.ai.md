This is part of the ongoing `the_repository` removal effort, specifically focusing on migrating repository-specific configuration variables from global scope to a new `struct repo_config_values` embedded in `struct repository`. The series has reached its fifth iteration with only minor typo fixes in the latest version.

The patches demonstrate a complete pattern for config migration, having already handled `core.attributesFile`, `core.sparseCheckout`, and `branch.autoSetupMerge`. The implementation maintains consistent access patterns while establishing the infrastructure for repository-specific storage. Phillip Wood has contributed naming improvements and commit message refinements throughout the review process.

The work remains blocked on resolving fundamental architectural concerns raised by Junio C Hamano regarding config scoping across multiple repositories and initialization patterns. These patches serve as both concrete examples of the migration approach and a test case for the remaining architectural work needed in the broader effort. The author is now seeking final review before potentially moving forward with additional variable migrations.
