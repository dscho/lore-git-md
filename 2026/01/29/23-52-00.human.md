This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the current state of development branches and pending patches. The report covers 40+ active topics across various stages of integration.

Several notable developments are in progress:

1. **New Features**:
   - A `--maximal-only` option for `git rev-list` to show only unreachable commits
   - Submodule fetching improvements to use configured default remote instead of hardcoded 'origin'
   - Hook API modernization replacing ad-hoc `run_command()` calls
   - `git status` enhancements for triangular workflows showing both upstream and push destination comparisons

2. **Infrastructure Work**:
   - Major ODB (object database) refactoring by Patrick Steinhardt to support multiple object sources
   - Continued `the_repository` removal effort
   - Documentation modernization converting more man pages to synopsis style
   - Rust interoperability work for SHA-1/SHA-256 mapping

3. **Bugfixes**:
   - Corrections for `refs_for_each_ref_in()` API misuse
   - Leak fixes in remote tracking ref handling
   - Shallow fetch fixes for relative deepen operations
   - Various memory leak and error handling improvements

The report also lists several topics that have been discarded due to inactivity, including some long-pending patches for config handling, worktree documentation, and rebase trailer support.

Several topics are marked as ready to merge to 'next' (the integration branch for stable patches), while others await further review or rerolls. The report provides a comprehensive snapshot of Git's development pipeline, showing both the breadth of ongoing work and the project's careful approach to integration.
