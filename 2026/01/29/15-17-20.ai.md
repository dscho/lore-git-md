This is a bugfix for git-gui's diff viewer, finalizing the solution to align tab display with gitk's behavior. The patch thread has reached consensus after thorough review, with Junio Hamano confirming that git-gui only needs to handle 3-way diffs (not octopus merges) since it shows index contents rather than commit history.

The technical approach uses Tk's native `apply_tab_size` configuration with different tabstop offsets (1 for regular diffs, 2 for combined diffs) to compensate for diff markers while preserving staging functionality. Johannes Sixt clarified that git-gui's scope is limited to showing index contents with "theirs" and "ours" comparisons, making octopus merge handling unnecessary.

Junio's email serves as final validation that the patch is documentation-complete and ready for merging. The solution matches gitk's behavior from 2007 while maintaining all existing staging interface capabilities ("Stage Line/Hunk for Commit").
