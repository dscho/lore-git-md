Feature: adding a `@{default}` shorthand for the default branch.

This patch introduces a new branch shorthand `@{default}` that resolves to the repository's default branch (typically "main" or "master"), similar to existing shorthands like `@{upstream}` and `@{push}`. The motivation is to provide a convenient way to reference the default branch without needing to know or look up its name, which is particularly useful when working across repositories with different default branch names.

The implementation follows the same pattern as other branch shorthands, adding a new `branch_get_default_ref()` function that queries the default branch name from `init.defaultBranch` configuration (falling back to "main" or "master" depending on Git version) and verifies it exists. The change includes documentation updates and test coverage in `t1508-at-combinations.sh` and `t2012-checkout-last.sh`.

The patch appears well-structured with clear motivation, implementation following existing patterns, and appropriate test coverage. This seems like a useful quality-of-life improvement for users who frequently switch between repositories with different default branch names. The change is relatively self-contained and unlikely to be controversial, though reviewers may want to verify the fallback behavior and error handling.
