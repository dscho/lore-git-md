This is a two-patch series improving the advice messages from `git switch` when encountering ambiguous remote branch names. The series comes from maintainer Junio C Hamano in response to user feedback from Simon Cheng.

The first patch refactors the internal plumbing of checkout/switch/restore commands to pass an enum rather than strings to identify which command is being executed. This sets up the infrastructure needed for the second patch's behavior change while maintaining identical external behavior.

The second patch modifies the advice text to suggest `git switch --track` (rather than `git checkout --track`) when the failure occurs during `git switch`. This makes the advice more contextually appropriate since users will want to continue using the command they originally invoked. The patch includes tests verifying both the old checkout behavior and new switch behavior.

The series demonstrates Git's typical pattern of separating refactoring from behavior changes. The changes are well-contained and focused, touching only the advice message generation while maintaining thorough test coverage. The v2 iteration incorporates review feedback from Kristoffer Haugsbakk to simplify some test assertions while keeping the core functionality intact.

This is a straightforward quality-of-life improvement that makes Git CLI behavior more consistent and user-friendly. The changes are non-controversial and likely to be merged quickly given they come from the maintainer with positive review feedback already incorporated.
