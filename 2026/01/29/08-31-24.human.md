This is a bugfix thread for git-gui addressing tab alignment inconsistencies in the diff viewer. Chris Idema confirms their solution using Tk's `apply_tab_size` now works across all diff states (regular, staged, merge conflicts, untracked files) after Junio Hamano provided technical analysis and commit message guidance. The fix matches gitk's long-standing behavior where tabstops are offset to account for diff markers.

Junio had tempered the urgency assessment, noting the misalignment existed for nearly two decades without significant complaint, but validated the technical approach. The thread shows consensus on the solution path, with Chris now seeking clarification on handling octopus merges (>2 parents) which Junio mentioned but considered out of scope for this fix. The patch appears ready for final review from maintainer Johannes Sixt once these last details are addressed.
