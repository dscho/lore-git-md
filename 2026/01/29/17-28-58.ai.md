This is a bugfix patch in the ongoing series addressing `refs_for_each_ref_in()` misuse in bitmap and bisect functionality. Jeff King (Peff) follows up on Patrick Steinhardt's earlier fix for the bisect case with a cleanup to simplify string_list memory management.

The patch switches from NODUP to DUP mode for the refs_for_removal string_list, eliminating manual string duplication in mark_for_removal() and redundant cleanup handling. This change is made possible by Patrick's prior fix that removed the need for xstrfmt() by using refs_for_each_fullref_in() to get properly formatted ref names directly. The cleanup maintains identical functionality while making the code more straightforward.
