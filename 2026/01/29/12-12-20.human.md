This is a refactoring patch that introduces a new utility function `string_list_sort_u()` to combine the common pattern of sorting a string list followed by removing duplicates. The patch is part of an RFC series by Amisha Chhajed that aims to simplify call sites where these operations are always performed together.

The new function wraps the existing `string_list_sort()` and `string_list_remove_duplicates()` calls, reducing boilerplate at multiple call sites. The patch mechanically converts several existing instances across clone.c, fast-export.c, pack-objects.c, sparse-checkout.c, help.c, and notes.c to use the new combined function.

The implementation is straightforward and maintains the same behavior as the separate calls. The patch includes comprehensive unit tests in t/unit-tests/u-string-list.c that verify the combined sort+deduplicate operation works correctly, including edge cases with empty strings and multiple duplicates.

This change appears well-scoped and non-controversial, with the motivation clearly explained in the commit message. The patch follows established patterns in the codebase and includes appropriate test coverage. It's part of a larger effort to improve the string-list API's ergonomics, with Junio Hamano having suggested the original idea.
