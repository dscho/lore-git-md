This is part 9/14 of Patrick Steinhardt's ODB abstraction series, converting promisor object enumeration to use the new `odb_for_each_object()` API. The patch refactors three call sites (`packfile.c`, `repack-promisor.c`, and `revision.c`) that previously used `for_each_packed_object()` with the `PROMISOR_ONLY` flag.

The key technical changes include:
1. Adapting callback signatures to match the new ODB API, replacing packed-git-specific parameters with a generic `object_info` struct
2. Consolidating promisor object handling through the unified iteration interface
3. Maintaining all existing behavior while eliminating direct packed-git dependencies
4. Adding a new `add_promisor_object_data` struct to pass repository context through the callback chain

The changes demonstrate the practical benefits of the ODB abstraction by:
- Simplifying the promisor object enumeration code
- Removing packed-git-specific logic from high-level operations
- Preserving all existing functionality including pack ordering and object parsing
- Reducing direct dependencies on the packed object storage implementation

This patch follows naturally from the earlier infrastructure work in the series, particularly the introduction of `odb_for_each_object()` in patch 7/14. It shows the kind of mechanical but meaningful conversion the new API enables, moving more of the codebase toward backend-agnostic object storage operations.
