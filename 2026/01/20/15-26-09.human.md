This is part of Patrick Steinhardt's ongoing ODB abstraction series, specifically converting the reachable.c code to use the new `odb_for_each_object()` API. The patch simplifies object iteration for determining recent objects by replacing separate loose and packed object iteration paths with a unified callback-based approach.

The change demonstrates the practical benefits of the ODB abstraction by:
1. Eliminating 90 lines of redundant code that previously handled loose and packed objects separately
2. Using the new mtime tracking capability (added in an earlier patch) through the `object_info` struct
3. Maintaining all existing functionality including pack order traversal and in-core kept pack handling

The conversion shows how the new API can clean up complex iteration patterns - in this case, the code that identifies unreachable objects for potential pruning. The patch keeps the same behavior but does so through a single callback function that works for both loose and packed objects, with the mtime and type information now provided directly by the iteration infrastructure.

This is the 13th patch in a 14-part series that Junio has indicated is nearly ready for merging, with all major technical concerns addressed in previous rounds of review. The series represents a significant step toward pluggable object storage backends in Git.
