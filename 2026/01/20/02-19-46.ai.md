Documentation patch for `git replay` manual page cleanup, removing unused formatting options.

Junio C Hamano responds to D. Ben Knoble's patch that removes the unused "Commit Formatting" section from `git-replay.adoc` by conditionally excluding it when the `git-replay` attribute is set, following the same pattern used for `git shortlog`. Junio notes this is the first use of multiple attributes in an `ifndef` directive in Git's documentation, making the syntax somewhat novel and potentially confusing - it's unsure whether the attributes are ANDed or ORed in this context. While approving the change, he suggests the observation about this being the first instance of this syntax pattern should be mentioned in the commit message for clarity.

The patch itself is straightforward, adding the `git-replay` attribute in `git-replay.adoc` and updating the conditional in `rev-list-options.adoc` to skip the formatting section for both `git-shortlog` and `git-replay`. This continues Git's documentation housekeeping effort to keep manual pages focused on relevant content. Junio's response indicates the change is technically sound but highlights the syntactic novelty that might benefit from explicit documentation in the commit message.
