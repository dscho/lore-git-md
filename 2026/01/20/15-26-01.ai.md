This is part 5/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch refactors packed object iteration to prepare for backend-agnostic object storage.

The change extracts the core logic from `for_each_packed_object()` into a new internal function `packfile_store_for_each_object_internal()`. This prepares for an upcoming commit that will introduce similar iteration for packfile stores while maintaining backend independence through `struct object_info`.

Key technical aspects:
- Preserves all existing flag handling (LOCAL_ONLY, PROMISOR_ONLY, etc.)
- Maintains error reporting through `pack_errors` parameter
- Keeps the MRU (most recently used) update suppression behavior
- The extracted function will be reused in the new packfile store interface

The refactoring is mechanical and doesn't change behavior - it just moves code in preparation for the new functionality coming in the next patch. The changes touch core packfile handling but have already been reviewed by Karthik Nayak and Justin Tobler in previous iterations.

This continues the series' pattern of carefully restructuring object storage internals to support pluggable backends while maintaining existing functionality. The patch is well-contained and follows the established approach seen in earlier parts of the series.
