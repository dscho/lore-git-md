CI optimization follow-up. Phillip Wood responds to Junio C Hamano's implementation of skipping CVS and P4 tests in leak-checking CI jobs, which builds on Johannes Schindelin's earlier git-svn test optimization. The thread has established consensus around this pattern for specialized CI contexts where certain tests provide minimal value relative to their runtime cost.

Phillip confirms the technical approach of placing the skip logic in library files (t/lib-cvs.sh and t/lib-git-p4.sh) rather than individual test scripts, and raises a new consideration: whether these same tests should also be excluded from the ASan (AddressSanitizer) jobs. This suggests the optimization pattern might extend further, though Phillip doesn't provide specific runtime data for ASan as was done for the leaks jobs (where CVS/P4 tests accounted for 24 minutes).

The email includes Junio's complete patch implementing NO_CVS_TESTS and NO_P4_TESTS variables, which follow the same pattern as NO_SVN_TESTS - setting an arbitrary non-empty value (LetsSaveSomeTime) in ci/lib.sh for relevant jobs, with corresponding early-exit checks in the test libraries. The implementation is clean and consistent with existing conventions. Phillip's question about ASan applicability hints at potential future work, though the current changes are narrowly scoped to leak-checking contexts.
