This is part 6/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch introduces a new function `packfile_store_for_each_object()` that provides a consistent interface for iterating through objects in packfiles, mirroring the existing loose object iteration interface.

The new function serves as a building block for the unified `odb_for_each_object()` API that will work across all object storage backends. It includes support for passing a `struct object_info` to the callback, allowing callers to efficiently access object metadata during iteration. The implementation wraps existing packfile iteration logic while maintaining the same error handling patterns.

This is a well-structured technical patch that follows the series' architectural direction. It has already undergone review from Justin Tobler and Karthik Nayak, with Junio Hamano indicating readiness to merge the series pending minor documentation fixes. The change is part of the larger effort to make Git's object storage layer backend-agnostic.
