This thread began with Phillip Wood submitting a straightforward mailmap patch to consolidate his contributor identity by mapping two alternate email addresses to his canonical one. The discussion took an interesting turn when Kristoffer Haugsbakk initially claimed Git remaps email addresses in commit trailers, prompting Junio Hamano to clarify that .mailmap entries only affect author/committer metadata, not trailers like Signed-off-by - a design choice to preserve privacy and non-email content in trailers.

Jeff King (Peff) later expanded on this by noting that while mailmap doesn't modify raw trailer contents, some tools like `git shortlog` do apply mailmap when displaying trailers by parsing them as idents. He referenced both the existing implementation and an old proof-of-concept for broader trailer mapping that was never merged. The thread has served to clearly document mailmap's current behavior - normalizing author fields while leaving trailers intact unless specifically processed by certain tools - without requiring any changes to Phillip's original patch. The discussion provides valuable context about this edge case in Git's attribution handling while maintaining the patch's validity for its intended purpose of standardizing author identification.
