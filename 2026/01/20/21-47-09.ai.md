This is a documentation and implementation patch for the ongoing `git-last-modified` experimental command series. It focuses on properly documenting and handling the `-z` NUL-termination option.

The patch, part of v3 series (2/4), makes two key changes:
1. Adds comprehensive documentation for the `-z` option in the man page, including its effect on output format and placement in both SYNOPSIS and OPTIONS sections
2. Moves `-z` option handling from diff machinery into the command's own `parse_options()`, introducing a new `nul_termination` boolean flag

The changes ensure the option appears in `-h` help output and is properly documented, while simplifying the implementation by removing reliance on diff's `line_termination` field. The output logic is updated to check the new flag while maintaining identical behavior.

This continues the series' trend of making options more discoverable and self-contained. The patch follows the established pattern of other Git commands that support NUL-termination, with clear documentation of both linefeed and NUL output formats in a new OUTPUT section. The implementation change aligns with Junio's earlier suggestion to handle command-specific options locally rather than through diff machinery.
