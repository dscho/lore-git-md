This is a test modernization patch in the ongoing effort to improve Git's test suite reliability. The patch addresses exit code suppression in t5500-fetch-pack.sh, specifically for testing shallow fetch behavior with commit graphs.

The changes simplify the test implementation by moving Git command execution outside of here-docs and pipes where failures could be silently suppressed. The new approach uses `test-tool pkt-line pack` to properly format protocol packets, storing object IDs in shell variables (`oid_algo`, `oid_other`, `oid_main`) for immediate failure detection. This follows Junio Hamano's earlier approval of using `test-tool pkt-line pack` for such cases.

Junio provides detailed feedback on the commit message wording, suggesting improvements to make the problem statement clearer and the solution more explicitly documented. He notes minor formatting issues (line wrapping and trailing whitespace) but overall approves the technical approach. The patch represents the culmination of a successful GSoC collaboration between Shreyansh Paliwal and mentors Patrick Steinhardt and Junio, with all prior concerns about portability and exit code reliability having been addressed.
