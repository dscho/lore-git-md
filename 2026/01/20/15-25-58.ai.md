This is part 2/14 of Patrick Steinhardt's ODB abstraction series, which is now in final integration phase. The patch fixes the type signature of flags parameters in several object database iteration functions to use `unsigned` instead of `enum odb_for_each_object_flags`, bringing them in line with Git's convention for bitfield parameters.

The change is mechanical but important for consistency - it updates function signatures in object-file.c/h and packfile.c/h that deal with object iteration. The patch follows the flag renaming done in patch 1/14 and precedes the introduction of new ODB iteration interfaces in later patches. Reviewers Justin Tobler and Karthik Nayak have already validated the overall approach in this series, and this particular change aligns with established Git coding patterns for flag parameters.

Key technical details:
- Changes function parameters from `enum odb_for_each_object_flags` to `unsigned` in:
  - `odb_source_loose_read_object_info()`
  - `for_each_object_in_pack()`
  - `for_each_packed_object()`
- Maintains identical behavior while fixing type signatures
- Touches core object database interfaces that will be used by the new ODB abstraction layer

This is a straightforward cleanup patch that follows the project's conventions for bitfield parameters. As part of the well-reviewed ODB abstraction series, it helps establish consistent interfaces for the more substantial changes that follow.
