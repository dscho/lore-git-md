[RFC PATCH] symlinks: use unsigned int for bitmask flags
Author: Tian Yuchen
Files: symlinks.c, symlinks.h

Core change: converts `int` to `unsigned int` for all flag variables in symlink handling code to properly represent bitmask usage and prevent undefined behavior with shift operations. Specifically updates:
- `flags` and `track_flags` in `struct cache_def`
- Function parameters and local variables in symlinks.c

Technical details:
- Changes are purely type-only; no behavioral modifications
- Affects symlink caching and tracking logic
- Follows C best practice for bitmask operations

Status: RFC - seeking feedback on approach before finalizing. No version history yet as this is the initial proposal.
