This is part 7/14 of Patrick Steinhardt's ODB abstraction series, introducing a new iteration function for object database traversal. The patch adds `odb_for_each_object()` as a unified interface to iterate through all objects in an object database, wrapping the existing loose and packed object iteration mechanisms.

The new function provides a single entry point that:
- Both loose and packed object iteration
- Flag handling for `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` and `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`
- Callback-based iteration pattern matching the existing `odb_source_loose_for_each_object()`
- Error propagation from callbacks
- Alternates database preparation

The implementation delegates to existing per-source iteration functions while maintaining the same callback signature. This continues the series' pattern of introducing backend-agnostic APIs while preserving the existing behavior. The documentation notes that objects may be visited multiple times if they exist in multiple sources - a behavior inherited from the underlying iteration mechanisms.

This transitional wrapper is part of the larger effort to abstract Git's object storage layer, with subsequent patches adapting callers to use this new interface. The implementation appears straightforward and aligns with the series' architectural direction, though the commit message could better explain why this wrapper is needed beyond being "essentially simple" - likely to provide a unified interface while the backend-specific implementations are still being refactored.
