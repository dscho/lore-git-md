This thread documents a straightforward but technically precise improvement to Git's documentation. D. Ben Knoble noticed that `git-replay`'s manual page was including a "Commit Formatting" section that isn't actually used by the command, similar to how `git shortlog` handles the same situation. His solution involves adding conditional logic to exclude this section when the documentation is included by `git-replay.adoc`.

The technical nuance here is the use of a multiple-attribute `ifndef` directive - a first in Git's documentation - which required verification that it works with both Python and Ruby implementations of AsciiDoc. Junio C Hamano reviewed the initial version and suggested documenting this novel syntax in the commit message, which Knoble incorporated in v2. With that addition and confirmation that the syntax works as intended, this small but clean documentation improvement appears ready to be merged. The change follows Git's ongoing effort to keep manual pages focused on relevant content by excluding unused sections.
