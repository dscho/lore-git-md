This thread covers two complementary documentation improvements that have now been finalized. The initial work by D. Ben Knoble cleaned up the `git-replay` manual page by removing a redundant "Commit Formatting" section when the page is included via `rev-list-options.adoc`, following the pattern previously established for `git shortlog`. This required introducing new conditional syntax in the AsciiDoc source files.

Junio C Hamano reviewed the change and identified a linting issue with the new multiple-attribute syntax, which he promptly fixed by adjusting the documentation linter's regex patterns. Jean-Noël Avila then followed up with a more comprehensive solution that simplifies the linter by having it skip any lines containing `ifdef`/`ifndef`/`endif` block macros entirely, making the tool more robust when processing complex conditional blocks. This final patch completes the tooling support needed for the documentation pattern and prevents similar issues in future documentation changes.

All parties involved - D. Ben Knoble for the original documentation change, Junio for the initial linter fix, and Jean-Noël for the refined solution - have signed off on their respective contributions. With these changes, both the `git-replay` documentation cleanup and the supporting linter improvements are ready for merging, marking another step forward in Git's ongoing documentation standardization efforts.
