This thread documents the completion of two coordinated documentation improvements. First, D. Ben Knoble updated the `git-replay` manual page to properly exclude the "Commit Formatting" section when included via `rev-list-options.adoc`, following the pattern established for `git shortlog`. This required complementary changes to the documentation linter to handle the new multiple-attribute `ifndef` syntax.

Junio C Hamano initially adjusted the linter's regex patterns to accommodate the new syntax, while Jean-Noël Avila later refined the approach by having the linter treat conditional blocks (`ifdef`/`ifndef`/`endif`) as block-level constructs rather than inline elements. This more robust solution prevents false positives when checking `linkgit:` macros in files with complex conditionals. Both changes have been finalized and merged, marking another step forward in the project's ongoing documentation standardization efforts led by Jean-Noël Avila. The work maintains compatibility with both AsciiDoc processors while improving the tooling for future documentation maintenance.
