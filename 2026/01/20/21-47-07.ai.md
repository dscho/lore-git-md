This is a feature patch series for the experimental `git-last-modified` command, focusing on improving its default behavior and documentation. The series addresses user confusion around the command's recursive behavior and adds proper documentation for existing options.

The key change in v3 is simplifying the depth control implementation by removing the redundant `recursive` flag and making `--recursive` set `max_depth=-1`. This follows Junio's suggestion to clarify that any negative `--max-depth` means unlimited recursion. The series also renames `<path>` to `<pathspec>` in documentation for accuracy.

The most significant behavior change comes in the final patch, which makes the default `max-depth=0` (non-recursive) to match user expectations when operating on subdirectories. This addresses real user reports of confusing output when running the command on specific files. The documentation now clearly explains all options, including the previously undocumented `-z` for NUL-terminated output.

The implementation moves option parsing for `-z` and `--max-depth` into the command's own `parse_options()` call rather than relying on diff machinery internals. This makes the options properly appear in help output while maintaining the same functionality. Test coverage has been expanded to verify the new default behavior with subdirectories.

The series represents the culmination of several iterations refining both the implementation and documentation of this experimental command. With these changes, the behavior should be more intuitive while maintaining all existing functionality through explicit options. The simplified control flow around recursion makes the implementation more straightforward.
