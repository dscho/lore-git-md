This is part 3/14 of Patrick Steinhardt's ODB abstraction series, which aims to make Git's object storage backend-agnostic. The patch refactors loose object handling in `object-file.c` by extracting a new `read_object_info_from_path()` function that reads object information given a direct path, rather than going through the loose object lookup machinery.

The change allows removing the now-redundant `stat_loose_object()` helper and consolidates the path handling logic. Karthik Nayak has already verified the path efficiency improvements in this optimization. The patch is a focused, mechanical change that fits cleanly into the larger series' goal of abstracting object storage access.
