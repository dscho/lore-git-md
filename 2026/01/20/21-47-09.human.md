This is a documentation and implementation patch for the ongoing `git-last-modified` experimental command series. It's part 2 of a 4-part v3 series that improves the command's depth control behavior and documentation.

The patch focuses on properly documenting and implementing the `-z` option for NUL-terminated output, which was previously supported but not documented. The changes include:
1. Adding `-z` to the SYNOPSIS and OPTIONS sections of the man page
2. Creating a new OUTPUT section that explains both newline and NUL-terminated formats
3. Moving the `-z` option handling from diff machinery into the command's own `parse_options()`
4. Updating the command's usage string to include `-z`

The implementation change makes the code more self-contained by handling the NUL-termination option directly rather than relying on diff machinery's `line_termination` field. The patch maintains backward compatibility while making the option more discoverable through both documentation and help text.
