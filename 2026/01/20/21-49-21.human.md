This is a follow-up to a documentation patch that removes unnecessary formatting options from the `git replay` manual page. The patch had already been reviewed and approved in its second iteration (v2), with Junio C Hamano noting that the novel use of compound `ifndef` directives in AsciiDoc should be documented in the commit message.

In this email, Junio points out that while the patch itself is sound, there's an additional linting issue to address. The `lint-docs` target in the Documentation/ directory fails because the lint-gitlink.perl script isn't expecting the new multiple-attribute syntax used in the documentation. This isn't a blocker for the original patch (which is still ready to merge), but it does identify a follow-up task to update the linter to recognize this now-valid documentation pattern.

The exchange shows the typical Git workflow where even after a patch is approved, additional polish may be needed in related areas. Junio's comment is characteristically pragmatic - noting the issue but not holding up the original improvement, trusting that the CI will catch any real problems while explicitly pointing out where the linter needs updating.
