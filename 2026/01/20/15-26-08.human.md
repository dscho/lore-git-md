This is part 12 of Patrick Steinhardt's 14-part ODB abstraction series, converting `git pack-objects` to use the new object database iteration API. The patch refactors cruft pack generation to use `packfile_store_for_each_object()` instead of the older `for_each_packed_object()`, simplifying the mtime handling logic.

The change moves mtime collection into the object info callback structure, where it's automatically handled for both regular packs and cruft packs (which store per-object mtimes). This eliminates manual mtime lookup code while maintaining the same behavior. The patch demonstrates how the new ODB API can simplify callers by handling backend-specific details like mtime storage internally.

This continues the series' pattern of converting individual commands to the new API after establishing the core infrastructure in earlier patches.
