This is the first patch in Patrick Steinhardt's 14-part ODB abstraction series, which is part of the ongoing effort to make Git's object storage layer backend-agnostic. The patch performs a mechanical rename of the `FOR_EACH_OBJECT_*` flags to use an `ODB_` prefix, preparing for the introduction of a new `odb_for_each_object()` function in later patches. The change ensures consistent naming between the upcoming function and its associated flags.

The patch touches 11 files across core Git subsystems including object-file handling, packfile operations, and reachability calculations. It updates flag names in function calls and declarations while maintaining identical behavior. The changes are straightforward and mechanical, with no functional impact - this is purely a naming change to establish consistent terminology for the ODB abstraction work.

Key technical details:
- Renames all `FOR_EACH_OBJECT_*` flags to `ODB_FOR_EACH_OBJECT_*` (e.g. `FOR_EACH_OBJECT_PACK_ORDER` becomes `ODB_FOR_EACH_OBJECT_PACK_ORDER`)
- Updates function parameters and calls across multiple subsystems to use the new names
- Maintains all existing flag semantics and behavior remains unchanged
- Touches core commands like `cat-file`, `pack-objects`, and `commit-graph`

This patch serves as foundational work for the larger ODB abstraction effort, establishing naming conventions that will be used in subsequent patches. The changes are straightforward and unlikely to be controversial, having already passed review from Justin Tobler and Karthik Nayak in the v2 iteration.
