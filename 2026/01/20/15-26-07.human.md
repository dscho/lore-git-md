This is part 11/14 of Patrick Steinhardt's ODB abstraction series, which is nearing final integration. The patch introduces mtime tracking for objects in the object database interface, a key capability needed for pruning unreachable objects.

The change adds a new `mtimep` field to `struct object_info` that callers can use to request an object's modification time. The implementation handles both loose objects (using filesystem mtime) and packed objects (using packfile mtime or the .mtimes file for cruft packs). The patch includes careful handling across all object storage backends with appropriate fallbacks when mtime isn't available.

This is a well-constructed piece of infrastructure work that builds on the ODB abstraction layer being established in the series. The changes are focused and clearly motivated, with clean integration into the existing object info machinery. The patch follows the series' pattern of careful, incremental changes to the object storage layer while maintaining all existing behavior.
