This is part 10/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch refactors remaining uses of `for_each_loose_object()` and `for_each_packed_object()` to use the new ODB API functions `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()`.

The changes focus on two key subsystems:
1. `builtin/cat-file.c` - Updates the batch object iteration to use the new ODB interfaces while maintaining the same callback behavior. The refactoring handles both loose and packed objects through the new API.
2. `commit-graph.c` - Consolidates packed commit enumeration into a new `add_packed_commits_oi()` helper that works with the object-info based callback signature. The changes preserve all existing functionality while switching to the new iteration API.

The patch demonstrates the transitional nature of this series - while some callers can't yet use the fully generic `odb_for_each_object()`, this moves them to the new backend-specific iteration functions that will eventually replace the old ones. The changes are mechanical but important for completing the ODB abstraction by removing dependencies on the old iteration patterns.

This continues the pattern seen in earlier patches where real-world commands (here `git cat-file` and commit-graph writing) are updated to use the new APIs while maintaining all existing behavior. The changes are well-contained and follow the established patterns from previous patches in the series.
