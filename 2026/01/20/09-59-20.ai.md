This is a refactoring patch in a completed bugfix series (v3 2/6) from Karthik Nayak and Jeff King that restores detailed error messages for batched reference updates. The patch extends the callback function signature for handling rejected ref updates to include rejection details, though the actual usage of these details will come in later patches.

The change modifies the `ref_transaction_for_each_rejected_update_fn` callback to accept a `details` parameter, which will contain the specific error message for failed reference updates. The patch updates are mechanical - adding the parameter to callback implementations in `fetch.c`, `receive-pack.c`, and `update-ref.c`, plus the corresponding plumbing through `refs.c` and `refs.h`.

This is part of a larger effort to fix a regression where batched reference updates lost detailed error messages that were previously available. The series maintains backward compatibility while restoring this diagnostic information. The changes here are straightforward and uncontroversial, serving as infrastructure for the more substantive error reporting improvements that follow in the series.
