Refactoring patch in Patrick Steinhardt's ODB abstraction series. This is patch 2/14 in the v2 iteration of the series that's nearing final integration.

The patch fixes the type signature for flags parameters in several object database iteration functions, changing them from `int` or `enum odb_for_each_object_flags` to `unsigned` to match Git's convention for bitfield parameters. It touches four files (object-file.[ch] and packfile.[ch]) with straightforward mechanical changes to function declarations and definitions.

This is a small but important consistency fix in the larger effort to make Git's object storage layer backend-agnostic. The changes are purely type-system related and don't affect runtime behavior. The patch has already been reviewed by Justin Tobler and Karthik Nayak as part of the thorough review process for this series.
