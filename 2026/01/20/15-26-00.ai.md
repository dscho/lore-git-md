Part of Patrick Steinhardt's ODB abstraction series, this patch introduces a new interface for iterating through loose objects in a backend-agnostic way. The key addition is `odb_source_loose_for_each_object()`, which provides a more flexible iteration mechanism than the existing `for_each_loose_object()` by accepting a `struct object_info` parameter that gets populated similarly to a direct object read.

The new function serves as a building block for unifying object iteration across different storage backends (loose and packed objects). It maintains the same callback pattern but adds the ability to gather object metadata during iteration. The implementation includes proper handling of flags like `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY` and `ODB_FOR_EACH_OBJECT_LOCAL_ONLY`.

This is a technical refactoring that doesn't change behavior but enables future patches in the series to standardize object iteration. The patch touches core object-file handling code and adds new declarations to both object-file.h and odb.h. The existing `for_each_loose_object()` is kept for eventual removal later in the series.
