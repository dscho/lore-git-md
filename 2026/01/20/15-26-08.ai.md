This is part of Patrick Steinhardt's ongoing ODB abstraction series (now 14 parts), specifically converting `git pack-objects` to use the new object database iteration API. The patch refactors cruft pack generation to use the new `packfile_store_for_each_object()` function instead of the older `for_each_packed_object()` approach.

The key change moves mtime handling into the object info callback structure (`struct object_info`) that gets passed through the iteration. This eliminates manual mtime lookup code that previously had to handle both regular packs (using packfile mtime) and cruft packs (using per-object mtimes from the `.mtimes` index). The new version relies on the mtime tracking infrastructure added in patch 11/14, which provides uniform access to modification times across all storage types.

The patch demonstrates the series' goal of consolidating object iteration patterns - here replacing a specialized packed-object walk with the more general ODB API while maintaining identical functionality. The callback function `add_object_in_unpacked_pack` becomes simpler by receiving pre-computed mtimes through the object info struct rather than calculating them itself.

This change affects the core pack-objects machinery that generates both regular and cruft packs, though the behavioral impact is neutral - it's purely an internal refactoring to adopt the new ODB interfaces. The patch follows the series' established pattern of converting commands one by one to demonstrate real-world use of the abstraction layer.
