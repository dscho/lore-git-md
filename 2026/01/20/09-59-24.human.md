This is the final patch in a bugfix series (v3, 6/6) from Karthik Nayak and Jeff King that restores detailed error messages for batched reference updates in `git fetch`. The series addresses a regression where error messages were lost when reference operations failed during batched updates.

The patch introduces a new `struct ref_update_display_info` to collate update outcomes and delays status printing until after the transaction is committed. This allows showing detailed error messages that were previously lost when updates were batched. The approach uses a dynamic array to store update information, with benchmarks showing minimal performance impact (about 1% slower for 1000 refs).

Key changes include:
- New data structure to track update status and messages
- Modified `update_local_ref()` to append to display list rather than printing immediately
- Final display phase that shows all updates with their success/failure status
- Additional test coverage for error message output

The patch maintains backward compatibility while fixing the regression, ensuring users see the same detailed error messages they got before batched updates were introduced. This completes the series' goal of restoring pre-batched-update error reporting functionality.
