This is the final patch in a series implementing the experimental `git-last-modified` command, focusing on changing the default behavior for path handling. The patch changes the default `max-depth` to 0 (non-recursive) to provide more intuitive results when querying specific files in subdirectories.

Previously, when given a path like `path/file`, the command would only show the modification time of the containing directory `path`. With this change, it now shows the modification time of the exact file specified. The `--recursive` option is modified to set `max-depth=-1` (unlimited) to maintain backward compatibility with existing uses.

- Documentation updates explaining the new default behavior
- Code changes to implement the new depth handling
- New test cases verifying the behavior with subdirectories and various depth settings
- The implementation simplifies the control flow by removing a redundant `recursive` flag
