This is a documentation and implementation patch for the experimental `git-last-modified` command, part of a series standardizing its depth control behavior. The patch documents the `--max-depth` option in both the man page and command-line help output, while moving the option's handling into the command's own `parse_options()` rather than inheriting it from the diff machinery. 

The changes include:
- Adding `--max-depth` to the SYNOPSIS and OPTIONS sections of the man page, explaining that it means unlimited recursion when negative and defaults to 0 (no recursion)
- Updating the command's usage string to show the new option
- Adding option parsing for `--max-depth` directly in `builtin/last-modified.c`
- Setting up the diff machinery flags based on the parsed max-depth value
- Preparing for a subsequent change to the depth behavior by initializing max_depth to -1 ("unset")

This continues the thread's progression toward making depth control more explicit and better documented, following Junio's earlier suggestions. The patch maintains all existing functionality while improving discoverability through documentation and help text. It's part of a well-structured series that has addressed reviewer feedback through multiple iterations.
