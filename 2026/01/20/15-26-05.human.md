This is part 9/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch converts several callsites that enumerate promisor objects to use the new `odb_for_each_object()` API instead of the older `for_each_packed_object()`.

The change is straightforward - it updates three locations (`packfile.c`, `repack-promisor.c`, and `revision.c`) to use the unified object database iteration interface. The key behavioral change is that these calls now explicitly skip loose object enumeration when the `PROMISOR_ONLY` flag is set, since promisor objects are always packed.

The patch demonstrates the practical benefits of the ODB abstraction by showing how multiple subsystems can be simplified to use a single iteration API. The changes are mechanical but important for maintaining consistency across the codebase as part of this large-scale refactoring effort.
