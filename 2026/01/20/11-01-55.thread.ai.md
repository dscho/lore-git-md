Kristoffer Haugsbakk initially incorrectly claimed Git remaps email addresses in commit trailers, but Junio Hamano demonstrated with a test case that .mailmap entries only affect author/committer metadata, not trailers like Signed-off-by. This is intentional design since trailers may contain non-email content or omit emails for privacy. Kristoffer later corrects his statement, acknowledging he confused the behavior with git-shortlog's mailmap handling.

Jeff King (Peff) elaborates that while mailmap doesn't change raw trailer contents, some Git commands like `git shortlog` do apply mailmap when displaying trailers by parsing them as idents (implemented in commit 56d5dde752). Peff mentions an old proof-of-concept patch to make mailmap apply more broadly to trailers, though it was never merged. The discussion documents mailmap's current scope - normalizing author/committer names while leaving trailers intact unless specifically parsed by tools like shortlog.
