Performance optimization for sparse-checkout pattern handling, completing a series that changes the pattern sorting from O(n^2) to O(n log n). This v6 patch from Amisha Chhajed finalizes the optimization by switching from `string_list_insert()` to `string_list_append()` followed by sorting, while also ensuring proper deduplication of patterns.

The patch modifies two functions in `builtin/sparse-checkout.c` that build pattern lists, adding explicit sorting and deduplication steps. The change is particularly relevant for large pattern sets where the previous insertion sort approach became inefficient. The commit includes new tests that verify the deduplication behavior works correctly in both the sparse-checkout file and when listing patterns.

This iteration addresses all previous feedback, including test coverage concerns raised by Derrick Stolee and path normalization cases noted by Pushkar Singh. The discussion has settled with Junio Hamano and Jeff King agreeing the optimization is sound and doesn't require additional performance testing beyond what's shown in the commit message. The patch appears ready for merging as part of the ongoing sparse-checkout optimizations.
