This is a documentation patch that cleans up the manual page for `git replay` by removing unnecessary formatting options that don't apply to this command. 

D. Ben Knoble noticed that `git-replay.adoc` was including the full set of `rev-list` formatting options even though `replay` doesn't use them (it has its own output format). The patch adds a conditional flag (`git-replay`) to exclude these formatting sections when included by the replay documentation, while keeping them available for other commands that do need them.

The change is straightforward - it adds the new condition alongside the existing `git-shortlog` condition that was already excluding these sections. The patch includes a minor note about the author's research into Asciidoc's multiple attribute syntax, though this doesn't affect the technical content of the change.

This appears to be a simple but worthwhile documentation hygiene improvement that makes the manual page more accurate by removing irrelevant content. The change is small, focused, and clearly explained in the commit message.
