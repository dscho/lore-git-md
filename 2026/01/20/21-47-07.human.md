This is a feature patch series that changes the default behavior of the experimental `git-last-modified` command to be more intuitive for users. The series comes from Toon Claes and represents version 3 of this effort.

The key change is making the command non-recursive by default (depth=0) when operating on subdirectories, rather than unexpectedly showing results for the top-level tree. This addresses multiple user reports of confusion with the current behavior. The series also improves documentation and help text for the `-z` and `--max-depth` options.

The implementation builds on the diff machinery's depth control while simplifying the internal handling of recursive behavior. The changes are well-motivated by real user confusion and include thorough test coverage. The documentation improvements make the command's behavior more discoverable and predictable.
