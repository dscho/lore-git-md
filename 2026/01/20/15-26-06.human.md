This is part 10/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch removes uses of `for_each_loose_object()` and `for_each_packed_object()` in favor of the new backend-agnostic APIs introduced earlier in the series.

The changes primarily affect `builtin/cat-file.c` and `commit-graph.c`, converting them to use the new iteration interfaces (`odb_source_loose_for_each_object()` and `packfile_store_for_each_object()`). The patch demonstrates how the new APIs can replace the old object iteration functions while maintaining the same functionality.

Key technical points:
- The `cat-file` command's object iteration is updated to handle both loose and packed objects through the new interfaces
- The commit-graph writing code is modified to use the packed object iteration API
- Callbacks are adapted to work with the new `object_info`-based interface
- The changes are mechanical refactorings that don't introduce new behavior
- Some callers still can't use the fully generic `odb_for_each_object()` yet, as noted in the commit message

This patch represents the final step in removing the old object iteration APIs, building on the foundation laid by earlier patches in the series. The changes are straightforward conversions to the new interfaces, with careful attention to maintaining existing behavior.
