This is part of Patrick Steinhardt's ongoing ODB abstraction series (patch 8/14), converting `git fsck` to use the new `odb_for_each_object()` API. The patch simplifies two key operations in fsck` - marking objects for connectivity checks and identifying unreachable referents - by replacing separate `for_each_loose_object()` and `for_each_packed_object()` calls with the unified interface.

The changes are mechanical but significant:
1. Combines three separate callback functions for loose/packed object iteration into single handlers (`mark_unreachable_referents` and `mark_object_for_connectivity`)
2. Updates the callback signatures to match the new ODB API, adding `struct object_info` parameters
3. Reduces code duplication by 45 lines while maintaining identical functionality
4. Preserves all existing behavior flags (HAS_OBJ, REACHABLE) and error handling

The patch demonstrates the practical benefits of the ODB abstraction by showing how it simplifies real-world command implementations. Since this is part of a well-reviewed series that's nearing merge readiness, the changes here follow established patterns from earlier patches and don't introduce new concepts. The fsck command serves as a good test case for the new API since it exercises both loose and packed object iteration paths.
