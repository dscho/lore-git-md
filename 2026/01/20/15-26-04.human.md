This is part 8 of Patrick Steinhardt's 14-part ODB abstraction series, which is in its final review stages with Junio Hamano preparing to merge. The series introduces backend-agnostic object storage APIs as part of a larger effort to make Git's object database pluggable.

This patch refactors `builtin/fsck.c` to use the new `odb_for_each_object()` interface instead of the separate `for_each_loose_object()` and `for_each_packed_object()` functions. The changes are mechanical but significant, eliminating 45 lines of redundant code by unifying the object iteration paths. The patch updates two key fsck operations - marking unreachable referents and connectivity checking - to use the new unified interface.

The implementation is clean and straightforward, converting the callback functions to match `odb_for_each_object()`'s signature while preserving all existing functionality. This is a typical example of the series' goal: replacing specialized iteration functions with a single, backend-agnostic API. The changes have been thoroughly reviewed in previous iterations, and this patch represents the final application of those abstractions to the fsck command.
