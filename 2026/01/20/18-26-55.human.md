This is a clarification about mailmap behavior in Git, specifically regarding how it handles email addresses in commit trailers. Junio C Hamano responds to Kristoffer Haugsbakk's confirmation that Git remaps addresses in trailers, providing a counter-example showing that mailmap does not actually affect trailer addresses in the output of `git show`.

Junio demonstrates this by adding a test mailmap entry and showing that while the commit author/committer lines are remapped, the Signed-off-by trailer addresses remain unchanged. He notes this is expected behavior since trailers don't always contain email addresses and some projects deliberately omit them for privacy reasons. The email serves to correct the earlier assumption about trailer remapping while acknowledging the past discussions about potentially implementing this feature.

The exchange provides useful technical clarification about Git's current mailmap implementation, though it doesn't directly impact Phillip Wood's original mailmap patch since that was about consolidating his own contributor identity regardless of trailer behavior.
