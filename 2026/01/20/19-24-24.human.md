This is a contributor housekeeping patch that clarifies mailmap behavior. Jeff King (Peff) follows up on Junio Hamano's test case showing that .mailmap entries don't affect Signed-off-by trailers in commit metadata, only author/committer fields. He notes that git-shortlog does apply mailmap to trailers when grouping commits, which may have caused Kristoffer Haugsbakk's initial confusion.

Peff references his own 2021 proof-of-concept patch that would expand mailmap to trailers, though it never progressed beyond experimental status. The discussion serves as useful documentation of mailmap's current scope - while Phillip Wood's original .mailmap additions remain valid for standardizing author attribution, the thread makes clear that trailer rewriting would require additional changes to Git's core behavior.

The exchange provides valuable technical clarification without requiring any changes to the proposed patch. It also surfaces an existing experimental approach (Peff's 2021 work) that could serve as a starting point if the project ever decides to expand mailmap functionality to cover trailers.
