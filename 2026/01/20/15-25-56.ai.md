This is a cover letter for a 14-part patch series introducing `odb_for_each_object()`, part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort. The series aims to make object iteration backend-agnostic by introducing new iteration interfaces while converting existing callers.

The series builds on two previous patch sets (ps/read-object-info-improvements and ps/packfile-store-in-odb-source) and has undergone thorough review from Justin Tobler and Karthik Nayak. Junio Hamano has indicated readiness to merge pending final procedural fixes. The v2 iteration addresses a minor nit about callback function documentation in patch 7/14.

Key technical changes include:
- New iteration interfaces: `odb_for_each_object()` (generic) and `odb_source_loose_for_each_object()` (loose objects)
- Optimized path handling via `read_object_info_from_path()`
- Conversion of core commands (fsck, pack-objects) and subsystems (reachable, promisor objects)
- Removal of now-unused `for_each_{loose,packed}_object()` functions

The series touches multiple core areas (object-file.c, packfile.c, reachable.c) and affects commands like `git fsck` and `git pack-objects`. Performance-sensitive path handling has been carefully validated, and the design allows for future backend-specific iteration while providing a transitional wrapper.

This represents a significant step in the ODB abstraction work, with all critical technical aspects vetted through review. The remaining changes are documentation clarifications before final integration.
