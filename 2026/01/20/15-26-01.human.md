This is part 5/14 of Patrick Steinhardt's ODB abstraction series, which is in its final integration phase. The patch refactors packed object iteration to prepare for a new backend-agnostic interface.

The change extracts the core logic from `for_each_packed_object()` into a new helper function `packfile_store_for_each_object_internal()`. This is groundwork for an upcoming commit that will introduce a new packed object iteration function using `struct object_info` to be backend-agnostic, similar to the loose object iteration interface added earlier in the series.

The refactoring:
- Moves the packfile iteration logic into a standalone function
- Maintains all existing flag handling (LOCAL_ONLY, PROMISOR_ONLY, etc.)
- Preserves error reporting through the pack_errors parameter
- Keeps the same performance characteristics

This is a mechanical refactor with no behavior change, typical of the careful, incremental approach seen throughout this series. The patch has already been reviewed by Karthik Nayak and Justin Tobler, with Junio Hamano indicating readiness to merge the series pending minor documentation fixes.
