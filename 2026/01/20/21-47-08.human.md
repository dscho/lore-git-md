Documentation patch for the experimental `git-last-modified` command, part of a v3 series that refines depth control behavior. This first patch updates the documentation to accurately describe the command's arguments as pathspecs rather than simple paths, bringing terminology in line with Git conventions. The changes include:

1. Replacing `<path>... with `<pathspec>...` in both the SYNOPSIS and OPTIONS sections
2. Adding a reference to gitglossary(7) for pathspec syntax details
3. Updating the description to clarify behavior when no pathspec is given
4. Adjusting the usage string in the C code to match

This is a straightforward documentation improvement that follows through on earlier feedback about terminology accuracy. The patch maintains consistency with how other Git commands document their path arguments. As part of a larger series that's been through multiple iterations, this change helps set up clearer expectations for users of this experimental command.
