This is a documentation patch that follows up on D. Ben Knoble's earlier change to remove unused formatting options from `git-replay`'s manual page. The maintainer, Junio C Hamano, acknowledges the correctness of the implementation but notes that the AsciiDoc syntax for checking multiple attributes (`ifndef::git-shortlog,git-replay[]`) is being used for the first time in Git's documentation and could benefit from being mentioned in the commit message for clarity.

The change itself is straightforward - it adds a `git-replay` attribute to conditionally exclude the "Commit Formatting" section when included by `git-replay.adoc`, matching the existing pattern used by `git-shortlog`. While the technical implementation is sound, Junio points out that the multiple attribute syntax might be confusing to readers unfamiliar with AsciiDoc's behavior (the attributes are OR'd together in this context). This appears to be a minor documentation cleanup that follows established patterns, with the only notable aspect being this first use of a particular AsciiDoc feature.
