This is part 7 of Patrick Steinhardt's 14-part ODB abstraction series, which is in its final integration phase. The patch introduces `odb_for_each_object()`, a new function that provides a unified interface for iterating through all objects in an object database, whether they're loose or packed.

The function serves as a wrapper that coordinates iteration across different object storage backends, handling flags like `ODB_FOR_EACH_OBJECT_LOCAL_ONLY` and `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`. It builds on earlier patches in the series that established the infrastructure for backend-agnostic object storage.

The implementation is clean and straightforward, delegating the actual iteration work to the appropriate backend-specific functions that were introduced in previous patches. The commit message notes this is transitional work - subsequent patches will migrate callers to use this new interface.
