Documentation patch completing a feature series for `git submodule foreach` traversal options. This final patch adds man page documentation for the new flags introduced in the previous patches:

- `--reverse-traversal` for post-order processing (children before parents)
- `--append-superproject` to include the top-level repository
- `--reversive` as a combined shorthand for both behaviors plus recursion

The documentation clearly states that these flags only take effect when used with `--recursive` and explains the use cases (particularly cleanup operations where dependency order matters). The patch maintains the existing documentation style while adding the new sections in a logical location among the other `foreach` options.

This completes the series that added these traversal modes to help with dependency-sensitive workflows in complex submodule hierarchies. The implementation was already reviewed in earlier patches, so this documentation addition should be straightforward to merge. The author has followed the project's convention of separating implementation from documentation, with the docs patch coming last in the series.
