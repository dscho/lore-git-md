This is the first patch in a 3-part series refactoring `wt-status.c` as part of the ongoing `the_repository` removal effort. The patch mechanically replaces direct uses of the global `the_repository` variable with repository instances already available in local structs (`struct wt_status` and `struct worktree`).

The changes are straightforward substitutions where `the_repository` is replaced with `s->repo` or `wt->repo` throughout the working tree status machinery. The patch also updates hash algorithm references from `the_hash_algo` to use the repository-specific `repo->hash_algo`. These are purely mechanical changes with no behavior modifications.

The patch follows the project's standard approach for `the_repository` removal work - eliminating global state in favor of explicitly passed repository contexts. The changes are well-scoped to `wt-status.c` and appear to be correctly implemented, though reviewers may want to verify some of the more subtle cases like rebase/cherry-pick status reporting.

This is a typical incremental step in the larger architectural effort to remove `the_repository` from the codebase, following patterns established by previous contributors like René Scharfe. The patch series looks like a solid, if unspectacular, contribution to that ongoing work.
