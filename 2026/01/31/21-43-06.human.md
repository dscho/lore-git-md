Feature patch adding reverse traversal to `git submodule foreach`, part of a series enabling dependency-aware submodule operations.

This second patch in a 5-part series implements the core `--reverse-traversal` flag for `git submodule foreach`. When used with `--recursive`, it performs a post-order traversal (children before parents), which is useful for operations that need to process dependencies in reverse order like cleanup or builds. The implementation adds a `reverse_traversal` flag to the submodule helper's internal state and modifies the traversal logic in `builtin/submodule--helper.c` to handle both forward and reverse cases. The patch also enables previously failing tests that verify the flag's parsing and execution.

The changes are well-contained, touching only the submodule helper code and test file. The commit message clearly explains the use case and implementation approach. This appears to be a straightforward addition that could be useful for complex submodule workflows, though real-world testing may reveal edge cases in deeply nested repositories.
