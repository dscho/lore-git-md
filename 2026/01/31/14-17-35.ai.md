This is a translation (l10n) update for Git 2.53.0, collecting updates to several language translations from the Git localization team. Jiang Xin is coordinating the pull request, which includes updates to Bulgarian, French, Irish, Indonesian, Swedish, Turkish, and both Simplified and Traditional Chinese translations.

The changes are primarily standard translation updates, with some fixes for consistency (like standardizing glossary terms in zh_CN) and addressing git-po-helper warnings. The volume of changes is substantial - over 7,000 lines modified across 8 .po files, though much of this is the nature of translation files where minor wording changes can touch many lines.

The pull request follows the standard l10n workflow where individual translators submit updates to the git-po repository, which are then merged by the l10n coordinator (Jiang Xin for zh_CN) before being pulled into the main Git repository. This appears to be a routine localization update with no particular controversies or special notes - just the regular flow of keeping translations current for the upcoming release.
