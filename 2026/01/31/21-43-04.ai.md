This is a feature patch series that enhances `git submodule foreach` with new traversal options for dependency-ordered operations. The series introduces three new flags that enable processing submodules in reverse order (children before parents) and optionally including the superproject in the operation.

The core additions are:
- `--reverse-traversal` for post-order (dependency-aware) processing
- `--append-superproject` to include the superproject in the operation
- `--reversive` as a shorthand combining both behaviors

The implementation touches both the `builtin/submodule--helper.c` plumbing and the `git-submodule.sh` script, with comprehensive test coverage in a new test file `t/t7425-submodule-reversion.sh`.
