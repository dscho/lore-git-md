Documentation patch completing a feature series for `git submodule foreach`. This is the fifth and final patch in a series that adds new traversal options to `git submodule foreach`, introducing documentation for the flags added in previous patches.

The patch adds man page entries for three new flags:
- `--reverse-traversal`: processes submodules in post-order (deepest first)
- `--append-superproject`: includes the superproject after processing submodules
- `--reversive`: a shorthand combining both behaviors plus recursion

The documentation clearly states that these flags only take effect when used with `--recursive` and explains the use cases (particularly cleanup operations where nested submodules must be processed before their parents). The patch maintains backward compatibility while adding these new options.
