Thread identity: Bugfix for pathspec handling regarding excluded pathspecs (`:!x`) interacting with `.gitignore` rules, authored by Remy D. Farley.

Core problem: Git incorrectly applies `.gitignore` checks to explicitly excluded pathspecs (prefixed with `:!`), causing operations like `git add :!x .` to fail when file `x` exists and is ignored. This violates the expected behavior where excluded pathspecs should bypass ignore rules.

Key technical details: The fix modifies `dir.c` to skip pathspec matching when `PATHSPEC_EXCLUDE` flag is set. The change is minimal (one-line modification) but precisely targeted to preserve existing behavior for non-excluded pathspecs while fixing the exclusion edge case. Includes reproduction script demonstrating the issue affects both `git add` and `git stash` operations.
