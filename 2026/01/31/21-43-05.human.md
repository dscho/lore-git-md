This is the first patch in a series adding new traversal options to `git submodule foreach`. It introduces comprehensive test coverage for the upcoming `--reversive` flag and its component options (`--reverse-traversal` and `--append-superproject`).

The test suite creates a complex submodule hierarchy with varying depths and sibling relationships to validate the new behaviors. Tests are currently marked as `test_expect_failure` since the features aren't implemented yet - they'll be flipped to success as each feature is added in subsequent patches.

Key behaviors being tested:
- `--reverse-traversal` for post-order (dependency-aware) processing
- `--append-superproject` to include the superproject in operations
- The combined `--reversive` shorthand that enables both behaviors

The test structure is thorough, covering flag combinations, edge cases, and variable handling. The setup creates a realistic multi-branch submodule tree that should provide good coverage for the new traversal modes. This looks like a solid foundation for the implementation work to follow in the series.
