This thread covers a v3 patch series (3 parts) from René Scharfe that removes the `the_repository` global from `wt-status.c`, continuing his long-running effort to eliminate this variable across the codebase. The series systematically replaces `the_repository` with local repository instances where available, focusing on status reporting functionality. 

The first two patches established that all `struct wt_status *s` functions can safely use `s->repo` instead of `the_repository`, since `s->repo` is guaranteed by `wt_status_prepare()`. These made 24 mechanical replacements affecting ref handling, path operations, and object ID handling. The final patch, just submitted, completes the series by replacing the global `the_hash_algo` with repository-specific hash algorithms in three locations - for cherry-pick/revert state tracking and checking for uncommitted changes.

All changes are behavior-preserving refactors following established patterns for `the_repository` removal. The series appears complete at v3 iteration with no outstanding objections or requested changes noted in the discussion. This work aligns with the broader project direction of removing global state dependencies from Git's codebase.
