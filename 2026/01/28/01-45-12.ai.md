This is a bug report and workaround for a systemd service interaction issue when Git is built with address sanitizer (ASAN). Jacob Keller reports that Git maintenance services get stuck in an infinite loop calling `sched_yield()` when built with ASAN, due to the leak sanitizer's behavior under systemd. The backtrace shows the process stuck in ASAN's leak detection code during shutdown.

The issue appears specific to systemd's process isolation environment, though the exact root cause isn't fully understood. The provided workaround disables leak detection via `ASAN_OPTIONS=detect_leaks=0` in a systemd service override file, which allows the maintenance services to complete successfully.

This affects users who build Git with sanitizers enabled (likely developers) and run maintenance services under systemd. The report serves primarily as documentation of the issue and solution rather than proposing a code change. The problem appears to be an interaction between systemd's process management and ASAN's shutdown behavior rather than a bug in Git itself.
