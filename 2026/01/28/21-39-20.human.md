This is part 5/12 of a hook subsystem refactoring series, converting the 'post-rewrite' hook in sequencer.c to use the new hook API. The patch replaces custom run-command calls with the simpler `hook_run_opt()` interface, which handles SIGPIPE toggling automatically and avoids manual child process setup.

The key changes are:
1. Introduces a `pipe_from_strbuf` helper to feed hook stdin from a strbuf via the new callback mechanism
2. Replaces the manual child process setup with a cleaner `run_hooks_opt` call
3. Maintains the same functionality while reducing boilerplate

This continues the series' pattern of converting individual hooks to the new API while demonstrating the callback-based stdin handling introduced in patch 4/12. The conversion looks straightforward and well-contained, with clear benefits in code simplicity. The patch has already collected sign-offs from key contributors (Emily Shaffer, Ævar Arnfjörð Bjarmason) and appears ready for merging as part of the larger series.
