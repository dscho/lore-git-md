This is a documentation patch clarifying the behavior of `git worktree prune` and their `--expire` option. The v3 patch from Sam Bostock:

1. Standardizes terminology to consistently use "prune" for missing worktrees rather than mixing "expire" and "prune"
2. Explicitly states that `--expire` only affects worktrees where the working directory path no longer exists
3. Expands the description of the `prune` subcommand itself to better explain when and why to use it, including guidance about moved worktrees

The changes are mechanical and uncontroversial, having been reviewed by both Eric Sunshine and Junio Hamano. The patch has evolved through three versions with feedback incorporated, and now appears ready for merging. It builds on earlier documentation clarity work from Julia Evans while focusing specifically on the worktree commands.
