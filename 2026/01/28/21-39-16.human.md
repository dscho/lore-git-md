This is a test patch in the hook subsystem refactoring series, which standardizes Git's hook execution with parallel support. The patch adds comprehensive test coverage for hook output streams, ensuring stdout and stderr behave as expected across various hook types.

The tests verify two key behaviors: some hooks keep stdout and stderr separate (like pre-push), while most others redirect stdout to stderr for historical compatibility. The patch introduces helper functions to check these conditions and exercises all major hook types - commit, checkout, merge, rebase, and server-side hooks. The test cases are well-organized and cover both client and server scenarios.
