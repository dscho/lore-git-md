Git for Windows 2.53.0-rc2 release announcement by Johannes Schindelin. This is a downstream distribution for Windows platforms, separate versioning from main Git. Updates bundled components: cURL 8.18.0, OpenSSL 3.5.5, MSYS2 runtime (Cygwin 3.6.6). User-visible changes: improved Tab key behavior in Git Bash, Microsoft Edit editor support, installer text display corrections. Includes Git Credential Manager 2.7.0 with x64/ARM64 support. Provides SHA-256 checksums for installers, portable versions, and MinGit variants across 64-bit, ARM64, and 32-bit architectures. This is a routine maintenance release with Windows-specific toolchain updates, not affecting core Git functionality.
