This is patch 8/12 in Adrian Ratiu's v8 series refactoring Git's hook subsystem. It converts the reference-transaction hook to use the new hook API introduced earlier in the series, eliminating direct use of `run-command` and manual signal handling.

The patch replaces the custom child process setup with the standardized hook API, moving the ref update processing into a callback function `transaction_hook_feed_stdin()`. This follows the pattern established in previous patches where each hook migration maintains its specific behavior while benefiting from the common infrastructure. The reference-transaction hook continues processing one ref update per callback invocation, though the commit message notes this could be batched for better pipe throughput if needed.

Key technical changes include:
- Removal of `run-command.h` and `sigchain.h` includes as they're no longer needed
- Introduction of `transaction_feed_cb_data` struct to track state across callbacks
- Conversion of the ref update formatting logic into the feed callback
- Use of `run_hooks_opt` with configured stdin feeding instead of manual process management

The patch has multiple sign-offs from series contributors including Emily Shaffer and Ævar Arnfjörð Bjarmason, indicating review consensus. It builds on the parallel execution and streaming infrastructure from earlier patches while demonstrating another real-world hook integration, further validating the API design. The changes are focused in `refs.c` with a net reduction of 50 lines through elimination of manual process management code.
