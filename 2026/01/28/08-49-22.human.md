Bugfix for bisect ref handling, part of a series addressing `refs_for_each_ref_in()` misuse. This third patch in Patrick Steinhardt's series fixes how bisect operations handle refs by correcting the use of `refs_for_each_ref_in()` in `bisect.c`. The original code could trigger a BUG() when processing exact ref matches due to improper string handling. The fix replaces it with `refs_for_each_fullref_in()` which avoids the problematic string trimming behavior while maintaining the same matching semantics. The change is small but important, demonstrating Steinhardt's characteristic thoroughness in addressing edge cases across related subsystems (here connecting bisect functionality with the earlier bitmap fixes in the series). The patch includes comprehensive test coverage, though the tests for this specific change are in the earlier patches of the series. This appears ready for merging as a clear bugfix with no outstanding concerns.
