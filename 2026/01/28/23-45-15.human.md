This is a patch series introducing infrastructure for pluggable object database (ODB) backends to handle transactions differently. It's part of the ongoing ODB abstraction effort led by Patrick Steinhardt, with Justin Tobler as a key contributor.

The series prepares the ground for future ODB implementations by:
1. Moving transaction handling logic out of the loose objects backend
2. Creating a generic `odb_transaction` structure that can store backend-specific commit callbacks
3. Centralizing common transaction behavior in shared functions

Currently only the loose objects backend is implemented, but the changes make it clear this is groundwork for supporting additional backends. The patch set appears well-structured with clean commit separation and reasonable test coverage (though no new tests are added in this series).

This is technical plumbing work that won't directly impact end users, but is important infrastructure for the pluggable ODB effort. The changes are focused and incremental, touching mainly the odb/ and object-file.c code. Reviewers familiar with the ODB abstraction work will want to look closely at how the transaction handling is being reorganized.
