This is patch 7/12 in a series refactoring Git's hook subsystem, specifically converting the pre-push hook to use the new hook API. The patch comes from Adrian Ratiu with sign-offs from Emily Shaffer and Ævar Arnfjörð Bjarmason, building on their earlier work in the series.

The key change replaces a custom `child_process` implementation with the standardized hook API, while preserving the pre-push hook's unique requirement for separate stdout/stderr streams (enabled by the `stdout_to_stderr=0` flag added in patch 6/12). The implementation now uses a callback-based approach (`pre_push_hook_feed_stdin`) to stream ref updates to the hook's stdin, filtering out non-pushed refs as before.

The patch maintains all existing behavior while eliminating manual signal handling and process management. It demonstrates the hook API's flexibility by cleanly handling the pre-push hook's specific I/O requirements. The conversion follows the pattern established in earlier patches, with Emily Shaffer's original authorship preserved through sign-off.

This continues the series' progression toward a unified hook infrastructure, with the pre-push hook being the second real-world integration after the post-rewrite hook in patch 5/12. The changes are focused and mechanical, with no user-visible behavior changes beyond internal implementation details.
