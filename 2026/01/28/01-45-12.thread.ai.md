Thread identity: Bug report about Git maintenance services getting stuck in infinite `sched_yield()` when built with address sanitizer (ASAN) under systemd, reported by Jacob Keller.

Core problem: Git maintenance services (likely `git maintenance run`) enter an infinite loop during shutdown when built with ASAN and run under systemd, due to interaction between systemd's process isolation and ASAN's leak detection behavior during process termination.

Current status: No code changes proposed; issue documented with a workaround. The problem is understood to be an ASAN/systemd interaction rather than a Git bug.

Key technical details: The infinite loop occurs in ASAN's leak detection code during shutdown. The workaround involves setting `ASAN_OPTIONS=detect_leaks=0` in a systemd service override file to disable leak detection for the maintenance services.

Open questions: The exact root cause of the ASAN/systemd interaction is not fully understood. No changes to Git's code are proposed since this appears to be an environmental interaction issue.
