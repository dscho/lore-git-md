Refactoring patch in a series addressing bitmap and bisect functionality issues. This first patch consolidates duplicate logic for iterating over preferred bitmap tips (configured via "pack.preferBitmapTips") into a new `for_each_preferred_bitmap_tip()` function. The change removes the last external caller of `bitmap_preferred_tips()`, allowing it to be made file-local to pack-bitmap.c. 

The patch is part of a series by Patrick Steinhardt that fixes a bug where exact ref matches in "pack.preferBitmapTips" could trigger a BUG() due to prefix stripping. While this initial patch doesn't yet fix the bug, it prepares the ground by cleaning up the code structure first - a typical Steinhardt approach of combining refactoring with bugfixes. The changes affect pack-bitmap.c, pack-objects.c, and repack-midx.c, standardizing how Git handles preferred bitmap tips across different commands.
