This is a bugfix series addressing incorrect usage of the `refs_for_each_ref_in()` function in the bitmap and bisect code. The issue was discovered when setting "pack.preferBitmapTips" to an exact branch name would trigger a BUG() due to improper refname handling.

Patrick Steinhardt's series fixes two cases where the function was misused by expecting it to handle exact ref matches when it's actually designed for prefix matching. The first patch consolidates duplicate bitmap tip iteration logic, while the second fixes the core bug in the pack-bitmap code. The third patch addresses a similar misuse in the bisect code.

The series includes new tests that verify the fixes work as intended, covering both the bitmap and bisect scenarios. The changes are focused and well-explained, with each commit clearly stating what problem it solves. Given Patrick's track record with ref-related code and the thorough test coverage, this appears to be a solid fix for a real edge-case bug.
