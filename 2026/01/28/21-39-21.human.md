Hook subsystem refactoring (part 6/12): This patch adds support for separate stdout and stderr streams in the hook API, addressing a regression in the pre-push hook where some users expect distinct output streams. The change makes the stdout-to-stderr redirection configurable via a new `stdout_to_stderr` flag in `struct run_hooks_opt`, defaulting to true for backward compatibility.
