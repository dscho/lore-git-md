This is a test modernization patch that finalizes the solution for fixing Git exit code suppression in t5500-fetch-pack.sh, part of Shreyansh Paliwal's GSoC project. The patch implements the approach that Junio Hamano approved in earlier discussion, using `test-tool pkt-line pack` to properly format protocol packets while avoiding the problematic exit code masking that occurred in the original test implementation.

The key changes store object IDs in shell variables for immediate failure detection and separate the packet generation from upload-pack invocation. This provides a cleaner structure while maintaining the test's ability to verify shallow fetch behavior with commit graphs. The solution serves as a specific fix for this test case and also establishes a pattern that could be applied to similar protocol-interaction tests.

Junio has already approved the technical approach, and this appears to be the final iteration of the patch after incorporating feedback from both Junio and Patrick Steinhardt. The patch looks ready for merging as part of the ongoing test modernization effort, demonstrating successful collaboration between a GSoC participant and core Git contributors.
