This is part 10 of Patrick Steinhardt's 14-part series refactoring Git's object database (ODB) to support pluggable backends. The patch converts remaining uses of `for_each_loose_object()` and `for_each_packed_object()` to the new `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()` interfaces in preparation for removing the legacy functions.

The changes affect `builtin/cat-file.c` and `commit-graph.c`, replacing direct iteration calls with the new backend-aware variants. Justin Tobler notes in his review that the iteration still happens in a backend-specific manner rather than being fully transparent, speculating this may relate to bitmap handling constraints. The patch demonstrates the transitional state as the series moves toward unified object iteration while maintaining compatibility with existing features like bitmap lookups.

This continues the systematic replacement of direct storage access with the pluggable backend interface, building on previous patches that introduced the new iteration mechanisms. The changes are mechanical but necessary steps toward the series' goal of abstracting object storage behind a clean interface.
