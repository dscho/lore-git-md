This is part 8 of Patrick Steinhardt's 14-part series refactoring Git's object database (ODB) interfaces to support pluggable backends. The patch converts `builtin/fsck.c` to use the new unified `odb_for_each_object()` interface introduced in patch 7/14, replacing separate calls to `for_each_loose_object()` and `for_each_packed_object()`.

The changes are mechanical but thorough - two main fsck operations (marking unreachable referents and connectivity checking) are updated to use the new callback-based iteration pattern. The patch eliminates 45 lines of redundant code by consolidating the loose and packed object handling paths into single implementations. Each callback now takes the standard `struct object_info` parameter and returns an int, matching the new ODB iteration API.

This is a straightforward application of the infrastructure built in earlier patches, demonstrating how the unified interface simplifies callers. The changes maintain all existing fsck behavior while removing backend-specific iteration code. As with previous patches in the series, this moves Git codebase toward the goal of configurable object storage backends by eliminating direct dependencies on loose/packed object implementation details.
