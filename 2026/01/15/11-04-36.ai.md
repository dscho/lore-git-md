This is part 7/14 of Patrick Steinhardt's ongoing object database (ODB) abstraction series, introducing a unified interface for iterating over all objects in the ODB. The patch adds `odb_for_each_object()`, which combines the loose and packed object iteration functions standardized in previous patches (4/14 and 6/14).

The new function serves as a single entry point that:
- Handles both loose and packed objects through a common callback interface
- Respects flags for local-only and promisor-only iteration
- Maintains the error propagation behavior established in the series
- Includes thorough documentation of the API contract in odb.h

The implementation walks through all ODB sources (including alternates), first checking loose objects (unless skipping promisor objects) then packed objects, stopping on any callback error. This matches the pattern seen in existing Git code but with the new standardized interfaces.

As with previous patches in the series, this is a building block toward the larger goal of making the object storage backend pluggable. The commit message notes that subsequent patches will convert callers to use this new unified interface, which will likely include fsck, pack-objects, and commit-graph operations mentioned in the thread context.

The patch appears carefully constructed to maintain existing behavior while providing a cleaner abstraction - a characteristic of Steinhardt's ODB work. The documentation is thorough and the implementation follows the established pattern from earlier in the series.
