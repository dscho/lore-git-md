Documentation fix correcting the replacement syntax for `--get-urlmatch` in `git-config`.

Pushkar Singh points out that the current documentation incorrectly states that `--get-urlmatch` can be replaced by combining `--all`, `--show-names`, and `--url` flags. In practice, `--url` cannot be used with `--all`, making the documented replacement command fail. The patch updates the documentation to show the correct replacement syntax using just `--url`.

This is a straightforward correction to the man page that aligns the documentation with actual behavior. The change is minimal (a one-line fix) and clearly motivated by testing the documented command. While small, it prevents confusion for users trying to transition from the deprecated `--get-urlmatch` flag to the newer syntax.
