This is patch 12/14 in Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer. The patch refactors how `pack-objects` handles object enumeration when creating cruft packs, switching from the older `for_each_packed_object()` to the new `packfile_store_for_each_object()` interface introduced earlier in the series.

The key change replaces direct mtime lookup from packfiles with a more abstracted approach that requests mtimes through the new ODB interface's `object_info` structure. This continues the series' pattern of moving away from direct packfile manipulation toward the new backend-agnostic APIs. The patch maintains the same functionality while better aligning with the series' architectural goals.

The change affects cruft pack creation specifically, where modification times are used to determine object expiration. The implementation handles both regular packs and cruft packs (which store mtimes separately in a `.mtimes` file) through the unified interface. This is another incremental step toward making the object storage layer pluggable while preserving existing behavior.
