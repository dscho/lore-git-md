This is part 8 of Patrick Steinhardt's 14-part series on object database (ODB) abstraction, specifically converting `git fsck` to use the new unified object iteration interface. The patch refactors fsck's connectivity checking to replace separate `for_each_loose_object()` and `for_each_packed_object()` calls with the new `odb_for_each_object()` interface.

Justin Tobler's review confirms the technical correctness of the change, noting how it eliminates redundant callback functions by unifying the loose and packed object iteration paths. The patch removes 45 lines of code while maintaining the same functionality, demonstrating the simplification enabled by the ODB abstraction layer. This is a mechanical conversion that follows the pattern established in earlier patches of the series, with no outstanding technical concerns raised in the review.

The changes touch `builtin/fsck.c`, modifying the object iteration logic for checking unreachable objects. The patch preserves all existing behavior while removing the need for separate handling of loose versus packed objects, a key goal of the broader ODB abstraction effort. With Justin's positive review, this appears ready for integration along with the rest of the series.
