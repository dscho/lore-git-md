This is patch 6/14 in Patrick Steinhardt's ongoing object database (ODB) abstraction series, introducing a new function for iterating through packed objects with a standardized interface. The patch adds `packfile_store_for_each_object()` to match the loose object iteration API introduced in patch 4/14, both building toward a unified object iteration mechanism.

The new function wraps existing packed object iteration but presents the same callback signature as loose object iteration, taking a `struct object_info` parameter and using the `odb_for_each_object_cb` type. This creates symmetry between the two storage types while maintaining all existing flag behaviors (LOCAL_ONLY, PROMISOR_ONLY). The implementation handles object metadata population and error reporting consistently with the loose object counterpart.

Key technical details:
- Introduces a wrapper struct to bridge between old and new callback signatures
- Preserves packed object error reporting through the `pack_errors` mechanism
- Maintains MRU pack tracking behavior from the original implementation
- Exports the new function in packfile.h with documentation matching the loose object variant
- Leaves `for_each_packed_object()` intact for now (to be removed later in the series)

This continues the series' pattern of methodical refactoring - each patch tackles a specific iteration path while maintaining existing behavior. The work is part of Patrick's broader effort to enable pluggable storage backends by abstracting object access patterns. The next logical steps would be to implement the unified `odb_for_each_object()` interface that can use both the loose and packed iteration functions introduced in these patches.
