This is the final patch (14/14) in Patrick Steinhardt's series abstracting Git's object database (ODB) to support pluggable backends. The patch removes the now-obsolete `for_each_loose_object()` and `for_each_packed_object()` functions after all callers have been converted to use the new ODB interface. It also inlines `packfile_store_for_each_object_internal()` since it only has one remaining caller.

The changes are mechanical cleanup following the series' architectural refactoring. The patch removes ~96 lines of code across object-file.c, packfile.c and their headers while maintaining the same functionality through the new ODB interfaces. This completes the transition from direct loose/packed object iteration to the unified `odb_for_each_object()` approach introduced earlier in the series.

Key technical details:
- Removes legacy iteration functions from object-file.c/h and packfile.c/h
- Inlines packfile iteration into its sole remaining use in packfile_store_for_each_object()
- Maintains all existing behavior through the new ODB interfaces
- Follows the series' pattern of incremental, behavior-preserving changes

This patch represents the completion of the ODB abstraction's core infrastructure work, having systematically replaced all direct object storage access with the new pluggable backend interface. The series as a whole demonstrates careful, mechanical progression toward making Git's object storage layer properly abstracted and extensible.
