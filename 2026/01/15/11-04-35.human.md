This is patch 6/14 in Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer, introducing a new function for iterating through packed objects. The patch adds `packfile_store_for_each_object()`, which provides a consistent callback interface matching the loose object iteration function introduced in patch 4/14.

The new function wraps existing packed object iteration logic while adding support for passing object metadata via `struct object_info`, aligning with the series' goal of creating a unified interface for all object iteration. It builds on the internal refactoring done in patch 5/14, maintaining all existing flag behaviors and error handling while preparing for the eventual removal of `for_each_packed_object()`.

The implementation carefully preserves performance-sensitive behaviors like MRU pack tracking and handles error cases consistently. This continues the methodical approach seen throughout the series, with each patch focusing on a specific iteration path while maintaining backward compatibility. The changes are confined to packfile.c/h, keeping the scope tight as the abstraction work progresses toward its goal of enabling pluggable storage backends.
