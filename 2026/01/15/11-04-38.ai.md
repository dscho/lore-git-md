This is patch 9/14 in Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer. The patch converts several callsites that enumerate promisor objects to use the new unified `odb_for_each_object()` interface rather than the older `for_each_packed_object()`.

The changes affect three key areas:
1. `packfile.c` - Updates the promisor object tracking to use the new callback signature and adds a wrapper struct to pass repository context
2. `repack-promisor.c` - Simplifies the promisor object repacking logic with the new interface
3. `revision.c` - Modifies revision walking to use the unified promisor object enumeration

The patch demonstrates the series' progress in replacing direct backend access with the abstracted ODB layer. Each conversion maintains the same functionality while reducing code duplication and standardizing on the new interface. The changes are mechanical but important for the series' goal of enabling pluggable object storage backends.

This continues the pattern of methodically converting subsystems while preserving behavior, with promisor object handling being a particularly sensitive area that benefits from the unified approach. The patch follows the series' careful, incremental style with clear commit messages explaining each change.
