This is the first patch in a refactoring series from Patrick Steinhardt that standardizes function names for working with commit lists. The patch renames `copy_commit_list()` to `commit_list_copy()` to match Git's established naming pattern where functions operating on a struct are prefixed with the struct name. The change is mechanical and affects several core commands (commit, merge, rebase) and infrastructure code.

The patch includes a compatibility wrapper for the old function name to avoid breaking in-flight work, with a note that it will be removed after Git 2.53. The changes are straightforward and touch about 40 files across the codebase, though this first patch only shows the immediate callers being updated. This is a typical code hygiene improvement from Patrick - well-scoped, clearly explained, and carefully implemented to maintain backward compatibility during the change.
