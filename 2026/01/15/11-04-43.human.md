This is the final patch in Patrick Steinhardt's 14-part series refactoring Git's object database (ODB) layer to support pluggable backends. The series has systematically replaced direct access to object storage with an abstracted ODB interface.

Patch 14/14 removes the now-unused `for_each_loose_object()` and `for_each_packed_object()` functions, completing the migration to the old iteration interfaces. All callers have been converted to use the new ODB abstraction layer in earlier patches. The change also inlines a helper function that became single-use after these removals, simplifying the callback flow.

The patch is a mechanical cleanup that follows through on the architectural changes made throughout the series. It touches four files, removing about 100 lines of now-redundant code while maintaining all existing functionality through the new interfaces. This is the capstone to a carefully executed refactoring that makes Git's object storage properly abstracted and ready for future extensibility.
