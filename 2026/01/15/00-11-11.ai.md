This is a follow-up cleanup patch in Taylor Blau's multi-pack-index compaction series, addressing Junio C Hamano's feedback about error handling. The patch removes the `u64_add()` and `u64_mult()` helper functions from git-compat-util.h that were previously used for overflow checking in MIDX writing code.

The change replaces these helpers with direct calls to `unsigned_add_overflows()` and `unsigned_mult_overflows()`, allowing callers to provide more descriptive error messages. The single remaining caller in midx-write.c is updated to include detailed context about the overflow condition ("overflow during fixed-point multiply" and the specific values involved.

This follows the same pattern as the earlier removal of `u32_add()` in the series, maintaining consistency in error reporting. The patch demonstrates careful attention to Junio's feedback about API design while preserving the safety checks needed for MIDX operations. The change is straightforward and well-contained, with clear commit message explaining the helpers' history and rationale for removal.
