This is a feature patch series extending Git's userdiff functionality to better support Lisp dialects. The v3 iteration combines two commits that were previously separate in v2, now properly structured as a series.

The main change extends the existing Scheme diff driver to also handle Common Lisp and Emacs Lisp by:
1. Adding patterns for common Lisp forms like `defun` and case-insensitive `(def` prefixes
2. Supporting conventional Lisp indentation (0, 1, or 2 spaces before top-level forms)
3. Maintaining backward compatibility with existing Scheme detection

The second commit tightens the word-diff test cases for the Scheme driver, particularly around vertical bar syntax handling that was problematic in earlier versions. This includes fixes for escaped characters and word boundary matching in the regex patterns.

Key technical details:
- The unified driver now uses disjunctive regex patterns to match both Scheme and Lisp dialects
- Handles case sensitivity through `IPATTERN` flag
- Tests verify no regression for Scheme while adding coverage for Lisp forms
- Documentation updated to reflect broader "lisp" driver support
- Total net change is +21 lines across userdiff.c and test files

The series appears ready for integration, having addressed all technical feedback from previous rounds. Scott L. The changes are focused and well-tested, representing a clear improvement to Git's diff highlighting for Lisp-family languages.
