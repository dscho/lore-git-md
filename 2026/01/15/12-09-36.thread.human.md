This thread addresses a bug in the `git subtree` contrib script where the `--prefix` argument validation during split operations was incorrectly checking the working tree instead of the target commit. The issue caused splits to fail when targeting historical commits where the subtree existed but had since been removed.

The patch series has progressed through three versions, with v3 now incorporating all requested changes. The fix modifies the validation to use `git ls-tree` against the specified commit for splits while keeping working tree checks for add/merge operations.
