This is patch 10/14 in Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer. The patch continues the mechanical conversion work, this time focusing on replacing direct calls to `for_each_loose_object()` and `for_each_packed_object()` with the new ODB-abstracted equivalents.

The changes affect two key areas: `builtin/cat-file.c` (used by `git cat-file --batch-all-objects`) and `commit-graph.c` (which builds commit graphs from packed objects). In both cases, the patch introduces new callback functions that work with the unified ODB interface while maintaining the same behavior. The commit-graph changes are performance-sensitive since they run during graph generation, but the patch carefully preserves the existing pack-order traversal.

This is a well-structured, incremental step in the larger ODB abstraction effort. The changes are mechanical but important for eliminating direct dependencies on the old iteration interfaces. The patch follows the series' pattern of introducing new infrastructure while maintaining backward compatibility, with clear commit messages explaining each transformation.
