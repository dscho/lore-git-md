This is a refactoring patch in Patrick Steinhardt's ongoing object database (ODB) abstraction series. It converts `git fsck` to use the new unified `odb_for_each_object()` interface instead of separate `for_each_loose_object()` and `for_each_packed_object()` calls.

Justin Tobler reviews the change positively, noting how it simplifies the code by eliminating redundant callbacks while maintaining the same functionality. The patch removes 45 lines of code while adding just 12, consolidating the object iteration logic into a single path. This is part of the broader effort to make Git's object storage layer pluggable by abstracting backend-specific details.

The change is mechanical but meaningful - it demonstrates how the new ODB interface reduces code duplication when dealing with different object storage types. Justin confirms the patch correctly handles the transition from the old iteration model to the new unified one.
