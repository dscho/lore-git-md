This is part 13/14 of Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer, enabling pluggable backends. The patch refactors the reachability checking code in `reachable.c` to use the new `odb_for_each_object()` interface rather than separate loose and packed object iteration.

The change simplifies the object traversal logic by consolidating what were previously two separate callbacks (`add_recent_loose` and `add_recent_packed`) into a single `add_recent_object` callback. The new version leverages the `object_info` structure introduced earlier in the series to handle mtime and type information uniformly across all object types.

Key technical aspects:
- Removes 90 lines of legacy object iteration code
- Uses the ODB interface's `mtimep` field (added in patch 11/14) for consistent mtime handling
- Maintains all existing functionality including cruft pack support
- Preserves the pack-order traversal optimization via the `ODB_FOR_EACH_OBJECT_PACK_ORDER` flag

This continues the series' pattern of behavior-preserving conversions that systematically replace direct object storage with the new abstraction layer. The patch appears well-structured and follows the established approach of the series, though as with previous patches in this effort, reviewers will likely scrutinize the performance characteristics of the new unified iteration path.
