This is part 4 of Patrick Steinhardt's 14-part series on object database iteration, continuing the ODB abstraction effort. The patch introduces a new unified interface for iterating through loose objects that will eventually replace the existing `for_each_loose_object()` function.

The new `odb_source_loose_for_each_object()` function provides a more consistent interface by:
- A `struct object_info` parameter that gets populated with object metadata
- A callback signature that matches the planned packed object iteration API
- Support for the same `ODB_FOR_EACH_OBJECT_*` flags used elsewhere

The implementation wraps the existing loose object iteration but adds the ability to populate object info during iteration, which wasn't previously possible without separate calls. This prepares the codebase for upcoming patches that will introduce a backend-agnostic iteration API using `struct object_iteration_context`.

Key technical details:
- Maintains all existing flag behavior (PROMISOR_ONLY, LOCAL_ONLY)
- Uses the `read_object_info_from_path()` helper from patch 3/14
- Defines a new callback type `odb_for_each_object_cb` in odb.h
- The old `for_each_loose_object()` remains temporarily for compatibility

This is a well-structured step in the larger ODB abstraction work, cleanly separating interface changes from implementation while maintaining backward compatibility. The changes touch core object-file handling but appear carefully constrained to the iteration path.
