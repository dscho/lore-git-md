This is part 11/14 of Patrick Steinhardt's ongoing object database (ODB) abstraction series, introducing mtime tracking for objects. The patch adds a new `mtimep` field to `struct object_info` to allow callers to request an object's modification time, which will be used in future pruning operations.

The changes touch several key areas:
- Adds mtime handling in `object-file.c` for loose objects via `st_mtime`
- Implements mtime retrieval for packed objects in `packfile.c`, including special handling for cruft packs (which store mtimes in a separate `.mtimes` file)
- Updates the ODB interface in `odb.h` and `odb.c` to support the new field

The implementation carefully maintains existing behavior while adding the new capability, with thorough error handling. This continues the series' pattern of incremental, behavior-preserving changes that build toward the larger goal of pluggable storage backends. The commit message clearly states this is preparatory work for future pruning functionality.
