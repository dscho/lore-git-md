Patrick Steinhardt's ODB abstraction series (now 17 parts) has reached functional completion with the final patch removing legacy iteration APIs after full transition to backend-agnostic object storage. The series establishes symmetric `odb_for_each_object()` interfaces for all storage types (loose, packed, cruft) while eliminating redundant code across five core commands (fsck, pack-objects, cat-file, commit-graph, reachable).

Key technical components:
1. Unified iteration interfaces:
   - `odb_for_each_object()` as primary API
   - `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()` for direct access
   - Flag handling preserved (`LOCAL_ONLY`, `PROMISOR_ONLY`, `SKIP_IN_CORE_KEPT_PACKS`)
2. Core command conversions demonstrating 45-96 line reductions per subsystem:
   - `fsck`: combined three callbacks into unified handlers
   - `pack-objects`: cruft generation using new API
   - `reachable.c`: replaced `add_recent_loose`/`add_recent_packed` with single callback
3. Infrastructure improvements:
   - Complete mtime tracking via `struct object_info`
   - Promisor object handling unified across subsystems
   - Optimized `read_object_info_from_path()`
4. Final cleanup:
   - Removed `for_each_loose_object()` and `for_each_packed_object()`
   - Inlined `packfile_store_for_each_object_internal()`
   - Eliminated 250+ lines across object-file.c, packfile.c, reachable.c
