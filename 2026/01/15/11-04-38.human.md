This is part 9/14 of Patrick Steinhardt's ongoing series to abstract Git's object database (ODB) layer. The patch converts several callsites that enumerate promisor objects to use the new unified `odb_for_each_object()` interface introduced earlier in the series.

The change affects three key areas:
1. `packfile.c` - Updates the promisor object tracking to use the new callback signature
2. `repack-promisor.c` - Simplifies promisor object repacking
3. `revision.c` - Modifies revision walking to properly exclude promisor objects

The patch demonstrates the series' progress in replacing direct backend access with the new ODB abstraction. It maintains all existing functionality while reducing code duplication - for example, the promisor object handling in `packfile.c` is now more clearly separated from the packed object iteration details.

This continues the methodical conversion of subsystems to the new ODB interfaces, with promisor handling being an important use case given its role in partial clone operations. The changes are focused and well-contained, following the pattern established in earlier patches of the series.
