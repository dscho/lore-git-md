Patrick Steinhardt has begun a significant series (14 patches) to introduce a new object database iteration API as part of his ongoing ODB abstraction work. The series aims to make object iteration backend-agnostic, building on recent improvements to object storage handling. 

The first patch performed a mechanical rename of iteration flags to use an ODB_ prefix across 11 files, while maintaining existing semantics. The second patch, just submitted, standardizes the type used for flags parameters from an enum to unsigned to match Git's conventions for bitfield parameters. These are preparatory changes that touch core object-file and packfile code, updating function signatures but not yet introducing new functionality.

The changes affect important subsystems like fsck, pack-objects, and commit-graph generation, though backward compatibility is maintained. The work appears technically sound so far, but given it touches fundamental object storage paths, it will need careful review from object storage experts like Jeff King and Taylor Blau. This is early in the discussion with no feedback yet on v1 of the series.
