Patrick Steinhardt's ODB abstraction series continues to make steady progress, now at version 3 with part 13/14 converting the reachability checking code. The series systematically refactors Git's object storage layer to support pluggable backends, with each patch building on the last.

The latest patch focuses on `reachable.c`, replacing separate loose and packed object iteration with the unified `odb_for_each_object()` API introduced earlier in the series. This change leverages the `object_info` struct from part 11 to handle mtimes consistently, eliminating 55 lines of redundant code while maintaining all existing functionality. The conversion follows the same pattern seen in previous parts - simplifying specialized cases like cruft pack handling by providing consistent metadata access through the new APIs.

With only one patch remaining, the series is nearing completion. It has already converted five major subsystems (`cat-file`, commit-graph, `fsck`, `pack-objects`, and now reachability checking) to the new object storage patterns. Review feedback from Justin Tobler and Karthik Nayak has been incorporated throughout, and the changes maintain backward compatibility while preparing for future pluggable storage backends. The consistent reduction in code duplication and global state usage demonstrates the value of the abstraction layer being introduced.
