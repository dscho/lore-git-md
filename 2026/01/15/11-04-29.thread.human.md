Patrick Steinhardt has completed his 14-part series refactoring Git's object database (ODB) layer to support pluggable backends. The series systematically replaced direct access to loose and packed objects with a unified interface, culminating in this final patch that removes the now-obsolete iteration functions. 

The work introduced core infrastructure for object iteration, promisor object handling, and mtime tracking while maintaining backward compatibility. Key changes included adding modification time support, refactoring cruft pack enumeration, and unifying reachability checking. The final patch cleans up the remaining legacy code, removing ~96 lines while preserving all functionality through the new ODB interfaces.

This architectural change prepares Git for future storage backends while demonstrating careful, incremental refactoring of performance-sensitive code. The series as a whole represents a significant step toward making Git's object storage layer properly abstracted and extensible, with all callers now using the new `odb_for_each_object()` interface instead of direct loose/packed object access.
