This is the second patch in a v3 series extending Git's userdiff support for Lisp dialects. The series unifies Scheme highlighting with Common Lisp and Emacs Lisp under a single "lisp" driver while maintaining backward compatibility.

The patch focuses on expanding the pattern matching to handle Common Lisp conventions like `defun` and `defmacro` forms, which weren't covered by the original Scheme patterns. It introduces several key improvements:

1. Adds support for Common Lisp's top-level forms by matching unindented parentheses and forms starting with "(def" (case-insensitive)
2. Handles indentation conventions where top-level forms may be nested with 1-2 spaces of indentation
3. Improves vertical bar syntax handling with proper regex for escaped characters
4. Adds new test cases demonstrating the extended functionality:
   - Common Lisp `defun` forms
   - Nested macrolet definitions
   - `eval-when` special forms
   - Module definitions with exports

The changes maintain all existing Scheme functionality while adding broader Lisp dialect support. The implementation carefully balances between false positives and negatives, leveraging Lisp community conventions around indentation and form prefixes. Test coverage is expanded to verify the new patterns work alongside the existing Scheme support.

This represents the final iteration of the series, having incorporated feedback from previous rounds about vertical bar handling and test coverage. The changes are minimal (22 LOC) but provide meaningful functionality for Lisp developers using Git's diff highlighting.
