This is a refactoring patch that's part of Patrick Steinhardt's larger object database (ODB) abstraction series. The patch renames `FOR_EACH_OBJECT_*` flags to use an `ODB_` prefix, aligning them with the upcoming `odb_for_each_object()` function. 

Justin Tobler provides a simple ack, noting the changes are straightforward renames with no functional impact. This is the first patch in a 14-part series that's already been reviewed and is in its final integration stage with Junio Hamano. The series as a whole represents a major architectural change to make Git's object storage layer properly abstracted and extensible, but this particular patch is purely mechanical preparation for that larger work.
