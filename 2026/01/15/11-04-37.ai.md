This is patch 8/14 in Patrick Steinhardt's series refactoring Git's object database iteration as part of the broader ODB abstraction effort. The patch converts `builtin/fsck.c` to use the new unified `odb_for_each_object()` interface introduced in earlier patches, replacing separate calls to `for_each_loose_object()` and `for_each_packed_object()`.

The changes are mechanical but thorough, eliminating duplicate callback wrappers and consolidating two object iteration paths into one. The patch:
- Updates `mark_unreachable_referents()` to match the new callback signature (adding `struct object_info` and `data` parameters)
- Removes the now-unnecessary `mark_loose_unreachable_referents()` and `mark_packed_unreachable_referents()` wrappers
- Similarly simplifies the connectivity checking path by removing redundant wrappers around `mark_object_for_connectivity()`
- Maintains all existing functionality while reducing code by 45 lines

This conversion demonstrates the series' progress in replacing direct backend access with the new ODB abstraction layer. The changes are straightforward and well-contained, focusing specifically on fsck's object iteration needs. As with previous patches in the series, the work is careful to preserve existing behavior while moving toward the more flexible interface.
