This is a test modernization patch that completes the work to fix Git exit code suppression in t5500-fetch-pack.sh, specifically for testing shallow fetch behavior with commit graphs. The patch represents the final iteration of a GSoC project where Shreyansh Paliwal has worked with Patrick Steinhardt and Junio Hamano to refine the approach.

The key technical improvement is replacing the previous temporary-file-based approach with direct shell variable storage of object IDs (`oid_algo`, `oid_other`, `oid_main`), which allows immediate failure detection. It also adopts Junio's recommended `test-tool pkt-line pack` for proper packet formatting, cleanly separating packet generation from upload-pack invocation.

This solution successfully eliminates the problematic here-doc and pipe-based masking of failures that was the original motivation for the work. The implementation now serves as a model for similar protocol-interaction tests, demonstrating proper test phases (data gathering -> formatting -> execution). Junio has explicitly approved the final approach, particularly endorsing the `test-tool pkt-line pack` usage.

The patch concludes a successful mentor/student collaboration that evolved through multiple iterations based on feedback from core contributors. It addresses all previously raised concerns about portability, temporary file usage, and exit code handling, with no outstanding issues remaining.
