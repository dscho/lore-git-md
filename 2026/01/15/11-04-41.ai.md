Continuing Patrick Steinhardt's ODB abstraction series, patch 12/14 refactors cruft pack object enumeration in `builtin/pack-objects.c` to use the new `packfile_store_for_each_object()` interface introduced earlier in the series. This replaces direct calls to `for_each_packed_object()` with the more abstracted iteration mechanism, while maintaining the same functionality for tracking object modification times.

The key change moves the mtime handling logic from the callback function into the object info request structure, leveraging the mtime tracking capability added in patch 11/14. The patch simplifies the cruft pack object addition by having the ODB infrastructure provide the packfile and offset details through the `object_info` struct rather than calculating them in the callback.

This is another incremental step in the systematic conversion of Git's object storage layer to use the new ODB abstraction interfaces. The change affects how `pack-objects` processes objects for cruft pack generation, but preserves all existing behavior while adopting the more flexible backend interface. The patch follows the series' pattern of mechanical conversions that prepare for pluggable storage backends without introducing functional changes.
