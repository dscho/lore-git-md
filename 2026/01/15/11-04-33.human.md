This is the fourth patch in Patrick Steinhardt's 14-part series introducing a new object database iteration API as part of the ODB abstraction effort. The patch adds `odb_source_loose_for_each_object()`, a new function that provides a more uniform way to iterate through loose objects while populating object metadata.

The key improvement is standardizing the iteration interface - the new function accepts the same callback signature that will later be used for packed objects, paving the way for a unified iteration API. It builds on the previous patch's consolidation of loose object reading into `read_object_info_from_path()`. The function includes flags for filtering (like promisor/local-only objects) and maintains the ability to get object metadata during iteration.

This is a technical but important step in the larger ODB abstraction work. The patch appears carefully implemented with clear documentation and maintains backward compatibility (the old `for_each_loose_object()` remains for now). The changes are focused on `object-file.c` and related headers, touching the core object storage layer.
