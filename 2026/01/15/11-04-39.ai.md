This is patch 10/14 in Patrick Steinhardt's ongoing object database (ODB) abstraction series, continuing the systematic conversion of object iteration interfaces. The patch refactors two key subsystems - `builtin/cat-file.c` and `commit-graph.c` - to use the new `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()` interfaces instead of the legacy `for_each_loose_object()` and `for_each_packed_object()` functions.

The changes are mechanical but important for the ODB abstraction effort. In `cat-file`, the patch unifies loose and packed object handling through a new `batch_one_object_oi()` callback that works with both object types via the new interfaces. For `commit-graph`, it introduces `add_packed_commits_oi()` to handle packed commits through the new API while maintaining the same functionality.

The patch follows the series' pattern of incremental conversion - each change maintains existing behavior while moving toward the goal of configurable backends. The commit message clearly states this is preparatory work for removing the old iteration functions entirely in a future patch. The changes touch performance-sensitive areas (object enumeration in `cat-file` and commit graph generation) but appear carefully implemented to avoid regressions.
