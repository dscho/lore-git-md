This is a cover letter for a 14-patch series introducing a new object database iteration API, part of Patrick Steinhardt's ongoing ODB abstraction effort. The series aims to make object traversal backend-agnostic by introducing `odb_for_each_object()` and converting existing callers to use it.

The series starts with flag cleanup (patches 1-2), then introduces the new iteration infrastructure (3-7), converts several subsystems to use it (8-13), and finally removes the now-obsolete functions (14). The changes touch core object-file handling, packfile management, and several builtins (fsck, pack-objects). 

The work builds on two recent series that improved object info reading and packfile storage in the ODB. Given Patrick's track record with the ODB abstraction work and the thoroughness of the series (converting multiple call sites while maintaining functionality), this looks like a well-structured step toward making Git's object storage truly pluggable. The changes are mechanical but wide-ranging, so careful review of the conversions will be needed to ensure no subtle behavior changes were introduced.
