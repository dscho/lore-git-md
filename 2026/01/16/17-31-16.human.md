CI / build system patch from Johannes Schindelin that optimizes the leak-checking CI jobs by skipping git-svn tests.

The patch notes that git-svn tests account for a disproportionate amount of CI runtime (42 minutes out of 5.25 hours total) while providing minimal value for leak detection, since git-svn is implemented in Perl and the leak checker only analyzes C code. The tests still exercise git-svn functionality in non-leak-checking CI jobs, so this change just removes redundant coverage.

The change adds a `NO_SVN_TESTS` environment variable to skip these tests specifically in the leak-checking jobs. The analysis appears thorough, showing the git-svn tests run about twice as long as average tests. This seems like a straightforward optimization to reduce CI resource usage without sacrificing meaningful coverage.
