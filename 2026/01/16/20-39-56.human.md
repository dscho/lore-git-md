This is a test fix targeting Cygwin platform compatibility. Ramsay Jones reports that test #29 in t0610-reftable-basics.sh ("ref transaction: corrupted tables cause failure") has become intermittently flaky when run with parallel jobs (-j8) on Windows 11, though it passes reliably when run serially. The failure occurs when trying to corrupt reftable files via shell redirection, resulting in a permission error.

After investigation, the help of Patrick Steinhardt, and comparing strace outputs, the solution replaces the shell redirection (`: >"$f"`) with a call to `test-tool truncate`. While the exact race condition isn't fully understood, this change reliably fixes the flakiness. The patch is minimal and focused, touching only the problematic test line. Given Ramsay's expertise in Cygwin issues and the straightforward nature of the fix, this appears to be a solid solution to a real platform-specific test instability.
