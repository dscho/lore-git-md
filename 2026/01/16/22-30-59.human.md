This is the fourth iteration of Samo Pogačnik's 2-patch series addressing shallow repository issues, now with a corrected typo ("allways" -> "always") in the commit message. The cover letter explains the core problem: when fetching with relative depth (`--deepen`) beyond merged branches, some shallow commits can become unreachable. The solution unifies absolute and relative depth calculations through a new `get_shallows_depth()` function that properly tracks minimum depths of existing shallow commits.

Key technical improvements in this version include:
- Final typo fix in documentation
- Further logic unification between `get_shallows_depth()` and `get_shallow_commits()`
- Continued focus on edge cases like deepening beyond merged branches

The patches remain well-contained in shallow.c and upload-pack.c, with comprehensive test coverage in t5500-fetch-pack.sh.
