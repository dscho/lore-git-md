Thread summary:

Johannes Schindelin (Dscho) initiated a CI optimization to skip git-svn tests during leak-checking jobs via NO_SVN_TESTS in ci/lib.sh, saving ~42 minutes of runtime from Perl-based tests irrelevant to C memory leak detection. Junio C Hamano approved this approach and extended it to CVS/Perforce tests (24-minute savings) by introducing NO_CVS_TESTS and NO_P4_TESTS variables with early-exit checks in t/lib-cvs.sh and t/lib-git-p4.sh, following the established pattern for linux-leaks and linux-reftable-leaks jobs. Phillip Wood confirms the technical approach of placing the skip logic in library files and raises a new consideration about whether these same tests should also be excluded from ASan (AddressSanitizer) jobs, suggesting potential future extension of this optimization pattern. Kristoffer Haugsbakk contributed a minor documentation polish regarding email address conventions in trailers, which Phillip clarified relates to his personal .mailmap configuration. The thread demonstrates consensus on practical CI optimizations, with current changes narrowly scoped to leak-checking contexts. Key files modified are ci/lib.sh, t/lib-cvs.sh, and t/lib-git-p4.sh. Phillip's question about ASan applicability remains as an open consideration for future work.
