This thread discusses a straightforward CI optimization proposed by Johannes Schindelin (Dscho) to skip git-svn tests during memory leak detection runs. The tests, being Perl-based, don't contribute to C memory leak checking while adding significant runtime (42+ minutes across 65 tests). Dscho provided clear metrics and rationale in his minimal patch modifying `ci/lib.sh` to introduce a `NO_SVN_TESTS` environment variable.

Git maintainer Junio C Hamano has reviewed and approved the change, noting the clean implementation and agreeing with the optimization. He indicates the patch will be merged into the integration branches. There are no outstanding questions or requested changes - this appears to be a non-controversial improvement that will reduce CI runtime without sacrificing meaningful coverage.
