This is a test fix targeting a flaky reftable test on Cygwin. The patch addresses test #29 in t0610-reftable-basics.sh which intermittently fails when run in parallel on Windows 11 (but passes when run serially or manually). The failure occurs due to a permission error when trying to corrupt reftable files using shell redirection (`: >file`).

The author (Ramsay Jones, a Cygwin specialist) investigated with strace but couldn't determine the root cause. The solution replaces the shell redirection with a `test-tool truncate` call, which empirically fixes the flakiness. Patrick Steinhardt helped with the solution. The change is minimal - just one line modified in the test script.

This appears to be a platform-specific workaround rather than a fundamental fix, but it's a reasonable solution given the difficulty in diagnosing the underlying race condition. The patch follows Git's standard practice of using test helpers rather than shell builtins when more reliable behavior is needed.
