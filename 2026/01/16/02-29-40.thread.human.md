This thread has been discussing how to report gettext support in Git's version output. Jiang Xin proposed adding detection through `git version --build-options`, initially following the pattern used for Rust support (showing "enabled/disabled"). Junio Hamano, the maintainer, suggested simplifying this to only show "gettext: enabled" when present, arguing that the Git version number provides enough context to distinguish between disabled builds and older versions that don't support the feature at all.

Jiang Xin implemented this simpler approach in v2 of the patch. While Patrick Steinhardt expressed a mild preference for the more verbose "enabled/disabled" reporting - finding it more user-friendly than requiring version number lookups - he acknowledged Junio's position and isn't pushing for changes. The discussion has effectively concluded with consensus around the simpler output, though it leaves open the broader question of whether feature detection outputs (gettext vs Rust vs libcurl) should be made consistent in the future. The patch appears ready for merging in its current form.
