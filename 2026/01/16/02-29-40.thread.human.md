This thread centers on Jiang Xin's patch series to add gettext support detection to Git version reporting via `git version --build-options`. The current v2 patch implements Junio's suggestion to simplify the output by only showing "gettext: enabled" when support exists, remaining silent otherwise - following libcurl's reporting style rather than Rust's explicit disabled-state approach.

Patrick Steinhardt raised a thoughtful counterpoint about the diagnostic value of showing disabled states, particularly for distinguishing between intentionally disabled builds and older versions lacking the feature entirely. However, he clarified this wasn't a strong objection. Jiang Xin responded that the Git version number itself provides sufficient context for such distinctions.

The discussion has evolved into a broader philosophical question about diagnostic reporting - whether tools should surface negative states or only positive ones. While Rust detection (commit cb2badb4) shows disabled states and libcurl does not, this patch doesn't propose altering either existing behavior. With Junio's prior approval of the simplified approach and no substantive new objections emerging, the series appears ready for inclusion in its current form. The thread remains open for any final design considerations before merging.
