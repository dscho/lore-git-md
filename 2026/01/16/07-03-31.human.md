This is part 4 of Patrick Steinhardt's 14-part series refactoring Git's object storage layer to support pluggable backends. The patch introduces a new iteration interface for loose objects that aligns with the planned unified object iteration model.

The key addition is `odb_source_loose_for_each_object()`, which provides a consistent way to iterate through loose objects using the same `struct object_info` pattern that will eventually work across all backends. Justin Tobler's review confirms this is building toward a generic `for_each_object()` that can work across storage types, though notes it will require expanding `struct object_info` for future backends.

The change is a stepping stone in the larger ODB abstraction effort, systematically replacing direct storage access with backend-agnostic interfaces. While this patch alone doesn't change behavior, it enables the subsequent unification of iteration across loose and packed objects in patch 7/14. The implementation looks clean and well-motivated as part of the series' architectural vision.
