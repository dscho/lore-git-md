This is a bugfix patch series addressing UTF-8 filename display issues in Git's diffstat output, submitted as part of Google Summer of Code (GSoC). The core problem is that diffstat incorrectly assumes byte count equals display width when truncating filenames containing multi-byte UTF-8 characters, which can lead to display corruption or infinite loops.

The main patch modifies `show_stats()` in diff.c to properly handle UTF-8 characters by using `utf8_width()` for accurate display width calculation. It also fixes a critical edge case where very small name-width values could cause an infinite loop. The second patch adds test coverage as requested by Junio Hamano, demonstrating correct behavior with UTF-8 filenames at various widths.

The changes are focused and well-motivated, addressing a real pain point for international users. The author has been responsive to review feedback, adding the requested tests and fixing the infinite loop issue discovered during testing. The patch looks ready for inclusion, though additional i18n-focused review would be valuable given the UTF-8 handling changes.
