This is a security patch in a series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005). The patch expands the configurable sanitization options for control sequences, allowing users to permit cursor movement and character erasure sequences through the `sideband.allowControlCharacters` setting.

The patch introduces two new allowed sequence types beyond just color: cursor movements (like moving cursor position) and erase operations (like clearing lines). These can be enabled via a comma-separated list in the config (e.g. `sideband.allowControlCharacters=color,cursor,erase`). The implementation carefully validates sequences against the configured policy without allocations.

The change comes after review discussions identified legitimate use cases where server hooks might use these sequences benignly, though they could also be abused to hide malicious activity. The patch maintains security by keeping these sequences disabled by default while providing opt-in flexibility. Test coverage verifies the new behaviors work as expected while still blocking unconfigured sequences.

This is part of a broader security hardening effort that has seen production validation in Git for Windows and Red Hat deployments. The series appears technically complete with all open items resolved in this v3 iteration.
