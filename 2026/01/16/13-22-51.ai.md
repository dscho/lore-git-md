This is a documentation patch for the experimental `git-last-modified` command, part of a v2 series that changes the default depth behavior. The patch documents the `--max-depth` option that was previously implemented but not properly documented.

The patch adds `--max-depth` to both the man page synopsis and options section, explaining that it limits directory traversal depth (with negative meaning no limit) and implies `--recursive` when positive. It also updates the command's usage string to include this option. The documentation notes the interaction with pathspecs - it can't be combined with wildcards.

This continues the series' focus on improving documentation and discoverability of options, following earlier patches that documented `-z` NUL-termination. The changes are straightforward and align with the command's experimental status, allowing behavior refinements while maintaining backward compatibility. The patch keeps the implementation simple by inheriting the depth control from Git's diff machinery rather than reinventing it.
