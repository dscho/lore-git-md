Security patch introducing configurable ANSI escape sequence handling in Git's sideband channel. This is part of a series addressing CVE-2024-32002 and CVE-2024-52005/GHSA-7jjc-gg6m-3329, which involve potential injection of malicious terminal control sequences through remote server messages.

Johannes Schindelin adds an "escape hatch" configuration option `sideband.allowControlCharacters` that lets users opt out of the default protections against ANSI escape sequences in sideband messages. The patch includes documentation and test updates to verify the new configuration works as intended. When enabled, this allows remote servers to send colored messages through the sideband channel, which some users may want for visual emphasis.

The implementation builds on previous security hardening that introduced strict sanitization by default. This patch makes that protection optional while maintaining security as the default stance. The test demonstrates both the default blocking behavior and the opt-in case where colors are allowed through.

This is the second of five patches in the series, following the initial security fix. The thread shows consensus on the approach, with input from brian m. carlson (who suggested the configuration option) and technical review from Patrick Steinhardt and Phillip Wood. The series represents a significant hardening of Git's remote protocol handling while preserving flexibility for trusted use cases.
