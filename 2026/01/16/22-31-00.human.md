This is a straightforward memory leak fix in the shallow repository handling code. The patch addresses a case where the `object_array` named 'stack' in `get_shallow_commits()` was not being properly cleaned up before the function returned, leaving allocated elements dangling.

The fix is simple - just one line added to call `object_array_clear(&stack)` before returning. The commit message notes this was caught by the leak-checking tests (linux-leaks and linux-reftable-leaks), and that the fix is needed for proper operation of the companion patch in this series that implements relative-depth fetching.

This is part of a well-reviewed 2-patch series (now at v4) that has gone through multiple rounds of feedback from Patrick Steinhardt, Junio Hamano, and Kristoffer Haugsbakk. The changes are minimal and focused - just fixing the memory leak while maintaining all existing functionality. The patch appears ready for integration.
