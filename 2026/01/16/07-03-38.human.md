This is part 7 of Patrick Steinhardt's 14-part series abstracting Git's object database to support pluggable backends. The patch introduces `odb_for_each_object()`, a unified interface for iterating over both loose and packed objects across all ODB sources. 

The new wrapper function handles alternates preparation and delegates to backend-specific iteration functions (`odb_source_loose_for_each_object()` for loose objects and `packfile_store_for_each_object()` for packed objects). It includes flags to control whether to process only local objects (`ODB_FOR_EACH_OBJECT_LOCAL_ONLY`) or promisor objects (`ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`).

Justin Tobler confirms his understanding that this current implementation is files-backend specific but will be generalized in future work. The patch represents an important step in the ODB abstraction effort by providing a single entry point for object iteration that can later be adapted for alternative backends. The series is nearing completion with only minor procedural issues remaining before merge.
