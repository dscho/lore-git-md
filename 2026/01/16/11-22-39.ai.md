This is a documentation patch updating the git-gui README to clarify Tcl/Tk dependencies. Oskar Jaskólski proposes adding explanatory text about the relationship between Tcl, Tk, and the `wish` command after encountering confusion while trying to build git-gui for the first time.

The patch modifies `git-gui/README` to explicitly state that Tk is used for the GUI while Tcl is the scripting language, and that `wish` executes Tk code. It also clarifies that only a single `tcl/tk` package needs to be installed rather than separate components. The change appears well-motivated by a real user experience of dependency confusion.

This is a straightforward documentation improvement that would help future users understand git-gui's requirements more clearly. The patch is small and focused, though it doesn't include any test updates since it's purely documentation. The explanation aligns with how Tcl/Tk actually work together, suggesting the author did sufficient research after their initial confusion.
