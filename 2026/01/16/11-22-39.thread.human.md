This thread discusses improvements to git-gui's README documentation regarding Tcl/Tk dependencies. Oskar Jaskólski originally proposed clarifying that users only need to install a single tcl/tk package, explaining the relationship between Tcl (the scripting language), Tk (the GUI toolkit), and the `wish` command that executes Tk code. The patch was motivated by real user confusion during Oskar's first build attempt.

Junio C Hamano has reviewed the proposal and identified several technical concerns that need addressing. He notes that on Debian systems, `wish` is just a virtual package and users actually need to install `tk`. He also questions marking gitk as optional since git-gui's menus integrate gitk functionality. Additionally, Junio points out that building from source requires `tclsh` for certain build processes, making the "no separate installation" claim inaccurate for source builds.

The discussion highlights the challenge of balancing clarity with technical precision in documentation. While Junio acknowledges the value of some proposed clarifications, he's flagged important platform-specific considerations and build requirements that need to be incorporated. The thread remains open while these technical points are resolved.
