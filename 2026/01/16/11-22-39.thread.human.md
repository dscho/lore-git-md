This thread introduces a documentation patch to clarify the Tcl/Tk dependencies for git-gui. Oskar Jaskólski noticed confusion around these requirements when first building git-gui and proposes updating the README to better explain that Tk provides the GUI while Tcl is the scripting language, with `wish` being the Tk interpreter. The patch helpfully notes that users typically only need to install a single `tcl/tk` package rather than separate components.

The change is small and focused, directly addressing a real point of confusion for new users. Since it's purely documentation, no test updates are needed. The explanation accurately reflects how Tcl and Tk work together, suggesting the author researched the topic after their initial experience. This appears to be a straightforward improvement that would make git-gui's requirements clearer for future users.
