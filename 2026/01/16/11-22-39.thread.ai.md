This thread introduces a documentation patch for git-gui's README to clarify Tcl/Tk dependencies. Oskar Jaskólski authored the patch after experiencing confusion about the relationship between Tcl, Tk, and the `wish` command during their first attempt to build git-gui. The patch modifies `git-gui/README` to explicitly explain that Tk provides the GUI while Tcl is the scripting language, with `wish` being the command that executes Tk code. It also clarifies that users only need to install a single `tcl/tk` package rather than separate components. The change is motivated by real user experience and provides accurate technical clarification about these dependencies. The patch is small and focused, touching only documentation without requiring test updates.
