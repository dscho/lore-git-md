This is a documentation patch updating the git-gui README to clarify Tcl/Tk dependencies. Oskar Jaskólski proposes adding explanatory text about the relationship between Tcl, Tk, and the `wish` command after encountering confusion while trying to build git-gui for the first time.

The patch adds a brief but helpful note explaining that Tk is the GUI toolkit, Tcl is the scripting language it uses, and that `wish` (the Tk shell) is what executes the GUI code. It also clarifies that users typically only need to install a single "tcl/tk" package rather than separate components. The change appears well-motivated by real user experience and makes the build instructions slightly more beginner-friendly.

While small in scope, this is exactly the sort of documentation improvement that helps new contributors - it addresses a point of confusion the author personally encountered and resolves it clearly. The patch is straightforward and unlikely to be controversial.
