This is the final patch in a security-focused series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005). The patch adds granular control over which ANSI control sequences are allowed through the sideband channel via the `sideband.allowControlCharacters` configuration.

The implementation introduces three new bitmask flags (ALLOW_ANSI_CURSOR_MOVEMENTS, ALLOW_ANSI_ERASE, and ALLOW_ALL_CONTROL_CHARACTERS) to complement the existing ALLOW_ANSI_COLOR_SEQUENCES. The configuration accepts comma-separated values like "color,cursor" to selectively enable specific sequence types. While the default remains restrictive (only allowing color sequences), this patch enables server operators to permit additional control sequences if needed.

Patrick Steinhardt's review notes the implementation could be slightly more readable with aligned enum assignments, which Johannes Schindelen agrees to change. They discuss whether supporting "true"/"false" in comma-separated lists is necessary, with Johannes arguing it provides consistency and flexibility. The implementation avoids allocations by parsing the CSV directly rather than using `string_list_split()`.

This patch concludes a technically complete solution that balances security (maintaining restrictive defaults) with flexibility (allowing per-URL configuration and selective opt-in for specific control sequences). The thread shows consensus on the implementation approach, with only minor style improvements remaining before finalization.
