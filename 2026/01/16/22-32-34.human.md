This is the final version of a security-focused patch series addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin's implementation has evolved through multiple iterations to provide configurable sanitization with increasing granularity.

The series introduces a new `sideband.allowControlCharacters` configuration that started as a simple boolean but now supports:
- String values ("default"/"color") for ANSI color sequences (SGR format ESC[..m)
- Comma-separated values ("cursor,erase") for cursor movement (ESC[nA) and erase sequences (ESC[K)
- Per-URL configuration via `sideband_apply_url_config()`

The core sanitization in `strbuf_add_sanitized()` validates sequences against policy without allocations, with dedicated handlers for each sequence type. The implementation maintains backward compatibility while adding flexibility through URL-scoped settings that follow `http.<url>.*` patterns, addressing Junio Hamano's suggestion for server-specific policies.

The series has been thoroughly reviewed by Patrick Steinhardt and Phillip Wood, with brian m. carlson endorsing the security/usability balance. It includes comprehensive test coverage in `t/t5409-colorize-remote-messages.sh` and has been updated to work with recent Git versions (including a rebased branch targeting v2.53.0-rc0).

This version represents the completion of the feature set with per-URL configuration as the final piece, resolving all architectural concerns about server trust scoping. The implementation is production-tested in Git for Windows (1+ year) and Red Hat (6+ months), with no outstanding review items.
