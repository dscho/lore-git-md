Documentation update for submodule `ignore=all` behavior with `git add --force`.

This final documentation patch in the series clarifies how `git add --force` interacts with submodules configured with `ignore=all`. The changes span three documentation files to ensure consistent messaging about the new requirement to use `--force` when staging updates to ignored submodules.

Key updates include:
- Explicitly stating in `git-add.adoc` that `--force` is needed to stage updates when `ignore=all` is set
- Rewriting the `submodule.<name>.ignore` documentation in `config/submodule.adoc` to clarify the behavior for each setting and the `--force` override
- Updating `gitmodules.adoc` to note which commands respect the ignore` setting and how `--force` can override it

The patch incorporates feedback from Ben Knoble about using more idiomatic "When set to..." phrasing and maintains technical precision while improving readability. This completes the v3 series that aligns `git add` behavior with other commands regarding submodule ignore settings, with all implementation and documentation now in sync.
