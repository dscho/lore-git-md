This is a documentation patch in the ongoing submodule `ignore=all` behavior thread. Claus Schneider responds to Kristoffer Haugsbakk's feedback on the commit message for patch 2/5 in the series, which implements consistent handling of ignored submodules across Git commands.

The response clarifies the motivation for the change: it enables better support for branch tracking in submodules (via `submodule.<name>.branch`) where users want to track the latest commit without manually updating SHA-1 references. The patch makes `git add` behave like `git status` by default when `ignore=all` is set, requiring `--force` to override. This matches the behavior for ignored files and reduces friction in workflows where submodules are loosely coupled dependencies.
