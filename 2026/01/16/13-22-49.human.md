This is a documentation patch for the experimental `git-last-modified` command, part of a v2 series that improves the command's UX. The patch adds missing documentation for the `-z` option, which makes output NUL-terminated rather than newline-terminated, matching behavior found in other Git commands.

The changes include:
1. Adding `-z` to the SYNOPSIS section
2. Documenting the option's behavior in the OPTIONS section
3. Adding an OUTPUT section that describes both the default and NUL-terminated formats
4. Updating the command's usage message to include `-z`

This is a straightforward documentation improvement that brings the man page in line with existing functionality. The patch is clean and focused, with no apparent issues. It's part of a larger effort to refine this experimental command's interface based on user feedback.
