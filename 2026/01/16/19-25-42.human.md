This is a security patch addressing ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin implements per-URL configuration for control character filtering, responding to Junio Hamano's request to make the security controls more granular while maintaining backward compatibility.

The patch introduces URL-specific overrides for the `sideband.allowControlCharacters` setting, following the same pattern as `http.<url>.*` configurations. This allows administrators to maintain strict security defaults while permitting trusted servers to send richer terminal output when needed. The implementation includes comprehensive test coverage and preserves Phillip Wood's whitelist for BEL/DEL handling.

The technical work appears solid, with careful attention to backward compatibility and transport-layer integration. However, the philosophical debate about default behavior continues - Schindelin advocates for security-first restrictive settings (backed by production evidence from Git for Windows and Red Hat deployments), while Hamano maintains a preference for opt-in controls to avoid workflow regressions.

This patch represents a pragmatic middle ground, providing the configuration machinery while leaving the policy debate about defaults for separate discussion. The implementation is ready for merging, with the remaining disagreement being about whether to ship it with permissive or restrictive defaults.
