This is a behavior change patch for the experimental `git-last-modified` command, part of a series improving its depth control and documentation. The patch changes the default behavior to be non-recursive (max-depth=0) rather than inheriting the diff machinery's recursive behavior, making it more intuitive when operating on specific files.

The key changes are:
1. Default max-depth is now 0 (non-recursive) instead of unlimited
2. Recursive flag is always enabled internally while respecting depth limits
3. Documentation updates clarify the new default behavior
4. New test cases verify the behavior with subdirectories and various depth settings

The change addresses user confusion where the command previously showed parent directory information rather than the exact file's modification when given a file path. The implementation maintains backward compatibility through explicit `--recursive` and `--max-depth` options while making the default behavior more predictable.

This is the final patch in the v2 series that has been evolving the command's depth control behavior and documentation. The change builds on previous patches that moved option handling into the command's own parsing and improved help text visibility.
