René Scharfe's series to remove implicit `the_repository` dependencies from tree parsing is nearing completion, having introduced new repository-aware APIs (`repo_parse_tree*()`) and converted callers across multiple subsystems including bloom filters, delta-islands, and path-walk. The work follows the project's established pattern for eliminating global state, with a Coccinelle semantic patch provided to automate future conversions.

Patrick Steinhardt initially raised minor architectural questions about constant placement and suggested squashing some mechanical changes, but these were non-blocking concerns. His later suggestion to tie the deprecation timeline for the old API to Git 2.53's release schedule drew pushback from Junio Hamano, who maintains that deprecation periods should not be version-locked to avoid constraining release planning. This final discussion point is purely process-related, as the technical approach is solid and the series has broad agreement. The work represents significant progress in the multi-year effort to remove `the_repository` global state, with tree parsing now joining other subsystems that have been converted to explicit repository parameters.
