René Scharfe has been leading an effort to remove implicit dependencies on the global `the_repository` variable from Git's tree parsing subsystem. His patch series introduces repository-aware variants of key functions (`repo_parse_tree*()`) and systematically converts callers across multiple subsystems including bloom filters, delta-islands, and path-walk. The changes are mechanical but thorough, preserving behavior while eliminating global state.

Patrick Steinhardt raised two points during review: first, a minor architectural suggestion about where to place the `DEFAULT_MAX_ALLOWED_TREE_DEPTH` constant (proposing either `repo-settings.h` or keeping it internal), and second, a non-blocking comment that some of the mechanical conversion patches could potentially be squashed together. Patrick explicitly noted this second point wasn't a substantive critique, just an observation about commit organization. 

The series follows René's established pattern for these large-scale refactorings (new API → caller conversions → deprecation) and builds on years of prior work. With the tree parsing subsystem now converted and a Coccinelle semantic patch provided for future conversions, this marks significant progress in the ongoing effort to eliminate global state from Git's codebase. The thread shows the changes are uncontroversial and likely ready for merging.
