This is a platform compatibility patch in the Windows symlink support series, specifically addressing error handling in `mingw_lstat()`. The patch ensures proper error detection when querying reparse point information (which includes symlinks) on Windows.

The change moves the `FindFirstFileW()` call earlier in the function to fail fast if it cannot access the reparse point data, before any `stat` structure fields are modified. This makes the error handling more robust while maintaining the existing behavior where `GetFileAttributesExW()` is still used for non-reparse-point files (since it's faster for that case).

The patch is part of a mature series (v5) that has already received sign-offs from key Windows contributors Karsten Blees and Johannes Schindelin, with Johannes Sixt providing review. The implementation looks clean and focused - it handles the error case while keeping the performance optimization of only using the more expensive `FindFirstFileW()` call when actually needed for reparse points.

This is one of the final refinements in a long-running effort to improve Windows symlink support, building on Git for Windows work dating back to 2015. With all technical issues now resolved and maintainer approval, this series appears ready for integration.
