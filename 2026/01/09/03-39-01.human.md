This is a documentation patch updating the builtin API comments in builtin.h. Derrick Stolee noticed the documentation was outdated, particularly missing details about the `struct repository` parameter added in a recent refactoring, as well as some builtin flags and testing requirements.

The patch makes several specific improvements:
1. Updates the function prototype to include the now-required `struct repository*` parameter
2. Adds missing documentation for the `NO_PARSEOPT` flag
3. Improves formatting with additional newlines for readability
4. Adds a new section detailing how various test scripts will verify the builtin's behavior

The motivation comes from wanting to better document the process for new builtin development, with Stolee verifying the changes against a local test implementation. The patch is cleanly focused on documentation accuracy without making any code changes.
