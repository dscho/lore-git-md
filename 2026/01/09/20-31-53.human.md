This is a feature patch adding a `--keys` flag to `git repo info` as part of a completed series that standardizes format handling across `git repo` subcommands. The patch enables programmatic discovery of available repository metadata keys without requiring users to parse documentation or use `--all`.

The implementation adds a new `print_keys()` function that outputs available keys in either newline or NUL-terminated format, with strict validation to prevent invalid combinations with other flags. The documentation is updated to explain the new option, and tests verify the behavior including format handling and error cases.
