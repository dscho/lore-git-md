Simon Cheng proposed adding a flag to `git clean` for removing ignored nested Git repositories, motivated by cleanup needs in Arch Linux's AUR packaging system. brian m. carlson pointed out this functionality already exists through the `-ff` (double force) flag. In a follow-up, Simon confirmed the existing flag meets their needs and suggested improving discoverability by enhancing the "Skipping repository" message to explicitly mention `-ff` as the solution. This turns out to be a documentation clarity issue rather than a missing feature. The discussion now awaits feedback on Simon's proposal to make the existing behavior more visible through improved messaging, which would help users encountering similar situations in the future.
