This is part of the ongoing `the_repository` removal effort, specifically the first patch in a 10-part series by René Scharfe. The patch moves the `core.maxTreeDepth` configuration from a global variable to repository-specific settings stored in `struct repo_settings`.

The change is mechanical but important for enabling multiple repositories with different tree depth limits to coexist in the same process. The patch:
1. Removes the global `max_allowed_tree_depth` variable and its config handling
2. Adds platform-specific default values as a macro in git-compat-util.h
3. Adds the setting to `struct repo_settings` and initializes it
4. Updates all call sites to use the repository-specific version

This follows the established pattern for similar refactorings in the `the_repository` removal effort. The patch's scope is well-contained and touches only the expected files (environment handling, tree walking code, and repo settings). Given René Scharfe's track record with these types of refactorings, this change is likely to proceed smoothly through review.
