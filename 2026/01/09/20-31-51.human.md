This is a feature addition to the `git repo` command family, specifically adding a `--keys` flag to `git repo info` and extending format support with `--format=default`. The patch series from Lucas Seiki Oshiro implements Junio Hamano's earlier suggestion for programmatic key discovery in the repository info command.

The main changes in v3 extend the format handling to be more flexible and consistent across commands. The `--format=default` option is now supported in both `git repo info` and `git repo structure`, resetting each to their respective default output styles (keyvalue for info, table for structure). This provides a clean way to override previous format specifications in a command chain.

The `--keys` flag itself allows listing available metadata keys without their values, which helps scripts discover what information is available. The implementation includes proper format support (including NUL-terminated output) and validation to prevent invalid combinations with other flags like `--all`.

The series has gone through several iterations with input from Junio and Patrick Steinhardt, and is now in its final polishing phase. The current version adds comprehensive test coverage for the new functionality, including verification of format reset behavior and cross-command consistency. The changes touch documentation, command implementations in builtin/repo.c, and test cases across two test scripts.
