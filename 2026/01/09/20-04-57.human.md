This is the final version (v2) of a major platform compatibility patch series introducing comprehensive Windows symbolic link support, now ready for integration. The 18-patch series builds on Git for Windows' symlink implementation that has been maturing since 2015, with contributions from Johannes Schindelin, Karsten Blees, Bill Zissimopoulos, and Johannes Sixt.

The series implements POSIX-like symlink operations in the MinGW compatibility layer, covering creation, reading, stat'ing, directory handling, renaming, and edge cases like index corruption. Key technical improvements include proper `stat()`/`lstat()` implementation using `GetFileInformationByHandle()`, robust `readlink()` functionality via NTFS reparse points, directory symlink handling in `unlink()`/`chdir()`, and Windows-specific error code translations.

All technical and administrative issues from previous iterations have been resolved, including clarifying historical behavior around `ELOOP` handling and fixing a typo in patch 10. The series represents a significant step forward in Windows-POSIX compatibility for symlink operations and has received thorough review from multiple Windows Git experts. Maintainer Junio Hamano has approved it for integration after addressing all technical points.

The patches touch `compat/mingw*` files and `read-cache.c`, with the final version simplifying `mingw_lstat()`. Notable changes include patch 2's improved symlink resolution, patch 10's directory symlink handling via `_wrmdir()`, and patch 11's robust rename implementation using `MoveFileEx()`. The series concludes the `js/prep-symlink-windows` foundation work and is ready for inclusion in upcoming releases.
