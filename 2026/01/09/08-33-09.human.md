This is the first patch in Patrick Steinhardt's 10-part series refactoring Git's packfile storage to support pluggable object database (ODB) backends. The patch prepares for moving packfile store ownership from the ODB layer to individual ODB sources by changing how stores are initialized.

The key change is modifying `packfile_store_new()` to take an `odb_source` parameter instead of an `object_database`. This creates a transitional state where stores are still owned by the ODB but can now access their future owning source. The patch touches 3 files with straightforward mechanical changes to function signatures and call sites.

This is a foundational change for the larger architectural goal of having each ODB source manage its own packfiles. While the patch itself is small, it enables the more significant refactorings that follow in the series. The changes are well-contained and maintain existing behavior, with no functional impact yet.
