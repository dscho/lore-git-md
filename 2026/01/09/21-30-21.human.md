This is the final patch in René Scharfe's series removing implicit `the_repository` dependencies from tree parsing functions. The patch adds and applies a Coccinelle semantic patch to convert remaining calls to `parse_tree()`, `parse_tree_gently()`, and `parse_tree_indirect()` to their repository-aware variants (`repo_parse_tree*()`).

The changes touch 27 files across builtins, merge machinery, diff code, and test helpers - all mechanical conversions where the global `the_repository` is passed explicitly. The patch follows the established pattern of this multi-year effort: first introducing repository-aware variants, then systematically converting callers, and finally deprecating the old API.

The semantic patch will help future contributors automatically convert any new code that might still use the old functions. This completes the tree parsing portion of the `the_repository` removal effort, building on prior work that made pack-bitmap-write and add-interactive repository-aware. The changes are well-tested and unlikely to introduce regressions since they're purely mechanical API updates with no behavior changes.
