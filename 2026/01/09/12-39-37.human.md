This is a refactoring patch in Patrick Steinhardt's ongoing series to improve ref backend verification. It removes unused fields from `struct fsck_ref_report` that were intended to provide more detailed error reporting but were never actually populated. The change is straightforward - deleting the unused `oid` and `referent` fields along with their related display code in `fsck_refs_error_function()`.

The patch is part of the larger effort to clean up and standardize ref verification across Git's files and reftable backends. While this particular change is minor, it's a sensible cleanup that removes dead code and simplifies the error reporting structure. The series as a whole shows careful attention to detail in refactoring the verification infrastructure.
