Platform compatibility patch improving Windows symlink handling. This is patch 11/18 in a completed v5 series that comprehensively addresses Windows symlink support, now ready for integration after extensive review.

The patch specifically fixes symlink renaming on Windows by replacing the problematic `_wrename()` call with direct `MoveFileEx()` usage, which properly handles symlinks. Johannes Schindelin confirms the code's reliability despite its complexity, noting it has been battle-tested over years in Git for Windows. The change includes proper error handling and attribute management during rename operations.

This is part of a larger effort to bring robust POSIX-like symlink behavior to Windows, with all technical and administrative matters now resolved. The series has received sign-offs from key Windows experts including Johannes Schindelin and Johannes Sixt, with Junio Hamano approving it for integration.
