This is part 5 of Patrick Steinhardt's 10-patch series refactoring Git's packfile storage to support pluggable object database (ODB) backends. The series moves packfile store ownership from the ODB layer to individual ODB sources, continuing the architectural work to make object lookup source-aware.

This specific patch moves the packfile store from `struct object_database` to `struct odb_source`, recognizing that each source connected to a database has its own set of packfiles. The change is mechanical but wide-ranging, touching packfile handling across fast-import, grep, index-pack, and other commands. The key insight is that most callers don't need adaptation since they use `repo_for_each_pack()` which already handles enumeration correctly.

The patch maintains identical behavior while cleaning up the conceptual model - sources that don't use packfiles (a future possibility) won't need to carry this baggage. Reviewers Justin Tobler and Toon Claes have already vetted earlier versions, and all feedback has been addressed. This continues the series' steady progress toward pluggable backends with careful attention to not disrupt existing functionality.
