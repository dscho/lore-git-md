This is a refactoring patch that's part of a 2-patch series enhancing `git status` to show divergence from both upstream and push tracking branches. The patch extracts and modularizes the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function in remote.c.

The key technical details are:
- Preserves the existing behavior while improving code structure
- Maintains special handling for quick mode case (AHEAD_BEHIND_QUICK) where branch state must be checked separately from commit counts
- Converts some parameters to bool per Phillip Wood's review suggestion
- Keeps the sti parameter (now renamed to up_to_date) to properly handle quick mode edge cases
- Leaves upstream-is-gone handling with the caller as suggested
- Avoids changing the header file interface to minimize scope

The refactoring has gone through extensive review with 17 iterations, with Phillip Wood confirming it faithfully preserves the original behavior while improving code organization. The patch appears ready for merging as part of the larger tracking-info enhancement effort.
