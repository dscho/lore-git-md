This is a performance optimization patch in the Windows symlink support series. It eliminates redundant `GetFileAttributes()` calls in Git's MinGW compatibility layer when handling paths with trailing slashes on Windows.

The patch simplifies `mingw_lstat()` by removing the path-traversal workaround that previously required two system calls. Instead, it now modifies the wide-character buffer directly to strip trailing slashes before making a single `GetFileAttributesExW()` call. This change builds on the series' wider Unicode conversion work to make path handling more efficient.

The implementation is straightforward - it removes 38 lines of now-unnecessary code while maintaining the same behavior. Johannes Schindelin has signed off, indicating this fits well with the broader Windows symlink improvements. As the first patch in a mature series that's been through multiple iterations, this appears ready for integration.
