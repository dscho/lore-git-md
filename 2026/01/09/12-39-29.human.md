This is a refactoring and bugfix series targeting Git's reference consistency checks, with work split between the files and reftable backends. Patrick Steinhardt leads this effort to improve and unify how Git verifies ref integrity.

Finally, it introduces shared verification infrastructure between the files and reftable backends (patches 9-14) and migrates some fsck checks to use this new shared code (patches 15-17).

The changes touch core ref-handling code in both backends, with corresponding test updates to verify the new behavior.
