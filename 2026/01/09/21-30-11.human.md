This is part of the ongoing `the_repository` removal effort, a series of 10 patches from René Scharfe that eliminates implicit use of the global repository variable in tree parsing functions. The series introduces new `repo_parse_tree*()` variants that take explicit repository parameters, then systematically converts all callers to use them instead of the old `the_repository`-dependent versions.

The changes are mechanical but wide-ranging, touching 41 files across the codebase including builtin commands, diff machinery, merge operations, and test helpers. The first patch moves `core.maxTreeDepth` configuration into repository settings, while the last provides a Coccinelle script to automate future conversions. 

As with most of René's work, this is a well-structured series that follows the project's incremental refactoring approach - each patch is focused and builds cleanly on the previous ones. The changes are purely internal with no user-visible behavior differences, continuing the long-running effort to make Git's code more explicit about repository dependencies.
