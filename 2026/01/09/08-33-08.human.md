This is the final version of Patrick Steinhardt's 10-patch series refactoring Git's packfile storage to track packs per object database (ODB) source rather than per ODB. The series completes the architectural groundwork for pluggable ODB backends by ensuring all object access routes through individual ODB sources.

The changes move packfile-related data (regular packs, kept packs, MIDX) to be managed by packfile stores owned by each ODB source, with over 30 files modified to make object lookup source-aware while maintaining identical behavior. Key technical changes include making core functions like `find_pack_entry()` source-aware, simplifying MIDX and pack preparation to operate on individual stores, and updating callers (fast-import, grep, pack-objects) to explicitly prepare stores.

The v3 iteration addresses all previous review feedback, including a typo fix in patch 8's commit message noted by Kristoffer Haugsbakk. Reviewers Justin Tobler and Toon Claes provided detailed feedback on earlier versions, with all open questions now resolved. The series is ready for merging once the minor documentation fix is incorporated.

This represents a significant step in the ongoing ODB abstraction effort, enabling future pluggable backends while maintaining current behavior. The changes are well-tested and reviewed, with no outstanding technical concerns.
