This is part 8 of Patrick Steinhardt's 10-patch series refactoring Git's packfile storage to support pluggable object database backends. The series moves packfile store ownership from the ODB layer to individual ODB sources.

This specific patch is a straightforward code cleanup that inlines `find_kept_pack_entry()` into its only caller, `has_object_kept_pack()`, and makes the function file-local by removing its declaration from packfile.h. The change simplifies the code by eliminating an unnecessary layer of indirection while maintaining identical behavior - the function call chain is flattened but the actual object lookup logic remains unchanged.

The patch modifies packfile.c to combine the two functions and reorders some existing function definitions to allow removing the declaration from packfile.h. This is a mechanical refactoring that doesn't affect functionality but improves code organization as part of the larger ODB abstraction effort. The change is small (28 lines modified) and focused, with no behavioral impact beyond the internal function structure.
