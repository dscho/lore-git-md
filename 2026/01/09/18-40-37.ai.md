Feature enhancement for `git status` showing divergence from both upstream and push tracking branches. This is the second and final patch in Harald Nordgren's series, implementing the push tracking display after the preparatory refactoring in patch 1.

The patch adds a new helper function `get_remote_push_branch()` that resolves the push tracking reference through the full refspec resolution chain. It extends `format_tracking_info()` to handle both upstream and push comparisons, showing the push comparison only when it differs from upstream. The output maintains Git's existing conventions while adding the new information on a separate line when relevant.

Key technical aspects:
- New `BRANCH_MODE_PULL` and `BRANCH_MODE_PUSH` flags control which comparisons to show
- Push advice is only shown when relevant to avoid noise
- Comprehensive test coverage (262 lines) verifies all edge cases including remapped refspecs and multiple remote scenarios
- Follows Git's established pattern for flags and bitmask operations
- Preserves existing advice messages while adding push-specific advice when appropriate

The implementation has undergone 19 iterations with extensive review from Junio C Hamano, Phillip Wood, and others, addressing all feedback. The series is now merge-ready, providing a useful feature for workflows where upstream and push tracking branches differ while maintaining backward compatibility.
