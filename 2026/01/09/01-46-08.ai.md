Documentation patch updating the Git FAQ to recommend stash import/export for syncing working trees across machines. This is a follow-up to Git 2.51's new stash import/export functionality.

The patch rewrites the FAQ section about transferring work between machines to prioritize the new import/export mechanism over direct filesystem syncing with rsync`. The new text explains how to:
1. Create and export stashes (including untracked files with `--include-untracked`)
2. Transfer them via normal Git push/fetch
3. Import and apply them on the destination machine

While still mentioning rsync as an alternative, the revised text clearly positions it as a secondary option with more caveats. The explanation of rsync's risks remains but is now framed as a fallback rather than the primary recommendation.

The patch appears well-motivated, building on a recent feature addition to provide clearer guidance. The commit message is concise but sufficient, and the documentation changes are thorough while maintaining the existing warning tone about data integrity risks.
