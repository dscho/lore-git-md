Platform compatibility patch in the Windows symlink support series. This is part of a major effort to improve symbolic link handling on Windows, building on Git for Windows' existing symlink implementation.

The patch focuses on error handling in `mingw_lstat()` when dealing with reparse points (Windows' mechanism for symbolic links and other special files). Currently, if `FindFirstFile()` fails when checking a reparse point, the function continues silently, potentially providing incorrect stat information. The change makes the function fail early in this case, before modifying the output buffer.

Key technical details:
- Moves the `FindFirstFile()` call earlier in the function
- Adds proper error handling when the call fails
- Still maintains the performance optimization where `GetFileAttributesEx()` is used for non-reparse files (about twice as fast)
- The diff is best viewed with `--color-moved -w` due to indentation changes

The patch has been signed off by both Karsten Blees (the original author) and Johannes Schindelin (Git for Windows maintainer), indicating consensus on the approach. This is part of a mature patch series (now at v5) that has undergone extensive review and is ready for integration.
