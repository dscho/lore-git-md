Thread summary:

Simon Cheng proposes adding a flag to `git clean` that would remove ignored nested Git repositories, which `git clean -dxf` currently skips. The motivation comes from Arch Linux's AUR packaging system, where `makepkg` creates source repositories in `./src/NAME` directories that need cleanup after builds. The change would modify `builtin/clean.c` and require documentation updates. The proposal is currently a feature request without implementation; key considerations include whether this warrants a new flag versus modifying existing behavior, and how to handle edge cases where nested repos should be preserved. The use case is concrete and well-articulated, focusing on build system workflows where temporary nested repositories are created in ignored paths.
