This is part of the ongoing `the_repository` removal effort, specifically the sixth patch in a 10-patch series by René Scharfe converting tree parsing functions to be repository-aware. The patch targets the pack-bitmap-write subsystem.

The change is mechanical and straightforward: it replaces a call to `parse_tree()` (which internally uses the global `the_repository`) with `repo_parse_tree()` in `pack-bitmap-write.c`, passing the repository pointer that was already made available in this file by prior work in March 2025. The modification occurs in the `fill_bitmap_tree()` function, which is part of the bitmap writing machinery.

This continues the series' established pattern of first introducing repository-aware variants of functions (done in earlier patches) and then systematically converting call sites. The change preserves all existing behavior while removing another implicit dependency on the global repository state. The patch is small (just one line changed) and follows the same proven approach as previous conversions in this series.

The series as a whole is progressing smoothly with no objections raised, which is typical for René Scharfe's carefully executed refactorings in this long-running effort to eliminate `the_repository` globals. This patch maintains that high standard of mechanical correctness with thorough coverage of impacted call sites.
