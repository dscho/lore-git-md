Refactoring patch in Patrick Steinhardt's ODB abstraction series, focusing on packfile store operations.

This is patch 9/10 in the v3 series that refactors Git's packfile storage to support pluggable object database backends. The patch modifies `find_pack_entry()` to operate on a single packfile store rather than scanning all repository sources, bringing it in line with the series' goal of moving packfile ownership to individual ODB sources.

Key changes:
- `find_pack_entry()` now takes a `packfile_store` parameter instead of a repository
- MIDX and packfile lookup logic remains functionally identical but operates on the passed store
- Callers (`packfile_store_freshen_object()`, `packfile_store_read_object_info()`) simplified as they already handle source iteration
- `has_object_pack()` updated to explicitly iterate sources when needed
- 43 lines modified with net -20 lines removed through simplification

The patch continues the series' pattern of making internal interfaces more precise while maintaining identical behavior. It follows the architectural direction established in earlier patches, with all prior review feedback incorporated. The changes are mechanical but important for the eventual goal of pluggable ODB backends.
