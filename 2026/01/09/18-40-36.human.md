This is a refactoring patch that prepares for adding push remote branch comparison to `git status`. It's the first of a two-patch series that has gone through 19 iterations with extensive review.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This modularization will make it easier to add push tracking information in the second patch while maintaining the existing behavior. Key changes include:

- Separating the message formatting from advice generation
- Converting some parameters to `bool` for clarity (as suggested by Phillip Wood)
- Renaming the `sti` parameter to `up_to_date` to better reflect its meaning
- Moving upstream-is-gone handling to the caller
- Preserving all existing output formats and quick mode (AHEAD_BEHIND_QUICK) behavior

The refactoring maintains identical output while making the code more maintainable. The patch has been thoroughly reviewed by multiple contributors (Junio C Hamano, Phillip Wood, Ben Knoble) and addresses all identified issues from previous iterations. It's now in its final form, ready to serve as the foundation for the push tracking feature in the next patch.
