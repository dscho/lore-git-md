This is a refactoring patch in the Windows symlink support series, specifically addressing the `do_lstat()` function in the MinGW compatibility layer. The patch simplifies the code by eliminating the separate `do_lstat()` helper function now that its logic is only needed for `mingw_lstat()` (which doesn't follow symlinks). The change removes 21 lines while adding 2, consolidating the symlink handling directly into `mingw_lstat()`.

The patch follows through on architectural changes made earlier in the series where `mingw_stat()` was reimplemented to properly handle symlinks via `GetFileInformationByHandle()`. With that in place, the dual-purpose `do_lstat()` function (which previously handled both `lstat` and `stat` cases) becomes unnecessary. The remaining symlink-specific code in `mingw_lstat()` is now simpler and more direct, just setting the appropriate mode bits when it detects a symlink.

Karsten Blees and Johannes Schindelin have both signed off on this change, indicating it's been reviewed and fits within the broader symlink support effort. The patch appears clean and focused, removing obsolete code paths while maintaining the same behavior for the remaining `lstat` case. This is part of the final v5 series that has been approved for integration after extensive review.
