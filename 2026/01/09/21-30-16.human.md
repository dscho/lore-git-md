This is part 5 of René Scharfe's ongoing series to remove `the_repository` global variable dependencies, specifically targeting tree parsing functions. The patch converts a call site in `delta-islands.c` from the implicit `parse_tree()` to the new explicit `repo_parse_tree()` variant, passing the available repository pointer.

The change is mechanical and follows the established pattern from earlier patches in the series - replacing a function that internally uses the global variable with one that takes a repository parameter. The commit message notes this builds on prior work from March 2025 that removed other `the_repository` dependencies in the delta-islands code.

This is a straightforward, well-executed change in a series that has been progressing smoothly. The patch is small (just one line changed) and focused, with no expected behavior changes. As with the rest of the series, this continues the project's long-term effort to make repository operations more explicit and less reliant on global state.
