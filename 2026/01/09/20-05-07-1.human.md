This is a platform compatibility patch that improves Windows symlink handling, specifically addressing directory symlinks in the `mingw_unlink()` function. It's part of a larger v5 series (18 patches total) introducing comprehensive Windows symlink support that's now ready for integration.

The patch fixes an edge case where Windows' `_wunlink()` and `DeleteFileW()` functions fail to delete symlinks pointing to directories, returning `ERROR_ACCESS_DENIED`. The solution is to attempt `_wrmdir()` when this error occurs, which can successfully remove such symlinks. The change maintains existing retry logic for in-use files while adding this new fallback path.
