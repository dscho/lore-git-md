This is the cover letter for the third version of Patrick Steinhardt's 10-patch series that completes the refactoring of Git's packfile storage to track packs per object database (ODB) source rather than per ODB. The series is part of the larger ODB abstraction effort to enable pluggable backends.

The key architectural change moves all packfile-related data (regular packs, kept packs, MIDX) to be managed by packfile stores owned by individual ODB sources. This ensures object lookup is always source-aware while maintaining identical behavior. The changes touch 30+ files across the codebase, with core functions like `find_pack_entry()` updated to work with the new model.

The v3 iteration addresses all feedback from previous reviews, including a typo fix in patch 8's commit message (noted by Kristoffer Haugsbakk) and some improved commit messages. Reviewers Justin Tobler and Toon Claes provided detailed feedback on earlier versions, with all open questions now resolved. The series builds on two other recently merged topics and is ready for inclusion pending this final documentation fix.

This represents the last major step needed before introducing pluggable ODB backends, though Patrick notes the abstractions remain leaky" and will need further refinement. The changes are mechanical but wide-ranging, affecting packfile handling across commands like fast-import, grep, and pack-objects.
