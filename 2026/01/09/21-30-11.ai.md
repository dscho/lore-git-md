This is a cover letter for a 10-patch series that continues the ongoing `the_repository` removal effort, specifically targeting tree parsing functions. The series is authored by René Scharfe, one of the primary drivers of this multi-year project to eliminate Git's reliance on the global `the_repository` variable.

The series introduces new `repo_parse_tree*()` variants that accept an explicit repository parameter, then systematically converts all callers to use these new functions instead of the old ones that implicitly used `the_repository`. The changes are mechanical but wide-ranging, touching 41 files across various subsystems including builtin commands, diff machinery, merge operations, and test helpers.

The first patch moves `core.maxTreeDepth` from a global setting to repository-specific settings, while the last patch provides a Coccinelle semantic patch to automate similar conversions in the future. The middle patches handle the actual conversion of tree parsing calls, with each targeting a specific subsystem or set of related callers.

This appears to be a well-structured series that follows the established pattern of previous `the_repository` removal work - introducing new API variants first, then converting callers incrementally. The changes are focused and the commit messages are clear about their limited scope. Given René's track record with this kind of refactoring and the mechanical nature of the changes, this series is likely to be uncontroversial and quickly merged.
