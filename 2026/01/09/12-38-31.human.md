This is a security patch in the ongoing series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). Patrick Steinhardt is reviewing Johannes Schindelin's implementation that adds granular control over which ANSI sequences are allowed through Git's sideband channel via the new `sideband.allowControlCharacters` configuration.

The patch introduces bitmask flags for cursor movement (`ALLOW_ANSI_CURSOR_MOVEMENTS`) and erase sequences (`ALLOW_ANSI_ERASE`), joining the existing color sequence flag. While Patrick questions the practical need for allowing these potentially dangerous sequences, he acknowledges the implementation is sound now that the infrastructure exists. His review focuses on minor readability and implementation details - suggesting aligned enum assignments and questioning whether boolean "true"/"false" values should be accepted in the comma-separated list format.

The discussion reflects late-stage refinement of a security feature that has already addressed core technical concerns. Patrick's feedback is constructive but not blocking, indicating the series is nearing readiness. The flexible configuration system maintains security while accommodating different trust models, with color sequences allowed by default but cursor/erase sequences blocked unless explicitly enabled.
