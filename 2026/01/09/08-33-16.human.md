This is patch 8/10 in Patrick Steinhardt's series refactoring Git's packfile storage to support pluggable object database backends. The patch focuses on code cleanup rather than functional changes.

The change inlines `find_kept_pack_entry()` into its only caller `has_object_kept_pack()`, eliminating an unnecessary layer of indirection. The implementation is moved directly into `has_object_kept_pack()` and simplified by making the `pack_entry` struct local rather than passed as a parameter. This allows removing the function declaration from packfile.h entirely.

The patch follows the series' pattern of making packfile operations more source-aware while maintaining identical behavior. It's a straightforward cleanup that reduces code complexity without changing functionality - the kind of mechanical improvement that often appears in later patches of a refactoring series after the core architectural changes are in place.

This continues the series' progression toward its goal of moving packfile store ownership from the ODB layer to individual ODB sources. The change is well-contained and unlikely to be controversial, building on the more substantial architectural work in earlier patches.
