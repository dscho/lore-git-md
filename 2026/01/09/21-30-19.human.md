This is part 8 of René Scharfe's ongoing series to remove `the_repository` global variable dependencies, specifically focusing on tree parsing functions. The patch converts one internal call in `tree.c` from `parse_tree()` to the new repository-aware `repo_parse_tree()` variant, passing through the repository pointer that's already available in the function context.

The change is mechanical and straightforward - just swapping one function call for another while maintaining the same error handling. This continues the established pattern seen in earlier patches of the series: first introducing repository-aware variants of functions, then systematically converting callers to use them. The patch touches only one file (`tree.c`) and makes no behavior changes.

As with the rest of the series, this is a well-executed step in the long-running `the_repository` removal effort. The change is uncontroversial and builds on prior work from 2018 that first made the tree reading functions repository-aware.
