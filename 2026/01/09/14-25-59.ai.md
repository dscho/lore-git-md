Documentation patch standardizing terminology in `git-patch-id` documentation and code. This is part 3 of a 6-patch series that has already received positive reviews and is now in its final iteration (v2).

The patch focuses on consistent capitalization and terminology, changing "patch-id" to "patch ID" throughout both the man page (`Documentation/git-patch-id.adoc`) and the command's source code (`builtin/patch-id.c`). It also ensures "ID" is capitalized when used alone. These changes align with Git's documentation style guidelines and improve readability without altering functionality.

The series as a whole has been well-received, with Pushkar Singh and Patrick Steinhardt providing positive feedback on v1. This v2 iteration addresses minor markup nits identified in review. The changes are uncontroversial and merge-ready, continuing Kristoffer Haugsbakk's established pattern of documentation improvements. The patch touches only documentation and help text, with no behavioral changes to the `git patch-id` command itself.
