This is a refactoring patch in the Windows symlink support series, now in its final form. It simplifies the MinGW compatibility layer by eliminating a redundant `do_lstat()` helper function that was only used by `mingw_lstat()`. The change consolidates the symlink-handling logic directly into `mingw_lstat()` since the separate `follow` parameter path (for `stat()`-like behavior) is now handled by the new `mingw_stat()` implementation introduced earlier in the series.

The patch removes 21 lines while adding just 2, showing the simplification. It's part of a well-reviewed effort to bring comprehensive symlink support to Windows, with sign-offs from both Karsten Blees (the original Windows symlink implementation author) and Johannes Schindelin (Git for Windows maintainer). The change is straightforward and low-risk, touching only Windows-specific code paths that have been thoroughly exercised in the larger symlink series.
