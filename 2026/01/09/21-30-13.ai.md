This is part of the ongoing `the_repository` removal effort, specifically focusing on tree parsing functions. It's the second patch in a 10-part series by René Scharfe.

The patch introduces new repository-aware variants of tree parsing functions: `repo_parse_tree_gently()`, `repo_parse_tree()`, and `repo_parse_tree_indirect()`. These mirror the existing functions but take an explicit `struct repository *` parameter instead of implicitly using `the_repository`. The original functions are kept as wrappers that call the new variants with `the_repository` for backward compatibility.

The changes are mechanical and follow the established pattern for this refactoring effort. The patch touches both the implementation in `tree.c` and declarations in `tree.h`, adding the new functions while preserving the existing API. This is a typical step in the `the_repository` removal process - first adding repository-aware variants before converting callers in subsequent patches.

Given René Scharfe's extensive experience with this type of refactoring and the straightforward nature of the changes, this patch appears to be a solid, uncontroversial step in the series. The next patches will likely convert callers to use these new repository-aware functions.
