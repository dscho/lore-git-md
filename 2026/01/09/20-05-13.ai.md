Platform compatibility patch adding Windows 10 unprivileged symlink creation support. This is part of the larger Windows symlink support series (now at v5) that has been through extensive review and is ready for integration.

The patch enables symlink creation without administrator privileges on Windows 10 Build 14972 and later when Developer Mode is active, by using the `SYMBOLIC_LINK_FLAG_ALLOW_UNPRIVILEGED_CREATE` flag. The implementation carefully checks the Windows version before attempting to use this flag, since older versions would reject it with `ERROR_INVALID_PARAMETER`. The flag is applied to both file and directory symlink creation paths.

Key technical details include:
- New `adjust_symlink_flags()` function that checks Windows version and conditionally sets the unprivileged creation flag
- Global variables `symlink_file_flags` and `symlink_directory_flags` to track the flags to use
- Integration with the existing symlink creation code paths, including the phantom symlink handling added earlier in the series

The patch maintains backward compatibility while taking advantage of newer Windows capabilities when available. Johannes Schindelin (Dscho) has signed off on this change, and it represents the final refinement to the comprehensive Windows symlink support that has been in development across multiple patch series versions.
