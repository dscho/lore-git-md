This is a platform compatibility patch that implements `readlink()` for Windows as part of the larger symlink support series. The patch removes the stub implementation in `mingw-posix.h` and adds a proper implementation in `mingw.c` that reads NTFS reparse points to handle both symlinks and directory junctions.

The implementation uses the existing `read_reparse_point()` helper function to get the target path, then carefully copies the result into the caller's buffer while respecting the POSIX `readlink()` API quirks - notably that it doesn't fail if the buffer is too small, just truncates the result. The code handles UTF-8 conversion and includes proper error checking.

This is patch 13/18 in the v2 series that's building comprehensive symlink support for Windows. The thread summary shows this work has since progressed to v5 with all technical issues resolved, including performance optimizations and additional edge cases.
