This is a feature patch in the `git repo info --keys` series, adding default format support to both `git-repo-info` and `git-repo-structure` commands.

The patch introduces a `FORMAT_DEFAULT` enum value (0) to represent the default output format, which maps to `FORMAT_KEYVALUE` for `repo info` and `FORMAT_TABLE` for `repo structure`. This allows users to explicitly request the default format via `--format=default`, which is particularly useful for resetting the format after specifying a non-default one (e.g., `--format=nul --format=default`).

Key technical changes include:
- Documentation updates to show `default` as a valid format option in both commands' synopses
- Enum output_format now starts with FORMAT_DEFAULT
- Format variables initialize to FORMAT_DEFAULT rather than hardcoded defaults
- New tests verify the default format behavior and format reset capability
- Consistent implementation across both commands
