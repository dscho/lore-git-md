This is a documentation patch updating the builtin.h API comments to reflect current practices, particularly the addition of repository parameters to builtin commands. The patch comes from Derrick Stolee and is currently in its first version (v1).

The changes bring the documentation in line with the current state of the codebase, specifically addressing the `struct repository *` parameter that was added to builtin command signatures as part of the broader `the_repository` removal effort. The patch also adds documentation for the `NO_PARSEOPT` flag and improves formatting with additional newlines for readability.

Pushkar Singh has reviewed the patch and confirmed it matches the current code and test behavior, noting that the updates will help reduce confusion for new developers working on builtin commands. The patch references several test scripts (t0012, t0450, t1517) that verify builtin command compliance with documentation and behavior expectations.

This appears to be a straightforward documentation improvement that accurately reflects the current state of the codebase.
