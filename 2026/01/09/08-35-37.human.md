This is a refactoring patch from Patrick Steinhardt, part of the v9 series introducing the new `git-history` command. The patch moves core replay logic from `builtin/replay.c` into a new `replay.c` file in libgit.a, making it available for reuse by other commands (notably the upcoming `git-history`).

The changes are mechanical rather than functional - the same logic is now in a shared library with proper headers and interfaces. Key technical points:
- New `replay_revisions()` function encapsulates the commit replay logic
- Introduces `replay_revisions_options` and `replay_result` structs for configuration and output
- Removes dependency on `the_repository` global
- Cleans up sign-comparison warnings

The patch is well-structured with clear commit message and documentation. It follows the series' established patterns while preparing infrastructure for future commands. As part of a mature series that has already addressed extensive review feedback, this appears ready for inclusion.
