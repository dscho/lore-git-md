This is part of the ongoing `the_repository` removal effort, specifically targeting tree parsing functions. The patch moves the `core.maxTreeDepth` configuration from a global variable to repository-specific settings in `struct repo_settings`.

The change is mechanical but important for enabling multiple repositories with different tree depth limits to coexist in the same process. The patch:
1. Removes the global `max_allowed_tree_depth` variable and its config handling
2. Adds a new `max_allowed_tree_depth` field to `repo_settings`
3. Updates all call sites to use the repository-specific setting
4. Preserves the platform-specific default values (512 for MSVC, 1280 for Windows/ARM64/clang, 2048 otherwise)

The conversion follows the established pattern for similar refactorings in this effort. René Scharfe is a frequent contributor to this removal work, and the patch appears well-executed with thorough updates to all affected callers. This is the first of a 10-patch series focused on removing implicit repository dependencies from tree-related code.
