This is a bugfix patch addressing a memory leak in the shallow repository handling code. It's the first of two patches in a series focused on improving shallow fetch behavior.

The patch fixes a memory leak in `get_shallow_commits()` where a local `object_array` called 'stack' wasn't being freed before the function. The leak was discovered when test cases from the second patch in the series failed leak-checking CI runs (`linux-leaks` and `linux-reftable-leaks`).

The fix is straightforward - adding a single call to `object_array_clear(&stack)` before the function. The commit message notes that this was validated by the test case from the companion patch, showing good attention to test coverage. The change is small (just one line added) but important for correctness.
