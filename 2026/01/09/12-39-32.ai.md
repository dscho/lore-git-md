Refactoring patch in Patrick Steinhardt's ref verification series. This is the third patch in a 17-part effort to improve ref consistency checks across Git's backends.

The change simplifies the files backend's reference checking logic by removing the `refs_check_dir` parameter from `files_fsck_refs_dir()`, since the function always checks the full "refs/" hierarchy anyway. The parameter was effectively redundant, always being called with "refs" as its value. The patch hardcodes this path instead, reducing indirection and making the code's behavior more immediately obvious.

This continues the preparatory refactoring work from earlier patches in the series, cleaning up the files backend implementation before introducing shared verification infrastructure in later patches. The change is mechanical and doesn't affect functionality - it just removes an unused parameter that was adding unnecessary complexity.
