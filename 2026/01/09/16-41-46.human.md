Feature enhancement for `git status` showing push tracking branch status. This is the second patch in Harald Nordgren's 2-patch series that adds push tracking branch comparison to `git status` output when it differs from the upstream branch.

The patch refactors `format_tracking_info()` to handle both upstream and push tracking branches, showing their status on separate lines when they differ. The output maintains Git's existing format while adding the new push branch information. For example, when tracking `origin/main` but pushing to `origin/feature`, it will show both the divergence from `origin/main` and the ahead/behind status relative to `origin/feature`.

The implementation includes:
- A new `get_remote_push_branch()` helper to resolve the push tracking reference
- Extended `format_branch_comparison()` to handle both branch types
- Comprehensive test coverage (262 lines) verifying all edge cases
- Careful preservation of existing advice messages

The patch has gone through 18 iterations with extensive review from Phillip Wood, Ben Knoble, and Patrick Steinhardt, addressing style and implementation concerns. The final version uses enum flags for branch modes while following Git's conventions for bitmask operations. The series appears ready for merging after this thorough review process.
