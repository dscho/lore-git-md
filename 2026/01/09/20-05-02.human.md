This is part of a major platform compatibility series introducing comprehensive Windows symbolic link support (patch 5/18 in v5 series). The patch refactors symlink detection logic in the MinGW compatibility layer.

The change moves symlink (`S_IFLNK`) detection from `mingw_lstat()` into the shared `file_attr_to_st_mode()` helper function, making the logic reusable. It also adds proper `DT_LNK` detection in the Windows `readdir()` implementation, ensuring directory listings correctly identify symlinks.

The patch is well-contained, touching only the MinGW compatibility files. It's signed off by both Karsten Blees (the original author) and Johannes Schindelin (Git for Windows maintainer), indicating consensus on the approach. This is part of a mature effort that has gone through multiple iterations and is now in its final form with all technical issues resolved.

The changes are part of a larger effort to bring proper symlink support to Windows Git, building on years of work in Git for Windows. The series is now maintainer-approved and ready for integration.
