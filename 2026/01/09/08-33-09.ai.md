This is the first patch in Patrick Steinhardt's 10-part series refactoring Git's packfile storage to support pluggable object database (ODB) backends. The patch prepares for moving packfile store ownership from the ODB layer to individual ODB sources by modifying `packfile_store_new()` to be initialized via an ODB source rather than directly through the ODB.

The key change is updating the packfile store struct to track its owning source (`struct odb_source *source`) instead of the ODB (`struct object_database *odb`). This creates a transitional state where stores are still owned by the ODB but initialized via sources, which Patrick notes is "weird" but makes subsequent refactoring easier. The patch updates all affected functions to access the repository through `store->source->odb->repo` rather than `store->odb->repo`.

This foundational change touches core packfile operations like loading packs, reading object info, and preparing stores. While mechanical, it's part of a larger architectural shift that will enable alternative ODB backends. The patch series has already undergone multiple rounds of review, with Justin Tobler and Toon Claes providing feedback on earlier versions. This v3 iteration appears ready for inclusion as part of the broader ODB abstraction effort.
