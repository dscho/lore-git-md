This is a refactoring patch that prepares for showing push remote tracking branch comparisons in `git status`. It's the first of a 2-patch series from Harald Nordgren that has gone through 18 iterations of review.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This modularization will allow the upcoming second patch to reuse this logic for push remote comparisons while maintaining consistent output formatting.

Key changes:
- Moves the core comparison message generation into a standalone function
- Preserves all existing behavior including quick mode (AHEAD_BEHIND_QUICK) handling
- Improves parameter naming (`sti` -> `up_to_date`) per Phillip Wood's review
- Maintains the same control flow and edge case handling
- Keeps the same advice messages and translation strings
