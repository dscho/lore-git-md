This is the first patch in a 2-part series that enhances `git status` to show divergence from both upstream and push tracking branches. The patch refactors the branch comparison formatting logic in preparation for the new feature.

The patch extracts the branch comparison formatting code from `format_tracking_info()` into a new `format_branch_comparison()` function. Key changes include:

1. Separating the message formatting logic from the upstream tracking branch resolution
2. Converting the `sti` parameter to a clearer `up_to_date` boolean
3. Moving the "upstream is gone" case to the caller
4. Maintaining all existing behavior while making the code more modular

The refactoring preserves the original control flow that handles various branch states (up-to-date, ahead, behind, diverged) and quick mode (AHEAD_BEHIND_QUICK) special cases. The changes follow Git's coding style and have been thoroughly reviewed across 19 iterations, with feedback from Junio C Hamano, Phillip Wood, and others incorporated.

This is a well-crafted preparatory patch that cleanly separates concerns while maintaining all existing functionality. The extensive review history suggests it's ready for merging as part of the larger tracking-info enhancement effort.
