This is the third and final patch in a series by Olamide Caleb Bello (an Outreachy intern mentored by Christian Couder) that moves configuration variables from global scope into `struct repo_config_values` as part of the ongoing `the_repository` removal effort. The patch migrates the `branch.autoSetupMerge` configuration, which controls whether new branches are automatically set up to merge with their upstream counterparts.

The change removes the global `git_branch_track` variable and replaces all its references with accesses through `the_repository->config_values.git_branch_track`. The patch updates several commands that use this setting, including `git branch`, `git checkout`, `git push`, and submodule operations. The initialization sequence ensures the default value (BRANCH_TRACK_REMOTE) is preserved.

This completes the series that also migrated `core.attributesFile` and `core.sparseCheckout` in previous patches. The work follows Phillip Wood's suggestion to use a dedicated config struct rather than overloading `repo-settings`. While some architectural questions about config scoping remain open, this implementation appears ready for merging as it cleanly handles the technical migration while maintaining existing behavior.
