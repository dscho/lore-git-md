This is part 2 of a 3-patch series by Olamide Caleb Bello (an Outreachy intern mentored by Christian Couder) that migrates repository-specific configuration variables out of global scope as part of the ongoing `the_repository` removal effort. The series introduces `struct repo_config_values` to store these variables per-repository.

This specific patch moves the `core.sparseCheckout` configuration from a global variable into the new per-repository struct. The change affects 12 files across various commands that interact with sparse checkout functionality (`sparse-checkout`, `clone`, `grep`, `mv`, etc.). The patch maintains existing behavior while ensuring the setting is properly scoped.

The implementation follows Phillip Wood's suggestion to use a dedicated config struct rather than overloading `repo-settings`. The change is mechanical but touches several sensitive areas of the codebase, particularly around sparse checkout operations. The patch appears well-tested, with all call sites updated consistently.

This is part of a larger pattern being established for migrating repository-dependent configs out of global scope. While some architectural questions remain open (notably around config scoping rules), this patch represents solid incremental progress on the `the_repository` removal effort.
