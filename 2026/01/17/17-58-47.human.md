Test fix addressing a subtle issue in t2203-add-intent.sh where exit codes from `git status` were being masked by grep pipelines. The original tests used patterns like `git status | grep -v` which would return 0 (success) even if `git status` failed, potentially hiding crashes.

Tian Yuchen's patch modifies these tests to first capture the status output to a temporary file, then filter it through grep. This ensures any failure in `git status` will be properly detected. The patch also updates one grep pattern to exclude the temporary file itself from the output comparison.

The changes are mechanical but important for test reliability - they make sure the tests that verify status output will actually fail if the status command itself fails. The patch is focused and well-explained, with a clear commit message describing both the problem and solution.
