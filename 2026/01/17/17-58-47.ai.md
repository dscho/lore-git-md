This is a test fix addressing a subtle issue in test t2203-add-intent.sh. The patch fixes cases where the test was masking the exit code of `git status` commands by piping them through `grep -v`. This could allow tests to pass incorrectly if `git status` crashed, since the grep would still succeed with exit code 0.

The changes modify the test to first write the `git status` output to a temporary file, then filter it through grep, ensuring any failure in `git status` itself will be caught. The patch also updates one grep pattern to additionally exclude the temporary file name from the output to maintain the expected test output.

The fix is straightforward and clearly motivated - it improves test reliability by properly checking command exit codes. The changes are mechanical but important for catching potential regressions. The patch follows Git's testing conventions and includes updates for all three porcelain formats (default, --porcelain, and --porcelain=v2) used in the test.
