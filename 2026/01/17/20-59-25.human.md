This is part of the ongoing `the_repository` removal effort, specifically moving repository-specific configuration variables out of global scope. The 3-patch series from Olamide Caleb Bello (an Outreachy intern mentored by Christian Couder) introduces a new `struct repo_config_values` to store config values that should be repository-scoped rather than global.

The series migrates three key configuration variables: `core.attributesFile`, `core.sparseCheckout`, and `branch.autoSetupMerge`. The changes affect over 20 files across the codebase, with careful attention to maintaining existing behavior while enabling proper repository isolation. The implementation embeds the config struct directly in `struct repository` to avoid heap allocation.

The cover letter notes this approach was suggested by Phillip Wood after earlier discussions about initialization timing and lazy-loading concerns. The intern is seeking final feedback before proceeding with more migrations, indicating the series serves as both a technical migration and a test case for the project's broader approach to eliminating global state.
