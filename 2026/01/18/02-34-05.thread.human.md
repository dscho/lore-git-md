Derrick Stolee has proposed adding a `--maximal-only` option to `git rev-list` that filters commits to show only those not reachable from others in the specified range - essentially identifying the "frontier" of a commit graph. This feature is particularly useful for bundle URIs and reachability optimizations.

After some initial discussion about naming (settling on `--maximal-only` rather than just `--maximal`), the patch has reached a mature state with thorough test coverage and clear documentation of its behavior and limitations (notably its incompatibility with `--boundary`). The implementation uses bit 28 of the object flags, raising some minor concerns about long-term flag bit availability, but this was deemed an acceptable tradeoff.

Junio Hamano and Johannes Sixt have both engaged with the proposal, helping shape the interface and confirming the mathematical properties. With all feedback addressed in this second iteration, the patch appears ready for maintainer consideration. The only remaining items are minor documentation tweaks and potential follow-up optimizations for the bundle URI use case.
