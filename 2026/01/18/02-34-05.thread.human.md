Derrick Stolee has proposed adding a new `--maximal` option to `git rev-list` that filters output to show only commits not reachable from others in the specified range. This could be particularly useful for selecting minimal reference points when creating bundle URIs or optimizing reachability bitmaps.

The implementation introduces a new `CHILD_VISITED` flag (bit 28) to track reachability during walks, pushing Git's object flag space usage to 29 of 32 available bits. While Stolee acknowledges the tight flag space, he argues the feature's utility justifies the allocation. The patch includes comprehensive tests covering various commit ranges and walk modifiers like `--first-parent`.

The implementation appears solid and well-tested, though the flag bit usage may prompt discussion given Git's limited remaining flag space. This could be particularly relevant for large repository optimizations and bundle operations where identifying maximal commits is valuable.
