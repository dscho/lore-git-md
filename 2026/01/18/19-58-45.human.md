This is a follow-up from Harald Nordgren on the ongoing effort to enhance `git status` with push tracking branch information. The patch implements Junio Hamano's suggestion for a configurable `status.compareBranches` setting that allows users to specify which branches to compare against (defaulting to just `@{upstream}`).

The key development here is the implementation of the configuration framework that was previously discussed, giving users control over whether to see both upstream and push comparisons in status output. However, Harald notes there appears to be a memory leak in the current implementation that he hasn't been able to resolve despite extensive testing.

This continues the thread's progression from core functionality to configuration design, now addressing the specific technical challenge of memory management in the new feature. The implementation appears to be nearing completion, with this being one of the final technical hurdles before the feature could be considered ready for merging. The memory leak issue suggests this may need another revision before being picked up by Junio.
