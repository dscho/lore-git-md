This is a refactoring patch in Harald Nordgren's ongoing series to make `git status` branch comparisons configurable. It's part 1/2 of v26, building on previous iterations that implemented Junio Hamano's proposed `status.compareBranches` configuration.

The patch extracts the core comparison logic from `format_tracking_info()` into a new `format_branch_comparison()` function, keeping the same behavior but making the code more modular. This prepares for upcoming changes that will support showing comparisons with push remote tracking branches in addition to the current upstream branch tracking.

Key changes:
- Moves the detailed comparison message generation into a separate function
- Maintains all existing functionality (up-to-date, ahead/behind, divergence messages)
- Preserves the advice hints and pluralization handling
- Keeps the same parameter structure for now, though this will likely evolve in part 2/2

The refactoring appears clean and focused, with thorough test coverage already established in previous iterations. This is a preparatory step for the more substantive changes coming in the next patch of the series.
