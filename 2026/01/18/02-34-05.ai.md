This is a feature patch from Derrick Stolee adding a new `--maximal` option to `git rev-list`. The option filters the output to only show commits that are not reachable from any other commit in the specified range, which could be useful for selecting a minimal set of reference points (like when creating bundle URIs).

The implementation adds a new `CHILD_VISITED` flag (bit 28) to track reachability during the walk, extending Git's object flag space to 29 bits. The patch includes thorough tests demonstrating behavior with various commit ranges and walk modifiers like `--first-parent`. 

Stolee acknowledges the flag bit allocation is tight (now using 28 of 32 available bits) but argues the feature's utility justifies it. The commit message suggests potential applications beyond bundle URIs, such as reachability bitmap optimization. The implementation appears clean and well-tested, though the flag bit concern may warrant discussion given Git's limited remaining flag space.
