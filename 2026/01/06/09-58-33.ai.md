This is a bugfix discussion about the `git last-modified` command's behavior in bare repositories, specifically regarding path handling and error messaging. The thread has two distinct issues:

1. A resolved crash when processing refspec paths (fixed in commit 05491b90ce on master)
2. An ongoing discussion about suboptimal error messaging when paths are missing

Patrick Steinhardt confirms that the memory safety issue (which caused crashes with refspec paths like HEAD:LICENSES) has been fixed in master. Gusted verifies the fix works in their Forgejo integration context. The remaining open question is whether this fix will be backported to the upcoming v2.52.1 maintenance release, which Patrick CC'ing Junio Hamano to consider.

The error messaging issue (where Git shows "unknown revision or path" even when `--` disambiguates it as a path) remains open for future discussion. This thread now primarily serves to track the backport decision, with the technical solution for the crash already implemented and verified.
