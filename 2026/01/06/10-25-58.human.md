Performance fix for `git cat-file` bitmap usage.

Jeff King (Peff) identifies and fixes a performance regression in `git cat-file` introduced by commit 8002e8ee18, which made the command always use bitmaps even when not filtering objects. The patch shows that this causes significant slowdowns (up to 331%) when listing all objects without filtering, while bitmap usage remains beneficial for filtered cases (like listing only blobs, which sees a 65% speedup).

The fix is straightforward: only prepare and use bitmaps when there's an active object filter. The patch includes new performance tests that clearly demonstrate the regression and its fix. The changes are minimal - just adding a condition to check for filters before using bitmaps - but have a dramatic impact on performance for unfiltered operations.

This is a classic Peff patch: precise, well-measured, and addressing a real performance issue with minimal code changes. The commit message provides thorough analysis and benchmarking, making the tradeoffs clear. The fix maintains the bitmap optimization where it helps while avoiding the overhead where it doesn't.
