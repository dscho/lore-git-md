This is a feature patch improving the interactive `git add -p` interface, now in its fifth iteration as part of a GSoC project. The patch adds visual feedback showing whether each hunk was previously marked for use ('y') or skip ('n') when navigating between hunks in all patch modes (stage, stash, reset, checkout).

The implementation tracks hunk decision state in `add-patch.c` and inserts "(previous decision: use/skip)" indicators into the prompts. The patch has been thoroughly reviewed through multiple versions, with v5 addressing the last remaining issue (a doubled "Reported-by" line) after earlier versions fixed prompt consistency, a memory leak, and an uninitialized variable. 

With comprehensive test coverage in `t3701-add-interactive.sh` and all technical concerns resolved, this appears ready for merging. The change is focused and well-contained, providing clear UX benefits for interactive patch selection without altering core functionality.
