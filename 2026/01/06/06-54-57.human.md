This is the first patch in Patrick Steinhardt's v3 series improving Git's object info handling, part of the ongoing ODB (object database) abstraction effort. The patch fixes a subtle inconsistency in `odb_source_loose_read_object_info()` where early returns weren't properly setting the `OI_LOOSE` flag in the object_info struct, even though the object was indeed loose.

The change ensures callers can reliably determine an object's storage type by making `whence` always reflect the actual state on success. While no current callers depend on this, the patch prevents future bugs by making the behavior consistent. The implementation carefully handles all early return paths while maintaining the existing quick-check optimization for size-only queries.

This is a straightforward cleanup that fits into the series' broader goals of standardizing object info handling and preparing for future ODB backend work. The patch shows Patrick's characteristic attention to detail in catching edge cases that could cause problems down the line.
