This is a cover letter for a two-patch series addressing performance test infrastructure issues. The patches come from Jeff King (Peff), a long-time contributor known for precise fixes and test infrastructure work.

The series fixes two problems in Git's performance test framework (`t/perf`):

1. The first patch corrects how `TEST_OUTPUT_DIRECTORY` is assigned in the performance test library, fixing a likely bug in directory handling.

2. The second ensures that environment variables prefixed with `GIT_PERF_` are properly preserved when running performance tests, which is important for consistent test execution when comparing Git versions.

The changes are small (12 lines total) but important for anyone using the performance test suite to compare Git versions. As expected from Peff, the patches are focused and well-motivated, though the cover letter doesn't elaborate on the specific symptoms these fixes address. The changes touch core test plumbing rather than user-facing behavior.
