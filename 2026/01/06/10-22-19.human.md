Bugfix for `git diff --relative` path handling. The maintainer Junio C Hamano confirms Johannes Sixt's report that `--relative` incorrectly treats its argument as a text prefix rather than a directory path, causing nonsensical output like "kefile" when given "Ma" as input. Junio speculates about what the correct behavior should be (likely producing "../Makefile" if "Ma" were a directory) but does not yet propose a fix. This appears to be a clear bug in path handling that needs addressing, though the thread is still in its early stages with just the initial report and maintainer confirmation. Given Junio's involvement, this will likely see prompt attention.
