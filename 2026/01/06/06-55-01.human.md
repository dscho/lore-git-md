Refactoring patch in Patrick Steinhardt's ODB abstraction series. This is patch 5/7 in the v3 iteration, focusing on simplifying the return value semantics of `packed_object_info()`.

The patch changes `packed_object_info()` to return a simple success/failure code (0/-1) rather than mixing object type information with error conditions. This cleanup is possible because the last caller that relied on the object type return value was removed in the previous patch. The change allows skipping object type reads in some cases and makes the function's behavior more straightforward.

The modifications touch both `packfile.c` and `packfile.h`, updating the implementation and adding clarifying documentation. All error cases that previously returned `OBJ_BAD` now return -1 consistently. The patch maintains the same functionality while making the code more maintainable as part of the larger ODB abstraction effort.

This continues the series' quality standard with clean, focused changes that improve internal consistency without introducing new behavior. The patch has no user-visible impact but helps pave the way for future ODB backend work.
