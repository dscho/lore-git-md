Thread summary:

Performance regression and fix for `git cat-file` bitmap usage. The thread addresses a significant performance degradation in `git cat-file` introduced by commit 8002e8ee18, where bitmap indexes were unnecessarily loaded even for non-filtered operations. Jeff King (Peff) provides the patch and detailed performance analysis showing a 331% slowdown when listing all objects in sorted order, while confirming bitmap optimizations remain beneficial for filtered cases (65% speedup for blob listing).

The fix modifies `builtin/cat-file.c` to only prepare bitmaps when `opt->objects_filter.choice` indicates an active filter, avoiding unnecessary bitmap loading and sorting operations. The patch includes new performance tests covering three scenarios: sorted object listing (the regressed case), unsorted listing, and filtered listing. Key technical changes involve conditional bitmap loading on filter state, maintaining optimizations for filtered cases while restoring original performance for unfiltered operations.

This is a focused performance fix from a trusted contributor (Jeff King) with clear benchmark evidence demonstrating both the regression and resolution. The patch maintains existing functionality while addressing a clear performance issue in the bitmap handling logic.
