Performance optimization in Patrick Steinhardt's ODB abstraction series. This is patch 6/7 in the v3 iteration, building on previous changes to object info handling.

The patch optimizes `packed_object_info()` by skipping header unpacking when only the disk size is requested, since this information is available without parsing the object contents. Benchmark results show a 9% speedup in `git rev-list --disk-usage` operations, with mean time dropping from 105.2ms to 96.7ms in the test case.

The change introduces a new `OBJ_NONE` case to handle objects where only size was requested, maintaining the previous behavior for all other cases. The implementation is minimal - just 5 lines added and 2 changed in `packfile.c` - but provides measurable performance benefits for disk usage calculations. This continues the series' pattern of focused, well-measured improvements to the object storage layer.

The patch fits cleanly into the ongoing ODB abstraction work by further separating the concerns of reading object metadata versus content. It maintains all existing interfaces while optimizing a common case, and includes clear benchmark evidence of the improvement. The change is low-risk as it only affects the packed object info path when specifically querying disk size.
