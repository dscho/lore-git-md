Performance optimization and interface cleanup for object info handling. This is the third version of Patrick Steinhardt's 7-patch series that refactors how Git reads object metadata from packs, building on prior review feedback. The changes focus on both immediate performance gains and long-term interface improvements for the ongoing ODB (object database) abstraction work.

The series delivers measurable speedups - about 9% faster `git rev-list --disk-usage` by avoiding unnecessary header unpacking for size-only requests. It also simplifies the object info interface by standardizing return values, removing the OI_DBCACHED flag distinction (now all pack objects report OI_PACKED), and eliminating a redundant repository parameter. The v3 iteration incorporates minor documentation fixes from Kristoffer Haugsbakk and Toon Claes while maintaining the core technical improvements.

Notable changes in this version include fixing a commit message ("inconsistecny" typo), clarifying a function comment, and rebasing on master. The series has already received positive review attention, with Toon Claes confirming the OI_DBCACHED removal and Patrick explaining the rationale for tracking delta types (ref-delta vs ofs-delta) even though current callers don't yet use the distinction. This work lays groundwork for future `odb_for_each_object()` functionality while delivering immediate benefits.
