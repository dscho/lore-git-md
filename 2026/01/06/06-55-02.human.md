This is patch 6/7 in Patrick Steinhardt's series refactoring Git's object info handling as part of the ODB (object database) abstraction effort. The patch optimizes disk size calculations by skipping unnecessary object header unpacking when only the disk size is requested.

The change provides a measurable 9% speedup for `git rev-list --disk-usage`, as shown in the included benchmark. The optimization works because disk size can be determined from the packfile index alone, without needing to examine the object contents. The patch modifies `packfile.c` to add this special case handling while maintaining all existing functionality.

This continues the series' pattern of clean, well-motivated improvements to the object storage layer. The change is small (7 lines modified) and focused, touching only the packed object info path. It builds on the earlier patches' work to simplify return values and delta tracking, demonstrating the series' cumulative benefits.

For readers following the ODB abstraction work, this patch shows how the refactoring enables targeted optimizations.
