This is a follow-up discussion about backporting a bugfix for the `git last-modified` command. The original issue involved a memory safety bug that caused crashes when processing refspec paths (like `HEAD:LICENSES`), which was fixed in commit 05491b90ce ("last-modified: support sparse checkouts") on the master branch. Gusted, who reported the bug, confirms the fix works in their Forgejo integration.

Patrick Steinhardt has now CC'd Junio Hamano to consider backporting this fix to the v2.52.1 maintenance release. Kristoffer Haugsbakk notes that the release notes already indicate this fix is slated for merging into the maintenance branch (which currently points to v2.52.0). The discussion remains open on whether to include it in v2.52.1 specifically, with Junio's input now formally sought.

While the memory safety issue is resolved, there's a separate open discussion about improving error messaging when paths are missing - currently showing "unknown revision or path" even when `--` disambiguates it as a path issue. That UX improvement is being tracked separately from this backport request.
