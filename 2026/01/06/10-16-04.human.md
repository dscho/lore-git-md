Performance test infrastructure fix by Jeff King (Peff), part 2/2 in a series addressing issues in the `t/perf/run` script. This patch fixes a regression where `GIT_PERF_*` environment variables were being clobbered when running performance tests through the `run` helper script.

The issue stems from how `GIT-BUILD-OPTIONS` loading overwrites environment variables, which became problematic after 5756ccd181 made the `run` script load these options. The patch applies the same workaround used in `perf-lib.sh` - preserving the environment variables before loading `GIT-BUILD-OPTIONS` and restoring them afterward. While Jeff acknowledges this is an "ugly hack", it maintains consistency with the existing solution and fixes the immediate problem.

The change is small (10 lines added) but important for anyone using the performance test framework with custom repositories or configurations. The patch includes a thorough commit message explaining the history of the issue and why this solution was chosen. As with the first patch in the series, this comes from a test infrastructure expert and addresses a real pain point in the performance testing workflow.
