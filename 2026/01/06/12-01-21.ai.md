This is a feature patch improving the interactive hunk selection interface in `git add -p`. The patch adds visual feedback showing whether each hunk was previously marked for use ('y') or skip ('n') when navigating between hunks.

The change modifies the prompt strings in `add-patch.c` to include a new placeholder for the decision status, then adds logic to populate it with either " (previous decision: use)" or " (previous decision: skip)" based on the hunk's state. The patch updates all prompt strings consistently across the various patch modes (stage, stash, unstage, etc.) and includes corresponding test updates.

This is the sixth iteration of the patch (v6), with only minor changes from previous versions (fixing a duplicate Reported-by` tag). The implementation touches both core functionality in `add-patch.c` and the test suite in `t3701-add-interactive.sh`.

The changes are focused and well-contained, modifying only the prompt display without altering the underlying hunk selection logic.
