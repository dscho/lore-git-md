This is patch 3/7 in Patrick Steinhardt's series refactoring Git's object info handling, part of the ongoing ODB (object database) abstraction effort. The patch extends the `is_delta` field in `struct object_info` from a simple boolean to a four-state enum that can distinguish between full objects, ref deltas, offset deltas, and an "unknown" state.

The change prepares for a future optimization where Git can skip parsing object data when only metadata (like size) is requested. Currently the code always knows whether an object is a delta, but with that optimization there will be cases where it doesn't - hence the need for an "unknown" state. The patch also distinguishes between ref and offset deltas, which isn't used by current callers but provides future-proofing for when the ODB interface abstracts away packfile implementation details.

The implementation touches `odb.h` (adding the enum) and `packfile.c` (updating the delta checks). While this is mostly preparatory work, it's a meaningful step toward separating the ODB interface from packfile-specific details. The patch maintains all existing functionality while enabling future improvements.
