This is the second patch of Patrick Steinhardt's 17-part refactoring series to centralize ref backend validation. It focuses on the files backend's fsck functionality.

The patch simplifies the ref verification code by moving the array of fsck callback functions (`files_fsck_refs_name` and `files_fsck_refs_content`) from local scope into file scope. Previously these functions were passed down through the call stack as parameters, despite never changing. The change eliminates this unnecessary indirection while maintaining identical behavior.

This is a straightforward refactoring that improves code organization in preparation for the series' later work to share validation logic between the files and reftable backends. The patch demonstrates the series' careful attention to cleaning up the refs subsystem before introducing new functionality. As with the first patch, this change is mechanical and low-risk, focused on establishing better foundations for the validation improvements to come.
