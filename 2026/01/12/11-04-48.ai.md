Oswald Buddenhagen responds to Krzysztof Zabłocki's proposal for a `.gittemplates` configuration that would index but not track changes to certain files. The exchange suggests this is a recurring idea in the community, with multiple contributors independently proposing solutions for the workflow pain point of maintaining template files (like `.env` or machine-specific configs) where users want to commit a base version but ignore local modifications. The thread appears to be in early stages of exploring whether this functionality is needed and whether existing mechanisms could address the use case.
