New thread summary:

This thread proposes a new Git configuration mechanism for template files, where files listed in a `.gittemplates` file (or equivalent config) would be indexed but their changes not tracked. The goal is to allow committing template versions of files like `.env` or machine-specific configs while permitting local modifications without those changes being committed. The author suggests this would solve the common workflow pain point of maintaining two versions of such files (a committed under different name and a local ignored version), particularly for pipeline configurations and personalized setups. The proposal is currently at the idea stage with no implementation details or code changes provided. Key open questions include whether this functionality could be achieved through existing mechanisms like `--assume-unchanged` or `--skip-worktree`, and what concrete use cases would most benefit from this feature. The thread begins as a design discussion seeking feedback on the concept before potential implementation work.
