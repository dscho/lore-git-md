This is a two-patch series addressing an issue with MIDX (multi-pack-index) handling when encountering corrupt checksums. The series comes from Taylor Blau, who is a key contributor to Git's pack and MIDX subsystems.

The first patch removes an early `test_done` in the MIDX test script that was accidentally masking a test failure. This exposes a bug where Git fails to detect when a MIDX with an invalid checksum needs to be rewritten. The second patch fixes this by making `midx-write.c` always treat MIDX files with invalid checksums as requiring an update, even when using `--stdin-packs`.

The series is split out from a larger MIDX compaction effort to ensure the fix makes it into the upcoming v2.53.0 release if the main series isn't ready in time. The changes are focused and well-explained, with clear commit messages linking the test changes to the behavioral fix. The patch touches core MIDX writing logic but the change is straightforward - when a MIDX is corrupt, we should always rewrite it rather than potentially skipping the update.
