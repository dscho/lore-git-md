This is the final patch in Patrick Steinhardt's v5 series refactoring Git's object info handling as part of the ODB abstraction effort. The patch removes the OI_DBCACHED state from the object_info struct since all packfile objects are now consistently handled as OI_PACKED, simplifying the interface. 

The change incidentally fixes a segfault in `git archive` that occurred when streaming deltified blobs exceeding core.bigFileThreshold - the bug manifested when the code incorrectly assumed OI_DBCACHED objects were non-deltified and tried to read from an uninitialized packed_git pointer. The patch adds a regression test to prevent future regressions.

Junio Hamano gives final approval ("Great. Thanks. Will requeue."), indicating this reviewed and tested series is ready for integration. The patch completes the series' goals of simplifying object info handling while improving correctness and maintainability, with the added benefit of fixing a real-world crash scenario.
