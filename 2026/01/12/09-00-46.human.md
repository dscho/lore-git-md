Performance optimization in the ODB abstraction series. This is patch 6/7 in Patrick Steinhardt's v5 series refactoring Git's object info handling, which has now received final approval from Karthik Nayak and addresses all prior feedback.

The patch optimizes disk size lookups for packed objects by skipping unnecessary header parsing when only the disk size is requested. Benchmark results demonstrate a 9% speedup in `git rev-list --disk-usage` operations. The change is straightforward - it modifies `packfile.c` to only unpack object headers when actually needed (for size, type, or delta base requests) rather than doing so unconditionally.

This is part of the larger ODB abstraction effort that has been thoroughly reviewed across multiple iterations. The series as a whole improves object handling with more precise delta tracking, consistent field initialization, and simplified interfaces. With all feedback addressed and regression tests added, this particular optimization is ready for integration.
