This is the final patch in Patrick Steinhardt's v5 series refactoring Git's object info handling as part of the ODB abstraction effort. The patch removes a redundant `repository` parameter from `packed_object_info()` since the same information is already available in the `packed_git` struct that's passed in.

The change is mechanical but meaningful - it eliminates duplicate repository tracking and simplifies the interface. The patch updates all callers (in cat-file, pack-objects, commit-graph, and packfile internals) to use the new signature. This builds on earlier work in the series that standardized how object info is handled across different storage backends.

The series has already received thorough review from Karthik Nayak and addresses all prior concerns. This final patch completes the interface cleanup started earlier in the series. With this change, the object info handling is now more consistent and better prepared for future ODB backend work. The series is ready for integration.
