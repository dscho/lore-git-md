This is part 8 of an 11-patch series implementing URL-encoded gitdir paths for submodules to prevent filesystem collisions. The series introduces a new `extensions.submodulePathConfig` extension that enables this behavior.

The patch specifically adds URL encoding for submodule gitdir paths when the extension is enabled, fixing cases where nested submodule names would otherwise cause filesystem conflicts. It implements a three-step fallback: first trying the plain module name, then falling back to URL-encoded names if that fails, and finally erroring out if neither works.

Key technical changes:
- New URL encoding of gitdir paths using `strbuf_addstr_urlencode()`
- Split validation logic into encoded vs legacy variants
- Added tests verifying nested submodule handling
- Confirmed working with parallel cloning (`--jobs=2`)

The patch builds on design input from Junio Hamano and Patrick Steinhardt, and follows the series' approach of only applying encoding when needed for new submodules. It's part of a well-reviewed series that has already received Junio's merge approval, with this version addressing all remaining feedback.
