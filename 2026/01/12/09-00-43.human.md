Part of Patrick Steinhardt's ODB abstraction effort, this patch refactors how Git tracks delta information for packed objects. It replaces a simple boolean `is_delta` field with a more expressive enum that can represent four states: unknown, full object, offset delta, or reference delta. 

The change prepares for a future fix where Git will need to handle cases where it can't determine an object's delta status (when skipping object parsing for performance). The patch maintains all existing behavior while making the type tracking more precise. It's the third in a v5 series that has already received thorough review from Karthik Nayak and addresses all prior feedback.

This is a well-motivated internal refactoring that improves type safety and sets up for future changes. The series as a whole shows careful attention to edge cases and performance, with this particular patch being a straightforward but meaningful improvement to the object storage internals.
