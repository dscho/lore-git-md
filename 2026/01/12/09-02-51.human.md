Refactoring patch in Patrick Steinhardt's ref backend validation series (2/17). This change moves the fsck verification function array from being passed down through call stacks to a static global variable in `refs/files-backend.c`. The patch eliminates redundant parameter passing since the function set never changes, simplifying the code while maintaining identical behavior.

This is part of a larger effort to unify validation between the files and reftable backends. The change demonstrates the series' attention to cleaning up implementation details - here removing unnecessary indirection that could confuse future maintainers. The patch follows cleanly from the first in the series (which fixed root ref handling) and precedes the introduction of shared validation functions that will work across both backends.
