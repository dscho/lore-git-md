This is a refactoring patch in Patrick Steinhardt's series to unify ref backend validation. It removes unused fields from `struct fsck_ref_report` that were intended for richer error reporting but never actually populated. The patch is straightforward - it deletes the `oid` and `referent` fields along with their unused display logic in the error formatter. This cleanup helps simplify the fsck infrastructure as part of the larger effort to standardize validation across ref backends. The change is mechanical and low-risk, with no behavior changes since the fields weren't being used anyway. 

This continues the pattern of incremental improvements seen in earlier patches of the series, where each change carefully prepares the codebase for the eventual introduction of shared validation functions. The patch maintains the series' high quality standard with a clear commit message and focused scope.
