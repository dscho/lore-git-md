This is a bugfix for the `git last-modified` command, which was crashing when given a tree OID instead of a commit. The patch comes from Toon Claes and addresses two issues:

1. The command would hit a BUG() assertion when processing tree objects, as reported by Gusted. The fix adds validation to ensure the input is a commit-ish (something that can be peeled to a commit).

2. It plugs a memory leak in `populate_paths_from_revs()` that was found during the fix.

The changes are straightforward - the commit message clearly explains the problem and solution, and includes a new test case to verify the fix. The patch touches both the command implementation and its test suite, with clean diffs that show the validation check being added alongside proper error handling.

This appears to be a well-contained fix for a clear bug. The addition of the test case is particularly good practice, ensuring this edge case won't regress. The patch is small and focused, exactly what you'd want for fixing a specific issue like this.
