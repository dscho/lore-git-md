This is the final version of Harald Nordgren's feature series enhancing `git status` to show divergence from both upstream and push tracking branches, now approved for merging into `next`. The v23 iteration addresses the last remaining discussion points from the extensive review process.

The core functionality remains unchanged from v22 - it still adds push tracking information while maintaining all existing behavior. The key change in this version is adjusting the divergence advice display logic. Phillip Wood had suggested showing advice for both upstream and push branches when they diverge, while Harald initially preferred showing it only for upstream. The v23 patch now makes the advice display consistent by removing the BRANCH_MODE_PULL check from the divergence advice condition, allowing it to show for both tracking branches when enabled.

The implementation handles all edge cases discussed in previous rounds:
- Maintains quick mode (`--no-ahead-behind`) behavior
- Preserves output format with push info on new line
- Works with remapped push refspecs
- Includes comprehensive test coverage in t6040-tracking-info.sh

With Junio's approval and all major technical concerns addressed, this represents the culmination of a 23-iteration review process that refined both the implementation and user experience. The remaining minor questions about `push.default` interaction can be handled in follow-up patches if needed, as they don't block the core functionality.
