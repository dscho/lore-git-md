Test modernization patch introducing a helper function for post-checkout hook testing in t5403. This is the first of two patches in a series that has already been merged.

The patch creates a new `check_post_checkout` helper function that consolidates the validation of post-checkout hook arguments (old ref, new ref, and branch-switch flag) which was previously repeated across multiple test cases. The helper follows Git's test infrastructure conventions by including a BUG check for argument count and combining the three separate validations into one call.

While this first version doesn't yet include the full documentation that will come in the second patch, it already improves maintainability by:
- Eliminating duplicate validation code
- Using `git rev-parse` directly in the test calls rather than storing intermediate values
- Maintaining the exact same assertions as the original tests

The changes are purely structural - no test behavior is modified. The patch touches only t/t5403-post-checkout-hook.sh, converting all test cases that verify hook arguments to use the new helper. This is part of Git's broader test modernization effort to replace repetitive patterns with documented helper functions.
