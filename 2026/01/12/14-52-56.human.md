This is a refactoring patch in Patrick Steinhardt's ongoing series to support pluggable object database backends. The patch cleans up the `unuse_one_window()` function in packfile.c, which handles memory management for mmap'd packfile windows.

Karthik Nayak provides a review confirming the change makes sense, noting the original code was misleading since it appeared to handle NULL packfile pointers but in practice never received them. The patch simplifies the function to take the object database directly rather than a packfile, making the code's intent clearer.

The change is part of a larger architectural shift to move packfile store ownership from the ODB layer to individual ODB sources. This particular patch is a small but meaningful cleanup that removes historical cruft while maintaining the same behavior. The review discussion indicates the change is straightforward and uncontroversial, with Karthik validating Patrick's analysis of the code history.
