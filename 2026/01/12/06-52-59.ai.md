This is a test modernization series for the post-checkout hook testing in t5403, building on a recently merged cleanup patch. The two patches aim to improve maintainability and diagnostics by introducing a helper function and standardizing test patterns.

The first patch introduces a `check_post_checkout` helper function to consolidate the validation patterns for post-checkout hook arguments. This refactoring doesn't change test behavior but makes the code more maintainable by eliminating duplication. The second patch further improves the helper by using `test_cmp` for argument validation instead of individual test commands, which provides clearer error messages when tests fail.

The series follows up on review feedback from Eric Sunshine and Pushkar Singh, who previously suggested improving documentation and hook output format. The changeset focuses exclusively on the test script t/t5403-post-checkout-hook.sh, keeping the same test coverage while making the code more robust and easier to maintain. This aligns with the broader project effort to modernize tests by using standardized patterns and documented helpers from test-lib-functions.sh.

Key technical details include the helper function's role in validating hook arguments (old ref, new ref, and flag indicating branch switch status) and the switch to `test_cmp` for better failure diagnostics. The changes are purely about test infrastructure - no functional changes to Git itself are involved.
