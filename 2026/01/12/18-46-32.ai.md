Feature: Final patch in the submodule gitdir path encoding series, adding conflict detection with existing gitdir configurations.

This is the concluding patch in Adrian Ratiu's 11-part series implementing path encoding for submodule gitdirs to prevent filesystem conflicts. The series has evolved through multiple iterations with extensive review feedback incorporated, and this final version includes a hashing fallback mechanism for unresolvable path conflicts.

The specific change here addresses a corner case where conflicts with existing gitdir configurations could silently pass validation only to fail later with cryptic errors. The patch adds validation that checks for these conflicts upfront, ensuring proper error messages. It introduces a new config callback `find_conflict_by_gitdir_cb` that detects when a new submodule's path would conflict with an existing gitdir configuration.

The implementation handles the case where a submodule named "nested/sub" (stored as "nested%2fsub") would conflict with a new submodule literally named "nested%2fsub". The test case demonstrates this scenario, showing how the system now properly encodes the conflicting name as "nested%252fsub" instead.

This completes the series' goal of handling all known edge cases for filesystem compatibility while maintaining the existing submodule path encoding architecture.
