This is the fifth version of Patrick Steinhardt's series improving object info handling as part of the ODB abstraction effort. The series has already received final approval from Karthik Nayak (GitLab ODB team) in v4, with all feedback addressed. The v5 iteration adds a regression test for a segfault in `git archive` when handling deltified blobs larger than core.bigFileThreshold, which the series incidentally fixes.

The 7-patch series refactors object info reading with several key improvements:
1. Ensures consistent OI_LOOSE flag setting in loose object handling
2. Simplifies the interface by removing OI_DBCACHED distinction (all packfile objects now OI_PACKED)
3. Introduces precise delta type tracking with a 4-state enum
4. Guarantees pack field population in packed_object_info()
5. Simplifies packed_object_info() return to success/failure only
6. Optimizes disk size lookups (9% speedup) by skipping header parsing
7. Removes redundant repository parameter from packed_object_info()

The changes touch core object handling code in object-file.c, packfile.c, and related headers, with impacts on several callers including cat-file, pack-objects, and commit-graph. The series is now fully reviewed and ready for integration, representing a completed step in the ODB abstraction effort with measurable performance benefits and cleaner interfaces.
