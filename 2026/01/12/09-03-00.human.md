Refactoring patch in Patrick Steinhardt's ongoing ref backend validation series. This is patch 11/17 in the second iteration, focusing on include file cleanup in the reftable backend implementation.

It moves `parse.h` from a local include to the main include path (now as `../parse.h`), removes a redundant include of `parse.h` that was already present via `../parse.h`, and reorders some other includes. The diff is small but part of the larger effort to make the backend code more maintainable.

This continues the series' pattern of first refactoring the files backend (patches 1-8), then building shared infrastructure (9-14), with fsck check migration coming later (15-17). The change is mechanical and uncontroversial, following established patterns seen in prior patches that have already been reviewed.
