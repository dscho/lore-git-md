This is a refactoring patch in Patrick Steinhardt's `git-history` series (v10 6/8), introducing new functionality to the working tree status subsystem. The patch adds `wt_status_collect_changes_trees()`, which computes and formats differences between two arbitrary trees rather than comparing the working tree or index.

The new function reuses the existing diff machinery and callback infrastructure from `wt_status_collect_updated_cb()` to present tree differences in the same format as staged changes. While this stretches the "working tree" status concept slightly, it avoids duplicating diff formatting code for the upcoming `git-history` command's needs. The implementation handles rename detection configuration consistently with other status operations and properly cleans up resources.

This change is part of the larger effort to build history editing capabilities on Git's replay infrastructure, with this particular piece providing the diff display functionality needed for commands like `reword` and `split`. The patch appears cleanly integrated with existing code and follows the project's patterns for diff handling.
