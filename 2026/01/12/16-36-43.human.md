This is the second patch in a merged test modernization series for the post-checkout hook tests in t5403. The patch improves test robustness by standardizing the hook output format and using `test_cmp` for validation.

The change converts the post-checkout hook to output arguments in a consistent "key=value" format (e.g., "old=HASH new=HASH flag=1") rather than space-separated values. This allows using `test_cmp` to compare the actual output, which provides clearer failure diagnostics by showing exactly which argument mismatches when a test fails. The patch updates both the main test case and the clone scenario to use this new format.

This follows through on review feedback from Eric Sunshine and Pushkar Singh requesting better documentation and standardized patterns. The implementation builds on the first patch's introduction of a `check_post_checkout` helper function, now making that helper more maintainable and debuggable. The changes are purely about test quality - no Git behavior is modified.

The series is now merged, concluding this particular test modernization effort for the post-checkout hook tests. The changes align with the broader project trend toward using standardized test helpers and patterns from test-lib-functions.sh.
