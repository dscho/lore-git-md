This is a test modernization patch that introduces a helper function for post-checkout hook testing in t5403. It's the first of a two-patch series that has already been merged.

The patch creates a new `check_post_checkout` helper function that consolidates the validation of post-checkout hook arguments (old ref, new ref, and branch-switch flag) which was previously repeated across multiple test cases. The helper follows Git's test helper conventions by including a BUG check for argument count and combining the three separate validations into one logical unit.

The changes are purely structural - no test behavior is altered. The patch converts all existing test cases to use the new helper, replacing the previous pattern of manually reading and checking each argument. This makes the test script more maintainable by reducing duplication and providing a single point of control for the validation logic.

The implementation shows good attention to detail, properly handling rev-parse calls to get the expected commit hashes and maintaining all the original assertions. This is part of Git's broader effort to modernize tests by introducing standardized helper functions and patterns.
