This is the final patch in a two-part test modernization series for the post-checkout hook testing in t5403. The series converts shell tests to use helper functions and standardized patterns for better maintainability and diagnostics.

The first patch introduced a `check_post_checkout` helper function to consolidate duplicate validation patterns. This follow-up adds comprehensive documentation for the helper, addressing review feedback to make the function's purpose and parameters clearer. The documentation follows the style used in `test-lib-functions.sh`, explicitly describing the four parameters (args-file, old, new, flag) and their roles in verifying the post-checkout hook's behavior.

The helper now has complete "Usage:" documentation explaining that it verifies the hook received correct arguments (old/new object IDs and flag value), with the flag distinguishing between branch switches (1) and other operations (0). The implementation preserves all original assertions while making them more maintainable through this standardized approach.

This concludes the test modernization effort for t5403, bringing it in line with patterns seen elsewhere in the test suite (like t5510-fetch.sh and t5520-pull.sh). The changes were prompted by Eric Sunshine's review suggesting improved documentation and Pushkar Singh's note about documenting the expected hook output format. The author (Deveshi Dwivedi) has fully implemented these suggestions, closing the feedback loop.
