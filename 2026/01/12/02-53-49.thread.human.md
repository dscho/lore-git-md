This thread explores a proposed Git feature for handling template files - configuration files like `.env` or machine-specific settings where users want to commit a base version but ignore local modifications. The original proposal suggested a `.gittemplates` configuration that would index but not track changes to such files, aiming to solve the common workflow of maintaining both committed templates and local ignored versions.

Oswald Buddenhagen has now joined the discussion, noting this idea resembles the "precious" ignored files concept previously discussed on the mailing list. The similarity suggests this is a recurring pain point in the Git community, with multiple contributors independently identifying the need for better template file handling. The conversation remains at an early stage, with participants considering whether existing mechanisms like `--assume-unchanged` or `--skip-worktree` could address these use cases, or if a new solution is warranted. No implementation details have been proposed yet as the focus remains on validating the need and exploring design options.
