This is part 7 of Patrick Steinhardt's 17-patch series refactoring Git's ref backend validation. The patch extends consistency checks to root refs (like HEAD) in the files backend, which were previously skipped.

The change introduces a new `files_fsck_root_ref()` helper that validates each root ref by:
1. Constructing the proper refname (handling worktree cases)
2. Checking the ref's filesystem path exists
3. Delegating to the existing `files_fsck_ref()` for actual checks

Two new test cases verify the behavior for both main repository and worktree HEAD refs, ensuring invalid references (like "refs/../HEAD") are properly reported. The implementation carefully handles memory management with `strbuf` cleanup and maintains the existing error accumulation pattern.

This continues the series' pattern of methodical refactoring - each patch builds toward the goal of unified validation while keeping intermediate changes small and testable. The patch demonstrates attention to edge cases (worktree handling) while maintaining clean separation of concerns from earlier changes in the series.
