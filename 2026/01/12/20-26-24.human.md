This is the final version of a feature patch series that enhances `git status` to show divergence information for both upstream and push tracking branches. The series has already been approved by Junio Hamano for inclusion in the `next` branch after 23 iterations of review.

The first patch refactors the branch comparison formatting logic into a new `format_branch_comparison()` helper function. The second patch implements the main feature - showing push tracking branch divergence alongside the existing upstream tracking information. The implementation handles remapped push refspecs and maintains all existing output formats and advice messages.

Key technical details:
- Uses new `BRANCH_MODE_PULL`/`BRANCH_MODE_PUSH` flags to control display
- Adds 262 lines of test coverage in t6040-tracking-info.sh
- Preserves quick mode (`--no-ahead-behind`) behavior
- Shows push divergence on a new line when it differs from upstream

The current discussion focuses on final refinements around push reference resolution with different `push.default` configurations and whether to show divergence advice for both upstream and push branches. Phillip Wood has suggested improvements in these areas, but they are considered follow-up opportunities rather than blockers.

This is a well-tested, carefully reviewed feature that cleanly extends `git status` output while maintaining backward compatibility. The 23-version history shows thorough attention to detail, and Junio's approval signals it meets project standards. The remaining discussion points represent minor polish that could be addressed in future patches.
