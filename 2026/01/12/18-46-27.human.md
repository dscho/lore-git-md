This is part 6 of an 11-patch series implementing submodule gitdir path encoding via a new `extensions.submodulePathConfig` mechanism. The series addresses filesystem conflicts in submodule gitdirs by requiring explicit path configuration when the extension is enabled.

This patch adds a `git submodule--helper migrate-gitdir-configs` command to automate migration of existing submodules to the new configuration scheme. The command scans `.git/modules/`, validates each submodule path, and creates the required `submodule.<name>.gitdir` config entries. It also sets the repository format version and enables the path config extension.

The implementation includes thorough test coverage verifying migration behavior, including edge cases like cloning repositories with migrated submodules. The command was suggested by both Junio Hamano and Patrick Steinhardt during earlier review rounds, and the patch has been polished through nine iterations with all feedback addressed.

This is a well-tested addition to the submodule infrastructure that completes the migration path for the new path encoding scheme. The series as a whole has received extensive review and real-world validation from Google, and appears ready for merging.
