This is part 1 of an 11-patch series implementing submodule gitdir path encoding, now in its 9th iteration. The series introduces runtime configuration option `extensions.submodulePathConfig` to handle filesystem conflicts in submodule gitdirs.

This particular patch is a small refactoring that replaces a hardcoded path construction with a call to `submodule_name_to_gitdir()`, which is the standard helper for this purpose. The change fixes test failures and narrows variable scope where possible. The diff shows the mechanical replacement of direct path manipulation with the helper function call, along with some cleanup of the surrounding code.

The patch is straightforward and uncontroversial - it's a cleanup to use an existing helper function consistently. The change is well-contained to `builtin/submodule--helper.c` and doesn't modify any behavior, just makes the code more maintainable by using the proper abstraction. This is part of the final polish for a series that has already received extensive review and real-world testing at Google.
