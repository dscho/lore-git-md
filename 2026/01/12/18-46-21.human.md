This is the final version (v9) of a feature series implementing path encoding for submodule gitdirs to prevent filesystem conflicts. The series introduces a new `extensions.submodulePathConfig` extension that enables runtime configuration of submodule gitdir paths, with comprehensive fallback mechanisms and case-folding protection.

The v9 iteration addresses two final review comments from Patrick Steinhardt: replacing `git config --global` with `test_config_global` in tests, and splitting long `die()` messages into multiple lines for better readability. These are minor polish changes that don't affect the core functionality.

Key aspects of the series include:
- A four-tier fallback system for path resolution (plain -> encoded -> numbered -> hashed)
- Case-folding protection using RFC3986 encoding
- New `git submodule--helper migrate-gitdir-configs` command for atomic migration
- Runtime restriction to new repositories
- Comprehensive test coverage including nested submodules and migration scenarios

The series has received final approval from Junio Hamano and Patrick Steinhardt, with Josh Steadmon confirming successful testing at Google (who sponsored Adrian Ratiu's work). The implementation is production-ready and will be merged once these final minor tweaks are applied.

This represents the culmination of 8 previous iterations and extensive review, with all technical and documentation issues resolved. The changes touch several core areas including submodule handling, repository initialization, and URL encoding utilities, but maintain backward compatibility while providing a robust solution for submodule path conflicts.
