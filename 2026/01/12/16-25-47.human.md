This is a two-part platform compatibility patch series addressing a macOS-specific bug in character encoding conversion. The patches provide a workaround for an issue where macOS 14/15's iconv implementation fails to properly handle ISO-2022-JP to UTF-8 conversion when the output buffer needs to grow.

The first patch introduces the core workaround in utf8.c, while the second enables it in the build system. The solution involves saving input state and resetting the converter when buffer growth occurs, maintaining compatibility while fixing the macOS-specific corruption issue. The author notes alternative solutions exist (using different iconv implementations via package managers), but this workaround provides a built-in fix.

The patches have gone through three iterations with improvements to the commit messages and build configuration details based on feedback from René Scharfe and Junio Hamano. The changes are narrowly scoped to utf8.c and maintain backward compatibility. This appears to be a well-motivated fix for a real platform-specific bug, with careful attention to documenting the workaround and considering alternative approaches.
