This is a refactoring patch from Patrick Steinhardt, part of a larger series (1/8) to move replay functionality into libgit. The patch extracts the core revision replay logic from `cmd_replay()` into a new `replay_revisions()` function that will later be moved to a library file. 

The new function encapsulates the commit replay process, taking input revisions and options, then producing a `replay_result` struct containing any reference updates that would occur. The change is purely structural - no behavior changes are intended, though the error handling has been slightly reworked to be more consistent.

This appears to be a well-crafted preparatory step in a larger architectural effort. The commit message clearly explains the motivation and the patch itself is focused and mechanical, mostly moving code while maintaining existing functionality. The next patch in the series will presumably move this logic into libgit proper.
