This is a refactoring patch in the submodule gitdir path encoding series, moving URL encoding functionality to a shared location.

The patch relocates the `is_rfc3986_unreserved()` function from `builtin/credential-store.c` to `url.[ch]` to make it available for submodule path encoding. The function was previously made static when only credential-store used it, but now the submodule path encoding work needs it for URL-style encoding of submodule names to prevent filesystem conflicts.

The change is straightforward: the function implementation moves to `url.c` with its declaration added to `url.h`, while the credential-store code now includes `url.h` to access it. The commit message explains the motivation clearly - this enables reuse of the submodule path encoding work while maintaining the function's original purpose of RFC3986 URL character validation.

This is a mechanical change that enables subsequent patches in the series to use URL encoding for submodule paths. The patch follows the project's pattern of moving shared functionality to appropriate library locations when multiple components need access.
