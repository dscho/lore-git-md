This is part 3 of an 11-patch series implementing submodule gitdir path encoding, now in its 9th iteration. The series introduces runtime configuration for submodule paths to prevent filesystem conflicts, with this particular patch adding a new `git submodule--helper gitdir` command.

The patch exposes the internal `submodule_name_to_gitdir()` function as a command-line interface, allowing users and tests to query the computed gitdir path for a given submodule name. This helper will be used in subsequent patches to validate gitdir paths and interact with the new configuration system.

Key technical details:
- Adds new `module_gitdir()` function to `builtin/submodule--helper.c`
- Takes a submodule name as input and outputs its computed gitdir path
- Uses the centralized `submodule_name_to_gitdir()` helper that now handles path validation
- Follows the pattern of other submodule--helper subcommands
