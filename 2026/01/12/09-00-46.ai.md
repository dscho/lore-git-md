Performance optimization in Patrick Steinhardt's ODB abstraction series. This patch (6/7) speeds up disk size lookups by skipping unnecessary header parsing when only the disk size is requested from packed objects. The change yields a measurable 9% improvement in `git rev-list --disk-usage` benchmarks while maintaining all existing functionality. The patch builds on earlier work in the series that restructured object info handling, particularly the introduction of the PACKED_OBJECT_TYPE enum in patch 3/7. With this change, the series now has all reviews addressed and is ready for integration.
