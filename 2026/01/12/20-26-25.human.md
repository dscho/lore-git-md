This is the first of two patches in Harald Nordgren's series to enhance `git status` tracking information. It's a refactoring patch that prepares for showing divergence from both upstream and push tracking branches by extracting the branch comparison formatting logic into a new `format_branch_comparison()` helper function.

The patch cleanly separates the formatting logic from the upstream tracking state handling in `format_tracking_info()`. The new helper takes parameters for the branch state (up-to-date, ahead, behind, or diverged), commit counts, branch name, and display flags. This modularization will allow the second patch to reuse the same formatting for push tracking information.

Key changes:
- Moves the message formatting code into `format_branch_comparison()`
- Preserves all existing output formats and advice messages
- Maintains the quick mode behavior (AHEAD_BEHIND_QUICK)
- Renames variables for clarity (`cmp_fetch` instead of `sti`)
- Keeps the same error handling for gone upstream branches

The refactoring looks thorough and mechanical, with no behavior changes intended. This is a well-structured preparation step that follows Git's convention of separating refactoring from feature changes.
