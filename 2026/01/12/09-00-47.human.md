This is the final patch in Patrick Steinhardt's v5 series refactoring Git's object info handling as part of the ODB abstraction effort. The patch removes a redundant `repository` parameter from `packed_object_info()` since the same information is already available in the `packed_git` struct that's passed in.

The change is straightforward and mechanical, updating all callers to omit the now-unneeded repository parameter. The patch follows the series' pattern of simplifying interfaces while maintaining functionality - in this case by relying on the repository pointer already stored in the packfile structure rather than requiring callers to pass it separately.

This concludes the series which has already received thorough review and approval from Karthik Nayak (GitLab ODB team). The changes improve code clarity and maintainability while also delivering a measurable 9% performance improvement for disk size lookups. With all feedback addressed and regression tests added, this series appears ready for integration.
