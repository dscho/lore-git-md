This is part of Patrick Steinhardt's v5 series refactoring Git's object info handling for the ODB abstraction effort. Patch 2/7 simplifies the interface by removing the OI_DBCACHED distinction - all packfile objects are now uniformly reported as OI_PACKED, since callers didn't meaningfully use the delta base cache distinction.

The change incidentally fixes a segfault in `git archive` when handling deltified blobs exceeding core.bigFileThreshold, which the patch now includes a regression test for. The test creates a repository with delta chain objects and verifies `git archive` can handle them correctly.

The patch maintains the series' focus on interface simplification while also catching a real bug. It has received approval from Karthik Nayak (GitLab ODB team) and appears ready for integration. This continues the pattern of the series delivering both cleaner abstractions and concrete improvements.
