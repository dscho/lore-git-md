This is an RFC patch from GSoC participant Shreyansh Paliwal, continuing the test modernization effort to remove Git exit code suppression in test scripts. The discussion focuses on test #365 in t5500-fetch-pack.sh which verifies shallow fetch behavior with commit graphs.

The thread shows active engagement between the new contributor and maintainer Junio C Hamano, who raised several technical concerns about the initial approach: using temporary files for object IDs (unusual compared to shell variables), the bash-specific $(<file) construct (non-portable), and the realization that the changes wouldn't actually address the core exit code suppression issue since pipe behavior would still mask failures.

Shreyansh acknowledges the feedback and proposes an alternative approach - explicitly checking git command success with `|| exit 1` before using the values. This would properly surface failures rather than having them suppressed by pipe behavior. The discussion remains open on how best to both improve test robustness and maintain portability while keeping the test's original purpose (verifying shallow fetch with commit graphs) intact.
