Documentation patch improving Git's "MyFirstContribution" guide with several practical fixes for new contributors. Shreyansh Paliwal addresses common stumbling blocks in the tutorial by adding missing header includes (`environment.h` and `strbuf.h`) to code examples that previously would fail to compile. The patch also corrects manpage synopsis formatting from the outdated `'git-psuh'` style to the current standard `git psuh` format, which would otherwise cause documentation test failures.

The changes clarify build prerequisites by explicitly mentioning DocBook-XSL alongside AsciiDoc as required for building documentation, with a reference to INSTALL for full details. The parallel test execution explanation is expanded to note that `-j$(nproc)` uses all available CPUs by default but can be adjusted, while maintaining the rationale for test randomization to avoid inter-test dependencies.

These are focused, well-motivated improvements that directly address real issues new contributors encounter when following the tutorial. The patch follows Git's documentation conventions and maintains the guide's pedagogical approach while fixing technical inaccuracies. Each change is small but meaningful, making the onboarding experience smoother without introducing new complexity.
