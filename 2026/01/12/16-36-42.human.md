Test modernization patch introducing a helper function for post-checkout hook testing in t5403. This is the first of two patches in a merged series that improves test robustness by consolidating repeated validation patterns into a single helper function.

The patch adds a `check_post_checkout` helper that encapsulates the common pattern of verifying post-checkout hook arguments (old ref, new ref, and flag). It replaces four-line validation blocks with single-line helper calls while maintaining the same assertions. The helper includes a BUG check for argument count and uses `rev-parse` for commit hash validation.

Notable improvements include:
- Making the clone test actually validate hook arguments rather than just checking file existence
- Using `rev-parse` to properly verify commit hashes
- Preparing the ground for further standardization in the follow-up patch

The changes are purely test-related with no impact on Git's functionality. The patch follows the project's test modernization trend of replacing ad-hoc validation with documented helper functions. Review feedback from Eric Sunshine and Pushkar Singh was incorporated in the follow-up patch to add documentation and standardize the output format.
