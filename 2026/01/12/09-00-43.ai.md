This is part 3 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch introduces a more precise way to track delta object types in packed storage.

The change replaces a simple boolean `is_delta` field with a 4-state enum that can represent:
- Unknown delta status (not yet determined)
- Full (non-delta) objects
- Offset deltas
- Reference deltas

The motivation comes from cases where we skip parsing packed objects entirely (when no object-specific data is requested), leaving the delta status unknown. While this isn't currently an issue due to a bug in the empty request check, the enum prepares for fixing that bug in a follow-up commit.

The patch touches core object handling code in `packfile.c` and the object info struct definition in `odb.h`. It maintains backward compatibility while enabling more precise tracking of object types, which will be important for the ODB abstraction work. The series has already received thorough review from Karthik Nayak and addresses all prior feedback.
