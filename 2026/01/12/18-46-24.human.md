This is part 3 of an 11-patch series implementing submodule gitdir path encoding, now in its 9th iteration. The series introduces runtime configuration for submodule paths to prevent filesystem conflicts, with this particular patch adding a new `git submodule--helper gitdir` command.

The new command exposes the internal `submodule_name_to_gitdir()` function, which computes and validates submodule gitdir paths. This helper will be used by subsequent patches to query and validate gitdir paths when users configure them. The implementation is straightforward - it takes a submodule name as input and outputs the computed gitdir path.

The patch builds on previous work by Brandon Williams and has gone through extensive review, with all feedback from maintainers now addressed. This version includes centralized path validation logic and other polish from 8 previous iterations. The series as a whole has been validated in production at Google and is ready for merging.

This is a well-crafted piece of a larger, carefully reviewed feature that solves real problems with submodule path handling. The patch itself is small and focused, doing exactly what it needs to support the broader effort.
