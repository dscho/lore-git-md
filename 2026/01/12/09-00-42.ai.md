This is part 2 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch simplifies the OI_DBCACHED enum by removing it entirely, always declaring objects from packfiles as OI_PACKED regardless of whether they're in the delta base cache.

The change makes the interface improvements:
- Removes an implementation detail (delta base cache status) that callers didn't need to know about
- Fixes a segfault in streaming packed objects that occurred when checking delta status on OI_DBCACHED objects
- Adds a regression test for the segfault case involving `git archive` with deltified blobs exceeding core.bigFileThreshold

The patch has already received approval from Karthik Nayak (GitLab ODB team) in previous iterations. The v5 version adds the regression test to prevent future regressions of the segfault case. This continues the series' pattern of simplifying interfaces while maintaining or improving functionality.
