This is a platform compatibility patch addressing a macOS-specific bug in character encoding conversion. The patch implements a workaround for a broken iconv implementation in macOS 14/15 that fails to maintain conversion state when growing output buffers during ISO-2022-JP to UTF-8 conversion, causing corrupted output in Git commands like `git show`.

The patch modifies `utf8.c` to add a new `ICONV_RESTART_RESET` workaround that saves input state, resets the converter, and retries from scratch when the output buffer needs to grow. This maintains correctness while preserving backward compatibility. The solution is narrowly scoped to the buffer growth case in `reencode_string_iconv()` and follows established patterns for platform-specific workarounds in Git's encoding infrastructure.

This is the first of two patches - the second will add build system support for enabling the workaround. The patch has already incorporated feedback from René Scharfe and Junio Hamano to improve clarity, and no technical objections remain. The work is well-motivated by actual test failures in t3900 and provides a clean solution that doesn't require users to install alternate iconv implementations.
