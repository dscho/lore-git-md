This is the third and final part of an Outreachy intern's patch series (mentored by Christian Couder) that moves global configuration variables into `struct repo_config_values` as part of the ongoing `the_repository` removal effort. The patch migrates the `branch.autoSetupMerge` config value from the global `git_branch_track` variable to repository-specific storage in the new struct.

The change affects several commands that deal with branch tracking behavior (`branch`, `checkout`, `push`, and `submodule--helper`), updating them to read from `the_repository->config_values.branch_track` instead of the global. The implementation follows the same pattern as previous parts in the series, with initialization handled in `repo_config_values_init()` and config parsing updated in `git_default_branch_config()`.

While this completes the technical implementation of moving these three config values (following parts 1 and 2 which handled `core.attributesFile` and `core.sparseCheckout`), the series still has the same fundamental limitation noted in previous reviews: config values are only properly initialized for `the_repository`, not other repository structs. This remains an open architectural question that will need to be addressed in future work. The patch itself is cleanly implemented and follows the established pattern from earlier parts of the series.
