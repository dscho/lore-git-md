This is a security patch discussion regarding ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005). Patrick Steinhardt is pushing back against Junio Hamano's characterization of the fix as an optional feature, arguing it should be treated as a mandatory security fix for a vulnerability that could lead to arbitrary code execution (e.g., via title bar injection).

The thread shows disagreement between maintainers about whether the stricter default behavior should be opt-in (Junio's position, supported by downstream maintainers like Ondrej Pohorelsky) or mandatory (Patrick's position). Patrick points out that Git has historically made backwards-incompatible changes for security reasons, questioning why this case should be different.

The underlying technical work (implemented by Johannes Schindelin) provides configurable sanitization with URL-specific policies, thorough test coverage, and has been production-tested in Git for Windows and Red Hat distributions for 6+ months. While the implementation itself is mature and well-reviewed, the discussion now centers on the appropriate default security posture rather than technical concerns.
