This is a performance optimization patch for the sparse-checkout feature, addressing an O(n^2) pattern sorting issue. It's part of an ongoing series that has already gone through several iterations with review from Jeff King and Derrick Stolee.

The patch changes how sparse-checkout builds its pattern list by first collecting patterns unsorted (using `string_list_append`) and then sorting them in one pass (O(n log n)) rather than inserting each pattern in sorted order (O(n^2)). The second patch adds tests to verify the deduplication behavior that was previously implicit but untested.

The optimization particularly helps when dealing with many duplicate patterns, which can occur when using `git sparse-checkout add --stdin`. The changes affect both the pattern listing output and the file writing logic in `builtin/sparse-checkout.c`. 

The series appears ready for merging, with Junio C Hamano having approved v4. The v5 iteration adds the requested test coverage while maintaining the performance improvements. This is a focused, well-motivated change that fits into the broader sparse-checkout optimization work led by Derrick Stolee and Elijah Newren.
