Performance optimization for sparse-checkout pattern handling, with test improvements suggested by Derrick Stolee.

This is a follow-up to Amisha Chhajed's v5 patch series optimizing sparse-checkout pattern sorting from O(n^2) to O(n log n). While the core optimization (switching from string_list_insert() to string_list_append() + sort) was already approved by Junio, Derrick Stolee provides detailed feedback on the accompanying test cases.

Stolee suggests improving the test coverage by:
1. Using more realistic nested directory patterns (like foo/bar/baz) rather than simple top-level directories
2. Testing the interaction between nested patterns and deduplication
3. Clarifying that the 'list' command test isn't actually exercising the deduplication logic since 'add' already handles it
4. Noting that non-cone mode should preserve duplicates since pattern order matters there

The feedback is constructive and specific, focusing on making the tests more thorough while acknowledging the optimization itself is sound. Stolee also catches a minor formatting issue in the patch subject line. This appears to be the final round of review before the series can be merged, with all technical concerns from earlier rounds now addressed.
