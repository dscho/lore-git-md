Performance optimization for sparse-checkout pattern handling, now with added test coverage. This is the fifth iteration of Amisha Chhajed's patch series that improves the efficiency of building sorted pattern lists in the sparse-checkout subsystem.

The first patch completes the optimization by switching from O(n^2) insertion sorting to O(n log n) append-then-sort, now properly handling duplicates with string_list_remove_duplicates(). The changes affect pattern collection in sparse_checkout_list() and write_cone_to_file() in builtin/sparse-checkout.c. The optimization was already approved by Junio C Hamano in v4, with Jeff King noting the theoretical soundness of the approach.

The second patch adds new test cases that were previously missing - it confirms that sparse-checkout properly deduplicates repeated cone-mode patterns both in the sparse-checkout file and when listing patterns. The tests cover both the file output format and the `git sparse-checkout list` command behavior.

This version addresses Derrick Stolee's earlier feedback about adding coverage for the deduplication behavior. The tests use a straightforward approach with repeated patterns (/foo/ appears twice in input) and verify the output contains each pattern only once. The patch series appears ready for merging, having incorporated all previous review comments and now including the requested test coverage.
