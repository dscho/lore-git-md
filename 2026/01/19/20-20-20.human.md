This is a feature patch adding a `--keys` flag to `git repo info` for programmatic repository metadata access. It's the final patch in a series that has evolved through multiple versions with input from Junio Hamano, Patrick Steinhardt, and Jean-Noël Avila.

The patch introduces a new `--keys` option that lists available metadata keys without their values, useful for scripting. The output format can be controlled with `--format` (defaulting to one key per line) or `-z` for NUL-terminated output. The implementation includes:
- A new `print_keys()` function in `builtin/repo.c`
- Documentation updates explaining the new option
- Comprehensive tests verifying the behavior and error cases

The series replaces an earlier queued topic (`lo/repo-info-keys`) and has addressed all review feedback, including format naming clarifications and documentation standardization. The patch appears well-tested and ready for integration, with clear commit messages and thorough test coverage.
