Bugfix patch from Jeff King addressing a const-correctness issue in remote.c's error_buf() helper function. This is the first of a 4-patch series fixing memory leaks in push tracking reference handling.

The patch changes error_buf()'s return type from `const char *` to `char *` to avoid compiler warnings when the helper is used in functions returning non-const strings. The const qualifier wasn't providing any real benefit since the function only ever returns NULL. This change enables the helper to be used more flexibly while maintaining the same behavior.

The modification is minimal (just one line changed in remote.c) and purely technical - it doesn't affect runtime behavior but prepares for subsequent patches in the series that will use this helper in different contexts. As with all of Jeff King's patches, this demonstrates careful attention to memory management details and compiler warnings.
