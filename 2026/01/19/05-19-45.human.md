Bugfix patch from Jeff King addressing a const-correctness issue in remote.c's error_buf() helper function. This is the first of a 4-patch series fixing memory leaks in push tracking reference handling.

The patch changes error_buf() to return a non-const char pointer instead of const char*. This removes an unnecessary restriction that was causing compiler warnings when the helper was used in functions returning non-const strings. The change is purely mechanical - the function only returns NULL anyway, so the const qualifier wasn't providing any real benefit.

This is a preparatory change for the subsequent patches in the series that will fix actual memory leaks. As with all of Jeff King's work, the patch is small, focused, and clearly explained in the commit message. The change touches just one line in remote.c.
