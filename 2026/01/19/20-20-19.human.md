This is a feature patch in a series implementing `git repo info --keys` functionality. The patch adds a "default" format option to both `git repo info` and `git repo structure` commands, making `--format=default` act as a synonym for their respective default output formats (keyvalue for info, table for structure).

The change standardizes format handling across these experimental repository inspection commands, allowing users to explicitly request the default format when needed. The implementation includes:
- Adding FORMAT_DEFAULT to the output_format enum
- Updating documentation to show the new option
- Comprehensive tests verifying the behavior
- Ensuring format can be reset to default after being changed

This is the first of two patches in v4 of the series, which has already gone through several iterations with feedback from Junio Hamano, Patrick Steinhardt, and Jean-Noël Avila. The patch appears well-tested and follows the project's documentation conventions. It's part of a larger effort to provide machine-readable repository metadata access while maintaining consistent format handling.
