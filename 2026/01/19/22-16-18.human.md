This is a security discussion thread about ANSI escape sequence handling in Git's sideband channel. brian m. carlson pushes back against Patrick Steinhardt's characterization of the patch series as a security fix rather than a feature, arguing that the threat model is overstated since similar risks exist in SSH and other common tools.

The key disagreement centers on whether the behavior change should be enabled by default. brian m. carlson notes that:
1. Modern terminals typically disable dangerous functionality like title bar injection
2. SSH connections present equivalent risks without similar filtering
3. Existing pre-receive hooks (including some on GitHub) would break with the new behavior
4. Many users run older Git versions from their distros and wouldn't immediately notice breakage

While not opposed to the feature itself, brian m. carlson advocates for making it opt-in rather than enabled by default, citing backward compatibility concerns. The response suggests this is a philosophical difference about security tradeoffs rather than a technical objection to the implementation. The thread shows the patch series is nearing completion but still has open questions about default behavior that may need maintainer input to resolve.
