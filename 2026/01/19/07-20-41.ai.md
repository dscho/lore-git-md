[Security] ANSI escape sequence injection in sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329)

Patrick Steinhardt weighs in on the ongoing discussion about ANSI escape sequence handling in Git's sideband channel, framing it as a security fix rather than a feature. He challenges the notion that backward compatibility should take precedence when addressing a vulnerability that could enable arbitrary code execution (e.g., via title bar injection). The email references prior instances where Git changed behavior for security reasons, questioning why this case should be treated differently.

The thread context shows this is part of a mature patch series (now at v5) that implements configurable sanitization through `sideband.allowControlCharacters`, with URL-specific policies and extensive test coverage. While earlier discussion focused on whether the stricter default should be opt-in or opt-out, Patrick's intervention shifts the security implications to center stage, noting that other security fixes have broken compatibility when necessary. The implementation has seen production validation in Git for Windows and Red Hat distributions, with technical reviews from Phillip Wood and Patrick Steinhardt himself confirming its soundness.
