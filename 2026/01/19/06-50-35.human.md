This is a test fix addressing flakiness in the reftable test suite on Windows platforms. The patch replaces a shell redirection (`: >file`) with a call to `test-tool truncate` to work around an intermittent permission error that occurs when running test #29 in t0610-reftable-basics.sh in parallel on Windows 11/Cygwin.

Ramsay Jones investigated the issue appears timing-dependent - the test passes when run serially or manually, but fails occasionally under parallel execution. While the root cause remains unclear (the strace analysis didn't reveal obvious differences), the `test-tool` approach reliably avoids the problem. Patrick Steinhardt confirms this matches a previous pattern where test helpers proved more reliable than shell builtins on Windows.

The change is minimal one-line substitution in the test script. Though the underlying race condition isn't fully understood, both contributors agree the pragmatic solution is worth merging to stabilize the test suite. This follows Git's general preference for using test helpers over shell builtins where platform quirks may cause issues.
