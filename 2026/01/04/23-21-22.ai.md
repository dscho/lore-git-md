This is the second and final patch in a series enhancing `git status` to show divergence from both upstream and push tracking branches. The feature was proposed by Harald Nordgren and has undergone extensive review (14 iterations) with input from Junio C Hamano, Phillip Wood, and others.

The patch implements push tracking display by:
1. Adding a new `get_remote_push_branch()` helper that resolves the push tracking reference through the full refspec resolution chain
2. Extending `format_tracking_info()` to handle both upstream and push comparisons
3. Showing push comparison only when it differs from upstream
4. Maintaining existing advice messages while adding push-specific advice when relevant

Key technical details:
- Uses `pushremote_for_branch()` for push reference resolution
- Adds 210 lines of test coverage (up from 168) verifying various states and edge cases
- Handles custom refspec transformations through `remote_ref_for_branch()` and `tracking_for_push_dest()`
- Output format examples show both upstream and push divergence when they differ

The implementation builds on the refactoring from patch 1/2 (already merged) and addresses all review feedback, including Junio's maintainer guidance on patch organization and Phillip Wood's detailed technical review of refspec handling. The series is now complete and ready for merging after this extensive review process.
