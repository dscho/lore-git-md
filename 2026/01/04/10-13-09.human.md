This is a bugfix for the reftable backend, addressing undefined behavior in the indexed table reference iterator. The patch comes from first-time contributor Tsahi Elkayam and has already been reviewed by Pushkar Singh, who confirmed it correctly fixes the known problem marked with a "BUG" comment in the code.

The issue involved unsafe access to union members in the reftable iterator without first checking the reference type, which could lead to memory corruption on malformed input. The fix follows the same pattern already used elsewhere in the codebase, properly validating the value type before accessing union fields. This makes the iterator more robust against invalid input while maintaining all existing behavior for valid cases.
