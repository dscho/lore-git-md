Feature enhancement for `git status` showing push tracking branch comparison. This is the second and final patch in a series that adds the ability to see both upstream and push tracking branch status in `git status` output when they differ.

The patch implements the core functionality after the first patch refactored the tracking info display code. When a branch has different upstream and push tracking branches (common when working on feature branches that track both main and their own remote branch), `git status` now shows both comparisons. For example, if you're tracking `origin/main` but pushing to `origin/feature`, it will show divergence from main and ahead/behind status relative to the feature branch.

The implementation handles all edge cases including custom refspecs, multiple remotes, and various branch states (ahead, behind, diverged). It maintains Git's existing output format while cleanly separating the push tracking information on a new line. The patch includes extensive test coverage (210 new test lines) verifying all scenarios.

This represents the culmination of 14 iterations of review, with feedback incorporated from Junio C Hamano, Phillip Wood, and others. The first refactoring patch has already been merged, and this final implementation addresses all technical requirements while maintaining Git's output conventions. The feature is now ready for inclusion in the main Git codebase.
