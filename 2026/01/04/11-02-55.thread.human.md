This patch series improves the `git add -p` interface by showing users their previous decisions (use/skip) when navigating between hunks. The change, now in its fourth iteration from a Google Summer of Code participant, was specifically requested by maintainer Junio C Hamano.

The modification adds context to the interactive prompt, displaying "(previous decision: use)" or "(previous decision: skip)" when users revisit hunks using the 'K' (previous) and 'J' (next) navigation commands. The implementation touches the core interactive patch code in `add-patch.c` and updates all related test cases in `t3701` to expect the new prompt format. The v4 iteration resolved a macOS-specific test issue that had caused v3 to skip a test case.

The change is thorough but focused - it consistently updates the prompt display across all interactive patch modes (stage, unstage, stash, reset, etc.) while maintaining clean implementation and comprehensive test coverage. This continues Git's ongoing effort to refine its interactive patch interface.
