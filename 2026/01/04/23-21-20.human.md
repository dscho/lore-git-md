This is the final version of a 2-patch series adding push tracking information to `git status` output. The feature shows how the current branch compares to both its upstream (pull) and push tracking branches when they differ, helping users understand their branch state in more complex workflows.

The first patch (already merged) refactored the branch comparison formatting code to prepare for the new feature. This second patch implements the push tracking display by:

1. Adding logic to resolve push tracking references through Git's existing refspec resolution chain
2. Extending the status output to show push comparisons only when they differ from upstream
3. Maintaining all existing advice messages while adding push-specific advice when relevant

The implementation handles edge cases like custom refspecs and maintains compatibility with existing behavior. It includes 210 lines of new test coverage (up from 168) verifying various branch states and configurations. Example output shows both upstream and push comparisons when they differ, with appropriate advice for each.

The series has gone through 14 iterations with thorough review from Phillip Wood (who helped solve the refspec mapping challenge) and maintainer guidance from Junio Hamano. All technical concerns have been addressed, and the feature is ready for inclusion. This represents a well-executed enhancement that provides clearer branch status information without disrupting existing workflows.
