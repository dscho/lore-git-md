Documentation style discussion about formatting command-line options in man pages, focusing on backticks (`` `--option` ``) versus plain (`--option`). Thread starter noted inconsistencies between commands like `git-am` (uses backticks) and `git-prune`/`git-name-rev` (no backticks). Junio C Hamano established the project's direction is toward adding more backticks for proper AsciiDoc markup, citing commit f7316a66 and Jean-Noël Avila's synopsis-style conversion work as reference. Avila confirms the conversion is proceeding systematically following git-scm.com command order, with `git-commit` and `git-add` as current style references. The effort is part of broader documentation standardization but distinct from the main synopsis-style conversion project. No open questions remain - both Junio and Avila provide clear guidance to follow the more-fully-marked-up style. Avila invites contributors to help with the ongoing conversion work, acknowledging the learning curve involved in adopting the new conventions. Affects Documentation/rerere-options.adoc and other files being converted.
