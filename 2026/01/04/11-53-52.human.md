Feature enhancement for `git status` showing push tracking branch comparisons. This is the final version of Harald Nordgren's 2-patch series that has undergone extensive review (14 iterations) and is now ready for inclusion.

The series adds push remote tracking information to `git status` output when it differs from the upstream branch. For example, it can now display both:
```
Your branch is ahead of 'upstream/main' by 1 commit.
Your branch is ahead of 'origin/feature' by 1 commit.
```

The implementation handles all edge cases including custom refspecs and maintains Git's existing output conventions. The first patch was a refactoring that extracted comparison formatting logic, while this second patch adds the push tracking display with comprehensive test coverage (210 lines of tests).

Key reviewers Junio C Hamano and Phillip Wood have approved the technical approach, with all feedback addressed. The series represents a well-executed enhancement that provides useful information about branch state while maintaining backward compatibility and following Git's established patterns.
