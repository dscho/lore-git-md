This is a documentation patch that clarifies the Git pack protocol specification. Heath Dutton noticed that while the protocol grammar defines 'depth' as '1*DIGIT', it uses 'timestamp' in the depth-request syntax without providing a similar specification. The patch simply adds the missing definition, making it clear that timestamp should also be one or more digits.

The change is straightforward and uncontroversial - it's filling in an obvious gap in the documentation without changing any behavior. The patch references an external issue tracker (git.issues.gerritcodereview.com) where this was presumably reported, though the exact context isn't visible in the email itself. The modification touches only the protocol documentation file, adding a single line to match the existing pattern used for similar numeric values in the protocol.
