This is a documentation patch that clarifies the pack protocol specification. Heath Dutton noticed that while the protocol grammar defines 'depth' as '1*DIGIT', it references 'timestamp' without providing a similar specification. The patch adds the missing definition, making it clear that timestamp should also be specified as one or more digits.

The change is straightforward - a single line addition to Documentation/gitprotocol-pack.adoc that mirrors the existing depth definition. The commit message references an external issue tracker (git.issues.gerritcodereview.com) where this was presumably reported, though this is not a standard Git project tracker. The patch appears well-formed and addresses a clear documentation gap in the protocol specification.
