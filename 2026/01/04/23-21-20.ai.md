This is the final version of a 2-patch series implementing a feature enhancement for `git status` to show divergence from both upstream and push tracking branches. The series has undergone extensive review (14 iterations) and is now ready for inclusion.

The first patch (already merged) refactored the branch comparison formatting code to prepare for the new functionality. This second patch implements the core feature by:

1. Adding a new `get_remote_push_branch()` helper that resolves push tracking references through the full refspec resolution chain
2. Extending `format_tracking_info()` to handle both upstream and push comparisons
3. Showing push comparison only when it differs from upstream
4. Maintaining existing advice messages while adding push-specific advice when relevant

The implementation handles all edge cases including custom refspec transformations and maintains Git's existing output conventions. It includes 210 lines of test coverage (up from 168) verifying various branch states and configurations. Example output shows both upstream and push tracking information when they differ, with appropriate advice messages.

The patch has received thorough review from Phillip Wood (who identified and helped solve the refspec mapping issue) and maintainer approval from Junio C Hamano. All technical concerns have been addressed through the 14 iterations of refinement. The series represents a well-executed enhancement that provides useful information to users while maintaining Git's existing conventions and behavior.
