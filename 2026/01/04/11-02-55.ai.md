This is a UI improvement patch for `git add -p` (interactive patch staging) that shows the previous decision (use/skip) when navigating between hunks. The patch is in its fourth iteration (v4) and comes from a GSoC (Google Summer of Code) participant.

The change modifies the interactive prompt to display whether the user previously chose to use or skip each hunk when navigating with 'K' (previous) and 'J' (next) commands. For example, the prompt now shows "(previous decision: use)" or "(previous decision: skip)" when revisiting a hunk. This helps users keep context of their earlier choices while working through multiple hunks.

The patch touches the core interactive patch code in `add-patch.c` and updates several test cases in `t/t3701-add-interactive.sh` to expect the new prompt format. The changes are mechanical but thorough - updating prompt strings across all patch modes (stage, stash, reset, checkout, etc.) and ensuring test cases match the new output.

- The v4 iteration fixes a test case that was skipped in v3 due to macOS-specific behavior
- The implementation is clean and focused, with clear test coverage
- This is part of ongoing work to improve the interactive patch interface
