This is a refactoring patch that prepares for adding push tracking information to `git status` output. It's the first of a two-part series that has already gone through extensive review (14 iterations) and has maintainer approval.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` helper function. This cleanly separates the message generation from the upstream reference resolution logic, making it easier to reuse the formatting for both upstream and push tracking comparisons in the follow-up patch.

Key changes:
- Moves all message formatting cases (ahead, behind, diverged, etc.) into the new function
- Takes the branch name and counts as parameters rather than resolving them internally
- Maintains identical output to the original implementation
- Handles all edge cases (gone upstream, quick mode, diverged branches)
- Incorporates Junio Hamano's feedback on parameter passing and style

The refactoring is mechanical and behavior-preserving, with no user-visible changes in this patch. It lays the groundwork for the second patch which will add push tracking information to the status output while reusing this formatting logic. The patch has already been reviewed and approved by Junio Hamano and other contributors, with all feedback addressed in previous iterations.
