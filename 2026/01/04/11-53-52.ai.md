This is the final version of a 2-patch series implementing a feature enhancement for `git status` to show divergence from both upstream and push tracking branches. The series has gone through 14 iterations of review and refinement, with all feedback addressed.

The first patch (already merged) refactored the branch comparison formatting code to prepare for the new feature. The second patch now implements the core functionality:

- Adds support for showing push tracking branch comparisons in `git status` output when they differ from the upstream tracking branch
- Uses Git's existing branch tracking configuration (`branch.<name>.pushRemote`)
- Handles all edge cases including custom refspec transformations
- Maintains clean separation between upstream and push tracking information
- Includes comprehensive test coverage (210 lines of tests) verifying various states and configurations

The implementation shows push tracking info only when it differs from upstream, with examples like:
```
Your branch is ahead of 'upstream/main' by 1 commit.
Your branch is ahead of 'origin/feature' by 1 commit.
```
or when diverged:
```
Your branch and 'origin/main' have diverged...
Your branch is ahead of 'origin/feature' by 1 commit.
```

The series has received thorough review from Phillip Wood (who identified and helped resolve refspec mapping issues) and maintainer approval from Junio C Hamano. All technical requirements are satisfied, with clean code organization and comprehensive test coverage. This represents the culmination of significant development and review effort to provide users with more complete branch tracking information.
