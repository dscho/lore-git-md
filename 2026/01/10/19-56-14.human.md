This is the final version of a feature patch series that enhances `git status` to show divergence from both upstream and push tracking branches. After 21 iterations of review and refinement, the series is now merge-ready with approval from Junio C Hamano and input from several other contributors.

The first patch refactors the branch comparison formatting logic into a new `format_branch_comparison()` helper function, centralizing the display logic while maintaining all existing behavior. The second patch implements the new push tracking display, adding support for showing divergence information from the push remote when it differs from the upstream. The implementation handles remapped push refspecs and maintains the same output format as the existing upstream tracking display.

The series comes with extensive test coverage (262 new test lines) and has addressed all feedback from reviewers over its long review cycle. Key contributors to the discussion included Ben Knoble for workflow advice, Phillip Wood for code review, and Patrick Steinhardt for flag convention guidance. The patches cleanly extend `git status` output while following project conventions, and all outstanding issues have been resolved.

This represents a useful quality-of-life improvement for users who work with different upstream and push remotes, giving them visibility into both relationships directly from `git status`. The implementation is careful to maintain backward compatibility and follows the project's established patterns for this type of feature.
