This is a memory leak fix in the shallow repository handling code, part of Samo Pogačnik's 2-patch series addressing shallow fetch depth issues. The patch adds a single line to properly clean up the `object_array` stack in `get_shallow_commits()` that was previously leaking memory. 

The fix is straightforward - just adding `object_array_clear(&stack)` before the function returns. The commit message notes this was caught by the leak-checking CI tests (linux-leaks and linux-reftable-leaks) when running the new test cases from the companion patch in the series. 

This appears to be a well-contained fix that properly addresses the memory management issue while maintaining the existing behavior.
