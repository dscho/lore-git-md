This is the second patch in Harald Nordgren's 2-part series to enhance `git status` output, now merge-ready after 22 iterations of review. The patch implements push tracking branch comparison in `git status` when the push destination differs from the upstream branch.

The core change adds a new `get_remote_push_branch()` helper to resolve the push tracking branch, then extends `format_tracking_info()` to show both upstream and push comparisons when they differ. The output maintains the existing format but adds a new line for push tracking info, with appropriate advice messages for each case (ahead, behind, diverged). The implementation handles remapped push refspecs and maintains all existing behavior.

Key technical details:
- New `BRANCH_MODE_PULL`/`BRANCH_MODE_PUSH` flags control which comparisons to show
- `format_branch_comparison()` now takes flags parameter to customize advice messages
- 262 lines of new test coverage in t6040-tracking-info.sh verify all cases
- Handles complex scenarios like remapped refspecs and multiple remotes
- Preserves existing quick mode (`--no-ahead-behind`) behavior

The patch has been thoroughly reviewed by Junio C Hamano (who provided final naming guidance), Ben Knoble, Phillip Wood and others through 22 iterations. All feedback has been incorporated and the implementation follows project conventions. This completes the series' goal of showing both upstream and push tracking relationships in `git status` output when they differ.
