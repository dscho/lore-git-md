Feature enhancement to `git status` showing push tracking divergence, now merge-ready after extensive review.

This is the 22nd iteration of Harald Nordgren's series to enhance `git status` to show divergence from both upstream and push tracking branches when they differ. The implementation is now finalized and merge-ready after incorporating feedback from Junio C Hamano, Ben Knoble, Phillip Wood, and others over 21 previous versions.

The first patch refactors the branch comparison formatting logic into a new `format_branch_comparison()` helper function, centralizing the display logic while maintaining all existing behavior including quick mode and "upstream is gone" cases. The second patch implements the push tracking display, adding a new `get_remote_push_branch()` helper and extending `format_tracking_info()` to handle both upstream and push relationships with comprehensive test coverage.

Key technical details include:
- Clean separation of concerns between branch state handling and display formatting
- BRANCH_MODE_PULL/PUSH flags to control display
- Support for remapped push refspecs
- 262 lines of new test coverage in t6040-tracking-info.sh
- Maintained output format consistency with existing behavior

The series has been through extensive review cycles addressing all technical concerns, with the only remaining note being a pre-existing pluralization issue that was deemed acceptable to leave for future work. The implementation follows project conventions and is ready for merging into the next release cycle.
