Refactoring patch for `git status` tracking info display, part of a 2-patch series that has undergone extensive review (20 iterations). This first part extracts the branch comparison formatting logic into a new `format_branch_comparison()` function, preparing for the second patch which will add push remote tracking information.

The changes here are purely structural - no behavior changes. The original `format_tracking_info()` function is split to isolate the message generation logic, making it reusable for both upstream and push tracking comparisons. The new helper takes consolidated parameters in a cleaner interface (addressing Junio C Hamano's earlier feedback about parameter organization).

This represents the final form of the refactoring after incorporating all review feedback, including naming improvements (sti -> cmp_fetch), proper handling of the "upstream is gone" case, and maintaining all existing behavior including the quick mode (AHEAD_BEHIND_QUICK). The patch follows Git coding standards and has been approved by Junio for structure.
