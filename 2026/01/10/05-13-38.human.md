This is the second patch in Samo Pogačnik's v3 series addressing shallow repository issues, specifically focusing on fixing relative-depth fetching (`--deepen`). The patch has undergone multiple rounds of review from Patrick Steinhardt and Junio C Hamano.

The key change is a new `get_shallows_depth()` function that properly handles both absolute and relative depth calculations during fetch operations. The patch eliminates the redundant `get_reachable_list()` function and introduces a more robust approach that tracks minimum depth of existing shallow commits using a new `commit_depth` slab. This fixes cases where deepening beyond merged branches could leave some shallow commits unreachable.

The implementation includes comprehensive test coverage in t5500-fetch-pack.sh, including a new test case "fetching deepen beyond merged branch" that demonstrates the corrected behavior. The patch also properly handles graft points and maintains backward compatibility with absolute depth fetches.
