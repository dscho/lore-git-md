This is the first patch in a 2-part series that enhances `git status` to show divergence from both upstream and push tracking branches. After 22 iterations of review, the series is now merge-ready with final approval from Junio C Hamano.

The patch refactors the branch comparison formatting logic in `remote.c` to prepare for the push tracking functionality coming in patch 2/2. It extracts the core formatting code into a new `format_branch_comparison()` helper function that will be reused for both upstream and push tracking displays. The refactoring maintains all existing behavior including quick mode (AHEAD_BEHIND_QUICK) and "upstream is gone" cases, while cleaning up the separation of concerns - the helper focuses purely on display formatting while the caller handles upstream state.

Key changes include:
- Moving the comparison message generation into a reusable function
- Renaming variables to `cmp_fetch` per Junio's naming guidance
- Preserving all output formats and advice messages
- Keeping the existing pluralization behavior (noted as a pre-existing issue for future work)

The patch has been thoroughly reviewed by multiple contributors including Ben Knoble and Phillip Wood, with all feedback incorporated over the 22 iterations. This foundational refactoring enables the push tracking functionality to be cleanly added in the next patch while maintaining the existing user experience.
