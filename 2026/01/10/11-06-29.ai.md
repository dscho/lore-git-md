This is a refactoring patch in Harald Nordgren's series to enhance `git status` with push tracking branch display. The patch introduces a `struct format_branch` to consolidate variables used in branch comparison formatting, addressing Junio C Hamano's feedback about naming consistency between the fetch and push tracking cases.

The key changes:
- Creates a new `struct format_branch` containing all variables needed for branch comparison (ours/theirs counts, comparison result, branch name)
- Updates `format_branch_comparison()` to take the struct instead of individual parameters
- Maintains all existing behavior while improving code organization
- Keeps the same output messages and advice strings
- Follows through with Junio's naming suggestion by using `sti` -> `cmp_fetch` in the struct
- Preserves the quick mode (AHEAD_BEHIND_QUICK) special case handling
- Still handles the "upstream is gone" case separately in the caller

The patch represents a clean structural improvement that sets up for the push tracking functionality in the second patch while addressing the maintainer's concerns about variable naming. It's a focused refactoring that doesn't change behavior but makes the code more maintainable for the upcoming push tracking addition.
