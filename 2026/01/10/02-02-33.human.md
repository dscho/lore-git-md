This is a refactoring patch in a series that enhances `git status` to show divergence from both upstream and push tracking branches. The patch extracts the `format_branch_comparison()` function from `format_tracking_info()` in `remote.c`, improving modularity while maintaining existing behavior. Key changes include:

- Separates message formatting from advice generation
- Converts the opaque `sti` parameter to a clearer `up_to_date` boolean
- Moves the "upstream is gone" case to the caller
- Preserves all branch state handling (up-to-date, ahead, behind, diverged)
- Retains quick mode (AHEAD_BEHIND_QUICK) special cases

Junio C Hamano notes in his review that while the "up to date" case could theoretically be moved to the caller like the "upstream is gone" case was, the current structure reads well and properly eliminates the redundant `(!ours && !theirs)` check. The patch represents the culmination of 19 review iterations with input from multiple contributors, demonstrating careful attention to Git's coding style and conventions.

This refactoring lays the groundwork for the second patch in the series, which will implement the actual push tracking display functionality. The extensive review history suggests this is a well-vetted change that maintains backward compatibility while improving code organization.
