This is the first patch in a 2-part series that refactors `git status`'s branch comparison display to show divergence from both upstream and push tracking branches. The series has gone through 19 iterations of review, with this particular patch focusing on structural improvements to prepare for the new functionality.

The patch introduces a `struct format_branch` to consolidate the various variables used in branch comparisons (counts, branch name, comparison result) that were previously passed individually. It follows Junio C Hamano's naming suggestion by renaming `sti` to `cmp_fetch` in the new struct. The refactoring maintains all existing behavior while improving code organization, preserving quick mode special cases and handling the "upstream is gone" case in the caller.
