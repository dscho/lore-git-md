Refactoring patch in Harald Nordgren's series to enhance `git status` tracking info display. This is the first of two patches in the v22 iteration, which has received extensive review and is now merge-ready.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` helper function. This prepares for the second patch that will add push tracking information while maintaining the existing output format. Key changes:

- Moves all message generation into the new helper while keeping the same output strings
- Lets the main function handle upstream state checks ("gone" case)
- Uses consistent variable naming (`cmp_fetch`) as directed by Junio
- Preserves all existing behavior including quick mode and advice messages
- Maintains the same pluralization handling (with one known issue noted for future work)

The refactoring cleanly separates concerns - the caller checks upstream state while the helper focuses purely on display formatting. This sets up the infrastructure needed for the second patch to add push tracking info without duplicating formatting logic. The changes have been thoroughly reviewed through 22 iterations, with final approval from Junio Hamano.
