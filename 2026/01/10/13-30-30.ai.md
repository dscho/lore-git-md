This is the first of two patches in Harald Nordgren's final iteration (v20) of a series to enhance `git status` with push tracking branch divergence information. The patch refactors the core comparison logic in preparation for the new feature.

The refactoring extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. The new function takes a consolidated set of parameters (up_to_date flag, ours/theirs counts, branch name, etc.) and handles all the output formatting cases that were previously inline. This prepares the codebase to handle both upstream and push tracking comparisons in a unified way.

Key technical details:
- Introduces `format_branch_comparison()` helper function
- Maintains all existing behavior including quick mode (AHEAD_BEHIND_QUICK)
- Handles "upstream is gone" case in the caller
- Follows Git coding standards
- Includes final pluralization fix for divergence messages
- Represents the culmination of 20 review iterations

The patch has been thoroughly reviewed by Junio C Hamano, Ben Knoble, and Phillip Wood, with all technical concerns addressed. It's now in its final, merge-ready state as part of this long-running effort to improve `git status` output. The second patch in the series will build on this refactoring to add the push tracking display functionality.
