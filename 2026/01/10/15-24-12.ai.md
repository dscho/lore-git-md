This is the first patch in Harald Nordgren's 2-part series to enhance `git status` tracking information, now in its 21st iteration. The patch refactors the branch comparison formatting logic in preparation for adding push remote tracking display in the second patch.

The change extracts the comparison formatting from `format_tracking_info()` into a new `format_branch_comparison()` helper function. This centralizes the logic that generates the "ahead/behind/diverged" messages while maintaining all existing behavior including the quick mode (AHEAD_BEHIND_QUICK) and "upstream is gone" cases. The refactoring makes the code more maintainable by separating concerns - the caller now handles the upstream state while the helper focuses purely on formatting the comparison.

Key technical details include renaming the `sti` variable to `cmp_fetch` for clarity (a change made in response to Junio Hamano's feedback), preserving all existing output formats, and maintaining the same advice messages. The patch has undergone extensive review over 21 versions with input from Junio Hamano, Ben Knoble, and Phillip Wood, and appears ready for merging as part of the larger feature.

This is a clean refactoring that enables the subsequent push tracking functionality while being careful not to change any existing behavior. The separation of concerns should make the code easier to maintain and extend going forward.
