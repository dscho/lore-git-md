This is the second and merge-ready patch in Harald Nordgren's 2-part series to enhance `git status` output with push tracking branch comparisons. After 20 iterations of review with input from Junio C Hamano, Ben Knoble, Phillip Wood and others, the implementation is now finalized.

The patch extends `git status` to show divergence information relative to both the upstream tracking branch (as before) and the push destination tracking branch (new) when they differ. The output uses the same familiar format on a new line, with appropriate advice messages. For example, when tracking origin/main but pushing to origin/feature, it will show both relationships.

Key technical components include:
- New `get_remote_push_branch()` helper to resolve push tracking references
- Extended `format_tracking_info()` to handle both upstream and push comparisons
- BRANCH_MODE_PULL/PUSH flags to control display behavior
- Comprehensive 262-line test coverage for all edge cases
- Support for remapped push refspecs and multiple remote scenarios

The implementation builds on the refactoring from patch 1/2 and maintains all existing behavior while cleanly adding the new functionality. All review feedback has been addressed through the 20-iteration refinement process, with final optimizations to pluralization and advice display logic. The patch is now in its final form with no outstanding technical concerns.
