This is a bugfix patch series addressing issues with shallow repository fetching. The v3 cover letter from Samo Pogačnik summarizes improvements to relative-depth fetching (`--deepen`) in shallow clones.

The series has already undergone thorough review from Patrick Steinhardt and maintainer Junio C Hamano, with all feedback addressed. The key changes in this version are formatting improvements to the commit message examples (indenting commit graphs and shallow commit lists) as suggested by Junio.

The first patch fixes a memory leak in `get_shallow_commits()` by properly freeing an `object_array`. The second patch implements correct relative-depth fetching by:
- Adding a new `get_shallows_depth()` function to calculate relative depths
- Removing redundant `get_reachable_list()`
- Sharing logic between depth calculation functions
- Adding test coverage in t5500-fetch-pack.sh

The series demonstrates a clear problem (incorrect shallow commits when deepening beyond merged branches) and provides a clean solution that unifies absolute and relative deepening behavior. The patches appear well-tested and ready for integration, having addressed both technical correctness and documentation quality.
