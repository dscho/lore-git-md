This is the first of two patches in Harald Nordgren's final v21 series to enhance `git status` tracking information. After 21 iterations incorporating feedback from Junio Hamano, Ben Knoble, and Phillip Wood, this preparatory refactoring is now merge-ready.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` helper function. This centralizes the display logic for ahead/behind/diverge messages in preparation for the second patch that will add push remote tracking. The refactoring maintains all existing behavior including quick mode (AHEAD_BEHIND_QUICK) and "upstream is gone" handling.

Key changes include:
- Renamed `sti` variable to `cmp_fetch` for clarity (per Junio's suggestion)
- Kept identical output formatting
- Preserved all advice messages
- Maintained type safety and control flow

The clean separation of concerns here sets up cleanly for the push tracking functionality in patch 2/2. With all review feedback addressed and comprehensive test coverage, this foundational change is now in its final polished state.
