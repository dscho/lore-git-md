This is a test patch in a 12-part series refactoring Git's hook subsystem. It adds comprehensive test coverage for hook output streams, verifying that different hook types write to the expected stdout/stderr destinations. The tests cover both client-side hooks (like pre-push and commit-related hooks) and server-side hooks (like pre-receive and update), with special attention to the pre-push hook's unique requirement for separate stdout/stderr streams.

The patch follows up on earlier feedback from Patrick Steinhardt and Junio Hamano about ensuring proper coverage for output stream behavior. While the tests are thorough, Junio notes some minor concerns about long lines and suggests breaking up the test steps for better debuggability. The patch maintains the series' high quality standard with clear test organization and good commit message attribution.

This foundational test work supports the larger hook refactoring effort to standardize the hook API and enable future features like parallel execution. The tests will help prevent regressions as the hook subsystem evolves.
