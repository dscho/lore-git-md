This is the seventh iteration of a major hook subsystem refactoring series, now reduced to 12 patches (from 13 in v6) with Adrian Ratiu and Emily Shaffer as primary authors. The series converts all remaining Git hooks to use the new `hook.h` API, completing the foundation for future config-based hooks and parallel execution support.

The v7 version incorporates significant rework of the sideband output and child process communication based on Jeff King's design suggestions. Key technical changes include:
- New test coverage for hook output streams (patch 1)
- Support for separate stdout/stderr streams to maintain pre-push hook compatibility (patch 6)
- Removal of now-unused includes from `refs.c` (patch 8)
- Addition of a jobs option for parallel execution (patch 9)
- Improved child process stdin polling (patch 10)

The series has already passed all review and CI checks, with approvals from both Patrick Steinhardt and Junio Hamano. The current changes represent final polish - like the header cleanup spotted by SZEDER Gabor - rather than substantive rework. This positions the hook subsystem for the next phase of development (config-based hooks and parallel execution) while maintaining backward compatibility with existing hook implementations.

The patch organization shows careful attention to the migration path, with core infrastructure changes coming first (run-command helpers, stream handling) followed by individual hook conversions. The receive-pack changes in particular demonstrate the complexity of maintaining sideband output during the transition. With all major technical concerns addressed and consensus reached, this series appears ready for integration.
