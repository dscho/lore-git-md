This is a test patch in the hook subsystem refactoring series, specifically adding test cases for hook output stream behavior. It's part of a larger v7 series that has already gone through extensive review and is nearing merge readiness.

The patch introduces comprehensive test coverage for how Git hooks handle stdout and stderr streams, addressing a gap that previously led to regressions during the hook API conversion. It tests two distinct behaviors: (1) the pre-push hook's special case where stdout and stderr remain separate, and (2) all other hooks where stdout is redirected to stderr for backward compatibility. The tests cover both client-side hooks (pre-commit, post-commit, etc.) and server-side hooks (pre-receive, update, etc.), verifying the output streams through various Git operations that trigger the hooks.

The test design follows suggestions from both Patrick Steinhardt and Junio Hamano, using helper functions `check_stdout_separate_from_stderr` and `check_stdout_merged_to_stderr` to validate the expected stream behavior. The test scenarios are thorough, exercising hooks through commits, checkouts, merges, rebases, patch application, and push operations. This foundational test work supports the series' broader goal of standardizing hook execution while maintaining compatibility.
