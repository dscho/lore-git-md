This is part 5/14 of Patrick Steinhardt's ongoing ODB abstraction series (v3), which refactors Git's object storage layer to support pluggable backends. The patch extracts a helper function `packfile_store_for_each_object_internal()` from `for_each_packed_object()` to prepare for upcoming changes that will make packfile iteration backend-agnostic.

The change is a straightforward refactoring that splits the existing packed object iteration logic into two parts: a new internal function that handles iteration for a single packfile store, and the original function that coordinates across all stores. The behavior remains identical - this is purely structural preparation for future patches in the series.

The patch follows the series' established pattern of methodical, incremental changes with clear commit messages explaining each step.
