This is a test patch in a hook subsystem refactoring series. It adds comprehensive coverage for verifying how Git hooks write to stdout and stderr streams, addressing a gap that previously led to regressions during the hook API conversion.

The patch introduces new test cases that systematically check output stream behavior for all major hook types, including client-side hooks (pre-push, commit-related, rebase, etc.) and server-side hooks (pre-receive, update, etc.). It distinguishes between hooks that expect separate stdout/stderr streams (like pre-push) versus those that merge stdout to stderr (most others).

The tests are well-structured with helper functions (`check_stdout_separate_from_stderr` and `check_stdout_merged_to_stderr`) that make the output verification clear and maintainable. The test scenarios cover realistic workflows that trigger multiple hooks in sequence, ensuring the stream behavior remains correct across complex operations.

This patch represents the final polish on the hook output stream handling before the series gets merged, having incorporated feedback from Jeff King and others in previous iterations. The thorough test coverage will help prevent future regressions as the hook subsystem continues to evolve.
