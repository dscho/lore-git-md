Documentation patch finalizing the linter update for conditional blocks in man pages. This is the last piece in a series that started with D. Ben Knoble's change to clean up `git-replay` documentation by conditionally excluding a formatting section when included from other man pages.

Jean-Noël Avila simplifies the `lint-gitlink.perl` script to ignore all conditional block macros (`ifdef`, `ifndef`, `endif`) at the start of lines, rather than trying to parse them as inline macros. This follows Junio C Hamano's earlier adjustment to handle multiple-attribute conditionals and completes the tooling support needed for the documentation pattern established by both `git-replay` and `git-shortlog`.

The change is straightforward - it skips any line starting with these block macros before checking for malformed linkgit references. This approach is both more robust and more efficient than the previous regex that tried to handle conditionals inline. With this final tweak, all parties have signed off and the series appears ready for merging.
