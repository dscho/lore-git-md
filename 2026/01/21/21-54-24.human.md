Hook subsystem refactoring (v7). This is the final iteration of Adrian Ratiu and Emily Shaffer's series to convert all remaining Git hooks to use the new `hook.h` API, following extensive review and approval from Patrick Steinhardt and Junio Hamano. The series was previously merged-then-reverted to incorporate additional fixes.

Key changes in v7 include a significant rework of sideband output and child process communication based on Jeff King's design, plus several squashed fixes from previous versions. The series now:
- Adds tests for hook output streams
- Allows separate stdout/stderr streams (important for pre-push hook compatibility)
- Introduces a jobs option for parallel execution
- Improves child process polling to handle both input and output
- Converts the remaining receive-pack hooks to the new API

The changes touch core hook execution infrastructure in `run-command.c` and `hook.[ch]`, plus conversions in `transport.c`, `refs.c`, `sequencer.c`, and `receive-pack.c`. The work maintains backward compatibility while laying groundwork for future features like config-based hooks and parallel execution.

This appears ready for integration with all CI passing and no outstanding objections. The thorough review process has produced a clean implementation that addresses all identified issues while preserving existing behavior.
