This is part 12/14 of Patrick Steinhardt's ODB abstraction series, focusing on converting `pack-objects` to use the new object storage iteration APIs. The patch refactors cruft pack handling to use `packfile_store_for_each_object()` instead of the older `for_each_packed_object()` approach.

The key change simplifies the cruft pack object enumeration by leveraging the mtime tracking infrastructure introduced in part 11. The new version:
1. Uses a shared `object_info` struct to pass mtimes through the iteration callback
2. Eliminates manual mtime lookup logic that previously distinguished between cruft packs and regular packs
3. Switches to iterating through the new `packfiles` list from the ODB source rather than using the global packed_git list

The implementation demonstrates how the ODB abstraction provides cleaner access to object metadata while reducing code duplication. This continues the series' pattern of methodically converting subsystems to use the new storage APIs while maintaining identical functionality. The change is particularly relevant for cruft pack handling, which benefits from the unified mtime access pattern established in the previous patch.
