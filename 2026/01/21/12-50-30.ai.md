This is the final patch (14/14) in Patrick Steinhardt's v3 series abstracting Git's object database (ODB) layer. The series systematically converts Git's object storage to support pluggable backends, with this patch completing the work by removing now-unused iteration functions.

The patch removes `for_each_loose_object()` and `for_each_packed_object()` after converting all callers to use the new ODB abstraction APIs introduced earlier in the series. It also inlines `packfile_store_for_each_object_internal()` since it now has only one caller, simplifying the callback indirection. The changes touch four files (`object-file.c`, `object-file.h`, `packfile.c`, `packfile.h`) with a net reduction of 97 lines.

This represents the culmination of the technical work in the ODB abstraction series, having methodically converted all object iteration to use the new unified APIs. The removal of these functions demonstrates the series' success in eliminating redundant code paths while maintaining functionality. With this patch, the groundwork is complete for future work on pluggable object storage backends.
