This is a technical response about hook access control in Git. Jeff King (Peff) addresses Chris Packham's question about distinguishing push sources in pre-receive hooks when multiple automated services share the same user identity. 

Peff confirms Git itself doesn't track push sources but suggests several transport-specific workarounds. For SSH connections, he mentions examining $SSH_CLIENT or using authorized_keys environment variables to differentiate clients. For HTTP pushes, he suggests checking $REMOTE_ADDR or $REMOTE_USER, with additional pointers to Apache configuration examples in git-http-backend documentation.
