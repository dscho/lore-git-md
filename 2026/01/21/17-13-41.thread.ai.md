Key user-facing changes: `git maintenance is-needed` subcommand, experimental `git replay` with transactional ref updates by default, `git blame --diff-algorithm` config, new data model documentation, whitespace handling improvements. Underlying technical work: packfile storage using `strmap`, ODB restructuring for pluggable backends (Patrick Steinhardt), `the_repository` removal progress, memory handling improvements in diff/object code, test modernization. Bug fixes across submodules (hash validation), ort merge strategy, fsck ref validation, memory safety, platform-specific issues (macOS iconv, Windows symlinks). Documentation updates include Jean-Noel Avila's man page synopsis-style conversion, 20+ doc-specific changes noted in release notes. Release continues Git's pattern of backward-compatible modernization with focus on memory safety, platform support, and test coverage (100+ test-related changes).
