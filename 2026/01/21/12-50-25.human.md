Part 9/14 of Patrick Steinhardt's ODB abstraction series, this patch converts promisor object enumeration to use the new `odb_for_each_object()` API. The change affects three key areas: `packfile.c`, `repack-promisor.c`, and `revision.c`, where promisor objects are handled during fsck, repacking, and revision walking.

The patch demonstrates the practical benefits of the ODB abstraction by showing how the unified API simplifies code that previously used `for_each_packed_object()` with the `PROMISOR_ONLY` flag. The changes maintain all existing functionality while reducing code duplication - the `packfile.c` changes alone remove 25 lines while adding 30, with the net reduction coming from shared callback handling.

This continues the series' pattern of methodically converting subsystems to the new API while preserving behavior. The changes are straightforward mechanical conversions, following the template established in earlier patches. Reviewers Justin Tobler and Karthik Nayak have been actively engaged in the series, and this patch appears consistent with their previous feedback.
