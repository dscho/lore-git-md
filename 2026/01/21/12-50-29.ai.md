This is part 13/14 of Patrick Steinhardt's ODB abstraction series, converting the reachability checking code to use the new object storage iteration APIs. The patch refactors `reachable.c` to use `odb_for_each_object()` for finding recent objects, eliminating separate paths for loose and packed object handling.

Key changes:
- Replaces `for_each_loose_object()` and `for_each_packed_object()` with a single `odb_for_each_object()` call
- Uses the `object_info` struct (introduced in part 11) to access mtimes and object types consistently
- Simplifies the code by removing redundant mtime lookup logic for cruft packs
- Maintains the same functionality while reducing code by 55 lines (90 deletions, 35 insertions)

The patch demonstrates how the ODB abstraction unifies object iteration across storage types while preserving specialized behaviors like in-core pack handling. It continues the series' pattern of methodically converting subsystems to the new APIs while maintaining backward compatibility. With this change, only one patch remains in the series before it can be considered for merging.
