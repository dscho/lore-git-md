Performance improvement and refactoring in Patrick Steinhardt's ODB abstraction series (part 13/14). This patch converts the reachability checking code in `reachable.c` to use the new `odb_for_each_object()` API introduced earlier in the series, continuing the systematic modernization of Git's object storage layer.

The change simplifies the object traversal logic by replacing separate paths for loose and packed objects with a unified interface. The key improvements are:

1. Eliminates duplicate mtime lookup code by using the shared `object_info` struct (introduced in part 11)
2. Removes special-case handling for cruft packs by leveraging the ODB's consistent metadata access
3. Reduces code size by 55% (90 lines removed) while maintaining identical functionality
4. Uses the established pattern of replacing global state (`the_repository->objects`) with repository-specific object storage access

This is the sixth major subsystem converted in the series, following similar changes to `pack-objects`, `cat-file`, commit-graph, `fsck`, and promisor object handling. The patch demonstrates how the ODB abstraction simplifies specialized cases like reachability checking by providing consistent object metadata access.

The change is well-contained and follows the established pattern of the series. With only one patch remaining (14/14), the ODB abstraction work appears to be nearing completion, having systematically converted nearly all of Git's object storage interactions to the new API.
