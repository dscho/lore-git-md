This is part 4/14 of Patrick Steinhardt's ongoing ODB abstraction series, introducing a unified interface for iterating through objects across different storage backends. The patch adds `odb_source_loose_for_each_object()` as a more flexible alternative to the existing `for_each_loose_object()`, designed to work with the new ODB abstraction layer.

The new function accepts a callback that receives both the object ID and a populated `struct object_info`, matching the behavior of direct object reads. This prepares for unifying iteration across loose and packed objects in future patches. The implementation handles existing flag conditions (PROMISOR_ONLY, LOCAL_ONLY) and maintains current behavior while providing a more extensible interface.

Key technical details:
- Introduces `odb_for_each_object_cb` callback type in odb.h
- Adds wrapper struct to pass callback data through the existing loose object iteration
- Preserves all existing flag behavior while adding object info population
- Keeps backward compatibility by retaining `for_each_loose_object()` temporarily
- Touches object-file.c, object-file.h, and odb.h with 64 net new lines
