This is part 8/14 of Patrick Steinhardt's ODB abstraction series, converting `git fsck` to use the new unified object iteration API introduced in part 7. The patch refactors two key operations in `builtin/fsck.c` that previously used separate loose and packed object iteration paths.

The changes replace `for_each_loose_object()` and `for_each_packed_object()` calls with the new `odb_for_each_object()` API in two contexts: marking unreachable objects during connectivity checks and marking all objects in connectivity-only mode. The patch demonstrates the simplification possible with the unified API, reducing 45 lines of code while maintaining identical behavior.

Key technical details:
- Adapts callback signatures to match `odb_for_each_object()`'s `(oid, object_info*, data)` pattern
- Preserves all existing flag handling and object marking logic
- Removes redundant wrapper functions that previously bridged between loose/packed callbacks
- Maintains the same alternates handling via `odb_prepare_alternates()`

This conversion follows the series' pattern of methodically migrating subsystems to the new ODB API while validating behavior remains unchanged. The changes are straightforward mechanical conversions that leverage the groundwork laid in earlier parts of the series.
