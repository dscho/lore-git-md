Refactoring patch in the hook subsystem series. This change introduces a helper function `child_is_working()` to check parallel child process states, replacing repeated direct state checks with a more readable abstraction. The patch extracts the anonymous `children` array element type into a named `struct parallel_child` containing the process state, child process data, error buffer, and opaque data pointer.

Junio Hamano suggests dropping "first" from the commit message since the helper's position in the sequence isn't particularly relevant. The change is mechanical - converting all instances of `pp->children[i].state == GIT_CP_WORKING` to use the new helper - and touches several functions in `run-command.c` that manage parallel processes, including output buffering and cleanup.

This is part of the larger hook subsystem refactoring effort to support parallel hook execution, building on prior work from multiple contributors. The change improves code readability while maintaining existing behavior, with no functional changes at this stage. The helper will be used by subsequent patches in the series that implement more complex parallel process management.
