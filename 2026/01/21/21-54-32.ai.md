This is part 8 of a 12-patch series refactoring Git's hook subsystem to use a standardized API. The patch converts the reference-transaction hook implementation from direct `run-command` usage to the new `hook.h` interface.

The change moves the hook's stdin feeding logic into a callback function `transaction_hook_feed_stdin()` that processes one ref update per invocation, streaming the data through the hook API's pipe mechanism. The implementation maintains all existing functionality while eliminating manual child process setup, signal handling, and hook path lookup. The callback approach allows for potential future batching of ref updates to optimize pipe throughput.

Key technical changes include:
- Removal of `run-command.h` and `sigchain.h` includes as they're no longer needed
- Introduction of `transaction_feed_cb_data` struct to track state across callback invocations
- Conversion from direct file descriptor writes to the hook API's `feed_pipe` callback mechanism
- Preservation of the hook's ref update format and error handling semantics

The patch carries sign-offs from both Emily Shaffer (original hook API author) and Ævar Arnfjörð Bjarmason (major contributor), indicating technical consensus. This continues the series' pattern of incrementally converting each hook type while maintaining backward compatibility and improving code reuse through the shared hook infrastructure.
