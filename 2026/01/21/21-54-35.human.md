Hook subsystem conversion for receive-pack. This is patch 11/12 in a series refactoring Git's hook system to use a standardized API, with this part focusing on converting receive-pack's update and post-update hooks. The changes replace direct child_process usage with the new run_hooks_opt interface while maintaining sideband output handling for remote clients.

The patch demonstrates the series' attention to backward compatibility and output streaming - it preserves the existing sideband behavior while using the new hook infrastructure. The implementation handles both sequential execution (current default) and lays groundwork for future parallel execution, with careful management of stderr redirection to maintain the sideband muxer functionality that Jeff King helped design.

This continues the pattern seen throughout the series of methodically converting each hook type while addressing real-world constraints like remote protocol requirements. The changes are focused on receive-pack.c, touching both the update and post-update hook handling with similar patterns of sideband-aware I/O redirection. The patch carries sign-offs from key contributors including Emily Shaffer and Ævar Arnfjörð Bjarmason, indicating broad consensus on the approach.
