The affected functions are spread across object-file.c/h and packfile.c/h, touching core object database operations like reading object info and iterating through packed objects.

This is a straightforward type correction that follows established patterns in the codebase. The patch is small (8 lines changed) and focused, with no behavioral changes - it's purely about type consistency as part of the larger ODB abstraction effort.
