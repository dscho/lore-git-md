This is part 6/14 of Patrick Steinhardt's v3 series refactoring Git's object database (ODB) to support pluggable backends. The patch introduces `packfile_store_for_each_object()`, completing the parallel iteration pattern for packed objects that was established for loose objects in part 4.

The new function provides the same callback interface as its loose object counterpart, taking a `struct object_info` parameter and using consistent flags. This symmetry is key to the series' goal of unifying object iteration across storage backends. The implementation wraps existing packed object iteration with a new callback adapter that handles object info population, maintaining all existing flag behaviors (LOCAL_ONLY, PROMISOR_ONLY).

The changes are focused in packfile.c (48 new lines) and packfile.h (14 new lines), with careful attention to preserving the existing `for_each_packed_object()` behavior while the transition is in progress. The patch follows the series' established pattern of methodical, incremental refactoring that maintains compatibility at each step.

This continues the series' steady progress toward complete ODB abstraction, with Justin Tobler and Karthik Nayak providing ongoing review. The parallel loose/packed iteration patterns now in place set up the planned unification in upcoming patches.
