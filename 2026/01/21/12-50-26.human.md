This is part 10/14 of Patrick Steinhardt's ongoing ODB abstraction series, continuing the effort to enable pluggable object storage backends in Git. The patch focuses on migrating remaining callers from the old `for_each_loose_object()` and `for_each_packed_object()` functions to the new ODB API.

The changes affect two key areas: `git cat-file --batch-all-objects` and commit-graph generation. In both cases, the patch replaces direct calls to the old iteration functions with the new `odb_source_loose_for_each_object()` and `packfile_store_for_each_object()` APIs. The conversion maintains existing behavior while preparing for the eventual removal of the old functions.

The patch demonstrates the ODB abstraction's flexibility by handling both loose and packed objects through a unified callback interface. Some callers still can't use the fully generic `odb_for_each_object()` yet, as noted in the commit message - these will be addressed in future work. The changes are mechanical but thorough, touching core functionality in ways that have been carefully validated by earlier patches in the series.
