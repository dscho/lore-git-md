Bugfix for histogram diff algorithm edge case. This patch from Junio C Hamano addresses a subtle issue in the xdiff implementation where the histogram diff algorithm can produce redundant output when shifting change groups during compaction. The problem occurs when shifted groups create new matching sections that should be marked as unchanged rather than included in the diff.

The fix adds logic to detect when shifting has created new matching groups and re-diffs those sections using Myer's algorithm while preserving all original diff flags. This ensures the output remains minimal and correct. The patch includes thorough test coverage in t4073-diff-shifted-matched-group.sh with multiple test cases.

While this edge case affects less than 1% of diffs in practice, the incorrect output is clearly undesirable when it occurs. The implementation carefully handles flag preservation (like --ignore-all-space) and only applies to histogram diff since other algorithms either produce minimal diffs naturally (Myer's) or use anchors that prevent this issue (patience).

Junio suggests the code might be clearer if the new logic were extracted into a helper function called from the relevant case in the existing if/else cascade, but the core solution appears sound. This is a focused fix for a specific edge case in the diff machinery that improves output quality without introducing new complexity.
