This is the maintainer's merge notification for a completed bugfix series from Karthik Nayak and Jeff King that restores detailed error messages in batched reference updates. The series addresses a regression where `git update-ref --batch-updates`, `git fetch`, and `git receive-pack` had lost their detailed error reporting when reference operations failed.

Junio Hamano confirms the v3 series looks good and is being merged. The changes include:
- Preserving detailed error messages while maintaining backward compatibility
- Using a list to maintain deterministic ordering of fetch status output
- Comprehensive test coverage for various failure scenarios

The fixes build on earlier work introducing batched updates while restoring the more informative error reporting that existed before the regression. The series has gone through multiple iterations with input from several contributors, and now addresses all identified issues with the error message propagation.
