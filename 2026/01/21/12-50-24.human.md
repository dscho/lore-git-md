This is part 8/14 of Patrick Steinhardt's ODB abstraction series, converting `git fsck` to use the new unified object iteration API introduced in part 7. The patch refactors two key loops in `builtin/fsck.c` that previously used separate functions for loose and packed object iteration (`for_each_loose_object()` and `for_each_packed_object()`), replacing them with the new `odb_for_each_object()` interface.

The changes are straightforward mechanical conversions that demonstrate the benefits of the unified API - the code duplication between loose and packed object handling is eliminated, reducing the file by 45 lines while maintaining identical behavior. The patch preserves all existing functionality, including the connectivity checking logic that marks unreachable objects.

This continues the series' pattern of methodically migrating subsystems to the new ODB interface while maintaining strict behavior preservation. The changes are well-contained to `fsck` internals and don't introduce any user-visible differences. As with previous patches in the series, this appears to be a clean, focused refactoring that moves the ODB abstraction effort forward.
