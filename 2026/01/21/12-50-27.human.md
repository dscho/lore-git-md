This is part 11/14 of Patrick Steinhardt's ODB abstraction series, introducing mtime tracking for objects as part of the ongoing effort to enable pluggable object storage backends.

The patch adds a new `mtimep` field to `struct object_info` that callers can use to request an object's modification time. This is particularly useful for pruning unreachable objects, where the mtime helps determine which objects are candidates for removal. The implementation handles both loose objects (using filesystem mtime) and packed objects (using packfile mtime or the special ".mtimes" file for cruft packs).

The changes touch core object storage code paths, modifying `object-file.c`, `odb.c`, `odb.h`, and `packfile.c` to support the new field while maintaining backward compatibility. The implementation carefully handles edge cases like quick object existence checks and cached objects.

This continues the series' pattern of methodical, well-contained changes that build toward the larger ODB abstraction goal. The patch follows the established style of the series and includes clear documentation of the new field's purpose. As with previous parts, it maintains existing functionality while extending the API in a way that will support future backend implementations.
