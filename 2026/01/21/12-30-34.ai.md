Bugfix for `git stash` failing with intent-to-add files. This email confirms that a known issue where `git stash` fails when trying to stash new files added with `git add --intent-to-add` still persists in Git 2.52.0, having been first reported back in 2021 with Git 2.32.0.

The bug manifests when a user creates a new file, marks it with `--intent-to-add`, then attempts to stash it - Git incorrectly claims the file is "not uptodate" and refuses to create the stash. The original 2021 report from Claas Augner included clear reproduction steps and expected behavior, and this follow-up from Jille Timmermans verifies the issue remains unfixed in newer Git versions.

The thread references an external GitHub issue (#990 in the lint-staged project) where this behavior was encountered, suggesting it may affect real-world workflows. The persistence of this bug across multiple Git versions indicates it may require deeper changes to how `git stash` handles intent-to-add files, though the email doesn't propose a specific fix.
