This is a documentation patch that finalizes the linter improvements for handling conditional blocks in Git's AsciiDoc documentation. Jean-Noël Avila follows up on Junio C Hamano's earlier work by simplifying the `lint-gitlink.perl` script to better handle `ifdef`/`ifndef`/`endif` macros.

The change makes the linter more robust by completely skipping lines that start with these conditional block macros, rather than trying to parse them as inline elements. This prevents false positives when checking `linkgit:` macro usage and matches the actual AsciiDoc syntax where these are block-level constructs.

The patch is a straightforward improvement to documentation tooling that builds on the recent work to clean up `git-replay`'s manual page. It follows the pattern established for `git shortlog` documentation and is part of Git's ongoing effort to standardize and improve its documentation infrastructure. With this change, the linter will be more accurate when processing documentation files that use complex macro conditionals.
