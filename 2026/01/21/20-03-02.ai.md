This is a documentation patch that completes a series of changes to clean up the `git replay` manual page and related linter updates. The work follows patterns previously established for `git shortlog` documentation.

The patch series has two main components: First, D. Ben Knoble's change to `git-replay.adoc` removes an unnecessary "Commit Formatting" section by using conditional exclusion when the file is included via `rev-list-options.adoc`. Second, Jean-Noël Avila improved the documentation linter to properly handle the new multiple-attribute `ifndef` syntax used in this pattern.

All technical issues have been resolved through collaboration between the contributors. Junio C Hamano initially adjusted the linter to handle the new syntax, and Jean-Noël Avila later refined the approach to completely ignore conditional block macros (`ifdef`/`ifndef`/`endif`) rather than trying to parse them as inline elements. This makes the linter more robust against false positives while maintaining compatibility with both AsciiDoc processors.

The changes are now fully complete and ready for merging, with all parties having signed off. This work contributes to Jean-Noël Avila's broader effort to standardize Git's manual pages using consistent AsciiDoc markup patterns.
