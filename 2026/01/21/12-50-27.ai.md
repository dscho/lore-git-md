Feature patch in Patrick Steinhardt's ODB abstraction series (part 11/14), introducing mtime tracking for objects. This patch adds a new `mtimep` field to `struct object_info` to expose modification timestamps for objects, which will be used for pruning unreachable objects in a future commit.

The changes:
1. Adds `mtimep` to `struct object_info` to request/store object mtimes
2. Modifies loose object handling in `object-file.c` to populate mtimes from filesystem stats
3. Updates packed object handling in `packfile.c` to provide mtimes from either:
   - Packfile mtime for regular packs
   - `.mtimes` index for cruft packs
4. Preserves existing behavior when mtime isn't requested
5. Introduces a new helper `packed_object_info_with_index_pos()` to share logic between direct calls and iteration callbacks

This continues the series' pattern of careful, incremental changes to the object storage layer. The mtime tracking will be particularly useful for the upcoming pruning functionality, where knowing object ages is essential for expiration policies. The implementation handles both loose objects and packed objects (including the special cruft pack case) while maintaining the series' focus on backward compatibility.
