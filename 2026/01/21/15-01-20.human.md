This is part 10/10 of a refactoring series for the xdiff subsystem, with Rust interoperability considerations. Phillip Wood provides a brief review of Ezekiel Newren's patch that moves `xdl_cleanup_records()` and related code from xprepare.c to xdiffi.c.

The patch reorganizes code so that cleanup functionality specific to the classic diff algorithm is colocated with that algorithm's implementation. Phillip agrees with the logical change of calling `xdl_cleanup_records()` from within `xdl_do_classic_diff()`, though he doesn't have strong feelings about the code movement itself. He notes the patch should also remove the now-unused `#include "compat/ivec.h"` from xprepare.c.

This appears to be a straightforward final piece of Ezekiel's larger xdiff refactoring effort, with Phillip providing light review feedback. The change seems well-contained and uncontroversial, completing the series' goal of better organizing xdiff's internals while maintaining existing behavior.
