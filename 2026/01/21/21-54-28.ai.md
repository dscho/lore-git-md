Hook subsystem refactoring introducing stdin callback support. This patch (v7 04/12) from Adrian Ratiu and Emily Shaffer adds a callback mechanism for feeding stdin to hooks without filesystem involvement, complementing the existing path_to_stdin file-based approach. The key technical additions are a feed_pipe_fn callback interface in struct run_hooks_opt and associated plumbing to handle streaming input to child processes, particularly useful for large data volumes like pre-push hook inputs.

The implementation carefully maintains backward compatibility by making path_to_stdin and feed_pipe mutually exclusive (enforced via BUG checks) while adding the new streaming capability. It integrates with the parallel process infrastructure from the previous patch in the series, passing callback state through pp_task_cb. The changes touch both hook.c (adding the stdin handling logic) and hook.h (documenting the new callback API with detailed comments about memory management and usage patterns).

This represents a significant step in the hook subsystem modernization, solving real-world performance problems with large inputs while maintaining the series' focus on incremental, well-tested improvements. The patch carries sign-offs from both the original author (Emily Shaffer) and major contributors to the hook effort (Ævar Arnfjörð Bjarmason), indicating broad consensus on the approach.
