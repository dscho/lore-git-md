This is a major refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The 14-part series introduces a new `odb_for_each_object()` API to provide a unified way to iterate through Git objects regardless of their storage backend (loose objects, packed objects, etc.).

The series builds on previous work to abstract object storage and now reaches a key milestone by removing the legacy iteration APIs (`for_each_loose_object()` and `for_each_packed_object()`). The changes touch core commands like `fsck`, `pack-objects`, and `reachable`, demonstrating 45-96 line reductions per subsystem through code deduplication.

Key technical aspects include:
- New symmetric iteration interfaces with proper flag handling (`LOCAL_ONLY`, `PROMISOR_ONLY`)
- Unified callback documentation and error handling
- Mtime tracking via `struct object_info`
- Promisor object handling unification
- Optimized `read_object_info_from_path()`

The series has undergone significant review iteration, with Karthik Nayak providing key feedback on callback interface documentation. Justin Tobler and others have verified the mechanical soundness of the conversions. The v3 iteration fixes error code handling in the final patch and appears ready for integration pending any final documentation tweaks.

This represents a major step forward in the ODB abstraction effort, establishing clean backend-agnostic interfaces while significantly reducing code duplication across Git's object storage layer. The removal of legacy APIs confirms the completeness of the transition.
