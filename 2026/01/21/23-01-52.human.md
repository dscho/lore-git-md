This is a refactoring patch in the hook subsystem modernization series. It introduces a helper function `child_is_working()` to clean up repeated state checks of parallel child processes in `run-command.c`. The change extracts an anonymous struct into a named `parallel_child` type and replaces direct state comparisons with the new helper, improving code readability.

The patch is straightforward and mechanical - it doesn't change behavior, just makes the code more maintainable by reducing duplication. Junio Hamano suggests dropping "first" from the commit message since the helper's position in the sequence isn't particularly relevant to understanding the change.

This is part of a larger effort (now in its 7th iteration) to standardize Git's hook infrastructure with parallel execution support. The series has already addressed performance concerns and received maintainer approval, with this patch representing final polish before merging.
