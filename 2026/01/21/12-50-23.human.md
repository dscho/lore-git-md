This is part 7/14 of Patrick Steinhardt's ongoing ODB abstraction series, introducing a new unified interface for iterating over objects in Git's object database. The patch adds `odb_for_each_object()`, which serves as a high-level wrapper that delegates to the appropriate backend-specific iteration functions (loose objects and packed objects) while respecting flags like LOCAL_ONLY and PROMISOR_ONLY.

The function provides a single entry point for object iteration that will work across all storage backends, a key step in making the object database pluggable. The implementation cleanly handles the alternates chain and maintains the existing behavior where objects may be visited multiple times if they exist in multiple sources. The commit message notes this is preparatory work - subsequent patches will migrate callers to use this new interface.

As with previous patches in this series, the change is methodical and well-contained, adding 44 lines across odb.c and odb.h. The documentation is thorough, explaining both the iteration behavior and error handling semantics. This continues the series' pattern of introducing new abstractions while preserving existing functionality at each step.
