Performance optimization for sparse-checkout pattern handling, finalizing a series that changes the pattern sorting from O(n^2) to O(n log n). This v7 patch from Amisha Chhajed addresses the last remaining whitespace issues in test formatting that Derrick Stolee flagged in v6, making it ready for merging.

The core change replaces `string_list_insert()` with `string_list_append()` followed by sorting and deduplication when building the sparse-checkout pattern list. This improves performance for large pattern sets while maintaining correct handling of duplicates, particularly important for cone mode where semantically equivalent patterns should collapse to a single canonical form.

The patch adds two new test cases that verify: (1) the sparse-checkout file contains each cone pattern only once when duplicates are provided via `--stdin`, and (2) the `sparse-checkout list` command reports each pattern only once even when the file contains duplicates. These tests cover edge cases that Jeff King identified earlier in the thread.
