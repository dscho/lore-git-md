This is Junio Hamano's regular "What's cooking in git.git" status report, providing a comprehensive overview of the current state of development branches and pending patches. The report covers topics that have graduated to 'master', new topics being introduced, stalled topics that may be discarded, and ongoing work in various stages of review.

Several significant changes have recently been merged to 'master', including:
- Improved subtree split handling for rebased history
- fsck fixes for more consistent ref warnings
- Documentation updates for `git reset`
- Windows symlink support preparation
- HTTP backend error message formatting fixes
- Major refactoring of the packfile and object database infrastructure
