This is a feature patch series from Patrick Steinhardt that introduces a unified object iteration API as part of the ongoing ODB (object database) abstraction effort. The 14-part series builds on previous work to establish `odb_for_each_object()` as the primary way to iterate through objects regardless of storage backend (loose, packed, etc.), eliminating redundant code across several core commands.

The series has already gone through two rounds of review, with v3 incorporating feedback about error code propagation and callback documentation. It now removes the legacy `for_each_loose_object()` and `for_each_packed_object()` functions entirely, confirming the new API's adoption across fsck, pack-objects, cat-file, commit-graph, and reachable subsystems. The changes are behavior-preserving but significantly reduce code duplication (45-96 lines per subsystem) while adding mtime tracking and unified promisor object handling.

Reviewers Karthik Nayak and Justin Tobler have validated the mechanical soundness, leaving only minor documentation adjustments before potential integration. This represents a major milestone in the ODB abstraction work, establishing clean backend-agnostic interfaces for object storage iteration.
