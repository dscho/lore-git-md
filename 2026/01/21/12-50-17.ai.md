This is the first patch in Patrick Steinhardt's v3 series (14 parts) continuing the ODB abstraction effort. It's a straightforward mechanical refactoring that renames the `FOR_EACH_OBJECT_*` flags to have an `ODB_` prefix, preparing for a new `odb_for_each_object()` function that will unify object iteration across storage types.

The patch updates flag names in 11 files, consistently changing:
- `FOR_EACH_OBJECT_LOCAL_ONLY` -> `ODB_FOR_EACH_OBJECT_LOCAL_ONLY`
- `FOR_EACH_OBJECT_PROMISOR_ONLY` -> `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`
- etc.

This is part of the larger ODB abstraction work to make Git's object storage backend pluggable. The rename ensures the flags will match the naming convention of the upcoming unified iteration API. The changes are purely mechanical - no behavior is altered, just symbol names updated to match the new architectural direction.

The patch touches core object-handling code (packfile.c, object-file.c) and several commands that iterate objects (cat-file, pack-objects, commit-graph). Given this is part of a well-reviewed series and the changes are straightforward symbol renames, it appears uncontroversial and ready for integration.
