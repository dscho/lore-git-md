This is the first patch in Patrick Steinhardt's 14-part series refactoring Git's object database (ODB) iteration interfaces. The patch performs a mechanical rename of the `FOR_EACH_OBJECT_*` flags to use an `ODB_` prefix, preparing for a new unified `odb_for_each_object()` function that will be introduced later in the series.

The changes are straightforward and touch multiple files that use these flags, including `packfile.c`, `object-file.c`, and several builtin commands. The rename ensures naming consistency between the upcoming function and its associated flags. This is a typical preparatory refactoring that makes the subsequent architectural changes cleaner by establishing consistent naming up front.

The patch appears well-scoped and mechanical, with no behavior changes. It's part of Steinhardt's larger effort to abstract Git's object storage layer to support pluggable backends. The series has already gone through several iterations with review from Karthik Nayak and Justin Tobler, suggesting the technical approach is sound.
