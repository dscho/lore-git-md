This is the final patch in a 12-part series refactoring Git's hook subsystem to use a new standardized API. The patch converts receive-pack's update and post-update hooks to the new hook.h interface, completing the migration of all core hooks.

The changes maintain all existing functionality while enabling future improvements like parallel execution and config-based hook specification. Key technical aspects include:

- Replacing direct child_process usage with run_hooks_opt
- Preserving sideband output handling for both sequential and future parallel execution
- Maintaining original error handling and return codes
- Adding proper cleanup of file descriptors and async muxer state

The conversion follows the pattern established in earlier patches, with careful attention to stderr redirection for receive-pack's sideband communication. The implementation has been reviewed by Jeff King and incorporates his suggestions about output handling.

This patch represents the culmination of a multi-iteration effort that has addressed all major technical concerns and received approvals from key reviewers. The series is now ready for merging, having passed CI checks with no outstanding objections. The changes lay the foundation for future hook subsystem development while maintaining backward compatibility.
