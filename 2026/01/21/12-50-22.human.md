This is part 6/14 of Patrick Steinhardt's v3 series refactoring Git's object database (ODB) to support pluggable backends. The patch introduces `packfile_store_for_each_object()`, a new function that provides consistent iteration over packed objects, mirroring the loose object iteration pattern established in earlier patches.

The new function follows the same callback interface as its loose object equivalent, taking a `struct object_info` parameter to populate object metadata. This standardization is a key step toward unifying object iteration across different storage backends. The implementation wraps existing packed object iteration logic while maintaining all existing flag behaviors (LOCAL_ONLY, PROMISOR_ONLY).

The changes are focused in packfile.c and packfile.h, adding 62 lines total. This continues the series' pattern of methodical, well-contained refactoring that preserves existing behavior while building toward the larger ODB abstraction goal.
