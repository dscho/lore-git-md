Test modernization patch improving protocol testing in t5500-fetch-pack.sh. This is the final iteration of a GSoC contribution from Shreyansh Paliwal, addressing exit code suppression in test cases that verify shallow fetch behavior with commit graphs. The patch has been through multiple rounds of review with Patrick Steinhardt and Junio Hamano, with all feedback incorporated.

The key change replaces a problematic here-doc construction that masked Git command failures with a cleaner approach using `test-tool pkt-line pack`. This stores object IDs in shell variables upfront (`oid_algo`, `oid_other`, `oid_main`) and properly formats the protocol input in a temporary file before feeding it to `git upload-pack`. This makes failures immediately detectable and removes manual packet length calculations.

The implementation demonstrates good test hygiene by separating data gathering, packet formatting, and command execution into distinct phases. Junio has approved the technical approach, particularly endorsing the use of `test-tool pkt-line pack` as the right way to handle protocol formatting in tests. The patch serves as a model for similar protocol-interaction tests needing to avoid exit code suppression.

This represents a successful GSoC contribution that evolved through mentor guidance, with all prior concerns (portability, temp file handling, exit code visibility) now addressed. The changes are focused on test infrastructure improvement rather than modifying core functionality, making this a low-risk but high-value contribution to test reliability.
