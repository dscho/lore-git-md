This is part 12/14 of Patrick Steinhardt's ongoing ODB abstraction series, focusing on converting `pack-objects` to use the new object database iteration APIs. The patch refactors how cruft pack objects are enumerated to use the recently introduced `packfile_store_for_each_object()` function rather than the older `for_each_packed_object()` approach.

The key change simplifies the object enumeration logic by leveraging the new infrastructure from part 11 that tracks object modification times (mtimes). Instead of manually handling mtime lookup for both regular and cruft packs, the code now uses a unified interface that automatically provides this information through the `object_info` struct. This makes the code more maintainable and consistent with the series' goal of abstracting object storage details.

The patch demonstrates the practical benefits of the ODB abstraction work - the new version is cleaner and handles edge cases (cruft packs vs regular packs) transparently through the shared infrastructure. This continues the series' pattern of methodically converting subsystems to use the new APIs while maintaining backward compatibility.
