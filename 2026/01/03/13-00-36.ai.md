Feature enhancement for `git status` showing divergence from both upstream and push tracking branches. This is the second patch in a 2-part series that implements push tracking branch comparison in `git status` output.

The patch adds logic to show the upstream tracking branch comparison (existing behavior) plus an additional comparison with the push tracking branch when they differ. The implementation handles all edge cases including:
- Refspec remapping via `remote_ref_for_branch()` and `tracking_for_push_dest()`
- Custom push destinations that differ from the branch name
- Multiple remote configurations (origin vs upstream)
- Various divergence states (ahead, behind, diverged)

Key technical components:
- New `get_remote_push_branch()` helper resolves the push tracking reference
- Extended `format_tracking_info()` handles both upstream and push comparisons
- Output shows push comparison only when differing from upstream
- Maintains existing advice messages with push advice only when relevant
- Comprehensive test coverage (210 new test lines) verifies:
  - Ahead/behind/diverged states
  - Remote configurations
  - Edge cases
  - Output formatting
  - Custom refspec transformations

The implementation builds on the refactoring from patch 1/2 and has undergone extensive review, with Phillip Wood verifying the refspec handling and Junio C Hamano approving the technical direction. The output format follows Git conventions while providing additional useful information about push tracking divergence.

Example output when tracking origin/main but pushing to origin/feature:
```
On branch feature
Your branch and 'origin/main' have diverged,
and have 3 and 1 different commits each, respectively.
  (use "git pull" if you want to integrate the remote branch with yours)

Your branch is ahead of 'origin/feature' by 1 commit.
  (use "git push" to publish your local commits)
```
