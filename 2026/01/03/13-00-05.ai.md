This is a follow-up to the `git status` push tracking feature series, specifically addressing Phillip Wood's feedback about refspec mapping handling. The patch author Harald Nordgren has implemented the suggested approach using `remote_ref_for_branch()` and `tracking_for_push_dest()` to properly handle custom refspec transformations, but is seeking another review pass due to uncertainty about the refspec implementation details.

The implementation now correctly follows Git's refspec resolution chain: first mapping the local branch through push refspecs to determine the remote destination, then mapping that back through fetch refspecs to find the corresponding local tracking branch.
