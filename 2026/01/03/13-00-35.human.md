This is a refactoring patch that prepares for showing push remote tracking branch comparisons in `git status`. It's the first of two patches in a series that has gone through extensive review (now at v14) and is functionally complete.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This makes the code more modular by separating the message generation from the advice generation, while maintaining all existing behavior. The refactoring enables the upcoming push tracking display (in part 2) to reuse this logic cleanly.

Key technical changes:
- Moves the ahead/behind message formatting into a standalone function
- Separates advice messages from the core comparison logic
- Preserves all existing output formats and edge case handling
- Maintains the single ref resolution optimization
- No functional changes to current behavior

The patch has been thoroughly reviewed by Phillip Wood and others, with all identified issues addressed in previous iterations. This foundational work enables the actual push tracking display to be added cleanly in the next patch.
