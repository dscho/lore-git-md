Feature enhancement for `git status` showing push tracking branch comparison. This is the final version (v14) of a patch series that adds push remote comparison information to `git status` output, addressing a long-standing user request. The implementation has evolved through review feedback to properly handle custom refspec mappings and maintain consistency with Git's existing branch tracking mechanisms.

The series consists of two patches:
1. A refactoring of `format_branch_comparison()` to improve modularity while preserving behavior
2. The main feature implementation that adds push tracking display, now properly handling custom refspec transformations

Key technical aspects include:
- New `get_remote_push_branch()` helper that resolves push tracking references
- Full refspec mapping support through `remote_ref_for_branch()` and `tracking_for_push_dest()`
- Careful separation of push vs upstream logic
- 210 lines of new test coverage verifying various configurations and edge cases

The output format shows both upstream and push comparisons when they differ, like:
```
On branch feature
Your branch is ahead of 'upstream/main' by 1 commit.
Your branch is ahead of 'origin/feature' by 1 commit.
  (use "git push" to publish your local commits)
```

The series has received thorough review from Phillip Wood (who identified and helped solve the refspec mapping issue) and approval from Junio Hamano on the technical approach. All identified issues have been addressed, making this functionally ready for inclusion pending final verification of the refspec implementation. This represents a polished solution to a feature that will help users better understand their branch relationships.
