This is the second patch in a 2-part series implementing a feature enhancement for `git status` to show divergence from both upstream and push tracking branches. The series has gone through 14 iterations with extensive review, particularly from Phillip Wood who helped resolve key technical issues around refspec handling.

The patch adds push tracking display to `git status` when the push destination differs from the upstream branch. For example, if you're tracking `origin/main` but pushing to `origin/feature`, it will display both comparisons. The output maintains Git's existing format and only shows the push comparison when it differs from upstream.

Key implementation details:
- New `get_remote_push_branch()` helper resolves the push tracking reference
- Extended `format_tracking_info()` handles both upstream and push comparisons
- Output shows push comparison on a separate line when relevant
- Maintains existing advice messages, only showing push advice when applicable
- Handles custom refspec mappings through `remote_ref_for_branch()` and `tracking_for_push_dest()`

The patch includes 210 lines of new test coverage (up from 168) verifying various scenarios:
- Ahead/behind/diverged states
- Different remote configurations
- Edge cases with unset/malformed branches
- Custom refspec transformations
- Example output:
  ```
  On branch feature
  Your branch is ahead of 'upstream/main' by 1 commit.
  Your branch is ahead of 'origin/feature' by 1 commit.
    (use "git push" to publish your local commits)
  ```
