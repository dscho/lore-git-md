Feature enhancement for `git status` showing push tracking branch divergence. This is the final version (v13) of a patch series that has evolved through community review, now ready for potential inclusion. The series adds push remote tracking information to `git status` output when it differs from the upstream branch.

The first patch refactors `format_branch_comparison()` in `remote.c` to prepare for the new functionality, separating message formatting from advice generation while maintaining existing behavior. The second patch implements the core feature, showing push tracking comparisons only when they differ from upstream, with appropriate advice messages.

Key technical changes in v13 include:
- Simplified variable naming and initialization
- Consolidated push branch resolution
- Fixed memory management for push branch names
- Maintained comprehensive test coverage (168 lines)

The implementation now cleanly uses Git's existing branch tracking mechanisms (`branch.<name>.pushRemote`) after earlier iterations explored alternative approaches. The output shows both upstream and push comparisons when they differ, helping users understand their branch's position relative to both remotes.

This represents the polished conclusion of a well-reviewed feature, with all major technical feedback addressed and comprehensive test coverage. The patches follow Git's conventional commit organization and are ready for maintainer consideration.
