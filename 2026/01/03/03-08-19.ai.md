This is the final version (v13) of a feature enhancement for `git status` that displays divergence from both upstream and push tracking branches. The series has evolved through multiple iterations based on feedback, with this version incorporating final refinements from Phillip Wood's review.

The first patch refactors `format_branch_comparison()` in `remote.c` to prepare for the new functionality, separating message formatting from advice generation while maintaining existing behavior. The second patch implements the core feature, showing push tracking information when it differs from the upstream branch, using Git's existing branch tracking mechanisms (`branch.<name>.pushRemote`).

Key technical improvements in v13 include:
- Variable naming and initialization cleanup
- Memory management fixes for push branch resolution
- More consistent handling of the `AHEAD_BEHIND_QUICK` flag
- Better separation of push vs upstream comparison logic

The implementation now shows push comparison only when it differs from upstream, with matching advice messages. Test coverage remains comprehensive at 168 lines, verifying all edge cases and output formats.
