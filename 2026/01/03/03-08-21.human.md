Feature enhancement for `git status` showing push tracking branch divergence. This is the second and final patch in a series that has evolved through 13 iterations based on-list feedback.

The patch implements the core functionality to show how the current branch differs from both its upstream tracking branch and its push destination branch (when they differ). This helps users understand their position relative to both integration and publication targets. The implementation uses Git's existing branch tracking mechanisms, specifically `branch.<name>.pushRemote`, falling back to the tracking branch if unset.

Key technical points:
- Adds a new helper function `get_remote_push_branch()` to resolve the push tracking reference
- Extends `format_tracking_info()` to handle both upstream and push comparisons
- Only shows the push comparison when it differs from the upstream
- Maintains existing advice messages, showing push advice only when relevant
- Includes comprehensive test coverage (168 lines) for various scenarios

The output format shows the push comparison on a separate line when applicable, with the same formatting as the upstream status. For example:
```
Your branch is ahead of 'upstream/main' by 1 commit.
Your branch is ahead of 'origin/feature' by 1 commit.
```

The patch represents the polished conclusion of this feature enhancement, incorporating all feedback from the extensive review process. It's now ready for inclusion in the next integration cycle.
