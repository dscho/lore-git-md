This is the first of two patches in a series that enhances `git status` to show divergence from both upstream and push tracking branches. The series has gone through 13 iterations, with this version incorporating all final refinements.

The patch refactors `format_branch_comparison()` in `remote.c` to prepare for the upcoming push tracking display functionality. It extracts the comparison formatting logic into a standalone function, separating it from the advice generation. The changes maintain existing behavior while improving modularity - the core comparison messages are now handled in one place while the advice strings remain in the calling function. This creates a cleaner separation that will make it easier to add push tracking comparisons in the next patch.

The refactoring preserves optimizations like the `AHEAD_BEHIND_QUICK` flag handling while making the code more maintainable. All test coverage remains intact, and the changes have been thoroughly reviewed by Phillip Wood and others over the series' evolution. The patch represents the technical foundation for the feature, with the actual push tracking display coming in patch 2/2.
