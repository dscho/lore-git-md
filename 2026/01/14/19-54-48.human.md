This is a preparatory patch in Taylor Blau's ongoing MIDX compaction series (now at 11/18). It introduces a small utility function `u32_add()` to safely add two 32-bit unsigned integers with overflow checking, following the pattern of the existing `u64_mult()` function in the same file.

The change is straightforward - it adds a new inline function to `git-compat-util.h` that will be used by subsequent patches in the series. The function checks for overflow using Git's existing `unsigned_add_overflows()` helper and dies with an error message if overflow would happen, otherwise returning the sum.

This is a typical infrastructure patch in a larger series - it doesn't implement any user-visible behavior yet, but provides a building block for the compaction functionality to come. The commit message clearly states this is preparation for future work, and the implementation looks clean and consistent with similar utilities in the codebase.
