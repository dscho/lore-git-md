This is part of Taylor Blau's MIDX compaction series (patch 4/18), which implements `git multi-pack-index compact` functionality with reachability bitmaps support. The series has already addressed major review comments from Patrick Steinhardt.

The current patch is a refactoring that centralizes the `--progress` option handling for all `multi-pack-index` subcommands (write, verify, repack, expire). Previously each subcommand declared its own `OPT_BIT()` for this option, despite it being common to all. The change moves the option declaration to the shared `common_opts` array while maintaining identical behavior.

Key technical details:
- Adds `--progress` to the common options section in the documentation
- Removes duplicate `OPT_BIT()` declarations from individual subcommands
- Keeps the same `MIDX_PROGRESS` flag bit
- Touches both the C implementation and documentation

This is a straightforward cleanup that follows Git's pattern of consolidating common command-line options. The change is mechanical and low-risk, with no functional impact beyond code organization. It demonstrates the series' attention to code hygiene even while implementing major new functionality.
