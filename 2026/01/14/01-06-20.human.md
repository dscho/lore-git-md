This is a bugfix for HTTP authentication in `remote-curl.c`, specifically for `probe_rpc()` requests during clone operations with bearer tokens. The patch addresses a case where large clone requests (exceeding `http.postBuffer`) would fail with 401 errors because `probe_rpc()` wasn't including authentication headers, even though the main request had successfully authenticated.

The fix adds `http_append_auth_header()` to `probe_rpc()` in `remote-curl.c`. The test case creates a repository with 2000 refs to force large requests and configures a small `http.postBuffer` to trigger `probe_rpc()`, using `git-credential-msal` for bearer token authentication testing.

The technical approach has already been approved by Patrick Steinhardt, and the patch appears ready for merging once these final tweaks are made.
