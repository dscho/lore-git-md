This is patch 12/18 in Taylor Blau's MIDX compaction series, introducing a helper function for pack permutation handling. The patch is a refactoring step that prepares for upcoming MIDX compaction work while maintaining current behavior.

The new `midx_pack_perm()` helper function abstracts access to `ctx->pack_perm` array lookups, which map original pack IDs to their positions in the current context. The motivation comes from how MIDX compaction will handle multi-layer MIDX chains, where pack IDs from upper layers could exceed the allocation size of the permutation array if accessed directly.

The patch replaces all direct `ctx->pack_perm[]` array accesses with calls to the new helper, which currently just passes through to the original array access. This is a behavior-preserving change that makes future modifications easier - specifically, the ability to handle offset pack IDs when compacting MIDX layers with different base pack ID ranges.

The change touches several MIDX-writing functions that need to look up pack permutation information, including object offset writing, pack ordering, and packing data preparation. The patch maintains all existing functionality while providing a single point of control for future pack ID mapping logic.

This continues the series' pattern of careful, incremental changes that build toward the final compaction functionality while keeping each step reviewable and bisectable. The helper function introduction follows established patterns seen elsewhere in the codebase for similar indirection needs.
