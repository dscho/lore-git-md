This is a bugfix patch addressing an authentication issue in the remote-curl transport when handling large requests. The problem occurs when a large request triggers the probe_rpc() path, which wasn't properly including authentication headers, causing HTTP 401 failures during operations like cloning with blob filters.

The patch modifies remote-curl.c to include auth headers in probe_rpc() requests, matching the behavior of other request paths. The author provides a detailed reproduction scenario showing how a clone operation with blob filters fails when the initial auth succeeds but subsequent blob requests fail due to missing auth headers. The fix is straightforward - just adding the auth header append call to probe_rpc().

The patch includes a comprehensive test case that:
1. Creates a repository with 2000 refs (to ensure large request size)
2. Configures a small http.postBuffer to force the probe_rpc() path
3. Sets up bearer token authentication
4. Verifies the clone succeeds with proper auth handling
