This is the final patch in Taylor Blau's 18-part series implementing MIDX compaction with reachability bitmap support. The series introduces a new `git multi-pack-index compact` subcommand for combining adjacent MIDX layers while maintaining bitmap compatibility.

The patch adds bitmap support to the compaction operation, allowing existing bitmaps from compacted layers to be combined into a single bitmap for the new layer. The key technical aspects are:

1. Adds `--[no-]bitmap` option to the `compact` subcommand to control bitmap generation
2. Modifies `midx_pack_order()` to treat all objects as non-preferred during compaction to preserve object ordering
3. Includes extensive test coverage verifying:
   - Bitmap preservation across compactions
   - Object selection consistency
   - Handling of both lex-ordered and non-lex-ordered pack scenarios
   - Complex commit graph topologies

The implementation builds on the series' earlier work with MIDX v2 format and pack ordering, demonstrating careful attention to backward compatibility. The tests suggest production-grade robustness, covering edge cases like non-trivial commit graphs and verifying object selection remains consistent after compaction.
