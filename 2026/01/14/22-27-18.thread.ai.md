Thread identity: Bugfix patch addressing UTF-8 filename truncation in diffstat output, submitted as part of Google Summer of Code (GSoC). Originating author not yet identified in thread.

Core problem: Current diffstat display incorrectly assumes byte count equals display width when truncating filenames containing UTF-8 characters (which may be multi-byte), causing either overflow or corrupted display when UTF-8 character bytes are split. Demonstrated with Chinese character example ("你好").

Technical solution: Uses `utf8_width()` to properly account for multi-byte characters when calculating truncation in `show_stats()` (diff.c line 2859), moving the filename pointer by actual byte count of dropped characters rather than display width. Small but impactful change (4 lines added, 11 removed) targeting international users. Fixes issue introduced by commit ce8529b2 (2022).
