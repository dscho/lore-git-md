Performance patch in Taylor Blau's MIDX compaction series (3/18). This patch introduces `midx_get_checksum_hex()` as a convenience wrapper around the existing `midx_get_checksum_hash()` function, which returns the checksum in hexadecimal format rather than raw bytes. The change eliminates repetitive calls to `hash_to_hex_algop()` across multiple files (midx-write.c, pack-bitmap.c, test helpers) while maintaining the raw byte access for callers that need it.

The implementation uses a static buffer (as indicated in the function's comment) for the hex conversion, following Git's common pattern for such utility functions. This is part of the larger MIDX compaction effort that aims to improve performance for large repositories by optimizing multi-pack-index handling while preserving bitmap coverage. The patch demonstrates careful attention to API design, with clear separation between raw and hex-encoded access to the checksum data.
