This is a test patch in a series addressing submodule `ignore=all` behavior. It's the third of five patches in v3 of the series, focused on adding comprehensive test coverage for the new `--force` behavior when adding ignored submodules.

The test file `t2206-add-submodule-ignored.sh` contains 8 test cases that verify:
1. Basic setup with submodule repositories
2. Default behavior with `ignore=none`
3. Transition to `ignore=all` configuration
4. Status behavior with ignored submodules
5. Normal `git add` behavior with ignored submodules
6. `git add --force` behavior with pathspecs
7. Explicit submodule adds with and without `--force`
8. Log behavior with ignored submodules

The tests validate both `.gitmodules` configuration and command-line overrides, ensuring the new `--force` flag works as expected while maintaining existing warning messages and status behavior. The test file is added to meson.build for execution in the test suite.

This patch builds on the plumbing changes from patch 1 and behavior implementation from patch 2, providing the verification layer for the new functionality. The test cases are thorough, covering both positive and negative cases while maintaining compatibility with existing submodule handling infrastructure.
