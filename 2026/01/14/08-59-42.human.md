This is a bugfix patch in the hook subsystem, addressing two distinct issues that were incorrectly combined in the previous version. The email is part of an ongoing thread with active discussion from multiple contributors.

The first issue involves stdout/stderr separation in pre-push hooks, where recent changes caused all hooks to redirect stdout to stderr by default. This broke the pre-push hook's ability to use separate streams. Adrian Ratiu's v2 patch addressed this with comprehensive tests and a new `stdout_to_stderr` flag in `run_hooks_opt`, which is now considered ready for merging.

The second issue concerns stdin feeding performance in `feed_pipe` when not using `ungroup=1`, causing poll timeouts during pre-push. Jeff King identified this as a separate problem that needs its own fix, likely requiring either enforcing `ungroup=1` or enhancing the poll mechanism. Adrian acknowledges this will be handled in v3.
