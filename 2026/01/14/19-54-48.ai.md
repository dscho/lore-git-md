This is a preparatory patch in Taylor Blau's MIDX compaction series (part 11/18), introducing a utility function for safe 32-bit unsigned addition with overflow checking. The patch adds `u32_add()` to `git-compat-util.h` as a counterpart to the existing `u64_mult()` function, following the program with a fatal error if overflow occurs.

The function will be used in upcoming patches of the series for MIDX-related calculations. This is a small but necessary building block that demonstrates the careful attention to overflow safety in the series. The implementation matches Git's existing patterns for arithmetic safety checks, using the same `unsigned_add_overflows()` primitive and error reporting style as other similar utilities.

As with previous patches in the series, this change is well-contained and clearly motivated by upcoming needs in the MIDX compaction work. The patch maintains the project's coding style and includes appropriate documentation via the function's behavior and error message.
