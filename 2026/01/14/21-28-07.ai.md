This is a patch in Taylor Blau's multi-pack-index compaction series, specifically addressing version compatibility between MIDX v1 and v2 formats. The patch removes the requirement for packs to be sorted lexicographically in MIDX v2 while maintaining backward compatibility with v1.

The key changes include:
- Introducing MIDX_VERSION_V1/V2 constants
- Making pack name sorting optional in v2 while keeping it enforced in v1
- Adding version awareness throughout the MIDX writing code
- Preserving v1 behavior when reading existing MIDX files

Junio Hamano's review confirms the technical approach but questions whether some version parameter additions are strictly necessary, since the writer should always use v2. The patch demonstrates careful attention to backward compatibility while modernizing the MIDX format's requirements.

This is part of the larger effort to improve MIDX handling for large repositories, with particular focus on the new compaction functionality that will follow in later patches. The version handling here provides the foundation for those subsequent changes while ensuring existing repositories continue to work as expected.
