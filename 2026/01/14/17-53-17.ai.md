This is a documentation patch completing a series that aligns `git add` behavior with other commands when submodules are configured with `ignore=all`. The patch updates three documentation files to reflect the new requirement that `--force` must be used to stage submodule updates when `ignore=all` is set.

The changes clarify the interaction between `ignore=all` and `git add` across the documentation:
- `git-add.adoc` now explicitly states that `--force` overrides `ignore=all` for staging submodule updates
- `gitmodules.adoc` and `config/submodule.adoc` are updated to document which commands respect the ignore setting and how `--force` interacts with it

The documentation maintains technical precision while being user-accessible, though Ben Knoble notes some minor English phrasing issues that could be improved (like missing 'When set to...' constructions). The patch matches the implementation exactly and completes the technical specification of the behavior change introduced in earlier patches of this series.
