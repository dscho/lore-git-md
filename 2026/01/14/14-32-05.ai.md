Documentation bugfix for git config URL matching syntax. Shreyansh Paliwal identifies and corrects a discrepancy between the documented and actual behavior of `git config`'s URL matching functionality. The documentation incorrectly suggests using `--url` with `--all`, which the code explicitly prohibits. 

The email provides two working alternatives: using `--url` alone for best-match lookup (`git config get --show-names --url=<name> <URL>`) or using `--all` with `--regexp` for seeing all matches (`git config get --all --show-names --regexp <name>`). This is a straightforward documentation fix that should help users avoid the fatal error when combining incompatible flags. The patch appears technically correct and addresses a clear documentation error, though it might benefit from being submitted as a formal patch to update the man page rather than just an email reply.
