This is a documentation patch in Taylor Blau's ongoing MIDX compaction series (patch 5/18). It fixes an outdated statement in the `git-multi-pack-index` man page that incorrectly claimed `--incremental` and `--bitmap` options were incompatible. The incompatibility was removed in a previous commit (27afc272c49) that added support for writing incremental MIDX bitmaps, but the documentation wasn't updated to reflect this change.

The patch is straightforward - it simply removes the "Incompatible with `--bitmap`" line from the man page. This aligns the documentation with the actual behavior where both options can now be used together. The change is minimal (just one line removed) and clearly motivated by prior technical changes in the codebase.

This is part of the larger effort to improve MIDX functionality, specifically around compaction and bitmap handling. The series has already addressed major technical feedback, and this patch represents a small but important documentation cleanup to keep the man pages accurate.
