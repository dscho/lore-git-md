This thread documents and fixes a discrepancy in Git's URL matching configuration syntax. The original report noted that the documented approach (`git config get --all --show-names --url=<URL> <name>`) fails in practice because `--url` and `--all` are mutually exclusive flags. 

Shreyansh Paliwal provided the correct syntax: either use `--url` alone for best-match lookup (`git config get --show-names --url=<name> <URL>`) or `--all` with `--regexp` to see all matches (`git config get --all --show-names --regexp <name>`). This is a straightforward documentation bug that could trip up users following the incorrect man page instructions. While the fix is simple, it would be helpful to see it submitted as a formal patch to update the documentation.
