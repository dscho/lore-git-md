This is a bugfix patch addressing UTF-8 filename truncation in diffstat output, submitted by Lorenzo Pegorari as part of Google Summer of Code (GSoC). The patch fixes an issue where multi-byte UTF-8 characters were being truncated incorrectly in diffstat displays, causing either overflow or corrupted output.

The core problem stems from `show_stats()` assuming byte count equals display width when truncating filenames. For UTF-8 characters (like Chinese "你好"), this assumption breaks down since multi-byte characters may have different display widths than their byte counts. The fix uses `utf8_width()` to properly account for character widths when calculating truncation points.

Junio Hamano's response notes the simplicity of the solution and requests two improvements: adding test coverage for the test suite (t/) to demonstrate the fix works with various UTF-8 cases, and considering whether to also address a related `NEEDSWORK` comment in the same function. The patch appears well-targeted and clearly motivated, though the lack of test coverage is a notable gap that reviewers will likely ask to be filled before merging.
