[PATCH v4] remote-curl: include auth headers in probe_rpc() requests

Fixes authentication failure in remote-curl transport when large requests trigger probe_rpc() path, which previously omitted auth headers despite successful initial auth. Problem affects operations like cloning with blob filters where initial auth succeeds but subsequent blob requests fail with HTTP 401. Reproduction scenario involves clone with blob filters when request size exceeds http.postBuffer, forcing probe_rpc() path without auth headers.

Changes in v4: addressed style nits from review, improved test portability using xargs. Patch modifies remote-curl.c to include auth headers in probe_rpc() matching other request paths. Test case verifies fix by creating repo with 2000 refs (ensuring large request size), configuring small http.postBuffer to force probe_rpc(), setting up bearer token auth, and confirming successful clone with proper auth handling. Touches remote-curl.c and t/lib-httpd.sh with minimal logic changes.
