This is the third patch in a six-part bugfix series addressing a regression in error message reporting for batched reference updates. The series is co-authored by Karthik Nayak and Jeff King, building on a report from Elijah Newren.

The patch modifies the callback function signature for handling rejected reference updates to include the new `rejection_details` field that was added in patch 2/6. While the details parameter is marked as UNUSED in this commit, it lays the groundwork for subsequent patches to surface these error messages to users. The changes touch three command implementations (`fetch`, `receive-pack`, and `update-ref`) along with the core refs infrastructure.

This is a mechanical but necessary step in the series - it updates all call sites to match the new callback signature while maintaining backward compatibility. The patch follows the established pattern of the series by being focused and well-contained, with clear commit messages explaining both the immediate purpose and how it fits into the larger fix.
