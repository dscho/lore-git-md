This is the final documentation patch in a series that aligns `git add` behavior with `git status` and `git diff` when handling submodules with `ignore=all` configuration. The patch updates three documentation files to reflect the new requirement that `--force` must be used to stage updates to submodules marked with `ignore=all`.

The changes clarify that while `ignore=all` prevents submodules from showing as modified in status/diff output, users can still stage submodule updates by explicitly using `git add --force` on the submodule path. The documentation now consistently describes this behavior across the config, git-add, and gitmodules man pages.

This patch follows four others in the series that implemented the plumbing changes, core behavior, tests, and test updates. The documentation matches the final implementation that was settled on after discussion rounds, using `--force` as the flag to override the ignore setting. The changes are mechanical updates to ensure the docs accurately reflect the new behavior.
