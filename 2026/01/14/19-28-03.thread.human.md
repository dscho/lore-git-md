Amisha Chhajed's patch series aims to optimize sparse-checkout pattern sorting from O(n^2) to O(n log n) by replacing string_list_insert() with string_list_append() followed by sorting. The core optimization is uncontested, but reviewers have identified an edge case regarding duplicate pattern handling. 

Jeff King (Peff) first noted that the duplicate suppression needed to be preserved for patterns from recursive_hashmap (which can contain user-supplied duplicates), while parent_hashmap patterns are guaranteed unique. René Scharfe has now reinforced this concern, pointing out the v3 patch's removal of string_list_remove_duplicates() could cause issues. 

The changes affect pattern collection in sparse_checkout_list() and write_cone_to_file() within builtin/sparse-checkout.c's cone mode handling. Junio C Hamano previously reviewed formatting aspects with no objections. The thread awaits either a v4 from Amisha addressing the duplicate handling or confirmation that Junio will apply the fix during merge. This localized optimization fits within the broader sparse-checkout/sparse-index work led by Derrick Stolee and Elijah Newren.
