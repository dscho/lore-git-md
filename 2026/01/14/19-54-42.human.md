This is part 9/18 of Taylor Blau's MIDX compaction series, focusing on refactoring the MIDX writing code. The patch introduces a `struct write_midx_opts` to consolidate the six parameters currently passed to `write_midx_internal()` into a single structure. This prepares for future addition of compaction-related parameters without further expanding the function's signature.

The change is purely structural - no behavior is modified. The patch converts all four callers of `write_midx_internal()` to use the new options struct instead of individual parameters. This follows the pattern seen elsewhere in Git where growing parameter lists are replaced with options structs to improve maintainability.

The series continues to demonstrate careful, incremental refactoring that lays groundwork for the larger compaction functionality while keeping each change focused and reviewable. This particular patch addresses a code organization issue that would have become more problematic as the series progressed.
