This thread addresses a bug in the remote-curl transport where authentication headers were being omitted in the probe_rpc() path, causing HTTP 401 failures for large requests (like those with blob filters) despite successful initial authentication. The fix, now in its fourth iteration, modifies remote-curl.c to consistently include auth headers in probe_rpc() requests.

The patch includes a robust test case that creates a repository with 2000 refs to force large requests, configures a small http.postBuffer to trigger the probe_rpc() path, and verifies successful authentication with bearer tokens. Version 4 incorporates style improvements and enhanced test portability using xargs, addressing feedback from earlier reviews. Lucas De Marchi has tested the patch, confirming it resolves the issue. While the code change itself is small, the impact is significant for users experiencing authentication failures during operations like filtered clones. The thorough test coverage and positive testing feedback suggest this is ready for merging.
