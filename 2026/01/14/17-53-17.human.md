This is the final documentation patch in a series that aligns `git add` behavior with other commands when dealing with submodules configured with `ignore=all`. The patch updates three documentation files to reflect the new requirement that `--force` must be used to stage changes to such submodules.

The changes clarify that while `ignore=all` prevents submodules from showing as modified in `status` and `diff` output, users can still stage submodule updates by explicitly using `git add --force` on the submodule path. The documentation now accurately describes which commands respect the `ignore` setting (`status`, `update-index`, `diff`, and `log`) and maintains consistency with the implementation from earlier patches in the series.

The patch follows the established pattern from the technical implementation, though Ben Knoble notes some minor English phrasing issues in the config documentation that could be made more idiomatic. This completes the series by ensuring users have clear guidance about the new behavior, particularly the interaction between `ignore=all` and `git add --force`.
