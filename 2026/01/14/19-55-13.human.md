This is the final patch in Taylor Blau's 18-part series implementing MIDX compaction with reachability bitmap support. The series introduces a new `git multi-pack-index compact` subcommand that combines adjacent MIDX layers while preserving bitmap compatibility.

The patch enables bitmap generation during compaction process by:
1. Adding a `--[no-]bitmap` option to the `compact` subcommand
2. Treating all objects as non-preferred during compaction to maintain proper object ordering
3. Including comprehensive tests verifying bitmap preservation across various scenarios

The implementation combines existing bitmaps from compacted layers rather than generating new ones, though the commit message notes this lays groundwork for more sophisticated bitmap strategies in future. The tests cover:
- Basic bitmap preservation
- Object selection consistency
- Non-trivial commit graph scenarios
- Lex-ordered and non-lex-ordered pack cases

This completes the series' core functionality after extensive preparatory work. The patch appears well-tested and builds logically on the established foundation, with no outstanding review comments at this stage.
