This is part of Taylor Blau's 18-patch series implementing MIDX compaction functionality with reachability bitmap support. Patch 2/18 is a refactoring change that renames `get_midx_checksum()` to `midx_get_checksum_hash()` to follow Git's naming conventions for struct-related operations. The change also clarifies that this function returns a raw hash (not hex-encoded) by adding the "_hash" suffix, which will help distinguish it from a future "_hex" variant. The patch touches several files that interact with MIDX checksums but makes no functional changes - it's purely a code hygiene improvement that prepares for later patches in the series. The change was suggested by Patrick Steinhardt during review of an earlier version.
