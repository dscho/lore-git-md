This is patch 3/18 in Taylor Blau's MIDX compaction series, which introduces a new helper function to simplify working with MIDX checksums. The patch adds `midx_get_checksum_hex()` as a convenience wrapper around the existing `midx_get_checksum_hash()` function, eliminating repetitive calls to `hash_to_hex_algop()` in several places.

The new function returns a static buffer containing the hexadecimal representation of a MIDX's checksum, making the common case of displaying the checksum more straightforward. The raw hash accessor (`midx_get_checksum_hash()`) remains available for callers that need the bytes directly. The patch updates four call sites to use the new helper, reducing boilerplate.

This is a clean, focused change that follows the series' pattern of incremental improvements to the MIDX API. The implementation is straightforward and well-tested, with all existing callers updated appropriately. As part of the larger MIDX compaction effort, this patch helps pave the way for more substantial changes while keeping the codebase tidy.
