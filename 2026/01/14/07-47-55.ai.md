This is part of a bugfix series addressing submodule `ignore=all` behavior consistency across Git commands, specifically focusing on aligning `git add` with `git status` and `git diff` handling. This is patch 1/5 in the third iteration of the series.

The change propagates through several callers in `builtin/add.c`, `checkout.c`, and `commit.c`. The implementation adds the parameter to the function signature and extends the `update_callback_data` struct to carry this new flag through the diff machinery.

The changes are mechanical plumbing updates that lay groundwork for the subsequent behavior changes in patch 2. The patch maintains existing functionality while adding the infrastructure needed for the new `--force` behavior that will allow adding ignored submodules when explicitly requested. The diff shows careful attention to maintaining the existing control flow while adding the new parameter in a way that doesn't disrupt current behavior.
