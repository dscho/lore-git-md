Git config URL matching documentation discrepancy. Thread reports incorrect documentation for `git config --get-urlmatch` replacement syntax (`git config get --all --show-names --url=<URL> <name>`), which fails in practice due to `--url` being mutually exclusive with `--all`. Shreyansh Paliwal identifies and corrects this discrepancy, providing two working alternatives: using `--url` alone for best-match lookup (`git config get --show-names --url=<name> <URL>`) or using `--all` with `--regexp` for seeing all matches (`git config get --all --show-names --regexp <name>`). The documentation currently contradicts actual behavior, showing incompatible flag combinations. This is a straightforward doc bug needing either syntax correction or behavior explanation in the man page. No series context indicated - appears to be a standalone documentation issue.
