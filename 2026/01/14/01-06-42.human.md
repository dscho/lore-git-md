This is a bugfix for the HTTP authentication handling in `remote-curl.c`. The patch addresses an issue where authentication credentials were not being passed during `probe_rpc()` calls, which could cause large requests to fail with 401 errors when using bearer token authentication.

The problem occurs when a large request triggers Git to split the request into chunks using `probe_rpc()`. While the main request includes authentication headers, the probe request did not, causing authentication failures. The fix is simple - just pass the auth headers to `probe_rpc()` like other requests do.

Aaron Plattner provides a detailed reproduction case using Microsoft Authentication Library (MSAL) credentials, where a clone with blob filters would fail during checkout when the probe request hit the server without credentials. The patch includes a test that creates a repository with enough refs to trigger the probe path, then verifies the clone works with bearer token auth.

The patch looks straightforward and well-tested, with v4 addressing some minor style nits. This affects users of bearer token authentication (like MSAL) when working with large repositories, so it's a worthwhile fix. The change is minimal (just one line of code) but the test coverage gives confidence it works as intended.
