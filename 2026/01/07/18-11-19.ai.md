This is a documentation quality patch, part of an ongoing effort to improve whitespace handling in Git's documentation files. Adrian Ratiu is implementing a new check to detect when tabs appear between non-whitespace characters in documentation (particularly .adoc files) where a space was likely intended, while preserving legitimate tab usage for indentation/alignment.

The patch has gone through several iterations with feedback from Junio Hamano and Johannes Sixt. Key technical aspects include a new WS_TAB_BETWEEN_NON_WS flag (likely to be renamed "tab-instead-of-space" per discussion), modifications to ws.c to track character and visual column positions, and emit_middle_section() changes for tab highlighting. The check is enabled by default for Documentation/**/*.adoc via .gitattributes.
