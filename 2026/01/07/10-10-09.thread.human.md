This thread introduces a patch series from Patrick Steinhardt to refactor Git's replay functionality into a library form. The first patch (v8 1/7) extracts the core revision replay logic from `builtin/replay.c` into a new `replay_revisions()` function, preparing it for eventual relocation to a library file. The refactoring introduces new structs to cleanly pass parameters and results while maintaining all existing functionality, though it still has FIXMEs about unsupported cases like root and merge commits.

The changes are purely internal - no user-visible behavior is altered - and represent a careful step in Patrick's ongoing effort to make more of Git's core functionality available as reusable library components. Given Patrick's extensive experience with such architectural refactorings and the patch's clean separation of concerns, this appears to be a well-considered change that maintains the existing behavior while setting up for future library integration.
