This is a code cleanup patch in Patrick Steinhardt's ongoing series to refactor Git's packfile storage. The patch addresses a misleading edge case in `unuse_one_window()`, a function that manages memory-mapped packfile windows.

The function currently takes a `packed_git` parameter that appears optional but is in fact always non-NULL in current code. Patrick traces this through Git's history, showing how earlier changes made the NULL case impossible while leaving confusing remnants of the old behavior. The patch simplifies the interface by making the object database parameter explicit rather than deriving it from a packfile that wasn't actually being used meaningfully.

Toon Claes replies positively, noting he hadn't considered the edge case Patrick identified and agrees the change makes the code clearer. This is a small but thoughtful improvement to a low-level packfile management function as part of the larger ODB refactoring effort.
