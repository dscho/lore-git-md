This is part 2 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch simplifies the interface by removing the distinction between `OI_PACKED` and `OI_DBCACHED` object types, treating all packfile objects as `OI_PACKED`.

The change eliminates what was essentially an implementation detail (whether an object was in the delta base cache) that callers didn't meaningfully use. The three callers that did check the `whence` field either get more complete information (for `packfile_store_read_object_info()`) or more accurate behavior (for promisor pack checks in `repack_local_links()` and `is_not_in_promisor_pack_obj()`).

The patch is straightforward, removing the enum value from `odb.h` and updating `packfile.c` to always return `OI_PACKED`. As part of the larger series that has already been thoroughly reviewed and approved, this change represents a clean simplification that maintains functionality while making the code easier to work with.
