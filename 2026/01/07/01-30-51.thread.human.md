The thread introduces a new whitespace check called `tab-between-non-ws` that detects when tabs appear between non-whitespace characters where spaces were likely intended - a common issue in documentation files that can cause formatting problems. Adrian Ratiu developed the patch based on a suggestion from Junio Hamano.

The implementation is sophisticated, tracking both character positions and visual column positions to properly handle different tab widths. It includes full highlighting support in `git diff` and fixing capability via `git apply --whitespace=fix`. The check is automatically enabled for AsciiDoc files in the Documentation directory through .gitattributes.

Version 2 of the patch incorporated Junio's feedback about the highlighting and fixing behavior. The implementation comes with extensive test coverage in t4015-diff-whitespace.sh that verifies correct operation across different tab width settings. The change appears well-tested and ready for inclusion, addressing a real documentation formatting issue while carefully avoiding false positives on legitimate tab usage.
