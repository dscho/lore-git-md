This is part 3 of an 11-patch series implementing submodule gitdir path encoding, now in its 8th iteration. The series has received Junio Hamano's ack for merging after addressing all review feedback.

The current patch adds a new `git submodule--helper gitdir` command that exposes the internal `submodule_name_to_gitdir()` function, which computes and validates submodule gitdir paths. This helper will be used by subsequent patches to query and validate gitdir paths, particularly when users configure custom paths via the new `submodule.<name>.gitdir` setting.

The implementation is straightforward - it adds a new subcommand that takes a submodule name, computes its gitdir path using the existing validation logic, and prints the result. The validation was centralized in a previous patch to ensure consistent handling across all callers.

This is a mechanical change that enables the user-facing configuration features coming in later patches. The series as a whole introduces runtime configuration of submodule gitdir paths to prevent filesystem conflicts and support custom layouts, with a four-tier fallback system (plain/encoded/numbered/hashed paths) and case-folding protection via RFC3986 encoding.
