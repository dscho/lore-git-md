This is a feature patch completing the implementation of `--filter=auto` for Git's promisor remote functionality, part of a larger 9-patch series. The patch wires up the auto-filter logic in `fetch-pack.c` and enables it for clone/fetch operations by setting `allow_auto_filter`.

Patrick Steinhardt's review raises two key points: First, he questions whether locally configured promisor filters should also be honored by `--filter=auto`, suggesting the documentation could be clearer about this interaction. Second, he finds the error handling convention in `promisor_remote_construct_filter()` awkward, suggesting it would be more idiomatic to return an error code rather than requiring callers to check an error buffer's length.

The changes themselves are relatively straightforward - enabling the auto-filter flag in clone/fetch commands and adding the server-side filter combination logic in fetch-pack. The patch builds on extensive prior work in the series to handle filter combination and promisor remote configuration.

This appears to be a well-considered addition to Git's partial clone capabilities, though Patrick's review suggests some final polish may be needed around error handling conventions and documentation clarity before the series is ready for merging.
