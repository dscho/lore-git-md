This is part 3 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch converts the boolean `is_delta` field in `struct object_info` into a 4-state enum that can represent full objects, offset deltas, ref deltas, and an "unknown" state for cases where the delta status hasn't been determined.

The change prepares for a future fix where Git will properly skip parsing objects when no object-specific data is requested. Currently the code always determines delta status, but with the upcoming change there will be cases where this isn't known. The enum provides a clean way to represent this while maintaining type safety.

The patch touches `odb.h` to define the new enum and `packfile.c` to update the type checks. It's a straightforward mechanical conversion that maintains all existing behavior while adding the infrastructure needed for the subsequent fix. As part of the well-reviewed ODB abstraction series, this change has already been approved by Karthik Nayak and other reviewers.
