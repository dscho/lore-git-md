This is part 2 of an 11-patch series implementing submodule gitdir path encoding, a feature that prevents filesystem conflicts in submodule directories by introducing configurable path encoding. The series has gone through 8 iterations and is now ready for merging, with Junio Hamano's approval.

The patch centralizes validation of submodule gitdir paths by moving checks into `submodule_name_to_gitdir()`, which now always validates paths before returning them. This eliminates redundant validation calls and ensures all paths (including future config-specified ones) get validated. The change simplifies the API while maintaining safety - two validation calls remain in `builtin/submodule--helper.c` to handle parallel clone races.

Adrian Ratiu is the primary implementer of this feature, with extensive review from Patrick Steinhardt and others. The series represents a significant architectural change to submodule handling, introducing runtime configuration through `extensions.submodulePathConfig` after rejecting build-time approaches. This patch in particular is a mechanical refactoring that improves consistency without changing behavior, part of the final polish before merging.
