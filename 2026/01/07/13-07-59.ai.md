This is a v4 patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The series refactors how Git reads information about objects, with improvements to loose and packed object handling. It follows up on previous review feedback, particularly from Karthik Nayak, and is now ready for integration pending one final style adjustment.

The key changes in v4 focus on improving the loose object handling in `object-file.c` by restructuring the function to use a single exit path via `goto cleanup`, as suggested by reviewers. This makes the code more maintainable despite being a larger change than the original patch. The series maintains all the previous improvements from v3, including a 9% speedup in disk usage calculations, cleaner packfile interfaces, and more consistent object type tracking via a new enum.

The patches touch core object-handling code in `object-file.c`, `packfile.c`, and related headers, with changes that are well-contained and low-risk. The series has received thorough review from Karthik Nayak (GitLab ODB team) and others, with all substantive feedback addressed. The remaining discussion centers on code style rather than functionality, showing the series is technically sound and ready for the next step in the ODB abstraction effort.
