This is the first patch in Patrick Steinhardt's v4 series refactoring Git's object info handling as part of the ODB abstraction effort. The patch focuses on improving the loose object reading code in `object-file.c`.

The key changes in this specific patch:
- Restructures `odb_source_loose_read_object_info()` to use a single exit path via `goto cleanup` pattern as requested by reviewers
- Ensures the `whence` field is always set to `OI_LOOSE` for successful reads
- Improves error handling by guarding cleanup operations and moving variable initialization closer to usage
- Renames variables to match Git's coding style (`status` -> `ret`)
- Maintains identical functionality while making the code more maintainable

The patch touches core object handling code but is focused on internal cleanup rather than behavior changes. It's part of a larger series that has already gone through multiple review rounds and received final approval from Karthik Nayak (GitLab ODB team). The changes here demonstrate careful attention to code quality that characterized the entire review process.
