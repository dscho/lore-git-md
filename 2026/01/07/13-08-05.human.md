This is patch 6/7 in Patrick Steinhardt's performance-focused series refactoring Git's object info handling for the ODB abstraction effort. The patch optimizes disk size lookups by skipping unnecessary object header unpacking when only the disk size is requested.

The change provides a measurable 9% speedup for `git rev-list --disk-usage` operations, as shown in the included benchmark. The implementation avoids parsing object headers when only the size is needed, while maintaining all existing functionality. The diff is small but impactful, touching only `packfile.c` to add a new condition and handle the OBJ_NONE case.

This patch follows the series' pattern of clean, focused improvements to the object storage layer. It has already been reviewed and approved by Karthik Nayak (GitLab ODB team) with no outstanding issues, making it ready for integration. The change is low-risk while delivering concrete performance benefits for a common operation.
