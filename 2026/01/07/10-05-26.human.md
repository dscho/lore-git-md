This is part 4 of a 9-patch series enhancing Git's promisor remote functionality. The patch refactors how filter options are handled in `git fetch`, converting a static global variable into a local one passed explicitly through the call chain.

Patrick Steinhardt approves the change, noting it reduces global state - a recurring theme in Git's ongoing code hygiene efforts. The patch itself is straightforward, moving the `filter_options` variable from file scope into `cmd_fetch()` and updating all functions that need access to it. This is preparatory work for later patches in the series that will add more sophisticated filter handling.

The change aligns with the series' broader goal of improving promisor remote support, though this particular piece is more about code structure than new functionality. Patrick's positive review suggests the approach is sound, and the patch appears uncontroversial - the kind of incremental improvement that typically gets merged quickly.
