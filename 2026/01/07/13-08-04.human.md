This is patch 5/7 in Patrick Steinhardt's v4 series refactoring Git's object info handling as part of the ODB abstraction effort. The patch simplifies the return value of `packed_object_info()` to just success/failure status rather than also encoding object type information, since no remaining callers need that dual-purpose return value.

The change makes the function's contract clearer and enables future optimizations by removing the need to read object types in some cases. The implementation updates all error paths to return -1 consistently and adjusts the one remaining caller (`packfile_store_read_object_info()`) to handle the simpler return value. The patch also adds clarifying documentation about the function's return value in packfile.h.

This is a straightforward cleanup that follows naturally from the earlier removal of the only caller that needed the object type return value (in patch 4/7). The change has been reviewed and approved by Karthik Nayak and others, with no outstanding concerns. It's a small but meaningful step in the larger ODB abstraction work.
