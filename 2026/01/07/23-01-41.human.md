This is part 7 of an 11-patch series implementing submodule gitdir path encoding to prevent filesystem conflicts. The series has been through multiple rounds of review and is now ready for merging, with Junio Hamano's ack.

The current email moves the `is_rfc3986_unreserved()` function from being a private helper in `credential-store.c` to a public utility in `url.[ch]`. This change supports the series' goal of safely encoding submodule names by making the URL encoding helper available to the submodule path handling code. The function checks whether a character is safe to appear in a URI without percent-encoding (alphanumerics plus '-', '_', '.', and '~').

This is a straightforward refactoring that follows good practice - moving a utility function to a more appropriate shared location when its use expands beyond its original context.
