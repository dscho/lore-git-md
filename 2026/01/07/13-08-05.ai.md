This is patch 6/7 in Patrick Steinhardt's series refactoring object info handling for the ODB abstraction effort. The patch optimizes disk size lookups by skipping unnecessary object header parsing when only the disk size is requested.

The key change is modifying `packed_object_info()` to avoid unpacking object headers when callers only need the disk size (as in `git rev-list --disk-usage`). The patch introduces a new `OBJ_NONE` case to handle this scenario while maintaining the existing behavior for all other cases. Benchmark results show a 9% speedup in disk usage calculations, which is a meaningful improvement for a common operation.

The implementation is clean and focused - it touches only the necessary logic in `packfile.c` while preserving all existing functionality. The change builds on the series' earlier work (particularly patch 3/7's enum introduction) and demonstrates the benefits of the refactored interface. With Karthik Nayak's approval and all prior feedback addressed, this appears ready for integration as part of the overall ODB abstraction effort.
