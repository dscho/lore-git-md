This is part of Patrick Steinhardt's ongoing ODB abstraction effort, specifically patch 3/7 in the v3 series. The patch extends the `is_delta` boolean field in `struct object_info` to a full enum (`PACKED_OBJECT_TYPE`) that can represent four states: unknown, full object, offset delta, or reference delta. This prepares for future changes where we may not always determine an object's type during info lookups.

The change touches `odb.h` (where the enum is defined) and `packfile.c` (where the type is set based on the object's actual storage format). Karthik Nayak reviews the change positively, noting it provides clearer information while maintaining safety against bad object types. The patch is part of a larger series that has already addressed all review feedback and is ready for integration, with demonstrated performance improvements (9% speedup in disk usage calculations) and interface simplifications.
