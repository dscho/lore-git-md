This is a refactoring patch in the submodule gitdir path encoding series, which implements runtime configuration for submodule paths to prevent filesystem conflicts. The series has already been reviewed and acked for merging by Junio Hamano.

The patch consolidates validation of submodule gitdir paths by moving ad-hoc checks into `submodule_name_to_gitdir()`, which now always validates paths before returning them. This ensures:
1. Consistent validation across all callers
2. Prevention of duplicate validation calls
3. Mandatory validation for user-provided paths (coming in later patches)

Key technical changes:
- Removes explicit validation calls from `clone_submodule()`, `submodule_move_head()`, and `relocate_single_git_dir_into_superproject()`
- Adds validation directly in `submodule_name_to_gitdir()`
- Maintains two remaining validation calls to handle parallel clone races
- Uses `die()` for validation failures to match existing error handling

The changes are mechanical and maintain the series' architectural approach of centralized path resolution. This patch follows up on v7 review feedback and is part of the final implementation ready for merging.
