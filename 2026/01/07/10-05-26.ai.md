This is a refactoring patch in the LOP (Large Object Promisors) series, specifically addressing global state in the fetch command. The patch converts the static `filter_options` variable in `builtin/fetch.c` into a local variable within `cmd_fetch()`, then passes it explicitly through the call chain to functions that need it. This is part of a broader effort to make filter handling more explicit and maintainable in preparation for the `--filter=auto` feature.

Patrick Steinhardt approves the change, noting his general preference for reducing global state. The modification is straightforward - it touches several functions in `builtin/fetch.c` to thread the filter options through, but doesn't change any behavior. This is a typical preparatory refactoring that makes subsequent functional changes easier to reason about by eliminating implicit state. The patch follows the series' pattern of first cleaning up the code structure before adding new functionality.
