This is a refactoring patch that moves a URL encoding helper function as part of the larger submodule gitdir path encoding series. The patch relocates `is_rfc3986_unreserved()` from being a static function in `builtin/credential-store.c` to a public function in `url.[ch]` where it can be reused by other parts of the codebase.

The change is motivated by the need to use this URL encoding function for submodule path handling in subsequent patches of the series. The function checks whether a character is unreserved according to RFC 3986 (A-Za-z0-9-._~), which will be used to safely handle submodule names in filesystem paths.

This is a straightforward change that:
1. Removes the static implementation from credential-store.c
2. Adds the public implementation to url.c
3. Exports it via url.h with documentation
4. Updates credential-store.c to use the new public version

The patch is well-contained and follows the project's coding style. As part of a larger series that has already received extensive review and Junio's ack, this change appears ready for merging.
