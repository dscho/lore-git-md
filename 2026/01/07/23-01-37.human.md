This is part 3 of an 11-patch series implementing submodule gitdir path encoding, a feature that prevents filesystem conflicts in submodule directories by introducing configurable path encoding. The series has already been reviewed and acked by Junio Hamano for merging.

The current patch adds a new `gitdir` subcommand to `git submodule--helper` that exposes the internal `submodule_name_to_gitdir()` function. This helper will be used in subsequent patches to validate and query submodule gitdir paths, which are being made configurable through a new extension. The implementation is straightforward - it takes a submodule name as input and outputs the computed gitdir path.

The patch builds on previous work by Brandon Williams and includes his sign-off. It's a small but necessary plumbing piece for the larger feature, which introduces runtime configuration of submodule paths through `extensions.submodulePathConfig` and related options. The series as a whole has gone through multiple iterations (now at v8) with all review feedback addressed.
