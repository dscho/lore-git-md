This is part 2 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch simplifies the interface by removing the OI_DBCACHED distinction, making all packfile objects report as OI_PACKED regardless of whether they are in the delta base cache.

The change affects three callers that check the `whence` field, all of which were treating OI_DBCACHED objects differently from OI_PACKED ones. The patch argues this distinction was an implementation detail that callers shouldn't need to care about, especially since the delta status is already available via the `is_delta` field. The modification gives callers consistent information while simplifying the code.

The patch removes the OI_DBCACHED enum from odb.h and updates packed_object_info() to always return OI_PACKED. This is a straightforward change that has already been reviewed and approved by Karthik Nayak and others as part of the larger series. The series as a whole is now ready for integration after multiple rounds of review.
