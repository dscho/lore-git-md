This is the final patch in Patrick Steinhardt's v4 series refactoring Git's object info handling for ODB abstraction. The series has already been approved and is ready for integration.

The patch removes a redundant `repository` parameter from `packed_object_info()`, since the same information is already available via the `packed_git` struct that's passed in. This is a straightforward cleanup that:

1. Simplifies the function signature by removing an unused parameter
2. Updates all callers to match the new signature
3. Maintains existing behavior since the repository pointer was already available through the packfile struct
4. Touches several files that call this function (`cat-file.c`, `pack-objects.c`, `commit-graph.c`, `pack-bitmap.c`, `packfile.c`, `packfile.h`)

The change is mechanical and low-risk, building on the previous patches in the series that already established the pattern of using the repository pointer from the packfile struct. This completes the interface cleanup work started earlier in the series.

With this final patch, the series achieves its goal of improving the object info handling code for the ODB abstraction effort while providing measurable performance improvements (9% speedup in disk usage calculations from patch 6/7) and cleaner interfaces. The changes have been thoroughly reviewed by Karthik Nayak and others on the GitLab ODB team, with all feedback addressed.
