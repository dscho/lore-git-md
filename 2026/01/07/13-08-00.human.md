This is part of Patrick Steinhardt's v4 patch series refactoring Git's object info handling for the ODB abstraction effort. The series has already been approved after multiple review rounds with Karthik Nayak and others.

Patch 1/7 restructures the loose object handling code in `object-file.c` to use a single exit path via `goto cleanup` pattern, addressing reviewer feedback to make the code more maintainable. The key changes:

- Consolidates multiple exit paths into one cleanup section to ensure consistent behavior
- Renames variables to match Git's style (`status` -> `ret`)
- Moves variable initialization closer to usage
- Adds guards for cleanup operations
- Resets object info pointers in a single place

While the diff is somewhat noisy due to indentation changes, the result is cleaner and more maintainable code. The patch maintains all existing functionality while making it easier to reason about control flow and resource cleanup. This is a mechanical refactoring that doesn't change behavior, just improves code structure as part of the larger ODB abstraction work.
