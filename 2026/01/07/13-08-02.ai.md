This is part 3 of Patrick Steinhardt's 7-patch series refactoring Git's object info handling for the ODB abstraction effort. The patch extends the `is_delta` boolean field in `struct object_info` to a 4-state enum (`PACKED_OBJECT_TYPE`) that can represent unknown, full, ref-delta, and ofs-delta object types. 

The change prepares for a future fix where we'll need to represent an unknown delta state when skipping object parsing for empty info requests. The enum provides more precise type tracking than the current boolean while maintaining the same functionality. The patch touches `odb.h` (adding the enum) and `packfile.c` (updating the type checks), with straightforward mechanical conversions at all call sites.

This is a well-contained preparatory change in the ODB abstraction series, following the pattern of earlier patches that have already been reviewed and approved. The enum approach is a clear improvement over the boolean and aligns with the series' goal of making the object storage interfaces more maintainable and future-proof.
