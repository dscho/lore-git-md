Thread identity: Patch series introducing new `tab-between-non-ws` whitespace check for documentation files, authored by Adrian Ratiu.

Core problem/goal: Detect and optionally fix cases where tabs appear between non-whitespace characters in documentation (particularly .adoc files) where a space was likely intended, while preserving legitimate tab usage for indentation/alignment. Requires accounting for tab expansion width to determine when a tab would visually appear as a single space.

Current status: v2 of patch incorporating Junio Hamano's feedback about highlighting and fixing capabilities. Includes comprehensive test coverage in t4015-diff-whitespace.sh.

Key technical details:
- New WS_TAB_BETWEEN_NON_WS flag in ws.h
- Core logic in ws.c tracks character position and visual column position
- emit_middle_section() modified for tab highlighting
- Enabled by default for Documentation/**/*.adoc via .gitattributes
- Test cases cover various tab positions and widths (4,8,etc)
- Supports git diff highlighting and git apply --whitespace=fix

Participant positions:
- Junio Hamano suggested the feature and reviewed v1
- Adrian Ratiu implemented the feature and addressed review feedback in v2
- No outstanding objections or requested changes at this time

Related work: Builds on existing whitespace checking infrastructure (ws.c) used by git diff and git apply. Specifically extends the whitespace checking capabilities rather than modifying core behavior.
