Thread identity: Patch series introducing new whitespace check for documentation files (originally named `tab-between-non-ws`), authored by Adrian Ratiu, with Junio Hamano and Johannes Sixt providing review feedback. Now in third iteration focused on test improvements.

Core problem/goal: Detect and optionally fix cases where tabs appear between non-whitespace characters in documentation (particularly .adoc files) where a space was likely intended, while preserving legitimate tab usage for indentation/alignment. Requires accounting for tab expansion width to determine when a tab would visually appear as a single space.

Current status: v2 patch incorporated Junio's naming and test presentation feedback, now being refined based on Johannes Sixt's test-specific suggestions. Discussion has converged on renaming the whitespace rule to "tab-instead-of-space" and improving test coverage.
