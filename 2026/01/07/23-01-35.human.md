This is part 1 of an 11-patch series implementing runtime-configurable submodule gitdir paths, now in its 8th iteration and ready for merging. The series as a whole introduces a new `extensions.submodulePathConfig` option that allows customizing where submodule gitdirs are stored, with fallback mechanisms for path conflicts.

This particular patch is a small refactoring that updates `add_submodule()` in `builtin/submodule--helper.c` to use the centralized `submodule_name_to_gitdir()` helper function rather than hardcoding the path construction. This change ensures consistent path handling across all submodule operations and fixes some test failures that surfaced during development of the larger feature.

The patch is straightforward - it replaces direct string formatting with a call to the existing helper function and cleans up some related variable scoping. Since this is part of a well-reviewed series that has already received Junio's ack, we can expect it to merge cleanly. The change aligns with the series' goal of making submodule gitdir paths consistently configurable while maintaining backward compatibility.
