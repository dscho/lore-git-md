This is part 6 of an 11-patch series implementing submodule gitdir path encoding, now in its 8th iteration. The series adds runtime configuration for submodule gitdir paths via a new `extensions.submodulePathConfig` extension, rejecting all build-time options in favor of pure runtime configuration.

This specific patch introduces a migration command `git submodule--helper migrate-gitdir-configs` to automate converting existing submodules to the new path configuration scheme. The command scans `.git/modules/` and for each submodule found, creates a corresponding `submodule.<name>.gitdir` config entry if one doesn't already exist. It also ensures the repository format version 1 and enables the path config extension.

Key technical details:
- The migration is atomic - it either fully succeeds or fails cleanly
- Includes validation of gitdir paths via `create_default_gitdir_config()`
- Handles repository format version requirements
- Adds comprehensive test coverage including:
  - Legacy module conversion
  - Clone behavior with/without the extension enabled
  - Path validation
  - Repository format handling

The implementation builds on the series' core architecture of centralized path resolution through `submodule_name_to_gitdir()`. This patch completes the migration piece that was previously manual-only, making the feature more practical for real-world use.
