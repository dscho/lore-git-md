This is a refactoring patch in the submodule gitdir path encoding series, which is now in its final form and ready for merging. The patch updates `git submodule--helper add` to use the centralized `submodule_name_to_gitdir()` helper function rather than hardcoding the path to `.git/modules/`. This change ensures consistent handling of submodule gitdir paths across the codebase, particularly important now that the path encoding extension allows for configurable gitdir locations.

The patch makes two key changes:
1. Replaces the hardcoded path construction with a call to `submodule_name_to_gitdir()`
2. Switches from a heap-allocated string to a strbuf for the gitdir path in the clone case

This is a mechanical change that aligns with the series' goal of centralizing gitdir path resolution. The patch is small (13 lines changed) and focused, with no behavior changes beyond what's needed for consistency with the new path encoding system.
