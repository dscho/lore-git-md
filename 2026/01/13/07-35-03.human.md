Bugfix for remote-curl HTTP authentication in the `probe_rpc()` path. This patch addresses an edge case where servers requiring Bearer token authentication would fail during operations like filtered clones when the `probe_rpc()` function (used for capability checks on large requests) didn't include authentication headers.

The v3 patch from Aaron Plattner incorporates review feedback from Patrick Steinhardt to combine setup and test into one subtest and properly clean up the test repository used for verification. The test demonstrates the scenario by creating a large repo with 2000 refs (to trigger `probe_rpc`), setting a small `http.postBuffer` to force the probe, and verifying clone with Bearer auth works correctly.

This appears to be a well-constructed fix for a real-world authentication issue affecting users of token-based auth with large repositories. The patch has gone through multiple iterations with constructive review feedback and now looks ready for inclusion.
