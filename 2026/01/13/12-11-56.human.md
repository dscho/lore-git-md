This is the second and final patch in Harald Nordgren's series to enhance `git status` to show divergence from both upstream and push tracking branches. The patch has been through 25 iterations of review and is now approved by Junio C Hamano for merging into `next`.

The implementation adds push tracking comparison to `git status` output when the push destination differs from the upstream branch. The output shows both relationships in a consistent format, with the push comparison on a new line. For instance, when tracking `origin/main` but pushing to `origin/feature`, it will show divergence from main and ahead/behind status for the feature branch.

The patch includes extensive test coverage (285 new lines in t6040-tracking-info.sh) that verifies behavior across various scenarios: diverged upstream vs ahead push, upstream ahead but push up-to-date, remapped push refspecs, multiple remote configurations, and `--no-ahead-behind` behavior. The implementation properly handles edge cases and maintains all existing output formats and advice messages.

Key technical changes include:
- New `get_remote_push_branch()` helper to resolve push references
- Extended `format_tracking_info()` to handle both upstream and push comparisons
- Renamed flags to `ENABLE_ADVICE_PULL/PUSH/DIVERGENCE` for clarity
- Maintains quick mode (`--no-ahead-behind`) behavior
- Shows divergence advice for both upstream and push branches when enabled

The patch represents a well-tested, carefully reviewed feature that cleanly extends Git's status reporting while maintaining backward compatibility. After addressing all feedback through 25 versions, it's now ready for wider testing in `next`.
