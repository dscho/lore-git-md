This is the first of two patches in Harald Nordgren's series to enhance `git status` with push tracking branch divergence. The patch refactors existing code in preparation for the new feature.

The change extracts the branch comparison formatting logic from `format_tracking_info()` into a new helper function `format_branch_comparison()`. This centralizes the message generation for all branch status cases (up-to-date, ahead, behind, diverged) while maintaining the existing behavior including quick mode (`AHEAD_BEHIND_QUICK`). The refactoring cleanly separates the formatting logic from the upstream branch state detection.

The patch follows Git's style guidelines and includes thorough handling of edge cases like gone upstream branches. It preserves all current output formats and advice messages while making the code more maintainable. The changes are mechanical and focused - this is clearly preparation work for the actual push tracking feature that will follow in patch 2/2.

This refactoring has been through 24 iterations of review and is now merge-ready, with Junio Hamano's approval. The implementation looks solid and well-tested, with all feedback from previous rounds incorporated. The next patch will build on this foundation to add the push tracking divergence display.
