Bugfix targeting the remote-curl HTTP authentication flow. This patch addresses an issue where probe_rpc() requests (used when post_rpc() needs to check server capabilities for large requests) weren't including authentication headers, causing failures when fetching from servers requiring Bearer token authentication.

The patch demonstrates a clear problem scenario where a clone with blob filters succeeds initially but fails during checkout when probe_rpc() hits a 401 error. The fix is straightforward - adding http_append_auth_header() to probe_rpc() - and comes with a thorough test case that:
1. Creates a large repository with 2000 refs to trigger the probe_rpc path
2. Configures a small http.postBuffer to force the probe
3. Verifies the clone works with Bearer auth

The test setup is robust, using test_when_finished for cleanup and demonstrating the real-world impact. The v3 changes incorporate review feedback to combine setup and test into a single subtest and properly clean up the large test repository. This appears to be a well-motivated fix for an authentication edge case that could affect users of token-based auth with large repositories.
