This is part 2 of a 3-part series (part of the `the_repository` removal effort) that moves configuration variables from global scope to repository-specific storage. The patch focuses on converting the `core.sparseCheckout` boolean config value to live in the new `struct repo_config_values` embedded in `struct repository`.

The change follows the same pattern established in part 1 (which handled `core.attributesFile`), updating all access points to read from the repository-specific config struct rather than the global `core_apply_sparse_checkout` variable. The patch touches 12 files across various commands that interact with sparse checkout functionality, including `sparse-checkout`, `clone`, `grep`, `mv`, and `worktree`.

Key technical changes include:
- Adding `sparse_checkout` field to `struct repo_config_values`
- Updating `git_default_core_config()` to store the value in the repository struct
- Converting all direct accesses of `core_apply_sparse_checkout` to use `repo->config_values.sparse_checkout` instead
- Removing the global `core_apply_sparse_checkout` declaration
