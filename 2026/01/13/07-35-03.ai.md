This is a bugfix patch for HTTP authentication in remote-curl, specifically in the probe_rpc() path. The patch addresses an issue where probe_rpc() requests (used for capability checks on large HTTP requests) weren't including authentication headers, causing failures when fetching from servers requiring Bearer token authentication.

The v3 iteration incorporates review feedback from Patrick Steinhardt, combining setup and test into a single subtest and properly cleaning up the test repository created for the test case. The test demonstrates the scenario by creating a large repo with 2000 refs (to trigger probe_rpc), setting a small http.postBuffer to force the probe, and verifying clone with Bearer auth works correctly. The patch appears ready for merging, with Patrick giving his approval in this final version.
