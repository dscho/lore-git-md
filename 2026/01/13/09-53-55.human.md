This is a test modernization patch from GSoC participant Shreyansh Paliwal, continuing the effort to fix Git exit code suppression in test scripts. The patch specifically targets test #365 in t5500-fetch-pack.sh, which verifies shallow fetch behavior with commit graphs.

The thread had previously converged on using `packetize` directly with variables rather than file operations, but Shreyansh discovered that approach introduced newline issues in the protocol v2 communication. This revised version instead uses `test-tool pkt-line pack` to properly format the protocol packets while still maintaining the desired properties of proper error propagation and shell portability.

The change moves the packet construction outside the here-doc, storing object IDs in variables first, then using the test helper to format them correctly for the protocol. This appears to be a robust solution that addresses all the concerns raised earlier in the thread - it properly propagates errors, avoids bashisms, and correctly implements the protocol requirements.
