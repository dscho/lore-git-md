This is a maintainer response to a reported bug involving pre-push hook performance. Junio C Hamano notes that the regression (introduced in commit 857f047e) might be related to a previous discussion about hook execution behavior. The bug causes pre-push hooks that read from stdin to slow down dramatically, from seconds to over a minute, which impacts CI/CD workflows.

The issue has been bisected to the problematic commit and affects all current integration branches. Junio suggests looking at a prior thread (linked) that discussed similar hook execution concerns, though he doesn't propose a specific fix yet. The regression appears connected to stdin handling changes in hooks after the ungroup option was made configurable. This affects real-world use cases where hooks process stdin, making it a significant performance regression for affected workflows.
