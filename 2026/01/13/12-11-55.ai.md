This is the first of two patches in Harald Nordgren's v25 series to enhance `git status` with push tracking branch divergence information. The patch is a refactoring that extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` helper function.

The refactoring cleanly separates the concerns of determining branch state (still handled by `format_tracking_info()`) from formatting the output (now in the new helper). This prepares for patch 2/2 which will reuse this formatting logic for both upstream and push tracking branches. The changes maintain all existing behavior including:
- Quick mode (`AHEAD_BEHIND_QUICK`) output
- Pluralization handling for commit counts
- Divergence advice messages
- Upstream-gone special case

Key technical details:
- Renames `sti` variable to `cmp_fetch` for clarity
- Moves the complex formatting logic with all conditional branches into the new helper
- Preserves exact same output strings and advice triggers
- Keeps the same parameter passing for `ahead_behind_flags` and advice display

The patch follows Git's coding style and has been through 25 iterations of review, with all feedback addressed. It represents a clean preparatory step for the push tracking functionality to come in patch 2/2.
