This is a bugfix for the remote-curl HTTP authentication handling, specifically addressing an issue where probe_rpc() requests weren't properly including authentication headers. The patch comes from Aaron Plattner at NVIDIA and is in its third iteration.

The core problem occurs when cloning large repositories with blob filters: the initial authentication works for the main request, but subsequent probe_rpc() calls (triggered when the request exceeds http.postBuffer size) fail with 401 errors because they don't include the auth headers. The patch fixes this by adding http_append_auth_header() to probe_rpc().

The commit includes a thorough test case that:
1. Creates a repository with 2000 refs to force large requests
2. Configures a small http.postBuffer to trigger the probe_rpc() path
3. Verifies cloning works with Bearer token authentication

The patch looks well-constructed with clear motivation, good test coverage, and has already incorporated feedback from Patrick Steinhardt in previous iterations. This addresses a real-world authentication edge case that could affect users of credential helpers like git-credential-msal when working with large repositories.
