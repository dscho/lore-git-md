This is a bugfix for the remote-curl HTTP authentication code, specifically addressing an issue where probe_rpc() requests weren't properly including auth headers when making large requests. The patch comes from Aaron Plattner at NVIDIA and has been tested by Lucas De Marchi.

The core issue occurs when cloning large repositories with blob filters: the initial authentication works for the first requests, but subsequent probe_rpc() calls (triggered when the request exceeds http.postBuffer size) fail with 401 errors because they don't include the auth headers. The fix is straightforward - just add the auth headers to probe_rpc() like other requests do.

The patch includes a detailed test case that:
1. Creates a repository with 2000 refs to force large requests
2. Configures a small http.postBuffer to trigger the probe_rpc path
3. Verifies the clone works with bearer token auth

This looks like a well-motivated fix with good test coverage. The commit message clearly explains the failure scenario and why the existing HTTP_REAUTH logic doesn't catch it. The credential helper interaction details might be of particular interest to those working on Git's HTTP authentication stack.
