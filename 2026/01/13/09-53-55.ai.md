This is a test modernization patch in an ongoing thread about fixing Git exit code suppression in test scripts. The specific test being modified is t5500-fetch-pack.sh #365, which verifies shallow fetch behavior with commit graphs.

The patch follows up on previous discussion where Junio Hamano and Patrick Steinhardt suggested simplifying the packet generation approach. The author initially proposed using `packetize` directly but found it caused protocol errors due to extra newlines. The revised solution uses `test-tool pkt-line pack` to properly format the protocol packets while avoiding the exit code suppression issue.

Key technical changes:
- Replaces the previous `packetize`-based approach with `test-tool pkt-line pack`
- Stores object IDs in shell variables (`oid_algo`, `oid_other`, `oid_main`) before packet generation
- Generates the protocol input in a separate step before passing to `git upload-pack`

The patch appears well-motivated and addresses the technical concerns raised earlier in the thread. It maintains the test's functionality while properly propagating exit codes and avoiding bashisms. This represents a good example of test modernization that could serve as a model for similar fixes elsewhere in the test suite.
