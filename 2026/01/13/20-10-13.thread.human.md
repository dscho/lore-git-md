Junio Hamano's January 2026 "What's cooking" report provides a comprehensive update on Git's development status. Several stable changes have recently graduated to 'master', including Jean-Noël Avila's documentation style updates, mailmap maintenance, test modernization work, and René Scharfe's unification of commit stack handling. These will ship in the next release.

New work is progressing across multiple fronts. Documentation improvements continue for stash, builtin APIs, and patch-id, alongside ongoing test modernization. More substantial technical efforts include Patrick Steinhardt's ref consistency checks, René Scharfe's removal of `the_repository` dependencies from tree APIs, and Johannes Schindelin's Windows symlink support. The report also notes active work on major architectural changes: the object database abstraction (led by Steinhardt), ref backend improvements, and brian m. carlson's SHA-1/SHA-256 Rust interoperability work.

Several topics remain in discussion or need revision before merging. The report shows Git's characteristic balance between incremental quality improvements and larger modernization efforts, with particular focus on codebase maintainability through the ongoing `the_repository` removal and platform-specific enhancements for Windows.
