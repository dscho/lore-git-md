Bugfix for remote-curl HTTP authentication in probe_rpc() path. The issue occurs when fetching from servers requiring Bearer token authentication - probe_rpc() requests (used by post_rpc() for capability checks on large requests) weren't including authentication headers, causing 401 failures during operations like filtered clones. The fix adds http_append_auth_header() to probe_rpc(). The test case demonstrates the scenario by: 1) creating a large repo with 2000 refs to trigger probe_rpc, 2) setting small http.postBuffer to force the probe, and 3) verifying clone with Bearer auth. V3 incorporates review feedback to combine setup and test into one subtest and properly clean up the test repo. This addresses an authentication edge case affecting users of token-based auth with large repositories.
