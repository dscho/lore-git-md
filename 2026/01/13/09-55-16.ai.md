This is the final version of Harald Nordgren's feature series enhancing `git status` to show divergence from both upstream and push tracking branches, now approved for merging into `next`. The v24 iteration makes two key refinements to the advice-display logic:

1. Renames the branch mode flags to better reflect their purpose (ENABLE_ADVICE_* rather than BRANCH_MODE_*)
2. Simplifies the push branch resolution by removing the redundant `full_ref_out` parameter from `get_remote_push_branch()`

The implementation now cleanly handles:
- Displaying divergence information for both upstream and push branches when they differ
- Maintaining all existing output formats and advice messages
- Preserving quick mode (`--no-ahead-behind`) behavior
- Showing appropriate advice for both upstream and push branches when enabled
- The core refactoring in patch 1/2 centralizes formatting logic in `format_branch_comparison()`
- Patch 2/2 adds push tracking support with 262 lines of test coverage in t6040-tracking-info.sh

Key technical details:
- Uses ENABLE_ADVICE_PULL/PUSH/DIVERGENCE flags to control advice display
- Handles remapped push refspecs through `get_remote_push_branch()`
- Maintains same output format on new line for push tracking
- Preserves all edge case handling from previous versions

The series has undergone 24 iterations with feedback from Phillip Wood (advice consistency), Junio Hamano (final approval), and others. All major technical requirements are met, though potential follow-ups could address `push.default` interactions beyond the current `push.default=current` assumption. The implementation represents a complete feature ready for wider testing in `next`.
