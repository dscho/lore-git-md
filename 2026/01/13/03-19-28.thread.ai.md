Thread identity: Bugfix for HTTP authentication in `remote-curl.c` affecting `probe_rpc()` requests during clone operations with bearer tokens.

Core problem: When cloning large repositories with blob filters where requests exceed `http.postBuffer`, the `probe_rpc()` call fails with 401 errors because it wasn't including authentication headers despite the main request having successfully authenticated. This breaks bearer token authentication flows for large requests.

Current status: Patch v1 proposes adding `http_append_auth_header()` to `probe_rpc()` to fix the missing auth headers. The change is minimal (2 lines) but comes with thorough test coverage.

Key technical details:
- Fix targets `probe_rpc()` in `remote-curl.c`
- Test creates repo with 2000 refs to force large requests
- Configures small `http.postBuffer` to trigger `probe_rpc()`
- Uses `git-credential-msal` for bearer token auth testing
- Verifies both failure case and successful fix
