This is the first patch in a 2-part series that enhances `git status` to show divergence from both upstream and push tracking branches. The series has gone through 24 iterations and is now approved for merging into `next`.

The patch refactors the `format_branch_comparison()` function to prepare for the push tracking functionality coming in patch 2/2. It extracts the comparison formatting logic from `format_tracking_info()` into a new helper function, maintaining all existing behavior including the quick mode (`AHEAD_BEHIND_QUICK`) and advice messages. The refactoring creates a clean separation between the caller and helper functions while preserving all output formats.

Key changes include:
- Moving the core comparison logic to `format_branch_comparison()`
- Renaming variables for clarity (`cmp_fetch` instead of `sti`)
- Maintaining identical output behavior
- Keeping all advice messages and pluralization handling
- Preparing the ground for push tracking support in the next patch

The implementation follows project conventions and has been thoroughly reviewed, with all feedback from previous iterations addressed. This foundational refactoring enables the push tracking feature while ensuring no regression in existing functionality. The patch represents the culmination of extensive discussion and refinement over multiple versions.
