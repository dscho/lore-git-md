This is a test modernization effort, specifically addressing exit code suppression in test #365 of t5500-fetch-pack.sh. The patch comes from GSoC participant Shreyansh Paliwal as the final iteration of a solution that was previously discussed and refined with input from Patrick Steinhardt and Junio Hamano.

The test verifies shallow fetch behavior with commit graphs, and the patch improves it in two key ways: First, it stores Git command outputs in variables upfront using `&&` chaining to properly catch failures. Second, it replaces the manual packet construction with `test-tool pkt-line pack` to ensure proper protocol formatting while avoiding the exit code masking that occurred in the previous here-doc approach.

Junio has already approved this solution, praising its use of the right tool (`test-tool pkt-line pack`) for the job. The changes make the test both more robust (by properly propagating exit codes) and clearer (by separating the packet generation from the upload-pack invocation). This serves as a model for similar test modernization work elsewhere in the suite.
