This is a test modernization effort, specifically addressing exit code suppression in test #365 of t5500-fetch-pack.sh. The patch comes from GSoC participant Shreyansh Paliwal as the final iteration of a solution that has evolved through review feedback from Patrick Steinhardt and Junio C Hamano.

The test verifies shallow fetch behavior with commit graphs, and the original implementation had several issues: it used a complex here-doc structure that masked Git command failures through command substitution and pipes, and it manually constructed protocol packets in a way that could introduce formatting errors. The new version stores object IDs in shell variables (`oid_algo`, `oid_other`, `oid_main`) up front to catch failures immediately, then uses `test-tool pkt-line pack` to properly format the protocol input before passing it to `git-upload-pack`.

Junio has already approved this approach, specifically praising the use of `test-tool pkt-line pack` as the right tool for protocol formatting. This serves as a model for similar test modernizations elsewhere in the suite where protocol interaction is needed while maintaining proper error detection. The patch is clean separation of concerns - first gathering all required data, then formatting it correctly, and finally executing the test operation - making it both more robust and easier to understand.
