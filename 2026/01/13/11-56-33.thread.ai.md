Thread identity: Bugfix patch addressing a regression in Git's hook subsystem output handling, specifically for the pre-push hook. Authored by Chris Darroch with input from brian m. carlson.

Core problem: A recent change made hook output always redirect stdout to stderr, which broke the pre-push hook's ability to use stdout and stderr separately as it historically could. The patch makes this behavior configurable via a new `stdout_to_stderr` option in `run_hooks_opt`, defaulting to 1 (backward compatible) while explicitly setting it to 0 for pre-push hooks.

Technical details: Modifies `hook.c` and `hook.h` to add the configuration option, and updates `transport.c` to set the option appropriately for pre-push hooks. Small change (8 lines net) focused on restoring historical behavior while making the output handling more flexible.

Status: Patch is based on current master, has passed CI testing, and appears ready for review. Maintains backward compatibility while fixing the regression.

Related work: Part of ongoing hook subsystem improvements, though not directly tied to Adrian Ratiu's larger hook configuration work. The change is self-contained and doesn't appear to conflict with other in-flight hook-related patches.
