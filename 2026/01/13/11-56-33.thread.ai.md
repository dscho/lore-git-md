Thread identity: Bugfix discussion addressing a regression in Git's hook subsystem output handling, specifically for the pre-push hook. Authored by Chris Darroch with participation from brian m. carlson, Patrick Steinhardt, Adrian Ratiu, Junio C Hamano, Jeff King (Peff), and now Kristoffer Haugsbakk.

Core problem: A recent change caused all hooks to redirect stdout to stderr by default, breaking the pre-push hook's ability to use separate streams. The issue has two components: the stdout/stderr separation regression and a deeper stdin feeding issue in `feed_pipe` when not using `ungroup=1`.

Current status: Adrian Ratiu's v2 patch implements the agreed-upon solution for stdout/stderr separation with comprehensive test suite. The implementation adds a `stdout_to_stderr` flag to `run_hooks_opt` (defaulting to 1) while explicitly setting it to 0 for pre-push hooks. Kristoffer Haugsbakk has reviewed and acked the patch, confirming it addresses the reported issue. The stdin feeding issue identified by Peff remains open for future work.

Technical details: The solution preserves the pre-push special case while fixing the regression from recent hook API changes. Key changes include:
- New `stdout_to_stderr` configuration option in hook API
- Special handling for pre-push hook in transport.c
- Output ungrouping fix for pre-push case
- Comprehensive test coverage in `t/t1800-hook.sh` for all hook output behaviors
Peff's analysis revealed a separate stdin feeding issue in `feed_pipe` that may need either requiring `ungroup=1` or enhancing the poll mechanism.

Open questions: The stdout/stderr separation fix is validated and ready for merging. The stdin feeding issue remains open with two potential solutions:
1. Require ungroup when using feed_pipe (possibly via BUG())
2. Enhance poll mechanism to properly handle child input readiness

Participant positions: Chris Darroch reported the issue. Patrick Steinhardt raised test coverage concerns. Adrian Ratiu implemented the stdout/stderr solution with tests. Junio Hamano provided historical context and approved the approach. Jeff King identified the separate stdin feeding issue. Kristoffer Haugsbakk has reviewed and acked the current patch. Consensus exists on the stdout/stderr fix while stdin feeding remains for future work.

Related work: Part of ongoing hook subsystem work, though not directly tied to Adrian Ratiu's larger hook configuration effort. The test coverage added here serves as a foundation for future changes. The stdin feeding issue may require revisiting hook execution machinery design.
