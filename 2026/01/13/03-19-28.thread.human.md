This thread addresses a bug in HTTP authentication where `probe_rpc()` requests during clone operations weren't including authentication headers, causing 401 errors for large requests (particularly with bearer tokens). The issue surfaces when cloning repositories with blob filters where requests exceed `http.postBuffer`.

The fix is straightforward - adding `http_append_auth_header()` to `probe_rpc()` in `remote-curl.c`. The comprehensive test setup creates a repository with 2000 refs to force large requests and uses `git-credential-msal` for bearer token testing.
