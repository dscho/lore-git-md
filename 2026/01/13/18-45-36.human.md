This is a documentation patch in Jean-Noël Avila's ongoing effort to convert Git's man pages to a consistent synopsis-style AsciiDoc format. The current discussion focuses on formatting guidelines for command examples in the git-bisect documentation.

Jean-Noël responds to Junio's request for clarification about when to use `[synopsis]` blocks versus verbatim formatting in documentation. He explains that when a section transitions from being a concrete example to a command model/synopsis (as this patch does by replacing specific script names with placeholders), it may be appropriate to use the `[synopsis]` style for consistency. However, he notes this isn't a hard rule yet - the project is still establishing these conventions.

The exchange represents a meta-discussion about documentation standards rather than substantive changes to the git-bisect content itself. The underlying patch (which updates placeholders and formatting) has already been reviewed and approved, with this being a follow-up about establishing clearer guidelines for future contributors working on similar documentation conversions.
