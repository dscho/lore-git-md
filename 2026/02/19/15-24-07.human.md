This is a test fix addressing an issue with whitespace handling in `git cat-file`'s `%(rest)` placeholder. The test in `t1006-cat-file.sh` was failing when object names contained spaces (like "HEAD:path with spaces") because the whitespace made it ambiguous where the object name ended and the `%(rest)` content began.

Deveshi Dwivedi's solution replaces the problematic object name with its resolved OID (object ID), which is guaranteed to be a hexadecimal string without whitespace. This makes the parsing unambiguous while maintaining the test's original purpose. The patch removes a FIXME comment and converts a conditional `test_expect_failure` into a straightforward `test_expect_success`.

The change is small and focused, touching only the test file. It demonstrates a clear understanding of the issue and provides a clean solution that improves test reliability. The commit message explains both the problem and solution well.
