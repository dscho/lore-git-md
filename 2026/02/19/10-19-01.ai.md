This is a build system patch addressing dependency tracking for `config-list.h` generation in both Meson and Makefile builds. Phillip Wood confirms successful testing of the Meson changes, verifying that the header properly regenerates when documentation files change (including with tricky path names containing special characters).

The patch implements robust dependency tracking by:
- Having `generate-configlist.sh` produce a depfile listing all documentation sources
- Handling path escaping for special characters (spaces, octothorpes) in both build systems
- Using a single optimized sed command for depfile generation (addressing Windows performance concerns)
- Maintaining identical behavior between Meson and Makefile builds

Key technical points:
- Meson integration uses `depend_files` for the script and depfile output
- Makefile creates `.depend/config-list.h.d` and includes it
- Path escaping handles all problematic characters that could appear in filenames
- The solution assumes documentation edits will reference new config files

The patch appears ready with positive testing feedback from both Phillip Wood and Patrick Steinhardt. While some stylistic questions about printf vs echo remain open (as noted in the commit message), the core functionality is complete and validated across platforms. This provides a robust solution to prevent stale builds from documentation changes.
