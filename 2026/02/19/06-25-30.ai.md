This is a CI/build system patch that fixes an issue with GitHub Actions workflows for Meson build tests on Windows.

The patch corrects a misconfiguration where the Meson test script was being executed by PowerShell instead of Bash, causing the tests to silently fail without proper execution. Patrick Steinhardt identifies that while the step was running, the POSIX shell script wasn't actually being executed due to the wrong shell interpreter being specified.

The fix is straightforward - changing the shell from PowerShell (`pwsh`) to Bash for the test execution step. This matches how other shell script steps are configured in the workflow.
