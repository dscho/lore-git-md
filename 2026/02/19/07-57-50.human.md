This is a bugfix patch in Patrick Steinhardt's series addressing ref iteration issues in bitmap and bisect functionality. The patch specifically fixes a bug where Git would hit a BUG() when processing exact ref matches in the "pack.preferBitmapTips" configuration.

The issue occurs when users specify an exact reference (like "refs/heads/main") rather than a reference prefix (like "refs/heads/"). The current implementation incorrectly tries to trim the entire refname, leading to an empty string and triggering a BUG(). The fix follows the same approach used in a previous ref exclusion pattern fix (10e8a9352b) by automatically appending a trailing slash to the pattern if missing, ensuring proper hierarchy matching.

The patch includes:
- Documentation updates clarifying the expected format (hierarchy patterns with trailing slashes)
- Code changes to handle the trailing slash logic
- Comprehensive tests in both t5310-pack-bitmaps.sh and t5319-multi-pack-index.sh
- Memory management improvements via STRBUF_INIT

This is part of a larger effort to consolidate and fix ref iteration patterns across Git's codebase. The series has received maintainer approval from Taylor Blau and incorporates feedback from Jeff King and others. The changes maintain backward compatibility while fixing the immediate issue and aligning with Git's ref matching conventions.
