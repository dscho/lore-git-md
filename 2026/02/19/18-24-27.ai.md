This is a CI/build system patch series that has now been marked for integration by Junio. The series from Patrick Steinhardt improves test infrastructure reliability across GitLab and GitHub CI, with particular focus on Windows/MSVC builds using Meson.

The v2 series has been accepted after addressing all identified issues, including Johannes Schindelin's Windows+VS test-slicing fix in patch 5/7. The final patch (7/7) completes the standardization by adding three key MSVC+Meson failure handling components to GitLab CI that were already present in GitHub CI: test output printing, artifact collection, and proper after_script handling. This creates full parity between the two CI systems for Windows/MSVC builds.

Key technical changes include standardized test-slicing implementation (with Windows+VS specific corrections), identical test execution paths via the `ci/run-test-slice-meson.sh` script, and consistent `TEST_OUTPUT_DIRECTORY` for test artifacts. The series emerged from debugging MSVC+Windows CI failures and now provides robust cross-platform testing infrastructure.

With Junio marking the topic for 'next', this work is now on track for inclusion in an upcoming release. The series demonstrates Git's commitment to reliable cross-platform testing by addressing concrete Windows/MSVC edge cases and unifying behavior between CI providers.
