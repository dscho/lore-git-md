This is part of Patrick Steinhardt's CI/build system patch series (v2 5/7) that standardizes test infrastructure across GitLab and GitHub CI, particularly for Windows/MSVC builds using Meson. The patch specifically addresses test-slicing consistency between Make and Meson builds.

The change makes Meson's test-slicing behavior one-based (like Make) rather than zero-based, modifying both the GitHub workflow YAML and the Meson test-slicing script. The patch includes a subtle but important fix for the GitHub workflow where test slice numbers now increment properly for Visual Studio builds, addressing a concrete CI failure case that Johannes Schindelin identified in earlier discussion.

This is a mechanical change that completes the standardization of test-slicing behavior across build systems, with the Meson implementation now matching Make's one-based numbering scheme. The patch is part of a larger effort to make Git's test infrastructure robust across platforms, particularly for Windows/MSVC builds, and has already been picked up by Junio for integration after receiving review feedback.
