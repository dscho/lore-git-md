This is a refactoring patch that's part of Patrick Steinhardt's series fixing ref iteration bugs in bitmap and bisect functionality. The patch consolidates duplicate logic for iterating over preferred bitmap tips (configured via `pack.preferBitmapTips`) into a new `for_each_preferred_bitmap_tip()` function.

The changes remove duplicate code from `builtin/pack-objects.c` and `repack-midx.c` by introducing a shared helper function in `pack-bitmap.c`. The refactoring also makes `bitmap_preferred_tips()` file-local since it's now only used internally. This is a clean mechanical change that doesn't modify behavior - it just prepares for the actual bugfixes in later patches.

The patch follows Git's typical refactoring style: small, focused, with clear commit message explaining both the what and why. It's part of a well-structured series that has already received maintainer approval from Taylor Blau, with positive feedback from other contributors like Jeff King and Karthik Nayak. The changes align with Git's direction on ref handling while solving immediate technical problems.
