[PATCH v2 3/7] meson: set MERGE_TOOLS_DIR for tests on Windows

This patch fixes a test failure in Git's mergetool tests when running with --no-bin-wrappers on Windows. The core issue is that MERGE_TOOLS_DIR environment variable, normally set by bin-wrappers, was missing in this configuration, causing tests to look in the wrong location for mergetool scripts. Patrick Steinhardt's solution adds one line to t/meson.build to explicitly set MERGE_TOOLS_DIR to the correct directory path in the source tree. This ensures tests can find the tools regardless of bin-wrapper usage. The change is minimal and targeted, with the commit message clearly explaining both the problem and solution. This is part of a larger series (v2 3/7) about Meson and CI improvements, though the full context isn't provided in this individual patch. The fix addresses a testing gap that was previously masked by a CI bug on Windows platforms.
