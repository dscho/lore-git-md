This is a bugfix patch in Patrick Steinhardt's series improving Meson build system support, specifically addressing Windows test failures. The issue occurs when running tests with `--no-bin-wrappers` (a Windows performance optimization) where the mergetool directory location isn't properly set.

The patch ensures the `MERGE_TOOLS_DIR` environment variable is always set during tests, fixing a case where mergetool scripts couldn't be found when bin-wrappers are disabled. This was previously masked by a CI bug that prevented Windows tests from running.

The change is minimal (one line added to `t/meson.build`) but important for correct test execution. As part of a larger series (v2 3/7), it shows Patrick's continued work on the Meson build system integration, following his pattern of thorough, well-explained patches. The fix is straightforward and unlikely to be controversial.
