This is a build system patch addressing dependency tracking for `config-list.h` in both Meson and Makefile builds. The patch ensures this generated header stays in sync with Git's documentation files that define configuration options, fixing cases where documentation changes weren't properly triggering rebuilds.

D. Ben Knoble's v5 iteration provides complete coverage for both build systems, with key improvements including:
- A dual-mode `generate-configlist.sh` that generates both the header and a depfile
- Comprehensive path escaping handling special characters
- Single optimized sed command for Windows performance
- Identical behavior between Meson and Makefile builds

The patch has received thorough review from Patrick Steinhardt and Phillip Wood, with all test suites passing across platforms. While there's a minor stylistic question about printf vs echo remaining open, the technical implementation appears sound and ready for merging. This solution could serve as a pattern for similar generated header dependencies in the future.
