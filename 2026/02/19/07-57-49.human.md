This is a refactoring patch that's part of Patrick Steinhardt's series fixing ref iteration bugs in bitmap and bisect functionality. The patch consolidates duplicate logic for iterating over preferred bitmap tips (configured via `pack.preferBitmapTips`) into a new `for_each_preferred_bitmap_tip()` function.

The change removes duplicate code paths in `pack-objects.c` and `repack-midx.c` that were both subtly wrong in how they handled exact refname matches. The new helper function is now the single point of truth for this iteration logic, with the original `bitmap_preferred_tips()` function made file-local since it's no longer needed outside `pack-bitmap.c`.

This is a preparatory change that enables the subsequent fixes in the series. The patch has already received maintainer approval from Taylor Blau and positive feedback from other contributors. It's a clean refactoring that doesn't change behavior yet, but sets up the architecture for the fixes that follow.
