This is a follow-up discussion in a bugfix thread about `git format-patch`'s `--from` option handling in cover letters. Jeff King (Peff) reflects on the historical context of the feature, noting he originally implemented the `--from` option in 2013 but never considered its interaction with cover letters since he doesn't use that feature himself.

The exchange reveals an interesting workflow detail - while Jeff assumed most people use `git send-email`'s cover letter generation, D. Ben Knoble points out the documentation actually shows using `git format-patch` to create cover letters. Jeff acknowledges this may explain why the inconsistency went unnoticed for so long, as most users likely don't set different `--from` values than their committer identity.

The discussion doesn't introduce new technical changes to the patch (which was already approved for merging in v4), but provides useful background about why this edge case existed. Jeff humorously questions his own original motivation for implementing the `--from` option at all, calling it one of the mysteries of the cosmos. This lighthearted aside from a long-time contributor adds color to the thread while confirming the fix addresses a real, if rarely encountered, inconsistency.
