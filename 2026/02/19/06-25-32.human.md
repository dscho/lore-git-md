This is part 6 of a 7-patch series improving CI test infrastructure, now picked up by Junio for integration. The series standardizes test execution across GitLab and GitHub CI, with particular focus on Windows/MSVC builds using Meson.

This specific patch aligns GitLab CI's test execution with GitHub's by using the shared `ci/run-test-slice-meson.sh` script rather than open-coding the Meson test parameters. The change ensures both CI systems use identical Meson options when running tests. The patch is straightforward - it replaces a direct Meson invocation with the standardized script, maintaining the same parallel test slicing behavior but through a common interface.

The series as a whole has been thoroughly reviewed, with Johannes Schindelin contributing a Windows-specific fix in an earlier patch. With all identified issues addressed, this final version represents a robust standardization of test infrastructure across platforms and CI providers.
