This is a test modernization patch that follows up on prior suggestions from Jeff King and Junio Hamano about simplifying test scripts. The patch eliminates temporary files in several test cases by piping `test_seq -f` output directly to Git commands like `update-ref` and `mktree`.

The changes are mechanical replacements across six test scripts in the refs and archive test suites. The original patterns either used `printf` with `test_seq` to generate temporary files, or used `test_seq -f` but still wrote to temporary files unnecessarily. The new approach streams the sequence data directly via pipes.

Junio notes in his reply that while the changes are an improvement, temporary files can sometimes be useful for debugging when tests fail, as they preserve the exact input that was used. However, he acknowledges this isn't important enough to block the patch, which follows established patterns they've previously recommended.

The patch appears uncontroversial as it aligns with ongoing test modernization efforts and has clear precedent in prior discussions. The changes are focused on test infrastructure rather than core functionality, touching only test scripts in `t/` directory. The author (Aaron Plattner) credits Jeff King and Junio for the original suggestions that motivated the cleanup.
