This is a code hygiene patch in the ongoing ODB (object database) abstraction effort, specifically addressing type safety in object-file.c. The original patch from Justin Tobler converted direct pointer casts to the safer `container_of()` macro pattern when working with object read streams and transactions. Patrick Steinhardt (a key driver of the ODB work) has reviewed and approved the changes, noting they make the code more robust by removing dependence on struct member ordering.

The changes are purely internal - no user-visible behavior is affected. This appears to be a straightforward improvement that aligns with the project's broader effort to modernize and make the object storage layer more maintainable. Given Patrick's approval and the mechanical nature of the changes, this patch seems ready to progress toward merging.
