This is a CI/build system patch series from Patrick Steinhardt that has now been picked up by Junio for integration. The series improves test infrastructure reliability across GitLab and GitHub CI, with particular focus on Windows/MSVC builds using Meson.

The v2 series addresses several issues that emerged during debugging of failing MSVC+Windows jobs in GitLab CI. Key fixes include standardizing test-slicing logic to use one-based numbering across all build systems (with a Windows+VS specific correction from Johannes Schindelin), ensuring consistent Meson test execution between CI providers, and adding proper failure diagnostics and error handling in test infrastructure. The series now provides full parity between GitLab and GitHub CI for MSVC+Meson builds.

Notable technical changes span multiple files: CI configs for both platforms, test execution paths, MERGE_TOOLS_DIR handling in meson.build, and shell interpreter corrections. The final patch adds test failure reporting via ci/print-test-failures.sh and artifact collection in t/failed-test-artifacts for GitLab CI, matching GitHub's existing behavior while using Git for Windows' bash.

The series appears well-tested and complete, with all identified issues addressed including Schindelin's Windows+VS specific test-slicing fix that corrected a concrete CI failure case. This represents the final piece in making Git's test infrastructure robust across platforms, particularly for Windows/MSVC, and demonstrates the project's commitment to cross-platform testing rigor.
