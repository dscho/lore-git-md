CI / build system patch from Patrick Steinhardt that improves error handling in the test-slicing helper script. This is part of a larger series (v2, 1/7) about meson build improvements, though the cover letter wasn't provided in this digest.

The change modifies `ci/run-test-slice.sh` to properly capture the output of the test-slicing helper before piping it, ensuring any errors from the helper are detected rather than being lost in the pipeline. The script uses this helper to divide the test suite across parallel CI jobs. The patch splits what was previously a single pipeline into two steps: first storing the test list in a variable, then formatting and passing it to make.

This is a straightforward robustness improvement that should prevent silent failures when the test-slicing helper encounters problems. The change is small and focused - just moving the helper invocation out of the pipe while maintaining the same overall functionality. As the first patch in a series, it appears to be setting up groundwork for later meson-related CI changes.
