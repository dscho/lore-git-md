This is part of Patrick Steinhardt's CI/build system patch series (v2 5/7) that standardizes test infrastructure across GitLab and GitHub CI, particularly for Windows/MSVC builds using Meson. The series has been picked up by Junio for integration.

The patch makes test slicing consistent between Meson and Make builds by changing the Meson test slicing script from zero-based to one-based numbering, matching the behavior established in the previous patch. The change requires a corresponding adjustment in the workflow YAML file to increment the slice number for GitHub CI jobs.

Johannes Schindelin identified and fixed a Windows+VS specific issue where test-slicing numbering remained zero-based for Visual Studio builds, which this patch now properly handles. The change is straightforward but important for consistency across build systems and CI providers. With this fix, the series achieves full parity between GitLab and GitHub CI for MSVC+Meson builds.
