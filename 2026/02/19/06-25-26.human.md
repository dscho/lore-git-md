CI/build system patch series improving test infrastructure reliability, now ready for integration.

Patrick Steinhardt's 7-patch series addresses several CI test infrastructure issues, particularly for Windows/MSVC builds using Meson. The key improvements include standardizing test-slicing to use one-based numbering across all build systems (fixing a bug where GitLab CI was skipping the first test), unifying Meson tests execution between GitLab and GitHub CI, and adding proper failure handling for MSVC+Meson jobs. Johannes Schindelin contributed a fix for Windows+VS builds where test-slicing numbering needed adjustment.

The series now has all identified issues addressed, including the Windows-specific correction, and Junio has picked it up for integration. This represents the final piece in making Git's test infrastructure robust across platforms with full parity between GitLab and GitHub CI systems. The changes touch CI configuration files, test execution paths, and Meson build settings, demonstrating the kind of cross-platform testing rigor needed for Git's diverse build environments.
