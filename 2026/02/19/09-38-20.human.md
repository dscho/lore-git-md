This is a refactoring patch that cleans up how repository reference databases are initialized. It's part of a larger series (1/6) from Karthik Nayak focused on reference storage handling.

The patch removes an unnecessary side effect in `create_reference_database()` where it was redundantly setting the repository's ref storage format. The function is only called in two places (git-init and git-clone), and in both cases the format is already properly set before calling. The current behavior could cause issues if the format structure grows to include dynamically allocated strings.

The changes are straightforward - removing the format parameter from the function signature and its call sites. The patch looks like a clean, logical simplification that removes duplicate work without changing any actual behavior. This appears to be preparatory work for the series' later patches that will deal more substantially with reference storage formats.
