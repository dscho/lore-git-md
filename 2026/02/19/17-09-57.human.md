This is a test modernization patch that follows up on prior suggestions from Jeff King and Junio Hamano to simplify test scripts by eliminating temporary files when generating sequences for Git commands. The patch updates six test scripts across the refs and archive test suites to use `test_seq -f` with direct piping instead of writing to temporary files first.

The changes are mechanical replacements of two patterns: converting `printf`+`test_seq` combinations that wrote to temp files, and simplifying `test_seq -f` usages that still used temp files when they could pipe directly. Junio notes the improvements make the tests more concise, though he observes that temporary files can sometimes be useful for debugging when tests fail. The patch appears uncontroversial as it follows established test modernization patterns that have been discussed and approved before. It's a straightforward cleanup that makes the test code slightly more maintainable without changing any test behavior.
