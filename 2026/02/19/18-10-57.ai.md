This is a documentation patch that corrects the man page for `git-format-patch` to properly reference `format.noprefix` instead of `diff.noprefix`. The change uses AsciiDoc conditionals to show the correct config variable depending on whether the documentation is being rendered for `git-format-patch` or other commands.

The patch follows up on an earlier change where `format.noprefix` was introduced as a format-patch-specific option, while the documentation still incorrectly claimed it respected the diff-specific `diff.noprefix` setting. The new version properly documents that `--default-prefix` overrides `format.noprefix` for format-patch, while keeping the reference to `diff.noprefix` for other commands.

Junio Hamano has reviewed and queued the patch, noting that while the AsciiDoc conditional syntax is new to Git's documentation, the approach makes sense. The change is straightforward and uncontroversial, aligning the documentation with the actual implementation behavior where `git-format-patch` has always ignored `diff.noprefix` in favor of its own `format.noprefix` setting.
