CI/build system patch completing test infrastructure improvements for Windows/MSVC builds. This is the final patch in Patrick Steinhardt's series to standardize test execution across GitLab and GitHub CI environments, now picked up by Junio for integration.

The patch adds failure handling for MSVC+Meson test jobs in GitLab CI, matching the existing GitHub CI behavior. When tests fail, it now runs the test failure reporting script and collects artifacts in `t/failed-test-artifacts`. The changes ensure both CI systems handle test failures identically, using Git for Windows' bash to execute the reporting scripts.

This completes the series' goal of making test infrastructure robust across platforms, particularly for Windows/MSVC builds. Johannes Schindelin previously contributed a fix for Windows+VS test-slicing numbering in patch 5/7, and this final patch ensures the remaining gap in failure handling is addressed. The series demonstrates careful attention to cross-platform testing edge cases.
