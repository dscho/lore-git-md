This thread addresses a segfault in `git clone` when using the `--revision` flag with the older v0/v1 protocols. The original fix attempt by Jayce Cao would have masked a deeper issue where `.peer_ref` isn't properly set in these cases. 

Junio Hamano, the maintainer, identified the root cause and suggested restructuring the code to properly handle the `--revision` case by splitting functionality from `update_remote_refs()` and making its call conditional. Jayce agreed with this approach and is seeking clarification on whether `find_ref_by_name()` should also be made conditional, since `--revision` detaches HEAD.

The discussion reveals this is a protocol-specific edge case where older versions don't properly initialize refs during `--revision` clones. Jayce plans to add tests once the team agrees on the correct fix approach. This appears to be a genuine bug that requires careful handling to avoid introducing subtle issues while resolving the immediate crash.
