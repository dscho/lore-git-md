René Scharfe continues his long-running effort to eliminate `the_repository` global variable with another focused refactoring patch. This change modifies `read_mmblob()` to take an explicit object database parameter rather than implicitly using the global, propagating this change through several merge-related files. The patch also includes a small cleanup to use `is_null_oid()` instead of a more verbose hash-algorithm-dependent check.

Patrick Steinhardt reviewed an earlier version, suggesting the changes could have been split for clarity but approving the combined patch given its small size. Junio Hamano has now weighed in, noting that passing the full repository structure would have been an alternative approach but agreeing with the current minimal approach of passing just the object database. Both maintainers are satisfied with the change, which follows René's characteristic style of small, precise refactorings that improve code hygiene without altering core logic. With no outstanding concerns, this appears ready to merge as part of the broader `the_repository` removal effort.
