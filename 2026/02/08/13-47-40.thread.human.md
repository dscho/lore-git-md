René Scharfe continues his ongoing effort to remove implicit dependencies on the global `the_repository` variable. This latest patch refactors the `read_mmblob()` function to take an explicit `struct object_database *` parameter instead, propagating this change through callers in several merge-related subsystems (`apply.c`, `checkout.c`, `merge-file.c`, `merge-ort.c`, and `notes-merge.c`). 

The changes follow René's characteristic style - small, focused, and mechanically sound. Each caller is updated to pass `the_repository->objects` explicitly, making the object database dependency visible without altering core logic. As a bonus, the patch also replaces `oideq(oid, null_oid(the_hash_algo))` checks with the more generic `is_null_oid(oid)`, further reducing hash-algorithm dependencies. This work is part of the broader `the_repository` removal effort that has been steadily progressing through the codebase.
