This is a documentation patch proposing updates to the color.diff configuration options. Alejandro Colomar points out that `color.diff.commit` currently only affects the commit hash color, despite the documentation suggesting it applies to all commit headers (Author, Date, etc.). He suggests two changes: first, updating the docs to clarify that 'commit' only affects the hash, and second, adding a new 'header' slot to control coloring of the other commit metadata fields.

The patch is straightforward and well-motivated, addressing a small but clear documentation mismatch. The proposed solution seems reasonable, though it would need implementation work beyond just the doc change. The email is just a proposal at this stage - no actual patch is attached, so this appears to be an RFC-style exploration of the idea before writing code.
