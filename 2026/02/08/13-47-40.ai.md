This is a refactoring patch as part of the ongoing `the_repository` removal effort. René Scharfe continues his work to eliminate implicit dependencies on the global `the_repository` variable by making the `read_mmblob()` function take an explicit `struct object_database *` parameter instead. The change propagates this new parameter through several callers in `apply.c`, `checkout.c`, `merge-file.c`, `merge-ort.c`, and `notes-merge.c`.

The patch also replaces `oideq(oid, null_oid(the_hash_algo))` with the more generic `is_null_oid(oid)` check, further reducing hash-algorithm dependencies. This is a straightforward mechanical change that follows the project's established pattern for removing `the_repository` usage - pushing the dependency up to callers rather than having functions implicitly rely on globals.

The changes are consistent with René's typical style - small, focused, and mechanically sound. Each caller is updated to pass `the_repository->objects` explicitly, maintaining the same behavior while making the object database dependency visible in the interface. The patch touches several merge-related subsystems but doesn't change their core logic, just their object access patterns.
