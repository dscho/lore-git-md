This is a refactoring patch from René Scharfe, part of his ongoing effort to clean up and modernize Git's codebase. The change replaces a manually managed array of commits in the `rev_collect` struct with the existing `commit_stack` utility, which provides the same functionality with less boilerplate.

The patch touches `commit.c`, specifically the `get_fork_point()` function which finds where a branch diverged from another ref. The main changes are:
- Replacing the custom array management (`commit`, `nr`, `alloc`) with `struct commit_stack`
- Converting the loop counter to `size_t` to match the stack's size type
- Updating all related operations to use the stack API (`push`, `init`, `clear`)

This is a straightforward quality-of-life improvement that reduces code duplication. As typical for René's patches, it's a clean, focused change with no behavior modifications. The commit message clearly explains what's being changed and why.
