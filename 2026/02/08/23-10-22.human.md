This is an update on the SHA-1/SHA-256 interoperability effort, part of the ongoing Rustification work in Git. brian m. carlson reports that version 3 of their patch series has been submitted, addressing CI breakages that were noted in Junio's "What's cooking" report. The series introduces Rust-based infrastructure for maintaining mappings between objects using different hash algorithms, a key requirement for repositories that need to interoperate between SHA-1 and SHA-256 formats.

The work touches several areas including object file conversion, hashfile wrappers, and new binary object map formats. This is a technically complex series that has been in development since November 2025, with v3 now resolving the immediate technical blockers. The changes span both C and Rust code, reflecting the project's gradual Rust integration strategy.
