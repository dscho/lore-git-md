This is a feature proposal to allow UTF-8 characters in Git alias names, currently restricted to ASCII alphanumerics and hyphens. The author, Jonatan Holmgren, suggests modifying `git_config_parse_key()` in config.c to specifically allow UTF-8 for alias.* keys while keeping other config keys ASCII-only, with case-sensitivity for non-ASCII aliases to avoid locale-dependent case folding complexities.

The proposal acknowledges platform-specific Unicode normalization challenges (particularly macOS's NFD vs NFC handling) and seeks feedback on whether this feature would be welcome, the proposed implementation approach, and any compatibility requirements to consider. The change would enable non-English speakers to create aliases in their native scripts (e.g. Swedish "förgrena" or Chinese "分支" for "branch").

The patch would touch config parsing internals but appears narrowly scoped to alias names. The RFC nature suggests the author is looking for design feedback before implementation, particularly around platform compatibility and whether the project wants to support this use case. The proposal is well-framed with clear examples and identifies the specific code constraints.
