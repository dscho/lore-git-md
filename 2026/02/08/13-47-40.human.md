This is a refactoring patch as part of the ongoing `the_repository` removal effort. René Scharfe continues his systematic work to eliminate the global `the_repository` variable by making the `read_mmblob()` function take an explicit `struct object_database *` parameter instead of implicitly using `the_repository->objects`.

The change is mechanical but touches several key areas that deal with blob reading during merges and diffs - including the apply machinery, checkout, merge-file command, and notes merging. Each caller now passes `the_repository->objects` explicitly. The patch also replaces an oideq(null_oid) check with the more direct `is_null_oid()`.

The changes are straightforward and follow the established pattern for `the_repository` removal - pushing the repository dependency up to callers rather than having it hidden in helper functions. This is part of making Git's object database handling more flexible by removing implicit assumptions about which repository is being operated on.
