This thread continues work on enabling UTF-8 support in Git configuration subsections (like `[alias "förgrena"]`), now in its seventh iteration in the `next` branch. The core functionality is working well, with recent focus shifting to polishing documentation and fixing edge cases.

A memory leak was discovered in the `--list-cmds=alias` functionality, where 37 allocations (totaling 1453 bytes) weren't being freed. Jacob Keller diagnosed the issue and proposed a straightforward solution - changing a `free_util=0` to `free_util=1` in `git.c`. While reviewing this fix, Junio Hamano noted a similar potential leak in `list_cmds_by_config()` that may need the same treatment, suggesting the solution should be applied more broadly.

The thread still has a few open items: a regression affecting dot-prefixed aliases (reported by Patrick Steinhardt as breaking Johannes Schindelin's workflow), some remaining documentation formatting issues (including visible `+` markers in HTML output), and now this memory leak fix that may need to be extended. The empty subsection compatibility issue has been resolved, and most documentation concerns have been addressed through follow-up patches from Jonatan Holmgren, the original author.
