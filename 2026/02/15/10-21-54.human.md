This is a translation (l10n) patch fixing a typo in the German localization file for Git. The patch corrects the spelling of the `allow-indentation-change` mode in the error message for `--color-moved-ws` from "allow-identation-change" to "allow-indentation-change". 

The issue was causing a frustrating loop where copying the suggested mode from the error message would fail because the suggestion itself was misspelled. The fix ensures the German translation matches the actual valid option name in the code.

The change is straightforward and uncontroversial, touching only a single line in the German `.po` file. It's a clear improvement that prevents user confusion when working with color-moved whitespace modes in the German locale.
