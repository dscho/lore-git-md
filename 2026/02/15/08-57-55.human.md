This is a refactoring series from Jeff King (Peff) that cleans up the ref-filter subsystem's lstrip/rstrip code. It builds on Collin Funk's earlier patch that addressed a compiler warning about const qualifiers in glibc-2.43.

The series consists of four patches that progressively simplify the code:
1. Factors out refname component counting into a helper function
2. Simplifies memory handling in `lstrip_ref_components()`
3. Does the same for `rstrip_ref_components()`
4. Open-codes the slash search in `rstrip_ref_components()` to eliminate the const warning issue entirely

Peff acknowledges this goes beyond just fixing the warning but argues the changes make the code more readable while solving the original problem. The first three patches are straightforward cleanups, while the fourth is slightly more involved but still low-risk. The series touches only ref-filter.c and reduces the code size by about 40 lines.

This appears to be a well-motivated cleanup from an experienced contributor, addressing both an immediate technical issue and some underlying code quality concerns. The changes are focused and unlikely to be controversial.
