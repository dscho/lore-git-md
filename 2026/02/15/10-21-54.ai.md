This is a translation (l10n) patch fixing a German localization error in the `color-moved-ws` configuration option. The current German translation misspells "allow-indentation-change" as "allow-identation-change" in the error message that suggests valid modes. This creates a frustrating loop where copying the suggested mode from the error message results in another error because the suggestion itself contains a typo.

The patch corrects the spelling in the German translation file (`po/de.po`), changing "allow-identation-change" to "allow-indentation-change" to match the English source text. This ensures users who copy the suggested mode from the error message will get a valid configuration value rather than hitting the same error again.

The change is straightforward and clearly correct - the typo was causing a real usability issue for German-speaking users trying to configure diff coloring behavior. The patch comes from Matthias Schwarzott, a Gentoo contributor who has previously sent similar l10n fixes.
