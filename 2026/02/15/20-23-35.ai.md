2. The same update succeeds when `--force` is specified

The test follows the existing pattern in `test_force_fetch_tag()` but exercises the command-line flag path rather than the refspec syntax. This lays groundwork for the series' second patch, which will modify `builtin/fetch.c` to make `--prune-tags` properly force-update tags as documented.
