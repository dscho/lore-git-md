Memory leak fix in shallow repository handling. This is the first of two patches in Samo Pogačnik's series addressing shallow clone/fetch operations, now at version 5 after thorough review.

The patch fixes a memory leak in `get_shallow_commits()` where the `stack` object_array was not being properly cleared before function return, leaving allocated elements dangling. The issue was caught by leak-checking tests that were added in the companion patch (2/2) for relative-depth fetching.

This is a straightforward cleanup that has been reviewed and approved by multiple contributors including Patrick Steinhardt and Junio C Hamano across five iterations. The fix is minimal - just a single line addition to call `object_array_clear()` - but important for correctness. The patch series as a whole demonstrates careful attention to resource management in the shallow clone infrastructure.
