This thread addresses a German localization issue in Git's configuration error messages. The original report identified that the German translation for the `color-moved-ws` option contained a typo in the suggested value "allow-indentation-change" (misspelled as "allow-identation-change"), creating a frustrating loop where users copying the suggestion would encounter the same error again.

Matthias Schwarzott, a Gentoo contributor with prior l10n experience, submitted a straightforward fix that corrects the spelling in `po/de.po` to match the English source text. The change resolves a real usability problem for German-speaking users configuring diff coloring behavior. Since this is a clear-cut translation correction with no technical implications, it's likely to be merged without further discussion.
