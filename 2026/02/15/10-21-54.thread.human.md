This thread concerns a straightforward but important fix for a German localization error in Git's `color-moved-ws` configuration option. The original patch from Matthias Schwarzott (a Gentoo contributor) corrects a misspelling in the German translation where "allow-indentation-change" was rendered as "allow-identation-change". This created a frustrating loop where Git's error messages would suggest the incorrect spelling, only to reject it again when users copied the suggestion.

Junio C Hamano has forwarded the patch to Jiang Xin, Git's internationalization coordinator, for inclusion. The change is uncontroversial - it simply fixes a clear typo in the German translation file (po/de.po) to match the English source text. As this is a straightforward correction with no outstanding questions or objections, it will likely be merged without further discussion.
