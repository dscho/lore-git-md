This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics. The report covers patches that have graduated to 'master' and 'next', new topics under consideration, and ongoing work in the 'seen' branch.

Several patches have recently graduated to 'master', including improvements to `git add -p` showing hunk decisions, HTTP transport authentication fixes, submodule path handling improvements, and various test cleanups. The submodule changes by Adrian Ratiu are particularly notable as they address filesystem collisions by encoding gitdir paths.

New topics under consideration cover a range of areas:
- `git merge-file` now honors configs outside repositories (Yannic Tausch)
- Sparse-checkout integration for `git merge-ours` (Shreyansh Paliwal)
- A new `--rework-with-file` mode for `git add -p` (Abraham Adekunle)
- Reference backend location configuration (Karthik Nayak)
- Parallel hook execution support (Adrian Ratiu)

Ongoing work includes significant architectural changes:
- The ODB (object database) transaction API is being made per-object-source (Josh Tobler)
- Major refactoring of object enumeration APIs (Patrick Steinhardt)
- Continued work on incremental MIDX repacking (Taylor Blau)
- Rust interoperability work for SHA-1/SHA-256 mapping (brian m. carlson)
- A new `git history` command for rewriting history (Patrick Steinhardt)

The report also notes several test fixes, documentation updates, and smaller improvements across various subsystems. Junio flags some topics as needing rerolls or additional review, and calls out specific conflicts or CI issues affecting certain patches. This snapshot shows Git development proceeding across multiple fronts, with particular focus on object storage improvements, submodule handling, and the ongoing Rust integration effort.
