This is a Rust infrastructure patch in brian m. carlson's series introducing SHA-1/SHA-256 interoperability. It adds a fundamental building block for Rust/C interop by defining an `ObjectID` struct that mirrors Git's C `struct object_id`.

The patch creates a new `src/hash.rs` file containing a `#[repr(C)]` struct that exactly matches the C layout, with a 32-byte hash array and algorithm identifier. This enables efficient FFI exchange between Rust and C code when working with object IDs, which will be critical for performance-sensitive operations like index-pack and pack-objects during hash algorithm conversion.

The implementation prioritizes direct C compatibility over Rust idioms, as evidenced by the explicit `#[repr(C)]` attribute and matching field names. This is part of the larger effort to support hash algorithm interoperability while introducing Git's first production Rust code. The patch is well-contained and follows the project's standard licensing boilerplate.
