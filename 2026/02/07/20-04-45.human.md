This is part of the ongoing Rustification effort, specifically patch 15/16 in a series introducing Rust infrastructure for SHA-1/SHA-256 interoperability. The patch adds a Rust wrapper around Git's hashfile functionality to enable writing binary object maps to disk.

The new `HashFile` struct implements Rust's `Write` trait, providing a clean interface between Rust code and Git's existing C-based file handling. This allows the object map code (introduced in previous patches) to write data either to memory (for testing) or to actual files (for production use), while maintaining the ability to compute checksums over the written data.

Key technical points:
- Wraps C functions `hashfd`, `hashwrite`, `hashflush`, and `finalize_hashfile`
- Preserves Git's existing checksumming behavior while providing a Rust-native API
- Handles chunked writes transparently (splitting large writes to avoid u32 overflow)
- Returns computed hashes in a properly sized Vec<u8> based on the hash algorithm

It builds on prior work that established Rust/C interop patterns and hash algorithm abstractions. The implementation appears well-considered, with proper error handling and memory safety through Rust's type system.
