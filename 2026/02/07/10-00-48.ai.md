This is the third and final patch in a v3 series removing `the_repository` global usage from `wt-status.c`, part of the ongoing `the_repository` removal effort. The patch focuses on replacing the global `the_hash_algo` with repository-specific hash algorithms (`s->repo->hash_algo` or `r->hash_algo`) in three locations within `wt-status.c`.

The changes are mechanical replacements that maintain identical behavior while removing global state dependencies. The affected code paths handle cherry-pick/revert state tracking (using `null_oid`) and checking for uncommitted changes (using the empty tree). The patch follows established patterns for this refactoring effort, consistently using the local repository's hash algorithm rather than the global one.

This appears to be a well-scoped, behavior-preserving change that completes the series' goal of eliminating `the_repository` usage from `wt-status.c`. The patch builds on the previous work in the series which established that all `struct wt_status *s` functions can safely use `s->repo` instead of global state. No new test coverage is added since this is purely an internal refactoring with no observable behavior change.
