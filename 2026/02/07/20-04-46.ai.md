This is a bugfix patch in the SHA-1/SHA-256 interoperability series, addressing an issue with zero-initialized object IDs. The patch ensures object IDs always have a valid algorithm specified, which is particularly important for the new Rust-based loose object map implementation.

The core issue stems from zero-initialized object IDs having their algorithm field set to zero (invalid), which causes problems when the Rust code compares these IDs. The fix modifies `repo_oid_to_algop()` to create a temporary copy of any input object ID with a zero algorithm, setting its algorithm to the repository's default before proceeding with the conversion.

This change maintains compatibility with existing code that relies on zero-initialized object IDs while ensuring the Rust infrastructure receives properly formed object IDs. The patch is small and focused, touching only the necessary conversion logic while preserving the function's existing behavior for valid inputs.
