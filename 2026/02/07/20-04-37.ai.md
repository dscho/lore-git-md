This is part 7 of a 16-patch series introducing Rust infrastructure for SHA-1/SHA-256 interoperability, marking Git's first major Rust usage. The series is authored by brian m. carlson and builds on prior hash-algorithm-agnostic work.

The patch adds safety and usability improvements to the `ObjectID` Rust struct, which represents Git object hashes. It introduces:
- A constructor (`new()`) that properly initializes object IDs with validation
- An algorithm getter (`algo()`) that returns a proper `HashAlgorithm` enum
- `Display` and `Debug` trait implementations for human-readable output
- Comprehensive tests verifying the formatting and behavior

The changes enforce proper handling of hash values by:
- Validating algorithm IDs when accessing them
- Ensuring hash slices are the correct length for their algorithm
- Providing panic-free error handling for invalid states
- Formatting object IDs consistently with Git's conventions

This is part of the larger effort to enable SHA-1 and SHA-256 repositories to exchange objects through new Rust-based infrastructure. The patch demonstrates careful attention to type safety and error handling at the Rust/C boundary, which is critical for this foundational work. The test coverage is thorough, verifying both normal cases and edge conditions.
