This is part of the ongoing Rustification effort in Git, specifically patch 6/16 in the third iteration of a series introducing Rust infrastructure for SHA-1/SHA-256 interoperability. The patch comes from brian m. carlson, who has been leading the hash algorithm abstraction work.

The patch adds a new helper function `hash_algo_ptr_by_number()` that provides a bridge between Rust's hash algorithm abstraction and Git's existing C implementation. This allows Rust code to obtain a pointer to the C `git_hash_algo` structure when needed for interoperability with existing C functions. The implementation includes both the C function definition and corresponding Rust FFI (Foreign Function Interface) bindings.

Key technical points:
- Adds a new C function that safely looks up hash algorithm structures by numeric ID
- Exposes this function to Rust via FFI in the new `src/hash.rs` module
- Includes bounds checking to prevent invalid algorithm IDs
- Maintains type safety while allowing Rust to interface with legacy C code

This is a foundational piece for the larger effort to make Git's object storage work with both SHA-1 and SHA-256 repositories. The patch appears well-contained and focused on its specific interoperability task, with proper error handling and documentation. As part of a carefully structured series, it follows the project's incremental approach to introducing Rust components while maintaining compatibility with existing C code.
