Documentation patch adding a practical example script for `git patch-id`. This is the second patch in a three-part series improving the `git-patch-id` man page.

The patch adds a concrete shell script demonstrating how to use `git patch-id` to map equivalent commits between branches. The script takes an upstream branch and local branch as arguments, generates patch IDs for both, then outputs pairs of commits that have matching patch IDs. This addresses a known usability gap where `git patch-id` is primarily useful in scripts rather than one-liners.

The example builds on prior discussion (referencing a Linus Torvalds email) about the command's scripting-oriented nature. The script shows the full workflow: generating two sorted lists of patch IDs, joining them, and formatting the output. It includes logic to handle optional limiting of the upstream commit range, either by count or by date.

The change is purely additive (+38 lines) with no modifications to existing content. The example ties into related functionality by cross-referencing `git-cherry(1)` while providing more direct mapping capabilities. This continues the series' focus on making `git patch-id`'s batch processing capabilities more discoverable through practical documentation.
