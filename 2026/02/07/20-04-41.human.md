This is a build system patch in the ongoing Rust infrastructure series for SHA-1/SHA-256 interoperability. It fixes a Windows/MSVC-specific linking issue that arises when building with Cargo under MSYS (as in Git for Windows CI).

The core problem is that MSYS puts Unix tools like `/usr/bin/link` first in PATH, which conflicts with MSVC's `link.exe` when Cargo tries to link binaries. The patch solves this by reordering PATH to prioritize MSVC tools while still allowing access to Unix utilities. This becomes important as the series introduces Rust build scripts that will invoke the linker directly.

The change is straightforward and well-explained, moving the PATH adjustment earlier in the script and making it MSVC-specific. The patch carries sign-offs from both brian m. carlson (the series author) and Ezekiel Newren (who is handling CI infrastructure for this effort). This continues the careful coordination between core functionality and build system concerns that has characterized the series.
