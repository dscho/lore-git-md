This is a CI/build system patch addressing the ongoing issue with uutils coreutils in Ubuntu's rolling release. Colin Stagner proposes a targeted fix that replaces just the problematic `dirname` command with GNU coreutils' implementation, rather than switching all CI jobs to stable Ubuntu images as Junio suggested earlier.

The patch modifies `ci/install-dependencies.sh` to create a symlink from `/usr/bin/dirname` to `/usr/bin/gnudirname` when available, working around a specific bug in uutils where `dirname "foo/."` incorrectly outputs "." instead of "foo". This approach is more surgical than previous suggestions, keeping most of the rolling release testing intact.

The change is well-motivated with a clear reference to the upstream uutils issue (#10508) and follows the pattern of an existing sudo.ws workaround in the same file. This represents a middle ground between Junio's conservative approach and Patrick Steinhardt's vision of using Git as a test case for uutils stabilization. The patch is small, focused, and appears technically sound for its stated purpose.
