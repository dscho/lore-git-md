This is the second patch in a documentation series improving the `git-patch-id` man page. It adds a practical example script showing how to use patch IDs to correlate commits between branches.

The script demonstrates a real-world use case: mapping commits from a feature branch to their equivalent commits in an upstream branch. It generates two sorted lists of patch IDs (one for each branch), joins them to find matches, and presents the results in a clear format. The example includes handling for limiting the commit range and uses temporary files for intermediate storage.

The patch builds on a discussion where Linus Torvalds noted that `git patch-id` is primarily useful in scripts rather than one-liners. The example makes this concrete by showing how to use the command effectively in a shell script context. The implementation is straightforward and well-commented, making it easy for readers to adapt for their own needs.
