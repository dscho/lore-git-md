This is a build system patch addressing an issue with the Meson build configuration. D. Ben Knoble fixes a problem where `config-list.h` (a generated header file containing Git configuration options) wasn't being rebuilt when its source documentation files changed. This caused test failures when configuration options were added or modified in the documentation.

The patch adds a new script `generate-configlist-deps.sh` that lists all the documentation files used to generate `config-list.h`, then makes the Meson build depend on these files. This ensures the header gets regenerated when any relevant documentation changes, matching the behavior of the traditional Make-based build.

The change is straightforward and well-motivated by a concrete test failure case (t9902-completion.sh failing due to missing submodule configuration options). The author notes they considered alternative approaches but chose this solution for its simplicity, while inviting feedback on whether a different dependency tracking method might be preferable.
