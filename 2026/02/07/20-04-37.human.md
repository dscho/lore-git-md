This is part 7 of a 16-patch series introducing Rust infrastructure for SHA-1/SHA-256 interoperability, marking Git's first major Rust usage. The patch focuses on the `ObjectID` struct, which represents Git object hashes in Rust.

The patch adds several key improvements to `ObjectID`:
- A constructor that validates hash lengths against the specified algorithm
- An algorithm accessor method with proper error handling
- `Display` and `Debug` trait implementations for human-readable output
- Comprehensive tests verifying the new functionality

The changes enforce type safety by preventing invalid algorithm IDs or improperly sized hashes from being used. The new formatting capabilities will be particularly useful for debugging and logging as this Rust infrastructure becomes more widely used in Git's codebase.
