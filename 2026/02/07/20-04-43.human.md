This is part of the Rustification effort, specifically patch 13/16 in a series introducing Rust infrastructure for SHA-1/SHA-256 interoperability. The patch adds cryptographic hashing functionality to the Rust codebase, building on earlier FFI exposure of Git's hash operations.

The patch introduces a `CryptoHasher` struct that provides safe Rust wrappers around Git's hash algorithms (SHA-1 and SHA-256). Key features include:
- Safe memory management via `Clone` and `Drop` implementations
- Support for incremental hashing through the `Write` trait
- Conversion to both `ObjectID` and raw byte vectors
- Comprehensive test coverage including empty blob/tree cases

The implementation uses the FFI-exposed hash functions from earlier in the series, maintaining safety through Rust's type system while allowing efficient interaction with Git's C code. The hasher is marked as safe for use with untrusted data when Git is compiled with collision-detecting SHA-1.

This is a well-structured patch that follows Rust idioms while integrating cleanly with Git's existing hash infrastructure. The tests verify both basic functionality and edge cases, and the implementation appears robust with proper memory management. As part of the larger Rustification series, this moves Git closer to having production Rust code while maintaining the safety and performance characteristics needed for core operations.
