Thread summary:

Sylvain Rabot proposes adding a `--keep-ignored` option to `git clean -fdx` to prevent accidental deletion of valuable ignored files like editor/debug configurations. The patch modifies `builtin/clean.c` but is presented as a proof-of-concept by a non-C-developer seeking feedback on the concept. Core questions are whether this functionality belongs in Git (vs. scripts) and how it should handle edge cases like nested ignore rules. The current behavior forces users to choose between thorough cleaning (risking data loss) and manual selective cleaning (more work). Implementation would need careful review performance impact of checking ignore patterns during cleaning.
