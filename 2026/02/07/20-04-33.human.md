This is a preparatory patch in brian m. carlson's multi-part series introducing Rust infrastructure for SHA-1/SHA-256 interoperability. The patch standardizes the hash algorithm type from `int` to `uint32_t` across several files to ensure consistent representation between C and Rust code.

The change affects core data structures like `struct object_id` and various hash algorithm lookup functions, making them use an explicit 32-bit unsigned integer for the algorithm identifier. This is groundwork for upcoming Rust components that will need to interface with these structures, ensuring type compatibility between the languages.

The patch is mechanical in nature, touching six files with straightforward type changes. It's part of a larger effort to enable hash algorithm interoperability while introducing Git's first production Rust code. The changes appear well-contained and focused on the stated goal of type alignment between C and Rust representations.
