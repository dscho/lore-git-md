This is part 15/16 of brian m. carlson's Rust infrastructure series for SHA-1/SHA-256 interoperability. The patch introduces a Rust wrapper around Git's hashfile functionality, enabling Rust code to write data to files while computing checksums.

The new `HashFile` struct implements Rust's `Write` trait, providing a safe interface to Git's C hashfile functions (`hashfd`, `hashwrite`, `hashflush`, `finalize_hashfile`). This allows the object map code from previous patches to write to both in-memory buffers (for testing) and real files (for production) using the same interface. The implementation handles chunking large writes to avoid overflow and properly finalizes the hash when done.

Key technical points:
- Wraps C hashfile operations in a Rust `Write` trait implementation
- Maintains type safety with proper `HashAlgorithm` integration
- Supports both incremental writing and finalization with checksum
- Includes FFI bindings for the underlying C functions
- Follows the series' pattern of thorough Rust/C interop with safety considerations

This is a supporting piece for the larger object map infrastructure, providing the file I/O layer needed to persist the binary object maps introduced in patch 14/16. The implementation is straightforward and well-contained, with clear safety boundaries between Rust and C.
