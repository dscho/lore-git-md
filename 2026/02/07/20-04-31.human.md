This is the first patch in a 16-part series introducing Rust infrastructure for SHA-1/SHA-256 interoperability, marking Git's first major Rust usage. The patch makes Rust a hard requirement for hash algorithm interoperability support, causing Git to die with an error if Rust is not available when compatibility mode is requested.

The change technically removes some existing functionality (the C-based loose object map implementation) but the authors argue this is acceptable since the interoperability features are already marked experimental and not fully functional. The patch updates several test scripts to conditionally run compatibility tests only when Rust is available, using a new RUST test prerequisite.

This is a foundational change for the larger interoperability effort, establishing Rust as a required component. The patch appears well-structured with thorough test coverage, though it's worth noting this represents a significant architectural shift in Git's build requirements. The change is coordinated with Ezekiel Newren's parallel work on CI infrastructure to ensure Windows/MSVC compatibility.
