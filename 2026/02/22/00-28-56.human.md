This is an infrastructure patch in Adrian Ratiu's parallel hook execution series (v2, patch 2/10). It introduces a new helper function to handle unsigned integer configuration values, which will be used by the upcoming 'hook.jobs' configuration option.

The patch adds `git_config_uint()` and related functions to parse and retrieve unsigned int values from Git configuration. This fills a gap in the config API which previously only supported signed ints and unsigned longs. The implementation follows the existing pattern of similar config value parsers, adding matching functions at each layer: low-level parsing (`git_parse_uint`), config set access (`git_configset_get_uint`), and repository-level access (`repo_config_get_uint`).

The change is straightforward and well-contained, with tests for the new functionality presumably coming in later patches of the series. As part of the parallel hooks infrastructure, this helper will support configuring the number of parallel hook jobs while avoiding the need to use oversized types (unsigned long) or signed types that don't match the semantic meaning of a job count.
