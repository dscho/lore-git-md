Thread identity: Bugfix for `git fsck` packfile verification, addressing an infinite loop during MRU list traversal.

Core problem: When `git fsck` verifies multiple packfiles, updating the MRU (most recently used) list during iteration could cause the traversal to revisit packs it had already processed, resulting in an infinite loop. This occurs in the object database (ODB) layer's pack access logic.

Current status: Patch v1 introduces a fix by adding a `skip_mru_updates` flag to prevent MRU list modifications during fsck's verification pass. Includes test case in t1050-large.sh that reproduces the issue.

Key technical details:
- Modifies `struct packed_git` to add `skip_mru_updates` flag
- Changes MRU update behavior in `install_packed_git()` when flag is set
- Test case placed in t1050-large.sh (unconventional location) because it naturally triggered the bug during development
- Touches object-file.c and packfile.c
