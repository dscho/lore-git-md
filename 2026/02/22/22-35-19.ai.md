This is a test modernization patch in the ongoing `repo-info` subsystem refactoring series. Lucas Seiki Oshiro responds to Patrick Steinhardt's feedback about patch 6/8, which proposes changing how NUL-formatted output is tested in `t1901-repo-structure.sh`. The key motivation - not initially clear in the patch description - is to avoid diffing binary files (containing NUL bytes) when tests fail, making failure output more readable. This approach was previously suggested by Junio Hamano in an earlier review.

The author acknowledges Patrick's point that both approaches require `tr` and neither is clearly superior technically, but clarifies the human-facing benefit: when tests fail, the diff output will show text rather than binary data. The author plans to make this rationale clearer in the next version of the patch. This continues the series' pattern of mechanical test modernization while incorporating review feedback, though Patrick's question about the relative merits of the approaches remains open pending the revised explanation.
