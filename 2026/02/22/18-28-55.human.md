Test modernization patch for the new `git repo` command series.

This is the second patch in a 4-part series introducing enhanced repository reporting functionality. The patch focuses on making the test suite more robust by:

1. Making tests hash-agnostic by replacing hardcoded SHA-1 values with `test_oid` calls
2. Improving portability by removing shell-specific syntax (like `$` quoting in arithmetic comparisons)
3. Using helper functions to count objects rather than hardcoding expected values

The changes affect two test files:
- t/t1900-repo.sh: Updates the object format test to work with any hash algorithm
- t/t1901-repo-structure.sh: Replaces static counts with dynamic calculations for references and objects

This appears to be solid preparatory work that follows Git's test modernization patterns. The patch maintains the same test coverage while making the tests more maintainable and portable. It's a typical test infrastructure improvement that should be uncontroversial, though reviewers may want to verify the dynamic calculations match the original test cases' intent.
