Bugfix for `git fsck` packfile processing that prevents an infinite loop. 

brian m. carlson reports a subtle interaction in how `git fsck` processes packfiles that can lead to an infinite loop. The issue occurs because the packfile verification process modifies the most-recently-used (MRU) list that's also used for iteration, causing the same pack to be processed repeatedly. The patch disables MRU updates during iteration to prevent this.

The fix adds a `skip_mru_updates` flag to the packfile iteration logic and includes a test case in t1050-large.sh that would trigger the infinite loop without the fix. The commit message explains the technical details clearly and notes the test placement (while unusual) was chosen because it naturally reproduces the issue.

This appears to be a well-motivated fix for a real issue, with a clear explanation of both the problem and solution. The patch is focused and includes test coverage. Given brian m. carlson's deep knowledge of Git's object storage layer, this fix is likely to be correct and worth reviewing.
