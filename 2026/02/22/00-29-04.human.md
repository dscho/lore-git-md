This makes it easier to enable parallel execution for hooks like pre-push by standardizing their output behavior.

The implementation ensures the setting is respected during repository initialization and cloning, with comprehensive tests verifying the interaction between global config, repository extensions, and parallel execution. The patch maintains backward compatibility while providing a migration path for tools that rely on pre-push hook stdout.
