This is a discussion about GSoC proposal submission format, related to the ongoing `the_repository` removal effort. Usman Akinyemi responds to Tian Yuchen's draft GSoC proposal about reducing Git's global state, which was shared via Google Doc link rather than inline text.

Akinyemi makes the case that mailing list culture expects proposals to be self-contained in emails, both for easier review and to create a permanent archive that future contributors can reference. The response suggests that requiring reviewers to follow links and copy content back into emails creates unnecessary friction.

While the technical content of Tian's proposal (about `the_repository` removal) isn't discussed here, this exchange highlights an important cultural norm in Git development - the preference for complete, self-contained email discussions rather than relying on external platforms or documents.
