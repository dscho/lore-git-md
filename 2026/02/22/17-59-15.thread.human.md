Tian Yuchen has proposed a GSoC project to work on reducing Git's global state, particularly `the_repository`, as part of the ongoing effort to make the codebase more modular. The initial proposal was shared via Google Doc link rather than inline text, which has drawn feedback about the Git project's preferred workflow.

Usman Akinyemi responded to emphasize that proposals should be submitted as self-contained emails rather than external document links. He explained that the traditional "giant wall of text" format is better suited to the Git community's email-based workflow, as it allows for easier discussion and archival. This exchange highlights an important cultural norm for new contributors to understand - the project strongly prefers all technical discussion to happen inline in email rather than through external documents or web interfaces.

The technical proposal itself remains in draft stage, seeking feedback from core contributors like René Scharfe who have been leading the `the_repository` removal effort. The project would involve converting functions across Git's codebase to take explicit `struct repository *` parameters instead of relying on the global variable. While the technical direction aligns with ongoing work, the discussion format may need adjustment to follow project norms before substantive review can begin.
