This is the first patch in a feature series enhancing `git repo info` with structured path reporting capabilities. The series is now focused solely on path reporting after splitting out structural metrics into a separate effort.

The patch introduces a `repo_info` context struct to encapsulate repository state, removing direct coupling to global variables. It also adds category key expansion (e.g. accepting "layout" to show all `layout.*` fields), improving scripting ergonomics while maintaining backward compatibility with explicit key requests.

Key technical changes include:
- New `struct repo_info` to pass repository context explicitly
- Category name expansion for grouped field access
- Threaded context through all value lookup functions
- Maintained existing field access patterns while adding new capabilities

The changes appear well-contained and focused, with clear motivation explained in the commit message. This foundational work enables the path reporting features in subsequent patches while following the project's direction of reducing global state usage. The patch includes thorough updates to the command's internal plumbing but no user-visible behavior changes beyond the new category expansion feature.
