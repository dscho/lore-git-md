This is patch 6/17 in Patrick Steinhardt's ref iteration API unification series. It introduces the core `refs_for_each_ref_ext()` function with an options struct to replace the existing proliferation of specialized ref iteration functions. The patch converts all callers to use the new unified interface while maintaining identical behavior.

Karthik Nayak provides a review that confirms the mechanical correctness of the conversion - replacing individual parameters with the new options struct and updating all existing iteration functions to use it. The changes are straightforward and maintain the same functionality, just with a more composable interface.

This is the key technical patch in the series that establishes the new unified API pattern. The rest of the series will build on this foundation to remove the old specialized functions. The review suggests the approach is sound and the implementation matches the stated goal of reducing interface complexity while maintaining flexibility.
