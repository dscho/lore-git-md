This is a test infrastructure patch in Patrick Steinhardt's series to change git maintenance's default strategy from "gc" to "geometric". The patch specifically addresses potential test failures in rebase tests (t34xx range) that would occur under the new maintenance strategy.

Justin Tobler provides a review confirming the technical approach but suggests adding a comment to clarify why the `gc.reflogExpire=never` setting is needed. The issue stems from Git's test suite hardcoding commit and reflog dates to 2005, which would cause the new geometric maintenance strategy to immediately expire these "ancient" reflog entries during normal maintenance. This wasn't previously an issue because the old gc strategy would skip maintenance when the object database was already optimized.

The patch modifies four rebase test files to disable reflog expiration, preserving the test behavior under the new maintenance defaults. Justin's review indicates this is the right solution but could benefit from additional documentation to help future maintainers understand the context. The change is part of a well-reviewed series that has already addressed similar test infrastructure concerns across multiple test files.
