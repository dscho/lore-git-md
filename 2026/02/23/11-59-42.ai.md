This patch is part of Patrick Steinhardt's ongoing ref iteration API unification effort (v2 08/17). It generalizes the namespace-aware ref iteration functionality by moving the namespace handling into the new `refs_for_each_ref_ext()` interface.

The key change is adding a `namespace` field to `struct refs_for_each_ref_options`, which allows callers to specify an arbitrary namespace (rather than always using the global `GIT_NAMESPACE`). The patch preserves all existing behavior - when a namespace is set, it still only yields refs in that namespace and properly handles exclude patterns - but now makes this functionality available through the unified API.

The implementation handles namespace concatenation with prefixes and rewrites exclude patterns to work within the namespace. Memory management for temporary buffers is properly handled with `strbuf` and `strvec`. The original `refs_for_each_namespaced_ref()` function is simplified to a thin wrapper that sets the namespace option.

This is a well-contained change that follows the series' pattern of incrementally migrating specialized iteration functions to the new unified interface. The patch has already been reviewed and approved by Karthik Nayak as part of the overall series.
