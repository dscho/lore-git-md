This is part of Patrick Steinhardt's ongoing effort to make Git's object database (ODB) subsystem pluggable. The patch series (now up to 17 parts) systematically refactors core ODB operations to use callback-based dispatch.

Patch 13/17 converts the `write_object()` operation to the new callback pattern. It:
- Adds a `write_object` callback to `struct odb_source` with clear documentation about expected behavior (including freshening existing objects and handling `WRITE_OBJECT` flags)
- Moves the files backend implementation from `odb.c` to `source-files.c`
- Maintains existing behavior while enabling future alternative backend implementations

The changes follow the established pattern of this series: focused, incremental steps toward the larger architectural goal while preserving all existing functionality. Each patch maintains backward compatibility while enabling future alternative backend implementations. The thorough documentation of callback contract is particularly notable, as it helps ensure consistent behavior across different backend implementations.
