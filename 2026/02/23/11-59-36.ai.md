This is part 2/17 of Patrick Steinhardt's refactoring series to unify Git's ref iteration interfaces. The patch moves `refs_head_ref_namespaced()` to be grouped with `refs_head_ref()` in refs.h, since it shares that function's single-ref nature rather than the for-each-ref pattern of the other functions being unified.

The change is purely organizational - no behavior is altered. The function remains exactly the same, just relocated in the header file to better reflect its logical grouping. This is groundwork for the larger API consolidation where most ref iteration functions will be unified under `refs_for_each_ref_ext()`.

The patch is straightforward and uncontroversial, with Karthik Nayak having already approved the series. It demonstrates the careful attention to code organization that characterizes this refactoring effort - even small details like header file grouping are being addressed systematically.
