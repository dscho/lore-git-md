This is part of Patrick Steinhardt's ongoing effort to make Git's object storage backends pluggable. The 17-patch series is restructuring the object database (ODB) subsystem to support alternative storage backends beyond the traditional loose objects and packfiles.

Patch 5/17 introduces an explicit type field for ODB sources, laying groundwork for future backend implementations. Currently there's only one type (ODB_SOURCE_FILES), but the change adds runtime type checking via a BUG() assertion when downcasting to catch misuse. The patch updates initialization code to set the type and adds the type check to the downcast helper function.

This is a straightforward preparatory change that follows the series' pattern of incrementally refactoring the ODB interface while maintaining existing behavior. The type system will become more important as additional backends are introduced in later patches. The change touches several ODB-related files but the modifications are mechanical and well-contained.
