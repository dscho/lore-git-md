This is a test infrastructure patch in a bugfix series addressing pack validation issues. Jeff King (Peff) provides a focused technical review of Patrick Steinhardt's first patch, which improves the `genrandom` test helper to better handle size arguments.

The patch in question adds proper error handling for size arguments in the test helper, using `git_parse_ulong()` instead of direct `strtoul()` calls. Peff confirms the approach makes sense but points out a minor implementation detail - the return value check should use the boolean convention of `git_parse_ulong()` rather than comparing against negative values.

This is a straightforward review comment on a preparatory patch in a series that ultimately fixes an infinite loop in `git fsck` when dealing with large objects across multiple packfiles. The exchange shows the careful attention to detail in Git's review process, even for test helper improvements.
