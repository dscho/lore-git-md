This is patch 12/17 in Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. The patch converts the `freshen_object()` operation to use callback-based dispatch, continuing the established pattern of the series.

The change:
- Adds a new `freshen_object` callback to `struct odb_source` with clear documentation about its contract (updating object timestamps to prevent garbage collection)
- Moves the files backend implementation from `odb.c` to `source-files.c` while maintaining the existing behavior of checking both packed and loose objects
- Updates the core `odb_freshen_object()` function to use the new callback interface
- Preserves all existing functionality including the alternates handling

The patch follows the same careful approach seen in previous conversions in this series: type-safe interfaces, thorough documentation of behavioral expectations, and maintaining backward compatibility while enabling future alternative backend implementations. The changes are focused and mechanical, with no surprises in the implementation.
