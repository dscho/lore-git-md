This is a test patch in the ongoing "repo info path reporting" series from Eslam Reda Ragheb. The patch adds comprehensive test coverage for the path-related functionality in the new `git repo info` command.

The test suite (t1900-repo.sh) is extended with 196 lines of new tests that verify:
- Category key expansion (e.g. requesting "layout" returns all "layout.*" fields)
- Path key behavior matching equivalent `git rev-parse` invocations
- The new `--path-format` option for controlling absolute vs relative path output
- Mixed key/category request ordering preservation
- Submodule-specific path cases
- Error handling for invalid path formats

The tests systematically compare `git repo info` output against established `git rev-parse` behavior to ensure plumbing consistency. Key path fields tested include repository locations (git-dir, common-dir, toplevel), object storage paths, and configuration file locations. The test design follows Git's established patterns while covering the new functionality's edge cases.

This patch represents the test component of the v3 series, which has been narrowed to focus solely on path reporting after splitting out structural metrics to a separate effort. The implementation avoids global state usage, aligning with the broader `the_repository` removal effort.
