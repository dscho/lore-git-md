This is part of Patrick Steinhardt's ongoing effort to make Git's object storage backends pluggable, now focusing on making the cleanup mechanism backend-specific. 

Patch 6/17 introduces a pluggable `free` callback in the `struct odb_source` interface, moving backend-specific cleanup logic out of the generic ODB layer. The change removes the direct call to `odb_source_files_free()` from the generic `odb_source_free()` function, instead delegating cleanup to the backend via the new callback. The files backend now registers its own cleanup function during initialization.

This is a typical incremental step in Patrick's architectural refactoring - carefully moving functionality from hardcoded implementations to callback-based interfaces while maintaining existing behavior. The patch touches several files but follows a clear pattern seen in earlier patches of this series, where operations are systematically made backend-specific. The change is well-contained and appears mechanically sound, continuing the series' focus on enabling alternative storage backends while keeping the current files-based implementation working unchanged.
