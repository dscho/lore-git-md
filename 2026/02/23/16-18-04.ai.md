This is part of Patrick Steinhardt's ongoing effort to make Git's object database (ODB) subsystem pluggable. Patch 13/17 in the series converts the `write_object()` operation to use callback-based dispatch, continuing the systematic refactoring of ODB operations.

The patch:
- Adds a `write_object` callback to `struct odb_source` with detailed documentation about its contract (must persist objects, freshen existing ones, handle WRITE_OBJECT flags)
- Moves the files backend implementation from `odb.c` to `source-files.c` while maintaining existing behavior
- Updates the public interface to route through the new callback mechanism
- Preserves support for compatibility object IDs (used in hash algorithm transitions)

This follows the established pattern of the series - defining type-safe interfaces, converting operations to callbacks, and maintaining existing files backend behavior. The change enables future alternative storage backends to implement their own write logic while keeping the current loose object behavior intact.

The patch is focused and mechanical, similar to previous conversions in the series. It touches core object writing functionality but maintains backward compatibility, making it a low-risk step toward the larger architectural goal of pluggable ODB backends.
