This is a performance optimization patch in Patrick Steinhardt's ongoing ref iteration API unification series. The patch speeds up `refs_for_each_glob_ref_in()` by leveraging the new unified `refs_for_each_ref_ext()` interface to handle prefix filtering at the backend level rather than in a callback.

The key improvement comes from avoiding iteration over all refs when only a subset matching a prefix is needed. Benchmark results show a dramatic 107x speedup in an extreme case with 1 million refs outside the target prefix. Karthik Nayak reviews the change positively, noting the significant performance gain while also suggesting a potential follow-up cleanup of the prefix trimming logic.

This patch is part of a larger effort to consolidate Git's ref iteration interfaces, replacing 14 specialized functions with a single configurable API. The series has been carefully reviewed, with Karthik Nayak providing feedback on several earlier patches. The performance improvement here is a concrete benefit of the API unification work.
