This is a documentation formatting follow-up to the recently merged UTF-8 alias support feature. Kristoffer Haugsbakk points out that the rendered HTML documentation shows raw AsciiDoc list continuation markers (`+`) in three places where they should have been processed and hidden. The issue is visible when comparing the master and next branches using `Documentation/doc-diff`.

The core functionality of the feature (supporting non-alphanumeric alias names via subsection syntax) is already merged into the `next` branch and working correctly. This is purely a documentation polish issue that doesn't affect the implementation. The thread shows the typical attention to detail in Git's documentation, where even minor rendering artifacts get noticed and reported post-merge.

The original patch series went through seven iterations with thorough review from multiple contributors including Jeff King and Junio Hamano, so this appears to be the only remaining issue with an otherwise complete feature. Kristoffer's report suggests using the project's standard `doc-diff` tool to verify documentation rendering - a good practice that caught this subtle formatting problem.
