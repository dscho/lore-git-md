This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The series systematically converts ODB operations to callback-based dispatch while maintaining existing behavior for the files backend.

Patch 17/17 makes the transaction handling pluggable by introducing a `begin_transaction()` callback in `struct odb_source`. This allows alternate backends to implement their own transaction semantics while keeping the existing files backend behavior. The patch follows the established pattern seen throughout the series: define the callback interface, implement it for the files backend, and provide a convenience wrapper function.

The series as a whole represents a significant architectural change to enable future storage backends beyond the traditional filesystem-based approach. Each patch has carefully preserved existing behavior while introducing the necessary abstractions. With this final piece in place, the ODB subsystem now has a complete callback interface for all major operations. The work demonstrates Git's approach to subsystem evolution through incremental, behavior-preserving refactoring.
