This is a test infrastructure improvement patch from Patrick Steinhardt, part of a series fixing pack validation issues with large objects. The patch enhances the `test-tool genrandom` helper to better handle size specifications and error cases.

The change makes two key improvements: it adds support for size suffixes (k/m/g) to make test code more readable, and it properly validates numeric inputs using `git_parse_ulong()` rather than silently accepting malformed input. The patch updates several test cases to demonstrate the new functionality.

Eric Sunshine spotted a typo in the commit message ("argumemnt" -> "argument") which Patrick will presumably fix in the next version. The change is straightforward and uncontroversial - it's preparatory work for the larger fsck fix series, improving test tooling that will be used to verify the core bugfix.
