This thread introduces a new `re-sign-if-invalid` mode for `git fast-import`'s signature handling, allowing commits with invalid signatures to be automatically re-signed during import. The three-part series was originally proposed by Christian Couder, with implementation work by Justin Tobler. 

The first patch cleaned up an unused function, while the second refactored signing logic into shared infrastructure in gpg-interface.c. This final patch implements the actual re-signing behavior, matching `git commit --gpg-sign` syntax for key specification. The series has evolved through thorough review, with all v1 feedback incorporated - including improved warnings, test coverage, and explicit handling of interoperability constraints.

Christian Couder and Patrick Steinhardt provided detailed technical reviews, with Christian noting a few remaining nits around naming consistency and warning message deduplication. The conservative experimental feature handling satisfied brian m. carlson's concerns, and Junio C Hamano has approved the direction. While tag signature support remains for future work, this series completes the commit signature functionality as originally envisioned, providing a useful middle ground between stripping invalid signatures and failing the import.
