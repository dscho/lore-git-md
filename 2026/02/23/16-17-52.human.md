This is the first patch in Patrick Steinhardt's 17-part series to make Git's object database (ODB) storage pluggable through callback-based operations. The patch performs preparatory refactoring by splitting `struct odb_source` into its own header file, separating it from the main ODB interface. This is a mechanical change that moves existing code from `odb.[ch]` to new `odb/source.[ch]` files, with no functional changes. The commit message explains this is groundwork for upcoming expansions to the structure that will add function pointers for backend operations. The patch follows Patrick's characteristic pattern of incremental, well-structured changes to the ODB abstraction effort he has been leading.
