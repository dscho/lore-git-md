This is a documentation patch that removes the `{litdd}` AsciiDoc macro usage in favor of escaping double-dashes with backslashes (`\--`). The author argues that `{litdd}` was originally used because `--` is reserved in AsciiDoc, but notes several problems with this approach: it requires special configuration, creates unnecessary complexity when exporting to other formats, and renders as HTML entities in output.

The patch makes this change across multiple documentation files, build configurations, and a test script. The changes are mechanical replacements that don't affect content, only formatting. The author has verified the changes work with `make all doc` and that links still function correctly.

This appears to be a straightforward cleanup that simplifies the documentation toolchain by using AsciiDoc's built-in escaping mechanism rather than a custom macro. The patch is focused and well-contained, touching only documentation-related files.
