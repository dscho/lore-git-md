This is a refactoring series from Patrick Steinhardt that unifies Git's ref iteration API into a single extensible function. The 17-patch series is now in its second iteration with Karthik Nayak's approval and addresses all previous feedback.

The core change replaces 14 specialized `refs_for_each_*()` functions with a single `refs_for_each_ref_ext()` that takes an options structure. This simplifies the API while maintaining identical behavior. The series demonstrates significant performance improvement (115ms->1.1ms for glob iteration) and includes thorough documentation updates.

Key technical aspects:
- Introduces `struct refs_for_each_ref_options` to configure iteration behavior
- Handles namespace prefixes, multiple patterns, and glob matching
- Standardizes callback type to `refs_for_each_cb`
- Adds safety checks like NULL ref store validation
- Carefully manages memory with strbuf/strvec
- Preserves behavior across all converted callers (bisect, rev-parse, etc.)

The v2 changes include:
- Moving removal of unused function to start of series
- Commit message improvements
- Better handling of prefix stripping in glob matching
- Documentation clarifications around namespace-prefix interaction

The series builds on recent ref backend work and is part of broader API consolidation efforts. While most specialized functions are replaced, `refs_for_each_replace_ref()` remains as a special case for future consideration. The implementation carefully maintains backward compatibility while providing a more maintainable foundation for future extensions.
