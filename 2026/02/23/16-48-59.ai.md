This is the final patch in Patrick Steinhardt's series to change git maintenance's default strategy from "gc" to "geometric". The patch modifies builtin/gc.c to make geometric_strategy the default while maintaining backward compatibility through the maintenance.strategy=gc config option.

Justin Tobler confirms the technical correctness of the change, noting that while both gc and geometric strategies may eventually perform expensive "all-into-one" repacks, geometric delays these operations longer - an improvement for large repositories. The thread shows consensus from key reviewers including Derrick Stolee (who designed geometric repacking) and Justin (who reviewed test infrastructure impacts).

The series has been carefully prepared with 7 infrastructure patches addressing test interactions before this behavioral change. Test coverage includes explicit maintenance.auto=false settings in packfile/delta/midx tests, gc.reflogExpire=never in rebase tests, and strategy overrides in several test suites to preserve existing expectations. Documentation has been updated to clarify the new default and incremental strategy availability.

This change moves Git to a more scalable maintenance approach while maintaining backward compatibility, with thorough review confirming the implementation is sound. The patch is ready for merging as the culmination of a well-executed series.
