This is a documentation fix for the ref storage backend configuration patch series, which has already received maintainer approval. Kristoffer Haugsbakk points out a formatting issue in the HTML output of the git-config man page where list continuation markers (`+`) and the `;;` syntax from the included ref-storage-format.adoc file are being rendered literally rather than processed as AsciiDoc markup.

The issue appears when documenting the new URI-based reference backend configuration syntax (`<format>://<payload>`). The current formatting causes raw markup to appear in the final output, which should instead show clean bullet points. Kristoffer suggests removing the list continuations to fix the rendering, though he notes he isn't certain why the current syntax isn't working as intended.

This is a minor polish for an otherwise complete and approved series that implements reference backend selection for zero-downtime migrations between storage formats (files and reftable). The series has gone through eight iterations with extensive review from key contributors including Patrick Steinhardt, Karthik Nayak, and Junio Hamano. The documentation issue doesn't affect the functionality, just the presentation of the configuration options in the man page.
