Build system fix addressing dependency tracking for `config-list.h`. This is the sixth iteration of D. Ben Knoble's patch to ensure the generated header stays in sync with Git's configuration documentation files, fixing cases where documentation changes weren't properly triggering rebuilds (causing test failures like in `t9902-completion.sh`).

The patch has undergone extensive review and testing, with contributions from Patrick Steinhardt and Phillip Wood, and appeared merge-ready until SZEDER Gábor identified a regression: the current implementation fails when configuration documentation files are removed (like during bisection), as the dependency tracking still expects the now-missing files. The core approach - having `generate-configlist.sh` produce both the header and a dependency file - remains sound, but needs adjustment to handle file removal cases gracefully.

This represents the final edge case to address in what has otherwise been a thorough solution that works across both Make and Meson build systems, with proper path handling and Windows performance considerations. The next version will need to resolve this while maintaining all existing functionality.
