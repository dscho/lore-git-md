This is part 3/5 of Justin Tobler's series adding repository statistics to `git repo`, focusing on improving the table output format with OID annotations.

The patch enhances the "structure" output format by adding OID references for the largest objects in each category (commits, trees, blobs, tags). Each maximum size entry in the table now includes a numbered reference (e.g., [1], [2]) that links to the full OID shown below the table. The changes include:

1. A new `annotations` field in `struct stats_table` to track OID references
2. A helper function `stats_table_object_size_addf()` that handles OID annotation formatting
3. Updated table formatting to accommodate the reference numbers
4. Test updates to verify the new annotation format works correctly

The implementation maintains backward compatibility with empty repositories (handling NULL OIDs) while providing more detailed object identification in populated repositories. The test changes show both the new reference-numbered table format and the corresponding OID list that appears when objects are present.

This continues the series' evolution toward more actionable repository statistics, building on previous patches that established the maximum-size tracking infrastructure. The changes are focused and well-contained, with thorough test coverage demonstrating both the new functionality and edge cases.
