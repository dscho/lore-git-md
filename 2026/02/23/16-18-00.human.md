This is the 9/17 patch in Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. The patch converts the `read_object_info()` function to use a callback-based approach, continuing the systematic refactoring of ODB operations.

The change introduces a new `OBJECT_INFO_SECOND_READ` flag to handle the two-phase lookup behavior where Git first checks for an object and, if not found, reprepars the ODB before checking again. The patch moves this logic into the ODB source abstraction while maintaining the existing behavior for the files backend.

Key technical aspects:
- Adds a `read_object_info` callback to `struct odb_source`
- Documents the callback contract and flag behavior
- Implements the callback for the files backend while preserving the two-phase lookup optimization
- Moves object info flag definitions to `odb/source.h` where they logically belong

The patch is a focused, incremental step in the larger ODB abstraction effort, maintaining backward compatibility while enabling future alternative storage backends. As with previous patches in the series, it demonstrates careful consideration of edge cases and maintains the existing performance characteristics.
