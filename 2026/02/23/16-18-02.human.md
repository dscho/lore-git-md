This is part of Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. Patch 11/17 continues the systematic refactoring by converting the `for_each_object()` operation to use callback-based dispatch.

The patch:
1. Adds a new `for_each_object` callback to `struct odb_source`
2. Moves the existing files backend implementation from `odb.c` to `odb/source-files.c`
3. Documents the callback contract in `source.h` with clear behavioral expectations
4. Updates the core iteration logic in `odb.c` to use the new callback interface

This follows the established pattern of the series - converting operations to the callback pattern while maintaining existing behavior. The change enables future alternative backend implementations while preserving current functionality. The documentation is thorough, explaining edge cases and flag handling expectations.

The patch is well-contained and follows the incremental approach seen in previous patches of this series. It continues the architectural work needed to make object storage truly pluggable while maintaining backward compatibility.
