This is part 13/17 of Patrick Steinhardt's series to unify Git's ref iteration APIs, specifically removing the `refs_for_each_rawref_in()` function in favor of the new unified `refs_for_each_ref_ext()` interface.

The patch converts the last remaining caller in `builtin/remote.c` to use the new API with the `REFS_FOR_EACH_INCLUDE_BROKEN` flag, which preserves the rawref iteration behavior. The function is then removed from both `refs.c` and `refs.h`, completing its elimination from the codebase.

This change follows the series' pattern of replacing specialized iteration functions with the unified API while maintaining identical functionality through configuration flags. The remote command's ref renaming operation continues to work as before, just using the new generalized interface. With this patch, all rawref iteration is now handled through the central `refs_for_each_ref_ext()` path.

The series has been thoroughly reviewed by Karthik Nayak and is in its final polishing stages, with this patch representing another incremental step in the broader ref API unification effort that has already demonstrated significant performance improvements (115ms to 1.1ms for glob iteration in patch 7/17).
