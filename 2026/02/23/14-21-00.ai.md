Feature patch series extending `git repo` command with path reporting and structural metrics. This is v2 of a series that intersects with Justin Tobler's parallel work on repository introspection, as noted in the thread.

The series enhances `git repo info` with:
- Category-based key expansion (e.g. requesting "layout" expands to all layout.* keys)
- Path-oriented keys (path.*) exposing repository locations
- `--path-format=(absolute|relative)` option for path rendering

For `git repo structure`, it adds richer metrics including:
- Maximum object sizes (inflated and on-disk, per-type)
- Topology metrics (max commit parents, max tree entries)
- Path metrics (longest/deepest blob paths)
- Tag chain depth
- Aggregate totals in keyvalue output

The v2 rewrite splits the changes into 9 smaller logical commits, addresses portability concerns from v1 reviews, and unifies author identity. Tests cover both human-readable and machine-readable output formats.

Key technical details:
- 518 lines added to builtin/repo.c
- New test coverage in t1900/t1901
- Path formatting uses repository context rather than global state
- Metrics inspired by git-sizer functionality
- Overlaps with Justin Tobler's in-progress work on structural maxima reporting
- Part of broader effort to remove reliance on `the_repository` global
