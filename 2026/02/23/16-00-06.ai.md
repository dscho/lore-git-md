This is a test infrastructure improvement patch from Patrick Steinhardt, part of a bugfix series addressing pack validation issues with large objects. The patch enhances the `test-tool genrandom` helper to better handle size specifications and error cases.

The change makes two key improvements to the test helper: it adds proper error handling for invalid size arguments using `git_parse_ulong()`, and supports human-readable size suffixes (k/m/g) for specifying byte counts. This allows tests to use more readable sizes like "10k" instead of hardcoded values like "10240". The patch updates several test scripts to use the new suffix syntax while maintaining the same test behavior.

The changes touch the test helper implementation and seven test files that use it, primarily in tests dealing with large objects, packfiles, and bitmaps. The patch has already incorporated feedback from Jeff King and Eric Sunshine (fixing a typo in the error message) in this v2 submission. This is a straightforward quality-of-life improvement for test suite maintainers that doesn't affect production code.
