Andrew Au's patch to clean up zombie network helper processes in containerized Git operations has been queued for merging after receiving final approval from Jeff King and addressing all documentation concerns. The solution uses Git's existing `run-command` infrastructure to properly terminate and reap orphaned processes like git-remote-https and ssh during abnormal exits, fixing cases where thousands of zombies could accumulate. The carefully scoped change affects just three points in the transport layer code.

Following this, Jeff King discovered an unrelated but longstanding memory leak in transport color configuration handling that only became detectable with the new process cleanup in place. The leak, present since 2018, involves string allocations that weren't being freed. Jeff proposes a simple 4-line fix using temporary string access to avoid allocations entirely. While this issue predates the zombie process work, the timing of its discovery means it could either be applied as a separate fix or folded into Andrew's queued patch. The fix is straightforward and doesn't interact with the process management logic, so it shouldn't affect the already-approved solution. Junio will decide whether to handle these as one combined change or two separate fixes.
