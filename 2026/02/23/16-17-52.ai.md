This is the first patch in Patrick Steinhardt's 17-part series to make Git's object database (ODB) subsystem pluggable. The patch moves the `struct odb_source` definition and related functions into a new header/source file pair (`odb/source.h` and `odb/source.c`), separating them from the main ODB interface. This is preparatory work for upcoming changes that will expand `struct odb_source` with callback-based operations for core ODB functionality.

The change is purely organizational at this stage - no behavior is modified. The patch carefully maintains all existing functionality while setting up the structure for the more substantial interface changes to come in later patches. The commit message clearly explains the motivation: to keep high-level ODB interfaces separate from low-level source implementations as the latter grows more complex with callback functions.

This follows Patrick's established pattern of incremental refactoring for large architectural changes. The patch touches build files (Makefile, meson.build) to add the new source file, moves existing code with minimal modifications, and adds proper header guards to the new files. The changes are focused and well-contained, typical of Patrick's careful approach to major subsystem restructuring.
