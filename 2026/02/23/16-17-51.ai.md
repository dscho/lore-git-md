This is a cover letter for a major architectural change to Git's object database (ODB) subsystem, part of Patrick Steinhardt's ongoing effort to make object storage backends pluggable. The 17-patch series introduces callback-based interfaces for core ODB operations, moving backend-specific logic into `struct odb_source` implementations. 

The changes touch nearly every part of Git that interacts with objects, from basic reads/writes (`read_object_info`, `write_object_stream`) to transaction handling (`begin_transaction`) and alternate management (`read_alternates`). The initial implementation focuses on the traditional files-based backend, with other storage formats (like reftable) expected to follow in future series. Key files affected include `object-file.c`, `odb.c`, and new headers in `odb/source*`.

While this series handles core operations, several important features remain for future work: object counting, OID abbreviation, consistency checks, packfile generation, and the "objectStorage" extension. The changes are extensive but carefully structured - each patch tackles one callback family, and the cover letter clearly signals what's out of scope. Given Patrick's track record with large refactorings and the ODB abstraction effort, this appears to be a serious, well-planned step toward pluggable storage backends.
