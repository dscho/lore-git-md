This is part 13/17 of Patrick Steinhardt's series to unify Git's ref iteration APIs, specifically removing the specialized `refs_for_each_rawref_in()` function in favor of the new unified `refs_for_each_ref_ext()` interface.

The patch converts the one remaining caller in `builtin/remote.c` to use the new API with the `REFS_FOR_EACH_INCLUDE_BROKEN` flag, which preserves the same behavior for handling broken refs during remote renames. The old function is then removed from both `refs.c` and `refs.h`.

This continues the series' pattern of consolidating specialized ref iteration functions into the unified interface. The change is straightforward and maintains identical functionality while reducing API surface area. With Karthik Nayak having already approved the full series, this appears to be a well-vetted step in the broader ref API unification effort.
