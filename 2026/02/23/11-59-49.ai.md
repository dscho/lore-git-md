This is patch 15/17 in Patrick Steinhardt's series to unify Git's ref iteration interfaces. The series is now in its final polishing stage with Karthik Nayak's approval.

The patch removes the specialized `refs_for_each_glob_ref()` function, replacing its calls with the new unified `refs_for_each_ref_ext()` interface. The conversion is straightforward - each call site now initializes a `struct refs_for_each_ref_options` with the glob pattern and passes it to the unified function. The changes affect several key areas: fetch negotiation tips handling in `builtin/fetch.c`, notes ref globbing in `notes.c`, and revision walking glob patterns in `revision.c`. The implementation demonstrates backward compatibility while eliminating another specialized iteration function.

This continues the series' pattern of converting specialized ref iteration functions to use the new unified API with configurable options. The patch maintains identical behavior while simplifying the API surface, with all callers now using the same underlying mechanism for glob pattern matching that was introduced earlier in the series (notably the 107x speedup in patch 7/17). The removal of `refs_for_each_glob_ref()` marks another step toward the series' goal of consolidating ref iteration into a single flexible interface.
