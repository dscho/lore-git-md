Refactoring patch in Justin Tobler's repository statistics series (v2 1/5). This change modifies `count_objects()` in `builtin/repo.c` to update statistics per-object rather than aggregating totals by type first. The patch moves the type-switch logic inside the object iteration loop, incrementing counts and sizes individually for each object rather than processing batches by type.

Key technical changes:
- Removes `inflated_total` and `disk_total` accumulators
- Moves type-switch inside object iteration loop
- Updates `struct object_stats` fields incrementally per object
- Maintains same statistics tracking (counts, inflated sizes, disk sizes)
- Preserves existing object type handling (tags, commits, trees, blobs)

The refactoring prepares for future granular statistics collection while maintaining identical functionality. This is a mechanical change with no behavior difference - the same totals are calculated, just via per-object updates rather than type-batched sums. The patch shows careful attention to preserving all existing accounting while restructuring for future extensibility.
