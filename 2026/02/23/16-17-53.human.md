This is part 2/17 of Patrick Steinhardt's series to make Git's object storage backends pluggable, continuing the architectural work to abstract the ODB layer. The patch introduces a new "files" source type that encapsulates both loose objects and packfiles, mirroring how the refs backend handles loose refs and packed-refs. This is a transitional step - the next patch will flip the relationship so the files source contains the odb_source rather than being contained by it.

The changes are mechanical but widespread, updating callers across 20 files to access packfiles and loose objects through the new `source->files` indirection rather than directly through `source->packfiles` and `source->loose`. The patch maintains all existing behavior while setting up the structure for the deeper interface changes coming in subsequent patches.

This continues Patrick's characteristically thorough approach to large refactorings - each commit tackles one logical piece while keeping the code functional. The changes are focused and well-contained, touching only the necessary call sites to support the new indirection layer.
