This is the 8th patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable backends. The series is systematically converting direct function calls into callback-based operations.

The current patch makes the `close()` operation pluggable by:
1. Adding a `close` callback to `struct odb_source`
2. Moving the files backend's close logic into a new `odb_source_files_close()` function
3. Updating the generic `odb_close()` to use the callback interface
4. Documenting the callback's contract (resources should be closable/reopenable)

The change follows the same pattern seen in earlier patches for `free` and `reprepare` operations, continuing the incremental transformation toward a fully pluggable architecture. The files backend remains functionally identical - this is purely an interface change to support future alternative backends.

As with previous patches in the series, this is a well-structured change with clear documentation and maintains backward compatibility. The series continues to make steady progress toward its goal of abstracting ODB operations while keeping each step small and reviewable.
