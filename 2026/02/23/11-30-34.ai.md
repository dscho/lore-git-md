This is a documentation patch that removes the `{litdd}` AsciiDoc macro usage in favor of escaping double dashes (`--`) with backslashes. The author (Michael Ryzhikov, signing as "samonon") explains that `{litdd}` was originally used because `--` is a reserved text in AsciiDoc, but this approach had several drawbacks: it required special configuration, created unnecessary complexity when exporting to other formats, and rendered as HTML entities rather than plain `--` in HTML output.

The patch makes widespread changes across documentation files, build configurations, and test scripts to replace all instances of `{litdd}` with `\--`. The changes are mechanical but touch many files (19 in total), including man pages, configuration files, and the documentation build system. The author verified the changes work with `make all doc` and that links still function correctly.

This appears to be a straightforward cleanup that simplifies the documentation toolchain while maintaining the same output. The change aligns with Git's ongoing documentation modernization efforts, though it's not part of the specific synopsis-style conversion led by Jean-Noël Avila. The patch is well-contained and unlikely to be controversial, though reviewers may want to verify the HTML output still renders correctly across different browsers.
