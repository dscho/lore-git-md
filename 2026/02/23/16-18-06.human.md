This is part of Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. Patch 15/17 converts the `read_alternates()` function to use the callback pattern established in previous patches.

The change moves the alternates file reading logic from `odb.c` to the files backend implementation in `odb/source-files.c`, adding a new `read_alternates` callback to `struct odb_source`. The patch follows the established pattern of:
1. Defining the callback interface with clear documentation about expected behavior
2. Moving the existing files backend implementation
3. Maintaining all current functionality while enabling future alternative backends

The alternates handling remains unchanged - it still reads from `info/alternates` and processes the paths as before, just now through the callback interface. This continues the systematic refactoring of ODB operations to support pluggable backends while preserving existing behavior.
