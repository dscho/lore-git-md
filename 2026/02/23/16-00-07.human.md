This is the second patch in Patrick Steinhardt's bugfix series addressing pack validation issues with large objects. The patch refactors `stream_object_signature()` to accept a preconstructed `odb_read_stream` rather than creating its own, allowing callers more control over the stream lifecycle.

The key change moves stream management responsibility to the caller while maintaining the same hash-checking functionality. This prepares for subsequent changes that need to verify objects using custom streams. The patch also improves error reporting in `parse_object_with_flags()` to distinguish between stream opening failures and hash mismatches - a refinement based on Jeff King's review of v1.

The changes touch core object handling code in `object-file.c` and `object.c`, plus pack verification in `pack-check.c`. The implementation is clean and maintains all existing behavior while enabling the next steps in the series. Jeff King has already confirmed the technical soundness of this approach.
