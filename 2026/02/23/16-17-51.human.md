This is a major architectural patch series from Patrick Steinhardt that makes Git's object database (ODB) sources pluggable. It's part of the ongoing ODB abstraction effort to enable alternative storage backends beyond the traditional files/packfiles system.

The series introduces a new `struct odb_source` with callback functions for core ODB functionality, then moves the existing files-based backend into this framework. While this first iteration covers basic operations like reading/writing objects and handling alternates, several important features remain for future work (object counting, abbreviation handling, consistency checks, etc.).

The changes are wide-ranging, touching nearly all parts of Git that interact with object storage. The patch organization shows careful incremental refactoring - each commit focuses on making one operation pluggable while maintaining existing behavior. The series appears well-structured with clear commit messages, though the full impact will only become clear once the remaining functionality lands in follow-up work.

This represents a significant step toward Patrick's long-term goal of making Git's storage layer properly abstracted and extensible. The approach seems technically sound, though reviewers will likely scrutinize the design choices around the new callback interface. The patch count and scope suggest this will be a multi-release effort before reaching full functionality.
