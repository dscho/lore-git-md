This is part of Patrick Steinhardt's ongoing refactoring of Git's object database (ODB) subsystem to enable pluggable storage backends. The patch series (now up to 17 parts) systematically converts ODB operations to a callback-based dispatch pattern while maintaining existing behavior.

Patch 16/17 introduces a new callback in `struct odb_source` to make writing alternates pluggable, following the same pattern as previous conversions in the series. The change moves the existing alternates writing logic from `odb.c` to `odb/source-files.c` where it becomes the files backend's implementation of the new callback. The patch maintains all existing behavior while enabling future alternative backends to implement their own alternates handling.

The work continues the series' consistent methodology of defining type-safe interfaces, converting operations one by one, documenting callback contracts, and preserving backward compatibility. This incremental approach is characteristic of Patrick's architectural refactoring work, where each patch builds carefully on the last toward the larger goal of pluggable ODB backends.
