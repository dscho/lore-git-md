This is a documentation patch adding support for special date keywords in `git commit --date`. The original patch from Md Ferdous Alam proposed documenting several undocumented but long-supported date keywords like "now", "yesterday", "tea" (5pm), and "never" (maximum timestamp).

Junio Hamano, the Git maintainer, responds with skepticism about whether these should be formally documented. He views them more as "easter eggs" that were intentionally left undocumented for users to discover, noting that the existing date formats documentation already covers precise specification needs. He also points out other undocumented but supported formats like "7.days.ago" that aren't included in the patch.

The response suggests this documentation addition may face resistance from the maintainer, who questions both the completeness of the proposed list and the value of formalizing these informal features. The thread is at an early stage with just the initial exchange, but Junio's "I dunno" signals this may not be a straightforward documentation improvement.
