This is the second patch in Derrick Stolee's 13-part performance improvement series for `git config list --type=<X>` filtering. The series aims to optimize config value parsing by enabling type filtering during initial parsing rather than after.

Patch 2/13 introduces a 'gently' parameter to `format_config()` that will be used in later patches to implement non-fatal parsing of config values. Currently, the parameter is unused (all callers pass 0), but it lays groundwork for upcoming changes where gentle parsing will be needed when trying to parse all values in a list without dying on invalid entries.

The change is mechanical and low-risk - it adds the parameter with appropriate documentation while maintaining all existing behavior. The patch follows the series' pattern of incremental refactoring, with this step preparing for the actual performance improvements that come in subsequent patches.
