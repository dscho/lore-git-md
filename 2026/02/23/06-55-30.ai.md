This is a CI/build system patch addressing a dependency tracking issue in the build system for `config-list.h`. SZEDER Gábor reports a regression in v6 of D. Ben Knoble's series that breaks builds when configuration documentation is removed.

The issue occurs when a file listed in the dependency tracking (like `hook.adoc`) is removed from `Documentation/config/` - the Makefile still tries to rebuild based on the stale dependency file, failing with "No rule to make target". This reveals a gap in the otherwise thorough solution that had previously passed extensive testing across platforms.

The patch series had evolved through six iterations to handle both Meson and Makefile builds, with careful attention to path escaping, Windows performance, and cross-platform consistency. While the technical approach was sound for the addition/modification case, this edge case of file removal wasn't caught in earlier testing. The dependency tracking now needs to account for files that may disappear between builds.

This doesn't invalidate the overall approach but shows one remaining edge case to address before the series can be considered complete. The solution will likely need to either gracefully handle missing dependency files or find a way to regenerate the dependency list when files disappear.
