This is a documentation patch fixing formatting in the alias.adoc man page. It corrects a list continuation issue introduced in commit ac1f12a9, where a code block wasn't properly marked as part of the surrounding list, causing subsequent paragraphs to be incorrectly formatted.

The patch makes three specific changes:
1. Adds list continuation markers (`+`) before and after the code block
2. Converts the indented code block to use explicit `----` delimiters for consistency with the preceding example
3. Changes the comment prefix from `#` to `$ #` to match the terminal prompt style used elsewhere

The change is straightforward and aligns with the project's documentation conventions.
