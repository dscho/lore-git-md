This is patch 14/17 in Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. The patch converts the `write_object_stream()` operation to use callback-based dispatch, continuing the established pattern of the series.

The change:
- Adds a new `write_object_stream` callback to `struct odb_source` with clear documentation about its contract (must persist the stream and return the object ID)
- Moves the files backend implementation from `odb.c` to `source-files.c`
- Updates the public interface to use the new callback-based dispatch
- Maintains all existing behavior while enabling future alternative backends to implement their own streaming write logic

This follows the same careful approach seen in previous patches of the series - defining type-safe interfaces, documenting behavioral contracts, and preserving backward compatibility while enabling future extensibility. The patch is narrowly focused on converting this one operation to the callback pattern, keeping the change small and reviewable.

The series continues to make steady progress toward its goal of a fully pluggable ODB subsystem, with each patch methodically converting another operation to the callback-based model. This particular change handles the streaming write path, complementing the direct write operation converted in the previous patch.
