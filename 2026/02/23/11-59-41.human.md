Performance optimization in Patrick Steinhardt's ref iteration unification series. This patch (7/17) dramatically speeds up glob-based ref iteration by properly handling prefixes in the new `refs_for_each_ref_ext()` interface.

The key improvement comes from avoiding iteration over all refs when only a prefix subset is needed. The benchmark shows a 107x speedup (115ms -> 1.1ms) for a case with 1 million refs outside the target prefix and just one inside. The change moves glob pattern handling into the unified iteration framework while maintaining the same filtering behavior.

This is part of the larger effort to consolidate Git's 14 specialized ref iteration functions into a single configurable interface. The patch has already been reviewed and approved by Karthik Nayak, with only minor documentation tweaks remaining in the thread. The series is in its final polishing stages and appears ready for merging.
