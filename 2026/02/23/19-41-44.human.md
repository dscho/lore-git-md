This is a feature patch series adding a new signing mode to `git fast-import`. The two-patch series introduces a `re-sign-if-invalid` mode for `--signed-commits` that will automatically re-sign commits with invalid signatures while preserving valid ones.

The first patch is a minor cleanup removing an unused forward declaration in `commit.h`. The second patch is the main addition, allowing `git fast-import` to regenerate signatures for commits that fail verification. The author notes this currently doesn't handle `extensions.compatObjectFormat` for cross-hash compatibility, leaving that as potential future work.

The implementation appears straightforward, with test updates showing the new mode in action. This builds on previous work from November 2025 that added a `strip-if-invalid` mode. The patch seems well-structured with clear commit messages and test coverage, though the hash compatibility question remains open for discussion. This would be useful for repository maintenance workflows where signature verification needs to be enforced but existing invalid commits should be preserved with fresh signatures rather than stripped.
