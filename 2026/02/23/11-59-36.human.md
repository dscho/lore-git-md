This is part 2/17 of Patrick Steinhardt's ref iteration API unification series, which aims to consolidate Git's ref iteration functions into a single `refs_for_each_ref_ext()` interface. The series has been reviewed by Karthik Nayak and is in its final polishing stage.

This particular patch moves the `refs_head_ref_namespaced()` function declaration in `refs.h` to be grouped with `refs_head_ref()` rather than with the `refs_for_each_*` functions. The rationale is that while the for-each functions yield multiple refs, `refs_ref_namespaced()` only yields at most the HEAD ref of the current namespace, making it more conceptually similar to `refs_head_ref()`.

This is a straightforward code organization change with no behavior modification. The patch is small (5 lines changed) and well-explained, continuing the series' pattern of careful refactoring. The change helps clarify the API structure as part of the larger unification effort.
