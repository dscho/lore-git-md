This is part 11 of Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. The patch converts the `for_each_object()` operation to use callback-based dispatch, continuing the systematic refactoring pattern established in previous patches.

The key changes are:
- Adds a new `for_each_object` callback to `struct odb_source` with detailed documentation of its contract
- Moves the files backend implementation from `odb.c` to `odb_source_files_for_each_object()` in `source-files.c`
- Updates the core `odb_for_each_object()` function to use the new interface
- Maintains all existing behavior including handling of loose objects, packed objects, and various flags (LOCAL_ONLY, PROMISOR_ONLY)

The patch follows the established approach of:
1. Defining the callback interface with clear behavioral expectations
2. Moving existing files backend logic to its proper location
3. Updating the core function to use the new abstraction
4. Preserving all current functionality while enabling future alternative backends

This continues the incremental, methodical transformation of the ODB subsystem toward pluggable backends. The changes are focused and maintain backward compatibility while progressing the larger architectural goal. The documentation is thorough, explaining the callback's expected behavior and flag handling requirements.
