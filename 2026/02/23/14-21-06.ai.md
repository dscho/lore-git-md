Feature patch adding aggregate repository metrics to `git repo` output, part of Eslam Reda Ragheb's ongoing series to enhance repository introspection.

This patch (6/9 in v2) extends the key-value output format of `git repo` with aggregate totals for references, objects, and sizes, complementing the per-type breakdowns already present. The new totals include reference count, object count, total inflated size, and total disk size - values that previously required external summation. The implementation adds four new fields to the machine-readable output while maintaining backward compatibility.

The changes follow the series' established pattern of repository-aware computation without global state, using helper functions like `get_total_reference_count()` and `get_total_object_values()`. The patch is narrowly focused, touching only `builtin/repo.c` with 16 new lines that mirror the existing per-type output structure. This maintains consistency between human-readable table output and machine-parsable formats.

This continues the series' technical coordination challenge with Justin Tobler's parallel work on repository introspection, though the aggregate totals here appear complementary rather than overlapping. The patch builds on previous infrastructure from patches 1-5 while remaining self-contained for review purposes. Test coverage for these additions would logically belong in the existing t1900/t1901 tests, though this patch does not modify them.
