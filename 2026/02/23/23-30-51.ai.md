This is a documentation patch that clarifies the interaction between `--default-prefix` and configuration variables in `git-format-patch`. The change fixes the `diff-options.adoc` man page to correctly reference `format.noprefix` (which format-patch actually uses) rather than the unrelated `diff.noprefix` configuration.

The patch makes two key improvements: it uses AsciiDoc conditionals to show the correct variable name depending on whether the documentation is being rendered for format-patch or other commands, and it removes an incorrect implication that `--default-prefix` overrides `diff.noprefix` in format-patch contexts. The commit message notes this is primarily a documentation accuracy fix rather than a functional change, as `format.prefix` already exists as an escape hatch for users who need to control prefix behavior.

This is the second patch in a two-part series that has already been reviewed and approved by Junio Hamano. The first patch addressed the boolean validation behavior of `format.noprefix`, while this one focuses on documentation consistency. The change is straightforward and uncontroversial, aligning the docs with the actual implementation behavior that was established in commit 8d5213de.
