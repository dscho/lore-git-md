Test infrastructure improvement from Patrick Steinhardt, part of a series fixing pack validation issues. This first patch enhances the `test-tool genrandom` helper to better handle size arguments with unit suffixes (like "10k" or "1m") and improve error reporting. The change makes test scripts more readable by replacing magic numbers with human-readable sizes, and prevents silent failures when invalid sizes are provided. The patch updates several test scripts to use the new syntax, including tests for large objects and pack handling that will be relevant to the series' later pack validation fixes. The changes are mechanical but well-contained, with clear commit message explaining both the problem and solution.
