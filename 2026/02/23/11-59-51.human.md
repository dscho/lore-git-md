This is the final patch in Patrick Steinhardt's 17-part series to unify Git's ref iteration API. The series consolidates various specialized `refs_for_each_*()` functions into a single `refs_for_each_ref_ext()` interface with configurable options.

Patch 17/17 removes the last remaining specialized function `refs_for_each_fullref_in()`, converting all its callers to use the new unified API. The changes touch several key areas including bisect handling, ref advertisement in receive-pack, rev-parse's bisect support, show-ref functionality, and revision walking. The patch demonstrates the series' success in maintaining identical behavior while simplifying the API surface - all callers now use the same options struct pattern seen throughout the series.

With this patch, the ref iteration API unification is complete except for `refs_for_each_replace_ref()`, which remains as a specialized case. The series has been thoroughly reviewed by Karthik Nayak and shows significant performance improvements (115ms->1.1ms for glob iteration). This represents a major step in modernizing Git's ref handling infrastructure.
