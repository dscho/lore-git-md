This is the first patch in a v3 series introducing enhanced repository path reporting functionality to `git repo info`. The series is now focused specifically on path reporting after splitting out structural metrics into a separate effort.

The patch introduces a `struct repo_info` to encapsulate repository state and thread it through value lookups, removing direct coupling to repository globals. It also adds category key expansion (e.g. accepting "layout" to match all "layout.*" keys) to improve scripting ergonomics while maintaining backward compatibility with explicit key requests.

Key technical changes:
- New `struct repo_info` containing repository pointer and prefix
- Modified getter functions to use the context struct
- Added category key handling that expands requests like "layout" to all matching "layout.*" fields
- Maintained existing explicit key behavior with clear errors for unknown names
- Updated all field printing to use the new context-aware approach

The changes appear well-contained and focused scope, with thorough updates to the existing field accessors. The patch maintains compatibility while providing a cleaner foundation for the path reporting features to come in subsequent patches of the series.
