This is part 14 of Patrick Steinhardt's ongoing series to make Git's object database (ODB) backend pluggable. The patch converts the `write_object_stream()` operation to use the callback pattern established in previous patches.

The change adds a new callback to `struct odb_source` for streaming object writes, moving the existing files backend implementation from `odb.c` to `source-files.c`. Like earlier patches in the series, this maintains the same behavior while making the operation backend-specific. The commit includes detailed documentation of the callback's expected contract.

This continues the methodical approach seen throughout the series - each patch tackles one ODB operation at a time, converting it to the callback pattern while preserving existing functionality. The work is part of the larger architectural effort to enable alternative object storage backends beyond the traditional files/packs implementation.
