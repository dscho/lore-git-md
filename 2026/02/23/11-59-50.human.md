This is part 16/17 of Patrick Steinhardt's series to unify Git's ref iteration APIs, now in final polishing stage with Karthik Nayak's approval. The patch removes the specialized `refs_for_each_namespaced_ref()` function, replacing its calls with the new unified `refs_for_each_ref_ext()` interface.

The change affects three key areas: `http-backend.c` (serving refs over HTTP), `upload-pack.c` (push/pull protocol), and the refs subsystem itself. The conversion maintains identical behavior while using the new options struct to handle namespaces and exclude patterns. The patch demonstrates how the unified API cleanly replaces specialized functions while preserving all existing functionality, including hidden ref filtering in upload-pack.

This continues the series' pattern of methodically eliminating specialized ref iteration functions in favor of the configurable interface. With this change, only `refs_for_each_replace_ref()` remains as a specialized case in the codebase. The changes are straightforward mechanical conversions with no behavior changes, as expected at this late stage of the series.
