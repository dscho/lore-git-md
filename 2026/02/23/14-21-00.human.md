This is a feature patch series extending Git's repository introspection capabilities, now in its second version (v2). The series enhances both `git repo info` and `git repo structure` commands with new functionality and metrics.

The key improvements in this version include:
- Better path reporting in `git repo info` with new `--path-format` option (absolute/relative) and category-based key expansion
- New structural metrics in `git repo structure` including maximum object sizes, commit parent counts, tree entry counts, and path depths
- Improved test coverage and portability fixes
- Unified author identity (now using real name) and cleaner commit history organization

The series has been reworked from v1 into 9 smaller, more logical commits addressing previous feedback about test robustness and documentation. It now properly handles hash algorithm differences and platform-specific behaviors (like BSD/macOS `wc` output).

Notable technical details:
- Adds 12 new path-related keys to `repo info` (like `path.git-dir`, `path.toplevel`)
- Introduces maxima tracking for various repository metrics
- Includes comprehensive tests in t1900/t1901
- Documents all new features in git-repo.adoc

The series intersects with Justin Tobler's parallel work on repository introspection, though this version appears more comprehensive in scope. The author has addressed previous maintainer concerns about submission hygiene and test design, though coordination with Justin's efforts remains an open question.
