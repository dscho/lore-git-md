This is part 3/5 of Justin Tobler's series adding repository statistics to `git repo`, focusing on improving the table output format with OID annotations. The patch builds on previous work tracking largest objects by type (commits, trees, blobs, tags) and now shows their corresponding object IDs.

The key changes introduce numbered references linking table entries to OIDs displayed below the table. The implementation adds:
- A new `annotations` string list in `struct stats_table` to store OID references
- `stats_table_object_size_addf()` helper for size+OID table entries
- Indexed references like `[1]` in the table that map to full OIDs in footnotes
- Proper handling of NULL OIDs for empty repositories
- Updated test expectations to verify the new annotation format

The patch maintains all existing functionality while adding the OID visibility that was missing from earlier versions. Test coverage in t1901 confirms the annotation format works for both empty and populated repositories, with the latter showing real OIDs for maximum-size objects of each type.

This continues the series' trend of incremental improvements based on feedback, here addressing the need to connect statistics with the actual objects they reference. The changes are localized to output formatting without altering the underlying statistics collection from previous patches.
