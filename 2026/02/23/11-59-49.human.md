This is part 15/17 of Patrick Steinhardt's series to unify Git's ref iteration APIs, now removing the `refs_for_each_glob_ref()` function in favor of the new `refs_for_each_ref_ext()` interface. The patch converts all callers (in fetch.c, notes.c, and revision.c) to use the new API with a pattern specified in the options struct, then deletes the now-unused function and its declaration.

The change is straightforward mechanical conversion - each caller now initializes a `refs_for_each_ref_options` struct with the glob pattern before calling the unified iteration function. The series has already been reviewed and approved by Karthik Nayak, with earlier patches demonstrating significant performance improvements (115ms to 1.1ms for glob iteration). This continues the pattern seen in previous patches of the series where specialized iteration functions are removed after their callers are converted to the new unified API.
