This is a performance-focused patch series by Derrick Stolee that improves `git config list --type=<X>` filtering. The series has gone through three iterations and is now ready for merging, having addressed all substantive feedback.

The core improvement makes `git config list` respect `--type` filters by parsing values during iteration rather than after, which significantly speeds up path-type config lookups. This was motivated by performance bottlenecks in git-credential-manager when dealing with path configs.

Key technical changes include:
- Early filtering during config parsing to avoid wasted work
- Gentle/quiet parsing variants for different config types
- Careful handling of path values with `:(optional)` macros
- Conversion of the formatting logic to a switch statement with enum types
- Comprehensive test coverage demonstrating the behavior changes

The series has been thoroughly reviewed, with Junio C Hamano and Patrick Steinhardt providing detailed feedback that shaped the final implementation. All open questions from earlier versions have been resolved, including:
- Path handling for optional/missing files
- Naming conventions for parsing variants
- Output formatting efficiency
- Defensive programming in the switch statement

Performance measurements show the changes achieve the desired speedup for git-credential-manager's use case. The series maintains backward compatibility while adding the new filtering capability.

This represents a well-executed optimization that addresses a real-world performance pain point while maintaining Git's config model and error handling patterns. The careful iteration and thorough test coverage make it a high-quality contribution.
