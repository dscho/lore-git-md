This is the final patch in Derrick Stolee's performance improvement series for `git config list --type=<X>` filtering. The series originally aimed to optimize config value filtering by type, particularly benefiting git-credential-manager's handling of path-type values.

Patch 13/13 converts the config type definitions from macros to a proper enum in `builtin/config.c`. This is a clean-up change that:
- Moves the type definitions earlier in the file to ensure proper ordering
- Explicitly initializes the type field to TYPE_NONE in config_display_options
- Provides better type safety and documentation of possible values
- Maintains compatibility with the existing switch statement from patch 12/13

The change is straightforward and mechanical, completing the series' transition to more maintainable type handling. With this patch, all implementation work for the performance improvements is complete, and the maintainer has already approved the technical approach. The series appears ready for merging.
