This is part 10 of Patrick Steinhardt's ongoing series to make Git's object database (ODB) backend pluggable. The patch converts the `read_object_stream()` operation to use callback-based dispatch, continuing the established pattern of making ODB operations backend-agnostic.

The change introduces a new `read_object_stream` callback in `struct odb_source` that backends must implement to provide streaming object access. The files backend implementation (`odb_source_files_read_object_stream()`) combines the packed and loose object lookup paths that were previously handled directly in `odb/streaming.c`. The core streaming logic now delegates entirely to the backend via `odb_source_read_object_stream()`, cleaning up the direct backend-specific calls from the central implementation.

This follows the series' systematic approach: each patch tackles one ODB operation at a time, converting it to the callback pattern while maintaining all existing behavior. The change is well-contained, with clear documentation of the new callback's contract in `source.h`. As with previous conversions in the series, this enables future alternative backends to implement their own streaming logic while keeping the files backend fully functional.
