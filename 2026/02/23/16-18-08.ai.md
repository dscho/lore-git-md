This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database (ODB) subsystem to support pluggable storage backends. The patch makes the transaction handling mechanism pluggable by introducing a `begin_transaction` callback in `struct odb_source`.

The change follows the established pattern seen throughout the series: defining a new callback interface in `source.h` and implementing it for the existing files backend in `source-files.c`. The transaction mechanism allows writing objects to a temporary staging area that only persists when explicitly committed, which is important for atomic updates.

The patch maintains the existing behavior while making it backend-specific. As with previous conversions in the series, this completes another piece of the pluggable ODB interface. The implementation includes thorough documentation of the callback's expected behavior and return values.

This concludes the major structural work for the ODB abstraction effort. The series has systematically converted all core ODB operations to use callback-based dispatch while preserving the existing files backend functionality. Future work can now focus on implementing alternative backends using this pluggable interface.
