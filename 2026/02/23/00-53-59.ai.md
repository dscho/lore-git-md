This is a documentation follow-up in the ongoing thread about changing git maintenance's default strategy from "gc" to "geometric". Derrick Stolee, who originally designed the geometric repacking strategy, fully supports Patrick Steinhardt's implementation but notes two minor documentation gaps that should be addressed before merging.

The key points are that the documentation should clarify: (1) the incremental strategy is available via `git maintenance start` and not just through Scalar, and (2) maintenance.adoc needs updating to reflect the new geometric default. Stolee confirms the geometric strategy is the right default for most users, though extremely large repositories may still need the incremental approach.

The thread shows consensus on the technical implementation after thorough test updates (patches 1-7) and careful review. This email represents the final step before merging, with only these documentation clarifications remaining. The change represents a significant shift in Git's maintenance behavior, moving to a more flexible and scalable approach while maintaining backward compatibility through the maintenance.strategy=gc config option.
