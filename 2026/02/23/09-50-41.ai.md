Refactoring patch in a series addressing pack validation issues with large objects. This is the second of four patches from Patrick Steinhardt, following initial test infrastructure improvements.

The change modifies `stream_object_signature()` to accept a preconstructed `odb_read_stream` rather than creating its own, shifting stream management responsibility to callers. This prepares for future changes where callers need to pass in custom streams. The patch updates three call sites in `object.c` and `pack-check.c` to handle the new interface, properly opening and closing streams around verification.

The modification is mechanical but touches core object handling code paths. The commit message clearly explains the motivation (enabling future stream customization) without detailing the specific large-object validation issues the series ultimately addresses. As with Patrick's typical contributions, the change is well-contained and includes updates to both implementation and callers.
