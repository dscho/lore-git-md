This is part 12/17 of Patrick Steinhardt's series to unify Git's ref iteration APIs, converting the remaining `refs_for_each_rawref()` calls to use the new `refs_for_each_ref_ext()` interface. The patch removes the now-unused `refs_for_each_rawref()` function entirely after updating all callers in `describe.c`, `fsck.c`, `fetch-pack.c`, and the refs backend to use the new API with `REFS_FOR_EACH_INCLUDE_BROKEN` flag.

The changes are mechanical but thorough, touching several key subsystems that inspect raw refs: `git describe` (for finding tags), `git fsck` (for ref validation), and the fetch negotiation logic. The conversion maintains identical behavior while eliminating one of the last specialized ref iteration functions in favor of the unified API. 

This patch follows the series' established pattern of replacing legacy iteration functions while preserving all existing functionality through appropriate option flags. With Karthik Nayak's review approval on the full series, this appears to be a well-vetted step in the larger ref API consolidation effort.
