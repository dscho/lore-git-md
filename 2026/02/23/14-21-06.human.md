Feature patch adding aggregate repository metrics to `git repo` output. This is patch 6/9 in Eslam Reda Ragheb's series enhancing repository introspection capabilities.

The patch adds four new metrics to the machine-readable key-value output format: total reference count, total object count, total inflated size, and total disk size. These aggregate values complement the existing per-type breakdowns (commits, trees, blobs, tags) that were added in earlier patches. The change makes the output more convenient for scripting by eliminating the need for external summation.

The implementation follows the established pattern from previous patches, using helper functions to compute the totals from the existing per-type counts. The patch is small (16 lines added) and focused, touching only the key-value` output formatting function in `builtin/repo.c`. It maintains consistency with the human-readable table output which already includes these totals.

This continues the series' theme of providing comprehensive repository diagnostics while avoiding global state. The change appears straightforward and well-contained, though reviewers may want to verify the aggregation logic matches expectations for all object types. The patch builds naturally on the object counting infrastructure introduced in patch 3 and size tracking from patch 4.
