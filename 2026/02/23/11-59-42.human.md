This is part 8 of Patrick Steinhardt's 17-patch series to unify Git's ref iteration APIs. The series has already been reviewed and approved by Karthik Nayak, with performance improvements showing a 107x speedup in earlier patches.

This patch generalizes `refs_for_each_namespaced_ref()` to use the new unified `refs_for_each_ref_ext()` interface by adding a `namespace` field to the options structure. The key changes are:

1. Namespace handling is now built into the core iteration logic rather than being a wrapper function
2. The implementation properly handles both namespace prefixes and exclude patterns
3. The old wrapper function becomes a simple caller of the new unified API

The patch maintains all existing behavior while giving callers more flexibility - they can now use either the global namespace (via `GIT_NAMESPACE`) or specify an arbitrary namespace directly. Memory management is handled carefully with proper cleanup of temporary buffers.

As with the rest of the series, this is a well-constructed change that moves toward the goal of API unification while preserving performance and correctness. The implementation looks solid and follows the pattern established in earlier patches.
