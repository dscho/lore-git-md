This is part of Patrick Steinhardt's ongoing effort to make Git's object database (ODB) backend pluggable. Patch 7/17 in the series introduces a new callback mechanism for the `reprepare()` operation, which clears caches when the repository state changes (e.g., after a repack).

The change moves the existing reprepare logic for the files backend into a dedicated callback function, following the same pattern as earlier patches in the series that made other operations pluggable. The files backend now registers its implementation during initialization, while the same behavior is maintained through the new callback interface.

This continues the systematic refactoring to convert direct backend operations into callback-based dispatch, a key step toward supporting alternative storage backends. The patch is focused and well-contained, touching only the reprepare functionality while leaving other operations for future patches. As with previous changes in the series, it maintains existing behavior while making the architecture more flexible.
