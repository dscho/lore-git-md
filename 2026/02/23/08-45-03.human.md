This is a documentation patch that adds missing information about special date keywords accepted by `git commit --date`. 

The patch documents several human-readable date formats that Git already supports but weren't listed in the manual pages, including "now", "yesterday", "noon", "midnight", "tea", and "never". These keywords can be used with `--date` to specify commit timestamps in a more intuitive way than raw timestamps or relative dates.

The changes add these special keywords to the "DATE FORMATS" section of git-commit(1) and update the `--date` option description to point readers to this section. The documentation explains that these keywords can be combined with other date constructs (like "yesterday noon" or "3.days.ago").

The patch appears straightforward and well-motivated, addressing a clear documentation gap. The implementation is clean, adding the new content in the appropriate sections without disrupting the existing documentation structure. This should be a non-controversial improvement that makes Git's date handling features more discoverable.
