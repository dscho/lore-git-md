Refactoring patch in Derrick Stolee's config type-filtering series.

This is patch 12/13 in the v3 series improving `git config list --type=<X>` performance. The series restructures config parsing to filter by type during initial parsing rather than after, with previous patches implementing type handlers for integers, booleans, paths, colors, and other types.

This patch simplifies the `format_config()` function by converting its nested if/else conditions into a switch statement. The change is purely structural - the behavior remains identical. The code becomes more readable by:
- Using a switch on the type field
- Adding a `TYPE_NONE` constant for the default case
- Reducing nesting depth with a goto label for early termination
- Adding a BUG() check for invalid types

The patch follows the established pattern from earlier in the series and maintains all existing functionality while making the control flow clearer. As with previous patches in this well-reviewed series, the change is straightforward and unlikely to be controversial.
