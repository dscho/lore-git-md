This thread documents Patrick Steinhardt's ongoing effort to refactor Git's object database (ODB) subsystem to support pluggable storage backends. The series, now at 15 patches, systematically converts each ODB operation to a callback-based interface while maintaining existing files backend behavior.

The latest patch (15/17) tackles the `read_alternates()` functionality, moving the parsing logic to the files backend while establishing a clear callback contract. This follows the established pattern of the series: earlier patches converted core functions like `write_object()`, `read_object_info()`, and `for_each_object()` to the new callback model. Each conversion maintains backward compatibility while documenting the exact behavior expected from future backend implementations.

The work represents a major architectural shift for Git's object storage layer, enabling alternative backends while preserving the existing files/packs implementation. The careful, incremental approach - converting one operation at a time with thorough documentation - reflects Git's conservative evolution of core subsystems. With 15 operations now converted, the series is approaching completion of the foundational work needed for pluggable ODB backends.
