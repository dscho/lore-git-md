Pro Git book Turkish translation status update: Tuna Dinçer announces completion of the Turkish translation for Pro Git 2nd Edition, hosted at https://github.com/Hweord/progit2-tr. The work appears ready for integration into the main Pro Git project, though the website still shows it as incomplete. This is a community-maintained translation effort coordinated by Jean-Noël Avila, separate from Git development but often discussed on the Git list. No patch is included - this is purely a notification of completion status.
