This thread documents a cleanup effort to simplify Git's documentation toolchain by replacing the `{litdd}` AsciiDoc macro with escaped double dashes (`\--`). Michael Ryzhikov (samonon) explains that while `{litdd}` was originally used because `--` is reserved in AsciiDoc, it created unnecessary complexity in the build system and rendered as HTML entities rather than plain text. The patch makes mechanical changes across 19 files - including man pages, build configurations, and test scripts - to standardize on the simpler `\--` syntax.

The change aligns with Git's broader documentation modernization efforts, though it's separate from Jean-Noël Avila's synopsis-style conversion work. The author verified the changes work with `make all doc` and that links remain functional. This appears to be a non-controversial improvement that reduces toolchain complexity while maintaining output quality. Reviewers will likely want to spot-check the HTML rendering, but the change is otherwise ready for consideration.
