This is a minor refactoring patch from Karthik Nayak providing feedback on Patrick Steinhardt's ongoing ref iteration API unification series. The patch moves `refs_head_ref_namespaced()` to be grouped with the similar `refs_head_ref()` function rather than with the `refs_for_each_*` family of functions, since it operates on a single ref rather than iterating multiple refs.

Karthik suggests two small wording improvements to the commit message to clarify the function's behavior. The change itself is straightforward - just relocating the function declaration in refs.h to be next to its logical counterpart. This is part of the larger effort to simplify Git's ref iteration interfaces by consolidating many specialized functions into a single configurable API.

The patch appears well-motivated and uncontroversial, making a small but logical improvement to code organization. As the first patch in a 17-part series that has already gone through review, this change helps set up the more substantial refactoring that follows.
