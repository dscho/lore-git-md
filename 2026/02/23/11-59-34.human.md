This is a refactoring series from Patrick Steinhardt that unifies Git's ref iteration API. The series consolidates 14 specialized `refs_for_each_*()` functions into a single `refs_for_each_ref_ext()` with a flexible options structure, while maintaining identical behavior.

The series has gone through thorough review from Karthik Nayak and shows significant performance improvements (115ms to 1.1ms for glob iteration). Key changes in v2 include moving an unused function removal to the start of the series, improving commit messages, and better handling of prefix stripping in glob matching.

The patch set is well-structured with:
1. Preliminary cleanups (patches 1-5)
2. Core API introduction and optimization (patches 6-9)
3. Additional verification (patch 10)
4. Replacement of legacy functions (patches 11-17)

This is part of Patrick's broader effort to modernize Git's ref backend infrastructure. The series appears ready for merging with all reviewer feedback addressed, though some minor discussions continue about prefix handling details. The changes touch many callers but maintain backward compatibility while providing a cleaner foundation for future ref iteration needs.
