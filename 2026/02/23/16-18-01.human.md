This is part of Patrick Steinhardt's ongoing series to make Git's object database (ODB) backend pluggable. Patch 10/17 continues the `read_object_stream()` operation conversion, following the established pattern of moving files backend logic into callback-based dispatch.

The patch introduces a new `read_object_stream` callback in `struct odb_source` and implements it for the files backend. This allows streaming object contents through a polymorphic interface, similar to how previous patches handled other operations like `read_object_info()`. The change removes direct files backend calls from `odb/streaming.c`, replacing them with the new callback-based dispatch.

The implementation maintains existing behavior while enabling future alternative backends to provide their own streaming implementations. As with earlier patches in the series, this is a focused, incremental step that keeps backward compatibility while advancing the larger architectural goal of pluggable ODB backends.
