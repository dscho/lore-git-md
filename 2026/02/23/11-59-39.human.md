Refactoring patch in Patrick Steinhardt's ref iteration API unification series. This is patch 5/17 in the v2 submission, which renames the `each_ref_fn` callback type to `refs_for_each_cb` to better match current naming conventions.

The change is purely mechanical, updating the type name across 11 files while keeping all behavior identical. The patch follows the series' pattern of standardizing names around the `refs_for_each_*` prefix that was established in earlier patches. Karthik Nayak has already reviewed and approved the full series, including this straightforward rename.

This continues the effort to consolidate Git's ref iteration API into a unified `refs_for_each_ref_ext()` interface, eliminating 14 specialized functions. The series has demonstrated significant performance improvements (115ms to 1.1ms for glob iteration) while maintaining identical behavior across all converted callers.
