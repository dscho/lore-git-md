This is a follow-up in the thread about zombie processes when Git runs as PID 1 in containers. Kristoffer Haugsbakk points out a discrepancy in the email addresses used in Andrew Au's patch submission - the From header uses a GitHub noreply address while the Signed-off-by trailer uses a personal email. This is a minor housekeeping note about contributor identity consistency rather than technical feedback on the patch itself.

The observation doesn't challenge the technical merits of the proposed atexit handler solution for reaping child processes during abnormal exits. It simply flags that the author's identity as presented in the headers doesn't match their signing identity, which could cause attribution issues if not corrected before merging. The comment suggests this may be an automatic GitHub behavior rather than an intentional choice.

This is a straightforward administrative note that the patch author will likely want to address in a v2 by ensuring their real email appears in both places, but it doesn't affect the technical assessment of the zombie process fix. The thread's core discussion about container process handling remains unchanged by this observation.
