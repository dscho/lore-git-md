This is part 15 of Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. The patch converts the `read_alternates()` functionality to use a callback-based approach, continuing the systematic refactoring pattern established in previous patches.

The changes:
- Move the existing alternates parsing logic from `odb.c` to `source-files.c` as a new callback implementation
- Add a `read_alternates` callback to `struct odb_source` with detailed documentation about the expected behavior and format
- Keep the core `parse_alternates()` function in `odb.c` but make it publicly available via `odb.h` since it's still needed by the files backend
- Maintain all existing behavior while enabling future alternative backends to implement their own alternates handling

The patch follows the same careful approach as previous conversions in the series - preserving functionality while establishing clear contracts for backend implementations. This continues the incremental progress toward the larger goal of making object storage fully pluggable.
