This patch continues Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to support pluggable backends. It focuses on making the cleanup mechanism for ODB sources polymorphic by introducing a `free` callback in `struct odb_source`.

The change moves backend-specific cleanup logic (previously handled by `odb_source_files_free()`) into a callback that gets registered when the source is created. The generic `odb_source_free()` now delegates to this callback rather than directly calling the files-backend implementation. This follows the established pattern for pluggable subsystems in Git, where operations are defined through function pointers in a base structure.

Key technical points:
- Removes the public `odb_source_files_free()` function since cleanup is now handled through the callback
- Adds the `free` function pointer to `struct odb_source` with clear documentation about its contract
- Updates the files backend to register its cleanup function during initialization
- Maintains all existing cleanup behavior while making the mechanism extensible

This is a typical incremental step in Patrick's architectural work - focused, well-contained, and moving systematically toward the goal of pluggable storage backends. The patch follows the series' pattern of introducing callback-based operations one at a time while keeping the changes minimal and behavior-preserving.
