This is part 5/17 of Patrick Steinhardt's refactoring series to unify Git's ref iteration interfaces. The patch performs a mechanical rename of the `each_ref_fn` callback function type to `refs_for_each_cb` to better match current naming conventions. 

The change is straightforward but wide-ranging, touching 11 files across the codebase where the callback type is used. The rename maintains identical behavior while making the API more consistent with the project's current best practices. This is part of the broader effort to consolidate 14 specialized ref iteration functions into a single unified `refs_for_each_ref_ext()` interface.

Key technical details:
- The callback type is used throughout the refs subsystem for iterating over references
- All call sites are updated to use the new name
- The change is purely syntactic - no behavior is modified
- Documentation comments are updated to reference the new type name
- Part of a larger series that has already been reviewed and approved by Karthik Nayak

This patch follows the pattern established in part 4/17 which renamed the `do_for_each_ref_flags` enum. The series as a whole is in its final polishing stages with all major technical issues resolved.
