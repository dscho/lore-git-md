This is the second patch in Derrick Stolee's 13-part performance improvement series for `git config list --type=<X>` filtering. The series aims to optimize config value parsing by enabling type filtering during initial parsing rather than after-the-fact.

This particular patch is a preparatory change that adds a new `gently` parameter to the `format_config()` function, though it doesn't yet implement the gentle parsing functionality. The parameter is currently unused but will be leveraged in later patches to avoid `die()` calls when parsing config values in list mode. The change is straightforward - it updates the function signature and all callers to pass 0 for now, with a comment explaining the future intent.

As part of a well-structured series, this patch follows the first one (pure code movement) and precedes the actual implementation of gentle parsing. The changes are mechanical and low-risk, serving as groundwork for the more substantive performance improvements to come. The commit message clearly indicates this is an intermediate step toward the series' goal.
