This is a documentation patch thread that has now been withdrawn. The original patch proposed documenting special date keywords like "now", "yesterday", and "tea" that Git's `--date` parser accepts but were previously undocumented. 

Junio C Hamano, the Git maintainer, explained that these were likely left undocumented intentionally as "easter eggs" rather than formal features, with "now" being the only one that might have practical use for commits. He also noted there are other undocumented relative formats like "7.days.ago" that weren't included in the proposal, making selective documentation potentially misleading.

The author, Md Ferdous Alam, has accepted this reasoning and withdrawn the patch. The thread shows the project's careful consideration of what belongs in official documentation versus informal implementation details, with the maintainer's perspective carrying decisive weight in such cases. No further discussion appears needed on this topic.
