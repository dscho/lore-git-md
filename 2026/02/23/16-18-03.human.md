This is part of Patrick Steinhardt's ongoing series to make Git's object database (ODB) subsystem pluggable. Patch 12/17 converts the `freshen_object()` operation to use the callback pattern established in earlier patches.

The change moves the freshening logic (which updates object timestamps to prevent garbage collection) from `odb.c` into the files backend implementation in `source-files.c`. The patch follows the established pattern: it adds a new callback to `struct odb_source`, documents its expected behavior, and provides a type-safe wrapper function (`odb_source_freshen_object()`).

The implementation maintains all existing behavior while making the operation pluggable for future alternative backends. Like the rest of the series, this is a focused, mechanical change that advances the larger architectural goal while preserving backward compatibility. The commit message is clear and the diff shows the systematic approach seen throughout this effort.
