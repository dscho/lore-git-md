This is patch 11/17 in Patrick Steinhardt's series to unify Git's ref iteration interfaces. The series replaces 14 specialized ref iteration functions with a single configurable `refs_for_each_ref_ext()` interface.

This particular patch removes the `refs_for_each_ref_in()` function, converting all its callers to use the new unified interface instead. The changes are mechanical - each caller now constructs a `refs_for_each_ref_options` struct with the same prefix and trim parameters that were previously passed directly to `refs_for_each_ref_in()`. The patch touches several key areas including bisect`, `rev-parse`, and the bitmap code.

The series has been thoroughly reviewed by Karthik Nayak and is in its final polishing stages. Performance testing shows significant improvements (115ms to 1.1ms for glob iteration) from earlier patches in the series. This patch continues the clean, focused approach seen throughout - each change is straightforward and well-contained, with clear commit messages explaining the transformation.
