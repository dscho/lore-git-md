Documentation patch addressing a missing command-line option in the git-clone man page.

The email points out that while `--recursive` is commonly used in project documentation to clone with submodules (equivalent to `--recurse-submodules`), this shorthand is not mentioned in the official `git-clone` documentation. The author asks whether `--recursive` is outdated or intentionally undocumented.

This appears to be a straightforward documentation gap - `--recursive` has been a supported alias for `--recurse-submodules` since Git 1.6.5 (2009), but the man page only documents the longer form. The patch would be a simple addition to the options list, though it might warrant a note about preferred usage since `--recurse-submodules` is the canonical form. The email is clear and well-motivated, identifying a real inconsistency between common practice and official docs.
