This is the final patch in a 5-part series improving Gitweb's mobile responsiveness. The series targets CSS layout issues that appear on narrow screens (<=768px width), with this patch specifically addressing how the page header handles long project names that wrap to multiple lines.

The change replaces a fixed `height: 25px` with `min-height: 25px` in the page header's CSS, allowing the header to expand vertically when project names wrap while maintaining the same minimum height for single-line titles. This completes the mobile adaptation work started in earlier patches, which fixed overflow issues in search bars, diff views, and footers.

The implementation is minimal (a one-line CSS change) and maintains backward compatibility with desktop layouts. The series as a whole appears well-scoped, addressing specific mobile usability pain points without attempting a full redesign. The commit message clearly explains the problem and solution, though it might benefit from mentioning that this was the last remaining issue identified in the cover letter's mobile adaptation plan.
