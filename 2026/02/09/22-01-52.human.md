This is a documentation clarification from the maintainer regarding the `--recursive` alias in `git clone`. Junio C Hamano confirms that while `--recursive` still works as an alias for `--recurse-submodules` for backward compatibility, it was intentionally removed from documentation and help text after being recognized as a poor naming choice. The project prefers users to use the clearer `--recurse-submodules` form.

The email suggests this might be a candidate for removal in Git 3.0, along with other hidden compatibility aliases, though that would require a separate discussion thread. This is a straightforward response that settles the original question - the undocumented status of `--recursive` is intentional, not an oversight. The maintainer's position is clear: users should avoid the alias in favor of the properly named option.
