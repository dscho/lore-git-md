This is a final polishing patch in a series implementing reference backend selection for Git repositories, allowing runtime switching between files-based and reftable storage. The series is now in its fourth iteration with all major technical issues resolved.

The current patch adds a `GIT_REFERENCE_BACKEND` environment variable that mirrors the functionality of the `extensions.refStorage` config option introduced earlier in the series. The environment variable takes precedence over the config setting, enabling temporary backend overrides for individual commands. This completes the dual configuration mechanism for reference storage selection.
