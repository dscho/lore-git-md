This creates a real problem for users trying to follow modern practices of renaming the default branch from "master" to "main" - they can't see what branch they're actually on when trying to rename it.

Ryan argues this is poor user experience that hides important information, and that `git branch` should show the pending default branch name to match what `git status` displays. The change would need to modify the branch listing code in `builtin/branch.c` to surface this information more consistently.
