Junio's response indicates the project considers this a configuration matter rather than a code behavior issue that needs fixing. While the UX inconsistency between `git status` and `git branch` remains, the maintainer position appears to be that the planned Git 3.0 default branch name change will address the broader concern, making code changes to unify the behavior unnecessary.
