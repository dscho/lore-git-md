Documentation patch standardizing command references in `git am` docs. This is the first of four patches in a series from Kristoffer Haugsbakk to improve `git am` documentation.

The patch normalizes how Git commands are referenced in the `git-am` man pages, replacing inline verbatim/emphasis markup with consistent `linkgit` references. It also removes redundant "see <gitlink>" phrases when the command is already linked. Changes are purely presentational - no content is added or removed, just reformatted for consistency with project documentation standards.

This appears to be a straightforward documentation cleanup with no controversial changes. The patch is part of an ongoing effort to standardize Git's documentation formatting. The author notes it conflicts with another of their documentation topics currently in Junio's `seen` branch, which will need resolution before merging.
