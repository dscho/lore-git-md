This is a gitweb improvement patch that adds mobile device support. The first in a 5-part series, it introduces a viewport meta tag to make gitweb render properly on mobile browsers by ensuring the layout viewport matches the device width rather than defaulting to desktop dimensions.

The change is straightforward - a single line addition to gitweb.perl that inserts the standard viewport meta tag used by responsive websites. The commit message clearly explains the problem (mobile browsers render desktop-width pages scaled down) and how this change addresses it (making the viewport track device width). This appears to be well-motivated and uncontroversial, serving as the foundation for subsequent mobile CSS improvements mentioned in the commit message.

The patch touches only gitweb's HTML header generation, modifying how the web interface renders rather than any core Git functionality. As the first of five patches, readers should expect follow-up changes to build on this viewport adjustment with more mobile-specific styling. The change is small, focused, and clearly explained - exactly what we want to see in an initial patch of a series.
