This is a documentation patch series that improves the `git am` man pages and related configuration. The series comes from Kristoffer Haugsbakk, who has been an active documentation contributor.

The main changes in this 4-patch series are:
1. Standardizing how `git am` and other commands are referenced in the documentation by using `linkgit` markup consistently
2. Documenting the `am.messageId` configuration option which was previously missing
3. Clarifying that `--message-id` adds a Message-Id trailer to commits
4. Expanding the documentation about hooks used during `git am`

The patches touch `Documentation/config/am.adoc` and `Documentation/git-am.adoc`, with mostly mechanical changes to improve consistency and completeness. The author notes this conflicts with another of their documentation topics in Junio's `seen` branch due to overlapping changes in adjacent paragraphs.

This appears to be straightforward documentation maintenance work - the changes are well-scoped and the commit messages clearly explain each improvement. The series follows Git's documentation conventions and doesn't introduce any controversial changes. The conflict with another pending topic is noted upfront, which is helpful for the maintainer.
