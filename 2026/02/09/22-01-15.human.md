This is a feature patch that implements UTF-8 support for Git aliases using config subsections, following the design consensus reached in the mailing list discussion. The patch comes from Jonatan Holmgren and builds on Jeff King's suggestion to use subsection syntax (`[alias "förgrena"] command = branch`) rather than modifying the existing ASCII-only alias syntax.

The implementation adds case-sensitive matching for subsection aliases while maintaining backward compatibility with the existing case-insensitive flat syntax (`alias.co = checkout`). The documentation is thoroughly revised to explain both syntaxes, with clear examples showing UTF-8 and whitespace-containing aliases. The patch includes comprehensive tests covering:
- Basic UTF-8 alias functionality (Swedish and CJK characters)
- Aliases containing spaces
- Case sensitivity differences between old and new syntax
- Error cases like invalid subsection keys

The solution avoids Unicode normalization complexities by treating subsection names as literal byte streams, leveraging existing config infrastructure. Security concerns raised earlier in the thread are addressed by not introducing new Unicode handling code. The maintainer (Junio Hamano) has already approved the approach, and this appears to be a well-crafted implementation of the agreed design.
