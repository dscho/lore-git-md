This is a build system fix targeting the meson build configuration. Phillip Wood addresses an issue where building documentation with meson fails when the build directory isn't directly under the source directory. The problem occurs because the mergetool documentation generator script can't find its supporting library due to incorrect path assumptions.

The patch modifies `Documentation/meson.build` to pass the correct source directory path to the script rather than relying on relative paths. It also removes an unnecessary environment variable setting since the script already handles this internally. The change is small (4 lines removed, 1 added) and focused on the specific build issue.

The commit message notes this doesn't address the underlying problem that the build doesn't fail when the script errors out (due to the error being upstream of a pipe), suggesting this might need follow-up work. The patch appears straightforward and well-motivated, fixing a clear build system bug.
