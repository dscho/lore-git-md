This is a documentation patch series that has now been accepted into Junio's queue. The four patches improve the `git am` man pages by:

1. Standardizing command references to use `linkgit` markup consistently
2. Clarifying that `--message-id` and `--signoff` add trailers to commit messages
3. Documenting the previously undocumented `am.messageId` configuration option
4. Expanding and improving the documentation around hooks, including fixing the synopsis to show the `--verify` option and clarifying that `post-applypatch` cannot be skipped

The series was reviewed by D. Ben Knoble who found no issues, and Junio has now queued it for inclusion. The author notes it conflicts with another of their documentation topics currently in Junio's `seen` branch, but that appears to be an administrative rather than technical issue.

These changes follow Git's ongoing documentation standardization efforts, particularly around command reference formatting and synopsis style. The patches are straightforward improvements that fill gaps and make the documentation more consistent and complete.
