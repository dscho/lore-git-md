This is the fifth and final patch in Patrick Steinhardt's series improving CI/build system reliability, specifically targeting test execution consistency across platforms. The patch focuses on enhancing failure handling for MSVC+Meson test jobs in GitLab CI.

The change adds proper test failure reporting for the Windows/MSVC environment when using Meson builds. It introduces three key improvements: (1) setting up a dedicated test output directory, (2) printing test failures via `ci/print-test-failures.sh` when jobs fail, and (3) collecting failed test artifacts for upload. These changes mirror functionality already present in GitHub Actions, making debugging test failures on Windows more practical.

The patch modifies `.gitlab-ci.yml` to:
- Define a `TEST_OUTPUT_DIRECTORY` variable pointing to "C:/Git-Test"
- Create this directory in the `before_script` phase
- Pass the directory to Meson via `-Dtest_output_directory`
- Add an `after_script` that runs the failure reporting script and moves artifacts when tests fail
- Configure artifact uploads to include the failure reports

This completes the series' goal of making test execution behavior consistent between GitHub and GitLab CI environments, particularly for Windows builds. The changes are focused and well-contained, following the pattern established in earlier patches of the series.
