This is a test infrastructure patch series addressing CI failures on Windows/MSVC platforms. The issue stems from tests assuming the presence of the `iconv(1)` executable when Git's ICONV support is enabled, which isn't reliably available in the Git for Windows/MSVC test environment.

Patrick Steinhardt's 4-patch series makes several test scripts properly respect the ICONV prerequisite, ensuring they skip rather than fail when the executable isn't available. The changes are focused on test scripts that deal with character encoding conversion (t4xxx, t4205, t6006) and HTTP error message handling (t5550). 

The series takes a pragmatic approach by building on the existing ICONV prerequisite check rather than introducing a new ICONV_EXECUTABLE check, since Git itself doesn't perform re-encoding without ICONV support anyway. The patches are straightforward mechanical conversions of test conditions and skip messages, with t4205 seeing the most significant restructuring to better handle the prerequisite.

This appears to be a well-scoped fix for a real CI problem, coming from a contributor with deep knowledge of Git's test infrastructure. The changes are limited to test scripts and don't affect production code, making them low-risk while solving an immediate pain point in the Windows/MSVC test environment.
