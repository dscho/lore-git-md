Patrick Steinhardt's patch set fixes this by properly handling the distinction between libiconv (linked into Git) and the `iconv(1)` executable (used in test scripts) across multiple test files including t6006-rev-list-format.sh and others.

The solution makes the test suite more robust by not assuming the presence of the `iconv(1)` executable, particularly important since recent MinGW builds no longer include it.
