CI/build system patch series from Patrick Steinhardt addressing GitLab CI issues. This 5-part series focuses on improving test failure handling and consistency between Meson and Make-based test runs in the CI pipeline.

The main changes include fixing a test-slicing bug that was causing GitLab CI to skip the first test, unifying the Meson test execution between GitLab and GitHub workflows, and adding proper error logging for failed tests - particularly for the MSVC+Windows environment where debugging was previously difficult. The patches demonstrate Patrick's characteristic attention to CI infrastructure details, though he notes some test failures remain that will be addressed in a separate series.

This appears to be routine maintenance work to improve CI reliability and debugging capabilities, particularly for Windows builds. The changes are focused and well-motivated by real debugging pain points encountered while working on the GitLab CI setup.
