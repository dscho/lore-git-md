This thread addresses a documentation gap in the `git-clone` man page regarding the `--recursive` option. While this shorthand for `--recurse-submodules` has been supported since Git 1.6.5 (2009) and appears frequently in project documentation and tutorials, it is currently missing from the official manual page. The author notes this inconsistency and questions whether the omission is intentional or simply an oversight.

The proposed change would be straightforward - adding `--recursive` to the options list with a note that it's equivalent to `--recurse-submodules`. However, there may be some discussion about whether to explicitly recommend the longer form in the documentation, since `--recurse-submodules` is the canonical option name. The patch appears well-motivated and addresses a genuine discrepancy between common usage and official documentation.
