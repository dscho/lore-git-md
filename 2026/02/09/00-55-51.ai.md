This is an update on the SHA-1/SHA-256 interoperability effort, part of Git's ongoing Rustification work. Maintainer Junio C Hamano confirms that brian m. carlson's v3 patch series has resolved the CI breakages that were noted in the previous "What's cooking" report. The series adds Rust-based infrastructure for maintaining object name mappings between different hash algorithms, including wrappers for hashfile code, a new binary object map format, and hash algorithm abstractions.

The v3 iteration is functionally identical to v2 but with fixed CI issues (notably Rust linking problems). Junio notes that while v1 generated substantial discussion, v2 saw little feedback, suggesting the technical approach may have stabilized. The series remains focused on the long-term goal of enabling interoperability between SHA-1 and SHA-256 repositories, though platform compatibility challenges persist. This work continues Git's gradual introduction of Rust into core object storage components while maintaining the project's C foundations.
