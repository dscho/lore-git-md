This is part 3/5 of a series improving Gitweb's mobile responsiveness, focusing on fixing horizontal overflow in log/commit/blob/diff views. The patch adds mobile-specific CSS rules (64 new lines) that adjust padding, enable horizontal scrolling for preformatted content, and constrain table widths to prevent overflow on narrow screens. Key changes include making diff headers and code blocks scrollable rather than forcing page-wide overflow, reducing padding in log views, and ensuring search boxes stay within viewport bounds.

The technical approach uses a shared media query (`@media (max-width: 768px)`) to scope all changes to mobile viewports, maintaining desktop layout compatibility. Notable adjustments include `overflow-x: auto` for scrollable containers, `min-width: max-content` to preserve code block readability, and reduced padding in log/diff sections. The patch builds on part 2/5's search box fixes by moving those rules into the media query block for consistency.

This continues the series' theme of adaptive rather than redesign-oriented changes, with careful attention to preserving existing functionality while fixing mobile usability issues. The implementation appears thorough, addressing multiple view types with targeted rules that should work across modern mobile devices. No behavioral changes are introduced for desktop users.
