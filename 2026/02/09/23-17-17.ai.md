This is part 4 of a 5-patch series improving Gitweb's mobile responsiveness, specifically addressing footer overflow issues. The patch fixes a layout problem where the footer's fixed height and floated elements could cause content to overflow on narrow screens when text wraps.

The technical changes replace the fixed `height: 22px` with `min-height: 22px` and add a clearfix hack (`::after` pseudo-element) to ensure the footer container properly expands to contain its floated children. This maintains the same visual appearance on desktop while allowing proper text wrapping on mobile without overflow. The changes are scoped to the existing mobile-responsive CSS rules introduced earlier in the series.

The implementation is straightforward - just 8 lines changed in gitweb.css - and follows the series' pattern of minimal, targeted fixes that preserve desktop layout while improving mobile experience.
