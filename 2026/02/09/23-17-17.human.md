This is part 4 of a 5-patch series improving Gitweb's mobile responsiveness. The patch addresses footer overflow issues on narrow screens by replacing a fixed height with a minimum height and adding a clearfix to properly contain floated elements when text wraps.

The change is straightforward: the footer had a fixed 22px height that could cause overflow when text wrapped on small screens. The patch switches to `min-height` to allow vertical expansion and adds a CSS clearfix (using `::after` pseudo-element) to ensure floated footer elements don't escape their container. This maintains the existing desktop appearance while fixing mobile display issues.

The series is shaping up as a focused, incremental improvement to Gitweb's mobile experience. Each patch tackles a specific display issue while preserving the desktop layout. This particular change is small (8 lines modified) and well-contained, following the pattern established in earlier parts of the series. The commit message clearly explains the problem and solution without unnecessary detail.
