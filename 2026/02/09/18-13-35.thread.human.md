This thread documents a small but useful improvement to Git's documentation. Kristoffer Haugsbakk has submitted a patch that adds a proper hyperlink from the rerere-options documentation to the main `git-rerere` man page. Currently, the options documentation mentions "rerere" in plain text; the change converts this to a `linkgit:` reference that will render as a clickable link in the documentation.

The change helps users discover the full `git-rerere` command when reading about the `--[no-]rerere-autoupdate` options that appear in several Git commands. This follows Git's documentation conventions for cross-referencing and is exactly the sort of small polish that improves the user experience. Given Kristoffer's track record with documentation improvements and the straightforward nature of this change, it will likely be merged without controversy.
