This is a documentation clarification regarding a deprecated Git clone option. The thread began with a user noticing that `--recursive` (a common alias for `--recurse-submodules`) is missing from the official documentation. 

D. Ben Knoble confirms this is intentional - `--recursive` is an undocumented alias kept for backward compatibility, with `--recurse-submodules` being the preferred modern form. He points to historical commits showing this was a deliberate documentation choice made years ago when the more precise option name was introduced.

The thread is effectively closed, with maintainer Junio C Hamano having previously confirmed this undocumented status is correct policy. While the alias remains functional for compatibility, it's considered deprecated and won't be added back to documentation. The exchange serves as a useful reference for anyone else who might notice this discrepancy in the future.
