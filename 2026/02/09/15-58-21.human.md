This is the final patch in a series implementing reference backend selection for Git repositories, adding environment variable support to complement the existing config-based approach. The patch introduces `GIT_REFERENCE_BACKEND` as an environment variable that can override the reference storage backend (files or reftable) and its location on a per-command basis, similar to how `GIT_OBJECT_DIRECTORY` works for object storage. The environment variable takes precedence over the `extensions.refStorage` config when both are set.

The implementation handles URI parsing and validation consistently with the config approach, including proper worktree integration. The patch includes comprehensive test coverage in t1423-ref-backend.sh that verifies both config and environment variable approaches work equivalently for reading, writing, and migrating between backends. Documentation is added to git.adoc explaining the new variable.

This completes the technical implementation of the reference backend selection feature that has been under development through multiple iterations. The series is now in final polishing phase with only minor documentation wording refinements remaining.
