This is a feature patch that implements UTF-8 support for Git aliases using the config subsection syntax, following the design consensus reached in the mailing list discussion. The patch comes from Jonatan Holmgren and builds on Jeff King's suggestion to use subsections rather than modifying the core config key parser.

The implementation adds a new subsection-based syntax (`[alias "förgrena"] command = branch`) alongside the existing flat syntax (`alias.co = checkout`). The key differences are that the subsection syntax preserves case and allows UTF-8 characters, while the flat syntax remains case-insensitive for backward compatibility. The patch includes comprehensive documentation updates and new tests covering both UTF-8 aliases and the interaction between the two syntax forms.

Technical details include modifications to `alias.c` to handle both syntax forms through `parse_config_key()`, with case-sensitive matching for subsections and case-insensitive for flat syntax. The tests verify Swedish, CJK characters, spaces in names, and case sensitivity behavior. The solution avoids Unicode normalization complexities by treating subsection names as literal byte streams.

This appears to be a well-crafted implementation of the agreed-upon design, with thorough test coverage and clear commit message. The patch maintains backward compatibility while adding the requested functionality. Given the prior discussion and maintainer approval, this seems ready for merging pending any final review comments.
