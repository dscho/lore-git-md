Test infrastructure patch in Patrick Steinhardt's series fixing CI failures related to ICONV support on Windows/MSVC platforms. This is the fourth and final patch in the v1 series, addressing test assumptions in t6006 (rev-list formatting tests).

The patch modifies two tests in t6006 that currently depend on the `iconv(1)` executable being available when checking commit message encoding. The tests were failing on platforms where Git has ICONV support compiled in but the `iconv` executable isn't present in the test environment. The changes make the tests more robust by:

1. Making the commit message encoding conditional on the ICONV prerequisite - using UTF-8 when ICONV isn't available
2. Similarly handling the expected output encoding for test comparisons
3. Restructuring the test setup to use shell variables and heredocs for better readability

The patch maintains the same test coverage while removing the implicit dependency on the `iconv` executable being present. This continues the series' theme of making tests more portable across different build configurations, particularly important for Windows/MSVC environments where toolchain differences often surface these assumptions. The changes are mechanical and focused solely on test reliability without altering any production code behavior.
