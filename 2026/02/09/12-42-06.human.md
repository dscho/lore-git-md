This is the third patch in a 4-part test infrastructure series from Patrick Steinhardt addressing CI failures on Windows/MSVC platforms related to `iconv(1)` availability. The patch focuses on HTTP fetch tests in t5550 that check error message handling.

The tests connect to a special "$HTTPD_URL/error" endpoint that uses `iconv` to reencode error messages, but this executable may be missing on some platforms (particularly Windows/MSVC). The patch adds ICONV prerequisites to these tests so they'll be skipped rather than failing when `iconv` isn't available. It also modernizes some test assertions by replacing direct `grep` calls with the preferred `test_grep` helper.

This is a straightforward test robustness improvement that follows the pattern established in earlier patches of the series. The changes are mechanical but important for making the test suite more portable across different build environments. The patch maintains all existing test coverage while properly handling platform limitations.
