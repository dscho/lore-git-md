Gitweb mobile responsiveness improvements. This is a 5-patch series from Rito Rhymes that addresses layout issues in gitweb when viewed on mobile devices (screen widths ≤768px). The changes preserve the existing desktop layout while adding mobile-specific CSS rules to prevent content overflow and improve readability.

The series starts by adding a viewport meta tag (patch 1), then tackles specific overflow issues in the project search bar (patch 2), various content views (patch 3), footer layout (patch 4), and project name display in headers (patch 5). The cover letter includes before/after screenshots demonstrating the improvements across projects, log, commitdiff, and tree views.

The motivation notes that while development remains primarily desktop-oriented, common Git browsing tasks are increasingly done on mobile devices. The changes are focused on adaptive layout rather than redesign, maintaining backward compatibility while fixing the most disruptive mobile rendering issues. The patches touch gitweb.perl (adding the viewport tag) and gitweb.css (adding 74 lines of mobile-specific CSS rules).
