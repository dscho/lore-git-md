This is a documentation patch from Kristoffer Haugsbakk, part of a 4-patch series improving `git am` documentation. This first patch focuses on standardizing command references throughout the man pages.

The patch normalizes how Git commands are referenced in both `git-am.adoc` and `am.adoc` configuration documentation. It replaces inline verbatim/emphasis markup (like 'git am') with consistent `linkgit` references (like `linkgit:git-am[1]`), and removes redundant "see <gitlink>" phrases when the link is present in the text. The changes are mechanical but improve consistency and make the documentation more maintainable.

The patch touches many command references across both files, including `git-mailsplit`, `git-mailinfo`, `git-apply`, and `git-rebase`.
