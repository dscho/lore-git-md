This is a patch in the ongoing Rust infrastructure reorganization effort, specifically addressing the directory structure for Git's experimental Rust code. Mike Hommey proposes moving all Rust-related files from `src/` to a dedicated `rust/` subdirectory, including the Cargo.toml, build scripts, and source files.

The patch follows up on earlier RFC threads where concerns were raised about mrustc compatibility and project structure conventions. Key changes include updating the Makefile and meson.build configurations to point to the new locations, and adding appropriate entries to .gitignore for the relocated Rust build artifacts. The move aims to clarify the project is multi-language and prevent confusion from having a top-level Cargo.toml that doesn't produce useful standalone builds.

Notably, this version comes after technical revelations in the thread showed mrustc's minicargo can handle non-standard directory structures, weakening one of the original technical objections. The patch doesn't yet address the separate git-cinnabar build issues that were part of the original motivation, focusing purely on the directory reorganization.

The changes are mechanical but touch multiple build systems (both Make and meson) and would affect anyone working with Git's experimental Rust support. The patch appears well-formed with proper sign-off and clean diffs, though it remains to be seen how the community will weigh the tradeoffs between project structure clarity and any remaining cross-compilation concerns.
