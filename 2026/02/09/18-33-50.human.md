CI infrastructure patch completing a series to improve test reliability on Windows/MSVC builds. This final patch in Patrick Steinhardt's 5-part series adds proper failure handling for MSVC+Meson test jobs in GitLab CI, mirroring the behavior already present in GitHub Actions. 

The change ensures failed tests are properly reported and their artifacts collected when running under GitLab CI on Windows. Key improvements include setting up a dedicated test output directory, configuring Meson to use it, and adding an after-script that prints test failures and preserves their artifacts when jobs fail. Justin Tobler confirms the patch looks good in his review, having previously provided feedback on earlier patches in the series.

This completes the systematic effort to standardize test execution and failure handling across both major CI platforms (GitHub Actions and GitLab CI), with particular attention to Windows/MSVC environments where test infrastructure has historically been more fragile. The series demonstrates the project's ongoing investment in making CI pipeline failures more debuggable and consistent across platforms.
