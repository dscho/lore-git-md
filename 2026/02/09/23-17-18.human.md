This is the final patch in a 5-part series improving Gitweb's mobile responsiveness. The series adds mobile-specific CSS rules to make Gitweb more usable on small screens while maintaining the desktop layout.

This specific patch addresses an issue where long project names in the Gitweb header would wrap to multiple lines on mobile devices, but the fixed header height didn't adjust to accommodate the wrapped text. The solution changes the header's CSS from a fixed `height: 25px` to `min-height: 25px`, allowing the header to expand vertically when needed while maintaining the same baseline height for single-line titles.

The change is minimal (just one line modified) but completes the mobile responsiveness improvements started in earlier patches. The series has focused on adaptive changes rather than a full redesign, carefully preserving the existing desktop experience while fixing overflow and layout issues on mobile viewports. No behavioral changes are introduced for desktop users.

The patch appears well-contained and follows the same approach as the rest of the series - a targeted fix for a specific mobile usability issue. With this change, the series now addresses all the mobile layout problems identified in the cover letter.
