This is a refactoring patch in the final stages of the reference storage backend selection series, addressing Patrick Steinhardt's review comments on the v4 implementation. The patch focuses on properly handling reference storage paths when using alternate locations (via `extensions.refStorage` config or `GIT_REFERENCE_BACKEND` environment variable).

The key changes in this iteration are documentation and code cleanups based on Patrick's feedback. Karthik Nayak updates the config documentation to use "payload" instead of "location" terminology, removes redundant comments about stub creation now handled by a dedicated function, and adds allocation optimizations by using `strbuf_detach()`. The files backend initialization now uses the new `refs_compute_filesystem_location()` helper to parse paths from the payload.
