Gitweb mobile responsiveness improvement (part 2/5). This patch addresses a specific layout issue where the project search bar could overflow its container on narrow screens, forcing horizontal scrolling. The fix adds padding to the search container and constrains the input field width using CSS `max-width` and `box-sizing` properties.

The changes are minimal (7 lines added to `gitweb.css`) and focused on the search bar component. This is part of a larger series that systematically improves mobile usability while maintaining the existing layout for desktop users. The patch follows the series' stated approach of being backward-compatible and avoiding redesigns in favor of targeted adaptations.

Technical details for future reference: modifies `div.projsearch` and its `input[type="text"]` styling in gitweb's static CSS, adding padding and width constraints that only affect mobile viewports (<=768px) through media queries established in the series' first patch. The `box-sizing: border-box` ensures padding is included in width calculations.
