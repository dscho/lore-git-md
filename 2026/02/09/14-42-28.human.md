This is a final review comment on a 4-part series adding macOS support for Git's TRACE2 process ancestry tracing while refactoring the Windows implementation. The series has already been reviewed by Derrick Stolee, who confirms the technical approach.

The patch being discussed (4/4) completes the work by making Windows emit ancestry data through both the legacy JSON format (for backward compatibility) and the new unified `trace2_cmd_ancestry()` interface. Stolee agrees with the dual-emission strategy but suggests setting a timeline - perhaps two major versions - for eventually dropping the JSON compatibility layer.

The series appears well-executed, with careful attention to cross-platform consistency (10-level depth limit, cycle detection) and build system integration (Makefile, CMake, Meson). Stolee's earlier reviews identified minor optimizations but no blocking issues. This final comment indicates the series is effectively complete from a technical standpoint, with only a minor policy question about the compatibility window remaining.
