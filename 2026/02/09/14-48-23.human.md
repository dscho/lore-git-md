This is a review response from Derrick Stolee on a series adding macOS support for TRACE2 process ancestry tracing. The series (previously summarized in the thread context) implements macOS process info collection via `sysctl`, refactors the Windows implementation, and unifies the output format across platforms.

Stolee notes the technical approach looks sound but raises two key points: the lack of test coverage for the new macOS functionality, and the need to eventually phase out the legacy JSON format on Windows (while agreeing the current dual-emission strategy is appropriate). He suggests a two-version deprecation timeline for the old format.

The review is generally positive with only minor nitpicks about implementation details and string handling. Stolee specifically asks about expanding test coverage in `t0210-trace2-normal.sh`, though acknowledges platform limitations in CI. This suggests the series is nearly ready to merge pending potential test additions, with clear forward-looking guidance about the Windows JSON format's eventual removal.
