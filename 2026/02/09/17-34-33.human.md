This is a documentation patch series that improves the `git am` man pages in two ways: standardizing command references and filling in missing details about configuration and hooks.

The series from Kristoffer Haugsbakk first normalizes how `git am` documentation refers to other Git commands, replacing informal mentions like 'git rebase' with proper `linkgit:` markup for consistency. It then documents the previously undocumented `am.messageId` configuration option that controls whether to add a Message-Id trailer when applying patches.

The final patch expands the hooks section of `git am` documentation to be more thorough. The changes are focused and mechanical, touching only documentation files. The author notes this conflicts with another of their documentation topics in Junio's `seen` branch, but the changes appear straightforward and well-contained.

This looks like a solid documentation cleanup - the kind of small but meaningful improvement that makes the manuals more precise and complete. The changes are focused and unlikely to be controversial.
