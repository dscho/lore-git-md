This is a test infrastructure patch series addressing CI failures on Windows/MSVC builds. The issue stems from tests assuming the `iconv(1)` executable is available when it may not be, particularly in GitLab CI's MSVC environment which lacks a full MSYS2 installation.

Patrick Steinhardt proposes fixing this by properly gating all `iconv(1)` usage behind the existing `ICONV` prerequisite in the test suite, rather than introducing a new prerequisite. The series touches six test scripts that make this assumption, adjusting them to skip tests when iconv support isn't available.

The changes are mechanical but important for maintaining CI reliability. The approach is pragmatic - since Git itself doesn't perform re-encoding without built-in ICONV support, there's no need for the tests to assume the executable exists independently. This keeps the solution simple while fixing the immediate problem.

The patch series is focused and well-motivated, with each commit addressing a specific test file. Given Patrick's track record with CI and Windows-related fixes, this is likely to be uncontroversial and quickly accepted. The changes don't affect production code - they only modify test behavior when prerequisites aren't met.
