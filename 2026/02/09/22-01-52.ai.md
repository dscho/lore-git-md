This is a documentation clarification from the maintainer regarding the `--recursive` alias in `git clone`. Junio C Hamano confirms that while `--recursive` still works as an alias for `--recurse-submodules` for backward compatibility, it was intentionally removed from documentation and help text after being recognized as a poor naming choice. The alias dates back to early Git versions before the more precise `--recurse-submodules` name was established.

The email suggests this might be part of a broader pattern of hidden compatibility options that could be audited and potentially removed in a future Git 3.0 release, though that would require separate discussion. For now, users should consider `--recursive` deprecated in favor of the properly named `--recurse-submodules` option, despite its continued technical support.

This response effectively closes the original inquiry by confirming the documentation omission was intentional rather than an oversight. It also hints at a potential future cleanup effort around hidden compatibility options, though no immediate action is proposed beyond continuing to avoid the deprecated alias in documentation and new scripts.
