This is a UI improvement patch for gitweb, the first in a 5-part series aimed at improving mobile device support. The patch adds a standard viewport meta tag to gitweb's HTML output, which ensures mobile browsers will render pages at their native width rather than scaling down a desktop-sized layout. The commit message clearly explains the problem being solved (pages rendered too small on mobile) and positions this as foundational work for subsequent mobile CSS improvements.

The change is straightforward - a single line addition to `gitweb/gitweb.perl` that inserts the viewport meta tag in the page header. The patch appears well-scoped and correctly implemented, with the commit message following Git project conventions. As the first in a series, it sets up for more substantial mobile UI work to follow.
