This thread introduces a series of patches to improve gitweb's mobile experience. The first patch, from an author whose name we'll see in subsequent emails, adds a viewport meta tag to ensure gitweb pages render at the proper width on mobile devices rather than being scaled down from desktop dimensions. The change is minimal - just one line added to gitweb.perl - but serves as the necessary foundation for upcoming mobile styling improvements mentioned in the commit message.

The patch appears uncontroversial, addressing a clear usability issue for mobile users without impacting desktop rendering or core Git functionality. As the first of five planned patches, we can expect follow-up changes to build on this viewport adjustment with more comprehensive mobile support. The commit message does an excellent job explaining both the problem and solution, suggesting this will be a well-structured series.
