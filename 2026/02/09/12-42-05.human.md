Test infrastructure patch from Patrick Steinhardt improving ICONV prerequisite handling in t4205 (log formatting tests). This is part of a series addressing CI failures on Windows/MSVC where tests incorrectly assume the `iconv(1)` executable is available when Git's ICONV support is enabled.

The patch restructures t4205's test setup to be more robust when ICONV isn't available. It makes the test encoding conditional - using ISO-8859-1 when ICONV is available, falling back to UTF-8 otherwise. This allows removing the ICONV prerequisite from many tests that don't actually need character re-encoding, while still maintaining test coverage.

The changes are careful to preserve the test's original intent while making it more portable. The patch demonstrates Patrick's characteristic attention to test infrastructure details, particularly around cross-platform compatibility. This continues his ongoing work to improve Git's test reliability across different environments.
