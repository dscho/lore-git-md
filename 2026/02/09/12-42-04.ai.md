Test infrastructure fix addressing ICONV-related test failures on Windows/MSVC platforms. This is the first patch in a 4-part series from Patrick Steinhardt that corrects test scripts which incorrectly assume the presence of the `iconv(1)` executable when Git's ICONV support is enabled.

The patch modifies three submodule-related test scripts (t4041, t4059, t4060) that use `iconv` to convert commit message encodings. Currently these tests check for ICONV support but still attempt to use the `iconv` executable even when the prerequisite fails. The changes make the tests properly skip the `iconv` call when ICONV support isn't available, which both fixes Windows/MSVC CI failures and makes the tests more correct - when ICONV is unavailable, the tests would only be converting UTF-8 to UTF-8 anyway.

The patch takes a pragmatic approach rather than introducing a separate ICONV_EXECUTABLE prerequisite, as Patrick notes this would require more extensive test changes for minimal benefit. The changes are mechanical but thorough, restructuring the message handling in each test to properly respect the ICONV prerequisite. This continues Patrick's ongoing work to improve test reliability across different platforms.
