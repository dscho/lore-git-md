This is part 3/5 of a series improving Gitweb's mobile responsiveness. The series adds mobile-specific CSS rules to make Gitweb usable on small screens while preserving the desktop layout.

Patch 3 specifically addresses horizontal overflow issues in log, commit, blob, and diff views. The changes include:
- Adding horizontal scrolling for preformatted content (like diffs) rather than forcing page-wide overflow
- Reducing padding in log/commit sections to better use screen space
- Ensuring headers and search content stay within the viewport
- Adding touch-friendly scrolling behavior with `-webkit-overflow-scrolling`

The implementation uses a shared media query targeting screens <=768px wide, keeping these changes scoped to mobile viewports. The patch is focused and well-contained, touching only the CSS file with clear before/after behavior described in the commit message. This continues the series' theme of incremental, compatibility-preserving improvements to Gitweb's mobile experience.
