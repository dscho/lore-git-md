This is a CI/build system patch series from Patrick Steinhardt addressing several issues in GitLab CI testing infrastructure. The 5-patch series focuses on improving test execution and failure handling, particularly for MSVC+Windows environments.

The key changes include fixing test slicing logic that was skipping the first test case due to index miscalculation, standardizing Meson test execution between GitLab and GitHub CI to use the same script, and adding better failure handling to surface test errors and artifacts when tests fail. The series also demonstrates Patrick's characteristic attention to consistency across platforms - he notes that some test failures visible in the demo are actually fixed in a separate series.

The changes touch CI configuration files (.github/workflows/main.yml, .gitlab-ci.yml), test helper scripts (ci/run-test-slice*.sh), and test infrastructure code (t/helper/test-path-utils.c). While the immediate motivation was debugging difficulties with MSVC+Windows test failures, the improvements benefit the broader CI pipeline by making test execution more reliable and failures more debuggable across all platforms.
