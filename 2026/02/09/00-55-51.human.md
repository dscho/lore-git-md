This is an update on the SHA-1/SHA-256 interoperability effort, part of Git's ongoing Rustification work. Maintainer Junio C Hamano confirms he has updated the integration branch with brian m. carlson's v3 patch series, which fixes CI breakages from the previous version. The series adds Rust infrastructure for mapping objects between different hash algorithms, including wrappers for hashfile code, a new binary object map format, and hash algorithm abstractions.

The v3 iteration appears to be a straightforward update addressing build issues, with no significant technical changes from v2. Junio notes that while v1 generated substantial discussion, v2 was relatively quiet, suggesting the technical approach may have stabilized. The series remains focused on the long-term goal of enabling repositories with different hash algorithms to interoperate, though platform compatibility challenges (particularly around Rust support on some systems) continue to be a consideration. This work represents an incremental step in Git's gradual adoption of Rust for core object storage components.
