Thread summary:

Bug report regarding `git send-email`'s suppression options (`--suppress-to`, `--suppress-cc`, `--no-to`, `--no-cc`). Jim Cromie identified that these options are incorrectly passed through to `format-patch` instead of being handled by `send-email` itself, causing fatal errors. The issue affects all variants of recipient suppression flags, preventing users from properly controlling automatic recipient additions when sending patches via email. The problem manifests as a clear option processing bug rather than a design flaw, with broken behavior demonstrated through command-line examples showing failed invocations. Impact is limited to users needing precise control over email recipient lists during patch submission. No proposed fix yet, but the bug report provides clear reproduction steps and error outputs.
