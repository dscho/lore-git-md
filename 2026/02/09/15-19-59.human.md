This is a build system patch addressing a dependency tracking issue in the Meson build configuration.

D. Ben Knoble fixes a problem where the `config-list.h` header (which contains Git's configuration options) could become stale when documentation changes, since the Meson build wasn't properly tracking dependencies on the AsciiDoc source files. The issue manifested in test failures when new configuration options were added but the header wasn't regenerated.

The solution introduces a new `generate-configlist-deps.sh` script that explicitly lists all documentation files affecting the config list generation. This output is then used by Meson to properly track dependencies. The v2 patch corrects a minor oversight from v1 where the script filename was referenced without its `.sh` extension.

The change is straightforward and well-motivated by a concrete test failure case. Knoble notes he considered alternative approaches but opted for this explicit solution that follows Meson's patterns. The patch appears ready for merging as it cleanly solves the build system issue without introducing complexity.
