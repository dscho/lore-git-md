This is the fourth patch in Patrick Steinhardt's series improving CI/build system reliability, specifically targeting test execution across platforms. The patch aligns GitLab CI's Meson test execution with GitHub's by using the shared `ci/run-test-slice-meson.sh` script rather than open-coding the parameters.

The change ensures both CI systems use identical Meson options and test slicing logic, continuing the series' theme of cross-platform consistency. The modification to `.gitlab-ci.yml` replaces direct Meson invocation with a call to the standardized script, passing the same one-based slice parameters established in earlier patches. This completes the unification of test slicing behavior between GitHub and GitLab CI for Meson builds.

The patch is small and focused, touching only the GitLab CI configuration to adopt the shared infrastructure. It follows naturally from the previous standardization work and demonstrates Patrick's systematic approach to CI improvements - first establishing consistent behavior in the helper scripts, then propagating that consistency to all CI systems. The change should make test failures more debuggable by ensuring identical test execution paths across platforms.
