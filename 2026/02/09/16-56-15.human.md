This is the final patch in Patrick Steinhardt's 5-part series improving CI reliability, specifically targeting the MSVC+Meson test job on GitLab CI. The patch is a bugfix that adds proper failure handling for tests run in this configuration.

The patch ensures that when tests fail in the MSVC+Meson environment, the CI job will now:
1. Print details of failed tests (using the existing `ci/print-test-failures.sh` script)
2. Preserve test artifacts for debugging by moving them to a standard location
3. Make these artifacts available in the CI interface when the job fails

This brings the MSVC+Meson job's failure handling in line with what GitHub Actions already does, making test failures easier to diagnose. The changes are focused on the GitLab CI configuration file (`.gitlab-ci.yml`), adding new steps to the job's lifecycle while maintaining the existing parallel test execution via `ci/run-test-slice-meson.sh`.

The patch completes the series' goal of making CI test results more reliable and debuggable across platforms, with this final piece addressing a gap in the Windows/Meson test reporting pipeline. As with the rest of the series, the changes are methodical and well-contained, demonstrating Patrick's attention to infrastructure details.
