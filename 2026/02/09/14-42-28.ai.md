This is the final patch in a series adding macOS support for TRACE2 process ancestry tracing while refactoring the Windows implementation. The patch maintains backward compatibility by continuing to emit the Windows ancestry data in both the original JSON format and the new unified `trace2_cmd_ancestry()` interface introduced earlier in the series.

Derrick Stolee's review confirms the dual-emission approach is the right strategy for maintaining compatibility with existing tools that parse the JSON format. He suggests planning to remove the JSON fallback after two major versions, giving consumers time to migrate to the new interface. This follows the pattern established in earlier patches where the Windows implementation was refactored to separate data collection from formatting.

The patch completes the cross-platform unification of process ancestry tracing, with all platforms now using the same event format while preserving backward compatibility where needed. Stolee's review indicates the technical approach is sound and the series appears ready for merging, with only a minor future cleanup (removing JSON support) noted as follow-up work.
