This is part 3 of an 11-patch series enhancing repository path reporting in Git. The series introduces structured path reporting through a new `git repo info` command, replacing shell-outs to `git rev-parse`.

Patch 3 adds a `--path-format` option to control whether paths are output as absolute or relative. The option is wired through the `repo_info` context structure and affects all path-related fields consistently. The implementation handles both formats by either using `strbuf_add_absolute_path()` or computing relative paths from the current working directory.

The change aligns with the series' goal of providing stable, script-friendly path reporting while maintaining consistency with existing `rev-parse` behavior. The patch appears well-contained, adding the new option while keeping path resolution centralized in `repo_info_add_path()`. It builds on the context-aware approach established in earlier patches of the series.

This continues the series' focus on path reporting after structural metrics were split out to a separate effort. The implementation looks straightforward and maintains the series' clean separation of concerns.
