This is part 1 of a 5-patch series implementing configurable cover letter formatting for `git format-patch`. The series is now in its fifth iteration and appears ready for merging, having addressed all feedback.

The current patch adds two new placeholders to `pretty.c` for use in formatted output: `%(count)` and `%(total)`. These are designed specifically for numbering patches in cover letters, with `%(count)` showing the current patch number (zero-padded to match the total width) and `%(total)` showing the total number of patches. The implementation includes validation to ensure these placeholders can only be used with commands that provide the necessary revision context (like `format-patch`).

The patch follows Jeff King's (Peff) design for the numbering scheme and includes proper error handling when used in unsupported contexts. This is a foundational piece for the larger cover letter formatting feature, which will allow customization of cover letter content through both command-line options and configuration settings.

The implementation looks clean and focused, with clear error messages and proper integration with the existing pretty-printing infrastructure. As the first in the series that's already gone through multiple rounds of review, this appears to be a well-vetted change that's ready for inclusion.
