Feature patch (part of cover letter formatting series) that refactors shortlog generation for cover letters into a dedicated function. This is the second of five patches implementing configurable cover letter formatting.

The patch extracts the shortlog generation code from `make_cover_letter()` into a new `generate_shortlog_cover_letter()` function in `builtin/log.c`. This is a pure refactoring with no behavior change, preparing for subsequent patches that will introduce customizable formatting options. The new function maintains all existing shortlog behavior including line wrapping, indentation, and author grouping.

Key technical details:
- Preserves the same shortlog configuration (MAIL_DEFAULT_WRAP, 2/4 indent levels)
- Keeps the same output destination (rev->diffopt.file)
- Maintains author grouping (SHORTLOG_GROUP_AUTHOR)
- Moves the shortlog initialization and cleanup into the new function
- The function signature includes all needed parameters (log struct, rev_info, commit list and count)

This is a straightforward preparatory change that modularizes the code before introducing the more complex formatting system in later patches. The thread context shows this series has already gone through multiple iterations and received maintainer approval for the overall approach.
