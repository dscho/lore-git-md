This is a test suite improvement patch that fixes a subtle issue with exit code handling in `t/t3700-add.sh`. The author, Siddharth Shrimali, identifies that several test cases pipe `git ls-files` output directly into `grep`, which suppresses `git ls-files`'s exit code. This means test failures from `git ls-files` itself (like crashes) would go undetected.

The patch changes these cases to first redirect `git ls-files` output to a file, then run `grep` on that file. This preserves the exit code from `git ls-files` while maintaining the same test assertions. The changes are mechanical but thorough - the patch updates 15 test cases across the file to use this more robust pattern.

The motivation is clear: this makes the test suite more reliable by ensuring it catches failures in the plumbing commands being tested, not just in the grep assertions. The changes are straightforward and don't affect test semantics - they just make the failure modes more precise. The patch follows Git's test suite conventions and appears to be a clean, focused improvement.
