This is a feature patch adding configurable cover letter formatting to `git format-patch`, part of an ongoing series that has evolved through multiple iterations with maintainer input. The patch introduces a new `--cover-letter-format` option that allows custom formatting of the commit list in cover letters, complementing the existing shortlog-based output.

The implementation adds a new `generate_commit_list_cover()` function that processes a format string (prefixed with "log:") through `repo_format_commit_message()`, enabling per-commit formatting with access to patch numbering placeholders `%(count)` and `%(total)`. The core change integrates this with the existing cover letter generation in `make_cover_letter()`, which now accepts the format string and dispatches to either the new formatter or the traditional shortlog output.

Key technical elements include:
- New format string processing with "log:" prefix handling
- Integration with the revision context for numbering placeholders
- Preservation of existing shortlog behavior via explicit "shortlog" keyword
- Comprehensive test coverage in t4014 verifying:
  * Custom format string behavior
  * Numbering placeholder functionality
  * Shortlog fallback
  * Default behavior compatibility

The patch builds on prior work in the series that established the numbering placeholder infrastructure in `pretty.c` and refactored shortlog generation. It maintains backward compatibility while providing new flexibility in cover letter presentation. The implementation follows the maintainer-approved architecture with a single validation point and modular component design.
