This is a UI improvement patch for gitk, the Git repository browser. The patch adds a "Links" color option to gitk's Preferences dialog, allowing users to customize the color of hyperlinks in the interface. This addresses a specific usability issue for dark theme users where default link colors may not provide sufficient contrast.

The change follows gitk's existing pattern for color configuration, modifying the Tcl/Tk code that handles the color preferences page. Maintainer Johannes Sixt (Hannes) has reviewed the patch and suggested minor wording improvements - changing "Link color" to "Links" for better dialog phrasing and adjusting the commit message to use imperative mood. 

Junio C Hamano chimes in with a meta-comment about potentially documenting these style guidelines more prominently for new contributors, though this isn't directly about the patch itself. The technical implementation appears sound, with proper handling of the color variable serialization. 

This is a small, focused change (10 lines net) that maintains consistency with gitk's existing UI while solving a real usability pain point. With Hannes' approval and the straightforward nature of the changes, this patch appears ready for inclusion.
