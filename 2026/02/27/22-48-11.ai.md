This is the first patch in a 5-part series implementing configurable cover letter formatting for `git format-patch`. The series is now in its fifth iteration and has maintainer approval for merging.

The patch adds two new placeholders to `pretty.c` for use in formatted output:
- `%(count)` - zero-padded patch number (width matches total patch count)
- `%(total)` - total number of patches in series

These placeholders are specifically designed for use in cover letter formatting, and the implementation enforces this by requiring a `rev_info` context (which only exists during patch generation). The error message makes it clear these can't be used with other commands. The zero-padding of `%(count)` follows Jeff King's design to maintain consistent numbering width across the patch series.

The implementation is straightforward C code that:
1. Checks for the new placeholders
2. Validates the required context exists
3. Formats the numbers appropriately (with zero-padding for count)
4. Returns the correct parse length

This is a key building block for the rest of the series, which will build on these placeholders to provide flexible cover letter formatting through both command-line and configuration options. The patch has already gone through multiple rounds of review and addresses all technical requirements identified during the RFC phase.
