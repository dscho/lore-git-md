This is the final cover letter for a feature patch series that adds configurable cover letter formatting to `git format-patch`. The series is now complete with all technical components implemented and tested, awaiting only a documentation update to demonstrate the new `%(count)` and `%(total)` placeholders before merging.

The four patches provide:
1. Core placeholders in `pretty.c` for patch numbering (`%(count)` and `%(total)`)
2. Refactored cover letter summary generation
3. New `--cover-letter-format` option
4. Matching `format.commitListFormat` config option

The implementation handles both CLI and config-based formatting, with special handling for the "shortlog" format. The placeholders are contextually validated to work only in cover letters. Testing in `t4014-format-patch.sh` covers all major cases including backward compatibility.
