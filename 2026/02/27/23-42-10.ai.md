This is part 2 of a 5-patch series refactoring Git's oidmap cleanup API. The patch converts `builtin/rev-list.c` to use the new `oidmap_clear_with_free()` function introduced in the first patch, specifically for the `missing_objects` map.

The change moves the cleanup logic for `missing_objects_map_entry` structures into a dedicated callback function `free_missing_objects_entry()`. Previously, the code manually freed the path strings before calling `oidmap_clear()`. Now the cleanup is handled through the callback, making the memory management more explicit and type-safe.

The patch demonstrates the series' goal of replacing implicit cleanup (via a boolean flag in `oidmap_clear()`) with explicit callback-based cleanup. This particular conversion is straightforward since it involves a simple structure containing a dynamically allocated string. The change maintains identical behavior while improving code organization.
