This is a documentation patch completing a series that adds configurable cover letter formatting to `git format-patch`. The series has gone through four iterations and received maintainer approval, with this final addition documenting the new `--cover-letter-format` option and corresponding `format.commitListFormat` config setting.

The patch adds clear documentation for both the command-line option and config variable, showing how users can customize the commit list format in cover letters. It explains the format accepts either "shortlog" (the default) or a custom format string prefixed with "log:". The examples demonstrate practical usage, like `log: %s (%an)` to show commit subjects with author names.

This wraps up the feature by providing the necessary user-facing documentation after the implementation was completed in earlier patches. The series has addressed all technical requirements and review feedback, including Junio C Hamano's request for proper documentation. The implementation allows both CLI and config-based control over cover letter formatting while maintaining backward compatibility with the existing shortlog output.
