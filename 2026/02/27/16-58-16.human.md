This is a GSoC draft proposal (v5) from Tian Yuchen, continuing the effort to reduce Git's global state as part of the ongoing `the_repository` removal project. The proposal has evolved through community feedback, now incorporating technical corrections from Phillip Wood about configuration parsing behavior and lifecycle management.

Tian's proposal focuses on systematically converting functions that rely on global variables (like environment and config settings) to instead use explicit `struct repository*` parameters. The work addresses concrete problems in library contexts - thread safety, memory leaks in repeated invocations, and testing difficulties. The latest iteration distinguishes between startup-parsed config (like `editor_program` that must fail fast) and lazily-loaded settings (handled via `struct repo_settings`), reflecting Phillip Wood's review feedback.
