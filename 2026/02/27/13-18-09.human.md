This is the first patch in a 4-part series implementing configurable cover letter formatting for `git format-patch`. The series has already gone through several iterations and is now in its final form, with all technical components complete and maintainer-approved.

The current patch adds two new formatting placeholders to `pretty.c`: `%(count)` (the current patch number) and `%(total)` (total number of patches in series). These are specifically designed for use in cover letters, with strict validation ensuring they can't be used in other contexts (which would trigger an error). The implementation handles zero-padding of numbers to match the width needed for the total patch count.

This is a well-crafted foundational piece for the rest of the series, with clear error handling and proper integration with the existing pretty-printing infrastructure. The patch has already been reviewed and approved by Jeff King (Peff), who designed the numbering approach, and maintainer Junio Hamano has signed off on the overall architecture. The implementation is production-ready with comprehensive test coverage in later patches.
