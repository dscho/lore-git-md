This is the first patch in a 4-part series implementing configurable cover letter formatting for `git format-patch`. The series has already gone through several iterations and is now in its final form, with all technical components complete and maintainer-approved.

The current patch adds two new formatting placeholders to `pretty.c`: `%(count)` and `%(total)`. These are designed specifically for use in cover letters to show patch numbering (e.g., "1/4" style numbering). The implementation includes strict context validation - the placeholders will error out if used outside of a `rev_info` context (which is only available in `format-patch`). The `%(count)` placeholder is zero-padded to match the width of the total number of patches, while `%(total)` simply shows the count.

This is a foundational piece for the larger feature that allows custom formatting of cover letters. The implementation follows Peff's design for the numbering scheme and has been reviewed as part of the complete series. The patch includes appropriate error handling and maintains backward compatibility with existing behavior.

The series as a whole addresses a long-standing limitation where cover letter formatting was hardcoded, and this patch provides the core numbering mechanism that the subsequent patches will build upon to enable full customization. The thread context shows the maintainer has approved the approach despite initial concerns about complexity, and all outstanding documentation gaps have been addressed in later patches of the series.
