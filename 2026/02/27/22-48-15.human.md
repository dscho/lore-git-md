This is the final documentation patch in a series implementing configurable cover letter formatting for `git format-patch`. The patch adds comprehensive documentation for the new `--cover-letter-format` option and its corresponding `format.commitListFormat` config setting.

The documentation explains that users can now customize how commit lists appear in cover letters, with two main choices: the traditional shortlog format (default) or a custom format string prefixed with "log:". The format strings support standard placeholders like `%s` for subject and `%an` for author name, plus new `%(count)` and `%(total)` placeholders for patch numbering.

The patch follows the project's documentation conventions, adding clear entries to both the config and command man pages. It shows the feature is production-ready, with all design decisions resolved through five iterations of review. The implementation has maintainer approval from Junio C Hamano and incorporates Jeff King's numbering scheme design.
