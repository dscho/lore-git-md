This is a refactoring patch in a series implementing configurable cover letter formatting for `git format-patch`. It's the second of four patches in the v4 iteration.

The patch moves the shortlog summary generation code from `make_cover_letter()` into a new standalone function `generate_shortlog_cover_letter()`. This is a preparatory change for later patches in the series that will allow users to customize the commit list format in cover letters through both command-line options and configuration settings. The actual behavior remains unchanged - this is purely an internal reorganization to make the code more modular.

The change is mechanical and well-contained, touching only `builtin/log.c`. The author (Mirko Faina) has clearly structured this as part of a larger effort that has already gone through several iterations of review, with the overall design approved by both Jeff King (Peff) and Junio Hamano. The patch follows the project's style guidelines and includes a clear commit message explaining the change's purpose in the context of the series.
