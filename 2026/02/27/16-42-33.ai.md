This is a documentation patch completing a feature series that adds configurable cover letter formatting to `git format-patch`. The patch adds documentation for the new `--cover-letter-format` command-line option and its corresponding `format.commitListFormat` configuration variable.

The documentation explains that users can now specify either "shortlog" (the default) or a custom format string prefixed with "log:" to control how commit lists appear in cover letters. The format string supports placeholders like `%s` for subject and `%an` for author name. The config option provides the same functionality but can be set persistently.

This patch was the final missing piece in a series that has already gone through multiple iterations and received maintainer approval. The implementation (covered in previous patches) handles format validation, maintains backward compatibility with existing shortlog output, and properly manages configuration precedence (CLI overrides config). The documentation follows the project's standard format and includes both command-line and config-file examples.

The patch is straightforward and uncontroversial, matching the implementation that was already approved. It completes the feature by providing the user-facing documentation that was requested during review.
