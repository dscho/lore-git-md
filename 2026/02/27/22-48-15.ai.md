This is the final documentation patch in a series implementing configurable cover letter formatting for `git format-patch`. The patch adds comprehensive documentation for both the new `--cover-letter-format` command-line option and its corresponding `format.commitListFormat` config setting.

The documentation explains that users can now customize how commit lists appear in cover letters, either using the traditional shortlog format or specifying a custom format string prefixed with "log:". It provides examples of format strings and clarifies the relationship between the CLI option and config variable. The patch also updates the configuration examples section to include the new `commitListFormat` setting.

The implementation has gone through five iterations with maintainer approval, and this documentation completes the feature by providing clear usage instructions. The feature maintains backward compatibility while offering new flexibility in cover letter formatting, with the shortlog format remaining the default. The documentation follows Git's standard format and includes both reference-style details and practical examples.
