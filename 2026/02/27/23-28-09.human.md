This is a performance optimization for the option parsing validation patch series. The thread has been discussing René Scharfe's work to detect duplicate long option names in Git's command option tables, which was identified as a bug by Junio Hamano.

Jeff King (Peff) proposes a small but measurable optimization to the validation code - using the return value from `strset_add()` to check for duplicates rather than making a separate `strset_contains()` call. This shaves about 1% off the benchmark time for option parsing validation, which Junio agrees is both a correct and worthwhile change despite the modest improvement.

The change is straightforward and uncontroversial, building on the already-reviewed validation infrastructure. It demonstrates the kind of micro-optimization that experienced contributors like Peff regularly provide during code review. The patch series appears ready for merging with this tweak incorporated.
