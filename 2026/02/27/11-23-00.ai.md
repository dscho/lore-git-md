Performance optimization series targeting `git-upload-pack` lock contention, part 1/2. This first patch removes a leftover debug statement that was inadvertently being sent to clients during packfile transfers. The "flushed." message has been present since 2006 but was likely never intended to be visible to end users, as demonstrated by the reproduction showing the message appearing in clone output. The change is straightforward - just removing the `fprintf(stderr)` call - but serves as cleanup before the more substantial performance optimization in the next patch. Patrick Steinhardt's commit message provides clear context about the issue's history and impact.
