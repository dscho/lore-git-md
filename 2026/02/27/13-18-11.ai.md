This is a feature patch adding configurable cover letter formatting to `git format-patch`. It's the third in a four-part series that has already gone through several iterations of review and refinement.

The patch introduces a new `--cover-letter-format` option that accepts either "shortlog" (the current default behavior) or a custom format string prefixed with "log:". The format string can use placeholders like `%(count)` and `%(total)` to show patch position within the series, along with other commit metadata. For example, `log:[%(count)/%(total)] %s (%an)` would produce output like `[1/3] Commit subject (Author Name)`.

The implementation adds a new `generate_commit_list_cover()` function that handles the custom formatting, while preserving the existing shortlog generation via `generate_shortlog_cover_letter()`. The changes include thorough test coverage verifying the new formatting options, backward compatibility with the shortlog format, and proper handling of edge cases.

This builds on the foundation established in earlier patches of the series, which added the core formatting infrastructure and placeholders. The implementation has been reviewed and approved by key contributors including Jeff King (Peff), with Junio C Hamano confirming the documentation now addresses previous gaps. The series appears ready for merging, having addressed all technical requirements through multiple iterations.
