This is a feature patch series from Eslam Reda Ragheb, now in its fifth iteration, focused on enhancing `git repo info` with structured path reporting capabilities. The series has been narrowed down from its previous versions to concentrate solely on path-related improvements, separating out structural metrics work that will be handled in a different series.

The key additions in this version are:
- Category-aware key expansion (e.g. requesting "layout" expands to all layout.* keys)
- New path-oriented keys (path.*) exposing repository locations
- A --path-format option to control absolute vs relative path output
- Comprehensive test coverage in t1900
- Updated documentation

The changes since v4 include dropping all structural metrics code to keep this series focused, while preserving the path-related functionality. The implementation introduces explicit info-context plumbing and maintains backward compatibility.

Technical details of note:
- 13 path fields are exposed through the new interface
- Path format control via enum (absolute/relative)
- New helper functions for output formatting
- Test infrastructure with verification helpers
- Documentation covering usage and fields
