This is the final patch in a feature series adding configurable cover letter formatting to `git format-patch`. The patch introduces a `format.commitListFormat` configuration option that allows users to specify a default format for the commit list in cover letters, rather than always requiring the `--cover-letter-format` command-line option.

The config option supports several behaviors: when set to "shortlog" it maintains backward compatibility with the existing shortlog format; when set to an empty value it defaults to "[%(count)/%(total)] %s"; and when given a custom format string it applies that format (without requiring the "log:" prefix used on the command line). The implementation includes thorough test coverage for all these cases.

This completes the RFC-to-feature journey that has spanned four patch versions, with the maintainer (Junio C Hamano) having approved the architecture and Jeff King (Peff) contributing the numbering approach design. The series is now production-ready with comprehensive documentation and validation in place.
