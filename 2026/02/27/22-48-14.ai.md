This is the fourth patch in a five-part series implementing configurable cover letter formatting for `git format-patch`. The series has gone through five iterations and is now in final form, ready for merging.

The current patch adds a `format.commitListFormat` config option that allows users to specify the format for commit lists in cover letters through Git configuration, rather than always requiring the `--cover-letter-format` command-line option. The config option supports three modes:
1. When set but empty, defaults to "[%(count)/%(total)] %s"
2. When set to a format string prefixed with "log:" (e.g. "log:%s (%an)")
3. When unset, falls back to the traditional shortlog format

The implementation includes proper memory management for the config value and comprehensive test coverage in t4014-format-patch.sh, verifying all three modes plus edge cases like empty config values and the "shortlog" keyword. The patch maintains backward compatibility while providing the new configuration capability.

This is part of a larger effort to make cover letter formatting more flexible and user-configurable.
