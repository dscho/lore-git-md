This is a feature patch introducing automatic branch name prefixing via a new `branch.addCurrentBranchAsPrefix` config option. When enabled, creating a new branch (via `git branch`, `git checkout -b`, or `git switch -c`) will prefix the new branch name with the current branch name (e.g., creating "test" while on "main" produces "main-test"). The feature supports recursive prefixing (creating "main-test-sub" when on "main-test").

The implementation adds a new `add_branch_prefix()` helper in branch.c that handles the prefix logic, with comprehensive test coverage across all three affected commands. The commit message cites backport workflows across many branches as the motivating use case, though this rationale hasn't been discussed by other list participants yet.

Notable technical details for future reference:
- Config key: `branch.addCurrentBranchAsPrefix` (default false)
- Affected commands: `branch`, `checkout -b/-B`, `switch -c/-C`
- Recursive prefixing behavior preserved from v1
- New test cases in t2018-checkout-branch.sh, t2060-switch.sh, t3200-branch.sh
- Helper function: `add_branch_prefix()` in branch.c
