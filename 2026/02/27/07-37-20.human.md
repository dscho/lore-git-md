This is a feature patch for gitk, the Git repository browser, adding configurable link colors to improve readability in dark themes. The patch follows up on Wang Zichong's initial submission, with Johannes Sixt (gitk's maintainer) providing minor style suggestions while accepting the core idea.

The change allows users to set link colors through gitk's Preferences dialog, addressing a specific pain point for dark theme users where default link colors may not provide sufficient contrast. Sixt suggests tweaking the UI text from "link color" to "links" for better phrasing in the color picker dialog, and proposes a more concise subject line for the commit.

The patch is small and focused, touching only gitk's Tcl/Tk UI code in the color preferences handling. Since gitk is maintained separately from core Git, this change would be routed through Sixt rather than the main Git maintainer. The discussion indicates the patch is technically sound and likely to be accepted with the suggested wording improvements.
