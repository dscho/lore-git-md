Feature patch series finalizing configurable cover letter formatting for `git format-patch`. This fifth iteration reconciles the command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options after extensive review process, with all technical and documentation requirements now addressed.

The series introduces a flexible system for customizing cover letter generation, allowing users to specify format strings with placeholders like `%s` for subject and `%an` for author name. Special handling maintains backward compatibility with the traditional shortlog format while enabling richer alternatives. The implementation includes proper memory management, contextual validation of placeholders, and a clear precedence order between CLI and config options.

Key technical points resolved in this version include the unified requirement for a "log:" prefix on all non-shortlog formats (both CLI and config) and Jeff King's numbering scheme using `%(count)` and `%(total)` placeholders. The documentation now thoroughly explains both the command-line option and config variable, with examples demonstrating the formatting capabilities.
