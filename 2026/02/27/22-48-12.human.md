This is a refactoring patch that's part of a larger series to implement configurable cover letter formatting in `git format-patch`. 

The patch moves the shortlog summary generation code for cover letters into its own function, `generate_shortlog_cover_letter()`. This is a preparatory change for the rest of the series which will allow users to customize the commit list format through both command-line options and configuration settings. The refactoring maintains all existing behavior while making the code more modular.

The change is straightforward - it extracts the shortlog generation logic from `make_cover_letter()` into a new function with the same parameters and behavior. The patch has been through several iterations (v5) and is part of a well-reviewed series that's now ready for merging. The author, Mirko Faina, has clearly structured this as a clean refactoring with no behavior changes, making it a safe preparatory step for the more substantial formatting changes that follow in the series.
