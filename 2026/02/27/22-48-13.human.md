This is a feature patch adding configurable cover letter formatting to `git format-patch`. It's part 3 of a 5-part series that has gone through multiple iterations and is now ready for merging.

The patch introduces a new `--cover-letter-format` option that allows specifying either "shortlog" (the current default behavior) or a custom format string prefixed with "log:". The custom format can use placeholders like `%(count)` for patch number, `%(total)` for series size, and standard commit formatting options like `%s` for subject and `%an` for author name. For example, it enables output like "[1/3] Commit subject (Author Name)".

The implementation adds a `generate_commit_list_cover()` function to handle the new format, modifies the existing make_cover_letter() to use either this or the traditional shortlog approach, and includes comprehensive tests verifying the new functionality. The changes maintain backward compatibility while providing more flexible cover letter generation.

This patch represents the core functionality of the series, building on earlier groundwork and incorporating feedback from maintainers Jeff King and Junio Hamano. The implementation looks clean and well-tested, with clear documentation of the new feature.
