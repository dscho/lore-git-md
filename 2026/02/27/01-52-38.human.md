This is a feature patch adding configurable cover letter formatting to `git format-patch`. It's part of a series (patch 3/4) that implements alternative ways to format the commit list in cover letters, addressing the limitation that the default shortlog groups commits by author rather than showing them in chronological order.

The patch introduces a new `--cover-letter-format` option that accepts either "shortlog" (the current behavior) or a custom format string prefixed with "log:". The format string can use standard commit formatting placeholders like `%s` (subject) and `%an` (author name), plus new `%(count)` and `%(total)` placeholders for patch numbering. For example, `--cover-letter-format="log:[%(count)/%(total)] %s (%an)"` would produce output like "[1/3] subject (Author Name)".

The implementation adds a new `generate_commit_list_cover()` function that processes the format string for each commit, plus tests verifying the formatting options. The changes maintain backward compatibility - when no format is specified, it falls back to the traditional shortlog output. The patch appears well-structured with clear commit message and thorough test coverage, addressing a real usability pain point in patch series communication.
