Thread identity: Test suite improvement patch fixing exit code handling in t/t3700-add.sh, authored by Siddharth Shrimali.

Core problem: Several test cases in t/t3700-add.sh pipe git ls-files directly into grep, which suppresses git ls-files's exit code. This means test failures from git ls-files itself (like crashes) would go undetected.

Solution: Changed test cases to first redirect git ls-files output to a file, then run grep on that file. This preserves git ls-files's exit code while maintaining the same test assertions. The patch updates 15 test cases across the file to use this more robust pattern.

Technical details: The changes are mechanical but thorough, affecting test assertions but not their semantics. The pattern changes from `git ls-files | grep` to `git ls-files >out && grep out`. This makes the test suite more reliable by ensuring it catches failures in the plumbing commands being tested, not just in the grep assertions.
