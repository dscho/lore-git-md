This is part 3 of an 11-patch series enhancing repository path reporting in Git. The series focuses on providing structured, programmatic access to repository locations through a new interface, replacing shell-outs to `git rev-parse`.

Patch 3/11 introduces a `--path-format` option for `git repo info` that lets callers explicitly request either absolute or relative paths for all path-related output. The option is wired through the existing `repo_info` context structure and affects all path fields (like `path.git-dir`, `path.worktree`, etc.) via centralized handling in `repo_info_add_path()`. 

The implementation adds an enum for path format types and modifies the path resolution logic to honor the requested format. Relative paths are computed using `relative_path()` against the current working directory, while absolute paths continue using `strbuf_add_absolute_path()`. The change maintains backward compatibility by defaulting to absolute paths.

This patch aligns with the series' goal of providing stable, script-friendly path reporting while reducing ad-hoc path conversion in callers. It builds on the context-aware approach established in earlier patches and integrates cleanly with the existing path APIs. The change is part of the broader `the_repository` removal effort and coordinates with (but does not overlap) Justin Tobler's parallel work on structural metrics.

Key technical details include:
- New `PATH_FORMAT_ABSOLUTE`/`PATH_FORMAT_RELATIVE` enum
- `--path-format` option parsing via `parse_path_format_cb()`
- Centralized path formatting in `repo_info_add_path()`
- Default absolute path behavior preserved
- Relative path computation using working directory context
- Integration with existing `repo_info` structure

The patch appears well-contained and follows the series' established patterns. It addresses a clear use case (consistent path formatting for scripts) while maintaining the architectural approach of centralized path handling. The implementation looks straightforward and maintains the separation from structural metrics that was established in the v5 reorganization.
