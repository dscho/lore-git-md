This is a bugfix patch that removes a duplicate option definition in `pack-objects`. It's patch addresses the same underlying issue that Junio identified in the thread about silent duplicate option acceptance, but this is a concrete fix rather than a discussion of the general problem.

The patch removes a redundant `--stdin-packs` option definition in `builtin/pack-objects.c` that was left behind when the option was enhanced to accept an argument in commit cd846bacc7. The old boolean version was shadowing the new callback version but still appeared in the help text, which could confuse users. René Scharfe follows Junio's hint to clean this up.

Key technical details:
- Removes the old `OPT_BOOL` definition of `--stdin-packs` while keeping the newer `OPT_CALLBACK_F` version that handles the argument
- Affects the pack-objects command's option parsing
- Fixes an inconsistency where the help text showed a simpler version of the option than what was actually implemented

This is a straightforward cleanup that aligns with the thread's theme of option parsing correctness, though it doesn't address the general duplicate-detection mechanism Junio proposed. The patch is small, focused, and clearly motivated - exactly the kind of quality cleanup René is known for.
