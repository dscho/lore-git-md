This is a feature patch adding configurable cover letter formatting to `git format-patch`. It's the fourth in a five-part series that's now ready for merging after several iterations.

The patch introduces a new `format.commitListFormat` configuration option that lets users specify how commit lists should appear in cover letters, rather than always requiring command-line flags. The config supports three formats: a default "[%(count)/%(total)] %s" when set but empty, custom formats prefixed with "log:" (like "log:%s (%an)"), and the traditional shortlog format when unset. The implementation handles memory management properly and maintains backward compatibility.

The change integrates with the existing cover letter generation in `builtin/log.c` and includes comprehensive tests verifying all the config behaviors. This builds on earlier patches in the series that established the formatting system and placeholder syntax (like %(count) and %(total)).

The series has gone through five iterations with maintainer approval, particularly from Junio C Hamano and Jeff King (Peff), who designed the numbering approach. The implementation looks solid with thorough test coverage and clear documentation. This is a well-executed addition that gives users more control over cover letter formatting while preserving existing behavior.
