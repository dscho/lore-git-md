This is the second patch in a two-part series introducing automatic branch prefixing, now adding a `--no-prefix` command-line option to complement the config setting from the first patch.

The series proposes a workflow where new branches are automatically prefixed with the current branch name (e.g., creating "test" while on "main" produces "main-test"). This patch adds an escape hatch via `--no-prefix` to override the behavior when needed. The implementation touches `git branch`, `git checkout -b`, and `git switch -c`.
