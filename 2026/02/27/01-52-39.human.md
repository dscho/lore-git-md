This is a feature patch adding configurable commit list formatting for `git format-patch` cover letters. It's the final patch in a series that has evolved through multiple iterations with maintainer input.

The patch introduces a new `format.commitListFormat` configuration option that controls how commits are listed in cover letters. The option accepts either "shortlog" (the current default format) or a custom format string with placeholders like `%(count)` and `%(total)` for patch numbering. The implementation handles several cases:
- When set but empty, defaults to "[%(count)/%(total)] %s"
- When set to "shortlog", uses the traditional format
- When unset, falls back to "shortlog"

The change builds on previous work in the series that added numbering placeholders and refactored shortlog generation. The implementation includes comprehensive tests verifying the various configuration scenarios and format string combinations.

The patch appears well-crafted with clean separation of concerns and maintains backward compatibility. It completes the feature set for customizable cover letter formatting that has been under discussion and review across multiple versions.
