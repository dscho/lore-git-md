Feature patch adding configurable cover letter format to `git format-patch`, part of a completed RFC-to-feature series.

This patch introduces a `--cover-letter-format` option that lets users customize how commit lists appear in cover letters, addressing the limitation of the default shortlog` format which groups by author without clear chronology. The new option accepts either "shortlog" (preserving current behavior) or a "log:"-prefixed format string supporting `%(count)` and `%(total)` placeholders for patch series numbering.

The implementation adds a new `generate_commit_list_cover()` function that processes the formatted commit list, while maintaining backward compatibility through the existing `generate_shortlog_cover_letter()`. The change includes comprehensive tests verifying the new formatting options and their interaction with existing cover letter behavior.

This is the third of four patches in a series that has already addressed all technical feedback, including Junio C Hamano's concerns about numbering complexity and Jeff King's design input. The implementation is production-ready with thorough test coverage in `t4014-format-patch.sh` and maintains the project's standards for backward compatibility. The series as a whole provides a complete solution for configurable cover letter formatting that has progressed from RFC to final implementation.
