The test uses `test_decode_color` to reliably verify the output and exercises the edge case that motivated the series.

The test design is thorough, checking both the successful case (full filename display) and the graceful degradation case (precise trimming when space is constrained). This complements the implementation change in the first patch, which modified `diff.c` to properly skip ANSI sequences when calculating display widths.
