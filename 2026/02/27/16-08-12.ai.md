This is the second patch in a two-part bugfix series addressing incorrect diffstat width calculation when line prefixes contain ANSI color codes. The patch adds test coverage for the fix introduced in the first patch, which modified `diff.c` to properly handle ANSI sequences in prefix width calculations.

The test verifies correct diffstat output when using `git log --graph --stat` with colored graph prefixes, specifically checking that:
1. With sufficient terminal width (MIN_TERM_WIDTH), the full filename appears in the diffstat
2. With one column less (MIN_TERM_WIDTH-1), the filename is properly truncated with an ellipsis

The test setup creates a commit with a placeholder file, then checks the output formatting under different COLUMNS constraints. It uses `test_decode_color` to properly handle the ANSI color sequences in the output verification.

This test complements the first patch's implementation change by demonstrating the fixed behavior in a real-world scenario (colored log graphs) and verifying edge cases around terminal width constraints. The test is added to the existing t4052-stat-output.sh rather than creating a new test file, following feedback from the previous version.
