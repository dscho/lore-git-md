This is a refactoring patch from Karthik Nayak, part of the v9 series implementing reference storage backend selection. The patch extracts duplicate stub-creation code into a new `refs_create_refdir_stubs()` function.

Git requires certain files/directories (HEAD and refs/) to recognize a directory as a repository, which were originally tied to the files backend. Newer backends like reftable store references differently but still need these stubs. The patch consolidates this logic from clone.c and reftable-backend.c into a single helper function in refs.c.

The change is straightforward - it moves existing code with minimal modifications, just parameterizing the refs/heads content message. The patch follows the series' established patterns and has already been reviewed by multiple contributors (including Patrick Steinhardt and Toon Claes) through nine iterations. This is a clean-up step preparing for additional backend work in subsequent patches.
