This is a test refinement patch in the final iteration of the reference backend selection series. Toon Claes points out two test assertion ordering issues where `expect` and `actual` files are swapped in the test comparisons. The tests verify that the `GIT_REFERENCE_BACKEND` environment variable correctly initializes repositories with alternate reference directories.

The patch shows test cases for:
1. Migrating a repository to use an alternate ref directory via environment variable
2. Initializing a new repository with an alternate ref directory
3. Cloning into a repository with an alternate ref directory

The issues are minor test script corrections in the final polishing phase of a larger feature that has already received maintainer approval. The series implements three ways to specify reference backends (config, environment variable, and URI syntax) for zero-downtime migrations between backends like files and reftable. This particular patch focuses on test case validation for the environment variable approach.
