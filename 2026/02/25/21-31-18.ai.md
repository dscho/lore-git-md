This is a refactoring patch in the Linux fsmonitor support series, specifically addressing code deduplication between the macOS and Linux implementations of filesystem monitoring settings checks. The patch merges the nearly identical Unix domain socket compatibility logic from both platforms into a shared `fsm-settings-unix.c` file.

The key technical changes:
- Combines macOS and Linux filesystem checks (remote filesystems, NTFS/FAT32 support) into a single implementation
- Adopts the safer `xstrdup()` + `dirname()` approach from the macOS code to avoid `strbuf` mutation issues
- Maintains the "vfat" filesystem check that was previously Linux-specific
- Updates all three build systems (Makefile, meson, CMake) to use the shared file

Junio Hamano notes this follows the same pattern as the previous patch (05/10) which consolidated the IPC path handling. The changes appear straightforward and build on the established approach of unifying the Unix platform implementations where possible. This continues the series' trend of reducing code duplication while maintaining all necessary platform-specific behavior checks.
