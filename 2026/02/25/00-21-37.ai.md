This is patch 9/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The patch extracts a helper function `repack_fill_midx_stdin_packs()` from `write_midx_included_packs()` to handle the common case of writing pack names to stdin when running `git multi-pack-index write --stdin-packs`.

The new helper encapsulates the process of setting up stdin pipe, starting the command, writing pack names, and finishing the command. This prepares for future changes where the same helper will be reused to capture MIDX checksums from stdout when using `--checksum-only`. The patch is purely a refactoring with no functional changes.

This continues the series' pattern of breaking down complex MIDX operations into reusable components. The change is mechanical and low-risk, touching only the repack-midx.c file. It builds on previous infrastructure patches in the series (particularly patch 8/14 which extracted MIDX command preparation) and will be used by upcoming patches that implement the geometric repacking strategy.
