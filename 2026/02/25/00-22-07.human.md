This is the final patch in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking, now allowing `--write-midx=incremental` to work without requiring `--geometric`. The series builds on previous MIDX compaction work to improve large repository repacking.

The patch removes the previous restriction that forced `--write-midx=incremental` to be used with `--geometric`. Without geometric repacking, the behavior becomes append-only - creating a new MIDX layer for freshly written packs while preserving existing layers unchanged. This is implemented via a new `repack_make_midx_append_plan()` function that builds a simpler plan than the geometric version.

The documentation is updated to clarify the two modes of operation (with and without `--geometric`), and the test suite is adjusted to verify the new append-only behavior rather than enforcing the old restriction. The implementation appears thorough, with careful handling of pack lists and MIDX layer management.

This completes the core functionality of the series, providing both geometric compaction and simple append modes for incremental MIDX repacking. The patch maintains the series' high quality with clear commit messages, comprehensive tests, and careful attention to backward compatibility.
