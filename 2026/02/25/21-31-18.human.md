This is a code refactoring patch that consolidates the Unix platform filesystem monitoring (fsmonitor) settings logic between macOS and Linux implementations. The patch is part of a larger series (v6 06/10) bringing Linux fsmonitor support to parity with existing Windows and macOS backends.

The change merges nearly identical Unix domain socket compatibility checking code from separate macOS and Linux files into a single shared implementation (fsm-settings-unix.c). It adopts the safer memory handling approach from the macOS version while preserving all necessary filesystem checks. The patch updates all three build systems (Makefile, meson.build, CMakeLists.txt) to use this unified file for non-Windows platforms.

Junio Hamano notes this follows the same pattern as the previous patch (05/10) which consolidated Unix domain socket path handling. The implementation appears clean and well-motivated, continuing the series' trend of deduplicating code while maintaining all functionality. This is a straightforward improvement that reduces maintenance overhead for the cross-platform fsmonitor daemon support.
