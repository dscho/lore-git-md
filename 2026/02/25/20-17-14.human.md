This is a test patch for the Linux fsmonitor implementation, part of the ongoing effort to bring filesystem monitoring support to Linux (matching existing Windows and macOS capabilities). The patch adds two key tests:

1. A smoke test that verifies the filesystem actually delivers inotify events to the daemon, skipping the entire test suite if event delivery fails (which can happen on some container/overlayfs setups).

2. A stress test for rapid nested directory creation that exercises race conditions in the daemon's event handling, particularly around EEXIST errors during concurrent directory watch registration.

The patch also includes several reliability improvements to the test infrastructure:
- Adds generous timeouts for daemon operations to prevent CI hangs
- Improves process group cleanup in background test operations
- Makes test cleanup more robust against hung processes

This is the 8th of 10 patches in the v6 series, which has undergone extensive review and testing. The implementation is now stable in Junio's 'seen' branch with all major technical concerns addressed. The test coverage here helps ensure the Linux fsmonitor backend behaves correctly under edge cases that could trigger crashes or hangs in earlier versions.
