This is part of Taylor Blau's RFC patch series introducing incremental MIDX/bitmap-based repacking, building on his prior work with multi-pack-indexes (MIDX). The series aims to improve repacking in large repositories by avoiding periodic all-into-one repacks through geometric repacking of non-MIDX'd packs.

Patch 4/14 introduces a new `--checksum-only` flag for `git multi-pack-index write` and `compact` commands. This flag allows writing a new MIDX layer without immediately updating the MIDX chain file, giving callers more control over when the chain is atomically updated. The patch includes documentation updates, implementation changes to the MIDX writing logic, and new tests verifying the behavior.

The change is well-motivated as preparation for the incremental repacking strategy that will assemble multiple MIDX layers before atomically updating the chain. The implementation is clean and maintains backward compatibility while adding the new capability. Test coverage is thorough, including both positive cases and validation that `--checksum-only` requires `--incremental`.

Given Taylor's expertise in the pack/MIDX subsystem and the preparatory nature of this change, it's likely to be accepted with minimal discussion. The patch follows the project's conventions for command-line interface changes and includes all expected components (man page updates, tests, implementation).
