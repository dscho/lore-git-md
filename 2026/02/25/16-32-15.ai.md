This is a test modernization patch in an ongoing series about the `repo-info` subsystem. The patch improves testability by avoiding NUL characters in test output comparisons, making test failures easier to diagnose.

The change modifies `t1901-repo-structure.sh` to transform NUL-separated output from `git repo structure --format=nul` into the same format used by `--format=keyvalue` before comparing it, rather than comparing raw NUL-containing output. This addresses a practical debugging issue where `test_cmp` would treat files with NULs as binary and not show useful diffs on failure.

The transformation is done via `tr` commands that swap NUL and newline characters for equals signs and newlines, matching the keyvalue format. The same expected output can then be reused for both formats. The patch maintains all test coverage while improving debuggability, following the series' pattern of mechanical improvements focused on maintainability.

This is part of a larger effort (patches 5-7) to modernize test patterns in the repo-info subsystem's test files, implementing suggestions from prior review feedback. The change is straightforward and unlikely to be controversial, as it doesn't modify any functionality - just how the tests verify that functionality.
