This is the final version of Harald Nordgren's feature patch series for configurable branch comparisons in `git status`. After 28 iterations over two months of review, the implementation has been simplified to focus exclusively on `@{upstream}` and `@{push}` comparisons while deferring more complex branch matching scenarios.

The series consists of two patches: a preparatory refactoring of `format_branch_comparison()` in remote.c, followed by the main implementation adding the `status.compareBranches` config option. The option accepts a space-separated list of special refs (`@{upstream}` and `@{push}`) to compare against, with any other values triggering a warning. The default behavior remains equivalent to `@{upstream}` for backward compatibility.

The implementation includes thorough test coverage (337 lines in t6040-tracking-info.sh) and clear documentation of the current limitations. The patch has been reviewed by multiple contributors including Jeff King, who proposed the simplified approach, and has Junio Hamano's confirmation that it is ready for merging. This represents a successful navigation of Git's mailing list workflow by a first-time contributor, with the feature now positioned for inclusion in an upcoming release cycle.
