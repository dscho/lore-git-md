This is patch 7/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The series aims to improve repacking in large repositories through geometric repacking of non-MIDX'd packs while maintaining geometric progression.

This particular patch is a small refactoring that renames `midx_contains_pack_1()` to the more descriptive `midx_layer_contains_pack()` and makes it publicly accessible. The key difference from the existing `midx_contains_pack()` is that this new function checks only a single MIDX layer rather than recursing through the entire chain. This will be used in a later patch to specifically check if a pack belongs to the tip MIDX layer.

The change is straightforward - it just renames the function, exposes it in midx.h, and updates the single call site in `midx_contains_pack()`. As noted in the commit message, there are no functional changes here - this is purely preparatory work for the larger repacking strategy being introduced in the series. The patch appears well-contained and follows the series' pattern of building up infrastructure before introducing new behavior.
