This thread introduces a new `git maintenance list` subcommand proposed by Rémy Léone. The command displays all repositories registered for background maintenance via the `maintenance.repo` config variable, reading from the global config by default but supporting an alternate config file via `--config-file`. 

The implementation is clean and well-tested, using Git's configset API to query repository paths and printing them one per line. The patch includes thorough test coverage for both the default and custom config file cases. This appears to be a straightforward quality-of-life improvement for users managing multiple repositories with background maintenance.
