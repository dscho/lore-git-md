Refactoring patch in Taylor Blau's MIDX/bitmap repacking series. This is patch 6/14 in an RFC proposing incremental MIDX-based repacking strategy for large repositories.

The patch moves ODB source tracking from direct repository access to a new field in the `existing_packs` struct. While functionally equivalent (it still uses the first source in the list), this prepares for two future needs: (1) the incremental MIDX machinery will need to know the source to read existing MIDX data, and (2) potential future support for repacking from alternate object sources. The change touches the repack command implementation and adds the new field to the struct definition.

This is a straightforward preparatory change that follows the pattern of Taylor's prior MIDX work. The implementation is clean and focused, with clear commit message explaining both the mechanical change and its purpose in the larger series. The patch adds the infrastructure needed by subsequent patches while maintaining backward compatibility.
