This is a build system patch that completes the work to ensure `config-list.h` stays synchronized with Git's documentation files that define configuration options. The patch has gone through seven iterations, with v7 now handling all identified cases including the critical edge case where Make builds would fail when config documentation files were removed.

The solution implements proper dependency tracking for both Meson and Makefile builds, with identical behavior between the two systems. Key technical aspects include generating both the header and a depfile with proper path escaping, optimized sed commands for Windows performance, and handling of removed files without build failures. The implementation has been thoroughly reviewed and tested, with contributions from Patrick Steinhardt, Phillip Wood, and SZEDER Gábor.
