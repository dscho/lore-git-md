This is a refactoring patch in the v9 series implementing reference storage backend selection, now approved for integration. The patch cleans up `create_reference_database()` to remove an unexpected side effect where it was modifying the repository's ref storage format.

The key change is removing the redundant `repo_set_ref_storage_format()` call inside `create_reference_database()`, since the format is already set by callers (`git-init` and `git-clone`) before invoking this function. The patch avoids potential future issues with dynamically allocated strings in the format structure and makes the function's behavior more predictable.

This is a straightforward cleanup that follows naturally from the larger ref backend work. The change is mechanical and low-risk, touching only three files with simple signature updates and call site adjustments.
