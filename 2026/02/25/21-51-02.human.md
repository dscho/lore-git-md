Refactoring patch for the configurable branch comparison feature in `git status`. This is the first of two patches in the final version of Harald Nordgren's long-running effort to make branch comparisons configurable via `status.compareBranches`.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. This is purely a code reorganization with no behavior changes, preparing for the second patch that will add support for push remote comparisons. The refactoring makes the code more modular by separating the comparison formatting from the upstream tracking logic.

This represents the culmination of a 28-iteration review process over two months, with the implementation now simplified to focus on @{upstream}/@{push} comparisons while deferring more complex scenarios. The changes are well-contained (82 lines modified in remote.c) and maintain backward compatibility. With maintainer approval confirmed, this series is positioned for merging in the next release cycle.
