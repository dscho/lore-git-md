This is patch 4/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The series builds on his prior MIDX compaction work and aims to improve repacking in large repositories by avoiding periodic all-into-one repacks.

This specific patch adds a `--checksum-only` flag to `git multi-pack-index write/compact` that writes a new MIDX layer without updating the MIDX chain file. This allows callers (like the upcoming incremental repacking strategy) to assemble multiple layers before atomically updating the chain. The flag requires `--incremental` since layers only make sense in that context.

Key technical changes:
- Adds `MIDX_WRITE_CHECKSUM_ONLY` flag constant
- Modifies `write_midx_internal()` to skip chain file updates when flag is set
- Prints the new layer's checksum when flag is set
- Adds tests verifying the new behavior and its interaction with `--incremental`
- Updates documentation for both write and compact subcommands

The patch is well-contained and clearly motivated by the series' overall goal. It follows the pattern of earlier preparatory patches in the series by adding infrastructure piece needed for the core functionality. The test coverage is thorough, checking both successful cases and invalid combinations (like using `--checksum-only` without `--incremental`).

Given Taylor's expertise in the pack/MIDX subsystem and the mechanical nature of this change, it's likely to be accepted with minimal discussion. The only potential point might be whether the flag name clearly conveys its behavior, but the implementation itself looks solid.
