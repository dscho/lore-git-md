This is a refactoring patch in Taylor Blau's RFC series on incremental MIDX/bitmap-based repacking. It converts the `keep_hashes` array in MIDX writing code from a manually managed array to a `strvec`, which provides better memory management and a more ergonomic interface.

The change simplifies the code by eliminating manual memory management of the array that tracks which MIDX files to retain during pruning operations. The patch updates both the MIDX writing logic and cleanup functions to use the new `strvec` approach, reducing the number of parameters needed in several places.

This is a preparatory change for the larger geometric repacking strategy Taylor is proposing. The use of `strvec` makes the subsequent patches cleaner by handling the array management automatically. The patch maintains all existing functionality while making the code more maintainable.

As part of a well-structured series from an experienced contributor in the pack/MIDX subsystem, this change looks straightforward and uncontroversial. It follows the pattern established in earlier patches of the series to modernize the codebase's data structures.
