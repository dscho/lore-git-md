Feature proposal for incremental MIDX/bitmap-based repacking strategy. This is the third and final major component in Taylor Blau's effort to improve repacking in large monorepos, building on previous work to refactor repack code and implement MIDX layer compaction.

The core idea is to replace Git's current geometric repacking approach (which rewrites the entire MIDX and bitmap on each run) with an incremental strategy that:
1. Repacks non-MIDX'd packs geometrically
2. Adds new MIDX layers for fresh packs
3. Compacts adjacent MIDX layers to maintain geometric progression
4. Prunes redundant layers

This aims to significantly reduce repacking overhead in large repositories by avoiding full rewrites while still keeping the MIDX chain efficient. The series includes preparatory refactors, new MIDX write/compact options needed for the strategy, and the core implementation.

The 14-patch series is marked as RFC since it hasn't been thoroughly tested yet and may see significant changes based on feedback. Taylor notes this completes the major work for this effort, with some smaller follow-ups planned around cruft pack handling and bitmap configuration.

Key files touched include the repack and MIDX machinery, with new test scripts added to exercise the functionality. The changes are substantial but build on Taylor's established expertise in the pack/MIDX subsystems.
