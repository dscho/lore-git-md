This is a platform compatibility patch adding Windows support for timed condition variable waits, part of the larger fsmonitor Linux support effort. Paul Tarjan contributes a Windows implementation of `pthread_cond_timedwait()` using the native `SleepConditionVariableCS()` API with millisecond timeout conversion from absolute timespec values.

The implementation handles:
- Timeout calculation from absolute to relative milliseconds
- ETIMEDOUT return when the deadline passes
- Error code translation between Windows and POSIX
- Maintaining the existing pthread compatibility layer conventions

This enables bounded waits on condition variables in the Windows pthread emulation layer, which the fsmonitor daemon will use for its IPC synchronization. The change is straightforward and follows the pattern of other pthread functions in this compatibility layer. As part of a well-reviewed series that's been through six iterations, this patch appears ready for inclusion.
