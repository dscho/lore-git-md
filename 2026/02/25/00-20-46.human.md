This is part 6 of Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking, building on his prior work with multi-pack indexes (MIDX). The patch is a refactoring step that moves the object database (ODB) source tracking from direct repository access to a new field in the `existing_packs` struct.

The change serves two purposes: it prepares for the incremental repacking machinery that will need to know the ODB to read existing MIDX files, and it future-proofs the code for potential support of multiple object sources. The patch touches the repack command implementation and associated helper functions, but makes no functional changes - it just relocates where the ODB source is stored.

As with the rest of this series, this is marked RFC and awaits feedback. Given Taylor's deep expertise in Git's pack subsystem and his track record with MIDX improvements, this foundational change is likely to be uncontroversial. The patch is cleanly separated from the more complex MIDX logic that will follow in later parts of the series.
