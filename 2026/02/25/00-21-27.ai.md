This is patch 7/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The patch renames and exposes a previously internal function that checks if a single MIDX layer contains a given pack, without recursing through the entire MIDX chain like the existing `midx_contains_pack()` does.

The change is straightforward: `midx_contains_pack_1()` becomes the public `midx_layer_contains_pack()`, with the same binary search implementation but now available to other parts of the codebase. This prepares for future use in determining pack membership in specific MIDX layers rather than anywhere in the chain, which will be needed for the geometric repacking strategy.

The patch maintains all existing behavior - it just makes the single-layer check reusable. As with the rest of the series, this is infrastructure work building toward the larger repacking improvements. The change is mechanical and unlikely to be controversial, though reviewers may check that the new public interface is appropriately documented (the header addition is minimal but sufficient for this helper).
