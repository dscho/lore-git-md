This is a test modernization patch in an ongoing series about the `repo-info` subsystem. The patch improves test reliability by avoiding NUL characters in test output comparisons, which can cause `test_cmp` to treat files as binary and obscure differences when tests fail.

The change modifies `t1901-repo-structure.sh` to transform NUL-separated output from `git repo structure --format=nul` into the same format used by `--format=keyvalue` before comparison. This ensures test failures will show readable diffs while still verifying the NUL format's correct behavior. The transformation uses `tr` to swap newlines and NULs for equals signs and newlines used in keyvalue format.

This is a straightforward improvement that follows the series' theme of mechanical test modernization. The patch maintains the same test coverage while making failures easier to diagnose. It's a small but practical change that aligns with the project's emphasis on robust test infrastructure.
