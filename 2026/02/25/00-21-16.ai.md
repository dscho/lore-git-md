Performance patch in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking strategy. This is patch 5/14, adding support for custom base layers in MIDX writes.

The patch introduces a new `--base` option for both `git multi-pack-index write` and `compact` subcommands, allowing callers to specify which existing MIDX layer should be used as the base for new incremental writes. This provides flexibility beyond the current behavior where `compact` always uses the immediate parent of the compacted range and `write` always appends to the tip. The special value "none" can be used to create a root layer with no parent.

For `write`, using `--base` requires `--checksum-only` to maintain chain invariants, since non-checksum-only writes append to the live chain. The patch includes extensive tests verifying the new behavior, including error cases like invalid base checksums. The implementation touches MIDX writing internals, command-line parsing, and documentation.

This is infrastructure work supporting the series' larger goal of improving repacking in large repositories through geometric repacking of non-MIDX'd packs. The ability to specify custom bases will be needed when the repacking machinery determines intermediate layers should be replaced. The patch follows Taylor's established pattern of thorough test coverage and careful consideration of backward compatibility.
