This is the final patch in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking, now allowing `--write-midx=incremental` to work without requiring `--geometric`. The patch completes the series by decoupling these two features that were previously tightly coupled.

The change enables an append-only mode for incremental MIDX repacking where new packs are simply added as fresh layers without any geometric compaction. This provides more flexibility in how repositories can manage their MIDX chains. The implementation introduces a new `repack_make_midx_append_plan()` function that builds a simple plan of WRITE steps for new packs and COPY steps for existing layers, bypassing the geometric compaction logic entirely when `--geometric` isn't specified.

Documentation is updated to clearly explain both modes of operation (with and without geometric repacking), and tests are added to verify the new append-only behavior. The patch removes the previous restriction that required `--geometric` and replaces the test that enforced it with one demonstrating the new functionality.

This appears to be a well-considered addition to the series, providing more flexibility in how the incremental MIDX feature can be used. The implementation is clean and maintains the existing behavior when `--geometric` is used. The test coverage is thorough, verifying both the basic append operation and interaction with existing layers. As the final patch in the series, it completes the feature set while keeping the door open for future optimizations around the geometric compaction strategy.
