This is patch 8/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The patch is a refactoring that extracts common MIDX command preparation logic into a new `repack_prepare_midx_command()` helper function.

The change factors out the shared setup for `git multi-pack-index` commands - setting up the subcommand verb, progress display, and bitmap flags - while leaving subcommand-specific arguments (like `--stdin-packs` for the `write` subcommand) to be handled by callers. This prepares for future patches that will need to construct similar commands for both `write` and `compact` operations.

The patch is purely mechanical with no behavior changes, touching only the repack-midx.c file. It follows the series' pattern of infrastructure preparation before introducing new functionality. The extracted helper will be used by upcoming patches in the series that implement the geometric repacking strategy.

This is building toward the series' goal of improving repacking in large repositories through incremental MIDX updates while maintaining geometric progression of pack layers. The refactoring here is low-risk and unlikely to be controversial, though reviewers may suggest minor style tweaks to the new helper function.
