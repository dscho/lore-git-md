This is patch 11/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The series aims to improve repacking in large repositories through geometric repacking of non-MIDX'd packs while maintaining MIDX layer organization.

This particular patch converts the `--write-midx` flag from a simple boolean option to a callback that can handle multiple modes of MIDX writing. It introduces an enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states, preserving existing behavior when no argument is given while preparing for future incremental MIDX writing modes.

The change is primarily infrastructure work - it refactors how MIDX writing is controlled without yet adding new functionality. The patch:
- Adds a new `option_parse_write_midx()` callback to handle the option parsing
- Updates all boolean checks of `write_midx` to use the new enum values
- Introduces a dispatcher function `repack_write_midx()` that will select between different MIDX-writing implementations
- Maintains backward compatibility with existing `-m` usage

This appears to be solid preparatory work for the incremental MIDX functionality coming in later patches. The changes are mechanical but necessary to support the more complex MIDX writing modes the series will introduce. The patch follows the series' pattern of careful refactoring before adding new features.
