This is a feature patch adding a new subcommand to `git maintenance`. Rémy Léone introduces a `git maintenance list` command that displays all repositories registered for background maintenance via the `maintenance.repo` config variable.

The new subcommand reads from the global config by default but accepts a `--config-file` option to specify an alternate configuration file. The implementation handles both cases by using Git's configset API to query the configured repositories, printing their paths one per line. The patch includes thorough test coverage verifying both the default global config behavior and the custom config file case.

The change is well-contained, touching only the maintenance command's documentation, implementation, and tests. The commit message clearly explains the purpose and behavior of the code is straightforward, and the tests cover the main use cases. This appears to be a useful quality-of-life improvement for users managing multiple repositories with background maintenance.
