This is a refactoring patch in the fsmonitor series, specifically addressing IPC path handling for Unix platforms. 

Paul Tarjan's patch consolidates the nearly identical Unix domain socket path logic between macOS and Linux implementations into a shared `fsm-ipc-unix.c` file. The key changes include moving the worktree NULL check (a BUG guard) from the Linux version into the unified implementation, where it was previously missing from the macOS version. The patch updates all three build systems (Makefile, meson.build, and CMakeLists.txt) to use this new shared file for non-Windows platforms.

The changes are mechanical and focused on code deduplication rather than functional changes, though the added BUG check does improve robustness. This is part of the larger fsmonitor effort to bring Linux support up to parity with existing Windows and macOS implementations, now in its sixth iteration with all major technical concerns addressed. The patch series as a whole has undergone extensive review and is in final form, with this particular change representing a straightforward cleanup of duplicated logic.
