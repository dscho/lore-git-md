This is a test refinement patch in the final stages of the reference backend selection series, which enables zero-downtime migrations between different ref storage formats (files<->reftable). The series has gone through nine iterations and is now approved for inclusion in Git's 'next' branch.

Karthik Nayak responds to Toon Claes' review feedback about test assertion ordering in the final patch of the series. The issue is straightforward: two test cases had their `expect` and `actual` files swapped when comparing Git's configuration output. Karthik acknowledges the mistake and agrees to fix it in the next version.

The patch itself adds support for the `GIT_REFERENCE_BACKEND` environment variable as a third way to specify the reference storage backend, complementing the existing `extensions.refStorage` config option and URI syntax. The test case being corrected verifies that repository initialization and cloning properly respect the environment variable by checking the stored configuration.

This is a minor polish to an otherwise complete and well-reviewed series that has involved contributions from many core developers (Patrick Steinhardt, Junio Hamano, Derrick Stolee, and others). The attention to test detail shows the project's high standards even for final iterations of major features.
