This is part of the ongoing fsmonitor feature series adding Linux support via inotify. The patch focuses on code deduplication between Unix platforms.

Paul Tarjan consolidates the nearly identical Unix domain socket compatibility checking logic from macOS and Linux into a shared implementation. The new unified code handles filesystem checks for remote mounts and unsupported filesystems (NTFS, FAT32, vfat) in a safer way, using `xstrdup()` + `dirname()` rather than modifying a strbuf. The change affects build configurations across Makefile, meson, and CMake.

This is the sixth version of the series, which has undergone extensive review and testing. The patch represents a straightforward cleanup that reduces code duplication while maintaining the same functionality. It's part of a larger effort to bring Linux fsmonitor support to the same level as existing Windows and macOS implementations.
