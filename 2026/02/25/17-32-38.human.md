This is a feature patch adding a new subcommand to `git maintenance`. Rémy Léone proposes adding a `git maintenance list` command that shows all repositories registered for background maintenance via the `maintenance.repo` config variable.

The new subcommand reads from the global config by default but can use a custom config file with `--config-file`. The implementation handles both cases cleanly, returning successfully if no repositories are registered. The patch includes thorough tests verifying the basic listing functionality and the custom config file option.

The change is straightforward and follows the existing pattern of `git maintenance` subcommands. The documentation is clear, the implementation is clean, and the test coverage is good. This seems like a useful quality-of-life improvement for users managing multiple repositories with background maintenance.
