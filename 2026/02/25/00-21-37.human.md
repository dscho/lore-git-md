This is patch 9/14 in Taylor Blau's RFC series introducing incremental MIDX/bitmap-based repacking. The series aims to improve repacking in large repositories through geometric repacking of non-MIDX'd packs while maintaining MIDX layer integrity.

This particular patch is a refactoring that extracts the pack-writing logic from `write_midx_included_packs()` into a new helper function `repack_fill_midx_stdin_packs()`. The new helper handles the stdin-packs workflow (argument setup, command execution, writing pack names to stdin) in a reusable way. This prepares for a future change where the same logic will be used to capture MIDX checksums from stdout when writing with `--checksum-only`.

The change is mechanical and well-contained, touching only `repack-midx.c`. It maintains all existing functionality while making the code more modular. This is typical infrastructure work for the larger series - not particularly exciting on its own, but necessary plumbing for the more substantive changes to follow. The patch follows the series' pattern of careful, incremental refactoring with clear commit messages explaining both the what and the why.
