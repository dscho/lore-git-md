This is the final patch in a 5-part series improving Gitweb's mobile responsiveness. The series adds mobile-specific CSS rules to handle narrow screens (<=768px width), with this patch specifically addressing how project names display in the header.

The change replaces a fixed `height: 25px` with `min-height: 25px` for the page header div, allowing it to expand vertically when long project names wrap to multiple lines on narrow screens. This maintains the same baseline height for single-line titles while accommodating wrapped text. The implementation is minimal (1-line change) and focused, completing the mobile layout improvements started in earlier patches.

The series appears well-structured, with each patch handling a distinct aspect of mobile layout (viewport meta tag, search bar, diff views, footer, and now header). This final piece cleanly addresses a specific edge case where long project names would be truncated or overflow due to the fixed height constraint. The change is low-risk since it only affects mobile views and preserves all existing desktop styling.
