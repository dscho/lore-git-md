This is the final patch in Patrick Steinhardt's v3 series improving the `git history` command's UI. The patch focuses on documentation, specifically clarifying the default behavior of the `--update-refs` option.

The change is straightforward: it adds a single line to the man page stating that `--update-refs` defaults to updating all local branches (`branches`) rather than just HEAD. This completes the series' documentation improvements, which have included renaming options for clarity (`--ref-action` became `--update-refs` in patch 4) and adding the new `--dry-run` flag (patch 3).

The series has evolved through three iterations with all reviewer feedback addressed, and this patch represents the last remaining documentation gap. With this change, the behavior that was previously only visible in the implementation (where branches are updated by default) is now properly documented for users. The patch maintains consistency with the series' goal of making the command's behavior more transparent and user-friendly.
