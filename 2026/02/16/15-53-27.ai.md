This is the first patch in a 5-part series improving Gitweb's mobile responsiveness. It adds a viewport meta tag to `gitweb.perl` to ensure mobile browsers properly scale the page to device width rather than rendering at desktop dimensions. This foundational change enables the subsequent CSS fixes in patches 2-5, which address specific layout issues on narrow screens.

The patch is straightforward - a single line addition setting `width=device-width` and `initial-scale=1`. This matches standard web practices for mobile-friendly sites. The commit message clearly explains the purpose and positions this as prerequisite work for the rest of the series.

As noted in the thread summary, this series has already incorporated feedback from Eric Sunshine about patch organization in v1, and appears technically sound. The viewport tag addition is uncontroversial and unlikely to generate discussion - it's a standard first step for any responsive design effort. The real substance of the mobile improvements comes in the CSS changes that follow.
