This is part 3 of a 9-patch series implementing secure storage for promisor remote fields and dynamic filter combination in Git's partial clone functionality. The series is now in its fourth iteration and has received thorough review from Patrick Steinhardt, Jean-Noël Avila, and Christian Couder, with a bugfix from Jeff King.

Patch 3/9 is a small refactoring that makes the `filter_options` variable in `builtin/clone.c` local to `cmd_clone()` rather than being a static file-level variable. This clarifies ownership of the variable as it will be used more extensively in later patches. The change is straightforward - it moves the variable declaration and passes it as a parameter to `checkout()`, while also ensuring proper cleanup with `list_objects_filter_release()`.

This is a preparatory change for the larger feature work coming in later patches. The patch itself is mechanical and low-risk, maintaining identical behavior while improving code organization. It's part of the broader effort to enhance Git's promisor remote capabilities with secure field storage and dynamic filter selection.
