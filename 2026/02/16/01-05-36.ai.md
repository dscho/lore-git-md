This is a discussion about improving stash diff functionality, following up on a feature request for a dedicated `git stash diff` command. Eric Sunshine points out that the requested functionality already exists via `git stash show -p`, which shows the stash contents as a diff (the documentation refers to it indirectly by mentioning "diff-options"). The exchange highlights a discoverability issue - the current interface requires users to know about the `-p` flag rather than offering an intuitive `diff` subcommand. Eric's response suggests the feature request may be unnecessary since the capability exists, though the thread remains open to discussing whether the alternative syntax would improve usability. The discussion touches on Git's general principle of providing both plumbing and porcelain commands, with this case showing how porcelain could better wrap underlying functionality.
