This is the main implementation patch in a series adding UTF-8 support for Git aliases via config subsections. The patch enables defining aliases with non-ASCII characters (like `[alias "förgrena"] command = branch`) while maintaining backward compatibility with the existing case-insensitive ASCII-only aliases.

The key changes include:
- Adding support for subsection syntax in alias definitions, allowing any characters (including UTF-8) in the alias name
- Keeping the traditional syntax (`[alias] co = checkout`) working as before for backward compatibility
- Updating the help system to properly list and handle subsection aliases
- Using `utf8_strwidth()` for proper column alignment of non-ASCII aliases in command listings
- Adding comprehensive tests covering Swedish, CJK characters, spaces in names, and case sensitivity

The implementation builds on existing config infrastructure and avoids Unicode normalization complexities by doing byte-wise comparison of subsection names. The patch includes thorough documentation updates explaining both syntax forms with clear examples.

This is the third patch in a v5 series that has undergone extensive review, with all known issues (including a shell completion bug fixed in v5) now addressed. The implementation looks solid with good test coverage and maintainer-approved documentation.
