This is the final patch in a 5-part series improving Gitweb's mobile responsiveness. The series adds mobile-specific CSS rules to make the interface more usable on small screens.

The current patch specifically addresses an issue where long project names in the Gitweb header would wrap to multiple lines on narrow screens, but the fixed header height would cause the wrapped text to overflow. The solution is simple but effective: changing `height: 25px` to `min-height: 25px` allows the header to expand vertically when needed while maintaining the same baseline height for single-line titles.

This completes the mobile responsiveness improvements that began with adding a viewport meta tag and included fixes for search bars, diff views, and footer layout. The changes are well-contained (just a one-line CSS modification) and maintain backward compatibility with desktop layouts. The series appears ready for merging, having addressed Eric Sunshine's feedback about patch organization in the v1 submission.
