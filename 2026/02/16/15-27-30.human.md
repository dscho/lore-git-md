Bugfix for `git format-patch` cover letter generation, addressing the `--from` option handling. This is the second version of a patch that ensures the `--from` option is respected in cover letters, not just individual patches in a series.

The patch modifies `builtin/log.c` to check for a configured `from` value before falling back to the default committer info when generating cover letters. The author has incorporated Junio Hamano's feedback from the initial review: renaming the `committer` variable to `from` for clarity, improving the commit message, and adding test coverage. The new test in `t/t4014-format-patch.sh` verifies that the `From:` header in cover letters correctly uses the specified `--from` identity.

This is a straightforward fix that aligns cover letter behavior with the existing patch behavior, addressing an inconsistency that could cause confusion when using alternative sender identities. The changes are well-contained and the test provides good regression protection. With the maintainer's requested improvements now implemented, this appears ready for merging.
