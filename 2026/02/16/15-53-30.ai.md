This is part 4/5 of a series improving Gitweb's mobile responsiveness, specifically addressing footer layout issues. The patch changes the footer from a fixed height to a minimum height and adds a clearfix to properly contain floated elements when text wraps on narrow screens.

The change replaces the static `height: 22px` with `min-height: 22px` in the footer container and introduces a `::after` pseudo-element with `clear: both` to prevent floated content from overflowing. This ensures the footer expands vertically when needed while maintaining the same visual appearance on desktop browsers.

The implementation is straightforward and focused - just 8 lines of CSS changes within the existing mobile media query context established earlier in the series. This follows the pattern seen in previous patches of making targeted adjustments to specific components while preserving desktop behavior. The change addresses a real layout issue that would occur when footer text wraps on mobile devices.
