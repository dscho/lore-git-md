This is a feature request proposing a more user-friendly way to view stash diffs. The author, Pierre Houston, notes that the current method (`git diff 'stash@{0}^' 'stash@{0}'`) is unintuitive and suggests adding a `git stash diff [stashname]` command that would serve as a shorthand, defaulting to the most recent stash.

The request acknowledges that similar suggestions may have been made before but notes the difficulty of searching the mailing list archives thoroughly. The proposal is straightforward and addresses a genuine usability pain point - the current stash diff syntax is indeed cumbersome compared to other Git commands.

This seems like a reasonable quality-of-life improvement that would make Git more approachable. The change would be relatively small in scope, primarily affecting the `git-stash` command. The main questions would be whether this overlaps with existing functionality (like the `!` syntax mentioned) and whether the core team sees value in adding another stash subcommand versus improving documentation of the current method.
