Thread summary:

Feature request for a new `git stash diff [stashname]` command to simplify viewing stash diffs, proposed by Pierre Houston. Currently users must either know to use `git diff 'stash@{0}^' 'stash@{0}'` (understanding stash implementation details) or discover `git stash show -p` (documented indirectly via "diff-options" mention). Eric Sunshine points out the existing `show -p` functionality, suggesting the feature request may be redundant, while acknowledging the discoverability issue. Core discussion now centers on whether adding an explicit `diff` subcommand would improve usability despite the existing capability, touching on Git's porcelain/plumbing design principles. The proposal remains open with key questions: (1) whether the cognitive overhead of learning `show -p` justifies a new command, and (2) if the command should default to most recent stash when no argument given (matching `stash show` behavior). No other participants have weighed in yet.
