This is part 3/5 of a series improving Gitweb's mobile responsiveness, focusing on fixing horizontal overflow in log, commit, blob, and diff views. The patch adds mobile-specific CSS rules (52 new lines) to handle preformatted content and padding adjustments while maintaining desktop layouts.

The key changes include:
- Adding horizontal scrolling (`overflow-x: auto`) for page bodies and title sections with touch-friendly scrolling on iOS
- Setting `min-width: max-content` on preformatted blocks to prevent wrapping while allowing scrolling
- Reducing padding in log/commit views and adjusting diff header layouts
- A global `overflow-wrap: anywhere` safeguard for log bodies to handle unbreakable text tokens

The implementation builds on the media query introduced in part 2/5, addressing specific mobile layout pain points while keeping desktop behavior unchanged. The patch appears well-scoped and follows the series' established pattern of mobile-specific adjustments.
