This is part 6 of a 9-patch series implementing the LOP (Large Object Promisors) effort, which enhances Git's promisor remote functionality. The series is now in its 4th iteration and has been reviewed by Patrick Steinhardt, Christian Couder, and others.

This patch introduces infrastructure to support an 'auto' mode for the `--filter` option. It adds a new `allow_auto_filter` flag to `struct list_objects_filter_options` to control which commands can accept "auto" as a filter spec. The implementation ensures "auto" cannot be combined with other filters and adds proper error handling. A new unit test file is introduced to verify the parsing behavior.

The changes are well-contained, touching only the filter options infrastructure while maintaining backward compatibility. The patch includes comprehensive tests and follows Git's established patterns for filter handling. This is a technical foundation for the subsequent patches that will implement the actual "auto" filter behavior in clone/fetch operations.

The patch has already gone through multiple rounds of review and addresses all feedback from previous iterations. It represents a key piece of the larger LOP effort to improve partial clone capabilities.
