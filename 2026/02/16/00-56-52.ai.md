This is a feature request proposing a more user-friendly interface for viewing stash diffs. The author, Pierre Houston, notes that the current method (`git diff 'stash@{0}^' 'stash@{0}'`) is unintuitive and suggests adding a dedicated `git stash diff [stashname]` command that would default to showing the most recent stash.

The request acknowledges that similar suggestions may have been made before but states the author couldn't find them through mailing list searches. The proposal is straightforward - create a more discoverable and ergonomic way to view stash diffs without requiring users to understand the underlying stash implementation details (the parent commit relationship between stash commits).

This appears to be a well-motivated usability improvement targeting a common workflow pain point. The suggestion aligns with Git's general pattern of providing porcelain commands for common operations that would otherwise require plumbing knowledge. The implementation would likely be simple, just wrapping the existing diff functionality in a more intuitive interface.
