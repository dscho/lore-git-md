This is the first patch in a 5-part series improving Gitweb's mobile responsiveness. The patch adds a basic viewport meta tag to `gitweb.perl` to ensure mobile browsers properly scale the page to device width rather than shrinking desktop-sized layouts. This foundational change enables the subsequent CSS fixes in patches 2-5 that address specific mobile layout issues like search bar overflow and diff view readability.

The change is straightforward - a single line addition that follows standard mobile web practices. As noted in the thread context, this series has already incorporated feedback from Eric Sunshine about patch organization in v2, and appears ready for maintainer consideration. The patch does what it claims without introducing any complexity or side effects for desktop users.
