This is the third patch in Patrick Steinhardt's v2 series improving the `git history` command's UI. The patch replaces the technical `--ref-action=print` option with a more intuitive `--dry-run` flag that prints reference updates in a format suitable for piping to `git update-ref`.

The change addresses usability concerns while maintaining functionality - the dry-run output remains machine-readable for scripting purposes. Kristoffer Haugsbakk noted a typo in the documentation (fixed in the next version) and suggested clarifying wording about HEAD updates, though Patrick prefers to keep the existing description for now since this patch only removes the now-irrelevant `print` option documentation.

The patch builds on earlier work in the series that moved validation checks earlier in execution. Reviewers have approved the approach, with Junio Hamano having previously confirmed the test design and dry-run behavior. This refinement continues the series' trend of making the command's interface more user-friendly while preserving its technical capabilities.
