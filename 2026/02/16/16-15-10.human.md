This is a refactoring patch that consolidates alias listing logic between `alias.c` and `help.c`. It's the first in a v5 series implementing UTF-8 support for Git config subsections (particularly aliases).

The patch eliminates duplicate alias parsing code by having `help.c` reuse `list_aliases()` from `alias.c` instead of maintaining its own `get_alias()` callback. The key change is making `list_aliases()` store alias values (via the string_list util field) while preserving the existing error checking for value-less aliases. A new test case verifies this error handling.

The change is mechanical and well-contained, touching only the alias listing functionality without altering behavior. It follows the pattern of the series by cleaning up infrastructure before adding new features. The patch has already been through several rounds of review, with the shell completion bug fixed in v5, the series appears ready for merging.
