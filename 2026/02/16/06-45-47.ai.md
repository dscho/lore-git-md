Patch 4/5 in Patrick Steinhardt's v3 series for improving the `git history` command UI. This is a straightforward renaming change that follows from the previous patch's refactoring - the `--ref-action=` option is renamed to `--update-refs=` to better reflect its current behavior of controlling which references get updated rather than the action performed on them.

The change is mechanical but important for clarity, updating the option name in three places: the documentation, the command-line help text, and the test suite. The patch maintains all existing functionality while making the interface more intuitive. The new name better matches the option's purpose after the series' earlier changes separated the "what to update" concern from the "how to update it" behavior (now handled by `--dry-run`).

This continues the series' trend of improving usability through careful naming choices, building on the previous introduction of `--dry-run` in patch 3. The change is well-contained and unlikely to be controversial, with all tests passing and documentation updated to match.
