This is a performance optimization series from Patrick Steinhardt targeting `git receive-pack`'s handling of shallow pushes. The patches aim to address real-world cases where shallow pushes were causing excessive memory usage and multi-minute delays in production repositories.

The series consists of three commits that work together to optimize `assign_shallow_commits_to_refs()` by:
1. Avoiding unnecessary parsing of non-commit objects in `lookup_commit_reference_gently()`
2. Making `repo_parse_commit_no_graph()` more robust against malformed input
3. Leveraging the commit graph in `lookup_commit_reference_gently()` for faster lookups

The changes touch core commit-handling code in commit.c and object.c, with corresponding header updates. Given Patrick's track record with performance optimizations and the clear production motivation, this appears to be a well-justified series worth watching for anyone working with large repositories or the receive-pack/shallow clone infrastructure.
