This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically addressing a zsh completion issue for subsection-style aliases like `[alias "förgrena"]`. The patch fixes an edge case where zsh completion was incorrectly handling the subsection syntax by introducing a new `--aliases-for-completion` option to `git help`.

The core issue stems from zsh's current implementation using `git config --get-regexp` which doesn't properly handle the subsection format, leaving malformed completion candidates. The solution mirrors the existing `--config-for-completion` pattern, adding a hidden option that uses the C-level `list_aliases()` function (which already handles both alias syntaxes correctly) to output NUL-separated name/value pairs.

Key technical changes include:
- New `HELP_ACTION_ALIASES_FOR_COMPLETION` mode in `builtin/help.c`
- Integration with the `list_aliases()` function that was properly handling subsections in earlier patches
- NUL-delimited output format matching completion script expectations
- A one-line change in `git-completion.zsh` to use the new interface

This patch completes the technical work for the series, with all prior feedback addressed across the four commits. The implementation maintains consistency with existing completion infrastructure while properly supporting UTF-8 subsection aliases.
