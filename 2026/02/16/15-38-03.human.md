Performance optimization for shallow push handling in `git receive-pack`. This is the third and final patch in Patrick Steinhardt's series that improves both speed and memory usage when processing shallow pushes. 

The patch modifies `lookup_commit_reference_gently()` to use the commit-graph for faster commit lookups, building on the previous optimizations that avoided parsing non-commit objects. Benchmark results show a 3.93x speed improvement when pushing to a repository with 600,000 commit references, along with significant memory allocation reductions (from 407MB to 15MB). The change is relatively small (4 lines modified in commit.c) but impactful, swapping `parse_object()` for the more efficient `repo_parse_commit_gently()` path that leverages the commit-graph.

This completes the series' goal of optimizing shallow push performance through targeted object database improvements, with each patch addressing a different aspect: avoiding unnecessary parsing, fixing edge cases, and now leveraging the commit-graph. The implementation appears well-tested and benchmarked, showing Patrick's characteristic attention to both performance and correctness in object handling scenarios.
