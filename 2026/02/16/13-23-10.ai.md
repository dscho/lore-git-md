This is part 4/9 of a v4 series implementing promisor remote enhancements, specifically focusing on refactoring the filter options handling in `git fetch`. The patch makes the `filter_options` variable local to `cmd_fetch()` rather than being a static file-level variable, clarifying ownership and preparing for subsequent changes in the series.

The changes involve:
- Moving the `filter_options` definition into `cmd_fetch()`
- Passing it through several helper functions (`prepare_transport()`, `do_fetch()`, etc.)
- Updating all call sites to handle the new parameter
- Adding proper cleanup with `list_objects_filter_release()`

The refactoring maintains identical behavior while making the code more maintainable for the upcoming `--filter=auto` implementation in later patches. The patch has been reviewed by Patrick Steinhardt and fits into the larger LOP (Large Object Promisors) effort to improve partial clone functionality. This is a mechanical change that doesn't introduce new features but enables cleaner implementation of the auto-filter capability in subsequent patches.
