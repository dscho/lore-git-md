This is a refactoring patch in the LOP (Large Object Promisors) series, which aims to improve Git's promisor remote functionality. It's the first of nine patches in version 4 of the series.

The patch extracts common initialization code from `fields_sent()` and `fields_checked()` functions in `promisor-remote.c` into a new `initialize_fields_list()` helper. Both functions were doing similar setup work - initializing string lists and loading configuration - and this change eliminates that duplication. The refactoring prepares for adding another similar function in a later patch.

The change is mechanical and straightforward, just moving code around without changing behavior. It's been reviewed by Patrick Steinhardt and is part of a larger effort that has gone through multiple iterations with feedback incorporated. The patch touches only `promisor-remote.c` and follows the project's coding style.
