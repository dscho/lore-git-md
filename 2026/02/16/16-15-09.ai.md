This is the fifth iteration of a feature patch set enabling UTF-8 support in Git alias names through config subsection syntax (`[alias "förgrena"]`). The series addresses a shell completion bug discovered after the v4 review while maintaining all previously implemented functionality.

The v5 series consists of four commits: First, it consolidates alias listing between `help.c` and `alias.c` via `list_aliases()`. Second, it prepares the alias subsystem for subsection support. The third commit implements the core UTF-8 alias functionality using config subsections. Finally, it fixes a zsh completion bug where subsection aliases were incorrectly suggested in `<alias>.command` syntax.

Key technical improvements in v5 include fixing the zsh completion handler to properly suggest subsection syntax for non-ASCII aliases, updating documentation with clearer examples (including one demonstrating spaces in alias names), and refining terminology per Richard Kerry's suggestion ("languages outside English range" rather than "native speakers"). The implementation maintains strict validation via `parse_config_key()` and preserves all existing error checking while adding comprehensive test coverage for Swedish, CJK, and space-containing aliases.
