This is part 2/5 of a series improving Gitweb's mobile responsiveness. The patch focuses on fixing overflow issues in the project search bar when viewed on narrow screens (<=768px width).

The change introduces a media query that adds padding to the search container and ensures the input field stays within its bounds by using `max-width: 100%` and proper box sizing. This prevents horizontal scrolling that would otherwise occur when the search input exceeds the viewport width.

The implementation is clean and focused - just 12 lines of CSS added to handle the mobile-specific styling. As noted in the thread context, this addresses Eric Sunshine's feedback from v1 about keeping all search bar constraints in one patch rather than splitting them across multiple changes. The patch appears ready for consideration, maintaining desktop layout while fixing the specific mobile issue it targets.
