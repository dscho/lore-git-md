This is the fourth patch in Patrick Steinhardt's v3 series improving the `git history` command's interface. The patch renames the `--ref-action` option to `--update-refs` to better reflect its current behavior after earlier changes in the series.

The option now only controls which references will be updated (branches or just HEAD) rather than the action performed on them, making the new name misleading. The change is straightforward but thorough - updating the documentation, command help text, and test cases to use the new option name consistently.

This is part of the broader effort to make the command's interface more intuitive, following the introduction of `--dry-run` in the previous patch. The series has been through multiple rounds of review with all feedback outstanding from earlier versions addressed, and this patch appears to be a clean, uncontroversial rename that aligns with the command's refined behavior.
