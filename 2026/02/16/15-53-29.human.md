This is part 3 of a 5-patch series improving Gitweb's mobile responsiveness. The patch focuses on fixing horizontal overflow issues in log, commit, blob, and diff views when viewed on small screens.

The changes introduce mobile-specific CSS rules (scoped to screens <=768px wide) that:
- Enable horizontal scrolling for page content and diff headers
- Adjust padding and whitespace handling in log and diff views
- Ensure preformatted content remains readable by setting appropriate minimum widths
- Add a global safeguard against text overflow in log bodies that applies to all viewport sizes

The implementation builds on the media query introduced in part 2 of the series, addressing specific layout pain points in Gitweb's various content views. The changes are well-scoped to mobile while preserving the desktop experience, and the commit message clearly explains both the problem and solution. This appears to be a thoughtful, incremental improvement to Gitweb's mobile usability.
