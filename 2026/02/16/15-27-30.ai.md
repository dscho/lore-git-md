Bugfix for `git format-patch` cover letter generation regarding `--from` option handling.

This is the second version of a patch fixing an inconsistency in `git format-patch` where the `--from` option (which sets an alternative sender identity) was being ignored for cover letters while working correctly for individual patches in a series. The fix modifies `make_cover_letter()` in `builtin/log.c` to check the configured `from` value before falling back to the default committer info, matching the behavior of the per-patch generation path.

The patch now addresses all feedback from the maintainer: the commit message has been improved to clearly explain the problem and solution, the variable has been renamed from `committer` to `from` to better reflect its purpose, and a new test case has been added to verify the fix works and prevent future regressions. The change is small (6 lines modified) and focused, with test coverage demonstrating both the fixed behavior and that redundant in-body headers are still properly omitted. This appears ready for merging once any final review comments are addressed.
