This is part 6/9 of a series implementing the `--filter=auto` mode for Git's promisor remote functionality. The patch focuses on the infrastructure changes needed to support the new "auto" filter mode in the list-objects-filter system.

The key changes include:

1. Adding a new `LOFC_AUTO` filter choice and corresponding `allow_auto_filter` flag in `struct list_objects_filter_options` to control which commands can accept "auto" filters.

2. Modifying `gently_parse_list_objects_filter()` to handle "auto" filters when allowed, while maintaining backward compatibility for other filters.

3. Preventing "auto" from being combined with other filters through checks in both `parse_combine_subfilter()` and `parse_list_objects_filter()`.

4. Adding a BUG() check in the filter initialization code to ensure "auto" filters are resolved to concrete filters before actual filtering begins.

5. Creating new unit tests in `u-list-objects-filter-options.c` to verify the parsing behavior, including tests for allowed/denied "auto" filters and combination cases.

The patch maintains careful backward compatibility while laying the groundwork for the actual "auto" filter implementation in subsequent patches.
