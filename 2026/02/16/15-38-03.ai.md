Performance optimization for shallow push handling in `git receive-pack`. This is the third and final patch in Patrick Steinhardt's series that improves commit reference lookups during shallow pushes. Building on the previous patches that optimized non-commit object handling and fixed commit-graph edge cases, this change modifies `lookup_commit_reference_gently()` to use the commit-graph for faster commit parsing.

The key technical change replaces `parse_object()` with `lookup_commit()` followed by `repo_parse_commit_gently()`, which can leverage the commit-graph. Benchmarks show a 3.93x speedup (from 9.179s to 2.337s) when pushing to a repository with 600,000 commit references, along with significant memory allocation reductions (407MB to 15.5MB allocated). The implementation maintains the same error handling and quiet flag behavior while switching to the more efficient commit-graph path.

This completes the series' goal of optimizing shallow push performance through targeted object lookup improvements. The changes are narrowly scoped to commit.c and build on established commit-graph infrastructure. With all three patches now submitted, reviewers can evaluate the complete solution for both its performance gains and robustness in edge cases.
