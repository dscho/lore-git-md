This is part of the ongoing `the_repository` removal effort, specifically targeting the migration of global configuration variables into per-repository storage. The patch moves `core.sparseCheckout` from a global variable to `struct repo_config_values` in `the_repository`.

The change affects 12 files across sparse-checkout, clone, worktree, grep and other commands that interact with sparse checkouts. The patch maintains existing behavior while eliminating the global state that could cause issues when multiple repositories operate in the same process. The implementation follows Phillip Wood's suggested approach and has been refined through seven iterations of review.

Key technical aspects:
- Adds `apply_sparse_checkout` to `struct repo_config_values`
- Updates all access sites to use the repository-specific version
- Preserves the existing default behavior
- Passes all tests including fuzz testing after fixing a regression

This is the second of three patches in the series (v7), with Phillip Wood having reviewed and approved the technical approach. The changes are mechanical but touch several critical paths in the sparse checkout machinery.
