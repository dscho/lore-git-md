This is a discussion about improving the discoverability of stash diff functionality in Git. Eric Sunshine responds to Pierre Houston's feature request for a `git stash diff` command by noting that the capability already exists via `git stash show -p`, though acknowledges the discoverability issue. He suggests that improving the documentation to highlight the `--patch` option for both `show` and `list` subcommands would be a welcome contribution, rather than adding a new command. The thread remains open on whether the existing functionality is sufficient or if a dedicated `diff` subcommand would provide better usability. The key technical points are the existing `show -p` behavior and the question of whether porcelain commands should mirror plumbing capabilities for discoverability.
