Bugfix targeting whitespace handling for symbolic links. This patch from Junio C Hamano addresses an issue where recent checks for incomplete lines (missing newlines at end of files) were incorrectly triggering for symbolic links, where such endings are normal.

The changes modify both `apply.c` and `diff.c` to explicitly disable the WS_INCOMPLETE_LINE check when dealing with symbolic links. The patch adds test cases in both `t4015-diff-whitespace.sh` and `t4124-apply-ws-rule.sh` to verify the behavior remains correct for symlinks while preserving the incomplete-line checks for regular files.

This appears to be a straightforward correction of an unintended side effect from recent whitespace checking improvements. The patch is small, focused, and comes with comprehensive test coverage - exactly the sort of maintenance fix expected from the project maintainer. The changes touch core diff/apply machinery but are well-contained to the specific edge case being addressed.
