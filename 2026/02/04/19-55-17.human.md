This is a test compatibility patch in the ongoing subtree/reftable thread. Colin Stagner addresses a test failure in the `git subtree` contrib script when running with the reftable backend. The issue stems from the test script directly reading `.git/HEAD` to determine the default branch name, which doesn't work with reftable's different storage format.

The patch replaces this direct file access with the already-configured `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=main` value, making the test backend-agnostic. Junio C Hamano approves the change, noting it's cleaner than his previous workaround. This is part of broader CI improvements that are uncovering various compatibility issues in contrib/ scripts.

The change is minimal (4 lines modified) but important for ensuring subtree tests pass across all storage backends. It demonstrates how expanded CI testing is revealing previously hidden compatibility requirements in less-frequently-exercised parts of the codebase.
