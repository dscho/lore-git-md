This is a bugfix addressing an inconsistency in how `git add` handles excluded pathspecs (`:!path`) when the excluded path is in `.gitignore`. The patch corrects the behavior so that `git add :!x` no longer errors when `x` is an ignored file, aligning with the documented behavior that exclude pathspecs should be treated the same as normal ones.
