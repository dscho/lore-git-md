This is a build system patch continuing the Meson integration effort for Git's GUI components (gitk and git-gui). The thread has progressed through several iterations, with v2 switching to a symlink-based solution to maintain the original source layout while meeting Meson's requirements for subproject locations.

Junio Hamano raises two concerns in this email: First, he questions whether the symlink approach will work well on Windows, which has historically had poor symlink support. Second, he notes an unrelated issue with `.gitattributes` handling of symlinks and trailing newlines, suggesting either a new pattern syntax or special-case handling.

The patch itself is the final piece needed for Meson feature parity with the Makefile build system. Previous discussion has established technical consensus around the symlink approach, with Karthik Nayak confirming it works as intended. The remaining open items (libexecdir handling and shell quoting) appear to be separate from these symlink concerns.

This email doesn't introduce new technical changes - it's maintainer feedback on an already-reviewed patch series that's nearing completion. The Windows symlink question is the main outstanding consideration that may need addressing before merging.
