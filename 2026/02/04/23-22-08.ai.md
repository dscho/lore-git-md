This is an RFC patch proposing to move Git's experimental Rust infrastructure from `src/` to a dedicated `rust/` subdirectory. The change is motivated by two factors: (1) making the project structure clearer in a multi-language codebase, and (2) addressing a specific build issue in git-cinnabar (a Mercurial remote helper) where `cargo package` skips directories containing Cargo.toml files.

The patch moves all Rust-related files (Cargo.toml, lib.rs, varint.rs, and build scripts) into a new `rust/` directory and updates the build system (Makefile and meson.build) to accommodate the change. The author acknowledges this is a temporary workaround for git-cinnabar's publishing process, as the problem would resurface if Rust becomes non-optional in Git.

The change is purely organizational - no Rust code is modified, only relocated. The patch affects build system files and adds new entries to .gitignore for the moved Rust artifacts. This appears to be a well-considered infrastructure change from an experienced contributor (Mike Hommey maintains git-cinnabar), though its long-term value depends on how Git's role in the Rust ecosystem evolves.
