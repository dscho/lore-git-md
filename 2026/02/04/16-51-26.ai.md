Feature patch extending Adrian Ratiu's hook configuration series to support out-of-repo execution. This is the fourth patch in the series, building on prior work to make hooks configurable via Git config rather than just filesystem paths.

The change allows `git hook run` to work outside a Git repository when hooks are defined in global/system configs, while still excluding traditional hookdir-based execution (which requires a repository). The main implementation is a single-line change in `git.c` to mark the hook command as `RUN_SETUP_GENTLY` rather than `RUN_SETUP`, plus updated tests showing global config hooks working in a nongit context.

Key technical details:
- Maintains the series' focus on config-based hooks while gracefully handling the no-repo case
- Specifically enables use cases like `sendemail-validate` hooks when running `git send-email` from non-repo directories
- Tests demonstrate both listing and running global hooks without a repository
- Carries Emily Shaffer's sign-off from prior related work

This appears to be a straightforward extension of the config-hook functionality, with clear motivation and test coverage. The change is minimal and focused, fitting naturally with the series' goal of making hooks more flexible. Reviewers will likely want to verify the security implications of running hooks without repository context, though the global config is already a trusted source.
