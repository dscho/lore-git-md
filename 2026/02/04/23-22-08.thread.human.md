This RFC thread has progressed from discussion to concrete action regarding the reorganization of Git's experimental Rust infrastructure. Mike Hommey, maintainer of git-cinnabar, has now submitted a patch to move all Rust-related files from `src/` to a dedicated `rust/` subdirectory, including Cargo.toml, build scripts, and source files. This follows earlier technical discussions that revealed mrustc's minicargo can handle non-standard directory structures, weakening one of the original objections to such a move.

The patch focuses on the mechanical changes needed for the relocation, updating both Makefile and meson.build configurations while adding appropriate .gitignore entries. Notably, however, it does not yet address the separate git-cinnabar build issues that were part of the motivation for this reorganization. The changes aim to make the project's multi-language nature clearer and prevent confusion from having a top-level Cargo.toml that doesn't produce useful standalone builds.

While the patch appears technically sound with proper sign-off and clean diffs, the community must still weigh the tradeoffs between project structure clarity and any remaining cross-compilation concerns. The earlier revelation about mrustc's flexibility may shift the discussion toward focusing on project hygiene benefits rather than technical constraints. This represents a concrete step forward in Git's ongoing Rust infrastructure evolution, though the separate git-cinnabar build issues remain to be resolved.
