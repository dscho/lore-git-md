This thread discusses an RFC proposal to reorganize Git's experimental Rust infrastructure by moving it from `src/` to a dedicated `rust/` subdirectory. The change is motivated by both project clarity (separating Rust code from C) and a practical build issue in git-cinnabar, a Mercurial remote helper that uses Git's Rust code. The patch moves all Rust-related files (Cargo.toml, lib.rs, varint.rs, and build scripts) while keeping the actual code unchanged.

The proposal comes from git-cinnabar maintainer Mike Hommey, who notes this is a temporary workaround for cargo packaging issues. The change would make Git's structure more conventional for a mixed C/Rust codebase, though its long-term value depends on how Git's Rust integration evolves. The patch includes updates to both Makefile and meson build systems to accommodate the new location.
