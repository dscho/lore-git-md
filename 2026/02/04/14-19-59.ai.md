This is a refactoring patch in Derrick Stolee's `git config-batch` series, which aims to optimize configuration operations by batching them. The patch extracts configuration location handling code from `builtin/config.c` into shared `config.[ch]` files to enable reuse by the new `config-batch` command.

The key changes are:
1. Moves `struct config_location_options` and related functions (`location_options_init()`, `location_options_release()`) from `builtin/config.c` to `config.h`/`config.c`
2. Modifies the functions to take an explicit `struct repository *` parameter instead of using `the_repository` global
3. Updates all callers in `builtin/config.c` to pass `the_repository` explicitly

This is a mechanical refactoring that doesn't change behavior - it just relocates and slightly generalizes existing code to make it reusable. The patch follows Git's typical refactoring pattern of moving code that's needed in multiple places into shared infrastructure files.

The change supports the broader `config-batch` effort by allowing the new command to reuse the same configuration location handling logic that the existing `git config` command uses. This is patch 7/11 in the series, continuing the incremental implementation approach with each patch adding well-tested functionality.
