This is part 6/8 of a series implementing 'auto' filter mode for promisor remotes. The patch adds infrastructure to support `--filter=auto` in Git's object filtering system.

Christian Couder introduces a new `LOFC_AUTO` filter choice and adds an `allow_auto_filter` flag to `struct list_objects_filter_options` to control which commands can accept "auto" as a filter spec. The implementation includes safeguards to prevent combining "auto" with other filters (though the commit notes this could be relaxed in future work) and adds a BUG() check to ensure "auto" filters are resolved before actual filtering begins.

The patch includes comprehensive unit tests in a new `u-list-objects-filter-options.c` file that verify the parsing behavior for both allowed and disallowed cases. The implementation appears well-considered, with clear attention to edge cases and proper resource management. Patrick Steinhardt has been actively reviewing this series, and this patch follows the established pattern of the previous infrastructure changes in the series.
