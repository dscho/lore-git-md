This is a build system patch continuing the Meson integration effort for Git's GUI components (gitk and git-gui). Karthik Nayak reviews Patrick Steinhardt's v2 patch which switches from physically moving the gitk/git-gui directories to using symlinks in the `subprojects/` directory to satisfy Meson's requirements while preserving the original source layout.

The review notes the conditional build behavior based on Tcl/Tk tool availability (tclsh and wish) matches the Makefile's approach, with git-gui requiring both tools while gitk only needs wish. Nayak asks whether Meson has an open issue for configurable subproject paths, suggesting that could eventually eliminate the symlink workaround.

This patch represents the technical convergence point in the earlier architectural debate about build systems influencing source layout. The symlink approach addresses Junio Hamano's concerns while meeting Meson's requirements. The review focuses on implementation details rather than raising new issues, indicating the technical solution is sound pending resolution of remaining shell quoting and libexecdir path handling noted by Ramsay Jones in earlier discussion.
