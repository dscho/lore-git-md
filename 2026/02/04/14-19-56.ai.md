This is part 4/11 of Derrick Stolee's series introducing a new `git config-batch` builtin to optimize configuration operations. The patch adds a `help` command to the protocol, allowing clients to discover available commands and their versions.

The implementation provides a structured way for tools to query supported functionality:
- First line reports total command count
- Subsequent lines list each command with its highest supported version
- Follows the same line-based protocol as other commands
- Includes comprehensive test coverage

The help output currently shows two commands (help and get) with version 1 support, matching the functionality introduced in previous patches. The implementation is cleanly integrated with the existing command dispatch system and maintains the protocol's forward compatibility guarantees.

This continues the careful, incremental approach seen in earlier patches, with clear documentation and thorough testing. The help command is particularly valuable for the intended credential manager use case, where clients need to dynamically discover available capabilities across different Git versions.
