This is a refactoring patch in the ongoing LOP (Large Object Promisors) effort, specifically part of a series enhancing Git's promisor remote functionality. It's the first patch in the second version of an 8-patch series (down from 9 in v1).

The patch extracts common initialization code from `fields_sent()` and `fields_checked()` functions in `promisor-remote.c` into a new `initialize_fields_list()` helper function. This prepares for adding another similar function in a future commit. The change is purely mechanical - no behavior is altered, just code organization improved.

The patch is straightforward and well-contained, touching only `promisor-remote.c`. It follows good practice by keeping the diff small (14 lines changed) and the commit message clearly explains both the what and the why of the change. Given this is part of a larger series that has already received review from Patrick Steinhardt and others, and the change itself is non-controversial, it appears ready to move forward.
