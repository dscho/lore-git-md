Adrian Ratiu's config-based hooks series has reached its final stages after being merged into 'master'. The series introduced configuration-based hook management (`hook.<friendly-name>.command`, `hook.<friendly-name>.event`, and `hook.<friendly-name>.enabled`) while maintaining compatibility with traditional filesystem hooks. Key features include out-of-repo execution support, NUL-terminated output, scope visibility, and disabled hook display.

The series received thorough review from Junio Hamano and Patrick Steinhardt, with all major technical concerns addressed. The core functionality is now complete, with only minor test infrastructure cleanup remaining. SZEDER Gábor identified a missing `&&` chain in test helper functions that could mask failures, which Adrian has acknowledged will be fixed in a follow-up patch. This represents the final polish for the feature's test suite.

With the prerequisite work now in 'next' and the main series merged, this marks the successful completion of the effort to bring configurable hooks to Git while preserving backward compatibility. The remaining test script fix is a minor cleanup item that doesn't affect the shipped functionality.
