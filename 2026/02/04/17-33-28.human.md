This is the final patch in Adrian Ratiu's series introducing parallel hook execution, building on his prior work to make hooks configurable. The patch adds a runtime configuration option (`hook.forceStdoutToStderr`) that enables parallel execution for hooks like `pre-push` by forcing their output to stderr, addressing the interleaving issues that previously required serial execution.

The change allows users to opt into parallel hook behavior globally without modifying repository formats, making it easier to adopt the feature. The implementation includes thorough test coverage for `git init`, `git clone`, and existing repository scenarios, verifying both the configuration propagation and actual parallel execution behavior. The patch maintains backward compatibility while providing a clear migration path for users who want to enable parallel hooks across their workflow.
