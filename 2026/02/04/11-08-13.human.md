This is the final patch in an 8-part series enhancing Git's promisor remote functionality, implementing the `--filter=auto` option for clone and fetch operations. The patch wires up the infrastructure built in previous patches to enable automatic filter specification based on server-advertised promisor remotes.

The key changes in this patch:
- Enables `allow_auto_filter` in clone/fetch commands and transport layer
- Implements the logic in fetch-pack to compute and use auto filters
- Updates documentation to explain the new `--filter=auto` behavior
- Adds tests verifying the auto filter functionality persists across operations

The implementation allows servers to suggest optimal filters which clients can automatically adopt, with the configuration persisting for future fetches. This builds on the series' earlier work around promisor remote configuration and filter combination logic.

The patch has received review from Patrick Steinhardt and incorporates feedback from Jean-Noël Avila on documentation formatting. It represents the series' culmination in delivering dynamic filter configuration for partial clones.
