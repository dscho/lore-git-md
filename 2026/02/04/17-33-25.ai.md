A preparatory patch in Adrian Ratiu's parallel hook execution series, introducing infrastructure needed for the upcoming hook.jobs setting. This adds a new `repo_config_get_uint()` helper to properly handle unsigned integer config values, avoiding the need to cast from signed int or use oversized unsigned long. The implementation follows Git's existing config parsing patterns, with matching functions at both the low-level parsing layer (`git_parse_uint`) and higher-level configset/repo APIs. The commit message clearly explains the motivation for adding this specific helper rather than reusing existing types. This is a straightforward plumbing change that will be used by the next patch to read the parallel job count configuration.
