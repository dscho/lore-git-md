This is a test compatibility patch in the ongoing subtree bugfix series, addressing reftable backend support. The patch modifies `contrib/subtree/t/t7900-subtree.sh` to remove direct `.git/HEAD` file access that breaks with reftable, instead relying on the already-set `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=main` environment variable. 

The change replaces branch name detection that previously read `.git/HEAD` directly with hardcoded 'main' branch references, maintaining the test's behavior while making it compatible with reftable's different ref storage format. Junio indicates he will replace his earlier workaround with this cleaner version, which properly handles the case where tests operate on the initial branch.

This is part of broader CI infrastructure improvements that are revealing compatibility issues in contrib/ scripts, with subtree being one of the more complex cases due to its test dependencies on branch naming and filesystem access patterns. The patch demonstrates the pattern of updating tests to work with both traditional and reftable backends while preserving existing test coverage.
