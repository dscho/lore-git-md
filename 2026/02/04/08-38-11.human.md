This is a build system patch completing Meson integration for Git's GUI components (gitk and git-gui). Patrick Steinhardt's v2 submission addresses earlier feedback by using symlinks rather than physically moving the gitk and git-gui directories into the subprojects/ folder, maintaining the existing source layout while satisfying Meson's requirements.

The patch adds Meson build rules for both GUI tools, handling Tcl/Tk dependency checks (tclsh and wish) with the same auto-disable behavior as the Makefile - the tools will only build when either explicitly requested with all dependencies present, or in "auto" mode with all requirements available. The implementation uses Meson's subproject() mechanism while preserving the ability to build these components standalone.

This represents the final piece for feature parity between Meson and Makefile builds, though the thread discussion notes some remaining work items (libexecdir handling, shell quoting issues) before Meson can be considered fully production-ready. The architectural debate about whether Git should adapt its source structure to Meson's requirements remains unresolved, with Junio Hamano expressing concerns about build systems dictating source organization.

The patch is well-structured and follows the established pattern of Meson integration work in Git. It maintains backward compatibility while moving the build system forward, though some reviewers may want to see the outstanding issues addressed before declaring full support.
