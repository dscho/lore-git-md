This is the final patch in an 8-part series implementing automatic filter selection for promisor remotes. The patch wires up the `--filter=auto` functionality in `git clone` and `git fetch`, completing the LOP (Large Object Promisors) effort.

The key changes enable the auto-filter logic by:
1. Setting `allow_auto_filter=1` in clone/fetch, and transport.c to accept "auto" filter specs
2. Having fetch-pack compute the actual filter by combining server-advertised filters when `--filter=auto` is used
3. Persisting the "auto" setting in config so subsequent fetches maintain dynamic filter behavior
4. Adding comprehensive tests verifying the auto-filter workflow

The implementation handles the critical link between server-advertised filters and client-side filter computation, with attention to error handling and backward compatibility. Documentation is updated across clone, fetch, and protocol-v2 man pages to explain the new auto-filter behavior.

This builds on the infrastructure from previous patches, particularly patch 7/8 which added server-advertised filter storage. The series has received thorough review from Patrick Steinhardt, with documentation feedback from Jean-Noël Avila. The changes are well-tested and complete the promised functionality for dynamic filter selection based on server capabilities.
