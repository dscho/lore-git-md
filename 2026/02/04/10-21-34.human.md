This is part 6/9 in a series enhancing Git's promisor remote functionality, focusing on implementing an `--filter=auto` mode for dynamic filter selection. Christian Couder addresses Patrick Steinhardt's feedback on the previous version, making several improvements to the implementation.

The patch introduces infrastructure to support 'auto' as a filter specification, adding an `allow_auto_filter` flag to control which commands can use this mode. It handles parsing of 'auto' filters while preventing invalid combinations with other filters. Christian makes several code improvements based on Patrick's review: fixing indentation, adding cleanup handling, and explaining why the `allow_auto_filter` flag needs preservation during filter reset operations.

The discussion reveals some interesting implementation details - the filter options struct gets reused during command-line processing, necessitating careful handling of the auto-filter flag. While the current implementation prohibits combining 'auto' with other filters, both contributors acknowledge this could be relaxed in future if needed. The changes maintain the series' focus on secure, well-tested promisor remote functionality while addressing edge cases in the auto-filter behavior.
