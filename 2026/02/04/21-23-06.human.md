Bugfix for whitespace handling of symbolic links in `git diff` and `git apply`. 

This patch addresses an issue where Git's recent incomplete-line detection was incorrectly flagging symbolic links as problematic when they lacked a trailing newline. Since symlinks typically don't end with newlines, the patch modifies both `diff.c` and `apply.c` to disable the WS_INCOMPLETE_LINE check for symlinks. 

The changes are straightforward - they check the file mode and mask out the incomplete-line rule when dealing with symlinks. The patch includes new tests in both the diff and apply test suites to verify the behavior. 

This comes from the maintainer (Junio Hamano) and appears to be a clean, focused fix for a real edge case that could cause false positives in whitespace checking. The changes are minimal and well-tested, making this a low-risk improvement to Git's whitespace handling.
