Bugfix for `git add` and `git stash` behavior with excluded pathspecs. This patch addresses an inconsistency where `git add :!x` would fail when 'x' is in .gitignore, despite the exclude pathspec explicitly saying it should be added. The current behavior contradicts the documented expectation that exclude pathspecs should work the same as normal ones.

The fix modifies `dir.c` to skip the ignored-file check for pathspecs marked with PATHSPEC_EXCLUDE. The patch includes thorough test coverage in both the `git add` and `git stash` test suites, demonstrating the fix works for various scenarios including nested paths and .gitignore cases.

The commit message clearly explains the problem and provides a reproduction script. The change is small and focused, touching only the necessary logic in dir.c while adding comprehensive tests. This appears to be a well-justified fix for a long-standing edge case that was likely overlooked when PATHSPEC_EXCLUDE was introduced.
