This is part 6 of a 9-patch series enhancing Git's promisor remote functionality, focusing on implementing `--filter=auto` support. Christian Couder addresses Patrick Steinhardt's feedback from earlier review comments.

The patch adds infrastructure in `list-objects-filter-options.[ch]` to support an 'auto' filter mode that will automatically select the best filter advertised by the remote. Key changes include:
- Adding an `allow_auto_filter` flag to control which commands accept 'auto'
- Modifying parsing logic to handle 'auto' while preventing combinations with other filters
- Preserving the `allow_auto_filter` flag during filter resets
- Adding `LOFC_AUTO` enum value with BUG() protection against direct use

Christian incorporates Patrick's suggestions about error message formatting, adding missing `goto cleanup` statements, and clarifies why `allow_auto_filter` needs preservation during resets (it's command-specific configuration rather than user input). The discussion confirms that while future extensions could allow combining 'auto' with other filters, the current implementation deliberately keeps things simple.

The changes maintain the series' focus on secure, backward-compatible promisor remote improvements while adding dynamic filter selection capability. Test coverage appears thorough, and the implementation carefully considers edge cases around command-line parsing and filter combination semantics.
