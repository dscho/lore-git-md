This is a documentation patch in Derrick Stolee's ongoing series introducing a new `git config-batch` builtin. The patch adds a design document outlining the command's protocol and planned future commands.

The document describes the versioned protocol approach (already implemented in earlier patches) and recommends best practices for clients, particularly suggesting use of the NUL-terminated format for robustness. It then lists several planned but not-yet-implemented commands that would expand the tool's functionality to match more of `git config`'s capabilities, including `set`, `unset`, and `--type` options.

The design doc serves as both a reference for future contributors and a roadmap for the feature's evolution. It's notable that Stolee is taking a careful, incremental approach - the design explicitly calls out versioning and compatibility considerations, and the document itself is structured to track progress by removing items as they're implemented.

This patch continues the series' strong technical documentation practices, maintaining the high standard set by earlier patches. The design doc will be particularly valuable as the credential manager integration work progresses, helping other contributors understand the protocol's constraints and future direction.
