This is the fourth patch in Adrian Ratiu's series to make Git hooks configurable via Git configuration, building on Emily Shaffer's earlier work. The patch allows `git hook` commands to run outside a Git repository when hooks are defined in global or system configuration.

The key change is modifying the `git hook` command to use `RUN_SETUP_GENTLY` instead of `RUN_SETUP`, which means it will no longer fail when run outside a repository. The patch includes tests showing that global hooks (defined in config) now work in non-repo contexts, while traditional hookdir hooks (which require a repository) remain unavailable.

This enables use cases like running `sendemail-validate` hooks from non-repo directories when using `git send-email`. The implementation maintains security by still requiring explicit configuration for any hooks to run outside a repository - it doesn't automatically pick up any filesystem hooks.

The patch carries Emily Shaffer's sign-off from prior related work and includes comprehensive coverage of the new behavior in the test suite. This appears to be a well-considered extension of the hooks configuration system that maintains backward compatibility while adding useful functionality.
