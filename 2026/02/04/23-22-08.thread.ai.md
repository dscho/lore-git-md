Thread identity: RFC patch proposing to move Git's experimental Rust infrastructure from `src/` to a dedicated `rust/` subdirectory, authored by Mike Hommey (git-cinnabar maintainer), with follow-up discussion involving brian m. carlson.

Core problem/goal: Reorganize Rust code location to address (1) project structure clarity in a multi-language codebase and (2) git-cinnabar build issues with `cargo package`. The proposal would move all Rust files while maintaining functionality. Discussion has expanded to consider Rust project layout conventions and alternative solutions.

Current status: Active RFC discussion with two main perspectives. No version updates as this remains a design discussion. The git-cinnabar build issue remains unresolved regardless of directory structure decisions.

Technical details: Proposed move would relocate Rust files (Cargo.toml, lib.rs, varint.rs, build scripts) from `src/` to new `rust/` directory. brian m. carlson advocates for standard Rust layout with `rust/src/` subdirectory, while Mike Hommey questions strict adherence citing projects like Servo that deviate. Both Makefile and meson.build would require updates. The git-cinnabar issue stems from Cargo's package behavior skipping directories containing `Cargo.toml` files when Git is a submodule.

Open questions: Three distinct dimensions now under discussion: (1) whether to move files at all versus modify Cargo, (2) if moving, whether to adopt standard Rust layout conventions, and (3) how to resolve the git-cinnabar build issue regardless of directory structure. The debate reveals deeper questions about Git's relationship to Rust ecosystem norms.

Participant positions: Mike Hommey maintains proposal benefits while questioning strict layout conventions, emphasizes git-cinnabar use case. brian m. carlson continues advocating standard Rust layout if moving files, suggests Cargo modifications as alternative solution. Both positions remain unchanged but discussion has clarified underlying assumptions about tool behavior and project structure philosophy.

Related work: git-cinnabar's build system constraints remain primary driver. Servo project cited as example of non-standard Rust layout. Cargo's package exclusion rules documented behavior that may require workaround regardless of directory structure decisions.
