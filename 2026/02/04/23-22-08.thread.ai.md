Thread identity: RFC patch proposing to move Git's experimental Rust infrastructure from `src/` to a dedicated `rust/` subdirectory, authored by Mike Hommey (git-cinnabar maintainer).

Core problem/goal: Reorganize Rust code location to (1) clarify project structure in a multi-language codebase and (2) work around a git-cinnabar build issue where `cargo package` skips directories containing Cargo.toml files. The change is purely organizational with no Rust code modifications.

Technical details: Moves all Rust-related files (Cargo.toml, lib.rs, varint.rs, build scripts) to new `rust/` directory. Updates both Makefile and meson.build build systems. Adds new .gitignore entries for relocated Rust artifacts.

Open questions: Long-term value depends on Git's evolving role in Rust ecosystem, as the git-cinnabar workaround would be temporary if Rust becomes non-optional in Git. No technical objections raised yet in this initial proposal.
