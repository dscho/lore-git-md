This is part 4/8 of a series enhancing Git's promisor remote functionality, focusing on refactoring the filter options handling in `builtin/fetch.c`. The patch converts the static `filter_options` variable into a local variable within `cmd_fetch()`, passing it explicitly through the call chain to `prepare_transport()`, `do_fetch()`, and other helper functions.

The change improves code organization by making ownership and lifetime of the filter options clearer, while maintaining identical behavior. This is a mechanical refactoring that follows the same pattern as patch 3/8's changes to `builtin/clone.c`, both approved by Patrick Steinhardt in the previous iteration. The patch properly releases filter resources at cleanup time.

This is part of a larger effort to improve promisor remote support, with subsequent patches in the series building on this foundation to implement new features like `--filter=auto`. The change is straightforward and uncontroversial, following established patterns in the codebase.
