Refactoring patch in the promisor-remote series. This is the first patch in v2 of an 8-part series (down from 9 in v1) that enhances Git's promisor remote functionality. The patch extracts common initialization code from `fields_sent()` and `fields_checked()` into a new `initialize_fields_list()` helper function, preparing for additional similar functions to be added later. The change is mechanical and straightforward - it moves the repeated initialization pattern (setting up a string list with strcasecmp comparison and loading config values) into a shared function while maintaining identical behavior. The patch follows the series' established pattern of careful refactoring with static analysis in mind (using initialized flags to prevent multiple config reads). As this is part of a larger effort to improve promisor remote handling, the change aligns with the series' focus on secure storage of remote fields and dynamic filter combination.
