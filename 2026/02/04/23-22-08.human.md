This is an RFC patch proposing to reorganize Git's Rust code into a dedicated `rust/` subdirectory, part of the ongoing Rustification effort. The author, Mike Hommey, provides two motivations: first, that having Rust files in `src/` is too generic for a multi-language project, and second (more pressingly) that the current layout breaks `cargo publish` for git-cinnabar (a Mercurial remote helper that uses Git as a submodule) because cargo skips directories containing Cargo.toml files.

The patch moves all Rust-related files (Cargo.toml, lib.rs, varint.rs, and build scripts) from the root and `src/` into a new `rust/` directory, updating Makefile and meson.build references accordingly. The author acknowledges this is a temporary workaround that will need revisiting when Rust becomes non-optional in Git.

The change is straightforward mechanically, but the RFC framing suggests the author is seeking input on whether this is the right approach before proceeding, particularly given the downstream impact on projects like git-cinnabar. The patch appears well-formed with clean diffs and updates to both build systems.
