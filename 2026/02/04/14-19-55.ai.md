This is patch 3/11 in Derrick Stolee's series introducing a new `git config-batch` builtin, which aims to optimize configuration operations by batching multiple queries/modifications in a single process. The primary motivation is performance improvement for credential management workflows on Windows where individual `git config` calls are slow.

This patch implements the first concrete command for the batch interface - `get` version 1, which provides functionality equivalent to `git config --get` with optional value filtering. The implementation includes:

1. A protocol for `get` requests that supports:
   - Scope specification (system/global/local/worktree/etc)
   - Optional value filtering via exact matches or regex patterns
   - Clear response formats for found/missing values

2. Core parsing infrastructure:
   - Token parsing utilities for the line-based protocol
   - Callback-based config value lookup
   - Scope handling and string conversion utilities

3. Comprehensive test coverage:
   - Basic command parsing errors
   - Inherited config lookups
   - Worktree config scenarios
   - Both regex and exact value matching

The implementation appears solid, with careful attention to protocol design and error handling. The tests demonstrate thorough coverage of the new functionality. This builds on the scaffolding from earlier patches while maintaining the forward compatibility requirements established in the RFC.

Key technical details for future reference:
- Command format: `get 1> <scope> <key> [arg:regex|arg:fixed-value <pattern>]`
- Response formats: `get 1 found <key> <scope> <value>` or `get 1 missing <key> [<value>]`
- Uses existing `repo_config()` infrastructure for actual lookups
- Adds new `CONFIG_SCOPE__NR` enum value for scope validation
- Test file: `t/t1312-config-batch.sh` with extensive scenario coverage

The patch moves the series from prototype to functional implementation while maintaining the careful, incremental approach seen so far. Subsequent patches are expected to add `set` and `unset` commands to complete the core functionality.
