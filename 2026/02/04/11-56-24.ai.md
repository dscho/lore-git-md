Refactoring of the Meson build system to integrate gitk and git-gui, now using symlinks to preserve source layout while meeting Meson's subproject requirements. This patch follows up on Karthik Nayak's review of the v2 series, addressing his question about configurable subproject paths in Meson. Patrick Steinhardt explains that while Meson does support custom subproject locations via the `subproject_dir` parameter, there are intentional restrictions that prevent using the top-level directory - hence the symlink approach remains necessary. The technical constraints include prohibiting absolute paths, dot-prefixed paths, and parent directory references ("../").

The exchange confirms the v2 solution is architecturally sound while identifying a potential area for future Meson improvement. This completes the review cycle for the gitk/git-gui integration, with all major technical concerns now addressed. The only remaining issues are the series' path handling and shell quoting problems noted earlier by Ramsay Jones.
