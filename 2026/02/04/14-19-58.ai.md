This is a documentation patch adding a design document for the new `git config-batch` builtin, part of an 11-patch series aimed at optimizing configuration operations. The series is currently up to patch 6/11, with the first five patches already implementing core functionality including protocol parsing, command handling, and NUL-terminated I/O support.

The new design document outlines the protocol's versioning approach and recommended interaction patterns, emphasizing forward compatibility and the preference for NUL-terminated format in automated contexts. It also lists planned future commands that will expand the tool's capabilities to match `git config`'s full functionality, including `set`, `unset`, and pattern-based operations.

The document serves as both a reference for current implementation status and a roadmap for future development. It maintains the series' focus on performance optimization (particularly for credential management on Windows) while establishing clear versioning and compatibility guidelines. The patch follows Git's documentation conventions and will be updated as more commands are implemented in subsequent patches.
