This is a refactoring patch in the ongoing `the_repository` removal effort, specifically addressing the migration of `core.sparseCheckout` configuration from a global variable to `struct repo_config_values`. The patch is part of an RFC series by Olamide Caleb Bello (an Outreachy intern) with mentorship from Christian Couder and Usman Akinyemi.

Phillip Wood provides a minor style review, noting that new variable declarations should be separated from statements by a blank line in several files (`builtin/clone.c`, `dir.c`, and `sparse-index.c`). The changes themselves are straightforward mechanical conversions from accessing the global `core_apply_sparse_checkout` to using the repository-specific `cfg->apply_sparse_checkout` via the new accessor pattern.

The patch demonstrates the established migration approach for configuration variables in this series, with Phillip's review focusing on code style rather than architectural concerns. This suggests the technical approach has stabilized after earlier discussions about memory management and initialization patterns. The changes touch sparse-checkout functionality across multiple commands (clone, worktree operations, grep) while maintaining the same behavior.
