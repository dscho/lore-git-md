This is a test fix for the `git subtree` contrib script, addressing compatibility with the reftable backend. The patch hardcodes the branch name 'main' in the subtree tests rather than reading it from `.git/HEAD`, which fails with reftable. This is part of the broader effort to expand CI testing of contrib/ components, which has uncovered several compatibility issues.

The change is straightforward - replacing dynamic branch name detection with the hardcoded 'main' that the test already configures via `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME`. This maintains the test behavior while working with reftable. The patch demonstrates both the value of expanded CI testing (catching this issue) and the maintenance challenges of contrib/ scripts as Git evolves.

This fix comes in the context of ongoing work to improve contrib/ testing and prepare for Git 3.0's default branch name transition. While the change itself is small, it's part of a larger conversation about how to handle contrib/ components that may need updates to keep pace with core Git changes like reftable support.
