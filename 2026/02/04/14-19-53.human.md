This is the first patch in an 11-part series introducing a new `git config-batch` builtin, part of a feature proposal to optimize configuration operations. The series comes from Derrick Stolee and is currently in RFC status, seeking feedback on the overall approach.

The patch establishes basic boilerplate for the new command, following Git's standard patterns for adding builtins. It creates the C implementation file, adds build system entries (Makefile and meson.build), documentation stubs, test scaffolding, and updates the command list. The commit also fixes an oversight in builtin.h's instructions by noting the need to update meson.build files when adding new commands.

As the first in a series, this patch doesn't yet implement any functionality - it just sets up the skeleton. The following patches will add the actual batch processing capabilities, documentation, and tests. The overall goal is to improve performance by reducing process startup overhead when making multiple config queries, particularly benefiting credential management workflows on Windows where individual `git config` calls can take 150-200ms each.

The patch looks clean and follows established patterns for introducing new commands. The test included is minimal but appropriate for this scaffolding stage. Reviewers will likely want to see the actual implementation details in subsequent patches before evaluating the overall approach.
