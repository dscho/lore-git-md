This is a follow-up patch in Elijah Newren's series standardizing string list sorting behavior, though submitted by a new contributor (Amisha Chhajed) with Elijah's guidance. The patch targets the help subsystem, specifically the command output formatting in `builtin/help.c`.

The change replaces an explicit deduplication call (`string_list_remove_duplicates()`) with the combined sort-and-deduplicate operation (`string_list_sort_u()`). This ensures consistent behavior matching `sort -u` expectations, addressing a potential future regression point where the deduplication might diverge from the sorting logic. The modification is minimal - just one line changed in the help command's config listing functionality.

The patch appears mechanically sound, following the established pattern from the first patch in the series. It maintains identical output behavior while using the preferred API pattern. Given the straightforward nature of the change and its alignment with the ongoing standardization effort, this seems like a low-risk improvement likely to be accepted. The patch has not yet received review feedback, but the series' previous version also saw no objections.
