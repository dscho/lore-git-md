Bugfix in the ODB abstraction effort, correcting flag usage in `builtin/backfill.c`. This patch fixes a case where the wrong flag type (`OBJECT_INFO_FOR_PREFETCH`) was being passed to `odb_has_object()`, which expects `HAS_OBJECT_*` flags. While the code happened to work by coincidence (due to the specific bit patterns of the flags), Patrick Steinhardt is fixing it to be explicitly correct.

The patch changes the call to pass no flags (0) instead, which results in the same effective behavior since `odb_has_object()` internally uses the desired flags (`OBJECT_INFO_QUICK | OBJECT_INFO_SKIP_FETCH_OBJECT`) when no flags are specified. This is part of Patrick's ongoing work to improve type safety in the object database API, following up on previous discussions about enum usage and flag handling.

The change is minimal (just removing the incorrect flag) and has been verified to maintain the existing functionality while making the code more robust against future changes. This continues the thread's theme of carefully validating and improving low-level object storage APIs, though this particular patch focuses on fixing an actual bug rather than just improving type safety.
