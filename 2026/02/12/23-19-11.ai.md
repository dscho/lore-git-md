This is a documentation patch finalizing warnings about patch roundtrip hazards in Git's email-based workflow. Junio Hamano is queuing Kristoffer Haugsbakk's v3 patch for the `next` integration branch after confirming the text is sound. The patch adds explicit caveats to `format-patch-caveats.adoc` and related man pages about how embedded diffs in commit messages can be misinterpreted during `git am` processing, building on prior discussions of this security vulnerability.

The patch represents one layer of a multi-pronged solution to the long-standing issue where tools can misparse email streams containing both intended patches and commit message content that resembles patch syntax. It complements technical solutions under discussion (boundary markers, strict modes, quoting mechanisms) by clearly documenting the hazard and recommended practices. The documentation changes have now been reviewed by Phillip Wood and approved by Junio, marking the conclusion of this particular documentation thread while the broader technical solutions continue to be developed.
