Feature patch completing Patrick Steinhardt's series improving the `git history` command's UI. This final patch renames the `--ref-action` option to `--update-refs` to better reflect its refined purpose after the previous changes in the series. The option now solely controls which references will be updated (either HEAD or all branches) rather than also dictating the action taken, with dry-run behavior now handled by a separate `--dry-run` flag.

The change updates documentation, command help text, and test cases to use the new option name while maintaining the same functionality. The patch follows the series' pattern of careful attention to both technical implementation (consistent renaming across all affected files) and user experience (clearer option naming). This completes the transition from the more technical `--ref-action` terminology to more intuitive command-line flags that better match user expectations.
