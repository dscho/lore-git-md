This is the final patch in a 9-part series implementing automatic filter configuration for promisor remotes. The patch wires up the `--filter=auto` functionality in clone and fetch operations, completing the LOP (Large Object Promisors) effort.

The key changes enable:
- Automatic filter computation by combining server-advertised specs from accepted promisor remotes
- Persistence of the auto setting in config so future fetches maintain dynamic behavior
- Transport layer support for auto filters
- Comprehensive tests verifying the dynamic filter updates work as expected

The implementation:
- Sets `allow_auto_filter=1` in clone/fetch commands and transport layer
- Modifies fetch-pack to compute and use combined filters when auto is specified
- Updates documentation across clone, fetch and protocol-v2 man pages
- Adds tests showing the filter updates dynamically based on server changes

The patch builds on previous infrastructure from the series (filter storage, API cleanup, documentation) and has been reviewed by Patrick Steinhardt and Jean-Noël Avila. It represents a significant enhancement to partial clone capabilities by allowing servers to suggest optimal filters while maintaining security and backward compatibility.
