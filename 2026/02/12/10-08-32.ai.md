This is a refactoring patch that's part of a larger series enhancing Git's promisor remote functionality. It's the first of nine patches in version 3 of the series.

The patch extracts common initialization code from `fields_sent()` and `fields_checked()` functions in `promisor-remote.c` into a new helper function `initialize_fields_list()`. Both original functions were doing nearly identical setup of string lists for tracking promisor remote fields, differing only in their configuration keys ("promisor.sendFields" vs "promisor.checkFields").

The refactoring is mechanical and straightforward - it moves the shared initialization logic while maintaining the same behavior. This prepares for adding another similar function in a subsequent patch, avoiding further code repetition. The change touches only implementation details in `promisor-remote.c` with no user-visible effects.

As noted in the thread summary, this is a preparatory change for the larger LOP (Large Object Promisors) effort that will introduce new promisor remote features. The patch has already been reviewed and approved in previous iterations of the series.
