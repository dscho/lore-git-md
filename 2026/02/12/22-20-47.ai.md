This is part of an ongoing feature series introducing inter-file navigation to Git's hunk selection interface. The specific discussion here focuses on UI design for the prompt shown when revisiting already-decided hunks.

The author had proposed a compact combined prompt ("What now? (was: n) [y,n,q,a,d,s,e,>,<,p,P,?]?") that shows both the previous decision and current options. Junio expresses concern that users might find the switch between "Stage this hunk" and "What now" phrasing confusing, suggesting instead to rely on existing "(was: X)" indicators and disabled navigation keys as implicit signals of completion.

The author agrees with Junio's assessment and will modify the approach to:
1. Keep the existing "(was: X)" notation for decided hunks
2. Remove the special "What now" prompt in favor of consistent phrasing
3. Add hunk statistics to the help text ('?') to show completion status

This resolves the last major design question in the series. The implementation will now focus on:
- Maintaining consistent prompt phrasing throughout
- Enhancing help text with completion statistics
- Keeping navigation keys disabled when no undecided hunks remain

The discussion shows the author responsive to feedback and willing to simplify the approach in service of clearer user experience. With this settled, the series appears ready for final polishing before potential inclusion.
