This is a follow-up in the ongoing ODB (object database) abstraction cleanup effort, specifically addressing flag parameter types in the `odb_has_object()` API.

Patrick Steinhardt confirms he will send another version of his patch series that converts the flag parameters from unsigned integers to enum types, following Junio Hamano's suggestion. The maintainer had previously expressed reservations about mixing cleanup layers but acknowledged the technical merit of using enums for type safety. This change will affect several commands including `git fsck` and `git backfill` that use these object-info flags.

The exchange shows the careful balance between incremental cleanup and API design decisions in Git's development. While the enum conversion wasn't deemed essential for the initial series, Patrick is taking the opportunity to implement this improvement now rather than leaving it for future work. This reflects the project's typical approach of iterating on patches based on maintainer feedback while keeping series focused.
