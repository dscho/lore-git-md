This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort, specifically focusing on improving type safety for object info flags. The patch converts the `OBJECT_INFO_*` flags from preprocessor macros to a proper enum type, updating all related function signatures to use the new type.

The change makes the API more self-documenting by clearly indicating which functions expect object info flags, and provides limited compiler protection against passing incorrect flag types (though bitwise operations still produce integers that bypass type checking). The patch maintains all existing flag behaviors while adding explicit documentation for each one.

This is the fourth patch in a five-part series that has seen thorough review from Justin Tobler and Karthik Nayak, with Junio Hamano considering broader API design questions. The change is a straightforward improvement to code clarity and type safety as part of the larger ODB abstraction work. The patch appears well-considered and uncontroversial, following established patterns for enum usage in the codebase.
