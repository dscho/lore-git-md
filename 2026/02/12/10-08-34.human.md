This is a refactoring patch in a 9-part series enhancing Git's promisor remote functionality. It's the third patch in version 3 of the series.

The change makes the `filter_options` variable in `builtin/clone.c` local to `cmd_clone()` rather than being a static file-level variable. This is a preparatory cleanup for subsequent patches that will use this variable more extensively. The modification is straightforward - it moves the variable declaration into `cmd_clone()` and passes it as a parameter to the `checkout()` function. The patch includes proper memory cleanup by calling `list_objects_filter_release()` before returning.

The change has been reviewed and approved by Patrick Steinhardt in previous iterations. It's a mechanical refactoring with no behavior changes, serving as groundwork for the more substantial promisor remote enhancements coming later in the series. The patch follows Git's coding style and includes a clear commit message explaining the rationale.
