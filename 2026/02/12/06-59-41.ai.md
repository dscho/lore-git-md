This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort, specifically focusing on type safety improvements for object storage flags. The patch converts the flags used by `odb_has_object()` from anonymous enum bitflags to a proper named enum type (`enum has_object_flags`).

The change helps catch incorrect flag usage at compile time, as demonstrated by the example where passing `OBJECT_INFO_FOR_PREFETCH` (from a different enum) to `odb_has_object()` would now trigger a compiler warning. This follows the same pattern as previous patches in the series that converted other object-info-related flags to proper enums.

The patch is minimal, touching only the function signature in `odb.c` and the declaration in `odb.h`, while maintaining all existing behavior. It builds on earlier work in the series that renumbered the flags and fixed incorrect usage in `builtin/backfill.c`. The change represents another incremental step toward making Git's object storage layer more type-safe and maintainable as part of the broader ODB abstraction effort.

Technical details to note for future reference: the enum defines two flags - `HAS_OBJECT_RECHECK_PACKED` and `HAS_OBJECT_PROMISOR` - which control behavior when checking for object existence. The patch maintains the same bit values (0 and 1) established in previous renumbering work.
