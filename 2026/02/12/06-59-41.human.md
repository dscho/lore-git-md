This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort, specifically focusing on type safety improvements for object storage flags. The patch converts the flags used by `odb_has_object()` from anonymous enum bitfields to a proper named enum type (`enum has_object_flags`).

The change would have caught a previous bug in `builtin/backfill.c` where the wrong flag type was being passed, as the compiler would now generate a warning for such type mismatches. The patch is small and mechanical, touching just the function signature in `odb.c` and the flag declaration in `odb.h`.

This continues the pattern seen earlier in the series of making flag usage more type-safe across the object storage layer. The change maintains backward compatibility while improving compile-time checking. As with previous patches in this series, it demonstrates careful attention to API design in the ODB abstraction work.
