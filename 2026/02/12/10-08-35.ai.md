This is part 4/9 of a v3 series enhancing Git's promisor remote functionality. The patch refactors `builtin/fetch.c` to make the `filter_options` variable local to `cmd_fetch()` rather than being a file-scoped static variable.

The change involves:
- Moving the `filter_options` definition into `cmd_fetch()`
- Passing it through several helper functions (`prepare_transport()`, `do_fetch()`, `backfill_tags()`, `fetch_one_setup_partial()`, and `fetch_one()`)
- Adding proper cleanup with `list_objects_filter_release()`

This is a mechanical refactoring with no behavior changes, approved by Patrick Steinhardt in previous iterations. It improves code organization by clarifying ownership of the filter options and prepares for subsequent patches that will make more use of this variable. The diff shows the straightforward nature of the changes - mostly adding parameters and updating function calls.

This patch follows a similar refactoring done for `builtin/clone.c` in patch 3/9, maintaining consistency across the two commands.
