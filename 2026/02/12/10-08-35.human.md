This is part 4/9 of a v3 series enhancing Git's promisor remote functionality. The patch refactors `builtin/fetch.c` to make the `filter_options` variable local to `cmd_fetch()` rather than being a static global.

The change clarifies ownership of the filter options by moving them into the function scope and passing them explicitly through the call chain. This is a mechanical refactoring with no behavior changes, preparing for subsequent patches that will make more use of this variable. The patch includes proper cleanup with `list_objects_filter_release()` to avoid memory leaks.

This follows the same pattern as patch 3/9 which did a similar refactoring for `builtin/clone.c`. Both changes were approved by Patrick Steinhardt in earlier reviews. The series as a whole is adding new promisor remote features while improving code organization along the way.
