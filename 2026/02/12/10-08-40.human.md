This is the final patch in a 9-part series implementing automatic filter configuration for promisor remotes. The patch wires up the `--filter=auto` option in clone and fetch commands, completing the LOP (Large Object Promisors) effort.

The key changes in this patch:
- Enables `allow_auto_filter` in clone/fetch commands and transport layer
- Implements the auto-filter resolution logic in fetch-pack, combining server-advertised filters from accepted promisor remotes
- Persists the "auto" setting in config so subsequent fetches maintain the behavior
- Adds comprehensive tests verifying the dynamic filter updates work as expected

The implementation ensures security and backward compatibility while providing a smooth workflow - when the server updates its recommended filter, clients will automatically use the new filter on subsequent operations. The documentation is updated across clone, fetch and protocol-v2 man pages to explain the new behavior.

This represents a significant final piece of the LOP functionality, allowing servers to guide clients toward optimal partial clone configurations. The series has undergone thorough review from Patrick Steinhardt and others, with all feedback incorporated across three iterations. The changes are well-tested and documented, making this a solid conclusion to the feature work.
