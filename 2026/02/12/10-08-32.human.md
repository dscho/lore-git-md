This is a refactoring patch that's part of a larger series enhancing Git's promisor remote functionality. It's the first of nine patches in version 3 of the series.

The patch extracts common initialization code from two similar functions (`fields_sent()` and `fields_checked()`) in `promisor-remote.c` into a new helper function called `initialize_fields_list()`. This is a straightforward code cleanup that reduces duplication, making the code more maintainable as the series adds more similar functions in subsequent patches.

The change is mechanical and non-controversial - it doesn't modify behavior, just reorganizes the code. The patch is signed off by Christian Couder, who is actively involved in this series along with reviewers Patrick Steinhardt and Jean-Noël Avila. As the first patch in the series, it sets up for more substantive changes to come in later patches that implement new promisor remote features.
