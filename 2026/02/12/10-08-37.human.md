This is part 6 of a 9-patch series implementing the LOP (Large Object Promisors) effort, focusing on adding infrastructure for a new `--filter=auto` mode. The patch introduces core support for the "auto" filter option while maintaining safety and backward compatibility.

The changes add a new `LOFC_AUTO` filter choice and an `allow_auto_filter` flag to control which commands can accept this special filter mode. The implementation includes:
- Strict validation to prevent combining "auto" with other filters
- A BUG() check to ensure "auto" gets resolved before actual filtering
- New unit tests verifying the parsing behavior
- Careful memory management preserving the auto-filter flag during resets

The patch follows the series' pattern of mechanical preparation work before the actual feature implementation in later patches. It has been reviewed by Patrick Steinhardt, with Christian Couder addressing feedback about error message formatting. The changes are cleanly separated from the rest of the series and maintain the project's coding standards.

This is a well-structured infrastructure patch that lays groundwork for the more user-visible changes coming in patch 9/9. The test coverage is thorough, and the implementation appears robust with its multiple safety mechanisms.
