Build system patch for macOS credential helper. This is version 2 of a change to move build targets for `git-credential-osxkeychain` from its local Makefile to the top-level Makefile. The motivation stems from recent macOS-specific build changes (Homebrew configuration and iconv workarounds) that broke the standalone build when linking against libgit.a.

The patch centralizes the build logic in the main Makefile while preserving the required Security/CoreFoundation framework linkages. Key changes include:
- Adding new top-level targets for building, installing, and cleaning the credential helper
- Simplifying the local Makefile to delegate operations to these targets
- Using `$(MAKE) -C` instead of direct `cd` commands per Junio Hamano's feedback from v1

The change follows the pattern of other credential helpers and addresses the fragility of maintaining macOS-specific flags in multiple places. The thread shows consensus on the approach, with only minor technical refinements needed from the initial version. This should resolve the build issues while making future maintenance easier.
