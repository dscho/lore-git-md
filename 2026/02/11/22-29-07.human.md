This is the first patch in the final v4 series implementing UTF-8 support for Git configuration subsections, specifically focusing on alias definitions. The patch refactors the alias listing logic to consolidate duplicate code between `alias.c` and `help.c`.

The change moves the alias value parsing entirely into `alias.c` by enhancing `list_aliases()` to store values via the string_list util field, eliminating the need for a separate callback in `help.c`. This also fixes a subtle bug where "git --list-cmds=alias" previously included broken (value-less) aliases but now properly rejects them with an error.

Junio Hamano has reviewed and approved the change, noting it can be considered a bugfix. The patch includes new test coverage verifying error handling for value-less aliases. This preparatory refactoring sets up the subsequent patches in the series which will add UTF-8 subsection support.

The implementation maintains all existing error checking while cleaning up the code structure. With this final iteration, all technical feedback has been addressed and the series is ready for merging.
