This is the final patch in Patrick Steinhardt's CI/build system series improving test infrastructure for Windows/MSVC builds under Meson. The patch completes the standardization between GitLab and GitHub CI by adding proper test failure handling for the MSVC+Meson job on GitLab CI.

The change ensures that when tests fail in the MSVC+Meson job on GitLab CI, the system will now:
1. Print details of failing tests using the existing `ci/print-test-failures.sh` script
2. Collect and preserve test artifacts in `t/failed-test-artifacts`
3. Make these artifacts available when the job fails

The implementation matches GitHub CI's existing behavior for MSVC+Meson tests, using Git for Windows' bash installation to run the test failure reporting scripts. The patch modifies the GitLab CI configuration to set up proper test output directories and adds the failure handling logic in the `after_script` section.

This completes the series' goal of standardizing test execution and failure handling across both GitLab and GitHub CI systems for Windows/MSVC builds. The changes are focused on the GitLab CI configuration file (`.gitlab-ci.yml`), with no other files affected in this final patch.
