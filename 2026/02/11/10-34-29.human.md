This is part 3 of Patrick Steinhardt's 7-patch series improving CI test infrastructure, specifically addressing Windows/MSVC builds using Meson. The patch fixes an issue where `git mergetool --tool-help` fails on Windows when tests are run with `--no-bin-wrappers` (a performance optimization that avoids spawning expensive shell processes).

The problem occurs because the merge tool directory path isn't properly set when bypassing the bin-wrappers. The patch ensures the `MERGE_TOOLS_DIR` environment variable is always set to the correct source directory location in the Meson build configuration. This fixes test failures that were previously unnoticed because Windows CI jobs weren't properly executing the tests.

The change is straightforward - a single line addition to the Meson build file that sets the environment variable. This is a clear bugfix that aligns Meson's behavior with the Makefile build system's handling of merge tools. The patch is well-explained with background on why the issue occurred and why it went undetected.
