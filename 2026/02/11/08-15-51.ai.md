This is a documentation and implementation discussion thread about the `format.noprefix` configuration option, with Kristoffer Haugsbakk now taking on the implementation fix after Jeff King identified the core issue.

The thread has evolved from initial documentation concerns to uncovering an implementation bug where `format.noprefix` incorrectly accepts any value rather than properly interpreting boolean values. Jeff King has done the diagnostic work and proposed using `git_config_bool()` for standard boolean parsing, passing the implementation baton to Kristoffer.

Kristoffer confirms he will work on the fix, acknowledging that the hard part (identifying the problem) is already done. This continues the collaborative pattern seen throughout the thread, where different contributors tackle different aspects: version attribution (Alejandro Colomar), documentation (Kristoffer), and now implementation (Kristoffer with Jeff's guidance).

The technical context remains: `format.noprefix` was added in v2.41.0 (correcting earlier misattribution to 2.39.5) to control prefix stripping in `git format-patch`, but its current any-value acceptance violates Git's standard boolean configuration convention. The fix will align it with `diff.noprefix`'s boolean behavior while maintaining backward compatibility for existing configurations. The man page patch for `futex_waitv.2` serves as a test case demonstrating the version-dependent behavior.
