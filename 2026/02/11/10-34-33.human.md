This is the final patch in Patrick Steinhardt's CI/build system series improving test infrastructure for Windows/MSVC builds under Meson. The patch completes the standardization between GitLab and GitHub CI by adding proper test failure handling for the MSVC+Meson job on GitLab CI.

The change ensures that when tests fail in the MSVC+Meson job, GitLab CI will now properly report the failures by printing them and uploading artifacts, matching the behavior already present in GitHub CI. The patch adds a TEST_OUTPUT_DIRECTORY variable, creates the directory in the before_script, and adds an after_script that runs the failure reporting logic when the job isn't successful.

This is a straightforward improvement that brings parity between the two CI systems' handling of test failures. The series as a whole has systematically addressed test infrastructure reliability across platforms, with this final patch closing the last gap in the Windows/MSVC test reporting workflow.
