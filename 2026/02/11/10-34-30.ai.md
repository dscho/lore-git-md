This is a CI/build system patch in Patrick Steinhardt's series improving test infrastructure reliability, specifically addressing Windows/Meson test execution on GitHub CI. 

The issue fixes a silent failure where Meson tests weren't actually running on Windows GitHub CI jobs because the workflow incorrectly used PowerShell (`pwsh`) to execute a POSIX shell script (`ci/run-test-slice-meson.sh`). The patch simply changes the shell specification to `bash` for this step, matching how other shell script steps are handled in the workflow. 

The change is minimal (one line in `.github/workflows/main.yml`) but important - it ensures the test slicing mechanism actually executes on Windows CI rather than silently doing nothing. This connects to the series' broader theme of making test execution more reliable and properly diagnosed across CI environments, particularly for the Meson build system. The fix is straightforward and clearly correct, addressing a gap that was likely missed during initial Meson CI integration.
