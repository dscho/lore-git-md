This is a refactoring patch that consolidates alias listing logic between `alias.c` and `help.c` as part of the UTF-8 alias support series. The patch moves the alias value parsing responsibility entirely to `alias.c` by enhancing `list_aliases()` to store values via the string_list util field, eliminating the duplicate `get_alias()` callback in `help.c`.

Key technical changes:
- Modifies `config_alias_cb()` in `alias.c` to handle NULL values by calling `config_error_nonbool()` immediately
- Adds value storage via `string_list->util` when listing aliases
- Removes the now-redundant `get_alias()` function from `help.c`
- Updates `list_all_cmds_help_aliases()` to use the consolidated `list_aliases()`
- Adds a new test case verifying error reporting for value-less aliases

The changes maintain all existing error checking while centralizing the alias parsing logic. This preparatory refactoring enables the subsequent UTF-8 subsection support patches to work with a single unified alias handling implementation. The patch has been reviewed by Jeff King and Junio Hamano in previous iterations, with the NULL value handling resolution being the final piece addressed in v4.
