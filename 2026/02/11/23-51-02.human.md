This is a build system patch addressing dependency tracking in the Meson build for `config-list.h`, which is generated from Git's documentation files. The patch ensures the header gets rebuilt when either the documentation files or the generator script itself changes.

The issue surfaced when stale builds caused test failures, particularly in `t9902-completion.sh`, because config option additions weren't being properly reflected. D. Ben Knoble's solution builds on Patrick Steinhardt's suggestion to use Meson's depfile feature, with the generator script now producing both the header and a dependency file tracking all inputs.

The patch handles several edge cases: it includes the generator script as a dependency, properly escapes special characters in filenames, and ensures the build system catches both content changes and file additions/removals. While the implementation appears solid, Knoble notes some uncertainty about exact escaping behavior for certain edge cases in Ninja's depfile format.

This is the third iteration of the patch, with previous versions having been refined through discussion with Patrick Steinhardt and Phillip Wood. The thread has converged on this approach as the right balance between correctness and build performance.
