This is a brief follow-up in the ongoing LOP (Large Object Promisors) patch series discussion. Junio C Hamano weighs in on a naming question from Patrick Steinhardt regarding how to label the set of filters that have been accepted from those advertised by the server. 

Junio agrees with Patrick's suggestion that "accepted_filters" would be a better name than the current "advertised_filters" to clearly distinguish between all filters offered by the server versus those actually selected for use. His comment indicates approval of this naming change, which helps clarify the relationship between advertised and accepted filters in the promisor remote implementation.

This small naming refinement comes as part of the broader effort to implement `--filter=auto` functionality and improve promisor remote configuration handling. The exchange shows the maintainer engaging with the technical details while letting the primary contributor (Patrick) drive the implementation decisions.
