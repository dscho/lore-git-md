Security patch series from Tian Yuchen hardening Git's repository discovery by validating `.git` file types, currently at v4. The series addresses security issues where Git could attach to parent repositories through malformed `.git` entries (FIFOs/sockets) while maintaining legitimate symlink support. Core changes focus on `setup.c` and `setup.h`, introducing refined error taxonomy in `read_gitfile_gently()` with four distinct cases: missing paths (continue searching), directories (check validity), non-files (reject FIFOs/sockets), and other errors (fatal).

Key technical implementation:
- Uses `stat()` instead of `lstat()` for `.git` checks to allow symlinks to directories
- Explicitly rejects dangerous `.git` entry types with clear errors
- Comprehensive test coverage in `t/t0009-git-dir-validation.sh` verifies:
  - Valid symlinked directories
  - Rejection of FIFOs/sockets
  - Edge cases (garbage content, empty dirs)
