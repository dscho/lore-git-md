This is the cover letter for the second version of Patrick Steinhardt's CI/build system patch series, now complete at 7 patches. The series aims to standardize and improve test infrastructure reliability across GitLab and GitHub CI environments, with particular focus on Windows/MSVC builds using Meson.

The final patch adds MSVC+Meson test failure handling to GitLab CI to match GitHub CI's behavior.

The series represents a comprehensive overhaul of test infrastructure, standardizing test-slicing logic (using one-based numbering across build systems), improving failure diagnostics, and ensuring consistent Meson test execution between CI providers. Patrick has tested the changes on both GitLab and GitHub CI systems, indicating the series is now ready for integration. This appears to be the final piece in making Git's test infrastructure robust across platforms, particularly for Windows/MSVC builds.
