This is a CI/build system patch fixing test infrastructure reliability, part of Patrick Steinhardt's v2 series improving cross-platform CI testing. The patch addresses a subtle issue where the test-slicing helper's error codes were being ignored due to its placement in a pipeline. By first capturing the output in a variable, failures in the slicing logic will now properly propagate.

The change is small but meaningful - it modifies `ci/run-test-slice.sh` to store the sliced test list before passing it to make, rather than piping directly. This ensures any errors from the test-tool (like invalid slice parameters) will be caught rather than silently ignored. The patch demonstrates Patrick's attention to robust infrastructure - even edge cases in test execution are being hardened.

As the first in a 7-part series, this sets the tone for the overall effort: precise fixes to CI reliability, particularly around test execution is handled across different platforms and build systems. The change is straightforward and unlikely to be controversial, serving as groundwork for more complex CI improvements later in the series.
