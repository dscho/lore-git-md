This is part 6 of a 7-patch series improving CI test infrastructure, specifically targeting Windows/MSVC builds using Meson. The series aims to standardize test execution across different CI environments (GitHub and GitLab) and improve reliability.

Patch 6 standardizes the test slicing implementation between GitLab CI and GitHub workflows by making GitLab CI use the same `run-test-slice-meson.sh` script that GitHub already uses, rather than open-coding the Meson test parameters. This ensures consistent behavior across both CI systems.

The change is straightforward - it replaces the direct Meson test invocation in GitLab CI with a call to the shared script, using bash to execute it (since GitLab CI on Windows uses PowerShell by default). This matches the approach already working in GitHub Actions.

The patch is part of Patrick Steinhardt's ongoing effort to improve cross-platform CI reliability. It builds on previous patches in the series that standardized test numbering and fixed various edge cases in test execution. The changes are focused on infrastructure rather than test content itself, and appear to be a logical next step in the standardization effort.
