CI/build system patch fixing Windows Meson test execution in GitHub CI.

This is the fourth patch in Patrick Steinhardt's series improving CI test infrastructure reliability, particularly for Windows/MSVC builds using Meson. The patch fixes a subtle but critical issue where Windows test jobs in GitHub CI weren't actually running - the test script was being passed to PowerShell (pwsh) rather than bash, causing silent failure. The fix is straightforward: switch the shell to bash for this step, matching how other shell script steps are handled.

The patch demonstrates the kind of cross-platform gotcha that frequently surfaces in CI systems - a POSIX script being handed to the wrong shell interpreter. While the change itself is small (a one-line switch from pwsh to bash), it's part of the larger effort to make Git's test infrastructure more robust across different environments. The series as a whole shows careful attention to detail in ensuring tests actually run as intended, particularly for the newer Meson build system on Windows.
