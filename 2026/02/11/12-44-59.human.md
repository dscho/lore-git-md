Performance fix for pack-objects when merging promisor packs. This patch from Patrick Steinhardt addresses an issue where `git pack-objects --stdin-packs` could unnecessarily fetch objects during geometric repacking of promisor packs (those containing objects promised by a partial clone).

The problem arises because the command performs a best-effort rev walk to improve delta selection, and this walk would trigger backfill fetches for any missing promised objects. The fix is simple: disable fetching during this walk since the names are only a heuristic anyway. The patch includes a test verifying no fetches occur.

This is a focused, well-explained change that solves a real performance problem in large repositories using partial clones. The commit message clearly describes the issue, the solution, and includes a helpful test case. It builds on recent work (dcc9c7ef47) to handle promisor packs during geometric repacking.
