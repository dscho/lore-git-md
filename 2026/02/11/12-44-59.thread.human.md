This thread documents the approval of Patrick Steinhardt's performance optimization for `git pack-objects` in partial clone scenarios, which prevents unnecessary object fetches during geometric repacking of promisor packs. The change addresses a regression introduced by commit dcc9c7ef47, where delta selection heuristics were triggering unwanted backfill fetches during pack merging operations.

The solution temporarily disables fetching during the specific rev walk used for delta selection, using a global variable that's safe since only one pack operation runs at a time. Jeff King provided initial review focusing on test coverage, while Taylor Blau supported the optimization's value for large repositories. Junio Hamano has now approved the final version after a minor typo fix ("passe" -> "pass"), and the patch will be included in the next release. The change is particularly impactful for large repositories using partial clones, demonstrating how a focused optimization can address a concrete performance regression with minimal code changes.
