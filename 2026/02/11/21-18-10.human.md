This is the final patch in a three-part series implementing UTF-8 support for Git configuration subsections, specifically for aliases. The patch adds support for non-ASCII alias names using the subsection syntax (e.g., `[alias "förgrena"]`), while maintaining backward compatibility with the existing case-insensitive ASCII-only syntax.

The implementation allows arbitrary Unicode characters in subsection-based aliases while keeping the traditional syntax limited to ASCII alphanumerics and dashes. The patch includes comprehensive documentation explaining both syntax forms, with clear examples. It also updates the help` subsystem to properly list and display UTF-8 aliases using `utf8_strwidth()` for correct column alignment.

Key technical aspects include:
- Case-sensitive matching for subsection aliases vs case-insensitive for traditional syntax
- Strict validation of config keys using `parse_config_key()`
- Proper handling of NULL values in config callbacks
- Extensive test coverage including Swedish, CJK, and space-containing aliases
- Documentation updates explaining the two syntax forms and their differences

The series has gone through multiple iterations with feedback from Jeff King and Junio Hamano, and all technical concerns (including NULL value handling) have been addressed. The implementation appears solid with thorough test coverage, though Windows support remains a known limitation for future work. This is the final version ready for merging.
