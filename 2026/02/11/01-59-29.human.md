Build system improvement for macOS credential helper. This is version 2 of a patch that moves the build targets for `git-credential-osxkeychain` from its local Makefile to the top-level Makefile. The change addresses build failures that occurred after recent macOS-specific refinements to the top-level build configuration (Homebrew paths and iconv workarounds) weren't being properly inherited by the credential helper.

The patch follows the pattern of other credential helpers by centralizing the build logic while maintaining the required Security/CoreFoundation framework linkages. Junio C Hamano provided feedback on the first version, suggesting standard Makefile practices (using `$(MAKE)` and `-C` flags) which have now been incorporated. The approach has consensus and appears ready for merging once this version is reviewed.
