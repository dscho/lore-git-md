This is the second patch in a 3-part series implementing UTF-8 support for Git configuration subsections, specifically focused on alias definitions. The patch prepares for the new subsection syntax by refactoring the alias parsing logic in `help.c` to use `parse_config_key()` instead of `skip_prefix()`. 

The change makes the config parser stricter - it will now silently ignore malformed `alias.<subsection>.<key>` entries unless the key is "command" (which will be used in the next patch). The commit message clearly explains this as a compatibility break that fixes what was arguably a bug in the overly permissive previous behavior.
