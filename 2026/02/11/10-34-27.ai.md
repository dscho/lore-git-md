CI/build system patch fixing test-slicing helper error handling in CI infrastructure.

This is the first patch in Patrick Steinhardt's v2 series improving CI test reliability, particularly for Windows/MSVC builds using Meson. The change fixes a subtle issue where the test-slicing helper's error codes were being ignored due to its execution being part of a pipe in `ci/run-test-slice.sh`. The patch stores the test list in a variable first before processing, making the pipeline more robust by properly capturing the helper's exit code.

The change is small but important - it modifies the test execution pipeline to first capture the sliced test list from `./helper/test-tool path-utils slice-tests` before passing it to `make`. This ensures any failures in the slicing operation itself will be properly detected rather than silently ignored. The patch demonstrates Patrick's attention to detail in CI infrastructure, catching an edge case that could mask test setup problems.

This builds on the ongoing effort to standardize and improve test execution across Git's CI platforms (GitLab and GitHub). While the change is mechanical, it's part of a larger series addressing Windows/MSVC test reliability under Meson, showing the incremental nature of CI infrastructure improvements.
