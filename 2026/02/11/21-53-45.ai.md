This is the second patch in a 3-part series implementing UTF-8 support for Git configuration subsections, specifically focusing on alias definitions. The patch refactors the alias parsing logic in `help.c` to use `parse_config_key()` instead of `skip_prefix()`, which properly handles the three-level config key structure needed for the upcoming subsection syntax.

The change introduces a compatibility break by no longer accepting malformed "alias.subsection.key" entries unless the key is "command" (which will be used in the next patch). The author and reviewers agree this was effectively a bug fix since dotted aliases were never intentionally supported. The patch is well-explained and maintains all existing functionality while preparing for the new subsection syntax.

Key technical details:
- Replaces `skip_prefix()` with `parse_config_key()` in `help.c`
- Silently ignores malformed "alias.subsection.key" entries (except when key is "command")
- Preserves the ability to list aliases while adding stricter validation
- Part of a logical progression where this preparatory refactoring enables the main feature in the next patch
