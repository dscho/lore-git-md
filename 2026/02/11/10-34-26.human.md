This is a CI/build system patch series from Patrick Steinhardt addressing several issues in Git's test infrastructure across both GitLab and GitHub CI systems. The series focuses on improving test execution reliability and failure diagnostics, particularly for Windows/MSVC builds using Meson.

The key improvements include fixing test slicing issue that was skipping the first test, standardizing Meson test execution between CI platforms, and adding better failure handling to surface test artifacts and logs when tests fail. The changes touch both GitLab and GitHub CI configurations, test helper scripts, and Meson build files.

This appears to be a well-motivated series addressing real pain points in CI debugging. The patches are focused and come with testing evidence from both CI platforms. The changes are primarily infrastructure-focused and unlikely to be controversial, though they may be of particular interest to Windows developers and CI maintainers. The series builds on previous work (referenced in the cover letter) that fixed underlying test failures these improvements now help surface.
