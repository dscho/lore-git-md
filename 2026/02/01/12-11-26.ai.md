Documentation patch continuing Jean-Noël Avila's standardization effort, with Kristoffer Haugsbakk providing detailed review feedback. This iteration focuses on `git-clone` and `for-each-ref-options` man pages, refining AsciiDoc formatting and consistency.

Key changes include converting `--[no-]reject-shallow` to explicit `--reject-shallow`/`--no-reject-shallow` forms, using proper AsciiDoc `NOTE:` macros instead of manual `*NOTE*` markup, and standardizing placeholder formatting (e.g., `_<when>_`). The patch also converts option descriptions to imperative mood ("Do not checkout" instead of "No checkout") and improves phrasing to avoid "When given" introductions.

Haugsbakk's review confirms the changes are correct and notes one remaining inconsistency between stuck (`--option=<value>`) and unstuck (`--option <value>`) long option forms that may need future alignment with gitcli(7) recommendations. The review also verifies cross-toolchain compatibility between asciidoc.py and asciidoctor.

This is part of the ongoing documentation standardization effort that systematically improves consistency across Git's man pages without altering command behavior. The collaboration between Avila and Haugsbakk demonstrates the project's meticulous attention to documentation quality, with each iteration refining formatting details.
