Thread summary:

Bugfix for clone command's handling of `--revision` with protocol v0/v1, addressing a segmentation fault when using shorthand revision names (e.g. `--revision master` instead of full ref path). The issue occurs because older protocols fetch all references without filtering, potentially leaving `remote_head_points_at->peer_ref` NULL during reference updates. The fix adds a NULL check in `builtin/clone.c` before updating HEAD. The patch explains the protocol version behavior differences but lacks a regression test case. The bug affects real-world usage where shorthand revision names are common with older protocols.
