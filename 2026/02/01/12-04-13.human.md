This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git's man pages to synopsis-style AsciiDoc format. Kristoffer Haugsbakk provides feedback on the `git-clone` documentation conversion, focusing on consistent formatting of command-line options.

Haugsbakk notes that the patch correctly switches to using backticks for option names now that the synopsis style handles placeholder rendering automatically. He points out that while not urgent, the documentation should eventually standardize on the "stuck form" (`--option=<value>`) for long options as recommended in gitcli(7), since the current text mixes stuck and unstuck forms.

The reviewer confirms that the changes look good overall, with one minor observation about option parsing behavior - noting that the stuck form (`--config=<key>=<value>`) does work in practice despite the multiple equals signs. This continues the project's meticulous attention to documentation detail, though the changes are purely presentational with no impact on actual command behavior.
