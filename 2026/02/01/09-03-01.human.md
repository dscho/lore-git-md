Documentation patch providing style feedback on the `git submodule foreach` flag documentation. This is the final patch in a series adding new traversal options for submodule processing.

Jean-Noël Avila, who maintains Git's documentation style consistency, reviews William Hatfield's documentation for the new `--reverse-traversal`, `--append-superproject`, and `--reversive` flags. He notes that the submodule documentation is being converted to the "synopsis" style of AsciiDoc markup and provides specific feedback on formatting and phrasing. The key points are to use backticks around option names in descriptions and to restructure the text to lead with the option's action before its conditions and rationale.

This is a straightforward documentation polish that doesn't affect the functionality added in the previous patches. The changes align with Jean-Noël's ongoing effort to standardize Git's man page style. The feedback is constructive and focused on presentation rather than technical content, which should be easy for the original author to incorporate in a v2.
