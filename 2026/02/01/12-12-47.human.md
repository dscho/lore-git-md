This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git's man pages using AsciiDoc synopsis-style formatting. Kristoffer Haugsbakk provides a detailed review of the changes to `git-show.adoc` and `pretty-formats.adoc`, confirming the conversion to consistent backtick-wrapped command references and proper placeholder formatting.

The review notes several improvements: conversion of manual `*NOTE*` markup to AsciiDoc macros, standardized option presentation (avoiding `--[no-]` shorthand), and proper handling of placeholders with `_<placeholder>_` syntax. Haugsbakk verifies the HTML rendering looks correct for the new synopsis blocks while noting one remaining inconsistency in long option formatting (stuck vs. unstuck forms) that may need future alignment.

The changes are strictly presentational - no command behavior is altered. This continues the meticulous, incremental work to bring all documentation to a uniform standard, with Haugsbakk providing thorough review feedback on both markup correctness and rendering quality. The collaboration demonstrates the project's attention to documentation quality, though Haugsbakk notes he doesn't verify the man page output directly due to toolchain setup challenges.
