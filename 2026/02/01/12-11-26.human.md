This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git's documentation format. Kristoffer Haugsbakk provides a detailed review of changes to `git-clone.adoc` and `for-each-ref-options.adoc`, confirming the conversion to consistent AsciiDoc syntax.

The changes focus on presentation improvements: converting `--[no-]` shorthand to explicit `--option`/`--no-option` pairs, using proper AsciiDoc `NOTE:` macros instead of manual `*NOTE*` markup, fixing placeholder formatting (like `_<when>_`), and rewriting option descriptions in imperative mood. Haugsbakk notes these are all correct conversions and checks for any remaining inconsistencies.

One subtle point is the difference between "stuck" (`--option=<value>`) and "unstuck" (`--option <value>`) long option forms in the documentation, which Haugsbakk suggests may need future alignment with gitcli(7) recommendations. The review also confirms cross-toolchain compatibility between asciidoc.py and asciidoctor processors.

This is part of a well-established documentation standardization effort where Avila and Haugsbakk have developed an effective collaboration pattern - Avila makes the bulk changes and Haugsbakk provides meticulous review feedback. The changes are purely presentational and don't affect any command behavior.
