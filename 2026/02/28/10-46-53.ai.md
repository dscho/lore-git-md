This is a follow-up patch in the ongoing effort to standardize string list sorting behavior across Git commands, specifically addressing an issue in the help command's implementation.

The patch from Amisha Chhajed focuses on cleaning up how `keys_uniq` is constructed in `builtin/help.c`, removing its problematic dependency on the sort operation of `keys`. The core issue is that reproducing this dependency in tests is complex because it requires rebuilding Git to update the `config-list.h` array that's baked into the binary. The patch includes changes to both the help command implementation and its test suite.

The technical changes involve restructuring 84 lines in `builtin/help.c` and updating 26 lines of test code in `t/t0012-help.sh`. The modifications aim to preserve existing behavior while making the implementation more robust. The author has tried multiple approaches to create a reliable test case (including direct file operations and applying existing patches) but found the test environment constraints make this particularly challenging.
