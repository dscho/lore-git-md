This is a refinement patch in a series standardizing string list sorting behavior across Git commands, specifically focusing on the help command's implementation. Authored by Amisha Chhajed with Elijah Newren's oversight, it follows up on earlier work to ensure consistent sorted+deduplicated output matching `sort -u` behavior.

The patch restructures `builtin/help.c` to remove a dependency where `keys_uniq` construction relied on the sort order of `keys`. The new implementation moves sorting after processing, guaranteeing proper ordering regardless of input. The changes include extracting helper functions (`set_config_vars` and `set_config_sections`) to improve readability and maintainability.

Test updates accompany the changes, replacing `grep` with `sed` and adjusting pattern matching to be more precise. The modifications preserve the existing behavior while making the implementation more robust - a sensible refinement given the command's role in configuration discovery.

This iteration addresses testability concerns raised in previous reviews while maintaining the architectural approach approved in the v3 merge. The changes are focused and well-contained, touching 84 lines in the main implementation and 26 in tests. It represents a solid incremental improvement to the ongoing standardization effort.
