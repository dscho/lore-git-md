This is Junio C Hamano's "What's cooking in git.git" report for February 2026, providing an update on the state of various topics in the Git project's development branches. Several notable patches have graduated to 'master', including test cleanups, documentation updates, and UI improvements for commands like `git history reword`. Ongoing efforts include the continued removal of `the_repository` global variable usage, Rust interoperability work for SHA-1/SHA-256 mapping, and MIDX/bitmap improvements for incremental repacking. The report notes several topics that are awaiting review responses or final rerolls before potential merging.
