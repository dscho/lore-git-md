This is a documentation patch in Kristoffer Haugsbakk's series about `format.noprefix` behavior. Jean-Noël Avila (the French translation maintainer) provides feedback on how to structure the documentation changes to better support translations.

The key issue is that the original patch split a single sentence across conditional blocks (`ifdef`/`ifndef`), which makes translation difficult. Jean-Noël confirms that Kristoffer's revised approach - using complete paragraphs in each conditional block - is translation-friendly, though he notes a minor syntax error (an incorrect `ifndef` that should be `endif`) and questions the need for an explicit translator comment.

The discussion shows good collaboration between the patch author and documentation experts to ensure the changes work well for internationalization. This is a small but important refinement to the series, which has already been reviewed and queued by Junio. The exchange demonstrates how Git's documentation maintainers pay attention to details that affect translation workflows.
