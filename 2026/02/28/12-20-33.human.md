This is a documentation patch addressing translation concerns in the `format.noprefix` configuration documentation. Kristoffer Haugsbakk responds to feedback from Jean-Noël Avila about how AsciiDoc conditionals were making the text difficult to translate by restructuring the documentation to keep complete sentences intact.

The patch replaces a conditional that split a single sentence with two complete versions of the text - one for `git-format-patch` context and one for other contexts. This maintains the same information while being more translation-friendly. A comment is added to help translators about the intentional duplication.

The change shows good responsiveness to reviewer feedback about an important but easily overlooked aspect of documentation - how it will be handled in translation workflows. While the technical content remains the same, the presentation is more maintainable for the l10n team. The patch is already in Junio's `next` branch, indicating it has passed review.
