This is a follow-up to a refactoring patch in the `the_repository` removal effort, addressing feedback from the maintainer. The original patch attempted to move the `warn_on_object_refname_ambiguity` flag from a global variable to the `repo_settings` struct, but Junio Hamano pointed out this is actually a user preference that should remain process-wide rather than being repository-specific.

The v2 patch reverts those changes and instead simply adds a clarifying comment to the global variable declaration in environment.c, noting that this is a "process-wide user preference". This addresses the core of Junio's concern while still documenting the variable's purpose for future contributors. The change is minimal - just a one-line comment addition alongside the existing variable declaration.

This shows good responsiveness to maintainer feedback - the author quickly pivoted from the initial approach once the architectural mismatch was pointed out. The patch is now correctly aligned with Git's configuration model where user preferences (as opposed to repository-specific behaviors) should be stored at the process level. The comment addition is a small but useful improvement to the codebase's documentation.
