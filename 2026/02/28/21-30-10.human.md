This is a documentation clarification in response to a user request about the deprecated `git whatchanged` command. Kristoffer Haugsbakk provides a more detailed explanation than the original deprecation warning, showing how to replicate `whatchanged`'s behavior using `git log` flags and suggesting alternative output formats that may be more readable.

This provides a clear migration path for users who want to keep the familiar command name while using the modern implementation.

The response is technically accurate and maintains the project's position that `whatchanged` should be deprecated, while being more constructive than the original warning by offering specific alternatives.
