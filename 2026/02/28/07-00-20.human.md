Test suite improvement fixing exit code handling in t/t3700-add.sh. This is the second version of a patch that addresses hidden test failures by properly capturing git command exit codes and using Git's test helper infrastructure.

Siddharth Shrimali's patch converts several test cases in t/t3700-add.sh that were piping git commands directly into grep, which could mask failures by suppressing exit codes. The new version addresses Junio Hamano's review feedback by:

1. Replacing raw grep calls with test_grep for better debuggability (automatically showing failed output)
2. Simplifying negative assertions using test_grep ! instead of counting lines with wc -l
3. Maintaining the same test semantics while making failures more visible

The changes affect 15 test cases, mostly mechanical conversions from patterns like `git ls-files | grep` to `git ls-files >out && test_grep out`. The patch looks well-considered, addressing all the edge cases Junio noted in the initial review while keeping the test logic intact. This aligns with Git's ongoing effort to improve test reliability through proper exit code handling and use of test helpers.
