This is a refactoring patch as part of the ongoing `the_repository` removal effort. It updates commit formatting functions to take an explicit repository parameter rather than relying on the global `the_repository` variable.

Tian Yuchen's patch modifies `pretty_print_commit()` and `pp_commit_easy()` to accept a `struct repository*` parameter, allowing them to access encoding settings via the repository-specific `repo_settings` rather than global state. The changes propagate through 15 files across various builtin commands and helper functions that handle commit formatting.

The patch maintains backward compatibility by falling back to `the_repository` for callers that don't yet have repository context available (like in `bundle.c`). This follows the established pattern for incrementally migrating away from global variables while keeping the code functional during the transition.

The changes are mechanical but widespread, touching commit display functionality in commands like `log`, `show-branch`, `stash`, and the sequencer. The patch appears well-scoped and follows the project's conventions for this type of refactoring, though reviewers will likely want to verify all call sites properly handle NULL repository pointers in the fallback cases.
