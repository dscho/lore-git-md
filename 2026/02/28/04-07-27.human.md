This is a refactoring patch that's part of the ongoing `the_repository` removal effort. Tian Yuchen proposes moving two global encoding-related variables (`git_commit_encoding` and `git_log_output_encoding`) into `struct repo_settings` to support repository-specific encoding configurations and enable lazy loading.

The patch introduces new API functions `repo_get_commit_output_encoding()` and `repo_get_log_output_encoding()` that take a repository parameter, updating all callers to use these instead of the global variables. For builtin commands and core functions without repository context, it falls back to `the_repository`. The change also ensures CLI encoding overrides (like `--encoding`) take precedence over lazy-loaded settings.
