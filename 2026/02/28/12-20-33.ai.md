This is a documentation patch addressing translation workflow concerns raised in the ongoing `format.noprefix` series. Kristoffer Haugsbakk responds to feedback from Jean-Noël Avila about how AsciiDoc conditionals were making the documentation harder to translate by splitting sentences into fragments.

The patch restructures the `diff-options.adoc` content to present complete paragraphs under each conditional block rather than interleaving conditionals mid-sentence. This maintains the context translators need while still preserving the original goal of showing `format.noprefix` in format-patch contexts and `diff.noprefix` elsewhere. A comment explicitly marks the variation point for translators.

The change demonstrates responsiveness to internationalization concerns while keeping the technical accuracy of the previous version. The thread shows consensus on the approach, with Jean-Noël Avila's expertise in documentation translation guiding the solution. This patch completes the series by ensuring the documentation improvements don't inadvertently create problems for the translation workflow.
