[GSoC proposal] git repo command improvements by Ayush Kumar Jha. Proposal to enhance repository metadata access and health analysis through git repo subcommands, continuing libification efforts. Student has prior experience with global state reduction patches (is_bare_repository(), read_attr()). Three main goals: (1) decouple builtin/repo.c from the_repository, (2) expand git repo info with consolidated path information (git-dir, hooks, objects), (3) enhance git repo structure with health metrics (tree depth, large objects) using path-walk API. Timeline spans standard GSoC period with libification in Phase 1 (May-July), analysis in Phase 2 (July-August). Challenges noted around Windows path normalization and performance.
