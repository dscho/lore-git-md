This is a refinement patch in the ongoing effort to standardize string list sorting behavior across Git commands, specifically focusing on the help command's config output. The patch addresses testability issues that emerged after the initial merge of the series.

Amisha Chhajed's v4 patch restructures how `builtin/help.c` processes configuration keys to ensure the `keys_uniq` list maintains proper sorting regardless of the input order. The key changes include:

1. Extracting the config processing logic into dedicated functions (`set_config_vars` and `set_config_sections`) for better separation of concerns
2. Moving the sorting operation (`string_list_sort_u`) to after all processing is complete, rather than depending on pre-sorted input
3. Updating the test suite to use `sed` instead of `grep` for more precise pattern matching and better alignment with the new implementation

The changes affect 84 lines in `help.c` and 26 lines in the test script, with the main goal being to make the output reliably sorted while maintaining the same functionality. This builds on Elijah Newren's earlier work in the series while addressing specific test constraints identified during review.
