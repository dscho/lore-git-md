Bugfix targeting the diff machinery, specifically addressing a crash when using `--find-object` outside a repository.

The patch fixes a crash that occurs when running `git diff --find-object=<oid>` outside a Git repository. Currently, the command attempts to resolve the OID through `repo_get_oid()`, which triggers a BUG() assertion when no repository is present. Michael Montalbo's solution adds a check for `startup_info->have_repository` before attempting OID resolution, returning a user-friendly error message instead of crashing.

The change is minimal (just 2 lines in diff.c) but effectively prevents the crash. A new test case in t4053-diff-no-index.sh verifies the fix by confirming the command fails gracefully with the expected error message when run outside a repository. This appears to be a straightforward and well-contained fix for a clear edge case in the diff machinery.
