Feature patch for gitk's color customization, now in its third iteration. This change adds a "Links" color option to gitk's Preferences dialog, addressing readability issues in dark themes by making the previously hardcoded `linkfgcolor` configurable through the UI.

The patch modifies two Tcl/Tk procedures in gitk's code: `prefspage_colors` to add the new color picker widget, and `prefspage_set_colorswatches` to update the color swatch. The implementation follows gitk's existing pattern for color configuration, adding a simple 10-line change that exposes this previously hidden setting. Maintainer Johannes Sixt (gitk's maintainer) had previously approved the technical approach while suggesting UI label simplification from "Link color" to "Links", which was implemented in v2.

This version removes CC trailers from the commit message per feedback from Johannes Sixt, who clarified that when using GitGitGadget, such metadata belongs in the GitHub PR description rather than the commit message. The change is otherwise unchanged from v2, which had already addressed all technical feedback. The patch appears ready for inclusion, having navigated both technical review and process clarifications around commit message style and submission conventions.
