Bugfix addressing a crash in `git diff --find-object=<oid>` when run outside a Git repository. The command currently crashes with a BUG() assertion when attempting OID resolution via `repo_get_oid()` without a repository present. Michael Montalbo's patch adds a `startup_info->have_repository` check to return a user-friendly error instead.
