Abraham Samuel Adekunle has proposed a Google Summer of Code (GSoC) project to implement prioritized fetching from multiple promisor remotes in partial clone scenarios, building on Christian Couder's existing promisor-remote work. The v2 proposal incorporates feedback from Christian, dropping the originally proposed `promisor.honorServerFetchOrder` config in favor of reusing `promisor.storeFields`, expanding the scope to handle all partial clone objects (not just blobs), and documenting edge cases.

The implementation will proceed in two phases: first adding local priority ordering via `remote.<name>.priority` configuration, then extending to protocol-level negotiation with a new v2 promisor-remote capability. Some open questions remain about protocol negotiation details and configuration approach. Abraham has demonstrated technical competence through prior contributions (including merged `git add -p` work) and responsiveness to feedback. Christian Couder has reviewed positively, noting this addresses a real need for partial clone users while being appropriately scoped for GSoC. The proposal is now in final review before the GSoC application deadline.
