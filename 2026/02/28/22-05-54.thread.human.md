This thread explores different approaches to handling path formats (absolute vs relative) in the new `git repo-info` command. The discussion began with Lucas Seiki Oshiro's initial implementation using a global `--path-format` flag, then evolved through two alternative proposals: Tian Yuchen's `ref-filter.c` integration with format modifiers, and Jayatheerth K's virtual fields approach that uses local state copies to support mixed formats.

The technical exploration has shown that both alternative approaches can meet the requirements, with Jayatheerth's virtual fields demonstrating particular elegance in handling mixed formats without complex per-field tracking. Lucas has now proposed a specific dot notation syntax (`path.git-dir.absolute`/`path.git-dir.relative`) for the virtual fields approach, while stepping back from driving the decision. The thread has reached consensus on the technical feasibility but awaits Junio Hamano's input on the preferred design direction, with his known preference for plumbing simplicity likely to be the deciding factor. Several participants including brian m. carlson, Phillip Wood, and Ayush Jha have contributed to evaluating the approaches, particularly around Windows path handling and API design considerations. With the technical discussion largely concluded, the thread now awaits maintainer guidance on which path to pursue.
