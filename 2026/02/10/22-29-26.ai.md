This is the third iteration of a feature patch enabling UTF-8 support for Git aliases via config syntax, now split into three logical commits. The core change allows defining aliases with non-ASCII names using subsection syntax like `[alias "förgrena"] command = branch`, while maintaining backward compatibility with traditional `[alias] co = checkout` syntax. The implementation handles case sensitivity differences between the two forms and includes comprehensive test coverage for Swedish, CJK, and space-containing aliases.

Key technical improvements in v3 include stricter config key validation via `parse_config_key()`, proper handling of malformed alias definitions, and UTF-8-aware column alignment in help output using `utf8_strwidth()`. The series also consolidates alias listing logic between `alias.c` and `help.c` while preserving error checking. Windows support remains a known limitation deferred for future work.

The patch has been reviewed by Jeff King (validating core functionality) and Junio Hamano (approving documentation wording), with all feedback from previous iterations addressed. The implementation is now merge-ready, with the three commits cleanly separating preparatory refactoring, compatibility documentation, and the main feature implementation.
