This is the third patch in Patrick Steinhardt's 5-part series improving CI test execution consistency across platforms. The focus here is aligning the Meson build system's test slicing behavior with the Make-based approach standardized in the previous patches.

The change updates GitHub Actions to use one-based indexing for test slices in Meson builds (changing `$matrix.nr` to `$matrix.nr + 1`), matching the convention established earlier. Justin Tobler's review confirms the technical correctness but suggests the change could have been combined with the prior patch to avoid transitional CI failures. Patrick clarifies this affects a separate Meson-specific script and notes Meson would already fail on invalid ranges.

The patch demonstrates the series' systematic approach - first establishing core behavior changes, then propagating them to all CI systems and build variants. It touches `.github/workflows/main.yml` to update the Meson test slicing parameters while maintaining the same validation semantics. The changes are part of the broader effort to unify test execution across GitHub Actions, GitLab CI, Make and Meson builds, with particular attention to Windows/MSVC environments.
