This is a feature patch series that implements UTF-8 support for Git alias names through config subsections. The second iteration addresses all feedback from the initial version, with maintainer approval on the documentation refinements, it appears ready for merging.

The series enables non-ASCII alias names (like `[alias "förgrena"]`) while maintaining backward compatibility with the traditional syntax (`[alias] co = checkout`). The implementation takes Jeff King's suggestion to use config subsections rather than modifying key syntax, providing a clean solution that works with arbitrary bytes in alias names. The patch splits into two logical parts: first a refactoring to consolidate alias listing logic, then the main feature implementation.

Notable improvements in v2 include better terminology in documentation (using "without subsection" instead of "flat syntax"), elimination of duplicate parsing logic by reusing `list_aliases()`, proper UTF-8 column alignment in help output, and expanded test coverage. The tests now verify case sensitivity, subsection validation, and help listing behavior. Windows support remains an open question deferred to future work, but the Unix implementation is complete.
