This is the first patch in a series to improve type filtering in `git config list --type`. The patch is a pure refactoring that moves the `show_all_config()` function lower in `builtin/config.c` to prepare for using `format_config()` in a future patch. 

Derrick Stolee identified a performance bottleneck in git-credential-manager where `git config list --type` currently parses all config values before filtering by type, which is inefficient for path-type values. This series aims to enable type filtering during the initial config parsing.

The change itself is straightforward - it just relocates the function without modifying its behavior. The commit message clearly states the motivation (preparing to use `format_config()`) and the patch shows only the mechanical movement of code. This looks like a clean preparatory step for the more substantive changes to come in later patches of the series.
