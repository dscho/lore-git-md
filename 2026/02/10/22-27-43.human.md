This is a refactoring patch that consolidates alias listing logic as part of the UTF-8 alias support series. The patch moves the alias parsing code from `help.c` into `alias.c` where it can be shared, eliminating duplicate implementation while preserving all existing error checking.

The key changes are:
1. Modifies `list_aliases()` in `alias.c` to store alias values (via the string_list util field) in addition to names
2. Removes the private `get_alias()` callback from `help.c` in favor of using the shared `list_aliases()`
3. Maintains the same behavior for value-less aliases by checking in `alias.c` rather than `help.c`

This is a clean preparatory change that doesn't modify functionality but makes the codebase more maintainable by centralizing the alias handling logic. The patch has already been reviewed and approved by Jeff King and Junio Hamano in previous iterations of the series.
