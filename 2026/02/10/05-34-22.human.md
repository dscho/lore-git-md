This is the third patch in Patrick Steinhardt's 5-part series improving CI test execution consistency, specifically addressing the Meson build system's test slicing behavior. The patch aligns Meson's test slicing with the Make-based approach standardized in the previous patch, using one-based indexing for test slices.

Justin Tobler had raised a question about whether this change should have been combined with the prior patch to avoid transitional CI failures, but Patrick clarifies this is a separate script (`ci/run-test-slice-meson.sh`) that needed its own update to match the new behavior. The change ensures both build systems handle test slicing identically, with Meson already having its own validation for invalid ranges.

The patch demonstrates Patrick's methodical approach to CI infrastructure - first establishing the correct behavior, then propagating it consistently across all build systems. This continues the series' theme of making test execution more reliable, particularly for Windows/MSVC environments.
