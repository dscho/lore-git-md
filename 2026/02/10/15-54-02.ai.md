This is a documentation patch addressing a known issue with `diff.noprefix` affecting patch generation and application. The thread centers around a recurring problem where locally setting `diff.noprefix=true` causes `git format-patch` to generate patches without standard `a/` and `b/` prefixes, which then fail to apply with `git am` despite working with `git add -p`.

Kristoffer Haugsbakk points out that while the issue was merged in commit 15108de2 (adding `format.noprefix` to control this behavior), the documentation could be clearer about how this configuration differs from `diff.noprefix`. The current wording states "If set" but doesn't specify that any value (not just `true`) enables the behavior, unlike `diff.noprefix` which is strictly boolean.

The patch appears well-motivated by real user confusion (Alejandro Colomar and наб both encountered the issue) and builds on prior discussion where Junio Hamano acknowledged the need for this fix. The proposed doc clarification would help users understand the subtle but important distinction between these related configurations.
