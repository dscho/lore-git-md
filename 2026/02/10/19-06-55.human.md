This is a platform compatibility discussion about Git's build system, specifically around meson deprecation warnings and path handling differences between make and meson builds.

Ramsay Jones reports that a meson deprecation warning about `configure_file` copy arguments appears on Linux (meson 1.3.2) but not Cygwin (meson 1.5.2). Patrick Steinhardt explains this is expected since the deprecation was rolled back in meson 1.5.0, making the warning a non-issue.

The discussion then shifts to differences between make and meson builds, particularly around paths (`/bin/sh` vs `/usr/bin/sh`) and version numbers in the git-gui executable. Patrick identifies the root cause as incorrect `GIT_CEILING_DIRECTORIES` handling in the meson build configuration, which he fixes in a GitHub PR. The fix aims to align meson behavior with the traditional Makefile builds while maintaining platform compatibility.

This is a typical platform-specific build system discussion, with Patrick providing clear technical explanations and quick fixes for the reported issues. The exchange demonstrates the project's attention to build consistency across platforms, even for relatively small differences in behavior.
