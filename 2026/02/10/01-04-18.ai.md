The key point is that on macOS, command-line arguments already go through `precompose_argv_prefix()` to handle Unicode normalization (converting from NFD to NFC form), so aliases will automatically get the same treatment without needing special handling in the alias subsystem. This confirms the thread's earlier consensus that no additional normalization logic is needed in the alias implementation itself.
