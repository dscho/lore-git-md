This is the first patch in a performance-focused series to improve type filtering in `git config list --type=<X>`. The patch is a pure refactoring that relocates the `show_all_config()` function within `builtin/config.c` to prepare for future changes, without altering any behavior.

Derrick Stolee (a known expert in performance optimizations) is the author, motivated by a bottleneck he identified in git-credential-manager where current `--type` filtering requires parsing all config values before filtering. The series will enable type filtering during initial parsing for better efficiency, particularly for path-type values.

This initial patch simply moves `show_all_config()` below `format_config()` to allow the latter to be used by the former in subsequent patches. The diff shows the mechanical relocation with no functional changes - the function's implementation remains identical, just positioned differently in the file. This is a common preparatory step when restructuring code to share functionality between components.

The patch follows Git's standard practices: a clear one-sentence commit message explaining the "why", a Signed-off-by line, and a clean diff that makes the pure-move obvious. As the first in a series, it sets up the groundwork for the more substantive changes to come in patches 2-5 that will modify how config values are filtered by type.
