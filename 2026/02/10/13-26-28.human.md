This is a platform compatibility discussion about the meson build system integration for gitk and git-gui.

Patrick Steinhardt responds to Ramsay Jones' report of a meson deprecation warning when building git-gui on Linux (but not Cygwin). He explains the warning about `copy arg in configure_file` was actually reverted in meson 1.5.0, so it doesn't need addressing. The warning appears on Linux (using meson 1.3.2) but not Cygwin (using meson 1.5.2) because the deprecation was rolled back in between those versions.

Patrick also notes some path and version differences between make and meson builds. He identifies a bug where GIT_CEILING_DIRECTORIES is incorrectly set when git-gui is built as a subproject, causing version number discrepancies. He has submitted a pull request to the git-gui repository to fix these issues, preferring `/bin/sh` over `/usr/bin/sh` and correcting the version detection.

The exchange shows careful attention to build system details across platforms, with Patrick providing context about meson version history and diagnosing the root cause of the version number mismatch. The fixes appear straightforward and well-contained.
