This is the third iteration of a feature patch series to support UTF-8 characters in Git alias names via config subsections. The series has progressed through technical review and documentation refinement, with all feedback from the maintainer addressed in v3.

The core change allows aliases with non-ASCII characters by using the subsection syntax `[alias "förgrena"]` while maintaining backward compatibility with the traditional `[alias] co = checkout` form. The implementation carefully preserves existing behavior for malformed config entries and adds comprehensive test coverage for UTF-8 handling, including Swedish and CJK characters.

The v3 series splits the changes into three logical commits: a preparatory refactoring of alias listing code, a compatibility-breaking change to alias parsing internals, and the main feature implementation. This structure makes the changes easier to review and bisect. The tests now properly verify edge cases like value-less alias definitions, and the documentation has been updated with clearer terminology about ASCII limitations in the traditional syntax.

The patch appears ready for merging, with all technical concerns addressed and maintainer-approved documentation. The only remaining open question is Windows support, which is deferred to future work. This represents a careful, incremental expansion of Git's UTF-8 support that maintains backward compatibility while enabling non-English alias names.
