This is the third iteration of a feature patch series adding UTF-8 support for Git aliases via config subsections (e.g., `[alias "förgrena"]`). The series has been refined through review feedback and is now in its final form, ready for merging.

The key changes in v3 include splitting the work into three logical commits: preparatory refactoring, explicit compatibility note, and the main feature implementation. The patch now properly handles edge cases like malformed alias definitions and preserves error checking for NULL values. It also introduces strict validation of config keys using `parse_config_key()`.

The implementation allows non-English speakers to create aliases in their native languages while maintaining backward compatibility with the existing case-insensitive ASCII-only syntax. The help system has been updated to properly list and align UTF-8 aliases using `utf8_strwidth()`. Test coverage includes Swedish, CJK, and space-containing aliases.

Notable reviewers Jeff King and Junio Hamano have approved the technical approach and documentation wording. The only remaining open question is Windows support, which has been deferred to future work. The series represents a well-executed addition to Git's configuration system with thorough consideration of backward compatibility and edge cases.
