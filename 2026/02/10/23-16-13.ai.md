This is a build system patch continuing the macOS credential helper improvements. Koji Nakamaru responds to Junio C Hamano's review feedback on their earlier patch that moved the `git-credential-osxkeychain` build targets to the top-level Makefile.

The maintainer suggested two technical improvements: using `$(MAKE)` instead of hardcoded `make` invocations for portability, and using the `-C` flag to change directories rather than explicit `cd` commands. Nakamaru acknowledges the feedback and indicates they will incorporate these changes in the next version of the patch.

This follows the established pattern seen in other credential helpers and addresses recent build breakages caused by Homebrew configuration changes and iconv workarounds. The thread shows consensus on the approach, with only these minor Makefile best practices remaining to be addressed before the patch is ready for merging. The changes maintain the required Security/CoreFoundation framework linkages while centralizing build logic in the top-level Makefile.
