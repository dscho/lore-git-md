Build system patch for macOS credential helper. This moves the build targets for `git-credential-osxkeychain` from its standalone Makefile into the top-level Makefile to ensure consistent build flags and dependencies. The change addresses recent build failures that occurred when macOS-specific refinements (like Homebrew integration and iconv workarounds) were added to the main build system but not properly propagated to the credential helper's separate build. The patch simplifies the credential helper's Makefile to just delegate to the top-level targets.

The motivation is clear - maintaining duplicate build logic is fragile, especially when the helper needs to link against `libgit.a` which depends on many top-level build flags. The solution looks straightforward and well-contained, touching only the two Makefiles involved. This appears to be a sensible build system cleanup rather than introducing new functionality.
