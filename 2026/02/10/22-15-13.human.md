CI/build system fix addressing GitHub Actions syntax error in test slicing.

Junio Hamano reports that Patrick Steinhardt's patch to make Meson test slicing consistent (changing from zero-based to one-based indexing) contains invalid GitHub Actions workflow syntax. The error occurs because GitHub Actions expressions don't support arithmetic operations like `matrix.nr + 1` directly in the YAML file. This was known behavior per a 6-year-old GitHub discussion, though Patrick may have assumed the limitation was lifted.

The patch itself was part of a larger series to standardize test execution across CI platforms, with this specific change updating the Meson test script to match the one-based indexing already implemented for Make builds. Junio has reverted the topic from the 'next' integration branch due to the syntax error, noting he should have caught this during the 'seen' testing phase.

This appears to be a straightforward syntax oversight in an otherwise well-reviewed series. The fix will likely involve moving the arithmetic operation into a script rather than attempting it inline in the YAML. The underlying goal of consistent test slicing remains sound, and the series has already received positive review from Justin Tobler on its technical approach.
