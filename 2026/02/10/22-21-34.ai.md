This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics. The report covers patches that have graduated to 'master', new topics under consideration, and ongoing work in the integration branches.

The report shows several topics have recently graduated to 'master', including:
- A new string_list_sort_u() API function and related tests
- Fixes for batched ref update error reporting
- The new "git history" command for history rewriting
- Improvements to "git replay" to drop empty commits
- Documentation updates for worktree prune/expire behavior
- Performance test optimization

New topics being proposed include:
- Completion updates for stash import/export
- Documentation improvements for patch-id and am commands
- Sample commit-msg hook updates to detect problematic messages
- Test modernization using path helpers
- Various documentation cross-reference fixes
- CI updates for GitLab/MSVC builds
- Test fixes for iconv-related issues
- Several cleanups reducing use of the_repository global
- Build system fixes for meson
- Duplicate include removal
- Commit stack API usage improvements

Ongoing work includes:
- Config type filtering for "git config list"
- Mobile-friendly gitweb updates
- OSX keychain build simplification
- Merge-file config handling outside repos
- Sparse checkout integration for merge-ours
- Interactive add-patch improvements
- Ref backend location configuration
- Parallel hook execution
- Process ancestry tracing for macOS
- Submodule ignore=all support
- Object enumeration API revamp
- SHA-1/SHA-256 interoperability work
- MIDX compaction improvements

The report provides a healthy mix of new features, bug fixes, documentation improvements, and ongoing architectural work. Several topics appear ready to graduate soon, while others still need review iterations. The breadth of activity shows continued strong development across Git's subsystems.
