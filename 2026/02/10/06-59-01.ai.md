This is a follow-up clarification in the concluded UTF-8 aliases thread, confirming that pager configuration (unlike aliases) does need to consider on-disk path representation. Jeff King notes that while the alias implementation correctly treats names as command-line arguments (benefiting from macOS's existing argument normalization), the pager.* configuration does interact with filesystem paths and thus requires different handling. This distinction was already understood in the thread's final resolution but serves as a useful reminder about the broader context of UTF-8 handling in Git configuration. The comment doesn't change the implementation approach for aliases but provides important context for future work on other configuration sections that might involve pathnames.
