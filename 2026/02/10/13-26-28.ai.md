This is a build system patch addressing meson integration for gitk/git-gui. Patrick Steinhardt responds to Ramsay Jones's report of a meson deprecation warning during git-gui builds on Linux (but not Cygwin). The warning stems from a temporarily deprecated `configure_file` copy argument that was later reverted in meson 1.5.0. Patrick determines this doesn't require immediate action since the deprecation was rolled back.

The email also notes path differences between make and meson builds (`/bin/sh` vs `/usr/bin/sh`) and version number discrepancies caused by `GIT_CEILING_DIRECTORIES` being set incorrectly in the meson build. Patrick identifies this as a bug and submits a fix via pull request to the git-gui repository. The changes aim to align the meson build behavior with the traditional Makefile approach while maintaining platform compatibility. This is part of the ongoing meson build system modernization effort, with the gitk/git-gui integration currently waiting on an external gitk PR before proceeding further.
