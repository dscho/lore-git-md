This is the second patch in a two-part series implementing UTF-8 support for Git configuration subsections, specifically focused on aliases. The patch enables non-alphanumeric alias names (like `förgrena` or `分支`) by using the subsection syntax (`[alias "förgrena"] command = branch`), while maintaining backward compatibility with the traditional case-insensitive syntax (`[alias] co = checkout`).

The implementation handles several key aspects:
- Case sensitivity differences between the two syntax forms (subsection names are case-sensitive while traditional aliases remain case-insensitive)
- UTF-8 support in the alias listing and help system, using `utf8_strwidth()` for proper column alignment
- Comprehensive test coverage including Swedish, CJK characters, and spaces in alias names
- Documentation updates explaining both syntax forms and their differences

The patch builds on feedback from the first iteration, with Jeff King (Peff) providing the initial suggestion and Junio Hamano reviewing the documentation wording. The implementation is now merge-ready, though Windows support remains as future work. This represents a careful expansion of Git's Unicode support while maintaining backward compatibility.
