This is a refactoring patch that consolidates alias handling logic in preparation for UTF-8 support in Git configuration subsections. It's the first of two patches in the v2 series implementing UTF-8 aliases.

The patch removes duplicate alias parsing code from `help.c` by extending `list_aliases()` in `alias.c` to store alias values (via string_list's util field) and using it consistently. It also switches `git_unknown_cmd_config()` from `skip_prefix()` to `parse_config_key()` for better handling of multi-level config keys, though this doesn't affect functionality yet.

The changes are clean and mechanical, with no behavior changes intended. The patch has already been reviewed by Jeff King and Junio Hamano in previous iterations, suggesting it's technically sound. This groundwork will enable the actual UTF-8 alias support in the following patch while maintaining backward compatibility.

The implementation looks solid - it simplifies the codebase by removing duplicate logic while preparing for the new feature. Since this is part of a reviewed series that has addressed all technical feedback, it appears ready for merging.
