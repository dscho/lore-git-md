This biweekly "What's cooking" report from Junio Hamano provides a snapshot of Git's development activity. Several significant features have recently graduated to 'master', including the new "git history" command for history rewriting, improvements to "git replay", and performance optimizations. The report also highlights ongoing architectural work like reducing reliance on the `the_repository` global variable and improvements to the ref backend configuration.

New proposals include various documentation improvements, test modernizations, and CI updates. Notable ongoing work includes SHA-1/SHA-256 interoperability efforts, MIDX compaction improvements, and parallel hook execution. The breadth of activity shows healthy development across all subsystems, from core functionality to user-facing features and infrastructure improvements. Several topics appear close to graduate while others still need review iterations before being ready for merging.
