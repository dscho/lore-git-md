This is the final patch in a three-part series implementing UTF-8 support for Git configuration subsections, specifically focused on aliases. The patch enables non-ASCII alias names through the subsection syntax (e.g., `[alias "förgrena"]`), while maintaining backward compatibility with the traditional case-insensitive ASCII-only format.

The implementation handles several key aspects:
- Subsection aliases are matched case-sensitively as raw bytes, while traditional aliases remain case-insensitive
- The help system (`git help -a`) properly displays UTF-8 aliases using `utf8_strwidth()` for correct column alignment
- Comprehensive test coverage includes Swedish, CJK, and space-containing aliases
- Strict validation ensures subsection aliases must use the `command` key
- Documentation clearly explains both syntax forms and their differences

The patch builds on preparatory refactoring from earlier in the series that consolidated alias listing logic and introduced strict config key parsing. All technical feedback from previous iterations has been addressed, with maintainer-approved documentation and thorough test coverage. The only remaining open question is Windows support, which is deferred to future work.

This well-crafted patch series appears ready for merging, having gone through multiple rounds of review with input from Jeff King, Junio Hamano, and Torsten Bögershausen. The implementation is clean, the tests cover edge cases, and the documentation is clear - a solid contribution that improves Git's internationalization support.
