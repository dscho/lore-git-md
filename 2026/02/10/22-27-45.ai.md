Feature implementation for UTF-8 alias support via config subsections, completing the v3 patch series. This is the main patch that enables non-ASCII alias names through the subsection syntax (`[alias "förgrena"]`), while maintaining backward compatibility with the traditional case-insensitive ASCII-only format.

The patch introduces several key changes:
1. Documentation updates explaining the two syntax forms (ASCII-only vs. UTF-8 subsection) with clear examples
2. Core implementation in `alias.c` using `parse_config_key()` to handle both syntax variants
3. Help system integration to properly list and align UTF-8 aliases using `utf8_strwidth()`
4. Comprehensive test coverage including Swedish, CJK, and space-containing aliases

The implementation preserves all existing behavior while adding the new functionality, with careful attention to edge cases like NULL values and malformed subsection entries. The test suite verifies case sensitivity differences between syntax forms and proper handling of various Unicode characters.

This patch builds on the preparatory refactoring from earlier in the series, which consolidated alias listing logic and introduced strict key validation. All technical feedback from previous iterations has been addressed, and the maintainer has approved the documentation wording. The only remaining open question is Windows support, which is deferred to future work.
