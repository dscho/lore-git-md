RFC proposal for `git repo info` to expose repository paths, starting with `--git-dir` equivalent. Author Pushkar Singh suggests making Git directory path available through structured output as more discoverable alternative to `git rev-parse`, while maintaining both interfaces. Open questions include whether paths should be absolute or relative. Initial focus is on git-dir path, leaving room to expand to other paths (common dir, hooks) based on feedback. Explicitly positions this as complementary to existing mechanisms rather than replacement. Targets improved usability for scripts/tooling needing repository metadata.
