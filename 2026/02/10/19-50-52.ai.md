Build system improvement for macOS credential helper. This is a follow-up to Koji Nakamaru's patch that moved the build targets for `git-credential-osxkeychain` from its local Makefile to the top-level Makefile. Junio C Hamano suggests two small improvements to the implementation: using `$(MAKE)` instead of the literal `make` command, and using the `-C` flag for directory changes rather than `cd`. These are standard practices in Makefiles to ensure proper behavior across different environments.

The changes maintain the core goal of the original patch - centralizing the build logic while preserving the required Security/CoreFoundation framework linkages for macOS keychain access. Junio's feedback is minor and technical, indicating the overall approach is sound. The thread shows no substantive objections to the need for this change, which was motivated by recent Makefile modifications that broke the standalone build of this credential helper.
