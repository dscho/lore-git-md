Refactoring patch consolidating alias listing logic between `alias.c` and `help.c`. This is the first of three preparatory patches for UTF-8 alias support.

The patch moves the alias listing functionality from `help.c`'s private `get_alias()` callback to use the existing `list_aliases()` function in `alias.c`. Key changes:
- Modifies `list_aliases()` to store alias values via the string_list util field
- Preserves error checking for value-less aliases by moving it into `alias.c`
- Removes duplicate parsing logic from `help.c`
- Maintains identical functionality while cleaning up the code structure

This refactoring enables subsequent patches to implement UTF-8 alias support in a single location rather than duplicating changes across files. The patch follows Git's incremental approach to refactoring - making mechanical improvements first before adding new functionality.

Technical details:
- Touches `alias.c` and `help.c`
- Uses string_list util field to pass alias values
- Preserves NULL value handling
- No behavior change intended
- Part of larger UTF-8 alias support effort
