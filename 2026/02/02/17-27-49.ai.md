Bug report confirmation for `git log --graph` misalignment issue. Pushkar Singh independently verifies the reported behavior where graph characters appear at line ends rather than starts when combining `--graph`, custom `--pretty=format:` without newlines, and `-p`. The reproduction steps are minimal and clear, showing the same symptom on Git 2.43.0 (WSL/Linux environment) as originally reported for 2.51.0. This confirmation strengthens the case that this is a genuine, long-standing bug in the graph/patch output interleaving logic rather than an environment-specific issue. The thread now has two independent reproductions but still lacks proposed fixes or deeper analysis of the underlying cause in `log-tree.c`.
