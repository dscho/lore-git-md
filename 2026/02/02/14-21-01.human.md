This is a bugfix for `git stash`'s handling of ignored files, continuing a thread where Pushkar Singh introduced new `--overwrite-ignore` and `--no-overwrite-ignore` options. The patch aims to resolve a long-standing FIXME where `git stash` was unconditionally overwriting ignored files during index updates.

Kristoffer Haugsbakk points out two issues in the patch submission:

1. The commit message should use present tense when describing the current behavior (as per project conventions in SubmittingPatches)
2. The patch is missing a required Signed-off-by trailer

The patch itself appears to be a straightforward improvement that aligns `git stash` behavior with other commands like `checkout` and `reset` regarding ignored files. However, as noted in the thread summary, there are implementation issues around the option parsing that need to be addressed (using OPT_BOOL correctly) and test coverage that needs expansion.

This is a focused change that addresses a known limitation in `git stash`, though it needs some polish before being ready to merge. The discussion shows careful attention to both the technical details of the submission requirements and the parse-options API usage.
