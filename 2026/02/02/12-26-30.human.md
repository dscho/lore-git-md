This is the first patch in a 4-part series implementing reference backend selection for zero-downtime migrations between files and reftable backends. The series is now in its fourth iteration with all major technical challenges resolved.

The patch extends the `extensions.refStorage` configuration to support URI-style specification of reference backend locations, allowing out-of-tree reference directories. It introduces a `ref_storage_payload` field in the repository structure to store the parsed URI components and modifies several functions to propagate this information through the reference database initialization process.

Key changes include:
- Adding URI parsing logic in `parse_reference_uri()`
- Modifying repository setup to handle the new payload field
- Updating `create_reference_database()` to accept the payload
- Ensuring proper memory management of the payload string

The patch is well-structured and follows Git's established patterns for configuration handling. It builds on previous discussion and review feedback, particularly around the URI format and worktree reference handling. The changes are focused and maintain backward compatibility while enabling the new functionality needed for backend migration scenarios.
