Hook subsystem modernization (part 6/12) - stream separation control. This patch from Adrian Ratiu addresses a specific regression concern raised by Chris Darroch regarding the pre-push hook's stdout/stderr behavior. The change makes the hook API more flexible by allowing callers to control whether stdout and stderr streams should be merged (the common case) or kept separate (needed for pre-push compatibility).

The patch adds a `stdout_to_stderr` flag to `struct run_hooks_opt`, defaulting to true for backward compatibility with most hooks. This simple but important change enables the pre-push hook conversion in the next patch while maintaining existing behavior for other hooks. The implementation is clean, focused, and well-documented, with just two small changes needed in hook.c and hook.h.

Chris Darroch confirms in the thread that this change (as part of the full v8 series) passes the Git LFS test suite, providing real-world validation of the backward compatibility. The patch demonstrates good attention to edge cases in the broader hook modernization effort, showing how the new infrastructure can accommodate legacy requirements when needed.
