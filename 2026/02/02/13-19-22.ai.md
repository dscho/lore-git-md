Bugfix for `git stash`'s handling of ignored files. This patch addresses a long-standing FIXME in the code where `git stash` was unconditionally overwriting ignored files during index updates, contrary to the behavior of similar commands like `checkout` and `reset`.

Pushkar Singh adds new `--overwrite-ignore` and `--no-overwrite-ignore` options to `git stash push/save` (defaulting to overwrite, maintaining backward compatibility). The options control whether ignored files should be preserved during stash operations, with the implementation plumbing this through to the `reset_tree()` function where the FIXME was previously noted.

The change is accompanied by a new test case that verifies `--no-overwrite-ignore` correctly preserves ignored file contents. The patch is focused and well-contained, touching only the stash command's behavior around ignored files while maintaining the existing default behavior. This brings `git stash` into alignment with how other commands handle ignored files when updating the working tree.
