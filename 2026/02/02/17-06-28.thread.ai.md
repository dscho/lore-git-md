Git v2.53.0 release summary:

Junio C Hamano announces Git v2.53.0 with 466 non-merge commits from 70 contributors (21 new). Major changes span user features, performance, and internal refactoring. New user-facing additions include `git maintenance is-needed` subcommand, `git replay` now handling ref updates directly, and new whitespace error class "incomplete-line" for apply/diff. A new manual documents Git's data model.

Significant performance work includes packfile handling refactored through packfile store (replacing packed_git), 50% memory reduction plus speedup for `git diff --find-copies-harder`. Object database restructuring progresses for alternate store handling and pluggable backend preparation. Continued `the_repository` removal touches tree handling and tag parsing subsystems.

Platform-specific fixes address macOS iconv issues and improve Windows symlink support. Merge-ort edge cases receive attention. Changes are widespread but concentrated in refs, odb, and packfile areas. Documentation updates, test improvements, and l10n translations accompany the release. The object storage changes suggest ongoing preparation for pluggable backends, while `the_repository` elimination continues across subsystems.
