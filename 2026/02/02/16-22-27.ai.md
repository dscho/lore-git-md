This is a bugfix for `git stash`'s handling of ignored files, addressing a long-standing FIXME where it unconditionally overwrote ignored files during index updates. The patch is version 2 of a series that introduces new `--overwrite-ignore` and `--no-overwrite-ignore` options to `git stash push/save`, defaulting to overwrite for backward compatibility.

Pushkar Singh's v2 patch makes several improvements over the initial version: it correctly uses a single `OPT_BOOL` for the overwrite-ignore option (fixing a parse-options API misuse), properly handles the interaction between `-a/--all` and `--no-overwrite-ignore` by downgrading `INCLUDE_ALL_FILES` to just include-untracked when needed, and adds regression tests covering both overwrite and no-overwrite cases. The commit message and documentation have also been updated to use present tense and include the required Signed-off-by trailer.

The change aligns `git stash` behavior with `checkout` and `reset` regarding ignored files while maintaining existing defaults. Reviewers Patrick Steinhardt and Karthik Nayak identified technical issues in v1 (redundant option handling, test coverage gaps), while Kristoffer Haugsbakk flagged documentation problems - all of which have been addressed in this revision. The patch now appears ready for inclusion, having passed careful review of both implementation details and submission requirements.

Key technical details: The patch modifies `builtin/stash.c` to properly handle the interaction between include-untracked modes and the new overwrite behavior, and adds two test cases in `t/t3905-stash-include-untracked.sh` that ignored files are either preserved or overwritten based on the option. The changes are focused but touch core stash behavior, particularly around the `INCLUDE_ALL_FILES` constant and how it interacts with the new overwrite control.
