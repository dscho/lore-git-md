Bug report: `git log --graph` misplaces graph characters when combined with `-p/--patch` and custom pretty formats lacking newlines. The issue occurs when using `--graph --pretty='format:%h' -p`, causing graph connection characters (`|`, `\`, `/`) to appear at line ends rather than starts, breaking the visual graph structure. Reproduction requires: (1) `--graph` with custom `--pretty=format:` (not `tformat:`), (2) `-p` flag, (3) format string without trailing newline (`%h` vs `%h%n`). Workarounds exist (using `tformat:` or adding `%n`) but introduce their own formatting quirks. The bug resides in `log-tree.c`'s graph/patch output interleaving logic and has persisted since at least Git 2.51.0.
