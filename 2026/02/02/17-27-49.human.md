This is a bug report confirmation for `git log --graph` output formatting. Pushkar Singh reproduces an issue where graph connection characters (`|`, `\`, `/`) appear incorrectly at the end of commit hash lines rather than at the start when using `--graph` with a custom `--pretty=format:` that lacks a trailing newline and the `-p` flag. The reproduction steps are clear and minimal, showing the problem occurs across Git versions (2.43.0 through at least 2.51.0). 

The issue affects the visual structure of the commit graph when viewing patches, making it harder to follow commit relationships. While workarounds exist (using `tformat:` or adding `%n` to the format string), they come with their own formatting tradeoffs. The bug appears to stem from how `log-tree.c` interleaves graph and patch output.

This confirmation from another user strengthens the original report by showing the issue isn't isolated to one environment or Git release. The thread is still in the early stages with no proposed fixes yet, but the clear reproduction steps should help pinpoint the problematic code.
