This is Junio Hamano's monthly "What's cooking" report, providing a status update on all active topics in the Git development pipeline. The report covers patches in various stages - from new proposals to those nearing inclusion in the next release.

Several notable topics are progressing:

1. **Object Database Improvements**: Justin Tobler is working on making ODB transactions per-source rather than per-repository, while Patrick Steinhardt continues his extensive odb_for_each_object() refactoring to revamp object enumeration.

2. **Documentation Modernization**: Jean-Noël Avila is converting more man pages to the synopsis style as part of the ongoing documentation standardization effort.

3. **Performance Optimizations**: A perf test setup was sped up, and string_list gains a new string_list_sort_u() function for unique sorting.

4. **Submodule Handling**: Nasser Grainawi proposes using the configured default remote instead of hardcoded 'origin' for submodule fetches.

5. **Hook System Refactoring**: Adrian Ratiu has a 12-patch series converting various hooks to use the new hook API instead of direct run_command() calls.

6. **Rust Interop**: brian m. carlson continues work on SHA-1/SHA-256 interoperability with Rust components, though CI issues remain unresolved.

The report also lists several topics being discarded due to inactivity, including improvements to global config handling, rebase trailer support, and shallow clone time boundaries.

This update shows Git's development remains active across multiple fronts - from core object storage improvements to documentation and tooling modernization. The mix of new features, performance work, and infrastructure changes suggests a healthy balance between innovation and maintenance.
