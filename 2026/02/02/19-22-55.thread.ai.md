Git for Windows 2.53.0 release announcement. Maintained by Johannes Schindelin as a Windows-specific fork tracking upstream Git 2.53.0. Key changes: Tab key behavior fix in Git Bash to prevent freezing, InnoSetup 6.6.1 for installer, Microsoft Edit support as Git editor. Bundled component updates: cURL 8.18.0, Git Credential Manager 2.7.0 (with ARM64 support), mimalloc 2.2.7, OpenSSL 3.5.5. Bug fixes for installer text clipping, I/O setup for Microsoft Store apps, astextplain empty file handling. SHA-256 checksums provided for all distribution variants (64-bit, ARM64, portable, MinGit, busybox). This is a separate release from upstream Git with Windows-specific changes only.
