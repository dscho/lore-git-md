This is a release announcement for Git for Windows 2.53.0, the Windows-specific distribution of Git maintained separately from the main Git project. Johannes Schindelin announces the new version with several updates and fixes.

The release includes the standard upgrade to Git 2.53.0 core functionality. Notable user-facing improvements include fixing a Bash tab-completion freeze issue, adding Microsoft Edit as a supported editor option, and upgrading the Git Credential Manager to version 2.7.0 with native x64 and ARM64 support. The release also updates several dependencies including cURL, OpenSSL, and the MSYS2 runtime.

Bug fixes address installer display issues, I/O handling for Microsoft Store apps, and proper handling of empty files by the astextplain diff tool. The announcement provides SHA-256 checksums for all distribution variants (installer, portable, MinGit) across 32-bit, 64-bit and ARM64 architectures.

As with all Git for Windows releases, this is distinct from the main Git project's releases - it builds on Git 2.53.0 but includes Windows-specific patches and tooling. The announcement follows the project's standard format with clear sectioning of new features versus bug fixes.
