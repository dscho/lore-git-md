This is a bugfix for `git stash`'s handling of ignored files, addressing a long-standing FIXME where it unconditionally overwrote ignored files during index updates. The patch introduces new `--overwrite-ignore` and `--no-overwrite-ignore` options to control this behavior, defaulting to overwrite for backward compatibility.

D. Ben Knoble points out several test issues in Pushkar Singh's v2 patch. The test for `--no-overwrite-ignore` currently passes even on unmodified Git, indicating it isn't properly validating the new behavior. Knoble suggests using `test_grep` instead of plain `grep` to properly detect file existence, and notes that the `--overwrite-ignore` test should likely use `test_path_is_missing` since it's testing the default behavior.

The discussion reveals that while the core functionality changes appear sound, the test coverage needs refinement to properly validate both the new preserve-ignored-files behavior and the existing overwrite behavior. Knoble's review focuses on ensuring the tests accurately reflect the intended behavior changes, which is particularly important for this bugfix touching long-standing stash behavior.

This follows up on earlier feedback from Patrick Steinhardt, Karthik Nayak, and Kristoffer Haugsbakk that led to improvements in option handling and documentation in v2. With this final round of test validation, the patch appears to be nearing readiness for inclusion.
