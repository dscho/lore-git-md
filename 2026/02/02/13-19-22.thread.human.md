This thread addresses a long-standing issue where `git stash` would unconditionally overwrite ignored files during index updates. Pushkar Singh has proposed adding `--overwrite-ignore` and `--no-overwrite-ignore` options to control this behavior, with the default maintaining backward compatibility by overwriting files.

The v2 patch incorporates feedback from several reviewers, fixing technical issues, improving test coverage, and addressing documentation concerns raised by Patrick Steinhardt, Karthik Nayak, and Kristoffer Haugsbakk. D. Ben Knoble identified remaining test gaps that need to be addressed to properly validate the new behavior.

Elijah Newren has now joined the discussion, raising deeper technical concerns about the patch's approach. He questions the silent downgrade of `INCLUDE_ALL_FILES` when `--no-overwrite-ignore` is used, suggesting these options should be explicitly marked as incompatible. Newren also notes the commit message references a FIXME that isn't actually removed, and provides historical context about related stash issues with ignored files that may need broader consideration.

The patch is currently in a state where most initial feedback has been addressed, but Newren's comments indicate there may be underlying design questions that need resolution before finalizing the changes. The discussion now centers on whether the current implementation properly handles the interaction between the new options and existing flags, or if a more fundamental rethinking of the approach is needed.
