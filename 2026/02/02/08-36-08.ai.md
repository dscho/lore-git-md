This is a documentation patch review discussion continuing Jean-Noël Avila's effort to standardize Git man pages in AsciiDoc synopsis style. Kristoffer Haugsbakk follows up on a previous discussion about long option formatting conventions, specifically whether to use the "stuck form" (`--option=<value>`) versus "unstuck form" (`--option value`) in documentation.

Haugsbakk confirms there is no automated tool to enforce the preferred stuck form convention, which is documented in gitcli(7) and has been mentioned by Junio Hamano. The exchange shows the careful attention to detail in this documentation standardization effort, where even minor formatting choices are being systematically reviewed and aligned across all man pages. This particular thread focuses on `git-clone.adoc` but connects to the broader pattern of consistency improvements being made throughout the documentation conversion project.
