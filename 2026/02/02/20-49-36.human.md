This is a bugfix discussion about `git log --graph` output formatting when combined with custom pretty formats and the `-p` flag. The maintainer Junio C Hamano chimes in to clarify that `--format=<whatever>` is a shorthand for `--pretty=tformat:<whatever>`, which is one of the workarounds identified earlier in the thread.

The core issue occurs when using `--graph` with a custom `--pretty` format that lacks a trailing newline (`%n`) and the `-p` flag to show patches - the graph connection lines (`|`, `\`, `/`) appear at the end of lines rather than the start. D. Ben Knoble had previously noted two solutions: using `tformat:` instead of `format:` (which Junio confirms has the shorthand `--format`), or explicitly adding `%n` to the format string.

Junio's brief comment doesn't propose a fix but provides helpful context note about the existing shorthand syntax. The thread has clearly identified the bug's conditions and workarounds but hasn't yet progressed to discussing an actual code fix for the underlying output formatting issue in `log-tree.c`.
