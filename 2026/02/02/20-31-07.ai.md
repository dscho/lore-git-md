Bugfix for `git stash`'s handling of ignored files, addressing a long-standing issue where it unconditionally overwrote ignored files during index updates. This is part of Pushkar Singh's ongoing effort to add `--overwrite-ignore` and `--no-overwrite-ignore` options to `git stash push/save`.

Elijah Newren raises several technical concerns about the v2 patch. He questions the basis for the changes since he doesn't see the "overwrite-ignore" functionality in the current `builtin/stash.c`. He points out that the silent downgrade of `INCLUDE_ALL_FILES` to just include-untracked when `--no-overwrite-ignore` is given may be problematic, suggesting these options should be explicitly marked as incompatible rather than having one override the other.

Newren also notes the commit message references removing a FIXME comment that isn't actually removed in this patch, and provides historical context about other potential stash-related issues in this area that may still need addressing. He links to previous discussions indicating this is part of a larger set of problems with stash's handling of ignored files.

The technical discussion focuses on the interaction between the new overwrite-ignore options and the existing `-a/--all` flag, with Newren suggesting the current implementation may be masking an underlying design issue. The patch modifies `builtin/stash.c` to handle include-untracked modes and the new overwrite behavior, but these changes may need further refinement based on the feedback.
