This is a bugfix for `git stash`'s handling of ignored files, addressing a long-standing FIXME where it would unconditionally overwrite ignored files during index updates. Pushkar Singh's patch introduces proper support for the `--overwrite-ignore` and `--no-overwrite-ignore` options, with backward-compatible behavior as the default.

The patch fixes an issue where `stash -a` (include all files) would incorrectly remove ignored files even when `--no-overwrite-ignore` was specified. The solution downgrades the INCLUDE_ALL_FILES flag to include-untracked when overwrite_ignore is false. The v2 revision addresses reviewer feedback by correctly using a single OPT_BOOL for the option pair, adding test coverage for both behaviors, and including the missing Signed-off-by trailer.

Reviewers Karthik Nayak and Patrick Steinhardt identified implementation issues in v1, while Kristoffer Haugsbakk caught documentation problems. The patch now appears technically sound with comprehensive test coverage showing both the preservation of ignored files (with `--no-overwrite-ignore`) and their overwrite (with `--overwrite-ignore`). This brings `git stash` behavior in line with how `checkout` and `reset` handle ignored files.
