Bugfix for `git stash`'s new `--overwrite-ignore` option implementation. Kristoffer Haugsbakk points out two issues in Pushkar Singh's patch that aims to fix how `git stash` handles ignored files during index updates.

First, the commit message uses past tense ("cleared", "left") when it should use present tense to describe the current behavior, following Git's documentation standards. Second, the patch is missing a required Signed-off-by trailer, which is necessary for contribution acceptance.

The patch itself introduces new `--overwrite-ignore`/`--no-overwrite-ignore` options to control whether `git stash` preserves ignored files during operations, addressing a long-standing FIXME. This aligns stash behavior with other commands like `checkout` and `reset`. The implementation had already been flagged by Karthik Nayak and Patrick Steinhardt for incorrectly using two `OPT_BOOL` calls when the parse-options API can handle the `--no-` variant automatically.

Kristoffer's review focuses on the submission requirements rather than the technical implementation, which had already received thorough review from others. The patch appears to be a straightforward improvement once these documentation and process issues are addressed. The change maintains backward compatibility by defaulting to overwriting ignored files while providing the new option to preserve them.
