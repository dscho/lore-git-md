This is a release announcement for Git for Windows, the Windows-specific fork of Git maintained by Johannes Schindelin. It announces version 2.53.0, which tracks upstream Git 2.53.0 while adding Windows-specific improvements and fixes.

The release includes several notable changes: Tab key behavior in Git Bash is fixed to prevent freezing, the installer now uses InnoSetup 6.6.1, and Microsoft Edit can now be specified as the Git editor. The bundled components have been updated, including cURL 8.18.0, Git Credential Manager 2.7.0 (with native ARM64 support), mimalloc 2.2.7, and OpenSSL 3.5.5.

Bug fixes address installer text clipping issues, I/O setup for Microsoft Store apps, and handling of empty files by the astextplain tool. The announcement provides SHA-256 checksums for all distribution variants (64-bit, ARM64, portable, MinGit, and busybox versions).

As with all Git for Windows releases, this is distinct from the upstream Git project's releases, though it tracks the same version number. The changes are specific to the Windows platform and packaging.
