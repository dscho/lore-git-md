Documentation patch in a series enhancing `git submodule foreach` with new dependency-aware traversal options. This is the fifth patch in the series, focusing on updating the man page to document the new `--reverse-traversal`, `--append-superproject`, and `--reversive` flags.

The patch adds documentation for the new traversal modes that enable post-order (bottom-up) processing of submodules, which is particularly useful for cleanup operations where child submodules must be processed before their parents. The flags only take effect when used with `--recursive`.

Jean-Noël Avila provides specific documentation style feedback, noting that the patch should align with the ongoing transition to synopsis-style markup in Git's man pages. He requests two changes: wrapping option names in backticks (`` `--reverse-traversal` ``) and restructuring the description to lead with the option's action rather than its constraints. The author acknowledges the feedback and indicates these changes will be incorporated in the next version.

This patch is part of a series that has received conceptual approval from the maintainer, with discussion now focused on interface naming and documentation presentation. The implementation itself (in previous patches) appears uncontroversial, touching `builtin/submodule--helper.c` and `git-submodule.sh` while adding test coverage in `t/t7425-submodule-reversion.sh`. The documentation updates are part of a broader man page standardization effort led by Jean-Noël Avila.
