This is a follow-up discussion in the RFC thread about improving `git format-patch`'s cover letter commit list format. Junio C Hamano responds to Mirko Faina's proposal to replace the current author-grouped shortlog with a numbered chronological list.

Junio suggests making the format configurable through a new `format.commitListFormat` setting that would accept printf-style format specifiers. He proposes examples showing how this could produce either simple numbered entries ("[1/1] subject") or include author names ("[1/1] subject (Author Name)"). The configuration would default to the current shortlog format when unspecified.

The discussion continues exploring alternatives to the original proposal's commit hashes, which Junio had previously dismissed as "useless garbage" since they wouldn't match the final repository state. Mirko had suggested showing author identifiers instead, and Junio's response formalizes this as a configurable option.

This exchange moves the design toward greater flexibility while still addressing the core motivation - making patch series flow more apparent. The maintainer appears open to the concept but wants to preserve backward compatibility through configuration rather than a hard switch. The thread remains focused on design validation before implementation refinements.
