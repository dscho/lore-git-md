This is part 3 of a 6-patch series in the ongoing `the_repository` removal effort, specifically targeting the merge-ort and replay subsystems. The patch systematically replaces all remaining direct uses of the `the_repository` global variable in merge-ort.c with repository-specific parameters from `opt->repo`.

The changes are mechanical but thorough, covering tree parsing, blob reading/writing, merge base calculations, configuration handling, and hash algorithm access. Key conversions include updating `repo_parse_tree()`, `read_mmblob()`, `odb_write_object()`, and various config access functions to use the repository instance passed through the merge options rather than the global.

This patch builds on the previous two in the series (which handled prefetch logic and `write_tree()`) to complete the repository context propagation through merge-ort. The changes are straightforward replacements with no behavior modifications, just ensuring all operations use the correct repository context. The patch maintains Elijah Newren's authoritative handling of merge-ort internals while advancing the broader repository abstraction work.

With Patrick Steinhardt having already approved the approach in previous iterations, this patch appears ready for integration as part of the complete series. It demonstrates the careful attention to repository context propagation needed for the `the_repository` removal effort while keeping the ort merge strategy's behavior.
