This is part 3 of a 6-patch series removing `the_repository` usage from merge-ort and replay, part of the ongoing `the_repository` removal effort. The patch focuses on converting repository access in merge-ort.c to use the repository parameter (`opt->repo`) rather than the global `the_repository`.

Elijah Newren systematically replaces all direct uses of `the_repository` in merge-ort.c with `opt->repo`, covering tree parsing, blob operations, merge base calculations, and configuration handling. The changes are mechanical but thorough, touching key functions like `collect_3way_info()`, `handle_content_merge()`, and the configuration parser. This continues the work started in earlier patches to properly propagate repository context through the merge machinery.

The patch demonstrates Elijah's deep knowledge of merge-ort internals, with careful attention to maintaining correct behavior while removing the global variable dependency. This version incorporates feedback from Patrick Steinhardt's review of v2, showing the series is maturing well. The changes are straightforward and unlikely to be controversial, representing solid progress in the broader repository abstraction work.
