This is a follow-up in the ongoing discussion about improving `git format-patch`'s cover letter commit list format. Junio C Hamano responds to Mirko Faina's proposal to replace the current author-grouped shortlog with a numbered chronological list.

Junio suggests making the format configurable through a new `format.commitListFormat` setting that would accept printf-style format specifiers. The default would show just the numbered subject line ("[1/1] subject"), while custom formats could include author names ("[1/1] subject (Author Name)") or other commit metadata. When unset or false, it would fall back to the current shortlog grouping.

The proposal addresses two key concerns from earlier discussion:
1. Whether to include commit hashes (now dropped as "useless garbage")
2. Whether to make the format configurable (now proposed as a flexible format string)

Junio's suggestion moves beyond the binary choice between shortlog vs commitlist that Mirko proposed, offering instead a template system that could satisfy both the original flow-visibility goal and potential future customization needs. The thread appears to be converging toward a design that preserves the current behavior while enabling the improved chronological view, with the exact syntax still under discussion.

The maintainer's engagement suggests the feature has conceptual approval pending resolution of these interface details, though the implementation will still need to address the known technical issues (ordering, memory management) once the design settles.
