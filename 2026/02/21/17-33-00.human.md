This is a follow-up discussion on the configurable cover letter format feature for `git format-patch`. Maintainer Junio C Hamano responds to Mirko Faina's concerns about the proposed command-line interface for overriding the format.

The thread has settled on implementing a flexible `format.commitListFormat` configuration that uses printf-style format strings to customize how commits are listed in cover letters. The default will show "[N/M] subject" while allowing custom formats like "%s (%an)" to include author names. 

Junio strongly advocates for keeping the command-line override capability (`--cover-letter=log:"..."`), arguing that configuration options should always allow runtime exceptions even if the default works most of the time. Mirko had questioned whether this was necessary given the goal of establishing good defaults, but Junio maintains that flexibility is essential for any configuration system.

The exchange shows the feature design is nearly finalized, with only minor interface details remaining. The maintainer's position on config+override as a standard pattern appears decisive, suggesting this will likely be implemented as proposed unless significant new objections emerge. The patch appears well-considered and addresses a clear usability need for patch series authors.
