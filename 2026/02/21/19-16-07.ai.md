This is a follow-up in the ongoing discussion about configurable cover letter formatting for `git format-patch`. The thread has established that the feature will use a `format.commitListFormat` configuration with printf-style formatting, and Junio has emphasized the necessity of a command-line override capability.

Mirko Faina acknowledges Junio's point about always needing command-line override capability for configuration settings, agreeing to implement this functionality in the coming week. The exchange shows the proposal moving from design discussion to implementation phase, with the maintainer's guidance ensuring the solution adheres to Git's configuration philosophy while preserving the original goal of customizable cover letter commit lists.

The technical approach is now settled: printf-style format string configuration with mandatory command-line override, defaulting to "[N/M] subject" format. The remaining work appears to be purely implementation of the agreed design, particularly the command-line syntax for overrides. This represents the final step before the feature can be considered ready for merging.
