This is a follow-up in the ongoing discussion about configurable commit list formatting for `git format-patch` cover letters. The thread has reached consensus on using a `format.commitListFormat` configuration with printf-style formatting, but maintainer Junio C Hamano has emphasized the need for a command-line override capability.

Mirko Faina, the patch author, acknowledges Junio's point about the importance of command-line overrides for configuration settings. He confirms he will implement this functionality in the coming week, indicating the feature is moving from design discussion to implementation.

The exchange shows the patch is progressing well through the RFC phase, with the maintainer's guidance being incorporated. The remaining work appears to be straightforward implementation of the agreed-upon design rather than any fundamental changes. This suggests the feature is likely to land in a future Git release once the command-line override is implemented and any remaining issues (like the known memory leak) are addressed.
