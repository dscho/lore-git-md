This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git man pages to consistent AsciiDoc synopsis-style formatting. It's the second of four patches in v4 of the series, specifically finalizing the conversion of `git-clone.adoc`.

The patch makes several formatting improvements to the clone documentation:
- Wraps command-line options in backticks consistently (e.g. `--server-option=<option>` instead of ++--server-option=++__<option>__)
- Standardizes option syntax formatting (e.g. `-o <name>` instead of `-o` _<name>_)
- Maintains proper spacing between option variants (e.g. `-f | --force` style)
- Preserves the semantic meaning while improving visual consistency

Kristoffer Haugsbakk has reviewed all versions of this conversion and gives his Reviewed-by for this version, having previously declared the `git-clone.adoc` conversion "spotless" in earlier iterations. The changes are purely presentational - no behavioral information is altered - and follow the project's established documentation standards. This represents another incremental step in the multi-year effort to bring all Git documentation to a consistent format.
