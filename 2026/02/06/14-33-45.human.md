This is a feature patch completing the reference backend selection mechanism, allowing runtime switching between files and reftable backends via environment variable. The patch adds `GIT_REFERENCE_BACKEND` as an environment-variable counterpart to the existing `extensions.refStorage` config option, with the environment variable taking precedence when both are set. The syntax matches the config option's URI format (e.g. `reftable:///path/to/refs`).

Patrick Steinhardt provides final review feedback on the documentation wording, suggesting two small improvements: correcting "git" to "Git" in the commit message and changing "for more description" to "for more details" in the environment variable documentation. These are minor polish items for what appears to be a technically complete implementation.

The patch is part of a larger effort to enable zero-downtime migrations between reference backends, primarily for GitLab's use case. With all substantive technical issues resolved in previous iterations, this final version addresses documentation nits before potential integration. The series has already undergone extensive review from multiple contributors including Karthik Nayak, Toon Claes, and Eric Sunshine.
