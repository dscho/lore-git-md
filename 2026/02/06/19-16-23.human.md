This is the second patch in a two-part series that integrates the `merge-ours` strategy with Git's sparse-index functionality, part of the ongoing sparse-checkout/sparse-index optimization effort.

The patch enables `git merge -s ours` to work efficiently with sparse checkouts by preventing unnecessary index expansion. It does this by:
1. Adding proper configuration reading via `repo_config()` to populate sparse-checkout settings
2. Explicitly setting `command_requires_full_index = 0` to allow sparse-index operation
3. Adding test coverage in t1092 to verify identical behavior between full and sparse modes and confirm no index expansion occurs

The changes are minimal (6 lines of implementation plus 14 lines of tests) but follow the established pattern for sparse-index integration seen in other commands. The patch builds on the first in the series (which removed `the_repository` usage) and has addressed all maintainer feedback from the initial version. 

This is a straightforward, well-contained improvement that aligns with the project's sparse-index optimizations and `the_repository` removal efforts. The changes are small, focused, and come with appropriate test coverage, making this a low-risk addition likely to be merged.
