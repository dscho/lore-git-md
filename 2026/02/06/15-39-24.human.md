This is a follow-up to Patrick Steinhardt's Meson build system integration series, specifically addressing a Windows build issue with the `msgfmt` tool. The thread has been tracking the effort to wire up gitk and git-gui in Meson while maintaining compatibility with the existing Makefile.

Jeff King identified a CI failure on Windows where the build couldn't find the `msgfmt` executable (part of gettext). Patrick quickly diagnosed the issue - while the code handled missing `msgfmt`, the Meson configuration didn't mark it as optional. He submitted a fix to the gitk repository (j6t/gitk#37) which has now been merged.

The email shows the fix working in practice and confirms the symlink approach functions on Windows. Patrick is now seeking guidance from Junio Hamano on how to proceed with integrating this fix into the main Git repository, as subtree merges can't be sent via email. The CI verification PR (#2190) is already open to confirm the Windows build now passes.

This represents the last remaining issue for Windows compatibility in the Meson build system modernization effort, with all core functionality now working. The series appears ready for final integration pending resolution of this administrative question about the gitk subtree update process.
