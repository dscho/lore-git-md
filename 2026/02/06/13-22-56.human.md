This is the first patch in a 5-part series addressing submodule `ignore=all` behavior consistency across Git commands. The series aims to align `git add` with how `git status` and `git diff` handle ignored submodules.

Patch 1/5 is a plumbing change that adds an `ignored_too` parameter to `add_files_to_cache()`, which will be used to explicitly update the index for submodules that would normally be ignored. The change is mechanical, updating the function calls and declarations across several files (`builtin/add.c`, `builtin/checkout.c`, `builtin/commit.c`, and related headers).

The patch maintains the existing behavior by passing `0` for `ignored_too` in all current callers, as the actual behavior change will come in later patches. This is a clean preparatory change that follows the project's convention of splitting plumbing and behavior changes.

The patch appears well-structured with a clear commit message and proper sign-off. It's part of a larger effort that has gone through multiple iterations (now at v4) with active review from several contributors including Junio C Hamano, Phillip Wood, and Ben Knoble. The series as a whole has comprehensive test coverage and documentation updates in subsequent patches.
