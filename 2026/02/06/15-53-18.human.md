HTTP authentication test patch with netrc focus

This is a test patch in the ongoing series about HTTP authentication with .netrc files, specifically handling 401 (Unauthorized) and 403 (Forbidden) responses. The discussion clarifies that these tests primarily verify curl's built-in netrc handling rather than Git's credential helper system, confirming Git properly enables curl's netrc support without exercising Git-specific credential logic.

Jeff King notes the tests have limited practical value for Git's own code paths since they mostly test curl internals, though they serve to document behavior. The author Ashlesh Gawande responds to feedback about GitHub's actual behavior (401->404 sequence versus 403 with fine-grained tokens) and considers adjusting the test case to better reflect real-world scenarios.

The patch appears technically sound with proper test cleanup and improved commit messages. While Junio C Hamano has reviewed all versions with feedback addressed, the broader question of netrc's future remains unresolved but outside this patch's scope. The series seems ready for inclusion as a documentation of behavior, if not as a critical test of Git's own functionality.
