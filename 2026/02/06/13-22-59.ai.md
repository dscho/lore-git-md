This is a test update patch in a series addressing submodule `ignore=all` behavior consistency. It's part 4/5 of the v4 series that aligns `git add` behavior with `git status` and `git diff` when dealing with ignored submodules.

The patch updates existing test files to account for the new requirement that `git add` operations on ignored submodules must use the `--force` flag. It modifies four test files (via two direct changes in this patch) where tests were relying on the old behavior of `git add` automatically updating submodule references. The changes are mechanical replacements of `git add submodule` with `git add --force submodule` in test setup code.

The test updates cover:
- Shared submodule test library (`t/lib-submodule-update.sh`)
- Status command tests (`t7508-status.sh`)
- With indirect updates to two other test files through the library changes

This follows the series' established pattern where the core behavior change (in patch 2) requires explicit `--force` for ignored submodule updates, and all tests must be updated accordingly. The changes maintain test coverage while adapting to the new stricter behavior.
