This thread discusses Sam Bostock's two-patch series to integrate the `merge-ours` strategy with Git's sparse-index functionality. The first patch (now at v2) removes reliance on the `the_repository` global variable in `builtin/merge-ours.c`, following the project's established pattern for such refactorings. The changes are straightforward - replacing global access with the repository parameter that's guaranteed to be non-NULL due to the `RUN_SETUP` registration. This preparatory refactoring enables the second patch (not shown here) to add proper sparse-index support.

The series is part of two ongoing efforts: the sparse-checkout/sparse-index optimizations led by Derrick Stolee and Elijah Newren, and the broader removal of repository globals championed by René Scharfe and Patrick Steinhardt. Maintainers Junio Hamano and Patrick Steinhardt reviewed the initial version and confirmed the technical approach; their feedback about improving the commit message documentation has been incorporated in v2. With all feedback addressed and the changes following established patterns, this appears ready for inclusion in the next integration cycle.
