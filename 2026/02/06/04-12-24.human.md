This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git man pages to consistent AsciiDoc synopsis-style formatting. It's the second patch in a v4 series of four, focusing on finalizing the `git-clone.adoc` conversion.

The patch makes several formatting improvements to the `git-clone` documentation:
- Consistently wraps command-line options in backticks
- Standardizes the presentation of option-value pairs (like `-o <name>` instead of `-o` _<name>_)
- Maintains proper syntax highlighting and placeholder notation
- Kristoffer Haugsbakk has reviewed and approved this version with a Reviewed-by tag, noting it addresses all previous feedback.

This continues the project's meticulous documentation standardization work where even stylistic changes undergo multiple review iterations before finalization. The changes are purely presentational with no behavioral impact.
