This is the final patch in a series implementing reference storage backend selection for zero-downtime migrations between backends (files<->reftable), primarily targeting GitLab's migration needs. The series has gone through multiple rounds of review and now includes both configuration (`extensions.refStorage`) and environment variable (`GIT_REFERENCE_BACKEND`) control mechanisms.

Patrick Steinhardt provides final review feedback on Karthik Nayak's v4 patchset, noting that while he has some minor comments, he's generally pleased with how the implementation has shaped up. The key technical additions in v4 include proper worktree support (storing references in `ref_dir/worktrees/wt_id` with stubs in the git dir) and relative path resolution relative to `GIT_DIR`.

The series appears technically complete, having addressed all substantive feedback from multiple reviewers including Patrick himself, Junio Hamano, Eric Sunshine, and others. The environment variable support was the last major piece added, and all architectural decisions seem settled. This looks ready for final consideration by the maintainer.
