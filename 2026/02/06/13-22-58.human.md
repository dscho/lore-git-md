This is the third patch in a 5-part series addressing submodule behavior with `ignore=all`, specifically ensuring `git add` aligns with how `git status` and `git diff` handle ignored submodules. The series introduces a `--force` flag to override the ignore setting when needed.

This test patch adds comprehensive coverage for the new behavior, with 8 test cases verifying:
1. Baseline submodule setup and default behavior
2. Status/log behavior with `ignore=all` configured
3. The effect of `--ignore-submodules=none` on status output
4. That normal `git add` skips ignored submodules (with trace output)
5. That `git add --force .` respects the ignore setting (contrary to expectations, which the test confirms)
6. Explicit submodule pathspec behavior with and without `--force`
7. That `--force` properly stages submodule changes when explicitly requested
8. Log visibility of forced updates when using `--ignore-submodules=none`

The tests cover both direct submodule paths (`sub`) and pathspecs with trailing slashes (`./sub/`), and include trace output to verify the skip logic. The test file is added to meson.build for execution in the Meson build system.

This patch completes the test coverage for the series' core functionality, complementing the plumbing changes and documentation updates in other patches. The tests are thorough and well-structured, following Git's established test patterns while adding new coverage for the `--force` override behavior.
