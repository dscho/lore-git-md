This is a documentation patch converting the `git-submodule` man page to the standardized AsciiDoc synopsis style, part of Jean-Noël Avila's ongoing documentation standardization effort. The patch systematically reformats the submodule documentation with consistent command syntax highlighting, proper placeholder notation (`_<arg>_`), and conversion of inline lists to definition lists. The conversion maintains compatibility with both asciidoc.py and asciidoctor toolchains while resolving several documentation quirks - particularly around submodule terminology and command syntax. The changes are purely presentational with no behavioral impact, following the project's established pattern for documentation standardization patches.
