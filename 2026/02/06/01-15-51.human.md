This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the current state of development branches and pending topics. The report covers both new topics and those that have been cooking for some time.

Several documentation fixes and test updates are ready to merge to 'master', including GitHub contribution guide links, test modernization, and man page corrections. More substantial changes include:

- A new `GIT_REFERENCE_BACKEND` environment variable and config option to specify reference backend storage locations (kn/ref-location)
- Hook system improvements allowing parallel execution and config-based hook definitions (ar/parallel-hooks)
- A fix for GPG signature validation to properly handle signatures from expired keys (uk/signature-is-good-after-key-expires)
- Ongoing work on the object database abstraction (ps/odb-for-each-object) and reference backend improvements (kn/ref-location)
- Multiple patches related to the hook subsystem modernization (ar/config-hooks, ar/parallel-hooks)

The report notes several topics that need review or may require rerolls, including meson build system integration for gitk/git-gui (ps/meson-gitk-git-gui) and improvements to the "git last-modified" command (tc/last-modified-not-a-tree).

Some larger efforts continue cooking, like the incremental MIDX repacking work (tb/incremental-midx-part-3.2), SHA-1/SHA-256 interoperability (bc/sha1-256-interop-02), and the new "git history" command (ps/history). The report also mentions the Rustification effort's CI breakages still needing resolution.

The report serves as both a status update and a call for review on the various topics, with clear indicators of what's stable ('next'), what's experimental ('seen'), and what needs attention. Junio notes that Git 2.53 has been tagged and they're waiting for potential regression reports before starting the next development cycle.
