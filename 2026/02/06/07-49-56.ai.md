This is the first patch in a 4-part series fixing bugs in bitmap and bisect functionality related to ref matching. The patch refactors duplicate logic for iterating over preferred bitmap tips (configured via `pack.preferBitmapTips`) into a new `for_each_preferred_bitmap_tip()` helper function.

The change consolidates two existing callsites that were both incorrectly handling exact refname matches, which could trigger a BUG(). The new helper function will be used by both `pack-objects` and `repack-midx` code paths. The patch also makes the `bitmap_preferred_tips()` function file-local since it's now only used within `pack-bitmap.c`.

This is a preparatory refactoring that enables the actual bugfix in subsequent patches. The changes are mechanical and well-contained, touching only the bitmap-related code paths. The patch follows the established pattern in the thread of deduplicating logic while fixing the underlying issue with ref matching.
