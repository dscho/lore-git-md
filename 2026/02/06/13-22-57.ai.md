This is the core behavior patch in a series addressing submodule `ignore=all` consistency across Git commands. The change makes `git add` skip submodules with `ignore=all` configuration unless explicitly forced with `--force`, aligning with how `git status` and `git diff` already handle such submodules.

The patch introduces a comprehensive `skip_submodule()` helper function that:
- Verifies path is a directory and submodule
- Checks for `ignore=all` configuration
- Validates pathspec matching
- Handles `--force` flag override
- Provides user guidance via advice message when skipping

Key technical details:
- Maintains backward compatibility through the `ignored_too` parameter
- Preserves existing sparse checkout behavior
- Adds trace output for debugging
- Uses existing advice infrastructure for user messaging
- The implementation follows the thread's settled approach using `--force` rather than alternative naming like `--include-ignored-submodules`
- The commit message explains the workflow benefits for branch tracking in submodules where users want loose coupling rather than SHA-1 tracking
