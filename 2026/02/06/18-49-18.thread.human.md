This thread explores a proposed new `git log --graph --untangle` option to simplify visualization of complex histories, particularly for octopus merges. Toon Claes's RFC patch suggests altering how merged branches are displayed by suppressing some ancestry lines, making the graph less cluttered while preserving the key relationships. The implementation would modify graph.c's column tracking and merge base calculations.

Junio Hamano, the Git maintainer, has responded positively to the general concept, noting he's long wanted improvements in this area. He's not weighing in on specifics yet but has asked to see concrete examples of how the proposed output would render the complex histories that motivated the change. This keeps the discussion open while signaling that compelling visual demonstrations could help move the proposal forward.

The thread remains in the RFC phase, with open questions around naming (`--untangle` vs alternatives), memory management of the new data structures, and handling of complex merge scenarios. The next steps will likely involve Toon providing the requested visualization examples and addressing the memory leaks he's already identified, after which more detailed technical discussion can proceed.
