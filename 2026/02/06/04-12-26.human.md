This is a documentation patch completing Jean-Noël Avila's v4 series standardizing Git man pages to AsciiDoc synopsis-style formatting. The final patch converts `git-show.adoc` and `pretty-formats.adoc` to the new style, with Kristoffer Haugsbakk's Reviewed-by confirming the changes maintain technical accuracy while improving consistency.

The changes include:
- Adding synopsis-style block definitions in `asciidoc.conf.in`
- Converting command syntax blocks to use the new `[synopsis]` format
- Standardizing placeholder formatting (e.g. `<placeholder>`)
- Minor formatting fixes throughout

This follows the same pattern seen in earlier patches of the series, with careful attention to preserving all technical content while making the documentation more consistent. The `pretty-formats.adoc` conversion is particularly extensive, restructuring the format descriptions into a more uniform presentation.

With this patch, the v4 series appears complete and well-reviewed, representing another step forward in the ongoing documentation standardization work. The changes are purely presentational with no behavioral impact.
