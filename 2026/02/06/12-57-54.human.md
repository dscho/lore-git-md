This resolves the NULL safety issue in `worktree_git_path()` that was identified in earlier discussion. The author reports that the changes pass all tests.

The patch modifies several files (`wt-status.c`, `branch.c`, `worktree.c`, and `wt-status.h`) to consistently pass repository and status state structures through function calls. Notable changes include updating stash counting, rebase state reading, porcelain v2 output handling, and hash algorithm usage. The solution establishes patterns for safe repository access in refactored code.

The patch appears well-tested and addresses the core technical concerns raised in previous rounds of review.
