This is a test patch adding coverage for HTTP authentication with .netrc files, specifically handling 401 (Unauthorized) and 403 (Forbidden) responses. The patch adds three test cases to t5550-http-fetch-dumb.sh that verify successful cloning with valid .netrc credentials, proper credential prompting after a 401 response, and immediate failure on 403 responses without credential retry.

The tests use new `set_netrc()` and `clear_netrc()` helper functions to manage test credentials, with proper cleanup via `test_when_finished`. Junio notes the clear distinction between 401 (unknown user) and 403 (known but unauthorized user) behavior in his reply, while also asking whether similar tests exist for other credential helpers. The implementation appears solid, following test suite conventions after incorporating feedback from earlier reviews.

This patch completes the test coverage for .netrc authentication scenarios that was started in the earlier versions of this series. While there was some discussion about potentially deprecating .netrc files entirely, this patch focuses strictly on testing the current behavior without modifying production code.
