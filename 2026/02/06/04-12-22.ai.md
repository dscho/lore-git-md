Documentation patch series finalizing synopsis-style conversions for several man pages, with Kristoffer Haugsbakk's review sign-off.

This is the fourth iteration of Jean-Noël Avila's ongoing effort to standardize Git's documentation formatting. The series converts `git-submodule` and `git-show` to the new synopsis style while fixing residual issues in previously converted pages (`git-clone`, `for-each-ref-options`). Kristoffer Haugsbakk, a frequent documentation contributor, has reviewed all versions and now provides his Reviewed-by for v4, indicating the changes meet his quality standards.

Key technical changes include standardizing references to `HEAD` and `origin` (now consistently backtick-wrapped as reserved terms), fixing decoration rendering, and improving option syntax. The patches touch multiple documentation files but are purely presentational - no behavior changes. The work maintains compatibility with both asciidoc.py and asciidoctor toolchains.

With Kristoffer's thorough review and Jean-Noël's responsive iterations addressing all feedback, these documentation conversions appear ready for merging. The series exemplifies the project's careful, consensus-driven approach to documentation improvements, where even stylistic changes undergo multiple review rounds before finalization.
