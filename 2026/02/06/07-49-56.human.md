This is a refactoring patch that's part of Patrick Steinhardt's series fixing issues with bitmap and bisect functionality when processing exact branch names. The patch consolidates duplicate logic for iterating over preferred bitmap tips (configured via `pack.preferBitmapTips`) into a new `for_each_preferred_bitmap_tip()` function.

The change removes the last external caller of `bitmap_preferred_tips()`, allowing it to be made file-local to pack-bitmap.c. The refactoring prepares for fixing a BUG() that occurs when preferred bitmap tips contain exact refname matches. The patch maintains all existing functionality while cleaning up the code structure.

This is the first of four patches in the series, which has already gone through multiple iterations with positive feedback from reviewers including Taylor Blau and Junio Hamano. The series as a whole addresses both bitmap and bisect cases, using ref hierarchy matching (with trailing slashes) for consistency with Git's ref matching conventions.
