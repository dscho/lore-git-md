This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git's man page formatting. The patch focuses on style improvements for `git-clone.adoc`, `for-each-ref-options.adoc`, and `ref-storage-format.adoc`.

The changes include several consistent formatting updates: spelling out all forms of `--[no-]reject-shallow` options, using imperative mood for option descriptions, standardizing the NOTE macro in AsciiDoc, and fixing various markup issues. The patch also improves consistency in option formatting (e.g. changing `-o <name>` to `-o<name>`) and clarifies some descriptions.

Kristoffer Haugsbakk has reviewed and approved these changes, having previously declared the `git-clone.adoc` conversion "spotless" in earlier iterations. This patch is part 3 of a 4-part series that has undergone multiple rounds of review, demonstrating the careful attention given to documentation standardization in the Git project. The changes are purely stylistic and don't affect functionality.
