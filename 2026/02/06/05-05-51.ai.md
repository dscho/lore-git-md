This is a test patch in the ongoing HTTP authentication testing series, specifically focusing on .netrc credential handling for 401 (Unauthorized) and 403 (Forbidden) responses. The patch adds three test cases to t5550-http-fetch-dumb.sh that verify different authentication scenarios when using .netrc files: successful authentication with valid credentials, credential prompting after a 401 response, and immediate failure on 403 responses without credential prompting.

The test infrastructure includes new helper functions `set_netrc()` and `clear_netrc()` in t/lib-httpd.sh for managing .netrc files during tests. The test cases cover: (1) successful cloning with correct .netrc credentials, (2) failed cloning with invalid credentials (triggering a 401 and subsequent credential prompt), and (3) failed cloning with valid but unauthorized credentials (resulting in a 403 without prompting). The Apache test configuration was modified to support the 403 test case by adding a "forbidden-user" case.
