Feature patch completing the `--rework-with-file` series for interactive hunk selection. This third patch fixes a behavioral edge case where hunk decisions could be incorrectly applied when navigating between files with the new inter-file navigation feature.

The change ensures patch application only occurs after all hunk decisions are finalized (when quitting the interface), rather than applying immediately when leaving a file. This prevents situations where a user might mark a hunk for use, navigate away, then return and change their mind to skip it - previously the hunk would remain applied despite the skip decision. The core change extracts patch application logic into a new `apply_patch()` function and calls it either immediately (default behavior) or at the end (with `--rework-with-file`).

The 66-line diff touches only `add-patch.c`, focusing on the state machine around hunk application timing. It maintains all existing behavior when not using the new flag. This appears to be the final piece of the series after Junio's feedback on prior versions, completing the inter-file navigation feature while fixing this subtle interaction case.
