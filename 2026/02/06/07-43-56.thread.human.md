This builds on Wood's earlier work standardizing hook infrastructure and adding diff detection capabilities.

The solution represents a layered approach - while deeper parser improvements in `git am` continue to be debated, these hook-based changes provide immediate security benefit for projects that adopt them. The implementation carefully maintains backward compatibility and handles edge cases like custom comment characters ending with "$".
