This is the first patch in a v4 series addressing submodule `ignore=all` behavior consistency. The patch introduces plumbing change to support explicit submodule updates via pathspec.

The change adds an `ignored_too` parameter to `add_files_to_cache()` to allow callers to explicitly include ignored submodules when updating the index. This is part of making `git add` behavior consistent with `git status` and `git diff` when dealing with submodules marked with `ignore=all`.

The implementation:
- Adds the new parameter through the call chain from `cmd_add()` down to the diff machinery
- Updates all existing callers to pass 0 for backward compatibility
- Extends the `update_callback_data` struct to carry the new flag through to the diff processing

This is a foundational change for the series, enabling the subsequent patches to implement the actual behavior change where `git add --force` will override submodule ignore settings. The patch maintains all existing behavior when the new parameter is 0, making it a safe preparatory step.

The change touches several core commands (`add`, `checkout`, `commit`) and the index update machinery, but is narrowly focused on adding the plumbing hook without yet changing any observable behavior. The v4 iteration preserves the technical approach from previous versions while incorporating feedback on documentation and test coverage in later patches.
