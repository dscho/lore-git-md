This is a documentation patch completing Jean-Noël Avila's v4 series standardizing Git man pages to AsciiDoc synopsis-style formatting. The final patch converts `git-show.adoc` and `pretty-formats.adoc` to the new style, with Kristoffer Haugsbakk's Reviewed-by confirming the changes are purely presentational while maintaining all technical content.

Key changes include:
- Adding synopsis block definitions in `asciidoc.conf.in` to support the new formatting
- Converting command syntax blocks to use `[synopsis]` markup
- Standardizing placeholder notation to `_<placeholder>_` format
- Reformatting the extensive pretty formats documentation with consistent section headers and code block styling
- Applying minor formatting fixes throughout

The patch follows the same high-quality pattern seen in earlier conversions in this series, with careful attention to preserving all existing information while improving presentation. The changes have undergone multiple review rounds (v1-v4) and now appear ready for merging as part of this long-running documentation standardization effort.
