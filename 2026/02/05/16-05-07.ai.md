This is a platform compatibility patch adding macOS support for Git's TRACE2 process ancestry tracing, part of a 4-patch series that also refactors the Windows implementation. The patch introduces a new `compat/darwin/procinfo.c` that uses macOS's `sysctl` with `KERN_PROC` to gather parent process IDs and names, matching the existing Linux implementation's behavior (which uses procfs) rather than the Windows approach of emitting a custom `data_json` event.

The implementation recursively walks the process tree up to a depth of 10 (NR_PIDS_LIMIT) to avoid cycles, stopping at PID 1 (launchd). It emits the ancestry chain via the existing `trace2_cmd_ancestry()` interface used by Linux, ensuring consistent event formatting across Unix-like platforms. The code structure mirrors the Linux version while using macOS-specific system calls, with careful handling of edge cases like process lookup failures.
