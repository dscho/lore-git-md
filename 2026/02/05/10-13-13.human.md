Refactoring patch in the ongoing `the_repository` removal effort, specifically targeting the working tree status machinery. This is the third patch in version 2 of a series that has already gone through several review cycles with input from Karthik Nayak, Junio C Hamano, and Phillip Wood.

The patch eliminates remaining uses of the global `the_hash_algo` in `wt-status.c`, replacing them with the hash algorithm from the local repository instance (accessed via `s->repo->hash_algo` or `r->hash_algo`). The changes are mechanical but important for consistency - they ensure the working tree status code uses the same hash algorithm as the repository it's operating on, rather than relying on global state.

Three specific changes are made:
1. Updating cherry-pick head OID initialization to use the local repo's hash algo
2. Doing the same for revert head OID initialization
3. Using the local repo's empty tree hash instead of the global one

The patch follows the established pattern in this series of systematically replacing global dependencies with proper repository context. While small, it's part of a larger effort to make `wt-status.c` properly repository-aware. The changes have been reviewed for safety and correctness, with the behavioral impact being minimal since in practice the local hash algo would match the global one.
