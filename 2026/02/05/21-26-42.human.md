This is a CI/build system patch from the Git maintainer addressing a transient issue in GitHub Actions workflows. 

Junio Hamano reports that the CI jobs using `ubuntu:rolling` (the latest development version of Ubuntu) recently broke due to a bug in the `uutils` implementation of `dirname`. The patch switches most affected jobs from `ubuntu:rolling` to the more stable `ubuntu:latest` as a temporary workaround.

The change is straightforward - it modifies 7 lines in `.github/workflows/main.yml` to use the stable Ubuntu image instead of the rolling release. Junio notes this is a temporary measure while `uutils` stabilizes, and leaves open the question of whether Git should continue using `ubuntu:rolling` (to help catch such issues early) or stick with more stable images. The patch is already in Junio's integration branches as part of today's updates.

This appears to be a pragmatic, low-risk fix for an immediate CI problem. The maintainer's note suggests this may be revisited later when the underlying `uutils` issue is resolved.
