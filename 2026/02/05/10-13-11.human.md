This is part 1 of a 3-patch series refactoring `wt-status.c` to remove dependencies on the global `the_repository` variable, as part of the ongoing `the_repository` removal effort.

The patch systematically replaces direct uses of `the_repository` with the repository pointer already available through `struct wt_status` (`s->repo`) or `struct worktree` (`wt->repo`). The changes are mechanical but important for reducing global state usage - they ensure functions use the repository instance they were given rather than implicitly reaching for the global.

Key changes include:
- Updating ref operations to use `s->repo` instead of `the_repository`
- Using the repository's hash algorithm from `s->repo` rather than the global
- Adjusting path lookups to use the correct repository context

The patch maintains behavior while making the repository dependencies explicit. Since `wt_status_prepare()` initializes `s->repo` from the caller-provided repository, these changes are safe - the repository pointer is guaranteed valid when these functions run. This is a clean, focused step in the larger refactoring effort.
