This is the final patch in a series extending Git's TRACE2 process ancestry tracing to macOS while unifying the Windows implementation. The patch provides a minor documentation correction to the commit message format, noting that commit references should use `git show -s --pretty=reference` (optionally with `--abbrev=8`) to include dates and standardize formatting. This is a style nit rather than a technical issue with the patch itself.

The patch series as a whole adds macOS support via `sysctl` with `KERN_PROC`, refactors the Windows implementation to separate data collection from JSON formatting, and finally unifies the output format across platforms while maintaining backward compatibility for existing consumers of the Windows JSON data. The changes are confined to platform-specific compatibility code and build files, with careful attention to cross-platform consistency.
