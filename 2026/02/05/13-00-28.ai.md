This is the second part of a two-patch series introducing AI-assisted workflows for Git's localization (l10n) process, specifically focused on documentation of guidelines for human translators using AI tools. The series comes from Jiang Xin, the Chinese translation maintainer.

The patch adds comprehensive documentation to po/README.md about using AI as an optional assistant in translation work while maintaining human control. It provides detailed technical guidelines for AI tools, including quality checklists, workflow recommendations, and handling of PO file specifics like plural forms and placeholder reordering. The documentation emphasizes that AI is only a tool and human translators remain responsible for final quality, cultural appropriateness, and technical accuracy.

Key technical aspects covered include:
- Maintaining glossaries in PO file comments for terminology consistency
- Using msgattrib commands to identify untranslated/fuzzy entries
- Proper handling of plural forms and placeholder reordering
- Splitting large PO files for processing within AI context limits
- Integration recommendations for AI tool developers

The patch also updates git-po-helper command examples to include the --pot-file=build option. This builds on the first patch in the series which implemented .gitattributes rules for location filtering in PO files.

The approach is pragmatic and implementation-focused, deliberately sidestepping the ongoing philosophical debates about AI-generated content that have been raised by other contributors like brian m. carlson. The documentation is thorough and well-structured, providing clear guidance while maintaining the primacy of human translators in the localization process.
