Build system integration for macOS process ancestry tracing. This is the second patch in a 4-part series adding TRACE2 process ancestry support to macOS while refactoring the Windows implementation. The patch adds build system support for the new `compat/darwin/procinfo.c` file introduced in patch 1, ensuring it gets compiled on macOS across all three supported build systems (Makefile, CMake, and Meson). 

The changes are straightforward and mechanical - each build system gets a conditional addition to include the Darwin-specific process info implementation when building on macOS. The Makefile addition sets `HAVE_PLATFORM_PROCINFO` and adds the object file to `COMPAT_OBJS`, while CMake and Meson simply add the source file to their respective source lists. The patch maintains consistency with how Linux and Windows process info implementations are already handled in each build system.

This is a well-structured patch that follows established patterns for platform-specific code in Git's build systems. The changes are minimal and focused, touching only build configuration files. As with the rest of the series, it shows careful attention to cross-platform consistency while keeping the scope tightly constrained to macOS support.
