This thread documents an edge case in `git merge-file`'s behavior regarding conflict style configuration. Yannik Tausch noticed that while `git merge-file` accepts `--diff3` and `--zdiff3` command-line flags in any context, it only respects the `merge.conflictStyle` configuration when run inside a Git repository - behavior that has existed since 2008 but wasn't documented. 

The proposed patch adds a clear note to the man page explaining this limitation. The change is purely documentation-focused and well-researched, addressing a subtle but real point of confusion without modifying any functionality. Given its straightforward nature and clear benefit to users, this seems likely to be accepted as a helpful clarification.
