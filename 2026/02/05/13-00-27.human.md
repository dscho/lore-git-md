This is a technical implementation patch in the ongoing discussion about AI-assisted localization workflows for Git. Jiang Xin, the Chinese translation maintainer, proposes adding a `.gitattributes` file to automate location filtering in `.po` files, building on earlier discussions about improving the l10n process.

The patch introduces two types of filters for translation files: one that strips both filenames and line numbers (`gettext-no-file-no-location`), and another that preserves filenames while removing line numbers (`gettext-no-location`). The default is the more aggressive stripping, with specific languages (Catalan, Indonesian, and both Chinese variants) configured to keep filenames. The accompanying README.md updates explain how contributors should set up the required filter drivers.

This appears to be a straightforward technical improvement to the translation workflow, separate from the more contentious AI aspects of the broader discussion. The implementation looks clean and well-documented, with clear instructions for contributors. While the patch is part of a larger debate about AI in localization, it focuses narrowly on a mechanical improvement to the existing process.
