This is the final patch in a series adding cross-platform process ancestry tracing to Git's TRACE2 performance instrumentation. The patch focuses on Windows compatibility, ensuring the Windows implementation emits ancestry data through both the new standardized `trace2_cmd_ancestry()` interface (added for Linux and macOS in earlier patches) while maintaining backward compatibility with the existing JSON format.

Kristoffer Haugsbakk provides a minor review comment noting that commit references in the commit message should follow Git's standard formatting (using `git show -s --pretty=reference`). The patch itself looks well-constructed - it cleanly separates the data collection from formatting while preserving existing behavior, and the dual-emission strategy is clearly documented. This completes the series that brings consistent process tracing across Linux, macOS and Windows platforms.
