Refactoring patch series (v2) targeting `wt-status.c` as part of the ongoing `the_repository` removal effort. This three-patch set from Shreyansh Paliwal eliminates direct dependencies on the global variables `the_repository` and `the_hash_algo` in the working tree status machinery.

The series systematically replaces global variable usage with repository instances already available through local structs (`wt_status` and `worktree`). Patch 1 handles direct `the_repository` replacements, patch 2 updates function signatures to explicitly pass repository contexts, and patch 3 switches hash algorithm access from the global `the_hash_algo` to repository-specific instances. The changes touch several files including `wt-status.c`, `branch.c`, and `worktree.c`.

While this removes all direct uses of the targeted globals, the cover letter notes that `USE_THE_REPOSITORY_VARIABLE` cannot yet be fully removed due to remaining dependencies on other global variables (`core_apply_sparse_checkout`, `comment_line_str`, and `DEFAULT_ABBREV`). The first is already being addressed in a separate series, while the latter two will require follow-up work. The patches appear well-scoped and focused, with clear documentation of current limitations. This represents solid incremental progress on the larger `the_repository` removal project.
