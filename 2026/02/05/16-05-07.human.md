This is a platform compatibility patch adding macOS support for Git's TRACE2 process ancestry tracing. It's the first in a 4-part series that extends and unifies process tracing across platforms.

The patch introduces a new `compat/darwin/procinfo.c` that implements macOS process ancestry collection using `sysctl` with `KERN_PROC` to get parent process IDs and names. The implementation follows the Linux model (added in commit 2f732bf1) by emitting a `cmd_ancestry` TRACE2 event, rather than the Windows-style `data_json` approach from commit 353d3d77. 

The code handles process chains recursively with a depth limit (10 levels) to prevent cycles, and skips system processes (PID 0/1). The implementation is clean and focused, with clear error handling and memory management. The author notes this could be extended in future to include macOS-specific exit statistics, matching Windows' memory tracking.

This appears well-considered platform work that maintains consistency with existing tracing while adding macOS support. The patch stands alone but clearly fits into the broader series goal of unifying process tracing across platforms.
