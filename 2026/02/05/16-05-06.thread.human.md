Matthew John Cheetham's series to unify TRACE2 process ancestry tracing across platforms has received maintainer approval from Junio C Hamano. The six-patch series extends tracing to macOS while refactoring the Windows implementation, building on existing Linux and Windows support. Key changes include a new macOS implementation using `sysctl`, a refactored Windows backend that separates data collection from JSON formatting, and comprehensive test infrastructure.

Junio has now acked patch 4/6, which updates the Windows implementation to emit ancestry data in both legacy JSON and the new standardized format. While noting the change is straightforward, he raised an open question about whether to eventually deprecate the JSON format or maintain dual emission long-term. The current approach keeps both formats to support existing consumers while enabling cross-platform analysis.

The series has evolved through multiple revisions, growing from four to six patches to add test coverage and build system support. It now includes a dedicated test helper and script that verify behavior across all TRACE2 output types and handle platform-specific cases like Windows' "sh.exe" layer. With Junio's approval of the technical direction, this completes platform coverage for major operating systems and provides the infrastructure needed for ongoing maintenance of the ancestry tracing feature.
