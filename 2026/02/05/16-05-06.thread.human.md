This thread introduces a 4-patch series by Matthew John Cheetham that extends Git's TRACE2 process ancestry support to macOS while refactoring the Windows implementation. The work builds on existing Linux and Windows tracing capabilities, aiming for cross-platform consistency in how Git reports process ancestry data.

The series adds macOS support through new `sysctl`-based process information gathering in `compat/darwin/procinfo.c`, matching Linux's format rather than Windows's JSON output. It also refactors the Windows implementation to cleanly separate data collection from JSON formatting while maintaining backward compatibility through dual emission of both formats. Derrick Stolee provided thorough review feedback on all patches, suggesting optimizations, confirming the build system integration, and proposing a timeline for eventually removing the legacy JSON format.

The work represents a careful unification of process tracing across platforms while maintaining compatibility for existing Windows tooling.
