The thread discusses Matthew John Cheetham's work to extend Git's TRACE2 process ancestry tracing to macOS while refactoring the existing Windows implementation. The goal is to create a unified approach across Linux, Windows, and macOS platforms, with Junio Hamano having already acked the technical approach after reviewing version 2 of the series.

The latest patch (3/6) focuses on refactoring the Windows implementation to separate the collection of process names from the JSON formatting. Previously these were combined in a single function, but now process names are first collected into a strvec before being formatted into JSON. This matches the Linux implementation's structure and prepares for future changes where ancestry data will use the newer cmd_ancestry event format. The change maintains backward compatibility by still emitting the old JSON format during the transition period.

The series as a whole introduces macOS support using sysctl with KERN_PROC to gather parent process information, with a 10-level depth limit matching Linux's implementation. Test coverage has been expanded, and the build system now supports the new macOS implementation across Makefile, CMake and Meson. The Windows changes in this patch don't modify behavior but clean up the architecture to better align with the cross-platform consistency goals of the series.
