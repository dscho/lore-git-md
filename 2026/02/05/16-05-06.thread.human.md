This thread discusses a 4-patch series that adds macOS support for Git's TRACE2 process ancestry tracing while refactoring the Windows implementation. The work builds on existing Linux and Windows tracing capabilities, aiming for cross-platform consistency in how Git reports process ancestry information for performance tracing.

The series implements macOS support via `sysctl` calls to gather parent process IDs and names up to PID 1, matching Linux's format rather than Windows's JSON output. It also refactors the Windows implementation to separate data collection from formatting, while maintaining backward compatibility through dual-emission of both formats. Derrick Stolee has reviewed all patches, confirming the technical approach while suggesting minor optimizations and noting the growing complexity of maintaining multiple build systems.

In his latest review, Stolee highlights two remaining considerations: the need for test coverage of the new macOS implementation (acknowledging platform-specific challenges), and a proposal to set a timeline (two major versions) for eventually removing the legacy Windows JSON format. His feedback indicates the series is otherwise in good shape, with only minor implementation nits around recursion handling and string vector usage. The core design appears validated, positioning this work as likely ready for merging after addressing the testing gap.
