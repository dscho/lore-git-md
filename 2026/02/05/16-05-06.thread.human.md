This thread covers Matthew John Cheetham's 4-patch series to extend Git's TRACE2 process ancestry tracing to macOS while refactoring the Windows implementation. The work builds on existing Linux and Windows support, aiming for cross-platform consistency in how Git reports process ancestry for debugging and telemetry.

The series has undergone thorough review from Derrick Stolee and now has Junio C Hamano's maintainer ack pending minor final tweaks. The macOS implementation uses `sysctl` to recursively gather parent process information (with a 10 limit), matching Linux's approach. The Windows version was refactored to separate data collection from formatting while maintaining backward compatibility with existing JSON output.

Recent discussion focused on whether to convert the recursive process walk to an iterative approach, as Stolee had initially suggested. Cheetham noted the Linux implementation uses recursion with a depth limit, and Stolee agreed consistency with the existing codebase was more important than potential optimizations at this stage. This leaves the series in a nearly-final state, with only minor documentation and commit message polish remaining before expected merging. The cross-platform tracing unification represents careful work balancing technical implementation with backward compatibility concerns.
