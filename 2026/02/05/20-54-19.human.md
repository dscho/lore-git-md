This is a CI / build system update from Junio Hamano addressing platform-specific issue in the `git subtree` tests. The thread has uncovered that some test failures were actually due to a bug in Ubuntu's `dirname` utility (fixed upstream but not yet widely deployed). Junio proposes a temporary workaround similar to one used previously for `sudo-rs` issues - demoting the CI from Ubuntu rolling to Ubuntu latest to avoid the problematic version.

The email shows successful test results from a custom CI run that combines:
1. The Ubuntu version downgrade
2. Pushkar Singh's subtree test fix (hardcoding 'main' branch)
3. A similar fix for diff-highlight tests
4. Expanded contrib/ directory testing

This demonstrates that the core fixes are sound when separated from the platform-specific `dirname` issue. The thread reveals how expanded CI testing is uncovering both Git issues and platform dependencies, particularly in contrib/ scripts that may interact more directly with system tools. Junio's approach shows the pragmatic balancing act between testing rigor and practical workarounds for external issues.
