This is the second patch in a 4-part series adding macOS support for Git's TRACE2 process ancestry tracing. The patch focuses on build system integration, adding the new macOS implementation (`compat/darwin/procinfo.c`) to all three build systems: Make, CMake, and Meson. 

The changes are straightforward and follow the pattern established by the existing Linux and Windows implementations. Each build system gets a new conditional block that includes the Darwin-specific source when building on macOS. The Makefile addition also sets `HAVE_PLATFORM_PROCINFO` to match the behavior of other platforms.

This is a mechanical but necessary step that enables the actual macOS implementation introduced in patch 1. The patch maintains consistency with how platform-specific code is handled elsewhere in the codebase. Since this is part of a larger series, the real substance will be in how the macOS implementation works (patch 1) and how the Windows side gets refactored (patches 3-4).
