This is a CI/build system patch from the Git maintainer Junio C Hamano, addressing an immediate issue with Ubuntu's rolling release in GitHub Actions workflows. The patch switches several CI jobs from using `ubuntu:rolling` to `ubuntu:latest` to avoid breakage caused by a buggy `dirname` implementation in the uutils coreutils replacement that recently landed in Ubuntu's rolling release.

The change affects 7 different CI configurations that test various Git features (SHA-256, reftable, leaks detection, ASAN/UBSAN, meson builds) by pinning them to the stable Ubuntu release rather than the bleeding-edge rolling version. Junio notes this is a temporary measure until uutils stabilizes, leaving open the question of whether Git should continue avoiding rolling releases or serve as a test case for them.

The patch is minimal and focused - just changing the Docker image tags in the GitHub Actions YAML file. As a maintainer-driven fix for actively breaking CI, this is clearly important infrastructure maintenance, though the discussion thread suggests there may be more to come about long-term strategy for handling rolling releases in CI.
