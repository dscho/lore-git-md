This is a CI/build system patch addressing Windows compatibility concerns for the Meson build system's integration of gitk and git-gui.

Patrick Steinhardt responds to Junio Hamano's question about Windows symlink support in the Meson build system. The patch series (now in its second iteration) uses symlinks to integrate gitk and git-gui as subprojects while preserving their original source layout. 

Patrick explains that modern Windows can support symlinks when Developer Mode is enabled, and that Cygwin/MSYS2 environments provide symlink emulation (Cygwin through virtual symlinks, MSYS2 through deep copies). However, he notes this hasn't been tested on Windows and acknowledges the platform's historically spotty symlink support.

The response confirms the technical approach is sound for modern Windows environments with proper configuration, but leaves open the question of behavior on default Windows installations without Developer Mode or third-party emulation. This appears to be the final outstanding issue for this build system modernization effort, which otherwise has achieved technical consensus through the symlink-based solution.
