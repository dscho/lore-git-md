This is a follow-up to a const-correctness patch series that addresses compiler warnings from glibc 2.43 in C23 mode. The original series added const qualifiers to pointers receiving results from search functions where the data isn't modified.

Junio Hamano has reviewed and approved the series for merging, noting that the changes are safe since compilers would catch any attempts to write through the now-const pointers. The only minor point of discussion was whether removing NULL initialization in gpg-interface.c should be split into a separate patch - Collin Funk acknowledges this and plans to send a v2 with that change separated.

The patch represents a straightforward but important maintenance change to keep Git compatible with modern C standards and compiler versions. With Junio's approval, this series is now ready for integration into the codebase.
