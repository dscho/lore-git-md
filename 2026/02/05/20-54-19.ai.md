This is a CI / build system update addressing platform-specific test failures in the `contrib/` directory, specifically around the `dirname` utility behavior in Ubuntu's rolling release.

Junio is responding to Colin Stagner's report that some `git-subtree` test failures under the reftable backend were actually caused by a bug in Ubuntu's `dirname` implementation. He references a previous workaround (commit fddb4842) where they dealt with a similar issue by using `/etc/alternatives/sudo` when Ubuntu switched to `sudo-rs`.

The email reports successful test results from a custom CI run that implements several fixes: downgrading from ubuntu:rolling to ubuntu:latest to avoid the problematic `dirname`, applying Pushkar Singh's subtree test fix that hardcodes 'main' branch references, a similar fix for diff-highlight tests, and enabling tests in contrib directories. The full run is available at the linked GitHub Actions URL.

This demonstrates the ongoing challenges of maintaining platform compatibility, particularly for contrib scripts that may rely on external tools. The solution follows the pattern of previous platform-specific workarounds while broader fixes propagate upstream. The successful CI run suggests these changes may be ready for integration, though the temporary nature of the Ubuntu workaround indicates this may need revisiting when the `dirname` fix reaches stable releases.
