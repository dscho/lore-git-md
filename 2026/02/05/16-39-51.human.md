This is a CI infrastructure discussion thread about platform-specific test failures uncovered by expanded contrib/ testing.

Junio C Hamano notes that enabling contrib/ tests in CI has revealed multiple pre-existing issues, including failures in the `git subtree` tests (t7900) and diff-highlight tests (t9400) across various configurations. Colin Stagner identifies that some of the subtree failures on the reftable backend are actually due to a bug in Ubuntu's `dirname` utility implementation, not a Git issue. This echoes a previous CI workaround needed for Ubuntu switched to `sudo-rs`.

The thread shows how expanded CI testing is surfacing both real Git issues and platform-specific quirks in contrib/ scripts. While frustrating, this demonstrates the value of the enhanced test coverage. The discussion suggests looking for workarounds similar to previous fixes for Ubuntu toolchain changes, while acknowledging some contrib/ components may need maintenance evaluation. The exchange highlights the ongoing challenge of maintaining compatibility across platforms while improving test coverage.
