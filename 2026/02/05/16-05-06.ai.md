Feature and platform compatibility patch series adding process ancestry tracing for macOS and refactoring Windows implementation.

This 4-patch series extends Git's TRACE2 process ancestry tracing to macOS while refactoring the existing Windows implementation. The work builds on two prior commits (353d3d77 and 2f732bf1) that added process ancestry tracing for Windows and Linux respectively.

The first patch implements macOS support by adding a new `compat/darwin/procinfo.c` that gathers process ancestry information using macOS-specific syscalls. The second ensures this implementation gets built on macOS. The third and fourth patches refactor the Windows implementation to emit the same `cmd_ancestry` event type as Linux/macOS (while maintaining backward compatibility with the old `data_json` format).

The changes touch platform-specific compatibility code (Darwin and Windows) and build system files to enable the new functionality. The series appears well-structured with each patch focused on a clear task. The author has considered backward compatibility for existing TRACE2 consumers on Windows, which suggests careful attention to real-world deployment concerns. This looks like a solid addition to Git's cross-platform instrumentation capabilities.
