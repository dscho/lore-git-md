This is a technical implementation patch in Jiang Xin's ongoing effort to improve Git's localization workflow with AI-assisted tooling. It introduces `.gitattributes` rules to automate location filtering in `.po` files, replacing manual per-user configuration with repository-wide settings.

The patch adds a new `po/.gitattributes` file that defines two filter types for translation files: one that strips both filenames and line numbers (`gettext-no-file-no-location`), and another that preserves filenames while removing line numbers (`gettext-no-location`). The default languages use the more aggressive stripping, while Chinese (zh_CN/TW), Catalan, and Indonesian translations preserve filenames. The accompanying `po/README.md` updates explain how to check which filter applies and configure the corresponding driver.

This change builds on the RFC discussion about AI-assisted translation workflows by standardizing the pre-processing of `.po` files before they enter version control. While the broader debate about AI's role in translations continues (with legal and quality concerns raised by other contributors), this patch focuses narrowly on the mechanical aspects of location filtering. The implementation appears clean and well-documented, with clear instructions for contributors to set up the required filters. As part of a 2-patch series, this likely serves as infrastructure for subsequent AI-related tooling.
