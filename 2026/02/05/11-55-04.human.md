This is a build system patch addressing a Windows CI failure in the ongoing Meson integration effort for Git's GUI components (gitk and git-gui). The patch fixes a missing `msgfmt` tool dependency that was causing the Windows+Meson CI job to fail.

Patrick Steinhardt identifies that while the logic to handle a missing `msgfmt` executable exists, the executable check itself wasn't marked as optional. The fix is straightforward - adding `required: false` to the `find_program('msgfmt')` call in gitk's meson.build file. This matches the existing behavior in the Makefile build system where the gettext tools are optional.

The patch demonstrates that the symlink-based approach for subprojects (introduced in v2 of this series) is working on Windows, though this particular issue was unrelated to the symlink concerns raised earlier in the thread. The fix has already been submitted as a pull request to the gitk repository (j6t/gitk#37).

This is one of the final hurdles in completing Meson build system support for Git's GUI components, with the series having already addressed core architectural questions and received positive review from Karthik Nayak. The remaining issues are primarily Windows-specific toolchain and path handling concerns.
