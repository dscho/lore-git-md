This is the fifth patch in Patrick Steinhardt's 17-part series refactoring Git's ref iteration API. The patch removes an unused function `refs_for_each_include_root_refs()` that was meant to iterate over all refs including root refs (pseudorefs and HEAD).

The change is straightforward - the function is deleted from both the implementation (refs.c) and header (refs.h) files. The commit message notes the function was unused, suggesting this is a cleanup rather than a behavior change. The removal aligns with the series' goal of simplifying the ref iteration API surface.

This continues the series' pattern of preparatory changes before introducing the new unified API. The patch is small and focused, touching only the refs subsystem. Given the function was unused and this is part of a larger, well-motivated refactoring effort, it's unlikely to generate controversy. The change builds on the previous patches' renaming of types and flags to establish consistent naming conventions.
