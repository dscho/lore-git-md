This thread documents the development of a new cover letter formatting feature for `git format-patch`, which has now reached its final form after eight iterations. The feature provides configurable formatting through both command-line (`--commit-list-format`) and configuration (`format.commitListFormat`) interfaces while maintaining backward compatibility with the existing shortlog-based output.

The implementation introduces new functions in `builtin/log.c` to handle different formatting styles, with the shortlog generation cleanly modularized. It supports custom formats with placeholders like `%(count)` and `%(total)`, validated through `rev_info` context checks. A notable design decision was the adoption of DWIM (Do What I Mean) behavior for format string prefixes - while the "log:" prefix remains technically required, it can be omitted when using %-placeholders, following the precedent of `git log --pretty`.

Key participants included Junio C Hamano, who approved the architecture and interface compromise; Jeff King, who designed the numbering approach; and Phillip Wood, who advocated for the more flexible prefix handling that was ultimately adopted. The author, Mirko Faina, implemented all technical requirements through eight versions of the patch series.

The series is now production-ready with comprehensive test coverage and documentation updates. It has been merged to the 'next' branch through incremental updates, with any future follow-up work to be structured as new patch series building on this foundation. The maintainer has accepted the approach, marking the successful conclusion of this feature's development cycle.
