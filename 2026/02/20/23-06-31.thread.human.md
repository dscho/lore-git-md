This RFC-to-feature patch series has evolved through seven iterations to implement comprehensive cover letter formatting options for `git format-patch`. The series introduces both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) interfaces while maintaining backward compatibility with the traditional shortlog-based output.

The latest patch is a pure refactoring that moves the shortlog generation code from being inline in `make_cover_letter()` to a dedicated `generate_shortlog_cover_letter()` function. This structural change improves modularity without altering behavior, preparing the ground for the new formatting features. The series has already addressed all technical feedback, with key contributions from Jeff King (Peff) on the numbering scheme design and Junio C Hamano reviewing and approving the documentation.

The implementation includes new `%(count)` and `%(total)` placeholders with strict context validation, a clear behavior matrix for configuration options, and comprehensive test coverage. Author Mirko Faina confirms this v7 iteration is final, with all maintainer concerns resolved. The series is now production-ready and awaiting merge, representing a complete solution that preserves backward compatibility while adding flexible formatting capabilities.
