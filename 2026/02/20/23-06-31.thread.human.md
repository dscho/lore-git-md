This thread documents the implementation of configurable cover letter formatting for `git format-patch`, now in its final form and ready for merging. The feature allows users to customize how commit lists appear in cover letters through either a new `--cover-letter-format` command-line option or `format.commitListFormat` config setting, while maintaining backward compatibility with the traditional shortlog format.

The implementation includes core formatting logic in `builtin/log.c`, with new functions like `generate_commit_list_cover()` and `generate_shortlog_cover_letter()`, plus patch numbering support in `pretty.c` with new `%(count)` and `%(total)` placeholders. The design went through five iterations to reach consensus on key decisions like requiring a "log:" prefix for custom formats and implementing Jeff King's numbering approach.
