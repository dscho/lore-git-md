This RFC patch series introduces configurable commit list formatting for `git format-patch` cover letters, allowing both command-line (`--cover-letter-format`) and config-based (`format.commitListFormat`) control while maintaining backward compatibility. The implementation uses `repo_format_commit_message()` for clean formatting without global state, with changes focused in `builtin/log.c`.
