Peff notes that Mirko Faina's current patch incorrectly conflates NULL checking with empty string detection, potentially breaking existing functionality.

The discussion has revealed that the solution likely requires adjusting patch 2/3's design rather than changing core pretty-printing behavior. Peff plans to review patch 2/3 next to provide architectural guidance. While the series remains blocked pending this review, the debate has produced valuable clarity about subsystem contracts that will inform the final implementation. The feature's core goal - providing both command-line (`--cover-letter-format`) and config-based (`format.commitListFormat`) control over commit list presentation - remains sound, but the path forward now appears to require revisiting how the new functionality integrates with the pretty-printing subsystem's existing assumptions.
