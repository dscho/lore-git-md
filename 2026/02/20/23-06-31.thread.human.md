This thread documents the development of a now-complete feature to make `git format-patch` cover letters configurable through both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options. The series, authored by Mirko Faina, has gone through five iterations with extensive review from Jeff King (Peff) and maintainer Junio C Hamano.

The implementation introduces flexible formatting while maintaining backward compatibility with the traditional shortlog-based output. Key technical elements include new `%(count)` and `%(total)` placeholders for patch numbering (designed by Peff), a cleanly separated `generate_shortlog_cover_letter()` function, and integration with Git's existing formatting system. A "log:" prefix is required for all non-shortlog formats to ensure consistency between interface types.

Junio has approved the architecture and implementation, confirming the documentation is now complete with clear examples. The series includes comprehensive test coverage in t4014-format-patch.sh and has addressed all technical requirements through the review process. With no outstanding issues and maintainer approval confirmed, this production-ready enhancement to `git format-patch` is now ready to be merged into Git's main codebase.
