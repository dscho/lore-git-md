This thread documents the implementation of configurable cover letter formatting for `git format-patch`, a feature that has now reached completion. The series, authored by Mirko Faina, allows users to customize how commit lists appear in cover letters through both command-line options (`--cover-letter-format`) and configuration settings (`format.commitListFormat`). The implementation supports either the traditional shortlog format or custom format strings with placeholders like `%s` for subject and `%an` for author name.

The technical work involved refactoring the shortlog generation into a dedicated function, adding validation for format strings, and ensuring proper precedence between CLI and config options. Jeff King (Peff) contributed the numbering approach design, while Junio Hamano as maintainer approved the architecture and requested the final documentation polish that this patch provides. The series has gone through multiple iterations and now includes comprehensive test coverage in `t4014-format-patch.sh`.

With this documentation patch, the feature is fully complete and ready for merging. It maintains backward compatibility while offering new formatting flexibility, addressing all technical requirements and review feedback from the maintainer and other contributors. The implementation has been production-ready for several iterations, with this final patch simply adding the user-facing documentation that was the last remaining piece.
