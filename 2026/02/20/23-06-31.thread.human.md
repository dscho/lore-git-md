This thread documents the final stages of a feature adding configurable cover letter formatting to `git format-patch`. The series, now at version 6, introduces both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options for customizing cover letter output while maintaining backward compatibility with the traditional shortlog format. Key technical components include new functions in `builtin/log.c`, strict validation of placeholders like `%(count)` and `%(total)`, and comprehensive test coverage.

The implementation has been through six iterations with all technical requirements met. Jeff King (Peff) contributed the numbering approach using `decimal_width()`, while author Mirko Faina handled the implementation and testing. Junio Hamano has approved the architecture and confirmed the documentation is complete, though in this final email he suggests minor wording improvements to avoid shorthand "config" references and clarify the CLI/config precedence relationship. With these last documentation tweaks, the series is ready for merging, representing a complete solution that preserves backward compatibility while adding flexible formatting options.
