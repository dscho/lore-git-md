This RFC patch series implements configurable formatting for commit lists in `git format-patch` cover letters, fulfilling maintainer Junio C Hamano's request for both command-line and configuration-based control. The implementation comes in three carefully structured patches: first fixing a NULL dereference in the formatting code, then introducing the core formatting engine with a `--cover-letter-format` command-line option, and finally adding the persistent `format.commitListFormat` configuration option in this third patch.

The feature allows printf-style formatting of commit lists (using %s for subject, %a for author etc.), with the command-line option taking precedence over the config setting when both are present. The implementation handles memory management properly and maintains backward compatibility by falling back to traditional shortlog format when neither option is specified. Mirko Faina has delivered a complete implementation matching Junio's requirements, including comprehensive test coverage and documentation updates. With all technical boxes checked and no outstanding objections, the series appears ready for maintainer consideration, demonstrating Git's incremental development philosophy through its logical patch-by-patch progression.
