This thread documents the implementation of configurable cover letter formatting for `git format-patch`, now in its final form after seven iterations (v7). The feature allows users to customize how commit lists appear in cover letters through both command-line (`--cover-letter-format`) and configuration (`format.commitListFormat`) options, while maintaining backward compatibility with the traditional shortlog-based output.

The implementation introduces new functions in `builtin/log.c` to handle the formatting, with special care taken to cleanly separate the shortlog functionality. It adds `%(count)` and `%(total)` placeholders (using Jeff King's `decimal_width()` design for alignment) with strict validation to ensure they're only used in the proper `rev_info` context. The series has been thoroughly reviewed, with Junio C Hamano approving the architecture and documentation, and Jeff King signing off on the numbering approach.

Author Mirko Faina has confirmed this seventh version as final, having addressed all feedback. The implementation is production-ready with comprehensive test coverage and complete documentation that explains the format string syntax, configuration behavior, and provides practical examples. With no outstanding issues, this feature is now ready to be merged into Git's mainline.
