This RFC patch series introduces configurable formatting for cover letter commit lists in `git format-patch`, implementing a printf-style approach as discussed in earlier design discussions. The series has progressed cleanly through implementation, with each patch building on verified foundations.

The first patch fixed a NULL dereference in `commit_format_is_empty()`, while the second established the core formatting engine with a `--cover-letter-format` command-line option. This final patch completes the feature by adding the `format.commitListFormat` configuration option, allowing users to set a default format in their Git config. The implementation supports %s (subject) and %a (author) specifiers with "log:" prefix, falling back to traditional shortlog format when unset.
