First-time contributor Shreyansh Paliwal reported that the command's current encoding prompt is confusing - when it detects 8-bit content, it asks "Which 8bit encoding should I declare [UTF-8]?" which users may misinterpret as a yes/no question. Ben Knoble has joined the discussion, agreeing the interface needs clarification. While no technical implementation has been proposed yet, this appears to be a straightforward documentation/UI issue that could be resolved with relatively minor changes to prevent this common misunderstanding.
