This is part of Elijah Newren's ongoing series to remove `the_repository` usage from merge-ort and replay, a contribution to the project-wide `the_repository` removal effort. 

The patch modifies `write_tree()` in merge-ort.c to take an explicit `struct repository *` parameter instead of relying on the global `the_repository`. This is a straightforward mechanical change that follows the established pattern for eliminating global variable dependencies. The function now gets the hash algorithm size directly from the passed repository rather than taking it as a separate parameter, which simplifies the call sites.

The changes are behavior-preserving and well-contained, touching only the merge-ort subsystem. Elijah's expertise in this area (he designed the ort merge strategy) gives confidence in the correctness of the modifications. The patch has already incorporated feedback from the v1 review round, including improved commit message clarity about the hash-algo parameter removal.

This is the second of six patches in the series, building on the prefetch check cleanup from patch 1. The changes are uncontroversial and align with the project's direction to parameterize repository access. The patch appears ready for merging as part of the broader effort.
