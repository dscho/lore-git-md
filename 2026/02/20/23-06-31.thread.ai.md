RFC patch series (now v2) implementing configurable cover letter commit list formatting for `git format-patch`, consisting of 2 patches. The series provides both command-line (`--cover-letter-format`) and config-based (`format.commitListFormat`) control over commit list presentation while respecting Git's internal contracts.

Key technical implementation:
- Patch 1/2) Command-line option `--cover-letter-format` with format string support ("shortlog" or "log:<format>") and assertions for validation
- Patch 2/2) Config option `format.commitListFormat` for persistent formatting, with same syntax as command-line option
- Both implementations use `repo_format_commit_message()` for one-off formatting without global state
- Memory management handled in `format_config_release()`
- Falls back to traditional shortlog when unconfigured
- Defaults to "%s" format when config is set but empty
- Changes focused in `builtin/log.c` (65-line diff in patch 1, 22-line diff in patch 2)
