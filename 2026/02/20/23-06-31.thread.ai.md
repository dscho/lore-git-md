RFC-to-feature patch series implementing comprehensive cover letter formatting for `git format-patch`, now in final form (v8) with all design decisions resolved. Core implementation includes:
- New `generate_commit_list_cover()` and refactored `generate_shortlog_cover_letter()` functions in `builtin/log.c`
- Special "shortlog" handling cleanly separated into dedicated function
- `%(count)` and `%(total)` placeholders in `pretty.c` with strict `rev_info` context validation
- Config behavior matrix (unset->shortlog, empty->default format, custom formats) via `format.commitListFormat`

- Bash completion support
- Comprehensive test coverage in `t4014-format-patch.sh` and `t9902-completion.sh`
