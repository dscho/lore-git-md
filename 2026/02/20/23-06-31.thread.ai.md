RFC-to-feature patch series implementing comprehensive cover letter formatting for `git format-patch`, now in final form ready for merging (v6). The series provides configurable formatting through both CLI (`--cover-letter-format`) and config (`format.commitListFormat`) interfaces while maintaining backward compatibility with shortlog-based output.

Core implementation includes:
- New `generate_commit_list_cover()` and `generate_shortlog_cover_letter()` functions in `builtin/log.c` (the latter extracted from `make_cover_letter()` in patch 2/5)
- Special "shortlog" handling now cleanly modularized in dedicated function
- New `%(count)` (zero-padded using `decimal_width()`) and `%(total)` placeholders in `pretty.c` for patch numbering, with strict `rev_info` context validation
- Config behavior matrix (unset->shortlog, empty->default format, custom formats) via new `format.commitListFormat` option in patch 4/5
- "log:` prefix requirement for all non-shortlog formats
- Integration with existing `make_cover_letter()` and `repo_format_commit_message()`
- Bash completion support
- Comprehensive test coverage in `t4014-format-patch.sh` and `t9902-completion.sh`

Documentation complete with:
- `--cover-letter-format` CLI option details including example format strings with new `%(count)`/`%(total)` placeholders
