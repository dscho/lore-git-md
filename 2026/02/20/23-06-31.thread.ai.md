RFC patch series proposing configurable cover letter commit list format for `git format-patch`, evolving from Mirko Faina's initial numbered-list proposal. Maintainer Junio C Hamano now suggests a flexible `format.commitListFormat` configuration using printf-style format strings, with `[N/M]` automatically prepended to show patch series flow.

Key technical details:
- New `format.commitListFormat` config accepts printf-style format string
- Default shows "[N/M] subject" without commit hashes
- Custom formats can include author names via "%a" specifier
- Falls back to current shortlog when unset
- Command-line override proposed (`--cover-letter=log:"%s (%an)"`)
- Modifies `builtin/log.c` to use log machinery for formatted output
- Original implementation issues (reverse order, memory leak) remain but are secondary to design finalization
