This is part 3 of a 6-patch series in the ongoing `the_repository` removal effort, specifically targeting the merge-ort subsystem. The patch systematically replaces direct uses of the `the_repository` global variable with the repository pointer available through `opt->repo` in merge-ort.c.

The changes are mechanical but thorough, updating repository access in key functions like `collect_merge_info()`, `merge_3way()`, `handle_content_merge()`, and configuration handling. Notable conversions include repository-aware tree parsing, blob reading/writing, and merge base calculations. The prefetch check for promisor remotes is also updated to use the correct context.

This patch follows the established pattern for `the_repository` removal - maintaining identical behavior while making the repository dependency explicit. As with the rest of the series, these changes are behavior-preserving and have been reviewed by Patrick Steinhardt, who characterized the approach as "welcome cleanup". The patch demonstrates Elijah Newren's deep knowledge of the merge-ort subsystem while advancing the project-wide architectural goal of eliminating global state.
