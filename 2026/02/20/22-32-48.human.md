This is the final patch in a series introducing a new `--[no-]auto-advance` option for interactive patch selection commands like `git add -p`. The option controls whether Git automatically moves to the next file after processing hunks in the current one, with `--no-auto-advance` enabling manual navigation via new '>' (next) and '<' (previous) commands.
