This is the fourth patch in a five-part test infrastructure series addressing CI failures on Windows/MSVC platforms related to `iconv(1)` executable availability. The patch focuses on t5550-http-fetch-dumb.sh.

The change adds ICONV prerequisites to tests that use "$HTTPD_URL/error" endpoints, which depend on the `iconv(1)` executable for message reencoding. The patch also converts several `grep` calls to the preferred `test_grep` helper for consistency, as suggested in previous reviews.

The key technical points are:
1. Tests interacting with error endpoints now properly declare their ICONV dependency
2. Error message handling remains functional when ICONV is available
3. The change maintains test coverage while making it conditional on having the required tool
4. Follows the pattern established in earlier patches of the series to handle the libiconv vs iconv(1) distinction

This version incorporates Eric Sunshine's feedback from v3, standardizing on test_grep usage. The patch is part of a now-complete series that has received approval from both Christian Couder and Junio Hamano, with all feedback addressed across the four iterations.
