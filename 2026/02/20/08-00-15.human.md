This is the final patch in a series addressing test failures on Windows/MSVC platforms related to `iconv(1)` availability when Git has ICONV support enabled. The patch focuses on t5550-http-fetch-dumb.sh, making its error message tests conditional on the ICONV prerequisite.

The change ensures tests that rely on the `iconv(1)` executable (via the HTTP error endpoint) are skipped when the executable isn't available, while also modernizing the test syntax by converting `! grep` to the preferred `test_grep !` form. Eric Sunshine caught a typo ("proprely" -> "properly") and suggested the test_grep style improvement, which Patrick Steinhardt acknowledges and will incorporate in a follow-up version.

This patch completes the series' goal of handling the distinction between libiconv (linked into Git) and the `iconv(1)` executable (used in test scripts) across all affected test files. The approach maintains test coverage while improving portability, particularly for Windows/MSVC environments where MinGW no longer ships `iconv(1)`. With all feedback addressed, the series is now ready for maintainer pickup.
