This is the third patch in Patrick Steinhardt's 17-part series refactoring Git's ref iteration API. The series aims to simplify the current API which has 14 different `refs_for_each_*()` functions with subtle variations.

This particular patch is a straightforward renaming change, converting the enum `do_for_each_ref_flags` to `refs_for_each_flag` and updating all its flag names to match Git's current naming conventions. The changes are mechanical but widespread, touching 6 files across the refs subsystem including all three backend implementations (files, packed, and reftable).

The patch maintains the same functionality while making the code more consistent with Git's style. It's part of the preparatory work before introducing more substantial changes to the ref iteration API in later patches. The changes are uncontroversial and follow Patrick's typical careful, incremental refactoring approach.
