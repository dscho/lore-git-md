This is part of Adrian Ratiu's ongoing series to implement config-based hooks, now at version 2 with 8 patches. The current patch focuses on internal plumbing for hook state management, moving from stack allocation to dynamic allocation of callback data structures.

The patch introduces alloc/free callbacks in the hook subsystem to better manage the lifecycle of hook execution state. Patrick Steinhardt provides detailed review feedback, suggesting modernizations like using `CALLOC_ARRAY` and considering structural improvements to avoid data copying. Adrian confirms he'll incorporate these suggestions in v3, including renaming the callback typedefs to be more clearly scoped to hooks.

The discussion shows steady progress on technical implementation details, with Patrick's reviews helping refine the approach. This is a preparatory patch in a larger series that has already received maintainer approval for its architectural direction. The changes here support the broader goal of making hooks configurable while maintaining backward compatibility with filesystem hooks.
