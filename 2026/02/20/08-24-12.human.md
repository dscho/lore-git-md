This is patch 8/17 in Patrick Steinhardt's ref iteration API unification series. It extends the new unified API to handle namespaced references, which are references filtered by the `GIT_NAMESPACE` environment variable.

The patch adds a `namespace` field to the `refs_for_each_ref_options` struct and ports the existing `refs_for_each_namespaced_ref()` functionality to use the new unified API. The key changes are:

1. Namespace handling is moved into `refs_for_each_ref_ext()` where it rewrites reference paths and exclude patterns to work within the specified namespace
2. The old `refs_for_each_namespaced_ref()` function becomes a thin wrapper that sets the namespace option and delegates to the unified API

This continues the series' pattern of incrementally migrating specialized ref iteration functions to use the new unified interface while maintaining identical behavior. The change gives callers more flexibility by allowing them to specify any namespace (not just the global one) and keeps the namespace logic centralized in one place.

The patch touches core ref iteration code but follows the established pattern from earlier patches in the series. It's part of the broader effort to simplify Git's ref iteration API by replacing 14 specialized functions with one configurable interface.
