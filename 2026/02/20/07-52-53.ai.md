This is a feature patch adding client certificate support to `git send-email` for SMTP servers that require mutual TLS authentication. The patch introduces two new options:

1. `--smtp-ssl-client-cert` to specify a client certificate file (in PKCS12 or PEM format)
2. `--smtp-ssl-client-key` as an optional private key file (required for PEM certificates, optional for PKCS12)

The implementation modifies the Perl script to pass these parameters through to the underlying IO::Socket::SSL library. The documentation is updated to explain the new options and link to the relevant Perl module documentation. The changes appear straightforward and well-contained, with proper error handling for cases like specifying a key without a certificate.

The patch addresses a real use case (mutual TLS authentication with SMTP servers) that wasn't previously supported. The implementation looks clean and follows existing patterns in the code for handling SSL parameters. The documentation includes a reference to the underlying Perl module's behavior, which helps users understand the expected certificate formats.
