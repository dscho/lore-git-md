This is the third patch in a five-part series addressing test failures related to iconv handling on Windows/MSVC platforms. The patch focuses on t4205-log-pretty-formats.sh, improving how the tests handle the ICONV prerequisite.

The key change makes the test encoding conditional: when ICONV is available, it uses ISO-8859-1 as before, but falls back to UTF-8 when iconv(1) is unavailable. This fixes test setup failures on platforms without the iconv executable while maintaining test coverage. The patch also removes the ICONV prerequisite from many tests that don't actually need it, since they don't perform encoding conversions.

The changes are mechanical but well-justified in the commit message, which explains the two classes of tests in this file and why some ICONV dependencies were unnecessary. This is part of a larger effort to make Git's tests more portable across platforms, particularly addressing issues where MinGW no longer ships the iconv(1) executable. The patch has already been reviewed and approved by Christian Couder and Junio Hamano, with Eric Sunshine providing final polish in previous iterations.
