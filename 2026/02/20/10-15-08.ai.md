This is a test adjustment patch in Patrick Steinhardt's series changing git maintenance's default strategy from "gc" to "geometric". The patch modifies t5400-send-pack.sh to explicitly set `maintenance.strategy=gc` in a test that verifies receive-pack's auto-gc behavior.

The test checks that receive-pack prunes temporary objects by observing the effect of git-gc. Since the series will change the default to geometric maintenance (which might not prune in the same way), this patch ensures the test continues to test the gc-specific behavior by forcing that strategy. This is one of several preparatory test changes in the series that isolate tests from the upcoming default behavior modification.

The change is minimal - a single config line addition - and follows the pattern seen in earlier patches of the series where tests that depend on gc-specific behavior are explicitly pinned to that strategy. This demonstrates the careful, incremental approach Patrick is taking to ensure test stability before making the core behavior change in builtin/gc.c.
