This is a test infrastructure series from Patrick Steinhardt addressing CI failures on Windows/MSVC platforms related to the `iconv(1)` executable. The series is now in its fourth iteration and has received final approval from Christian Couder and Junio Hamano, with Eric Sunshine providing polish on the t5550 changes.

The core issue stems from Git being built with ICONV support (using libiconv) on Windows/MSVC, but the `iconv(1)` executable not being available in the test environment. The series makes all affected tests properly handle this distinction by using the ICONV prerequisite consistently. The five patches cover:

1. Fixing the ICONV prerequisite to not be set when the executable is missing
2. Updating t40xx submodule tests to respect the prerequisite
3. Improving ICONV handling in t4205 (pretty-format tests)
4. Adding ICONV prereq to t5550 HTTP error tests (with final typo fixes from Eric)
5. Making t6006 rev-list format tests work without iconv(1)

The series demonstrates a complete solution for the iconv distinction while maintaining test coverage, particularly important for Windows/MSVC environments where MinGW no longer ships `iconv(1)`. All feedback has been incorporated and the series is now ready for merging.
