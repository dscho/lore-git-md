Refactoring patch in Patrick Steinhardt's series to unify ref iteration interfaces. This is patch 5/17 in v1 of the series.

The patch removes the unused `refs_for_each_include_root_refs()` function and its declaration. The function was meant to iterate over all refs including root refs (pseudorefs and HEAD) but appears to have no callers in the codebase. The removal is straightforward - deleting the function implementation from refs.c and its prototype from refs.h.

This continues the series' pattern of cleaning up the ref iteration API before introducing the new unified interface. The change is mechanical and low-risk since the function wasn't being used. The patch maintains the series' careful, incremental approach - each change is small and focused, building toward the larger goal of API unification.

The removal demonstrates how the ref iteration API has accumulated cruft over time, with functions that were added but never actually used. This cleanup helps reduce the surface area that will need to be maintained when the new unified API is introduced in later patches. The widespread impact shown in patch 4 (updating 11 files) suggests this unused function may have been intended for broader use that never materialized.
