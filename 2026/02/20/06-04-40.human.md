This is a refactoring patch series from GSoC contributor Burak Kaan Karaçay, part of the ongoing `the_repository` removal effort. The two patches clean up global state in Git's mailmap subsystem, with v2 addressing a header inclusion issue found after initial review.

The series removes implicit dependencies on the global `the_repository` variable by making mailmap functions take explicit repository parameters. It also eliminates two global configuration variables (`git_mailmap_file` and `git_mailmap_blob`), replacing them with on-demand config reading. The changes touch several commands that use mailmap functionality (blame, log, shortlog, etc.) while maintaining existing behavior.

Junio C Hamano reviewed the initial version positively, noting the clean implementation and proper scope. The v2 revision fixes a `make hdr-check` failure by properly declaring `struct repository` in `mailmap.h`. This appears to be a straightforward improvement to Git's internal architecture with no expected user-facing impact, continuing the project's gradual elimination of global state. The patches look ready for merging after this mechanical header fix.
