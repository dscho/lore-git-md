Junio Hamano has accepted Joaquim Rocha's patch to normalize paths in `git apply --directory` arguments. This bugfix addresses cases where paths with `./` prefixes or `././` sequences would cause the command to fail with invalid path errors. The solution uses `strbuf_normalize_path()` for comprehensive path handling rather than just stripping prefixes, as Junio now agrees this provides better user experience with negligible performance impact. The patch builds on existing path normalization infrastructure and includes tests in `t4128-apply-root.sh` to verify behavior with various path formats. While earlier discussion debated whether a minimal fix would suffice, Junio's acceptance indicates the more general solution meets the project's standards for correctness and usability.
