Refactoring patch in Patrick Steinhardt's series to unify ref iteration interfaces. This is the third patch in a 17-part series (v1).

The patch renames `do_for_each_ref_flags` enum to `refs_for_each_flag` to better match Git's naming conventions. The enum's flags are also renamed with a `REFS_FOR_EACH_` prefix instead of `DO_FOR_EACH_`. This is a mechanical change that updates all callers across multiple ref backend implementations (files, packed, reftable) and related code in ref-filter.c.

The changes are straightforward and maintain the same flag semantics:
- `INCLUDE_BROKEN` -> `REFS_FOR_EACH_INCLUDE_BROKEN`
- `PER_WORKTREE_ONLY` -> `REFS_FOR_EACH_PER_WORKTREE_ONLY`
- `OMIT_DANGLING_SYMREFS` -> `REFS_FOR_EACH_OMIT_DANGLING_SYMREFS`
- `INCLUDE_ROOT_REFS` -> `REFS_FOR_EACH_INCLUDE_ROOT_REFS`

This continues the series' preparatory work before introducing more substantial refactoring. The patch touches 6 files with 32 line changes, all mechanical renames. No functional changes are made - this is purely a naming improvement to establish consistent terminology before the later patches introduce the new unified iteration API.
