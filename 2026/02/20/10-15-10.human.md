Performance patch (part of a series changing git maintenance's default strategy). This is patch 6/8 in Patrick Steinhardt's series to switch git maintenance's default strategy from "gc" to "geometric". The patch modifies t6500-gc.sh to explicitly set the maintenance strategy to "gc" for the test suite.

The change ensures the gc-specific tests continue working as intended after the default strategy changes. The test suite in t6500 is specifically designed to test git-gc behavior and makes assumptions about the on-disk repository state that would break under the new geometric strategy. Rather than disabling auto-maintenance entirely (which would also work), Patrick opts to pin the strategy to "gc" since the whole test is focused on gc behavior anyway.

This follows the pattern seen in earlier patches of the series where tests making specific behavioral assumptions about maintenance are updated to explicitly declare their strategy requirements. The change is minimal - just a single config line added to the test setup. The patch maintains Patrick's characteristic thorough approach to test coverage while making the actual code change needed to support the larger strategy switch.
