Test infrastructure patch fixing iconv-related test failures on Windows/MSVC.

This is the second patch in Patrick Steinhardt's five-part series addressing test failures that occur when Git is built with ICONV support (using libiconv) but the `iconv(1)` executable isn't available on Windows/MSVC systems. The patch modifies three submodule-related test scripts (t4041, t4059, t4060) to properly handle cases where the ICONV prerequisite isn't met.

The tests previously tried to use the `iconv(1)` executable even when ICONV support wasn't available, which could fail on systems without the executable. The changes make the tests skip the iconv call when the prerequisite isn't set, falling back to using UTF-8 directly. This matches the behavior where converting UTF-8 to UTF-8 would be a no-op anyway.

The patch follows the same pattern across all three test files, making the changes consistent. This version (v4) incorporates all feedback from previous iterations and has been approved by both Christian Couder and Junio Hamano, indicating it's ready for merging. The changes are part of a broader effort to improve test reliability on Windows/MSVC platforms where MinGW no longer ships the `iconv(1)` executable.
