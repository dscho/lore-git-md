The maintainer questions the feature's readiness for a configuration variable, noting the project's general practice of first introducing such functionality as a command-line option to gauge usefulness before making it configurable. This feedback suggests the patch may need to be reworked to first introduce the functionality via command-line flags before adding the config option. The comment doesn't reject the feature outright but indicates it doesn't yet follow Git's typical development pattern for new behaviors.
