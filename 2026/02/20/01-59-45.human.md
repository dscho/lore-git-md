This is part of the ongoing `the_repository` removal effort, specifically targeting the merge-ort subsystem. Patch 3/6 in Elijah Newren's series continues the mechanical conversion from using the global `the_repository` variable to passing repository state explicitly through `opt->repo`.

The patch updates various functions in merge-ort.c to use the repository pointer from the merge options struct rather than the global variable. Changes include repository-aware tree parsing, blob reading, object writing, and configuration lookups. The prefetch check for promisor remotes is also updated to use the correct repository context.

As with the rest of the series, these changes are behavior-preserving and follow established patterns for eliminating global state. The patch demonstrates Elijah's deep knowledge of the merge machinery, with careful attention to maintaining correct functionality while advancing the subsystem's alignment with the project's architectural goals. The changes are straightforward and uncontroversial, building on feedback from the v1 review.
