Feature patch adding client certificate support to `git send-email`. This adds two new options for SMTP servers that require mutual TLS authentication:

- `--smtp-ssl-client-cert` to specify a client certificate file (PEM or PKCS12 format)
- `--smtp-ssl-client-key` as an optional private key when using PEM certificates

The implementation builds on the existing SSL/TLS support in `git-send-email.perl`, extending the `ssl_verify_params` function to handle the new client certificate options. The documentation explains the formats and links to Perl's IO::Socket::SSL documentation for further details.

The patch appears well-structured with clear documentation and error handling. It addresses a real use case (mutual TLS authentication with SMTP servers) that wasn't previously supported. The changes are focused and don't introduce any obvious complexity or maintenance burden. This would be useful for users in environments with strict email security requirements.
