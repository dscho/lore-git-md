This is patch 15/17 in Patrick Steinhardt's refactoring series to unify Git's ref iteration interfaces. The patch removes the `refs_for_each_glob_ref()` function, migrating its callers to use the new unified `refs_for_each_ref_ext()` API instead.

The changes follow the same pattern seen in previous patches in the series: each caller to initialize a `refs_for_each_ref_options` struct with the glob pattern, then pass it to the new API. The patch updates three call sites - in `builtin/fetch.c`, `notes.c`, and `revision.c` - while maintaining identical behavior. The function and its declaration are then removed from `refs.c` and `refs.h`.

This continues the systematic elimination of specialized ref iteration functions in favor of the single configurable interface introduced earlier in the series. The changes are mechanical but thorough, showing Patrick's characteristic attention to detail in ensuring all callers are properly converted before removing the old API.

The patch is part of a well-structured series that has been carefully preparing for these interface removals through earlier preparatory and infrastructure patches. It follows the established pattern of the series while bringing the ref iteration API closer to its final unified form.
