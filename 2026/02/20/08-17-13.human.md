This is a feature patch adding client certificate authentication support to `git send-email`. The patch introduces new configuration options and command-line flags to enable mutual TLS authentication with SMTP servers that require client certificates.

The changes add three new settings:
- `sendemail.smtpSSLClientCert` config option and `--smtp-ssl-client-cert` flag for specifying a client certificate file (PEM or PKCS12 format)
- `sendemail.smtpSSLClientKey` config option and `--smtp-ssl-client-key` flag for the corresponding private key (optional when using PKCS12)
- Documentation updates explaining the new options and linking to relevant Perl SSL module documentation

The implementation modifies the Perl script to properly handle these new parameters during SMTP connection setup, including error checking for file existence and validating that a key isn't specified without a corresponding certificate. The changes appear well-contained, focusing only on the certificate authentication feature while maintaining compatibility with existing SMTP authentication methods.
