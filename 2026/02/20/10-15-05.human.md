This is a test infrastructure change that prepares for switching git maintenance's default strategy from "gc" to "geometric". The patch fixes potential test races caused by background maintenance operations.

Patrick Steinhardt explains that many Git commands spawn background maintenance, which can race with tests that verify repository state. While this hasn't been a major issue with the current "gc" strategy (which bails out if the object database is already optimized), the upcoming switch to "geometric" maintenance will trigger more frequent optimizations.

The solution introduces a new `GIT_TEST_MAINT_AUTO_DETACH` environment variable that makes maintenance run synchronously during tests by default. This prevents races while maintaining test coverage of the maintenance operations themselves. Benchmarking shows no significant performance impact from this change.

The patch updates several test files to use the new variable and modifies `run-command.c` to respect it. This is primarily infrastructure work to support the larger series, showing Patrick's characteristic thorough approach to test coverage when making behavioral changes.
