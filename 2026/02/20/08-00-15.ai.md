This is the final patch in Patrick Steinhardt's five-part series fixing test failures related to `iconv(1)` availability on Windows/MSVC platforms when Git is built with ICONV support. The patch specifically addresses t5550-http-fetch-dumb.sh tests that use the error endpoint.

The patch adds ICONV prerequisite checks to tests that connect to "$HTTPD_URL/error", which depends on the `iconv(1)` executable for message reencoding. Eric Sunshine points out two minor issues in the commit message ("proprely" typo) and suggests using `test_grep !` style instead of `! test_grep` for consistency with Git's test conventions. Patrick acknowledges both points and indicates he'll send an updated version.

This concludes the technical discussion of the series, which has already received approval from Christian Couder and Junio Hamano. The changes demonstrate careful handling of the distinction between libiconv (linked into Git) and the `iconv(1)` executable (used in test scripts), particularly important for Windows/MSVC environments where MinGW no longer ships `iconv(1)`. The patch maintains test coverage while improving portability across platforms.
