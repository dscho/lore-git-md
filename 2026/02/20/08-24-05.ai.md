This is the first patch of Patrick Steinhardt's 17-part refactoring series to unify Git's ref iteration interfaces. The series aims to simplify the current API which has 14 different `refs_for_each_*()` functions with subtle variations.

Patch 1/17 is a straightforward code organization change that moves `refs_head_ref_namespaced()` to be grouped with `refs_head_ref()` in refs.h, since they are logically related - both deal with HEAD refs rather than the for-each iteration pattern. The change is mechanical and uncontroversial, just relocating the function declaration to a more appropriate location in the header file.

This patch serves as preparatory cleanup before the more substantial API unification work in later patches. It demonstrates Patrick's careful, incremental approach - starting with simple uncontroversial changes before introducing the more complex refactoring. The patch touches only refs.h and makes no functional changes, just improving code organization.
