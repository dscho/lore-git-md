This is a test infrastructure patch in Patrick Steinhardt's series changing git maintenance's default strategy from "gc" to "geometric". 

The patch disables automatic maintenance in several test scripts that verify object database structure, since maintenance operations could alter that structure and cause test failures. It adds `maintenance.auto false` configurations to 11 test files across the t53xx (object storage), t55xx (fetch/push), and t77xx (maintenance) ranges.

This is a preparatory change that ensures test suite stability before the actual behavior change in later patches. The modifications are mechanical and focused - each just adds one configuration line to prevent background maintenance from interfering with tests that make assertions about packfile structure or object storage layout. 

The patch follows Patrick's characteristic thorough approach of first making the test suite robust before changing behavior. It's part of his larger effort to transition Git's more efficient geometric repacking strategy to be the default.
