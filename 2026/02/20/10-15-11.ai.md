This is part 7/8 of Patrick Steinhardt's series to change git maintenance's default strategy from "gc" to "geometric". The patch prepares the t7900 maintenance test suite for this upcoming change.

The test suite has two types of maintenance-related tests that need adaptation: those explicitly testing gc behavior (which now pin the strategy to "gc" explicitly) and those making assumptions about object database state (which disable auto-maintenance to prevent interference). The changes are minimal but targeted - adding `maintenance.strategy=gc` to one test and `maintenance.auto=false` to several others.

This continues the pattern seen in earlier patches of the series, where Patrick systematically updates tests that might be affected by the strategy change. The approach is conservative - rather than rewriting tests to work with the new strategy, he preserves their existing behavior through configuration. This ensures the test suite remains stable while allowing the default behavior to change.

The patch maintains the series' focus on comprehensive test coverage while making the actual behavioral change (coming in patch 8) as straightforward as possible. All changes are clearly motivated by specific test requirements rather than being speculative.
