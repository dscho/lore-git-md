This is the fourth patch in a five-part series addressing test failures on Windows/MSVC platforms related to `iconv(1)` availability. The patch focuses on `t5550-http-fetch-dumb.sh`, which tests HTTP error message handling.

The key change is adding the ICONV prerequisite to tests that use "$HTTPD_URL/error" endpoints, since these rely on the `iconv(1)` executable which may not be available even when Git binary has ICONV support. The patch also converts several `grep` calls to the preferred `test_grep` helper for consistency with the test suite's modern style.

This is part of a well-reviewed series that has gone through multiple iterations, with v4 incorporating final polish from Eric Sunshine. The changes are straightforward - conditionally skipping tests that require `iconv(1)` when it's unavailable, while maintaining test coverage where possible. The series as a whole demonstrates careful attention to platform portability concerns, particularly for Windows environments where MinGW no longer ships `iconv(1)` by default.
