This is the final patch in Patrick Steinhardt's series addressing test failures related to iconv availability on Windows/MSVC platforms. The patch fixes two tests in t6006-rev-list-format.sh that were unconditionally using the `iconv(1)` executable without checking the ICONV prerequisite.

The changes make the tests more robust by:
1. Using UTF-8 encoding as a fallback when ICONV is not available
2. Properly encapsulating the test setup in a prerequisite-checked block
3. Maintaining the same test coverage while being portable to environments where `iconv(1)` isn't present

This completes the series that has already been reviewed by Christian Couder and Junio Hamano, with v4 incorporating final polish from Eric Sunshine. The approach is consistent with the rest of the series - distinguishing between libiconv (used by Git itself) and the `iconv(1)` executable (used in tests). The patch is well-structured and follows the established pattern from previous patches in the series.
