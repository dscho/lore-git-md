This is patch 8/17 in Patrick Steinhardt's ref iteration API unification series. It extends the new unified API to handle namespace-aware reference iteration, previously handled by the specialized `refs_for_each_namespaced_ref()` function.

The patch adds a `namespace` field to the `refs_for_each_ref_options` struct, allowing callers to specify either the global namespace (from `GIT_NAMESPACE` environment variable) or an arbitrary namespace. When set, the iteration will only yield refs in that namespace and properly rewrite exclude patterns to work within the namespace context.

The implementation moves the namespace handling logic into the core `refs_for_each_ref_ext()` function while maintaining identical behavior. The existing `refs_for_each_namespaced_ref()` is simplified to become a thin wrapper that sets the namespace option and delegates to the unified API.

This continues the series' pattern of incrementally migrating specialized functions to use the new unified API while preserving existing behavior. The change is mechanical and well-contained, with clear documentation of the new field. Later patches in the series will presumably remove the now-redundant `refs_for_each_namespaced_ref()` function entirely.
