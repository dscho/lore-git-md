This is a code hygiene patch in the object-file subsystem, part of the ongoing ODB (object database) abstraction effort. Justin Tobler's patch replaces direct pointer casts with the safer `container_of()` macro when converting between base types (`struct odb_transaction`, `struct odb_read_stream`) and their concrete implementations in object-file.c.

The change improves type safety by making structure relationships explicit through layout rather than casting, while maintaining identical runtime behavior. Patrick Steinhardt has already reviewed and approved the changes, confirming they achieve the intended goal. The patch appears ready for merging as a straightforward improvement to the ODB infrastructure.

This is a small but meaningful cleanup that follows established patterns in the codebase. The change is uncontroversial and well-motivated as part of the larger effort to make Git's object storage more modular and maintainable.
