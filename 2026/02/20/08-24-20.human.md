This is patch 16/17 in Patrick Steinhardt's refactoring series to unify Git's ref iteration interfaces. The patch removes the specialized `refs_for_each_namespaced_ref()` function in favor of the new unified `refs_for_each_ref_ext()` API introduced earlier in the series.

The change migrates two call sites - in `http-backend.c` and `upload-pack.c` - to use the new API with a namespace option set. The patch maintains the same functionality while eliminating another specialized iteration variant, continuing the series' goal of reducing API surface area. The implementation handles namespace filtering and hidden ref exclusion through the options struct rather than separate parameters.

This is a straightforward mechanical conversion that follows the established pattern from previous patches in the series. The changes are well-contained and maintain all existing behavior, just expressed through the new unified interface. With this patch, only one more specialized iteration function remains to be converted in the final patch.
