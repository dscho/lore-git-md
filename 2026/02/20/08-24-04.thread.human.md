Patrick Steinhardt's ref iteration API unification series is nearing completion, with all 14 specialized ref iteration functions now replaced by a single configurable `refs_for_each_ref_ext()` interface. The series now awaits final testing to confirm no performance regressions have been introduced, particularly in bisect and receive-pack operations. Once these verifications are complete, the patch ordering adjustment is incorporated, this substantial API simplification should be ready for merging.
