Patrick Steinhardt's 17-patch series to unify Git's ref iteration API has reached completion with Karthik Nayak's final approval. The series consolidates 14 specialized ref iteration functions into a single `refs_for_each_ref_ext()` interface with a configurable options struct, significantly simplifying the API while preserving all existing behavior. Performance optimizations remain intact, including a notable 100x speedup for glob iteration.

Karthik reviewed the entire series thoroughly, noting improvements in v2 such as better handling of prefix stripping and reduced churn from reordering patches. The only remaining special case is `refs_for_each_replace_ref()`, which will be addressed separately. All callers across Git's codebase have been converted to the new unified interface, and documentation has been updated accordingly.

With the technical work complete and reviewed, the series now awaits merging by Junio. This represents a major step in modernizing Git's refs subsystem and sets a pattern for future API simplifications. The changes maintain backward compatibility while providing a cleaner foundation for future development.
