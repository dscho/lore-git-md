This is a test infrastructure patch in Patrick Steinhardt's series changing git maintenance's default strategy to geometric repacking. The patch disables automatic maintenance in tests that verify object database structure, since maintenance operations could alter that structure and cause test failures.

The change adds `maintenance.auto false` configurations to 11 test files across the t53xx (object storage), t55xx (fetch/push), and t77xx (repacking) ranges. These tests explicitly check packfile organization, delta chains, and multi-pack-index behavior - all of which could be affected by background maintenance repacking objects. The modifications are straightforward additions of the config setting at test setup points.

This is a preparatory patch that ensures test reliability before the later behavioral change in the series. It demonstrates Patrick's characteristic thorough approach - first hardening the test suite against potential side effects before making the actual functional change. The patch is mechanical but important for maintaining test stability when the maintenance strategy changes.
