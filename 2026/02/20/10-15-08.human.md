This is a test adjustment patch in Patrick Steinhardt's series changing git maintenance's default strategy from "gc" to "geometric". The patch modifies t5400-send-pack.sh to explicitly set `maintenance.strategy=gc` in a test that verifies receive-pack's auto-gc behavior.

The test checks that receive-pack prunes temporary objects by observing gc's effects, which won't happen with the new geometric strategy. Rather than rewriting the test to work with geometric repacking, Patrick opts to preserve the existing gc-specific verification by pinning the strategy. This is a pragmatic choice that keeps the test focused on its original purpose while allowing the broader default behavior change to proceed.

The change is straightforward - just one line adding the config - and follows the pattern seen in earlier patches of this series where tests are updated to handle the strategy switch. It demonstrates Patrick's careful approach to test maintenance: rather than making tests more complex to handle both strategies, he isolates the gc-specific verification where needed.
