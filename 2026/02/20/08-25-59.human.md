This is the first patch in a five-part test infrastructure series addressing CI failures on Windows/MSVC platforms. The core issue involves tests failing when Git is built with ICONV support (using libiconv) but the `iconv(1)` executable isn't available - a situation that arose when Git for Windows stopped shipping the `iconv(1)` binary.

The patch modifies the ICONV prerequisite in `t/test-lib.sh` to require both that Git was built with iconv support (`NO_ICONV` not set) AND that the `iconv(1)` executable exists (verified by testing a simple conversion). This ensures tests will properly skip when either condition isn't met, rather than failing. The patch includes a NEEDSWORK note suggesting this could eventually be split into two separate prerequisites.

This change provides the foundation for the subsequent patches that will fix individual test scripts to properly handle cases where the executable is missing. The series has already gone through several rounds of review and is now ready for merging, with all feedback incorporated.
