This is a feature patch adding MIDX compaction functionality, part of Taylor Blau's ongoing work on the multi-pack-index subsystem. The patch implements a new `git multi-pack-index compact` subcommand that combines adjacent MIDX layers while preserving the MIDX chain structure and bitmap compatibility.

The key motivation is to prevent MIDX chains from growing too long by compacting sequences of layers into single layers. The implementation handles both lexicographically ordered and unordered pack names, preserves pseudo-pack ordering (important for bitmap compatibility), and includes safeguards against invalid compaction ranges.

The patch adds comprehensive tests covering:
- Basic compaction scenarios with both ordered and unordered pack names
- Error cases (missing endpoints, reversed ranges, identical endpoints)
- Version compatibility (rejecting v1 MIDX formats)
- Object uniqueness verification across layers
