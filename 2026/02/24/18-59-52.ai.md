Documentation patch correcting outdated MIDX bitmap compatibility note in the `git-multi-pack-index` man page. This is part of Taylor Blau's ongoing series to add compaction support for multi-pack-index files.

The patch removes a stale statement claiming that `--incremental` and `--bitmap` options are incompatible for `git multi-pack-index write`. This incompatibility existed in the initial incremental MIDX implementation (fcb2205b774) but was resolved in a later commit (27afc272c49) that added bitmap support for incremental MIDX files. The documentation simply hadn't been updated to reflect this change.

This is a straightforward documentation fix that aligns the man page with the actual implementation. As part of the larger MIDX compaction series (now in its third iteration), this patch helps ensure users have accurate information about feature compatibility.
