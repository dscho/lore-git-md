This is the final patch in Phillip Wood's series adding `--trailer` support to `git rebase`, now in its 7th iteration. The patch implements the actual `--trailer` option for `git rebase`, allowing trailers (like Signed-off-by) to be automatically appended to each rewritten commit message during a rebase.

The implementation requires the merge backend (rejecting use with `--apply`) and implies `--force-rebase` to ensure trailers are added even to fast-forwarded commits. The patch includes extensive test coverage (147 lines in t3440-rebase-trailer.sh) verifying error handling, trailer insertion behavior, and interaction with fixup commands and conflicts.
