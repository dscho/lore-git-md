This is the final patch in a series implementing configurable cover letter formatting for `git format-patch`. The series adds both a command-line option (`--cover-letter-format`) and a config setting (`format.commitListFormat`) to control how commit lists appear in cover letters.

The implementation builds carefully across three patches, with this final one adding the persistent config option. The formatting syntax supports printf-style placeholders (%s for subject, %a for author) and maintains backward compatibility by falling back to the traditional shortlog format when unconfigured. The series addresses a NULL dereference bug along the way and includes thorough test coverage.

The patch appears well-crafted and complete, matching maintainer Junio C Hamano's requirements. It provides a clean solution to a real pain point - the inflexibility of cover letter commit list formatting - while following Git's incremental development philosophy. The careful progression from RFC to production-ready implementation suggests this is likely to be merged without further major changes.
