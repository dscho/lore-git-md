Test patch for `git for-each-repo` repository-less operation.

This is the first patch in Derrick Stolee's v2 series addressing environment handling in `git for-each-repo`. The patch modifies the test suite to verify the command works correctly outside a repository context, which is its typical use case (e.g. for background maintenance). The changes switch all test repository configurations to use `--global` and remove the default test repo creation, while maintaining the same verification logic.

Key technical details:
- Adds `TEST_NO_CREATE_REPO=1` to prevent automatic test repo creation
- Converts all `git config` calls to use `--global`
- Updates test assertions to work without a default repository
- Preserves all existing test cases (bad config keys, NULL values, --keep-going)
- Touches only `t/t0068-for-each-repo.sh`

The patch reveals an underlying architectural issue - the command still relies on `the_repository` global when handling config outside a repo context, similar to `builtin/config.c`. This dependency will need to remain until a better solution for repository-less config access is implemented. The test changes help surface these edge conditions while maintaining the command's core functionality.
