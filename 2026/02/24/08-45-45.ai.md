This is the first patch in Patrick Steinhardt's 8-part series to make geometric repacking the default maintenance strategy. The patch addresses test suite reliability issues that would arise when background maintenance becomes more aggressive under the new geometric strategy.

The change introduces a new `GIT_TEST_MAINT_AUTO_DETACH` environment variable that forces maintenance tasks to run synchronously during tests rather than in the background. This prevents races between test assertions and background operations while maintaining test coverage of the maintenance behavior itself. The patch updates several test files to account for this change, including modifying subcommand checks in t5616-partial-clone.sh and adding the variable to t/test-lib.sh.

The commit message provides thorough justification for the approach, noting that while this diverges from real-world behavior by removing true background operation, it provides more reliable test results. Benchmark results show no significant performance impact from the change. The patch is well-motivated as preparatory work for the geometric repacking default that follows in later patches.
