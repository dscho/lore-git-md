This is a performance-focused patch series from Patrick Steinhardt that makes geometric repacking the default maintenance strategy in Git. The series has gone through thorough review and is now ready for merging.

The key change comes in the final patch, which modifies `builtin/gc.c` to use the geometric strategy by default while maintaining backward compatibility via the `maintenance.strategy=gc` config option. This completes a transition to more flexible repository maintenance infrastructure and provides better performance for large repositories by delaying expensive "all-into-one" repacks longer than the traditional gc strategy.

The series demonstrates careful preparation with the first 7 patches updating test infrastructure to handle the new default behavior. Tests are modified to either:
- Explicitly disable maintenance where it would interfere with object database verification
- Preserve hardcoded reflog entries in rebase tests
- Explicitly request the old "gc" strategy where tests expect specific behavior

Reviewers Derrick Stolee (who designed geometric repacking) and Justin Tobler have confirmed the technical approach is sound, with Tobler noting the comprehensive test coverage. The change maintains backward compatibility while moving Git to a more scalable maintenance approach that should benefit most users.
