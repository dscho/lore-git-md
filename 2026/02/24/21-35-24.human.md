This is the second patch in a two-part series improving environment handling in `git for-each-repo`, focusing on worktree compatibility. The patch ensures the command works correctly when run from a worktree by properly managing Git's environment variables (GIT_DIR, GIT_WORK_TREE, etc.).

The key changes include:
- Adding a worktree to the test setup and verifying `for-each-repo` works from it
- Moving test config from local to global scope to accommodate repository-less operation
- Implementing proper save/restore of environment variables around child processes using Git's `local_repo_env` mechanism

The patch builds on feedback from v1, with Jeff King and Patrick Steinhardt contributing to the environment isolation approach. The test changes reveal the command now handles worktree cases correctly while maintaining existing functionality. This completes the series' goal of robust environment handling, though it surfaces an unresolved dependency on `the_repository` for config access in repository-less cases.
