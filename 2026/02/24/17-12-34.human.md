This is a follow-up patch series addressing minor documentation and compatibility issues in the UTF-8 alias subsection implementation that was recently merged into `next`.

Jonatan Holmgren sends two small fixes to polish the feature:

1. A documentation patch correcting the formatting of an example in `alias.adoc` that shows the equivalence between `alias.last` and `alias.last.command` syntax. The example was missing list continuation markers, making it harder to read.

2. A compatibility fix for the case where an empty subsection (`[alias ""]`) appears in config files. The current implementation treats this as distinct from a plain `[alias]` section, which breaks existing configs that use this pattern. The patch makes them equivalent.

The changes are straightforward with good test coverage - the second patch adds new tests verifying the empty-subsection behavior. This continues the careful attention to backward compatibility that has characterized the entire UTF-8 alias subsection effort. The patches address real issues but don't introduce new functionality or controversy.

These look like sensible final tweaks before the feature graduates from `next` to `master`. The series maintains the high quality we've seen throughout this development, with clear commit messages and appropriate test coverage.
