This is the second patch in a 3-part series implementing configurable cover letter formatting for `git format-patch`. The patch adds the core functionality to support alternative commit list formats in cover letters via a new `--cover-letter-format` option.

The implementation allows users to specify either "shortlog" (the current default behavior) or a printf-style format string prefixed with "log:" (e.g. "log:%s (%an)" to show subject and author name). The format string supports standard commit formatting placeholders like %s for subject and %a for author. When no format is specified, it falls back to the traditional shortlog output.

Key technical changes:
- New `generate_commit_list_cover()` function handles the formatted output
- Modified `make_cover_letter()` to accept and process the format parameter
- Added `--cover-letter-format` command-line option parsing
- Maintains backward compatibility with existing shortlog behavior
- Includes basic error handling for invalid format strings

The patch follows the design direction established in the RFC discussion, implementing the printf-style approach requested by maintainer Junio C Hamano. It builds on the foundation from patch 1/3 (which fixed a NULL dereference issue) and prepares for patch 3/3 (which will add the config option).

The implementation appears clean and focused, with clear separation between the new formatting logic and existing shortlog handling. The changes are well-contained within `builtin/log.c` and maintain the project's coding style.
