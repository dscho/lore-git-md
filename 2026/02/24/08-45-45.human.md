This is the first patch in Patrick Steinhardt's 8-part series to make geometric repacking the default maintenance strategy. It's a test infrastructure preparation patch that addresses race conditions issue between background maintenance and the test suite.

The patch introduces a new `GIT_TEST_MAINT_AUTO_DETACH` environment variable that forces maintenance tasks to run synchronously during tests rather than in the background. This prevents flaky tests that could occur when background maintenance modifies repository state while tests are running assertions about that state.

The change is particularly important because the upcoming switch to geometric maintenance (in patch 8) will make maintenance more aggressive about optimizing repository structures beyond just the object database. The patch includes benchmark results showing this change doesn't significantly impact test suite runtime.

This is a well-motivated infrastructure change that lays groundwork for the series' main feature. It shows careful consideration of both test reliability and performance impacts, with thorough testing of the code paths being modified. The patch has already received positive review from domain experts in the thread.
