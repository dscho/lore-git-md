Karthik Nayak responds to Kristoffer Haugsbakk's observation about formatting issues in the HTML output of `git-config(1)` man pages. The problem occurs when list continuations (`+`) and the `;;` syntax appear in the rendered documentation. The fix removes these list continuations and adjusts the formatting to ensure clean HTML output.

The patch is a small but important polish to the documentation for the new `refStorage` configuration option, which allows specifying reference storage formats (like 'files' or 'reftable') with optional URI-style payloads. This is part of a larger effort to enable zero-downtime migrations between different reference storage backends, primarily serving GitLab's needs.
