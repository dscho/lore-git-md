This is the third and final patch in a series implementing configurable cover letter formatting for `git format-patch`. It adds the `format.commitListFormat` configuration option, completing the feature set established in earlier patches.

The patch introduces persistent configuration for the cover letter commit list format, allowing users to set a default format in their Git config rather than specifying it each time via `--cover-letter-format`. The implementation follows the same printf-style formatting established in patch 2/3, where format strings can include `%s` for subject and `%a` for author (with the "log:" prefix). When unset, the behavior falls back to the traditional shortlog format.

Key technical details:
- Adds `fmt_cover_letter_commit_list` field to `struct format_config`
- Implements config parsing in `git_format_config()` with proper memory management
- Maintains backward compatibility with command-line override behavior
- Includes basic validation of format strings
- Properly frees allocated memory in `format_config_release()`

The patch builds cleanly on the previous work, with patch 1/3 fixing a NULL dereference and patch 2/3 establishing the core formatting engine. This final piece provides the configuration layer, completing the feature as specified in the RFC discussion. The implementation appears thorough and matches the maintainer's requirements for flexibility while maintaining backward compatibility.
