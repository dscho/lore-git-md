This is a v2 patch series from Derrick Stolee addressing environment handling in `git for-each-repo`, with both bugfix and refactoring components. The series follows up on a reported issue where the command wasn't working correctly in worktree contexts.

The first patch adds tests to verify `for-each-repo` works outside a repository context, while the second patch fixes the worktree operation by properly handling Git environment variables. The key change is a more comprehensive approach to environment isolation - rather than just unsetting GIT_DIR, the patch now saves, unsets, and restores all Git-specific environment variables (from `local_repo_env`) when running commands in child repositories.

The series builds on previous discussion where Jeff King identified broader environment handling requirements and Patrick Steinhardt noted NULL-safety concerns. The v2 appears to address these by:
1. Using the full `local_repo_env` array for isolation
2. Properly managing variable restoration
3. Adding test coverage for both worktree and non-repo cases

The changes are focused on `builtin/for-each-repo.c` and its test file, with careful memory management of the environment variables. This looks like a solid improvement over the initial approach, though reviewers may want to verify the environment handling is complete and robust across all edge cases.
