This is the third patch in Phillip Wood's v7 series adding `--trailer` support to `git rebase`. The patch introduces in-process trailer manipulation to avoid forking `git interpret-trailers`.

The key changes are:
1. Adds `amend_strbuf_with_trailers()` to apply trailers directly to a strbuf using the existing trailer logic
2. Updates `amend_file_with_trailers()` to use the new in-process helper while maintaining the same --in-place semantics via tempfile+rename
3. Preserves backward compatibility by stripping --trailer= prefixes for existing callers
4. Adds validation of trailer arguments via `validate_trailer_args()`

The implementation carefully maintains atomic file updates and handles edge cases like empty arguments and file permissions. The patch moves more trailer processing logic into trailer.c while keeping the file I/O responsibilities in builtin/interpret-trailers.c.

This is part of the larger effort to enable rebase to modify trailers (like Signed-off-by) without spawning a separate process. The changes are focused on the trailer subsystem internals and don't yet expose any new user-facing functionality - that will come in later patches in the series. The implementation appears thorough, with clear commit message explanations and handling of edge cases.
