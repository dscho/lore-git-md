This is a refactoring patch in Taylor Blau's multi-pack-index compaction series, specifically part 12 of 17 in the third iteration. The patch extracts a helper function `fill_pack_from_midx()` from the existing `fill_packs_from_midx()` to reduce code duplication in preparation for the compaction functionality.

The new helper function handles the core operation of loading pack information from a MIDX file - preparing the pack data and reading its name. This extraction allows the same logic to be reused when implementing MIDX compaction, where the caller context will differ from the current usage. The change is purely structural with no behavior modification, maintaining the same error handling and memory growth patterns.

This continues the series' pattern of careful refactoring to support the new compaction feature while keeping the codebase maintainable. The patch follows the established style of the surrounding MIDX code and includes appropriate error messages. As with previous patches in the series, this appears technically sound and well-motivated as part of the larger effort.
