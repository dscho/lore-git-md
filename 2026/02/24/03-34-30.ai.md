Review feedback on worktree environment handling in `for-each-repo`. Eric Sunshine raises an important consideration about the scope of environment variable cleanup in Derrick Stolee's worktree fix for `git for-each-repo`. While Stolee's patch correctly addresses the immediate issue by unsetting `GIT_DIR`, Sunshine points out that the githooks documentation recommends a more thorough approach - clearing all Git-specific environment variables using `git rev-parse --local-env-vars` when operating across different repositories or worktrees.

This suggests the current fix might be incomplete, as other variables like `GIT_WORK_TREE` could also interfere with child operations. The reference to established practice in the hooks subsystem provides a more robust pattern that the `for-each-repo` command might want to adopt. The comment is directed to both Stolee and Peff (Jeff King), likely because of Peff's deep knowledge of Git's environment handling and edge cases.

The feedback doesn't reject the patch outright but flags an area that may need expansion to match Git's own documented best practices for cross-repository operations. This is characteristic of Sunshine's review style - precise, well-documented, and focused on consistency with existing patterns.
