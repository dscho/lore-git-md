This is a bugfix patch from Junio C Hamano addressing a compiler warning in Mirko Faina's cover letter formatting series. The issue is a type mismatch when assigning the string literal "shortlog" to a non-const char pointer in `builtin/log.c`. Junio points out that the compiler correctly flags this as an error since string literals are constant in C.

The patch is part of an ongoing effort to add configurable formatting for cover letter commit lists in `git format-patch`. While the series has cleared major architectural hurdles after Jeff King's review, Junio is now catching implementation details that need polishing before final acceptance. This particular fix appears straightforward - the variable should be declared as `const char *` to properly handle the string literal assignment.

The series as a whole provides useful flexibility for regular patch submitters by allowing both command-line (`--cover-letter-format`) and config-based (`format.commitListFormat`) control over how commit lists appear in cover letters. With this compiler warning addressed, the implementation moves closer to being merge-ready.
