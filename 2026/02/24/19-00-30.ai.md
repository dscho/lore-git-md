This is a refactoring patch in Taylor Blau's ongoing series to implement `git multi-pack-index compact` functionality. The patch focuses on improving code organization in the MIDX (multi-pack-index) writing logic.

The change factors out fanout layer handling from `compute_sorted_entries()` into a new helper function `midx_fanout_add()`. This prepares the codebase for MIDX compaction by separating the core fanout processing logic from the surrounding object sorting infrastructure. The new helper maintains all existing behavior while making the code more modular - it still handles both MIDX and pack sources, respects preferred pack positioning, and processes objects one fanout layer at a time.

This is part of the larger effort to enable combining adjacent MIDX layers while maintaining bitmap compatibility. The refactoring doesn't change functionality but makes the code more maintainable for the compaction feature being added in later patches. The change is well-contained, touching only midx-write.c with straightforward extraction of existing logic into a new function.
