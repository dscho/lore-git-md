This is a v2 patch series from Derrick Stolee addressing worktree handling in `git for-each-repo`, building on prior discussion about environment variable isolation in cross-repo operations. The series now has two patches: first adding tests for repository-less contexts, then fixing worktree operation by properly managing Git's environment variables.

The key technical change in v2 expands from just unsetting GIT_DIR to handling all Git-specific environment variables (from `local_repo_env`) - storing their values, unsetting them before child process execution, then restoring them afterward. This addresses Jeff King's concern about comprehensive environment isolation while maintaining the parent process's environment.

The test changes demonstrate both repository-less operation and correct behavior across worktrees, including global config usage and path interpolation. The discussion history shows this builds on prior input from Patrick Steinhardt (NULL-safety), Eric Sunshine (environment patterns), and Jeff King (environment handling requirements).

The patch touches `builtin/for-each-repo.c` (environment management) and `t/t0068-for-each-repo.sh` (expanded test cases). Open questions from v1 about NULL-safety and -C interaction appear resolved, with the solution now systematically handling all relevant environment variables through Git's existing `local_repo_env` mechanism.
