This is the final patch in a 3-part series implementing configurable commit list formatting for `git format-patch` cover letters. The series follows Junio C Hamano's design direction for this feature.

Patch 3/3 adds the `format.commitListFormat` configuration option, allowing users to set a default format for the commit list in cover letters. The format uses printf-style specifiers like `%s` (subject) and `%a` (author), matching the command-line `--cover-letter-format` option introduced in patch 2/3. When unset, it falls back to the traditional shortlog format.

The implementation carefully handles memory management and maintains backward compatibility. It builds on the NULL dereference fix from patch 1/3 and the core formatting engine from patch 2/3. The patch follows Git's configuration conventions precisely, with proper string handling and error checking.

This completes the feature by providing both command-line and config-file control over cover letter formatting, addressing the original use case where users wanted to avoid repeatedly specifying the format on the command line. The series appears well-structured, with each patch building logically on the previous one.
