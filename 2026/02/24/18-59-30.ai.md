This is the third version of Taylor Blau's patch series implementing MIDX compaction, building on previous discussions about arithmetic safety and version compatibility. The series introduces a `git multi-pack-index compact` subcommand that combines adjacent MIDX layers while maintaining bitmap compatibility.

The key changes in this version are:
- Documentation fixes around the new `midx.version` config setting
- A bugfix for handling objects at the compaction boundary
- Removal of the `u32_add()` helper after confirming Git's standard `st_add()` pattern is sufficient for arithmetic safety
- Refactoring of the fanout layer handling to properly support compaction ranges

The series remains focused on infrastructure for future repacking strategies rather than direct user-facing features. It requires MIDX v2 format due to fundamental limitations in v1's pseudo-pack ordering representation. All technical feedback from reviewers (Jeff King, Patrick Steinhardt, and Junio Hamano) has been addressed, with the arithmetic safety discussion now resolved in favor of Git's standard overflow-checking patterns.

The implementation includes thorough test coverage in new test scripts and maintains backward compatibility where possible. The changes are isolated to the compaction logic itself, minimizing risk to existing functionality. Taylor indicates this should be close to final, with plans to build the actual repacking strategy on top in a follow-up series.
