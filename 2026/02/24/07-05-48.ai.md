This is a refactoring patch in Phillip Wood's series to add `--trailer` support to `git rebase`. The patch moves the `process_trailers()` function from `builtin/interpret-trailers.c` to `trailer.c` and exposes it via `trailer.h`, making the trailer processing logic reusable by other commands.

The change is straightforward - the function is copied verbatim to its new location with only a minor parameter rename (from `sb` to `input`). This enables the upcoming rebase integration to use the same core trailer manipulation logic without duplicating code. The patch maintains all existing functionality while preparing for the series' goal of allowing in-process trailer manipulation during rebase operations.

This is part of a well-structured series that has gone through multiple iterations of review, with the author (Phillip Wood) carefully addressing feedback. The change aligns with Git's practice of refactoring shared functionality into reusable components before adding new features that depend on them.
