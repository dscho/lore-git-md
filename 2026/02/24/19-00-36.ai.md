This is a test infrastructure patch in Taylor Blau's multi-pack-index compaction series. It fixes a memory leak in the test helper `test-read-midx.c` that would occur when looking up a specific MIDX layer by checksum. The leak happens because the helper drops its reference to the topmost MIDX layer while walking the chain, then fails to properly clean up when closing.

The patch adds proper reference tracking by keeping a pointer to the tip of the MIDX chain (`tip`) and ensuring it gets closed at the end. It also improves error handling by using `goto out` for cleanup and returning an error message when the requested MIDX layer isn't found. This is preparatory work for the compaction functionality being added in the series, though the test helper's lookup-by-checksum path isn't currently exercised by any tests.

The change is straightforward and well-contained, addressing a real issue that would become visible once the compaction functionality starts using this code path. As with the rest of the series, it demonstrates careful attention to resource management in the MIDX infrastructure.
