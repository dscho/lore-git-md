Refactoring patch as part of Phillip Wood's series to add `--trailer` support to `git rebase`. This is the second patch in v7 of the series.

The patch moves the `process_trailers()` function from `builtin/interpret-trailers.c` to `trailer.c` and exposes it via `trailer.h`. This refactoring enables reuse of the trailer processing logic by other commands (specifically `git rebase` in later patches) without duplicating code. The implementation remains unchanged - it's purely a code reorganization to support the broader goal of adding trailer manipulation during rebase operations.

The change is mechanical but important infrastructure work for the series. It follows the pattern seen in earlier iterations where core functionality is extracted to make it available across commands. The patch maintains all existing behavior while enabling the planned rebase integration.
