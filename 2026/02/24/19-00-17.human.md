This is a refactoring patch in Taylor Blau's ongoing series to implement `git multi-pack-index compact` functionality. The patch introduces a helper function `midx_pack_perm()` to safely access the `pack_perm` array during MIDX compaction operations.

The change addresses a potential out-of-bounds read when compacting MIDX layers with different pack ID ranges. Currently, the code directly indexes into `ctx->pack_perm` using pack IDs that may exceed the array bounds during compaction. The new helper function will eventually implement bounds checking and index adjustment logic (though that's not yet in this patch).

This is a preparatory change that maintains existing behavior while making the codebase ready for the actual compaction logic to be added. The patch touches several MIDX-writing functions that need to access pack permutations, converting their direct array accesses to use the new helper. The change is mechanical and well-contained, with all modifications clearly focused on the pack permutation access pattern.

As part of Taylor's larger MIDX compaction effort, this patch helps pave the way for safely combining MIDX layers while preserving bitmap compatibility. The series has already gone through multiple rounds of review, with this version addressing previous feedback.
