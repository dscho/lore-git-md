This is a test modernization patch in Derrick Stolee's series improving `git for-each-repo`'s behavior outside repository contexts. The patch updates the test script to properly exercise repository-less operation by:

1. Adding `TEST_NO_CREATE_REPO=1` to prevent automatic test repo creation
2. Converting all test configs to use `--global` since there's no local repo
3. Adjusting test assertions to work without assuming a local working directory

The changes reveal that `for-each-repo` still relies on `the_repository` global when handling config outside a repo context, similar to `builtin/config.c`. This dependency will need future attention as part of the ongoing `the_repository` removal effort.

The patch is part of a v2 series addressing environment handling in `for-each-repo`, with this first patch establishing proper test coverage before the implementation changes in the second patch. The test changes look thorough and appropriately focused on the repository-less use case that maintenance operations typically encounter.
