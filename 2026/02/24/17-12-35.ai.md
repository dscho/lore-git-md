This is a documentation patch fixing formatting in the alias configuration documentation, part of the ongoing UTF-8 subsection support effort. It addresses one of the minor documentation issues identified in the v7 series that was recently integrated into `next`.

The patch corrects a rendering issue where the example showing the equivalence between `alias.last` and `alias.last.command` was missing list continuation markers (`+`), causing the explanatory text to detach from the list item in the HTML output. The fix adds proper AsciiDoc list continuation syntax while maintaining all the existing content.

This is a straightforward improvement to the documentation that doesn't affect functionality. The change aligns with the project's documentation standards and follows up on earlier feedback about the formatting. The patch is cleanly focused on this single issue, with no behavioral changes or new content introduced.
