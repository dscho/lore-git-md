This is the final patch in a series implementing configurable cover letter commit list formatting for `git format-patch`. The series adds both a command-line option (`--cover-letter-format`) and a config setting (`format.commitListFormat`) to control how commits are listed in cover letters.

The implementation builds on two previous patches that fixed a NULL dereference in the formatting code and introduced the core formatting engine. This third patch adds the persistent config option, completing the feature set requested by maintainer Junio C Hamano. The config uses the same printf-style format specifiers as the command-line option (%s for subject, %a for author, etc.), with the command-line version taking precedence when both are present.

Key technical details include proper memory management in `format_config_release()` and maintaining backward compatibility by falling back to traditional shortlog format when neither option is specified. The patch includes comprehensive test coverage and documentation updates. With all three patches now complete and interdependent, the series appears ready for maintainer consideration, having addressed all technical requirements while following Git's incremental development approach.
