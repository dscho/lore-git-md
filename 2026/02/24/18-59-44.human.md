This is part of Taylor Blau's multi-pack-index compaction series, specifically patch 3/17 introducing a helper function for MIDX checksum handling. The patch adds `midx_get_checksum_hex()` to simplify the common case of converting a MIDX's checksum hash to its hexadecimal representation, while keeping the existing `midx_get_checksum_hash()` for callers needing the raw bytes.

The change follows Git's established patterns for hash handling functions and reduces repetitive code in several places that were manually converting the hash to hex. The implementation uses a static buffer (as is conventional for such hex conversion helpers in Git's codebase) and updates all relevant callers in midx-write.c, pack-bitmap.c, and test helpers.

This appears to be a straightforward quality-of-life improvement that builds on Patrick Steinhardt's earlier suggestion to rename the checksum function in this series. The patch is well-contained with clear motivation and maintains backward compatibility for existing callers. As part of the larger MIDX compaction effort, this small helper will make subsequent patches more readable by eliminating repetitive hash-to-hex conversions.
