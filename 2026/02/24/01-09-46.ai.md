This is a bugfix patch series addressing an issue with diffstat width calculation when line prefixes contain ANSI color codes. The series comes from a GSoC (Google Summer of Code) contributor and consists of two patches: one to fix the core issue and another to add a regression test.

The problem occurs when calculating the width of diffstat output - the code currently uses `strlen()` on line prefixes that may contain ANSI color codes, which don't take up visible space but do contribute to string length. This leads to incorrect width calculations. The fix properly accounts for ANSI codes by using display width rather than string length.
