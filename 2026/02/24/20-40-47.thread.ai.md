Original plumbing-style design (Phillip Wood) showed nothing by default. V2 proposed showing all fields when either `--all` given OR no arguments, but Junio C Hamano strongly opposed this as violating Git's plumbing command principles (zero arguments must mean zero output for scripting). K Jayatheerth reinforced this by pointing contributor to "Plumbing and Porcelain" chapter in Pro Git book, confirming maintainer's stance that new commands must follow established plumbing conventions regardless of porcelain convenience. Lucas Seiki Oshiro further endorsed this position, reinforcing the educational value of Pro Git's documentation.

Technical implementation in `builtin/repo.c` will proceed under settled guidelines, with the experimental command showing nothing by default as required for plumbing commands.
