Build system fix for config-list.h dependencies, addressing final edge case in v6 series.

This is the latest in a multi-iteration effort to properly track dependencies between Git's configuration documentation and the generated `config-list.h` header. The thread has identified a final edge case where removing documentation files (like `hook.adoc`) breaks the build due to stale dependency tracking in the Makefile.

D. Ben Knoble agrees with Phillip Wood's assessment that the solution should follow GCC/Clang's approach of including empty targets for all dependencies in the depfile, rather than dropping Makefile support entirely. This matches how Meson already handles the case while maintaining cross-platform compatibility. The change will be implemented in `generate-configlist.sh` to produce depfiles that list both the real dependencies and empty targets for each file, preventing make from failing when files are removed.

The patch series has already addressed numerous technical challenges including path escaping, Windows performance, and dual-build-system support (Makefile and Meson). This final tweak will complete the solution while preserving all existing functionality. The discussion shows careful consideration of edge cases and platform differences, with input from multiple experienced contributors (Patrick Steinhardt, Phillip Wood, and SZEDER Gábor) helping refine the approach.
