This is a bugfix patch addressing a compiler warning in the configurable cover letter formatting series. Junio C Hamano points out a const-correctness issue in Mirko Faina's implementation where a non-const pointer is assigned a string literal (which is const-qualified in C). The compiler correctly flags this as an error since it would allow potentially unsafe modification of read-only memory.

The issue appears in the second patch of the series which adds config-based control over cover letter formatting. The problematic line attempts to set a default format of "shortlog" when no custom format is specified. The fix will need to either declare the pointer as const or use a different approach to handle the default case.

This is a straightforward technical correction needed to make the series compile cleanly. The architectural approach has already been validated through earlier review, and this appears to be the only remaining compiler warning to address before the series can proceed. The patch demonstrates Git's attention to detail in maintaining strict compiler warning hygiene, even for what might seem like minor issues.
