This is a refactoring patch in Taylor Blau's multi-pack-index compaction series (patch 4/17). It consolidates the `--progress` option handling for all `git multi-pack-index` subcommands (write, verify, repack, expire) into a common options structure, rather than having each subcommand declare it separately. 

The change is straightforward - it moves the `OPT_BIT` declaration for `--progress` into the shared `common_opts` array and removes the redundant declarations from each subcommand. The documentation is also updated to note that this option applies to all subcommands. 

This is a clean, mechanical improvement that follows the DRY principle while maintaining all existing functionality. The patch fits well with the series' broader goal of improving the MIDX infrastructure. Since this is part of a larger effort that has already undergone significant review (now in its third iteration), this particular change appears uncontroversial and ready for merging.
