This is a refactoring patch from Taylor Blau's multi-pack-index compaction series, introducing a `struct write_midx_opts` to consolidate parameters for MIDX writing operations. The patch is part of a larger effort to add `git multi-pack-index compact` functionality with bitmap support.

The change replaces the six direct parameters to `write_midx_internal()` with a single options struct containing the same fields. This prepares for future additions to the MIDX writing interface without requiring all callers to pass new parameters they don't need. The patch maintains all existing functionality while making the code more maintainable.

Key technical points:
- New `struct write_midx_opts` contains all parameters previously passed to `write_midx_internal()`
- All callers updated to initialize the struct with their parameters
- Zero-initialization pattern ensures new fields can be added without requiring changes to existing callers
- No behavior changes in this patch - purely a refactoring step
- The struct will be used in subsequent patches to support MIDX compaction
- Maintains existing error handling and progress reporting behavior
- Preserves all MIDX version compatibility and bitmap support logic

This is a well-contained preparatory change that follows Git's pattern of using options objects for complex parameter sets. The patch is cleanly separated from the functional changes that will build on it later in the series.
