This is the second patch in Patrick Steinhardt's 8-part series to make geometric repacking the default maintenance strategy. The patch focuses on test reliability by disabling auto-maintenance in tests that verify object database structure.

The change modifies 11 test scripts to explicitly set `maintenance.auto=false` when they need to inspect or verify the exact state of the object database. This ensures tests aren't affected by background maintenance operations that might repack or optimize the object store during test execution. The affected tests include various packfile and multi-pack-index related tests, partial clone verification, and repack tests.

This is a preparatory patch that ensures test stability before the later change to make geometric repacking the maintenance default. The careful approach of first hardening the test suite before changing behavior is characteristic of Patrick's thorough patch series style. The changes are mechanical but important for maintaining test reliability of the object storage layer as the maintenance strategy changes.

Key technical details:
- Adds `maintenance.auto=false` to tests that inspect packfiles and object storage
- Affects tests for delta chains, multi-pack indexes, bitmaps, and partial clones
- Follows the series' pattern of infrastructure changes before behavior changes
- Maintains test coverage while preventing interference from background maintenance

The patch builds on the test infrastructure work from patch 1 and continues the careful preparation for the geometric repacking default change coming in patch 8.
