This is a technical patch in Taylor Blau's multi-pack-index compaction series, specifically addressing how pack files are ordered within MIDX files. The patch removes the requirement for packs to be sorted lexicographically in MIDX v2 format, which is necessary for the compaction feature to work without invalidating existing bitmaps.

The key change is introducing version-aware handling of pack ordering - while MIDX v1 still enforces lexicographic order for backward compatibility, v2 allows arbitrary ordering. This enables combining adjacent MIDX layers while preserving bitmap validity, as the pseudo-pack ordering (which considers preferred packs) can now be maintained regardless of pack names. The patch implements this by lazily building a sorted index array when needed for binary search in `midx_contains_pack()`.

The change is guarded behind a version bump to MIDX v2 to avoid breaking external tools that might rely on the lexicographic ordering assumption. The patch includes corresponding documentation updates and test adjustments to verify the version-specific behavior. This is a foundational change enabling the compaction functionality while maintaining backward compatibility where needed.
