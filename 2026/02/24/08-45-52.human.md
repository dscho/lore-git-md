Performance patch that changes Git's default maintenance strategy from "gc" to "geometric" repacking. This is the final patch in Patrick Steinhardt's 8-part series preparing the test suite and infrastructure for this behavior change.

The patch updates the default strategy used by `git maintenance run` (manual mode) while keeping the "incremental" strategy for scheduled background maintenance. The geometric strategy maintains a progression of packfiles that reduces expensive all-into-one repacks, making it better suited for modern large repositories compared to the 2006-era "gc" strategy. The documentation is updated to reflect the new default and clarify the tradeoffs between strategies.

This change comes after extensive test infrastructure updates in the previous 7 patches to ensure the test suite works reliably with the new and old strategies. The series has received positive feedback from Derrick Stolee (who designed the geometric repacking approach) and careful test reviews from Justin Tobler. The technical consensus appears solid, with the main outstanding item being documentation updates to explain the new default behavior.
