This is a refactoring patch in Taylor Blau's ongoing series to implement `git multi-pack-index compact` functionality. As patch 14/17 in the third iteration, it factors out fanout layer handling from `compute_sorted_entries()` into a new `midx_fanout_add()` helper function.

The change improves code organization by separating the logic for adding objects from different sources (existing MIDX files and individual packfiles) into a dedicated function. This prepares the codebase for the upcoming compaction feature, where the fanout handling will need to work differently during compaction operations.

The patch is a straightforward extraction with no behavior changes - it simply moves existing code into a new function and calls it from the original location. This follows the series' pattern of careful refactoring to support the new compaction feature while maintaining existing functionality. The change is well-contained and clearly motivated by the need to keep `compute_sorted_entries()` readable as more complexity is added for compaction support.
