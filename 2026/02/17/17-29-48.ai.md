This is the third and final patch in Shreyansh Paliwal's v4 series eliminating `the_repository` and `the_hash_algo` globals from `wt-status.c`, part of the ongoing `the_repository` removal effort. The patch focuses on replacing remaining uses of `the_hash_algo` with the hash algorithm from the local repository instance (`r->hash_algo` or `s->repo->hash_algo`).

The changes are mechanical but important for consistency - three instances where hash algorithm access is converted from global to repository-specific:
1. Two calls to `null_oid()` during cherry-pick/revert state tracking
2. One lookup of the empty tree for detached HEAD checks

This completes the series' goal of removing global state dependencies from `wt-status.c`, following the same incremental pattern seen in patches 1-2. The changes maintain identical behavior while better aligning with the project's direction toward explicit repository passing. 

The patch demonstrates the straightforward nature of these final conversions - each is a direct substitution where the repository context is already available. This leaves no remaining `the_hash_algo` uses in the file, marking successful completion of this phase of the status subsystem's modernization. The work fits cleanly into the broader `the_repository` removal effort while avoiding entanglement with the parallel worktree API standardization discussions noted in the thread.
