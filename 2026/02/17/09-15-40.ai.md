This is a refactoring patch in the ongoing ref backend selection series, specifically addressing a redundant repository modification in `create_reference_database()`. The patch removes an unnecessary call to `repo_set_ref_storage_format()` that was duplicating work already done by the callers (`git-init` and `git-clone`). Karthik Nayak points out this could cause issues if the format structure grows to include dynamically allocated strings, as it would trigger pointless reallocation. Patrick Steinhardt confirms the simplification is correct, noting the format is already handled by `repository_format_configure()` in `init_db()` and directly set in `clone.c`. The change is straightforward - just dropping the now-unused parameter from the function signature and its two call sites. This is a minor but clean improvement to the series' internal plumbing as it nears finalization.
