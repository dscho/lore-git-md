The thread has progressed through several rounds of review with Christian Couder, Junio Hamano, and Torsten Bögershausen, reaching consensus on the technical approach.

The technical context remains that Windows/MSVC environments may have libiconv linked into Git but lack the `iconv(1)` executable needed by some tests. The series handles this by making tests work with either the executable or falling back to default UTF-8 behavior. Torsten Bögershausen had raised whether Git for Windows should restore the `iconv(1)` binary, but the current solution avoids requiring this change. The only remaining loose end is documenting the relationship between build-time NO_ICONV and test-time ICONV prerequisites, which may be deferred to a follow-up.
