Test infrastructure patch from Patrick Steinhardt addressing iconv-related test failures in t6006-rev-list-format.sh, part of a series improving Windows/MSVC CI reliability. This fourth patch modifies two tests in t6006 that previously assumed the `iconv(1)` executable would be available when testing commit message encoding. The changes make the tests fall back to UTF-8 when the ICONV prerequisite isn't met, matching the pattern established in earlier patches of the series.

The patch restructures the test setup to:
1. Move the message generation into a test_expect_success block
2. Conditionally use iconv only when the ICONV prerequisite is satisfied
3. Fall back to plain UTF-8 output when iconv isn't available
4. Apply the same conditional logic to the expected output file generation

This follows the same approach as the previous patches in the series, maintaining consistency in how tests handle the iconv availability. The changes are straightforward and well-contained, affecting only the test file's encoding-related portions while preserving all test assertions.
