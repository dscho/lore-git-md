Tian Yuchen is exploring a Google Summer of Code (GSoC) project focused on reducing Git's global state by converting functions that implicitly use `the_repository` to instead take explicit `struct repository *` parameters. This connects to René Scharfe's long-term effort to eliminate implicit global state in Git. Yuchen has already demonstrated preparation by submitting a v4 patch handling FIFO in `setup.c`, one of the candidate subsystems for the project.

Karthik Nayak provided initial guidance, confirming the project scope is appropriately bounded but noting there's no strict priority order among the candidate subsystems (`setup.c`, `environment.c`, and `config.c`). He suggested examining last year's related patches for patterns, particularly as `setup.c` presents significant complexity due to tight coupling. Yuchen has acknowledged this feedback, recognizing that `setup.c` may be too ambitious as a primary target and committing to study prior work.

The discussion remains open for input from other mentors copied on the thread (Christian Couder, Justin Tobler, and others), with key questions still to resolve: which subsystem offers the best balance of impact and achievability within the GSoC timeline, and whether any area has blocking factors that make it more urgent. Yuchen is engaging thoughtfully with the feedback while keeping technical direction flexible for further community input.
