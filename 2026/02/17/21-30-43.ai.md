This is a documentation and test improvement patch addressing behavior of `git format-patch`'s `--from` option in cover letters. The thread began with Patrick Steinhardt noting that the man page wording could be interpreted as applying `--from` only to individual commit emails, not cover letters. The current patch author (Mirko Faina) agrees this is unintentional and will update the documentation to clarify.

The patch also incorporates Patrick's suggested test improvement - rather than testing both the cover letter and a patch in one assertion, it now specifically checks just the cover letter's From header. This makes the test more precise and avoids potential false negatives. The change appears straightforward and uncontroversial, with clear agreement between the participants about both the documentation ambiguity and the testing approach.

For future reference in this thread: the change affects `builtin/log.c` (where format-patch is implemented) and `t/t4014-format-patch.sh` (the test file). The key behavior being standardized is that `--from` applies consistently to both cover letters and individual patches in a series. The documentation update will remove any implication that cover letters might be treated differently.
