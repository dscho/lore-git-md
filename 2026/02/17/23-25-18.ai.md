This is a bugfix for `git format-patch`'s handling of the `--from` option in cover letters. The patch addresses an inconsistency where `--from` was respected for individual patches but ignored for cover letters, causing them to use the committer's identity instead.

The fix modifies `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value before falling back to default committer info. The variable is renamed from `committer` to `from` to better reflect its purpose. Documentation is updated to explicitly state that `--from` applies to both patches and cover letters, and a new test case in t4014-format-patch.sh verifies the fixed behavior.

The patch has gone through multiple iterations (now at v4) with review from Junio Hamano, Patrick Steinhardt, and Jeff King. The technical implementation was approved in v2, with v3 and v4 addressing minor documentation and version marking issues. While there are some related documentation improvements suggested for future work, this specific fix is considered ready to merge.

The change is small (6 lines modified) and focused, with clear test coverage. It maintains backward compatibility while fixing the inconsistency that has existed since the `--from` option was introduced in commit a9080475 (2013). The patch demonstrates good attention to detail with both code and documentation updates, and follows Git's standard practices for bugfix contributions.
