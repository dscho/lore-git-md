This is the fourth and final patch in Patrick Steinhardt's series addressing test failures related to `iconv(1)` availability on Windows/MSVC platforms. The patch fixes two tests in t6006-rev-list-format.sh that were unconditionally using the `iconv` executable without checking the ICONV prerequisite.

The changes make the tests more robust by:
1. Only using `iconv` when the ICONV prerequisite is met (checked via `test_have_prereq`)
2. Falling back to UTF-8 encoding when ICONV is not available
3. Properly handling the test setup and expected output files in both cases

This completes the series' goal of making the test suite work correctly when Git is built with ICONV support (using libiconv) but the `iconv(1)` executable isn't available - a scenario that occurs on Windows/MSVC platforms. The patch follows the same pattern established in earlier patches of the series, maintaining consistency in how ICONV-related tests are handled across the codebase.

With all review feedback addressed in v2, this appears ready for merging as part of the overall CI/test infrastructure improvements for Windows platforms.
