This is a translation (l10n) patch fixing a German localization error in the `color-moved-ws` configuration option. The patch corrects a misspelling of "allow-indentation-change" in the German translation file (po/de.po), where it was previously rendered as "allow-identation-change".

The error created a frustrating user experience where Git would suggest the misspelled mode in its error message, and when users copied that suggestion, Git would reject it again with the same incorrect suggestion. The patch simply fixes the spelling to match the English source text.

Junio C Hamano is forwarding this patch to Jiang Xin, Git's i18n coordinator, for inclusion. The patch is straightforward - it changes one line in the German translation file to correct the typo. This appears to be a standalone fix from Matthias Schwarzott, a Gentoo contributor who has previously submitted similar translation corrections. The change is uncontroversial and clearly corrects an error in the existing translation.
