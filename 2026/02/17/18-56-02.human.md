This is a translation (l10n) patch fixing a German localization error in the `color-moved-ws` configuration option. The patch corrects a misspelling of "allow-indentation-change" in the German translation file (po/de.po), where it was previously rendered as "allow-identation-change".

The error created a frustrating user experience - when Git suggested valid modes for `color-moved-ws` in error messages, the suggestion itself contained the typo. This meant users copying the suggested mode would hit the same error again in an infinite loop. The patch simply fixes the spelling to match the English source text.

Junio C Hamano is forwarding the patch (originally submitted by Matthias Schwarzott, a Gentoo contributor) to Jiang Xin, Git's i18n coordinator, for inclusion. This appears to be a straightforward, uncontroversial fix that should be quickly merged. The change is minimal (a single character correction) and clearly improves the user experience for German-speaking Git users.
