This is a bugfix for `git format-patch`'s handling of the `--from` option in cover letters. The patch addresses an inconsistency where `--from` was respected for individual patch emails but ignored for cover letters, which would always use the committer's identity instead.

The fix modifies `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value before falling back to the committer info. The variable is renamed from `committer` to `from` to better reflect its purpose. A new test case in t4014-format-patch.sh verifies the corrected behavior while maintaining existing functionality.

The documentation is updated to clarify that `--from` applies to both patches and cover letters. The change is small (6 lines modified) and focused, with reviewers having confirmed the technical soundness. Junio Hamano provided historical context about the original 2013 implementation that didn't consider cover letters, and suggested some follow-up improvements to the cover letter format.

This appears ready for merging after the final documentation updates, with the remaining discussion points (documentation consistency and cover letter format improvements) noted as potential future work. The patch cleanly addresses the core issue while maintaining backward compatibility.
