This is a refactoring patch in the final stages of the reference storage backend selection series, which enables zero-downtime migrations between files and reftable backends. The patch removes an unnecessary side effect in `create_reference_database()` where it was redundantly setting the repository's ref storage format. Karthik Nayak points out this was either duplicating work (in git-init) or pointlessly re-setting the same value (in git-clone). Patrick Steinhardt reviews and approves the change, noting it simplifies the code without changing behavior.

The change is part of a larger effort that has already received maintainer approval from Junio Hamano and addresses feedback from multiple reviewers. This particular patch is a clean-up that removes a confusing redundancy while maintaining all existing functionality. The series as a whole is nearing completion with comprehensive test coverage and all major technical concerns resolved.
