This is a refactoring patch in the final stages of the reference storage backend selection series, which enables zero-downtime migrations between files and reftable backends. The patch moves stub creation and deletion logic for reference directories into the generic layer, making it available to all backends except the files backend (which handles stubs differently).

The changes are relatively small and focused, continuing the pattern of careful refactoring seen throughout this series. With maintainer approval already secured and the broader technical concerns resolved, this appears to be one of the final polishing steps before the feature can graduate to the 'next' branch.
