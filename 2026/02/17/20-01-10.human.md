This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically focusing on fixing zsh completion for subsection-style aliases (like `[alias "förgrena"]`). The patch adds a new `--aliases-for-completion` option to `git help` that properly handles both traditional and subsection alias formats, outputting NUL-separated name/value pairs for zsh completion scripts.

The change addresses a discrepancy where zsh completion was incorrectly handling subsection aliases by not properly parsing the "alias.name.command" format. While bash completion already worked correctly through `git --list-cmds=alias`, zsh needed both the alias name and value for descriptive completion, requiring this new plumbing interface.

Junio Hamano notes the patch looks good but is missing a sign-off line. He also observes that a future cleanup could potentially unify the bash and zsh completion approaches, though that would be a separate effort. The patch represents the last piece needed to fully support UTF-8 in Git config subsections, completing a series that has gone through five iterations with input from multiple reviewers.
