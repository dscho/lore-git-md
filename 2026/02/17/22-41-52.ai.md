This is a bugfix for `git format-patch`'s handling of the `--from` option in cover letters. The patch addresses an inconsistency where the `--from` option (which specifies an alternative sender identity) was being respected for individual patches but ignored for cover letters, causing mismatched sender identities in multi-patch series.

The fix modifies `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value before falling back to default committer info, and renames a variable from `committer` to `from` to better reflect its purpose. Documentation is updated to clarify that `--from` applies to both patches and cover letters, and a new test case in t4014-format-patch.sh verifies the corrected behavior.

Junio Hamano notes that the code changes look good and approves the test approach, while suggesting the commit message could better highlight that this behavior has been broken since the `--from` option was introduced (commit a9080475 in 2013). The patch appears ready for merging after addressing this minor documentation point, with Junio also noting two potential follow-up improvements: updating the cover letter patch listing format and ensuring consistent documentation across related commands.
