This is a bugfix for `git format-patch` that ensures the `--from` option is properly respected in cover letters, not just individual patches. The patch comes from Mirko Faina and has gone through several iterations with review feedback from Junio Hamano, Patrick Steinhardt, and Jeff King.

The core issue was that while `--from` correctly set the sender identity for individual emails in a patch series, it was being ignored for the cover letter, which would instead use the committer's identity. The fix modifies `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value before falling back to default committer info, and includes a test case to verify the behavior.

Junio notes in his review that the changes look good, though he suggests the commit message could better highlight that this inconsistency has existed since the `--from` option was first introduced. The documentation has also been updated to clarify that `--from` applies to all emails generated by `format-patch`, including cover letters.

This appears to be a straightforward and well-tested fix for a long-standing inconsistency. The patch is in its third version with all prior technical feedback addressed, and Junio's review suggests it's ready for merging. He does note some potential follow-up work around improving the patch listing format in cover letters, but considers those separate from this bugfix.
