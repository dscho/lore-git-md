This is a test infrastructure series addressing CI failures on Windows/MSVC platforms related to `iconv(1)` availability. Patrick Steinhardt has been working through feedback from multiple reviewers, with Christian Couder being the latest to suggest improvements to the documentation around the relationship between the build-time `NO_ICONV` flag and test-time `ICONV` prerequisite.

The core issue stems from Windows environments where Git is built with ICONV support (linking against libiconv) but lacks the `iconv(1)` executable needed by some tests. The series modifies test expectations to handle this case gracefully while maintaining test coverage where possible. Christian noted that while the changes affect the relationship between build configuration and test prerequisites, the Makefile documentation wasn't updated to reflect this.

Patrick agrees with the need for better documentation and plans to address it in the test library rather than the Makefile, expanding the explanation of the `ICONV` prerequisite to cover the new semantics. This follows earlier rounds of feedback where Junio Hamano and Torsten Bögershausen provided Windows-specific context and suggestions about test behavior.

The series appears ready for merging once this final documentation improvement is made. It's part of ongoing work to make Git's test suite more robust across different platforms and build configurations, particularly for Windows/MSVC environments where tool availability differs from traditional Unix-like systems.
