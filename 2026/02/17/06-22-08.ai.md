Bugfix for `git format-patch` cover letter generation regarding `--from` option handling.

This email from Patrick Steinhardt provides review feedback on Mirko Faina's v2 patch fixing the `--from` option behavior in `git format-patch`. The core issue is that while `--from` correctly sets the sender identity for individual patches, it was being ignored for cover letters. The v2 version has addressed all previous maintainer feedback with improved variable naming, commit message, and test coverage.

Patrick confirms the technical correctness of the changes to `builtin/log.c` where the cover letter generation now properly respects the configured `from` value. However, he raises a documentation concern - the man page currently states `--from` applies to "each commit email", which could be read as intentionally excluding cover letters. While Patrick sees no reason for this limitation, he suggests updating the documentation to clarify.

The review also includes a suggested improvement to the test case. Rather than checking all patches in one output, Patrick proposes testing just the cover letter file separately for clearer verification. This would make the test more focused and easier to maintain.

The patch appears ready for merging pending any additional feedback, with all substantive technical concerns from the initial review having been addressed. The remaining discussion points are minor documentation wording and test structure refinements. This represents the final polishing stage before the fix can be integrated.
