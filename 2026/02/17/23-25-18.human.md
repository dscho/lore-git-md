Bugfix for `git format-patch` cover letter generation regarding the `--from` option. This patch fixes an inconsistency where the `--from` option (which specifies an alternative sender identity) was being respected for individual patches but ignored for cover letters, causing mismatched sender identities in multi-patch series.

The fix modifies `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value before falling back to the default committer info. The variable is renamed from `committer` to `from` to better reflect its purpose. Documentation is updated to explicitly state that `--from` applies to both patches and cover letters, and a new test case verifies the corrected behavior.

This is the fourth iteration of the patch, now approved by Junio Hamano for merging after addressing all technical feedback. The change remains small (6 lines modified) and focused. While there are some related documentation improvements suggested for future work, they are not blockers for this fix. The patch has consensus from reviewers including Patrick Steinhardt and Jeff King, who confirmed its technical soundness.
