This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically focusing on fixing zsh completion for subsection-style aliases (like `[alias "förgrena"]`). The patch addresses a remaining edge case where zsh completion wasn't properly handling the subsection syntax, completing the full "name.command" instead of just the alias name.

The solution introduces a new hidden `--aliases-for-completion` option to `git help`, following the pattern of existing completion helpers. This outputs NUL-separated name/value pairs using the already-implemented `list_aliases()` function, which correctly handles both traditional and subsection alias formats. The zsh completion script is updated to use this new interface.

Junio Hamano notes the patch is missing a Signed-off-by line but otherwise appears ready, observing that while a follow-up could potentially unify bash and zsh completion approaches, that would be a separate effort. The implementation builds on prior work in the series that consolidated alias listing and added UTF-8 support, with all technical issues now resolved across the four commits.

This patch completes the feature by ensuring shell completion works correctly with the new UTF-8 subsection aliases, maintaining consistency with the bash implementation while accommodating zsh's need for both names and values in its descriptive completion system. The series as a whole has received positive reviews and appears merge-ready.
