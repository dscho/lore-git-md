This is a test infrastructure patch series addressing CI failures on Windows/MSVC platforms related to `iconv(1)` availability. The thread has reached consensus on Patrick Steinhardt's approach of modifying test expectations rather than skipping tests when the `iconv(1)` executable is unavailable.

The series is now in its final polishing stage, with only minor documentation and reference updates remaining before likely merge. Christian Couder pointed out a typo in the cover letter (which Patrick acknowledges but notes is minor for a cover letter) and suggested referencing GitHub issue #6083 about `iconv(1)` in Git for Windows, which Patrick agrees to include.

The discussion has clarified the distinction between libiconv (linked into Git) and the `iconv(1)` executable (used in scripts), particularly relevant for Windows/MSVC environments. While the technical approach is settled, there remains some discussion about whether Git for Windows should restore the `iconv(1)` binary to simplify test assumptions, as suggested by Torsten Bögershausen.

This work is part of ongoing CI/test infrastructure improvements for Windows/MSVC platforms and builds on existing ICONV prerequisite infrastructure. The series appears well-vetted at this point, with feedback from multiple contributors including Junio Hamano incorporated.
