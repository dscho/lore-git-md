This is the third patch in a four-part series addressing test failures related to `iconv(1)` availability on Windows/MSVC platforms when Git is built with ICONV support. The series has already incorporated all previous review comments and is now in its second version.

The patch focuses on `t5550-http-fetch-dumb.sh`, which contains tests that verify HTTP error message handling. Several of these tests use `"$HTTPD_URL/error"` endpoints that rely on the `iconv(1)` executable to reencode error messages. Since this executable may not be present (particularly on Windows/MSVC platforms), the patch adds the ICONV prerequisite to these tests to prevent failures when the tool is unavailable.

Key changes include:
- Adding ICONV prerequisite to four tests that depend on error message reencoding
- Converting raw `grep` calls to use the `test_grep` helper for consistency
- Maintaining existing behavior where tests will be skipped rather than fail when iconv(1) is missing

This is part of a broader effort to make Git's test suite more robust across platforms, particularly addressing Windows/MSVC CI failures. The patch series has already addressed all review feedback and appears ready for merging.
