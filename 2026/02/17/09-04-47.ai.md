This is a performance improvement patch in Derrick Stolee's series to make `git config list --type=<X>` filtering more efficient. The patch implements type-based filtering during initial config parsing rather than after full parsing, addressing a performance bottleneck that particularly affected git-credential-manager with path-type config values.

The key change in this specific patch is modifying `show_all_config()` to use the new `format_config()` infrastructure, which allows early filtering by type. When listing multiple values, it ensures proper output formatting by initializing key display and delimiters. The patch maintains the behavior of silently skipping rows that fail type parsing.

Patrick Steinhardt's review suggests documenting the error-handling rationale in the commit message and notes the choice between `fwrite()` and `puts()` for output is likely inconsequential for performance. The implementation follows the established pattern from earlier patches in the series, with type-specific formatting handled consistently across the codebase.

This patch represents the third of thirteen in a well-reviewed series where all major design questions have been resolved. The changes are focused and mechanical, building on the infrastructure established in previous patches while maintaining backward compatibility.
