This is a bugfix for `git format-patch`'s handling of the `--from` option in cover letters, now in its third iteration. The patch corrects an inconsistency where `--from` was respected for individual patches but not for cover letters in a series. The fix is small and focused, modifying `make_cover_letter()` in `builtin/log.c` to properly check the configured `from` value.

The patch has already received thorough review from multiple contributors, including Patrick Steinhardt and Jeff King, with Junio Hamano approving the technical implementation. All feedback from previous versions has been addressed, and the addition of a test case in t4014-format-patch.sh verifies the corrected behavior. The only remaining tweak requested is a minor clarification in the commit message about historical context (the bug dates back to 2013).

While the core fix is ready for merging, Junio notes two potential follow-up improvements: updating the cover letter patch listing format and ensuring consistent documentation across related commands. These don't block the current patch, which cleanly resolves the immediate issue. The patch represents a straightforward correction to email generation behavior that will make `--from` work consistently across all parts of a patch series.
