This is a platform compatibility patch in Matthew John Cheetham's series to extend Git's TRACE2 process ancestry tracing to macOS. The patch adds build system support for the new macOS implementation by including `compat/darwin/procinfo.c` in the compilation for Darwin systems across all three build systems (Make, CMake, and Meson). 

Junio Hamano notes that while one could argue for combining this with the implementation patch (since the file would be unused until then), keeping them separate allows build system experts to review this portion independently from the macOS-specific code. The changes are straightforward additions to each build system's configuration, following the existing pattern for Linux and Windows implementations.

This is part of the larger effort to unify process ancestry tracing across platforms, with the implementation details handled in subsequent patches. The series has Junio's ack and appears ready for merging, with this patch serving as the necessary build infrastructure groundwork.
