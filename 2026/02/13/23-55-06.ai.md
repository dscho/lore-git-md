This is the first patch in Derrick Stolee's 13-part series improving `git config list --type=<X>` performance. It's a pure refactoring change that moves the `show_all_config()` function lower in `builtin/config.c` to prepare for using `format_config()` in a future patch. The function itself remains unchanged - this is just repositioning code to enable cleaner diffs in subsequent patches.

The change is mechanical and straightforward, moving 24 lines of code down in the file while maintaining all functionality. This kind of preparatory refactoring is common in larger series to make later changes more focused and reviewable. The patch touches only `builtin/config.c` and has no behavioral impact yet - that will come in later patches that build on this foundation.

As the thread summary notes, this series ultimately aims to improve performance by filtering config values by type during parsing rather than after, particularly benefiting path-type config values that were causing bottlenecks in git-credential-manager. This first patch is just setting up the scaffolding for those more substantive changes to come.
