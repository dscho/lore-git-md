This is the final patch in Abraham Samuel Adekunle's series adding `--no-auto-advance` functionality to Git's interactive patch commands (`add -p`, `checkout -p`, etc.). The patch implements inter-file navigation and hunk summary display when auto-advance is disabled.

The key additions are:
- '>' and '<' navigation between files when `--no-auto-advance` is active
- A hunk summary showing totals (Hunks: X, USE: Y, SKIP: Z) when all hunks in a file are decided
- Persistence of hunk decisions when moving between files, allowing users to revisit and modify choices
- The patch maintains backward compatibility by keeping auto-advance as the default behavior
- Includes comprehensive tests covering navigation, decision persistence, and summary display

The implementation builds on the refactoring from earlier patches in the series, particularly the extracted `apply_patch()` function from patch 3/4. The changes are focused in `add-patch.c` with corresponding test additions in `t3701-add-interactive.sh`.

This completes the series' goal of giving users finer control during multi-file interactive sessions while maintaining the familiar default workflow. The patch appears well-tested and thoughtfully integrated with the existing interactive patch machinery.
