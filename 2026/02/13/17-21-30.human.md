Documentation patch for the `git history` command's `--update-refs` option. This is the fifth and final patch in Patrick Steinhardt's v2 series improving the UI of the new `git history` command.

The patch adds a simple but important clarification to the man page, explicitly stating that the `--update-refs` option defaults to updating all local branches (`branches`) when no value is specified. This completes the documentation improvements in the series, which has already addressed early validation checks, clearer flag naming (replacing `--ref-action` with `--dry-run` and `--update-refs`), and other UI refinements.

Junio Hamano acknowledges the change with a brief but positive response ("Good to see the default clearly described"), indicating this likely concludes the review process for the series. With all prior feedback addressed and no outstanding concerns, the series appears ready for potential inclusion in the next integration window.
