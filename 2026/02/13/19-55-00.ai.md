This is the final patch in a 6-part series adding macOS support for Git's TRACE2 process ancestry tracing, now including comprehensive test coverage. The series has been acked by Junio Hamano after expanding from 4 to v6 patches in the latest revision.

The patch introduces a new test script `t0213-trace2-ancestry.sh` that verifies `cmd_ancestry` events work correctly across all three TRACE2 output formats (normal, perf, and event). It uses a new "400ancestry" test helper to create controlled process trees through Git alias resolution, then filters the output to focus only on the relevant portion of the ancestry chain. The tests handle platform-specific cases like Windows' extra "sh.exe" layer when running without bin-wrappers.

Key technical aspects include runtime detection of ancestry support (skipping tests on platforms with only the stub implementation), format-specific filtering functions that normalize output for comparison, and careful handling of the test environment to ensure reliable results. The test cases verify both simple 2-level chains (Git alias resolution) and deeper 3-level chains (using test-tool's 004child helper).

This completes the cross-platform TRACE2 ancestry tracing implementation by providing the same test coverage on macOS that Linux and Windows already have. The test infrastructure will help maintain consistency as the feature evolves. The patch also updates an existing test comment to direct ancestry testing to this new dedicated script.
