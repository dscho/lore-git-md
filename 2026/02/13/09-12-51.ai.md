This is the fifth and final patch in Patrick Steinhardt's v2 series improving the `git history` command's UI. It's a documentation patch that clarifies the default behavior of the `--update-refs` option.

The patch adds a single line to the man page specifying that when `--update-refs` is used without a value, it defaults to updating all local branches (`branches` mode) rather than just the current `HEAD`. This completes the series' goal of making the command's behavior more transparent and user-friendly.

The change is straightforward and uncontroversial, building on the previous patches that renamed and restructured these options. It addresses a minor documentation gap that was likely noticed during the earlier review process. With this addition, the man page now fully documents all default behaviors for the command's flags.

This patch appears ready for merging as part of the complete series, which has already addressed all reviewer feedback from v1. The documentation change is consistent with the implementation and helps users understand the command's behavior without needing to read the source code.
