This is a clarification from the maintainer about Git's date parsing behavior. Junio C Hamano confirms that the current behavior of `--since` (where date-only inputs default to the current local time rather than midnight) is intentional, not a bug. He points to a 2005 email thread where this design was discussed and established.

The response settles the open question from the original bug report, indicating this is working as designed rather than something needing to be fixed. This aligns with Git's historical behavior and means any change would need to be justified as an intentional backward-incompatible change rather than a bugfix.

For future reference, the key detail is that `approxidate_careful()` and related date parsing functions in `date.c` were explicitly designed this way from early in Git's history. The thread reference (Pine.LNX.4.64.0511171505080.13959@g5.osdl.org) provides the original design context for anyone wanting to understand the rationale.
