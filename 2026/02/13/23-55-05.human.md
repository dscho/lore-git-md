This is a performance-focused series by Derrick Stolee that implements type-aware filtering for `git config list --type=<X>`, fixing what was previously broken behavior where the `--type` option was ignored. The series has evolved from RFC to implementation based on positive feedback.

The core improvement allows `git config list` to filter values by type during parsing rather than after, which is particularly beneficial for path-type values that previously required expensive full parsing. The implementation builds on existing `--type` functionality from `git config get`, extending it to the `list` operation with performance optimizations.

The 13-patch series follows an incremental approach:
1. Moves and refactors `show_all_config()` for code reuse
2. Adds gentle parsing infrastructure to avoid dying on parse errors
3. Implements the actual type filtering for `git config list`
4. Adds gentle parsing variants for various types (int64, bool, path, color, etc.)
5. Restructures the formatting logic for clarity

The changes touch `builtin/config.c`, `config.c`, `parse.c`, and add comprehensive tests in `t/t1300-config.sh`. Performance testing shows measurable improvements, particularly for git-credential-manager use cases that motivated the work.

The series is now in its final polishing stage, with only minor documentation updates remaining before merging. Patrick Steinhardt has approved the implementation direction, and Junio Hamano's earlier concerns have been addressed. The changes are framed as fixing broken behavior rather than introducing new features.
