Performance optimization patch for Linux file copying in Git.

This patch introduces a Linux-specific optimization to `copy.c` that uses the `sendfile()` system call for copying data between file descriptors, replacing the existing read/write loop. The `sendfile()` approach performs the copy entirely in kernel space, avoiding unnecessary user-space buffer copies. The change is guarded by `#ifdef __linux__` to maintain portability, falling back to the existing implementation on other platforms.

The implementation handles the file copy in a single system call when possible, though it still includes a loop to handle partial writes (despite `sendfile()` typically copying the entire file in one operation on modern kernels). The patch includes proper error handling through the existing `COPY_WRITE_ERROR` return value.

This appears to be a straightforward performance optimization targeting a common operation (file copying) in Git's internals. The change is narrowly scoped and maintains compatibility with non-Linux systems. The commit message could benefit from benchmark numbers showing the performance improvement, but the technical approach seems sound. The patch is small and focused, touching only the copy functionality without introducing broader architectural implications.
