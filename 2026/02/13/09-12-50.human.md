This is the fourth patch in Patrick Steinhardt's v2 series improving the `git history` command's interface. Following the previous patch's change to make `--ref-action` only control which refs are updated (rather than the action itself), this patch renames the option to `--update-refs` to better reflect its purpose.

The change is straightforward and mechanical, updating the option name in three places: the documentation, the command's usage string, and the test suite. The patch maintains all existing functionality while making the interface more intuitive - a clear improvement from the more technical-sounding `--ref-action` name.

This continues the series' theme of improving user experience by making the command's options more self-explanatory. The change is well-contained and builds logically on the previous patches in the series. With this rename, the command's interface better matches its actual behavior after the refactoring done earlier in the series.
