This is a contributor housekeeping patch that updates Git's template files to properly handle sample hook scripts. Phillip Wood makes two small but sensible changes:

1. Adds a `.gitattributes` entry for the sample hook files (which end in `.sample`) to ensure they are treated consistently with other shell scripts - preserving whitespace and using LF line endings.

2. Updates `.editorconfig` to include these same files, ensuring they follow Git's standard tab-based indentation style (8-character tabs) when edited.

The changes are straightforward and uncontroversial, aligning with Git's existing conventions for shell scripts. This is part of the ongoing effort to maintain consistency across Git's template and configuration files. The patch is cleanly separated from the security-focused hook work happening in parallel in this thread.
