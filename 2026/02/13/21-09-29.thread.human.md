This thread clarified Git's behavior when parsing date-only inputs for operations like `--since`. When given just a date (without a time component), Git defaults to the current local time rather than midnight (00:00:00), which surprised the original reporter, Gregor. 

Maintainer Junio C Hamano confirmed this is intentional behavior dating back to Git's earliest days, referencing a 2005 email from Linus Torvalds that established this precedent. The design rationale is practical: using the current time makes common queries like "what changed in the last 24 hours" more convenient, while users who specifically need midnight can explicitly specify the time component. 

The discussion revealed this is a longstanding design choice rather than a bug, though Junio acknowledged the midnight interpretation would also be technically valid. No code changes are planned, but the thread serves as useful documentation of this edge case for future reference. Scripts using date-only inputs should account for the current-time behavior or explicitly specify times when needed.
