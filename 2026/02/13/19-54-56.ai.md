This is a build system patch in a series adding macOS support for Git's TRACE2 process ancestry tracing. It's the second of six patches in v2 of the series, which has already received Junio's ack.

The patch adds the new macOS implementation (`compat/darwin/procinfo.c`) to all three build systems (Makefile, CMake, and Meson). It follows the same pattern as the existing Linux and Windows implementations, with the new file being conditionally included when building on Darwin (macOS). The changes are straightforward additions to the build configuration files, with no behavior changes or new functionality introduced in this patch itself.

The implementation being added here (shown in later patches) uses macOS's `sysctl` with `KERN_PROC` to gather process ancestry information, matching the depth limit (10 levels) and output format of the existing Linux implementation. This continues the series' goal of unified cross-platform tracing while maintaining backward compatibility.
