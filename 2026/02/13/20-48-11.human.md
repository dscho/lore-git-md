This is a follow-up to a bugfix patch series addressing shallow repository issues, now in its fourth iteration. The second patch in the series implements correct relative-depth fetching (`--deepen`) by introducing a new `get_shallows_depth()` function that properly handles both absolute and relative depth calculations.

Patrick Steinhardt's review identifies several implementation refinements needed for the v4 patch:
- Code style improvements (inline loop variable declarations, removing unnecessary braces)
- Behavioral inconsistencies when the `shallows` parameter is provided
- Suggested inlining of `get_shallows_depth()` into its single caller
- Redundant calls to `get_shallow_commits()` that could be consolidated

The author, Samo Pogačnik, acknowledges the feedback and indicates plans to address these points in a future version. The core algorithm has already been vetted through multiple rounds of review from Patrick Steinhardt, Junio C Hamano, and Kristoffer Haugsbakk, with all previous technical and documentation concerns having been addressed.

This appears to be the final round of polish needed before the patch can be merged, solving both memory leaks and edge cases in shallow repository handling while maintaining backward compatibility. The thread demonstrates productive collaboration between the author and reviewers across four iterations.
