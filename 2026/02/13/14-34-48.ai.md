Housekeeping patch for Git's sample hooks infrastructure. This is a follow-up to Phillip Wood's security-focused commit-msg hook work, though it stands alone as a minor technical improvement.

The patch makes two small but sensible changes to ensure consistent handling of the sample hook files in Git's template directory. First, it adds a `.gitattributes` entry to properly classify the `.sample` files as shell scripts (with LF line endings and whitespace rules), since their extension differs from standard `.sh` files. Second, it updates the `.editorconfig` to apply the same tab-based indentation rules to these files as other shell scripts in the project.

This is a straightforward maintenance change that doesn't affect runtime behavior - it just ensures the sample hooks are treated consistently with the project's coding guidelines during development. The patch is cleanly separated from Wood's more substantive security work on commit message validation, though both touch the hooks infrastructure. Given Wood's track record with subtle hook-related patches and the uncontroversial nature of this change, it's likely to be merged without significant discussion.
