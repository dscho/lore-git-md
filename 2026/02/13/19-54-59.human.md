This is a test infrastructure patch in a 6-part series extending Git's TRACE2 process ancestry tracing to macOS. Patch 5/6 adds a new test helper specifically for verifying ancestry tracing behavior in isolation.

The new `400ancestry` test helper creates a controlled environment where a child process's TRACE2 output (including ancestry events) can be captured without interference from parent process settings. It clears all inherited TRACE2 environment variables in the child and enables only the requested output target (normal/perf/event), directing it to a specified file. This gives tests a predictable way to check ancestry data, since the child will always see "test-tool" as its immediate parent.

The implementation follows the pattern of existing TRACE2 test helpers, adding a new function to `t/helper/test-trace2.c` with clear documentation of its purpose and usage. The helper will be used by `t0213-trace2-ancestry.sh` to verify the cross-platform ancestry tracing behavior introduced earlier in the series.

This patch is part of a well-structured series that has already received maintainer ack from Junio Hamano after addressing review feedback in v2. The test helper is a logical addition that provides the necessary verification capability for the new macOS tracing support while maintaining consistency with the existing test framework.
