This is a platform compatibility patch adding macOS support for Git's TRACE2 process ancestry tracing. It's part of a 6-patch series that extends process tracing to macOS while refactoring the Windows implementation, building on prior work for Linux and Windows.

The patch itself is straightforward build system plumbing - it adds the new `compat/darwin/procinfo.c` file to the build configuration for all three build systems (Make, CMake, and Meson) when compiling on macOS. Junio notes that while the file isn't used until the next patch, this separation makes sense for review purposes.

The series as a whole has already been acked by Junio after incorporating feedback from v1. The macOS implementation uses `sysctl` with `KERN_PROC` to gather process ancestry data, matching the Linux implementation's behavior and format. The Windows implementation was refactored to separate data collection from JSON formatting for better consistency.

This is a well-structured series that completes cross-platform process tracing support, with careful attention to backward compatibility and testing. The patches show good attention to detail across all build systems and platforms.
