Performance optimization for file copying on Linux.

This patch introduces a Linux-specific optimization to `copy.c` that uses the `sendfile()` system call for copying data between file descriptors, replacing the existing read/write loop. The `sendfile()` approach performs the copy entirely in kernel space, which should be more efficient for large files.

The change is straightforward and well-contained, adding a Linux-specific implementation while keeping the original portable version as a fallback. The patch includes proper error handling and maintains the same return value semantics as the existing code.

This appears to be a clean, focused optimization that could provide measurable performance benefits for operations that copy large files (like `git checkout` or `git clone`). The implementation looks correct and maintains compatibility with non-Linux systems.
