This is a feature patch series extending Git's TRACE2 process ancestry tracing to macOS while refactoring the Windows implementation. The series builds on prior work that added ancestry tracing for Linux and Windows, now unifying the approach across all three platforms.

Matthew John Cheetham's 6-patch series adds macOS support using `sysctl` with `KERN_PROC` to recursively gather parent IDs and names, matching Linux's 10-level depth limit. The Windows implementation is refactored to separate data collection from JSON formatting, with dual-emission of both the legacy JSON format and new unified `cmd_ancestry` event for backward compatibility. New tests in t0213 verify the behavior using an extended test helper that can spawn processes with controlled ancestry.

The series has already been acked by Junio Hamano after addressing Derrick Stolee's review feedback. Notable changes in v2 include removing macOS-specific filtering of PID 1/0 to match Linux behavior, adding comprehensive tests, and standardizing commit message references. The implementation maintains cross-platform consistency while preserving compatibility for existing TRACE2 consumers on Windows.

This represents a clean extension of Git's instrumentation capabilities, with particular value for debugging and performance analysis on macOS systems. The careful attention to backward compatibility and test coverage suggests this is production-ready work that should integrate smoothly.
