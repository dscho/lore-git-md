This is a feature patch series introducing a new `--auto-advance` option for interactive patch selection in Git commands like `add -p`, `checkout -p`, and `reset -p`. The series comes from Abraham Samuel Adekunle and is now in its fourth iteration.

The main addition is a `--no-auto-advance` flag that changes how interactive patch selection works. By default (with `--auto-advance`), Git currently moves automatically to the next file after you've made all decisions for the current file's hunks. The new option lets users stay on the current file and navigate between files manually using '>' (next file) and '<' (previous file) commands, which is useful when you want to revisit files after seeing others.

The series also includes some preparatory refactoring: moving the apply logic into a reusable function and changing how `patch_update_file()` takes its parameters. The implementation adds tests to the interactive test file and ensures the new option works across all relevant commands (`add`, `checkout`, `reset`, `stash`).
