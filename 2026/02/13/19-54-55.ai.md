This is the first patch in a 6-part series adding macOS process ancestry tracing to Git's TRACE2 instrumentation, following similar implementations for Windows and Linux. The patch introduces a new `compat/darwin/procinfo.c` that uses macOS's `sysctl` with `KERN_PROC` to recursively gather parent process IDs and names, matching the existing Linux behavior.

The implementation recursively walks the process tree up to 10 levels deep (NR_PIDS_LIMIT) using `push_ancestry_name()`, collecting process names into a strvec that is then emitted via the existing `trace2_cmd_ancestry()` API. Like the Linux version, it skips invalid PIDs and handles cycles by checking for self-referential parent PIDs. The code structure mirrors the Linux implementation's recursive approach rather than the Windows version's iterative one, maintaining cross-platform consistency in the trace output format.

The patch builds on prior work (353d3d77 for Windows, 2f732bf1 for Linux) and is part of a broader effort to unify process tracing across platforms while maintaining backward compatibility. Junio has already acked the technical approach after v2 revisions expanded test coverage and aligned behavior. The macOS implementation fills the last major platform gap in Git's process ancestry tracing capabilities.
