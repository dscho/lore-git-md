This is a test infrastructure patch in Matthew John Cheetham's series to unify TRACE2 process ancestry tracing across platforms. The patch adds a new test helper called "400ancestry" to `test-tool trace2` that creates a controlled environment for testing cmd_ancestry events.

The helper spawns a child process with a clean TRACE2 environment, clearing inherited variables and enabling only the requested output target (normal/perf/event). This isolation ensures tests can reliably capture and verify the child's ancestry data, with "test-tool" predictably appearing as the immediate parent in the process tree. The implementation uses Git's child_process API to manage the environment and command execution.

This is the fifth patch in a 6-part series that has already received Junio's ack after v2 revisions. The test helper will be used by t0213-trace2-ancestry.sh to verify the cross-platform ancestry tracing added in earlier patches. The implementation is straightforward - it builds on existing test-tool patterns and focuses specifically on enabling reliable ancestry verification without side effects from the parent's TRACE2 configuration.
