This is part 3 of a 6-patch series refactoring Git's TRACE2 process ancestry tracing to support macOS while maintaining cross-platform consistency. The series has Junio's ack and is in its second revision.

The patch refactors the Windows implementation of process ancestry tracing to separate the collection of process names from the JSON formatting. Previously, these were intertwined in `get_processes()`, which both gathered parent process names and built a JSON array. Now, process names are collected into a `strvec` first, then formatted into JSON separately. This matches the approach used in the Linux implementation and prepares for future changes where the same ancestry data will be emitted via the newer `cmd_ancestry` event.

Key changes:
- `get_processes()` now takes a `strvec` instead of a JSON writer
- JSON formatting is moved to `trace2_collect_process_info()`
- The same cycle detection and depth limiting (10 levels) remains
- Backward compatibility is maintained by still emitting the old JSON format

This is a clean refactoring that doesn't change behavior but enables the cross-platform unification work in later patches. The commit message clearly explains the motivation and connects it to the broader series goal of consistent ancestry tracing across Linux, Windows, and macOS.
