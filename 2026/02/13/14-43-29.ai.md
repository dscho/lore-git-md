This is a documentation patch concluding the documentation component of the security vulnerability discussion around `git am` patch parsing. Kristoffer Haugsbakk's patch adding explicit warnings about patch roundtrip hazards in `format-patch-caveats.adoc` has now been finalized after review by Phillip Wood and Junio Hamano, and is queued for the `next` branch.

The patch represents one piece of a multi-faceted solution to the long-standing issue where `git am` can misinterpret embedded diffs in commit messages as intended patches. While the technical solutions (including new commit-msg hooks, strict modes, and boundary markers) continue to be developed, this documentation update serves to clearly warn users about the potential hazards when round-tripping patches through email.

The thread shows consensus that this documentation improvement is valuable and complete, with both Phillip Wood and Junio Hamano expressing satisfaction with the final wording. This marks the first completed component of the layered security approach being developed for patch parsing vulnerabilities.
