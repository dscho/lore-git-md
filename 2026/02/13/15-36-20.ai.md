Performance optimization for Linux file copying using sendfile().

This is a follow-up discussion on a patch that would optimize file copying in Git by using Linux's `sendfile()` system call instead of the current read/write loop. The original patch from George Hu proposed using `#ifdef __linux__` to conditionally enable this optimization.

Chris Torek suggests the patch should check for the `sendfile()` feature's availability rather than hardcoding it to Linux, since other systems (notably BSDs) also support this system call. This is a more portable approach that would allow the optimization to work wherever the underlying system provides the functionality, not just on Linux.

The technical discussion remains focused on the implementation details of how to detect and use `sendfile()`, without revisiting the core premise that using it would be beneficial when available. The patch itself was narrowly scoped to the copy functionality in `copy.c`, maintaining the existing error handling and falling back to the current implementation when `sendfile()` isn't available.
