This is part 4 of a 6-patch series extending Git's TRACE2 process ancestry tracing to macOS while refactoring the Windows implementation. The series has been acked by Junio after incorporating feedback from v1.

The current patch focuses on the Windows implementation, ensuring it emits process ancestry data in both the legacy JSON format (for backward compatibility) and the new unified `trace2_cmd_ancestry()` format that matches Linux's behavior. The change is minimal but important - it adds the new event emission while preserving the existing JSON output that some tools may depend on.

The patch maintains careful backward compatibility by keeping the JSON output that was introduced earlier, while adding the new standardized ancestry event. This dual-emission approach follows the project's typical transition strategy for such changes. The implementation is straightforward, just adding a call to `trace2_cmd_ancestry()` after the existing JSON emission.

This is part of a well-structured series that has clearly benefited from prior review, with each patch focused and properly motivated. The changes are small and targeted, making this an easy review for anyone familiar with the TRACE2 subsystem.
