Build system patch for macOS process ancestry tracing. This is part 2 of a 6-part series extending Git's TRACE2 process ancestry tracing to macOS, following similar implementations for Linux and Windows.

The patch adds build system support for the new macOS implementation across all three build systems (Makefile, CMake, and Meson). It introduces a new `compat/darwin/procinfo.c` file that will contain the macOS-specific process information collection code. The changes are straightforward build system additions that mirror how the Linux and Windows implementations are already integrated.

This is a mechanical but necessary step in the series, ensuring the macOS code gets compiled when building on Darwin systems. The patch has already been acked by Junio Hamano in the v2 iteration of this series, indicating it meets the project's technical standards. The actual implementation of the macOS process info collection will come in subsequent patches.
