Platform compatibility patch (Windows process ancestry tracing) in a series that has Junio's ack.

This is the third patch in a 6-part series refactoring Git's TRACE2 process ancestry tracing to work consistently across platforms (Linux, Windows, macOS). The current patch focuses on the Windows implementation, separating the data collection from JSON formatting to prepare for emitting the newer `cmd_ancestry` event format while maintaining backward compatibility.

The changes move the JSON formatting out of the Windows-specific process info collection code and into the generic trace2_collect_process_info() function. The Windows implementation now uses a strvec to collect process names before converting them to JSON, matching the approach used by the Linux implementation. This refactoring enables future patches to reuse the collected process names for both the legacy JSON format and the newer standardized ancestry event.

Junio notes the refactoring is straightforward and easy to follow even without Windows-specific knowledge. The patch maintains all existing behavior while cleaning up the implementation - it still emits the same JSON output via trace2_data_json() but does so through a more modular design. This is part of the broader effort to unify process ancestry tracing across platforms while keeping backward compatibility during the migration period.
