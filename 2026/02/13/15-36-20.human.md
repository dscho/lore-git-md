Performance optimization for Linux file copying using sendfile(). This is a follow-up to George Hu's patch proposing to use Linux's `sendfile()` system call for more efficient file copying between descriptors. Chris Torek suggests broadening the approach to check for `sendfile()` availability rather than hardcoding it to Linux, since other systems (notably BSDs) also support this feature. The original patch was narrowly scoped to `copy.c` with a Linux-specific implementation that falls back to the existing read/write loop.

The discussion is still early, with no technical objections raised yet to the core idea of using `sendfile()`. The main point of feedback so far is about making the change more portable by detecting the feature rather than the OS. This looks like a straightforward optimization that could benefit from being more widely applicable if implemented portably. The patch appears well-structured but would need benchmarking data to quantify the performance gains.
