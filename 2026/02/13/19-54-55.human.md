This is the first patch in a 6-part series adding macOS support for Git's TRACE2 process ancestry tracing, following similar implementations for Windows and Linux. The patch introduces a new `compat/darwin/procinfo.c` that uses macOS's `sysctl` interface with `KERN_PROC` to recursively gather parent process IDs and names, matching the existing Linux behavior.

The implementation:
- Uses a recursive approach with a 10-level depth limit (NR_PIDS_LIMIT)
- Emits the ancestry chain via the existing `trace2_cmd_ancestry()` interface rather than creating a macOS-specific JSON event
- Handles process name collection and parent PID lookup through `get_proc_info()`
- Maintains consistency with Linux version by not filtering PID 1/0

The patch is part of a broader effort to unify process tracing across platforms while maintaining backward compatibility. It has already been acked by maintainer Junio Hamano after v2 revisions that expanded test coverage and aligned behavior. The series appears well-considered, with clear commit messages and careful attention to cross-platform consistency.
