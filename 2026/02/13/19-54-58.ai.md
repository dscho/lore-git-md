This is part 4 of a 6-patch series extending Git's TRACE2 process ancestry tracing to macOS while refactoring the Windows implementation. The series has been acked by Junio Hamano after updates in v2.

This specific patch modifies the Windows implementation to emit process ancestry data using the new standardized `trace2_cmd_ancestry()` event type, while maintaining backward compatibility by continuing to emit the old JSON format. The change ensures Windows process tracing matches the cross-platform format introduced for Linux and now being added for macOS.

The patch adds dual emission - first the legacy JSON format (for existing consumers) followed by the new standardized format. The implementation carefully preserves the existing data collection while adding the new event type, with clear comments explaining the transitional approach. The change is minimal (8 lines added) and focused, touching only the Windows-specific process info file.

This is part of the broader effort to unify process tracing across platforms in Git's TRACE2 instrumentation system. The series as a whole brings macOS support while aligning Windows behavior with the Linux implementation, with this patch specifically handling the Windows event emission transition.
