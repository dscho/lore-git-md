This is a feature patch series extending Git's TRACE2 process ancestry tracing to macOS while refactoring the Windows implementation. The series builds on prior work for Windows (353d3d77) and Linux (2f732bf1) ancestry tracing, now adding macOS support via `sysctl` with `KERN_PROC` to gather parent process IDs and names with a 10-level depth limit matching Linux's format.

The key changes in v2 include: removing macOS-specific filtering of PPID 1/0 to match Linux behavior, adding comprehensive tests in t0213 using a new "400ancestry" test helper, dropping an unused macro, and standardizing commit message references. The Windows implementation is refactored to separate data collection from JSON formatting while maintaining backward compatibility by emitting both legacy and new unified formats.

The series has received maintainer ack from Junio Hamano after addressing Derrick Stolee's review feedback. It introduces a new `compat/darwin/procinfo.c` for macOS support and updates build systems (Makefile, CMake, Meson) accordingly. The tests verify cross-platform consistency in ancestry tracing while accounting for uncontrolled test environment factors.

This represents the final iteration of a well-structured series that carefully maintains compatibility while unifying tracing behavior across platforms. The implementation choices (like keeping recursive process lookup to match Linux) reflect deliberate consistency decisions rather than platform-specific optimizations. The added test coverage and build system integration suggest this is production-ready for merging.
