This is a refactoring patch in a 6-part series that standardizes process ancestry tracing across platforms (Linux, Windows, macOS) via Git's TRACE2 performance tracing system. The patch focuses on the Windows implementation, separating the data collection logic from JSON formatting to prepare for future unification with the newer `cmd_ancestry` event format.

The changes cleanly split the Windows-specific process info gathering (which uses the Windows Toolhelp API) from the JSON serialization, moving the latter to the main `trace2_collect_process_info()` function. This makes the code more maintainable and paves the way for the series' later patches that will introduce cross-platform consistency. The patch maintains backward compatibility by still emitting the legacy JSON format while the transition occurs.
