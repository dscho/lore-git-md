This is a response from the Git maintainer clarifying the behavior of date parsing in `--since` operations. Junio C Hamano confirms that the current behavior - where date-only strings default to the current local time rather than midnight - is intentional, not a bug. He points to a 2005 email thread where this design decision was made, showing this has been Git's behavior since very early in the project.

The response settles the question raised in the original bug report, indicating this is working as designed rather than something that needs fixing. For users and script authors, this means they should be aware that date-only specifications in `--since` will use the current time of day rather than assuming midnight, and should explicitly specify times if they need different behavior.

The thread appears resolved with this authoritative answer from the maintainer, though others could still chime in if they have additional historical context or use cases to discuss. The behavior is now clearly documented as intentional rather than being an undocumented quirk.
