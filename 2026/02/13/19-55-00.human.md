This is the final patch in a 6-part series adding TRACE2 process ancestry tracing support for macOS while refactoring the Windows implementation. The series has been acked by Junio Hamano after incorporating feedback from v1.

The patch adds comprehensive testing for the new cross-platform ancestry tracing functionality. It introduces a new test script `t0213-trace2-ancestry.sh` that verifies `cmd_ancestry` events across all three TRACE2 output formats (normal, perf, and event). The tests use a new "400ancestry" test helper to spawn controlled process trees and filter the ancestry output to focus only on the relevant portions.

Key aspects of the testing approach:
- Handles platform differences (Windows vs Unix paths, bin-wrappers)
- Tests multi-level process trees via Git alias resolution
- Verifies all three TRACE2 output formats consistently
- Includes a runtime check to skip tests on platforms without ancestry support
- Updates related test documentation to point to this new dedicated test

The test design shows careful attention to cross-platform consistency and provides a solid foundation for verifying the ancestry tracing behavior added in the earlier patches. This completes the series by ensuring the new functionality works as intended across all supported platforms.
