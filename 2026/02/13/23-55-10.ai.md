This is patch 5/13 in Derrick Stolee's performance improvement series for `git config list --type=<X>` filtering. The series aims to make type filtering more efficient by skipping full parsing of non-matching values.

The current patch introduces gentle parsing for boolean config values, following the pattern established in earlier patches for other types. It moves the boolean formatting logic into a new `format_config_bool()` helper function that can operate in both strict (die on error) and gentle (skip invalid values) modes. When used with `--type=bool`, non-boolean values are now be quietly filtered out rather than causing the command to fail.

The change is mechanical and consistent with the series' incremental refactoring approach. It includes a test update to verify the new behavior where invalid boolean values are skipped rather than causing errors.
