This is a refactoring patch in a 6-part series that extends Git's TRACE2 process ancestry tracing to macOS while unifying the implementation across platforms. The series has been acked by maintainer Junio Hamano after updates in v2.

The patch refactors the Windows implementation of process ancestry tracing to separate the collection of process names from the JSON formatting. Previously, these were combined in `get_processes()`, which both gathered parent process names and built a JSON array. The new version uses a `strvec` to collect names first, then formats them into JSON separately. This matches the Linux implementation's structure and prepares for adding macOS support in later patches.

The change maintains backward compatibility by still emitting the same JSON format via `trace2_data_json()`, though future work may phase this out. The refactoring is clean and focused, with clear commit messages explaining the motivation. As part of a larger cross-platform effort, this helps ensure consistent ancestry tracing behavior whether Git runs on Windows, Linux, or macOS.
