This is the fourth patch in a five-part test infrastructure series addressing CI failures related to `iconv(1)` availability on Windows/MSVC platforms. The patch focuses on t5550-http-fetch-dumb.sh, which tests HTTP fetch behavior.

The key change is adding ICONV prerequisites to tests that use "$HTTPD_URL/error" endpoints, since these rely on the `t/lib-httpd/error.sh` script which needs the `iconv(1)` executable. The patch makes four tests conditional on ICONV availability and updates them to use `test_grep` instead of raw `grep` for consistency with modern test practices. The changes follow the same pattern established in earlier patches of the series - preserving test functionality while making it conditional on executable availability.

The patch maintains the distinction between libiconv (used by Git itself) and the `iconv(1)` executable (used by test scripts). This is particularly relevant for Windows/MSVC where MinGW no longer ships the `iconv(1)` executable. The changes are straightforward and maintain existing test coverage while making the tests more robust across platforms.
