This is a refactoring patch that consolidates alias listing functionality between `alias.c` and `help.c`. It's the first of four patches in the v6 series implementing UTF-8 support for Git configuration subsections.

The patch removes duplicate alias parsing logic from `help.c` by extending `list_aliases()` in `alias.c` to also store alias values (using the string_list util field). This maintains the existing error checking for value-less alias definitions but moves it to `alias.c`. The change is verified by a new test case that confirms error is properly reported for aliases without values.

Key technical details:
- Modifies `alias.c` to store alias values via string_list util field
- Removes `get_alias()` callback from `help.c` in favor of unified `list_aliases()`
- Preserves error checking for malformed aliases
- Adds test coverage for value-less alias case
- Part of broader UTF-8 subsection support effort

The change is purely internal with no user-facing behavior difference, but it cleans up the codebase by eliminating duplicate logic. The patch has been through multiple iterations and appears ready for merging, with all prior feedback addressed.
