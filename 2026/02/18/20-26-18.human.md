This is a documentation patch that fixes an inaccuracy in the `diff-options.adoc` man page regarding how `git-format-patch` handles prefix configuration. 

Kristoffer Haugsbakk points out that while the documentation currently states `--default-prefix` overrides `diff.noprefix`, in reality `git-format-patch` uses and is affected by `format.noprefix` instead. The patch corrects the documentation to show the proper config variable (`format.noprefix`) when the documentation is being built for `git-format-patch`, while keeping the original `diff.noprefix` reference for other commands.

The change is straightforward and well-justified, noting that `format.noprefix` was specifically added as an escape hatch for this command. The patch maintains consistency with the actual implementation while cleaning up the documentation. This is part of a larger series that also makes `format.noprefix` behave as a proper boolean value, though this particular patch stands alone as a documentation fix.
