This is a bugfix patch that makes `format.noprefix` behave as a proper boolean configuration option, aligning it with `diff.noprefix`'s behavior. The change makes the config reject non-boolean values (like "not-a-bool") where previously it would enable the no-prefix behavior for any non-empty value.

The patch modifies `builtin/log.c` to use `git_parse_maybe_bool()` for validation and adds helpful error messages when invalid values are provided. It also includes new test cases in `t/t4014-format-patch.sh` to verify both the boolean behavior and the error messaging. The change is technically breaking for any users who had non-boolean values set, but the author argues this is justified since the documentation always described it as boolean and such configurations would be unusual.

The implementation follows the pattern established by Jeff King (Peff) for similar config validation, and the error message includes a hint about the changed behavior to help users transition. The patch is part of a 2-patch series that also updates documentation to properly reference `format.noprefix` for `git-format-patch` instead of `diff.noprefix`.
