This is the third and final patch in Patrick Steinhardt's series optimizing shallow push performance in `git receive-pack`. The patch modifies `lookup_commit_reference_gently()` to use the commit-graph for faster commit parsing, building on the previous two patches that optimized non-commit object handling and fixed commit-graph edge cases.

The change replaces `parse_object()` with `lookup_commit()` followed by `repo_parse_commit_gently()`, allowing the function to leverage the commit-graph. Benchmark results show a 3.93x speed improvement (9.179s -> 2.337s) and significant memory reduction (407MB -> 15.5MB allocated) when pushing to a repository with 600,000 commit references. The implementation carefully maintains the existing error handling and quiet flag behavior while switching to the more efficient parsing path.

The systematic optimization - first handling non-commits, then hardening edge cases, and finally leveraging the commit-graph - demonstrates a methodical approach to performance improvement.
