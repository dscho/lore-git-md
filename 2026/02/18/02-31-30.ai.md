This is the first patch in a 3-part bugfix series for the contrib/subtree component, specifically addressing issues with the subtree split operation's history handling. The series removes a problematic optimization that was incorrectly excluding commits from split history.

This patch adds comprehensive test coverage to t7900-subtree.sh, creating three new test cases that verify correct behavior around:
1. The `--ignore-joins` flag respecting subtree adds
2. Proper handling of commits before and after `--rejoin` operations
3. Preservation of merges with unrelated histories

The tests use precise commit counting via `rev-list --count` and explicit branch comparisons to validate history integrity. Each test case documents which specific historical bug it guards against, referencing prior commits that attempted fixes (dd21d43b58, 315a84f9aa, 68f8ff8151).

The test additions are substantial (+110 lines) and appear well-constructed, with clear assertions about what should and shouldn't be present in the split history.
