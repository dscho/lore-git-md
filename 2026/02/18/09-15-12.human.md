This is part 2/5 in Elijah Newren's series to remove `the_repository` usage from merge-ort and replay, part of the ongoing project-wide effort to eliminate implicit repository dependencies. 

The patch mechanically converts most remaining uses of `the_repository` in merge-ort.c to instead use the explicit `opt->repo` parameter that's already available. The changes are straightforward replacements across various functions that handle tree parsing, blob reading, object writing, and configuration. One exception remains in `prefetch_for_content_merges()` where `the_repository` is still used, which the commit message notes will be addressed separately.

The changes follow established patterns for this type of conversion (seen in René Scharfe's work) and touch about 40 lines total. Given Elijah's deep expertise in the merge machinery (he designed the ort strategy) and the non-controversial nature of these mechanical changes, this appears to be a solid step forward in the broader cleanup effort. The patch maintains all existing functionality while making the repository dependencies more explicit.
