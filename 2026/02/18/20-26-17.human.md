This is a bugfix patch that makes `format.noprefix` behave as a proper boolean config option, aligning it with `diff.noprefix`'s behavior. The change makes the config reject non-boolean values (like "not-a-bool") where it would previously accept any value as enabling the no-prefix mode.

The patch comes with a migration path - when users provide invalid values, Git will now error out but include a hint explaining the changed behavior. The implementation updates `builtin/log.c` to properly validate the config value and adds tests in `t/t4014-format-patch.sh` to verify both the new boolean behavior and the error messaging.

While technically a breaking change, the author argues it's justified since:
1) The documentation already described it as equivalent to `diff.noprefix`
2) Non-boolean values were never intentionally supported
3) The only affected users would be those with unreasonable configurations

The patch is well-structured with clear commit message rationale, thorough test coverage, and consideration for backward compatibility. It follows the precedent set by Jeff King's similar changes to other config options. This appears to be a straightforward improvement that makes the config system more consistent.
