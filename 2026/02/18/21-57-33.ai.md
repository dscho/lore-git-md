This is the seventh iteration of a feature patch series enabling UTF-8 support in Git alias names via config subsection syntax (e.g., `[alias "förgrena"]`). The series has already addressed all technical concerns in previous rounds, with this version making a final adjustment to the completion output format to match Git's established conventions.

The v7 changes focus specifically on the zsh completion output format, reverting from using NUL separators for both name/value pairs and records (as tried in v6) back to matching `git config -z`'s convention of newline-separated name/value pairs within NUL-terminated records. This maintains consistency with Git's existing output patterns.

The four-commit series remains structurally unchanged from v6:
1. Consolidates alias listing between help.c and alias.c
2. Prepares the alias subsystem for subsection support
3. Implements the core UTF-8 subsection functionality
4. Fixes zsh completion to handle the new syntax

All technical review feedback has been addressed across previous iterations, with this version making only the final output format adjustment. The implementation includes comprehensive test coverage for non-ASCII characters (including Swedish and CJK examples) and maintains backward compatibility while adding the new subsection syntax.
