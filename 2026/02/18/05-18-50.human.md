Security patch hardening Git's repository discovery by validating `.git` file types, now in its fifth iteration. This second patch in the series focuses on allowing legitimate symlinks to directories while maintaining protection against malicious `.git` entries like FIFOs and sockets.

The change switches from `lstat()` to `stat()` in `setup_git_directory_gently_1()` to properly follow symlinks to directories, while leveraging the error handling infrastructure established in the first patch to reject dangerous file types. The implementation includes comprehensive tests verifying:
- Valid symlinked directories are accepted
- FIFOs and sockets are rejected with clear error messages
- Edge cases like garbage content and empty directories are handled appropriately

The series has addressed all feedback from Junio Hamano and other reviewers, with the security model now well-established and uncontested. The tests are integrated into the meson build system, and the patch appears ready for merging. This completes the security hardening while maintaining compatibility with legitimate repository setups using symlinks.
