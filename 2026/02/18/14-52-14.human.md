This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically addressing zsh completion for aliases with non-ASCII characters. The patch fixes an edge case where zsh completion was incorrectly handling subsection-style aliases (like `[alias "förgrena"]`) by introducing a new `--aliases-for-completion` option to `git help`.

The change ensures zsh completion properly displays both traditional (`alias.name`) and subsection (`alias.name.command`) alias formats by using the same C-level `list_aliases()` function that bash completion already uses. The new implementation outputs NUL-separated name/value pairs to preserve config order and handle all edge cases correctly.

This completes the technical work for UTF-8 alias support, with all feedback addressed across the four-patch series. The implementation has been reviewed by D. Ben Knoble for the zsh-specific aspects and has maintainer approval from Junio Hamano. The patch is ready for merging into the next integration branch.
