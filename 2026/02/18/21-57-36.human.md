This is a feature patch that enables UTF-8 support for Git aliases through config subsections, now in its seventh iteration with all technical issues resolved. The patch allows aliases to use non-ASCII characters (like "förgrena" or "分支") by defining them in subsections format (`[alias "förgrena"] command = branch`), while maintaining backward compatibility with the existing case-insensitive ASCII-only format.

The implementation handles several key aspects: case-sensitivity differences between the old and new formats, proper UTF-8 display alignment in help output using `utf8_strwidth()`, and comprehensive test coverage including Swedish, CJK, and space-containing aliases. The patch also refactors alias listing logic between `alias.c` and `help.c` to properly support the new syntax.

This well-tested change has gone through multiple rounds of review with input from Jeff King and Junio Hamano, and now includes the final adjustments to zsh completion output format and parser refactoring to use `parse_config_key()`. The documentation clearly explains both syntax forms with concrete examples. The patch is ready for merging after addressing all feedback across its seven iterations.
