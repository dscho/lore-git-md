This is a test modernization patch that simplifies several test scripts by using `test_seq -f` with pipes instead of temporary files. The changes were suggested by Jeff King (Peff) and Junio Hamano in previous discussions.

The patch updates 6 test files to replace patterns like:
```sh
printf "format string" $(test_seq N) >file
git command <file
```
with the more direct:
```sh
test_seq -f "format string" N | git command
```

The changes are mechanical but improve readability by:
1. Eliminating temporary files
2. Using `test_seq`'s built-in formatting capability
3. Piping directly to the Git command

The affected tests cover various scenarios including ref updates, reftable operations, archive handling, and hook testing. The patch maintains all test functionality while making the code more concise. It's a straightforward cleanup that follows established test patterns.
