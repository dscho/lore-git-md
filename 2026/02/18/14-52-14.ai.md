Final patch in the UTF-8 alias support series, focused on zsh completion fixes. This completes the implementation by ensuring subsection-style UTF-8 aliases (like `[alias "förgrena"]`) work properly in zsh completion, matching the behavior already working in bash.

The patch adds a new `--aliases-for-completion` option to `git help` that outputs NUL-separated alias names and values, similar to the existing `--config-for-completion`. This provides zsh completion with properly formatted alias data while preserving the descriptive text needed for completion menus. The implementation uses the regex-based approach that was causing problems with subsection aliases, replacing it with direct access to the alias list that already handles both syntax forms correctly.

Key technical details:
- Adds new `HELP_ACTION_ALIASES_FOR_COMPLETION` mode to `builtin/help.c`
- Outputs NUL-separated pairs via `list_aliases()` to preserve config order
- Updates `__git_zsh_cmd_alias()` to use the new interface
- Maintains all existing completion functionality while fixing subsection case
