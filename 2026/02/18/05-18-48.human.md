This is a security-focused patch series hardening Git's repository discovery against malicious `.git` entries. The v5 iteration splits the changes into two logical commits as requested by Junio Hamano, with all substantive feedback from previous rounds addressed.

The first commit refactors error handling in `read_gitfile_*` functions to properly distinguish between "path doesn't exist" (non-fatal, continue searching) and other stat failures (fatal). The second commit implements the core security change - switching from `lstat()` to `stat()` to support legitimate symlinks while rejecting dangerous filesystem entities like FIFOs and sockets. The accompanying test script (`t0009-git-dir-validation.sh`) verifies both valid and invalid cases.

The series has evolved through five versions with thorough review from Karthik Nayak and Junio Hamano, who have now approved the technical approach. The remaining build system integration (adding the test to `meson.build`) is complete in this version. The patch structure follows Junio's guidance for clear separation of concerns, making this likely the final version before merging. Tian Yuchen has been responsive to feedback throughout, and the security model - allowing safe symlinks while blocking potentially malicious attachments - is well-validated by the comprehensive test coverage.
