This is the final patch in Patrick Steinhardt's series addressing test failures related to `iconv(1)` availability on Windows/MSVC platforms. The patch updates t6006-rev-list-format.sh to properly handle cases where Git is built with ICONV support but the `iconv(1)` executable isn't available.

The changes make two tests in t6006 conditional on the ICONV prerequisite, falling back to UTF-8 encoding when the prerequisite isn't met. The first test creates a commit message with special characters, while the second prepares expected output for comparison. Both now check for ICONV support before attempting to use the `iconv(1)` executable.

The patch follows the same pattern established in the series: maintaining test coverage while improving portability by properly separating the concerns of libiconv (used by Git internally) from the `iconv(1)` executable (used in test scripts). It completes the series' goal of making these tests robust across platforms where the executable might be missing, particularly Windows/MSVC environments where MinGW no longer ships `iconv(1)`.

With this patch, all test files in the series have been updated to handle the iconv distinction consistently.
