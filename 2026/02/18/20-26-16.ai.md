This is a documentation and behavior change patch series addressing how `format.noprefix` config is handled. The series comes from Kristoffer Haugsbakk, who has been an active documentation contributor.

The main issue is that `format.noprefix` currently acts as a boolean that's always "on" regardless of its value, unlike its counterpart `diff.noprefix` which properly respects boolean values. The first patch changes this to make `format.noprefix` behave like a proper boolean, treating non-boolean values as errors (a breaking change, but with clear error messaging). The second patch updates the documentation in `diff-options.adoc` to mention `format.noprefix` for `git-format-patch` instead of `diff.noprefix`.

The changes touch the format-patch implementation in `builtin/log.c`, add tests in `t/t4014-format-patch.sh`, and modify the documentation. The author notes this is a breaking change but follows precedent from Jeff King's (Peff) previous comments on similar changes. The patches appear focused and well-motivated, with clear commit messages explaining both the technical change and its rationale.
