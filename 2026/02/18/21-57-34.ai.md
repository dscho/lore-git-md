This is a refactoring patch that consolidates alias listing logic between `alias.c` and `help.c`. It's part of a larger series (v7 1/4) implementing UTF-8 support for Git configuration subsections, specifically for aliases.

The patch removes duplicate alias parsing code from `help.c` by extending `list_aliases()` in `alias.c` to also store alias values (via the string_list util field). This maintains the existing error checking for value-less alias definitions while eliminating code duplication. The change is verified by a new test case that confirms error reporting when an alias lacks a value.

Key technical details:
- Modifies `alias.c` to store values when listing aliases
- Removes the `get_alias()` callback from `help.c`
- Adds test coverage for empty alias error case
- Preserves existing behavior while simplifying the codebase
