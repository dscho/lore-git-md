This is a documentation and behavior change patch series addressing how `format.noprefix` config is handled. The first patch makes `format.noprefix` properly behave as a boolean config option (currently it's active regardless of value). This is a breaking change that will error if the config is set to a non-boolean value. The second patch updates the documentation in `diff-options.adoc` to mention `format.noprefix` for `git-format-patch` instead of `diff.noprefix`.

The changes are straightforward but technically breaking - the author notes this was discussed with Jeff King (Peff) regarding how to handle such changes. The series includes test coverage in t4014 to verify the new boolean behavior. This appears to be a sensible cleanup to make the config handling more consistent with Git's conventions.
