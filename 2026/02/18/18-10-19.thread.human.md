This thread discusses a test modernization patch from Aaron Plattner that simplifies several test scripts by eliminating temporary files when generating sequences for Git commands. The changes follow patterns previously suggested by Jeff King (Peff) and Junio Hamano, replacing temporary file usage with direct piping of `test_seq -f` output to commands like `update-ref` and `mktree`. The patch affects six test scripts across the refs and archive test suites.

Junio noted in his reply that while the changes are an improvement, temporary files can sometimes aid debugging by preserving test inputs when failures occur. However, he acknowledged this isn't a strong enough reason to block the patch, which aligns with established test modernization practices. The patch appears uncontroversial, being a mechanical cleanup that follows prior recommendations from key contributors. The changes focus solely on test infrastructure in the `t/` directory, without touching core functionality.
