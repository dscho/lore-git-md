This is a test modernization patch that simplifies several test scripts by using `test_seq -f` with pipes instead of temporary files. The changes were suggested by Jeff King (Peff) and Junio Hamano in previous discussions.

The patch updates 6 test scripts (`t/pack-refs-tests.sh`, `t/t0613-reftable-write-options.sh`, `t/t1400-update-ref.sh`, `t/t1460-refs-migrate.sh`, `t/t5004-archive-corner-cases.sh`, and `t/t5401-update-hooks.sh`) to replace patterns that either:
1. Used `printf` with `test_seq` and wrote to a temporary file before piping to Git commands
2. Used `test_seq -f` but still wrote to a temporary file first

The new approach directly pipes the output of `test_seq -f` to Git commands like `update-ref` and `mktree`. This makes the tests cleaner by eliminating temporary file handling while maintaining the same functionality. The changes are mechanical and focused on test infrastructure rather than affecting Git's core behavior. The patch appears well-scoped and follows established patterns for test modernization.
