This is a CI/build system patch in Patrick Steinhardt's series improving test infrastructure reliability across GitLab and GitHub CI. Johannes Schindelin (Git for Windows maintainer) provides a fixup patch for an issue he encountered when testing the changes on Windows with Visual Studio builds.

The original patch (5/7 in the series) standardized test-slicing to use one-based numbering consistently between Make and Meson builds. Schindelin found that the GitHub workflow still needed adjustment for Windows+VS test jobs, where the slice numbering was incorrectly zero-based. His proposed amendment modifies the workflow YAML to properly increment the slice number for these jobs.

The fix is straightforward - adding 1 to the matrix number before passing it to the test-slicing script. Schindelin provides a successful CI run demonstrating the fix works. This is a minor but important correction to ensure the test-slicing changes work correctly across all platforms, particularly for Windows builds which have different requirements.
