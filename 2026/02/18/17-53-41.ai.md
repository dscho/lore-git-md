This is part 2 of Shreyansh Paliwal's 3-part series to eliminate `the_repository` and `the_hash_algo` globals from `wt-status.c`, continuing the project's incremental removal of global state. The patch focuses on converting core status reporting paths to use local repository instances (`s->repo` or `r`) instead of the global `the_repository`.

The changes are mechanical but wide-ranging, touching status preparation, stash counting, rebase/cherry-pick status display, and tracking information. Key conversions include:
- Using `s->repo` for index file paths and ref operations
- Accessing the hash algorithm through the local repository
- Reading HEAD/ORIG_HEAD through the proper ref store
- Generating paths and abbreviations with the correct repository context

The patch maintains identical behavior while making repository dependencies explicit. It builds on part 1's function signature conversions and prepares for part 3's removal of `the_hash_algo`. The changes are part of Git's broader architectural effort to eliminate global state, with `wt-status.c` serving as a reference implementation for this conversion pattern.
