This is a build system patch addressing dependency tracking for `config-list.h` in both Meson and Makefile builds. The issue occurs when documentation changes (particularly config option additions/removals) don't properly trigger rebuilds, which can lead to test failures like in `t9902-completion.sh`.

The solution implements proper dependency tracking by having `generate-configlist.sh` output both the header file and a depfile listing all documentation dependencies. The patch now covers both build systems consistently, with the Meson version being the primary focus. Key improvements include proper path escaping (handling spaces and special characters), explicit script dependencies, and clear documentation of the rebuild assumptions.

The implementation has been thoroughly reviewed by Patrick Steinhardt and Phillip Wood, with all test cases passing across platforms. While there are some open questions about portability (printf vs echo) and edge cases in path escaping, the core functionality is complete and robust. The patch includes useful debugging commands in the commit message to verify the dependency tracking works as intended.

This represents a significant improvement in build reliability, ensuring `config-list.h` stays synchronized with the documentation that defines Git's configuration options. The solution is well-tested and addresses all previous review feedback while maintaining compatibility with both build systems.
