This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically focusing on fixing zsh completion for subsection-style aliases (like `[alias "förgrena"]`). The patch addresses a discrepancy where zsh completion was showing full subsection paths rather than just the alias names.

The change introduces a new hidden `--aliases-for-completion` option to `git help` that outputs alias names and values in a NUL-separated format matching Git's conventions. This replaces the previous regex-based approach in zsh completion that didn't properly handle subsection syntax. The implementation reuses the existing `list_aliases()` function from `alias.c` that already correctly processes both traditional and subsection-style aliases.

This patch completes the technical work for UTF-8 alias support, having gone through seven iterations with thorough review from multiple contributors including Jeff King and Junio Hamano. The zsh completion now matches bash's behavior while maintaining the descriptive output zsh users expect. All feedback from previous versions has been addressed, making this series ready for merging.
