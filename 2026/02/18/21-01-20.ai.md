Refactoring patch in the ODB abstraction effort, converting direct pointer casts to `container_of()` for type safety.

Justin Tobler sends a small cleanup patch to the object-file subsystem, replacing direct pointer casts with the safer `container_of()` macro when converting between base and derived types in the ODB (object database) transaction and read stream implementations. This follows up on prior discussion (referenced by message ID) about improving code hygiene in this area.

The changes are mechanical but meaningful - they make the type relationships explicit through the container structure's layout rather than relying on potentially unsafe C casts. The patch touches several functions in object-file.c that handle loose object transactions and streaming reads, consistently applying the same pattern. While small, this is part of the broader ODB abstraction work that Patrick Steinhardt and Justin have been driving to make Git's object storage more modular.

The implementation looks straightforward and well-contained, with no apparent behavior changes beyond the type safety improvement. As a focused cleanup in an active development area, this seems like a low-risk change that aligns with the project's ongoing code quality efforts.
