This is the final patch in a series implementing UTF-8 support for Git configuration subsections, specifically focusing on fixing zsh completion for subsection-style aliases (like `[alias "förgrena"]`). The patch addresses a discrepancy where zsh completion was incorrectly handling subsection aliases by introducing a new `--aliases-for-completion` option to `git help`.

The key technical change moves zsh completion from using `git config --get-regexp` (which didn't properly handle subsection syntax) to a new C-based implementation that leverages the existing `list_aliases()` function. This ensures consistent behavior between bash and zsh completions while maintaining the NUL-separated output format Git uses for completion. The implementation outputs alias names and values as "name\nvalue\0" pairs, matching Git's established patterns.

The patch follows the project's completion system conventions, building on the existing `--config-for-completion` pattern. It completes the technical work needed for UTF-8 alias support by ensuring the zsh completion handles both traditional (`alias.name`) and subsection (`alias.name.command`) formats correctly. All prior feedback has been addressed, including Junio Hamano's note about adding a missing Signed-off-by line.

This represents the last piece of the UTF-8 alias support series, which has gone through seven iterations with input from multiple reviewers (Jeff King, D. Ben Knoble, Torsten Bögershausen). The implementation is now ready for merging, with all technical issues resolved and the zsh completion output standardized to match Git's conventions.
