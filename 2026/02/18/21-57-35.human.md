This is the second patch in a v7 series implementing UTF-8 support for Git configuration subsections, specifically for aliases. The patch refactors the alias parsing logic in `help.c` to use `parse_config_key()` instead of `skip_prefix()`, which properly handles the three-level config key structure needed for subsection support.

The change introduces a compatibility break by no longer accepting malformed "alias.<subsection>.<key>" entries (unless <key> is "command"). The commit message notes this was arguably a bug since dotted aliases were never intentionally supported. The patch includes the necessary updates to maintain existing functionality while preparing for the new subsection syntax that will be introduced in the next commit.

The implementation looks clean and focused, with just 7 lines added and 3 removed in `help.c`. The change has been through multiple review iterations (now at v7) and appears ready for merging, having addressed all technical feedback. The compatibility implications are clearly documented in the commit message.
