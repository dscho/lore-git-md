This is the sixth iteration of a feature patch series enabling UTF-8 support in Git alias names via config subsection syntax (e.g., `[alias "förgrena"]`). The series has progressed through extensive review and is now in its final form with all technical issues resolved.

The v6 series consists of four commits that:
1. Consolidate alias listing between `alias.c` and `help.c`
2. Refactor alias handling to prepare for subsection support
3. Implement the core UTF-8 alias functionality
4. Fix zsh completion to properly handle subsection aliases

Key changes in this version include:
- Removal of unnecessary sorting to preserve config order (per D. Ben Knoble's suggestion)
- Fixing the `--aliases-for-completion` output to use NUL separators instead of newlines
- Adding a missing Signed-off-by trailer
- Minor style cleanup in `builtin/help.c`

The implementation touches multiple components including alias handling, help system integration, and shell completion. It maintains backward compatibility while adding support for non-ASCII characters in alias names through Git's existing subsection syntax. The changes include comprehensive test coverage with Swedish, CJK, and space-containing aliases.

The thread shows consensus that the implementation is technically sound, with positive reviews from D. Ben Knoble on the zsh completion aspects and maintainer approval from Junio Hamano. All known edge cases have been addressed, making this series merge-ready. The only remaining suggestion is potential future work to unify bash and zsh completion approaches, but this does not block the current changes.
