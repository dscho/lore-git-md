This is a refactoring patch that consolidates Git's alias-listing logic between `alias.c` and `help.c`. It's the first of four patches in the sixth iteration of a series implementing UTF-8 support for Git configuration subsections (specifically for aliases like `[alias "förgrena"]`).

The patch eliminates duplicate code by having `help.c` use `list_aliases()` from `alias.c` rather than maintaining its own `get_alias()` callback. The key changes are:

1. Modifies `list_aliases()` to store alias values using the string_list's util field
2. Preserves error checking for value-less aliases by moving the check into `alias.c`
3. Adds a test case verifying proper error reporting for aliases without values

The changes are clean and focused - this is clearly a preparatory refactoring for the main UTF-8 support feature coming in later patches. The test addition shows good attention to maintaining existing behavior while simplifying the code. The patch has already been reviewed and approved by the maintainer (Junio Hamano) in previous iterations.
