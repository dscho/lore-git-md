This is the fourth patch in a series addressing test failures on Windows/MSVC platforms related to `iconv(1)` availability when Git's ICONV support is enabled. The patch focuses on t5550-http-fetch-dumb.sh, which verify HTTP error message handling.

The key change adds ICONV prerequisites to tests that interact with "$HTTPD_URL/error" endpoints, since these rely on the `iconv(1)` executable to reencode messages. The patch also converts several `grep` calls to the preferred `test_grep` helper. Tests that don't actually need encoding conversion remain unchanged.

This continues the series' consistent approach of distinguishing between libiconv (used by Git itself) and the `iconv(1)` executable (used in test scripts). The changes are straightforward and follow the pattern established in earlier patches, making the tests more robust on platforms where the executable isn't available. With this patch remaining in the series, the work appears nearly complete.
