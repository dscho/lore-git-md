This is the third patch in a four-part series implementing UTF-8 support for Git configuration subsections, specifically for aliases. The patch enables non-ASCII alias names by leveraging Git's existing config subsection syntax (e.g., `[alias "förgrena"]`).

The implementation handles both backward compatibility (keeping the existing case-insensitive matching for traditional `[aliasname]` syntax) while adding case-sensitive matching for the new subsection form. The help system has been updated to properly list and display these aliases, using `utf8_strwidth()` for correct column alignment of non-ASCII names.

Key technical details include:
- New config parsing logic in `alias.c` that distinguishes between the two syntax forms
- Updates to `help.c` to properly handle subsection aliases in command listings
- Comprehensive test coverage including Swedish, CJK, and space-containing aliases
- Strict validation rejecting malformed dotted aliases
- Documentation updates explaining both syntax forms with concrete examples

The patch represents the core functionality of the series, with all technical issues resolved through multiple iterations of review. It has received positive feedback from Jeff King and maintainer approval from Junio Hamano, with the final zsh completion output format standardized in this version to match Git conventions. The implementation is now ready for merging, having gone through seven iterations to address all edge cases and review feedback.
