This is the main implementation patch in a series adding UTF-8 support for Git aliases via config subsections. The patch enables aliases with non-ASCII characters by allowing them to be defined using the subsection syntax (e.g., `[alias "förgrena"] command = branch`), while maintaining backward compatibility with the traditional case-insensitive syntax for simple ASCII aliases.

The implementation handles several key aspects:
- Subsection aliases are matched case-sensitively while traditional aliases remain case-insensitive
- The help system (`git help -a`) is updated to properly display subsection aliases using utf8_strwidth() for correct column formatting
- Comprehensive test coverage is added for Swedish, CJK, and space-containing aliases
- The documentation is expanded to clearly explain both syntax forms and their differences

The patch builds on preparatory refactoring in patch 2/4 (which switched to parse_config_key()) and will be followed by zsh completion fixes in patch 4/4. The implementation follows Jeff King's suggestion to use existing config infrastructure rather than introducing Unicode normalization.

Technical details include:
- Modified files: alias.c (core logic), help.c (display), Documentation/config/alias.adoc, t/t0014-alias.sh (tests)
- New test cases verify behavior for various character sets and edge cases
- The implementation preserves all existing alias functionality while adding the new capability
- Documentation clearly distinguishes between the two syntax forms and their constraints
