Test modernization patch in the repo-info subsystem series. This is patch 6/8 in a series focused on naming consistency and code organization, following recent work on `git-repo-info` and `git-repo-structure`.

The patch simplifies the test for NUL-formatted output in `t1901-repo-structure.sh` by using `tr` to transform the actual output to match the expected key-value format, rather than maintaining separate expected output files. This approach better reflects that the two formats (key-value and NUL) are fundamentally the same data with different separators. The change makes the test more maintainable by eliminating the need to keep two output files in sync.

The test now transforms the NUL output by converting newlines to equals signs and NULs to newlines, then compares against the existing key-value expected output. This matches the series' theme of mechanical improvements to test infrastructure while maintaining identical behavior. The patch follows the established pattern of small, focused changes with clear motivation tied to the subsystem's ongoing standardization efforts.
