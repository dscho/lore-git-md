This is the third patch in a 4-part series implementing UTF-8 support for Git configuration subsections, specifically focused on aliases. The patch enables non-ASCII alias names through the subsection syntax (e.g., `[alias "förgrena"] command = branch`), while maintaining backward compatibility with the existing case-insensitive simple alias syntax.

The implementation handles several key aspects:
- Subsection aliases are matched case-sensitively while simple aliases remain case-insensitive
- UTF-8 characters are properly supported in subsection names
- The help system (`git help -a`) correctly displays subsection aliases using utf8_strwidth() for alignment
- Comprehensive test coverage includes Swedish, CJK characters, and spaces in alias names

The patch builds on preparatory refactoring from patch 2/4 and will be followed by zsh completion fixes in 4/4. The series has gone through multiple iterations with input from Jeff King and Junio Hamano, and appears ready for merging with all technical issues resolved. The documentation updates clearly explain both syntax forms and provide concrete examples.
