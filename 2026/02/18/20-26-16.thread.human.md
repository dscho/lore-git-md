This thread concerns improvements to the `format.noprefix` configuration option and its documentation. Kristoffer Haugsbakk's series makes two key changes: first, enforcing boolean validation for `format.noprefix` (matching `diff.noprefix`'s behavior) with clear error messages for invalid values; second, correcting the `git-format-patch` documentation to properly reference `format.noprefix` instead of the incorrect `diff.noprefix` mention.

Junio Hamano reviewed both patches, suggesting improvements to the error messaging wording in the first patch to be more explicit about the behavior change from accepting any value to requiring proper booleans. He also recommended using `advise()` rather than `advise_if_enabled()` for configuration errors. The second documentation patch, which uses AsciiDoc conditionals to properly show the correct config variable contextually, was straightforward and has been queued by Junio. The changes align the implementation and documentation while maintaining backward compatibility for valid boolean settings, with clear messaging for any users affected by the stricter validation.
