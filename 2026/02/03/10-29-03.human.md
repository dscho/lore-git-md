This is a refactoring patch that extends Coccinelle rules for the `MEMZERO_ARRAY()` macro, which was introduced a couple months ago to replace common `memset()` patterns. Toon Claes, who wrote the original macro, now improves the semantic patch to catch more cases that could use it, including some that were previously converted manually.

The patch makes several improvements to the Coccinelle rules:
- Handles more variants of `memset()` calls that zero memory
- Removes unnecessary parentheses in the converted code
- Fixes some indentation (spaces to tabs)
- Applies the changes to a few real code examples in `diffcore-delta.c` and `ewah/bitmap.c`

The author notes this might not be worth applying since the original conversions are already done, but the patch does clean up some remaining cases. It's a straightforward improvement to the codebase's consistency, though not urgent. The changes are mechanical and low-risk, touching only test infrastructure and internal helper code.
