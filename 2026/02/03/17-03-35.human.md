This is a documentation patch from Jean-Noël Avila, part of his ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis-style conventions. The patch focuses on converting `git-show.adoc` and `pretty-formats.adoc` to the new style while making related adjustments to `asciidoc.conf.in`.

The changes introduce proper synopsis blocks for command documentation, standardize placeholder formatting (`_<name>_`), and improve option presentation. The patch also adds block definitions in `asciidoc.conf.in` to support the new formatting while maintaining compatibility across different AsciiDoc toolchains (asciidoc.py and asciidoctor).

Kristoffer Haugsbakk has reviewed and signed off on the changes. The work is purely presentational - it doesn't alter any functionality, just improves documentation is rendered. This continues Avila's multi-patch series to bring consistency to Git's documentation, with previous patches in the series having already addressed other man pages.

The changes are mechanical but thorough, touching formatting details like:
- Converting command synopses to use proper `[synopsis]` blocks
- Standardizing how options and placeholders are marked up
- Improving the presentation of the various pretty formats
- Ensuring consistent rendering of special characters and formatting codes

This represents another incremental step in the long-running documentation standardization effort that has seen steady progress across multiple releases.
