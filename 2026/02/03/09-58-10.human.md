Feature patch for the experimental `git-last-modified` command. This is the final approval in the thread, with both Junio C Hamano and Karthik Nayak agreeing that the v3 patch series is ready to be merged into the `next` integration branch. The series changes the default behavior to be non-recursive (max-depth=0) while maintaining backward compatibility via a `-r/--recursive` option, and includes comprehensive documentation updates.

The implementation has gone through multiple iterations, with all substantive feedback addressed in this version. Notable changes include removing the separate `recursive` flag in favor of unified depth control through `max_depth`, standardized pathspec terminology in documentation, and thorough test coverage. While marked as EXPERIMENTAL, the interface is now considered stable.

A minor post-merge documentation formatting issue was noted by Kristoffer Haugsbakk regarding pathspec markup in the man page synopsis, but this doesn't affect functionality. The patch represents the conclusion of active development for this feature, with the implementation behavior fully finalized and ready for wider testing in the integration branch.
