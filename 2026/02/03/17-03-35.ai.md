This is a documentation patch from Jean-Noël Avila, part of his ongoing effort to standardize Git's man pages to consistent AsciiDoc synopsis-style formatting. The patch focuses on converting `git-show.adoc` and `pretty-formats.adoc` to the new style while adding supporting infrastructure in `asciidoc.conf.in`.

Key changes include:
- Adding `blockdef-open` definitions in `asciidoc.conf.in` to support synopsis-style blocks across both docbook and xhtml backends
- Converting `git-show`'s command syntax to use the new `[synopsis]` block with proper stuck-form options and placeholders
- Reformatting `pretty-formats.adoc` to use definition lists for each format type, with nested synopsis blocks showing the format structure
- Standardizing option presentation (e.g., changing `->` to `->` in decoration options)
- Using `_<placeholder>_` consistently for arguments
- Converting manual markup to proper AsciiDoc macros

The changes maintain cross-toolchain compatibility between asciidoc.py and asciidoctor while improving documentation consistency. Kristoffer Haugsbakk has reviewed and signed off on the changes. This patch represents incremental progress in the broader documentation standardization effort, with no functional changes to Git's behavior.
