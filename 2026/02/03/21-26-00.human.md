This is a CI/build system patch from Junio Hamano that addresses a test failure in the `diff-highlight` contrib script when running with Git 3.0's breaking changes (specifically the default branch naming change from 'master' to 'main'). 

The patch forces the initial branch name back to 'master' in the `t9400-diff-highlight.sh` test script to maintain compatibility with the test's expectations and its documented history topology. This is presented as the simplest solution among several possible approaches to make the test pass in CI.

The change is part of a broader effort to enable CI testing of contrib/ scripts, which has already revealed several previously unknown test failures across different configurations (SHA-256, leaks, reftable, ASAN). This particular fix demonstrates how the expanded CI coverage is surfacing compatibility issues that weren't caught before.

The patch is straightforward and low-risk, focusing specifically on making the test pass rather than updating the test's assumptions. It follows the pattern seen elsewhere in the codebase for handling similar branch naming transitions.
