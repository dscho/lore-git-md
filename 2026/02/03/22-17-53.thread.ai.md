Justin Tobler's 5-patch series for repository statistics in `git repo` (v3) is now complete with patch 5/5 adding tree entry counting to the existing metrics tracking maximum object sizes and commit parent counts. - `stats_table_object_size_addf()`, `stats_table_object_count_addf()`, and tree entry display in formatted output
- `strbuf_detach()` optimizations for string handling
- NULL OID handling for empty repositories
- Numbered reference system ([1], [2]) linking table entries to OIDs
- `annotations` string list in `struct stats_table` for OID footnotes
- Refactored `count_objects()` processes statistics per-object with commit parent parsing and tree entry counting
