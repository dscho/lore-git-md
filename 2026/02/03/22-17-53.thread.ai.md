Justin Tobler's 5-patch series for repository statistics in `git repo` (v3) continues refining maximum-value metrics and table output, incorporating feedback from Junio Hamano and Patrick Steinhardt. The series modifies `builtin/repo.c` and tests (t1901) to track largest objects by type (blobs, trees, commits, tags) while dropping octopus merge tracking due to bisection concerns.

Key technical elements:
- `struct object_stats` tracks maximum sizes per type
- `largest_objects` struct with SHA-1/SHA-256 compatible OID handling
- `stats_table_object_size_addf()` for annotated table output (enhanced in v3 3/5)
- `strbuf_detach()` optimizations for string handling
- NULL OID handling for empty repositories
- Numbered reference system ([1], [2]) linking table entries to OIDs (new in v3 3/5)
- `annotations` string list in `struct stats_table` for OID footnotes (new in v3 3/5)
- Refactored `count_objects()` processes statistics per-object rather than by type batches
- `check_largest()` helper for per-object maximum size tracking
