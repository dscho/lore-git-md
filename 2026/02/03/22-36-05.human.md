Maintainer feedback on repository statistics series.

Junio Hamano provides review comments on the first patch of Justin Tobler's series enhancing `git repo` with detailed repository statistics. The proposed restructuring would use either:
1. A nested struct grouping count/size metrics per type, or
2. An array-based approach with type indexing

Junio notes this is just an observation from looking at this specific code section - other parts of the implementation may justify the current structure. His tone is constructive, offering food for thought rather than demanding changes.

This feedback comes as the series appears ready for maintainer consideration, suggesting Junio is engaging with the technical approach while leaving room for the author to justify or adapt the design. The comment focuses narrowly on code organization in the object counting logic, not questioning the overall feature addition.
