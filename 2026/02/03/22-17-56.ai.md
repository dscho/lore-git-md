This is the third patch in Justin Tobler's series enhancing `git repo` with repository statistics. The patch focuses on improving the table output format by adding OID annotations for the largest objects in each category (commits, trees, blobs, tags).

The key changes introduce:
- A new `annotations` field in `stats_table` to track OID references
- A modified `stats_table_object_size_addf()` that accepts OIDs and creates numbered annotations
- Expanded table formatting to include annotation indices (e.g. "[1]") next to size metrics
- A footer section displaying the full OIDs corresponding to each annotation

The implementation maintains backward compatibility while adding the new information in a structured way. Test cases in t1901 are updated to verify both the annotation indices in the table and the OID listing in the footer. The changes build cleanly on the object tracking infrastructure established in earlier patches.

This continues the series' pattern of incremental, focused improvements to the repository statistics feature. The OID annotations will help users identify exactly which objects are the largest in their repositories, making the statistics more actionable. The patch appears well-structured with thorough test coverage.
