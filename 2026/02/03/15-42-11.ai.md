This is part 3/3 of a patch series moving configuration variables from global storage into `struct repo_config_values` as part of the `the_repository` removal effort. The patch migrates the `branch.autoSetupMerge` configuration, which controls automatic upstream branch tracking behavior, from the global `git_branch_track` variable to repository-specific storage.

The change affects several commands that use branch tracking behavior: `git branch`, `git checkout`, `git push`, and `git submodule--helper`. Each command now accesses the configuration through `repo_config_values(the_repository)->branch_track` rather than the global variable. The initialization value `BRANCH_TRACK_REMOTE` is preserved by setting it in `repo_config_values_init()`.

The patch follows the established pattern from previous migrations in this series, maintaining the same behavior while moving the storage location. Phillip Wood provided suggestions on naming improvements, and the patch carries mentorship tags from Christian Couder and Usman Akinyemi as part of an Outreachy internship project. The series has evolved through six iterations with increasing safety mechanisms, though as noted in the thread summary, some architectural questions about initialization patterns remain open.
