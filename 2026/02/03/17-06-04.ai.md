This is a platform compatibility fix for the `git subtree` contrib script, addressing test failures when running with the reftable ref backend. Junio C Hamano identifies a test that assumes the refs/files backend by directly reading `.git/HEAD` as a text file, which fails under reftable. The fix replaces the direct file read with `git symbolic-ref --short HEAD`, making the test backend-agnostic.

The patch is small (3 lines changed) but demonstrates the value of the new CI infrastructure that tests contrib/ components across different configurations. This particular issue was uncovered by running subtree tests with `GIT_TEST_DEFAULT_REF_FORMAT=reftable`, which revealed the backend-specific code path. The fix follows Git's standard pattern for ref access and maintains the same test behavior while being portable across ref storage formats.

Notably, this comes as part of broader CI improvements to test contrib/ components more thoroughly, which are already surfacing multiple previously unknown issues (including in diff-highlight tests and across SHA-256, leaks, and ASAN configurations). The patch serves as both a specific fix and an example of why expanded test coverage is valuable for contrib/ scripts that may have developed platform-specific behaviors over time.
