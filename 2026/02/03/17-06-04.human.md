This is a platform compatibility fix for the `git subtree` contrib script, addressing test failures when using the reftable ref backend. The patch comes from Junio C Hamano as part of ongoing CI infrastructure improvements to test contrib/ components more thoroughly.

The issue stems from the subtree test script making assumptions about the filesystem layout of Git refs, specifically reading `.git/HEAD` directly as a text file. This breaks with the reftable backend which stores refs differently. The fix replaces the direct file read with `git symbolic-ref --short HEAD`, which works consistently across all ref backends.

This change is part of a broader effort to expand CI test coverage of contrib/ components, which has already uncovered several previously unknown issues (including this one) when testing with different configurations like reftable, SHA-256, and ASAN. The patch is straightforward and clearly correct - it maintains the same functionality while being backend-agnostic.

Notably, this reveals that the subtree script lacks a dedicated maintainer, as Junio had to manually identify recent contributors to CC on the patch. The fix itself is small but important for ensuring the script works reliably with alternative Git configurations.
