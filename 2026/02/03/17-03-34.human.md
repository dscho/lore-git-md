This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git man pages to consistent AsciiDoc synopsis-style formatting. This third iteration in a four-part series focuses on polishing `git-clone.adoc` and `for-each-ref-options.adoc`, with Kristoffer Haugsbakk reviewing the changes.

The patch makes several stylistic improvements: spelling out both `--reject-shallow` and `--no-reject-shallow` forms explicitly, converting manual `*NOTE*` markup to proper AsciiDoc `NOTE:` macros, and fixing placeholder formatting (`_<name>_`). It also standardizes option presentation to use the "stuck-form" convention (`--option=<value>`) that Junio Hamano endorsed earlier in the thread, applying this consistently to options like `--reference`, `--branch`, and `--upload-pack`.

The changes are purely presentational - no command behavior is altered. The patch continues the systematic cleanup of documentation formatting details across multiple man pages, with each iteration refining the consistency of the AsciiDoc markup. The work is part of a larger project to improve Git's documentation quality through standardized formatting.
