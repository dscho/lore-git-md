This is a CI/build system patch from Junio Hamano that addresses a test failure in the diff-highlight contrib script when running with Git 3.0's breaking changes (specifically the default branch name change from 'master' to 'main'). The patch forces the initial branch name back to 'master' for the diff-highlight test script to maintain compatibility with its existing test expectations.

The change is minimal - just two lines setting GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=master at the start of t9400-diff-highlight.sh. This matches the test's documented topology illustration which assumes 'master' branch naming. The patch demonstrates the value of the new contrib/ test coverage in CI by catching this previously unnoticed compatibility issue.

This is part of the broader effort to expand CI testing of contrib/ components, which has already uncovered several issues including this one and the earlier reftable compatibility problem in git-subtree. The fix is straightforward and maintains backward compatibility while allowing the test to pass in Git 3.0's breaking changes environment. Junio notes this is the simplest of several possible solutions, chosen to preserve the test's existing documentation and expectations.
