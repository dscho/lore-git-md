Documentation standardization effort continuing with `git-submodule` and `git-show` conversions.

This is part of Jean-Noël Avila's ongoing documentation standardization work, converting Git man pages to consistent AsciiDoc synopsis-style formatting. The v3 series includes conversions of `git-submodule` and `git-show` documentation, along with final polish on previously converted pages like `git-clone` and `for-each-ref-options`. Kristoffer Haugsbakk has reviewed the changes, catching various formatting issues.

Key changes in this iteration include:
- Complete conversion of `git-submodule.adoc` to synopsis style with proper option formatting (e.g. `--branch=<branch>` instead of `--branch <branch>`)
- Finalization of `git-clone.adoc` conversion with consistent stuck-form options
- Fixes to decoration option rendering in `pretty-formats.adoc`, particularly around the `->` pointer symbol
- Standardization of placeholder formatting (`_<name>_`) and command references throughout

The work maintains strict focus on documentation presentation without altering command behavior, systematically improving formatting details across multiple man pages. Each conversion follows the established pattern of using backticks for commands/options, proper AsciiDoc macros for notes, and consistent synopsis blocks. The patches show careful attention to cross-toolchain compatibility between asciidoc.py and asciidoctor.
