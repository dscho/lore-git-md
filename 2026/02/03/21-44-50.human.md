Documentation patch finalizing the `git-show` man page conversion to synopsis-style AsciiDoc formatting. This is part of Jean-Noël Avila's ongoing effort to standardize Git's documentation, with Kristoffer Haugsbakk reviewing and approving the changes.

The patch completes the conversion of `git-show.adoc` to use the new synopsis blocks introduced in earlier patches, ensuring consistent formatting of command syntax, placeholders, and options across all man pages. Key changes include proper stuck-form options (like `--option=<value>`), standardized argument placeholders (`_<name>_`), and integration with the new `asciidoc.conf.in` definitions that support both docbook and xhtml backends.

Kristoffer confirms all his previous review comments have been addressed, though he notes some coordination complexity from accidentally replying to an earlier version of the patch series. The work maintains cross-toolchain compatibility between asciidoc.py and asciidoctor while improving documentation presentation without altering command behavior. This patch represents the final piece of the v3 series that also included conversions of `git-submodule`, `git-clone`, and other man pages.
