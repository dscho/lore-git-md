This is a documentation patch converting the `git-submodule` man page to the new synopsis-style format as part of Jean-Noël Avila's ongoing documentation standardization effort. The patch is the first in a v3 series of man page conversions, with Kristoffer Haugsbakk providing review.

The changes systematically reformat the submodule documentation to use consistent AsciiDoc syntax, including:
- Converting command synopses to the new `[synopsis]` block format
- Using `_<placeholder>_` notation for arguments
- Replacing manual formatting with proper AsciiDoc macros (e.g. `NOTE:` instead of `*NOTE*`)
- Standardizing option presentation to stuck form (`--option=<value>`)
- Converting inline lists to definition lists for better readability

The patch maintains compatibility with both asciidoc.py and asciidoctor toolchains while improving the rendering quality. It focuses exclusively on presentation changes - no command behavior is altered. The conversion follows established conventions from previous documentation conversions in this series, particularly the gitcli(7) style for option formatting.

Key technical details include proper handling of submodule command variants (add/update/status etc.), consistent formatting of placeholders and variables, and conversion of the complex `update` command's procedural options into a clearer definition list structure. The patch has already been reviewed and carries Kristoffer Haugsbakk's Reviewed-by tag, indicating it meets the project's documentation standards.
