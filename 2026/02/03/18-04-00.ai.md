Bugfix for `git stash`'s handling of ignored files, addressing a long-standing FIXME where it unconditionally overwrote ignored files during index updates. This is the third version of Pushkar Singh's patch to add `--overwrite-ignore` and `--no-overwrite-ignore` options to `git stash push/save`, defaulting to overwrite for backward compatibility.

The v3 patch incorporates feedback from multiple reviewers. It now uses proper test helpers (`test_grep` and `test_path_is_missing`) as suggested by D. Ben Knoble, and has been rebased onto current master. The core change remains the same: when `--no-overwrite-ignore` is given with `-a/--all`, the patch downgrades the `INCLUDE_ALL_FILES` flag to just include-untracked to preserve ignored files as requested.

The implementation modifies `builtin/stash.c` to handle the interaction between include-untracked modes and the new overwrite behavior, while the test changes in `t/t3905-stash-include-untracked.sh` add regression tests covering both overwrite and no-overwrite cases. Elijah Newren's earlier concerns about the silent downgrade behavior potentially masking design issues remain unaddressed in this revision, suggesting this may need another iteration before being ready for inclusion.
