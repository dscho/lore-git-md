This is a documentation patch in Jean-Noël Avila's ongoing effort to convert Git man pages to consistent AsciiDoc synopsis-style formatting. The patch focuses on `git-clone.adoc` and `for-each-ref-options.adoc`, with minor tweaks to `ref-storage-format.adoc`.

Key changes include standardizing option presentation to use stuck-form (`--option=<value>`) consistently throughout `git-clone.adoc`, as previously endorsed by Junio Hamano. The patch also converts manual `*NOTE*` markup to proper AsciiDoc `NOTE:` macros, fixes placeholder formatting (`_<name>_`), and ensures imperative mood for option descriptions. Notable adjustments include splitting `--[no-]reject-shallow` into two explicit options and standardizing the presentation of configuration-related options like `-c<key>=<value>`.

The changes maintain cross-toolchain compatibility between asciidoc.py and asciidoctor while improving documentation clarity. Kristoffer Haugsbakk has reviewed and signed off on the changes. This work is part of a larger v3 series that includes conversions of several other man pages (`git-submodule`, `git-show`, etc.), with each iteration systematically improving formatting details across the targeted documentation.
