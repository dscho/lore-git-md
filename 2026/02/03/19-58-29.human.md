This is a documentation patch clarifying the behavior of `git format-patch --no-renames`. Chris Packham notes that while the man page mentions this option overrides configuration, it's unclear which specific diff configuration option controls rename detection for format-patch.

The patch highlights a practical use case - wanting different rename detection behavior between interactive diff viewing (where renames are helpful) and patch generation (where compatibility with basic `patch` commands is needed). The current documentation doesn't make clear whether format-patch shares the same diff.renames configuration as regular diffs.

The email suggests this could be clarified in the documentation, though no actual patch is included in this initial inquiry. This appears to be a straightforward documentation improvement that would help users understand the relationship between format-patch's rename detection and Git's general diff configuration.
