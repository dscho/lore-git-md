This is a refactoring patch that extends Coccinelle rules for converting memset() calls to the newer MEMZERO_ARRAY() macro. The patch comes from Toon Claes, who originally introduced the MEMZERO_ARRAY() macro in December with Junio Hamano's improvements.

The patch makes several technical improvements to the Coccinelle rules:
1. Expands pattern matching to catch more variants of memset() calls that can be converted to MEMZERO_ARRAY()
2. Handles additional cases where parentheses can be safely removed
3. Fixes indentation in converted code (spaces to tabs)
4. Updates a few existing MEMZERO_ARRAY() calls to remove now-unnecessary parentheses

The author notes this is somewhat belated (the original work was done months ago) and expresses ambivalence about whether the patch is still worth applying. The changes are clean and mechanical, following the established pattern of the original conversion. The patch touches only three files: the Coccinelle rule definition and two implementation files where parentheses were cleaned up.
