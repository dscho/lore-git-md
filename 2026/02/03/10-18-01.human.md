This patch introduces per-URL configuration for sideband control character sanitization, addressing security concerns around ANSI escape sequence injection (CVE-2024-32002, CVE-2024-52005). Johannes Schindelin implements Junio Hamano's suggestion to allow scoping the `sideband.allowControlCharacters` setting to specific URLs, similar to how `http.<url>.*` works.

The change enables administrators to maintain secure defaults while permitting trusted servers to send control sequences (like colored error messages from `pre-receive` hooks). The implementation adds URL-specific configuration handling in `sideband.c` and exposes new public functions in `sideband.h` for transport code to apply these settings. Tests verify that URL-specific overrides work as expected.

This is part of a mature v4 series that has seen production validation in Git for Windows and Red Hat environments. The patch maintains security while accommodating real-world use cases, though the broader debate continues about whether secure-by-default behavior should wait for Git 3.0. The implementation is clean and well-tested, with clear documentation of the new URL-scoped configuration options.
