This is a CI infrastructure update from the Git maintainer, Junio C Hamano, regarding test coverage for contrib/ components. The email follows up on an earlier proposal to expand CI testing to include contrib/ scripts like `git-subtree` and `diff-highlight`.

Junio reports that enabling these tests has uncovered multiple existing issues across different configurations (SHA-256, leaks, reftable, ASAN). While some failures might be due to in-flight topics in the 'seen' branch, others appear to be long-standing problems that went unnoticed because these tests weren't previously run in CI.

The maintainer has temporarily limited the contrib/ testing to just the linux-TEST-vars and *-breaking-changes CI jobs, which are currently passing, while asking for help from contributors familiar with the subtree component to investigate the failures. He specifically points to a test run showing these issues and CCs recent contributors to the subtree test file along with the project's reftable expert (likely Patrick Steinhardt or Karthik Nayak).

This email highlights both the value of expanded CI testing (catching previously unknown issues) and the maintenance challenges of contrib/ components that lack dedicated subsystem maintainers. The thread shows the project's careful approach to infrastructure changes - testing incrementally and seeking community input when problems surface.
