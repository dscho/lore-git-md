This is a refactoring patch that extends and improves the Coccinelle semantic rules for converting `memset()` calls to the `MEMZERO_ARRAY()` macro. The patch comes from Junio Hamano in response to Toon Claes' earlier work on this conversion.

The changes expand the pattern matching in `contrib/coccinelle/memzero-array.cocci` to catch more variants of `memset()` calls that can be converted, including handling different forms of the size calculation (with and without parentheses) and different zero representations (0, 0x0, '\0'). The patch also fixes style issues in existing `MEMZERO_ARRAY()` calls by removing unnecessary parentheses and correcting indentation (converting spaces to tabs).

Junio notes some quirks in the Coccinelle pattern matching - it handles some equivalent forms (like 0 vs 0x0) but not others (like '\0' vs 0 or operand ordering in multiplications). Despite these limitations, he finds the changes worthwhile and queues the patch. The changes touch three files: the Coccinelle rule file itself, plus `diffcore-delta.c` and `ewah/bitmap.c` where existing macro calls are cleaned up.

This continues the project's ongoing effort to use Coccinelle for code hygiene improvements, building on work from December when the `MEMZERO_ARRAY()` macro was first introduced. The patch is straightforward and uncontroversial, addressing minor but clear improvements to the automated conversion rules.
