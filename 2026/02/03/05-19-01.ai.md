This is a platform compatibility patch addressing compiler warnings introduced by glibc 2.43's stricter const-correctness for string functions. The change makes `git_find_last_dir_sep()` return a `const char*` to match the behavior of `strrchr()` under C23, fixing warnings when compiling with GCC 15's default `-std=gnu23`.

The patch updates the function declaration in `git-compat-util.h` and modifies callers in `config.c`, `remote.c`, `scalar.c`, and `strbuf.c` to handle the new return type. The only place needing an explicit cast is in `remote.c` where the result is modified. The change is straightforward and well-contained, with the commit message clearly explaining both the technical background (glibc's C23 compliance changes) and the practical impact (warning elimination).
