This is a documentation patch series continuing Jean-Noël Avila's effort to standardize Git man pages into consistent AsciiDoc synopsis-style formatting. The v3 series converts `git-submodule` and `git-show` documentation while fixing style issues in previously converted pages like `git-clone` and `for-each-ref-options`.

The changes focus on presentation improvements without altering command behavior:
- Standardizing option formatting (e.g., converting `--[no-]` to explicit `--reject-shallow`/`--no-reject-shallow`)
- Using proper AsciiDoc macros instead of manual markup
- Fixing placeholder formatting (e.g., `_<when>_`)
- Ensuring consistent imperative mood for option descriptions
- Addressing rendering issues with special characters in decoration options

Kristoffer Haugsbakk provided thorough review feedback that led to refinements in v3, particularly around the display of pointer symbols in `%(decorate:)` format specifiers and ensuring long option formatting aligns with Git's preferred "stuck form" convention (`--option=<value>`). The series maintains cross-toolchain compatibility between asciidoc.py and asciidoctor.

This is part of Avila's long-running documentation standardization effort, with each iteration systematically improving formatting details across multiple man pages. The patches show careful attention to technical accuracy while modernizing the documentation presentation.
