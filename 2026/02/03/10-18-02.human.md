Security patch deferring sideband sanitization default change to Git 3.0. This is the final patch in Johannes Schindelin's series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). While the technical implementation is complete - allowing configurable control over which ANSI sequences are permitted - this patch delays changing the default behavior from permissive to secure until Git 3.0.

The patch modifies documentation and tests to reflect that the secure-by-default behavior (which only allows ANSI color sequences by default) will now be deferred. This gives users and tools time to prepare for the breaking change. The implementation uses a `WITH_BREAKING_CHANGES` conditional to toggle between current and future behavior, with tests updated to explicitly enable sanitization when needed.

This comes after extensive discussion about the security/usability tradeoff, with Schindelin advocating for secure defaults while others preferred opt-in configuration. The series has seen production validation in Git for Windows and Red Hat systems. The architecture remains flexible enough to support both immediate needs and the planned Git 3.0 behavior change.
