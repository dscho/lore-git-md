This is a documentation patch converting the `git-submodule` man page to the new synopsis-style format as part of Jean-Noël Avila's ongoing standardization effort. The patch makes several systematic changes to improve consistency and readability:

1. Converts command syntax to use the new `[synopsis]` block format with proper command highlighting
2. Standardizes option presentation to stuck form (`--option=<value>`) per gitcli(7) conventions
3. Replaces manual formatting of placeholders with `_<name>_` markup
4. Converts inline lists to proper AsciiDoc definition lists
5. Improves cross-references by using proper linkgit macros
6. Fixes minor formatting inconsistencies throughout

The changes are purely presentational - no command behavior is altered. Kristoffer Haugsbakk has reviewed the changes, and this version incorporates feedback from earlier iterations of the patch series. The conversion follows the same pattern seen in other recently updated man pages like `git-clone` and `git-show`.

This patch is part of a larger v3 series (1/4) that standardizes multiple man pages. The work demonstrates careful attention to detail in maintaining cross-toolchain compatibility between asciidoc.py and asciidoctor while improving documentation consistency.
