Junio Hamano's latest "What's cooking" report provides a snapshot of Git's development status, highlighting merged documentation updates, performance improvements like `git diff --anchored` optimizations, and major ongoing efforts including Patrick Steinhardt's ODB abstraction work and René Scharfe's `the_repository` removal patches. The report also notes several user-facing feature developments and infrastructure improvements.

Derrick Stolee, known for his graph algorithm expertise, has now contributed a performance optimization adding a `--maximal-only` option to `git rev-list`. This option efficiently identifies root commits or the most recent commits in disconnected subgraphs, which could benefit repository analysis tools. Stolee reports the patch has been stable in testing and recommends moving it to the 'next' branch. Given his track record with graph optimizations and the focused nature of this addition, it appears to be a low-risk but useful enhancement for certain history query patterns.
