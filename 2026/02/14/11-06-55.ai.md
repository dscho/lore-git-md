This is the final patch in a 4-part series introducing a `--no-auto-advance` option for interactive patch selection commands (`add -p`, `checkout -p`, `reset -p`, `stash -p`). The option allows manual navigation between files during interactive patch selection rather than automatically advancing after processing all hunks in a file.

The patch implements the core navigation behavior:
- Adds '>' and '<' commands to move between files when `--no-auto-advance` is active
- Shows a hunk summary when all hunks in a file are decided (total hunks, used, skipped)
- Maintains existing behavior when auto-advance is enabled (default)
- Includes comprehensive tests verifying the new functionality across multiple files and commands

The implementation extends the interactive patch selection UI while maintaining backward compatibility. Changes are well-scoped to the `add-patch.c` core and include thorough test coverage in `t3701-add-interactive.sh`. The patch completes the series by delivering the promised navigation features after the preparatory refactoring in earlier patches.

This provides useful flexibility for users who want to review changes across multiple files before finalizing their selections, while preserving the familiar auto-advance behavior for existing workflows. The series has evolved through multiple review rounds with this final version addressing feedback on edge cases and test coverage.
