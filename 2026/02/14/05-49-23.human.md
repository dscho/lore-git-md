Bugfix for `git format-patch`'s cover letter handling. This small patch corrects the "From" header in cover letters when the `--from` option is specified. Currently, the cover letter ignores the `--from` value and always uses the committer identity, while the individual patch emails respect the override. The fix is straightforward - just a one-line change to check the config's `from` field before falling back to the committer info.

The patch is minimal and clearly motivated, though it lacks test coverage (which would be useful to prevent regression). This seems like a clear improvement that should be uncontroversial to merge. The author (Mroik) is not a frequent contributor, but the change is simple enough that this shouldn't raise concerns.
