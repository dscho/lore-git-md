This is part of a series introducing a `--auto-advance` option for interactive patch selection commands (`add -p`, `checkout -p`, etc.), currently at version 5. The patch modifies the internal `patch_update_file()` function signature to support manual file navigation when `--no-auto-advance` is used.

The change replaces direct `file_diff` pointer access with index-based lookup, allowing the function to track and return the current file position. This enables future patches to implement 'next' and 'previous' file navigation commands. The patch maintains existing behavior while preparing the infrastructure for the new feature.

The implementation is clean and focused, with clear commit message explaining the motivation. It's part of a well-structured series that has evolved through several review rounds, addressing feedback on code organization. The change touches core interactive patch machinery but does so in a way that preserves the current default behavior.
