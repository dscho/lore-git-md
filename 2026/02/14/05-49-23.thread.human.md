This thread addressed a bug in `git format-patch` where the `--from` option (for specifying an alternative sender identity) worked correctly for individual patches but was ignored in cover letters. The inconsistency has been fixed after four iterations, with the v4 patch approved by Junio Hamano for merging. The small but focused change ensures `--from` now applies consistently to both patches and cover letters, with updated documentation and test coverage confirming the fix.

Key contributors included original author Mirko Faina, who incorporated feedback through multiple versions, and reviewers Patrick Steinhardt and Jeff King who verified the technical soundness. Jeff King—who originally implemented the `--from` feature in 2013—later added some amusing historical context, noting that the bug went unnoticed for nearly a decade because most users generate cover letters directly via `format-patch` rather than `send-email`, and the feature itself sees relatively little use. While the thread concluded with the fix ready to merge, Junio flagged two follow-up documentation improvements for future work.
