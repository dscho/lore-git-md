This thread addresses a bug in `git format-patch` where the `--from` option (for specifying an alternative sender identity) was correctly applied to individual patches but ignored in cover letters, creating an inconsistency. The issue was reported and fixed by Mirko Faina, with the patch now in its second iteration.

The technical fix modifies `make_cover_letter()` in `builtin/log.c` to properly respect the `--from` configuration, with improved variable naming and test coverage added in t4014-format-patch.sh. The change is small (6 lines) and focused, with no technical objections remaining.

Reviewers - including Junio Hamano, Patrick Steinhardt, and now Jeff King - have confirmed the solution is sound. Jeff King noted the documentation's current wording ("each commit email") dates back to his 2013 implementation and should be updated to explicitly include cover letters, matching the now-consistent behavior. This was the last remaining refinement needed before merging.

The thread shows clear consensus that this is a straightforward improvement worth incorporating. With all maintainer feedback addressed and only minor documentation clarifications remaining, this fix is likely to be merged in the next cycle.
