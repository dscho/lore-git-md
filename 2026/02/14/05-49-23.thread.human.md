This thread addresses a bug in `git format-patch` where the `--from` option (which sets an alternative sender identity) was correctly applied to individual patches but not to cover letters in a series. The inconsistency has been fixed in the third version of the patch, which ensures the From header in cover letters respects the `--from` option just like the individual patches do.

The fix modifies `builtin/log.c` to properly check the configured `from` value before falling back to default committer information, with accompanying test coverage in t4014. Documentation has also been updated to clarify that `--from` applies to both patches and cover letters. The patch is small (6 lines modified) and focused, with all technical feedback from reviewers like Junio Hamano, Patrick Steinhardt, and Jeff King already addressed in previous versions.

This version appears ready for merging. The author notes it's a resend of the previous version (v3 marking was accidentally omitted before) with only a sender name correction. Junio has suggested two follow-up improvements: updating the cover letter's patch listing format and ensuring commit message clarity, but these can be addressed separately. The core fix resolves the inconsistency that was the original motivation for the patch.
