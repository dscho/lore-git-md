This is a bugfix for `git format-patch`'s cover letter generation. The patch corrects an issue where the `--from` option (which allows specifying an alternative sender identity) was not being respected in the cover letter's From header, even though it worked correctly for individual patches in the series.

The fix is straightforward - when generating the cover letter, it now checks for a configured `from` value in the `cfg` struct (which would be set by `--from`) before falling back to the default committer info. The change is minimal (a one-line modification in `builtin/log.c`) and appears well-contained.
