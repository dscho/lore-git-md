Refactoring patch in the reference backend switching series, now moving stub creation/deletion to generic layer. This is part of the larger effort to enable zero-downtime migrations between ref backends (files<->reftable), with GitLab's deployment needs being a key driver.

It also handles a special case for the files backend to avoid redundant stub deletion when cleaning up packed refs. The changes maintain existing functionality while preparing for upcoming support of alternate reference directories.
