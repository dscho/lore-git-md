This is a feature patch series introducing a new `--auto-advance` option for interactive patch selection in Git commands like `add -p`, `checkout -p`, and `reset -p`. The series is now in its fifth iteration, with the option renamed from earlier versions to better reflect its behavior.

The core change adds a `--no-auto-advance` flag that prevents automatic progression to the next file after processing hunks, allowing users to manually navigate between files using '>' (next file) and '<' (previous file) commands. The default `--auto-advance` maintains the current behavior of automatically moving to the next file.

The implementation touches several interactive commands by adding the new option to their argument parsing. The series also includes preparatory refactoring - moving the patch application logic into a reusable function and modifying `patch_update_file()` to work with file indices rather than direct `file_diff` references.
