Refactoring patch in the `--auto-advance` interactive patch series.

This is the second patch in a 4-part series introducing a `--auto-advance` option for interactive patch commands (`add -p`, `checkout -p`, etc.). The patch modifies the signature of `patch_update_file()` to work with file indices rather than direct `file_diff` pointers, preparing for the upcoming navigation commands ('>' and '<') that will allow manual movement between files when auto-advance is disabled.

The changes are mechanical but important for the series' goal: the function now takes and returns indices rather than pointers, which will let callers track and control position in the file list. The patch maintains all existing behavior while enabling the planned navigation features. Test coverage for the new functionality appears in later patches of the series.

The implementation looks clean and focused - it changes only what's needed to support the navigation commands while preserving the current auto-advance behavior.
