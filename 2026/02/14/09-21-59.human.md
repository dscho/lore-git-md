Performance optimization discussion for `sendfile()` implementation in file copying. George Hu responds to Chris Torek's suggestion about making the `sendfile()` check feature-based rather than Linux-specific, pointing out that while both Linux and BSD support `sendfile()`, their APIs differ significantly. The Linux version takes simpler parameters (output fd, input fd, offset, count) while FreeBSD's has additional complexity (hdtr structure, sbytes output, flags). This suggests a truly portable implementation would need to handle these API variations, making the original Linux-specific approach potentially simpler to maintain despite being less general. The exchange remains technical and constructive, focused on implementation tradeoffs rather than questioning the optimization's value.
