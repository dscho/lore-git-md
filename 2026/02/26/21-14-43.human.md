This is patch 6/10 in Eslam Reda Ragheb's series enhancing `git repo info` with structured repository metrics. The series aims to provide programmatic access to repository information through a clean interface, replacing shell-outs to `git rev-parse`.

This particular patch adds aggregate totals to the key-value output format, including:
- Total reference count (summing branches, tags, remotes, and other refs)
- Total object count (summing commits, trees, blobs, and tags)
- Total inflated size (sum of all objects' inflated sizes)
- Total disk size (sum of all objects' on-disk sizes)

The patch maintains consistency between machine-readable output and human-readable table summaries while eliminating the need for callers to recompute these sums themselves. The implementation builds on existing helper functions for calculating object metrics and follows the series' pattern of careful memory management and structured output.

The changes are straightforward, adding new printf statements alongside the per-type metrics that were already being output. The patch continues the series' focus on creating a robust programmatic interface for repository information, with particular attention to scripting ergonomics.
