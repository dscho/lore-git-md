Bugfix for memory leaks in UTF-8 alias subsection implementation. This is part of the ongoing effort to support UTF-8 in Git configuration subsections (like `[alias "förgrena"]`), which is currently in its 7th iteration and merged into the `next` branch.

Jacob Keller confirms that Junio Hamano's proposed fixes for memory leaks in both `git.c` and `help.c` paths look correct. The leaks occurred when listing aliases, where alias command values stored in the string list's util field weren't being properly freed. The fix changes `string_list_clear()` and `string_list_remove_duplicates()` calls to free these util pointers.

This addresses the last significant technical issue in the series, leaving only one remaining regression regarding dot-prefixed aliases (like `.foobar`) that affects Johannes Schindelin's workflow. The patch series appears ready for final merge once that edge case is resolved. The implementation maintains all existing functionality while properly handling memory management for the new UTF-8 alias support.
