This is a GSoC 2026 proposal from Jayatheerth Kulkarni to enhance the experimental `git repo info` command, building on Lucas Oshiro's GSoC 2025 work. The proposal focuses on two main technical objectives: adding path-related functionality (git-dir, common-dir, toplevel, etc.) to replace `git rev-parse` usage, and removing reliance on the `the_repository` global in builtin/repo.c as part of Git's broader libification effort.

The proposal demonstrates strong preparation, with Kulkarni having already contributed several merged patches to Git (including fixes for stash messaging and submodule path handling) and completed micro-projects related to the target code. The timeline accounts for Git mailing list review realities, with Phase 1 (path implementation) scheduled for May-July and Phase 2 (global removal) in July-August, plus buffer time for iteration. Stretch goals include category-based queries and git-sizer integration if time permits.

Notable technical details for future summarizer: the work touches builtin/repo.c (global state), path.c/setup.c (path resolution), and test updates in t/. The path implementation would add equivalents to `rev-parse`'s --git-path values, while the libification work specifically targets the `USE_THE_REPOSITORY_VARIABLE` macro and functions like `get_layout_bare()` that currently ignore their repository parameter. The proposal connects to both the `git repo info` command's evolution and the project-wide `the_repository` removal effort.
