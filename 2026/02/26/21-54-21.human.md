This is a follow-up in the thread about adding push group functionality to match fetch groups. The original proposal from Junio identified an inconsistency where `git push group` fails while `git fetch group` works when a remote group is defined in config. Usman Akinyemi had volunteered to implement the change back in September 2025, but here Junio checks in 5 months later to see if any progress was made.

The change would involve refactoring the remote group handling code from builtin/fetch.c into remote.c to make it shareable with push, then modifying builtin/push.c to use this shared infrastructure. While conceptually straightforward, this is a non-trivial change that would touch multiple core files.

Junio's brief check-in suggests this is still an open item on the project's radar, though there's no indication yet whether Usman has started work or run into obstacles. The thread remains in an early state - we're still waiting for the first implementation patches to appear for review.
