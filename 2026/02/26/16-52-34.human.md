This is a patch series (v7) adding `--trailer` support to `git rebase`, allowing automatic trailer (e.g. Signed-off-by) appending during rebase operations. The series is now in its 7th iteration, with the first five patches posted.

The core goal is to enable in-process trailer manipulation during rebase by refactoring trailer handling to be reusable across commands. The series extracts core trailer logic into a new `process_trailers()` helper, moves it to `trailer.c`, and introduces `amend_strbuf_with_trailers()` for in-process trailer application. It also refactors `--trailer` argument parsing in `git commit` and `git tag` to use `OPT_STRVEC`.

The `rebase --trailer` implementation works only with the merge backend (rejecting `--apply`), implies `--force-rebase` to rewrite fast-forwarded commits, and handles both interactive and non-interactive rebases while preserving trailers through conflict resolution. The series maintains backward compatibility while simplifying code.
