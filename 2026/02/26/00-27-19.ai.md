This is a refactoring patch in the fsmonitor series, specifically part 6 of 10 in version 7. The patch focuses on consolidating Unix platform settings logic for fsmonitor by renaming and generalizing the macOS-specific implementation to work across Unix variants.

The key changes:
- Renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` with improved path handling using `xstrdup()` and `dirname()`
- Adds vfat filesystem to the incompatible filesystem checks
- Updates build configurations (Makefile, CMake, meson) to use the unified Unix settings
- Sets `FSMONITOR_OS_SETTINGS=unix` for macOS in `config.mak.uname`
- Removes redundant conditionals from build files by using the new unified settings variable

The patch builds on previous work to deduplicate fsmonitor IPC logic between Unix platforms, now extending that unification to the settings checking code. It maintains all existing functionality while making the code more maintainable across Unix variants. The changes are mechanical but important for long-term maintenance as the fsmonitor feature expands to more platforms.
