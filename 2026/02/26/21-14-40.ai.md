Feature patch adding path format control to `git repo info`. This is patch 3/10 in Eslam Reda Ragheb's series enhancing repository path reporting.

The patch introduces a `--path-format` option that lets callers explicitly request either absolute or relative paths in the output. This matches existing `git rev-parse` behavior while centralizing the path conversion logic in the new `repo_info_add_path()` helper. The implementation handles relative path conversion safely using `xgetcwd()` and `relative_path()`, with proper cleanup of allocated resources.

Key technical details:
- Adds `enum path_format` with ABSOLUTE/RELATIVE variants
- Extends `struct repo_info` to track the format preference
- Implements path conversion in `repo_info_add_path()` using existing Git path utilities
- Includes new `parse_path_format_cb()` option parser
- Maintains memory safety with `STRBUF_INIT` and proper cleanup
- Updates command usage documentation to reflect the new option

This builds on the series' foundation by providing script-friendly control over path presentation while keeping the actual path resolution logic centralized. The change is part of the broader effort to create a robust programmatic interface for repository information that can replace shell-outs to `git rev-parse`.
