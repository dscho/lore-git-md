This is patch 4/10 in a feature series enhancing `git repo info` with structured repository metrics. The patch adds tracking of maximum object sizes (both inflated and on-disk) per object type (commit, tree, blob, tag) and overall.

The implementation extends the existing object statistics infrastructure in `builtin/repo.c` to track these maxima while walking reachable objects. It adds new fields to `struct object_stats` for the maximum sizes and updates the table and key-value output formats to display them. The changes include:

- New `max_inflated_sizes` and `max_disk_sizes` struct fields
- Helper function `get_max_object_value()` to find the largest value across object types
- Updates to both human-readable table output and machine-readable key-value output
- Careful handling of size tracking during object enumeration
