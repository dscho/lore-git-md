This is a refactoring patch in preparation for adding configurable branch comparison to `git status`. It's the first of two patches in the final version of Harald Nordgren's feature, which has gone through 28 iterations of review.

The patch extracts the branch comparison formatting logic from `format_tracking_info()` into a new `format_branch_comparison()` function. The refactoring:

1. Separates the branch state analysis (done in `format_tracking_info`) from the message formatting (now in `format_branch_comparison`)
2. Makes the formatting logic reusable for multiple branch comparisons (needed for the upcoming push remote support)
3. Preserves all existing behavior including:
   - Up-to-date messages
   - Ahead/behind counts
   - Diverged branch warnings
   - Advice hints

The changes are mechanical and don't alter functionality - all test cases would pass both before and after this change. The diff shows the core movement of code from the original function to the new helper, with parameter adjustments to make the formatting self-contained.

This is the final version that has been reviewed by Junio Hamano and Jeff King, with all style issues addressed (brace usage, line lengths, etc). The patch is now cleared for merging as part of the configurable branch comparison feature.
