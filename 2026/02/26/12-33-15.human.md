This is a feature patch for gitk, the Git repository browser GUI. The patch adds a new color configuration option to gitk's Preferences dialog, allowing users to customize the foreground color of links in the `linkfgcolor` variable). 

The motivation comes from dark theme users who find the default link color hard to read against dark backgrounds. Currently, this is the only color in gitk that wasn't configurable through the GUI, requiring manual code edits to change. The patch adds a simple color picker button in the Colors tab of Preferences, matching the existing UI for other color settings.

The change is straightforward - it adds the new control alongside existing color pickers and ensures the selected color is applied to link text. The patch is small (10 lines changed) and well-contained to the gitk Tcl script. It includes a clear commit message explaining the problem and solution.

This appears to be a useful quality-of-life improvement for gitk users, particularly those using dark themes. The patch is cleanly implemented and unlikely to be controversial. It's worth noting that gitk is maintained separately from core Git (by Johannes Sixt), so this would need his review/approval.
