This is a test patch in the ongoing "[PATCH v4 0/N] repo: enhanced repository path reporting" series from Eslam Reda Ragheb. The patch extends test coverage for repository structure metrics in t1901-repo-structure.sh.

The test now validates both human-readable table output and machine-readable key-value format for an expanded set of metrics, including maximum object sizes, commit parent counts, tree entry counts, blob path lengths/depths, and tag chain lengths. The test helpers have been significantly expanded to calculate these metrics independently for verification.

Key technical aspects:
- Adds 10 new test helper functions to calculate metrics like max_inflated_size, tag_chain_depth, commit_parent_count etc.
- Makes tests more portable by avoiding assumptions about hash algorithms and platform-specific output formats
- Verifies both human-readable table output and machine-parsable key-value format
- Maintains compatibility with SHA-1 while being ready for SHA-256
- Handles edge cases like empty repositories and malformed objects

The patch continues the series' focus on creating robust programmatic access to repository metrics while maintaining test coverage. It builds on the earlier path reporting tests while adding the structural metrics verification that was noted as outstanding in previous versions. The test helpers follow Git's established patterns for metric calculation while being careful about portability concerns.
