This is the final implementation patch for Harald Nordgren's configurable branch comparison feature in `git status`, now ready for merging after 28 iterations of review. The patch adds the `status.compareBranches` configuration option that allows users to specify which remote branches to compare against (defaulting to just @{upstream} for backward compatibility). The implementation handles @{upstream} and @{push} comparisons with proper deduplication, maintains all existing ahead/behind counting behavior, and includes comprehensive test coverage in t6040-tracking-info.sh.

The core changes are in remote.c's format_branch_comparison() with a new resolve_compare_branch() helper. The feature supports triangular workflows and includes appropriate advice messages. Junio Hamano has confirmed merge readiness after final style and organization tweaks, including renaming ENABLE_ADVICE_* flags to USE_ADVICE_* and separating advice applicability checks from user preferences. This represents a successful first contribution from Harald Nordgren, demonstrating persistence through Git's mailing list workflow.
