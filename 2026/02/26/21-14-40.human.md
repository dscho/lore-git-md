This is part 3 of a 10-patch series enhancing Git's repository path reporting capabilities. The series introduces a new `git repo info` command to provide structured access to repository paths, replacing shell-outs to `git rev-parse`.

The current patch adds a `--path-format` option to control whether paths are output as absolute or relative. This gives callers explicit control over path formatting, matching existing `rev-parse` behavior while centralizing the logic in the new command. The implementation uses `relative_path()` for relative formatting and maintains the default absolute path behavior.

The change is cleanly implemented with:
- A new `path_format` enum in `struct repo_info`
- Callback-based option parsing
- Proper memory management via `strbuf` and `xgetcwd()`
- Integration with the existing path resolution infrastructure

This continues the series' pattern of careful, well-documented additions to the repository introspection capabilities. The patch appears technically sound with clear motivation and maintains consistency with the broader effort to provide structured repository information.
