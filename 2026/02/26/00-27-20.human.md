This is the 7th version of a patch series implementing Linux support for Git's filesystem monitoring (fsmonitor) using inotify, bringing Linux to parity with existing Windows and macOS backends. The implementation enables faster status operations by watching filesystem events rather than performing full directory scans.

The patch adds the core inotify listener implementation that:
- Uses inotify_init1(O_NONBLOCK) with a poll loop to monitor events
- Maintains bidirectional watch descriptor <-> path mappings
- Handles directory renames via inotify's cookie mechanism
- Detects remote filesystems via statfs() and falls back to $HOME for IPC sockets when needed
- Includes comprehensive test coverage for event delivery and race conditions

This version addresses feedback from previous iterations, fixing memory leaks, improving error handling, and adding timeout handling to prevent hangs. The implementation is now stable in Junio's 'seen' branch with production testing showing good results. The patch represents a significant final piece in bringing full fsmonitor support to Linux.
