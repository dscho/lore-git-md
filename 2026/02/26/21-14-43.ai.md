Feature patch adding aggregate metrics to repository structure output. This is patch 6/10 in Eslam Reda Ragheb's v4 series enhancing `git repo info` with structured repository metrics.

The patch adds four new aggregate totals to the key-value output: total reference count, total object count, total inflated size, and total disk size. These complement the existing per-type metrics (counts and sizes for commits, trees, blobs, and tags) while maintaining the same output format. The implementation uses new helper functions (`get_total_reference_count()` and `get_total_object_values()`) to compute the sums.

This change improves scripting ergonomics by eliminating the need for callers to recompute these sums themselves. It also keeps the machine-readable output aligned with the human-readable table format that already includes these totals. The patch follows the series' pattern of careful memory management and consistent output formatting.

The series as a whole is part of the effort to provide better programmatic access to repository information, replacing shell-outs to `git rev-parse`. This particular addition focuses on making the metrics output complete and convenient for consumers. The implementation appears straightforward and well-contained, building on the existing metrics infrastructure from earlier patches in the series.
