This is a platform compatibility patch adding Windows support for timed condition variable waits, part of the larger fsmonitor effort to bring Linux support to parity with existing Windows and macOS backends.

Paul Tarjan contributes a Windows implementation of `pthread_cond_timedwait()` using the native `SleepConditionVariableCS()` API. The implementation converts the absolute timeout from `struct timespec` to milliseconds and handles the `ETIMEDOUT` case correctly. This enables bounded waits on condition variables in the fsmonitor IPC synchronization code, preventing potential hangs.

The change is straightforward and well-contained, adding just 26 lines to the Windows pthread compatibility layer. It follows the established pattern of the existing `pthread_cond_wait()` implementation in the same file. The patch is part of the v7 series that has already addressed extensive review feedback and is now in Junio's 'seen' branch.
