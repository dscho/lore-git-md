This is a follow-up patch series addressing final issues in the UTF-8 alias subsection implementation, now in its seventh iteration. The series fixes three small but important problems that surfaced after the main functionality was merged into `next`.

The first patch corrects a documentation formatting issue where list continuation markers (`+`) were incorrectly rendering in the HTML output of the alias subsection examples. The second ensures empty subsections like `[alias ""]` are treated the same as plain `[alias]` sections for backward compatibility. The third and most significant patch fixes memory leaks in the alias listing functionality that were introduced by earlier changes - this addresses issues in both `git.c` and `help.c` paths where allocated util pointers weren't being freed.

The series comes from Jonatan Holmgren, who has been driving this UTF-8 alias subsection effort, with fixes based on reports from Jacob Keller (memory leaks) and review feedback from Junio Hamano. While the core UTF-8 functionality is working well, this cleanup round shows the careful attention to detail needed before final merging - particularly for memory management in code paths that handle configuration. The patches are straightforward and well-explained, addressing the last remaining issues before this feature can be considered complete.
