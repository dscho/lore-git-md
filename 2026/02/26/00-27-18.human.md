This is part of the ongoing fsmonitor series adding Linux support for filesystem monitoring. The patch focuses on code deduplication between Unix platforms (macOS and Linux).

Paul Tarjan's patch renames the macOS-specific IPC path handling code to be Unix-generic (`fsm-ipc-darwin.c` -> `fsm-ipc-unix.c`), since the logic applies to both platforms. It introduces a new `FSMONITOR_OS_SETTINGS` build variable to distinguish between platform-agnostic Unix settings and backend-specific implementations. The change also adds a missing BUG guard for NULL worktree cases that was absent in the original macOS version.

The patch affects build system configurations (Makefile, CMake, meson) to handle the new file naming and variable scheme. This is a clean refactoring that follows the series' theme of consolidating common Unix platform logic while maintaining clear separation for Windows-specific code paths. The changes are straightforward and well-contained, continuing the series' trend of addressing review feedback through incremental improvements.
