This is a feature patch series enhancing the `git repo info` command with improved path reporting capabilities. The v4 iteration focuses solely on path-related functionality after splitting out structural metrics into a separate series.

The key additions in this series include:
- Category-aware key expansion (e.g. "layout" expands to "layout.*")
- New path-oriented keys (path.*) for common repository locations
- A `--path-format` option to control absolute vs relative path output
- Comprehensive documentation of all 13 path fields and their behavior

The implementation avoids global state, aligning with the `the_repository` removal effort, and includes thorough test coverage in t1900-repo.sh. The changes aim to make `git repo info` more script-friendly by reducing the need for multiple plumbing calls while providing consistent path formatting.

Notably, this version drops all structural metric code that was present in v3, keeping the scope narrowly focused on path reporting. The author has coordinated with Justin Tobler's parallel work on repository structure analysis to avoid overlap. The patch series appears well-structured with clear commit separation and documentation updates.
