This is a memory leak fix for the UTF-8 alias subsection series that is currently in `next`. The patch addresses two memory leaks in the alias listing functionality that were introduced by earlier changes in the series.

The leaks occur when `list_aliases()` allocates util pointers but two callers (`git.c` and `help.c` paths) clear the list without freeing them. The fix changes `string_list_clear(&list, 0)` to `string_list_clear(&list, 1)` in `git.c` and updates `string_list_sort_u(list, 0)` to `string_list_sort_u(list, 1)` in `help.c` to ensure proper cleanup of heap-allocated alias command strings.
