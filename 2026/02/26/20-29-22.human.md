This is a refactoring patch from Taylor Blau that's part of a larger RFC series introducing incremental MIDX/bitmap-based repacking. The patch simplifies MIDX file cleanup code by replacing hand-rolled string arrays with `string_list` structures.

The change makes the code more maintainable by:
- Replacing manual array management with the standard `string_list` API
- Eliminating the need to track array lengths separately
- Using built-in string lookup rather than linear search
- Following Git's typical patterns for string handling

While the commit mentions potential performance benefits from faster lookups, the real value is in code organization - the number of MIDX files is typically small enough that the lookup speed difference won't matter. The patch touches two functions that clean up MIDX files, making them more consistent with each other and with Git's codebase conventions.
