This is patch 8/11 in a completed bugfix series for git-gui that has already received maintainer approval from Johannes Sixt. The series addresses long-standing issues with repository and worktree detection.

The specific patch fixes a regression where git-gui's browser mode would fail when run in a detached HEAD state. The issue stems from a 2024 change that switched from direct file reading to using `git branch --show-current` for refs (to support reftable backends), but didn't properly handle the empty output that command produces in detached HEAD states. The fix restores the previous behavior by explicitly setting the branch name to "HEAD" when detached.

The change is small (3 lines added) and clearly motivated, completing one of the edge cases the series set out to address. Since this is part of an already-approved series that has gone through multiple iterations, it can be considered ready for merging.
