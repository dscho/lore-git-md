This is a feature patch for the `git-jump` contrib script, now in its second version, implementing automatic mode selection when run without arguments. The patch builds on previous discussion to add an explicit "auto" mode that detects repository state and chooses the most appropriate action:

1. Uses "merge" mode if unmerged paths exist (detected via `git ls-files -u`)
2. Uses "diff" mode for unstaged changes (via `git diff --quiet`)
3. New in v2: Adds "ws" mode for whitespace errors (via `git diff --check`)
4. Falls back to showing usage if none apply

Key changes from v1:
- Added explicit "auto" mode instead of implicit behavior
- Incorporated whitespace error detection as a third condition
- Updated documentation to clarify the default behavior
- Maintains backward compatibility with explicit mode specification

The implementation remains clean and focused, using standard Git plumbing commands for detection. The patch appears ready for merging with consensus on the approach from Jeff King and documentation improvements from Erik Cervin Edin. The optional whitespace checking addition (new in v2) follows the same pattern as the other auto-detection cases.
