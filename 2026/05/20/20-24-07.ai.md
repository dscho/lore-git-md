This is patch 8/11 in a completed bugfix series for git-gui, addressing an edge case where the browser fails with a detached HEAD. The patch fixes a regression introduced in 2024 when git-gui switched from direct file access to using `git branch --show-current` for ref lookups (to support reftable backends).

The issue occurs because `git branch --show-current` returns an empty string for detached HEAD states, while git-gui's browser expects "HEAD" in this case. The fix adds special-case logic to explicitly set the branch name to "HEAD" when detached, restoring the pre-reftable behavior.

This is a straightforward one-liner that completes the reftable compatibility work while maintaining expected behavior. The patch has already been approved by git-gui maintainer Johannes Sixt as part of the v2 series, which means it represents the consensus solution after review. The change is minimal and focused, touching only the branch name handling without affecting other functionality.
