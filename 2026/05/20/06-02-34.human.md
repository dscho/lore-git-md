This is the final CI fix for the `--max-count-oldest` feature, addressing portability issues in the test suite. Junio C Hamano points out three specific problems in the test case for `--max-count-oldest` with graph/boundary output:

1. The test used `rm` rather than `rm -f` for cleanup, which could fail if the test didn't create the file
2. It piped `git log` output to `wc -l`, losing the command's exit status
3. It assumed `wc -l` output format is portable (GNU vs macOS differences)

The fix replaces these with more robust test patterns using `test_line_count` and proper cleanup. This is the last remaining issue before the feature can be merged, following eight previous iterations that refined the implementation, documentation, and test coverage. The patch maintains all the carefully designed characteristics of the sliding-window algorithm while ensuring the tests work across platforms.
