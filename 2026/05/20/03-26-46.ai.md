Final approval for dynamic mailmap toggling in `git cat-file`.

Junio Hamano gives the green light to Siddharth Asthana's v5 patch implementing mailmap toggling for `git cat-file --batch-command`, indicating it has addressed all previous review feedback and is ready for merging into the 'next' integration branch. The feature allows runtime control of mailmap name/email rewriting via a new `mailmap <bool>` subcommand, solving GitLab Gitaly's need to modify behavior in long-running processes without restarting them.

The implementation includes lazy-loaded mailmap caching, unified boolean parsing using `git_parse_maybe_bool()`, and comprehensive test coverage. All technical concerns from earlier rounds (documentation structure from Karthik Nayak, boolean parsing from Patrick Steinhardt, AsciiDoc formatting from Jean-Noël Avila) have been resolved. Junio's approval confirms the patch's readiness after multiple iterations, with no outstanding objections from reviewers. The change remains cleanly scoped to `builtin/cat-file.c` and its test suite.
