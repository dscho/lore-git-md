This is the first patch in an approved bugfix series for git-gui, addressing repository and worktree detection issues. The patch focuses on properly handling of GIT_DIR and GIT_WORK_TREE environment variables during git-gui operations.

The change introduces two new Tcl procedures (`set_gitdir_vars` and `unset_gitdir_vars`) to centralize management of these critical environment variables. The key improvements are:

1. Fixes a bug where empty GIT_WORK_TREE could be exported, which caused failures in Git commands like `git branch --show-current`
2. Ensures consistent handling of these variables across all code paths
3. Maintains compatibility with user-overridden environment settings
4. Preserves the ability to discover repositories when GIT_DIR isn't set

The patch replaces scattered direct environment variable manipulation with centralized procedures, making the code more robust while fixing edge cases. This is particularly important for bare repository operations and submodule handling. The changes are mechanical but important groundwork for the rest of the series.

As part of an already-approved series, this patch has been reviewed by git-gui maintainer Johannes Sixt and implements his requested changes. It demonstrates careful attention to edge cases while maintaining backward compatibility.
