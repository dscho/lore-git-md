This is a bugfix patch from Git maintainer Junio C Hamano that plugs a memory leak in the `apply.c` code. The issue occurs when `read_patch_file()` fails after having already read data into a `strbuf` buffer - the buffer wasn't being properly released in the error path.

The patch makes the caller (`apply_patch()`) responsible for releasing the `strbuf` when `read_patch_file()` fails, which simplifies the error handling. The change is small (just 3 lines added) but important for proper resource cleanup. This is the kind of careful attention to detail we regularly see from the maintainer in keeping Git's code clean.
