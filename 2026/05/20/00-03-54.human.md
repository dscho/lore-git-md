This is a review comment on the main feature patch in a series introducing external command execution for Git notes. Junio C Hamano raises two substantive concerns about the patch's motivation and structure.

First, he questions whether the proposed solution (external command execution) is the right approach to solve the TOCTOU race condition problem described in the commit message. He points out that similar race conditions exist in other parts of Git's history handling, and suggests that better merge support might be a more general solution.

Second, he challenges the patch's decision to split documentation and tests into separate commits, arguing that undocumented code is harder rather than easier to review. This suggests the patch may need restructuring to keep documentation and implementation together.

The review engages with the technical approach rather than surface-level issues, though Junio doesn't yet offer specific technical objections to the implementation itself. His comments indicate the patch may need stronger justification for its design choices and better integration of supporting materials before it can move forward.
