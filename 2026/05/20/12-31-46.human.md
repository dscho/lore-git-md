This is a feature patch for the `git-jump` contrib script, which helps navigate Git changes in an editor. The v2 patch builds on previous discussion by:

1. Adding an explicit "auto" mode that automatically selects between:
   - "merge" mode when unmerged paths exist
   - "diff" mode when unstaged changes exist
   - "ws" mode when whitespace errors are detected
   - Falls back to showing usage if none apply

2. Making "auto" the default behavior when no mode is specified, maintaining backward compatibility with explicit mode specification.

3. Adding documentation updates including a new example for whitespace checking.

The implementation uses standard Git plumbing commands (`git ls-files -u`, `git diff --quiet`, `git diff --check`) to detect repository state. The patch has already received positive feedback from Jeff King (Peff) on the core functionality and incorporates suggestions from Erik Cervin Edin regarding documentation and implementation structure.
