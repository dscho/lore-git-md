This is the final version of a bugfix series for git-gui, addressing long-standing issues with repository and worktree detection. The series has received maintainer approval from Johannes Sixt (git-gui maintainer) after extensive review iterations.

The key improvements in this v2 series include:
- Proper handling of bare repositories and missing worktrees
- More reliable repository picker behavior that doesn't mask configuration problems
- Corrected behavior when launching from .git directories
- Better compatibility with core Git's repository discovery rules
- Fixed parsing of blame/browser subcommand arguments in bare mode

The implementation now consistently uses `git rev-parse` for repository discovery, ensuring git-gui follows the same rules as command-line Git. Notable fixes include proper handling of detached HEAD states, Windows path resolution, and config loading sequence preservation.

This represents the culmination of a multi-iteration effort (previously at v7) to address issues dating back to 2014/2019 regressions. The patches touch core git-gui startup logic but focus on making existing behavior more robust rather than introducing new features. The series is now ready for merging.
