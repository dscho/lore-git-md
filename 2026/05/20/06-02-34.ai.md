This is a final CI fix for the `--max-count-oldest` feature, addressing portability issues in the test suite. Junio C Hamano points out three specific problems in the test script that caused CI failures:

1. The test used `rm` rather than `rm -f` for cleanup, which could fail if the file didn't exist
2. The test piped `git log` output through `wc -l`, losing the command's exit status
3. The `wc -l` output format isn't portable across platforms (macOS vs Linux)

The fix updates the test to use Git's `test_line_count` helper instead of `wc -l` and makes the cleanup more robust. This represents the last remaining issue before the feature can be merged, following eight previous iterations that refined the implementation and addressed all technical concerns. The patch maintains the feature's core functionality while ensuring it works reliably across platforms.
