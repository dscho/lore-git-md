This is the third patch in an 11-part bugfix series for git-gui, focusing on repository path handling. The patch simplifies git-gui's startup logic by using `git rev-parse --absolute-git-dir` instead of the relative path variant, eliminating the need for manual path resolution when running from the .git directory.

The change leverages a Git 2.31+ feature to always get absolute paths directly from rev-parse, removing a special case that previously converted "." to [pwd]. This makes the code more robust by ensuring consistent absolute path handling throughout git-gui's initialization. The patch removes 9 lines of now-unnecessary path conversion logic while maintaining identical behavior.

This is a straightforward technical improvement that aligns with the series' goal of making git-gui's repository detection more reliable. The change has already been reviewed and approved by git-gui maintainer Johannes Sixt as part of the complete series.
