This is a merge notification for Justin Tobler's ODB transaction interface rework series, which has now been approved for integration into the 'next' branch. The 7-patch series refactors Git's object writing interface to be more explicit and pluggable, with changes that enable future backend implementations while maintaining compatibility. The series has been through multiple review iterations and has now addressed a memory leak identified by Jeff King (Peff).

The changes include making `write_object_stream()` backend-aware, generalizing packfile writes via odb_write_stream, optimizing object writes by checking sizes upfront, and cleaning up transaction-related flags. This work is foundational for Patrick Steinhardt's in-memory ODB backend effort (ps/odb-in-memory) that builds on these changes. Junio Hamano confirms the series is now stable enough to merge, noting its importance as a dependency for other ongoing work.

The series represents a significant step in the larger ODB abstraction effort to make Git's object storage layer more modular. This approval clears the way for dependent work to progress while the changes bake in 'next' before eventual graduation to 'master'.
