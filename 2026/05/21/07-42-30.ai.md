This is the third patch in Patrick Steinhardt's 8-part series refactoring repository initialization and object database setup. The patch focuses on deduplicating the logic for applying repository format configurations.

The key change introduces a new `apply_repository_format()` function that centralizes the scattered logic for applying repository format settings (hash algorithm, ref storage format, worktree config, etc.) to a repository. Previously this logic was duplicated across three different call sites. The patch also renames `check_repository_format()` to `check_and_apply_repository_format()` to better reflect its dual purpose of both checking and application.

The changes touch core repository setup code in `repository.c` and `setup.c`, with corresponding updates to the header file. The refactoring maintains all existing behavior while making the code more maintainable - particularly important as this is groundwork for future extensions like pluggable object storage backends. The patch follows Patrick's characteristic careful approach, with each commit building logically on the last in this series aimed at cleaning up repository setup internals.
