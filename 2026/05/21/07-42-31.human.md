This is the fourth patch in Patrick Steinhardt's series refactoring repository initialization and object database setup. The patch removes object database initialization from `repo_set_gitdir()`, where it was somewhat hidden among other setup tasks, and moves it to more logical locations in `repo_init()` and `setup_git_env_internal()`.

The change simplifies the control flow by eliminating conditional initialization logic that was previously needed to handle multiple calls to `set_git_dir()`. While this introduces some temporary duplication (as noted in the commit message), the series will later consolidate this further when object database creation is tied to repository format application.

The patch follows Patrick's typical careful approach - each change is focused and well-explained, with clear mechanical transformations that don't change behavior. This continues the series' goal of making repository setup more maintainable and preparing for future pluggable storage backends.
