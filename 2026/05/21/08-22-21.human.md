This is the first patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch moves the `struct odb_source_loose` definition and its constructor function from `object-file.[ch]` to new files `odb/source-loose.[ch]`, following the same pattern used by other ODB sources.

The change is purely mechanical - no behavior is modified. It's the initial step in converting the loose object source to a proper `struct odb_source` that will integrate with Git's generic object storage layer interfaces. The patch demonstrates Patrick's characteristic careful approach, with clean separation of concerns and clear commit message explaining the motivation.

This foundational change sets up the subsequent patches that will wire up the loose object source to the ODB callback interface. The risk appears minimal since it's just code movement at this stage, though it does modify core object handling infrastructure.
