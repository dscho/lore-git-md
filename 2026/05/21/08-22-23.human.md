This is the third patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch begins converting `struct odb_source_loose` into a proper pluggable `struct odb_source` by embedding the base struct and implementing core lifecycle management.

Key changes in this patch:
- Embeds `struct odb_source` in `struct odb_source_loose` and assigns it the new `ODB_SOURCE_LOOSE` type
- Implements the `free` callback to handle proper cleanup
- Takes ownership of chdir notifications for path handling
- Moves related functions from object-file.c to the new odb/source-loose.c
- Adds downcast helper function for type safety

The patch is purely structural - it wires up the basic scaffolding needed for the loose source to operate as a proper odb_source, but doesn't yet implement the actual object access callbacks (those come in later patches). The changes are mechanical and well-contained, continuing the pattern established in earlier patches of this series.

This continues the careful, methodical approach seen in the first two patches, with each commit focused on one clear aspect of the conversion. The risk appears low since this is just moving and reorganizing code rather than changing behavior. The patch maintains test coverage by keeping all existing functionality working through the transition.
