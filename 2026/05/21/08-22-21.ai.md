This is the first patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch moves the `struct odb_source_loose` definition and its constructor function from `object-file.[ch]` to new files `odb/source-loose.[ch]`, following the loose object source implementation pattern already established for other odb sources.

The change is purely mechanical - no behavior is modified. The patch creates the new files, moves the code, and updates build files (Makefile and meson.build) to include the new source file. This prepares for subsequent patches that will convert the loose source to use the proper `struct odb_source` interface.

As noted in the commit message, this detaches the loose object source implementation from the generic object file code, aligning with how other odb sources are organized. The patch appears straightforward and low-risk since it's just code movement with no functional changes. It's a typical first step in Patrick's well-structured refactoring series.
