This is the 6th patch in Patrick Steinhardt's 8-part series refactoring Git's repository initialization and object database setup. The patch fixes an inconsistency where Git would initialize an object database even when no repository exists (specifically when GIT_DIR_EXPLICIT points to a non-existent directory).

The key change moves object database initialization inside the conditional block that checks for a valid repository, rather than doing it unconditionally. This makes logical sense since you can't have an object database without a repository. The patch also fixes a related issue in commit-graph.c where the code was checking for a gitdir rather than an object database.

The change is particularly the git-index-pack case that needs to work outside a repository - the patch ensures commit parsing still works in this scenario by modifying the commit-graph check to look for the object database rather than the gitdir. This maintains functionality while cleaning up the initialization logic.

This continues the series' pattern of carefully separating concerns in the repository setup code, with each patch making one logical improvement while maintaining backward compatibility. The changes are focused on internal plumbing rather than user-visible behavior.
