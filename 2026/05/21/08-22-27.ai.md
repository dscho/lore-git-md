This is patch 7/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_stream()` callback for loose objects, moving the implementation from object-file.c to odb/source-loose.c.

The key changes are:
- Moves the streaming read implementation for loose objects to the new odb/source-loose.c file
- Exposes two helper functions (`unpack_loose_header()` and `parse_loose_header()`) in object-file.h since they're now shared between subsystems
- Updates the files backend to use the generic `odb_source_read_object_stream()` interface rather than calling the loose-specific function directly
- Maintains all existing functionality while converting to the callback-based interface

The patch continues the mechanical conversion pattern established in earlier patches, systematically moving loose object operations to the new odb_source interface. The changes are focused and well-contained, touching primarily the object-file and odb/source-loose files. This appears to be another incremental step in the larger ODB abstraction effort to make Git's object storage pluggable.
