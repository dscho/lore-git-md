Feature patch adding `--track=fetch` mode to `git checkout`/`git switch`.

This is version 12 of Harald Nordgren's patch series that adds a `--track=fetch` option to `git checkout` and `git switch`. The feature automatically fetches from the remote when creating a tracking branch, eliminating the need for a separate `git fetch` step. The key changes in this version address the two edge cases Junio identified in v11:

1. **Overlapping remote-tracking refs**: When multiple remotes map to the same namespace, the patch now clearly errors out rather than making an ambiguous choice. The error message suggests adjusting the remote fetch refspecs or omitting `=fetch`.

2. **Missing HEAD case**: For bare namespace names (like `origin`), the patch now properly handles cases where `<remote>/HEAD` is not set by providing a helpful error message suggesting `git remote set-head --auto`.

The implementation has been thoroughly tested with 18 new test cases covering hierarchical remotes, custom refspecs, error conditions, and combinations with other tracking modes. The documentation clearly explains the behavior with both branch and remote-name start points.

Phillip Wood's review feedback on the overlapping refs case was incorporated by reusing the existing `--track` behavior rather than inventing new logic. The patch appears ready for inclusion pending final maintainer approval, having addressed all substantive technical concerns raised in previous rounds.
