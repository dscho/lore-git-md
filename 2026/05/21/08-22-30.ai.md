This is patch 10/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `count_objects()` callback for the loose source implementation.

The key changes move the loose object counting functionality from object-file.c to odb/source-loose.c and convert it to use the callback interface. The implementation maintains both exact counting (via object iteration) and approximate counting (via directory scanning) modes. The patch updates callers to use the new callback-based interface rather than direct function calls.

This continues the mechanical conversion pattern seen in previous patches of the series, systematically moving loose object operations to the callback-based ODB source interface. The changes are focused and well-contained, touching only the loose object counting logic and its callers. The patch follows the established approach of keeping the same functionality while changing how it's accessed through the abstraction layer.
