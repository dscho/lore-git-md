This is a refactoring patch series from Patrick Steinhardt that reorganizes how Git initializes repositories and their object databases. The series is part of the ongoing ODB (object database) abstraction effort.

The main goal is to consolidate repository setup logic that's currently scattered across multiple functions. The key changes are:
1. Unifying the repository format application code that had diverged in different locations
2. Moving object database creation to happen at the same time as repository format application

The end result makes the initialization process more consistent and provides a clearer point where all repository configuration is known, which will help future work (like adding an "objectStorage" extension). The series builds on recent work to remove `the_repository` usage.

The changes touch core setup code in `setup.c` and `repository.c`, with corresponding test coverage added in `t0001-init.sh`. Given Patrick's track record with architectural changes and the focused nature of these patches (8 small, well-explained commits), this looks like a solid incremental improvement to Git's internals.
