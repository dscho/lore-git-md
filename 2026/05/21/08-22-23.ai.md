This is the third patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch begins converting `struct odb_source_loose` into a proper pluggable `struct odb_source` by embedding the base struct and implementing core lifecycle management.

The key changes include:
- Embedding `struct odb_source` within `struct odb_source_loose`
- Adding a new `ODB_SOURCE_LOOSE` type identifier
- Implementing the `free` callback to handle proper cleanup
- Taking ownership of chdir notification handling from the files source
- Moving loose object cache clearing functionality to the new source-loose.c file

The patch is purely structural - no behavior changes are introduced. It's an incremental step that wires up the basic scaffolding needed before implementing the actual object access callbacks in later patches. The changes follow the same pattern used for other odb sources in this abstraction effort.

Code is moved from object-file.c to the new odb/source-loose.c location, continuing the separation of concerns started in earlier patches. The patch maintains all existing functionality while setting up the architecture for the full callback-based interface to come.
