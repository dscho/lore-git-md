This is the final patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch removes the loose source's dependency on the "files" source now that all callbacks operate directly on `struct odb_source_loose`.

The change makes the loose backend fully standalone by:
1. Dropping the `files` pointer field from `struct odb_source_loose`
2. Modifying `odb_source_loose_new()` to accept ODB, path, and local parameters directly rather than getting them from the files source
3. Updating the files source to pass these parameters when creating the loose source

This completes the mechanical conversion of loose object handling to the callback-based odb_source interface, following the pattern established in previous patches. The changes are straightforward and maintain all existing functionality while improving the code organization. This appears to be a clean conclusion to the series' goal of properly integrating loose objects into Git's generic object storage layer.
