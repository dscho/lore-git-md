Bugfix patch changing Git's date approximation to make "today" mean midnight rather than the current time. This is part of a five-patch series addressing edge cases in Git's approxidate parser, now in its fifth iteration.

The patch introduces a new `date_today()` function that sets the time to midnight when no specific time is given (e.g. plain "today"), while preserving time components when combined with other specifiers (like "noon today"). This changes the behavior of commands like `git log --since=today` to show commits from the current day rather than potentially showing nothing (when using the current time would mean looking for future commits).

The change is motivated by the current behavior being an undocumented accident rather than a design choice. The patch includes documentation updates and new test cases to verify the behavior, including combinations like "January 5th today pm" which should preserve the time component while using the current month/day.
