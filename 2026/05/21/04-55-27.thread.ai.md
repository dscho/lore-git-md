Subject: git-gui worktree detection bug for linked worktrees. Core problem is incorrect path handling where git-gui looks for "gitdir" in the wrong location (current working directory) instead of using the proper `$_gitdir` path that would point to `.git/worktrees/<name>/gitdir` for linked worktrees. Current implementation fails to detect worktrees created via `git worktree add`. Author suggests two potential fixes: 1) correctly using `$_gitdir` path to locate gitdir file, or 2) checking for .git file pointing to worktree directory. This is a substantive technical issue affecting git-gui's ability to work with linked worktrees. No reviews or alternative solutions have been proposed yet. The bug appears to prevent proper functionality when using git-gui with linked worktrees.
