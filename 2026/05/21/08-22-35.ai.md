This is patch 15/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch continues the mechanical conversion of loose object writing code to operate through the odb_source callback interface.

The key change is refactoring the loose object writing functions to take a `struct odb_source_loose` directly rather than the more abstract `struct odb_source`. This makes the dependency on the loose source implementation explicit while maintaining all existing functionality. The patch updates callers in http-walker.c, http.c, and the files backend to use the new interface.

The changes are mostly straightforward parameter type updates, with the core writing logic (`write_loose_object()`, `odb_source_loose_write_stream()`) now operating directly on the loose source structure. This is preparatory work for eventually moving all loose object writing code into odb/source-loose.c, though that final step isn't taken yet since some shared logic with `force_object_loose()` remains to be untangled.

The patch follows the established pattern of the series - methodically converting one aspect of the loose object handling to the callback-based interface. It touches several files but the changes are mechanical and well-contained, with no behavioral modifications. The series continues to demonstrate careful, incremental progress toward the ODB abstraction goal.
