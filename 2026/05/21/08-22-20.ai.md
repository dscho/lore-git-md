This is a cover letter for an 18-patch series by Patrick Steinhardt that refactors Git's loose object handling as part of the ongoing ODB (object database) abstraction effort. The series converts the loose object source into a proper `struct odb_source` to integrate it with Git's generic object storage layer interfaces.

The key technical change is moving from direct function calls to callback-based operations through the odb_source interface. The series also cleans up an awkward parent pointer relationship between the loose source and files source that wasn't logically necessary. The changes are mostly mechanical code movement and interface wiring, with the loose object functionality being relocated to new files in the odb/ directory.

This builds on Patrick's previous work abstracting Git's object storage layer to support pluggable backends. The series appears well-structured with each commit focused on wiring up a specific callback. The cover letter helpfully calls out the one potentially confusing aspect (the parent pointer relationship) that gets resolved over the course of the series.

The changes touch core object handling code across multiple files, but the risk appears manageable since the functionality itself isn't changing - just how it's organized and called. The series includes test updates showing the changes don't break existing behavior. This looks like another solid step in Patrick's long-term ODB abstraction work.
