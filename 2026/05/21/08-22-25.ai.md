This is the fifth patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `close()` callback for the loose source implementation.

The change is straightforward - it adds a no-op `close()` callback to the loose source since that source doesn't actually need to release any resources when closed. The callback is then called from the files source via the generic `odb_source_close()` interface for consistency with the other ODB sources, even though it doesn't do anything in this case.

This continues the mechanical work of converting direct function calls to callback-based operations through the odb_source interface. Like the previous patches, this is a structural change that doesn't modify behavior - it just moves the code into the new callback-based pattern. The patch follows the same approach used for other ODB sources in earlier parts of the series.

The changes are minimal and focused, touching only two files with simple additions. The patch-specific test coverage isn't shown here, but given the nature of the change and the thoroughness demonstrated in previous patches, it's likely adequate. This appears to be another incremental step in the larger ODB abstraction effort.
