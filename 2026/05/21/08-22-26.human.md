This is the sixth patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_info()` callback for the loose object source, moving the implementation from object-file.c to odb/source-loose.c.

The key change is converting direct calls to `odb_source_loose_read_object_info()` to go through the generic `odb_source_read_object_info()` interface instead. The patch also adjusts `read_object_info_from_path()` to explicitly take a loose source parameter rather than a generic odb_source, clarifying its relationship to the loose object backend.

This continues the mechanical conversion work from earlier patches in the series, maintaining all existing functionality while moving toward the callback-based architecture needed for pluggable object storage. The changes are focused and well-contained, touching only the necessary files while keeping the same behavior. As with previous patches in the series, this appears to be a straightforward step in the larger ODB abstraction effort.
