Documentation patch completing a series of hook-related doc improvements. This final patch removes redundant self-linking in the hook configuration documentation, following the same pattern used in `git-init` and `git-commit` documentation. The change uses AsciiDoc conditionals to avoid linking to `git-hook(1)` when the content is already being included in that man page, while preserving the link when included elsewhere.

The implementation adds a `:git-hook:` variable in `git-hook.adoc` and uses it to conditionally define a `see-git-hook` variable in `config/hook.adoc`. This matches prior work by other contributors (referencing commits e7b3a768 and 819fdd6e) and maintains consistency with how similar documentation is handled elsewhere in the project.

Kristoffer Haugsbakk's series has systematically addressed minor documentation issues in the hook subsystem, from formatting fixes to cross-referencing improvements. This patch concludes the series with a mechanical but thoughtful change that improves the project's documentation consistency. The changes are non-controversial and align with established patterns, making them likely to be accepted without significant discussion.
