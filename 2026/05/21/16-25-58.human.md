This is the fourth and final patch in Kristoffer Haugsbakk's documentation series improving hook-related documentation. The patch removes redundant self-linking in the hook configuration documentation - when the config section is included in git-hook(1), it no longer links back to itself.

The change follows the same pattern used in git-init(1) and git-commit(1) documentation, using AsciiDoc conditionals to only show the link when the config section is included elsewhere. This is a mechanical improvement that makes the documentation more maintainable and consistent with other parts of the codebase.

The patch series as a whole has been focused on small but meaningful documentation polish - fixing formatting, standardizing capitalization, and improving cross-references. These changes are unlikely to be controversial and align with the project's ongoing documentation standardization efforts. With this final patch, the series appears ready for merging.
