This is the fifth patch in Patrick Steinhardt's series refactoring Git's repository initialization and object database setup. The patch continues the work of centralizing object database creation by removing conditional logic from `setup_git_env_internal()` and explicitly creating the object database in all repository setup paths.

The key change is that object database creation is now performed directly in each caller (`enter_repo()`, `setup_git_directory_gently()`, and `init_db()`) rather than being conditionally handled in `setup_git_env_internal()`. This creates some temporary duplication that Patrick notes will be resolved in the next patch when the object database creation is unified with repository format application.

The patch maintains the series' careful, incremental approach - each change is clearly motivated and builds toward the larger goal of cleaning up repository setup. While this introduces some immediate code duplication, it's a necessary step toward the final architecture where object database creation will be properly centralized. The changes are plumbing-only and don't affect user-visible behavior.
