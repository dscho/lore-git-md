This is the first patch in Harald Nordgren's v10 series adding `git branch --prune-merged` functionality. The patch introduces the foundational `--forked` option that will be used by the pruning feature.

The `--forked` option lists local branches whose upstream matches given branch arguments, which can be:
- Remote-tracking branches (e.g. `origin/master`)
- Local branches (e.g. `main`) 
- Shell-style glob patterns (e.g. `origin/*`)

The implementation handles multiple arguments by unioning the results, and includes comprehensive tests covering:
- Exact branch matching
- Local branch tracking
- Glob pattern matching
- Combining literal and glob arguments
- Error cases for invalid inputs

The patch builds the plumbing needed for the safe branch pruning feature while maintaining Git's cautious approach to destructive operations. The implementation uses wildmatch for glob pattern matching and carefully handles both remote-tracking and local upstream branches.

This is a well-structured patch with clean separation between the core functionality and test coverage. The changes are focused and the commit message clearly explains the purpose and behavior of the new option. The tests demonstrate thoughtful consideration of edge cases and usage patterns.
