This thread covers Patrick Steinhardt's 18-patch series refactoring Git's loose object handling as part of the ongoing ODB (object database) abstraction effort. The changes convert the loose object source into a proper `struct odb_source`, moving from direct function calls to callback-based operations through the odb_source interface. This is a mechanical but important step toward making Git's object storage pluggable.

Junio C Hamano provided initial surface-level feedback on two patches, noting minor documentation wording issues. In the latest exchange, Patrick confirmed Junio's suggestion to change "difference to" to "difference from" in a comment for the streaming write callback implementation. This was purely a documentation phrasing adjustment with no impact on the technical approach. The series remains in its first version with no substantive technical reviews yet. The changes are largely organizational, moving code to better support the long-term goal of pluggable object storage while maintaining existing functionality. Some shared logic with `force_object_loose()` remains to be untangled, and transaction support is explicitly deferred for future work.
