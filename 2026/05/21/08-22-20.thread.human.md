Patrick Steinhardt continues his methodical refactoring of Git's loose object handling with patch 14/18 in the ODB abstraction series. This installment wires up the `write_object()` callback, moving the implementation from object-file.c to odb/source-loose.c while keeping the behavior identical. The change follows the established pattern of converting direct function calls to callback-based operations through the odb_source interface.

Two helper functions from object-file.c needed to be exposed for shared use between subsystems, and the files backend was updated to use the new callback mechanism. Like previous patches in the series, this is a focused, behavior-preserving change that advances the architectural goal of making the object storage layer pluggable.

The series has seen only minor documentation feedback from Junio Hamano on earlier patches, which Patrick addressed in v2. No substantive technical concerns have been raised about the approach. With each patch building carefully on the last, the work is progressing steadily toward the goal of a fully independent loose object backend. Remaining work includes implementing a few more callbacks and eventually removing the files backend dependency entirely.
