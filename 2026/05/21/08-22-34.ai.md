This is the 14th patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `write_object()` callback for the loose source implementation.

The key changes are:
1. Moves `odb_source_loose_write_object()` from object-file.c to odb/source-loose.c and makes it the loose source's `write_object` callback
2. Exposes `write_object_file_prepare()` and `write_loose_object()` functions from object-file.h since they're now used by both subsystems
3. Updates the files backend to call the loose source's write_object callback directly rather than calling the function by name

The patch follows the established pattern from previous patches in the series, continuing the mechanical conversion of loose object handling to the callback-based odb_source interface. No behavior changes are introduced - this is purely an internal reorganization to support the ODB abstraction work. The changes are limited to the expected files (object-file.c, odb/source-loose.c) and maintain all existing functionality including compatibility object handling.

This continues the systematic conversion of the loose object backend to work through the odb_source interface, another incremental step in Patrick's long-term effort to make Git's object storage pluggable. The patch appears well-contained and follows the established pattern from earlier in the series.
