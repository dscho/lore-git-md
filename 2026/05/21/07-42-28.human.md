Test patch for repository initialization with GIT_OBJECT_DIRECTORY.

This is the first patch in Patrick Steinhardt's 8-part series refactoring repository initialization and object database setup. It adds a test case verifying that `git init` correctly honors the GIT_OBJECT_DIRECTORY environment variable by creating the object database at the specified path rather than the default location.

The test creates a custom object directory, runs `git init` with GIT_OBJECT_DIRECTORY set, and verifies the objects are created in the expected location while the default .git/objects remains empty. This fills a gap in test coverage that was discovered during the refactoring work - the behavior was documented but not explicitly tested.

While a small preparatory change, it demonstrates Patrick's thorough approach - identifying and fixing test gaps before making structural changes to the affected code. The test is cleanly written with proper cleanup and clear assertions. This lays groundwork for the more substantial refactoring to follow in subsequent patches.
