This is the sixth patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_info` callback for the loose object source, moving the implementation from object-file.c to odb/source-loose.c.

Key changes:
- Moves `odb_source_loose_read_object_info()` to the new location and registers it as the loose source's callback
- Updates callers to use the generic `odb_source_read_object_info()` interface
- Adjusts `read_object_info_from_path()` to take a loose source parameter instead of generic source, clarifying its scope
- Keeps `read_object_info_from_path()` in object-file.c since it's still used by `for_each_object_wrapper_cb() 

The changes are mechanical and follow the same pattern as previous patches in the series, continuing the conversion to callback-based operations. The functionality remains unchanged - this is purely an interface refactoring to support the ODB abstraction work. The patch touches core object handling code but appears low-risk since it's moving rather than modifying logic.

This continues the systematic approach seen in earlier patches, with each commit wiring up one piece of the odb_source interface. The series remains focused and well-structured, with Patrick clearly marking the boundaries between mechanical changes and logical ones.
