This is patch 11/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch removes a redundant function that checked for loose object existence via direct filesystem access, consolidating this check into the more general `odb_source_read_object_info()` interface.

The change eliminates `odb_source_loose_has_object()` which performed an lstat() check, noting this functionality is already available through `odb_source_read_object_info()` when called without the OBJECT_INFO_QUICK flag. The patch updates three call sites in pack-objects.c and object-file.c to use the unified interface instead.

This continues the series' pattern of converting direct function calls to callback-based operations through the odb_source interface. The change is mechanical but meaningful - it removes a special-case API in favor of the more general object storage interface being established. The diff shows careful attention to the casting needed when working with the layered source types (odb_source vs odb_source_files).

As with previous patches in the series, this appears to be a well-considered step in the larger ODB abstraction work, maintaining existing behavior while simplifying the interface. The changes are limited to the expected files and follow the established pattern from earlier conversions in the series.
