This is the second patch in Tuomas Ahola's five-part series improving Git's date approximation logic. The patch enhances the date parsing test infrastructure by adding time offset support, allowing tests to verify how date strings parse relative to different reference times.

The key addition is an `add_time_offset()` helper function that can adjust the test reference time by hours or days, demonstrated with a new test case showing how "January 5th yesterday" parses differently when the reference date is adjusted by +2 days. This infrastructure will be used in subsequent patches to test edge cases around month/year boundaries and special time formats.

The implementation is clean and focused - it preserves the existing test interface while adding the new capability, and includes clear error handling for the offset parameter. This test helper will be immediately useful in the next patch (3/5) which fixes core issues with special time formats respecting explicit days.

This patch has already been accepted in previous iterations of the series, and the v5 version shows only minor refinements to the test infrastructure. It's a straightforward improvement that enables more comprehensive testing of the date parsing fixes to come.
