This is patch 16/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `write_object_stream()` callback for the loose object backend, continuing the mechanical conversion to the new callback-based interface.

The change connects the loose object source's streaming interface while leaving the actual implementation in object-file.c for now, as moving it fully would require additional refactoring of `force_object_loose()`. The patch includes a TODO noting this future work. The changes are limited to header declarations and wiring up the callback - the core functionality remains unchanged.

This continues the established pattern from previous patches in the series, systematically converting each operation to the new interface. The risk appears low since the patch just adds indirection without changing behavior. As with the rest of the series, this is no functional change - just internal reorganization to support the ODB abstraction goals.
