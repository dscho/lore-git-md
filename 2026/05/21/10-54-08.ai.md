This is the fourth patch in Tuomas Ahola's five-part series fixing edge cases in Git's approxidate parser. The patch introduces deferred day-of-month adjustments using negative `tm_mday` values to handle special time formats ("noon", "tea") when combined with explicit date references.

The key technical change is a new mechanism where negative tm_mday values (-1 for yesterday, -2 for day before) allow the date parser to defer day adjustments until it's clear whether an explicit date was specified. This fixes cases like "tea yesterday" where the previous behavior would first find the last tea-time and then subtract a day, rather than treating it as yesterday's tea-time.

The implementation:
- Modifies `update_tm()` to handle negative tm_mday values as deferred adjustments
- Changes time-related functions (`date_time`, `date_noon`, etc.) to use this mechanism
- Adds new test cases verifying the behavior with time offsets
- Preserves the existing function signatures for callback compatibility

The patch builds on the series' earlier work establishing "today=midnight" semantics and adds the final piece of logic needed for consistent handling of relative dates with time specifications.
