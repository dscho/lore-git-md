This is the fourth patch in Tuomas Ahola's five-part series fixing edge cases in Git's date approximation logic ("approxidate"). The patch introduces a deferred adjustment mechanism for special date/time formats like "today" and "yesterday" when combined with time specifications like "noon" or "tea".

The key change is using negative `tm_mday` values (-1 for yesterday, -2 for day before) to mark dates that need deferred adjustment, allowing the parser to properly handle combinations like "tea yesterday" without unexpected rollback behavior. The implementation:
- Modifies `update_tm()` to handle negative day markers
- Updates time-specific functions (`date_noon`, `date_tea`, etc.) to use the new deferred adjustment approach
- Adds test cases verifying the new behavior works correctly with time offsets

This builds on previous patches in the series that established the "today=midnight" semantic and improved test infrastructure. The changes are well-contained and maintain backward compatibility while fixing the edge cases that motivated the series. With comprehensive test coverage and all prior feedback addressed, this appears to be the final form of the core fix.
