This is a new thread started by Patrick Steinhardt with an 8-patch series refactoring Git's repository initialization and object database setup logic. The series is part of the ongoing effort to clean up repository setup and prepare for pluggable object storage backends.

The core changes unify scattered repository format application logic into a single location (currently duplicated), move object database creation to happen alongside format application, and eliminate redundant object database initializations during setup. The patches modify `setup.c` and `repository.c` with corresponding test updates in `t0001-init.sh`. This builds on Patrick's prior work removing `the_repository` from `init_db()` and appears to lay groundwork for introducing an "objectStorage" extension in future work.

The series follows Patrick's characteristic style - carefully structured commits that build logically on each other, with clear explanations of both the changes and their motivation. While these are internal plumbing changes with no immediate user-visible impact, they improve maintainability and consistency in core setup code.
