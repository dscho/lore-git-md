This is the fourth patch in Patrick Steinhardt's series refactoring repository initialization and object database setup. The patch moves object database initialization out of `repo_set_gitdir()` where it was previously happening alongside other gitdir setup tasks. 

The change removes the conditional object database creation logic from `repo_set_gitdir()` and relocates it to the callers - specifically `repo_init()` and `setup_git_env_internal()`. This creates some temporary duplication that will be cleaned up in subsequent patches when object database initialization is centralized with repository format application.

The patch touches core repository setup code in `repository.c` and `setup.c`, removing several fields from `struct set_gitdir_args` that are no longer needed. The changes are mechanical and maintain existing behavior while making the initialization sequence more explicit. This continues Patrick's careful, incremental approach to refactoring the repository setup code in preparation for future pluggable object storage backends.
