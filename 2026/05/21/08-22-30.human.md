This is the 10th patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `count_objects()` callback for the loose object backend.

The change moves the loose object counting implementation from object-file.c to odb/source-loose.c and updates callers to use the new callback-based interface. The counting logic itself remains unchanged - it still provides both an approximate mode (sampling one shard directory) and an exact mode (iterating all objects). The patch updates `builtin/gc.c` to use the new interface when checking if there are too many loose objects.

This continues the mechanical conversion pattern seen in previous patches of the series, systematically moving functionality to the new ODB abstraction layer. The changes are focused and well-contained, touching only the loose object counting logic and its callers. As with earlier patches in the series, this appears to be a straightforward step in the larger ODB abstraction effort.
