This is patch 13/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch cleans up an implicit assumption in the loose object map code where functions were accepting a generic `struct odb_source*` but always expecting it to be the "files" backend.

The key change is making the loose object map functions operate directly on `struct odb_source_loose` instead, eliminating the unnecessary indirection through the files backend. This makes the code's intent clearer and removes some awkward dependencies. The changes are mechanical but improve the architecture by making the relationships between components more explicit.

The patch follows the established pattern of the series - focused, well-contained changes that move the ODB abstraction forward while maintaining existing functionality. It touches several files but the changes are straightforward parameter type updates and call site adjustments. This continues the systematic conversion of loose object handling to the callback-based interface that's central to the ODB abstraction work.
