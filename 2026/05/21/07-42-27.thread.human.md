Patrick Steinhardt continues his careful refactoring of Git's repository initialization code with this fifth patch in the series. The thread focuses on cleaning up object database (ODB) setup as part of preparing for pluggable storage backends. 

The latest patch removes conditional ODB initialization from `setup_git_env_internal()`, making object database creation explicit in all code paths that discover and configure a repository. This eliminates the `skip_initializing_odb` parameter that previously made the behavior conditional, creating more consistent behavior at the cost of temporary code duplication that will be resolved later. The changes affect several core setup functions but don't alter user-visible behavior.

The series as a whole is methodically restructuring how Git handles repository setup - first by centralizing format handling, then by separating ODB initialization from gitdir setup, and now by making ODB creation unconditional. Each patch builds logically on the last while maintaining working code at each step. The work demonstrates Patrick's signature approach to large refactorings: incremental, well-tested changes that move steadily toward the architectural goal of cleaner setup code and eventual pluggable storage backends.
