This is a major refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The series converts Git's loose object handling into a proper `struct odb_source` implementation, making it work through the generic ODB abstraction layer.

The 18-patch series moves and reorganizes code to implement all the required callbacks for loose object handling (reading, writing, counting objects, etc.) while cleaning up some confusing pointer relationships in the existing code. Notably, it removes an unnecessary parent relationship between the loose object source and files source that made the code harder to reason about.

The changes are mechanical in nature - moving code between files and wiring up callbacks - rather than introducing new functionality. The series builds on Patrick's previous work on the ODB abstraction and appears to be a logical next step in that effort. Given Patrick's track record with large-scale refactorings and the focused nature of these changes, the series looks like solid technical debt reduction that moves the ODB abstraction forward.

The patch touches many parts of Git's object handling code, including object-file.c and several builtins, but the changes appear to be well-contained within the ODB abstraction work. Reviewers will want to pay particular attention to the pointer relationship cleanup mentioned in the cover letter, but otherwise this seems like a straightforward (if large) refactoring that improves code organization.
