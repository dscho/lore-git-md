This is a test patch from Patrick Steinhardt that plugs a testing gap in the repository initialization code. It's the first in an 8-part series refactoring Git's repository setup and object database initialization.

The patch adds a new test case to verify that `git init` correctly respects the `GIT_OBJECT_DIRECTORY` environment variable, which specifies where the object database should be created. While this behavior is documented, there was previously no test coverage for it - a gap that became apparent when subsequent changes in the series accidentally broke this functionality.

The test creates a custom object directory, runs `git init` with `GIT_OBJECT_DIRECTORY` set, and verifies the objects are created in the specified location rather than the default `.git/objects`. This is a straightforward but important test that will help prevent regressions in the object directory handling as the setup code is refactored in later patches.
