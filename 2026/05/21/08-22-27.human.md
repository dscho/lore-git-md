This is patch 7/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_stream()` callback for loose objects, moving the implementation from object-file.c to odb/source-loose.c.

The change is primarily a code movement that relocates the streaming read functionality for loose objects into the new odb/source-loose.c file where it belongs as part of the ODB source abstraction. The patch exposes two helper functions (`unpack_loose_header()` and `parse_loose_header()`) in object-file.h since they're now needed by both subsystems.

This continues the mechanical conversion of loose object handling to callback-based operations through the odb_source interface. The changes are straightforward and maintain all existing functionality while following the pattern established in previous patches of the series.
