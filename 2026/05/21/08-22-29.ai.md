This is the 9th patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `find_abbrev_len` callback for loose object sources.

The change moves the implementation of `odb_source_loose_find_abbrev_len()` and its helper functions from object-file.c to odb/source-loose.c, where it becomes the loose source's `find_abbrev_len` callback. This continues the mechanical conversion of direct function calls to callback-based operations through the odb_source interface.

Key technical details:
- The implementation remains functionally identical, just relocated
- The callback finds the shortest unique prefix length for a given object ID
- Updates the files backend to use the generic callback interface
- Follows the same pattern established in previous patches of the series

This is another incremental step in the systematic conversion of loose object handling to the odb_source interface. The patch-specific risk appears low since it's primarily code movement with no behavior changes. The series continues to demonstrate careful, methodical progress on the ODB abstraction work.
