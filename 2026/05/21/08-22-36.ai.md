This is patch 16/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `write_object_stream()` callback for the loose object backend.

The change connects the streaming write interface to the odb_source abstraction while leaving the actual implementation in object-file.c for now. The commit explains this is temporary - moving the full implementation requires additional refactoring of `force_object_loose()` that will come later. The patch includes a TODO noting this future work.

Key technical details:
- Adds the callback stub in odb/source-loose.c that delegates to the existing implementation
- Updates object-file.h with documentation about the transitional state
- Modifies odb/source-files.c to use the new callback interface
- Maintains all existing functionality through the indirection

The changes are mechanical and follow the established pattern from previous patches in the series. This continues the systematic conversion of loose object operations to the callback-based odb_source interface, another incremental step toward making Git's object storage fully pluggable.
