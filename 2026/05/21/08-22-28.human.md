This is patch 8/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `for_each_object()` callback for the loose source implementation.

The key changes:
- Moves `odb_source_loose_for_each_object()` and related helper functions from object-file.c to odb/source-loose.c
- Exposes `for_each_file_in_obj_subdir()` in object-file.h for shared use
- Updates callers to use the generic `odb_source_for_each_object()` interface
- Adjusts the files backend to use the new callback-based interface

This continues the mechanical conversion of loose object handling to the callback-based ODB source interface, following the pattern established in previous patches. The changes are focused and well-contained, touching primarily the loose object implementation files while maintaining all existing functionality.

The patch appears to be another solid step in the ongoing ODB abstraction work, systematically converting each piece of functionality to the new interface. As with previous patches in the series, the risk seems low since this is primarily code reorganization rather than functional changes.
