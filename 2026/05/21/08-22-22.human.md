This is the second patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch makes the relationship between the "loose" and "files" object sources more explicit by changing a generic parent pointer to specifically reference the "files" source.

The change replaces a `struct odb_source*` with a `struct odb_source_files*` in the loose source implementation, making the dependency clearer in the code. This is an intermediate step - the cover letter notes the eventual goal is to remove this parent pointer entirely, allowing the loose source to stand alone. The patch updates all related function calls and type definitions across four files while maintaining the same behavior.

This appears to be a straightforward mechanical change that improves code clarity as part of the larger architectural work. The patch follows the series' pattern of incremental, focused changes to the object storage layer. No behavior changes are introduced here - it's purely preparing for later patches that will detangle the loose source from its parent.
