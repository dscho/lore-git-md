This is patch 8/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `for_each_object()` callback for the loose object source.

The key changes:
- Moves `odb_source_loose_for_each_object()` and related helper functions from object-file.c to odb/source-loose.c
- Exposes `for_each_file_in_obj_subdir()` in object-file.h for shared use
- Updates callers to use the generic `odb_source_for_each_object()` interface
- Adjusts the files backend to use the new callback-based interface

The patch continues the mechanical conversion of loose object handling to the callback-based odb_source interface, following the pattern established in previous patches. It maintains all existing functionality while moving the implementation to the new home in odb/source-loose.c.

This is part of Patrick's ongoing work to make Git's object storage pluggable by abstracting the backend interfaces. The changes are focused and well-contained, following the established pattern from earlier patches in the series. The patch appears to be another incremental step in this long-term architectural effort.
