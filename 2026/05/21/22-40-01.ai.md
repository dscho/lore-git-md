This is the first patch in Harald Nordgren's v10 series introducing `git branch --forked` as a building block for the eventual `--prune-merged` functionality. The patch adds core infrastructure for identifying local branches that track specified upstreams, whether remote-tracking branches (like `origin/main`) or local branches (like `main`), with support for glob patterns.

Key technical aspects:
- Introduces `--forked <branch>` option that accepts:
  - Literal remote-tracking refs (`origin/master`)
  - Local branch names (`main`)
  - Shell-style glob patterns (`origin/*`)
- Uses wildmatch()` for glob pattern matching
- Combines multiple arguments via union
- Includes comprehensive tests covering:
  - Exact branch matching
  - Glob pattern expansion
  - Union of multiple patterns
  - Error cases (invalid patterns, missing arguments)

The implementation carefully handles both remote and local upstream cases while maintaining Git's existing ref resolution patterns. The tests demonstrate the flexible branch specification syntax that will underpin the safety-focused pruning functionality in later patches.

This foundational change enables the series' goal of safe automated branch cleanup while addressing Junio C Hamano's request for a more generalized interface. The patch shows clean integration with existing branch machinery and thorough test coverage of the new behavior.
