This is patch 12/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `freshen_object()` callback for the loose object source.

The change moves the `odb_source_loose_freshen_object()` function from object-file.c to odb/source-loose.c and makes it the official callback implementation. As part of this, it inlines the now-unused `check_and_freshen_source()` helper function. The patch also updates the files source to use the new callback interface rather than calling the loose source function directly.

This continues the mechanical conversion pattern seen in previous patches - moving functionality to the new odb/source-loose.c while maintaining the same behavior. The changes are focused and well-contained, touching only the necessary files to wire up this callback. Like the rest of the series, this appears to be a straightforward step in the larger ODB abstraction effort.
