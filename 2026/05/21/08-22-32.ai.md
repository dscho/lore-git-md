This is patch 12/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `freshen_object()` callback for the loose object backend.

The change moves the `odb_source_loose_freshen_object()` function from object-file.c to odb/source-loose.c and makes it the official callback implementation. As part of this move, it inlines the now-unused `check_and_freshen_source()` helper. The patch updates the files source to use the new callback interface rather than calling the loose source function directly.

This continues the mechanical conversion pattern seen in previous patches of the series - moving functionality to the new odb/source-loose.c file and wiring up callbacks one by one. The changes are straightforward and maintain all existing behavior, just reorganizing how the code is structured. The patch touches core object handling code but doesn't introduce new functionality or behavior changes.

This is another incremental step in Patrick's long-term effort to abstract Git's object storage layer to support pluggable backends. The series appears to follow the established pattern of previous ODB abstraction work, with each patch focused on wiring up a specific callback interface.
