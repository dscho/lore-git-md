Maintainer feedback on commit-reach optimization series.

Junio Hamano notes a potential collision with bit 20 flag usage between the new ENQUEUED flag in commit-reach.c and the ONELINE_SEEN flag in object-name.c (formerly sha1-name.c). While he observes the current usage patterns likely don't conflict - since commit-reach operations wouldn't simultaneously perform textual object name parsing - he highlights that the flag allocation table in object.h is outdated and needs auditing.

The maintainer's technical assessment suggests the immediate change is safe, but flags a broader documentation issue: the centralized flag assignment tracking hasn't been maintained as the codebase evolved. This doesn't block the current series but indicates follow-up work needed to properly document flag bit usage across subsystems.

The feedback doesn't challenge the optimization approach itself, focusing instead on a peripheral documentation concern that affects multiple areas of the current patch. Junio's analysis implies the series can proceed while the flag documentation issue is handled separately.
