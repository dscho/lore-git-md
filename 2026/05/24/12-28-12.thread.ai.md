Performance optimization for `git fetch` connectivity checks. Kristofer Karlsson from Spotify identified and implemented a patch to pass the transport parameter through `store_updated_refs()` to enable an existing optimization in `check_connected()`, allowing skipping verification of objects already in newly received packs when the transport provides self-contained packs. This requires clarification - either identifying an undocumented fetch code path that enables the optimization, or acknowledging this is preparatory work for future fetch improvements.
