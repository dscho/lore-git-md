This is the final patch in a git-gui bugfix series, adding explicit subcommands to control repository and worktree discovery behavior. The patch introduces two new subcommands: `gui` (fails if repository discovery fails rather than falling back to the picker) and `pick` (always runs the picker first). The changes maintain backward compatibility while giving users more control over when the repository picker appears.

Johannes Sixt (the git-gui maintainer) reviews the implementation and confirms it looks good, specifically noting the proper error handling when git directory discovery fails. The review identifies that the patch converts an unconditional branch into a conditional one (using `is_enabled gitdir_discovery`) and verifies the error message propagation from failed discovery attempts.

This patch completes the series' goal of making git-gui's startup behavior more predictable and aligned with user expectations.
