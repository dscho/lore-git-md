This is the first patch in a performance optimization series for commit-reach.c algorithms, focusing on the `paint_down_to_common()` function used by `git merge-base` and ahead-behind calculations. The patch introduces deduplication of queue entries in the graph traversal by adding an ENQUEUED flag to track whether a commit is already in the priority queue. While this change itself doesn't improve performance (the O(n) scan remains), it enables the subsequent optimization in patch 2 that will eliminate that scan.

The implementation is straightforward - it adds a new flag bit, introduces a helper function `maybe_enqueue()` that checks the flag before adding, and clears the flag when processing each commit. The change is well-contained and clearly motivated as preparation for the more significant optimization to come. The patch maintains the existing functionality while setting up for the performance win demonstrated in the cover letter's benchmarks.
