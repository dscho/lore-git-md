This is a bugfix for the `git subtree` contrib script, addressing an issue where `git subtree split` fails when processing merge commits that make the same commit reachable via multiple paths in the commit graph.

The patch fixes a specific error case where the command would fail with "fatal: cache for <hash> already exists!" when encountering merge commits in the history being split. The problem occurs because the DAG traversal tries to cache the same commit multiple times when it's reachable via different paths. The solution modifies the script to prune these duplicate paths.
