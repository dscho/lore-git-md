This is the first patch in Kristofer Karlsson's performance optimization series for commit-reach.c algorithms. The patch introduces deduplication of queue entries in paint_down_to_common() by adding an ENQUEUED flag to track whether a commit is already in the priority queue.

The change adds a new ENQUEUED flag (bit 20) to the object flags and introduces a maybe_enqueue() helper that checks this flag before adding commits to the queue. While this change alone doesn't improve performance (the O(n) queue scan remains), it enables the subsequent optimization in patch 2 which will replace the scan with an O(1) counter.

The implementation carefully maintains the existing flag handling while adding the new tracking, clearing ENQUEUED when processing each commit. The flag documentation in object.h is updated to reflect the new usage in commit-reach.c. This appears to be a clean preparatory change that sets up for the more significant optimization to follow.
