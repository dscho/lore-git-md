Thread identity: Shell completion patch series (v2) modifying path completion behavior for dotfiles in `git rm`, `git mv`, and `git ls-files`, authored by Zakariyah Ali.

Core problem: Git's path completion currently shows dotfiles (e.g. `.gitignore`) by default, differing from standard shell completion behavior.
