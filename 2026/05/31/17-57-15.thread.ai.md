Thread identity: Performance optimization patch for Git's priority queue implementation by Kristofer Karlsson (Spotify), focusing on `prio_queue_get()` operation, now with Junio C Hamano's input on `prio_queue_replace()` implications.

Core problem: Optimizing the sift-down algorithm in `prio_queue_get()` for ascending-key workloads (Git's common case) while maintaining correctness of `prio_queue_replace()` which was previously optimized by René Scharfe.

Key technical details: The patch implements a cascade-down approach that:
1. Promotes smaller child upward at each level (1 comparison + 1 copy)
2. Lets vacancy sink to leaf
3. Places last array element with potential sift-up
Benchmarks show consistent improvements:
- 15-23% faster for ascending keys
- 1-4% faster for descending keys
- ~4% speedup in `rev-list` on wide DAGs
Changes to `prio_queue_replace()` (now using get+put) may need reevaluation against René's original optimization intent.
