Bugfix patch in the git-gui repository detection series. This is patch 7/12 of a merged series that standardizes git-gui's repository and worktree discovery on `git rev-parse` for consistency with core Git.

The patch simplifies worktree discovery by:
1. Moving all worktree path resolution to use `git rev-parse --show-toplevel` and `--show-prefix`
2. Consolidating error handling for invalid worktrees
3. Reordering configuration loading to happen after worktree discovery
4. Removing redundant path manipulation code

The changes ensure git-gui properly handles edge cases like bare repositories, submodules, and invalid GIT_DIR/GIT_WORK_TREE configurations while maintaining the same behavior as the Git CLI. The implementation now fails early with clear errors when encountering invalid states rather than trying to proceed with potentially broken paths.

This patch represents a key architectural shift in the series by fully delegating path resolution to core Git's rev-parse plumbing. The maintainer (Johannes Sixt) had already approved the approach in previous iterations, and this version incorporates all requested changes.
