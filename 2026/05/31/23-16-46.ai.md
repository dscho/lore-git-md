This is a build system patch that removes duplicate library references in the Makefile's link recipes. The author, Harald Nordgren, noticed that three link commands were listing archive files twice - once through explicit filtering and again via the $(LIBS) variable. This was causing linker warnings on macOS about duplicate libraries.

The patch modifies the link rules for:
1. test-helper programs
2. fuzz programs
3. unit tests

The change aligns these recipes with the pattern used elsewhere in the Makefile, where $(LIBS) alone provides the necessary library references. This is a straightforward cleanup that eliminates harmless but noisy warnings during builds. The patch is small, focused, and clearly explained in the commit message.
