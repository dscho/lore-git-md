This is the fourth patch in a 12-part bugfix series for git-gui, focusing on repository and worktree detection. The series has already been reviewed and approved by maintainer Johannes Sixt.

The patch refactors the repository picker (`choose_repository::pick`) to avoid modifying global variables during repository selection. Instead of directly setting globals like `_gitdir` and `_prefix`, it now leaves the current directory at the worktree root and lets the caller handle repository validation through `git rev-parse`. This makes the behavior more robust by ensuring proper validation occurs even for repositories selected from the "recent" list.

Key changes include:
- Removing direct manipulation of `_gitdir` and `_prefix` globals
- Adding proper error handling when repository validation fails
- Introducing a `pick_ok` field to track success/failure state
- Maintaining the same functionality while making the code more maintainable

The change is part of a larger effort to align git-gui's behavior with core Git's repository handling conventions. It addresses edge cases that could previously lead to cryptic errors, particularly around bare repositories and worktree detection. The patch maintains backward compatibility while improving reliability.
