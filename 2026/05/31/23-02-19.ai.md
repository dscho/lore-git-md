This is patch 6/12 in a merged bugfix series for git-gui, focusing on repository discovery. The patch standardizes on using `git rev-parse --absolute-git-dir` as the sole method for finding repositories, replacing a hybrid approach that first checked GIT_DIR environment variables. This ensures all of Git's built-in repository validation runs upfront rather than potentially deferring errors.

Key technical changes:
- Introduces new `is_gitvars_error` helper to handle GIT_DIR/GIT_WORK_TREE validation consistently
- Removes fallback path that used raw environment variables without validation
- Initializes `_prefix` globally rather than conditionally
- Simplifies error flow by removing redundant directory checks (since rev-parse already validated)
- Maintains existing behavior of showing repository picker on failure when no environment variables are set

The change makes git-gui's repository detection more robust by fully aligning with core Git's validation logic. This was the last major piece in the series' architectural shift to using rev-parse exclusively for repository discovery. The patch builds on earlier work in the series that introduced environment variable management helpers and prepares for subsequent patches that will further clean up worktree handling.
