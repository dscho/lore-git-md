This is the first patch in a merged 12-part bugfix series for git-gui, addressing edge cases in repository and worktree detection. The series has already been reviewed and approved by maintainer Johannes Sixt.

The patch fixes a regression where git-gui's browser subcommand would fail when run in a detached HEAD state. The issue arose from a 2024 change that switched from direct file reading to using `git branch --show-current` for ref access (to support reftable backends), but didn't properly handle the empty output that occurs in detached HEAD states. The fix restores the previous behavior by explicitly setting the branch to "HEAD" when detached.

This is a straightforward bugfix that maintains backward compatibility while aligning with the series' broader goal of making git-gui's behavior more robust and consistent with core Git. The change is small (3 lines added) and clearly motivated by a specific regression. As part of an already-approved series, this patch represents a completed piece of work rather than something still under discussion.
