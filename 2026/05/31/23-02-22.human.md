This is the 9/12 patch in a completed bugfix series for git-gui, now merged. The series standardizes repository and worktree detection to match core Git behavior, fixing edge cases that caused cryptic errors.

This particular patch improves worktree discovery when git-gui is launched from a gitdir (like .git/ or worktree-specific directories). It handles three scenarios:
1. When core.worktree is set (already handled by rev-parse)
2. When in a .git subdirectory (parent may be worktree)
3. When in a worktree-specific gitdir (under mainrepo/worktrees/)

The implementation adds validation to ensure discovered worktrees actually point back to the gitdir, preventing issues from filesystem inconsistencies or misconfiguration. This completes the architectural shift to using `git rev-parse` for all repository operations.

The patch represents the culmination of extensive review, with maintainer Johannes Sixt contributing to and approving the final version. It resolves long-standing edge cases while maintaining backward compatibility.
