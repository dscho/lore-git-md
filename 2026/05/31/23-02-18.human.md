This is a technical cleanup patch in the git-gui bugfix series, now merged. It simplifies repository path handling by using `git rev-parse --absolute-git-dir` instead of manually converting relative paths to absolute ones. The change removes special-case code that previously handled the case where `--git-dir` returned "." (indicating the current directory is the repository root).

The patch is straightforward and mechanical - it replaces one Git command with a more appropriate variant that does exactly what the code needs (always returning an absolute path), allowing removal of the manual path conversion logic. Since git-gui already requires Git 2.36+ and the `--absolute-git-dir` option was added in 2.31, this is a safe change that makes the code both simpler and more robust.

This was part of a larger effort to make git-gui's repository detection more reliable by aligning with core Git's behavior. The patch was reviewed and approved by git-gui maintainer Johannes Sixt as part of the final merged series.
