This is a build system cleanup patch addressing a minor issue with duplicate library specifications in the Makefile. The patch removes redundant `.a` file filters from three link recipes (for test helpers, fuzz programs, and unit tests) that were causing macOS's linker to emit warnings about duplicate libraries.

The change is straightforward and appears correct - it aligns these recipes with the pattern used elsewhere in the Makefile where libraries are only specified once through the `$(LIBS)` variable. The commit message clearly explains the motivation (avoiding linker warnings) and the solution.

This seems like a low-risk, quality-of-life improvement for developers building Git on macOS. The patch is small, focused, and well-explained. Since it's purely a build system change that doesn't affect runtime behavior, it's unlikely to generate much discussion.
