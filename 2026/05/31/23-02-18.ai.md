This is a cleanup patch in the git-gui bugfix series, switching from `git rev-parse --git-dir` to `--absolute-git-dir` for repository path resolution. The change simplifies the code by eliminating manual path normalization that was previously needed when the repository was the current directory (returning "."). 

The patch leverages Git's built-in absolute path formatting (available since Git 2.31) to always get canonical paths, removing the need for special-case handling of relative paths. This is part of the series' broader effort to make git-gui's repository detection more robust by aligning with core Git's behavior. The change is straightforward and low-risk since it uses functionality that's been available for several Git releases (git-gui requires Git 2.36+).

The patch was authored by Mark Levedahl, who has been implementing fixes based on Shroom Moo's original bug reports, and is part of the now-merged series that addressed long-standing edge cases in git-gui's repository handling.
