The thread began with Harald Nordgren’s patch series addressing macOS linker warnings about duplicate library references in Git’s Makefile build system. The series concluded with a v3 patch that suppresses the warning at the linker level using `-Wl,-no_warn_duplicate_libraries`, version-gated for Xcode 15+ (ld64-907+, dyld-1009.5+). This approach preserves the ability to list libraries multiple times—a necessity for handling circular dependencies—while eliminating cosmetic noise during builds.

The patch is now ready for merging, with D. Ben Knoble confirming successful testing on both older (Xcode 14.2) and newer macOS systems, and across both Makefile and Meson builds. Junio C Hamano’s latest email adds context: the linker flag suppression was inspired by a prior Meson maintainer effort (commit `7c901d7a8af2`), reinforcing the solution’s soundness. While Patrick Steinhardt noted that the warning also appears in Meson builds, the thread treats this as a separate concern; the current patch remains focused on the Makefile. The discussion leaves open whether to extend suppression to Meson builds, but no further changes are needed for the immediate merge.
