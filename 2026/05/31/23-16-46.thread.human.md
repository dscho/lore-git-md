This thread is about a small but practical build system cleanup: silencing macOS linker warnings about duplicate library references in Git’s Makefile. Harald Nordgren sent a patch series to address the cosmetic warnings (`ld: warning: ignoring duplicate libraries`) that appear when the same library is listed multiple times in link commands—a necessary workaround for circular dependencies between archives.

The agreed solution, now in its third version, adds a macOS-specific linker flag (`-Wl,-no_warn_duplicate_libraries`) to `config.mak.uname`, gated to Xcode 15+ (ld64-907+, dyld-1009.5+) using the existing `LD_MAJOR_VERSION` infrastructure. This preserves the Makefile’s current logic while eliminating the noise during builds. Junio C Hamano, who proposed the approach, has given the patch a final review and called for broader testing across Xcode versions and build systems (Makefile vs. meson) to ensure the version gate and flag work as intended. No regressions are expected, and the patch is ready for merging once testing confirms its robustness. The discussion also sets a precedent for handling similar platform-specific linker behaviors in Git’s build system.
