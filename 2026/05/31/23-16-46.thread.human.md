This thread is about a build system cleanup to suppress macOS linker warnings about duplicate library references in Git’s Makefile and Meson builds. Harald Nordgren initially proposed the patch series to address cosmetic but noisy warnings (`ld: warning: ignoring duplicate libraries`) that appear during builds, particularly when the same library is listed multiple times to handle circular dependencies.

The series converged on a solution from Junio C Hamano: adding the linker flag `-Wl,-no_warn_duplicate_libraries` to `config.mak.uname`, version-gated for Xcode 15+ (ld64-907+, dyld-1009.5+). This approach was directly inspired by a prior Meson commit from Paolo Bonzini, who later endorsed the solution as architecturally sound and assigned the Meson integration to Patrick Steinhardt. D. Ben Knoble confirmed the patch works as intended on both older (Xcode 14.2) and newer (Xcode 26.1) macOS systems, with no regressions in Makefile or Meson builds. The patch is now ready for merging, and the Meson follow-up is a concrete next step with clear ownership.

Key participants include Harald Nordgren (author), Junio C Hamano (maintainer), Paolo Bonzini (Meson maintainer), Patrick Steinhardt (assigned Meson integration), and D. Ben Knoble (testing). The thread establishes a precedent for handling platform-specific linker behaviors in Git’s build system, aligning with upstream tools like Meson. No open questions remain for the Makefile patch, and the Meson integration is now a well-defined follow-up effort.
