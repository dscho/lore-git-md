This thread began with Harald Nordgren’s patch series addressing macOS linker warnings about duplicate library references in Git’s build system. The series has now concluded with a consensus solution: suppressing the warning at the linker level using `-Wl,-no_warn_duplicate_libraries` in `config.mak.uname`, version-gated for Xcode 15+ (ld64-907+, dyld-1009.5+). This approach preserves the ability to list libraries multiple times—a necessity for handling circular dependencies—while eliminating cosmetic noise during builds.

The solution was directly inspired by a prior Meson commit by Paolo Bonzini, who has now explicitly endorsed the same linker flag suppression for Git’s Meson builds, calling the warning "mostly a nuisance" and advising against version checks. D. Ben Knoble confirmed the patch works correctly on both older (Xcode 14.2) and newer macOS systems, and Patrick Steinhardt has agreed to implement the suppression in Meson as a follow-up. The v3 patch is ready for merging, with no outstanding technical objections.

Key participants included Junio C Hamano, who proposed the linker flag approach and emphasized maintainability; Paolo Bonzini, whose Meson precedent and endorsement reinforced the architectural soundness of the solution; and Patrick Steinhardt, who will handle the Meson integration. The thread establishes a pattern for handling platform-specific linker behaviors in Git’s build system, now aligned with Meson’s approach and backed by maintainer support.
