This is patch 3/12 in a merged bugfix series for git-gui, focusing on environment variable handling during repository operations. The patch addresses a subtle but important issue where git-gui was unconditionally setting GIT_DIR and GIT_WORK_TREE environment variables, including cases where GIT_WORK_TREE was empty (invalid in Git).

The change introduces two new helper functions - set_gitdir_vars and unset_gitdir_vars - that properly handle these environment variables. Key improvements include:
- Never exporting an empty GIT_WORK_TREE (which was causing errors)
- Properly maintaining the variables when needed (like when core.worktree is set)
- Centralizing the variable management logic to avoid duplication
- The patch also cleans up gitk and git-gui submodule handling by using these new functions

This is part of a larger effort to make git-gui's repository detection more robust and aligned with core Git behavior. The changes are well-contained and focused on fixing edge cases rather than introducing new functionality. The patch has already been reviewed and merged as part of the complete series.
