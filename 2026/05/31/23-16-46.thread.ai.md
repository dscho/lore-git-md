Thread identity: Build system cleanup patch series from Harald Nordgren addressing duplicate library references in Makefile link recipes, with focus on maintaining correct linker behavior while eliminating macOS build warnings. Series is now at v2.

Core problem: Multiple Makefile recipes contain duplicate library references causing macOS linker warnings (`ld: warning: ignoring duplicate libraries`), while requiring preservation of left-to-right linker symbol resolution where object files must precede archives. The challenge is to eliminate warnings without breaking this critical ordering, particularly during repeated test executions in development workflows like rebasing.

Current status: v2 patch merged Harald Nordgren's architectural solution that restructures $(LIBS) to explicitly include prerequisite archives first while maintaining correct ordering. The solution now consistently covers test helpers, fuzz targets, and unit test build rules with a maintainable approach that replaces v1's ad-hoc duplicate removal. The patch demonstrates thorough cross-platform testing, though some less common build configurations remain to be verified.
