Thread identity: Build system cleanup patch series from Harald Nordgren addressing macOS linker warnings about duplicate library references in Makefile link recipes. The series explores linker flag suppression as the agreed architectural approach. Thread type is patch series with build system focus.

Core problem: macOS linker emits warnings (`ld: warning: ignoring duplicate libraries`) when the same library appears multiple times in link commands, despite Git's build system sometimes intentionally listing libraries multiple times to handle circular dependencies between archives. The challenge is to eliminate the cosmetic warning without breaking symbol resolution or build system maintainability.

Current status: The series has concluded with the v3 patch implementing Junio C Hamano’s proposed solution: suppressing the warning at the linker level via `-Wl,-no_warn_duplicate_libraries` in `config.mak.uname`, version-gated for XCode 15+ (ld64-907+, dyld-1009.5+) using `LD_MAJOR_VERSION`. This approach preserves the existing Makefile logic while addressing the developer experience issue. Junio has now called for broader testing across Xcode versions (pre-15 and 15+) and build systems (Makefile and meson) as a final due-diligence step before merging. The patch remains ready for merging pending this verification.

Key technical details:
- Files touched: `config.mak.uname`
- New symbols/flags: `-Wl,-no_warn_duplicate_libraries` (macOS linker flag), version-gated via `LD_MAJOR_VERSION` regex matching ld, ld64, and dyld versions (ld64-907+, dyld-1009.5+)
- Linker behavior: macOS ld warns on duplicate libraries; GNU ld silently accepts them. The flag suppresses the warning without affecting symbol resolution
- Circular dependency handling: listing the same library multiple times remains necessary for correct symbol resolution (e.g., libA.a -> libB.a -> libA.a)
- Version gating: flag only applied to Xcode 15+ linkers, avoiding errors on older macOS versions. The regex now matches ld, ld64, and dyld to ensure robustness
- Alternative syntax: GNU ld's `--start-group`/`--end-group` remains less portable and was not adopted
- Build configurations: macOS-specific linker flag, version-gated using existing `LD_MAJOR_VERSION` infrastructure. Compatibility confirmed for both Makefile and meson build systems
- Test coverage: implicit in repeated test executions (e.g., rebase workflows) where warnings previously accumulated. Explicit testing requested for pre-Xcode 15 environments
