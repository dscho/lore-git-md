This is a test infrastructure patch in Johannes Schindelin's series addressing Windows platform limitations with large objects (>4GB). As patch 9/11 in v2, it extends the test tool's precomputed pack capabilities to support SHA-256 repositories.

The change adds a SHA-256 variant of the precomputed pack suffix data that was previously only available for SHA-1. The pack structure remains identical (same prefix and deflate blocks), but the suffix differs due to SHA-256's longer (32-byte) object IDs and different pack checksum format. The constants were generated by running the standard pack generation path in a SHA-256 repository.

This builds on earlier optimizations in the series (patches 5/11 and 8/11) that introduced precomputed pack data to dramatically speed up testing of large object handling. The SHA-256 support ensures the test infrastructure works equally well for both hash algorithms, though the immediate focus remains on Windows' 32-bit truncation issues. The patch maintains the series' careful attention to test performance while expanding coverage.
