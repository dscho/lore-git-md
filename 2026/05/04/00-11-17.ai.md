This is a documentation patch that updates the `git-pack-objects` man page to reflect current compatibility between `--path-walk` and other options. It's the first patch in Taylor Blau's 7-part RFC series addressing `--path-walk` integration with reachability bitmaps and delta-islands.

The patch corrects two outdated claims in the documentation:
1. Removes the incorrect statement that `--path-walk` is incompatible with `--shallow` (fixed in commit c178b02e29f)
2. Replaces the blanket `--filter` incompatibility notice with specific details about which filter types are supported (`blob:none`, `blob:limit=<n>`, `sparse:oid=<blob>`) and notes that others fall back to regular traversal

The changes are straightforward and well-justified by existing code behavior. This sets up the context for the subsequent patches in the series that will expand `--path-walk` compatibility further. The patch follows Git's documentation conventions and maintains the existing style while making the information more accurate.
