Feature: Final patch in series adding `--all-remotes` flag to `git branch` for branch pruning automation.

This is the sixth and final patch in Harald Nordgren's series to automate local branch cleanup when upstream branches are deleted. The series has evolved through multiple iterations based on Junio Hamano's feedback, culminating in this composable design where `git fetch --prune-merged` builds on new `git branch` plumbing commands.

The key addition here is `--all-remotes`, which works with both `--forked` and `--prune-merged` to operate across all configured remotes rather than requiring explicit remote arguments. This provides a convenient way to clean up branches tracking any remote, not just specific ones. The implementation:

- Adds the flag to both `--forked` and `--prune-merged` modes
- Uses `for_each_remote()` to collect all configured remotes
- Maintains all existing safety checks (preserving checked-out branches, honoring per-branch `pruneMerged=false` config)
- Includes comprehensive tests covering:
  - Basic functionality with multiple remotes
  - Error cases (invalid remote names)
  - Interaction with explicit remote arguments
  - Validation that the flag can't be used alone

The patch follows the series' established pattern of thorough documentation and test coverage. It completes the feature set by providing both granular control (specific remotes) and broad automation (`--all-remotes`), while maintaining the safety mechanisms that protect unpushed work and checked-out branches. With this addition, the series appears ready for final review and potential merging.
