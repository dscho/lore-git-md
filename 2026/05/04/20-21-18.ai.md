This patch adds support for the `object:type` filter to the path-walk machinery in `git pack-objects`, completing the set of object-type filters that can be used with the `--path-walk` optimization. The filter allows selecting only objects of a specified type (commit, tag, tree, or blob).

The implementation leverages the existing type-based filtering infrastructure in path-walk, using bitwise AND operations to preserve only the requested object types. The patch includes two important fixes to handle edge cases:
1. Maintaining pending trees when blobs are requested (since blobs may be reachable through trees referenced by tags)
2. Ensuring the walker sees these pending trees by properly setting `revs->tree_objects`

The patch adds comprehensive test coverage for all four object types, with particular attention to the blob case which exercises the pending-tree fix. Documentation is updated to reflect the new supported filter type.

This is part of a larger performance optimization series (v2 09/10) that integrates path-walk with various filter options. The implementation appears thorough and maintains the careful attention to edge cases seen throughout the series. The test coverage is particularly robust, verifying both the direct filtering behavior and the more subtle pending-tree interactions.
