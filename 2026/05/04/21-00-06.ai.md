This is a response to Junio C Hamano's review of the diff-stat pretty format placeholders patch. Andrey Zarubin addresses the design boundary concerns by clarifying the scope of the proposed feature - it only exposes the numeric counters from `--shortstat` (files changed, insertions, deletions) rather than richer diff content.

The author makes a technical distinction between these bounded scalar values (which are already computed for `--shortstat`) versus multi-line diff output like path summaries or patch text. He suggests the long `%(diff-stat:<field>)` forms make this limited scope clearer than the short aliases, and is willing to drop the short forms if they give the wrong impression about expanding the pretty format system's capabilities.

This reply engages substantively with the maintainer's philosophical concern while maintaining that the current proposal stays within reasonable bounds by focusing only on numeric statistics that are already-available data.
