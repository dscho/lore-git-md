This is a test infrastructure patch in Johannes Schindelin's series addressing Windows platform limitations with large objects (>4GB). The patch optimizes the test helper's performance by using unsafe SHA-1 hashing when generating large test packs.

The key change replaces `repo->hash_algo` with `unsafe_hash_algo()` in the test-synthesize helper, which provides significant speed improvements (3-5x faster) by using hardware-accelerated SHA-1 when available. This addresses Jeff King's observation that the large-object tests were dominating the test suite runtime (160+ seconds vs under 90s for the rest).

The optimization is safe for testing purposes as the helper generates known test data where collision detection isn't needed. The change is a no-op on platforms without an unsafe backend (like default builds on Windows), maintaining compatibility while improving performance where possible. This patch demonstrates responsiveness to review feedback about test suite efficiency while maintaining the series' focus on Windows-specific large object handling.
