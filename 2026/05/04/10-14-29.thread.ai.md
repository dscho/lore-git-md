The thread addresses test failures in t7703-repack-geometric.sh concerning MIDX (multi-pack-index) retention verification. The tests, introduced in commit 6ce9d558ce, check that `git repack --geometric` with `--write-midx` avoids rewriting an up-to-date MIDX file, covering both bitmap and non-bitmap cases. The original implementation compared full `ls -l` output, which proved unreliable on ZFS and similar copy-on-write filesystems due to variable 'total N' block count headers. The fix modifies the test cases to strip these headers using `sed 1d` before comparison, resolving the spurious failures while maintaining the intended verification of MIDX file stability. The patch is narrowly focused on this filesystem-specific test instability without altering the underlying MIDX behavior being tested. Multiple users had reported the issue across different non-traditional filesystem configurations.
