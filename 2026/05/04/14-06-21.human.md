Performance optimization in xdiff's Myers diff algorithm implementation. This is the fourth and final patch in Phillip Wood's series to reduce memory usage in Git's diff machinery. The change moves allocation of `reference_index` arrays to `xdl_cleanup_records()` where the actual needed size is known, shrinking these arrays from full-file size to just the count of processed lines.

The patch builds on the previous optimizations in the series, which have already been reviewed and approved by Junio C Hamano. The change is mechanical and focused solely on memory efficiency without affecting diff results. This continues Phillip Wood's established pattern of careful xdiff optimizations, particularly beneficial for large file comparisons. With Junio's prior approval of the technical approach and no new substantive changes in v2, this series appears ready for integration.
