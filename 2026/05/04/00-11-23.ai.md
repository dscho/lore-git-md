This is patch 3/7 in Taylor Blau's RFC series to integrate `--path-walk` with various Git features. The patch adds support for the `object:type` filter, which allows filtering objects by type (commit, tag, tree, or blob).

The implementation builds on the path-walk infrastructure's existing type-based filtering, with two key fixes needed for correct behavior:
1. Modified `setup_pending_objects()` to retain trees when blobs are requested (since blobs may be reachable through trees referenced by tags)
2. Adjusted revision walk setup to preserve pending tree objects when either trees or blobs are needed

The patch includes extensive test coverage (86 new lines) verifying all four object type filters work correctly. Notably, the blob filter test confirms that blobs reachable through tag-pointed trees are properly included.

Documentation is updated to list `object:type` among the supported filter forms. The changes are focused and well-contained, touching only `path-walk.c` and the test file while following patterns established in earlier patches.

This appears to be a solid technical contribution that moves the series forward while maintaining compatibility with the path-walk architecture. The test coverage is particularly thorough, exercising edge cases around tag-to-tree-to-blob reachability. Reviewers will likely focus on verifying the interaction between the pending objects handling and the filter logic.
