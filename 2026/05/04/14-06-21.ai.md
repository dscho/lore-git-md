This is the fourth and final patch in Phillip Wood's performance optimization series for xdiff, Git's diff algorithm implementation. The patch continues the theme of reducing memory usage in the Myers diff algorithm by shrinking dynamically allocated arrays.

The key change moves the allocation of `reference_index` arrays from `xdl_prepare_ctx()` to `xdl_cleanup_records()`, where the actual needed size (just the count of processed lines after prefix/suffix removal) is known. This shrinks these arrays from full-file size to only what's needed for the diff computation.

The patch maintains the same optimizations from v1, with only a rebase on latest upstream changes. Junio C Hamano had already given explicit "Looking good" approval to this approach in v1, confirming correct array access and appropriate allocation. The changes are mechanical memory optimizations that don't affect diff results, continuing Phillip Wood's established pattern of xdiff improvements.

This concludes a well-reviewed series that demonstrates careful attention to memory usage in core diff algorithms, particularly beneficial for large file comparisons. With Junio's prior approval and no new changes in v2 beyond the rebase, this patch appears ready for integration along with the rest of the series.
