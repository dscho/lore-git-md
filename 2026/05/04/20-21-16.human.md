This is a performance optimization patch (v2 07/10) from Derrick Stolee and Taylor Blau that adds `sparse:oid` filter integration to `git pack-objects`'s path-walk feature. The patch builds on their earlier work to make path-walk work with various filter types.

The key improvement here enables path-walk to efficiently handle `--filter=sparse:<oid>` by leveraging cone-mode sparse-checkout patterns to skip blobs outside the sparse scope while still walking all trees. This avoids the quadratic overhead of checking each object against sparse patterns individually. The implementation includes careful handling of edge cases where the same tree OID appears at both in-cone and out-of-cone paths.

Performance tests show dramatic improvements - 60% faster execution and 14% smaller packs when using path-walk with sparse filters compared to the standard approach. The patch includes extensive test suite additions that verify both correctness (matching the standard traversal's output) and the shared-tree-OID edge case.
