This is the second patch in Phillip Wood's performance optimization series for xdiff subsystem, focusing on memory usage improvements in the Myers diff algorithm. The patch simplifies the `xdl_clean_mmatch()` function by:

1. Removing the now-unused `s` parameter (always 0 after previous changes)
2. Changing the `e` parameter to accept a length value rather than an end index
3. Moving the end index calculation inside the function

These changes build on the first patch's optimizations and make the calling code cleaner. The modifications are purely internal - they don't affect the diff results, just make the code more straightforward to work with. 

Junio C Hamano had already reviewed and approved the technical approach in v1 of this series with a simple "Makes sense" response, indicating these are uncontroversial improvements. The v2 version shown here maintains the same changes while rebasing on upstream. This continues Phillip Wood's established pattern of careful xdiff-focused optimizations.
