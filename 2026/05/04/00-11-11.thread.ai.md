RFC series (7 patches) from Taylor Blau addressing `--path-walk` incompatibilities with reachability bitmaps and delta-islands, building on Derrick Stolee's filter integration work. Core goal: make path-walk work with GitHub's infrastructure requirements. Current status: patches 1-4/7 implemented, adding `tree:0`, `object:type`, and now `combine` filters after initial documentation updates.

Key technical elements:
1. Documentation updates (patch 1) correcting two claims in `git-pack-objects` man page:
   - Removes incorrect incompatibility with `--shallow` (fixed in c178b02e29f)
   - Replaces blanket `--filter` incompatibility with specific supported filters (`blob:none`, `blob:limit=<n>`, `sparse:oid=<blob>`, now including `tree:0`, `object:type`, and `combine`)
2. `tree:0` filter support (patch 2) with path-walk integration:
   - Simple flag-based implementation skipping tree/blob processing
   - Explicit rejection of path-sensitive `tree:1` filter
   - 45 lines of tests covering basic and edge cases
3. `object:type` filter support (patch 3):
   - Handles all four object types (commit, tag, tree, blob)
   - Modified `setup_pending_objects()` to retain trees when blobs are requested
   - Adjusted revision walk setup for tag-pointed tree cases
   - 86 lines of tests including tag-pointed tree cases
4. `combine` filter support (patch 4):
   - Monotonic restriction semantics (intersection of child filters)
   - Special handling for `blob:limit` (minimum size) and `sparse:oid` (single instance)
   - Rejection of unsupported subfilters like `tree:1`
   - 112 lines of tests in t6601 covering composition cases
5. Planned ports of Stolee's filter support for reachability bitmap integration (patch 5)
6. Delta-island support needing tree depth tracking and mark propagation (patch 7)

Touches `builtin/pack-objects.c` and `path-walk.c` with focused changes. Adds 439 lines of tests across t5310, t5320, t6600, t6601. Marked RFC due to:
- Potential approach refinement needed
- Coordination with Stolee's parallel work
- Performance impact on large repos
- Edge cases in bitmap/island integration

Open questions remain about the interaction between path-walk and core packing features, particularly how the bitmap and delta-island integrations will handle filtered objects. The `combine` filter implementation introduces new test coverage for filter composition cases that may inform later patches. Reviewers should focus on these areas as the series progresses. Follows established patterns from related work while introducing new interactions between subsystems.
