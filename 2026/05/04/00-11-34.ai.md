This is the final patch in Taylor Blau's RFC series addressing `--path-walk` compatibility with delta-islands, building on previous work to integrate path-walk with filters and bitmaps. The patch removes the documented incompatibility between `--path-walk` and `--delta-islands` by implementing the necessary mark propagation during path-walk traversal.

Key technical aspects:
1. For commits, calls `propagate_island_marks()` in the same descendant-first order as the regular traversal, ensuring proper island mark inheritance
2. For trees, records depths using the helper from patch 6, maintaining consistency with the main traversal's depth calculations
3. Updates documentation to remove the delta-islands incompatibility notice
4. Adds comprehensive tests verifying island behavior with path-walk in both regular and bitmap-enabled repacks

The implementation follows Jeff King's earlier suggestion that delta-islands fundamentally just need proper mark propagation, regardless of traversal method. The patch demonstrates this by carefully replicating the key behaviors from the regular traversal within path-walk's callback.

This completes the series' goal of making path-walk work with GitHub's infrastructure requirements. The changes are focused and maintain existing island semantics while enabling the new traversal mode. Reviewers will want to verify the subtle ordering guarantees around mark propagation and depth recording.
