This is a platform compatibility patch refining the handling of Clang compiler warnings for unused parameters. Maintainer Junio Hamano follows up on Dominik Loidolt's initial proposal to improve unused parameter warnings in Clang by providing a concrete implementation suggestion.

The key change introduces a new `GIT_CLANG_PREREQ` macro to properly detect Clang versions, mirroring the existing `GIT_GNUC_PREREQ` macro for GCC. This allows applying the more descriptive "parameter declared as UNUSED" warning (via the `deprecated` attribute) only to Clang versions 2.9 and newer, while maintaining compatibility with older versions. The implementation cleanly separates the version detection logic from the attribute application.
