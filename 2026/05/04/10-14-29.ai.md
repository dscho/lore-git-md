Test fix addressing spurious failures on ZFS and similar filesystems. The patch modifies two test cases in t7703-repack-geometric.sh that were comparing full `ls -l` output to verify MIDX retention behavior. The original tests could fail on copy-on-write or compressing filesystems where the 'total N' block count line from `ls -l` might change between invocations even when directory contents are identical. The fix strips this header line using `sed 1d` before comparing outputs.

The change relates to MIDX (multi-pack-index) retention checks introduced in commit 6ce9d558ce. The tests verify that `git repack --geometric` with `--write-midx` doesn't unnecessarily rewrite the MIDX file when it's already up-to-date, both with and without bitmap generation. The patch is small and focused, directly addressing a known filesystem-specific quirk that was causing test instability.
