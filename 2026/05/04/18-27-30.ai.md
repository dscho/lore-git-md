This sixth and final patch in Harald Nordgren's v2 series introduces a convenience flag `--all-remotes` that works with both the new `--forked` and `--prune-merged` options. When specified, it automatically includes all configured remotes in the operation, in addition to any explicitly named remotes. The implementation:

1. Adds the flag to both command variants in documentation and usage strings
2. Implements remote collection via `for_each_remote()` when the flag is set
3. Includes comprehensive tests verifying:
   - Basic functionality with `--forked`
   - Validation of explicit remote names even when `--all-remotes` is used
   - Rejection of standalone `--all-remotes` without a primary operation
   - Full integration with `--prune-merged` across multiple remotes

The patch maintains all existing safety checks and preserves the series' careful handling of checked-out branches and per-branch opt-outs. The tests demonstrate multi-remote scenarios and confirm the flag properly combines with explicit remote arguments.
