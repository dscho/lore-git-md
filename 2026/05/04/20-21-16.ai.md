This is a performance optimization patch (v2 07/10) from Derrick Stolee and Taylor Blau that adds `sparse:oid` filter support to `git pack-objects`'s `--path-walk` feature. The patch builds on their earlier work integrating path-walk with blob filters, now extending it to sparse-checkout patterns.

The key technical contribution is enabling path-walk to efficiently handle `--filter=sparse:<oid>` by leveraging cone-mode patterns to skip blobs outside the sparse scope while still walking all trees. This avoids the quadratic overhead of per-object pattern checks in the standard revision walk. The implementation loads sparse patterns from the given OID, verifies they're cone-mode compatible, and integrates them with the existing path-walk infrastructure.

A notable edge case addressed is when the same tree OID appears at both in-cone and out-of-cone paths - the patch ensures blobs are still found at the in-cone location even if the tree was first encountered out-of-cone. Performance tests show dramatic improvements: 60% faster execution and 14% smaller packs for sparse-filtered operations in the Git repository.

The patch includes comprehensive test coverage in t5317 and t6601, verifying both correctness (matching the standard walk's output) and the shared-tree-OID edge case. Documentation updates clarify that `sparse:oid` is now supported alongside other filters with `--path-walk`.

This appears to be a well-constructed patch with clear performance benefits, thorough testing, and careful attention to edge cases. It represents a meaningful step in the ongoing path-walk optimization effort while maintaining compatibility with existing sparse-checkout workflows.
