This is the first patch in Phillip Wood's v2 series optimizing xdiff's memory usage, specifically targeting the Myers diff algorithm implementation. The patch reduces the size of temporary action arrays in `xdl_cleanup_records()` to only cover the post-prefix/suffix portion of files rather than allocating for the full file size.

The key changes:
- Introduces `off`, `len1`, and `len2` variables to track the working range after prefix/suffix removal
- Adjusts array allocations and indexing to use these reduced sizes
- Maintains correct absolute indexing into xdfile_t structures via offset calculation
- Updates bounds passed to `xdl_clean_mmatch()` to match the new array sizes

This continues Phillip Wood's established pattern of xdiff optimizations, building on prior work in the en/xdiff-cleanup-3 series. The changes are mechanical memory optimizations that don't affect diff results, focusing specifically on the action arrays used during line change detection. Junio C Hamano has already reviewed the technical approach in v1 with only minor wording suggestions, indicating confidence in the changes. The v2 version appears to be a straightforward rebase with no substantive modifications.
