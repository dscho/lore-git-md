Feature: New `git branch --forked` plumbing command for branch management.

This patch introduces the foundational building block for Harald Nordgren's v2 series on automated branch pruning. It adds a new `git branch --forked <remote>` command that lists local branches tracking the specified remote(s). The command accepts either remote names (like `origin`) or specific remote-tracking refs (like `origin/master`), with multiple arguments being unioned.

Key technical details:
- The implementation parses remote arguments into two categories: configured remotes and specific remote-tracking refs
- Uses `refs_for_each_branch_ref()` to efficiently scan local branches
- Includes thorough test coverage in t3200-branch.sh for:
  - Basic remote name matching
  - Specific ref matching
  - Multiple argument unioning
  - Error cases (unknown remotes, missing arguments)

The command is designed to be composable with the upcoming `--prune-merged` functionality, following Junio's architectural feedback to decompose the branch management operations. The implementation appears clean with proper error handling and documentation.

This is the first of six patches in the series, establishing the read-only query primitive that the subsequent patches will build upon for actual branch pruning operations. The test cases demonstrate careful consideration of edge cases while maintaining a focused scope.
