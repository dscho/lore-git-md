This is a performance test addition for Derrick Stolee's ongoing `pack-objects` optimization series, specifically measuring the interaction between `--path-walk` and various filter options. The patch adds a new benchmark script `t/perf/p5315-pack-objects-filter.sh` that systematically compares packing performance across different filter combinations.

The test measures three scenarios:
1. Baseline with no filters
2. `blob:none` filter (blobless)
3. `sparse:oid` filter (cone-mode sparse)

Each scenario is tested both with and without `--path-walk`, producing timing and size measurements. The sparse filter setup is particularly clever - it automatically generates cone-mode patterns by sampling depth-2 directories from the test repository, making the test portable across different repository shapes. For repositories without depth-2 directories, it falls back to a single top-level directory.

Current results show modest differences between path-walk and non-path-walk modes, as the full integration isn't yet implemented (the path-walk feature currently falls back to standard revision walk). The most notable result is the sparse filter case taking ~72 seconds regardless of path-walk, hinting at the optimization potential this series aims to unlock.

The test will become more valuable as the series progresses, providing concrete measurements of the performance improvements from integrating path-walk with filters. The automatic sparse pattern generation ensures the test remains useful across different repository structures while maintaining consistent measurement conditions.
