This is patch 8/10 in Derrick Stolee and Taylor Blau's performance optimization series for `git pack-objects`, adding support for the `tree:0` filter in path-walk mode. The patch enables path-walk to efficiently handle the `tree:0` filter which omits all trees and blobs, keeping only commits and tags. The implementation is straightforward since this filter doesn't depend on path-sensitive state - it simply sets `info->trees = 0` and `info->blobs = 0` in the path-walk info structure. The existing path-walk infrastructure already handles these flags appropriately by skipping tree and blob processing entirely.

Key aspects:
- Non-zero tree-depth filters are explicitly rejected since they require path-walk depth information not currently exposed to the filter machinery
- Includes comprehensive test coverage verifying both `--all` and single-branch cases correctly omit trees/blobs
- Maintains the series' pattern of careful edge case handling while delivering performance benefits
- Updates documentation to reflect the newly supported filter type
