This is patch 6/7 in Taylor Blau's RFC series addressing `--path-walk` compatibility with delta-islands and reachability bitmaps. The patch focuses on delta-island integration by extracting tree depth recording logic into a reusable helper function.

The change factors out the delta-islands-specific tree depth calculation from `show_object()` into a new `record_tree_depth()` helper. This prepares for future changes that will need to record tree depths from another location. The helper:
- Takes a tree OID and path name as input
- Calculates depth by counting path components (slashes)
- Only updates depth if the object is in the pack list and the new depth is greater
- Now explicitly checks for tree objects only

The patch makes several cleanups while moving the code:
- Gates depth calculation on `obj->type == OBJ_TREE` since only trees need depth tracking
- Moves the packlist lookup earlier to avoid unnecessary depth calculations
- Maintains the same behavior but with clearer separation of concerns

This is a preparatory refactoring for the delta-island integration work that will follow in patch 7. The changes are focused and mechanical, touching only `builtin/pack-objects.c` with no behavior changes. The patch follows the series' pattern of careful, incremental changes with clear motivations.
