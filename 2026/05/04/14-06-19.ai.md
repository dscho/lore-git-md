This is the second patch in Phillip Wood's performance optimization series for xdiff subsystem, specifically cleaning up the `xdl_clean_mmatch()` function after the changes in the first patch. The changes are mechanical improvements to the diff algorithm's memory handling.

The patch simplifies `xdl_clean_mmatch()` by:
1. Removing the now-unused `s` parameter (always 0 after previous changes)
2. Changing the `e` parameter to accept a length rather than end index
3. Moving the end index calculation inside the function

These changes maintain the same behavior while making the calling code cleaner. The patch follows naturally from the first patch's adjustments to array bounds and continues the series' focus on reducing memory usage in xdiff's Myers diff implementation. Junio C Hamano had already approved the technical approach in v1 with "Makes sense", and this v2 version appears to be a straightforward rebase with no substantive modifications to the changes.
