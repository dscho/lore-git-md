This is the third patch in Taylor Blau's RFC series to make `--path-walk` work with GitHub's infrastructure requirements, specifically focusing on supporting the `object:type` filter. The patch builds on Derrick Stolee's earlier filter integration.

The key changes in this patch:
1. Adds support for `object:type=<type>` filters in path-walk, which restrict objects by type (commit, tag, tree, or blob)
2. Fixes two edge cases where pending trees were being incorrectly dropped when only blobs were requested
3. Adds comprehensive test coverage for all four object types in t6601
4. Updates documentation to list `object:type` as a supported filter

The implementation is careful to handle cases where blobs might be reachable through trees pointed to by lightweight or annotated tags. The test cases verify this by checking that blobs reachable only through tag-pointed trees are properly included when filtering for blobs.

This appears to be a well-constructed patch with thorough test coverage. The changes are focused and follow the established pattern from previous filter support work. The RFC flag suggests Taylor is open to discussion about the implementation approach, particularly around the pending tree handling.
