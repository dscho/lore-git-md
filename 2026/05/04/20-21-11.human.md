This is a performance test patch from Derrick Stolee, part of his v2 series optimizing `git pack-objects` with path-walk and filter integration. The patch adds a new benchmark script (t/perf/p5315-pack-objects-filter.sh) to measure the impact of different filter combinations on pack-objects performance.

The test measures three scenarios: no filter (baseline), blobless (`--filter=blob:none`), and sparse-checkout (`--filter=sparse:oid`), each tested with and without `--path-walk`. The script automatically generates sparse-checkout patterns by sampling repository directories, making it adaptable to different test repositories. Current results show modest differences between path-walk and standard traversal, with the most significant gains expected in later patches that fully integrate path-walk with filters.

The test infrastructure is thorough, handling edge cases like repositories without depth-2 directories by falling back to simpler patterns. This benchmark will help validate the performance improvements claimed in the rest of the series, particularly for sparse-checkout scenarios where path-walk optimizations are expected to shine.
