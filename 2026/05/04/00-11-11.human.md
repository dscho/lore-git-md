This is an RFC patch series from Taylor Blau addressing compatibility issues between Git's new `--path-walk` feature and several existing pack-objects optimizations. The series builds on Derrick Stolee's recent work integrating path-walk with object filters.

The key focus is making `--path-walk` work with:
1. Reachability bitmaps (by ensuring path-walk callbacks properly index commits for bitmapping)
2. Delta islands (requiring propagation of island marks and tree depth recording)
3. Various filter types (`tree:0`, `object:type`, and `combine` filters)

The series comes as 7 patches that:
- Document current incompatibilities
- Add filter support by adapting Stolee's approach
- Implement bitmap integration
- Enable delta-islands through helper extraction and mark propagation

Taylor notes this is still in RFC stage as he's unsure if this is the right approach and wants to coordinate with others working in this space (particularly Stolee). The patches include extensive test coverage across three test files.

This appears to be part of GitHub's effort to adopt `--path-walk` in their infrastructure, requiring compatibility with existing optimizations they rely on. The changes touch core packing logic but seem focused and incremental, building on established patterns from the bitmap and filter implementations.
