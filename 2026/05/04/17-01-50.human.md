This is a bug report about Git incorrectly trimming the last character of remote server output when displayed in a terminal. The issue occurs when remote messages (like GitLab's merge request URLs) are exactly the width of the terminal - the last character gets cut off due to an ANSI escape sequence ("\033[K") that clears the line from the current position to the end.

The reporter provides a clear reproduction case showing how a merge request URL gets truncated when the terminal width matches the line length. The problem doesn't occur when output is piped to another command or file. The issue appears to stem from sideband.c's handling of ANSI control sequences.

This looks like a legitimate display bug that could affect any user seeing remote messages in a terminal. The impact is relatively minor (cosmetic truncation of URLs), but could be annoying when trying to copy-paste links. The report is well-documented with specific examples and points to the likely culprit code.
