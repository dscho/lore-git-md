This is the second patch in Taylor Blau's RFC series to integrate `--path-walk` with various Git features. The patch adds support for the `tree:0` filter, which excludes all trees and blobs while keeping commits and tags.

The implementation is straightforward since `tree:0` doesn't depend on path information - it just sets flags to skip trees and blobs entirely during the walk. The patch includes:

1. Documentation updates to list `tree:0` alongside other supported filters
2. Filter handling code that rejects non-zero tree depths (which would require path-aware filtering)
3. Comprehensive tests verifying the filter works with both `--all` and single-branch walks, plus a test confirming the rejection of `tree:1`

The changes are cleanly scoped to `path-walk.c` and the pack-objects documentation, following the pattern established in earlier filter integrations. The 45 lines of new test coverage provide clear verification of both the happy path and error cases.

This appears to be a well-constructed patch that moves the overall series forward while maintaining the RFC status for the more complex bitmap and delta-island integrations still to come. Reviewers will likely focus on whether the error handling and test coverage adequately capture the edge cases around filter interactions.
