This is a performance optimization patch from Derrick Stolee (with Taylor Blau) that enables `--path-walk` to work with blobless filters in `git pack-objects`. It's part of a larger series (v2, patch 3/10) integrating path-walk with various filter options.

The key change allows `--path-walk` to handle `blob:none` filters by:
1. Modifying the path-walk API to recognize and process blobless filter case
2. Clearing the filter from revs to avoid rejection during walk preparation
3. Adding test coverage for blobless filtering with both `--all` and single-branch cases

Performance tests show the tradeoffs - while computation time increases (~73% slower), the resulting packs are 16% smaller due to better delta compression when not reusing deltas. The implementation appears thorough with careful attention to test coverage and API boundaries.

The patch builds on previous path-walk work and maintains compatibility with the broader optimization goals while expanding filter support. It demonstrates measurable benefits for blobless partial clone scenarios while setting up infrastructure for future filter integrations.
