This is a preparatory patch in Derrick Stolee's performance optimization series for `git pack-objects` with `--walk-path` and filter options. The patch addresses a technical issue where the revision walk machinery requires explicit `--objects` when using filters, even though the path-walk API previously assumed this implicitly.

The change is straightforward: adds `--objects` to the revision parameters when `--path-walk` is enabled, while maintaining the bitmap disablement that was already in place. The patch removes an outdated comment about "removing" options that was misleading since they were never actually removed.

This appears to be a clean, mechanical change that properly sets up the revision walk infrastructure for the filter support being added in later patches of the series. The modification is minimal (just 5 lines changed) and focused specifically on enabling the filter functionality without introducing new behavior.
