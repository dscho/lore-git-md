This is a preparatory patch in Derrick Stolee's performance optimization series for `git pack-objects` with `--path-walk` and `--filter` options. The patch fixes an issue where the path-walk API would trigger a fatal error when used with object filters, by explicitly adding the `--objects` flag that the revision machinery requires for filtering.

The change is straightforward - it removes an outdated comment about "removing" options (which wasn't actually happening) and adds the necessary `--objects` flag while maintaining the bitmap disablement that was already in place. This is a small but important foundation for the subsequent patches that will enable various filter types to work with the path-walk optimization.

The patch appears clean and focused, addressing a clear technical requirement for the larger series. It's part of an ongoing effort that has already gone through one round of review and is now in its second iteration, with test coverage and performance benchmarks showing promising results for sparse-checkout scenarios.
