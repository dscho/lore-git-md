This is patch 2/7 in Taylor Blau's RFC series to integrate `--path-walk` with reachability bitmaps and delta-islands. The patch adds support for the `tree:0` filter in path-walk operations, which omits all trees and blobs while keeping commits and tags.

The implementation is straightforward since `tree:0` doesn't depend on path-sensitive state - it simply sets flags to skip tree and blob processing during the walk. The patch includes:

1. Documentation updates to list `tree:0` among the compatible filters
2. Filter handling in `path-walk.c` that rejects non-zero tree depths (which require path-sensitive state)
3. Comprehensive tests verifying:
   - Correct filtering behavior with `--all` and single-branch cases
   - Proper rejection of unsupported `tree:1` filter
   - No tree/blob objects in output

The changes are cleanly scoped to the filter integration goal, following the pattern established in earlier filter support work. The test coverage is thorough, with 45 new test lines across three scenarios. This appears to be a well-constructed patch that moves the overall series forward while maintaining compatibility with existing behavior.

As noted in the cover letter, this remains marked RFC pending discussion of the approach, particularly around how it fits with Derrick Stolee's parallel work on path-walk filters. Reviewers will likely focus on whether this implementation properly handles edge cases and maintains expected performance characteristics.
