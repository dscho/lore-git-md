This is patch 8/10 in Derrick Stolee and Taylor Blau's performance optimization series for `git pack-objects`, focusing on integrating path-walk with filter options. The patch adds support for the `tree:0` filter, which excludes all trees and blobs from the output, keeping only commits and tags.

The implementation is straightforward since `tree:0` doesn't require path-sensitive state - it simply sets flags to skip trees and blobs during the walk. The patch includes tests verifying that no trees or blobs are emitted with `tree:0`, and that non-zero tree-depth filters (like `tree:1`) are properly rejected with an error message.

This continues the series' pattern of adding filter support while maintaining performance gains from the path-walk optimizations. The patch appears well-contained with clear test coverage, though as with the rest of the series, sparse-checkout experts may want to review the edge case handling. The documentation is also updated to reflect the new supported filter type.
