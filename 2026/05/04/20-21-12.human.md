This is a performance optimization patch from Derrick Stolee (with Taylor Blau) that enables `git pack-objects` to use the `--path-walk` option with blobless filters (`--filter=blob:none`). It's part of a larger series (v2 03/10) focused on integrating path-walk with various filter options.

The key change allows path-walk to natively handle blobless filters by skipping blob objects during the walk while still processing commits and trees. The patch includes:
- Core logic to detect and handle blob:none filters in path-walk.c
- Documentation updates noting the new compatibility
- Test helper updates to support filter testing
- New test cases verifying blobless behavior with both --all and single-branch walks

Performance tests show a tradeoff - path-walk with blob:none yields 16% smaller packs but takes 73% longer due to extra compression passes. The implementation appears thorough, with careful attention to test coverage and edge cases. This continues the series' focus on optimizing sparse-checkout scenarios while expanding filter compatibility.
