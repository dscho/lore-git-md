This is a bug report about terminal output corruption in Git's remote message handling. Hugo Osvaldo Barrera reports that when Git displays remote messages (like GitLab's merge request URLs) in a terminal where the line width exactly matches the terminal width, the last character gets truncated. The issue stems from Git's use of the ANSI escape sequence "\033[K" (clear to end) in sideband.c, which appears to eat the last character in this edge case. The problem doesn't occur when output is piped to another command or redirected to a file.

The report is well-documented with clear reproduction steps and analysis pointing to the likely culprit in the code. This affects the user experience when viewing remote messages, particularly from GitLab, though the underlying issue would affect any remote message output that hits this terminal width edge case. The bug appears to be in how Git handles line wrapping and ANSI control sequences in terminal output.
