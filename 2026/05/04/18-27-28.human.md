Feature: `fetch --prune-merged` integration for automatic local branch cleanup.

This patch adds the `--prune-merged` option to `git fetch`, completing the plumbing chain for Harald Nordgren's redesigned local branch pruning functionality. When enabled, it automatically runs `git branch --prune-merged` after a successful fetch to clean up local branches whose upstream tracking refs were pruned.

The implementation:
- Adds the new option to fetch's documentation and CLI
- Invokes the `--prune-merged` plumbing command after successful fetches
- Includes tests verifying both the happy path (merged branches deleted) and safety case (unmerged branches preserved with warning)

This builds on the standalone `git branch` plumbing commands introduced earlier in the series (patches 1-3), following Junio Hamano's architectural guidance to decompose the functionality. The design cleanly separates concerns while maintaining the original goal of automating branch cleanup without risking unpushed work.

- Clear documentation of the new option
- Straightforward integration with fetch's existing flow
- Complementary test coverage for core scenarios
- Preservation of all safety mechanisms from the underlying plumbing
