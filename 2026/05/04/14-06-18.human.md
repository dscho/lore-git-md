Performance optimization in xdiff diff algorithm implementation. This is the first patch in a v2 series from Phillip Wood that reduces memory usage in Git's diff machinery by shrinking temporary arrays used during the Myers diff algorithm.

The patch focuses on `xdl_cleanup_records()` in xdiff/xprepare.c, which processes files after removing common prefix/suffix lines. It introduces `len1`/`len2` variables to track the actual needed array sizes (just the lines between prefix/suffix) rather than allocating for the full file. The changes maintain correct indexing via an offset while updating all array accesses to use the new bounds. This continues Phillip Wood's established pattern of xdiff optimizations.

Junio C Hamano has already reviewed the technical approach in v1 with only minor wording suggestions, indicating confidence in the changes. The v2 appears to be just a rebase with no substantive changes from the approved v1. The optimization should benefit large file comparisons while maintaining identical diff results.
