This is a performance optimization series from Derrick Stolee (with contributions from Taylor Blau) that integrates `--path-walk` with various `--filter` options in `git pack-objects`. The series builds on previous path-walk work and demonstrates significant performance improvements, particularly for sparse-checkout scenarios.

The key technical contribution is enabling `--path-walk` to work with three filter types:
1. `blob:none` - skips blobs during the path walk
2. `blob:limit=<size>` - filters out large blobs
3. `sparse:<oid>` - validates paths against sparse-checkout patterns

The most compelling performance gains come from the sparse filter integration, where checking patterns against entire path groups proves much faster than per-blob checks. Benchmarks across several repositories show dramatic improvements - for example, the git/git repository sees a 60% speedup (72.53s to 29.00s) when using `--path-walk` with sparse:<oid> filtering.

The series also introduces infrastructure for future work, including a proposed `treesparse:<oid>` filter that would leverage cone-mode sparse-checkout patterns, though this isn't implemented yet. The changes touch core path-walk logic and add new test coverage, including a new performance test script.

This v2 iteration rebases onto en/backfill-fixes-and-edges and incorporates Taylor Blau's patches to extend support for additional filter types (`tree:0`, `object:type`, and `combine`). The implementation appears thorough with careful attention to both performance and correctness, though the interaction between path-walk's tree pruning and sparse filters may warrant close review from sparse-checkout experts. The series continues demonstrating robust optimization of sparse-checkout scenarios while maintaining strict filter compatibility.
