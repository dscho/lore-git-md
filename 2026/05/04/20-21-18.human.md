This is the 9th patch in a 10-part performance optimization series from Taylor Blau and Derrick Stolee, adding support for the `object:type` filter in `git pack-objects`'s path-walk machinery.

The patch enables filtering objects by type (commit, tag, tree, or blob) during path-walk operations, similar to existing bitmap traversal support. The implementation leverages the path-walk's existing type flags (info->{commits,trees,blobs,tags}) to efficiently filter objects without additional overhead.

Key technical aspects:
- Uses bitwise AND operations to map the filter type to the appropriate flags
- Fixes two edge cases where trees need to be preserved when filtering for blobs (to catch blobs reachable through tag-pointed trees)
- Adds comprehensive test coverage for all four object types
- Updates documentation to include `object:type` in the supported filters list

The patch maintains the series' focus on performance while expanding filter capabilities. It follows the established pattern of careful edge case handling and thorough testing seen in previous patches. The implementation appears clean and well-integrated with the existing path-walk optimizations.

This continues the series' progression toward full filter support in path-walk, with only one patch remaining in the v2 submission. The changes are focused and build logically on the foundation established earlier in the series.
