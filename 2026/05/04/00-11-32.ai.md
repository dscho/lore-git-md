This is patch 6/7 in Taylor Blau's RFC series addressing `--path-walk` compatibility with delta-islands and reachability bitmaps. The patch focuses on delta-island integration by refactoring tree depth tracking.

The change extracts tree depth recording logic from `show_object()` into a new helper function `record_tree_depth()`, preparing for future use from another call site. The helper:
- Takes a tree OID and path name as input
- Calculates depth by counting path components (slashes)
- Only updates depth for trees already in the `to_pack` list
- Maintains the maximum observed depth per tree

The patch includes minor cleanups:
- Gates depth calculation on `OBJ_TREE` type since only trees need depth tracking
- Moves the `packlist_find()` check earlier to avoid unnecessary work
- Preserves the existing depth calculation logic (empty path = depth 0)

This is a straightforward refactoring that doesn't change behavior but makes the code more reusable for the upcoming delta-island integration work. The changes are well-contained to `builtin/pack-objects.c` and maintain the existing depth tracking semantics. The patch follows the series' pattern of focused, incremental changes with clear motivation.
