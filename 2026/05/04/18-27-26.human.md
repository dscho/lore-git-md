Feature: Improved branch deletion warnings for bulk operations in `git branch`.

This second patch in Harald Nordgren's v2 series enhances the branch deletion machinery to better support bulk operations. The key change is modifying `delete_branches()` and its helper `check_branch_commit()` to provide more appropriate feedback when pruning multiple branches at once.

The patch introduces two new parameters:
- `warn_only` - downgrades the error message about unmerged branches to a one-line warning (rather than the current error + four-line advice)
- `n_not_merged` - allows counting skipped branches without printing per-branch advice

The existing behavior remains unchanged for single-branch deletions (`git branch -d`), which still show the full error and advice. The new parameters will be used by the upcoming `--prune-merged` functionality to provide cleaner output when pruning many branches at once.

The implementation is clean and focused, with thorough error handling preserved. The changes are well-contained within `builtin/branch.c` and the patch maintains backward compatibility of all existing callers by defaulting the new parameters to their original behavior.

This is a sensible refinement that addresses a real usability issue - the current verbose error messages would be overwhelming when pruning many branches. The patch demonstrates good attention to both functionality and user experience in bulk operations.
