This is the third patch in Phillip Wood's four-part performance optimization series for xdiff diff algorithm memory usage. The patch simplifies error handling in `xdl_cleanup_records()` by combining two separate allocation failure checks into a single conditional with logical OR operator.

The change is straightforward - instead of checking each XDL_CALLOC_ARRAY() call individually and jumping to cleanup on failure, it now checks both allocations in one if statement. This reduces code duplication and makes the control flow clearer, particularly as the same error handling path is used in both cases. The patch also prepares for future changes that will add more allocations to the same error handling path.

Junio C Hamano had already reviewed this approach in v1 of the series and confirmed the consolidation was safe given the shared cleanup path. The v2 version maintains this change with only a rebase on upstream changes. This continues the series' pattern of mechanical, non-functional improvements to xdiff's memory handling that don't affect diff results.
