Feature enhancement for `git add -p` adding a word-diff view option.

This patch introduces a new 'w' command to `git add -p` that displays the current hunk using word-diff formatting, making it easier to review inline changes in files with long lines (like JSONP, CSV, LaTeX, or Markdown). The implementation builds word-diff versions of the old/new content and uses Git's existing diff machinery to render the word-diff output.

The change touches three files:
1. Documentation update to add the new command to the help text
2. Core implementation in add-patch.c with new functions to:
   - Build word-diff versions of the hunk content
   - Handle the word-diff display logic
3. Test updates to verify the new functionality and ensure existing tests account for the new command in prompts

The implementation appears clean and focused, with proper test coverage including a dedicated test case for the word-diff functionality. The patch maintains backward compatibility while adding a useful feature for reviewing certain types of changes. The commit message clearly explains the motivation and behavior without being overly verbose.

This would be particularly helpful for reviewing changes in structured text formats where small inline modifications can be hard to spot in regular line-based diffs. The implementation follows Git's existing patterns for handling diffs and interactive commands.
