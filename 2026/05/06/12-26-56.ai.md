This is a bug report about a minor output inconsistency in `git reflog expire`'s used with `--dry-run`. The author, Sven Weiland, notes that when running `git reflog expire --verbose --expire=now --dry-run HEAD`, the output shows "prune checkout: <something>" when it should show "would prune checkout: <something>" to be consistent with other dry-run outputs in Git.

The issue is purely cosmetic - the actual behavior matches expectations for a dry-run, but the wording differs from Git's usual dry-run convention of prefixing actions with "would". The report includes full system information showing this was observed with Git 2.54.0 on Linux. No patch is provided; this appears to be an initial bug notification rather than a proposed fix.
