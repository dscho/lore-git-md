This is a follow-up in the Windows large-objects thread, where Johannes Schindelin points to Patrick Steinhardt's diagnosis of the CI build failure that Junio had noted. The issue stems from a conflict between glibc's use of C11's `_Generic` feature in system headers and clang's strict C99 checking, which was triggered by an upgrade to Ubuntu 26.04 in the CI runners.

Patrick has already proposed a fix (linked in the email) that would make the CI more tolerant of this glibc behavior. This is a good example of how platform-specific work (the Windows large-objects series) can surface broader toolchain compatibility issues, and how the community collaborates to diagnose and address them quickly. The exchange also shows how CI infrastructure upgrades can have unexpected effects on build stability.
