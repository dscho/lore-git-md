Core problem: When rebase.instructionFormat includes %d (ref decorations), the rebase machinery incorrectly generates update-ref instructions for non-branch refs like HEAD or tags in both interactive and non-interactive modes. The fix in sequencer.c filters decorations to DECORATION_REF_LOCAL types via load_branch_decorations(). Phillip Wood confirmed that non-interactive rebase shares this code path by design (it is effectively git rebase -i with no sequence editor), so the same behavior is expected rather than surprising.
