This is a performance optimization patch in Johannes Schindelin's RFC series adding merge commit support to `git history`. The patch targets the common case where a history rewrite (like `git history reword`) only changes commit messages while leaving all trees unchanged.

The key optimization detects when both the rewritten parents and their merge bases have identical trees to the originals, allowing it to skip three expensive merge operations per merge commit. This provides significant speedup for the common case of simple message rewrites in histories with many merges.

The implementation carefully checks both parent trees and all merge base trees to ensure the optimization is safe - it only applies when the auto-merge results would be identical. The patch demonstrates good attention to edge cases while providing measurable performance benefits for the happy path.
