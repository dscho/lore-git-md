A minor output inconsistency has been reported in `git reflog expire` when used with `--dry-run`. Sven Weiland observed that while the command correctly performs a dry run (not actually pruning anything), its verbose output says "prune checkout" where it should say "would prune checkout" to match Git's standard dry-run messaging convention. This is purely a cosmetic issue in the output formatting - the functionality itself works as expected. The report was filed against Git 2.54.0 on Linux, but no patch has been proposed yet to address the wording discrepancy.
