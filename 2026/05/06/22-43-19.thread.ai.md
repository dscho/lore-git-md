RFC proposal from Johannes Schindelin to add merge commit support to `git history` (introduced in Git 2.54), building on Elijah Newren's design. Current implementation focuses on 2-parent merges while explicitly deferring octopus merges and merge reverts. Core approach uses three-way merge composition: R (auto-remerge of original parents), N (auto-remerge of rewritten parents), and O (original merge tree), layering user's manual resolutions onto new auto-merge using R as base.

Key technical details:
- `replay.c` merge handling updated with consistent conflict marker labels between R and N
- `create_commit()` refactored to support multiple parents while maintaining boundary commit mapping
- New performance optimization (part 2/5) detects when only commit messages change (`reword` case), skipping expensive merge operations by reusing original trees when parent and merge base trees match exactly
- Merge bases computed upfront for reuse in both fast and slow paths
- Explicit rejection of octopus merges and merge reverts in current scope
- New test infrastructure (`test-historian` helper) and extensive test coverage (300+ line `t3454-history-merges.sh`)
- Documentation updated to reflect supported merge scenarios (two-parent merges using R/O/N algorithm) and limitations (octopus merges, symbol-level intent propagation)

Open questions for RFC feedback:
- Merge conflict handling strategy adequacy
- Boundary case behaviors under complex merge scenarios
- Test coverage completeness for edge cases
- Performance impact measurement of the new optimization
- Clarity of documentation around when to fall back to interactive rebase

Implementation shows thoughtful incremental improvements to the recently introduced v2.54 command, now with performance optimizations for common cases and comprehensive documentation. The series remains in RFC status seeking design feedback, with reviewers encouraged to examine both the core merge composition logic, the new optimization's correctness guarantees, and the accuracy of the updated documentation.
