Refactoring patch as part of a series introducing a new `git url-parse` command. This first patch renames the `enum protocol` to `enum url_scheme` and related functions/variables to use RFC 1738 terminology ("scheme" instead of "protocol"). The change is purely mechanical with no behavior changes, preserving existing diagnostics and error messages.

The rename helps avoid confusion with the unrelated `enum protocol_version` and prepares for exposing URL parsing logic in a shared header. The patch follows Torsten Bögershausen's suggestion to use standard URL terminology. It's a clean, focused change that establishes consistent naming before the subsequent patches build on it.

This is the first of 8 patches in v2 of the series, which has already incorporated feedback from v1 (as noted in the thread summary). The series aims to provide reliable URL parsing plumbing that matches Git's internal behavior, particularly for non-standard formats like SCP-style URLs.
