This is patch 4/8 in the `git url-parse` series, continuing the refactoring of Git's URL parsing logic. The patch makes `url_get_scheme()` return `URL_SCHEME_UNKNOWN` for unrecognized schemes rather than dying, moving the error handling to `parse_connect_url()` where the function is used.

The change allows `url_get_scheme()` to be used in contexts that need to identify a URL's scheme without aborting the program, such as the upcoming `git url-parse` plumbing command. The patch maintains the same external behavior for existing callers by keeping the die() call in `parse_connect_url()` with the same error message.

Key technical details:
- Adds `URL_SCHEME_UNKNOWN` with value 0 to the `enum url_scheme`
- Removes the die() call from `url_get_scheme()` and makes it return the new enum value
- Moves the error handling to `parse_connect_url()` where the scheme is actually used
- Removes the now-unneeded `gettext.h` include from url.c
- Updates the function documentation in url.h to reflect the new behavior

This is a clean refactoring that improves the API's flexibility while maintaining backward compatibility. The change aligns with the series' goal of making URL parsing logic more generally usable outside of Git's connection-specific code paths.
