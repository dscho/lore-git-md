This is part 4 of a feature series introducing a new `git url-parse` builtin command, focusing on making the URL scheme detection more flexible. The patch modifies `url_get_scheme()` to return `URL_SCHEME_UNKNOWN` for unrecognized schemes rather than dying, moving the error handling to `parse_connect_url()` where it's actually needed.

The change allows the URL parsing logic to be used in contexts where failure should not be fatal, such as validation tools. The implementation is clean - it adds the new enum value, removes the `die()` call from `url_get_scheme()`, and adds equivalent error handling in `parse_connect_url()` while maintaining the same user-facing behavior.

This is a logical step in the series' progression toward exposing Git's URL parsing as reusable plumbing. The patch follows the established pattern of the earlier refactoring work while enabling new use cases. The change is well-contained and doesn't introduce any behavior changes for existing callers.
