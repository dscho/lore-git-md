Bugfix targeting the rebase status display. This is the second patch in a two-part series from Phillip Wood that improves how `git status` shows the rebase todo list during interactive rebase operations.

The patch fixes two specific issues in the status output: it now properly abbreviates commit object IDs in "fixup -C" and "merge -C" commands (which were previously shown in full), and it preserves refnames rather than incorrectly substituting them with object IDs in commands like "reset" and "update-ref". The implementation carefully handles edge cases by only abbreviating object IDs when they start with the abbreviated form, avoiding confusion with branch names that might consist entirely of hex digits.
