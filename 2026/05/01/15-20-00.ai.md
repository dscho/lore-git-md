This is a refactoring patch that's part of the ongoing `the_repository` removal effort. Phillip Wood renames `get_worktree_from_repository()` to `get_current_worktree()` to better reflect its actual behavior after a recent change (commit 0f779147602) made it always return the current worktree. The change was suggested by Junio C Hamano.

The patch is straightforward, touching only three files to update the function name and its single call site in `wt-status.c`. This appears to be a mechanical cleanup following the earlier behavioral change, with no functional impact. The rename improves clarity by making the function's behavior more obvious from its name.

The patch is part of Phillip Wood's broader work on the worktree subsystem and aligns with the project's effort to make repository and worktree handling more explicit. Given the maintainer's suggestion and the non-controversial nature of the change, this is likely to be merged without significant discussion.
