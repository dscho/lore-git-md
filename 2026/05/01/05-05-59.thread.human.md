This thread reports an issue with Git's rename detection for Ruby files when classes are moved between namespaces. Sébastien Stettler demonstrates that while simple class renames are correctly detected as file renames, moving a class between namespaces (e.g., `Foo::Bar` to `Foo::Baz::Bar`) is treated as a deletion and addition rather than a rename. 

The reporter has provided a test repository showing the behavior difference and is seeking clarification on whether this is intentional (and the reasoning behind it) or if it represents an opportunity to improve Git's rename heuristics for Ruby code. They've offered to assist with test cases and potential implementation if the behavior is considered suboptimal. The report includes all relevant system details (Git 2.47.1 on macOS ARM64) to help diagnose the issue.
