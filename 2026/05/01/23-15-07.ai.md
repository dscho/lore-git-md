This is patch 5/8 in a feature series introducing a new `git url-parse` builtin command. The patch defines a new `url_parse()` function in urlmatch.[ch] that provides generalized URL parsing supporting all Git URL formats including SCP-style and IPv6 addresses.

Key technical aspects:
- Adapts the parsing algorithm from `parse_connect_url()` in connect.c but with a different contract (returns NULL on failure rather than dying)
- Uses the same interface as `url_normalize()` and shares the `url_info` struct
- Handles SCP-style URLs by converting them to SSH URLs internally
- Includes comprehensive unit tests for SCP syntax, URL forms, and query/fragment stripping
- Deliberately diverges from `parse_connect_url()` in rejecting bare local paths (requires scheme://host form)
- Maintains consistent scheme classification with the connection path code

The implementation appears robust with:
- Careful handling of IPv6 and bracketed hostnames
- Proper memory management (strbuf usage, xstrndup/free)
- Clear documentation of intentional differences from parse_connect_url
- 45 new test cases covering edge cases

This continues the series' pattern of thorough implementation and test coverage. The patch builds on previous refactoring work (patches 1-4) to establish clean separation between URL parsing and connection logic. The new function provides the core plumbing needed for the upcoming `git url-parse` command while maintaining compatibility with existing URL handling code.
