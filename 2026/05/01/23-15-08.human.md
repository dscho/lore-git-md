This is patch 6/8 in a feature series introducing a new `git url-parse` plumbing command. The command exposes Git's internal URL parsing logic to allow scripts to reliably extract components from Git's various URL formats (including non-standard ones like SCP-style URLs).

The patch implements the core command-line interface for `git url-parse`, which can:
- Parse URLs using Git's internal logic (building on the refactored URL parsing functions from earlier patches)
- Extract specific components (scheme, user, password, host, port, path) via the `-c` option
- Reject invalid URLs with clear error messages
- Handle multiple URLs in a single invocation

Key implementation details:
- Uses the `url_info` struct consistently across parsing functions
- Returns components as offset/length pairs into normalized URL buffer
- Includes comprehensive error handling for invalid URLs and components
- Follows Git's standard command structure with parse_options() and usage strings

The implementation looks clean and well-integrated with the preparatory refactoring done in earlier patches. This provides a useful plumbing primitive for tools that need to interact with Git repositories programmatically, particularly given Git's support for non-standard URL formats that general-purpose URL parsers can't handle.

The series as a whole appears well-structured and thorough, with this patch completing the user-facing command after the foundational refactoring and parsing logic were established in previous patches.
