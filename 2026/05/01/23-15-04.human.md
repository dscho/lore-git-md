This is part 2 of a 13-patch series introducing a new `git url-parse` builtin command, now at version 2. The series aims to expose Git's internal URL parsing logic for use by external tools.

This particular patch is a straightforward refactoring that moves the `url_is_local_not_ssh()` function from connect.c to url.c, making it available to other URL-handling code without requiring a dependency on connect.c. The function's logic remains unchanged - it still distinguishes local paths from SCP-style SSH URLs using the same colon/slash position heuristic and DOS drive prefix check.

The change is mechanical but important for the larger effort, as it allows the new URL parsing code (introduced in later patches) to reuse this utility function. The patch includes the necessary header updates and adds the missing include in remote.c that was implicitly relying on connect.h's declaration.

As part of the series' RFC-compliance improvements (noted in the thread context), this moves URL-related functionality into dedicated URL-handling files rather than keeping it scattered across the codebase. The patch appears clean and well-contained, following the series' overall goal of making Git's URL parsing logic more modular and reusable.
