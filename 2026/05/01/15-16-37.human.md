This is a bugfix series from Phillip Wood addressing display issues in `git status` during interactive rebases. The two patches improve how the rebase todo list is shown by fixing incorrect object ID abbreviation and refname preservation.

The first patch factors out the sequencer's todo command parsing logic into a reusable function (`sequencer_parse_todo_command()`), enabling shared use by the status display code. The second patch then uses this to properly handle "-C" commands and refnames in the status output. The changes touch core rebase machinery (sequencer.c) and status display code (wt-status.c), with test updates in t7512.
