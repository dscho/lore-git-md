This thread is about the final version (v24) of Harald Nordgren's `git branch --delete-merged` series, which is now ready to be merged. The series introduces a safe, automated way to clean up local branches that have been merged into their upstream, with robust filtering and safety controls.

The core feature is the `--delete-merged` subcommand, which deletes local branches merged into a specified upstream (e.g., `origin/main`) while preserving branches used as upstreams for unmerged work. Key safety mechanisms include per-branch opt-out via `branch.<name>.deleteMerged=false`, order-independent protection for stacked branches, and a `--dry-run` preview mode. The v24 update fixed two critical correctness issues: the push-detection logic now accurately determines whether pushing a branch would update its upstream, and the stacked-branch protection has been simplified to clear stale upstream configs for kept branches.

The series is now effectively complete, with all planned features implemented and thoroughly tested.
