Harald Nordgren’s `git branch --delete-merged` series is now complete and ready for final review after 16 iterations. The feature provides safe, automated cleanup of local branches that have been merged, with multiple safety mechanisms to prevent accidental data loss. Key capabilities include filtering by forked branches, per-branch opt-out via configuration, and a `--dry-run` mode to preview deletions.

The series has addressed all prior feedback, including API consistency, safety checks, and test coverage. Phillip Wood and Junio C Hamano provided significant input on the design, with Phillip focusing on the flags-based API and Junio confirming that stacked-branch safety checks were unnecessary. The final patch adds the `--dry-run` option, which mirrors the actual deletion logic without modifying any refs, completing the feature set. All safety mechanisms—such as preserving checked-out branches, branches with missing upstreams, and those with push divergence—remain intact.
