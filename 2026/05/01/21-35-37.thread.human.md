Harald Nordgren's `git branch --prune-merged` series (formerly called `--delete-forked`) has reached its final form after 13 iterations, now including all planned safety features for automated local branch cleanup. The series allows safely deleting branches whose commits are fully merged elsewhere, with protections against accidentally removing in-progress work. The latest patch adds a `--dry-run` option that previews which branches would be deleted without actually removing them, joining other safety features like warn-only mode for unmerged branches and per-branch configuration opt-outs.

The implementation preserves all the safety checks from `git branch -d` while adding bulk operation capabilities. Users can now preview deletions (especially useful with branch patterns like `origin/*`), get warnings about unmerged branches in bulk operations, and exempt specific branches via `branch.<name>.pruneMerged=false`. Phillip Wood and Johannes Sixt provided key design input during the series' evolution, and Junio C Hamano confirmed the technical completeness in v11. With all major concerns addressed and comprehensive test coverage, this appears ready for merging as a robust solution for local branch maintenance.
