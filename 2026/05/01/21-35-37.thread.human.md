This thread covers Harald Nordgren's v15 series introducing `git branch --delete-merged`, a feature for safely cleaning up merged local branches. The series has evolved through 15 iterations, with all major technical concerns now addressed. The latest patch adds a foundational `--forked` filter option for `git branch --list` that will support the deletion functionality. This new filter identifies branches whose upstream matches specified patterns, supporting exact refs, remote shorthands, glob patterns, and combinations with other filters like `--merged`.

The implementation includes robust safety mechanisms: it never deletes checked-out branches, skips branches with missing upstreams, preserves branches that push back to their upstream, and offers both dry-run previews and per-branch opt-out configuration. Recent changes from v14 include silently skipping not-yet-merged branches (rather than warning) and adding bare remote name shorthand support. Phillip Wood provided detailed implementation feedback that has largely been incorporated, and platform-dependent test failures have been resolved.

With the technical implementation complete, the remaining work focuses on final documentation wording refinements and verifying edge cases in remote name resolution. The series builds on established patterns like `fetch.prune` while introducing this new automated cleanup capability.
