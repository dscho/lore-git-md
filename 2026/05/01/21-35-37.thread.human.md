This thread is about the final version (v18) of Harald Nordgren's `git branch --delete-merged` series, which is now implementation-complete and ready for merging. The series introduces a new `--delete-merged` command for safe automated local branch cleanup, with comprehensive filtering and safety controls.

Key features include the `--forked` filter (supporting exact refnames, remote shorthand, shell-style globs, and `<branch>` arguments), per-branch opt-out via `branch.<name>.deleteMerged=false`, `--dry-run` preview, and refined stacked-branch protection that aborts deletion if a branch is used as an upstream for an unmerged branch while clearing stale upstream configs for kept branches. The command also supports limiting deletion candidates via `<branch>` arguments.

All design questions have been resolved, and the series has received high-weight review from Phillip Wood and Junio C Hamano. The only remaining pre-merge actions are mechanical fixes: cleaning up the flags-based API in patches 2-4/7, rejecting the nonsensical `--dry-run --quiet` combination, and extending the stacked-branch protection to `git branch -d` for consistency (as requested by Junio). Phillip Wood's review is complete, and his suggested test improvements have been applied. The series is ready for merging once these final mechanical fixes are made.
