Following up on Junio C Hamano's review of v6, author Harald Nordgren has acknowledged that the design change in the merged-ness checking was a mistake. Junio had flagged that v6 incorrectly compared local branches against the remote's default branch head instead of against each branch's specific upstream — a regression for anyone tracking a non-default remote branch. Harald conceded the point and said he will fix it in the next iteration. No new patches were sent; this is simply an acknowledgment from the author. The series remains blocked on this single open detail: reverting the merged-ness check back to using each branch’s specific upstream (via `branch_get_upstream()`), with the fallback to the remote's HEAD being optional rather than mandatory. Expect a v7 that addresses this before the series can advance.
