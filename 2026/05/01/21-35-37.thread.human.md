This thread is about the final version (v16) of Harald Nordgren’s patch series implementing `git branch --delete-merged`, a new command for safe automated cleanup of local branches. The series is now technically complete and ready for final review after addressing all prior feedback.

The goal is to provide a safe, configurable way to delete branches that have been merged, with features like `--forked` filtering (to target only branches matching a remote or glob), per-branch opt-out via config, and a `--dry-run` preview mode. The latest patch extends the existing `delete_branches()` function with two new flags: `DELETE_BRANCH_NO_HEAD_FALLBACK` (to avoid redundant merge-base checks) and `DELETE_BRANCH_DRY_RUN` (to enable accurate dry-run previews). These changes prepare the plumbing for the bulk deletion logic in later patches while maintaining backward compatibility.
