This is patch 2/5 of Harald Nordgren's v8 `git branch --prune-merged` series. It retrofits `delete_branches()` and `check_branch_commit()` in `builtin/branch.c` with two new parameters: `warn_only` (downgrades per-branch "not fully merged" errors to one-line warnings instead of multi-line errors with `-D` advice, and prevents a non-zero exit code) and `n_not_merged` (a tally counter for the caller to report a summarized refusal count at the end). All existing call sites pass `0` and `NULL` and are unaffected -- about 20 lines of purely mechanical C.

The motivation is straightforward: when `--prune-merged` runs in bulk across many branches, printing the full multi-line error with advice about `-D` for each skipped branch would be noisy. This is a clean, narrowly-scoped prep patch with a clear commit message and a trivial diff. It should be uncontroversial and should not hold up the series if it lands.
