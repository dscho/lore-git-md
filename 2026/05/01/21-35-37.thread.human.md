This thread covers Harald Nordgren's v9 series adding `git branch --prune-merged`, a feature for safely cleaning up local branches whose changes have been merged upstream. The core functionality is now complete with all technical concerns addressed, including Junio's earlier objection about the `--force` option (which has been removed entirely). The series provides several ways to manage this cleanup: showing branches tracking a remote (`--forked`), pruning merged branches (`--prune-merged`), per-branch opt-outs via config, and applying to all remotes (`--all-remotes`).

This isn't a blocking issue but rather a final polish consideration about making the behavior maximally intuitive.
