This is patch 5/8 in a feature series introducing a new `git url-parse` builtin command. The patch defines a new `url_parse()` function that provides generalized URL parsing for all Git URL formats, including SCP-style URLs like `host:path` and IPv6 addresses.

The key technical aspects are:
- Adapts Git's internal URL parsing logic from `connect.c` into a reusable function
- Handles both standard URLs (`scheme://host/path`) and SCP-style URLs (`user@host:path`)
- Returns parsed components as offset/length pairs into a normalized URL buffer
- Includes comprehensive unit tests for SCP syntax and URL forms
- Deliberately diverges from `parse_connect_url()` in handling local paths (requires explicit scheme)

The implementation looks clean and well-tested, with 45 new lines of unit tests covering various URL formats. This is part of the larger effort to expose Git's URL parsing logic as reusable plumbing, which could be valuable for tools that need to reliably parse Git URLs without reimplementing the logic.

The patch continues the series' logical progression from internal refactoring to new functionality. Based on the thorough test coverage and clear motivation, this appears to be a well-considered addition to Git's URL handling capabilities.
