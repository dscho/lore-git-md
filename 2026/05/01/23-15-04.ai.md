This is part 2 of a feature series introducing a new `git url-parse` builtin command, focusing on internal refactoring to support the new URL parsing functionality. The patch moves the `url_is_local_not_ssh()` function from connect.c to url.c as part of the broader effort to consolidate URL handling code in preparation for the new command.

The change is straightforward - it relocates the function and its declaration to the new URL module while maintaining identical behavior. This allows the upcoming `url_parse()` function (and other future code) to use this local-path detection logic without depending on connect.c. The patch includes the necessary header adjustments in remote.c to maintain compilation.

This is a mechanical refactoring with no functional changes, typical of the preparatory work needed when introducing new plumbing commands. The series appears well-structured, with this patch logically following the initial RFC-compliant renaming in patch 1. The move makes architectural sense as it properly separates URL parsing concerns from connection-specific code.
