This is patch 3/8 in a feature series introducing a new `git url-parse` command, focused on refactoring Git's URL parsing internals. The patch moves the URL scheme detection logic (enum url_scheme and url_get_scheme()) from connect.c to new url.[ch] files, making this functionality available to other parts of Git without requiring a dependency on connect.c.

The change is purely structural - no behavior is modified. The error message when an unsupported scheme is provided remains identical, just now coming from url.c instead of connect.c. The url_scheme_name() helper stays in connect.c since it has no other callers.

This is part of the broader effort to cleanly separate URL parsing concerns from connection-specific code, preparing for the new `git url-parse` plumbing command. The patch follows logically from the earlier RFC-compliant renaming in patch 1/13 and sets up the architecture for the remaining patches to build upon. The implementation looks straightforward and maintains all existing functionality while improving code organization.
