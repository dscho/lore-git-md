Thread identity: Proposal for new `fetch.pruneBranches` config option to automatically delete local branches when their upstream remote-tracking refs are pruned, authored by Harald Nordgren, now with maintainer feedback from Junio C Hamano.

Core problem/goal: Automating local branch cleanup when upstream branches are deleted, addressing namespace hygiene while preserving unpushed work. Current discussion focuses on architectural approach after Junio suggested decomposing the functionality into more fundamental primitives.

Key technical details:
- Original proposal included:
  - `fetch.pruneBranches` config with safe/force modes
  - Per-remote overrides and CLI flag
  - Protections for checked-out branches and unpushed work
- Junio's architectural suggestions:
  - New plumbing commands: `git branch --forked` and `git branch --prune-merged`
  - Compositional approach where `fetch --prune-merged` uses these primitives
  - Consideration for branch-level opt-out markers
- Safety distinctions (safe vs force modes) remain relevant but would apply to the primitives

Current status: Initial proposal (v1) now under discussion. Junio supports the feature's value but requests architectural changes to make the functionality more composable and workflow-aware. Key open questions:
1. Exact design of the proposed `git branch` plumbing commands
2. Handling of multi-phase development workflows where branches should persist despite upstream merges
3. Whether to retain any fetch-specific configuration or move entirely to command-driven approach

Participant positions:
- Harald Nordgren: Proposed initial implementation with fetch integration
- Junio C Hamano: Supports feature goal but advocates for decomposed design with standalone branch plumbing commands

Implementation considerations pending:
- Whether the new plumbing should live in `git-branch` or as separate commands
- How to surface the safe/force modes in the decomposed design
- Potential need for branch-level metadata to track which branches should persist despite upstream changes
