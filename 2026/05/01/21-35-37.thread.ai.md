Key technical details:
1) `--delete-merged` core behavior:
   - Filters candidates using `ref_filter_forked_add()` (patch 1/7)
   - Verifies tip reachability from upstream (skips unmerged branches)
   - Checks push divergence (preserves branches where push == upstream)
   - Respects `branch.<name>.deleteMerged=false` config opt-out (patch 6/7)
   - Never touches checked-out branches (any worktree)
   - Supports `--dry-run` preview mode (fully implemented in patch 7/7)
   - **Stacked-branch protection**: **Intended to clear upstream config** of branches used as upstreams for unmerged branches (e.g., "Cleared upstream of 'feature1' because 'feature2' depends on it"), but **current implementation preserves all upstream configurations** instead of selectively clearing them.

2) Implementation highlights:
   - **Per-branch opt-out (patch 6/7)**:
     - New `branch.<name>.deleteMerged` config key (false = opt-out)
     - Checked during candidate filtering in `delete_merged_branches()`
     - Non-quiet message explains opt-out skip
     - Ignored by traditional `git branch -d` (continues to use normal merge check)
   - **Stacked-branch protection (upstream config clearing)**:
     - **Design intent**: Clear `branch.<name>.remote` and `branch.<name>.merge` for branches used as upstreams for unmerged branches
     - **Current bug**: Implementation preserves *all* upstream configurations instead of selectively clearing them
     - **Inefficiency**: Builds a separate list of upstream branches instead of pruning the deletion candidate set directly in the `refs_for_each_branch_ref()` callback
     - Warning message: "Cleared upstream of '<branch>' because '<dependent>' depends on it"
     - Avoids traversal complexity by clearing config without recursive retargeting
     - Handles chains of dependencies (e.g., `b1→b2→b3`) and self-referential upstreams (e.g., `b3→b3`) uniformly
     - Applies uniformly to both `--delete-merged` and `-d` for consistency
   - **`--forked` filter (patch 1/7)**:

   - **Core command (patch 5/7)**:
