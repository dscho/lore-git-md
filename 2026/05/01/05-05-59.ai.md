This is a bug report about Git's rename detection for Ruby files when moving classes between namespaces. The reporter (Sébastien Stettler) observes that when Ruby classes are moved between namespaces, Git marks this as a file deletion and addition rather than a rename/move, whereas simple class renames are correctly detected as renames.

The issue is demonstrated in a test repository (https://github.com/billybonks/git-rename) showing the different behaviors. The reporter seeks clarification on whether this is expected behavior (and why) or if it's something that could be improved in Git's rename detection heuristics specifically for Ruby namespace changes.

The report includes full system information showing Git 2.47.1 running on macOS (ARM64). The reporter offers to help with test cases and implementation if this is deemed a valid area for improvement. The core question is about Git's expectations and design decisions around rename detection for this type of code restructuring in Ruby.
