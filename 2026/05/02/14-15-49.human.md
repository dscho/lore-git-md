This is a performance test patch from Derrick Stolee, part of his 7-patch series integrating `--path-walk` with various `--filter` options in `git pack-objects`. The series aims to optimize performance for sparse-checkout scenarios.

Patch 2/7 adds a new performance test script `p5315-pack-objects-filter.sh` that benchmarks different combinations of `--filter` and `--path-walk` options. The test measures:

1. Baseline performance with no filters
2. `--filter=blob:none` (blobless)
3. `--filter=sparse:oid=<oid>` (cone-mode sparse)

Each scenario is tested both with and without `--path-walk` to show the impact of path-walk traversal. The test automatically generates sparse-checkout patterns by sampling depth-2 directories from the test repository, making it work across different repository shapes. For repositories without depth-2 directories, it falls back to using a single top-level directory.

The current results show minimal differences between path-walk and non-path-walk modes, as the full integration isn't implemented yet in this patch. However, this establishes the benchmarking framework that will demonstrate the performance improvements in later patches of the series. The test is carefully designed to be portable across repositories while still providing meaningful metrics for the optimization work to come.
