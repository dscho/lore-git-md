This is the 5th patch in a 13-part series introducing a new `git url-parse` builtin command, focusing on implementing the core URL parsing functionality. The patch defines `url_parse()` in urlmatch.c, which provides a general parsing function supporting all Git URL formats including SCP-style and IPv6 addresses.

The new `url_parse()` function:
- Shares the same interface as `url_normalize()` but handles additional URL formats
- Reuses the URL scheme detection infrastructure from previous patches
- Intentionally diverges from `parse_connect_url()` by returning NULL on failure rather than dying
- Exposes URL components as offset/length pairs into a normalized buffer
- Includes comprehensive unit tests for SCP-style URLs, standard URL forms, and query/fragment stripping

Key technical decisions:
- Maintains separation from `parse_connect_url` due to different contracts (error handling vs. connection setup)
- Handles SCP-style URLs by temporarily converting them to SSH URLs for normalization
- Preserves special handling of `~user` paths in Git/SSH URLs
- Includes Windows-compatible path assertions in tests

The implementation appears thorough, with clear attention to edge cases and cross-platform concerns. The unit test coverage is extensive, validating all major URL formats and parsing behaviors. This patch represents the core functionality that will power the new `git url-parse` command in subsequent patches of the series.
