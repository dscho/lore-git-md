This is a refactoring patch (2/8) in the `git url-parse` series, moving the `url_is_local_not_ssh()` function from connect.c to url.c as part of the URL parsing infrastructure reorganization.

The change relocates the helper function that distinguishes local paths and SCP-style URLs to the new URL handling module, removing its dependency on connect.c. This prepares for the new `url_parse()` function (coming in later patches) to use this logic without pulling in unrelated connection code. The patch includes all necessary header updates and maintains the exact same behavior - it's purely a code movement.

The series as a whole is introducing a new plumbing command to expose Git's URL parsing logic, with this patch being one of several preparatory refactorings to create clean separation between URL handling and other subsystems. The v3 iteration has already addressed all prior feedback and includes Windows compatibility fixes.
