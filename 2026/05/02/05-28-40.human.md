This is patch 6/8 in a feature series introducing a new `git url-parse` plumbing command, which exposes Git's internal URL parsing logic to scripts and tools. The command handles Git's special URL formats including SCP-style and IPv6 addresses that standard parsers can't process.

The patch adds the actual command implementation in `builtin/url-parse.c`, which:
- Provides a `-c` option to extract specific URL components (scheme, user, host, port, path)
- Includes clear error messages for invalid URLs or components
- Uses the refactored URL parsing infrastructure from earlier patches
- Properly handles local paths by requiring explicit `file://` scheme
- The implementation appears robust with thorough error handling
- Follows Git's standard command-line conventions
- Integrates cleanly with the build system
- Is classified as a "purehelper" in command-list.txt

This is the user-facing piece of a well-structured series that has already addressed all prior review comments, including Windows compatibility fixes in v3. The command fills a real need for tools that need to reliably parse Git URLs without reimplementing Git's complex parsing logic.
