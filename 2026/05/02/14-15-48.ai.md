This is the first patch in Derrick Stolee's 7-part series integrating `--path-walk` with `--filter` options in `git pack-objects`. The patch fixes a small but important technical issue where the path-walk API wasn't properly passing the `--objects` flag to the revision machinery, which is required when using object filters.

The change is straightforward - it adds `--objects` to the revision parameters when `--path-walk` is enabled, while maintaining the now-incorrect comment about "removing" options. The patch also keeps the existing bitmap index disablement since path-walk still can't use bitmaps. This appears to be a necessary plumbing change to enable the filter integration work that follows in the series, with no expected behavior change for existing path-walk usage. The fix addresses a potential fatal error that would occur when trying to combine path-walk with filters without this change.
