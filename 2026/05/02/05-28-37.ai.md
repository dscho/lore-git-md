This is part 3 of a 8-patch series introducing a new `git url-parse` builtin command. The series aims to expose Git's internal URL parsing logic for external tools.

This particular patch moves URL scheme detection code (enum url_scheme and url_get_scheme()) from connect.c to dedicated url.[ch] files, allowing other code to identify URL schemes without depending on connect.c. The change is purely structural - behavior remains identical, including the error message when an unsupported scheme is encountered. The scheme_name() helper stays in connect.c as it has no other callers.

The patch demonstrates careful attention to code organization, keeping related functionality together while maintaining existing behavior. It's part of the broader effort to create a clean API for URL parsing that can be used by both internal Git code and external tools via the new `git url-parse` command. The changes are straightforward and well-contained, with no functional impact beyond the code movement.
