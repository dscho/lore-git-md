This is the documentation patch (7/8) for the `git url-parse` feature series, adding the man page for the new builtin command. The documentation thoroughly explains the command's purpose, options, output format, and provides clear examples.

Key points:
- The man page follows Git's standard AsciiDoc format and synopsis style
- Documents both validation mode (no output, just exit status) and component extraction mode (-c/--component)
- Lists all supported URL components (scheme, user, password, host, port, path)
- Includes practical examples showing different URL formats and their parsed components
- References related commands (clone, fetch, config) in SEE ALSO
- Adds the new man page to meson.build for build system integration

The documentation appears complete and matches the implementation's behavior as described in previous patches. It covers all the functionality introduced by the command while maintaining Git's documentation conventions. The examples effectively demonstrate both simple and edge case usage, including SCP-style URLs and empty components.
