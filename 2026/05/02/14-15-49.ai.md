Performance test addition for pack-objects filter and path-walk integration.

This is the second patch in Derrick Stolee's 7-patch series optimizing `git pack-objects` performance with sparse-checkouts. It introduces a new performance test script (t/perf/p5315-pack-objects-filter.sh) that benchmarks various filter and traversal combinations:

1. Baseline with no filter
2. `--filter=blob:none` (blobless)
3. `--filter=sparse:oid=<oid>` (cone-mode sparse)

Each scenario runs both with and without `--path-walk` to measure the impact of path-walk traversal for each filter type. The test automatically generates sparse-checkout patterns by sampling depth-2 directories from the test repository, making it adaptable to different repository structures. For repositories without depth-2 directories, it falls back to using a single top-level directory.

The current results (shown in the commit message) demonstrate minimal differences between path-walk and non-path-walk modes at this stage, as the full integration comes in later patches. This establishes a baseline for measuring the optimizations that follow in the series. The test infrastructure is thorough, handling edge cases like flat repositories by skipping sparse tests when appropriate. This continues Stolee's pattern of pairing performance optimizations with robust measurement tools.
