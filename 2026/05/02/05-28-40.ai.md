This is patch 6/8 in a feature series introducing a new `git url-parse` builtin command, which exposes Git's internal URL parsing logic as a plumbing command for use by scripts and tools. The command handles Git's various URL formats including non-standard ones like SCP-style URLs and IPv6 addresses.

The patch implements the actual `git url-parse` command with:
- `-c/--component` option to extract specific URL parts (scheme, user, password, host, port, path)
- Error handling that distinguishes between local paths and malformed URLs
- Component extraction via offset/length pairs into the normalized URL buffer
- Cross-platform path handling (including special error messages for DOS drive prefixes)
- The command is added to the build system (Makefile, meson.build)
- Registered in command-list.txt as a "purehelper"
- Includes comprehensive error messages for invalid inputs

The implementation builds on the URL parsing infrastructure introduced in earlier patches, providing a user-friendly way to access the normalized components. The error messages guide users toward correct URL formats when local paths are mistakenly provided.

This is the main user-facing piece of the series, providing the plumbing interface that makes the refactored URL parsing logic accessible to external tools. With this patch, scripts can reliably parse Git URLs without reimplementing Git's parsing logic themselves. The implementation appears robust and well-integrated with Git's existing command infrastructure.
