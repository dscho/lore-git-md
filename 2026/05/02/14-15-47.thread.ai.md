**Key technical details:**

Core architecture moves filter logic into `path-walk.c`. Implementation patterns:
- `blob:limit` checks blob sizes via `odb_read_object_info()` before emission; confirmed correct even in partial clones.
- `sparse:oid` validates entire path groups against sparse-checkout patterns at once (speedup: 77.91s to 31.41s for git/git sparse repack).
- `object:type` adds `strict_types` flag to prevent direct-object bypass.
- `combine` filters use recursive `prepare_filters_one()` helper.
