This is part 4 of a feature series introducing a new `git url-parse` command, which exposes Git's internal URL parsing logic. The patch refactors the URL scheme detection to be more flexible by having `url_get_scheme()` return `URL_SCHEME_UNKNOWN` for unrecognized schemes rather than dying, while maintaining the same fatal behavior in `parse_connect_url()`.

The change allows the scheme detection to be used in contexts where failure should not be fatal, such as the upcoming `git url-parse` command that needs to validate URLs without aborting. The patch is a straightforward refactoring that:
- Adds `URL_SCHEME_UNKNOWN` as the first enum value (0)
- Removes the `die()` call from `url_get_scheme()`
- Moves the fatal error handling to `parse_connect_url()`
- Updates the function documentation to reflect the new behavior

This is a clean architectural improvement that enables the new plumbing command while maintaining existing behavior for Git's internal URL parsing needs. The change is well-contained and follows the series' pattern of carefully separating concerns in the URL parsing code.
