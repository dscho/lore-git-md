This is a refactoring patch that's part of the larger `git url-parse` series. It moves the `url_is_local_not_ssh()` function from connect.c/connect.h to url.c/url.h as part of the architectural separation of URL parsing logic from connection handling.

The change is straightforward - the function's implementation is copied verbatim to the new location in url.c, with corresponding header updates. This allows the new URL parsing code (introduced in later patches) to use this helper function without creating a dependency on connect.c. The patch includes the necessary #include adjustment in remote.c to maintain compilation.

This is a mechanical change with no behavior modification, serving purely to improve code organization in preparation for the new URL parsing functionality. The patch follows the series' pattern of carefully separating concerns and building up the URL handling infrastructure in dedicated files.
