This is patch 5/8 in a feature series introducing a new `git url-parse` builtin command, which exposes Git's internal URL parsing logic. The patch defines the core `url_parse()` function that handles all Git URL formats including SCP-style and IPv6 addresses.

The implementation adapts Git's existing URL parsing from `connect.c` but with key differences: it returns NULL on failure rather than dying, exposes components as offset/length pairs, and requires explicit scheme detection (unlike `parse_connect_url` which assumes local paths). The function shares infrastructure with `url_normalize()` but deliberately diverges in handling bare local paths.

New unit tests verify SCP-style URL parsing, standard URL forms, and proper stripping of query/fragment components. The implementation shows careful attention to edge cases like IPv6 literals and host:port pairs in bracketed forms. This is a well-constructed plumbing function that maintains Git's URL handling behavior while providing a more flexible interface for external tools.

The patch builds on prior refactoring work and demonstrates thorough test coverage, with clear documentation of intentional design choices. It represents a key piece of the series' goal to make Git's URL parsing available as reusable plumbing.
