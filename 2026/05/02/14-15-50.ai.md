This is the third patch in Derrick Stolee's 7-part series integrating `--path-walk` with `--filter` options in `git pack-objects`. The patch specifically enables support for the `blob:none` filter in the path-walk API.

The key technical change is modifying the path-walk implementation to handle `blob:none` by skipping all blob objects during traversal while still processing commits, trees, and tags. The patch adds a new `prepare_filters()` helper that checks filter compatibility and modifies the path-walk behavior accordingly. When `blob:none` is detected, it sets `info->blobs` to 0 and clears the filter from the revision walk to avoid rejection.

The patch includes test updates to verify the new functionality:
- Adds `--filter=<spec>` support to the test-path-walk helper
- Includes tests for `blob:none` with both `--all` and single-branch walks
- Shows performance impact in the p5315 test with 16% smaller blobless packs (at a 73% time cost due to extra compression passes)

This continues Stolee's focus on optimizing large-repository performance, particularly for sparse-checkout scenarios. The implementation looks thorough with proper test coverage, though the performance tradeoff between time and space may warrant discussion. The changes touch core path-walk logic but maintain backward compatibility.
