This is the first patch in a 13-part series introducing a new `git url-parse` builtin command. The patch performs a mechanical rename of URL-related identifiers in connect.c to use RFC-compliant "scheme" terminology instead of "protocol", which was both technically inaccurate and collided with the unrelated `protocol_version` enum.

Key changes:
- Renames `enum protocol` to `enum url_scheme`
- Updates all related to URL scheme handling (PROTO_* -> URL_SCHEME_*, prot_name -> url_scheme_name, etc.)
- Preserves existing user-visible diagnostics and error messages for compatibility
- No functional changes - purely a naming improvement

The rename prepares for sharing the URL parsing logic with a new plumbing command by establishing consistent terminology. The change was suggested by Torsten Bögershausen in earlier review feedback and has been cleanly implemented with comprehensive updates to all affected code paths.

This is a straightforward refactoring that improves code clarity while maintaining backward compatibility. As the first patch in the series, it sets up the naming conventions that will be used throughout the subsequent URL parsing implementation.
