This is the first patch in Derrick Stolee's series integrating `--walk-path` with `--filter` options in `git pack-objects`. The patch is a small but necessary preparation step that ensures the path-walk API properly handles object filtering by explicitly adding the `--objects` flag to the revision walk parameters.

The change fixes a potential fatal error that would occur when trying to use object filtering with path-walk, while maintaining the existing behavior. The patch removes an outdated comment about "removing" options that was never actually implemented, clarifying that we simply weren't adding `--objects` before. The bitmap index remains disabled for path-walk operations as before.

This appears to be a straightforward technical prerequisite for the more substantial filter integration work that follows in the series. The change is minimal and focused, touching only the pack-objects command's option handling. As the first patch in the series, it sets up the infrastructure needed for the subsequent performance optimizations with various filter types.
