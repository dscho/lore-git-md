This is the final patch in Patrick Steinhardt's 8-part series refactoring repository initialization and object database setup. The patch completes the centralization of object database creation by moving it into `apply_repository_format()`, eliminating redundant initialization code across multiple call sites.

The key technical aspects are:
1. Object database creation is now handled within `apply_repository_format()` rather than at individual call sites
2. Introduces `APPLY_REPOSITORY_FORMAT_HONOR_ENV` flag to control environment variable handling
3. Establishes precise initialization ordering: hash algorithm -> ODB creation -> compat hash algorithm
4. Removes duplicate ODB setup code from `repository.c`, `setup.c`, and `init_db.c`

The patch acknowledges that the current ordering (where compat hash setup requires ODB initialization) isn't architecturally ideal, but defers that cleanup for future work. This follows the series' pattern of making incremental improvements while maintaining functionality.

With this patch, the series achieves its goal of consolidating scattered repository setup logic and eliminating redundant object database initializations. The changes are purely internal - no user-visible behavior changes - but provide important groundwork for future ODB abstraction work. The series has received maintainer approval with minor documentation fixes incorporated from Kristoffer Haugsbakk.
