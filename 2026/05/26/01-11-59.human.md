This is a test infrastructure discussion where Junio C Hamano responds to brian m. carlson's analysis of test permission issues. The thread had identified that running tests as root in containers was causing false positives in permission checks.

Junio makes two key technical points: First, he clarifies that while the !SANITY test prerequisite bypasses read/write permissions, it shouldn't automatically affect executable permissions (POSIXPERM). He suggests adding an automated check to detect when POSIXPERM should be dropped. Second, he strongly endorses native development on various platforms (not just macOS) to improve cross-platform compatibility.

The exchange shows the project's pragmatic approach to testing - while the immediate issue was root privileges in containers, the broader discussion emphasizes making development accessible across environments. Junio's response reinforces that Git aims to support all platforms where users run Git, not just Linux.
