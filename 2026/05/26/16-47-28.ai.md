This is the second patch in a 5-part series introducing the new `git son` command, which creates independent child repositories with loose parent-child relationships. The patch focuses on build system integration.

The changes are straightforward mechanical additions to register the new shell script (`git-son.sh`) with both the traditional Makefile and meson build systems, ensuring the command will be properly installed. It also adds the build artifact to `.gitignore` to prevent it from showing up as untracked during development.

The patch follows standard patterns seen when adding new shell-based Git commands:
1. Adds the script to `SCRIPT_SH` in Makefile
2. Includes it in the `scripts_sh` array in meson.build
3. Updates `.gitignore` for the generated binary

This is a typical infrastructure patch that would normally follow the initial implementation. The implementation appears correct and aligns with Git's conventions for shell script commands. Since this is part of an RFC series, the main discussion points will likely focus on the overall concept rather than these build system changes.
