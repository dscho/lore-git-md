This is the second patch in a 5-part series introducing the new `git son` command, which creates independent child repositories with loose parent-child relationships. The patch focuses on build system integration.

The changes are straightforward mechanical additions to register the new `git-son.sh` script in both the traditional Makefile and meson build systems, ensuring the command gets installed alongside other shell-based Git commands. It also adds the build artifact to `.gitignore` to prevent it from showing up as untracked.

As part of the larger feature proposal, this patch is purely infrastructure - it doesn't implement any user-facing behavior but enables the command to be built and installed. The implementation appears clean and follows the pattern of other shell script commands in Git. The patch is small, focused, and correctly scoped for its position in the series.
