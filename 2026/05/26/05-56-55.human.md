This is a refactoring patch series from Patrick Steinhardt that reorganizes how Git initializes repositories and their object databases. The series is part of the ongoing effort to clean up repository setup logic and prepare for future extensions like pluggable object storage backends.

The key changes in this 8-patch series are:
1. Unifying the scattered repository format application logic into a single location (currently duplicated and inconsistent across multiple sites)
2. Moving object database creation to happen at the same time as repository format application
3. Eliminating redundant object database initializations that currently happen during setup

The changes touch core setup code in `setup.c` and `repository.c`, with corresponding test updates in `t0001-init.sh`. The refactoring builds on Patrick's previous work removing `the_repository` usage from `init_db()` and appears to be groundwork for introducing an "objectStorage" extension in future work.

The series follows Patrick's typical style - carefully structured, with each commit building logically on the last, and clear commit messages explaining both the what and why of each change. The changes are focused on internal plumbing rather than user-visible behavior, though they should make the codebase more maintainable and consistent.
