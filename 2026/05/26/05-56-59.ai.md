This is patch 4/8 in Patrick Steinhardt's series refactoring repository initialization and object database setup, part of the broader ODB abstraction effort. The patch removes object database initialization from `repo_set_gitdir()`, where it was conditionally performed based on flags, and moves it to explicit call sites in `repo_init()` and `setup_git_env_internal()`.

The change simplifies `repo_set_gitdir()` to focus solely on setting the Git directory, while making object database creation more visible at the initialization points. This is an intermediate step - the commit message notes the current duplication will be resolved in a later patch that centralizes ODB creation during repository format application.

The patch touches core repository setup code in `repository.c` and `setup.c`, removing several fields from `struct set_gitdir_args` that are no longer needed. The changes are mechanical and don't affect user-visible behavior, continuing Patrick's careful approach to refactoring this sensitive initialization path. This prepares for the series' ultimate goal of unifying repository format application and ODB creation.
