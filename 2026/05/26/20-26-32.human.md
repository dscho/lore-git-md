# Performance optimization for sparse index in `git restore` (v2)

This is the second version of Derrick Stolee's two-patch series optimizing `git restore --staged` to better handle sparse index cases. The changes focus on avoiding unnecessary index expansion when using `..` pathspecs, since `SKIP_WORKTREE` paths will be ignored anyway.

The key improvement in v2 is the extraction of sparse-directory handling logic into a new helper function `try_update_sparse_directory()`, as suggested by Junio Hamano in his review of v1. This makes the code more readable while maintaining the same functionality. The series continues Stolee's ongoing work to optimize Git commands for sparse checkouts, following his characteristic test-first approach with comprehensive coverage in t1092.

The changes are focused and well-contained, touching only builtin/checkout.c and the test suite. Given Stolee's deep expertise in sparse-index optimizations and Junio's positive reception of the approach, this series appears ready for merging after the v2 improvements. The optimization should provide measurable performance benefits for users working with large sparse checkouts.
