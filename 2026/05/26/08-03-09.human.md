This is a bugfix addressing an interaction between `--really-refresh` and the preload-index optimization when files are marked as assume-unchanged. The patch is the first in a two-part series introducing a new `--refresh-stat-only` feature for CI workflows.

The fix corrects a subtle issue where preload-index would incorrectly mark assume-unchanged files as up-to-date during a `--really-refresh` operation, causing subsequent refresh steps to skip those files. The problem only manifests when preload-index is active (not the default configuration, but observable via GIT_TEST_PRELOAD_INDEX=1).

Key changes:
- Adds a `refresh_flags` field to thread_data to pass refresh options to preload threads
- Makes preload respect `REFRESH_REALLY` by adding `CE_MATCH_IGNORE_VALID` when appropriate
- Includes a regression test that forces preload and verifies assume-unchanged files get properly refreshed

It serves as a prerequisite for the subsequent feature addition by ensuring refresh flags are properly handled in the preload path. The change is relatively small and low-risk, touching only the interaction between two specific features.
