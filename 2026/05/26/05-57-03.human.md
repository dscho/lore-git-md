This is the final patch in Patrick Steinhardt's 8-part series refactoring repository initialization and object database setup. The patch completes the centralization of object database creation by moving it into `apply_repository_format()`, eliminating redundant initialization code across multiple call sites.

The change establishes a clear initialization sequence:
1. Sets the main hash algorithm
2. Creates the object database (now handling environment variables via a new `APPLY_REPOSITORY_FORMAT_HONOR_ENV` flag)
3. Sets the compatibility hash algorithm

Patrick notes this isn't the ideal architectural solution - the object database should ideally handle its own compatibility hash initialization - but defers that cleanup for future work. The patch touches core setup code in `repository.c` and `setup.c`, removing now-redundant object database creation calls while maintaining all functionality.

This concludes the series' goal of cleaning up repository setup logic in preparation for future pluggable storage backends. The changes are internal plumbing improvements with no user-visible behavior changes, but make the codebase more maintainable and consistent. With all technical and editorial requirements addressed, the series is now ready for integration.
