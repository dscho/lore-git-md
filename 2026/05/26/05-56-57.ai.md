This is a refactoring patch from Patrick Steinhardt that removes the `setup_git_env()` wrapper function as part of his ongoing series to clean up repository initialization code. The patch eliminates this now-unnecessary indirection since there's only one remaining call site (which now calls `setup_git_env_internal()` directly). It also removes stale documentation in environment.h that referenced the removed function and updates a comment in refs.c to be more accurate about when the replace refs namespace gets initialized.

The changes are mechanical and focused on code hygiene rather than behavior changes, continuing Patrick's characteristic careful approach to refactoring core plumbing code. This patch builds on his earlier work removing `the_repository` usage from setup code and helps prepare for future repository initialization improvements. The patch touches setup.c, environment.h, and refs.c, with straightforward deletions and one comment update.
