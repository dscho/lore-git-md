This is patch 6/8 in Patrick Steinhardt's series refactoring repository initialization and object database setup. The patch fixes an edge case where Git was unnecessarily initializing an object database even when no repository existed, specifically when `GIT_DIR_EXPLICIT` pointed to a non-existent directory.

The key change moves object database creation inside the `have_repository` check in `setup_git_directory_gently()`, preventing ODB initialization when there's no valid repository. This requires a corresponding fix in `commit-graph.c` to check for the object database presence rather than the gitdir, which maintains functionality for `git-index-pack` operations outside a repository.

The patch demonstrates Patrick's typical careful approach - identifying a subtle inconsistency in initialization logic, fixing it with minimal changes, and ensuring edge cases (like index-pack operations) continue working. This is another incremental step toward the series' goal of centralizing and rationalizing repository setup code.
