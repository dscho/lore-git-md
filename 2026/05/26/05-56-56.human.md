Test patch addressing an edge case in `git-init` with `GIT_OBJECT_DIRECTORY`.

Patrick Steinhardt adds a test case to verify that `git init` correctly respects the `GIT_OBJECT_DIRECTORY` environment variable, which specifies where Git should create the object database. The test confirms that when this variable is set, the objects directory is created at the specified path rather than the default `.git/objects` location.

This is part of a larger series (1/8) reworking repository setup, where this edge case was discovered. The patch itself is straightforward - it adds a new test case that creates a custom object directory and verifies the expected directory structure. The commit message clearly explains the test's purpose and how it plugs a gap in test coverage that could have allowed a regression to slip through.
