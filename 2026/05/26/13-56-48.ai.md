This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the state of various topics in the Git development pipeline. The report covers patches that have graduated to 'master', new topics under consideration, and ongoing work still cooking in integration branches.

Several notable patches have recently graduated to 'master':
- A sequencer cleanup removing unused struct member
- Documentation clarifying that .git/info/exclude is shared across worktrees
- HTTP walker fix for handling absolute-path alternates
- Performance optimizations for merge-base calculations and octopus merges
- Validation that diff context options take only non-negative values

New topics being proposed include:
- Fetch optimization for self-contained packs
- Sparse index optimization for 'git restore'
- Commit reachability performance improvements
- Fix for GIT_WORK_TREE environment variable handling
- Documentation clarification for push.default=simple behavior
- Support for -m/-F/-c/-C options with all --fixup variants

Significant ongoing work includes:
- Refactoring of the loose object source into proper odb_source structure
- Centralization of object database initialization
- macOS CI improvements
- Documentation updates for hooks and git-replay
- Commit-graph lazy-load robustness improvements
- Reachability bitmap generation optimizations
- Line-log refactoring to support more diff formats
- Path-walk integration with object filters

The report also lists numerous smaller fixes, optimizations and documentation updates at various stages of review. As always, Junio provides clear indicators of which branches contain each topic and whether they are considered stable ('next') or still under review ('seen').
