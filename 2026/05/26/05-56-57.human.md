This is a refactoring patch from Patrick Steinhardt's series on centralizing repository initialization and object database setup. The patch removes the `setup_git_env()` wrapper function, which had become redundant after earlier changes in the series. 

The change is straightforward: since `setup_git_env()` was just a thin wrapper around `setup_git_env_internal()` with a single call site, it's being eliminated to simplify the code. The patch also cleans up some stale documentation in environment.h that referenced the removed function, and updates a comment in refs.c to be more accurate about when the replace refs namespace gets initialized.

This is a mechanical cleanup that doesn't change behavior, just removes an unnecessary layer of indirection. It's part of Patrick's larger effort to make repository setup more consistent and prepare for future object storage backend work. The patch follows his typical careful style - small, focused, and well-explained in the commit message.
