This is a refactoring patch from Patrick Steinhardt that's part of his series to clean up repository initialization and object database setup. The patch removes object database initialization from `repo_set_gitdir()`, where it was somewhat hidden and conditional, and moves it to more appropriate locations in `repo_init()` and `setup_git_env_internal()`.

The change makes the initialization flow clearer by separating the concerns of setting the gitdir from creating the object database. While this introduces some temporary duplication, Patrick notes this will be cleaned up in a later patch that centralizes object database creation with repository format application.

The patch touches core repository setup code in `repository.c` and `setup.c`, removing several now-unused fields from `set_gitdir_args`. This is a typical Patrick Steinhardt patch - carefully reasoned, with clear commit message explaining both the current state and the planned future direction. The change is part of his broader effort to make the object database more modular and pluggable.
