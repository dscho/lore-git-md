This is the fifth patch in Patrick Steinhardt's 8-part series refactoring repository initialization and object database setup. The patch continues the work of centralizing object database creation by removing conditional ODB initialization from `setup_git_env_internal()` and making it explicit at all call sites.

The key change is eliminating the `skip_initializing_odb` parameter and moving ODB creation to happen immediately after repository discovery in several functions (`enter_repo()`, `setup_git_directory_gently()`, and `init_db()`). This creates temporary duplication that will be cleaned up in the next patch when ODB creation is fully centralized in `apply_repository_format()`.

The patch touches core setup code in `setup.c` but maintains the same behavior - it's purely an internal refactoring with no user-visible changes. This is another incremental step toward the series' goal of making repository initialization more consistent and preparing for future pluggable storage backends. The changes follow Patrick's characteristic careful, methodical approach to refactoring sensitive initialization paths.
