This is patch 5/8 in Patrick Steinhardt's series refactoring repository initialization and object database setup. The patch continues the effort to centralize object database creation by removing conditional ODB initialization from `setup_git_env_internal()` and making it explicit at all call sites.

The key changes in this patch:
- Eliminates the `skip_initializing_odb` parameter from `setup_git_env_internal()` and related functions
- Moves ODB creation to explicit calls in `enter_repo()`, `setup_git_directory_gently()`, and `init_db()`
- Introduces temporary duplication of ODB creation code as an intermediate step
- Prepares for the final unification of ODB creation in `apply_repository_format()` (which will come in patch 8/8)

The patch touches core setup code in `setup.c`, modifying how the object database is initialized during repository discovery and setup. While this introduces some temporary code duplication, it's a deliberate intermediate step toward the series' goal of fully centralizing ODB creation logic.

This continues Patrick's careful, well-structured approach to refactoring sensitive initialization paths - each patch builds logically on the last while maintaining clear commit messages explaining both the changes and their purpose in the larger series. The changes are purely internal with no user-visible behavior modifications.
