Feature: New `git branch --forked` plumbing command for local branch management.

This is the first patch in Harald Nordgren's v3 series implementing `fetch.pruneBranches` functionality. It introduces a new `git branch --forked` command that lists local branches tracking specified remote branches - the foundational plumbing for the upcoming `--prune-merged` feature.

The command accepts either remote names (like `origin`) or specific remote-tracking branches (like `origin/main`), with multiple arguments unioned. The implementation efficiently scans branch refs using `refs_for_each_branch_ref()` and checks upstream configuration via `branch_get_upstream()`. 

Key aspects:
- Clearly documented behavior and error cases
- Comprehensive test coverage including:
  - Basic remote name matching
  - Specific remote-tracking branch matching
  - Multi-remote union behavior
  - Error handling for invalid inputs
- Follows Git's existing branch plumbing patterns
- Prepares for the series' ultimate goal of safe branch cleanup while preserving unpushed work

This appears to be a well-constructed plumbing primitive that cleanly isolates the branch listing functionality from the deletion logic that will come in later patches. The implementation looks thorough with attention to edge cases and clear documentation.
