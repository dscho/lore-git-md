Feature: Core plumbing command `git branch --forked` for local branch tracking detection.

This patch introduces the foundational `--forked` option to `git branch`, which lists local branches that track any of the specified remote references. The implementation handles both remote names (like `origin") and specific remote-tracking branches (like `origin/main`), with multiple arguments being unioned. 

The command serves as the building block for the subsequent `--prune-merged` functionality in this series. It uses efficient ref iteration via `refs_for_each_branch_ref()` and includes comprehensive tests covering:
- Basic remote name matching
- Specific remote-tracking branch matching
- Multi-remote union behavior
- Error cases for invalid inputs

The documentation clearly explains the relationship between local branches and their upstream tracking references, using consistent "remote-tracking branches" terminology as requested in previous reviews. The implementation appears solid with proper memory management and error handling.

This is patch 1/6 in the v3 series that builds toward automated branch cleanup functionality. The changes from v2 to v3 are minimal (primarily terminology updates), maintaining the same core behavior while preparing for the new `--all-remotes` convenience flag in later patches.
