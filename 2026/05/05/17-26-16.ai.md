# Build system patch for Rust-enabled osxkeychain helper

This is a small Makefile change to properly link the git-credential-osxkeychain helper with Rust libraries when Rust support is enabled. The patch comes from Shardul Natu (Google) and appears to be addressing internal code review feedback.

The change introduces a new `RUST_LIBS` variable that holds the Rust library dependency, which is then used when building the osxkeychain helper. The implementation cleanly handles cases where Rust is disabled by making this a no-op. The patch is part of the ongoing Rustification effort in Git, though it's a relatively minor build system tweak rather than a major architectural change.

The diff shows the straightforward addition of `$(RUST_LIBS)` to the helper's link line, alongside existing dependencies like `$(LIB_FILE)` and `$(EXTLIBS)`. The change is well-contained and appears to be a logical extension of the existing Rust build infrastructure.
