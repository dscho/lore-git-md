Feature: New `git branch --forked` plumbing command for local branch management.

This is the first patch in Harald Nordgren's v4 series introducing new branch management functionality. It adds a `--forked` option to `git branch` that lists local branches tracking specified remote(s). The command accepts either remote names (e.g. `origin`) or specific remote-tracking branches (e.g. `origin/main`), with multiple arguments being unioned.

The implementation is clean and well-tested:
- Core logic efficiently scans branches using `refs_for_each_branch_ref()`
- Handles both remote names and specific tracking refs
- Includes comprehensive tests covering:
  - Basic remote name matching
  - Specific tracking branch matching
  - Multiple argument union
  - Error cases (unknown remote, missing arguments)

This low-level plumbing command serves as the foundation for the higher-level `--prune-merged` functionality (coming in later patches) that will safely delete these branches. The patch maintains Git's usual code quality standards with thorough documentation and test coverage.

The series as a whole aims to automate local branch cleanup when upstream branches are deleted, while protecting unpushed work and default branches. This first patch provides the essential building block for identifying which branches are candidates for such operations.
