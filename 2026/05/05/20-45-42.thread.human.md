This thread documents a straightforward but useful improvement to Git's man pages. Kristoffer Haugsbakk has added explicit warnings in both `git-commit-graph` and `git-replace` documentation noting that commit-graph functionality is disabled when replace objects or commit grafts are present. While this behavior was previously documented in the technical notes, it wasn't mentioned in the user-facing manuals where most people would look for it. The patch follows Git's documentation conventions by adding clear "CAVEATS" sections with cross-references between the two man pages. The change is uncontroversial and improves the documentation for users working with these advanced features.
