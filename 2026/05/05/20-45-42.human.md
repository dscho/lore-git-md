This is a documentation patch that adds a note about commit-graph behavior when replace objects or commit grafts are present.

Kristoffer Haugsbakk noticed that while the technical documentation for commit-graph mentions that replace objects and commit grafts disable commit-graph functionality, this important caveat isn't mentioned in the user-facing documentation for either `git-commit-graph` or `git-replace`. The patch adds matching "CAVEATS" sections to both man pages to make this behavior more visible to users.

The change is straightforward - it copies the warning from the technical docs into the appropriate places in the user documentation. This seems like a clear improvement that helps users understand an important limitation of the commit-graph feature. The patch is small, focused, and well-formed with a clear commit message explaining the motivation.
