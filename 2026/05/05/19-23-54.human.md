Feature: Bulk branch deletion improvements for `fetch.pruneBranches` series.

This patch from Harald Nordgren's v4 series enhances the bulk branch deletion behavior in preparation for the new `--prune-merged` functionality. The changes make `delete_branches()` more flexible for batch operations by:

1. Adding a `warn_only` parameter that converts hard errors about unmerged branches into one-line warnings while still skipping deletion
2. Introducing a `n_not_merged` counter to track skipped branches without verbose per-branch output
3. Maintaining existing behavior for single-branch deletions (the default case)

The implementation cleanly extends the existing code with minimal churn, keeping the core safety checks while making the bulk operation more user-friendly. This is a supporting change for the larger feature set that will use these bulk operations in `git branch --prune-merged` and `git fetch --prune-merged`.

The patch demonstrates good attention to backward compatibility - all existing callers pass 0/NULL to maintain current behavior. The changes are well-contained within `builtin/branch.c` with comprehensive parameter passing through both `delete_branches()` and its helper `check_branch_commit()`.
