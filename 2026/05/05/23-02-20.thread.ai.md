Thread identity: "[PATCH v2 0/4] fix for silently accepting negative numbers in -U and --inter-hunk-context" by Michael Montalbo. Patch series, two versions circulated.

Core problem: `-U` (interdiff context lines) and `--inter-hunk-context` silently accepted negative numeric values, which downstream would cause BUG() assertions in xdiff. The fix requires validation at the option-parsing layer to reject negative values before they reach xdiff, plus a defensive BUG() guard in xdiff itself.

- Patch 3: adds a BUG() guard in `xdiff-interface.c` (function `parse_num`) as a defense-in-depth measure covering all xdiff consumers.
- Patch 4 (documentation): clarifies comment on `PARSE_OPT_NONEG` flag in `parse-options.h` with parenthetical `"(i.e. rejects --no-<option>)"` to prevent future confusion -- this flag blocks only the boolean `--no-` form, not negative numeric values, as was originally misunderstood in v1.
