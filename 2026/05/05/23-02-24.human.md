This is the final patch in a bugfix series addressing negative diff context values. The patch clarifies documentation for `PARSE_OPT_NONEG` in `parse-options.h`, explaining that the flag only prevents boolean negation (--no-option forms) rather than rejecting negative numeric values. 

The change comes after earlier patches fixed cases where negative values for `-U`/`--unified` and `--inter-hunk-context` were being silently accepted, leading to malformed diff output. The documentation update helps prevent similar misunderstandings in the future by making it clear that `OPT_UNSIGNED` should be used when negative values need to be rejected.
