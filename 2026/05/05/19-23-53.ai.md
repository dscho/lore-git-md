Feature: New `git branch --forked` plumbing command for local branch tracking.

This is the foundational patch in Harald Nordgren's v4 series implementing `fetch.pruneBranches` functionality. It introduces a new `git branch --forked` command that lists local branches tracking specified remote branches, serving as the building block for the subsequent pruning functionality.

The command accepts either remote names (e.g. `origin`) or specific remote-tracking branches (e.g. `origin/main`), with multiple arguments being unioned. The implementation:
- Uses efficient ref iteration via `refs_for_each_branch_ref()`
- Handles both remote names and specific tracking refs
- Includes comprehensive tests covering:
  - Basic remote name matching
  - Specific tracking branch matching
  - Multiple argument union
  - Error cases (unknown remotes, missing arguments)

The patch maintains clean separation from existing branch operations and follows Git's established patterns for ref handling. Documentation clearly explains the new option's behavior and syntax.

This low-level plumbing command enables the higher-level `--prune-merged` functionality in later patches while being useful on its own for scripting and inspection. The implementation appears robust with thorough test coverage of the core functionality.
