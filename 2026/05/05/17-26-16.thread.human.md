This thread explores build system adjustments needed to support Rust in the `git-credential-osxkeychain` helper. Shardul Natu's initial patch introduced a new `RUST_LIBS` variable for linking Rust libraries, which Junio Hamano flagged as potentially duplicating the existing `RUST_LIB` variable. The discussion has shifted from implementation details to broader questions about how to cleanly model Rust dependencies in Git's build system.

Koji Nakamaru now proposes an alternative approach that avoids introducing a new variable by conditionally including `RUST_LIB` when Rust is enabled. This addresses Junio's architectural concern while maintaining the same functionality. The patch appears technically sound but awaits review from build system experts to determine which approach better serves Git's long-term maintenance. 

While the immediate scope is narrow (one credential helper), the discussion reflects larger tensions in the Rustification effort - how to introduce new infrastructure without complicating the build system. With Junio engaged and multiple solutions on the table, we can expect further refinement before this reaches a conclusion. The thread remains focused on build system design rather than Rust's merits, with all participants working within the shared assumption that Rust support will proceed.
