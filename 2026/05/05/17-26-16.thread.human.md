This thread is about a small but important build system adjustment for Git’s Rustification effort on macOS. Shardul Natu and Koji Nakamaru authored a two-patch series that (1) fixes a parallel build race condition in the macOS credential helper by ensuring Rust libraries are built before linking, and (2) adds Universal Binary support for Rust components via the `RUST_TARGETS` environment variable. The series has now reached its final version (v4) and is ready for integration.

All feedback has been addressed, including Junio’s style tweaks and Patrick Steinhardt’s architectural concerns about Universal Binary completeness. While Patrick noted that the C build’s multi-architecture support remains untouched, the current design is accepted as sufficient for practical use cases like macOS distribution and CI. The changes are minimal, uncontroversial, and confined to the `Makefile`, with no new user-facing behavior or on-disk format changes. Junio has now signed off on the series, confirming it will proceed to his integration branches. No further discussion or revisions are expected.
