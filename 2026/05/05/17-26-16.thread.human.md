This thread is about a small but important build system adjustment for Git’s Rustification effort on macOS. Shardul Natu and Koji Nakamaru authored a two-patch series that ensures the macOS credential helper (`git-credential-osxkeychain`) links correctly against Rust libraries and supports Universal Binaries. The series is now finalized and ready for integration after addressing all feedback, including Junio C Hamano’s sign-off and a minor cosmetic cleanup in the patch description.

The second adds Universal Binary support via the `RUST_TARGETS` environment variable, allowing users to specify multiple target triples (e.g., `aarch64-apple-darwin x86_64-apple-darwin`) and combining them into a single binary using `lipo`. The changes are minimal, uncontroversial, and focused on the `Makefile`, with no on-disk format changes or new test coverage.
