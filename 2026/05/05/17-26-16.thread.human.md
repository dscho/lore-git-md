This thread is about adjusting Git’s build system to better support Rust components on macOS, specifically enabling Universal Binary builds for the `git-credential-osxkeychain` helper. Shardul Natu and Koji Nakamaru from Google sent a three-patch series that fixes a parallel build race condition, adds Universal Binary support for Rust libraries via the `RUST_TARGETS` environment variable, and cleans up redundant build variables.

The series is now effectively ready to proceed. The first and third patches are uncontroversial, while the second (Universal Binary support) has been accepted in principle pending minor Makefile style tweaks requested by Junio C Hamano. Patrick Steinhardt initially raised concerns about whether the approach fully leveraged macOS’s Universal Binary capabilities, but those concerns are no longer blocking, as the current design is deemed sufficient for practical use cases like macOS distribution and CI. D. Ben Knoble’s follow-up confirmed that `lipo`, the tool used to create Universal Binaries, has been a stable part of Xcode since at least 2005, addressing Patrick’s question about platform assumptions. No new test coverage was added, as the changes are implicitly covered by existing build tests. The thread is converging, with no open technical objections remaining.
