This is a security hardening patch for Git's HTTP proxy handling, addressing a vulnerability where malformed proxy URLs with invalid schemes (like "htpp://") were silently accepted. The patch now explicitly rejects unsupported schemes while maintaining backward compatibility with the simpler host:port format.

The v2 iteration incorporates Junio C Hamano's review feedback by:
- Switching to a table-driven approach for SOCKS proxy type handling
- Using `test_must_fail` in the regression test
- Making the error message check more robust with `test_grep`

The changes are focused (93 lines modified in `http.c` plus test additions) and well-motivated - silently accepting invalid proxy URLs could lead to security issues. The implementation demonstrates clean separation of concerns through refactoring while preserving existing behavior for valid inputs. The test addition shows attention to regression prevention.
