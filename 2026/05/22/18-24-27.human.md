This is a performance test patch (03/13) in Derrick Stolee and Taylor Blau's series to integrate `--path-walk` with `--filter` options in `git pack-objects`. The patch adds a new benchmark script `p5315-pack-objects-filter.sh` that measures the impact of different filter combinations with and without `--path-walk`.

The script automatically generates sparse-checkout patterns by sampling directories from the test repository, making it adaptable to different repository shapes. It tests three scenarios: no filter (baseline), `blob:none` filter, and `sparse:oid` filter (for cone-mode sparse checkouts). Each is tested both with and without `--path-walk`, showing current performance characteristics before the full integration is complete.

The initial results show minimal differences between standard and path-walk modes, as expected since the full integration isn't implemented yet. The test is designed to provide a baseline for measuring improvements as the series progresses. The script handles edge cases like repositories without depth-2 directories by falling back to simpler patterns or skipping sparse tests when appropriate.

This is infrastructure work supporting the larger effort to make `--path-walk` work seamlessly with all filter types. The test demonstrates careful consideration of real-world repository structures and provides a robust framework for tracking performance impacts throughout the series.
