This is a follow-up review comment on patch 3 of an already-approved git-gui bugfix series. The patch simplifies repository path handling by using `git rev-parse --absolute-git-dir` instead of manual path resolution.

Git-gui maintainer Johannes Sixt notes that while the change is good, there's a now-inaccurate comment about `.git` directory behavior that should be updated to match the new implementation. The original comment warned that running from the `.git` dir would set `_gitdir` to `.`, but with `--absolute-git-dir` this is no longer true - it will always return an absolute path.

This is a minor documentation tweak to keep comments in sync with code changes. The patch itself has already been approved as part of the larger series addressing git-gui's repository and worktree detection edge cases. The series is otherwise ready for merging after this small adjustment.
