This RFC proposes a new `diff.<driver>.process` configuration to let external tools inject diff hunks into Git's diff and blame pipelines, primarily to support structural/AST-based diffs while preserving standard display formats. The series is technically complete with comprehensive test coverage, having addressed all major review feedback.

The final sticking point was test implementation - Johannes Schindelin identified issues with the Python-based test helper on Windows, where Python version incompatibilities and availability problems caused CI failures. Michael Montalbo has now committed to transitioning to a C-based test helper following Johannes' prototype, aligning with the project's direction of reducing scripting language dependencies. This resolves the last significant implementation concern.

Junio Hamano had previously indicated the core implementation was sound, with Windows compatibility being the final blocking issue. With that now being addressed through the test helper rewrite, the series appears ready for merging pending verification of the Windows fixes and some minor refinements. The feature's design and protocol remain uncontested, with all substantive technical feedback incorporated.
