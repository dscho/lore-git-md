This thread is about an RFC proposal for `diff.<driver>.process`, a feature that allows external tools to inject diff hunks into Git's diff and blame pipelines via a long-running subprocess. The series, now at version 6 with 9 patches, aims to enable structural/AST-based diff capabilities while preserving downstream features like word-diff, color-moved, function context, `--stat`, `git blame`, and `git log -L`.

The latest update (Patch 8 in v6) wires the `--stat`, `--numstat`, and `--shortstat` summary formats to consult the external diff process. This ensures that the counts in these formats reflect the tool's view of which lines changed, rather than Git's builtin line diff. The patch modifies `builtin_diffstat()` to call `diff_process_fill_hunks()` before running xdiff. If the tool reports the files as equivalent, the xdiff is skipped, and the file is pruned from the stat output, matching the behavior of `git diff`. The integration preserves existing behaviors like mode-only changes, textconv asymmetry, and range filtering under `git log -L`. The documentation has been updated to reflect these changes, and 130 lines of test coverage have been added to verify the new functionality.

Key participants include Michael Montalbo, the author, who has implemented all requested refinements, including subprocess API refactoring, bypass mechanism unification, and integration of stat and range tracking. Junio Hamano, the maintainer, has endorsed the technical direction and acknowledged the resolution of a merge conflict with `mm/line-log-limited-ops` via rebase. Johannes Schindelin recommended the C-based test helper approach, which has been implemented.

The series is now technically complete, with all major diff and blame features wired to consult the external tool. The author has addressed all substantive review feedback, including the merge conflict, and the series is ready for final sign-off and merging, pending Junio's re-review of v6 and minor documentation refinements. The only remaining cases using the builtin algorithm are combined diffs (`--cc` and merge diffs), whose protocol would need extension for multiple parent comparisons.
