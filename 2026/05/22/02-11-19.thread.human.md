This RFC series introduces a new `diff.<driver>.process` feature that allows external tools to inject diff hunks into Git's diff and blame pipelines. The feature mirrors the existing `filter.<driver>.process` protocol, enabling specialized tools to participate in the diff process while preserving downstream features like word-diff and color-moved. The series has now been completed with a built-in whitespace normalizer tool (`git diff-process-normalize`) that serves as a reference implementation.

The implementation carefully integrates with existing subsystems, with patches that modify xdiff to accept pre-computed hunks, add configuration plumbing, implement the core diff protocol, and integrate with blame. The final patch demonstrates the feature's utility by suppressing whitespace-only changes in diff and blame output, similar to `git diff -w` but without requiring a `.git-blame-ignore-revs` file. The tool falls back to Git's built-in diff for files with non-whitespace changes.

The series includes extensive test coverage across all components, validating hunk boundary handling, error recovery, session state management, and integration with various Git commands. The blame integration is particularly notable as it enables skipping semantically-irrelevant reformatting commits. With this final patch providing both the infrastructure and a practical example, the series appears well-tested and ready for final review.
