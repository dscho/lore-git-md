This is a feature patch series introducing support for an external command to fetch Git notes, with significant test coverage and documentation updates.

The series (v2) refactors and extends Git's notes functionality to allow specifying an external command that will be called to retrieve notes content. The author has addressed feedback from v1 by:
- Splitting out documentation changes
- Removing timeout-related code that was deemed unnecessary
- Consolidating implementation commits
- Moving configuration into a proper struct rather than using globals

The implementation adds new files `notes-external.{c,h}` with the core functionality, plus extensive test coverage in `t3301-notes.sh` and related test files. The changes span multiple commands that display notes (`format-patch`, `range-diff`, etc.) and include completion updates.

The motivation appears to be enabling more flexible notes storage/retrieval without modifying Git's core notes storage format. The test suite demonstrates usage with a sample external notes command (`t/helper/test-external-notes`).

This looks like a well-structured series with thorough testing (448 lines of new test code) and documentation. The changes touch several areas but appear focused on the notes subsystem. Reviewers will likely want to examine the security implications of executing external commands, though the implementation seems to handle this carefully with config validation and proper process spawning.
