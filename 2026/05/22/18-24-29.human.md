This is patch 5/13 in a series enabling `--path-walk` to work with `--filter` options in `pack-objects`. The specific focus here is adding support for the `blob:none` filter, which creates blobless packfiles.

The patch teaches the path-walk API to handle `blob:none` by skipping blob objects during traversal. When this filter is detected, it clears the filter from the revision walk to avoid rejection while still achieving the desired blob exclusion. The implementation includes:

1. A new `prepare_filters()` helper that checks filter compatibility and modifies the path-walk info when appropriate
2. Updates to the test helper to accept filter specifications
3. Removal of temporary test workarounds now that the feature works
4. New test cases verifying blobless behavior with both `--all` and single-branch walks

Performance tests show the expected tradeoffs - blobless packs with path-walk are 16% smaller but take 73% longer to create due to extra compression passes. The changes are well-contained, touching mainly the path-walk internals while maintaining the existing API.

This represents solid progress in the series' goal of full filter compatibility, with the implementation demonstrating careful handling of edge cases through both code and test coverage. The collaborative nature of the work is evident in the co-authorship with Taylor Blau and the incorporation of feedback from previous iterations.
