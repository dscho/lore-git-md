This is patch 11/13 in a series adding `--path-walk` and `--filter` interaction to `git pack-objects`. The patch focuses specifically on supporting the `tree:0` filter, which omits all trees and blobs from the result while keeping commits and tags.

The key changes in this patch:
- Implements `tree:0` filter support by setting appropriate flags in `path_walk_info` to skip tree and blob processing
- Fixes handling of tagged trees that were previously being silently dropped
- Adds comprehensive test coverage showing the filter works correctly with both `--all` and single-branch cases
- Explicitly rejects non-zero tree-depth filters (like `tree:1`) since they require path-walk depth information not currently available to the filter machinery

The implementation avoids unnecessary tree processing when `tree:0` is active, matching the filter's intended behavior. The test changes demonstrate careful attention to edge cases, particularly around tagged tree objects that aren't reachable from commits.

This is part of a larger effort to make `--path-walk` work with various filter types, with previous patches in the series already adding support for `blob:none`, `blob:limit`, and `sparse:oid` filters. The series has gone through multiple iterations with substantive review feedback incorporated at each stage.
