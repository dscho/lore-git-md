This is v11 of Harald Nordgren's series adding `git branch --prune-merged` for safe automated local branch cleanup, now with a revised safety model based on push/upstream comparison. The series has evolved through extensive review, with Phillip Wood and Johannes Sixt providing substantive feedback on the safety mechanisms and interface design.

Key changes in v11:
- Replaces the remote-based filtering with a more precise push/upstream comparison to distinguish trunk branches from fork-based topics
- Adds `--dry-run` mode to preview deletions
- Introduces `branch.<name>.pruneMerged` config to opt-out specific branches
- Maintains all previous safety checks (checked-out branch protection, unmerged commit detection)

The implementation now:
- Uses `@{push}` vs `@{upstream}` comparison to identify fork-based topics (branches that push somewhere other than their upstream)
- Preserves branches where push == upstream (typical trunk workflow)
- Skips branches with unmerged commits (with clear warnings)
- Honors the new per-branch opt-out config
- Provides dry-run capability for previewing deletions

It addresses all prior feedback while maintaining the original goal of safe automated cleanup. The safety model has been strengthened through collaborative review, particularly around distinguishing trunk vs topic branches.
