This is a performance test patch (03/13) in Derrick Stolee and Taylor Blau's series to integrate `--path-walk` with `--filter` options in `pack-objects`. The patch adds a new benchmark script `p5315-pack-objects-filter.sh` that measures the impact of different filter combinations with and without `--path-walk`.

The script tests three scenarios: no filter (baseline), `--filter=blob:none`, and `--filter=sparse:oid=<oid>` (cone-mode sparse). Each is tested both with and without `--path-walk`, producing paired measurements. The sparse filter definition is automatically generated by sampling depth-2 directories from the test repository, making the test work across different shapes of repositories.

Current results show minimal differences between standard and path-walk traversal since the full integration isn't complete yet, but the test establishes a baseline for future comparisons. The sparse filter tests are skipped for flat repositories via a prerequisite check. This is infrastructure work supporting the larger series goal of enabling full interoperability between path-walk and filter options.
