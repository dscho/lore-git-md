This is patch 12/13 in the `pack-objects --path-walk --filter` integration series, focusing on adding support for the `object:type` filter. The patch completes the series' coverage of all major filter types that can work with path-based object traversal.

The key technical contribution is implementing `LOFC_OBJECT_TYPE` filter handling in the path-walk machinery. The implementation uses bitwise AND operations on the existing type flags (`info->{commits,trees,blobs,tags}`) to selectively enable only the requested object type. The patch also fixes two edge cases where the interaction between tree and blob filtering needed adjustment:

1. Modified `setup_pending_objects()` to preserve trees when blobs are requested (since trees may be needed to reach blobs via tags)
2. Adjusted the revision walk's `tree_objects` flag to ensure pending objects survive `prepare_revision_walk()`

The patch includes comprehensive test coverage in t6601-path-walk.sh, verifying correct behavior for all four object types (commit, tag, tree, blob). The blob filtering tests specifically validate that blobs reachable only through tagged trees are properly included. Documentation is updated to list `object:type` as a supported filter option.
