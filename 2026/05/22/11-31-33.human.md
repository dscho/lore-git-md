This is the first patch in v11 of Harald Nordgren's series adding `git branch --forked` and `--prune-merged` for safe local branch cleanup. The `--forked` option lists local branches whose upstream matches given patterns, serving as the foundation for the upcoming `--prune-merged` functionality.

The patch introduces a new `--forked` flag that accepts branch names or wildcard patterns to match against local branches' upstreams. Key features include:
- Support for literal branch names (e.g. "origin/main"), wildcards (e.g. "origin/*"), and bare remote names (resolving to the remote's HEAD)
- Union of multiple patterns when multiple arguments are given
- Sorted output by branch name
- Comprehensive test coverage of matching behaviors and edge cases

The implementation handles both remote-tracking and local upstream branches, with careful parsing to distinguish literal names from wildcards early for efficiency. The tests verify various matching scenarios including glob patterns, remote HEAD resolution, and combinations of literal/pattern arguments.

This is a well-structured foundational patch that has evolved through 11 iterations of review. The code is cleanly separated from the upcoming deletion logic that will use it, and the test coverage is thorough. The interface design reflects careful consideration of real-world branch management workflows.
