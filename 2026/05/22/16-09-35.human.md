The patch is a mechanical preparation step for the larger feature, cleaning up the code before adding new functionality. The author has updated all call sites and the function signatures to match.

This kind of preparatory cleanup is common in Git development, especially when touching code that will be modified in subsequent patches. The change is small, focused, and clearly motivated by the upcoming work in the series.
