This is patch 09/13 in a performance-focused series enabling `--path-walk` to work with various `--filter` options in `git pack-objects`. The specific focus here is adding support for the `sparse:oid` filter, which restricts blobs to those matching a sparse-checkout pattern while keeping all reachable trees.

The patch demonstrates significant performance improvements when using `--path-walk` with `sparse:oid` - showing 60% faster execution and 14% smaller packs compared to the standard revision walk approach. The key technical work involves:

1. Loading sparse-checkout patterns from the provided OID and verifying they use cone-mode patterns
2. Handling edge cases where the same tree OID appears at both in-cone and out-of-cone paths by deferring SEEN flag marking
3. Adding comprehensive test coverage in t5317 and t6601 to verify identical object sets between path-walk and standard traversal

The implementation builds on previous work from the series, particularly the path-walk infrastructure and earlier filter support. Performance data shows the path-walk approach avoids the quadratic behavior of checking each object against sparse patterns individually. The patch maintains compatibility with existing sparse-checkout workflows while establishing a foundation for potential future "treesparse" filters.

Co-authored with Taylor Blau, this represents a mature iteration (v5) of the series that has incorporated extensive review feedback. The changes are well-tested and documented, with clear performance benefits demonstrated for local operations using sparse filters.
