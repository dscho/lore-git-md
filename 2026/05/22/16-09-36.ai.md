This is the second patch in a 4-part series introducing support for external notes commands in Git. The patch adds timeout and deadline support to Git's read/write wrappers, which will be used by the external notes functionality in later patches.

The key changes are:

1. New `xread_timeout()` and `xread_deadline()` functions that extend the existing xread() with timeout capabilities, using poll() to wait for fd readiness. The deadline variant allows multiple reads to share a common timeout.

2. Corresponding `read_in_full_timeout()` and `read_in_full_deadline()` variants that read an exact number of bytes with timeout support.

3. New `strbuf_getwholeline_fd_timeout()` and `strbuf_getwholeline_fd_deadline()` functions for reading lines with timeouts.

4. The implementation carefully handles edge cases like:
   - Negative/invalid timeouts
   - Interrupted system calls (EINTR)
   - Non-blocking I/O (EAGAIN/EWOULDBLOCK)
   - File descriptor errors (POLLERR/POLLNVAL)

The changes are preparatory work for the external notes command feature, where timeouts will be needed when executing and communicating with the external process. The patch maintains backwards compatibility by keeping the original non-timeout versions of all functions.

The implementation looks thorough, with clear documentation of the new functions and careful error handling. The changes touch core I/O wrapper code but appear to be well-contained and follow existing patterns. This is a solid infrastructure patch that enables the more user-visible functionality coming in later parts of the series.
