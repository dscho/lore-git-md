This is patch 12/13 in a series enabling `--path-walk` to work with various `--filter` options in `git pack-objects`. The patch specifically adds support for the `object:type` filter, which restricts output to objects of a specified type (commit, tag, tree, or blob).

The implementation maps the filter type to the existing `info->{commits,trees,blobs,tags}` flags in the path-walk machinery. Key technical points:
- Uses bitwise AND operations to maintain compatibility with future combined filters
- Fixes two edge cases where tree objects were being incorrectly dropped when filtering for blobs
- Adds comprehensive test coverage for all four object types in t6601-path-walk.sh

The patch builds on previous work in the series that already addressed major correctness issues, particularly around `tree:0` filters. With this addition, the series now supports all major filter types (`blob:none`, `blob:limit`, `sparse:oid`, `tree:0`, `object:type`, and `combine`).

The implementation appears solid, with careful attention to edge cases and thorough test coverage. The patch maintains the series' focus on performance while ensuring correctness, as evidenced by the detailed test cases for blob filtering through tag-pointed trees. Documentation is updated to reflect the new supported option.
