This is patch 07/13 in the fifth iteration of the `pack-objects --path-walk --filter` integration series from Derrick Stolee and Taylor Blau. The patch adds support for the `blob:limit=<size>` filter to the path-walk API, allowing blobs above a certain size threshold to be excluded from the walk.

The implementation checks blob sizes via `odb_read_object_info()` during path walking, skipping blobs that meet or exceed the limit. The patch handles edge cases like zero limits (equivalent to `blob:none`) and conservatively includes blobs when size cannot be determined. It also updates `git backfill` to explicitly reject blob size limits since they would trigger undesirable on-demand downloads.

Test coverage demonstrates the filter's behavior with both `blob:limit=0` (excluding all blobs) and `blob:limit=3` (excluding only larger blobs). The implementation builds on the series' existing filter infrastructure while adding new validation logic specific to size-based filtering.

This continues the series' methodical approach to integrating filters with path-walk, with each patch focusing on a specific filter type while maintaining consistent behavior with Git's existing filter machinery. The patch shows careful attention to edge cases and command integration, particularly around the interaction with `git backfill`.
