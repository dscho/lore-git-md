This is the final patch (6/6) in Harald Nordgren's series adding `git branch --prune-merged` for safe automated local branch cleanup. The patch introduces a `--dry-run` option that previews which branches would be deleted without actually removing them.

The dry-run mode prints "Would delete branch <name>" for each candidate branch, maintaining all the safety checks from previous patches (push-tracking comparison, unmerged branch protection, etc.). This allows users to verify the behavior before running potentially destructive operations with broad patterns like 'origin/*'.

The implementation:
- Rejects `--dry-run` when not used with `--prune-merged`
- Preserves all existing safety mechanisms during dry-run
- Adds comprehensive tests verifying dry-run behavior matches actual execution
- Updates documentation to explain the new option

This completes the feature set for the series, which has undergone extensive review over 11 iterations to refine both the safety model and interface design. The dry-run capability was a frequently requested feature during review, and this patch implements it while maintaining the careful safety guarantees established in earlier patches.

With this addition, the series appears technically complete and ready for final consideration. The only remaining work is documentation polish, which this patch includes updates to the man page and command-line help text.
