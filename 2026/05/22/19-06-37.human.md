This is a technical response addressing Junio Hamano's review of the xdiff infrastructure changes for the `diff.<driver>.process` feature, which enables external tools to inject diff hunks into Git's diff/blame pipelines.

Michael Montalbo agrees with Junio's assessment that the `changed[]` array manipulation with a -1 offset is ugly but necessary, proposing to improve the comment to clarify why this defensive clearing of sentinel values is required. He then addresses three specific suggestions from Junio's review:

3. On automatic disabling of misbehaving tools, Michael acknowledges this as a good idea for future enhancement but suggests keeping it simple for the RFC version, noting it could be implemented as a configurable failure policy (e.g., disable after N failures).
