This is patch 5/6 in Harald Nordgren's series adding `git branch --prune-merged` functionality, focused on adding a per-branch opt-out mechanism. The patch introduces a new `branch.<name>.pruneMerged` config option that lets users exempt specific branches from automated cleanup while still allowing explicit deletion with `git branch -d`.

The implementation:
- Adds config documentation explaining the new option's purpose (preserving topic branches for further development)
- Updates the man page to document this as another condition that prevents pruning
- Modifies the pruning logic to check the config setting before deletion
- Includes tests verifying both the opt-out behavior and that explicit deletion still works
- Shows skipped branches in the output (when not using `--quiet`) so users understand why branches were preserved

This builds on the safety mechanisms established in earlier patches, maintaining all existing protections (checked-out branches, push/upstream mismatch detection) while adding this new opt-out capability. The series has been through extensive review over 11 iterations, with this patch representing one of the final refinements before completion.
