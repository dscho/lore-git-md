This is patch 5/13 in a series enabling `--path-walk` to work with `--filter` options in `pack-objects`. The patch specifically adds support for the `blob:none` filter, which is commonly used in blobless partial clones.

The key changes:
- Modifies the path-walk API to handle `blob:none` by skipping blob objects while still processing commits, trees
- Updates documentation to clarify `--path-walk` now works with `--filter=blob:none`
- Adds test coverage showing the filter works with both `--all` and single-branch walks
- Includes performance data showing 16% space savings when combining `--path-walk` with blobless filters

The implementation introduces a `prepare_filters()` helper that checks filter compatibility and modifies the path-walk info to skip blobs when `blob:none` is active. This allows the path-walk optimization to work while maintaining the blobless behavior.
