This is patch 08/13 in the fifth iteration of the `pack-objects --path-walk --filter` integration series from Derrick Stolee and Taylor Blau. The patch introduces a new `pl_sparse_trees` flag to control tree pruning behavior in the path-walk API.

The key change allows the path-walk machinery to distinguish between two sparse filtering modes:
1. Pruning both trees and blobs outside sparse patterns (used by `git backfill --sparse`)
2. Only pruning blobs while keeping all trees (needed for future `sparse:<oid>` filter support)

The patch also fixes a subtle edge case where objects could be incorrectly skipped if they appeared at multiple paths - by moving the SEEN` flag assignment after sparse pattern checks, objects skipped at one path remain discoverable at other valid paths.

Test coverage is added to verify both behaviors:
- The existing sparse mode that prunes trees
- The new mode that keeps all trees while only filtering blobs

This is a technical refinement that builds on the series' core goal of enabling `--path-walk` to work with all `--filter` options. The implementation maintains careful attention to edge cases and integration points, consistent with the series' quality so far. The change is well-motivated by the need to support both sparse-checkout and sparse-oid filter behaviors through the same path-walk machinery.
