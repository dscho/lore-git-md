This is the third patch in a 4-part series introducing support for external notes commands. It's a test-only patch that expands coverage of Git's existing notes display behavior before the actual external notes implementation in patch 4/4.

The patch adds four new test cases to `t/t3301-notes.sh` that verify how notes interact with various Git commands and options:
1. Confirms raw notes formatting works correctly (showing just the note content without decoration)
2. Verifies `--no-notes` suppresses note display as expected
3. Tests that explicit notes refs (like `--notes=other`) override the default notes display
4. Checks that notes content participates in `--grep` matching

These tests don't exercise the new external notes functionality yet - they're establishing baseline behavior that the external notes implementation will need to maintain. The tests are concise but cover important integration points with the log/show formatting pipeline.

The patch follows the series' pattern of careful, incremental preparation - first adding infrastructure (patch 2), then expanding test coverage (this patch), before implementing the actual feature (patch 4). The test additions look thorough and well-targeted to catch regressions in the upcoming changes.
