This is a test modernization patch in Derrick Stolee's ongoing series to improve `pack-objects` path-walk and filter interactions. The patch modifies test setup in `t6601-path-walk.sh` to create truly unreachable tagged trees (previously they were reachable from abandoned commits) using `git mktree` rather than relying on amended commits.

The change demonstrates a subtle bug in the path-walk API where tagged trees weren't being properly emitted when they weren't reachable from commits. The test restructuring makes this issue visible while maintaining all existing test coverage. The patch is part of a well-tested series that has gone through multiple iterations with thorough review.

This appears to be a final cleanup before the series is ready for merging, addressing an edge case that was only discovered during the rigorous testing process. The use of `git mktree` to create standalone tree objects is a clean way to test this scenario without polluting the repository history.
