This thread introduces a Windows-specific patch to unify how `SIGTERM` and `SIGKILL` are handled in Git's process termination code. The change modifies `mingw_kill()` in `compat/mingw.c` to treat both signals identically when terminating processes on Windows, simply calling `TerminateProcess()` with the same exit code for either case. 

The implementation is straightforward and low-risk since Windows' process termination API doesn't distinguish between these signals anyway. While the patch appears technically sound, the commit message could better explain what motivated this change now and which callers will benefit from the simplified interface. The modification helps align Windows behavior slightly closer to Unix conventions while maintaining Git's existing process handling model on the platform.
