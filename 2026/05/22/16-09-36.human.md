This is the second patch in a series adding support for external notes commands. It introduces timeout and deadline handling for read operations, which will be used when executing external notes commands to prevent hangs.

The patch adds new variants of existing read functions (`xread_timeout`, `xread_deadline`, `strbuf_getwholeline_fd_timeout`, etc.) that allow callers to specify either a per-read timeout in milliseconds or an absolute deadline in nanoseconds. The implementation uses `poll()` to wait for the file descriptor to become readable before attempting the read, with proper error handling for timeouts and other edge cases.

Key technical details:
- Adds timeout support while maintaining backwards compatibility with existing non-timeout versions
- Implements deadline handling by converting to relative timeouts
- Includes comprehensive error handling (EINTR, EAGAIN, ETIMEDOUT, etc.)
- Touches core I/O wrapper functions that are used throughout Git
- Adds new helper functions to support the timeout functionality

This is a preparatory patch for the main external notes functionality coming in patch 4/4. The changes are focused and well-contained, with clear documentation of the new functions. The implementation looks robust, handling both timeout and non-timeout cases while preserving existing behavior when timeouts aren't specified.
