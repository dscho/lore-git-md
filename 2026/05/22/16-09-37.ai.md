This is the third patch in a 4-part series introducing support for external notes commands. It's a test expansion patch that verifies existing notes display behavior before the external notes functionality is added in patch 4/4.

The patch adds four new test cases to `t/t3301-notes.sh` that validate how Git currently handles notes display in various scenarios:
1. Verifies raw notes formatting (`--format=%N`) shows notes without the "Notes:" prefix
2. Confirms `--no-notes` suppresses notes display as expected
3. Tests that explicit notes refs (`--notes=other`) override the default notes display
4. Checks that notes content participates in `--grep` matching

These tests establish a baseline of expected behavior that the upcoming external notes implementation will need to maintain. The test coverage is thorough, checking both positive and negative cases (like `--no-notes` suppressing matches that would otherwise appear).

The patch follows the series' pattern of careful, incremental preparation - this test expansion ensures the core notes display behavior is well-understood before introducing the new mechanism. The tests are cleanly written and follow Git's test style conventions. This is a solid preparatory patch that will help catch any regressions when the external notes functionality lands in the next patch.
