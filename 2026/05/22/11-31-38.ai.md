The `--dry-run` option prints which branches would be deleted by `--prune-merged` without actually deleting them, providing a safety check before running potentially broad patterns like `origin/*`. The implementation ensures dry-run output exactly matches what would be deleted in a live run, maintaining all the safety checks from previous patches (push-tracking comparison, unmerged branch protection, etc.).
