This is a platform compatibility patch targeting Windows (mingw) process handling. The change allows `SIGKILL` to terminate processes on Windows, matching the behavior on Unix-like platforms where `SIGKILL` is the standard "forceful termination" signal.

Currently, Git's Windows compatibility layer only handles `SIGTERM` in `mingw_kill()`, requiring callers to add platform-specific conditionals when they want to use `SIGKILL`. The patch removes this inconsistency by treating both signals equivalently on Windows, using the same underlying `TerminateProcess` API.

The change is small and focused - just a one-line modification to the signal check in `mingw_kill()`. The commit message clearly explains the motivation (avoiding "ifdef soup") and the patch appears straightforward with no obvious issues. This seems like a reasonable quality-of-life improvement for Windows users and developers.
