This is patch 7/13 in a series adding `--path-walk` and `--filter` interaction to `git pack-objects`. The patch focuses on implementing support for the `blob:limit=<size>` filter in the path-walk API.

The key changes:
- Extends the path-walk API to handle blob size limits by checking object sizes via `odb_read_object_info()`
- Blobs equal to or larger than the limit are excluded (unless directly requested)
- Adds validation in `git backfill` to reject blob size limits since they would trigger inefficient single-object downloads
- Includes tests showing the filter works equivalently to `blob:none` when limit=0 and properly filters mid-sized blobs when limit=3

The implementation carefully handles edge cases like:
- Tagged blobs (always included regardless of size)
- Missing objects (conservatively included)
- Empty batches after filtering

This continues the series' pattern of methodically expanding filter support while maintaining performance and correctness. The patch builds on previous infrastructure (like `path_walk_filter_compatible()`) and includes thorough coverage of the new behavior. With co-author Taylor Blau's sign-off and the careful attention to edge cases, this appears ready for inclusion.
