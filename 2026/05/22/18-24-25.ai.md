This is a preparatory patch in the `pack-objects --path-walk --filter` integration series. It temporarily disables the `GIT_TEST_PACK_PATH_WALK` test variable in three test cases in `t5620-backfill.sh` to avoid warnings about `--path-walk` being incompatible with `--filter`. The patch is working towards making these options work together, but for now needs to suppress the warning to keep the tests passing. 

The changes are straightforward - adding `GIT_TEST_PACK_PATH_WALK=0` before the test commands that would otherwise trigger the warning. Each addition comes with a comment explaining why it's needed. This is a mechanical change that paves the way for the more substantial filter integration work in later patches of the series.

The patch shows good attention to test hygiene by:
1) Only touching the specific tests affected by the warning
2) Adding explanatory comments for each change
3) Maintaining the existing test assertions

This is a small but necessary step in the larger effort to enable `--path-walk` and `--filter` interoperability. The patch itself is uncontroversial and well-contained.
