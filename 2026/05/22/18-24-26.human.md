This is patch 2/13 in a series enabling `--path-walk` to work with various `--filter` options in `git pack-objects`. The patch is a straightforward fix that adds the `--objects` flag when `--path-walk` is enabled, which prevents a fatal error when object filters are used.

The change is minimal - just adding one line to pass `--objects` and removing an outdated comment about removing options. This maintains compatibility with the revision machinery while preparing for the filter integration work that follows in later patches. The patch doesn't change behavior for existing `--path-walk` usage, but enables the path-walk API to work with filters being added in the rest of the series.

As part of an established series now on its fifth iteration, this patch represents a small but necessary step in the larger goal of filter/path-walk interoperability. The change is well-justified in the commit message and has already been reviewed by co-author Taylor Blau in previous versions.
