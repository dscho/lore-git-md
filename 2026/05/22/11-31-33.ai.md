This is the first patch in v11 of Harald Nordgren's series adding `git branch --forked` and `--prune-merged` functionality for safe local branch cleanup. The patch introduces the foundational `--forked` option that lists local branches whose upstream matches given patterns.

The `--forked` option accepts:
- Literal upstream names (e.g. "origin/main")
- Wildmatch patterns (e.g. "origin/*")
- Remote names (resolved via refs/remotes/<remote>/HEAD)

Key implementation details:
- Uses wildmatch for pattern matching
- Combines multiple arguments via union
- Resolves remote names to their default branch
- Includes comprehensive tests covering:
  - Literal matches
  - Wildcard patterns
  - Remote resolution
  - Argument combinations
  - Error cases

The patch builds cleanly on the existing branch machinery while introducing new helper functions for pattern parsing and branch matching. The tests verify both happy paths and edge cases like invalid patterns. This provides the core functionality that the subsequent `--prune-merged` patches will build upon.

The implementation appears technically sound with careful attention to:
- Memory management (pattern list cleanup)
- Reference resolution safety
- Consistent sorting of output
- Clear error messages
- Backward compatibility
