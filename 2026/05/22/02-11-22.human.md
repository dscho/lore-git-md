This is the third patch in a series introducing a new `diff.<driver>.process` feature that allows external tools to inject diff hunks into Git's diff and blame pipelines. The patch implements the core process protocol and integration with Git's diff machinery.

The implementation follows Git's established long-running process protocol (similar to `filter.<driver>.process`), where an external tool communicates via pkt-line over stdin/stdout. The tool receives file pairs and returns hunk descriptors that Git then feeds into its standard diff pipeline, preserving downstream features like word-diff and color-moved.

Key aspects of this patch:
- Adds the process protocol implementation in new files `diff-process.{c,h}`
- Integrates with the existing diff machinery via the xdiff interface
- Includes comprehensive tests covering hunk handling, error cases, and integration with other diff features
- Maintains graceful fallback to built-in diff when the external tool fails or returns invalid hunks
