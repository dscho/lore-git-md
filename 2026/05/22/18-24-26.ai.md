This is a preparatory patch in the ongoing series to enable `--path-walk` and `--filter` interoperability in `git pack-objects`. The patch fixes a minor inconsistency where the path-walk API assumed `--objects` was implicitly set, which would cause problems when filters are introduced since they explicitly require `--objects`.

The change is straightforward - it explicitly adds `--objects` to the revision parameters when `--path-walk` is enabled, while maintaining the existing behavior of disabling bitmaps. The patch removes an outdated comment about "removing" options that was never accurate, clarifying the code's intent.

This is a small but necessary step in the larger series, ensuring the revision walk machinery will properly handle the upcoming filter integration. The change is well-contained and uncontroversial, with no expected impact on performance or behavior beyond enabling the filter work to proceed.
