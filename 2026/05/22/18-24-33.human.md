Performance optimization for `pack-objects` with sparse filters. This patch from Derrick Stolee and Taylor Blau enables the `--filter=sparse:<oid>` option to work efficiently with `--path-walk`, significantly speeding up pack creation for sparse checkouts.

The key improvement comes from deferring sparse pattern checks until after path grouping, allowing the path-walk to skip blobs outside the sparse scope in bulk rather than checking each object individually. The implementation handles edge cases like shared tree OIDs appearing at both in-cone and out-of-cone paths by re-walking trees when needed.

Performance tests show dramatic improvements - 60% faster pack creation and 14% smaller packs when using `--path-walk` with sparse filters. The patch includes extensive test coverage demonstrating correctness across various sparse patterns and edge cases.

This is part of a larger series (v5 09/13) integrating path-walk with all filter types. The technical approach has been vetted through multiple iterations, with Taylor Blau co-signing the design. The patch appears production-ready, with only minor documentation updates remaining in the series.
