This is the fourth and final patch in a series introducing support for an external command to fetch and display Git notes. The patch implements the core functionality for `notes.externalCommand` configuration.

The key additions include:

1. A new `notes-external.{c,h}` module that:
   - Manages the external command process lifecycle and communication
   - Handles timeouts and error conditions
   - Implements the protocol for sending commit IDs and receiving notes

2. Configuration options:
   - `notes.externalCommand` - the command to run
   - `notes.externalCommandName` - label for notes header
   - `notes.externalCommandTimeoutMs` - response timeout
   - `notes.externalCommandForGrep` - whether to include notes in grep matching

3. Command-line options:
   - `--external-notes`/`--no-external-notes` to control usage

4. Integration with:
   - `log`, `format-patch`, `range-diff` and other commands that display notes
   - The notes display formatting system
   - The grep matching system when configured

The implementation includes extensive test coverage (400+ new test lines) verifying behavior across different commands, configurations, and edge cases. The external command protocol is designed to be simple but robust, with clear error handling.

Compared to v1, this version has:
- Split documentation into a standalone patch
- Removed unnecessary helper functions
- Consolidated implementation commits
- Improved commit messages
- Added more robust configuration handling

The patch appears well-structured and thoroughly tested, addressing a real use case (custom notes storage/retrieval) while maintaining backwards compatibility with existing notes functionality. The changes touch multiple areas of the notes subsystem but are carefully integrated.
