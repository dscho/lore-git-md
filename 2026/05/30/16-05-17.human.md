Refactoring patch moving a helper function from header to implementation file.

This is part 2 of a 4-patch series (no cover letter seen) that moves the `ce_mode_from_stat()` function from being a static inline in `read-cache.h` to a regular function in `read-cache.c`. The motivation is to prepare for future work that will need repository-specific configuration - having the function in the implementation file will make it easier to access that configuration logic.

The change is straightforward: the function implementation moves to the .c file while keeping the same behavior, and the header is updated with just the declaration. The patch removes an `extern` declaration that was only needed when the function was inline in the header. The change appears mechanical and well-contained, with three mentors listed (Christian Couder and two others) suggesting this is part of a mentored contribution effort.
