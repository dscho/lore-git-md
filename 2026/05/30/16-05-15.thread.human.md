This thread is part of the ongoing effort to eliminate Git's `the_repository` global variable by moving configuration into repository-scoped storage. The initial series focuses on refactoring the `trust_executable_bit` setting, which controls how Git handles filesystem executable bits.

Tian Yuchen, working under mentorship from Christian Couder and others, has begun with a straightforward cleanup patch that removes redundant `extern` declarations in read-cache.c. This small but precise change prepares for the more substantial work to come in the series, which will move the configuration into proper repository-scoped storage. The approach builds on previous attempts to properly scope this configuration, with the author noting that targeting `struct repo_settings` was deemed optimal.

The series currently consists of four patches, with this first one being a mechanical cleanup that eliminates duplicate declarations while maintaining identical behavior. The changes touch core index handling code in read-cache.c and related filesystem interaction paths. While this initial patch is minor, it demonstrates careful attention to detail in preparing for the more significant refactoring to follow.
