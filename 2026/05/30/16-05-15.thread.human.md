The initial version proposed moving just this one setting, with cleanup of related index handling code.

Junio Hamano raised two key concerns in his feedback: first, that the changes could introduce performance overhead by unconditionally checking repository configuration in hot paths, and second, that the related `has_symlinks` setting should be migrated at the same time for better design cohesion. Tian has now responded, agreeing with both points and committing to restructure the code to maintain performance while expanding the series' scope to include `has_symlinks`.

Christian Couder, who is mentoring Tian, previously noted some structural inconsistencies in how configuration fields are ordered between declarations and initialization. The next version of the series is expected to address all these points while maintaining the core goal of removing dependency on the global `the_repository` variable. This work builds on René Scharfe's long-running effort to eliminate global state from Git's codebase.
