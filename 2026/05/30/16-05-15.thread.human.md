Tian Yuchen has completed a refactoring series that migrates the `trust_executable_bit` configuration from global scope to repository-specific storage, marking another step in the ongoing effort to eliminate the `the_repository` global variable. The three-patch series has evolved through review, with version narrowing its scope to focus on the executable bit handling while deferring the more complex `has_symlinks` migration.

The changes are technical but important for Git's architecture: moving configuration storage, adding proper getter functions, and updating call sites while maintaining existing behavior. The series has benefited from reviews by Christian Couder, Ayush Chandekar, and Olamide Caleb Bello, with Patrick Steinhardt providing documentation suggestions that were incorporated. Junio C Hamano's earlier position on deferring `has_symlinks` remains unchanged.

The patches touch core index handling code in read-cache.c and configuration plumbing, demonstrating how filesystem capability flags are being migrated to the new storage pattern. With the third patch now completing the executable bit work, this series appears ready for inclusion while establishing patterns for future complex migrations in the broader `the_repository` removal effort.
