This is a test patch (4/5) in Kristoffer Haugsbakk's `git format-rev` series. It adds a dedicated regression test for the `--annotate-stdin --name-only` option combination in `git name-rev`, which was recently refactored to use a new command dispatch system.

The test ensures proper handling of name-only output when processing stdin, catching potential regressions in the command's core functionality. The author notes this test would have caught issues in the refactoring if the command structure wasn't properly initialized, even though those issues weren't related to the specific features being tested in other existing tests.

The test follows the established pattern of:
1. Generating expected output by processing each commit individually
2. Comparing against batch processing via stdin
3. Using sorting to handle non-deterministic output order

This maintains the series' high standard of test coverage while addressing a gap identified during the refactoring work. The patch is well-contained and clearly motivated by the technical changes in previous patches of the series.
