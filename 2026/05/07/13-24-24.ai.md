Feature enhancement for `git add -p` adding word-diff view option.

Phillip Wood provides a substantive review of Javier Bassi's patch to add a 'w' command to `git add -p` that shows hunks with word-diff formatting. While supportive of the feature's usefulness, Phillip identifies several technical refinements needed:

1. The implementation should propagate filename information to ensure correct word-diff regex matching for different file types
2. Context and inter-hunk context settings from `struct interactive_options` should be preserved
3. The original unified diff hunk header should be reused for accurate line numbers

Phillip notes the current approach of using hunk text (rather than running `git diff --diff-words`) is correct as it handles edited and split hunks properly. This feedback comes from someone with deep knowledge of Git's interactive commands and diff machinery, suggesting the changes would make the feature more robust while maintaining its core value proposition.

The review maintains the patch's focus on helping users review changes in structured text formats (JSON, CSV, etc.) where word-diffs are particularly valuable, while addressing technical details that would improve integration with Git's existing diff infrastructure.
