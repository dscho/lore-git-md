This is patch 5/6 in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows builds. The patch continues the mechanical deletion of the malloc.c.h file, removing the "Overlaid data structures" through "System allocation" sections (1699 lines).

The removal is part of a larger effort to address GCC 16 compatibility issues with the unmaintained nedmalloc code, which Git for Windows has already replaced with mimalloc. The series follows a careful progression: first disabling usage (patch 1), then build system references (patch 2), auxiliary files (patch 3), and now the core implementation in chunks (patches 4-6).

This particular patch removes internal data structures and algorithms for managing memory chunks, including:
- Small/large chunk representations
- Segment management
- The malloc_state bookkeeping structure
- Tree-based bin management for larger chunks
- Various helper macros and functions

The change is purely a deletion - no behavior changes since Git for Windows hasn't used this code in years. The patch follows the established pattern of the series, with a clear commit message noting its position in the overall removal sequence.
