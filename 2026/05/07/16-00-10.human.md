This is the third patch in a series removing the unmaintained nedmalloc allocator from Git's Windows builds. The patch focuses on deleting the smaller auxiliary files (LICENSE, README, and wrapper files) to make room for removing the much larger malloc.c.h file in subsequent patches.

The change is part of a systematic cleanup triggered by GCC 16 compatibility issues with the outdated nedmalloc code. Since Git for Windows has already switched to mimalloc, this series fully removes all nedmalloc-related code rather than just disabling it.

Key points:
- The patch deletes four files totaling 1,293 lines of code (License.txt, Readme.txt, nedmalloc.c, and nedmalloc.h)
- This is a mechanical removal with no behavior changes
- The commit message explains the technical constraint (email size limits) that necessitated splitting the removal across multiple patches
- The change affects only Windows/MINGW builds and follows Git for Windows' earlier switch to mimalloc

The patch appears well-structured and follows the series' logical progression of first disabling usage, then removing build system references, and now deleting the actual source files. The commit message provides clear rationale for the split into multiple patches.
