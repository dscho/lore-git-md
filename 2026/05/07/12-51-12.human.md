This is the first patch in a two-part series fixing a Windows-specific deadlock in geometric repacking during `git maintenance`. The issue occurs when mmap'd pack index files prevent deletion of old packfiles on certain Windows 10 versions.

The patch introduces test infrastructure to simulate legacy Windows delete behavior (where files with active views cannot be deleted) on modern systems via a new `GIT_TEST_LEGACY_DELETE` environment variable. This allows testing the deadlock scenario without requiring older Windows versions. The implementation uses `SetFileInformationByHandle()` with `FileDispositionInfo` to force the legacy behavior when the variable is set.

The change is well-contained in `compat/mingw.c` and follows the pattern of other Windows-specific test helpers. It builds on prior review feedback by using `git_env_bool()` for environment variable parsing. The commit message clearly explains the Windows version behavior change and the purpose of the test infrastructure.

This is a preparatory patch that enables proper testing of the actual fix (which comes in patch 2/2). The series has already received positive reviews from domain experts Derrick Stolee and Patrick Steinhardt, with all technical concerns addressed. The test infrastructure may be useful for other Windows compatibility testing scenarios beyond just this deadlock issue.
