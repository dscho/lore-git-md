This is the second patch in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows builds, following up on the initial patch that disabled its usage. The patch focuses on build system cleanup, removing all nedmalloc-related configuration and build rules.

The changes systematically eliminate nedmalloc references across multiple build systems:
- Removes the `USE_NED_ALLOCATOR` option and related compiler flags from the Makefile
- Deletes the commented-out nedmalloc setting in `config.mak.uname`
- Strips nedmalloc from the list of third-party sources in both Makefile and meson.build
- Removes a nedmalloc reference from VSCode configuration

The patch is purely mechanical removal of now-unused build system plumbing, following the logical sequence established in the series. It prepares for the subsequent patches that will delete the actual nedmalloc source files. The changes are straightforward and unlikely to be controversial, being the natural follow-through on the decision to remove nedmalloc entirely rather than just disable it.

This continues the well-structured approach seen in the series, with each patch handling a distinct aspect of the removal process. The commit message clearly explains the patch's role in the larger effort and its relationship to the surrounding patches.
