This is the final patch in Johannes Schindelin's series removing the unmaintained nedmalloc allocator from Git's Windows builds. The patch completes the deletion of the malloc implementation by removing the remaining 1827 lines from `compat/nedmalloc/malloc.c.h`, which contained the core allocation algorithms and system interaction code.

The removal is motivated by GCC 16 compatibility issues (specifically new `-Wunused-but-set-variable` warnings) and the fact that Git for Windows has already switched to using mimalloc. The series took a structured approach to removal: first disabling usage (patch 1), then build system references (patch 2), auxiliary files (patch 3), and finally splitting the large malloc implementation file into reviewable chunks (patches 4-6).

This final patch removes the "System allocation" functionality through the end of the file, including:
- Core memory management operations (sys_alloc, sys_trim)
- Large and small allocation algorithms (tmalloc_large, tmalloc_small)
- Reallocation and alignment support (internal_realloc, internal_memalign)
- Public interface functions (dlmalloc, dlfree, etc.)
- Memory space management for multi-threaded scenarios
- Extensive historical changelog comments

With this change, the entire `compat/nedmalloc/` directory is now removed from the tree, completing the deprecation that began when Git for Windows switched to mimalloc. The patch is mechanical in nature - it simply deletes code that is no longer used or maintained. No behavior changes result since the code was already disabled in earlier patches.
