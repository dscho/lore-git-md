This is a follow-up from the Dash shell maintainer addressing the multibyte character handling issue in heredocs that Patrick Steinhardt reported. Herbert Xu provides a fix for Dash's parser to properly handle multibyte characters in quoted heredoc delimiters, which was causing test failures in Git's test suite.

The patch modifies Dash's `readtoken1()` function to properly handle multibyte characters when processing quoted heredocs (SQSYNTAX case). The key change is passing an additional flag to `getmbc()` to indicate we're in a quoted heredoc context, preventing the incorrect escaping that was corrupting multibyte characters like "perú" in Git's tests.

This is the upstream fix for the issue that Patrick's test workarounds were addressing. The patch is well-contained, touching only the parser logic for heredoc handling. With this fix in Dash, some of Patrick's test modifications might eventually become unnecessary, though they'll still be valuable for compatibility with older Dash versions.

The response shows good collaboration between the Git and Dash projects - Patrick identified and reported the shell bug with clear reproduction cases, and Herbert promptly provided the fix. This is a good example of cross-project issue resolution in the open source ecosystem.
