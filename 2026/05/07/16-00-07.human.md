This is a platform compatibility patch series from Johannes Schindelin, completing the removal of the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds. The series follows up on an earlier single-patch version that just disabled nedmalloc usage, now fully excising the code from the tree.

The motivation remains GCC 16 compatibility - the old nedmalloc code triggers new warnings treated as errors. Git for Windows has already moved to mimalloc, but benchmarks show no significant advantage over system allocators, so Schindelin is dropping mimalloc support too rather than upstreaming it. The series thus removes all nedmalloc infrastructure in six steps:

1. Disables nedmalloc in build configs (CMake/Meson too this time)
2-6. Systematically removes the vendored nedmalloc code, split across patches to avoid email size limits

The changes are mechanical deletions with no behavior impact since Git for Windows hasn't used nedmalloc in years. The series appears well-structured, with each commit focused on a logical removal step. The cover letter provides clear rationale and links to relevant benchmarks and prior discussion.

This represents the natural conclusion of the nedmalloc deprecation path started in the initial patch, now that mimalloc integration plans have been abandoned. The changes are low-risk and uncontroversial, addressing a concrete build issue while cleaning up technical debt.
