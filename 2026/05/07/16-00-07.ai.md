This is a platform compatibility patch series from Johannes Schindelin, completing the removal of the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds. The series expands on the initial single-patch approach by fully removing all nedmalloc-related code and build system plumbing.

The core motivation remains GCC 16 compatibility - the vendored nedmalloc code fails to build with GCC 16's new warnings. Since Git for Windows already switched to mimalloc years ago (and benchmarks show no significant advantage over platform allocators), the series takes the opportunity to fully excise nedmalloc rather than just disable it.

Key changes in v2:
- Adds 5 new patches that completely remove the nedmalloc code (split across multiple commits due to mailing list size limits)
- Updates CMake and Meson configurations alongside the Makefile changes
- Drops the temporary "keep code in tree" approach from v1 in favor of full removal

The series is structured to first disable nedmalloc usage (patch 1), then remove build system references (patch 2), auxiliary files (patch 3), and finally the large malloc.c.h in chunks (patches 4-6). This follows the natural dependency order while working around technical constraints.

The change is well-motivated and appears mechanically sound. The commit messages provide clear rationale and the patch structure demonstrates thoughtful handling of the technical constraints. This represents the logical conclusion of the nedmalloc deprecation path that began with Git for Windows' earlier switch to mimalloc.
