This is a bugfix patch series addressing a Windows-specific deadlock in `git maintenance`'s geometric repacking strategy. The issue occurs on certain Windows 10 versions where mmap'd pack index files prevent child processes from deleting old packfiles.

The root cause is that `maintenance_task_geometric_repack()` wasn't properly releasing the object database before spawning `git repack`, unlike other maintenance tasks. Johannes Schindelin (Git for Windows maintainer) provides both the fix and a test helper (`GIT_TEST_LEGACY_DELETE`) to simulate the problematic Windows behavior on modern systems.

The series has already gone through one round of review, with Patrick Steinhardt suggesting the use of `git_env_bool()` for environment variable parsing - a change that's been incorporated in v2. The patches are well-structured, with the first adding test infrastructure and the second containing the actual fix.

This addresses a real-world issue reported in the Git for Windows tracker (#6210) and demonstrates careful attention to platform-specific edge cases. The changes are focused and clearly explained, with the Windows version behavior changes properly documented. The test coverage appears thorough, including verification of the fix on both affected and unaffected Windows versions.
