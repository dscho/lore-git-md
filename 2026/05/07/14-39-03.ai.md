Feature enhancement for `git add -p` adding word-diff view option.

D. Ben Knoble builds on Phillip Wood's substantive review of Javier Bassi's patch to add a 'w' command for word-diff viewing in `git add -p`. While agreeing with the usefulness of the feature, Knoble suggests a more extensible approach that would allow arbitrary diff options rather than just word-diff. He proposes a `:show <opts>` command syntax (inspired by Vim) that could support any combination of diff options without requiring new single-letter mnemonics for each variant. This suggestion comes from someone familiar with Git's interactive commands and build system, though it represents a more ambitious extension than the current focused word-diff proposal. The email keeps the discussion grounded in the practical need for better change visualization in structured text formats while exploring how the interface might evolve to accommodate future needs. Knoble's suggestion doesn't contradict Phillip Wood's technical feedback about filename propagation and context preservation, but rather offers a complementary perspective on the command interface design.
