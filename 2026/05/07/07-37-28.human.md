This is a follow-up from the Dash shell maintainer with the final fix for the multibyte character handling issue in heredocs that was causing test failures in Git's test suite. Herbert Xu provides the upstream Dash patch that resolves the root cause of the problem Patrick Steinhardt had been working around in his test modifications.

The patch modifies Dash's `readtoken1()` function to properly handle multibyte characters in quoted heredoc delimiters by passing a new flag to `getmbc()` when processing single-quoted heredocs (SQSYNTAX case). This ensures multibyte characters like "perú" in Git's tests are preserved correctly rather than being corrupted.

This completes the cross-project collaboration that began with Patrick's bug report - the Dash maintainer has now provided the definitive fix that will prevent the issue in future shell versions. While Patrick's test workarounds will remain valuable for older Dash versions, this upstream solution means the problem won't affect users with updated shells.

The patch is well-contained and clearly explained, showing good technical collaboration between the Git and Dash projects. With this fix, the original issue can be considered fully resolved at both the test suite and shell implementation levels.
