This is a bugfix patch series addressing a Windows-specific deadlock in geometric repacking during `git maintenance`. The issue occurs when mmap'd pack index files prevent child processes from deleting old packfiles on certain Windows 10 versions.

The root cause is that `maintenance_task_geometric_repack()` fails to set `child.odb_to_close` when spawning `git repack`, unlike other maintenance tasks. This leaves mmap'd files locked, triggering deletion failures on pre-POSIX-delete Windows 10. The fix adds the missing ODB closure.

The series comes from Johannes Schindelin (Git for Windows maintainer) and has already gone through one revision incorporating Patrick Steinhardt's suggestion to use `git_env_bool()` for environment variable parsing. The first patch introduces test infrastructure (`GIT_TEST_LEGACY_DELETE`) to simulate legacy Windows delete behavior on modern systems, while the second patch implements the actual fix by properly setting `odb_to_close`.

The changes are well-considered and focused, with clear commit messages explaining both the Windows-specific behavior and the solution. The test infrastructure addition demonstrates thoughtful design for platform-specific issues, allowing the regression test to verify the fix works even on Windows 11. The series has received positive reviews from domain experts (Derrick Stolee confirmed LGTM for upstream submission) and appears ready for inclusion.
