This is the second patch in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows build configuration. Following the first patch which disabled nedmalloc usage, this one removes all remaining build system plumbing - Makefile rules, configuration options, and meson build references.

The changes are mechanical and straightforward:
- Removes USE_NED_ALLOCATOR definitions and related Makefile rules
- Deletes the commented-out USE_NED_ALLOCATOR line in config.mak.uname
- Drops nedmalloc from the third-party sources list
- Updates the VSCode configuration to remove a related spelling exception
- Removes nedmalloc from meson.build's third-party excludes

The patch is part of a well-structured series that methodically removes all traces of the unmaintained nedmalloc code, which was already obsolete since Git for Windows switched to mimalloc years ago. The changes are clean and focused, with no expected impact since the allocator was already disabled in practice.
