This is a build system patch addressing a Clang compiler warning issue on Linux. The problem occurs when building with DEVELOPER=1, where Clang treats C11 features in glibc headers (like _Generic in string.h macros) as extensions and raises errors due to the combination of -std=gnu99, -pedantic, and -Werror flags. The patch adds -Wno-c11-extensions to DEVELOPER_CFLAGS specifically for Clang on Linux, while maintaining strict checking on other platforms.

The change is narrowly scoped to only affect Linux builds with Clang, preserving the existing behavior on macOS and other platforms. The commit message clearly explains the technical rationale and the specific conditions under which the warning suppression applies. This appears to be a well-motivated, platform-specific build system tweak rather than a broader change to Git's code or build requirements.
