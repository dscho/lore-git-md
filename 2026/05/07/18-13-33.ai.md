Documentation patch clarifying `--follow` and `--no-follow` options in git-log.

This v2 patch builds on the initial documentation effort by Tamir Duberstein to properly document the long-standing but previously undocumented `--no-follow` option for `git log`. - Clarifies that `--follow` works with a single pathspec (not just a single file)
- Uses matching terminology between the config and man page documentation
- Explicitly notes `--no-follow` can override the `log.follow` config
- Maintains references to the original implementation commits (aebbcf5797, 076c98372e, 1e9250b5aa)

The patch remains focused on documentation accuracy, touching only the config and man page files with clear, concise additions.
