This is patch 5/6 in Johannes Schindelin's series removing the nedmalloc allocator from Git's MINGW builds. The patch continues the mechanical deletion of the malloc.c.h file, removing the "Overlaid data structures" through "System allocation" sections (1699 lines).

The removal follows the structured approach established in earlier patches: first disabling usage (patch 1), then build system references (patch 2), auxiliary files (patch 3), and now the core implementation in chunks (patches 4-6). This patch focuses on the memory management internals including:

- Data structures for free chunks (small bins as doubly-linked lists, larger chunks in trees)
- Segment management for non-contiguous memory regions
- The malloc_state structure tracking all allocation metadata
- Configuration parameters and initialization
- Debugging and statistics support
- Operations on bins and trees

The changes are purely deletion - no behavior changes since Git for Windows already uses mimalloc. The patch maintains the series' careful approach of splitting the large file into reviewable chunks while preserving logical boundaries in the code.

This continues the well-motivated cleanup to address GCC 16 compatibility while removing unmaintained code. The commit message clearly documents the section boundaries and the series' progression.
