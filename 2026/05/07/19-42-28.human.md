Documentation patch clarifying commit-graph behavior with replace objects and grafts.

This v3 patch from Kristoffer Haugsbakk adds an Acked-by from Derrick Stolee to the documentation improvements about how replace objects and commit grafts affect commit-graph functionality. The patch maintains the same content as v2, which added clear "CAVEATS" sections to both `git-commit-graph` and `git-replace` man pages explaining these interactions.

The key points remain:
- Commit-graph functionality is disabled when replace objects or grafts are present
- Performance impact is noted in the `git-replace` documentation
- Cross-references between the two man pages help users find related information

With Stolee's explicit approval now added, this documentation improvement appears ready for merging. The patch cleanly surfaces technical details that were previously only in the internal `technical/commit-graph.adoc` file, making them more accessible to end users.
