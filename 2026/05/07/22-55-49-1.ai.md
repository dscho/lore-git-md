This is a follow-up in the RHEL 6 build failure thread, where the reporter has identified the specific OpenSSL version conflict and found a working solution. The issue stems from commit 6392a0b75d which updated `imap-send` to use OpenSSL 1.1+ APIs, conflicting with RHEL 6's system OpenSSL 1.0.1e.

The reporter discovered that while their system had OpenSSL 3.5.6 installed, Git was defaulting to the older system OpenSSL during compilation. They successfully worked around this by explicitly pointing the newer OpenSSL installation path (`--with-openssl=/usr/local/openssl`) during configuration. This solution works across both RHEL 6 and RHEL 8, though RHEL 8 already ships with OpenSSL 1.1.1 by default.

The email serves as a case study in debugging build issues, showing how checking build options (`git --version --build-options`) revealed the actual OpenSSL version being linked. While the project maintains that RHEL 6 is unsupported, this provides a practical resolution for users who need to build on such systems. The reporter also notes they'll now routinely check build options to avoid similar issues.
