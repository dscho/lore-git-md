Documentation patch adding `--no-follow` to git-log's man pages.

This patch fills a documentation gap by properly documenting the `--no-follow` option for `git log`, which has existed since 2012 but was only mentioned in the code and commit messages. The option allows overriding the `log.follow` configuration when it's enabled by default. The change is straightforward - adding the negated form alongside `--follow` in the man page and noting the override capability in the config documentation.

The patch is cleanly focused on documentation improvements, touching only two files with clear, concise additions. It references the relevant historical commits that introduced and modified the functionality, showing good attention to Git's history. The change is non-controversial and likely to be accepted as it simply brings the documentation in line with long-standing behavior.
