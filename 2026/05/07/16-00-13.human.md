This is the final patch in Johannes Schindelin's series to completely remove the unmaintained nedmalloc allocator from Git's Windows builds. The patch deletes the remaining 1827 lines of `malloc.c.h`, completing the removal of all nedmalloc code from the repository.

The series was motivated by GCC 16 compatibility issues with the outdated nedmalloc code (last updated in 2014). Since Git for Windows has already been using mimalloc for years without performance regressions, the team decided to fully remove nedmalloc rather than just disable it.

This patch follows a careful removal sequence that started with disabling usage (patch 1), then build system references (patch 2), auxiliary files (patch 3), and finally splitting the core implementation deletion across multiple patches (4-6) for manageable review. The changes are mechanical deletions with no runtime impact since the code wasn't being used.

The removal represents the completion of a long-planned cleanup that began when Git for Windows switched to mimalloc. With this patch, the entire `compat/nedmalloc/` directory is now removed from the tree. The change is well-structured and uncontroversial, following earlier agreement from reviewers like Patrick Steinhardt.
