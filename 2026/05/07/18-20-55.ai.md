Documentation patch clarifying commit-graph behavior with replace objects and grafts.

This v2 patch from Kristoffer Haugsbakk improves user-facing documentation about how replace objects and commit grafts affect commit-graph functionality. The key addition is a "CAVEATS" section in both `git-commit-graph` and `git-replace` man pages that explains these interactions, with cross-references between the two documents.

The main change from v1 is the addition of "which can cause performance issues" in the `git-replace` documentation, addressing Derrick Stolee's review feedback about making the performance impact more explicit. The `git-commit-graph` documentation remains focused on the behavioral aspect without emphasizing performance.

The patch cleanly surfaces information that was previously only in the `technical/commit-graph.adoc` documentation, making it more accessible to end users. The changes follow Git's documentation conventions and the diff shows proper formatting. With the v2 changes addressing the review feedback, this appears ready for merging.
