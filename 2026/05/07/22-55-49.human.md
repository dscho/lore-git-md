This is a follow-up in the RHEL 6 build failure thread, where the root cause was an OpenSSL version mismatch. The reporter, Азат Усманов, confirms they've identified the specific issue: Git 2.54's `imap-send` requires OpenSSL 1.1+ APIs (introduced in commit 6392a0b75d) while their RHEL 6 system only provides OpenSSL 1.0.1e.

The email provides a workaround that worked for them - explicitly pointing the build to a newer OpenSSL installation via `--with-openssl=/usr/local/openssl`. They note this solution works on both RHEL 6 and RHEL 8, though the latter would have built successfully anyway since RHEL 8 ships with OpenSSL 1.1.1 by default.

The reporter acknowledges they should have been checking build options more carefully, and thanks the thread participants for helping them diagnose the issue. This effectively closes the thread with a practical solution, though the project's position remains that RHEL 6 is unsupported. The email demonstrates how users can work around platform support limitations when they have control over their build environment.
