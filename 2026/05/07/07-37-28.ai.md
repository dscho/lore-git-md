This is an upstream fix from the Dash shell maintainer addressing the multibyte character handling issue in heredocs that was causing test failures in Git's test suite. Herbert Xu provides the definitive solution for Dash's parser to properly handle multibyte characters in quoted heredoc delimiters.

The patch modifies Dash's `readtoken1()` function to correctly process multibyte characters when in a quoted heredoc context (SQSYNTAX case). The key change passes an additional flag to `getmbc()` to indicate we're in a quoted heredoc, preventing the incorrect escaping that was corrupting multibyte characters like "perú" in Git's tests. The fix is well-contained, touching only the parser logic for heredoc handling.

This represents the completion of the cross-project collaboration - Patrick Steinhardt originally identified and reported the shell bug with clear reproduction cases, and Herbert has provided the upstream fix. While Patrick's test modifications in Git will remain valuable for compatibility with pre-fix Dash versions, this change addresses the root cause. The patch is cleanly implemented with a clear explanation of the fix and its context.
