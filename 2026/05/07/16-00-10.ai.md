This is patch 3/6 in Johannes Schindelin's series removing the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds. The series addresses GCC 16 compatibility issues and completes the removal that began when Git for Windows switched to mimalloc.

This patch removes the smaller auxiliary files from the nedmalloc implementation:
- License.txt (Boost license)
- Readme.txt (documentation and changelog)
- nedmalloc.c (wrapper implementation)
- nedmalloc.h (header file)

The commit explains this is being done in a separate patch because the main nedmalloc implementation file (malloc.c.h) is too large (196KB) to delete in one mailing list message. This preparatory patch creates space for the subsequent patches that will remove the larger file in chunks.

The removal is part of a systematic cleanup - earlier patches disabled nedmalloc usage and removed build system integration. This continues the logical progression toward completely excising the unmaintained code. No functional changes are introduced, as Git for Windows has already been using mimalloc instead of nedmalloc for years.

The patch is mechanically straightforward, deleting files that are no longer needed. The commit message clearly explains the technical constraints (mailing list size limits) that motivated splitting the removal across multiple patches.
