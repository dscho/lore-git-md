This is a follow-up to a build system adjustment for the Rustification effort, specifically addressing the osxkeychain credential helper. Shardul Natu (Google) has revised their patch in response to Kristoffer Haugsbakk's review, removing an internal Google reference ("CL 910223487") from the commit message that would have been meaningless to external readers.

The patch itself remains unchanged in its technical content - it still adds Rust library linking support to git-credential-osxkeychain when Rust is enabled, using a new RUST_LIBS variable. The change is narrowly scoped to build system integration and remains a no-op when Rust support is disabled.

The revision shows the author responding promptly to documentation feedback, though the patch still awaits substantive technical review of its build system changes. This continues to be a small but necessary piece of the broader Rustification effort, specifically targeting macOS credential helper integration.
