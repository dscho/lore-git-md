Documentation patch adding `--no-follow` to the git-log man page.

This patch fills a documentation gap by properly documenting the `--no-follow` option for `git log`, which has existed since 2012 but was only mentioned in the code and commit messages. The option allows overriding the `log.follow` configuration when it's set to true. The changes are straightforward - adding the negated --no-follow form alongside --follow in the options list and clarifying its interaction with the config in both the config and command documentation.

The patch is cleanly focused on documentation completeness, referencing the relevant historical commits that introduced the functionality. It follows the project's documentation style and makes the behavior more discoverable for users. A simple but useful improvement to the docs.
