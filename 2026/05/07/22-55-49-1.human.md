This is a follow-up in a thread about build failures on RHEL 6 due to OpenSSL version conflicts. The original reporter, Азат Усманов, has identified the specific commit (6392a0b75d) that introduced OpenSSL 1.1+ API requirements for `imap-send`, breaking compatibility with RHEL 6's system OpenSSL 1.0.1e.

The reporter found a workaround by explicitly configuring the build to use a local OpenSSL 3.5.6 installation via `--with-openssl=/usr/local/openssl`. They note this solution works across both RHEL 6 and RHEL 8, though RHEL 8 already ships with OpenSSL 1.1.1 by default. The thread serves as a useful case study in debugging build issues on older platforms, though the project's official position (as previously stated by brian m. carlson) remains that RHEL 6 is unsupported.

The reporter also shares a lesson about checking build options more carefully, having discovered through `git --version --build-options` that their previous builds were unintentionally using the system OpenSSL rather than their intended version. This provides a practical resolution for others who might encounter similar issues, even on unsupported platforms.
