This is a follow-up to Patrick Steinhardt's test infrastructure patch series addressing Dash shell compatibility issues. Herbert Xu, the Dash maintainer, provides an upstream fix for the multibyte character handling bug in quoted heredocs that Patrick had worked around in his test patches.

The patch modifies Dash's parser.c to properly handle multibyte characters in heredocs with quoted delimiters (SQSYNTAX case). The fix ensures such characters are written unescaped, addressing the specific issue Patrick observed where strings like "perú" were being corrupted in test output. The change is minimal and targeted, adding a check for SQSYNTAX before calling getmbc() and passing a flag to control escaping behavior.

This is significant because it means Patrick's workaround (converting quoted heredocs to unquoted ones in the test suite) may no longer be strictly necessary once this Dash fix is widely deployed. However, the test suite changes will still be valuable for compatibility with older Dash versions. The patch demonstrates good cross-project collaboration, with the shell maintainer responding to Git's test suite findings with a proper upstream fix.
