This is a test modernization patch from a GSoC participant, continuing the effort to clean up t2000 by consolidating test blocks. The patch combines eight separate test steps into a single cohesive block that shows the setup, operations, and assertions together.

The change improves readability by putting the entire test scenario in one place rather than scattering it across multiple blocks. It maintains all the same test coverage while removing redundant test_debug calls and intermediate state checks. The consolidation follows the pattern established in previous test modernization work.

The patch is mechanically sound - it doesn't change any test logic, just reorganizes the existing steps. The helper functions (test_path_is_dir_not_symlink etc.) were introduced in earlier modernization work, so this builds on that foundation. Karthik Nayak's Helped-by suggests the change has already had some review attention.

This is a straightforward improvement that aligns with the project's test suite guidelines. The consolidation makes the test's purpose and flow clearer while maintaining all the original coverage. As the first of two patches in this series, it sets up for the cleanup of debug code in the follow-up.
