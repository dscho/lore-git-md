This is a test patch (part 3/4) in Siddh Raman Pant's series adding external notes display support. The patch adds test coverage for existing notes display behavior that the new external command feature will need to integrate with.

The tests verify four key aspects of notes display that must work consistently whether notes come from Git's internal storage or an external command:
1. Raw formatting (--format=%N) shows note content without decoration
2. --no-notes suppresses note display as expected
3. Explicit --notes=ref overrides the default notes ref
4. --grep searches note text when notes are displayed

The tests are straightforward and well-scoped, each checking one specific behavior. This establishes a baseline before the next patch introduces the external command integration. The test names clearly describe what they verify, and the assertions use Git's test helpers (test_grep, test_must_be_empty) appropriately.

As part of a larger feature series, this patch does the important groundwork of documenting the current behavior that the new feature must maintain. The tests will help catch any regressions when the external command support is added in subsequent patches.
