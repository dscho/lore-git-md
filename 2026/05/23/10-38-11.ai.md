This is a test patch (part 3/4) in Siddh Raman Pant's series adding external notes display functionality. The patch adds test coverage for existing notes display behavior that the new external command feature will need to integrate with.

The test additions verify four aspects of notes display that will be relevant for the external command implementation:
1. Raw formatting of notes (without the "Notes:" header)
2. Suppression of notes display with --no-notes
3. Overriding the default notes ref with an explicit --notes=ref
4. Using notes content for --grep pattern matching

These tests establish baseline behavior that the external notes command will need to maintain compatibility with. The tests are focused and well-structured, each verifying a specific aspect of the display pipeline that the new feature will hook into.

As part of a larger series, this patch helps ensure the external notes command will properly handle these existing use cases. The test additions are straightforward and appear correct, though their real value will become clear when the external command implementation is reviewed in subsequent patches.
