This is a technical infrastructure patch in Siddh Raman Pant's series adding external notes display support. It introduces timeout and deadline handling for read operations in Git's wrapper functions.

The patch adds new variants of `xread()` and related functions that support timeouts (milliseconds) and deadlines (nanoseconds since epoch). The key additions are:
- `xread_timeout()` and `xread_deadline()` variants of the core read function
- Corresponding `read_in_full_timeout()` and `read_in_full_deadline()` helpers
- New `strbuf_getwholeline_fd_timeout()` and `strbuf_getwholeline_fd_deadline()` for line-oriented reading
- A poll()-based wait mechanism in `wait_for_fd()` that handles the timeout logic

The implementation maintains backward compatibility by keeping the original non-timeout versions, which now call the new functions with timeout=0. The changes touch core I/O functions in wrapper.c and strbuf.c, with corresponding header updates.
