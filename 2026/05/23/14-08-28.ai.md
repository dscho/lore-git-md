This is a maintainer-approved follow-up to patch 8/11 in the git-gui bugfix series. The patch addresses a regression where the browser subcommand fails with a detached HEAD state after the switch to using `git branch --show-current` for reftable compatibility.

Git-gui maintainer Johannes Sixt confirms the fix is correct and plans to reorder it as the first commit in the series. The change is minimal - just three lines that restore the pre-reftable behavior by explicitly setting the branch name to "HEAD" when in detached state. This maintains consistency with git-gui's browser expectations while keeping the reftable compatibility improvements from the original change.

The thread context shows this is part of a larger effort to modernize git-gui's repository handling, with all fundamental technical concerns already addressed in previous rounds of review. This particular patch represents a straightforward resolution to a clear edge case that was identified during testing phase.
