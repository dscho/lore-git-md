This is the final patch in Siddh Raman Pant's series adding support for external notes display commands. The patch implements the core functionality for executing and communicating with an external notes helper process.

Key technical aspects:
- Adds new `notes-external.{c,h}` files implementing the external command protocol
- Defines configuration options (`notes.externalCommand`, `notes.externalCommandName`, `notes.externalCommandTimeoutMs`, `notes.externalCommandForGrep`)
- Implements timeout handling using the new wrapper.c helpers from patch 2
- Modifies notes display logic to integrate external notes alongside traditional notes refs
- Adds extensive test coverage (400+ lines across 6 test scripts)

The implementation allows configuring an external command that Git will execute to display notes content, with the command receiving commit object IDs as input. The protocol supports both "missing" responses and notes payloads with length-prefixed content. Timeout handling prevents hangs from unresponsive helpers.

The patch maintains backward compatibility while adding the new functionality. External notes can be combined with traditional notes refs or used exclusively via command-line flags (`--external-notes`, `--no-external-notes`).

Security considerations:
- External commands are only be configured in protected configuration
- Timeouts prevent denial of service from slow commands
- Input/output is strictly validated

The extensive test coverage suggests the author has considered many edge cases around protocol parsing, timeout handling, and integration with existing notes functionality. Reviewers will likely scrutinize the security implications of executing external commands.
