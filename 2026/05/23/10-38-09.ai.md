This is a refactoring patch from Siddh Raman Pant's series adding external notes display support. It converts the `raw` parameter in notes display functions from `int` to `bool` to better reflect its usage. The change is mechanical but improves type safety and clarity, touching four files that handle notes display:

- Updates function signatures in notes.c and notes.h
- Modifies call sites in log-tree.c and revision.c
- Adjusts related documentation to use boolean terminology

The patch is straightforward with no behavior changes, serving as groundwork for the more substantive notes display changes that follow in the series. As the first patch in v3 of the series, it continues the pattern seen in earlier iterations of starting with preparatory cleanups before introducing new functionality.
