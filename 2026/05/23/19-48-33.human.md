This is a refactoring patch that's part of Harald Nordgren's series to add `--track=fetch` functionality to `git checkout` and `git switch`. The patch extracts helper functions from `branch.c` that will be reused in the subsequent feature implementation.

The key changes:
- Moves the `struct tracking` definition to `branch.h` to make it available to other files
- Extracts `find_tracking_remote_for_ref()` and `advise_ambiguous_fetch_refspec()` from the existing `setup_tracking()` function
- Updates `setup_tracking()` to use these new helpers instead of its inline implementation
- Maintains all existing behavior while making the remote tracking logic reusable

This is a clean refactoring that enables the next patch to share the same remote tracking logic that `git branch --track` uses, ensuring consistent behavior across commands. The patch has already been reviewed and approved in previous iterations of the series, with Junio Hamano and Phillip Wood having signed off on the approach.

The refactoring is well-motivated as it eliminates duplicate code and will allow the new `--track=fetch` feature to handle ambiguous remote references consistently with existing commands. The changes are focused and mechanical, with no functional changes to the existing code paths.
