The patch updates the type to `bool` throughout the call chain, including the function signature, documentation, and all call sites. The behavior remains identical - this is purely a type cleanup.

As the first patch in the series, this appears to be preparatory work for the larger feature that follows. The change is mechanical and low-risk, touching only the notes display plumbing. The patch maintains consistency with surrounding code and follows Git's style guidelines.
