This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the current state of patches in the Git project's integration branches. The report covers both recently merged topics and new patches under consideration.

Several notable changes have graduated to 'master':
- HTTP proxy URL validation now rejects unsupported schemes
- Expensive tests are enabled in CI to catch integration issues earlier
- Multiple leak fixes from Jeff King
- Refactoring of ref backend service routines
- A new "git url-parse" subcommand exposes internal URL parsing
- Maintenance daemon mode now properly uses lockfiles
- Memory usage improvements in the xdiff diff engine

New topics under discussion include:
- git-jump improvements for automatic mode selection
- Documentation fixes for range-diff and replay commands
- Significant ODB (object database) refactoring work from Patrick Steinhardt
- macOS CI runner updates
- Branch pruning options for merged branches
- Performance optimizations for bitmap generation
- Improvements to date parsing ("Friday noon" edge case)

The report also lists many ongoing efforts in various states of review, including:
- The ort merge backend's handling of corrupt trees
- Path-walk integration with object filters
- Promisor remote configuration improvements
- Fsmonitor implementation for Linux
- Subcommand autocorrection in parse-options
- Incremental MIDX repacking strategy

This update shows Git's development continuing at a steady pace, with a mix of bugfixes, performance improvements, and architectural refactoring. The maintainer has carefully categorized each topic by its current integration status, making it easy to see what's stable versus what's still under active discussion.
