This is version 13 of Harald Nordgren's feature patch series adding `--track=fetch` mode to `git checkout`/`git switch`. The series is now split into two patches:

1. **Refactoring**: Exposes `find_tracking_remote_for_ref()` and `advise_ambiguous_fetch_refspec()` from branch.c so checkout can reuse the same remote lookup logic that `git branch --track` uses. This ensures consistent behavior between commands.

2. **Feature implementation**: Uses the newly exposed helpers to handle the "multiple remotes match" case with identical messaging to `git branch --track`. The key change from v12 is replacing custom ambiguity resolution code with the shared implementation from branch.c.

The implementation now has:
- Unified remote tracking resolution across commands
- Matching error messages for ambiguous cases
- Full test coverage (18 test cases)
- Documentation updates
- Maintainer-approved design

Junio and Phillip Wood had previously approved the technical approach in v12. This version addresses the final polish point by making the error handling identical to `git branch --track`. The feature appears complete and ready for merging.
