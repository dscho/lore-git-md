This is patch 7/18 in Patrick Steinhardt's series to remove `the_repository` usage from the setup subsystem, part of the ongoing `the_repository` removal effort. The patch converts `verify_non_filename()` to take an explicit `struct repository *` parameter instead of implicitly using the global variable.

The change is mechanical but touches several callers across checkout, grep, reset commands and revision handling. Each caller now passes `the_repository` explicitly, maintaining the same behavior while removing the hidden dependency. The patch follows the series' consistent approach of pushing repository parameters up the call stack rather than relocating static state.

This continues the systematic elimination of global state from Git's setup machinery, with Patrick having already incorporated feedback on thread-safety and performance from earlier reviews. The changes are straightforward and unlikely to be controversial at this point in the well-reviewed series.
