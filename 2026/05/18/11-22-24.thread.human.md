Erik Cervin Edin has proposed extending `git commit --fixup` to support non-interactive message specification via `-m`, `-F`, `-c`, and `-C` options when using `--fixup=amend:` or `--fixup=reword:`. The series has gone through multiple iterations addressing feedback from Junio Hamano and Phillip Wood.

The current v2 series completes the functionality by adding support for `-c` and `-C` options across all fixup variants. The implementation carefully routes these cases through `prepare_to_commit()` while maintaining backward compatibility (the editor still launches when no message options are provided). For amend-style messages, it strips "amend!" lines when copying from source commits to match interactive editing behavior.

Both Junio and Phillip have reviewed the changes, with Phillip's sequencer expertise particularly valuable for the message handling implementation. Their feedback on test hygiene, terminology, and code reuse has been fully incorporated. The series now provides comprehensive test coverage and appears production-ready, offering a consistent interface for all message specification methods across fixup variants while preserving existing behavior.
