This is patch 4/8 in Derrick Stolee's series to improve fetch/push negotiation in monorepos. The patch adds a new `remote.<name>.negotiationRestrict` config option that provides the same functionality as the existing `--negotiation-restrict` command-line flag, allowing users to set default negotiation restrictions per remote.

The config option is multi-valued and supports both exact ref names and glob patterns. Command-line arguments take precedence over config values, and an empty value can be used to reset the list (useful for overriding system/global configs). The implementation includes thorough test coverage showing the config works as expected and properly interacts with command-line overrides.

This is part of the larger effort to address inefficient object transfers in monorepos by giving users more control over which refs are considered during negotiation. The patch has been reviewed by Matthew Cheetham and carries his Reviewed-by tag, indicating it's technically sound. The series as a whole appears well-considered and ready for maintainer consideration.
