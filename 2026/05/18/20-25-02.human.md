This is a performance optimization patch from René Scharfe, part of his series improving Git's overflow checking patterns. The patch specifically targets the `st_add()` function in git-compat-util.h, which performs safe addition with overflow checking.

The key change introduces a new `st_add_overflow()` helper that uses Clang's `__builtin_add_overflow()` when available, falling back to Git's existing overflow check otherwise. This provides a 4% performance improvement on ARM64 (Apple M1) for operations that heavily exercise strbuf growth, as shown in the included benchmark of `git cat-file --batch-all-objects`.

The patch maintains all the existing safety guarantees while optimizing the common case where Clang can generate better machine code by checking processor flags rather than doing explicit comparisons. Jeff King suggested this approach, and René has carefully implemented it to work across platforms while keeping the code clean and maintainable.

This continues René's pattern of precise, thoughtful refactoring - the change is small but meaningful, with clear performance benefits and no loss of safety. The patch appears ready for merging, having addressed all previous review feedback in the v2 iteration.
