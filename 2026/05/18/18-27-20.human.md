This is part 2 of a 3-patch series adding remote group support to `git push`, mirroring the existing `git fetch` functionality. The series has gone through six iterations and appears ready for merging.

The patch moves generic remote group resolution helpers (`get_remote_group`, `add_remote_or_group`, and `remote_group_data`) from builtin/fetch.c to remote.c/remote.h, making them available to other commands. This refactoring was suggested by Junio Hamano to avoid code duplication, as the push implementation in the next patch will need the same logic. The change is purely mechanical - the functions are identical, just relocated to be shared.

The implementation is straightforward and well-tested, with the series having comprehensive test coverage. This particular patch is a clean-up that enables the actual push group functionality in patch 3 while keeping the codebase DRY. No functional changes are introduced here - it's purely moving and exposing existing code for reuse.
