This is the final patch in Derrick Stolee's series introducing new negotiation controls for fetch and push operations. The patch completes the push integration by passing the `--negotiation-include` and `--negotiation-restrict` configurations from the transport layer to the underlying `git fetch --negotiate-only` process that handles push negotiation.

The key changes in this patch:
- Extends `send-pack.c` to pass the negotiation include/restrict configurations when spawning the negotiate-only fetch
- Updates documentation to clarify these configs also affect push negotiation
- Adds tests verifying the configs work properly with push negotiation
- Maintains backward compatibility by falling back to using all remote refs when no restrict config is set

The implementation is clean and follows the pattern established in earlier patches. Matthew Cheetham has reviewed and signed off on the changes. This completes the series' goal of providing fine-grained control over negotiation behavior for both fetch and push operations in monorepo scenarios.

With this patch, the series is now fully baked and ready for maintainer consideration. It addresses all review feedback from previous iterations and provides comprehensive test coverage for the new functionality.
