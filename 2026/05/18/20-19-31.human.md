This is patch 5/8 in Derrick Stolee's series to improve fetch/push negotiation in monorepos. The patch introduces a new `have_sent()` interface to the fetch negotiator, which allows the negotiator to track commits that have already been sent as "have" lines outside its control.

The key technical addition is a callback that lets the negotiator mark these commits as common, preventing redundant transmission of commits that are already known. The implementation is straightforward - it simply marks the commit as common in the negotiator's state - but provides the foundation for the upcoming `--negotiation-include` feature in patch 6/8.

The patch follows the series' pattern of thorough implementation, adding the new method to all three negotiator implementations (default, noop, and skipping) with appropriate documentation. It has already been reviewed and approved by Matthew Cheetham, as indicated by the Reviewed-by tag. This is a clean, focused addition that enables the more user-visible negotiation controls coming in later patches.
