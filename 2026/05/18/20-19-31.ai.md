This is patch 5/8 in Derrick Stolee's series introducing new negotiation controls for fetch/push operations. The patch adds a `have_sent()` callback to the fetch negotiator interface, allowing the negotiator to track commits that have already been sent as "have" lines outside its control.

The key technical addition is a new method in the fetch_negotiator interface that lets the negotiator know when commits are sent independently, so it can avoid redundant transmission and optimize further negotiation. The implementation marks these commits as common in both the default and skipping negotiators (with a no-op for the noop negotiator).

This is a well-contained infrastructure change that enables the subsequent patches to implement the `--negotiation-include` feature. The patch has already been reviewed and approved by Matthew Cheetham, with no outstanding technical concerns. It follows the project's conventions and includes proper documentation of the new interface.

The change is now in its final form after multiple rounds of review, with all feedback addressed. This patch represents a key technical solution in the series, replacing an earlier approach that used COMMON flags, and provides the foundation for the include/restrict negotiation controls that follow in patches 6-8.
