This is the final patch in Derrick Stolee's 8-part series introducing new negotiation controls for fetch and push operations. The patch completes the integration by passing the `--negotiation-include` and `--negotiation-restrict` configurations through to push operations when `push.negotiate` is enabled.

The key changes in this patch:
- Modifies `send-pack.c` to pass the negotiation include/restrict configurations from the remote to the child `git fetch --negotiate-only` process
- Updates documentation to clarify that these configs affect push negotiation
- Adds tests verifying the push integration works with both include and restrict configurations
- The implementation handles both the case where restrict config is provided (replacing default behavior) and when it's not (falling back to all remote refs)
- Includes are passed through to ensure their refs are always advertised during push negotiation

The patch carries Matthew Cheetham's Reviewed-by tag, confirming technical approval. With this final piece in place, the series is now complete and provides a comprehensive solution for controlling negotiation behavior during both fetch and push operations in monorepo scenarios.
