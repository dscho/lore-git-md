This is a feature patch proposing to enhance `git commit --fixup` functionality. The author, Erik Cervin-Edin, wants to allow using `-m` and `-F` options with `--fixup=amend:` and `--fixup=reword:` flags, which currently only work with an interactive editor.

The patch addresses a limitation where users currently must use `$EDITOR` to rewrite commit messages when using these fixup types. The change would enable non-interactive workflows, such as batch-applying rewritten messages from files. The proposal builds on previous discussion from 2021 where Junio Hamano considered but didn't implement this capability.

The implementation touches documentation, the commit command's core logic, and adds new test cases. The author has deliberately kept the scope narrow (excluding `-c/-C` options for now) as this is their first contribution. The patch appears well-motivated and thoughtfully scoped, addressing a real workflow pain point while maintaining backward compatibility.
