This is patch 4/8 in Derrick Stolee's final version of the negotiation control series, adding config support for the `--negotiation-restrict` feature. The patch introduces `remote.<name>.negotiationRestrict` as a multi-valued config option that provides default negotiation restrictions for fetches, mirroring the existing command-line option behavior.

The implementation:
- Adds documentation explaining the config syntax and its interaction with CLI options
- Extends the remote struct to store negotiation restrictions
- Modifies fetch's transport setup to apply config defaults when no CLI options are given
- Includes tests verifying config behavior, including override precedence and empty-value reset semantics

Key technical points:
- Config values are ignored if any `--negotiation-restrict` is specified on CLI
- Empty value clears previous config entries (useful for overriding system/global settings)
- Maintains consistency with the renamed CLI option (from `--negotiation-tip`)
- Preserves the warning when protocol doesn't support negotiation restrictions
