Junio Hamano's "What's cooking in git.git" status report for May 2026 tracks the state of in-flight Git development topics. Recent graduates to 'master' include `git backfill` improvements, ORT merge strategy cached rename handling, automatic stashing in `git checkout -m`, HTTP proxy fixes, submodule.fetchJobs corrections, and documentation/build updates. New proposals under review cover revision traversal optimizations, Mirko Faina's `--max-count-oldest` rev-list option (now in v7 with boundary condition bug identified), branch pruning via `--prune-merged`, worktree path configuration, and performance fixes. Mirko plans a v8 to address the boundary issue.

Taylor Blau's incremental MIDX repacking series (16 commits) has completed final review and is confirmed for 'next' after Jeff King approved v4 updates. The changes enable efficient MIDX repacking without full repacks, completing a major performance optimization effort with all feedback from Jeff King and SZEDER Gábor addressed.

Justin Tobler's ODB transaction interface rework (7 patches) has been merged into 'next' after addressing a memory leak identified by Jeff King. The series refactors object writing to be more pluggable, with changes including backend-aware `write_object_stream()`, generalized packfile writes via odb_write_stream, upfront size checks, and transaction flag cleanup. This foundational work enables Patrick Steinhardt's in-memory ODB backend effort (ps/odb-in-memory) and represents a key step in the ODB abstraction project. The changes touch core object writing paths but are now considered stable after thorough review.

Ongoing large-scale efforts include: `the_repository` global removal (René Scharfe), ODB abstraction (Patrick Steinhardt), reftable backend improvements (Steinhardt/Karthik Nayak), Rustification (Ezekiel Newren), platform compatibility (Randall Becker), repack/MIDX machinery changes (Steinhardt/Taylor Blau), and Linux fsmonitor daemon finalization (Paul Tarjan). The report flags several topics awaiting author responses, with the `--max-count-oldest` series in active iteration to resolve its boundary case. Development remains active across performance, features, documentation, and architectural fronts.
