Junio Hamano's "What's cooking in git.git" status report for May 2026 tracks the state of in-flight Git development topics across integration branches. Recent graduates to 'master' include: `git backfill` behavior improvements, ORT merge strategy cached rename handling, automatic stashing in `git checkout -m`, HTTP proxy URL validation fixes, submodule.fetchJobs configuration corrections, and various documentation/build system updates. New proposals under review cover revision traversal optimizations using priority queues, Mirko Faina's `--max-count-oldest` rev-list option (currently in v7 with a boundary condition bug identified), branch pruning via `--prune-merged`, worktree path configuration in includeIf, and performance/memory fixes. Mirko has acknowledged the `--max-count-oldest` boundary interaction issue and plans a v8 to address it before potential integration.

Taylor Blau's incremental MIDX repacking series (16 commits) has been fully reviewed and approved by Jeff King and SZEDER Gábor, addressing all prior feedback. The changes enable incremental MIDX repacking without full all-into-one repacks, improving maintenance efficiency for large repositories. The series is now ready for integration pending Junio's decision.

Justin Tobler's ODB transaction interface rework series (7 patches) refactors Git's object writing interface to be more pluggable, with changes including making `write_object_stream()` backend-aware, generalizing packfile writes via odb_write_stream, optimizing object writes by checking sizes upfront, and cleaning up transaction flags. The series has addressed a memory leak identified by Jeff King and is now ready for integration into 'next'. This work is foundational for Patrick Steinhardt's in-memory ODB backend effort (ps/odb-in-memory).

Ongoing large-scale efforts include: `the_repository` global removal (René Scharfe), ODB abstraction (Patrick Steinhardt), reftable backend improvements (Steinhardt/Karthik Nayak), Rustification (Ezekiel Newren), platform compatibility (Randall Becker), repack/MIDX machinery changes (Steinhardt/Taylor Blau), and Linux fsmonitor daemon finalization (Paul Tarjan). The report flags several topics awaiting author responses or rerolls, with the `--max-count-oldest` series now in active iteration to resolve its boundary case issue. Development activity remains high across performance, features, documentation, and architectural fronts.
