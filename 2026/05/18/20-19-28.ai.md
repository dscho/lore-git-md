This is patch 2/8 in Derrick Stolee's series introducing new negotiation options for fetch/push. The patch renames the existing `--negotiation-tip` option to the more accurately named `--negotiation-restrict` while keeping the old name as an alias for compatibility.

The change better reflects the option's actual behavior - it restricts negotiation to a subset of refs rather than just specifying "tips". The patch updates all documentation, warning messages, and test cases to use the new name while maintaining backward compatibility. Key changes include:

- Adding `--negotiation-restrict` as the primary option name in docs
- Marking `--negotiation-tip` as an alias
- Making warning messages translatable with the new option name
- Adding new tests showing the option works with globs and can be mixed with the old name

The patch has already been reviewed by Matthew Cheetham and carries his Reviewed-by tag. It's a straightforward rename/refactor that maintains all existing functionality while improving clarity for future development of the negotiation features in this series.
