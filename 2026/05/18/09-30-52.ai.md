This is the first patch in Patrick Steinhardt's 18-part series to remove `the_repository` usage from the setup subsystem, part of the ongoing `the_repository` removal effort. The patch focuses on converting static functions in setup.c to use explicit `struct repository *` parameters instead of the global variable.

The changes are mechanical but extensive - 100 insertions and 88 deletions across setup.c. Each static function that previously accessed `the_repository` now takes it as a parameter, with callers updated to pass `the_repository` for now. This is an intermediate step - later patches will propagate the repository parameters up to the callers.

Key conversions include:
- `abspath_part_inside_repo()`
- `setup_original_cwd()`
- `check_repository_format_gently()`
- `setup_git_env_internal()`
- Various template and directory creation functions

The patch maintains all existing behavior while preparing for deeper architectural changes in subsequent patches. It's a foundational change that enables the rest of the series to properly propagate repository contexts through the setup machinery.
