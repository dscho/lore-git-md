This is patch 7/8 in Derrick Stolee's final version of the negotiation control series, adding config support for the new `--negotiation-include` feature. The patch introduces `remote.<name>.negotiationInclude` as a multi-valued config option that provides default values for the command-line `--negotiation-include` option, mirroring how `remote.<name>.negotiationRestrict` works for the restrict option.

The config allows specifying refs or glob patterns whose tips should always be sent as "have" lines during fetch negotiation, ensuring critical refs aren't accidentally dropped from the negotiation process. The implementation is thorough, with proper handling of empty values to reset the list, glob pattern support, and clear precedence over config values when CLI options are provided. 

The patch includes comprehensive documentation updates and three new test cases verifying:
1. Basic config functionality and empty-value reset behavior
2. Glob pattern support in the config
3. Command-line override precedence over config values

Matthew Cheetham has reviewed and approved the implementation, as indicated by the Reviewed-by tag. This patch completes the config integration for the negotiation include feature, building on the earlier negotiator.h interface changes and CLI implementation. The series as a whole addresses inefficient object transfer in monorepos by giving users precise control over which refs participate in negotiation.
