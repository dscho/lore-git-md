This is the final version of a feature series adding remote group support to `git push`, mirroring the existing `git fetch` functionality. The implementation has been through multiple review rounds with maintainer Junio Hamano and appears ready for merging.

The series enables pushing to all remotes in a configured group (defined via `remotes.<name>` in config) with commands like `git push all-remotes`. Key aspects include:

- Each remote is pushed independently via child processes to ensure failure isolation
- Proper handling of per-remote configs like `remote.<name>.push`
- Mirror flag isolation to prevent force-push bleeding between remotes
- Explicit rejection of `--atomic` for group pushes
- Comprehensive test coverage verifying behavior and edge cases

The v6 iteration addresses only minor documentation formatting nits from Kristoffer Haugsbakk's review (fixing backtick usage in man page examples). All architectural decisions were settled in earlier versions, with the implementation following Junio's guidance on process isolation and type safety. The series has seen no substantive objections and appears ready for inclusion.
