This is a refactoring patch from Usman Akinyemi's v6 series adding remote group support to `git push`. The patch moves shared remote group resolution logic from builtin/fetch.c to remote.c so it can be reused by both fetch and push commands.

The change extracts three components that handle remote group configuration parsing:
1. The `remote_group_data` struct that holds group name and result list
2. `get_remote_group()` which parses `remotes.<name>` config entries
3. `add_remote_or_group()` which resolves a name to either group members or a single remote

These utilities are moved to remote.c and exposed via remote.h, following Junio Hamano's suggestion to avoid code duplication. The implementation remains functionally identical - it just changes the linkage from static to shared. This enables the group resolution logic to be used by the upcoming group push functionality while maintaining the existing fetch behavior.

The patch is mechanical and straightforward, with no behavior changes. It's part of a well-reviewed series that appears ready for merging, having addressed all feedback through six iterations. The refactoring properly prepares for the core push group support in the next patch while keeping the changes minimal and focused.
