This is Junio Hamano's regular "What's cooking in git.git" status report, providing updates on the state of various topics in the Git development pipeline as of May 2026. The report organizes topics into three categories: those that have graduated to 'master', new topics being proposed, and topics that are cooking (in progress).

Several notable changes have graduated to 'master', including:
- Improvements to `git backfill` command behavior
- Better handling of cached renames in the ORT merge strategy
- `git checkout -m` now automatically stashes local changes when switching branches
- Fixes for HTTP proxy URL validation and submodule.fetchJobs configuration
- Documentation updates and build system fixes

New topics being proposed include:
- Optimizations for revision traversal using priority queues
- New `--max-count-oldest` option for `git rev-list`
- Improvements to branch pruning with new `--prune-merged` option
- Configuration updates for worktree paths in includeIf conditions
- Various performance optimizations and memory leak fixes

Ongoing work includes:
- Continued refactoring to remove `the_repository` global variable usage
- Improvements to the ODB (object database) abstraction
- Enhancements to the reftable backend
- Rustification efforts and platform compatibility work
- Large-scale changes to the repack machinery and MIDX handling
- The Linux fsmonitor daemon implementation is nearing completion

The report also notes several topics waiting for review responses or rerolls, indicating active discussion points in the community. Junio's meticulous tracking shows Git's development remains highly active, with contributions spanning performance optimizations, new features, documentation improvements, and architectural refactoring.
