This is patch 2/8 in Derrick Stolee's series introducing new negotiation options for fetch/push. The patch renames the existing `--negotiation-tip` option to the more accurately named `--negotiation-restrict`, while keeping the old name as an alias for compatibility.

The change clarifies that this option restricts negotiation to a subset of refs (a "maximum set") rather than implying it's the only set that will be considered. This prepares the codebase for the complementary `--negotiation-include` option (a "minimum set") that will be introduced later in the series.

The patch updates documentation, warning messages, and tests to use the new name while maintaining backward compatibility. It also makes the warning messages translatable by using the `_()` wrapper.
