This is a build system patch that has now reached final approval. The patch fixes a compatibility issue with older versions of Ninja (pre-1.10.0) that fail to properly parse multi-line dependency files when generating config-list.h. The problem was specifically encountered on AlmaLinux 8 which ships with Ninja 1.8.2.

The solution, which has been through three iterations, now uses `tr` to collapse dependencies onto a single line in a portable way that works across all Ninja versions while maintaining compatibility with Make. Phillip Wood, who had raised concerns about portability in earlier versions, has now approved the final implementation.

The patch demonstrates good collaboration between Toon Claes (who implemented and tested the fix), Patrick Steinhardt (who suggested the unconditional approach), and Phillip Wood (who ensured portability). With all technical concerns addressed and positive reviews from build system experts, this patch is ready for merging. The change is low-risk as it only modifies build system behavior without affecting runtime functionality.
