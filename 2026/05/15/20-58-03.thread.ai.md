RFC patch proposing to make "today" resolve to midnight in Git's date parsing, with discussion of edge cases. Original proposal adds `date_today()` function to handle "today" as midnight when no time is specified, fixing current behavior where "today" falls back to current time (causing `git log --since=today` to incorrectly include future commits). Junio C Hamano notes the tradeoff with `--until=today` - while midnight works well for `--since`, it creates ambiguity for `--until` where "until today" would naturally mean "now". Maintainer suggests keeping the midnight definition for `--since` as more practically useful (allowing easy specification of "today's work"), while explicitly documenting the `--until` tradeoff in commit message.
