This is a build system patch that has reached final approval. Phillip Wood gives his sign-off on Toon Claes's v3 patch fixing Ninja 1.8.2 compatibility for config-list.h generation.

The patch addresses a build failure on AlmaLinux 8 (which ships with Ninja 1.8.2) where the depfile parser incorrectly handled multi-line dependencies. The solution unconditionally collapses dependencies into a single line using `tr` instead of sed, making it portable across all sed implementations while maintaining compatibility with both Make and Ninja.

Key technical points:
- Preserves the no-op targets for Make compatibility
- Uses `tr '\n' ' '` instead of sed newline replacement for portability
- Verified working on Ninja 1.8.2 through real-world testing
- No runtime impact - purely a build system change
