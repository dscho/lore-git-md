This is a build system patch that finalizes the Ninja compatibility fix for config-list.h generation with a portable implementation. The v3 patch addresses Phillip Wood's review feedback about non-portable use of `\n` in sed replacement strings by using `tr` to collapse dependencies onto a single line.

The patch maintains the core solution from v2 (unconditionally collapsing dependencies to work around Ninja 1.8.2's multi-line parsing bug) while making the implementation robust across different sed implementations. The changes are minimal - just modifying the dependency generation in generate-configlist.sh to:
1. Print the target first
2. Pipe dependencies through `tr` to collapse them
3. Preserve the no-op targets for Make compatibility

The commit message provides clear reproduction steps showing the failure on AlmaLinux 8 (Ninja 1.8.2) and explains why the solution works. The thread shows consensus from multiple build system experts (Patrick Steinhardt, Phillip Wood, D. Ben Knoble) that this is the right approach, with all technical concerns now addressed. The patch is ready for merging with no runtime impact - it purely affects build system behavior.
