Junio C Hamano has reported UBSan (Undefined Behavior Sanitizer) failures in Git's CI pipeline, uncovered when Johannes Schindelen (Dscho) enabled EXPENSIVE tests. The main issue is a signed integer overflow in `commit.c` (line 1574) where `-2147483648 - 1` exceeds `int` capacity - a classic edge case when dealing with timestamps or other signed quantities near 32-bit limits. A second, unspecified issue was also revealed by the expanded test coverage. Both problems appear on the 'next' branch, meaning they affect code previously considered merge-ready. While these are likely edge cases that don't surface during normal operation, they represent real undefined behavior that needs addressing.
