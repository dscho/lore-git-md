This thread addresses a file descriptor leak in Git's promisor pack fast-path within `connected.c`, which can cause deadlocks in `receive-pack` when used with partial clones. The issue originates from commit 50033772d which introduced the promisor fast-path but failed to properly close the `err_fd` file descriptor before returning, despite documentation in `connected.h` promising this cleanup. This same oversight has previously caused deadlocks in `receive-pack` (fixed in 49ecfa13f and 6cdad1f13) where the async sideband muxer would wait indefinitely for EOF on the leaked descriptor.

The proposed fix adds the missing `close(opt->err_fd)` call in the promisor fast-path exit of `check_connected()`, following the established pattern seen in other exit paths of this function.
