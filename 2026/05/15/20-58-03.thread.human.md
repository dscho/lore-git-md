The thread discusses a change to how Git interprets "today" in date specifications like `git log --since=today`. Currently, "today" falls back to the current time, which can incorrectly show future commits. The proposed patch makes "today" resolve to midnight when no specific time is given, fixing this issue while maintaining existing behavior for expressions like "noon today".

Junio noted this creates a tradeoff for `--until=today` where midnight might feel less intuitive than the current time. However, the practical benefits for `--since=today` (letting users easily see "today's work") outweigh this edge case. The v2 patch expands documentation to clearly explain both behaviors and adds thorough test coverage.
