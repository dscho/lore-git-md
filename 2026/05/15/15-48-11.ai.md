This is the third and final patch in Philippe Blain's documentation series clarifying aspects of Git's raw diff output format. The patch focuses on making the documentation more precise about when mode and hash fields show as all-zeros for unmerged paths.

The change specifies that these fields are only zeroed when the unmerged entry comes from the index - meaning on the left side for `git diff-files` and right side for `git diff-index --cached`. The patch also standardizes the wording around the "work tree out of sync with the index" case.

Like the previous patches in the series, this is a small but meaningful documentation improvement that makes the behavior more accurately described without changing any actual functionality. The commit message clearly explains the motivation and scope of the change. This completes the series' goal of cleaning up and clarifying the diff format documentation, catching several subtle but long-standing inconsistencies.
