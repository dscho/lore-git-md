This is a build system patch that finalizes a fix for Ninja compatibility issues when generating config-list.h dependencies. The v3 iteration addresses a portability concern raised by Phillip Wood regarding the use of `\n` in sed replacement strings, making the solution work across all sed implementations.

The patch solves a specific problem where older Ninja versions (pre-1.10.0) incorrectly parse multi-line dependency files, creating circular dependencies. The solution unconditionally collapses all dependencies onto a single line using `tr`, maintaining compatibility with both Make and all Ninja versions while preserving the no-op targets needed for Make.

The changes are minimal and focused, touching only the generate-configlist.sh script. The patch has undergone thorough review from build system experts (Patrick Steinhardt, Phillip Wood, D. Ben Knoble) and has been tested on the problematic AlmaLinux 8 environment with Ninja 1.8.2. With all technical concerns addressed, this appears ready for merging.
