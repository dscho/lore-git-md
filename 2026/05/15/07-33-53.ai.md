This is a performance optimization patch from René Scharfe, part of his ongoing work to improve memory efficiency in Git's core subsystems. The patch refactors the trailer subsystem's `unfold_value()` function to perform newline-whitespace normalization in-place rather than using a temporary buffer.

The change eliminates an allocation by modifying the input strbuf directly, safely collapsing newlines and adjacent whitespace into single spaces in a single pass. The v2 iteration removes a redundant comparison that was identified in review (the `pos != i` check from v1), though it had no functional impact. The transformation is guaranteed safe since the operation never increases the string length.

The patch demonstrates René's characteristic precision - the function is reduced from 16 lines to 6 while maintaining identical behavior. Jeff King (Peff) previously confirmed the correctness of the non-trivial in-place approach, and Ramsay Jones provided surface-level feedback that was incorporated. With all review comments addressed, this appears ready for integration as a clean internal optimization with no user-visible effects.
