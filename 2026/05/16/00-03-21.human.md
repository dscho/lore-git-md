This is a discussion about the RFC patch proposing to make "today" resolve to midnight in Git's date parsing. Junio Hamano (the Git maintainer) weighs in with nuanced thoughts on the proposal.

Junio acknowledges the appeal of having `--since=today` show commits since midnight, but points out the asymmetry this creates for `--until=today` - should that mean "until now" or "until midnight tonight"? He notes that without context about which direction the date is being used (since vs until), the parser can't make both cases work well simultaneously. 

While recognizing this limitation, Junio ultimately leans toward accepting the midnight interpretation for "today" because:
1) It provides more practical utility for the common `--since` case
2) The `--until` case is less useful anyway (since it would effectively mean "up to now")
3) The midnight definition lets users easily specify "today's work" without manual time calculations

The response suggests the patch is likely to proceed, with perhaps some additional justification in the commit message about why midnight was chosen over other possible interpretations. This maintains the patch's focus on improving a real usability pain point while thoughtfully considering edge cases.
