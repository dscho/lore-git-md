Performance test addition for commit-reach optimization. This is the second patch in v3 of a series optimizing `tips_reachable_from_bases()` in commit-reach.c, addressing a bottleneck in ref-filter operations.

The patch adds three test cases specifically covering the scenario where multiple refs point to the same commit (duplicate tips), which was a key concern raised in earlier reviews. The tests verify:
1. All duplicate tips are correctly reported when reachable
2. None are reported when unreachable
3. Edge case behavior when duplicates are at the minimum generation (testing early termination logic)

These tests validate the object-flag optimization approach from the first patch, which naturally handles duplicate tips through shared commit object flags. The test cases were suggested by Derrick Stolee during v2 review to ensure robustness against the decoration hash collision issue that affected the initial implementation.

The test additions are straightforward and follow the existing pattern in t6600-test-reach.sh, using the `run_all_modes` helper to verify behavior across different commit-graph modes. This completes the test coverage requested during review, complementing the performance improvements with correctness verification.
