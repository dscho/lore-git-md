This is the second patch in a four-part series improving Git's date approximation logic ("approxidate"). The patch focuses on test infrastructure, adding support for date adjustments in the test suite to better verify edge cases in date parsing.

The key change is the addition of a time offset capability to `check_approxidate()`, allowing tests to temporarily adjust the reference date (GIT_TEST_DATE_NOW) for specific test cases. This enables testing date rollover scenarios like month/year boundaries that were previously require manual date changes. The patch demonstrates this with new test cases for "yesterday" behavior across month boundaries.

This test infrastructure change was already accepted in previous iterations of the series (it was patch 1/4 in v3). The implementation looks solid, with careful handling of both time units (hours/days) and test expectations. The new test cases verify the core functionality works as intended while maintaining the existing test structure.

As part of an already-reviewed patch that's now moving forward in the series, this appears ready for inclusion. The test improvements will support the more substantive date parsing fixes in subsequent patches.
