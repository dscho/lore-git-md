This is a discussion about the RFC patch proposing to make "today" resolve to midnight in Git's date parsing. Junio C Hamano weighs in with nuanced thoughts on the behavior.

Junio acknowledges the current inconsistency where "today" falls back to current time, but raises an important edge case: how should "--until=today" behave in the afternoon? He notes that while defining "today" as midnight works well for "--since", it creates ambiguity for "--until" since "until today" would naturally mean "now" rather than midnight. 

The maintainer suggests that while technically impossible to satisfy both cases perfectly (without adding context to approxidate calls), the midnight definition for "--since" provides more practical utility - allowing users to easily specify "today's work" without knowing the current time. He proposes strengthening the justification in the commit message to explicitly discuss this "--until" tradeoff.

1) Validating the core idea of making "today" mean midnight
2) Surfacing an important edge case (--until behavior)
3) Suggesting how to document the design tradeoffs
