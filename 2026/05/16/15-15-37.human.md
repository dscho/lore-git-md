This is the first patch in a four-part series fixing edge cases in Git's date approximation logic ("approxidate"). The patch implements a semantic change where "today" now refers to midnight rather than the current time, addressing a long-standing quirk where "today" was an undocumented alias for "now".

The change makes "--since=today" more useful by showing commits from the current day (since midnight) rather than future commits (when interpreted as "now"). While this changes the behavior of "--until=today" to exclude today's commits, the author argues this better matches the documented meaning of "--until" (show commits older than date) and enables new use case like "@{today}" to reference ref states at day start.

The implementation adds a new `date_today()` function that returns midnight unless a time is explicitly specified (e.g. "noon today" still works). The patch includes documentation updates and test cases to verify the new behavior. This change was discussed in previous iterations of the series and aligns with Junio's preference for making "today" mean midnight.

The patch appears well-constructed with clear motivation, implementation, and test coverage. As the first in a series that has already seen several iterations, it represents a settled design decision rather than an open question.
