Bugfix for UBSan failures in commit message handling and apply patch size verification.

Jeff King (Peff) responds to Junio's report of UBSan failures in Git's CI pipeline with a two-patch fix. The first patch addresses a memory leak in the apply codepath when handling patches that exceed size limits. The second patch, which directly relates to the reported UBSan error, fixes integer overflow in commit message UTF-8 verification when processing very large commit messages (specifically the case where a negative timestamp value approaches INT_MIN).

The fixes are concise and targeted - the commit.c changes restructure the UTF-8 verification to avoid the problematic arithmetic while maintaining the same functionality. This appears to be a robust solution to the edge case that was exposed by the newly enabled EXPENSIVE tests in CI. Given Peff's reputation for thorough fixes and the direct correspondence between the patches and the reported issues, these changes are likely to be quickly merged.
