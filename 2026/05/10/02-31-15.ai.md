This is a platform compatibility patch series from Johannes Schindelin, now merged by Junio C Hamano. The series completes the removal of the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds, addressing GCC 16 compatibility issues.

The v3 iteration had incorporated maintainer feedback by rewording the last 4 patches to clearly indicate they should be squashed during integration. Junio has now applied the series to the Git repository, marking the completion of this technical cleanup effort.

The removal was motivated by both technical necessity (nedmalloc failing to build with GCC 16's new warnings) and practical considerations (Git for Windows having already switched to mimalloc years ago with no performance regression). The series followed a careful dependency order - first disabling usage, then removing build system references, and finally deleting the implementation code.

With this merge, the nedmalloc chapter in Git's history is officially closed. The change maintains existing runtime performance while simplifying the codebase by removing over 5,700 lines of unmaintained allocator code. No technical concerns remained unresolved at the time of merging.
