Build system patch addressing Clang warning suppression on Linux. This is a follow-up to Shardul Natu's initial patch that proposed adding `-Wno-c11-extensions` to `DEVELOPER_CFLAGS` when building with Clang on Linux, to handle false positives from glibc's use of C11 features in system headers.

Junio notes that while this overlaps with another ongoing discussion about glibc header compatibility, the current approach of selectively suppressing warnings may be less disruptive than the alternative proposal to drop `-std=gnu99` entirely. He suggests the warning suppression might need to be applied consistently across both Makefile and meson build systems.

The technical issue stems from Clang's strict interpretation of C11 features in glibc headers when building with developer flags (`-std=gnu99 -pedantic -Werror`), while GCC handles these cases more gracefully. The patch maintains platform specificity by only applying the suppression on Linux systems.

This appears to be a focused, tactical solution to an immediate build problem while broader discussions about glibc compatibility continue in parallel. The maintainer's involvement suggests this may be headed for quick resolution, though coordination with the meson build system remains an open question.
