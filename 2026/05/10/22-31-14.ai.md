Documentation patch finalizing the `--no-follow` option documentation for `git log`.

This v3 patch completes the documentation of Git's long-standing but previously unrecorded `--no-follow` option, incorporating Junio Hamano's feedback from earlier iterations. The changes precisely capture that `--follow` tracks renames for individual files (not directory pathspecs) while maintaining the option's existing behavior.

Key technical clarifications added:
- Explicitly states `--follow` requires exactly one pathspec and only follows file renames (not directory renames)
- Documents that directory pathspecs still use rename-following traversal mode but don't track directory renames
- Makes clear `--no-follow` overrides both command-line and config-based `log.follow`
- Maintains references to original implementation commits (aebbcf5797, 076c98372e, 1e9250b5aa)
