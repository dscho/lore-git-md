Bugfix for git-svn: This is a report of a warning that will become a fatal error in future versions of Getopt::Long. The issue occurs in git-svn.perl where the option 'id|i=s' is specified, which Getopt::Long 2.55+ now flags as a duplicate specification (due to case sensitivity changes). The reporter notes this currently works but will break when Getopt::Long makes the check fatal.

The problem is in the command-line option parsing code of git-svn, specifically around line 352 where the 'id|i=s' option is defined. This needs to be fixed before future Getopt::Long releases turn this warning into an error. The reporter is using Git 2.54.0 on Fedora 43 aarch64 and has helpfully identified both the problematic code location and the upstream Getopt::Long change that triggered this.
