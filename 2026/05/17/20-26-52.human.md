This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's man page formatting. The patch converts the git-grep documentation to the new AsciiDoc synopsis style, following the same mechanical changes demonstrated in the git-bisect conversion from patch 1/5 of this series.

The changes are purely presentational - replacing verse formatting with synopsis blocks, standardizing option references with backticks, and updating cross-references to use consistent markup. The patch touches both the main git-grep.adoc file and its related config documentation, ensuring the style remains consistent across both.

As with the rest of this series, there are no functional changes to the content - this is purely about making the documentation more uniform and easier to maintain. The conversion follows established patterns from previous documentation standardization work, and given Jean-Noël's role as the documentation lead, this change can be expected to align with the project's documentation style guidelines.
