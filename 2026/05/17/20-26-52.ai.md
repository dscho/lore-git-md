This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. The patch converts the git-grep documentation to the new format, following the same mechanical changes demonstrated in the git-bisect conversion from patch 1/5.

The changes are purely presentational:
- Replaces [verse] with [synopsis] in the SYNOPSIS section
- Standardizes quoting of commands/options with backticks
- Updates man page references to use `command`(N) format
- Converts angle-bracket placeholders to italicized versions
- Applies consistent formatting to option descriptions

The patch also updates the related grep.adoc config file to match the new style. As with the rest of this series, there are no content changes - this is strictly about documentation presentation consistency. The conversion follows the established patterns being rolled out across all Git documentation, with Jean-Noël Avila as the primary driver of this standardization effort.
