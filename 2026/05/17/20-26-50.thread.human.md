Jean-Noël Avila continues his systematic conversion of Git's documentation to the new AsciiDoc synopsis style with this third patch in a five-part series. Following the already-converted git-bisect and git-grep man pages, this update transforms the git-am documentation to match the project's standardized format. The changes are purely presentational - reorganizing content into [synopsis] blocks, consistently formatting command options with backticks, and standardizing cross-references - without altering any technical content. 

The patch also updates several related documentation fragments (config files and format-patch notes) to maintain consistency. As with the previous conversions, this work demonstrates careful attention to detail while following the established template. Given the mechanical nature of these changes and Jean-Noël's role as the documentation standardization lead, substantive technical review is neither expected nor necessary, though reviewers may spot minor formatting tweaks. This effort represents another step in the multi-year project to bring uniformity to Git's man pages.
