Git rebase segfault during signing: pack corruption vs NULL-dereference

Thread identity: Bug report for `git rebase --continue` segfault during commit signing, affecting Git 2.54.0 (commit 94f057755b). Originating author Alex Naidenkov provided detailed system specs.

Core problem: Initial analysis pointed to NULL-dereference in `repo_parse_tree_gently()` during merge-ort processing, but Phillip Wood suggests this may be a symptom of underlying pack corruption from parallel `run_auto_maintenance()` during rebase.
