Git rebase segfault during signing: NULL-dereference in merge-ort

Thread identity: Bug report for `git rebase --continue` segfault during commit signing, affecting Git 2.54.0 (commit 94f057755b). Originating author provided detailed system specs.

Core problem: NULL-dereference in `repo_parse_tree_gently()` when merge-ort backend processes a tree object during rebase sequence, potentially triggered by GPG signing interaction. Backtrace shows NULL `item` parameter reaching tree parsing code path.

Technical details:
- Fault occurs in merge-ort.c during rebase operation
- System context: x86_64 Linux (Arch), Rust-enabled build, SHA-1 default hash, OpenSSL 3.6.2
- Specific trigger appears when user enters signing PIN during rebase
