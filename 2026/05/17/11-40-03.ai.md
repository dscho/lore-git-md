This is a response in the ongoing RFC series adding merge commit support to `git history`, specifically addressing feedback on the test infrastructure DSL in patch 4/5.

Johannes Schindelin (Dscho) accepts both of Toon Claes' suggested improvements to the `test-tool historian` subcommand's DSL syntax:

1. Replaces `PATH=BLOB` syntax with `PATH:BLOB` to visually distinguish file specifications from keyword arguments, agreeing this improves clarity while maintaining conciseness.

2. Adopts Toon's more flexible design using `parent=` (zero or more times) instead of separate `from=`/`merge=` keywords, and makes the ref assignment optional via `branch=` or `ref=`. This allows root commits and unrelated histories while reducing cognitive load in test writing - Dscho explicitly prioritizes readability over strict fast-import similarity.

The exchange remains collegial, with Dscho acknowledging the tool's inherent design challenges while welcoming concrete improvements. This resolves the DSL syntax questions raised in Toon's review, leaving Phillip Wood's substantive merge algorithm edge case (silent conflicts when only one parent is rebased) as the remaining open technical issue in the series.
