This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. The patch converts the git-apply documentation to the new format, following the same pattern established in previous patches in this series (git-bisect, git-grep, and git-am).

The changes are purely presentational, converting the git-apply.adoc file and its related config/apply.adoc to use consistent markup:
- Replaces [verse] with [synopsis] in the SYNOPSIS section
- Standardizes quoting of commands, options, and placeholders (using backticks for commands/options, underscores for placeholders)
- Updates cross-references to use the new style
- Maintains conditional includes for config documentation

The patch follows the same mechanical conversion pattern seen in the series' earlier patches, with no functional changes to the documentation content. This continues the systematic documentation standardization work that has been progressing through the Git project, with Jean-Noël Avila as the primary driver of this effort.
