Documentation patch converting the git-am man page to the new AsciiDoc synopsis style, part of Jean-Noël Avila's ongoing documentation standardization effort. This is patch 3/5 in the series, following the same mechanical conversion pattern as the earlier git-bisect and git-grep patches.

The changes are purely presentational, reorganizing the git-am documentation to match the project's new standard format without altering technical content. Key transformations include replacing [verse] blocks with [synopsis], consistently backtick-quoting command options and placeholders, and standardizing man page references. The patch also updates related documentation files (config/am.adoc, format-patch-caveats.adoc, and format-patch-end-of-commit-message.adoc) to maintain consistency.

This continues the established pattern from previous documentation conversion patches, with Jean-Noël Avila as the primary author and maintainer of this effort.
