This is a documentation patch converting the git-bisect man page to the new synopsis style, part of Jean-Noël Avila's ongoing effort to standardize Git's documentation format. The patch makes purely presentational changes to Documentation/git-bisect.adoc without altering technical content.

The changes include:
- Replacing [verse] with [synopsis] in the SYNOPSIS section
- Removing single quotes around command names and using backticks consistently
- Formatting OPTIONS entries with backtick-quoted terms
- Adding synopsis-style formatting to listing blocks
- Updating man page references to use `command`(N) format
- Making minor wording tweaks for consistency (e.g. "HEAD" to `HEAD`)

The patch also includes related updates to Documentation/asciidoc.conf.in to support the new formatting in listing blocks. As with the rest of this series, this is a mechanical conversion following established patterns, with Jean-Noël Avila as the primary driver of the documentation standardization effort. Given the nature, this change is unlikely to require deep technical review.
