This is a documentation patch series, part of the ongoing effort to convert Git's man pages to a consistent synopsis style using AsciiDoc markup. The series is authored by Jean-Noël Avila, who has been leading this documentation standardization work.

The series converts five command manuals to the new format:
- git-bisect
- git-grep
- git-am
- git-apply
- git-imap-send

The author notes this batch served as a test case for AI-assisted conversion, though the details of that process aren't specified in the cover letter. The changes are purely presentational - reorganizing and reformatting the documentation without altering the technical content. Each patch touches both the main command documentation and related config files to maintain consistency.

The series builds on commit 59ff4886a5 (the current master at time of sending) and consists of five focused patches, each handling one command's documentation conversion. Given Jean-Noël's role as the documentation style conversion lead and the mechanical nature of these changes, this series appears to be a straightforward continuation of established work rather than introducing new controversy or requiring deep technical review.
