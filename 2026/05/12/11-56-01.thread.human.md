This thread is about a set of small, mechanical performance patches from René
Scharfe that replace `strbuf_addf()` calls with the more specialized
`strbuf_add_uint()` in several Git builtins. This particular email (patch 2/4)
targets `builtin/cat-file.c`, where two formatting calls printing object sizes as
unsigned integers are swapped -- a change the benchmarks show yields a 4-7%
speedup on full repository traversals. The patch is narrow (two lines changed),
the rationale is straightforward (avoid variable-argument parsing overhead), and
the numbers are solid. As with the rest of the series, this is a clean,
uncontroversial refactoring; the only question is whether anyone spots an edge
case where an object size could meaningfully exceed the `uintmax_t` range,
which seems unlikely in practice. No maintainer action is required beyond a
routine review and pickup.
