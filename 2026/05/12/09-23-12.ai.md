This is a "What's cooking" report from Junio C Hamano, the Git maintainer. It is the periodic status summary of every in-flight topic across the integration branches (maint, master, next, seen). It is not a patch or a discussion thread -- it is an administrative snapshot of the project's overall state as of May 12, 2026.

The report covers roughly 60 topics in various states: graduated, newly arrived, cooking, or discarded. A large batch of topics moved from next to master in the first "for quite a while" graduation since 2.54-rc2, indicating the project has been in a quiet cycle and is now accelerating again.

The most notable changes in this report include:

The `jc/neuter-sideband-fixup` topic graduated to master. This is a multi-year effort to sanitize escape sequences received over sideband (e.g., from remote Git servers during push/fetch) that could be used for terminal injection attacks. Junio explicitly notes that he graduated the stricter form of the patch -- which masks control characters by default -- ahead of the looser "allow everything for now" final step. This is a deliberate strategy to give the stricter form real-world testing before potentially dialing it back at the Git 3.0 boundary (the `jc/neuter-sideband-post-3.0` topic, which is on hold for that purpose).

Several large topics are approaching readiness. Taylor Blau's `tb/pseudo-merge-bugfixes` (9 commits fixing bugs in pseudo-merge bitmap code) and `tb/incremental-midx-part-3.3` (16 commits introducing incremental MIDX repacking without requiring all-into-one repacks) are both queued for next. Patrick Steinhardt's `ps/odb-in-memory` (18 commits adding a new in-memory object database source for tentative objects) is waiting on its base topic `jt/odb-transaction-write` to be leakfixed.

`ps/maintenance-daemonize-lockfix` fixes a real bug: `git maintenance --detach` was not using the lockfile, allowing concurrent processes. This is a new topic.

The `hn/branch-prune-merged` series (5 commits adding `--prune-merged` to `git branch`) has been around for several iterations but still needs a reroll following Junio's comments.

On the "recently graduated and potentially fragile" side, `jc/neuter-sideband-fixup` is explicitly described as an experiment. The `js/maintenance-fix-deadlock-on-win10` topic avoids removing mmap'd files on Windows 10, which is a platform-specific workaround rather than a general fix.

A handful of topics were discarded for inactivity. None appear to have been controversial -- they were simply stale.

Overall this is a routine but slightly busier-than-normal cooking report. The graduation batch and the number of topics in next suggest the next release cycle (post-2.54) is starting to pick up steam.
