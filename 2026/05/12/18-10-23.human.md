This is a documentation patch, the fourth and final piece of a four-patch
bugfix series from Michael Montalbo. The series as a whole fixes a
real bug where `-U` and `--inter-hunk-context` silently accepted
negative values that produced garbage output. Patches 1 and 2 applied
the root-cause fix (switching both options to unsigned types), patch 3
added a defensive `BUG()` in the xdiff layer, and this patch is a
cleanup.

The patch itself is minimal: it adds a one-line parenthetical comment
to the `PARSE_OPT_NONEG` flag definition in `parse-options.h`,
explaining that "cannot be negated" means it rejects the `--no-<option>`
form. This arose from confusion in the v1 submission, where the author
initially thought `PARSE_OPT_NONEG` might affect negative numeric
values (it does not -- it only blocks boolean-style `--no-` prefixes).

The commit message is clear about the motivation and the change is
small enough to trust at a glance. This is a trivial documentation
improvement that clarifies existing behavior without changing it.
Together with the range-diff showing the revisions from v1, the patch
is a tidy capstone to a well-executed series. Ready to merge.
