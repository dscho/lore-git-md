This is a low-level utility patch from René Scharfe, adding a
`strbuf_add_uint()` function to avoid the overhead of `strbuf_addf()` when
formatting unsigned integers. It is the first of four patches in a series.

The patch is small and clean -- two files changed, one new function. The
implementation fills a stack buffer from the right using repeated modular
division, then appends the result to the buffer. The buffer sizing comment
in the commit message is characteristically precise.

The patch follows a well-established pattern in Git's strbuf API: provide
type-specific "add" functions (`strbuf_addstr`, `strbuf_addbuf`,
`strbuf_addch`) so that simple formatting does not need to go through the
full `vsnprintf` machinery. This is classic René Scharfe territory -- a
small, correct, uncontroversial cleanup.

For the busy reader: this is a "yes, that is fine" patch. It is not fixing
a bug or enabling any new feature, but it is a reasonable performance and
simplicity improvement. It will merge without drama. Whether the follow-up
patches (which presumably use the new function) are interesting depends on
what they do.
