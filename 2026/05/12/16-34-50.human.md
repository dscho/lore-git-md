This is a maintainer review of patch 1/3 in the approxidate bugfix series.

Junio is generally on board with the approach but is asking for a cleaner
implementation of the shell logic in the test helper. His specific request is
to use an explicit `if test -n "$4"` guard (consistent with Git's coding style,
which prefers `test` over `[ ]` and puts `then`/`else` on their own lines)
rather than the current approach of computing an offset that becomes zero when
the fourth argument is absent. He also points out a minor shell scripting
detail: once a variable is exported, it stays exported -- there is no need to
re-export it on every assignment.

This is a lightweight, procedural review. Junio is not questioning the design
or the feature itself -- he is asking for the helper to be written the way Git
prefers its shell code to look. The patch is otherwise clearly fine in his
view.

For a busy reader: this is a trivial formatting request, and the series
remains in good shape. The patch should need just a v3 re-roll with the shell
style fixed. No fundamental issues.
