Core problem or goal: Replace four existing uses of `strbuf_addf(sb, "%"PRIuMAX, (uintmax_t)value)` with a specialized function `strbuf_add_uint()` that formats an unsigned integer directly via a simple division loop, avoiding the overhead of the full printf machinery. This is a performance optimization for high-volume output commands.

Current status: v1 submitted and fully reviewed. The series is ready for maintainer pickup. No further iteration is planned. The follow-up email from Rene was purely conversational -- it confirmed marginal performance numbers (1.2 ms improvement for the padded case, within noise of 1.0 ms) and established that the author independently reached the same design conclusions as the reviewer.

Key technical details:
- Files touched: `strbuf.h`, `strbuf.c`, `builtin/cat-file.c`, `builtin/ls-files.c`, `builtin/ls-tree.c`
- New function: `void strbuf_add_uint(struct strbuf *sb, unsigned int value)` added to strbuf interface. Formats the integer as a decimal string using a loop of `x / 10` and `x % 10` operations, writing digits to a small on-stack temporary buffer in reverse then appending to the strbuf with `memcpy()`. Located in `strbuf.c` with declaration in `strbuf.h`.
- Call sites converted (patches 2-4): `cat-file.c`, `ls-files.c`, `ls-tree.c` -- all replace `strbuf_addf(... PRIuMAX ...)` with `strbuf_add_uint()`.
- Overall delta: 38 insertions, 14 deletions across 5 files.
- Benchmark (from patch 2): `cat-file --batch-all-objects --batch-check='%(objectsize)'` went from 751.7 ms to 720.4 ms, a 4% speedup. For the padded case in patch 3, the improvement is ~1.2 ms and within noise (1.0 ms), so marginal.
- No test changes needed (behavior is identical).
- No new symbols, config keys, CLI options, or on-disk format changes.
- Patch 3 (ls-tree.c conversion) additionally handles field-width padding by formatting the number into the strbuf, then using `strbuf_insert()` to shift content right if padding is required. This involves a `memmove()` that reduces the performance gain for that specific caller.
