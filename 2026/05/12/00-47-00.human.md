This is a bugfix patch, patch 5 of 9 in Taylor Blau’s pseudo-merge bitmap fix series, which Junio has already signaled as nearly ready to merge.

The patch fixes three bugs in how Git handles commits that belong to more than one pseudo-merge group. When a commit is in multiple groups, its lookup-table entry uses a special “extended” table, and three independent mistakes made that path fail silently. On the write side, the offset calculation for the extended table underestimated entry size, so it wrote pointers that landed in the middle of ordinary lookup entries. On the read side, the code interpreted a raw bitmap offset as a larger struct and clobbered the field it needed. And a third check used the wrong comparison, potentially swallowing actual errors from corrupt bitmaps. With all three fixed, the previously-marked-as-expected-failure test for overlapping pseudo-merge groups now passes.

The patch itself is small (4 net lines changed across three files) and mechanically correct—each fix is clearly isolated and explained. The real meat was in earlier patches that established the test infrastructure and fixed the simpler bugs; this is clearing one of the remaining known-failing tests. The series is cooking in its final iteration and this patch looks ready to go with it.
