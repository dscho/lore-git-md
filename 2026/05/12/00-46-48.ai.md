Classification: Test infrastructure / bugfix prep. This is the first patch of a nine-patch series from Taylor Blau fixing pseudo-merge bitmap bugs, and it introduces a new test helper rather than fixing anything itself.

This patch adds a `test-tool bitmap write` subcommand that gives tests fine-grained control over which commits receive bitmaps in a given pack. The author explains this infrastructure is needed because the subsequent patches will expose and fix a variety of bugs in the pseudo-merge bitmap code path, and those tests require very precise selection of which commits get bitmaps. The existing test suite never exercises `apply_pseudo_merges_for_commit()` at all, as was noted in an earlier fix (f16eb1c091, March 2026).

The new subcommand works by taking a pack basename and reading commit OIDs from stdin. It looks up the pack, builds a packing_data structure from all its objects, then selectively assigns bitmaps only to the commits supplied on stdin. It also respects `bitmapPseudoMerge.*` config, so pseudo-merge bitmaps will be created alongside the regular commit bitmaps when that configuration is present. The mechanics are standard: `bitmap_writer_init`, `bitmap_writer_build_type_index`, `bitmap_writer_push_commit` for each input commit, `select_pseudo_merges`, `bitmap_writer_build`, and `bitmap_writer_finish`.

The patch also adds one test that exercises the helper end-to-end: initializes a small repository with 64 commits, repacks, then uses the new subcommand to write a bitmap for only the HEAD commit, and verifies that exactly that commit shows up in the bitmap listing and that `--use-bitmap-index` gives the same object count as a non-bitmap traversal.

The code is straightforward and well-structured. The test-hygiene point raised by Elijah Newren in v2 (ordering `test_when_finished` above `git init`) has been addressed. This is entirely uncontroversial infrastructure -- it is test scaffolding that enables the actual fixes in the rest of the series to be tested rigorously. The cover letter notes that Junio C Hamano has already described the series as "so close to the finish line," so nothing here is expected to hold up the series.
