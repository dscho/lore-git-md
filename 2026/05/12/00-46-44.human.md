This is the v3 reroll of a nine-patch bugfix series for pseudo-merge bitmaps from Taylor Blau.

The series addresses multiple bugs that Jeff King noticed when he realized the pseudo-merge code path was never covered by the test suite -- a red flag that turned out to be well-founded, as the investigation uncovered several compounding issues that together made the feature effectively broken during fill-in traversal.

The technical fixes are substantial. The lookup table for pseudo-merge commits was being sorted by object ID instead of bit position, completely defeating the binary search. The binary search itself had its low/high bounds swapped. Extended lookup paths had three cumulative errors: incorrect entry-size calculation at write time, misinterpretation of extended table entries at read time, and a silently swallowed error check. In the group selection path, commits were not being parsed before inspecting their dates, so every candidate got date 0 and landed in the stable bucket unconditionally. The config validator accepted a sample rate of zero, which produces a division by zero once the date parsing is fixed and unstable code paths are exercised. There is also a fix for a regex memory leak when pseudo-merge patterns are redefined in config.

The v2 reviews by Elijah Newren and others caught two test-hygiene issues -- a duplicate `git init` and a pipeline ordering problem -- which this reroll fixes. Junio had already characterized the series as "so close to the finish line" and was simply waiting for this final update.

The series looks well-assembled. The test infrastructure (a new `test-tool bitmap write` subcommand giving precise control over which commits get bitmaps) is clean and establishes good foundations. The commit messages are clear about what each bug was and how it was missed. At seven lines changed in production code across three files, it is a compact set of fixes for a surprisingly large functional gap. Nothing here should be controversial, and this v3 appears to be what Junio was waiting for to merge.
