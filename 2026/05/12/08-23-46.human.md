**Infrastructure patch (part of the `--prune-merged` series).**

This is the second patch in Harald Nordgren's v7 series for branch pruning. It is pure plumbing -- no user-visible change on its own. The patch adds two optional parameters to the internal functions `delete_branches()` and `check_branch_commit()`: `warn_only` (switches from `error()` to `warning()` and skips the multi-line advisory about `-D`) and `n_not_merged` (a counter so a caller can report a summary count instead of per-branch messages). All existing call sites pass 0/NULL and are unaffected.

The motivation is clear from context: the later patch in the series that introduces `--prune-merged` will call `delete_branches()` in bulk mode, where printing a four-line hint for every refused branch would be noisy and unhelpful. This patch sets up the escape hatch. The implementation is mechanical and straightforward -- four changed hunks in one file, no new tests (none needed, since it is dead code until the caller arrives).

This is the kind of preparatory refactoring that a well-structured patch series does. It looks correct and uncontroversial. The series still needs eyes on the later patches where the actual design complexity lives, but this piece is ready.
