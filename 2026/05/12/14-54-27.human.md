This is the cover letter for a three-patch re-roll (v2) fixing edge cases in Git's date approximation logic (approxidate). The author, Tuomas Ahola, previously sent a two-patch version that Jeff King reviewed; this round splits those changes differently and adds a preparatory test patch.

The series targets inconsistencies with how "special" time-of-day keywords (noon, tea, now, yesterday) interact with explicit day specifications. As the cover letter notes, this is inspired by a 19-year-old email from Linus Torvalds, and it aims to make expressions like "last Friday noon" or "yesterday tea" produce the correct result regardless of what time of day the query is made. The test infrastructure change adds a way to fix the test's idea of "now" so that these edge cases can be reliably tested.

The tone of the cover letter is wry ("the aproxidate system is an endless source of absurdities") but the content is serious -- this is a narrow, well-scoped fix to a long-standing pain point. The three-patch split is sensible: tests first, then the fix for date-based specials, then the deferred-adjustment logic that makes time-of-day specials work correctly. Given that Jeff King already reviewed the v1 approach and this iteration addresses his feedback, this series looks ready for a close read and likely eventual acceptance.
