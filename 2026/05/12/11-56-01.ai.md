This is a performance patch that replaces two `strbuf_addf()` calls in `builtin/cat-file.c` with the more specialized `strbuf_add_uint()` when printing the `objectsize` and `objectsize:disk` atoms in `--batch-check` mode. The change is mechanical: both formatting calls already treated the size as an unsigned integer (`%"PRIuMAX`, `uintmax_t`), so the substitution is safe and direct -- two lines changed, one function call replaced per line.

René provides attached benchmarks showing about 4-7% speedup on a full `--batch-all-objects` traversal (720 ms vs 752 ms for `objectsize`, 378 ms vs 405 ms for `objectsize:disk`). These are real but modest gains, consistent with avoiding the variable-argument parsing overhead of `strbuf_addf()` for a simple integer print.
