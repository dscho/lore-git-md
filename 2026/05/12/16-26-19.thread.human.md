This is a short (3-line) bug-fix patch from Jeff King for `http-walker.c`. When Git fetches from a dumb HTTP server whose URL has no path component (e.g. `http://example.com`), the code that parses absolute alternate object store paths crashes because `strchr()` returns NULL instead of pointing past the hostname. The fix is a one-character change from `strchr` to `strchrnul`, which safely returns a pointer to the end of the string. Jeff King's security analysis concludes the worst outcome is a failed clone.

Junio C Hamano replied, self-deprecatingly noting that he introduced the bug in 2005 when he wrote the dumb HTTP walker code. He immediately greenlit the fix ("Absolutely"), so the patch is ready for integration. No further review or changes are needed.
