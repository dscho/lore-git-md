Classification: Part of Taylor Blau's nine-patch bugfix series for pseudo-merge bitmaps. This is the eighth patch, and it is a documentation-only fix.

This patch corrects two example configuration snippets in `gitpacking(7)` that show a `sampleRate` of 100. As patch 7 in this same series established, `sampleRate` is now validated to be in the range `(0, 1]`, so a value of 100 is invalid. These examples appear to date from an earlier version of the feature when `sampleRate` was expressed as a percentage (0--100). The fix simply replaces `100` with `1` (meaning 100% sampling) in both example blocks.

This is a straightforward, one-line-per-example, mechanical documentation fix. It was noticed by Elijah Newren in earlier review rounds. There is nothing controversial or notable here. The patch is clearly correct and the series is otherwise ready to merge, so this is just tying up a loose end in the documentation that could have been introduced when the configuration semantics changed during development.
