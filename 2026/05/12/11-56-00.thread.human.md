This thread introduces a new `strbuf_add_uint()` function from René Scharfe. It converts an unsigned integer directly to decimal digits and appends them to a `strbuf`, avoiding the overhead of `strbuf_addf()` and its `vsnprintf(3)` call.

The patch is small (18 lines across `strbuf.c` and `strbuf.h`), the implementation follows project conventions, and the function accepts `uintmax_t` for maximum flexibility. The reasoning is that integer formatting is common enough that avoiding printf's overhead is worthwhile, and Git already has similar specialized functions like `strbuf_addstr()`.

This is part of a larger series adding several `strbuf_add_*` helper functions, with the overall direction of replacing `strbuf_addf()` usage where simpler alternatives suffice. René's patches are routine, clean improvements -- unlikely to be controversial and easy to review. No discussion or objections have been raised so far.
