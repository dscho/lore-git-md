This is a patch to git-gui (Git's graphical interface) that proposes a cleaner handling of the GIT_DIR and GIT_WORK_TREE environment variables. The author, Aina Boot, identifies that the current implementation has scattered and unguarded environment variable manipulation, which could lead to issues.

The patch introduces five new procedures to systematically manage these environment variables:
1. `set_worktree_env` - Safely sets GIT_WORK_TREE only when there's an actual worktree
2. `unset_worktree_env` - Safely unsets GIT_WORK_TREE
3. `clear_git_env` - Clears both variables when entering submodule context
4. `capture_git_env` - Saves current values for later restoration
5. `restore_git_env` - Restores previously saved values

The changes aim to make the code more robust by preventing cases where GIT_WORK_TREE might be incorrectly set when there is no worktree, and by centralizing the environment variable handling logic. The approach looks well-considered, focusing on making the intentions explicit while reducing repetitive error handling code. This appears to be a quality-of-life improvement for git-gui's internal implementation.
