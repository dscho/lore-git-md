This thread discusses how git-gui should handle the GIT_DIR and GIT_WORK_TREE environment variables. The original patch proposed adding save/restore functionality for these variables, but Shroom Moo is now arguing this adds unnecessary complexity. They contend the current direct set/unset operations are already safe and properly encapsulated, and that the proposed functions would introduce more conceptual overhead than benefit. The discussion appears to be converging toward keeping the simpler approach, unless new concerns about the current implementation's safety emerge.
