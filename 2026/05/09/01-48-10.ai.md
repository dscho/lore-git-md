Bugfix patch addressing network address handling in the Git daemon. The patch fixes three related issues in `daemon.c`:

1. IPv6 support was broken in `lookup_hostname()` - it was incorrectly casting IPv6 addresses to `sockaddr_in` and using `AF_INET` with `inet_ntop()`. The fix properly handles both IPv4 and IPv6 address families.

2. `ip2str()` was passing the wrong buffer size to `inet_ntop()` for IPv6 addresses, potentially truncating output. The function now uses the correct buffer size and drops its now-unused length parameter.

3. The connection logging in `execute()` could pass NULL for the port number, causing undefined behavior. It now uses a fallback "?" when the port is unset.

The changes are straightforward and address clear bugs in the network handling code. The patch touches only `daemon.c` with 19 lines added and 12 removed, focused specifically on the address handling issues. The commit message clearly explains each problem and the corresponding fix.
