This is a bugfix patch addressing network address handling issues in Git's built-in daemon (`daemon.c`). The patch fixes three related problems:

1. IPv6 support was broken - the code assumed IPv4 addresses by casting to `sockaddr_in` unconditionally, which fails on IPv6-only hosts. The fix properly handles both address families.

2. IPv6 address string conversion was silently truncating long addresses due to passing the wrong buffer size to `inet_ntop()`. The patch uses the correct constant buffer size.

3. A potential NULL dereference when logging connections if the REMOTE_PORT environment variable was unset, now using a fallback "?" string.

The changes are straightforward and focused - adding proper IPv6 support where it was missing, fixing buffer size issues, and hardening against NULL values. The patch touches only `daemon.c` with 19 lines added and 12 removed. While not a security issue per se, these fixes make the daemon more robust, especially in IPv6 environments. The commit message clearly explains each problem and solution.
