This is the main feature patch in a series introducing external command execution for Git notes. Patch 7/9 implements the core functionality that allows Git to fetch notes content from a long-running external process rather than just from refs.

The patch adds a new protocol where Git sends commit OIDs to an external helper and receives either "missing" or the note content. Key components include:

- New config options: `notes.externalCommand`, `notes.externalCommandTimeoutMs`
- New command-line option: `--external-notes`
- Timeout handling infrastructure with nanosecond precision
- Process management with graceful termination
- I/O operations with deadlines
- Windows compatibility considerations
- Integration with existing notes display logic

The motivation is to solve TOCTOU race conditions in large distributed repos where notes updates may not propagate quickly enough. The implementation spans multiple files (notes.c, notes-external.c, revision.c) and adds 500+ lines of new code with careful attention to edge cases.

The patch appears well-structured with thorough error handling and platform-specific considerations. It builds on the preparatory infrastructure from earlier patches in the series (timeout handling, I/O utilities). The main functionality is gated behind config options that can only be set in protected config for security.

This represents a significant expansion of Git's notes capabilities, enabling integration with external note storage systems while maintaining security constraints. The implementation looks carefully considered with attention to edge cases and graceful degradation.
