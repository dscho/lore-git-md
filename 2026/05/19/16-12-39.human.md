This is the second patch in Taylor Blau's performance optimization series for the pack-bitmap-write subsystem. The patch builds on the previous optimization by further reducing redundant work in bitmap generation.

The key change moves the bitmap check for already-set tree bits earlier in the process, avoiding unnecessary stack frame setup for trees that don't need processing. This yields measurable improvements: a 3.4% reduction in elapsed time (582.4s to 562.8s) and instruction count (2.4B to 2.3B) when generating bitmaps for a large test repository.

The patch modifies `fill_bitmap_tree()` in pack-bitmap-write.c to check bitmap positions before recursing into tree processing. This is a focused optimization that maintains the same behavior while eliminating redundant work - a typical pattern in Taylor's performance-focused contributions to the bitmap subsystem.

As with the first patch, this change is low-risk since it only affects internal bitmap generation behavior without changing user-facing functionality.
