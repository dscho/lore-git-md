This is the sixth patch in a 9-part series introducing external command support for Git notes. It adds test coverage for existing notes display behavior before the main feature is implemented in subsequent patches.

The patch adds four new test cases in `t/t3301-notes.sh` that verify how notes are currently displayed in log output:

1. Tests that raw notes formatting (`%N`) shows the note content without "Notes" headers
2. Confirms `--no-notes` suppresses note display as expected
3. Verifies that explicit notes refs (`--notes=other`) override the default notes display
4. Checks that notes content participates in `--grep` matching

These tests establish baseline behavior that the external notes feature will need to maintain compatibility with. The tests are straightforward and well-scoped, using standard test helpers like `test_grep` and `test_must_be_empty`. 

This is preparatory work for the main feature - the actual external notes implementation will need to ensure it integrates with these existing display mechanisms correctly. The patch follows the series' pattern of careful, incremental changes with thorough test coverage.
