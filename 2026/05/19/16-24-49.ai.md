This is patch 2/8 in Derrick Stolee's series to improve fetch/push negotiation in monorepos. The patch renames the existing `--negotiation-tip` option to the clearer `--negotiation-restrict` while keeping the old name as an alias for compatibility.

The change reflects that this option restricts negotiation to a subset of refs rather than just "tipping" it. The patch updates all documentation, warning messages, and tests to use the new name while maintaining backward compatibility. Key changes include:

- Adding `--negotiation-restrict` as the preferred name in docs
- Marking `--negotiation-tip` as an alias
- Making warning messages translatable and using the new name
- Adding tests showing the options can be mixed
- Updating protocol v2 tests to expect the new error message format

The patch is straightforward and mechanical changes, with Matthew Cheetham's Reviewed-by tag indicating it's been thoroughly reviewed. This rename paves the way for the complementary `--negotiation-include` option to be added in later patches.
