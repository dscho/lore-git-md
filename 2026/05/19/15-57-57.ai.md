This is patch 7/16 in Taylor Blau's incremental MIDX repacking series, which refactors how Git tracks the object database (ODB) source during repacking operations. The patch moves the ODB source tracking from directly accessing `repo->objects->sources` to storing it in the `existing_packs` struct.

The change serves two purposes:
1. Immediate need: The upcoming incremental MIDX repacking machinery will need to know which source is being used to read existing MIDX/chain files.
2. Future-proofing: If `git repack` is later extended to work with other object sources, this field will provide the authoritative source value.

The patch makes no functional changes - it still uses the first source from the list, just accessed through the new field. The implementation is straightforward, adding the source field to `existing_packs` and updating the two places in `cmd_repack()` that previously accessed the source directly.

This appears to be a preparatory refactoring for the larger MIDX repacking functionality coming in later patches. The change is mechanical and low-risk, with no substantive review feedback needed or provided so far in the thread.
