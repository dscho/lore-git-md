This is part 5/16 of Taylor Blau's incremental MIDX repacking series (v4), introducing a new `--no-write-chain-file` option for MIDX operations. The patch enables callers to write new MIDX layers without immediately updating the chain file, allowing for atomic assembly of multi-layer MIDX structures.

The change is motivated by the upcoming incremental repacking strategy, which needs to write multiple layers before atomically updating the chain. The new flag makes the MIDX layer checksum available to callers while leaving the chain file untouched. The implementation includes:
- New `MIDX_WRITE_NO_CHAIN` flag
- Documentation updates for both `write` and `compact` subcommands
- Lockfile handling refinements
- Comprehensive tests verifying the new behavior

The patch follows the series' pattern of careful, well-tested changes to the MIDX infrastructure. It's a clean addition that maintains backward compatibility while enabling the more sophisticated repacking strategy to come in later patches. The implementation looks solid, with thorough test coverage and clear documentation.
