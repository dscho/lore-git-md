This is patch 7/16 in Taylor Blau's incremental MIDX repacking series, which aims to improve Git's handling of large repositories through smarter repacking strategies. The patch is a refactoring step that moves the ODB (object database) source tracking into the `existing_packs` struct rather than accessing it directly from the repository's objects.

The change is primarily preparatory work for two future needs:
1. The upcoming incremental MIDX repacking code will need to know which source is being used to read existing MIDX/chain files
2. Potential future support for repacking from alternative object sources

The patch itself makes no functional changes - it just reorganizes where the source information is stored. The implementation looks straightforward, storing the source during pack collection and then using that stored value in the repack command. This is typical of Taylor's careful, incremental approach to architectural changes.

As part of the larger series that has already addressed substantive review feedback, this patch appears ready to move forward. The series as a whole represents significant scalability improvements for large repositories.
