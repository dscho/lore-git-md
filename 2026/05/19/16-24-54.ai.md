This is patch 7/8 in Derrick Stolee's v6 series introducing negotiation control options for fetch/push. The patch adds config support for the `--negotiation-include` feature introduced in earlier patches.

The patch implements `remote.<name>.negotiationInclude` as a multi-valued config option that provides default values for `--negotiation-include` when not specified on the command line. This mirrors the existing `remote.<name>.negotiationRestrict` config added in patch 4/8. Key aspects:

- Config values can be exact refs or glob patterns, same as CLI
- Empty value resets the list (useful for ignoring system/global configs)
- Config is additive with normal negotiation - included refs are sent unconditionally on top of heuristically selected commits
- CLI `--negotiation-include` overrides the config values
- Includes comprehensive tests covering:
  - Basic config usage
  - Glob pattern matching
  - CLI override behavior
  - Empty-value reset functionality

The implementation follows the same pattern as the restrict config, with matching documentation and test coverage. This completes the config integration for the include feature, complementing the earlier restrict config work.
