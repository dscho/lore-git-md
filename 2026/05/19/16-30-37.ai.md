This is a documentation patch completing the 9-part series introducing external command support for Git notes. Patch 8/9 adds comprehensive documentation for the new functionality, covering:

1. Four new config options in `notes.adoc`:
   - `notes.externalCommand`: The helper command to invoke, with detailed protocol specification
   - `notes.externalCommandName`: Display name for external notes in output
   - `notes.externalCommandTimeoutMs`: Response timeout in milliseconds
   - `notes.externalCommandForGrep`: Whether to include external notes in grep matching

2. Command-line option documentation in multiple man pages:
   - `--external-notes`/`--no-external-notes` flags for `git-format-patch`, `git-range-diff`, and general pretty-formatting
   - Clear explanation of how these interact with existing `--notes` options

3. Bash completion updates to include the new flags

The documentation emphasizes security constraints (all config options are protected-config only) and carefully specifies the protocol between Git and the helper. It also notes performance implications when enabling external notes for grep operations. The patch maintains consistency with existing notes documentation while cleanly integrating the new functionality.

This completes the user-facing documentation for the feature, leaving only patch 9/9 (test coverage for the external notes functionality) remaining in the series. The documentation appears thorough and well-integrated with Git's existing man page structure.
