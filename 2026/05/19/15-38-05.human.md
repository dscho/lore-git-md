This is the 5/8 patch in Christian Couder's v3 series adding URL-based auto-configuration for promisor remotes. The patch introduces the core `promisor.acceptFromServerUrl` config option that will allow clients to automatically configure promisor remotes based on URL patterns.

The key technical additions in this patch are:
- A new `struct allowed_url` to store parsed URL patterns and optional remote name prefixes
- Validation functions to check URL patterns and remote name syntax
- Infrastructure to load and store the config values
- Initial test coverage for invalid config cases

The implementation carefully handles security considerations like:
- Strict validation of remote names and URL patterns
- Warning messages for invalid configurations
- Memory management for parsed patterns
- Initial test case verifying rejection of invalid remote names

This is a foundational patch that sets up the infrastructure for the actual URL matching functionality that will be added in subsequent patches. The code follows Git's established patterns for config handling and includes appropriate test coverage.

The patch has already gone through multiple rounds of review and addresses all previous feedback, making it technically ready for merging as part of the complete series.
