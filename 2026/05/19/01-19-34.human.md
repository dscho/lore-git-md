This is the second patch in Jeff King's (Peff) three-part series for cleaning up the quote.[ch] files. The patch removes the unused `sq_dequote_to_argv()` function, which became obsolete after a 2021 change to use `sq_dequote_step()` instead.

Peff explains the rationale for removal: the function represented an awkward middle ground between the low-level `sq_dequote_step()` (for performance-sensitive cases) and the higher-level `sq_dequote_to_strvec()` (for simpler usage). The function had problematic memory management semantics where callers had to manually free the argv array but not its elements.

The change is straightforward - removing the function and its documentation - and reduces the codebase by 14 lines. This continues the series' pattern of precise, well-justified cleanups from a trusted contributor. Given the function has been unused for over five years and the explanation is clear, this patch is unlikely to generate discussion.
