This is the third patch in a series adding external command support for Git notes. It introduces a new `sleep_nanosec()` function in the wrapper subsystem, which will be used by the timeout mechanism for the external notes command.

The implementation provides nanosecond-precision sleeping with platform-specific handling:
- On Windows, uses `nanosleep()` with proper EINTR handling and chunking for large durations
- On other platforms, falls back to millisecond precision via `sleep_millisec()` with appropriate rounding

The function signature matches POSIX `nanosleep()` conventions, returning 0 on success and -1 on error (though the Windows implementation currently always returns 0). This is a preparatory change for the timeout functionality that will be used in patch 4/9's `finish_command_with_timeout()` API.

The patch appears technically sound with careful attention to edge cases (interrupt handling, large durations) and platform compatibility. While standalone, its purpose becomes clear in context of the series' goal to support timeouts for external notes commands. The implementation is consistent with Git's existing timeout patterns in other subsystems.
