This is a preparatory patch (4/8) in Christian Couder's v3 series adding URL-based auto-configuration for promisor remotes. The patch introduces a new `local_name` field to `struct promisor_info` to handle cases where the locally stored remote name differs from the server-advertised name.

The change enables future commits in the series to auto-generate remote names (with a `promisor-auto-` prefix) while preserving the original advertised names. A new helper function `promisor_info_internal_name()` is added to abstract the name selection logic, which is then used in two key functions that interact with the local repository configuration.

The patch is a straightforward refactoring that maintains the existing functionality while paving the way for the auto-configuration feature. It has already been reviewed and approved as part of the complete series, which is now technically ready for merging. The changes are focused and well-contained, touching only `promisor-remote.c` with clear documentation updates.
