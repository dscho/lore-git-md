This is a refactoring patch in a series adding external command support for Git notes. It's patch 2/9 in the initial submission.

The change converts an `int` parameter to `bool` in several notes-related functions where the parameter was being used as a boolean flag. The affected functions are `format_display_notes()` and `format_note()`, which handle displaying notes content. The patch updates both the function declarations and all call sites to use the more semantically correct `bool` type.

The changes are mechanical and straightforward:
- Updates the parameter type in notes.h
- Modifies the implementation in notes.c
- Adjusts callers in log-tree.c and revision.c
- Updates related documentation comments

This appears to be preparatory work for the larger feature of external notes commands, ensuring the codebase uses proper types before adding new functionality. The patch is small (7 lines changed) and focused, with no behavior changes - just type safety improvements.
