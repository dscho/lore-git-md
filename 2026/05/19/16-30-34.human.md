This is patch 5/9 in a series adding external command support for Git notes. The patch introduces timeout and deadline handling for read operations, building infrastructure needed for the notes feature.

The changes add new variants of read functions (`xread_timeout`, `xread_deadline`, and corresponding `read_in_full` versions) that allow callers to specify either a per-read timeout in milliseconds or an absolute deadline in nanoseconds. The implementation uses `poll()` to wait for the file descriptor to become readable before attempting the actual read, with proper handling of EINTR and other edge cases.

Key technical points:
- Maintains backward compatibility by keeping the original non-timeout versions
- Adds thorough error handling for invalid timeouts
- Uses nanosecond`getnanotime()` for deadline calculations
- Includes new helper functions in `wrapper.h` to support callback-based reading
- Touches multiple core I/O functions (`xread`, `read_in_full`, `strbuf_getwholeline_fd`)

The patch appears well-structured with clear documentation of the new functions.
