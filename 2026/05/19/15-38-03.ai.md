This is a refactoring patch from Christian Couder's URL-based promisor remote configuration series (v3). It introduces a new helper function `url_normalize_pattern()` to handle URL patterns containing glob characters ('*') in the host portion.

The patch exports a variant of the existing `url_normalize()` function that specifically allows glob patterns by setting `allow_globs=true` in the internal `url_normalize_1()` call. This is needed for the promisor remote URL pattern matching feature in subsequent commits.

The new helper maintains the same interface as `url_normalize()` but adds documentation clarifying its special handling of glob characters. The implementation is straightforward - just a thin wrapper that passes the glob-allowing flag to the underlying normalization function.

This change is part of the larger effort to enable secure, pattern-based configuration of promisor remotes via the `promisor.acceptFromServerUrl` config option. The series has already gone through multiple rounds of review and is now technically complete, with this patch representing one of the final refinements before merging.
