This is patch 12/16 in Taylor Blau's incremental MIDX repacking series, which refactors the `--write-midx` option handling in preparation for adding incremental MIDX support.

The patch converts the `--write-midx` flag from a simple boolean to an `OPT_CALLBACK` that can handle multiple modes. It introduces an enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states, and updates all boolean checks to use the new enum. The actual behavior remains unchanged at this point - passing `-m` still triggers the default MIDX writing mode.

Key changes include:
1. Adding a new callback function `option_parse_write_midx()` to handle the option parsing
2. Creating a dispatcher function `repack_write_midx()` that will eventually select between different MIDX-writing implementations
3. Updating all call sites that previously checked the boolean flag to use the new enum values

This is a mechanical refactoring that lays groundwork for the actual incremental MIDX functionality to be added in subsequent patches. The changes are straightforward and maintain existing behavior while making the code more extensible. The patch follows the series' pattern of careful, incremental changes with comprehensive test coverage.
