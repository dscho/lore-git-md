This is a documentation patch in Siddh Raman Pant's series adding external command support to Git notes. Patch 8/9 focuses on documenting the new configuration options and command-line flags introduced earlier in the series.

The patch adds comprehensive documentation for four new config options in notes.adoc:
- `notes.externalCommand` - The helper command to invoke for fetching notes
- `notes.externalCommandName` - Header name for external notes
- `notes.externalCommandTimeoutMs` - Response timeout in milliseconds
- `notes.externalCommandForGrep` - Whether to include external notes in grep matching

It also documents the new `--external-notes`/`--no-external-notes` flags across multiple man pages (format-patch, range-diff, pretty-options) and updates shell completion to include the new options. The documentation clearly explains the protocol between Git and the external command, security restrictions (only works in protected config), and interaction with existing notes flags.

The patch appears thorough and consistent with the implementation shown in previous patches. It maintains Git's documentation style while clearly explaining the new functionality. This completes the user-facing documentation for the external notes feature, leaving just one patch remaining in the series.
