This is patch 9/16 in Taylor Blau's incremental MIDX repacking series, which aims to improve Git's repacking strategy for large repositories by maintaining incrementally growing and shrinking MIDX chains.

The patch is a refactoring that extracts common MIDX command preparation logic into a new `repack_prepare_midx_command()` helper function. This function handles the boilerplate of setting up a `git multi-pack-index` command (setting git_cmd, pushing the subcommand, and handling progress/bitmap flags), while allowing callers to add subcommand-specific arguments like `--stdin-packs`.

The change is purely mechanical - no behavior is altered. This prepares for future patches that will need to construct similar MIDX commands for both `write` and `compact` subcommands. The patch follows the series' pattern of careful, incremental refactoring with comprehensive test coverage.

As part of an established series that has already addressed substantive feedback in earlier iterations, this patch appears straightforward and low-risk. It continues the architectural work to make MIDX repacking more maintainable and flexible.
