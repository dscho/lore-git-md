This is the third patch in a series adding external command support for Git notes. It introduces a new `sleep_nanosec()` function in the wrapper subsystem, which will be used by the timeout handling for the external notes process.

The patch provides nanosecond-precision sleep functionality with platform-specific implementations: using `nanosleep()` on Unix-like systems and falling back to millisecond granularity on Windows (where `nanosleep()` isn't available). The Windows version handles large durations by chunking them into `INT_MAX` millisecond intervals. Both implementations properly handle EINTR interruptions.

This is a preparatory change for the main feature, building infrastructure needed for precise timeout checking when communicating with the external notes helper. The implementation looks thorough, with attention to edge cases and platform differences. The patch follows Git's coding style and includes the necessary header updates.
