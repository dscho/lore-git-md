This is a refactoring patch from Jeff King (Peff) that cleans up the interface for connecting to remote services in Git. The patch addresses some long-standing confusion around the "name" parameter in git_connect(), which is actually meant to specify the type of service being connected to (like upload-pack or receive-pack) rather than the program name.

The key changes are:
1. Renaming the vague "name" parameter to the more precise "service"
2. Converting from a string parameter to an enum type for better type safety
3. Maintaining backwards compatibility by still using the well-known string names when needed for protocol communication

The patch touches several files across the codebase to update all callers of the affected functions. Peff notes this is a pure cleanup with no behavior changes, originating from earlier discussions about the confusing interface. The changes make the code more self-documenting and help catch errors at compile time rather than runtime.

This is a typical Peff patch - small, focused, and improving code clarity in a non-disruptive way. The changes are mechanical but meaningful, and the commit message provides excellent historical context about why the cleanup is valuable.
