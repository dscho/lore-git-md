This is patch 13/16 in Taylor Blau's incremental MIDX repacking series, focusing on a memory leak fix in the packfile revindex handling. The patch addresses a long-standing issue where in-memory revindexes (used when on-disk .rev files are unavailable) were never freed.

The change is straightforward: it adds a `FREE_AND_NULL(p->revindex)` call to `close_pack_revindex()` to properly clean up the in-memory revindex. The leak was discovered while working on MIDX bitmap functionality where packs without on-disk revindex files would generate in-memory revindexes that persisted indefinitely.

This appears to be a genuine bug fix rather than new functionality - the commit message notes this code path predates Git's modern leak-checking infrastructure. The change is minimal (just 2 lines added) and well-contained to the packfile subsystem.
