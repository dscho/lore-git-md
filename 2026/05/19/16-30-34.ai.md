This is patch 5/9 in a series adding external command support for Git notes. The patch introduces timeout and deadline functionality to Git's low-level read operations, building infrastructure needed for the notes feature.

The changes add:
- New `xread_timeout()` and `xread_deadline()` functions that extend the existing xread() with timeout capabilities
- Corresponding `read_in_full_timeout()` and `read_in_full_deadline()` variants
- A new `wait_for_fd()` helper that uses poll() to wait for file descriptor readiness with millisecond precision
- Timeout variants of `strbuf_getwholeline_fd()`
- Callback infrastructure to support different timeout strategies

The implementation handles edge cases like:
- Signal interruptions (EINTR)
- Non-blocking I/O (EAGAIN/EWOULDBLOCK)
- Invalid file descriptors (EBADF)
- I/O errors (EIO)
- Timeout expiration (ETIMEDOUT)

The timeout functionality will be used by subsequent patches to implement the external notes command protocol, ensuring Git doesn't hang if the external process becomes unresponsive. The changes maintain backward compatibility by keeping the original non-timeout versions and adding new functions rather than modifying existing ones.

This is a well-structured plumbing change that follows Git's established patterns for I/O handling while adding the necessary timeout support. The patch includes thorough error handling and preserves the non-blocking behavior of the original functions when timeout is zero. The changes are focused on the wrapper and strbuf subsystems, with clear documentation of the new APIs.
