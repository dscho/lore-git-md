This is the 7th patch in Christian Couder's v3 series adding URL-based auto-configuration for promisor remotes, building on previous work to enhance Git's promisor remote functionality. The series is now technically complete and ready for merging.

The patch implements automatic remote configuration when a server advertises an unknown promisor remote whose URL matches a `promisor.acceptFromServerUrl` pattern. Key features include:

- New helpers to sanitize URLs into valid remote names (prefixed with `promisor-auto-`) and handle name collisions with numeric suffixes
- Auto-creation of remote config sections with URL, promisor flag, and original advertised name stored in `remote.<name>.advertisedAs`
- Integration with the existing URL matching logic to trigger auto-configuration
- Comprehensive documentation updates explaining the new behavior and security implications
- Extensive test coverage of various auto-configuration scenarios (new remotes, named remotes, collisions, reuse cases)

The implementation is clean and thorough, with careful attention to security considerations. The patch completes the URL-based auto-configuration feature alongside the previously approved LOP (Large Object Promisors) series, representing significant progress in promisor remote functionality. All technical review feedback has been addressed, and the series is now ready for merging.
