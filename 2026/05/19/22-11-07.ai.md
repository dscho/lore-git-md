This is a status update on Justin Tobler's ODB transaction interface rework series, part of the larger ODB abstraction effort led by Patrick Steinhardt. The 7-patch series refactors Git's object writing interface to make it more pluggable and explicit, with changes including:

- Making `write_object_stream()` pluggable for different backends
- Generalizing packfile writes to use the odb_write_stream interface
- Optimizing object writes by checking sizes upfront to avoid seek operations
- Cleaning up transaction-related flags and callbacks
- Splitting the odb_transaction struct into a separate header

The series has been through multiple iterations and has now addressed a memory leak identified by Jeff King (Peff) in review. Justin confirms this version is ready for integration into the 'next' branch. This work is foundational for Patrick Steinhardt's in-memory ODB backend effort (ps/odb-in-memory) that builds on these changes. The changes touch core object writing paths but maintain backwards compatibility while enabling future backend implementations.
