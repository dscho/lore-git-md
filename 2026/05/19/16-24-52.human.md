This is patch 5/8 in Derrick Stolee's series to improve fetch/push negotiation in monorepos. The patch introduces a new `have_sent()` interface for negotiators, which allows the fetch machinery to inform negotiators when commits have already been sent as "have" lines outside the negotiator's control.

The key technical addition is a callback that lets negotiators track which commits have been sent, so they can avoid sending redundant "have" lines or commits reachable from them. The implementation is straightforward - it marks these commits as common in both the default and skipping negotiators (the noop negotiator ignores it, as expected).

This is a foundational change that enables the `--negotiation-include` feature coming in patch 6/8. The patch is well-contained, with clean implementations across all three negotiator types, and carries Matthew Cheetham's Reviewed-by tag. As part of a mature series that has gone through multiple iterations, this patch appears ready for merging.
