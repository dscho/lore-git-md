This is a bugfix patch from Jeff King (Peff) addressing an edge case in Git's commit-graph handling. The issue occurs when lazy-loading tree objects from commit-graphs interacts poorly with `git clone --dissociate`, causing checkout failures after the graph file is closed. Peff's solution adds a fallback path that reads the commit object directly from disk when graph-based lookup fails, parsing just enough to find the tree OID.
