This is the final patch in Taylor Blau's performance optimization series targeting the pack-bitmap-write subsystem. The series focuses on speeding up bitmap generation for large repositories, with this particular patch addressing inefficiencies in how pseudo-merges are handled.

The key improvement in this patch is restructuring the bitmap generation process to build pseudo-merge bitmaps *after* regular bitmaps, rather than mixing them together. The current approach treats pseudo-merges like regular commits in the maximal commit selection algorithm, which performs poorly since pseudo-merges don't represent real commits. 

The patch shows dramatic improvements - reducing the pseudo-merge generation time from 575s to 328s (a 43% reduction) while maintaining the same query coverage. The changes are focused on pack-bitmap-write.c internals, keeping the on-disk format unchanged.

The implementation:
1. Excludes pseudo-merges from initial bitmap generation
2. Adds a separate pass to build pseudo-merge bitmaps after regular ones
3. Reuses existing pseudo-merge bitmaps when possible
4. Maintains all existing functionality while being more efficient

This completes the series' goal of significantly improving bitmap generation performance, particularly for large repositories.
