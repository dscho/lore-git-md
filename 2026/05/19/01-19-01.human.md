This is the first patch in Jeff King's (Peff) refactoring series cleaning up quote.[ch]. It's a straightforward header file organization change that moves a `struct strvec` forward declaration to the top of quote.h where forward declarations typically live, rather than keeping it inline near the function declaration that uses it.

The change is purely mechanical - no behavior is altered. Peff notes in the commit message that while inline declarations can have explanatory value, they're also more likely to become stale if other uses are added later. This follows his typical pattern of small, precise cleanups that improve code maintainability without introducing new complexity.

Given Peff's reputation for careful cleanups and the uncontroversial nature of this change (just moving a declaration), this patch is likely to be merged with little discussion. The series as a whole removes unused code and simplifies the quoting implementation, with this first patch being the most minor of the three.
