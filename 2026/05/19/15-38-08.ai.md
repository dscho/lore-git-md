This is a documentation patch that improves the `promisor.acceptFromServer` config entry in the promisor.adoc man page. It's the final patch (8/8) in Christian Couder's v3 series adding URL-based auto-configuration for promisor remotes.

The patch addresses several documentation issues:
- Clarifies that `acceptFromServer` doesn't create new remotes (that's handled by the new `acceptFromServerUrl` option)
- Reformats the text from a dense paragraph into clear bullet points
- Makes the default option ("none") more visible
- Fixes a minor error where "client" was used instead of "server"
- Explicitly links to the new `acceptFromServerUrl` option
- Improves overall readability while maintaining all technical details

The changes are purely presentational - no behavior is modified. The patch follows the series' theme of improving promisor remote documentation while maintaining security clarity. Since this is the final patch in a technically complete series that has already been approved, it's likely to be merged as-is.
