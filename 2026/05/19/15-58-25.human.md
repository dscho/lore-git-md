This is the final patch in Taylor Blau's 16-part series on MIDX incremental repacking, which implements a more scalable repacking strategy for large repositories. The patch removes the previous requirement that `--write-midx=incremental` must be used with `--geometric`, allowing it to operate in an append-only mode when used alone.

Without `--geometric`, the command simply adds a new MIDX layer containing the freshly written packs while preserving all existing layers unchanged. This provides a simpler alternative to the geometric compaction strategy when users want to maintain a growing chain of MIDX layers without automatic merging.

The implementation introduces a new `repack_make_midx_append_plan()` function that builds a straightforward append-only plan, while keeping the existing compaction logic for when `--geometric` is active. The patch updates documentation to explain both modes and replaces the test that enforced the old restriction with one verifying the new append-only behavior.

This completes the series after addressing all prior feedback, with only minor terminology and cleanup nits remaining from earlier versions. The implementation appears solid with comprehensive test coverage, and the flexibility to use incremental MIDX repacking without geometric compaction should make the feature more widely usable.
