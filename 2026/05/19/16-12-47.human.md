This is the fifth patch in Taylor Blau's performance optimization series for the pack-bitmap-write subsystem. It introduces an object position cache to speed up bitmap generation in large repositories.

The patch adds a direct-mapped cache that stores mappings from object IDs to their bit positions, avoiding repeated expensive lookups. The cache is sized dynamically based on repository size (between 1K and 2M entries) and shows significant performance improvements - a 9.4% reduction in runtime (from 324.8s to 294.1s) in the test repository with ~57M objects. The cache achieves a high hit rate (1.024B hits vs 59.957M misses) while adding only 80MB of memory overhead.

This continues the series' pattern of focused, well-measured optimizations to the bitmap generation path. The implementation is clean with proper bounds checking and cache invalidation. As with previous patches, this targets internal behavior rather than user-facing functionality, keeping the risk low while delivering measurable gains. The patch includes detailed performance metrics and cache statistics to validate the approach.
