This is patch 8/16 in Taylor Blau's incremental MIDX repacking series, which implements improved repacking strategies for large repositories. The patch is a straightforward refactoring that renames and exposes a previously internal function.

The change renames `midx_contains_pack_1()` to the more descriptive `midx_layer_contains_pack()` and makes it publicly available via midx.h. The key difference from the existing `midx_contains_pack()` is that this new function checks only a single MIDX layer rather than recursing through the entire chain. This will be used in a subsequent patch to specifically check whether a pack belongs to the tip MIDX layer.

The implementation remains unchanged - it still performs a binary search on the pack names array to determine if the given pack is present in the MIDX layer. The patch includes the necessary header file update to expose the function and updates the single call site where the old internal name was used.

This is a mechanical preparation step for upcoming functionality in the series, with no behavior changes. The patch follows the series' pattern of careful, incremental changes to the MIDX infrastructure to support the new repacking strategies.
