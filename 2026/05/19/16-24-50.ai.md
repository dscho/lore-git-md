This is patch 3/8 in Derrick Stolee's series to improve fetch/push efficiency in monorepos by adding negotiation controls. The patch performs a mechanical rename of internal variables and functions from `negotiation_tips` to `negotiation_restrict_tips` to better reflect the renamed CLI option (`--negotiation-restrict` replacing `--negotiation-tip`).

The changes are straightforward and consistent across the transport layer (fetch-pack.c, transport.c) and builtin/fetch.c, updating:
- Variable names in structs and function parameters
- String list storing CLI inputs
- Function names like `add_negotiation_tips` -> `add_negotiation_restrict_tips`
- Documentation comments

This is purely a naming change with no behavior modifications, keeping the series moving toward its goal of providing both restrict and include negotiation controls. The patch carries Matthew Cheetham's Reviewed-by and is part of the final iteration of this well-reviewed series.
