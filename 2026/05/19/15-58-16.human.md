This is a memory leak fix in Taylor Blau's incremental MIDX repacking series (now at v4, patch 13/16). The patch addresses a long-standing oversight where Git would generate in-memory reverse indexes for packs without on-disk .rev files but never free that memory.

The change is straightforward - it adds a `FREE_AND_NULL()` call in `close_pack_revindex()` to clean up the in-memory revindex. The leak was discovered while working on MIDX bitmap functionality that needs to handle packs without on-disk revindexes. The fix is mechanical but important for correctness, especially as the series introduces new test coverage that would catch such leaks.

This appears to be a preparatory patch for upcoming MIDX bitmap work in the series. The change is uncontroversial and follows the pattern of other packfile cleanup functions. Given the series' thorough review history and this patch's narrow scope, it seems likely to be accepted as-is.
