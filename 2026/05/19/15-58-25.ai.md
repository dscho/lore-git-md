This is the final patch (16/16) in Taylor Blau's incremental MIDX repacking series, which relaxes the requirement that `--write-midx=incremental` must be used with `--geometric`. The patch enables standalone incremental MIDX repacking in an append-only mode, where new layers are added without compaction.

Key changes:
1. Removes the `--geometric` requirement check in `builtin/repack.c`
2. Introduces `repack_make_midx_append_plan()` to handle append-only layer creation
3. Updates documentation to clarify the two modes (append-only vs geometric compaction)
4. Replaces the test that enforced the old restriction with new tests for append-only behavior

The append-only mode creates a new MIDX layer containing freshly written packs and copies all existing layers unchanged, while the geometric mode (when enabled) performs compaction according to the configured split factor. The implementation maintains the series' careful attention to atomic updates and verification.

This completes the incremental MIDX repacking functionality, providing both flexible layer growth and automatic compaction strategies. The patch series as a whole represents a significant scalability improvement for large repositories, particularly when combined with the geometric repacking strategy.
