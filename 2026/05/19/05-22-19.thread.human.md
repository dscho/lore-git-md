This thread introduces a refactoring from Jeff King (Peff) to improve type safety in Git's connection handling. The patch replaces ambiguous string parameters in `git_connect()` with an explicit `enum git_connect_service` (UPLOAD_PACK, RECEIVE_PACK, UPLOAD_ARCHIVE), making the code more self-documenting and catching invalid service types at compile time. 

Peff clarifies this is a behavior-preserving change that originated from earlier protocol version discussions. The changes are mechanical but widespread, updating callers across the codebase to use the new enum while maintaining backward compatibility through a `connect_service_cmd()` helper for protocol communication. Variable names are also updated from "name" to "service" for clarity. As a pure refactoring from a trusted contributor with deep protocol knowledge, this change is likely to be merged without controversy.
