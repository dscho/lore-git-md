This is a review comment from Junio C Hamano on the third patch in Siddh Raman Pant's series adding external command support for Git notes. The patch introduces a `sleep_nanosec()` function for platform-specific nanosecond-precision sleeping, which will be used for timeout handling in the external notes feature.

Junio notes that the implementation itself looks technically sound, but points out that the commit message should better explain why nanosecond precision is needed for this feature. The current message lacks motivation that would help reviewers understand how this fits into the larger series. This is a substantive review pointing to a real documentation gap, not just surface-level nitpicking.

The patch provides careful platform-specific implementations (using `nanosleep()` where available and falling back to millisecond precision on Windows) with proper handling of edge cases like EINTR interrupts and large durations. While the Windows implementation currently always returns 0 (a minor deviation from POSIX behavior), the overall approach appears solid and consistent with Git's existing timeout patterns.

This feedback suggests the author should expand the commit message to connect this preparatory change to the series' goal of implementing timeouts for external notes commands. The technical content of the patch itself seems acceptable pending that documentation improvement.
