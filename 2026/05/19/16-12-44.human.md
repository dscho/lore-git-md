Performance optimization patch from Taylor Blau, part of his series improving bitmap generation speed. This is patch 4/8, focusing on code cleanup in the pack-bitmap-write.c internals.

The change consolidates the success path for `find_object_pos()` by using a shared return pattern for both the packlist and MIDX cases. This prepares for future bookkeeping around object position lookups.

The patch is a straightforward refactoring with no behavior change - it's part of the groundwork for the more significant optimizations coming later in the series (bitmap sorting and pseudo-merge restructuring).
