2. The second patch removes sq_dequote_to_argv(), a function that hasn't been used since 2019 when its last caller was converted to use strvec.

3. The third patch simplifies the internal dequoting implementation by removing some redundant helper functions that were only used in one place.

The series is a typical Peff cleanup - small, focused, and clearly motivated by removing dead code. The changes touch only 35 lines across two files and don't affect any user-visible behavior. This is the kind of low-risk maintenance work that often gets picked up quickly by the maintainer.
