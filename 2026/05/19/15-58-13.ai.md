This is patch 12/16 in Taylor Blau's incremental MIDX repacking series, which refactors the `--write-midx` option handling in preparation for adding incremental MIDX support.

The patch converts the `--write-midx` flag from a simple boolean (`OPT_BOOL`) to a more flexible callback-based option (`OPT_CALLBACK`) that can accept optional mode arguments. It introduces an enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states to distinguish between different MIDX-writing modes, with the latter preserving the existing behavior when no argument is provided.

Key changes include:
1. New `option_parse_write_midx()` callback to handle the option parsing
2. Conversion of all boolean `write_midx` checks to use the new enum
3. Extraction of `repack_write_midx()` as a dispatcher function that will select between different MIDX-writing implementations (currently just the default one)
4. Addition of the mode field to `struct repack_write_midx_opts`

The patch is a mechanical refactoring that maintains all existing functionality while setting up the infrastructure for the incremental MIDX modes to be added in subsequent patches. It follows the pattern seen earlier in the series of breaking down changes into small, focused steps.

This continues the series' pattern of careful, incremental changes to the repack machinery, with each patch building on the last to implement the full incremental MIDX functionality. The changes are well-contained and maintain backward compatibility while preparing for new features.
