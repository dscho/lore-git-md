This is the main feature patch in a series introducing external command support for Git notes. It enables Git to fetch notes content from a long-running external process rather than just from refs, addressing TOCTOU race conditions in large distributed repositories where notes updates may not be immediately visible to all users.

The implementation adds:
- New config options (`notes.externalCommand`, `notes.externalCommandTimeoutMs`)
- Command-line flags (`--external-notes`, `--no-external-notes`)
- A simple protocol where Git sends commit OIDs to the helper and receives either "missing" or note content
- Comprehensive timeout handling infrastructure
- Integration across multiple commands (`log`, `name-rev`, `range-diff`)

The patch appears carefully implemented with attention to edge cases (signals, non-blocking I/O) and maintains backwards compatibility with existing notes behavior. It builds on preparatory infrastructure from earlier patches in the series (timeout handling, I/O helpers). The commit message clearly explains the motivation (TOCTOU races in large repos) and solution approach.

This represents a significant expansion of Git's notes capabilities, allowing integration with external note storage systems while maintaining security (the command can only be configured in protected config). The implementation spans multiple subsystems and includes thorough test coverage (500+ lines across the series).
