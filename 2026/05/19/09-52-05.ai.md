This is the first patch in Patrick Steinhardt's 18-part series completing the `the_repository` removal effort in Git's setup subsystem. The patch mechanically converts all static functions in setup.c to take an explicit `struct repository *` parameter instead of relying on the global `the_repository` variable.

The changes are purely mechanical at this stage - each static function gains a repository parameter, and callers pass `the_repository` explicitly. The actual migration of callers to pass their own repository pointers will come in subsequent patches. The diff shows 188 lines changed (100 insertions, 88 deletions) across setup.c, touching functions like `abspath_part_inside_repo()`, `setup_original_cwd()`, and various git directory setup helpers.

This patch follows the established three-step conversion pattern for `the_repository` removal: first make functions static with repository parameters, then update parameter passing, and finally modify callers. The changes are straightforward and maintain identical behavior while preparing for proper repository parameterization. As the foundational patch in the series, it sets up the structural changes needed for the more substantive conversions to follow.
