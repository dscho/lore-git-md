This is a technical patch in Christian Couder's URL-based promisor remote configuration series (v3). It introduces a new helper function `url_normalize_pattern()` to handle URL glob patterns that may contain wildcards ('*') in the host portion.

The patch exports this function from urlmatch.c for use in the promisor remote auto-configuration feature, where it will be needed to normalize and parse URL patterns from user configuration. The function is similar to the existing `url_normalize()` but allows glob characters by passing `allow_globs=true` to the internal normalization routine.

The implementation is straightforward - just a thin wrapper around the existing normalization logic - and comes with clear documentation in the header file explaining its purpose and behavior. This is part of the larger effort to securely handle promisor remote configuration via URL patterns, which has already gone through multiple rounds of review and is now technically complete.
