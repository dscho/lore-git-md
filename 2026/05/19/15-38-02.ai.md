This is a small refactoring patch in Christian Couder's URL-based promisor remote configuration series. It changes the `allow_globs` parameter in `urlmatch.c` from a `char` to a `bool` type to better reflect its boolean usage, and updates the two call sites to use `true`/`false` rather than `1`/`0`.

The change is straightforward and mechanical - part of the ongoing effort to improve type safety in Git's codebase. Since this is part of a larger series that has already received thorough review (including from Patrick Steinhardt and Junio C Hamano), this particular patch doesn't introduce new functionality but rather cleans up the implementation details of the URL matching code that supports the promisor remote auto-configuration feature.

The patch touches the urlmatch subsystem, which is being used here to handle the URL pattern matching for promisor remote configuration. The change is consistent with Git's coding guidelines and follows the pattern of using proper boolean types where appropriate.
