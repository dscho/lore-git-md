This is patch 7/18 in Patrick Steinhardt's series to remove `the_repository` usage from Git's setup subsystem. The patch converts `verify_non_filename()` to take an explicit `struct repository *` parameter instead of relying on the global variable.

The change follows the established three-step pattern seen throughout this series: updating the function signature, modifying callers to pass the repository explicitly, and then adjusting the implementation. The patch affects several builtin commands (`checkout`, `grep`, `reset`) and revision handling code, with all callers now passing `the_repository` directly.

The implementation change itself is straightforward - the function now checks the passed-in repository's worktree/gitdir status rather than using the global. This maintains identical behavior while making the repository dependency explicit. The patch continues the series' mechanical but important work of eliminating global state from Git's core.
