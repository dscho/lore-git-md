This is patch 5/16 in Taylor Blau's incremental MIDX repacking series, introducing a `--no-write-chain-file` option for incremental MIDX writes. The patch enables callers to write new MIDX layers without immediately updating the chain file, allowing for atomic assembly of multiple layers before finalizing the chain.

The key addition is a new `MIDX_WRITE_NO_CHAIN` flag that, when combined with `--incremental`, writes the MIDX layer to disk but leaves the chain file untouched, printing the new layer's checksum to stdout. This is particularly useful for the repacking strategy being implemented in this series, which needs to assemble multiple layers atomically.

The patch includes thorough documentation updates, command-line validation to ensure `--no-write-chain-file` is only used with `--incremental`, and new test cases verifying both the happy path and error conditions. The implementation carefully handles lockfile management to avoid holding unnecessary locks when chain file updates are disabled.
