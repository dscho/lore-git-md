This thread introduces a new feature allowing Git to fetch notes content from an external command rather than just from refs, addressing TOCTOU race conditions in large distributed repositories. The series is currently at version 1 (9 parts), with Siddh Raman Pant as the author.

The first six patches laid the groundwork with timeout infrastructure (nanosecond-precision sleeping, process termination with timeouts, and I/O operations) and basic notes behavior tests. The main feature arrives in patch 7/9, implementing a protocol where Git sends commit OIDs to an external helper and receives either note content or "missing". The implementation includes new config options (`notes.externalCommand`, `notes.externalCommandTimeoutMs`), a `--external-notes` CLI flag, and careful attention to security (gated behind protected config), edge cases, and Windows compatibility.

While the technical implementation appears thorough, the series still lacks stated motivation in the cover letter and has yet to receive any reviews. Open questions remain about performance overhead, whether the timeout API should be more broadly exposed, and Windows-specific behavior of the new `sleep_nanosec()` function. The remaining two patches in the series will presumably complete the feature. This represents a significant expansion of Git's notes capabilities, but its adoption will depend on community feedback about the approach and security implications.
