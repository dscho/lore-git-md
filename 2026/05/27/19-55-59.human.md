This is the fourth patch in Taylor Blau's performance optimization series for the pack-bitmap-write subsystem, building on his pseudo-merge bitmap work. The series aims to speed up bitmap generation for large repositories, with this particular patch focusing on code consolidation.

The patch refactors `find_object_pos()` to share the success return path between two cases (packlist and MIDX lookups) by introducing a local `pos` variable. This is a preparatory change for adding more bookkeeping around object-position lookups in future optimizations. The change is mechanical and doesn't affect behavior - it just makes the code slightly more maintainable by eliminating duplicate success-path logic.

As with previous patches in the series, this continues the pattern of careful, incremental optimizations to the bitmap generation code. The change is well-contained (only touching pack-bitmap-write.c) and maintains the series' focus on measurable performance improvements for large repositories. Jeff King has reviewed earlier versions of this series and confirmed the technical approach.
