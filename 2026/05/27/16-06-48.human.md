This is Junio Hamano's regular "What's cooking in git.git" status report, covering development activity from May 2026. The report lists topics that have graduated to 'master' and 'next', new topics under consideration, and ongoing work in various states of review.

Several significant changes have been merged:
- Fetch negotiation options were reworked to allow requiring certain refs to be sent and restricting negotiation scope
- Performance improvements for lazy clones in `git cherry` and `git grep` through bulk prefetching
- ODB transaction interface improvements for explicit object writes
- MIDX repacking optimizations including incremental strategies
- Continued progress on removing `the_repository` global variable usage
- Linux fsmonitor daemon implementation completed after extensive review

New topics under consideration include:
- Dotfile hiding in path completion by default
- Sparse index optimizations for `git restore`
- Commit reachability optimizations
- Configuration file locking with retries
- Branch pruning for merged branches
- Worktree-aware conditional config includes

The report also notes several documentation updates, test coverage improvements, and ongoing large-scale efforts like the ODB abstraction and Rustification. As always, Junio provides clear indicators of each topic's status and readiness for merging.
