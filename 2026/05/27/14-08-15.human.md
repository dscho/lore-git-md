This is a technical plumbing patch (part 3/8) in Christian Couder's v4 series enabling URL-based auto-configuration for promisor remotes. The patch introduces a new helper function `url_normalize_pattern()` that extends Git's URL normalization to handle glob patterns (`*`) in hostnames, which will be used for matching promisor remote patterns.

The implementation is straightforward - it exposes an existing internal function (`url_normalize_1()`) with the `allow_globs` parameter set to true. The accompanying documentation clearly explains the purpose and behavior, noting that while `*` is allowed in host portions for pattern matching, it's also technically valid in paths per RFC 3986.

This change is part of the larger effort to support secure, pattern-based promisor remote configuration, and follows the project's typical pattern of small, focused commits with clear documentation. The patch appears ready for merging as part of the complete series.
