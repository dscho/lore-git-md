This is a review of Taylor Blau's performance optimization patch for the pack-bitmap-write subsystem, part of his series to speed up bitmap generation. Jeff King (Peff) confirms the patch's correctness and verifies the claimed 5% speedup on the linux.git repository.

The patch moves a bitmap check outside of `fill_bitmap_tree()` to avoid unnecessary function calls when a tree's bit position is already set. While Peff notes some mild discomfort with the slight code duplication this introduces (the check now appears at two call sites), he considers it a worthwhile tradeoff given the measurable performance improvement.

Peff's review is substantive - he independently verified the performance claims and analyzed the code change's impact. His comment about the previous patch's unexpected speedup (referenced with a wink) suggests ongoing discussion about the optimization's theoretical basis versus its practical effects. The review confirms this patch is ready to proceed as part of the larger optimization series.
