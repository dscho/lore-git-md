This is Junio Hamano's "What's cooking" report for May 2026, providing a status update on various Git development topics. The report covers both graduated topics (merged to 'next') and new/cooking topics under consideration.

Key highlights from the graduated topics:
- Several performance optimizations landed, including bulk prefetching for lazy clones (en/batch-prefetch), optimized revision traversal (kk/limit-list-optim), and octopus merge checks (kk/merge-octopus-optim)
- The ODB (object database) transaction interface saw significant rework (jt/odb-transaction-write) enabling new in-memory object storage (ps/odb-in-memory)
- Multiple patches continued the_repository removal effort (ps/setup-wo-the-repository)
- MIDX repacking gained incremental strategy support (tb/incremental-midx-part-3.3)
- Various bugfixes and documentation updates were merged

New/cooking topics of note:
- Path completion now hides dotfiles by default (za/completion-hide-dotfiles)
- Sparse index optimizations for 'git restore' (ds/restore-sparse-index)
- Commit reachability optimizations (kk/commit-reach-optim)
- New "--prune-merged" option for branch cleanup (hn/branch-prune-merged)
- Linux fsmonitor implementation (pt/fsmonitor-linux) appears ready for merging
- Several documentation modernization efforts continue (ja/doc-synopsis-style-again)

The report shows active development across performance, infrastructure, and usability fronts, with particular focus on the object database abstraction and repository setup modernization. Many topics are marked as ready for merging to 'next', while others await further discussion or rerolls.
