This is the third and final patch in a bugfix series addressing network address handling issues in Git's daemon mode. The patch adds NULL pointer safety when logging connection details, specifically guarding against the REMOTE_PORT environment variable being unset.

The change is straightforward - it adds a fallback "?" string when REMOTE_PORT is NULL, matching the existing behavior for REMOTE_ADDR. This prevents undefined behavior from passing NULL to printf's %s format specifier. The fix maintains consistency with the existing logging format while making it more robust.
