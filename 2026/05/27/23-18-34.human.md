This is a feature patch series from Taylor Blau that enhances `git pack-objects` to support reachability bitmaps and delta-islands when using the `--path-walk` option. The series builds on previous work by Derrick Stolee that added filter support to path-walk mode.

The three patches:
1. Enable reachability bitmaps to work with `--path-walk`, falling back to path-walk when bitmaps can't answer the request
2. Refactor delta-islands code by extracting a helper function for tree depth recording
3. Extend delta-islands support to work with `--path-walk` by ensuring the same tree depth information is available

The changes appear well-motivated and build logically on existing functionality. The series includes tests in both the pack-bitmaps and delta-islands test suites to verify the new behavior. This looks like a solid incremental improvement to the pack-objects machinery, particularly for users who need path-based filtering while still benefiting from bitmap and delta-island optimizations.
