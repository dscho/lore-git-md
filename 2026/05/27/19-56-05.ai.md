This is the sixth patch in Taylor Blau's performance optimization series for the pack-bitmap-write subsystem, focusing on reducing bitmap file sizes through smarter sorting before XOR compression. The series builds on his earlier pseudo-merge bitmap work and has already achieved a 60% speedup in bitmap generation time through previous optimizations.

The current patch introduces commit date sorting before computing XOR offsets between bitmaps, which significantly improves compression efficiency. The change reduces bitmap file size by 72% (from 635MB to 176MB) in test cases, with minimal impact on generation time. The implementation sorts selected commits by date while maintaining the bitmap map consistency through careful hash table updates.

This optimization complements the series' earlier position caching and lookup reduction work, demonstrating Taylor's systematic approach to performance tuning. The patch builds logically on prior infrastructure changes while maintaining clean separation of concerns. Jeff King's ongoing technical validation continues to confirm the soundness of each optimization.

The remaining patches in the series will restructure pseudo-merge handling and introduce a separate generation pass, completing the planned optimizations. This mid-series patch shows the expected progression toward the goal of faster bitmap generation with smaller on-disk footprints for large repositories.
