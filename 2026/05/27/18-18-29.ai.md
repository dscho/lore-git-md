This is the first patch in a bugfix series addressing network address handling issues in Git's daemon mode (`daemon.c`). The patch specifically fixes IPv6 address corruption that could occur when `getaddrinfo()` returns IPv6 results but the code incorrectly assumed IPv4 addresses.

The fix properly handles both AF_INET and AF_INET6 address families by:
1. Checking the address family before processing
2. Extracting the correct struct pointer (sockaddr_in or sockaddr_in6)
3. Passing the proper family to `inet_ntop()`
4. Adding a safety check to die() on unexpected address families

The changes are straightforward and focused, touching only the `lookup_hostname()` function in `daemon.c`. The patch follows the maintainer-approved approach from previous discussion, including the use of `(void *)` casting that Junio noted as "cute" but valid. This appears ready for merging as part of the series, which has already received positive reviews from both Junio C Hamano and Patrick Steinhardt.

The patch maintains IPv4 behavior while fixing IPv6 support, with no protocol or on-disk format changes. One remaining consideration is verification on IPv6-only configurations, though the technical approach is sound.
