This is the second patch in a 3-part RFC series introducing a new `--word-diff-align` feature that highlights edits within moved code blocks. The patch adds a temporary debug renderer to visualize the line pairings identified by the core matching logic from patch 1.

The renderer shows word-level differences between paired lines using the familiar `[-old-]` and `{+new+}` markers, while maintaining the moved-line coloring from `--color-moved`. This helps reviewers inspect the quality of the matches by showing exactly which tokens were aligned between deleted and inserted lines. The implementation includes tokenization, LCS calculation for token matching, and span highlighting.

The author emphasizes this is just a prototype for RFC review - the final version would reuse Git's existing word-diff machinery rather than this debug implementation. The patch includes extensive 200-line diff showing the detailed implementation, with careful memory management and error handling.

This continues the well-structured approach from the first patch, providing concrete output reviewers can evaluate while keeping the experimental nature clear. The debug output includes scoring details (window, line and pair scores) to help assess match quality.
