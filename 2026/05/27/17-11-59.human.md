This is a platform compatibility patch addressing a macOS linker warning. The change initializes the `packet_buffer` array in pkt-line.c to avoid alignment-related warnings during compilation on macOS. The warning occurs because the uninitialized large buffer's default section alignment exceeds macOS's segment maximum alignment.

The fix is straightforward - initializing the array with `= {0}` - and appears to be a clean solution to the cosmetic build warning. While the warning doesn't indicate a functional problem, the patch improves the build experience for macOS users. The change is minimal and low-risk, touching only the declaration of this global buffer.
