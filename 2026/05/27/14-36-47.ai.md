Performance optimization follow-up in the pack-bitmap-write subsystem. Taylor Blau responds to Jeff King's review of his second patch in the bitmap generation speedup series, agreeing with the tradeoff analysis around code duplication versus performance gains.

The patch moves a bitmap check outside `fill_bitmap_tree()` to avoid unnecessary function calls when a tree's bit is already set, providing a measurable 5% speedup on linux.git. While this introduces some code duplication at the two call sites (for root trees and recursive subtree handling), both Taylor and Peff consider this an acceptable tradeoff given the significant performance improvement in bitmap generation time.

This brief exchange confirms consensus on the patch's approach between two of Git's most experienced performance optimization experts, with Taylor noting the natural constraint that there will only ever be two call sites for this function. The interaction demonstrates the project's balance between code cleanliness and measurable performance gains in critical paths.
