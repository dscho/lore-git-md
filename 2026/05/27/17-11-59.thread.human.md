Harald Nordgren, who reported the issue, provided concrete implementation details - a Makefile snippet that checks for linker version 1167+ to apply the flag. Maintainer Junio C Hamano endorsed this build-system approach, preferring it over source modifications to avoid object file bloat. The solution demonstrates Git's typical handling of platform-specific quirks through targeted build system adjustments rather than core code changes.

With the technical approach settled and implementation details confirmed, this is ready for inclusion in config.mak.uname's macOS section.
