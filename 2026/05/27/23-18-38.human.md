This is the first patch in Taylor Blau's 3-part series to enhance `git pack-objects` with bitmap and delta-islands support for `--path-walk` mode. The patch specifically enables reachability bitmaps to work with `--path-walk`, allowing bitmap acceleration when possible while falling back to path-walk when needed.

The change removes an artificial limitation that previously prevented bitmap usage with path-walk. The patch modifies the path-walk object callback to properly index commits for bitmaps and ensures boundary commit handling works correctly when both `--path-walk` and `--use-bitmap-index` are specified. The implementation includes thorough test coverage showing the feature works for both repacking and direct object enumeration.

This continues Taylor's ongoing work optimizing the pack subsystem, building on Derrick Stolee's earlier path-walk filter support. The changes are focused and well-motivated, with clear technical rationale provided in the commit message. The patch touches core packing functionality in `builtin/pack-objects.c` and adds tests in `t5310-pack-bitmaps.sh`.
