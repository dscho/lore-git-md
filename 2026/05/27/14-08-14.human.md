This is a small refactoring patch that's part of Christian Couder's larger series on URL-based auto-configuration for promisor remotes. The change is straightforward: it converts a `char allow_globs` parameter to `bool` in the `url_normalize_1()` function, and updates the two call sites to use `true`/`false` instead of `1`/`0`. 

The patch is clean and mechanical - it doesn't change any behavior, just makes the code more type-correct. Since it's part of a larger series that's already been thoroughly reviewed (with Patrick Steinhardt's approval and Junio's positive feedback), this particular change is unlikely to be controversial. The series as a whole is focused on improving promisor remote configuration with URL pattern matching, and this patch helps clean up some underlying URL handling code that supports that feature.
