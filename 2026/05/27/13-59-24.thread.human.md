Kristoffer Haugsbakk sent a two-patch series removing long-deprecated commit list functions from commit.h, completing work that had been planned since Git 2.53.0. The first patch updates the few remaining callers to use the modern equivalents (`commit_list_free()` instead of `free_commit_list()`, etc.), while the second removes the deprecated functions entirely. Patrick Steinhardt, who originally introduced the modern API replacements, acknowledged the cleanup with approval, noting the irony of having been both the creator of the new API and a primary user of the old one. 

The change is straightforward and uncontroversial, following Git's standard deprecation process where functions are first marked obsolete, callers are migrated, and then the old functions are removed after ensuring no in-flight topics still depend on them. With no remaining callers in active branches and Steinhardt's implicit approval, the series appears ready for merging as part of routine codebase maintenance.
