This is the sixth patch in Taylor Blau's performance optimization series for the pack-bitmap-write subsystem, focusing on reducing bitmap file sizes through smarter sorting. The series has already achieved a 60% speedup in bitmap generation time across previous patches.

The current patch introduces commit date sorting before computing XOR offsets between bitmaps, which can significantly compress the resulting bitmap file by finding better ancestor/descendant pairs. In testing, this reduced a 635MB bitmap file down to 176MB (72% smaller) with negligible impact on generation time. The change sorts selected commits by date while preserving the existing bitmap map relationships.

This continues the series' pattern of well-instrumented, incremental optimizations that build on each other. The patch has a clear technical rationale and demonstrates measurable improvements without affecting user-visible behavior.
