This is a refactoring patch from René Scharfe that removes an unnecessary sorting operation in the commit-reach.c code. The patch targets the `paint_down_to_common()` function, which is used to find common ancestors between commits.

The key observation is that none of the three callers of this function actually need the result list to be sorted - one caller sorts it again anyway, and the other two don't use the list order at all. The patch simply removes the `commit_list_sort_by_date()` call that was doing this unnecessary work.

This is a clean, straightforward cleanup that follows René's typical pattern of removing redundant operations and simplifying code. The commit message clearly explains the change and its justification. Since this is a pure optimization with no behavior change, it's unlikely to generate much discussion beyond perhaps an Ack from one of the regular reviewers.
