This thread discusses a small but meaningful cleanup in Git's commit reachability code. René Scharfe has identified and removed a redundant sorting operation in `paint_down_to_common()`, which was unnecessarily sorting commit lists by date when none of its three callers actually required sorted results. The change is safe and well-justified - one caller re-sorts the list anyway, while the other two don't use the ordering at all. This is a classic René Scharfe cleanup: surgical, well-reasoned, and eliminating unnecessary work without changing observable behavior. The patch touches core reachability algorithms but does so in a mechanical way that clearly improves the code.
