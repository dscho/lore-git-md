This is the second patch in Taylor Blau's 3-part series to enable reachability bitmaps and delta-islands with `git pack-objects --path-walk`. The patch is a refactoring that extracts tree-depth recording logic into a helper function.

The change moves the delta-islands tree-depth calculation from `show_object()` into a new `record_tree_depth()` helper. This prepares for a follow-up change that will need to record tree depths from another location. The helper maintains the existing behavior of:
- Calculating depth based on slash counts in path names
- Only updating when the new depth is greater than the recorded one
- Skipping objects not in the packlist

The refactoring is clean and mechanical, with no behavior changes. It touches core packing code but is well-contained, just shuffling code between functions. This continues the series' pattern of careful, incremental improvements to the pack machinery while maintaining compatibility with existing features.

The patch follows naturally from the first one (which enabled bitmaps with path-walk) and sets up for the third patch that will properly integrate delta-islands with path-walk mode. The commit message clearly explains the motivation and implementation.
