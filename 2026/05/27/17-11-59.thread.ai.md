Thread subject: [PATCH] pkt-line: initialize packet_buffer to avoid macOS linker warning. Core issue is a macOS/Xcode 16.3+ linker warning about alignment constraints when linking large uninitialized global arrays (65520-byte packet_buffer in pkt-line.c). The solution uses `-fno-common` compiler flag, with version detection refinement for edge cases.

Technical details: the packet_buffer in pkt-line.c is used for Git's network implementation. The warning occurs only on newer macOS/Xcode toolchains (linker version 1167+). The solution modifies config.mak.uname to detect the linker version and conditionally add -fno-common to BASIC_CFLAGS, directing large arrays to BSS rather than __DATA,__common sections. The final refinement adds a test for non-empty version string before numeric comparison to handle malformed version strings cleanly.
