This is a bugfix series addressing network address handling issues in Git's daemon mode, now in its second iteration. The three patches fix IPv6 address corruption, IPv6 address truncation in logs, and NULL pointer safety when logging connection details.

The series has been restructured since v1 based on Patrick Steinhardt's feedback, with each fix now in a separate commit. The changes maintain the same technical corrections while improving the code organization. The fixes address clear correctness issues that could cause misbehavior on IPv6-only hosts or lead to crashes from NULL pointer dereferences.

Notable improvements in v2 include deduplicated address family handling in the IPv6 fix (using a void* intermediate cast that the maintainer noted as "cute but valid"), and more thorough NULL checking for both REMOTE_ADDR and REMOTE_PORT environment variables. The author has also added explicit handling for unexpected address families rather than silently leaving buffers uninitialized.

The patches remain focused on `daemon.c` with straightforward changes that don't affect on-disk formats or protocols. While the technical approach has been approved by both Junio Hamano and Patrick Steinhardt, some open questions remain about IPv6-only configuration testing and whether to add specific test coverage for the fixed cases.
