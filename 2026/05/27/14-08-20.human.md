This is the final documentation patch in Christian Couder's URL-based promisor remote auto-configuration series, now ready for merging. The patch improves the `promisor.acceptFromServer` config entry in promisor.adoc to be clearer and more structured.

The changes address several documentation issues:
- Makes it explicit that this option doesn't create new remotes (unlike the new `acceptFromServerUrl`)
- Reformats the options as bullet points for better readability
- Clarifies the default is "none"
- Fixes a wording error about "advertised by the client" to say "server" instead
- Links to the new `acceptFromServerUrl` option
- Adds security guidance for each option level

The patch follows Kristoffer Haugsbakk's documentation review feedback and completes the series' documentation polish. With this change, both the LOP and URL-based auto-configuration series are fully documented and ready for integration. The improvements make the security tradeoffs and behavior differences between the configuration options much clearer for users.
