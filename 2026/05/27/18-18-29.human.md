This is the first patch in a v2 bugfix series addressing network address handling issues in Git's daemon mode. The patch specifically fixes IPv6 address corruption that could occur when `getaddrinfo()` returns IPv6 results but the code incorrectly assumed IPv4, reading from the wrong struct offset.

The fix properly handles both AF_INET and AF_INET6 address families by checking `ai_family` and extracting the correct address pointer before calling `inet_ntop()`. It also adds a safety check to die on unexpected address families. The changes are confined to `daemon.c` and maintain IPv4 behavior while fixing IPv6 support.

The patch has already received positive reviews from both Junio C Hamano and Patrick Steinhardt in previous iterations, with Junio noting the `(void *)` casting style as acceptable. The author has incorporated all feedback from v1, including splitting the original single patch into this more focused commit. This appears to be a straightforward correctness fix that's ready for merging.
