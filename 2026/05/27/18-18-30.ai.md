This is the second patch in a bugfix series addressing network address handling issues in Git's daemon mode. The patch specifically fixes IPv6 address truncation in the `ip2str()` function where the sockaddr struct size was incorrectly used as the output buffer size for `inet_ntop()`, causing silent truncation of long IPv6 addresses.

The fix replaces the `ai_addrlen` parameter with the actual buffer size (`sizeof(ip)`), which properly accommodates full IPv6 addresses (46 bytes via INET6_ADDRSTRLEN). The change simplifies the function signature by removing the now-unused length parameter and updates all callers accordingly. The patch maintains the same behavior for IPv4 while fixing IPv6 case.

This is a straightforward technical correction that follows the maintainer-approved approach from the previous discussion. The change is contained to `daemon.c` and doesn't affect protocol or on-disk formats. The patch appears ready for merging as part of the series, which has received positive reviews from both Junio C Hamano and Patrick Steinhardt.
