This is the second patch in Taylor Blau's 3-part series to enable reachability bitmaps and delta-islands with `git pack-objects --path-walk`. The patch is a refactoring that extracts tree-depth recording logic from `show_object()` into a new helper function `record_tree_depth()`.

The change is purely mechanical - it moves the delta-islands tree-depth calculation code into a standalone function without altering behavior. This prepares for the next patch which will need to call this logic from another location. The helper maintains the existing behavior where:
- Empty string paths are treated as root trees (depth 0)
- Depth is calculated by counting path components (slashes)
- The maximum depth encountered for each tree is preserved

The patch touches only `builtin/pack-objects.c`, with straightforward changes that replace inline code with a function call. This continues the series' focus on careful refactoring to support the new path-walk functionality while maintaining existing behavior. The commit message clearly explains the motivation and guarantees no functional change.
