Performance enhancement to `pack-objects` that enables reachability bitmaps to work with `--path-walk`. This is the first patch in Taylor Blau's 3-part series building on Derrick Stolee's earlier work on path-walk filters.

The patch removes two key restrictions that previously prevented bitmap usage with path-walk:
1. It now indexes commits discovered via path-walk for bitmap writing
2. It allows bitmap lookups during path-walk operations, falling back to path-walk when bitmaps can't satisfy the request

The changes maintain careful handling of edge cases like `--boundary` flags, which path-walk needs but bitmap traversal doesn't understand. Test coverage verifies both bitmap writing and reuse scenarios work correctly with path-walk.

This continues Taylor Blau's ongoing optimizations of Git's pack subsystem, specifically around object enumeration strategies. The implementation appears focused and well-considered, with clear documentation updates and thorough test coverage. The changes touch core packing functionality in `builtin/pack-objects.c` and `pack-bitmap.c`, with new tests in `t5310-pack-bitmaps.sh`.
