This is the final patch in a 3-part series improving `git log -L` (line-log) integration with Git's standard diff pipeline. The patch enables several non-patch diff formats (`--raw`, `--name-only`, `--name-status`, `--summary`) to work with `-L` while still blocking stat formats (`--stat`, `--numstat`, etc.) which would show whole-file statistics rather than range-specific ones.

The changes are well-motivated - the patch formats now work because they only need filepair metadata that's already available, while stat formats remain blocked since they'd require computing diffstats on the full file content. The implementation updates the allowlist in `setup_revisions()` and adds comprehensive tests verifying the new behavior.

This completes the series' goal of unifying line-log` output with Git's standard diff pipeline while maintaining the architectural separation between line-log and full-diff paths. The author has carefully addressed all feedback from the v1 review, making this a solid incremental improvement to the line-log feature.
