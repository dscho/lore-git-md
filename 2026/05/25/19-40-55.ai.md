This is version 2 of a 3-patch series refactoring how `git log -L` (line-log) integrates with Git's diff output pipeline. The series aims to make line-log processing flow through the standard `log_tree_diff()` pipeline rather than taking a separate shortcut.

The main improvements in v2 address feedback from D. Ben Knoble's review of v1:
- Refined the return path behavior in `log_tree_diff()` to match existing conventions
- Clarified commit messages about the pipeline change
- Improved test hygiene by using `test_grep` consistently and removing `sed | grep` pipes
- Softened the `--full-diff` rejection message from "incompatible" to "not yet supported"

The series now cleanly integrates line-log output with Git's standard diff pipeline while:
1. Fixing pickaxe (`-S`, `-G`) and `--diff-filter` suppression when line ranges are filtered out
2. Aligning commit/diff separator behavior with regular log output
3. Adding support for non-patch diff formats (`--raw`, `--name-only`, etc.) while still blocking stat formats

The author explicitly notes that stat format support (showing range-clipped diffstats) is planned as follow-up work. The changes demonstrate careful attention to both technical correctness and review feedback, making this a well-structured incremental improvement to the line-log machinery.
