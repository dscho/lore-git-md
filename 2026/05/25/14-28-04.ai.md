Performance optimization patch (part 2/3) implementing queue deduplication in commit-reach.c.

This middle patch in Kristofer Karlsson's series introduces deduplication for the priority queue used in paint_down_to_common(), ensuring each commit appears in the queue at most once. The change adds an ENQUEUED flag (bit 20) to track queue membership and provides wrapper functions prio_queue_put_dedup() and prio_queue_get_dedup() to manage this flag automatically.

The patch updates the flag allocation documentation in object.h to reflect the new ENQUEUED bit usage. While this change doesn't directly improve performance (the O(n) scan remains), it provides the necessary invariant for the next patch's O(1) optimization by guaranteeing no duplicate queue entries. The implementation maintains all existing behavior while preparing for the more significant performance improvement to come.

This is a mechanical prerequisite for the series' main optimization, carefully preserving the one-way stale transition property that the algorithm relies on. The patch follows the established pattern of the series by keeping changes focused and well-contained within commit-reach.c.
