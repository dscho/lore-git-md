This is the first patch in version 2 of Michael Montalbo's series to integrate `git log -L` (line-log) with Git's standard diff output pipeline. The patch is a preparatory refactoring that moves the line-log setup code earlier in `setup_revisions()` to ensure the default `DIFF_FORMAT_PATCH` output format is visible when `revs->diff` is computed.

The change is mechanical but important for the series' goal - it ensures that when no explicit output format is requested with `-L`, the patch format will be properly recognized by the diff pipeline that subsequent patches will route through. The commit message clearly explains both the current harmless state and why this ordering matters for the upcoming changes.

This patch shows careful attention to the review feedback from v1, with a clean separation of concerns and no behavior change on its own. It's a well-structured foundation for the more substantive changes to follow in patches 2 and 3 of the series.
