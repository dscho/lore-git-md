This is the second patch in a 3-patch series refactoring Git's line-log (`-L`) output to integrate with the standard diff pipeline. The patch focuses on routing line-log output through `log_tree_diff()` and `log_tree_diff_flush()` rather than taking a separate shortcut path.

The key changes in this patch:
- Renames `line_log_print()` to `line_log_queue_pairs()` and simplifies it to just queue pre-computed filepairs
- Makes line-log flow through the standard `log_tree_diff()` -> `log_tree_diff_flush()` path used by other diff outputs
- Fixes several long-standing issues where pickaxe (`-S`, `-G`) and `--diff-filter` weren't properly suppressing commits when line ranges were filtered out
- Aligns commit/diff separator behavior with regular log output
- Explicitly rejects `--full-diff` (not yet supported with `-L`)
- Updates tests to verify the new behavior

The patch demonstrates careful attention to both technical correctness and review feedback from v1, with test improvements showing the fixed pickaxe/diff-filter behavior. The changes maintain a clear separation between line-log and full-diff paths while bringing the output pipeline into alignment with Git's standard diff machinery.
