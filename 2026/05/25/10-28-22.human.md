This is a documentation patch (part 1/6) in Jean-Noël Avila's series converting Git man pages to standardized AsciiDoc synopsis style. The patch specifically updates the git-bisect.adoc documentation.

The changes are mechanical formatting updates rather than content changes:
- Replaces [verse] with [synopsis] in the SYNOPSIS section
- Uses backticks consistently for commands, options, and references
- Applies synopsis styling to in-body command examples (with placeholders)
- Formats OPTIONS section with proper backtick quoting
- Updates man page cross-references to use `command`(N) style

This version incorporates feedback from Junio about distinguishing between synopsis formatting (for command syntax) versus regular code blocks (shell prompts). The patch shows the author's interpretation that synopsis style should be used for any command syntax with placeholders, not just the formal SYNOPSIS section.

The changes are straightforward and follow the established patterns from previous documentation conversions in this multi-year standardization effort. The patch appears ready for merging as part of the broader documentation cleanup.
