This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. This is patch 4/6 in version 2 of the series, converting the git-am documentation to the new format.

The changes are mechanical and focus on presentation rather than content:
- Replacing [verse] with [synopsis] blocks in the SYNOPSIS section
- Consistently backtick-quoting option names and config variables
- Standardizing cross-references and placeholder notation
- Updating related config files to match the new style

The patch follows the same patterns established in earlier patches of the series, applying the agreed-upon rules for distinguishing between abstract command syntax (in [synopsis] blocks) and concrete shell examples (in regular code blocks). The extensive option documentation in git-am serves as another test case for the new formatting approach.

This continues the multi-year documentation standardization project that has been converting hundreds of Git's man pages to a uniform style. The changes appear straightforward and consistent with the project's goals, with no technical content modifications. Given that this is version 2 of the series and the formatting approach has already been discussed, this patch seems ready for merging pending maintainer confirmation.
