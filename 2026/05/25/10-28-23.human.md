This is a documentation patch in Jean-Noël Avila's ongoing effort to standardize Git's man pages using AsciiDoc synopsis style. The patch specifically clarifies the distinction between command synopses (abstract representations with placeholders) and actual command examples (concrete shell commands prefixed with $).

The changes in this v2 iteration:
- Explicitly documents when to use synopsis formatting (for abstract command syntax with placeholders) versus code blocks (for concrete shell commands with $ prefix)
- Updates git-bisect.adoc examples to follow this distinction
- Shows responsiveness to Junio's feedback from v1 while maintaining the author's position that synopsis formatting has value beyond just SYNOPSIS sections

The patch is part of a larger series converting five command manuals to the new style. This particular change appears non-controversial and well-justified, providing clear standard for future documentation work. The author has struck a reasonable balance between maintainer feedback and documentation usability concerns.
