This is a documentation patch series, part of the ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. Jean-Noël Avila continues his work with version 2 of this batch converting five command manuals: git-bisect, git-grep, git-am, git-apply, and git-imap-send.

The key change from v1 addresses Junio's feedback about proper usage of the synopsis style in git-bisect.adoc, particularly clarifying when to use synopsis formatting versus regular code blocks for command examples. The series now includes a new patch (2/6) specifically documenting this distinction, showing the author's interpretation that synopsis style should be used for command syntax with placeholders while keeping shell prompts in regular code blocks.

The conversion remains mechanical in nature, focusing on presentation rather than content changes. Each command's documentation is updated to use consistent AsciiDoc markup for synopses, options, and cross-references. The series maintains the same scope as v1 while incorporating the stylistic clarification about command formatting.

This continues the multi-year documentation standardization project that has been converting hundreds of Git's man pages to a uniform style. The v2 iteration shows responsiveness to maintainer feedback while maintaining the author's position that synopsis formatting has value beyond just SYNOPSIS sections. The changes appear straightforward and unlikely to generate further controversy, positioning this series to potentially be picked up for merging in the next integration window.
