This is the first patch in Kristofer Karlsson's v2 performance optimization series for commit-reach.c algorithms. While primarily a prerequisite cleanup, it fixes several inaccuracies in object.h's flag allocation table documentation:

1. Updates the renamed sha1-name.c to object-name.c
2. Corrects builtin/show-branch.c's flag usage from bits 0-26 to 0-28 (accounting for REV_SHIFT=2 and MAX_REVS=27)
3. Adds negotiator/skipping.c's flag usage (bits 2-5, matching negotiator/default.c)

The changes are straightforward documentation fixes that don't affect runtime behavior but ensure the flag allocation table accurately reflects current usage. This cleanup prepares for the subsequent patches that optimize commit-reach.c's algorithms by ensuring the flag documentation is up-to-date before those changes land.

The patch maintains the existing format and style of the flag allocation table while making the minimum necessary corrections. As a documentation fix with no functional impact, it serves as a clean foundation for the more substantive performance optimizations that follow in patches 2 and 3 of the series.
