This is a documentation patch series (v2) from Jean-Noël Avila, continuing the effort to convert Git's man pages to a standardized AsciiDoc synopsis style. The series updates documentation for five commands: git-bisect, git-grep, git-am, git-apply, and git-imap-send.

The key change in this revision addresses feedback from Junio about the formatting of command examples in git-bisect.adoc. The author has clarified the distinction between synopsis-style formatting (for command syntax with placeholders) and code blocks (for literal shell commands with '$' prompts). A new patch (2/6) specifically documents this distinction in the git-bisect manual.

The series remains focused on mechanical conversion of documentation formatting without changing technical content. The changes are part of a long-running project to establish consistent man page presentation across Git's documentation. Given Jean-Noël's role as the documentation standardization lead and the straightforward nature of these formatting updates, this revision appears ready for merging once the CI issue mentioned in the thread is resolved.
