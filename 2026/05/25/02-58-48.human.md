This is a documentation patch from maintainer Junio C Hamano that updates the SubmittingPatches guide to encourage contributors to monitor GitHub CI results even if they don't use GitHub CI themselves. 

The patch adds a new section explaining that contributors should watch for CI failures that might appear after their patches are merged into the integration branches (particularly 'seen'). It provides a direct link to the GitHub Actions workflow page filtered to show only pushes by the maintainer (gitster). 

The change reflects the project's increasing reliance on CI to catch integration issues, and aims to distribute responsibility for monitoring CI results more broadly among contributors rather than leaving it solely to the maintainer. The tone is characteristically direct from Junio - encouraging proactive engagement while making clear that contributors should quickly address any breakages they cause.
