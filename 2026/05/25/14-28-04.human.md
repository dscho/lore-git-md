This is the second patch in Kristofer Karlsson's performance optimization series for commit-reach.c algorithms. It introduces commit deduplication in the priority queue used by `paint_down_to_common()`, which is a prerequisite for the O(1) optimization in the next patch.

The patch adds an `ENQUEUED` flag to track whether a commit is already in the queue, preventing duplicate entries when commits are reached through different parent paths. New wrapper functions `prio_queue_put_dedup()` and `prio_queue_get_dedup()` manage this flag during queue operations.

While this change alone doesn't improve performance (the O(n) scan remains the bottleneck), it provides the invariant needed for the next patch's optimization. The implementation is clean separation of concerns - this handles deduplication while the follow-up will tackle the performance issue. The patch updates the flag allocation documentation in object.h to account for the new `ENQUEUED` flag (bit 20).

This is a well-structured intermediate step in the series, clearly separating the logical concerns of deduplication from the performance optimization that follows. The changes are focused and the commit message clearly explains both the immediate effect and how it enables the next improvement.
