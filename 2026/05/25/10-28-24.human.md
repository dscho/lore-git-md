This is a documentation patch (part 3/6) in Jean-Noël Avila's series converting Git man pages to standardized AsciiDoc format. The patch updates the git-grep documentation to use consistent synopsis-style formatting, following the rules established in earlier patches of the series.

The changes are mechanical and focus on presentation rather than content:
- Replaces [verse] with [synopsis] in the SYNOPSIS section
- Converts single-quoted commands to backtick-quoted
- Standardizes option formatting with backticks
- Updates cross-references and placeholders to use consistent markup
- Applies the config file changes to match the new style

The patch demonstrates the series' approach to distinguishing between abstract command syntax (using [synopsis] blocks with _<placeholders>_) and concrete terminal examples (in regular code blocks). The changes align with the compromise position that emerged from discussion of v1, where Jean-Noël addressed Junio's feedback about proper usage of synopsis formatting.

This continues the multi-year effort to standardize Git's documentation formatting across all man pages. The patch appears technically sound and unlikely to generate controversy, following the patterns established in earlier converted files.
