This is the first patch in Kristofer Karlsson's v2 performance optimization series for commit-reach.c algorithms. While primarily a prerequisite cleanup, it fixes several inaccuracies in Git's object flag allocation table documentation:

1. Updates the renamed `sha1-name.c` reference to `object-name.c`
2. Corrects the bit range for `builtin/show-branch.c` from 0-26 to 0-28 (accounting for REV_SHIFT=2 and MAX_REVS=27)
3. Adds missing documentation that `negotiator/skipping.c` uses bits 2-5 like `negotiator/default.c`

The changes are straightforward documentation fixes that don't affect runtime behavior, but ensure the flag allocation table accurately reflects current usage. This cleanup was identified during an audit while working on the larger performance optimization series, which introduces O(1) nonstale commit tracking in commit-reach.c. The patch demonstrates careful attention to detail - even when making mechanical updates, the author verified the actual bit usage in each case rather than just copying stale information.
