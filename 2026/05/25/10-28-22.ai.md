This is a documentation patch (1/6 in the series) converting git-bisect's man page to the standardized AsciiDoc synopsis style. Jean-Noël Avila continues his multi-year effort to standardize Git's documentation formatting.

The patch mechanically updates git-bisect.adoc to use consistent AsciiDoc markup throughout:
- Replaces [verse] with [synopsis] in the SYNOPSIS section
- Uses backticks for commands, options, and special values
- Applies synopsis formatting to in-body command examples containing placeholders
- Formats OPTIONS entries with backtick-quoted terms
- Updates man page references to use `command`(N) style

The changes are purely presentational - no technical content is altered. This version incorporates feedback from v1 by distinguishing between synopsis-formatted command syntax (with placeholders) versus regular code blocks for shell prompts. The patch also includes supporting changes to asciidoc.conf.in to enable the new formatting rules.

This conversion follows patterns established in earlier documentation standardization work while addressing the specific formatting question about [synopsis] scope that arose in v1's review. The changes appear straightforward and unlikely to generate controversy, positioning this series for potential merging.
