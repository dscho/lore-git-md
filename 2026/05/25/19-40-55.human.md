This is version 2 of a 3-patch series that refactors how `git log -L` (line-log) integrates with Git's diff output pipeline. The changes make line-log processing flow through the standard `log_tree_diff()` path used by other diff operations, rather than taking a separate shortcut.

The key improvements in this version:
1. Better alignment with existing return conventions in `log_tree_diff()`
2. Clearer commit message explanations about the pipeline changes
3. More accurate wording about `--full-diff` being deferred rather than incompatible
4. Improved test hygiene by replacing `sed | grep` pipes with `test_grep`

The series enables several benefits:
- Fixes issues where pickaxe (`-S`, `-G`) and `--diff-filter` weren't properly suppressing commits
- Aligns commit/diff separator behavior with regular log output
- Adds support for non-patch diff formats (`--raw`, `--name-only`, etc.) with `-L`
- Maintains blocking of stat formats that would show whole-file stats

The changes appear well-considered and the author has thoughtfully incorporated feedback from D. Ben Knoble's review of v1. The series represents a solid technical improvement to make line-log behave more consistently with Git's other diff operations.
