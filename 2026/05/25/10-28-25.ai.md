This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's man page formatting using AsciiDoc synopsis style. Patch 4/6 in version 2 of the series converts the git-am documentation to the new format.

The changes are mechanical and consistent with the patterns established in earlier patches of this series:
- Replaces [verse] with [synopsis] blocks in the SYNOPSIS section
- Backtick-quotes all option names and configuration variables
- Standardizes cross-references using linkgit syntax
- Converts placeholder notation to _<placeholder>_ style
- Updates related documentation files (config/am.adoc, format-patch-*.adoc) to match

The patch demonstrates the series' approach to distinguishing between abstract command syntax (in [synopsis] blocks) and concrete shell examples (in regular code blocks). It also shows the consistent treatment of configuration variables like `am.keepcr` and options like `--3way`.

This continues the multi-year documentation standardization project that has been converting hundreds of Git's man pages to a uniform style. The changes are purely presentational and unlikely to generate controversy, following the patterns already established in earlier patches of this series. The patch appears technically ready for merging, pending maintainer confirmation of the overall documentation approach.
