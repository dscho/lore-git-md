Johannes Schindelin has completed a series removing the unmaintained nedmalloc allocator from Git's codebase, prompted by build failures with GCC 16 on Windows (MINGW). The allocator had been effectively obsolete since Git for Windows switched to mimalloc years ago. The six-part series systematically disabled and then removed all 5,761 lines of nedmalloc code, with the final patch deleting the core allocation algorithms and remaining implementation details. The changes span all build systems (Makefile, CMake, Meson) but have no runtime impact since the code was already disabled in the first patch.

Junio Hamano, while acknowledging the technical necessity of splitting the large file deletion into multiple patches for mailing list size constraints, has suggested two cleaner integration approaches: either marking later deletion patches as "to be squashed" with rationale in the first patch, or handling the final deletion as a single commit pulled directly from Johannes' repository. This reflects Junio's typical focus on maintaining a clean project history while working within practical constraints. The substantive technical work appears uncontested, with Patrick Steinhardt having previously endorsed the removal direction. The series now awaits final integration.
