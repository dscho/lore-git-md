Johannes Schindelin (Dscho) continues his series removing the obsolete nedmalloc allocator from Git's Windows builds, now at version 3. The first patch disabled nedmalloc usage across all build systems (Makefile, CMake, Meson), and this second patch follows up by cleaning up all build system references to the allocator. The changes are straightforward deletions of configuration options and file inclusions from the Makefile, meson.build, and VS Code settings.

The series follows a careful progression - first ensuring the allocator isn't used, then removing references to it, with the final step (coming in subsequent patches) being the actual deletion of the implementation files. This approach prevents any build breakage during the transition. The work builds on Git for Windows' prior switch to mimalloc, making nedmalloc obsolete. No new technical concerns have been raised since the series began, and it appears ready for integration. Junio C Hamano and Patrick Steinhardt have previously indicated support for the full removal approach.
