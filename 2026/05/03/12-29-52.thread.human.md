Johannes Schindelin (Dscho) proposed removing the Windows (MINGW) build's dependency on the unmaintained nedmalloc allocator, which was causing GCC 16 compatibility issues. Since Git for Windows already uses mimalloc instead, this change simply updates the build configuration while leaving the unused nedmalloc code in place for now.

Patrick Steinhardt agreed with the approach but noted this makes the entire nedmalloc subtree a candidate for removal, as no platform configuration uses it anymore. While this cleanup doesn't need to happen immediately, it's a logical next step now that the allocator is effectively orphaned. The discussion remains focused on build system maintenance, with both contributors aligned on the technical direction. The patch addresses the immediate GCC 16 issue while opening the door for future codebase simplification.
