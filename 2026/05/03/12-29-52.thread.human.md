This thread discusses a Windows-specific build fix proposed by Johannes Schindelin (Dscho) to address compatibility issues with GCC 16. The patch removes the long-unmaintained nedmalloc allocator from Git's Windows configuration, as it causes build failures with the new compiler due to unpatched warnings in the vendored code. 

Dscho notes that Git for Windows has been using mimalloc instead of nedmalloc for years, and this change simply aligns the main Git project's Windows build configuration with that reality. The minimal patch unblocks GCC 16 adoption in CI while leaving the door open for future mimalloc integration. The change appears uncontroversial, addressing a concrete technical issue with a focused solution.
