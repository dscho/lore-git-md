Johannes Schindelin has completed the removal of the unmaintained nedmalloc allocator from Git's Windows builds. The work was prompted by GCC 16 compatibility issues and the fact that Git for Windows had already switched to using mimalloc years ago. The removal was done methodically across six patches, first disabling usage, then removing build system references, auxiliary files, and finally the core implementation code in reviewable chunks.

The final patch removes the last remaining 1827 lines of the malloc implementation, including core allocation algorithms, system interaction code, and public interface functions. With this change, the entire `compat/nedmalloc/` directory is now gone from the tree. Since the code was already disabled in earlier patches, this is purely a cleanup with no runtime behavior changes.

The series received no objections and completes a deprecation path that began when Git for Windows first adopted mimalloc. The structured removal approach - disabling first, then deleting - ensured the change was safe and reviewable at each step. This marks the end of nedmalloc's decade-long presence in the codebase.
