This is a platform compatibility issue affecting Git 2.54 builds on RHEL 6. The problem manifests when linking `git-imap-send`, which fails due to an OpenSSL 3.x symbol (`ASN1_STRING_get0_data`) that isn't available in the system's OpenSSL 1.0.x libraries. The error suggests a conflict between the newer OpenSSL 3.5.6 that curl was built against and the older system OpenSSL libraries.

Key technical details:
- The build fails specifically on `git-imap-send` with undefined reference to `ASN1_STRING_get0_data` (an OpenSSL 3.0+ API)
- Warnings show library conflicts between libssl.so.3/libcrypto.so.3 (from newer OpenSSL) and libssl.so.10/libcrypto.so.10 (system OpenSSL)
- The reporter confirms Git 2.53 builds fine on the same system with OpenSSL 3.5.6

The issue appears to stem from Git 2.54's IMAP code using newer OpenSSL APIs while the system still has older OpenSSL libraries. This is a common problem when mixing newer software with older enterprise Linux distributions that have long-term support but outdated system libraries.
