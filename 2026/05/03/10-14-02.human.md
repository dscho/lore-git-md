This is a bugfix for the submodule configuration system. The patch corrects how `submodule.fetchJobs` values are read from `.gitmodules` files. The key issue was passing the wrong pointer (`&max_jobs` instead of `max_jobs`) to `config_from_gitmodules()`, which prevented the configured parallel job count from being properly applied during submodule updates.

The fix is straightforward - just removing the incorrect address-of operator. The patch includes a new test case that verifies the configuration is properly honored by checking the trace output for the expected job count. This appears to be a clean, well-motivated fix with appropriate test coverage.
