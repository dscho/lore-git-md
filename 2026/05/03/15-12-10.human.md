This is a platform compatibility patch targeting Clang compiler support. The change enables more descriptive warning messages for unused parameters when compiling with Clang, matching the behavior already present for GCC 4.5+.

The patch modifies the `UNUSED` macro in `compat/posix.h` to treat Clang the same as modern GCC versions, allowing it to show the "parameter declared as UNUSED" warning message. Currently, Clang identifies itself as GCC 4.2.1 for compatibility, causing it falls back to the less informative version of the warning. The author notes this has been supported in Clang since version 2.9 (2011).

The change is small and focused - a one-line modification with a straightforward explanation. The author acknowledges this may drop support for very old Clang versions (pre-2.9) but reasonably assumes such old compilers are no longer relevant.
