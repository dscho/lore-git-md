This thread addresses a minor compiler warning in the `name-rev` command when built with `DEVELOPER=1`. The issue stems from an uninitialized `commit` variable in `cmd_format_rev()`, introduced in Kristoffer Haugsbakk's commit 5903855b1c. Ramsay Jones provided a straightforward fix by initializing the variable in an else clause, noting it could be squashed into the original commit. The patch is small and uncontroversial, typical of the cleanup work that often follows compiler warnings. Its relevance depends on whether Kristoffer's original branch gets resubmitted.
