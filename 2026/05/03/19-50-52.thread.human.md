This thread documents a build failure affecting Git 2.54 on RHEL 6 systems when compiling `git-imap-send`, caused by OpenSSL version conflicts between Git's requirement for OpenSSL 3.0+ APIs and the system's older OpenSSL 1.0.x libraries. The issue was introduced in Git 2.53 via commit 6392a0b75d, which updated `imap-send` to use OpenSSL 1.1+ APIs.

The project maintains that RHEL 6 is no longer supported (as established by brian m. carlson, referencing platform support documentation), but participants have provided both diagnostic help and practical solutions. D. Ben Knoble suggested using `git bisect` to identify the problematic change, while Phillip Wood confirmed the technical root cause and suggested build configuration workarounds.

The original reporter has now successfully resolved their issue by explicitly pointing the build to a newer OpenSSL installation (`--with-openssl=/usr/local/openssl`), despite the system defaulting to the older version. They demonstrated thorough debugging by checking build options with `git --version --build-options` to verify the linked OpenSSL version. While RHEL 8 users wouldn't normally encounter this issue (as it ships with OpenSSL 1.1.1), this workaround provides a path forward for those needing to build on older systems. The thread serves as both a policy statement on platform support and a practical guide for troubleshooting similar build issues.
