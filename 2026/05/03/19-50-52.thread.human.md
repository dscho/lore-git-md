This thread documents a build failure affecting Git 2.54 on RHEL 6 systems, where `git-imap-send` fails to link due to OpenSSL version conflicts between Git's requirement for OpenSSL 3.0+ APIs and the system's older OpenSSL 1.0.x libraries. The reporter initially noted this as a regression from Git 2.53, which built successfully on the same configuration.

brian m. carlson clarified that RHEL 6 is no longer a supported platform per Git's documented requirements, as it lacks security support (having reached end-of-life in 2024). The project's position is that this is an unsupported platform issue rather than a regression to fix, with an OS upgrade recommended over build fixes due to security risks.

In a recent follow-up, the original reporter asked for more specific information about what changed between Git 2.53 and 2.54 that caused the build failure, noting they couldn't identify the problematic change from the changelog. While this suggests the user is exploring potential workarounds, the project's stance remains that RHEL 6 is unsupported, and there has been no indication that the position will change. The thread illustrates Git's practical approach to platform support, where compatibility with end-of-life systems is explicitly not maintained, even when technically feasible.
