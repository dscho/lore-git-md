This thread reports a build failure affecting Git 2.54 on RHEL 6 systems, where `git-imap-send` fails to link due to an OpenSSL version mismatch. The issue stems from Git 2.54's IMAP code using OpenSSL 3.x APIs (specifically `ASN1_STRING_get0_data`) while the system only has OpenSSL 1.0.x libraries installed. The reporter notes that Git 2.53 builds successfully on the same system configuration, suggesting this is a regression introduced in 2.54. This appears to be a classic case of newer software encountering older enterprise Linux environments with long-term support but outdated system libraries. No solutions or workarounds have been proposed yet in this initial report.
