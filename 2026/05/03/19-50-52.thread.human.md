This thread documents a build failure when compiling Git 2.54 on RHEL 6 systems, where `git-imap-send` fails to link due to OpenSSL version conflicts between the system's OpenSSL 1.0.x libraries and the newer OpenSSL 3.0+ APIs that Git now requires. The original reporter noted this as a regression from Git 2.53, which built successfully on the same system.

brian m. carlson has responded that RHEL 6 is no longer a supported platform for Git, as it lacks security updates (support ended in 2024) and falls outside Git's documented platform requirements. He points to the project's platform support policy, which requires active security maintenance from the OS vendor. While the technical cause is understood (OpenSSL API version mismatch), the project's position is that users should upgrade their OS rather than expect Git to maintain compatibility with outdated platforms. The response does not address the regression aspect or offer workarounds, maintaining a firm stance on platform support boundaries. This effectively closes the issue as "won't fix" for RHEL 6 users.
