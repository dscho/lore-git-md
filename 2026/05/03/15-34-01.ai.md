This is a refactoring patch that moves remote group resolution logic from `builtin/fetch.c` to `remote.c` as part of Usman Akinyemi's series adding remote group support to `git push`. The change follows Junio Hamano's suggestion to share this functionality between fetch and push commands.

The patch relocates three key components:
1. The `remote_group_data` struct that holds group resolution state
2. `get_remote_group()` which parses `remotes.<name>` config entries
3. `add_remote_or_group()` which resolves a name to either group members or a single remote

The implementation remains functionally identical but now exposes these helpers via `remote.h` for broader use. This enables the subsequent push group functionality to reuse the same config parsing logic rather than duplicating it. The change is mechanical with no behavior modifications - it simply moves code between files while maintaining all existing functionality.

This refactoring is a clean preparatory step that establishes shared infrastructure for the new push group feature while keeping the diff focused. The patch follows Git's convention of moving from command-specific implementations to more general library functions when functionality proves reusable.
