Git will participate in Google Summer of Code 2026 with four student projects. Kaartic Sivaraam announced the selected contributors and their projects: K Jayatheerth will enhance the new `git repo` command, Pablo Sabater will extend `git cat-file`'s remote object handling, Siddharth Shrimali will work on partial clone disk space recovery, and Tian Yuchen (an emerging reviewer with prior substantive contributions) will tackle global state reduction - continuing the ongoing `the_repository` removal effort. 

The projects are mentored by experienced contributors, including former GSoC participants who have become mentors themselves. Christian Couder continues coordinating Git's GSoC participation, which has successfully introduced new developers to the project while producing meaningful contributions. The announcement noted the selection process was challenging due to many qualified applicants, reflecting Git community's growing engagement with the program.
