This is a refactoring patch from Usman Akinyemi that moves remote group resolution logic from `builtin/fetch.c` to `remote.c` as part of the ongoing effort to add remote group support to `git push`. The change extracts three components that were previously static helpers in fetch.c - `get_remote_group()`, `add_remote_or_group()`, and the `remote_group_data` struct - making them available for reuse by other commands.

The refactoring was suggested by maintainer Junio Hamano to avoid duplicating this logic when implementing group push functionality. The patch cleanly separates the generic group resolution code from fetch-specific concerns, with no behavior changes - it just relocates the code and exposes it via remote.h. This enables the subsequent patch in the series to use the same helpers for push group resolution.

The implementation looks straightforward and well-contained, with comprehensive test coverage coming in later patches of the series. This appears to be a mechanical but necessary step in the overall feature implementation, following the project's preference for small, focused patches. The change has already gone through several review iterations and addresses all feedback received.
