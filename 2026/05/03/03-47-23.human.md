This is Junio Hamano's monthly "What's cooking in git.git" status report, providing a comprehensive overview of all active development topics in the Git project as of May 2026. The report categorizes patches into "New Topics" (recently proposed changes) and "Cooking" (longer-running efforts), indicating their stability and readiness for inclusion.

Key highlights from the new topics include:
- Patrick Steinhardt's "git history fixup" command addition
- René Scharfe's fix for `git grep --column --only-match` behavior
- A buffer size increase for pack operations by Stefan Beller
- Christian Couder's promisor-remote auto-configuration improvements
- Windows-specific fixes from Johannes Schindeler for large objects and maintenance deadlocks

Notable ongoing efforts in the "Cooking" section feature:
- Elijah Newren's ORT merge backend improvements for handling corrupt trees
- The continued `the_repository` removal effort across multiple subsystems
- Taylor Blau's work on incremental MIDX repacking
- Paul Tarjan's Linux fsmonitor implementation
- Adrian Ratiu's parallel hooks infrastructure (already merged to next)

The report shows Git's development remains active across multiple fronts - from core object storage improvements to platform-specific fixes and new commands. Several topics are marked as needing review or expecting rerolls, indicating ongoing collaborative refinement. The Rustification effort continues with xdiff cleanup work preparing for Rust integration, while the long-running `the_repository` removal persists as a major architectural change.

This snapshot captures Git's development at a transitional moment - with Git 2.54 recently released and the next cycle just beginning, many significant changes are in flight but not yet stabilized for the main branch.
