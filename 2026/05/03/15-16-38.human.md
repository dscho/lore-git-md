Bugfix for an uninitialized variable warning in `name-rev`. Ramsay Jones reports that the `seen` branch fails to build with DEVELOPER=1 due to a potential use of an uninitialized `commit` variable in `cmd_format_rev()`. The patch adds an explicit NULL initialization in the else branch of a conditional that checks a peeled tag object.

This appears to be a straightforward compiler warning fix for code that was recently introduced in Kristoffer Haugsbakk's `kh/name-rev-custom-format` branch (commit 5903855b1c). Ramsay notes the issue has since disappeared with the branch's removal, but suggests the fix be squashed into any future version of that work. The change is minimal and uncontroversial - just ensuring proper initialization of a variable that the compiler couldn't prove was always set before use.
