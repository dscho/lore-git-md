This is a platform compatibility issue affecting Git 2.54 builds on RHEL 6. The problem manifests when linking `git-imap-send`, which fails due to an OpenSSL 3.x symbol (`ASN1_STRING_get0_data`) that isn't available in the system's OpenSSL 1.0.x libraries.

The key symptoms are:
1. The build succeeds for Git 2.53 but fails for 2.54 on the same machine
2. The error occurs during linking of `git-imap-send` with an undefined reference to OpenSSL 3.0's `ASN1_STRING_get0_data`
3. There are also warnings about potential conflicts between OpenSSL 1.0.x and 3.x libraries

This appears to be a regression introduced in Git 2.54 where the IMAP send functionality started using newer OpenSSL APIs without proper fallback handling for older OpenSSL versions. The reporter is using OpenSSL 3.5.6 but the system still has OpenSSL 1.0.x libraries present, leading to the conflict.

The issue looks legitimate and affects a still-supported platform (RHEL 6), so it will likely need to be addressed either by:
1. Adding compatibility code for older OpenSSL versions
2. Making the IMAP send feature conditional on OpenSSL 3.x availability
3. Documenting the OpenSSL 3.x requirement more clearly
