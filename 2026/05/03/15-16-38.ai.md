Bugfix for a compiler warning in `name-rev` when built with DEVELOPER=1. The patch addresses a "may be used uninitialized" error for the `commit` variable in `cmd_format_rev()`. Ramsay Jones provides a straightforward fix by initializing the variable in an else clause, though he notes this is one of several possible solutions and suggests squashing it into Kristoffer Haugsbakk's earlier commit (5903855b1c) that introduced the issue. The fix is small and mechanical - exactly the sort of cleanup that often appears in response to compiler warnings in the Git codebase. The patch appears correct and uncontroversial, though its relevance depends on whether Kristoffer's original branch gets resubmitted.
