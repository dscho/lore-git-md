Thread summary:

This thread reports a build failure affecting Git 2.54 on RHEL 6 systems, specifically when linking `git-imap-send`. The error stems from an OpenSSL version mismatch - the IMAP code requires OpenSSL 3.0+ APIs (notably `ASN1_STRING_get0_data`) while the system has only OpenSSL 1.0.x libraries installed. The reporter observes that Git 2.53 builds successfully on the same system configuration, suggesting this is a regression introduced in 2.54. The build logs show library conflicts between newer OpenSSL 3.5.6 (which curl was built against) and the system's older OpenSSL 1.0.x libraries. No workaround or fix has been proposed yet, and it's unclear if this is part of a larger discussion about OpenSSL compatibility in enterprise Linux environments. The issue appears specific to RHEL 6 systems with outdated system OpenSSL packages.
