This is a follow-up from Elijah Newren, responding to Derrick Stolee's review of the final patch in the partial-clone prefetch optimization series for `git grep` -- the patch that is already in `next`.

Newren acknowledges Stolee's pathspec-filtering test suggestion and says it uncovered an actual bug: the code was unconditionally requesting downloads for blobs that matched the pathspec (or all blobs, if no pathspec was given), even when those blobs were already local. This is a quality-of-life improvement and a sign that the code was written correctly for the common case but sloppy around the edges. The mistake is understandable but would have been a real drag on performance for users who have some blobs local (e.g., after a previous search).
