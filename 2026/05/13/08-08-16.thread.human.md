This is a short, well-reviewed patch series that is essentially done. Chen Linxuan (taking over from Kohei Enami's v3) extends Git's `includeIf` config mechanism with `worktree:` and `worktree/i:` conditions, so that configuration can be conditionally included based on which linked worktree is active. In multi-worktree setups, the `gitdir:` pattern cannot distinguish between worktrees because they share a `.git` directory -- the new `worktree:` condition matches against the checkout path instead.

The series is two patches: a mechanical refactoring that renames `include_by_gitdir()` to `include_by_path()` and makes it take an explicit path argument, followed by the new feature itself. All prior v3 feedback from Patrick Steinhardt and Junio C Hamano has been addressed. Phillip Wood -- known for rigorous reviews -- has reviewed the v4 patch and given it a brief but meaningful green light ("Thanks for expanding the documentation - this looks good to me"), which effectively functions as an Acked-by. No issues were raised, and no open questions remain. The series is waiting for Junio to pick it up for `next`.
