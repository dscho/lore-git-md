This is a small, mechanical fix within the larger `--path-walk`/`--filter` integration series (patch 02/13). The patch adds `--objects` to the revision parameters when `--path-walk` is enabled, because the revision machinery will fatal-error with "object filtering requires --objects" when a filter is supplied without it. Up to this point `--objects` was implicitly assumed by the path-walk API and could be omitted, but the upcoming patches in this series will start passing filter options through the revision walk, so the explicit flag is now needed. The only other change is cleaning up a stale comment about "removing" options that were never actually present.

The patch is trivial -- one line added, one line kept, a stale comment removed. The commit message is clear and the change is obviously correct.
