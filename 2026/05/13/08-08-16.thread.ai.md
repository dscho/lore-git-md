**CORE PROBLEM OR GOAL**: Same as before: extend Git's conditional config inclusion mechanism (`includeIf` in `.gitconfig`) to support matching against the current worktree's working directory via a new `worktree:<pattern>` condition (with case-insensitive `worktree/i:<pattern>` variant), complementing the existing `gitdir:<pattern>` and `onbranch:<pattern>` conditions. In multi-worktree setups where a linked worktree's `.git` file points into the main repository's `.git/worktrees/<id>/` directory, `gitdir` patterns cannot distinguish worktrees by their checkout path.
