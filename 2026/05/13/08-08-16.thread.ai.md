**CORE PROBLEM OR GOAL**: Extend Git's conditional config inclusion (`includeIf` in `.gitconfig`) with `worktree:<pattern>` and `worktree/i:<pattern>` conditions that match against the working tree's checkout path, complementing existing `gitdir:<pattern>` and `onbranch:<pattern>`. In multi-worktree setups, linked worktrees share the same `.git` directory via `.git/worktrees/<id>/`, making `gitdir` patterns unable to distinguish worktrees by checkout path. A single global config like `[includeIf "worktree:/home/user/work/"] path = work.inc` now suffices.
