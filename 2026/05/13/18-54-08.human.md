Peff's own thought on Junio's cleanup suggestion. Peff agrees with the idea in principle but adds some practical notes.

He points out that the audit Junio proposed would be workable, with the caveat that anyone doing it should read through each function to make sure removing a `strbuf_grow()` call does not break something that depends on the buffer having been pre-sized -- for example, a function that writes into the buffer directly (bypassing `strbuf_addX()`) after the grow.

Peff then offers a concrete, satisfying example from `builtin/fast-import.c`, where removing the `strbuf_grow()` call also allows deleting the loop that computed `maxlen` in the first place -- dead code that existed solely to feed that pre-sizing. It is a nice demo of the kind of cleanup the broader effort would yield.
