This is a patch review iteration for a new `[includeIf "worktree:..."]` config condition, analogous to `gitdir`, that lets users include configuration based on which worktree they're in. Chen Linxuan is the author; Patrick Steinhardt is the reviewer.

The series is at v3, moving to v4. Two minor review points are accepted and will be fixed in the next version: deduplicating the documentation with the existing gitdir section, and adding a test for the "outside a repository" case.

The open question is whether the worktree condition will work with early-config parsing. It does not currently, unlike `gitdir` which does. Chen has a fix in progress but isn't sure whether this is a hard requirement before the series can land. If it ships without it, the asymmetry between `gitdir` and `worktree` conditions would be a lingering inconsistency. This is the only unresolved item as the series moves toward v4.
