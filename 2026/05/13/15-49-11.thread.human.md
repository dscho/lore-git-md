This is a cleanup patch from René Scharfe that introduces `strbuf_add_oid_hex()`, a new function to append an object ID's full hex representation directly to a `strbuf`. This replaces the existing `strbuf_addstr(sb, oid_to_hex(oid))` pattern, fixing two issues: thread-unsafety from `oid_to_hex()`'s static buffer, and an extra copy through an intermediate buffer. Jeff King (Peff) reviewed the patch positively, with his independent testing showing a ~3% speedup on an extreme case. The patch also includes a Coccinelle semantic patch to mechanically convert all 17 existing call sites across 14 files.

René then followed up with his own benchmarks using Peff's suggested extreme case, finding a consistent ~7-8% speedup on both Apple M1 and M5 systems. The thread is settled -- the patch has been authored, reviewed, tested independently by both Peff and René on multiple platforms, and is ready for Junio to pick up. No open questions or objections remain.
