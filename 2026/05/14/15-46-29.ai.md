This is a bugfix series addressing network address handling issues in Git's daemon mode. The patches fix three related problems in `daemon.c`:

1. IPv6 address corruption when `getaddrinfo()` returns IPv6 results but the code incorrectly assumes IPv4 and reads from the wrong struct offset. The fix properly handles both AF_INET and AF_INET6 address families.

2. IPv6 address truncation where the sockaddr struct size was incorrectly used as the output buffer size for `inet_ntop()`, causing silent truncation of long IPv6 addresses. The fix uses the proper buffer size constant.

3. A NULL pointer dereference when logging connection details if the REMOTE_PORT environment variable is unset. The fix adds a NULL check and fallback string.

The changes are focused on the network plumbing layer and affect how the Git daemon logs and processes client connection information. The fixes appear well-motivated and address clear correctness issues - the IPv6 handling problems could cause misbehavior on IPv6-only hosts, while the NULL pointer issue could lead to crashes. The series touches only `daemon.c` with straightforward changes that maintain the existing functionality while fixing the edge cases.
