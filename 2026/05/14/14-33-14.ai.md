This is a bugfix patch in the git-gui series addressing environment variable handling for bare repositories. The patch introduces centralized functions to safely manage GIT_DIR and GIT_WORK_TREE environment variables, fixing cases where empty GIT_WORK_TREE could cause fatal errors.

The key changes are:
1. Adds `set_gitdir_vars` proc that only exports GIT_WORK_TREE when non-empty
2. Adds `unset_gitdir_vars` proc that safely unsets both variables
3. Replaces direct environment manipulation with these new procs throughout git-gui.sh
4. Maintains backward compatibility while preventing empty GIT_WORK_TREE exports

This is part of a larger effort to make git-gui work properly in bare repositories and cases with missing worktrees. The patch specifically enables blame and browser subcommands to function in bare repos by avoiding the problematic empty GIT_WORK_TREE case. The changes are mechanical but important for correct behavior, replacing scattered direct environment manipulation with centralized, safer alternatives.
