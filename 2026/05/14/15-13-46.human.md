This is a performance optimization patch that improves overflow checking efficiency on Clang compilers. René Scharfe follows up on his earlier strbuf_grow refactoring by optimizing the underlying st_add()` helper function when built with Clang.

The patch introduces a Clang-specific implementation of `st_add()` that uses `__builtin_add_overflow()` instead of the existing `unsigned_add_overflows()` check. Benchmark results show a 5% speedup in `git cat-file` operations on an Apple M1 processor, where Clang's code generation for overflow checks was previously suboptimal. The change maintains identical safety guarantees while producing more efficient machine code.

This is a suggestion from Jeff King (Peff) and continues René's pattern of precise, low-level optimizations that improve performance without changing behavior. The patch is narrowly focused - it affects only Clang builds and leaves GCC behavior unchanged since GCC already generates optimal code for both approaches. The optimization is particularly relevant given the recent refactoring of strbuf_grow() to use st_add3(), making this a hot path in string-building operations.
