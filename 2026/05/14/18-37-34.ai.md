This is the first patch in a 7-part feature series finalizing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch splits out `struct odb_transaction` and related functions from the main ODB interface into new dedicated files `odb/transaction.{c,h}`.

The change is purely organizational - it moves the transaction-related code to its own module in preparation for expanding the transaction interface in subsequent patches. The patch updates all relevant callers to include the new header, including commands like `git add`, `git update-index`, and `git unpack-objects` that use ODB transactions.

This is a mechanical refactoring with no behavior changes, following the pattern seen elsewhere in the ODB abstraction work of splitting functionality into logical modules. The patch has already been reviewed in previous iterations of the series, with Patrick Steinhardt approving the technical direction and Jeff King having reviewed the resource management aspects.

The change affects core object-file handling but is low-risk since it's just moving code between files. It sets up the infrastructure needed for the more substantive transaction interface changes coming in later patches of this series.
