This is a refactoring patch that simplifies overflow checking in the strbuf_grow() function. René Scharfe replaces manual overflow checks with the existing st_add3() helper function, which performs the same checks while providing more detailed error messages when overflow occurs.

The change removes two explicit overflow checks that were previously guarding the ALLOC_GROW macro call. Instead, it consolidates the overflow protection into a single st_add3() call that adds sb->len, extra, and 1 (for the NUL terminator). The error message will now show the specific values that caused an overflow if one occurs.

This is a typical cleanup patch from René - small, focused, and improving code hygiene by using existing helper functions rather than open-coding similar logic. The change maintains the same safety guarantees while making the code more maintainable. The patch is part of an ongoing effort to standardize overflow checking patterns throughout the codebase.
