Subject: strbuf_grow overflow check refactoring and performance optimization
Author: René Scharfe
Thread type: code cleanup and performance improvement

René Scharfe's ongoing work to improve Git's overflow checking infrastructure. The thread began with a refactoring of strbuf_grow()'s overflow checking to use st_add3(), combining two validations into one call while maintaining safety. The new patch extends this by optimizing the underlying st_add() helper for Clang builds, using __builtin_add_overflow() to achieve 5% speedup on M1 hardware for strbuf-heavy operations like git cat-file --batch-all-objects. The optimization is Clang-specific (does not affect GCC) and was discussed with Jeff King (Peff), who provided the suggested approach. Both patches maintain identical overflow safety while respectively improving code clarity and performance. The changes are narrowly focused on core arithmetic primitives (st_add, st_add3) used throughout the codebase, following René's pattern of small, precise infrastructure improvements. No behavior changes beyond error message format and Clang-specific performance characteristics. The series exemplifies the project's ongoing effort to standardize and optimize low-level safety checks.
