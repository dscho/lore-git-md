This is the second patch in a bugfix series addressing network address handling issues in Git's daemon mode. The patch fixes IPv6 address truncation in logs by correcting the buffer size passed to `inet_ntop()`.

The issue occurs when converting socket addresses to strings - the code was incorrectly using the sockaddr struct size (28 bytes for IPv6) as the output buffer size, while the actual required buffer size for IPv6 addresses is 46 bytes (INET6_ADDRSTRLEN). This could silently truncate long IPv6 addresses in log messages. The fix uses the proper buffer size constant and simplifies the `ip2str()` function by removing the now-unused length parameter.

The changes are straightforward and focused - they maintain the existing functionality while fixing the edge case. This follows the first patch in the series which fixed IPv6 address corruption, and precedes a third patch addressing NULL pointer safety. The changes are limited to `daemon.c` and appear well-motivated, addressing a clear correctness issue in IPv6 logging behavior.
