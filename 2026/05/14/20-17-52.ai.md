Performance optimization and safety improvement for arithmetic overflow checking.

René Scharfe responds to Junio Hamano's suggestion about generalizing the overflow checking approach by proposing a new helper function `uint_add_overflow()`. This would replace the current `unsigned_add_overflows()` macro with a more robust implementation that both checks for overflow and computes the result in one operation, avoiding the potential for argument evaluation issues in macros.

The proposed solution introduces a type-generic overflow check that:
1. Validates the sum won't exceed the maximum value for the type
2. Computes the result if safe
3. Handles the result through an output parameter
4. Includes a macro wrapper `UINT_ADD_OVERFLOW` for cleaner calling syntax

This approach would address Junio's concern about argument evaluation while maintaining the safety guarantees of the current implementation. The patch shows how this would modify `st_add()` to use the new helper, demonstrating both the overflow check and result computation in a single operation.
