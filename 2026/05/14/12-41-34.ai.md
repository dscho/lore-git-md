This is **patch 7 of 8** in Derrick Stolee's `--negotiation-include` / `--negotiation-restrict` series (v4) -- the config counterpart to patch 6's CLI option, adding `remote.<name>.negotiationInclude`.

The patch adds a `remote.<name>.negotiationInclude` multi-valued config key that works as a mirror of patch 4's `remote.<name>.negotiationRestrict`. When no `--negotiation-include` flag is given on the command line, the config values (ref names, commit hashes, or glob patterns) resolve to commit tips that are always sent as "have" lines during fetch negotiation. The config is additive with the heuristic negotiator -- the algorithm still picks its own commits, but the config-specified refs are sent unconditionally on top. An empty value resets the list, letting a narrower scope override broader system/global config, matching the established `negotiationRestrict` behavior. If `--negotiation-include` *is* specified on the CLI, the config is ignored entirely (CLI takes precedence).

The implementation is straightforward and follows the exact pattern of its restrict counterpart: `handle_config()` in `remote.c` calls `parse_transport_option()` to store the key on the `remote` struct's new `negotiation_include` string list, and `prepare_transport()` in `builtin/fetch.c` feeds it into the same `add_negotiation_tips()` codepath. The documentation in `remote.adoc` and `fetch-options.adoc` is thorough, including the push-negotiation note. Test coverage adds three scenarios in `t5510-fetch.sh`: basic usage with empty-value reset (verifying `alpha_1` is excluded after reset), glob patterns against `refs/tags/beta_*`, and CLI override (showing `beta_2` from config is dropped when `--negotiation-include=beta_1` is given explicitly).

This is a well-motivated, mechanically consistent patch that completes the config surface for the include side of the feature. Like its restrict mirror, it follows the established pattern exactly -- no surprises, no design decisions to debate. It is the penultimate patch of the series; only the push-negotiation wiring remains.
