This is the second patch in a 7-part series finalizing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes transaction initialization pluggable by using the ODB source's callback rather than hardcoding the files backend implementation.

The change is straightforward - it replaces a direct call to `odb_transaction_files_begin()` with the new `odb_source_begin_transaction()` callback that was introduced in an earlier commit (d6fc6fe6f8). This allows different ODB backends to provide their own transaction implementations while maintaining the same interface.

The patch is a small but important piece of the larger ODB abstraction work, continuing the pattern of making the ODB interfaces more modular and backend-agnostic. With Patrick Steinhardt having approved the technical direction and Jeff King's earlier resource management concerns addressed in v4, this appears to be a well-vetted change that's ready for merging.
