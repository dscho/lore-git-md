This is a bugfix series addressing network address handling issues in Git's daemon mode. The patch series fixes three related problems in `daemon.c`:

1. IPv6 address corruption when `lookup_hostname()` incorrectly assumes IPv4 address format for all results from `getaddrinfo()`, leading to garbage output on IPv6-only hosts.

2. IPv6 address truncation in `ip2str()` where the buffer size passed to `inet_ntop()` was too small for full IPv6 addresses.

3. A potential NULL pointer dereference when logging connection details if the REMOTE_PORT environment variable is unset.

The changes are focused and well-explained, with each commit addressing a distinct issue in the network address handling code. The fixes appear straightforward and correct, though they would benefit from test coverage to prevent regression. This is particularly important for the IPv6 handling changes, which might not be routinely tested in all environments.

The series touches a relatively stable part of the codebase (daemon mode) that doesn't see frequent changes, so these fixes are likely to be uncontroversial. The author (Sebastien Tardif) isn't a regular contributor to Git, but the patches follow project conventions and appear technically sound.
