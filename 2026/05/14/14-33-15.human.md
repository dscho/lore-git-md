This is a refactoring patch in the git-gui bugfix series for bare repository handling. It extracts the repository picker logic into a dedicated `pick_repo` procedure, cleaning up the main repository discovery flow.

The change moves the picker code (which runs when no valid git repository is found) into a separate proc that:
- Clears GIT_DIR/GIT_WORK_TREE variables
- Loads configuration
- Invokes the repository picker UI
- Sets the repository path and prefix variables

This is a preparatory change that makes the code more modular and readable, paving the way for later patches in the series to add an explicit 'pick' subcommand. The patch maintains all existing behavior while making the control flow clearer. It's part of a well-reviewed series that's already reached consensus and appears ready for merging.
