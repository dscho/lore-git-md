This is a refactoring patch in the git-gui bugfix series for bare repository handling. It extracts the repository picker logic into a dedicated `pick_repo` procedure to improve code organization and prepare for future changes.

The patch moves the repository selection UI code (which runs when no valid Git repo is found) from inline in the main discovery block to a new `pick_repo` proc. This proc:
- Clears GIT_DIR/GIT_WORK_TREE environment variables
- Loads configuration
- Shows the repository picker dialog
- Sets the _gitdir variable based on user selection

The change is purely structural - no behavior is altered. It makes the main discovery logic easier to read and sets up for a planned 'pick' subcommand that would explicitly invoke this UI. The patch maintains all existing functionality while making the code more modular.

This is patch 4/11 in the v8 series that comprehensively fixes git-gui's handling of bare repos and worktree detection. The series has already undergone extensive review and is in its final form, with this patch representing a clean internal refactoring that supports the larger architectural improvements.
