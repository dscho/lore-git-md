This is the final patch in Justin Tobler's series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes the `write_object_stream()` functionality pluggable by introducing it as a callback in `struct odb_transaction`.

The key changes include:
- Adding a new `write_object_stream` callback to the transaction interface
- Renaming `index_blob_packfile_transaction()` to the more descriptive `odb_transaction_files_write_object_stream()`
- Wiring up the files backend implementation to use this callback
- Providing a public wrapper `odb_transaction_write_object_stream()`

This completes the transition to explicit transaction-based writes that the series has been working toward. The changes affect core object-file operations in commands like `git add` and `git update-index`. With Patrick Steinhardt's approval of the approach and Jeff King's resource management concerns addressed in v4, this series appears ready for merging as a significant step in enabling pluggable storage backends.

The patch maintains the careful attention to interface design and naming consistency seen throughout the series, with clear documentation of the new callback's expectations. This represents the culmination of the technical work started in earlier patches to refactor and extend the transaction interface for streaming writes.
