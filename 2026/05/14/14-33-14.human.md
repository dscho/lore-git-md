This is part 3 of an 11-patch bugfix series addressing git-gui's handling of bare repositories and missing worktrees. The series has gone through extensive review and iteration, with this version representing the consensus solution.

The specific patch introduces helper functions to safely manage GIT_DIR and GIT_WORK_TREE environment variables. The key changes are:

1. Adds `set_gitdir_vars` to conditionally export these variables (only setting GIT_WORK_TREE when it has a non-empty value)
2. Adds `unset_gitdir_vars` to safely unset them without errors if they don't exist
3. Replaces direct environment manipulation with these helpers throughout the code

This fixes a critical issue where empty GIT_WORK_TREE values would cause Git commands to fail, particularly affecting bare repository operations. The changes maintain backward compatibility while making the environment handling more robust.

The patch is part of a larger effort to make git-gui work correctly in all repository states (bare, non-bare, separate gitdir) and properly handle visualization features when no worktree is available. The series has received thorough review and appears ready for merging.
