This is the sixth patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch generalizes packfile writes to use the new `odb_write_stream` interface rather than operating directly on file descriptors.

The key change refactors `index_blob_packfile_transaction()` to accept a stream object instead of an fd, allowing more flexible data sources while maintaining the same packfile writing behavior. The implementation carefully preserves the existing error handling and hash computation logic while adapting it to the stream interface. This builds on previous patches that introduced the stream abstraction and optimized packfile handling.

The patch shows good attention to detail - it maintains the same buffer sizes, compression behavior, and error checking as the original code while making it more reusable. As with the rest of the series, Patrick Steinhardt has approved the technical direction and Jeff King's earlier review caught resource management issues that have since been fixed. This appears to be a solid incremental step toward the series' goal of enabling pluggable ODB backends.
