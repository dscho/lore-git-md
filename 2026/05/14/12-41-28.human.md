This is a tiny one-line bugfix patch, part 1 of 8 in Derrick Stolee's v4 series adding negotiation controls for fetch/push. It stands alone as a separate fix.

The patch fixes a test-ordering flakiness in t5516 introduced by commit 3f763ddf28 ("fetch: set remote/HEAD if it does not exist", 2024-11-22). The test was sorting `git for-each-ref` output on column 4, but that output only has 3 columns, meaning the sort depended on locale-specific behavior for records with fewer fields than the sort key expects. Changing `sort -k 4` to `sort -k 3` makes the sort key match the actual number of columns, producing deterministic results regardless of locale.

This is a small, mechanical, and clearly correct fix. The commit message explains the root cause -- an accidental column mismatch -- and the motivation (locale-dependent flakiness). The one-liner diff is about as minimal as it gets. Nothing controversial here; this is the kind of cleanup fix that should just go in.
