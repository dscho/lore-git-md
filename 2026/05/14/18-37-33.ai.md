This is version 4 of a feature patch series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort led by Justin Tobler and Patrick Steinhardt. The series makes ODB writes explicitly use the transaction interface rather than implicit redirection.

The key change in v4 is fixing a file descriptor leak in the loose object writing path that Jeff King identified in v3. The leak occurred when erroring out before `close_loose_object()` was called. This version closes the fd explicitly in the error path.

The 7-patch series refactors and extends the transaction interface to support streaming writes, particularly for large blobs. It splits out transaction-related code into new headers ("odb/transaction.h" and "odb/streaming.h"), makes transaction initialization pluggable, and introduces optimizations for packfile handling. The changes affect core object-file operations in commands like `git add` and `git update-index`.

With Patrick Steinhardt having approved the technical direction and Jeff King's resource management concern now addressed, this appears to be the final iteration before merging. The series represents a significant step in the multi-year ODB abstraction effort to enable pluggable storage backends.
