This is the second patch in Justin Tobler's 7-part series finalizing the write operations interface in Git's object database (ODB) abstraction effort. The patch transitions transaction initialization to use the pluggable `begin_transaction()` callback that was introduced in an earlier commit (d6fc6fe6f8).

The change is mechanical but meaningful - rather than hardcoding the files backend's transaction initialization via `odb_transaction_files_begin()`, it now uses the source-provided callback `odb_source_begin_transaction()`. This allows different ODB backends to provide their own transaction implementations while maintaining the same external interface.

The patch updates only two lines in `odb/transaction.c`, switching the include from "object-file.h" to "odb/source.h" and replacing the direct files backend call with the callback invocation. This is part of the broader architectural shift to make the ODB backend properly pluggable, with Patrick Steinhardt and Jeff King having already reviewed and approved the technical direction in previous iterations.

As the second patch in a well-reviewed series that has already addressed Jeff King's resource management concerns in v4, this change appears ready for merging as part of the larger ODB transaction interface completion.
