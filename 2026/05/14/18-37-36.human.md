This is patch 3/7 in a feature series finalizing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch refines the `struct odb_write_stream` interface to clarify buffer management and error handling.

The key change moves from a design where the stream callback returns a pointer to its internal buffer (making ownership unclear) to one where the caller provides the buffer and gets back a byte count or error. This makes the API more robust by eliminating potential buffer lifetime issues and adding proper error reporting. The patch also relocates the stream structure definition to a new "odb/streaming.h" header for better organization.

The changes affect `git unpack-objects` and other commands that stream objects into the ODB. While mostly mechanical, this interface improvement is an important step in the larger ODB abstraction work to support pluggable storage backends. The patch follows the same careful approach seen throughout the series, with clean separation of concerns and thorough updates to all call sites.

With Patrick Steinhardt having approved the technical direction and Jeff King's earlier resource management concerns addressed in v4, this iteration appears ready for merging. The series as a whole represents significant progress on the multi-year ODB abstraction effort.
