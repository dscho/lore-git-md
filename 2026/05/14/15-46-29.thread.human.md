This thread addresses a series of bugfixes for Git's daemon mode network address handling, specifically targeting IPv6 support issues and NULL pointer safety. The original author, Sebastien Tardif, has submitted three patches that: 1) properly handle IPv4/IPv6 address families, 2) fix IPv6 address truncation in logs, and 3) add NULL pointer safety for REMOTE_PORT logging. The series is now at v2, having incorporated feedback from both Junio C Hamano and Patrick Steinhardt.

The technical changes are well-contained within daemon.c and include proper sockaddr structure handling, correct buffer sizing for IPv6 addresses, and NULL checks for environment variables. Junio approved the technical approach, noting the thread continuity, while Patrick suggested splitting the original patch into three logical commits - a change the author implemented in v2. The final patch completes the series by adding a NULL check for REMOTE_PORT that mirrors the existing REMOTE_ADDR handling, using "?" as a fallback value.

With all identified issues addressed and positive reviews from both Junio and Patrick, this series appears ready for merging. The only remaining open questions are about IPv6-only configuration testing and whether to add explicit tests for the fixed cases - though these don't block the immediate correctness fixes. The changes are minimal, focused, and maintain backward compatibility while fixing clear bugs in the daemon's network plumbing.
