This is patch 4/7 in a series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch refactors blob writing to split the hash computation and object writing phases, preparing for the transaction interface changes in later patches.

The key change removes the `INDEX_WRITE_OBJECT` flag check from packfile writes, making them unconditional since the conditional behavior will be handled at a higher level. It introduces a new `hash_blob_stream()` helper for pure hash computation and updates the streaming interface with proper buffer management via `odb_write_stream_release()`.

The changes affect core object-file operations in commands like `git add` and `git update-index`. With Patrick Steinhardt having approved the technical direction and Jeff King's earlier resource management concerns addressed in v4, this appears to be a well-vetted step toward enabling pluggable storage backends. The patch maintains the series' careful attention to error handling and resource cleanup.
