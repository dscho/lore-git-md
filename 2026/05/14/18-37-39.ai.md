This is the 6th patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch generalizes packfile writes to use the new `odb_write_stream` interface rather than operating directly on file descriptors.

The key change refactors `index_blob_packfile_transaction()` to accept a stream interface instead of an fd, allowing more flexible data sources. The implementation:
- Replaces direct file reading with `odb_write_stream_read()`
- Adds proper size validation for streamed data
- Maintains existing compression and hashing behavior
- Updates callers to use the new interface

This builds on previous patches that introduced the stream interface and optimized packfile handling. With Patrick Steinhardt's approval and Jeff King's resource management concerns addressed in v4, this appears to be the final technical piece before merging the series. The changes affect core object writing paths in commands like `git add` and `git update-index`, completing a major step toward pluggable ODB backends.
