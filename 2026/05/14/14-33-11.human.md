This is a bugfix series for git-gui addressing several longstanding issues with repository and worktree detection. The patches come from Mark Levedahl, a core git-gui contributor, and represent the culmination of a multi-iteration discussion (v7 of the series) that has now reached consensus.

The series fixes git-gui's behavior in several problematic scenarios:
- Bare repositories (where git-gui previously failed with cryptic Tcl errors)
- Situations without accessible worktrees
- Separate git directory configurations
- The repository picker appearing unexpectedly
- Blame/browser subcommands failing when they should work

Key improvements include:
- Restructured startup sequence with dual-mode detection (blame/browser vs GUI/citool)
- Early bare repository detection after config loading
- Proper handling of .git directory behavior
- Removal of unsafe relative path fallbacks
- Better gitk visualization feature handling in bare repos
- More robust GIT_DIR/GIT_WORK_TREE handling
- Clearer error messages for failure cases

The series has been through seven iterations with input from multiple reviewers, including Johannes Sixt who confirmed the architectural soundness. With Mark Levedahl's final approval, these patches appear ready for merging and should significantly improve git-gui's reliability across different repository configurations.
