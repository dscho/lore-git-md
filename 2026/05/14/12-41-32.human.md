This is patch 5/8 in Derrick Stolee's v4 series adding `--negotiation-include` and `--negotiation-restrict` to fetch and push. It introduces a new `have_sent()` callback on the negotiator struct that solves the key design problem Cheetham identified in the v3 review.

The patch adds one function pointer to `struct fetch_negotiator` in `fetch-negotiator.h`: `have_sent()`. When called, it tells the negotiator that a particular commit has already been sent as a "have" outside the negotiator's own iteration loop. The negotiator can then treat that commit as already handled (marking it common in the default and skipping negotiators, or doing nothing in the noop negotiator), preventing it from being emitted again by `next()` and avoiding redundant work walking its ancestors. The implementation in each negotiator is small and mechanical -- about 7 lines per file, all of it straightforward bookkeeping.

This is the abstraction fix that makes the whole series work. In v3, Stolee had worked around the problem by marking included commits with the COMMON flag, which conflated "already known to the server" with "don't emit this because we already advertised it." That was a semantic hack that would have caused subtle correctness issues: marking a commit as common tells the negotiator to skip it *and* its ancestors during have selection, which is fine for commits the server actually knows about, but wrong for commits that were force-included purely for coverage. The `have_sent()` callback separates these two concepts cleanly: the negotiator marks the commit as shown but does not reach the wrong conclusion about the server's knowledge.

The commit message is clear and well-motivated, explaining both why the interface is needed and what each implementation does. For a plumbing patch this is the right length and tone -- it sets up the infrastructure without overselling it, simply noting that the logic will be exercised in the next patch (patch 6/8 adds `--negotiation-include`). A solid, well-scoped patch that is exactly what the series needed.
