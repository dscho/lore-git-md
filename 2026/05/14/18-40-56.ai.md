This is a refactoring patch targeting Git's trailer subsystem (commit message footers). René Scharfe eliminates an unnecessary allocation in `unfold_value()` by modifying the strbuf in-place rather than using a temporary buffer.

The function processes trailer values by replacing newlines and subsequent whitespace with single spaces (similar to `s/\n\s*/ /g`). The original implementation used a temporary strbuf for this transformation before swapping it with the input buffer. The new version works directly on the input strbuf, tracking both read and write positions to safely perform the transformation in a single pass.

The change is motivated by a performance optimization suggestion from Jeff King (Peff). The patch demonstrates René's characteristic attention to memory efficiency and clean code - a typical contribution style for him. Since the transformation never increases the string length, the in-place modification is safe and avoids the overhead of buffer allocation/copying.
