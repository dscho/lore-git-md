This is version 4 of a feature patch series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort led by Justin Tobler and Patrick Steinhardt. The series makes ODB writes explicitly use the transaction interface rather than implicit redirection, with a file descriptor leak fix being the key change in this iteration.

The 7-patch series refactors core object-file handling to support streaming writes, particularly optimizing large blob handling in packfiles. The changes affect commands like `git add`, `git update-index`, and `git unpack-objects`. This version specifically addresses a resource management issue identified by Jeff King in the previous round, where error paths in loose object writing could leak file descriptors.

With all major technical feedback now addressed - including Patrick Steinhardt's approval of the architecture and Jeff King's leak detection - the series appears ready for merging. The changes introduce new headers ("odb/transaction.h" and "odb/streaming.h"), optimize packfile handling by checking object sizes upfront, and rename key functions like `index_blob_packfile_transaction()` to better reflect their purpose.

This represents a significant milestone in the ODB abstraction work, completing the write-side plumbing needed for future pluggable storage backends. The careful iteration through multiple review rounds (now at v4) and responsiveness to feedback suggests this is production-ready code that maintains Git's stability while advancing the architectural vision.
