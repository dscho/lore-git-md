This is a refactoring patch targeting Git's trailer parsing code. René Scharfe simplifies the `unfold_value()` function in trailer.c, which handles folding multi-line trailer values into single lines by replacing newlines and subsequent whitespace with single spaces.

The change eliminates a temporary strbuf allocation by modifying the input strbuf in-place rather than building a new string and swapping it in. The optimization is safe because each replacement sequence (newline plus whitespace) is always replaced by a single space, never increasing the string length. The patch also removes redundant whitespace trimming steps.

This is a clean, focused improvement that follows René's typical pattern of small but thoughtful optimizations. The change was inspired by feedback from Jeff King (Peff) in a previous discussion, showing how the project's iterative review process leads to incremental improvements.
