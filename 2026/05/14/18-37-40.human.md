This is the final patch in Justin Tobler's feature series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes the `write_object_stream()` functionality pluggable by introducing it as a callback in `struct odb_transaction`, allowing different ODB backends to implement their own streaming write behavior.

The key changes include:
- Renaming `index_blob_packfile_transaction()` to the more descriptive `odb_transaction_files_write_object_stream()`
- Adding the new callback to the transaction struct
- Providing a public wrapper function `odb_transaction_write_object_stream()`
- Wiring up the files backend implementation

This builds on previous patches that refactored transaction handling and optimized packfile writes. With Patrick Steinhardt's approval of the approach and Jeff King's resource management concerns addressed in v4, this series appears ready for merging as a significant step toward pluggable ODB backends. The changes affect core object writing paths used by commands like `git add` and `git update-index`.
