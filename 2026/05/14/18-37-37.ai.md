This is part 4 of a 7-patch series implementing the write operations interface for Git's object database (ODB) transactions, a key piece of the ongoing ODB abstraction effort. The patch splits blob writing into two distinct phases - hash computation and actual writing - by introducing a new `hash_blob_stream()` helper function.

The change removes the conditional `INDEX_WRITE_OBJECT` flag handling from `index_blob_packfile_transaction()`, making the packfile writes unconditional. The flag check is moved up to `index_fd()`, which now either calls the full transaction write path or just the hash computation path. This prepares for integrating packfile writes into the transaction interface in subsequent patches.

The patch also adds infrastructure for streaming from file descriptors via `odb_write_stream_from_fd()` and proper cleanup with `odb_write_stream_release()`. These changes affect core object-file operations used by commands like `git add` and `git update-index`.

With Patrick Steinhardt having approved the technical direction and Jeff King's earlier resource management concerns addressed in v4, this appears to be a well-justified refactoring that maintains the series' clean separation of concerns while simplifying the interface. The changes are focused and mechanical, with clear commit message explanations of both the immediate changes and their role in the larger series.
