This is a design discussion about Pablo Sabater's `git log --graph` rendering improvement for root commits. Phillip Wood suggests an alternative approach to the visual separation of root commits in the graph output.

Phillip proposes using blank lines rather than indentation to distinguish unrelated root commits, arguing this would keep child commits visually grouped with their actual parents. His example shows:

```
* root-B

* child-A2
* child-A1
* root-A
```

This contrasts with Pablo's current approach which indents subsequent commits when they follow a root commit from a different lineage. Phillip's suggestion maintains the same vertical space but prioritizes parent-child grouping over column alignment.

The email is a late-stage design input on an already well-developed patch series (v3) that has addressed earlier technical concerns. Phillip's feedback focuses purely on the visual presentation aspect, not the underlying implementation. This suggests the technical approach (using `is_placeholder` flags) is sound, leaving only aesthetic preferences to resolve.
