This is the first patch in a 7-part series that completes the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch is a straightforward code organization change that splits out the ODB transaction interface from the main odb.{c,h} files into new dedicated files odb/transaction.{c,h}.

The change moves `struct odb_transaction` and related functions to their own header to keep the growing ODB interface manageable. This is a mechanical refactoring that doesn't change behavior - it just updates include paths and build system references to point to the new location. The patch affects several commands (`git add`, `git update-index`, `git unpack-objects`) and core components that use ODB transactions.

As the first patch in a well-reviewed series that has already gone through multiple iterations (now at v4), this change is low-risk and uncontroversial. It sets up the code structure needed for the more substantive transaction interface changes that follow in the series. Patrick Steinhardt (the ODB abstraction architect) has approved the technical approach, and Jeff King's earlier review feedback on resource management has been addressed in later patches.
