This is the third and final patch in a bugfix series addressing network address handling issues in Git's daemon mode. The patch fixes a NULL pointer dereference that could occur when logging connection details if the REMOTE_PORT environment variable is unset.

The change is straightforward - it adds a fallback string ("?") when REMOTE_PORT is NULL, matching the existing safety check for REMOTE_ADDR. This prevents undefined behavior from passing NULL to printf's %s format specifier. The fix is minimal (just a one-line change) and clearly motivated by the potential crash risk.

With this patch, the series now addresses all three identified issues in `daemon.c`:
1. IPv6 address corruption in hostname lookup
2. IPv6 address truncation in logs
3. NULL pointer safety for REMOTE_PORT logging

The changes appear well-contained to the network plumbing layer and maintain existing functionality while fixing edge cases. The series looks ready for review, though testing on IPv6-only configurations would help verify the fixes.
