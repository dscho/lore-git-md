This is the third and smallest patch in a bugfix series addressing network address handling issues in Git's daemon mode. The patch fixes a NULL pointer dereference that could occur when logging connection details if the REMOTE_PORT environment variable is unset. The change is straightforward - it adds a fallback string ("?") when port is NULL, matching the existing addr check in the same log statement.

The fix is minimal (a one-line change) and clearly correct, addressing a real undefined behavior case. While the impact is limited to logging (not affecting core functionality), it's a clean completion to the series' goal of hardening the daemon's network address handling. The patch maintains consistency with the existing code by using the same "?" placeholder seen elsewhere in Git for unknown/missing values.

With this patch, the series now fully addresses the three identified issues: IPv6 address corruption, IPv6 logging truncation, and NULL pointer safety in logging. The changes remain focused on `daemon.c` with no broader implications for other subsystems.
