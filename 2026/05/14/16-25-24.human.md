This is the third iteration of Elijah Newren's performance optimization series for partial clone behavior in `git cherry` and `git grep`. The series addresses two key improvements:

1. Adding batch prefetching to `git cherry` to avoid hundreds of individual blob fetches when comparing commits in partial clones
2. Extending similar prefetching to `git grep` as a related optimization

The v3 changes include:
- A new documentation patch clarifying the promisor-remote filtering contract
- A fix to avoid re-downloading blobs that are already present locally (discovered independently by the author)
- Pathspec filtering test cases for `git grep` as suggested by Derrick Stolee

The implementation follows established patterns from other commands that support batch prefetching (checkout/diff/merge). The changes are well-contained, touching only the relevant builtin files and adding new test cases. The optimizations should provide measurable performance benefits for partial clone users of these commands.

The thread shows productive technical discussion between Newren and Stolee about architectural decisions, with Newren providing a detailed rationale for keeping the prefetch logic local to each builtin rather than centralizing it at this time. The series appears ready for integration after these final improvements.
