Documentation patch adding a missing long option to `git merge`'s man page.

Brandon Dong notices that while `git merge` accepts both `-m` and `--message` for specifying a commit message (matching `git commit`'s behavior), only the short `-m` form is documented. This patch adds the long option to the man page for consistency.

The change is straightforward - a one-line addition to `Documentation/git-merge.adoc` to document the existing `--message` flag alongside `-m`. The patch appears correct and well-motivated, though quite minor in scope. It follows the pattern seen in other commands where both short and long forms of options are documented together.
