This is the fifth patch in a v3 series introducing the `diff.<driver>.process` feature, which allows external tools to inject diff hunks into Git's diff and blame pipelines. The series is progressing toward finalization, with this patch focusing on compatibility and bypass mechanisms.

The patch makes two key improvements to the diff process integration:

1. **`--no-ext-diff` bypass**: Extends the existing `--no-ext-diff` flag to also disable the new diff process mechanism, treating it consistently with the older `diff.<driver>.command` approach. The implementation replaces a simple OPT_BOOL with an OPT_CALLBACK to coordinate both settings.

2. **format-patch safety**: Automatically disables the diff process when generating patches via `format-patch`, ensuring the output uses Git's built-in diff algorithm for reliable application by recipients who may not have the external tool.

The changes come with documentation updates and new test cases verifying the bypass behavior. This addresses an important use case - generated patches should not depend on external tools that recipients might lack. The implementation maintains the series' careful approach to backward compatibility while adding sensible guardrails.
