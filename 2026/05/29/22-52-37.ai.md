This is a documentation follow-up in the thread about Git's handling of small Unix timestamps. Junio C Hamano responds to Luna Schwalbe's suggestion to document the `@` prefix workaround for specifying very old dates (like Unix epoch 0).

Junio confirms the `@` prefix syntax was introduced in 2012 (116eb3ab and 2c733fb2) specifically to handle ancient timestamps without conflicting with YYYMNDD formats, but notes this feature was never documented. He suggests `Documentation/date-formats.adoc` would be the right place for this addition and invites Luna to submit a patch.

The exchange shows the maintainer validating the documentation gap while keeping focus on the practical solution (`@` prefix) rather than the underlying parsing inconsistency.
