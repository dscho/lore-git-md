This is a performance-focused follow-up in the ongoing discussion about integrating `--path-walk` with bitmaps and delta-islands in `git pack-objects`. Derrick Stolee shares benchmark results from testing Taylor Blau's patch series, providing concrete data on how the changes affect packfile sizes and operation speeds.

The benchmarks show mixed results - path-walk mode produces significantly larger packfiles (up to 17x) for small fetches but shows modest improvements for larger operations (20-40% speedups on 64-128 day ranges). Stolee notes the path-walk logic overrides bitmap logic in the baseline comparison, and that without path-walk enabled, the new code shows no regression from current behavior.

The email raises an important open question about why path-walk doesn't show more dramatic improvements in these test scenarios, particularly for repositories known to benefit from path-walk optimizations. Stolee's testing methodology appears thorough, using both the Git repository itself and Microsoft's fluentui repo as test cases. The results suggest the series is safe from a performance regression standpoint but leave room for further optimization of the path-walk/bitmap interaction.
