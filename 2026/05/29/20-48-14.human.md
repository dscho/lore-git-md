This is the first patch in a series introducing a new `diff.<driver>.process` configuration that allows external tools to inject diff hunks into Git's diff and blame pipelines. The patch adds core xdiff infrastructure to support externally computed hunks.

The key changes in this version include:
- New `xdl_hunk` struct to represent diff hunks from external tools
- Validation logic for hunk bounds, ordering, and synchronization
- Fallback to built-in diff on validation failure
- Skip of tail trimming when using external hunks (since they reference original line numbers)
- New `xdl_clear_changed()` helper for resetting diff state

The implementation appears thorough, with careful attention to edge cases and validation. The patch lays the foundation for the rest of the series which will introduce the actual protocol and integration with Git's diff and blame commands. This is part of an effort to enable structural/AST-based diffs while preserving Git's existing diff display features.

The patch has comprehensive test coverage (mentioned in the thread context) and addresses previous review feedback about validation and error handling. It's a technically sound foundation for the feature being proposed.
