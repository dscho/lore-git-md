This is a follow-up in the thread about Git's date parsing behavior for small Unix timestamps. Luna Schwalbe responds to Kristoffer Haugsbakk's discovery that using an `@` prefix (like `@0 +0000`) works as a workaround for the timestamp issue.

The email suggests documenting this workaround in `Documentation/date-formats.adoc` to help others encountering the same problem. This moves the discussion from bug identification toward documentation improvement, though the underlying technical inconsistency between environment variables and `--date` option handling remains unresolved.

The exchange confirms the `@` prefix syntax bypasses the problematic code path, reinforcing that the bug appears limited to numeric parsing of small timestamps. While not a fix, this workaround provides a practical solution for users needing to specify very old dates in Git operations.
