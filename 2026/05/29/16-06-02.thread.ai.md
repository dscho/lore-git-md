Performance optimization for index-pack's delta resolution. Arijit Banerjee's patch series addresses an inefficiency where index-pack prematurely freed reconstructed delta base objects still needed for child delta resolution, forcing redundant reconstruction. The core change removes a single `free_base_data()` call to leverage the existing delta base cache.

The change remains minimal - still just removing one function call - but now better justified with performance measurements.
