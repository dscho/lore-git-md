This is the foundational patch in a series introducing `diff.<driver>.process` support, enabling external tools to inject diff hunks into Git's diff and blame pipelines. The patch adds core xdiff infrastructure to accept pre-computed hunks via new `xpparam_t` fields (`external_hunks` and `external_hunks_nr`), bypassing Git's built-in diff algorithm when provided.

Key technical aspects:
- Introduces `struct xdl_hunk` to represent externally supplied diff hunks with 1-based line numbers
- Adds validation logic for hunk bounds, ordering, and synchronization invariants
- Skips `trim_common_tail()` when using external hunks since they reference original line numbers
- Falls back to built-in diff on validation failures
- Adds `xdl_clear_changed()` helper to reset diff state between attempts

The changes are focused on xdiff internals, laying groundwork for the higher-level diff-process protocol that will be built on top in subsequent patches. The validation ensures external hunks maintain Git's diff invariants while allowing specialized tools (like AST-based diff tools) to participate in the pipeline.

This is a well-structured patch with clear focus on the xdiff layer, keeping the interface minimal while providing robust validation. The fallback behavior maintains compatibility when external hunks fail validation. The changes are localized to xdiff with no impact on higher-level Git code yet.
