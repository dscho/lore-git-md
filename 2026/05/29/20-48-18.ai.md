This is the fifth patch in a v3 series introducing the `diff.<driver>.process` configuration, which allows external tools to inject diff hunks into Git's diff and blame pipelines. The patch focuses on bypassing the diff process in specific scenarios.

The key changes in this patch are:

1. Makes `--no-ext-diff` disable both `diff.<driver>.command` and `diff.<driver>.process` for consistency, since both involve external tools. The implementation replaces a simple OPT_BOOL with an OPT_CALLBACK to handle both flags together.

2. Forces format-patch to always use the builtin diff algorithm by setting `no_diff_process`, ensuring generated patches can be applied by recipients without the external tool.

3. Documents that `--diff-algorithm` also bypasses the diff process (a behavior that was already implemented but not documented).

4. Adds tests verifying the bypass behavior for both `--no-ext-diff` and format-patch cases.

The changes are straightforward and well-justified, maintaining compatibility with existing workflows while ensuring reliable patch generation. The patch follows the series' pattern of thorough test coverage (adding 16 lines of new test cases) and clear documentation updates.

This continues the series' progression toward finalization, addressing one of the remaining integration points by ensuring the new feature works properly with Git's existing diff control mechanisms.
