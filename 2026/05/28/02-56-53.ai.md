This is the third version of a bugfix series addressing network address handling issues in Git's daemon mode (`daemon.c`). The series is now complete with all three patches:

1. Fixes IPv6 address corruption in `lookup_hostname()` by properly handling both AF_INET and AF_INET6 address families when `getaddrinfo()` returns results.

2. Corrects IPv6 address truncation in `ip2str()` by using the proper buffer size constant (INET6_ADDRSTRLEN) rather than the sockaddr struct size.

3. Adds NULL pointer safety for REMOTE_PORT environment variable in `execute()` logging, matching the existing protection for REMOTE_ADDR.

Changes in v3 are minimal, focused on improving the commit message for patch 3/3 to clarify that while the NULL check is technically redundant (since REMOTE_ADDR and REMOTE_PORT are set together), it serves as defensive programming against future changes. The actual code changes remain the same as in v2.

The series has received positive reviews from both Junio C Hamano and Patrick Steinhardt in previous iterations, with all suggested improvements incorporated. The technical approach is sound and the changes are confined to `daemon.c` with no protocol or on-disk format changes. While IPv6-only testing remains outstanding, the fixes address clear correctness issues and the series appears ready for merging.
