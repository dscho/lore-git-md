This is version 3 of a 3-patch series that refactors how `git log -L` (line-log) integrates with Git's diff output pipeline. The series has already been through two rounds of review and is now in its final form, addressing all substantive feedback.

The key improvement in v3 is a minor test syntax fix - changing `! test_grep` to the more conventional `test_grep !` pattern in several test assertions. This was the last remaining nit from the v2 review. The author has also committed to documenting test helper patterns in a future series, as this inconsistency was noted as a project-wide issue.

The core technical work remains unchanged from v2:
- Patch 1 reorders revision setup to properly handle default output formats
- Patch 2 routes line-log` through the standard `log_tree_diff()` pipeline
- Patch 3 enables non-patch diff formats (`--raw`, `--name-only`, etc.) while still blocking stat formats

The series now cleanly unifies line-log output with Git's standard diff processing while maintaining all existing functionality. It fixes several long-standing inconsistencies where `-L` bypassed features like pickaxe filtering and diff formatting options. The changes demonstrate careful attention to both technical correctness and review feedback, making this a well-structured improvement to the line-log machinery.

With all feedback addressed and only a test syntax tweak in v3, this series appears ready for merging. The discussion has also helpfully surfaced a broader project need around test helper documentation that will be addressed separately.
