This is the first patch in a completed bugfix series addressing network address handling issues in Git's daemon mode. The patch fixes IPv6 address corruption in `lookup_hostname()` by properly handling both AF_INET and AF_INET6 address families when processing results from `getaddrinfo()`.

The key changes are:
1. Checking `ai_family` to determine the address type (IPv4 or IPv6)
2. Extracting the correct address pointer from the appropriate sockaddr struct
3. Passing the proper address family to `inet_ntop()`
4. Adding a safety check to die() on unexpected address families

The fix prevents garbage IP addresses from being produced on IPv6-only hosts where the code was previously reading from the wrong struct offset. The changes are confined to `daemon.c` and maintain the existing behavior for IPv4 while adding proper IPv6 support.

This version (v3) incorporates all maintainer feedback from previous iterations, with the technical changes remaining the same as in v2. The series has received positive reviews and appears ready for merging.
