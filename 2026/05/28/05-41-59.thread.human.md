This thread is about a bugfix series for `git rebase --update-refs` that handles edge cases involving symbolic references (symrefs) to branches or other refs. The series, now at its third version (v3) and authored by Son Luong Ngoc, addresses failures that occur when symrefs—like a `main` branch pointing to `master` or a symref pointing to a tag—are present during rebase operations. These issues particularly affect branch rename migrations and cross-worktree workflows.

The current version of the series is functionally complete and has been under active review. Phillip Wood’s latest feedback refines earlier suggestions, focusing on a potential bug in the HEAD comparison logic and requesting minor test organization tweaks. Erik Cervin-Edin confirmed that v3 resolves a regression from v2, where the current branch was incorrectly skipped due to `branch_checked_out()` behavior, but also identified a pre-existing bug in `master` where the `head_ref` buffer is clobbered during HEAD resolution, causing unexpected entries in the rebase todo list in multi-worktree setups. Junio C Hamano recently weighed in, agreeing with Phillip’s suggestion to use the resolved symref target (`resolved_ref`) instead of the symref name (`decoration->name`) for HEAD comparison, but raised a broader question about whether the code should even handle cases where HEAD points outside `refs/heads/` (e.g., to a tag). This introduces a design consideration for future iterations.

The series touches `sequencer.c` and `branch.c`, with test coverage in `t3404-rebase-interactive.sh`. It ensures symrefs are resolved safely, skips updates for symrefs targeting branches under `refs/heads/`, and prevents cross-worktree conflicts. While all technical concerns from prior reviews have been addressed, the latest feedback—including Junio’s question—may lead to further refinements in a v4. No merge status has been reported, and the latent `head_ref` bug in `master` is likely to be addressed separately. Key participants include Phillip Wood, Erik Cervin-Edin, and Junio, all of whom have provided substantive feedback.
