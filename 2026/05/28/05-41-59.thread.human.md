This thread addresses a bug in `git rebase --update-refs` where symbolic references to branches (like `main` pointing to `master`) caused rebase failures. The author submitted a two-patch series that first demonstrated the issue with a failing test and then provided the fix, converting the test to expect success. The implementation carefully handles symref resolution while maintaining all the safety checks of the original `--update-refs` feature.

Kristoffer Haugsbakk reviewed the series, noting that while the technical solution is correct, the project prefers combining regression tests with their fixes in a single patch rather than splitting them across commits. This is a stylistic point about patch organization, not a critique of the underlying fix. The core functionality—properly handling symrefs during rebase operations—remains uncontested and appears ready for merging. The author may want to follow the single-patch approach for similar fixes in the future, but no changes to this series are needed.
