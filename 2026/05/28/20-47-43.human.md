This is version 3 of a 3-patch series that integrates Git's line-log functionality (`-L`) with the standard diff output pipeline. The series has already been through two rounds of review and is now in its final form, addressing all substantive feedback.

The key improvement in this version is a minor test syntax fix - changing `! test_grep` to the more conventional `test_grep !` pattern in the test suite. This follows up on a style consistency point raised in the v2 discussion. The core technical changes remain the same as v2:

1. The series restructures how `git log -L` processes diffs to flow through Git's standard `log_tree_diff()` pipeline rather than taking a separate shortcut path. This fixes several inconsistencies where line-log output behaved differently from regular log output.

2. It enables support for non-patch diff formats (`--raw`, `--name-only`, `--name-status`, `--summary`) with `-L`, while still blocking stat formats (like `--stat`) which would show whole-file statistics rather than range-scoped ones.
