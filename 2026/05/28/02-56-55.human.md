This is the second patch in a completed bugfix series addressing network address handling issues in Git's daemon mode (`daemon.c`). The patch specifically corrects IPv6 address truncation in logging by fixing the buffer size passed to `inet_ntop()`.

The key change replaces the incorrect use of `ai_addrlen` (the sockaddr struct size) with `sizeof(ip)` (the actual buffer size) when calling `inet_ntop()`. This ensures IPv6 addresses aren't silently truncated in logs. The patch also simplifies the `ip2str()` function signature by removing the now-unused length parameter, updating all callers accordingly.

This is the third iteration (v3) of the series, which has already received positive reviews from both Junio C Hamano and Patrick Steinhardt. The changes are straightforward and well-contained to `daemon.c`, with no protocol or on-disk format implications. The series appears ready for merging, addressing clear correctness issues in the daemon's network plumbing.
