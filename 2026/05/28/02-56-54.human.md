This is the first patch in a completed bugfix series addressing network address handling issues in Git's daemon mode. The patch fixes IPv6 address corruption in `lookup_hostname()` by properly handling both AF_INET and AF_INET6 address families when processing results from `getaddrinfo()`.

The issue occurs because the code was unconditionally casting the address to IPv4 format (sockaddr_in) even when IPv6 addresses were returned, leading to garbage output on IPv6-only hosts. The fix adds proper family checking and extracts the correct address pointer before calling `inet_ntop()`. It also adds a safety check to die() on unexpected address families.

This is the third iteration of the patch, with all previous feedback incorporated. The changes are well-contained within `daemon.c` and have been reviewed positively by both Junio C Hamano and Patrick Steinhardt. The series appears ready for merging, addressing clear correctness issues in the daemon's network plumbing.
