This is the second patch in a two-part cleanup series removing deprecated functions from commit.h. It follows through on deprecations planned since Git 2.53.0, now that all in-flight uses have been migrated.

The patch removes three deprecated inline functions from commit.h that were marked for removal: `copy_commit_list()`, `reverse_commit_list()`, and `free_commit_list()`. These have direct modern equivalents (`commit_list_copy()`, `commit_list_reverse()`, `commit_list_free()`) that were already used in the first patch of the series to update all callers.

Patrick Steinhardt, who originally authored both the old and new versions of these functions, has acked the removal - a strong social signal that this cleanup is uncontroversial. The author has verified there are no remaining uses in the integration branches. This is a mechanical, well-vetted change that follows Git's standard deprecation workflow.
