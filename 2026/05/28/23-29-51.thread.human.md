Jacob Keller has fixed a bug in `git describe` where the `--match` and `--exclude` options weren't being properly handled when used with `--contains` and `--all`. The documentation stated these options should work together, but the implementation was silently ignoring the patterns in `--all` mode. 

The fix ensures `git describe` correctly passes the patterns to the underlying `git name-rev` command, with the appropriate ref prefixes (refs/tags, refs/heads, refs/remotes) depending on whether `--all` is used. The patch includes four new tests that verify the corrected behavior across different combinations of these options with branches and tags. This appears to be a clean, well-tested fix for a clear inconsistency between the documented and actual behavior.
