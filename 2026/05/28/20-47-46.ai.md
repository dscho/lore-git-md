This is the third and final patch in Michael Montalbo's series to integrate `git log -L` (line-log) with Git's standard diff output pipeline. The patch enables support for metadata-only diff formats (`--raw`, `--name-only`, `--name-status`, and `--summary`) with `-L`, while still blocking stat formats that would show whole-file statistics rather than range-scoped ones.

The changes include:
- Updating documentation to clarify which formats are now supported
- Modifying the format allowlist in `revision.c` to permit the new formats
- Adding comprehensive tests verifying the new format works as expected while stat formats remain blocked

The patch builds on the previous refactoring work in the series to properly flow line-log output through Git's standard processing pipeline. It demonstrates careful attention to edge cases, including testing the new formats with root commits and verifying the error messages for unsupported formats. With this change, line-log now properly integrates with Git's diff machinery while maintaining clear boundaries around what makes sense for line-oriented history.

This completes the technical goals of the series, which has already been merged into the `next` branch after addressing all review feedback. The discussion also surfaced a broader need for test helper documentation that will be addressed in future work.
