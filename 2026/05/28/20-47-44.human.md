This is the first patch in a 3-part series that integrates Git's line-log functionality (`-L`) with the standard log output pipeline. The series has already been through two rounds of review and is now in its final form.

The patch moves the line-log setup code earlier in the revision setup sequence to ensure the default `DIFF_FORMAT_PATCH` output is properly registered before the diff output flag is computed. This is a necessary preparation for the next patch which will route line-log output through the standard `log_tree_diff()` path. The change is purely mechanical with no behavior change on its own.

The author (Michael Montalbo) has addressed all previous review feedback, including fixing test syntax in v3 to use the more conventional `test_grep !` pattern. The series is now ready for merging and represents a well-structured improvement to Git's line-log machinery, fixing long-standing inconsistencies where `-L` bypassed features like pickaxe filtering and diff formatting options.
