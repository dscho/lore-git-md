Platform compatibility fix for Windows path handling in wildmatch tests.

Kristofer Karlsson from Spotify identifies an issue where 36 tests in t3070-wildmatch.sh fail on Windows due to backslash handling differences. On Windows (MINGW), backslashes in pathspecs get converted to forward slashes before reaching the wildmatch function, altering the intended glob semantics for patterns like '\[ab]' and '[A-\\]'.

The patch skips these problematic ls-files test variants on platforms where BSLASHPSPEC isn't set (which includes Windows), using the existing prereq system. This matches the test suite's established approach for platform-specific behavior, where wildmatch function itself works correctly but the ls-files path has different semantics.

The change is straightforward - it adds BSLASHPSPEC as an additional prerequisite for tests containing backslash patterns. This maintains test coverage where the behavior is meaningful while avoiding false negatives on Windows. The patch appears well-targeted to the specific issue without broader implications.
