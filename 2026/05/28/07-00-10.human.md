This is the first patch in a two-part series removing deprecated functions from commit.h, part of ongoing codebase maintenance. The patch mechanically replaces calls to the deprecated `free_commit_list()` with its modern equivalent `commit_list_free()` across three files: builtin/history.c, replay.c, and upload-pack.c.

The changes are straightforward replacements with no behavioral impact, following through on deprecations planned since Git 2.53.0. The patch has received an explicit ack from Patrick Steinhardt, who originally authored both the old and new APIs, providing strong validation that this cleanup is complete and uncontroversial. The second patch in the series will remove the deprecated function declarations entirely from commit.h.

This appears to be a well-vetted, low-risk cleanup that follows Git's standard deprecation workflow. The author has done due diligence checking for remaining uses in integration branches, and the changes touch only internal callers that have already been updated to the modern equivalents.
