Event announcement.

Taylor Blau (GitHub) and Scott Chacon (GitButler) have opened ticket sales for **Git Merge 2026**, to be held **September 17-18** at Suspenso in Lisbon, Portugal, with a dedicated **JJ Day** on September 16. Main conference tickets are $99 USD; a combined ticket with JJ Day is $129, and a JJ-only ticket is $49. Git and JJ contributors can email Taylor off-list for a free registration code; Git contributors also get access to the **Contributor's Summit** on the 18th. The **Call for Proposals** is now open through **June 30**, using a single form for both Git Merge and JJ talks. Requests for travel assistance can be sent to the Git PLC at `git@sfconservancy.org` until **May 15**, with decisions shortly after.
