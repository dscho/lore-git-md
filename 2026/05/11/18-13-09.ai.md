Part of `[PATCH v3 12/12]` in a 12-patch series, this is the capstone patch that adds `combine` filter support to the `--path-walk --filter` machinery. Authored by Taylor Blau (with Derrick Stolee as co-signer, though this is noted only in the trailers).

The implementation is straightforward and well-architected. The key insight is that every supported child filter is a monotonic restriction, so intersecting them via `path_walk_info` is natural: `blob:none` and `tree:0` simply clear flags that may already be clear; `object:type=blob+object:type=tree` ANDs the type flags down to zero; `blob:limit` takes the minimum of its child values; `sparse:oid` is allowed at most once and refuses overwriting.

The main structural change is splitting `prepare_filters()` into a recursive `prepare_filters_one()` helper plus a thin wrapper that releases the top-level filter once after all children have been processed. This avoids the problem of releasing child filters prematurely when recursing into `LOFC_COMBINE` -- the parent's `list_objects_filter_release` already handles the recursive release. Unsupported sub-filters bubble a failure up, triggering the existing fallback to standard revision walking.

Test coverage is solid: four new tests in `t6601-path-walk.sh` cover the `blob:none+tree:0` intersection (collapsing to `tree:0`), `object:type=blob+blob:limit=3` (emitting only small blobs), a disjoint `object:type=blob+object:type=tree` (resulting in empty output), and rejection of `tree:1` as an unsupported sub-filter. The documentation in `git-pack-objects.adoc` is updated to mention the `combine:<spec>+<spec>` form.

This is a clean, well-motivated patch that closes the series logically. The `combine` filter is the natural composition point for all the per-type support added in patches 7-11. The recursive split of `prepare_filters()` is a minimal and correct refactoring. No test gaps or edge cases jump out. The series as a whole has received no review discussion so far, which is unusual for a change of this size, but the quality is high.
