This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics as of May 2026. The report covers topics that have graduated to 'master', new topics proposed for inclusion, and ongoing work still under review.

Several significant features have recently graduated to 'master':
- Parallel execution of hook scripts (Adrian Ratiu)
- Rust support enabled by default (brian m. carlson)
- Promisor remote handling refactoring (Christian Couder)
- Cache-tree validation fixes (David Lin)
- Test suite improvements for `set -e` compatibility (Patrick Steinhardt)
- Lisp dialect support in userdiff (Stefan Beller)

New topics proposed for 'next' include:
- Removal of nedmalloc from Windows builds (Johannes Schindelin)
- Fix for submodule.fetchJobs configuration (Shourya Jha)
- Proxy URL scheme validation (Amin Nimaj)
- Branch pruning of merged branches (Harald Nordgren)
- New `git url-parse` command (Michał Majcher)

Notable ongoing work includes:
- Refactoring of refs backend code (D. Ben Knoble)
- `git history fixup` command (Patrick Steinhardt)
- Handling of large (>4GB) objects on Windows (Johannes Schindelin)
- Path-walk integration with object filters (Derrick Stolee)
- In-memory ODB source implementation (Patrick Steinhardt)
- Linux fsmonitor daemon (Paul Tarjan)

The report also notes several documentation updates, test improvements, and platform-specific fixes in progress. Junio indicates which topics are likely to proceed to 'next' and which need further review or revision before being considered for inclusion.
