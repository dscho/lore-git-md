This is a conference announcement, not a code patch. Taylor Blau announces that tickets are now on sale for **Git Merge 2026**, to be held September 17-18 in Lisbon, Portugal, at the venue Suspenso. This is the annual in-person gathering for the Git community, featuring talks, social events, and a Contributor’s Summit.

Tickets are $99 USD, with an optional add-on for a “JJ day” (focused on the Jujutsu version control system) on September 16, available for an additional $30 ($129 total) or standalone at $49. Git and Jujutsu contributors can email off-list for a free ticket; for Git contributors, this also registers them for the Contributor’s Summit on September 18.

The call for proposals is open through June 30, with a single submission form covering both Git Merge and JJ day talks. Financial assistance for travel is available through the Git PLC at Software Freedom Conservancy, with requests due by May 15. The announcement is co-signed by Scott Chacon (GitButler) and Taylor Blau (GitHub).
