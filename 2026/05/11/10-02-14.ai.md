This is a CI configuration discussion concluding the strategy for running expensive tests (including the >4GB object tests from Johannes Schindelin's Windows platform series). Patrick Steinhardt and Junio C Hamano agree on simplifying the CI setup by making expensive tests run unconditionally across all CI events, including GitLab CI and non-standard workflows.

The exchange confirms the resolution of earlier discussions about conditional test execution. Junio acknowledges the appeal of Patrick's proposal to remove conditional execution entirely, accepting the increased resource usage as a worthwhile tradeoff for broader test coverage. Both dismiss the alternative approach of limiting expensive tests to specific platforms, doubting that the bugs they catch would be platform-specific.

This represents a policy shift from the previous strategy of running expensive tests only on official branches and pull requests. The decision aligns with the project's ongoing effort to balance thorough testing against CI resource constraints, particularly for platform-specific issues like Windows' 32-bit type limitations. The change will be implemented in the final patch (11/11) of Schindelin's series.
