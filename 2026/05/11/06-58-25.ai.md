Feature: Bulk branch deletion improvements in the finalized branch pruning series.

This is patch 2/5 in Harald Nordgren's v5 series implementing standalone branch pruning functionality. The patch modifies the branch deletion machinery to better support bulk operations when pruning branches with deleted upstreams.

Key changes:
1. Adds `warn_only` parameter to suppress error messages and advice for individual branch deletions during bulk operations
2. Adds `n_not_merged` counter to track skipped branches without verbose output
3. Preserves all safety checks (unmerged work protection) while making bulk operations less noisy
4. Maintains existing behavior for single-branch deletions (full error messages and advice)

The implementation cleanly extends the existing `delete_branches()` and `check_branch_commit()` functions while keeping the core safety mechanisms intact. The changes are focused on improving the bulk operation experience when used with the new `--forked` and `--prune-merged` functionality from the series.

This patch represents a straightforward quality-of-life improvement for the new branch pruning commands, reducing noise while maintaining safety. The series continues to progress toward finalization with this refinement to the bulk deletion interface.
