This is the third patch in Kristoffer Haugsbakk's v5 series introducing the new `git format-rev` command. It's a refactoring patch that prepares the codebase for sharing functionality between the existing `git name-rev` and the upcoming `git format-rev` commands.

The patch introduces a new `command` struct with a tagged union to handle command-specific payloads, currently only supporting the `NAME_REV` type. It factors out the `name_rev_line` function to make it reusable, while maintaining the same behavior through the command dispatch mechanism. The changes include:

1. Adding the `command` struct and `init_name_rev_command` helper
2. Modifying `name_rev_line` to use the command struct instead of direct `name_ref_data` access
3. Implementing a switch statement for command dispatch in the line processing logic
4. Updating the main command function to initialize and pass the command struct

The patch follows good refactoring practices by:
- Keeping the changes mechanical and behavior-preserving (no functional changes)
- Adding clear documentation of the intent in the commit message
- Maintaining clean separation between the refactoring and feature work
- Including notes about review feedback addressed from previous versions

This is a well-structured preparatory patch that cleanly separates concerns in anticipation of the new command's implementation in patch 5. The changes show attention to maintainability while keeping the diff focused and understandable.
