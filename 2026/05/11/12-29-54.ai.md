This is a two-patch series from Patrick Steinhardt addressing issues in Git's maintenance mode functionality. The series targets two specific problems:

1. The first patch fixes a locking issue that occurs when running maintenance with the `--detach` flag. Currently, the maintenance process fails to properly release its lock file when running in detached mode, which can cause subsequent maintenance runs to fail.

2. The second patch ensures that auto-maintenance (triggered via `gc.auto`) properly respects the configured `gc.auto` threshold. The current implementation doesn't correctly check whether the number of loose objects exceeds this threshold before running maintenance tasks.

The changes touch core functionality in `builtin/gc.c` and `run-command.c`, with corresponding updates to the lockfile API (`lockfile.c/h`) and setup code. The series includes extensive test coverage in `t/t7900-maintenance.sh`, adding 95 lines of new test cases to verify both fixes.

This appears to be a well-scoped maintenance improvement series addressing clear bugs in existing functionality. Given Patrick's track record with the maintenance subsystem and the thorough test coverage, these changes are likely to be uncontroversial. The patches build on Git 2.54.0 and include all necessary context about the reported issues.
