This thread is about a simple cleanup patch that removes an unused `commit` field from `struct todo_add_branch_context` in `sequencer.c`. The field was being written to during rebase `--update-refs` operations but never read — the commit is passed directly to `add_decorations_to_list()` when needed. The author found it during code inspection and proposed its removal as a single, self-contained patch.

Patrick Steinhardt reviewed the patch and confirmed the field has actually been dead code since the struct was first introduced in 2022 — it was never read, even from the beginning. He offered only a single surface-level nit: after removing the assignment, the remaining `if` block could lose its braces per Git coding guidelines, since the assignment was the only statement in it. He explicitly noted this is not worth a reroll. No substantive concerns about correctness or behavioral impact were raised.

The patch has no opposition, no outstanding requests, and no competing proposals. It appears ready to be picked up by the maintainer as-is; the braces adjustment, if desired, could be handled as part of applying the patch.
