This is a follow-up discussion in the CI configuration thread regarding when to run expensive tests (including the >4GB object tests from Johannes Schindelin's Windows platform series). The exchange between Junio Hamano and Patrick Steinhardt considers whether to make expensive tests run unconditionally across all CI events.

Junio acknowledges the appeal of Patrick's suggestion to simplify the configuration by removing conditional execution entirely. He notes this would provide broader test coverage at the cost of increased resource usage, which he considers an acceptable tradeoff given that machine cycles are cheaper than human debugging time. Junio also considers but rejects the opposite extreme of limiting expensive tests to specific platforms, doubting that the bugs they catch would be platform-specific.

The discussion reflects the project's ongoing effort to balance thorough testing against CI resource constraints, particularly for platform-specific issues like Windows' 32-bit type limitations. Junio's response suggests he is leaning toward Patrick's proposal for unconditional execution, though no final decision is recorded here. This would represent a shift from the current strategy of running expensive tests only on official branches and pull requests.
