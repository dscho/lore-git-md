**Thread identity**: Two-patch v2 bugfix series from Patrick Steinhardt fixing maintenance mode issues in Git. Series at v2; the only substantive change from v1 is the type correction in patch 2. Targeting Git 2.54.0.

**Core problem/goal**: Correct two maintenance subsystem issues: (1) lockfile release in `git maintenance run --detach` mode causing stale locks that block subsequent runs, and (2) restore expected `gc.auto` integer-threshold behavior after the transition from `git gc` to `git maintenance` while maintaining backward compatibility. The `gc.auto` regression has a detailed root cause: when the default maintenance strategy stopped shelling out to `git gc`, the code path that previously hit `git gc`'s own config check was broken; the newer `maintenance.auto` was the only key checked, so `gc.auto=0` no longer suppressed automatic maintenance. The fix reads `maintenance.auto` first (takes precedence), falling back to `gc.auto` as an integer when unset. If `gc.auto` is 0 or negative, maintenance is disabled.
