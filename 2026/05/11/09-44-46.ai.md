Harald Nordgren's v6 patch series completes the branch pruning functionality with a key refinement: `--prune-merged` now measures merged-ness against the remote's default branch rather than the candidate's upstream. Key technical changes in v6:
1. Merged-ness is now determined by comparing against the remote's default branch (via `refs/remotes/<remote>/HEAD`) rather than the candidate's specific upstream branch

3. Additional test cases verifying the independence from local HEAD position
4. Completion of the `--all-remotes` flag functionality for both `--forked` and `--prune-merged`

The implementation handles edge cases gracefully:
