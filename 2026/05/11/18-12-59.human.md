This is a small preparatory patch in the 12-patch `--path-walk --filter` integration series from Derrick Stolee and Taylor Blau. It fixes a crash: when you pass a filter like `blob:none` together with `--path-walk`, the revision machinery bails with "object filtering requires --objects". The fix is simply to add `--objects` to the revision parameters that `--path-walk` sets up.

The commit message notes that `--objects` was already implicitly assumed by the path-walk API, so this is really about satisfying the rev-list option checker rather than changing behavior. It also tidies up a stale comment that talked about "removing" options that had never been added in the first place.

This is a straightforward, mechanical fix -- the kind of thing that tends to turn up when you start composing features. It is not interesting on its own, but it is correct and necessary for the rest of the series.
