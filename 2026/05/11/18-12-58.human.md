This is a preparatory patch for a larger series, the first of 12 in v3 of the `--path-walk --filter` integration. It's authored by Derrick Stolee.

The change is small and mechanical: it sets `GIT_TEST_PACK_PATH_WALK=0` in three tests in `t5620-backfill.sh` that run `git backfill` with pathspecs. The issue is that `GIT_TEST_PACK_PATH_WALK` is a test variable that enables `--path-walk` on `git pack-objects` by default, but in the current state `--path-walk` and `--filter` are incompatible and produce a warning over stderr that these tests check for (`test_must_be_empty err`). Disabling the test variable in these specific locations prevents spurious test failures until the rest of the series makes the two options work together.

This is straightforward housekeeping: a one-line environment override per test, with a comment explaining why. No behavioral change, no controversy.
