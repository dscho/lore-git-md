This is the final patch in Harald Nordgren's v6 series introducing safe branch pruning functionality via standalone `git branch` commands. The patch adds the promised `--all-remotes` flag, which allows operating on all configured remotes rather than requiring explicit remote arguments.

The implementation:
- Adds `--all-remotes` flag that works with both `--forked` and `--prune-merged`
- Rejects the flag when used without one of those main operations
- Includes comprehensive tests verifying multi-remote scenarios
- Maintains all existing safety checks (checked-out branch protection, per-branch opt-out)
- Updates documentation to reflect the new flag

The changes are cleanly integrated with the existing branch command infrastructure, using `for_each_remote()` to collect all remote names when the flag is specified. Error handling remains robust - the command still validates any explicit remote arguments even when `--all-remotes` is used.

This completes the series' functionality, providing a full solution for identifying and safely pruning branches whose upstreams have been deleted. The implementation stays true to the architectural decision to keep this as a standalone branch operation rather than integrating with fetch.
