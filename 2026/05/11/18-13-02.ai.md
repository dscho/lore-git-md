This is patch 05/12 of Derrick Stolee and Taylor Blau's `--path-walk --filter` integration series. It adds support for the `blob:none` filter to the path-walk API, which is a common use case at scale -- users with blobless partial clones who have `pack.usePathWalk=true` were previously hitting a warning that `--path-walk` and `--filter` are incompatible, falling back to the slower walk.

The technical approach is straightforward. A new `prepare_filters()` function in `path-walk.c` checks the filter type; for `LOFC_BLOB_NONE` it simply sets `info->blobs = 0` (skipping all blob objects) and releases the filter options so `prepare_revision_walk()` does not reject the configuration. The same function is exposed as `path_walk_filter_compatible()` so `builtin/pack-objects.c` can check compatibility before the walk starts. Unsupported filter types produce an error and return 0. The three `t5620-backfill.sh` workarounds that disabled `GIT_TEST_PACK_PATH_WALK` are reverted, confirming the incompatibility is resolved. New tests in `t6601-path-walk.sh` verify the walk emits no blobs (only commits, tags, and trees) for `blob:none --all` and for a single-branch walk. A minor fix in the test helper replaces `REV_INFO_INIT` with `repo_init_revisions()` to properly initialize the filter strbuf needed for parsing.

The most interesting bit of data is in the performance test: the path-walk path is 73% slower on this repo (23.43s vs 13.51s) but produces a packfile that is 16% smaller (115.2M vs 137.7M). Stolee frames this as a meaningful space benefit at the cost of two compression passes, which is an honest tradeoff worth noting for users deciding whether to enable this.

This is a clean, well-motivated patch that does exactly what it says and is a natural prerequisite for the more interesting filter types (sparse, tree:0, combine) that follow. The documentation in `git-pack-objects.adoc` is updated to remove `--filter` from the list of incompatible options (though notably it still says "Whe" instead of "When" -- a typo). No review comments or objections have appeared.
