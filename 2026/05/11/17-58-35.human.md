This is a bugfix review from Jeff King (Peff) addressing a file descriptor leak in Justin Tobler's ODB write stream implementation. The issue occurs in the error path when reading from an object stream - if the read fails, the function jumps to cleanup without closing the file descriptor that was opened earlier.

The fix is straightforward - either close the descriptor at the error site or ensure the cleanup handler properly closes it. This is a small but important correctness issue in the streaming interface that was caught by Coverity static analysis. The patch being reviewed is part of a larger series (v3 3/7) that refines Git's object database write operations as part of the ODB abstraction effort.

Peff's review is substantive - he identifies a real resource leak and suggests two concrete ways to fix it. The feedback is timely as the series has just hit Junio's integration branch ("jch"), meaning this should be addressed before final merging. This continues the pattern of thorough review this series has received from both Peff and Patrick Steinhardt.
