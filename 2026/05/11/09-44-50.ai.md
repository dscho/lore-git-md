Feature: Per-branch opt-out for merged branch pruning in v6 series.

This patch introduces a `branch.<name>.pruneMerged` configuration option that allows specific branches to be exempted from `git branch --prune-merged` operations, even when using the `--force` flag. The opt-out is designed for topic branches that may need to persist between development cycles while still allowing explicit deletion via `git branch -d`.

The implementation adds configuration checking in the pruning logic, with clear messaging when branches are skipped due to the setting. The patch includes comprehensive test coverage for:
- Basic opt-out behavior
- Interaction with `--force` flag
- Preservation of explicit deletion capability
- User feedback when skipping protected branches

The changes maintain all existing safety mechanisms while adding this new layer of control. Documentation updates clearly explain the new configuration option and its relationship to other branch operations. This completes the functionality set for the branch pruning feature while preserving the architectural separation from fetch operations that was established earlier in the series.

The patch fits cleanly into the v6 series, which has already addressed all maintainer feedback and appears technically complete. The implementation is consistent with the project's focus on providing robust, configurable branch management tools while maintaining clear safety boundaries.
