This is a feature patch for the `git-jump` contrib script, which helps navigate Git changes in an editor. The patch makes the script more user-friendly by automatically selecting the most likely mode when run without arguments.

The change adds logic to detect two common scenarios:
1. When there are unmerged paths (selects "merge" mode)
2. When there are unstaged changes (selects "diff" mode)

If neither condition is met, it falls back to the existing behavior of showing usage and exiting. The patch includes corresponding documentation updates explaining the new behavior.

The implementation is straightforward, using existing Git plumbing commands (`git ls-files -u` and `git diff --quiet`) to detect the repository state. The change maintains backward compatibility while adding a quality-of-life improvement for interactive use.
