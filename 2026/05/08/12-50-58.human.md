This is patch 3/6 in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows builds. The series addresses GCC 16 compatibility issues with the unmaintained nedmalloc code, which Git for Windows has already replaced with mimalloc.

This patch removes the core nedmalloc` implementation files from the `compat/nedmalloc/` directory, including the license, readme, and source files. The removal is split across multiple patches due to mailing list size limits - this one handles the smaller auxiliary files while follow-up patches will remove the large `malloc.c.h` file in chunks.

The commit message clearly explains the mechanical nature of this change, noting it's part of a logical single deletion that's only split for practical reasons. The patch follows the series' established pattern of first disabling usage (patch 1), removing build system references (patch 2), and now deleting the implementation.

The changes are straightforward deletions with no functional impact since nedmalloc was already disabled. The patch appears well-structured and properly motivated as part of the overall removal effort.
