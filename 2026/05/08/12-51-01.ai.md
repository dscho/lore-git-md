This is the final patch in Johannes Schindelin's series removing the unmaintained nedmalloc allocator from Git's Windows builds. The patch completes the deletion of the implementation by removing the core malloc.c.h file (1827 lines) from the compat/nedmalloc directory.

The change follows the structured approach established in earlier patches: first disabling usage (patch 1), then removing build system references (patch 2), and now deleting the implementation files. This final deletion was split across three patches (4-6) due to mailing list size constraints, with explicit squashing instructions provided for integration.

The removal is motivated by GCC 16 compatibility issues (new -Wunused-but-set-variable warnings) and the fact that Git for Windows has used mimalloc as its default allocator for years, making nedmalloc obsolete. The changes are low-risk since the code being removed was already unused in production builds.

With this patch, the series is now complete and ready for integration. The mechanical nature of the changes and clear dependency ordering make this a straightforward removal with no outstanding technical concerns. The only remaining question is whether to squash the split deletion patches as requested or use a direct repository pull for the large file deletion.
