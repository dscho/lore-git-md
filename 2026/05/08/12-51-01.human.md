Platform compatibility patch completing the nedmalloc removal series from Johannes Schindelin (Dscho). This is the final patch in the v3 series that fully deletes the unmaintained nedmalloc allocator code from Git's Windows builds.

The patch removes the remaining 1827 lines of nedmalloc implementation from `compat/nedmalloc/malloc.c.h`, following the structured removal approach established in earlier patches. This completes the deprecation path that began when Git for Windows switched to mimalloc years ago. The change addresses GCC 16 compatibility issues with the outdated nedmalloc code while maintaining the same runtime behavior (since mimalloc was already in use).

The patch is marked to be squashed into patch 3/6 during integration, as requested by Junio Hamano in previous feedback. No technical concerns remain - this is a straightforward deletion of obsolete code that has already been disabled in earlier steps. The series demonstrates careful attention to dependency order and integration mechanics while removing the legacy allocator.
