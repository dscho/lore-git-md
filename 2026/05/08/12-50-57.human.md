This is the second patch in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows builds. Following the first patch that disabled nedmalloc usage, this one cleans up the build system references across multiple files:

- Removes all Makefile rules and variables related to nedmalloc, including the `USE_NED_ALLOCATOR` option and associated compiler flags
- Deletes the commented-out nedmalloc configuration in `config.mak.uname`
- Eliminates a nedmalloc reference in the VSCode settings file
- Updates the meson build configuration to exclude nedmalloc files

The changes are straightforward mechanical removals now that nedmalloc is no longer used. The patch maintains the series' logical progression - first disabling the feature, then removing its infrastructure. This continues the work to fully excise the unmaintained allocator that was causing GCC 16 compatibility issues, building on Git for Windows' earlier switch to mimalloc.
