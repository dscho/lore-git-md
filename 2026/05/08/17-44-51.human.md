This is a follow-up in the ongoing Rustification build system discussion, specifically about linking the git-credential-osxkeychain helper with Rust libraries. Shardul Natu (Google) responds to Koji Nakamaru's alternative approach, agreeing it's cleaner and implementing the suggested changes.

The key technical point is that wrapping RUST_LIB usage in `ifndef NO_RUST` blocks allows the same variable to be used directly without introducing a separate RUST_LIBS variable, while maintaining the universal build support for macOS. The patch demonstrates this works by:
1. Conditionally including RUST_LIB definitions
2. Keeping the lipo-based universal build logic Rust-aware only when needed
3. Simplifying the link line to use RUST_LIB directly

This appears to resolve Junio Hamano's earlier concern about variable duplication while preserving all functionality. The implementation looks technically sound, though the broader architectural question about Rust build system patterns remains open for further discussion among build system experts.
