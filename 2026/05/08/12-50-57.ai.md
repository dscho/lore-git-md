This is the second patch in Johannes Schindelin's v3 series removing the nedmalloc allocator from Git's Windows builds, following up on the first patch that disabled its usage. The patch systematically removes all build system references to nedmalloc across the Makefile, config.mak.uname, meson.build, and VS Code configuration.

The changes are mechanical and straightforward, deleting:
- The USE_NED_ALLOCATOR build option and related compiler flags
- The nedmalloc source file inclusion from THIRD_PARTY_SOURCES
- Platform-specific configuration in config.mak.uname
- A VS Code spellcheck exception for "nedmalloc'ed"
- The meson.build exclusion rule for the nedmalloc directory

As noted in the commit message, this prepares for the upcoming pure file deletion of the compat/nedmalloc/ directory by first removing all build system dependencies on it. The patch maintains the series' careful progression - first disabling usage, then removing references, before finally deleting the implementation files in subsequent patches.

No new technical discussion has emerged since the parent summary, and the changes align with the established approach of completely removing the unmaintained allocator rather than just disabling it. The patch appears uncontroversial and ready for integration.
