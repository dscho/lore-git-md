Bugfix for `rebase --update-refs` handling of non-branch decorations. This v2 patch from Abhinav Gupta addresses an edge case where using `rebase.instructionFormat` with `%d` (show decorations) could incorrectly generate `update-ref` instructions for non-branch refs like HEAD.

The fix filters decorations to only process `DECORATION_REF_LOCAL` types, preventing invalid instructions while maintaining correct behavior for legitimate branch updates. The patch incorporates Phillip Wood's review feedback from v1 by simplifying the test case - it now verifies the complete `update-ref` list rather than checking individual patterns, and removes redundant branch checks.

The change is small and focused, with the test providing clear coverage of both the edge case (ignoring HEAD/tags) and normal operation (updating branches). This appears ready for merging as a straightforward correctness fix for the relatively new `--update-refs` feature. No new technical concerns have emerged since v1, and the author has addressed the review feedback.
