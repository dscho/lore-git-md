This is a platform compatibility patch series finalizing the removal of the unmaintained nedmalloc allocator from Git's Windows builds. The series has now reached its third iteration with all technical aspects settled - Patrick Steinhardt's brief reply indicates he's happy with the current state and supports moving forward.

The core motivation remains GCC 16 compatibility issues with the vendored nedmalloc code failing to build with new compiler warnings. Since Git for Windows already switched to mimalloc years ago (with benchmarks showing no significant advantage over platform allocators), the series takes the opportunity to completely excise nedmalloc rather than just disable it.

The v3 series incorporates maintainer feedback by clearly marking the squash intention for the final deletion patches (4-6), which were split only due to mailing list size constraints. With no outstanding technical concerns and positive review from Patrick (who works closely with the Windows ecosystem through GitLab), this appears ready for integration. The change represents the logical conclusion of nedmalloc's deprecation path that began with Git for Windows' earlier allocator switch.
