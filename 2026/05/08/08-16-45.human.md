This is a test infrastructure patch in Johannes Schindelin's series addressing Windows platform issues with large objects (>4GB). Patch 7/11 optimizes the test-synthesize helper to use faster, non-collision-detecting SHA-1 hashing when generating large test packs.

The change responds to Jeff King's observation that the 4GB+ test cases were dominating test suite runtime (160+ seconds vs 90s for the rest). By switching to `unsafe_hash_algo()` for known test data generation, the patch achieves a 3.5-4x speedup on supported platforms (21s vs 75s for 4GB packs). The optimization is safe since the helper generates deterministic test data where collision resistance isn't needed.

The patch maintains compatibility - builds without accelerated SHA-1 (like default Windows) fall back to the regular implementation. This is a pragmatic optimization that significantly improves test performance while remaining transparent to most developers.
