This is part 4/6 of Johannes Schindelin's platform compatibility patch series removing the nedmalloc allocator from Git's Windows builds. This chunk deletes the first portion (2235 lines) of the large `malloc.c.h` implementation file from the `compat/nedmalloc` directory.

The deletion is mechanical and straightforward - it simply removes the file contents while preserving the file itself (as indicated by the diff showing the file still exists but is now nearly empty). This is one of three split deletions for this large file due to mailing list size constraints, with the commit message noting it should be squashed into patch 3/6 during integration.

The removed code was the core implementation of the nedmalloc allocator, including:
- Memory management primitives and chunk representations
- Locking infrastructure for thread safety
- Platform-specific mmap/munmap implementations
- Size alignment and boundary tag handling
- Bit manipulation for tracking chunk states

Since Git for Windows has already switched to mimalloc and the prior patches disabled nedmalloc usage, this deletion is the logical next step in completely removing the unmaintained allocator. The change is low-risk as the code hasn't been active in the Windows build for some time.
