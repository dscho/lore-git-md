# Build system adjustment for Rust-enabled osxkeychain helper

Junio C Hamano provides maintainer feedback on Shardul Natu's patch to link the git-credential-osxkeychain helper with Rust libraries. While acknowledging the technical correctness of the change, Junio raises two concerns: first, he notes the author's name inconsistency between the From header ("Shnatu") and the Signed-off-by line ("Shardul Natu"), expressing a preference for consistency. Second, he questions the need for both RUST_LIB and RUST_LIBS variables, suggesting the relationship between them isn't clearly explained in the patch.

The patch itself remains unchanged from the previous version - it's a straightforward build system tweak to ensure proper linking when Rust is enabled. Junio has CC'd additional reviewers who may have more expertise in this area, indicating he wants more eyes on the variable naming question before proceeding. This suggests the patch may need another revision to address these concerns before being ready for inclusion.
