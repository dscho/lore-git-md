# Maintainer feedback on Rustified osxkeychain build

Junio C Hamano provides maintainer feedback on Shardul Natu's patch to link the git-credential-osxkeychain helper with Rust libraries. While acknowledging the patch's technical correctness, Junio raises two higher-level concerns.

First, he gently suggests the author use their full name ("Shardul Natu") rather than the abbreviated "Shnatu" in both From and Signed-off-by lines, following project preference though not strictly requiring it. Second, and more substantively, he questions the relationship between RUST_LIB and RUST_LIBS variables, noting the apparent duplication and unclear separation of concerns between them. He CCs additional reviewers who may have more context on the build system's Rust integration patterns.

The feedback indicates the patch may need clarification around the variable design before proceeding, though no functional issues are identified with the actual linking change. This moves the discussion from the previous surface-level review (which focused on commit message clarity) to a more architectural consideration of how Rust library dependencies should be modeled in the build system.
