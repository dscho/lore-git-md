This is the first patch in Johannes Schindelin's v3 series removing the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds. The patch disables nedmalloc usage across all build systems (Makefile, CMake, and Meson) in preparation for its complete removal in subsequent patches.

The commit message thoroughly documents the motivation: nedmalloc hasn't been updated since 2014 and now fails to build with GCC 16 due to a new `-Wunused-but-set-variable` warning. Since Git for Windows already switched to mimalloc years ago with no performance regression, this patch takes the opportunity to fully deprecate nedmalloc rather than just patching the warning.

The changes are mechanical but carefully coordinated - this first patch only disables the allocator while leaving the code in place, allowing the actual deletion to happen in dependency order across the series. The patch appears well-tested, noting successful builds against a GCC 16-upgraded Git for Windows SDK. This represents the first step in completing the nedmalloc deprecation path that began with Git for Windows' earlier mimalloc adoption.
