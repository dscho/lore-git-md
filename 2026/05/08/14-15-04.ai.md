The discussion here is purely about repository mechanics - how to represent this large deletion cleanly in the project history while respecting mailing list size constraints.

No new technical issues are raised; this is a brief optimization suggestion from an experienced contributor (Peff) to the maintainer (Junio) about integration logistics.
