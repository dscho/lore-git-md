This is a platform compatibility patch series from Johannes Schindelin, completing the removal of the unmaintained nedmalloc allocator from Git's Windows (MINGW) builds. The v3 iteration incorporates maintainer feedback and prepares for final integration.

The series addresses a GCC 16 compatibility issue where the vendored nedmalloc code fails to build with new compiler warnings. Since Git for Windows already switched to mimalloc years ago (with benchmarks showing no significant advantage over platform allocators), the series fully removes nedmalloc rather than just patching it.

Key changes in v3:
- Reworded the last 4 patches as suggested by Junio to clearly indicate they should be squashed during integration
- Maintains the same technical approach of first disabling nedmalloc usage, then removing build system references, and finally deleting the source files
- The large malloc.c.h deletion remains split across three commits due to mailing list size constraints, but now explicitly marked for squashing

The patch structure demonstrates careful consideration of both technical dependencies and mailing list practicalities. With Junio's suggested integration approach and no outstanding technical concerns, this appears ready for final merging to resolve the GCC 16 build issue.
