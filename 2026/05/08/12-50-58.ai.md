This is the third patch in Johannes Schindelin's series removing the nedmalloc allocator from Git's Windows builds. The patch deletes the actual nedmalloc implementation files that were made obsolete by previous patches disabling its usage.

The change removes four files from the `compat/nedmalloc/` directory:
- License.txt (Boost license)
- Readme.txt (implementation details and changelog)
- nedmalloc.c (core allocator code)
- nedmalloc.h (public interface)

The commit explains this is part of a logical single deletion that had to be split across multiple patches due to mailing list size limits (the large malloc.c.h file will be removed in subsequent patches). The commit message clearly marks the follow-up patches as "to be squashed" per Junio's earlier suggestion.

This is a straightforward deletion of unused code that follows the deprecation path already taken by Git for Windows (which switched to mimalloc years ago). The change is mechanical and low-risk since the code was already disabled in the previous patches. The patch maintains the careful, structured approach seen throughout this series.
