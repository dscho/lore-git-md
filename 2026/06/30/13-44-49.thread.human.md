The Git mailing list has received a call for contributions to the upcoming **Git Rev News edition 136**, the project’s monthly newsletter. Christian Couder has shared a draft of the edition, which is available [on GitHub](https://github.com/git/git.github.io/blob/master/rev_news/drafts/edition-136.md), and is inviting the community to help refine it before publication on **July 2, 2026**.

The draft is open to edits, suggestions, or additions from anyone in the community—whether it’s fixing typos, adding links, proofreading, or volunteering for interviews. Contributions can be submitted via GitHub pull requests or by replying directly to the email. Christian also noted that while he tried to CC all contributors mentioned in the edition, some may have been missed. The GitHub issue tracking this edition is [#846](https://github.com/git/git.github.io/issues/846).

This isn’t a technical discussion or patch review but a community effort to compile and share updates from the Git project. The newsletter typically summarizes recent mailing list activity, notable patches, and broader developments, making it a useful resource for those who want a high-level overview of the project’s progress. Even small contributions, like typo fixes or link suggestions, are welcome.
