This is the final reroll (v3) of Patrick Steinhardt’s five-patch series that adds reference-writing subcommands to the new `git refs` builtin. The series is now merged into Junio’s `next` branch and proposed for the next release cycle.

The only change in v3 is a one-line typo fix in the `git refs create` subcommand: the error message now correctly says “null new object ID” instead of “null old object ID.” Everything else—subcommands, options, behavior, and test coverage—remains exactly as approved in v2. The series consolidates reference manipulation under a unified interface (`git refs delete`, `update`, `create`, and `rename`), mirroring or extending the functionality of `git update-ref` while improving discoverability. All new subcommands are thoroughly tested, and the implementation is uncontroversial. If you care about reference handling or the ongoing `the_repository` removal effort, this is a clean, finished feature worth noting.
