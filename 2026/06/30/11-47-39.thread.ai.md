Thread identity: Refactoring series from Patrick Steinhardt to separate repository discovery from setup in Git's core code. Series version: v2 (13 patches). Thread type: patch series.

Core problem or goal: Decouple repository *discovery* (finding the repository location and format) from *setup* (configuring the repository object) in `setup.c`. The current code intertwines these phases, making it harder to consolidate repository configuration logic into `repo_init()`. The series introduces a new `struct repo_discovery` to hold discovery results, enabling distinct, self-contained phases and reducing scattered setup logic.
