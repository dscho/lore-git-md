This is the **first patch in Phillip Wood’s 11-patch series** addressing the systemic issue of notes being incorrectly copied from dropped commits during rebase. It is a **test-only patch** targeting the test suite (`t3400-rebase.sh`).

The patch restores test coverage for the "apply" rebase backend, which was lost when the default backend switched from "apply" to "merge". The change is minimal: it replaces the `-m` flag (which forced the merge backend) with `--apply` in a single test case, ensuring that the apply backend’s note-copying behavior is still verified. The test’s logic and assertions remain unchanged.

This patch is a **prerequisite for the rest of the series**, as it ensures that regressions in the apply backend are caught in CI. The commit message is clear and concise, explaining the rationale for the change. There is no behavior change in Git itself—only in the test suite. The patch is uncontroversial and looks like a straightforward, necessary step in the broader effort to fix the rebase-dropped-commit problem.
