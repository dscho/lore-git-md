This thread is a two-patch bugfix series from Jeff King (Peff) that fixes small, self-contained memory leaks in `git format-patch` and the test harness. The series is at its first version (v1) and is ready for merging with no open questions or review feedback yet.

The first patch fixes an infrastructural annoyance in the test harness where LeakSanitizer (LSan) reports were misdirected to stdout, causing TAP parse errors with `prove`. The second patch, now summarized, plugs a memory leak in `prepare_bases()` in `builtin/log.c` by adding a single line to free a `rev_info` struct. This leak has existed since the `--base` option was introduced in 2016 but only became detectable after other leaks were fixed. The fix is demonstrated using existing tests with commit-graph support enabled, which triggers the allocation in the revision machinery.

Both patches are mechanical, low-risk, and touch only two files (`builtin/log.c` and `t/test-lib.sh`). The series is self-contained, with no dependencies on other in-flight topics, though the cover letter references an ongoing leak discussion. No new tests were added, as the existing test suite suffices to verify the fixes. The patches are ready for review and merging.
