This is a test modernization patch for the submodule subsystem. Bryan B. Lima (with co-authorship from Gustavo S. Correa) updates the test script `t/t7412-submodule-absorbgitdirs.sh` to replace raw `test -f`, `test -d`, and `! test -e` calls with the more descriptive helper functions `test_path_is_file`, `test_path_is_dir`, and `test_path_is_missing`.

The change is purely mechanical: every instance of the old pattern is swapped for the corresponding helper from `test-lib-functions.sh`. The helpers produce clearer error messages when a test fails, which makes debugging easier. No behavior is altered—this is a refactoring of the test suite itself.

The patch touches only one file and is small (11 insertions, 11 deletions), making it a straightforward, low-risk cleanup. It aligns with the ongoing community-wide effort to modernize Git’s test scripts by adopting the newer helper functions. If you follow test infrastructure improvements, this is a routine example of that trend.
