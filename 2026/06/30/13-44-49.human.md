This is a call for contributions to the next **Git Rev News** edition (136), the project's community newsletter.

Christian Couder has posted a draft of the upcoming edition on GitHub and invites the community to help polish it before publication on **July 2, 2026**. The draft is open for edits via pull request or comments on the linked GitHub issue. Contributions can include proofreading, article suggestions, relevant links, or volunteering for interviews. While Christian has CC’d those mentioned in the draft, he acknowledges some may have been missed. This is a routine community-driven effort to highlight recent Git development activity, discussions, and contributor spotlights.
