This thread is about a small but practical improvement to Git’s build system as part of the ongoing Rustification effort. Jan Palus noticed that the Makefile incorrectly lists the main Git C library (`$(LIB_FILE)`) as a dependency of the Rust static library (`$(RUST_LIB)`), even though the Rust code doesn’t link against or use the C library at build time. The meson build system doesn’t have this dependency either, which supports the claim.

The patch itself is a one-line change to the Makefile, removing `$(LIB_FILE)` from the dependency list for `$(RUST_LIB)`. The justification is straightforward: it eliminates unnecessary rebuilds of the Rust library when the C library changes, even if the Rust code hasn’t. The change is mechanical, well-motivated, and unlikely to be controversial. No test failures or build breakages have been reported. So far, there’s no indication of pushback or open questions—this looks like a clean fix.
