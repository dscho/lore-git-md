This is a small bugfix series from Jeff King (Peff) targeting memory leaks in `` `git format-patch` `` and test infrastructure.

The first patch moves LeakSanitizer (LSan) error messages from stdout to stderr in the test harness. This is a minor but useful cleanup: it prevents LSan noise from interfering with test output when running under `prove`, making test failures easier to diagnose.

The second patch plugs a leak in `` `git format-patch` ``’s `prepare_bases()` function, where a `rev_info` struct was not being freed. The fix is a one-line addition of a `release_revisions()` call.

Both patches are narrowly scoped, well-explained, and come with clear commit messages. The series is self-contained and does not depend on any larger effort. Given Peff’s track record, these fixes are likely to be uncontroversial and ready for merging.
