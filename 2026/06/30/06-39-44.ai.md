This is a two-patch bugfix series from Jeff King targeting memory leaks in `git format-patch` and test infrastructure.

The first patch (`t: move LSan errors from stdout to stderr`) adjusts the test harness to redirect LeakSanitizer (LSan) error output from stdout to stderr. This fixes a minor issue where LSan reports were interfering with test suite output when run under `prove`, making it harder to distinguish actual test failures from leak reports. The change is small (three lines modified in `t/test-lib.sh`) and purely infrastructural—no behavior change to Git itself.

The second patch (`format-patch: fix leak of rev_info in prepare_bases()`) plugs a memory leak in `builtin/log.c` where a `rev_info` struct allocated in `prepare_bases()` was not being freed. The fix is a one-line addition of a `release_revisions()` call. The leak was discovered while investigating an unrelated leak in another thread, suggesting this was a targeted cleanup rather than part of a broader audit.

The series is self-contained and low-risk: the first patch is test-only, and the second touches a single function in a well-understood code path. Both patches are mechanical and well-scoped.
