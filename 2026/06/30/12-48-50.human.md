This is a bugfix patch from Rishav Dewan that addresses a long-standing case-sensitivity mismatch in Git's config file parser.

The issue occurs when using the old-style `[section.subsection]` syntax in `.gitconfig`. The parser unconditionally lowercases the subsection during parsing, but when a user runs `` `git config` `` with a mixed-case subsection (e.g., `section.Subsection.key`), the command-line argument preserves the original case. The current code compares these two forms with a simple `strcmp()`, so they never match, causing Git to append a duplicate line instead of updating the existing value.

The patch tracks whether the active section was parsed case-insensitively (old-style) or case-sensitively (new-style, quoted) and adjusts the comparison function accordingly. It also removes the now-obsolete `BUGS` section from the `git-config` documentation and updates the test suite to reflect the fixed behavior.
