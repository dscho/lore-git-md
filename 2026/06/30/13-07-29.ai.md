This is a build system patch targeting the Rustification effort. Jan Palus reports what appears to be a spurious dependency in the Makefile: the `$(RUST_LIB)` target (the Rust static library built from Git's Rust code) is declared to depend on `$(LIB_FILE)` (the main Git C library), but the Rust code does not actually link against or otherwise use the C library at build time. The meson build system does not encode this dependency either, reinforcing the claim.

The patch is a single-line Makefile change that removes `$(LIB_FILE)` from the dependency list of `$(RUST_LIB)`. The commit message is concise and cites the lack of actual linkage as justification. No test failures or build breakages are reported, and the change is mechanical. This looks like a straightforward cleanup that reduces unnecessary rebuilds when the C library changes but the Rust code has not. The patch is well-motivated and unlikely to be controversial.
