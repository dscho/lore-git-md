This is the ninth patch in Phillip Wood’s 11-patch series that overhauls how the sequencer handles dropped commits during rebase. It is a **pure refactoring** in `sequencer.c` that simplifies control flow in `pick_one_commit()` by returning early when a commit is successfully recorded as rewritten.

The patch moves the `return 0` statement into the `else if (!res)` block, making it clear that once `record_in_rewritten()` is called, the function’s work is done. The trailing `return res` is replaced with a `BUG()` macro to catch any unhandled return values from `do_pick_commit()`, reinforcing the intent that all cases should be explicitly handled. This change is preparatory for the next two patches, which introduce an enum for pick results and add a `PICK_DROPPED` state. No behavior change is introduced; the patch only reorganizes existing logic to make the control flow more linear and easier to extend.
