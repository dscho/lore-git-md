This is a **CI/build system** follow-up in the macOS CI hang thread. Junio C Hamano accepts Patrick Steinhardt’s proposal to add a GitLab CI status badge to the project’s `README.md`, making GitLab CI results as discoverable as GitHub’s.

The change is a one-line addition that inserts a GitLab CI badge alongside the existing GitHub badge, linking directly to the pipelines page for the `master` branch on GitLab’s official mirror. Junio endorses the idea, noting that both GitHub and GitLab have provided sustained service to the community and deserve equal visibility. This resolves the earlier concern about maintainers not knowing where to find GitLab CI results, and it does so without requiring any CI configuration changes or policy decisions about test coverage.

The third patch in the original series (enabling `GIT_TEST_LONG` for GitLab CI) remains on hold, but this small documentation tweak is now ready to merge and will make GitLab CI a first-class part of the project’s workflow.
