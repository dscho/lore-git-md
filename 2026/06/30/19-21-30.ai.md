This is a **CI/build system** follow-up in the macOS CI hang thread. Junio C Hamano accepts Patrick Steinhardt’s proposal to add a GitLab CI status badge to the project’s `README.md`, calling it a "nice" and low-cost way to address the visibility concern he raised earlier.

The patch itself is trivial: a one-line addition that inserts a GitLab CI badge alongside the existing GitHub badge. The badge links directly to the pipelines page for the `master` branch on GitLab’s official mirror. Junio explicitly endorses the change, noting that both GitHub and GitLab "deserve one line each for their continued service to the community." This removes the last open question about CI policy and visibility; the badge addition is now likely to be merged independently of the still-on-hold third patch (enabling `GIT_TEST_LONG` for GitLab CI).

No new technical or policy issues are introduced. The thread’s original two-patch series (Apache timeout increase and test isolation) is already merged for Git 2.55, and this follow-up is purely about documentation. The change is uncontroversial and directly addresses the maintainer’s stated barrier to GitLab CI adoption.
