This is the first patch in the final v12 series adding `git branch --prune-merged` functionality, introducing the new `--forked` filter as a building block. The series has undergone extensive review over 12 iterations and appears technically complete.

The patch adds a `--forked` option to `git branch --list` that filters branches based on their upstream tracking relationship. Branches are kept if their upstream matches any of the given patterns, which can be either literal refs (like "origin/main") or shell-style globs (like "origin/*"). The option composes with existing filters like `--merged`, allowing precise queries like "show me branches forked from origin that have been merged into origin/main".

Key implementation details:
- Uses wildmatch for glob pattern matching
- Handles both literal refs and glob patterns in a unified way
- Preserves all existing safety checks
- Includes comprehensive tests covering various filtering combinations
- Exposes new ref-filter.h API for the implementation

The safety model remains robust - it only considers local refs (no implicit fetches) and properly handles edge cases like NULL upstreams. The interface has been refined through review to be more composable and explicit about its inputs.

This foundational change enables the subsequent patches that will add the actual `--prune-merged` deletion capability while maintaining all the safety guarantees developed through the series' extensive review process.
