Build system patch discussion about git-gui's silent mode implementation.

Johannes Sixt provides a substantive review of Harald Nordgren's v2 patch that fixes git-gui's Makefile to properly respect `make -s` silent mode. While acknowledging the improvement in making the code more suitable for standalone builds, Johannes points out two key issues:

1. The commit message still doesn't explain why the condition needed to change from `ifeq` to `ifneq` - a non-obvious but important technical detail.

2. More critically, Johannes reveals that the original condition was actually broken in its parameter ordering (`findstring` takes needle,haystack arguments), meaning the silent mode check never worked as intended. The new version correctly checks for 's' in the MAKEFLAGS string.

This review elevates the discussion from a simple silent mode fix to exposing a long-standing bug in the build system's flag detection. Johannes suggests the commit message should document both the fix and the pre-existing defect it corrects. The technical exchange demonstrates deep Makefile expertise, with Johannes catching subtle parameter ordering that would be easy to miss.
