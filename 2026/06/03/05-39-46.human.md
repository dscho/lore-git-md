This is the third patch in a v2 series improving TAP output validation in Git's test infrastructure. The patch focuses on cleaning up process termination in the git-p4 tests.

The change addresses an issue where killing the p4d watchdog process could produce asynchronous shell job-control messages that would interfere with strict TAP output parsing. The fix:
1. Adds explicit `wait` calls to synchronously reap processes
2. Silences the termination output by redirecting stderr to /dev/null
3. Deduplicates the process termination logic between two helper functions

The patch builds on previous work to make test output more reliable, particularly in preparation for strict TAP validation (which is added in patch 4 of this series). The changes are mechanical improvements to test infrastructure with no behavioral impact on the actual git-p4 functionality itself.

Patrick has incorporated feedback from the v1 review (noted in the thread context) and the patch appears ready for merging. This is part of a broader effort to improve test reliability across different platforms and subsystems.
