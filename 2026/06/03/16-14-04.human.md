This is part 5 of Patrick Steinhardt's v2 series adding a "drop" subcommand to the experimental `git history` command. The patch introduces a new `RESET_HEAD_SKIP_REF_UPDATES` flag for the `reset_head()` function, allowing callers to update just the index and working tree without modifying references.

The change is a preparatory step for the history command's drop functionality, which needs to test operations without actually updating refs. The implementation adds appropriate BUG checks to prevent invalid combinations of flags (like trying to both skip ref updates and update a branch). The patch follows Patrick's typical thoroughness, with clear commit message and careful handling of edge cases.

This continues the series' pattern of enhancing `reset_head()` to support more flexible use cases while maintaining safety. The changes here are focused and well-contained, touching only the reset machinery (reset.c and reset.h) with no behavioral changes to existing callers.
