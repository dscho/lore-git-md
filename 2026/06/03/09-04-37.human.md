This is patch 4/6 in Harald Nordgren's v12 series adding `git branch --prune-merged` for safe automated local branch cleanup. The series has undergone extensive review over 12 iterations and appears technically complete.

The patch introduces the core `--prune-merged` functionality, which safely deletes local branches whose work has been integrated into their upstream branches. The implementation carefully preserves several safety checks:
- Never deletes checked-out branches
- Skips branches whose upstream no longer exists locally
- Protects trunk-like branches by comparing push vs upstream destinations
- Warns rather than fails on unmerged branches during bulk operations

The patch includes comprehensive tests covering:
- Basic deletion of merged branches
- Literal vs glob pattern matching
- Multiple upstream specifications
- Various protection scenarios (checked-out, missing upstream, push==upstream)
- Warning behavior for unmerged branches
- Input validation

The implementation builds on the shared `collect_forked_set()` infrastructure from earlier patches and integrates with the existing `delete_branches()` machinery in warn-only mode. Documentation is thorough, explaining both the behavior and safety mechanisms.

This appears to be a well-considered addition to Git's branch management capabilities, with attention paid to edge cases and workflow safety. The extensive test coverage and careful documentation suggest it's ready for final review.
