This is a documentation patch from Kristoffer Haugsbakk, part of his ongoing effort to improve `git replay` configuration documentation. The patch adds cross-references between the command and config documentation by including the `replay.adoc` config section in both `git-config(1)` and `git-replay(1)` man pages.

The change is straightforward - it inserts the missing include directive for the replay configuration section in both documentation files. This ensures the `replay.refAction` configuration option (added in commit 336ac90c) is properly documented in both places. The patch follows the standard documentation conventions and maintains consistency with how other config options are referenced across Git's man pages.

This is the first patch in a 4-part series that has already gone through one iteration (v1) with maintainer feedback.
