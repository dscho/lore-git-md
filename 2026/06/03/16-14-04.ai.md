This is part 5 of Patrick Steinhardt's v2 series adding a "drop" subcommand to the experimental `git history` command. The patch introduces a new `RESET_HEAD_SKIP_REF_UPDATES` flag for the `reset_head()` function, allowing callers to update the index and working tree without modifying references.

The change is motivated by upcoming needs in the history command's drop functionality, which will want to perform worktree updates independently of ref updates. The implementation adds a BUG check to prevent contradictory flag combinations (requesting both ref updates and skipping them) and modifies the ref update logic to respect the new flag.

This is a focused, well-contained change that follows Git's established patterns for flag handling in the reset machinery. The patch demonstrates Patrick's characteristic attention to detail with clear commit message, proper error checking, and minimal scope. The change is part of the broader effort to modernize `reset_head()` for reuse across Git commands while being specifically motivated by the history command's needs.
