Build system patch improving git-gui's silent mode behavior in v2.

This is a follow-up to Harald Nordgren's earlier patch that fixed git-gui's Makefile to properly respect `make -s` silent mode. The v2 revision clarifies the commit message to better explain the change's motivation - specifically that install/uninstall recipes were emitting output via embedded echo calls even in silent mode.

The technical change remains the same: wrapping the existing quiet block in the standard silent flag check from shared.mak, while removing a redundant narrower check that only affected QUIET_GEN. The patch still touches only git-gui/Makefile with 6 lines changed (4 deletions, 2 additions).

This version addresses Johannes Sixt's earlier feedback about the silent flag detection approach by explicitly noting it matches shared.mak's implementation (lines 40 and 46). However, the open question about standalone builds without shared.mak remains unresolved in this revision. The patch demonstrates careful attention to build system behavior while leaving that portability concern for potential future work.
