This is the third patch in Patrick Steinhardt's v2 series fixing TAP output validation issues in Git's test infrastructure. The patch specifically addresses noise in git-p4 test output that would interfere with strict TAP parsing.

The change modifies the git-p4 test helper scripts to properly synchronize and silence process termination. When killing the p4d daemon and its watchdog, the shell was previously emitting asynchronous job-control messages that would corrupt TAP output. The patch fixes this by:

1. Adding explicit `wait` calls to synchronously reap processes
2. Redirecting stderr to /dev/null to suppress termination messages
3. Deduplicating the cleanup logic between two helper functions

The changes are mechanical improvements to test infrastructure with no behavioral impact beyond making the output cleaner. This builds on the series' goal of ensuring reliable TAP output across different test scenarios (fsmonitor, Windows cleanup, and now git-p4). The patch addresses Junio C Hamano's v1 feedback about variable naming while also improving the process waiting behavior. The implementation is straightforward and focused, touching only the git-p4 test helper script.
