Git-gui build system fix for silent mode behavior.

The thread concerns a patch modifying git-gui/Makefile to properly respect `make -s` silent mode during installation/uninstallation. Johannes Sixt has raised substantive technical questions about the implementation details:

1. The patch assumes `shared.mak` is available, which may not be true for standalone git-gui builds. This dependency should be made explicit or handled gracefully.

2. The silent mode detection logic has changed from checking exact equality (`ifeq -s,$(firstword -$(MAKEFLAGS))`) to substring matching (`ifneq (,$(findstring s,$(firstword -$(MAKEFLAGS))))`). Johannes questions whether this indicates the original check was incorrect or if the new behavior is intentionally more permissive.

The patch remains small (6 lines changed) and focused on git-gui/Makefile, but now has an open question about the technical correctness of the silent flag detection approach. The change affects only build-time output formatting, not runtime behavior. Johannes' review engages with the technical substance of the change rather than surface-level concerns.
