This is patch 4/6 in Harald Nordgren's v12 series adding `git branch --prune-merged` for safe automated local branch cleanup. The series has evolved through 12 iterations with all major technical concerns addressed.

The patch implements the core `--prune-merged` functionality, which deletes local branches that are both forked from specified upstreams and have all their commits merged into those upstreams. The implementation carefully preserves several safety checks:
- Branches checked out in any worktree are never deleted
- Branches whose upstream no longer resolves locally are skipped
- Branches that push to the same place as their upstream (like main tracking origin/main) are preserved to avoid accidentally deleting trunk branches

The command operates in warn-only mode when encountering unmerged branches, allowing bulk operations to continue rather than failing entirely. The implementation builds on the shared `collect_forked_set()` infrastructure from earlier patches and integrates with the existing `delete_branches()` machinery with new flags for bulk operation optimization.
