This is a refactoring patch from Patrick Steinhardt's v2 series adding a "drop" subcommand to the experimental `git history` command. The patch modernizes the flag handling in the reset machinery by converting from `#define` macros to an `enum` for the `reset_head()` flags.

The key changes are:
- Replaces `RESET_ORIG_HEAD` with `RESET_HEAD_ORIG_HEAD` to maintain naming consistency with other flags
- Groups all flags into a new `enum reset_head_flags` type
- Updates all callers to use the new enum type and flag names
- Maintains the same bit values and behavior, just with improved type safety

This is a mechanical change that improves code hygiene while preparing the reset machinery for use by the new `git history drop` functionality. The patch touches several files that use the reset functionality (`rebase.c`, `sequencer.c`) but the changes are straightforward and consistent.

The patch follows Git's current conventions for flag handling and is part of Patrick's broader effort to modernize the reset machinery for reuse in the history command. It builds on previous work in the series that enhanced `reset_head()` with new capabilities like dry-run mode.
