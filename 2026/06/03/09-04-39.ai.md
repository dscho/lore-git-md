This is the final patch (6/6) in Harald Nordgren's v12 series adding `git branch --prune-merged` functionality, now introducing a `--dry-run` option for safe previewing of branch deletions. The series has undergone extensive review over 12 iterations and appears technically complete.

The patch adds `--dry-run` support to `--prune-merged`, which prints the branches that would be deleted (prefixed with "Would delete branch") without actually removing them. The dry-run output precisely matches what the live operation would do, applying all the same safety checks (push/upstream comparison, unmerged branch protection, etc.). The option is rejected if used without `--prune-merged`.

Key implementation details:
- New `dry_run` parameter added to `prune_merged_branches()`
- Dry-run mode passes through all existing safety logic
- Output format designed to be machine-parseable
- Comprehensive tests verify:
  * Dry-run lists exactly what would be deleted
  * Current branch and unmerged branches are excluded
  * Option validation (requires `--prune-merged`)

This completes the series' safety model by allowing users to preview deletions before executing them, particularly useful when using broad patterns like `origin/*`. The patch maintains all prior safety guarantees while adding this preview capability. With all technical feedback addressed through 12 iterations, the series appears ready for final review and potential merging.
