This is a build system patch for git-gui, Git's graphical interface. The change makes the install and uninstall recipes respect the `make -s` (silent) flag by properly suppressing output messages that were previously still being shown.

The patch wraps the existing quiet-mode block in the standard silent-mode check from shared.mak, removing a redundant narrower check that only affected QUIET_GEN. This brings git-gui's behavior in line with the main Git build system's handling of silent mode.

The change is straightforward and appears well-motivated - it's a small quality-of-life improvement for build automation where silent operation is desired. The patch follows the project's conventions and includes a clear commit message explaining both the problem and solution.
