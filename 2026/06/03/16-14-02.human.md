This is a refactoring patch from Patrick Steinhardt's v2 series adding a "drop" subcommand to the experimental `git history` command. The patch modernizes the flag handling in the reset machinery by converting from `#define` macros to an `enum` for the `reset_head()` flags.

The changes include:
- Replacing `RESET_ORIG_HEAD` with `RESET_HEAD_ORIG_HEAD` for naming consistency
- Grouping all flags into a new `enum reset_head_flags`
- Updating all callers to use the new enum type
- Fixing documentation references to the old flag names

This is a mechanical cleanup that improves code organization while maintaining the same functionality. The changes touch several key files including `reset.c`, `reset.h`, and callers in `rebase.c` and `sequencer.c`. While small, this refactoring is part of the broader effort to modernize the reset machinery for use in the new `git history drop` functionality.

The patch appears well-contained and follows Git's current coding practices. It's a typical example of the kind of preparatory refactoring Patrick often includes in his larger feature series.
