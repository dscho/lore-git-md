This thread addresses a small but clear inconsistency in Git's build system behavior. The git-gui subproject's Makefile was not fully respecting the `make -s` silent flag during installation and uninstallation, unlike the rest of the build system. The patch fixes this by properly wrapping the relevant commands in the standard silent flag check from shared.mak, removing a narrower check that only affected QUIET_GEN output.

The change is straightforward and focused - just six lines modified in git-gui/Makefile - and brings git-gui's behavior in line with the rest of Git's build system. This appears to be a clean improvement that makes the silent mode work as expected across all build operations.
