This thread addresses a build system fix for git-gui's Makefile to properly respect `make -s` silent mode during installation and uninstallation. The original patch series from Harald Nordgren has gone through two iterations, with Johannes Sixt providing substantive technical reviews at each stage.

The core issue is that git-gui's install/uninstall recipes were emitting output even in silent mode. The v1 patch changed the silent mode detection from an exact equality check to substring matching, aligning with `shared.mak`'s approach. In v2, Johannes spotted a subtle but important bug - the `findstring` parameters were reversed, making the condition always fail. The current implementation now correctly checks for 's' in MAKEFLAGS, though the commit message doesn't yet explain this fix.

While the technical solution appears sound, one open question remains regarding `shared.mak` dependency for standalone builds. The discussion has been highly technical throughout, with Johannes' reviews catching implementation nuances and Harald responding with careful adjustments. The changes are confined to build-time behavior with no runtime impact, and one final revision may be needed to document the parameter order fix in the commit message.
