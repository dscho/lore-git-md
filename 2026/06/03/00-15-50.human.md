Bugfix review for HTTP authentication headers during redirects. Junio C Hamano provides a detailed technical review of Aaron Plattner's patch that preserves WWW-Authenticate headers across HTTP redirects.

The review confirms the patch's correctness in handling memory (no leaks or use-after-free) while noting the string copying may be inefficient. Junio validates the design choice to unconditionally preserve the headers, explaining they represent active authentication challenges for the redirected URL.

Key concerns raised:
1. Future maintenance risk - the current approach manually saves/restores headers in http.c, creating tight coupling with credential internals
2. Scalability - if credential struct gains more transient fields, each would need similar manual handling
3. Architectural suggestion - proposes moving this logic into credential.c via a new `credential_update_url()` helper to better encapsulate the behavior

The review doesn't block the current patch (which solves an immediate OAuth authentication breakage) but thoughtfully considers longer-term design implications. This is a substantive review that goes beyond surface-level issues to examine architectural maintainability.
