This is part 2 of Harald Nordgren's v12 series adding `git branch --prune-merged` for safe automated branch cleanup. The patch modifies the branch deletion logic to optionally warn rather than error when encountering unmerged branches during bulk operations.

The key change makes `delete_branches()` and `check_branch_commit()` accept a `warn_only` flag that converts the traditional error+advice (which includes the `git branch -D` suggestion) into a simple one-line warning when set. This allows bulk operations like `--prune-merged` to continue processing other branches after encountering unmerged ones, while maintaining the stricter behavior for direct `git branch -d` usage.

The implementation preserves all safety checks - it only changes how violations are reported. The patch is narrowly focused and follows the series' established pattern of careful, incremental changes with clear commit messages.
