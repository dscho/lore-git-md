This is the final patch in Harald Nordgren's 12-iteration series adding `git branch --prune-merged` for safe automated local branch cleanup. The series has already addressed all major technical concerns and is now in its final review stage.

The patch adds a `--dry-run` option to `--prune-merged` that shows which branches would be deleted without actually removing them. The dry-run output matches exactly what the live operation would do, including all the safety checks around push/upstream comparisons and unmerged branch protection. The implementation ensures `--dry-run` can only be used with `--prune-merged` and is rejected otherwise.

The changes include:
- Documentation updates explaining the new option
- Integration with the core branch deletion logic
- Comprehensive tests verifying the dry-run behavior matches real execution
- Clear error handling for invalid usage

This completes the series' feature set, which now includes:
- Safe branch deletion based on upstream merge status
- Configurable branch exemptions via `branch.<name>.pruneMerged`
- Warning rather than failing on unmerged branches in bulk operations
- The new dry-run capability for verification
