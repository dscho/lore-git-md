This is v12 of Harald Nordgren's series adding `git branch --prune-merged` for safe automated local branch cleanup, now with a push-tracking safety check and dry-run support. The series has evolved through extensive review to refine both the safety mechanisms and interface design.

Key changes in v12:
- Reworked `--forked` from a standalone action into a `--list-mode` filter that can be combined with other list filters
- Made both `--forked` and `--prune-merged` accept repeatable OPT_STRING_LIST options
- Dropped bare remote name resolution for `--forked` (arguments must now be refs or globs)
- Added comprehensive tests showing how `--forked` filter composes with other list options
- Improved documentation of the filtering behavior

The implementation now provides:
- Wildmatch pattern matching for branch selection
- Union of multiple `--forked`/`--prune-merged` arguments
- Push-tracking safety checks to avoid deleting trunk branches
- `branch.<name>.pruneMerged` config opt-out
- `--dry-run` mode to preview deletions
- Full test coverage of edge cases and combinations
