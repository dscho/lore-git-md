This is the first patch in the final v12 series adding `git branch --prune-merged` functionality, introducing the foundational `--forked` filter for branch listing. The series has undergone extensive review over 12 iterations and is now in its final review stage.

The patch adds a `--forked` option to `git branch --list` that filters branches based on their upstream tracking relationship. The filter accepts both literal branch names (like "origin/main") and shell-style glob patterns (like "origin/*"), with the option being repeatable to widen the filter scope. The implementation includes:

1. Wildmatch-based glob pattern matching for flexible upstream specification
2. Composition with existing list filters like `--merged` and `--no-merged`
3. Comprehensive test coverage of the filtering behavior
4. Clear error messages for invalid branch/pattern inputs

Key technical details:
- Uses OPT_STRING_LIST for repeatable argument handling
- Implements wildmatch pattern matching for glob support
- Preserves all safety checks from earlier versions
- Maintains compatibility with other branch listing options
- The filtering happens after other list operations, allowing composition like `--merged origin/main --forked 'origin/*'` to find merged feature branches
- Includes tests for literal/glob combinations and edge cases
