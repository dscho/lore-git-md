This is a documentation patch from Kristoffer Haugsbakk, part of his ongoing effort to improve the `git replay` configuration documentation. The patch adds cross-references between the `git-replay(1)` man page and the configuration documentation by including the `config/replay.adoc` file in both places.

The change ensures that users reading either the command documentation or the general config documentation will see the same information about `replay.refAction`. This is the first patch in a v2 series that has already received maintainer approval from Junio C Hamano, with previous iterations refining the formatting and synchronization of these documentation sections.

The patch is straightforward and uncontroversial, following Git's documentation conventions by using the standard include:: directive to share content between man pages. It exemplifies the kind of careful documentation maintenance that helps keep Git's man pages consistent and discoverable.
