This is a preparatory refactoring patch from Patrick Steinhardt as part of his v2 series adding a "drop" subcommand to the experimental `git history` command. The patch splits out index handling logic from `repo_read_index_unmerged()` into a new standalone function `index_state_unmerged_to_stage0()` that can operate on any index state, not just the repository's main index.

The change is small but meaningful - it generalizes the unmerged-entry resolution logic while fixing a signedness issue in the index iteration. This refactoring enables future patches in the series to reuse this functionality more flexibly. The patch follows Patrick's characteristic style of careful, incremental changes with clear commit messages explaining both the what and the why.

As the first patch in a 9-part series, this sets up infrastructure that will be used later for the history drop functionality. The series as a whole is part of Patrick's ongoing work on the `git history` command, building on previous replay subcommand work.
