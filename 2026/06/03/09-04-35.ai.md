This is patch 2/6 in Harald Nordgren's v12 series adding `git branch --prune-merged` functionality. The patch modifies the branch deletion logic to support warning rather than erroring when encountering unmerged branches during bulk operations.

The key change introduces a `warn_only` flag to `delete_branches()` and `check_branch_commit()`, allowing bulk operations like `--prune-merged` to continue processing after encountering unmerged branches rather than stopping with an error. The existing single-branch deletion path (`git branch -d`) remains unchanged by defaulting the flag to 0.

Technical details:
- When `warn_only` is set, unmerged branches trigger a one-line warning instead of the full error message and advice about using `-D`
- The change preserves all safety checks while making bulk operations more user-friendly
- The patch maintains backward compatibility by keeping the original behavior for non-bulk callers

This is a focused change that supports the series' goal of safe automated branch cleanup while improving the experience for bulk operations. The implementation is straightforward and maintains the existing safety model.
