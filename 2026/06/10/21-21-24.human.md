This is patch 6/11 in Kristoffer Haugsbakk's documentation series for `git-interpret-trailers`, which has already been merged after addressing all review comments. The patch explicitly documents that trailer keys must use only alphanumeric ASCII characters and hyphens, closing a gap where this restriction was previously only implied by examples.

The change is straightforward - it inserts one sentence defining the valid key format into the existing trailer definition paragraph. The commit message notes this prevents readers from missing that digits are allowed (since earlier examples only showed letters and hyphens). The patch is well-contained and clearly motivated by a real user report of confusion.

This was part of a larger effort to comprehensively document trailer parsing rules after discovering users were hitting silent failures with keys containing periods. The series as a whole improved both technical accuracy and pedagogical structure of the man page.
