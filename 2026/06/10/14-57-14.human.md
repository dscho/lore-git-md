This is patch 8/9 in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. The patch focuses on a small but clear optimization in `refs_compute_filesystem_location()`.

The change eliminates an unnecessary intermediate buffer in the path computation logic. The function was using a temporary `strbuf` to construct a path before passing it to `strbuf_realpath()`, but since `strbuf_realpath()` can operate in-place on its input buffer, this extra step was redundant. The patch simplifies the code by using the output buffer directly.

This is a straightforward cleanup that removes a minor inefficiency (the extra buffer allocation) while making the code slightly easier to follow. It's a typical example of the kind of small, focused improvements that often appear in later patches of a refactoring series - addressing secondary issues uncovered while working on the main changes.

The patch maintains all existing behavior while being more efficient, and it fits well with the series' broader goal of cleaning up the backend code. As with the rest of the series, this change is unlikely to be controversial but may warrant a quick review from anyone working in the refs subsystem.
