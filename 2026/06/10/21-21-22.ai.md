This is a documentation patch in Kristoffer Haugsbakk's 11-part series improving the `git-interpret-trailers` man page. This particular patch (4/11) clarifies that the command can process trailers in any text, not just commit messages, though commit messages remain the primary use case.

The change updates the DESCRIPTION section to remove the implication that trailers are commit-message-specific, while keeping the example focused on commits since they're the most common scenario. The patch references git-tag's trailer support as evidence of broader applicability. This is a straightforward documentation improvement that aligns with the series' goal of making the trailer functionality's scope and rules more precise.
