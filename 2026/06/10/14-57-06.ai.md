This is a refactoring series targeting the reference backend infrastructure, part of Patrick Steinhardt's ongoing work to clean up and modernize Git's ref storage layer. The series aims to eliminate the use of `chdir_notify_reparent()` by making reference backends consistently use absolute paths internally.

The key technical changes involve:
- Removing chdir notification callbacks from ref backends
- Ensuring ref stores always use absolute paths
- Fixing some subtle issues around refdb initialization with "onbranch" config
- Cleaning up repository setup code that was applying format settings twice

The series builds on Patrick's recent work centralizing ODB creation and touches multiple ref backends (files, packed, reftable). It includes test updates showing the behavior remains correct. While the series grew larger than expected due to some initialization quirks, the changes appear focused and well-motivated by the goal of simplifying the ref storage code.

This continues Patrick's pattern of thorough, incremental refactoring in the refs subsystem. The changes are unlikely to be controversial but may warrant close review from anyone working on the ref backends or repository initialization code.
