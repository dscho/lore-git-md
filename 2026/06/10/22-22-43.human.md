This is a documentation patch series from Kristoffer Haugsbakk that updates the SubmittingPatches guide with more detailed information about commit trailers. The 6-patch series aims to clarify best practices around using trailers like Signed-off-by, Reviewed-by, and other common tags in Git commit messages.

The patches address several practical concerns that have come up in mailing list discussions: when to use trailers for non-trivial contributions (not just typo fixes), documenting the less common "Based-on-patch-by" trailer, warning against using Linux-specific trailers that don't apply to Git, being consistent with trailer formatting, and noting that trailer order matters in some contexts.

The changes are focused on the Documentation/SubmittingPatches file and appear to be well-motivated by real mailing list experiences. As documentation improvements, they don't affect code behavior but should help contributors follow project norms more easily. The patches look straightforward and uncontroversial - the kind of incremental documentation polish that typically gets merged after light review.
