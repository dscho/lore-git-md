This is a refactoring patch series that continues the effort to migrate configuration settings from global variables to repository-scoped storage, specifically targeting the `trust_executable_bit` setting (which controls whether Git respects filesystem executable bits). The work is part of the larger `the_repository` removal project.

The series has been refined since v1 based on feedback, with notable changes including:
- Dropping the `istate` plumbing changes to keep the scope focused
- Adding a safe getter function `repo_trust_executable_bit()`
- Improving documentation for `ce_mode_from_stat()`

The patches make several mechanical changes:
1. Cleans up redundant extern declarations in read-cache
2. Moves `ce_mode_from_stat()` to read-cache.c where it's primarily used
3. Moves the `trust_executable_bit` variable into `repo_config_values`

The author notes this is groundwork for eventually eliminating `the_repository`, though full multi-repository support isn't implemented yet. The changes are well-motivated and build on previous attempts to scope this configuration properly, with clear mentorship from established contributors. The series appears ready for consideration, with the more complex `has_symlinks` migration deferred to future work as previously agreed in the thread.
