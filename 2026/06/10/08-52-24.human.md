This is a refactoring patch in Patrick Steinhardt's `git history drop` series, modernizing the reset machinery flags. The patch converts the reset flags from `#defined` constants to an `enum` type and updates their names to match the recently renamed `reset_working_tree()` function.

The changes are mechanical but important for code hygiene:
- Flag names now consistently use `RESET_WORKING_TREE_` prefix
- Flags are properly typed via `enum reset_working_tree_flags`
- All callers (rebase.c, sequencer.c) are updated to use the new names

This is part of a larger effort to clean up and modernize Git's reset machinery while adding new functionality for the history command. The patch follows established patterns seen in other parts of the codebase and maintains backward compatibility. It touches several key files (reset.c, reset.h) but the changes are straightforward and well-contained.
