This is the third patch in Patrick Steinhardt's 7-part series to eliminate global state in setup.c, continuing the `the_repository` removal effort. The patch removes the `git_work_tree_cfg` global variable after refactoring its last remaining usage in setup.c.

The key changes are:
1. The variable is no longer needed since its value is already stored in the repository format structure
2. All references to the global are replaced with direct access to `repo_fmt->work_tree`
3. The patch includes cleanup of now-redundant code paths and memory management

The changes are mechanical and focused - touching only setup.c with straightforward replacements that maintain the same behavior. This follows the established pattern in the series of first making callers pass repository state, then removing the now-unused globals. The patch builds on the previous refactoring that stopped modification of this variable in builtin/init-db.c.

As with the rest of the series, this appears to be a well-structured, incremental step in the larger architectural cleanup effort. The changes are limited in scope and maintain existing functionality while removing technical debt. Given Patrick's track record with similar refactorings and the focused nature of these changes, this patch seems likely to be uncontroversial.
