This is patch 6/9 in Patrick Steinhardt's series to modernize Git's reference backend infrastructure, focusing on memory management cleanup. The patch fixes a memory leak where the main reference database wasn't being freed when clearing a repository, while worktree and submodule reference databases were properly released.

The change adds cleanup code to `repo_clear()` in repository.c to release the `refs_private` member when destroying a repository struct. The leak had gone unnoticed because the pointer was being maintained by the chdir_notify subsystem, which the previous patches in the series have been working to eliminate.

This is a straightforward memory leak fix that logically follows the earlier patches' removal of chdir notification infrastructure. The change is small (5 lines) and focused, continuing the series' pattern of careful refactoring. Since this is part of a larger refactoring effort, reviewers will likely evaluate it in the context of the full series rather than as an isolated change.
