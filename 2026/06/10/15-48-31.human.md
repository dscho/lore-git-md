Junio C Hamano (the Git maintainer) responds to Kristofer Karlsson's patch that removes the `get_reachable_subset()` function in favor of `tips_reachable_from_bases()`. He notes the curious fact that both functions were originally written by the same author (Derrick Stolee) but were never consolidated.

Junio questions the patch's claim that the DFS/BFS performance difference "should not matter in practice", pointing out that the given rationale about worst-case scenarios doesn't fully support this assertion. However, he acknowledges the clean nature of the change - it's primarily a renaming with flag adjustments (from bit 0 to TMP_MARK) to accommodate how the new function uses SEEN internally.

The maintainer initially worried that test changes might indicate behavioral differences, but confirms they're just updating test names to match the new function being tested. Junio seems generally positive about the change, noting the significant code reduction (126 lines removed) and calling the explanation in the commit message sensible. His "Thanks" at the end suggests he's likely to accept the patch, though he might want the performance rationale tightened up first.
