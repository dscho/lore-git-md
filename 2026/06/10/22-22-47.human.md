This is the fourth patch in Kristoffer Haugsbakk's documentation series updating the SubmittingPatches guidelines, focusing on commit message conventions. The patch adds documentation for the `Based-on-patch-by` trailer, which is used when incorporating someone else's patch work that wasn't properly attributed with a Signed-off-by line.

The patch explains that this trailer is appropriate when someone has sent patch content (like a snippet to the mailing list) without proper commit message formatting, and you've picked it up to submit properly. The author notes this is distinct from `Co-authored-by` (for collaborative drafting) and `Helped-by` (for idea contributions).

The change is well-motivated by observed mailing list practices and fills a gap in the official documentation. The patch maintains the series' careful approach - using "can be used" rather than prescriptive language, acknowledging that other trailers might sometimes be more appropriate depending on context. This continues the series' pattern of documenting existing practices rather than imposing new rules.
