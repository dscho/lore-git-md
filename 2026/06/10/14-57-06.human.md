This is a refactoring series from Patrick Steinhardt that removes the use of `chdir_notify_reparent()` in Git's reference backends. The series grew larger than expected due to uncovering some oddities in how reference databases are constructed with "onbranch" configurations.

The key changes:
- Converts reference backends to always use absolute paths internally
- Removes the now-unnecessary `chdir_notify_reparent()` mechanism
- Fixes some subtle issues around reference database construction that were previously masked by the chdir notification system
- Includes some cleanup of repository setup code along the way

The series builds on Patrick's recent work centralizing object database creation. While the first few setup.c patches weren't strictly needed for the refs changes, Patrick kept them as worthwhile cleanups.

This appears to be a well-motivated technical cleanup that removes some complexity while fixing latent issues. The changes touch core reference handling code but come with test updates showing the behavior remains correct. The series is part of Patrick's ongoing work to modernize Git's reference storage layer.
