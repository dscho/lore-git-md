This is patch 5/9 in Patrick Steinhardt's series modernizing Git's reference backend infrastructure by eliminating chdir_notify_reparent() usage. The patch removes the now-unused `chdir_notify_reparent()` function and its helper callback after all callers were removed in previous patches.

The changes are straightforward cleanup:
- Deletes the `reparent_cb` helper function and `chdir_notify_reparent()` from chdir-notify.c
- Updates the header file documentation to remove mention of the convenience function
- Maintains the core chdir notification machinery while removing this specific helper

This continues the series' goal of simplifying the ref backend code by moving away from relative path handling via chdir notifications. The removal is safe since earlier patches in the series (particularly patch 4) replaced all uses with direct absolute path handling. The patch demonstrates good hygiene by cleaning up now-dead code rather than leaving it as unused cruft.
