This is the first patch in Patrick Steinhardt's v4 series introducing the `git history drop` command. It's a preparatory refactoring that splits out index handling functionality from `repo_read_index_unmerged()` into a new standalone function `index_state_unmerged_to_stage0()`.

The change makes the unmerged-entry cleanup operation reusable for arbitrary index states, not just the repository's main index. This will be needed for the drop command's implementation in later patches. The patch also fixes a minor signedness mismatch in the index iteration.

This is a straightforward mechanical refactoring with no behavior change - the existing functionality is just being reorganized for better reuse. The patch is small (12 lines changed) and focused, touching only the index handling code in read-cache.c. It's a typical preparatory patch that enables the more interesting changes to come in the series.
