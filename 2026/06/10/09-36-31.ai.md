This is a refactoring patch series that continues the effort to migrate configuration settings from global variables to repository-scoped storage, specifically targeting `trust_executable_bit` as part of the `the_repository` removal project. The series represents version 2 of the work, incorporating feedback from the previous iteration.

Key changes in this version:
1. The scope has been narrowed - the patch to pass `istate` to stat/mode helpers has been dropped to keep the changes focused
2. A safe getter function `repo_trust_executable_bit()` has been added
3. Documentation for `ce_mode_from_stat()` has been improved

The series makes three main changes:
1. Cleans up redundant extern declarations in read-cache
2. Moves `ce_mode_from_stat()` to read-cache.c where it's primarily used
3. Migrates the `trust_executable_bit` variable into `repo_config_values`

The work builds on previous attempts to scope this configuration properly, with the author noting that earlier approaches targeting `struct repo_settings` were deemed suboptimal. The changes touch core index handling code, modifying how filesystem capability flags are stored and accessed while maintaining the existing eager parsing behavior needed for performance.

This appears to be a well-structured incremental step in the larger `the_repository` elimination effort. The author has clearly incorporated feedback from mentors and previous discussion, focusing the scope while still making meaningful progress toward the long-term goal. The changes remain mechanical and behavior-preserving, just moving state management to be more explicitly scoped.
