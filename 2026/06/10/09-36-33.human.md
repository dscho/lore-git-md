This is the second patch in a 3-part refactoring series that moves the `trust_executable_bit` configuration into repository-scoped storage as part of the ongoing `the_repository` removal effort. The patch focuses on relocating the `ce_mode_from_stat()` function from `read-cache.h` to `read-cache.c` to better encapsulate its dependencies.

The key change is moving the implementation` of `ce_mode_from_stat()` from a static inline in the header file to a proper function in the C file. This prepares for future work where the function will need access to repository-specific configuration. The patch also adds documentation explaining the function's purpose in determining file modes while handling filesystem limitations.

Notably, this version drops the `extern` declarations that were previously needed when the function was in the header file. The change is behavior-preserving but enables the next step of properly scoping the configuration variables. The patch has been reviewed by multiple mentors and appears ready for inclusion.

This continues the incremental but meaningful progress on the larger `the_repository` elimination effort, with careful attention to maintaining clean boundaries between components.
