This is the first patch in Kristoffer Haugsbakk's documentation series updating the SubmittingPatches guidelines, specifically focusing on trailer usage conventions. The patch strengthens the encouragement for using trailers to credit substantial contributions while adding clearer guidance about when and how to use them.

The key changes in this patch:
- Moves trailer discussion into its own "Commit trailers" section with a proper heading
- Replaces the passive "If you like" language with active encouragement to credit significant help
- Adds guidance about using proper Git author format (name + email) for trailers to ensure they work with tooling like `git shortlog`
- Notes that the threshold for crediting is a judgment call, aiming to prevent over-crediting of minor contributions
- Links the new section from the send-patches section where trailer usage was previously mentioned

The patch appears well-motivated by observed mailing list practices and maintains the project's philosophy of crediting contributions while avoiding trivial acknowledgments. It's a focused documentation improvement that codifies existing best practices without introducing new requirements. As part of a larger series, this sets up the foundation for more specific trailer-related guidance in subsequent patches.
