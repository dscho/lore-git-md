This is a documentation patch fixing AsciiDoc markup in the sideband configuration documentation, part of Tuomas Ahola's v2 series addressing formatting issues in config-related man pages.

The patch corrects a single typo in `sideband.adoc`, changing a malformed list delimiter from `cursor:` to `cursor::` to properly format the description list item. This is a straightforward mechanical fix that ensures the documentation renders correctly, maintaining consistency with the surrounding list items that already use double colons.

The change is minimal and uncontroversial, having already received positive review from Kristoffer Haugsbakk in the v1 iteration. As part of the broader documentation maintenance effort led by Jean-Noël Avila, this patch helps standardize the AsciiDoc syntax across Git's man pages. The fix is ready for merging alongside the other patches in the series.
