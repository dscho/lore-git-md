This is patch 2/3 in a refactoring series that moves the `ce_mode_from_stat()` function from `read-cache.h` to `read-cache.c` as part of the ongoing `the_repository` removal effort. The change prepares for future work that will need repository-specific configuration access by relocating the function implementation while maintaining identical behavior.

The patch:
1. Moves the static inline implementation from the header to the source file
2. Removes the now-unnecessary `extern` declarations of `trust_executable_bit` and `has_symlinks`
3. Adds documentation explaining the function's purpose and behavior
4. Preserves all existing functionality while making the codebase more amenable to future repository-scoping changes

The change is mechanical and behavior-preserving, with no user-visible impact. The new documentation helps clarify the function's role in handling filesystem capability degradation (for systems lacking symlinks or reliable executable bits). Multiple mentors have reviewed the approach, suggesting this is on track for inclusion in the larger refactoring effort.
