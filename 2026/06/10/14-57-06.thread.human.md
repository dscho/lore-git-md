Patrick Steinhardt has sent a 9-part series modernizing Git's reference backend infrastructure, with the focus on cleaning up path handling by transitioning to absolute paths throughout. The series eliminates the complex `chdir_notify_reparent()` callback mechanism that previously handled relative paths, replacing it with simpler absolute path computations.

The final patch in the series completes this transition by modifying `refs_compute_filesystem_location()` to always return absolute paths, removing the last remaining need for chdir_notify callbacks. This affects all ref backends (files, packed, and reftable) and results in more consistent error messages that now always use absolute paths. Several tests had to be updated to expect these new absolute paths in their output.

While this is a technical cleanup with no major functional changes, it represents an important simplification of the reference backend architecture. The series builds on Patrick's ongoing work to modernize Git's object and reference storage layers, connecting to his broader ODB abstraction and reftable integration efforts. So far there haven't been any reviews on the series, but given its focused nature and clear technical benefits, it seems likely to be picked up for merging after any minor feedback is addressed.
