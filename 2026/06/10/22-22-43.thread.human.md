Kristoffer Haugsbakk has proposed a six-part documentation series to clarify Git's commit message trailer conventions in the SubmittingPatches guidelines. The series comprehensively addresses trailer usage, including when to credit contributions, proper formatting, and the significance of trailer ordering - notably that `Signed-off-by` should appear last.

Junio C Hamano, the project maintainer, has reviewed the final patch about trailer ordering. While agreeing with the technical content, he suggests improving the explanation by first establishing the chronological principle behind trailer ordering - that they should reflect the sequence of contributions. This would prevent readers from mistakenly thinking the order is determined by trailer type rather than timeline. Junio's feedback is substantive and aims to make the documentation more precise, though it doesn't challenge the patch's core direction.

The series remains uncontroversial and likely to progress, now with this maintainer-suggested refinement. As the patches document existing practices rather than proposing new ones, they're expected to attract only light review before being merged, possibly from documentation specialists like Jean-Noël Avila or D. Ben Knoble. The changes will provide clearer guidance for contributors about properly crediting work in commit messages.
