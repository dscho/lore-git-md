This documentation patch series from Kristoffer Haugsbakk aims to clarify and standardize Git's commit message trailer conventions in the SubmittingPatches guidelines. The first patch establishes a dedicated "Commit trailers" section, actively encouraging the use of trailers to credit substantial contributions while providing clearer guidance on proper formatting (name + email) and appropriate usage to avoid over-crediting minor help. 

The series builds on prior mailing list discussions about trailer usage, consolidating these practices into official documentation. So far the thread has seen only the initial version from the author, with no reviews or objections yet. The changes appear non-controversial - they codify existing best practices rather than introducing new requirements - but will need review feedback before progressing. Subsequent patches in the series will address more specific trailer conventions like non-identity trailers and Linux-specific trailer usage in Git.
