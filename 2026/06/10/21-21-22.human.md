This is a documentation patch from Kristoffer Haugsbakk, part of an 11-patch series improving the `git-interpret-trailers` man page. The series was prompted by a bug report about strict parsing of trailer keys, but this particular patch focuses on clarifying the command's broader applicability.

The patch updates the DESCRIPTION section to note that `git-interpret-trailers` can process trailers in any text, not just commit messages, while still using commit messages as the primary example. It references git-tag's `--trailer` option (added in 2024) as evidence of this broader use case. The change is small but helps set accurate expectations for users who might want to apply the command to other text formats.

This is a straightforward documentation improvement that aligns with the series' goal of making the trailer functionality's scope and limitations clearer. The patch maintains the existing commit message example while adding the more general context.
