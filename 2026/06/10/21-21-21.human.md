This is a documentation patch from Kristoffer Haugsbakk, part of an 11-patch series improving the `git-interpret-trailers` man page. The series emerged from earlier discussions about trailer key format restrictions (ASCII alphanumeric + hyphen only) and aims to standardize terminology and improve clarity.

Patch 3/11 makes a small but meaningful change to the NAME section, replacing "structured information" with "metadata" to match the terminology introduced in previous patches. The rationale is that "metadata" is more concise while conveying the same meaning, and it maintains consistency with the rest of the documentation. This is a straightforward terminology alignment with no functional impact.

The patch is well-motivated and fits cleanly into the larger series' goal of standardizing documentation language. Given that earlier patches in the series have already established "metadata" as the preferred term, this change helps reinforce that consistency. The commit message clearly explains the reasoning behind the change.
