This is a documentation patch series fixing AsciiDoc markup issues in Git's config documentation, part of the ongoing effort to standardize man page formatting. Tuomas Ahola is sending an updated version of three small patches that were previously reviewed, incorporating feedback from Kristoffer Haugsbakk and Junio C Hamano.

The series addresses specific formatting problems:
1. Terminates runaway lists in config documentation by wrapping them in open blocks
2. Fixes a description list delimiter typo (cursor: -> cursor::) in sideband config docs
3. Escapes octothorpe (#) characters in git-config.adoc to prevent them from being interpreted as AsciiDoc highlight markers

The changes are mechanical and focused purely on documentation rendering, with no content changes. The v2 updates include improved commit message wording (changing "typo" to the more precise "description list delimiter") and additional octothorpe escaping as suggested in previous reviews.
