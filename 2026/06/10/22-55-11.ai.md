This is a documentation patch fixing AsciiDoc markup issues in git-config man pages, part of the ongoing effort to standardize documentation formatting. The patch specifically addresses list termination problems where paragraphs were incorrectly being appended to list items due to AsciiDoc parsing quirks.

The change wraps problematic list sections in open block delimiters (`--`) across four config-related documentation files (config.adoc, promisor.adoc, safe.adoc, git-config.adoc). This ensures proper rendering of paragraphs following lists. The fixes are mechanical and don't modify any content - they purely correct formatting.

This is the first patch in a v2 series that has already incorporated feedback from previous reviews, including Junio C Hamano's suggestion about octothorpe escaping consistency. The changes here are straightforward and uncontroversial, building on Jean-Noël Avila's broader documentation standardization work. The patch appears ready for merging as part of the documentation maintenance effort.
