This is a documentation patch series fixing AsciiDoc markup issues in git-config man pages, sent by Tuomas Ahola as part of the ongoing documentation maintenance effort. The series builds on Jean-Noël Avila's work standardizing man page formatting.

The v2 series contains three small fixes:
1. Terminates runaway lists in config documentation by wrapping them in open block delimiters
2. Corrects a description list delimiter typo in sideband.adoc (cursor: -> cursor::)
3. Escapes octothorpe (#) characters in git-config.adoc to prevent them from being interpreted as highlight markup

The changes are purely mechanical formatting fixes with no content modifications. The patches touch multiple config-related documentation files but each change is small and focused. The v2 iteration incorporates feedback from Kristoffer Haugsbakk on the commit message wording and expands the octothorpe escaping to be more thorough, addressing Junio C Hamano's earlier suggestion about consistency.
