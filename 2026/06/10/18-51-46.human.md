This is a documentation patch fixing AsciiDoc formatting issues in the git-config man pages. It's the first of three patches in a series originally started by Jean-Noël Avila, though this particular patch comes from Tuomas Ahola.

The patch addresses a common AsciiDoc quirk where paragraphs following lists can get incorrectly formatted. It wraps several lists in the config documentation with explicit open blocks (using `--` markers) to ensure proper rendering. The changes touch multiple files under Documentation/ but are purely mechanical formatting fixes - no content is altered.

The changes look correct and well-scoped, following the established pattern for fixing these documentation issues. Since this is part of the ongoing effort to standardize man page formatting, and the author has followed the project's documentation conventions, this patch should be uncontroversial. The commit message clearly explains both the problem and solution, making it easy to review.
