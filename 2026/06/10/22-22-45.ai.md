This is the second patch in Kristoffer Haugsbakk's documentation series updating the SubmittingPatches guidelines, focusing on trailer usage conventions. The patch adds guidance about non-identity trailers (those that don't credit people) to the documentation.

The change clarifies that while identity-related trailers (like Signed-off-by) are most common and encouraged, other types of trailers may be appropriate in some cases - for example, to reference an issue tracker from a downstream project affected by a Git bug. The patch maintains the existing advice against using trailers as a general metadata dumping ground.

This continues the series' theme of codifying existing practices around commit message trailers. The change is straightforward and unlikely to be controversial, as it simply documents current conventions rather than proposing new ones. The patch follows the same clean style as the rest of the series, with a clear commit message explaining the rationale.

As with the rest of the series, this documentation update helps standardize contributor expectations without requiring any code changes. The patch appears ready for review and likely eventual merging as part of the complete series.
