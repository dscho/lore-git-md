This is the first patch in Patrick Steinhardt's v4 series introducing the `git history drop` subcommand. The patch refactors index handling to split out functionality for cleaning up unmerged index entries into a standalone function.

The change extracts the unmerged-to-stage-0 conversion logic from `repo_read_index_unmerged()` into a new `index_state_unmerged_to_stage0()` function that can operate on any index state, not just the repository's main index. This prepares for future need to perform this operation on arbitrary indexes. The patch also fixes a signedness mismatch in the index iteration.

This is a mechanical refactoring with no behavior change - it simply makes the unmerged entry cleanup reusable. The new function is added to `read-cache-ll.h` for broader access. The implementation remains functionally identical, just moved to a more general location.

The change is part of the larger effort to support the `git history drop` command by modernizing and generalizing the reset machinery. This particular piece provides cleaner index handling infrastructure that will be used by subsequent patches in the series.
