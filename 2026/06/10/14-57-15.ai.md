This is the final patch in Patrick Steinhardt's 9-part refactoring series to modernize Git's reference backend infrastructure. The patch completes the transition to absolute paths in reference backends by modifying `refs_compute_filesystem_location()` to always return absolute paths, eliminating the last need for `chdir_notify_reparent()` callbacks.

The key changes are:
- Modifies path computation to always resolve to absolute paths via `strbuf_realpath()`
- Removes now-unnecessary chdir_notify registration from all ref backends (files, packed, reftable)
- Updates test expectations to match new absolute path output in error messages

This builds on the series' earlier work to simplify reference backend initialization and path handling. The change is mostly mechanical but does have a user-visible impact - error messages will now consistently show absolute paths rather than sometimes showing relative ones. The patch includes updates to several test scripts to accommodate this change.

The removal of chdir_notify callbacks completes the architectural cleanup started earlier in the series, resulting in simpler and more predictable path handling across all reference backends. This final patch appears well-contained and aligns with the series' overall goals.
