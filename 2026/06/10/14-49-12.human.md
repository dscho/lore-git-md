This is a refactoring patch from Toon Claes, part of a series adding a `--linearize` option to `git replay`. The patch simplifies the code by converting an enum (`replay_mode`) that had only two possible values into a boolean flag (`reverse`). 

The change makes the code more straightforward by:
- The enum definition and its BUG() checks for invalid values
- Ternary operators checking the enum value
- Some conditional logic branches

The patch maintains all existing functionality while reducing complexity. It's a clean mechanical change that follows through the call chain consistently, updating all affected functions to use the boolean instead of the enum. The commit message clearly explains the motivation and the change's safety.

This is the first of three patches in the series, setting up the internal structure before introducing the new `--linearize` feature in later patches. The change has already been reviewed in v1 of the series and incorporated feedback, with no new issues raised in v2.
