This is patch 8/9 in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. The patch focuses on a small optimization in `refs_compute_filesystem_location()` by eliminating an unnecessary intermediate buffer.

The change removes a local `strbuf` that was being used solely to construct a path before passing it to `strbuf_realpath()`. Since `strbuf_realpath()` can operate in-place on its input buffer, the patch simplifies the code by using the output buffer directly throughout. This avoids one memory allocation and release cycle while maintaining identical functionality.

The modification is straightforward and low-risk, touching only the internal path computation logic. It continues the series' theme of cleaning up reference backend code, though this particular change is more about code hygiene than the broader architectural improvements seen in earlier patches. The change demonstrates Patrick's attention to detail in optimizing even small utility functions.
