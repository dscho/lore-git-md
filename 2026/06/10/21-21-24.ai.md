This is patch 6/11 in Kristoffer Haugsbakk's documentation series for `git-interpret-trailers`, focusing on explicitly documenting the strict key format requirements for trailer keys (ASCII alphanumeric + hyphen only). The patch adds this specification to the man page, addressing a real-world issue where users were encountering silent failures with keys containing periods.

The change is straightforward - it inserts a sentence defining valid key characters right after introducing the key-value pair concept. The commit message explains this prevents users from having to infer the rules from examples (which only showed letters and hyphens, omitting digits). The patch maintains the series' focus on clarity while being technically accurate about the existing behavior.

This is part of the comprehensive documentation overhaul that emerged from a bug report about period-containing keys, with all feedback from previous rounds now incorporated. The series is in its final form and has been merged.
