This is the first patch in Patrick Steinhardt's 7-part series to eliminate global state in setup.c as part of the ongoing `the_repository` removal effort. The patch focuses on the `git_work_tree_cfg` global variable used during repository initialization.

The change makes `git_work_tree_cfg` file-local to setup.c and function-local to `cmd_init_db()`, removing its global visibility. The key insight is that the worktree location is already properly set via `set_git_work_tree()` which updates the repository structure, making the global variable redundant. The patch demonstrates Patrick's characteristic approach of methodically identifying and removing unnecessary global state while maintaining existing functionality.

The changes are mechanical but well-justified in the commit message, which explains why the global variable isn't needed. This is a typical preparatory step in the larger refactoring pattern - first making state local before eventually eliminating it entirely in later patches. The patch touches several files but the changes are straightforward and focused.
