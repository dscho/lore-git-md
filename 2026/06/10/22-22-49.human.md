This is the sixth and final patch in Kristoffer Haugsbakk's documentation series updating the SubmittingPatches guidelines, focusing on trailer conventions in commit messages. The patch adds a new section clarifying that trailer order matters - specifically that non-author trailers (like Acked-by) should appear before the Signed-off-by line, since the sign-off applies to both the patch content and all preceding trailers.

The explanation includes a clear example showing how proper ordering makes it obvious which acknowledgments were added by the original contributor versus later additions. This codifies an existing but previously unwritten rule about trailer sequencing that helps maintain clear attribution chains.

As with the rest of the series, this is a non-controversial documentation improvement that formalizes established mailing list practices. The change is well-motivated and clearly explained, making it a straightforward candidate for merging. The patch completes the series' goal of providing comprehensive guidance on Git's trailer conventions.
