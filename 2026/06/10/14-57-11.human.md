This is patch 5/9 in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. The patch removes the now-unused `chdir_notify_reparent()` function and its helper callback after the previous patches in the series eliminated all callers.

The change is straightforward - it deletes 26 lines of implementation code and simplifies the header file documentation to remove references to the removed function. This is a clean-up step in the larger effort to eliminate chdir notification callbacks from ref backends in favor of using absolute paths consistently.

The patch appears well-contained and mechanical, following the natural progression of the series. Since the function is no longer called anywhere, this removal should be uncontroversial. It continues the pattern of incremental simplification in the ref storage layer that Patrick has been driving.
