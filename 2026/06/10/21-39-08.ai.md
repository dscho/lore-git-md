This is a test cleanup patch from the maintainer Junio C Hamano. It fixes an issue in the t1400-update-ref.sh test script where lingering FIFO (named pipe) files could cause later tests to hang.

The problem occurs when a test creates FIFOs named "in" and "out" but doesn't clean them up. Subsequent tests that try to use files with these generic names get blocked because the FIFOs remain but nothing is reading from them. The patch adds a `test_when_finished` cleanup handler to remove these FIFOs after the test completes.

This is a straightforward maintenance fix that follows Git's test hygiene practices - tests should clean up after themselves to avoid affecting other tests. The change is minimal (just one line added) and clearly explained in the commit message. Since it comes from the maintainer and addresses a clear issue, it's likely to be merged without controversy.
