This is a documentation patch fixing AsciiDoc formatting issues in config-related man pages, part of an ongoing series by Tuomas Ahola building on Jean-Noël Avila's documentation standardization work.

The patch specifically addresses a common AsciiDoc quirk where paragraphs following lists can be incorrectly interpreted as list continuations. It fixes this by wrapping affected lists in open block delimiters (`--`), ensuring proper rendering. The changes touch four files (`config.adoc`, `promisor.adoc`, `safe.adoc`, and `git-config.adoc`) but are purely mechanical formatting fixes with no content modifications.

This is the first of three patches in v2 of the series, which has already incorporated feedback from Junio C Hamano and Kristoffer Haugsbakk on earlier versions. The changes are straightforward and appear ready for merging as part of the broader documentation cleanup effort. The patch demonstrates careful attention to detail in addressing a subtle but important formatting issue that affects man page readability.
