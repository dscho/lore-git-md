This is the first patch in Kristoffer Haugsbakk's documentation series updating the SubmittingPatches guidelines, specifically focusing on trailer usage conventions. The patch strengthens the recommendation to use trailers (like `Reviewed-by`, `Helped-by`) to credit substantial contributions, while cautioning against overuse for minor feedback.

The changes move trailer discussion into its own section and clarify that credited names should follow Git's standard author format (name + email) to work with tools like `git shortlog`. The patch also frontloads a list of common trailers that was previously only implied later in the document.

The motivation comes from observed mailing list practices and a desire to standardize contributor expectations. This appears to be a thoughtful documentation improvement that codifies existing community norms while providing clearer guidance for new contributors.
