This is a refactoring patch from Patrick Steinhardt's v4 series introducing the `git history drop` command. The patch modernizes the flags passed to `reset_working_tree()` (formerly `reset_head()`) by converting them from #defines to an enum and updating their names to match the new function name.

The changes are mechanical but widespread, touching:
- Flag declarations in reset.h (now an enum with RESET_WORKING_TREE_* prefixes)
- Flag usage in builtin/rebase.c, reset.c, and sequencer.c
- Documentation of the flags in reset.h

The patch maintains the same flag semantics while bringing the code in line with current Git conventions. It's part of a larger effort to clean up and modernize the reset machinery while eliminating `the_repository` usage. The changes are straightforward and unlikely to be controversial, having been reviewed in previous iterations of the series.

This continues the pattern seen throughout the series of careful, incremental modernization that improves code quality while maintaining backward compatibility. The patch demonstrates good attention to detail in updating all call sites consistently.
