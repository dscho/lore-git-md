This documentation thread continues the effort to clean up AsciiDoc markup in Git's config-related man pages, now in its third iteration. The series, originally from Jean-Noël Avila but currently shepherded by Tuomas Ahola, addresses subtle parsing issues that affect how lists and special characters render in the final documentation.

The core challenge has been handling octothorpe (#) escaping and list termination quirks in AsciiDoc. After testing revealed context-sensitive behavior with backslash escaping, the series settled on using backticks (`#`) as the most reliable solution. The current v3 patch focuses specifically on fixing cases where paragraphs meant to follow lists were being incorrectly appended to the last list item. The solution wraps these problematic lists in open blocks (delimited by --) across four config documentation files.

Jeff King (Peff) previously confirmed the technical soundness of this approach through doc-diff testing, though he noted some typographical tradeoffs in the rendered output. Junio C Hamano had earlier approved related fixes while flagging the need for consistent octothorpe handling. With no outstanding objections and the backtick solution now proven effective, these changes represent straightforward documentation maintenance as part of the broader AsciiDoc conversion effort. The patches are expected to merge cleanly into the ongoing work.
