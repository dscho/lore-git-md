This is a documentation patch that's part of a larger series introducing a new lint tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The patch adds comprehensive documentation for the `test_grep` helper function to t/README, which was previously missing despite the helper being widely used.

The documentation clearly explains:
- The purpose of `test_grep` (providing better debugging output than bare grep)
- How to use it for both positive and negative assertions (noting the special '!' syntax)
- When to use it (for assertions) vs when to stick with plain grep (for filters/command substitution)
- The importance of using the built-in negation rather than shell negation to preserve diagnostic output

This is a well-written addition that will help contributors understand the proper use of `test_grep` in test scripts. The explanation is thorough yet concise, covering both basic usage and edge cases. As the first patch in the series, it provides necessary background for the automated conversions that follow.
