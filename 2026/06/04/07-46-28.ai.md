This is the fourth patch in Patrick Steinhardt's v3 series refactoring repository initialization and object database setup, part of the ongoing ODB abstraction effort.

The patch removes object database initialization from `repo_set_gitdir()`, where it was previously happening alongside other Git directory setup. This change untangles the initialization sequence by separating ODB creation from directory configuration. The ODB initialization is moved to callers - both `repo_init()` and `setup_git_env_internal()` now handle it directly.

The change introduces temporary duplication (initializing the ODB in two places) which will be resolved in patch 8/8 when ODB creation is centralized in `apply_repository_format()`. The patch maintains all existing functionality while making the initialization sequence clearer and more maintainable.

This is a mechanical refactoring step that prepares for the larger architectural change coming later in the series. It has already been thoroughly reviewed by Karthik Nayak in previous iterations, with all feedback addressed in this v3. The patch is now in its final form and ready for merging as part of the complete series.
