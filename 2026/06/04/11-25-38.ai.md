This is patch 11/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `count_objects()` callback for packed sources, moving the implementation from packfile.c to odb/source-packed.c.

The changes are mechanical:
- Moves `packfile_store_count_objects()` to become `odb_source_packed_count_objects()`
- Updates the files backend to call the new interface
- Preserves all existing behavior including MIDX handling and error conditions
- Removes the now-unused declaration from packfile.h

The implementation counts objects by:
1. Adding MIDX objects (if present)
2. Iterating through non-MIDX packs and summing their object counts
3. Handling pack index opening errors appropriately

This continues the pattern seen in previous patches of the series - moving functionality into the new ODB abstraction layer while maintaining identical behavior. The diffstat (+34/-42 lines) shows this is primarily a code reorganization rather than introducing new logic.

The patch appears well-contained and follows the established conversion approach. As with the rest of the series, the main consideration will be ensuring all edge cases (particularly around MIDX and repack interactions) are properly handled in the new location.
