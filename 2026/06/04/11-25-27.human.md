This is a major refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The series converts Git's packed object storage into a proper `struct odb_source`, following a similar conversion for loose objects that was recently merged.

The key changes include:
- Renaming `struct packfile_store` to the more consistent `struct odb_source_packed`
- Moving packed object source handling into the odb/ subsystem
- Wiring up all the required callbacks for the packed source to function as a proper odb_source
- Refactoring midx (multi-pack-index) interfaces to work with the new structure

The series is quite large (16 patches touching 24 files) but appears to be a logical next step in the ODB abstraction work. Patrick notes this should be the last major code movement in this area, with future changes being more incremental. The changes are built on established patterns from the loose objects conversion, suggesting the approach is well-proven.

This is a technical plumbing change that won't directly impact end users, but is important infrastructure work for enabling future object storage backends. Given Patrick's deep involvement in the ODB abstraction effort and the careful progression of these changes, the series appears well-considered and likely to merge after review.
