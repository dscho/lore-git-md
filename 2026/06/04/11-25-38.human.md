This is patch 11/16 in Patrick Steinhardt's series converting Git's packed object storage to use the new `struct odb_source` interface, part of the ongoing ODB (object database) abstraction effort. 

The patch moves the `count_objects()` functionality from packfile.c to odb/source-packed.c, implementing it as a proper callback in the packed source interface. The change is mechanical - the implementation remains identical but is now called through the new abstraction layer. Key aspects:

- Preserves the existing behavior of counting objects across both multi-pack-indexes and individual packfiles
- Handles error cases the same way (returning -1 if pack index cannot be opened)
- Updates the files backend to use the new callback interface rather than calling the packed store directly

This continues the pattern seen in previous patches of the series - moving functionality while maintaining identical behavior. The diff shows a straightforward code movement (-31 lines from packfile.c, +34 in odb/source-packed.c) with no functional changes. 

With this patch, only two remaining callbacks (`find_abbrev_len()` and `freshen_object()`) need to be implemented to complete the packed source conversion. The series remains unreviewed but follows the established pattern that has worked well for the loose object storage conversion.
