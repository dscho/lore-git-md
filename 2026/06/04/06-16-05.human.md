This is a technical discussion about repository mirroring and submodule handling, with Jeff King (Peff) proposing an alternative approach to Simon Richter's UUID-based solution for Debian's mirroring needs.

Peff suggests leveraging Git's existing `url.*.insteadOf` configuration mechanism rather than introducing UUIDs. He demonstrates how repository URLs could be rewritten to use a custom `repoid://` scheme, which could be mapped to actual URLs via config. This would allow Debian to maintain stable references to submodules while still enabling flexible mirroring.

The proposal is notable for its simplicity - it uses existing Git features rather than requiring new mechanisms. Peff acknowledges this may not fully address all aspects of the original request, but suggests it might cover the core need for URL rewriting. He questions whether UUIDs are actually necessary if the same result can be achieved through URL rewriting.

This moves the discussion forward by offering a concrete, lightweight alternative to the more complex solution previously discussed. The approach would work for both submodules and general repository mirroring, aligning with Junio's preference for a general solution.
