This is patch 9/16 in Patrick Steinhardt's series converting Git's packed object storage to use the new `struct odb_source` interface, part of the ongoing ODB (object database) abstraction effort.

The patch wires up the `read_object_stream()` callback for packed object sources, moving the implementation from packfile.c to odb/source-packed.c while maintaining identical behavior. The key changes are:
- Implements `odb_source_packed_read_object_stream()` as the new callback
- Updates the files backend to use the new interface via `odb_source_read_object_stream()`
- Removes the now-unused `packfile_store_read_object_stream()` function

The changes are mechanical and follow the same pattern as previous patches in the series, continuing the conversion of direct packfile access to go through the ODB abstraction layer. The diff shows a net zero line count change (17 lines added, 17 removed), with code being relocated rather than substantially modified.

This patch is part of Patrick's larger effort to make Git's object storage pluggable by abstracting away the implementation details of packed and loose object storage behind a consistent interface.
