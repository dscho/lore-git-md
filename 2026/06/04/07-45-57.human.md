This is a test infrastructure patch fixing three cases where grep assertions in tests were missing their file arguments, causing them to silently pass incorrectly. The patch is part of a larger series introducing a lint tool to catch such issues.

The patch fixes three specific test cases where `grep` was reading from stdin instead of the intended file due to missing file arguments. In each case, the test was effectively not checking what it claimed to be checking since an empty stdin always matches nothing. The author confirms the tests pass with the corrected arguments, validating the intended behavior.

The changes are straightforward:
1. t2402-worktree-list.sh: Adds missing 'out' file argument to a negated grep
2. t7507-commit-verbose.sh: Fixes a malformed grep pattern that was treating the entire diff command as the pattern
3. t7700-repack.sh: Adds missing 'packlist' file argument to a negated grep

This patch demonstrates the practical value of the larger linting effort by fixing real bugs in the test suite that had gone unnoticed. The changes are small but meaningful improvements to test reliability.
