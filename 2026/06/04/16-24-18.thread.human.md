Johannes Schindelin (Dscho) has proposed bringing two Windows-specific process management improvements from Git for Windows into the main Git project. The first patch introduces graceful process termination on Windows by using thread injection to call ExitProcess() rather than TerminateProcess(), allowing atexit handlers to run - a solution that's been battle-tested in Git for Windows for nearly a decade. The second patch, just arrived, improves Ctrl+C handling by properly translating Windows' console events into SIGINT signals, making Git behave more like its Unix counterpart when interrupted.

Together, these changes make Git's process management on Windows more predictable and Unix-like, particularly when running under MSYS2. The implementations are carefully scoped to Windows-specific code paths and include thorough documentation of their behavior and limitations. Both patches have already proven reliable through extensive real-world use in Git for Windows.
