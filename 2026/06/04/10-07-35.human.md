This is a test infrastructure patch that fixes TAP output corruption in the grep tests (t7810) when multibyte regex support is missing. It's part of Patrick Steinhardt's v3 series addressing various test suite issues.

The patch converts the multibyte regex capability check from an immediate test to a lazy prerequisite. Previously, when run on systems without proper locale support, the failing check would output an error message that broke the TAP protocol format. The new version defers the check until actually needed, keeping the output properly formatted.

The change is small (3 lines modified) but important for test reliability. It follows the same pattern used in an earlier patch for fsmonitor tests (t7527) and addresses feedback from Jeff King about TAP output validation. The fix is straightforward and uncontroversial, aligning with the series' goal of making test output more robust.
