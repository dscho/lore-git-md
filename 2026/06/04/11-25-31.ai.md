This is the fourth patch in Patrick Steinhardt's 16-part series converting Git's packed object storage to use `struct odb_source` as part of the broader ODB abstraction effort. The patch begins implementing the packed source as a proper pluggable backend by:

1. Embedding `struct odb_source` in `struct odb_source_packed` and assigning it the new `ODB_SOURCE_PACKED` type
2. Wiring up lifecycle management with a `free` callback implementation
3. Taking ownership of chdir notifications from the parent files source
4. Removing the now-redundant `packfile_store_free()` function

The changes are mechanical but important groundwork - they establish the packed source as a first-class `odb_source` while maintaining existing functionality. The patch touches 6 files with 60 lines added and 22 removed, mostly moving code between files rather than changing behavior. Subsequent patches will implement the remaining required callbacks to make the packed source fully functional as a standalone backend.

This continues Patrick's pattern of careful, incremental refactoring seen in previous ODB work. The changes appear straightforward and low-risk, though reviewers will want to verify the chdir notification handoff between parent and packed sources works as intended.
