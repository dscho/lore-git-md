This is the third patch in Patrick Steinhardt's v3 series standardizing CI environments between GitLab and GitHub. It aligns the Linux container images used in both CI systems to ensure consistent test behavior.

The patch makes two mechanical changes:
1. Updates the "linux-breaking-changes" job in GitLab CI to use `ubuntu:rolling` (matching GitHub's existing configuration)
2. Changes GitHub's "linux32" job to use the version-numbered `ubuntu:20.04` tag (equivalent to the existing "focal" tag but more consistent with other jobs)

These changes eliminate the last remaining differences in Linux container configurations between the two CI systems, ensuring tests run in identical environments regardless of platform. The patch is straightforward and uncontroversial, continuing the series' goal of CI standardization.
