This is the third patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch makes the relationship between packed object storage and its parent "files" source more explicit by changing the generic `struct odb_source*` pointer to a specific `struct odb_source_files*` pointer.

The key changes are:
- Renames the `source` field in `struct odb_source_packed` to `files` to clarify it always points to a files source
- Updates all related function signatures and call sites to use the more specific type
- This is an intermediate step toward completely removing the parent pointer in later patches

The patch is mechanical and focused - it touches 4 files with straightforward changes to variable names and types. As noted in the commit message, this change helps make subsequent refactoring steps clearer by being explicit about the relationship between packed storage and its files parent. The diff shows the changes are localized and don't introduce new logic.

This continues the pattern from earlier patches in the series of incremental, well-explained changes to prepare for more substantial ODB abstraction work. The patch appears low-risk and uncontroversial, though as with the rest of this large series, the midx and repack interactions will need careful review in later patches.
