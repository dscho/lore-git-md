This is patch 12/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `find_abbrev_len()` callback for packed sources, moving the implementation from packfile.c to odb/source-packed.c.

The changes are mechanical - the implementation remains identical but is now called through the new ODB interface. The patch:
- Moves `packfile_store_find_abbrev_len()` and helper functions
- Updates the files backend to use the new callback
- Adds the callback to the packed source vtable
- Removes the now-unused declarations from packfile.h

The implementation handles both MIDX and non-MIDX packs, checking nearby objects to determine the minimum unambiguous abbreviation length for a given OID. The diff shows pure code movement with no behavior changes (+112/-117 lines).

This continues the pattern seen in previous patches of the series - each one wires up another required callback in the packed source implementation. With this change, only the `freshen_object()` callback remains to be implemented in the final patches.
