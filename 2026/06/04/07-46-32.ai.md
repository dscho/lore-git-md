This is the final patch (8/8) in Patrick Steinhardt's v3 series refactoring repository initialization and object database setup, part of the ongoing ODB abstraction effort. The patch completes the centralization of object database creation by moving it into `apply_repository_format()`.

Key changes in this patch:
- Object database construction is now handled within `apply_repository_format()` rather than being duplicated across multiple callers
- Introduces a new `APPLY_REPOSITORY_FORMAT_HONOR_ENV` flag to control whether environment variables should be respected
- Carefully sequences ODB creation between hash algorithm setup and compat hash setup
- Removes redundant ODB initialization code from several locations (`repo_init()`, `enter_repo()`, `setup_git_directory_gently()`, `init_db()`)

The patch maintains the careful sequencing noted in previous iterations - ODB is created after setting the main hash algorithm but before setting the compat hash algorithm. The commit message acknowledges this ordering could potentially be improved further but leaves that for future work.

This completes the series' goal of centralizing ODB initialization while preserving all existing functionality. The changes are internal plumbing improvements with no user-visible behavior differences. With all review feedback addressed in v3 and the series now fully mechanical, it appears ready for merging into the next integration window.
