Test infrastructure patch converting bare 'grep' assertions to 'test_grep' in the test suite. This is the final patch in a 6-part series introducing a new lint tool to improve test debugging.

The patch extends lint-style.pl to detect bare 'grep' commands used as test assertions and convert them to 'test_grep', which provides better failure output by showing file contents. The implementation:
- Distinguishes grep assertions from grep used as filters by analyzing shell context (pipes, control flow, redirects)
- Handles various grep flags and negation patterns
- Preserves formatting when fixing
- Includes tests for the conversion rules
- Applies the conversion to ~2800 grep assertions across ~340 test files

Five test files require '# lint-ok' annotations for cases where bare grep is intentionally used (e.g. checking packed-refs existence with reftable). The patch also fixes several pre-existing test bugs where grep assertions were missing file arguments.

This builds on earlier series patches that:
- Documented test_grep usage
- Extracted shell parsing from chainlint.pl
- Fixed line counting in the parser
- Added initial lint tool infrastructure

The implementation appears thorough, with careful attention to edge cases and shell syntax handling. The series demonstrates both tooling improvements and concrete fixes to the test suite.
