This is a test infrastructure patch in response to a review comment on a series introducing a lint tool for Git's test suite. The author, Michael Montalbo, acknowledges D. Ben Knoble's suggestion to extract the complex Makefile shell script into a separate file for better maintainability. The original patch (4/6 in the series) adds a lint tool that detects and fixes incorrect negation patterns in test_grep assertions, converting shell-level negation (`! test_grep`) to use test_grep's built-in negation (`test_grep !`).

The exchange is brief and constructive - Montalbo agrees with the improvement and indicates it will be addressed in a follow-up. The core functionality of the lint tool (which has already found and fixed several test bugs) remains unchanged by this interaction. The series as a whole represents a significant quality improvement for Git's test suite by standardizing grep assertions to preserve diagnostic output on failures.
