This is patch 8/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `read_object_info()` callback for packed object storage, moving the implementation from packfile.c to odb/source-packed.c.

Key changes:
- Moves `find_pack_entry()` and implements it as the core lookup function for packed objects
- Implements `odb_source_packed_read_object_info()` as the callback that will be used through the new ODB interface
- Updates callers to use the new interface rather than direct packfile access
- Temporarily exposes `find_pack_entry()` to other packfile.c callers until they can be converted in later patches

The changes are largely mechanical, continuing the pattern established in earlier patches of the series. The diff shows 60 lines added and 78 removed, with most changes being straightforward relocations rather than functional modifications.
