This is a CI configuration patch that standardizes Linux test environments between GitLab and GitHub workflows, part of Patrick Steinhardt's larger test infrastructure series.

The patch unifies the Docker images used for the "linux-breaking-changes" job (now using `ubuntu:rolling` on both platforms) and aligns the naming convention for the "linux32" job (using `ubuntu:20.04` instead of `ubuntu:focal` on GitHub). These changes eliminate minor discrepancies between the CI systems while maintaining identical test environments.

The modifications are straightforward and mechanical, touching only the CI configuration files. This patch builds on the series' goal of ensuring consistent test behavior across platforms by removing one of the last remaining differences between the GitHub and GitLab CI setups. The changes follow naturally from Jeff King's earlier feedback about CI standardization gaps.
