This is a test infrastructure fix in a series introducing a new lint tool for test assertions. The patch corrects three instances where grep assertions in tests were missing their file arguments, causing them to silently pass by reading from empty stdin rather than the intended files.

The fixes address:
1. A worktree listing test where the negation check for unprunable worktrees wasn't reading the output file
2. A commit verbose test with a malformed grep pattern that accidentally made the filename part of the pattern
3. A repack test checking for object presence where the file argument was omitted

The author notes these were effectively no-op assertions that now properly verify the intended conditions. The changes are straightforward file argument additions that preserve the original test logic while making the assertions actually work. This patch demonstrates the value of the series' broader linting effort by catching subtle but meaningful test bugs.
