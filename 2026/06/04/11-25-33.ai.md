This is patch 6/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `reprepare()` callback for packed sources, moving the logic from packfile.c to odb/source-packed.c.

Key changes:
- Implements `odb_source_packed_reprepare()` which clears and reinitializes the packed source
- Adds `odb_source_packed_prepare()` to handle initial packfile/MIDX loading
- Moves packfile sorting and garbage reporting logic to the new location
- Updates callers to use the new interface rather than direct packfile_store functions
- Maintains all existing behavior while restructuring the code organization

The patch continues the mechanical conversion pattern seen in earlier parts of the series, with most changes being straightforward relocations of existing code. The diffstat (+157/-160) shows this is primarily a code movement patch with minimal functional changes.

This is part of Patrick's ongoing effort to abstract Git's object storage layer to support pluggable backends. The series remains unreviewed at this point, though the changes appear consistent with the established pattern from previous ODB abstraction work.
