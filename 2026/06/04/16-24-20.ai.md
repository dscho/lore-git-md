This is the second patch in Johannes Schindelin's Windows process management series, focusing on SIGINT handling. The patch improves Ctrl+C behavior when running Git under MSYS2 on Windows by properly installing a ConsoleCtrlHandler.

The key change is adding a handler that translates Windows' CTRL_C_EVENT into a proper SIGINT signal, which allows Git processes to terminate cleanly while leaving pagers (like `less`) running - matching Unix behavior. The implementation is minimal (9 lines added) and well-contained in the Windows-specific compat/mingw.c file.

This completes the series' goal of bringing Windows process termination closer to Unix semantics. The solution is production-proven, having been used in Git for Windows for years. The patch maintains the series' high quality with clear commit message explaining the behavioral improvement.
