This is a platform compatibility patch series addressing Windows-specific limitations with large objects (>4GB) on LLP64 systems. The series, originally contributed by Philip Oakley and maintained in Git for Windows for 4 years, converts object header length handling from `unsigned long` to `size_t` to properly support large files on Windows where `unsigned long` is 32-bit.

The patches demonstrate the issue through test cases and systematically update the relevant code paths in `object-file.c`, SHA-1 implementation, and related headers. The changes are focused and mechanical, primarily involving type signature updates. The series has proven stable through years of production use in Git for Windows, with Johannes Schindelin now proposing it for upstream inclusion.

The final patch in the series adds test coverage for the clean/smudge filter interface with large files, completing the validation of all major code paths. The changes are complementary to other ongoing large-object handling work in Git. With Johannes Schindelin's sign-off and the long production validation, this appears ready for merging as a well-tested solution to a real platform limitation.
