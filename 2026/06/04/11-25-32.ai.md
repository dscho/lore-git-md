This is the fifth patch in Patrick Steinhardt's 16-part series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort.

The patch implements the `close()` callback for packed object sources, moving the functionality from the standalone `packfile_store_close()` function into the new ODB source interface. Key changes include:
- Adds `odb_source_packed_close()` that handles closing both packfiles and MIDX (multi-pack-index) files
- Updates the files source to use the generic `odb_source_close()` interface rather than calling `packfile_store_close()` directly
- Removes the now-unused `packfile_store_close()` function and its declaration
- Maintains the same safety check for `do_not_close` packs that existed in the original implementation

The changes are largely mechanical, continuing the pattern of moving packed object storage logic into the ODB subsystem while preserving existing behavior. This patch builds on the foundation laid in previous patches that established the packed source structure and basic callbacks.

The implementation appears straightforward and maintains all existing functionality while fitting into the new ODB source abstraction. As with the rest of the series, this is an incremental step toward the larger goal of making Git's object storage fully pluggable.
