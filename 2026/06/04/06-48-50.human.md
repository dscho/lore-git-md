Git-gui build system fix for silent mode behavior, now with corrected parameter order.

This v3 patch from Harald Nordgren addresses the final issue in the series to make git-gui's Makefile properly respect `make -s` silent mode. The key change in this version is fixing the inverted `findstring` parameter order that Johannes Sixt identified in his review - the previous version was checking for "-s" in "s" rather than "s" in MAKEFLAGS, which would never match correctly.

The commit message now clearly explains both the original issue (install/uninstall recipes emitting output even in silent mode) and the specific fix for the `findstring` logic. The patch maintains compatibility with the approach used in `shared.mak` while confining changes to just 6 lines in git-gui/Makefile (4 deletions, 2 additions).

With this revision, the technical implementation appears sound and well-documented. The remaining open question about standalone builds without shared.mak is noted but not blocking for this particular fix. The thread demonstrates effective collaboration between Harald and Johannes to catch and correct a subtle build system edge case.
