The two patches have been carried in Git for Windows for nearly a decade and are now proposed for upstream inclusion. The core issue addresses Windows' lack of direct equivalents to Unix signals like SIGTERM - currently Git uses TerminateProcess() (similar to Unix's SIGKILL), preventing proper cleanup. The solution introduces a gentler approach by creating remote threads to call ExitProcess() (emulating SIGTERM behavior) and properly handling SIGINT emulation in the MSYS2 runtime. The changes are contained to Windows-specific code in compat/mingw.c and a new compat/win32/exit-process.h header. While having some limitations (won't work across different CPU architectures), this represents a significant improvement over the current brute-force termination.
