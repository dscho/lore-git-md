This is the first patch in Patrick Steinhardt's v3 series refactoring repository initialization and object database setup. The patch adds missing test coverage for `git-init` behavior with the `GIT_OBJECT_DIRECTORY` environment variable.

The test verifies that when `GIT_OBJECT_DIRECTORY` is set, `git init` creates the object directory at the specified path rather than the default `.git/objects` location. This was documented behavior but not previously tested, and the upcoming refactoring could have inadvertently broken it without these tests catching the regression.

The test case is straightforward: it creates a custom object directory, runs `git init` with `GIT_OBJECT_DIRECTORY` set to that path, and verifies the objects directory structure appears in the custom location rather than the default one. This is a clean, focused test that will help ensure the expected behavior is maintained through the subsequent refactoring changes.

As the first patch in a well-reviewed series that has already gone through multiple iterations, this test addition is a prudent foundation for the architectural changes that follow. The patch follows Git's standard test patterns and includes appropriate cleanup via `test_when_finished`.
