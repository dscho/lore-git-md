This is the 7/16 patch in Patrick Steinhardt's series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The change is a mechanical conversion to use the new `packfile_store_read_object_info()` interface rather than directly calling the lower-level `find_pack_entry()`.

The patch updates `has_object_pack()` to check for object existence via the higher-level ODB interface, which will eventually make `find_pack_entry()` an internal implementation detail of the packed source backend. The change is straightforward - replacing a direct packfile lookup with a call through the new interface while maintaining identical behavior.

This continues the pattern seen in earlier patches of the series, systematically moving packed object operations behind the ODB abstraction layer. The diff is small (4 lines removed, 2 added) and focused, typical of Patrick's incremental approach in this large refactoring effort. The change appears uncontroversial and well-contained, though as with the broader series, it will need review from those familiar with the packed object storage internals.
