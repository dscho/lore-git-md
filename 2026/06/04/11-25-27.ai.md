This is a major refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The series converts the packed object storage backend into a proper `struct odb_source`, following the same pattern previously applied to the loose object storage in an earlier series.

The key changes include:
- Renaming `struct packfile_store` to the more consistent `struct odb_source_packed`
- Moving packed source code into the odb/ subsystem
- Implementing all required odb_source callbacks for packed storage
- close()
- reprepare()
- read_object_info()
- read_object_stream()
- for_each_object()
- count_objects()
- find_abbrev_len()
- freshen_object()

The series touches many parts of the codebase that interact with packed objects, requiring updates to midx (multi-pack-index) handling, repack machinery, and various builtin commands. The changes are largely mechanical conversions to use the new interface rather than direct packfile access.

Patrick notes this represents the last of his major ODB restructuring work, with future changes expected to be more incremental. The series builds on previous work (ps/odb-source-loose) and has a trivial conflict with a recent typo-fix commit that's shown in the cover letter.

The scale of changes (16 patches touching 24 files) suggests this will need careful review, particularly around midx and repack interactions. The series appears well-structured with each commit focused on wiring up a specific callback or interface. Given Patrick's track record with ODB work and the preparatory nature of these changes, the approach seems sound though the diffstat (+1054/-983) indicates substantial code movement.
