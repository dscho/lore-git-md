This is the fifth patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch wires up the `close()` callback for packed object sources, moving the implementation from `packfile.c` to the new `odb/source-packed.c` location and integrating it with the generic `odb_source` interface. 

Key changes:
- Implements `odb_source_packed_close()` to handle closing packfiles and MIDX (multi-pack-index) files
- Removes the now-redundant `packfile_store_close()` function
- Updates the files source to use the new callback via `odb_source_close()`
- Maintains all existing behavior while moving to the new abstraction

The patch continues the mechanical conversion work from the series, touching 4 files with a +17/-19 line diff. It builds on the previous patches that established the packed source structure and prepares for implementing additional callbacks in subsequent patches. The changes appear straightforward and focused, with no reviews yet on the series.
