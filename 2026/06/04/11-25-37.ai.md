This is patch 10/16 in Patrick Steinhardt's series converting the packed object storage backend to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `for_each_object()` callback for packed sources.

Key changes:
- Moves `packfile_store_for_each_object()` and related helpers from packfile.c to odb/source-packed.c
- Implements the callback interface while maintaining identical behavior
- Updates callers in builtin/cat-file.c, builtin/pack-objects.c, commit-graph.c, and odb/source-files.c to use the new interface
- The implementation handles both regular iteration and prefix-based iteration (used for object name abbreviations)
- Maintains all existing functionality around MIDX (multi-pack-index) handling, pack flags, and error conditions

The patch is largely mechanical code movement (258 lines added, 280 removed) with no behavior changes. It follows the same pattern as previous patches in the series, continuing the incremental conversion of packed object storage to the new ODB source interface. 

This leaves 3 remaining callbacks to implement in the series: `count_objects()`, `find_abbrev_len()`, and `freshen_object()`. The changes are well-contained and appear to maintain all existing functionality while moving toward the goal of a fully abstracted object storage layer.
