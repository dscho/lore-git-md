This is patch 6/8 in Patrick Steinhardt's series refactoring repository initialization and object database setup, part of the ongoing ODB abstraction effort. The patch removes an odd behavior where Git would initialize an object database even when no repository exists (triggered by the `GIT_DIR_EXPLICIT` environment variable pointing to a non-existent directory).

The change makes the code more logical by only creating an object database when we actually have a repository. The one exception - `git index-pack` running outside a repository - is handled by modifying `parse_commit_graph()` to check for the object database rather than the gitdir. This maintains functionality while cleaning up the initialization flow.

The patch is a mechanical step toward the series' goal of centralizing ODB creation in `apply_repository_format()` (coming in patch 8/8). It follows naturally from the previous patches' work to separate concerns, and has already been reviewed and approved by Karthik Nayak. The changes are internal plumbing improvements with no user-visible effects.
