This is the fifth patch in Johannes Schindelin's series addressing Windows platform compatibility for handling objects larger than 4GB. The patch focuses on `pack-objects`, converting object size handling from `unsigned long` to `size_t` to properly support large objects on Windows where these types differ in size.

The changes are mechanical but important - they remove size truncation that previously caused `upload-pack` to fail when serving large blobs. The patch updates size-related functions and data structures in `pack-objects.c` and `pack-objects.h`, including accessors, setters, and the `delta_size` array. It also eliminates now-unnecessary size casting in `check_object()`.

The patch maintains careful compatibility with existing codebase while enabling proper large object support.
