This is the v3 cover letter for Patrick Steinhardt's refactoring series that centralizes repository initialization and object database setup. The series is part of the ongoing ODB (object database) abstraction effort.

The series has completed its technical discussion cycle, with all feedback from Karthik Nayak addressed in this version. The key changes in v3 are improved documentation around the verification role of `apply_repository_format()` and better explanation of function renames. The series now cleanly separates repository format application from ODB creation, eliminating duplicate initialization paths.

The 8 patches systematically:
1. Add missing test coverage for `GIT_OBJECT_DIRECTORY` behavior
2. Remove the obsolete `setup_git_env()` function
3. Deduplicate repository format application logic
4. Stop initializing ODB in `repo_set_gitdir()`
5. Stop creating ODB in `setup_git_env()`
6. Stop initializing ODB without a repository
7. Eliminate duplicate loose object map reading
8. Finally centralize ODB creation in `apply_repository_format()`

This work lays important groundwork for future extensions like the "objectStorage" backend while making the existing code more maintainable. The changes are internal plumbing improvements with no user-visible behavior changes. The series has received thorough review and is ready for merging.
