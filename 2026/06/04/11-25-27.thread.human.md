Patrick Steinhardt’s ODB abstraction series continues to make incremental progress, with the 17-part v2 now focusing on wiring up callbacks for the packed object source. The latest review from Justin Tobler covers patch 11/17, which adds the `for_each_object()` callback to the packed source implementation. While Tobler confirms the callback registration follows the established pattern for ODB sources, the feedback remains surface-level—addressing only symbol visibility and mechanical alignment rather than deeper technical concerns like edge-case handling or performance.

The series remains blocked by unresolved refdb infrastructure issues Patrick discovered during implementation, including memory leaks, duplicate refdb creation paths, and initialization ordering problems. These require an 11-patch fix series, which itself depends on the prior "ps/setup-centralize-odb-creation" work. Meanwhile, patches 1–7 of v2 have received mechanical approval, with the type system now consistently using an embedded `struct odb_source` for both loose and packed sources. The architectural consistency of the callback wiring and lifecycle management is confirmed, but substantive review of the refdb problems—or the broader ODB design—has yet to materialize. Justin Tobler and Karthik Nayak have focused on mechanical alignment, leaving open questions about chdir notification behavior, path handling, and the future of parent pointer removal. Patrick’s planned fixes will need to be sequenced carefully, as the refdb issues now overshadow the original ODB abstraction goals.
