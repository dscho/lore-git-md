Patrick Steinhardt continues his multi-year effort to abstract Git's object storage with patch 9/17 in the v2 ODB series, implementing the `read_object_info()` callback for packed objects. This moves the core `find_pack_entry()` logic into the new `odb/source-packed.c` while maintaining the same behavior, renaming supporting functions for clarity. The changes are mechanical but important for encapsulation - callers now use the proper `odb_source_read_object_info()` interface rather than reaching into packed storage internals.
