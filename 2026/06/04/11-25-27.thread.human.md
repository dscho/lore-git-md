Patrick Steinhardt's 16-part series converting packed object storage to use `struct odb_source` is now complete, marking a significant step in the multi-year ODB abstraction effort. The series fully decouples packed storage from the files backend while maintaining identical runtime behavior, with all 16 patches implementing the necessary callbacks and removing final dependencies. Changes span 41 files with over 1,600 lines modified.

The work enables future pluggable storage backends and properly constrains MIDX operations to packed sources, though some internals remain temporarily exposed for future cleanup. Karthik Nayak provided a brief surface-level review of the first patch, with Patrick later clarifying that some related function renames would be deferred to avoid scope creep. The series now awaits maintainer consideration, with open questions around chdir notification handoff and midx/repack integration details still to be resolved. This foundational work interacts with several ongoing efforts including reftable development and geometric repacking optimizations.
