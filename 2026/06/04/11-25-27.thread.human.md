Patrick Steinhardt continues his major refactoring of Git's object storage layer with the ninth patch in his 16-part series converting packed object storage to use the new `struct odb_source` interface. This patch focuses on implementing the `read_object_stream()` callback, which handles streaming object contents from packfiles.

The changes are mechanical and consistent with the series' approach - moving implementation details from `packfile.c` to the new `odb/source-packed.c` while maintaining identical behavior. This patch is a code reorganization (+17/-17 lines) that removes now-unused helpers and updates the files backend to use the new callback interface. 

With this patch applied, the series now has four remaining callbacks to implement for packed storage: `for_each_object()`, `count_objects()`, `find_abbrev_len()`, and `freshen_object()`. The work builds on Patrick's previous conversion of loose object storage and is part of his broader effort to make Git's object storage fully pluggable. 

The series remains unreviewed at this point, though the changes follow an established pattern that has proven effective in earlier patches. The mechanical nature of this particular patch suggests it's unlikely to introduce new issues while moving the abstraction effort forward.
