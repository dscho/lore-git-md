This is patch 14/16 in Patrick Steinhardt's series converting the packed object storage backend to use `struct odb_source` as part of the ODB abstraction effort. The patch stubs out remaining callback functions that aren't needed for packed storage.

The changes:
- Adds error-returning stubs for write operations (objects, streams, transactions) since packed storage is read-only
- Implements a no-op for reading alternates (which packed storage doesn't use)
- Wires up these callbacks in the packed source initialization

The patch follows the established pattern of the series by:
- Maintaining the same error behavior as before (packed storage was already read-only)
- Using UNUSED attributes consistently for unused parameters
- Keeping the changes focused on interface implementation rather than behavior changes

This marks another step toward completing the ODB source interface for packed storage. With this patch, all callbacks are now either properly implemented or explicitly stubbed out where not applicable. The remaining patches in the series will handle final integration and cleanup.
