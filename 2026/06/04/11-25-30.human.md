This is the third patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch makes the relationship between packed object storage and its parent "files" source more explicit by changing a generic `struct odb_source*` pointer to a `struct odb_source_files*` pointer. This is an intermediate step toward completely removing the parent pointer in later patches.

The changes are mechanical and focused:
- Renames the pointer field from `source` to `files` in `struct odb_source_packed`
- Updates all callers to pass the more specific type
- Touches 4 files with straightforward changes (+11/-11 lines total)

This continues the pattern from earlier patches in the series of incrementally restructuring the code to make the object storage relationships clearer. The patch appears well-contained and low-risk, though as noted in the commit message, this is a temporary step toward a larger goal of detangling the storage hierarchy. The series as a whole will need careful review of the midx and repack interactions in later patches.
