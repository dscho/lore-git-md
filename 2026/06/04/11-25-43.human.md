This is the final patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch removes the last remaining coupling between the packed object storage backend and its parent "files" source, making it fully standalone.

Key changes:
- Drops the `files` pointer from `struct odb_source_packed` that previously linked back to the files source
- Updates initialization to take ODB parameters directly rather than inheriting them from the files source
- Adjusts all affected code paths to work with the parent pointer removed

The patch completes the transition of packed storage to a proper pluggable backend interface, following the pattern established earlier for loose object storage. With this change, the packed source can now operate independently as a true ODB backend implementation.

This marks a significant milestone in the ODB abstraction work Patrick has been driving. The series has systematically converted packed storage to use the `struct odb_source` interface while maintaining identical behavior. The changes are mechanical but touch many parts of the codebase that interact with packed objects.

The patch is small (19 lines net change across 4 files) and appears to be a clean conclusion to the series. Given Patrick's deep involvement in this area and the thoroughness of the preceding patches, this final step seems well-justified and low-risk.
