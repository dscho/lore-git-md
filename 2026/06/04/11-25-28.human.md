This is the first patch in Patrick Steinhardt's 16-part series converting Git's packed object storage to use the `struct odb_source` interface as part of the ongoing ODB (object database) abstraction effort.

The patch performs a mechanical rename of `struct packfile_store` to `struct odb_source_packed` to better reflect its role as one of Git's object storage backends. This aligns the naming convention with other ODB sources and prepares for the structure to implement the full `odb_source` interface in subsequent patches.

The changes are straightforward - updating all function signatures, type definitions, and variable names to use the new type name. The patch touches 3 files with 46 lines added and 46 removed, showing a clean 1:1 rename operation. 

This is a foundational change that enables the more substantial work in later patches to implement the required ODB source callbacks for packed storage. The commit message clearly explains the motivation for the rename and how it fits into the larger ODB abstraction goal.
