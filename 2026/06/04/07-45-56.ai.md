This is the fourth patch in a test infrastructure series introducing a new lint tool to convert bare 'grep' assertions to 'test_grep' in the test suite. The patch adds the core lint-style.pl tool with its first rule for handling test_grep negation patterns.

The lint tool is designed to detect and fix style violations in test scripts, starting with the specific case of shell-level negation (`! test_grep`) which should be converted to use test_grep's built-in negation (`test_grep !`). The latter preserves test_grep's diagnostic output on failure, unlike shell negation which suppresses it.

Key technical aspects:
- The tool reuses the shell parser from chainlint.pl (extracted in earlier patches) to properly handle shell syntax
- It processes test bodies while preserving original formatting for --fix mode
- Includes test cases demonstrating detection of violations in various contexts (heredocs, sed commands)
- Adds Makefile integration for both checking and fixing modes
- Fixes four existing violations in the test suite (three in test bodies, one in a helper function)

The implementation appears thorough, with careful attention to edge cases like heredocs and line number tracking.
