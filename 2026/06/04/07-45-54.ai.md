This is a refactoring patch that extracts the shell script parser from `t/chainlint.pl` into a shared module (`t/lib-shell-parser.pl`) so it can be reused by other tools. It's part of a series introducing a new tool to convert bare `grep` assertions to `test_grep` in the test suite.

The patch moves the Lexer, ShellParser, and ScriptParser packages into the shared module while keeping the chainlint-specific TestParser and ChainlintParser in the main script. The shared parser handles shell syntax parsing (heredocs, substitutions, command parsing etc.) while the chainlint-specific parts remain focused on &&-chain detection.

Key technical points:
- The parser is now reusable via `do()` for portability
- ScriptParser becomes a base class that can be subclassed for different linting purposes
- The unwrap() utility function is moved to ScriptParser for reuse
- ChainlintParser remains responsible for &&-chain checking
- The patch preserves all existing functionality while making the parser available to other tools

This is a mechanical refactoring with no behavior changes - it just reorganizes code to enable the new lint tool in subsequent patches. The implementation looks clean and maintains all the existing parser capabilities while making them reusable.
