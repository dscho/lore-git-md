This is patch 6/16 in Patrick Steinhardt's series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch wires up the `reprepare()` callback for packed object sources, moving related logic from packfile.c to the new odb/source-packed.c.

Key changes:
- Implements `odb_source_packed_reprepare()` which clears and reloads packfile/MIDX data
- Introduces `odb_source_packed_prepare()` helper that handles the actual loading and sorting of packfiles
- Moves packfile garbage reporting and sorting logic to the new location
- Updates callers to use the new interface rather than direct packfile_store functions

The changes are largely mechanical code movement with minimal behavior changes, continuing the pattern of converting packed storage to use the odb_source interface. The patch touches several files but the core logic remains similar - it's mostly reorganizing where the code lives rather than what it does.

This continues the incremental approach seen in earlier patches, with each commit focusing on wiring up one callback at a time. The series appears well-structured, though the scale of changes (+157/-177 lines across 7 files) suggests careful review will be needed, particularly around MIDX and repack interactions.
