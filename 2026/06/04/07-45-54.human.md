This is a refactoring patch that extracts the shell script parser from `t/chainlint.pl` into a shared module (`t/lib-shell-parser.pl`), as part of a larger series to improve test infrastructure by converting bare `grep` assertions to `test_grep`.

The patch moves the Lexer, ShellParser, and ScriptParser packages into a reusable module while keeping the test-specific ChainlintParser in the main script. This prepares for the introduction of a new lint tool in subsequent patches that will share this parser infrastructure. The changes are mechanical - the code is moved verbatim with only minor adjustments to package inheritance and module loading.

Key technical points:
- The shared parser handles shell syntax including heredocs, command substitution, and quoting
- ChainlintParser remains in chainlint.pl as a ScriptParser subclass that checks &&-chains
- The extraction preserves all existing functionality while making the parser reusable
- Future tools (like the upcoming grep linter) can now use the same shell parsing logic

This is a well-executed infrastructure change that follows the pattern of previous test tooling refactors. The commit message clearly explains the motivation and the patch does what it claims with minimal churn.
