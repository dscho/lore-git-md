This is a documentation patch that's part of a larger test infrastructure series. It adds documentation for the `test_grep` helper function to t/README, which was previously missing despite being widely used in the test suite.

The patch clearly explains:
- What `test_grep` does (a grep wrapper that shows file contents on failure)
- How to use it for both positive and negative assertions (including the proper way to negate with '!')
- When to use it (for assertions) vs when to use grep (for filtering)

The documentation is thorough and matches the style of other helper docs in t/README. This is a straightforward but important addition since `test_grep` is a core test helper that wasn't properly documented before. The patch serves as a good foundation for the rest of the series which will automate converting bare grep assertions to use this helper.
