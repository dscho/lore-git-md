This is part 4 of an 8-patch series focused on test infrastructure improvements, specifically addressing TAP output validation and CI consistency issues. The series as a whole aims to fix various test suite problems while standardizing CI environments between GitLab and GitHub.

This particular patch fixes a TAP output corruption issue in the fsmonitor tests (t7527). The problem occurs because the test's initial filesystem verification runs outside the test harness, allowing git-init's output to leak into the TAP stream. The fix converts this verification into a lazy prerequisite, which properly contains the output within the test framework.

The change is straightforward and mechanical - it wraps the existing verification in `test_lazy_prereq` and updates the check to use the new prerequisite. This follows the same pattern used elsewhere in the test suite to handle similar cases. The patch is part of a well-structured series that has already addressed review feedback in previous iterations.
