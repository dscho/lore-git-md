This is patch 5/8 in Patrick Steinhardt's series refactoring repository initialization and object database (ODB) setup, part of the larger ODB abstraction effort. The patch continues the work of centralizing ODB creation by removing conditional logic from `setup_git_env()` and making ODB initialization more explicit in callers.

The key change is eliminating the `skip_initializing_odb` parameter and moving ODB creation to the call sites where repositories are discovered and configured. This creates temporary duplication (as noted in the commit message) that will be resolved in patch 8/8 when ODB creation is fully centralized in `apply_repository_format()`.

The patch touches several initialization paths:
- `enter_repo()`
- `setup_git_directory_gently()`
- `init_db()`

Each now explicitly creates the ODB right before applying repository formats. The changes are mechanical and maintain all existing functionality while making the initialization sequence clearer. This is an internal plumbing change with no user-visible impact.

The series has already gone through thorough review from Karthik Nayak, with all feedback addressed in this v3 iteration. The patch represents an intermediate step in the larger refactoring that will enable future ODB backend work while improving code maintainability.
