This is the fourth patch in Patrick Steinhardt's 16-part series converting Git's packed object storage to use `struct odb_source` as part of the broader ODB (object database) abstraction effort.

The patch begins the conversion of `struct odb_source_packed` into a proper pluggable `struct odb_source` by:
- Embedding the base `struct odb_source` within `struct odb_source_packed`
- Assigning it the new `ODB_SOURCE_PACKED` type
- Implementing the `free` callback for lifecycle management
- Taking ownership of chdir notifications (needed when paths change due to directory changes)

The changes are largely mechanical, moving functionality from the old `packfile_store_free()` into the new `odb_source_packed_free()` callback. The patch removes the now-unused `packfile_store_free()` function and adds a downcast helper for type safety.

This is foundational work - the packed source isn't yet functional as a standalone `struct odb_source` since other required callbacks will be added in subsequent patches. The changes touch several files but are straightforward plumbing updates that follow the pattern established in earlier work on loose object storage conversion.

The patch continues Patrick's careful, incremental approach to the ODB abstraction - each commit focuses on one clear piece of the conversion while maintaining buildability throughout the series.
