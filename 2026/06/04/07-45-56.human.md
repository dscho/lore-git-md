This is a test infrastructure patch introducing a new lint tool to improve test assertions. It's part of a series converting bare 'grep' assertions to 'test_grep' in the test suite.

Patch 4/6 adds the core lint tool (lint-style.pl) with its first rule: detecting shell-level negation of test_grep (! test_grep) and converting it to the preferred form (test_grep !). The key difference is that the built-in negation preserves test_grep's diagnostic output on failure, while shell negation would suppress it.

The implementation builds on the shared shell parser extracted in earlier patches, allowing it to correctly handle complex shell constructs like heredocs and command substitutions. The tool can both detect violations and automatically fix them with --fix. The patch includes test cases demonstrating the lint rule in action and converts several existing violations in the test suite.

The lint tool is designed to be extensible - future patches could add more rules for other test anti-patterns. The implementation appears careful and thorough, with attention to edge cases and proper handling of the test suite's shell syntax. The patch follows the series' pattern of including both the tool and its test cases while making the minimal necessary changes to existing tests.
