This is patch 12/16 in Patrick Steinhardt's series converting Git's packed object storage to use the new `struct odb_source` interface as part of the ODB abstraction effort.

The patch moves the `find_abbrev_len()` functionality from packfile.c to odb/source-packed.c, implementing it as a callback in the packed source backend. The change is mechanical - the same algorithm is preserved, just relocated to its new home in the ODB subsystem. The implementation handles both regular packs and multi-pack-indexes (MIDX) when determining the minimum unique abbreviation length for a given object ID.

Key aspects:
- Pure code movement with no behavior change (+112/-117 lines)
- Maintains MIDX handling and error conditions
- Updates the files backend to use the new callback interface
- Part of the broader pattern converting direct packfile access to ODB source callbacks

This continues the series' incremental approach to restructuring the object storage layer. The changes appear straightforward and well-contained, following the same pattern as previous callback implementations in the series. With this patch, only one major callback (`freshen_object()`) remains to be implemented in the packed source backend.
