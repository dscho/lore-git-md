This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the current state of patches in the Git project's integration branches. The report covers new topics, stalled patches, cooking patches, and discarded efforts.

The report shows several notable developments:

1. **New Features & Fixes**:
   - HTTP authentication headers are now preserved across redirects
   - The project now recommends using `b4` for patch submission
   - `git rebase --update-refs` now properly handles branch symrefs
   - `git describe --contains --all` now correctly honors `--match`/`--exclude`

2. **Performance Improvements**:
   - Streaming revision walks optimized with priority queues
   - `git index-pack` retains child bases in delta cache
   - Reachability bitmap generation significantly optimized
   - `git stash -p` reuses cached index entries

3. **Documentation Updates**:
   - New guidelines for writing cover letters
   - Clarifications for `push.default=simple` behavior
   - Modern synopsis style conversions for several commands
   - Improved `--word-diff` documentation

4. **Infrastructure Changes**:
   - macOS linker warning fixed for Xcode 16.3+
   - Memory leak fixes in HTTP pack index handling
   - Subprocess handshake made more robust
   - Many configuration variables migrated to per-repository storage

5. **Experimental Features**:
   - `git history drop` subcommand added for commit removal and replay
   - New `diff.<driver>.process` configuration for external hunk providers
   - `git branch --prune-merged` option to remove merged branches

The report also notes several stalled topics that may be discarded due to inactivity, including some `the_repository` removal work and subtree split recursion improvements. Junio indicates he'll be away, so changes to this status will be minimal until next week.

This snapshot shows Git's development continuing to focus on performance, correctness, and modernization, with particular attention to the object database abstraction work, repository configuration improvements, and documentation standardization. The mix of new features, optimizations, and infrastructure work suggests steady progress across multiple fronts of the codebase.
