This is the second patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch moves the packed source implementation from `packfile.{c,h}` to new files `odb/source-packed.{c,h}`, following the same pattern used for other storage backends.

The changes are mechanical:
- Creates new files with the packed source struct and initialization function
- Updates build files (Makefile and meson.build) to include the new source
- Removes the now-redundant declarations from packfile.h
- Renames `packfile_store_new()` to `odb_source_packed_new()`

This is a straightforward preparatory step that detaches the packed storage implementation from the generic packfile code, setting up for the actual callback implementations in subsequent patches. The diff shows mostly code movement with minimal logic changes, just renaming and file reorganization.

As part of the larger ODB abstraction series, this continues Patrick's work to make Git's object storage pluggable. The changes appear clean and focused, though reviewers will want to verify the file moves don't break any implicit dependencies on the old locations.
