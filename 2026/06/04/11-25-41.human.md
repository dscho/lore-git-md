This is patch 14/16 in Patrick Steinhardt's series converting Git's packed object storage to use the new `struct odb_source` interface as part of the ODB abstraction effort. The patch stubs out remaining callback functions that aren't needed for packed storage but must be implemented to satisfy the interface.

The changes:
- Adds error-returning stubs for write operations (objects, streams, transactions) since packed storage is read-only
- Implements a no-op for reading alternates (which packed storage doesn't use)
- Wires these new stubs into the packed source's function table

This is a straightforward mechanical change that completes the callback implementation for packed storage. The patch follows the established pattern of the series - implementing required interfaces while maintaining existing behavior. With this, the packed backend now has all callbacks defined, though some are just stubs where the functionality isn't applicable.

The series continues to progress methodically through the ODB abstraction work, with this patch marking another incremental step toward pluggable storage backends. Given Patrick's track record with this multi-year effort and the careful structure of the changes, the approach remains sound.
