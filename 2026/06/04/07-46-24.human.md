This is the third version of Patrick Steinhardt's refactoring series that centralizes repository initialization and object database setup. The series is part of the ongoing ODB (object database) abstraction effort.

The key changes in v3 are improved documentation around the verification of repository formats and the role of `apply_repository_format()`. The series now clearly states that this function handles both applying and verifying the repository format, eliminating redundant verification steps from the code.

The 8-patch series:
1. Adds test coverage for `GIT_OBJECT_DIRECTORY` behavior
2. Removes the `setup_git_env()` function
3. Deduplicates repository format application logic
4. Stops initializing the ODB in `repo_set_gitdir()`
5. Stops creating the ODB in `setup_git_env()`
6. Stops initializing ODB without a repository
7. Avoids reading the object map twice during init
8. Finally centralizes ODB creation in `apply_repository_format()`

The changes are well-motivated and carefully structured, with each commit building logically on the last. The series has already gone through thorough review from Karthik Nayak in previous iterations, and Patrick has addressed all feedback. This version appears ready for merging as it establishes cleaner initialization paths while maintaining transitional compatibility, paving the way for future ODB extensions.
