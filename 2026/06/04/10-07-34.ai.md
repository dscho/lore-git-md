This is a test infrastructure patch in Patrick Steinhardt's series addressing TAP output validation issues. The patch fixes a specific problem in the fsmonitor test script (t7527) where pre-test verification output could corrupt the TAP stream.

The issue occurs because the fsmonitor capability check runs outside test cases, printing raw output that violates TAP format requirements (git-init's repository path output was breaking the protocol). The fix converts the check into a lazy prerequisite, properly containing its output within the test framework.

This is part of a broader effort to enforce strict TAP validation across Git's test suite. The change is mechanical and well-contained, touching only t7527 while maintaining the same functionality. It follows naturally from the series' goal of making test output reliably parseable by standard TAP output processors.

The patch has already been through multiple iterations (now at v3) with all prior feedback addressed. It represents one piece of a larger CI/test infrastructure improvement that includes both immediate fixes and preventative measures for future test issues.
