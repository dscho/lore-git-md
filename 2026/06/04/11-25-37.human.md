This is patch 10/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `for_each_object()` callback for packed sources, moving the implementation from packfile.c to odb/source-packed.c.

The changes are mechanical - the patch moves 260 lines while adding 258, with no functional changes. It updates callers in builtin/cat-file.c, builtin/pack-objects.c, commit-graph.c, and odb/source-files.c to use the new callback interface rather than direct packfile access. The implementation handles both regular iteration and prefix-based lookups, maintaining all existing behavior around midx (multi-pack-index) handling and error conditions.

This continues the pattern seen in earlier patches of the series - moving functionality into the new ODB abstraction layer while preserving behavior. The patch appears well-structured and focused, following the established approach for these conversions. With this change, only three callbacks remain to be wired up in the series: `count_objects()`, `find_abbrev_len()`, and `freshen_object()`.
