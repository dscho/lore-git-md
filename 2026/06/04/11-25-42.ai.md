This is patch 15/16 in Patrick Steinhardt's series refactoring Git's object storage layer as part of the ODB (object database) abstraction effort. The patch focuses on MIDX (multi-pack-index) interfaces, making them explicitly work with the "packed" source type rather than the generic `struct odb_source`.

Key changes:
- Modifies all MIDX-related functions to take `struct odb_source_packed*` instead of `struct odb_source*`
- Updates callers throughout the codebase to use the new type
- Adds downcasting where needed to convert from files source to packed source
- Maintains existing behavior while making the type system more precise

The change is motivated by the observation that MIDX operations are inherently tied to packed storage, so using the generic source type was misleading. This also prepares for a future change that will drop the pointer to the "files" source in the "packed" source structure.

The patch affects 13 files with 144 lines added and 129 removed, mostly mechanical conversions of function signatures and call sites. It continues the series' pattern of incremental, behavior-preserving refactoring to support pluggable object storage backends.

This is a substantive technical change in a complex area of Git's object storage, though the diff is largely mechanical. The series as a whole represents a major architectural shift in how Git handles object storage, with this patch tightening up the MIDX interface as part of that transition.
