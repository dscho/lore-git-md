This is a platform compatibility patch series addressing Windows-specific handling of large objects (>4GB) on LLP64 systems where `unsigned long` is 32-bit. The series has been maintained in Git for Windows for 4.5 years and is now being proposed for upstream inclusion.

The patches convert object header length handling from `unsigned long` to `size_t` across core object-file and hash algorithm code paths. The changes touch `object-file.c`, `sha1dc_git.c`, and related headers, with test cases added to verify the fixes work with >4GB inputs through various code paths including filtered input.

Johannes Schindelin notes the series has proven stable in Git for Windows and complements other ongoing large-object handling work. Philip Oakley, the original author, confirms his approval of the upstreaming effort. The changes appear well-tested and focused, with clear production validation from their long tenure in Git for Windows.
