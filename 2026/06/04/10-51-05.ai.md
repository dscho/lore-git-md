This is a platform compatibility patch series from Johannes Schindelin, focused on enabling Git to properly handle objects larger than 4GB on Windows systems where `size_t` is 64-bit but `unsigned long` is 32-bit. The series consists of 7 patches that systematically replace `unsigned long` with `size_t` for object size handling across multiple subsystems:

1. Starts with Windows-specific changes, using `_chsize_s` for `ftruncate` in MSVC compat layer
2. Updates delta handling to use `size_t`
3. Modifies pack-objects and packfile code to use `size_t` for in-memory object sizes
4. Removes now-unnecessary size conversion wrappers
5. Converts the object database API to use `size_t` for size parameters

The changes are wide-ranging, touching 71 files across core functionality like object handling, packfiles, deltas, and the ODB layer. The series is rebased on top of the ongoing `ps/odb-source-loose` work, with conflicts noted in the range-diff.
