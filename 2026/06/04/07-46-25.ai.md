This is the first patch in Patrick Steinhardt's v3 series refactoring repository initialization and object database setup. The patch adds test coverage for `git-init` behavior with `GIT_OBJECT_DIRECTORY`, which was previously undocumented in the test suite despite being specified in the man page.

The test verifies that when `GIT_OBJECT_DIRECTORY` is set, `git-init` creates the object directory at the specified path rather than the default `.git/objects` location. This test gap was discovered during the refactoring work, and plugging it helps prevent regressions in the subsequent changes to repository setup.

The patch is straightforward - it adds a single test case that creates a repository with a custom object directory and verifies the objects are created in the expected location. This is a preparatory test patch that ensures the existing behavior is properly validated before the more substantial refactoring in later patches.
