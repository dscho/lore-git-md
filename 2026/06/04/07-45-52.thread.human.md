This thread discusses a 6-part series introducing greplint.pl, a tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The effort began with documentation establishing test_grep standards and has evolved through multiple iterations addressing maintainer feedback. The series demonstrates concrete value by uncovering and fixing 10 test bugs during development, including some that were silently failing.

The final patch adds the greplint.pl tool itself, which intelligently identifies assertion contexts while ignoring legitimate grep usage in pipelines and command substitutions. It integrates with existing test infrastructure through a shared shell parser and includes comprehensive test coverage of edge cases. The tool preserves intentional bare greps via "# lint-ok" annotations and handles grep flags and negations properly.

While the technical implementation appears robust - with thorough test fixtures and careful handling of shell syntax nuances - maintainer Junio Hamano maintains reservations about the automated conversion approach. The series author, Michael Montalbo, has shown the practical benefits through multiple bugfixes and a bulk conversion of ~2800 grep assertions. The discussion remains open on whether to accept the transformative approach or limit the tool to diagnostics-only use. The shared parser infrastructure developed for this work may prove valuable for future linting efforts regardless of the outcome.
