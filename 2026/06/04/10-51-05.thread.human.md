The series systematically converts object size handling throughout Git's codebase to use `size_t` instead of `unsigned long`.

The final patch, just received, completes the conversion by updating the ODB API itself to use `size_t` for size parameters. This affects core functions like object reading and info retrieval, while still supporting unconverted subsystems like diff and blame.
