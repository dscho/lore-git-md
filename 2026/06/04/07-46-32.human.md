This is the final patch (8/8) in Patrick Steinhardt's v3 series refactoring repository initialization and object database (ODB) setup. The series is part of the ongoing ODB abstraction effort to enable pluggable storage backends.

The patch centralizes ODB creation in `apply_repository_format()`, eliminating duplicate initialization paths that previously existed across multiple callers. Key changes:

1. Moves ODB construction into `apply_repository_format()` after hash algorithm setup but before compatibility hash setup
2. Introduces a new `APPLY_REPOSITORY_FORMAT_HONOR_ENV` flag to control whether environment variables (like GIT_OBJECT_DIRECTORY) should be respected
3. Updates all initialization paths to use this centralized approach
4. Maintains the same functionality while simplifying the code

The patch touches core initialization paths in `repository.c` and `setup.c`, removing redundant ODB creation calls and cleaning up related environment variable handling. It builds on the previous patches' work to separate format application from ODB creation.

This completes the series' goal of establishing clear, maintainable initialization patterns for future ODB backend work. The changes have been thoroughly reviewed by Karthik Nayak and are ready for merging.
