This is the second patch in Patrick Steinhardt's 16-part series converting Git's packed object storage to use the `struct odb_source` interface as part of the ODB abstraction effort. The patch moves the packed source implementation from `packfile.{c,h}` to new files `odb/source-packed.{c,h}`, following the same pattern used for other storage backends.

Key changes:
- Creates new source-packed files with the existing `struct odb_source_packed` definition
- Moves the `packfile_store_new()` function to `odb_source_packed_new()`
- Updates build systems (Makefile and meson.build) to include the new files
- Maintains all existing functionality while reorganizing the code structure

The change is largely mechanical, detaching the packed storage implementation from the generic packfile code to better align with the ODB abstraction architecture. This prepares for subsequent patches that will implement the full `struct odb_source` callback interface for packed storage.

The patch touches 7 files with 95 lines added and 84 removed, mostly moving code between files rather than changing behavior. It builds on the first patch's rename of `struct packfile_store` to `struct odb_source_packed` and follows the pattern established by previous work on loose object storage abstraction.
