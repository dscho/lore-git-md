This is the final patch in Patrick Steinhardt's 16-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch removes the last remaining coupling between the packed object storage backend and its parent "files" source, making the packed source fully standalone.

Key changes:
- Drops the `files` pointer from `struct odb_source_packed`
- Updates initialization to take ODB parameters directly rather than inheriting from files source
- Modifies pack loading and preparation to work without files parent
- Maintains all existing functionality while completing the decoupling

The patch is a mechanical conclusion to the series' goal of making packed storage a proper independent backend. It touches 4 files with 19 lines changed, mostly straightforward updates to function signatures and call sites. The changes appear consistent with the series' incremental approach and Patrick's established pattern of careful ODB refactoring.

With this patch, the packed object storage now fully implements the odb_source interface without dependencies on the files backend, marking completion of this phase of the ODB abstraction work. The series as a whole represents a significant architectural improvement that enables future pluggable storage backends while maintaining current behavior.
