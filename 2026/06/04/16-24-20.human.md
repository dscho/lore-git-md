This is the second patch in Johannes Schindelin's Windows process management series, focusing on SIGINT handling. The change improves Ctrl+C behavior on Windows to match Unix systems by properly terminating only the Git process while leaving the pager running.

The patch adds a ConsoleCtrlHandler that specifically handles Ctrl+C events (CTRL_C_EVENT) by translating them to SIGINT signals. This builds on the MSYS2 runtime's ability to call ConsoleCtrlHandler, which wasn't previously leveraged. The implementation is cleanly scoped to Windows-specific code in compat/mingw.c.

This completes the series' goal of bringing Windows process termination behavior closer to Unix norms. The change has been production-tested in Git for Windows for years, suggesting it's a stable solution. The patch is small and focused, with clear documentation of its purpose in the commit message.
