This is patch 4/8 in Patrick Steinhardt's series refactoring repository initialization and object database (ODB) setup. The series is part of the ongoing ODB abstraction effort.

The patch removes ODB initialization from `repo_set_gitdir()`, where it was happening conditionally in a way that made the code harder to follow. Instead, the ODB creation is moved to the callers - specifically `repo_init()` and `setup_git_env_internal()`. This creates some temporary duplication that will be cleaned up in later patches when ODB creation is centralized in `apply_repository_format()`.

The changes are mechanical plumbing improvements with no user-visible effects. The patch follows the series' goal of making initialization sequence clearer and better organized. Karthik Nayak has already signed off on this approach in previous reviews, and the technical discussion appears settled. The series is now in its final form and ready for merging.
