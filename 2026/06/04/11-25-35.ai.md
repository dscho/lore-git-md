This is patch 8/16 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `read_object_info()` callback for packed sources, moving the implementation from packfile.c to odb/source-packed.c while maintaining identical behavior.

Key changes:
- Moves `find_pack_entry()` and implements it as the core lookup helper
- Introduces `packfile_fill_entry()` as the new public interface for direct pack lookups
- Updates all callers to use the new `odb_source_read_object_info()` interface
- Keeps `find_pack_entry()` temporarily exposed (will be made file-local in later patches)

The patch continues the mechanical conversion pattern seen throughout the series, with a net reduction of 4 lines (157+4=161 added, 160+4=164 removed). It builds on previous patches establishing the packed source structure and prepares for subsequent patches that will implement remaining callbacks like `read_object_stream()` and `for_each_object()`.

This is a straightforward continuation of the ODB abstraction work, maintaining the series' focus on incremental, behavior-preserving changes while moving implementation details behind the new interface. The changes appear well-contained and follow the established pattern from earlier in the series.
