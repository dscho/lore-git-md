This is the first patch in Patrick Steinhardt's 16-part series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch performs a mechanical rename of `struct packfile_store` to `struct odb_source_packed` to better reflect its role as an object database source.

The change is straightforward - it touches 3 files (odb/source-files.h, packfile.c, packfile.h) with 46 lines added and 46 removed, showing this is purely a naming update. The commit message explains that while the structure was originally introduced as a packfile manager, it's now clear it should be treated as a proper ODB source like other storage backends.

This rename aligns with the series' goal of making packed storage conform to the same interface as other ODB sources. The patch appears well-contained and low-risk, serving as groundwork for the more substantive interface conversions that follow in subsequent patches. Given this is part of Patrick's ongoing ODB abstraction work and follows the pattern established for loose object storage, the approach seems sound.
