This is patch 7/8 in Patrick Steinhardt's series refactoring repository initialization and object database setup. The series is part of the ongoing ODB (object database) abstraction effort.

The patch eliminates a redundant read of the loose object map during repository initialization. Currently, the map gets read twice: once through `apply_repository_format()` (via `repo_set_compat_hash_algo()`) and again directly in `repo_init()`. The change removes the second read while maintaining all functionality, as the first read already handles the case where a compatibility hash algorithm is configured.
