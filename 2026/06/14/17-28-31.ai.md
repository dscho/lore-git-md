This is a documentation patch fixing a minor typo in the 2.14.0 release notes from 2017. D. Ben Knoble noticed the error while researching timestamp handling in Git. The correction changes "along" to "alone" in the explanation of the `timestamp_t` type introduction. The patch is trivial and uncontroversial, though the author notes it's not critical if not accepted. The change doesn't affect functionality - it just improves documentation clarity for a nearly decade-old release note.
