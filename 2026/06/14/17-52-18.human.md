This is a build system patch for gitk, part of a 2-patch series to make translation catalog generation quieter during silent builds (`make -s`). The patch modifies gitk's Makefile to suppress "Generating catalog" messages and `msgfmt --statistics` output when building silently, while maintaining the existing verbose output for normal builds.

The change is straightforward - it wraps the msgfmt invocations in conditionals that check MAKEFLAGS for the -s flag. The patch follows the same pattern as the companion patch for git-gui, both addressing the same issue where translation-related output was bypassing the silent build flag. The commit message clearly explains the motivation and solution.

Since gitk is maintained separately from core Git (by Johannes Sixt), this change will need his review/ack. The patch appears well-contained and focused solely on the described issue, with no obvious technical concerns. It's a small but useful quality-of-life improvement for those using silent builds.
