This is a technical patch in the `diff.<driver>.process` RFC series, which enables external tools to inject diff hunks into Git's diff and blame pipelines. The patch adds the configuration plumbing for the new `diff.<driver>.process` setting by extending the `userdiff_driver` struct with `process` and `process_owned` fields and teaching the config parser to handle the new setting.

The changes are straightforward - the new fields follow the same pattern as existing configuration fields in the struct (like `algorithm`/`algorithm_owned`), with the owned variant managing memory allocation. The patch is well-contained, touching only the userdiff configuration parsing logic and struct definition.

This is part of a larger effort to support structural/AST-based diffs while preserving Git's existing diff display features. The series has already addressed key review feedback, particularly around test implementation (moving from Python to a C-based test helper) and Windows compatibility. This specific patch is a foundational piece that enables the rest of the series to work by providing the configuration mechanism to specify external diff processors.
