This is a build system patch (part 1 of 2) that modifies gitk's Makefile to properly respect the `-s` (silent) flag during translation catalog generation. The change ensures that "Generating catalog" messages and `msgfmt` statistics output are suppressed when building with `make -s`, while maintaining the existing verbose output in normal builds.

The patch follows the established pattern seen in similar Makefile changes across Git project - it introduces conditionals to check for the silent flag in MAKEFLAGS before emitting output. The implementation is clean and focused, touching only the specific issue without introducing broader changes to the build process.

Since gitk is maintained separately from core Git (by Johannes Sixt), this change will need his review/ack. The patch appears ready for maintainer consideration - it's a straightforward improvement to build system behavior with no apparent technical issues or open questions. The second patch in the series applies the same change to git-gui's Makefile.
