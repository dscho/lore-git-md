The changes are straightforward - the Makefiles are modified to only show the catalog generation output when not in silent mode. This maintains the existing verbose build behavior while properly respecting the silent flag. The patches touch only build infrastructure (Makefiles) and don't affect runtime behavior.

The motivation is clear and the implementation looks correct - this appears to be a simple quality-of-life improvement for developers who use silent builds.
