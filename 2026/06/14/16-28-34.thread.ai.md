The change affects `builtin/cat-file.c` with minimal code delta (6 added, 3 removed).

In follow-up testing, Peff determined that converting callbacks to a switch statement provided no additional benefit, confirming the callback design's adequacy. His analysis suggests deeper architectural changes would only be justified if Git unified its formatting systems (`ref-filter`, `cat-file`, `--pretty=format`), which remains an open question.

René Scharfe now proposes a more compact representation of the parsed format string, storing opcodes and literal characters in a strbuf rather than using callback functions or a switch statement. Benchmarks on an Apple M1 show negligible differences between approaches (all within 1%), while a Ryzen system shows slightly more variation but no clear winner. A prototype patch implements this approach by restructuring format parsing to use a strbuf for storing parsed instructions. René suggests further optimization might be possible through smaller opcodes and more efficient literal character storage, though current gains appear marginal.
