Performance optimization for `git cat-file`'s default batch format. René Scharfe updates the code to use more efficient string buffer operations (`strbuf_add_oid_hex()` and `strbuf_add_uint()`) instead of the slower `strbuf_addf()` for formatting object information in the standard `%(objectname) %(objecttype) %(objectsize)` output pattern when using `--batch-check`. The change affects `builtin/cat-file.c` with 6 lines added and 3 removed, maintaining backward compatibility while improving performance by 3-7% (979ms vs 1.051s in benchmarks). This continues René's pattern of targeted optimizations, particularly impactful for bulk object queries. The patch includes thorough benchmarking data showing consistent improvements across multiple runs.
