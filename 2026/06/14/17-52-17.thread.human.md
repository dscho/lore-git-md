This thread completes a small but long-running effort to make `make -s` builds fully quiet in gitk and git-gui, matching the behavior already established in core Git. The work is split into two final patches: this one (1/2) updates gitk, and its companion (2/2) updates git-gui.

The goal is simple: eliminate all verbose output during silent builds by removing the `--statistics` flag from `msgfmt` invocations and conditionally suppressing "Generating catalog" messages. The gitk patch adds a new `QUIET_MSGFMT` helper to the Makefile, ensuring both the command echo and the "Generating" message are hidden when `make -s` is used. The changes are minimal—just a few lines in the Makefile—and don’t affect functionality, only build output verbosity.

Johannes Sixt, gitk’s maintainer, is expected to review this patch, while Johannes Schindelin has effectively signed off on the git-gui portion. The author, Harald Nordgren, has addressed all prior feedback, and the series is now procedurally ready for final review. No objections remain, and the implementation follows the clean, maintainer-approved pattern established in core Git. This is the last step in a years-long effort to standardize quiet builds across all three repositories.
