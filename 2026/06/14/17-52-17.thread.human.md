This thread is about a small but practical build system improvement for Git's companion tools, gitk and git-gui. The goal is to clean up noisy output during silent builds (`make -s`) by removing translation catalog generation messages entirely, rather than just suppressing them conditionally. The original patches took the suppression approach, but after Johannes Sixt (gitk's maintainer) suggested a simpler solution—removing the output altogether, following a precedent set in core Git in 2021—the author revised the patches to do just that.

The changes are minimal: they drop the `--statistics` flag from `msgfmt` invocations and remove a "Generating catalog" echo in gitk's Makefile. Both gitk (maintained by Sixt) and git-gui (maintained by Johannes Schindelin) are affected, but the modifications are straightforward and uncontroversial. The thread is now effectively resolved, with the revised patches aligning with existing practice in the main Git codebase. All that remains is for the maintainers to review or ack the final version before it can be merged.
