This thread introduces a pair of patches to improve the silent build behavior (`make -s`) for Git's GUI tools, gitk and git-gui. Currently, these tools output "Generating catalog" messages and translation statistics even during silent builds. The first patch, modifying gitk's Makefile (maintained by Johannes Sixt), wraps the msgfmt invocations to suppress this output when -s is specified. The second patch applies the same change to git-gui's Makefile (maintained by Johannes Schindelin), keeping the tools' behavior consistent.

Both patches are straightforward, focused changes that follow established patterns for silent builds elsewhere in Git. They maintain verbose output for normal builds while properly respecting the -s flag. Since gitk and git-gui are maintained separately from core Git, these changes await review or acknowledgment from their respective maintainers. No technical concerns have been raised - the patches appear ready for consideration.
