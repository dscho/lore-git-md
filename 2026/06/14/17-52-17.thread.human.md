This thread completes a small but long-overdue cleanup to make Git's build output consistent across its three main components: core Git, gitk, and git-gui. Harald Nordgren sent a two-patch series that finally aligns gitk and git-gui with core Git's quiet build conventions during `make -s` builds. The first patch (already sent) updates gitk, while this second patch targets git-gui.

The goal is simple: eliminate all verbose build output during silent builds by removing `--statistics` from `msgfmt` invocations and conditionally suppressing "Generating catalog" messages. The changes are minimal—just a few lines in each project's Makefile—and don't affect functionality, only build verbosity. Johannes Sixt, gitk's maintainer, proposed the approach, and Johannes Schindelin, git-gui's maintainer, has effectively signed off on the git-gui portion. The series is now procedurally ready for final review and merging, with no open questions or objections remaining. This is a textbook example of a well-scoped, uncontroversial cleanup that brings consistency to the project's build system.
