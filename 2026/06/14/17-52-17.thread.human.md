This thread is about a small but useful cleanup to the build system for Git's companion tools, gitk and git-gui. The goal is to make their translation catalog generation quieter during `make -s` builds, matching a precedent set in core Git back in 2021. The original patch proposed conditionally suppressing output, but Johannes Sixt (gitk's maintainer) suggested a simpler approach: just remove the verbose messages entirely, which the author adopted in the second version.

The latest update is a follow-up from Sixt that tidies up the git-gui Makefile further by removing now-unnecessary shell variable handling that was previously used to capture `msgfmt --statistics` output. This change is purely mechanical and aligns the build output style with other quiet rules in the Makefile. Both patches are now ready for integration, needing only the sign-off from the respective maintainers—Sixt for gitk and Johannes Schindelin for git-gui. There’s been no technical pushback, and the changes are uncontroversial, focusing solely on reducing build noise without affecting functionality. Expect this to land soon once the maintainers weigh in.
