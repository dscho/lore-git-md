This thread discusses whether to accept a trivial typo fix ("along"->"alone") in the Git 2.14.0 release notes from 2017. D. Ben Knoble originally submitted the patch, but Junio C Hamano questioned the value of correcting minor issues in historical documentation unless they address factual errors that could mislead users. Junio also noted additional grammatical problems in the same sentence that Knoble's patch didn't fix.

In his follow-up, Knoble acknowledges Junio's position and agrees about the other grammatical issue (a mismatch between plural "timestamps" and singular "a vanilla ulongs"). The discussion remains focused on documentation maintenance philosophy, with both participants recognizing that minor editorial fixes to old release notes may not justify the maintenance overhead when they don't affect technical accuracy. No changes have been made to the release notes as a result of this exchange.
