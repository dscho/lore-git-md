Proposal to fold commit ranges into a single commit, implemented as `git history squash` standalone subcommand. **Series v5 (4 patches) by Harald Nordgren is code-complete but requires additional input validation and edge-case handling** before Junio’s final assessment, following Phillip Wood’s substantive review identifying usability gaps and test coverage omissions.

Core problem: efficiently collapse a linear or merge-commit-containing range (`@~3..`, `@~5..@~2`) into its oldest commit while preserving descendant history, avoiding the repeated conflict stops of a rebase-based approach. **Finalized behavior**: refs pointing to commits inside the squashed range (e.g., `o---A---B---C` → `o---X`) are **detected and rejected by default**, with an `advice.historyUpdateRefs` message suggesting `--update-refs=head` to explicitly retarget the current branch to the squashed commit.

Implementation details:
- New subcommand `git history squash [--reedit-message] [--update-refs[=head]] <range>`
- Single three-way merge of entire range against oldest commit’s parent, replaying descendants on top
- **Strict range validation**: ranges must be in `<base>..<tip>` form, with a boundary commit (`UNINTERESTING`) present; **single revisions (e.g., `HEAD`) are explicitly rejected** (per v5), but **single-commit ranges (e.g., `@^!`) are still accepted** (Phillip Wood’s concern)
- **`--ancestry-path` adoption**: revision walk enforces that only commits descended from the base are folded
- Rejects ranges with multiple bases or refs pointing inside the range (configurable advice)
- **`--reedit-message`**: seeds editor with *all* folded-in commit messages (oldest first) via `build_squash_message()`, mirroring `git rebase -i` squash behavior. **Plumbing**: `commit_tree_ext()` now accepts an optional `message_template` parameter (patch 2/4), allowing callers to override the commit message without altering existing behavior for `NULL` templates.

- **`--ancestry-path` requirement**: Ensures predictable range resolution by folding only commits descended from the base.
