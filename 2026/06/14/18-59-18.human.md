This is the first patch in a series introducing `diff.<driver>.process`, which allows external tools to inject diff hunks into Git's diff and blame pipelines. The patch adds core xdiff infrastructure to accept pre-computed hunks from an external source.

The key changes in this revision:
- Adds validation for externally supplied hunks, checking for out-of-bounds line numbers, overlaps, and synchronization invariants
- Skips trim_common_tail() when using external hunks since they reference original content line numbers
- Falls back to built-in diff algorithm if validation fails
- Includes detailed warning messages to help debug hunk validation issues

The implementation introduces a `xdl_hunk` struct to represent pre-computed diffs and adds fields to `xpparam_t` to pass them through. The validation logic is thorough, checking both individual hunk validity and cross-file consistency. This provides the foundation for the rest of the series which will build the Git-facing interface.

The patch appears well-constructed with clear error handling and fallback paths. The validation warnings will be particularly useful for tool authors integrating with this feature. This is a solid technical foundation for the feature being proposed.
