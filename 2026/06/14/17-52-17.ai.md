This is a build system patch series (2 patches) that makes translation catalog generation quieter when building with `make -s`. The changes affect gitk and git-gui, two GUI tools that ship with Git.

The core issue is that these tools' Makefiles were outputting "Generating catalog" messages and `msgfmt --statistics` output to stderr, which remained visible even with `make -s` (the "silent" flag). The patches modify the Makefiles to only show this output when not building silently.

The changes are straightforward - they wrap the msgfmt invocations in conditionals that check MAKEFLAGS for the -s flag. The first patch handles gitk's Makefile, the second handles git-gui's. Both follow the same pattern of suppressing output during silent builds while maintaining the existing verbose output otherwise.

This appears to be a clean, focused improvement to the build system's behavior. The changes are small and well-contained, touching only the specific issue described. The commit messages clearly explain the motivation and solution. Since gitk and git-gui are maintained separately from core Git (by Johannes Schindelin and Johannes Sixt respectively), these changes will need their review/ack.
