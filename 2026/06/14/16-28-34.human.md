Performance optimization for `git cat-file`'s default format.

René Scharfe improves the performance of `git cat-file --batch-check` when using the default format (showing object name, type, and size). The patch replaces three `strbuf_addf()` calls with more efficient direct string buffer operations (`strbuf_add_oid_hex()`, `strbuf_add_uint()`, etc.), bringing the default format's performance in line with custom formats.

Benchmarks show a 3-7% speedup compared to the current implementation, with the new version processing objects in about 979ms versus 1.051s previously. The change is small (6 lines added, 3 removed) and focused purely on the performance optimization without altering functionality.

This continues René's pattern of sending clean, focused performance patches that replace printf-style formatting with more efficient alternatives. The commit message clearly explains the motivation and includes thorough benchmarking data to validate the improvement.
