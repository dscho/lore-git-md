This is the second patch in a 2-part series improving silent build behavior for Git's GUI tools (gitk and git-gui). The patch modifies git-gui's Makefile to suppress translation catalog statistics output during `make -s` builds, matching the change made to gitk in the first patch.

The change is straightforward: it moves the `--statistics` flag for msgfmt into a variable that's only set when not building silently. This maintains the existing verbose output for normal builds while properly respecting the `-s` flag. The patch follows the same pattern as the gitk change, keeping behavior consistent across both tools.

Since git-gui is maintained separately from core Git (by Johannes Schindelin), this change will need his review/ack. The patch appears ready for maintainer consideration - it's a focused improvement that doesn't introduce new complexity or affect behavior outside the specific silent build case. The commit message clearly explains the change and its motivation.
