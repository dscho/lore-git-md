Feature implementation adding `--fixup-all` option to `git rebase --autosquash`, completing the 2-part series. This follows the preparatory test cleanup patch that was already sent.

The new option folds a range of commits into their oldest ancestor while preserving the original commit message, addressing a workflow pain point where users previously had to manually edit each commit to "fixup" or use reset/amend. Key technical aspects:

- When no upstream is specified, defaults to `@{upstream}..HEAD` range
- Preserves original commit order so existing fixup!/squash! commits work naturally
- Forbids combining with `--rebase-merges` since merge commits can't be folded
- Adds comprehensive test coverage (105 lines) verifying various scenarios:
  - Basic range folding
  - Handling of existing fixup commits
  - Edge cases (single commit, empty range, dropped commits)
  - Merge commit handling
  - Option validation

The implementation modifies `sequencer.c` to add the range-folding logic and updates `builtin/rebase.c` for option handling. Documentation is added to `git-rebase.adoc` explaining the new behavior.
