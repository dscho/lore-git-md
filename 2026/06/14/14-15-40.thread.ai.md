**Thread identity**: Bugfix patch for memory leak in `git history reword` command, part of Patrick Steinhardt's ongoing `git history` work, now expanded to broader slab management issues exposed by commit-graph interactions.

**Core problem or goal**: Fix and analyze memory leaks tied to Git's commit buffer and slab management, particularly when commit-graph bypasses raw object parsing. The original `git history reword` leak (fixed) revealed a systemic pattern: commits loaded from the commit-graph do not populate the commit slab cache, requiring explicit cleanup of dynamically allocated buffers. This pattern now surfaces in additional test failures (`t345x` and `t4014`), indicating unaddressed slab management gaps across Git's codebase.

**Current status**: The original `git history reword` fix remains merged and correct. The thread has broadened to diagnostic confirmation of related leaks:
- **Confirmed**: `t345x` failures stem from the same slab-cache bypass mechanism (commit-graph loading).
- **New issue**: `t4014` exposes a distinct leak in the topological walk slab (`init_topo_walk`), unrelated to commit buffers but sharing the same root cause (slab not freed).
No regression or design objections to the original fix; discussion now centers on systemic slab management and test coverage.

**Key technical details**:
- **Original fix**: `builtin/history.c` (`commit_tree_ext`), `repo_unuse_commit_buffer` for non-slab-cached buffers.
- **Bypass mechanisms**:
  - **Commit-graph**: Metadata loaded from commit-graph never opens raw objects, so no buffer is cached (primary cause for `t345x`).
  - **Unparsed commits**: Commits where `parse_commit()` is never called.
  - **Disabled `save_commit_buffer`**: Repositories with commit buffer caching turned off.
- **New leak**: Topological walk slab (`init_topo_walk`) not freed in `t4014`, distinct from commit buffer leaks but sharing slab management gaps.
- **Reproduction**: `SANITIZE=leak GIT_TEST_COMMIT_GRAPH=1 make test` exposes both `t345x` (commit buffer) and `t4014` (topo walk slab) leaks.
- **Files/functions**: `builtin/history.c` (`commit_tree_ext`), `repo_logmsg_reencode`, `repo_get_commit_buffer`, `parse_commit`, `commit-slab.h` (`init_topo_walk`).
- **Subsystems**: Commit buffer management, slab cache, commit-graph, topological walks, encoding/decoding.
