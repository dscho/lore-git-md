This is part 5 of a 6-patch series introducing the `diff.<driver>.process` feature, which allows external tools to inject diff hunks into Git's diff and blame pipelines. The series is in its fourth revision and has been through extensive review, with the test implementation recently transitioned from Python to a C-based helper per project guidelines.

This patch focuses on bypass mechanisms for the diff process feature. It makes three key changes:

1. Extends `--no-ext-diff` to disable both `diff.<driver>.command` and the new `diff.<driver>.process` mechanisms, since both involve external tools. The implementation replaces a simple OPT_BOOL with an OPT_CALLBACK that coordinates both flags.

2. Forces `format-patch` to always use the builtin diff algorithm rather than external processes, ensuring generated patches are reliable for recipients who may not have the same external tools configured.

3. Documents that explicitly setting `--diff-algorithm` also bypasses the diff process, since it requires using Git's builtin diff implementation.

The changes come with corresponding test cases verifying each bypass scenario. This maintains consistency with Git's existing diff behavior while adding the new process capability.
