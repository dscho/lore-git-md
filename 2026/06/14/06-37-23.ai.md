This is the second patch in Elijah Newren's five-part series hardening merge-ort's error handling and corruption detection. The patch removes an unnecessary `show_all_errors` flag from `collect_merge_info()` that was originally copied from unpack-trees.c but never actually used in merge-ort's error handling.

The change is straightforward - it deletes one line that was setting the flag to true. The commit message explains this was a vestigial setting from when the code was first written, and removing it will allow future patches to properly stop processing when errors are detected rather than continuing unnecessarily. 

This is a small but meaningful cleanup that prepares for the more substantial error handling improvements in later patches of the series. The patch has already been reviewed and approved by the maintainer (Junio Hamano) in the v1 discussion, and this v2 iteration incorporates no changes beyond what was already agreed upon. The series as a whole is now ready for merging.
