This is a documentation patch fixing a small typo in the Git 2.14.0 release notes from 2017. D. Ben Knoble corrects "along" to "alone" in the explanation of the `timestamp_t` type introduction. The change is trivial and uncontroversial, found while researching timestamp handling in response to another thread.

The patch is a straightforward one-line fix with no functional impact. Knoble notes the change is minor enough that it wouldn't be problematic if rejected. The correction improves clarity in historical documentation that explains why Git moved from `ulong` to a dedicated `timestamp_t` type for time handling.
