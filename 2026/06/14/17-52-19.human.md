This is the second patch in a 2-patch series improving silent build behavior for Git's GUI tools. It applies the same change from the first patch (which modified gitk's Makefile) to git-gui's Makefile, ensuring translation catalog generation output is properly suppressed when building with `make -s`.

The change is minimal and mechanical - it wraps the `msgfmt --statistics` output in a conditional that checks for the silent flag in MAKEFLAGS. The patch follows the same pattern as the first one, maintaining consistency across both GUI tools' build systems. 

Since git-gui is maintained separately from core Git (by Johannes Schindelin), this change will need his review/ack. The patch appears ready for maintainer consideration - it's a straightforward improvement that doesn't introduce any new complexity or side effects.
