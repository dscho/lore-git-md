This is a documentation patch series fixing AsciiDoc markup issues in git-config man pages, now in its third iteration. The series is part of the ongoing documentation synopsis-style conversion effort led by Jean-Noël Avila, though this particular version is being sent by Tuomas Ahola.

The v3 series contains three mechanical fixes for AsciiDoc syntax problems:
1. Terminates runaway lists in config documentation by wrapping problematic lists in open blocks (-- delimiters)
2. Fixes a description list delimiter in sideband.adoc (cursor: -> cursor::)
3. Escapes octothorpes (#) in git-config.adoc using backticks rather than backslashes, after doc-diff testing revealed context-sensitive rendering issues with the previous approach

The changes are well-scoped and focused purely on documentation formatting rather than content. The patches touch multiple config-related files (config.adoc, promisor.adoc, safe.adoc, git-config.adoc, sideband.adoc) but each change is small and straightforward. The series has already undergone substantive review from Jeff King and Junio C Hamano, with the backtick-escaping solution for octothorpes emerging as the consensus approach after testing revealed issues with backslash escaping.

This appears ready for merging - the changes are uncontroversial documentation fixes that maintain consistency in the ongoing AsciiDoc conversion effort. The patches have been tested with doc-diff to validate rendering improvements, and all outstanding technical questions from previous iterations appear resolved.
