This is a refactoring patch that consolidates two reachability functions in commit-reach.c (`get_reachable_subset()` and `tips_reachable_from_bases()`) into a single implementation with configurable traversal modes (DFS or priority queue). The patch comes from Kristofer Karlsson and represents version 2 of the series, addressing feedback from Junio Hamano and Derrick Stolee.

The key technical aspects:
- The unified function uses `prio_queue` for both modes (LIFO stack for DFS, min-heap for PQ)
- DFS mode defers commit parsing until pop time for efficiency
- Merge commit revisits are eliminated (2-parent merges now require 1 visit instead of 3)
- First-parent traversal order is preserved in DFS mode
- The remote.c caller is updated to use PQ mode (matching its original behavior)
- New exhaustive tests exercise all commits as tips to catch subtle traversal bugs

Performance measurements show speedups of 1.09-1.14x in some real-world cases, though the primary goal was code consolidation rather than optimization. The patch removes 126 lines across 5 files while maintaining optimal traversal strategies for different repository states.

The thread shows consensus with no outstanding objections, with Derrick Stolee (original author of both functions) providing historical context and validating the technical approach. The change is well-tested with both existing and new test cases covering both traversal modes.
