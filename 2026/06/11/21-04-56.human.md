This suggests a change in curl's handling of authentication flows between versions 8.18.0 and 8.21.0-rc2.

The issue appears to be platform-specific (Fedora 45 with newer curl) rather than a Git regression per se, but it's causing test failures that need to be understood. Todd is seeking help from those familiar with Git's HTTP and authentication code to debug why the test behavior differs between curl versions. The test failure could indicate either:
1. A legitimate change in curl's authentication behavior that requires test adjustment
2. An unintended regression in curl that needs to be reported upstream
3. A test that was overly specific about implementation details
