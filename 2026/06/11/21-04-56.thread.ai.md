Core problem: Test t5563.18 ("http.emptyAuth=auto attempts Negotiate before credential_fill") failed due to a curl regression where `--anyauth -u :` no longer attempted Negotiate authentication, reducing expected HTTP 401 responses from three to two. The regression highlighted an undocumented but relied-upon behavior in curl's `CURLOPT_USERPWD = ":"` (empty username/password) triggering Negotiate authentication attempts, which Git's test suite now reaffirms as correct.

The test, added in Git commit 9b1630b972, verifies `http.emptyAuth=auto` behavior by expecting three HTTP 401 responses. Upstream curl 8.21.0-rc3 restored the original behavior, eliminating the need for Git-side changes. The resolution validates the test's expectations and underscores the importance of documenting curl's edge-case behavior to prevent future regressions.
