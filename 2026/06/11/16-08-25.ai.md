This is Junio Hamano's "What's cooking in git.git" report for June 2026, providing a comprehensive overview of the current state of in-flight Git development topics. The report follows the project's standard format, categorizing patches into graduated (merged to 'next'), new topics, stalled topics, cooking topics, and discarded topics.

Key highlights from this report include:

Several topics have graduated to 'next' and are candidates for the upcoming Git 2.55 release. These include optimizations to git-jump's auto-mode selection, macOS linker warning fixes, documentation clarifications for push.default=simple, Windows test fixes, line-log improvements, and significant refactoring of the object database source handling.

New topics introduced include optimizations to priority queue handling, removal of the get_reachable_subset() API, memoization for --contains checks, a new --linearize option for git replay, and various documentation fixes. The ongoing effort to eliminate global state continues with patches targeting git_work_tree_cfg and is_bare_repository_cfg.

Notable performance improvements are in progress, including significant optimizations to reachability generation in pack-bitmap and streaming revision walks. The experimental git history command is gaining a new "drop" subcommand for commit editing.

Several documentation efforts are underway, including updates to interpret-trailers documentation and git-replay configuration. The project is also seeing continued migration of global configuration variables into per-repository structures.

The report shows active work across many areas of Git, with particular focus on performance optimizations, the ongoing removal of global state, documentation improvements, and the continued evolution of the object database infrastructure. Junio notes several topics that may need rerolls or are waiting for review responses, indicating active discussion threads on the mailing list.
