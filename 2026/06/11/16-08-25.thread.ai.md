Git development status report for June 2026 (What's cooking in git.git):

This is Junio Hamano's comprehensive status update on in-flight Git development topics, following the project's standard categorization. The report covers topics at various stages of maturity, from newly introduced patches to those ready for the upcoming Git 2.55 release.

Key graduated topics (merged to 'next' and candidates for 2.55) include: git-jump auto-mode selection optimizations, macOS linker warning fixes, push.default=simple documentation clarifications, Windows test fixes, line-log improvements, and significant refactoring of object database source handling. These represent stable improvements across multiple subsystems.

New topics introduced this cycle focus on performance and API cleanup: priority queue optimizations, removal of the get_reachable_subset() API, --contains check memoization, and a --linearize option for git replay. The ongoing global state elimination effort continues with work targeting git_work_tree_cfg and is_bare_repository_cfg. Performance work includes major optimizations to pack-bitmap reachability generation and streaming revision walks, with Mirko Faina now suggesting coordination between the --max-count-oldest feature and their own related patch series for revision walking optimizations.

Documentation efforts include updates to interpret-trailers and git-replay configuration, alongside continued migration of global configuration variables into per-repository structures. Open items noted by Junio include topics needing rerolls (priority queue optimizations, get_reachable_subset removal) and those awaiting review responses (--contains memoization, --linearize replay option, and now the --max-count-oldest coordination request from Mirko Faina). The report reflects broad activity across Git's codebase, with particular emphasis on performance, global state reduction, and infrastructure evolution, now with additional note of potential feature overlap in revision walking optimizations.
