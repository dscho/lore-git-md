This is a refactoring patch from Patrick Steinhardt's `git history drop` series, modernizing the flag system in Git's reset machinery. The patch converts the reset flags from `#define` macros to an enum type and updates all flag names to match the recent rename of `reset_head()` to `reset_working_tree()`.

The changes are mechanical but widespread, touching four files (builtin/rebase.c, reset.c, reset.h, sequencer.c) to update flag names and their usage. The enum provides better type safety and follows current Git coding practices. The flag renaming maintains consistency with the new function name while preserving all existing functionality.

This patch is part of the larger effort to improve the reset API for the new `git history drop` command, and also contributes to the project's ongoing code modernization efforts. The changes are straightforward and unlikely to be controversial, having already passed review in previous iterations of the series.
