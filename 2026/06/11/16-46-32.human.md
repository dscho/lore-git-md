This is a review of patch 3/6 in Kristoffer Haugsbakk's documentation series about Git commit trailer conventions. The patch explains why Linux-specific trailers like `Fixes:` and `Link:` aren't used in Git development.

Junio C Hamano provides a surface-level review, catching two minor issues:

The review doesn't challenge the technical content of the patch, which documents Git's existing practice of avoiding Linux-style trailers in favor of inline references and `refs/notes/amlog` for discussion links. The changes appear straightforward and well-justified, continuing the series' goal of clarifying trailer usage norms.
