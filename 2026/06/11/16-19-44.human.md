This is a documentation patch fixing AsciiDoc formatting issues in the git-config man pages. It's part of an ongoing effort to maintain clean documentation markup during the transition to consistent AsciiDoc syntax.

The patch specifically addresses a common AsciiDoc quirk where paragraphs following lists can get incorrectly appended to the last list item. The solution is to wrap problematic lists in open blocks (using `--` delimiters) to ensure proper rendering. The changes are mechanical and touch multiple config-related documentation files (config.adoc, promisor.adoc, safe.adoc, and git-config.adoc).

The doc-diff output shows the effect is purely formatting - fixing indentation and paragraph separation without changing content. This is the third iteration of the patch series, with previous versions having established the technical approach through review discussion. The changes are straightforward and uncontroversial, typical of the documentation maintenance work that regularly flows into the project.
