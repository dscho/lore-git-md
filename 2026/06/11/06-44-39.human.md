This is the first patch in Patrick Steinhardt's v2 series to eliminate global state in setup.c, part of the ongoing `the_repository` removal effort. The patch focuses on removing the `git_work_tree_cfg` global variable from the environment handling code.

The change makes `git_work_tree_cfg` file-local to setup.c and function-local to `cmd_init_db()`, since it's only needed during repository initialization. The patch demonstrates careful attention to memory management by properly freeing the worktree configuration after use. This is a mechanical but important cleanup that removes one more piece of global state from Git's core.

The patch follows the series' pattern of methodically eliminating global variables while maintaining identical behavior. With the review feedback from v1 addressed and the memory management clearly documented, this appears ready for merging as part of the larger refactoring effort.
