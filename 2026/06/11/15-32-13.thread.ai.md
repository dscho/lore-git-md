Git v2.55.0-rc0 release announcement thread, focusing on Rust compatibility concerns. Randall S. Becker reported build failures on NonStop systems due to default-enabled Rust components, noting the platform lacks Rust tooling and requesting changes for v2.55.0-rc1. Junio C Hamano responded by pointing to the existing `NO_RUST` Makefile flag as a temporary workaround, while stating the project's intention to make Rust mandatory in Git 3.0. This exchange highlights the transitional phase of Rust integration - currently optional with escape hatches, but planned as required in the future. The tension remains between Git's Rustification roadmap (led by Ezekiel Newren) and platform support realities (particularly NonStop, where Randall indicates Rust availability may not arrive before 2027). Open questions include whether to improve the build system's fallback behavior for missing Rust tooling and how to reconcile the Git 3.0 timeline with NonStop's constraints. The thread captures a key release-blocking issue at the intersection of technical direction and platform compatibility.
