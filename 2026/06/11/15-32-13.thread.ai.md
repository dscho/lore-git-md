Git v2.55.0-rc0 release announcement thread. This is the first release candidate for Git 2.55, containing 397 non-merge commits from 70 contributors (22 new). Key user-facing changes: parallel hook execution via config, improved terminal control sequences during remote ops, new `git checkout -m` stash behavior, `git format-rev` command, `git history fixup` subcommand, Linux fsmonitor daemon, and performance improvements in diff/traversal/object handling. Internal changes: continued `the_repository` removal, ODB transaction interface rework, MIDX repacking optimizations, Rust now enabled by default (optional), xdiff Rust prep, lazy clone fetch optimizations. The announcement lists all contributors and provides detailed release notes covering UI changes, performance work, and bug fixes across hooks, diff, merge, fetch/push, object storage, and platform-specific areas. This RC represents a major update with both user features and deep internal refactoring, particularly around object storage and performance paths.

Randall S. Becker reports a platform compatibility issue with the default-enabled Rust components, noting build failures on NonStop systems where the `cargo` command is unavailable. This continues his longstanding concerns about Rust's platform support limitations. The current build system lacks graceful fallback to pure C when Rust tooling is missing, despite Rust being technically optional. The report raises questions about whether the build system should be modified to better handle missing Rust toolchains or if Rust components should revert to opt-in rather than default-on for this release. This reflects the tension between advancing Git's memory safety through Rust and maintaining compatibility with platforms lacking Rust support, particularly NonStop where Randall maintains the Git port.
