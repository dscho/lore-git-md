Git v2.55.0-rc0 release announcement thread. This is the first release candidate for Git 2.55, containing 397 non-merge commits from 70 contributors (22 new). Key user-facing changes: parallel hook execution via config, improved terminal control sequences during remote ops, new `git checkout -m` stash behavior, `git format-rev` command, `git history fixup` subcommand, Linux fsmonitor daemon, and performance improvements in diff/traversal/object handling. Internal changes: continued `the_repository` removal, ODB transaction interface rework, MIDX repacking optimizations, Rust now enabled by default (optional), xdiff Rust prep, lazy clone fetch optimizations.

Randall S. Becker reports platform compatibility issues with the default-enabled Rust components, noting build failures on NonStop systems where the `cargo` command is unavailable. He explains the NonStop Rust port is a volunteer effort unlikely to be completed before 2027 and requests removing the Rust dependency for v2.55.0-rc1. This continues the tension between Git's Rustification efforts (led by Ezekiel Newren) and platform compatibility concerns (championed by Randall for NonStop systems). The current build system lacks graceful fallback to pure C when Rust tooling is missing, despite the feature being designed as optional. The issue raises questions about whether to modify the build system for better fallback handling or revert Rust to opt-in status for this release. The discussion highlights the ongoing challenge of balancing memory safety improvements through Rust with maintaining compatibility for platforms lacking Rust support.
