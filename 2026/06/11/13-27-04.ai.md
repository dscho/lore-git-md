This is the first patch in Patrick Steinhardt's v5 series introducing the `git history drop` command. It's a preparatory refactoring that extracts index handling logic from `repo_read_index_unmerged()` into a new standalone function `index_state_unmerged_to_stage0()`.

The change makes the unmerged-to-stage-0 conversion operation reusable on arbitrary index states rather than just the repository's main index. This will be needed by subsequent patches in the series for the history drop functionality. The patch also fixes a signedness mismatch in the index iteration.

The refactoring is clean and mechanical, with the new function following the same pattern as the original code while being more general. The change is well-contained (just 12 lines modified across two files) and comes with a clear commit message explaining both the immediate change and its purpose in the larger series. This is typical of Patrick's careful, incremental approach to larger features.
