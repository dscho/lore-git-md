The HTTP authentication test failure in Git 2.55.0-rc0, specifically t5563.18, has been fully resolved. The issue stemmed from a curl regression in Fedora 45 (curl 8.21.0-rc2) where `--anyauth -u :` no longer attempted Negotiate authentication, reducing expected HTTP 401 responses from three to two. This was tracked in curl's issue #21943 and fixed upstream in curl 8.21.0-rc3.

Matthew John Cheetham initially identified the regression and later proposed documenting curl's undocumented `CURLOPT_USERPWD = ":"` behavior to prevent future issues. Todd Zullinger confirmed the analysis and verified that the upstream curl fix resolves the test failure without requiring Git-side changes. Junio C Hamano's closing note confirms the resolution, marking the thread as complete. The only remaining action is Cheetham's proposed curl documentation patch, which is outside Git's scope but would clarify the implicit contract between the projects. No further Git-side work is needed.
