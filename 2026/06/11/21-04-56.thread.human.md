This thread tracks a test failure in Git's HTTP authentication test suite (t5563.18) that surfaced when running Git 2.55.0-rc0 on Fedora 45. The root cause has been identified as a regression in curl (specifically commit 8f71d0fde515) that changed how `--anyauth -u :` handles Negotiate authentication, resulting in fewer HTTP 401 responses than Git's test expects.

Matthew John Cheetham first reported the issue and traced it to the curl behavior modification, linking it to upstream issue curl/curl#21943. Todd Zullinger has since confirmed the analysis and noted that distributions like Fedora will likely pick up any curl fix quickly. The discussion is in a holding pattern while awaiting the curl maintainers' decision on whether to treat this as a bug (and revert the behavior) or intended (requiring Git to adapt its test or implementation).

The collaborative tone highlights how Git test suite and distribution testing caught this interoperability issue early. For now, no Git-side changes are needed - the thread serves to document the issue and track the upstream resolution, which will determine whether Git needs to adjust its HTTP authentication expectations for `http.emptyAuth=auto`.
