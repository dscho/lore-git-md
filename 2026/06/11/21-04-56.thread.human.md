This thread began with a report that Git’s HTTP authentication test t5563.18 was failing on Fedora 45 due to a curl regression in version 8.21.0-rc2. The issue—where `--anyauth -u :` stopped attempting Negotiate authentication—was quickly traced to a curl commit and fixed upstream in curl 8.21.0-rc3. Todd Zullinger confirmed the fix resolves the Git test suite without requiring any changes to Git itself, and distributions are expected to adopt the updated curl version before Git 2.55.0’s release.

In the latest follow-up, Matthew John Cheetham notes that while the regression is resolved, the behavior of `CURLOPT_USERPWD = ":"` (empty username/password) triggering Negotiate authentication remains undocumented in curl. He plans to submit a documentation patch to curl to formalize this behavior, treating it as a supported contract rather than an implementation detail. This would help prevent similar regressions in the future. The thread is now effectively closed for Git, with no further action needed beyond routine adoption of the fixed curl version by distributions.
