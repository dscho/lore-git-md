This is the second patch in a v3 documentation series fixing AsciiDoc markup issues in Git's man pages, specifically addressing description list delimiters in the sideband configuration documentation. The patch corrects a malformed description list item in `sideband.adoc` by changing `cursor:` to `cursor::` to properly terminate the list item.

The change is mechanical and focused purely on documentation formatting - it doesn't alter any content or meaning. The doc-diff output shows the fix properly formats the cursor option description in the rendered man page, separating it from the color option above with appropriate spacing.

This patch has already received surface-level review from Kristoffer Haugsbakk in previous iterations and is part of the uncontroversial final fixes needed before this documentation series can be merged. The change aligns with the ongoing effort to standardize AsciiDoc syntax across Git's documentation.
