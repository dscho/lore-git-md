This is a refactoring patch that consolidates two reachability functions in commit-reach.c (`get_reachable_subset()` and `tips_reachable_from_bases()`) into a single implementation with configurable traversal modes. The patch comes from Kristofer Karlsson and has already gone through review, with input from Junio Hamano and Derrick Stolee (the original author of both functions).

The key changes:
- Removes `get_reachable_subset()` in favor of an enhanced `tips_reachable_from_bases()` that can operate in either DFS or priority queue mode
- Improves traversal efficiency by eliminating merge commit revisits (2-parent merges now require 1 visit instead of 3)
- Maintains first-parent traversal order in DFS mode
- Adds comprehensive testing including new tests that use every commit in the test grid as a tip
- Updates callers in remote.c and ref-filter.c to use the new function

The patch appears well-constructed with thorough test coverage and clear documentation of the changes needed for callers. Performance benchmarks show modest speedups (1.09x-1.14x faster) in some real-world scenarios. The thread shows consensus among reviewers, with Stolee providing historical context about why the implementations originally diverged and validating the technical approach.

This represents a clean-up of duplicate code while preserving the optimal traversal strategy for each use case. The changes are conservative in maintaining existing behavior while providing a foundation for potential future optimizations.
