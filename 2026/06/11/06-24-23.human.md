This is a documentation patch review that uncovers an interesting AsciiDoc rendering quirk. Jeff King (Peff) follows up on his earlier review of the octothorpe escaping patch, discovering that Git's custom asciidoc.conf file affects how `#` characters are rendered in HTML output compared to plain AsciiDoc processing.

Peff demonstrates that while standard AsciiDoc`#` as code, Git's configuration suppresses this behavior due to a change made in 974cdca345. He notes this appears to be an unintended side effect of the synopsis typesetting work, and tags the original author (Jean-Noël Avila) for awareness.

The review maintains that the current patch series can proceed with either backslash or backtick escaping for octothorpes, as the rendering issue is separate from the immediate markup fixes. This is a substantive technical review that surfaces a potentially wider documentation tooling consideration while keeping it distinct from the current patch's scope.
