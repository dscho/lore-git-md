This is a documentation patch fixing AsciiDoc markup issues in Git's config documentation, part of an ongoing series being shepherded by Tuomas Ahola on behalf of Jean-Noël Avila's documentation maintenance efforts.

The patch specifically addresses a common AsciiDoc parsing quirk where paragraphs meant to follow lists get incorrectly appended to the last list item. The solution wraps affected lists in open blocks (delimited by `--`) to force proper termination. The changes are mechanical but important for correct rendering of the man pages.

The patch touches four documentation files (config.adoc, promisor.adoc, safe.adoc, git-config.adoc) with similar fixes. Each change follows the same pattern: identifying lists that need termination and wrapping them in open blocks. The doc-diff output shows the improvements in rendered formatting, particularly in sections about boolean values, promisor remotes, and safe repository handling.

This is the first of three patches in v3 of the series, building on previous discussion that established backticks as the preferred solution for octothorpe escaping. The changes are well-scoped and uncontroversial, representing straightforward documentation maintenance as part of the broader AsciiDoc conversion effort.
