This is the first patch in Patrick Steinhardt's v2 series to eliminate global state in setup.c, part of the ongoing `the_repository` removal effort. The patch focuses on removing the global `git_work_tree_cfg` variable from the environment handling code.

The change makes `git_work_tree_cfg` file-local to setup.c and function-local to `cmd_init_db()`, where it's only needed during repository initialization. The patch demonstrates careful attention to memory management by adding the missing `free()` call for the worktree path when it's no longer needed.

This is a mechanical refactoring that doesn't change behavior - it simply removes unnecessary global state while maintaining the same functionality through the repository's worktree field. The patch continues Patrick's pattern of well-structured, incremental changes that methodically tackle technical debt in the codebase.
