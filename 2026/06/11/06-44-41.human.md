This is the third patch in Patrick Steinhardt's v2 series to eliminate global state in setup.c, continuing the `the_repository` removal effort. The patch removes the `git_work_tree_cfg` global variable, which was previously used to track worktree configuration across setup.c and builtin/init-db.c.

The key changes in this revision are:
1. The worktree configuration is now sourced directly from the repository format rather than through the global variable
2. Added explicit memory management for the candidate work tree variable in `check_repository_format_gently()` to maintain previous NULL-setting semantics
3. Updated all call sites to reference the repository format's work tree field instead of the global

The patch demonstrates careful attention to maintaining existing behavior while cleaning up the architecture. The commit message clearly explains the rationale for the memory management change, showing this isn't just a mechanical substitution but a thoughtful refactoring. This continues the series' high standard of methodically removing global state while preserving functionality.
