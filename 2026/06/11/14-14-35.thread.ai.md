Documentation patch proposing to add email etiquette advice about trimming quoted text in mailing list replies to Git's MyFirstContribution guide. Author Weijie Yuan cites existing similar advice from both Git's ReviewingGuidelines and Linux kernel docs, noting maintainer Junio Hamano has previously emphasized this best practice. The change adds 5 lines to MyFirstContribution.adoc explaining when and how to trim quoted text to improve discussion readability. The patch is small, focused, and aligns with established project norms. Author invites feedback on wording, acknowledging potential need for polish. No technical changes - purely documentation improvement targeting new contributor experience.
