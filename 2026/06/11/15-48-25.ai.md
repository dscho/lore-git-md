This is a security update from Junio Hamano regarding the sideband sanitization series that addresses ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). The series had originally planned to delay the secure-by-default behavior (only allowing ANSI color sequences) until Git 3.0, but after merging the stricter version into 'master' a month ago with no reported issues, Junio now proposes shipping it in Git 2.55 as-is.

The key change removes the transitional compatibility layer that would have maintained permissive behavior until Git 3.0. The implementation has already seen production validation in Git for Windows and Red Hat environments. The sanitization prevents terminal state corruption and input buffer injection attacks while preserving legitimate ANSI color sequences used by pre-receive hooks.

This represents an acceleration of the security hardening timeline based on real-world testing showing no negative impact. The decision reflects confidence in the implementation's stability and the importance of addressing these CVEs promptly rather than waiting for a major version bump. The thread context shows this was the final patch in a mature series that had already introduced configurable control via `sideband.allowControlCharacters` with URL-specific settings.
