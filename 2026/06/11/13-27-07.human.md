This is a refactoring patch in Patrick Steinhardt's `git history drop` series, modernizing the flag definitions for the reset machinery. The patch converts the reset flags from `#define` macros to an enum type and updates all flag names to match the recently renamed `reset_working_tree()` function (previously called `reset_head()`).

The changes are mechanical but widespread, touching rebase.c, reset.c, reset.h, and sequencer.c to update flag names and their usage. The new enum makes the flags more type-safe and follows current Git coding conventions. The patch maintains all existing functionality while making the code more maintainable.

This is part of the larger effort to improve Git's reset machinery for the new `git history drop` command, and it follows naturally from the previous patch that renamed the core reset function. The changes have been carefully applied across all callers, showing good attention to detail. Since this is a straightforward refactoring with no behavior changes, it's unlikely to be controversial.
