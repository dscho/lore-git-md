This is a documentation patch proposing to add email etiquette advice to Git's MyFirstContribution guide. The patch suggests adding a paragraph about trimming quoted text in mailing list replies, citing existing similar guidance from both Git's ReviewingGuidelines and the Linux kernel documentation.

The author, Weijie Yuan, notes that Junio Hamano (the Git maintainer) has previously pointed out that over-quoting makes discussions harder to follow. The patch aims to make this best practice more visible to new contributors by including it in the onboarding documentation. The change is small and focused - just adding 5 lines to the MyFirstContribution.adoc file with clear advice about when and how to trim quoted text in replies.

The patch appears well-motivated and uncontroversial, addressing a real documentation gap. The author acknowledges their English may need polishing and invites feedback, suggesting this is a genuine attempt to improve contributor experience rather than pushing a personal preference. The change aligns with existing project norms and documentation.
