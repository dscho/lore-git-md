This is a security update from Junio Hamano regarding the ANSI escape sequence injection fixes (CVE-2024-32002, CVE-2024-52005). The patch series, originally developed by Johannes Schindelin, introduces stricter sanitization of control characters in Git's sideband channel while preserving ANSI color sequences by default.

The key development here is that Junio is deciding to ship the stricter sanitization behavior in Git 2.55, rather than waiting until Git 3.0 as originally planned. This comes after a month of testing the changes in the 'next' branch without any reported issues. The change affects how Git handles potentially malicious control sequences in remote messages while maintaining compatibility with legitimate colored output from pre-receive hooks.

The series has undergone extensive vetting, including production use in Git for Windows and Red Hat environments. The implementation allows for per-URL configuration via `sideband.<url>.allowControlCharacters` while defaulting to secure behavior globally. Junio is soliciting final feedback before making this change permanent in the upcoming release.

This represents a significant security hardening for Git's remote protocol handling, addressing known vulnerabilities while carefully balancing compatibility concerns. The lack of reported issues during testing suggests the change is ready for broader deployment.
