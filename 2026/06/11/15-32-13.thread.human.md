This thread discusses Rust compatibility concerns in the upcoming Git v2.55.0-rc0 release, particularly regarding NonStop systems that lack Rust tooling. Randall S. Becker initially raised the issue of build failures on NonStop platforms, prompting Junio C Hamano to point to the existing `NO_RUST` Makefile flag as a temporary workaround. 

In the latest update, Randall confirms this workaround successfully resolves the immediate build issue. However, the core tension remains: while this solution works for now, Git's roadmap calls for Rust to become mandatory in version 3.0, which poses a problem for NonStop systems where Rust tooling may not be available until 2027. The thread captures both a practical short-term fix and the unresolved long-term challenge of aligning Git's technical direction with platform support realities. The discussion leaves open how the project will reconcile these competing priorities as it moves toward Git 3.0.
