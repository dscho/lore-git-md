Junio Hamano announced Git v2.55.0-rc0, a major update with new features like parallel hooks and Linux fsmonitor, plus significant internal refactoring around object storage and performance. The release also enables Rust components by default as part of Git's gradual Rustification effort.

Randall Becker raised concerns about this change, noting the build fails on NonStop systems which lack Rust tooling. In a second email, he elaborated that the NonStop Rust port is a long-term volunteer effort unlikely to be ready before 2027. He's requesting the Rust components be made optional again for the 2.55 release cycle, as originally planned for Git 3.0. This highlights an ongoing tension between advancing Git's memory safety through Rust and maintaining compatibility with platforms like NonStop where Randall maintains the Git implementation. The immediate issue is that the build system doesn't properly handle cases where Rust tooling is missing, despite the feature being designed as optional. The thread may need to resolve whether to modify the build system or revert Rust to opt-in status for this release.
