Git v2.55.0-rc0 introduces significant new features and internal refactoring, including Rust components that are now enabled by default. The release candidate announcement highlighted parallel hook execution, new commands like `git history fixup`, and performance improvements across several subsystems.

Randall S. Becker, maintainer of Git's NonStop port, reports that the build fails on NonStop systems due to missing Rust tooling. This revives his longstanding concerns about platform compatibility, as the current build system doesn't gracefully fall back to C when Rust isn't available. The Rust integration represents a key advancement for memory safety, but this issue raises questions about whether it should remain opt-in for platforms lacking Rust support or if the build system needs modifications to handle such cases. The thread may see discussion about balancing technical progress with broad compatibility, particularly for maintained ports like NonStop.
