This is patch 5/7 in Patrick Steinhardt's v2 series to eliminate global state in setup.c, part of the ongoing `the_repository` removal effort. The patch refactors how Git tracks whether a repository is bare, splitting the concept into two distinct concerns:

1. `startup_info.force_bare_repository` now tracks whether the user passed the `--bare` flag (which forces bare treatment regardless of repository configuration)
2. `struct repository::bare_cfg` tracks the actual bare state of each repository, considering both the --bare flag and repository configuration

The change is mechanical but touches core repository initialization code across 9 files. It enables future patches to make `is_bare_repository()` independent of global state. The patch follows the series' pattern of careful, well-documented refactoring that maintains existing behavior while removing global dependencies.
