This is a bugfix follow-up to a recently reported hang in `git receive-pack`. Patrick Steinhardt confirms the issue Wei Hu described—where a zero-object push to a promisor remote repository causes an indefinite hang—but notes it was already fixed in commit `d9982e8290` ("connected: close err_fd in promisor fast-path"), which will ship in Git 2.55 (releasing today).

Patrick provides a minimal test case (a new test in `t/t5616-partial-clone.sh`) that reproduces the hang and verifies the fix. The test creates a promisor-shaped repository, pushes an existing commit under a new branch name (triggering a zero-object transfer), and confirms the push completes without hanging. He observes that while the fix exists, it lacks test coverage, and invites Wei to contribute the test if interested; otherwise, Patrick will send a patch himself.

The summary is straightforward: the bug is already resolved, but the fix could use a regression test.
