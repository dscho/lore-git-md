This is the **Git 2.55.0 release announcement** from Junio C Hamano. The latest feature release includes 505 non-merge commits from 100 contributors, 33 of whom are new to the project. The release notes highlight several new features, performance improvements, and fixes across the codebase.

Key **user-facing changes** include:
- **Parallel hook execution**: Hooks defined in Git’s configuration can now run in parallel, improving performance for multi-hook workflows.
- **Enhanced `git checkout -m`**: The command now stashes local changes automatically when switching branches with conflicts.
- **New built-ins**: `git format-rev` for pretty-formatting revision expressions and `git url-parse` for parsing URLs.
- **Linux fsmonitor support**: The fsmonitor daemon is now available on Linux, complementing existing Windows/macOS backends.
- **`git push` remote groups**: Push to multiple remotes at once using a configured "remote group."
- **`git history fixup`**: A new subcommand for amending commits interactively.
- **Improved diffstat handling**: UTF-8 truncation now correctly accounts for invalid sequences and control characters.

**Performance and internal improvements** are substantial:
- **Reachability bitmap optimizations**: Faster `git repack --write-midx-bitmaps` via tree traversal reordering and pseudo-merge caching.
- **Priority queue for revision walks**: Speeds up `git log` and `git rev-list` in repositories with many merges.
- **ODB abstraction**: Refactoring continues to support pluggable object storage backends, including a new in-memory source for tentative objects.
- **Rust support enabled by default**: Rust code can now be included in the build (opt-out remains possible).
- **Memory safety fixes**: Plugged leaks in `fetch_and_setup_pack_index()` and `transport-helper`, and widened size_t usage to handle >4GB objects on Windows.

**Notable fixes** address regressions and edge cases:
- **Proxy URL validation**: Misspelled schemes (e.g., `httt://`) now trigger errors.
- **`git fetch --deepen`**: No longer truncates history in full clones.
- **`git backfill`**: Rejects incompatible revision options and includes boundary blobs by default.
- **`git grep`**: Prefetches blobs in lazy clones to avoid one-by-one fetches.
- **Windows compatibility**: Fixed mmap-related issues and improved SIGINT handling.

**Documentation updates** are extensive:
- Clarified `push.default=simple` behavior and `--word-diff` implementation details.
- Modernized man pages for `git difftool`, `git range-diff`, and others using AsciiDoc synopsis style.
- Added guidelines for cover letters in `SubmittingPatches`.

The release also includes **platform-specific fixes** (macOS linker warnings, Cygwin path handling) and **test suite improvements** (TAP compliance, Windows-specific skips). New contributors are welcomed, and returning contributors are thanked for their sustained efforts.

This is a **major release** with significant new functionality, performance gains, and robustness improvements. Users should upgrade, especially those working with large repositories or hooks. The full notes are detailed, but the highlights above capture the most impactful changes.
