This thread reports a bug where `git receive-pack` hangs indefinitely when a zero-object ref update is pushed to a repository configured as a promisor remote. The issue was confirmed and has already been fixed by Patrick Steinhardt in commit `d9982e8290`, which will be included in today's Git 2.55 release. The fix addresses a deadlock in the promisor object resolution logic when no objects are transferred.

While the bug itself is resolved, the fix currently lacks test coverage. Patrick provided a minimal test case (a patch to `t/t5616-partial-clone.sh`) to reproduce the hang and invited Wei Hu, the original reporter, to contribute the test or offered to submit it himself. This is a straightforward follow-up task to prevent future regressions in the promisor remote subsystem, which has seen multiple bugs in the past. No further discussion or controversy remains in the thread.
