This is a security coordination update from Johannes Schindelin, the maintainer of Git for Windows, responding to an inquiry about CVE-2026-34182 in OpenSSL 3.5.6 bundled with Git 2.54.0.

Johannes clarifies that the `openssl.exe` binary included in Git for Windows is not part of Git’s critical functionality—it’s a historical artifact rather than an active dependency. Because Git itself does not use the CMS functionality affected by the CVE, the vulnerability poses no risk to Git’s core operations. As a result, Git for Windows will not issue an out-of-band security release for this issue. Instead, the fixed OpenSSL 3.5.7 will be included in the upcoming Git for Windows 2.55.0 release, expected within the next day or two.

The response is concise and authoritative, closing the inquiry by confirming that no action is required for Git users. It also underscores the separation between Git and Git for Windows: while the original question asked about "Git," the answer applies only to the Windows installer, which is maintained independently. No further discussion is expected on this thread.
