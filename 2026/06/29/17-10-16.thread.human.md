Git v2.55.0 has just been released by Junio C Hamano, marking a significant milestone with 505 non-merge commits from 100 contributors—including 33 new faces. This release introduces several major features and architectural changes. Parallel hook execution is now supported, allowing hooks defined in Git configuration to run concurrently, with new options like `--jobs` and `hook.jobs` to control the number of parallel jobs. Two new built-in commands debut: `git format-rev` for pretty-formatting revision expressions and `git url-parse` for internal URL handling.

Performance improvements are a standout in this release, with optimizations in revision traversal (using priority queues for date-sorting), reachability bitmap generation, and sparse-index operations in `git restore`. The Linux fsmonitor daemon is now natively supported, joining the existing Windows and macOS backends. Rust support has also taken a step forward, now enabled by default (though still opt-out), with preparatory work in the xdiff/ codebase and build system. Other notable changes include backfill and promisor remote improvements, MIDX compaction, and stricter validation of proxy URLs.

The release also includes over 50 bug fixes, addressing memory leaks, edge cases in `git bisect` and `git describe`, and Windows-specific issues. Some breaking changes are worth noting: sideband terminal control sequences are now disabled by default (except for ANSI colors), and `git checkout -m` now stashes local changes by default. The ODB (object database) subsystem has seen significant refactoring, and incremental MIDX repacking is now possible with `--write-midx=incremental`. While the breadth of changes reflects active development, areas like Rust integration and ODB transaction rework may spark further discussion in the community.
