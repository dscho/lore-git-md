This is a **surface-level review** of patch 6/8 in the `paint_down_to_common()` optimization series. Gábor SZEDER points out that the two static functions removed in this patch (`nonstale_queue_put_dedup()` and `nonstale_queue_get_dedup()`) became unused in the *previous* patch (5/8), which means the code cannot build with `DEVELOPER=1` enabled due to `-Wunused-function` warnings. He requests that the two patches be squashed into one to avoid breaking the build in the intermediate state.

The issue is purely mechanical: the functions are dead code as soon as their last caller is removed, so they should be deleted in the same commit that removes the caller. No technical objections to the removal itself; the feedback is about patch organization rather than correctness. The fix is straightforward and uncontroversial.
