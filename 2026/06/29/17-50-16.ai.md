Key technical details for the AI brief:

- **New topics needing review**
  - `tb/repack-geometric-cruft` (11 patches): teaches `git repack --geometric --cruft` to roll up non-cruft packs into a geometric progression while writing a separate cruft pack for unreachable objects.
  - `jk/reftable-leakfix` (1 patch): fixes a leak in the reftable backend on API error.
  - `ps/reftable-hardening` (12 patches): fuzz-driven hardening of the reftable parser against OOB reads/writes, NULL derefs, and aborts on corrupted tables; adds libFuzzer support to Meson.
  - `ps/odb-drop-whence` (7 patches): removes the `whence` field from `struct object_info`, replacing it with an opt-in `struct object_info_source` that carries backend-specific data.
  - `jt/receive-pack-use-odb-transactions` (6 patches): refactors `git-receive-pack` to use the ODB transaction API instead of `tmp_objdir`, making it backend-agnostic.
  - `ps/libgit-in-subdir` (4 patches): moves all `libgit.a` source files into a new `lib/` directory to clean up the top-level directory.
  - `ps/odb-generalize-prepare` (3 patches): generalizes the `reprepare()` callback into a `prepare()` callback with a flush flag and adds an `odb_prepare()` wrapper.
  - `hn/history-squash` (4 patches): adds a `git history squash` subcommand to fold a range of commits into one, replaying descendants on top.
  - `ps/history-drop` (11 patches): adds a `git history drop` subcommand to remove a commit and replay its descendants onto its parent, using a dry-run mode and refactoring the reset machinery to avoid touching HEAD or the index unnecessarily.
