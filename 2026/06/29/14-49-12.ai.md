Junio C Hamano notes that the squash commit-message template produced by `git history squash --reedit-message` omits the numbered markers (`# This is the 1st commit message`) that `git rebase -i` includes between folded-in commit messages. Junio endorses the idea, suggesting that code sharing (even if cleaned up) would be beneficial.

The change is trivial: it affects only the editor template’s appearance, not the resulting commit message or any other behavior. The series itself is code-complete, well-tested, and ready for Junio’s final assessment; this is a follow-up opportunity rather than a blocker. No further design or technical work remains.
