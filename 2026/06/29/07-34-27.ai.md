This is a refactoring patch that splits out a helper function, `index_state_unmerged_to_stage0()`, from `repo_read_index_unmerged()`. The new function operates on an arbitrary `struct index_state *` rather than the repository's default index, preparing the codebase for future callers that need to drop unmerged entries to stage 0 on non-default indexes. The patch also fixes a signedness mismatch in the loop counter (changing `int i` to `unsigned int i`).

This is the first patch in Patrick Steinhardt’s 11-patch `git history drop` series (v7). It is a small, mechanical change with no behavior impact—just moving code into a reusable helper. The commit message explains the motivation clearly: a subsequent patch will use this helper on arbitrary indexes, not just the repository’s default one. The signedness fix is a minor bonus.

The patch touches only `read-cache-ll.h` and `read-cache.c`, adding the new function declaration and definition. No tests are added because the existing `repo_read_index_unmerged()` tests continue to cover the behavior. This is a clean, uncontroversial refactoring that advances the series’ goal of modernizing the reset API and removing implicit `the_repository` usage.
