This email announces the release of **Git for Windows 2.55.0**, the Windows-specific distribution of Git maintained by Johannes Schindelin. It tracks the upstream Git 2.55.0 release but focuses on Windows-specific packaging, dependencies, and bug fixes.

Key changes include dropping support for Windows 8.1 (following MSYS2’s lead), fixes for a `git fetch` regression causing infinite unlink loops on older Windows 10 versions, process shutdown issues in Git Bash, and parallel checkout problems with FSCache enabled. The release also tightens `.git` file validation and improves handling of large clones or packfiles. All downloadable artifacts (installers, portable builds, and archives) are provided with SHA-256 checksums.

This is a downstream release and does not affect upstream Git development, though it bundles the latest upstream version. The announcement is aimed at Git for Windows users, not upstream contributors.
