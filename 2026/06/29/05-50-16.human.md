This is Junio’s review of the final patch in Harald Nordgren’s `git history squash` series (v6 4/4). The patch implements the `--reedit-message` flag, which gathers all folded-in commit messages (oldest first) into an editor template, mirroring `git rebase -i`’s squash behavior.

Junio notes a minor cosmetic difference: unlike `git rebase -i`, the new implementation does **not** insert markers like `# This is the 1st commit message` between the folded messages. While this doesn’t affect functionality, it means the editor template will be slightly less structured than the one produced by rebase. The observation is factual and not a request for change—Junio explicitly says he doubts it will make a practical difference.

The rest of the series has already addressed all prior feedback, and this patch completes the feature. No design or technical issues are raised; the comment is purely about presentation. The series remains ready for Junio’s final assessment.
