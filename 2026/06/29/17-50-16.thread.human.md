Here’s a concise narrative summary of the current state of the Git mailing list as of Junio’s latest "What’s cooking" report:

Git 2.55 has just been released, and the integration branches are active with a mix of new, graduated, and stalled topics. The most substantial new work centers on Patrick Steinhardt’s ongoing ODB (object database) abstraction and reftable hardening efforts. His `ps/reftable-hardening` series (12 patches) uses fuzzing to harden the reftable parser against corruption, while `ps/odb-drop-whence` (7 patches) removes the `whence` field from `struct object_info` in favor of a more flexible backend-specific structure. These changes are part of a broader push to make Git’s storage layer more modular and robust, with Justin Tobler’s `jt/receive-pack-use-odb-transactions` (6 patches) refactoring `git-receive-pack` to use the ODB transaction API, a key step toward backend-agnostic operations.

Other notable new topics include Taylor Blau’s `tb/repack-geometric-cruft` (11 patches), which extends geometric repacking to handle cruft packs separately, and two new history-editing commands: `git history squash` (Hannes’s 4-patch series) and `git history drop` (Patrick’s 11-patch series). The latter refactors the reset machinery to avoid unnecessary index/HEAD updates, a long-requested improvement for interactive rebase workflows. Meanwhile, `ps/cat-file-remote-object-info` (Patrick) adds a `remote-object-info` batch command to `git cat-file`, enabling clients to fetch object metadata from remote servers via protocol v2—useful for partial clones and promisor remotes.

On the review front, several topics are waiting for author updates, including stalled work on config file locking (`jt/config-lock-timeout`) and subcommand autocorrection (`js/parseopt-subcommand-autocorrection`). The `next` branch is cooking with Patrick’s `refs-writing-subcommands` (new `git refs create|delete|update|rename` commands) and `connected-generic-promisor-checks` (ODB-based connectivity checks for promisor objects), alongside smaller but impactful changes like `hn/branch-delete-merged` (a `--delete-merged` flag for `git branch`) and `kk/merge-base-exhaustion` (an optimization for merge-base computation). Junio’s report flags open review threads and expected rerolls, so expect updates on these soon.
