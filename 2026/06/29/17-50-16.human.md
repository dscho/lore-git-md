This is Junio’s biweekly “What’s cooking in git.git” report for June 2026, summarizing the state of 50+ in-flight topics.  It is not a patch itself, but a high-level digest of what is happening across the entire integration tree.

The report opens with the usual logistics: Git 2.55 final has just been tagged, and the usual four integration branches (maint, master, next, seen) are listed with their public clone URLs.  The bulk of the email is a categorized inventory of topics, each annotated with its current integration branch, age, a one-line summary, and pointers to review discussion.

New topics of note include Taylor Blau’s `tb/repack-geometric-cruft` (11 patches), which teaches `git repack` to combine `--geometric` and `--cruft` so that unreachable objects are collected in a separate cruft pack while the rest are rolled up geometrically.  Jeff King’s `jk/reftable-leakfix` (1 leak plug) and Patrick Steinhardt’s `ps/reftable-hardening` (12 patches) are hardening the reftable backend against corrupted tables and API misuse.  Toon Claes’s `tc/replay-linearize` (3 patches) adds a `--linearize` option to `git replay` that drops merge commits, mimicking `git rebase --no-rebase-merges`.

Several topics have graduated to master: Peff’s HTTP proxy hotfix (`js/http-https-proxy-fix`), a TAP output fix (`ps/t4216-tap-fix`), and two test-suite robustness improvements (`jk/t5551-expensive-test-timeouts-fix` and `sg/t3420-do-not-grep-in-missing-file`).

Stalled topics include Jörg Thalheim’s config-lock timeout (`jt/config-lock-timeout`) and Johannes Schindelin’s subcommand autocorrection (`js/parseopt-subcommand-autocorrection`), both waiting for author responses to review comments.

The “Cooking” section lists topics in next or seen that are actively being reviewed.  Highlights: Patrick Steinhardt’s ODB abstraction work (`ps/odb-drop-whence`, `ps/odb-source-packed`, `ps/connected-generic-promisor-checks`), a new `git refs` write subcommand suite (`ps/refs-writing-subcommands`), and Han-Wen Nienhuys’s `hn/history-squash` (4 patches) that adds a `git history squash` subcommand to fold a range of commits into one.

Overall, the report paints a picture of steady progress on ODB abstraction, reftable hardening, and the experimental `git history` command, with a handful of smaller fixes and documentation updates rounding out the queue.
