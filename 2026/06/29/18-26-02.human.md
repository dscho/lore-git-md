This is an **announcement** of the Git for Windows 2.55.0 release.

Johannes Schindelin announces the availability of Git for Windows 2.55.0, which bundles Git 2.55.0 and updates several key dependencies: the MSYS2 runtime (based on Cygwin 3.6.9), Git Credential Manager 2.8.0, OpenSSL 3.5.7, Bash 5.3.15, and cURL 8.21.0. The release also ports the diff helper for Word documents from Perl to Rust.

Notable bug fixes include resolving an endless unlink loop during `git fetch` on older Windows 10 versions, improving process shutdown in Git Bash, and tightening `.git` file validation (following TortoiseGit 2.19), which now requires explicit `safe.directory` configuration for UNC file paths. The release drops Windows 8.1 support after this version, aligning with the MSYS2 project’s decision. Downloads are available for 64-bit, ARM64, and 32-bit systems, including portable and MinGit variants.
