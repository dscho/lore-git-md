This is the second patch in Patrick Steinhardt’s v2 twelve-patch series hardening Git’s reftable backend against maliciously corrupted files. It adds a new libFuzzer target (`oss-fuzz/fuzz-reftable.c`) that exercises the three main entry points into the reftable parser—ref, log, and raw block iterators—by feeding them arbitrary byte sequences. The fuzzer is wired into both the Makefile and Meson build systems and is included in Git’s CI via `ci/run-build-and-minimal-fuzzers.sh`. No new vulnerabilities are fixed in this patch; it is purely infrastructure that will be used to discover and prevent regressions in the subsequent ten patches. The code is straightforward, well-scoped, and already integrated into the project’s fuzzing pipeline.
