This is a utility function patch, part of the `git cat-file --batch-command` remote object metadata series (GSoC v14, patch 2/13). It adds `strtoul_szt()`, a safe conversion function that parses a string into a `size_t` with full error handling, mirroring the existing `strtoul_ui()` pattern.

The new function checks for negative signs (which `strtoul` would otherwise accept), validates the entire string was consumed, and propagates `errno` from the underlying `strtoul` call. This matches the project's preference for defensive numeric parsing and will be used in the upcoming `remote-object-info` command to handle object size fields, which were recently changed from `unsigned long` to `size_t`.
