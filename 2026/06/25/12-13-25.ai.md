This is a refactoring patch in the ongoing `git cat-file --batch-command` security series. It mechanically moves loop counter declarations (`int i`) into their respective `for()` statements and changes their type to `size_t` where appropriate, matching the type of the loop bounds.

The patch touches two files: `builtin/cat-file.c` (four loops) and `fetch-pack.c` (one loop). In each case the change is purely stylistic—no logic is altered, only variable scope and type. The commit message notes that the counters are only used within the loops, so declaring them there improves readability. The type change from `int` to `size_t` aligns with the unsigned nature of array indices and loop bounds (e.g., `ARRAY_SIZE()`, `nr`).

This is the third patch in the v14 series and is part of the preparatory cleanup that precedes the core protocol and security changes. The patch is uncontroversial and follows established Git style; it was authored by Eric Ju and carried forward by Pablo Sabater. No review feedback has surfaced on this specific patch, but the broader series has been thoroughly reviewed and is considered ready for merging.
