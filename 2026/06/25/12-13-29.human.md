This is a refactoring patch in the ongoing `git cat-file --batch-command` security series. It generalizes the `write_fetch_command_and_capabilities()` function into `write_command_and_capabilities()`, allowing it to write arbitrary protocol v2 commands (like the new `remote-object-info` command) instead of being hardcoded to "fetch".

The change is mechanical: the function now takes a `command` string parameter, and the callers in `fetch-pack.c` pass "fetch" explicitly. The patch updates the function name, signature, and documentation to reflect its broader purpose. Jonathan Tan and Christian Couder are credited with helping shape this refactoring.

This is part of the preparatory work for the `remote-object-info` command (patch 10/13 in the series) and doesn’t change behavior on its own. The patch is small, well-contained, and aligns with the series’ goal of reusing protocol infrastructure. No controversy or open questions are evident.
