This is the **third patch in Patrick Steinhardt's 11-part v6 refactoring series** for Git's reference backend infrastructure. The patch is a **mechanical cleanup** that addresses a minor inefficiency in repository discovery: it stops applying the `GIT_REFERENCE_BACKEND` environment variable when no repository is found, and removes a redundant call to `repo_set_ref_storage_format()`.

The change moves the environment variable handling into the branch where a repository has been discovered (`startup_info->have_repository`), eliminating unnecessary work when Git is run outside a repository. This also allows the patch to drop the explicit `repo_set_ref_storage_format()` call because the ref storage format is now adjusted *before* `apply_repository_format()` is called, avoiding a second application of the repository format. The diff is small (19 insertions, 20 deletions) and confined to `setup.c`.

This patch is **uncontroversial** and serves as a preparatory step for the lazy-loading design introduced later in the series. It does not change behavior for users or other subsystems, but it simplifies the initialization sequence by removing redundant format application. The commit message clearly explains the motivation and the mechanical nature of the change.
