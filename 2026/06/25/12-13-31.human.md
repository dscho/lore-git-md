This is the ninth patch in the fourteenth iteration of a security-focused feature series that adds `` `git cat-file --batch-command` `` support for querying remote object metadata. The series is now in its final form, with all prior review feedback addressed and no outstanding objections.

This patch enables the Git server to advertise its support for the `object-info` capability, which is the foundation for the new `` `git cat-file --batch-command` `` functionality. The change is minimal: it modifies the `object_info_advertise` function in `serve.c` to append the string "size" to the capability value when the feature is enabled, signaling that the server can provide object size information. The feature remains disabled by default, respecting the existing `transfer.advertiseobjectinfo` configuration setting.

The patch is authored by Calvin Wan but carries co-authorship from Eric Ju and Pablo Sabater, reflecting the collaborative nature of the series. The `Helped-by` trailers credit Jonathan Tan and Christian Couder, indicating substantive review input. This is a well-placed, mechanical change that directly supports the series' core goal of secure, capability-based object metadata queries without full downloads.

There is nothing controversial here; the patch is a straightforward implementation of the agreed protocol design. The commit message clearly explains the purpose and the current limitation (only "size" is advertised, though the protocol is designed to be extensible). This is a necessary step before clients can safely use the new `remote-object-info` command introduced later in the series.
