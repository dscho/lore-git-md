Subject: [PATCH] gpg-interface: allow SSH signature inspection without allowedSignersFile
Series version: standalone patch
Originating author: Grayson Tinker
Thread type: bugfix patch

Core problem or goal
Git’s SSH signature verification currently requires `gpg.ssh.allowedSignersFile` to be configured before it will display any signature information (key, fingerprint, validity). Users who only want to inspect the signature—without automated principal validation—are blocked by an error and forced to create the file. The patch relaxes this requirement so that basic signature details (key type, fingerprint, “Good”/“Bad” status) are always shown, while principal validation remains optional.

Current status
Patch is new; no prior versions. Under review following maintainer feedback. No merge decision yet.

Key technical details
- File touched: `gpg-interface.c`
- New include: `advice.h` (for hint message)
- New behavior: “novalidate” fallback mode when `gpg.ssh.allowedSignersFile` is unset; signature key type, fingerprint, and “Good”/“Bad” status are now shown
- Advice message: emitted unconditionally for every SSH-signed commit when the allowed signers file is unset; bypasses `advise_if_enabled()`
- On-disk format: unchanged
- Test coverage: none added in this patch

Open questions and loose ends
- **Usability trade-off (Junio)**: the unconditional advice message creates noise in bulk operations (e.g., `git log --show-signature -100`); users cannot suppress it. The author acknowledges the trade-off but argues the current one-line message is preferable to the previous error. Junio has not yet indicated whether he considers the trade-off acceptable or prefers a suppressible or rate-limited message.
- No test coverage for the new fallback path.
- No documentation update for the relaxed requirement.
- **Use-case prevalence**: Junio questions whether the inspection-without-validation workflow is common enough to justify the noise; the author states it is their own workflow but does not provide broader evidence.

Participant positions
