The patch moves parsing of `core.logAllRefUpdates` back into the ref stores to avoid premature config reads that could trigger recursive initialization via "onbranch" conditions.

The fix is straightforward: the check for `LOG_REFS_UNSET` will be removed, simplifying the logic to rely solely on whether the config value exists. This aligns with the patch’s goal of unifying backend config handling while avoiding unnecessary complexity.

The change is minor and uncontroversial, addressing a technical edge case without altering the patch’s core behavior.
