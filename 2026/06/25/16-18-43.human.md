This is a refactoring patch series that continues the ongoing libification effort in Git. The author, Tian Yuchen, moves the global `excludes_file` string variable into the `repo_config_values` struct, which is part of the broader push to eliminate global state and make Git's internals more modular and reusable.

The series consists of two patches. The first abstracts the lazy-loading logic for the XDG fallback path out of `dir.c` into a dedicated getter function. The second moves the variable itself into `repo_config_values` and introduces a `repo_config_values_clear()` function to handle memory cleanup. Both patches include a temporary guard to prevent issues with uninitialized submodules, a detail borrowed from an earlier discussion on the mailing list.

The commit messages are clear and the changes are well-scoped, touching only `dir.c`, `environment.c`, `environment.h`, and `repository.c`. The series is mentored by Christian Couder, Ayush Chandekar, and Olamide Caleb Bello, which suggests it’s part of a structured contribution effort (likely through Outreachy or a similar program). The code looks clean and the motivation—reducing global state—aligns with long-standing project goals. If you’re following the libification work, this is a small but meaningful step forward.
