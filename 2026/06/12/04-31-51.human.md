Performance optimization for `git ls-files` with pathspecs.

This final version of the series implements a significant performance improvement for `git ls-files --deleted` and `--modified` when used with pathspecs. The key change filters pathspec matches before making expensive `lstat()` calls, avoiding unnecessary filesystem operations for non-matching entries. Benchmarks show dramatic speedups - from 65.8 seconds down to 5.0 seconds in one test case with 881,290 index entries.

The patch has evolved through three versions with input from Jeff King (Peff) and Junio Hamano. The initial approach was made more robust by restricting the optimization to single pathspec cases where the matching cost is minimal, avoiding potential regressions with multiple pathspecs. The implementation includes new performance tests and verification of wildcard pathspec behavior.

All technical concerns have been addressed, and both Peff and Junio have approved the approach. The only remaining items were minor documentation and email threading fixes, which Tamir has now incorporated. This is ready for merging with its clear performance benefits and thorough test coverage.
