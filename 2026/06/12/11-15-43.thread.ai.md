Thread identity: Performance optimization for commit reachability in `paint_down_to_common` (merge-base calculations), with three independent discoveries. Authored by Kristofer Karlsson as RFC, with substantive reviews from Derrick Stolee and Elijah Newren. GitHub has a limited production deployment.

Core problem: Merge-base computations perform unnecessary traversal after one branch's commits are exhausted, particularly costly in monorepos. The optimization introduces early termination when one side is fully processed, with STALE bit propagation and generation number validation. Handles edge cases including imported repositories (generation 0 roots) and infinite generation numbers.

Current status: Two production-validated implementations exist - Karlsson's PR #2149 and Newren's GitHub deployment. Both show 300-1000x speedups (4.85s->6ms) in "shape 2" topologies. Key difference: Newren disables optimization when both sides touch commits outside commit-graph, while Karlsson enables it in finite-generation regions. Karlsson has incorporated Newren's test cases.

Key technical details: Targets `paint_down_to_common` in commit-reach.c. Implementation nuances:
1. STALE propagation handling now validated through shared test cases
2. Generation-0 roots behavior confirmed between implementations
3. Finite vs infinite generation number divergence identified
GitHub's deployment provides real-world validation despite generation number limitation.
