This is a refactoring patch in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. Karthik Nayak provides a review of the final patch (9/9) which completes the transition to absolute paths in reference backends.

The patch removes the last remaining uses of `chdir_notify_reparent()` callbacks by ensuring `refs_compute_filesystem_location()` always returns absolute paths. This simplifies path handling across all ref backends (files, packed, reftable) and makes behavior more predictable. The review notes two minor documentation nits where the commit message incorrectly references `chdir_notify_reparent()` instead of `chdir_notify_register()`, but otherwise approves the technical approach.
