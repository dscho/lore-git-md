This is a feature patch series introducing a global `fetch.followRemoteHEAD` configuration option, building on the per-remote version added in Git 2.48. The series is now in its implementation phase after design discussions with Jeff King and Bence Ferdinandy.

The core change adds a global fallback setting that applies when no remote-specific `remote.<name>.followRemoteHEAD` is configured, following the same precedence pattern as `fetch.prune`. The implementation carefully handles edge cases like dangling symrefs and refspec fetches while maintaining the existing per-remote override capability. Bence Ferdinandy confirms that `git clone` behavior remains unaffected, using its own separate mechanism for remote-tracking HEAD.

The 7-patch series includes preparatory cleanups, core functionality, comprehensive tests, and documentation. Matt Hunter indicates he may explore the clone behavior in a future series but is keeping this one focused.
