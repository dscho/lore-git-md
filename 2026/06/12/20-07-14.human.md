This is the third and final patch in Taylor Blau's series fixing MIDX incremental writes with custom base layers. The patch completes the fix by correcting the pack inclusion logic when using `--base` options.

The core issue was that the MIDX write path was incorrectly excluding packs that should have been included when using custom base layers (either `--base=none` or `--base=<hash>`). The previous patch in the series fixed the base layer passthrough, and this one addresses the pack selection logic.

The key change is in `should_include_pack()`, which now properly considers `ctx->base_midx` as the exclusion boundary for incremental writes rather than always using `ctx->m`. This ensures packs from layers above the specified base are included in the new MIDX layer, maintaining proper reachability closure for bitmaps.
