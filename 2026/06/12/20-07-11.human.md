This is the second patch in Taylor Blau's series fixing MIDX incremental writes with custom base layers. The patch addresses a bug where the `--base` option wasn't being properly passed through to the MIDX write path, causing incorrect behavior when creating incremental MIDX layers.

The key changes are:
1. Threading the `incremental_base` parameter through the MIDX write functions
2. Updating the repack caller to pass NULL when no custom base is needed
3. Marking two test cases as expected failures (to be fixed in the next patch)

The issue manifests when using `--base=none` or `--base=<hash>` with incremental writes - the MIDX writer was skipping packs it shouldn't, breaking reachability closure needed for bitmaps. The patch cleanly separates the plumbing fix (this patch) from the behavioral fix (coming next).
