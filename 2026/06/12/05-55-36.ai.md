This is a feature patch series introducing a global `fetch.followRemoteHEAD` configuration option, building on the per-remote `remote.<name>.followRemoteHEAD` introduced in Git 2.48. The series comes from Matt Hunter and represents the implementation phase after design discussions have been finalized.

The core change adds a new `fetch.followRemoteHEAD` setting that serves as a default for all remotes when no remote-specific setting exists, following the same precedence pattern as `fetch.prune`/`remote.*.prune`. The implementation explicitly excludes support for the "warn-if-not-$branch" value at the global level since that behavior is too remote-specific to make sense as a default.

The 7-patch series includes preparatory cleanups (fixing advice messages, test cleanup, function renaming), the main implementation, and documentation updates. The changes touch the fetch machinery, remote configuration handling, and test coverage. Notably, the series maintains backward compatibility where per-remote settings take precedence over the new global default, and it doesn't affect clone operations.
