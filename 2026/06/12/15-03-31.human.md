This is a follow-up in the Git v2.55.0-rc0 release thread, where Randall S. Becker reiterates his platform compatibility concerns about Rust integration. He reports that the build fails on NonStop systems due to the missing `cargo` command (Rust's build system), which is now required by default in this release candidate.

Randall politely requests that the Rust dependency be removed for v2.55.0-rc1, noting that while his volunteer team is working on a NonStop Rust port, it won't be ready before 2027. This continues his longstanding position about Rust's platform support limitations, particularly for NonStop where he maintains the Git port.

The email highlights the tension between Git's memory safety improvements through Rust and maintaining compatibility with platforms lacking Rust toolchains. Randall's request suggests the current build system doesn't properly handle the "optional" nature of Rust components when the toolchain is unavailable. This is likely to prompt discussion about whether to modify the build system or revert Rust to opt-in status for this release.
