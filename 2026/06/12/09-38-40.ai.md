This is a UI improvement for gitk, the Git repository browser. The patch adds a horizontal scrollbar to the commit list pane, addressing a long-standing usability issue where wide commit messages could get cut off without a way to scroll horizontally.

The change comes via a merge from Rob McDonald's fork, showing this was developed externally before being integrated by Johannes Sixt (the gitk maintainer). The implementation is minimal - just 5 lines added and 2 changed in the Tcl code that powers gitk's interface.

This appears to be a straightforward quality-of-life improvement that makes gitk more usable when dealing with repositories that have long commit message subjects. The small diff size and focused scope suggest it's low-risk and unlikely to be controversial. Since it's being merged by the gitk maintainer, we can assume it's been reviewed and tested.
