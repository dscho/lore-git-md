This is a follow-up in the Git v2.55.0-rc0 release thread, specifically addressing platform compatibility concerns with the newly enabled Rust components. Randall S. Becker reiterates that the build fails on NonStop systems due to the missing `cargo` command (Rust's build tool), despite Rust being technically optional. He notes this dependency was originally planned for Git 3.0 rather than the current 2.55 release cycle.

Randall politely requests removing the Rust dependency for v2.55.0-rc1, explaining that the NonStop Rust port is a volunteer effort unlikely to be completed before 2027. This continues the ongoing tension between Git's Rustification efforts (led by Ezekiel Newren) and platform compatibility concerns (championed by Randall for NonStop systems). The email highlights a concrete build system issue where the current implementation doesn't gracefully fall back to C when Rust tooling is unavailable, despite the feature being designed as optional. This may prompt discussion about either modifying the build system to better handle missing Rust toolchains or reverting Rust to opt-in status for this release.
