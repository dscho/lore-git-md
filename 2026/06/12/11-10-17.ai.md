This is a usability improvement patch series that aims to make Git's error messages more helpful when users accidentally swap or misformat remote/branch arguments.

The two patches address common command-line mistakes:
1. `git branch --set-upstream-to=origin/main` (missing slash) will now suggest the correct `origin/main` form
2. `git push origin/main` (using slash instead of space) will suggest `origin main`

The changes add new advice messages (configurable via `advice.*`) and corresponding tests. The implementation touches the branch and push command internals, adding logic to detect these specific error patterns and provide tailored suggestions.
