This is a series of improvements to git-gui, Git's graphical interface, focusing on repository discovery and command-line handling. The changes come from three contributors, with Mark Levedahl providing the bulk of the work (11 patches).

The key improvements include:

1. More robust repository discovery using `git rev-parse` instead of custom logic, which should handle edge cases better
2. New explicit `gui` and `pick` subcommands for clearer command-line usage
3. Better handling of worktree detection, particularly for bare repositories
4. More careful argument checking for browser/blame operations
5. Silent installation when using `make -s`

The changes touch core functionality but appear to be well-contained refactorings rather than major architectural shifts. Johannes Sixt, the git-gui maintainer, has merged these changes into the master branch of his git-gui fork. The series builds on previous work to improve git-gui's reliability and follows the project's incremental improvement style.
