This thread improves Git’s error messages for two common command-line mistakes: omitting the slash in `git branch --set-upstream-to=origin main` (where the user likely meant `origin/main`) and using a slash instead of a space in `git push origin/main`. Harald Nordgren sent a two-patch series (`hn/branch-push-mistake-advise`) that adds helpful advice when these errors occur, gating the suggestions on whether the intended remote-tracking branch exists. The first patch refines its logic to avoid false positives, while the second patch ensures no performance penalty when advice is disabled.

The series is now complete and ready to merge.
