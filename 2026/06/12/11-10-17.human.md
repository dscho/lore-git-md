This is a usability improvement patch series that makes Git suggest the correct command syntax when users accidentally swap or misplace remote/branch arguments in `git branch` and `git push` commands.

The two patches address common slip-ups:
1. When setting upstream branch with `git branch --set-upstream-to=origin main` (should be `origin/main`), Git will suggest the correct form
2. When pushing with `git push origin/main` (should be `git push origin main`), Git will offer the proper syntax

The changes add new advice messages (configurable via `advice.*`) and corresponding tests. The implementation touches the branch and push command implementations plus adds tests to verify the new behavior.

This appears to be a well-scoped quality-of-life improvement that could help new users recover from common mistakes. The patch series is small (2 focused changes) and comes with thorough test coverage in both the branch and push test suites. The commit messages clearly explain the motivation and implementation approach.
