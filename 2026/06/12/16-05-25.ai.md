This is the second patch in a 3-part refactoring series that migrates the `trust_executable_bit` configuration from global scope to repository-specific storage, as part of the ongoing `the_repository` removal effort. The patch moves the `ce_mode_from_stat()` function from `read-cache.h` to `read-cache.c` to better encapsulate its dependencies and prepare for future repository-scoped configuration access.

The change relocates the implementation while preserving all existing behavior, removing redundant `extern` declarations in the process. The patch also gains improved documentation explaining the function's purpose in handling filesystem limitations (missing symlink support or unreliable executable bits). This is a mechanical change that serves as groundwork for the more substantive repository-scoping work in patch 3/3.

The series has been through multiple iterations with mentoring from Christian Couder, Ayush Chandekar, and Olamide Caleb Bello, and is now in its final form ready for merging. This particular patch was reviewed with feedback incorporated about documentation placement and content. The change touches core index handling code but is behavior-preserving, focusing specifically on preparing the configuration migration while deferring more complex cases like `has_symlinks`.
