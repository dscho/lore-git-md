This is the second patch in a 3-part refactoring series that moves the `trust_executable_bit` configuration from global scope to repository-specific storage, as part of the ongoing `the_repository` removal effort. The series is now in its final iteration and ready for merging.

Patch 2/3 relocates the `ce_mode_from_stat()` function from `read-cache.h` to `read-cache.c` to better encapsulate its dependencies, which will be needed for future repository-scoped configuration work. The change is mechanical and behavior-preserving, with no functional impact yet. The patch also adds documentation comments explaining the function's purpose in handling filesystem limitations (missing symlinks or unreliable executable bits).

The implementation removes redundant `extern` declarations that were only needed when the function was inline, and moves the documentation from the implementation to the header file where it's more visible to callers. The patch has been reviewed by multiple contributors (Christian Couder, Ayush Chandekar, and Olamide Caleb Bello) and incorporates all feedback from earlier iterations.

This is a straightforward preparatory change that paves the way for the more substantive repository-scoping work in patch 3/3. The series as a whole represents incremental but important progress in eliminating global state from Git's codebase.
