This is the second patch in Pablo Sabater's v4 series improving `git log --graph` rendering of commits with excluded parents. The patch implements cascading indentation for visual root commits to prevent misleading vertical alignment of unrelated commits.

The key technical changes include:
- A new `GRAPH_PRE_ROOT` state to connect children to indented visual roots
- `is_visual_root` flag and `visual_root_depth` counter to track hierarchy
- Cascading indentation where each subsequent visual root increases indentation
- New test file `t4218-log-graph-indentation.sh` with extensive test cases

The implementation handles several scenarios:
- Visual roots with children get connected via a new edge row
- Childless visual roots are indented directly
- Adjacent visual roots cascade their indentation
- Merge parents are exempt from indentation since they're already connected

One known edge case remains where the lookahead mechanism can't perfectly predict when a commit will become a visual root after history simplification, leading to suboptimal indentation in rare cases. This is documented with a NEEDSWORK comment.

The patch appears technically sound with thorough test coverage. It represents a significant redesign from v3 based on feedback, now indenting the visual roots themselves rather than following commits.
