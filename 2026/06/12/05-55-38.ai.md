This is a documentation patch in Matt Hunter's series implementing the global `fetch.followRemoteHEAD` configuration option. It adds documentation for the `fetchRemoteHEADWarn` advice message that appears when using the `warn-if-not-$branch` setting for `remote.<name>.followRemoteHEAD`.

The patch explains that this advice is shown when `git fetch` detects a remote's HEAD differs from the locally configured remote HEAD and the user has opted into receiving warnings about this situation. The documentation follows the existing pattern in `advice.adoc` and links to `git-fetch[1]` for context.

This is a straightforward documentation improvement that completes the feature's documentation coverage. The change is small but important for users who encounter the warning message and need to understand its purpose. The patch fits cleanly into the larger series by addressing a documentation gap that would otherwise be left by the new configuration options.
