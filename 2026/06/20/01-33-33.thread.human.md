Here’s a concise narrative summary for a developer catching up on the Git mailing list after some time away:

---

The Git 2.55 release cycle is in its final stages, with Junio’s latest "What’s cooking" report marking feature freeze—only regression fixes and review-ready topics will land before the release. The integration branches are busy with a mix of new plumbing commands, performance tweaks, and long-running refactoring efforts.

Patrick Steinhardt’s ref-backend work continues to bear fruit with the new `git refs` subcommands (`create`, `delete`, `update`, `rename`), which provide low-level plumbing for reference management. These will likely become the foundation for future changes to `git branch` and `git tag`. Steinhardt also contributed `git cat-file --batch-command remote-object-info`, letting clients fetch object metadata (currently just size) from remotes without downloading the full object—a feature gated by server capabilities and expected to spark discussion about exposing more fields like type or mtime.

The experimental `git history` command (by Hannes Nägele and Steinhardt) now supports `squash` and `drop` subcommands, reusing the sequencer machinery to fold or remove commits while replaying descendants. Meanwhile, `git log -L` (Matthias Aßhauer) gained `--stat`, `--check`, and `-G` support, limiting diff operations to the specified range to avoid unnecessary work. Other user-facing additions include `git branch --delete-merged` (with opt-out config and dry-run mode) and `git checkout --track=... --fetch`, which can now fetch the start-point when creating a tracking branch.

Under the hood, Tyler Yep’s migration of `core.ignorecase`, `core.filemode`, and `core.protectHFS/NTFS` to repository-scoped configuration continues the push to eliminate global state, while Taylor Blau fixed a reachability bug in `git multi-pack-index write --incremental --base`. Tao Klerks contributed several performance fixes, including prefix-scoped ref iteration for `git branch`/`tag` and pathspec prefiltering for `git ls-files --modified`/`--deleted`. The Windows CI pipeline also ditched Chocolatey for dependency management, addressing reliability issues.

Open questions and likely discussion points include the default behavior of `git branch --delete-merged` (should it default to `--force`?), security implications of exposing more object metadata in `remote-object-info`, and the aesthetics of `git log --graph`’s new root-commit indentation. The `diff.<driver>.process` feature (Aßhauer) may also draw attention for its potential to integrate language servers into Git’s diff machinery.
