This is a build system patch for the Meson build. It adds a `nanosec` option to Meson's build configuration, mirroring the existing `USE_NSEC` knob in the Autotools build. When enabled, this option defines the `USE_NSEC` macro, which makes Git care about sub-second file modification and change times (mtimes and ctimes).

The patch is minimal: it adds the option to `meson_options.txt` with a descriptive comment and wires it up in `meson.build` to pass `-DUSE_NSEC` to the compiler when the option is enabled. The default is `false`, matching the Autotools default. The change affects only the Meson build; Autotools is untouched.

D. Ben Knoble is the author, a contributor known for build system work (both Makefile and Meson). The patch is standalone and not part of a larger series. The commit message is clear but does not explain *why* someone might want to enable this option—only that Autotools already supports it. The diff is clean and mechanical, touching only the two build files.

This is a parity fix: it ensures Meson users have the same configurability as Autotools users. The option itself is niche (sub-second timestamps), so the patch is unlikely to be controversial, but it may prompt discussion about whether all Autotools knobs should be mirrored in Meson or whether some should be dropped. The patch is ready for review and looks like a straightforward improvement.
