This is a build system patch for the Meson build. D. Ben Knoble adds a new `nanosec` option to Meson that mirrors the existing `USE_NSEC` knob in the autotools build. When enabled, it passes `-DUSE_NSEC` to the compiler, allowing Git to care about sub-second file timestamps (mtimes and ctimes).

The change is minimal: six lines added across two files (`meson.build` and `meson_options.txt`). The commit message is clear and to the point, though it assumes the reader already knows what `USE_NSEC` does. There are no tests or documentation updates, which makes sense for a build-system-only change.

This is a straightforward, uncontroversial addition that brings feature parity between the two build systems. It looks well-crafted and ready for review.
