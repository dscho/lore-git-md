This is Junio’s biweekly "What’s cooking in git.git" report for June 2026, summarizing the state of all in-flight topics as the Git 2.55 release cycle winds down. The tree is now feature-frozen; only regression fixes and review-ready topics will graduate to `master` before the final release.

The report lists 44 topics, 10 of which have already graduated to `master` (small fixes and cleanups), 12 are cooking in `next` (stable enough to be candidates for 2.55), 19 are new and need review, and 3 are stalled. Two documentation patches (`jc/submittingpatches-design-critiques` and `wy/doc-clarify-review-replies`) update contribution guidelines to clarify how to handle design critiques and when to reroll patches. A small but practical Windows CI improvement (`ps/gitlab-ci-windows`) migrates the GitLab CI Windows builds away from the unreliable Chocolatey package manager.

Two larger efforts stand out. Patrick Steinhardt’s `ps/refs-avoid-chdir-notify-reparent` series (11 patches) overhauls the reference backends to use absolute paths internally, eliminating the need for `chdir_notify_reparent()` and fixing a memory leak in the reference database construction. Meanwhile, the experimental `git history` command gains two new subcommands: `squash` (Hannes’s 6-patch series) to fold a range of commits into one, and `drop` (Patrick’s 10-patch series) to remove a commit and replay its descendants. Both series are marked as needing review and carry “SQUASH???” markers, indicating they are still in flux.

On the performance front, Taylor Blau’s `tb/pack-path-walk-bitmap-delta-islands` (6 patches) enables reachability bitmaps and delta-islands to work together with `--path-walk`, while Toon Claes’s `tc/replay-linearize` (4 patches) adds a `--linearize` option to `git replay` that mimics `git rebase --no-rebase-merges`. Both are waiting for responses to review comments.

Finally, the report notes that Git 2.55-rc1 has been tagged, so the focus now shifts to regression hunting and polishing the topics already in `next`.
