This thread is about a small but useful build system improvement for Git’s Meson build. D. Ben Knoble—who regularly works on Git’s build infrastructure—has sent a patch that adds a `nanosec` option to Meson, matching the existing `USE_NSEC` knob in the Autotools build. When enabled, this option makes Git track sub-second file timestamps (mtimes and ctimes), which can matter in high-precision environments.

The patch itself is minimal and mechanical: it adds the option to `meson_options.txt`, wires it up in `meson.build`, and defaults it to `false` to stay in sync with Autotools. There’s no controversy here—it’s a parity fix that gives Meson users the same configurability as Autotools users. The only open question is whether this kind of mirroring is the right long-term approach, but that’s a broader discussion unlikely to block this specific change. The patch is ready for review and should be a straightforward merge once someone gives it a look.
