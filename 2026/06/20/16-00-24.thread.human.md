This thread is about a small but practical build system patch from D. Ben Knoble that adds a `nanosec` option to Git’s Meson build, mirroring the existing `USE_NSEC` knob in the Autotools build. The patch ensures that Git can track sub-second file timestamps (mtimes and ctimes) when built with Meson, just as it can with Autotools. Junio C Hamano, the maintainer, has reviewed and accepted the patch, noting only a minor concern about the discoverability of the `-Dnanosec=true` option name—but not enough to block it. The patch is now queued for merging and will likely appear in the `next` branch soon.

The change itself is minimal, touching only `meson_options.txt` and `meson.build`, and doesn’t alter runtime behavior or on-disk formats. While the commit message clearly describes *what* the patch does, it doesn’t explain *why* a user might want `USE_NSEC`—only that it exists in Autotools and should be mirrored in Meson. This omission might leave some readers curious about the feature’s purpose, though the functionality is uncontroversial. D. Ben Knoble, a frequent contributor to Git’s build system improvements, authored the patch, and it fits into the broader effort to modernize and align Git’s build systems.

With Junio’s approval, this patch is effectively a done deal. Any future discussion would likely focus on whether *all* Autotools knobs should be mirrored in Meson or if some should be deprecated, but that’s a separate question. For now, this is a straightforward, low-risk addition that ensures parity between the two build systems.
