Subject: [PATCH] meson: add `nanosec` option to mirror Autotools `USE_NSEC`
Series version: standalone patch
Originating author: D. Ben Knoble
Thread type: patch (build system parity)

Core problem or goal
Add a `nanosec` Meson build option that defines the `USE_NSEC` macro, matching the existing Autotools `USE_NSEC` knob. This enables Git to track sub-second file modification and change times (mtimes and ctimes) when the option is enabled, ensuring feature parity between the two build systems.

Current status
Patch has been reviewed and accepted by Junio C Hamano. It is queued for merging and will likely graduate to the `next` branch soon. No prior versions; Autotools side remains unchanged.

Key technical details
- Files touched: `meson_options.txt`, `meson.build`
- New Meson option: `nanosec` (boolean, default `false`)
- Macro defined: `USE_NSEC` (when `nanosec=true`)
- Subsystem: build system (Meson)
- On-disk or runtime behavior: none directly; only affects Git’s sensitivity to sub-second timestamps
- Test coverage: none added; existing Autotools tests already cover the functionality

Open questions and loose ends
- Junio noted a minor reservation about the discoverability of the `-Dnanosec=true` option name but did not consider it a blocker.
- The commit message does not explain the *purpose* of `USE_NSEC` (why a user might want it), only that it mirrors the Autotools knob.
- Future discussion might arise about whether all Autotools knobs should be mirrored in Meson or if some should be deprecated, but this patch does not itself raise that question.
