This is a build system patch that aligns gitk and git-gui with core Git's existing practice. The v2 revision drops the `--statistics` flag from `msgfmt` invocations entirely, along with gitk's "Generating catalog" echo, rather than conditionally suppressing them during `make -s` builds.

The change follows the precedent set in commit 2f12b31b746c (2021) for core Git's Makefile, where the statistics output was deemed unnecessary. The patch is minimal: it removes two lines from gitk's Makefile and one flag from git-gui's, with no conditional logic. This makes the build quieter by default while simplifying the Makefiles.

Both gitk (maintained by Johannes Sixt) and git-gui (maintained by Johannes Schindelin) are affected. The v2 revision directly addresses Sixt's review feedback from the v1 thread, which suggested outright removal rather than conditional suppression. The change is uncontroversial and appears ready for maintainer review.

This is a clean, focused improvement that eliminates unnecessary build output without changing functionality. The commit message clearly explains the motivation and the connection to existing Git practice.
