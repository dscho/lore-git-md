Core problem or goal
Replace `tmp_objdir` usage in `git-receive-pack` with the `odb_transaction` subsystem to advance ODB-backend agnosticism. The series stages incoming objects via transactions (replacing temporary object directories) while preserving existing object-write behavior (via `git-index-pack`/`git-unpack-objects` and the "files" backend). **All blocking feedback from v1 is addressed**; follow-up work (error-handling improvements, lazy directory creation, explicit abort interface, detangling object-write paths, **redundant validation removal, surfacing previously ignored errors, propagating backend errors to callers, environment-variable plumbing for child processes, and flag-based behavioral preservation for `receive-pack`**) is explicitly deferred to maintain focus.

Error handling is consistent with the rest of the series: failures during transaction begin or commit are surfaced as command errors.
Retains all prior v2 changes (patches 1–2/11: naming consistency; error-handling semantics, file-local global, deferred improvements).
