Core problem or goal
Replace `tmp_objdir` usage in `git-receive-pack` with the `odb_transaction` subsystem to advance ODB-backend agnosticism. The series stages incoming objects via transactions (replacing temporary object directories) while preserving existing object-write behavior (via `git-index-pack`/`git-unpack-objects` and the "files" backend). **All blocking feedback from v1 is addressed**; follow-up work (error-handling improvements, lazy directory creation, explicit abort interface, detangling object-write paths, **redundant validation removal**) is explicitly deferred to maintain focus.
