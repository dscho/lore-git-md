Core problem or goal
Replace `tmp_objdir` usage in `git-receive-pack` with the `odb_transaction` subsystem to advance ODB-backend agnosticism. The series stages incoming objects via transactions (replacing temporary object directories) while preserving existing object-write behavior (via `git-index-pack`/`git-unpack-objects` and the "files" backend). A follow-up series is planned to make object writes themselves backend-agnostic.

Open questions and loose ends
- **Patch 1/6**:
  - Naming consistency: **resolved in v2** by renaming `flush_loose_object_transaction()` to `odb_transaction_files_flush()` for consistency with `odb_transaction_files_prepare()`.
- **Patch 2/6**:
  - **Error-handling design tension**: the patch surfaces previously ignored errors in temporary directory creation, migration, and commit, but callers ignore them, preserving backward compatibility. This resolves the tension in favor of backward compatibility, but the latent error-handling gap remains: callers of `odb_transaction_files_prepare()` (e.g., `write_loose_object()`, `odb_source_loose_write_stream()`) are not updated to handle its new error returns. Not a regression, but a robustness concern for future work.
  - **Abort semantics**: **clarified**: transaction abort is currently **implicit**, handled by `tmp_objdir.c:remove_tmp_objdir()` via an `atexit()` handler. This is tied to the global `tmp_objdir` constraint, which blocks multiple transactions and complicates cleanup. A future series will introduce an explicit `odb_transaction_abort()` interface, which may be adopted here for clarity. **Design-level question** remains whether to use it in this patch or defer to the follow-up series.
  - **Code organization**: why the "files" transaction functions remain in `object-file.c` instead of `odb/source-files.c` (due to entangled object-write paths; follow-up series planned to clean this up).
  - ODB transaction system’s single-transaction-per-ODB limitation, inconsistent with reference transactions’ multi-transaction design (noted for future work).
- **Patch 3/6**:
