This is the first patch in Justin Tobler’s six-part series refactoring `git-receive-pack` to use ODB transactions instead of `tmp_objdir`. It performs a purely mechanical rename: the function `prepare_loose_object_transaction()` in `object-file.c` becomes `odb_transaction_files_prepare()`, aligning the name with the fact that the same temporary directory will soon be used for packfiles as well. The change is confined to a single file, with three call sites updated. No behavior changes; this is pure refactoring to set the stage for the rest of the series. The patch is small, well-scoped, and uncontroversial.
