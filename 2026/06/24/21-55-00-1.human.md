This is the first patch in Harald Nordgren’s **v18 `git branch --delete-merged` series**, which is now implementation-complete and ready for final review. This patch adds the `--forked` filter to `git branch --list`, allowing users to list only branches whose upstream matches a given pattern (e.g., `origin/main`, `origin/*`, or a remote name like `origin`).

The `--forked` filter is a foundational building block for the series’ core feature: `--delete-merged`, which will use this filter to identify branches whose work has been merged into their upstream and can safely be deleted. The filter supports exact refnames, remote shorthand (e.g., `origin` for `origin/HEAD`), and shell-style globs, and can be combined with existing filters like `--merged` or `--no-merged`. For example, `git branch --merged origin/main --forked 'origin/*'` lists branches forked from `origin` that are already merged into `origin/main`.
