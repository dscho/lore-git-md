This is the first patch in Patrick Steinhardt’s v2 series refactoring Git’s connectivity checks to support ODB abstraction. It is a preparatory refactoring that extracts pack-exclusion logic into a new helper function, `should_exclude_pack()`, without changing behavior.

The patch moves the existing conditional logic that skips packs based on caller flags (e.g., `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`, `ODB_FOR_EACH_OBJECT_LOCAL_ONLY`) from the main iteration loop into a dedicated function. This is a straightforward code motion: the logic is unchanged, but now lives in a reusable helper. The motivation is to prepare for the next patch, which will lift the restriction that prevents `odb_for_each_object()` from accepting flags when an object prefix is specified.
