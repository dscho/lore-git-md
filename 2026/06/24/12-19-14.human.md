This is the first patch in Patrick Steinhardt’s six-part series refactoring `struct object_info` to replace the `whence` field with a richer `source` field. The patch threads an optional `struct odb_source_packed *source` parameter through the `packed_object_info()` and `packed_object_info_with_index_pos()` functions. For now the parameter is unused; it will be populated in a later patch so callers can record which specific packfile (or other backend) an object came from.

The change is mechanical: every caller outside the packed ODB backend passes `NULL`, while the backend itself passes its own `source` pointer. Eight files are touched (`builtin/cat-file.c`, `builtin/pack-objects.c`, `commit-graph.c`, `odb/source-packed.c`, `pack-bitmap.c`, `packfile.c`, `packfile.h`, and `t/helper/test-bitmap.c`), but the diff is small—only 17 insertions and 13 deletions. No behavior changes; this is pure plumbing for the follow-up patches. If you care about the ODB abstraction effort, this is the foundational step that enables multi-source object resolution.
