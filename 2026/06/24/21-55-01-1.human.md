This is the second patch in Harald Nordgren’s seven-part `git branch --delete-merged` series, now in its eighteenth iteration and ready for merging. The series as a whole adds a safe, automated local-branch cleanup command with comprehensive filtering and safety controls.

This specific patch refactors the internal `delete_branches()` API to use a single `unsigned int flags` argument instead of two separate boolean parameters (`force` and `quiet`). The change is purely mechanical: the function’s behavior is unchanged, but the new flags-based interface will make it easier to add more options in later patches (such as `DELETE_BRANCH_SKIP_UNMERGED` and `DELETE_BRANCH_DRY_RUN`). The patch introduces an enum for the flag bits and splits them back into local boolean variables so the rest of the function reads the same as before.

The refactoring is clean and well-motivated; it’s a necessary plumbing step for the rest of the series. No review issues remain, and the patch is stable across the last several iterations. If you’re following the series, this is a straightforward infrastructure change that sets the stage for the more interesting logic in patches 5 and 7.
