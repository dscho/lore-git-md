This is the second patch in Harald Nordgren’s v15 series introducing `--track=fetch` for `` `git checkout` `` and `` `git switch` ``. The patch implements the user-facing feature: when `--track=fetch` is specified, Git automatically fetches the remote branch before creating the local tracking branch, ensuring the new branch starts from the latest remote tip rather than a potentially stale local copy.

The implementation extends the `--track` option to accept a comma-separated list of modes (`direct`, `inherit`, `fetch`), with `fetch` triggering the automatic fetch. The code handles bare remote names (e.g., `origin`) by following `refs/remotes/<remote>/HEAD`, respects configured fetch refspecs, and gracefully falls back to the existing remote-tracking ref if the fetch fails. The patch updates both `git-checkout` and `git-switch` documentation, and the test suite thoroughly covers edge cases: offline fallback, ambiguous refspecs, namespace resolution, quiet mode, and invalid input rejection. The v15 changes address all of Phillip Wood’s requested code nits—dropping `RESOLVE_REF_NO_RECURSE`, removing redundant refname checks, switching to brace initialization, and streamlining the test suite—without altering the core design.
