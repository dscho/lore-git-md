This is the second patch in Harald Nordgren’s seven-patch v18 series implementing `git branch --delete-merged`. The series is now implementation-complete and ready for merging, with all design questions resolved, including the refined stacked-branch protection mechanism.

This patch refactors `delete_branches()` and its helper `check_branch_commit()` to replace two boolean arguments (`force` and `quiet`) with a single `unsigned int flags` parameter and an enum (`DELETE_BRANCH_FORCE`, `DELETE_BRANCH_QUIET`). The change is purely mechanical: the function bodies split the flags back into the same named boolean locals they used before, so behavior is unchanged. The motivation is to prepare the API for additional flags (such as `DELETE_BRANCH_SKIP_UNMERGED`, `DELETE_BRANCH_NO_HEAD_FALLBACK`, and `DELETE_BRANCH_DRY_RUN`) that will be introduced in later patches.

The patch touches only `builtin/branch.c`, converting the function signatures and adding the enum definition. The call site in `cmd_branch()` is updated to pass the flags as a bitmask. The refactoring is clean and well-contained, with no functional changes. It is a necessary preparatory step for the core `--delete-merged` logic that follows in patch 5/7.
