This is an **announcement** for the second release candidate of Git for Windows 2.55.0. Git for Windows is the Windows-specific distribution of Git, maintained by Johannes Schindelin, and this release tracks the upstream Git 2.55.0-rc2 release.

The announcement highlights several key changes since the last stable release (v2.54.0). Notably, **Windows 8.1 support will be dropped after this release**, following the MSYS2 project’s decision. The release bundles updated dependencies, including Git Credential Manager v2.8.0, cURL v8.20.0, OpenSSL v3.5.7, and Bash v5.3.15. Performance improvements are also included, such as expanded FSCache acceleration for `git add` scenarios and a Rust port of the diff helper for Word documents (previously Perl-based).

Several bugs are fixed, including a regression in v2.54.0 that caused infinite unlink loops during `git fetch` on older Windows 10 versions, parallel checkout failures with FSCache enabled, and process shutdown issues in Git Bash. The release also tightens `.git` file validation, requiring explicit `safe.directory` configuration for UNC path access to remote repositories. This aligns with changes in TortoiseGit v2.19.

The announcement includes download links for multiple variants (64-bit, ARM64, 32-bit, portable, and MinGit) along with SHA-256 checksums for verification. This is a routine pre-release update, but the Windows 8.1 deprecation and tightened UNC path handling may be of particular interest to users and packagers.
