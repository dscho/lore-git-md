This is the fourth patch in Patrick Steinhardt’s six-part series refactoring Git’s `struct object_info` to replace the `whence` field with a more detailed `source` field. The series is part of the ongoing ODB (object database) abstraction effort, which aims to make Git’s object storage layer pluggable.

This patch mechanically converts all remaining callers of the old `whence` field to use the new `source` field instead. The changes are straightforward: each instance of `oi->whence` is replaced with a check on `oi->sourcep->source->type`, and the surrounding logic remains unchanged. The four files modified—`builtin/cat-file.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, and `reachable.c`—are all downstream consumers of object lookup results, so the patch is essentially a drop-in replacement.

The commit message is concise but clear: `whence` is now redundant because the `source` field provides the same information (and more) in a structured way. All callers already set up the `sourcep` pointer, so the conversion is purely syntactic. No behavior changes are introduced; this is a pure refactoring step that paves the way for the next patch, which removes `whence` entirely.

The patch looks well-crafted: the diff is minimal, the rationale is sound, and the changes align with the series’ goal of making object provenance information opt-in and more precise. If you’re following the ODB abstraction work, this is a routine but necessary step in the progression.
