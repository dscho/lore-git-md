Provide a Windows-specific distribution of Git v2.55.0-rc2, updating bundled components and fixing Windows-specific bugs. This is not a patch to upstream Git but a downstream release that tracks upstream Git v2.55.0-rc2.

Current status
Released as Git for Windows 2.55.0-rc2. No upstream Git changes; purely a packaging and platform-specific update.

Key technical details
- Bundled components updated: MSYS2 runtime (Cygwin v3.6.9), Git Credential Manager v2.8.0, cURL v8.20.0, less v702, OpenSSL v3.5.7, Bash v5.3.15.
- Windows-specific changes:
  - Dropped support for Windows 8.1 after this version.
  - Tightened `.git` file validation (following TortoiseGit v2.19).
  - Fixed platform-specific bugs: endless unlink loop during `git fetch` on older Windows 10, process shutdown issues in Git Bash, parallel checkout failures with FSCache enabled, display scaling problems in MinTTY.
  - FSCache subsystem gains broader acceleration for `git add`.
  - UNC path access to remote repositories now requires explicit `safe.directory` configuration.
- Tooling Rustification: diff helper for Word documents ported from Perl to Rust.
- Installer variants: 64-bit, ARM64, 32-bit, portable, MinGit, BusyBox.
