This is the sixth patch in Harald Nordgren’s **v18 `git branch --delete-merged` series**, which is now implementation-complete and ready for merging. This patch adds a **per-branch opt-out mechanism** via the `branch.<name>.deleteMerged` config key, allowing users to exempt specific branches from automated cleanup while still permitting explicit deletion via `git branch -d`.

The patch introduces a new configuration option, `branch.<name>.deleteMerged`, which defaults to `true`. When set to `false`, the branch is skipped by `git branch --delete-merged`, and a non-quiet message explains the skip. The opt-out is ignored by traditional `git branch -d`, which continues to use the normal merge check. This addresses iterative topic-branch workflows where an early round of a branch has been merged upstream, but the branch itself remains active for further development.

The implementation is straightforward: during candidate filtering in `delete_merged_branches()`, the code checks for the config key and skips the branch if it is set to `false`. The patch includes documentation updates for `branch.adoc` and `git-branch.adoc`, as well as tests verifying both the opt-out behavior and the continued ability to delete the branch explicitly. The tests cover the non-quiet skip message and confirm that `git branch -d` bypasses the opt-out.

This patch is **well-motivated** and **thoroughly tested**, fitting cleanly into the series’ broader goal of safe, automated branch cleanup. The opt-out mechanism complements the existing safety checks (checked-out branches, missing upstreams, push divergence, and stacked-branch protection) without complicating the core logic. The implementation is minimal and non-intrusive, touching only the candidate-filtering loop in `builtin/branch.c` and adding the necessary documentation and tests.

Key technical details:
- **Config key**: `branch.<name>.deleteMerged` (boolean, defaults to `true`).
- **Behavior**: Skips the branch in `--delete-merged` if set to `false`; ignored by `git branch -d`.
- **Output**: Non-quiet mode prints a skip message (e.g., "Skipping 'kept' (branch.kept.deleteMerged is false)").
- **Tests**: Verify opt-out behavior, skip messages, and explicit deletion via `git branch -d`.
- **Files touched**: `Documentation/config/branch.adoc`, `Documentation/git-branch.adoc`, `builtin/branch.c`, and `t/t3200-branch.sh`.
