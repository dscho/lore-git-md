This is a surface-level review from Junio C Hamano on the second patch of Harald Nordgren’s v2 usability series. The patch improves error messages for the common mistake of writing `` `git push origin/main` `` (slash instead of space), suggesting the correct `` `git push origin main` `` syntax.

Junio points out a mechanical issue in the test script: the patch uses plain `grep` commands instead of the Git test suite’s preferred `test_grep` helper. This is a minor style nit—`test_grep` is the project’s convention for grepping output in tests, and the patch should follow it. The error messages from the test linter clearly flag all six instances where `grep` appears outside a pipeline.

The review is purely about test style and does not engage with the patch’s substance. The implementation itself—adding a new advice key, a helper function that avoids performance penalties when advice is disabled, and thorough test coverage—remains technically sound and uncontroversial. The patch is well-motivated and addresses a real usability pain point, but this round of feedback is limited to test-script hygiene. Once the `grep`→`test_grep` changes are made, the patch should be ready for broader review.
