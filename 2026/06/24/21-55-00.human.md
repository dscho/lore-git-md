This is the second patch in Harald Nordgren’s four-part series introducing the new `` `git history squash` `` subcommand. The series is now code-complete and ready for Junio’s final assessment.

This patch adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, it is used instead of the commit’s original message; when NULL, the original behavior is preserved. The change is a small but necessary refactoring that enables the final patch to construct a squash commit message from all folded-in commits. The existing fixup and split callers continue to pass NULL, so their behavior is unchanged. The diff is clean, the commit message is clear, and the patch fits neatly into the larger effort.
