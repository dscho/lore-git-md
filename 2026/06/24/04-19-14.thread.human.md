This thread is a patch series from Justin Tobler refactoring `git-receive-pack` to use ODB transactions instead of `tmp_objdir`, advancing Git's object database abstraction. The v2 series, now at 11 patches, has addressed all feedback from v1, with follow-up work like error-handling improvements and lazy directory creation explicitly deferred to keep the current effort focused.

The latest patch (9/11) introduces `enum odb_transaction_flags` and the `ODB_TRANSACTION_RECEIVE` flag to preserve `receive-pack`'s existing behavior during the transition. This is a mechanical change—adding plumbing for flags without altering behavior—preparing for the actual conversion in the next patch. The series has no objections to its goals or approach and is queued for Junio's `next` branch pending integration.

Key changes so far include inlining redundant helpers, removing duplicate validation, propagating previously ignored errors, and adding environment-variable plumbing for child processes. The architectural limitation of one transaction per ODB remains, but the series is otherwise non-regressive. The next patches will complete the `receive-pack` conversion and finalize error-handling semantics.
