This thread is Justin Tobler’s six-patch series refactoring `git-receive-pack` to use ODB transactions instead of the older `tmp_objdir` mechanism, moving the command toward backend-agnostic object storage. The first three patches—mechanical renames and error propagation in the transaction infrastructure—have been posted without review yet. The fourth patch, just arrived, fixes a silent failure in `odb_transaction_commit()`: it now propagates backend commit errors (e.g., when migrating a temporary object directory fails) instead of ignoring them. This is a small, uncontroversial change that prepares for patch 5, where `receive-pack` will handle push failures more gracefully.

The series is part of Patrick Steinhardt’s broader ODB abstraction effort, with a follow-up planned to make object writes themselves backend-agnostic. So far, the patches are infrastructure-only, touching the transaction layer and its callers (`add`, `unpack-objects`, `update-index`, etc.) without changing user-facing behavior. No substantive reviews have landed yet, but the changes are low-risk plumbing fixes that surface previously ignored errors. The next two patches will complete the `receive-pack` conversion.
