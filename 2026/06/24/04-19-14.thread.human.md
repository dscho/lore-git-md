This thread is about Justin Tobler’s six-patch series converting `git-receive-pack` to use ODB transactions instead of `tmp_objdir`, a key step in Patrick Steinhardt’s broader effort to make Git’s object database backend-agnostic. The series has been fully reviewed and is now queued for the `next` branch pending a v2 update.

The core change replaces temporary object directories with ODB transactions, preserving existing behavior while surfacing previously ignored errors and preparing for future backend-agnostic object writes. Patches 1–5 refactor the ODB transaction layer, while patch 6 applies the changes to `receive-pack`, introducing the `ODB_TRANSACTION_RECEIVE` flag to maintain its eager directory creation and naming conventions. Both Patrick Steinhardt and Junio C Hamano provided feedback, with Patrick’s review identifying blocking issues in error handling, interface design, and documentation. Junio integrated the series via an evil merge to resolve conflicts with other in-flight ODB and ref backend work.

Justin has now responded to Patrick’s review of patch 6, agreeing to split the patch, document the flag’s purpose, reword user-facing error messages, and investigate whether lazy directory creation is needed. The v2 will also address naming consistency, transaction-begin semantics, and the `env` callback redesign. The series is uncontroversial and aligns with the project’s ODB abstraction goals, though follow-up work remains to make object writes fully backend-agnostic and introduce an explicit transaction abort interface.
