This is the fourth patch in Patrick Steinhardt’s six-part series refactoring `struct object_info` to replace the `whence` field with a new `source` field. The patch mechanically converts all remaining callers of `oi->whence` to use the new `oi->sourcep->source->type` instead, completing the transition begun in earlier patches.

The changes touch four files: `builtin/cat-file.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, and `reachable.c`. Each conversion is straightforward—replacing `whence == OI_PACKED` with `sourcep->source->type == ODB_SOURCE_PACKED`—and preserves the existing logic. The patch assumes all callers already set up the `sourcep` pointer (as established in patch 2/6), so no additional plumbing is needed.

This is a pure refactoring step with no behavior change; the series’ functional payoff comes in later patches. The patch is clean, well-scoped, and directly advances the ODB abstraction effort.
