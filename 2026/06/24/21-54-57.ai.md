This is the first patch in Harald Nordgren’s v15 `--track=fetch` series, a refactoring that exposes two helpers from `branch.c` so the upcoming feature patch can reuse them. The patch moves `struct tracking` into `branch.h` and adds `find_tracking_remote_for_ref()` and `advise_ambiguous_fetch_refspec()`, both of which are already used internally by `setup_tracking()`. No behavior changes are introduced; the goal is purely to make the existing logic available to other callers.

The implementation is straightforward: the `for_each_remote` loop that was previously inlined in `setup_tracking()` is now wrapped in `find_tracking_remote_for_ref()`, and the advice message for ambiguous refspecs is extracted into `advise_ambiguous_fetch_refspec()`. The patch also cleans up the header by replacing `#include "string-list.h"` with a forward declaration (`struct string_list;`) and adds the necessary `#include "refspec.h"` for `struct refspec_item`. These changes were requested in Phillip Wood’s v14 review and are now fully addressed.

This patch is uncontroversial and has Junio’s technical approval from earlier iterations. It is a prerequisite for the second patch, which implements the `--track=fetch` feature itself. The refactoring is well-motivated—it avoids code duplication and keeps the tracking logic centralized in `branch.c`—and the changes are mechanical and thoroughly tested. No substantive objections remain, and the patch is ready for merging once the maintainer decides whether the feature as a whole should proceed.
