This is the first patch in Patrick Steinhardt’s six-patch series refactoring `struct object_info` to use a `source` field, part of the ongoing ODB abstraction effort. It threads an optional `struct odb_source_packed *source` parameter through `packed_object_info()` and `packed_object_info_with_index_pos()`, preparing the ground for later commits that will populate and use this field to uniquely identify an object’s source.

The patch touches eight files: `builtin/cat-file.c`, `builtin/pack-objects.c`, `commit-graph.c`, `odb/source-packed.c`, `pack-bitmap.c`, `packfile.c`, `packfile.h`, and `t/helper/test-bitmap.c`. All callers outside `odb/source-packed.c` pass `NULL` for the new parameter, which is intentional—only the packed store will use it initially. The changes are mechanical: function signatures are updated, and existing calls are adjusted to match. No behavior changes occur in this patch; it is purely preparatory.

This is a clean, well-scoped step in a larger refactoring. The commit message clearly explains the purpose and the follow-up work, and the patch itself is minimal and focused. If the ODB abstraction effort is on your radar, this patch is worth noting as the foundation for the rest of the series. No review feedback has appeared yet, so the series is still in its first iteration.
