This is a brief maintenance note from Junio C Hamano about the integration of Justin Tobler’s six-patch series that replaces `tmp_objdir` usage in `git receive-pack` with ODB transactions. The series itself has already received thorough review and is on track for a v2 to address feedback, but Junio reports that merging it into `next` required an "evil merge" to resolve conflicts with two other in-flight topics: Patrick Steinhardt’s `ps/odb-source-packed` and `ps/refs-avoid-chdir-notify-reparent`.

The merge fix is small—just two hunks—but notable because it touches the packed ODB backend and a unit test for reftable. The packed backend now correctly rejects transactions (a behavior the series enforces), and the reftable test needed a hash-algorithm parameter added to match an API change elsewhere. Neither change alters the substance of Justin’s patches, but they show how tightly this ODB refactoring interacts with other ongoing work. If you are tracking the ODB abstraction effort, this is a routine heads-up that the series is now cooking in `next` and will need a reroll soon.
