This is an **announcement** for **Git for Windows 2.55.0-rc2**, the second release candidate of the Windows-specific distribution of Git. It is not a patch to the Git project itself, but a downstream packaging effort maintained by Johannes Schindelin.

The release tracks upstream Git v2.55.0-rc2 and updates several bundled components: the MSYS2 runtime (now based on Cygwin v3.6.9), Git Credential Manager v2.8.0, cURL v8.20.0, less v702, OpenSSL v3.5.7, and Bash v5.3.15. A notable change is the porting of the diff helper for Word documents from Perl to Rust, reflecting the ongoing Rustification trend in tooling.

On the Windows-specific front, the release drops support for Windows 8.1 after this version, tightens `.git` file validation (following TortoiseGit v2.19), and fixes several platform-specific bugs: an endless unlink loop during `git fetch` on older Windows 10 versions, process shutdown issues in Git Bash, parallel checkout failures with FSCache enabled, and display scaling problems in MinTTY. The FSCache subsystem also gains broader acceleration for `git add` scenarios. UNC path access to remote repositories now requires explicit `safe.directory` configuration.

The announcement includes SHA-256 checksums for all installer variants (64-bit, ARM64, 32-bit, portable, MinGit, and BusyBox flavors) and links to the GitHub release page. No upstream Git changes are introduced; this is purely a packaging and platform-specific update.
