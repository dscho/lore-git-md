This is an announcement for **Git for Windows 2.55.0-rc2**, the second release candidate of the Windows-specific distribution of Git. The release aligns with upstream Git v2.55.0-rc2 and updates several bundled components, including the MSYS2 runtime, Git Credential Manager, cURL, and OpenSSL. A notable change is the porting of the diff helper for Word documents from Perl to Rust, reflecting broader Rust adoption in tooling.

On the Windows front, this release drops support for Windows 8.1 after this version and tightens `.git` file validation to address issues seen with TortoiseGit v2.19. Several platform-specific bugs are fixed, including an endless unlink loop during `git fetch` on older Windows 10 versions, process shutdown issues in Git Bash, parallel checkout failures with FSCache enabled, and display scaling problems in MinTTY. The FSCache subsystem now accelerates more `git add` scenarios, and UNC path access to remote repositories requires explicit `safe.directory` configuration. The announcement includes checksums for all installer variants and links to the GitHub release page. This is purely a downstream packaging update and does not introduce any changes to upstream Git.
