This is the first patch in a finalized two-patch series targeting build system quietness in gitk. It aligns gitk's translation catalog generation with core Git's `make -s` conventions by removing the `--statistics` flag from `msgfmt` invocations (matching commit 2f12b31b746c in core Git) and conditionally suppressing "Generating catalog" messages during silent builds.

The patch modifies `gitk-git/Makefile` to introduce a new `QUIET_MSGFMT` helper that is only defined when neither `V` nor `s` is in `MAKEFLAGS`. This ensures both the "MSGFMT" and "GEN" lines are suppressed during `make -s` builds. The change is minimal—only four lines added and two removed—and touches no functionality beyond build output verbosity.

This patch is procedurally ready for review by Johannes Sixt (gitk's maintainer). The implementation follows the maintainers' guidance from earlier rounds and matches the pattern already established in git-gui and core Git.
