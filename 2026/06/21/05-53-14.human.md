This patch implements the core `squash` subcommand, which folds a commit range (`<base>..<tip>`) into its oldest commit while preserving descendant history. The command performs a single three-way merge of the entire range against the oldest commit’s parent, then replays any descendants on top of the result. The range must have a single base (rejecting ambiguous ancestry), and merge commits inside the range are handled naturally. By default, the command refuses to proceed if any ref (branch, tag, or other) points into the squashed range, with an advice message suggesting `--update-refs=head` to explicitly retarget only the current branch.
