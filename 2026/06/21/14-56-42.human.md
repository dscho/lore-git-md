This is the first patch in a two-part series that makes `make -s` builds fully silent in gitk by aligning its translation catalog generation with the quiet build conventions already established in core Git and git-gui. The patch removes the `--statistics` flag from `msgfmt` invocations (matching core Git's precedent) and adds conditional suppression of "Generating catalog" messages when `make -s` is specified.

The change is minimal and targeted: it modifies only the `gitk-git/Makefile`, adding a new `QUIET_MSGFMT` helper that is defined only when neither `V` nor `s` is in `MAKEFLAGS`. This ensures that both the "MSGFMT" and "GEN" build output lines are suppressed during silent builds. The patch follows the exact pattern requested by Johannes Sixt (gitk's maintainer) in earlier review rounds and is procedurally ready for his final review.

This is a build system housekeeping patch with no functional impact on gitk itself. The motivation is consistency: core Git and git-gui already suppress this output during `make -s`, and gitk should behave the same way.
