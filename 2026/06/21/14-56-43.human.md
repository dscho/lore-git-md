This is the second patch in a two-patch series that completes the effort to silence translation catalog output during `make -s` builds in Git's companion tools. This patch targets `git-gui`, simplifying its build system to match the quiet build conventions already established in core Git and now adopted by `gitk` in the first patch.

The change removes the `--statistics` flag from `msgfmt` invocations in `git-gui/Makefile`, eliminating verbose output that previously survived silent builds. It also streamlines the `QUIET_MSGFMT` rule by replacing the redundant `QUIET_MSGFMT0`/`QUIET_MSGFMT1` pair with a single quiet prefix, since there is no longer any output to format or suppress beyond the command itself. The result is a minimal, consistent quiet build pattern across all three repositories (core Git, `gitk`, and `git-gui`).

The patch is narrow and well-motivated, touching only the build system without affecting functionality. It follows the precedent set by core Git in commit 2f12b31b746c and aligns with maintainer Johannes Schindelin's guidance. The series is now procedurally ready for merging, with this patch awaiting final review from the `git-gui` maintainer. No technical objections remain, and the implementation is clean and uncontroversial.
