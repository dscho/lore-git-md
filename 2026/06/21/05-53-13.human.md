This is the second patch in Harald Nordgren’s four-part `git history squash` series, now in its fourth iteration. The patch extends `commit_tree_ext()`—a helper used by the history subsystem—with an optional `message_template` parameter. When provided, this template seeds the commit message editor instead of the original commit’s message, enabling the caller to construct a composite message from multiple commits.

The change is small (10 insertions, 6 deletions) and mechanical: the new parameter defaults to `NULL`, preserving existing behavior for the `fixup` and `split` callers. The only logic addition is a fallback to the original commit’s body when `message_template` is `NULL`. This refactoring is a prerequisite for the next patch, which will use the template to build a squashed commit message from all folded-in commits.

The patch is clearly motivated by the series’ goal and touches only the plumbing layer, so it should not be controversial. It is well-tested indirectly through the squash functionality in later patches.
