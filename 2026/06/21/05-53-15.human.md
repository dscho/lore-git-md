This is the final patch in Harald Nordgren’s four-part series introducing the new `` `git history squash` `` subcommand. The series is now code-complete and ready for Junio’s final assessment.

This patch implements the ``--reedit-message`` option, which lets users combine the messages of every commit in the squashed range into a single editor buffer. The messages are presented oldest-first, mirroring the familiar `` `git rebase -i` `` squash workflow. The implementation gathers the messages before the descendant walk so that the walk’s flags do not disturb the template. Tests verify that all folded-in messages appear in the buffer and that an empty message aborts the operation.

The change is small and focused: 61 lines added to ``builtin/history.c``, 37 lines of new tests in ``t/t3455-history-squash.sh``, and a minor documentation tweak to clarify the behavior. The patch directly addresses the last piece of user-facing functionality that was missing from earlier iterations, completing the feature as designed.
