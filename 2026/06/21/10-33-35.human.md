This is a build system patch for `git-gui`, part of the ongoing effort to clean up quiet (`make -s`) build output. Johannes Sixt, the `gitk` maintainer, follows up on Harald Nordgren’s v2 patch by further simplifying the `git-gui` Makefile now that the `--statistics` flag and "Generating catalog" echo have been removed.

The change is minimal: it replaces the two-line `QUIET_MSGFMT0`/`QUIET_MSGFMT1` rule (which captured and reformatted `msgfmt` output) with a single-line `QUIET_MSGFMT` that just prints the target filename. This matches the style of other quiet rules in the Makefile and aligns with the precedent set by core Git’s 2021 commit. The diff is three lines, all in the Makefile, and the commit message clearly explains the motivation.

This patch is ready to merge once Johannes Schindelin (the `git-gui` maintainer) reviews or acks it. The simplification is uncontroversial and consistent with the rest of the build system.
