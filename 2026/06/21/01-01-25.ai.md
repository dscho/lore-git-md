This is a build system patch, specifically a small but useful parity fix for the Meson build. Junio C Hamano (the maintainer) has reviewed and accepted the patch, noting that it mirrors the existing `USE_NSEC` knob from the Autotools/Makefile build. The only minor reservation he expresses is whether the Meson option name `-Dnanosec=true` is intuitive or discoverable, but he does not consider this a blocker and has queued the patch for merging.

The patch adds a `nanosec` boolean option to Meson’s build configuration, defaulting to `false`. When enabled, it defines the `USE_NSEC` macro, allowing Git to track sub-second file modification and change times (mtimes and ctimes). This matches the behavior already available in the Autotools build. The change is minimal, touching only `meson_options.txt` and `meson.build`, and does not alter runtime behavior or on-disk formats.

D. Ben Knoble, the author, is a known contributor to Git’s build system improvements, and this patch continues that work. The commit message is clear but does not explain the *purpose* of `USE_NSEC`—only that it exists in Autotools and should be mirrored in Meson. This omission might leave some readers wondering why someone would want this feature, though the functionality itself is uncontroversial.

The patch is now in Junio’s queue and will likely graduate to the `next` branch soon. It is a straightforward, low-risk addition that ensures feature parity between the two build systems. Future discussion, if any, might focus on whether *all* Autotools knobs should be mirrored in Meson or if some should be deprecated, but this patch does not itself raise that question. For now, it is a done deal.
