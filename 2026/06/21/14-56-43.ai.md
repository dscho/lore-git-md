This is the second patch in a finalized two-patch series targeting build system quietness in `git-gui`. It removes the `--statistics` flag from `msgfmt` invocations and simplifies the `QUIET_MSGFMT` rule to match the pattern already established in core Git (commit 2f12b31b746c) and now adopted in `gitk` by the first patch.

The change touches only `git-gui/Makefile`, replacing the existing `QUIET_MSGFMT0`/`QUIET_MSGFMT1` pair with a single `QUIET_MSGFMT` helper that suppresses the "MSGFMT" line during `make -s` builds. The patch is minimal: two lines added, three removed, with no functional impact beyond silencing the statistics output that previously escaped the `-s` flag. Johannes Schindelin, the `git-gui` maintainer, has effectively signed off on this approach in earlier discussion.

This patch completes the series’ goal of fully aligning `git-gui` and `gitk` with core Git’s quiet build conventions. The implementation is consistent with maintainer guidance and precedents, and the series is now procedurally ready for final review. No new symbols or behavior changes are introduced; the only observable difference is the absence of statistics output during silent builds. The patch carries Harald Nordgren’s sign-off and awaits Johannes Schindelin’s formal review.
