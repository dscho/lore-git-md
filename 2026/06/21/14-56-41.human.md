This is a build system patch series that completes the effort to silence translation catalog output during `make -s` builds in gitk and git-gui. The v3 revision splits the changes into two focused commits—one for each repository—following review feedback to keep modifications distinct.

The series now fully aligns both tools with core Git's quiet build conventions. For gitk, it adds conditional suppression of "Generating catalog" messages and `msgfmt` output when `make -s` is used, while for git-gui, it simplifies the existing quiet helper logic by removing redundant variables after dropping `--statistics`. The changes are mechanical and well-motivated, mirroring the 2021 precedent in core Git (commit 2f12b31b746c).

Johannes Sixt (gitk maintainer) and Johannes Schindelin (git-gui maintainer) have both been involved in the review process, with no technical objections remaining. The split into separate commits makes it easier for each maintainer to review their respective portion. This series is effectively ready for integration once the maintainers sign off, as it addresses all prior feedback and maintains consistency across the three repositories.
