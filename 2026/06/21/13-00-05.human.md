This is a build system patch targeting the gitk and git-gui subprojects. Johannes Sixt, the gitk maintainer, reviews Harald Nordgren’s v2 patch that removes `--statistics` output from `msgfmt` invocations to align with core Git’s precedent. Sixt notes that while the patch removes the statistics output, it does not yet fully silence the build when `make -s` is used, as it omits the conditional suppression logic for the "Generating catalog" echo. He suggests combining both changes—removing the statistics flag *and* silencing the echo—into a single patch for gitk, keeping the changes separate from git-gui due to their distinct repositories.

Sixt also politely requests a commit message rewrite to use present tense for describing the current state, a standard Git project convention. The feedback is constructive and technical, focusing on completeness and consistency rather than questioning the patch’s motivation. The patch itself is uncontroversial and follows established practice, but it will need a v3 to address these minor adjustments before maintainer sign-off. No objections to the core idea have been raised.
