This is the second patch in the v7 series that adds standardized path formatting to `` `git repo info` ``. It introduces two new fields—``path.commondir.absolute`` and ``path.commondir.relative``—to expose the repository’s common directory in both absolute and relative formats.

The patch builds on the ``append_formatted_path()`` helper introduced in the first (now squashed) patch, using it to format the common directory path retrieved via ``repo_get_common_dir()``. The implementation is straightforward: two new getter functions (``get_path_commondir_absolute`` and ``get_path_commondir_relative``) are added to the ``repo_info_field`` array, each calling the helper with the appropriate ``path_format`` enum value. The documentation in ``git-repo.adoc`` is updated to describe the new fields, and the test script ``t/t1900-repo-info.sh`` is extended with 52 lines of new tests covering standard repositories, custom common directories (via ``GIT_COMMON_DIR``), and ``GIT_DIR``-only setups, all exercised in both absolute and relative variants.

No behavior changes are introduced for existing commands; the new fields are purely additive and scriptable. The patch is clean, well-tested, and directly addresses the gap in worktree support identified in the cover letter. It is ready for maintainer pickup alongside the rest of the series.
