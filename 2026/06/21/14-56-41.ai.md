This is the final version of a two-patch series that completes the effort to silence translation catalog output during `make -s` builds in gitk and git-gui. The series now splits the changes cleanly: the first patch targets gitk, the second git-gui. Both adopt the quiet build pattern established in core Git (commit 2f12b31b746c) by removing `--statistics` from `msgfmt` invocations and conditionally suppressing "Generating catalog" messages when `make -s` is used.

The gitk patch (1/2) adds a new `QUIET_MSGFMT` helper that is only defined when neither `V` nor `s` is in `MAKEFLAGS`, ensuring the "MSGFMT" and "GEN" lines are suppressed during silent builds. The git-gui patch (2/2) simplifies its existing `QUIET_MSGFMT` rule by removing the now-unnecessary `QUIET_MSGFMT0`/`QUIET_MSGFMT1` pair, since the only remaining output (the command itself) can be handled by a single quiet prefix.

The series is now procedurally ready for review by the respective maintainers: Johannes Sixt for gitk and Johannes Schindelin for git-gui. The changes are minimal, well-motivated, and consistent with existing practice in core Git. No technical objections remain, and the implementation follows the maintainers' guidance from earlier rounds. The patches touch only the build system (`gitk-git/Makefile` and `git-gui/Makefile`) and introduce no new symbols or behavior changes beyond silencing build output.
