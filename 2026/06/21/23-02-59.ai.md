This is the first patch in Taylor Blau’s **v3 4-patch series** integrating `--delta-islands` and reachability bitmaps with `--path-walk` in `git pack-objects`. It prepares the **p5311 perf test** for the upcoming changes by simplifying its structure.

The patch removes the **lookup-table permutation** in `p5311-pack-bitmaps-fetch.sh`, which previously ran the test twice—once with the bitmap lookup table enabled and once disabled. Since the lookup table is now the de-facto default in server-side deployments (and will soon be the official default), this comparison is no longer necessary. The change reduces the test’s runtime by half while retaining the core `test_fetch_bitmaps()` function, which will be reused in the next patch to measure `--path-walk`’s impact.

The diff is minimal: it removes the `pack.writeBitmapLookupTable` configuration, drops the `lookup=$1` parameter from test descriptions, and simplifies the function call to run only once. This sets the stage for the next patch, which will add a new parameterization to compare repacks with and without `--path-walk`. The commit message explicitly notes that the lookup table’s default value will be addressed in a future series, keeping this change focused.

This is a **test infrastructure patch** with no functional impact on Git itself. It’s a straightforward cleanup that aligns the test with current realities and prepares for the series’ core performance measurements. The change is uncontroversial and directly supports the series’ goal of empirically validating `--path-walk`’s behavior when combined with bitmaps.
