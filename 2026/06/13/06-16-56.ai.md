This is a translation (l10n) coordination email kicking off the localization effort for Git 2.55.0. Jiang Xin, the Chinese translation maintainer, announces that 125 new strings need translation since the last release and provides updated workflow instructions for contributors.

Key changes from previous cycles include:
- The `po/git.pot` template file is no longer pre-generated by the coordinator; translators must generate it locally with `make po/git.pot` (or let the update process handle it automatically)
- AI-assisted translation is now explicitly mentioned as an option, with the caveat that outputs should be treated as drafts requiring human review
- The email details the process for refreshing translation files, setting up Git filters to strip source location comments, and submitting pull requests to the git-l10n/git-po repository

The deadline for submissions is June 27, 2026. The email is addressed to the Git l10n team leads for various languages (French, German, Spanish, etc.) and includes technical details about the CI validation pipeline that runs on pull requests. This is a routine coordination message in the established localization workflow rather than proposing any substantive changes to the translation process.
