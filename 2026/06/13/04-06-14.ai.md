This is the 5th patch in a 6-part series converting bare 'grep' assertions to 'test_grep' in Git's test suite. The series introduces a new 'greplint.pl' tool to automate this conversion while preserving intentional bare grep uses.

**Test infrastructure improvement**: This patch performs the bulk conversion of ~2800 grep assertions across ~340 test files to use 'test_grep' instead. The conversion:

1. Preserves bare grep usage in pipelines/conditionals with "# lint-ok" annotations
2. Converts '! grep' to 'test_grep !' to maintain failure output
3. Handles edge cases like negated greps and grep flags
4. Includes fixes for 10 pre-existing test bugs found during conversion

The changes are mechanical but thorough, touching nearly every test file. The conversion was automated using the 'greplint.pl' tool from the next patch, with manual review of edge cases. This improves test debuggability since 'test_grep' shows file contents on failure unlike bare grep.

The patch demonstrates the value of the conversion by fixing several test bugs where bare grep was silently failing assertions. It's part of an ongoing effort to standardize test assertions and improve failure diagnostics.

**Substantive review context**: The series has seen maintainer feedback preferring diagnostic-only linting over automated conversion, but the author continues demonstrating value through concrete bugfixes. The shared shell parser infrastructure from earlier patches enables this robust conversion while maintaining existing chainlint functionality.
