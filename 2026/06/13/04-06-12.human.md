**Test infrastructure refactoring**: This is the third patch in a v2 series introducing a tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The current patch focuses on extracting the shell parser from chainlint.pl into a shared module (lib-shell-parser.pl) so it can be reused by the new greplint.pl tool.

The patch moves the Lexer, ShellParser, and ScriptParser classes into the shared module while keeping the &&-chain specific checks in chainlint.pl. This is a mechanical refactoring with no functional changes - the chainlint self-tests still pass. The shared parser will be used by the subsequent greplint.pl patch to properly identify command boundaries when scanning for grep assertions.

The series as a whole aims to improve test reliability by standardizing on test_grep (which shows file contents on failure) rather than bare grep (which fails silently). This patch lays groundwork by making the shell parsing infrastructure reusable, addressing maintainer concern from v1 about code duplication. The implementation appears clean and well-isolated, with the original chainlint functionality preserved exactly while enabling future lint tools to build on the same foundation.
