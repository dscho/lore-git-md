**Documentation patch**: This is the first patch in a 6-part series introducing a tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The patch adds documentation for the existing `test_grep` helper function to t/README, which was previously undocumented despite being widely used.

The documentation clearly explains:
- The basic usage pattern
- How to properly negate assertions (using `test_grep !` rather than `! test_grep`)
- When to use `test_grep` (for assertions) vs bare `grep` (for filtering/data processing)
- The key benefit of `test_grep` - it shows file contents on failure for easier debugging

This is a straightforward documentation improvement that stands on its own merits, though it's part of a larger effort to standardize test assertions. The patch is clean and focused, with good examples that match existing test suite conventions. The documentation will be valuable regardless of whether the rest of the series is accepted.
