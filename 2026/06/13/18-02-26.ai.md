This is a security and maintenance release for tig (Git text-mode interface) version 2.6.1, following up on the major 2.6.0 release. The update addresses a command injection vulnerability (#1432) that was introduced in 2.6.0, along with 15 bugfixes and 4 improvements.

The security fix patches an editor command injection vector that could be exploited when tig launches an external editor. Other notable fixes include notes view handling (#1394), grep with revision arguments (#1398), Cygwin build updates, and performance improvements for status operations in subdirectories (#1424). The release also adds support for the NO_COLOR standard and introduces a tree view recursion option.

The changes span 119 files with 873 insertions and 375 deletions, touching core functionality like blame views, diff handling, and repository status display. Multiple contributors joined Thomas Koutcher in this release, including fixes for compiler warnings with glibc-2.43 and cursor color issues in the chocolate theme. The update maintains tig's cross-platform support while addressing both functional and security concerns from the previous release.
