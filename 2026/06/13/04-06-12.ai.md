**Test infrastructure refactoring**: This is the third patch in a v2 series introducing a lint tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The patch extracts chainlint.pl's shell script parser into a shared module (lib-shell-parser.pl) that can be reused by other lint tools.

The key changes in this patch are:
- Moves Lexer, ShellParser, and ScriptParser classes into lib-shell-parser.pl
- Makes ChainlintParser a subclass of ScriptParser (rather than ShellParser)
- Preserves all existing functionality while enabling code reuse
- No behavior changes - chainlint's output remains identical

This refactoring enables the subsequent greplint.pl tool (added in later patches) to reuse the same shell parsing infrastructure rather than duplicating it. The shared parser handles POSIX shell syntax including:
- Command parsing and tokenization
- String handling (single/double quoted, here-docs)
- Control structures (if/for/case/etc)
- Command substitution ($(...))
- Line continuation and comments

The patch demonstrates good separation of concerns - the core parsing logic is extracted while the chainlint-specific checks remain in chainlint.pl. This follows the pattern of other Git test infrastructure where reusable components are factored out (like test-lib.sh).

The changes are mechanical and well-contained, with no functional impact on existing chainlint behavior. The shared parser infrastructure will be used by the greplint tool in the next patch to identify grep assertions needing conversion.
