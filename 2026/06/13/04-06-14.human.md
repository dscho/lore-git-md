This is the 5th patch in a 6-part series introducing a `greplint.pl` tool to convert bare `grep` assertions to `test_grep` in Git's test suite. The series aims to standardize test assertions while addressing maintainer concerns about tool scope and methodology.

**Test infrastructure improvement**: This patch performs the bulk conversion of ~2800 grep assertions across ~340 test files to use `test_grep` instead of bare `grep`. The conversion preserves diagnostic output on failures while maintaining the distinction between assertion-style greps (converted) and filter-style greps (left as-is with `# lint-ok` annotations).

Key aspects:
- Only converts greps used for assertions (command position)
- Preserves existing `! test_grep` patterns by rewriting to `test_grep !`
- Leaves pipeline/filter greps unchanged with annotations
- Includes fixes for 3 pre-existing test cases that demonstrated issues with bare greps
- Generated via a script that identifies assertion-style greps while avoiding false positives

The conversion follows the pattern established in earlier patches, where `test_grep` provides better failure output by showing file contents when assertions fail. The patch demonstrates the practical benefits of the standardization effort while maintaining the series' focus on automation and correctness.

This is part of an ongoing effort to improve test infrastructure robustness, building on shared shell parsing components from `chainlint.pl`. The series has already uncovered and fixed several test bugs through this conversion work.
