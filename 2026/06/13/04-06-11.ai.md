**Bugfix in test suite**: This patch fixes three test cases where `grep` assertions were missing their file arguments, causing them to silently pass by reading from empty stdin rather than checking the intended files. The issues were found during the author's work on converting bare `grep` to `test_grep` assertions.

The fixes address:
1. A worktree listing test where the negation check wasn't reading the output file
2. A commit status test with malformed grep pattern that accidentally omitted the file
3. A repack test checking object presence where the file argument was missing

All three cases were effectively no-ops before the fix, as empty stdin always matches nothing in `grep`. The corrected versions now properly verify the intended conditions, and the tests pass with these changes. This patch demonstrates the value of the broader `test_grep` conversion effort by catching subtle test bugs that were previously hidden.

The changes are mechanical and focused - each fix simply adds the missing filename argument to a `grep` command while preserving the surrounding test logic. This patch stands on its own as a test suite improvement, though it's part of a larger series about standardizing test assertions.
