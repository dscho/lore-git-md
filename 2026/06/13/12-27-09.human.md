Compiler compatibility improvement for Clang's UNUSED attribute

This is the first patch in Dominik Loidolt's v4 series modernizing compiler compatibility macros in `compat/posix.h`. The change introduces a dedicated version check for Clang to properly support warning messages with the UNUSED attribute.

The patch adds a new `GIT_CLANG_PREREQ` macro that detects Clang versions 2.9 and above, allowing them to use the deprecated("...") message form in UNUSED attributes. This fixes an issue where Clang identifies itself as GNUC 4.2.1 for compatibility, causing the existing GCC version test to incorrectly disable the warning message feature.

The change is well-motivated by a real compatibility gap and follows Git's careful approach to cross-platform support. The implementation is clean and maintains the existing behavior for other compilers. Documentation is added to clarify the relationship between the GCC and Clang version checks.

As part of a thoroughly reviewed series that has gone through multiple iterations with substantive feedback from Patrick Steinhardt, this patch appears ready for inclusion. It represents a straightforward quality-of-life improvement for Clang users while maintaining Git's high compatibility standards.
