Jiang Xin has initiated the localization effort for Git 2.55.0, announcing that 125 new strings need translation since the last release. The workflow has been updated: translators must now generate the `po/git.pot` template file locally rather than receiving it pre-generated, and AI-assisted translation is now an option (though outputs require human review). The email provides detailed instructions for refreshing translations, setting up Git filters, and submitting pull requests to the git-l10n/git-po repository, with a submission deadline of June 27, 2026. This is a routine coordination message for the established localization process, addressed to the Git l10n team leads for various languages.
