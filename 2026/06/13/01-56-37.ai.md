This is a follow-up in the Git v2.55.0-rc0 release thread regarding Rust compatibility, specifically addressing build issues on NonStop systems. Randall S. Becker confirms that the `NO_RUST=yes` build flag successfully works around the lack of Rust tooling on NonStop platforms, as suggested by Junio C Hamano in the previous email.

The exchange demonstrates a practical resolution to the immediate build failure, but leaves the larger question of long-term Rust requirements unresolved. While the workaround functions for now, Randall's earlier concerns about NonStop's Rust toolchain timeline (potentially not available until 2027) remain unaddressed in relation to Git 3.0's planned mandatory Rust requirement. The thread continues to highlight the tension between Git's Rust roadmap and platform support realities.
