**Documentation patch** - This is the first patch in a 6-part series (v2) that introduces a tool to convert bare 'grep' assertions to 'test_grep' in Git's test suite. The patch adds documentation for the `test_grep` helper function to t/README, which was previously undocumented despite being widely used.

The documentation explains:
- `test_grep` is a wrapper around grep for test assertions that shows file contents on failure (unlike bare grep which fails silently)
- It supports negation via a leading '!' argument (rather than `! test_grep` which would suppress diagnostics)
- Appropriate use cases (test assertions) vs cases where bare grep should remain (data filtering, command substitution)

This foundational documentation patch provides context for the subsequent automated conversion work in the series. The explanation of when to use `test_grep` vs bare grep is particularly important given the series' goal of distinguishing assertion greps from implementation greps. The patch follows Git's documentation style and includes clear examples.
