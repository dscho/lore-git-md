This is the final v4 submission of Dominik Loidolt's compiler compatibility patch series, now split into three focused commits. The series modernizes version check macros in `compat/posix.h` to improve Clang's handling of the UNUSED attribute while maintaining cross-platform compatibility.

The first patch introduces `GIT_CLANG_PREREQ` to properly detect Clang versions supporting the "deprecated" attribute with messages. The second patch cleans up preprocessor indentation and comment formatting without changing behavior. The third patch (new in v4) simplifies the GCC version comparison logic by replacing the bit-shift approach with direct major/minor checks, matching BSD-style headers.

The changes since v3 reflect thorough review feedback from Patrick Steinhardt, with documentation improvements split into separate commits and final polish applied to commit messages.
