Code style cleanup in compiler compatibility macros.

This is the second patch in Dominik Loidolt's v4 series modernizing Git's compiler compatibility macros. It focuses purely on code style improvements in `compat/posix.h` without changing any behavior:

- Fixes preprocessor indentation to match Git's coding guidelines
- Standardizes capitalization of "GCC" in comments
- Adjusts comment formatting and spacing
- Maintains identical macro behavior throughout

The changes are mechanical and well-contained, continuing the series' theme of careful modernization. Since this is a style-only patch in a well-reviewed series (with Patrick Steinhardt having verified the technical soundness in previous iterations), it represents low-risk maintenance work. The patch follows Git's convention of separating cosmetic changes from functional ones, making the overall series easier to review.
