This is a maintenance and security release for tig, the ncurses-based Git repository browser. Version 2.6.1 follows up on the major 2.6.0 release with a security fix and several improvements.

The key change is a fix for an editor command injection vulnerability (CVE not yet assigned) that affected version 2.6.0. The release also includes 15 bugfixes addressing issues like notes handling, grep behavior with revisions, Cygwin build support, and performance when viewing status in subdirectories. New features include NO_COLOR environment variable support, recursive tree view option, and direct blob editing capability.

The changes span 119 files with 873 insertions and 375 deletions, showing this is a substantial update despite being a point release. Multiple contributors were involved, with Thomas Koutcher (the maintainer) handling most of the changes. The release maintains tig's cross-platform support with specific attention to Cygwin compatibility.

This continues tig project's pattern of active maintenance - the security fix in particular makes this a recommended upgrade for 2.6.0 users. The breadth of fixes and improvements suggests this is more than just a routine maintenance release.
