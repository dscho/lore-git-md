This is a platform compatibility patch series finalizing improvements to Git's compiler version checking macros. The v4 iteration from first-time contributor Dominik Loidolt addresses the last round of feedback by splitting stylistic cleanups into a separate commit and fixing preprocessor indentation.

The series makes three focused changes to `compat/posix.h`:
1. Adds proper Clang version detection (`GIT_CLANG_PREREQ`) to enable UNUSED macro warning messages
2. Cleans up formatting of existing macros without changing behavior
3. Simplifies GCC version checks by replacing bit-shift comparisons with direct major/minor checks

Patrick Steinhardt provided thorough review of the technical aspects in earlier versions, confirming the changes maintain compatibility while improving code clarity. The v4 changes are purely organizational - splitting commits and fixing style - with no functional impact. The series demonstrates Git's careful approach to modernization, with all substantive feedback incorporated through multiple iterations.

This appears ready for inclusion as a low-risk improvement to compiler compatibility infrastructure. The changes are compile-time only and maintain backwards compatibility while making the version check logic more maintainable.
