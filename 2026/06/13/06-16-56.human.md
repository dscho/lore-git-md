This is a translation (l10n) coordination email kicking off the localization effort for Git 2.55.0. Jiang Xin, the Chinese translation maintainer, announces that 125 new strings need translation since the last release.

The email provides updated workflow instructions for translators, including how to generate the translation template (`po/git.pot`), refresh language-specific `.po` files, and use AI-assisted translation tools (with human review). It also explains the filter drivers that strip source location comments from committed `.po` files to reduce repository noise.

Translators are directed to submit pull requests to the git-l10n/git-po repository by June 27, 2026, and to address any issues flagged by the l10n CI pipeline. The message follows Git's established localization process while incorporating newer tooling like AI assistance and GitHub Actions-based validation.
