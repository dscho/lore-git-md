**Test infrastructure improvement**: This is the final patch in a 6-part series introducing a new lint tool (greplint.pl) to detect and convert bare 'grep' assertions to 'test_grep' in Git's test suite. The patch adds the greplint.pl tool itself along with test fixtures and Makefile integration.

The tool reuses the shared shell parser infrastructure (lib-shell-parser.pl) to accurately identify bare grep assertions while ignoring grep usage in pipelines, command substitutions, and other non-assertion contexts. Key features include:
- Detection of bare grep at command position (not as arguments or values)
- Handling of grep flags (-e, -f, -c, etc.) and negations
- Support for "# lint-ok" annotations to suppress warnings where bare grep is intentional
- Accurate line number reporting even with backslash-continuations in test bodies
- Integration with test-lint via new test-greplint target

The implementation appears thorough, with 44 test fixtures covering edge cases like:
- Grep in subshells, compound commands, and after control operators
- Proper handling of grep as filters vs assertions
- Line number adjustment for multi-line quoted test bodies
- Correct negation syntax (flagging "! test_grep" in favor of "test_grep !")

This completes the series' goal of preventing regression of bare grep assertions while maintaining the ability to use grep as a filter when needed. The shared parser infrastructure also enables future lint rules to be added more easily. The series has already uncovered and fixed 10 pre-existing test bugs during development.
