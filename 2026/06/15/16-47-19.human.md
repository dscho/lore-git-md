This is patch 4/7 in Harald Nordgren's v15 series introducing `git branch --delete-merged` for safe automated branch cleanup. The patch prepares the underlying `delete_branches()` function for bulk operations by adding two new modes:

1. `DELETE_BRANCH_NO_HEAD_FALLBACK` - Skips the fallback to HEAD when checking if a branch is merged (only considers upstream)
2. `DELETE_BRANCH_DRY_RUN` - Simulates deletions without actually removing branches

The changes maintain backward compatibility while enabling the new `--delete-merged` behavior. The patch includes careful handling of edge cases like:
- Only checking HEAD if explicitly requested
- Proper dry-run output formatting
- Preserving existing force/quiet behavior

This is a technical refactoring that lays groundwork for the user-facing `--delete-merged` feature while keeping the existing branch deletion behavior unchanged. The implementation appears clean with clear flag-based control flow and thorough consideration of the different operation modes.
