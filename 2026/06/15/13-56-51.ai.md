Refactoring patch in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. This is patch 5/8 in version 2 of the series, which removes the now-unused `chdir_notify_reparent()` function after its last caller was eliminated in the previous patch.

The change is straightforward: the function and its helper `reparent_cb` are deleted from chdir-notify.c, and the documentation in chdir-notify.h is updated to remove mention of the convenience function. The removal is safe since all callers have been converted to use the more direct registration approach introduced earlier in the series.

This continues the series' goal of simplifying the chdir-notify infrastructure while maintaining the same functionality. The patch follows the incremental improvement pattern seen throughout this refactoring effort - each change is small and focused, with clear justification in the commit message. The change is unlikely to be controversial as it simply removes dead code after its functionality has been superseded.
