This is the final patch in Patrick Steinhardt's series modernizing Git's reference backend infrastructure, specifically addressing absolute path handling. The patch completes the transition to using absolute paths for reference stores across all backends (files, packed, reftable), allowing removal of the remaining chdir_notify callbacks.

Karthik Nayak's review identified two minor documentation nits where the commit message incorrectly referenced `chdir_notify_reparent()` instead of `chdir_notify_register()`. Patrick has acknowledged these and will fix them. The review confirms the technical correctness of the changes, with Karthik having previously provided substantive feedback on other patches in this series.

The patch represents the culmination of work to simplify path handling in the ref backends, eliminating complex relative path management in favor of consistent absolute paths. While this may cause a performance regression in extreme cases (as noted in earlier discussion), the tradeoff is considered acceptable given modern ref storage formats and the architectural benefits. With all major reviewers having weighed in and only minor documentation fixes remaining, this series appears ready for integration.
