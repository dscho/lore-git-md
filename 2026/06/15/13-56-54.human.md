Refactoring patch in Patrick Steinhardt's series modernizing Git's reference backend infrastructure (8/8). This final patch in the v2 series cleans up path computation in the refs subsystem by eliminating an unnecessary intermediate buffer.

The change simplifies `refs_compute_filesystem_location()` by removing a redundant `strbuf` that was only used to temporarily hold a path before passing it to `strbuf_realpath()`. The function now works directly with the output buffer, avoiding an extra allocation and copy. This is a straightforward optimization that makes the code both more efficient and easier to follow.

This patch concludes the v2 series, which has been carefully reviewed throughout by Karthik Nayak, Junio Hamano, and Jeff King. While the original goal of completely eliminating relative paths was deferred due to performance concerns, these preparatory changes (including this cleanup) represent meaningful improvements to the ref backend code. The series maintains its focus on incremental, well-justified improvements while Patrick continues exploring alternative approaches like `openat(3p)` for the remaining path handling challenges.
