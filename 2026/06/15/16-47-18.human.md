This is patch 3/7 in Harald Nordgren's v15 series adding `git branch --delete-merged` functionality. The patch modifies the branch deletion internals to silently skip unmerged branches when operating in bulk mode, rather than erroring out with the familiar "not fully merged" warning and advice to use `-D`.

The change introduces a new `DELETE_BRANCH_SKIP_UNMERGED` flag that suppresses warnings when branches aren't fully merged, making the behavior more suitable for automated cleanup scenarios. The existing single-branch deletion path remains unchanged, continuing to warn users about unmerged work. This is a sensible refinement that maintains safety while enabling the new bulk deletion feature to work smoothly through partially cleaned branch sets.

The implementation is cleanly done via the flags parameter that was refactored in patch 2/7, showing good forward planning in the series structure. The change is focused and well-contained, touching only the branch deletion internals while leaving all other behavior intact. This continues the series' pattern of careful, incremental improvements to the branch deletion machinery.
