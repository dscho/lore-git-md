This is the final patch in Patrick Steinhardt's approved series standardizing `b4` tool usage for Git mailing list workflows. The patch adds project-level configuration files that establish Git's preferred defaults for `b4`:

1. `.b4-config` sets `send-same-thread = shallow` to ensure patch series versions thread properly by replying to the first version's cover letter, and specifies a custom cover letter template path.

2. `.b4-cover-template` provides a Git-specific template that includes a range-diff section, matching Git's existing practices. The configuration is designed to be overridable via Git config without modifying the committed files. 

This completes the technical implementation side of the standardization effort, building on the documentation updates in the previous patches. The only change from v3 was a minor commit message wording improvement (changing "we're about to" to past tense). With maintainer approval already received, this patch is ready to merge as-is, concluding the series.
