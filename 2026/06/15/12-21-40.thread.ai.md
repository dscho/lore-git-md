CI infrastructure improvement for Windows builds in GitLab CI, initiated by Patrick Steinhardt. The thread addresses unreliable Chocolatey package manager usage by introducing a dedicated PowerShell script (`ci/install-dependencies.ps1`) for direct dependency management (Git, Meson, Rust) with version-controlled installations and caching. The solution reduces setup time from ~3 to ~1 minute and improves reliability. Changes modify `.gitlab-ci.yml` and add the new script. Justin Tobler provided **substantive review**, confirming the approach and validating the patch on GitLab CI. He raised **medium-weight** maintainability questions about version pinning frequency and performance attribution (caching vs. direct downloads), but did not challenge the design. No objections or alternative proposals have been raised; the patch is viewed as a well-considered improvement to the build system's Windows support. Key technical details: hardcoded dependency versions (Git 2.46.0, Meson 1.4.0, Rust 1.78.0), PowerShell-based error handling, and GitLab CI caching integration. Open items: long-term version update process (no concrete proposal yet). Participants: Patrick Steinhardt (author), Justin Tobler (reviewer, tested).
