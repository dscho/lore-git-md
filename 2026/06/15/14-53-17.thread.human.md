This occurs in standard installations where both Git for Windows and GPG4Win are present, and affects users who need to configure GPG home directories.

The reporter provides clear reproduction steps showing the difference between PowerShell's correct handling and Git Bash's problematic behavior. The issue appears specific to Git Bash's environment variable processing during Windows-to-Unix path conversion, potentially impacting users who rely on custom GPG configurations.
