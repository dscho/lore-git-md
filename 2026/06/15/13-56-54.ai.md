This is the final patch (8/8) in Patrick Steinhardt's refactoring series to modernize Git's reference backend infrastructure. The patch focuses on a small optimization in `refs_compute_filesystem_location()` by eliminating an unnecessary intermediate buffer.

The change removes a local `strbuf` that was being used as temporary storage when computing ref paths, instead directly using the output buffer for both input and output of `strbuf_realpath()`. This simplifies the code by:
- Removing one memory allocation/deallocation pair
- Making the path computation more direct and obvious
- Maintaining identical functionality while being slightly more efficient

This is a straightforward cleanup that follows naturally from the earlier refactoring in the series. The patch doesn't introduce any behavior changes - it just removes some redundant code that became apparent during the larger refactoring effort. 

As the final patch in the series, it represents a small but tidy conclusion to the preparatory work that:
- Simplified repository initialization
- Fixed memory leaks
- Cleaned up chdir_notify infrastructure
- Optimized path handling

The series as a whole has received substantive review from multiple core contributors (Karthik Nayak, Junio Hamano, Jeff King) and this final piece appears uncontroversial. It's a clean, focused improvement that fits well with the series' goal of modernizing the ref backend code.
