This is the first patch in v15 of Harald Nordgren's series adding `git branch --delete-merged` functionality. The patch introduces a new `--forked` filter for `git branch --list` that will be used by the deletion feature in later patches.

The `--forked` option lists branches whose configured upstream matches a given branch or pattern. It supports:
- Exact refs (e.g. "origin/main")
- Remote names (e.g. "origin" resolves to origin/HEAD)
- Shell glob patterns (e.g. "origin/*")
- Multiple arguments to widen the filter
- Combination with other filters like `--merged`

The implementation adds the new filter logic to ref-filter.c and exposes it through the branch command. The patch includes extensive test suite covering various matching scenarios and edge cases. This foundational work enables the safe branch deletion functionality that will follow in the series.
