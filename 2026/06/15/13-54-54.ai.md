This is a refactoring patch from Patrick Steinhardt's `git history drop` series, modernizing the reset machinery flags as part of the broader effort to remove `the_repository` global usage.

The patch converts the reset flags from `#define` macros to an enum type (`reset_working_tree_flags`), bringing them in line with modern Git coding practices. It also updates all flag names to match the recent rename of `reset_head()` to `reset_working_tree()`, changing prefixes from `RESET_HEAD_*` to `RESET_WORKING_TREE_*`. The changes are mechanical but touch several key files including `reset.c`, `reset.h`, `builtin/rebase.c`, and `sequencer.c`.

This is part of the larger v6 series that introduces the `git history drop` command while modernizing related infrastructure. The flag modernization here is a preparatory step that improves code organization and maintainability without changing behavior. The patch follows through on Phillip Wood's earlier suggestion to rename the reset functions and flags consistently. All call sites are updated to use the new enum values, ensuring the changes are complete and consistent across the codebase.
