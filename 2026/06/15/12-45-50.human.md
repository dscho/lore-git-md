This is a follow-up from Patrick Steinhardt addressing Junio Hamano's review of patch 6/10 in the `git history drop` series. The issue concerns the reset machinery's handling of dry-run mode when updating references.

Junio had identified a bug where the code would perform actual reference updates during a dry-run operation when the new `RESET_WORKING_TREE_UPDATE_HEAD` flag was set. Patrick acknowledges the oversight and confirms he will fix it. The problem occurs in the reference-only reset path where `update_refs()` is called without checking the dry-run flag.

This brief exchange shows the maintainer catching a subtle but important behavioral inconsistency in the reset infrastructure changes, and the author promptly accepting the feedback. The fix for this issue will be needed before the series can be considered ready for merging.
