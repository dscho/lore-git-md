This is patch 3/7 in Harald Nordgren's v15 series adding `git branch --delete-merged` functionality. The patch introduces a new `DELETE_BRANCH_SKIP_UNMERGED` flag that allows bulk branch deletion operations to silently skip unmerged branches rather than erroring out with the familiar "use 'git branch -D'" advice.

The change modifies `check_branch_commit()` and `delete_branches()` to accept the new flag, which suppresses the error message and advice when a branch isn't fully merged. This is particularly useful for the upcoming `--delete-merged` feature where users will want to clean up many branches at once without being stopped by unmerged ones. The existing single-branch deletion path (`git branch -d`) remains unchanged.

The implementation follows the series' pattern of using flags rather than boolean parameters, maintaining consistency with the refactoring done in patch 2/7. The change is cleanly isolated and doesn't affect other callers of these functions. This continues the series' focus on safe branch deletion while making bulk operations more convenient.
