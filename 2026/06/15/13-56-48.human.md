This is patch 2/8 in Patrick Steinhardt's refactoring series to modernize Git's reference backend infrastructure. The patch cleans up redundant repository format configuration during initialization.

The change fixes a subtle issue where repository format settings (hash algorithm and ref storage format) were being applied twice during repository setup - once via `repository_format_configure()` and again via `apply_repository_format()`. The patch reorders these operations so the format is configured first, then being applied to the repository in a single step.

This is a preparatory change that simplifies the initialization sequence while maintaining the same end result. It's part of the larger effort to clean up reference backend infrastructure, though this particular patch is focused on the setup path rather than the ref-specific changes that come later in the series.

The change is straightforward and unlikely to be controversial - it removes duplicate work without changing behavior. Karthik Nayak has already provided a substantive review of this patch in the thread. The diff shows a net reduction of 7 lines while making the initialization flow more logical.
