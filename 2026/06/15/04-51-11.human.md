This is the third patch in a 4-part series from a GSoC participant that standardizes path formatting in Git's plumbing commands. The patch introduces explicit `.absolute` and `.relative` variants for the common directory path in worktree setups.

The key changes in this patch:
- Adds `path.commondir.absolute` and `path.commondir.relative` fields to `git repo info`
- Implements the underlying functions using the new shared `append_formatted_path()` helper
- Includes comprehensive tests that verify behavior in standard repos and with environment overrides (GIT_COMMON_DIR/GIT_DIR)
- Uses an isolated test helper to prevent state leaks between cases

The implementation follows the pattern established in earlier patches of the series, providing explicit machine-readable output variants rather than trying to guess what format callers might prefer. The test coverage is thorough, checking both normal and edge cases.

The patch has already gone through multiple rounds of review with substantive feedback from Justin Tobler and Lucas Seiki Oshiro, and the current version addresses all outstanding comments. The changes are focused and well-contained, building on the infrastructure introduced in earlier patches of the series.

This continues the series' theme of making Git's path handling more robust and consistent while maintaining backwards compatibility. The work appears ready for integration.
