This is a refactoring patch in Harald Nordgren's `git branch --delete-merged` series (v15 2/7). The patch converts the `delete_branches()` and `check_branch_commit()` functions from using separate boolean parameters (`force` and `quiet`) to a single flags parameter using bitwise operations. 

Key changes:
- Introduces an `enum delete_branch_flags` with `DELETE_BRANCH_FORCE` and `DELETE_BRANCH_QUIET` flags
- Maintains the same behavior while making the code more extensible for future flag additions
- Splits the flags back into named boolean locals within the functions to preserve readability
- Updates all call sites to use the new flags interface

The change is purely mechanical with no functional impact, preparing the codebase for subsequent patches in the series that will add more flag options. This is a common refactoring pattern in Git's codebase to avoid proliferating boolean parameters. The patch follows Git's established conventions for flag handling and maintains all existing behavior while making the API more maintainable.
