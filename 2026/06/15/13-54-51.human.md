This is the first patch in Patrick Steinhardt's v6 series introducing the `git history drop` command. It's a preparatory refactoring that splits out index handling logic from `repo_read_index_unmerged()` into a new standalone function `index_state_unmerged_to_stage0()`.

The change allows operating on arbitrary index states rather than just the repository's main index, which will be needed for the history drop functionality. The patch also fixes a signed/unsigned mismatch in the index iteration while maintaining identical behavior. 

This is a straightforward code organization improvement that doesn't change functionality but enables cleaner integration with the upcoming history drop feature.
