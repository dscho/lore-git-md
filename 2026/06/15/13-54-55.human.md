The changes touch core reset functionality in `reset.c` and add the new flag definition in `reset.h`. This groundwork enables the subsequent patch in the series to implement dry-run mode for the new `git history drop` command.

The patch follows the series' pattern of careful, incremental changes to the reset machinery while advancing broader goals like `the_repository` removal.
