This is patch 6/8 in Patrick Steinhardt's series refactoring Git's reference backend infrastructure. The patch fixes a memory leak in the repository cleanup code where the main reference database wasn't being freed when clearing a repository, while worktree and submodule reference databases were properly released.

The leak had gone unnoticed because the pointer was kept alive by the chdir_notify subsystem, which the previous patches in the series have been cleaning up. The fix is straightforward - adding proper cleanup of `repo->refs_private` in `repo_clear()`.

This is part of the larger effort to modernize Git's reference backend code, with this particular patch being a cleanup that was enabled by the earlier work in the series. The change is small and focused, touching only repository.c to add the missing cleanup. Given the series has already received substantive reviews from Karthik Nayak, Junio Hamano, and Jeff King, and this patch follows naturally from that work, it seems likely to be uncontroversial.
