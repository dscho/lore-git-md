This is the first patch in Patrick Steinhardt's approved v4 series standardizing the use of `b4` for Git mailing list workflows. The patch updates the "MyFirstContribution" tutorial to recommend shallow threading of cover letters (linking each version back to the first cover letter) rather than deep threading (linking each version to the immediately preceding one). 

The change addresses a usability issue where deep threading could create excessively deep nesting in email clients, making threads hard to follow. The patch is purely documentation-focused, updating examples and instructions throughout the tutorial to consistently recommend the shallow threading approach. 

This change aligns with the project's broader effort to standardize contributor workflows around `b4`, which will be further documented in the subsequent patches of this series. The patch has already gone through multiple rounds of review and was approved by Junio C Hamano for merging.
