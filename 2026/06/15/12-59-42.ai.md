This is the second patch in Patrick Steinhardt's v4 series promoting the `b4` tool for Git mailing list workflows. The patch updates the `MyFirstContribution.adoc` tutorial to recommend `b4` as the preferred method for sending patches, alongside the existing GitGitGadget and `git send-email` options.

The key changes in this patch:
1. Adds a new "Sending Patches with `b4`" section to the tutorial, covering:
   - Initial setup with `b4 prep`
   - Editing cover letters and managing recipients
   - Dry-run and actual patch sending
   - Version iteration workflow
   - Configuration options
2. Updates the introductory text to present three methods (GitGitGadget, `git send-email`, and `b4`) rather than two
3. Adds a cross-reference in `SubmittingPatches` recommending `b4`

The documentation presents `b4` as building on top of `git format-patch` and `git send-email` while automating much of the manual bookkeeping. It maintains the tutorial's pedagogical approach of teaching the underlying concepts while recommending `b4` as the optimized workflow. The patch is part of the now-approved series that standardizes the contributor workflow around `b4` with project configuration files (added in patch 3/3).
