Platform compatibility patch series (Windows LLP64 large object handling) - Test case addition

Patrick Steinhardt provides a brief review of Philip Oakley's test patch for handling large (>4GB) objects on Windows/LLP64 systems. The patch adds another test case to verify basic file hashing works correctly with 5GB files when `size_t` is 64-bit but `long` is 32-bit.

Patrick's feedback is surface-level, noting the test could have been included in the initial commit rather than added separately. This is a minor organizational point rather than a technical concern. The test itself follows the established pattern of the series and has already been validated in Git for Windows (as indicated by Johannes Schindelin's sign-off).

The series as a whole addresses a long-standing platform limitation with comprehensive test coverage across different code paths (`--stdin`, `--literally`, and now basic file hashing). All production code changes are already merged in Git for Windows, with only test additions and minor rebasing needed for upstream integration. Patrick's earlier architectural question about using `size_t` vs introducing an `objsize_t` typedef remains open but doesn't block this particular test addition.
