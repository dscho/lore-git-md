This is part 6/7 of Harald Nordgren's `git branch --delete-merged` series, which adds a new configuration option to opt out of automated branch cleanup. The patch introduces `branch.<name>.deleteMerged=false` to exempt specific branches from being deleted by `--delete-merged`, while still allowing explicit deletion with `git branch -d`.

The key addition is a per-branch configuration that lets users mark certain branches (like long-lived topic branches) as exempt from automated cleanup, while still allowing manual deletion when desired. The implementation includes:
- Documentation updates explaining the new config option
- Logic in `builtin/branch.c` to check the config and skip deletion when set
- New test cases verifying both the opt-out behavior and that `git branch -d` still works normally

This patch builds on the series' existing safety mechanisms (like not deleting checked-out branches) by adding another layer of user control. The implementation appears clean and well-tested, with clear documentation of the new behavior. This is the penultimate patch in a series that has gone through 15 iterations with thorough review, suggesting it's a mature addition to Git's branch management capabilities.
