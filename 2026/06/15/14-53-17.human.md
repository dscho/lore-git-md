This is a bug report for Git for Windows, specifically about how it handles the GNUPGHOME environment variable differently from other Windows programs. The reporter, Will Flowers, shows that while GPG4Win correctly uses the GNUPGHOME value to set the GPG home directory, Git Bash incorrectly appends this value to the default path, creating an invalid combined path like "/c/Users/wiflow/C:\Users\wiflow\.gnupg".

The bug is well-documented with clear reproduction steps and version information (Git for Windows 2.54.0.windows.1 on Windows 11). This appears to be a Windows-specific path handling issue in Git Bash's environment variable processing. The report doesn't propose a fix but provides all the necessary details for someone familiar with Git for Windows' shell integration to investigate.
