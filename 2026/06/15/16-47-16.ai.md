This is the first patch in Harald Nordgren's v15 series introducing `git branch --delete-merged`, which provides safe automated cleanup of merged local branches. The patch adds a new `--forked` filter option for `git branch --list` mode that will be used as a building block for the deletion functionality.

The `--forked` option lists branches whose configured upstream matches a given branch or pattern. It supports:
- Exact ref matching (e.g. "origin/main")
- Remote name shorthand (e.g. "origin" resolves to origin/HEAD)
- Shell-style patterns (e.g. "origin/*")
- Multiple arguments to widen the filter
- Combination with other filters like `--merged` and `--no-merged`

The implementation includes:
- New `ref_filter_forked_add()` function to parse and validate patterns
- Logic to match branch upstreams against patterns (exact matches compare full refnames while globs match abbreviated names)
- Comprehensive test coverage of various matching scenarios

This foundational work enables the subsequent patches to implement safe branch deletion by first identifying branches that are both forked from specified upstreams and merged into them. The series has gone through 15 iterations with all major technical concerns addressed, leaving only minor documentation refinements as remaining work.
