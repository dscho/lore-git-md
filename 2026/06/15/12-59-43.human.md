This is the final patch in Patrick Steinhardt's series standardizing the use of `b4` for Git mailing list workflows. The patch adds project-wide configuration files that establish sensible defaults for contributors using `b4` to send patches.

The `.b4-config` file sets two key defaults:
1. `send-same-thread = shallow` - ensures new versions of a patch series reply to the original cover letter (v1) rather than the previous version
2. `prep-cover-template = ./.b4-cover-template` - points to a custom cover letter template that includes a range-diff section matching Git's conventions

The accompanying `.b4-cover-template` provides the actual template content with sections for the cover letter, shortlog, diffstat, range-diff, and base commit information. The configuration is designed to be overridable via Git config without modifying the checked-in files.

This patch represents the technical implementation side of the workflow standardization, complementing the documentation updates in the previous patches. With maintainer approval already received, this completes the series and establishes `b4` as a recommended tool with project-specific defaults for Git contributors.
