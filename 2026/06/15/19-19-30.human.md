Documentation patch improving rebase's user guidance.

Harald Nordgren's patch adds `--abort` instructions alongside existing `--continue` advice in two rebase-related contexts: when an "exec" step fails during rebase, and in the status messages shown while editing or splitting commits. The change makes the abort option consistently visible in these scenarios, matching how conflicts are already handled.

The patch modifies three files:
- `sequencer.c` to add abort hints in exec-step failure messages
- `wt-status.c` to include abort guidance in rebase-in-progress status
- `t/t7512-status-help.sh` with corresponding test updates

This is a straightforward documentation improvement that makes the UI more consistent by ensuring users always see both continuation and abort options together. The changes are mechanical but useful, with comprehensive test coverage showing the new messages in various rebase scenarios.
