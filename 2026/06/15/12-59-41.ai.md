This is the first patch in Patrick Steinhardt's approved v4 series standardizing the use of `b4` for Git mailing list workflows. The patch updates the `MyFirstContribution.adoc` tutorial to recommend "shallow threading" of cover letters rather than the previous "deep threading" approach.

The change means that when sending subsequent versions of a patch series (v2, v3, etc.), the cover letter should reference the first version's cover letter (v1) rather than the immediately preceding version. This prevents deep nesting of threads that can become difficult to follow, while still maintaining the connection between iterations.

The patch makes this change in three places in the documentation:
1. Clarifying that each iteration's cover letter is a reply to the first iteration's cover letter
2. Updating the instruction to find the Message-ID of the first cover letter rather than the previous one
3. Making it clear that all versions should reference the v1 Message-ID

This change aligns with the project's `.b4-config` file (added in patch 3/3) which sets `send-same-thread = shallow` as the default behavior. The patch has been through multiple rounds of review and discussion, with all concerns addressed in previous iterations, and is now approved by the maintainer for merging.
