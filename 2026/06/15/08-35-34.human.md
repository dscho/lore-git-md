This is a platform compatibility patch in a series addressing Windows' LLP64 limitations with large (>4GB) objects. The discussion focuses on test prerequisites for the now-working 5GB file hashing test.

Patrick Steinhardt suggests simplifying the test prerequisites by removing the `!LONG_IS_64BIT` condition, since the test should now pass on all platforms regardless of `long` size. The test was previously marked as failing (`test_expect_failure`) on 32-bit systems but has been fixed by the series' conversion from `unsigned long` to `size_t` for object sizes.

The change is straightforward and uncontroversial - Johannes Schindelin has already signed off on the patches, and the core technical work was validated through years of production use in Git for Windows. The series is effectively complete, with only minor administrative cleanup (like this test tweak) remaining before merging.
