This is patch 3/8 in Patrick Steinhardt's refactoring series to modernize Git's reference backend infrastructure. The patch focuses on cleaning up how the `GIT_REFERENCE_BACKEND` environment variable is applied during repository setup.

The key change moves the environment variable handling to only apply when we've actually found a repository, rather than doing it unconditionally. This eliminates a redundant call to `repo_set_ref_storage_format()` since we now adjust the format before applying it via `apply_repository_format()`. The patch also fixes two issues: applying the variable unnecessarily when no repository exists, and having to manually reapply the repository format after the fact.

The changes are part of Patrick's ongoing effort to simplify and improve the ref backend code. Junio C Hamano provided substantive review of this patch in particular. While the change is relatively small (40 lines modified), it's a meaningful cleanup that makes the initialization sequence more logical and removes some redundant operations.

This continues the series' pattern of careful, incremental improvements to the ref backend infrastructure while avoiding the performance regressions that were identified in the original approach. The patch maintains all existing functionality while making the code more straightforward.
