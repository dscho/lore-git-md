CI / build system patch from Patrick Steinhardt addressing flaky Windows builds in GitLab CI. The current setup uses Chocolatey package manager which proves unreliable for dependency installation, causing frequent job failures. The patch introduces a new PowerShell script (`ci/install-dependencies.ps1`) that directly downloads and installs required dependencies (Git, Meson, Rust) from their official sources.

Key changes:
- Replaces Chocolatey-based installation with direct downloads of specific dependency versions
- Adds caching for downloaded installers via GitLab CI cache
- Claims to reduce installation time from ~3 minutes to ~1 minute
- Provides explicit version control over dependencies
- Includes error handling and progress reporting in the new script

The patch touches `.gitlab-ci.yml` to modify the Windows job configuration and adds the new PowerShell script. This appears to be a straightforward reliability improvement for the CI pipeline, though it does hardcode specific dependency versions that may need updating over time. The approach aligns with GitLab CI best practices by leveraging caching and direct artifact downloads.
