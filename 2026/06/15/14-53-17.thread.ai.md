Thread summary:

Bug report regarding Git Bash on Windows incorrectly handling the GNUPGHOME environment variable. Reporter Will Flowers describes Git Bash appending rather than replacing the GNUPGHOME value, creating malformed hybrid paths like "/c/Users/wiflow/C:\Users\wiflow\.gnupg" when running gpg commands. The issue occurs with default Git for Windows installations when GPG4Win is present and GNUPGHOME is set in Windows environment variables. The behavior differs between PowerShell (correct) and Git Bash (incorrect path concatenation). Reproduction steps provided for Git for Windows 2.54.0.windows.1 on Windows 11 Enterprise. This appears to be a Windows-specific path conversion bug in Git Bash's environment variable processing, affecting users who configure custom GPG directories. No maintainer response or proposed fix yet.
