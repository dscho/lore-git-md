This thread is about improving the reliability of Windows builds in GitLab CI. Patrick Steinhardt proposed replacing the flaky Chocolatey package manager with a dedicated PowerShell script (`ci/install-dependencies.ps1`) that directly installs and caches dependencies like Git, Meson, and Rust. The change cuts setup time from about three minutes to one and has been thoroughly reviewed and tested by Justin Tobler, who confirmed the approach works well in GitLab CI.

The patch is now ready to merge. All earlier questions—like how often versions should be pinned and whether caching or direct downloads drove the speedup—have been resolved. The only minor quirk is that Meson hardcodes Git’s installation path, so the script doesn’t need to adjust `$env:Path`; this could be documented in a comment but isn’t blocking. The solution is seen as a solid, low-risk improvement to the build system’s Windows support.
