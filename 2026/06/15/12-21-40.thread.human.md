This thread is about improving the reliability and speed of Windows builds in GitLab CI. Patrick Steinhardt proposed replacing the flaky Chocolatey package manager with a dedicated PowerShell script (`ci/install-dependencies.ps1`) that directly installs and caches dependencies like Git, Meson, and Rust. The change cuts setup time from about three minutes to one and has been well-received.

Justin Tobler reviewed the patch, testing it on GitLab CI and raising two practical questions: how often dependency versions should be updated, and whether the speedup came from caching or the new script. Patrick clarified that the project is conservative about minimum dependency versions, so updates will be infrequent, and the performance gain comes mostly from ditching Chocolatey’s overhead, not caching. The patch is now effectively ready to merge, with no outstanding objections. The only minor loose end is a quirk where Git’s path isn’t explicitly added to `$env:Path` because Meson hardcodes its location, but this isn’t blocking. The thread is a straightforward, collaborative improvement to the build system’s Windows support.
