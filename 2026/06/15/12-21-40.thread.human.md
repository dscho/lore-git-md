Patrick Steinhardt has proposed a fix for flaky Windows builds in GitLab's CI pipeline. The current setup relies on Chocolatey package manager, which has proven unreliable for installing dependencies like Git, Meson and Rust. His solution introduces a new PowerShell script that directly downloads and installs these dependencies from their official sources, bypassing Chocolatey entirely.

The new approach offers several improvements: it cuts installation time from 3 minutes to about 1 minute, provides better version control over dependencies, and includes proper error handling. The patch modifies the CI configuration and adds the new installation script. While this hardcodes specific dependency versions that will need periodic updates, it should significantly improve build reliability for Windows test jobs.
