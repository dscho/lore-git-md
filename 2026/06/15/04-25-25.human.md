This is a small bugfix for Git's `.gitattributes` file, correcting the line-ending normalization attribute for Perl scripts.

The patch fixes an incorrect attribute in `.gitattributes` where Perl scripts (`*.pl`) were using `eof=lf` instead of the correct `eol=lf` attribute. The latter is the standard attribute for line-ending normalization, matching how neighboring Perl file patterns (`.perl` and `.pm`) are already configured. This ensures Perl scripts will be checked out with consistent LF line endings.

The change is straightforward - a one-line diff that replaces `eof=lf` with `eol=lf`. The commit message clearly explains the issue and the fix, though it might have been helpful to note that `eof` isn't a valid attribute (rather than just saying it's "not built-in"). The patch appears correct and uncontroversial, aligning the `.pl` handling with the existing patterns for other Perl files.
