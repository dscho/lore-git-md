This is a refactoring patch from Patrick Steinhardt's `git history drop` series, modernizing the reset machinery flags. The patch converts the reset flags from `#define` macros to an enum type and updates their names to match the recent `reset_head()` to `reset_working_tree()` function rename.

The changes are mechanical but touch several key files (reset.c, reset.h, builtin/rebase.c, sequencer.c) that use the reset functionality. The enum provides better type safety and the renamed flags (now prefixed with `RESET_WORKING_TREE_`) better reflect their purpose after the function rename in the previous patch.

This is part of the broader effort to modernize Git's reset machinery in preparation for the new `git history drop` command. The patch maintains full backwards compatibility while improving code quality - a typical example of Patrick's careful, incremental refactoring approach.
