This is patch 5/8 in Patrick Steinhardt's refactoring series to modernize Git's reference backend infrastructure. The patch removes the now-unused `chdir_notify_reparent()` function after its last caller was eliminated in the previous patch.

The change is straightforward cleanup - deleting the function implementation from chdir-notify.c and updating the header file documentation to remove mention of the convenience wrapper. The removal is safe because all callers have been converted to use the more direct `chdir_notify_register()` API instead.

This continues the series' goal of simplifying the chdir-notify subsystem while maintaining the same functionality. The patch follows the incremental approach of the v2 series, which focuses on preparatory improvements while deferring more controversial changes (like the absolute path transition that showed performance regressions in v1).

The change is well-contained and unlikely to be controversial, as it simply removes dead code that's no longer needed after the refactoring. It maintains the test coverage established earlier in the series. Reviewers have already given substantive feedback on the overall approach in earlier patches.
