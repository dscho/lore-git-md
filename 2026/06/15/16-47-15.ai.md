This is v15 of Harald Nordgren's series adding `git branch --delete-merged` for safe automated local branch cleanup, now renamed from `--prune-merged` to better reflect its behavior. The series has evolved through 15 iterations with all major technical concerns addressed.

Key changes in this version:
- Renamed the option from `--prune-merged` to `--delete-merged` throughout
- Now silently skips not-yet-merged branches rather than warning about them
- Added support for bare remote names (e.g. "origin") as shorthand for the branch its origin/HEAD points to
- Improved initialization of variables in `delete_branches()`
- Added documentation and code cleanups, including redundant NULL checks and clearer wording
- Expanded test coverage with more realistic scenarios and fixed misleading test names

The implementation provides safe automated cleanup of local branches whose work has landed on their upstream, with several safety mechanisms:
- Never deletes checked-out branches
- Skips branches whose upstream no longer exists
- Preserves branches that push back to their upstream (like main tracking origin/main)
- Supports per-branch opt-out via `branch.<name>.deleteMerged` config
- Includes a `--dry-run` mode to preview deletions

The series appears technically complete, with the remaining work being final documentation and naming refinements rather than functional changes. Phillip Wood has been providing detailed implementation feedback on flag handling and test coverage. The platform-dependent test failures that were blocking earlier versions appear resolved.
