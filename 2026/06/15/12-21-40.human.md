CI / build system patch from Patrick Steinhardt that migrates GitLab's Windows CI builds away from Chocolatey package manager. The change addresses frequent flakiness in Windows builds caused by Chocolatey's unreliable community package repository.

The patch introduces a new PowerShell script (`ci/install-dependencies.ps1`) that directly downloads and installs required dependencies (Git, Meson, Rust) from their official sources. This approach provides several benefits: better reliability by removing the Chocolatey dependency, faster installation (reducing from ~3 minutes to ~1 minute), version control over dependencies, and the ability to cache installers.

The implementation shows careful attention to Windows-specific details - it handles installer downloads, silent installations, path configuration, and adds the download directory to git's exclude file. The change appears well-motivated and addresses a clear pain point in the CI pipeline. Given Patrick's track record with CI and Windows-related work, this seems like a solid improvement to the build infrastructure.
