This is the second patch in Patrick Steinhardt's v4 series documenting and promoting the `b4` tool for Git contributor workflows. The patch adds comprehensive documentation about using `b4` to the "MyFirstContribution" tutorial, positioning it as the recommended method for mailing list submissions.

The documentation covers:
- Basic `b4 prep` setup for tracking a patch series branch
- Editing cover letters and managing recipients
- Dry-run and actual sending of patches
- Handling version iterations (v2, etc.) with automatic version bumping and range-diffs
- Configuration via both git-config and project-level `.b4-config`

The patch also updates `SubmittingPatches` to recommend `b4` alongside GitGitGadget. This completes the pedagogical side of the standardization effort, complementing the configuration files added in patch 3. The changes are well-integrated with the existing tutorial structure while clearly presenting `b4` as an optimization layer over the manual email workflow.

With all discussion points from previous iterations resolved and maintainer approval granted, this series is now ready to merge as part of improving Git's contributor experience.
