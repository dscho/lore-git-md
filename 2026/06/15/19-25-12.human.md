This is a build system patch series that fixes an issue where translation catalog generation output wasn't being properly silenced during `make -s` builds for gitk and git-gui. The problem manifests as verbose "Generating catalog" messages and `msgfmt --statistics` output appearing even when the silent flag (-s) is used. The patches modify the Makefiles for both GUI tools to conditionally suppress this output based on the MAKEFLAGS setting.

The changes are minimal and focused - they wrap the msgfmt invocations in conditionals that check for the silent flag, maintaining existing verbose output in normal builds while properly honoring `make -s`. The approach follows patterns already established elsewhere in Git's build system.

Since gitk and git-gui are maintained separately from core Git (by Johannes Sixt and Johannes Schindelin respectively), these changes will need their review. The patches appear ready for maintainer consideration, with no outstanding technical questions. This is a straightforward quality-of-life improvement for developers who use silent builds.
