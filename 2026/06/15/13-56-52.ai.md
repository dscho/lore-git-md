This is patch 6/8 in Patrick Steinhardt's series refactoring Git's reference backend infrastructure. The patch fixes a memory leak in the repository cleanup code where the main reference database wasn't being freed when clearing a repository structure.

The change adds cleanup of `repo->refs_private` in `repo_clear()`, matching how worktree and submodule reference databases are already handled. The leak had gone unnoticed because the pointer was being kept alive by the chdir-notify subsystem, which the series is in the process of removing.

This is a straightforward bugfix that:
- Adds proper cleanup of the main ref store
- Maintains consistency with how other ref stores are handled
- Is part of the broader ref backend modernization effort

The patch has already received review from Karthik Nayak in previous iterations. It's a clear improvement that closes a real resource leak while being low-risk - the kind of change that typically gets merged quickly once the series as a whole is approved.
