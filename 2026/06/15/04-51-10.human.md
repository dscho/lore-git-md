This is part 2/4 of a GSoC participant's patch series refactoring path handling in Git. The patch removes duplicate path formatting logic from `rev-parse` in favor of using the new shared `append_formatted_path()` helper introduced earlier in the series.

The changes are straightforward mechanical replacements - the local `format_type` and `default_type` enums are removed, and all path printing calls now delegate to the centralized helper. The patch maintains all existing functionality while eliminating the risk of divergence between different implementations of path formatting.

Reviewers Justin Tobler and Lucas Seiki Oshiro have already given positive feedback on earlier versions, and the v4 changes are minor style tweaks. The implementation looks clean and well-tested, with comprehensive test coverage carried over from previous patches in the series. This appears ready for integration as part of the larger path formatting standardization effort.
