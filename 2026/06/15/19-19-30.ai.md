Documentation patch improving rebase's user interface by adding --abort hints.

Harald Nordgren's patch adds mentions of `git rebase --abort` alongside existing `--continue` advice in two scenarios: when an "exec" step fails during rebase, and in the status help text shown while splitting or editing commits. The change makes the UI more consistent with other commands that offer both continue and abort options.

The patch modifies three files:
1. `sequencer.c` to add abort advice in exec step failure messages
2. `wt-status.c` to include abort option in rebase status messages
3. `t/t7512-status-help.sh` with corresponding test updates

The changes are straightforward and mechanical additions of parallel advice text, matching the existing pattern for conflict cases. The test updates verify the new messages appear as expected in various rebase scenarios. This appears to be a well-contained quality-of-life improvement for users who might want to exit a rebase operation.
