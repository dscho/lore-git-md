This is the final version of a GSoC participant's patch series that introduces standardized path formatting for repository information. The series refactors path handling logic into a shared helper function and extends `git repo info` to provide both absolute and relative path variants for gitdir and commondir.

The implementation has gone through multiple rounds of review with substantive feedback from Phillip Wood, Lucas Seiki Oshiro, and Justin Tobler. Key technical aspects include:

1. A new `append_formatted_path()` helper in `path.c` that handles all path formatting cases (UNMODIFIED, RELATIVE, RELATIVE_IF_SHARED, CANONICAL)
2. Complete integration with `rev-parse` to eliminate duplicate logic
3. Explicit `.absolute` and `.relative` variants for both gitdir and commondir paths
4. Comprehensive test coverage including edge cases and shared repository scenarios

The v4 changes are minor style tweaks based on Lucas Seiki Oshiro's feedback - removing unnecessary quotes in test helper calls and maintaining POSIX-compliant export syntax. All substantive technical discussion has concluded with consensus around the design.

The series appears ready for integration, having addressed all reviewer feedback while maintaining clean separation of concerns and robust test coverage. The shared path formatting helper in particular provides a solid foundation for future path-related features.
