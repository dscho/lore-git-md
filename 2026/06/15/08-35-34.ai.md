This is a platform compatibility patch in a series addressing Windows' LLP64 limitations with large (>4GB) objects. Patrick Steinhardt suggests a refinement to the test prerequisites in the final patch of the series.

The test in question verifies correct hashing of 5GB files, which previously failed on systems with 32-bit `long` (like Windows). Now that the underlying issue is fixed, Patrick questions whether the `!LONG_IS_64BIT` prerequisite should be removed entirely since the test should pass on all platforms. This would make the test more broadly applicable rather than specifically targeting LLP64 systems.

The change is minor but shows attention to detail in test coverage. The series has already been validated in production via Git for Windows, with Johannes Schindelin's sign-off. The only remaining work is a rebase to resolve integration conflicts, as noted by Junio Hamano. The technical approach is sound and the changes are well-contained, addressing a long-standing platform limitation with proven stability.
