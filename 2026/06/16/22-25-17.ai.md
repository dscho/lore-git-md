This is a test cleanup patch in Matt Hunter's 7-patch series implementing the global `fetch.followRemoteHEAD` configuration option. Specifically, this is patch 3/7 of v2, preparing the test suite for a later patch in the same series that will introduce a similar test case.

The patch addresses a potential test conflict by adding a `test_when_finished` cleanup hook to remove the `custom-head` remote created in the existing "followRemoteHEAD create does not overwrite dangling symref" test. Without this change, a subsequent test (introduced later in the series) that also creates a `custom-head` remote would fail when run after this one, as the remote would already exist.

This is a minor but necessary housekeeping change that ensures test isolation. The modification is straightforward: a single line addition that registers a cleanup command to remove the remote after the test completes. The change is well-motivated and directly supports the series' goal of comprehensive test coverage for the new configuration feature. No substantive behavior changes are introduced by this patch.
