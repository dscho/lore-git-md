This is a small documentation polish patch in Matt Hunter’s 7-patch series implementing the global `fetch.followRemoteHEAD` configuration. It corrects a single line in the advice message emitted by `` `git fetch` `` when the remote’s HEAD points to something other than a branch. The current text says `warn-if-not-branch-%s`, but the actual configuration value (and the documentation) uses `warn-if-not-%s`; this patch aligns the advice with the real setting. The change is purely textual, touches only `builtin/fetch.c`, and is uncontroversial.
