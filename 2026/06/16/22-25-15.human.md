This is a small but important documentation polish patch in Matt Hunter’s 7-patch series implementing the global `fetch.followRemoteHEAD` configuration. It corrects a single line in the advice message shown when Git detects that a remote’s HEAD has changed and the user has configured `remote.<name>.followRemoteHEAD` to `warn-if-not-branch`. The current text incorrectly says `warn-if-not-branch-%s`; the patch changes it to `warn-if-not-%s` to match both the actual implementation in `remote.c` and the existing documentation. The fix is purely textual—no behavior changes—and ensures the advice users see is consistent with the configuration values they can actually set. This is the first patch in the v2 series and addresses a minor but visible inconsistency that was likely caught during final review.
