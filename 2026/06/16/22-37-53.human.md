This is patch 16/17 in Patrick Steinhardt's ODB abstraction series, which continues the effort to convert Git's object storage layer to use explicit source types. The patch refactors MIDX (multi-pack-index) interfaces to work specifically with `struct odb_source_packed` rather than the generic `struct odb_source`, making the type system more precise since MIDX operations are inherently tied to packed storage.

The changes are mechanical but widespread, updating function signatures and call sites across 13 files. The patch maintains existing behavior while making the packed-source relationship explicit, which helps prevent misuse and aligns with the architectural direction established in earlier patches. Justin Tobler's review confirms the changes look correct, noting that the downcasting required at some call sites doesn't appear to alter error flows since only the "files" source exists currently.

This is part of the larger ODB abstraction effort that has been ongoing for several months, with this particular series currently blocked by refdb infrastructure issues discovered during implementation. The patch itself appears straightforward and well-contained, following the established pattern from earlier conversions of loose object storage. While the series is technically complete, it remains dependent on other infrastructure work before it can progress.
