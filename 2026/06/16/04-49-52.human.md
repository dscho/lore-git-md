This is a feature patch in a GSoC participant's series that standardizes path formatting in Git's plumbing commands. The patch adds `path.commondir.absolute` and `path.commondir.relative` fields to `git repo info`, providing script-friendly access to the shared repository directory location in both formats.

The change is part of a larger effort to consolidate path handling logic through a new `append_formatted_path()` helper. This particular patch focuses on worktree scenarios where the common directory (containing shared objects and refs) differs from the per-worktree gitdir. The implementation handles edge cases like environment variable overrides (GIT_COMMON_DIR/GIT_DIR) and includes comprehensive tests.

The series has undergone multiple rounds of review with substantive feedback from Justin Tobler and Lucas Seiki Oshiro, and this iteration incorporates their test infrastructure improvements. The patch demonstrates careful attention to script usability by providing explicit output variants rather than relying on implicit defaults. The changes are well-contained and maintain backwards compatibility while adding the new functionality.
