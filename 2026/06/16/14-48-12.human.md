This is a platform compatibility patch, part of the long-running Windows LLP64 large-object handling series. The email is a brief reply from Johannes Schindelin to Patrick Steinhardt about test organization in Philip Oakley’s patch series.

Johannes agrees with Patrick’s earlier suggestion to remove the `!LONG_IS_64BIT` test prerequisite (already done in the thread), making the 5 GB test run on all platforms that support large files. On the minor point about whether all tests should have been introduced in the first commit, Johannes politely disagrees: he finds the current patch-by-patch structure clearer, as each commit addresses a distinct concern and keeps cognitive load low.

The series itself is effectively complete, with all production code changes merged and validated in Git for Windows. Only test additions and a routine rebase remain before upstream integration. The technical approach—using `size_t` for object header lengths—has Junio’s approval, and the architectural discussion about type consistency is settled in favor of `size_t`.
