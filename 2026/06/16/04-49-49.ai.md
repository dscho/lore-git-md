This is a feature patch series from a GSoC participant that refactors Git's path handling logic and extends `git repo info` to provide standardized path formatting. The series has progressed through multiple rounds of review with substantive feedback from Justin Tobler and Lucas Seiki Oshiro.

The v5 iteration focuses on test infrastructure improvements, simplifying the `test_repo_info_path` helper by:
1. Removing the redundant `repo_name` argument and using `test_when_finished` for cleanup
2. Consolidating path expectation arguments into a single `expected_dir` parameter
3. Moving repository creation into individual test cases for better debuggability

The core changes remain:
- A new `append_formatted_path()` helper in `path.c` that centralizes path formatting logic
- Refactored `rev-parse` to use this shared implementation
- New `path.gitdir` and `path.commondir` fields in `git repo info` with explicit `.absolute` and `.relative` variants

The series demonstrates careful attention to test isolation and maintainability, with each version incorporating reviewer feedback. The technical approach has consensus, and this iteration addresses the remaining test infrastructure concerns from Justin Tobler's v4 review. The changes are well-contained and focused on providing reliable path information for scripting use cases.
