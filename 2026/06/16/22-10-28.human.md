This is patch 11/17 in Patrick Steinhardt’s ongoing ODB abstraction series, which is converting Git’s packed object storage to use the new `struct odb_source` interface. Justin Tobler’s review here is surface-level but confirms the mechanical correctness of wiring up the `for_each_object()` callback for the packed source.

The patch moves the existing `packfile_store_for_each_object()` function and its helpers from `packfile.c` to `odb/source-packed.c`, then registers it as the callback. No behavior changes are introduced; the code is simply relocated to align with the new abstraction layer. Justin’s only question is whether the newly exposed `packed_object_info_with_index_pos()` function is meant to be temporary, mirroring a similar exposure of `find_pack_entry()` in an earlier patch. The commit message does not clarify this, but the pattern suggests it is likely an intermediate step in the refactoring.

This patch is part of the final stretch of the series, which has already seen mechanical approval for its foundational changes. The ODB abstraction work remains on track, though the series as a whole is currently blocked by unrelated refdb lifecycle issues Patrick discovered during implementation. Those issues are being addressed in a separate 11-patch series, but this patch itself looks ready for maintainer consideration. If you are following the ODB effort, this is a routine step; if you are not, it is safe to skip unless you are specifically interested in the object storage layer.
