The series is now fully updated to address all prior review feedback from Junio C Hamano, Elijah Newren, and Justin Tobler.

The implementation also includes new test coverage for edge cases: `--linearize` with `--advance`, the `--revert`/`--linearize` incompatibility, and a `git range-diff` check to verify that the replayed patch chain is functionally equivalent to the original. The test script has been corrected to accurately reflect the commit range and to properly test replaying down to the root commit.

The series consists of three patches: the first refactors `enum replay_mode` into a boolean `reverse` flag (no behavior change), the second extracts a helper function and renames an existing one (no behavior change), and the third implements the `--linearize` option. All prior design questions about root-commit handling and extensibility have been resolved; the author has confirmed that root commits are intentionally replayed (merges are dropped) and that the enum-to-bool refactoring is sufficient for current needs.
