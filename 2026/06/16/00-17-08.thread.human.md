This thread covers the long-running SHA-1/SHA-256 interoperability work by brian m. carlson, which aims to allow Git repositories using different hash algorithms to exchange objects. The latest update confirms the core functionality now works with passing test results, though significant cleanup and optimization remains. Supported features include test suite compatibility and protocol extensions for shallow clones, submodules, and partial clones, while known limitations remain around filtered bundles, multi-pack indexes, and packfile URIs.

The author notes several technical challenges still to address, including delta resolution in `git index-pack`, object map batching, and performance optimizations. With over 200 patches involved, brian m. carlson explicitly states this work won't target Git 3.0 due to the volume and need for extended testing, though the branch remains available for others to test or potentially continue upstream. The update provides both technical implementation details and broader considerations about the feature's adoption path forward.
