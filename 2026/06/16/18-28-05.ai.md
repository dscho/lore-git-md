This is the **final patch in Harald Nordgren’s `--delete-merged` series**, adding `--dry-run` support to the new branch-cleanup command. The patch itself is small and focused: it extends `prune_merged_branches()` with a boolean `dry_run` parameter, prints “Would delete branch <name>” for each candidate, and exits without modifying any refs.

Phillip Wood’s **substantive review** (in the parent email) flags two issues that now block this patch. First, he objects to the boolean parameter, insisting on a flags-based API for consistency with `delete_branches()` and future extensibility. Second, he wants the dry-run tests integrated into the existing test suite rather than added as standalone scripts. Harald acknowledges the first point and will need to rework the function signature across the entire series; the test-design feedback is still unaddressed.

The patch is otherwise complete and well-motivated: it gives users a safe preview of what `--delete-merged` would do, mirroring the real deletion logic exactly. If the API and test changes are made, this should be ready to merge.
