This is the first patch in Toon Claes's three-part series introducing a `--linearize` option to `git replay`. It refactors the existing `enum replay_mode` into a simple boolean `reverse` flag, simplifying the code by removing redundant checks and reducing the number of conditional branches.

The patch replaces the two-value enum (`REPLAY_MODE_PICK` and `REPLAY_MODE_REVERT`) with a boolean that directly encodes whether the operation is a revert (true) or a pick (false). This change eliminates the need for a `BUG()` check guarding against invalid enum values, shortens ternary expressions, and makes the control flow slightly more straightforward. The refactoring is purely internal: the behavior of `git replay` remains unchanged, and no new functionality is introduced.

The diff touches only `replay.c`, updating function signatures, variable declarations, and conditional logic to use the new boolean flag. The patch is well-contained and does not affect any other files or subsystems. Review feedback from earlier iterations (notably from Justin Tobler) has already been incorporated, and the boolean approach has been accepted as sufficient for the current dual-mode needs.
