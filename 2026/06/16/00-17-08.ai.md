This is a major update on the SHA-1/SHA-256 interoperability work, a long-running effort to allow repositories using different hash algorithms to exchange objects. The author, brian m. carlson, announces that the core functionality is now working with passing test suite results, though significant cleanup and optimization remains.

The message details both supported features (test suite, protocol extensions for shallow/submodule/partial clones) and current limitations (filtered bundles, multi-pack index usage, packfile URIs, and several other edge cases). Notable technical challenges include recursive delta resolution in `git index-pack` that needs iterative reworking, batching requirements for object maps, and performance optimizations needed for production use.

The author explicitly states this work will not target Git 3.0 due to the large patch volume (200+ patches) and need for extended testing, while noting someone else may take up the upstreaming work. The branch is available for testing but remains in flux. The update includes both technical specifics about implementation constraints and higher-level considerations about the feature's future direction and community adoption challenges.
