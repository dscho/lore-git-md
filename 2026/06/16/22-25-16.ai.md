This is a documentation patch, part of Matt Hunter’s 7-patch series implementing the global `fetch.followRemoteHEAD` configuration option. It adds a brief entry to `Documentation/config/advice.adoc` explaining the new `fetchRemoteHEADWarn` advice message that appears when `remote.<name>.followRemoteHEAD` is set to `warn` or `warn-if-not-<branch>` and the fetched remote HEAD disagrees with the local configuration. The entry follows the existing style and links to `git-fetch(1)` for context. This patch is the second in the v2 series and completes the documentation coverage for the advice subsystem.
