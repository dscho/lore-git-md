This is a major milestone announcement for the SHA-1/SHA-256 interoperability work, a long-running effort to allow repositories using different hash algorithms to exchange objects. Brian m. carlson reports that the core functionality is now working in their development branch, with the test suite passing and basic operations functional across hash boundaries.

The announcement outlines several current limitations, including unsupported features like filtered bundles and packfile URIs, and notes areas needing performance improvements. The work introduces new documentation and some Rust code for object conversion, though carlson emphasizes this remains experimental and not yet ready for upstream submission. They explicitly state this should not delay Git 3.0, given the substantial remaining work and the need for extended testing.

The email serves as both a progress report and an invitation for community testing, while managing expectations about the timeline for potential inclusion in mainline Git. The technical limitations described suggest this will remain a specialized feature with notable constraints even when complete.
