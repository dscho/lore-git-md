This is a feature patch series from a GSoC participant that refactors Git's path handling logic and extends `git repo info` to provide standardized path formatting. The series has progressed through multiple rounds of review with substantive feedback from Justin Tobler, Lucas Seiki Oshiro, and Phillip Wood.

The key changes in v5:
1. Simplified the test helper by removing redundant arguments and using `test_when_finished` for better isolation
2. Added clarifying comments about PATH_FORMAT_DEFAULT behavior
3. Trimmed verbose explanations from commit messages
4. Maintained the same core functionality while improving test maintainability

The series introduces:
- A new `append_formatted_path()` helper in path.c that centralizes path formatting logic
- Refactored `rev-parse` to use this shared helper
- New `path.gitdir` and `path.commondir` fields in `git repo info` with explicit `.absolute` and `.relative` variants

The implementation looks clean and well-tested, with the v5 changes addressing reviewer feedback to improve the test infrastructure. The series appears ready for final review, having incorporated all substantive technical feedback from previous rounds. The changes follow Git's philosophy of explicit over implicit behavior for plumbing commands.
