This is the final patch in a GSoC participant's series to standardize Git's path formatting, adding `.gitdir` variants to complement the existing `.commondir` functionality in `git repo info`. The patch introduces `path.gitdir.absolute` and `path.gitdir.relative` fields that provide stable, script-friendly access to repository paths without parsing `rev-parse` output.

The implementation reuses the `append_formatted_path()` helper introduced earlier in the series, applying the same canonical and relative path formatting logic used for common directories. Test cases verify both standard and GIT_DIR-overridden scenarios, maintaining consistency with the test patterns established for commondir. The changes are well-contained, touching only documentation, the repo command implementation, and tests.

This completes the mechanical conversion work to eliminate duplicate path-handling code while providing explicit machine-readable output options. The series has undergone multiple rounds of substantive review from Justin Tobler and Lucas Seiki Oshiro, with this final iteration incorporating their test infrastructure refinements. The approach aligns with Git's philosophy of explicit over implicit for plumbing commands, and the implementation appears robust with comprehensive test coverage.
