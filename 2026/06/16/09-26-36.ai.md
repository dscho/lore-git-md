This is the second patch in the v3 series introducing `git replay --linearize`. It is a pure refactoring patch that extracts the logic for storing a commit mapping into a new helper function `put_mapped_commit()` and renames the existing `mapped_commit()` to `get_mapped_commit()` for symmetry. The patch touches only `replay.c` and makes no behavior changes; it is a preparatory step for the `--linearize` implementation in patch 3.

The extraction reduces the length of `replay_revisions()` by moving the khash insertion boilerplate into a dedicated function, improving readability. The rename from `mapped_commit` to `get_mapped_commit` pairs naturally with the new `put_mapped_commit` helper, making the code’s intent clearer. The patch is uncontroversial and has already been reviewed in previous iterations; no new feedback is expected. It is a clean, mechanical change that sets up the subsequent feature patch.
