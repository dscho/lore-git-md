This thread introduces a performance optimization for `git describe` that significantly speeds up the command in repositories with many non-tag refs. The patch modifies the ref iteration logic to only scan the `refs/tags/` namespace by default, since non-tag refs are ignored unless `--all` is specified. Benchmark results show a 3.1x speedup (196ms to 63ms) when describing HEAD in a repository with over 124,000 refs, with system time dropping from 123ms to just 12ms as the backend no longer needs to stat irrelevant refs. The change comes with a thorough performance test case that creates 10,000 dummy refs to validate the optimization's impact. The patch is small, focused, and well-justified by the performance data.
