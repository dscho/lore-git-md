This is a performance optimization for `git describe` that limits ref iteration to just tags when `--all` isn't specified. The patch demonstrates a 3x speedup in a repository with 124k refs (only 330 of which are tags) by avoiding unnecessary ref iteration.

The change is straightforward - it sets the `prefix` field of `for_each_ref_opts` to "refs/tags/" when `--all` isn't used, allowing the ref backend to skip non-tag refs entirely rather than filtering them out after iteration. The commit includes clear benchmark results showing the improvement in both elapsed time and system time.

The patch includes a new performance test that creates 10,000 unrelated refs to demonstrate the optimization's impact. The test is gated behind a prereq to only run with the files ref backend, since other backends may handle this case differently.
