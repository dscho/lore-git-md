This is a discussion about commit message trailers and LLM attribution in Git contributions. Kristoffer Haugsbakk responds to Tamir Duberstein's use of an "Assisted-by: Codex gpt-5.5" trailer, noting that such specific LLM attribution isn't standard practice in the Git project (unlike in Git for Windows).

The email raises concerns about the value of detailed LLM version tracking in commit messages, comparing it to graffiti ("Peter was here") and questioning what meaningful information this provides years later. Haugsbakk suggests that if LLM assistance is noted, a link to the prompt/conversation would be more useful than version-specific attribution. They share that they'll be switching to a simpler "LLM: Yes" trailer in their company's repository instead.

The discussion touches on broader questions about how open source projects should document AI assistance in contributions, balancing transparency with maintainability of commit messages. While not directly about code changes, this exchange reflects evolving norms around AI-assisted development in the Git ecosystem.
