This is a cover letter for a two-patch documentation series from Git maintainer Junio C Hamano, updating the SubmittingPatches guide. The series follows up on recent mailing list discussions and incorporates feedback from Christian Couder, Derrick Stolee, and Patrick Steinhardt.

The first patch creates a dedicated section for typo fixes, making this common contribution type easier to find in the documentation. The second patch adds new guidance about writing effective cover letters, specifically advising contributors to frame their work in a way that appeals to a broad audience - advice Junio recently gave on-list that wasn't previously documented.

As documentation updates from the maintainer, these changes represent authoritative guidance for contributors. The patches are focused and non-controversial, adding about 25 lines total to SubmittingPatches. The series appears ready for merging, with all reviewer feedback incorporated in this v2 iteration. This continues Git's ongoing effort to keep contributor documentation clear and comprehensive.
