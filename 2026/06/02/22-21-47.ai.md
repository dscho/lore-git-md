This is a performance optimization patch in the pack-objects subsystem, part of Taylor Blau's 4-patch v2 series integrating `--delta-islands` with `--path-walk`. The patch enables reachability bitmaps to work with `--path-walk`, resolving their previously documented incompatibility.

The key technical change removes the forced bitmap disablement when path-walk is active, allowing bitmap traversal to answer requests when possible while falling back to path-walk enumeration otherwise. The implementation:
- Teaches the path-walk object callback to call `index_commit_for_bitmap()` for commits
- Maintains `--objects` flag for internal rev_list while keeping bitmap index enabled
- Handles the `--boundary` flag carefully to avoid bitmap traversal issues

Performance tests show dramatic improvements - up to 99.6% time reduction for small fetches while maintaining identical pack sizes, as the same pack is generated but via bitmap reuse rather than full traversal. The patch includes test coverage in t5310 and updates documentation to clarify the new interaction.

This builds on Derrick Stolee's path-walk filter work and represents a significant optimization for path-walk operations when bitmaps are available. The changes are well-contained and maintain compatibility with existing behavior while unlocking new performance benefits.
