This is the final patch in Taylor Blau's 4-part series to enable `--delta-islands` compatibility with `--path-walk` in `git pack-objects`. The patch removes the documented incompatibility between these options and adds test coverage.

The implementation builds on Derrick Stolee's path-walk filter work by:
1. Calling `propagate_island_marks()` during path-walk for commits (matching the behavior of the regular traversal)
2. Using the new `record_tree_depth()` helper (from patch 2) to maintain tree depth information during path-walk
3. Preserving the commit processing order required by the island algorithm

The changes allow delta-islands to work with path-walk while maintaining bitmap support. The patch includes three new test cases in t5320 that verify:
- Basic path-walk repack respects islands
- Bitmap-enabled path-walk repack respects islands
- Deltas are still allowed within the same island

The implementation appears well-considered, with careful attention to maintaining the same behaviors as the regular traversal. The test coverage is thorough, exercising both the island separation and bitmap interaction cases. This completes the series' goal of removing the documented incompatibility while preserving all existing functionality.
