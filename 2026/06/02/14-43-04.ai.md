This is the second patch in a two-part documentation series from maintainer Junio C Hamano, updating the SubmittingPatches guide with new advice about cover letters. The patch adds a dedicated [[cover-letter]] section that formalizes best practices Junio has previously shared on-list.

The new content (24 lines) provides concrete guidance for contributors on how to effectively introduce their patch series, emphasizing the need to:
- Justify the change's value relative to its risk/cost
- Make the proposal accessible to new readers
- Summarize changes between iterations
- Help both new and returning reviewers engage with the work
