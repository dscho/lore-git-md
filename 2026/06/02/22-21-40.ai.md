This is a performance optimization series in the pack-objects subsystem, building on Derrick Stolee's path-walk filter work. Taylor Blau's 4-patch v2 series enables `--path-walk` to work with both reachability bitmaps and delta-islands, resolving their previously documented incompatibility.

The key changes in this iteration are:
1. A new first patch simplifying p5311 performance tests by removing lookup-table permutations
2. Updated performance metrics showing 98.8% time reduction for small fetches when properly configured path-walk with bitmaps
3. Clarification that stable pack sizes occur because both test cases use path-walk, with HEAD benefiting from bitmap-based reuse

The series maintains the core technical approach from v1: propagating island marks during path-walk via `propagate_island_marks()` while using `record_tree_depth()` for consistent tree-depth recording. Performance testing now properly isolates the path-walk/bitmap interaction effects, showing the optimization's real benefits when correctly configured.

Test coverage remains strong with additions to t5310 (bitmaps) and t5320 (delta-islands), plus the enhanced p5311 performance tests. The changes appear focused and well-motivated, continuing Taylor Blau's work on pack optimizations. The series is now based on the graduated 'ds/path-walk-filters' with only minor adjustments from v1.
