This is a documentation patch (v2) clarifying the `@` prefix requirement for raw Unix timestamps in Git's date parsing. The patch has been reviewed and approved by maintainer Junio Hamano, who notes it will be queued for merging.

The change documents existing behavior that has been in Git since 2012 but was never formally specified - that timestamps under 100,000,000 must be prefixed with `@` to be interpreted as raw Unix timestamps rather than other date formats like YYYYMMDD. The documentation update in `date-formats.adoc` makes this requirement explicit, while new cases in `t0006-date.sh` demonstrate the parsing difference between prefixed and unprefixed timestamps (e.g., `@2000` vs `2000`).

Junio provides minor process feedback about threading v2 patches properly, but confirms the technical content is sound. The patch follows the project's ongoing documentation standardization efforts and has clear test coverage of the behavior being documented. With the maintainer's approval and no outstanding technical concerns, this appears ready for inclusion.
