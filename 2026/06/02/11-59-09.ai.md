This is the first patch in a two-part documentation series introducing b4 configuration for the Git project. Patrick Steinhardt adds two new files to configure the b4 tool for Git's mailing list workflow:

1. `.b4-config` sets two key behaviors:
   - `send-same-thread = shallow` ensures patch series revisions reply to the original cover letter
   - `prep-cover-template` points to a custom template file

2. `.b4-cover-template` provides a standardized cover letter format that includes a range-diff by default showing changes between versions.

The changes are purely additive - no existing files are modified. The patch follows the pattern seen in other projects adopting b4, with configuration focused first on thread management and cover letter consistency. The commit message notes this is just a starting point, leaving room for future additions like automated Cc handling.

As part of the broader effort to document and standardize b4 usage (as indicated in the thread context), this initial configuration provides sensible defaults while being minimally invasive. The implementation looks clean and well-contained, with the template following b4's variable substitution syntax. This aligns with the project's gradual approach to tooling adoption, introducing configuration before promoting the tool in documentation (which will come in patch 2/2).
