This is a bugfix addressing a thread sanitizer (TSAN) race condition in the transport helper code. The patch fixes a race in the `transfer_debug()` function where a static variable was being lazily initialized based on the `GIT_TRANSLOOP_DEBUG` environment variable. Since this function can be called from multiple worker threads, the initialization was unsafe.

The solution moves the initialization of the debug flag to `bidirectional_transfer_loop()` before any worker threads are created, making the access pattern thread-safe. This allows removing the corresponding suppression from `.tsan-suppressions`. The change is straightforward and well-explained, with the commit message clearly describing both the problem and solution.
