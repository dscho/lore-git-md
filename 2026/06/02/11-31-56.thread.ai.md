Thread identity: Bug report about Git for Windows failing to complete clone operations with corrupt pack file errors.

Core problem: Cloning from a remote server (Git 2.47.3) works on Linux but fails on Windows (Git for Windows 2.54.0.windows.1) with error "fatal: pack has bad object at offset 460179591: inflate returned 1". The error suggests either pack file corruption during transfer or platform-specific decompression issues in the Windows implementation.

Key technical details: The failure occurs during pack file handling, specifically during object inflation. The same operation succeeds on Linux, indicating the remote repository is not corrupt and pointing to a Windows-specific issue in either network transfer, zlib decompression, or pack index handling.

Current status: Reported but not yet diagnosed or fixed. The report includes complete version information (Git for Windows 2.54.0.windows.1 failing against server running Git 2.47.3).

Participant positions: Original reporter has provided initial details. No maintainer responses yet.

Related work: This appears to be a Git for Windows-specific issue rather than a core Git problem. The Git for Windows maintainers (Johannes Schindelin) would be the appropriate point of contact for investigation.
