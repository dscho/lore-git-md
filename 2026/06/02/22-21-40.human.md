This is a performance optimization series from Taylor Blau that enhances `git pack-objects` to work efficiently with both `--path-walk` and reachability bitmaps/delta-islands. The 4-patch series builds on Derrick Stolee's earlier path-walk filter work and addresses the remaining integration gaps.

The key improvements in this version are:
1. A new first patch that adjusts the p5311 performance test to properly measure bitmap behavior with path-walk
2. Updated performance results showing dramatic time reductions (up to 99.6%) for small fetches when using path-walk with bitmaps
3. Confirmation that pack sizes remain identical while achieving these speedups

The series maintains the core approach from v1: allowing pack-objects to first try using bitmaps when path-walk is requested, falling back to full traversal only when necessary. The boundary commit handling has been refined based on discussion, and test coverage remains thorough.

Performance analysis shows the combination is particularly effective for recent fetches (1-32 days old), where time reductions of 98.8-99.6% are achieved while maintaining identical pack sizes. The changes appear well-tested and build logically on established work in the pack subsystem.
