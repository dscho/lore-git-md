This is the third patch in Patrick Steinhardt's series to improve TAP output validation in Git's test suite. The patch specifically addresses noise in git-p4 tests where asynchronous shell job-control messages could corrupt TAP output.

The change modifies `t/lib-git-p4.sh` to properly synchronize process cleanup when stopping the p4d daemon and its watchdog. Previously, killing these processes could result in shell messages appearing in the test output, which would break strict TAP parsing (a change coming in patch 4 of this series). The fix adds proper `wait` calls with stderr redirection to ensure these messages are suppressed.

The patch is a straightforward improvement to test infrastructure that doesn't modify test behavior - it just makes the output cleaner and more reliable. As with the rest of the series, this appears ready for merging as it solves a clear problem with minimal risk. The change is well-contained to the git-p4 test helpers and follows the pattern established elsewhere in the test suite for clean process termination.
