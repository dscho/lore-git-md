This is a test infrastructure patch in Taylor Blau's series integrating `--delta-islands` with `--path-walk` in `git pack-objects`. The patch simplifies the p5311 performance test script by removing redundant test permutations for bitmap lookup tables, which are now considered stable after nearly four years of use.

The change drops the dual test runs (with/without lookup tables) that were added in 2022, reducing the test count by half. This cleanup prepares the script for future testing of path-walk variations while maintaining the core `test_fetch_bitmaps()` function. The patch follows Derrick Stolee's suggestion and represents a straightforward simplification of the test harness before introducing new path-walk test cases in subsequent patches.
