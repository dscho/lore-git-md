This is the final patch in Taylor Blau's 4-part series enabling `--delta-islands` to work with `--path-walk` in `git pack-objects`. The patch removes the documented incompatibility between these two features and implements the necessary integration.

The key technical changes are:
1. Adding island mark handling during path-walk by calling `propagate_island_marks()` for commits in the same order as the regular traversal
2. Using the new `record_tree_depth()` helper (from patch 2/4) to maintain consistent tree depth recording during path-walk
3. Removing the warning about `--delta-islands` incompatibility from the documentation
4. Adding comprehensive test coverage in t5320 for path-walk island repacks with and without bitmaps

The implementation follows the approach suggested by Jeff King (Peff) in earlier discussion - performing island side effects directly in the path-walk callback rather than doing a separate walk. This maintains the descendant-first commit ordering required for correct island propagation while avoiding the performance cost of a second traversal.

The patch demonstrates good attention to edge cases like boundary commits and multiple path traversals to the same tree. Performance impact appears minimal since it builds on existing infrastructure rather than introducing new walks. The test additions provide clear verification of the functionality across different configurations.

This completes the series' goal of combining path-walk's space savings with delta-islands' object grouping while maintaining bitmap support. The changes are well-contained and build cleanly on the graduated 'ds/path-walk-filters' work.
