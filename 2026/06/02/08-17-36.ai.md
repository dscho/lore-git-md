Documentation patch clarifying the `@` prefix for raw timestamps in Git's date parsing. This documents and tests a behavior that has existed since 2012 but was never formally documented - that timestamps (particularly those under 100,000,000) must be prefixed with `@` to be interpreted as raw Unix timestamps rather than other date formats like YYYYMMDD.

The patch adds clear documentation in `date-formats.adoc` explaining this requirement and includes test cases in `t0006-date.sh` that demonstrate the difference between prefixed and unprefixed small timestamps (like `@2000` vs `2000`). The tests show how the same numeric value can be interpreted differently - as a raw timestamp when prefixed with `@` versus as a YYYYMMDD-style date when unprefixed.

This is a straightforward documentation improvement with clear test coverage, co-authored by Junio Hamano which suggests it has maintainer approval. The change is small and focused, just documenting existing behavior rather than introducing new functionality.
