Bugfix addressing a thread sanitizer (TSAN) race condition in the transport helper code. The patch fixes a lazy initialization pattern in `transfer_debug()` that was flagged by TSAN as potentially racy when called from multiple worker threads.

The issue stems from a static variable `debug_enabled` being initialized based on the `GIT_TRANSLOOP_DEBUG` environment variable, which could happen concurrently from different threads. The fix moves this initialization to `bidirectional_transfer_loop()` before any worker threads are created, and renames the variable to `transfer_debug_enabled` for clarity. This allows removing the corresponding suppression from `.tsan-suppressions`.

The change is straightforward and appears well-motivated - it eliminates a known race condition while maintaining the same debug functionality. The patch demonstrates good attention to thread safety in code that may run concurrently, though the impact is limited to debugging scenarios where `GIT_TRANSLOOP_DEBUG` is set.
