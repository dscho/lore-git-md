This is a test infrastructure patch series addressing TAP output validation issues, with a particular focus on fixing broken output in the fsmonitor tests.

Patrick Steinhardt's series has four parts:
1. Fixes incorrect TAP output in t7527 (fsmonitor tests) where test numbers were being reused
2. Silences EBUSY errors during test cleanup on Windows
3. Quiets output when killing p4d processes in git-p4 tests
4. Makes `prove` fail when it encounters invalid TAP output, helping catch similar issues earlier

The series stems from a recurring problem where invalid TAP output (specifically in the fsmonitor tests) has been merged. The final patch represents a preventative measure by making the test harness more strict about TAP format violations. The changes are focused and well-explained, with each commit addressing a specific issue while maintaining backward compatibility with existing test behavior.

The patches touch test infrastructure files (t/test-lib.sh), fsmonitor tests (t7527), and git-p4 test helpers. The changes are mechanical rather than behavioral - they improve test reliability without modifying core functionality. The series appears ready for merging as it addresses clear problems with uncontroversial solutions.
