This is a cover letter for a two-patch documentation series from Git maintainer Junio C Hamano, updating the SubmittingPatches guide. The series has already gone through one round of review and incorporates feedback from Christian Couder, Derrick Stolee, and Patrick Steinhardt.

The first patch creates a dedicated section for typo fixes in the documentation, making this common contribution type more discoverable. The second patch adds new guidance about writing effective cover letters, specifically advising contributors to "sell the idea to the widest possible audience" - advice Junio had previously given on-list but wasn't formally documented.

The changes are small (25 lines total) and focused, following Git's standard documentation conventions. As documentation updates from the maintainer himself, they carry authoritative weight. The series appears ready for merging with all review feedback addressed, including typo fixes and wording improvements from reviewers. This continues Git's ongoing effort to keep contributor documentation clear and comprehensive.
