This is a community announcement about the latest edition of Git Rev News, a monthly digest of Git project activity.

Christian Couder announces the publication of edition 135 of Git Rev News, summarizing recent developments on the Git mailing list and in the wider ecosystem. The announcement thanks contributors Matthias Aßhauer and Štěpán Němec for their help with this edition.

The digest provides a curated overview of discussions, patches, and releases that occurred in the Git community over the past month. It serves as a valuable resource for those who want to stay informed about Git development but don't have time to follow the high-volume mailing list closely.

Christian also notes that issue #846 is already open for contributions to the next edition, inviting community members to suggest topics or help with future editions. The announcement follows the standard format for these monthly updates, which are collaboratively produced by a small team of regular editors.
