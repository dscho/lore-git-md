This is a documentation patch series from maintainer Junio C Hamano updating the SubmittingPatches guide. The two changes aim to:

1. Separate typo fixes into their own section in the document, making it clearer how to handle these common contributions
2. Add guidance on writing effective cover letters that explain the motivation and value of a patch series to a broad audience

The motivation comes from Junio realizing that while he frequently gives advice about cover letters in reviews, this wasn't formally documented in the project's contribution guidelines. The changes are focused on improving contributor experience by making expectations more explicit.

As expected from the maintainer, the patches are cleanly separated and focused changes to the documentation. The commit messages will likely follow Junio's usual thorough style. This is a straightforward quality-of-life improvement for new contributors learning the project's patch submission process.
