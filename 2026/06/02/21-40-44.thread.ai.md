Thread identity: Feature patch adding metadata tracking to Git worktrees, including creation timestamps and user-provided descriptions, now using the existing description file mechanism.

Core problem/goal: Enable users to track when worktrees were created and add descriptive notes about their purpose via the existing description file mechanism, making it easier to manage multiple worktrees while maintaining consistency with Git conventions.

Key technical details:
- New metadata stored in `.git/worktrees/<id>/`:
  - `created`: Unix timestamp (auto-recorded on creation)
  - Existing `description` file repurposed for user notes
- New commands/options:
  - `git worktree add --description <text>`
  - `git worktree annotate` subcommand for modifying descriptions
  - Enhanced `git worktree list` with `--show-created`, `--show-description`, `--sort` options
- Main worktree cannot be annotated (no administrative files)
- Pre-existing worktrees show "created: unknown" and sort after timestamped ones
