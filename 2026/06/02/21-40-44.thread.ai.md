Thread identity: Feature patch adding metadata tracking to Git worktrees, including creation timestamps and user-provided descriptions.

Core problem/goal: Enable users to track when worktrees were created and add descriptive notes about their purpose, making it easier to manage multiple worktrees. The implementation maintains backward compatibility while adding new metadata capabilities.

Key technical details:
- New metadata stored in `.git/worktrees/<id>/`:
  - `created`: Unix timestamp (auto-recorded on creation)
  - `note`: free-form user description
- New commands/options:
  - `git worktree add --note <text>`
  - `git worktree annotate` subcommand for modifying notes
  - Enhanced `git worktree list` with `--show-created`, `--show-note`, `--sort` options
- Main worktree cannot be annotated (no administrative files)
- Pre-existing worktrees show "created: unknown" and sort after timestamped ones
