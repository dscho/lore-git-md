Performance optimization in pack-objects subsystem. This is the second patch in Taylor Blau's 4-part v2 series that integrates `--path-walk` with reachability bitmaps in `git pack-objects`, resolving their previous incompatibility.

The patch enables significant performance improvements by allowing bitmap traversal to work alongside path-walk. Key changes include:
- Teaching the path-walk object callback to index commits for bitmaps
- Maintaining bitmap index usage when `--path-walk` is specified
- Carefully handling boundary commits to avoid conflicts between traversal modes

Performance tests show dramatic time reductions (up to 99.6% faster) for small fetches while maintaining identical pack sizes. The implementation builds on Derrick Stolee's path-walk filter work and includes thorough test coverage in t5310 and enhanced p5311 performance tests.

The changes appear well-considered, with clear explanations of both the technical approach and performance impact. This continues Taylor Blau's ongoing work optimizing Git's pack machinery, now addressing a specific limitation in how path-walk interacted with existing bitmap infrastructure.
