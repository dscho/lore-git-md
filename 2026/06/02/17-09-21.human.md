This is the final patch in a v5 series completing the `the_repository` removal effort by migrating the last remaining configuration globals into `struct repo_config_values`. The patch specifically moves the `core.warnAmbiguousRefs` setting from a global variable to repository-specific storage.

The change ensures refname ambiguity warnings are properly scoped to individual repositories, preventing cross-repo state leakage. The patch updates all call sites that previously accessed the global variable, including commands like `cat-file`, `pack-objects`, and submodule handling. The implementation maintains the existing eager parsing behavior since these warnings affect user-facing behavior across many commands.

The series has undergone thorough review and is now merge-ready, with Junio Hamano signaling approval. This completes a significant milestone in eliminating global state from Git's codebase. The changes follow established patterns from prior migrations in this multi-year refactoring effort.

Key technical impacts include modifications to core commands that handle object references, with careful attention to performance-sensitive paths. The work builds on previous `the_repository` removal efforts and aligns with Git's architectural direction toward proper repository isolation.
