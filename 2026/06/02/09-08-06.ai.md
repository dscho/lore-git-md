This is a documentation patch series from the Git maintainer Junio C Hamano, consisting of two small updates to the SubmittingPatches guide. The changes aim to improve contributor guidance around two specific areas: typo fixes and cover letters.

The first patch splits out typo fixes into their own dedicated section in the documentation, making it clearer how these simple contributions should be handled. The second patch adds new advice about writing effective cover letters, specifically recommending that they should aim to "sell the idea to the widest possible audience" - advice Junio recently gave in a mailing list thread that wasn't previously documented.

As these are documentation updates from the maintainer himself, they represent authoritative guidance for contributors. The changes are focused and mechanical, adding about 20 lines total to SubmittingPatches. The patches follow Git's standard documentation conventions and appear ready for merging without controversy. This is part of the ongoing effort to keep Git's contributor documentation clear and comprehensive.
