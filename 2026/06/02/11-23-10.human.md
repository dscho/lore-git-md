This is Junio Hamano's weekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics as of June 2026. The report covers patches that have graduated to 'master', new topics under consideration, stalled efforts, and discarded proposals.

Several significant changes have recently been merged to 'master', including:
- Path-walk traversal integration with object filters (blobless, sparse)
- Linux fsmonitor daemon implementation
- Graph output width limiting with --graph-lane-limit
- Improved "git describe --contains --all" behavior with --match/--exclude
- Notable new topics under review include:
- Optimizations for streaming revision walks using priority queues
- Memory leak fixes in HTTP pack index handling
- A new diff.<driver>.process configuration for external hunk providers
- Reachability bitmap optimizations for pack-objects
- Migration of various config variables to per-repository storage

The report also notes several stalled efforts that may be discarded due to lack of activity, including work on removing the_repository usage in unpack-trees and subtree split recursion improvements.

This status update provides a comprehensive overview of Git's development pipeline, showing both the steady progress of mature features and the influx of new optimizations and capabilities. The breadth of changes - from core algorithms to documentation fixes - reflects the project's continued active maintenance and evolution.
