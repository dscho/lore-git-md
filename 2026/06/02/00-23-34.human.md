Documentation patch review regarding the `@` prefix for raw timestamps in Git's date parsing.

Junio Hamano provides feedback on Luna Schwalbe's documentation patch about the `@` prefix behavior. He questions the formatting of the new paragraph in `date-formats.adoc`, suggesting it might need adjustment to match the style used for other sections in the file (using '+' list continuation rather than four-space indentation).

The review also notes an edge case with the test for '99999999' - while currently marked as ambiguous, Junio observes this couldn't actually be a valid YYYYMMDD date since there's no 99th month or day. This suggests the parsing rules could potentially be tightened to recognize such clearly invalid dates as timestamps even without the `@` prefix, though he acknowledges this would be a separate enhancement.

The feedback is substantive but focused narrowly on documentation presentation and a minor test case observation, leaving the core clarification about the `@` prefix behavior intact. The exchange shows the maintainer engaging with both the content and presentation details of the documentation improvement.
