This is the second patch in Junio C Hamano's two-patch documentation series updating the SubmittingPatches guide. The patch adds a new "Cover Letter" section that provides concrete advice for writing effective cover letters when submitting patch series.

The new section explains that cover letter's purpose is to "sell" the changes to the widest possible audience, with three specific recommendations: (1) make the changes understandable without prior context, (2) ensure new readers can follow along even if they missed earlier iterations, and (3) summarize changes from previous rounds for those familiar with the topic. The advice formalizes guidance Junio has previously given on the mailing list but wasn't documented.

The patch adds 19 lines of clear, practical advice following Git's documentation conventions. As the second part of a maintainer-authored documentation update, it represents authoritative guidance and is likely to be merged without controversy. The changes complement the first patch's typo-fix section reorganization, together improving contributor documentation in focused ways.
