This is the third patch in Patrick Steinhardt's series to clean up TAP output validation issues in Git's test infrastructure. The patch focuses on silencing asynchronous shell job-control messages that appear when killing the p4d daemon and its watchdog process during git-p4 tests.

The change ensures these messages don't interfere with TAP output parsing, which will become stricter in a subsequent patch. The fix is straightforward - adding `wait` calls with stderr redirection to synchronously reap the processes and suppress the "Killed" notifications. The patch touches only the git-p4 test helper script and maintains all existing functionality while making the output cleaner.

This is a mechanical improvement that follows logically from the series' goal of ensuring clean TAP-compliant test output. Like the previous patches, it addresses a specific, well-identified issue without introducing new behavior. The change is small and focused, exactly what you'd want for test infrastructure fixes.
