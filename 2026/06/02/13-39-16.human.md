This is a config subsystem patch that enhances `git_config_parse_key()` to support silent validation, part of a series improving user experience when mistakenly using `=` syntax in `git config` commands.

The patch adds a "quiet" parameter to suppress error messages during key validation, allowing callers to check key validity without generating stderr output. It also makes the key storage parameter optional when only validation is needed. The changes maintain backward compatibility while enabling the new use case for the config hint system in the next patch.

The implementation touches core config parsing logic in `config.c` and updates all callers to pass the new parameter. The validation remains robust while now being usable in contexts where silent failure is preferred. This is the first of two patches in v5 of the series, with the second patch expected to use this new capability for its "did you mean" hint feature.
