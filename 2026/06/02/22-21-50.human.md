This is a refactoring patch in Taylor Blau's series to integrate `--delta-islands` with `--path-walk` in `git pack-objects`. The patch extracts tree-depth recording logic from `show_object()` into a new helper function `record_tree_depth()` to prepare for reuse in a subsequent change.

The change is mechanical and straightforward - it moves the existing delta-islands tree-depth bookkeeping code into a standalone function while maintaining identical behavior. The helper calculates depth by counting path components (slashes) in the object name and updates the maximum depth seen for each tree object in `to_pack`.

This is part of the larger effort to make path-walk work with both reachability bitmaps and delta-islands. The refactoring itself doesn't change functionality but enables cleaner reuse of this logic in future patches of the series. The patch follows the project's style and includes a clear commit message explaining the motivation.
