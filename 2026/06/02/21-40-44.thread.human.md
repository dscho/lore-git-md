This thread introduces a new feature for tracking metadata in Git worktrees, specifically creation timestamps and user-provided descriptions. The patch adds several new commands and options:

- `git worktree add --note` to set an initial description when creating a worktree
- `git worktree annotate` to modify notes on existing worktrees
- Enhanced `git worktree list` with sorting and display options for the new metadata

The implementation stores this information in `.git/worktrees/<id>/` files, maintaining backward compatibility so existing worktrees continue to function normally. The patch includes comprehensive tests and documentation, following Git's established patterns while solving a clear use case for tracking worktree purposes and ages. The changes are self-contained and well-considered, with no apparent conflicts with other ongoing work.
