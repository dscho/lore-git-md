This thread proposes adding metadata tracking to Git worktrees, specifically creation timestamps and user descriptions. The technical approach has been settled - the metadata will reuse the existing (but previously unused) `.git/description` file for the main worktree and corresponding files in linked worktrees, avoiding the need for new file types. Author Norbert Kiesel and maintainer Junio Hamano have agreed on this implementation.

However, Junio has raised concerns about the feature's fundamental value, noting that file modification times would be unreliable for tracking creation dates (since descriptions might be updated later). While the technical solution is sound, Junio remains unconvinced that this functionality is needed and has deferred to community input. The patch now stands at an inflection point - it has cleared implementation hurdles but needs broader support to justify its inclusion. Other contributors may want to weigh in on whether this metadata tracking would meaningfully improve workflows before Junio makes a final decision.
