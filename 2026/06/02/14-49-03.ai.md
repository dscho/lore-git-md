This is an announcement of the Git Rev News newsletter, a regular publication that summarizes recent activity in the Git project. Christian Couder, one of the newsletter editors, is sharing the 135th edition which covers developments from May 2026.

The newsletter provides a digest of mailing list discussions, new features, bug fixes, and other project activity - serving as a valuable resource for those who want to stay informed without closely following every thread. This edition was prepared with help from contributors Matthias Aßhauer and Štěpán Němec.

The announcement also notes that issue #846 is open for contributions to the next edition, indicating the newsletter welcomes community input about noteworthy Git happenings. As a PLC member and experienced contributor, Christian's involvement signals this is an official project communication channel rather than an independent effort.
