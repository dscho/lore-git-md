This is a final cleanup patch in a completed bugfix series for git-gui, now merged after three iterations. The series addressed long-standing issues with repository and worktree detection, particularly in edge cases involving bare repos and missing worktrees.

Maintainer Johannes Sixt provides a small fixup to patch 03/12, removing an unnecessary global variable reference in the `do_gitk` procedure that was missed during the earlier refactoring. The change is straightforward - deleting a line that declares an unused global variable - and aligns with the series' goal of cleaning up legacy code paths.

The series as a whole represents a significant improvement to git-gui's core behavior, standardizing on `git rev-parse` for repository discovery and bringing the GUI tool's behavior in line with core Git's handling of worktrees and bare repositories. With this final tweak applied, the maintainer indicates the series is ready for merging.
