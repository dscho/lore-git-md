This is a refactoring patch in Taylor Blau's series to integrate `--delta-islands` with `--path-walk` in `git pack-objects`. The patch extracts tree-depth recording logic from `show_object()` into a new helper function `record_tree_depth()` to prepare for reuse in an upcoming change.

The key technical change is moving the delta-islands tree-depth bookkeeping into a standalone function that:
1. Takes an object ID and path name as input
2. Calculates depth by counting path components (slashes)
3. Updates the maximum depth for each tree in `to_pack` when needed

This maintains the existing max-depth-wins behavior when a tree paths are traversed multiple ways. The refactoring is clean and mechanical, with no functional changes - the diff shows the logic being lifted verbatim into the new helper before being called from the original location.

The change supports the series' broader goal of making path-walk work with both reachability bitmaps and delta-islands by centralizing tree-depth handling. As noted in the thread context, this builds on Derrick Stolee's path-walk filter work and represents one of the preparatory steps before the main optimization in patch 4/4.
