This is a test infrastructure patch series addressing TAP output validation issues. Patrick Steinhardt fixes several problems that cause invalid TAP output in the test suite, particularly in the fsmonitor tests that were recently merged.

The series has four parts:
1. Fixes broken TAP output in t7527 (fsmonitor tests) where test numbers were incorrectly reported
2. Silences EBUSY errors on Windows test cleanup to avoid noise
3. Quiets output when killing p4d processes in git-p4 tests
4. Makes `prove` fail when it encounters invalid TAP output, which surfaces some preexisting issues

The motivation comes from multiple instances of invalid TAP output slipping into the codebase, most recently via the fsmonitor merge. The changes look straightforward - the fsmonitor fix corrects test numbering, while the other changes clean up test output and add validation. The series demonstrates Patrick's characteristic attention to test infrastructure quality.
