This is patch 11/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `for_each_object()` callback for the packed source implementation.

The changes move the `packfile_store_for_each_object()` function and its helpers from packfile.c to odb/source-packed.c, implementing it as the packed source's `for_each_object` callback. The implementation handles both regular packfile traversal and prefix-based lookups (used by commands like `git cat-file --batch-all-objects`).

Key technical aspects:
- Preserves all existing behavior while moving to the new callback interface
- Handles MIDX (multi-pack-index) files during traversal
- Maintains pack error reporting semantics
- Updates callers in cat-file, pack-objects, commit-graph to use the new interface
- The patch is largely a code movement (260 lines deleted from packfile.c, 258 added to odb/source-packed.c)
- Follows the same pattern as previous patches in the series for converting packed storage operations to odb_source callbacks

This continues the systematic conversion of packed object storage operations to the abstracted interface, bringing the ODB abstraction effort closer to completion. The changes appear mechanical and well-contained, following the established pattern from earlier in the series.
