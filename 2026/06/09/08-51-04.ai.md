This is patch 11/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `for_each_object()` callback for the packed source implementation.

Key changes:
- Moves `packfile_store_for_each_object()` and related helpers from packfile.c to odb/source-packed.c
- Implements the callback to iterate through all objects in packed storage while maintaining existing behavior
- Updates callers in builtin/cat-file.c, builtin/pack-objects.c, commit-graph.c, and odb/source-files.c to use the new interface
- Preserves all existing functionality including prefix matching and various filtering flags
- The implementation handles both regular packs and multi-pack-indexes

The changes are largely mechanical, relocating code rather than altering behavior. The patch continues the pattern seen in earlier parts of the series of moving packed storage functionality into the odb/source-packed implementation while maintaining the same external interface.

This represents another step in the final major restructuring of Git's object database to enable pluggable storage backends. The series has already received substantive architectural review from Karthik Nayak and appears ready for maintainer consideration.
