This is the third patch in Patrick Steinhardt's 17-part series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort. The patch moves the packed source implementation from packfile.{c,h} to new odb/source-packed.{c,h} files, following the same pattern previously used for loose object storage.

Key changes:
- Creates new odb/source-packed.{c,h} files containing the `struct odb_source_packed` definition and its constructor
- Updates Makefile and meson.build to include the new source files
- Removes the packed source implementation from packfile.{c,h}
- Renames `packfile_store_new()` to `odb_source_packed_new()` to match the new location
- The change is primarily code movement with minimal functional impact
- Maintains all existing functionality while better organizing the code
- Follows the architectural pattern established by the loose object storage conversion
- Part of the multi-year effort to enable pluggable storage backends

This mechanical refactoring prepares for subsequent patches that will implement proper `struct odb_source` callbacks for packed storage. The patch has already received architectural approval from Karthik Nayak in the v1 review, with only minor formatting nits that have now been addressed.
