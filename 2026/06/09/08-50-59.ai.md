This is patch 6/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `close()` callback for packed sources, moving the implementation from `packfile.c` to the new `odb/source-packed.c` location and calling it through the generic `odb_source_close()` interface.

Key changes:
- Implements `odb_source_packed_close()` in odb/source-packed.c to handle closing packfiles and MIDX
- Removes the now-redundant `packfile_store_close()` function from packfile.c
- Updates the files backend to call the packed source's close via the generic interface
- Maintains the same behavior of closing all packs except those marked "do-not-close"
- The change is mechanical - no functional differences in how packs are closed
- Touches 4 files with net -19/+17 line changes
- Follows the pattern established in earlier patches of moving functionality to odb/source-packed.c

This continues the systematic conversion of packed storage to the odb_source interface, with each patch implementing another required method. The series remains focused on restructuring without behavior changes, keeping the ODB abstraction effort moving forward.
