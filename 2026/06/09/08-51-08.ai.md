This is patch 15/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch stubs out remaining unimplemented callbacks in the packed object storage implementation.

The changes:
- Adds error-returning stubs for write operations (`write_object`, `write_object_stream`, `begin_transaction`, `write_alternate`) since the packed backend is read-only
- Implements a no-op `read_alternates` callback that returns success
- Wires up these callbacks in the packed source initialization

This is a straightforward patch that completes the callback interface for the packed backend by handling the remaining operations that either aren't supported (writes) or are trivial (reading alternates). The changes are mechanical and follow the same pattern as earlier patches in the series.

The patch is part of the final major restructuring in the multi-year ODB abstraction effort, which aims to enable pluggable storage backends. With this patch, the packed backend now implements all required `odb_source` callbacks while maintaining the existing behavior of being a read-only storage layer.
