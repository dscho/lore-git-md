This is part 2 of Patrick Steinhardt's 17-part series refactoring Git's packed object storage as part of the ongoing ODB (object database) abstraction effort. The patch splits out packfile list management into separate "packfile-list.{c,h}" files to resolve a cyclic header dependency that would arise when introducing the new packed object database source in the next patch.

The change is mechanical - it moves the existing packfile list implementation from packfile.c into new files while maintaining identical functionality. The patch:
- Creates new packfile-list.c with all list management functions
- Adds corresponding packfile-list.h with type declarations
- Updates Makefile and meson.build to include the new compilation unit
- Removes the moved code from packfile.c and simplifies packfile.h

This preparatory work enables the subsequent patch to introduce the packed ODB source without header dependency issues. The change follows the established pattern of the ODB abstraction effort and has already been reviewed in v1 by Karthik Nayak, who confirmed the architectural approach. The series represents the final major restructuring in the multi-year ODB abstraction project.
