This is patch 10/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `read_object_stream()` callback for packed storage, implementing the streaming read interface for packed objects.

Key changes:
- Implements `odb_source_packed_read_object_stream()` in odb/source-packed.c, which finds the pack entry and calls the low-level `packfile_read_object_stream()`
- Updates the files backend to use the new callback via `odb_source_read_object_stream()` rather than the direct `packfile_store_read_object_stream()` call
- Removes the now-unused `packfile_store_read_object_stream()` function from packfile.c and its declaration from packfile.h

The changes are straightforward plumbing work - moving existing functionality into the new callback-based interface while maintaining the same behavior. This continues the pattern seen in previous patches of converting direct packed storage access to go through the odb_source abstraction layer.

The patch touches 4 files with 17 lines added and 17 removed, showing this is primarily a code reorganization rather than introducing new functionality. It builds on the infrastructure established in earlier patches (particularly the `find_pack_entry()` and stream reading logic) while cleaning up now-redundant interfaces.
