This is the second patch in Patrick Steinhardt's 17-part series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort. The patch splits out packfile list management logic into new "packfile-list.{c,h}" files to resolve a header dependency cycle that would occur when introducing the new packed object source.

The changes are purely structural - moving existing code from packfile.{c,h} to the new files while maintaining all functionality. The patch:
- Creates new packfile-list.{c,h} with all packfile list management functions
- Updates Makefile and meson.build to include the new compilation unit
- Removes the moved code from packfile.{c,h}
- Adds necessary includes to maintain compilation

This is a mechanical refactoring that enables the subsequent patch to introduce the packed object source without cyclic header dependencies. The change follows the pattern of previous ODB abstraction work and has no functional impact - it's purely about code organization to support the larger architectural change coming in patch 3.
