This is the second version of Patrick Steinhardt's major refactoring series converting Git's packed object storage to use `struct odb_source` as part of the ongoing ODB (object database) abstraction effort. The 17-patch series follows up on his earlier work that did the same for loose object storage.

The key changes in v2:
- Split out `struct packfile_list` into separate "packfile-list.{c,h}" files to resolve a cyclic dependency
- Fixed a minor formatting issue (extraneous newline)
- Maintains all the core functionality from v1 while improving code structure

The series continues the architectural work of decoupling Git's object storage from specific backends, enabling future pluggable storage implementations. It renames `struct packfile_store` to the more consistent `struct odb_source_packed` and moves the packed source code into the odb/ subsystem.

Reviewer Karthik Nayak had previously confirmed the series was in good shape overall, with only minor feedback addressed in this revision. The changes are largely mechanical conversions to use the new interface rather than direct packfile access, though the diffstat (+1163/-1079 lines across 26 files) shows this is a substantial restructuring.

Patrick notes this represents the last of his major ODB restructuring work, with future changes expected to be more incremental. The series builds on previous work (ps/odb-source-loose) and appears ready for maintainer consideration after this revision.
