This is patch 12/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `count_objects()` callback for the packed source backend.

The changes:
1. Moves `packfile_store_count_objects()` from packfile.c to odb/source-packed.c and renames it to `odb_source_packed_count_objects()`
2. Updates the files backend to call the new interface via `odb_source_count_objects()` rather than directly
3. Removes the now-unused declaration from packfile.h
4. Adds the callback to the packed source's vtable initialization

The implementation remains functionally identical - it still counts objects by summing:
- Objects in the multi-pack-index (if present)
- Objects in each packfile not covered by the MIDX

This continues the mechanical conversion of packed storage functionality to the ODB source interface, with all changes being straightforward code movement rather than behavioral modifications. The patch follows the established pattern seen in previous patches of the series.
