This is patch 4/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ongoing ODB (object database) abstraction effort. The patch makes the relationship between packed storage and its parent "files" source more explicit by changing the generic `struct odb_source` pointer to a specific `struct odb_source_files` pointer.

The change is a preparatory step toward eventually removing the parent pointer entirely, as noted in the commit message. The patch touches 4 files with straightforward mechanical changes to update the type and variable names. While this is a small change in isolation, it's part of the larger architectural work to enable pluggable storage backends by properly abstracting the object database interfaces.

The patch follows cleanly from the previous three in the series (which handled renaming and moving code) and maintains the same careful approach to refactoring that has characterized this multi-year effort. With Karthik Nayak having already approved the architectural approach in v1, this iteration appears ready for maintainer consideration.
