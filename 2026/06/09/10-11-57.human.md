This is the final patch in Harald Nordgren's 14-iteration series adding `git branch --prune-merged` for safe automated local branch cleanup. The series has addressed all major technical concerns, including a recent regression fix for remote-tracking branch behavior.

The patch introduces a `--dry-run` option for `--prune-merged` that shows which branches would be deleted without actually removing them. This provides a safety check before running the actual deletion, particularly useful when using broad patterns like `origin/*`. The implementation:
- Prints "Would delete branch <name>" for each candidate branch
- Maintains all existing safety checks (merged status, HEAD protection, etc.)
- Rejects `--dry-run` when not used with `--prune-merged`

The tests verify that:
- Dry-run output matches what would actually be deleted
- Only properly merged branches are listed
- The option is properly rejected when used alone

This completes the series' goal of providing configurable, safe branch cleanup with multiple layers of protection (warn-only mode, per-branch opt-out, and now dry-run preview). The implementation appears solid with comprehensive test coverage.
