This is patch 5/17 in Patrick Steinhardt's v2 series converting Git's packed object storage to use `struct odb_source` as part of the ongoing ODB (object database) abstraction effort. The patch begins implementing the packed storage backend as a proper `struct odb_source` by:

1. Embedding the base `struct odb_source` in `struct odb_source_packed`
2. Adding the new `ODB_SOURCE_PACKED` type identifier
3. Implementing lifecycle management with a `free` callback
4. Taking ownership of chdir notification handling from the files backend

The changes are mostly mechanical plumbing work to establish the new interface while maintaining existing behavior. The packed source isn't yet fully functional as an independent `odb_source` - that will come in subsequent patches that implement the remaining callbacks. 

This continues the multi-year effort to enable pluggable storage backends in Git's object database, with Karthik Nayak having already reviewed and approved the architectural approach in v1. The changes touch several files but are focused on internal infrastructure rather than user-visible behavior.
