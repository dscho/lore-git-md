This is patch 16/17 in Patrick Steinhardt's series converting Git's packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch refactors MIDX (multi-pack-index) interfaces to explicitly work with packed sources rather than generic odb_source types.

The key change is making MIDX functions accept `struct odb_source_packed*` instead of the more generic `struct odb_source*`, since MIDX operations are inherently tied to packed storage. This involves:

1. Updating all MIDX-related function signatures in midx.h and their implementations
2. Modifying callers throughout the codebase to pass the packed source explicitly
3. Adding necessary downcasts when getting the packed source from repository objects

The changes are mechanical but widespread, touching 13 files with 144 insertions and 129 deletions. The patch maintains existing behavior while making the packed-source relationship more explicit in the type system, which helps prevent misuse and prepares for future changes to the ODB abstraction.

This continues the pattern established in earlier patches of the series, where loose object storage was similarly converted. The changes appear straightforward and well-contained, with no functional changes beyond the type system improvements. The patch follows the established approach from previous iterations, with Karthik Nayak having already reviewed and approved the architectural direction in v1.
