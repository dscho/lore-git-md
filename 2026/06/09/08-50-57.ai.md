This is patch 4/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch makes the relationship between packed storage and its parent "files" source more explicit by changing the generic `struct odb_source *` pointer to a specific `struct odb_source_files *`.

Key changes:
- Replaces the generic `source` field in `struct odb_source_packed` with a specific `files` pointer to the parent files source
- Updates all related function signatures and call sites to use the new type
- Notes this is a temporary step toward completely removing the parent pointer in later patches

The change helps clarify the current architecture while preparing for future work to make the packed source fully independent. The patch is mechanical in nature, with straightforward updates across 4 files (+11/-11 lines). It follows the pattern established in earlier patches of this series to make the ODB abstraction boundaries more explicit.

This continues the multi-year effort to enable pluggable storage backends in Git's object database, with this series representing the final major restructuring of the ODB interface. The change maintains existing behavior while improving code clarity during the transition period.
