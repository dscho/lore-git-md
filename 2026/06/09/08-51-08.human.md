This is patch 15/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch stubs out the final required callback functions for the packed object storage implementation that either aren't needed or are no-ops for this backend.

The patch adds five new callback implementations:
1. `write_object` and `write_object_stream` explicitly fail since the packed backend is read-only
2. `begin_transaction` fails as packed storage doesn't support transactions
3. `read_alternates` succeeds as a no-op (packed storage doesn't handle alternates)
4. `write_alternate` fails since alternates can't be written to packed storage

These stubs complete the interface required by `struct odb_source` while maintaining the packed backend's read-only nature. The changes are straightforward - each callback either returns an error for unsupported functionality or a no-op success. This follows the pattern established earlier in the series and keeps the packed storage behavior consistent with its existing limitations.

The patch is part of the final major restructuring in the multi-year ODB abstraction effort, which aims to enable pluggable storage backends in Git's object database. With these stubs in place, the packed storage now fully implements the odb_source interface.
