This is the final patch in Patrick Steinhardt's 17-part series converting Git's packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort. The patch removes the last coupling between the packed storage backend and its parent "files" source, making the packed source fully standalone. This completes the architectural goal of the series - packed object storage can now operate independently as a proper ODB source.

Key changes in this patch:
- Drops the `files` pointer from `struct odb_source_packed`
- Updates `odb_source_packed_new()` to take ODB/path parameters directly rather than getting them from a parent source
- Modifies all affected call sites to work with the new standalone interface
- Maintains all existing functionality while removing the architectural dependency

The changes are mechanical but important for the ODB abstraction - they demonstrate the packed backend no longer needs any special relationship with the files backend. This was the last major piece of coupling in the series, following previous patches that converted the interfaces and callbacks.

With this patch, the v2 series appears complete and well-reviewed, addressing all feedback from Karthik Nayak's v1 review. The ODB abstraction effort has now reached a significant milestone with packed storage fully decoupled, paving the way for future pluggable storage backends.
