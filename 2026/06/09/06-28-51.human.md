This is a test infrastructure patch in the final stages of a security-focused series adding remote object metadata queries to `git cat-file --batch-command`. The patch moves three utility functions from `t1006-cat-file.sh` to a new shared library `lib-cat-file.sh`.

Chandra Pratap questions whether this refactoring is truly necessary at this stage, noting it seems premature unless subsequent commits require it or it was specifically requested in v11 feedback. The functions being moved are simple string utilities: printing without newlines, converting newlines to NULL bytes, and calculating string length.

The patch itself is mechanically sound - the functions are moved verbatim with no behavior changes. However, the review raises a valid point about motivation: without clear justification for why this change belongs in the security series rather than as a standalone cleanup, it risks appearing as unnecessary churn. The series as a whole has undergone extensive review and is otherwise ready for merging, with all major design questions resolved.
