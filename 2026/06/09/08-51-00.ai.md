This is patch 7/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `reprepare()` callback for packed object storage, moving the implementation from packfile.c to the new odb/source-packed.c location.

Key changes:
- Moves packfile preparation logic (157 lines) from packfile.c to odb/source-packed.c
- Implements `odb_source_packed_reprepare()` as a thin wrapper that resets initialization state
- Updates all callers to use the new `odb_source_packed_prepare()` instead of the old `packfile_store_prepare()`
- Maintains identical behavior while restructuring the code to fit the ODB source abstraction
- Removes now-unused packfile.h declarations for the prepare functions

The patch continues the mechanical conversion work from v1, now focusing on the reprepare functionality. As with previous patches in the series, this appears to be a straightforward relocation of existing code into the new abstraction layer rather than introducing functional changes. The implementation preserves all existing behavior including pack sorting order and garbage reporting.

This represents another incremental step in the multi-year ODB abstraction effort to enable pluggable storage backends. The series has already received substantive architectural review from Karthik Nayak in v1, with only minor formatting nits identified that have since been addressed.
