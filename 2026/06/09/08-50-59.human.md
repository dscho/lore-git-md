This is patch 6/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `close()` callback for packed object storage, moving the implementation from packfile.c to odb/source-packed.c where it belongs in the new architecture.

The changes:
1. Implements `odb_source_packed_close()` to handle closing packfiles and MIDX files
2. Removes the now-obsolete `packfile_store_close()` function
3. Updates the files backend to call the new generic `odb_source_close()` instead of the old packed-specific function

The patch continues the mechanical conversion work with no functional changes - it's about properly wiring up the new abstraction layer. The implementation carefully preserves the existing behavior around packfile closing, including the BUG() check for "do-not-close" packs.

This is part of the final major restructuring in the multi-year ODB abstraction effort, which will enable pluggable storage backends. The series has already received substantive architectural review from Karthik Nayak in v1, with only minor formatting nits identified (now fixed). The changes are well-contained and follow the established pattern from earlier conversions.
