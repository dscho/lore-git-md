This is patch 7/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort. The series is nearing completion, with this patch implementing the `reprepare()` callback for packed object storage.

The patch moves the logic for preparing and repreparing packed sources from `packfile.c` to the new `odb/source-packed.c` location, wiring it up as part of the ODB source interface. Key changes include:

1. Moving packfile preparation logic (loading packs and multi-pack indices) into the new callback
2. Maintaining the same behavior for packfiles (local packs first, then newer packs)
3. Keeping the garbage reporting functionality for orphaned pack files
4. Updating callers to use the new `odb_source_packed_prepare()` function

The changes are largely mechanical, with 157 lines added to the new location and 160 removed from the old one. The patch follows the same pattern used earlier for loose object storage conversion. Karthik Nayak's v1 review confirmed the architectural approach, and this iteration appears to address all previous feedback.

This work is part of the multi-year effort to enable pluggable storage backends in Git's object database, with Patrick noting this is the last major restructuring needed in the ODB abstraction work. The series is well-structured and appears ready for maintainer consideration.
