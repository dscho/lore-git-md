This is patch 13/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `find_abbrev_len()` callback for packed object storage.

The change moves the `packfile_store_find_abbrev_len()` function and its helper functions (`extend_abbrev_len()`, `find_abbrev_len_for_midx()`, `find_abbrev_len_for_pack()`) from packfile.c to odb/source-packed.c, implementing them as the `odb_source_packed_find_abbrev_len()` callback. The functionality remains the same - it calculates the minimum abbreviation length needed to uniquely identify an OID within the packed storage.

Key technical details:
- The implementation handles both regular packs and multi-pack-indexes
- Maintains the same binary search behavior to find neighboring objects
- Updates the files backend to use the new callback interface
- Removes the now-unused declarations from packfile.h

This continues the mechanical conversion pattern seen in previous patches of the series, moving packed storage functionality into the new ODB abstraction layer while preserving existing behavior. The patch is part of the final major restructuring in the multi-year ODB abstraction effort.
