This is v14 of Harald Nordgren's series adding `git branch --prune-merged` for safe automated local branch cleanup, now addressing the critical regression that was blocking merging. The series has evolved through 14 iterations with all major technical concerns addressed.

The key fix in this version resolves the regression where the new warn-only mode was incorrectly affecting `git branch -d -r` behavior for remote-tracking branches. The issue stemmed from the remotes path setting a local force flag without properly setting the DELETE_BRANCH_FORCE bit that `check_branch_commit()` checks. The fix makes flags the single source of truth in `delete_branches()` to prevent such mismatches.

The implementation now properly isolates the new functionality from existing command behavior while maintaining all the safety features developed through previous iterations:
- Three-way branch preservation checks
- Checked-out branch protection
- Configurable opt-out via `branch.<name>.pruneMerged`
- Dry-run support showing exactly what would be deleted

While the author notes some unrelated CI failures on GitHub, the core regression appears fixed based on local testing.
