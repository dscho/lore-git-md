This is the final patch in Patrick Steinhardt's 17-part series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch removes the last coupling between the packed storage backend and its parent "files" source, making the packed source fully standalone.

The key change is removing the `files` pointer from `struct odb_source_packed` and updating all callers to pass the ODB, path, and local flag directly to `odb_source_packed_new()` rather than getting them from the parent source. This affects initialization in `odb/source-files.c` and requires updates to several functions in `odb/source-packed.c` that previously relied on the parent relationship.

The changes are mechanical but important for the architectural goal - they complete the separation of concerns between the packed and loose storage backends. With this patch, the packed source can now operate independently, a key requirement for enabling pluggable storage backends. The patch touches 4 files with 19 lines added and 19 removed, maintaining all existing behavior while improving the code structure.

This concludes the major restructuring work in the ODB abstraction series, representing a significant milestone in the multi-year effort to make Git's object storage more modular. The changes have been reviewed by Karthik Nayak in previous iterations, and the final patch appears ready for maintainer consideration.
