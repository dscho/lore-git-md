This is Junio Hamano's "What's cooking in git.git" report for June 2026, providing a comprehensive overview of the current state of patches in the Git project's integration branches. The report follows Junio's standard format, categorizing patches into graduated topics (merged to 'master'), new topics, stalled topics, cooking topics, and discarded topics.

Key highlights from this report include:

Several performance optimizations have graduated to 'master', including improvements to stash's temporary index handling, streaming revision walks using priority queues, and reachability bitmap generation. These changes demonstrate ongoing work to optimize Git's performance, particularly for large repositories.

The documentation modernization effort continues with multiple patches updating man pages to use the new synopsis style. This is part of Jean-Noël Avila's long-running effort to standardize Git's formatting.

Notable new topics include Patrick Steinhardt's ongoing ODB (object database) abstraction work, which is refactoring Git's object storage layer to support pluggable backends. This represents a significant architectural change that could enable new storage formats in the future.

The report also notes several Windows-specific improvements, including better child process handling and fixes for IPv6 address handling in the Git server. These changes reflect Johannes Schindelin's continued focus on Windows compatibility.

Several patches are marked as stalled or needing rerolls, indicating they require further work before being ready for inclusion. The report serves as both a status update and a gentle nudge to contributors to address outstanding review comments.

This comprehensive report provides maintainers and contributors with a clear picture of what changes are in flight, what's ready for the next release, and what needs further attention. The categorization helps readers quickly assess the maturity of various patches and identify areas where they might want to focus their review efforts.
