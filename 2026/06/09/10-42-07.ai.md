This is a preparatory refactoring patch (part 1/2) for Pablo Sabater's v2 RFC series modifying the experimental `git history reword` command. The patch refactors `commit_tree_with_edited_message()` to accept flags that will be passed through to `commit_tree_ext()`, rather than hardcoding `COMMIT_TREE_EDIT_MESSAGE`.

The change is mechanical and straightforward - it adds a flags parameter to the function signature and updates all callers to pass the existing flag explicitly. This sets up the infrastructure needed for the next patch, which will introduce new flag behavior for handling unchanged commit messages in `git history reword`.

The patch maintains backward compatibility of existing behavior while enabling the planned changes. It follows Git's typical pattern of small, focused preparatory patches that make subsequent functional changes easier to review. The commit message clearly explains the motivation and scope of the change.
