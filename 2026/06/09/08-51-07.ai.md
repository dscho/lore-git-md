This is patch 14/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `freshen_object()` callback for the packed source backend.

Key changes:
- Moves `packfile_store_freshen_object()` from packfile.c to odb/source-packed.c and renames it to `odb_source_packed_freshen_object()`
- Makes `find_pack_entry()` static since it no longer has external callers
- Updates the files backend to use the new callback via `odb_source_freshen_object()` rather than calling the packed implementation directly
- Removes now-unused declarations from packfile.h and odb/source-packed.h

The change is mechanical - the patch preserves the existing freshening behavior while moving it into the new ODB source callback structure. This continues the pattern of converting direct packed storage function calls into indirect calls through the odb_source interface.

This represents another step in the packed storage backend's conversion to the ODB source abstraction, following the same approach used for loose objects. The series appears to be progressing smoothly with no major issues raised in review.
