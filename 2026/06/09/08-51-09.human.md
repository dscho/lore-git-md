This is patch 16/17 in Patrick Steinhardt's series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch focuses on MIDX (multi-pack-index) interfaces.

The key change is making MIDX interfaces explicitly work with `struct odb_source_packed` rather than the more generic `struct odb_source`. Since MIDX functionality is inherently tied to packed storage, the generic interface was misleading - it suggested MIDX could work with other storage types when it cannot.

The patch updates all MIDX-related functions across 13 files to use the packed-specific type. This includes:
- MIDX file writing/verification functions
- Repacking and expiration logic
- Helper functions for MIDX filenames and paths
- Test infrastructure

This change prepares for the next patch which will remove the pointer to the "files" source from the packed source structure. The conversion is mechanical but important for maintaining clear type relationships in the ODB abstraction.

The patch continues the series' pattern of careful, incremental refactoring with thorough updates to all callers. It touches many files (13 modified) but the changes are straightforward type updates rather than functional modifications. The series as a whole represents the final major restructuring in the multi-year ODB abstraction effort.
