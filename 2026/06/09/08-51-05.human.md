This is patch 12/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `count_objects()` callback for packed storage by moving the implementation from packfile.c to odb/source-packed.c.

The changes are straightforward:
1. Moves `packfile_store_count_objects()` to become `odb_source_packed_count_objects()`
2. Updates the files backend to call the new interface
3. Removes the old implementation and declaration
4. Wires up the callback in the packed source initialization

The implementation counts objects by:
- Summing objects from the multi-pack-index (if present)
- Iterating through individual packfiles (excluding those already counted via MIDX)
- Returning the total count via the output parameter

This continues the mechanical conversion work of the series, with no functional changes. The patch follows the established pattern of moving functionality into the odb/ subsystem while maintaining the same behavior. With this change, another required odb_source callback is properly implemented for packed storage.
