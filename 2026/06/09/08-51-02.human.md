This is patch 9/17 in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort.

The patch moves the `read_object_info()` functionality for packed objects into the new `odb/source-packed.c` implementation and wires it up as a callback. Key changes include:

1. Moves `find_pack_entry()` to the packed source implementation (though it remains temporarily exposed)
2. Implements the `read_object_info` callback with the same logic previously in `packfile_store_read_object_info()`
3. Updates all callers to use the new interface via `odb_source_read_object_info()`

The changes are largely mechanical - the core logic remains the same but is now properly encapsulated as part of the ODB source abstraction. The patch touches 5 files with 79 lines added and 78 removed, showing this is primarily a code reorganization rather than functional change.

This continues the pattern established in earlier patches of the series, systematically converting packed object handling to the new abstraction layer. The work is part of the multi-year effort to enable pluggable storage backends in Git's object database.
