This is patch 13/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `find_abbrev_len()` callback for packed object storage.

The change moves the implementation of `packfile_store_find_abbrev_len()` and its helper functions from packfile.c to odb/source-packed.c, renaming it to `odb_source_packed_find_abbrev_len()`. The functionality remains the same - it still determines the minimum abbreviation length needed to uniquely identify an OID within the packed storage by examining nearby objects in packfiles and MIDX files.

The patch follows the established pattern of the series by:
1. Moving existing packed storage functionality into the new odb/source-packed.c
2. Wiring it up as a callback in the odb_source vtable
3. Updating callers to use the new interface

This is a mechanical refactoring with no behavior change, continuing the multi-year effort to enable pluggable storage backends in Git's object database. The series has already received substantive architectural review from Karthik Nayak and appears ready for maintainer consideration.
