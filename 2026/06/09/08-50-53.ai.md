This is a major refactoring patch series from Patrick Steinhardt, part of the ongoing ODB (object database) abstraction effort. The v2 series converts the packed object storage backend into a proper `struct odb_source`, following the same pattern previously applied to the loose object storage. 

Key changes in v2:
- Split out `struct packfile_list` into separate "packfile-list.{c,h}" files to resolve a header dependency cycle
- Fixed an extraneous newline
- Maintains the same core changes from v1:
  - Renames `struct packfile_store` to `struct odb_source_packed`
  - Moves packed source code into the odb/ subsystem
  - Implements all required odb_source callbacks for packed storage
  - Updates midx and repack interfaces to work with the new abstraction

The series touches 26 files (+1163/-1079 lines), with most changes being mechanical conversions to use the new interface rather than functional changes. Patrick notes this represents the last of his major ODB restructuring work, with future changes expected to be more incremental.

Karthik Nayak's v1 review confirmed the architectural approach and identified only minor formatting nits, which have been addressed. The series appears ready for maintainer consideration after this v2 iteration. This work is part of the multi-year effort to enable pluggable storage backends in Git's object database.
