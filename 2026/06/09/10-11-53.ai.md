This is part 2/6 of Harald Nordgren's v14 series introducing `git branch --delete-forked` (formerly `--prune-merged`), which provides safe automated local branch cleanup. The series has undergone extensive review over 14 iterations, with all major technical concerns now resolved.

The current patch introduces a warn-only mode for `delete_branches()` and `check_branch_commit()`, allowing bulk operations to continue after encountering unmerged branches rather than erroring out. The key technical changes include:

1. New flag `DELETE_BRANCH_WARN_ONLY` that makes unmerged branch checks emit warnings instead of errors
2. Refactored flag handling in `delete_branches()` to use bitflags consistently
3. Preservation of existing error behavior for direct `git branch -d` calls while enabling warnings for bulk cleanup path

The implementation carefully maintains all existing safety checks (like branch merge state verification) while adding the new warning capability. This change supports the series' goal of safe automated cleanup by allowing tools to report problematic branches without failing the entire operation. The patch includes comprehensive updates to the branch deletion internals while keeping the external behavior unchanged for existing callers.
