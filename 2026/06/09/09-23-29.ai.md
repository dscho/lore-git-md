Feature addition to `git switch` introducing an idempotent branch switching option.

This patch adds a new `--ensure` (`-e`) flag to `git switch` that combines branch creation and switching into a single idempotent operation. The key behaviors are:

1. When the target branch doesn't exist, it acts like `git switch -c` to create and switch to the new branch
2. When the branch exists, it simply switches to it without changing the branch tip
3. With `--track`, it updates the branch's upstream configuration when switching to an existing branch, using either an explicit start-point or the current branch

The implementation handles several edge cases:
- Fails in detached HEAD state when no start-point is available for tracking
- Properly integrates with existing tracking options (`--track`, `--no-track`)
- Includes comprehensive tests covering creation, tracking updates, and failure cases

The motivation is to simplify workflows where users frequently switch between topic branches and may not know if a local branch already exists. This eliminates the need to first check branch existence before choosing between `switch` and `switch -c`.

- Clean integration with existing switch/checkout machinery
