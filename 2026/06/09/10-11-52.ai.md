This is the first patch in v14 of Harald Nordgren's series adding `git branch --delete-forked` (formerly called `--prune-merged`). The series provides safe automated cleanup of local branches that have been merged upstream.

The patch introduces the foundational `--forked` filter for `git branch --list`, which identifies branches whose upstream matches a given ref or pattern. This will be used by the deletion functionality in later patches. Key aspects:

- Adds `--forked <branch>` option that accepts either exact refs (like "origin/main") or glob patterns (like "origin/*")
- Multiple `--forked` options can be combined to widen the filter
- Works with existing filters like `--merged` and `--no-merged`
- Includes comprehensive tests covering exact matches, glob patterns, combination with other filters, and error cases

The implementation resolves refs/patterns to full refnames for exact matches while applying globs to shortened branch names (so "origin/*" works as expected). The filter checks each branch's configured upstream against the patterns.

This is a well-tested building block for the series' ultimate goal of safe branch cleanup. The patch follows Git's established patterns for ref filtering and includes thorough documentation. With the critical regression from earlier versions now fixed in this series, this foundational piece appears ready for inclusion.
