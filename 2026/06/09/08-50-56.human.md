This is the third patch in Patrick Steinhardt's 17-part series refactoring Git's packed object storage as part of the ODB (object database) abstraction effort. The patch moves the packed object source implementation from packfile.{c,h} to new odb/source-packed.{c,h} files, following the same pattern previously used for loose object storage.

The changes are primarily mechanical:
- Creates new odb/source-packed.{c,h} files with the packed source implementation
- Updates Makefile and meson.build to include the new files
- Removes the implementation from packfile.{c,h}
- Renames packfile_store_new() to odb_source_packed_new() for consistency

This continues the architectural work to separate the packed storage backend from the generic packfile code, making it easier to implement alternative storage backends in the future. The patch appears straightforward with no functional changes - it's purely moving and renaming code to better organize the ODB subsystem.

This is part of the multi-year effort to enable pluggable storage backends in Git's object database, with Patrick Steinhardt being the primary driver of this architectural change. The series has already received positive architectural review from Karthik Nayak in v1.
