This is the first patch in Patrick Steinhardt's v2 series converting packed object storage to use `struct odb_source` as part of the ongoing ODB abstraction effort. The patch performs a mechanical rename of `struct packfile_store` to `struct odb_source_packed` to better reflect its role as an object database source.

The change aligns the packed storage backend's naming with the project's architectural direction, where all storage backends are being converted to implement the `odb_source` interface. While purely a rename at this stage, it sets up for subsequent patches that will implement the full `odb_source` callbacks. The patch touches 3 files with 46 line changes, all straightforward identifier renames.

This continues the multi-year effort to enable pluggable storage backends in Git's object database, following the same pattern previously applied to loose object storage. The series has already received substantive architectural review from Karthik Nayak in v1, with only minor formatting nits that have now been addressed.
