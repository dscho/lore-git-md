This is a performance optimization patch for `git ls-files` that has already received technical review and is now in the final submission phase, with the only remaining issue being proper email threading.

The patch series from Tamir Duberstein optimizes `git ls-files --deleted` and `--modified` when used with pathspecs by applying pathspec filtering before making expensive `lstat()` calls. The key innovation is doing this optimization only for single pathspec cases while preserving the current behavior for multiple pathspecs or wildcards. Performance improvements are substantial - one test case showed a reduction from 60.7 seconds to 1.1 second.

Jeff King (Peff) reviewed the technical aspects of the patch and identified a performance concern with many pathspecs that was addressed in v2. The technical content appears sound and reviewed. The only current discussion is about submission mechanics - Junio C Hamano provided detailed guidance on maintaining proper email threading for patch revisions, which Tamir has acknowledged and committed to following in future submissions.

This appears to be a well-considered optimization that's ready for merging once the submission format is corrected.
