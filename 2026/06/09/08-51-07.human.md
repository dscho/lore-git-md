This is patch 14/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort. The patch wires up the `freshen_object()` callback for packed storage, completing the removal of direct `find_pack_entry()` calls from packfile.c.

The changes are straightforward:
1. Moves `packfile_store_freshen_object()` to `odb/source-packed.c` as `odb_source_packed_freshen_object()`
2. Updates the files backend to call the new interface
3. Makes `find_pack_entry()` static since it now has no external callers
4. Removes now-unused declarations from headers

This continues the pattern seen in previous patches of the series - moving functionality into the new abstraction layer with minimal behavioral changes. The patch is well-contained (26 lines added, 29 removed across 5 files) and follows the established approach. With this change, the packed storage backend now implements all major odb_source callbacks.

The series as a whole represents the final major restructuring in the multi-year ODB abstraction effort, which will enable pluggable storage backends. Previous reviews from Karthik Nayak have confirmed the architectural approach, and this patch appears to be a straightforward continuation of that work.
