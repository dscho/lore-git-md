This is patch 10/17 in Patrick Steinhardt's series converting packed object storage to use `struct odb_source` as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_stream()` callback for packed object storage, moving the implementation from packfile.c to odb/source-packed.c.

Key changes:
- Implements the `read_object_stream()` callback in odb/source-packed.c, using the existing `find_pack_entry()` and `packfile_read_object_stream()` functions
- Updates the files backend to call the new callback via the odb_source interface rather than directly
- Removes the now-unused `packfile_store_read_object_stream()` function from packfile.c
- Touches 4 files with net -17 lines (mostly removing the old interface)

The changes are mechanical and follow the same pattern as previous patches in the series, continuing the conversion of packed storage to the new ODB source abstraction. This represents incremental progress toward the larger goal of enabling pluggable storage backends.

The patch appears well-contained and builds on the architectural approach that was already reviewed and approved in earlier iterations of the series. No new technical concerns are introduced - this is straightforward implementation of an expected interface.
