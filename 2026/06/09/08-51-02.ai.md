Refactoring patch in Patrick Steinhardt's ODB abstraction series, implementing the `read_object_info()` callback for packed object sources.

This patch moves the logic for reading object information from packed storage into the new `odb/source-packed.c` implementation, wiring it up as the `read_object_info()` callback. The key changes are:

1. Moves `find_pack_entry()` and implements new `odb_source_packed_read_object_info()` callback
2. Updates callers to use the new interface via `odb_source_read_object_info()` rather than direct `packfile_store_read_object_info()` calls
3. Temporarily exposes `find_pack_entry()` while other callers still need it (to be made file-local in later patches)
4. Renames `fill_pack_entry()` to `packfile_fill_entry()` and makes it for use by remaining packfile.c callers

The changes are largely mechanical, with the core logic remaining the same but now properly encapsulated as part of the ODB source abstraction. The patch continues the pattern established in earlier patches of moving packed storage functionality into the new odb/source-packed.[ch] files while maintaining existing behavior.

This is part of the multi-year effort to enable pluggable storage backends by abstracting Git's object database access. The series has received substantive architectural review from Karthik Nayak and appears ready for maintainer consideration after this v2 iteration.
