This is a refactoring patch from Patrick Steinhardt, part 5/17 in the v2 series converting packed object storage to use `struct odb_source` as part of the ODB abstraction effort.

The patch begins implementing the packed storage backend as a proper `struct odb_source` by:
1. Embedding the base `struct odb_source` in `struct odb_source_packed`
2. Assigning it the new `ODB_SOURCE_PACKED` type
3. Wiring up lifecycle management with a `free` callback
4. Taking ownership of chdir notification handling from the files backend

Key technical changes:
- Adds downcast helper `odb_source_packed_downcast()`
- Moves packfile cleanup from `packfile_store_free()` to new `odb_source_packed_free()`
- Updates the files backend to use `odb_source_free()` instead of direct packed store cleanup
- Removes now-unused `packfile_store_free()` function
- The packed source is not yet fully functional as it still lacks other required callbacks
- Follows same pattern previously applied to loose object storage
- Maintains existing behavior while restructuring internals

This continues the multi-year effort to enable pluggable storage backends in Git's object database, with Patrick noting this is the last major ODB restructuring needed. The changes are mechanical and focused on the architectural transformation rather than functional changes.
