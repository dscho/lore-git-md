This is Junio Hamano's "What's cooking in git.git" report for June 2026, providing a comprehensive overview of the current state of in-flight Git development topics. The report categorizes patches into several buckets:

**Graduated to 'master'** includes several notable changes:
- Optimizations to `git stash -p` by reusing cached index entries
- A fix for GIT_WORK_TREE variable leakage in receive-pack
- Sparse index optimizations for `git restore --staged`
- Documentation updates converting several commands to modern synopsis style
- Code cleanup removing deprecated commit list functions
- Performance improvements to commit reachability calculations

**New Topics** introduces several significant efforts:
- Patrick Steinhardt's ongoing ODB (object database) abstraction work with packed object source refactoring
- A new `remote-object-info` command for `git cat-file` to fetch object metadata without downloading
- Windows process handling improvements for cleaner child process termination
- Configuration changes to ignore include directives via new `--no-includes` option
- **Stalled** topics that may need attention or could be discarded include:
  - `the_repository` removal in unpack-trees
  - Recursion fixes for git-subtree

- **Cooking** topics still under review include:
  - HTTP redirect handling fixes
  - Recommendations to use b4 for patch submission
  - Streaming walk optimizations
  - Rebase improvements for symref handling
  - Experimental `git history drop` command
  The report also notes several documentation updates, test fixes, and configuration migrations that are progressing through the integration branches.

This snapshot shows Git's development continuing to focus on performance optimizations, repository infrastructure improvements, and better tooling for contributors, while maintaining stability through careful integration and testing.
