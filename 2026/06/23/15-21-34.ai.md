This is a **feature enhancement** to the existing `help.autoCorrect=prompt` functionality, refining the v2 patch after Junio C Hamano and Justin Tobler’s feedback. The patch now focuses solely on including the user’s original arguments in the autocorrect prompt (e.g., `Run 'git checkout neo' instead [y/N]?`), addressing a usability gap where users were previously unsure whether their arguments would be preserved.

The implementation updates `help_unknown_cmd()` in `help.c` to accept the full argument vector, allowing the prompt to display the complete corrected command. Callers that cannot provide the argument vector (like `builtin/help.c`) pass `NULL`, triggering a graceful fallback to the old prompt format. The change is backward-compatible and touches only the help subsystem (`help.c` and its test file), with no new symbols exposed. Test coverage verifies the new behavior while dropping tests for the controversial default-interactive behavior removed in v2.
