This is a **feature patch** that refines Git’s interactive typo correction when `help.autoCorrect=prompt` is set. The patch updates the prompt to show the full corrected command, including arguments (e.g., `Run 'git checkout neo' instead [y/N]?`), addressing a usability gap where users were unsure if their original arguments would be preserved. Junio’s review highlights a critical oversight: the patch does not shell-quote arguments, which could break commands with spaces or special characters (e.g., `git commit -m "Hello world"` would become malformed). He also points out that the patch mistakenly removes the interactive prompt for single-command suggestions, reducing functionality.

The patch touches `help.c` and its test file, with a clean but incomplete implementation. While the core idea—preserving arguments in the prompt—is sound, the current version introduces regressions (missing shell quoting, removed interactivity) and does not apply cleanly to the main branch. Junio’s feedback suggests this needs a v3 to fix these issues before it can be considered for merging. The patch is narrowly scoped and uncontroversial in principle, but the execution flaws make it unready for now. Watch for a revised version that addresses quoting and restores the removed functionality.
