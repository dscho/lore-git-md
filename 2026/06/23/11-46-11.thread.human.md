This GSoC 2026 project by Siddharth Shrimali successfully delivered a solution for safely reclaiming disk space in partial clones by pruning unneeded promisor objects. The work introduces `git maintenance run --task=gc-promisor`, a new maintenance task that removes unreachable promisor objects older than a configurable grace period (default 30 days) while preserving the ability to re-fetch them if needed. The implementation is robust, featuring per-remote `.keep` files with timestamps and remote-specific markers to prevent data loss, a `--dry-run` flag for safe previews, and integration with the existing `git maintenance` scheduler to run after `gc`.

The project touched key files like `promisor-remote.c` and `builtin/maintenance.c`, adding new symbols such as `cmd_maintenance__gc_promisor()` and config keys like `maintenance.gcPromisor.enabled`. Performance testing on large repositories (up to 15 remotes and 1GB+ promisor packs) showed minimal impact on fetch latency (<5% increase), and the new test suite (`t/t5329-partial-clone-prune.sh`) covers safety, re-fetch fallback, and multi-remote scenarios.
