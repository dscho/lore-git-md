This is Junio's biweekly "What's cooking in git.git" report for June 2026, summarizing the state of all in-flight topics as the project prepares for the Git 2.55 release. The tree is now feature-frozen, with only a few last-minute fixes expected to graduate to `master` before the final release.

The report highlights several key themes. Performance optimizations are prominent: Kaartic Sivaraam's `kk/merge-base-exhaustion` stops merge-base walks early when one side's commits are exhausted, yielding significant speedups for one-sided histories, while Taylor Blau's `tb/pack-path-walk-bitmap-delta-islands` enables concurrent use of reachability bitmaps and delta islands with `--path-walk`. The object database abstraction work continues with Patrick Steinhardt's `ps/odb-source-packed` and follow-up topics (`ps/connected-generic-promisor-checks`, `ps/odb-generalize-prepare`, `ps/libgit-in-subdir`), which refactor packed object sources and prepare for generic promisor object checks.

Several new user-facing features are nearing completion. Patrick Steinhardt's `ps/refs-writing-subcommands` adds `git refs create|delete|update|rename` subcommands, while Hariom Verma's `hn/branch-delete-merged` introduces `git branch --delete-merged` to remove merged local branches. The experimental `git history` command gains new subcommands: Hariom's `hn/history-squash` for folding ranges and Patrick's `ps/history-drop` for removing commits. Phillip Wood's `pw/status-rebase-todo` improves `git status` output during rebase by better parsing the todo list.

Windows compatibility remains a focus. Johannes Schindelin's `js/win32-localtime-r` fixes 32-bit Windows builds, while the graduated `js/objects-larger-than-4gb-on-windows-more` series (7 patches) enables handling objects larger than 4GB by switching to `size_t` for object sizes. Johannes Sixt's `hn/macos-linker-warning` silences Xcode 15 linker warnings about duplicate library archives.

Documentation updates are active. Junio's `jc/submittingpatches-design-critiques` clarifies how to handle design critiques in patch submissions, while Karthik Nayak's `kh/submittingpatches-trailers` updates trailer usage guidance. Weiyi Yuan's `wy/doc-clarify-review-replies` advises batching rerolls and limiting frequency to one per day.

Some topics are stalled or awaiting rerolls. Kaartic's merge-base optimization needs a reroll, as does D. Ben Knoble's Meson USE_NSEC build knob. Jonathan Nieder's subcommand autocorrection and Jiang Xin's worktree includeIf conditions have been stalled for over a month. The report also notes several topics cooking in `next` that are likely to stay there until the next cycle, including Patrick's reference backend work (`ps/refs-avoid-chdir-notify-reparent`) and Taylor's midx incremental base fixes.

The report serves as a snapshot of the project's state at feature freeze, with the focus shifting to regression fixes and final polish before the 2.55 release.
