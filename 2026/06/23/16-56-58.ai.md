This is Junio C Hamano’s "What’s cooking in git.git" report for June 2026 (#09), summarizing the state of in-flight topics as Git 2.55-rc2 enters deep feature-freeze. Below is the technical brief for a follow-up AI summarizer session.

The report covers 38 topics, grouped into three sections: Graduated to 'master' (3 patches), Stalled (3 topics), and Cooking (32 topics). The "Cooking" section is the most relevant for ongoing work, with topics marked as needing review, expecting a reroll, or waiting for responses.

Key subsystems and efforts touched by in-flight topics include:
- **Object database (ODB) abstraction**: Patrick Steinhardt’s `ps/odb-source-packed` (merged to 'next') refactors the packed object source into a proper `struct odb_source`, and follow-up topics (`ps/connected-generic-promisor-checks`, `ps/libgit-in-subdir`, `ps/odb-generalize-prepare`) build on this to generalize connectivity checks, move libgit.a sources into a dedicated `lib/` directory, and introduce a unified `odb_prepare()` interface.
- **Reference backends**: `ps/refs-avoid-chdir-notify-reparent` (12 commits) converts reference backends to use absolute paths internally, eliminating `chdir_notify_reparent()` calls and fixing a memory leak in repository construction. `ps/refs-writing-subcommands` (5 commits) adds new "create", "delete", "update", and "rename" subcommands to `git refs`.
- **Performance optimizations**: Karthik K’s `kk/merge-base-exhaustion` (6 commits) optimizes merge-base computation by terminating early when one side’s exclusive commits are exhausted. Taylor Blau’s `tb/pack-path-walk-bitmap-delta-islands` (5 commits, merged to 'next') enables reachability bitmaps and delta-islands with `--path-walk` in `git pack-objects`. Karthik K’s `kk/prio-queue-cascade-sift` (1 commit) and `kk/prio-queue-get-put-fusion` (2 commits) optimize priority queue operations for commit traversal.
- **Connectivity checks**: `ps/connected-generic-promisor-checks` (4 commits) refactors connectivity checks to search for promisor objects generically via the ODB interface, enabling support for non-packfile repositories.
- **Repository setup and global state**: `ps/setup-drop-global-state` (8 commits, merged to 'next') removes remaining global state (`git_work_tree_cfg`, `is_bare_repository_cfg`) from `setup.c`, tying configuration to repository instances. `ty/migrate-ignorecase` (2 commits) and `ty/migrate-trust-executable-bit` (3 commits) migrate `core.ignorecase` and `core.trust_executable_bit` into `struct repo_config_values`.
- **Experimental commands**: `hn/history-squash` (4 commits) and `ps/history-drop` (10 commits) extend the experimental `git history` command with "squash" and "drop" subcommands, allowing range folding and commit removal with descendant replay. `tc/replay-linearize` (3 commits) adds a `--linearize` option to `git replay` to drop merge commits.
- **Documentation updates**: `jc/submittingpatches-design-critiques` (1 commit, merged to 'next') clarifies how to address design critiques in commit messages. `kh/submittingpatches-trailers` (5 commits, merged to 'next') updates trailer documentation to encourage standard trailer use. `wy/doc-clarify-review-replies` (2 commits) advises batching patch rerolls and replying to reviews before rerolling.
- **Test infrastructure**: `mm/test-grep-lint` (6 commits) introduces a `greplint` tool to detect bare `grep` assertions in tests and converts existing tests to use `test_grep`. `mm/diff-process-hunks` (6 commits) adds `diff.<driver>.process` to allow external tools to control which lines Git considers changed.
- **Protocol v2 and remote operations**: `ps/cat-file-remote-object-info` (12 commits) adds `remote-object-info` to `git cat-file --batch-command`, allowing clients to request object metadata (e.g., size) from a remote server without downloading the object. The client dynamically filters format placeholders based on server-advertised capabilities.
- **Configuration and usability**: `mh/fetch-follow-remote-head-config` (8 commits, merged to 'next') adds `fetch.followRemoteHEAD` to provide a default for `remote.<name>.followRemoteHEAD`. `cl/conditional-config-on-worktree-path` (2 commits, stalled) proposes `includeIf.worktree` and `includeIf.worktree/i` conditions for configuration files. `za/completion-hide-dotfiles` (2 commits) updates path completion to hide dotfiles by default unless explicitly requested.
- **Merge machinery**: `en/ort-harden-against-corrupt-trees` (5 commits, merged to 'next') hardens the "ort" merge backend against corrupt trees by aborting on duplicate entries or non-adjacent D/F conflicts.
- **Windows and platform compatibility**: `hn/macos-linker-warning` (1 commit, merged to 'master') silences a macOS linker warning about duplicate library archives. `js/win32-localtime-r` (1 commit, merged to 'master') fixes a build issue for 32-bit Windows. `ps/gitlab-ci-windows` (1 commit, merged to 'master') migrates GitLab CI Windows builds away from Chocolatey.

Notable stalled topics include `jt/config-lock-timeout` (config file locking retries), `js/parseopt-subcommand-autocorrection` (subcommand autocorrection in `parse-options`), and `cl/conditional-config-on-worktree-path` (worktree-scoped `includeIf` conditions). These have been stalled for over a month due to unresolved review comments.

The report also highlights several topics needing review or rerolls, including `ps/refs-avoid-chdir-notify-reparent`, `ps/libgit-in-subdir`, `ps/odb-generalize-prepare`, `ty/migrate-trust-executable-bit`, `ps/history-drop`, and `mm/diff-process-hunks`. Performance-related topics (`kk/merge-base-exhaustion`, `tb/pack-path-walk-bitmap-delta-islands`) and experimental command extensions (`hn/history-squash`, `tc/replay-linearize`) are also active.

Key names introduced or modified include:
- Configuration keys: `fetch.followRemoteHEAD`, `promisor.acceptFromServerUrl`, `branch.<name>.deleteMerged`, `diff.<driver>.process`.
- Command options: `git refs create|delete|update|rename`, `git history squash|drop`, `git replay --linearize`, `git cat-file --batch-command remote-object-info`, `git branch --delete-merged`, `git checkout --track=... --fetch`.
- Functions and structs: `odb_prepare()`, `struct odb_source`, `struct repo_config_values` (fields `ignore_case`, `protect_hfs`, `protect_ntfs`, `trust_executable_bit`), `repo_ignore_case()`, `repo_protect_hfs()`, `repo_protect_ntfs()`.
- Test helpers: `test_grep`, `greplint`, `nth_line()`.
- Protocol capabilities: `object-info`.

Likely points of contention include the `ps/refs-avoid-chdir-notify-reparent` approach to absolute paths (review comments suggest potential recursion issues), the `mm/diff-process-hunks` external hunk provider design (reviewers have raised concerns about integration complexity), and the `ps/cat-file-remote-object-info` dynamic capability filtering (review comments question the safety of the allow-list approach). The `tc/replay-linearize` topic may also spark debate about the semantics of dropping merge commits in a replay context.
