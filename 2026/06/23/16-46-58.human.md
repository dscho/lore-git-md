This is the second release candidate for Git v2.55.0, a major update with 486 non-merge commits from 85 contributors (30 of them new). The release notes draft covers a wide range of improvements, fixes, and internal changes.

Key user-facing features include parallel hook execution (configurable via `hook.jobs`), a new `git format-rev` builtin for pretty-printing revision expressions, and `git history fixup` for amending commits. The fsmonitor daemon is now available on Linux, and `git push` can target remote groups (e.g., `git push all`). The "ort" merge backend and sparse-checkout handling see further refinements, and `git checkout -m` now stashes local changes automatically when switching branches.

Performance work is substantial: reachability bitmap generation is significantly faster, revision traversal uses priority queues for date-sorted walks, and `git restore` avoids expanding the sparse index unnecessarily. The ODB layer gains an in-memory source for tentative objects, and the repack machinery supports incremental MIDX updates. Windows builds benefit from gentler process termination and fixes for >4GB object handling.

Notable fixes address edge cases in `git backfill`, `git cherry`, `git grep`, and promisor remote handling. The sideband protocol now sanitizes control characters by default (with an escape hatch for ANSI colors), and the test suite has been hardened against `set -e` issues. Documentation improvements include a synopsis-style conversion for many man pages and clarifications for `push.default=simple` and raw timestamp formats.

The release candidate is well-tested, with CI improvements to catch regressions earlier. While the changelog is long, the changes are incremental and focused—no single feature dominates, and the overall impression is of steady progress across many subsystems. Worth testing if you rely on hooks, fsmonitor, or large repositories.
