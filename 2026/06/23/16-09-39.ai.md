The only substantive feedback is that the prompt string should shell-quote the arguments so that cut-and-paste works correctly. Junio gives a concrete example: `git comit -m "Hello world"` should produce a prompt that preserves the quotes, not one that would misinterpret the arguments. He is puzzled by this change and asks for clarification, but the patch does not explain it in the commit message or cover letter. The removal looks like an accidental regression rather than an intentional design choice.

He instructs the author to rebase so that v2 applies directly to the public tree, avoiding the impression that the patch depends on earlier, flawed iterations.
