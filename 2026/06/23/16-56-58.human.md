This is Junio C Hamano’s biweekly “What’s cooking in git.git” report for June 2026, summarizing the state of all in-flight topics as Git 2.55 enters deep feature-freeze.

Git 2.55-rc2 has been tagged, so the tree is now in deep freeze: no new topics will graduate from ‘next’ to ‘master’ until after the final release. The report lists 47 topics, grouped by their integration branch: 11 have already graduated to ‘master’, 2 are stalled (awaiting author response), and 34 are cooking in ‘next’ or ‘seen’.

The graduated topics are minor but useful: a macOS linker warning fix (hn/macos-linker-warning), a 32-bit Windows build fix (js/win32-localtime-r), and a GitLab CI migration away from Chocolatey (ps/gitlab-ci-windows). Nothing controversial here—just small, safe fixes that made the cut before freeze.

Two topics are marked stalled: jt/config-lock-timeout (config file locking retries) and js/parseopt-subcommand-autocorrection (auto-correcting mistyped subcommands). Both have been waiting for author responses to review comments for over a month. The third stalled topic, cl/conditional-config-on-worktree-path, adds [includeIf "worktree"] and [includeIf "worktree/i"] conditions; it has been waiting since late May.

The cooking topics span the usual mix: performance, refactoring, new features, and documentation. On the performance front, kk/merge-base-exhaustion stops merge-base walks early when one side’s exclusive commits are exhausted, yielding large speedups for one-sided queries. td/ref-filter-memoize-contains extends the memoized commit traversal (previously used only by `git tag --contains`) to `git branch --contains` and `git for-each-ref --contains`, significantly speeding up connectivity checks across many refs. kk/prio-queue-cascade-sift optimizes prio_queue_get() by halving the number of comparisons per extract-min operation.

Refactoring continues apace. ps/odb-source-packed (18 commits) converts the packed object source into a proper `struct odb_source`, the latest step in Patrick Steinhardt’s ODB abstraction effort. ps/libgit-in-subdir moves libgit.a sources into a new “lib/” directory, cleaning up the top-level directory. ps/setup-drop-global-state (8 commits) drops the remaining global state (`git_work_tree_cfg`, `is_bare_repository_cfg`) from setup.c, tying them to per-repository configuration. ps/refs-avoid-chdir-notify-reparent (12 commits) converts reference backends to use absolute paths internally, eliminating calls to `chdir_notify_reparent()` and fixing a memory leak.

New features are still landing despite the freeze. ps/refs-writing-subcommands adds “create”, “delete”, “update”, and “rename” subcommands to `git refs`, providing a low-level toolbox for reference manipulation. hn/history-squash teaches the experimental `git history` command a “squash” subcommand to fold a range of commits into one, replaying descendants on top. ps/history-drop (10 commits) adds a “drop” subcommand to remove a commit and replay its descendants onto its parent. hn/branch-delete-merged (7 commits) adds `--delete-merged` to `git branch` to remove local branches already merged to their remote-tracking counterparts. hn/checkout-track-fetch (2 commits) extends `git checkout --track` with a “fetch” mode to refresh the start-point branch from its remote.

Documentation updates are plentiful. jc/submittingpatches-design-critiques clarifies how contributors should respond to design critiques and record resolutions in commit messages. wy/doc-clarify-review-replies advises batching patch rerolls and limiting them to one per day to give reviewers time to participate. wy/doc-myfirstcontribution-trim-quotes updates the contributor guide to recommend trimming quoted text in replies. kh/submittingpatches-trailers (5 commits) updates the trailer sections to encourage standard trailers and document the Based-on-patch-by trailer. kh/doc-trailers (10 commits) overhauls the interpret-trailers documentation, committing to the “trailer block” term and explaining key formats. ps/doc-recommend-b4 (3 commits) introduces project-specific b4 configuration and recommends its use in MyFirstContribution.

Bugfixes and regressions are also in the mix. mv/log-follow-mergy fixes `git log --follow` to better handle non-linear history where the tracked path is renamed differently in multiple lines. tb/midx-incremental-custom-base corrects `git multi-pack-index write --incremental` to honor the `--base` option and avoid breaking reachability closure for bitmaps. en/ort-harden-against-corrupt-trees (5 commits) makes the ort merge backend abort when encountering duplicate tree entries or non-adjacent D/F conflicts. pw/status-rebase-todo improves the display of the rebase todo list in `git status` to correctly abbreviate object IDs and avoid misinterpreting refs as object IDs.

Controversy is minimal, but ps/shift-root-in-graph (indenting parentless root commits in `git log --graph`) has drawn pushback on its peek-ahead approach, and mm/diff-process-hunks (external hunk providers via `diff.<driver>.process`) is still iterating after review comments. The rest of the cooking topics look like they will land in ‘next’ and graduate after 2.55 final.

For a busy reader, the highlights are the performance wins (merge-base, ref-filter memoization), the new `git refs` subcommands, the `git history` enhancements, and the ongoing ODB and setup refactoring. The stalled topics and the peek-ahead graph change are worth watching for follow-up discussion.
