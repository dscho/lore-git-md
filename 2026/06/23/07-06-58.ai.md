This is Junio C Hamano’s "What’s cooking in git.git" report for June 2026 (#08), summarizing the state of integration branches ahead of the Git 2.55 release. The report is a snapshot of topics in flight, their maturity, and next steps. Below is a technical brief for a follow-up AI summarizer session.

The report covers 38 topics, grouped into four sections: Graduated to 'master', New Topics, Stalled, and Cooking. The tree is feature-frozen for 2.55; only regression fixes and a few late topics will graduate before rc2 (tagged 2026-06-24). Everything else in 'next' will remain there until after the release.

Key technical details to retain:

- **Graduated**: two topics. `js/objects-larger-than-4gb-on-windows-more` (7 commits) widens object size fields to `size_t` across the ODB, packfile, and delta code, fixing LLP64 (Windows) support for objects >4 GiB. `kw/gitattributes-typofix` (1 commit) fixes the `eol` attribute for Perl scripts.

- **New Topics** (8): all are post-feature-freeze candidates.
  - `kk/merge-base-exhaustion` (6 commits) optimizes merge-base walks by terminating early when one side’s exclusive commits are exhausted; significant speedup for one-sided histories. Expecting a reroll due to review comments.
  - `dk/meson-enable-use-nsec-build` (1 commit) wires up the `USE_NSEC` build knob in Meson; waiting for response.
  - `js/win32-localtime-r` (1 commit) is a build fix for 32-bit Windows; already merged to 'next'.
  - `ps/connected-generic-promisor-checks` (4 commits) refactors connectivity checks to use the ODB interface instead of iterating packfiles directly, enabling promisor object searches in non-packfile repositories. Depends on `ps/odb-source-packed`.
  - `ps/libgit-in-subdir` (3 commits) moves libgit.a sources into a new `lib/` directory; depends on `ps/odb-source-packed`.
  - `ps/odb-generalize-prepare` (3 commits) introduces `odb_prepare()` and generalizes the `reprepare()` callback; depends on `ps/odb-source-packed`.
  - `ps/refs-avoid-chdir-notify-reparent` (12 commits) converts reference backends to use absolute paths, drops `chdir_notify_reparent()`, and fixes a memory leak in reference database construction. Depends on `ps/setup-centralize-odb-creation`.
  - `ps/odb-source-packed` (18 commits) refactors the packed object source into a proper `struct odb_source`; already merged to 'next' and used by several follow-up topics.

- **Stalled** (3): `jt/config-lock-timeout`, `js/parseopt-subcommand-autocorrection`, and `cl/conditional-config-on-worktree-path` have been waiting for responses for over a month.

- **Cooking** (25): the bulk of the report. Highlights:
  - `tb/midx-incremental-custom-base` (3 commits) fixes `--incremental --base` in `git multi-pack-index write` to honor the custom base and maintain reachability closure.
  - `ps/cat-file-remote-object-info` (12 commits) adds `remote-object-info` to `git cat-file --batch-command`, allowing clients to request object metadata (currently size) from a remote server via protocol v2 without downloading the object. The client dynamically filters format placeholders based on server-advertised capabilities.
  - `tb/pack-path-walk-bitmap-delta-islands` (5 commits) enables reachability bitmaps and delta-islands concurrently with `--path-walk` in `git pack-objects`.
  - `hn/branch-delete-merged` (7 commits) adds `--delete-merged` to `git branch` to remove local branches already merged to their remote-tracking counterparts.
  - `hn/checkout-track-fetch` (2 commits) extends `git checkout --track` with a "fetch" mode to refresh the start-point branch from its remote.
  - `ps/shift-root-in-graph` (3 commits) indents parentless "root" commits in `git log --graph` to visually distinguish them from unrelated commits above.
  - `ps/history-drop` (10 commits) adds a "drop" subcommand to the experimental `git history` command, removing a commit and replaying its descendants onto its parent.

The report also notes that `ps/odb-source-packed` and its dependents (`ps/connected-generic-promisor-checks`, `ps/libgit-in-subdir`, `ps/odb-generalize-prepare`, `ps/refs-avoid-chdir-notify-reparent`) form a stack of ODB abstraction work, with the packed source as the first backend converted. The `ps/setup-drop-global-state` topic (8 commits) continues the `the_repository` removal effort by dropping remaining global state in `setup.c`.

No security or data-corruption fixes are highlighted; the focus is on performance, correctness, and refactoring.
