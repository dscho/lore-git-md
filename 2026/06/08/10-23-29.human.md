This is part 5 of Patrick Steinhardt's v3 series adding a "drop" subcommand to the experimental `git history` command. The patch introduces a new `RESET_HEAD_SKIP_REF_UPDATES` flag for `reset_head()` that allows callers to update the index and working tree without modifying any references. 

The change is straightforward - it adds the flag definition and modifies `reset_head()` to skip reference updates when the flag is set, with a BUG check to prevent contradictory flag combinations. The implementation maintains the existing error handling and cleanup paths while adding this new capability.

This infrastructure change enables the subsequent patch in the series that implements the actual `git history drop` functionality, which needs to modify the working tree without updating HEAD or other references. The careful flag validation and clear separation of concerns suggest this is building robust plumbing for the new feature.
