Compiler compatibility patch refining version checks for Clang's UNUSED macro warnings.

First-time contributor Dominik Loidolt submits v3 of his patch to improve Clang's handling of the UNUSED macro, incorporating feedback from Patrick Steinhardt. The patch introduces a clean `GIT_CLANG_PREREQ` macro that mirrors Git's existing `GIT_GNUC_PREREQ` pattern but tailored for Clang's version numbering. This enables proper detection of Clang versions 2.9+ that support the "deprecated" attribute with messages, while maintaining compatibility with older toolchains.

The v3 iteration addresses Steinhardt's minor comment style nit ("/* Similar for Clang. */") and removes unnecessary parentheses around the version comparison. The implementation remains focused in `compat/posix.h`, cleanly separating GCC and Clang version detection while improving warning messages for modern compilers. The patch demonstrates good attention to Git's compatibility standards and represents a straightforward quality-of-life improvement for Clang users.

This appears ready for inclusion, completing the focused improvement to compiler warning quality. The accompanying v3 series (this being 1/2) will modernize the version check style for both GCC and Clang, building on the research Loidolt provided about the historical context of Git's current bit-shift implementation.
