This is a documentation patch in Patrick Steinhardt's series promoting the `b4` tool for Git mailing list workflows, now at version 2. The patch modifies the "MyFirstContribution" guide to recommend shallow threading (where cover letters link back to the first version rather than deep nesting (linking to the previous version).

Kristoffer Haugsbakk provides real-world validation of the change, noting how deep nesting becomes unusable on mobile clients (specifically Safari) where deeply nested replies become unclickable. He cites Patrick's own 11-version git-history series as a positive example of shallow threading remaining comprehensible without these usability issues.

Patrick acknowledges the feedback, agreeing that while deep nesting may work fine for small series, it becomes problematic with many iterations. The exchange reinforces that this documentation change addresses actual pain points while maintaining thread readability. The patch appears ready for merging with only minor documentation consistency fixes remaining in the series.
