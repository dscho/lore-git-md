This is a preparatory refactoring patch (7/12) in a security-focused series that adds remote object metadata query support to `git cat-file --batch-command`. The patch moves initialization code for fetch-pack's protocol v2 state machine outside the state machine itself, making it available regardless of which state the machine starts in.

The change relocates three key initializations from inside the `FETCH_CHECK_LOCAL` state to just before the state machine begins:
1. Enables reachable SHA1 requests by default for v2
2. Sets sideband usage
3. Handles depth-related arguments

This refactoring enables a subsequent patch to introduce an alternative initial state while maintaining these common initializations. The patch maintains identical behavior since the code is simply being moved from the first state to just before state machine execution begins.

The change is mechanical and well-contained, with sign-offs from multiple contributors (Calvin Wan, Eric Ju, Pablo Sabater) and help acknowledgments from Jonathan Tan and Christian Couder. It's part of a mature series that has gone through 12 iterations with extensive security-focused refinements.
