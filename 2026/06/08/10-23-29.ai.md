This is part 5 of Patrick Steinhardt's 9-patch series adding a "drop" subcommand to the experimental `git history` command. The patch introduces a new `RESET_HEAD_SKIP_REF_UPDATES` flag for the `reset_head()` function, allowing callers to update only the index and working tree without modifying any references.

The change is straightforward - it adds the flag definition and modifies `reset_head()` to skip reference updates when the flag is set. A BUG() check ensures the flag isn't used with conflicting options that would require reference updates. The implementation maintains the existing error handling and cleanup paths.

This infrastructure change enables the subsequent patches in the series to implement the commit-dropping functionality without unwanted reference updates. The patch follows the established pattern of the series by cleanly extending the reset machinery's capabilities while maintaining safety through explicit flag validation.
