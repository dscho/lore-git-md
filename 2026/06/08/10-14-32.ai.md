This is part of a security-focused series implementing remote object metadata queries via protocol v2, specifically adding client-side support for the object-info capability. The patch introduces core functionality for requesting and processing object information from remote servers without full downloads.

The implementation centers around new `fetch-object-info.[ch]` files that handle the protocol v2 negotiation and response parsing. Key aspects include:
- A `send_object_info_request()` function that constructs the protocol v2 command with object IDs and options
- The main `fetch_object_info()` function that manages the full request/response cycle
- Integration with the transport layer to support git://, file:// and http:// transports
- Strict protocol version enforcement (v2 only)
- Server capability checking via transfer.advertiseobjectinfo
- Safe numeric parsing of size responses using a new `strtoul_ul()` helper
- Clear error messages when objects are unrecognized or have invalid data

The patch follows the established pattern of writing the entire request into a buffer before sending, similar to fetch-pack's `send_fetch_request()`. It includes comprehensive error handling and maintains Git's security posture by requiring explicit server capability advertisement.

This is patch 9/12 in a mature series that has undergone extensive review across 12 iterations, with all core participants aligned on the approach. The implementation builds on Calvin Wan's prior protocol v2 object information work and represents a complete solution for secure remote object metadata queries.
