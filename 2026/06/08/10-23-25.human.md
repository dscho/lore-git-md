This is the first patch in Patrick Steinhardt's v3 series adding a "drop" subcommand to the experimental `git history` command. The patch refactors index handling code to prepare for later changes in the series.

The change extracts the unmerged-entry resolution logic from `repo_read_index_unmerged()` into a new standalone function `index_state_unmerged_to_stage0()`. This allows the operation to be performed on arbitrary index states rather than just the repository's main index. The patch also fixes a signedness mismatch in the index iteration.

This is a straightforward preparatory refactoring that:
- Adds the new function declaration to read-cache-ll.h
- Moves the core logic to the new function while keeping the repository wrapper
- Converts the loop counter to unsigned to match cache_nr's type

The change is cleanly separated from the rest of the series and appears well-motivated by the upcoming needs of the drop subcommand implementation. As the first in a series that has already gone through two rounds of review, this patch seems unlikely to be controversial.
