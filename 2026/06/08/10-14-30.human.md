This is a preparatory refactoring patch in a 12-part series implementing secure remote object metadata queries via protocol v2. The patch moves initialization code for fetch-pack's state machine out of the first state (FETCH_CHECK_LOCAL) to before the state machine begins, making it available regardless of which state the machine starts in. 

The change is mechanical and behavior-preserving - it just relocates three variable initializations (allow_unadvertised_object_request, use_sideband, args->deepen) that were previously set at the start of FETCH_CHECK_LOCAL. The patch notes this is needed because a subsequent change will introduce an alternative initial state while still requiring these same initializations.

The patch has been reviewed and signed off by Jonathan Tan and Christian Couder, indicating it's a straightforward change that fits into the larger security-focused effort. As part of a mature series that's gone through 12 iterations with extensive review, this particular patch represents a small but necessary step in generalizing the fetch-pack state machine initialization.
