This is a security-focused patch in a series implementing remote object metadata queries for `git cat-file`. The patch specifically addresses validation issue with format placeholders when querying remote objects.

The key changes in this patch:
- Adds an allow-list of supported atoms (`objectname` and `objectsize`) for remote queries
- Changes behavior to return empty strings for unsupported placeholders rather than dying
- Initializes `data->type` to `OBJ_BAD` and adds NULL checks to prevent segfaults
- Updates documentation to reflect the new behavior matching `for-each-ref`'s handling of inapplicable placeholders
- Modifies tests to expect empty strings rather than errors for unsupported placeholders

This is part of a larger effort (now at v12) to securely implement remote object metadata capabilities in Git. The series has undergone extensive review and hardening, with this patch specifically addressing a validation gap that could lead to crashes. The change makes the behavior more consistent with other Git commands while maintaining security.
