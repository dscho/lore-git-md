This is a minor code cleanup patch in the `git cat-file --batch-command` series, which adds remote object metadata query support. The patch moves variable declarations inside their respective for` loops where appropriate and changes some `int` types to `size_t` for better type safety.

The changes are straightforward and uncontroversial:
- Moves loop counter declarations (`i`) inside the `for` statements where they're only used within the loop
- Changes some `int` counters to `size_t` where they index into arrays or count elements
- Affects both `builtin/cat-file.c` and `fetch-pack.c`

This is a small but sensible improvement to the code's readability and type safety, following up on earlier work in the series. The patch has already been reviewed and signed off by Christian Couder, indicating it's ready for inclusion.
