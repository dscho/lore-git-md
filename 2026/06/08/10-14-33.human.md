This is part 10/12 of a security-focused series adding remote object metadata queries to `git cat-file --batch-command`. The patch implements the client-side `remote-object-info` command that lets users query object sizes from remote servers without downloading the full objects.

The command accepts multiple object IDs in a single request to minimize round trips, with a default format of `%(objectname) %(objectsize)`. The implementation includes:
- Transport integration for git://, file:// and http:// protocols
- Input validation and size limits (max 10,000 objects per request)
- Error handling for unsupported format specifiers and missing objects
- Tests verifying behavior across all supported transports

The patch builds on extensive prior review, with v12 specifically hardening the implementation against memory leaks and adding transport helper cleanup. The series has reached maturity after 12 iterations with approval from core contributors.

For context, this is part of a larger effort to enable secure remote object metadata queries via protocol v2, minimizing attack surfaces by allowing size verification before download. The implementation is designed for future expansion to support additional metadata types.
