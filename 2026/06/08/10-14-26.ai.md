This is a minor code style cleanup patch in the `git cat-file --batch-command` series. The changes:

1. Move variable declarations of loop counters (`i`) inside their respective `for` loops where they are only used locally
2. Change the type from `int` to `size_t` where appropriate for array indexing
3. Apply these changes consistently across both `builtin/cat-file.c` and `fetch-pack.c`

The patch follows Git's coding conventions by:
- Keeping variable scopes minimal
- Using appropriate types for array indices
- Maintaining consistent style with the existing codebase

This appears to be a straightforward mechanical change with no functional impact, just improving code hygiene as part of the larger security-focused series. The changes have been reviewed and signed off by both the original author (Eric Ju) and the series contributor (Pablo Sabater), with Christian Couder providing guidance.
