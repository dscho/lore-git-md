This is the third patch in Patrick Steinhardt's v3 series adding a "drop" subcommand to the experimental `git history` command. The patch modernizes the flag handling in the reset machinery by converting `#define` constants to an `enum reset_head_flags` type.

The changes are mechanical but important for code quality:
- Converts five `#define` flags to properly typed enum values
- Renames `RESET_ORIG_HEAD` to `RESET_HEAD_UPDATE_ORIG_HEAD` (a change requested by Phillip Wood in v2 review)
- Updates all callers to use the new enum type
- Maintains exact same bit values and behavior
- Touches reset.h (interface change), reset.c (implementation), and call sites in rebase.c and sequencer.c
- Part of broader reset machinery modernization needed for the history drop functionality

This is a common Git modernization pattern we've seen in other subsystems - moving from C-style defines to typed enums for better type safety and tooling support. The patch is straightforward and unlikely to be controversial, building on established patterns in the codebase.

The change fits naturally into the larger series by cleaning up the reset API before the subsequent patches extend it for the drop functionality. As with the rest of the series, the implementation appears careful and well-tested.
