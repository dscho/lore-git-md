This is a security-focused feature addition to `git cat-file --batch-command` that enables querying remote object metadata without full downloads. The series builds on prior work by Calvin Wan and Eric Ju, now in its 12th iteration with Pablo Sabater as the primary contributor.

The key addition is `remote-object-info`, which lets clients safely query object sizes from protocol v2 servers. The implementation spans protocol handling, transport layer modifications, and user-facing command integration, with particular attention to security hardening. Notable improvements in v12 include:

- Dynamic allow-list validation of placeholders based on server capabilities
- Memory leak fixes in transport-helper disconnect
- Refactored packet writing infrastructure in connect.c
- More robust error cases handling (unsupported fields now return empty strings)
- Forward-compatibility for future metadata types
- Comprehensive test coverage across transports (git://, file://, http://)

The series is now fully baked after addressing all substantive feedback across 12 versions. The remaining open question is how to best differentiate "unsupported" versus "no data" responses for future metadata fields - the current approach follows `for-each-ref`'s empty string convention, but Eric Ju had proposed using "???" instead.

This represents a significant security enhancement by allowing size verification before download, minimizing attack surface. The implementation is ready for consideration with all core technical issues resolved.
