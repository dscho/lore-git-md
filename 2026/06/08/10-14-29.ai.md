This is a protocol refactoring patch in the security-focused `git cat-file --batch-command` series that enables remote object metadata queries. The patch generalizes the protocol v2 packet writing infrastructure by converting the fetch-specific `write_fetch_command_and_capabilities()` into a more flexible `write_command_and_capabilities()` that can handle any protocol v2 command.

The key changes include:
- Renaming and modifying the function to accept a command name parameter instead of hardcoding "fetch"
- Updating the function's documentation to reflect its broader purpose
- Adjusting the hash algorithm check to use `GIT_HASH_SHA1` instead of the legacy `GIT_HASH_SHA1_LEGACY`
- Updating all callers in fetch-pack.c to pass the "fetch" command explicitly

The refactoring enables the protocol layer to support additional commands like "object-info" while maintaining all existing capabilities negotiation and security checks. The patch builds on prior work by Calvin Wan and Eric Ju, with sign-offs from Jonathan Tan and Christian Couder indicating technical review.

This is a mechanical change that doesn't introduce new functionality but prepares the protocol layer for the remote object info queries implemented later in the series. The patch maintains strict protocol v2 enforcement and hash algorithm validation while making the code more reusable.
