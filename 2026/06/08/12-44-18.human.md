This is a platform compatibility patch refining compiler version checks for the `UNUSED` macro. First-time contributor Dominik Loidolt's v3 patch follows up on previous review feedback, implementing a dedicated `GIT_CLANG_PREREQ` macro to properly detect Clang versions 2.9+ that support the "deprecated" attribute with messages.

The patch cleanly separates GCC and Clang version detection in `compat/posix.h`, enabling full "parameter declared as UNUSED" warning messages on modern Clang compilers while maintaining compatibility with older toolchains. Loidolt has addressed all previous review comments, including fixing a comment style nit and removing unnecessary parentheses in the version check logic.

This is part 1 of a 2-patch series - the second patch will modernize the GCC version check to match the more readable comparison style used for Clang. The technical approach has been validated by reviewer Patrick Steinhardt, who confirmed there's no compelling reason to retain the older bit-shift implementation for GCC. The patch demonstrates good attention to Git's compatibility standards and appears ready for inclusion.
