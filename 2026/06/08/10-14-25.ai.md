This is a utility patch in the security-focused `git cat-file --batch-command` series that adds remote object metadata queries. The patch introduces `strtoul_ul()`, a new helper function for safely converting strings to unsigned long values with proper error handling.

The function follows the pattern of existing `strtoul_ui()` but returns an unsigned long instead of unsigned int. It includes robust input validation:
- Explicitly rejects negative numbers (which strtoul would otherwise accept)
- Checks for conversion errors via errno
- Validates the entire string was consumed
- Returns -1 on any error condition

This utility function will be used in subsequent commits in the series for parsing numeric values from remote protocol responses. The implementation is straightforward and follows Git's established patterns for safe string-to-number conversion. As part of a security-sensitive feature, having proper error handling for numeric parsing is particularly important to prevent malformed input from causing issues.

The patch is well-contained and clearly motivated by the needs of the larger series. It has already been reviewed and incorporated into the v12 iteration of the work.
