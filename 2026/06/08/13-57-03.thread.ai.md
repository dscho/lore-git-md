Thread subject: [PATCH 0/3] Add ways to disable config includes  
Author: Derrick Stolee  
Type: feature proposal (config system modification)  

Core goal: Introduce mechanisms to globally disable Git config include directives, addressing sandboxed build system use cases where included config files would cause filesystem access violations.  

Implemented mechanisms:  
1. `GIT_CONFIG_INCLUDES=0` environment variable (patch 2/3)  
2. `--no-includes` command-line option (Git top level) (patch 3/3)  

Current status:  
- Series complete with all 3 patches implemented  
- Patch 1/3 (documentation fix) already applied  
- Patch 2/3 adds environment variable mechanism with comprehensive tests  
- Patch 3/3 adds equivalent command-line option  

Technical details:  
- Both mechanisms set same internal flag to skip include processing  
- Environment variable takes precedence over command-line option  
- `--includes` can override either mechanism  
- Comprehensive test coverage in t1305-config-include.sh verifies:  
  - Include skipping behavior  
  - Override capability  
  - Alias resolution impact  
  - Interaction between mechanisms  
- Documentation updated in git-config.txt and git.adoc
