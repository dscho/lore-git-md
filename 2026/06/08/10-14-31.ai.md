This is a protocol v2 advertisement patch for the remote object metadata query feature, part of the larger `git cat-file --batch-command` security hardening series. The patch modifies the server-side capability advertisement to indicate support for object size queries when `transfer.advertiseobjectinfo` is enabled.

Key changes:
- The `object_info_advertise()` function now populates a `value` strbuf with "size" when the feature is enabled, allowing clients to detect supported capabilities
- Maintains the default-off behavior via `transfer.advertiseobjectinfo` configuration
- Prepares for future expansion by using a value string rather than just a flag

The patch represents a small but critical piece of the overall security architecture, ensuring clients can discover server capabilities before attempting metadata queries. It's been through multiple iterations with input from Jonathan Tan and Christian Couder, and fits into the series' broader goals of safe remote object inspection.
