This is part of a security-focused series (v12 patch 8/12) adding remote object metadata queries to `git cat-file --batch-command`. The patch specifically handles server-side capability advertisement for the new object-info feature.

The change modifies `serve.c` to advertise supported object-info components (currently just "size") when the server has `transfer.advertiseobjectinfo` enabled. This lets clients know what metadata they can request before making queries. The implementation is minimal but designed for future expansion - the `value` parameter is now used to list supported features rather than being ignored.

This builds on Calvin Wan's earlier protocol v2 work and has been through extensive review, with sign-offs from Jonathan Tan and Christian Couder. The series as a whole has addressed all identified security concerns across 12 iterations, making this a mature addition to Git's remote query capabilities.
