This is a v2 submission of a parse-options API improvement patch, now consolidated into a single commit as suggested in review. The patch introduces a new helper function `die_for_missing_opt()` to validate option dependencies in a standardized way, following the pattern of existing mutual-exclusion helpers in parse-options.c.

The implementation provides a clean way to enforce that one option requires another (e.g. "--pathspec-file-nul requires --pathspec-from-file"), with consistent error messages that are marked for translation. The patch demonstrates the helper by converting one such check in `builtin/add.c`, removing manual error handling while maintaining the same behavior. Existing test coverage in t3704 and related pathspec tests continues to verify this case.

- Renamed function to `die_for_missing_opt()` for clarity
