This is a test infrastructure patch that extracts utility functions from `t1006-cat-file.sh` into a new shared library file `lib-cat-file.sh`. The change is part of a larger security-focused series adding remote object metadata queries to `git cat-file --batch-command`.

The patch moves three test helper functions into the new library:
- `echo_without_newline()` - prints strings without trailing newlines
- `echo_without_newline_nul()` - converts newlines to NULL bytes
- `strlen()` - calculates string length

This refactoring improves code reuse and maintainability, allowing future tests to use these utilities without duplication. The changes are mechanical - the functions are moved verbatim with no behavior changes. The patch is well-contained and follows Git's test infrastructure conventions.

As part of the v12 series, this contributes to the overall security hardening effort by cleaning up test code organization while maintaining the same test coverage. The series has undergone extensive review and is now in its final form with all major design questions resolved.
