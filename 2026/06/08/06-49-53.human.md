This is the first patch in Patrick Steinhardt's v3 documentation series promoting the `b4` tool for Git contributions. The patch updates the "MyFirstContribution" guide to recommend "shallow threading" of cover letters - linking each new version's cover letter back to the very first one rather than the immediately preceding version.

The change addresses a practical issue where deep threading (each version linking to the previous) creates excessively nested email threads that become hard to follow. The patch makes straightforward documentation updates to consistently recommend shallow threading throughout the tutorial.

This is part of a broader effort to standardize contributor workflows around `b4` while resolving inconsistencies between tooling defaults and documentation. The v3 series has already addressed all substantive technical feedback, with this patch now representing the final documentation alignment. The only remaining open question is whether the maintainer prefers this shallow threading approach or the status quo - Patrick has indicated willingness to drop this patch if the maintainer favors the current behavior.

The change is well-contained and clearly explained, with the commit message noting both the problem (hard-to-follow deep threads) and solution (shallower linking). The diff shows the straightforward documentation updates needed to implement this recommendation.
