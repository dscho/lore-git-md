This thread reports a significant regression in worktree performance. D. Ben Knoble has identified that `git diff` operations in secondary worktrees run about 10x slower than in the main worktree (223ms vs 3.4ms), with profiling showing excessive time spent in stat checking and filesystem operations. The slowdown affects basic diff operations and shell prompt responsiveness when checking dirty status, and has been present since at least Git v2.50.0. Knoble suspects the issue may lie in the worktree or object-file subsystems, where Patrick Steinhardt and Jeff King have done prior work, and is offering to help investigate further. The thread is just starting, with no responses yet to determine whether this is a known issue or what the root cause might be.
