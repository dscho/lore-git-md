This is the third and final patch in Patrick Steinhardt's series to standardize Git's documentation and configuration around the `b4` mailing list tool. The patch adds two new files to the Git project:

1. `.b4-config` - Sets default b4 configuration for the Git project, specifically:
   - `send-same-thread = shallow` to thread patch series versions under the original cover letter
   - `prep-cover-template` pointing to the project's template file

2. `.b4-cover-template` - A custom cover letter template that includes a range-diff section, matching Git's existing practices

The configuration is designed to be overridable via git-config without modifying the checked-in files, allowing contributors to personalize settings while maintaining project defaults. This completes the technical implementation side of the b4 integration, following the documentation updates in the previous patches.

The patch represents the final piece of the series after extensive discussion about threading models and workflow documentation. With all substantive technical questions resolved in previous iterations, this version focuses purely on the configuration implementation. The only remaining open question is whether Junio prefers the "shallow" threading style (linking to the first cover letter) or the status quo behavior - Patrick has indicated willingness to adjust based on maintainer preference.
