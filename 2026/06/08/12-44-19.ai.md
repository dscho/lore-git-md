This is the second patch in Dominik Loidolt's v3 series modernizing compiler version checks in Git's compatibility layer. The patch simplifies the `GIT_GNUC_PREREQ` macro in `compat/posix.h` by replacing the legacy bit-shift version comparison with a more readable major/minor number comparison.

The change aligns with the style already used for Clang checks (introduced in patch 1/2) and follows the pattern found in BSD headers. The new implementation is functionally equivalent but more maintainable - it removes the implicit assumption that GCC version components will never exceed 65536 and makes the version check logic immediately obvious to readers.

The patch maintains all existing functionality while improving code clarity. It's the culmination of research showing the bit-shift approach was inherited from glibc without technical necessity. Patrick Steinhardt has already validated the technical soundness of this change in previous review rounds.

With both patches in the series now addressing all feedback, this appears ready for maintainer consideration. The changes are low-risk (compile-time only) and demonstrate good attention to Git's cross-platform compatibility requirements while modernizing legacy code patterns.
