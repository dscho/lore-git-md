This is the third patch in Patrick Steinhardt's v3 series adding a "drop" subcommand to the experimental `git history` command. The series is part of ongoing work to modernize Git's reset machinery and expand the history command's capabilities.

This particular patch modernizes the flag handling in `reset_head()` by converting the existing macro-based flags to a proper enum type. The key changes are:
- Replaces `#define` constants with an `enum reset_head_flags` enum
- Renames `RESET_ORIG_HEAD` to `RESET_HEAD_UPDATE_ORIG_HEAD` (a change requested by Phillip Wood in v2 review)
- Updates all callers to use the new enum type

The changes are mechanical but important for code hygiene, making the flag handling more type-safe and consistent with modern Git conventions. The patch touches several key files including `reset.c`, `reset.h`, and callers in `rebase.c` and `sequencer.c`.

This is a straightforward refactoring that builds on the series' earlier infrastructure work. It doesn't introduce new functionality but cleans up the API in preparation for the actual drop command implementation in later patches. The changes are well-contained and unlikely to be controversial.
