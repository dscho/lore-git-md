This is a memory leak fix in the transport-helper code, part of a larger security-focused series adding remote object metadata queries to `git cat-file --batch-command`. The patch addresses a specific issue where `data->name` wasn't being freed when the transport helper disconnected before being fully initialized.

The change is straightforward - it moves the `FREE_AND_NULL(data->name)` call outside the conditional block so it executes regardless of whether the helper was fully started. This fixes a leak that was identified during review of the larger series. The patch has been reviewed (with Mentored-by tags from Karthik Nayak and Chandra Pratap) and appears ready for inclusion.

As part of the v12 security hardening effort, this memory leak fix helps ensure proper resource cleanup in the transport layer, which is particularly important for the new object metadata query functionality that relies on these code paths. The change is small but meaningful for the overall stability of the feature.
