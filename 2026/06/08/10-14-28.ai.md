This is a refactoring patch from the security-focused `git cat-file --batch-command` series that enables remote object metadata queries. The patch moves `write_fetch_command_and_capabilities()` from `fetch-pack.c` to `connect.c` to make it more generally available to other commands.

The key changes are:
- The function is now initialized with `repo_config_get_bool()` directly rather than through a static variable
- The move is safe because the protocol v1-specific `advertise_sid` handling is irrelevant for protocol v2 usage
- The change prepares for future refactoring to make this a more general-purpose function

The patch maintains all existing functionality while improving code organization. It's part of the broader effort to enable secure remote object metadata queries via protocol v2, with this particular change focused on cleaning up the protocol infrastructure. The implementation has been reviewed by Jonathan Tan and Christian Couder.
