This is a refactoring patch from Pablo Sabater as part of a larger security-focused series adding remote object metadata queries to `git cat-file --batch-command`. The patch moves the `write_fetch_command_and_capabilities()` function from `fetch-pack.c` to `connect.c` to make it more generally accessible to other commands.

The key changes are:
- The function is relocated to `connect.c` with its declaration added to `connect.h`
- The `advertise_sid` configuration is simplified by reading it directly via `repo_config_get_bool()` rather than maintaining it as a static variable
- The change is safe because the protocol v1-specific side effects of the original implementation are irrelevant for protocol v2 usage

The patch has been reviewed by Jonathan Tan and Christian Couder, and builds on prior work by Calvin Wan and Eric Ju. This is patch 5/12 in a mature series that has gone through 12 iterations with extensive security-focused refinements. The relocation of this function helps prepare for broader use of protocol v2 capabilities across Git commands.
