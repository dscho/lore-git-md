This is the third version of Patrick Steinhardt's documentation patch series promoting the `b4` tool for Git's mailing list workflow. The series now consists of three patches:

1. Updates `MyFirstContribution.adoc` to recommend shallow threading of cover letters (linking to the first cover letter rather than the most recent one)
2. Adds documentation recommending `b4` as the preferred tool for patch submission and review
3. Adds project-level `.b4-config` and `.b4-cover-template` files to standardize Git's b4 configuration

The key changes in v3 address feedback from the v2 discussion:
- Clarifies terminology around "shallow/deep threading" of cover letters
- Fixes remaining instances where deep threading was still recommended
- Leaves the threading style question open for maintainer input (Patrick notes willingness to drop the shallow threading patch if consensus favors the status quo)

The series builds on Junio's earlier endorsement of b4 and represents a significant documentation improvement for new contributors. The discussion has largely converged, with only minor outstanding questions about threading style preferences and whether to document version compatibility details for older b4 versions (pre-v0.15).

This appears ready for maintainer review, pending any final feedback on the threading style question. The changes are well-contained documentation updates that formalize existing community practices while improving the contributor experience.
