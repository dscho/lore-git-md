This is part of a security-focused series adding remote object metadata query support to `git cat-file --batch-command` via protocol v2. The patch implements client-side support for requesting object information from remote servers without full downloads.

The key addition is a new `fetch-object-info.[ch]` module that handles the protocol v2 negotiation and response parsing for object metadata queries. The client can request object sizes (the only currently supported feature) by sending a list of object IDs to the server. If the server doesn't advertise the object-info capability (controlled by `transfer.advertiseobjectinfo`), the client fails with a clear error.

The implementation follows Git's security-conscious patterns - it validates all server responses, uses safe numeric parsing with the new `strtoul_ul()` helper, and maintains buffer overflow protections. The request is written entirely to a buffer before transmission rather than being streamed, matching the approach used in `fetch-pack`.

This patch builds on Calvin Wan's earlier server-side object-info work and represents the client-side counterpart. It's part of a mature series that has gone through 12 iterations with thorough review from core contributors like Jonathan Tan and Christian Couder. The implementation is now ready for merging, providing a secure foundation for remote object metadata queries.
