This is the first patch in Toon Claes’s three-part series introducing a `--linearize` option to `git replay`. It refactors the internal `enum replay_mode` into a simple boolean flag (`reverse`).

The patch is a clean mechanical conversion: the two existing enum values (`REPLAY_MODE_PICK` and `REPLAY_MODE_REVERT`) are replaced with a single boolean (`reverse`) that is true when `--revert` is given and false otherwise. All switch-like logic is rewritten as if/else blocks, and the BUG() calls that guarded against invalid enum values are removed. The diff is confined to `replay.c` and shrinks the file by nine lines.

The motivation is straightforward: with only two modes, an enum is overkill and a boolean simplifies the code. The change is purely internal and does not alter user-visible behavior. No tests or documentation are touched, so this is a safe preparatory step for the feature that follows. The patch looks well-executed and uncontroversial.
