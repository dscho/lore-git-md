This is a protocol refactoring patch from the security-hardened `git cat-file --batch-command` series that enables remote object metadata queries. The patch generalizes the protocol v2 packet writing function to support both fetch and other commands (such as the new object-info capability).

The key change renames `write_fetch_command_and_capabilities()` to `write_command_and_capabilities()` and makes it take the command name as a parameter rather than hardcoding "fetch". This allows the same function to be used for the new object-info protocol commands while maintaining all the existing capability negotiation logic. The patch includes updates to the function's documentation and call sites in fetch-pack.c.

The change is straightforward and mechanical, with no behavior changes beyond the generalization. It's part of a well-reviewed series that has gone through 12 iterations, with this particular patch receiving help from Jonathan Tan and Christian Couder. The refactoring prepares the codebase for future protocol extensions while keeping the security-focused capability negotiation centralized in one place.
