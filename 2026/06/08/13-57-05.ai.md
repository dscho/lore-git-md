This is the second patch in Derrick Stolee's series to disable config includes, implementing the environment variable mechanism. The patch adds a `GIT_CONFIG_INCLUDES=0` environment variable that, when set, prevents Git from following `include.path` and `includeIf.*.path` directives during config loading.

The implementation touches core config handling in `config.c`, adding a check for the new environment variable before processing includes. The patch includes thorough test coverage in `t1305-config-include.sh` that:
1. Verifies includes are skipped when the variable is set
2. Confirms `--includes` flag can override the environment setting
3. Demonstrates practical impact by testing alias overrides via includes

The change is well-motivated by the sandboxed build system use case described in the cover letter, where included config files could cause filesystem access violations. The implementation appears clean and focused, with clear documentation updates and comprehensive tests that cover both direct config access and indirect effects like alias resolution.

This patch maintains the series' high quality standard, with careful attention to the interaction between the new environment variable and existing `--includes` command-line behavior. The test cases suggest Stolee has considered real-world usage patterns where this feature would be valuable.
