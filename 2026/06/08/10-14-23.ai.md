This is a security-focused extension to `git cat-file --batch-command` that adds remote object metadata queries via protocol v2, building on prior work by Calvin Wan and Eric Ju. The series implements a new `remote-object-info` command that lets clients safely query object sizes from remote servers without full downloads.

The v12 changes focus on hardening the implementation with several key improvements:
- Dynamic allow-list validation of format placeholders based on server capabilities
- Memory leak fixes in transport-helper disconnect paths
- More robust error handling with clearer messages ("server does not recognize object")
- Forward-compatible client-side request path for future type support
- Protocol v2 packet writing refactored into reusable connect.c functions
- Comprehensive test coverage across git://, file:// and http:// transports

Notable technical decisions:
- Unsupported fields (like objecttype) return empty strings rather than failing
- Server capability advertisement via transfer.advertiseobjectinfo
- Strict protocol v2 enforcement with clear error messages
- Buffer overflow protection and input validation throughout
- Architecture designed for future expansion to support additional metadata types

The series is now fully rebased on current master (9ac3f193c0) and addresses all prior review comments. It represents a complete solution for secure remote object metadata queries, though the author notes an open design question about differentiating "unsupported" vs "no data" responses for future placeholders. The implementation has been thoroughly tested and reviewed across 12 iterations, with all identified security concerns addressed.
