This is patch 8/9 in Patrick Steinhardt's v3 series adding a "drop" subcommand to the experimental `git history` command. The patch refactors the reference update handling by splitting it into two distinct phases: computing the updates and then applying them.

The change separates `handle_reference_updates()` into:
1. `compute_pending_ref_updates()` - gathers all refs that need updating
2. `apply_pending_ref_updates()` - executes the actual ref transactions

This prepares for future work where these phases may need to be called separately. The patch maintains all existing functionality while making the code more modular.
