This is a release announcement for Git v2.55.0-rc1, the first release candidate for the upcoming Git 2.55 feature release. Junio C Hamano, the maintainer, cut the -rc1 after merging 460 non-merge commits from 82 contributors (27 of them first-time contributors). The tarballs are available at the usual locations, and the tag is present in all public repositories.

The release notes draft highlights a mix of new features, performance improvements, internal refactoring, and fixes. Notable user-facing changes include:

- Hook scripts defined via configuration can now run in parallel, with new options to control concurrency (`hook.jobs`, `hook.<event>.jobs`, and `hook.<event>.enabled`).
- A new builtin `git format-rev` provides on-demand pretty formatting of revision expressions.
- `git checkout -m` now stashes local changes when switching branches, giving users another chance to resolve conflicts.
- `git push` learned to accept a "remote group" name, pushing to multiple remotes at once.
- The fsmonitor daemon is now implemented for Linux, completing the cross-platform fsmonitor support.
- `git restore` avoids unnecessary sparse index expansion when operating on paths within the sparse checkout definition.
- The graph output from `git log --graph` can now be limited to a specified number of lanes to prevent overly wide output.

Performance and internal improvements are substantial:
- Reachability bitmap generation was significantly optimized, improving `git repack --write-midx-bitmaps` performance.
- The revision traversal infrastructure was optimized by replacing linear lists with priority queues in several core functions.
- The ODB (object database) abstraction work continues, with the loose object source refactored into a proper `struct odb_source` and a new in-memory ODB source introduced for tentative objects.
- Many global configuration variables were migrated into `repo_config_values` to avoid cross-repository state leakage.
- The `the_repository` removal effort continues, with many setup.c codepaths updated to use appropriate repository instances.

The release also includes numerous bug fixes, documentation updates (including Jean-Noël Avila's ongoing synopsis-style conversion), and test suite improvements. The Rust support is now enabled by default, though still opt-out, and the xdiff codebase is being prepared for Rust integration.

This -rc1 marks the start of the stabilization period for Git 2.55. The release notes draft is comprehensive, and the sheer volume of changes suggests this will be a significant release. The next steps will be testing and addressing any regressions found during the -rc period.
