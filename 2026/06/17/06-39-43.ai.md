This is the v3 cover letter for Patrick Steinhardt’s 17-patch series completing the ODB abstraction by converting the packed object storage backend into a proper `struct odb_source`. The series is the counterpart to an earlier loose-source conversion and represents the final large-scale ODB restructuring Patrick plans to undertake; future work should be more incremental.

The main technical change is the mechanical conversion of `struct packfile_store` to `struct odb_source_packed`, moving all packed-source code into the `odb/` subsystem and wiring up the required callbacks (`close()`, `reprepare()`, `read_object_info()`, `read_object_stream()`, `for_each_object()`, `count_objects()`, `find_abbrev_len()`, and `freshen_object()`). The series also splits out `struct packfile_list` into a separate unit to break a cyclic header dependency and refactors midx interfaces to work directly on the new packed source type. By the end, the packed source’s interface is fully aligned with the loose source’s precedent: both use an embedded `struct odb_source` as a base, share identical constructor signatures, and no longer carry a parent pointer.

v3 adds only minor commit-message clarifications; the substantive changes were already present in v2 (splitting the packfile list and fixing an extraneous newline). The diffstat (1163 insertions, 1079 deletions across 26 files) reflects the scale of the mechanical conversion, which touches builtin commands, midx handling, repack machinery, and test helpers. Justin Tobler’s surface-level review of the mechanical changes in v2 is now complete, confirming the interface alignment and callback wiring pattern. The series remains blocked, however, by unresolved refdb lifecycle issues (memory leaks, duplicate refdb creation, initialization ordering) that Patrick has diagnosed and is preparing an 11-patch fix series to address. Those fixes depend on the earlier “ps/setup-centralize-odb-creation” series, so the ODB work will not progress until that dependency is merged. No substantive review of the callback logic, refdb implications, or midx edge cases has occurred yet.
