Here’s a concise narrative summary of the current state of the Git mailing list, based on Junio’s latest "What’s cooking" report for June 2026:

The Git project is in the final stabilization phase of the 2.55 release cycle, with -rc1 already tagged. The focus is now on reviewing and merging critical fixes rather than introducing new features. Several performance optimizations have graduated to `master`, including improvements to delta caching (`ab/index-pack-retain-child-bases`) and streaming walks (`kk/streaming-walk-pqueue`). New topics of note include `mh/fetch-follow-remote-head-config`, which adds a `fetch.followRemoteHEAD` option to control whether `git fetch` tracks the remote’s HEAD ref—a small but useful feature for users working with remote branches. For scripting and automation, `ps/refs-writing-subcommands` extends `git refs` with new subcommands (`create`, `delete`, `update`, `rename`) for programmatic ref management. On the correctness front, `po/hash-object-size-t` and `js/objects-larger-than-4gb-on-windows-more` address long-standing limitations around large objects on Windows and LLP64 platforms, converting size-related variables to `size_t` to handle objects over 4GB.

Refactoring efforts remain active, with `ps/setup-drop-global-state` and `ps/refs-avoid-chdir-notify-reparent` continuing to reduce global state and improve path handling in ref backends. Patrick Steinhardt’s ODB abstraction work progresses with `ps/odb-source-packed`, which refactors the packed object source into a proper `struct odb_source`. A few topics are stalled, including `jt/config-lock-timeout` (configurable lock retry timeout) and `ds/config-no-includes` (ignoring config includes), both awaiting updates after review feedback.

The experimental `git history` command gains a `drop` subcommand (`ps/history-drop`) to remove commits and replay descendants, offering more flexible history editing akin to `git rebase --no-rebase-merges`. Meanwhile, `mm/diff-process-hunks` introduces a `diff.<driver>.process` configuration to delegate hunk generation to external tools, which could enable deeper integrations with third-party diff tools. Documentation updates include `kh/submittingpatches-trailers` (trailer guidance) and `ps/doc-recommend-b4` (promoting `b4` for patch submission).

Overall, the report paints a picture of a project in a mature stabilization phase, balancing performance tweaks, platform fixes, and ongoing architectural work. The most user-visible changes this cycle are likely to be the new `fetch.followRemoteHEAD` option and the expanded `git refs` tooling.
