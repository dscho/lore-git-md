This is the twelfth patch in Patrick Steinhardt’s 17-part ODB abstraction series, which is the final large-scale restructuring of Git’s object database before shifting to incremental work. The patch wires up the `count_objects()` callback for the packed object source, moving the logic from `packfile.c` to `odb/source-packed.c` and registering it in the packed source’s constructor. The change is purely mechanical: the implementation remains identical, including the multi-pack-index and packfile traversal logic, and the only behavioral difference is that callers now use the ODB-prefixed interface (`odb_source_count_objects()`) instead of the old `packfile_store_count_objects()`. The patch removes the now-unused `packfile_store_count_objects()` function from `packfile.h`, continuing the series’ pattern of encapsulating packed-source internals. No substantive review has occurred yet, but the callback wiring follows the established pattern from earlier patches in the series.
