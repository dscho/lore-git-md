Subject: [ANNOUNCE] Git v2.55.0-rc1
Series version: v2.55.0-rc1 (release candidate)
Originating author: Junio C Hamano
Thread type: release announcement

Core problem or goal
Provide the first release candidate for Git 2.55, incorporating 460 non-merge commits from 82 contributors since the last feature release. The goal is to stabilize the codebase for the upcoming v2.55.0 final release by exposing it to wider testing.

Current status
Git v2.55.0-rc1 has been tagged and tarballs published. The stabilization period is now open; no new features will be merged, only regression fixes and documentation updates.

Key technical details
- New built-in: `git format-rev` (on-demand pretty formatting of revision expressions)
- New config keys: `hook.jobs`, `hook.<event>.jobs`, `hook.<event>.enabled` (parallel hook execution)
- CLI changes: `git checkout -m` now stashes local changes; `git push` accepts remote groups; `git log --graph --max-lanes=<n>` limits graph width
- Subsystems touched: hooks, fsmonitor (Linux backend), sparse-checkout, revision traversal, reachability bitmaps, ODB abstraction, repository setup, configuration handling, xdiff, Rust integration
- On-disk format: no breaking changes; all changes are backwards-compatible
- Test coverage: extensive updates to t/ reflecting new features and edge cases

Open questions and loose ends
- No open design questions; this is a stabilization phase
- Loose ends: any regressions or bugs discovered during the -rc period will be addressed in follow-up patches before v2.55.0 final

Participant positions
- Junio C Hamano (maintainer): cut the -rc1, authored the announcement, and will merge regression fixes during the stabilization period
- 82 contributors: authored the 460 commits; no individual positions expressed in this email (this is a roll-up announcement)

Related work
- Ongoing efforts reflected in this release: ODB abstraction (Patrick Steinhardt), `the_repository` removal (René Scharfe), documentation synopsis-style conversion (Jean-Noël Avila), Rustification (Ezekiel Newren), fsmonitor (Paul Tarjan), sparse-checkout/sparse-index (Derrick Stolee, Elijah Newren)
