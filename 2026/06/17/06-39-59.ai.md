This is patch 16/17 in Patrick Steinhardt’s ODB abstraction series, targeting the multi-pack-index (MIDX) subsystem. The patch refactors MIDX interfaces to work directly on the new `struct odb_source_packed` type instead of the generic `struct odb_source` base. This is a mechanical but conceptually important change: MIDXs are inherently tied to the packed object storage backend, so passing a generic source type gave a false impression of flexibility. The refactoring updates all MIDX-related functions in `midx.h`, `midx.c`, and `midx-write.c`, along with callers in builtin commands (`multi-pack-index`, `pack-objects`, `repack`), the pack-bitmap subsystem, and test helpers. The diff is large (144 insertions, 129 deletions across 13 files) but purely type-system driven: every function that previously took a `struct odb_source *` now takes a `struct odb_source_packed *`, and callers are updated to downcast the generic source to the packed type. The change also simplifies some internal logic by removing redundant downcasts and making the packed source’s ownership of the MIDX explicit. This patch paves the way for patch 17/17, which will remove the parent pointer from the packed source, completing the interface alignment with the loose source. No behavioral changes are introduced; the MIDX’s functionality remains identical. The patch has received surface-level mechanical approval from Justin Tobler, but no deeper review of MIDX edge cases or interaction with the broader ODB abstraction has occurred yet. The series remains blocked by unresolved refdb lifecycle issues that Patrick is addressing in a separate 11-patch fix series.
