This is the fifteenth patch in Patrick Steinhardt’s 17-part ODB abstraction series, which completes the conversion of Git’s packed object storage into a proper `struct odb_source`. This patch stubs out the remaining ODB interface functions that the packed backend either does not support or implements as no-ops.

The packed ODB backend is read-only, so the patch adds error-returning stubs for `write_object()`, `write_object_stream()`, `begin_transaction()`, and `write_alternate()`. The `read_alternates()` callback is implemented as a no-op (returning 0) since packed backends do not use alternates. All five stubs are registered in the packed source’s constructor, bringing the packed backend’s interface into full alignment with the loose source’s precedent.

The change is mechanical and uncontroversial: the packed backend has always been read-only, and these stubs simply formalize that constraint in the new ODB interface.
