This thread is about a build regression in the macOS keychain credential helper (`git-credential-osxkeychain`) that surfaced when Git is built with Rust support enabled. The issue—a linker error due to unresolved Rust varint symbols—was introduced in Git v2.55.0 and blocked the release candidate. Toon Claes identified the problem and proposed a minimal fix: a one-line Makefile change to ensure the Rust library is included during linking. Junio C Hamano merged the patch directly to `master` ahead of the release, resolving the immediate regression.

The fix aligns the build rule with other Git components, but the underlying issue—a coarse-grained dependency in the build system—remains unresolved. Patrick Steinhardt later clarified that the problem only affects the Makefile-based build; Meson handles the dependency correctly, which explains why the regression went unnoticed in CI. While the thread is effectively resolved, the broader dependency issue could resurface in other components as Rust code continues to integrate into `libgit.a`. No follow-up work is planned yet, but the discussion highlights gaps in build coverage for Rust-enabled configurations.
