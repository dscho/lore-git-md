This is the third patch in Kristoffer Haugsbakk’s five-part documentation series updating `SubmittingPatches` to standardize Git’s trailer conventions. It introduces and documents the `Based-on-patch-by:` trailer, which is used when a patch incorporates code originally authored by someone else—typically a patch previously sent to the mailing list.

The patch adds a concise four-line section to the existing "Commit trailers" documentation, explaining when to use `Based-on-patch-by:` (e.g., when building on someone else’s patch) and emphasizing the legal requirement that the original author must have signed off on the patch. The v2 revision explicitly clarifies this precondition, addressing Junio C Hamano’s feedback that the trailer should only be used if the original patch was properly signed off. The change is minimal and targeted, touching only the `Documentation/SubmittingPatches` file.

This patch is uncontroversial and well-motivated, reflecting common mailing-list practice. It complements the series’ broader goal of reducing ambiguity in trailer usage while ensuring DCO compliance. The trailer’s distinction from `Co-authored-by:` (for collaborative drafts) and `Helped-by:` (for ideas rather than code) is now clearly documented, making it easier for contributors to credit prior work appropriately. The series as a whole is finalized and ready for merging.
