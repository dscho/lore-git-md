Subject: [PATCH] completion: zsh: fix completion for `git -C <path> <command>`
Series version: v2 (standalone patch)
Originating author: Lutz Lengemann
Thread type: bugfix

Core problem or goal
The zsh Git completion script (`contrib/completion/git-completion.zsh`) fails to complete commands or arguments when global options (`-C`, `--git-dir`, `--work-tree`, `-p`, etc.) are used, due to hard-coded assumptions in the `_arguments` spec and command-index calculation. The goal is to align zsh completion with the bash implementation (`__git_main` in `git-completion.bash`) to consistently handle all global options.

Current status
Patch v2 is under review and effectively unblocked. The 25-line fix scans past all global options (not just `-C`) and their arguments to set `__git_cmd_idx`, ensuring completions work for constructs like `git -p checkout <TAB>` and `git --git-dir=<path> checkout <TAB>`. Junio’s architectural feedback and D. Ben Knoble’s technical concerns from v1 are fully addressed. The patch documents two remaining gaps: (1) `-c` is still missing from the `_arguments` spec, and (2) `--git-dir` only accepts `--git-dir=<path>` (not `--git-dir <path>`), both left for follow-ups. Directory completion for chained `-C` options (e.g., `git -C dir -C <tab>`) remains broken but is explicitly noted in the commit message. The unrelated `git -<tab>` bug (redundant output) is confirmed as pre-existing. The author has updated the GitGitGadget PR and resent the patch to the mailing list; no further procedural steps remain.

Key technical details
- File: `contrib/completion/git-completion.zsh`
- Modified logic: `_arguments` spec extended to include `-C`; `__git_cmd_idx` calculation now skips all global options (e.g., `--git-dir`, `--work-tree`, `-p`) and their arguments, mirroring `__git_main` in `git-completion.bash`. The patch also collects `-C` paths into `__git_C_args` to ensure bash helpers run `git` in the intended directory.
- Behavior change: completions now work for `git -C <path> <command> <TAB>`, `git -p checkout <TAB>`, and similar constructs; directory completion for chained `-C` options remains broken.
- Reference implementation: `__git_main` in `git-completion.bash` (lines 100–140).
- No new variables; `i` (loop counter) is reused. No on-disk format, CLI, or test coverage changes; purely shell-script behavior.
