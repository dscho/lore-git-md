This is patch 13/17 in Patrick Steinhardt’s ODB abstraction series, continuing the mechanical conversion of the packed object storage backend into a proper `struct odb_source`. The patch wires up the `find_abbrev_len()` callback by relocating `packfile_store_find_abbrev_len()` and its supporting MIDX and packfile helpers (`find_abbrev_len_for_midx()`, `find_abbrev_len_for_pack()`, and `extend_abbrev_len()`) from `packfile.c` to `odb/source-packed.c`. The callback is registered in the packed source’s constructor, and the files source is updated to use the new ODB-prefixed interface (`odb_source_find_abbrev_len()`). The diffstat (114 insertions, 117 deletions) reflects the 1:1 code move, with no behavioral changes introduced.

The implementation follows the established pattern of earlier patches in the series: the logic remains functionally identical, including MIDX traversal, packfile iteration, and the two-neighbor abbreviation-length calculation. The only caller in `odb/source-files.c` is updated to use the ODB interface, and the now-unused `packfile_store_find_abbrev_len()` declaration is removed from `packfile.h`. This leaves only the `freshen_object()` callback unwired, completing the callback registration phase of the ODB abstraction. The patch is purely mechanical and has not yet received review, but it continues the consistent interface alignment between loose and packed sources that Justin Tobler previously approved in patches 1–12.
