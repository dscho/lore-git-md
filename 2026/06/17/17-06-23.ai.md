This is Junio Hamano’s biweekly "What’s cooking in git.git" report for June 2026, summarizing the state of integration branches and in-flight topics. The report marks the end of the Git 2.55 development cycle (with 2.55-rc1 tagged) and the beginning of a feature freeze, shifting focus to regression fixes and review of stalled topics.

Key themes this cycle include:
- **Object storage refactoring** (Patrick Steinhardt’s ODB abstraction work continues with `ps/odb-source-packed` and `ps/refs-avoid-chdir-notify-reparent`).
- **Reference backend improvements** (`ps/refs-writing-subcommands` adds `git refs create|delete|update|rename`; `mh/fetch-follow-remote-head-config` adds `fetch.followRemoteHEAD`).
- **Large-object handling** (`po/hash-object-size-t` and `js/objects-larger-than-4gb-on-windows-more` fix 4GB+ object support on Windows/LLP64).
- **Performance optimizations** (`kk/prio-queue-get-put-fusion`, `kk/streaming-walk-pqueue`, `rs/cat-file-default-format-optim`).
- **New experimental commands** (`ps/history-drop` adds `git history drop`; `tc/replay-linearize` adds `git replay --linearize`).
- **Documentation and contributor tooling** (`ps/doc-recommend-b4` encourages b4 for patch submission; `kh/submittingpatches-trailers` updates trailer guidance).

Notable graduated topics:
- `ab/index-pack-retain-child-bases` (delta cache optimization).
- `jk/describe-contains-all-match-fix` (fixes `--contains --all` with `--match`/`--exclude`).
- `js/osxkeychain-build-wo-rust` (build fix).
- `js/win-kill-child-more-gently` (Windows process cleanup).
- `mf/revision-max-count-oldest` (new `--max-count-oldest` for `git log`/`rev-list`).

Stalled topics needing attention:
- `jt/config-lock-timeout` (config file locking retries).
- `mv/log-follow-mergy` (`git log --follow` for non-linear history).
- `mm/diff-process-hunks` (external hunk providers via `diff.<driver>.process`).
- `tb/pack-path-walk-bitmap-delta-islands` (pack-objects + bitmaps + delta-islands).

Controversial or complex topics:
- `ps/cat-file-remote-object-info` (remote object metadata via protocol v2; needs reroll).
- `mm/diff-process-hunks` (external hunk providers; security/performance concerns).
- `hn/branch-prune-merged` (`git branch --delete-merged`; UX debates).

The report also highlights **retracted topics** (e.g., `kk/fetch-store-ref-optimization`, `lp/repack-propagate-promisor-debugging`) and **discarded efforts** (e.g., `jc/neuter-sideband-post-3.0`).

For follow-up, the most actionable items are the stalled topics (especially `mv/log-follow-mergy` and `mm/diff-process-hunks`) and the ODB/refactor series (`ps/odb-source-packed`, `ps/refs-avoid-chdir-notify-reparent`). The `ps/history-drop` and `tc/replay-linearize` topics introduce new user-facing functionality worth monitoring.
