This is patch 16/17 in Patrick Steinhardt’s ODB abstraction series, now in its second iteration. The patch refactors MIDX interfaces to use the concrete `struct odb_source_packed` type instead of the generic `struct odb_source`, making the packed source’s ownership of MIDX operations explicit. Patrick’s reply to Justin Tobler’s review clarifies that while callers now handle downcasting earlier, the error flows remain unchanged because the "files" source is currently the only backend. The `BUG()` behavior is preserved, just triggered sooner in some cases. This is a mechanical type-system cleanup that aligns with the series’ goal of making object storage relationships more explicit, but it does not address the deeper refdb lifecycle issues that are still blocking the series. No substantive objections have been raised to this change.
