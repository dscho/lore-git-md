This refactoring anticipates the eventual move of `find_pack_entry()` into `odb/source-packed.c` as a file-local function, a step that will further encapsulate the packed source implementation.

The patch maintains the existing logic of iterating over all ODB sources and checking for the object’s presence, but now uses the ODB-prefixed interface. This aligns with the series’ broader goal of exposing a consistent, high-level API for object storage operations while hiding implementation details.
