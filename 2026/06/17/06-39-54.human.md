This is the 11th patch in Patrick Steinhardt’s 17-part ODB abstraction series, now in its third iteration. The patch wires up the `for_each_object()` callback for the packed object storage backend, completing the interface alignment between loose and packed sources.

The change moves the `packfile_store_for_each_object()` function and its supporting helpers from `packfile.c` into `odb/source-packed.c`, then registers it as the packed source’s `for_each_object()` callback. The implementation remains functionally identical: it iterates over all objects in the packfile store (including multi-pack-index entries), applies prefix filtering if requested, and invokes the provided callback for each matching object. To maintain compatibility, the patch exposes `packed_object_info_with_index_pos()` as a public symbol, which the callback uses to populate object metadata when an `object_info` request is supplied.

The diffstat (269 insertions, 280 deletions) reflects the mechanical nature of the move: the code is relocated verbatim, with only minor adjustments to use the ODB-prefixed interface (`odb_source_read_object_info()` instead of direct calls). Callers in `builtin/cat-file.c`, `builtin/pack-objects.c`, `commit-graph.c`, and `odb/source-files.c` are updated to use the new `odb_source_for_each_object()` wrapper, mirroring the pattern established in earlier patches.
