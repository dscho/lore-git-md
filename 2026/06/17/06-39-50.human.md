This is the seventh patch in Patrick Steinhardt’s 17-part ODB abstraction series (v3), which completes the conversion of the packed object storage backend into a proper `struct odb_source`. This patch moves the `reprepare()` logic from `packfile.c` into `odb/source-packed.c` and wires it up as the ODB source callback, mirroring the loose source’s precedent.

The change is mechanical: 157 lines of code are relocated from `packfile.c` to `odb/source-packed.c`, and the public API is updated so that callers now invoke `odb_source_packed_prepare()` and `odb_source_reprepare()` instead of the old `packfile_store_*` functions. The patch also removes the now-unused `packfile_store_prepare()` and `packfile_store_reprepare()` declarations from `packfile.h`. Three call sites (`builtin/grep.c`, `midx.c`, and `odb/source-files.c`) are updated to use the new ODB-style functions.

The commit message notes that the `reprepare()` callback will eventually be renamed to `prepare()` with an optional flag for re-preparation, but that redesign is deferred to a future series. Justin Tobler’s review of the mechanical changes in v2 confirmed the 1:1 relocation and the callback wiring pattern, so this patch is unlikely to generate new discussion. The series as a whole remains blocked by unresolved refdb lifecycle issues that Patrick is addressing in a separate 11-patch fix series.
