This is the **release announcement** for Git v2.55.0-rc1, the first release candidate for the upcoming Git 2.55.0. Junio C Hamano, the maintainer, has tagged this version after integrating 460 non-merge commits from 82 contributors, including 27 first-time contributors.

The release notes draft highlights a mix of **new features, performance improvements, internal refactoring, and bug fixes**. Key user-facing changes include:
- **Parallel hook execution**: Hooks defined in Git’s configuration can now run in parallel, controlled by new `hook.jobs` and per-event configuration.
- **New built-in commands**: `git format-rev` (for pretty-printing revision expressions) and `git url-parse` (for parsing Git URLs).
- **Enhanced merge and checkout workflows**: `git checkout -m` now stashes local changes automatically, and the `ort` merge backend has further improvements.
- **Linux fsmonitor daemon**: Brings Linux support for the filesystem monitoring feature previously available only on Windows and macOS.
- **Push to remote groups**: `git push` can now target a group of remotes (e.g., `git push all`), mirroring the existing `git fetch` behavior.
- **Sparse index optimizations**: `git restore --staged` and other commands avoid unnecessary index expansion when operating within a sparse checkout.

Performance and internal changes are substantial:
- **Reachability bitmap generation** has been optimized, improving `git repack --write-midx-bitmaps` performance for large repositories.
- **Revision traversal** now uses priority queues for date-sorted walks, speeding up operations like `git log` in repositories with many merges.
- **ODB (object database) abstraction** continues to evolve, with new in-memory and loose object sources, and transaction interfaces being reworked.
- **`the_repository` removal** progresses, with many core functions now taking explicit `struct repository *` parameters instead of relying on the global variable.
- **Rust support** is now enabled by default (though still opt-out), marking a milestone in the ongoing Rustification effort.

Notable fixes include:
- **Proxy URL validation**: Git now rejects invalid schemes (e.g., `httt://`).
- **HTTP Negotiate auth**: The `http.emptyAuth=auto` setting now correctly attempts Negotiate (e.g., Kerberos) before falling back to manual credentials.
- **Memory leaks and crashes**: Fixes for leaks in `fetch_and_setup_pack_index()`, `git grep`, and `git cherry`, as well as crashes in diffstat UTF-8 truncation and commit signing with custom encodings.
- **Windows compatibility**: Improvements to signal handling, mmap cleanup, and linker warnings on newer macOS/Xcode versions.

The release also includes **documentation updates**, such as Jean-Noël Avila’s ongoing synopsis-style conversion of man pages, and **test suite improvements**, including better handling of `set -e` and TAP output validation.

This is a **major release candidate** with significant changes, particularly around performance, object storage, and parallelism. Users testing this RC should pay special attention to:
- The new `hook.jobs` configuration and parallel hook execution.
- The Linux fsmonitor daemon (if enabled).
- The `git push` remote group feature.
- Any custom scripts or tools that interact with Git’s object database or hooks.

The final release is expected soon, pending feedback on this RC.
