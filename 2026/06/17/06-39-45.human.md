This is the second patch in Patrick Steinhardt’s 17-part ODB abstraction series (v3), a refactoring effort that completes the conversion of packed object storage into a proper `struct odb_source`. This specific patch splits the packfile list logic into a new compilation unit (`packfile-list.c` and `packfile-list.h`) to break a cyclic header dependency that would otherwise block the upcoming introduction of `struct odb_source_packed`.

The change is purely mechanical: 83 lines of code are moved verbatim from `packfile.c` into the new files, and the original declarations are removed from `packfile.h`. The new unit provides the same API (`packfile_list_clear`, `packfile_list_remove`, `packfile_list_prepend`, `packfile_list_append`, and `packfile_list_find_oid`) and is wired into both the Makefile and Meson build systems. No behavior changes are introduced; this is a preparatory step for patch 1/17, which renames `struct packfile_store` to `struct odb_source_packed` and embeds a `struct packfile_list` inside it.

The patch is well-motivated and cleanly executed. It has already received surface-level review from Justin Tobler, who confirmed the mechanical correctness in v2. There are no open questions or objections; this is a straightforward infrastructure change that enables the larger ODB abstraction work. Readers following the ODB series can safely treat this as a routine preparatory step.
