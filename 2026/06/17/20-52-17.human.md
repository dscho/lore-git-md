This is the third patch in Kristoffer Haugsbakk’s five-part documentation series updating the `SubmittingPatches` guidelines for trailer conventions. It documents the `Based-on-patch-by:` trailer, which is used when a patch incorporates code originally authored by someone else—typically a patch previously sent to the mailing list.

The patch adds a concise four-line entry to the existing trailer list in `Documentation/SubmittingPatches`, explaining when to use `Based-on-patch-by:` instead of `Co-authored-by:` and emphasizing the requirement that the original author must have signed off on the patch (or be asked to do so if they haven’t). This addresses a gap in the current documentation, where the trailer’s use case wasn’t explicitly covered despite its frequent appearance in practice.

The change is uncontroversial and well-motivated, reflecting established mailing-list conventions. Feedback from Junio C Hamano in the v1 round led to a key clarification: the patch now explicitly states the precondition that the original author’s sign-off is required, aligning with DCO compliance. The series as a whole is finalized and ready for merging, with this patch fitting neatly into the broader effort to standardize trailer usage.
