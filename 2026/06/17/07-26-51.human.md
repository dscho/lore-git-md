This is the final patch in Patrick Steinhardt’s 17-part series completing the ODB abstraction for Git’s packed object storage. The patch removes the last vestige of the parent-child relationship between the packed and loose object sources by dropping the `files` pointer from `struct odb_source_packed`. The constructor now takes the object database, path, and locality flag directly, matching the loose source’s interface and making the packed source fully standalone. Justin Tobler’s review was mechanical, confirming the alignment with the loose source’s pattern and the improved type safety in `prepare_packed_git_one()`. The series as a whole is now technically complete, but remains blocked by an 11-patch refdb fix series that must land first. This patch is a small but symbolically important step: it finishes the interface unification that began with the ODB abstraction effort and signals the end of large-scale ODB restructuring work from Patrick.
