This is the third patch in Patrick Steinhardt’s 17-part ODB abstraction series (v3). It moves the packed object source (`struct odb_source_packed`) from `packfile.{c,h}` into the `odb/` subsystem, creating new files `odb/source-packed.{c,h}`. The change is purely mechanical: the struct definition and its constructor function are relocated without any behavioral modification.

The patch follows the established pattern set by the loose and in-memory object sources, which already live in `odb/`. This is a preparatory step for later patches that will turn `odb_source_packed` into a proper `struct odb_source` with all required callbacks. The diff is small (87 insertions, 75 deletions) and touches only build system files and the new/old source locations. No review feedback has been posted yet on this specific patch, but the series as a whole has received surface-level mechanical approval from Justin Tobler on earlier iterations.
