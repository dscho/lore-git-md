This is the sixteenth patch in Patrick Steinhardt’s 17-part series completing the ODB abstraction for Git’s packed object storage. The patch refactors multi-pack index (MIDX) interfaces to work directly with the new `struct odb_source_packed` type instead of the generic `struct odb_source`. This is a mechanical but important cleanup that removes a conceptual inconsistency: MIDXs are inherently tied to the packed source, so passing a generic source type was misleading.

The change is straightforward: every function that previously took a `struct odb_source *` now takes a `struct odb_source_packed *`, and callers are updated to downcast the generic source to its packed variant. The diff touches 13 files, mostly in the MIDX and repack subsystems, and is purely a type-system adjustment with no behavioral changes. This sets the stage for the next patch, which will remove the parent pointer from the packed source, completing the interface alignment with the loose source.

The patch is well-contained and looks like a natural follow-up to the earlier ODB abstraction work. It has already received surface-level review from Justin Tobler, who confirmed the mechanical correctness. Since this is part of a larger series that remains blocked by unresolved refdb lifecycle issues, it isn’t yet ready for merging, but the change itself appears uncontroversial and aligns with the series’ goal of a cleaner ODB interface.
