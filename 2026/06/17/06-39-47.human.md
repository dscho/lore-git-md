This is the fourth patch in Patrick Steinhardt’s 17-part ODB abstraction series (v3). It makes a small but important mechanical change to clarify the relationship between the packed object source and its parent “files” source.

The patch replaces the generic `struct odb_source *source` pointer in `struct odb_source_packed` with a more specific `struct odb_source_files *files` pointer. This is a temporary step that makes the code’s intent clearer: the packed source is owned by the files source, not by some generic ODB source. The change affects only four files and is purely a type-system adjustment—no behavior changes. All callers are updated to pass the concrete `files` pointer instead of the generic `source` one.

This is a well-motivated refactoring step that prepares for the eventual removal of the parent pointer altogether (patch 17/17). The commit message explains the rationale clearly, and the diff is minimal and mechanical. Justin Tobler’s earlier review already confirmed the interface alignment, so this patch should be uncontroversial. It’s a small but necessary part of the larger ODB abstraction effort.
