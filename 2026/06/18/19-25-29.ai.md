This is the final patch in Harald Nordgren’s 7-part `git branch --delete-merged` series, adding the `--dry-run` option. The patch is small, focused, and directly addresses the last piece of user-facing functionality promised in the cover letter.

The implementation is straightforward: when `--dry-run` is supplied alongside `--delete-merged`, the command prints which branches would be deleted (one “Would delete branch <name>” line per branch) and exits without touching any refs. The same filtering and safety checks apply, so the output is exactly the set that a real run would delete. The option is rejected if used without `--delete-merged`, preventing confusion.

The patch updates the man page with a concise description, adds the new `OPT_BOOL` in `builtin/branch.c`, and passes the `DELETE_BRANCH_DRY_RUN` flag into `delete_merged_branches()`. The test suite is extended with two new cases: one that verifies the dry-run output matches the real deletion output, and another that confirms the option is rejected when used alone.

This is a clean, well-scoped addition that completes the series’ advertised feature set. No open questions remain; the patch is ready for final review.
