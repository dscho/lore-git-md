This is the first patch in a seven-part series extending `git log -L` to support range-scoped diff stat formats, whitespace checking, and the `-G` pickaxe. This patch is pure refactoring: it renames and reorganizes the line-range filter internals to make the code clearer before the functional changes in later patches.

The patch targets `diff.c`, renaming `struct line_range_callback` to `struct line_range_filter` and replacing cryptic abbreviations (`lno_post`, `lno_pre`, `rhunk_*`) with descriptive names (`lno_in_postimage`, `lno_in_preimage`, `hunk.old_begin`, etc.). The hunk state is also moved into a nested `hunk` struct for better grouping. The commit message explains the rationale: the current naming conflates pre/post-image axes with 0-based/1-based indexing, making the code hard to follow. No behavior changes are introduced.

This is a well-motivated cleanup that directly supports the series' goal of making the line-range filter easier to extend. The detailed commit message and careful renaming suggest the author has put thought into making the code more maintainable. If the rest of the series maintains this level of clarity, it looks like a solid contribution.
