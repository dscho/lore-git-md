This thread introduces a patch to make Git's typo correction interactive by default—prompting users to run the corrected command when a single close match is found. The patch touches `help.c` and related files, adding TTY detection and argument preservation, and includes new tests.

Justin Tobler's review reveals that the proposed behavior already exists via `help.autoCorrect=prompt`, which handles both the interactive prompt and argument passing. The patch's commit message doesn't explain why this config-based approach is insufficient or why the default behavior should change, making the patch appear redundant. No technical flaws are raised, but the discussion has shifted to whether the feature is needed at all. The thread now hinges on whether to adjust the default, deprecate the config option, or rework the patch to address unmet needs.
