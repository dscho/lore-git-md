Core problem or goal
When a user mistypes a Git command, Git currently prints a list of close matches and exits. The patch changes this so that, when there is exactly one close match and the session is interactive (stdin and stderr are terminals), Git prompts the user with the full corrected command line (including original arguments) and re-executes if the user answers 'y'.
