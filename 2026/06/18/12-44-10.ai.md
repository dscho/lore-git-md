This is the v14 cover letter for Harald Nordgren’s `--track=fetch` feature series, now split into two patches. The series extends `git checkout` and `git switch` with a `--track=fetch` mode that automatically fetches from the remote when creating a tracking branch, addressing the workflow pain point where users must manually fetch before checking out remote branches.

The v14 update is minimal: it improves header file handling by replacing an explicit `#include "string-list.h"` with a forward declaration (`struct string_list;`) in `branch.h`. This is a minor cleanup suggested by Junio in the v13 review. The rest of the series remains unchanged—v13 already completed the technical work by exposing tracking remote lookup functions from `branch.c` (patch 1/2) and implementing the feature using those shared helpers (patch 2/2). The implementation is technically approved, with comprehensive test coverage (276 lines) and consistent error handling across commands.

The series is now technically complete, with only the maintainer’s final decision on the feature’s workflow merit outstanding. Junio has expressed sustained reservations about the feature’s value—specifically, whether the convenience of automatic fetching during checkout justifies the potential risks (e.g., network operations without user preview, encouraging risky workflows). Harald has acknowledged the series is unlikely to be merged and reflected on the review process, noting that technical feedback proceeded before the feature’s fundamental acceptance was resolved. Junio clarified that technical approval was conditional on broader support for the feature’s premise, and authors are expected to advocate for their feature’s merit to build that support.
