This is the first patch in Harald Nordgren’s v16 series implementing `git branch --delete-merged`, introducing the `--forked` filter for `git branch --list`. The filter is the foundation for the deletion logic: it lets users list only branches whose upstream matches a given ref, remote, or glob pattern (e.g., `origin/*`). The implementation is clean, well-tested, and integrates naturally with the existing `--merged`/`--no-merged` filters. The patch touches `ref-filter.c`/`ref-filter.h` for the core matching logic, `builtin/branch.c` for the CLI plumbing, and adds comprehensive tests in `t3200-branch.sh` that cover exact refs, globs, remote shorthand, and composition with other filters. No red flags; this is a solid building block for the series.
