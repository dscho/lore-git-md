This is the first patch in Harald Nordgren’s v14 `--track=fetch` series, a refactoring that exposes tracking-remote lookup helpers from `branch.c` for reuse elsewhere. The patch moves `struct tracking` to `branch.h` and adds two public functions—`find_tracking_remote_for_ref()` and `advise_ambiguous_fetch_refspec()`—that encapsulate the logic previously buried in `setup_tracking()`. The only functional change is a minor header cleanup: replacing `#include "string-list.h"` with a forward declaration (`struct string_list;`) in `branch.h`, as Junio requested in the v13 review.

The refactoring is straightforward and well-motivated. It extracts shared infrastructure that both `git branch --track` and the upcoming `--track=fetch` feature (patch 2/2) will use, avoiding code duplication. The commit message clearly explains the purpose—enabling other commands to determine which remote owns a given tracking ref—and the implementation is clean, with no behavior changes. The patch is technically complete, with all prior review feedback addressed, and it carries Junio’s and Phillip Wood’s approvals from earlier iterations.
