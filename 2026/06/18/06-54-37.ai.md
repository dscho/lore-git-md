This is the final patch in Patrick Steinhardt's 8-part refactoring series modernizing Git's reference backend infrastructure. It performs a small but meaningful cleanup in `refs.c` by eliminating an unnecessary local buffer in `refs_compute_filesystem_location()`.

The patch removes a redundant `strbuf` allocation that was only used as an intermediate step before calling `strbuf_realpath()`. The function already supports using the same buffer for both input and output, making the extra allocation pointless. The change reduces memory churn and simplifies the code by removing 6 lines (including the buffer initialization and release) while adding just 2. The logic remains identical: it still handles both relative and absolute paths correctly, and the worktree detection logic is untouched.

This is a pure refactoring with no behavior change, addressing a minor inefficiency in a core ref subsystem function. The patch is uncontroversial and aligns with the series' broader goal of cleaning up reference backend internals. Given the thorough review the earlier patches received (particularly the memory leak fixes and initialization improvements), this final cleanup should be ready for integration. It touches only `refs.c` and requires no coordination with other subsystems.
