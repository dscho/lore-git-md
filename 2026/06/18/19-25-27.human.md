This is the core implementation patch in Harald Nordgren's v16 series adding `git branch --delete-merged`, a safe automated local branch cleanup command. The patch introduces the new `--delete-merged` option to `git branch`, which deletes local branches whose work has already landed on their upstream, while preserving branches that are checked out, missing their upstream, or push to the same remote (like `main` tracking `origin/main`).

The implementation is technically complete and addresses all prior blocking issues: it uses the unified flags-based API (matching `delete_branches()`), omits the controversial stacked-branch safety check (per Junio's feedback), and integrates naturally with the existing `--forked` filter. The new option silently skips unmerged branches rather than aborting, and supports per-branch opt-out via `branch.<name>.deleteMerged` config. The test suite verifies all safety cases together in a single realistic workflow, showing both deleted and preserved branches.

This patch is the centerpiece of the series and appears ready for final review. The commit message and documentation clearly explain the behavior and safety mechanisms, and the code itself is clean and well-structured. If the series lands, this will be a significant usability improvement for users who work with many topic branches in a fork workflow.
