This is the first patch in Harald Nordgren’s v3 series introducing `git history squash`. It is a refactoring patch that extracts a small helper function, `first_parent_tree_oid()`, from three duplicated code paths in `builtin/history.c`. The helper consolidates the logic for resolving the tree OID of a commit’s first parent (or the empty tree for a root commit) and propagates any parse errors. The patch is purely mechanical, touching only `builtin/history.c` with 26 insertions and 32 deletions, and makes no behavior changes.

The helper is immediately used in three places: `commit_tree_with_edited_message()`, `commit_became_empty()`, and `split_commit()`. Each caller now delegates the tree resolution to the helper, eliminating the repeated `repo_parse_commit()` and `oidcpy()` dance. The patch is a clean, focused refactoring that prepares the codebase for the subsequent `squash` subcommand implementation by reducing duplication and centralizing a common operation. It is uncontroversial and appears ready for integration.
