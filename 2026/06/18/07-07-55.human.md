This is an **announcement** for the Git for Windows 2.55.0-rc1 release candidate.

Johannes Schindelin announces the availability of Git for Windows 2.55.0-rc1, the first release candidate for the upcoming 2.55.0 version. This release tracks upstream Git v2.55.0-rc1 but is a separate distribution tailored for Windows users. The release drops support for Windows 8.1 following the MSYS2 project’s lead, a change that will take effect after this version.

Key updates include the latest MSYS2 runtime (based on Cygwin v3.6.9), Git Credential Manager v2.8.0, cURL v8.20.0, OpenSSL v3.5.7, and Bash v5.3.15. The FSCache feature now accelerates more `git add` scenarios, and the diff helper for Word documents has been ported from Perl to Rust, reflecting ongoing modernization efforts.

Several bugs have been fixed: an endless unlink loop during `git fetch` on older Windows 10 versions, a process shutdown issue in Git Bash, and parallel checkout failures when FSCache is enabled. Git Bash (MinTTY) also now respects screen scaling settings more reliably.

The announcement includes SHA-256 checksums for all downloadable artifacts (installers, portable builds, and archives for x86, ARM64, and BusyBox variants). This is a routine release candidate, so unless you’re a Windows user testing the new version, there’s no immediate action required. The fixes and updates are Windows-specific and don’t affect upstream Git’s core functionality.
