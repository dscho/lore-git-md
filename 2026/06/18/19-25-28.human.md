This is the sixth patch in Harald Nordgren’s v16 series implementing `git branch --delete-merged`, a new command for safe automated local branch cleanup. This installment adds a per-branch opt-out mechanism via the `branch.<name>.deleteMerged` configuration setting.

The patch introduces a new config key that, when set to `false`, exempts the specified branch from deletion under `--delete-merged`. The exemption is reported to the user (unless `--quiet` is given) so they understand why their topic branch was preserved. Crucially, the opt-out only applies to the automated `--delete-merged` command; explicit deletion via `git branch -d` still works normally and ignores the setting.

The implementation is straightforward: a single `strbuf` is reused to construct the config key for each candidate branch, and a boolean check skips any branch whose `deleteMerged` value is `false`. The test suite verifies both the opt-out behavior and the fact that explicit deletion remains unaffected. The patch is well-motivated, clearly documented, and fits neatly into the safety architecture established by earlier patches in the series. No controversy or open questions remain.
