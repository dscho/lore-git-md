This is the final patch in Karthik Nayak’s seven-part series extending `git log -L` (line-log) to support range-scoped diff stat formats, whitespace checking, and the `-G` pickaxe. This patch teaches `-G` to honor the tracked line range, so commits are selected only if the pattern appears on an added or removed line within the range.

The implementation exposes the line-range filter as `diff_emit_line_ranges()`, a scoped version of `xdi_diff_outf()`, and threads the filepair’s `line_ranges` through the pickaxe callback. The patch deliberately skips scoping under textconv, since the driver’s output is not in the original file’s line coordinates. `-S` is left unchanged because it counts needle occurrences per blob rather than grepping the diff, so scoping it would require a different approach.

The documentation update clarifies the behavioral distinction between `-G` (range-scoped) and `-S` (whole-file), and the tests verify that `-G` now correctly ignores changes outside the tracked range, including under textconv. The series as a whole is well-structured, with detailed commit messages and thorough test coverage, and it addresses a clear gap in `-L`’s functionality. This patch completes the feature set described in the cover letter.
