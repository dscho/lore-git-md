This is the fourth and final patch in Harald Nordgren’s `git history squash` series (v3). It implements the `--reedit-message` option so that when the user chooses to re-edit the squashed commit’s message, the editor is seeded with *every* folded-in commit’s message (oldest first), mirroring the behavior of `git rebase -i`’s squash.

The patch adds a new helper `build_squash_message()` that walks the commit range in reverse topological order, extracts each commit’s subject and body, and concatenates them into a single template. The template is built *before* the descendant walk so that the flags the walk leaves on the commits do not interfere. The plumbing patch (2/4) already extended `commit_tree_ext()` to accept a `message_template` parameter; this patch simply passes the constructed template to that function.

Documentation is updated to clarify that `--reedit-message` now offers all folded messages, not just the oldest. The test script grows two new tests: one that verifies the editor receives every message, and another that confirms the operation aborts cleanly if the user clears the message.

The implementation is clean, the test coverage is thorough, and the change directly addresses the user-experience gap Phillip Wood raised in earlier rounds. No new objections or edge cases are introduced; this patch completes the series.
