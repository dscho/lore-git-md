This is the second patch in Harald Nordgren’s four-part series introducing `git history squash`. It adds a `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`, allowing callers to supply a custom commit message instead of reusing the original commit’s message.

The change is small (16 lines, 10 insertions, 6 deletions) and mechanical: the function now accepts an optional template string, and when NULL, falls back to the original behavior. The existing `fixup` and `split` callers pass NULL, so they remain unchanged. This prepares the ground for the next patch, which will use the new parameter to seed the squash commit’s message with the combined messages of all folded commits.

The patch is uncontroversial and clearly motivated by the upcoming squash feature. It does not change any user-visible behavior on its own, but it is a necessary refactoring step for the series’ overall goal.
