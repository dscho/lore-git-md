Git for Windows 2.55.0-rc1 release announcement by Johannes Schindelin. The thread is a routine pre-release update for the Git for Windows distribution, which tracks upstream Git v2.55.0-rc1 but includes Windows-specific packaging, dependency updates, and bug fixes. This release drops Windows 8.1 support (following MSYS2), updates the MSYS2 runtime to Cygwin v3.6.9, Git Credential Manager to v2.8.0, cURL to v8.20.0, OpenSSL to v3.5.7, and introduces a Rust port of the diff helper for Word documents. Windows-specific bug fixes address `git fetch` regressions (endless unlink loops on older Windows 10), process shutdown issues in Git Bash, parallel checkout failures with FSCache, and improved screen scaling in MinTTY. The announcement provides download links for x64, ARM64, 32-bit installers, portable builds, MinGit, and tarballs. No upstream Git codebase changes or mailing list discussions are impacted; this is purely a distribution update. Key participants: Johannes Schindelin (author). No open questions or technical decisions for the Git project. Related work: Git for Windows packaging and dependency management.
