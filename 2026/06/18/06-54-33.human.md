This is a bugfix patch in Patrick Steinhardt’s 8-part refactoring series that modernizes Git’s reference backend. It plugs a long-standing memory-management hole in the `chdir_notify` subsystem: reference stores were being registered for directory-change notifications but never unregistered, leaving dangling pointers that could point to freed memory (for submodules and worktrees) or simply leaking the main repository’s refdb. The patch switches from `chdir_notify_reparent()` to `chdir_notify_register()` so that the stores can later be unregistered in the release functions. The change is mechanical, touches all three ref backends (files, packed, reftable), and is uncontroversial—it fixes a latent bug without altering behavior. Reviewers familiar with ref backends or repository teardown will recognize this as a necessary hygiene improvement that paves the way for the larger absolute-path transition deferred from earlier versions of the series.
