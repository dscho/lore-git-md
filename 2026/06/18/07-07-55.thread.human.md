This is a routine announcement for the Git for Windows project, not a development thread for the upstream Git codebase. Johannes Schindelin has released Git for Windows 2.55.0-rc1, which tracks the upstream Git v2.55.0-rc1 release but includes Windows-specific updates and fixes.

The release drops support for Windows 8.1, updates bundled dependencies (MSYS2 runtime, Git Credential Manager, cURL, OpenSSL), and includes a Rust-based diff helper for Word documents. Several Windows-specific bugs are fixed, including fetch regressions, process shutdown issues in Git Bash, and parallel checkout failures with FSCache. The announcement provides download links for various architectures and formats, but these changes are limited to the Windows distribution and do not affect the core Git project.
