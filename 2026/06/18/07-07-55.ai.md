This is an **announcement** for the Git for Windows 2.55.0-rc1 release, not a patch or technical discussion for the Git project itself. Johannes Schindelin announces the availability of Git for Windows 2.55.0-rc1, which tracks upstream Git v2.55.0-rc1 but includes Windows-specific updates, bug fixes, and bundled dependencies.

The release drops Windows 8.1 support after this version, following the MSYS2 project’s lead. Key updates include the latest MSYS2 runtime (Cygwin v3.6.9), Git Credential Manager v2.8.0, cURL v8.20.0, OpenSSL v3.5.7, and a Rust port of the diff helper for Word documents. Bug fixes address regressions in `git fetch` (endless unlink loops on older Windows 10), process shutdown issues in Git Bash, parallel checkout failures with FSCache, and improved screen scaling support in MinTTY.

The announcement provides download links for multiple architectures (x64, ARM64, 32-bit) and formats (installers, portable builds, MinGit, and tarballs). This is a routine pre-release update for the Windows distribution, with no direct impact on the upstream Git codebase or mailing list discussions beyond platform-specific compatibility. The changes are primarily packaging, dependency updates, and Windows-specific fixes.
