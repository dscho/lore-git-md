This is a follow-up to the ongoing discussion about the curl authentication regression affecting Git's HTTP test suite. Todd Zullinger reports that the issue is resolved in curl 8.21.0-rc3, which Fedora has already packaged. The fix means Git's test t5563.18 now passes again without requiring any changes to Git itself.

The thread confirms that the root cause was indeed the curl regression (curl/curl#21943) introduced in commit 8f71d0fde515, and that upstream has addressed it in time for the final 8.21.0 release. Todd's update closes the loop on the Git side, noting that distributions are already picking up the fix, so no Git-side changes are needed. The tone is positive, highlighting the effectiveness of the test suite in catching regressions and the responsiveness of the curl project.

This is good news for anyone tracking the Git 2.55.0 release: the HTTP authentication test failure was a false alarm caused by a transient curl issue, not a problem in Git. The thread is now effectively resolved.
