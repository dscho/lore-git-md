This is the fourth patch in Karthik Nayak’s seven-patch series extending `` `git log -L` `` to support range-scoped diff stat formats, whitespace checking, and the `` `-G` `` pickaxe. The patch extracts a reusable helper, `` `line_range_filter_diff()` ``, from the open-coded line-range filter setup in `` `builtin_diff()` ``, along with an initialization function, `` `line_range_filter_init()` ``.

The helper consolidates the boilerplate that every consumer of the line-range filter needs: inflating `` `ctxlen` `` to the largest range span so each range yields a single xdiff hunk, clearing `` `XDL_EMIT_NO_HUNK_HDR` `` so the filter can seed its position from hunk headers, running the diff, flushing the final range hunk, and releasing the filter’s buffer. By folding these steps into a single function, the patch ensures the invariants the filter relies on are maintained consistently across all consumers. The next two patches will reuse this helper in `` `builtin_diffstat()` `` and `` `builtin_checkdiff()` ``, eliminating duplicated code.

The patch touches only `` `diff.c` `` and introduces no behavior change; it is purely a refactoring that prepares the codebase for the new functionality in patches 5-7. The commit message explains the design choices clearly, and the code changes are mechanical and well-contained. This looks like a clean, necessary step in the series.
