This is a refactoring patch in Harald Nordgren’s `git branch --delete-merged` series (v16, patch 2/7). It converts the `delete_branches()` and `check_branch_commit()` functions from separate boolean arguments (`force`, `quiet`) to a single `unsigned int flags` parameter, matching the pattern used elsewhere in Git.

The change is purely mechanical: the two booleans are replaced with an enum (`DELETE_BRANCH_FORCE`, `DELETE_BRANCH_QUIET`) and the flags are unpacked into local booleans at the start of each function. The rest of the code remains unchanged, so behavior is identical. The patch addresses Phillip Wood’s earlier feedback about API consistency by aligning `delete_branches()` with the flags-based interface used by other branch-deletion functions.

This is a small, focused refactor that prepares the ground for the later patches in the series, which will add more flags to control the new `--delete-merged` behavior. The commit message is clear and the diff is straightforward, making it easy to verify that no logic was altered. No controversy or open questions remain on this patch.
