This is v13 of Harald Nordgren's series adding `git branch --prune-merged` for safe automated local branch cleanup, now with final refinements before merging. The series has evolved through 13 iterations with all major technical concerns addressed.

Key changes in v13:
- Reworked `--forked` to be a proper ref-filter applied in `apply_ref_filter()` rather than a post-processing step
- Now matches exact `--forked` patterns on full refnames (only globs use abbreviated upstream)
- Replaced boolean parameters in `delete_branches()`/`check_branch_commit()` with a single flags bitfield
- Made `--prune-merged` take its branch patterns as positional arguments rather than repeating the option
- Added comprehensive tests for the new filtering behavior

The implementation now:
- Uses wildmatch` for glob pattern matching
- Combines literal and glob arguments via union
- Preserves branches by name (not just by upstream)
- Includes `--dry-run` support showing exactly what would be deleted
- Maintains configurable opt-out via `branch.<name>.pruneMerged`

The safety model has been strengthened through collaborative review, particularly around tracking branch protection and interface design. The series appears technically complete and ready for final review before potential merging.
