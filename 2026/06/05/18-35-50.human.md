This is patch 3/6 in the final v13 iteration of Harald Nordgren's series adding `git branch --delete-forked` (formerly `--prune-merged`), which provides safe automated local branch cleanup. The series is now in its final polishing phase before merging.

The patch prepares the `delete_branches()` function for bulk branch deletion by adding two new modes:
1. A `NO_HEAD_FALLBACK` mode that checks only against a branch's upstream (not falling back to HEAD when no upstream exists)
2. A `DRY_RUN` mode that shows what would be deleted without actually removing refs

The changes maintain all existing safety checks while enabling the new functionality. The implementation uses a flags bitfield for parameters rather than booleans, making the interface cleaner and more extensible. The patch includes thorough handling of edge cases, such as properly skipping HEAD fallback checks when explicitly requested.

This is a technical refactoring that enables the core functionality of the series while preserving Git's careful branch protection mechanisms. The changes are well-contained and focused on the kind of preparatory work needed before introducing new user-facing features.
