This is a documentation patch in Kristoffer Haugsbakk's series standardizing the `git replay` configuration documentation. The patch focuses on improving the presentation of the `replay.refAction` option description in the config documentation.

Key changes in this patch:
- Converts the bullet-point list of refAction modes to a description list format (using `;;` delimiters), which Junio Hamano had requested in earlier reviews
- Adds conditional linking to avoid self-references within the git-replay man page
- Moves the default value indicator to the right side for consistency with Git conventions
- Adds cross-references between the config and command documentation

The changes are purely stylistic - no functional changes to the configuration itself. This continues the series' goal of bringing the replay documentation in line with project conventions while maintaining technical accuracy. The patch follows established patterns seen in other config documentation updates.

Kristoffer notes in the commit message that this change was inspired by similar work in commit e7b3a768 for `init.templateDir`. The patch has already incorporated feedback from Junio and Patrick Steinhardt from previous iterations.
