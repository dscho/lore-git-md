This is the final patch in Harald Nordgren's 13-iteration series adding `git branch --prune-merged` (formerly called `--delete-forked`), which provides safe automated cleanup of local branches whose upstream branches have been merged. The series is now in its final polishing phase before merging.

The patch adds a `--dry-run` option that shows which branches would be deleted without actually removing them, useful for previewing the effect of a wide pattern like `'origin/*'`. The implementation:
- Prints "Would delete branch <name>" for each candidate branch
- Maintains all the same safety checks as the real operation
- Rejects `--dry-run` when not used with `--prune-merged`

The tests verify that:
- Dry-run shows the correct branches that would be deleted
- It doesn't list branches that would be protected (like checked-out branches)
- The option is properly rejected when used alone

This completes the feature set for safe bulk branch deletion, joining the existing warn-only mode, configurable opt-outs, and comprehensive safety checks. The series has been thoroughly reviewed over 13 versions and appears ready for merging.
