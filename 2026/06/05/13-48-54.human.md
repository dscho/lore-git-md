This is a review of the final v12 patch series adding `git branch --prune-merged` functionality, focusing on the `--forked` filter implementation. Phillip Wood provides substantive feedback on the technical implementation details while acknowledging the series is in good shape overall.

Key points from the review:
- Suggests supporting remote names as aliases for `$remote/HEAD` to match `git checkout -b` behavior
- Recommends moving the `--forked` documentation next to similar filtering options like `--merged`
- Proposes implementing the filtering earlier in `apply_ref_filter()` rather than post-processing the array
- Notes concerns about abbreviating refnames which could introduce ambiguity
- Points out the quadratic matching behavior for multiple patterns (though not a blocker)
- Suggests using full refnames for matching rather than abbreviated ones
- Recommends using `strvec` instead of `string_list` for the implementation

The review identifies several opportunities to improve the implementation's robustness and maintainability, particularly around refname handling and filtering integration. However, Phillip acknowledges the core approach is sound and the series appears ready for final review before merging.

This represents the final round of review for a series that has undergone extensive iteration (12 versions) with all major technical concerns previously addressed. The feedback focuses on polish and implementation details rather than fundamental issues.
