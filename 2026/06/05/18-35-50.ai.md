This is patch 3/6 in Harald Nordgren's v13 series adding `git branch --delete-forked` (formerly `--prune-merged`) functionality. The patch prepares the `delete_branches()` function for bulk branch deletion operations.

The key changes introduce two new modes for branch deletion:
1. `DELETE_BRANCH_NO_HEAD_FALLBACK` - Skips the fallback to HEAD when checking if a branch is merged (used when the caller has established the branch has an upstream)
2. `DELETE_BRANCH_DRY_RUN` - Shows what would be deleted without actually removing any refs

The implementation:
- Adds new flag bits to the existing `delete_branch_flags` enum
- Modifies `branch_merged()` to respect the no-HEAD-fallback mode
- Updates `delete_branches()` to handle dry-run output
- Maintains all existing safety checks while adding the new functionality

This is a technical refactoring that enables the bulk deletion capabilities needed for the full `--delete-forked` feature while preserving the safety mechanisms that prevent accidental data loss. The changes are focused and well-contained to the branch deletion infrastructure.
