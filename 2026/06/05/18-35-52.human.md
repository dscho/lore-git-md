This is patch 5/6 in the final v13 iteration of Harald Nordgren's series adding `git branch --prune-merged` (formerly `--delete-forked`) for safe local branch cleanup. The patch introduces a configurable opt-out mechanism via `branch.<name>.pruneMerged=false` to exempt specific branches from automated deletion while still allowing explicit deletion with `git branch -d`.

The implementation:
- Adds documentation for the new config option in both the config and command man pages
- Modifies the pruning logic to check the config setting before deletion
- Reports skipped branches (unless `--quiet` is given) so users understand why a branch was preserved
- Includes tests verifying both the opt-out behavior and that `branch -d` remains unaffected

This completes the safety mechanisms for the feature, allowing users to be protected from accidentally deleting branches they intend to keep developing, even if those branches appear merged. The patch maintains all existing safety checks while adding this new layer of protection. With this addition, the series appears technically complete and well-tested, addressing all major concerns raised during its 13-iteration review process.
