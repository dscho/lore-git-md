This is the fourth patch in the v4 series optimizing `paint_down_to_common()` in Git’s commit-reach subsystem. It adds **trace2 instrumentation** to measure the number of commits visited during the paint walk, enabling observable performance metrics via `GIT_TRACE2_EVENT` without relying solely on wall-clock benchmarks.

The patch introduces a step counter in `paint_down_to_common()` and emits a trace2 event (`trace2_data_intmax`) at the end of the walk, reporting the total steps taken. This allows developers to quantify the impact of future optimizations (like the side-exhaustion optimization in patch 7/8) across different commit-graph modes (none, full, half, no-gdat). The test suite is updated to capture trace2 output per mode and validate step counts using a new helper, `test_paint_down_steps()`, which checks the recorded steps against expected values for each mode.

The changes are **minimal and focused**: only 5 lines added to `commit-reach.c` (the step counter and trace2 call) and 36 lines to `t/t6600-test-reach.sh` (refactoring `run_all_modes()` to capture trace2 output and adding step-count assertions for existing and new tests). The test updates ensure the instrumentation is **self-verifying**—step counts are asserted for all commit-graph modes in every relevant test, including the new edge cases added in patch 2/8 (e.g., `pending-stale` and `infinity-both-sides`).

Derrick Stolee **unconditionally approved** this patch in v3, calling the implementation "clean" and noting it "over-achieves" by capturing step counts for all modes. The patch is **stable and uncontroversial**, with no changes since v3. It is **ready to merge** and provides the foundation for the performance claims in the series, particularly the dramatic speedups demonstrated in patch 7/8.

**Key technical details**:
- **New symbols**: `steps` counter in `paint_down_to_common()`, `test_paint_down_steps()` helper in `t6600-test-reach.sh`.
- **Behavior change**: None; this is purely instrumentation.
- **Test coverage**: Step-count assertions for all commit-graph modes (none, full, half, no-gdat) in tests for `in_merge_bases_many`, `get_merge_bases_many`, and `merge-base --all`.
- **Files touched**: `commit-reach.c`, `t/t6600-test-reach.sh`.
