This is the second patch in Harald Nordgren’s four-patch `git history squash` series (v6). It adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the original commit’s message; when NULL, behavior is unchanged. The patch updates all existing callers (`cmd_history_fixup` and `split_commit`) to pass NULL, preserving their current behavior.

The change is a plumbing prerequisite for the `--reedit-message` feature in the final patch: `git history squash --reedit-message` will build a template from every folded-in commit and hand it to `commit_tree_ext()` so the user can edit the combined message before the squash commit is written. The implementation is minimal and mechanical, touching only the function signature, a single conditional, and the two call sites. No new behavior is exposed yet; the template machinery will be exercised in patch 4/4.
