This is the fourth and final patch in Harald Nordgren’s `git history squash` series (v6), implementing the `--reedit-message` feature to let users combine commit messages from every folded-in commit, not just the oldest one.

The patch adds a new helper `build_squash_message()` that walks the commit range in reverse topological order, collects each commit’s subject and body, and concatenates them (oldest first) into an editor template. When the user supplies `--reedit-message`, this template is passed to the editor, mirroring the behavior of `git rebase -i`’s squash. The plumbing layer `commit_tree_ext()` already gained a `message_template` parameter in an earlier patch, so this change simply wires it up.

Tests verify that every folded-in message appears in the template and that an empty message aborts the operation. The documentation is updated to clarify that `--reedit-message` now offers all messages, not just the oldest.

The implementation is clean and well-tested; no further design changes are expected. This patch completes the series, which is now ready for Junio’s final review.
