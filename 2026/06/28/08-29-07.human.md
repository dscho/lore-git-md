This is the second patch in Harald Nordgren’s four-part series introducing `git history squash`. It extends the internal `commit_tree_ext()` helper with an optional `message_template` parameter, allowing callers to supply a custom commit message instead of reusing the original commit’s message. The change is minimal and mechanical: the existing fixup and split callers pass `NULL` to preserve their current behavior, while the upcoming `git history squash` command will use this new parameter to seed the editor with a combined message from all folded commits.

The patch itself is straightforward refactoring with no behavior change for existing commands. It touches only `builtin/history.c` and is clearly motivated by the need to support `--reedit-message` in the squash feature, where the user expects to see every folded commit’s message in the editor. The commit message explains the purpose and the backward-compatible design (NULL leaves behavior unchanged), and the diff is clean and focused. This is a well-crafted plumbing change that directly supports the series’ overall goal.
