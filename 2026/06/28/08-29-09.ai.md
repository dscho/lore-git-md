This is the fourth and final patch in Harald Nordgren’s `git history squash` series (v6). It implements the `--reedit-message` flag to gather and present *all* folded-in commit messages (oldest first) in the editor template, mirroring the behavior of `git rebase -i` when squashing.

The patch adds a new helper function, `build_squash_message()`, which walks the commit range in reverse topological order, extracts each commit’s subject and body, and concatenates them into a single template. The template is then passed to the existing `commit_tree_ext()` plumbing (introduced in an earlier patch) via its `message_template` parameter. The man page is updated to clarify that `--reedit-message` now opens an editor pre-filled with every folded commit’s message, not just the oldest one.

Test coverage verifies that the template includes all folded-in messages, that the editor can combine them into a new message, and that the operation aborts if the user leaves the message empty. The implementation is straightforward and leverages Git’s existing revision-walking machinery, making it a clean and maintainable addition. No design questions remain; this patch completes the series.
