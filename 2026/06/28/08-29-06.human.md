This is the first patch in Harald Nordgren’s **v6 `git history squash` series**, a refactoring that extracts a small helper function to reduce code duplication. The patch introduces `first_parent_tree_oid()`, which encapsulates the common pattern of resolving the tree of a commit’s first parent (or falling back to the empty tree for root commits). Three existing call sites in `builtin/history.c` are updated to use the new helper, trimming 32 lines of repetitive code down to 26.

The change is purely mechanical and has no effect on behavior. It is a preparatory step for the rest of the series, which will rely on the helper in later patches. The commit message is clear and the diff is clean, making this a straightforward, uncontroversial refactoring.
