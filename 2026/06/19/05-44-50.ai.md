This is the first patch in a now-merged five-part documentation series that standardizes Git's trailer conventions in `Documentation/SubmittingPatches`. The patch encourages the use of trailers (e.g., `Helped-by`, `Co-authored-by`) for substantial contributions while cautioning against over-crediting minor help. It explicitly requires trailers to follow the Git author format (name + email) to ensure proper parsing by `git shortlog --group=trailer:<key>` and `.mailmap` normalization. The patch also introduces a dedicated "Commit trailers" section, moving existing trailer examples into it and linking from the `send-patches` section for better visibility.

The changes are mechanical but meaningful: replacing "If you like" with direct encouragement, adding a new heading for HTML output clarity, and frontloading the list of common trailers. The motivation is well-supported by references to mailing list discussions and aligns with Git's practice of crediting contributors in release notes. The patch is uncontroversial and part of a broader effort to codify existing conventions into clear, prescriptive guidelines. No technical debt or open questions remain; this is a straightforward documentation improvement.
