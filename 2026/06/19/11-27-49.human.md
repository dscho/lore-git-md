This is the first patch in Patrick Steinhardt’s v4 refactoring series for Git’s reference backend. It inlines the `check_and_apply_repository_format()` helper function into its two callsites in `setup.c` (`enter_repo()` and `init_db()`). The commit message explains this is preparatory work: a later patch will change the order of reading and applying the repository format in one of these callsites, making the helper function no longer suitable.

The change is purely mechanical—no behavior is altered, only code structure. The patch removes 31 lines of helper code and replaces them with 16 lines of inlined logic, making the flow slightly more explicit at each callsite. This is a classic refactoring step: simplify the codebase by eliminating a helper that no longer fits the evolving design. The patch is uncontroversial and part of the series’ broader goal of modernizing ref backend initialization.
