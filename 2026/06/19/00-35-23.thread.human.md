This thread is about a sudden and puzzling reliability problem in Git’s GitHub Actions CI: macOS jobs (`osx-clang` and `osx-gcc`) are now hitting the 6-hour timeout and being killed, yet the exact same commit completes in under 30 minutes when all other CI jobs are disabled. Junio C Hamano, the maintainer, has posted the details and is asking for help from anyone familiar with macOS CI quirks or GitHub Actions flakiness. The issue appears to be environmental—possibly resource contention or a change in the runner image—rather than a code regression, but so far no root cause has been identified. If you’ve seen similar behavior or have insights into macOS CI, this is the thread to watch.
