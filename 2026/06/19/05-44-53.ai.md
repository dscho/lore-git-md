This is the fourth patch in a now-merged five-part documentation series that standardizes Git’s commit-message trailer conventions. The patch enforces consistent markup for trailer references throughout `Documentation/SubmittingPatches`: every trailer key is now wrapped in backticks and followed by a colon (e.g., `` `Signed-off-by:` ``). The change is purely mechanical—seven one-line substitutions—and aligns the document with the project-wide AsciiDoc style used in the rest of the file and in Jean-Noël Avila’s ongoing man-page standardization effort. No substantive content is altered; the patch simply removes visual inconsistency that could confuse new contributors. Because the series is already merged, this patch is effectively a historical record of the final stylistic polish.
