This is a documentation patch, part of Matt Hunter’s now-merged 8-patch series that adds the global `fetch.followRemoteHEAD` configuration option. This specific patch documents the new `fetchRemoteHEADWarn` advice message in `Documentation/config/advice.adoc`.

The patch adds a four-line entry explaining when the advice appears: when `git fetch` detects that the remote’s `HEAD` symref disagrees with the locally configured remote `HEAD` and the user has enabled warnings via `remote.<name>.followRemoteHEAD = warn` or `warn-if-not-$branch`. The text cross-references the `git-fetch` man page and keeps the style consistent with the surrounding advice entries.

This is a straightforward, uncontroversial addition that closes a small gap in the user-facing documentation. The commit message is clear and the diff is minimal. Since the series is already merged to `master`, this patch is effectively a post-merge formality—it simply ensures the advice message is discoverable in `git config --help advice`.
