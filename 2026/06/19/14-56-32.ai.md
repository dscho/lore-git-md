This is a small refactoring patch in the GSoC `git cat-file --batch-command` series. It moves loop counter declarations (`int i`) into the `for()` statement itself and changes the type from `int` to `size_t` where appropriate, improving code hygiene and readability.

The patch touches two files: `builtin/cat-file.c` (three loops in the batch-command dispatch logic) and `fetch-pack.c` (one loop writing server options). Each loop now declares its counter inline (`for (size_t i = 0; ...)`), which is the modern C style and makes it clearer that the variable is only used within the loop. The type change to `size_t` aligns the counter with the types of the arrays it indexes (`nr` and `ARRAY_SIZE()` both return `size_t`).

This is the third patch in the twelve-patch series; the cover letter and earlier patches established the security-hardened remote-object-info protocol. The change here is purely mechanical and has no behavioral impact. It addresses a minor readability nit that Junio Hamano raised in review of an earlier iteration. The patch carries sign-offs from both Eric Ju (author) and Pablo Sabater (series maintainer).
