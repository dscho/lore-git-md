This is a test infrastructure patch, part of Matt Hunter’s now-merged 8-patch series that implements the global `fetch.followRemoteHEAD` configuration option. Patch 3/8 is a small, targeted cleanup in `t5510-fetch.sh` that adds a `test_when_finished` call to remove the `custom-head` remote after the “followRemoteHEAD create does not overwrite dangling symref” test. The motivation is to prevent a conflict with a later test in the same series that will create an identically named remote; without this cleanup, the second test would fail because the remote already exists. The change is purely preparatory and does not alter the behavior or coverage of the existing test.
