This is the first patch in a now-merged five-part documentation series that standardizes Git’s trailer conventions in commit messages. The patch encourages contributors to use trailers (like `Helped-by:`, `Co-authored-by:`) for *substantial* help while cautioning against over-crediting minor contributions. It also clarifies that trailers must follow the Git author format (name + email) to ensure they’re properly parsed by `git shortlog --group=trailer:<key>` and normalized via `.mailmap`.

The change moves trailer guidance from the `send-patches` section into a dedicated "Commit trailers" subsection, making it more visible and consolidating all trailer-related advice in one place. The motivation is practical: trailers are already widely used on the mailing list, and the project credits both authors and trailer-mentioned contributors in release notes. The patch strikes a balance between encouraging recognition and preventing noise—explicitly noting that "simple review work" doesn’t warrant a trailer.

This patch is uncontroversial and well-motivated, with clear ties to real-world contributor behavior. The technical detail about format requirements (name + email) is particularly useful for newcomers. As part of the larger series, it lays the groundwork for the prescriptive guidelines that follow, all of which have already been merged to `master`. No further changes are expected.
