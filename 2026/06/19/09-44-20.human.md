This is a small, targeted bugfix patch in Matt Hunter’s now-merged 8-patch series introducing the global `fetch.followRemoteHEAD` configuration. It is the first patch in the v3 iteration.

The patch corrects a single line in the advice message shown when Git detects that a remote’s HEAD points to something other than a branch (e.g., a tag or a dangling symref). The current message incorrectly says `warn-if-not-branch-%s`, but the actual configuration value—and the implementation in `remote.c`—is `warn-if-not-%s`. This mismatch would confuse users who copy-paste the suggested command. The fix is a one-character deletion that aligns the advice with the documented and implemented behavior.

The change is purely textual, touching only the advice string in `builtin/fetch.c`. No code paths or behaviors are altered. The patch is uncontroversial and clearly motivated; it is a straightforward follow-up to the larger series. Since the series is already merged into `next`, this patch is effectively a post-merge polish.
