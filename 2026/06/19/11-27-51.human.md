This is a refactoring patch (3/10 in Patrick Steinhardt's v4 series) that tidies up how Git handles the `GIT_REFERENCE_BACKEND` environment variable during repository discovery. The patch fixes two minor but messy issues: the variable was being applied unconditionally even when no repository was found, and the repository format had to be reapplied afterward because the variable was set too late in the process.

The change moves the environment variable logic into the block where a repository is actually discovered, so it only runs when needed. This lets the code drop an explicit call to `repo_set_ref_storage_format()` because the format is now adjusted before `apply_repository_format()` is called. The patch is a small, clean step in the larger effort to modernize Git's reference backend and avoid initialization-order problems. It looks well-motivated and uncontroversial—just the sort of mechanical cleanup that makes later architectural work easier.
