This is a documentation patch, part of Matt Hunter’s now-merged 8-patch series that implements the global `fetch.followRemoteHEAD` configuration option. This specific patch adds a missing entry for the `fetchRemoteHEADWarn` advice key to `Documentation/config/advice.adoc`.

The change is a straightforward four-line addition that explains when the advice message appears: when `git fetch` detects that the remote’s `HEAD` symref disagrees with the locally configured remote `HEAD` and the user has opted into warnings via `remote.<name>.followRemoteHEAD` set to `warn` or `warn-if-not-$branch`. The wording is clear and matches the established style of the advice documentation.

This patch is the second in the series and is purely additive; it does not alter any code or behavior. It simply ensures that users who consult `git config --help advice` or the HTML/man page documentation will find the new advice key documented alongside the others. The commit message is concise and accurately describes the purpose.
