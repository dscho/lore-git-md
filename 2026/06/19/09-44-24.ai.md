This is a small refactoring patch in Matt Hunter’s now-merged 8-patch series implementing the global `fetch.followRemoteHEAD` configuration option. Patch 5/8 fixes control flow in the `git_fetch_config` callback so that it returns early for the known `fetch.output` key instead of falling through to `git_default_config`. The change is purely mechanical: a single `return 0;` line is added after the `fetch.output` handling block, matching the pattern already used for other known keys in the same function. This avoids unnecessary config parsing and aligns with Git’s config-handling conventions. The patch is uncontroversial and part of the final cleanup that preceded Junio C Hamano’s merge of the series into `master`.
