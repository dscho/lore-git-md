This is a call for help from Junio C Hamano about the persistent unreliability of macOS CI jobs in GitHub Actions. Over recent weeks, the `osx-clang` and `osx-gcc` jobs have been timing out after six hours—far longer than the usual 30-minute runtime—without any clear pattern. Junio notes that the same commit can fail in one run and pass in another, even when the workflow is pared down to just the macOS jobs, suggesting the issue is not load-related but something inherent to the macOS runners or the Git test suite on that platform. The thread is a request for debugging assistance rather than a patch or proposal; if you maintain macOS CI or have seen similar flakiness, this is the place to weigh in.
