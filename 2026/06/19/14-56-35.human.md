This is a refactoring patch that generalizes the protocol-v2 packet-writing helper so it can be reused for commands beyond `` `git fetch` ``. The patch is part of the ongoing `` `git cat-file --batch-command` `` series (v13, patch 6/12) that adds remote object-info queries.

The change itself is small and mechanical: ``write_fetch_command_and_capabilities()`` is renamed to ``write_command_and_capabilities()`` and gains a ``const char *command`` parameter. The only callers are in ``fetch-pack.c``, which now pass the literal string ``"fetch"``. The commit message explains that this refactoring enables future protocol-v2 commands—most immediately the ``object-info`` capability that the series is building.

The patch is clean, well-motivated, and has already been reviewed by Jonathan Tan and Christian Couder. It looks ready to merge as part of the larger feature.
