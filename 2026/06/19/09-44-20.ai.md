This is a minor documentation fix in the fetch subsystem, part of Matt Hunter’s now-merged 8-patch series that introduced the global `fetch.followRemoteHEAD` configuration option. The patch corrects a single line in `builtin/fetch.c` where the advice message suggested an invalid configuration value (`warn-if-not-branch-%s`). The actual supported value is `warn-if-not-%s`, matching both the implementation in `remote.c` and the existing documentation. The change is purely textual and does not affect program behavior; it ensures the advice users see aligns with what Git actually accepts. This is the first patch in the v3 series and addresses a surface-level consistency issue identified during earlier review.
