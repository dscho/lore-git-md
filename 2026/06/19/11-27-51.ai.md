This is a refactoring patch (v4 3/10) in Patrick Steinhardt's series modernizing Git's reference backend infrastructure. It addresses a minor inefficiency in repository discovery by deferring the application of the `GIT_REFERENCE_BACKEND` environment variable until after a repository is confirmed to exist.

The patch moves the logic for parsing and applying the `GIT_REFERENCE_BACKEND` environment variable into the block where a repository is actually discovered, eliminating two issues: (1) the previous unconditional application of the variable even when no repository was found, and (2) the need to manually reapply the repository format after adjusting it. This change allows the repository format to be adjusted before it is applied via `apply_repository_format()`, simplifying the initialization sequence.

The diff shows a straightforward code reorganization in `setup.c`, moving the environment variable handling into the `startup_info->have_repository` block and removing the redundant `repo_set_ref_storage_format()` call. The change is mechanical and does not alter behavior, but it makes the initialization flow more logical. This patch is uncontroversial and part of the foundational cleanup that enables the more significant architectural changes in later patches (7–9/10). No test failures or edge cases are expected.
