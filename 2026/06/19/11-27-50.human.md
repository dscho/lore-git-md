This is a refactoring patch (2/10) in Patrick Steinhardt’s v4 series modernizing Git’s reference backend. It eliminates redundant application of repository format settings during initialization.

The patch addresses a minor inefficiency in `setup.c`: the repository format (hash algorithm and ref storage format) was being applied twice—once via `repository_format_configure()` and again via `apply_repository_format()`. The fix reorders the calls so the format is configured once and then applied, removing the need for the second update. The change is small (7 lines removed, 2 added) and purely mechanical, with no behavior change.

This is a preparatory cleanup that enables later architectural improvements in the series, particularly the targeted fix for recursive initialization in patches 7–9. The patch is uncontroversial and aligns with the series’ goal of simplifying ref backend code. Reviewers of v3 (including Justin Tobler) approved similar cleanup patches, so this should face no resistance.
