This is the cover letter for the final version (v4) of a 3-patch series that migrates the `trust_executable_bit` configuration from global scope into `struct repo_config_values`, part of the ongoing `the_repository` removal effort. The series is now ready for merging after incorporating all review feedback.

The work targets core index handling and configuration plumbing, touching `read-cache.c`, `environment.c/h`, `apply.c`, and related headers. The migration is mechanical and behavior-preserving, moving the flag into repository-scoped storage while maintaining eager parsing for performance in hot paths. A new getter function `repo_trust_executable_bit()` is introduced, and all call sites are updated to use repository-scoped access. The series temporarily preserves fallback to `the_repository` due to deep integration of these flags, but lays groundwork for future elimination of the global.

Key technical details include: removal of redundant extern declarations in patch 1, relocation of `ce_mode_from_stat()` implementation and documentation in patch 2, and the core migration of `trust_executable_bit` into `repo_config_values` in patch 3. The series also fixes documentation typos and improves header documentation placement. The more complex `has_symlinks` migration was formally deferred due to demonstrated complexity, showing pragmatic adaptation to implementation realities.
