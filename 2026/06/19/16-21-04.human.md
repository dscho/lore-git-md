This is the second patch in a now-ready three-patch series refactoring the `trust_executable_bit` configuration as part of the ongoing `the_repository` removal effort. The patch moves the `ce_mode_from_stat()` helper function from `read-cache.h` (where it was a static inline) into `read-cache.c`, preparing the ground for repository-scoped configuration access in later patches.

The change is purely mechanical and has no visible behavior impact. The function’s logic remains identical, but its relocation allows it to later access repository-specific settings without exposing global variables in the header. The commit message notes that the redundant `extern` declarations for `trust_executable_bit` and `has_symlinks` are dropped, as they are no longer needed in the header. A descriptive comment is added to clarify the function’s purpose.

This patch is a necessary preparatory step for patch 3/3, which migrates `trust_executable_bit` into `struct repo_config_values`. The series has been thoroughly reviewed, and this version incorporates all feedback on documentation placement and wording. The patch carries Reviewed-by tags and is ready for merging.
