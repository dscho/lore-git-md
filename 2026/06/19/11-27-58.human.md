This is the final patch in Patrick Steinhardt’s 10-part refactoring series modernizing Git’s reference backend. It is a small, targeted cleanup in `refs.c` that removes an unnecessary local buffer in `refs_compute_filesystem_location()`.

The function currently uses a temporary `strbuf` to construct a path before calling `strbuf_realpath()`, but `strbuf_realpath()` can safely operate in-place on its input buffer. The patch eliminates the extra allocation and simplifies the code by having `strbuf_realpath()` write directly into `ref_common_dir`. The change is purely internal—no behavior or API changes—and the commit message clearly explains the motivation.

This patch is uncontroversial and rounds out the series with a minor but sensible improvement. It does not interact with the core architectural changes (the `ignore_refdb` flag or config-parsing logic) introduced earlier in the series, so it should not require additional review beyond verifying the mechanical correctness of the buffer handling.
