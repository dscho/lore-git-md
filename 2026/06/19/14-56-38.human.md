This is the ninth patch in the GSoC RFC v13 series implementing secure remote object metadata queries. It adds the core client-side support for the object-info capability, allowing Git to request object sizes (and eventually other metadata) from protocol v2 servers without downloading the full objects.

The patch introduces `fetch-object-info.c`, a new file that implements the client-side protocol logic. The `fetch_object_info()` function handles the full request/response cycle: it validates server support, sends the object-info command with requested features (currently only "size"), and parses the server's response into a structured `object_info` array. The implementation follows Git's established patterns for protocol v2 commands, including stateless RPC handling and proper error checking.

Key integration points include:
- Transport layer hooks in `transport.c` and `transport-helper.c` that trigger object-info requests when the feature is enabled
- Protocol state machine updates in `fetch-pack.c` to handle the new `FETCH_SEND_REQUEST` state
- Build system additions (Makefile and meson.build) to compile the new source file

The patch maintains strict protocol v2 enforcement and includes comprehensive error handling for malformed responses. It currently supports only the "size" feature but is designed to be extensible for future metadata types. The implementation avoids unnecessary server requests when no supported features are available and properly cleans up allocated memory.
