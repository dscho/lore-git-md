This is patch 11 in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch removes the redundant `odb_source_loose_has_object()` function, which checked for loose object existence via lstat(3p), in favor of using the more general `odb_source_read_object_info()` interface.

The change eliminates duplicate code paths for object existence checking, since `read_object_info_from_path()` (called by `odb_source_read_object_info()` with certain flags) already performs the same lstat(3p) check. The patch updates three call sites in builtin/pack-objects.c and object-file.c to use the unified interface instead.

This continues the series' pattern of converting direct function calls to callback-based operations through the odb_source interface. The change is mechanical and doesn't modify behavior - it simply removes a redundant code path while maintaining the same functionality through the more general interface. The patch removes 20 lines while adding 12, with the diff showing straightforward conversions at each call site.

This is another incremental step in the larger ODB abstraction work, following the same careful approach seen in previous patches. The change appears uncontroversial and well-motivated as part of the series' goal to standardize object storage operations through the odb_source interface.
