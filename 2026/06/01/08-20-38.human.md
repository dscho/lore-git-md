This is patch 15/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch focuses on making the loose object writing code operate directly on `struct odb_source_loose` rather than the more generic `struct odb_source`.

The changes are mechanical but wide-ranging, updating function signatures and call sites across multiple files to use the loose-specific type. The core writing logic remains in object-file.c for now, as it's still shared with `force_object_loose()`, but this patch makes the dependency explicit in preparation for future moves.

Key changes include:
- Converting `write_loose_object()` and related helpers to take `struct odb_source_loose*`
- Updating callers in http-walker.c, http.c, and the files backend
- Maintaining identical behavior while changing the type signatures
- Keeping test coverage unchanged

This continues the series' pattern of focused, behavior-preserving changes to prepare for the eventual full migration of loose object handling to the odb/source-loose.c implementation. The patch appears well-structured and follows the established approach of the series.
