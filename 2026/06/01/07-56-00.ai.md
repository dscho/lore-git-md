This is the second patch in Patrick Steinhardt's series to deprecate the `git-init-db` command alias in favor of `git-init`. The patch focuses on the documentation and build system changes needed to mark `git-init-db` as deprecated while maintaining backward compatibility.

The changes include:
- Adding a deprecation notice to `BreakingChanges.adoc`
- Creating a new `git-init-db.adoc` man page that warns about the deprecation and redirects to `git-init`
- Updating build systems (Makefile and meson.build) to handle the deprecation
- Modifying test scripts to use `git-init` instead of `git-init-db`
- Conditionally compiling out the `init-db` command when `WITH_BREAKING_CHANGES` is enabled

The patch notes that `git-init-db` has been effectively replaced by `git-init` since 2007, with all documentation already pointing to the newer command. The changes are low-risk since they maintain backward compatibility while steering users toward the preferred form. This continues the project's ongoing effort to clean up historical command aliases.
