This is the sixth patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ongoing ODB (object database) abstraction effort. The patch wires up the `read_object_info()` callback for loose objects, moving the implementation from object-file.c to odb/source-loose.c.

The change converts direct function calls to use the generic `odb_source_read_object_info()` interface instead. The core functionality remains the same - this is purely an internal reorganization to better fit the ODB abstraction model. One helper function (`read_object_info_from_path()`) stays in object-file.c since it's still used by other code, but is adjusted to explicitly take a loose source parameter.

The patch follows the series' established pattern of methodically moving functionality while maintaining existing behavior. It touches several files but the changes are mechanical and focused. Test coverage should confirm no regressions, though no test updates are shown in this patch.

This continues the careful, incremental approach seen in previous patches, with each commit wiring up the loose source's callback interface piece by piece. The changes appear straightforward and well-contained, building toward the larger goal of making Git's object storage fully pluggable.
