This is patch 14/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `write_object()` callback for the loose source implementation.

The change moves the `odb_source_loose_write_object()` function from object-file.c to odb/source-loose.c and makes it the designated callback. This follows the pattern established in previous patches of converting direct function calls to callback-based operations through the odb_source interface. The implementation shows careful attention to maintaining existing behavior while restructuring the code.

Key technical aspects:
- Exposes `write_object_file_prepare()` and `write_loose_object()` from object-file.c since they're now shared between subsystems
- Preserves all existing functionality including compatibility hash handling
- Updates the files backend to use the callback rather than calling the function directly
- Maintains the same error handling and object freshening behavior

The patch continues the series' methodical approach - each commit wires up one specific callback while keeping changes focused and behavior-preserving. With no substantive technical feedback on previous versions, this appears to be progressing smoothly as part of the larger ODB abstraction effort.
