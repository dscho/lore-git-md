This is part 5 of an 8-patch series continuing the `the_repository` removal effort, focusing on migrating the `core.precomposeunicode` configuration from a global variable into `struct repo_config_values`. The change affects macOS-specific Unicode filename handling, which needs eager parsing to maintain consistent filesystem behavior across operations.

The patch moves the `precomposed_unicode` setting into the repository-specific config structure while preserving its eager parsing behavior, since lazy parsing could lead to inconsistent path normalization results. It also changes the variable type from `int` to `bool` to better reflect its boolean nature. The changes touch four files with straightforward mechanical updates to access the config through the repository structure.

This continues the established pattern from earlier parts of the series, maintaining performance in critical paths while eliminating cross-repository state leakage. The patch has already been reviewed positively by Christian Couder and Usman Akinyemi, and follows the same well-tested approach as the previous configuration migrations in this series. With no new technical concerns raised, it appears ready for merging as part of the ongoing effort to remove global configuration variables.
