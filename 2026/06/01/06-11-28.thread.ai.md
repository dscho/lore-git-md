[PATCH] Proposal: Mirror repositories as alternate submodule sources

Author: Benson Muite
Thread type: Feature proposal
Status: Initial proposal met with maintainer pushback on scope, now evolving toward general mirroring solution with real-world use case support from Debian packaging
Core problem: Fetch operations fail due to single-source timeouts/bandwidth limits, with Debian identifying specific pain points for archived projects with submodules when external URLs or relative paths change
Current direction: General repository-level mirror fallback functionality favored by Junio Hamano, now with Jeff King (Peff) proposing alternative using existing url.*.insteadOf mechanism
Technical details: Original submodule-specific config syntax proposal now unlikely; Peff demonstrates how insteadOf could handle repository identity and mirroring without new UUID infrastructure, including protocol switching and abstract-to-concrete URL mapping
Subsystems affected: submodule.c, remote.c, fetch-pack.c, config machinery (expanding scope from initial proposal)
Open questions: Whether url.*.insteadOf can fully replace UUID approach (particularly for per-repository configuration), exact precedence rules between mirror sources, error handling strategies, and how to maintain internal references when mirrored
Participant positions: Junio opposes submodule-specific implementation; Debian use case supports general approach; Peff now advocates for leveraging existing insteadOf rather than new UUID system
Key decision points: Need to evaluate whether insteadOf covers all use cases (especially per-repo config), or if hybrid approach combining it with minimal UUID-like identifiers would be better
Related work: Debian's UUID/symlink workaround remains interim solution; Peff's proposal connects to Git's long-standing URL rewriting capabilities
New technical direction: Thread now exploring whether url.*.insteadOf can provide sufficient mirroring functionality without protocol changes, while maintaining the general repository focus Junio prefers
