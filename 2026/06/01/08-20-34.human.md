This is patch 11 in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch removes the redundant `odb_source_loose_has_object()` function, which checked for loose object existence via lstat(3p), in favor of using the more general `odb_source_read_object_info()` interface that can perform the same check.

The change affects three call sites - two in `builtin/pack-objects.c` (for pack-objects and cruft pack generation) and one in `object-file.c` (for force-writing loose objects). The patch demonstrates the series' pattern of consolidating object storage operations into the odb_source callback interface. While this is a small change, it's part of the larger architectural shift toward making object storage pluggable.

The removal is safe because the two approaches were functionally equivalent when called without object info requests or the QUICK flag. This continues the series' careful, incremental approach to refactoring while maintaining existing behavior. No test changes were needed since the functionality remains identical, just implemented through a different interface.
