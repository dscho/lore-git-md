This is the second patch in an eight-part series continuing the `the_repository` removal effort, specifically migrating the `core.checkstat` configuration from a global variable to `struct repo_config_values`. The change ensures repository-specific behavior while maintaining the existing eager parsing that's important for performance in file status checking paths like `match_stat_data()`.

The patch makes mechanical changes across four files to move the `check_stat` variable into the repository-specific config structure and update all references. The commit message explains the rationale for keeping eager parsing (to avoid unexpected behavior in file freshness checks) while eliminating the global state. 

This follows the same pattern as the first patch in the series (which handled `core.trustctime`) and has already received positive reviews from Christian Couder, Usman Akinyemi, and Karthik Nayak. The changes are straightforward and maintain performance-sensitive behavior, with Tian Yuchen's earlier analysis confirming this approach won't introduce regressions.

The series as a whole is nearing completion, with only minor documentation polish remaining before Junio Hamano can merge it. This patch represents incremental progress in the larger `the_repository` removal project that René Scharfe and others have been driving.
