This is part 7 of an 8-patch series continuing the `the_repository` removal effort, focusing on migrating the `sparse.expectfilesoutsideofpatterns` configuration from a global variable into `struct repo_config_values`. The patch follows the established pattern of the series by maintaining eager parsing for performance-critical settings while eliminating cross-repository state leakage.

The change affects three files (environment.c, environment.h, sparse-index.c) with straightforward mechanical updates to reference the configuration through the repository-specific struct rather than the global variable. The commit message explains the rationale for keeping eager parsing - this setting controls fundamental sparse-checkout behavior that many commands rely on, and lazy parsing could lead to inconsistencies.

The patch has already been reviewed positively in previous iterations, with Christian Couder and Usman Akinyemi listed as mentors. It builds on prior work in the series that migrated other configuration settings (core.trustctime, compression levels, Unicode handling) using the same pattern. The changes are consistent with the broader `the_repository` removal effort led by René Scharfe.
