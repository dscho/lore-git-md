Documentation patch clarifying the `@` prefix for raw timestamps in Git's date parsing.

This patch documents a long-standing but previously undocumented behavior where prepending `@` to a Unix timestamp (e.g., `@123456789`) forces Git to interpret the value as a raw timestamp rather than potentially ambiguous formats like YYYYMMDD. The change is particularly important for timestamps under 100,000,000 (fewer than 9 digits) which would otherwise fail to parse.

The patch adds clear documentation in `date-formats.adoc` and includes test cases in `t/t0006-date.sh` that demonstrate the difference between prefixed and unprefixed timestamps. Notably, it shows how `@2000` correctly parses as a Unix timestamp while `2000` is rejected (or interpreted differently by approxidate).

The change is co-authored by Junio Hamano, suggesting maintainer approval of the clarification. The tests cover both the exact parsing behavior and the approxidate fallback path, making this a thorough documentation improvement. The patch is cleanly focused and touches only the relevant files.
