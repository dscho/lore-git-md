This is a refactoring patch from a GSoC participant that moves path formatting logic from `rev-parse.c` into a shared `strbuf_add_path()` helper function. The patch is part of a series to improve path handling in repository information commands.

The key technical change is replacing `rev-parse`'s local path formatting implementation with calls to the new centralized helper. The patch:
- Removes duplicate enum definitions for path formatting options
- Simplifies `print_path()` to a wrapper around `strbuf_add_path()`
- Updates all callers to use the shared enum types from `path.h`

The implementation looks clean and maintains all existing functionality while reducing code duplication. The author has clearly coordinated with mentors (Justin Tobler and Lucas Seiki Oshiro) and the changes align with the series' goal of consistent path handling.

This is a mechanical refactoring that paves the way for subsequent patches to extend path formatting in `git repo info`. The changes are low-risk since they don't modify behavior - they just relocate and unify existing logic. The patch appears ready for inclusion pending any final review feedback.
