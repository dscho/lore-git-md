This is patch 14/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `write_object()` callback for the loose source implementation.

The key change moves `odb_source_loose_write_object()` from object-file.c to odb/source-loose.c and makes it as the loose source's write callback. This continues the pattern of converting direct function calls to callback-based operations through the odb_source interface. The implementation remains functionally identical - it just changes where the code lives and how it's invoked.

The patch exposes two helper functions (`write_object_file_prepare()` and `write_loose_object()`) from object-file.c since they're now needed by both subsystems. The files backend is updated to use the callback rather than calling the function directly.

This is another incremental step in the larger ODB abstraction work, following the same careful approach as previous patches - small, focused changes that maintain existing behavior while moving toward the new architecture. The changes are mechanical and well-contained, touching only the expected files with no surprises in the diff.

With no substantive technical feedback on previous versions and this being a straightforward continuation of the established pattern, the patch appears ready for inclusion in the series. It brings the loose source implementation one step closer to being a fully independent odb_source backend.
