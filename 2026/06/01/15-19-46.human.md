This is a feature proposal for `git repo info` that would add path formatting options for gitdir and commondir paths. The 4-patch series comes from a Google Summer of Code (GSoC) participant and builds on previous discussions about how to expose repository path information.

The key changes would:
1. Add a new `strbuf_add_path()` helper for consistent path formatting
2. Use this helper in `git rev-parse`
3-4. Add both absolute` and `relative` variants for `path.gitdir` and `path.commondir` outputs in `git repo info`

The cover letter raises several open questions about the interface design, particularly around default behaviors and whether to include a `--path-format` flag. The author has consulted with previous contributors (Justin Tobler, Lucas Seiki Oshiro, and others) but is seeking broader community input before finalizing the approach.
