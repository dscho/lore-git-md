This is a bugfix patch in Elijah Newren's series hardening merge-ort against malformed trees. Junio C Hamano, the maintainer, has reviewed and approved the technical approach in this fourth patch.

The patch addresses a specific case where merge-ort could silently overwrite duplicate tree paths (which fsck would flag as invalid) rather than properly aborting. The key change converts setup_path_info() from void to int return to detect duplicates via strmap_put()'s return value, then fails the merge with a clear error message.

Junio notes the solution is more robust than alternatives that might depend on tree sorting, since it directly detects duplicates regardless of entry order. The patch builds on his earlier approval of the series' error handling foundation, with no new concerns raised. This continues the systematic hardening of merge-ort's tree traversal against corruption scenarios.
