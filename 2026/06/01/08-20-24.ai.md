The patch moves the `struct odb_source_loose` definition and its constructor from object-file.[ch] to new files odb/source-loose.[ch], following the pattern used by other ODB sources.

The patch updates build files to include the new source file and maintains all existing functionality while detaching the loose source implementation from the generic object file code.

This initial step is straightforward infrastructure work that cleanly separates concerns in preparation for the more substantive changes to come in the series. The patch appears well-formed with appropriate file moves and build system updates, keeping with Patrick's typical careful approach to large-scale refactoring.
