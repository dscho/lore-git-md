This is patch 4/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `reprepare()` callback for the loose object backend by moving the implementation from object-file.c to odb/source-loose.c and making it a proper vtable callback.

The changes are straightforward mechanical refactoring:
- Moves `odb_source_loose_reprepare()` to its new home in odb/source-loose.c
- Makes the cache-clearing helper function static since it's now only used locally
- Updates the files backend to call through the new vtable instead of directly
- Removes now-unneeded declarations from headers

This continues the pattern seen in earlier patches of converting direct function calls into callback-based operations through the odb_source interface. The patch maintains the series' careful approach of small, focused changes that don't modify behavior - it's purely moving code to its proper place in the new structure.

The changes touch core object handling code but are low-risk since they're just relocating existing functionality. With no substantive technical feedback on v1 and only minor doc fixes needed, this appears to be progressing smoothly as part of the larger ODB abstraction work.
