This is patch 17/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch stubs out the remaining callback functions that weren't yet implemented for the loose object backend.

The key additions are:
- Transaction support stubs (explicitly deferred until transaction interfaces stabilize)
- Alternates handling stubs (read_alternates and write_alternate callbacks)
- Error messages indicating unsupported operations

The patch follows the series' pattern of incremental, behavior-preserving changes while moving toward a fully pluggable storage architecture. Patrick notes that while transaction support could theoretically be implemented now, it's being deferred to avoid potential churn from ongoing transaction interface work.

This continues the methodical approach seen throughout the series - each patch wires up specific callbacks while maintaining existing functionality. The changes are mechanical and focused, with no behavior modifications. The series appears to be progressing smoothly toward its goal of converting loose object handling to use the odb_source interface.
