This is patch 3/18 in Patrick Steinhardt's v2 series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch begins converting `struct odb_source_loose` into a proper pluggable `struct odb_source` by embedding the base struct and implementing core lifecycle management.

The changes:
- Embed `struct odb_source` in `struct odb_source_loose` and assign it the new `ODB_SOURCE_LOOSE` type
- Move loose source lifecycle management (cache clearing, chdir notifications) from object-file.c to the new odb/source-loose.c
- Implement the `free` callback for proper odb_source integration
- Add downcast helper function for type-safe conversion
- Update the files backend to use the new odb_source-based free mechanism

The patch is purely structural - no behavior changes. It follows the established pattern seen in other ODB source conversions, with careful attention to maintaining existing functionality while moving toward the callback-based interface. The changes span multiple files but are well-contained, focusing only on the infrastructure needed to make the loose source act as a proper odb_source.

This continues Patrick's methodical approach to the ODB abstraction work, with each patch making small, focused changes that build toward the larger goal. The implementation looks clean and maintains all existing functionality while setting up the necessary hooks for future patches to implement the remaining callbacks.
