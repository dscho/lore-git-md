This is patch 10/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `count_objects()` callback for the loose source implementation.

The change moves `odb_source_loose_count_objects()` and its helper `count_loose_object()` from object-file.c to odb/source-loose.c, making it available through the odb_source interface. The implementation remains functionally identical - it still provides both exact counting (via object iteration) and approximate counting (by sampling one shard directory and scaling up).

Key technical details:
- The approximate counting method samples the "17" shard directory and multiplies by 256, maintaining the same estimation technique
- Callers in builtin/gc.c and odb/source-files.c are updated to use the callback interface
- The change removes 60 lines from object-file.c while adding 61 to odb/source-loose.c
- All existing functionality is preserved, including error handling for directory access failures

This continues the series' pattern of converting direct function calls to callback-based operations through the odb_source interface. The patch is well-contained and follows the established approach seen in previous patches of the series. With the count_objects callback now wired up, the loose source implementation is nearing completion of its core functionality.
