This is part 6 of an 8-patch series in the ongoing `the_repository` removal effort, focusing on migrating the `core.sparseCheckoutCone` configuration setting from a global variable into `struct repo_config_values`. The change prevents cross-repository state leakage while maintaining the existing eager parsing behavior, which is important since this setting affects early repository setup and sparse-checkout behavior.

The patch updates references across several files (`builtin/mv.c`, `builtin/sparse-checkout.c`, `dir.c`, etc.) to use the new repository-specific storage. The changes are mechanical but widespread, touching the sparse-checkout subsystem's core functionality. The commit message explains the performance rationale for keeping eager parsing, noting this setting determines fundamental sparse-checkout mode and is consulted early in repository setup.

This continues the established pattern seen in previous patches of the series, with similar scope and impact. The series has already gathered positive reviews and appears ready for merging, with Junio Hamano indicating readiness to queue pending final confirmations. The patch maintains compatibility with existing sparse-checkout behavior while advancing the broader goal of eliminating global configuration state.
