This is patch 8/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `for_each_object()` callback for the loose source by moving the implementation from object-file.c to odb/source-loose.c.

The change follows the established pattern of the series - converting direct function calls to callback-based operations through the odb_source interface. This patch moves 264 lines of code while removing 305 lines, primarily from object-file.c. Key functions like `odb_source_loose_for_each_object()` and its helpers are relocated, with some functions like `unpack_loose_rest()` and `for_each_file_in_obj_subdir()` made non-static to be shared between files.

The patch maintains all existing functionality while reorganizing the code to better fit the ODB abstraction model. It continues the incremental approach seen in previous patches, with each commit wiring up a specific callback. The changes are mechanical but important for the larger goal of making Git's object storage pluggable.

No substantive technical feedback has been given on this part of the series yet, though Junio provided minor doc fixes on earlier patches that were addressed in v2. The patch appears ready for review as part of the ongoing ODB abstraction work.
