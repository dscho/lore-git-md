This is patch 4/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch moves the `reprepare()` callback implementation for loose objects from object-file.c to odb/source-loose.c and wires it up properly in the loose source's vtable.

The changes are straightforward mechanical refactoring:
- Moves `odb_source_loose_reprepare()` to its new home
- Makes the previously public `odb_source_loose_clear_cache()` function static since it's now only used internally
- Updates the files backend to call through the new callback interface
- Maintains all existing functionality while better organizing the code

This continues the pattern seen in earlier patches of the series - moving functionality from the old object-file.c implementation to the new odb/source-loose.c while converting direct function calls to callback-based operations. The patch is small, focused, and appears to be a clean step in the larger refactoring effort with no behavior changes.

Given the uncontroversial nature of the previous patches in the series and the mechanical nature of this change, it seems likely to proceed smoothly through review. The careful separation of concerns and clear commit message make this easy to evaluate as part of the ongoing ODB abstraction work.
