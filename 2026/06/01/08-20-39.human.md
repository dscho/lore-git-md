This is part 16 of Patrick Steinhardt's 18-patch series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The series is now at version 2.

The current installment wires up the `write_object_stream()` callback for loose objects, though the actual implementation remains in object-file.c for now due to shared logic with `force_object_loose()`. The changes are mechanical - adding the callback infrastructure while maintaining existing behavior. The patch updates function signatures to use the proper `struct odb_source_loose` type and adjusts callers in http-walker.c and http.c accordingly.

This continues the series' pattern of incremental, behavior-preserving changes to convert loose object handling to the new ODB abstraction layer. The work is clearly part of a well-planned larger effort, with Patrick noting that some refactoring (moving the implementation fully into odb/source-loose.c) is deferred to future work. The changes are straightforward and unlikely to be controversial, following the same careful approach seen in previous patches.

The series as a whole is progressing smoothly with only minor documentation feedback from Junio C Hamano on v1, which Patrick has addressed. This patch maintains the high quality seen throughout - focused, well-explained, and with clear separation between mechanical infrastructure changes and future behavioral modifications.
