This is part 3 of Patrick Steinhardt's 18-patch series refactoring Git's loose object handling as part of the ongoing ODB (object database) abstraction effort. The patch converts `struct odb_source_loose` into a proper pluggable `struct odb_source` by embedding the base struct and assigning it a new `ODB_SOURCE_LOOSE` type.

The key changes in this patch:
- Moves loose source lifecycle management (freeing and cache clearing) from object-file.c to the new odb/source-loose.c
- Implements the `free` callback for the loose source
- Handles chdir notifications for path updates
- Adds downcast helper function for type safety
- Updates the source type enum to include `ODB_SOURCE_LOOSE`

This is infrastructure work - no behavior changes, just moving code to its proper place in preparation for implementing the full callback interface in later patches. The changes are mechanical but important for the larger goal of making loose object handling properly pluggable. 

The patch follows the established pattern seen in Patrick's previous ODB abstraction work, with careful attention to type safety and proper resource management. Test coverage is maintained through existing tests, though the patch itself doesn't add new ones since it's purely refactoring.
