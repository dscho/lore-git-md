This is the first patch in Patrick Steinhardt's series to deprecate the `git-init-db` command alias in favor of `git-init`. The patch performs a mechanical rename of the implementation file from `builtin/init-db.c` to `builtin/init.c` to match the preferred command name.

The changes include:
- Renaming the source file and updating all references in build systems (Makefile, meson.build)
- Updating the function name from `cmd_init_db` to `cmd_init`
- Maintaining backward compatibility by keeping both command names (`init` and `init-db`) mapped to the same implementation

The patch is straightforward and low-risk, touching only build system files and the renamed source file. It's part of a broader effort to clean up historical command aliases in favor of more consistent naming. The actual functionality remains unchanged - this is purely a code organization and naming improvement.
