This is the first patch in Patrick Steinhardt's 18-part series refactoring Git's loose object handling as part of the ongoing ODB (object database) abstraction effort. The patch moves the `struct odb_source_loose` definition and its constructor function from object-file.[ch] to new odb/source-loose.[ch] files, following the same pattern used by other ODB sources.

The change is purely organizational - no behavior is modified. This initial step detaches the loose object source implementation from the generic object file code, setting up for subsequent patches that will turn it into a proper `struct odb_source`. The patch includes the typical build system updates to add the new source files.

As the first in a well-structured series, this patch does the minimal groundwork needed for the larger refactoring. The commit message clearly explains the motivation and assures readers this is a no-op change. Given this is v2 of the series with only minor doc fixes from v1, and that Patrick is the primary driver of the ODB abstraction work, this appears to be a solid foundation for the rest of the series.
