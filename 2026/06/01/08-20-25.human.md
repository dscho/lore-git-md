This is patch 2/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch makes the relationship between the "loose" and "files" object sources more explicit by changing the loose source's parent from a generic `struct odb_source` pointer to a specific `struct odb_source_files` pointer.

The change is a preparatory step toward eventually removing the parent pointer entirely, as noted in the commit message. While this is a mechanical change, it helps clarify the code by making the relationship between these components more obvious during the transition period. The patch updates several call sites to use the new pointer type, including the loose object path lookup and cache access functions.

This continues the careful, incremental approach seen in the rest of the series - each change is self-contained and moves toward the larger goal of making the loose object source standalone. The patch touches core object handling code but doesn't modify behavior, maintaining the series' focus on internal reorganization rather than functional changes.
