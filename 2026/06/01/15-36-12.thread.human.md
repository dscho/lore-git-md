The series now has extensive test coverage across four test scripts.

This infrastructure change enables the upcoming commit-dropping functionality while maintaining safety through explicit flag validation. The implementation follows the series' pattern of cleanly extending reset machinery.

Key reviewers Phillip Wood and Junio C Hamano provided input that shaped v3's technical direction, particularly around conflict detection and flag naming. While the core functionality appears solid, some design questions around API structure and root/merge commit handling remain for follow-up work.
