This is patch 2/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch makes the relationship between the "loose" and "files" object sources more explicit by changing the loose source's parent pointer from a generic `struct odb_source` to specifically point to a `struct odb_source_files`.

The change is a transitional step toward completely removing the parent pointer in later patches, as the loose source will eventually operate independently. The patch updates all callers to use the new explicit pointer type, including the loose object path lookup and cache access functions. While this is purely an internal refactoring with no behavior change, it helps clarify the code's intent during the transition period.

The changes touch core object handling code in object-file.c and the new odb/source-* files, maintaining the series' careful approach of small, focused steps toward the larger ODB abstraction goal. The patch follows the pattern of previous work in this area and appears well-contained, with no substantive technical feedback yet from reviewers on this specific change.
