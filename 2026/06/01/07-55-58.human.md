This is a documentation and refactoring patch series from Patrick Steinhardt that deprecates the `git-init-db` command alias in favor of the more commonly used `git-init`. The series consists of two straightforward patches:

1. Renames the implementation file from `builtin/init-db.c` to `builtin/init.c` to match the preferred command name.
2. Marks `git-init-db` as deprecated in the documentation while keeping it as an alias for backwards compatibility.

The changes are mechanical - updating file references, build system rules, and test scripts to use the new name while maintaining the old name as a deprecated alias. The commit messages note this is part of cleaning up historical aliases, with `git-init` being the clearly preferred form (it's mentioned 3x more often in the documentation).

This appears to be a low-risk cleanup with clear motivation. The patches follow Git's standard deprecation approach of keeping backwards compatibility while steering users toward the canonical form. The changes are limited to implementation details and documentation - no behavior changes are introduced.
