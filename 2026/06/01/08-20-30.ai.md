This is patch 7/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `read_object_stream()` callback for loose objects, moving the implementation from object-file.c to odb/source-loose.c.

The key changes are:
1. Moves the streaming read implementation (`odb_source_loose_read_object_stream`) and its helper functions from object-file.c to odb/source-loose.c
2. Makes two previously static functions (`unpack_loose_header` and `parse_loose_header`) non-static so they can be shared between subsystems
3. Updates the files backend to use the new callback-based interface
4. Maintains all existing functionality while reorganizing the code to fit the ODB source abstraction pattern

The patch follows the series' established pattern of converting direct function calls to callback-based operations through the odb_source interface. It's a significant code movement (200 lines removed from object-file.c, 189 added to odb/source-loose.c) but doesn't introduce behavioral changes - this is purely an internal reorganization to support the pluggable storage architecture.

The changes touch core object handling code but maintain test coverage, and the series has so far received only minor doc fixes from Junio in previous iterations. This appears to be another solid step in the incremental refactoring approach Patrick has taken with the ODB abstraction work.
