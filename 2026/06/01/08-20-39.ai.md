This is part 16 of Patrick Steinhardt's 18-patch series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The series converts the loose object source into a proper `struct odb_source` to integrate it with Git's generic object storage layer interfaces.

This patch wires up the `write_object_stream()` callback for loose objects, though the actual implementation remains in object-file.c for now due to shared logic with `force_object_loose()`. The changes are mechanical - adding the callback infrastructure while maintaining identical behavior. The patch updates function signatures to use `struct odb_source_loose` explicitly and adjusts callers in http-walker.c and http.c to properly downcast the source.

The implementation follows the series' pattern of behavior-preserving preparatory changes, with test coverage remaining unchanged. A TODO comment notes the eventual goal of moving the streaming write implementation fully into odb/source-loose.c, but this is deferred until `force_object_loose()` can be made generic in a future patch.

This continues the methodical approach seen throughout the series, with each commit wiring up a specific callback. The changes touch core object handling code but don't modify behavior, maintaining the incremental refactoring strategy used in previous backend conversions. With no substantive technical feedback on earlier versions, this appears to be progressing smoothly as part of the long-term pluggable storage effort.
