This is the second patch in an eight-part series continuing the `the_repository` removal effort, focusing on migrating repository-specific configuration globals. This patch moves the `core.checkstat` configuration from a global variable into `struct repo_config_values`, maintaining its eager parsing behavior since it affects performance-sensitive file status checking in `match_stat_data()` (used by `git status`).

The changes are mechanical but important for eliminating cross-repository state leakage in multi-repo processes. The patch updates four files to use the new location, with straightforward variable access changes. The commit message clearly explains why eager parsing is preserved (to avoid performance regressions in file freshness checks) and how this fits into the broader refactoring effort.

The patch has already been reviewed positively by Christian Couder and Usman Akinyemi (both listed as mentors), and follows the same pattern established in earlier patches of this series. With no outstanding technical concerns and only minor documentation updates addressed in v4, this appears ready for merging as part of the ongoing `the_repository` removal project.
