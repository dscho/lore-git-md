This is the first patch in a two-part series from Patrick Steinhardt that refactors and deprecates the `git-init-db` command alias in favor of `git-init`. The patch performs a mechanical rename of the implementation file from `builtin/init-db.c` to `builtin/init.c` to match the modern command name.

The changes are straightforward and touch several build system components:
- Updates the Makefile and meson.build to reference the new filename
- Renames the command function from `cmd_init_db` to `cmd_init`
- Maintains backward compatibility by keeping both command names (`init` and `init-db`) mapped to the same implementation

The patch appears well-scoped and low-risk, focusing purely on the file rename while preserving all existing functionality. This is part of a broader effort to clean up historical command aliases in favor of more consistent naming. The second patch in the series will handle the documentation side of the deprecation.
