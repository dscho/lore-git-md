This GSoC patch series is now complete and ready for merging. It standardizes path formatting across Git by introducing a new `append_formatted_path()` helper in `path.c`, which replaces duplicated logic in `rev-parse` and powers four new fields in `git repo info`: `path.commondir.absolute`, `path.commondir.relative`, `path.gitdir.absolute`, and `path.gitdir.relative`.

The new fields provide scriptable access to the repository’s Git directory and common directory in both absolute and relative formats, filling a gap for tools that need stable, machine-readable paths without parsing `git rev-parse` output.
