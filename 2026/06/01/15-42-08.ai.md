This is part 5 of an 8-patch series continuing the `the_repository` removal effort, focusing on migrating the `core.precomposeunicode` configuration from a global variable into `struct repo_config_values`. The patch handles Unicode filename normalization behavior on macOS, which needs to remain eagerly parsed to avoid filesystem inconsistencies.

The change moves the `precomposed_unicode` setting into the config structure while maintaining its eager parsing behavior, since this affects fundamental filesystem operations. The patch updates four files with mechanical changes to reference the new location, including the macOS-specific precompose_utf8.c compatibility layer. The type change from `int` to `bool` better matches the configuration's actual usage.

This follows the same pattern as previous patches in the series, with positive reviews already received for parts 1-4. The changes are straightforward and maintain existing behavior while progressing the larger goal of eliminating configuration globals. The patch appears ready for merging as part of the ongoing series.
