A new proposal from Benson Muite suggests adding mirror repository support for submodules, allowing Git to fall back to alternate sources when the primary submodule repository is slow or unavailable. The idea aims to address practical reliability and bandwidth concerns when fetching submodules, particularly for projects using multiple hosting services. While the email presents the concept at a high level without implementation details, it would likely require changes to submodule URL handling and remote configuration if pursued. The proposal appears to be an initial exploration of interest rather than a concrete implementation plan at this stage.
