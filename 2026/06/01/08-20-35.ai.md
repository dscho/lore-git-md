This is patch 12/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch wires up the `freshen_object` callback for the loose object backend, moving the implementation from object-file.c to odb/source-loose.c and inlining a helper function that no longer has other callers.

The change follows the established pattern of the series - converting direct function calls into callback-based operations through the odb_source interface. The patch removes 19 lines while adding 10, with the net effect being a cleaner separation between the loose object backend and the rest of the codebase. The functionality remains identical, just reorganized to fit the new abstraction layer.

Key technical details:
- Moves `odb_source_loose_freshen_object()` implementation
- Inlines `check_and_freshen_source()` helper
- Updates callers to use the callback interface
- Maintains existing behavior for freshening loose objects
- Part of incremental conversion to pluggable storage backends

This continues the methodical, focused approach seen in previous patches of the series. With no substantive technical feedback on earlier versions, this infrastructure change appears uncontroversial and well-aligned with the ODB abstraction goals. The patch touches core object handling code but doesn't modify behavior, keeping risk low while progressing the larger architectural effort.
