This is patch 17/18 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the ODB (object database) abstraction effort. The patch stubs out the remaining unimplemented callbacks for the loose object backend - transaction support and alternates handling.

The key additions are:
- `begin_transaction()` callback that currently errors out, with a TODO noting this will be addressed later when transactional interfaces stabilize
- `read_alternates()` callback that does nothing (returns success)
- `write_alternate()` callback that errors out since alternates aren't supported

Patrick explicitly defers implementing transactions, noting there are separate efforts to polish the transactional interfaces that should settle first. The alternates callbacks are similarly minimal, with write operations disabled since the loose backend doesn't support alternates.

This continues the series' pattern of methodical, behavior-preserving changes to convert the object storage layer to use callback-based operations. The patch is straightforward infrastructure work that wires up the remaining required interfaces while leaving actual implementations for future work. With no behavior changes and the series progressing smoothly through review process, this appears ready for inclusion as part of the larger ODB abstraction effort.
