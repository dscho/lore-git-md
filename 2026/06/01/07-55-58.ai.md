This is a refactoring and documentation patch series from Patrick Steinhardt that deprecates the `git-init-db` command alias in favor of the more modern `git-init`. The series consists of two patches:

1. Renames the implementation file from `builtin/init-db.c` to `builtin/init.c` to match the preferred command name. This is a straightforward mechanical change that updates all references to the file.

2. Officially deprecates the `git-init-db` alias by adding documentation in `BreakingChanges.adoc` and creating a new `git-init-db.adoc` man page that redirects users to `git-init`. The patch updates various test scripts and build files to handle the deprecation.

The motivation isn't explicitly stated, but appears to be cleaning up historical aliases in favor of more consistent command names. The change is low-risk since it maintains backward compatibility while steering users toward the preferred form. The patches touch several build systems (Makefile, meson) and documentation files, but the core functionality remains unchanged.
