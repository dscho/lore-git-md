This is a **CI/platform-compatibility** discussion advancing the macOS CI hang investigation.

Patrick Steinhardt responds to Jeff King’s concern about masking the underlying HTTP/2 deadlock. He shares a new observation: GitLab CI (which does not hang) uses curl 8.7.1, while GitHub’s macOS runners use 8.6.0. This version difference is a plausible lead, but Patrick cautions that the hang could equally stem from Git’s curl usage, a curl bug, or an Apache bug. He suggests updating the GitHub runner image to macOS 15 as a low-risk experiment, but the core question—whether the hang is Git’s fault, curl’s, or Apache’s—remains open. No code changes are proposed yet; the email is diagnostic rather than prescriptive.
