This is the second and final patch in Patrick Steinhardt's v2 RFC series to reorganize Git's source tree by moving all `libgit.a` components into a new `lib/` directory. The patch is purely mechanical: it relocates roughly 700 files from the root directory into `lib/` while preserving their internal structure, and updates all build system references (Makefile, CMake, Meson) to match.

The motivation remains unchanged from the cover letter: reducing root directory clutter (from ~550 to ~80 files) to improve discoverability and make the `libgit.a` boundary explicit. This patch completes the move by handling the remaining files not covered in the preparatory first patch, including core subsystems like object handling, refs, diff, merge, and platform compatibility shims. The changes are limited to path updates in build files and documentation; no code logic is modified beyond location adjustments.

Testing across GitLab and GitHub CI pipelines has passed, and Johannes Schindelin (Git for Windows maintainer) has signaled preliminary approval. The series is now technically complete, with no outstanding objections, and appears ready for finalization pending coordination on transition timing (likely post-v2.54.0). Downstream forks like GitHub and Microsoft Git have been engaged to address potential merge conflicts.

This is a significant structural change with broad implications for contributors and tooling, but the incremental approach (focusing first on `lib/`) has minimized disruption. Future iterations may introduce a `cmd/` directory for built-in commands, but that is explicitly out of scope for this series.
