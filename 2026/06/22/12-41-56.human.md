This is the second patch in the v4 series introducing the `--linearize` option to `git replay`. It is a pure refactoring patch with no behavior change, extracting a helper function `put_mapped_commit()` from the lengthy `replay_revisions()` function in `replay.c`. The patch also renames the existing `mapped_commit()` function to `get_mapped_commit()` to pair semantically with the new helper.

The change is mechanical and straightforward: the logic for inserting a commit into the `replayed_commits` hash map is moved into a dedicated static function, and all call sites are updated to use the new helper. The patch reduces code duplication and improves readability by giving a clear name to the operation. The commit message is concise and accurately describes the change.

This patch was not the focus of prior review feedback, which centered on the core `--linearize` implementation and its documentation. The refactoring here is uncontroversial and appears well-executed, serving as a preparatory step for the feature addition in patch 3.
