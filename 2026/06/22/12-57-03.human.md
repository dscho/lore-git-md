This is a brief follow-up in the ongoing macOS linker warning suppression thread. Junio C Hamano acknowledges Patrick Steinhardt’s observation that the duplicate-library warning also appears in Meson builds and notes that the linker flag approach (`-Wl,-no_warn_duplicate_libraries`) used in the Makefile patch was inspired by a similar fix in Meson itself. He references a Meson GitHub issue and commit where Paolo Bonzini (a Meson maintainer) implemented the same suppression technique for the same warning.

The email does not propose any changes or raise new concerns; it simply connects the dots between the Makefile patch and existing Meson work. The thread’s main patch (v3) remains ready for merging, and the question of whether to extend suppression to Meson builds is still open but not blocking. If you’re tracking the build system cleanup, this is a minor footnote confirming the approach’s cross-build-system relevance.
