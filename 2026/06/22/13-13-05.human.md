This is a brief follow-up in the macOS linker warning thread. Paolo Bonzini, the Meson maintainer whose earlier commit (`7c901d7a8af2`) inspired Git’s current approach, chimes in to endorse the linker flag suppression (`-Wl,-no_warn_duplicate_libraries`) as the right solution. He confirms that Meson disables the warning unconditionally in its own build system, calling it "mostly a nuisance," and suggests Git need not bother with version checks if it adopts the same flag for Meson builds. His message reinforces the architectural soundness of the approach and subtly nudges the project toward consistency across build systems, though it doesn’t demand any immediate action. The existing Makefile-only patch remains ready for merging.
