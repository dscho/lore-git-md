This is the v2 cover letter for Patrick Steinhardt's RFC patch series to reorganize Git's source tree by moving all `libgit.a` components into a new `lib/` directory. The series is now at version 2, incorporating feedback from the initial RFC and addressing build system updates across Makefile, CMake, and Meson configurations.

The patch mechanically relocates approximately 700 files—including core subsystems like object handling, refs, diff, merge, and utilities—from Git's root directory into the new `lib/` directory while preserving their internal structure. The changes are primarily path updates in build files, with minimal code modifications beyond location adjustments. Key updates in v2 include fixes for previously missed Meson instances and refinements to the build system logic, such as handling of ODB sources (`source-inmemory.c`, `source-loose.c`, `source-packed.c`) and fsmonitor backend paths.

The series has been tested with GitLab and GitHub's CI pipelines, and Patrick notes preliminary approval from Johannes Schindelin (Git for Windows maintainer) for the transition. The motivation remains focused on improving root directory usability (reducing ~70 files that interfere with shell tab completion) and establishing a clearer boundary for `libgit.a`. While the series does not yet move command implementations into a separate directory (e.g., `cmd/`), Patrick has prototyped this and indicates it could follow in a future iteration.

Discussion in the thread has converged on the incremental approach, with Derrick Stolee acknowledging the reduced risk of focusing on the `lib/` move first. No outstanding technical objections remain, and the series appears poised for finalization pending coordination on transition timing (likely post-v2.54.0). The patch touches nearly every build configuration, including CI workflows, documentation references, and platform-specific shims, making it a significant structural change with broad downstream implications. Key files introduced or modified include `lib/` directory paths, `Makefile`, `meson.build`, `CMakeLists.txt`, and GitHub Actions workflows.
