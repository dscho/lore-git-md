This is a **CI/platform-compatibility** follow-up in the macOS CI hang thread. Patrick Steinhardt responds to Jeff King’s substantive review by investigating the environment differences between GitHub and GitLab CI runners.

Patrick notes that GitLab CI does not exhibit the same hangs, and he identifies a version mismatch in libcurl: GitHub runners use 8.6.0, while GitLab uses 8.7.1. He acknowledges that upgrading curl alone may not resolve the underlying HTTP/2 flow-control stall, but suggests it as a starting point, along with updating the macOS build image to version 15. The core question remains whether the hang stems from a bug in Git’s curl usage, curl itself, or Apache’s h2_mod. No code changes are proposed here; this is purely an environmental diagnosis. The thread is still focused on root-cause analysis rather than a final fix.
