This is the second patch in Harald Nordgren’s seven-patch v17 series implementing `git branch --delete-merged`. It refactors the internal `delete_branches()` function to use a flags-based API instead of separate boolean arguments (`force` and `quiet`). The change is purely mechanical: the two booleans are replaced with an `unsigned int flags` parameter and an enum (`DELETE_BRANCH_FORCE`, `DELETE_BRANCH_QUIET`), and the function body is updated to extract the flags into local booleans with the same names. No behavior changes are introduced.

The patch touches only `builtin/branch.c`, converting the function signature and updating all call sites to pass the new flags. The enum and flag names follow the established Git convention (uppercase, `DELETE_BRANCH_` prefix). This refactoring is a prerequisite for later patches in the series, which will add new flags (`DELETE_BRANCH_SKIP_UNMERGED`, `DELETE_BRANCH_NO_HEAD_FALLBACK`, `DELETE_BRANCH_DRY_RUN`) to support `--delete-merged` and its safety checks.

The implementation is straightforward and aligns with the project’s API consistency goals. The commit message clearly states that there are no behavior changes, and the diff confirms this. This patch is uncontroversial and ready for integration; it serves as a clean foundation for the more complex logic introduced in subsequent patches.
