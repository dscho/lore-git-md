This is the first patch in Harald Nordgren’s seven-part v17 series introducing `git branch --delete-merged`. It adds the `--forked` filter to `git branch --list`, which lets users list only branches whose configured upstream matches a given ref, remote name, or shell glob. The filter is repeatable and composes with existing filters like `--merged` and `--no-merged`.

The implementation is clean: it extends the `ref_filter` struct with a new `forked` string vector, adds a callback to parse and resolve `--forked` arguments, and teaches the ref-filter machinery to match branch upstreams against the registered patterns. Exact refs are matched literally; globs are matched against the abbreviated upstream name. The patch includes thorough tests covering exact refs, globs, remote shorthand, repeated arguments, and composition with other filters.

This is a well-crafted building block for the `--delete-merged` feature that follows. The commit message is clear, the code is idiomatic, and the test coverage is comprehensive. No red flags—this looks ready for review.
