This is a refactoring and feature patch series from Patrick Steinhardt targeting the connectivity checks in Git, specifically to make them work correctly in repositories that don’t use packfiles. The series consists of three patches that collectively extract and generalize the logic for searching promisor objects, removing direct dependencies on the internal object database (ODB) structure.

The motivation is clear: currently, the connectivity checks in `connected.c` assume a packfile-based object storage, which breaks in repositories using alternative backends (like the ongoing ODB abstraction work). The series aims to make the promisor object search generic, so it works regardless of the underlying storage mechanism. This is part of the broader effort to decouple Git’s core logic from packfile-specific assumptions, a recurring theme in Patrick’s recent work on the ODB abstraction.

The patches touch two files: `connected.c` (the main logic for connectivity checks) and `odb/source-packed.c` (the packed-object backend). The changes are focused and mechanical, extracting helper functions and adding support for flags during object iteration. The commit messages are detailed and explain the "why" behind each change, which is helpful for reviewers.

This series looks well-motivated and timely, given the ongoing ODB abstraction work. It’s a small but important step toward making Git’s internals more modular. If you’re following the ODB or promisor-remote efforts, this is worth paying attention to. The patches themselves appear clean and incremental, with no obvious red flags in the diffstat.
