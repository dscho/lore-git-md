This is a CI/build system follow-up confirming the final patch in Harald Nordgren’s series to suppress macOS linker warnings about duplicate libraries. D. Ben Knoble reports test results from two machines: an older one with Xcode 14.2 (ld64-711) and a newer one with Xcode 26.1 (ld-1230.1).

On the older machine the patch correctly omits the suppression flag, and neither Makefile nor Meson builds emit warnings. On the newer machine the patch suppresses the duplicate-library warning for Makefile builds, while Meson builds still show it (as expected, since the patch only touches `config.mak.uname`). The linker version regex in the patch works as intended, and no regressions are observed. This confirmation removes the last open question—broader testing across Xcode versions—and the patch is now ready to merge.
