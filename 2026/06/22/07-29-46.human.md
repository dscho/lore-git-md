This is the core implementation patch in Harald Nordgren’s seven-part series adding `git branch --delete-merged`. Patch 5/7 introduces the actual deletion logic, building on the `--forked` filter (patch 1/7) and the flags-based API refactoring (patches 2–4/7).

The command deletes local branches whose work has already landed on their configured upstream, while preserving branches that are checked out, missing their upstream, pushing back to their upstream (like `main` tracking `origin/main`), or used as an upstream for another branch. The stacked-branch protection—implemented here—aborts deletion if the branch is an upstream for any other branch, ensuring chains like `b1→b2→b3` are fully protected. The check repeats until the set of deletable branches stabilizes, using `refs_for_each_branch_ref()` and a `strset` to track upstreams.
