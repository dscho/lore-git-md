This is the second and final patch in Patrick Steinhardt's RFC v2 series to reorganize Git's source tree by moving all `libgit.a` components into a new `lib/` directory. The patch is purely mechanical, relocating approximately 700 files—including core subsystems like object handling, refs, diff, merge, and platform compatibility shims—from the root directory into `lib/` while preserving their internal structure. The changes are dominated by path updates in build system files (`Makefile`, `meson.build`, `CMakeLists.txt`, and `config.mak.uname`), with minimal code modifications beyond location adjustments.

The patch updates include paths for all build configurations, CI workflows (GitHub Actions), and platform-specific logic, ensuring the build remains functional after the reorganization. Key adjustments include updating `SPATCH_INCLUDE_FLAGS` to point to the new `lib/` paths, relocating third-party sources (e.g., `sha1collisiondetection`, `sha1dc`), and fixing references in `config.mak.uname` for platform-specific objects (e.g., `compat/win32/path-utils.o` → `lib/compat/win32/path-utils.o`). The `CMakeLists.txt` file is similarly updated to reflect the new directory structure, including adjustments to `VCPKG_DIR` and include paths.

The motivation for the series remains unchanged: reducing root directory clutter (from ~550 to ~80 files) to improve discoverability and establish a clearer boundary for `libgit.a`. The patch has been tested across GitLab and GitHub CI pipelines, and Patrick notes preliminary approval from Johannes Schindelin (Git for Windows maintainer) for the transition. No functional changes or new symbols are introduced; this is strictly a structural reorganization.
