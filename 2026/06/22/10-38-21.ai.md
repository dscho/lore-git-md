This is a preparatory patch for the ongoing source tree reorganization effort, specifically the introduction of a `lib/` directory to house `libgit.a` components. It is the first patch in Patrick Steinhardt’s v2 RFC series (1/2).

The patch makes a minimal but necessary change to `t/helper/test-example-tap.c`, adjusting an include path from `"t/unit-tests/test-lib.h"` to `"../unit-tests/test-lib.h"`. This ensures the file will continue to compile correctly once the surrounding code is moved into the new `lib/` directory in the next patch. The change is purely mechanical and does not alter any functionality or behavior.

This is a clear example of the kind of low-risk, preparatory work that enables the larger structural change. The patch itself is trivial, but it is essential for the series to build cleanly. No substantive discussion or controversy is expected here; the value lies in its role as a stepping stone for the broader reorganization.
