This is a CI/build system follow-up to the macOS linker warning suppression series. Patrick Steinhardt reports that the same duplicate-library warning also appears in Meson builds, though it was partially addressed in Meson itself (starting with commit 17d1cc60) to avoid breaking builds when `--fatal-warnings` is used. The warning remains visible but harmless.

Patrick suggests it might be worth disabling the warning unconditionally in Git’s Meson configuration, as it provides no real value. He has cc’d Paolo Bonzini, a Meson maintainer, to weigh in. This does not affect the already-approved Makefile patch (which remains ready for merging) but opens a parallel discussion about whether Git should suppress the warning in Meson builds as well. The thread is now waiting on input from Meson maintainers or other Git contributors who use Meson.
