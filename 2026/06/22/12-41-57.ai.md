This is the final patch in Toon Claes's **`git replay --linearize` feature series** (v4 3/3). It implements the core functionality: a `--linearize` option that flattens merge commits into linear history by walking only first parents, mirroring `git rebase --no-rebase-merges`.

The patch touches five files:
- **`Documentation/git-replay.adoc`**: Adds `--linearize` to the SYNOPSIS and documents its behavior (dropping merge commits, incompatibility with `--revert`).
- **`builtin/replay.c`**: Updates the command-line parser to accept `--linearize`, enforces mutual exclusion with `--revert`, and tweaks the usage string.
- **`replay.c`**: The heart of the change. It modifies `replay_revisions()` to skip merge commits when `--linearize` is active, reparenting their children onto the previous non-merge commit. The `pick_regular_commit()` helper gains a `replayed_base` parameter to support linearization, and a BUG() check prevents combining `--linearize` with reverse replay.
- **`replay.h`**: Adds a `linearize` field to `struct replay_revisions_options`.
- **`t/t3650-replay-basics.sh`**: Expands test coverage with four new cases:
  1. Rebasing a merge commit with `--linearize`
  2. Linearizing down to a root commit (verifying divergence from merge handling)
  3. Cherry-picking with `--linearize` and `--advance`
  4. Validating patch preservation via `git range-diff` (updated in v4 to use `test_grep` for linting compliance).

The implementation is **technically complete** and addresses all prior feedback:
- **Root commit handling**: Explicitly tested and documented as diverging from merge commit behavior.
- **Incompatibility**: `--linearize` and `--revert` are mutually exclusive (enforced at runtime).
- **Code clarity**: Leverages the getter/setter refactoring from patch 2/3 and the boolean `reverse` flag from patch 1/3.
- **Test coverage**: Includes edge cases (root commits, combinations) and verifies patch equivalence via `range-diff`.
- **Linting compliance**: Uses `test_grep` instead of bare `grep` to satisfy `mm/test-grep-lint`.
