This thread is Junio C Hamano’s latest “What’s cooking” report for Git 2.55-rc2, summarizing all in-flight topics as the project enters deep feature-freeze. The focus is now strictly on bugfixes and documentation; everything else will stay in the integration branches until after the release.

The most significant work in progress is Patrick Steinhardt’s ODB abstraction stack, which is refactoring Git’s object storage layer to support pluggable backends. The foundational series (`ps/odb-source-packed`) is already in `next`, and the next piece (`ps/odb-generalize-prepare`) just cleared its last review hurdle: Toon Claes’s substantive feedback has been addressed, and Junio has explicitly approved the series, so it should move to `next` shortly. Other ODB-related topics—removing the `whence` field, generic promisor checks, and moving libgit.a sources—are queued behind it.

Elsewhere, Taylor Blau’s multi-pack-index fix (`tb/midx-incremental-custom-base`) is ready, as are several smaller improvements: Han-Wen Nienhuys’s new `git history squash` and `git branch --delete-merged` commands, Karthik K’s merge-base optimization, and a handful of documentation updates. About a dozen topics are still waiting for author responses or rerolls, but none are blocking the release. The only open questions are minor design choices in a few series, like whether `git checkout --track --fetch` should fetch implicitly or require an explicit flag.
