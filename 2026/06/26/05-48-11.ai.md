This is the first patch in Toon Claes's v5 series introducing `--linearize` support to `git replay`. It is a refactoring patch that extracts the logic for updating the `replayed_commits` khash OID map into a new helper function `put_mapped_commit()`, while renaming the existing `mapped_commit()` to `get_mapped_commit()` to form a clear getter/setter pair.

The patch touches only `replay.c` and makes no behavior changes. It moves 11 lines of code into a new function and updates two call sites to use the new helpers. The motivation is to improve code clarity by encapsulating the awkward khash interface, making the lengthy `replay_revisions()` function slightly easier to follow. Patrick Steinhardt previously endorsed this change in v4 as a sensible wrapper around khash's low-level API.

This patch is uncontroversial and serves as a preparatory step for the series' main goal. It was carried over unchanged from v4, where it was already reviewed and approved. The subsequent patches in the series build on this refactoring to implement the `--linearize` functionality.
