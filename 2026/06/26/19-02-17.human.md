This is a refactoring patch in Taylor Blau’s RFC series to combine `git repack --geometric` and `--cruft`. It is the second patch in the ten-patch series (2/10) and the first step in the refactoring phase described in the cover letter.

The patch extracts the pack-lookup logic from `existing_packs_retain_cruft()` into a new static helper, `locate_existing_pack()`. The helper takes a `string_list` and a `packed_git` pointer, constructs the pack’s basename (stripping the `.pack` suffix), and returns the corresponding `string_list_item`. The existing function is then updated to call the helper instead of open-coding the lookup.

The change is purely internal: no behavior or user interface is altered. The motivation is to prepare for a later patch that will reuse the same lookup logic against a different `string_list`. The diff is small (17 insertions, 6 deletions) and touches only `repack.c`. The commit message is clear and explains the purpose of the refactoring.
