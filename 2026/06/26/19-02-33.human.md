This is a refactoring patch in Taylor Blau’s RFC series to combine `git repack --geometric` and `--cruft`. It is the seventh patch in a ten-patch series and the first in the second phase, which prepares for the new `--stdin-packs=follow-reachable` mode in `git pack-objects`.

The patch extracts the inner loop that enumerates objects from each pack into a new helper, `stdin_packs_add_all_pack_entries()`. The existing `stdin_packs_add_pack_entries()` function now builds the list of packs and dispatches to the new helper. This split is purely mechanical and does not change behavior; it simply sets the stage for the next patch, which will add an alternate code path that walks reachability instead of adding every object from the selected packs.

The change is confined to `builtin/pack-objects.c` and is small (28 insertions, 21 deletions). The commit message is clear and explains the motivation: the new helper will soon be called from two different places, depending on the `--stdin-packs` mode. No tests or documentation are added here, since this is an internal refactoring with no user-visible effect.

This patch looks like a clean, low-risk step toward the larger goal. It is well-motivated by the upcoming feature and does not introduce any new complexity on its own. Reviewers who are following the series will likely see it as a straightforward preparation for the more interesting work in patch 8/10.
