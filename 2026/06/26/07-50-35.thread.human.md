This thread is a v8 patch series from Tian Yuchen that continues the libification effort by migrating nine global configuration variables into `struct repo_config_values`, building on the recently merged `excludes_file` work. The series is now technically complete, with the final patch moving `object_creation_mode` into the per-repository structure. All patches are CI-clean, and the memory leak concern Junio C Hamano raised in v7 has been fully addressed in v8, ensuring proper cleanup of heap-allocated strings during re-assignment.

The series touches configuration handling, ignore-file logic, apply settings, branch/push defaults, editor/pager/askpass programs, attributes file, and object creation mode. While no user-visible behavior changes are introduced, the work is foundational for further modularization. Two RFC questions remain open: whether migrating program paths (editor, pager, askpass) is worthwhile, and how this effort relates to prior discussions about `git_branch_track`. The author has also promised a follow-up cleanup for comments and variable classification in `repo_config_values`, and a few `NEEDSWORK` items remain, including a circular dependency workaround for the `push_default` enum placement.

Junio’s memory leak concern was the primary technical blocker, and its resolution in v8 removes the last major obstacle to merging. The series is now under review, with no merge status reported yet. If accepted, it will further reduce Git’s reliance on global state, aligning with the broader `the_repository` removal effort.
