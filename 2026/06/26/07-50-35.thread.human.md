This thread is a follow-up to the recently merged `excludes_file` migration, extending the pattern to nine more global configuration variables. Tian Yuchen’s v9 series moves editor, pager, askpass programs, apply whitespace settings, and four enums into `struct repo_config_values`, eliminating globals and centralizing memory management. The work is technically complete, CI-clean, and leak-free after Junio C Hamano flagged a regression in v8 that Tian fixed in v9.

The series is under active review but not yet in `next`. Pablo Sabater has raised design concerns about submodule handling and initialization-order crashes in the destructor, while also noting minor performance nits in the getters. Tian has agreed to some signature changes but prefers fail-fast behavior over robustness, leaving a philosophical divide that could delay merging. Junio’s latest note is purely procedural—clarifying how to find the base commit for local testing—and doesn’t signal any new technical issues. The only open questions are Tian’s RFCs about whether migrating program paths is worthwhile and how this work might interact with `git_branch_track` in the future.
