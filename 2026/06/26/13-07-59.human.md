This is a **test patch** in the ongoing `paint_down_to_common()` optimization series. It adds edge-case coverage for the side-exhaustion optimization in `t6600-test-reach.sh`, targeting four specific scenarios that the main optimization patch (now merged) did not exercise.

The new test cases cover:
- **Self-check**: A commit that is both the query tip and one of the merge-base candidates.
- **Duplicate inputs**: Repeated entries in the `X` list passed to `get_merge_bases_many()`.
- **Pending-stale transition**: A diamond topology where a commit transitions to `STALE` while still pending in the queue, exercising the `(PARENT1|PARENT2) -> (PARENT1|PARENT2|STALE)` code path.
- **Infinity-both-sides**: A topology entirely outside the commit-graph with non-monotonic commit dates, forcing the walk to fall back to commit-date ordering.

The tests are **well-motivated and thorough**. Each case includes a detailed ASCII diagram in the setup phase and clear input/output expectations. The `pending-stale` and `infinity-both-sides` topologies are particularly clever, constructed to hit rarely exercised code paths that could otherwise regress silently. The patch also updates the test script’s setup to build these side topologies, ensuring they are available for future test additions.

This is **not a new optimization**—it is test coverage for an already-merged performance improvement. The patch is **low-risk** (no behavior changes) and **high-value** (defends against subtle regressions in a critical merge-base calculation). It is part of a **collaborative effort**: authored by Elijah Newren, co-signed by Kristofer Karlsson, and directly addresses feedback from the v2 discussion about edge-case coverage.

The patch is **ready for review** and should be uncontroversial. It touches only the test suite and does not interact with the main codebase or on-disk formats. If you care about merge-base correctness or the `paint_down_to_common()` optimization, this is worth a quick skim to confirm the test logic matches the described scenarios.
