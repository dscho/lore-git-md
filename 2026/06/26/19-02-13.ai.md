This is the first patch in Taylor Blau’s RFC series to combine `git repack --geometric` and `--cruft`. It is a **refactoring** that simplifies the cruft-pack machinery by making the exclusion of non-kept packs unconditional.

The patch removes the conditional logic that previously handled non-kept pack exclusion in two separate branches (one for `--combine-cruft-below-size`, one for everything else) and instead always excludes non-kept packs. This change is preparatory: the next patch will use the `pack_geometry` struct to decide which non-kept packs to exclude, so the logic must be unified first.

The diff touches only `repack-cruft.c`, moving the `for_each_string_list_item` loop that writes non-kept packs outside the `if` block. The change is mechanical and does not alter behavior; it merely reorganizes the code to make the subsequent geometric-split integration cleaner. No new tests are added here, as the patch is purely internal refactoring.
