This is the eighth patch in Taylor Blau’s ten-patch RFC series to combine `git repack --geometric` and `--cruft`. It introduces the new `--stdin-packs=follow-reachable` mode to `git pack-objects`, which is the technical centerpiece of the series.

The new mode is a reachability-aware variant of the existing `--stdin-packs=follow`. Instead of including every object from the listed packs, it starts from reference tips and walks only those objects that are both reachable *and* belong to an included pack (or are reachable from a commit in one). Objects in excluded-open packs (`!`) are traversed but not included; objects in excluded-closed packs (`^`) halt the traversal. The implementation uses a two-phase commit-only pre-walk to mark included-pack commits, then a full object traversal from the reachable marked tips.

The patch adds 175 lines of C code in `builtin/pack-objects.c`, documents the new mode in `git-pack-objects(1)`, and provides four new tests in `t/t5331-pack-objects-stdin.sh` that verify exclusion of unreachable objects, handling of open/closed pack boundaries, and integration with `--unpacked` (including loose commits and annotated tags). No on-disk format changes are involved; the feature is purely a workflow optimization for geometric repacking with cruft packs.
