This is a **surface-level review** from Junio C Hamano on the first patch of Toon Claes's fully merged `git replay --linearize` series. The patch itself is a refactoring that introduces `put_mapped_commit()` and renames `mapped_commit()` to `get_mapped_commit()` to create a clearer getter/setter pair for the `replayed_commits` khash OID map.

Junio's feedback is purely stylistic: he points out that the `BUG()` macro (and similar Git print utilities like `warning()`, `error()`, and `die()`) automatically append a newline, so the explicit `\n` at the end of the single-line message is redundant and should be removed. This is a minor nit about coding style rather than a technical concern. The rest of the patch meets his approval ("looking good").

The patch remains uncontroversial and is part of a series that has already been fully merged to Junio's `seen` branch. This review does not affect the series' status or its readiness for the next release.
