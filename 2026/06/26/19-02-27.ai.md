This is the fifth patch in Taylor Blau’s RFC series to combine `git repack --geometric` and `--cruft` modes. It teaches geometric repacks to use the common `existing_packs` deletion machinery instead of the geometry-specific `pack_geometry_remove_redundant()` function, unifying the deletion path for all repack types.

The patch makes two key changes. First, it moves the deletion logic for geometric repacks into the shared `existing_packs_mark_for_deletion()` call, which already handles all-into-one repacks. Packs above the geometric split line are retained earlier (via `existing_packs_retain_from_geometry()` in patch 3/8), so they are automatically excluded from deletion. Second, it adds a new helper, `existing_packs_retain_all_cruft()`, to ensure that cruft packs are not deleted when running a geometric repack without `--combine-cruft-below-size` (since geometric repacks in that mode do not rewrite cruft packs).

The diff touches `builtin/repack.c` to adjust the deletion logic, `repack.c` to add the new helper, and `repack.h` to declare it. The change is mechanical and low-risk: it replaces a geometry-specific deletion path with the existing shared machinery, with the only new behavior being the conditional retention of cruft packs. This aligns with the series’ goal of unifying repack workflows while preserving existing semantics. No new tests are introduced here, but the patch sets up the groundwork for the `--stdin-packs=follow-reachable` integration in later patches.
