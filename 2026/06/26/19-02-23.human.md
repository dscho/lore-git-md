This is the fourth patch in Taylor Blau’s ten-patch RFC series to combine `git repack --geometric` and `--cruft`. It teaches the MIDX retention logic to skip packs that are below the geometric split line, so they remain eligible for deletion even if an old MIDX chain still references them.

The patch adds two helpers: `pack_geometry_contains_pack()` walks a list of packs to see if a given basename is present, and `pack_geometry_contains_rollup()` uses that to check whether a pack is part of the geometric rollup (either regular or promisor packs). The main function, `existing_packs_retain_midx_packs()`, is updated to take an optional `pack_geometry` parameter; when provided, it skips any pack that is below the split line. The only caller in `builtin/repack.c` is adjusted to pass the geometry struct when writing an incremental MIDX.

This is a small, focused refactoring that does not change behavior yet—geometric repacks still do not use the existing-packs deletion path—but it lays the groundwork for the later patches that will wire everything together. The change is clean and well-contained, touching only the MIDX retention logic in `repack.c` and its header. No new tests are introduced in this patch; testing will come when the feature is fully plumbed in later patches.
