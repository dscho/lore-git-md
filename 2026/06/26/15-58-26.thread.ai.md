Core problem or goal
The loose object map (`ObjectMap`) in Git’s Rust codebase has an unchecked invariant: the two object IDs passed to `insert()` must use the expected hash algorithms (one for storage, one for compatibility). The current implementation silently accepts mismatched or unknown algorithms, risking incorrect object mapping. This patch enforces the invariant by validating the algorithms and returning a new `ObjectMapInsertError` enum for failures.
