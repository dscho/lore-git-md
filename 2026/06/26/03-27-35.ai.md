This is a **CI/platform-compatibility** follow-up in the ongoing macOS CI hang investigation. Michael Montalbo now identifies the root cause as an **Apache `mod_http2` bug** (upstream bug 70131) that manifests as either a mid-transfer abort (`curl 18`) or an indefinite HTTP/2 stall when the server-side timeout is hit. The bug is reproducible without Git (using only Apache and a quiet CGI script) and persists across multiple curl versions, ruling out curl or Git as the source. Montalbo proposes a **client-side mitigation**: enabling Git’s existing but disabled `http.lowSpeedLimit` and `http.lowSpeedTime` settings to turn indefinite hangs into fast, loud failures. The suggested patch (a one-line addition to `t/lib-httpd.sh`) sets a 1-byte/sec floor and a 60-second window, which locally converts a stall into a bounded abort. No new test or CI configuration changes are introduced; the proposal is purely about bounding the symptom while waiting for an upstream Apache fix. The thread remains focused on **whether this mitigation is acceptable**, with no maintainer response yet.
