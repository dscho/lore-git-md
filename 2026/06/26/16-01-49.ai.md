This is a platform compatibility fixup for Patrick Steinhardt’s RFC v2 patch that moves `libgit.a` sources into a `lib/` directory. Johannes Schindelin (Git for Windows maintainer) reports a missed path adjustment in the GitHub Actions workflow file (`.github/workflows/main.yml`) that broke the `vs-build` job. The fix adds a missing `path: lib/compat` directive to the `get-azure-pipelines-artifact` step, ensuring the Windows CI job can locate the relocated compatibility files. The change is minimal—one line added—and is validated by a successful CI run on Git for Windows.

The fix is a direct follow-up to the second patch in the series, addressing a build regression specific to the Visual Studio toolchain. No other subsystems are affected, and the adjustment aligns with the broader reorganization’s goal of preserving build integrity. Johannes’s patch is presented as a `fixup!` commit, indicating it should be squashed into the original patch before final submission. This is a surface-level review contribution, but it is critical for Windows compatibility and has been tested in the Git for Windows CI pipeline.
