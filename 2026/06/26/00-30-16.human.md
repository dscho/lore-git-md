This is Junio C Hamano’s biweekly “What’s cooking in git.git” report for June 2026 (#10), summarizing the state of the integration branches as Git 2.55-rc2 enters deep feature-freeze.

The tree is now in deep freeze: only regression fixes and documentation updates will graduate from ‘next’ to ‘master’ before 2.55 final; everything else will stay in ‘next’ until the next cycle.

Below are the highlights that a busy reader might want to scan:

• **New topics needing review**
  – ad/gpg-strip-cr-before-lf (1 patch): fixes GPG/SSH signature parsing to strip CR only when it immediately precedes LF, not unconditionally.
  – jt/receive-pack-use-odb-transactions (6 patches): refactors git-receive-pack to use the new ODB transaction API instead of tmp_objdir, moving it closer to ODB-backend agnosticism. One review comment is still open.
  – ps/odb-drop-whence (7 patches): removes the ‘whence’ field from struct object_info, replacing it with an opt-in struct object_info_source for backend-specific data. Depends on ps/odb-source-packed.
  – ps/reftable-hardening (11 patches): hardens the reftable parser against corrupted tables (OOB reads/writes, NULL derefs, etc.) and adds an oss-fuzz target.
  – hn/branch-push-slip-advice (3 patches): teaches “git push origin/main” and “git branch origin main” to suggest the obvious typo fix when the slash is misplaced. Junio requested a test-grep tweak.
  – jc/history-message-prep-fix (1 patch): plugs a file stream leak in the experimental “git history” command.
  – ty/migrate-excludes-file (2 patches): moves the excludes_file global into struct repo_config_values. Junio asked for a re-roll to address a test nit.

• **Stalled topics** (no activity for weeks)
  – jt/config-lock-timeout (1 patch): adds core.configLockTimeout to retry acquiring config.lock.
  – js/parseopt-subcommand-autocorrection (11 patches): teaches parse-options to autocorrect mistyped subcommands.
  – cl/conditional-config-on-worktree-path (2 patches): adds [includeIf "worktree"] and [includeIf "worktree/i"] conditions.

• **Cooking in ‘next’ (ready for 2.56 unless regressions surface)**
  – kk/merge-base-exhaustion (7 patches): speeds up merge-base walks by stopping early when one side’s exclusive commits are exhausted.
  – dk/meson-enable-use-nsec-build (1 patch): wires up the USE_NSEC Meson knob.
  – ps/connected-generic-promisor-checks (5 patches): refactors connectivity checks to use the ODB interface instead of iterating packfiles directly, enabling promisor-object searches in non-packfile backends.
  – ps/libgit-in-subdir (3 patches): moves libgit.a sources into a new “lib/” directory to clean up the top-level.
  – ps/odb-generalize-prepare (3 patches): generalizes the reprepare() callback into a prepare() callback with a flush flag and adds an odb_prepare() wrapper.
  – jc/submittingpatches-design-critiques (1 patch): clarifies how to respond to design critiques in SubmittingPatches.
  – wy/doc-clarify-review-replies (2 patches): encourages replying to review comments before rerolling and advises at most one reroll per day.
  – ty/migrate-ignorecase (2 patches): migrates core.ignorecase into repo_config_values.
  – mm/line-log-limited-ops (7 patches): scopes --stat, --check, and -G to the -L range in “git log -L”.
  – hn/history-squash (4 patches): adds “git history squash” to fold a range of commits into one and replay descendants.
  – ps/t4216-tap-fix (1 patch): fixes a no-op test that broke TAP output.
  – mh/fetch-follow-remote-head-config (8 patches): adds fetch.followRemoteHEAD to control whether HEAD is auto-followed.
  – ps/refs-writing-subcommands (5 patches): extends “git refs” with create/delete/update/rename subcommands.
  – po/hash-object-size-t (6 patches): fixes >4 GB object hashing on LLP64 platforms by switching to size_t.
  – kh/submittingpatches-trailers (5 patches): updates SubmittingPatches to encourage standard trailers and discourage Linux-specific ones.
  – mv/log-follow-mergy (1 patch): improves “git log --follow” for non-linear histories with divergent renames.
  – wy/doc-myfirstcontribution-trim-quotes (1 patch): advises new contributors to trim quoted text in replies.
  – tb/midx-incremental-custom-base (3 patches): fixes “git multi-pack-index write --incremental --base” to honor the custom base.
  – mm/test-grep-lint (6 patches): adds a greplint tool to detect bare grep assertions and converts existing tests to test_grep.
  – rs/cat-file-default-format-optim (1 patch): speeds up “git cat-file” default format.
  – ps/setup-drop-global-state (8 patches): drops the remaining global setup variables (git_work_tree_cfg, is_bare_repository_cfg) and stops using the_repository in is_bare_repository().
  – ps/refs-avoid-chdir-notify-reparent (12 patches): converts ref backends to use absolute paths, eliminating chdir_notify_reparent() and fixing a memory leak.
  – ps/odb-source-packed (18 patches): refactors the packed object source into a proper struct odb_source.
  – td/ref-filter-restore-prefix-iteration (1 patch): restores prefix-scoped iteration in ref-filter, fixing a loose-ref scaling regression.
  – ty/move-protect-hfs-ntfs (2 patches): migrates protect_hfs and protect_ntfs into repo_config_values.
  – ps/cat-file-remote-object-info (13 patches): adds “remote-object-info” to “git cat-file --batch-command”, allowing clients to request object metadata (size) from a remote server without downloading the object. The client dynamically filters format placeholders based on server-advertised capabilities.
  – ps/doc-recommend-b4 (3 patches): adds project-specific b4 configuration and recommends its use in MyFirstContribution.
  – sn/rebase-update-refs-symrefs (1 patch): teaches “git rebase --update-refs” to skip branch symref aliases.
  – tb/pack-path-walk-bitmap-delta-islands (5 patches): enables reachability bitmaps and delta-islands with “git pack-objects --path-walk”.
  – pw/status-rebase-todo (2 patches): improves “git status” rebase todo list parsing to correctly abbreviate object IDs and avoid misinterpreting refs as object IDs.

• **On hold (blocked by other topics)**
  – kk/prio-queue-get-put-fusion (2 patches) and kk/prio-queue-cascade-sift (1 patch): two prio-queue optimizations that depend on each other; neither can land first.

• **Other notable items**
  – tc/replay-linearize (3 patches): adds “git replay --linearize” to drop merge commits and linearize history, mimicking “git rebase --no-rebase-merges”.
  – ty/migrate-trust-executable-bit (3 patches): migrates core.filemode into repo_config_values.
  – jk/repo-info-path-keys (3 patches): adds path.gitdir and path.commondir keys to “git repo info” with both absolute and relative formatting.
  – ps/history-drop (10 patches): adds “git history drop” to remove a commit and replay descendants.
  – jk/setup-gitfile-diag-fix (1 patch): fixes a NULL-pointer crash in read_gitfile() error reporting.
  – kh/doc-trailers (10 patches): improves interpret-trailers documentation.
  – za/completion-hide-dotfiles (2 patches): hides dotfiles by default in path completion unless the user types a dot.
  – ec/commit-fixup-options (2 patches): allows -m/-F/-c/-C for all “git commit --fixup” variations.
  – kh/doc-replay-config (4 patches): improves git-replay(1) documentation and links to its configuration variables.
  – hn/status-pull-advice-qualified (1 patch): qualifies “git pull” advice with <remote> <branch> when the push branch is not the upstream.
  – hn/branch-delete-merged (7 patches): adds “git branch --delete-merged <branch>” to delete local branches already merged to their remote-tracking branch.
  – cc/promisor-auto-config-url-more (8 patches): loosens promisor-remote protocol handling to allow the server to add to the list of promisor remotes via promisor.acceptFromServerURL.
  – hn/checkout-track-fetch (2 patches): extends “git checkout --track” with a “fetch” mode to refresh the start-point branch.
  – en/ort-harden-against-corrupt-trees (5 patches): makes the ort merge backend abort when it encounters duplicate tree entries or non-adjacent D/F conflicts.
  – ap/http-redirect-wwwauth-fix (1 patch): preserves WWW-Authenticate headers across redirects.
  – mm/diff-process-hunks (6 patches): introduces diff.<driver>.process to allow external tools to act as hunk providers while leaving output formatting to Git.
