This is the first patch in the v5 series introducing `--linearize` to `git replay`. It is a pure refactoring patch that extracts the logic for storing a commit mapping into a new helper function, `put_mapped_commit()`, and renames the existing `mapped_commit()` to `get_mapped_commit()` for symmetry.

The change is mechanical and does not alter behavior. It shortens `replay_revisions()` by moving the khash map insertion into a separate function, making the code slightly easier to read. The new helper is static and only used within `replay.c`. This patch was originally part of v4 but was carried over unchanged after the controversial `enum replay_mode` refactoring was reverted in response to Junio and Patrick Steinhardt’s feedback.

The patch is small (20 insertions, 11 deletions) and touches only `replay.c`. It is a prerequisite for the later patches in the series, which build on the renamed and extracted helpers. No test changes are needed because the patch does not change functionality. The refactoring is clean and uncontroversial; it simply prepares the codebase for the `--linearize` feature introduced in patch 3.
