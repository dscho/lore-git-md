This is a minor review comment from Junio Hamano on the first patch of Toon Claes’s now-merged `git replay --linearize` series. This is a surface-level nit about consistency with the project’s coding conventions. The patch was otherwise approved and has already been merged to the `seen` branch as part of the full series.
