This is a **performance optimization** in the commit-reach subsystem, specifically targeting the `paint_down_to_common()` function used in merge-base calculations. The series is now in its **third iteration (v3)** and is **post-merge follow-up work**—all patches from v2 are already merged, and this version introduces **one new patch (8/8)** that consolidates termination conditions and adds a **behavior change** to the generation-monotonicity assertion.

The core optimization teaches `paint_down_to_common()` to terminate early when one side of the history is exhausted—no new merge-base candidates can emerge once one side’s queue is empty. This eliminates unnecessary traversal of large one-sided histories (e.g., repositories with import grafts or shallow histories), yielding **100-1000x speedups** for asymmetric queries. The optimization is gated by the finite-generation guard (`last_gen < GENERATION_NUMBER_INFINITY`) to ensure correctness, and the series now **widens the generation-monotonicity BUG assertion** to fire unconditionally, not just when `min_generation` is set. This is a **behavior change**: the assertion now enforces correct generation ordering for all callers, not just those using `min_generation`.

The new patch (8/8) moves the `min_generation` termination check into `paint_queue_get()`, consolidating all halt conditions in one place. This simplifies the main loop and ensures the `last_gen` monotonicity assertion is shared across all checks. The patch also adopts a "pop first" form for `paint_queue_get()` (pop, check, then decrement counters), keeping the optimization commit’s diff minimal. The commit message and inline comments now focus on *what* the function does rather than *how*, improving readability.

The series is **well-tested and instrumented**. The benchmarks include both step counts and wall-clock times, and the test coverage spans edge cases (self/duplicate/pending-stale/infinity-both-sides), diamond topologies, mixed finite/INFINITY generation numbers, criss-cross merges, grafts, and shallow histories.
