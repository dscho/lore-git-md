This is the first patch in Taylor Blau’s RFC series to combine `git repack --geometric` and `--cruft`. It’s a small refactoring in the cruft-pack machinery that unconditionally excludes non-kept packs from the cruft pack, regardless of whether `--combine-cruft-below-size` is in use.

The change itself is straightforward: previously, non-kept packs were excluded only in the `else` branch of a conditional that handled `--combine-cruft-below-size`. Now they’re excluded in all cases, which simplifies the logic and prepares the code for a later patch that will use the `pack_geometry` struct to decide which non-kept packs to exclude. The diff is minimal—just moving a loop outside the conditional—and the commit message clearly explains the motivation and the preparatory nature of the change.

This patch is well-crafted and uncontroversial on its own. It doesn’t change behavior, just cleans up the code to make the next steps easier. If the series as a whole gains traction, this patch is likely to be merged as-is.
