This is Junio C Hamano’s "What’s cooking in git.git" report for June 2026 (#10), summarizing the state of all in-flight topics as Git 2.55-rc2 enters deep feature-freeze. Below is the technical brief for a future AI summarizer session, capturing the key details needed to follow subsequent discussion.

The report lists 48 topics, grouped into New Topics (8), Stalled (3), and Cooking (37). The tree is in deep freeze: only bugfixes and documentation updates will graduate from ‘next’ to ‘master’; everything else will remain in ‘next’ until after 2.55 final.

New Topics
• ad/gpg-strip-cr-before-lf (1 commit): GPG/SSH signature parsing now strips CR only when it immediately precedes LF, fixing a regression in handling mixed CRLF/LF signatures. Needs review.
• jt/receive-pack-use-odb-transactions (6 commits): git-receive-pack is refactored to use the ODB transaction interface instead of tmp_objdir, making it backend-agnostic. Waiting for author response to review comments.
• ps/odb-drop-whence (7 commits): The ‘whence’ field in struct object_info is removed; backend-specific information is now opt-in via struct object_info_source. Depends on ps/odb-source-packed. Needs review.
• ps/reftable-hardening (11 commits): The reftable backend is hardened against corrupted tables: OOB reads/writes, NULL pointer dereferences, and aborts during parsing are fixed. A libFuzzer-based fuzzer is added. Needs review.
• hn/branch-push-slip-advice (3 commits): “git push origin/main” and “git branch origin main” now suggest the obvious typofix when the slash is misplaced. Waiting for author response.
• jc/history-message-prep-fix (1 commit): Code clean-up and leak fix in the experimental “git history” command. Needs review.
• ty/migrate-excludes-file (2 commits): The global excludes_file variable is moved into struct repo_config_values. Waiting for author response.
• ps/connected-generic-promisor-checks (5 commits): The connectivity check is refactored to search for promisor objects generically via the ODB interface, allowing it to work in repositories that do not use packfiles. Depends on ps/odb-source-packed. Ready for ‘next’.

Stalled Topics
• jt/config-lock-timeout (1 commit): Configuration file locking now retries for a configurable period. Stalled for too long; needs author response.
• js/parseopt-subcommand-autocorrection (11 commits): The parse-options library learns to autocorrect misspelled subcommand names. Stalled for too long; needs author response.
• cl/conditional-config-on-worktree-path (2 commits): [includeIf] learns “worktree” and “worktree/i” conditions. Stalled for too long; needs author response.

Cooking Topics (highlights)
• kk/merge-base-exhaustion (7 commits): Merge-base computation stops early when one side’s exclusive commits are exhausted, yielding large speedups for one-sided histories. Expecting reroll.
• dk/meson-enable-use-nsec-build (1 commit): USE_NSEC is wired up in the Meson build. Waiting for author response.
• ps/libgit-in-subdir (3 commits): libgit.a sources are moved into a new “lib/” directory. Depends on ps/odb-source-packed. Needs review.
• ps/odb-generalize-prepare (3 commits): The reprepare() callback is generalized into a prepare() callback with an optional flush flag, and odb_prepare() is introduced. Depends on ps/odb-source-packed. Needs review.
• jc/submittingpatches-design-critiques (1 commit): SubmittingPatches now documents how to handle design critiques and record resolution in commit messages. Already merged to ‘next’.
• wy/doc-clarify-review-replies (2 commits): Documentation encourages replying to review comments before rerolling and advises at most one reroll per day. Ready for ‘next’.
• ty/migrate-ignorecase (2 commits): core.ignorecase is moved into struct repo_config_values. Waiting for Johannes Schindelin’s review.
• mm/line-log-limited-ops (7 commits): “git log -L<range>:<path>” now limits --stat, --check, and -G to the specified range. Expecting reroll.
• hn/history-squash (4 commits): “git history squash” folds a range of commits into one, replaying descendants. Needs review.
• ps/refs-avoid-chdir-notify-reparent (12 commits): Reference backends now use absolute paths internally, dropping chdir_notify_reparent() and fixing a memory leak in repository construction. Ready for ‘next’.
• ps/odb-source-packed (18 commits): The packed object source is refactored into a proper struct odb_source. Already merged to ‘next’.
• ps/cat-file-remote-object-info (13 commits): “git cat-file --batch-command” gains a remote-object-info command that requests object metadata (currently size) from a remote server via protocol v2. The client dynamically filters format placeholders based on server capabilities. Waiting for author response.
• tb/midx-incremental-custom-base (3 commits): git multi-pack-index write --incremental now honors --base, fixing reachability closure for bitmaps. Needs review.
• mm/test-grep-lint (6 commits): A greplint tool detects bare grep assertions in tests; many tests are converted to test_grep. Needs review.
• ty/migrate-trust-executable-bit (3 commits): core.trustctime and core.filemode are moved into struct repo_config_values. Needs review.
• tc/replay-linearize (3 commits): “git replay --linearize” drops merge commits and linearizes the replayed history. Expecting reroll.
• ps/setup-drop-global-state (8 commits): The last global setup variables (git_work_tree_cfg, is_bare_repository_cfg) are removed; is_bare_repository() no longer implicitly uses the_repository. Already merged to ‘next’.
• hn/branch-delete-merged (7 commits): “git branch --delete-merged <branch>” removes local branches already merged to their remote-tracking branch. Needs review.
• hn/checkout-track-fetch (2 commits): “git checkout --track=remote/branch --fetch” fetches the branch before creating the local tracking branch. Waiting for author response.
• ps/shift-root-in-graph (3 commits): “git log --graph” indents parentless root commits to visually distinguish them. Waiting for author response; the peek-ahead approach may be dropped.
• kh/doc-trailers (10 commits): interpret-trailers documentation is updated to clarify key format, comment-line treatment, and the “trailer block” terminology. Expecting reroll.

Key dependencies
• ps/odb-source-packed is a prerequisite for ps/odb-drop-whence, ps/connected-generic-promisor-checks, ps/libgit-in-subdir, and ps/odb-generalize-prepare.
• ps/setup-centralize-odb-creation is a prerequisite for ps/setup-drop-global-state and ps/refs-avoid-chdir-notify-reparent.

Controversy / discussion points likely to recur
• ps/cat-file-remote-object-info: whether the dynamic allow-list is too complex or whether additional object metadata (type, oid, etc.) should be exposed.
• ps/shift-root-in-graph: whether the peek-ahead logic is the right approach or whether a simpler solution should be used.
• hn/branch-delete-merged: whether the opt-out branch.<name>.deleteMerged configuration is necessary.
• hn/checkout-track-fetch: whether the fetch should be implicit or require an explicit flag.
