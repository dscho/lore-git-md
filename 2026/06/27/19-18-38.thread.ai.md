Thread type: security inquiry / release coordination

Core problem or goal
A reported critical CVE (CVE-2026-34182) in OpenSSL 3.5.6, bundled with Git 2.54.0, prompted an inquiry about whether Git is exposed and, if so, when an updated release or installer would be available. The inquiry concluded that Git’s limited OpenSSL usage does not expose it to the CVE.

Current status
The thread is now closed. The original reporter accepted Todd Zullinger’s assessment that Git’s OpenSSL usage (primarily TLS for fetch/push) does not invoke the CMS functionality affected by CVE-2026-34182, and that the Windows installer question is handled by the separate Git for Windows project. No Git release or advisory is planned.

Key technical details
- Vulnerable component: OpenSSL 3.5.6 (CVE-2026-34182 affects CMS decryption/encryption)
- Git’s OpenSSL usage: TLS for fetch/push; CMS is not used directly
- Potential exposure vector: only if Git is configured to use gpgsm (via gpg.program) for x509 signatures, but gpgsm itself is not impacted by this CVE
- On-disk/installer impact: Git itself does not distribute binaries; the Windows installer is produced by Git for Windows
- Fixed OpenSSL version: 3.5.7 (released 12 June 2026)

Open questions and loose ends
None remain. The thread is closed.
