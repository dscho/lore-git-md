Subject: Security inquiry: CVE-2026-34182 (OpenSSL 3.5.6 in Git 2.54.0)
Series version: N/A (not a patch series)
Originating author: Tim Person
Thread type: security inquiry / release coordination

Core problem or goal
A reported critical CVE (CVE-2026-34182) in OpenSSL 3.5.6, bundled with Git 2.54.0 and Git for Windows, prompted an inquiry about whether Git is exposed and when an updated release or installer would be available. The inquiry concluded that neither Git nor Git for Windows is exposed to the CVE due to limited OpenSSL usage.

Current status
The thread is closed. The original reporter accepted Todd Zullinger’s assessment that Git’s OpenSSL usage does not invoke the CMS functionality affected by the CVE, and Johannes Schindelin confirmed that the OpenSSL executable bundled with Git for Windows is not critical and will be updated in the next scheduled release (v2.55.0, June 29–30, 2026). No Git release or advisory is planned.

Key technical details
- Vulnerable component: OpenSSL 3.5.6 (CVE-2026-34182 affects CMS decryption/encryption)
- Git’s OpenSSL usage: TLS for fetch/push; CMS is not used directly. Git itself is not exposed.
- Git for Windows: Bundles OpenSSL.exe for historical reasons only; not used in core operations (e.g., TLS for fetch/push). No exposure to the CVE.
- Potential exposure vector: Only if Git is configured to use gpgsm (via gpg.program) for x509 signatures, but gpgsm itself is not impacted by this CVE.
- On-disk/installer impact: Git does not distribute binaries; the Windows installer is produced by Git for Windows. The next Git for Windows release (v2.55.0) will include OpenSSL 3.5.7.
- Fixed OpenSSL version: 3.5.7 (released 12 June 2026)
