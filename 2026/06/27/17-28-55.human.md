This is the first patch in the v2 series extending `` `git log -L` `` to support range-scoped diff stat, whitespace checking, and the ``-G`` pickaxe. This patch is purely a refactoring: it renames and reorganizes the line-range filter internals to make the code clearer before the functional changes in later patches.

The patch renames the `line_range_callback` struct to `line_range_filter` and updates its field names to match the vocabulary used elsewhere in `diff.c`. For example, `lno_post` becomes `lno_in_postimage`, `rhunk_old_begin` moves into a nested `hunk` struct as `hunk.old_begin`, and the filter-state pointer in callbacks changes from `s` to `filter`. The `flush_rhunk` function is also renamed to `flush_range_hunk` for consistency. These changes make the code’s intent clearer—distinguishing between pre- and post-image line numbers, 0-based vs. 1-based indices, and hunk geometry—without altering any behavior.

The patch touches only `diff.c` and is mechanical: every change is a straightforward rename or reorganization. The commit message explains the motivation well, and the renames are applied consistently throughout the file. This sets the stage for the functional improvements in patches 2-7, which will reuse this filter to scope stat counts, whitespace errors, and pickaxe matches to the tracked line ranges. The series as a whole looks well-structured, and this patch is a sensible first step.
