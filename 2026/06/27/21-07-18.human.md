This is a security coordination reply clarifying the scope of CVE-2026-34182 for Git. Todd Zullinger responds to Tim Person’s inquiry about a critical OpenSSL vulnerability in Git 2.54.0, explaining that the Git project itself does not distribute binaries—so the request should be directed to Git for Windows instead. More importantly, he questions whether the CVE even affects Git’s usage of OpenSSL, noting that the vulnerability involves CMS (Cryptographic Message Syntax), a feature Git does not use except in niche configurations (e.g., `gpg.program` set to `gpgsm`), and even then, the affected component (`gpgsm`) is not impacted by this OpenSSL issue.

The reply is concise and authoritative, effectively downgrading the urgency of the original inquiry. It suggests the CVE may not be relevant to most Git users, though it leaves the door open for Git for Windows to address the bundled OpenSSL executable if they deem it necessary. No timeline or action plan is proposed here, but the tone implies this is not a pressing concern for the core Git project. Readers should follow up with Git for Windows if they rely on its installer.
