This is a user support report about a potential infinite loop in `git ls-remote` when querying a specific repository (`https://gitlab.xiph.org/xiph/opus.git`). The reporter, Steffen Nurpmeso, observed 100% CPU usage and an apparent hang. Michael Montalbo replies with troubleshooting suggestions rather than a code fix.

Montalbo notes that he could not reproduce the hang reliably but observed stalls, speculating that the repository's Anubis proxy (a rate-limiting service) might be interfering. He suggests enabling `GIT_TRACE_CURL=1` to debug the HTTP/TLS interaction and provides Git configuration options (`http.version=HTTP/1.1`, `http.lowSpeedLimit`, `http.lowSpeedTime`) to work around potential network issues. The response is diagnostic rather than a patch or bug confirmation, so there is no code change or subsystem to track. The thread remains open as a potential network-layer issue rather than a Git bug.
