This is the first patch in the v2 series extending `` `git log -L` `` to support range-scoped diff stat formats, whitespace checking, and the ``-G`` pickaxe. It is a pure refactoring that renames and reorganizes the line-range filter internals to make the code clearer before the functional changes in later patches.

The patch renames the ``line_range_callback`` struct to ``line_range_filter`` and replaces cryptic abbreviations with full names that match the rest of ``diff.c``. Key changes include ``lno_post`` → ``lno_in_postimage``, ``lno_pre`` → ``lno_in_preimage``, ``lno_0`` → ``idx_in_postimage``, and moving the hunk geometry fields (``rhunk_old_begin``, etc.) into a nested ``hunk`` struct. The ``flush_rhunk`` function is renamed to ``flush_range_hunk``, and the filter-state pointer in callbacks is now called ``filter`` instead of ``s``. The patch touches only ``diff.c`` and makes no behavior changes; it is purely about improving readability and maintainability.

The renaming is thorough and systematic, replacing every instance of the old names throughout the file. The new names are more descriptive and align with the vocabulary used elsewhere in the diff subsystem, which should make the subsequent patches easier to review. The patch is well-motivated in the commit message, which explains the confusion caused by the original abbreviations and how the new names clarify the filter’s model. There are no functional or behavioral changes, so this is a safe preparatory step for the series.
