This is a user support thread about a now-resolved hang in `git ls-remote`. Steffen Nurpmeso reports that the issue he previously observed—where `git ls-remote https://gitlab.xiph.org/xiph/opus.git` entered an apparent infinite loop with 100% CPU usage—no longer occurs. He confirms that the problem affected multiple repositories on the same host, not just the Opus repository, and that the hang was not due to network stalls but rather a genuine busy-loop in Git.

The thread does not involve a patch or code change. Steffen acknowledges Michael Montalbo’s earlier troubleshooting suggestions, particularly the Git configuration options (`http.version=HTTP/1.1`, `http.lowSpeedLimit`, and `http.lowSpeedTime`) that may help avoid similar issues in the future. He plans to adopt these settings but notes that the original problem has already disappeared without further intervention.

Since the issue is no longer reproducible, the thread is effectively closed as a transient or environment-specific problem rather than a Git bug. There is no actionable follow-up for developers, though the discussion may serve as a reference for users encountering similar symptoms.
