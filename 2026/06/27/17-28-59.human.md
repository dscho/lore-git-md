This is the fifth patch in Karthik Nayak’s v2 series extending `` `git log -L` `` to support range-scoped diff stat formats. It enables ``--stat``, ``--numstat``, and ``--shortstat`` to count only the lines within the tracked range, while deliberately excluding ``--dirstat`` (both bare and ``--dirstat=lines``) because its default mode measures whole-file change, not the tracked lines. The implementation reuses the line-range filter to wrap ``diffstat_consume()``, forwarding only in-range lines for counting. The documentation now clearly explains which formats are supported and why ``--dirstat`` is excluded, and the test suite has been expanded with thorough coverage of range-scoped stat counts, including edge cases like root commits, renames, and multiple ranges. The patch is well-motivated, the rationale for excluding ``--dirstat`` is sound, and the test coverage looks comprehensive. Junio’s feedback on v1 has been incorporated, and the series appears ready for further review.
