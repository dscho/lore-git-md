The patch is the final version (v4) of a series that has incorporated all prior feedback, including squashing two patches into one, replacing a temporary guard with a stricter `repo->initialized` check, and marking an unused parameter as `UNUSED`.

The patch abstracts the lazy-loading XDG fallback logic into a new getter function (`repo_excludes_file()`), migrates the variable into the repository configuration struct, and introduces proper heap memory management via an extended `repo_config_values_clear()` helper. It touches core files (`dir.c`, `environment.c`, `environment.h`, `repository.c`) and is foundational for further modularization, with no user-visible behavior changes. The implementation follows existing patterns for repository initialization checks and memory cleanup, and the author notes consistency with earlier global variable removal patches.

All substantive technical objections from earlier versions have been resolved, and the patch is now ready for submission to `next`.
