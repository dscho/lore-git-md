This is the fourth patch in Karthik Nayak’s v2 seven-patch series extending `` `git log -L` `` to support range-scoped diff stat, whitespace checking, and the ``-G`` pickaxe. It extracts a reusable helper so the upcoming stat and check formats can share the same line-range filter setup without repeating boilerplate.

The patch moves the open-coded filter initialization and xdiff pass from ``builtin_diff()`` into two new functions: ``line_range_filter_init()`` for zeroing the struct and wiring up the callback, and ``line_range_filter_diff()`` for inflating ``ctxlen`` to the largest range span, clearing ``XDL_EMIT_NO_HUNK_HDR``, running the diff, flushing the final hunk, and releasing the buffer. The helper guarantees that every change within a single range lands in one xdiff hunk and that hunk headers are always emitted, which the filter’s position tracking relies on. ``builtin_diff()`` now simply calls the two helpers, and the next two patches will reuse them in ``builtin_diffstat()`` and ``builtin_checkdiff()``.

No behavior changes; the patch is pure refactoring. The commit message explains the invariants clearly, and the code is cleanly split. It looks ready for review and should make the follow-on patches smaller and more focused.
