This thread began as an inquiry into whether Git or Git for Windows was affected by CVE-2026-34182, a critical vulnerability in OpenSSL 3.5.6. The reporter, Tim Person, initially sought confirmation and a timeline for an updated release. Todd Zullinger quickly clarified that Git itself does not use the vulnerable CMS functionality in OpenSSL, and Johannes Schindelin confirmed that the OpenSSL executable bundled with Git for Windows is not critical to core operations. The reporter has now accepted these conclusions, thanking the contributors for their explanations. The thread is now closed, with no further action required—Git is unaffected, and the next Git for Windows release (v2.55.0) will include the fixed OpenSSL version as part of its regular update cycle.
