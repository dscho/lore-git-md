This thread began as a security inquiry about CVE-2026-34182, a critical vulnerability in OpenSSL 3.5.6 (bundled with Git 2.54.0), with the reporter asking when Git would release an updated installer. Todd Zullinger quickly clarified that the Git project itself does not distribute binaries—the Windows installer is handled by the separate Git for Windows project—and questioned whether the CVE even affects Git, given its limited use of OpenSSL (primarily for TLS) and the CMS-specific nature of the flaw. The reporter has now closed the thread, accepting that Git’s usage does not appear to expose users to the vulnerability and that any installer updates would be Git for Windows’ responsibility. No further action is expected from the Git project.
