This thread began as a security inquiry about CVE-2026-34182 in OpenSSL 3.5.6, which is bundled with Git 2.54.0. Tim Person initially asked whether Git was exposed to the vulnerability and when an updated release or installer would be available. Todd Zullinger quickly clarified that Git’s limited use of OpenSSL—primarily for TLS during fetch and push operations—does not invoke the CMS functionality affected by the CVE, so Git itself is not vulnerable. He also noted that the Windows installer is handled by the separate Git for Windows project.

Johannes Schindelin, the maintainer of Git for Windows, followed up to address the Windows installer concern directly. He confirmed that the OpenSSL executable bundled with Git for Windows is not critical to Git’s functionality and poses no risk from this CVE. While no out-of-band release is planned, the next scheduled Git for Windows release (v2.55.0, expected June 29–30, 2026) will include the fixed OpenSSL 3.5.7. This closes the thread, as all questions about Git and Git for Windows exposure have been resolved. No further action is needed on the Git mailing list for this issue.
