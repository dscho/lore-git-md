This is a bug report about a hang in Git 2.54.0. The author, Steffen Nurpmeso, reports that running ``git ls-remote https://gitlab.xiph.org/xiph/opus.git`` triggers an endless loop consuming 100% CPU. The issue is fully reproducible on their system, and they note that updating the expat library did not resolve it. No investigation or patch is provided—this is purely a heads-up to the list. The report is brief and lacks details like a stack trace or bisect result, but the symptom (a hang in network-related code) is clear and serious enough to warrant attention. If this affects other users, it could be a blocker for the 2.54.0 release.
