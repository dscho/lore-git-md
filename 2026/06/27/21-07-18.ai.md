This is a security coordination reply clarifying the scope of CVE-2026-34182 and redirecting the inquiry to the correct project.

Todd Zullinger responds to Tim Person’s urgent request about a Git 2.54.0 installer update for the OpenSSL CVE. He explains that the Git project itself does not distribute binaries — the Windows installer is produced by the separate Git for Windows project — and suggests the inquiry be redirected there. More importantly, he questions whether the CVE even affects Git’s usage of OpenSSL: the vulnerability is in CMS (Cryptographic Message Syntax) functionality, which Git does not use directly. The only potential exposure would be if Git were configured to use `gpgsm` (via `gpg.program`) for x509 signatures, but Todd notes that `gpgsm` is not impacted by this OpenSSL flaw.

The tone is factual and slightly skeptical; Todd does not dismiss the CVE outright but makes it clear that the risk to Git users appears minimal. This reply shifts the thread’s focus from "when will Git release a fix?" to "does this CVE actually apply to Git at all?" and points downstream users to the Git for Windows project for any installer-specific updates. No timeline or release plan is offered, and the thread remains open for further technical clarification.
