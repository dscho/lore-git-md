This is a refactoring patch that's part of the ongoing `the_repository` removal effort. Tian Yuchen moves the global `protect_hfs` and `protect_ntfs` variables into the repository-specific `repo_config_values` struct, which helps eliminate reliance on the global repository instance.

The patch:
1. Removes the global variables and adds them to `repo_config_values`
2. Updates all access points to use the repository-specific versions
3. Handles a special case in the test helper where these were used as loop variables by introducing local replacements

The changes are mechanical but touch several files including platform-specific code (mingw.c) and the test helper benchmark. The patch maintains existing behavior while moving toward the architectural goal of removing `the_repository`. It's a straightforward change with clear motivation, though it leaves some temporary fallbacks to `the_repository` that will need future cleanup.

Mentored by Christian Couder and others, this appears to be a solid incremental step in the larger refactoring effort. The patch is well-contained and doesn't introduce any new functionality or behavior changes.
