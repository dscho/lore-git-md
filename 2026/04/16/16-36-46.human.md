Feature patch adding submodule support to worktree add.

This third patch in a series adds a `--recurse-submodules` flag to `git worktree add`, bringing it in line with similar flags on other commands like `checkout` and `clone`. The implementation ensures proper isolation by storing submodule gitdirs under the worktree-specific directory rather than the shared modules directory, preventing cross-contamination between worktrees.

Two new tests verify the behavior: one confirms submodules are properly initialized, while the other checks the isolation guarantee by verifying the gitdir location and working tree contents. The patch also renames an existing test to clarify it covers the non-recursive case.

The implementation appears well-considered, with clear test coverage for both the happy path and the isolation properties. This fills a notable gap in worktree functionality for projects using submodules. The patch builds on previous work in the series (not shown here) that established the basic worktree-with-submodules infrastructure.
