This is a test infrastructure patch from Patrick Steinhardt, part of his ongoing series to enable `set -e` in Git's test suite when running under Bash 5+. The patch fixes specific test cases that would fail under `set -e` due to how they check for expected signal deaths.

The change modifies three test cases that verify Git dies with SIGPIPE (signal 13) under certain conditions. The original tests used a pattern of `command; echo $?` to capture the exit code, which would cause the subshell to exit immediately under `set -e` when the command fails. The patch replaces this with `command && echo 0 || echo $?`, which properly handles the failure case while remaining compatible with `set -e`.

The changes are mechanical and focused - touching only the signal verification tests in t0005-signals.sh and t3600-rm.sh. This continues Patrick's careful, incremental approach to test modernization, ensuring each change maintains backward compatibility while preparing for the `set -e` transition. The patch shows his characteristic attention to detail, with each modification clearly serving the series' goal of making the suite more robust against silent failures.
