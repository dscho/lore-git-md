The change relocates ~700 files from Git's root directory (including core subsystems like object handling, refs, diff, merge, and utilities) while preserving their internal structure. Motivation remains improved code discoverability by reducing root directory file count from ~550 to ~80, making libgit.a boundary more visible in directory structure.
