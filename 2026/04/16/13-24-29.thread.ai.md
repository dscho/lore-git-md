RFC proposal from Patrick Steinhardt to reorganize Git's source tree by moving all libgit.a components into a new "lib/" directory. This would relocate ~700 files currently in the root directory (including core subsystems like object handling, refs, diff, merge, and utilities) while keeping their internal structure intact. Build system files (Makefile, CMakeLists.txt, meson.build) are updated to reflect new paths. Minimal code changes beyond location updates.

Motivation is improved code discoverability, following up on 2024 Contributor's Summit discussions. Acknowledges potential controversy with RFC status. Tested against GitLab and GitHub builds. Would be a significant structural change affecting all build configurations and downstream consumers relying on current header locations. Timing suggests aiming for next release cycle if accepted.
