This is part 7 of Patrick Steinhardt's 12-patch series to enable `set -e` in Git's test suite when running under Bash 5+. The patch focuses on fixing the behavior of `test_when_finished()` and `test_atexit()` cleanup handlers to work correctly under strict error checking.

The change modifies how exit codes are preserved when running cleanup commands. The current implementation uses `&& (exit "$eval_ret")` which would fail under `set -e` when `eval_ret` is non-zero. The patch replaces this with `|| eval_ret=$?`, which maintains the same exit code preservation behavior while being compatible with `set -e`. The commit message includes clear truth tables showing the behavior remains identical before and after the change.
