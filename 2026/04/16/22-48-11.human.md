This is a performance optimization series from Elijah Newren that adds batch prefetching of missing blobs to `git cherry` and `git grep` commands when running in partial clone mode. The motivation comes from real-world cases where single-blob fetches were causing significant slowdowns (3 seconds per blob in one reported case).

The series consists of:
1. A documentation fix to `patch-ids.h` (a preparatory cleanup)
2. Implementation of blob prefetching for `git cherry`
3. Implementation of blob prefetching for `git grep`

The cover letter includes a detailed design spec document (`investigations/cherry-prefetch-design-spec.md`) explaining the approach. The key insight is that while users could manually run `git backfill` to pre-download needed blobs, it's better to automatically batch prefetch when we can determine what will be needed - especially for commands like `cherry` where predicting needed blobs manually would be difficult.

The changes are well-motivated by concrete performance problems and come with new tests to verify the behavior. As a merge/diff expert, Newren is well-positioned to implement this optimization correctly. The series looks like a solid quality-of-life improvement for partial clone users.
