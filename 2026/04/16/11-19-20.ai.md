This is part 3 of Patrick Steinhardt's test infrastructure series to enable `set -e` in Git's test suite when running under Bash 5+. The patch focuses on preparing the `stop_git_daemon()` helper function for `set -e` compatibility.

The change modifies how the function handles process termination and error checking when stopping a background git-daemon process. The key adjustments are:
1. Changing the `wait` call to explicitly capture the exit code rather than letting it potentially trigger `set -e` termination
2. Silencing the second `kill` attempt (which often fails since the process is already terminated) by adding `|| :` to swallow the error

These changes maintain the existing behavior while making it robust under `set -e`. The patch continues the series' pattern of mechanical test infrastructure updates that preserve backward compatibility while enabling stricter error checking. As with previous patches in the series, this demonstrates careful attention to edge cases in test helpers that might otherwise cause spurious failures under `set -e`.

The change is narrowly scoped to the git-daemon test helper and follows the established pattern from earlier patches in the series. It represents another incremental step toward the overall goal of making the test suite more reliable by catching silent failures.
