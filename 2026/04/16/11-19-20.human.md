This is a test infrastructure patch from Patrick Steinhardt, part of his ongoing series to enable `set -e` in Git's test suite when running under Bash 5+. The patch focuses on preparing the `stop_git_daemon()` helper function for this change.

The function currently has two issues that would cause failures under `set -e`: an unconditional `wait` call that's expected to fail, and a redundant `kill` attempt that often fails. The patch makes these operations resilient by:
1. Making the `wait` call explicitly handle failure with `||` syntax
2. Silencing the second `kill` attempt with `|| :`

This is a mechanical but necessary change to support the broader `set -e` effort, which aims to catch silent test failures more reliably. The patch follows the established pattern seen in earlier parts of the series, showing careful attention to backward compatibility while modernizing test infrastructure. As with previous patches in the series, this appears to be a well-considered change that maintains existing behavior while preparing for the stricter error handling to come.
