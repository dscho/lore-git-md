Feature addition to `git cat-file`'s batch mode, now ready for merging.

This is the final version of Siddharth Asthana's patch adding dynamic mailmap toggling to `git cat-file --batch-command`. The feature allows changing mailmap behavior mid-operation without restarting the process, addressing GitLab Gitaly's need to reuse long-running processes. The implementation introduces a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off).

The patch has gone through five iterations with feedback incorporated from multiple reviewers, including Junio Hamano, Patrick Steinhardt, and Jean-Noël Avila. The final version simplifies the documentation to focus on user-visible behavior while maintaining all the key functionality: mailmap data is loaded on first use and persists in memory, allowing toggling without reloading. The changes are well-contained to `builtin/cat-file.c` and its tests, with comprehensive test coverage in `t/t4203-mailmap.sh`.

This is a clean, well-reviewed feature that solves a real-world use case for GitLab's infrastructure.
