This is a refactoring proposal from Patrick Steinhardt to reorganize Git's source code by moving all libgit.a sources into a dedicated "lib/" directory. The patch series comes as an RFC (Request For Comments), acknowledging it may be controversial.

The change would relocate nearly 700 files that currently live in the root directory into a new lib/ subdirectory, including core components like object handling, refs, diff, merge, and various utilities. The patch shows extensive file moves but minimal actual code changes - the primary modification is updating build system files (Makefile, CMakeLists.txt, meson.build) to handle the new locations.

Patrick notes this follows up on a discussion from the 2024 Git Contributor's Summit and aims to improve code discoverability, which he says is currently problematic even for experienced contributors. The RFC status suggests he's open to alternative approaches or rejection if the community disagrees. The patch has been tested against GitLab and GitHub's builds.

This would be a significant structural change affecting nearly every part of Git's build system. While mechanically straightforward (just moving files), it touches many build configurations and could impact downstream consumers who expect certain header locations. The timing right before a new release cycle suggests Patrick wants to land this early if accepted, giving maximum time to address any fallout.
