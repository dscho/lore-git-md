Feature addition to `git worktree` with submodule support. This patch adds a `--recurse-submodules` flag to `git worktree add` that properly initializes submodules in the new worktree while maintaining isolation from the main worktree.

The implementation ensures two key properties: (1) submodule working trees are properly populated when the flag is used (verified by checking `git diff --submodule` output), and (2) submodule gitdirs are stored under the worktree-specific directory (`.git/worktrees/<id>/modules/`) rather than the shared location, ensuring clean removal of worktrees doesn't affect the main worktree's submodules. The patch includes two new tests in t2405-worktree-submodule.sh that verify these behaviors.

The change appears well-motivated and carefully implemented, with clear test coverage for both the basic functionality and the isolation guarantees. The tests check both the working tree state and the underlying gitdir locations, suggesting thoughtful consideration of the edge cases involved in worktree/submodule interactions. This builds on existing worktree and submodule infrastructure while maintaining backward compatibility (the original behavior without the flag remains unchanged, though noted as test_expect_failure).
