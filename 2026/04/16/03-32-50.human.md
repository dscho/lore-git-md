Feature addition to `git cat-file`'s batch mode, now ready for merging.

This final patch from Siddharth Asthana adds dynamic mailmap toggling to `git cat-file --batch-command`, allowing mailmap behavior to be changed mid-operation without restarting the process. The implementation introduces a new `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off), addressing GitLab Gitaly's need to modify mailmap behavior in long-running processes.

The technical approach uses lazy-loaded mailmap data caching (loaded on first use and preserved when disabled) and restructures the dispatch logic in `builtin/cat-file.c`. The patch includes comprehensive test coverage in `t/t4203-mailmap.sh` for runtime toggling, startup option interactions, and boolean value handling. Documentation has been simplified to focus on user-visible behavior while noting the one-time data loading characteristic.

After multiple rounds of review incorporating feedback from Junio Hamano, Patrick Steinhardt, Karthik Nayak, and Jean-Noël Avila, the patch is now in its final form with consensus that it's ready for merging. The changes remain well-scoped to `builtin/cat-file.c` and its tests while solving the original use case for GitLab's needs. This represents a clean, focused addition to Git's plumbing interface.
