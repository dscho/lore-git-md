Feature addition to `git cat-file`'s batch mode, now finalized for merging.

This is the final implementation patch for Siddharth Asthana's dynamic mailmap toggling in `git cat-file --batch-command`. The change adds a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) to control name/email rewriting during operation. This addresses GitLab Gitaly's need to modify mailmap behavior in long-running processes without restarting them.

The implementation uses lazy-loaded mailmap data that loads on first use and remains cached when disabled. The patch restructures dispatch logic in `builtin/cat-file.c` with a new `parse_cmd_mailmap` function using `git_parse_maybe_bool()` for consistent boolean parsing.
