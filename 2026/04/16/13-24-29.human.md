This is a refactoring proposal from Patrick Steinhardt to reorganize Git's source code by moving all libgit.a sources into a dedicated "lib/" directory. The patch series comes as an RFC (Request For Comments), acknowledging it may be controversial.

The change would relocate nearly 700 files - essentially all of Git's core library code - into a new top-level directory. The motivation is improved discoverability, as Patrick notes both newcomers and experienced contributors (including himself) struggle with the current flat directory structure. The patch shows extensive file movements but no functional changes - this is purely an organizational change.

The proposal follows up on discussions from the 2024 Git Contributor's Summit. Patrick has tested the changes with both GitLab and GitHub CI systems. He's timing this near a release to allow for discussion before the next cycle if consensus emerges.

This is a significant structural change that would affect all contributors working with Git's internals. While mechanically straightforward (just moving files), it touches build systems (Makefile, CMake, meson) and could impact development workflows. The RFC label suggests Patrick expects debate about whether the benefits outweigh the churn.
