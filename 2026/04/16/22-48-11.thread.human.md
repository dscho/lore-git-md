Elijah Newren has been working on optimizing partial clone behavior for `git cherry` and `git grep`, where single-blob fetches were causing significant performance issues. His three-patch series implements batch prefetching for both commands, following established patterns from checkout/diff/merge operations. The implementation handles edge cases like merge commits and binary files while maintaining exact patch ID computation, with new tests verifying the behavior.

Junio Hamano raised a minor question about including a separate design specification document, which Elijah quickly clarified was accidental - the file will be removed, keeping with Git's convention of embedding design rationale in commit messages. With this resolved and no technical concerns raised about the actual code changes, the series appears ready for merging. The optimizations should provide noticeable performance improvements for users working with partial clones.
