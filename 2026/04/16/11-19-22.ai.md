This is part 5 of Patrick Steinhardt's 12-patch series to make Git's test suite compatible with `set -e` (errexit) mode when running under Bash 5+. The patch focuses on fixing conditional test execution patterns that would fail under `set -e`.

The change addresses test patterns where conditional execution was done via `test ... && test_expect_success`. Under `set -e`, if the first `test` fails, the shell would exit rather than continuing to the next statement. The patch converts these to proper `if` statements in two test files:

- `t4032-diff-inter-hunk-context.sh`: Changes conditional test execution based on file existence
- `t7450-bad-git-dotfiles.sh`: Changes conditional test execution based on variable presence

The modifications are mechanical and maintain the same test behavior while making the code more robust under `set -e`.
