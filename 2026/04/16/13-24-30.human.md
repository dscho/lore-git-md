Refactoring patch preparing for a new "lib/" directory structure.

Patrick Steinhardt sends an RFC patch that changes an include path in a test helper file to use a relative path. This is in preparation for moving Git's code into a new "lib/" directory structure, which would otherwise break this include. The change is minimal - just adjusting one include path from "t/unit-tests/test-lib.h" to "../unit-tests/test-lib.h" in test-example-tap.c.

This appears to be part of a larger restructuring effort (indicated by the RFC status and being 1/2 in a series), though the cover letter explaining the full context isn't provided here. The patch itself is straightforward and seems uncontroversial, just ensuring the test helper will continue to work after the planned reorganization. As an RFC, it's likely seeking early input on the approach before finalizing the directory structure changes.
