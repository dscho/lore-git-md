This is a test infrastructure patch from Patrick Steinhardt, part 7 of his 12-part series to enable `set -e` in Git's test suite when running under Bash 5+. The patch focuses on fixing the cleanup command handling in `test_when_finished()` and `test_atexit()` to work correctly under strict error checking.

The change modifies how test cleanup commands preserve the test's exit code when running cleanup handlers. The current implementation uses `&&` logic that would break under `set -e` when the test fails. The patch switches to using `||` logic instead, which maintains the same behavior while being compatible with strict error checking. The commit message includes clear truth tables showing the behavior before and after the change.

This continues the series' pattern of careful, mechanical changes to prepare the test suite for stricter error handling.
