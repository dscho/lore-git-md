Patrick Steinhardt’s RFC patch series (v4) to reorganize Git’s source tree by moving all `libgit.a` components into a new `lib/` directory continues to spark debate. The goal is to reduce root-directory clutter—shrinking the number of files from roughly 550 to 80—and enforce clearer boundaries for Git’s core library code, though the change remains purely mechanical with no functional or API modifications. The latest iteration includes Ramsay Jones’s Windows build fix and a preparatory include path adjustment, ensuring the build remains intact after the move. However, the core tension persists: whether the long-term benefits of a tidier codebase justify the short-term disruption to workflows, including broken `git log --follow` history, rebasing headaches for in-flight topics, and merge conflicts for downstream forks.

The series consists of two patches: the first adjusts an include path in `t/helper/test-example-tap.c`, and the second relocates about 700 files—spanning core subsystems like object handling, refs, diff, merge, and platform compatibility shims—into `lib/` while preserving their internal structure. Build system files, CI workflows, and `.gitmodules` are all updated to reflect the new paths. The discussion has narrowed to practical concerns, with critics like Junio C Hamano and Phillip Wood questioning the recurring mental overhead of remembering file moves (e.g., `wt-status.c` → `lib/wt-status.c`) and suggesting alternatives like documentation or tooling improvements. Kaartic Sivaraam’s proposal to add a hint in `git show` when a file appears renamed—suggesting the new path—remains a potential compromise, though its feasibility is untested.

Patrick has refined his rationale to emphasize root-directory decluttering and enforcing coding conventions (e.g., avoiding `the_repository` or `die()` in library code), but skepticism lingers about whether these benefits outweigh the friction. The timing of v4, sent close to the upcoming release, suggests Patrick aims to land this early in the next cycle if consensus emerges. For now, the series remains under active debate, with no clear resolution in sight.
