Patrick Steinhardt’s RFC patch series to reorganize Git’s source tree by moving `libgit.a` components into a new `lib/` directory is now complete with the arrival of the second and final patch in the v2 series. The goal remains reducing root directory clutter—shrinking the file count from roughly 550 to 80—while establishing a clear boundary for the library.

This latest patch is purely mechanical, relocating about 700 files (including core subsystems like object handling, refs, diff, and platform compatibility shims) into the new `lib/` directory while preserving their internal structure. The changes focus on build system updates—`Makefile`, `meson.build`, `CMakeLists.txt`, and platform-specific files—ensuring all configurations and CI workflows remain functional. Johannes Schindelin has already signaled preliminary approval for Git for Windows, and the series has been tested across GitLab and GitHub CI pipelines. All prior technical feedback, including adjustments for Meson, ODB sources, and fsmonitor paths, has been addressed.

The series is now ready for finalization, with transition timing likely slated for after Git v2.54.0. No functional changes or new symbols are introduced; this is strictly a structural reorganization. The only remaining steps involve coordinating with downstream forks to manage merge conflicts and rebase challenges, which Patrick has committed to assisting with. No substantive objections are expected, and the effort appears on track for smooth integration.
