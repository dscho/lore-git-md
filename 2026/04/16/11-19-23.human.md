This is part 6 of Patrick Steinhardt's 12-patch series to make Git's test suite compatible with `set -e` (errexit) when running under Bash 5+. The series systematically updates test infrastructure to handle stricter error checking, with each patch addressing specific patterns that would break under `set -e`.

This patch focuses on converting tests that execute potentially failing commands outside conditionals - a pattern that would cause immediate test termination under `set -e`. It updates 11 files containing tests that check for executable availability (like `svn`, `cvs`, and `git` itself) or handle expected failures. The changes are mechanical but important for reliability, replacing direct command execution with conditional checks that capture exit codes safely.

The patch continues the series' consistent approach: narrowly scoped changes that maintain existing behavior while improving robustness. It touches several test areas including CVS/SVN integration, HTTPD setup, and core test infrastructure. As with previous patches, Jeff King (Peff) has been the primary reviewer, and the changes appear well-vetted. This is solid incremental work in Git's ongoing test modernization effort.
