Test infrastructure patch from Patrick Steinhardt continuing his series to make Git's test suite compatible with `set -e`. This fifth patch in the 12-part series fixes conditional test execution patterns that would fail under stricter error checking.

The change converts `test ... && test_expect_success` patterns to proper `if` statements in two test files (t4032 and t7450). These patterns currently work but would cause the test script to fail under `set -e` when the condition is false, since the `&&` chain would evaluate to false. The new version maintains the same behavior while being `set -e`-safe.

The changes are mechanical but important for the test suite's reliability. Patrick's approach remains consistent with previous patches in the series - making targeted, backward-compatible changes to prepare for stricter error handling. The patch touches test cases dealing with diff hunk contexts and symlink handling, both areas where conditional test execution is used to skip tests when certain conditions aren't met.
