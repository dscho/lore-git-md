This is a MIDX (multi-pack-index) compatibility fix for the upcoming Git 2.54.0 release. The patch reverts the default MIDX version from v2 back to v1 to maintain backward compatibility with Git 2.53.0, addressing a regression where repositories touched by v2.54.0-rc2 became unusable with the stable release.

The change comes after Johannes Schindelin (Dscho) reported the compatibility issue, and Jeff King (Peff) analyzed the problem - older Git versions were failing hard when encountering unknown MIDX versions rather than gracefully falling back to pack files. The solution keeps v2 available via explicit configuration (`midx.version=2`) for users needing its features, while defaulting to v1 for stability.

The patch updates the MIDX writer to use v1 by default and adjusts tests that exercise v2-specific features (like compaction) to explicitly request v2. This demonstrates Git's conservative approach to file format changes, prioritizing stability while still allowing forward progress for users who need newer capabilities. The change has already been approved and applied by Junio Hamano as a critical fix for the 2.54.0 release.
