This is the test patch completing a bugfix series for HTTP authentication, specifically addressing Kerberos (SPNEGO) behavior with `http.emptyAuth=auto`. The series has already established that a conflict between two historical changes was causing Negotiate authentication to fail in auto mode.

The new tests verify the fixed behavior by:
1. Confirming `auto` mode now properly attempts Negotiate authentication first (resulting in three 401 responses before falling back to Basic auth when no Kerberos ticket exists)
2. Showing `false` mode still strips Negotiate immediately (only one 401 response) as expected

The test setup carefully controls the HTTP server responses and checks the authentication flow via curl traces and credential helper interactions. The tests are gated behind a `SPNEGO` prerequisite to skip when the test environment lacks Kerberos support.

This completes the series with comprehensive test coverage, matching the behavior described in the earlier patches. The tests are well-constructed, verifying both the happy path and edge cases while maintaining isolation between test cases. With this addition, the series appears ready for merging.
