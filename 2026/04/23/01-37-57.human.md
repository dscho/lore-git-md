This is the final patch in Jiamu Sun's series adding subcommand autocorrection to Git's parse-options API, now approved for merging. The implementation provides consistent autocorrection behavior between main commands and subcommands, using the same Damerau-Levenshtein distance algorithm and similarity thresholds.

Key aspects:
- Autocorrection is applied to mistyped mandatory subcommands (those without PARSE_OPT_SUBCOMMAND_OPTIONAL flag)
- The logic mirrors Git's existing command autocorrection, including the same similarity threshold (7) and user prompting behavior
- Core implementation moved to new autocorrect.{c,h} files for reuse
- Includes comprehensive test updates to verify the new behavior

The patch completes the series by:
1. Moving autocorrection constants to autocorrect.h for shared use
2. Implementing subcommand similarity matching in parse-options.c
3. Updating tests to expect the new autocorrection hints rather than direct errors
4. Maintaining consistent exit codes (129) for parse errors
