This is part of the ongoing `the_repository` removal effort, specifically migrating the `sparse_expect_files_outside_of_patterns` configuration variable from a global to repository-specific storage. The patch is the 7th in an 8-part series (v3) that's moving several configuration variables into `struct repo_config_values`.

The change moves the sparse-checkout-related configuration that controls whether Git expects files outside sparse patterns to exist. This was previously a global variable, risking cross-repository state leakage. The patch updates all references to use the new repository-specific storage location while maintaining the existing eager parsing behavior, which is important for consistent sparse-checkout handling.

The diff shows the typical pattern for these migrations: removing the global variable declaration, adding it to the repository config struct, updating the config parser, and modifying call sites. The changes are mechanical and well-contained, touching only 3 files with minimal line changes. This continues the incremental progress on eliminating global state while preserving existing behavior.

The patch has received positive feedback from mentors Christian Couder and Usman Akinyemi, suggesting it follows established patterns for this type of refactoring. It fits into the broader context of sparse-checkout/sparse-index work while being a straightforward technical change.
