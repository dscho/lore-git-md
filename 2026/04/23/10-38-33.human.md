This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing updates on the state of various Git development topics as of April 2026. The report categorizes patches into "New Topics" (recently added) and "Cooking" (ongoing work), indicating their readiness for merging.

Key highlights from this update include:

1. Several merge-ort backend improvements from Elijah Newren, including better handling of cached renames and corrupt trees.

2. A revert by Jeff King of a transport-helper change that caused regressions for mksh users.

3. GitHub Actions CI updates from Johannes Schindeler, bumping various action versions.

4. Multiple documentation fixes, including corrections to format.commitListFormat docs.

5. Significant work on the object database (ODB) abstraction by Patrick Steinhardt, adding an in-memory source for tentative objects.

6. Test suite improvements to make it work correctly with `set -e` enabled.

7. A new fsmonitor daemon implementation for Linux by Paul Tarjan.

8. Various `the_repository` removal efforts continuing across different subsystems.

The report also notes several topics that need review responses or are expecting rerolls, including Derrick Stolee's pseudo-merge bugfixes and Taylor Blau's incremental MIDX repacking work. Some controversial topics like Rustification (now enabled by default) and sideband sanitization are being monitored for feedback.

This status report is particularly useful for tracking the progress of larger efforts like the ODB abstraction and `the_repository` removal, while also highlighting smaller fixes and documentation improvements that are making their way through the pipeline.
