This is the final patch in Karthik Nayak's refactoring series to consolidate reference backend logic. The series has been through multiple iterations with thorough review from Patrick Steinhardt.

The patch modifies the packed and reftable backends to use the peeled tag values that are now provided by the generic refs layer (introduced in previous patches), rather than each backend performing its own peeling operation. This eliminates duplicate work and ensures consistent behavior across backends.

The changes are straightforward - the backends now check for the REF_HAVE_PEELED flag and use the pre-peeled value from the update struct when available. The packed-backend.c and reftable-backend.c changes follow the same pattern of removing their independent peeling logic in favor of the centralized version.

This completes the series' goal of moving object validation and peeling into the shared layer, which should make the backends simpler and more consistent. The patch appears clean and well-integrated with the prior work in the series.
