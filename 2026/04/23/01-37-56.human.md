This is a refactoring patch in Jiamu Sun's series adding subcommand autocorrection support to Git's parse-options API. The patch focuses on improving the config resolution implementation.

The key changes:
- Introduces a new `autocorrect_resolve()` API that provides a cleaner way to retrieve autocorrect configuration
- Makes the config callback internal rather than exposing it in the header
- Moves the config resolution logic from help.c` to the new `autocorrect.c` file
- Maintains the same behavior while improving code organization

This is part of the final polish for the series, which has already received maintainer approval. The changes help consolidate the autocorrection logic into dedicated files while keeping the API surface clean. The patch doesn't introduce new functionality but improves the implementation quality of the existing autocorrection feature.

The series as a whole provides consistent autocorrection behavior for both main commands and subcommands, with this patch specifically cleaning up the config handling portion of that work.
