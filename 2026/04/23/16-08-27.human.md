This is a documentation patch correcting an inaccurate description of `git am --message-id` behavior in the man page. The patch reverts a previous claim that the option adds a Git trailer (which would follow trailer block formatting rules), clarifying that it simply appends the Message-ID line after the commit message body without regard for trailer formatting.

The change is straightforward and uncontroversial, with sign-offs from both the original author (Kristoffer Haugsbakk) and maintainer Junio Hamano. The patch acknowledges this reveals an inconsistency in the command's handling of different message formats (working properly only for subject-only messages or those with existing trailers), but defers fixing that behavior to avoid last-minute changes in the release cycle.

This is a minor but precise correction to ensure documentation matches actual behavior, typical of Kristoffer's frequent documentation contributions. The patch is clearly merge-ready with no outstanding questions.
