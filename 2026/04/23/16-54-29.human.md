This is part of the ongoing `the_repository` removal effort, specifically migrating the `core.precomposeunicode` configuration from a global variable to repository-specific storage in `struct repo_config_values`. The patch focuses on macOS-specific Unicode path normalization behavior, which needs eager parsing since it affects fundamental filesystem operations.

The change converts the global `precomposed_unicode` variable to a repository-specific field while maintaining the same eager parsing semantics. This prevents cross-repository state leakage and continues the broader effort to eliminate global configuration state. The patch also changes the type from `int` to `bool` to better match its actual usage as a boolean value.

The modifications touch four files, with the bulk of changes in `compat/precompose_utf8.c` where the Unicode handling logic resides. The changes are mechanical but important for the long-term goal of making Git's configuration system more robust and repository-aware. This is the fifth patch in an eight-part series that has received positive technical reviews, though some documentation improvements were requested in earlier iterations.
