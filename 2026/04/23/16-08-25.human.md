This is a platform compatibility patch that reverts a previous attempt to introduce a `writev()` wrapper for Windows systems. The change removes the compatibility layer that was added to support the POSIX `writev()` system call on platforms that don't natively provide it.

The patch:
- Deletes the `compat/writev.c` implementation file
- Removes related Makefile and meson build system entries
- Strips out the `writev` declarations from `compat/posix.h`
- Updates platform-specific configuration to no longer mark Windows as needing the `writev` wrapper

Maintainer Junio Hamano provides the simple rationale: "let's not use writev() for now." The change appears uncontroversial as it's a straightforward removal of unused code that was previously added but is no longer needed. The patch is part of a larger series but stands alone as a clean-up of compatibility code.
