Documentation patch fixing AsciiDoc formatting issues in the Git glossary. This is a follow-up to Jeff King's earlier work on cleaning up glossary formatting, now addressing specific cases where nested lists were causing incorrect indentation in the rendered output.

The patch focuses on four problematic glossary entries ("glob", "attr", and two under "refs") where sub-lists were causing the subsequent text to indent incorrectly. The solution involves two different approaches depending on context: using empty lines before continuation markers ("+") for some cases, and explicit "--" block markers for others where the first technique didn't work consistently across AsciiDoc implementations.

Key technical details:
- Fixes rendering issues that made some definition paragraphs appear as if they belonged to sub-lists when they should have been at the parent level
- Maintains compatibility with both AsciiDoc and Asciidoctor processors
- Preserves all existing content while only adjusting the markup structure

The patch has already been signed off by both Jeff King (the original author of the glossary formatting work) and Junio Hamano, indicating it's ready for merging. This is a straightforward documentation improvement that doesn't affect any code behavior.
