This thread addresses a regression in Git 2.54.0 where hierarchical aliases (like `pull.sub`) stopped working after functioning correctly in 2.53.0. The issue was originally identified by Michael Grossfeld, with technical analysis from Jeff King and René Scharfe confirming the root cause - a change in alias handling that misinterpreted dotted names. Jonatan Holmgren, author of the original change that introduced the regression, has submitted a v1 fix that restores backward compatibility while preserving the new functionality. The patch includes comprehensive test coverage and has already received implicit technical approval from both King and Scharfe.

Kristoffer Haugsbakk noted a minor procedural oversight - the patch is missing the required Signed-off-by trailer - but this appears to be a simple submission formality rather than any substantive concern about the fix itself. With the technical approach validated and only this administrative detail remaining, the patch seems ready for merging once the signoff is added. The remaining open question is whether the fix will be backported to the 2.54.x maintenance series, which would help affected users sooner rather than waiting for the next feature release.
