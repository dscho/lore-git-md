This is a refactoring patch from Jiamu Sun's series adding subcommand autocorrection support to Git's parse-options API. The patch focuses on improving the autocorrect configuration handling by replacing magic numbers with a proper enum and struct.

The key changes in this patch:
- Introduces an `enum autocorrect_mode` to clearly represent the different autocorrection behaviors (prompt, never, immediate, show, delay)
- Defines a `struct autocorrect` to bundle the mode and delay values together
- Updates the configuration parsing logic to use these new types
- Modifies the confirmation logic to work with the structured config
- Maintains all existing behavior while making the code more type-safe and self-documenting

The changes are mechanical in nature - they don't alter functionality but make the code more maintainable by:
- Eliminating magic numbers
- Grouping related configuration values
- Making the different autocorrection modes explicit in the type system
- Keeping the same external behavior while improving internal structure

This is part of the final polish for the series, which has already received maintainer approval. The patch follows the established pattern of the series by focusing on clean abstractions and type safety while maintaining compatibility with existing autocorrection behavior.
