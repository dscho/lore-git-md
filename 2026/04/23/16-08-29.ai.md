This is a CI/build system patch that updates a GitHub Actions workflow to use actions/checkout v5 instead of v4. The change fixes an inconsistency where the rust-analysis job was the only one still using the older version, which was causing Node.js 20 compatibility warnings.

The patch explains this was caused by a near-simultaneous merge conflict between two changes in October 2025 - one adding a new job with v4 and another updating all existing jobs to v5. Junio Hamano (the maintainer) noticed the discrepancy and submitted this straightforward update to align the rust-analysis job with the rest of the CI configuration.

This is a minor but sensible housekeeping change that maintains consistency across the CI setup. As it comes directly from the maintainer with a clear explanation of the context, it's likely to be merged without further discussion. The patch is part of a larger series but stands alone as a simple version bump.
