This is a documentation patch fixing indentation issues in the Git glossary's AsciiDoc formatting. The patch addresses a subtle problem where nested lists (bulleted items within definition lists) were causing incorrect indentation in the rendered output.

The core issue involves how AsciiDoc handles continuation markers ("+") when definition lists contain sub-lists. The patch provides a detailed technical explanation of the problem and demonstrates two different workarounds that produce consistent output across both AsciiDoc and Asciidoctor processors:

1. For the "glob" and "attr" entries, it adds an extra blank line before the continuation marker to properly scope the continuation
2. For the "refs" entry, it uses "--" open-block markers since the blank line technique didn't work consistently there

The patch comes from Jeff King (Peff) and has already been signed off by Junio Hamano, indicating it's ready for merging. This is a documentation-only change that doesn't affect Git's behavior, just the formatting of the rendered man pages. The fix demonstrates careful attention to the nuances of AsciiDoc processing and maintains compatibility with both major AsciiDoc implementations.
