This is Junio C Hamano's regular "What's cooking in git.git" status report, providing updates on the current state of the Git development tree as of April 2026. These reports are essential for tracking the progress of patches through Git's integration branches.

The report covers several topics that have recently graduated to 'master' (stable) and 'next' (candidate for next release), along with many new and ongoing topics still under review. Notable highlights include:

Several patches continue the ongoing effort to remove reliance on `the_repository` global variable, with updates to fsck, unpack-trees, and setup code. The fast-import command gained more configurable handling of signed commits and tags, while line-log output was improved to work with standard diff options like -S/G.

A regression fix addresses broken object hash computation outside repositories since Git 2.52. The commit-graph writer was fixed to properly handle commits with dates beyond year 2514. There's also work on improving portability of the reftable library and various documentation updates.

New topics in progress include Rust being enabled by default (but still optional) in Git 2.54, parallel hook execution support, Linux fsmonitor daemon implementation, and improvements to MIDX repacking strategies. The report also notes several documentation standardization efforts and test cleanups.

As always, Junio provides clear indicators of each topic's status - which integration branch it's in, whether it's awaiting review responses or rerolls, and when it might merge to 'next' or 'master'. The report serves as both a progress update and a call for review on the many patches still in flight.
