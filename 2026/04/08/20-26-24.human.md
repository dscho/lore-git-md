This is part 2 of a 6-part refactoring series for the xdiff subsystem, focusing on type safety improvements. The patch changes `xdl_bogosqrt()` to use `uint64_t` instead of `long` for its calculations, since negative numbers don't have real square roots and `size_t` may not be large enough for some cases. The change is straightforward - updating the function signature and call sites with appropriate casts where needed.

The patch touches several xdiff files but makes no functional changes - it's purely a type safety refactoring. This is part of a larger effort that had a regression in v4 which has now been fixed in v5 by reverting the problematic changes while keeping the type improvements like this one. The series has been reviewed and approved by key contributors including Phillip Wood and Junio C Hamano.
