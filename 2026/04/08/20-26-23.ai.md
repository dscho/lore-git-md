This is the first patch in a refactoring series targeting the xdiff subsystem's record cleanup logic. The patch simplifies the code in `xdl_cleanup_records()` by removing a redundant `recs` pointer variable and directly indexing the `xdfile.recs` array instead. The change affects four loops in xdiff/xprepare.c, though the pointer was only used in the first two.

The modification is straightforward: it replaces pointer arithmetic with direct array indexing, which improves clarity by making the data flow more explicit. The patch also introduces local variables (`mph1` and `mph2`) to store the minimal perfect hash values, making the code slightly more readable. This change was carried forward from the previous version (v4) of the series after being reviewed and found to be safe.

The patch touches only xdiff/xprepare.c and is purely a code cleanup with no behavior changes. It's part of a larger effort to improve type safety and clarity in the xdiff subsystem, following up on earlier work by Phillip Wood. The regression that appeared in v4 series (related to INVESTIGATE handling) does not affect this particular change.
