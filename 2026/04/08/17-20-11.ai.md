This is a release announcement for Git v2.54.0-rc1 from maintainer Junio C Hamano. The release candidate includes 691 non-merge commits from 123 contributors, with 62 new contributors joining the project. Key highlights include:

The release introduces several new features and improvements. A new experimental `git history` command has been added for history rewriting, while `git replay` gains the ability to drop commits that become empty. The `--expire` option for worktree commands has improved documentation, and `git show-index` now warns when defaulting to SHA-1 outside a repository. Configuration handling sees multiple enhancements, including better support for non-ASCII alias names and per-hook configuration.

Performance and internal improvements are significant in this release. The maintenance command now uses geometric repacking by default, and there's ongoing work to reduce reliance on `the_repository` global variable across multiple subsystems. The object database (ODB) API is being restructured to support pluggable backends, and Rust code is being introduced for object name handling. The release also includes various optimizations for the pack subsystem and MIDX/bitmap handling.

Numerous fixes address issues across the codebase. HTTP transport authentication has been corrected, diff-stat column width computation now handles non-ASCII characters properly, and several memory leaks have been plugged. The release also includes documentation updates, test improvements, and platform-specific fixes for Windows and macOS.

The announcement follows Git's standard release process, with tarballs available for testing and the code tagged in multiple public repositories. Junio notes the significant contribution from both new and returning developers, highlighting the project's continued growth and community involvement.
