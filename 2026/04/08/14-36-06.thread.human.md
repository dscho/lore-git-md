Derrick Stolee's series introducing bidirectional negotiation controls for Git object transfer is now ready for merging after receiving final review approval. The eight-patch series adds `--negotiation-include` to guarantee certain refs are always advertised during object transfer and `--negotiation-restrict` (formerly `--negotiation-tip`) to limit negotiation scope, addressing costly full-history transfers in monorepos when long-lived branches are dropped.

Matthew Cheetham provided thorough review throughout the series' development, with all patches now carrying his Reviewed-by tag using the corrected email address (mjcheetham@outlook.com). The implementation includes comprehensive test coverage, config support for both remote.*.negotiationInclude and remote.*.negotiationRestrict, and full push/pull integration. With all technical feedback addressed across multiple iterations, the series awaits only Junio Hamano's final review before merging. The changes build on existing negotiation infrastructure while introducing a clean `have_sent()` callback interface to track included objects without disrupting optimization logic.
