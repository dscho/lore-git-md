This is a test adjustment patch in the ongoing fsmonitor series, specifically addressing split-index compatibility issues in the scalar clone tests. Paul Tarjan follows up on Junio Hamano's confirmation that the split-index setting was indeed breaking t9211 tests, just as it had with t9210.

The patch simply extends the same workaround from t9210 to t9211 - unsetting GIT_TEST_SPLIT_INDEX at the start of each test. This maintains consistency across both test files while the underlying split-index/fsmonitor interaction issue remains unresolved. Paul verifies the fix works on Fedora with GIT_TEST_SPLIT_INDEX=yes.
