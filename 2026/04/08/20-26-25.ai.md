This is the third patch in a refactoring series targeting the xdiff subsystem's record cleanup logic. The patch focuses on type safety by converting several `long` variables to `ptrdiff_t` in `xdl_clean_mmatch()` and `xdl_cleanup_records()` functions. 

The changes are straightforward and mechanical:
- Parameters `i`, `s`, `e` in `xdl_clean_mmatch()` are changed from `long` to `ptrdiff_t`
- Local variables `r`, `rdis0`, `rpdis0`, `rdis1`, `rpdis1` in the same function also become `ptrdiff_t`
- Variables `i`, `nm`, `mlim` in `xdl_cleanup_records()` are similarly converted

This continues the series' theme of using more precise types for array indexing and pointer arithmetic operations. The patch appears uncontroversial - it's a simple type change that doesn't affect behavior, just makes the code more correct by using the appropriate for pointer differences. The changes align with the series' goal of improving type safety while maintaining all existing functionality.

This patch builds on previous work in the series that removed redundant pointer variables and improved code clarity. It's part of the v5 iteration that resolved a regression from v4 while preserving all the safe improvements. The changes touch only xdiff/xprepare.c and are purely internal to the diff machinery.
