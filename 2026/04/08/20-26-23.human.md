This is the first patch in a refactoring series for Git's xdiff subsystem, specifically targeting the `xdl_cleanup_records()` function. The patch simplifies the code by removing a redundant `recs` pointer variable and directly indexing the `xdfile.recs` array instead. 

The changes are purely internal - no behavior is modified. The patch:
1. Eliminates the `recs` pointer which was previously incremented in loops
2. Replaces pointer dereferencing with direct array indexing
3. Maintains all existing logic while making the code slightly more straightforward

This is part of a larger effort (v5 of the series) that follows up on a regression found in v4. The series has been reviewed by Phillip Wood and maintains Junio C Hamano's approval for the non-regressing parts. The changes touch xdiff/xprepare.c, which handles diff record preparation.

The patch appears clean and focused - a straightforward simplification that doesn't introduce new complexity. Since it's part of a series that has already gone through multiple rounds of review (including regression detection and fixing), it seems likely to be in good shape for merging.
