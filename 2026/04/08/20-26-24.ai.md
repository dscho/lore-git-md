This is part 2 of a 6-patch refactoring series targeting the xdiff subsystem, specifically focusing on type safety improvements. The patch changes the `xdl_bogosqrt()` function to use `uint64_t` instead of `long` for its parameters and return value, since square roots of negative numbers are undefined and some callers may need the extra range.

The change is straightforward but touches multiple files in the xdiff directory to update both the function declaration and its call sites. The key technical aspects are:
- Function signature change in xutils.h
- Implementation update in xutils.c
- Call site adjustments in xdiffi.c and xprepare.c with explicit casts where needed

This is a pure refactoring with no behavior change - the function still implements the same integer square root approximation algorithm, just with more appropriate types. The patch maintains all existing functionality while improving type safety, particularly for large inputs where `long` might be too small.

The change is part of a larger effort to improve xdiff's type safety that has gone through multiple iterations (now at v5) with careful attention to avoiding regressions. This particular patch appears uncontroversial and well-contained.
