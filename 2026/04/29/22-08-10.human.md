This is the first patch in a refactoring series targeting Git's xdiff subsystem (the diff engine). The patch simplifies the code in `xdl_cleanup_records()` by removing an unused local pointer variable (`recs`) and directly accessing the `xdfile.recs` array instead. 

The changes are purely internal and don't affect behavior:
- The first two loops now index directly into `xdf1->recs` and `xdf2->recs` rather than using the `recs` pointer
- The last two loops (which didn't use `recs`) are simplified by removing the unused pointer increment
- The minimal perfect hash value is now stored in a local variable for clarity

This is a straightforward cleanup that makes the code slightly more readable while maintaining all existing functionality. The patch is part of a larger effort to improve type safety and clarity in xdiff, with this particular change being uncontroversial and mechanical in nature. The series has already gone through several rounds of review and appears ready for merging.
