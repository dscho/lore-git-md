This is a follow-up patch in Taylor Blau's incremental MIDX repacking series, addressing Jeff King's (Peff) review feedback on process handling safety.

The patch makes two key changes to address Peff's substantive technical concerns:

1. Replaces the custom pipe handling with `pipe_command()` to eliminate any theoretical deadlock risk between parent and child processes. The new implementation is both safer and more readable.

2. Fixes a resource leak in the error path by properly cleaning up the child process before jumping to the error handler, as Peff identified. This ensures no processes or file descriptors are left dangling if an error occurs.

These changes complete the technical review cycle for this patch, with both Peff (process safety) and Elijah Newren (geometric repacking strategy) having signed off on their respective areas of expertise. The series now appears ready for integration, representing the final component of the large-repository repacking effort.
