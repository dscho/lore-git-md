2. Added explicit handling for each action type (KEEP, DISCARD) with clear code paths
3. Introduced a BUG() check for illegal action states as a defensive programming measure
4. Applied the same restructuring to both file processing loops (xdf1 and xdf2) for consistency

The patch maintains all the type safety improvements from previous versions and fully preserves the existing behavior.
