This is a refactoring patch (9/16) in Taylor Blau's series on incremental MIDX/bitmap-based repacking. The patch extracts common MIDX command preparation logic into a new helper function `repack_prepare_midx_command()` to avoid duplication as the series adds more MIDX operations.

The change moves the shared setup for `git multi-pack-index` commands - setting git_cmd, pushing the subcommand/verb, and handling progress/bitmap flags - into a reusable function. Callers remain responsible for subcommand-specific arguments like `--stdin-packs` for the write operation. The patch maintains existing behavior while making the code more maintainable as the series introduces additional MIDX operations in subsequent patches.

This continues the series' pattern of careful, incremental refactoring to support the larger architectural goal of geometric MIDX chain repacking. The change is well-contained and clearly motivated by upcoming needs in the series.
