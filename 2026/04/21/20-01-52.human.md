This is an updated version of Taylor Blau's bugfix series addressing issues in Git's pseudo-merge bitmap implementation. The series has grown from 5 to 9 patches since the previous version, incorporating feedback and fixing additional problems.

The key changes in this revision include:
- Fixed a use-after-realloc bug in the test helper
- Swapped initialization order in test scripts to prevent cleanup issues
- Updated documentation to clarify the valid range for sampleRate (now must be >0 and ≤1)
- Added a new commit fixing incorrect sampleRate examples in gitpacking documentation
- Resolved an API type mismatch by passing 0 instead of false to match the unsigned parameter type

The series continues to address the core issues originally identified:
- Incorrect sorting of pseudo-merge commit tables
- Swapped binary search implementation
- Multiple bugs in extended lookup paths
- Date parsing issues in group selection
- Division-by-zero risk in config validation

Taylor has incorporated feedback from multiple reviewers including Junio C Hamano and Elijah Newren, demonstrating careful attention to both implementation correctness and test safety. The changes appear well-considered and focused on making the pseudo-merge bitmap feature more robust. This remains an important performance optimization for large repositories.
