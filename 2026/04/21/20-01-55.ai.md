This is the first patch in Taylor Blau's v2 series fixing bugs in pseudo-merge bitmaps, a performance optimization feature. The patch introduces a new `test-tool bitmap write` subcommand to enable precise testing of bitmap generation.

The new test tool allows writing bitmaps for specific commits in a controlled way, reading commit OIDs from stdin. This addresses the testing gap identified in the parent commit where `apply_pseudo_merges_for_commit()` wasn't being exercised. The implementation handles both regular commit bitmaps and pseudo-merge bitmaps (respecting the `bitmapPseudoMerge.*` config).

Key technical details:
- Adds a new `bitmap_write()` function to test-bitmap.c that:
  - Finds the specified packfile
  - Builds a packing data structure
  - Processes stdin to get commits that should get bitmaps
  - Generates and writes the bitmap file
- Includes a test case verifying the tool can selectively bitmap commits
- Uses proper memory management with cleanup handlers
- Maintains compatibility with existing bitmap infrastructure

The patch is well-structured with clear commit message explaining the motivation and implementation. It provides the foundation for the subsequent bugfix patches in the series by enabling targeted testing of bitmap behavior. The test case demonstrates both the basic functionality and verifies the bitmap selection works as expected.
