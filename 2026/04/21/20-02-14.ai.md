This is the 7th patch in Taylor Blau's v2 series fixing bugs in the pseudo-merge bitmap implementation. The patch addresses a division-by-zero issue that occurs when the `bitmapPseudoMerge.*.sampleRate` configuration is set to 0.

The key changes in this patch:
- Updates config validation to reject sampleRate=0 (previously allowed but caused undefined behavior)
- Fixes documentation to clarify the valid range is now 0 < sampleRate ≤ 1
- Converts a previously failing test case (`sampleRate=0`) to expect success
- Adds more descriptive warning message when invalid values are provided

The issue became exposed after the previous patch (6/9) fixed commit date parsing, which allowed the unstable commit path (where sampleRate is used) to be properly exercised. The patch shows careful attention to both the technical fix and documentation updates, maintaining consistency with the series' thorough approach to addressing pseudo-merge bitmap issues.
