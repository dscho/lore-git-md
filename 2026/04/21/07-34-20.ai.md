This is patch 7/12 in Patrick Steinhardt's v6 series to make Git's test suite compatible with `set -e` (errexit). The series is now complete and ready for merging after thorough review feedback.

The patch focuses on the test cleanup handlers `test_when_finished()` and `test_atexit()`, which build chains of commands to run after test execution. The current implementation uses `&&` logic that would break under `set -e` when the test fails (non-zero `eval_ret`). The change replaces this with `||` logic that properly preserves the test's exit code while remaining `set -e` safe.

The key technical insight is that the new `|| eval_ret=$?` pattern maintains the same behavior as before - it updates `eval_ret` only when the cleanup fails, otherwise preserving the original test result. This is demonstrated through the comprehensive truth tables included in the commit message, showing identical behavior across all combinations of test/cleanup success/failure.

This is a mechanical but important change that enables the broader `set -e` adoption by ensuring test cleanup handlers work correctly under strict error checking. The patch follows the established pattern of the series - careful, focused changes that maintain existing behavior while enabling the new error-handling regime.
