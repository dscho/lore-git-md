This is a bugfix patch in Taylor Blau's series addressing issues in pseudo-merge bitmaps, specifically targeting a division-by-zero vulnerability. The patch is part of a larger effort to stabilize this performance optimization feature.

The patch fixes a critical issue where setting the `sampleRate` configuration to 0 could trigger undefined behavior by causing a division by zero. This was previously masked by another bug that incorrectly classified all commits as stable. Now that the date classification is fixed (in patch 6), this edge case becomes reachable.

Key changes in this patch:
1. Updates documentation to clarify that `sampleRate` must be greater than 0 (previously allowed 0)
2. Modifies config validation to reject 0 values with a more precise warning message
3. Converts a failing test case (`test_expect_failure`) into a success case now that the issue is fixed

The fix is straightforward and well-contained, with clear documentation updates and test coverage. This continues the series' pattern of thorough attention to edge cases in the pseudo-merge bitmap implementation. The patch shows good responsiveness to the issues identified in earlier review rounds.
