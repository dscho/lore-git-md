This is the final patch in Johannes Schindelin's 4-part CI/build system series updating GitHub Actions dependencies. The patch bumps `actions/checkout` from v5 to v6 across all workflow files.

The key change in v6 moves credential storage from `.git/config` to `$RUNNER_TEMP`, improving security by preventing accidental token leakage. Schindelin's analysis confirms this change is safe for Git's CI - the workflows either check out the default repo (no special credentials) or explicitly specify a vcpkg repository path, neither of which rely on the credential storage location.
