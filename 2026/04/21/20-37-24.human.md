This is a refactoring patch in Taylor Blau's ongoing MIDX/bitmap-based repacking series, which aims to improve Git's scalability for large repositories. The patch converts the `keep_hashes` array in the MIDX writing code from a hand-rolled array to Git's `strvec` data structure.

The change simplifies memory management by using `strvec`'s built-in allocation and cleanup rather than manual `CALLOC_ARRAY` and free operations. It also makes the code more maintainable by using standard Git container APIs instead of custom array handling. The patch preserves the existing behavior while reducing the risk of memory leaks and simplifying the cleanup path.

This is part of a larger effort to improve MIDX chain handling for incremental repacking. The change is mechanical but demonstrates careful attention to code quality in performance-sensitive areas of the MIDX infrastructure. The patch follows naturally from previous refactors in the series and helps prepare for future work with more robust data structures.
