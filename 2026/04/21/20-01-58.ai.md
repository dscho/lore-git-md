This is the second patch in Taylor Blau's 9-part series fixing bugs in the pseudo-merge bitmap implementation. The patch adds comprehensive test coverage that demonstrates several known issues in the current implementation.

The test file `t5333-pseudo-merge-bitmaps.sh` gains five new test cases, four marked as expected failures (`test_expect_failure`) and one passing test (`test_expect_success`). The tests cover:

1. Basic pseudo-merge application during bitmap traversal
2. Handling of multiple pseudo-merge groups
3. Overlapping pseudo-merge group patterns
4. Correct date-based classification of commits
5. A latent division-by-zero bug when sampleRate=0 (currently passing but will fail when underlying bugs are fixed)

The tests use the new `test-tool bitmap write` helper from patch 1 to generate controlled bitmap scenarios. They verify both bitmap correctness (via `git rev-list` comparisons) and internal behavior (via trace2 event counting). The test cases are carefully constructed to isolate specific code paths in the pseudo-merge implementation.

Notably, the "sampleRate=0" test is currently passing but will start failing when subsequent patches fix the masking bugs - demonstrating the thoroughness of the test coverage. Elijah Newren has already reviewed and confirmed the test structure and shell syntax are correct.

This patch provides the test infrastructure needed to verify the fixes in the remaining patches of the series, showing Taylor's methodical approach to addressing the bitmap issues.
