This is part 5 of Patrick Steinhardt's 12-patch series to make Git's test suite compatible with `set -e` (errexit). The series is now in its sixth iteration and ready for merging.

The patch converts conditional test execution patterns from using `&&` chains to proper `if` statements. This prepares the tests for `set -e` by ensuring skipped tests don't cause the overall statement to fail. The changes affect two test files:

1. `t4032-diff-inter-hunk-context.sh` - Converts a test that checks diff output only when an expected output file exists
2. `t7450-bad-git-dotfiles.sh` - Updates tests for symlink handling to properly condition execution based on the `$refuse_index` variable

The changes are mechanical but important for the overall goal of making the test suite reliably fail on errors. This patch follows the established pattern seen throughout the series of methodically updating test patterns to work safely with `set -e`. All technical questions about the approach were resolved in earlier iterations, and this final version incorporates all feedback.
