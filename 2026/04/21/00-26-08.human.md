This is the second patch in Elijah Newren's series fixing merge-ort issues with duplicate tree entries and D/F conflict detection. The patch removes an unnecessary `show_all_errors` flag from `collect_merge_info()` that was originally copied from unpack-trees.c but serves no purpose in merge-ort.

The change is a straightforward cleanup - the flag controlled error message batching in unpack-trees, but merge-ort has no such batching logic. More importantly, removing it enables proper early termination when tree traversal encounters errors, which will be used by subsequent patches to abort processing when corrupt trees are detected.

As with the rest of the series, this comes from Git's merge subsystem expert and appears well-justified. The change is small and focused, removing dead code while enabling future error handling improvements. It maintains the series' pattern of careful, incremental changes to sensitive merge machinery.
