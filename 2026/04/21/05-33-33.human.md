This is the second patch in Siddharth Shrimali's v2 series modernizing tests in t7004-tag.sh. The patch focuses on making tag listing and deletion tests more robust by removing hardcoded assumptions about repository state.

The key change replaces static expectations of which tags should exist with dynamic checks that capture the actual state before operations and verify it remains unchanged afterward. This addresses a fragility where tests would break if other tests in the file were modified or reordered, since they relied on specific tags existing globally.

The patch simplifies the test logic by:
1. Using `git tag -l >expect` to capture the current tag state rather than hardcoding expected tags
2. Verifying tag listing behavior by comparing against this dynamic state
3. Confirming tag deletion with no arguments is a no-op by checking the state remains identical

Junio Hamano had already approved this approach in the v1 review with an "Excellent" comment, and the changes align with Patrick Steinhardt's emphasis on thorough state verification. The implementation is clean - just 2 lines replacing 9, while making the tests more isolated and reliable. This continues the series' pattern of surgical improvements to test robustness.
