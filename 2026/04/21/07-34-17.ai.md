This is a test infrastructure patch from Patrick Steinhardt, part of his v6 series to make Git's test suite compatible with `set -e` (errexit). The series is now complete and ready for merging after thorough review iterations.

This specific patch (4/12) addresses calls to `git config --unset` that could fail when the configuration variables being unset don't exist. These calls were previously harmless since the test suite didn't use `set -e`, but now need to be made robust by adding `|| :` to suppress errors when the unset operation fails. The changes affect three test scripts:

1. `t4032-diff-inter-hunk-context.sh` - unsetting diff.interHunkContext
2. `t7508-status.sh` - unsetting color.status and color.ui
3. `t9138-git-svn-authors-prog.sh` - unsetting svn.authorsfile and svn.authorsprog

The modifications are mechanical and straightforward, simply adding error suppression where needed. This is part of the broader effort to enable `set -e` by default in Bash 5+ while maintaining compatibility with other shells via the `GIT_TEST_USE_SET_E` option. The series has been extensively reviewed and tested, with all technical questions resolved in previous iterations.
