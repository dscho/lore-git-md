This is a refactoring patch in Taylor Blau's ongoing MIDX/bitmap-based repacking series, which aims to improve Git's scalability for large repositories. The patch converts the `keep_hashes` array in `write_midx_internal()` from a hand-rolled array to a `strvec`, following similar changes made in previous patches of the series.

The change simplifies the code by:
1. Replacing manual memory management with `strvec`'s built-in allocation
2. Eliminating the need to pre-count and allocate space for the hashes
3. Providing cleaner cleanup via `strvec_clear()`

The patch maintains the same behavior while improving maintainability, particularly around the ordering of hashes which is critical for the MIDX chain file format. This is part of the broader effort to make the MIDX infrastructure more robust as it gains new features like geometric repacking and incremental updates.

The changes are mechanical and well-contained, touching only the MIDX writing and cleanup code paths. The patch follows the series' pattern of gradually modernizing data structures while preserving the architectural improvements to repacking performance.
