This is the fifth patch in Taylor Blau's v2 series fixing bugs in the pseudo-merge bitmap implementation. The patch addresses three distinct issues in the extended lookup path for commits that appear in multiple pseudo-merge groups:

1. A write-side miscalculation where the extended table offset was undercounted by 4 bytes (12 vs 8 bytes per entry), causing the extended table to be written in the wrong location.

2. A read-side bug where bitmap offsets were incorrectly interpreted as commit table entries, corrupting the merge offset value. The fix stores the offset directly rather than re-parsing.

3. A latent error-checking issue where the wrong comparison was used to detect failures, which could silently ignore corruption in the bitmap file.

The patch includes a test case that previously failed (due to these bugs) but now passes, demonstrating the fixes work for commits that appear in overlapping pseudo-merge groups. The changes are focused and well-explained, with clear separation between the three independent fixes. This continues the series' pattern of thorough bugfixes with corresponding test coverage improvements.
