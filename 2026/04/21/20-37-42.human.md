This is a refactoring patch in Taylor Blau's ongoing series to improve Git's MIDX/bitmap-based repacking strategy for large repositories. It's patch 10/16 in the second iteration of the series.

The patch extracts the pack-writing logic from `write_midx_included_packs()` into a new helper function `repack_fill_midx_stdin_packs()`. This helper handles the complete lifecycle of writing pack names to stdin when running `git multi-pack-index write` as a child process, including argument setup, command execution, and cleanup.

The change is purely structural - no behavior is modified. The refactoring prepares for a future change where the same helper will be reused to capture MIDX checksums from stdout when writing MIDX layers with `--checksum-only`. The patch follows the series' pattern of careful, incremental refactoring to improve code organization while maintaining functionality.

This continues Taylor's multi-year effort to optimize Git's scalability for large repositories by introducing more sophisticated repacking strategies. The series has already addressed several rounds of technical feedback from reviewers like Jeff King and Elijah Newren.
