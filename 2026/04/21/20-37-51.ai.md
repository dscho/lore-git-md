This is a bugfix patch in Taylor Blau's ongoing MIDX/bitmap-based repacking series (13/16). The patch addresses a memory leak in the packfile revindex handling that was discovered while implementing MIDX bitmap writing over packs without on-disk revindex files.

The issue occurs when Git falls back to generating a revindex in memory (when no on-disk *.rev file exists) - this memory was never being freed. The fix adds proper cleanup in `close_pack_revindex()` by freeing the in-memory revindex data when closing the pack. This prepares for a subsequent commit that will introduce test coverage for this case.

The change is small (just 2 lines added) but important for correctness, particularly as part of the larger repacking infrastructure work. The patch follows the established pattern in this series of identifying and fixing edge cases that emerge when working with the new MIDX/bitmap repacking strategy. It's a straightforward fix that maintains the series' high standard of attention to memory management details.
