This is a test infrastructure change from Patrick Steinhardt, part of his v6 series to make Git's test suite compatible with `set -e` (errexit). The patch specifically addresses signal-handling tests that expect Git commands to die with specific signals (like SIGPIPE).

The change modifies three test cases that use `test_match_signal()` to verify exit codes from commands expected to fail. The original pattern of `command; echo $?` would cause the subshell to fail under `set -e` when the command fails. The new pattern `command && echo 0 || echo $?` maintains the same test semantics while being `set -e` safe.

This is a mechanical but necessary adaptation as part of the larger effort to enable stricter error checking in the test suite. The changes are straightforward and focused on test reliability, with all prior review feedback already incorporated in this final version of the series.
