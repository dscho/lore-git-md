This is a feature patch in Taylor Blau's ongoing series to improve Git's MIDX (multi-pack-index) repacking strategy for large repositories. The patch introduces a new `--base` option for both `write` and `compact` subcommands of `git multi-pack-index`, allowing callers to specify which existing MIDX layer should serve as the base for new incremental writes.

The key additions are:
- A `--base=<checksum>` option that accepts either a valid MIDX layer checksum or "none" to create a root layer
- Safety checks ensuring `--base` is only used with `--no-write-chain-file` for writes (to maintain chain invariants)
- Comprehensive test coverage including edge cases like invalid base checksums
- Documentation updates explaining the new option's behavior and restrictions

This builds on previous patches in the series that refactored MIDX internals and introduced atomic chain updates. The new flexibility will be used by the incremental repacking machinery to replace bottommost layers of the MIDX chain when needed. The implementation shows careful attention to edge cases and maintains the series' focus on large-repository scalability.
