This is a CI/build system patch updating the `microsoft/setup-msbuild` GitHub Action from v2 to v3 in Git's main workflow file. The change is part of a 4-patch series from Johannes Schindelin that updates various GitHub Actions dependencies.

The patch explains this is a proactive update to maintain compatibility as GitHub phases out Node.js 20 support from their runners. The v3 action runs on Node.js 24 instead, with no functional changes to the MSBuild setup itself - it still just adds `msbuild.exe` to PATH. The commit message provides detailed rationale and links to the release notes and diff showing the minimal changes between versions.

This appears to be a straightforward maintenance update with minimal risk, as the action's behavior remains identical and the only requirement (a recent Actions Runner) is already met by GitHub's hosted runners. The patch originated from a Dependabot update but has been properly reviewed and documented by Schindelin.
