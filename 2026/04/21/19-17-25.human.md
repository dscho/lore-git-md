Build system fix targeting older Ninja versions. This patch addresses a build failure on AlmaLinux 8 (which ships with Ninja 1.8.2) where the `config-list.h.d` dependency file format triggers a cyclic dependency error. The issue stems from a bug in pre-1.10.0 Ninja versions that mishandles multi-line depfiles.

Toon Claes proposes modifying the `generate-configlist.sh` script to optionally collapse dependencies onto a single line when building with older Ninja versions. The Meson build system now detects the Ninja version and passes a "collapse" flag when needed. The change maintains compatibility with both newer Ninja versions and the traditional Makefile build system.

The patch appears well-motivated with a clear reproduction case and links to the upstream Ninja fix. The solution is backward-compatible and doesn't affect builds using modern tooling. This is a practical fix for users stuck on older distros while keeping the build system working smoothly across environments.
