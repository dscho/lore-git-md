This is a bugfix patch in Taylor Blau's ongoing MIDX/bitmap-based repacking series (13/16). It addresses a memory leak in the packfile revindex handling code.

The patch fixes a case where Git generates an in-memory revindex (used for packfile reverse indexing) when working with packs that lack on-disk *.rev files, but fails to free that memory. The issue was discovered while testing the larger MIDX bitmap series, where this leak became visible under the test suite's memory checking.

The change is straightforward - it properly frees the `p->revindex` field in `close_pack_revindex()` using Git's `FREE_AND_NULL()` macro. This is a clear case of fixing a long-standing oversight (the code predates Git's current leak checking infrastructure) that was uncovered by new test coverage in the series.

As part of Taylor's larger repacking effort, this is one of those small but important plumbing fixes that ensures proper resource management in edge cases. The patch follows the series' pattern of careful attention to memory handling and test coverage.
