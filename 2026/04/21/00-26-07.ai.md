This is the first patch in Elijah Newren's series addressing merge-ort issues with duplicate tree entries and D/F conflicts. The patch fixes error propagation in traverse_trees_wrapper(), ensuring callback errors during tree traversal are properly reported rather than silently ignored.

The change makes traverse_trees_wrapper() capture and propagate the return value from the collect_merge_info_callback function. Previously, errors during the replay of cached tree entries would be discarded, potentially allowing merges to proceed with corrupt state. The fix ensures negative (error) returns stop processing and propagate up, while normalizing successful positive returns to 0 for the caller.

This is a preparatory cleanup that enables the groundwork for later patches in the series to properly handle malformed trees. The change is focused on merge-ort.c's internal tree traversal machinery and maintains the same behavior for valid cases while adding proper error handling for corrupt ones. As with the rest of the series, this comes from the recognized merge subsystem expert and appears carefully constructed.
