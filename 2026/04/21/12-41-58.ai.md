This is the third patch in a 4-part CI/build system series updating GitHub Actions dependencies. Johannes Schindelin bumps `actions/github-script` from v8 to v9 in the main CI workflow file.

The patch focuses on a specific optimization step that checks whether an identical tree-SHA was already tested successfully. The commit message provides a thorough risk analysis of the version change, noting three key aspects of v9: an HTTP user-agent string change (transparent to Git), a new `getOctokit` factory (unused here), and two breaking changes that don't affect Git's usage pattern. 

The script is marked as advisory" - if it fails, CI would still run normally but without the optimization. The change is mechanical (just a version bump) with no functional modifications to the workflow logic. Like the rest of the series, this originated from Dependabot but has been carefully reviewed by Schindelin, who added the detailed analysis of why the update is safe.
