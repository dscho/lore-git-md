This is the final version of Patrick Steinhardt's test infrastructure series to make Git's test suite compatible with `set -e` (errexit), now ready for merging. The series has gone through six iterations with thorough review from multiple contributors, including Jeff King, Junio Hamano, and others.

The key changes in v6 are minimal - just dropping one defensive change in t1410 that was only needed for broken shells, as confirmed by Jeff King's review. The series now:

1. Makes `set -e` the default for Bash 5+ while allowing opt-in via `GIT_TEST_USE_SET_E` for other shells
2. Has CI-tested adaptations across the test suite to handle strict error checking
3. Includes careful fixes for shell arithmetic, test cleanup handlers, and conditional execution patterns
4. Maintains compatibility with all supported shells and platforms

The work significantly improves test reliability by ensuring failures outside test cases are caught immediately. All substantive technical questions have been resolved, and the series is now in its final form with all tests passing across environments. This represents a major step forward in Git's ongoing effort to modernize and harden its test infrastructure.
