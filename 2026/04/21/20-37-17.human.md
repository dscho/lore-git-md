This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, which aims to improve Git's scalability for large repositories. The patch modernizes how MIDX (multi-pack-index) files are tracked during cleanup operations.

The change replaces hand-rolled arrays of filenames with a `strset` data structure for tracking which MIDX files to retain when pruning stale ones. This simplifies the code by:
- Eliminating manual memory management of string arrays
- Reducing parameter passing (no more separate length parameter)
- Using more efficient lookups (though the performance impact is negligible given the small typical size)

The patch affects two functions that clean up MIDX files (`clear_midx_files_ext` and `clear_incremental_midx_files_ext`), making them more maintainable while preserving their behavior. This is a straightforward internal improvement that doesn't change user-facing functionality but makes the code more robust as part of the larger repacking effort.

The change follows the series' pattern of careful attention to edge cases and memory management, with proper initialization and cleanup of the new `strset` structures. As with other patches in this series, it demonstrates Taylor Blau's methodical approach to refactoring core Git infrastructure.
