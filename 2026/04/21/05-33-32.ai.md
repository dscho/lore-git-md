Here is the second patch in Siddharth Shrimali's test modernization series for t7004-tag.sh, implementing Junio Hamano's suggested "belt-and-suspenders" approach to verifying repository state.

The patch replaces brittle tag count checks with a more robust verification method. This ensures the repository state remains unchanged while being resilient to changes in the test file's overall tag count.
