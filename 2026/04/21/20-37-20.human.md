This is a refactoring patch in Taylor Blau's ongoing series to improve MIDX/bitmap-based repacking for large repositories. The patch simplifies how checksum hashes are collected when writing MIDX files by replacing a reverse-indexing approach with a more straightforward temporary array method.

The change makes the code easier to follow by eliminating the need to mentally track backward array indexing while processing forward-linked lists. It introduces a temporary `layers` array to collect MIDX nodes first, then processes them in reverse order to populate the `keep_hashes` array sequentially. This prepares for a future change to use Git's `strvec` data structure.

While not user-visible, this internal cleanup improves maintainability of the MIDX infrastructure. The patch includes an assertion to verify the final hash count matches expectations, demonstrating attention to correctness. This is part of the larger effort to make Git's repacking strategy more scalable for large repositories.
