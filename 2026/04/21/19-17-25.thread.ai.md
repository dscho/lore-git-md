Subject: Ninja build system compatibility fix for config-list.h generation
Thread type: build system patch
Author: Toon Claes
Core problem: Older Ninja versions (pre-1.10.0) incorrectly parse multi-line dependencies in config-list.h generation, causing build failures on systems like AlmaLinux 8 (Ninja 1.8.2).

Technical details:
- Final implementation uses `tr` to unconditionally collapse dependencies onto single line (Patrick Steinhardt's suggestion)
- Works around Ninja parser bug while maintaining compatibility with both Make and all Ninja versions
- Preserves harmless no-op targets in config-list.h.d for Make compatibility
- Changes isolated to build system (meson.build and generate-configlist.sh)
- No runtime behavior changes
- Confirmed working on Ninja 1.8.2 through real-world testing

Status: Ready for merging with consensus on solution
Participant positions:

- Patrick Steinhardt: Proposed simpler unconditional approach (substantive technical review)
