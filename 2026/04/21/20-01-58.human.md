This is the second patch in Taylor Blau's 9-part series fixing bugs in the pseudo-merge bitmap implementation. The patch adds comprehensive test coverage that demonstrates several existing bugs in the feature.

The test file `t5333-pseudo-merge-bitmaps.sh` gains 198 lines of new test cases that are intentionally marked as failing (except one). These tests exercise different scenarios:

1. Basic pseudo-merge application during bitmap traversal
2. Handling multiple pseudo-merge groups simultaneously 
3. Overlapping pseudo-merge groups (testing extended lookup paths)
4. Date-based classification of commits into pseudo-merge groups
5. A special case for sampleRate=0 that's currently latent (marked passing but will fail when other bugs are fixed)

The tests follow a consistent pattern - they set up repositories with specific pseudo-merge configurations, generate bitmaps using the new test helper from patch 1, then verify behavior through rev-list operations and trace2 event counting. The tests are well-structured with clear setup/assertion phases and include defensive programming patterns (like `: >trace2.txt` initialization) that Elijah Newren has confirmed as correct.

This test infrastructure will be used in subsequent patches to verify the fixes for the demonstrated bugs. The patch shows careful attention to edge cases and provides the foundation for validating the pseudo-merge bitmap functionality that's important for Git's performance with large repositories.
