This is a refactoring patch in Taylor Blau's ongoing MIDX/bitmap-based repacking series (part 7 of 16). The change moves the ODB (object database) source tracking from direct repository access to the `existing_packs` struct that's already used to track pack information during repacking.

The patch makes no functional changes - it still uses the same source as before (the repository's primary ODB source). However, it sets up two future needs:
1. The upcoming incremental repacking code will need to know which source contains existing MIDX files
2. It prepares for potential future support of repacking from alternate object sources

The changes are straightforward - storing the source in `existing_packs` during collection and using that stored value rather than accessing the repository directly. This continues the series' pattern of careful refactoring to support the larger geometric repacking architecture while maintaining existing behavior.

As with previous patches in the series, this shows attention to the incremental nature of the changes - each step builds logically on the last while keeping the code functional at each stage. The patch is well-contained and clearly motivated within the context of the larger effort.
