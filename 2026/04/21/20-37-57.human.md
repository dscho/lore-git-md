This is a feature patch in Taylor Blau's series introducing incremental MIDX/bitmap-based repacking, now at patch 15/16. The series implements geometric MIDX chain repacking to avoid periodic full repacks in large repositories.

This patch exposes the incremental MIDX repacking mode via a new `--write-midx=incremental` option for `git repack`, which requires `--geometric` to be specified. It introduces two new configuration options to control compaction behavior:
- `repack.midxSplitFactor` (default 2) - geometric merging factor for MIDX layers
- `repack.midxNewLayerThreshold` (default 8) - minimum packs in tip layer before considering them for repacking

The implementation includes extensive test coverage across various scenarios like geometric violations, multi-round chain integrity, branching/merging histories, and threshold-based compaction. The tests verify the new mode maintains object accessibility while optimizing the MIDX chain structure.

This represents the final functional piece of Taylor's multi-year effort to improve Git's scalability for large repositories through smarter repacking strategies. The patch shows careful attention to edge cases and builds on the infrastructure from previous patches in the series.
