This is patch 5/9 in Taylor Blau's bugfix series for pseudo-merge bitmaps, addressing issues in the lookup path for commits that appear in multiple pseudo-merge groups. The patch fixes three distinct bugs:

1. A write-side miscalculation where extended table offsets were being incorrectly computed due to an undercounted entry size (12 bytes vs 8 bytes assumed). This caused the extended table to overlap with the regular lookup table.

2. A read-side issue where bitmap offsets were being incorrectly interpreted as commit table entries, leading to data corruption. The fix stores the offset directly rather than re-parsing.

3. A latent error-checking bug that would have silently ignored corruption cases (though this wasn't triggering in practice with the other bugs present).

The patch also updates a test case from expected-failure to expected-success now that the underlying issues are fixed. The changes show careful attention to the technical details of the pseudo-merge bitmap implementation, particularly around the extended lookup path for shared commits. This continues the series' pattern of thorough fixes backed by test coverage improvements.
