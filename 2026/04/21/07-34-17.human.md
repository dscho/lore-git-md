This is part 4 of Patrick Steinhardt's 12-patch series to make Git's test suite compatible with `set -e` (errexit). The series is now in its sixth iteration and ready for merging.

The patch modifies several test scripts to handle `git config --unset` calls more robustly under `set -e`. Currently, these calls fail silently when trying to unset configuration variables that don't exist, but with `set -e` enabled, such failures would cause the test to abort. The changes add `|| :` to suppress these harmless failures, maintaining the original intent of cleaning up test state while working with strict error checking.

The modifications touch three test files:
- t4032-diff-inter-hunk-context.sh (diff context tests)
- t7508-status.sh (status command tests)
- t9138-git-svn-authors-prog.sh (SVN author mapping tests)

This is a mechanical but necessary change as part of the broader effort to enable `set -e` by default in the test suite. The patch follows the established pattern seen in earlier parts of the series for handling similar cases where commands might fail harmlessly.
