This is the first patch in Elijah Newren's series addressing merge-ort issues with duplicate tree entries and D/F conflicts. As the recognized expert on Git's merge machinery, his changes carry significant technical weight.

The patch fixes error handling in `traverse_trees_wrapper()`, which currently silently drops error returns from its callback during tree traversal. This could allow merges to proceed with corrupt state if the callback detected problems. The change makes the wrapper properly propagate callback errors back to the caller, stopping processing on any error.

The fix is straightforward - capturing the callback's return value and breaking the loop on errors - but addresses a real issue where malformed trees could slip through. This is preparatory work for the later patches that will actually detect and handle duplicate entries. The change is well-contained to merge-ort.c and comes with Elijah's characteristic thoroughness - he notes the current behavior masks callback errors and explains the non-negative return normalization.

As the first in a series from a domain expert addressing real-world corruption cases, this patch sets up the foundation for more substantive fixes to come. The change is small but important for correctness.
