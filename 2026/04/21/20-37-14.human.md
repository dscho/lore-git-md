This is a bugfix patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, which aims to improve Git's scalability for large repositories. The patch addresses an edge case in MIDX (multi-pack-index) writes when dealing with incremental chains.

The issue occurs when Git tries to skip writing a MIDX file that would be identical to an existing one. The current logic fails to properly compare pack names when there are multiple MIDX layers, treating the tip layer as containing all packs rather than examining each layer individually. This patch fixes that by walking through each MIDX layer when comparing pack names.

The change is accompanied by a new test case that verifies non-incremental writes work correctly when an incremental MIDX chain already exists. The patch also fixes a typo in a comment ("exisiting" -> "existing").
