This is the fourth and final patch in Johannes Schindelin's CI/build system series updating GitHub Actions dependencies. It bumps `actions/checkout` from v5 to v6 across all workflow files in `.github/workflows/`.

The key change in v6 moves credential storage from `.git/config` to `$RUNNER_TEMP`, improving security by preventing accidental token leakage through artifacts. The patch includes a thorough risk analysis showing this change is transparent to Git's workflows - the CI either checks out the default repo or explicitly sets paths for `vcpkg`, neither of which rely on the credential storage mechanism. 

The update affects multiple workflows including main CI, style checks, Coverity scans, and Windows builds. As with previous patches in the series, this originated from Dependabot but has been carefully reviewed by Schindelin with detailed commit message documentation. The changes are purely version bumps with no functional modifications to the workflow logic.

This completes the series' updates to GitHub Actions components, having now addressed `setup-msbuild`, `upload-artifact`, `download-artifact`, `github-script`, and `checkout`. All changes appear to be low-risk maintenance updates to keep CI infrastructure on supported versions.
