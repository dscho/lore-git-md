This is a build system patch addressing a Ninja compatibility issue. The problem occurs when generating config-list.h dependencies on older Ninja versions (pre-1.10.0) where the depfile parser incorrectly creates a circular dependency when dependencies are listed on separate lines.

The patch modifies tools/generate-configlist.sh to optionally collapse all dependencies onto a single line when building with older Ninja versions, while maintaining the original multi-line format for Make and newer Ninja. The meson.build file is updated to detect the Ninja version and pass the appropriate flag to the script.

The issue was discovered when building Git on AlmaLinux 8 which ships with Ninja 1.8.2. The solution is backwards-compatible and doesn't affect builds using Make or newer Ninja versions. The commit includes detailed technical background about the Ninja parser bug and clear reproduction steps.

The patch maintains compatibility across different build systems while addressing the specific issue in older Ninja versions. The changes are localized to the build system components and don't affect runtime behavior.
