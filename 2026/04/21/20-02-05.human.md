This is the fourth patch in Taylor Blau's v2 series fixing bugs in pseudo-merge bitmaps, a performance optimization feature. The patch corrects an inverted binary search implementation in `pseudo_merge_at()` that was causing lookups to fail when multiple pseudo-merge groups existed.

The core issue is straightforward: the binary search was updating its bounds in the wrong direction, causing it to search left when it should search right and vice versa. While this bug was masked when only one pseudo-merge group existed (since the single entry would always be at the midpoint), it became apparent with multiple groups where lookups would search in the wrong direction and miss entries.

The fix swaps the "lo" and "hi" assignments to make the search work correctly. The accompanying test case, which previously expected failure, now passes as it demonstrates successful application of pseudo-merges from multiple groups during fill-in traversal. This is a clear bugfix that addresses a specific algorithmic issue while maintaining the feature's overall design.
