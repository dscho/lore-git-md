This is patch 3/12 in Patrick Steinhardt's v6 series to make Git's test suite compatible with `set -e` (errexit). The series is now complete and ready for merging after thorough review feedback.

The patch modifies the `stop_git_daemon()` helper function in `t/lib-git-daemon.sh` to work correctly under `set -e` by:

1. Changing the `wait` call to use `||` to capture the exit code without triggering immediate exit when `set -e` is active
2. Silencing the second `kill` call (which often fails since the daemon is already dead) with `|| :` to prevent it from stopping execution

These changes maintain the same behavior while making the function robust under strict error checking. The modifications are mechanical adaptations needed for the broader `set -e` compatibility effort, which will help catch silent test failures by making errors immediately fatal outside of test cases.

The patch follows the established pattern seen throughout this series of carefully adapting test infrastructure to work with `set -e` while preserving original semantics. With all technical questions resolved in previous iterations, this version represents the final refinement of the change.
