This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series, which aims to improve Git's scalability for large repositories. The patch modernizes how MIDX (multi-pack-index) files are tracked during cleanup operations.

The change replaces hand-rolled arrays with a `strset` data structure for tracking which MIDX files to retain when pruning stale ones. This provides several improvements:
1. Eliminates manual memory management of string arrays
2. Simplifies function signatures by removing length parameters
3. Provides O(1) lookups instead of linear searches
4. Makes the code more maintainable by using standard Git utilities

While the performance impact is likely negligible given the small number of files typically involved, the change follows Git's general direction toward using more robust data structures. The patch includes corresponding updates to both `clear_midx_files_ext()` and `clear_incremental_midx_files_ext()` functions.

This is a straightforward internal cleanup that doesn't affect user-visible behavior, but contributes to the overall robustness of the MIDX repacking infrastructure. The change is well-contained and follows established patterns seen elsewhere in the codebase.
