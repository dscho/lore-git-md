This is a test infrastructure patch from Patrick Steinhardt, part of his v6 series to make Git's test suite compatible with `set -e` (errexit). The series is now complete and ready for merging after thorough review.

The specific patch modifies t1301-shared-repo.sh to handle cases where the `setfacl` command fails or doesn't exist. The test currently tries to remove default ACLs from the test directory, but this isn't essential for the test's operation - it was added as a precaution in 2008. With `set -e` becoming the default, such failures would cause the test to abort, so the patch adds `|| :` to ignore them while maintaining the test's core functionality.

This is a small but important piece of the larger effort to harden Git's test infrastructure by ensuring the suite can run with strict error checking enabled. The change is mechanical and uncontroversial, following the pattern established throughout the series for handling non-critical external tool failures.
