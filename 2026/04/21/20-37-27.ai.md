This is a feature patch in Taylor Blau's incremental MIDX/bitmap-based repacking series (patch 5/16), introducing a new `--no-write-chain-file` option for MIDX writes. The change enables callers to write new MIDX layers without immediately updating the chain file, allowing atomic updates of the chain after assembling multiple layers.

The patch adds the new flag to both `write` and `compact` subcommands, requiring it to be used with `--incremental`. When set, Git writes the MIDX layer to disk and prints its checksum, but leaves the chain file untouched. This prepares for the repacking strategy that will assemble the complete new chain before atomically updating it.

Key technical changes include:
- New `MIDX_WRITE_NO_CHAIN` flag in midx.h
- Lockfile handling modifications in midx-write.c to skip chain updates when requested
- Validation ensuring the flag is only used with `--incremental`
- Comprehensive tests verifying the new behavior in both write and compact operations

The implementation shows careful attention to edge cases, with tests covering both successful and invalid usage scenarios. This is a well-contained preparatory change that maintains the series' focus on large-repository scalability while improving the atomicity guarantees of MIDX chain updates.
