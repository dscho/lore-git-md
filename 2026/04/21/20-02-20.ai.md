This is the final patch in Taylor Blau's bugfix series for pseudo-merge bitmaps, addressing a memory leak in the pattern redefinition logic. The patch fixes an issue where redefining a pseudo-merge group's pattern would leak the internal state of the previously compiled regular expression.

The key fix is in `pseudo_merge.c`, where the code now properly calls `regfree()` before `free()` when replacing an existing pattern. The patch also adds a new test case that verifies the fix by deliberately redefining the same pattern twice and checking for leaks.

This completes the series that has systematically addressed multiple issues in the pseudo-merge bitmap implementation, from lookup path correctness to configuration validation and now memory management. The test coverage added throughout the series provides comprehensive verification of the fixes.
