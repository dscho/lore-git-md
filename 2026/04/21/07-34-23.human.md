This is a test modernization patch in Patrick Steinhardt's series to make Git test suite compatible with `set -e` (errexit). The patch updates the bisection tests in `t6002-rev-list-bisect.sh` to use shell arithmetic (`$(( ))`) instead of the older `expr` command, which fails under `set -e` when the result is zero.

The change is mechanical but important - `expr` has subtle failure modes that would break tests when strict error checking is enabled. The new version also improves readability by using proper `if` statements rather than chained `&&` expressions. This is part of the final v6 series that's now ready for merging after thorough review.

The patch demonstrates the careful, systematic approach taken throughout this effort - each test script is examined for patterns that would break under `set -e`, then updated while preserving the original test semantics. The bisection test changes follow the same principles seen across the series: replacing problematic shell constructs with more robust alternatives.
