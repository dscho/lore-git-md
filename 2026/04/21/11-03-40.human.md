This is a security bug report affecting the `git-credential-libsecret` helper, which is part of Git's contrib directory. The helper incorrectly writes credentials to stdout during `store` and `erase` operations, leaking sensitive information to terminal scrollback, log files, or CI artifacts when used in the documented non-interactive pattern.

The bug is reproducible in Git 2.53.0 and current master. The author provides a clear reproduction case showing the credential leak and proposes two potential fixes: a minimal one-line guard or a more thorough refactoring of the output contract. They note this is a moderate severity issue since it affects the documented workflow but requires no special exploitation.

The report is well-structured with clear sections on impact, root cause, and workaround. The author offers to submit a proper patch and coordinate disclosure if needed, though notes the trivial workaround (redirecting stdout) makes immediate disclosure reasonable. This appears to be a legitimate security issue that warrants prompt attention from maintainers.
