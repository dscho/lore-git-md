This is part 2 of Patrick Steinhardt's 12-patch series to make Git's test suite compatible with `set -e` (errexit), now in its sixth iteration and ready for merging. The series as a whole establishes `set -e` as the default for Bash 5+ while maintaining opt-in support for other shells.

This specific patch modifies the `test_must_fail()` helper function to work correctly under `set -e`. The function tests whether a Git command fails as expected, but with `set -e` enabled, the shell would exit immediately when the command fails - before the function can check the exit code. The change uses `||` to capture the exit code without triggering `set -e`, while maintaining all existing functionality including the special handling of Git commands and success/failure checking.

The patch is a straightforward mechanical change that follows the pattern used elsewhere in the series to adapt test helpers for strict error checking. It has already been reviewed in previous iterations, with all technical questions resolved. This is one of the foundational changes needed before the final patch can enable `set -e` by default.
