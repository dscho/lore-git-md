This is the second patch in Johannes Schindelin's 4-part CI/build system series updating GitHub Actions dependencies. The patch focuses on bumping the versions of `actions/upload-artifact` (from v5 to v7) and `actions/download-artifact` (from v6 to v8) across Git's CI workflows.

The changes are motivated by GitHub's deprecation of Node.js 20, which these actions' older versions relied on. The new versions switch to Node.js 24 by default. Schindelin provides a thorough risk analysis showing the updates are safe: the artifact format contract remains intact, the ESM migration doesn't affect Git's usage, and the stricter hash verification in download-artifact v8 is actually beneficial for security.

The patch updates all occurrences in `.github/workflows/main.yml`, including Windows build/test jobs and the meson build configuration. One stray v4 upload-artifact reference is aligned to v7 for consistency. The changes are mechanical version bumps with no functional modifications to the workflows themselves.

This appears to be a well-justified maintenance update that keeps Git's CI system running on supported infrastructure. The detailed commit message and risk assessment suggest careful review by Schindelin, despite originating from Dependabot automation.
