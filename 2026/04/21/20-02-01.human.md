This is patch 3/9 in Taylor Blau's bugfix series for pseudo-merge bitmaps, addressing a critical sorting issue in the commit lookup table. The patch fixes a binary search failure that was preventing pseudo-merges from being correctly applied during fill-in traversal.

The core issue was that the lookup table was being sorted lexically (by OID) rather than by pack position, which broke the binary search used to find applicable pseudo-merges. While this didn't produce wrong results (it just failed to apply some optimizations), it meant the feature wasn't working as intended for fill-in traversals.

The fix introduces a custom sort function (`pseudo_merge_commit_pos_cmp`) that sorts commits by their pack position instead of OID. This matches the documented bitmap format and enables the binary search to work correctly. The patch also updates a test case that was previously marked as an expected failure to now expect success.
