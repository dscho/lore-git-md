This is the second patch in a CI/build system series updating GitHub Actions dependencies. Johannes Schindelin bumps the versions of `actions/upload-artifact` (from v5 to v7) and `actions/download-artifact` (from v6 to v8) across multiple workflow files.

The key motivation is moving off the deprecated Node.js 20 runtime to Node.js 24. The changes are coordinated because these actions work in tandem - upload writes artifacts that download reads. The patch includes a thorough risk analysis showing the updates are safe for Git's usage patterns, as they don't use the new optional features being introduced in these versions.

Notable changes in the new versions include runtime updates, ESM conversion (invisible to callers), and stricter artifact validation. The patch also fixes a stray v4` reference to maintain version consistency. These appear to be well-vetted maintenance updates with no functional impact on Git's CI behavior.
