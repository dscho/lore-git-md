This is an announcement for the upcoming Git Merge 2026 conference, co-hosted by GitButler and GitHub. The event will take place September 17-18 in Lisbon, Portugal, with the main conference on the 17th and Contributor's Summit/unconference sessions on the 18th. Google will also host a separate Jujutsu (jj) event on September 16th.

The venue is Suspenso in Lisbon, with no hotel block currently arranged. The organizers note that registration details are forthcoming and financial assistance may be available through the Git PLC for those needing travel support. The email invites discussion about potential topics for the unconference sessions and general feedback about the event format.

This appears to be the initial announcement to allow attendees to plan travel, with more logistical details to follow. The co-hosts (Scott Chacon from GitButler and Taylor Blau from GitHub) are soliciting input from the community about session topics and event structure. The inclusion of both the main Git conference and a separate Jujutsu event reflects the growing ecosystem around version control tools.
