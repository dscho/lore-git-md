This is a refactoring patch in Taylor Blau's ongoing series to improve Git's repacking strategy for large repositories. The series introduces incremental MIDX/bitmap-based repacking to avoid periodic full repacks.

This specific change (patch 12/16) converts the `--write-midx` flag from a simple boolean to a callback that can handle multiple modes. It introduces an enum with `REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT` states, preserving existing behavior while setting up infrastructure for future incremental MIDX writing modes.

The patch:
1. Adds a new `option_parse_write_midx()` callback to handle the flag
2. Updates all boolean checks to use the new enum
3. Extracts `repack_write_midx()` as a dispatcher function
4. Maintains backward compatibility with the existing `-m` short option

This is a well-contained preparatory change that follows the series' pattern of building infrastructure incrementally. The patch touches several files but makes focused, mechanical changes that are easy to verify. It's part of a larger effort to improve Git's scalability for large repositories.
