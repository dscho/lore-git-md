This is a refactoring patch in Taylor Blau's incremental MIDX/bitmap-based repacking series (12/16). The patch converts the `--write-midx` flag from a simple boolean option to a callback-based option that can accept different modes, preparing for future expansion of MIDX writing functionality.

The key changes are:
1. Introduces an enum `repack_write_midx_mode` with `NONE` and `DEFAULT` states
2. Adds an option parser callback to handle the new mode-based syntax
3. Creates a dispatcher function `repack_write_midx()` that will select the appropriate MIDX-writing implementation
4. Updates all boolean checks to use the new mode enum

The patch maintains backward compatibility - passing just `-m` or `--write-midx` without arguments continues to use the default MIDX writing behavior. This is part of the ongoing effort to enable incremental MIDX repacking, where different MIDX writing strategies will be needed.

The changes are mechanical but important infrastructure work, following the series' pattern of careful, incremental refactoring. The patch touches several files but focuses cleanly on the option parsing and dispatch layer without making behavioral changes yet.
