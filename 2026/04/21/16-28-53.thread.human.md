This thread documents a comprehensive bugfix series for git-gui that addresses long-standing issues with repository and worktree detection. The original author, Shroom Moo, worked through eight iterations (v1-v8) to refine the solution, with final sign-off from git-gui maintainer Mark Levedahl and architectural review from Johannes Sixt.

The core improvements unify all repository detection through `git rev-parse`, replacing fragile custom logic with Git's built-in validation. The series simplifies bare repository detection, properly handles .git directory launches, and provides robust error handling for misconfigured environments. The final patch adds explicit subcommands (`gui` and `pick`) to give users control over when the repository picker appears, completing the architectural work while maintaining backward compatibility.

All technical concerns raised during review were addressed, and the solution now provides consistent behavior across edge cases that previously caused cryptic errors. The changes restore functionality broken since 2019 while removing 57 lines of legacy detection code. This represents a significant improvement to git-gui's reliability, particularly for users working with bare repositories or complex worktree setups.
