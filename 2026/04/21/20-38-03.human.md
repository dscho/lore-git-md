This is the final patch in Taylor Blau's 16-part series introducing incremental MIDX/bitmap-based repacking, a major architectural improvement for large repositories. The series implements geometric MIDX chain repacking to avoid periodic full repacks.

This specific patch relaxes a previous restriction that required `--write-midx=incremental` to be used with `--geometric`. Now the incremental MIDX repacking can work in an append-only mode when used without geometric repacking - it will create new MIDX layers containing freshly written packs while preserving existing layers unchanged. This provides more flexibility in how repositories can use the new incremental repacking feature.

The implementation adds a new `repack_make_midx_append_plan()` function that builds a simple plan to append new packs to the MIDX chain without compaction. The existing geometric compaction logic remains unchanged when `--geometric` is used. The patch includes updated documentation explaining both modes and adds test coverage for the new append-only behavior.

This completes the series by making the incremental MIDX repacking feature more versatile while maintaining all the benefits of geometric compaction when desired. The implementation appears clean and well-tested, with careful attention to edge cases and clear documentation of the new behavior.
