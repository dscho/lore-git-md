This is the fourth patch in Taylor Blau's v2 series fixing bugs in the pseudo-merge bitmap implementation. The patch corrects an inverted binary search in `pseudo_merge_at()` that was causing lookups to search in the wrong direction when multiple pseudo-merge groups existed.

The key fix swaps the `lo` and `hi` assignments in the binary search to properly narrow the search range. Previously, the search would incorrectly move left when it should have moved right (and vice versa), potentially causing valid pseudo-merges to be missed during fill-in traversal. The patch also updates the corresponding test case from `test_expect_failure` to `test_expect_success` now that the bug is fixed.

This is a straightforward correction to a core lookup function that affects how pseudo-merges are applied during bitmap operations. The change maintains compatibility with the on-disk format while fixing the runtime behavior. The test update demonstrates the fix works for the multiple-group case that was previously failing.
