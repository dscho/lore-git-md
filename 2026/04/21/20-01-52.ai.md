This is an updated version of Taylor Blau's bugfix series for pseudo-merge bitmaps, now at v2 with 9 patches. The series addresses multiple issues in the pseudo-merge bitmap implementation that were preventing the feature from working correctly.

Key changes in this revision:
- Fixed a use-after-realloc bug in the test helper by restructuring how the index array is built
- Swapped initialization/cleanup order in test scripts per Elijah Newren's review
- Updated documentation to clarify the valid range for sampleRate (now must be 0 < sampleRate ≤ 1)
- Added a new patch fixing a broken example in gitpacking(7) documentation
- Resolved an API type mismatch by passing `0` instead of `false` to match the unsigned parameter type

The series continues to:
1. Add test infrastructure (new test helper and test cases)
2. Fix lookup table sorting and binary search issues
3. Correct extended lookup path handling
4. Fix commit date parsing in group selection
5. Prevent division by zero from invalid config
6. Fix a memory leak in pattern redefinition

The changes show careful attention to review feedback, particularly around test safety and documentation accuracy. The pseudo-merge bitmap functionality is an important performance optimization, and this thorough fix series addresses both implementation bugs and test coverage gaps.
