This is a feature patch in Taylor Blau's ongoing series to improve Git's MIDX (multi-pack-index) repacking strategy for large repositories. The patch introduces a new `--base` option for both `write` and `compact` subcommands of `git multi-pack-index`, allowing callers to specify which existing MIDX layer should serve as the base for new incremental writes.

The key additions are:
- A `--base=<checksum>` parameter that accepts either a valid MIDX layer checksum or "none" to create a root layer
- Safety checks ensuring `--base` is only used with `--no-write-chain-file` for writes (to prevent chain corruption)
- Comprehensive test coverage including edge cases like invalid base checksums
- Documentation updates explaining the new option's behavior and constraints

The change enables more flexible MIDX chain manipulation, particularly useful for the incremental repacking machinery which may need to replace bottom layers or build on intermediate ancestors rather than always appending to the tip. The implementation maintains all existing safety checks while adding the new capability.

This patch follows the series' pattern of careful validation and thorough testing, with clear documentation of both the feature and its constraints. It represents an important building block for the larger geometric repacking strategy Taylor has been developing.
