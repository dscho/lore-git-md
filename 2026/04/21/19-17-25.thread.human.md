This thread addressed a build system compatibility issue where older versions of Ninja (pre-1.10.0) failed to correctly parse multi-line dependencies during config-list.h generation, particularly affecting systems like AlmaLinux 8 which ships with Ninja 1.8.2. Toon Claes initially identified the problem and proposed a solution, with Patrick Steinhardt suggesting a simpler approach of unconditionally collapsing the dependencies into a single line using `tr`.

The final implementation, now verified through real-world testing, works around the Ninja parser limitation while maintaining compatibility with both Make and all Ninja versions. The changes are isolated to the build system (meson.build and generate-configlist.sh) and introduce no runtime behavior changes.
