The thread addresses a build system compatibility issue where older versions of Ninja (pre-1.10.0) fail to correctly parse multi-line dependencies when generating config-list.h, causing build failures on systems like AlmaLinux 8. Toon Claes initially identified the issue and proposed a solution, which was refined through discussion with Patrick Steinhardt.

The final approach - using `tr` to unconditionally collapse dependencies onto a single line - emerged as the cleanest solution that works across all build systems while avoiding the Ninja parser bug. The fix preserves no-op targets for Make compatibility and has no runtime impact. Both Toon and Patrick confirmed the solution works, with Patrick providing the key technical insight that led to the simpler implementation.
