This is the first patch in Taylor Blau's v2 series fixing bugs in pseudo-merge bitmaps, a performance optimization feature. The patch introduces a new `test-tool bitmap write` subcommand to enable precise testing of bitmap generation by allowing test scripts to specify exactly which commits should receive bitmaps.

The new test tool reads commit OIDs from stdin and writes bitmaps for them, respecting pseudo-merge configuration. This provides the controlled test environment needed to properly exercise the pseudo-merge bitmap code paths that were previously untested. The patch includes a test case demonstrating the tool's ability to correctly generate bitmaps for specified commits.

This foundational change enables the subsequent patches in the series to properly test and fix various bitmap bugs. The implementation shows careful attention to memory safety and proper cleanup, addressing feedback from earlier reviews. The test helper will be used extensively in the following patches to validate fixes for bitmap lookup, sorting, and other issues.
