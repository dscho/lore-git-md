This is a refactoring patch in Justin Tobler's series to complete the object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The patch builds on previous work that made transaction initialization pluggable via a callback in `struct odb_source`.

The change is straightforward: instead of directly calling `odb_transaction_files_begin()` (the filesystem-specific implementation), the code now uses the source's `begin_transaction()` callback. This makes the transaction system properly pluggable, allowing alternative ODB backends to provide their own transaction implementations. The patch updates the header include from "object-file.h" to "odb/source.h" to reflect this architectural shift.

This is a mechanical change that follows through on the interface introduced in commit d6fc6fe6f8. It's a small but important piece of the larger ODB abstraction puzzle, ensuring all transaction operations consistently use the pluggable interface. The patch has already been reviewed by Patrick Steinhardt in the previous iteration and appears ready for merging.
