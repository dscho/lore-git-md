This is a refactoring patch that splits the ODB transaction interface into its own header file, part of Justin Tobler's series completing the write operations interface for Git's object database (ODB) transactions. The patch moves `struct odb_transaction` and related functions from `odb.{c,h}` to new files `odb/transaction.{c,h}`, updating all callers to include the new header.

The change is mechanical but important for code organization as the transaction interface grows to support direct write operations. The patch affects several commands (`git add`, `git update-index`, `git unpack-objects`) and core components (cache-tree, read-cache) that use transactions. All changes are straightforward header updates and code movement with no functional changes.

This is the first of seven patches in the final version of the ODB write interface series, which has already gone through review with Patrick Steinhardt. The spelling of "colocated" in the commit message reflects Junio C Hamano's historical context from earlier discussion. The patch appears clean and focused, properly preparing the codebase for the subsequent transaction write interface additions.
