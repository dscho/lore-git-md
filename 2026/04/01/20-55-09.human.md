This is a feature patch series for the `git replay` plumbing command, introducing version 3 of the `--ref` option to control which reference gets updated during replay operations. The series comes from Toon Claes and builds on Siddharth Asthana's recent work adding `--revert` to `git replay`.

The v3 series addresses a SIGABRT crash that was blocking the previous version, caused by uninitialized merge options when invalid refnames reached merge-ort. The fix zero-initializes the merge options struct. Other changes include clearer documentation that `--ref` requires fully qualified refnames (not just branch names) and maintaining the stuck form (`--option=value`) syntax throughout.

The implementation continues to provide precise control over ref updates while maintaining backward compatibility. The changes look well-considered, with test coverage expanded to verify the new validation rules. Junio C Hamano had previously confirmed the crash was inherent to the patches (not rebase artifacts), and this version appears to resolve that issue while keeping the core functionality intact.
