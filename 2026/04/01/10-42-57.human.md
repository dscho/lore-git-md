This is a bugfix patch series addressing test failures caused by bugs in Dash v0.5.13. Patrick Steinhardt identifies two specific issues in this shell interpreter version that affect Git's test suite: incorrect handling of multibyte characters in heredocs and a data-reading bug that has since been fixed upstream.

The series modifies several test scripts to work around these Dash bugs, touching credential tests, rebase tests, quoted string handling, format-patch, shortlog, send-email, and fast-import tests. The changes are mechanical adjustments to heredoc usage and input handling patterns that trigger the Dash bugs.

The patches appear well-motivated and narrowly targeted - they don't change test behavior, just make the tests more robust against known shell interpreter issues. Patrick notes he's CC'd the Dash maintainer about the bugs, suggesting this is a temporary workaround while waiting for proper fixes in Dash itself. The changes are straightforward and unlikely to be controversial, though reviewers may want to verify the test modifications don't mask other potential issues.
