This is the first patch in a 7-part series that completes the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch is a straightforward code organization change that splits the `struct odb_transaction` and related functions out of the main `odb.{c,h}` files into new dedicated files `odb/transaction.{c,h}`.

The change is mechanical but important for maintainability - it prevents the main ODB files from becoming too large as the transaction interface grows. The patch updates all callers to include the new header, including several builtin commands (`add`, `unpack-objects`, `update-index`) and core components like `cache-tree` and `read-cache`.

This patch has already been reviewed and approved by Patrick Steinhardt, with Justin Tobler confirming he updated the spelling of "colocated" in the commit message based on Junio C Hamano's historical context. The change is uncontroversial and serves as groundwork for the more substantive transaction interface changes that follow in the series.
