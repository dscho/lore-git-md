This is a feature patch series introducing new `includeIf` conditions for matching worktree paths in Git configs. The 3-patch series comes from Chen Linxuan and aims to make it easier to include configuration based on the working tree location in multi-worktree setups.

The core addition is two new `includeIf` conditions: `worktree:<pattern>` and its case-insensitive variant `worktree/i:<pattern>`. These match against the realpath of the current worktree's directory using glob patterns, addressing a pain point where current `gitdir` matching requires knowing internal `.git/worktrees/` paths. The implementation supports common glob features like wildcards, `**/` recursion, and `~` expansion.

The series includes thorough documentation explaining the new conditions and their pattern syntax, plus comprehensive tests covering various matching scenarios and edge cases. The implementation appears clean and well-considered, with the config parsing logic modified to handle the new conditions alongside existing ones.
