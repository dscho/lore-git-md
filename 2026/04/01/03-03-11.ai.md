This is the third patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. Justin Tobler refines the `struct odb_write_stream` interface to clarify buffer ownership and error handling.

The patch changes the `read()` callback signature from returning a pointer to an internal buffer to having the caller provide the buffer, which makes ownership semantics clearer and enables proper error reporting. The callback now returns the number of bytes written or a negative value on error. This affects the streaming write path used by commands like `git unpack-objects`.

The implementation updates two key call sites: the zlib decompression helper in `unpack-objects.c` and the loose object writer in `object-file.c`. Both are modified to use the new interface while maintaining their existing functionality. The changes are straightforward mechanical conversions with no behavior changes beyond the improved error handling.

This patch builds on the previous infrastructure work in the series and has already incorporated review feedback from Patrick Steinhardt. It's a clean, focused change that improves the robustness of the streaming write path while maintaining compatibility with the rest of the ODB transaction system being built up in this series.
