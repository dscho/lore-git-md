This thread focuses on making Git's test suite more robustly handle known bugs in Dash shell v0.5.13. Patrick Steinhardt has identified two specific issues: incorrect handling of multibyte characters in heredocs (still present in Dash master) and partial reads (already fixed upstream). 

The current patch addresses the multibyte heredoc problem, where quoted heredocs incorrectly wrap multibyte sequences with CTLMBCHAR bytes (85 02 and 02 85). The solution is mechanical - converting quoted heredocs (`<<-\EOF`) to unquoted heredocs (`<<EOF`) in affected test files covering credential handling, rebase, quoting, format-patch, shortlog, and send-email tests. The changes are test-only and don't impact production code behavior.

The series is well-scoped, focusing on making Git's tests work with known shell bugs rather than attempting to fix Dash itself. The Dash maintainer has been CC'd for awareness. So far there have been no reviews or objections to these straightforward test infrastructure improvements. The changes should make the test suite more reliable when run with affected Dash versions.
