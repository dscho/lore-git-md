This thread addresses test failures that occur when running Git's test suite with Dash shell version 0.5.13. Patrick Steinhardt has submitted a two-patch series to work around two specific Dash bugs: one involving incorrect handling of multibyte characters in heredocs, and another causing partial reads that could hang tests.

The first patch converts quoted heredocs to unquoted ones in several test files (including credential, rebase, and send-email tests) to avoid the multibyte handling issue. In response to Eric Sunshine's feedback, v2 of this patch added clear *DONTQUOTE* markers to document these workarounds while maintaining the technical fix. The second patch, which remains unchanged from v1, rewrites output checking in t9300-fast-import.sh to avoid hangs from Dash's partial read bug by comparing the last line after the loop rather than reading line-by-line.

Both patches provide complete solutions to their respective issues while carefully documenting the shell-specific workarounds. The Dash maintainer has been kept in the loop, and all review concerns have been addressed. The series is now ready for inclusion, having demonstrated robust analysis of the shell bugs and thoughtful attention to both technical correctness and long-term maintainability of the test suite.
