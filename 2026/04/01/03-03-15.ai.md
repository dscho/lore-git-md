This is the final patch in Justin Tobler's series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes the `write_object_stream()` operation pluggable by adding it as a callback in `struct odb_transaction`, allowing different ODB implementations to provide their own streaming write strategies.

The key change is introducing the `write_object_stream` callback field in the transaction struct and wiring up the existing packfile implementation (`odb_transaction_files_write_object_stream`) as the default. This completes the architectural shift where all ODB write operations now go through the transaction interface rather than direct filesystem access. The patch renames `index_blob_packfile_transaction()` to better reflect its role as a transaction callback and updates callers to use the new `odb_transaction_write_object_stream()` wrapper function.

With this change, the series achieves its goal of making ODB writes fully pluggable through the transaction interface, a significant milestone in the ODB abstraction work. The implementation maintains backward compatibility while providing the foundation for future storage backends to implement their own write strategies. Patrick Steinhardt has reviewed and approved the series, indicating it's ready for merging.

The changes affect core object writing paths used by commands like `git add` and `git update-index`.
