This April Fools' Day thread began with Patrick Steinhardt's satirical proposal to add MD5 as a Git hash algorithm, complete with a fully implemented patch demonstrating Git's hash algorithm extensibility. The joke patch, which would enable the cryptographically broken MD5 algorithm, humorously referenced Linus Torvalds' original hash choice philosophy while showcasing technical work across multiple subsystems.

Kristoffer Haugsbakk played along with the gag, enthusiastically endorsing the proposal with "I've been waiting years for this!" and jokingly asking when it would be available on CD-ROM - a fittingly outdated medium for the outdated hash algorithm. The exchange serves as both a technical demonstration of Git's flexibility and a lighthearted commentary on the project's serious SHA-256 migration efforts.
