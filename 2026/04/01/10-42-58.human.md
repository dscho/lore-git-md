This is a test infrastructure patch addressing a multibyte character handling bug in Dash shell v0.5.13. Patrick Steinhardt identifies a specific issue where quoted heredocs containing multibyte characters (like "perú") get corrupted with extra control bytes when processed by affected Dash versions. The patch works around this by converting quoted heredocs to unquoted ones in several test files that were failing due to this behavior.

The change is mechanical and focused - it touches credential handling, rebase, quoting, format-patch, shortlog, and send-email tests, modifying their heredoc usage to avoid the Dash bug. The commit message provides a detailed technical explanation of the issue, including hex dumps showing the corrupted output, and notes this is a known Dash bug that still exists in master. 

This appears to be a well-scoped, low-risk change that improves test reliability when running with affected Dash versions. The patch doesn't attempt to fix Dash itself but makes Git's tests more robust against this shell quirk.
