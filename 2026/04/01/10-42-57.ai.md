This is a test infrastructure patch series addressing compatibility issues with Dash shell v0.5.13. Patrick Steinhardt identifies two specific bugs in Dash that cause test failures: one involving incorrect handling of multibyte characters in heredocs (still present in Dash master), and another involving partial reads (already fixed upstream).

The series modifies several test scripts to work around these Dash bugs. The changes are mechanical adjustments to heredoc usage and input handling in tests that were failing due to Dash's behavior. The affected tests span credential handling, rebase, quoting, format-patch, shortlog, send-email, and fast-import functionality.

The patch appears well-motivated and narrowly scoped - it doesn't try to fix Dash itself but makes Git's tests robust against known shell bugs. The commit message clearly identifies the specific Dash versions affected and notes that one issue has already been fixed upstream. The Dash maintainer is CC'd for awareness. This looks like a straightforward improvement to test reliability when running with affected Dash versions.
