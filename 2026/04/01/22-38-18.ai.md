This is an announcement for the Git Rev News newsletter, a regular publication that summarizes recent activity in the Git project. Christian Couder, one of the newsletter editors, is sharing the 133rd edition which covers Git development news from March 2026.

The newsletter is a community effort with contributions from Olamide Caleb Bello, Bruno Brito, Štěpán Němec and Kristoffer Haugsbakk. It provides a digest of important discussions, new features, bug fixes, and other notable changes in the Git project over the past month, serving as a valuable resource for those who want to stay informed without closely following every mailing list thread.

The announcement also notes that issue #842 is already open for contributions to the next edition, indicating the newsletter welcomes community participation in its production. The Git Rev News is published on the git.github.io website, which hosts project documentation and resources.
