This is the third patch in a series introducing the `--ref` option to `git replay`, allowing users to specify exactly which reference should be updated by the command. The patch builds on previous versions that fixed a SIGABRT crash and hardened option parsing.

The key addition here is the `--ref` option, which lets users override the default ref update behavior. When used with `--onto`, it updates only the specified ref instead of inferring refs from the revision range. With `--advance` or `--revert`, it updates the given ref rather than the branch passed to those options. The implementation includes validation to ensure the ref is fully qualified and compatible with other options.

The patch includes comprehensive test coverage in t3650-replay-basics.sh, verifying various combinations of `--ref` with other options and edge cases like invalid refnames.
