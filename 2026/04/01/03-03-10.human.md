This is part 2 of a 7-patch series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes transaction initialization pluggable by using the `begin_transaction()` callback from `struct odb_source` that was introduced in an earlier change (d6fc6fe6f8).

The change is straightforward - it updates `odb_transaction_begin()` to call the source-provided callback rather than directly invoking `odb_transaction_files_begin()`. This is a mechanical change that follows through on the pluggable architecture established in the previous patch. The diff shows the simple header change and function call update needed.

Patrick Steinhardt has already approved this patch in previous review rounds, and it appears ready for merging as part of the larger series. The change helps complete the transition to a fully pluggable ODB transaction system where different storage backends can provide their own implementations.
