This is part 4 of a 7-patch series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. Justin Tobler refactors how blob objects are written to packfiles during transactions.

The patch removes the conditional `INDEX_WRITE_OBJECT` flag check from packfile writes, splitting the functionality into two clear paths: a new `hash_blob_stream()` helper that just computes the object ID, and an unconditional `index_blob_packfile_transaction()` that always writes to the packfile. This prepares for making packfile writes part of the transaction interface in later patches.

The changes affect core object-file handling used by commands like `git add` and `git update-index`. The patch appears well-structured and builds logically on the previous work, with Patrick Steinhardt having reviewed the series. This is a technical refactoring that doesn't change user-visible behavior but improves the internal architecture for future ODB backend implementations.
