This is a test infrastructure patch addressing a specific Dash shell bug affecting heredoc handling. Patrick Steinhardt identifies a multibyte character quoting issue in Dash v0.5.13 where quoted heredocs incorrectly wrap multibyte sequences with CTLMBCHAR bytes (85 02 and 02 85). The bug causes test failures in several scripts when comparing expected vs actual output containing non-ASCII characters.

The patch works around the issue by converting quoted heredocs (`<<-\EOF`) to unquoted heredocs (`<<EOF`) in affected test files, including credential tests, rebase tests, quoted string tests, format-patch tests, shortlog tests, and send-email tests. The changes are mechanical and focused on making the tests pass with the known shell bug rather than fixing Dash itself. The commit message provides detailed technical analysis of the bug's symptoms and confirms it still exists in Dash master.

This appears to be a well-scoped, test-only change that doesn't affect production code behavior. The patch is part of a two-patch series addressing Dash compatibility issues, with this one focusing specifically on the multibyte heredoc problem. The changes are straightforward substitutions that should make the tests more robust when run with affected Dash versions.
