This is a feature patch series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort led by Patrick Steinhardt. Justin Tobler's 7-patch series builds on previous work to make ODB writes explicitly use the transaction interface rather than implicit redirection.

The key changes in this version include:
- Improved error handling and documentation
- Refactored stream interface to support error returns and caller-provided buffers
- Optimized packfile size limit handling by checking object sizes upfront
- Generalized packfile writes to use the `odb_write_stream` interface
- Made the `write_object_stream()` callback pluggable in the transaction interface

The series touches core object-file handling code affecting commands like `git add`, `git update-index`, and `git unpack-objects`. While mostly plumbing changes, patch 4 introduces a behavioral optimization by avoiding file descriptor seeks when packfiles would exceed size limits. The changes appear well-structured with clear commit messages explaining each preparatory step.

This work represents the final refinement of the interface boundaries before merging, completing a key part of the ODB abstraction effort. Patrick Steinhardt has reviewed all patches, and with all technical feedback addressed, the series looks ready for merging. The changes lay important groundwork for future storage backend improvements while maintaining backward compatibility.
