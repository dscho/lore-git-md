This is a refactoring patch in Justin Tobler's series completing the write operations interface for Git's object database (ODB) transactions. The patch splits blob handling into two distinct operations: pure hashing via a new `hash_blob_stream()` helper, and unconditional packfile writing via `index_blob_packfile_transaction()`. 

The key change removes the `INDEX_WRITE_OBJECT` flag check from the packfile writing path, making writes unconditional since the conditional logic now happens at a higher level in `index_fd()`. This prepares for making packfile writes part of the transaction interface in subsequent patches. The patch introduces `odb_write_stream_from_fd()` to create a stream from a file descriptor, used by both operations.

For future AI reference: The patch moves hashing logic from `index_blob_packfile_transaction()` to the new `hash_blob_stream()` in object-file.c, and adds `odb_write_stream_from_fd()` in odb/streaming.{c,h} to create streams from file descriptors. It removes the `flags` parameter from several functions including `prepare_packfile_transaction()` and `stream_blob_to_pack()`. The changes affect blob handling in commands like `git add` and `git update-index` when writing objects to the ODB.
