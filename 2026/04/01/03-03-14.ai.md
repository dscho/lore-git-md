Performance optimization and refactoring patch in the ODB abstraction series, focusing on packfile writes. This sixth installment in Justin Tobler's 7-part series generalizes packfile writing to use the new `odb_write_stream` interface rather than direct file descriptor operations.

The patch refactors `index_blob_packfile_transaction()` to accept a stream interface instead of a file descriptor, making the packfile write path more flexible for different data sources. Key changes include:
- Rewriting `stream_blob_to_pack()` to read from a stream rather than directly from a file descriptor
- Adding size validation to ensure the expected amount of data is read
- Updating callers to pass the stream interface through the transaction system

The changes maintain all existing functionality while enabling future backends to implement their own streaming strategies. This builds on previous patches that introduced the streaming infrastructure and optimized packfile size handling. Patrick Steinhardt has reviewed the series, and this patch appears consistent with the overall architectural direction of the ODB abstraction effort.
