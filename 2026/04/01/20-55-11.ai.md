This is a documentation patch in Toon Claes' ongoing series to enhance the `git replay` command with a `--ref` option. The patch standardizes the command's documentation and help text to use Git's preferred "stuck form" for options (e.g., `--onto=<newbase>` instead of `--onto <newbase>`), as recommended in gitcli(7). 

The changes are mechanical but important for consistency:
- Updates all option documentation in `Documentation/git-replay.adoc` to use stuck form
- Reorders some documentation sections to match the order in the manual
- Adjusts the command's usage string in `builtin/replay.c` to match
- Maintains all existing functionality while making the presentation more consistent with Git conventions

This patch follows the v3 changes that fixed a SIGABRT crash in merge-ort and hardened option parsing. The documentation updates here are complementary to those technical fixes, ensuring the command's interface is properly documented following Git's style guidelines. The changes are part of the broader effort to make `git replay` a more flexible plumbing command for manipulating commit history.
