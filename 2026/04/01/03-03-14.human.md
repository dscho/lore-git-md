This is the sixth patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. Justin Tobler refactors the packfile write path to use the new `odb_write_stream` interface rather than operating directly on file descriptors.

The key change generalizes `index_blob_packfile_transaction()` to accept a stream interface instead of an fd, allowing callers to supply blob data from arbitrary sources. The patch updates the streaming logic to use the stream's `read()` callback and tracks total bytes read to verify the expected size matches what was actually streamed. This maintains the existing packfile writing functionality while making it more flexible for future backends.

The changes affect core object-file handling used by commands like `git add` and `git update-index`. Patrick Steinhardt has reviewed the series, and this patch builds cleanly on the previous interface refinements. The series appears ready for merging as it completes an important piece of the ODB abstraction work.
