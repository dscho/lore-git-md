This is a preparatory patch in the parallel hook execution series, adding infrastructure needed for the upcoming hook.jobs configuration. It introduces a new `repo_config_get_uint()` helper function for reading unsigned integer config values, along with supporting functions in the config and parse subsystems.

The change is motivated by the need to properly handle the `hook.jobs` configuration that will be added in later patches. While the existing config API could handle this via `int` or `unsigned long`, the author argues unsigned int is the most appropriate type for this use case. The patch follows Git's standard pattern for config value helpers, adding parallel functions at each layer of the config stack (low-level parsing, configset, and repository-specific access).

The implementation is straightforward and well-contained, adding the expected supporting functions while maintaining consistency with existing config handling code. As part of the already-approved parallel hooks series, this change has effectively been reviewed by both Junio C Hamano and Patrick Steinhardt. It serves as a building block for the more user-visible parallel execution features that follow in the series.
