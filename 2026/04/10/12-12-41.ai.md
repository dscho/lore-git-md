This is part 11 of Patrick Steinhardt's 17-part series implementing an in-memory object database (ODB) backend, a key piece of the ongoing ODB abstraction effort. The patch implements the `for_each_object()` callback for the in-memory source, completing another core piece of the ODB interface.

The implementation handles both basic iteration and filtered iteration with object info population, supporting the full range of options that callers might pass. Key technical aspects include:
- A new `populate_object_info()` helper extracted from the existing read callback
- A callback adapter structure to pass iteration state through the oidtree traversal
- Support for both bare OID iteration and info-populated iteration
- Proper handling of iteration options (promisor/local flags and prefix filtering)
- The implementation uses the oidtree data structure (with O(1) lookups) that was refactored in earlier patches
- Maintains consistency with the existing ODB interface contract

This patch follows the established pattern of the series - thorough implementation of required callbacks with careful attention to interface contracts and proper state handling. The extraction of `populate_object_info()` is a nice cleanup that reduces duplication while making the code more maintainable. With this callback implemented, the in-memory ODB now provides complete coverage of the ODB source interface.
