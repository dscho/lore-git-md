This is a test patch (5/6) in Lorenzo Pegorari's v5 series on promisor file handling during repacks, part of their GSoC work mentored by Eric Sunshine. The patch adds comprehensive test coverage for verifying `.promisor` file content preservation after geometric repacks.

The test creates multiple packfiles with associated `.promisor` files containing ref mappings, then performs a geometric repack and verifies the merged `.promisor` file contains the expected OID-ref pairs from the repacked packs while excluding those from the larger pack. Key aspects tested include:
- Correct merging of ref mappings from multiple source `.promisor` files
- Proper exclusion of non-repacked packfile mappings
- Preservation of the "<oid> <ref>" format with timestamps
- Integration with geometric repacking thresholds

The test uses `test_commit_bulk` to generate packfiles, manually creates `.promisor` files with ref mappings, and verifies results with `test_grep`. It complements the earlier test in the series that verified basic promisor pack handling during geometric repacks.

This patch demonstrates the series' thorough approach to testing - it exercises the edge case of content merging during geometric repacks that was a key motivation for the original 5374a290 change. The test design follows Git's established patterns for packfile testing while adding specific validation of the debugging information preservation behavior.
