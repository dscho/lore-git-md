This is the first patch in the v9 series implementing customizable conflict markers for `git stash apply`. The patch adds three new options to `git stash apply`: `--label-ours`, `--label-theirs`, and `--label-base`, allowing users to specify custom labels for conflict markers instead of the default "Updated upstream"/"Stashed changes"/"Stash base".

The implementation:
1. Adds documentation for the new options in `git-stash.adoc`
2. Modifies `builtin/stash.c` to accept and pass through the new label parameters
3. Updates `xdiff/xmerge.c` to properly handle empty labels (a key feature for scripting use cases)
4. Adds comprehensive tests in `t/t3903-stash.sh` covering both custom labels and empty labels

The changes are well-contained and focused, with clear documentation and test coverage. The patch has been through nine iterations of review with all technical concerns addressed, including option naming standardization (now using `--label-*` prefix) and proper handling of edge cases like empty strings. This represents a clean, production-ready addition to the stash command's functionality.
