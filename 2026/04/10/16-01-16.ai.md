This is a code style clarification from Junio Hamano on Lorenzo Pegorari's promisor file repacking patch series. Junio points out that the current implementation uses non-standard timestamp formatting (`%lld` and `st_mtim.tv_sec`) and provides the preferred Git-style alternative using `PRItime` and `timestamp_t`.

The correction ensures consistency with Git's established patterns for handling timestamps, as seen in core components like the worktree and blame machinery. This is a minor but important style fix that brings the patch in line with project conventions. The change doesn't affect functionality but maintains codebase uniformity.

Key technical details for future reference:
- Replaces `%lld` with `PRItime` macro for portable timestamp formatting
- Uses `timestamp_t` type instead of direct `long long int` cast
- References `st_mtime` rather than `st_mtim.tv_sec` for compatibility
- Follows patterns established in `worktree.c`, `date.c`, and `builtin/blame.c`

This feedback represents the final polish on an otherwise well-structured patch that has already addressed all major technical concerns in previous iterations. The change is straightforward to implement and aligns with the project's coding guidelines.
