This is a feature patch implementing streaming read support for the in-memory object database backend, part of Patrick Steinhardt's ongoing ODB abstraction effort (patch 5/17 in v3 of the series). The patch adds the `read_object_stream()` callback to enable efficient streaming access to objects stored in memory.

The implementation follows the established pattern for ODB backends, creating a stream structure that tracks the current read position and provides the standard read/close operations. Objects are looked up in the in-memory oidtree and streamed directly from their memory buffers. The patch includes proper error handling when objects are not found.

This is one of the final pieces needed to make the in-memory backend fully functional, following earlier patches that implemented other required callbacks. The series has already received thorough review and is considered technically complete, with only minor terminology alignment in error messages remaining before integration. The careful implementation and test coverage suggest this is a robust addition to Git's object storage layer.
