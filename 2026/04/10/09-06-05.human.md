This is a refactoring patch in the parallel hook execution series, moving the `is_known_hook()` function from being static in builtin/hook.c to being exported in hook.c/hook.h for wider use. The change allows this utility function to be reused by other parts of the codebase that need to check if a given name is a recognized Git hook.

The patch makes several clean changes:
1. Moves the function implementation to hook.c with minor style improvements (using bool return type and renaming iterator to 'h')
2. Updates build systems (Makefile and meson.build) to reflect the new location of hook-list.h dependency
3. Adds proper documentation in hook.h for the now-public function
4. Includes a co-author credit for Patrick Steinhardt who helped with the meson.build changes

This is a straightforward preparatory change that enables the next patch in the series (which will use this function to validate hook names). The patch has already been reviewed as part of the larger parallel hooks series that has maintainer approval.
