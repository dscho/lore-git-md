This is patch 2/6 in Lorenzo Pegorari's v5 series on promisor file handling during repacks, part of his GSoC work mentored by Eric Sunshine. The patch introduces a helper function `copy_promisor_content()` that preserves debugging information in `.promisor` files when repacking promisor packfiles.

The function maintains ref-to-packfile mappings in `.promisor` files (which track which refs were fetched when the pack was downloaded) by copying them to new files after repacking. It handles both timestamped entries (from previously repacked files) and adds timestamps to new entries using the file's modification time. The implementation carefully checks which objects are actually present in the new pack and avoids duplicating entries.
