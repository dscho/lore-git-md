This is patch 2/17 in Patrick Steinhardt's series implementing an in-memory object database (ODB) backend, part of the ongoing ODB abstraction effort. The patch focuses on proper cleanup by implementing the `free()` callback for the in-memory source.

The change moves memory management responsibilities into the new ODB source infrastructure, cleaning up the previous ad-hoc approach. Key aspects:
- Defines the `struct cached_object_entry` in the header file since it's now shared between multiple compilation units
- Implements proper cleanup of in-memory objects when the source is freed
- Removes redundant cleanup code from `odb.c` since the new callback handles it
- Maintains the same functionality while better integrating with the ODB source abstraction

This is a straightforward but important piece of the larger series, ensuring proper resource cleanup for the in-memory storage.
