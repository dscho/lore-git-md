This is the final test patch in Lorenzo Pegorari's v4 series on promisor file handling during repacks, part of their GSoC work mentored by Eric Sunshine. The patch adds comprehensive test coverage for the geometric repack scenario, verifying that `.promisor` file contents are correctly preserved when packs are combined.

The test creates multiple packs with associated `.promisor` files containing OID-ref pairs, then performs a geometric repack and checks that:
1. The repacked `.promisor` file contains the expected OID-ref pairs from the two smaller packs
2. The timestamp format is preserved (verified via pattern matching)
3. The larger pack's `.promisor` contents are not incorrectly included

The test follows Junio Hamano's earlier feedback on test hygiene, using direct file operations and `test_grep` rather than shell variable manipulation. It builds on the series' earlier work to handle geometric repacks properly while maintaining the debugging information in `.promisor` files.

With this patch, the series appears complete - all prior feedback has been addressed, and the test coverage now spans both regular and geometric repack scenarios. The only remaining open question is about header inclusion policy, which doesn't affect this test patch. The thoroughness of the test implementation suggests this contribution is ready for final review and likely merging.
