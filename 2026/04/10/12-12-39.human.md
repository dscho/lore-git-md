This is a refactoring patch in Patrick Steinhardt's ongoing ODB (object database) abstraction series, specifically enhancing the oidtree data structure to support arbitrary payload storage. The patch is part of a 17-part series that's now in its third iteration and nearly ready for integration.

The change extends oidtree's capabilities beyond just storing object IDs - it now allows associating arbitrary data with each OID. This is a prerequisite for the in-memory ODB backend being introduced later in the series. The implementation:
- Adds a `data` field to `struct oidtree_node`
- Introduces new `oidtree_get()` to retrieve stored data
- Updates all callbacks to handle the new payload parameter
- Includes comprehensive unit tests verifying the new functionality
- Maintains backward compatibility with existing uses (passing NULL for data)

The patch is well-contained and follows the series' established patterns. It's been thoroughly reviewed and tested, with the only remaining discussion in the series being about terminology in error messages. This change represents a small but important building block in the larger ODB abstraction effort.
