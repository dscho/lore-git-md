This is a feature patch implementing streaming write support for the in-memory object database backend, part of Patrick Steinhardt's ongoing ODB abstraction series (v3, patch 7/17). The patch adds the `write_object_stream()` callback to handle chunked writes to the in-memory store, completing the streaming interface alongside the previously implemented read support.

The implementation buffers incoming chunks (using 16KB blocks) until the full object is received, then delegates to the existing `write_object()` function. It includes error handling for both over- and under-sized streams, maintaining the same safety guarantees as direct writes. The callback is registered in the source's vtable during initialization.

This represents the last major piece of the in-memory ODB's write interface, following the direct-write implementation in earlier patches. The careful error checking and reuse of existing write logic suggests this is a well-considered addition that maintains the series' high standard of implementation quality. With both streaming and direct write paths now complete, the backend provides full write capability for transient objects.
