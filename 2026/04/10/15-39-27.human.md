Final review feedback on the silent autostash patch in the `git checkout -m` series.

Phillip Wood provides a few small but important technical suggestions for the v8 patch that adds silent autostash creation capability. He questions the message output change (moving from stdout to stderr) and suggests using a bool type for the new `silent` parameter rather than `int`. These are minor refinements to an otherwise solid implementation that has already undergone extensive review.

The patch is part of a larger effort to improve conflict resolution during branch switching by integrating autostash behavior into `git checkout -m`. This particular change allows the sequencer to create stashes without printing status messages, which will be useful for automated operations while maintaining the existing verbose behavior for direct stash commands. The series as a whole is in its final stages, with all core functionality approved and only these last polish items remaining before merge.
