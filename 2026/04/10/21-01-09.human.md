This is the ninth iteration of a feature patch series that enhances `git checkout -m` to use autostash behavior when switching branches with conflicts. The series is now fully polished and ready for merging after extensive review.

The key improvements in v9 include:
1. Renamed the stash apply label flags from `--ours-label`/`--theirs-label`/`--base-label` to `--label-ours`/`--label-theirs`/`--label-base` for consistency with other Git commands
2. Fixed test cases to use `test_commit` for better isolation
3. Maintained the silent autostash creation capability added in previous versions
4. Kept support for empty conflict labels in stash application

The implementation provides:
- Customizable conflict markers via new label options in `git stash apply`
- Silent autostash creation during branch switching
- Unified conflict resolution behavior matching existing rebase/merge workflows
- Comprehensive test coverage (19 cases in t7201-co.sh)

The series has received maintainer approval through multiple iterations and addresses all feedback. The implementation is now production-ready with comprehensive documentation. This represents a significant quality-of-life improvement for branch switching workflows, particularly when working with uncommitted changes.

The patch series is authored by Harald Nordgren with input from Phillip Wood and Junio C Hamano. All technical concerns have been resolved, and the changes are well-tested and documented. The v9 iteration primarily focuses on final naming consistency and test improvements rather than functional changes.
