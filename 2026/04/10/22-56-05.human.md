This is a test patch in Lorenzo Pegorari's v5 series on promisor file handling during repacks, part of his GSoC work mentored by Eric Sunshine. The patch adds verification that geometric repacks correctly preserve the content of `.promisor` files, which store debugging information about ref-to-packfile mappings.

The test creates multiple packfiles with associated `.promisor` files containing ref mappings, then performs a geometric repack and verifies the resulting `.promisor` file contains the expected refs from the repacked packs while excluding those from the larger, unrepacked pack. This complements the earlier test in the series that verified basic promisor pack handling.

The test is thorough, covering:
- Multiple pack scenarios (small packs being repacked while a larger one remains)
- Manual creation of `.promisor` files with ref mappings
- Verification of both included and excluded content after repacking
- Clean test isolation with `test_when_finished`

This appears to be the final test coverage needed for the series, which has already addressed all previous feedback around timestamp formatting, header inclusion, and geometric repack integration. The test follows Git's established patterns and should provide robust validation of the promisor file preservation behavior.
