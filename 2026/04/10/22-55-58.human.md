This is a test patch (4/6) in Lorenzo Pegorari's v5 series on promisor file handling during repacks, part of his GSoC work mentored by Eric Sunshine. The patch adds test coverage to verify that `.promisor` file contents are correctly preserved during repacking operations.

The tests cover two scenarios: repacking with a single promisor packfile and repacking with multiple promisor packfiles. In both cases, the tests verify that the original content (object IDs and ref names) from the `.promisor` files is correctly copied to the new files after repacking, including proper handling of timestamps. The tests use `test_commit_bulk` to create test packs and manually simulate `.promisor` files to control the test conditions.

This patch follows the earlier technical improvements in the series, including standardized timestamp handling with `PRItime` and comprehensive header inclusion. The test design appears thorough, checking both the initial repack case and subsequent repacks to ensure stable behavior. The tests will help prevent regressions in promisor file handling, particularly for the geometric repacking scenarios that are part of this series' focus.
