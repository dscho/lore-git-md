This is a refactoring patch in Patrick Steinhardt's ODB abstraction series, specifically part 16/17 of v3. The patch makes the in-memory object database source more generic by changing its type from `struct odb_source_inmemory*` to the base `struct odb_source*` type.

The changes are mechanical but important for the in-memory ODB backend's integration with the broader ODB infrastructure. The patch updates all references to `inmemory_objects` to use the base type, including in the object info lookup path, object writing (`odb_pretend_object`), initialization (`odb_new`), and cleanup (`odb_free_sources`). The type change in `odb.h` reflects this more abstract interface.

This is part of the final polishing before integration, following the thorough technical review the series has already received. The changes maintain all existing functionality while making the in-memory source better aligned with the ODB abstraction's design. With this change, the in-memory source behaves more like other ODB backends from the perspective of the core object database code.
