This is part 13 of Patrick Steinhardt's 17-part series implementing an in-memory object database source, a feature that's part of the ongoing ODB abstraction effort. The patch implements the `count_objects()` callback for the in-memory backend, completing another piece of the ODB interface.

The implementation leverages the existing for_each_object() infrastructure by providing a simple callback that increments a counter. This maintains consistency with how other ODB backends handle object enumeration while keeping the code straightforward. The callback ignores the unused oid and object_info parameters, focusing solely on incrementing the counter passed through the callback data.

This patch follows the established pattern seen in previous parts of the series - implementing required ODB callbacks in a clean, minimal way while reusing existing infrastructure where possible.
