This is a refactoring patch from Patrick Steinhardt's ODB abstraction series, specifically modifying the cbtree implementation to support arbitrary wrapper structures. The change enables embedding `struct cb_node` in custom data structures while maintaining the tree's functionality.

The patch removes the flex array from `struct cb_node` and replaces it with a key offset mechanism stored in the containing `cb_tree`. This allows callers to define their own node structures that include both the tree node and their custom data. The oidtree implementation is updated to use this new approach, creating a proper `oidtree_node` structure that combines the base node with the object ID key.

Key technical changes:
- New `key_offset` field in `struct cb_tree` tracks where the key begins in wrapper structures
- `cb_node_key()` helper function computes key location for any node
- Oidtree now uses proper `struct oidtree_node` instead of manually aligning keys
- Memory allocation is simplified since padding/alignment is handled by the structure
- Small size increase (60->64 bytes per node) traded for cleaner architecture

The change appears well-motivated as it solves several awkward workarounds while maintaining all existing functionality. The implementation is thorough, updating both the core cbtree logic and its primary user (oidtree). This refactoring supports the broader ODB abstraction effort by providing more flexible data structures for object storage backends.
