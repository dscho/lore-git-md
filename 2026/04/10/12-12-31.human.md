This is the first patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source, part of the ongoing ODB abstraction effort. The patch lays the groundwork by creating the basic infrastructure for storing objects purely in memory, without persisting them to disk.

The implementation introduces a new `odb/source-inmemory.[ch]` pair that defines the in-memory backend structure and its initialization. Key changes include:
- Moving existing cached object handling into the new in-memory source structure
- Adding build system support for the new source files
- Defining the `odb_source_inmemory` struct to track objects stored in memory

The patch maintains all existing functionality while preparing for future extensions that will make this a fully-fledged ODB source. This is a foundational change that enables subsequent patches to implement the complete interface for reading, writing, and managing in-memory objects.
