This is a feature patch implementing streaming write support for the in-memory object database backend, part of Patrick Steinhardt's ongoing ODB abstraction series (now at v3). The patch adds the `write_object_stream()` callback to handle chunked writes, completing the streaming interface alongside the previously implemented read support.

The implementation buffers incoming chunks (using 16KB blocks) while verifying the total size matches expectations, then delegates to the existing `write_object()` function once all data is collected. Error handling ensures consistency if the stream provides too much or too little data. The change is straightforward and maintains the same behavior as direct writes while supporting streaming use cases.

With both read and write streaming now implemented, this marks another step toward the series' goal of providing a complete in-memory ODB backend. The patch follows the established pattern of the series and has already been reviewed by Karthik Nayak and Justin Tobler, with Junio Hamano indicating the technical implementation is sound. The only remaining discussion point is terminology alignment in error messages across the series.
