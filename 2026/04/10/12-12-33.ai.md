This is a refactoring patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source (part of the ongoing ODB abstraction effort). The patch removes a redundant object existence check in `odb_pretend_object()`.

The function writes objects to the in-memory ODB source without persisting them to disk. Currently it performs two checks for existing objects: first via `odb_has_object()` (which already checks the in-memory source internally through `find_cached_object()`), and then again via `find_cached_object()` directly. This patch eliminates the redundant second check.

The change is straightforward and clearly motivated - it removes unnecessary work while maintaining the same behavior. The patch is small (3 lines changed) and focused on a single optimization. As part of a well-reviewed series that's already received technical approval from Karthik Nayak and Justin Tobler, this change appears uncontroversial and ready for integration.
