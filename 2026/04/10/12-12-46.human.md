This is a refactoring patch in Patrick Steinhardt's ODB abstraction series, making the in-memory object database implementation more generic. It's the 16th patch in a 17-part series that's nearly ready for integration.

The change simplifies the interface by removing direct dependency on the `odb_source_inmemory` structure, instead using the more general `odb_source` type throughout the code. This makes the in-memory source behave like any other ODB source while maintaining all functionality. The patch updates four call sites in `odb.c` and one type declaration in `odb.h` to use the generic interface.

This is a mechanical change that follows from earlier architectural decisions in the series. The implementation remains exactly the same - it just presents a cleaner interface to the rest of the system. The patch is small (5 lines changed) and since the series has already undergone extensive review, this appears to be a straightforward cleanup before final integration.
