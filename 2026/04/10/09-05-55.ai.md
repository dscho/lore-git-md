This is the final version (v7) of the parallel hook execution feature series, now incorporating a SIGPIPE test from Jeff King. The series builds on Adrian Ratiu's configurable hooks work to enable concurrent execution of hooks with extensive configuration options.

The v7 refresh adds one new commit (13/13) with a test case for SIGPIPE handling in parallel hook execution, addressing a recent master branch fix. The core functionality remains unchanged from v6, which had already received maintainer approval from both Junio C Hamano and Patrick Steinhardt. The series provides a comprehensive configuration system with global (`hook.jobs`), per-hook (`hook.<name>.parallel`), per-event (`hook.<event>.jobs`), and CLI (`-j/--jobs`) controls, plus a new `hook.<event>.enabled` master switch.

Implementation spans multiple subsystems including new config helpers (`repo_config_get_uint()`), strmap caching, transport.c integration for pre-push hook output handling, and updates to builtins requiring serial execution. Seven commit/checkout-related hooks remain permanently serialized for safety. The series includes extensive test coverage in t/t1800-hook.sh and has been rebased on current master with successful CI runs.

This represents the culmination of multi-iteration development, now ready for merging with all technical concerns addressed. The final patch from Jeff King ensures robust SIGPIPE handling, completing the parallel execution safety story. The work enables significant performance improvements for hook-heavy workflows while maintaining backward compatibility through careful design of the configuration hierarchy and opt-in requirements for potentially problematic cases like pre-push hooks.
