This is a preparatory patch in the parallel hook execution series, adding infrastructure needed for the upcoming hook.jobs configuration. It introduces a new `repo_config_get_uint()` helper function and supporting parsing utilities to handle unsigned integer configuration values properly.

The patch adds a complete set of unsigned int config functions mirroring the existing int/ulong APIs: `git_config_uint()`, `git_configset_get_uint()`, and `repo_config_get_uint()`, plus a new `git_parse_uint()` parser. The implementation is straightforward, following the same patterns as the existing config value handling. The commit message explains the rationale for adding unsigned int support rather than using int or ulong alternatives.

This is a clean, focused addition that will be used by subsequent patches in the series to handle the hook.jobs configuration. The change is well-contained, touching only config and parse infrastructure without affecting any existing behavior. As part of the already-approved parallel hooks series, this patch represents uncontroversial plumbing work to support the larger feature.
