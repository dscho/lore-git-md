Feature patch implementing silent autostash creation for branch switching workflows. This is the second patch in a v9 series that enhances `git checkout -m` with autostash behavior and has been through extensive review iterations.

The patch adds a `silent` parameter to the internal autostash creation function and introduces a new `create_autostash_ref_silent()` API that suppresses the "Created autostash" message. This enables silent operation when needed while maintaining the existing verbose behavior for other callers. The implementation modifies `sequencer.c` to conditionally print the message based on the `silent` flag and adds the new public declaration in `sequencer.h`.

Key technical details:
- New function `create_autostash_ref_silent()` provides the silent variant
- Modified `create_autostash_internal()` now takes a `bool silent` parameter
- Message printing is controlled via the `silent` flag
- Existing callers continue using the non-silent variants
- The change is part of a larger effort to unify conflict resolution behavior across Git commands

The patch follows the series' established pattern of careful, incremental changes and maintains compatibility with existing autostash workflows. It addresses all feedback from previous iterations, including proper boolean typing for the `silent` parameter. The series as a whole is now considered production-ready with comprehensive test coverage.
