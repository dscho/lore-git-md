This is a documentation formatting follow-up in the thread about AsciiDoc indentation fixes in the Git glossary. Jeff King responds to Kristoffer Haugsbakk's observation about `+` artifacts appearing in HTML output when using `make html`.

King confirms the artifacts only appear when building with asciidoctor (not asciidoc), suggesting a difference in how the two tools handle nested entries in open blocks. He notes this affects both HTML and doc-diff output. While asciidoc appears to handle the nested entries correctly, asciidoctor's behavior reveals an edge case in the formatting approach.

The response indicates King has identified a workaround for the asciidoctor-specific issue, which he plans to share shortly. This moves the discussion forward from problem identification to solution development, while maintaining the thread's tight focus on documentation rendering details.
