This is a documentation formatting fix addressing AsciiDoc indentation issues in the Git glossary. Jeff King follows up on earlier discussion about rendering artifacts that appeared when using asciidoctor (but not asciidoc) to build the documentation.

The patch fixes ambiguous list continuation markers in glossary entries for "glob", "pathspec", and irregular refs. King explains the subtle interplay between nested lists and open blocks in AsciiDoc syntax, where continuation markers ("+") can be misinterpreted when sub-lists are involved. He provides two different workarounds - using extra blank lines before continuations in some cases and explicit open block markers ("--") in others - to ensure consistent rendering across both asciidoc and asciidoctor toolchains.

The changes are purely presentational, with no modifications to the actual glossary content. The patch demonstrates Git's attention to documentation quality, particularly around cross-tool compatibility in the build pipeline. King's thorough analysis and solution reflect his deep understanding of both Git's documentation system and AsciiDoc's nuances.
