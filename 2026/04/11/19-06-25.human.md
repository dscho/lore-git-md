This is a documentation patch fixing indentation issues in the Git glossary. Jeff King noticed that when glossary entries contain sub-lists (bullet points), the AsciiDoc formatting can cause subsequent paragraphs to be incorrectly indented as if they were part of the final bullet point rather than the main definition.

The patch fixes this by using "--" markers to properly scope sub-lists in three glossary entries: "glob", "gitattributes", and "ref". This ensures paragraphs following sub-lists maintain correct indentation levels. The changes are mechanical and focused on formatting rather than content.

The fix is straightforward and well-explained, with clear before/after examples showing the problem and solution. As a documentation improvement from a long-time contributor known for attention to detail, this patch is likely to be uncontroversial and quickly accepted.
