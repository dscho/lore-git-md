Documentation patch correcting an earlier misstatement about `git am --message-id` behavior. Kristoffer Haugsbakk reverts part of their own earlier commit (3c18135b) that incorrectly claimed the `--message-id` option adds the Message-ID header as a Git trailer. The patch explains that the option actually appends the Message-ID line directly after the message body when there are no existing trailers, which is inconsistent with trailer behavior. 

The change is framed as a documentation correction rather than a behavior fix to avoid last-minute changes in the release cycle. The patch keeps one improvement from the original commit - using inline-verbatim for `Message-ID` in the docs. This is a single-file change to `Documentation/git-am.adoc`, reverting the misleading description while preserving the accurate parts of the commit message provides clear examples of the actual behavior versus the previously documented behavior.
