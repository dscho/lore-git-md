This is a documentation patch fixing indentation issues in the Git glossary. Jeff King noticed that when glossary entries contain sub-lists (bullet points), the AsciiDoc formatting can cause subsequent paragraphs to be incorrectly indented as if they were part of the final bullet point rather than the main definition.

The patch fixes this by using "--" markers to properly scope sub-lists in several glossary entries: "glob", "pathspec", and irregular refs in the root hierarchy. Each change wraps the bulleted list in a block delimiter to prevent the following paragraph from being incorrectly nested. The changes are mechanical but important for correct rendering of the documentation.

The patch is straightforward and clearly motivated, with examples showing both the incorrect and corrected formatting. As expected from Jeff King, it's a small but precise fix with a thorough commit message explaining the issue. The changes affect only documentation formatting and don't modify any actual content.
