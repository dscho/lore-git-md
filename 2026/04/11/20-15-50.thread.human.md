The thread documents a correction to the `git am --message-id` documentation. Kristoffer Haugsbakk identified and fixed an inaccuracy in their own earlier commit (3c18135b) that incorrectly described how the option behaves. The original documentation mistakenly claimed `--message-id` adds the Message-ID header as a Git trailer, when in fact it appends the line directly after the message body when no trailers exist. 

Rather than changing the behavior at this stage, Kristoffer opted for a documentation-only fix to avoid last-minute changes in the release cycle. The patch preserves one improvement from the original commit - using inline-verbatim formatting for `Message-ID` in the docs - while correcting the misleading description. The change is limited to `Documentation/git-am.adoc` and includes clear examples contrasting the actual behavior with what was previously documented.
