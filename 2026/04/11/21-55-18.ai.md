This is a documentation formatting patch addressing AsciiDoc rendering issues in the Git glossary. Jeff King follows up on earlier discussion about indentation problems in sub-lists, providing a more comprehensive fix that works across both asciidoc and asciidoctor toolchains.

The patch targets four specific glossary entries ("glob", "attr", and two "refs" sections) where nested lists were causing incorrect indentation in the rendered output. King explains the core issue: when a definition contains a sub-list, the "+" continuation markers can become ambiguous about which level they refer to. The original fix using "--" block delimiters worked for asciidoc but caused artifacts in asciidoctor.

King's solution employs two complementary techniques: using extra blank lines before "+" markers to clarify nesting levels in some cases, and falling back to "--" markers where that approach doesn't work. He notes the irregular behavior in the "refs" section appears to be an asciidoctor bug, but provides a workaround. The patch produces identical output in both doc-diff and HTML formats across both documentation toolchains.

This demonstrates Git's attention to documentation rendering details, particularly cross-tool compatibility. The fix is narrowly scoped to formatting issues without changing glossary content, maintaining the thread's focus on presentation rather than substance.
