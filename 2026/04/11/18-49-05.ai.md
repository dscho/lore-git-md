This is a test patch review in Lorenzo Pegorari's v5 series on promisor file handling during repacks. Tian Yuchen provides implementation feedback on patch 5/6, which tests `.promisor` file content preservation after geometric repacks.

Tian identifies several shell scripting issues in the test implementation:
1. The use of `ls` to find packfiles is problematic (violating the "never parse ls" principle)
2. Unquoted `$path` variable could break with spaces in paths
3. The sed substitution for `.pack` to `.promisor` is fragile and could match unintended paths
4. The approach may fail if paths contain literal ".pack" strings

The review maintains the technical focus of the series while pointing out specific shell scripting anti-patterns that could make the test unreliable. Tian suggests these are implementation details rather than fundamental flaws in the test's purpose or design. The feedback doesn't challenge the core functionality being tested (promisor file merging during geometric repacks) but rather the robustness of the test implementation itself.
