Test fix addressing a shell scripting edge case in the test suite.

SZEDER Gábor identifies a potential issue in the `t6112-rev-list-filters-objects.sh` test where unquoted tildes in grep patterns could lead to tilde expansion. While unlikely to trigger in practice (since the variables contain object hashes), this could cause problems if a system user happened to have a matching username. The patch also notes that some Bash versions (v3.2 and v5.0) handle this case particularly poorly, potentially segfaulting.

The fix is straightforward - simply quoting the grep patterns containing tildes. This is a defensive change that follows shell scripting best practices. The patch is small, well-explained, and clearly addresses a real (if unlikely) issue. It's part of ongoing test suite maintenance rather than any larger effort.
