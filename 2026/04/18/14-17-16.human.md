This is patch 4/6 in Lorenzo Pegorari's GSoC project to improve promisor file handling during repacks. The patch adds test coverage to verify that `.promisor` file contents (which track ref-to-packfile mappings for partial clones) are correctly preserved across repack operations.

The tests demonstrate two scenarios:
1. A single pack with a manually created `.promisor` file, verifying the content (object ID and ref) is preserved after repacking
2. A more complex case with two packs and their corresponding `.promisor` files, checking that both sets of information are correctly merged and maintained

The test implementation shows careful attention to robustness - using `find` instead of `ls` for pack discovery, proper path quoting, and clear verification steps. The tests also validate that subsequent repacks don't alter the preserved content.

This appears to be a well-constructed test addition that complements the core functionality added in earlier patches. The test cases cover both basic and edge cases while following Git's test conventions. With help from Tian Yuchen and Junio Hamano, the patch looks ready for inclusion.
