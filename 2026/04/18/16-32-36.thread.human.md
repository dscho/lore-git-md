This thread addresses a subtle shell scripting issue in Git's test suite. The original test in `t6112-rev-list-filters-objects.sh` used unquoted tildes in grep patterns to verify composite filters, which could theoretically cause problems if a system username matched an object hash. SZEDER Gábor identified two concerns: potential unwanted expansion and known Bash version quirks (v3.2-v5.0) that might segfault.

The fix is straightforward - adding quotes around the grep patterns containing tildes. This small change (3 lines modified) makes the test more robust against shell expansion edge cases while maintaining the original test's purpose. The patch has no impact on Git's core functionality, just improving test reliability.
