This is the final version of Elijah Newren's performance optimization series for partial clone behavior in `git cherry` and `git grep`. The series is now ready for merging after addressing the maintainer's feedback to remove an extraneous design document that was accidentally included in v1.

The key improvements remain unchanged from the initial submission:
1. Adds batch prefetching to `git cherry` to avoid hundreds of individual blob fetches when comparing commits in partial clones
2. Extends similar prefetching to `git grep` as a related optimization
3. Includes tests verifying the behavior in both commands

The implementation follows established patterns from other commands that already support batch prefetching (checkout/diff/merge). The changes are focused and well-contained, touching only:
- `builtin/log.c` for the cherry prefetch logic
- `builtin/grep.c` for grep prefetching
- Test files with new test cases
- A minor doc fix in `patch-ids.h`

With the accidental inclusion of the design document now removed, this series appears ready for integration. The optimizations should provide measurable performance benefits for partial clone users of these commands, particularly in workflows that heavily use `git cherry`.
