This is a test fix addressing a subtle shell scripting issue in the test suite. The patch corrects tilde expansion behavior in `t6112-rev-list-filters-objects.sh` that could theoretically cause problems if a system user happened to have a username matching an object hash.

The test was introduced in 2019 to verify composite object filters, using unquoted tildes in grep patterns to check for omitted objects. SZEDER Gábor points out two issues: first, the unquoted tildes could trigger unwanted path expansion if a matching username exists (though unlikely with hash values), and second, some Bash versions (v3.2-v5.0) handle this expansion poorly, potentially causing segfaults.

The fix simply adds quotes around the grep patterns containing tildes, making the test more robust against shell expansion quirks. This is a straightforward improvement to test reliability with no functional impact on Git itself. The change is small (3 lines modified) and clearly motivated, addressing both a potential edge case and known shell implementation bugs.
