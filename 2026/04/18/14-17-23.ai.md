This is a test patch (5/6) in Lorenzo Pegorari's v6 series on preserving promisor file content during repacks, part of their GSoC project. The patch adds test coverage specifically for geometric repacks, verifying that `.promisor` files maintain their ref-to-packfile mappings correctly after this type of repack operation.

The test creates multiple packs with associated promisor files, performs a geometric repack, and then checks that the resulting promisor file contains the expected ref mappings from the packs that were actually repacked (while excluding those that weren't). The test uses robust shell constructs like `find` and `sed` for path handling rather than fragile `ls` parsing, following Git's test suite best practices.

Key technical points:
- Tests both single and multiple pack scenarios
- Uses `test_commit_bulk` to generate test objects
- Verifies content preservation through `test_grep` checks
- Includes proper cleanup via `test_when_finished`
- Maintains test isolation with a dedicated repository
