This is the fourth patch in Lorenzo Pegorari's v6 series improving promisor file handling during repacks, part of his GSoC project. The patch adds test coverage to verify that `.promisor` file contents (which track ref-to-packfile mappings for partial clones) are correctly preserved during repacking operations.

The tests demonstrate two scenarios:
1. A single pack with one `.promisor` file, verifying the content is preserved across repacks
2. Multiple packs with distinct `.promisor` files, checking merged contents are maintained

Key technical aspects:
- Uses `test_commit_bulk` to create test packs
- Manually creates `.promisor` files with ref/oid mappings
- Verifies content preservation using `test_grep` and `test_cmp`
- Handles path discovery robustly with `find` and `sed` (addressing earlier shell parsing concerns)
- Includes cleanup via `test_when_finished`

The tests complement the core functionality added in earlier patches, providing verification that the repack logic correctly handles both simple and merged promisor file cases. This continues the series' pattern of thorough test coverage that has been refined through multiple review iterations.
