The test, originally added in 2019 to verify composite object filters, used unquoted tildes in grep patterns to check for omitted objects. SZEDER Gábor identified two issues: potential unwanted path expansion if a system username matched an object hash (unlikely but possible), and problematic handling in Bash versions 3.2 through 5.0 that could lead to segfaults.

The solution adds quotes around the grep patterns containing tildes, making the test more robust against shell expansion edge cases and Bash implementation quirks.
