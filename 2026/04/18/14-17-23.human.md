This is a test patch (5/6) in Lorenzo Pegorari's GSoC series about preserving promisor file content during repacks. The patch adds validation that geometric repacks correctly maintain the ref-to-packfile mappings in `.promisor` files, which are used by partial clone operations.

The test creates multiple packs with associated promisor files, performs a geometric repack, and verifies that:
1) The repacked promisor file contains the expected refs from the two smaller packs that were merged
2) The larger pack's promisor content is not incorrectly included
3) The test uses robust shell scripting practices (avoiding `ls`, using `find` and `sed` safely)
4) Includes proper cleanup via `test_when_finished`

This builds on the core implementation from earlier patches, which introduced the `write_promisor_file_after_repack` helper function. The test demonstrates the geometric repack case works as intended, complementing the existing test coverage for regular repacks. Junio Hamano provided guidance on the test approach (credited as Helped-by).

The patch follows Git's test conventions well - it's isolated, self-documenting, and verifies both positive and negative cases. With this addition, the series now has comprehensive test coverage across both repack types, addressing one of the final review points before potential merging.
