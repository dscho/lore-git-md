This is a test patch (4/5) in Kristoffer Haugsbakk's series introducing the new `git format-rev` command. The patch adds a dedicated regression test for the `--annotate-stdin --name-only` option combination in `git name-rev`, which was recently refactored to use a new command abstraction.

The test ensures proper handling of name-only output when processing stdin, catching potential regressions in the command's core formatting behavior. It exercises the same code path that will be shared with the upcoming `format-rev` command, verifying that the refactored infrastructure works correctly before the new command is introduced in the final patch of the series.

The test follows the pattern of existing tests in t6120-describe.sh, comparing sorted output from direct `name-rev` calls against the stdin-processing variant. This maintains consistency of the test suite while covering the newly important code path. The patch demonstrates careful attention to test coverage as part of the larger architectural change.
