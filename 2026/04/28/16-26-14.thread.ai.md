Thread identity: Patch series by Johannes Schindelin (Git for Windows maintainer) addressing Windows platform limitations with large objects (>4GB) during cloning process, focusing on truncation issues caused by 32-bit types on Windows-specific paths. Current series spans 11 patches (v2) covering index-pack/unpack-objects (1/11), zlib wrapper (2/11), ODB/packfile streaming (3/11), delta header handling (4/11), test infrastructure (5/11,8/11,9/11,10/11), regression tests (6/11), with final CI integration (11/11).

Core problem: Windows' 32-bit types (unsigned long, zlib's uLong) cause object size truncation in critical paths during cloning, preventing correct handling of objects >4GB. The series systematically replaces these with 64-bit size_t while maintaining compatibility, with each patch targeting a different component.
