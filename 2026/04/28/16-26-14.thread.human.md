Johannes Schindelin has completed his 11-patch series addressing Windows' handling of large objects (>4GB) during cloning, with the final patch focusing on CI integration. The series systematically replaces 32-bit types with 64-bit size_t across critical paths (index-pack, zlib wrappers, ODB streaming) to prevent truncation, while adding comprehensive test infrastructure including a new `test-tool synthesize pack` command and precomputed pack optimizations that reduced test generation time from hours to seconds.

Key reviewers Derrick Stolee and Jeff King raised concerns about resource usage, leading to EXPENSIVE test classification and now this final CI optimization - the expensive tests will only run on integration branch pushes, not every PR. The series maintains Windows fixes while pragmatically addressing runtime concerns, completing with platform-specific validation that won't burden routine CI. Some loose ends like cat-file paths remain for future work, but the core cloning functionality is now robust for large objects on Windows.
