This is a final refinement patch in the long-running `checkout -m` autostash feature series, now adding silent operation capability for autostash creation. The patch modifies the sequencer internals to allow callers to suppress the "Created autostash" message when needed.

The key change introduces a `silent` parameter to `create_autostash_internal()` and exposes it through `create_autostash_ref()`. This gives merge operations control over whether to display the autostash creation message. The implementation maintains all existing behavior while adding the new flexibility.

This is part of the v16 series that concludes a 20-iteration effort (14 pre-merge + 6 post-merge) to implement autostash behavior for conflicted branch switches. The series has already addressed all major technical concerns and is now focused on final polish items like this one. The patch demonstrates careful attention to interface design, adding the new capability without disrupting existing callers.
