This is a bugfix patch series targeting a Windows-specific deadlock in the geometric repacking strategy of `git maintenance`. The issue occurs when mmap'd pack index files prevent child processes from deleting old packfiles on certain Windows 10 versions.

The root cause is that `maintenance_task_geometric_repack()` fails to set `child.odb_to_close` when spawning `git repack`, unlike other maintenance tasks. This leaves mmap'd files locked, triggering deletion failures on pre-POSIX-delete Windows 10 builds. The fix adds the missing ODB closure.

Notably, the series includes a test helper (`GIT_TEST_LEGACY_DELETE`) to simulate the legacy Windows delete behavior on modern systems, allowing the regression test to verify the fix works even on Windows 11. This demonstrates thoughtful testability design for platform-specific issues.

The patch comes from Johannes Schindelin, Git for Windows maintainer, addressing a real-world issue reported in the Git for Windows issue tracker. The changes are focused and well-explained, with the Windows-specific nature clearly documented. The two-patch structure separates the test infrastructure addition from the actual bugfix, following good patch-series hygiene.
