This thread addresses a Windows-specific deadlock that occurs during geometric repacking in `git maintenance`, reported and fixed by Johannes Schindelin (Git for Windows maintainer). The issue affects pre-POSIX-delete Windows 10 where mmap'd pack index files prevent child processes from deleting old packfiles. Johannes provided a two-patch series with both test infrastructure and the actual fix.

The first patch introduced `GIT_TEST_LEGACY_DELETE` to simulate legacy Windows delete behavior on modern systems, incorporating Patrick Steinhardt's suggestion to use `git_env_bool()` for environment variable parsing. The second patch fixes the deadlock by properly setting `odb_to_close` in the maintenance task. The solution maintains backward compatibility across all Windows versions while following established patterns from other maintenance tasks.

The series has now received positive reviews from key domain experts - Derrick Stolee (who reviewed equivalent patches in Git for Windows) and Patrick Steinhardt (who confirmed his earlier feedback was properly addressed). Patrick's latest message serves as final approval, noting the correct implementation of his `git_env_bool()` suggestion. With all technical discussion points resolved and multiple approvals in place, the series appears ready for merging. The added test infrastructure may prove valuable for future Windows compatibility testing scenarios beyond this specific issue.
