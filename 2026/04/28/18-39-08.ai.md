This is a feature patch adding customizable conflict marker labels to `git stash apply`, part of the concluded 20-iteration effort implementing autostash behavior for `git checkout -m`. The patch introduces three new options:

1. `--label-ours=<label>` - Custom label for the upstream side in conflict markers
2. `--label-theirs=<label>` - Custom label for the stashed side
3. `--label-base=<label>` - Custom base label (only affects diff3-style conflicts)

The implementation modifies `builtin/stash.c` to pass these labels through to the merge machinery, with the existing defaults ("Updated upstream", "Stashed changes", "Stash base") preserved when no custom labels are provided. The documentation is updated in `git-stash.adoc` and new tests verify both custom labels and empty label cases.

Key technical details:
- Labels are passed through `struct merge_options` to `xdiff/xmerge.c`
- Empty strings are handled specially to produce unlabeled markers
- The diff3-style conflict markers respect all three labels
- Test coverage includes verification of marker formatting and edge cases

This represents the final polish on the autostash feature, with all architectural considerations around stash message handling explicitly deferred to future work. The patch is well-tested and follows the established patterns from the larger series.
