This is a patch in the final refinement series for the `checkout -m` autostash feature, adding silent operation capability to autostash creation. The patch modifies the sequencer internals to allow callers to suppress the "Created autostash" message when needed, particularly for programmatic use cases.

The key changes are:
1. Adds a `silent` parameter to `create_autostash_internal()` to control message output
2. Extends `create_autostash_ref()` to accept both a custom message and silent flag
3. Updates callers in `builtin/merge.c` to use the new interface while maintaining current behavior (non-silent with default message)
4. Preserves all existing functionality while adding the new capability

This represents one of the final polish items in a 20-iteration effort to implement robust autostash behavior for conflicted branch switches. The change is straightforward and well-contained, touching only the sequencer subsystem and its callers. The patch maintains backward compatibility while enabling cleaner integration for automated tools that might use the autostash functionality internally.

The implementation follows Git's established patterns for quiet/silent operation modes and demonstrates the project's attention to both user-facing output and programmatic interfaces. This was identified as a needed refinement during the extensive review process and now concludes that aspect of the feature.
