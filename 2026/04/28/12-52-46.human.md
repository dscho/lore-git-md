This is a bugfix targeting Windows-specific behavior in Git's geometric repacking during maintenance. The patch series from Johannes Schindelin (Git for Windows maintainer) addresses a deadlock that occurs when running `git repack` under certain Windows versions.

The core issue involves mmap'd pack index files preventing their deletion during repacking on older Windows 10 builds (pre-POSIX delete semantics). The fix properly releases these files by setting `child.odb_to_close` before spawning the repack process, matching behavior in other maintenance tasks.

The series includes:
1. A test helper to simulate legacy Windows delete behavior (useful for regression testing even on modern Windows)
2. The actual fix to release index files before repacking

This resolves a specific Git for Windows issue (#6210) where fetch-triggered maintenance would fail with "Unlink of file failed" errors. The changes are well-motivated and narrowly scoped, with appropriate test coverage added. Given Schindelin's deep Windows expertise and the clear reproduction scenario, this appears to be a solid fix for a real-world problem affecting Windows users.
