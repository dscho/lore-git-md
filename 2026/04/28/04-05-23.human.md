This is a 3-patch series refactoring how `git log -L` (line-log) integrates with Git's diff output pipeline. The goal is to make line-log behave more consistently with other diff formats by routing it through the standard `log_tree_diff()` path rather than using a custom output function.

The key improvements are:
1. Fixes issues where pickaxe (`-S/-G`) and `--diff-filter` weren't properly suppressing commits when all line ranges were filtered out
2. Aligns commit/diff separator formatting with regular log output
3. Enables non-patch diff formats (`--raw`, `--name-only`, etc.) to work with `-L`, though stat formats remain blocked as they'd show whole-file stats
