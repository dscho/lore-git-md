Bugfix follow-up review. Jeff King (Peff) reviews Junio C Hamano's backport of Justin Tobler's fix for an ODB transaction segfault when running `git diff` outside a repository on large files. The core fix - splitting hashing-only and object-writing paths in `index_fd()` - looks correct to Peff, though he notes the test case has a technical issue: it changes directory without a subshell, affecting subsequent tests. He suggests using the existing "nongit" test wrapper instead.

Peff also observes that while the original bug was found via `git diff`, it could be demonstrated more simply with `git hash-object`. These are minor refinements to an otherwise sound fix that has already been verified across multiple Git versions. The review maintains the patch's trajectory toward stable releases while catching a test pollution issue that should be addressed before final inclusion.
