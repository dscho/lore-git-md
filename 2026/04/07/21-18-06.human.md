Bugfix for an ODB transaction segfault when diffing large files outside a repository. This is Junio Hamano's response to Justin Tobler's patch that fixes a NULL dereference in `index_fd()` when hashing (but not writing) objects outside a repository context.

Junio confirms the bug was introduced in v2.52.0-rc0 and has backported the fix to maintenance branches (maint-2.52, maint-2.53) while also applying it to master. The fix avoids ODB transactions when only object hashing is needed, using a new `hash_blob_stream()` helper instead. Junio adjusted the patch slightly to apply cleanly to older versions and is asking Justin to verify the backported versions look correct.

This is a straightforward bugfix with clear reproduction steps and test coverage. The change is now in Junio's hands for integration, suggesting it will likely appear in the next maintenance releases. The fix is technically sound and uncontroversial - it cleanly separates the hashing-only case from the object-writing path that requires transactions.
