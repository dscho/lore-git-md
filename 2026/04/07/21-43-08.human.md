Bugfix for ODB transaction interface, now confirmed for backport. Justin Tobler reviews Junio C Hamano's backported version of his fix for a segfault that occurs when running `git diff` outside a repository with large files (exceeding core.bigFileThreshold). The issue stemmed from the ODB transaction logic incorrectly activating during object hashing operations that don't require writing objects.

Justin confirms the backported patch correctly addresses the issue in the v2.52 codebase where the ODB transaction interface was first introduced. He notes he'll address Jeff King's test improvement suggestions (wrapping directory changes in subshells and simplifying the test case) separately. The core fix remains unchanged - it properly separates hashing-only operations from object-writing paths in `index_fd()` by introducing a new `hash_blob_stream()` helper.

This marks the final confirmation needed before the backport can proceed to maintenance branches, showing the project's multi-version maintenance process in action. The fix has now received thorough review from both the original author (Justin) and a senior contributor (Jeff King), with Junio shepherding the backport process.
