This is Junio Hamano's biweekly "What's cooking in git.git" status report, summarizing the state of in-progress topics in the Git project. The report covers both recently merged topics and new work under discussion.

Several topics have recently graduated to 'master' (the main development branch), including:
- A fix for child process handling in transport-helper and connect code
- Cleanups around the hooks-in-config feature
- Backfill command improvements for revision and pathspec handling
- C23 compatibility fixes for const-correctness
- Various build system and platform-specific updates
- Documentation improvements for format-patch and gitignore
- Performance optimizations for rev-list and pack-objects
- Replay command enhancements for reverting commits

New topics under discussion include:
- Test suite updates to explicitly handle bare repositories
- Memory usage improvements in the diff algorithm
- Conditional config includes based on worktree paths
- Enabling Rust support by default in Git 2.54
- Graph output improvements for multi-root histories
- Config file locking with timeout retries
- Reducing the_repository usage in the refs subsystem
- Fixes to cache-tree validation logic
- Optimizations for rev-list --maximal-only
- Documentation updates to use synopsis style
- Promisor remote debugging info preservation
- Parallel hook execution support
- Filesystem monitor implementation for Linux
- Various ongoing efforts to remove the_repository global variable
- MIDX (multi-pack-index) repacking improvements
- Object database abstraction work
- Several test cleanups and modernization efforts

The report also notes several topics that are awaiting rerolls or further review before being considered for merging. This comprehensive update provides a snapshot of Git's active development areas, with a mix of new features, performance work, code cleanups, and ongoing architectural efforts.
