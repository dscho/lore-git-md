Bugfix follow-up review. Jeff King (Peff) reviews Junio C Hamano's backported version of Justin Tobler's ODB transaction fix, confirming the core correctness of the new `hash_blob_stream()` helper function that avoids object database transactions when only hashing is needed. While approving the technical approach, Peff identifies three test improvements needed before the backport can proceed.

First and most critically, the test case modifies the working directory with a bare `cd` that affects subsequent tests - this needs to be wrapped in a subshell or use the existing `nongit` helper. Second, he notes the bug could be demonstrated more simply with `git hash-object` rather than `git diff`. Third, he suggests stylistic tightening of parentheses in the conditional check, though acknowledges this is a matter of taste.

The review maintains the project's high standards for test hygiene while validating the core fix's soundness. Peff's comments focus on making the test suite robust rather than questioning the underlying solution, which he confirms meets the need. This moves the backport closer to completion with clear, actionable feedback.
