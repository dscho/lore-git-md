This is a refactoring patch in Christian Couder's series to improve promisor-remote handling. The change simplifies memory management by keeping accepted `promisor_info` structs alive longer rather than immediately freeing them and reconstructing their data in separate structures.

The patch modifies `filter_promisor_remote()` to maintain a single list of accepted remotes (`accepted_remotes`) instead of splitting the data across three parallel structures (`accepted` strvec, `accepted_filters` string_list, and the original `promisor_info`). This makes the code more straightforward by eliminating redundant iterations and data copying.

The change also prepares for future work by preserving the complete `promisor_info` structs, which will be needed when a `local_name` field is added. The patch maintains all existing behavior while making the code more maintainable - a typical preparatory change in this well-structured series that has already addressed technical feedback from Patrick Steinhardt and Junio Hamano.
