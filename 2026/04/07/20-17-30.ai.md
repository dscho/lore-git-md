Bugfix targeting the ODB (object database) transaction interface. This patch fixes a segfault that occurs when running `git diff` outside a repository on files that exceed core.bigFileThreshold. The issue stems from the ODB transaction path being incorrectly entered when only object hashing (not writing) is needed.

Justin Tobler identifies that ce1661f9da's introduction of ODB transaction logic caused `index_fd()` to attempt transactions even in non-repository contexts where no object writing occurs. The fix splits the logic - when only hashing is requested (INDEX_WRITE_OBJECT flag unset), it uses a new `hash_blob_stream()` helper that avoids ODB transactions entirely. The patch includes a test case that reproduces the segfault and verifies the fix.

This appears to be a well-contained fix with clear motivation (the reported segfault) and proper test coverage. The change is part of the broader ODB abstraction effort but stands on its own as a bugfix. The patch extracts cleanly from a larger series, suggesting the author considered the fix's independence from other changes.
