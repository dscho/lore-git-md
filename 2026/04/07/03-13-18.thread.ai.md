Thread identity: Feature patch to preserve 'change-id' header during rebase, cherry-pick, and amend operations. Originating author not specified in this email.

Core problem: Tools like Gerrit, GitButler and Jujutsu use change IDs to track commits across rewrites, but Git currently drops these headers during commit rewriting operations. The patch addresses this by preserving existing 'change-id' headers regardless of format.

Current status: Initial proposal with implementation and tests. No version history yet as this appears to be the first iteration.

Key technical details:
- Modifies sequencer code to detect and preserve 'change-id' headers
- Tests cover three scenarios: rebase, cherry-pick, and amend
- Intentionally format-agnostic - preserves whatever change-id format was present
- Does not enforce any particular change-id standard

- Future standardization not precluded by this change
