Bugfix for a segfault in object-file handling when computing hashes outside a repository. This patch addresses a specific case where `git diff` with `core.bigFileThreshold` set would crash when run outside a Git repository.

The issue stems from the ODB (object database) transaction interface added in commit ce1661f9da. The current code attempts to start an ODB transaction even when only computing object hashes (not writing objects), which fails in non-repository contexts. Justin Tobler's fix introduces a new `hash_blob_stream()` helper that handles the hash computation path separately, avoiding the transaction machinery when no object writing is needed.

The patch includes a test case that reproduces the crash scenario (running `git diff` on large files outside a repository) and verifies the fix. The change is cleanly separated from the existing transaction logic and maintains the same behavior for the object-writing path.

This appears to be a well-contained fix with clear motivation and test coverage. The change touches the object-file subsystem and relates to the ongoing ODB abstraction work, though it stands on its own as a bugfix.
