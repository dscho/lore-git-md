This is a documentation patch fixing AsciiDoc formatting in the `git-log` man page. The change is purely cosmetic, maintaining consistency with the documentation format conversion done in commit 026f2e3b.

The patch is straightforward - just changing the block delimiters without altering any content. It's part of the ongoing effort to standardize man page formatting, though not directly tied to the larger synopsis-style conversion work. The change improves readability while keeping the exact same information. Given the author's track record with documentation patches and the non-controversial nature of the change, this should be an easy merge.
