Documentation patch fixing AsciiDoc block formatting in the `git-log` man page's `--decorate` option description. This is the first of two patches from Kristoffer Haugsbakk, who frequently contributes documentation improvements.

The patch corrects a formatting issue introduced in commit 026f2e3b, which converted the `--decorate` option values from inline text to a description list. The original conversion used a source code block (`---`) instead of the proper open block (`--`) delimiter for the list. This change makes the formatting consistent with AsciiDoc conventions while maintaining identical rendered output.

The change is purely mechanical, affecting only the documentation syntax without altering the content or meaning. The patch is small (2 lines changed) and clearly motivated by the commit message referencing the prior conversion work. This appears to be part of the ongoing effort to maintain consistency in Git's documentation formatting, though not explicitly tied to the larger synopsis-style conversion project.
