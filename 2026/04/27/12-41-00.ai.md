This is a feature patch series by Christian Couder that enhances Git's promisor remote functionality with URL-based auto-configuration capabilities. It builds on the previous LOP (Large Object Promisors) work.

The series introduces a new `promisor.acceptFromServerUrl` config option that allows clients to automatically configure promisor remotes based on URL patterns, rather than requiring pre-configured remotes. This is particularly useful for organizations that want to allow certain trusted servers to advertise promisor remotes without manual client-side configuration.

Key technical aspects:
- URL patterns can include globs (`*`) with security-conscious matching rules (scheme/port must match exactly, host matching prevents crossing `/` boundaries)
- Patterns can optionally specify remote names (e.g. `cdn=https://example.com/*`)
- Auto-generated remote names use `promisor-auto-` prefix with URL sanitization
- Collision handling appends numeric suffixes to prevent overwrites
- Original advertised names are stored in `remote.<name>.advertisedAs` for traceability
- Comprehensive tests cover various URL matching and auto-configuration scenarios

The implementation touches:
- `promisor-remote.[ch]` for core functionality
- `urlmatch.[ch]` for URL pattern matching utilities
- Documentation updates across multiple files
- New test cases in `t5710-promisor-remote-capability.sh`

The series has gone through multiple iterations (now at v2) with reviews from Patrick Steinhardt and Junio C Hamano. It appears well-structured with preparatory refactors, core implementation, and documentation updates clearly separated across patches. The security considerations around URL pattern matching are particularly thorough.

This represents a significant usability improvement for promisor remote workflows while maintaining strong security defaults. The ability to auto-configure remotes based on URL patterns should reduce configuration overhead in organizational settings while still allowing fine-grained control over which servers are trusted.
