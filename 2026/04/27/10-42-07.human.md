The patch ensures errors are shown immediately when they occur during updates, which will become more common as validation logic moves earlier in the flow in subsequent patches.

The implementation carefully distinguishes between generic errors (which remain fatal) and specific rejections (which can be skipped in batch mode). This maintains existing behavior while preparing for the validation changes coming in later patches. The diff is mechanical but thorough, updating all command parsers to accept the new options struct.
