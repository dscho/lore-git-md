This is a preparatory patch in Christian Couder's URL-based promisor remote configuration series. It introduces a new helper function `url_normalize_pattern()` that extends Git's URL normalization to handle glob patterns (specifically `*` wildcards) in the host portion of URLs.

The patch exports this functionality from urlmatch.c while maintaining the existing security constraints - globs are only allowed in the host part, not crossing segment boundaries. The implementation is straightforward, building on the existing `url_normalize_1()` infrastructure with a new boolean flag.

This change supports the series' goal of allowing pattern-based promisor remote configuration while keeping the URL parsing secure and well-defined. The documentation in the header file clearly explains the purpose and limitations of the new function.

As part of an already-reviewed series, this patch appears uncontroversial and well-contained. It follows the pattern of the series by separating infrastructure changes from the main feature implementation.
