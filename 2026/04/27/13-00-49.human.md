This is the final documentation patch (8/8) in Christian Couder's series to enhance Git's promisor remote functionality with URL-based auto-configuration. The patch focuses on improving the documentation for the new `promisor.acceptFromServerUrl` config option.

The changes clarify the documentation by:
- Restructuring the text into clearer bullet points
- Better explaining the relationship between `acceptFromServer` and the new `acceptFromServerUrl` options
- Adding cross-references to the new feature
- Preserving all security warnings while making them more readable
- Correcting some client/server wording

The documentation now more clearly explains that `acceptFromServerUrl` provides an additive security allowlist that works alongside `acceptFromServer`, allowing organizations to specify trusted URL patterns for auto-configuring promisor remotes. The security considerations are thorough, warning about the risks of overly broad patterns.

This patch concludes a well-structured series that has gone through multiple iterations with reviews from Patrick Steinhardt and Junio C Hamano. The series represents a significant usability improvement for promisor remote workflows while maintaining strong security defaults.
