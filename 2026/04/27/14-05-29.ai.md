This is a refactoring patch that moves remote group resolution logic from `builtin/fetch.c` to `remote.c` as part of the remote group push feature series. The change extracts three components that were previously static in fetch.c - `get_remote_group()`, `add_remote_or_group()`, and the `remote_group_data` struct - making them available for reuse by other commands.

The patch follows Junio Hamano's suggestion to share this logic between fetch and push implementations rather than duplicating it. The moved code handles parsing `remotes.<name>` config entries and resolving a name to either group members or a single remote. This prepares for the next patch which will implement group push functionality using these shared helpers.

The implementation appears straightforward - it's a direct move of existing code with the minimal changes needed to make the functions non-static and expose them in remote.h. The patch maintains all existing behavior while enabling the functionality to be used by the upcoming group push feature. This is a typical preparatory refactoring that follows Git's pattern of moving reusable components to shared locations when new features need them.
