This is a preparatory patch in Christian Couder's series enhancing promisor remote functionality with URL-based auto-configuration. The patch introduces a new `local_name` field to `struct promisor_info` to handle cases where the locally configured remote name differs from what the server advertised.

The change allows for auto-generated remote names (like `promisor-auto-*`) while preserving the original advertised name for reference. A new `promisor_info_internal_name()` helper function abstracts the name selection logic, returning `local_name` when set and falling back to the advertised `name`. The patch updates two key functions to use this helper when looking up remote configuration.

This is a clean, focused change that lays groundwork for the auto-configuration feature while maintaining existing behavior when `local_name` isn't set. The patch follows the series' pattern of careful, incremental changes with clear documentation updates. It has already been reviewed positively by Patrick Steinhardt and Junio Hamano in previous iterations.
