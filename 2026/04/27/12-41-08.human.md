This is a documentation patch that improves the `promisor.acceptFromServer` config entry in the promisor-remote documentation. It's the final patch in Christian Couder's 8-part series adding URL-based auto-configuration for promisor remotes.

The patch addresses several issues with the current documentation:
- Makes it clearer that `acceptFromServer` doesn't create new remotes (that's what the new `acceptFromServerUrl` does)
- Reformats the text from a dense paragraph into bullet points for better readability
- Clarifies the default value is "none"
- Fixes a wording error about "advertised by the client" vs "advertised by the server"
- Adds a cross-reference to the new `acceptFromServerUrl` option

The changes make the documentation more approachable while maintaining all the technical details about security implications of each option. This is a common pattern in Git's documentation - converting dense prose into structured, scannable content while preserving the precision needed for configuration options.

As the last patch in a well-structured series that has already received positive reviews, this appears ready for merging. The documentation improvements complement the new functionality added earlier in the series.
