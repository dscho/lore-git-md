This is a preparatory refactoring patch in Christian Couder's URL-based promisor remote auto-configuration series. It introduces a new `local_name` field to `struct promisor_info` to handle cases where the locally configured remote name differs from the server-advertised name.

The key changes are:
1. Adds `local_name` to track auto-generated or locally configured remote names separately from server-advertised names
2. Introduces a helper function `promisor_info_internal_name()` that returns the appropriate name (local if set, otherwise advertised)
3. Updates configuration storage and lookup functions to use the helper
4. Ensures proper memory cleanup of the new and existing fields

This is a mechanical change that enables the series' later patches to implement auto-generated remote names while maintaining traceability of the original advertised names. The patch follows Git's typical refactoring pattern - small, focused changes with clear documentation updates and no behavior modifications yet.
