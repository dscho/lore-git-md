This is the third version of a feature patch from Pablo Sabater that improves how `git log --graph` renders commits with excluded parents (including root commits). The current graph output can misleadingly align unrelated commit lineages vertically when parent commits are excluded from display.

The solution introduces a placeholder mechanism that keeps parentless commits "alive" for an extra row via an `is_placeholder` flag in graph columns, forcing proper indentation of subsequent commits. This handles both true root commits and commits with parents outside the displayed range uniformly. The patch includes comprehensive test cases demonstrating improved output for multiple scenarios.

Changes from v2 include:
- Documentation clarifications about the placeholder mechanism
- Renamed `is_root` to `is_parentless` for consistency
- Simplified ASCII-art examples in the cover letter
- Added more comments to aid reviewability
