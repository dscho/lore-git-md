This is the final patch in Pablo Sabater's series improving `git log --graph` rendering for commits with excluded parents (including root commits). The patch builds on previous RFC and v2 discussions, now awaiting final review before potential merging.

The core issue fixes misleading graph output where unrelated commit lineages appear vertically aligned when parent commits are excluded from display. The solution introduces a placeholder mechanism that keeps parentless commits "alive" for an extra row via an `is_placeholder` flag in graph columns, forcing proper indentation of subsequent commits. This handles both true root commits and commits with parents outside the displayed range uniformly.

The implementation modifies graph.c (rendering logic) and graph.h (new flag), with comprehensive test cases added to t4215-log-skewed-merges.sh demonstrating improved output. V3 maintains all improvements from v2 while adding minor documentation clarifications about the placeholder mechanism's behavior. The author notes some remaining visual quirks in diagonal line rendering between distant columns but suggests addressing those in follow-up work.
