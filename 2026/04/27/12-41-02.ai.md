This is a refactoring patch in Christian Couder's URL-based promisor remote auto-configuration series. It changes the `allow_globs` parameter in `urlmatch.c` from a `char` to a `bool` type to better reflect its boolean usage.

The patch makes three straightforward changes:
1. Updates the function signature of `url_normalize_1()` to use `bool` instead of `char` for the `allow_globs` parameter
2. Changes the call in `url_normalize()` to pass `false` instead of `0`
3. Changes the call in `urlmatch_config_entry()` to pass `true` instead of `1`

This is a mechanical improvement that aligns with Git's coding style preferences for boolean parameters. The change is part of the larger effort to enhance promisor remote functionality with URL pattern matching capabilities, but this particular patch is purely about code hygiene rather than adding new features. It follows the common Git practice of separating preparatory refactoring from functional changes in patch series.
