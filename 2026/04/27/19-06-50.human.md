This is the second patch in a two-part documentation series from Kristoffer Haugsbakk, fixing AsciiDoc formatting in the `git-log` man page's `--decorate` option description. 

The patch standardizes the delimiter used in the description list for `--decorate` options, changing from `::` to `;;` to maintain consistency with the rest of the list. The commit message explains that mixing delimiters would incorrectly create a nested description list in the rendered output. The change is purely cosmetic, affecting only the documentation syntax without altering any content or behavior.

This follows the first patch in the series which fixed an incorrect source code block delimiter. Together these patches clean up minor formatting issues introduced when this section was converted to description list format in commit 026f2e3b. The changes are straightforward and uncontroversial, typical of Kristoffer Haugsbakk's frequent documentation contributions.
