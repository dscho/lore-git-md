This is part 2/9 of a refactoring series standardizing reference backend initialization. The patch introduces a new `ref_store_init_options` struct to consolidate initialization parameters for Git's reference backends (files, packed, reftable).

The key change moves the `access_flags` parameter into this new structure, which will later also house reflog configuration. This provides a cleaner foundation for extending backend initialization options without repeatedly modifying function signatures. The change is mechanical but touches all three backend implementations to adopt the new structure.

The patch follows the series' broader goal of moving shared logic out of backend-specific code. It has already undergone substantive review from Patrick Steinhardt and Toon Claes in prior iterations, with all feedback addressed in this version. The changes are straightforward and appear ready for integration.
