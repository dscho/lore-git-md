This is a refactoring patch that moves remote group resolution logic from `builtin/fetch.c` to `remote.c` as part of the remote group push feature series. The change extracts three components that handle parsing `remotes.<name>` config entries and resolving remote groups into reusable library functions.

The patch doesn't introduce new functionality but prepares the shared infrastructure needed for the subsequent patch that will implement group push support. The moved code includes the `remote_group_data` struct and two key functions: `get_remote_group` (which parses the config) and `add_remote_or_group` (which resolves a name to either a group or single remote).

This appears to be a straightforward code movement with no behavior changes, following Junio Hamano's suggestion to make the group resolution logic available to other commands beyond just `git fetch`. The patch is well along in the review process (v4) and seems ready for merging as part of the larger feature.
