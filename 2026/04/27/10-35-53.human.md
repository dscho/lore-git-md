This is a follow-up ping for Pablo Sabater's feature patch (v3) that improves `git log --graph` rendering for commits with excluded parents. The patch has been awaiting review since early April after addressing all previous feedback.

The core improvement fixes misleading vertical alignment in graph output when displaying root commits or commits whose parents are outside the displayed range. The solution introduces a placeholder mechanism that properly indents subsequent commits by keeping parentless commits "alive" for an extra row via an `is_placeholder` flag.

The v3 iteration includes minor documentation improvements - better comments, simplified ASCII graph examples in the cover letter, and renamed variables for clarity (`is_root` → `is_parentless`). Test coverage remains thorough, now with added explanations of edge cases.
