This is a feature patch in Christian Couder's series enhancing Git's promisor remote functionality with URL-based auto-configuration. This patch specifically implements automatic remote creation when a server advertises an unknown remote whose URL matches an allowed pattern.

The patch introduces several key components:
- Helper functions to sanitize and generate remote names from URLs (prefixed with "promisor-auto-")
- Logic to handle name collisions by appending numeric suffixes
- Configuration writing for the new remote's URL, promisor status, and original advertised name
- Integration with the existing URL pattern matching from earlier in the series

The implementation includes comprehensive tests covering:
- Basic auto-creation from URL patterns
- Named pattern matching ("cdn=url")
- Collision handling when names conflict
- Reuse of existing remotes with matching URLs
- Error cases like invalid names

Documentation is added explaining the auto-creation behavior, name generation rules, and security considerations. The patch builds on previous work in the series while maintaining the strict security model around URL pattern matching.

This appears to be a well-structured patch with clear separation of concerns between the new helper functions and their integration into the existing promisor remote logic. The test coverage is thorough and the documentation updates are clear. The implementation follows the series' established patterns while adding significant new functionality to reduce configuration burden for users.
