This is a test fix patch (part 2/8) in Johannes Schindelin's security-focused series changing default bare repository access behavior. The patch addresses an interaction between the test infrastructure's global config settings and XDG config file precedence in the `git maintenance` tests.

The issue arises because test-lib.sh writes to `$HOME/.gitconfig` (for the `safe.bareRepository` setting), which then takes precedence over XDG config locations in subsequent tests. This particular patch fixes the `t7900-maintenance.sh` tests by overriding `$HOME` to a non-existent directory in the subshells testing XDG behavior, ensuring the XDG config location is used without interference from the global `.gitconfig`.

The change demonstrates the careful approach needed when modifying global test infrastructure - the fix isolates the XDG tests from side effects of other test setup while maintaining the intended security hardening. This is part of the broader preparation work before the actual behavior change in patch 8/8.
