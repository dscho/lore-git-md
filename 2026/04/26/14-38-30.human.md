This is a test fix patch in Johannes Schindelin's security-focused series changing default bare repository access behavior. It's part 2 of 8 in the v2 iteration.

The patch addresses an interaction between the test infrastructure's global `safe.bareRepository` setting and XDG config tests in `t7900-maintenance.sh`. The issue arises because Git prefers `$HOME/.gitconfig` over XDG locations when both exist, causing maintenance registration tests to write to the wrong config file when test-lib.sh has created a `.gitconfig`.

The solution cleanly isolates the XDG tests by overriding `HOME` to a non-existent directory within the test subshells, ensuring the XDG config location is used without interference from global config. This approach maintains test reliability while working within the constraints of the broader security changes.

The change demonstrates careful attention to test isolation in the context of global configuration changes, a recurring challenge in this series. It's a focused, mechanical adjustment that follows the series' pattern of preparing tests before making the core behavior change.
