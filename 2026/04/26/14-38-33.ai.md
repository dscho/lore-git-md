This is a test fix patch in Johannes Schindelin's security-focused series changing default bare repository access behavior. The patch addresses an interaction between the test-lib.sh infrastructure (which sets safe.bareRepository=all when WITH_BREAKING_CHANGES is enabled) and t5601-clone.sh's includeIf test.

The issue arises because the test overwrites $HOME/.gitconfig with its own configuration, clobbering the safe.bareRepository setting needed by subsequent tests. The fix backs up .gitconfig before the test runs and restores it afterward, preserving the global test configuration while still allowing the includeIf test to proceed.

This demonstrates the careful attention being paid to test interactions in this series - even seemingly simple test modifications can have cascading effects when global state is involved. The patch maintains the series' pattern of isolating test changes from the core behavior modification (which comes in patch 8/8).
