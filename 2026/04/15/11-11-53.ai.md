This is a feature patch adding custom conflict marker labeling to `git stash apply`. It's part of a larger series (v13) that enhances `git checkout -m` with autostash behavior, now in final polishing phase after being merged to the `next` branch.

The patch introduces three new options to `git stash apply`:
- `--label-ours=<label>` - Custom label for the upstream side in conflict markers
- `--label-theirs=<label>` - Custom label for the stashed changes
- `--label-base=<label>` - Custom label for the base in diff3-style conflicts

The implementation modifies the merge options structure in `do_apply_stash()` to use the provided labels, falling back to the default "Updated upstream"/"Stashed changes"/"Stash base" when not specified. The xdiff merge machinery is updated to handle empty labels properly. Two new test cases verify the functionality - one checking custom labels with diff3 style, another verifying empty labels produce minimal markers.
