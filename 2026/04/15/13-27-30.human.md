This is a refactoring patch in the fsmonitor series, part of the ongoing effort to implement cross-platform filesystem monitoring support. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms, not just macOS. It also introduces a clearer separation between platform-specific components (handled by `FSMONITOR_DAEMON_BACKEND`) and Unix-shared components (handled by `FSMONITOR_OS_SETTINGS`).

The changes are mechanical but important for the Linux fsmonitor implementation that will reuse this code. The patch updates the build system (Makefile, CMake, meson) to handle the new file organization and variable split. This is the 6th patch in a 13-part series that has already gone through 15 iterations of review, with maintainer approval for integration. The patch builds on earlier work by Eric DeCosta and Marziyeh Esipreh, as noted in the "Based-on-patch-by" credits. The changes are straightforward and unlikely to be controversial at this late stage in the series.
