This is part 3 of Patrick Steinhardt's test infrastructure series to enable `set -e` in Git's test suite. The patch focuses on making the `stop_git_daemon()` helper function work correctly under strict error checking.

The change addresses two issues in the daemon shutdown logic that would cause failures when `set -e` is enabled: the `wait` call that expects a non-zero exit code would trigger an immediate exit, and the second `kill` attempt (via PID file) would fail since the process is already dead. The solution uses the now-standard `ret=0; command || ret=$?` pattern for the wait call, and adds `|| :` to silence the second kill.

This is a mechanical but important change in the context of the larger series, ensuring test daemon cleanup remains reliable while gaining the benefits of stricter error checking. The patch follows the established pattern seen in earlier parts of the series, showing careful attention to edge cases in test infrastructure.
