This is a refactoring patch in the fsmonitor series, part of the cross-platform filesystem monitoring implementation. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms, not just macOS. It introduces a new `FSMONITOR_OS_SETTINGS` build variable to distinguish between platform-specific files (like listen/health/path-utils) and shared Unix files (IPC/settings).

The changes affect multiple build systems (Makefile, CMake, meson) and update the file organization while maintaining all functionality. The patch carries forward attribution to previous contributors (Eric DeCosta and Marziyeh Esipreh) whose work informed this refactoring. This is a straightforward infrastructure change that properly separates platform-specific and shared components in preparation for the Linux fsmonitor implementation.
