Feature patch refining Lisp dialect support in Git's userdiff functionality.

This is the first patch in the final v4 series that enhances Git's ability to handle Lisp dialects (Scheme, Common Lisp, Emacs Lisp, Clojure) in its diff highlighting. Johannes Sixt focuses specifically on improving the test cases for the Scheme driver's word-diff behavior, particularly around vertical bar syntax and parentheses handling.

The changes tighten the test coverage by:
1. Modifying the vertical bar test case to better demonstrate that content between bars is treated as a single word (changing from `some-text` to `|the greeting|` vs `|a greeting|`)
2. Adding new test cases showing that all types of parentheses (`()`, `[]`, `{}`) are properly recognized as word separators when they appear in sequences

These test improvements verify that the underlying regex patterns correctly handle edge cases in Lisp syntax while maintaining backward compatibility with existing Scheme files. The patch builds on Scott L. Burson's earlier work unifying Lisp dialect support and has been reviewed by both the original author and the Scheme driver maintainer Atharva Raykar.

The changes are purely test-focused and don't modify the actual implementation - they serve to validate the robustness of the vertical bar and parentheses handling that was implemented in previous versions of this series. The careful attention to test cases reflects the project's emphasis on thorough verification of diff behavior, especially for syntax-sensitive languages like Lisp dialects.
