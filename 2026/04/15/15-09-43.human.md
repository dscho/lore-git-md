Feature addition to `git cat-file`'s batch mode, now ready for merging.

This patch from Siddharth Asthana adds a `mailmap` subcommand to `git cat-file --batch-command`, allowing dynamic toggling of mailmap processing during a long-running operation. The change addresses GitLab Gitaly's need to reuse processes without restarting them, as previously mailmap behavior could only be set at process startup.

The implementation introduces a new command that accepts standard Git boolean values (yes/no, true/false, on/off) to control mailmap rewriting. Mailmap data is loaded lazily on first use and cached in memory, with the implementation carefully handling the mailmap's string duplication state. The patch includes comprehensive tests covering runtime toggling, interaction with startup options, boolean parsing, and error cases.

After multiple rounds of review incorporating feedback from Junio Hamano, Patrick Steinhardt, Karthik Nayak, and Jean-Noël Avila, the patch is now finalized with all requested documentation and code clarity improvements. The changes are well-contained to `builtin/cat-file.c` and its tests, with no outstanding technical issues. This appears to be a clean, focused addition that solves a real-world use case while maintaining Git's existing behavior and performance characteristics.
