This is a status update from the maintainer regarding the Linux fsmonitor implementation series. Junio Hamano confirms he has reverted the fsmonitor patches from the `next` integration branch, keeping them only in the experimental `seen` branch while further testing and feedback continues. This comes in response to Ben Knoble's report of Gentoo-specific build issues caused by the series conflicting with existing Gentoo patches.

The core functionality remains unchanged from previous iterations: cross-platform filesystem monitoring with Linux inotify support, process isolation improvements, and comprehensive test coverage. The current discussion focuses purely on integration workflow, not technical changes to the implementation itself. Testers are now expected to check both `seen` (for the fsmonitor series) and `next` (for other in-progress topics) during evaluation.

The Gentoo build issue remains a downstream packaging matter that doesn't require action from the Git project. This email serves as procedural guidance for contributors tracking the fsmonitor work's path through the integration branches.
