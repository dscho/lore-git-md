The main changes in v14 address Phillip Wood's feedback about simplifying tests in `t/t3903-stash.sh`. The series maintains all the core functionality from previous versions while making the test suite cleaner and more maintainable. Key aspects include:

2. Allowing silent autostash creation during operations with branch-specific messages
3. Improved error handling with proper lock rollback in `merge_working_tree()`
4. Core autostash behavior for `checkout -m` that stashes changes before attempting a merge and reapplies them afterward

The implementation spans multiple components (`builtin/checkout.c`, `builtin/stash.c`, `sequencer.c`) and includes comprehensive test coverage.
