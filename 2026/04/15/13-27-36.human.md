This is a test patch in the fsmonitor series, adding Linux-specific test coverage for the new filesystem monitoring daemon. It's part of a 15-iteration effort to implement comprehensive cross-platform fsmonitor support, now has maintainer approval, and is ready for integration.

The patch adds two key test scenarios: a smoke test to verify event delivery works (skipping all tests if the filesystem can't deliver events properly), and a stress test for rapid nested directory creation to catch race conditions in watch handling. It also includes several test infrastructure tweaks - reducing timeouts for faster feedback, improving process group handling for submodule tests, and making the test helpers more robust in CI environments.

The changes are well-motivated by real-world edge cases (overlayfs issues, EEXIST races) and the implementation shows attention to detail with proper cleanup handling and defensive programming. This is the final test coverage needed to complete the Linux fsmonitor implementation after extensive review and iteration. The patch maintains consistency with the series' high quality bar and addresses all previously identified test suite issues.
