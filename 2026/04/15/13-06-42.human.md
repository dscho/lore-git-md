This is a test infrastructure patch in Patrick Steinhardt's ongoing series to make Git's test suite robust under `set -e`. The patch modifies t1301-shared-repo.sh to handle cases where the `setfacl` command fails or doesn't exist on the system.

The test currently tries to remove ACLs from the test directory using `setfacl -k`, which can fail on systems without ACL support or where the command isn't installed. While this currently doesn't cause test failures, it would break under `set -e`. The fix adds `|| :` to swallow the error, maintaining the test's behavior while making it from failing when `setfacl` isn't available.

This is a straightforward change that follows the pattern established in earlier patches of the series - making test infrastructure resilient to command failures when running with strict error checking enabled. The patch is small, focused, and clearly motivated by the broader `set -e` effort.
