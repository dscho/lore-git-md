This is a feature patch in the final polishing phase of a series that enhances Git's autostash functionality during merge operations. The patch adds customizable conflict marker labels and stash messages when applying autostashes.

The key changes allow callers to specify custom labels for conflict markers (ours/theirs/base) and customize the stash message when an autostash is applied. The implementation extends the `apply_autostash_ref()` interface to accept these new parameters, which get passed through to the underlying `git stash apply` command. The patch maintains backward compatibility by making all new parameters optional (NULL falls back to default behavior).

The changes affect several commands that use autostash internally (`commit`, `merge`), though in this version all callers pass NULL for the new parameters, preserving existing behavior. The implementation is clean and follows Git's established patterns for adding new functionality while maintaining compatibility.

This patch represents a thoughtful refinement of the autostash feature, giving users more control over conflict resolution while keeping the existing simple cases simple. The changes are well-tested and have already been through multiple rounds of review, with feedback from Phillip Wood and Junio C Hamano incorporated. As part of a merged series now in `next`, this patch is in its final form before potential inclusion in a future release.
