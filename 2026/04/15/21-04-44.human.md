This is a follow-up in the MIDX compatibility discussion thread regarding Git v2.54.0-rc2. Junio Hamano responds to Johannes Schindelin's report that the new MIDX version 2 format breaks backward compatibility with Git v2.53.0.

Junio identifies the specific commit (b2ec8e90) that introduced the MIDX version bump, noting that while the commit message claims older Git versions would "gracefully degrade," in practice they fail with a hard error. He suggests this may be causing more harm than intended by preventing older versions from working at all rather than falling back gracefully.

The email directly addresses Taylor Blau (the primary MIDX contributor) with a practical suggestion - providing recovery instructions for users who hit this issue, such as deleting the MIDX files to force regeneration in the old format. This indicates the problem may need resolution before the final 2.54.0 release.

The exchange highlights a tension between advancing MIDX capabilities and maintaining backward compatibility, particularly for mixed-version environments and tools like GitHub Desktop that bundle specific Git versions. Junio's response shows the maintainer actively working to mitigate the impact of this breaking change.
