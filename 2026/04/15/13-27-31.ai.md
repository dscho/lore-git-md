This is a refactoring patch in the fsmonitor series, part of the cross-platform filesystem monitoring implementation. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is shared across Unix platforms, not just macOS. It updates both the CMake and meson build systems to use a new `FSMONITOR_OS_SETTINGS` variable for platform-specific settings, matching the approach already used for IPC paths.

The change is straightforward - a pure rename with corresponding build system updates - but it's an important architectural improvement that properly separates platform-specific components from shared Unix logic. The patch acknowledges prior work from Eric DeCosta and Marziyeh Esipreh who contributed to the original IPC implementation. This is patch 7/13 in the v15 series that has already received maintainer approval, indicating the overall approach is sound. The rename helps pave the way for the Linux fsmonitor implementation by making the Unix-common code clearly reusable across platforms.
