This is a platform compatibility patch adding Windows support for timed condition variable waits, part of the larger fsmonitor series that has now been approved for integration. The patch implements `pthread_cond_timedwait()` for Windows using the native `SleepConditionVariableCS()` API, converting between POSIX timespec and Windows millisecond timeouts.

The implementation handles the time conversion carefully, checking for timeout expiration before making the system call and properly translating Windows error codes to POSIX equivalents (including ETIMEDOUT). This enables the fsmonitor daemon's 30-second shutdown timeout to work consistently across platforms, a key requirement for the cross-platform support.

As the 4th patch in the 13-part v15 series, this builds on the Windows pthread emulation layer to complete the fsmonitor daemon's process management capabilities. The change is straightforward and well-contained, with no behavioral impact outside the Windows compatibility layer. With the series already approved, this represents final polish rather than new functionality.
