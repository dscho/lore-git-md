This is a test infrastructure patch in Patrick Steinhardt's ongoing series to enable `set -e` (errexit) in Git's test suite. The patch specifically addresses `git config --unset` calls that currently fail when the configuration variables being unset don't exist - a scenario that would become fatal under `set -e`.

The changes are mechanical but important for robustness: each `git config --unset` call is modified to append `|| :` to silence the command's failure when the key isn't present. This preserves the original intent (cleaning up configs that may have been set by earlier test steps) while making the cleanup resilient to missing keys. The patch touches three test scripts that perform such cleanup: t4032 (diff hunk context), t7508 (status output), and t9138 (SVN author mapping).

This is part of the broader effort to make test cleanup routines reliable under strict error checking. The changes follow the pattern established earlier in the series for handling expected failures, and the patch fits naturally with the prior work on `test_must_fail` and daemon management. While small, these changes are important for the test suite's reliability when `set -e` is enabled, particularly since some of these cleanup operations run outside test cases where failures would be fatal.
