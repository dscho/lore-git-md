This is a resource management patch in the ongoing autostash feature series for `git checkout -m`. The patch fixes lockfile handling in `merge_working_tree()` by ensuring proper rollback on all early return paths.

The change addresses a subtle issue where the function could exit without releasing the index lock acquired via `repo_hold_locked_index()`. While currently harmless since the process exits soon after, this could cause problems if the function were called multiple times in the same process. The patch adds `rollback_lock_file()` calls to all 7 early return paths in the function.

The implementation is straightforward - wrapping each early return with lock cleanup. The changes touch only `builtin/checkout.c`, adding 22 lines while removing 7.
