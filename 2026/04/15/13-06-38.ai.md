This is a test infrastructure patch in Patrick Steinhardt's ongoing series to enable `set -e` (errexit) in Git's test suite. The series has progressed through multiple iterations addressing platform-specific shell behaviors and hardening test infrastructure.

The patch fixes a pattern where conditional test execution using `test ... && test_expect_success` would fail the overall statement when skipping a test, which would become problematic under `set -e`. It converts these to proper `if` conditionals in two test scripts (t4032 and t7450) that check diff hunk context and dotfile handling respectively.

The changes are mechanical but important for the broader `set -e` effort, ensuring skipped tests don't trigger errexit failures. The patch follows the series' established approach of making test infrastructure more robust while maintaining compatibility. It builds on prior work that already addressed similar patterns in other test scripts, demonstrating consistent application of error-handling improvements across the test suite.
