This is the final version of a feature patch adding dynamic mailmap toggling to `git cat-file --batch-command`. The patch has gone through multiple rounds of review and is now ready for merging, with all feedback from Junio Hamano, Patrick Steinhardt, Karthik Nayak, and Jean-Noël Avila addressed.

The change adds a `mailmap` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off) to control name/email rewriting in long-running `git cat-file` processes without requiring restart. This solves a real-world need for GitLab's Gitaly service, which maintains persistent `git-cat-file` processes.

Key implementation details include lazy loading of mailmap data (loaded on first use and cached), robust boolean parsing with `git_parse_maybe_bool()`, and comprehensive test coverage. The final version incorporates several documentation and code clarity improvements suggested during review, including proper AsciiDoc formatting and removal of an intermediate variable in the parsing logic.

The patch is well-contained, touching only `builtin/cat-file.c` and its tests/documentation. With all review feedback addressed and consensus reached, this appears to be a clean solution to the stated problem that meets Git's quality standards.
