This is the second patch in a v4 series extending Git's userdiff functionality to better support Lisp dialects (Scheme, Common Lisp, Emacs Lisp, Clojure). The patch focuses on implementing the unified pattern matching while maintaining backward compatibility with existing Scheme detection.

The key technical changes include:
- A new regex pattern that matches unindented parentheses for top-level forms across Lisp dialects
- Case-insensitive matching of `(def` prefixes for Common Lisp forms
- Support for conventional 1-2 space indentation of grouped forms
- Enhanced vertical bar syntax handling that properly escapes characters within identifiers
- Comprehensive test coverage including new cases for Common Lisp forms (defun/defmacro, eval-when, macrolet)

The implementation builds on previous iterations that addressed column-0 parentheses and vertical bar syntax, now with Johannes Sixt's refinement for escaped vertical bars. The documentation has been updated to explicitly list supported dialects while maintaining the "scheme" driver name for backward compatibility.

Test coverage is thorough, including:
- New test files for Common Lisp forms (scheme-lisp-defun-*, scheme-lisp-eval-when)
- Updated vertical bar test cases with escaped characters
- Preservation of existing Scheme regression tests
- Verification of parentheses word separation

The patch appears ready for integration, having addressed all technical feedback across multiple review rounds. It represents a consensus solution that balances dialect coverage with backward compatibility, demonstrated through both implementation and expanded test cases.
