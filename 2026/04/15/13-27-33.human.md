This is part of the cross-platform fsmonitor implementation series, specifically addressing process isolation by cleaning up inherited file descriptors in child processes. The patch adds a `close_fd_above_stderr` flag to `struct child_process` that, when enabled, closes all file descriptors above stderr (FD 2) in child processes before exec, while preserving the child-notifier pipe.

The implementation caps the scan at the minimum of `sysconf(_SC_OPEN_MAX)` or 4096, providing a practical balance between thoroughness and performance. This change helps prevent child processes from inheriting unwanted file descriptors from the parent environment, which is particularly important for the fsmonitor daemon's process isolation requirements.

The patch is well-contained, adding just 21 lines across two files with clear documentation of the new flag's purpose.
