Feature patch finalizing extended Lisp dialect support in Git's userdiff functionality. This is the concluding email in a well-reviewed series that has gone through four iterations to properly handle Scheme, Common Lisp, Emacs Lisp, and Clojure syntax in Git's diff highlighting.

Johannes Sixt provides his Acked-by for the v4 series, which implements the consensus from earlier discussions. The key changes in this version were:
1. Refining the documentation to explicitly list supported dialects while using the inclusive "most Lisp dialects" phrasing
2. Updating the test case for vertical bar syntax to properly handle escaped vertical bars (`|the \| \greeting|`)

The patch appears ready for integration, having addressed all technical feedback across multiple review rounds. Scott L.
