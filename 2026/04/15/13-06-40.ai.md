This is a test infrastructure patch in Patrick Steinhardt's ongoing series to enable `set -e` (errexit) in Git's test suite. The patch focuses on making `test_when_finished()` and `test_atexit()` cleanup handlers work correctly with `set -e` enabled.

The key change replaces the existing `&& (exit "$eval_ret")` pattern with `|| eval_ret=$?` in both functions. This modification preserves the test's exit code behavior while making it compatible with `set -e`. The commit message includes detailed truth tables showing how the old and new implementations handle various combinations of test success/failure and cleanup success/failure.

The change is mechanical but important - these functions are fundamental test infrastructure used throughout the test suite. The patch maintains the same behavior as before while removing a pattern that would cause early termination under `set -e`. This continues the series' careful approach of incrementally hardening test infrastructure components to work reliably with stricter error checking.
