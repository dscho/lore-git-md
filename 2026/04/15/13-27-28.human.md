This is a platform compatibility patch that adds Windows support for `pthread_cond_timedwait()` as part of the larger fsmonitor implementation series. The patch implements the function using Windows' native `SleepConditionVariableCS()` API with millisecond timeout calculation.

The implementation handles time conversion from the absolute timespec deadline to a relative Windows timeout, including proper error handling for timeouts and other system errors. This enables the fsmonitor daemon's shutdown timeout mechanism to work consistently across platforms.

As part of the 15-iteration fsmonitor series that has already received maintainer approval, this patch represents a straightforward but necessary piece of the cross-platform puzzle. The implementation follows established patterns seen elsewhere in Git's Windows compatibility layer, converting between POSIX and Windows timing conventions while maintaining the expected pthread semantics.

The patch is small, focused, and well-contained - exactly what we'd expect for a compatibility shim in this late stage of a well-reviewed series. With the core functionality already approved and this being a mechanical platform adaptation, it should integrate smoothly.
