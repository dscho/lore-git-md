This is a post-merge follow-up patch series for the already-merged autostash feature in `git checkout -m`. The series focuses on test simplification and rebasing against upstream, addressing feedback from Phillip Wood about test organization in `t3903-stash.sh`.

The main changes in v14 are:
1. Simplification of test setup in `t3903-stash.sh` by using `git reset --hard initial` instead of `test_when_finished` cleanup
2. Addition of an `initial` tag to make test resets more precise
3. Rebase against current upstream to ensure clean integration

The technical implementation remains unchanged from v13, which added:
- Custom conflict marker labels via `--label-ours`, `--label-theirs`, `--label-base` in `git stash apply`
- Silent autostash creation capability
- Proper lockfile rollback in `merge_working_tree()`
- Core autostash behavior for conflicted branch switching

This version demonstrates Git's post-merge refinement process, with the author (Harald Nordgren) addressing remaining test organization concerns after the core functionality was already merged to `next`. The changes show responsiveness to review feedback while maintaining the stability of the already-accepted implementation.
