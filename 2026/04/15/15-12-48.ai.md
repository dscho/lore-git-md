Jimmy Aguilar Mena responds to Phillip Wood's concerns about how submodule worktree state would be managed. This provides the same isolation pattern that regular worktrees already use for the main repository.

The email suggests that a proper implementation should likely use `git worktree add` machinery for each submodule rather than relying on the hardlink+rename behavior, which is presented as an implementation detail of the current prototype.
