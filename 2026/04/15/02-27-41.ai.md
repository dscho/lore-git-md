This is a feature patch series (v4) extending Git's userdiff functionality to better support Lisp dialects. The series builds on previous iterations that unified Scheme and Common Lisp/Emacs Lisp support under a single "lisp" driver while maintaining backward compatibility.

The v4 version makes two key changes from v3:
1. Updates the documentation wording to describe support for "most Lisp dialects" while explicitly mentioning Scheme, Emacs Lisp, Common Lisp, and Clojure
2. Further refines the vertical bar syntax test case to properly handle escaped vertical bars in identifiers (changing `|the \greeting|` to `|the \| \greeting|`)

The core technical approach remains:
- Using disjunctive regex patterns to match both Scheme and Lisp dialects
- Supporting case-insensitive `(def` prefixes for Common Lisp forms
- Handling conventional Lisp indentation (0-2 spaces before top-level forms)
- Maintaining backward compatibility with existing Scheme detection

The series appears ready for integration, having addressed all technical feedback across multiple iterations. Scott L. Burson and Johannes Sixt have collaborated on the implementation, with maintainer approval from Atharva Raykar. The changes are well-tested with new cases covering:
- Vertical bar syntax edge cases (including the new escaped bar scenario)
- Common Lisp forms (defun/defmacro)
- Nested macrolet and eval-when special forms
- Module definitions

The documentation change reflects community consensus on how to describe the broader Lisp dialect support while being precise about which dialects are explicitly verified. The test updates demonstrate the robustness of the vertical bar handling, which was a key focus of earlier review rounds.
