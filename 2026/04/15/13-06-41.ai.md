This is a test infrastructure patch in Patrick Steinhardt's ongoing series to enable `set -e` in Git's test suite. The patch specifically addresses t0008-ignores.sh, which tests Git's ignore patterns.

The change modifies two `grep -v` invocations in a test helper function to append `|| :` (a no-op that swallows errors) since these commands are expected to sometimes produce no matches. Without this, when `set -e` is enabled, the non-zero exit from `grep` would cause the test to fail prematurely. The change preserves the existing test behavior while making it compatible with stricter error checking.

This is a mechanical but necessary adjustment as part of the broader `set -e` effort. The patch follows the established pattern seen elsewhere in the series for handling expected command failures. Since t0008 is a fundamental test script that exercises core ignore functionality, ensuring its robustness under `set -e` is important groundwork for the rest of the test suite.
