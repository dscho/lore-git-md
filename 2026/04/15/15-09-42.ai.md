Feature addition to `git cat-file`'s batch mode, now finalized for merging.

This is the final version of Siddharth Asthana's patch adding dynamic mailmap toggling to `git cat-file --batch-command`. The feature allows changing mailmap behavior mid-operation without restarting the process, addressing GitLab Gitaly's need to reuse long-running processes. The implementation introduces a `mailmap <bool>` subcommand that accepts standard Git boolean values (yes/no, true/false, on/off).

The patch has gone through multiple rounds of review with feedback incorporated from Junio Hamano (documentation and code clarity), Patrick Steinhardt (boolean parsing), Karthik Nayak (documentation simplification), and Jean-Noël Avila (AsciiDoc formatting). Key technical aspects include lazy loading of mailmap data that persists in memory, shared loading logic between startup and runtime paths, and comprehensive test coverage in `t/t4203-mailmap.sh`.

The changes are well-contained to `builtin/cat-file.c` and its documentation/tests, with no outstanding technical issues. The thread shows clear consensus that the implementation is ready for merging, having addressed all review feedback while maintaining the original use case solution. The final version includes Junio's suggested documentation of the interface's boolean parsing behavior (which differs slightly from Git config syntax) and code clarity improvements like direct assignment to `use_mailmap` rather than using a temporary variable.
