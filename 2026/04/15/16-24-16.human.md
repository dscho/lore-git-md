This is a refinement patch in the completed autostash series, adding silent operation capability to the autostash creation process. The patch allows callers to suppress the "Created autostash" message when creating an autostash reference, which could be useful for scripts or other automated contexts where the output would be noise.

The changes modify the internal autostash creation function to accept a `silent` parameter and expose this through `create_autostash_ref()`. The patch also adds a `message` parameter to customize the stash description, though this appears to be unused in the current callers. The implementation maintains backward compatibility while adding these new capabilities.

This is part of a well-executed series that has already been through extensive review, with Phillip Wood providing key feedback on test organization and resource management. The changes are straightforward and focused, touching only the sequencer and merge machinery where autostash functionality lives.
