This is a feature patch in the ongoing autostash series, adding customization options for conflict markers during autostash application. The patch extends the `apply_autostash_ref()` function to accept optional parameters for customizing conflict marker labels (`label_ours`, `label_theirs`, `label_base`) and stash messages.

The changes propagate these new parameters through the autostash machinery, allowing callers to specify custom labels that will be passed through to `git stash apply`'s `--label-*` options. The implementation maintains backward compatibility by making all new parameters optional (NULL by default).

Key technical details:
- Modifies `sequencer.c` to handle the new parameters in the autostash application logic
- Updates call sites in `builtin/commit.c` and `builtin/merge.c` to pass NULL for the new parameters (preserving existing behavior)
- Adds the new parameters to function declarations in `sequencer.h`
- Uses the new `stash_msg` parameter when storing the autostash (falling back to "autostash" if NULL)

This builds on the previously merged autostash functionality, demonstrating Git's iterative refinement process where core functionality lands first and customization options follow. The patch shows careful attention to maintaining backward compatibility while extending the interface.
