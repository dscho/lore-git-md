This is a feature patch adding custom conflict marker labels to `git stash apply`. It's part of a larger series (v13) that's already been merged to `next`, focusing on autostash behavior during conflicted checkouts.

The patch introduces three new options to `git stash apply`:
- `--label-ours` - custom label for the upstream side
- `--label-theirs` - custom label for the stashed changes
- `--label-base` - custom base label (only affects diff3-style conflicts)

The implementation modifies the stash command's option parsing and passes the labels through to the merge machinery. The changes are well-contained, touching documentation, the stash command implementation, and adding new test cases that verify both normal and edge-case behavior (like empty labels).
