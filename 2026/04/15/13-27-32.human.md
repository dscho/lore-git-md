This is a feature patch implementing Linux filesystem monitoring (fsmonitor) support via inotify, part of a 15-iteration series that has now been approved for integration. The patch brings Linux fsmonitor to feature parity with existing Windows and macOS implementations.

The implementation uses inotify rather than fanotify due to privilege requirements, with careful handling of directory watches, rename tracking, and remote filesystem detection. Key technical aspects include non-blocking event polling, recursive watch registration, and mount point detection via /proc/mounts. The patch adds documentation about Linux-specific caveats including inotify watch limits and how to adjust them.

The series has undergone extensive testing across its 15 iterations, with this final version addressing all substantive review feedback and test suite issues. With maintainer approval and all test validations passing, this represents production-ready fsmonitor support across all major platforms. The implementation includes robust process isolation, proper daemon management, and simplified client-side path handling.
