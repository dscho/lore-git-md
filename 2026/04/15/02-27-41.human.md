This is a feature patch series (v4) extending Git's userdiff functionality to better support Lisp dialects. The series builds on previous iterations that unified Scheme and Common Lisp/Emacs Lisp support under a single "lisp" driver while maintaining backward compatibility.

The main changes in v4 are documentation refinements and test case improvements based on feedback from Johannes Sixt. The documentation now explicitly lists supported dialects (Scheme, Emacs Lisp, Common Lisp, Clojure) while using "most Lisp dialects" as the umbrella term. The test cases have been tightened to better handle vertical bar syntax edge cases, including escaped characters in identifiers.

The implementation uses disjunctive regex patterns to match both Scheme and Lisp forms while respecting dialect-specific conventions like case sensitivity and indentation patterns. Key technical aspects include:
- Matching top-level forms starting at column 0 or with 1-2 space indentation
- Case-insensitive handling of `(def` prefixes for Common Lisp forms
- Proper handling of vertical bar syntax with escaped characters
- Comprehensive test coverage across dialects and edge cases

The series appears well-tested and ready for integration, having addressed all technical feedback from previous rounds. Scott L. Burson and Johannes Sixt have collaborated closely on the implementation, with maintainer approval from Atharva Raykar. The changes are focused and represent a clear improvement to Git's diff highlighting for Lisp-family languages.
