This is a feature patch from Harald Nordgren that adds customizable conflict marker labels to `git stash apply`. The patch is part of a larger series that was recently merged to implement autostash behavior for conflicted branch switching, with this particular change focusing on enhancing the stash application process.

The patch introduces three new options to `git stash apply`:
- `--label-ours=<label>` - Custom label for the upstream side of conflicts
- `--label-theirs=<label>` - Custom label for the stashed changes side
- `--label-base=<label>` - Custom label for the base in diff3-style conflicts

The implementation modifies the stash application logic to use these custom values when provided, falling back to the default labels ("Updated upstream", "Stashed changes", "Stash base") otherwise. The changes span documentation updates, command option parsing in `builtin/stash.c`, and low-level conflict marker generation in `xdiff/xmerge.c`. Two new test cases verify the functionality, including edge cases with empty labels.
