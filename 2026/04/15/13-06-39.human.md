This is a test infrastructure patch in Patrick Steinhardt's ongoing series to enable `set -e` (errexit) in Git's test suite. The patch focuses on fixing test patterns that would fail under `set -e` by properly handling commands that may legitimately fail, such as prerequisite checks for binaries like `svn` and `cvs`.

The changes convert direct command execution followed by `$?` checks into proper conditional statements, using patterns like `if ! command` or the more robust `ret=0; command || ret=$?` approach that the series has standardized on. The patch touches various test scripts and library files, including SVN and CVS test prerequisites, HTTPD server startup, submodule tests, and core test library functions.

This continues the series' careful approach to hardening test infrastructure while maintaining compatibility across platforms. The changes are mechanical but important for catching more test failures early when `set -e` is enabled. Reviewers can expect this to follow the same high standard as previous patches in the series, with thorough testing across different shell environments.
