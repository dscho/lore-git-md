This is a test infrastructure change in Patrick Steinhardt's ongoing series to enable `set -e` (errexit) in Git's test suite. The patch fixes conditional test execution patterns that would fail under `set -e` by converting `test ... && test_expect_success` constructs into proper `if` statements.

The changes affect two test scripts:
- `t4032-diff-inter-hunk-context.sh` - updates file existence checks before comparing diff output
- `t7450-bad-git-dotfiles.sh` - modifies conditional tests for symlink handling to use proper conditionals

This is a mechanical but important change that makes the test suite more robust by ensuring skipped tests don't cause failures when `set -e` is enabled. The patch follows the series' established pattern of methodically addressing edge cases while maintaining readability. As with previous patches in the series, the changes are focused and well-contained, targeting specific patterns that would break under stricter error handling.
