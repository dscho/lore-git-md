This is a bugfix proposal addressing an edge case in `git log --simplify-by-decoration` behavior with empty root commits. Fernando Ramos identifies two issues when displaying commit graphs:

1. Empty root commits marked as TREESAME are incorrectly omitted from the graph output when using `--simplify-by-decoration`, making branch relationships unclear.
2. Root commits (with no parents) use the same "*" marker as regular commits, potentially misleading readers about the commit's position in the graph.

The first patch modifies `revision.c` to preserve empty root commits in the graph output when `--simplify-by-decoration` is active. The second patch proposes changing the graph marker for root commits from "*" to "I" to make their status visually distinct. The email includes a reproduction script demonstrating both the current behavior and the proposed fixes.

The changes are well-motivated by real-world confusion in graph visualization, though they do interact with Taylor Blau's prior work on TREESAME handling (commit 1343c893138). The patches are small and focused, with clear before/after examples showing the improvement in graph clarity. This seems like a reasonable quality-of-life improvement for users who rely on `--simplify-by-decoration` output.
