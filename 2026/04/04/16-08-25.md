> Regarding "--simplify-by-decoration", I found a somewhat unexpected behavior.

> Let's say we have a repository with two branches ("master" and "branch") and

> ```
>          a * <master>       b * <branch>

>
>     $ git log --graph --all --oneline --simplify-by-decoration

>     |/
>     * d783631 Start

>
>     * 7abc10a (branch) b
>     * 14d51e1 (master) a

>

> TREESAME and thus discarded when showing the graph.  This can be fixed with

> comments about it.

> Issue (2) can be "fixed" by using a diferent character (for example "I") for
> root commits (ie. those without parents), which can be done with patch #2 at the
> end of this email.

This only focuses on real roots, what about commits with excluded parents.
for example:

```
    O---A

    X---Y

    If you'd run 'git log --graph O..A Y', it shows A, Y, X but
```

because it only look for roots it
```
    ends up looking like:

      * A <- not a root but O is excluded so it seems like one
      * Y
      I X

```

This would make A and Y look related, also the "I" makes it very
confusing because
the vertical edges are very similar "|".
