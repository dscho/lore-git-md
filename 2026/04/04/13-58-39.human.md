This is part 2 of a 3-patch series continuing the `the_repository` removal effort in the refs subsystem. The patch removes usage of the global `the_hash_algo` variable from refs.c, replacing it with repository-specific hash algorithm lookups where possible.

The changes are mechanical but important - transaction-related functions now get the hash algorithm from the transaction's ref_store->repo, while other cases use the repository parameter directly. This affects ref creation/deletion, submodule ref stores, hook stdin feeding, and ref migration. The patch maintains existing behavior while moving toward the goal of eliminating global state.

This is the fifth iteration of the series, showing the author's responsiveness to review feedback. The changes are well-contained and follow established patterns of the larger `the_repository` removal effort led by René Scharfe. While not flashy, these incremental improvements are exactly what's needed to make the codebase more maintainable long-term.
