This is version 5 of a refactoring series that's part of the ongoing `the_repository` removal effort. Shreyansh Paliwal continues converting the refs subsystem to explicitly pass repository context rather than relying on global state, with three focused patches addressing lock timeouts, hash algorithm usage, and reftable backend changes.

The series has been narrowed down from previous iterations, with more complex branch helper conversions deferred for future work. The current patches systematically remove `the_repository` and `the_hash_algo` usage in specific areas: file ref lock timeouts now take explicit repository parameters (1/3), refs.c replaces hash algorithm globals with repository-specific versions (2/3), and the reftable backend removes remaining `the_repository` uses where repository context is already available (3/3).

Version 5's main change is improving the commit message for patch 1/3 to be more explicit about the remaining static variables and the need for future work to fully repository-scope the lock timeout functionality. The changes remain mechanical but important steps in René Scharfe's long-running effort to eliminate global state, following established patterns while maintaining existing behavior. The series appears well-structured, with the author responsive to review feedback and willing to iterate on more challenging aspects separately.
