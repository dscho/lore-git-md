This is a bugfix patch addressing a memory leak in `repo_init()`, discovered while working on the parallel hooks series. The leak occurs when enabling a v1 extension in a v0 repository format - an edge case that only surfaces in development environments, not normal usage. The fix is straightforward: adding a call to `clear_repository_format()` in the error path.
