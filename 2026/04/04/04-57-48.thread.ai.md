Thread summary:

Proposal to extend `git repo info` with path-related metadata fields (Git directory, working tree root, object directory) to reduce reliance on `git rev-parse` for these queries. Submitted by Arsh Srivastava as part of a GSOC project. The implementation would follow existing getter patterns in `repo.c`. Currently seeking feedback on whether this extension fits the command's intended scope before proceeding with implementation. No patches yet; this is an early design discussion to validate the approach. The proposal is well-motivated by the current need to use multiple commands for complete repository metadata.
