This is a bugfix for the `git backfill` command's sparse-checkout integration. The patch corrects an initialization issue where the command wasn't properly detecting sparse-checkout settings from repository configuration when no explicit `--sparse` or `--no-sparse` flags were provided.

The problem stems from the `ctx->sparse` field being initialized to 0 (false) rather than -1 (unset), which prevented the fallback to checking `core.sparseCheckout` configuration. The fix is straightforward - changing the initialization to -1 - and comes with a new test case verifying the command now correctly respects sparse-checkout settings when no flags are given.
