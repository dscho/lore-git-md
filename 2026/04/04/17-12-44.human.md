This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's manual pages to the synopsis-style AsciiDoc format. The patch converts the `git-difftool` man page and related config sections (`difftool.adoc`, `mergetool.adoc`) to the new format.

The changes are purely presentational - restructuring the documentation to follow the project's preferred markup style without altering the actual content. The conversion includes:
- Using backticks for command and option names
- Standardizing placeholder notation with `_<placeholder>_`
- Adjusting conditional text formatting
- Reorganizing the SYNOPSIS section to use the new `[synopsis]` style

The patch follows the well-established pattern for these documentation conversions, showing balanced additions and deletions (56 lines each) as the content is reorganized rather than substantively changed. This is routine maintenance in the long-running documentation standardization effort that has been consistently accepted into the project. Reviewers would primarily check for accidental content changes or formatting errors rather than debating the conversion approach itself.
