This is a refactoring patch in the parallel hook execution series, moving the `is_known_hook()` function from being a static helper in `builtin/hook.c` to a public function in `hook.c`. The change enables wider reuse of this hook validation logic, particularly for the upcoming namespace collision detection in the next patch.

The patch changes:
1. Moves the function implementation to `hook.c` with minor style tweaks (using `bool` return type and renaming the iterator to `h`)
2. Exports it via `hook.h` with documentation
3. Updates build systems (Makefile and meson.build) to reflect the header's new location in libgit rather than builtin sources
4. Includes a co-author credit for Patrick Steinhardt who helped with the meson.build changes

This is a straightforward code reorganization with no behavior changes, serving as infrastructure for the subsequent patch that will use this function to detect and warn about hook name/event name collisions. The build system adjustments ensure the relocated function remains properly linked across both build systems.
