This is a test modernization patch in Johannes Schindelin's series preparing for potential future changes to bare repository discovery behavior. The patch updates HTTP push tests in t5540 and t5541 to explicitly specify bare repository locations rather than relying on implicit discovery.

The changes modify `t/lib-httpd.sh` to use `--git-dir` when accessing the bare `REMOTE_REPO`, replacing previous invocations that assumed implicit discovery would work. The key technical changes are:
- Converting `git rev-parse` calls to use `--git-dir=.` when inside `$REMOTE_REPO`
- Replacing subshell-based repository access with direct `--git-dir="$REMOTE_REPO"` invocations
- Updating the force-with-lease test to use explicit bare repository specification throughout

This follows the established pattern from earlier patches in the series, demonstrating how to handle repository operations when combined with HTTP push testing. The changes are minimal (5 insertions, 7 deletions) but systematically eliminate implicit bare repository assumptions in the test helpers.

The patch maintains all existing test coverage while making the tests robust against potential future changes to `safe.bareRepository` defaults. It's part of the larger effort to modernize Git's test infrastructure in preparation for Git 3.0, though the behavior change itself remains guarded behind `WITH_BREAKING_CHANGES`.
