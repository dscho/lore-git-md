This is a feature patch (part 3/12 in a series) introducing the global `hook.jobs` configuration for parallel hook execution. The patch adds plumbing to parse and store the `hook.jobs` value from config, which will serve as the default parallelization level for all hooks unless overridden by more specific settings (to be added in later patches).

The implementation:
- Adds documentation for `hook.jobs` in config/hook.adoc
- Extends the hook config callback to parse the global jobs setting
- Stores the parsed value in the repository->hook_jobs field
- Includes validation to ensure the value is a positive integer
- Maintains backwards compatibility by defaulting to serial execution (1 job) when unset

This is foundational work for the larger parallel hooks feature, which has already received maintainer approval in principle.
