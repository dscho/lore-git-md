This is part 2 of Johannes Schindelin's 17-patch series modernizing Git's test infrastructure to explicitly handle bare repositories, preparing for a potential future change where `safe.bareRepository` would default to `explicit`. The patch specifically updates the `check_config` helper in t0001-init.sh to use `--git-dir` instead of relying on implicit repository discovery via `cd`.

The change is straightforward - it replaces two instances of `cd` followed by `git config` with direct `git --git-dir` invocations. This ensures the test helper will continue working even if implicit bare repository discovery is disabled by default in the future. The patch maintains the exact same test semantics while making the repository access explicit.

This is a mechanical change that follows the pattern established in the series for handling bare repositories. It's part of the broader effort to make tests more robust against potential future behavior changes while also improving test hygiene by removing reliance on implicit behavior. The patch has no functional impact on current test execution.
