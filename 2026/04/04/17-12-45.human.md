This is a documentation patch, part of Jean-Noël Avila's ongoing effort to standardize Git's manual pages to a consistent synopsis style using AsciiDoc markup. The patch converts the `git-range-diff` man page to the new format, following the same mechanical changes seen in previous documentation conversions:

- Options and commands are now wrapped in backticks for monospace formatting
-d`, `--creation-factor`)
- Placeholder arguments use `_placeholder_` syntax
- The SYNOPSIS section is reorganized with `[synopsis]` markup
- References to other man pages use single quotes ('Algorithm') rather than double quotes

The changes are purely presentational - no content is altered beyond formatting. This continues the well-established pattern of documentation standardization that has been progressing smoothly through the project. Reviewers need only verify the formatting changes are correct and no accidental content modifications were introduced. The patch is straightforward and uncontroversial, touching only the `Documentation/` directory with balanced line additions/deletions (25 each).
