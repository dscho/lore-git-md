This is a test modernization series preparing for a potential future change in Git's default behavior regarding bare repository discovery. Johannes Schindelin's 17-patch series updates test scripts to explicitly handle bare repositories rather than relying on implicit discovery, which may become disabled by default in Git 3.0.

The series systematically converts test infrastructure across 16 test files and git-p4.py to use explicit repository specification patterns: `--git-dir` for bare repos, `-C` for non-bare, and `safe.bareRepository=all` exceptions where implicit discovery is genuinely needed. The changes originated from CI breakage when experimenting with default behavior changes, but have independent value as test suite hygiene improvements.

Key technical aspects include preserving exact test behavior while making repository access explicit, particularly for edge cases like `ext::` URL path resolution. The v2 iteration simplified the t5509 solution by using `--git-dir=.` after `-C` rather than modifying URL paths, maintaining the original test semantics while satisfying the explicit access requirement.

While technically a prerequisite for changing defaults, these test improvements stand on their own as modernization work. The series demonstrates Git's high standards for test reliability during infrastructure changes, with careful attention to URL resolution semantics and maintainable patterns. The changes are mechanical but widespread, touching various test areas including worktree handling, fetch/push, submodules, and the git-p4 bridge.
