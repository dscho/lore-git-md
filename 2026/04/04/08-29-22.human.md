This is the final version (v6) of a feature series introducing parallel hook execution, now ready for merging. The series builds on Adrian Ratiu's earlier configurable hooks work and has received maintainer acks from Junio C Hamano. The v6 iteration includes only minor build system fixes from Patrick Steinhardt to correctly track header dependencies between the Makefile and meson.build systems.

The core functionality enables parallel execution of hooks with comprehensive configuration: a global `hook.jobs` default (now supporting `-1` for automatic CPU core detection), per-hook `hook.<name>.parallel` flags, CLI `-j/--jobs` override, and per-event `hook.<event>.jobs` settings. Special handling maintains backwards compatibility for the pre-push hook's output behavior in serial mode while merging streams in parallel mode. Seven hooks are marked as non-parallelizable by default due to shared resource constraints.

The implementation is thorough, touching multiple builtin commands and adding extensive test coverage in t/t1800-hook.sh. All technical concerns raised during review have been addressed, leaving only minor philosophical questions about future namespace organization that don't block merging. With the meson.build fix now incorporated and all tests passing, this series appears ready for final integration.
