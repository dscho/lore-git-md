This is a documentation follow-up to a bugfix patch that improved `git stash`'s argument parsing. The original patch made `git stash` automatically assume a "push" subcommand when unambiguous push-specific options (like `-m`, `--staged`, etc.) are present, rather than requiring explicit "push" or `--` before pathspecs.

Second, since the behavior described in the documentation is no longer accurate (there are now more exceptions beyond just `-p`), the man page for `git stash push` should be updated to reflect the current rules.
