This is a bugfix patch addressing a memory leak in `repo_init()`. The leak occurs in an error path when initializing a repository with v1 extensions on a v0 format repository - an edge case that would happen in development environments rather than normal usage. The fix is straightforward: adding a call to `clear_repository_format()` in the error case to properly clean up allocated memory.

The patch is part of Adrian Ratiu's larger parallel hooks series (v6 01/12), but this particular fix is independent and targets a pre-existing issue in the repository initialization code. While the memory leak was hard to trigger in practice, the fix follows good hygiene by ensuring proper cleanup in all error paths. The change is minimal (a single line addition) and low-risk, touching only the error handling path of a core function.
