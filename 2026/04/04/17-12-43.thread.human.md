Jean-Noël Avila continues his ongoing effort to standardize Git's documentation format with a series converting several manual pages to the project's synopsis-style AsciiDoc. The series now includes conversions for `git-difftool`, `git-range-diff`, and the newly added `git-shortlog`, with `git-describe` still to come. Each conversion follows the same mechanical process: wrapping commands and arguments in consistent formatting (backticks for options, underscores for placeholders), reorganizing SYNOPSIS sections, and normalizing cross-references - all without changing the actual content.

These changes are now a well-established part of the documentation maintenance workflow, requiring reviewers only to verify the correct application of the formatting rules rather than evaluating substantive changes. The work remains confined to the `Documentation/` directory with no impact on code behavior. With no open questions or unresolved issues, the series represents routine maintenance as part of the broader documentation standardization initiative that has been progressing steadily across many prior patch series.
