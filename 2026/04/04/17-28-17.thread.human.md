This thread addresses a bug in `git diff` that causes a segfault when comparing large files outside a Git repository, stemming from incorrect assumptions about object database (ODB) initialization. The issue was identified as part of the ongoing `the_repository` removal effort.

Justin Tobler proposed and implemented a solution that introduces a "hash-only" mode for blob indexing, which cleanly bypasses ODB transactions when only hashing is needed (as in repository-less operations). The approach maintains efficient streaming behavior for large files while avoiding the segfault. Jeff King (Peff) reviewed and confirmed the technical soundness of this solution, which is simpler than alternative approaches like conditional transaction handling. Luca Stefani verified the fix and will provide a Tested-by tag.

The fix will be extracted from Justin's larger ODB transaction series as a standalone patch, making it easier to backport if needed. Justin confirms he's proceeding with implementation and will include tests to verify the correction. All technical questions have been resolved, and the patch is expected soon. This solution may also inform future handling of hash-only operations in Git's codebase.
