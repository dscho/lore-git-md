This is a test modernization series preparing for a potential future change in Git's default behavior regarding bare repository discovery. Johannes Schindelin's 17-patch v2 series updates test scripts to explicitly handle bare repositories rather than relying on implicit discovery, which may become disabled by default in Git 3.0.

The series systematically converts test infrastructure across 16 test files and git-p4.py to use explicit repository specification patterns: `--git-dir` for bare repos, `-C` for non-bare, and `safe.bareRepository=all` exceptions where implicit discovery is genuinely needed. The changes are mechanical but widespread, touching various test areas including worktree handling, fetch/push, submodules, and the git-p4 bridge.

Key improvements in v2 include a simplified solution for t5509 that preserves `ext::` URL semantics by using `--git-dir=.` after `-C`, addressing Junio Hamano's technical concerns from the previous iteration. The series now has no remaining substantive technical objections and demonstrates Git's high standards for test reliability during infrastructure changes.
