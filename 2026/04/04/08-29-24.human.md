This is a refactoring patch that adds unsigned integer parsing helpers to Git's config system, part of Adrian Ratiu's parallel hook execution series (v6 02/12). The patch introduces `git_config_uint()`, `git_configset_get_uint()`, and `repo_config_get_uint()` functions, along with a new `git_parse_uint()` parser, to properly handle unsigned integer configuration values.

The change is motivated by the need to parse the new `hook.jobs` config option as an unsigned value rather than using the existing signed or unsigned long alternatives. The implementation follows the same pattern as other config type helpers, adding the new functions to config.c/h and parse.c/h with appropriate documentation.

This is a straightforward infrastructure addition that enables the parallel hooks feature while maintaining type safety. The patch has clean diffs and follows Git's established patterns for config value handling. As part of a well-reviewed series that has maintainer approval, this foundational change appears ready for inclusion.
