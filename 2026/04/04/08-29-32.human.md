This is a refactoring patch in Adrian Ratiu's parallel hook execution series (v6 10/12). The patch moves the `is_known_hook()` function from being a static helper in `builtin/hook.c` to a public function in `hook.c` so it can be reused by other parts of the codebase. 

The change makes the function return a `bool` for clarity and updates the build system (both Makefile and meson.build) to reflect that the hook-list.h header is now used by libgit rather than just the builtin sources. The next patch in the series will use this function to detect when users mistakenly configure hooks using friendly names (like "pre-commit") instead of event names.

This is a straightforward mechanical change that has already been reviewed and approved, with Patrick Steinhardt providing co-authorship on the meson.build adjustments. The patch helps enable the subsequent namespace validation work while keeping the codebase cleanly organized.
