This is a test modernization patch from Johannes Schindelin's series preparing Git's test suite for a potential future change in bare repository handling. The patch modifies test t0001-init.sh to explicitly allow bare repository discovery via `safe.bareRepository=all` for a test that verifies alias resolution works in bare repos.

The change is straightforward - it adds a global config setting to preserve the test's existing behavior while making the bare repository access explicit. This is part of a larger effort to systematically update tests to handle bare repositories explicitly rather than relying on implicit discovery, which may be disabled by default in future Git versions.

The patch demonstrates good test hygiene by isolating the bare repository permission change to just the test that needs it (testing alias resolution rather than bare repo behavior itself). It follows the pattern established in the larger series of using `safe.bareRepository=all` where implicit discovery is genuinely required for the test's purpose.
