This is a test modernization patch in Johannes Schindelin's series preparing for potential future changes to bare repository discovery behavior. The patch modifies t0056-git-C.sh to temporarily enable implicit bare repository discovery for tests that specifically verify the interaction between `-C` and `--work-tree` flags.

The tests in question need to enter a `.git` directory while also specifying a worktree, which would normally trigger the bare repository safety checks. Since these tests are explicitly testing this flag combination, using `--git-dir` would defeat their purpose. The solution is to temporarily set `safe.bareRepository=all` for these test cases.

This patch follows the established pattern from earlier in the series where tests that genuinely require implicit discovery are explicitly marked as exceptions. The change is minimal (just two test_config_global additions) and maintains the test's verification of flag interaction behavior while accommodating the potential future safety defaults.

The patch is part of a well-structured series that has already addressed technical concerns in previous iterations, and this particular change aligns with the overall approach of making test behavior explicit while preserving test semantics.
