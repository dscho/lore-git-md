This is a test modernization patch in Johannes Schindelin's series preparing for a potential future change to make `safe.bareRepository` default to `explicit`. The patch updates t1900-repo-info.sh to handle bare repositories properly by using `--git-dir` instead of `-C` when accessing them.

The change modifies the `test_repo_info` helper to accept an optional `repo_flag` parameter (defaulting to `-C` for non-bare repos) and updates the bare repository test case to use `--git-dir` instead. This maintains the same test coverage while properly specifying repository access for the case where bare repository discovery might be disabled by default in the future.

The patch follows the established pattern from earlier in the series of explicitly specifying repository locations rather than relying on implicit discovery. It's a straightforward mechanical change that aligns with the series' goal of making tests work regardless of future `safe.bareRepository` defaults. The change is well-contained and maintains the existing test semantics while using the more appropriate flag for bare repository access.
