This is a technical refinement in the now-concluded autostash feature series, adding customizable conflict marker labels to the autostash application process. The patch extends the `apply_autostash_ref()` function to accept optional labels for "ours", "theirs", and "base" sides of conflicts, plus a custom stash message.

The changeset modifies four files to thread these new parameters through the autostash machinery, with the core logic in `sequencer.c` now passing the labels to `git stash apply` via new `--label-*` options when present. The implementation maintains backward compatibility by passing NULL values from existing callers in `builtin/commit.c` and `builtin/merge.c`.

This represents one of the final post-merge refinements to a feature that went through 19 iterations (14 pre-merge and 5 post-merge) with extensive review from Phillip Wood and Junio C Hamano. The series as a whole provides unified conflict resolution experience for branch switching operations, now including both label customization and silent operation capabilities.

The patch is cleanly focused on its single purpose and follows the established pattern of the larger series. With all technical objectives now complete, this marks the conclusion of a well-executed feature development cycle in Git's mailing list workflow.
