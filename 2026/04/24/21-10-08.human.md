This is a feature patch that allows customizing conflict marker labels in `git stash apply`. It's part of a concluded 18-iteration effort to implement autostash behavior for conflicted branch switching.

The patch adds three new options to `git stash apply`:
- `--label-ours` - Custom label for the upstream side in conflict markers
- `--label-theirs` - Custom label for the stashed changes
- `--label-base` - Custom label for the base in diff3-style conflicts

The implementation handles empty labels (showing just the conflict markers without text) and maintains backward compatibility by falling back to the original labels ("Updated upstream", "Stashed changes", "Stash base") when no custom labels are provided. The changes touch documentation, the stash command implementation, and the underlying xdiff merge machinery.

Test coverage includes verification of:
- Custom labels in both regular and diff3 conflict styles
- Empty label behavior
- Proper integration with the existing stash apply functionality

This represents the final refinement of a long-running feature that has already been merged, with all technical objectives achieved and all review feedback addressed. The patch demonstrates careful attention to edge cases and maintains Git's existing behavior while adding the new customization capability.
