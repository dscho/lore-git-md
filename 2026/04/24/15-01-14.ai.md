Test fix addressing a configuration preservation issue in the clone tests.

This patch fixes a test in t5601-clone.sh that was inadvertently breaking subsequent tests by overwriting the global `.gitconfig` file. The test was modifying the config to test `includeIf` functionality but wasn't properly restoring the original state, which caused failures in later tests that relied on the `safe.bareRepository=all` setting added by test-lib.sh.

The solution backs up the original `.gitconfig` before the test and restores it afterward. This is particularly important fix when running with `WITH_BREAKING_CHANGES` enabled, as that's when the problematic `safe.bareRepository` setting gets added. The patch comes from Johannes Schindelin (Git for Windows maintainer) with assistance from Claude Opus 4.6 (likely an AI assistant).

This is a straightforward test infrastructure fix that properly maintains test isolation by ensuring global configuration changes don't leak between tests. The change is minimal (just 3 lines added) and follows the established pattern of using `test_when_finished` for cleanup.
