This is a bugfix patch that restores support for hierarchical/dotted aliases (like `pull.sub`) that broke in Git 2.54.0 due to changes in the alias handling code. The regression was reported by Michael Grossfeld and analyzed by Jeff King and René Scharfe before being fixed by the original author of the alias syntax changes, Jonatan Holmgren.

The patch makes Git fall back to treating the full name as an alias when the final key isn't "command", which preserves both the new subsection syntax functionality while restoring backward compatibility for simple dotted aliases. It includes test coverage verifying both execution and help output behavior for dotted aliases.

The fix addresses a real regression that affected users relying on documented functionality, and the patch appears well-crafted with thorough test coverage. The change has already received implicit endorsement from key contributors Jeff King and René Scharfe during the analysis phase. The only minor issue noted in the thread is a missing Signed-off-by trailer, which is a surface-level concern.

This seems likely to be accepted and possibly backported to the 2.54.x maintenance series since it fixes a regression in documented functionality. The patch maintains the existing edge case where aliases ending in ".command" remain broken (as that was the original intended behavior of the new syntax).
