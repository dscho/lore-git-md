Test fix addressing status output pollution from `.gitconfig` files.

This patch from Johannes Schindelin (part of an 8-patch series) fixes test failures caused by `.gitconfig` files appearing in `git status` output. The test infrastructure creates these files when `WITH_BREAKING_CHANGES` is set, causing them to show up as untracked or ignored files in test assertions.

The solution introduces a `filter_gitconfig` helper to strip these entries from status output before comparison in affected tests (t7061 and t7521), with targeted adjustments in three other test scripts. The changes are mechanical but necessary to maintain test reliability when the breaking changes flag is enabled.

The patch demonstrates careful attention to test hygiene, ensuring the test suite remains robust across different configurations. It's a straightforward fix that doesn't introduce new functionality but maintains existing test coverage.
