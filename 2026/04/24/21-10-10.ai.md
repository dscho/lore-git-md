This is a technical refinement in the now-concluded autostash feature series, adding support for custom conflict marker labels during autostash application. The patch extends the `apply_autostash_ref()` interface to accept optional labels for "ours", "theirs", and "base" markers, plus a custom stash message.

The implementation threads these new parameters through the autostash machinery down to the `git stash apply` call, adding corresponding `--label-*` options when present. The changes touch four files:
- `sequencer.c` gets the core implementation with new parameters
- `sequencer.h` updates the function prototype
- `builtin/commit.c` and `builtin/merge.c` are updated to pass NULL for the new parameters (maintaining current behavior)

This represents one of the final post-merge refinements to the autostash feature after its initial implementation. The patch follows the established pattern of the series with careful parameter handling and maintains backward compatibility by making all new parameters optional. The changes are focused and mechanical, primarily involving plumbing the new options through existing call chains.
