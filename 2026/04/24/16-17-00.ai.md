This is a bugfix patch that restores support for hierarchical/dotted aliases (like `pull.sub`) that broke in Git 2.54.0 due to changes in the alias handling code. The patch comes from Jonatan Holmgren, who originally introduced the regression in commit ac1f12a9de.

The fix implements the solution approach previously vetted by Jeff King and René Scharfe in the thread. It makes Git fall back to treating the full name as an alias when the final key isn't "command", which preserves both the new subsection syntax functionality and restores backward compatibility for simple dotted aliases. The patch includes test coverage verifying both execution and help output behavior for dotted aliases.

Notably, this maintains the documented edge case where aliases ending in ".command" remain broken (as that's the marker for the new subsection syntax). The fix is clean and focused, touching only the necessary parts of alias.c and help.c while adding comprehensive tests in t0014-alias.sh.

The patch is well-structured with a clear commit message explaining both the problem and solution. It includes proper attribution via Reported-by and Helped-by trailers, though Kristoffer Haugsbakk noted the missing Signed-off-by trailer in a follow-up. This appears ready for merging and would be a good candidate for backporting to maint since it fixes a regression affecting documented functionality.
