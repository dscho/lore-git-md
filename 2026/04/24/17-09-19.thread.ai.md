Subject: [PATCH v3] Worktree-shared exclude files in gitignore(5)
Series version: v3.
Originating author: D. Ben Knoble.
Thread type: documentation fix patch series.

Core problem/goal: The gitignore(5) man page and several other documentation and source files inaccurately state that per-repository exclude files live at `$GIT_DIR/info/exclude`. Since Git 2.20, these files are actually stored in `$GIT_COMMON_DIR/info/exclude`, a path shared by all worktrees. The patch corrects all stale references to match the existing behavior. No code behavior changes.

Current status: v3 submitted. Phillip Wood has reviewed and given a surface-level approval ("this looks good to me"). All known stale references have been corrected, addressing the v2 review feedback in full. The patch appears ready for merge pending a final pick-up by Junio.
