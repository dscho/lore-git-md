Per-worktree ignore patterns via new `extensions.worktreeIgnore` config option (D. Ben Knoble). Currently all worktrees share `$GIT_COMMON_DIR/info/exclude`. New option allows:
- Unset/`no`: current behavior (only common exclude)
- `worktree`: worktree-specific excludes (`$GIT_DIR/info/exclude`)
- `merge`: combine both common and worktree excludes

Implementation in `dir.c` checks config to select exclude files. Thorough docs update across 3 man pages. New test `t2408-worktree-ignore.sh` verifies all modes by creating main/secondary worktrees with different excludes and checking ignored files. Backward-compatible default. Handles invalid config values and integrates with existing exclude-file loading.
