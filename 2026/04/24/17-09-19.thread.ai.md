Subject: [PATCH v2] Worktree-shared exclude files in gitignore(5)

Series version: v2 (v3 expected soon).

Originating author: D. Ben Knoble.

Thread type: documentation fix patch series.

Core problem/goal: The gitignore(5) man page inaccurately states that per-worktree exclude files live at `$GIT_DIR/info/exclude`. Since Git 2.20, these files are actually stored in `$GIT_COMMON_DIR/info/exclude`, a path shared by all worktrees in a repository. The patch corrects the documentation to match the existing behavior, with no code changes.

Current status: v2 partially addresses the issue by updating the primary references in gitignore(5), but v3 is pending to fix all remaining instances.

Key technical details:
- Files and subsystems touched: `Documentation/gitignore.adoc`.
- Behavior change: none. This is a pure documentation fix to match a behavioral change that occurred in Git 2.20.
