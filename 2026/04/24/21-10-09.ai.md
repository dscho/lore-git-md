This is a post-merge refinement patch in the concluded autostash feature series, adding silent operation capability to autostash creation. The patch allows callers to suppress the "Created autostash" message when needed, particularly for internal operations where user feedback would be inappropriate.

Key changes:
1. Adds a `silent` parameter to `create_autostash_internal()` and exposes it through `create_autostash_ref()`
2. Allows customizing the stash message (default remains "autostash")
3. Updates callers in `builtin/merge.c` to use the new interface while maintaining current behavior
4. Preserves all existing functionality while adding the new capability

The implementation is clean and focused, with:
- Clear parameter passing through the call chain
- Backward-compatible defaults
- Minimal changes to existing call sites
- No behavioral changes unless explicitly requested via new parameters

This represents the final polish on a long-running feature that has already undergone extensive review and testing. The patch demonstrates Git's characteristic attention to detail in post-merge refinement, ensuring the interface meets all anticipated use cases while maintaining clean separation of concerns.
