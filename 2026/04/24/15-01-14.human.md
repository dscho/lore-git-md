Test fix for includeIf configuration handling.

This patch fixes an issue in the t5601-clone.sh test where a test overwriting `$HOME/.gitconfig` was inadvertently breaking subsequent tests. The test modifies the global gitconfig to test `includeIf` behavior, but its cleanup was too aggressive - it removed the config file entirely, including the `safe.bareRepository=all` setting that test-lib.sh adds when `WITH_BREAKING_CHANGES` is active. This caused later tests to fail when trying to access bare repositories.

The solution is straightforward: back up the original `.gitconfig` before modifying it, then restore it during cleanup. The patch handles edge cases gracefully - if the backup fails, it falls back to removing the modified config (though this would still leave subsequent tests broken, it's better than leaving test artifacts).

This is part of a larger series (position 5/8) but stands alone as a clear test fix. The change is minimal and well-explained, with the commit message clearly identifying both the problem and solution. The patch demonstrates good test hygiene by ensuring one test doesn't interfere with others.
