Feature patch adding a `--fetch` option to `git checkout` and `git switch` to automatically fetch remote refs before branch creation.

Kristoffer Haugsbakk provides a review of Harald Nordgren's patch that adds a `--fetch` flag to `git checkout` and `git switch`. The review is substantive, focusing on naming consistency and documentation clarity rather than implementation issues.

Key points from the review:
1. Questions why the config option is named `checkout.autoFetch` rather than matching the flag name as `checkout.fetch`
2. Approves of the design choice to only fetch when a remote-tracking branch is specified (avoiding unnecessary fetches)
3. Suggests the motivation for the feature should be included in the commit message itself rather than just the cover letter
4. Notes two documentation nits about using "remote-tracking branch" instead of "remote-tracking ref" in the help text
5. Observes that documentation updates (man pages) will presumably come in a later version

The review doesn't raise any technical concerns with the implementation, but focuses on making the user-facing aspects more consistent and better documented. The reviewer seems generally positive about the feature but wants to ensure the interface follows Git's conventions.
