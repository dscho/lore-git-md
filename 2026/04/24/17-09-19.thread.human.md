This thread is about a long-standing documentation inaccuracy in `gitignore(5)`, which incorrectly states that per-worktree exclude patterns live at `$GIT_DIR/info/exclude` when in fact they reside at `$GIT_COMMON_DIR/info/exclude` -- a path shared across all worktrees in a repository. D. Ben Knoble sent a v2 patch to fix this, and in a thorough review using `git grep`, Phillip Wood found that the fix was too narrow: five additional instances of the same error remain in `gitignore.adoc` alone, plus mentions in other documentation files.

Knoble has acknowledged the catch and will submit a v3 that addresses all of the ignore-related references. He is leaving the unrelated documentation files for a separate pass. The thread remains strictly documentation-only; there is no revived discussion of per-worktree ignores as a feature. Phillip Wood supports the approach and has no objections. A v3 that catches everything should be the final version before merging, followed by a review from brian m. carlson or Junio C Hamano.
