This thread is a documentation fix from D. Ben Knoble correcting the gitignore(5) man page (and several other files) to state that per-repository exclude files live at `$GIT_COMMON_DIR/info/exclude` rather than the outdated `$GIT_DIR/info/exclude`. The change aligns the documentation with Git's actual behavior since version 2.20 -- no code changes are involved.

The thread started with an original proposal (v1) for true per-worktree ignore files, but that received negative feedback from brian m. carlson, Phillip Wood, and Junio C Hamano, so the author scaled back to a documentation-only correction. In v2, the author updated some references in gitignore.adoc but left others. Phillip Wood provided a substantive review, identifying via `git grep` that five additional spots within gitignore.adoc still used the old path, plus instances in other documentation files.

Now in v3, the author has addressed all of Wood's feedback: the patch touches six files (Documentation/gitignore.adoc, git-ls-files.adoc, git-svn.adoc, gitformat-index.adoc, dir.c, and dir.h) with thirteen lines of purely substitutional changes. The patch also resolves the scope creep issue: the author explicitly notes that other documentation files referencing the old path are left for a separate pass. Wood's review was the only one on the series, and it has been fully addressed. The patch should be ready for merging after a final look from a maintainer.
