This thread explored the possibility of implementing per-worktree ignore patterns, prompted by D. Ben Knoble's use case involving LLM tool skill files across multiple worktrees. After initial implementation attempts, the discussion shifted when Junio Hamano expressed skepticism about the feature's necessity and Phillip Wood raised technical concerns about path handling. The proposal was ultimately scaled back to a documentation-only fix that accurately describes Git's current behavior of storing exclude patterns in the common directory.

The v2 patch correcting the gitignore(5) man page has now received positive feedback from brian m. carlson, confirming the documentation fix is the right approach. With this review, the thread appears to be concluding with consensus around maintaining the status quo for ignore pattern handling while ensuring the behavior is properly documented. The original feature exploration is effectively closed unless new compelling use cases emerge or someone proposes a more comprehensive worktree-info-files framework in the future.
