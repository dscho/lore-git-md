Test fix addressing a bare repository discovery issue in config include cycle tests.

This patch fixes a test failure in t1305-config-include.sh that occurs when running with WITH_BREAKING_CHANGES enabled. The test creates a bare repository to verify config include cycle detection, but fails because earlier tests overwrite $HOME/.gitconfig, clobbering the safe.bareRepository=all entry that test-lib.sh sets up.

The solution is to explicitly specify --git-dir=. when accessing the bare repository, avoiding reliance on global config for repository discovery. This makes the test more robust by removing the dependency on the safe.bareRepository setting. The change is minimal - just adding --git-dir=. to two git -C cycle commands.

The fix comes from Johannes Schindelin (Git for Windows maintainer) with assistance from Claude Opus 4.6 (likely an AI assistant).
