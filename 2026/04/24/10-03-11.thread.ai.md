Thread subject: [PATCH v10] checkout/switch: extend --track with fetch mode for remote ref updates

Core problem/goal: Extend `git checkout`/`git switch` with `--track=fetch` to automatically fetch from the remote when creating a tracking branch, eliminating the need for a separate `git fetch` step. This addresses a workflow pain point where users must manually fetch before checking out a remote branch.
