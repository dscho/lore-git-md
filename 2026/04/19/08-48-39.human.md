This is a feature patch adding a new `--missing=print-only` mode to `git rev-list` for partial clone workflows. The change is motivated by GitLab's Gitaly service, which currently has to post-process the output of `--missing=print` to extract just the missing object IDs.

The patch introduces a new mode that:
- Only outputs missing OIDs (no present objects)
- Omits the '?' prefix used in the existing print mode
- Outputs one OID per line
- Includes a helper function to consolidate the print-related logic

The implementation touches documentation, the rev-list command, and adds new test coverage. The patch appears well-structured with a clear motivation stated in the cover letter. This seems like a straightforward quality-of-life improvement for partial clone tooling, particularly for GitLab's infrastructure needs.

The patch is based on Git 2.54-rc2 and includes CI results from GitLab's pipeline. Given the narrow scope and clear use case, this seems likely to be uncontroversial. Reviewers may want to verify the test coverage handles edge cases, but the change itself is conceptually simple.
