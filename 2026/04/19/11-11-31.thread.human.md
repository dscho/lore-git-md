The Git 2.54.0 localization updates have been merged, bringing refreshed translations for Traditional Chinese (zh_TW), Bulgarian, Catalan, French, Irish, Swedish, and Turkish. The zh_TW changes were particularly substantial, with nearly 2,000 lines updated to improve accuracy. Jiang Xin coordinated the effort, with contributions from Alexander Shopov (Bulgarian), Jean-Noël Avila (French), and Emir SARI (Turkish), among others.

This round also introduced workflow improvements to maintain translation quality. A new `po/.gitattributes` file helps catch style inconsistencies, while `po/AGENTS.md` provides contributor guidelines. The team used AI-assisted review to identify quality issues in pull requests. These infrastructure changes complement the actual translation work that Junio C Hamano has already merged for the 2.54.0 release. The updates follow Git's standard localization process through the git-l10n/git-po repository, and no further action is needed for this release cycle.
