This thread implements a `--missing-only` option for `git rev-list` to support GitLab's Gitaly partial clone workflows. The feature, introduced by Siddharth Asthana, allows listing only missing object IDs in a script-friendly format, eliminating the need for post-processing to strip the `?` prefix from standard `--missing=print` output.

The implementation is complete and has incorporated all review feedback. The design cleanly separates formatting (controlled by `--missing=`) from filtering (now handled by `--missing-only`), with clear documentation and test coverage. Key participants—including Derrick Stolee, Patrick Steinhardt, Phillip Wood, and Kristoffer Haugsbakk—endorsed the approach, and the only remaining question was Junio Hamano's inquiry about how Gitaly consumes the missing object list.

That question has now been resolved: Siddharth clarified that Gitaly uses the feature in a single-pass transaction packing workflow, where missing objects are recorded as dependencies but not fetched. This confirms the feature is fit for purpose, and the patch is ready for final approval. No further code changes are expected.
