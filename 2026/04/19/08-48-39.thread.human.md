This thread introduced a `--missing-only` option for `git rev-list` to help GitLab's Gitaly efficiently identify missing objects in partial clones. The feature, proposed and implemented by Siddharth Asthana, lets GitLab list only missing object IDs in a single pass for transaction packing, avoiding the need for post-processing.

After two rounds of review and discussion, the implementation is complete. Key contributors—Derrick Stolee, Patrick Steinhardt, Phillip Wood, and Kristoffer Haugsbakk—helped refine the design, ensuring the new flag cleanly separates filtering from formatting and works well with existing `--missing=` options. The final version rejects incompatible options like `--count` and `--disk-usage` with clear error messages, and tests cover all edge cases. Junio C Hamano, the maintainer, initially asked about Gitaly's workflow but was satisfied with the clarification that the feature supports a single-pass transaction packing process.

The patch is now approved and ready for integration. The only remaining step is an optional tweak to the commit message to better explain the workflow, which Siddharth has offered to do. Expect to see this in `next` soon.
