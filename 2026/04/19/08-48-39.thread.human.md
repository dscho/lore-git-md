This thread is about a new `--missing-only` option for `git rev-list`, designed to help GitLab's Gitaly efficiently identify missing objects in partial clones. The feature is technically complete, with all review feedback incorporated into the v2 patch. The implementation adds a clean flag that filters output to only missing object IDs, integrates with existing `--missing=` formatting options, and includes thorough tests.

The key participants—Derrick Stolee, Patrick Steinhardt, Phillip Wood, Kristoffer Haugsbakk, and the author Siddharth Asthana—have all signed off on the design and implementation. The only remaining open question comes from Junio Hamano, the maintainer, who is probing the broader workflow: how GitLab's Gitaly actually uses the list of missing objects. He’s wondering if the current approach—peeling missing objects one layer at a time—is the intended workflow or if there’s a smarter batch-fetch strategy that should be documented or supported. This isn’t a request for code changes but a final check before the topic can be queued for integration. Unless the discussion reveals a fundamental flaw, the patch is ready to go.
