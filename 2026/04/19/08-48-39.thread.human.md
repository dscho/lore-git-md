This thread introduces a new `--missing=print-only` mode for `git rev-list` to better support partial clone workflows, particularly for GitLab's Gitaly service. The current `--missing=print` mode outputs missing object IDs prefixed with '?', which requires additional processing to extract the OIDs. The proposed change adds a `print-only` variant that emits just the bare object IDs, one per line, making the output easier to consume by tools.

The implementation is cleanly scoped, adding a new enum value and helper function while maintaining all existing behaviors. The patch includes thorough documentation updates and test coverage. The change appears well-motivated by real-world needs from GitLab's infrastructure and has been implemented in a backward-compatible way.
