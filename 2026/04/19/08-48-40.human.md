This is a feature patch adding a new `--missing=print-only` mode to `git rev-list` for partial clone workflows. The change is motivated by GitLab's Gitaly service, which currently uses the existing `--missing=print` mode and has to post-process its output to extract missing object IDs.

The patch introduces a cleaner alternative that outputs only the missing OIDs (without the '?' prefix) in a format directly usable by downstream tools. The implementation:
- Adds `MA_PRINT_ONLY` to the missing_action enum
- Introduces a `missing_action_prints()` helper function
- Updates documentation with the new mode
- Includes comprehensive tests verifying the new behavior

The change is well-contained and appears ready for review, with clear motivation from a real-world use case. The implementation avoids duplicating logic by reusing existing infrastructure where possible while cleanly handling the new output format requirements. The test coverage is thorough, checking both the positive case (missing objects appear) and negative case (present objects don't appear).

This looks like a straightforward quality-of-life improvement for partial clone tooling, particularly for GitLab's infrastructure needs.
