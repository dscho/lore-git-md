This is the final version of Deveshi Dwivedi's patch to improve `git stash`'s argument parsing behavior. The change makes `git stash` automatically assume the "push" subcommand when the command line starts with an option flag (like `-m` or `--staged`), eliminating the need to explicitly type "push" in common cases.

The patch represents a significant simplification from previous versions, moving all the logic into `cmd_stash()` and removing the `push_assumed/force_assume` handling from `push_stash()`. The implementation now uniformly treats any dash-prefixed argument (including negated forms like `--no-keep-index`) as triggering the push assumption.

Test coverage has been expanded to verify all edge cases, and the documentation clearly explains the new behavior using consistent "assumed" terminology. The change maintains backward compatibility while making the command more intuitive for common workflows like `git stash -m "message" file`.
