This is the final version of Deveshi Dwivedi's patch to improve `git stash`'s argument parsing behavior. The patch simplifies the logic by unconditionally assuming the "push" subcommand when the command line starts with an option flag (like `-m` or `--staged`), rather than maintaining a list of push-compatible flags.

Key changes from previous versions:
- Moved the push-assumption logic from `push_stash()` to `cmd_stash()`
- Removed the `push_assumed`/`force_assume` handling entirely
- Updated documentation to clarify the new behavior using "assumed" terminology
- Added comprehensive test coverage including negated options like `--no-keep-index`

The implementation now checks for any leading dash (`-`) to trigger the push assumption, making it more maintainable as new push-compatible options are added. The patch maintains backward compatibility while making common workflows more intuitive by eliminating the need for explicit "push" or `--` in unambiguous cases.
