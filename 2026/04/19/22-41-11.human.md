Stolee explains that his earlier phrasing about repositories being left in a "bad state" was imprecise. The core issue is that automatic maintenance (triggered by operations like fetch) can silently regenerate MIDX files in the new v2 format, which older Git versions can't read. Simply deleting the MIDX files isn't a permanent fix because Git will recreate them in the incompatible format during normal operations. 

This reinforces the need for the agreed-upon solution (reverting to v1 MIDX by default while keeping v2 opt-in) to prevent persistent compatibility issues in mixed-version environments.
