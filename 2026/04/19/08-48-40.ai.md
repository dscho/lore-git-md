This is a feature patch adding a `--missing=print-only` mode to `git rev-list` for partial clone workflows. The change builds on the existing `--missing=print` functionality but simplifies output processing by emitting only missing object IDs without the '?' prefix, one per line.

The patch:
1. Introduces `MA_PRINT_ONLY` as a new `missing_action` enum value
2. Adds a `missing_action_prints()` helper to consolidate print-related logic
3. Modifies output handling to skip present objects when in print-only mode
4. Updates documentation with the new option and its use case
5. Includes tests verifying the new behavior

The implementation appears clean and focused, with clear motivation from GitLab's Gitaly service needs. The change is backward-compatible and maintains all current behaviors while adding the simpler output format. Test coverage looks thorough, verifying both the presence of missing OIDs and absence of present ones in the output.

Key technical details:
- Touches `builtin/rev-list.c` for the core implementation
- Modifies `Documentation/rev-list-options.adoc`
- Adds test cases in `t/t6022-rev-list-missing.sh`
- Uses existing infrastructure but adds new output path for print-only mode
- Output format is one bare OID per line, no prefixes or other decoration

This appears ready for review as a clear quality-of-life improvement for partial clone tooling. The patch is well-structured and addresses a real-world use case cleanly.
