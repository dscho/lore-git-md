This is a feature patch adding a new `--missing=print-only` mode to `git rev-list` for partial clone workflows. The change is motivated by GitLab's Gitaly service, which currently uses `--missing=print` and has to post-process its output to extract missing object IDs.

The patch:
1. Adds the new mode that outputs only missing OIDs (without the '?' prefix)
2. Introduces a `missing_action_prints()` helper to consolidate print-related logic
3. Includes tests covering the new functionality
4. Updates documentation

The implementation appears clean and focused, with clear motivation from a real-world use case. The CI pipeline linked in the cover letter suggests the change has been tested. This looks like a straightforward quality-of-life improvement for partial clone tooling.

Key technical details for future reference:
- Touches `builtin/rev-list.c` to add the new mode
- Modifies `Documentation/rev-list-options.adoc`
- Adds test cases in `t/t6022-rev-list-missing.sh`
- Uses existing `MA_PRINT` infrastructure but adds `MA_PRINT_ONLY`
- Output format is one OID per line, no prefixes
