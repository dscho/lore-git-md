This is the third patch in Patrick Steinhardt's 16-part series introducing an in-memory object database source as part of the ODB abstraction effort. The patch addresses a minor optimization in the `odb_pretend_object()` function, which writes objects to the in-memory backend without persisting them to disk.

The change removes a redundant object existence check. Currently, the function calls both `odb_has_object()` (which checks all ODB sources) and `find_cached_object()` (which specifically checks the in-memory source). Patrick points out that `odb_has_object()` already checks the in-memory source through its call chain, making the explicit `find_cached_object()` check unnecessary.

The patch is a straightforward cleanup that simplifies the code while maintaining the same behavior. It touches only 3 lines in `odb.c`, removing the redundant check while keeping the object allocation logic unchanged.
