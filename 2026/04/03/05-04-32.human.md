Maintainer feedback on graph rendering RFC

Junio C Hamano responds to Pablo Sabater's RFC patch for improving multiple root commit display in `git log --graph` output. While acknowledging the problem, Junio clarifies that the issue isn't specifically about root commits but rather about any commit whose parents are excluded from the displayed range.

The maintainer points to a previous discussion where he illustrated that the same visual alignment problem occurs with non-root commits when their parents are outside the revision range (like commit A in the example `C..Z`). He suggests the solution should handle both cases uniformly, since the underlying cause is identical - ensuring proper spacing for commits whose parents won't appear in the graph.

This feedback indicates the patch may need to broaden its approach beyond just root commits. Junio's reference to "previous attempts and gotchas" suggests this area has subtle edge cases that have tripped up past efforts. The response maintains the project's typical pattern where the maintainer steers contributors toward more general solutions that cover related cases.
