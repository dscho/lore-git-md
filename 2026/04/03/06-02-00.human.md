This is patch 13/16 in Patrick Steinhardt's series introducing an in-memory object database (ODB) backend, part of the ongoing ODB abstraction effort. The patch implements the `count_objects()` callback for the in-memory source, which provides a way to count the objects stored in this temporary backend.

The implementation is straightforward - it uses the existing `for_each_object` infrastructure with a simple counter that increments for each object encountered. The callback handles the counting via a helper function that gets called for each object during iteration. This maintains consistency with how other ODB backends implement object counting.

As with previous patches in the series, this continues the pattern of methodically implementing each required ODB source callback while leveraging existing infrastructure where possible. The change is cleanly scoped to just adding the counting functionality without any broader architectural implications. Given the series' progression and Patrick's track record with these kinds of core changes, this appears to be another solid step toward completing the in-memory ODB implementation.
