Maintainer ack for Rust default enablement. Junio C Hamano has reviewed and accepted brian m. carlson's series to enable Rust support by default in Git 2.54, marking the next step in the Rustification effort. The series had been intended for Git 2.53 but was overlooked, and this implementation follows through on that prior plan.

The changes are straightforward build system and CI adjustments: documentation updates, Alpine Linux compatibility fixes (adding cargo support), explicit linking against libdl on Linux systems, and finally flipping the default Rust build flag. Junio's simple "Thanks." indicates this uncontroversial series is now queued for integration, maintaining the project's trajectory toward Rust adoption while preserving the ability to build without Rust via two retained CI jobs.

This marks a quiet but significant milestone in the Rustification effort, with the maintainer's approval signaling that the technical groundwork has met Git's standards despite the broader platform compatibility debates that have surrounded Rust adoption. The patch series now moves toward inclusion in the next release without further discussion needed.
