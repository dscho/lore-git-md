This is the first patch in a 16-part series introducing an in-memory object database source, part of Patrick Steinhardt's ongoing ODB abstraction effort. The patch lays groundwork by creating a new "inmemory" source type that will eventually replace Git's existing cached objects mechanism.

The change moves cached objects (currently stored directly in the object_database struct) into a new odb_source_inmemory structure, with proper initialization and cleanup routines. While this first patch doesn't yet implement the full functionality, it establishes the framework that subsequent patches will build upon to provide a proper in-memory backend with read/write capabilities.

The implementation adds new source-inmemory.[ch] files and updates build systems, while converting existing cached object handling to use the new structure. This appears to be a clean, incremental step in the larger effort to make object storage more modular and pluggable. Given Patrick's track record with architectural changes and the clear series progression, this seems like a solid foundation for the work.
