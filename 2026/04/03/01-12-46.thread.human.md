This thread documents a minor schedule adjustment in Git's Rustification effort. The original plan was to enable Rust support by default in Git 2.53, but this has been pushed to 2.54. The first patch in this series updates `BreakingChanges.adoc` to reflect the new version number, noting that builds will require Rust by default starting with 2.54 unless explicitly disabled via build flags.

The change is straightforward documentation update, but it touches on the broader context of Rust integration - an ongoing effort that has generated discussion due to platform compatibility concerns, particularly for systems like NonStop that currently lack Rust support. The commit message makes clear this is a schedule adjustment rather than a change in direction for the Rustification work.
