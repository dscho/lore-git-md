This is patch 5/16 in Patrick Steinhardt's series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch implements the `read_object_stream()` callback for the new in-memory backend, which provides streaming access to objects stored in memory.

The implementation follows the pattern established in earlier patches, with a new `odb_read_stream_inmemory` struct that wraps the in-memory object data and implements the required streaming interface. The callback handles both reading chunks of data (via `memcpy`) and proper bounds checking, while maintaining the existing behavior where objects are found via linear search of the in-memory store.

This continues the series' clean separation of concerns by moving streaming logic into the backend-specific implementation rather than handling it in generic ODB code. The patch appears straightforward and well-contained, building naturally on the infrastructure set up in previous patches. As with the rest of the series, this moves the project toward the goal of pluggable ODB backends while cleaning up technical debt in the object storage layer.
