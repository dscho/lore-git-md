Feature patch implementing `read_object_info()` for in-memory ODB backend (part 4/16 of Patrick Steinhardt's ODB abstraction series).

This patch implements the `read_object_info()` callback for the new in-memory object database backend, moving the functionality from `odb.c` to the new `odb/source-inmemory.c`. The change:

1. Relocates the object lookup logic (`find_cached_object()`) from `odb.c` to the in-memory source implementation
2. Implements the callback to populate `object_info` struct fields when querying in-memory objects
3. Maintains all existing behavior (including special handling of empty trees)
4. Simplifies `odb.c` by removing now-redundant code

The patch continues the series' pattern of cleanly separating concerns between the generic ODB interface and backend-specific implementations. As with previous patches, this appears carefully implemented with thorough attention to maintaining existing behavior while moving toward the new abstraction.

This is part of Patrick's larger effort to make Git's object storage layer pluggable, with the in-memory backend serving both immediate needs (like git-blame's temporary objects) and future use cases. The series remains in early stages but shows Patrick's characteristic methodical approach to architectural changes.
