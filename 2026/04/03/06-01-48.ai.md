This is the first patch in Patrick Steinhardt's series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch lays the groundwork by:

1. Adding new files `odb/source-inmemory.[ch]` that define the basic structure for the in-memory backend, including a new `odb_source_inmemory` struct to track objects stored purely in memory.

2. Replacing the existing `cached_objects` array in `struct object_database` with the new `inmemory_objects` pointer to this structured backend.

3. Moving allocation and cleanup of cached objects into the new infrastructure while maintaining the same functionality.

The changes are mechanical at this stage - the actual implementation of ODB source callbacks comes in later patches. This first commit focuses on the structural changes needed to support the new backend type, including build system updates (Makefile and meson.build) to compile the new source files.

The patch maintains backward compatibility by keeping the same object storage behavior while preparing for future extensions. It's a typical architectural first step in Patrick's style - carefully separating concerns before adding new capabilities.
