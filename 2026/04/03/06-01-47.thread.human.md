Patrick Steinhardt continues his methodical implementation of an in-memory object database backend with patch 11/16 in the series. This patch completes another key piece of the ODB interface by implementing the `for_each_object()` callback, which enables both simple iteration and filtered queries of objects in the in-memory store.

The implementation builds on the oidtree infrastructure introduced in earlier patches, providing efficient O(log n) lookups. It factors out common object info population logic into a new helper function and handles various iteration flags like `PROMISOR_ONLY` and `LOCAL_ONLY`. The changes are focused and consistent with the pattern established by previous callbacks in the series.

So far the thread has seen only Patrick's contributions as the author, with no review feedback yet on this substantial 16-part series. The work represents another step in his ongoing effort to abstract Git's object storage layer to support pluggable backends. The implementation appears technically sound given Patrick's deep expertise in this area, though reviewers may want to verify the callback behavior matches expectations for how object iteration should work across different ODB implementations.
