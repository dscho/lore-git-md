Patrick Steinhardt continues his ODB abstraction work with a technical refactoring of the cbtree data structure to better support embedded nodes. This foundational change allows wrapper structures (like those needed for the in-memory ODB) to contain both tree nodes and their own data while maintaining proper key alignment. The patch removes the flex array from cb_node in favor of storing a key offset in the tree itself, trading 4 bytes of padding per node for eliminating memory copies.

This change is part of Steinhardt's larger 17-patch series introducing an in-memory ODB backend, now at version 2. The series has evolved to include streaming read/write capabilities and rebased onto Justin Tobler's related ODB interface changes. While the current patch is a low-level refactoring, it supports the broader goal of creating clean abstractions for the ODB work. The series remains under review, with some open questions about path field handling and future integration with other ODB changes.
