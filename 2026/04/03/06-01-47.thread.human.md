This thread documents Patrick Steinhardt's 17-part series implementing an in-memory object database source, a significant milestone in the ongoing ODB abstraction effort. The series introduces a complete non-persistent backend for transient objects, with applications ranging from git-blame worktree commits to future use cases requiring temporary storage. The implementation uses oidtree for efficient O(1) lookups and sorted iteration while touching several core files including `odb/source-in-memory.[ch]` and `cbtree.[ch]`.

Karthik Nayak has been the primary reviewer, providing substantive feedback throughout. Key discussion points included the placement of downcast functions (resolved with justification for header placement to enable inlining) and an optimization for empty tree handling. A bug in streaming read offset handling was identified in patch 5 and confirmed by Patrick, who will address it. The most recent exchange confirms a minor rebase artifact in patch 7's commit message that needs squashing - the technical implementation remains sound, with proper object ID computation and array management.

With these final cleanups acknowledged, the series appears ready for integration.
