Patrick Steinhardt continues his work on implementing an in-memory object database backend with patch 14/17 in the series. This latest addition completes another required piece of the ODB source interface by implementing the `count_objects()` callback. The implementation is straightforward, leveraging the iteration infrastructure added in patch 12 to count all objects in the in-memory store.

The series, now at version 2, has been steadily progressing through the required ODB source callbacks one by one. This patch added about 20 lines of clean code to `odb/source-inmemory.c` that simply counts objects during iteration. It follows the established pattern of the series and doesn't introduce new complexity. 

With this patch, the in-memory backend now handles object counting in addition to the previously implemented read/write operations (including streaming), iteration, and prefix resolution. The work builds on Justin Tobler's parallel ODB interface changes and represents another step forward in Patrick's broader ODB abstraction roadmap. The series appears technically solid and well-considered, though some open questions remain about path field handling and the practical utility of certain interfaces.
