This is a refactoring patch in Patrick Steinhardt's ongoing ODB (object database) abstraction series. It modifies the cbtree data structure to support arbitrary wrapper structures around tree nodes, which is needed for the in-memory ODB backend being introduced in this series.

The patch changes how cbtree handles node data by removing the flex array from `struct cb_node` and instead allowing callers to specify an offset to the key data within their wrapper structure. This enables proper embedding of nodes in custom structures while maintaining type safety and memory management. The tradeoff is a small increase in node size (from 60 to 64 bytes on 64-bit systems) but eliminates alignment-related memory copies.

The changes affect both the cbtree implementation and its primary user, oidtree, which now uses a proper wrapper struct (`oidtree_node`) rather than manually managing memory alignment. This appears to be a well-considered technical change that simplifies the code while enabling the more flexible usage patterns needed for the ODB abstraction work.

As with previous patches in this series, the change is carefully scoped and builds logically on prior work. The implementation looks clean and maintains backward compatibility with existing cbtree users. This continues the pattern of methodical, well-explained changes that characterize Patrick's architectural work.
