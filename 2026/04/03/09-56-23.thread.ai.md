Thread identity: Platform compatibility patch for Windows builds, specifically addressing the transition from MSYS2's MINGW64 to UCRT64 environments. Authored by Johannes Schindelin (Git for Windows maintainer).

Core problem: Simplifying the `mingw_strftime()` wrapper in `compat/mingw.c` by removing redundant dynamic loading of UCRT `strftime()` when building against UCRT directly. The wrapper was originally needed for msvcrt.dll compatibility but becomes unnecessary with ucrtbase.dll.

Technical details: Adds `#ifdef _UCRT` conditional compilation to use system `strftime()` directly in UCRT builds while maintaining existing wrapper logic for non-UCRT builds. Preserves error handling behavior for invalid format strings in both paths. Touches only `compat/mingw.c`.

Context: Part of broader Git for Windows modernization as MSYS2 deprecates MINGW64 environment. Low-risk mechanical change focused on build system compatibility.
