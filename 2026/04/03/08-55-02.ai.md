This is a platform compatibility patch targeting the CMake build system. Johannes Schindelin follows up on his earlier work (3b9b2c2a29a) that added `writev()` wrapper support to the Makefile and Meson builds, now extending it to CMake. The change ensures the compatibility layer is used when the platform lacks native `writev()` support, specifically mentioning this was needed to fix Git for Windows CI builds.

The patch is straightforward - it adds `writev` to the list of functions checked during CMake builds and includes the compatibility implementation when missing. This matches the treatment already given to other POSIX functions like `memmem` and `strlcpy`. The commit message notes the practical motivation (CI failures) but doesn't delve into technical details about why Windows needs this wrapper.

Given Schindelin's role as Git for Windows maintainer and the focused nature of the change, this appears to be a routine platform-support update rather than anything controversial. The patch follows the established pattern for handling missing POSIX functions in Git's build system matrix.
