This is a cover letter for a series enabling Rust support by default in Git, part of the ongoing Rustification effort. brian m. carlson is following through on a previously stated plan (from the BreakingChanges document) to make Rust the default in Git 2.54 after missing the original 2.53 target.

The 4-patch series:
1. Updates documentation to reflect the new default
2. Fixes CI by ensuring cargo is installed on Alpine Linux
3. Adds libdl linking for Linux builds
4. Actually flips the default to enable Rust support

The author notes this doesn't force Rust in "breaking changes mode" since it's already becoming the default. CI passes across all platforms with these changes. The series maintains the ability to disable Rust for now, keeping two CI jobs that verify non-Rust builds still work.

This appears to be a straightforward technical follow-through on a previously announced plan, with the patches focused on documentation updates and build system tweaks needed to make Rust default work reliably. The changes seem uncontroversial given they implement an already-agreed direction rather than proposing new policy.
