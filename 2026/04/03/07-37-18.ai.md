This is a release announcement for Git for Windows, which is a downstream distribution of Git with Windows-specific patches and tooling. Johannes Schindelin announces Git for Windows 2.54.0-rc0, tracking the upcoming Git 2.54.0 release.

The key changes in this release candidate include:
- Removal of `git svn` from the distribution due to maintenance challenges, with instructions for users who still need it to obtain it via MSYS2 or WSL
- Updates to bundled components (Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2, MSYS2/Cygwin 3.6.7, cURL 8.19.0, OpenSSH 10.3.P1)
- Removal of winpty-based shell aliases for Python/Node.js as they are no longer needed
- Bug fixes including restoring the accidentally dropped iconv executable and fixing input ordering issues in Git Bash

The announcement provides SHA-256 checksums for all distribution variants (64-bit, ARM64, portable, MinGit, etc.). This is a routine pre-release announcement following Git for Windows' established packaging and distribution process, with the notable exception of dropping `git svn` support in the main distribution.
