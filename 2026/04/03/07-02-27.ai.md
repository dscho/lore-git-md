This is a feature patch series introducing new `includeIf` conditions for matching worktree paths in Git configs. The 2-patch series (v3) adds `worktree` and `worktree/i` pattern matching to complement the existing `gitdir` and `onbranch` conditions.

The core motivation is improving config inclusion in multi-worktree setups, where current `gitdir` patterns can be awkward since linked worktrees store their gitdirs in the main repo's `.git/worktrees/`. The new `worktree` condition matches against the actual working tree path instead, with glob pattern support including wildcards, `**/` recursive matching, and case-insensitive variants.

The implementation refactors existing path-matching logic from `include_by_gitdir()` into a more generic `include_by_path()` that handles both gitdir and worktree cases. Test coverage is thorough, exercising various path matching scenarios including relative paths, home directory expansion, and case sensitivity.
