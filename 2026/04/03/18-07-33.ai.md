This is a follow-up in Pablo Sabater's RFC series to improve Git's graph rendering for root commits and commits with excluded parents in `git log --graph` output. The email addresses a specific test case portability issue identified by Junio C Hamano.

The immediate concern is about test case filenames that differ only by case (`8_a` vs `8_A`), which would fail on case-insensitive filesystems like Windows and macOS. Pablo acknowledges the issue and commits to fixing it in v2 by ensuring unique filenames while preserving the test's intent. This is a straightforward technical blocker that needs resolution before the patch can progress.

The broader context remains the graph rendering improvements, where the series aims to handle both true root commits and commits with parents outside the displayed range through a unified "seems_root" concept. While this email doesn't discuss those core changes, it shows the author responding to review feedback about test infrastructure - a necessary step before the more substantive discussion about the graph rendering algorithm can continue. The thread's main technical questions about optimal indentation and handling of merge cases remain open for future discussion.
