This is the third patch in Patrick Steinhardt's 16-part series introducing an in-memory object database (ODB) backend. The series is part of the larger ODB abstraction effort to enable pluggable storage backends.

This particular patch is a small optimization that removes a redundant object existence check in `odb_pretend_object()`. The function was checking for the object's existence twice - once via `odb_has_object()` (which already checks the in-memory source) and again directly via `find_cached_object()`. The patch eliminates this unnecessary second check.

The change is straightforward and well-justified in the commit message. It touches only 3 lines in odb.c, removing the redundant check while maintaining all existing functionality. As with the rest of the series, this appears to be a clean, focused change that improves the code while moving toward the larger goal of a more flexible ODB architecture.

Given Patrick's track record with these kinds of architectural changes and the clear technical rationale provided, this seems like a solid incremental improvement to the series. The patch follows the pattern of the first two in the set - making focused, well-explained changes that both advance the new feature and clean up existing code.
