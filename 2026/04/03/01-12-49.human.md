This is a build system patch that enables Rust compilation by default in Git, part of the ongoing Rustification effort. It's the final patch in a series implementing a planned breaking change for Git 2.54.

The patch flips the default build configuration from opt-in to opt-out for Rust support, changing `WITH_RUST` to `NO_RUST` in the Makefile and meson build system. The commit message notes this aligns with the project's stated plan to make Rust mandatory by Git 3.0. The changes include:

1. Build system updates to make Rust the default
2. CI configuration adjustments to test both Rust-enabled and disabled scenarios
3. Documentation updates reflecting the new defaults

The implementation appears straightforward and well-motivated, following through on previously announced plans. The patch maintains backward compatibility by keeping the ability to disable Rust via `NO_RUST`, which is used in some CI jobs to ensure continued testing of the non-Rust code paths. This is a significant milestone in Git's Rust integration, though the controversial aspects of Rust adoption were presumably addressed in earlier discussion.
