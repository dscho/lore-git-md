This thread coordinates the localization (l10n) effort for the upcoming Git 2.54.0 release. Jiang Xin, the Chinese translation maintainer and l10n coordinator, has announced that 182 strings need updating since the last release. 

The workflow has been slightly updated: translators should now pull from the git-l10n/git-po repository and use `make po-update` rather than working with a pre-generated `po/git.pot` file. The message explicitly encourages using AI-assisted translation (with human review) and provides sample prompts. Technical details include the use of Git filter drivers to clean up .po files and the git-po-helper CI pipeline for validation.

The translation window is open until April 18, 2026, giving contributors two weeks to submit updates via pull requests to the git-l10n/git-po repository. This is a routine coordination email following the established l10n process, with minor workflow adjustments to accommodate modern tooling.
