Thread identity: `[PATCH v3 0/2]` from Chen Linxuan, adding `includeIf` config conditions `worktree` and `worktree/i` to complement `gitdir` and `onbranch`.

Core problem and goal: Enable config inclusion based on a worktree's checkout path, simplifying multi-worktree setups where `gitdir` patterns are awkward because linked worktrees store their gitdirs in the main repo's `.git/worktrees/`.

Key technical details:
- **Patch 1/2**: Refactors `include_by_gitdir()` into a generic `include_by_path()` helper in `config.c`.

Supports glob patterns and `~` expansion. The path matched is the worktree checkout root (`git rev-parse --show-toplevel`), not the `.git` directory.
