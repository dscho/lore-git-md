Thread summary:

The thread concerns the Rustification effort to integrate Rust code into Git, specifically a patch that changes the build system to enable Rust by default in preparation for Git 2.54. The change flips the default from opt-in (`WITH_RUST`) to opt-out (`NO_RUST`) in both Makefile and Meson builds, with CI configurations updated to test the new default behavior. The Linux CI jobs will now run with Rust enabled by default, while a single job (`linux-clang`) tests without Rust. Windows builds maintain explicit Rust disabling in Makefile but follow the new default in Meson. The commit references the breaking changes document as rationale for this timing, positioning it as a step toward making Rust mandatory in Git 3.0. This represents a significant policy shift in the contentious Rustification effort, particularly regarding platform support concerns raised by some contributors. The patch focuses narrowly on implementing the build system changes rather than rehashing the broader debate.
