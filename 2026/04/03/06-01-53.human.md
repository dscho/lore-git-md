This is patch 6/16 in Patrick Steinhardt's series introducing an in-memory object database (ODB) backend, part of the ongoing ODB abstraction effort. The patch implements the `write_object()` callback for the in-memory source, moving the object writing logic from `odb.c` into the new backend-specific implementation.

The change replaces the direct manipulation of the `inmemory_objects` array in `odb_pretend_object()` with a call to the new `odb_source_write_object()` function, which routes through the backend's callback. The actual writing logic remains similar - allocating space for the object, copying its data, and storing metadata - but is now properly encapsulated in the backend implementation.

This continues the pattern seen in earlier patches of moving functionality from the generic ODB layer into backend-specific code. The patch appears straightforward and maintains the series' focus on cleanly separating concerns between the ODB interface and its implementations. No new functionality is added beyond completing the backend's required callbacks.
