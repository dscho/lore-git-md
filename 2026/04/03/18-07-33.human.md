This is a follow-up in Pablo Sabater's RFC series improving `git log --graph` rendering for root commits and commits with excluded parents. The immediate issue is a test case portability problem identified by Junio C Hamano - the test uses filenames that differ only by case (`8_a` vs `8_A`), which fails on case-insensitive filesystems (Windows/macOS). 

Pablo acknowledges the issue and confirms he'll send a v2 patch addressing both this test case fix and the broader "seems_root" concept needed to handle both true root commits and commits with excluded parents uniformly. The exchange shows the careful attention to cross-platform compatibility that Git's test suite requires, even for experimental RFC patches.

While this email is brief, it signals progress on the underlying graph rendering improvement - the author is incorporating feedback and preparing a revised version. The thread remains focused on solving the core visualization problem where Git currently misaligns commit lineages in certain graph topologies.
