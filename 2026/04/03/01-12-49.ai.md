Rustification effort - this patch in a series enables Rust by default in the build system as planned for Git 2.54, flipping the default from opt-in to opt-out.

The patch makes several coordinated changes to implement this policy shift. The Makefile switches from `WITH_RUST` to `NO_RUST` as the controlling variable, with updated help text reflecting that Rust is now the default. The Meson build system similarly changes its default Rust setting from 'auto' to 'enabled' and stops automatically disabling Rust when Cargo is missing, as the goal is to surface build issues early.

CI configuration is updated to test the new default behavior - the Linux jobs now run with Rust enabled by default while adding a single job without Rust (linux-clang). The Makefile-based Windows job explicitly disables Rust while the Meson Windows job will use the new default. The changes align with the project's stated plan to make Rust mandatory in Git 3.0.

This appears to be the culmination of the Rustification effort that has been contentious in some quarters, particularly around platform support concerns. The patch itself is mechanically straightforward, focused solely on build system changes to implement the policy decision rather than debating its merits. The commit message references the breaking changes document as justification for the timing of this change.
