This is the final patch in Patrick Steinhardt's 16-part series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch makes the in-memory source generic by changing its type from `struct odb_source_inmemory*` to the more general `struct odb_source*` throughout the codebase.

The changes are mechanical but important for the interface - they ensure the in-memory backend is treated consistently with other ODB sources by using the base type rather than its concrete implementation type. The patch updates four call sites in `odb.c` where the in-memory source is accessed, plus the type declaration in `odb.h`.

This completes the series' technical implementation, which has built up the in-memory backend callback by callback over the previous 15 patches. The work appears well-structured and carefully implemented, with each patch focused on a specific aspect of the functionality. As the final patch in a substantial series from a key contributor to the ODB abstraction effort, it represents an important step toward making Git's object storage more flexible and modular.
