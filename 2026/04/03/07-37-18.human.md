This is a release announcement for Git for Windows 2.54.0-rc0), not a patch for the main Git project. Johannes Schindelin announces the first release candidate of Git for Windows, which tracks upstream Git v2.54.0-rc0 but includes Windows-specific changes and bundled components.

The most notable change is the removal of `git svn` from the distribution due to maintenance challenges. Users needing Subversion interoperability are directed to use WSL or install via MSYS2. The release includes updated versions of bundled tools like Bash (5.3.9), Git Credential Manager (2.7.2), and OpenSSH (10.3.P1).

Several Windows-specific fixes are included: restoring the accidentally dropped `iconv` executable, fixing input ordering issues in Git Bash, and improving `git worktree remove` to properly handle NTFS junctions. The announcement provides SHA-256 checksums for all distribution variants (64-bit, ARM64, portable, and MinGit versions).

This is a routine pre-release announcement for the Windows fork - the changes are specific to the Windows packaging and environment rather than core Git functionality. The removal of `git svn` may impact some Windows users who rely on Subversion interoperability without WSL.
