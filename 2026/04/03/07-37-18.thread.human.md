This is a release announcement for Git for Windows 2.54.0-rc0, a downstream distribution that packages Git with Windows-specific patches and tooling. Maintainer Johannes Schindelin notes this version tracks the upcoming Git 2.54.0 release. The most significant change is the removal of `git svn` from the main distribution due to maintenance challenges, though users needing it can still obtain it through MSYS2 or WSL. The release updates several bundled components including Bash, Git Credential Manager, and OpenSSH, while removing obsolete winpty-based shell aliases. Various bug fixes are included, such as restoring the missing iconv executable. The announcement follows Git for Windows' standard release process, providing checksums for all distribution variants.
