This thread documents the Rustification effort's transition to making Rust the default in Git's build system, planned for Git 2.54. The patch changes the build configuration from opt-in (`WITH_RUST`) to opt-out (`NO_RUST`), updating both Makefile and Meson build systems accordingly. CI configurations have been adjusted to test the new default behavior, with one Linux and one Windows job explicitly testing without Rust for compatibility. The change aligns with the project's roadmap to make Rust mandatory by Git 3.0.

The implementation appears to be the execution of a previously made policy decision, focusing purely on the build system mechanics rather than reopening debate about Rust's inclusion. The commit message cites the project's breaking changes policy as justification for the timing. While the Rustification effort has been controversial—particularly regarding platform support concerns—this patch represents its progression to becoming a default part of Git's build process.
