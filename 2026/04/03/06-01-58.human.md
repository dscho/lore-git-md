This is patch 11/16 in Patrick Steinhardt's series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch implements the `for_each_object()` callback for the in-memory backend, completing another piece of the ODB interface.

The implementation:
- Extracts object info population into a new `populate_object_info()` helper function (used by both read and iteration paths)
- Adds a callback wrapper `odb_source_inmemory_for_each_object_cb()` that handles both bare OID iteration and full object metadata requests
- Implements the main `for_each_object()` function with support for prefix filtering and promisor/local-only flags
- Uses the oidtree data structure (modified in earlier patches) for efficient O(log n) iteration

The changes are cleanly separated from existing functionality and maintain the series' pattern of methodical interface implementation. This continues the trend of well-structured, focused patches in the series, with each commit tackling a specific ODB callback while building on the foundation established in previous patches.
