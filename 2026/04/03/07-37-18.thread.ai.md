Git for Windows 2.54.0-rc0 release announcement from Johannes Schindelin, tracking upstream Git 2.54.0. Key changes: removal of `git svn` from main distribution (users needing it must use MSYS2 or WSL), updates to bundled components (Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2, MSYS2/Cygwin 3.6.7, cURL 8.19.0, OpenSSH 10.3.P1), removal of obsolete winpty-based shell aliases for Python/Node.js, and bug fixes including restoring the iconv executable and fixing Git Bash input ordering. SHA-256 checksums provided for all distribution variants (64-bit, ARM64, portable, MinGit). This marks a notable change in distribution policy with the removal of `git svn` support from the main package.
