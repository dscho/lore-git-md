This is patch 13/16 in Patrick Steinhardt's series introducing an in-memory object database source as part of the ODB abstraction effort. The patch implements the `count_objects()` callback for the in-memory backend, completing another piece of the ODB interface.

The implementation leverages the existing `for_each_object` infrastructure (added in patch 11) by providing a simple callback that increments a counter for each object. The callback ignores the object ID and info parameters (marked UNUSED) since it only needs to count objects. The count is stored in an unsigned long passed via the callback data.

The patch follows the established pattern of the series - each callback is a focused addition that builds on prior work. Here, the counting functionality reuses the iteration machinery rather than duplicating traversal logic. The implementation is straightforward and appears correct, though it doesn't yet handle the `flags` parameter (marked UNUSED) which could theoretically filter objects by type or other criteria in future.

This continues the series' methodical progression through the ODB interface. With this patch, the in-memory backend now supports counting objects alongside the previously implemented read/write/iteration operations. The changes are well-contained and maintain the series' clean separation between the generic ODB interface and backend-specific implementations.
