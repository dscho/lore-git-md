Johannes Schindelin (Git for Windows maintainer) has sent a patch to extend platform compatibility support to CMake builds. The change adds a `writev()` wrapper for systems that lack this POSIX function, following the same approach already implemented for Makefile and Meson builds. This fixes CI failures in Git for Windows where the native implementation is missing.

The patch is a straightforward addition to Git's existing compatibility layer, matching how other POSIX functions like `memmem` and `strlcpy` are handled. As a focused platform-support update from the Git for Windows maintainer, this change is uncontroversial and follows established patterns in the build system.
