This is the final patch in Patrick Steinhardt's 16-part series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch makes the in-memory source generic by changing its type from `struct odb_source_inmemory*` to the more general `struct odb_source*` throughout the codebase.

The changes are mechanical but important for the abstraction - they ensure the in-memory backend is treated consistently with other ODB sources. The patch updates the type in `odb.h` and adjusts four call sites in `odb.c` to use the new type. This completes the technical work of integrating the in-memory backend into Git's object storage layer.

With this patch, the series appears complete - all planned callbacks are implemented and the abstraction is now properly generic. The changes are small and focused, typical of Patrick's careful approach to large architectural changes. This work lays groundwork for future features needing temporary object storage while cleaning up technical debt in the ODB interface.
