This is a platform compatibility patch for the CMake build system, following up on a previous change that added `writev()` wrapper handling to the Makefile and Meson builds. Johannes Schindelin (the Git for Windows maintainer) notes this was needed to get Git for Windows CI builds passing.

The change adds `writev` to the list of functions checked during CMake configuration, and includes the compatibility wrapper from `compat/writev.c` when the system lacks native `writev()` support. This matches the treatment already given to other POSIX functions like `memmem` and `strcasestr` in the CMake build.

The patch is straightforward and clearly motivated - it completes the cross-build-system consistency for a POSIX compatibility wrapper that was already deemed necessary for Windows builds. As a build system tweak from a known platform expert, it's unlikely to be controversial.
