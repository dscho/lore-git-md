Git for Windows 2.54.0-rc1 release announcement by Johannes Schindelin, tracking upstream Git v2.54.0-rc1. This Windows-specific distribution includes updated bundled components: Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2, MSYS2 runtime (Cygwin 3.6.7-based), cURL 8.19.0, and OpenSSH 10.3.P1. Key changes: removal of `git svn` from default installation (users directed to MSYS2/WSL alternatives), restoration of missing `iconv` executable, improved Git Bash input handling, better NTFS junction handling in `git worktree remove`, and corrected multi-socket CPU core detection. SHA-256 checksums provided for installers, portable archives, and MinGit variants across 32-bit, 64-bit, and ARM64 architectures. This follows Git for Windows' standard practice of tracking upstream releases while maintaining Windows-specific components and tooling.
