This is a refactoring patch in the fsmonitor series, renaming a Darwin-specific settings file to be Unix-generic in preparation for Linux support. 

Patch 7/13 in v14 of Paul Tarjan's fsmonitor series renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` since the settings logic is not actually macOS-specific and will be shared by the new Linux implementation. The change updates both the Meson and CMake build systems to use a new `FSMONITOR_OS_SETTINGS` variable, matching the approach already used for IPC handling.

This is a straightforward mechanical change that follows the pattern established earlier in the series for the IPC code. The patch builds on prior work from Eric DeCosta and Marziyeh Esipreh, maintaining all existing functionality while improving code organization for cross-platform reuse. The series as a whole has been through extensive review and testing across 14 iterations, with this change representing the final build system adjustments needed before the Linux fsmonitor support can be integrated.
