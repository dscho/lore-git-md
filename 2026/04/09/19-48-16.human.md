This is a platform compatibility issue affecting Git's build system on NonStop systems. Randall S. Becker reports that despite specifying `NO_WRITEV=Nope` during build, Git 2.54.0-rc1 still attempts to use `writev()` on NonStop, resulting in a "Invalid function argument" error during test execution.

The error occurs during a clone operation from a bitmapped repository, causing the test to fail with a fatal writev error. Randall is seeking help understanding why the `NO_WRITEV` flag isn't being respected in the build configuration.

The issue appears to be a regression in build system behavior, as the explicit attempt to disable `writev` support isn't having the intended effect. This is particularly relevant for NonStop platforms where `writev` may not be available or may behave differently than on Unix-like systems. The error suggests the build system needs adjustment to properly honor the `NO_WRITEV` flag on this platform.
