This is the first patch in a feature series (v8) that adds customizable conflict marker labels to `git stash apply`. The patch introduces three new options (`--ours-label`, `--theirs-label`, and `--base-label`) that allow users to specify custom text for conflict markers when applying stashes with conflicts. The default labels ("Updated upstream", "Stashed changes", and "Stash base") can now be overridden, including with empty strings to omit labels entirely.

The implementation touches the stash documentation, command-line parsing in `builtin/stash.c`, and the xdiff merge logic to properly handle empty labels. Two new test cases verify the functionality: one for custom labels and another for empty labels, both using the diff3 conflict style. The xdiff changes ensure empty strings are handled correctly when calculating marker sizes.

This is part of a larger effort to unify conflict resolution behavior between `git checkout -m` and other commands that use autostash. The patch has been through multiple rounds of review and testing, with v8 specifically addressing edge cases around empty label handling. The changes are well-contained and focused, with clear documentation updates and thorough test coverage.
