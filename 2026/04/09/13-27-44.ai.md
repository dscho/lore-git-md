This is patch 3/4 in a feature series enhancing autostash functionality in Git's sequencer. The patch adds support for custom conflict marker labels when applying autostashes, building on the new labeling options introduced in earlier patches.

The key technical additions are:
1. A new `apply_autostash_ref_with_labels()` function that accepts three label parameters (ours, theirs, base) and passes them through to `git stash apply`
2. Modifications to the internal `apply_save_autostash_oid()` and `apply_save_autostash_ref()` functions to handle the new label parameters
3. Updated sequencer.h header with the new public function declaration

The implementation maintains backward compatibility by keeping the existing functions that don't take labels, while adding the new variant for callers that want customized conflict markers. The labels are only used when `merge.conflictStyle=diff3` is set, as established in earlier patches.

This change is part of the series' broader goal to unify conflict resolution behavior between `git checkout -m` and other commands that use autostash. The labeling capability gives users more control over how conflicts are presented when stashed changes are automatically reapplied during branch switching operations.
