This is a refactoring patch in Patrick Steinhardt's ongoing ODB (object database) abstraction series, specifically enhancing the oidtree data structure to store arbitrary payloads alongside object IDs. The patch is part of a 17-part series implementing an in-memory ODB backend.

The change extends oidtree's capabilities beyond just tracking object IDs to allow associating arbitrary data with each OID. This enables more sophisticated use cases while maintaining the structure's efficient prefix operations. The implementation adds a `data` field to each node and introduces new API functions like `oidtree_get()` to retrieve stored payloads.

Key technical changes include:
- Adding a `void *data` field to `struct oidtree_node`
- Modifying `oidtree_insert()` to accept and store a data pointer
- Introducing `oidtree_get()` to retrieve stored data
- Updating callbacks to pass through the node data
- Adding a test case verifying data overwrite behavior

The patch touches core object storage infrastructure (`oidtree.[ch]`) and updates several callers. It's a well-contained change that maintains backward compatibility while enabling new functionality needed for the in-memory ODB implementation in subsequent patches. The thorough test additions demonstrate the expected behavior, and the changes align with the series' overall architecture.
