This is patch 4/17 in Patrick Steinhardt's v2 series implementing an in-memory object database (ODB) source as part of the broader ODB abstraction effort. The patch implements the `read_object_info()` callback for the in-memory backend, moving functionality that was previously scattered in `odb.c` into the new dedicated source implementation.

The change relocates the object lookup logic from `odb.c` to `odb/source-inmemory.c`, where it properly belongs as part of the source-specific implementation. The patch maintains all existing behavior while better encapsulating the in-memory source's responsibilities. Key aspects include:

- Moves the `find_cached_object()` helper into the in-memory source module
- Implements proper callback dispatch through the ODB source interface
- Preserves special handling of empty trees
- Keeps all existing object info population behavior (type, size, content copying etc.)

This is a straightforward structural improvement that follows the series' goal of properly modularizing the ODB backend implementations. The patch appears cleanly separated from the rest of the series and maintains backward compatibility. Given Patrick's track record with architectural changes and the clear motivation for the overall effort, this seems like solid incremental progress.
