This is the final patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch makes the in-memory source generic by changing its type from `struct odb_source_inmemory*` to `struct odb_source*` in the codebase.

The changes are mechanical but important for the abstraction - they ensure the in-memory source can be treated uniformly with other ODB sources through the generic interface. The patch updates four call sites in `odb.c` and the type declaration in `odb.h` to use the base type rather than the implementation-specific type.

As the concluding patch of the series, this represents the last step in making the in-memory source a fully integrated part of Git's object storage system. The series as a whole provides a well-architected foundation for transient object storage that will support use cases like git-blame's worktree commits while cleaning up technical debt in the process.
