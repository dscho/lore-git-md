This is the final patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source as part of the ODB abstraction effort. The patch makes the in-memory source generic by changing its type from `struct odb_source_inmemory*` to `struct odb_source*` in the ODB interface.

The changes are mechanical but important for the in-memory source now presents the same interface as other ODB sources, completing its integration into the ODB abstraction framework. The patch updates all references to the in-memory source in `odb.c` and `odb.h` to use the generic `struct odb_source` type rather than the implementation-specific type.

This final patch follows the series' progression from foundational infrastructure through complete callback implementation (read/write operations, iteration, etc.) to now full interface unification. With this change, the in-memory source is fully integrated into Git's object storage layer while maintaining its transient nature (objects are discarded at process exit).

The patch appears straightforward and well-contained, touching only the necessary type conversions without introducing new functionality. It represents the last step in making the in-memory source a first-class citizen in the ODB abstraction architecture. Given the careful progression of the series and Patrick's track record with architectural changes, this seems like a solid conclusion to the effort.
