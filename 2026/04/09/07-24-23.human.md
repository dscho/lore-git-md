This is the second patch in Patrick Steinhardt's 17-part series introducing an in-memory object database (ODB) source as part of the broader ODB abstraction effort. The patch implements the `free()` callback for the in-memory ODB source, which handles cleanup when the source is destroyed.

The changes move the `struct cached_object_entry` definition from `odb.c` to `odb/source-inmemory.h` since it's now needed in both files. The actual free logic remains similar but is now properly encapsulated in the ODB source callback structure. This is a straightforward mechanical change that follows the pattern of the ODB abstraction work.

The patch continues the series' clean separation of concerns by moving source-specific cleanup into the source implementation rather than handling it in the generic ODB code. This is part of the architectural consistency Patrick has maintained throughout the series. The implementation looks correct and follows established patterns, though as noted in the commit message, the exposure of `struct cached_object_entry` will be addressed in later patches.
