This is a refactoring patch in the fsmonitor series, renaming `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is shared across Unix platforms, not just macOS. The change follows the same pattern already used for the IPC implementation, using the `FSMONITOR_OS_SETTINGS` build variable to select the appropriate file.

The patch updates both the CMake and meson build systems to reference the renamed file via the new variable. This is a straightforward mechanical change that maintains all existing functionality while improving the code organization for the upcoming Linux fsmonitor support. The rename was previously done for the IPC code, and this completes the parallel treatment of the settings component.

The patch carries forward attribution to Eric DeCosta and Marziyeh Esipreh for their earlier work that this builds upon. This is part of the larger cross-platform fsmonitor effort that has been through 14 iterations of review and testing, with this change representing final cleanup of the build system organization before potential inclusion.
