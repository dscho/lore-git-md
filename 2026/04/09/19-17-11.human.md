This is the final version (v8) of a feature patch series that enhances `git checkout -m` to use autostash behavior when switching branches with conflicts. The series has been through extensive review and testing, with all edge cases now resolved.

The key improvements in v8 include:
1. Added support for empty conflict labels in stash application
2. Fixed xdiff/xmerge.c to properly handle empty label strings
3. Added more robust stash list verification in tests
4. Improved documentation wording around conflict handling

The implementation now:
- Provides customizable conflict marker labels via new `--ours-label`, `--theirs-label`, and `--base-label` options for `git stash apply`
- Handles silent autostash creation during checkout operations
- Unifies conflict resolution behavior between `git checkout -m` and other commands
- Includes comprehensive test coverage (19 test cases in t7201-co.sh)

The series touches several core components:
- `builtin/checkout.c` for the main merge/checkout logic
- `builtin/stash.c` for the new labeling options
- `sequencer.c` for autostash handling
- Multiple test files for verification

This represents a significant quality-of-life improvement for branch switching workflows, particularly for developers who frequently context switch between branches with uncommitted changes. The maintainer feedback and thorough testing indicate this is production-ready and likely to be merged soon.
