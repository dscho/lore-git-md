The thread discusses enabling Rust support by default in Git's build system, marking a key step in the ongoing Rustification effort. brian m. carlson has sent a 4-patch series (now at v2) that flips the configuration from opt-in to opt-out, changing `WITH_RUST` to `NO_RUST` in both Makefile and Meson builds. The changes focus on build infrastructure rather than adding new Rust functionality, completing work originally planned for Git 2.53 but delayed until now.

The series updates CI configurations to test both Rust-enabled and disabled scenarios, with Windows builds explicitly disabling Rust while Meson builds default to enabled. Documentation has been made to reflect that Rust will become mandatory in Git 3.0. While the changes appear well-tested across most platforms, one notable open question remains: the series doesn't address compatibility with the NonStop platform, which lacks Rust toolchain support - a concern previously raised by Randall S. Becker. So far, no other contributors have commented on this iteration of the series.
