This is patch 12/17 in Patrick Steinhardt's series implementing an in-memory object database source as part of the broader ODB abstraction effort. The patch adds the `for_each_object()` callback to the in-memory ODB backend, completing another piece of the required functionality.

The implementation uses the oidtree data structure (converted from an array in patch 11) to efficiently iterate over stored objects. It handles both cases where callers request full object info (populated via a new helper function) and when they just need the OIDs. The callback respects iteration options like prefix filtering and promisor/local-only flags.

The changes are cleanly separated - first extracting object info population into a reusable helper, then implementing the iteration logic with proper callback handling. This continues the series' pattern of careful, incremental implementation of each ODB source operation. The patch appears well-structured and maintains consistency with the overall design.

As with previous patches in the series, this is foundational work that enables future functionality rather than providing immediate user-facing benefits. Reviewers will likely focus on the correctness of the iteration logic and its integration with the broader ODB source interface.
