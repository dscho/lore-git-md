This is a feature patchset introducing an in-memory object database source as part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort. The 17-patch series (version 2) adds a new backend that stores objects purely in memory without persistence, building on previous refactoring work.

The in-memory ODB serves several purposes: handling git-blame's temporary worktree commits, providing infrastructure for future features like re-merging diffs, and eventually allowing callers to opt into non-persistent writes. The series also aims to eliminate the `struct object_info::whence` field by providing richer backend-specific information.

Key technical changes include:
- New `odb/source-inmemory.[ch]` files implementing all required ODB callbacks
- Modifications to cbtree and oidtree data structures to support arbitrary data storage
- Simplification of existing ODB functions made possible by the new abstraction
- Conversion from array-based storage to oidtree for better performance

The v2 changes address object ID handling during writes and rebase onto Justin Tobler's ODB write stream refactorings. Patrick notes this may require waiting for Justin's series to land first. The series appears well-structured with each commit focused on implementing specific functionality, maintaining Patrick's reputation for careful architectural work.

This represents a significant step in the broader ODB abstraction effort, providing infrastructure that could enable future features while cleaning up technical debt in Git's object storage layer.
