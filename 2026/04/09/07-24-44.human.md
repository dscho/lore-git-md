This is a release announcement for Git for Windows 2.54.0-rc1, the Windows-specific fork of Git maintained by Johannes Schindelin. Note that this is not an upstream Git release - it's a packaging of Git 2.54.0-rc1 with Windows-specific modifications and bundled components.

The key changes in this release include:

1. **Removal of git-svn**: The Subversion interoperability command is no longer included due to maintenance challenges. Users needing this functionality are directed to use WSL or install via MSYS2.

2. **Component updates**: Bundles newer versions of supporting tools including Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2, and OpenSSH 10.3.P1.

3. **Bug fixes**: Several Windows-specific issues are fixed, including:
   - Restoring the missing iconv executable
   - Fixing input ordering issues in Git Bash
   - Improving git worktree remove behavior with NTFS junctions
   - Correcting CPU core detection on multi-socket systems

The announcement provides SHA-256 checksums for all distribution formats (installers, portable versions, and MinGit variants) across x64, ARM64, and 32-bit architectures.

This appears to be a routine maintenance release with the notable exception of dropping git-svn support, which may impact some Windows users' workflows depend on Subversion interoperability. The announcement provides clear migration paths for affected users.
