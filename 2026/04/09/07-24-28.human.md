This is part of Patrick Steinhardt's ongoing ODB (object database) abstraction effort, specifically patch 7/17 in the v2 series introducing an in-memory object database source. The patch implements the `write_object()` callback for this transient storage layer.

The change is straightforward - it adds object hashing via `hash_object_file()` before storing objects in the growing array (which will later be converted to an oidtree). This ensures objects get proper OIDs when written to the in-memory backend. The implementation matches the pattern seen in other ODB backends.

As part of a well-structured series from a trusted contributor, this patch appears to be a solid incremental step. It builds on the previous patches that set up the infrastructure and will be followed by more callbacks and storage optimizations. The change is small but necessary for the overall feature's correctness.
