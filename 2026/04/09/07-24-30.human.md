This is a refactoring patch in Patrick Steinhardt's ongoing ODB (object database) abstraction series. It modifies the cbtree data structure to allow embedding nodes in wrapper structures, which is needed for the in-memory ODB implementation.

The patch changes how the cbtree subsystem handles node keys by:
1. Removing the flex array from `struct cb_node` and instead tracking key locations via an offset
2. Adding helper functions to access keys based on this offset
3. Updating all cbtree operations to use the new key access pattern
4. Adapting the oidtree implementation (which uses cbtree) to work with the new approach

The change trades a small increase in memory usage (from 60 to 64 bytes per node) for better flexibility in how nodes are structured and eliminates some memory copies that were previously needed for alignment. This enables cleaner integration with the in-memory ODB backend being developed in the series.

The implementation appears thorough and maintains the existing functionality while providing the needed flexibility. As part of a larger architectural effort, this change helps pave the way for more flexible object storage backends in Git.
