Feature patch adding silent autostash creation capability to the sequencer, part of a larger series enhancing `git checkout -m` behavior.

This patch introduces a new `create_autostash_ref_silent()` function that allows creating an autostash without printing the "Created autostash" message. The implementation modifies the internal `create_autostash_internal()` function to accept a `silent` parameter, with existing callers continuing to use the non-silent behavior for backward compatibility. When silent mode is enabled, the status message is suppressed entirely rather than being redirected to stderr.

The change is part of a broader effort to improve the branch switching experience when there are uncommitted changes. The silent option will be used by `git checkout -m` to avoid cluttering output during automated operations while still maintaining the existing verbose behavior for direct stash commands. The patch includes updates to both `sequencer.c` and `sequencer.h` to expose the new functionality.

This is the second of four patches in the v8 series, which has undergone extensive review and testing. The implementation is now production-ready with comprehensive test coverage, including specific verification of the silent behavior in the test suite. The patch maintains backward compatibility while adding the new capability needed for the unified conflict resolution workflow.
