This is a test patch in the fsmonitor Linux implementation series, now at v14. It addresses an incompatibility between `index.skipHash` (enabled by default in Scalar) and split-index mode, which causes fsmonitor to trigger a BUG assertion when the shared index gets a null OID.

The patch disables `GIT_TEST_SPLIT_INDEX` in Scalar clone tests (t9210 tests 12, 13, and 22, plus all of t9211) to avoid this issue. This matches an existing workaround already present in t9210 test 16. The change is straightforward and uncontroversial, simply extending the same test workaround to additional test cases.

This is part of the larger cross-platform fsmonitor effort that has been through extensive review over 14 iterations. The patch maintains the established design decision that split-index and index.skipHash are fundamentally incompatible, following maintainer guidance for consistent test handling. The change helps ensure test reliability without requiring architectural modifications to the fsmonitor implementation itself.
