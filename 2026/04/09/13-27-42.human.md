This is the first patch in a feature series (v7) that enhances `git stash apply` with customizable conflict marker labels. The patch adds new `--ours-label`, `--theirs-label`, and `--base-label` options to `git stash apply`, allowing users to specify custom labels for conflict markers instead of the default "Updated upstream" and "Stashed changes" text. The `--base-label` option only takes effect when `merge.conflictStyle` is set to `diff3`.

The implementation includes:
- Documentation updates explaining the new options
- Usage string updates in `builtin/stash.c`
- A new test case verifying the custom labels work as expected

This change is part of a larger effort to improve conflict resolution during branch switching with `git checkout -m` by integrating autostash behavior. The custom labels will be used by subsequent patches in the series when automatically applying stashes during checkout operations. The patch appears well-tested and production-ready, with Junio Hamano having approved the approach in previous iterations.
