This is part 2 of a 4-patch series implementing unified conflict resolution in `git checkout -m` through autostash behavior. The series has been through multiple rounds of review and is now in its final polishing stage with maintainer approval.

This particular patch adds a silent mode for autostash creation, introducing a new create_autostash_ref_silent()` function that suppresses the "Created autostash" message. The change is straightforward - it modifies the internal `create_autostash_internal()` function to accept a `silent` parameter and routes the output to stderr when not silent. The patch maintains backward compatibility by keeping the existing functions unchanged while adding the new silent variant.

The change is clean and focused, touching only the sequencer code needed for autostash operations. It's part of the larger effort to make `git checkout -m` handle conflicts more gracefully by using autostash behind the scenes. The implementation appears solid with no obvious issues - the series as a whole has been thoroughly reviewed and tested, including new test cases added in v7 to verify edge cases.

This is a technical plumbing change that enables the more user-visible improvements in the rest of the series. While not flashy on its own, it's an important piece of the unified conflict resolution behavior that the maintainer has indicated is ready for merging.
