This is a maintainer review comment on a `git stash` usability improvement patch. Junio C Hamano points out a test hygiene issue in Deveshi Dwivedi's v3 patch, which makes `git stash` automatically assume the "push" subcommand when unambiguous push-specific flags are present.

He suggests using `test_when_finished` for more robust cleanup, explaining two common patterns: either placing a broad cleanup at the start (like `git reset --hard`) or adding specific cleanups right after creating test artifacts (like removing an untracked file immediately after creating it).

The feedback is narrowly focused on test structure rather than the core functionality, which appears sound based on the thread history.
