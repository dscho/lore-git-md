Platform compatibility patch adding Windows pthread emulation for `pthread_cond_timedwait()`. This is part of the larger fsmonitor series (v14) implementing cross-platform filesystem monitoring.

The patch implements the timed wait function using Windows' `SleepConditionVariableCS()` with millisecond timeout calculation. It handles time conversion from the POSIX `timespec` structure to Windows' DWORD timeout, including proper ETIMEDOUT handling when the deadline has passed. The implementation appears straightforward and well-contained, matching the style of existing pthread emulation in the compat layer.

This is one of several Windows compatibility pieces needed for the fsmonitor daemon's cross-platform behavior. The series has been through extensive review (14 iterations) and this particular component looks solid - it follows the established pattern for Windows emulation while adding the specific functionality needed for the fsmonitor timeout handling.
