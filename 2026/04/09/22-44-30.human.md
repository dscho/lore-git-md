This is a feature patch series that enables Rust support in Git by default, part of the ongoing Rustification effort. The cover letter explains this was originally planned for Git 2.53 but was missed, so the author is now targeting 2.54.

The series makes several build system changes to enable Rust by default while maintaining the ability to disable it. Key changes include moving Cargo configuration to `src/meson.rs`, adding a Meson build option without Rust, and updating CI to install cargo on Alpine Linux. The patches also handle platform-specific requirements like linking against libdl on Linux.

The author (brian m. carlson) is a long-time contributor who previously led the hash-algorithm-agnostic work. This series appears to be a straightforward follow-through on previously stated plans, with v2 incorporating feedback about build system organization. The changes are focused on build configuration rather than introducing new Rust code, suggesting this is an incremental step in the broader Rustification effort.
