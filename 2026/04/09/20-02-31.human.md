This is a follow-up from the Git maintainer on the branch name prefixing feature proposal, now in its fourth iteration. Junio Hamano raises additional concerns about the design's usability, specifically questioning why users should need to manually include a hyphen when creating prefixed branch names.

The maintainer suggests that the hyphen separating the prefix from the branch name should either be part of the configured prefix itself (e.g., "blob-") or automatically inserted by Git's prefixing mechanism. He notes that while he remains skeptical about the feature's value (as expressed in previous feedback), this particular design choice seems particularly user-unfriendly even if the feature were to be accepted.

The email continues the ongoing tension between the technical implementation (which has improved through multiple revisions) and fundamental questions about whether this functionality belongs in Git core. Junio's feedback indicates that even if the implementation details were perfected, the feature would still face an uphill battle for acceptance without stronger justification of its workflow benefits and reconsideration of its user interface design.
