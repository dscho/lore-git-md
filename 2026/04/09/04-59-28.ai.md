This is a refactoring patch in the fsmonitor series, specifically addressing build system organization for the cross-platform IPC implementation. Patch 6/13 in v14 renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that this IPC code is shared across Unix platforms (not just macOS), while introducing a new `FSMONITOR_OS_SETTINGS` variable to distinguish between platform-specific and shared components.

The change separates concerns between daemon backend implementations (listen/health/path-utils) and shared Unix infrastructure (ipc/settings). The patch updates all three build systems (Makefile, CMake, meson) consistently, with the IPC file now built based on `FSMONITOR_OS_SETTINGS` while path utilities remain tied to `FSMONITOR_DAEMON_BACKEND`. 

This is a mechanical change that builds on prior work from Eric DeCosta and Marziyeh Esipreh, maintaining all existing functionality while better organizing the code for the upcoming Linux fsmonitor support. The patch demonstrates careful attention to build system consistency across platforms, with macOS now using "unix" for shared components while keeping "darwin" for its platform-specific implementations.
