This is the third patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source as part of the broader ODB abstraction effort. The patch fixes a redundant object existence check in `odb_pretend_object()`.

The function currently checks for an object's existence twice when writing to the in-memory ODB: first via `odb_has_object()` (which already checks all sources including the in-memory one), then again with a direct `find_cached_object()` call. The patch removes this unnecessary second check since the first one already covers it through the call chain.

This is a small but logical cleanup that makes the code more efficient by eliminating a redundant lookup. The change is straightforward and low-risk, touching just 3 lines in `odb.c`. It fits naturally into the series' goal of properly structuring the in-memory ODB implementation.
