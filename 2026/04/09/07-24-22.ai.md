This is the first patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source as part of the ongoing ODB abstraction effort. The patch lays the groundwork by creating the basic infrastructure for the new in-memory backend while maintaining backward compatibility.

The patch:
1. Introduces new `odb/source-inmemory.[ch]` files with the core structure and initialization code
2. Replaces the existing `cached_objects` array in `struct object_database` with a new `inmemory_objects` field pointing to the structured source
3. Maintains identical functionality while preparing for future extension of the interface
4. Updates build systems (Makefile and meson.build) to include the new source files

Key technical details:
- The in-memory source will initially serve the same purpose as the existing cached objects (storing temporary objects like git-blame's worktree commits)
- The implementation uses the same ODB source abstraction pattern seen in other backends
- Memory management remains unchanged - objects are still freed when the ODB is closed
- The patch introduces proper type safety through the `odb_source_inmemory_downcast()` helper

This foundational change enables the subsequent patches to build out the full ODB source interface while keeping the series bisectable. The patch appears carefully crafted to minimize disruption while setting up the architectural framework for the new backend.
