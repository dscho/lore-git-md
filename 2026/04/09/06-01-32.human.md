This is a feature patch (v3) from Jayesh Daga adding structured access to repository metadata via `git repo info`, specifically introducing a `paths.toplevel` field that mirrors `git rev-parse --show-toplevel` functionality. The patch has already gone through two rounds of review with Junio C Hamano, who requested documentation improvements and style fixes in previous versions. This v3 iteration makes only minor tweaks to the commit message signature format and maintains all the substantive changes from v2.

The key aspects remain:
1. A new `paths.toplevel` field that exposes the working tree root via `repo_get_work_tree()`
2. Comprehensive documentation mapping `rev-parse` options to `repo info` fields
3. Consistent handling of bare repositories (empty string output)
4. Test coverage verifying behavior matches `rev-parse` in both regular and bare repositories

The changes from v2 to v3 are purely cosmetic - fixing the Signed-off-by line format and maintaining the tab indentation that was corrected in v2. The patch appears ready for inclusion, having addressed all maintainer feedback while providing a structured alternative to `rev-parse` for scripts needing repository root information. The implementation follows established patterns in the repo info subsystem and maintains backward compatibility.
