This is a feature patch series implementing Linux filesystem monitoring (fsmonitor) support via inotify, now at version 14. The maintainer Junio Hamano has reviewed the latest changes and is queuing the series for integration.

The series brings Linux fsmonitor support to parity with existing Windows and macOS implementations, completing cross-platform coverage. The v14 changes address a final test suite issue by consistently disabling GIT_TEST_SPLIT_INDEX in all relevant scalar clone tests (t9210 and t9211), following maintainer feedback.

The implementation is production-ready after extensive testing across 14 iterations, with thorough handling of edge cases like stale renames, watch limits, and remote filesystems. Key technical components include process isolation improvements, daemon shutdown timeouts, and platform-specific implementations (inotify for Linux, pthread emulation for Windows).

With the maintainer's approval and all substantive review feedback addressed, this appears to be the final version of this long-running effort to add native Linux fsmonitor support. The series represents a significant completion of cross-platform filesystem monitoring capabilities in Git.
