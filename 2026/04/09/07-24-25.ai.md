This is patch 4/17 in Patrick Steinhardt's v2 series implementing an in-memory object database source as part of the ODB abstraction effort. The patch implements the `read_object_info()` callback for the in-memory ODB source, moving the functionality from `odb.c` to the new `source-inmemory.c` module.

The change:
- Moves the `find_cached_object()` helper from `odb.c` to `source-inmemory.c`
- Implements `odb_source_inmemory_read_object_info()` to handle object info requests
- Updates the callback to use proper type safety with `odb_source_inmemory_downcast()`
- Maintains all existing behavior including special handling of empty trees
- Files touched: `odb.c`, `odb/source-inmemory.c`
- Key functions: `find_cached_object()`, `odb_source_inmemory_read_object_info()`
- Callback implemented: `read_object_info` in `struct odb_source_ops`

This is a straightforward refactoring that follows the series' pattern of moving ODB source functionality into dedicated modules. The implementation appears clean and maintains all existing behavior while properly integrating with the ODB abstraction interfaces. The patch continues the technical debt cleanup by removing the object info handling from `odb.c` and properly encapsulating it in the in-memory source module.
