This is part 2 of a 4-patch series implementing silent autostash creation during branch switching with conflicts. The series has been through extensive review and is now in its final form.

The patch adds a `silent` parameter to the internal autostash creation function and introduces a new `create_autostash_ref_silent()` public function. When silent mode is enabled, the "Created autostash" message is suppressed, which is useful for non-interactive contexts like `git checkout -m`. The message is also moved to stderr when not silent, following Git's convention for user-facing output.

This change supports the series' goal of unifying conflict resolution behavior between `git checkout -m` and other commands like rebase/merge that use autostash. The implementation is straightforward and well-contained, modifying only the sequencer code while maintaining backward compatibility. The series has already been thoroughly reviewed and tested, with 19 test cases covering the new behavior.
