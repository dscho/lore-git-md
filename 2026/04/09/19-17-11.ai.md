This is the final version (v8) of a feature patch series that enhances `git checkout -m` to use autostash behavior when switching branches with conflicts. The series has been through extensive review and testing, with all edge cases now resolved.

The key improvements in v8 include:
1. Added support for empty conflict labels in stash application
2. Fixed xdiff/xmerge.c to properly handle empty label strings
3. Added more robust stash list verification in tests
4. Further refined documentation wording around the merge behavior

The implementation now provides:
- Customizable conflict markers via new `--apply` label options
- Silent autostash creation during branch switching
- Unified conflict resolution behavior matching existing rebase/merge workflows
- Comprehensive test coverage (19 cases in t7201-co.sh) including new tests for:
  - Non-overlapping changes
  - Empty label handling
  - Stash list verification

Technical components modified:
- `builtin/checkout.c` - core merge/checkout logic
- `builtin/stash.c` - label options
- `sequencer.c` - autostash handling
- `xdiff/xmerge.c` - label string handling
- Multiple test files with expanded coverage

The series has received maintainer approval through multiple iterations and addresses all feedback. The additional test cases in v8 specifically verify edge case behavior around empty labels and proper stash list management, further strengthening the implementation. This represents a significant quality-of-life improvement for branch switching workflows, particularly when working with uncommitted changes. The implementation is now fully production-ready with comprehensive documentation.
