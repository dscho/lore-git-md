This is a platform compatibility patch in the fsmonitor series, implementing `pthread_cond_timedwait()` for Windows to support the filesystem monitoring daemon's timeout behavior. The patch adds a Windows-specific implementation of the POSIX function using `SleepConditionVariableCS()`, converting the absolute timespec to a relative millisecond timeout. It handles time calculations carefully, checking for already-expired deadlines and properly translating Windows error codes to POSIX equivalents (ETIMEDOUT for timeouts). The implementation matches the existing pthread emulation layer's style and will be used by the fsmonitor daemon's shutdown sequence where a 30-second timeout was recently added. This is one of the final pieces needed for complete cross-platform fsmonitor support.
