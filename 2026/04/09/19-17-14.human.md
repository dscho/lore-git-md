This is the third patch in a 4-part feature series that enhances `git checkout -m` with autostash behavior and conflict marker labeling. The series is now in its final version (v8) and has received maintainer approval.

The current patch focuses on the sequencer component, adding support for optional conflict marker labels during autostash application. It introduces new parameters to pass custom labels (ours/theirs/base) through to the underlying stash application, matching functionality recently added to `git stash apply`. The key addition is `apply_autostash_ref_with_labels()`, which allows callers to specify these labels.

The implementation is clean and focused, with minimal changes needed to the existing autostash machinery. The patch maintains backward compatibility by keeping the original label-less functions and adding new variants for the label support. This follows Git's typical pattern of introducing new functionality without breaking existing behavior.

This patch builds on the previous work in the series (which added silent autostash creation and unified conflict resolution behavior), and has been thoroughly tested with 19 test cases in t7201-co.sh, including new tests for empty label handling. The series as a whole represents a significant quality-of-life improvement for branch switching workflows with uncommitted changes.
