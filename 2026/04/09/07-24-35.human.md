This is patch 14/17 in Patrick Steinhardt's series implementing an in-memory object database source as part of the ODB abstraction effort. The patch adds the `count_objects()` callback to the in-memory backend, completing another piece of the ODB source interface.

The implementation is straightforward - it uses the existing `for_each_object()` infrastructure to iterate through all objects in the in-memory store while counting them. The callback ignores the object IDs and info (marked UNUSED) since we only care about the count. The result is stored in the output parameter.

This is a small but necessary piece of the larger puzzle - each ODB source needs to support counting objects, and this patch fills that gap for the in-memory variant. The implementation looks correct and follows the pattern seen in other parts of the series. 

As with previous patches in this series, the change is well-contained and builds logically on the infrastructure already established. The patch doesn't introduce any new concepts or dependencies - it's simply wiring up another required callback using the existing components. This continues the series' pattern of methodically implementing each piece of the ODB source interface.
