Maintainer approval for unified checkout -m autostash behavior. This is Junio Hamano's final review of Harald Nordgren's v7 patch series that enhances `git checkout -m` to use autostash when switching branches with conflicts. The series has been through multiple iterations and is now in its final form.

Junio notes the series appears ready, with the main changes in v7 being a rebase onto current master and the addition of a new test case for non-overlapping changes. He suggests it would have been helpful to include a cover letter summarizing the overall goal and changes between versions, though the technical content itself looks sound.

The implementation provides several key improvements:
- New stash labeling options (`--ours-label`, `--theirs-label`, `--base-label`)
- Silent autostash creation during checkout operations
- Unified conflict resolution behavior in `git checkout -m` through autostash
- Comprehensive test coverage (now 19 test cases in t7201-co.sh)

With maintainer approval and all edge cases addressed through thorough testing, this series is likely to be merged soon. It represents a significant quality-of-life improvement for developers who frequently switch branches with uncommitted changes.
