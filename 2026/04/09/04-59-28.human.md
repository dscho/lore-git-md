This is a refactoring patch in the fsmonitor series, now at v14. It renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms, not just macOS. The change prepares for reuse by the upcoming Linux fsmonitor implementation.

The patch introduces a distinction between `FSMONITOR_OS_SETTINGS` (for shared Unix/Win32 files) and `FSMONITOR_DAEMON_BACKEND` (for platform-specific components), updating the build system logic accordingly. The changes affect Makefile, CMake, and meson build configurations while maintaining existing functionality.

This appears to be a straightforward infrastructure change that properly separates platform-specific and shared components in the fsmonitor codebase. The patch builds on prior work from Eric DeCosta and Marziyeh Esipreh, and is part of the larger effort to bring Linux fsmonitor support to parity with Windows and macOS implementations.
