Feature patch implementing Linux fsmonitor support via inotify.

This patch adds Linux support to Git's filesystem monitoring daemon, completing the cross-platform fsmonitor implementation alongside existing Windows and macOS versions. The Linux version uses inotify rather than fanotify due to privilege requirements, with careful handling of directory watches, rename tracking, and remote filesystem detection.

Key technical aspects include:
- Non-blocking event polling with 50ms timeout to prevent queue overflows
- Bidirectional hashmaps for efficient watch descriptor <-> path lookups
- Cookie-based rename tracking with stale detection
- Recursive watch registration for new directories
- Remote filesystem detection via statfs() and /proc/mounts
- Edge case handling for watch limits, unmounts, and queue overflows

The implementation includes documentation updates noting Linux-specific caveats around inotify watch limits, which may need adjustment for large repositories. The patch builds on prior work from Eric DeCosta and Marziyeh Esipreh, with extensive testing across 14 iterations.
