This is part 2 of a 4-patch series implementing unified conflict resolution in `git checkout -m` through autostash behavior. The series has been through multiple iterations with maintainer review and is now in its final polishing stage.

This specific patch adds silent autostash creation capability to the sequencer, introducing a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message. The change is straightforward - it modifies the internal `create_autostash_internal()` function to accept a `silent` parameter and routes the output through stderr when not silent. The patch maintains backward compatibility by keeping the existing non-silent functions as wrappers.

The silent functionality will be used by the checkout machinery when performing branch switches with conflicts, where the autostash creation is an implementation detail rather than something the user needs to be notified about. The implementation is clean and follows the established pattern of the sequencer code, with appropriate function declarations added to sequencer.h.

This is a well-contained change that fits naturally into the larger series' goal of making `git checkout -m` behave more intuitively with uncommitted changes. The patch has already received maintainer approval in previous iterations and appears ready for merging.
