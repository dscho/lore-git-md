This is patch 3/17 in Patrick Steinhardt's v2 series introducing an in-memory object database source as part of the ODB abstraction effort. The patch removes a redundant object existence check in `odb_pretend_object()`.

The function writes objects to the in-memory ODB source (making them temporarily available but not persisting them to disk). Currently it performs two checks before storing an object: first via `odb_has_object()` (which checks all ODB sources) and then again via `find_cached_object()` (which specifically checks the in-memory source). The patch points out that `odb_has_object()` already checks the in-memory source through its call chain, making the second check redundant.

The change is straightforward - removing the extra `find_cached_object()` call while maintaining the same behavior. This is a small but logical cleanup that eliminates unnecessary work in the object storage path. The patch aligns with the series' broader goal of cleaning up technical debt in the ODB layer while implementing the new in-memory source functionality.
