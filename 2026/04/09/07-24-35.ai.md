This is patch 14/17 in Patrick Steinhardt's series implementing an in-memory object database source as part of the ODB abstraction effort. The patch adds the `count_objects()` callback to the in-memory ODB backend, completing another piece of the required interface.

The implementation is straightforward - it leverages the existing `for_each_object()` infrastructure (added in patch 12) to iterate through all objects while counting them. The callback simply increments a counter for each object encountered. The count is then returned via the `out` parameter.

This follows the pattern seen in other patches of the series - implementing required ODB source callbacks one by one. The implementation appears clean and consistent with the rest of the series. Since the in-memory backend already has full object iteration capability from earlier patches, this is a natural extension that completes another piece of the ODB source interface.

The patch touches only `odb/source-inmemory.c`, adding about 20 lines of straightforward code. It builds on the solid foundation established by previous patches in the series and doesn't introduce any new concepts or complexity. As with the rest of the series, this appears to be well-considered work that moves the ODB abstraction effort forward.
