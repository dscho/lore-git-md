This is patch 15/17 in Patrick Steinhardt's series implementing an in-memory object database (ODB) source as part of the broader ODB abstraction effort. The patch adds the `freshen_object()` callback to the in-memory backend, which checks whether an object exists in the in-memory store without actually reading it.

The implementation is straightforward - it reuses the existing `find_cached_object()` helper to look up the OID in the oidtree storage (added in patch 11). The callback returns 1 if the object exists and 0 otherwise, matching the behavior of other ODB backends. This completes another piece of the ODB source interface.

The change is small (10 lines) and focused, following the pattern of previous patches in the series where each implements a specific callback. Given the thoroughness of the overall series and Patrick's track record with architectural changes, this appears to be a solid incremental step toward completing the in-memory backend implementation.
