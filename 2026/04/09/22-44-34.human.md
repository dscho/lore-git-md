This is the final patch in a series enabling Rust support by default in Git's build system, part of the ongoing Rustification effort. The patch flips the default from opt-in to opt-out, changing the build configuration so Rust is enabled unless explicitly disabled with NO_RUST. It updates both Makefile and Meson build systems, along with CI configurations to test both Rust-enabled and disabled scenarios.

The changes are straightforward build system plumbing: switching WITH_RUST to NO_RUST in the Makefile, adjusting Meson configuration to enable Rust by default, and updating CI jobs to test the new default behavior. The patch maintains backward compatibility while moving toward the project's stated goal of mandatory Rust support in Git 3.0.

Notably, this iteration moves the cargo detection in Meson to a more appropriate location and simplifies the build logic. The CI changes ensure coverage of both Rust-enabled and disabled scenarios across platforms, though the Makefile-based Windows build is explicitly set to skip Rust (while Meson Windows builds will use it by default).

This appears to be a well-executed technical change that follows through on previously announced plans. The patch series has evolved cleanly from v1 to v2 based on feedback, though it still doesn't address the NonStop platform compatibility concerns previously raised by Randall S. Becker. The changes are focused and mechanical, with clear commit messages explaining each adjustment.
