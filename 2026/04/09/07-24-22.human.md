This is the first patch in Patrick Steinhardt's 17-part series introducing an in-memory object database source as part of the ongoing ODB (object database) abstraction effort. The patch lays the groundwork by creating the basic structure for an in-memory ODB source that can store temporary objects that won't persist after Git exits.

The patch moves the cached objects functionality (previously stored directly in the object_database struct) into a new odb_source_inmemory structure. This includes objects like the empty tree and temporary worktree commits used by git-blame. The implementation provides the same interface as other ODB sources, making it consistent with the broader abstraction effort.

Key changes include:
- New files `odb/source-inmemory.[ch]` for the in-memory backend
- Migration of cached objects from object_database to odb_source_inmemory
- Basic initialization infrastructure for the new source type

This appears to be a well-structured foundation for the subsequent patches that will implement the full functionality. The change is part of Patrick's larger effort to make Git's object storage more modular and pluggable. Given the author's track record with architectural changes, this is likely to be a solid technical foundation, though the full utility will become clearer as the series progresses.
