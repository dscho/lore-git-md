This is patch 8/17 in Patrick Steinhardt's series implementing an in-memory object database source as part of the broader ODB abstraction effort. The patch adds streaming write capability to the in-memory backend.

The implementation reads chunks from the input stream into a buffer, verifies the total length matches expectations, and then writes the complete object to memory storage. It handles error cases where the stream provides too much or too little data, and properly cleans up allocated memory. The streaming interface matches the pattern established in earlier patches and integrates with Justin Tobler's ODB write stream refactoring work.

This continues the series' pattern of thorough, incremental implementation - each patch focuses on adding one well-defined piece of functionality while maintaining consistency with the overall design. The code follows Git's established patterns for error handling and memory management. As with previous patches in the series, this appears ready for review but may need to wait for related infrastructure changes to land first.
