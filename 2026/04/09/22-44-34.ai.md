This is the final patch in a series enabling Rust support by default in Git's build system, part of the ongoing Rustification effort. The patch flips the default configuration from opt-in to opt-out, changing `WITH_RUST` to `NO_RUST` in the Makefile and Meson build systems. It updates CI configurations to test both Rust-enabled and disabled scenarios, with Windows builds explicitly disabling Rust while Meson builds default to enabled.

The changes are focused on build infrastructure rather than adding new Rust functionality, completing plumbing work that was originally planned for Git 2.53 but delayed. The patch moves cargo detection in Meson to a more appropriate location and updates documentation to reflect that Rust will become mandatory in Git 3.0. While the changes appear well-tested across platforms, the series does not address the known concern about NonStop platform compatibility (raised previously by Randall S. Becker) where Rust toolchain support is unavailable.
