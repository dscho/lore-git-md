Windows platform release announcement for Git for Windows 2.54.0-rc1. This is a release candidate for the Windows-specific distribution of Git, maintained separately from the main Git project.

The announcement comes from Johannes Schindelin, the primary maintainer of Git for Windows. The release tracks upstream Git v2.54.0-rc1 and includes several bundled components with version updates: Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2, MSYS2 runtime (based on Cygwin 3.6.7), cURL 8.19.0, and OpenSSH 10.3.P1.

Notable changes include the removal of `git svn` from the distribution due to maintenance challenges, with users directed to alternative installation methods via MSYS2 or WSL. Several Windows-specific fixes are included: restoration of the accidentally omitted `iconv` executable, improved input handling in Git Bash, better NTFS junction handling in `git worktree remove`, and corrected CPU core detection on multi-socket systems.

The announcement provides SHA-256 checksums for various distribution formats (installers, portable archives, and MinGit variants) across 32-bit, 64-bit, and ARM64 architectures. This release follows the standard Git for Windows practice of tracking upstream Git releases while maintaining Windows-specific components and fixes.
