This is patch 2/17 in Patrick Steinhardt's v2 series implementing an in-memory object database source as part of the broader ODB abstraction effort. The patch focuses on the cleanup infrastructure by implementing the `free()` callback for the in-memory ODB source.

The key change moves the memory management logic from `odb.c` into a dedicated `odb_source_inmemory_free()` function in the in-memory source implementation. This properly encapsulates the cleanup behavior within the source module rather than having it handled by the generic ODB code. The patch also makes the `struct cached_object_entry` definition public by moving it to the header file since it's now accessed by both the ODB core and the in-memory source implementation.

This is a straightforward refactoring that follows the series' architectural approach of moving functionality into the appropriate modules. The change is mechanical but important for proper resource management in the in-memory ODB source. The patch maintains consistency with the overall series goal of abstracting ODB sources while cleaning up technical debt in the object storage layer.
