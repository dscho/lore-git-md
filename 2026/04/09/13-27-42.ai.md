This is the first patch in a feature series (v7) that adds customizable conflict marker labels to `git stash apply`. The patch introduces three new options (`--ours-label`, `--theirs-label`, `--base-label`) that allow users to specify custom labels for conflict markers instead of the default "Updated upstream" and "Stashed changes" text.

The implementation modifies `builtin/stash.c` to accept the new options and updates the documentation accordingly. A new test case in `t/t3903-stash.sh` verifies the functionality by creating a simple conflict scenario and checking that the custom labels appear in the conflict markers. The `--base-label` option only takes effect when `merge.conflictStyle` is set to `diff3`.

This change is part of a larger effort to improve conflict resolution in `git checkout -m` by integrating autostash behavior, with these label options being a supporting feature. The patch is well-contained, with clear documentation and test coverage. The series has already received maintainer approval in previous iterations, and this version includes only minor documentation formatting fixes from v6.
