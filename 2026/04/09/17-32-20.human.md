This is a feature patch in the final stages of review, part of a series enhancing autostash functionality with custom conflict marker labels. The patch adds label support to the sequencer's autostash machinery, allowing callers to specify custom labels for "ours", "theirs", and "base" sides when applying stashed changes.

Junio Hamano provides final feedback on naming consistency in the parameter interface, suggesting either using the more descriptive "ours/theirs/base" terminology throughout, or adopting the conventional stage numbering (1=base, 2=ours, 3=theirs) if numbered parameters are preferred. This is a minor naming polish on an otherwise solid implementation that builds on the series' earlier work.

The patch introduces `apply_autostash_ref_with_labels()` as the new interface while maintaining backward compatibility with the label-less version. The changes are cleanly contained to the sequencer component and follow the established pattern of the series. With this feedback addressed, the patch appears ready for merging as part of the complete series, which has already received maintainer approval pending final test improvements.
