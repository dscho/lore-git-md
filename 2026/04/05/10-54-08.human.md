This is a platform compatibility patch targeting Windows support. The change unifies and updates the `_WIN32_WINNT` version definitions across several Windows-specific files to explicitly declare Windows 8.1 (0x0603) as the minimum supported version, dropping older version support that Git no longer maintains.

The patch comes from Matthias Aßhauer with Johannes Schindelin's sign-off, indicating Windows platform expertise. It follows Git's recent move to drop Windows 7 support (commit ce6ccba) and aligns with Git for Windows' current minimum requirement of Windows 8.1. The change removes outdated version checks while preparing for future work on CPU core detection improvements.

The patch touches several compatibility files (`mingw.c`, `nedmalloc`, `poll`, `posix.h`, `flush.c`) to consistently set the Windows API version level. This appears to be a straightforward cleanup with no expected controversy, though Windows-specific patches often receive extra scrutiny from the Git for Windows maintainers. The changes are mechanical and well-contained.
