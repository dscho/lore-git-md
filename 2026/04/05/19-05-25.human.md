This is a platform compatibility report about OpenSSL 3.0 build failures. Randall S. Becker, the NonStop port maintainer, reports that Git 2.54.0-rc0 fails to compile when built against OpenSSL 3.0 due to type mismatches and undefined functions in `imap-send.c`. The errors suggest the code assumes OpenSSL APIs that have changed in version 3.0.

The issue appears to be specific to the IMAP send functionality, where the code uses `ASN1_STRING_get0_data()` which is either missing or has incompatible signatures in OpenSSL 3.0. This is likely to affect users with extended support contracts who are still on OpenSSL 3.0 rather than newer versions.

Randall's report is characteristically terse but technically precise, identifying the exact lines and error types. As the NonStop maintainer, he frequently surfaces platform-specific issues that might otherwise go unnoticed. The problem looks legitimate and narrowly scoped - a straightforward OpenSSL API compatibility issue that will need addressing for users stuck on older OpenSSL versions.
