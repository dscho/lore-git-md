Thread identity: OpenSSL build failures in Git 2.54.0-rc0, reported by Randall S. Becker (NonStop port maintainer), concerning compilation errors in `imap-send.c`.

Core problem: Initial report claimed Git failed to compile against OpenSSL 3.0 due to type mismatches around `ASN1_STRING_get0_data()` in `imap-send.c`. René Scharfe's analysis correctly identified the errors as characteristic of pre-OpenSSL 1.1.0 usage (pre-2016), not OpenSSL 3.0. Becker has now confirmed this was an operator error in their build environment.

Current status: Originally reported as OpenSSL 3.0 issue, now confirmed to be caused by outdated OpenSSL 1.0.2w. Becker will disable the problematic 1.0.2w configuration to prevent recurrence. No code changes required as the issue was misdiagnosed.

Key technical details: The email-sending infrastructure (`imap-send.c`) uses OpenSSL functions for SSL/TLS certificate handling. Scharfe noted `ASN1_STRING_get0_data()` was added in OpenSSL 1.1.0 (commit 17ebf85abd) and the const-correctness errors would only appear with pre-1.1.0 versions. This technical analysis was validated by Becker's confirmation.
