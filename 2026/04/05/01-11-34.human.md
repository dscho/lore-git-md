This is a test modernization patch, the final version in a series from Zakariyah Ali updating Git's test scripts to follow current conventions. The patch comprehensively restructures `t2000-conflict-when-checking-files-out.sh`, a test from 2005, to match modern standards.

The changes are mechanical but thorough: consolidating test blocks, switching to tab-based indentation, using modern test_expect_success formatting, and replacing direct shell tests with dedicated test_path_is_* helpers. The patch also adds specialized symlink-aware helpers (test_path_is_file_not_symlink and test_path_is_dir_not_symlink) where appropriate, though these are rarely used in the test suite.

The patch has gone through four iterations with review feedback from Tian Yuchen and incorporates guidance from Junio Hamano about test structure. All technical concerns have been addressed, and the only remaining suggestions were documentation refinements - adding a Helped-by trailer and explaining the symlink helper choice - which Zakariyah has now incorporated.

This appears ready for merging as part of the ongoing test modernization effort. Zakariyah also asks about future contribution opportunities, indicating this was part of a GSoC microproject.
