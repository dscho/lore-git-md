This is a documentation patch series updating references to the deprecated `git config --list` option, replacing them with the newer `git config list` subcommand. The series is a follow-up to Patrick Steinhardt's earlier work introducing subcommands for `git config`.

Kristoffer Haugsbakk has revised version 2 of the series after feedback from Junio Hamano. The key changes in v2 are: (1) separating the mechanical updates from the man page rephrasing into distinct commits, and (2) removing an incorrect WARNING admonition that would have suggested full deprecation of `git var -l` when only its config listing functionality is deprecated. The series now cleanly distinguishes between logical variables (still valid) and configuration variables (where the new subcommand should be used).

The patches update six documentation files with straightforward replacements, plus one commit that improves phrasing in gitcvs-migration.adoc. With Junio's approval of the technical corrections and the clear separation of concerns in v2, this well-scoped documentation cleanup appears ready for merging. The changes are purely textual with no behavior impact, systematically converting deprecated syntax while maintaining documentation accuracy.
