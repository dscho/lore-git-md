This thread documents the uncontroversial update to Git for Windows' minimum supported version from Windows 7 to Windows 8.1 (0x0603). The two-patch series from Johannes Schindelin (Git for Windows maintainer) and Matthias Aßhauer standardizes the Windows version macro across the codebase and removes legacy workarounds for older systems, including a 30-line pre-Vista console font detection hack in winansi.c.

Junio Hamano has reviewed and accepted the changes for merging directly into master, bypassing the usual next/seen integration branches - a rare fast-track that reflects both the mechanical nature of these updates and their origin from the Git for Windows maintainer following an already-announced policy change. The cleanup enables future use of newer Windows APIs while removing obsolete code paths, with no technical objections raised during review. These changes will appear in Git v2.54.0.
