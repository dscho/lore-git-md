This thread documents a straightforward platform compatibility update for Git on Windows. The two-patch series, co-authored by Git for Windows maintainer Johannes Schindelin and Matthias Aßhauer, implements Git for Windows 2.47.0's decision to drop support for pre-Windows 8.1 systems. 

The first patch standardized the minimum Windows version requirement (0x0603 for Windows 8.1) across multiple Windows-specific files, removing legacy checks for older versions like Vista, 7, and XP. The second patch, which just arrived, cleans up the winansi.c compatibility layer by removing a pre-Vista workaround for console font detection. This eliminates about 30 lines of now-unnecessary code while maintaining the same warning functionality for non-TrueType fonts.

These mechanical changes enable future use of newer Windows APIs and follow Git for Windows' announced compatibility policy. The patches appear ready for inclusion in v2.54.0, with no technical objections raised during review. The changes come from the Git for Windows maintainer and align with prior work to modernize Windows support, making them uncontroversial updates.
