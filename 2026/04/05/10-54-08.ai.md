Platform compatibility patch updating Windows version requirements. This change unifies and bumps the `_WIN32_WINNT` macro definition to Windows 8.1 (0x0603) across several compatibility files, removing outdated version checks for Windows Vista and earlier. The patch is co-authored by Matthias Aßhauer and Johannes Schindelin, with Schindelin's involvement signaling this is part of Git for Windows maintenance.

The change follows Git for Windows' 2.47.0 decision to drop support for pre-8.1 Windows versions, and builds on previous work like ce6ccba which removed Windows 7-specific code. The update enables access to newer Windows APIs and removes conflicting legacy definitions. A comment in mingw.c is also updated to reflect the new minimum version.

This appears to be preparatory work for future improvements to CPU core detection on multi-socket systems. The patch touches several Windows-specific compatibility files: mingw.c, nedmalloc, poll emulation, posix.h, and flush.c. The changes are mechanical version number updates with no functional changes to the actual code logic.
