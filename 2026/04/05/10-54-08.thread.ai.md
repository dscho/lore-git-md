Platform compatibility update finalizing Git for Windows' move to requiring Windows 8.1 as the minimum supported version (0x0603). The two-patch series from Johannes Schindelin and Matthias Aßhauer has been accepted by Junio Hamano for immediate inclusion in master, bypassing the usual next/seen integration path. The first patch unifies `_WIN32_WINNT` macro definition to 0x0603 across multiple Windows-specific files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c, winansi.c), removing legacy version checks for Windows Vista/7/XP and updating related comments. The second patch eliminates a pre-Vista workaround from winansi.c that handled console font detection on older systems, removing about 30 lines of registry-based fallback code and manual CONSOLE_FONT_INFOEX structure definitions for older MinGW toolchains. The simplified implementation now directly uses GetCurrentConsoleFontEx API while maintaining warning functionality for non-TrueType fonts. These mechanical changes follow Git for Windows' announced compatibility policy and enable future use of newer Windows APIs, particularly for multi-socket CPU core detection improvements. The series builds on prior work (ce6ccba) that removed Windows 7-specific code. No technical objections were raised during review, and Junio's direct application to master confirms the changes are uncontroversial and ready for v2.54.0.
