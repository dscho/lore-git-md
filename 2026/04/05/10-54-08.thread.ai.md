Platform compatibility update setting Windows 8.1 as the new minimum version (0x0603) across multiple Windows-specific files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c). Co-authored by Matthias Aßhauer and Johannes Schindelin (Git for Windows maintainer), this follows Git for Windows 2.47.0's decision to drop support for pre-8.1 Windows. The change removes legacy version checks for Windows Vista/7 and updates API availability comments. No functional changes - purely version number updates to enable future use of newer Windows APIs, particularly for multi-socket CPU core detection improvements. Builds on prior work (ce6ccba) that removed Windows 7-specific code.
