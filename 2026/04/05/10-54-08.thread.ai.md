Platform compatibility update setting Windows 8.1 as the new minimum version (0x0603) across multiple Windows-specific files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c, winansi.c). Co-authored by Johannes Schindelin (Git for Windows maintainer) and Matthias Aßhauer, this two-patch series implements Git for Windows 2.47.0's decision to drop support for pre-8.1 Windows. The first patch unifies `_WIN32_WINNT` macro definition to 0x0603, removing legacy version checks for Windows Vista/7/XP and updating related comments. The second patch (now detailed) eliminates a pre-Vista workaround from winansi.c that handled console font detection on older systems, removing about 30 lines of registry-based fallback code and manual CONSOLE_FONT_INFOEX structure definitions for older MinGW toolchains. The simplified implementation now directly uses GetCurrentConsoleFontEx API while maintaining the same warning functionality for non-TrueType fonts. These mechanical changes enable future use of newer Windows APIs, particularly for multi-socket CPU core detection improvements, and build on prior work (ce6ccba) that removed Windows 7-specific code. The updates are uncontroversial as they follow Git for Windows' announced compatibility policy and appear ready for inclusion in v2.54.0. No technical objections or review comments have been raised against the changes.
