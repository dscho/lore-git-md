This thread reports a build failure when compiling Git 2.54.0-rc0 against OpenSSL 3.0, identified by Randall S. Becker, the maintainer of Git's NonStop port. The issue occurs in `imap-send.c` where type mismatches and undefined functions prevent successful compilation, specifically around the `ASN1_STRING_get0_data()` call. 

The problem stems from API changes in OpenSSL 3.0, which remains in use in some enterprise environments despite newer versions being available. While the impact is limited to builds using OpenSSL 3.0, this represents a real compatibility issue for users on systems with extended support contracts. Becker's report provides clear reproduction details but does not yet propose a solution. The affected component (`imap-send.c`) handles Git's email-sending functionality, though the failure would only affect users building with OpenSSL-backed IMAP support.
