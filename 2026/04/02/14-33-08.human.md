Test modernization patch from Johannes Schindelin, part of a series preparing for potential future changes to Git's bare repository discovery behavior. This is patch 2/17 in the series, following the initial pattern-setting patch that updated t0001-init.sh to handle implicit bare repository discovery.

The change replaces shell commands that used `cd` followed by `git config` with direct `git --git-dir` invocations in the `check_config` test helper. This makes the test explicitly specify the repository location rather than relying on Git's implicit discovery of bare repositories, which may be disabled by default in future Git versions.

The modification is straightforward and mechanical - exactly the type of change expected in this series. It maintains the test's functionality while making it robust against the anticipated configuration change. The patch follows the established pattern from the series' first commit, using `--git-dir` to explicitly target the repository rather than changing directories.

As with the rest of the series, this change is unlikely to be controversial. It's a clear improvement that makes the test more explicit about its intentions while preserving its behavior.
