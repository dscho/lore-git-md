This is the cover letter for the third version of a feature series completing the write operations interface in Git's object database (ODB) transaction system, part of the ongoing ODB abstraction effort. Justin Tobler's 7-patch series builds on previous work to make ODB writes explicitly use the transaction interface rather than implicit redirection.

The series refactors and extends the transaction interface to support streaming writes, particularly for large blobs. Key changes in v3 include improved variable naming for clarity, fully initializing the `odb_write_stream` structure, moving stream-related definitions to "odb/streaming.h", and adding an explicit cleanup function. The series also introduces optimizations for packfile handling when size limits are configured.

Patrick Steinhardt has reviewed and approved the technical approach, and the author has incorporated all feedback from previous rounds. The changes affect core object-file handling used by commands like `git add` and `git update-index`. With this series, the ODB transaction interface now has a complete write path, establishing the foundation for future storage backends to implement their own write strategies while maintaining a consistent interface. The work appears ready for merging into the next integration branch.
