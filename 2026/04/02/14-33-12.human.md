This is the sixth patch in Johannes Schindelin's 17-part test modernization series preparing for Git's potential default behavior change regarding bare repository discovery. The patch updates t1900-repo-info.sh to avoid using `-C` for bare repositories, which would stop working if `safe.bareRepository` defaults to "explicit" in Git 3.0.

The change modifies the `test_repo_info` helper to accept an optional `repo_flag` parameter (defaulting to `-C`), then uses `--git-dir` instead for the test case that operates on a bare repository. This maintains the test's functionality while making it compatible with the upcoming behavior. The patch follows the established pattern from earlier in the series - replacing implicit bare repo discovery with explicit handling.

The change is straightforward and mechanical, like the rest of the series. It touches only one test file and follows the same careful, incremental approach seen in previous patches. The commit message clearly explains the motivation and the specific change being made.
