Performance optimization completing Phillip Wood's xdiff memory reduction series. This final patch moves allocation of the `reference_index` arrays in the Myers algorithm to match only the post-prefix/suffix line counts rather than the full file size, continuing the memory efficiency improvements from the first three patches.

The change relocates the `reference_index` array allocation from `xdl_prepare_ctx()` to `xdl_cleanup_records()`, where the actual needed size (after common line removal) is known. This follows the same pattern as the earlier action array optimizations in the series. The patch touches only `xdiff/xprepare.c` and maintains the same error handling, just consolidating it with the other allocations.

As with the rest of the series, this is a mechanical change that doesn't affect diff results - it simply reduces memory usage during diff calculation. The commit message clearly explains the motivation and approach. Given the focused nature of the change and Phillip Wood's established expertise in this area, this appears to be a straightforward improvement likely to be accepted without controversy.
