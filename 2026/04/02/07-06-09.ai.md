This is part 6 of Christian Couder's series refactoring promisor-remote handling. The patch extracts control character checking into a new `has_control_char()` helper function, replacing inline checks in `valid_token()`. 

The change is a straightforward code cleanup that:
1. Introduces a reusable helper for control character detection
2. Simplifies `valid_token()` by delegating the check
3. Maintains identical behavior (same warning messages when invalid tokens are found)

This is a preparatory step for future work that will need to check strings for control characters in other contexts. The patch touches only `promisor-remote.c`, modifying how token validation is implemented without changing any user-visible behavior. The series continues its pattern of incremental improvements to the promisor-remote subsystem's internal structure.
