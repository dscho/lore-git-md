This is the final patch in Patrick Steinhardt's reftable portability series, introducing memory mapping abstraction for cross-platform compatibility. The patch adds a `reftable_mmap` struct and corresponding functions (`reftable_mmap()` and `reftable_munmap()`) to provide a consistent interface for memory-mapped file operations across different platforms.

The changes replace direct `mmap`/`munmap` calls in the reftable blocksource implementation with these new wrappers, which internally use Git's existing `xmmap_gently()` helper. This abstraction allows other projects (like libgit2) to provide their own platform-specific implementations while maintaining the same interface.

The patch follows the established pattern of the series - small, focused changes that maintain clean separation between platform-specific and portable code. With this addition, the reftable implementation now has all the necessary abstractions for libgit2 to adopt the shared codebase. The changes are well-contained to the reftable subsystem and maintain existing behavior while improving portability.
