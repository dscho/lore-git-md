This is the final patch in Christian Couder's 10-part series refactoring promisor-remote handling. The patch focuses on test improvements, specifically addressing URI formatting in the test script `t5710-promisor-remote-capability.sh`.

The key change fixes how file:// URIs are constructed in tests to ensure cross-platform behavior. On Windows, paths starting with drive letters (like D:/path) were being incorrectly interpreted as hostnames rather than paths when formatted as file://D:/path. The patch introduces $PWD_URL and $ENCODED_PWD_URL helper variables that properly format paths with a leading slash (file:///D:/path) to comply with RFC 8089 URI standards.

The changes are forward-looking, anticipating future work that will use URL normalization functions. While the current tests pass without this fix (since they use direct comparisons), the patch ensures they'll continue working when more sophisticated URI handling is introduced. The modifications touch nearly every test case in the file, replacing raw `file://$(pwd)` constructions with the new helper variables.

This is a clean, focused test improvement that maintains the series' pattern of careful, behavior-preserving changes. The patch demonstrates good attention to platform compatibility details while keeping the test logic itself unchanged. As the final patch in the series, it provides a solid foundation for future promisor-remote work by ensuring the test suite handles URIs correctly across all platforms.
