This is patch 11/12 in Jeff King's series addressing C23 const-correctness warnings, specifically focusing on the HTTP subsystem. The patch fixes a warning in `redact_sensitive_header()` where `strstr()` was assigning a const pointer to a non-const variable when processing cookie headers.

The change removes const qualifiers from `sensitive_header` and `cookie` variables since they point to writable memory within a strbuf, while also adapting `skip_iprefix()` to handle the const/non-const conversion safely using the CONST_OUTPARAM pattern introduced earlier in the series. The implementation follows the same approach as previous patches - converting the inline function to a macro wrapper (`skip_iprefix_impl`) to maintain type safety.

This is a straightforward continuation of the series' pattern, applying the established solution to another subsystem.
