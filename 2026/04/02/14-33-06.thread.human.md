Johannes Schindelin has sent a 17-patch series modernizing Git's test suite in preparation for a potential future change where bare repository discovery may be disabled by default in Git 3.0. The changes are mechanical but widespread, touching 16 test files and git-p4.py to explicitly handle bare repositories rather than relying on implicit discovery. Each commit focuses on a specific test file, consistently using techniques like replacing `git -C` with `--git-dir`, exporting GIT_DIR, or using subshells with GIT_DIR set. Tests that genuinely need implicit discovery are explicitly configured with `safe.bareRepository=all`. The series is part of a larger pull request (#2072) and follows Johannes' typical focus on Windows compatibility and test infrastructure improvements. The changes are straightforward and unlikely to be controversial, though they touch many areas including worktree handling, fetch/push, submodules, and the git-p4 bridge.
