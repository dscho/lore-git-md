Johannes Schindelin continues his systematic update of Git's test suite to prepare for the upcoming change in how Git handles bare repository discovery (where `safe.bareRepository=explicit` will become the default in Git 3.0). The 17-patch series is methodically converting tests that rely on implicit bare repo discovery to use explicit `--git-dir` invocations instead.

The first four patches established patterns in t0001-init.sh, t0003-attributes.sh, and t0056-git-C.sh, with most tests being converted to use `--git-dir` directly. The fifth patch (this update) tackles t1020-subdirectory.sh, replacing a test that used a subshell with `cd` into a bare repo with a simpler `git --git-dir=foo.git show` call. This maintains the test's purpose while making it compatible with the future behavior change.

The changes remain mechanical and uncontroversial, with each patch focusing on one test file. The series is part of pull request #2072 and represents proactive work to update tests before the backward-incompatible behavior takes effect.
