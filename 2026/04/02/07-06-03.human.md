This is a preparatory patch series for enabling auto-configuration of promisor remotes via URL allowlists, part of the ongoing work to improve partial clone functionality. Christian Couder splits out these 10 patches from a larger 16-patch series based on reviewer feedback.

The series mixes small fixes (patches 1-4) with refactorings and cleanups (patches 5-10). The most notable change is in patch 1, which modifies `get_direct()` to try accepted remotes first. Other patches improve error handling (rejecting empty remote names/URLs in patch 4), refactor control flow, and clean up data structures used for tracking accepted remotes.

The changes focus on the promisor-remote subsystem, which handles partial clone functionality where objects can be fetched on-demand from alternate remotes. The test updates in patch 10 standardize on proper `file://` URIs for absolute paths in the test suite.

This appears to be well-structured preparatory work - the patches are small and focused, with clear commit messages explaining each change. The series passes CI tests and builds on existing promisor remote functionality while cleaning up the code in preparation for the more substantial auto-configuration feature to come in a follow-up series.
