Performance optimization series by Phillip Wood targeting xdiff's Myers diff algorithm implementation to reduce memory usage. The changes focus on shrinking dynamically allocated arrays in `xdiff/xprepare.c` to match only the post-prefix/suffix line counts rather than full file sizes. Current version includes patches 1/4 and 2/4: 

1/4 adjusts action arrays in `xdl_cleanup_records()`: introduces `len1`/`len2` variables for reduced sizes, maintains correct indexing into xdfile_t via offset, and updates bounds passed to `xdl_clean_mmatch()`. 

2/4 follows up with simplifications to `xdl_clean_mmatch()` enabled by the first patch: removes unused `s` parameter (always 0), changes `e` parameter to accept length rather than end index, and moves end index calculation into the function. Changes are mechanical and focused, touching only `xdiff/xprepare.c`.

The changes are strictly memory optimization with no expected impact on diff results, continuing Phillip Wood's established pattern of xdiff improvements. Builds on prior xdiff cleanup work (en/xdiff-cleanup-3). No reviews or objections noted yet; the technical approach suggests low controversy potential. Remaining patches in series will address: 3) preparation error handling streamlining, 4) further preparation-stage array reductions.
