Satirical follow-up to April Fools' joke about hash algorithms. Patrick Steinhardt confirms his MD5 implementation patch was an April 1st joke, but notes it actually works with only 15 test failures, demonstrating Git's improved hash algorithm flexibility. He credits brian m. carlson for the underlying infrastructure work that made this possible.

While maintaining the lighthearted tone, Steinhardt transitions to a serious observation: the exercise revealed how feasible it would be to add a third hash algorithm optimized for speed (rather than cryptographic security) for internal use cases. He explicitly separates this potential future discussion from the current joke context.

The email serves both to close out the April Fools' thread and to plant seeds for a legitimate technical discussion about hash algorithm extensibility. It maintains the joke's spirit while demonstrating how even satirical patches can yield useful insights about the codebase's architecture. The mention of test failures (despite overall functionality) provides a realistic assessment of the current state of hash algorithm support.
