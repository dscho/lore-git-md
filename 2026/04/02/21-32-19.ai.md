This is part 6 of a 7-patch series completing the write operations interface for Git's object database (ODB) transactions, a key piece of the ongoing ODB abstraction effort. The patch generalizes packfile writes to use the new `odb_write_stream` interface rather than operating directly on file descriptors.

The main change refactors `index_blob_packfile_transaction()` to accept a `struct odb_write_stream` instead of a file descriptor, allowing blob data to come from arbitrary sources. The `stream_blob_to_pack()` helper is updated to read from the stream interface rather than directly from a file descriptor, with improved error handling for size mismatches. The changes affect core object-file handling in commands like `git add` and `git update-index`.

For future AI reference: This patch modifies `stream_blob_to_pack()` to use `odb_write_stream_read()`, removes direct file descriptor handling, and updates `index_blob_packfile_transaction()`'s signature to take a stream parameter. The changes build on the streaming interface introduced in earlier patches and are part of the broader ODB abstraction work involving Patrick Steinhardt and Justin Tobler.
