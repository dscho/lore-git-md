This is the final patch in Christian Couder's 10-part series refactoring promisor-remote handling, focusing on test improvements. The patch addresses cross-platform compatibility in test scripts by fixing how file:// URIs are constructed for absolute paths.

The issue stems from Windows paths starting with drive letters (D:/path) being misinterpreted as hostnames when formatted as file:// URIs. The patch introduces $PWD_URL and $ENCODED_PWD_URL helper variables that ensure proper 3-slash file:/// URIs on all platforms, with proper handling of spaces in paths. This future-proofs the tests for upcoming changes that will normalize URLs.

The changes are mechanical but important - they touch nearly every test case in t5710-promisor-remote-capability.sh to replace direct `file://$(pwd)` usage with the new helpers. The patch maintains all existing test behavior while making the URI handling more robust. This is a clean conclusion to the series, addressing a subtle platform-specific issue that could have caused problems with future URL normalization work. The changes are well-contained to the test script and don't affect production code.
