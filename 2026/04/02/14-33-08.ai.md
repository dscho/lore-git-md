This is the second patch in Johannes Schindelin's 17-part test modernization series preparing for Git's potential default behavior change regarding bare repository discovery. The patch updates the `check_config` helper function in t0001-init.sh to use explicit `--git-dir` instead of relying on implicit bare repo discovery via `cd`.

The change replaces two `cd`-and-`git` command sequences with direct `git --git-dir` invocations, maintaining the same functionality while removing the implicit bare repo discovery that may be disabled by default in future Git versions. The modification is straightforward and follows the pattern established in the first patch of the series - using explicit repository specification rather than relying on Git's current implicit behavior.

This continues the series' mechanical but important updates to make tests robust against the anticipated `safe.bareRepository=explicit` default. The patch is small, focused, and clearly motivated by the larger effort to future-proof the test suite. As with the rest of the series, this change is unlikely to be controversial and demonstrates Johannes Schindelin's characteristic attention to test infrastructure and Windows compatibility concerns.
