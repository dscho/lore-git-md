This is patch 4/7 in a feature series that refactors Git's object database write operations as part of the ongoing ODB abstraction effort. The patch removes conditional behavior from packfile writes by splitting the functionality of `index_blob_packfile_transaction()` into two distinct paths: one that just hashes the object (`hash_blob_stream()`) and another that unconditionally writes to the packfile.

The change makes the write operation non-optional by removing the `INDEX_WRITE_OBJECT` flag check, which simplifies the interface in preparation for integrating these writes into the transaction system. The patch introduces new helper functions in `odb/streaming.h` for stream initialization and cleanup, and moves some logic from `object-file.c` to the new streaming interface.

Patrick Steinhardt has reviewed and approved this change in previous iterations. The patch appears well-structured and focused, with clear commit message explaining the motivation. This is a technical but important step in the larger ODB abstraction work that will enable more flexible storage backends.
