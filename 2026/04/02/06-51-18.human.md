This is a test infrastructure patch addressing a Dash shell bug affecting Git's test suite. Patrick Steinhardt's v2 patch updates his earlier workaround for Dash v0.5.13's multibyte character handling in heredocs, now adding explanatory comments at each modified heredoc site as suggested by Eric Sunshine.

The patch fixes test failures that occur when multibyte characters (like "perú" or "濱野純") appear in quoted heredocs, where Dash incorrectly wraps the bytes with CTLMBCHAR sequences. The solution is to use unquoted heredocs instead, which Dash handles correctly. The changes affect several test files including credential handling, rebase, quoting, format-patch, shortlog, and send-email tests.

Each modified heredoc now includes a comment explaining why quoting is avoided, making the workaround more maintainable. The patch demonstrates careful attention to both the technical fix and documentation needs, showing the kind of thoroughness expected from a core contributor like Patrick Steinhardt. With the added comments addressing the previous round of feedback, this appears ready for inclusion.
