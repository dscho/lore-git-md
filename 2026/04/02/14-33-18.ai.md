This is the twelfth patch in Johannes Schindelin's test modernization series preparing for Git's potential default behavior change regarding bare repository discovery. The patch updates t5540 and t5541 by modifying their shared test helper in t/lib-httpd.sh to explicitly specify bare repository locations rather than relying on implicit discovery via `-C`.

The changes replace several instances where tests were changing directory into a bare repository and running Git commands, instead using `--git-dir` to directly target the repository. Key modifications include:
- Converting `cd $REMOTE_REPO && git rev-parse` to `git --git-dir=. rev-parse` when inside subshells
- Using `git --git-dir="$REMOTE_REPO"` for one-shot commands outside subshells
- Updating a force-with-lease test to avoid directory changes entirely

The patch follows the established pattern from earlier in the series, making bare repository access explicit while maintaining the same test semantics. This continues the mechanical but thorough approach seen in previous patches, now addressing HTTP push tests. The changes are straightforward and unlikely to be controversial, keeping with the series' goal of proactively updating tests before a potential backward-incompatible change in Git's bare repository handling.
