This is a feature patch improving Git's graph rendering for repositories with multiple root commits. The patch addresses an issue where unrelated root commits appear vertically aligned in `git log --graph` output, making them look connected when they're not.

Pablo Sabater proposes adding indentation for commits that follow root commits by introducing a "placeholder column" concept. This keeps the root commit's column occupied for an extra row, forcing subsequent unrelated commits to appear in their own column. The change makes the graph visually clearer by preventing misleading vertical alignment of unrelated roots.

The patch modifies the graph rendering engine to:
1. Track placeholder columns with a new `is_placeholder` flag
2. Maintain proper spacing through the commit line drawing functions
3. Handle various edge cases including multi-parent merges

Several test cases demonstrate the improvement, showing how the new rendering better distinguishes between unrelated root commits and their descendants. The change was motivated by feedback from Junio Hamano about confusing graph output in repositories with multiple roots.
