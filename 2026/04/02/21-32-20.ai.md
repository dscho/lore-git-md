This is the final patch in a 7-part feature series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes object writing pluggable by introducing a `write_object_stream()` callback in `struct odb_transaction`, allowing different ODB backends to implement their own write strategies.

The main changes rename `index_blob_packfile_transaction()` to the more descriptive `odb_transaction_files_write_object_stream()` and wire it up as the default implementation for the new callback. The patch also adds the public `odb_transaction_write_object_stream()` wrapper function that routes calls through the transaction's callback. These changes affect core object-file handling in commands like `git add` and `git update-index`.

With this patch, the series achieves its goal of making ODB writes explicitly use the transaction interface rather than implicit redirection. The work has been reviewed by Patrick Steinhardt and appears technically sound, marking a key milestone in the broader ODB abstraction effort. The changes are well-contained, touching only object-file.c and the odb/transaction.{c,h} files while maintaining all existing functionality.

For future reference: The patch introduces `write_object_stream` callback in `odb_transaction` struct, renames the packfile implementation to `odb_transaction_files_write_object_stream`, and adds the public wrapper `odb_transaction_write_object_stream()`. This completes the write interface foundation for future storage backends.
