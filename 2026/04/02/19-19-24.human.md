This is a performance optimization patch in Phillip Wood's series to reduce memory usage in xdiff's diff algorithm. Junio C Hamano provides a detailed review of the first patch, which shrinks temporary arrays used during diff calculation to only cover the non-common portions of files rather than the entire file size.

Junio confirms the technical approach is sound, walking through how the patch:
1. Reduces array sizes using new `len1`/`len2` variables
2. Maintains correct indexing via the `off` offset
3. Updates bounds passed to helper functions like `xdl_clean_mmatch()`

The review notes one minor typo ("As as") but otherwise finds the changes mechanically sound. Junio's analysis shows the patch achieves its goal of reducing memory usage without changing diff results, while carefully preserving the correct indexing into the original data structures. This continues Phillip Wood's established pattern of focused xdiff optimizations.
