This is the final patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch makes object writing pluggable by introducing a `write_object_stream()` callback in `struct odb_transaction`, allowing different ODB backends to implement their own write strategies.

The key change renames `index_blob_packfile_transaction()` to the more descriptive `odb_transaction_files_write_object_stream()` and wires it up as the default implementation for the files backend. The patch also adds a wrapper function `odb_transaction_write_object_stream()` to provide a clean interface for callers.

This completes the technical foundation for streaming object data into transactions, which has been carefully reviewed by Patrick Steinhardt across multiple iterations. The changes affect core object-file handling in commands like `git add` and `git update-index`. With this series, the ODB abstraction effort reaches an important milestone in making write operations consistently interface-driven rather than implementation-specific.
