This thread concerns a documentation update to clarify the status of the reftable format in preparation for Git 3.0. brian m. carlson originally proposed removing the "experimental" label from reftable (now considered stable) and clarifying that it will become the default ref storage format when the `with-breaking-changes` mode is enabled. The changes affect `Documentation/ref-storage-format.adoc` but don't require any code modifications.

Patrick Steinhardt, a key contributor to the reftable backend work, has acknowledged the changes with a simple ack, signaling consensus on these documentation updates. With this approval from a domain expert, the patch appears ready to proceed without further discussion. The thread remains focused and uncontroversial, serving as a small but important piece of the broader Git 3.0 transition effort where reftable adoption is planned.
