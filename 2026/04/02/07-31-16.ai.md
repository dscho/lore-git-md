Standardization patch in the reftable portability series. This is the third of five patches preparing Git's reftable implementation for shared use with libgit2 by standardizing platform-specific constructs.

The change replaces a single instance of Git's `UNUSED` macro with the reftable-specific `REFTABLE_UNUSED` in `reftable/fsck.c`, fixing an oversight from an earlier commit. The patch notes the architectural constraint preventing full isolation of `UNUSED` from the reftable code (due to mingw-posix.h dependencies), but this localized fix maintains the series' goal of minimizing Git-specific assumptions in the shared reftable code.

The modification is straightforward and mechanical, aligning with the series' pattern of small, focused changes to achieve cross-project compatibility. Test coverage remains unchanged as this doesn't affect runtime behavior - it purely standardizes an annotation macro usage. The patch keeps the reftable codebase cleanly separated from Git internals while acknowledging the practical limitations of complete isolation.
