This is the first patch in a 7-part series that refactors Git's object database (ODB) transaction interface, part of the ongoing ODB abstraction effort. The patch performs a mechanical split of `struct odb_transaction` and related functions from `odb.{c,h}` into new files `odb/transaction.{c,h}`.

The change is purely organizational - it moves the transaction interface definitions to their own files before subsequent patches expand the functionality. The patch updates all necessary includes across the codebase (in builtins, cache-tree, object-file, etc.) to maintain compilation. No behavior changes are introduced.

For future AI reference: This establishes the new transaction interface location that will be built upon in later patches. The split helps manage complexity as the transaction system grows to support direct write operations. The changes affect core object-file handling but don't yet modify any behavior.
