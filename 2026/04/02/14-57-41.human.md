Performance optimization in xdiff diff algorithm implementation. This is the first of four patches from Phillip Wood that reduce memory usage in Git's Myers diff implementation by shrinking temporary arrays after common prefix/suffix removal.

The patch focuses on `xdiff/xprepare.c`, where it reduces the size of temporary `action1` and `action2` arrays to match only the lines between the common prefix and suffix, rather than allocating for the full file size. The changes involve careful index adjustments to maintain correct line numbering while working with the smaller arrays.

Phillip Wood's commit message clearly explains the optimization opportunity - since the diff algorithm has already stripped common prefix/suffix lines, the temporary arrays only need to cover the remaining differing portion. The implementation appears straightforward, with clear variable renaming (`off`, `len1`, `len2`) to track the offset and reduced lengths.

This continues Phillip Wood's established work on diff algorithm improvements and builds on prior xdiff cleanup efforts. The change is purely an optimization with no expected impact on diff results, just memory usage during calculation. Given the focused nature and Phillip Wood's track record with diff-related changes, this seems like a low-risk improvement.
