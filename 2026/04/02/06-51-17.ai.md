This is a test infrastructure patch series addressing compatibility issues with Dash shell v0.5.13. Patrick Steinhardt's v2 series builds on the previous version by adding explanatory comments to heredocs that were modified to work around Dash bugs.

The series handles two specific Dash issues: a multibyte character handling bug in heredocs (still present in Dash master) and a partial read bug (fixed upstream in v0.5.13.2). The first patch now includes comments at each modified heredoc site explaining why quoting is avoided, addressing Eric Sunshine's feedback about documenting the workarounds. The second patch remains unchanged, fixing t9300-fast-import.sh to avoid hangs from Dash's partial read bug.

The changes are mechanical test adjustments affecting credential handling, rebase, quoting, format-patch, shortlog, send-email, and fast-import tests. The series demonstrates careful attention to both technical correctness and maintainability, with clear documentation of the shell-specific workarounds. The Dash maintainer remains CC'd for awareness. This appears ready for inclusion as it provides robust solutions for both test failures while properly documenting the non-obvious heredoc modifications.
