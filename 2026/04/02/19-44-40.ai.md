Performance optimization completing Phillip Wood's xdiff memory reduction series. This is the final patch in a four-part set that Junio C Hamano has reviewed and approved throughout. The change moves allocation of `reference_index` arrays in `xdiff/xprepare.c` to `xdl_cleanup_records()` where the actual needed size (post prefix/suffix removal) is known, shrinking these arrays from full-file size to just the count of lines processed by the Myers diff algorithm.

Junio's review confirms the technical soundness - the arrays were already being accessed correctly from index 0, so this change simply eliminates wasted space at the end. He notes the allocation size (`len1`/`len2`) is appropriate since the arrays grow by at most one element per iteration during processing. The patch follows the same pattern as earlier in the series: mechanical memory optimizations with no impact on diff results.
