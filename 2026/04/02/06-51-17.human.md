This is a test infrastructure patch series addressing compatibility issues with Dash shell v0.5.13. Patrick Steinhardt follows up on his initial version by adding explanatory comments to the heredoc workarounds, responding to Eric Sunshine's review feedback.

The series remains focused on two specific Dash bugs: incorrect handling of multibyte characters in heredocs (still present in Dash master) and partial reads (fixed upstream in v0.5.13.2). The v2 changes add clear "NOTE" comments at each modified heredoc site explaining why the heredoc must remain unquoted, addressing the maintainability concern while keeping the technical fix minimal.

The patches modify test scripts across several areas (credentials, rebase, quoting, format-patch, shortlog, send-email, and fast-import) to work around these Dash issues. The changes are mechanical and well-contained, with no impact on production code. The Dash maintainer remains CC'd for awareness.

This version demonstrates good responsiveness to review feedback while maintaining the series' original purpose - making Git's tests robust against known shell bugs. The added documentation makes the workarounds more maintainable while keeping the changes focused. The series appears ready for inclusion.
