This is patch 4/7 in a feature series refactoring Git's object database write operations as part of the ongoing ODB abstraction effort. Justin Tobler continues the work to make ODB writes explicitly use the transaction interface rather than implicit redirection.

The patch splits blob object handling into two distinct paths: `hash_blob_stream()` for pure hash computation and `index_blob_packfile_transaction()` for actual packfile writing. This removes the conditional `INDEX_WRITE_OBJECT` flag check that previously controlled both operations, making the packfile write path unconditional since it will soon become part of the transaction interface. The changes affect core object-file handling in commands like `git add` and `git update-index`.

Key technical changes include:
- New `hash_blob_stream()` helper in object-file.c for pure hash computation
- Removal of `INDEX_WRITE_OBJECT` flag checks from packfile writing path
- Introduction of `odb_write_stream_from_fd()` and `odb_write_stream_release()` in odb/streaming.[ch]
- Streamlined packfile writing logic in `index_blob_packfile_transaction()`

The patch builds on Patrick Steinhardt's prior review feedback and appears to complete the technical changes needed for this part of the series. With the interface now clearly separating hash computation from actual writing, the groundwork is laid for the remaining patches to integrate this with the transaction system.
