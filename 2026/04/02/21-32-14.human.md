Refactoring patch as part of the ODB abstraction effort.

This is the first patch in a 7-part series that completes the write operations interface for Git's object database transactions. Justin Tobler splits out `struct odb_transaction` and related functions from the general ODB interface into new dedicated files `odb/transaction.{c,h}`. The change is purely organizational - no behavior is altered - to prepare for expanding the transaction interface in subsequent patches.

The patch moves the transaction definitions and implements the same functions in the new location, updating all necessary includes across the codebase. This is a straightforward code reorganization that has already been reviewed and approved by Patrick Steinhardt as part of the larger series. The change affects several commands that use ODB transactions (`git add`, `git update-index`, `git unpack-objects`) but only at the include level.
