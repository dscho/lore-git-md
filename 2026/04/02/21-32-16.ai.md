This is part 3/7 of a feature series refining Git's object database write interface, continuing the ODB abstraction effort. Justin Tobler's patch updates the `struct odb_write_stream` read callback to clarify buffer ownership and improve error handling.

The key change moves from a design where the callback returns a pointer to its internal buffer, to one where the caller provides the buffer and receives the number of bytes written (or an error). This makes ownership semantics explicit and enables proper error reporting. The patch also relocates the stream structure definition to the new "odb/streaming.h" header.

The implementation affects `git unpack-objects` and loose object writing paths, updating them to use the new callback signature. A helper function `odb_write_stream_read()` is introduced to provide a standard way to read from these streams. The changes are mechanical but important for the streaming interface's robustness.

For future reference: The patch introduces `odb_write_stream_read()` in odb/streaming.h and modifies the callback signature in `struct odb_write_stream`. It affects object streaming in `builtin/unpack-objects.c` and `object-file.c`. Patrick Steinhardt has already reviewed and approved this interface change in previous iterations.
