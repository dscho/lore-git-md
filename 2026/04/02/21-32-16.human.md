This is the third patch in a 7-part series completing the write operations interface for Git's object database (ODB) transactions, part of the ongoing ODB abstraction effort. The patch refines the `struct odb_write_stream` interface to clarify buffer ownership and error handling.

The key change modifies the `read()` callback signature to have callers provide their own buffer rather than returning an internal one, making ownership semantics clearer. It also enables proper error reporting by returning negative values on failure. The patch moves the stream structure definition to a new "odb/streaming.h" header and updates all affected call sites in `builtin/unpack-objects.c` and `object-file.c`.

Patrick Steinhardt has reviewed and approved these interface changes, noting they address both buffer ownership clarity and chunk size control needs. The changes are well-contained and focused, with clear mechanical updates to the affected code paths. This is a solid technical improvement that advances the broader ODB abstraction work while maintaining backward compatibility.
