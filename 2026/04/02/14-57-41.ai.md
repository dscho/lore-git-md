Performance optimization patch 1/4 in Phillip Wood's series to reduce memory usage in xdiff's Myers algorithm implementation. This first patch focuses on shrinking the action arrays used during diff calculation.

The key change is adjusting the size of temporary `action1` and `action2` arrays to match only the post-prefix/suffix line counts rather than the full file size. The patch introduces new `len1` and `len2` variables to track the reduced size and carefully maintains correct indexing into the original xdfile_t structures by using an offset. The changes are localized to `xdl_cleanup_records()` in `xdiff/xprepare.c` and include:

1. Calculating the reduced array sizes based on `dstart` and `dend` (which mark the post-prefix/suffix region)
2. Adjusting all array accesses to use the new offset-based indexing
3. Updating the bounds passed to `xdl_clean_mmatch()` to match the new array sizes

The commit message clearly explains the optimization opportunity (arrays only need to cover the non-common portion of files) and the technical approach. The changes are mechanical and focused, with no expected impact on diff results - only memory usage during calculation. This continues the pattern of incremental xdiff optimizations from Phillip Wood, who has established credibility in this area.
