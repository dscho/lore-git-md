Performance optimization in the ODB abstraction effort, part 6/7 of a series to standardize write operations. This patch refactors packfile blob writing to use the new `odb_write_stream` interface rather than direct file descriptors, completing the transition to a more flexible streaming model.

The change replaces the fd-based `stream_blob_to_pack()` implementation with one that operates on the abstract stream interface, while maintaining all existing functionality. Key technical changes include:
- Removing direct file descriptor handling from `stream_blob_to_pack()`
- Adding proper error checking for stream read operations
- Updating callers to pass the stream rather than fd/path
- Ensuring accurate byte counting during streaming

The patch affects core object writing paths used by commands like `git add` and `git update-index`. As with previous patches in this series, Patrick Steinhardt has reviewed and approved the changes. This is a well-executed technical refactoring that moves Git closer to supporting pluggable object storage backends while maintaining performance. The series appears ready for merging.
