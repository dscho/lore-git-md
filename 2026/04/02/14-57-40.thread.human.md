The changes are mechanical improvements to reduce dynamically allocated array sizes without altering diff results, continuing Phillip's established pattern of xdiff optimizations.

Each patch in the series progressively refactors how xdiff handles memory allocation: first adjusting action arrays to use precise sizes, then simplifying related functions, consolidating error handling, and finally moving array allocations to where the exact needed size is known.
