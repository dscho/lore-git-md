Thread identity: RFC patch series from Pablo Sabater proposing improvements to Git's graph rendering engine for multiple root commits and commits with excluded parents in `git log --graph` output.

Core problem: Current graph rendering vertically aligns commits whose parents are excluded from display (including root commits and commits with parents outside the displayed range), creating misleading visual implications of parent-child relationships between unrelated commit lineages. The proposal aims to properly indent subsequent commits by keeping such commits "alive" via a placeholder mechanism that handles both true root commits and commits with excluded parents uniformly.

Technical details: Introduces `is_placeholder` flag to graph columns and modifies graph.c rendering logic, with test cases in t4202-log.sh covering multiple root scenarios and complex merges. Files touched: graph.c, graph.h, t/t4202-log.sh. The solution must now handle both true root commits and commits with parents outside the displayed range (C..Z) through a unified "seems_root" concept rather than checking actual root status.

Current status: Discussion has refined the problem scope beyond the initial RFC. Junio C Hamano clarified the solution must handle all commits with excluded parents, not just root commits. Author Pablo Sabater acknowledges this and demonstrates how the initial root-focused approach would fail for non-root commits with excluded parents (like commit A in O---A when displaying O..A Y). The placeholder mechanism needs adjustment to treat both cases uniformly, possibly introducing some artificial spacing to maintain clear commit relationships.

Open questions: Whether the adjusted placeholder approach optimally handles both root commits and commits with excluded parents through the "seems_root" concept, correctness of indentation logic for both cases, and whether to address diagonal line artifacts in this series. The discussion reveals subtle visual tradeoffs where perfect alignment may require artificial spacing to maintain clear commit relationships.
