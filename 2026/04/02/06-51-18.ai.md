This is a test infrastructure patch addressing a Dash shell compatibility issue with multibyte characters in heredocs. Patrick Steinhardt's v2 patch builds on the previous version by adding explanatory comments to each modified heredoc, implementing Eric Sunshine's suggestion from the v1 review.

The patch works around a specific bug in Dash v0.5.13 where quoted heredocs containing multibyte characters (like "perú") get corrupted with extra CTLMBCHAR byte sequences. The fix converts affected heredocs to unquoted form across several test files (credentials, rebase, quoting, format-patch, shortlog, send-email). Each modification now includes a comment explaining the workaround to prevent accidental reversion.

The changes are mechanical and well-scoped, touching only test files that demonstrated the issue. The patch demonstrates careful attention to both the technical fix and long-term maintainability by documenting the non-obvious workarounds. With the added comments addressing the v1 feedback, this appears ready for inclusion as it provides a complete solution to the test failures while properly documenting the shell-specific quirks.
