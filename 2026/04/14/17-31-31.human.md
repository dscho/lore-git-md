This is a security release announcement for Git for Windows, which is a separate project from the main Git codebase. Johannes Schindelin announces version 2.53.0(3), a security update addressing CVE-2026-32631.

The vulnerability involves a security flaw where Git for Windows would follow symbolic links pointing to network drives during clone operations, potentially exposing users' NTLMv2 hashes to malicious servers. This could allow attackers to attempt credential recovery through brute-force attacks. The fix prevents Git from following such network drive symlinks during checkout.

The announcement includes SHA-256 checksums for various distribution formats (installers, portable versions, and MinGit variants) across different architectures (64-bit, arm64, and 32-bit). This is a targeted security update rather than a feature release, with the changes focused specifically on addressing the identified vulnerability.
