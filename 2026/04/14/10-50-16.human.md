This is the first patch in the v11 series implementing unified conflict resolution in `git checkout -m`. The patch adds customizable conflict marker labels to `git stash apply` through new `--label-ours`, `--label-theirs`, and `--label-base` options. These options allow users to override the default conflict marker labels ("Updated upstream", "Stashed changes", and "Stash base") with custom text, including empty strings if desired.

The implementation modifies `builtin/stash.c` to pass the labels through to the merge machinery, updates the documentation, and adds two new test cases verifying the functionality - one for custom labels and another for empty labels. The changes are straightforward and well-contained, touching only the stash command while preparing infrastructure that will be used by the subsequent checkout autostash patches in the series.

This patch has already undergone extensive review across 11 iterations, with all technical concerns addressed. The implementation is clean and the test coverage is thorough, including edge cases like empty labels. The changes maintain backward compatibility while providing useful new flexibility for conflict resolution workflows. As part of the larger approved series, this patch is ready for merging.
