This is a follow-up discussion in the feature series implementing autostash behavior for `git checkout -m`, which has already been merged into the `next` integration branch. The series enhances branch switching conflict resolution by integrating autostash functionality while maintaining backward compatibility.

Junio Hamano responds to Harald Nordgren's suggestion about the autostash message format. While Harald proposed showing only the source branch (e.g. "autostash from master"), Junio argues that including both source and destination branches (e.g. "autostash while switching from 'master' to 'topic'") provides better context for his workflow. He notes that since he typically performs these operations while on 'master' or 'next', seeing just "autostash on master" would be as unhelpful as the current generic messages.

The maintainer indicates this is a minor UX polish point that can be addressed separately after users have had time to experience the core functionality. The series remains in good standing in `next`, with this discussion representing final refinements rather than blocking issues. Junio's perspective reflects the project's iterative approach - establishing solid core functionality first, then refining user experience based on real-world usage.
