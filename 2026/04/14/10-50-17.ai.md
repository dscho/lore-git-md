This is a technical patch in the v11 series implementing silent autostash creation during branch switching conflicts. The patch adds a new `create_autostash_ref_silent()` function to the sequencer, allowing callers to stash changes without printing the "Created autostash" message. This builds on the earlier work to integrate autostash behavior into `git checkout -m`.

The implementation modifies `create_autostash_internal()` to accept a `silent` parameter, then exposes this through a new public function while maintaining the existing behavior of the non-silent variants. The change is straightforward - it simply conditionally skips the printf when `silent` is true. The patch includes the necessary header declaration and updates both the internal implementation and public interface.

This is part of the larger effort to make branch switching with uncommitted changes more robust by automatically stashing changes when conflicts would otherwise prevent the operation. The silent variant will be used by `git checkout -m` to avoid cluttering output during automated conflict resolution scenarios. All technical concerns about the approach were resolved in earlier iterations, and this patch represents final polishing of the implementation details.
