This is part 2 of a 4-patch series that enhances `git checkout -m` with autostash behavior during branch switching conflicts. The series has already gone through extensive review and is now in its 12th iteration, with maintainer approval pending only minor naming refinements.

The current patch adds silent autostash creation capability to the sequencer, allowing operations like branch switching to stash changes without printing the usual "Created autostash" message. It introduces a new `create_autostash_ref_with_msg_silent()` function that builds on the existing autostash infrastructure while adding parameters for both custom messages and silent operation. The implementation maintains backward compatibility with existing callers while providing the new functionality needed for the `git checkout -m` integration.

Key technical changes include:
- Adding `silent` and `message` parameters to the internal `create_autostash_internal()` function
- Only printing the autostash creation message when not in silent mode
- Allowing custom stash messages (defaulting to "autostash" if none provided)
- Exposing the new functionality through `create_autostash_ref_with_msg_silent()` in sequencer.h

The patch is well-contained and follows the established pattern of the series, which has already addressed all substantive technical feedback in previous iterations. With this change, the autostash machinery gains the flexibility needed for the branch switching use case while keeping the existing behavior for other callers.
