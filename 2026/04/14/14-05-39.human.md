This is a review comment on patch 1/4 of a feature series implementing unified conflict resolution in `git checkout -m` with autostash behavior. Phillip Wood provides feedback on the implementation details while generally approving the approach.

The patch adds customizable conflict marker labels to `git stash apply` via new `--label-ours`, `--label-theirs`, and `--label-base` options, which will be used by the autostash functionality in later patches. Phillip suggests two improvements: (1) modifying the existing `do_apply_stash()` function directly rather than adding a new wrapper function, since there are only four callers, and (2) avoiding the creation of new repositories in the test cases to improve test suite performance.

The review indicates the series is nearing completion, with this being a minor optimization suggestion rather than a blocking concern. The core functionality - allowing custom labels for conflict markers including empty strings - is sound and well-tested, with Phillip noting "everything else looks good to me." This feedback comes after 12 iterations of the series, showing the patch is quite mature.
