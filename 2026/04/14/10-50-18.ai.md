This is the third patch in a v11 series implementing autostash improvements for `git checkout -m`. The patch adds support for optional conflict marker labels when applying stashes through the sequencer's autostash machinery.

The key technical change is the introduction of new parameters (`label_ours`, `label_theirs`, `label_base`) to several internal autostash functions, allowing callers to customize conflict marker labels during stash application. A new public function `apply_autostash_ref_with_labels()` is exposed in sequencer.h for callers that need this functionality. The implementation builds on the existing `git stash apply --label-*` options added earlier in the series.

The patch modifies the sequencer's autostash handling to pass these labels through to the underlying stash application. It maintains backward compatibility by keeping the existing functions that don't take labels, now implemented as wrappers that pass NULL for all label parameters. The changes are focused in sequencer.c with corresponding updates to sequencer.h's public API.

This is a well-contained change that completes the label support functionality for the autostash feature. The implementation follows the pattern of the rest of the series, with careful attention to maintaining the existing behavior when labels aren't specified. The patch has already been through multiple rounds of review and is part of a series that maintainer Junio Hamano has approved for merging.
