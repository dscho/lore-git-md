Git for Windows 2.54.0-rc2 release announcement by Johannes Schindelin, tracking Git 2.54.0-rc2. Key changes: removal of `git svn` from distribution due to maintenance burden (users directed to WSL/MSYS2 alternatives), updates to bundled components (Bash 5.3.9, Git Credential Manager 2.7.2, MinTTY 3.8.2). Windows-specific fixes include: character input ordering in Git Bash, NTFS junction handling in `git worktree remove`, multi-socket CPU core detection, TLS/SSL and authentication (NTLM/Kerberos) security updates. Provides SHA-256 checksums for installers/portable versions (64-bit, ARM64, 32-bit). Note this is a Git for Windows release, not an upstream Git release.
