This is a test modernization patch from Siddharth Shrimali, part of a series improving t7004-tag.sh. The patch removes brittle tag count checks that made the test dependent on the exact number of tags from previous tests. 

The change follows Junio Hamano's suggestion to eliminate redundant verification - since `test_must_fail` already confirms the invalid tags are rejected, counting tags before/after adds no value while making the test fragile. The patch simplifies the test by removing these checks, reducing the file by 5 lines while maintaining the same validation of invalid tag names.

This appears to be a straightforward improvement to test robustness, cleanly addressing the identified issue. The change is small and focused, exactly matching the pattern of test modernization work seen elsewhere in the project.
