Git for Windows maintainer Johannes Schindelin has announced version 2.53.0(3), a security update addressing CVE-2026-32631. This Windows-specific vulnerability could expose users' NTLMv2 hashes when cloning repositories containing symbolic links pointing to network drives. The fix prevents Git for Windows from following such symlinks during checkout operations.

The release includes patched installers, portable versions, and MinGit variants for 64-bit, arm64, and 32-bit architectures, with SHA-256 checksums provided for verification. While this release tracks the upstream Git version 2.53.0, the security fix is specific to Windows' handling of symbolic links and NTLM authentication, so it doesn't affect other platforms. Users of Git for Windows should upgrade to this version to mitigate the security risk.
