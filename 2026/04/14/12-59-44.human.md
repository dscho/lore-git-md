This is the third patch in a 12-part series implementing autostash behavior for `git checkout -m` during branch switching conflicts. The series has already undergone extensive review and is now in its final polishing stage.

The patch extends the sequencer's autostash machinery to support customizable conflict marker labels when applying stashed changes. It adds new parameters (`label_ours`, `label_theirs`, `label_base`) to internal functions and introduces a new public API function `apply_autostash_ref_with_labels()` that callers can use to specify these labels. The implementation maintains backward compatibility by keeping the existing functions that pass NULL for the label parameters.

The changes are straightforward plumbing work that builds on the previous patches in the series. The patch follows Git's established patterns for handling similar configuration options elsewhere in the codebase. With this addition, the series now fully support the label customization feature that was part of the original design.
