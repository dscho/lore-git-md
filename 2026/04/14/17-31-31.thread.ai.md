Git for Windows security release announcement (not part of main Git project). Johannes Schindelin announces version 2.53.0(3) of the Windows-specific fork, addressing CVE-2026-32631 - a security vulnerability where Git for Windows followed symbolic links pointing to network drives during clone operations, potentially exposing NTLMv2 hashes. The fix prevents following such symlinks during checkout. Release includes SHA-256 checksums for installers, portable versions, and MinGit variants across 64-bit, arm64, and 32-bit architectures. Version tracks upstream Git 2.53.0 but uses Windows-specific versioning (2.53.0(3)). Issue is Windows-specific, not affecting other platforms.
