This is the first patch in a feature series (v12) that adds customizable conflict marker labels to `git stash apply`. The patch introduces three new options: `--label-ours`, `--label-theirs`, and `--label-base`, allowing users to specify custom labels for conflict markers instead of the default "Updated upstream", "Stashed changes", and "Stash base".

The implementation adds a new `do_apply_stash_with_labels()` function that wraps the existing apply logic while accepting the new label parameters. The labels are passed through to the merge machinery, with empty strings allowed to produce unlabeled markers. The patch includes comprehensive documentation updates and two new test cases verifying the custom label functionality works as expected, including support for empty labels.

This change builds on Git's existing conflict marker infrastructure while providing more control over how stashed changes are presented during conflicts. The patch is well-tested and follows the established pattern of the series, which has already undergone extensive review and is ready for merging. The functionality will be particularly useful for scripts and tools that need consistent labeling when applying stashes programmatically.
