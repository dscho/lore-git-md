This is part 2 of a 4-patch series implementing silent autostash creation during branch switching conflicts. The series has already gone through extensive review and is in its 12th iteration, with this version making final naming refinements.

The patch modifies the sequencer's autostash internals to support silent operation, adding a new `create_autostash_ref_with_msg_silent()` function that suppresses the "Created autostash" message while allowing a custom message. The changes are straightforward:
- Adds `message` and `silent` parameters to `create_autostash_internal()`
- Introduces the new public function with the final name requested by Junio
- Maintains backward compatibility for existing callers
- Preserves all existing functionality while adding the silent option

The implementation is clean and focused, touching only the necessary parts of `sequencer.c` and its header. This is a technical building block for the larger feature that will be used by the `git checkout -m` integration in later patches. With the naming now finalized per maintainer feedback, this series appears ready for merging.
