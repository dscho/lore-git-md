This is a security release announcement for Git for Windows, not to be confused with the main Git project. Johannes Schindelin announces Git for Windows 2.53.0(3), a security-focused update to the Windows-specific fork of Git.

The release addresses CVE-2026-32631, a vulnerability where Git for Windows would follow symbolic links pointing to network drives during clone operations, potentially exposing users' NTLMv2 hashes to malicious servers. The fix prevents Git from following such symlinks during checkout, closing the security hole. The announcement includes SHA-256 checksums for various distribution formats (installers, portable versions, MinGit variants) across different architectures (64-bit, arm64, 32-bit).

As this is a Git for Windows release rather than an upstream Git patch, it follows its own versioning scheme (2.53.0(3)) while tracking the upstream Git version (2.53.0). The security fix appears specific to Windows' handling of symbolic links and NTLM authentication, which doesn't affect other platforms.
