This is the third patch in a v11 series implementing autostash improvements for `git checkout -m`. The series has already received extensive review and maintainer approval, with this version making final refinements.

The patch extends the sequencer's autostash machinery to support optional conflict marker labels when applying stashes. It adds new parameters `label_ours`, `label_theirs`, and `label_base` to several internal functions, and introduces a new public function `apply_autostash_ref_with_labels()` that callers can use to pass custom labels through to `git stash apply`. The implementation maintains backward compatibility by keeping the existing functions that don't take labels.

The changes are straightforward plumbing to connect the label functionality that was added to `git stash apply` in this series. The patch follows the established pattern of the surrounding code and includes the necessary updates to pass labels through the call chain. With this change, callers like `git checkout -m` can now specify custom labels for conflict markers when automatically applying stashes during branch switching conflicts.

This is a well-contained technical change that completes the label support for the autostash feature. The patch is part of a polished series that has already addressed all review feedback and is ready for merging.
