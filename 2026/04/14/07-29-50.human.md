The maintainer Junio Hamano had suggested improving the autostash message by including the destination branch name (e.g. "autostash while switching to 'topic'") as a final UX enhancement. 

Author Harald Nordgren responds with a counter-suggestion, proposing instead to show the source branch name ("autostash from master") since the changes could still be applied elsewhere if the merge is aborted. This is a minor refinement discussion about message wording - the core functionality is already solid and approved for merging. 

The exchange shows thoughtful consideration of user experience details even after technical approval, with both perspectives making reasonable cases about which branch context would be most helpful in the autostash message. Since this doesn't affect the implementation and was flagged as non-blocking by Junio, it's likely to be resolved with either approach in a follow-up patch if the author chooses to implement it.
