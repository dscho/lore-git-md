Git v2.54.0-rc2 release candidate announcement, second preview of upcoming Git 2.54.0 version. Contains 744 non-merge commits from 127 contributors (64 new). Notable changes since rc1 include reverting writev() series due to portability issues and now a MIDX version 2 compatibility problem reported by Johannes Schindelin. The MIDX version bump (commit b2ec8e90) breaks backward compatibility with Git v2.53.0, making repositories touched by v2.54.0-rc2 unusable with the previous stable version - contrary to the commit's claim that older versions would "gracefully degrade". This affects downgrade scenarios, mixed-version environments (including GitHub Desktop), and interoperability with libgit2/JGit. Junio Hamano has engaged Taylor Blau (MIDX expert) to provide recovery instructions, suggesting deleting `.git/objects/pack/*.midx` files as a potential workaround. Key areas: new experimental `git history` command for history rewriting, `git replay` improvements (empty commit handling), enhanced hook/alias configuration, pack handling optimizations (with MIDX compatibility concern), continued `the_repository` removal progress, Rust infrastructure work for object handling. Fixes address HTTP auth, diff stat with non-ASCII paths, submodule edge cases, ref transactions. Release notes organized into UI/workflow, performance/internal, fixes since v2.53.0 sections. Junio is carefully curating changes and reverting problematic patches, with the MIDX compatibility issue now a critical blocker requiring resolution before final release.
