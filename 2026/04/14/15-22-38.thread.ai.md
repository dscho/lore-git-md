Git v2.54.0-rc2 release candidate announcement, second preview of upcoming Git 2.54.0 version. Contains 744 non-merge commits from 127 contributors (64 new). Notable changes since rc1 include reverting writev() series due to portability issues. Key areas: new experimental `git history` command for history rewriting, `git replay` improvements (empty commit handling), enhanced hook/alias configuration, pack handling optimizations, continued `the_repository` removal progress, Rust infrastructure work for object handling. Fixes address HTTP auth, diff stat with non-ASCII paths, submodule edge cases, ref transactions. Release notes organized into UI/workflow, performance/internal, fixes since v2.53.0 sections. Junio Hamano curating changes carefully, reverting problematic patches. On track for final release in coming week barring last-minute issues.
