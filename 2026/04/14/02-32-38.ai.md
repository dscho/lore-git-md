This is Junio C Hamano's "What's cooking" report for April 2026, providing a status update on various Git development topics. The report covers new topics that have been introduced, topics that have graduated to 'master', and ongoing work still in progress.

Several notable topics are progressing:

1. The ongoing `the_repository` removal effort continues with patches reducing its use in the refs subsystem (sp/refs-reduce-the-repository and sp/refs-with-less-the-repository). These are part of the long-term project to eliminate this global variable.

2. Patrick Steinhardt is working on an "in-memory" ODB source (ps/odb-in-memory), which would hold tentative objects like those used by `git blame`. This builds on Justin Tobler's ODB transaction work (jt/odb-transaction-write).

3. The test suite is being made more robust with `set -e` support (ps/test-set-e-clean), fixing potential issues when tests fail unexpectedly.

4. Documentation updates include timestamp handling guidelines (jc/doc-timestamps-in-stat) and man page formatting improvements (ja/doc-difftool-synopsis-style).

Several topics have recently graduated to 'master', including:
- Optimizations for `rev-list --maximal-only` (ds/rev-list-maximal-only-optim)
- Reftable portability improvements (ps/reftable-portability)
- ODB subsystem cleanups (ps/odb-cleanup)
- A fix for cache-tree validation logic (dl/cache-tree-fully-valid-fix)

The report also notes many ongoing efforts like:
- Parallel hook execution (ar/parallel-hooks)
- Linux fsmonitor implementation (pt/fsmonitor-linux)
- MIDX repacking improvements (tb/incremental-midx-part-3.3)
- Rust support being enabled by default (bc/rust-by-default)

This status report provides a comprehensive overview of Git's development landscape, showing both incremental improvements and larger architectural changes in progress. The mix of documentation updates, performance optimizations, and subsystem refactoring reflects Git's continued evolution while maintaining stability.
