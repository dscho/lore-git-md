This is a release announcement for Git for Windows 2.54.0-rc2, the Windows-specific fork of Git maintained by Johannes Schindelin. The announcement highlights several updates and fixes specific to the Windows platform.

The most notable change is the removal of `git svn` from the default installation due to maintenance challenges. Windows users needing Subversion interoperability are directed to use WSL or install via MSYS2. The release includes updated versions of core components like Git (v2.54.0-rc2), Bash, Git Credential Manager, and OpenSSL.

Several Windows-specific bug fixes are included: restored `iconv` executable, improved terminal input handling in Git Bash, better NTFS junction handling in `git worktree remove`, and fixes for CPU core detection and Secure Channel timeouts. Security improvements include disabling NTLM fallback in Kerberos authentication following cURL's guidance.

The announcement provides SHA-256 checksums for various distribution formats (installers, portable versions, MinGit) across x64, ARM64, and 32-bit architectures. This is a routine pre-release update addressing Windows-specific issues rather than introducing major new functionality.
