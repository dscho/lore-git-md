This is a test patch in the fsmonitor Linux implementation series, specifically handling an incompatibility between split-index and index.skipHash in scalar clone tests. 

The patch disables GIT_TEST_SPLIT_INDEX in three test cases where scalar clone operations would otherwise trigger a BUG() in fsmonitor due to the interaction between these features. The issue occurs because index.skipHash (enabled by default in scalar) skips computing the OID for the shared index, causing it to fail loading on re-read. This matches an existing workaround pattern seen in test 16 of the same file.

The change is straightforward and maintainer-approved, following Junio Hamano's confirmation that split-index and index.skipHash are fundamentally incompatible. The patch demonstrates good attention to test hygiene by adding clear comments explaining the workaround and applying it consistently across all affected scalar clone tests. This is a minor but important piece of the larger fsmonitor effort, ensuring test stability while preserving the core functionality.
