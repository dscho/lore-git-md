Bugfix for the new `git history` command's help text.

René Scharfe corrects the short help text for the `--update-refs` option in two subcommands of the new `git history` command. The patch fixes two issues: 

1. The argh string (argument placeholder) incorrectly included "print" as a valid option when it's not actually supported. The valid choices are only "branches" and "head".
2. The help text is made consistent between the `reword` and `split` subcommands, both in the argument placeholder format (using literal "(branches|head)" instead of generic "<action>"/"<refs>") and in the description text.

The changes are minimal but important for accurate documentation of this new command's interface. As typical for René's patches, this is a precise, focused correction that improves consistency with surrounding code. The patch touches only the help text and doesn't affect actual functionality.
