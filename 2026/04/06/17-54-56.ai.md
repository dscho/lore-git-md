This is a feature patch in the fsmonitor series, adding a timeout to the daemon stop command to prevent indefinite hangs. The patch addresses a specific edge case where the fsmonitor daemon might fail to shut down properly after receiving a quit command.

If the daemon remains in the LISTENING state beyond this period, the command will error out rather than blocking forever. The implementation tracks elapsed time in milliseconds and increments it in 50ms sleep intervals, matching the existing polling cadence.
