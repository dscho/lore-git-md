This is a bugfix patch in the fsmonitor Linux implementation series, addressing a memory leak in the daemon's cookie tracking. The patch is part of a mature v13 series that has already addressed numerous technical challenges around filesystem monitoring.

The fix properly cleans up the `state.cookies` hashmap when the fsmonitor daemon shuts down, ensuring both the hashmap entries and their associated cookie name strings are freed. This was an oversight in the original implementation where the hashmap was initialized but never cleaned up. The solution follows Git's established patterns for resource cleanup, iterating through entries to free individual components before clearing the hashmap itself.

This patch demonstrates the series' attention to detail in resource management, coming after extensive testing and review. While small, it's an important correctness fix for production use. The change is straightforward and unlikely to be controversial given its focused nature and the series' overall stability.
