This is a refactoring patch in the fsmonitor series, which is part of the ongoing effort to bring Linux filesystem monitoring support to parity with Windows and macOS. The patch renames `fsm-settings-darwin.c` to `fsm-settings-unix.c` to reflect that the settings logic is not macOS-specific but shared across Unix platforms.

The change is straightforward - it renames the file and updates the build system (both CMake and meson) to use a new `FSMONITOR_OS_SETTINGS` variable for the settings file, matching the approach already used for the fsmonitor IPC code. This is a logical consolidation since the settings handling is common to all Unix implementations.

The patch builds on prior work from Eric DeCosta and Marziyeh Esipreh, and is part of the v13 series that has undergone extensive review. This particular change is a mechanical refactoring that doesn't introduce new functionality but prepares the codebase for the Linux fsmonitor implementation by making the platform-specific code organization more consistent.
