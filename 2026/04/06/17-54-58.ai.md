This is a refactoring patch in the fsmonitor Linux implementation series, converting a khash-based string set to use Git's strset API for pathname deduplication in the daemon's client handling code.

The change replaces the manual khash initialization and operations with the higher-level strset interface, which provides the same functionality with cleaner semantics. Since the paths are already interned strings from the batch data, the patch sets strdup_strings=0 to avoid unnecessary string copies. The change is straightforward and maintains all existing behavior while reducing code complexity.
