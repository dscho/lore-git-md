This is a refactoring patch in the fsmonitor series, specifically part 6 of 13. It renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` to reflect that the IPC path logic is shared across Unix platforms, not just macOS. The change prepares for Linux fsmonitor support by properly separating platform-specific components (handled via `FSMONITOR_DAEMON_BACKEND`) from shared Unix components (handled via `FSMONITOR_OS_SETTINGS`).

The patch updates build systems (Makefile, CMake, meson) to use the new naming scheme and variable separation. It's a straightforward mechanical change that builds on prior work from Eric DeCosta and Marziyeh Esipreh, with no functional impact beyond the build system reorganization. The change is well-contained and clearly motivated by the need to share code between macOS and the upcoming Linux fsmonitor implementation.
