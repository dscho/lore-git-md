This is the first patch in Derrick Stolee's performance optimization series, adding test coverage to verify that `git rev-list --maximal-only` and `git merge-base --independent` produce equivalent results under certain conditions. The patch adds a new test case to t6600-test-reach.sh that checks three scenarios: a mix of independent and dependent commits, all independent commits, and a case with only one independent commit. Each test compares the output of both commands after sorting.

The test demonstrates the behavioral equivalence that the subsequent patches will leverage to optimize `rev-list` by reusing the `merge-base` algorithm when possible. This is a typical Stolee approach - establishing thorough test coverage before making performance improvements. The test uses the existing commit graph setup from t6600, exercising the reachability logic that will be optimized in later patches.
