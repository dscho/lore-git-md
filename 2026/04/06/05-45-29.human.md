This is a platform compatibility patch updating Windows version requirements, co-authored by Matthias Aßhauer and Johannes Schindelin (Git for Windows maintainer). It's the first of a two-part series that formalizes Windows 8.1 as Git's new baseline Windows version.

The patch updates the `_WIN32_WINNT` macro definition to 0x0603 (Windows 8.1) across several compatibility files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c). This removes legacy version checks for older Windows versions (Vista/7) that Git for Windows already dropped support for in version 2.47.0. The changes are mechanical but important - they enable future use of newer Windows APIs while cleaning up outdated assumptions in the codebase.

The commit message clearly explains the motivation: there's no need to maintain compatibility shims for unsupported Windows versions, and this change will simplify upcoming work to improve CPU core detection on multi-socket systems. With Johannes Schindelin's co-authorship and the straightforward nature of the changes, this appears ready for merging in the next release cycle.
