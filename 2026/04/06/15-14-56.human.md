Bugfix for the cache-tree validation logic. David Lin corrects an inverted condition in `cache_tree_fully_valid()` that was causing the function to return the wrong result when checking for missing tree objects. The function was incorrectly marking cache trees as valid when their objects were absent from the object database, and vice versa. The fix adds the missing negation operator to properly invalidate cache trees when their objects don't exist.

The patch includes a new test case that verifies `write-tree` properly uses the cache-tree when it's valid, demonstrating the fixed behavior. The change is small but important for maintaining cache consistency, particularly in edge cases involving missing objects. The test coverage helps ensure this logic won't regress again.
