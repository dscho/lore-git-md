This is a test infrastructure patch in Adrian Ratiu's config-based hooks series. SZEDER Gábor points out a missing `&&` chain in the test helper functions `setup_hooks()` and `setup_hookdir()` in t1800-hook.sh. This is a minor but important shell scripting best practice to ensure test failures are properly caught.

The issue is purely about test script hygiene - the helper functions write multiple commands without connecting them with `&&`, which could mask failures if an intermediate command fails. This doesn't affect the core hook functionality being developed, but should be fixed before final integration since test reliability is critical.

The observation comes late in the series' review cycle (v3 patch 5/12), suggesting the test infrastructure has otherwise held up well through multiple iterations. Given the series is otherwise ready for merging to 'master', this appears to be one of the final polish items before integration. The fix should be straightforward - just connecting the config and script writing commands with `&&` operators.
