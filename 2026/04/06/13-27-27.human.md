This is the second patch in Derrick Stolee's performance optimization series for `git rev-list --maximal-only`. It adds a performance test comparing the current implementation against `git merge-base --independent`, which will be used to demonstrate the speedup from the optimization in the next patch.

The test shows that `merge-base --independent` is already significantly quicker (0.00s vs 0.70s in the Linux kernel repo) when references share history, validating the motivation for the optimization. The test also checks behavior with `--since` to ensure the generic walk logic still works when needed.

Stolee includes benchmark results from both git.git (showing modest differences) and the Linux kernel repo (showing dramatic speedups), demonstrating how the optimization will particularly help large repositories with many dependent branches. This follows his typical thorough approach - establishing performance baselines before making changes.
