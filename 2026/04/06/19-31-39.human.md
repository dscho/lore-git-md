This is a follow-up in the bugfix thread about `git diff`'s object database handling outside repositories, now confirming a proposed solution.

Luca Stefani reports that Justin Tobler's proposed fix - introducing a "hash-only" variant of `index_blob_packfile_transaction()` to avoid ODB transactions when only hashing is needed - works as expected for their use case. The patch would maintain the streaming behavior Jeff King wanted to preserve while fixing the segfault that occurs when trying to use transactions without an object database. 

Luca offers to provide a Tested-by tag if Justin extracts this fix from his larger ODB transaction series. The thread appears to be converging on this solution, which addresses both the immediate issue and the broader architectural concerns raised earlier about proper handling of hash-only operations. This fix would be particularly relevant for repository-less `git diff` operations on large files, while also fitting into Justin's ongoing work on ODB transaction improvements.
