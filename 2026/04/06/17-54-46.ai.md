This is a test patch in the fsmonitor Linux implementation effort, specifically addressing an incompatibility between split-index and index.skipHash in scalar clone tests. It's part of a larger v13 series that brings Linux fsmonitor support to parity with Windows/macOS implementations.

The patch disables GIT_TEST_SPLIT_INDEX in three scalar clone test scenarios where it conflicts with index.skipHash (a Scalar default). The conflict occurs because skipHash feature leaves the shared index with a null OID, causing fsmonitor to trigger a BUG() when the index is re-read. This matches an existing workaround pattern seen in test 16 of the same file.

The change is straightforward and maintainer-approved, following Junio Hamano's confirmation that split-index and index.skipHash are fundamentally incompatible. The patch demonstrates careful attention to test coverage and edge cases in the broader fsmonitor implementation. As the first patch in the v13 series, it sets up proper test conditions for subsequent fsmonitor validation.
