This is a refactoring patch in the fsmonitor series, specifically reorganizing the IPC implementation to be shared across Unix platforms. The patch renames `fsm-ipc-darwin.c` to `fsm-ipc-unix.c` since the IPC logic is not macOS-specific and will be reused by the upcoming Linux fsmonitor implementation.

Key changes include:
- Introduces a new `FSMONITOR_OS_SETTINGS` build setting to distinguish between platform-specific files (listen, health, path-utils) and shared Unix files (ipc, settings)
- Moves the IPC file to the `FSMONITOR_OS_SETTINGS` section in the Makefile
- Updates build configurations (Makefile, CMake, meson) to handle the new separation between daemon backend and OS settings
- Maintains Windows-specific path handling while generalizing the Unix IPC code

The change is part of the larger fsmonitor effort to bring Linux support to parity with existing Windows and macOS implementations. This particular patch focuses on code organization rather than adding new functionality, cleaning up the structure in preparation for the Linux implementation. The patch builds on prior work from Eric DeCosta and Marziyeh Esipreh, and maintains compatibility with existing macOS and Windows implementations.
