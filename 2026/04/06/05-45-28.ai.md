This is a platform compatibility patch series from Johannes Schindelin, co-authored with Matthias Aßhauer, updating Windows version requirements for Git. The two-patch series follows Git for Windows 2.47.0's decision to drop support for pre-8.1 Windows versions.

The first patch (carried over from v1) unifies the `_WIN32_WINNT` macro definition to Windows 8.1 (0x0603) across several compatibility files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c). The second patch (new in v2) removes a pre-Vista workaround from winansi.c that is no longer needed. Both changes are mechanical updates that remove legacy code now that the minimum Windows version has been raised.

The changeset is part of an ongoing effort to modernize Git's Windows support and enable use of newer Windows APIs, particularly for future improvements to CPU core detection on multi-socket systems. As these patches come from the Git for Windows maintainer and follow a previously announced compatibility policy change, they are likely to be uncontroversial. The series appears ready for inclusion in the upcoming v2.54.0 release.
