This thread addresses a bug in the promisor-remote subsystem where Git incorrectly used the superproject's `promisor.quiet` configuration when performing lazy fetches in submodules. The issue affects commands like `git grep --recurse-submodules` in partial clone scenarios.

Trieu Huynh submitted a focused fix that replaces `the_repository` with the proper repository context parameter in `fetch_objects()`, ensuring submodules respect their own `promisor.quiet` settings. The patch includes a thorough test case that verifies the fix by creating a superproject with a partial-clone submodule and confirming the submodule's configuration is properly honored during recursive operations.

This change is part of the ongoing `the_repository` removal effort and follows up on prior cleanup work noted by Patrick Steinhardt. The patch is well-crafted with a precise commit message and comprehensive test coverage, making it likely to be accepted without significant additional discussion.
