This is a platform compatibility patch updating Windows version requirements, co-authored by Matthias Aßhauer and Johannes Schindelin (Git for Windows maintainer). It's the first of a two-part series that unifies the `_WIN32_WINNT` macro definition to Windows 8.1 (0x0603) across several compatibility files (mingw.c, nedmalloc, poll emulation, posix.h, flush.c).

The change follows Git for Windows 2.47.0's decision to drop support for pre-8.1 Windows versions and removes legacy version checks for older Windows releases (Vista/7/XP). The patch updates comments and macro definitions consistently, noting this enables future use of newer Windows APIs - particularly for planned CPU core detection improvements on multi-socket systems. The mechanical nature of these updates and their alignment with Git for Windows' already-announced compatibility policy make this an uncontroversial change likely headed for v2.54.0.
