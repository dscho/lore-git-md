This is a platform compatibility patch that removes legacy Windows Vista/XP-era code from Git's Windows ANSI emulation layer. It's the second patch in a two-part series from Matthias Aßhauer and Johannes Schindelin (Git for Windows maintainer) that follows Git for Windows' decision to drop support for pre-Windows 8.1 systems.

The patch simplifies the font detection code in `compat/winansi.c` by removing a pre-Vista workaround that checked the registry for console font settings. Since Git now requires Windows 8.1 or later, the code can rely solely on the modern `GetCurrentConsoleFontEx` API that was introduced in Vista. The change removes 33 lines of legacy code while maintaining the same warning functionality when non-TrueType fonts are detected.

This is a straightforward cleanup that aligns with Git for Windows' announced compatibility policy. The changes are mechanical and uncontroversial, coming from the Git for Windows maintainer team. The patch series appears ready for inclusion in the upcoming v2.54.0 release.
