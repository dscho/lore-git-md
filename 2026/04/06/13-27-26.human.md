This is the first patch in Derrick Stolee's performance optimization series for `git rev-list --maximal-only`. It adds test coverage to establish that `git rev-list --maximal-only` and `git merge-base --independent` produce equivalent results when given the same input refs, which is the foundation for the optimization proposed in later patches.

The test creates three scenarios: a mix of independent and dependent commits, all independent commits, and a case with only one independent commit. For each case, it verifies that both commands output the same set of commits (after sorting). The test uses the existing test repository from t6600, which contains a complex commit graph structure suitable for testing reachability operations.

This is a typical first step in Stolee's approach - establishing thorough test coverage before making behavioral changes. The test looks well-constructed and covers the key cases needed to validate the equivalence claim that motivates the optimization. As the first patch in the series, it sets up the safety net for the actual implementation change coming in patch 3.
