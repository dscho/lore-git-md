This is a platform compatibility update for Windows support, now queued for inclusion in Git 2.54.0. The two-patch series from Johannes Schindelin (Git for Windows maintainer) and Matthias Aßhauer formalizes Windows 8.1 as the minimum supported version by standardizing the `_WIN32_WINNT` macro and removing legacy code paths for older Windows versions.

The changes are mechanical cleanups following Git for Windows' previously announced policy shift. The first patch unifies version definitions across several Windows-specific files, while the second eliminates a pre-Vista workaround for console font detection that's no longer needed. These changes pave the way for using newer Windows APIs in future development, particularly for multi-socket CPU core detection improvements.

Junio Hamano has indicated he will apply the patches directly to master, suggesting they are uncontroversial and align with the project's Windows support strategy. The changes appear well-scoped and low-risk, coming from the Git for Windows maintainer with clear technical rationale.
