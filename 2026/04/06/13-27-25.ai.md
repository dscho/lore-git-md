This is a performance optimization patch series from Derrick Stolee that aims to make `git rev-list --maximal-only` faster by using the same algorithm as `git merge-base --independent` when possible. The series consists of three patches that build up the change with tests and benchmarks.

The key insight is that these two commands currently produce equivalent results when no other walk modifiers are present, but the merge-base version can be faster when references share most of their history. The series first adds tests to verify this equivalence, then creates a performance benchmark, and finally implements the optimization by checking the rev_info struct for incompatible options before falling back to the faster algorithm.

The changes touch the rev-list builtin and add tests in multiple test files, including a new performance test script.
