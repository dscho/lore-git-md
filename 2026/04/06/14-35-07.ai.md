This resolves the discrepancy between Scharfe's technical analysis (which showed the errors matched pre-1.1.0 OpenSSL behavior) and the original OpenSSL 3.0 claim.

The thread demonstrates Git's ongoing challenges with OpenSSL version compatibility, particularly in the email-sending infrastructure (`imap-send.c`). With this clarification, the original issue appears to be a non-problem for OpenSSL 3.0 specifically, though it does highlight the project's need to track which OpenSSL versions remain in extended support.
