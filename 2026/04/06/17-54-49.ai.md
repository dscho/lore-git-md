This is a platform compatibility patch adding Windows pthread emulation support for `pthread_cond_timedwait()`, part of the larger fsmonitor Linux implementation series (v13). The patch implements the timed wait functionality using Windows' `SleepConditionVariableCS()` API with millisecond timeout calculation from absolute time.

The implementation handles time conversion carefully - getting current time via `gettimeofday()`, converting both current time and deadline to milliseconds, then computing the relative timeout. It properly handles the `ETIMEDOUT` case when the deadline has already passed, and translates Windows error codes to POSIX equivalents. The change is straightforward and well-contained, adding only the necessary Windows-specific code while maintaining the expected pthread semantics.

This is a supporting piece for the cross-platform fsmonitor work, ensuring consistent behavior between Unix and Windows implementations. The patch shows good attention to edge cases (timeout calculation, error code translation) and follows the established pattern of the existing pthread emulation layer in Git's Windows compatibility code.
