This is a platform compatibility update that has been accepted by the maintainer for immediate inclusion in Git's master branch. The two-patch series from Johannes Schindelin and Matthias Aßhauer finalizes Git for Windows' move to requiring Windows 8.1 as the minimum supported version (0x0603).

The first patch standardizes the `_WIN32_WINNT` macro definition across multiple Windows-specific files, removing legacy version checks for older Windows versions. The second patch eliminates a pre-Vista workaround in winansi.c that handled console font detection, simplifying the code by about 30 lines while maintaining the same warning functionality for non-TrueType fonts.

Junio Hamano has reviewed the series and indicated he will apply it directly to master, bypassing the usual next/seen integration branches. This quick acceptance reflects both the mechanical nature of the changes and their origin from the Git for Windows maintainer following an already-announced compatibility policy change. The patches enable future use of newer Windows APIs while cleaning up obsolete code paths.
