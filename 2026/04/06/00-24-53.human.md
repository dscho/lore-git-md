This is the second patch in Lorenzo Pegorari's v3 series addressing promisor file handling during repacks, part of his GSoC project under Eric Sunshine's mentorship. The patch introduces a new helper function `copy_promisor_content()` that preserves debugging information in `.promisor` files when repacking promisor packfiles.

The helper function carefully handles several key requirements:
- Maintains the original timestamp information (now in `<oid> <ref> <time>` format) for debugging partial clone operations
- Skips objects that weren't actually repacked (using an ignorelist for excluded packs)
- Only copies metadata for objects that appear in the new pack
- Preserves existing timestamp information if already present

The implementation shows attention to edge cases with proper error handling and cleanup. The function assumes well-formed input files, which is reasonable given this is internal plumbing code. The patch builds on the series' first documentation patch and will be followed by integration with geometric repacking logic and expanded test coverage.
