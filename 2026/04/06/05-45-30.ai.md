This is a platform compatibility patch that removes legacy Windows version support, specifically targeting the winansi.c compatibility layer. As the second patch in a two-part series from Matthias Aßhauer and Johannes Schindelin (Git for Windows maintainer), it follows up on Git for Windows 2.47.0's decision to drop support for pre-Windows 8.1 systems.

The patch eliminates a pre-Vista workaround in winansi.c that was originally added in 2014 to handle console font detection on older Windows versions. The removed code included both a registry-based fallback for systems before Vista and a manual definition of the CONSOLE_FONT_INFOEX structure for older MinGW toolchains. Now that Windows 8.1 is the minimum supported version, the code can directly use the GetCurrentConsoleFontEx API without fallbacks.

The change is straightforward and mechanical cleanup - it simplifies the font detection logic by removing about 30 lines of now-unnecessary code while maintaining the same warning functionality when non-TrueType fonts are detected. Since this aligns with Git for Windows' established compatibility policy and comes from its maintainer, the patch is likely to be uncontroversial and ready for inclusion.
