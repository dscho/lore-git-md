Test modernization patch that prepares signal-handling tests for `set -e` compatibility. This is part of a larger series (12 patches) to make Git's test suite work reliably with `set -e` enabled.

The patch modifies three test cases that verify Git dies with SIGPIPE (signal 13) under certain conditions. The current implementation uses `foo; echo $?` which would fail under `set -e` when `foo` exits non-zero. The new form `foo && echo 0 || echo $?` ensures the subshell succeeds regardless of the command's exit status while still capturing the exit code.

Changes affect:
- Two tests in t/t0005-signals.sh that verify Git dies with SIGPIPE when output is blocked
- One test in t/t3600-rm.sh that checks SIGPIPE handling during `git rm`

The modifications are mechanical and focused on test infrastructure rather than core functionality. As part of a larger test suite modernization effort, this change helps enable stricter error checking in shell scripts while maintaining existing test coverage for signal handling behavior.
