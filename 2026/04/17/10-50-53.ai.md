This is patch 7/12 in Patrick Steinhardt's series to enable `set -e` (errexit) in Git's test suite for Bash 5+. The patch focuses on adapting the test cleanup infrastructure to work correctly with strict error checking.

The change modifies `test_when_finished()` and `test_atexit()` functions to use `||` instead of `&&` for preserving test exit codes during cleanup. The author provides clear truth tables showing how both the old and new implementations behave across different test/cleanup pass/fail combinations, demonstrating the new version maintains the same semantics while being compatible with `set -e`.

The key insight is that the previous implementation would cause premature exit under `set -e` when `eval_ret` was non-zero, while the new version using `||` avoids this issue. This is a subtle but important change to ensure cleanup commands execute reliably while still properly tracking the test's exit status.

The patch follows the series' pattern of careful, behavior-preserving changes with thorough documentation of the rationale. It builds on previous infrastructure work in the series and maintains compatibility with the test suite's expectations around exit code handling.
