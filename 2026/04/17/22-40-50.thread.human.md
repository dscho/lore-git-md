Junio Hamano's latest "What's cooking" report provides a comprehensive snapshot of Git's current development landscape as of April 2026. The project continues to balance modernization efforts against stability needs, with Jeff King rolling back the MIDX default version to v1 to maintain compatibility with older Git versions - a typical example of progress being tempered by real-world deployment considerations.

Several significant technical efforts are progressing well: Patrick Steinhardt's in-memory ODB implementation (18 commits) represents a major architectural change, while parallel hook execution has graduated to the 'next' branch. The Rust support work has reached an important milestone by being enabled by default for the upcoming 2.54 release, though this remains a point of discussion given platform support concerns. Other notable improvements include Paul Tarjan's Linux fsmonitor daemon (13 commits) and various performance optimizations for blob fetching in lazy clones.

The report also highlights several areas needing attention, with multiple topics marked as awaiting review responses or expecting updated patch series. These include the ongoing `the_repository` removal efforts (touching multiple subsystems) and test suite improvements to properly handle `set -e`. The breadth of activity - from core architectural changes (ODB, Rust) to user-facing improvements (HTTP auth, diffstat fixes) - demonstrates Git's continued evolution while maintaining its characteristic stability-focused approach.
