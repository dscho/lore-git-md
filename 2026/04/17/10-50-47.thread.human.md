This thread focuses on modernizing Git's test suite to work reliably with `set -e` enabled, specifically addressing signal-handling tests. The current patch modifies three test cases that verify Git's behavior when dying with SIGPIPE (signal 13). 

The changes are mechanical but important for test infrastructure: replacing `foo; echo $?` patterns with `foo && echo 0 || echo $?` to maintain test behavior under `set -e`. This affects two tests in t/t0005-signals.sh (testing SIGPIPE when output is blocked) and one in t/t3600-rm.sh (testing SIGPIPE during `git rm`). The patch is part of a 12-part series aimed at making the entire test suite compatible with stricter shell script error checking while preserving existing test coverage for signal handling.
