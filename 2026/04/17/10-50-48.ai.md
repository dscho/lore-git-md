This is the second patch in Patrick Steinhardt's 12-part series to enable `set -e` (errexit) in Git's test suite for Bash 5+. The patch modifies the `test_must_fail()` helper function to work correctly when `set -e` is enabled.

The change ensures that when a command fails (which is the expected case for `test_must_fail`), the shell won't immediately exit due to `set -e`. Instead, it captures the exit code in a variable using the `||` operator before evaluating whether the failure matches expectations. The implementation is careful to maintain the existing behavior while making it compatible with strict error checking.

This is a foundational change in the series, preparing one of Git's most frequently used test helpers for the later patch that will actually enable `set -e`. The modification follows the pattern seen elsewhere in the series of making test infrastructure resilient to early exits while preserving all existing functionality. The patch has already been reviewed in previous iterations and appears ready for merging as part of the complete series.
