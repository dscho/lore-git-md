This is a Windows compatibility follow-up from the Git for Windows maintainer. Johannes Schindelin confirms that the listed Git versions (2.26.0 through the likely-typo 2.51.1) will work on Windows 11, though notes they all contain known vulnerabilities. The response is brief and to the point, emphasizing that while the versions will function, they are not secure choices for production use.

The exchange serves as a clear example of the project's division of responsibilities - core Git development happens on the main list, while Windows-specific support questions are handled by the separate Git for Windows project. No technical details about the vulnerabilities are provided, as that would require directing the user to the specific security advisories for each version. The thread appears to be concluded with this response.
