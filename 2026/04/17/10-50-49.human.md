This is patch 3/12 in Patrick Steinhardt's series to enable `set -e` (errexit) in Git's test suite for Bash 5+. The patch specifically prepares the `stop_git_daemon()` helper function to work correctly with strict error checking enabled.

The change addresses two issues that would cause premature test failures under `set -e`:
1. The `wait` command for the git-daemon process would fail (as expected) but trigger an immediate exit
2. A redundant second `kill` attempt would fail when the process was already terminated

The solution modifies the error handling to:
- Capture the `wait` exit code via `||` operator before evaluation
- Silently ignore failures of the second `kill` with `|| :`

This maintains the existing behavior while making it compatible with `set -e`. The patch follows the series' pattern of carefully adapting test infrastructure before enabling strict error checking globally. It has already been reviewed by Jeff King and SZEDER Gábor as part of the overall series.
