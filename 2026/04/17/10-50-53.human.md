This is patch 7/12 in Patrick Steinhardt's series to enable `set -e` (errexit) in Git's test suite for Bash 5+. The patch focuses on making the test cleanup handlers (`test_when_finished` and `test_atexit`) work correctly with strict error checking enabled.

The key change is replacing the existing cleanup command chaining logic that used `&& (exit "$eval_ret")` with a simpler `|| eval_ret=$?` pattern. The patch includes clear truth tables showing how both the old and new approaches handle different combinations of test body and cleanup command success/failure states. The new approach maintains the same behavior while being compatible with `set -e`.

This is a well-explained change that follows the series' pattern of making incremental, behavior-preserving adjustments to prepare for stricter error handling. The patch has already undergone review in previous iterations and appears ready for merging as part of the overall series.
