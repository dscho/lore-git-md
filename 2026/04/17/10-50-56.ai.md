This is patch 10/12 in Patrick Steinhardt's series to enable `set -e` (errexit) in Git's test suite for Bash 5+. The patch fixes a subtle issue in t6002-rev-list-bisect.sh where the test helper `test_bisection_diff()` uses `expr` for arithmetic that could fail when the result is zero.

The change replaces `expr` with shell arithmetic (`$(( ))`), which doesn't have the same failure mode. The patch also modernizes the test style by splitting the multi-line `test_expect_success` into a more readable format. This is a mechanical but important change that follows the series' pattern of making tests robust under strict error checking while preserving their original behavior.

The fix addresses one of the last remaining edge cases needed before the full `set -e` enablement can proceed. Given the thorough review history of this series and the straightforward nature of this arithmetic conversion, the patch appears uncontroversial and well-aligned with the overall goal of improving test reliability.
