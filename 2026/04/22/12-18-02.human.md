This is a refactoring patch from Jiamu Sun's series adding subcommand autocorrection support to Git's parse-options API. As the second patch of the now-finalized v5 series, it extracts the existing autocorrection logic from help.c into new autocorrect.{c,h} files to make the functionality reusable across different commands.

The patch cleanly moves:
- The autocorrect mode constants (AUTOCORRECT_SHOW, PROMPT, etc.)
- Configuration parsing via parse_autocorrect()
- The config resolution callback autocorrect_resolve_config()
- User confirmation logic via autocorrect_confirm()

The implementation maintains all existing behavior while properly separating concerns - the core autocorrection logic is now available as a library component rather than being tied to the help system. This enables the following patches in the series to reuse this infrastructure for subcommand autocorrection.

With the maintainer's approval and all technical feedback addressed across five iterations, this well-structured refactoring looks ready for merging as part of the broader subcommand autocorrection feature.
