This is patch 3/7 in Derrick Stolee's v3 series introducing fetch/push negotiation controls, focusing on internal renaming to clarify the option semantics. - `builtin/fetch.c` (command-line parsing and transport preparation)
- `fetch-pack.c` (negotiation logic)
- Transport layer files (`transport.c`, `transport.h`, `transport-helper.c`)
- Header files (`fetch-pack.h`)

Key technical points:
- Maintains backward compatibility through `OPT_ALIAS` for the old `--negotiation-tip` option name
- Updates all related function signatures and variable names consistently
- Preserves existing behavior while making the implementation's intent clearer
- Keeps the underlying `oid_array` structure but renames its usage context

The patch is part of the series' final naming refinement before integration, following consensus on the `--negotiation-restrict` terminology. It demonstrates careful attention to cross-component consistency in the rename operation.
