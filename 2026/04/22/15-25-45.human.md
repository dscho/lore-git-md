This is patch 6/7 in Derrick Stolee's series introducing negotiation control options for fetch/push operations. The patch adds config support for the `--negotiation-include` option introduced earlier in the series.

The patch adds a new `remote.<name>.negotiationInclude` config option that provides default values for `--negotiation-include` when the command-line option isn't specified. This mirrors the existing `remote.<name>.negotiationRestrict` config added in an earlier patch. The config supports both exact ref names and glob patterns, and empty values can be used to reset the list (useful for ignoring system/global configs).

Key implementation details:
- Adds the config option documentation
- Updates the remote struct to track the config values
- Modifies fetch's transport preparation to use the config when CLI options aren't present
- Includes tests verifying the config works with glob patterns and CLI override behavior

The patch maintains consistency with the series' design by:
- Config values are additive with normal negotiation
- Follows same pattern as negotiationRestrict config
- Includes comprehensive test coverage
- Handles protocol compatibility warnings
