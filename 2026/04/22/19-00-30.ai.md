This is a bug report about a regression in Git 2.54.0 where the test suite hangs indefinitely when run with mksh as the system shell. The reporter, Jan Palus, has bisected the issue to commit dd3693eb08 which introduced cleanup handling for child processes in transport-helper and connect code.

The core issue appears to be a difference in shell behavior - when Git spawns processes via "sh -c", bash implementation terminates and reparents children when receiving SIGTERM, while mksh waits for the child process to complete. This causes the test suite to hang in t5702-protocol-v2.sh when using mksh.

The regression stems from the interaction between Git's new cleanup mechanism (which sends SIGTERM to child processes) and shell process handling. The commit was intended to prevent zombie processes when Git exits abnormally, but inadvertently created this hang scenario with mksh. This looks like a legitimate regression that will need addressing, either through modifying the cleanup behavior or making it shell-aware.
