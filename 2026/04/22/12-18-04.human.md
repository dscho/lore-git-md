This is a refactoring patch in Jiamu Sun's series adding subcommand autocorrection to Git's parse-options API. The patch replaces magic numbers in the autocorrection configuration handling with a proper `autocorrect_mode` enum and structured `autocorrect` config object.

The changes:
- Introduces `enum autocorrect_mode` with named values for the different autocorrection behaviors (prompt, never, immediately, show, delay)
- Defines a new `struct autocorrect` to hold both the mode and delay values
- Updates the config parsing and confirmation logic to use these types instead of raw integers
- Maintains all existing behavior while making the code more type-safe and self-documenting

This is part of the final polishing for the series, which has already received maintainer approval. The refactoring improves code clarity without changing functionality, following the pattern established in earlier iterations of separating concerns into clean APIs. The patch shows careful attention to detail, with all edge cases (like non-interactive sessions) handled consistently with the previous implementation.
