This is a refactoring patch that extracts Git's command autocorrection logic into reusable components as part of the subcommand autocorrection feature series. The patch moves the core autocorrection handling from help.c into new files autocorrect.{c,h}, making the functionality available to other parts of Git that need similar behavior.

Key changes:
- Creates new autocorrect.c/h files containing the config parsing and user confirmation logic
- Moves the AUTOCORRECT_* constants and related functions out of help.c
- Updates Makefile and meson.build to include the new files
- Keeps the same behavior while making the code more modular

The refactoring enables the subsequent patches in the series to reuse this autocorrection infrastructure for subcommands. The implementation maintains all existing functionality while providing a cleaner API boundary. This is part of a well-reviewed series that has already addressed all technical feedback and is now in final polishing stage before merging.
