This is a bug report about a test suite hang when using mksh as the system shell. The reporter, Jan Palus, has bisected the issue to commit dd3693eb08 which introduced cleanup handling for child processes in transport-helper and connect code. 

The problem manifests when `/bin/sh` is mksh - the test suite hangs indefinitely because mksh doesn't properly terminate child processes when receiving SIGTERM, unlike bash which handles this case correctly. The reporter provides a process tree showing a stuck `t5702-protocol-v2.sh` test with git-upload-pack as a child process.

The commit in question was meant to fix zombie process accumulation by ensuring child processes are reaped on abnormal exits, but it appears to have unintended consequences with mksh's process handling. This looks like a legitimate regression that needs investigation, particularly around how different shells handle process termination signals. The report is well-documented with clear reproduction details and bisect results.
