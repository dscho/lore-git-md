This is a refactoring patch in Jiamu Sun's series adding subcommand autocorrection to Git's parse-options API. The patch renames `AUTOCORRECT_SHOW` to `AUTOCORRECT_HINT` throughout the codebase to better reflect the enum's purpose - showing similar commands as hints without taking any automatic action.

The change is mechanical, updating:
- The enum definition in autocorrect.h
- The parsing logic in autocorrect.c that handles config values
- The condition in help.c that checks whether to show hints

This is part of the final polishing for the series, which has already addressed all major technical feedback and received maintainer approval. The rename improves clarity while maintaining identical behavior, following through on earlier discussions about making the enum names more semantically precise. With this change, the autocorrection feature's code matches its documented behavior more clearly.
