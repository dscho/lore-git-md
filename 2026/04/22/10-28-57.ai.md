This is a cover letter for a 2-patch series introducing a new "fixup" subcommand to `git history`, part of Patrick Steinhardt's ongoing work on the experimental `git history` command. The series builds on commit 94f057755b ("...") from April 2026.

The new subcommand allows amending staged changes to an existing commit (similar to `git commit --fixup`) while automatically rebasing dependent branches - a workflow Patrick reports using frequently. The implementation currently aborts on merge conflicts, with plans to improve conflict handling when Git gains first-class conflict resolution capabilities.

Key technical details:
- Adds `git history fixup <commit>` command
- Generalizes internal tree-commit function in preparation
- Includes extensive tests (500+ lines in t3453-history-fixup.sh)
- Updates documentation in Documentation/git-history.adoc

The series appears well-structured with thorough test coverage, though the conflict handling limitation is notable. Given Patrick's track record with the history command and the clear motivation, this seems likely to progress smoothly through review.
