This is patch 6/7 in Derrick Stolee's feature series introducing configurable fetch/push negotiation controls. The patch adds `remote.<name>.negotiationInclude` as a config counterpart to the `--negotiation-include` command-line option introduced earlier in the series.

The config option mirrors the behavior of `remote.<name>.negotiationRestrict` (added in patch 4/7), allowing users to always advertise certain refs during negotiation. Key aspects:

- Multi-valued config that accepts exact refs or glob patterns
- Additive with normal negotiation - doesn't replace the algorithm's selections
- Empty value resets the list (useful for ignoring system/global configs)
- CLI option takes precedence when both are specified
- Includes comprehensive tests verifying:
  - Basic functionality
  - Glob pattern matching
  - Empty value reset behavior
  - CLI override precedence

The implementation touches `remote.c` for config handling and `builtin/fetch.c` for transport integration, maintaining consistency with the series' established patterns. Documentation updates cover both the config option and its interaction with the CLI flag.

This patch completes the config surface for the negotiation control feature, following the same design principles established earlier in the series. The tests demonstrate real-world usage patterns while maintaining the series' thorough coverage of edge cases.
