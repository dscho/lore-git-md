This is a refactoring patch in Taylor Blau's ongoing series to implement incremental MIDX/bitmap-based repacking. The patch converts the `--write-midx` flag from a simple boolean option to a callback that can handle multiple modes, preparing for future expansion of MIDX writing functionality.

The key changes are:
1. Introduces an enum to represent MIDX writing modes (`REPACK_WRITE_MIDX_NONE` and `REPACK_WRITE_MIDX_DEFAULT`)
2. Adds an option parser callback to handle the `--write-midx` flag with potential future mode arguments
3. Creates a dispatcher function `repack_write_midx()` that will select the appropriate MIDX-writing implementation
4. Updates all existing boolean checks to use the new mode enum

The patch maintains backward compatibility - passing just `-m` or `--write-midx` without arguments continues to use the default MIDX writing behavior. This is part of the infrastructure work needed to support the series' eventual goal of incremental MIDX chain repacking.

The changes are mechanical and focused, following the incremental refactoring approach seen throughout this series. The patch has already received review attention in previous iterations, with no outstanding technical concerns noted in this version.
