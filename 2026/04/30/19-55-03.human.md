This is a feature patch introducing new pretty-format placeholders for diff statistics in commit logs.

Andrey Zarubin proposes adding four new placeholders (`%(diff-stat:files)`, `%(diff-stat:insertions)`, `%(diff-stat:deletions)`, and `%(diff-stat:lines)`) along with short aliases (`%aF`, `%aA`, `%aR`) to show file change counts and line modifications in custom log formats. Currently users must post-process `git log --shortstat` output to get this information.

The implementation reuses Git's existing diffstat machinery, computing the statistics lazily only when needed. For merge commits, it respects the same diff modes (`-m`, `-c`, `--cc`) as `--shortstat`. The patch includes thorough test coverage verifying the new placeholders match `--shortstat` output across various commit types (normal, binary, merge, etc.).

The changes touch multiple files but are well-contained, adding the new functionality without disrupting existing behavior. The commit message clearly explains the motivation and implementation approach. This appears to be a well-considered addition that fills a gap in Git's pretty-format capabilities while maintaining good performance characteristics.
