This is a documentation patch that completes a bugfix series addressing HTTP authentication behavior with Kerberos (SPNEGO). The series fixes an interaction between two older features that was preventing `http.emptyAuth=auto` from working correctly with Negotiate authentication.

The new patch (4/4) updates the documentation to clearly explain the three possible values for `http.emptyAuth` (true, false, and auto) and their behaviors. It specifically clarifies that `auto` mode will attempt empty authentication first for certain mechanisms like GSS-Negotiate before falling back to credentials.

The patch series has already been reviewed positively, with Junio Hamano suggesting this documentation improvement. The changes are well-contained with:
- Code refactoring in patch 1
- Core behavior fix in patch 2
- Test coverage in patch 3
- Now complete documentation in patch 4

The fix has already been incorporated into Git for Windows 2.54.0-rc2, and with this documentation update, the series appears ready for merging. The documentation changes match the technical implementation exactly and help users understand when to use each configuration option.
