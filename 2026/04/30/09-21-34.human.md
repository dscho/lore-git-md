This is a small follow-up to the final patch in Kristoffer Haugsbakk's `git format-rev` series, fixing a minor bug in the error message output. The original patch introduced a new experimental command for on-demand commit formatting, but had an incorrect variable reference in the error path - it was printing `*argv` when it should have been printing `scratch_buf.buf` to show the problematic object name.

The fix is straightforward and addresses a clear-cut issue. Since this is part of an experimental feature, the change is low-risk and helps polish the user experience. The series as a whole has been well-received, with thorough test coverage and clear documentation. This tweak shows the author's attention to detail in catching small inconsistencies even after the main implementation work was complete.
