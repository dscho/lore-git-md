This is part 2 of Johannes Schindelin's 6-patch series updating GitHub Actions dependencies in Git's CI system. The patch focuses on bumping the versions of `actions/upload-artifact` (from v5 to v7) and `actions/download-artifact` (from v6 to v8) across all workflow files.

The changes are mechanical version updates with careful consideration of compatibility and security implications. Key points:

1. The upload/download artifact actions must be updated in lockstep since they share an artifact format contract. The update moves both to Node.js 24 runtime, phasing out the deprecated Node.js 20.

2. For upload-artifact, v7 adds new features (direct file uploads and ESM conversion) that don't affect Git's usage since we don't use those options. The main benefit is the Node.js version bump.

3. For download-artifact, v8 introduces stricter security by making hash mismatches a hard failure rather than just a warning - a safe change since we download artifacts we just uploaded in the same workflow.

4. The patch also fixes one stray v4 upload-artifact reference to align all uses to v7.

Schindelin provides thorough analysis of each change's impact, including links to changelogs and comparisons. The changes appear low-risk while keeping CI infrastructure current and secure. This continues the series' pattern of careful, well-documented maintenance updates.
