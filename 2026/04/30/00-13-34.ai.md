This is a refactoring patch in Taylor Blau's ongoing series to implement incremental MIDX/bitmap-based repacking. The patch extracts a helper function `repack_fill_midx_stdin_packs()` from `write_midx_included_packs()` to handle the common case of writing pack names to a child process's stdin when running `git multi-pack-index write --stdin-packs`.

The new helper encapsulates the process of:
1. Setting up the `--stdin-packs` argument
2. Starting the child command
3. Writing the pack names to stdin
4. Finishing the command

This prepares for future need to capture the MIDX checksum from stdout when using `--no-write-chain-file`, while keeping the current behavior unchanged. The change follows the series' pattern of incremental refactoring to improve maintainability before adding new features.

The patch is part of a well-reviewed series that has received substantive technical feedback from Elijah Newren (on geometric strategy) and Jeff King (on process safety). This particular change appears straightforward and mechanical, with no functional impact in isolation.
