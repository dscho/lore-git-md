This is the first patch in a 6-part CI/build system series updating GitHub Actions dependencies. The patch specifically bumps the `microsoft/setup-msbuild` action from v2 to v3 to maintain compatibility as GitHub phases out Node.js 20 support.

The change is straightforward - it updates the action version in the main workflow file. Johannes Schindelin provides thorough justification in the commit message, noting this is a minimal update that only changes the Node.js runtime version while keeping the core functionality (adding `msbuild.exe` to PATH). The risk is assessed as very low since the action's behavior remains unchanged and GitHub's hosted runners already meet the requirements.

This continues the series' pattern of careful, well-documented dependency updates that maintain existing functionality while keeping CI infrastructure current. The patch appears ready for merging as part of the larger maintenance effort.
