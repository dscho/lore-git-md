This is a follow-up bugfix to Kristoffer Haugsbakk's `git format-rev` series, addressing a compiler warning caught by CI. The warning flagged a potential uninitialized variable (`commit`) in the newly introduced `get_format_rev` function within `builtin/name-rev.c`. 

The author notes they are now using `config.mak.dev`, which enables stricter compiler warnings. This is exactly the kind of issue that configuration helps catch - a straightforward initialization bug that slipped through initial testing. The fix appears to be a simple matter of ensuring the variable is properly initialized before use.

This patch doesn't introduce new functionality but rather tightens up the implementation of the experimental `format-rev` command. The fact that the issue was caught by CI before merging demonstrates the value of the project's automated checks, especially for new features marked as experimental. The fix maintains the series' overall quality while addressing a technical correctness issue.
