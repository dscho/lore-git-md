This is the fifth patch in a 6-part CI/build system series updating GitHub Actions dependencies. Johannes Schindelin bumps the Git for Windows SDK setup action from v1 to v2 to maintain compatibility as GitHub phases out Node.js 20 support. The change is purely mechanical - updating version strings in workflow files - with no functional impact on the SDK provisioning itself. The commit message provides thorough analysis confirming the update only changes the Node.js runtime (to v24) while maintaining the same SDK installation behavior, and that GitHub's hosted runners already meet the minimum runner version requirement (2.327.1+). This continues the series' pattern of low-risk version bumps with comprehensive impact assessment for each dependency update.
