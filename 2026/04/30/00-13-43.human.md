This is a memory leak fix in Taylor Blau's ongoing MIDX/bitmap repacking series. The patch addresses a long-standing oversight where Git would generate in-memory pack revindexes (used for reverse object lookups) but never free them. The issue surfaces now because the series introduces cases where MIDX bitmaps are written for packs without on-disk revindex files, forcing more in-memory revindex generation.

The fix is straightforward: `close_pack_revindex()` now properly frees the in-memory revindex using `FREE_AND_NULL()`. This is a small but important change that plugs a memory leak that's likely existed since the revindex code was first written, though it only became detectable with the new test infrastructure in this series.

As part of the larger MIDX repacking effort, this patch shows the careful attention to resource management needed for the incremental repacking features. The change has minimal impact on its own but prevents memory leaks in the more complex MIDX bitmap scenarios the series enables.
