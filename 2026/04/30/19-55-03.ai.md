This is a feature patch introducing new pretty-format placeholders for diff statistics in Git logs. The patch adds four new placeholders:

1. `%(diff-stat:files)` - shows number of files changed
2. `%(diff-stat:insertions)` - shows number of inserted lines
3. `%(diff-stat:deletions)` - shows number of deleted lines 
4. `%(diff-stat:lines)` - shows total lines changed (insertions + deletions)

The patch also provides short aliases for these placeholders (`%aF`, `%aA`, `%aR`) since some obvious single-letter choices were already taken by author date placeholders. The implementation reuses Git's existing diffstat machinery and caches the results per commit during format expansion to avoid performance overhead when these placeholders aren't used.

The change touches several areas:
- Documentation updates explaining the new placeholders
- Core diff.c changes to expose the stat summarization logic
- Pretty-format integration to handle the new placeholders
- Extensive test coverage verifying the placeholders match `--shortstat` output in various scenarios (normal commits, binary changes, merges, etc.)

The implementation appears thorough, with careful attention to edge cases like merge commits (which show 0 by default unless using `-m`/`-c`/`--cc`). The patch includes performance optimizations to avoid computing diffs unnecessarily when these placeholders aren't used.

This would be useful for users who want to include change statistics in custom log formats without having to parse `--shortstat` output themselves. The feature seems well-motivated and the implementation looks solid based on the test coverage and code changes.
