This is patch 8/16 in Taylor Blau's series implementing incremental MIDX/bitmap-based repacking for large repositories. The patch refactors MIDX pack lookup functionality to expose a new helper function.

The change renames `midx_contains_pack_1()` to the more descriptive `midx_layer_contains_pack()` and makes it publicly available via midx.h. Unlike the existing `midx_contains_pack()` which recursively checks all MIDX layers, this new function only examines a single specified MIDX layer. 

This prepares for a subsequent change that needs to specifically check whether a pack belongs to the tip MIDX layer rather than any layer in the chain. The patch maintains all existing behavior while making the single-layer check available to other parts of the codebase.

The change is mechanical with no functional impact - it moves and renames code without altering its behavior. This continues the series' pattern of incremental refactoring to support the larger geometric repacking feature while keeping changes focused and reviewable. The patch follows the established pattern of the series by separating concerns between layer-specific operations and full-chain operations.
