This is the third patch in Johannes Schindelin's 6-part CI/build system update series, bumping the `actions/github-script` dependency from v8 to v9 in Git's GitHub Actions workflow. The change is mechanical but comes with thorough analysis of potential impacts.

The patch updates the script used to skip redundant CI runs when an identical tree-SHA was already tested successfully. Schindelin carefully examines v9's changes:
- New HTTP user-agent string addition (transparent to Git's usage)
- New `getOctokit` factory (unused by Git)
- Breaking changes that don't affect Git's simple usage of the pre-supplied REST client

The commit message provides a detailed risk assessment, noting the step is advisory and would degrade gracefully to a non-fatal warning if anything went wrong. The patch includes links to release notes and version comparison for transparency.

This continues the series' pattern of methodical version bumps with comprehensive impact analysis, maintaining the CI system's reliability while keeping dependencies current. The change affects only `.github/workflows/main.yml`, replacing `v8` with `v9` in the `github-script` action reference.
