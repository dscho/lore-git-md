This is a refactoring patch in Taylor Blau's 16-part series implementing incremental MIDX/bitmap-based repacking for large repositories. The patch simplifies the logic for building the `keep_hashes` array by first collecting MIDX layers into a temporary array and then processing them in reverse order, rather than using reverse indexing during traversal.

The change makes the code more straightforward to follow by eliminating the need to mentally track reverse indexing while traversing forward. It also sets up for a planned future change to use `strvec` instead of manual array management. The patch includes an assertion to verify the final count matches expectations and properly cleans up the temporary array.

This is a mechanical improvement that doesn't change functionality but improves code clarity as part of the larger repacking infrastructure work. The series has already received thorough review from both object storage and process management experts, with all technical concerns addressed in previous iterations.
