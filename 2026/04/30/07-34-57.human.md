This is the third patch in Johannes Schindelin's 6-part CI/build system update series, focusing on bumping the `actions/github-script` dependency from v8 to v9 in Git's GitHub Actions workflow. The change is part of a broader effort to keep CI infrastructure current across all workflows.

The patch updates a single line in `.github/workflows/main.yml` that controls an optimization step checking whether a tree-SHA was already tested successfully. Schindelin provides a thorough analysis of the v9 changes, noting that none of the breaking changes (ESM-only module loading and `getOctokit` shadowing) affect Git's usage pattern. The script only uses the pre-supplied `github` REST client and `core` helpers, making the upgrade safe.

The commit message thoughtfully addresses risk mitigation - even if the script were to fail, the surrounding error handling would degrade gracefully to a warning without impacting CI execution. This continues the series' pattern of careful, transparent updates with detailed rationale for each version bump. The change is low-risk maintenance that keeps Git's CI system aligned with supported dependency versions.
