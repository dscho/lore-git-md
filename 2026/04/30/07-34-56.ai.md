This is a CI/build system update from Johannes Schindelin, part of a 6-patch series updating GitHub Actions dependencies. This specific patch (2/6) focuses on bumping the artifact upload/download actions to newer versions while maintaining their tight coupling.

The changes update:
- `actions/upload-artifact` from v5 to v7 (with one stray v4 instance also updated)
- `actions/download-artifact` from v6 to v8

Key motivations for these updates:
- Moves off deprecated Node.js 20 runtime to Node.js 24
- Maintains security contract between upload/download actions
- Adds stricter hash verification for downloaded artifacts (now fails on mismatch rather than warning)
- Aligns all upload-artifact versions to v7 for consistency

The commit provides thorough risk analysis showing these are safe mechanical updates:
- No workflow logic changes - only version bumps
- No usage of new optional features that could affect behavior
- GitHub-hosted runners already meet minimum version requirements
- Artifact format remains compatible between versions

The patch follows the series' pattern of careful version analysis while keeping changes minimal. It continues the effort to modernize CI infrastructure dependencies across all workflow files.
