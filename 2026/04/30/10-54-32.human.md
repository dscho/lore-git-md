This is a documentation patch that completes a series fixing HTTP authentication issue with Kerberos (SPNEGO) when using `http.emptyAuth=auto`. The patch explicitly documents the three accepted values for `http.emptyAuth` (auto/true/false) and their behaviors, which until now had to be inferred from context or source code.

The documentation clearly explains:
- `auto` (default) only sends empty credentials when the server's 401 response advertises a mechanism that requires them (like GSS-Negotiate)
- `true` unconditionally sends empty credentials on the first request
- `false` disables the feature entirely, making mechanisms like GSS-Negotiate fail

This patch follows three technical patches that were already reviewed and acked by Junio, addressing a conflict between 2015 and 2017 changes to HTTP authentication. The series is now complete with both code fixes and clear documentation, and has already been incorporated into Git for Windows 2.54.0-rc2. The changes are well-contained to HTTP authentication logic and have comprehensive test coverage.
