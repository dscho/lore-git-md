This thread introduces a new feature for Git's pretty-formatting capabilities, adding diff statistics placeholders to log output. The patch adds four new placeholders that expose commit diff statistics (`%(diff-stat:files)`, `%(diff-stat:insertions)`, `%(diff-stat:deletions)`, and `%(diff-stat:lines)`), along with shorter aliases where possible. The implementation is thorough, reusing Git's existing diffstat machinery while adding careful caching to avoid performance overhead when the placeholders aren't used.

The change touches documentation, core diff functionality, and pretty-format integration, with extensive test coverage that verifies behavior matches `--shortstat` output across various scenarios including normal commits, binary changes, and merges. The implementation handles edge cases well - for example, merge commits show 0 by default unless using diff-generating options like `-m` or `-c`. This provides users with a cleaner way to include change statistics in custom log formats without having to parse `--shortstat` output themselves.
