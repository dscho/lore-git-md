This is a refactoring patch in Taylor Blau's ongoing series implementing incremental MIDX/bitmap-based repacking for large repositories. The patch renames and exposes a previously internal function that checks if a packfile exists in a single MIDX layer (rather than recursively checking the entire MIDX chain).

The change is straightforward - it enables future code to specifically check whether a pack belongs to the tip MIDX, which will be useful for the incremental repacking logic. The patch maintains all existing behavior while making this single-layer checking capability available to other parts of the codebase.

This is part of the larger effort to improve Git's scalability for large repositories by avoiding periodic all-into-one repacks. The series has received thorough review from both object storage (Elijah Newren) and process management (Jeff King) experts, with this particular change being a small but necessary step in the implementation.
