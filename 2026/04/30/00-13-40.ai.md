This is a refactoring patch in Taylor Blau's ongoing series to implement incremental MIDX/bitmap-based repacking. The patch converts the `--write-midx` flag from a simple boolean to an `OPT_CALLBACK` that can handle multiple modes of operation, preparing for future expansion of MIDX writing capabilities.

The key changes are:
1. Introduces an enum `repack_write_midx_mode` with `NONE` and `DEFAULT` states to replace the boolean flag
2. Adds a callback function `option_parse_write_midx()` to handle the new flag parsing
3. Creates a dispatcher function `repack_write_midx()` that will select the appropriate MIDX-writing implementation based on mode
4. Updates all existing boolean checks to use the new mode enum

The patch maintains backward compatibility - passing just `-m` or `--write-midx` without arguments continues to use the default MIDX writing behavior. This is part of the infrastructure work needed to support the series' geometric and incremental MIDX repacking features.

The changes are mechanical but important for the series' architecture, allowing future patches to introduce new MIDX writing modes while keeping the command-line interface clean. The patch follows the incremental refactoring approach seen throughout the series, with each change focused and reviewable.
