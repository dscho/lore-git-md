This is a memory leak fix in Taylor Blau's ongoing MIDX/bitmap repacking series. The patch addresses an oversight where in-memory revindexes (used when packs lack on-disk *.rev files) were never freed. 

The change is straightforward - it adds a `FREE_AND_NULL()` call in `close_pack_revindex()` to clean up the `p->revindex` field. This fixes a memory leak that would otherwise be exposed by new test cases in the series. The commit message notes this was likely missed originally because the code predates Git's modern leak-checking test infrastructure.

This is a small but important cleanup that ensures proper resource management as part of the larger MIDX work. The patch follows the series' pattern of incremental improvements to support the new repacking strategies while maintaining correctness.
