This is a refactoring patch in Taylor Blau's 16-part series on incremental MIDX/bitmap-based repacking. The patch extracts common MIDX command preparation logic into a new `repack_prepare_midx_command()` helper function that will be reused for both `write` and `compact` subcommands in future patches.

The change moves the shared setup - setting `git_cmd`, pushing the subcommand/verb, and handling progress/bitmap flags - into the new helper, while leaving subcommand-specific arguments (like `--stdin-packs`) to the caller. This is a clean separation that maintains the existing functionality while making the code more maintainable for upcoming additions.

The patch follows the series' pattern of incremental refactoring to support the larger geometric repacking feature. It builds on prior infrastructure work (like the `existing_packs` struct changes in patch 7/16) while keeping each change focused and reviewable. The commit message clearly explains the motivation and confirms there are no functional changes, which is exactly what we want to see in a pure refactoring patch.
