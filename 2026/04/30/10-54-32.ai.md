This is a documentation patch completing a series that fixes HTTP authentication behavior with Kerberos (SPNEGO) when using `http.emptyAuth=auto`. The patch explicitly documents the three accepted values for `http.emptyAuth` (auto/true/false) and their behaviors, which until now had to be inferred from context or source code.

The documentation clarifies that:
- `auto` (default) sends empty credentials only for mechanisms like GSS-Negotiate that require them
- `true` always sends empty credentials on the first request
- `false` disables empty credentials entirely, breaking Negotiate auth

This matches the technical implementation from earlier patches in the series, which fixed a conflict between 2015 and 2017 changes to HTTP auth handling. The series has already been reviewed and acked by Junio, with this final documentation patch providing the missing user-facing explanation of the configuration options. The changes are well-contained to the HTTP authentication documentation and complete the solution by making the behavior explicit for users.
