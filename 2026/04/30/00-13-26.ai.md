This is a refactoring patch from Taylor Blau's ongoing series to improve MIDX/bitmap-based repacking for large repositories. The patch is part of a 16-patch series (this is patch 7/16) that introduces incremental repacking strategies.

The change moves the ODB (object database) source tracking from directly accessing `repo->objects->sources` to storing it in the `existing_packs` struct. While functionally equivalent (it still uses the first source in the list), this refactoring serves two purposes:
1. It prepares for the incremental MIDX repacking machinery which will need to know the source when reading existing MIDX/chain files
2. It future-proofs the code for potential support of multiple object sources in `git repack`

The patch is mechanical in nature - it adds the source field to the existing_packs struct, populates it during collection, and updates the two call sites that previously accessed the source directly. This appears to be a straightforward preparatory change that follows the project's incremental refactoring approach.
