This is patch 15/16 in Taylor Blau's series implementing incremental MIDX/bitmap-based repacking for large repositories. The patch introduces the `--write-midx=incremental` option for `git repack`, which enables the new incremental MIDX chain compaction strategy.

Key technical details:
- The new mode requires `--geometric` and adds two configuration knobs:
  - `repack.midxSplitFactor` (default 2) controls when adjacent MIDX layers merge
  - `repack.midxNewLayerThreshold` (default 8) sets the minimum pack count before tip packs are considered for repacking
- The implementation builds on earlier infrastructure patches to:
  - Track MIDX layers during geometric repacking
  - Preserve existing MIDX chains when creating new layers
  - Handle pack cleanup differently for incremental vs non-incremental modes
- Includes comprehensive tests covering:
  - Layer threshold behavior
  - Geometric compaction scenarios
  - Edge cases like kept packs and max-pack-size limits
  - Validation of configuration values

The patch represents a major milestone in the series, exposing the incremental MIDX strategy to users while maintaining safety through careful handling of pack cleanup and chain updates. It follows the incremental approach of the overall series, with each patch building on the last to create reviewable, focused changes.
