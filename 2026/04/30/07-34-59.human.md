This is the fifth patch in a 6-part CI/build system series from Johannes Schindelin, updating GitHub Actions dependencies. The patch specifically bumps the `git-for-windows/setup-git-for-windows-sdk` action from v1 to v2 to maintain compatibility as GitHub phases out Node.js 20 support.

The change is straightforward - updating the version reference in four workflow files where the Windows SDK setup action is used. The commit message explains this is a maintenance update with no functional changes to the SDK provisioning itself, just a Node.js runtime upgrade from 20 to 24. The action continues to provide the same minimal SDK environment and outputs.

This follows the pattern of the series - mechanical version bumps with thorough analysis of impacts. The change appears low-risk since GitHub's hosted runners already meet the minimum runner version requirement (2.327.1+). The patch maintains consistency of the series by bringing the Windows SDK setup action in line with the other Node.js 24 updates.
