This is a refactoring patch in Taylor Blau's ongoing series to improve MIDX/bitmap-based repacking for large repositories. The patch extracts common MIDX command preparation logic into a new helper function `repack_prepare_midx_command()` that can be reused for both `write` and future `compact` subcommands.

The change is purely structural - it moves the shared parts of command setup (git_cmd flag, subcommand/verb, progress and bitmap flags) into the new helper while leaving subcommand-specific arguments (like `--stdin-packs`) to the caller. This prepares for future additions that will need similar command setup.

The patch follows the series' pattern of incremental refactoring to support the larger goal of geometric MIDX repacking. It's a straightforward change that maintains existing behavior while making the code more maintainable. The patch has no functional impact but enables cleaner implementation of upcoming features in the series.
