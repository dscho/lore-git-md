This is a test patch in a bugfix addressing HTTP authentication behavior with Kerberos (SPNEGO) when using `http.emptyAuth=auto`. It's the third patch in a 4-part series that has already been reviewed and acked by Junio.

The patch adds two new test cases to verify the interaction between `http.emptyAuth` and servers advertising Negotiate authentication. The tests confirm that `auto` mode properly attempts Negotiate auth (resulting in three 401 responses before falling back to Basic credentials) while `false` mode skips Negotiate entirely (only one 401 response). The tests use curl tracing to count authentication attempts and verify the expected flow.

The test setup includes:
- Custom HTTP server responses with Negotiate and Basic auth challenges
- Credential helper configuration to provide test credentials
- Verification of the number of 401 responses in the trace output
- Checks that credential helper is queried with the expected authentication types

This completes the test coverage for the behavior changes introduced in earlier patches of the series. The tests are well-contained and follow Git's existing test patterns for HTTP authentication. With this addition, the series now has comprehensive test coverage for the Negotiate auth edge case that motivated the changes.
