This is a feature patch in Taylor Blau's series implementing incremental MIDX/bitmap-based repacking for large repositories. The patch introduces a new `--no-write-chain-file` option for MIDX write and compact operations, allowing callers to write new MIDX layers without immediately updating the chain file.

The key change is the addition of a flag that lets the MIDX machinery write a new layer to disk and output its checksum, while leaving the chain file untouched. This enables atomic updates where callers can assemble multiple layers before committing the final chain. The patch includes thorough documentation updates and tests verifying the new behavior.

This builds on the series' existing incremental MIDX infrastructure, adding flexibility for the repacking strategy to manage the chain file updates itself. The implementation maintains all safety properties while giving more control to the caller. The patch follows the series' pattern of careful error handling and includes validation to ensure `--no-write-chain-file` is only used with `--incremental`.

The changes are well-contained, touching only the MIDX write path while preserving existing behavior when the new flag isn't used. Test coverage verifies both the happy path and error cases, including proper validation of the flag combination. This is a focused addition that fits cleanly into the larger repacking effort.
