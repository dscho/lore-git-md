This is the fourth patch in Johannes Schindelin's CI/build system update series, bumping the `actions/checkout` dependency from v5 to v6 across all GitHub Actions workflows. The change is primarily motivated by moving to Node.js 24 runtime and staying on maintained versions.

The key behavioral change in v6 is that credentials are now stored in `$RUNNER_TEMP` rather than `.git/config`, improving security by reducing credential leakage risks. The patch includes a thorough risk analysis showing this change doesn't affect Git's CI workflows since they either check out the default repository or use explicit paths with `GITHUB_TOKEN` authentication. 

The update maintains the series' pattern of being purely a version bump with no workflow logic changes, accompanied by detailed commit message documentation of the implications. The diff shows mechanical updates to all workflow files using `actions/checkout`. This continues the series' low-risk maintenance approach to keeping CI infrastructure current.
