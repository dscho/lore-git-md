This is a refactoring patch in Taylor Blau's ongoing series to improve Git's repacking machinery for large repositories. The patch is part of a 16-part series implementing incremental MIDX/bitmap-based repacking.

The change moves the tracking of the object database (ODB) source from directly accessing `repo->objects->sources` to storing it in the `existing_packs` struct. While this doesn't change functionality yet, it serves two purposes: (1) it prepares for the incremental MIDX repacking feature which needs to know the source when reading existing MIDX files, and (2) future-proofs the code for potential support of multiple object sources.

The patch is straightforward - it adds the source field to the struct, initializes it during collection, and updates the call sites to use the new field. This appears to be a clean preparatory change in the larger series that has already undergone thorough review from both object storage and process management experts.
