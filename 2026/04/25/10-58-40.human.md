This is the final patch in Johannes Schindelin's CI/build system update series, bumping the `mshick/add-pr-comment` action from v2 to v3 in Git's localization workflow. The change is motivated by GitHub's planned deprecation of Node.js 20, which v2 relies on, in favor of Node.js 24 in v3.

The patch follows the same careful pattern as the rest of the series - a mechanical version bump accompanied by thorough analysis of the implications. Schindelin notes this is a drop-in replacement with no breaking changes for Git's usage pattern, and that subsequent v3.x features (like message truncation and retry logic) won't affect the existing workflow since they're opt-in. The change completes the set of GitHub Actions updates across Git's CI system.

This appears to be a low-risk maintenance update to keep CI infrastructure on supported versions. The series as a whole shows Schindelin's characteristic attention to detail in analyzing each dependency change's impact, even when the changes seem straightforward. With this fifth patch, all GitHub Actions used by Git's CI are now updated to versions running on Node.js 24.
