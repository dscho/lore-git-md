It already does, doesn't it? Doing:

```
  $ git init
  $ git remote add --fetch origin /path/to/some/repo
  $ git for-each-ref

```

shows an origin/HEAD link.

Which I think is not too surprising, as it is just calling "git fetch"
under the hood.
