This is a CI/build system update from Johannes Schindelin, part of his v2 series updating GitHub Actions dependencies. The patch focuses on bumping the versions of `actions/upload-artifact` (from v5 to v7) and `actions/download-artifact` (from v6 to v8) across all workflow files in `.github/workflows/main.yml`.

The changes are motivated by GitHub's deprecation of Node.js 20, which these actions currently use by default. The version bumps transition the actions to Node.js 24 while maintaining compatibility. Schindelin provides a thorough risk analysis, noting that the changes are safe because:
1) The upload/download functionality remains unchanged (no new parameters are used)
2) The ESM conversion in the actions doesn't affect Git's workflows
3) The stricter hash verification in download-artifact v8 is actually beneficial for security

The patch also aligns one remaining `upload-artifact@v4` usage with the new v7 standard. All changes are mechanical version bumps with no workflow logic modifications, following the pattern established in the rest of the series. The commit message includes detailed references to the upstream release notes and comparisons, showing careful vetting of each change.

This appears to be a low-risk maintenance update to keep CI infrastructure on supported versions, with no functional impact on Git's test workflows. The patch maintains the series' pattern of thorough documentation and safety analysis for each dependency update.
