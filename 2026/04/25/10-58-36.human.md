This is the first patch in Johannes Schindelin's v2 series updating GitHub Actions dependencies in Git's CI system. The patch bumps `microsoft/setup-msbuild` from v2 to v3, a necessary update since GitHub is phasing out Node.js 20 support in their runners and v3 moves to Node.js 24.

The commit message provides a thorough risk analysis, noting this is a minimal change that only updates the Node.js runtime without altering the action's functionality (it still just adds `msbuild.exe` to PATH). The change is mechanical and low-risk, originating from Dependabot but carefully reviewed by Schindelin. 

This maintains compatibility with GitHub's evolving CI infrastructure while keeping the Windows build jobs working. The patch includes links to release notes and a diff between versions for transparency. As with the rest of the series, this appears to be routine maintenance to keep CI current rather than introducing new functionality.
