This is part 4 of Johannes Schindelin's CI/build system update series, bumping the `actions/checkout` dependency from v5 to v6 across all GitHub Actions workflows. The change is mechanical but comes with a thoughtful analysis of the implications.

The key behavioral change in v6 moves credential storage from `.git/config` to `$RUNNER_TEMP`, which improves security by preventing accidental credential leakage in artifacts. Schindelin notes this doesn't affect Git's CI since the workflows either check out the main repository (no special credentials) or explicitly specify `microsoft/vcpkg` with path parameters. The analysis confirms GitHub's runners already meet the minimum version requirement for this change.

The patch follows the series' pattern of thorough impact assessment, linking to release notes and changelogs. It originated from Dependabot's automated version checks in Git for Windows but has been carefully reviewed and documented by Schindelin. The change appears low-risk as it maintains existing functionality while keeping the CI infrastructure on supported versions.
