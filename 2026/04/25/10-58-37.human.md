This is a CI/build system update from Johannes Schindelin, part of a 5-patch series updating GitHub Actions dependencies. This specific patch (2/5) focuses on bumping the `actions/upload-artifact` and `actions/download-artifact` versions to v7 and v8 respectively.

The changes are mechanical version bumps in `.github/workflows/main.yml`, but come with thorough analysis in the commit message. The key motivations are:

1. Moving off Node.js 20 (which GitHub is deprecating) to Node.js 24
2. Keeping the tightly-coupled upload/download actions in sync to maintain artifact format compatibility
3. Addressing one stray v4 usage of upload-artifact to standardize on v7

Schindelin provides detailed risk assessment showing these changes won't affect Git's CI behavior since:
- The new ESM conversion in these actions doesn't impact Git's usage
- The zip-based artifact handling remains unchanged
- The stricter hash verification in download-artifact v8 is actually a security improvement

The patch originates from Dependabot's automated version checks but has been carefully reviewed and augmented with this safety analysis. As with the rest of the series, this appears to be low-risk maintenance to keep CI infrastructure on supported versions.
