This is part 2 of a 4-patch series implementing silent autostash creation for conflicted branch switches. The series has already been through extensive review and is now in its final polishing stage.

The patch adds a silent mode to autostash creation by introducing a new `create_autostash_ref_silent()` function that suppresses the "Created autostash" message. This builds on the existing autostash infrastructure in `sequencer.c`, adding a boolean `silent` parameter to the internal implementation function and exposing the silent variant through a new public API. The change is straightforward - it enables callers (particularly `git checkout -m`) to stash changes without printing status messages when that would be disruptive to the user experience.

The implementation maintains all existing behavior while adding the new capability, with the default remaining non-silent for backward compatibility. This is a clean, focused change that completes one piece of the larger autostash enhancement effort. With the refname convention now finalized (`CHECKOUT_AUTOSTASH_HEAD`) and all technical concerns addressed in previous rounds, this series appears ready for merging.
