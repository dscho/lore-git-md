This is the first patch in a v10 series implementing unified conflict resolution in `git checkout -m` through autostash behavior. The series has already received maintainer approval and this iteration finalizes the naming convention for the autostash ref.

The current patch adds new `--label-ours`, `--label-theirs`, and `--label-base` options to `git stash apply`, allowing customization of conflict markers. The labels can be empty strings to produce minimal markers. The implementation touches the stash command's documentation, core logic in `builtin/stash.c`, and adds comprehensive tests in `t/t3903-stash.sh`. The changes are well-contained and focused, with clear documentation updates and test coverage for both normal and non-empty label cases.

This is a polished patch that has gone through multiple rounds of review, including from Phillip Wood and Jeff King. The functionality is straightforward and provides useful customization for conflict resolution workflows. With the naming convention now finalized (`CHECKOUT_AUTOSTASH_HEAD`), the series is ready for merging.
