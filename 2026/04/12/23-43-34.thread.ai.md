Proposed new `git recall` command for formatted commit activity summaries. RFC from Ammaar Bakshi with working C implementation. Command would show commits grouped by date with --day/--week/--month/--year time windows, aiming to simplify standup/review workflows currently requiring complex `git log` invocations. Parallels `git switch`/`git restore` simplification of `git checkout`. Open questions: core Git scope appropriateness, command naming (`recall` vs `activity`), prior art discussion. Implementation exists as standalone tool, ready for potential integration. Key technical elements: date-grouped output format (hashes, messages, authors, times) and time window flags. Expected discussion focus: justification for new porcelain command vs improving existing `git log` documentation/ergonomics.
