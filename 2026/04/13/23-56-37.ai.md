This is a bugfix series targeting the pseudo-merge bitmap implementation, addressing several issues that were preventing the feature from working correctly. The series comes from Taylor Blau, who has been a primary contributor to Git's pack and bitmap subsystems.

The cover letter explains that Jeff King (Peff) noticed the pseudo-merge code path wasn't being exercised by the test suite, which led to uncovering multiple bugs. The series starts by adding test infrastructure (a new test helper and failing tests), then fixes the identified issues in both the lookup and group selection logic. Key fixes include:
- Incorrect sorting of the pseudo-merge commit table
- A swapped binary search implementation
- Multiple compounding bugs in extended lookup paths
- Date parsing issues in group selection
- A division-by-zero risk in config validation

The series touches core bitmap writing and pseudo-merge handling code, with changes to both the implementation and test coverage. Given Taylor's deep involvement in this area and the thorough test additions, this appears to be a well-motivated and carefully constructed fix series. The bugs being fixed were clearly impacting functionality, and the test additions will help prevent regressions. The changes are focused on the impact is significant - pseudo-merge bitmaps are an important performance optimization for large repositories.
