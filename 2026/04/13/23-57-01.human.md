This is the final patch in Taylor Blau's series fixing bugs in the pseudo-merge bitmap implementation. It addresses a memory leak that occurs when re-assigning the same pattern to a pseudo-merge group multiple times.

The patch fixes a case where the `pattern` configuration for a pseudo-merge group could leak memory when set more than once. Previously, if a pattern was reassigned, the old compiled regex would be freed without first calling `regfree()`, leaking its internal state. The fix properly cleans up the old regex before replacing it.

The change is straightforward - it adds a NULL check and proper cleanup before freeing the old pattern. The patch also adds a test case that verifies the fix by setting the same pattern twice and confirming no leaks occur. This maintains the series' pattern of thorough test coverage for each bugfix.

As with the rest of the series, this comes from Taylor Blau, a key contributor to Git's pack and bitmap subsystems, and addresses an issue found through Jeff King's review of test coverage gaps. The change is small but important for correctness, and fits well with the series' goal of making pseudo-merge bitmaps more robust.
