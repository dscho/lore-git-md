This is the third patch in Taylor Blau's series fixing bugs in pseudo-merge bitmaps, a performance optimization for large repositories. The patch addresses a critical issue where the commit lookup table was being sorted incorrectly, causing the binary search for pseudo-merges during fill-in traversal to fail.

The key fix changes how commits are sorted in the lookup table - from lexical (OID) order to pack position order, which is what the bitmap reader expects. While this technically changes the on-disk format, the author notes this is acceptable since the previous behavior was effectively broken. The patch includes a test that now passes, demonstrating the fix works.

This appears to be a well-justified change from a domain expert (Taylor Blau) that fixes a real functional issue while maintaining backward compatibility. The thorough explanation and test update give confidence in the fix. The patch is part of a larger effort to stabilize pseudo-merge bitmaps after Jeff King identified test coverage gaps.
