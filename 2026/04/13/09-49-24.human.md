This is part of Patrick Steinhardt's ongoing series to make Git's test suite more robust by enabling `set -e` (errexit) in test scripts. The current patch focuses on fixing the `stop_git_daemon()` helper function to work with strict error checking.

The patch modifies how the test suite stops background git-daemon processes to handle two issues that would cause failures under `set -e`: the `wait` call (which is expected to fail) and a redundant `kill` attempt (which may fail harmlessly). The changes wrap these operations in conditionals to prevent them from aborting the test script prematurely.

This is a mechanical but important preparation step in the larger effort to enable stricter error checking across the test suite. The changes are focused and well-explained, with clear reasoning for each modification. As with the rest of the series, this patch maintains all existing behavior while paving the way for more reliable test execution.
