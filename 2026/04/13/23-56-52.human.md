This is the fifth patch in Taylor Blau's bugfix series for pseudo-merge bitmaps, addressing issues in how shared commits (those appearing in multiple pseudo-merge groups) are handled. The patch fixes three distinct bugs in the extended lookup path for shared commits.

The first bug was an undercounting issue when writing the extended lookup table, causing offsets to point to wrong locations. The second bug involved incorrectly parsing pseudo-merge bitmap data as commit table entries. The third was a latent error-checking issue that could mask corruption problems. The fixes are accompanied by a test case that now passes, demonstrating correct behavior with overlapping pseudo-merge groups.

This continues the series' pattern of thorough fixes backed by comprehensive test coverage. The changes are focused on the commit message clearly explains both the problems and solutions. Given Taylor's expertise in this area and the careful approach taken throughout the series, these changes appear well-considered and important for the correct functioning of pseudo-merge bitmaps.
