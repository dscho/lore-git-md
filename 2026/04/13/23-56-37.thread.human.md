Taylor Blau continues his series fixing bugs in the pseudo-merge bitmap implementation, with this patch addressing a critical issue in date-based commit classification. The problem stemmed from unparsed commit timestamps causing all commits to appear as having zero timestamps, which completely broke the "stable" vs "unstable" commit distinction that pseudo-merge groups rely on. 

Jeff King originally identified the test coverage gaps that revealed these issues, and Taylor is systematically working through them. The latest fix ensures commit dates are properly parsed before classification, demonstrated by a new test case that shows the correct behavior when using timestamp-based grouping. The test uses `GIT_TEST_DATE_NOW` to create reliable test conditions.

This follows earlier patches that established test infrastructure and fixed issues in the lookup table sorting, binary search implementation, and extended lookup path handling. The series is methodically addressing both the immediate bugs and the underlying test coverage gaps that allowed them to slip through. These fixes are particularly important as pseudo-merge bitmaps are a key performance optimization for large repositories.
