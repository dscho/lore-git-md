Taylor Blau is working on a series to fix several bugs in the pseudo-merge bitmap implementation, following Jeff King's discovery that key code paths lacked test coverage. The first patch introduces a new `test-tool bitmap write` helper that enables precise testing of bitmap generation by allowing specific commits to be selected for bitmap creation. This fills an important gap in testing capabilities, as there was previously no standard way to test bitmap generation with exact commit selection.

The test helper supports both regular commit bitmaps and pseudo-merges while respecting the relevant configuration. It will be used in subsequent patches to expose and fix the identified bugs, which include issues with sorting, binary search, date parsing, and config validation in the pseudo-merge code paths. Given his expertise in the pack/bitmap subsystems, Taylor's approach of first establishing robust test infrastructure before fixing the bugs is a sound strategy for addressing these performance-critical issues.
