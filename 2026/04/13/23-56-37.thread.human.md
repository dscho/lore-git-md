Taylor Blau has posted an eight-patch series fixing several bugs in Git's pseudo-merge bitmap implementation, a performance-critical feature for large repositories. The series begins by adding test infrastructure (a new `test-tool bitmap write` command) and comprehensive test cases that demonstrate the issues, followed by fixes for problems ranging from incorrect sorting in lookup tables to memory leaks in pattern handling.

Junio C Hamano, the Git maintainer, has begun reviewing the series and raised an important concern about the first patch's implementation. He identified a potential memory safety issue in the test helper's object packing code, where stored pointers to `object_entry` structures could become invalid if the array is reallocated. This is a serious concern that needs resolution before the test infrastructure can be trusted to verify the subsequent fixes. Junio's review is characteristically thorough - he presents the issue as an open question rather than outright rejection, inviting Taylor to either explain the safety or propose a solution.

The series remains under active discussion, with the test infrastructure being scrutinized before the substantive bugfixes can proceed. Jeff King originally identified the lack of test coverage that revealed these issues, and Taylor has built comprehensive test cases that both demonstrate the bugs and will verify their fixes. The maintainer's engagement on this foundational piece suggests the series may need some iteration before being ready for merging.
