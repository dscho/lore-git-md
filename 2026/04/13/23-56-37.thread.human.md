Taylor Blau's nine-patch pseudo-merge bitmap bugfix series has been accepted and queued by maintainer Junio C Hamano. The series fixes multiple compounding bugs in the pseudo-merge bitmap implementation: incorrect binary-search sort order, a swapped comparator, extended-table offset and parsing errors, group-selection logic that rendered the `stableThreshold` and `sampleRate` configuration options completely inert, a latent division-by-zero crash when `sampleRate` is exactly zero, stale documentation, and a memory leak from duplicate pattern config keys. The existing test suite had never exercised the core pseudo-merge selection function before this series.

Junio confirmed the series is queued ("Queued. Thanks.") and expanded on his earlier guidance about how to write helpful rebase notes in cover letters. He noted that rebasing onto an older maintenance release for backporting is a particularly good reason to document the rebase, and mused that after collecting a few more examples, they should be documented in `Documentation/SubmittingPatches`. This was a minor aside, not a commitment. The thread is concluded with no further action expected.
