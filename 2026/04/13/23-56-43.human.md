This is the second patch in Taylor Blau's bugfix series for pseudo-merge bitmaps, adding test cases that demonstrate several issues in the implementation. The patch introduces five new test scenarios, four marked as expected failures (highlighting current bugs) and one passing test (for a latent bug that will be exposed by later fixes).

The tests cover:
1. Basic pseudo-merge application during bitmap traversal
2. Handling multiple pseudo-merge groups simultaneously
3. Correct behavior with overlapping group patterns
4. Proper date-based classification of commits
5. Safe handling of zero sample rates (the one passing test)

Each test sets up a repository with specific pseudo-merge configurations, generates bitmaps using the new test helper from patch 1, then verifies expected behavior. The failing tests will be fixed in subsequent patches, with the commit messages explaining each issue in detail.

The test cases are thorough and well-constructed, exercising different aspects of the pseudo-merge bitmap logic. This is a typical pattern in Git development - first demonstrate the bugs with failing tests, then fix them one by one. The series comes from Taylor Blau, who is deeply familiar with Git's bitmap code, and addresses issues originally spotted by Jeff King, another expert in this area.
