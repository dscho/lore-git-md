This is patch 6/9 in a documentation series clarifying `git-interpret-trailers` behavior, specifically addressing the format requirements for trailer keys. The patch explicitly states that keys must use only alphanumeric ASCII characters and hyphens, closing a documentation gap where this restriction was previously only implied by examples.

The change is straightforward - it inserts one sentence defining the key format into the existing description of trailers. The commit message notes this prevents readers from having to infer the rules from examples (which didn't show numeric digits, though they are allowed). The patch follows maintainer feedback to remove an unclear "paint by numbers" reference from v1.

This continues the series' pattern of making the trailer syntax rules more discoverable while maintaining technical accuracy. The change is small but meaningful, as it documents a restriction that previously caused confusion (the original bug report involved keys with periods being silently rejected). The series as a whole has been through multiple rounds of review and appears ready for merging.
