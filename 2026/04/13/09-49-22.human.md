Test infrastructure improvement: preparing signal tests for `set -e` enforcement.

This is the first patch in Patrick Steinhardt's 12-part series to make Git's test suite more robust by enabling `set -e` (errexit) in test scripts. The change modifies signal-handling tests to work correctly when `set -e` is active, which would otherwise cause these tests to fail prematurely.

The patch updates three test cases that verify Git dies with SIGPIPE (tests for commands that fail when their output pipe is closed). The original tests used a pattern that would break under `set -e` because they executed a failing command followed by `echo $?`. The new version uses `||` instead of `;` to ensure the exit code check runs even when the command fails.

This is a mechanical but important change that follows the series' pattern of preparing test infrastructure before flipping the `set -e` switch. The modifications are straightforward and focused on test reliability rather than changing Git's behavior. Reviewers will want to verify the signal tests still accurately detect the expected failures after this change.
