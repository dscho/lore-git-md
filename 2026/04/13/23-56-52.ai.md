Bugfix for pseudo-merge bitmap extended lookup path. This is the fifth patch in Taylor Blau's series addressing multiple issues in the pseudo-merge bitmap implementation, following Jeff King's discovery of test coverage gaps.

The patch fixes three distinct bugs in the extended lookup path for commits that appear in multiple pseudo-merge groups:
1. A write-side miscalculation where extended table offsets were being written incorrectly due to undercounting entry sizes (12 bytes vs 8)
2. A read-side issue where bitmap offsets were being misinterpreted as commit table entries
3. A latent error-checking bug that could silently ignore corruption

The changes are focused on the patch includes:
- Fixing the size calculation in `write_pseudo_merges()`
- Simplifying `nth_pseudo_merge_ext()` to directly store offsets rather than re-parsing
- Correcting the error check in `apply_pseudo_merges_for_commit()`
- Marking a previously failing test case as passing

The fixes ensure proper handling of commits that belong to multiple pseudo-merge groups, which is critical for the feature's correct operation. The patch maintains the safety properties of the implementation - while fixing the bugs could improve performance by enabling more optimizations, it doesn't affect correctness of results. The thorough test case updates demonstrate the fixes working as intended.
