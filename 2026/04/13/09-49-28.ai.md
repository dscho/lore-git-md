This is part 7 in Patrick Steinhardt's 12-patch series to prepare Git's test suite for `set -e` (errexit) usage. The patch focuses on fixing the cleanup handlers `test_when_finished()` and `test_atexit()` to work correctly with strict error checking enabled.

The core issue is that the current implementation uses `&&` chaining to preserve the test's exit code during cleanup, which would break under `set -e` when the original test fails (non-zero exit). The patch changes this to use `||` instead, which both simplifies the logic and maintains the desired behavior in all cases - preserving the test's original exit code unless the cleanup itself fails.

The change is mechanical but important for test reliability, touching the core `test-lib-functions.sh` infrastructure. The commit message includes clear truth tables showing the behavior before and after the change, demonstrating the equivalent outcomes while making the code `set -e` safe. This continues the series' pattern of methodically preparing test infrastructure before the final switch to enable `set -e`.
