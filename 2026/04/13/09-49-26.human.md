This is part 5 of Patrick Steinhardt's test infrastructure series to prepare Git's test suite for `set -e` (errexit) mode. The patch fixes conditional test execution patterns that would break under strict error checking.

The change addresses test scripts that use `test ... && test_expect_success` patterns to conditionally run tests. Currently, when the condition fails, the test is skipped but the overall command fails - which would cause `set -e` to abort the script prematurely. The patch converts these to proper `if` statements that cleanly skip tests without failing.

Two test files are modified:
- `t4032-diff-inter-hunk-context.sh` - changes file existence checks
- `t7450-bad-git-dotfiles.sh` - modifies symlink test conditions

The changes are mechanical but important for the test suite's robustness. This continues the series' pattern of preparing infrastructure before enabling `set -e` globally. The patch appears well-tested and follows Git's test modernization efforts. Reviewers should verify the conditionals still correctly skip tests when intended.
