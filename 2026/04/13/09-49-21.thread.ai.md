This doesn't impact the current series but documents an important shell behavior quirk for future test authors using `set -e` in helper functions.

The latest refinement addresses signal handling edge cases when testing SIGPIPE behavior (signal 13) in Git commands. Patrick's solution modifies three test cases across t0005-signals.sh (two cases) and t3600-rm.sh (one case) to use `command && echo 0 1>&3 || echo $? 1>&3` pattern with file descriptor redirection, ensuring explicit capture of both success and failure exit codes. Junio approves this approach as slightly preferable to variable-based status storage, though notes the verbosity. This resolves his earlier concern about silent failures when commands unexpectedly succeed under `set -e`.
