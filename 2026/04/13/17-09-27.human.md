This is part 6/12 of Patrick Steinhardt's series to prepare Git's test suite for `set -e` mode, focusing on prerequisite checks for external binaries. Junio Hamano reviews the changes that modify how tests verify the availability of tools like svn, cvs, and git itself.

The patch converts direct command execution followed by exit code checks into conditional statements, which is necessary for `set -e` compatibility. Junio approves the changes overall but suggests using `git version` instead of relying on the exit code from a bare `git` command, since the version command provides a more reliable success indicator.

This continues the careful, incremental approach seen throughout the series - each patch tackles a specific category of test patterns that would break under strict error checking. The changes are mechanical but important for maintaining test reliability. Junio's review indicates the patch is nearly ready, needing only the minor adjustment to the git binary check before being queued.
