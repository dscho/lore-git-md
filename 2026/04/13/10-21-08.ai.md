Documentation patch completing the git-interpret-trailers man page coverage by documenting comment line handling. This is the final patch in Kristoffer Haugsbakk's 9-part series that systematically improves the trailer documentation.

The patch adds a brief but important note that git-interpret-trailers ignores comment lines (those marked by core.commentString), primarily for compatibility with commit hooks. While this behavior is unlikely to surprise users, the addition makes the documentation properly comprehensive about all input processing rules. The change fits naturally alongside the existing description of trailer block parsing.

This concludes the series that began with a bug report about period-containing keys and evolved into a thorough documentation overhaul. All patches have been reviewed and approved, with this final piece addressing the last remaining gap in the spec. The series now provides complete, clear documentation of git-interpret-trailers' behavior, from key format restrictions to comment handling.
