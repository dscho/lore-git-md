This is part 6 of Patrick Steinhardt's 12-patch series to prepare Git's test suite for `set -e` (errexit) mode, continuing the test infrastructure improvements discussed earlier in the thread.

The patch modifies several test scripts that check for executable availability (like `svn`, `cvs`, and `git` itself) to run these checks inside conditionals rather than relying on the exit code being checked afterward. This change is necessary because with `set -e` enabled, a failed command would immediately abort the test script rather than allowing the subsequent exit code check.

Key changes include:
- Converting `command && test $? -ne 1` patterns to `if ! command` in test prerequisites
- Updating checks in `t/lib-git-svn.sh`, `t/lib-httpd.sh`, and several CVS-related test scripts
- Modifying the core `test-lib.sh` to check Git binary availability with proper error handling

The changes are mechanical but important for test reliability under `set -e`. This continues the series' pattern of preparing infrastructure before enabling the stricter error checking. The patch follows the established approach of the series and appears well-tested, though reviewers will want to verify the modified conditionals don't introduce any false negatives in test skipping behavior.
