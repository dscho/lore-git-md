This is a test infrastructure change in Patrick Steinhardt's ongoing series to prepare Git's test suite for `set -e` mode. The patch modifies prerequisite checks in several scripts to properly handle command failures under strict error checking.

Junio Hamano reviews the changes and finds them generally sound, suggesting one potential improvement: using `git version` instead of a bare `git` command for the Git binary check in test-lib.sh, since it provides a more reliable exit code (0 for success). The changes convert various prerequisite checks (for svn, cvs, httpd, and git) from post-command exit code examination to direct conditional execution, making them compatible with `set -e`.

The patch follows the established pattern of the series by making mechanical but important changes to ensure test reliability. Junio's feedback indicates the approach is correct but could be slightly refined in one case. This continues the careful, incremental work to modernize Git's test infrastructure while maintaining compatibility with existing test behavior.
