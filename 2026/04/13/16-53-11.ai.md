This is a test infrastructure patch in Patrick Steinhardt's series to make Git's test suite work with `set -e` (errexit) enabled. The patch modifies the `stop_git_daemon()` helper function to properly handle expected failures when killing background daemon processes.

Junio Hamano reviews the changes and agrees with the approach of silencing the second `kill` call with `|| :` since the daemon may already be terminated. He notes the same stylistic comment applies here as in patch 02/12 (though the specific comment isn't shown in this excerpt). The changes ensure the test suite won't abort when:
1. The `wait` command fails (as it should when killing the daemon)
2. The second kill attempt fails (since the process is already dead)

The patch maintains the function's error checking behavior while making it safe for `set -e`. This is a mechanical but important change in the larger effort to enable stricter error checking across Git's test framework. Junio's review suggests the approach is sound, though he hints at a minor stylistic improvement that likely matches his feedback on the previous patch in the series.
