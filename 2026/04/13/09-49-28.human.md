This is part 7 of Patrick Steinhardt's test infrastructure series to prepare Git's test suite for `set -e` (errexit) mode. The patch focuses on fixing the cleanup handlers `test_when_finished()` and `test_atexit()` to work correctly with strict error checking.

The change modifies how these functions preserve the test's exit code during cleanup operations. The current implementation uses `&& (exit "$eval_ret")` which would break under `set -e` when the test fails (non-zero `eval_ret`). The patch replaces this with a simpler `|| eval_ret=$?` pattern that maintains the same behavior while being `set -e` safe.

The commit includes clear truth tables showing the behavior before and after the change, demonstrating that the modification preserves all existing cases while fixing the `set -e` interaction. This is a well-explained, focused change that continues the series' pattern of carefully preparing test infrastructure before enabling strict error checking.
