This is a feature patch series that enhances `git checkout -m` with autostash behavior during conflicted branch switches, now in its 10th iteration and ready for merging. The series has undergone extensive review from Phillip Wood and Jeff King, with Junio C Hamano giving final approval after the last remaining issue (the autostash refname convention) was resolved in v10 by renaming it to `CHECKOUT_AUTOSTASH_HEAD`.

The main improvements include automatic stashing of uncommitted changes during conflicted branch switches (similar to existing rebase/merge behavior), new `--label-*` options for customizing conflict markers in `git stash apply`, and silent autostash creation. The implementation touches multiple components with thorough test coverage.

Junio notes one remaining usability tweak from his real-world testing - the autostash message could be more descriptive by including the destination branch name (e.g., "autostash while switching to 'topic'"). This is a minor polish item that doesn't block merging, as the core functionality is solid and all technical concerns have been addressed. The series represents a significant quality-of-life improvement for branch switching workflows.
