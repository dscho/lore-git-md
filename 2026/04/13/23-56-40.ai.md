This is a test infrastructure patch in Taylor Blau's series fixing pseudo-merge bitmap bugs. It introduces a new `test-tool bitmap write` subcommand to enable precise testing of bitmap generation, particularly for pseudo-merges.

The new helper allows writing bitmaps for specific commits in a controlled way, reading commit OIDs from stdin. This fills a gap in testing capabilities - previously there was no standard way to test bitmap generation with exact commit selection. The implementation handles both regular commit bitmaps and pseudo-merges (respecting the `bitmapPseudoMerge.*` config).

Key technical details:
- Adds new function `bitmap_write()` to test-bitmap.c
- Implements pack file lookup and bitmap generation with configurable commit selection
- Includes test case verifying basic functionality in t5310-pack-bitmaps.sh
- Maintains existing bitmap writer infrastructure while adding test-specific control

This is the first of eight patches addressing pseudo-merge bitmap issues identified by Jeff King. The test helper will be used in subsequent patches to expose and fix the bugs. Given Taylor's expertise in this area and the careful construction of the test infrastructure, this appears to be a solid foundation for the fixes to follow.
