This is a bugfix series targeting the pseudo-merge bitmap functionality, addressing several issues that were preventing the feature from working correctly. The series comes from Taylor Blau, who has been a key contributor to Git's pack and bitmap subsystems.

The cover letter explains that Jeff King (Peff) noticed the pseudo-merge code path wasn't being exercised by the test suite, which led to uncovering multiple bugs. The series starts by adding new test infrastructure (a bitmap writing helper and failing tests), then systematically fixes the issues:

1. The commit lookup table was incorrectly sorted by OID rather than bit position
2. A binary search had its bounds checking reversed
3. Multiple compounding bugs in the extended lookup path
4. Commit date parsing was missing, causing incorrect grouping
5. A config validation issue allowing division by zero
6. A memory leak in pattern handling

The series adds substantial test coverage (230 lines of new tests) to prevent regression. Given Taylor's deep expertise in this area and the thorough approach (first demonstrating the bugs, then fixing them), this appears to be a high-quality contribution that should improve the reliability of pseudo-merges in bitmap operations. The changes are focused and well-explained, making this likely to be uncontroversial and quickly accepted.
