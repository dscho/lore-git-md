This is a bugfix patch in Taylor Blau's series addressing issues in the pseudo-merge bitmap implementation. The patch specifically handles a division-by-zero risk when the `bitmapPseudoMerge.*.sampleRate` configuration is set to 0.

The fix changes the config validation to reject a sampleRate of 0 (while still accepting values between 0 and 1), preventing undefined behavior that would happen when casting infinity to uint32_t. This issue became reachable after the previous patch fixed date-based commit classification, which had been masking the problem by incorrectly marking all commits as stable.

The patch includes both the code change (updating the validation check and warning message) and updates the corresponding test case from `test_expect_failure` to `test_expect_success`, demonstrating the fix works. This is part of a larger effort to make pseudo-merge bitmaps reliable, with each patch in the series building on the last to address different aspects of the implementation.
