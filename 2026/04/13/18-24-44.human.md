This is a CI/build system patch from the Git maintainer Junio C Hamano. It fixes a minor inconsistency in the GitHub Actions configuration where one job was still using an older version (v4) of the actions/checkout action while all others had been updated to v5.

The patch explains this was caused by a timing coincidence - a new job using v4 was added just before another change updated everything to v5, resulting in this one job being missed. The update helps move away from Node.js 20, which GitHub Actions was complaining about.

The change is straightforward - a one-line update to the workflow file to use v5 checkout action instead of v4. As a maintenance fix from the maintainer himself, this is clearly correct and uncontroversial, though very minor in scope. It's the kind of housekeeping patch that will likely be merged without discussion.
