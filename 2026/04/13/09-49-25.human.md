This is part 4 of Patrick Steinhardt's 12-patch series to prepare Git's test suite for `set -e` (errexit) mode. The patch focuses on making `git config --unset` calls resilient to failures when the configuration being unset doesn't exist.

The changes are mechanical but important - they modify several test scripts to append `|| :` after `git config --unset` calls. This silences the error when unsetting a non-existent config, which would otherwise cause the test to fail under `set -e`. The affected tests include t4032 (diff hunk context), t7508 (status), and t9138 (SVN authors).

This patch continues the series' pattern of making test infrastructure changes before enabling `set -e` globally. The modifications are low-risk since they only affect test cleanup code that was already meant to be non-fatal. The changes align with the project's ongoing test modernization efforts and follow Junio Hamano's earlier discussion about using `set -e` for more robust test execution.
