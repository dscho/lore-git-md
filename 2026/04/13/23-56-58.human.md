This is a bugfix patch in Taylor Blau's series addressing issues with pseudo-merge bitmaps. The patch fixes a division-by-zero risk in the configuration validation for pseudo-merge sampling rates.

The problem occurs when `bitmapPseudoMerge.*.sampleRate` is set to 0, which leads to undefined behavior when casting infinity to an integer during commit selection. The patch changes the validation to reject 0 (requiring values strictly between 0 and 1) and updates the warning message to be more precise. A previously failing test is now marked as passing.

This is the seventh patch in an eight-part series that started with Jeff King identifying test coverage gaps in the pseudo-merge bitmap implementation. The series has been methodically adding test infrastructure and fixing discovered issues, with this patch addressing one of the final edge cases. Given Taylor's deep involvement in the bitmap subsystem and the thorough test coverage being added, this appears to be a well-justified fix for a real issue that was previously hidden by other bugs.
