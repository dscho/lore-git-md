[PATCH v1 0/5] fix pseudo-merge bitmap bugs

Thread identity: Bugfix series for pseudo-merge bitmaps from Taylor Blau (primary contributor to pack/bitmap subsystems), addressing issues found by Jeff King. Follow-up to discovery of missing test coverage.

Core problem: Multiple compounding bugs in pseudo-merge bitmap implementation affecting lookup paths (incorrect sorting, swapped binary search, extended lookup miscalculations) and group selection logic (date parsing, config validation). Series establishes test infrastructure then fixes issues.

Key technical details:
- New `test-tool bitmap write` subcommand (patch 1) enables controlled testing of bitmap generation
- t5333-pseudo-merge-bitmaps.sh (patch 2) adds comprehensive test cases demonstrating:
  - Fill-in traversal failures with single/multiple pseudo-merge groups
  - Extended lookup path issues with overlapping groups
  - Incorrect date-based commit classification
  - Latent division-by-zero when sampleRate=0
- Patch 3 fixes critical lookup table sorting bug:
  - Introduces `pseudo_merge_commit_pos_cmp` to sort by pack position (not OID)
  - Corrects binary search behavior for fill-in traversal
  - Changes on-disk format to match documented behavior
- Patch 4 fixes binary search implementation:
  - Corrects inverted comparison in `pseudo_merge_at()`
  - Swaps `hi = mi` and `lo = mi + 1` assignments
- Patch 5 fixes extended lookup path issues:
  - Corrects write-side miscalculation of extended table offsets (12 vs 8 bytes)
  - Fixes read-side misinterpretation of bitmap offsets as commit table entries
  - Adds proper error checking for corruption cases
  - Simplifies `nth_pseudo_merge_ext()` to store direct offsets
- New patch (6) fixes date parsing in group selection:
  - Adds `repo_parse_commit()` in `find_pseudo_merge_group_for_ref()`
  - Ensures proper timestamp reading for date-based classification
  - Makes `threshold` and `stableThreshold` config options effective
  - Includes test using `GIT_TEST_DATE_NOW` to verify stable/unstable group assignment
