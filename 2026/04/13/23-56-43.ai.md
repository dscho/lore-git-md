This is the second patch in Taylor Blau's bugfix series for pseudo-merge bitmaps, adding test cases that demonstrate various issues in the implementation. The patch follows the test infrastructure addition from patch 1/8.

The new tests in t5333-pseudo-merge-bitmaps.sh expose several distinct problems:
- Fill-in traversal fails to properly apply pseudo-merges (both single and multiple groups)
- Overlapping pseudo-merge groups cause issues in the extended lookup path
- Date-based classification of commits for pseudo-merges is incorrect
- A latent division-by-zero risk when sampleRate=0 (currently marked as passing but will fail after subsequent fixes)

Each test case sets up specific pseudo-merge configurations and verifies expected behavior through bitmap operations. The tests use the new test-tool bitmap write command from the previous patch to generate controlled bitmap scenarios. Most are marked as test_expect_failure since they document known issues that will be fixed in upcoming patches.

The test cases are thorough and well-constructed, exercising different aspects of pseudo-merge behavior:
- Multiple group configurations (single, multiple, overlapping)
- Date-based filtering thresholds
- Edge cases like zero sample rates
- Verification through both direct inspection and bitmap operations

This patch serves as both documentation of the bugs and validation that the fixes in subsequent patches actually resolve the issues. The careful test design suggests these cases were developed in close coordination with the bug investigation.
