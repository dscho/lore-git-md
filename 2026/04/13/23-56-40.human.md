This is a test infrastructure patch that's part of Taylor Blau's series fixing pseudo-merge bitmap bugs. The series was prompted by Jeff King noticing insufficient test coverage for this performance-critical feature.

The patch adds a new `test-tool bitmap write` subcommand that gives tests precise control over which commits receive bitmaps. This enables the subsequent patches to properly test the pseudo-merge bitmap functionality by allowing tests to specify exactly which commits should be bitmap-enabled. The helper reads commit OIDs from stdin and writes corresponding bitmaps, respecting pseudo-merge configuration.

The implementation handles all the low-level details of bitmap generation while providing a simple interface for tests. It's a foundational piece that enables the bugfixes in the rest of the series to be properly tested. Given Taylor's expertise in the bitmap subsystem and the clear need demonstrated by the test coverage gap, this looks like a well-considered addition to the test infrastructure.
