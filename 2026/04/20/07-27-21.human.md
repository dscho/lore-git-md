This is a test infrastructure patch from Patrick Steinhardt, part of his ongoing series to enable `set -e` (errexit) in Git's test suite. The patch specifically updates the `test_must_fail()` helper function to work correctly when `set -e` is active.

The change modifies how exit codes are captured from commands that are expected to fail. Previously, if a command failed under `set -e`, the shell would exit immediately rather than allowing the test to check the exit code. The patch fixes this by using the `||` operator to capture the exit code without triggering an early exit.

This is a straightforward technical change that maintains the existing behavior while making it compatible with the stricter error checking that `set -e` provides. The patch is well-contained, touching only the test infrastructure without affecting any actual test cases. It's part of a larger, carefully reviewed effort to improve test reliability that has already addressed shell compatibility concerns in previous iterations.
