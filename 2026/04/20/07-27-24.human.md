This is part 5 of Patrick Steinhardt's ongoing test infrastructure series to enable `set -e` (errexit) in Git's test suite. The patch focuses on fixing conditional test execution patterns that would break under `set -e`.

The issue addressed here involves test scripts that use `test ... && test_expect_success` patterns to conditionally run tests. Currently, when the condition fails, the test is skipped but the overall statement fails - which would cause `set -e` to abort execution. The patch converts these to proper `if` statements that cleanly handle the skip case.

Two test files are modified:
- `t4032-diff-inter-hunk-context.sh`: Changes conditional output verification
- `t7450-bad-git-dotfiles.sh`: Updates conditional symlink handling tests

This is a mechanical but necessary change that follows the established pattern from earlier in the series. The modifications are straightforward and maintain existing behavior while making the tests `set -e` safe. The patch continues the series' careful, incremental approach to test modernization.
