This is the first patch in a two-part bugfix series addressing issues in `git status`'s display of the rebase todo list during interactive rebase. Phillip Wood, a recognized expert in Git's sequencer and rebase subsystems, factors out the todo command parsing logic from sequencer.c into a new reusable function `sequencer_parse_todo_command()`.

The refactoring extracts the command detection logic that was previously embedded in `parse_insn_line()`, making it available for reuse by other components - specifically the status display code that will be fixed in the next patch. The changes are cleanly separated, with the new function added to sequencer.h for external access while maintaining all existing behavior.

This is a preparatory change that enables the actual bugfix in patch 2/2, where this shared parsing will be used to correctly handle object ID abbreviation and refname preservation in rebase status output. The patch demonstrates good separation of concerns and appears technically sound, coming from a domain expert with a clear path forward in the series.
