This is a bugfix series targeting the rebase status display in `git status`. Phillip Wood addresses two specific issues: 

1) The status output fails to abbreviate commit object IDs when the rebase todo line starts with "fixup -C" or "merge -C" 
2) It incorrectly replaces refnames (like "main") with their object IDs in "reset" and "update-ref" commands

The series first refactors the sequencer's todo command parsing logic into a reusable function, then uses that to improve the status display's handling of these edge cases. The changes touch the sequencer and wt-status code along with corresponding test updates.
