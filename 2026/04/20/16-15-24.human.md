This is Junio Hamano's biweekly "What's cooking in git.git" status report, providing a snapshot of active development topics as of April 2026. The report covers 40+ in-progress patch series at various stages of review and integration.

Key updates:
- Git 2.54 has been tagged as final, marking the start of a new development cycle
- Junio will be offline for a few weeks with no designated interim maintainer
- Several major efforts are progressing:
  - Patrick Steinhardt's ODB in-memory source (18 commits)
  - Taylor Blau's incremental MIDX repacking (16 commits)
  - The ongoing `the_repository` removal in setup.c (18 commits)
  - Paul Tarjan's Linux fsmonitor implementation (13 commits)
  - Adrian Ratiu's parallel hooks support (merged to next)

Notable new features:
- `git checkout -m` now automatically stashes local changes during branch switching
- `git push` gains support for pushing to remote groups
- `git name-rev` learns custom formatting
- `git cat-file --batch` adds a mailmap toggle command
- `git log --graph` gets a lane-limiting option

The report also highlights numerous bugfixes, test improvements, and documentation updates across the codebase. Several topics are marked as needing rerolls or awaiting review responses before progressing further.

This snapshot shows Git's development continuing at a steady pace, with significant work on core infrastructure (ODB, MIDX, repository handling) alongside user-facing features and quality-of-life improvements. The breadth of activity reflects both the project's maturity and ongoing efforts to modernize its internals.
