This is patch 15/18 in Patrick Steinhardt's ongoing series to remove `the_repository` global variable usage from the setup subsystem. The patch converts `check_repository_format()` to take an explicit `struct repository *` parameter instead of implicitly using `the_repository`.

The changes are mechanical but thoughtful:
1. The function is moved earlier in setup.c to avoid forward declarations
2. It's made static since it's only used within setup.c
3. All callers (enter_repo() and init_db()) are updated to pass the repository explicitly
4. The header declaration is removed from setup.h

The patch follows the established pattern of this series - making focused, incremental changes while maintaining backward compatibility. The diff shows careful attention to repository state management, particularly around hash algorithms and ref storage formats. This continues the methodical approach seen in previous patches, with the global variable dependency being pushed up one level to the callers.

As with earlier parts of the series, this is a low-risk change that moves the codebase incrementally toward the larger goal of eliminating `the_repository` while keeping the same behavior. The patch is cleanly focused on its specific objective without introducing broader architectural changes.
