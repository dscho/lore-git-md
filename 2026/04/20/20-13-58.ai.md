This is a feature patch adding `--word-diff` support to `git commit -v`. The change allows viewing word-level diffs (rather than line-level) in the verbose commit template, which can be particularly useful when working with column-based formats like CSV.

The implementation:
- Adds a new `--word-diff` option to `git commit` that only takes effect with `-v`
- Uses the existing PORCELAIN word-diff format (same as `git diff --word-diff=porcelain`)
- Includes comprehensive tests verifying:
  - Basic word-diff functionality
  - That `--word-diff` without `-v` does nothing
  - That `-v -v` shows word-diffs for both staged and unstaged changes
  - That diff markers are properly stripped from the final commit message

The patch touches multiple files to add the new option and pass the setting through to the diff machinery, but the changes are straightforward and well-contained. The commit message clearly explains the motivation (CSV/column-based data) and scope (PORCELAIN-only for now). Test coverage appears thorough for the new functionality.

This seems like a useful quality-of-life improvement for users who frequently work with structured data formats where word-level diffs are more meaningful than line-level ones. The implementation is clean and follows existing patterns in the codebase.
