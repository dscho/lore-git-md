This is a test infrastructure patch from Patrick Steinhardt, part of his ongoing series to make Git's test suite compatible with `set -e` (errexit) mode. The patch focuses on fixing cleanup handlers in test helper functions to work correctly under stricter error checking.

The change modifies `test_when_finished()` and `test_atexit()` - two key test helpers that register cleanup commands. The current implementation uses a complex `&& (exit ...)` pattern to preserve test exit codes during cleanup, but this breaks under `set -e`. The patch simplifies the logic to use `||` instead, which maintains the same behavior while being `set -e` safe.

The commit message includes clear truth tables showing the behavior before and after the change, demonstrating that the new version preserves all the important cases:
- Cleanup success/failure when test passes
- Cleanup success/failure when test fails

The change is mechanical but important for the broader goal of making the test suite more robust by catching errors that would otherwise be silently ignored.
