Johannes Schindelin has announced Git for Windows 2.54.0, the Windows-specific distribution that tracks upstream Git releases while adding platform-specific fixes. This release removes two legacy components: `git svn` (due to maintenance challenges) and the non-functional `git instaweb`. 

The update includes the core Git 2.54.0 functionality along with updated dependencies like Bash 5.3.9 and OpenSSL 3.5.6. Windows-specific improvements address terminal input handling, CPU core detection on multi-socket systems, TLS timeouts, and NTLM/Kerberos authentication security. The announcement provides SHA-256 checksums for installers and portable versions across x64, ARM64, and 32-bit architectures.

This is a routine maintenance release that follows upstream Git while addressing Windows-specific needs. Users requiring Subversion interoperability are advised to use WSL or MSYS2 instead of the now-removed `git svn`.
