This is part of Patrick Steinhardt's ongoing test infrastructure work to enable `set -e` (errexit) in Git's test suite. The patch modifies several test scripts to handle `git config --unset` calls that may fail when the configuration variables being unset don't exist. 

The changes are mechanical but important for the broader `set -e` effort - they silence expected failures in test cleanup code by adding `|| :` after `git config --unset` calls. This pattern ensures the test suite won't fail when trying to unset configuration that was never set or was cleaned up by a prior test. The affected tests include diff context configuration, status output coloring, and SVN author mapping.

This patch follows the established pattern from earlier in the series, where similar changes were made to other test helpers. It's a straightforward adaptation of existing test code to work with stricter error checking, with no behavior change when `set -e` is not enabled. The changes are limited to test framework code and don't affect Git's core functionality.
