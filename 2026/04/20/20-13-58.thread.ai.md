Thread identity: Feature patch adding `--word-diff` support to `git commit -v` for viewing word-level diffs in the commit template, particularly useful for column-based formats like CSV.

Core problem/goal: Currently `git commit -v` only shows line-level diffs; this change enables word-level diffs (using the existing PORCELAIN format) to better handle structured data where changes may be column boundaries rather than whole lines.

Implementation details:
- New `--word-diff` option for `git commit` that requires `-v` to take effect
- Uses existing PORCELAIN word-diff format (same as `git diff --word-diff=porcelain`)
- Changes span multiple files to add the option and pass it through
- Comprehensive test coverage including:
  - Basic word-diff functionality
  - Option validation (`--word-diff` without `-v` does nothing)
  - Double-verbose mode (`-v -v`) showing word-diffs for both staged/unstaged
  - Proper stripping of diff markers from final commit message
