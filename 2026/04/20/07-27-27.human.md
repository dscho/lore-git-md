This is part 8 of Patrick Steinhardt's ongoing series to make Git's test suite compatible with `set -e` (errexit) mode. The patch focuses on `t0008-ignores.sh`, which tests Git's ignore rules.

The change addresses a case where `grep -v` in a subshell could fail (when no lines match the inverted pattern) but the test currently relies on silently ignoring that failure. With `set -e` coming, such failures would cause the test to abort. The fix adds `|| :` to explicitly ignore any grep failure, maintaining the existing behavior while making it `set -e` safe.

This is a straightforward mechanical change that follows the established pattern from earlier patches in the series. It's a common idiom in shell scripting to use `|| :` when you want to ignore command failures, and the patch applies this consistently with the rest of the test suite modernization effort. The change is small, focused, and clearly explained in the commit message.
