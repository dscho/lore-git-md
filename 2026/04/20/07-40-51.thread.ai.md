Subject: filesystem ownership checks in Git for network filesystems (9p, AFS, Ceph, CIFS, NFS). David Howells proposes modifying `is_path_owned_by_current_uid()` to handle network filesystems differently since their UID/GID handling differs from local filesystems. Current implementation assumes UID/GID comparisons are universally meaningful, but network filesystems may use separate namespaces or fabricated IDs. Two potential solutions: 1) check filesystem type via `statfs()` to identify network filesystems, 2) add new `statx()` attribute flag in kernel to explicitly mark filesystems where UID/GID comparisons are unreliable. This affects Git's security model for repository access control, particularly in shared environments with network-mounted repositories. Proposal raises architectural question requiring coordination between Git and kernel maintainers; no patch yet provided. Key technical details: impacts operations checking repository ownership, touches security-sensitive path ownership verification code.
