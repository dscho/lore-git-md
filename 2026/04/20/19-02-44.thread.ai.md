Git for Windows 2.54.0 release announcement from Johannes Schindelin. This is the Windows-specific distribution, separate from main Git. Key changes: removed `git svn` (maintenance burden, suggests WSL/MSYS2 instead) and non-functional `git instaweb`. Updated components: Git 2.54.0 core, Bash 5.3.9, OpenSSL 3.5.6. Windows-specific fixes: terminal input handling, multi-socket CPU detection, TLS timeouts, NTLM/Kerberos security. Provides SHA-256 checksums for x64/ARM64/32-bit installers, portable versions, and MinGit. Routine maintenance release tracking upstream Git 2.54.0 with Windows-specific adjustments.
