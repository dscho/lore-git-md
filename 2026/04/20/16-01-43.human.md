This is a release announcement for Git v2.54.0 from maintainer Junio C Hamano. The release contains 771 non-merge commits from 137 contributors, including 66 first-time contributors. Key highlights include:

The release introduces several new features and improvements. A new experimental `git history` command has been added for history rewriting, while `git replay` gains the ability to drop commits that become empty. The `--expire` option for worktrees has better documentation, and `git show-index` now warns when defaulting to SHA-1 outside a repository. Configuration handling sees improvements with `git config list --type=<X>` support and better alias syntax allowing non-ASCII characters.

Performance and internal changes are substantial, with continued work on removing `the_repository` global variable dependencies, object database abstraction, and incremental repacking optimizations. The release also includes numerous fixes across various subsystems, including HTTP authentication improvements, diff stat UTF-8 display fixes, and corrections to the `git last-modified` command's options.

Junio notes he will be offline for a couple weeks after this release without designating an interim maintainer, expressing confidence in the community's ability to self-organize. The announcement follows Git's standard release format, listing all contributors (both new and returning) and providing detailed release notes covering UI changes, performance improvements, and fixes since v2.53.0.
