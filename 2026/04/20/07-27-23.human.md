This is part of Patrick Steinhardt's ongoing test infrastructure series to enable `set -e` (errexit) in Git's test suite. The patch modifies several test scripts to handle `git config --unset` calls that may fail when the config key doesn't exist, making them compatible with the stricter error checking that `set -e` provides.

The changes are mechanical but important - they add `|| :` to silence expected failures when unsetting configuration values that may not be set. This affects three test scripts that were using `git config --unset` as cleanup steps without checking the exit code. The modifications ensure these cleanup steps won't cause the test scripts to fail under `set -e`.

This patch is part of a well-structured series that has gone through multiple iterations with thorough review. The changes are straightforward and focused on test infrastructure rather than core Git functionality, following the established pattern from earlier patches in the series. All tests pass in CI, indicating the changes work as intended.
