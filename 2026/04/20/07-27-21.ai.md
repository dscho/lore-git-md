This is a test infrastructure patch from Patrick Steinhardt, part of his ongoing series to enable `set -e` (errexit) in Git's test suite. The patch modifies the `test_must_fail()` helper function to work correctly when `set -e` is active.

The change ensures that when a command fails (as expected in `test_must_fail`), the shell won't immediately exit due to `set -e`. The implementation now captures the exit code using `||` rather than checking it after execution, which maintains the same behavior while being compatible with `set -e`.

This is a straightforward technical change that follows the pattern seen in other parts of the series - adapting test infrastructure to work with stricter error checking. The patch is well-contained, touching only the test helper function while preserving all existing functionality. It's part of a larger effort that has already gone through multiple rounds of review and testing, with this particular change being a mechanical adaptation to the new error-handling regime.
