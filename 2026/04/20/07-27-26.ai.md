Test infrastructure patch from Patrick Steinhardt, part of the ongoing effort to make Git's test suite compatible with `set -e` (errexit) mode. This is patch 7/12 in the v5 series, focusing on fixing cleanup handlers in test infrastructure.

The patch modifies `test_when_finished()` and `test_atexit()` functions to work correctly under `set -e`. The current implementation uses `&&` chaining which would break when `set -e` is enabled, as a non-zero exit code would cause immediate termination. The new version switches to `||` chaining which preserves the same behavior while being `set -e` safe.

The commit message provides clear truth tables showing the behavior remains identical in all four cases (test pass/fail × cleanup pass/fail). The change is mechanical but important for the broader `set -e` compatibility work, which aims to catch more test failures early by making the shell exit immediately on uncaught errors.

This continues the pattern of methodical, well-explained changes in the series, with each patch addressing a specific aspect of test infrastructure that needs updating for `set -e` compatibility.
