This is a release announcement for Git for Windows 2.54.0, the Windows-specific distribution of Git maintained separately from the main Git project. Johannes Schindelin announces several updates and fixes in this version.

The most notable change is the removal of `git svn` from the distribution due to maintenance challenges. Users needing Subversion interoperability are directed to use WSL or install via MSYS2. The release includes updated versions of core components like Git 2.54.0, Bash 5.3.9, and OpenSSL 3.5.6.

Several Windows-specific bug fixes are included: improved terminal input handling in Git Bash, better CPU core detection on multi-socket systems, TLS timeout adjustments, and security improvements to NTLM/Kerberos authentication. The release also drops `git instaweb` which had become non-functional without GitWeb.

The announcement provides SHA-256 checksums for various distribution formats (installers, portable versions, MinGit) across x64, ARM64, and 32-bit architectures. This is a routine maintenance release following the upstream Git 2.54.0 version, with the expected Windows-specific adjustments and fixes.
