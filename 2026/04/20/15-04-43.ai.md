This is the first patch in a two-part bugfix series addressing issues in `git status`'s display of the rebase todo list during interactive rebase. The new function is exported via sequencer.h for use by other components. This is a clean refactoring that properly separates concerns between parsing and execution layers in the rebase machinery.

The patch touches core sequencer code (sequencer.c) and its header, with no behavior changes yet - those come in the second patch that will use this shared parsing.
