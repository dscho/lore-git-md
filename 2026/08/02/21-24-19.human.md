This is the first patch in the **v6 series** adding the `--reset-when-found` option to `git bisect`. It is a **refactoring patch** that prepares the codebase for the feature by adding a `quiet` parameter to `bisect_reset()`.

The change is small and surgical: `bisect_reset()` now accepts a boolean `quiet` flag that, when true, passes `--quiet` to the underlying `git checkout` command, suppressing progress and branch-status output. The patch updates all existing callers (`bisect_replay()` and `cmd_bisect__reset()`) to pass `false`, preserving current behavior. No user-visible changes are introduced yet; this is purely internal plumbing.

The motivation is clear: the upcoming `--reset-when-found` feature will use this quiet mode during auto-reset to avoid cluttering script or CI output with checkout progress. The implementation is clean, with no side effects or new dependencies. The patch is uncontroversial and ready for integration. If the series lands, this preparatory step will be invisible to users but essential for the feature’s polish.
