This is a feature patch introducing a new `git interactive` command. It adds a terminal-based menu system that lets users run common Git operations—status, add (with a file-picking submenu), log, log-graph, branch, and help—without typing individual commands. The implementation is a new built-in (`builtin/interactive.c`) with a small test script (`t/t0013-interactive.sh`).

The patch is self-contained and includes all the plumbing: Makefile, command registration, and a binary placeholder (`git-interactive`). The menu is colored and clears the screen between operations if running in a TTY. The add submenu lists changed files and lets the user stage individual files or all at once.

This is a first-time contribution from the author; the commit message is brief but the code is well-structured and the test coverage is present. The feature itself is uncontroversial in concept—similar helpers exist in other tools—but the patch is large and the email was truncated, so deeper review may surface edge cases or style nits. For now it looks like a clean, motivated addition that could appeal to new users.
