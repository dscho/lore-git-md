This is a feature patch introducing a new `git interactive` command, a terminal-based menu system for common Git operations. The patch adds a built-in command (`builtin/interactive.c`) that presents users with a numbered menu of actions: status, add (with a submenu for individual file selection), log (both linear and graph views), branch listing, help, and quit. The implementation uses ANSI color codes, `isatty()` checks for terminal awareness, and invokes existing Git commands (`git status`, `git add`, etc.) as subprocesses. Tests (`t/t0013-interactive.sh`) cover menu navigation and file staging.

The patch is self-contained and includes all necessary plumbing: Makefile and `builtin.h` entries, a `command-list.txt` update, and a test script. The commit message motivates the feature as a "simple interactive entry point for common working-tree and history operations," though it does not compare against existing tools like `git add -i` or third-party Git assistants. The implementation is straightforward but limited in scope—it does not persist state between invocations, lacks tab completion, and does not integrate with Git’s existing interactive modes (e.g., `git add -p`).
