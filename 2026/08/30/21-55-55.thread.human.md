This thread is about a use-after-free regression in `git stash show` when using `--src-prefix` or `--dst-prefix`, introduced in Git 2.52.0. The bug causes garbage diff headers (e.g., `diff --git Uf.txt Uf.txt`) and affects scriptability tools like `lint-staged`. Nicolas Le Cam reported the issue, and Jeff King proposed a two-patch fix: the first patch introduces a `strvec argv_to_free` field in `struct rev_info` to delay freeing `argv` elements until `release_revisions()` is called, while the second patch refactors the `mark_argv_for_free()` helper to consolidate redundant flag checks.

The series has reached consensus and is ready for Junio to pick up for the `maint` branch. The refactoring follow-up, just sent by Junio, simplifies the helper by moving the `free_removed_argv_elements` flag check into the function itself, eliminating redundancy in callers. This change is purely internal and improves code maintainability without any user-visible impact. Patrick Steinhardt initially raised a maintainability concern about the helper’s `const char *` parameter but accepted Jeff’s rationale after clarification. The fix restores correct diff header output and includes a regression test in `t/t3903-stash.sh` to prevent future issues. No controversy remains, and the patches are targeted at the regression’s source (commit 3ea35c64b).
