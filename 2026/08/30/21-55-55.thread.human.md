This thread is about a use-after-free regression in `git stash show` when using `--src-prefix` or `--dst-prefix`, introduced in Git 2.52.0. The bug causes garbage diff headers and affects scriptability tools like `lint-staged`. Nicolas Le Cam reported the issue, and Jeff King proposed a fix that delays freeing `argv` elements until `release_revisions()` is called, preventing dangling pointers in `diff_options`.

The fix is straightforward and uncontroversial, with Jeff also submitting a refactoring follow-up to improve code clarity. Patrick Steinhardt reviewed the patch, endorsing the centralized approach but raising a concern about the `mark_argv_for_free()` helper’s `const char *` parameter, which could hide ownership semantics and risk subtle lifetime issues. The discussion remains technical and constructive, with no alternative implementations proposed. The fix is still targeted for `maint`, but Jeff’s response to Patrick’s feedback is pending. No other open questions remain, and the regression test ensures the bug won’t recur.
