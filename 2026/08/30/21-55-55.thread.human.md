This thread is about a use-after-free regression in `git stash show` with `--src-prefix` or `--dst-prefix`, introduced in Git 2.52.0. The bug causes garbage diff headers and affects scriptability tools like `lint-staged`. Nicolas Le Cam reported the issue, and Jeff King proposed a fix that delays freeing of `argv` elements until `release_revisions()` is called, using a new `argv_to_free` field in `struct rev_info`. A follow-up patch refactors the `mark_argv_for_free()` helper to simplify callers.

The fix is now under review and has reached consensus on both correctness and design. Jeff King defended the `const char *` parameter in the helper as justified by its single purpose, and Patrick Steinhardt, who initially raised maintainability concerns, has accepted this rationale. The patches are targeted at the regression’s source and are suitable for the `maint` branch. No controversy remains, and the thread is now waiting for Junio to pick up the patches. The fix restores correct diff headers and improves code maintainability without user-visible changes.
