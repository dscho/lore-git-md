This thread began with Hardik Kumar submitting a simple patch to fix three minor spelling errors in comments and test descriptions across Git and Git GUI. The changes themselves—correcting "fractionnal" to "fractional", "occurence" to "occurrence", and "similiarity" to "similarity"—were uncontroversial and received a surface-level "LGTM" from Michael Montalbo.

However, Junio C Hamano quickly identified a procedural blocker: the patch mixed changes to Git (`versioncmp.c` and `t/t0022-crlf-rename.sh`) with a change to Git GUI (`git-gui/git-gui.sh`), violating the project's rule requiring separate submissions for these components. Hardik has now resolved this by splitting the patch. The Git-only portion (covering the two non-GUI files) has been resent as a standalone patch with a "versioncmp" prefix, while the Git GUI typo fix will need to be submitted independently to the Git GUI mailing list. With this split, the procedural issue is resolved, and the Git portion of the patch is ready for integration. No technical objections remain.
