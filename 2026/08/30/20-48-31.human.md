This is the fourth patch in Junio C Hamano’s eight-patch series refactoring the internals of `git checkout`, `git switch`, and `git restore`. The series is part of the ongoing effort to eliminate the monolithic `checkout_main()` function by extracting reusable logic into standalone helpers, aligning with the `the_repository` removal architectural direction.

This patch focuses on isolating option validation and pathspec handling logic from `checkout_main()` into four new static helper functions: `init_checkout_opts()`, `validate_path_options()`, `prepare_common_options()`, and `parse_pathspec_from_file_options()`. The changes are purely mechanical—moving existing code into separate functions without altering behavior—and reduce `checkout_main()` by roughly 70 lines. The extracted helpers are called in sequence from `checkout_main()`, improving code locality and readability. For example, `validate_path_options()` consolidates all patch-mode and index/worktree flag validation, while `prepare_common_options()` centralizes progress, merge, and force option setup.

The patch is uncontroversial and well-structured, with clear commit message documentation and no functional changes. It passes the test suite and is part of a larger, self-contained refactoring that has already addressed feedback from the first iteration (e.g., fixing a typo in patch 7 and ensuring `post_checkout_hook()` is multi-repository-ready in patch 8). The helpers introduced here (`init_checkout_opts()`, `validate_path_options()`, etc.) are internal to `builtin/checkout.c` and do not yet expose new APIs, but they lay the groundwork for future patches in the series that will move reusable logic into top-level files (`checkout.c`, `checkout.h`).

While the series is still an early draft and not intended for merging to `seen`, this patch is a straightforward cleanup that could be merged independently if the later patches are deferred. It demonstrates the libification path clarified in the parent thread: built-in commands should not be libified, but their reusable internals should be extracted into helpers that accept a `struct repository *` parameter. No objections have been raised, and the broader architectural direction has received support from D. Ben Knoble. The patch’s scale (96 insertions, 75 deletions) is modest compared to the series as a whole, making it a low-risk step toward eliminating the `checkout_main()` choke point.
