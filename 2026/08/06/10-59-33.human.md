This is a test infrastructure patch, part of the larger `paint_down_to_common()` optimization series (v7, patch 2/10). The series is already queued in Junio’s tree and awaiting additional review bandwidth to advance.

The patch improves diagnostic output for Trace2 data assertions in Git’s test suite. Currently, `test_trace2_data` is a bare `grep` that fails silently on mismatches, making debugging difficult. The new `test_trace2_data_singular` helper verifies that a Trace2 event appears exactly once and reports clear, actionable errors: whether the key was missing, appeared multiple times, or had an unexpected value. Diagnostics are written to file descriptor 4, matching the behavior of `test_grep`.

The implementation is straightforward: it extracts the value from the Trace2 JSON log, checks for duplicates (using `$LF` as a line separator), and compares the actual value against the expected one. The helper is designed to be a drop-in replacement for cases where a single occurrence is expected, and it includes an optional label for context in error messages.

This is a quality-of-life improvement for test authors and reviewers, particularly in performance-sensitive series like this one, where Trace2 instrumentation is used to measure algorithmic efficiency. The change is uncontroversial and aligns with the test suite’s existing conventions. No substantive objections are expected, and the patch is ready to merge as part of the larger series.
