This is the fifth patch in the ready-to-merge v7 series optimizing `paint_down_to_common()` in Git’s commit-reach subsystem. The patch adds Trace2 instrumentation to count and report the number of commits visited during the paint walk, enabling observable measurement of optimization impact without relying solely on wall-clock benchmarks.

The change is straightforward: it introduces a `steps` counter in `paint_down_to_common()` that increments for each commit processed, then emits the total via `trace2_data_intmax()` at the end of the walk. The test suite is updated to verify these counts deterministically across all commit-graph modes (none, full, half, no-gdat) using the new `test_paint_down_steps()` helper, which ensures the step counts match expected values for each test case. The test harness also now captures Trace2 events per mode, replacing the previous `grep`-based approach with the more robust `test_trace2_data_singular()` helper introduced earlier in the series.

The patch touches only `commit-reach.c` and `t/t6600-test-reach.sh`, adding no new symbols beyond the `steps` counter and the Trace2 event. The test updates are thorough, covering both existing and new test cases (e.g., `merge-base --all commit-walk steps`) to ensure the instrumentation works across all commit-graph configurations.
