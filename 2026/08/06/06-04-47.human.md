This is the third patch in Patrick Steinhardt’s six-patch series making Git’s on-disk object database (ODB) structures pluggable, part of the ongoing ODB abstraction effort. The patch moves handling of the `GIT_OBJECT_DIRECTORY` and `GIT_ALTERNATE_OBJECT_DIRECTORIES` environment variables into `odb_new()`, making the function self-contained and eliminating the need to duplicate environment variable logic elsewhere. The change is mechanical and uncontroversial, with no behavior change.

Toon Claes’s review spotted a minor cleanup opportunity: the `xstrdup_or_null()` call for `o->alternate_db` is now redundant because `secondary_sources` is already duplicated (or NULL) when the environment variables are honored. Patrick agrees and will remove the redundant allocation and the corresponding `free()` in the next iteration. This is a small improvement but does not affect the patch’s core purpose.

The patch remains ready for merging. It prepares the ground for future ODB backend work, including deferring ODB construction and moving alternate handling into the "files" backend, without altering current behavior. The broader series is still under review, with the first patch (a correctness fix) already marked for early graduation to `next`.
