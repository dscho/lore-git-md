This is the sixth and final patch in Patrick Steinhardt’s v4 series making on-disk object database (ODB) structures pluggable. It implements the `create_on_disk` callback in the "files" backend, replacing the hardcoded directory creation logic in `setup.c` with backend-specific handling.

The patch is straightforward: it moves the creation of `pack/` and `info/` subdirectories from `create_object_database()` into a new callback in `odb/source-files.c`. The top-level `objects/` directory remains hardcoded as a requirement for repository discovery, regardless of backend. The callback is invoked after ODB initialization, and the "files" backend uses `safe_create_dir()` to create its subdirectories. The change is mechanical and touches only three files: `odb/source-files.c`, `odb/source.h`, and `setup.c`.

This patch completes the series’ architectural goal: future ODB backends can now implement custom on-disk layouts without modifying core setup logic.
