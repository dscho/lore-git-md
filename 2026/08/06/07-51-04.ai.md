This is the sixth and final patch in Patrick Steinhardt’s v4 series making on-disk object database (ODB) structures pluggable. It implements the `create_on_disk` callback in the "files" backend, replacing the generic directory-creation logic in `setup.c` with backend-specific handling. The patch touches `odb/source-files.c`, `odb/source.h`, and `setup.c`, introducing the callback and wiring it up in `create_object_database()`.

The change is straightforward: the "files" backend now creates its own `pack/` and `info/` subdirectories via `safe_create_dir()`, while the top-level `objects/` directory remains hardcoded in `setup.c` as a requirement for repository discovery. The callback is invoked after ODB initialization, and the patch removes redundant environment-variable checks that were moved to `odb_new()` in an earlier patch. A minor cleanup removes the now-unused `strbuf` manipulation in `create_object_database()`.

This patch is uncontroversial and ready for merging. It completes the series’ architectural goal of decoupling backend-specific on-disk setup from core repository logic, enabling future ODB backends to implement custom layouts. The only open question—whether the `create_on_disk` callback should be renamed for non-filesystem backends—was deferred by Patrick in favor of consistency with the ref subsystem’s naming. No further changes are expected here.
