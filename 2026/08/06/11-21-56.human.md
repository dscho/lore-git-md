This is the first patch in a seven-part series introducing `git repack --drop-filtered`, a new feature for partial clones that lets users reclaim disk space by safely removing locally cached promisor blobs over a specified size threshold. This patch adds the `--drop-filtered` and `--dry-run` command-line options to `git repack`, along with all the necessary validation logic, but does not yet implement the actual object enumeration or deletion.

The patch is well-structured and clearly motivated. It enforces several important constraints: `--drop-filtered` requires `--filter` (currently limited to `blob:limit`), `-a`, and a configured promisor remote; it conflicts with `--filter-to` and explicit bitmap writing (`-b`); and `--dry-run` is only meaningful when paired with `--drop-filtered`. The validation logic is thorough, including a subtle but important fix for the bitmap-handling edge case: explicit `-b` on the command line is now always rejected, even when `repack.writeBitmaps` is set in the config, while config-driven bitmaps are silently disabled for the duration of the command. Tests cover all the validation rules, including the bitmap edge case, and the commit message explains the design choices clearly.

This patch looks production-ready for its scope. The validation logic is complete, the tests are comprehensive, and the commit message is detailed. The only missing piece is the actual object enumeration and deletion, which will follow in later patches. The series as a whole is part of a Google Summer of Code project mentored by Christian Couder and Siddharth Asthana, and this patch reflects the feedback from earlier iterations, particularly around the bitmap validation fix and the reframing of the safety guards as UX optimizations rather than correctness measures. Reviewers with expertise in repack or partial clones (e.g., Patrick Steinhardt or Taylor Blau) may weigh in on the trade-offs between the current safety guards and Junio’s proposed time-based heuristic, but that discussion belongs to the later patches in the series.
