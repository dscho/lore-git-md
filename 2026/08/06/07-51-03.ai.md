This is a refactoring patch that improves error messages in the ODB (object database) subsystem. It introduces `odb_source_type_to_name()`, a helper function that maps an ODB source type (e.g., `ODB_SOURCE_FILES`, `ODB_SOURCE_LOOSE`) to a human-readable string. The patch then updates all downcasting macros (`odb_source_files_downcast()`, `odb_source_inmemory_downcast()`, etc.) to use this function in their BUG messages, replacing raw numeric type values with descriptive names like "files" or "loose".

The change is purely internal and does not affect Git's behavior—it only makes debugging easier when a downcast fails. The implementation is straightforward: a static array maps each `enum odb_source_type` to its name, with bounds checking and a fallback to "unknown" for invalid values. The patch touches six files (`odb/source-*.h` and `odb/source.[ch]`) and adds 37 lines, mostly replacing existing BUG message formats.
