This is the first patch in Johannes Sixt’s five-part series to overhaul gitk’s color-preference dialog. It consolidates the initial color-swatch setup into the existing `prefspage_set_colorswatches` helper, which already handles updates after the user picks a new color. The change is purely mechanical: instead of hard-coding the initial background colors for each swatch, the patch removes those assignments and calls the helper once at the end of dialog construction. The result is cleaner code with no behavior change—swatches still show the same colors, but the logic is now in one place. This is a refactoring step that paves the way for the later patches that make the swatches clickable and improve the labels.
