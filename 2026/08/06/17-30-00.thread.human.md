This thread is about the long-deprecated `git whatchanged` command, which is a thin wrapper around `git log` with hardcoded flags. Itamar Perdomo started the discussion by reporting that he still uses it, raising the question of whether it should be removed from the codebase. So far, the only concrete feedback has come from users noting continued use, with no technical objections or maintainer decisions.

Junio C Hamano recently replied to clarify the expected process for users: before reporting continued use of a deprecated command, they should first try to find a replacement (likely by following the deprecation notice or documentation) and only reach out if they can’t determine a suitable alternative. His message doesn’t take a position on whether the command should be removed or propose any code changes—it’s purely a procedural note. The thread remains open, with no indication of when or if the command will be removed. If you’ve been using `git whatchanged`, now is a good time to check the deprecation notice for alternatives.
