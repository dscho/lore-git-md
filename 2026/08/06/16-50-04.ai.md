The review does not reject the patch outright but signals that the commit message needs to be strengthened to address these points before the change can be considered safe. No code changes are requested yet; the feedback is purely about the rationale. The patch remains in the review phase, and the author will need to revise the commit message to satisfy Junio’s concern.
