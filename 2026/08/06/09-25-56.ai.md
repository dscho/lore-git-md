This is the second patch in Tian Yuchen’s v2 refactoring series on repository config handling in `environment.h`. The patch removes redundant, function-specific documentation for the repository config getter trio (`repo_protect_hfs`, `repo_protect_ntfs`, `repo_ignore_case`) and replaces it with a single, unified comment block that accurately describes their shared behavior: when the repository is not fully initialized, the getters return the appropriate default values instead of calling `repo_config_values()`. The change is purely documentary—no code or signatures are altered—and directly addresses Junio C Hamano’s feedback on v1 by eliminating the misleading blank lines that previously suggested separate scopes for the functions. The patch deletes 11 lines and adds 3, leaving the net line count negative.
