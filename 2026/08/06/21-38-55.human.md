This is the second patch in Justin Tobler’s six-patch series making `git receive-pack` use the ODB transaction system for pluggable packfile writes. The series is part of the ongoing ODB abstraction effort led by Patrick Steinhardt.

This patch lifts the handling of shallow files out of the `unpack()` function and passes it explicitly through the call chain. Currently, `unpack()` creates a temporary shallow file and stores its path in a global variable (`alt_shallow_file`). Later patches will move the unpack logic behind a generic ODB transaction interface, which can’t rely on global state, so this patch prepares for that by making the shallow file path an explicit parameter. The change is mechanical: the same logic is preserved, just wired through function arguments instead of globals.

The patch touches only `builtin/receive-pack.c` and is a refactoring step with no behavior change. It’s a necessary precursor to the later patches that introduce the generic `odb_transaction_write_pack()` interface. The motivation is clear and the implementation looks clean, though reviewers may want to verify that the explicit passing of the shallow file path doesn’t complicate error handling or resource cleanup.
