This is the first patch in the v3 series introducing `git repack --drop-filtered` for partial clones. It adds the `--drop-filtered` and `--dry-run` command-line options to `builtin/repack.c` and implements all validation logic, but does not yet perform object enumeration or deletion. The patch enforces key constraints: `--drop-filtered` requires `--filter=blob:limit=<n>` and `-a`, rejects `--filter-to`, and mandates a promisor remote. It also resolves the bitmap validation edge case by distinguishing between explicit `-b` (always rejected) and config-driven `repack.writeBitmaps` (silently disabled). Tests cover all validation scenarios, including the bitmap-handling fix. The patch is well-structured and production-ready, with clear commit messages and thorough test coverage. The core logic for object enumeration and deletion will follow in later patches.
