This is the third patch in a five-patch series overhauling the **gitk color-preference dialog**. The series is a **UI improvement** targeting **gitk**, the built-in Git history visualizer, and is authored by Johannes Sixt, the current maintainer of gitk.

This patch makes the color swatches in the preferences dialog the primary clickable elements, addressing a long-standing usability issue. Currently, users must click the text label next to a color swatch to change it, which is unintuitive since the eye is naturally drawn to the swatch itself. The patch swaps the roles: the swatch becomes a clickable button, and the label becomes static text. The change is implemented by replacing the `ttk::button` widget (which cannot be easily recolored) with a non-themed `button` widget, allowing the background color to be set directly. The patch also adjusts the grid layout to place the label before the button, maintaining visual consistency.

The patch is confined to `gitk-git/gitk` and touches only the `prefspage_colors` and `prefspage_set_colorswatches` procedures. It is a straightforward mechanical change with no new symbols or behavior beyond the UI tweak. The commit message clearly explains the motivation and implementation, and the diff is minimal and focused.

This is a logical follow-up to the first two patches in the series, which refactored the color-setting logic and reduced code duplication. The remaining patches (4/5 and 5/5) will further improve the dialog by standardizing button widths and rewriting labels in more natural language. The series is well-structured, with each patch building on the previous ones, and this patch is a key step in making the dialog more intuitive.

No controversy is expected here. The change is a clear usability win, and the implementation is clean and well-explained. The only potential discussion points would be minor details like widget styling or layout, but those are easily adjusted if feedback arises. The patch is ready for review and should be a straightforward merge once any nits are addressed.
