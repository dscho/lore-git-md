This is the sixth patch in K Jayatheerth’s seven-patch GSoC series that extends `git repo info` with six new path-related keys. This installment adds the `path.git-prefix` key, which returns the relative path from the top-level working tree to the current directory, including a trailing slash. The implementation is straightforward: it simply exposes the `repo->prefix` field (or an empty string when at the root). Documentation and tests are included, and the patch is mechanically clean. No substantive design questions remain for this key; it is a simple, uncontroversial addition that rounds out the series.
