This is a refactoring patch in Patrick Steinhardt’s six-part series making Git’s object database (ODB) structures pluggable. It introduces `odb_source_type_to_name()`, a helper that maps ODB source types (`ODB_SOURCE_FILES`, `ODB_SOURCE_LOOSE`, etc.) to human-readable strings. The patch then updates every downcast macro (`odb_source_files_downcast()`, etc.) to use these names in BUG messages, replacing the raw enum values (`'%d'`) with clearer labels like “trying to downcast source of type 'packed' to 'files'”.

The change is purely internal: no behavior is altered, only error-message clarity. It touches the four backend headers (`source-files.h`, `source-inmemory.h`, `source-loose.h`, `source-packed.h`) and adds the lookup table in `odb/source.c`. The patch is uncontroversial and ready for merging; it was already marked as such in Junio’s “What’s cooking” report and carries Justin Tobler’s “looks good to me” from an earlier round.
