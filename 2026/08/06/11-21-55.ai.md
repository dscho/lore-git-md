This is the v3 patch series for `git repack --drop-filtered`, a feature that lets partial clone users reclaim disk space by safely dropping locally cached promisor blobs over a size threshold. The series is now complete and addresses all feedback from v2: the bitmap validation edge case is fixed (explicit `-b` is now always rejected, even when `repack.writeBitmaps` is set), the documentation softens "guaranteed recoverable" to acknowledge remote availability risks, and the safety guards (merge/rebase/cherry-pick checks and index validation) are reframed as UX optimizations rather than correctness measures. The core implementation remains unchanged: promisor objects are enumerated via `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`, filtered by size, and dropped by rebuilding the promisor pack while excluding them, with crash safety guaranteed by the existing repack machinery.

The series touches the repack subsystem, promisor infrastructure, and object filtering, introducing two new CLI options (`--drop-filtered` and `--dry-run`), a new helper function (`list_objects_filter__filter_oidset()`), and a new file (`repack-filtered.c`). Tests are thorough, covering option parsing, validation, enumeration, real drops, and the safety guards. The deferred work (drop log, remote verification, and recency-based filtering) is explicitly scoped and does not block the core functionality. This version looks production-ready, with no known blocking issues and clear documentation of the remaining follow-up work.

Key technical details for future discussion: the series now distinguishes between command-line and config-driven bitmap settings, ensuring explicit `-b` is always treated as a conflict with `--drop-filtered`; the safety guards are implemented but their necessity is contested (Junio’s time-based heuristic remains an open alternative); and the promisor-object enumeration mechanism (`ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`) is trusted but could benefit from real-world validation. The patch set is well-structured, with tests distributed across commits and clear commit messages.
