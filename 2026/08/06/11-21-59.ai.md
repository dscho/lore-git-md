This is the fourth patch in the v3 series introducing `git repack --drop-filtered` for partial clones. It implements the core enumeration logic that identifies which promisor blobs exceed the user-specified size threshold and are therefore candidates for removal.

The patch adds `enumerate_promisor_blobs()` in `repack-filtered.c`, a function that walks all promisor objects (using `odb_for_each_object()` with `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`) and collects blobs into an oidset. It then applies the filter (currently only `blob:limit`) to that set using the new `list_objects_filter__filter_oidset()` helper, producing the final `to_drop` set. In `--dry-run` mode, the patch prints the OIDs of these candidate blobs to stdout. The implementation avoids lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` to every object info query, ensuring it only operates on locally available data.

The patch also updates `builtin/repack.c` to call `enumerate_promisor_blobs()` when `--drop-filtered` is specified, storing the results in a new `drop_oids` oidset. In `--dry-run` mode, it iterates over this set and prints each OID. The test script (`t/t7706-repack-drop-filtered.sh`) is extended with three new tests: one verifies that blobs exceeding the threshold are listed, another confirms that locally created blobs are never listed, and a third ensures `--dry-run` does not actually remove objects.

This is a well-crafted patch that addresses the architectural limitation noted in earlier reviews: promisor objects are routed through a separate repack path (`repack_promisor_objects()`), so they never reach the filtered pack machinery. The direct enumeration approach is correct and avoids the need for a separate `is_promisor_object()` check, since `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY` guarantees every object visited is a promisor object. The tests are thorough and cover both the enumeration logic and the safety invariant (locally created blobs are never candidates for removal). The patch is ready for review by repack and promisor subsystem experts (e.g., Patrick Steinhardt or Christian Couder).
