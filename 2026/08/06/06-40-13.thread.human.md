This thread is a five-patch series from Johannes Sixt (Hannes), the maintainer of gitk, overhauling the color-preference dialog to improve usability. The current dialog has non-intuitive controls—users must click text labels rather than the color swatches themselves—and inconsistent button widths due to varying label lengths. The series aims to make the swatches the primary clickable elements, standardize button widths, and rewrite labels in more natural language.

The first two patches were pure refactorings with no behavior changes, consolidating color-setting logic and reducing code duplication. The third patch, just posted, makes the color swatches clickable by replacing `ttk::button` widgets with non-themed `button` widgets, allowing direct background color control. This is a straightforward mechanical change confined to `gitk-git/gitk`, with no new symbols or on-disk format changes. The remaining two patches will address button width standardization and label wording.

The series is under review, with no objections raised so far. The changes are incremental and well-structured, each building on the previous ones. While minor discussion around widget styling or label wording might arise, the core improvement—a more intuitive UI—is uncontroversial. The series is expected to merge smoothly once any feedback is addressed.
