This thread is about a six-patch series from Johannes Sixt (Hannes) that overhauls the gitk color-preference dialog to improve usability. The changes make color swatches the primary clickable elements, standardize button widths, rewrite labels in more natural language, and ensure all UI strings are fully translatable. The series is now in its second version (v2), incorporating surface-level feedback from the first round.

The patches are confined to `gitk-git/gitk` and don’t affect core Git functionality. Key improvements include clickable swatches, more intuitive labels (e.g., “Foreground” is now “Main text”), and full translatability of dialog titles. The only remaining discussion is cosmetic: Mark Levedahl suggests tweaking the “Marked line background” label to something like “Origin line background” to better reflect its function, which highlights lines revealed by the “Show origin of this line” feature in the diff panel. This is a minor presentational choice with no technical impact, and the series is otherwise ready for final review. Junio Hamano and Mark Levedahl have both weighed in on phrasing, but no substantive concerns remain.
