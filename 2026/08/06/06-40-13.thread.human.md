This thread is about Johannes Sixt’s five-patch series to overhaul gitk’s color-preference dialog, making it more user-friendly. The current dialog has non-clickable color swatches, inconsistent button widths, technical labels, and untranslatable dynamic titles. The series starts with two refactoring patches to clean up the code, followed by three patches that make the swatches clickable, rewrite labels in natural language, and ensure full translatability of dialog titles.

So far, only Mark Levedahl has commented, offering a brief, surface-level endorsement of the first patch’s refactoring goal. No substantive technical feedback has been provided yet, so the series remains under initial review. The patches are confined to `gitk-git/gitk` and don’t affect any other part of Git. If you’re catching up, the key changes to watch for are the clickable swatches, clearer labels, and fully translatable UI strings—all aimed at improving usability without altering functionality.
