This thread is a maintainer-driven overhaul of gitk’s color-preference dialog, submitted by Johannes Sixt (Hannes). The goal is to make the dialog more intuitive by turning color swatches into clickable elements, standardizing button widths, rewriting labels in natural language, and ensuring all UI text is fully translatable. The five-patch series is now complete and under review, with all changes confined to the Tcl/Tk code in `gitk-git/gitk`—no core Git functionality is affected.

The first two patches are pure refactorings that lay the groundwork for the UI improvements. The third patch implements clickable swatches, incorporating minor visual tweaks suggested by Mark Levedahl, such as adjusting button borders and padding. The fourth patch replaces abbreviated labels with clearer phrasing (e.g., “Diff: old lines bg” → “Diff: old lines background”), while the fifth ensures dialog titles are fully translatable by replacing dynamic fragments with complete, natural-language strings.

The only remaining discussion is cosmetic: whether to reword one label as “Background of old lines in diffs” or adopt Levedahl’s suggestion to reorganize the dialog’s labels under broader headings like “Commit Differences.” Neither proposal affects functionality or translatability, and no substantive concerns have been raised. The series is technically ready for final review, though the outcome of this minor phrasing debate may influence the final wording of a single UI string. So far, only surface-level feedback has been provided, leaving the code’s correctness untested by deeper technical scrutiny.
