This is the second patch in Tian Yuchen’s v2 refactoring series on repository config handling in `environment.h`. It addresses a documentation clarity issue raised during the v1 review by Junio C Hamano.

The patch removes redundant, function-specific comments above the repository config getter functions (`repo_protect_hfs`, `repo_protect_ntfs`, `repo_ignore_case`, etc.) and replaces them with a single, unified comment block that describes the common behavior: these getters return default values when the repository is not fully initialized, avoiding the need to call `repo_config_values()` prematurely. The change also removes blank lines that previously separated the functions, visually reinforcing their shared purpose.

No code logic is altered—only the comments and whitespace. The patch is a direct response to maintainer feedback and keeps the series’ non-functional-change intent intact. It touches only `environment.h` and reduces line count by eight.
