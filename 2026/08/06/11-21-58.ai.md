This is patch 3/7 of the v3 series introducing `git repack --drop-filtered` for partial clones. It extends `repack_promisor_objects()` to accept an optional `to_drop` oidset; when provided, the function rebuilds the promisor pack while excluding those objects. The change is minimal and backward-compatible: all existing callers pass `NULL`, so behavior is unchanged.

The patch touches `repack-promisor.c` (core logic), `builtin/repack.c` (call-site update), and `repack.h` (function signature change). The new `to_drop` parameter is plumbed through to the `write_oid()` callback, which skips objects present in the set. The commit message clearly states this is the mechanism `--drop-filtered` will use to remove promisor blobs.

This is a refactoring patch that prepares the repack machinery for the actual object-dropping logic introduced later in the series. It is well-scoped, with no behavior change for existing users, and the implementation is straightforward. The patch is ready for review by anyone familiar with the promisor repack code.
