Thread identity: bugfix patch series (5 patches) by Elijah Newren via GitGitGadget, targeting the merge machinery to prevent unsafe commit operations (`git commit --amend` and `git commit <paths>`) during conflict resolution for `git am`, `git revert`, and all forms of `git rebase`.

Core problem or goal: extend Git's existing protection against unsafe commit operations during conflict resolution to cover both `git commit --amend` and `git commit <paths>`, preventing users from accidentally amending the wrong commit or updating individual paths during conflict resolution, which can corrupt repository state. The fix reliably distinguishes between genuine conflict stops (where amending or partial commits would corrupt state) and internal `--amend` usage by interactive rebase directives (`squash`, `reword`, `edit`, `break`).
