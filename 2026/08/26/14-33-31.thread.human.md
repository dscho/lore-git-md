This thread is a small but important documentation cleanup from Junio C Hamano. When users run a deprecated Git command, they see a warning message that previously ran eight lines and could give the impression that the Git project might reverse its decision to remove the command. Junio’s patch tightens this to six lines, removing any suggestion of possible reprieve and instead directing users more clearly to the breaking changes documentation, mailing list archives, and the list itself for help finding a replacement. The change is purely textual—no code behavior changes—and touches only the error message in `usage.c`. There’s nothing left open or contested; this is a straightforward improvement that’s ready to merge.
