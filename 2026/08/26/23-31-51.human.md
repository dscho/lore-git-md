This is the first patch in Junio C Hamano’s two-part refactoring series introducing a varargs `die_for_incompatible_opts()` helper. The patch mechanically swaps the argument order of the existing fixed-arity `die_for_incompatible_optN()` functions from `(int set, const char *name)` to `(const char *name, int set)`. This preparatory change enables the NULL sentinel needed for the upcoming varargs helper, since there is no clear sentinel value for an `int`.

The patch touches 14 built-in commands (`add`, `clone`, `commit`, `difftool`, `gc`, `grep`, `log`, `merge-tree`, `pack-objects`, `push`, `repack`, `replay`, `rev-list`, `show-ref`) plus `parse-options.c`, `parse-options.h`, and `revision.c`. Every call site is updated to match the new parameter order. The change is purely internal: no behavior is altered, and the commit message explains that the swap is necessary for the varargs implementation to work cleanly. The diff is large but straightforward, making it easy to verify that no logic errors were introduced.
