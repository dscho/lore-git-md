This is a small but meaningful documentation patch from Junio C Hamano, the Git maintainer. It rewords the error message shown when a user runs a deprecated Git command (`you_still_use_that()` in `usage.c`).

The change tightens the language to make it clearer that the command is *already* deprecated and there is no process for reversing that decision. The old wording could be read as implying the project might reconsider if enough users complained; the new wording removes that ambiguity and focuses on helping users find a replacement. The commit message explains this intent explicitly.
