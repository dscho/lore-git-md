This is the first patch in Junio C Hamano’s two-patch refactoring series that prepares the ground for a new varargs helper `die_for_incompatible_opts()`. The patch mechanically swaps the parameter order of the existing `die_for_incompatible_optN()` family (N = 2, 3, 4) from `(int set, const char *name)` to `(const char *name, int set)` so that a NULL sentinel can later terminate a varargs list. Every call site in `parse-options.c`, `parse-options.h`, 14 built-in commands (`add`, `clone`, `commit`, `difftool`, `gc`, `grep`, `log`, `merge-tree`, `pack-objects`, `push`, `repack`, `replay`, `rev-list`, `show-ref`), and the `revision` subsystem is updated to match. The change is purely internal; no behavior or user-facing interface is altered. The patch is clean, well-scoped, and ready for review.
