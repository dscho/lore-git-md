This is Junio’s "What’s cooking in git.git" report for August 2026 (#11), the regular digest that tracks the state of all in-flight topics in the Git project. It is primarily a status update rather than a patch, but it is the most efficient way for a busy reader to catch up on what has graduated, what is cooking, and what is stalled.

The report covers 563 non-merge commits that have graduated to `master` since Git 2.55, 75 commits currently cooking in `next`, and 209 commits in `seen`. The highlights:

### Graduated to `master` (irreversibly part of the next release):

- Christian Couder’s `cc/fast-import-usage` series modernized `git fast-import`’s option parsing and usage display using the `parse_options()` API.
- A handful of small fixes: segfaults in `git --shallow-file` (Christian Couder), a misleading `git diff -l` help text (Elijah Newren), and a missing newline in `git send-email`’s error message (Hannes Nyberg).
- Jeff King’s Coverity-driven fixes (`js/coverity-unchecked-returns-fix`) plugged unchecked returns in bisect, transport-helper, and reftable code.
- Johannes Schindelin’s `js/pack-objects-delta-size-t` series widened delta-encoding size fields to `size_t` to avoid truncation on 64-bit Windows.
- Patrick Steinhardt’s ODB streaming unification (`ps/odb-streams`) consolidated read and write streams into a single `struct odb_stream`, paving the way for streaming arbitrary object types.
- Siddharth Shrimali’s `ss/repack-drop-filtered` added `--drop-filtered` to `git repack` to reclaim space by dropping local promisor blobs that exceed a configured limit (e.g., `blob:limit=`).
- Junio’s command-line completion fixes (`jc/complete-checkout` and `jc/complete-diff-tracked-paths`) now complete tracked and untracked paths for `git checkout` and `git diff`.
- Karthik K’s `kk/merge-base-exhaustion` optimized merge-base computation by terminating early when one side’s exclusive commits are exhausted, yielding significant speedups for one-sided histories.

### New topics (not yet in `next`):

- Derrick Stolee’s `dw/config-read-both-global` fixes an inconsistency where `git config --global` read only `$HOME/.gitconfig` and ignored `$XDG_CONFIG_HOME/git/config` when both were present. The series is waiting for a response from Junio.
- Victoria Valtchanov’s `vv/branch-recurse-no-start-ref` fixes a crash in `git branch --recurse-submodules` when the start point is not a reference (e.g., a raw object ID).
- Karthik Nayak’s `kn/reftable-optimize-reloading` optimizes reftable stack reloads by avoiding redundant `stat()` calls when the list file is already locked.
- Karthik K’s `kh/format-patch-range-diff-notes` adds `--range-diff-notes` to `git format-patch` to configure notes specifically for range-diff output.
- Patrick Steinhardt’s `ps/odb-alternates-at-creation` defers alternates setup to ODB creation time during clone, simplifying the backend interface.
- Patrick Steinhardt’s `ps/odb-pluggable-fsck` moves fsck checks into the ODB source layers, making them pluggable for different storage formats.
- René Scharfe’s `rs/worktree-add-basename-fixes` fixes out-of-bounds reads and improper handling of trailing slashes in `git worktree add`.
- Elijah Newren’s `en/no-amend-during-conflicts` teaches `git commit --amend` to refuse during conflict resolution, just like `git cherry-pick` and `git merge` already do.
- Karthik K’s `kn/receive-report-hook` introduces a new `report` hook for `git receive-pack` to filter or modify the status report sent back to the client.

### Stalled topics (no activity for weeks):

- Patrick Steinhardt’s `ps/libgit-in-subdir` (moving `libgit.a` sources into a `lib/` directory) was ejected due to too many evil merges.
- Hugo Santos’s `hs/rebase-continue-edit` (adding `--no-edit` to `git rebase --continue`) and Siddharth Shrimali’s `sn/rebase-update-refs-symrefs` (handling symrefs in `--update-refs`) are both waiting for responses.
- Taylor Blau’s `tb/pack-with-duplicates` (handling duplicate pack entries) and Toon Claes’s `tc/replay-linearize` (adding `--linearize` to `git replay`) are stalled.
- Chungmin Lee’s `cl/regexec-macos-leak` (workaround for macOS regex memory leak) and Christian Couder’s `cc/lazy-fetch-trusted-bit` (configurable lazy fetch for trusted repos) are also stalled.

### Cooking (in `next` or soon to be):

- Adam Simpkins’s `as/utimensat-utimes` replaces the obsolescent `utime()` with `utimensat()` for high-precision timestamps.
- Patrick Steinhardt’s `ps/fetch-packfile-uris-parallel` adds parallel packfile URI fetches via `fetch.packfileURIThreads`.
- Patrick Steinhardt’s `ps/odb-geometric-repack-loose-threshold` aligns geometric repacking’s loose object threshold with `git gc --auto`.
- Elijah Newren’s `en/midx-missing-pack-fallback` makes object lookups gracefully recover when a multi-pack-index points to a removed pack.
- Patrick Steinhardt’s `ps/odb-pluggable-pack-generation` makes packfile generation pluggable, removing hardcoded references to `pack-objects`.
- Taylor Yu’s `ty/repository-fetch-if-missing` moves `fetch_if_missing` into `struct repository`, continuing the libification effort.
- Victoria Valtchanov’s `yn/worktree-ambiguous-remote-advice` improves error messages for ambiguous remote branch names in `git worktree add` and `git checkout`.
- Johannes Schindelin’s `js/mingw-build-updates` upstreamed a collection of Git for Windows build fixes.
- Karthik K’s `kh/trailers-no-urls` stops mistaking URLs for trailers, preventing mangling of textual URLs.

The report is a snapshot of a busy integration cycle, with a mix of small fixes, performance optimizations, and foundational work for pluggable ODB backends. The most notable stalled topics are architectural (e.g., `ps/libgit-in-subdir`, `tb/pack-with-duplicates`), while the cooking topics are mostly incremental improvements.
