Subject: `git subtree add --squash` followed by `git rebase` produces spurious conflict

Originating author: Gabriel Ford <gabe@fordltc.net>
Thread type: bug report

Core problem or goal
When `git subtree add --prefix=<dir> --squash` is used to vendor an external repository that contains a file with the same relative path as an existing file in the main repository (e.g., `.clang-format`), a subsequent `git rebase` onto the main branch produces a spurious conflict between the two files. The files are in separate directories (main repository root vs. subtree prefix directory), and the main repository's file has not changed, so no conflict should occur.

Current status
Newly reported; no prior discussion or resolution. The issue is reproducible in a clean environment with Git 2.55.0 on Linux x86_64. No patches or workarounds have been proposed yet.
