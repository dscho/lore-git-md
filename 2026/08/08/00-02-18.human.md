This is a refactoring patch in Pablo Sabater’s GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder. It is the third patch in the ten-patch v6 series, which is now feature-complete and ready for integration.

The patch removes the `struct object_info_args` wrapper and passes its three members—`server_options`, `oids`, and `object_info_options`—directly to `fetch_object_info()` and `send_object_info_request()`. The wrapper was introduced to reduce parameter count, but the fields are always accessed individually and the struct is constructed immediately before the function call, so the abstraction added no real value. The change is purely mechanical: 44 lines of code are shuffled, but no behavior changes. Junio and Jeff King both endorsed the refactoring as ready to merge, and Karthik Nayak’s feedback about the commit message phrasing has been addressed. The updated commit message now clearly explains that `fetch_object_info()` does use all three fields and that the wrapper was removed because it grouped unrelated pointers.
