This is Junio’s “What’s cooking” report for early August 2026, the third of the month.
It is a dense, maintainer-curated snapshot of every in-flight topic, grouped by integration branch and annotated with status, recent discussion, and graduation notes.

The report opens by noting that the 11th batch of topics has graduated to `master`, bringing the total to 401 non-merge commits since Git 2.55.
Below that, topics are split into four sections:

• **Graduated to ‘master’** – five small, uncontroversial fixes that landed in the last week:
  - dl/pack-bitmap-position-zero plugs a boundary case in reachability bitmap traversal that previously skipped the object at position zero.
  - ds/sparse-index-ita-crash prevents a crash when the sparse-index code encounters an intent-to-add entry outside the cone.
  - jk/cat-file-batch-wo-type-fix stops a segfault in `git cat-file --batch-command` when ‘contents’ is requested without ‘type’.
  - jk/diff-relative-cached-unmerged-more cleans up the relative-path handling in the diff-lib code.
  - mm/revision-pure-get-commit-action refactors get_commit_action() to be a pure predicate, moving side-effecting line-range folding to simplify_commit().
  - tc/merge-default-to-upstream-leakfix fixes a memory leak in `git merge` when run without arguments (the default-to-upstream path).

• **New Topics** – six topics that entered the queue in the last week:
  - ss/repack-drop-filtered (8 patches) teaches `git repack --drop-filtered` to delete local promisor blobs that exceed a configured limit, reclaiming space in partial clones.  The series is marked “Expecting a reroll” because of a SQUASH comment and a review request for additional guards.
  - ty/repo-config-cleanups (3 patches) removes redundant NULL checks from repository configuration getters and clarifies their documentation.  It is ready for review.
  - vm/complete-history (4 patches) adds command-line completion for the experimental `git history` command and its subcommands.  Waiting for review.
  - cc/lazy-fetch-trusted-bit (5 patches) introduces an `uploadpack.lazyFetchTrusted` configuration that lets administrators mark certain repositories as safe for lazy-fetching without requiring the `GIT_NO_LAZY_FETCH` override.  Expecting a reroll after review feedback.
  - dk/use-nsec-runtime (3 patches) converts the build-time `USE_NSEC` knob into a runtime `core.useNanosec` configuration.  Junio asked for a response to a review comment.
  - ps/t7900-deflake-maintenance (2 patches) fixes a flaky test in `t7900` by adapting it to use a throwaway repository.  Needs review.

• **Stalled** – four topics that have not seen activity for weeks:
  - bl/t7412-use-test-path-helpers (1 patch) modernizes `t7412` to use test_path_is_* helpers instead of raw `test -[fde]`.  No response for two months.
  - tb/repack-geometric-cruft (11 patches) teaches `git repack` to combine `--geometric` and `--cruft`.  Stalled on review feedback about a bare `grep !` in a SQUASH comment.
  - hn/checkout-track-fetch (2 patches) extends `git checkout --track` with a “fetch” mode to refresh the start-point.  Junio has indicated he will discard it.
  - za/completion-hide-dotfiles (2 patches) hides dotfiles by default in path completion unless the user explicitly starts the path with a dot.  No response for six weeks.

• **Cooking** – the bulk of the report, listing 30+ topics currently in `next` or `seen`.
  Highlights:
  - ps/odb-streams (8 patches) unifies the `odb_read_stream` and `odb_write_stream` structures into a single `struct odb_stream`, simplifying the streaming API and enabling streaming of arbitrary object types.
  - bc/restrict-hex-to-lowercase (6 patches) prepares for Git 3.0 by making the hex parser reject uppercase characters in the breaking-changes mode.
  - js/mingw-build-updates (12 patches) upstream a batch of Git-for-Windows build cleanups, including dropping obsolete compatibility options and allowing `git.exe` to be used directly without the wrapper process.
  - yn/worktree-add-no-dwim-with-b (1 patch) stops `git worktree add` from doing DWIM when `-b` or `-B` is given.
  - hn/bisect-reset-when-found (2 patches) adds `--reset-when-found` to `git bisect` so it automatically jumps back to the original state or to the found commit.
  - jc/add-resolved (4 patches) introduces `git add --resolved` to stage conflict-resolved paths while leaving unrelated local changes unstaged.
  - tb/pack-with-duplicates (5 patches) hardens the packfile code to handle duplicate object entries gracefully.
  - ps/cat-file-remote-object-info-type (10 patches) extends the `remote-object-info` command to support the `%(objecttype)` placeholder.
  - ps/odb-make-creation-pluggable (6 patches) makes the creation of on-disk ODB structures pluggable, deferring ODB initialization and detangling loose-object-map loading.
  - hn/history-squash (8 patches) adds a `git history squash` subcommand to fold a range of commits into a single commit and replay any descendants on top.
  - mm/diff-process-hunks (11 patches) introduces `diff.<driver>.process` to let an external long-running process act as a hunk provider, controlling which lines Git considers changed while leaving output formatting to Git.
  - hn/branch-delete-merged (7 patches) adds `git branch --delete-merged` to remove local branches that are already merged into their upstream.
  - kk/merge-base-exhaustion (11 patches) optimizes merge-base computation by stopping the walk early when one side’s exclusive commits are exhausted, yielding large speedups for one-sided histories.
