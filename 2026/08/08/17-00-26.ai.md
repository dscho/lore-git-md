This is a review of a usability-focused patch improving the error message for `git worktree add` when an ambiguous remote branch name is provided. The patch, originally submitted by Yoichi NAKAYAMA, adds a detailed advice message explaining the ambiguity and offering actionable workarounds (specifying a fully qualified branch name or setting `checkout.defaultRemote`).

Junio’s review is substantive, focusing on two key aspects of the advice message’s context and clarity. First, he notes that the same advice message is shown in two distinct scenarios—when `worktree.guessremote` is set and when it isn’t—but questions whether the user’s intent (and thus the most helpful suggestion) might differ between them. For example, in the `guessremote` case, the user likely expects Git to infer the branch name from the path, while in the other case, they may have explicitly provided a branch name. Junio suggests tailoring the advice to each scenario for better relevance.

Second, Junio critiques the example command in the advice message (`git worktree add <path> origin/<name>`), arguing that it could mislead users into treating `origin/` as a fixed literal rather than a placeholder for the actual remote name. He proposes rewording the suggestion to emphasize that the remote name (e.g., `origin`) is the critical missing piece, not the command structure itself. Additionally, he flags a style nit (an overly long line with unnecessary braces) and asks for a clearer explanation of the second scenario’s handling in the commit message.

The review does not identify functional flaws but highlights opportunities to refine the user experience by making the advice more context-aware and precise. The patch remains a well-motivated usability improvement, but Junio’s feedback suggests it may need a v2 to address these nuances. No other participants have weighed in yet. Key files: `builtin/worktree.c` (DWIM logic) and `t/t2400-worktree-add.sh` (tests). The new config key `advice.checkoutAmbiguousRemoteBranchName` (default: true) controls the advice visibility.
