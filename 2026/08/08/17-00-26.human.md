This is a usability improvement for `git worktree add` that replaces a terse warning with a detailed advice message when the user provides an ambiguous remote branch name (e.g., `foo` when both `origin/foo` and `upstream/foo` exist). The patch is under review, and Junio C Hamano has raised thoughtful questions about the advice message's clarity and specificity.

The review is substantive, probing the patch’s user-facing messaging rather than its implementation.

The patch itself is well-structured: it adds a new advice message controlled by `advice.checkoutAmbiguousRemoteBranchName` (enabled by default), updates the DWIM logic in `builtin/worktree.c`, and includes test coverage in `t/t2400-worktree-add.sh`.
