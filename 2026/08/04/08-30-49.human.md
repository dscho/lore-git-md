This is the second patch in Harald Nordgren’s **v12 `git history squash` series**, a refactoring that prepares the plumbing for the new subcommand’s default message-editing feature. The patch adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. This change enables the core `squash` command (patch 4/4) to seed the commit message from a constructed template rather than reusing a single commit’s message.

The patch is **pure plumbing** with no user-visible behavior change. It modifies three existing callers (`commit_tree_with_edited_message`, `cmd_history_fixup`, and `split_commit`) to pass NULL, preserving their current behavior. The diff is small (16 lines) and mechanical, touching only the function signature and the three call sites. The commit message is clear and concise, explaining the motivation and the backward-compatibility guarantee.
