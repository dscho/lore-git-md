This is the sixth patch in Patrick Steinhardt’s seven-patch series unifying the ODB streaming API. It performs a targeted rename: `struct read_object_fd_data` becomes `struct fd_stream` to reflect that the structure now holds both the stream state and the file descriptor data, not just the latter. The change is confined to `odb/streaming.c` and updates the type name, its constructor, and the two callback functions (`read_object_fd` → `fd_stream_read`, `close_object_fd` → `fd_stream_close`). No behavior or API changes are introduced; this is purely a mechanical rename to align naming with the new unified `odb_stream` structure introduced in earlier patches. The patch is uncontroversial and should integrate cleanly.
