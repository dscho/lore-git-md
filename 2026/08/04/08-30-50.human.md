This is the third patch in Harald Nordgren’s **v12 series implementing `git history squash`**, a new subcommand that folds a commit range into its oldest commit. This patch is a **refactoring** that prepares the sequencer’s squash-message helpers for reuse by the upcoming `squash` command.

The patch extracts three static functions from `sequencer.c` and moves them to `sequencer.h`:
- `add_squash_combination_header()` – writes the "This is a combination of N commits." banner.
- `add_squash_message_header()` – writes the "This is the 1st/Nth commit message:" (or "will be skipped") header above each message.
- `squash_subject_comment_len()` – returns the length of the leading subject when it should be commented out (for `amend!`, `squash!`, or `fixup!` commits).

It also moves the `todo_item_flags` enum to the header so callers can distinguish an `amend!` (`TODO_REPLACE_FIXUP_MSG`) from a plain `fixup!`.

No behavior change; the only purpose is to let `git history squash` reuse the same autosquash-style template as `git rebase -i`. The patch is **uncontroversial** and ready for integration.
