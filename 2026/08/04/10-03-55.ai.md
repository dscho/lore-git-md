This is the final patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import`’s command-line parsing and libification infrastructure. It removes the now-redundant `from_stream` argument from `parse_one_feature()` and its callers, simplifying the code after patch 11/12 eliminated the only non-stream call site.

The change is purely mechanical: every invocation of `parse_one_feature()` and `check_unsafe_feature()` previously passed `1` as the `from_stream` argument, so the parameter is dropped and the value hard-coded. The patch touches only `builtin/fast-import.c`, reducing its line count by 9 while preserving behavior. No new symbols are introduced; the diff merely removes the argument and updates the function signatures and calls accordingly. The commit message explains the motivation clearly, and the patch itself is a straightforward cleanup that follows logically from the earlier work in the series.
