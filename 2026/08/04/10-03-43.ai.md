This is a refactoring and libification series for `git fast-import`, now expanded to 12 patches in its second iteration. The series standardizes the command's usage string to match its SYNOPSIS documentation, modernizes the parse-options API usage, and begins removing global variables by introducing a `struct fast_import_state`. The ultimate goal is full libification, though many globals remain for future work.

The v2 series addresses Junio's feedback on v1 by eliminating the placeholder local variables in the `struct option` array and fully integrating the parse-options API. New patches (5/12, 6/12, 10/12, 11/12, and 12/12) prepare for and complete the option parsing, including factoring out helper functions and using `OPT_CALLBACK` for complex options. Patch 11/12 also changes behavior by no longer accepting undocumented options (`--alias`, `--get-mark`, `--cat-blob`, `--ls`, and `--notes`) on the command line, as these are meant to be used only in the input stream.

Key technical details include the new `OPT_HIDDEN_GROUP` macro (patch 1/12), expanded parse-options API documentation (patches 2/12 and 3/12), and the introduction of `struct fast_import_state` (patches 7/12 and 8/12). The series touches `parse-options.h`, `parse-options.c`, `builtin/fast-import.c`, and related documentation. CI tests pass except for a likely unrelated Windows+Meson failure.

The work is incremental and well-structured, with clear motivation and no intended behavior changes beyond the undocumented option removal. The libification effort is explicitly marked as incomplete, but the usage string and SYNOPSIS are now consistent, allowing the command to be removed from `t0450/adoc-help-mismatches`. The series awaits broader review beyond Junio's feedback.
