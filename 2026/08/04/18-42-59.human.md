This is a bugfix patch (part 5 of 9) in Pablo Sabater’s GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The series is now at v4 and feature-complete, with all prior review feedback addressed.

This aligns the function’s error handling with the rest of its code paths, which already `die()` on failure, and makes `fetch_object_info()` a `void` function. The change is a straightforward robustness improvement that follows Git’s defensive programming practices.

Files touched are `fetch-object-info.c`, `fetch-object-info.h`, and `transport.c`, with the core logic in `fetch-object-info.c`.
