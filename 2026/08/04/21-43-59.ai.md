This is a feature patch for `gitk`, the built-in Git history browser. It adds user-configurable custom commands that appear in the right-click context menus of both the commit list and the diff display. Users can define up to three commands per area, with support for placeholder substitution (commit ID, title, author, blame origin, etc.) and shell execution. The configuration lives in a new "Commands" tab in the preferences dialog.

The implementation touches only the `gitk` script (217 lines added, 3 removed). It introduces new global variables for the command templates, extends the context-menu procedures to populate the menus dynamically, and adds a new preferences page for configuration. Commands are executed via `sh -c`, allowing background execution and pipes; exit code 42 is treated specially to display command output.

This is a self-contained change to the Tcl/Tk frontend with no impact on Git's core C code or plumbing. The feature is clearly motivated by workflow flexibility and appears well-scoped for a GUI tool. No prior discussion or cover letter is referenced, so the patch stands alone.
