This is the fifth patch in Patrick Steinhardt’s seven-patch series unifying the ODB streaming API. It merges `struct odb_read_stream` and `struct odb_write_stream` into a single `struct odb_stream` that can handle both directions. The patch is a mechanical refactor with two notable adaptations: `builtin/unpack-objects.c` and `odb/streaming.c` now allocate wrapper structures around the new `odb_stream` base instead of embedding data directly in the old `odb_write_stream`. All callers are updated to use the unified type and function names (`odb_stream_read`, `odb_stream_close`, etc.), and the old `odb_write_stream` API is removed. The unit test is adjusted to match.

The change is clean and aligns with the series’ goal of eliminating redundancy in the ODB layer. No behavior changes are introduced, and the patch touches 14 files, including core object handling, archive backends, and packfile code. Reviewers may focus on the completeness of the rename (no lingering references to the old types) and the correctness of the wrapper allocations in the two special cases.
