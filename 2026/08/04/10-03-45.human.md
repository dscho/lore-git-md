This is a documentation patch, part of Christian Couder’s 12-patch series refactoring `git fast-import` to standardize its usage string and prepare for libification. This specific patch adds a missing "Option flags" subsection to `Documentation/technical/api-parse-options.adoc`, documenting the per-option flags (like `PARSE_OPT_HIDDEN`) that can be set in the `flags` field of `struct option`.

The patch is straightforward and well-motivated: the flags are used throughout the codebase (e.g., `PARSE_OPT_HIDDEN` to hide options from `-h` while still showing them with `--help-all`), but until now, developers had to dig into `parse-options.h` to understand them. The new subsection clearly distinguishes these per-option flags from the global `parse_options()` flags, describes each flag’s purpose, and explains the `-h` vs. `--help-all` behavior for hidden options.

No behavior changes are introduced; this is purely documentation. The patch is clean, with no typos or formatting issues, and the commit message clearly explains the gap being filled. It’s a small but useful step toward making the parse-options API more accessible, especially as the broader series modernizes its usage in `git fast-import`. The patch is ready for review and unlikely to be controversial.
