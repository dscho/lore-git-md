This thread introduces a new feature for `gitk`, Git's built-in history browser. Tim Wiederhake has submitted a patch that adds user-configurable custom commands to the right-click context menus in both the commit list and diff display. Users can define up to three commands per area, with support for placeholder substitution (like commit ID, title, or author) and shell execution. The configuration is managed through a new "Commands" tab in the preferences dialog.

The implementation is contained entirely within the `gitk` script, adding 217 lines and removing just 3. It introduces new global variables for command templates, extends the context-menu procedures to populate menus dynamically, and adds the new preferences page. Commands run via `sh -c`, allowing background execution and pipes, with a special exit code (42) to display command output. This is a self-contained change to the Tcl/Tk frontend with no impact on Git's core C code or plumbing. So far, there's been no prior discussion or review activity on this patch.
