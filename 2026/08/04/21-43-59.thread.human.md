This thread is about a patch from Tim Wiederhake that adds user-configurable custom commands to `gitk`'s context menus. The feature lets users define up to three commands per menu (commit list and diff display), with placeholders for commit details and shell execution. The patch is self-contained to `gitk` (Tcl/Tk) and doesn’t touch Git’s core code.

The patch has been blocked on process issues. The maintainer, Johannes Sixt, refused to review the implementation until two conditions were met: the commit message explains the feature’s motivation, and the author confirms they’ve reviewed and understood every line of the AI-assisted code. Tim has now responded, clarifying the motivation—enabling workflows like editing a line at a specific point in history—and explaining his use of AI (Claude) to generate the initial Tcl code. While he iteratively reworked the code to match his intent, it’s still unclear whether this meets the project’s requirement for code ownership. The maintainer hasn’t weighed in yet, so the patch remains stalled.
