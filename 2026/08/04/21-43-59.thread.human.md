This thread introduces a patch by Tim Wiederhake to add user-configurable custom commands to `gitk`'s context menus, allowing users to define and execute shell commands with placeholders (e.g., commit ID, author) directly from the UI. The patch is self-contained to the `gitk` Tcl/Tk frontend and touches no core Git code.

The patch is still in its early review phase, with no prior versions or discussion. The only feedback so far comes from Johannes Sixt (Hannes), the `gitk` maintainer, who has raised two key concerns: the commit message lacks a clear explanation of *why* the feature is needed (making it difficult to assess the design), and the patch was developed with AI assistance (Claude Opus 4.6), which requires the author to personally review and understand every line of the generated code before further review can proceed. Hannes has made it clear he will not engage with the technical implementation until these issues are addressed. No other participants have weighed in yet, and there are no open technical questions—just these procedural and documentation gaps.
