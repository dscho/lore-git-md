This is the sixth patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import` for libification and parse-options modernization. It factors out five option-handling code paths (`--max-pack-size`, `--big-file-threshold`, `--signed-commits`, `--signed-tags`, and `--quiet`) into dedicated `option_*()` helper functions. The change is purely mechanical: the logic is lifted verbatim from the existing `parse_one_option()` switch, so behavior is unchanged except for slightly clearer error messages when argument parsing fails. These helpers will be reused in the upcoming parse-options conversion (patch 10/12), where they will be wired to `OPT_CALLBACK`. The patch is small, focused, and ready for review; it touches only `builtin/fast-import.c`.
