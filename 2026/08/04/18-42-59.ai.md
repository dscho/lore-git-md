This is the fifth patch in Pablo Sabater’s nine-patch GSoC series (v4) extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder in remote-object-info queries. The patch converts the last remaining error path in `fetch_object_info()`—a short read while parsing attribute lines—to `die()` instead of propagating a `-1` return code up the call stack. This aligns the function’s error handling with the rest of its paths and with Git’s defensive programming practices, where protocol violations are treated as fatal. The change is mechanical: the function signature is updated to `void`, and the final `return 0` is removed. Callers in `transport.c` are updated to drop the now-unused return value check. No new test coverage is added, but the patch addresses a latent robustness issue in the object-info subsystem. The change is uncontroversial and ready to merge.
