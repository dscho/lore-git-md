This is the penultimate patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import` to use the parse-options API and prepare for libification. Patch 11/12 finally flips the switch: it replaces the hand-rolled `parse_argv()` loop with a call to `parse_options()`, completing the command-line parsing modernization.

The patch brings three user-visible changes. First, it rejects five undocumented options (`--alias`, `--get-mark`, `--ls`, `--notes`, and `--cat-blob`) on the command line; these were previously accepted as no-ops because the old parser fell through to the in-stream feature handler. Second, it enables abbreviated options like `--dep=5` (for `--depth=5`), a standard parse-options feature. Third, it improves error messages for some options, notably `--cat-blob`, which now fails with “option `cat-blob-fd` requires a value” instead of silently accepting the abbreviation.

The code shrinks by 29 lines, removing the manual option loop and its fall-through logic. The test suite gains a new check that verifies the five feature-only options are rejected on the command line. No other behavior changes are intended, and the patch is purely mechanical: it simply wires up the `struct option` array that earlier patches built. The series remains under review, with only the final clean-up patch left to land.
