This thread adds bash completion support for the `git history` command, a recently introduced interactive rebase helper. Vincent Mailhol contributed the patch, which covers all `git history` subcommands (`drop`, `fixup`, `reword`, `split`), their options, and revision arguments. The implementation leverages Git’s existing completion infrastructure (`__gitcomp_builtin` and `__git_complete_refs`) and includes test coverage in the completion test suite (`t/t9902-completion.sh`).

The patch is a straightforward quality-of-life improvement with no behavioral changes to the command itself. It has been tested for correctness and completeness, and there are no open questions or objections in the thread so far. If the prior `git history` series has already been merged, this patch is likely to follow once reviewed.
