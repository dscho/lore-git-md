This thread is about adding bash completion support for the `git history` command. Vincent Mailhol submitted a single patch that teaches the completion script to handle the command's four subcommands (`drop`, `fixup`, `reword`, `split`), their options, and revision arguments. The patch includes test coverage and touches only the completion script and its test file.

Patrick Steinhardt reviewed the patch and found it a clear improvement, though he noted one edge case: the `split` subcommand's arguments after the first are pathspecs, not revisions, so completion should ideally switch to file paths. He chose not to block the patch on this refinement, calling it "good enough" for a first iteration. He also flagged an upcoming conflict with a new `squash` subcommand that will soon land in `seen`, which will require a trivial rebase. The patch is currently under review, with no objections or requests for changes beyond these observations.
