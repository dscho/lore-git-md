This is patch 10/12 in Christian Couder’s v2 series refactoring `git fast-import` to use the parse-options API and prepare for libification. The patch converts a dozen command-line options from direct string/unsigned assignments to `OPT_CALLBACK` entries in the `fast_import_options` array. Each option now has a dedicated callback function (e.g., `option_parse_date_format`, `option_parse_max_pack_size`) that delegates to the existing helper (e.g., `option_date_format`, `option_max_pack_size`). The change is purely mechanical and preparatory: the callbacks are not yet invoked by `parse_options()`, so behavior is unchanged. The patch touches only `builtin/fast-import.c` and adds no new symbols beyond the callback functions themselves. It is a clear, incremental step toward full parse-options integration, with no controversy or open questions.
