This is the tenth patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import` for libification and parse-options modernization. The patch prepares the ground for actually parsing command-line options via the parse-options API by converting a dozen option-handling code paths into `OPT_CALLBACK` entries in the `fast_import_options` array. Each callback (`option_parse_*`) simply delegates to the existing helper function (`option_*`) that already contains the parsing logic, so the change is purely mechanical and does not alter behavior. The patch touches only `builtin/fast-import.c` and is a straightforward, well-contained step toward the series’ goal of eliminating global variables and standardizing option handling.
