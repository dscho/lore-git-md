This is a small refactoring patch in Christian Couder’s ongoing `git fast-import` libification series. It is the fourth of twelve patches in v2.

The patch localizes the loop counter `i` into each of its four `for` loops inside `cmd_fast_import()`. The original code declared `i` as an `unsigned int` at the function scope, but three of the four loops are better served by a different type (`int` for the first, `size_t` for the last two). By moving the declaration into the loop header, each loop now uses the most appropriate type for its bounds. The change is purely mechanical, with no behavior change intended.

This is a clean, low-risk cleanup that aligns with Git’s coding guidelines. It prepares the ground for later patches in the series that introduce a `struct fast_import_state` and complete the parse-options integration. No review feedback has been posted yet.
