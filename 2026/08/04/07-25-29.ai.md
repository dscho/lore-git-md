This is the first patch in Patrick Steinhardt’s 7-patch series refactoring the object database (ODB) streaming API. It moves the expected size of a write stream from a separate `size_t` parameter into the `struct odb_write_stream` itself, making the stream self-describing. The change is mechanical and touches 14 files, primarily updating function signatures and call sites to use `stream->size` instead of passing the size as a separate argument.

The patch is a preparatory step for the broader goal of unifying `odb_write_stream` and `odb_read_stream` into a single `odb_stream` structure. By embedding the size in the stream, the API becomes more consistent and easier to extend. No behavior changes are introduced, and the commit message clearly explains the motivation: avoiding redundant size parameters and aligning the write stream with the read stream’s design.
