This is the ninth patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import` to modernize its usage string and prepare for libification. The patch replaces the hand-written, single-line usage string with a `struct option` array, aligning the `-h` and `--help-all` output with the SYNOPSIS in `Documentation/git-fast-import.adoc` and grouping options into logical sections (Common, Marks, Submodule rewrite, Signing, and Advanced). Hidden options are marked with `PARSE_OPT_HIDDEN` and organized under an `OPT_HIDDEN_GROUP`, ensuring they appear only with `--help-all`. The patch also removes `git fast-import` from `t0450/adoc-help-mismatches`, as the SYNOPSIS and usage string are now consistent.

The change is purely presentational: the parse-options API is used only to render the help text, not to parse arguments (that work is deferred to later patches). The `struct option` array references variables that will be populated in subsequent patches, but for now they are unused placeholders. The patch is mechanical and preparatory, touching only `builtin/fast-import.c`, `Documentation/git-fast-import.adoc`, and the test file. No behavior change is intended beyond the improved help output.
