This is the second patch in Harald Nordgren’s **v12 `git history squash` series**, a refactoring that prepares the plumbing for the default message-editing feature. The patch adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved.

The change is **minimal and uncontroversial**: it modifies only the function signature and three existing callers (`commit_tree_with_edited_message`, `cmd_history_fixup`, and `split_commit`), all of which pass NULL to preserve their current behavior. The patch is **pure plumbing**, enabling the next patch (4/4) to reuse the sequencer’s autosquash-style template for `git history squash --edit`.

Key names introduced: `message_template` parameter in `commit_tree_ext()`. No new user-visible flags or behaviors are added here. The patch is **ready for integration** and has no unresolved feedback.
