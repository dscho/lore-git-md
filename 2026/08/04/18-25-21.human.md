This is the sixth patch in Patrick Steinhardt’s seven-patch series refactoring the object database (ODB) streaming API to unify read and write operations. The patch renames `struct read_object_fd_data` to `struct fd_stream` in `odb/streaming.c`, along with its constructor and callback functions (`read_object_fd` → `fd_stream_read`, `close_object_fd` → `fd_stream_close`). The rename reflects the structure’s expanded role in the new unified `odb_stream` API, where it now holds both stream state and file descriptor data rather than just the latter.

Justin Tobler’s brief reply confirms the rename addresses his earlier feedback from Patch 5/7 and approves the changes as mechanically sound. This is a surface-level review—no substantive discussion of edge cases or behavior—but the patch itself is uncontroversial and aligns with the series’ broader goal of eliminating redundancy in the ODB streaming layer.
