This is the safety-guard patch in Siddharth Shrimali’s RFC v2 series that adds `--drop-filtered` to `git repack` for partial clones. The patch implements two long-blocking review requirements: it refuses to run while a merge, rebase, cherry-pick, revert, am, or bisect is in progress, and it refuses to drop any blob that the current index references. Both checks are skipped for bare repositories, and the error messages are specific and actionable. The test script adds two new tests that verify the guards work as intended.

Siddharth Asthana’s one-line reply (“Index guard looks good to me. Same idea as on the RFC.”) is a terse but clear endorsement of the implementation. It confirms that the guard is both technically sound and aligned with the earlier RFC discussion, where the same idea was floated. No new issues are raised; the patch is now ready for maintainer sign-off.
