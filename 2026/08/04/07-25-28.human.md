This is a refactoring patch series from Patrick Steinhardt targeting the object database (ODB) streaming interface. The series unifies the two existing stream types—`odb_write_stream` and `odb_read_stream`—into a single `odb_stream` structure, simplifying the API and making streams more versatile. The goal is to enable reuse of streams for different purposes, such as reading an object from one source and writing it to another without intermediate steps.

The series consists of seven patches, each making incremental changes to the streaming code. Key steps include tracking stream size in the structure, dropping redundant fields, supporting arbitrary object types, and consolidating the read and write stream implementations. The final patch renames functions to reflect the unified interface. The changes touch 23 files, primarily in the `odb/` directory but also affecting built-in commands like `git index-pack`, `git pack-objects`, and `git unpack-objects`.

This is part of Patrick’s ongoing ODB abstraction effort, which aims to make Git’s object storage layer more modular and backend-agnostic. The refactoring is mechanical but far-reaching, with no user-visible behavior changes expected.
