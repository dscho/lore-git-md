This is the ninth patch in Christian Couder’s 12-patch v2 series refactoring `git fast-import` to modernize its usage string and prepare for libification. The patch replaces the hand-written, single-line usage string with a `struct option` array, bringing `git fast-import` in line with Git’s standard help-text formatting and making its `-h` and `--help-all` output consistent with the SYNOPSIS in the manual page.

The change is purely presentational: the patch does not alter how options are parsed or what the command actually does. It reorganizes the help text into logical groups (Common, Marks, Submodule rewrite, Signing, and Advanced), marks hidden options with `PARSE_OPT_HIDDEN`, and uses the new `OPT_HIDDEN_GROUP` macro introduced earlier in the series. The SYNOPSIS line in `Documentation/git-fast-import.adoc` is updated to match, and the command is removed from the `t0450/adoc-help-mismatches` test file, indicating that the help text and documentation are now aligned.

The patch is a straightforward, well-motivated cleanup that addresses long-standing inconsistencies in `git fast-import`’s help output. It is part of a larger, incremental effort to modernize the command’s option handling and remove global variables, and it looks ready for review. No behavior changes are intended, and the patch is unlikely to be controversial.
