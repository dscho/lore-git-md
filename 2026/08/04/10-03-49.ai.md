This is patch 6/12 in Christian Couder’s v2 series refactoring `git fast-import` for libification and parse-options modernization. It factors out five option-handling code paths (`--max-pack-size`, `--big-file-threshold`, `--signed-commits`, `--signed-tags`, and `--quiet`) into dedicated `option_*()` helper functions so they can later be reused as `OPT_CALLBACK` targets when the command switches to the parse-options API. The patch also improves error reporting by replacing generic “unknown option” failures with specific `die()` messages when `git_parse_ulong()` fails to parse numeric arguments. No behavior change is intended beyond the more precise error messages. The refactoring is mechanical and preparatory, touching only `builtin/fast-import.c`.
