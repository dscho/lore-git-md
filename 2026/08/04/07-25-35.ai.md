This is the final patch in Patrick Steinhardt’s seven-part series unifying Git’s ODB streaming API. It standardizes the function names that create new streams—renaming `odb_read_stream_open()` to `odb_stream_from_object()` and `odb_write_stream_from_fd()` to `odb_stream_from_fd()`—and adds documentation clarifying that the caller retains ownership of the file descriptor passed to `odb_stream_from_fd()`.

The patch touches eight files, all of which are callers of the renamed functions: `archive-tar.c`, `archive-zip.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, `object-file.c`, `object.c`, `odb/streaming.c`, and `odb/streaming.h`. The changes are mechanical, replacing old function names with their new counterparts, and the commit message explicitly notes the ownership semantics for the file descriptor.

This is a clean, uncontroversial cleanup that completes the API unification begun in earlier patches. The naming is now consistent and the documentation improvement is a welcome addition. No behavior changes are introduced, and the patch is ready for review. The only likely discussion points are edge cases around file descriptor lifecycle management, but the documentation addition should preempt most of those questions.
