This is patch 8/12 in Christian Couder’s v2 series refactoring `git fast-import` for libification. It moves the global variables `seen_data_command` and `allow_unsafe_features` into the newly introduced `struct fast_import_state`. The change is purely mechanical: every access site is already in a function that already receives the `state` parameter, so no new parameter threading is needed. The `fast_import_state_init()` call is reordered to avoid clobbering the early `--allow-unsafe-features` scan, and the `UNUSED` marker is removed from `check_unsafe_feature()` because its `state` parameter is now used. No behavior change is intended. The patch touches only `builtin/fast-import.c` and is a straightforward continuation of the state-encapsulation work begun in patch 7/12.
