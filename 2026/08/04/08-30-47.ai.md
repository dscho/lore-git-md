This is the **v12 iteration of Harald Nordgren’s `git history squash` feature**, a new subcommand that folds a commit range into its oldest commit while preserving descendant history. The series is now **technically complete**, incorporating all of Phillip Wood’s fixup patches from his v10-based branch. This version resolves the last open integration question by fully adopting Phillip’s stricter range validation, merge-parent preservation, and autosquash message handling logic.

Key changes in v12:
- **Single-pass range validation**: Replaces the earlier multi-phase walk with a unified traversal that rejects root commits, multiple tips, and ranges with external parents in one go. Uses object flags (`SQUASH_SEEN`, `SQUASH_TIP`) to track tip count and enforce the "exactly one tip" rule, improving error messages and test coverage.
- **Merge-parent preservation**: The squashed commit now retains the full parent list of the original merge commit (the first commit in the range), preventing silent history corruption. This matches `git commit` and `git merge` behavior.
- **Autosquash message handling**: Resolves `fixup!`, `squash!`, and `amend!` targets directly during the range walk, enforcing stricter rules: a `squash!` or `amend!` is rejected unless its target is the first commit in the range or `--edit` is used, preventing accidental message loss. Supports nested fixups (e.g., `fixup! fixup! target`) and preserves `amend!` messages when squashing into a `fixup!`.
- **Ref-handling**: Protects all local branches descended from the squashed range by default, leaving tags and remote-tracking refs unchanged. The `--update-refs=head` flag restricts updates to the current branch.
- **Editor template**: Builds the autosquash-style template from the exact selected revisions (including exclusions), matching `git rebase -i --autosquash`’s grouping and comment-out behavior.

The series consists of **4 patches**:
1. **Refactoring**: Extracts `first_parent_tree_oid()` helper to centralize logic for resolving a commit’s first-parent tree.
2. **Refactoring**: Adds a `message_template` parameter to `commit_tree_ext()` to support default message editing.
3. **Refactoring**: Moves sequencer’s squash-message helpers (`add_squash_combination_header`, `add_squash_message_header`, `squash_subject_comment_len`) and the `TODO_REPLACE_FIXUP_MSG` flag to `sequencer.h` for reuse.
4. **Core implementation**: Implements `git history squash` with the above features, touching `builtin/history.c`, `sequencer.c`/`sequencer.h`, `advice.c`, and `Documentation/`. The test suite (`t/t3455-history-squash.sh`) is comprehensive, covering edge cases like interior merges, ref handling, and autosquash grouping.

**Key names introduced**: `--[no-]edit`, `--update-refs=(branches|head)`, `resolve_squash_range()`, `squash_check_subject()`, `SQUASH_SEEN`, `SQUASH_TIP`, `SQUASH_AMEND_TARGET`, and test helpers like `check_commit_author()`.
