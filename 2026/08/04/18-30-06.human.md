This is the final patch in Patrick Steinhardt’s seven-part series refactoring Git’s object database (ODB) streaming API. The patch standardizes function names by renaming `odb_read_stream_open()` to `odb_stream_from_object()` and `odb_write_stream_from_fd()` to `odb_stream_from_fd()`, completing the unification of the read and write streaming interfaces. It also adds documentation clarifying that the caller retains ownership of the file descriptor passed to `odb_stream_from_fd()`.

The changes are mechanical, touching eight files (`archive-tar.c`, `archive-zip.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, `object-file.c`, `object.c`, `odb/streaming.c`, and `odb/streaming.h`) to update function calls. Justin Tobler’s review confirms the renames are sensible and notes this patch addresses a naming consistency concern he raised earlier in the series. The patch is uncontroversial and appears ready for integration, with no behavior changes or edge cases introduced beyond the documented file descriptor ownership semantics.

This patch concludes the series, which has incrementally aligned the read and write stream designs to eliminate redundancy and prepare for pluggable ODB backends.
