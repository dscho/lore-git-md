This is the **final patch in Harald Nordgren’s `git history squash` feature series (v12 4/4)**, implementing a new subcommand that folds a commit range into its oldest commit while preserving descendant history. The patch is **ready for integration**, incorporating all feedback from Phillip Wood’s substantive review and resolving the last open technical questions.

The feature allows users to collapse a linear or merge-containing range (e.g., `git history squash HEAD~3..HEAD`) into a single commit, preserving the authorship and parents of the oldest commit and taking the tree of the tip. By default, it opens an editor with an autosquash-style template matching `git rebase -i --autosquash`, but `--no-edit` skips the editor and uses the oldest commit’s message (or the last `amend!` targeting it). The implementation handles `fixup!`, `squash!`, and `amend!` commits strictly: a marker is rejected unless its target is also in the range, and `--no-edit` refuses any `squash!` or `amend!` whose message would be discarded.

Key technical details:
- **Range validation**: Rejects ranges reaching a root commit, with more than one tip, or with external parents. Uses object flags (`SQUASH_SEEN`, `SQUASH_TIP`) to enforce "exactly one tip" and single-pass validation.
- **Merge handling**: Allows fully contained merges (all parents within the range) but rejects merges with external parents. Preserves the full parent list of the original merge commit.
- **Ref protection**: By default, refuses operations that would leave any local branch descended from the squashed range dangling, with advice guiding users to `--update-refs=head` to restrict updates to the current branch.
- **Autosquash message handling**: Resolves `fixup!`, `squash!`, and `amend!` targets during the range walk, enforcing stricter rules (e.g., rejecting `squash!` unless its target is the first commit or `--edit` is used). Supports nested fixups and preserves `amend!` messages when squashing into a `fixup!`.
- **Editor template**: Builds the template from the exact selected revisions, matching `git rebase -i --autosquash`’s grouping and comment-out behavior for `fixup!` messages.

The patch touches `builtin/history.c` (611+ lines), `sequencer.c`/`sequencer.h` (via extracted helpers), `advice.c`/`advice.h`, and adds a comprehensive test suite (`t/t3455-history-squash.sh`, 884 lines). New helpers include `resolve_squash_range()` for range validation, `squash_check_subject()` for autosquash logic, and `build_squash_message()` for template construction.
