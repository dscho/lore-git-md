The patch tweaks the phrasing for each term to reflect what the data model page offers compared to the glossary. The changes are confined to `Documentation/gitglossary.adoc` and `Documentation/glossary-content.adoc`, with no code or test modifications.

This is a clean, well-scoped documentation improvement that directly addresses the series’ goal: making `gitdatamodel(7)` visible to users who might not know it exists.
