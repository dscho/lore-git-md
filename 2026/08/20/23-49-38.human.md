This is a refactoring patch in Justin Tobler’s nine-patch series making `git receive-pack` fully ODB-agnostic. It prepares the ground for moving the unpack logic behind the generic `odb_transaction_write_pack()` interface by changing `unpack()` and `parse_pack_header()` to accept an explicit file descriptor instead of always reading from stdin. The patch touches only `builtin/receive-pack.c` and is purely mechanical: the seven-line diff updates function signatures and passes the new `pack_fd` parameter through the call chain. No behavior change is introduced; the series remains on track for the ODB abstraction effort.
