This is the third patch in Harald Nordgren’s eight-patch series adding `git history squash`, now in its fourteenth iteration. The series is functionally complete and ready for integration, with all prior feedback addressed.

This patch refactors the sequencer’s squash-message formatting helpers into reusable functions and moves the `todo_item_flags` enum to the header. The goal is to let `git history squash` present the same editor template as `git rebase -i`—a banner (“This is a combination of N commits”), numbered headers above each kept message, and commented-out subjects for fixup/squash/amend commits. The changes are purely internal: three static helpers (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) are extracted from `sequencer.c` and exposed in `sequencer.h`, along with the `todo_item_flags` enum so callers can distinguish an `amend!` from a plain `fixup!`. No behavior changes; the patch is a clean refactoring that enables the next patch to reuse the same template logic.
