This thread is about a small but useful documentation improvement: making the `gitdatamodel(7)` man page easier to find. The page, which explains Git's data model in tutorial form, was added years ago but never linked from anywhere, so most users never knew it existed. Kristoffer Haugsbakk is fixing that with a four-patch series that adds cross-references from key documentation files—`git(1)`, `gitglossary(7)`, and the glossary entries themselves—while also ensuring the links work both ways.

The series is now complete and under review. All four patches touch only documentation files, with no code or test changes, and the author has confirmed the full test suite passes when the series is merged with the current `seen` branch. The changes are straightforward: adding `gitdatamodel(7)` to the list of guides, placing it alongside other tutorials in `git(1)`, linking from relevant glossary terms, and finally adding reciprocal links back to the glossary from the data model page itself. No objections or requests for changes have been raised yet, and the series appears ready for merging once it gets a review.
