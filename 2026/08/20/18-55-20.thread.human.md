This thread is about a small but useful documentation improvement from Kristoffer Haugsbakk. The goal is to make Git’s existing `gitdatamodel(7)` man page — a tutorial explaining Git’s data model — easier to find. Right now, the page exists but isn’t linked from anywhere in the official documentation, so most users don’t know it’s there.

Kristoffer’s four-patch series fixes this by adding cross-references: it includes `gitdatamodel(7)` in the list of concept guides in `git(1)`, links to it from the main tutorial section, connects four key glossary terms (blob, commit, object, tree) to the data model page, and adds a reciprocal link back to the glossary. The changes are limited to documentation files and don’t touch any code. Testing on the current `seen` branch showed no regressions, and the series is straightforward and well-justified.

There’s no controversy here — this is a clean, low-risk improvement that addresses a real gap. The series is ready for review and should be uncontroversial.
