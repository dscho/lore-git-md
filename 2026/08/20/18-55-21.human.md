This is the first patch in a four-part documentation series from Kristoffer Haugsbakk that improves the discoverability of the `gitdatamodel(7)` man page. The patch adds `gitdatamodel(7)` to the list of concept guides in `command-list.txt`, which means it will now appear under the "Guides" section in `git(1)` and in the output of `git help --guides`.

The change is minimal -- a single line added to `command-list.txt` -- and directly addresses the core problem: the data model documentation, introduced in November 2025, has been effectively invisible because it wasn’t listed anywhere. This patch is a straightforward, low-risk step toward making that documentation accessible to users who might not know it exists. No code or test changes are involved, and the patch is uncontroversial. It’s part of a well-motivated series that has already been tested against the `seen` branch with no regressions. If the rest of the series is as clean as this patch, it looks like a clear win for documentation usability.
