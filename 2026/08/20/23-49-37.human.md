This is the sixth patch in Justin Tobler’s nine-patch v5 series making `git receive-pack` fully ODB-agnostic. The patch updates error reporting in the unpack machinery to use a `strbuf` instead of returning static strings, preparing the code for the generic `odb_transaction_write_pack()` interface introduced later in the series.

The change is mechanical: `unpack()` and `unpack_with_sideband()` now write any error messages to a caller-provided `strbuf` and return a negative value on failure, rather than returning a static string. Call sites in `cmd_receive_pack()` are updated to use the `strbuf` for reporting. The patch touches only `builtin/receive-pack.c` and is a straightforward refactor with no behavior change.

This is a well-motivated cleanup that removes a minor obstacle to the ODB abstraction. The commit message clearly explains the rationale, and the implementation is clean. The patch is part of a mature series (v5) that has addressed all prior feedback, including the lockfile lifecycle regression fix and test coverage enhancements in earlier patches.
