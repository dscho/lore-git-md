This is a refactoring patch in Justin Tobler’s nine-patch series that completes the ODB abstraction for `git receive-pack`. It is the eighth patch in the v5 iteration, which addresses all remaining feedback from the previous round and is now under final review.

The patch removes a fragile assumption in the ODB transaction system: that the temporary object directory (quarantine area) is always the first entry in the ODB source list. Instead, it makes the newly installed source directly available to callers by returning it from `odb_set_temporary_primary_source()` and propagating it through the call chain. The previous primary source is now reported via an optional out parameter, and the quarantine source is stored in the transaction struct for later use during commit and finalization.

The change is mechanical and touches five files: `object-file.c`, `odb.c`, `odb.h`, `tmp-objdir.c`, and `tmp-objdir.h`. It introduces no new behavior or user-visible changes, but it eliminates a subtle design debt that could cause issues as the ODB abstraction effort matures. The patch is well-motivated in the commit message and aligns with the series’ broader goal of making `git receive-pack` fully backend-agnostic. All prior feedback on this part of the design has been addressed, and the patch is ready for merging.
