This is a documentation patch series (4 patches) from Kristoffer Haugsbakk that advertises the existing `gitdatamodel(7)` man page by linking to it from other documentation. The goal is to make the data model tutorial more discoverable, as it is currently unlinked from anywhere in the documentation.

The series adds `gitdatamodel(7)` to the list of concept guides in `git(1)`, includes a direct link to it in the `git(1)` tutorial section, links four glossary terms (blob, commit, object, tree) to the data model page, and adds a reciprocal link from `gitdatamodel(7)` back to the glossary. The changes touch `Documentation/git.adoc`, `Documentation/gitdatamodel.adoc`, `Documentation/gitglossary.adoc`, `Documentation/glossary-content.adoc`, and `command-list.txt`.

Kristoffer tested the changes by merging the series with the current `seen` branch and running the full test suite (`cd t && make test`), confirming no regressions. The commit messages are clear and the rationale is straightforward: the data model documentation exists but is effectively invisible because it lacks cross-references.

This is a low-risk, high-value improvement to documentation discoverability. The patch is well-scoped, touches only documentation files, and addresses a real gap (an unadvertised man page). No controversy or technical debt is introduced. The series is ready for review and likely to be uncontroversial.
