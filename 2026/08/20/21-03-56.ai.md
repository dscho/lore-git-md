This is the first patch in the v6 series improving error messages for ambiguous remote branch names in `git checkout` and `git switch`. It extracts the advice-display logic into a new shared helper function, `advice_disambiguating_remotes()`, to avoid code duplication and prepare for reuse in `git worktree add` (covered in patch 3/3). The change is purely mechanical: the advice message itself is unchanged, and the patch does not alter behavior. The extracted function takes an `enum checkout_command` parameter to tailor the advice to either `checkout` or `switch`, with a `BUG()` for invalid commands.

The patch touches only `builtin/checkout.c` and is straightforward: the advice block is lifted verbatim from `parse_remote_branch()` into the new helper, and the original code is replaced with a call to that helper. This refactoring is a prerequisite for the functional changes in patches 2/3 and 3/3, which extend the advice to cover more commands and improve the message content. The commit message is minimal but sufficient for the mechanical nature of the change.

This patch is uncontroversial and ready for merging as part of the series. It introduces no new functionality or edge cases, and the extracted helper is well-scoped. The only follow-up work is the functional improvements in the subsequent patches, which build on this refactoring. Files touched: `builtin/checkout.c`; new function: `advice_disambiguating_remotes()`.
