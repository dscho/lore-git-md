This is the fourteenth iteration of a feature series adding `git history squash`, a new subcommand that folds a range of commits into their oldest ancestor in a single operation. The series is now functionally complete and technically ready for integration, with all substantive review feedback addressed across thirteen prior versions.

v14 makes two small housekeeping changes: it updates commit message trailers to include Phillip Wood’s `Signed-off-by` (positioned above his `Helped-by` trailer, per Kristoffer Haugsbakk’s clarification) and simplifies a test case by replacing a fragile `tr a-f A-F` pipeline with `git rev-parse --short`, eliminating a dependency on lowercase hexadecimal output. These changes resolve the last procedural and test-robustness concerns raised in the thread.

The series is split into eight patches. The first three are uncontroversial refactoring: extracting a helper for a commit’s first-parent tree, adding a message-template parameter to `commit_tree_ext`, and sharing sequencer helpers for squash-message formatting. Patches 4–8 implement the core functionality in focused steps: defining the revision input contract, validating ranges (rejecting roots, multi-tip ranges, and external parents), protecting descendant local branches (with sorted error messages and advice for `--update-refs=head`), creating squashed commits without editing (including autosquash handling and merge-parent preservation), and enabling default message editing with an autosquash-style template. The implementation touches `builtin/history.c`, `sequencer.c`/`sequencer.h`, and adds a new test script (`t/t3455-history-squash.sh`) with 886 lines of coverage.

Key behaviors are now finalized: the command rejects operations that would leave local branches dangling, preserves merge topology by retaining the full parent list of the original merge commit, and enforces stricter message rules for `squash!`/`amend!` commits (requiring their target to be the first commit in the range or `--edit` to be used). The default editor workflow matches `git rebase -i --autosquash`, grouping fixup/squash/amend markers under their targets and commenting out `fixup!` messages. The `--no-edit` flag skips the editor, using the oldest commit’s message or the last `amend!` targeting it.
