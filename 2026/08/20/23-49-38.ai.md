This is patch 7/9 in the v5 series extending the ODB transaction system to make `git receive-pack` backend-agnostic. The patch explicitly passes the packfile file descriptor through the call chain instead of hardcoding stdin (`fd 0`) in `unpack()` and `unpack_with_sideband()`.

The change is mechanical: `unpack()` and `parse_pack_header()` now take an `int pack_fd` parameter, and the call sites in `builtin/receive-pack.c` are updated to pass `0` (stdin) where the packfile is read. The sideband multiplexer (`unpack_with_sideband()`) still uses stdin, so its call to `unpack()` passes `0` as well. The patch touches only `builtin/receive-pack.c` and introduces no new symbols or behavior changes.

This is a necessary refactoring to prepare for the generic `odb_transaction_write_pack()` interface in patch 9/9, which will move the unpack logic behind the ODB transaction system. The explicit file descriptor passing removes the last hardcoded assumption about where the packfile is read from, aligning with the series' goal of making `git receive-pack` fully ODB-agnostic. The patch is well-motivated and uncontroversial, addressing a technical prerequisite for the broader ODB abstraction effort. All prior feedback on the series has been incorporated, and this patch is ready for merging as part of the larger transaction work.
