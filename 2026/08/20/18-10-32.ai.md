This is the final patch in Harald Nordgren’s `git history squash` series (v14, 8/8), implementing the default message-editing workflow. The patch enables users to combine commit messages interactively when squashing a range, matching the behavior of `git rebase -i --autosquash`.

The implementation records the selected commits as a `todo` list, rearranges it using Git’s existing sequencer machinery, and builds an editor template that groups `fixup!`, `squash!`, and `amend!` commits under their targets. The template follows the same rules as interactive rebase: `fixup!` messages are commented out entirely, `squash!` messages retain their bodies with only the marker subject commented, and `amend!` replaces its target’s message unless a preceding `squash!` requires both bodies. The `--no-edit` flag remains available to skip the editor and use the oldest commit’s message (or the last `amend!` targeting it).

The patch touches `builtin/history.c` (adding the `build_squash_message` helper and integrating it into `resolve_squash_range`), updates `Documentation/git-history.adoc` to document the new behavior, and extends the test suite (`t/t3455-history-squash.sh`) with 200+ lines of coverage for editor interaction, empty-message aborts, marker handling, and template formatting. The test cases verify that the template matches `git rebase -i --autosquash`’s output, including edge cases like nested markers and `amend!`/`squash!` interactions.
