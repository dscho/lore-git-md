This is patch 8/9 in Justin Tobler’s v5 series making `git receive-pack` fully ODB-agnostic. The patch removes a fragile assumption that the temporary quarantine directory is always the first entry in the ODB source list by returning the newly installed source directly from `odb_set_temporary_primary_source()` and propagating it through the call chain. The “files” ODB transaction now stores the quarantine source explicitly, eliminating the need to rely on source list ordering during commit and finalize. The change is mechanical: `odb_set_temporary_primary_source()` gains a `prev_source` out-parameter, `tmp_objdir_replace_primary_odb()` now returns the new source, and `struct odb_transaction_files` adds a `quarantine` field. No behavior change; the patch is a pure refactoring that tightens the interface for future ODB backends.
