This is the third patch in Justin Tobler’s nine-patch v5 series making `git receive-pack` fully ODB-agnostic. The series is part of Patrick Steinhardt’s ongoing ODB abstraction effort and is now technically complete, with all reviewer feedback addressed.

This patch removes the global `alt_shallow_file` variable by lifting the temporary shallow file setup out of `unpack()` and passing the shallow file path explicitly through the call chain. The change is a prerequisite for moving the unpack logic behind the new `odb_transaction_write_pack()` interface in a later patch, which cannot rely on global state. The patch touches only `builtin/receive-pack.c`, updating function signatures and wiring the shallow file path through `unpack()`, `unpack_with_sideband()`, `prepare_shallow_update()`, and `update_shallow_info()`. No user-visible behavior changes; the patch is purely internal refactoring.

The patch is clean and well-motivated: the commit message clearly explains why the global state must be removed, and the code changes are mechanical and localized. The explicit passing of the shallow file path aligns with the series’ broader goal of eliminating global state and making the codebase more modular. This patch is uncontroversial and ready for merging, pending Junio’s final review of the full series. It is a small but necessary step toward the ODB abstraction goal.
