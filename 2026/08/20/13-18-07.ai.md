This is the first patch in D. Ben Knoble’s three-patch series `dk/use-nsec-runtime` (v4), which is cooking in `next` and ready to graduate to `master`. It is a build-system fix targeting the Meson build.

The patch exposes a configurable knob (`man_base_url`) for Meson builds, mirroring the long-standing `MAN_BASE_URL` option in the Makefile. Currently, Meson hard-codes the base URL for relative links in manuals to `$prefix/$mandir`, which is incorrect for most distros (links end up broken, e.g., `/usr/share/manuser-manual.html`). The patch changes the default to `file://$(htmldir)/` (with a trailing slash) to match the Makefile’s behavior and adds a Meson option so distributions like Gentoo can override it if needed. The change is motivated by the author’s observation that a later patch in the series (adding a link to `technical/racy-git.html`) produced broken links in the generated man pages.

The patch touches only `Documentation/meson.build` and `meson_options.txt`, adding eight lines and changing one. It is uncontroversial and has already been reviewed by Patrick Steinhardt, who confirmed it aligns with the Makefile’s behavior. No further changes are expected. The only loose end is whether any distributions actually use `MAN_BASE_URL` today, but the author notes that a proper audit would require inspecting distro build scripts, which has not been done. The patch is ready to advance independently of the rest of the series.
