This is the first patch in D. Ben Knoble’s three-patch series converting the build-time `USE_NSEC` macro to a runtime configuration option (`core.useNanosec`). The series is cooking in `next` under the topic `dk/use-nsec-runtime` and is ready to graduate to `master` after final polish.

This patch addresses a long-standing inconsistency between Makefile and Meson builds: the Makefile has allowed `MAN_BASE_URL` to be configured since 2009, but Meson hard-codes a value that produces broken relative links in man pages. The patch changes the Meson default to `file://$(htmldir)/` (matching the Makefile’s behavior) and adds a configurable knob so distributions can override it if needed. The change is uncontroversial and aligns with the established build system conventions.

The patch touches only `Documentation/meson.build` and `meson_options.txt`, adding eight lines and changing one. It is self-contained and unlikely to require additional testing. The author notes that the patch was motivated by noticing broken links in a later patch, but the fix stands on its own as a build-system improvement. No objections or review comments have been raised on this patch in the thread.
