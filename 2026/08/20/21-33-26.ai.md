This is a brief follow-up in the ODB transaction series targeting `git receive-pack`. Patrick Steinhardt’s review of this patch identified a missing test step: the test does not verify that the `.keep` file is correctly migrated to the target repository during the reference update phase, which is critical for protecting the packfile from pruning while refs are being updated. The proposed test addition uses a `reference-transaction` hook to check for the `.keep` file’s presence in the main ODB during the reference update, then confirms its removal afterward.
