**Core problem or goal**
Fix Bash completion for `git checkout -C <dir>` to only suggest tracked paths (those in the index) rather than falling back to untracked paths. The series includes a preparatory refactoring to simplify the logic before applying the fix. Junio has since noted a potential future enhancement: completing paths that exist in a target branch but are untracked in the working tree (e.g., `git checkout other-branch <path>`), though this is not implemented due to lack of existing completion machinery for arbitrary trees. Additionally, Junio clarified in a follow-up that `__git_complete_index_file` must be called with the `--cached` option to strictly enforce tracked-path completion, ensuring untracked files are excluded.
