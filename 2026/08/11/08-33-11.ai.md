This is patch 9/12 of Christian Couder’s v3 series refactoring `git fast-import` to modernize its usage string and prepare for libification. The patch replaces the hand-written, single-line usage string with a `struct option` array, grouping options into logical sections (Common, Marks, Submodule rewrite, Signing, and Advanced), marking hidden options with `PARSE_OPT_HIDDEN`, and using the `OPT_HIDDEN_GROUP` macro introduced earlier in the series. The SYNOPSIS line in `Documentation/git-fast-import.adoc` is updated to match, and the command is removed from `t0450/adoc-help-mismatches`, indicating the help text now aligns with the documentation.

The change is purely presentational and preparatory: the new `fast_import_options` array is passed to `show_usage_with_options_if_asked()` to render `-h` and `--help-all` output, but the actual parsing is still handled by the existing hand-written loop in `parse_argv()`. The patch touches only `builtin/fast-import.c`, `Documentation/git-fast-import.adoc`, and the test file `t/t0450/adoc-help-mismatches`, with no behavior changes beyond improved help output. The `struct option` array includes all documented options, organizes them into logical groups, and marks hidden options appropriately, enabling future patches to complete the parse-options integration. The patch is well-structured and clearly motivated, serving as a key enabler for the parse-options conversion in patch 11/12.
