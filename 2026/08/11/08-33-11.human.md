This is patch 9/12 in Christian Couder’s v3 series refactoring `git fast-import` to use the parse-options API. The patch replaces the hand-written, single-line usage string with a `struct option` array, grouping options into logical sections (Common, Marks, Submodule rewrite, Signing, and Advanced), marking hidden options with `PARSE_OPT_HIDDEN`, and using the `OPT_HIDDEN_GROUP` macro introduced earlier in the series. The SYNOPSIS line in `Documentation/git-fast-import.adoc` is updated to match, and the command is removed from `t0450/adoc-help-mismatches`.

The change is purely presentational and preparatory: `git fast-import -h` now shows a multi-line, grouped usage message that matches the SYNOPSIS documentation, and `--help-all` reveals the hidden options. No behavior changes are introduced; the actual parsing of options remains handled by the existing hand-written loop for now. The patch is a clean, incremental step toward the parse-options integration completed in patch 11/12, and it aligns with Git’s broader effort to standardize help output across commands. The commit message clearly explains the motivation and the scope of the change, and the implementation is straightforward. This patch should interest anyone working on parse-options modernization or `git fast-import` internals.
