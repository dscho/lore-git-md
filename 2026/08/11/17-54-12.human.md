This is a refactoring patch in Justin Tobler’s nine-patch series that makes `git receive-pack` fully ODB-agnostic. It changes how unpack errors are reported: instead of returning a static string, the `unpack()` function now writes error messages to a caller-provided `strbuf` and returns a negative value on failure. The call sites in `receive-pack.c` are updated to match.

The patch is a mechanical but necessary step toward the series’ goal: moving the unpack logic behind the new `odb_transaction_write_pack()` interface. By switching to `strbuf`-based error reporting, the code avoids hardcoded strings and prepares for the transaction layer to handle errors generically. No user-visible behavior changes; this is purely plumbing.

The change is straightforward and well-contained, touching only `builtin/receive-pack.c`. The diff is clean, and the commit message clearly explains the motivation. This patch looks ready to merge as part of the larger ODB abstraction effort.
