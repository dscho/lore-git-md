This is a test infrastructure patch, part of the v8 series optimizing `paint_down_to_common()` in Git’s commit-reach subsystem. Specifically, it improves diagnostic output for Trace2 data assertions by introducing `test_trace2_data_singular()`, a helper that verifies a Trace2 event appears exactly once and reports mismatches in detail.

The patch addresses a long-standing pain point in Git’s test suite: the existing `test_trace2_data` helper is a bare `grep` that fails silently, making debugging difficult when Trace2 events don’t match expectations. The new helper checks for three failure modes—missing events, duplicate entries, or value mismatches—and prints clear diagnostics to FD 4 (the same channel used by `test_grep`). For example, a value mismatch now shows the expected and actual values side by side, rather than just returning a silent exit code.

The implementation is straightforward: it uses `sed` to extract the value from the Trace2 JSON event, then checks for duplicates (newlines in the output) and compares the value against the expected one. The helper also accepts an optional label for context, which is included in error messages. This is a pure test infrastructure improvement with no behavioral changes to Git itself, but it directly supports the broader series by making Trace2-based performance instrumentation more robust and debuggable.
