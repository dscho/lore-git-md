This is a refactoring patch in Justin Tobler’s nine-patch series that completes the ODB abstraction for `git receive-pack`. Specifically, patch 3/9 lifts the temporary shallow file setup out of the `unpack()` function and wires it through explicitly to its call sites, removing reliance on global state (`alt_shallow_file`).

The change is mechanical: the shallow file path is now passed as a parameter to `unpack()`, `unpack_with_sideband()`, `prepare_shallow_update()`, and `update_shallow_info()`. The global `alt_shallow_file` variable is removed, and the temporary shallow file is created at the call site in `cmd_receive_pack()` before being passed down. This prepares the code for the subsequent move of `unpack()` behind the generic ODB transaction interface, which cannot depend on global state.

The patch touches only `builtin/receive-pack.c` and is a straightforward refactor with no behavior change. It aligns with the series’ broader goal of making `git receive-pack` fully ODB-agnostic by eliminating hidden dependencies on the "files" backend. The change is well-motivated and necessary for the transaction interface introduced later in the series. No controversy or open questions are evident in this specific patch.
