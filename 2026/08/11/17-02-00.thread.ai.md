Subject: [PATCH] http: add http.sslVerifyStatus to check OCSP staples
Series version: standalone patch (no series)
Originating author: graysongordon-gl
Thread type: security feature patch

Core problem or goal
Git’s HTTPS certificate verification currently omits OCSP staple validation, leaving it vulnerable to accepting revoked certificates. While libcurl supports staple checking via `CURLOPT_SSL_VERIFYSTATUS`, Git does not expose this capability. The patch adds a boolean `http.sslVerifyStatus` option (default `false`) that enables staple validation, causing connections to fail if the server does not provide a staple. The design is fail-closed for security but defaults to `false` to avoid breaking remotes that do not support stapling.
