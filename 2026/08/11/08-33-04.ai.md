This is a documentation patch, the second in Christian Couder’s v3 series refactoring `git fast-import`’s usage string and preparing for libification. It adds a new “Option flags” subsection to `Documentation/technical/api-parse-options.adoc` that documents the per-option flags (e.g., `PARSE_OPT_HIDDEN`, `PARSE_OPT_OPTARG`, `PARSE_OPT_LASTARG_DEFAULT`) that can be set via the `flags` field of `struct option` or the `OPT_*_F()` macro variants. The documentation explicitly distinguishes these from the global `parse_options()` flags, describes the `-h` versus `--help-all` behavior for hidden options, and lists each flag’s purpose and typical use cases. Elijah Newren’s feedback on the `PARSE_OPT_LASTARG_DEFAULT` description has been incorporated: the rewording now clarifies that the no-argument form is only accepted when the option is the last token on the command line and that it should not be combined with `PARSE_OPT_OPTARG`. The patch is purely additive, touching only the documentation file, and is a foundational step for later patches that use these flags to organize `git fast-import`’s hidden options.
