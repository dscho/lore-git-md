This is an **announcement for Git for Windows 2.55.0(4)**, a security-fix release targeting the Windows platform. It is not a patch to upstream Git itself, but a downstream update to the Git for Windows fork maintained by Johannes Schindelin.

The release addresses **CVE-2026-62960**, a security vulnerability where attacker-controlled servers could advertise bundle URIs pointing to network shares, causing Windows to transparently perform NTLM authentication and disclose the user's NTLMv2 hash. The fix aligns bundle URI handling with Git's existing protocol restrictions, excluding `file://` URIs by default. This is a targeted security patch with no other changes mentioned.

Git for Windows is dropping support for Windows 8.1 after this release, following the upstream MSYS2 project's decision. The announcement includes download links and SHA-256 checksums for all variants (64-bit, ARM64, portable, MinGit, and busybox builds).

If you use Git on Windows, this update is worth applying promptly due to the security fix. For developers following upstream Git development, this is purely informational—no action is needed unless you maintain Windows-specific tooling or packaging.
