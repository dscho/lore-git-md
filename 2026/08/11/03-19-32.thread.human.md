This thread is a small but useful fix to Git’s Bash completion for `git checkout -C <dir>`. Junio C Hamano sent a two-patch series that ensures path completion for this command only suggests tracked files (those in the index), rather than falling back to untracked files in the current directory. The first patch refactors the completion logic without changing behavior, while the second implements the fix and adds test coverage.

Junio later clarified a minor but important detail in the second patch: the `__git_complete_index_file` helper should be called with the `--cached` option to strictly limit suggestions to tracked paths. This adjustment ensures the fix works as intended. The series is uncontroversial, with no objections or open questions—just a straightforward improvement to usability. D.
