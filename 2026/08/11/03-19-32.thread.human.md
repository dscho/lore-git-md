This thread is a three-patch series from Junio C Hamano fixing Bash completion for `git checkout`, particularly when used with `-C <dir>`. The goal is to make completion prioritize tracked paths (those in the index) over untracked ones, while adding a fallback to untracked paths as a last resort for consistency with the earlier `git diff` completion fix.

The series is now complete and ready for integration. The first patch refactors the completion script to prepare for the functional changes without altering behavior. The second patch ensures that `git checkout <path>` (with or without `-C <dir>`) completes only tracked paths by default, addressing a usability gap where untracked files were previously suggested inconsistently. The third patch adds the fallback to untracked paths when no tracked paths match, preventing silent completion failures. All patches include thorough test coverage, verifying both the happy path and edge cases like missing files or directory changes.
