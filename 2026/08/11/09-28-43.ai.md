This is the first patch in the v8 series optimizing `paint_down_to_common()` for one-sided histories. It adds a new technical document (`Documentation/technical/paint-down-to-common.adoc`) that explains the algorithm, generation-number regions ("ordered" and "unordered"), termination conditions, and clock-skew invariants. The document is now fully aligned with the series' adopted "ordered/unordered" terminology, replacing the earlier "finite/INFINITY region" phrasing to better reflect the semantic boundary between regions where topological ordering holds and where it does not.

The patch touches `Documentation/Makefile` and `Documentation/technical/meson.build` to include the new document in the build system, and adds a cross-reference in `commit-reach.c` to the technical document. The document itself is comprehensive, covering use cases (merge-base computation and ancestry checks), the paint-walk algorithm, generation-number regions, termination conditions (stale entry, generation cutoff, single result), and the commit-date ordering fallback for v1 commit-graphs. It also clarifies how v1 commit-graphs fit into the region model, using `GENERATION_NUMBER_V1_MAX` as the topological ceiling.

This patch is purely documentation and does not change runtime behavior. It provides the foundational context for the subsequent performance optimizations and refactoring in the series, ensuring reviewers and future maintainers understand the algorithm's invariants and edge cases. The document is well-structured and clearly written, addressing all prior review feedback about terminology and conceptual clarity.
