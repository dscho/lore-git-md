This thread introduces a security feature to Git’s HTTPS transport: the `http.sslVerifyStatus` configuration option, which enables OCSP staple validation to prevent Git from accepting revoked certificates. The new option defaults to `false` to avoid breaking existing setups but fails closed when enabled, rejecting connections if the server does not provide a valid staple.
