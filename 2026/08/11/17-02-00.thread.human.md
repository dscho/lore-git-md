This thread is about a security feature patch that adds `http.sslVerifyStatus`, a new Git configuration option to enable OCSP staple validation for HTTPS connections. The patch, now in its sixth iteration, is technically complete and addresses a specific security gap: OpenSSL-linked Git binaries (common in FIPS-compliant environments like US Department of Defense PKI) currently ignore OCSP staples, leaving revoked certificates unchecked. When enabled, the feature enforces fail-closed behavior—connections fail if the server doesn’t provide a valid staple—aligning with government and enterprise security requirements.

Key details include the new boolean config option (defaulting to `false` for backward compatibility), per-URL override support, and integration with libcurl’s `CURLOPT_SSL_VERIFYSTATUS`. The patch touches `http.c`, documentation, and test files, with robust error handling and backend parity in recent libcurl versions.
