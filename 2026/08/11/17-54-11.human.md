This is the fifth patch in Justin Tobler’s nine-patch v3 series that refactors `git receive-pack` to use ODB transactions for pluggable packfile writes. The series is part of the broader ODB abstraction effort led by Patrick Steinhardt, and this patch specifically lifts global state out of the `unpack()` function by introducing a `struct unpack_opts` to pass configuration explicitly.

The patch replaces several global variables (`receive_fsck_objects`, `transfer_fsck_objects`, `fsck_msg_types`, `max_input_size`, `reject_thin`, `quiet`, and `shallow_file`) with a structured `unpack_opts` that is passed into `unpack()` and `unpack_with_sideband()`. This is a necessary step toward making the packfile ingestion logic backend-agnostic, as the subsequent patches will move this logic behind a generic ODB transaction interface. The change is mechanical and well-explained: the commit message clearly states the motivation (removing reliance on globals for future ODB abstraction) and the implementation (introducing `struct unpack_opts`).

The patch touches only `builtin/receive-pack.c` and is straightforward: it defines the new `struct unpack_opts`, updates `unpack()` to accept it, and adjusts `unpack_with_sideband()` to initialize and pass the struct. The ternary initialization of `fsck_objects` and the late assignment of `err_fd` in `unpack_with_sideband()` are preserved as trade-offs for removing global state, which aligns with the series’ broader pattern of avoiding static variables in favor of explicit repository state. No user-visible behavior changes are introduced, and the patch appears well-crafted with no obvious oversights.

This is a refactoring patch that prepares the ground for the ODB abstraction work in later patches. It looks ready for review and should not be controversial, as it follows established Git patterns for eliminating global state. The patch is part of a larger, actively reviewed series that has already addressed critical design flaws in earlier iterations, and this step is a logical continuation of that effort.
