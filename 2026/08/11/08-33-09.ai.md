This is patch 7/12 of Christian Couder’s v3 series refactoring `git fast-import` to reduce global variables and prepare for libification. The patch introduces `struct fast_import_state` and moves the first three globals (`global_argc`, `global_argv`, `global_prefix`) into it, passing the struct as the first parameter to nearly every function in `builtin/fast-import.c`. Many functions receive the new parameter only to forward it or for future use, so they are marked `UNUSED` to silence compiler warnings. The change is purely mechanical and preparatory, with no intended behavior change. Elijah Newren’s feedback on overly long function signatures was addressed in v3 by reformatting all modified lines to Git’s 80-character limit. The patch touches only `builtin/fast-import.c` and is a solid, incremental step toward the series’ goal of modernizing the codebase.
