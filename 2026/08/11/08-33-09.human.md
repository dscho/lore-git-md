This is patch 7/12 in Christian Couder’s ongoing `git fast-import` refactoring series. It introduces `struct fast_import_state` to start encapsulating the command’s global variables, beginning with `global_argc`, `global_argv`, and `global_prefix`. The patch is purely mechanical: every function that previously accessed these globals now receives a `struct fast_import_state *` parameter, and the globals are removed from the file. Many functions are marked `UNUSED` because they only forward the state or will use it in later patches. No behavior changes are intended, and the diff is confined to `builtin/fast-import.c`.

The patch is a clear, incremental step toward libification. It follows the pattern established by `builtin/apply.c` and is well-motivated by the series’ goal of reducing global state. Elijah Newren’s feedback on v2 was purely stylistic (overly long function signatures) and has been addressed in v3 by reformatting to Git’s 80-character line limit. The patch is ready for review and should interest anyone working on parse-options modernization or `git fast-import` internals.
