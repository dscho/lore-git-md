This is the final patch (12/12) in Christian Couder’s `git fast-import` refactoring and libification series. It removes the redundant `from_stream` argument from `parse_one_feature()` and its callers after patch 11/12 eliminated the only non-stream call site.

The change is purely mechanical: every invocation of `parse_one_feature()` previously passed `1` as the `from_stream` argument, so the parameter is dropped and the value hard-coded. The `check_unsafe_feature()` helper is updated to match, removing its own `from_stream` parameter since it is now always called in a stream context. The patch touches only `builtin/fast-import.c`, reducing its line count by 9 while preserving behavior. No new symbols are introduced, and the simplification is a direct follow-up to the parse-options integration completed in patch 11/12.

This patch is a clean-up and does not introduce any behavioral changes or new technical debt. It is a logical conclusion to the series’ preparatory work and aligns with the goal of reducing global state and improving code clarity. The series as a whole is now complete, with all feedback addressed and the remaining edge case (the `--allow-unsafe-features` inconsistency) documented as a known limitation.
