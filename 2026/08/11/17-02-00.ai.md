This is a security feature patch introducing `http.sslVerifyStatus`, a new configuration option that enables Git to check stapled OCSP responses during TLS handshakes. The patch addresses a gap in Git's HTTPS certificate verification: while Git already verifies peer certificates and hostnames via libcurl, it does not request or validate OCSP staples (revocation status information sent by the server), leaving it vulnerable to accepting revoked certificates. The behavior varies by TLS backend—OpenSSL ignores staples unless explicitly asked, while GnuTLS checks them by default—creating inconsistent security across builds.

The patch adds a boolean `http.sslVerifyStatus` option (defaulting to `false`) that sets `CURLOPT_SSL_VERIFYSTATUS` in libcurl. This is a fail-closed design: if the server doesn’t staple a response, the connection fails. The commit message explains why the default must be `false` (to avoid breaking remotes that don’t staple) and why the option can’t delegate to libcurl’s default (libcurl intentionally leaves this off). The implementation includes per-URL configuration support (e.g., `http.https://example.com/.sslVerifyStatus`) and fails loudly if the TLS backend lacks staple-checking capability.

The new test file `t/t5567-http-verify-status.sh` verifies the fail-closed behavior by confirming that enabling the option turns a working fetch into a failing one when the test server (which doesn’t staple) is used. Tests also cover per-URL configuration and ensure the option doesn’t break existing workflows when disabled. The patch targets the `http.c` subsystem, with documentation in `Documentation/config/http.adoc`, and requires libcurl ≥ 7.41.0 (already below Git’s minimum version).

This is a well-motivated security improvement with thorough testing and clear documentation. The commit message’s explanation of backend differences and design trade-offs is particularly strong, and the fail-closed approach aligns with security best practices. The patch is likely to be uncontroversial but may spark discussion about whether the default should eventually change or if users should be warned when staples are ignored.
