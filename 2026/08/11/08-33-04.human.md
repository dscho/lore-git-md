This is a documentation patch, the second in Christian Couder’s twelve-patch v3 series refactoring `git fast-import`’s usage string and preparing for libification. It adds a new “Option flags” subsection to `Documentation/technical/api-parse-options.adoc` that documents the per-option flags (e.g., `PARSE_OPT_HIDDEN`, `PARSE_OPT_OPTARG`, `PARSE_OPT_LASTARG_DEFAULT`) that can be set via the `flags` member of `struct option` or the `OPT_*_F()` macro variants. The text explicitly distinguishes these flags from the global `parse_options()` flags, describes the `-h` versus `--help-all` behavior for hidden options, and lists every flag with a concise explanation of its purpose and typical use case.

The patch is purely additive, touching only the documentation file, and directly addresses feedback from Elijah Newren on the v2 iteration: the `PARSE_OPT_LASTARG_DEFAULT` description now clarifies that the no-argument form is only accepted when the option is the last token on the command line and that it should not be combined with `PARSE_OPT_OPTARG`. The change is well-motivated, uncontroversial, and already reviewed favorably by Newren. It provides the missing reference material that developers need when working with parse-options, making it a small but valuable step toward the series’ larger goal of standardizing and libifying `git fast-import`.
