This is a documentation patch, the third in Christian Couder’s 12-patch v3 series refactoring `git fast-import`’s usage string and preparing for libification. It updates `Documentation/technical/api-parse-options.adoc` to document the `OPT_*_F()` macro variants (which accept a trailing `flags` argument) and the convenience macros `OPT_HIDDEN_GROUP()` and `OPT_HIDDEN_BOOL()`, both of which were introduced in earlier patches of the same series. The patch is purely additive: it inserts 18 lines of explanatory text, placing the new macros adjacent to their non-hidden counterparts (`OPT_GROUP()` and `OPT_BOOL()`) and clarifying the `_F` suffix convention. No code behavior changes; the patch exists solely to improve the API documentation for future contributors. Elijah Newren’s feedback on the series has already been incorporated in earlier patches, and this patch itself has no open review comments. The change is uncontroversial and aligns with the series’ goal of modernizing parse-options usage.
