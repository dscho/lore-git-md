This is the first patch in Christian Couder’s 12-patch series refactoring `git fast-import`’s usage string and preparing for libification. It introduces a new `OPT_HIDDEN_GROUP` macro to the parse-options API, allowing hidden options to be grouped logically without exposing the group header in the default `-h` help output. The group and its options appear only when `--help-all` is requested.

The patch is a small, self-contained infrastructure addition. It updates `parse-options.c` to skip hidden groups unless `--help-all` is used, adds the macro definition to `parse-options.h`, and extends the test helper (`test-parse-options.c`) and test suite (`t/t0040-parse-options.sh`) to verify the new behavior. The change is purely additive and backward-compatible; no existing code is modified beyond the new macro’s implementation.

This is a well-crafted, incremental step toward the series’ larger goal of standardizing `git fast-import`’s usage string and modernizing its parse-options usage. The motivation is clear, the implementation is clean, and the test coverage is thorough. The patch should interest anyone working on parse-options or help-text consistency across Git commands.
