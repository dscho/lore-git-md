Core problem or goal
Git for Windows 2.55.0(4) fixes CVE-2026-62960, a Windows-specific vulnerability in bundle URI handling. When cloning from an attacker-controlled server, the server could advertise a bundle URI pointing to a network share, causing Windows to transparently perform NTLM authentication and disclose the user’s NTLMv2 hash. The fix blocks `file://` URIs by default, aligning bundle URI handling with Git’s existing protocol restrictions. The vulnerability is rated high-risk due to the potential for credential theft via brute-forcing the captured hash.

Current status
The fix is already shipped in Git for Windows 2.55.0(4). No further action is expected on the Git mailing list unless downstream packagers have questions. Upstream Git (the project on `git@vger.kernel.org`) is unaffected.

Key technical details
- **Platform**: Windows only; upstream Git is unaffected.
- **Vulnerability**: NTLMv2 hash disclosure via attacker-controlled bundle URI pointing to a network share.
- **Fix**: Block `file://` URIs by default in bundle URI handling.
