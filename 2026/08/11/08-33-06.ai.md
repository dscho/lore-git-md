This is a refactoring patch in the `git fast-import` libification series. It localizes the loop counter `i` into each of the four `for` loops in `cmd_fast_import()` to use the most appropriate type (`int`, `unsigned int`, or `size_t`) for each loop’s bounds. The change is purely mechanical: it removes the shared `unsigned int i` declaration and replaces it with loop-scoped declarations (`for (int i = ...)`, `for (unsigned int i = ...)`, `for (size_t i = ...)`). The patch touches only `builtin/fast-import.c`, reducing its line count by two while preserving behavior. No new symbols are introduced, and there are no on-disk or CLI behavior changes. The work is preparatory, improving code clarity and type safety ahead of later patches that will further refactor the command-line parsing logic.
