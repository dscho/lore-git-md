This thread began when Skybuck Flying reported two related but distinct usability issues causing silent corruption in Git workflows on Windows. The first, a textconv filter misconfiguration, was traced to unquoted backslashes in filter commands (e.g., `sed -e s/\r//`) being misparsed by the shell, stripping all 'r' characters instead of carriage returns. Jeff King (Peff) confirmed this as a shell misconfiguration rather than a Git bug, reproducible on Linux, and suggested documentation improvements. Theodore Ts'o (Ted) dismissed it as a "Windows problem" due to MSYS/Unix backslash handling, framing it as outside Git's scope.

The second issue, binary file corruption, is more pressing. Skybuck Flying demonstrated that overly broad global `.gitattributes` rules (e.g., `* text diff=lfclean`) force text filters onto binary files like PNGs and JPEGs, corrupting them during checkout. Initially, this was treated as a usability gap, but the author has since escalated it to a design critique, arguing that global `.gitattributes` rules with `text` or textconv filters are inherently unsafe. In their latest email, they abandon technical discussion entirely, issuing a strongly worded advisory to delete global `.gitattributes` files and unset related config entries. Their proposed workaround—using local `.gitattributes` with explicit extensions (e.g., `*.txt text`)—is practical but sidesteps the broader question of whether Git should mitigate this risk proactively.

No maintainer has yet weighed in on the binary corruption issue, leaving key questions unanswered: Should Git warn users when global rules force text filters onto binary files? Should it ignore `text` for known binary extensions by default? Is this a documentation gap or a code-level fix? The thread has shifted from a bug report to a design discussion, but the lack of maintainer engagement means the project's stance remains unclear. For now, users are left with Skybuck Flying's workaround—avoiding global `.gitattributes` rules—as the only reliable safeguard against silent corruption.
