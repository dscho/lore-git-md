This is the final patch in Christian Couder’s 12-patch series refactoring `git fast-import` to standardize its usage string and prepare for libification. The patch removes the now-redundant `from_stream` argument from `parse_one_feature()` and its callers after patch 11/12 eliminated the only non-stream invocation.

The change is purely mechanical: every call to `parse_one_feature()` previously passed `1` as the `from_stream` argument, so the parameter is dropped and the value hard-coded. The `check_unsafe_feature()` helper is similarly simplified, and its `UNUSED` marker is removed since the `state` parameter is now actively used. The patch touches only `builtin/fast-import.c`, reducing its line count by 9 while preserving behavior. No new symbols are introduced, and the commit message clearly explains the motivation.

This is a clean, well-justified cleanup that follows logically from the parse-options integration in patch 11/12. The series as a whole is now complete, with all feedback addressed and the remaining edge case (the `--allow-unsafe-features` inconsistency) documented in both the man page and commit messages. The patch itself is uncontroversial and ready for integration.
