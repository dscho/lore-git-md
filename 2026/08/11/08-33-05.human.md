This is a documentation patch, the third in Christian Couder’s twelve-patch v3 series refactoring `git fast-import`’s usage string and preparing for libification. It updates `Documentation/technical/api-parse-options.adoc` to document the `OPT_*_F()` macro variants (which accept a trailing `flags` argument) and the convenience macros `OPT_HIDDEN_GROUP()` and `OPT_HIDDEN_BOOL()` introduced in earlier patches. The additions are placed adjacent to their non-hidden counterparts (`OPT_GROUP()` and `OPT_BOOL()`) for clarity, and the `_F` suffix convention is explained in a new introductory paragraph. The patch is purely additive, touching only the documentation file, and is a straightforward follow-up to the infrastructure work in patches 1 and 2. Elijah Newren’s feedback on the earlier patches has already been incorporated, and this patch itself has no open questions or behavioral impact. It’s a small but necessary step toward making the parse-options API more discoverable for future contributors.
