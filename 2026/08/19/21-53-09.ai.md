This is patch 7/9 of Justin Tobler’s v4 series making `git receive-pack` fully ODB-agnostic by introducing the `odb_transaction_write_pack()` interface. The patch explicitly passes the packfile file descriptor through the call chain instead of hard-coding stdin, preparing for the unpack logic to move behind the generic ODB transaction interface.

The change is mechanical: `unpack()` and its helper `parse_pack_header()` now take an explicit `int pack_fd` parameter, and the call sites in `builtin/receive-pack.c` are updated to pass `0` (stdin) where the old code implicitly relied on it. The sideband multiplexer (`unpack_with_sideband()`) continues to read from stdin, so it passes `0` unchanged. No behavior change is introduced; the patch is purely preparatory for the ODB abstraction layer.

The patch touches only `builtin/receive-pack.c` and is straightforward, with no new symbols or interface changes beyond the signature updates to `unpack()` and `parse_pack_header()`. It directly addresses the feedback from earlier iterations that the unpack logic should not assume stdin, aligning with the series’ goal of backend-agnostic packfile ingestion. The change is consistent with the broader ODB transaction design, where file descriptors are passed explicitly to enable alternative backends to supply their own data sources.
