The patch updates the function signatures in `reftable-stack.h` and `stack.c`, removes redundant `REFTABLE_OUTDATED_ERROR` checks, and adjusts the unit tests to match the new flow. The only exceptions are unit tests that explicitly tested the old flag behavior, which are now updated to reflect the new status quo.

The patch touches core reftable files (`refs/reftable-backend.c`, `reftable/stack.h`, `reftable/stack.c`) and the corresponding unit tests, but introduces no new symbols or on-disk format changes. It’s a clean refactoring that paves the way for the next two patches, which will use this simplified logic to skip unnecessary reloads when the stack is already locked.
