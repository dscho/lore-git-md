This is the first patch in Justin Tobler’s v4 series making `git receive-pack` fully ODB-agnostic. It fixes a regression introduced in bdee7b3013 (July 2026) where the ".keep" lockfile used to prevent packfile races was written to the wrong directory, causing it to linger after the ODB transaction committed.

The patch updates `index_pack_lockfile()` to accept an explicit `struct odb_source *` instead of a `struct repository *`, ensuring the ".keep" file is written to the main object directory at commit time rather than the temporary quarantine directory. The call sites in `builtin/receive-pack.c` and `fetch-pack.c` are updated to pass the correct ODB source, and a new test in `t/t5547-push-quarantine.sh` verifies the ".keep" file is generated in the quarantine directory during the transaction and removed after commit.

This is a targeted bugfix that preserves the race-avoidance properties of ".keep" files while adapting to the ODB transaction infrastructure. The change is mechanical and well-motivated, with clear test coverage. It addresses the last open design flaw from v3 and is a prerequisite for the rest of the series. The patch looks ready for `next`.
