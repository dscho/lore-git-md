This is the third patch in Justin Tobler’s nine-patch v4 series making `git receive-pack` fully ODB-agnostic. The series is part of Patrick Steinhardt’s ongoing ODB abstraction effort and addresses all feedback from the previous iteration, including the critical ".keep" file placement design and transaction lifecycle management.

This patch removes the global `alt_shallow_file` variable by lifting the setup of the temporary shallow file out of the `unpack()` function and passing it explicitly through the call chain. The change is a prerequisite for moving the unpack logic behind the new `odb_transaction_write_pack()` interface in a later patch, since the transaction system cannot rely on global state. The patch updates `unpack()`, `unpack_with_sideband()`, `prepare_shallow_update()`, and `update_shallow_info()` to accept a `const char *shallow_file` parameter, and wires the temporary shallow file through `cmd_receive_pack()` where it is now created and passed down.

The refactoring is mechanical and does not change user-visible behavior. It touches only `builtin/receive-pack.c` and is well-motivated by the broader goal of eliminating global state to enable pluggable ODB backends. The commit message clearly explains the rationale and the patch itself is straightforward, with no obvious regressions or loose ends. This is a solid step toward the series’ goal and looks ready for merging.
