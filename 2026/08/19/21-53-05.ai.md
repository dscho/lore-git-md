This is patch 3/9 of Justin Tobler’s v4 series making `git receive-pack` fully ODB-agnostic. The patch removes the global `alt_shallow_file` variable by lifting the temporary shallow-file setup out of the `unpack()` helper and passing the shallow file path explicitly through the call chain. The change is a prerequisite for moving the unpack logic behind the new `odb_transaction_write_pack()` interface in a later patch, since the transaction system cannot rely on global state.

The patch touches only `builtin/receive-pack.c`, converting the static `alt_shallow_file` into a local variable in `cmd_receive_pack()` and threading it through `unpack()`, `unpack_with_sideband()`, `prepare_shallow_update()`, and `update_shallow_info()`. The diff is mechanical: sixteen lines removed, twenty-two added, with no behavior change. The temporary shallow file is still created by `setup_temporary_shallow()` and passed to the same subprocess arguments (`--shallow-file`), but now the path is scoped to the unpack call rather than stored globally.

This is a refactoring patch that prepares the codebase for the ODB abstraction; it does not introduce new functionality or alter user-visible behavior. The change is well-motivated by the series’ goal of eliminating global state, and the implementation is straightforward. The patch is uncontroversial and aligns with the feedback already addressed in earlier iterations.
