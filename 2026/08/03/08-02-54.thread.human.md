The issue, which surfaced between Git 2.40 and 2.43, was already fixed in the current development version (2.55.0), and Geiger confirmed the fix after testing.

Kristoffer Haugsbakk followed up to pinpoint the exact commit that resolved the issue: **94304b9f** ("sequencer: comment checked-out branch properly", 2024-11-25), which landed in Git 2.48.0. This commit ensured worktree advisory comments respect `core.commentChar`. Haugsbakk also refined the regression window, noting the bug was introduced after Git 2.39.5 and fixed before 2.48.0. The thread is now closed, with no further action needed—this follow-up simply adds retrospective clarity for the record.
