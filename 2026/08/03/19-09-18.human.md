This is Junio’s "What’s cooking in git.git" report for early August 2026, summarizing the state of 50+ in-flight topics.

The most notable news is the graduation of 10 topics to `master`, including Patrick Steinhardt’s **remote-object-info** series (`ps/cat-file-remote-object-info`), which lets `git cat-file --batch-command` request object metadata (currently size) from a remote server without downloading the object itself. This is a foundational piece for future object-negotiation optimizations. Also merged is the **ODB loose-object writing refactor** (`ps/odb-move-loose-object-writing`), which moves loose-object logic into the loose backend, making the ODB abstraction more self-contained.

In `next` (cooking), several user-facing improvements stand out. **`git add --resolved`** (`jc/add-resolved`) is a new option to stage conflict-resolved paths while leaving unrelated local changes unstaged; it scans for leftover conflict markers and aborts if any are found. **`git branch --delete-merged`** (`hn/branch-delete-merged`) adds a bulk-delete option for branches already merged into their upstream, with opt-out per-branch via `branch.<name>.deleteMerged`. The **`git replay --linearize`** topic (`tc/replay-linearize`) teaches the experimental command to drop merge commits, mimicking `git rebase --no-rebase-merges`.

On the plumbing side, **`git cat-file --batch-command`** now supports `%(objecttype)` (`ps/cat-file-remote-object-info-type`), and the **ODB housekeeping** series (`ps/odb-pluggable-housekeeping`) has refactored `git gc` and `git maintenance` to make optimizations pluggable, paving the way for alternative backends.

Stalled topics include Taylor Blau’s **geometric cruft repack** (`tb/repack-geometric-cruft`), which combines `--geometric` with `--cruft` but has unresolved test failures, and Han-Wen Nienhuys’s **checkout --track=fetch** (`hn/checkout-track-fetch`), which Junio has marked for discard.

The report also lists several small fixes that have already graduated: a segfault in `git clone --revision` with protocol v0 (`af/clone-revision-v0-segfault-fix`), a memory leak in `git merge` (`tc/merge-default-to-upstream-leakfix`), and a sparse-index crash with intent-to-add entries (`ds/sparse-index-ita-crash`).

Overall, this is a busy but incremental period, with no single blockbuster feature but steady progress on ODB abstraction, remote object negotiation, and user-facing convenience commands.
