This is a minor test cleanup in the first patch of Pablo Sabater’s eight-patch GSoC series extending `git cat-file --batch-command` to support the `%(objecttype)` placeholder. The patch replaces `wc -c | xargs` with the `test_file_size()` helper and caches the output of `git rev-parse` in variables, making the test more robust and portable. Junio’s review highlighted an additional benefit: the new version preserves the exit status of commands run inside `$(...)` within a here-document, whereas the old version would have masked failures (e.g., if `git rev-parse` segfaulted). Pablo has accepted the suggestion and will include the rationale in the next reroll. The change is purely mechanical, uncontroversial, and ready to proceed as-is. This patch does not affect the series’ core functionality or merge status.
