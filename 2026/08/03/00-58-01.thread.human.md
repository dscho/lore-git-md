This thread is about a three-patch series from Junio C Hamano that fixes inconsistent bash completion behavior for `git diff`. The goal is to make completion suggestions consistent with `git status` and `git add` by defaulting to tracked paths, with untracked paths as a fallback, and to handle edge cases like `git -C <path>` and empty revision input correctly. The series also resolves a prior `--no-index` regression by making untracked path completion explicit rather than relying on implicit fallback.

The patches touch `contrib/completion/git-completion.bash` (refactoring `_git_diff()` and adding helper functions) and add 120 new test cases in `t/t9902-completion.sh`.
