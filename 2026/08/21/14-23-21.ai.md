This is the first patch in a three-part series replacing the deprecated `utime()` function with `utimensat()` for POSIX.1-2024 compatibility. It introduces the core compatibility layer: a `git_utimensat()` wrapper in `compat/utimensat.c` for platforms lacking `utimensat()`, a MinGW-specific implementation in `compat/mingw.c`, and fallback definitions for `AT_FDCWD`, `UTIME_NOW`, and `UTIME_OMIT` in `compat/posix.h`. The patch also adds `ST_ATIME_NSEC(st)` to complement existing nanosecond-resolution macros and wires up build system support (Makefile, meson.build, CMakeLists.txt, and configure.ac) for the `NO_UTIMENSAT` feature flag.

The wrapper handles the full `utimensat()` interface, including the `UTIME_NOW` and `UTIME_OMIT` flags, by falling back to `utimes()` when necessary. On MinGW, the implementation converts `struct timespec` to Windows `FILETIME` with 100ns precision and rejects unsupported flags (`AT_FDCWD` and non-zero `flag`). The existing `mingw_utime()` is reimplemented as a thin shim over `mingw_utimensat()`.

This is a well-structured, platform-aware refactoring that lays the groundwork for the rest of the series. The wrapper design is thorough, handling edge cases like `UTIME_OMIT` (which requires fetching the current timestamp from the filesystem) and build system integration is complete. Reviewers are likely to focus on the correctness of the timestamp conversion logic and the handling of `UTIME_OMIT` in the fallback path. Key symbols introduced: `git_utimensat()`, `mingw_utimensat()`, `ST_ATIME_NSEC(st)`, and the `NO_UTIMENSAT` feature flag.
