This thread is a user inquiry from Anselm Schüler asking why Git’s `--ext-diff` option exists and why external diff drivers aren’t enabled by default in all commands that show diffs. Jeff King (Peff) has now weighed in, explaining that the inconsistency—external diffs are allowed by default in `git diff` but not in `git show`—is likely an oversight rather than a deliberate design choice. The key concern is that external diff drivers can execute arbitrary code, including opening GUI windows or performing other disruptive side effects, which would be problematic in commands like `git log` that iterate over many commits. Peff suggests that `textconv` (a more constrained mechanism for converting binary files to text) is often a better fit for most use cases, though he acknowledges this reflects his own bias as the author of `textconv`. The thread remains open, with no decisions or code changes proposed—it’s still focused on clarifying Git’s current behavior and the trade-offs involved.
