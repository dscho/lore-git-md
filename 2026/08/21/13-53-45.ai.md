This is the second patch in a two-patch feature series adding Unicode box-drawing characters to the `git repo structure` command when a UTF-8 locale is detected. The patch implements the actual Unicode rendering logic in `builtin/repo.c`, replacing ASCII bullets (`*`) and table borders (`|`, `-`) with Unicode box-drawing characters (`│`, `├`, `─`, `┼`, `┤`) and bullets (`•`) when `is_utf8_locale()` returns true. The changes are internal to `stats_table_setup_structure()` and `stats_table_print_structure()`, with no new symbols introduced.

The patch also updates the test suite in `t/t1901-repo-structure.sh` to verify Unicode output under a UTF-8 locale. It adopts the `GIT_TEST_UTF8_LOCALE` test helper (previously used in `t/lib-git-svn.sh`) to define a `UTF8_LOCALE` prerequisite, ensuring tests can run in a controlled environment. Existing tests are explicitly pinned to `LC_ALL=C` to guarantee ASCII fallback behavior regardless of the runner's default locale. Two new tests cover Unicode output: one under a normal UTF-8 locale and another under a UTF-8 locale with a missing locale directory, exercising the `is_utf8_locale()` fallback logic introduced in patch 1.

The implementation is straightforward and maintains backward compatibility by falling back to ASCII when a UTF-8 locale is not detected. The test coverage is thorough, including edge cases like missing locale directories. The patch is narrowly scoped to the `repo structure` command and does not affect other parts of Git. Key technical details for follow-up discussion include the `is_utf8_locale()` function, the `GIT_TEST_UTF8_LOCALE` test helper, and the specific Unicode characters introduced.
