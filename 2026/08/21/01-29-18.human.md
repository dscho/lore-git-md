This is Junio’s latest "What’s cooking" report for August 2026, summarizing the state of Git’s integration branches. It’s the project’s heartbeat, listing 472 commits in `master` since Git 2.55 and detailing what’s in `next` (128 commits) and `seen` (245 commits). Below are the highlights a busy developer should know.

The report is split into sections: **New Topics** (recently queued, not yet in `next`), **Graduated to 'master'** (topics that made it into the upcoming release), **Stalled** (topics needing attention), and **Cooking** (topics in `next` or `seen` that are still under review). Each entry includes the topic’s purpose, status, and any open discussion threads.

Key graduated topics include **hn/branch-delete-merged**, which adds `--delete-merged` to `git branch` to clean up local branches already merged into their upstream; **ps/odb-make-creation-pluggable**, a step toward pluggable object database backends; and **ps/writev**, which reintroduces `writev()` wrappers to reduce syscall overhead in packfile streaming. These are all now in `master` and will ship in the next release.

Among the new topics, **kn/receive-report-hook** introduces a new `report` hook for `git receive-pack` to filter or modify the status report sent back to clients, but it’s marked as "Expecting a reroll" due to feedback. **ps/odb-pluggable-pack-generation** makes packfile generation pluggable, allowing ODB backends to serve packfiles directly, but it also needs a reroll after review comments. **ps/odb-generic-corrupt-objects** refactors the ODB API to distinguish between missing and corrupt objects, a cleanup that looks solid but is still waiting for review.

Several topics in the **Cooking** section are close to graduation. **sk/object-name-use-after-free** fixes a use-after-free bug in object name parsing, and **kh/format-rev-doc-synopsis** improves the documentation formatting for the experimental `git format-rev` command. Both are in `next` and marked "Will merge to 'master'". **yn/worktree-add-no-dwim-with-b** fixes a DWIM logic bug in `git worktree add` when `-b` or `-B` is given, and **jc/complete-checkout** improves command-line completion for `git checkout` and `git diff` by completing tracked and untracked paths.

A few topics are stalled or contentious. **hs/rebase-continue-edit** adds `--no-edit` to `git rebase --continue` but has been waiting for a response for over a month. **tb/pack-with-duplicates** hardens packfile handling for duplicate objects but is still under discussion. **mm/diff-process-hunks**, which allows external processes to act as hunk providers, is stalled due to unresolved feedback.

The report also notes a few large-scale efforts in flight: **ps/odb-eagerly-load-alternates** simplifies ODB initialization by eagerly loading alternates, and **hn/history-squash** adds a `squash` subcommand to the experimental `git history` command. Both are still cooking and likely to evolve.

Overall, the report shows a healthy pipeline with a mix of small fixes, documentation improvements, and foundational refactoring. The topics marked "Needs review" or "Expecting a reroll" are the ones most likely to see activity in the coming weeks.
