This is a CI/build system patch that updates GitHub Actions workflow configuration to cancel stale workflow runs for pull requests. The patch itself was already summarized in the parent email; this reply is a gentle nudge from the author, Harald Nordgren, requesting review.

The change targets a real inefficiency: currently, every push to a pull request starts a new CI run without canceling the previous one, wasting runner capacity. The patch modifies `.github/workflows/main.yml` to group workflow runs by pull request number (instead of commit hash) for pull request events, enabling cancellation of stale runs. The implementation is self-contained, well-explained, and unlikely to be controversial.
