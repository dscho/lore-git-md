This is the second patch in a three-part series replacing the deprecated `utime()` function with `utimensat()` for POSIX.1-2024 compatibility. It performs the core mechanical migration across eight files in the codebase, updating timestamp-handling logic to use the new `utimensat()` wrapper introduced in the first patch.

The changes are straightforward: each call to `utime()` is replaced with `utimensat(AT_FDCWD, ...)`, and `struct utimbuf` is swapped for `struct timespec[2]` to support nanosecond precision. The patch preserves existing behavior while enabling sub-second timestamp resolution where supported. Notable adjustments include using `UTIME_OMIT` in `commit-graph.c` to avoid an extra `stat()` call, and propagating nanosecond fields in `copy.c` and `test-chmtime.c`.

The patch looks clean and well-scoped, with no obvious functional regressions. The commit message clearly explains the rationale for each change, and the diff is easy to follow.
