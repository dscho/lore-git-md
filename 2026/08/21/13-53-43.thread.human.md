This thread introduces a small but visually noticeable feature: Unicode box-drawing characters in the output of `git repo structure` when the user's locale is UTF-8. The series comes from a Google Summer of Code participant and consists of two patches.

The first patch fixes a subtle bug in Git's locale detection: when gettext isn't fully initialized (common in development builds), the code would incorrectly report a UTF-8 locale even under `LC_ALL=C`. The second patch implements the Unicode rendering itself, using standard box-drawing characters and bullets when UTF-8 is detected, while maintaining ASCII fallback for other locales.

The implementation is narrowly scoped to the `repo structure` command and includes thorough test coverage, including a new test helper (`GIT_TEST_UTF8_LOCALE`) borrowed from the git-svn test suite. The series touches the gettext subsystem and the repo built-in, with corresponding test updates. No maintainer decisions have been made yet about merging this feature.
