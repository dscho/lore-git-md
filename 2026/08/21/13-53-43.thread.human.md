This thread introduces a small but user-visible enhancement to `git repo structure`: when the user’s terminal is set to a UTF-8 locale, the command now draws its tree-like output with Unicode box-drawing characters (`│`, `├`, `─`, `┼`, `┤`) and bullets (`•`) instead of plain ASCII. The series is split into two patches. The first fixes a latent bug in `is_utf8_locale()` that could misreport the locale in uninstalled builds; the second implements the actual Unicode rendering. K Jayatheerth, a GSoC participant mentored by Justin Tobler and Lucas Seiki Oshiro, posted the series as v1. So far no reviews have appeared, so the patches are still under initial review. The implementation is self-contained, backward-compatible, and comes with test coverage that exercises both UTF-8 and ASCII fallback paths.
