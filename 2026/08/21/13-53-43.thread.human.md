This thread is about a Google Summer of Code patch series by K Jayatheerth that adds Unicode box-drawing characters (`│`, `├`, `─`, etc.) to `git repo structure` output when the user’s locale is UTF-8, while preserving ASCII fallback for other environments. The series also fixes a latent bug in locale detection that could misreport UTF-8 support in uninstalled builds.

The patches are under review, with the maintainer, Junio C Hamano, now requiring the feature to be opt-out via a configuration option (e.g., `repo.structure.unicode`) to address cross-terminal reliability concerns. The author has not yet responded to this requirement, which is the main blocker for the series. The implementation itself is narrowly scoped, touching only `gettext.c`, `builtin/repo.c`, and the test script, with no new public symbols or on-disk format changes. Tests cover both UTF-8 and ASCII fallback cases.

A recent review comment from Tuomas Ahola added a technical nuance: mutt, cited as a successful example of box-drawing characters, actually falls back to ACS when UTF-8 is unavailable. This complicates the earlier argument about terminal compatibility and may influence how the opt-out configuration is designed. The discussion remains focused on the opt-out requirement, with no signs of broader opposition to the feature itself.
