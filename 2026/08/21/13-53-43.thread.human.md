This thread is about a patch series by GSoC participant K Jayatheerth that adds Unicode box-drawing characters to `git repo structure` output when the user’s locale is UTF-8, while preserving ASCII fallback for other environments. The series also fixes a latent bug in locale detection that could misreport UTF-8 support in uninstalled builds.

The patches are under review, with Junio C Hamano expressing skepticism about the reliability of Unicode rendering across terminals—a concern that has stalled progress. The author has provided thorough test coverage, including a new test helper (`GIT_TEST_UTF8_LOCALE`) to verify UTF-8 output, but no technical counterarguments to Junio’s objection have been offered yet.

Oswald Buddenhagen has now weighed in, pushing back against Junio’s skepticism by pointing to widely used tools like *mutt* and *midnight commander*, which successfully use box-drawing characters without widespread complaints. He suggests that if terminal compatibility is a concern, the feature could be made opt-out via configuration rather than rejected outright. He also hints at broader potential, like extending Unicode rendering to `git log --graph`. This response shifts the discussion toward practical compromises and feature scope, potentially reviving the series if the maintainer finds the opt-out proposal acceptable.
