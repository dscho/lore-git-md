This thread is about a Google Summer of Code (GSoC) patch series from K Jayatheerth that adds Unicode box-drawing characters (`│`, `├`, `─`, etc.) to `git repo structure` output when the user’s locale is UTF-8, while preserving ASCII fallback for non-UTF-8 environments. The series also fixes a latent bug in locale detection that could misreport UTF-8 support in uninstalled builds.

The patches are under review, with Junio C Hamano initially objecting to the feature’s cross-terminal reliability, noting that Unicode box-drawing characters often render inconsistently. Oswald Buddenhagen countered by suggesting an opt-out configuration option (e.g., `repo.structure.unicode`) to address these concerns, and Junio has now clarified that his objection was not about the feature itself but about the lack of flexibility in the current implementation. He is open to the feature if it includes a configuration knob to override the locale-based default, giving users control over the rendering. The discussion has shifted from whether the feature should exist to how it should be implemented, with a clear path forward: the author may revise the series to add this opt-out option. No other technical objections remain unresolved.
