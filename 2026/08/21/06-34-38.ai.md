This is a bugfix patch targeting Git's auto-maintenance geometric repacking strategy, now ready for integration after reviewer approval. The patch adjusts the default threshold for loose object repacking from 100 to 6700 to match `git gc`'s long-standing default, addressing instability in high-concurrency repositories caused by overly frequent repacks.

The change is minimal and focused: it updates the default value of `maintenance.geometric-repack.auto` in `Documentation/config/maintenance.adoc` and `odb/source-files.c`. The author, Patrick Steinhardt, provides historical context for the 6700 threshold, tracing it back to a 2007 calibration in `git gc --auto` that balanced pragmatism and stability. The fix is purely a configuration default adjustment with no on-disk format changes, making it low-risk. The author explicitly notes that the core issue is the aggressive default (100), not the estimation heuristic used to count loose objects.
