This is a Google Summer of Code (GSoC) feature patch series adding Unicode support to the `git repo structure` command.

The series introduces Unicode box-drawing characters and bullet points for cleaner hierarchical output when a UTF-8 locale is detected, while maintaining ASCII fallback for non-UTF-8 environments. The work is split into two patches: the first fixes a bug in `is_utf8_locale()` where it incorrectly reported UTF-8 support in non-UTF-8 environments (like `LC_ALL=C`) due to an unset `charset` variable, and the second implements the Unicode rendering logic in the `repo structure` command itself.

The implementation touches `gettext.c` for the locale detection fix and `builtin/repo.c` for the output formatting changes. Tests in `t/t1901-repo-structure.sh` are updated to verify both ASCII fallback and Unicode rendering paths, following established Git test conventions for locale handling.

This appears to be a well-scoped feature addition with proper attention to backward compatibility. The commit messages are detailed and the test coverage looks thorough. The series addresses a real usability improvement for users with UTF-8 terminals while maintaining the existing behavior for others.
