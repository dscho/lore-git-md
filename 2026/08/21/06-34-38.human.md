This is a bugfix patch that adjusts the default threshold for geometric repacking in Git's auto-maintenance to reduce instability in high-concurrency repositories.

The patch changes the default value of `maintenance.geometric-repack.auto` from 100 to 6700, aligning it with `git gc`'s long-standing default. This reduces the frequency of repacks triggered by loose objects, addressing race conditions where loose object directories are pruned while another process is writing to them. The fix is minimal, touching only the documentation and the default configuration value in `odb/source-files.c`.

The author, Patrick Steinhardt, has provided historical context for the 6700 threshold, tracing it back to a 2007 calibration in `git gc --auto` that balanced pragmatism and stability. The rationale reaffirms this as the simplest and most conservative fix. Justin Tobler, the sole substantive reviewer, has confirmed the patch is "fine as is" and withdrawn his earlier suggestion to expand the commit message.
