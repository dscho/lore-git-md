This is the third patch in Harald Nordgren’s **v11 `git history squash` series**, a refactoring that extracts the squash-message template helpers from `sequencer.c` so they can be reused by the new `git history squash` subcommand. The patch moves three static functions (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) into `sequencer.h` and relocates the `todo_item_flags` enum so callers can distinguish `amend!` from plain `fixup!` markers. No behavior change; this is pure plumbing to enable the default message-editing feature introduced in patch 4/4.

The helpers are straightforward: they generate the same “This is a combination of N commits” banner, “This is the 1st/Nth commit message” headers, and commented-out subject lines that `git rebase -i --autosquash` already uses. By exposing them, the patch ensures `git history squash` produces an identical template, resolving the template-consistency feedback from earlier rounds. The `TODO_REPLACE_FIXUP_MSG` flag (now in the header) lets the caller know when an `amend!` message should replace the target’s message rather than being appended.

This patch is **ready to merge** and is a prerequisite for the final patch in the series. It touches only `sequencer.c` and `sequencer.h`, adding 30 lines to the header and moving 31 lines out of the implementation file.
