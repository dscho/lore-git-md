This is the second patch in Harald Nordgren’s four-part `git history squash` series (v11). It is a **refactoring patch** that adds an optional `message_template` parameter to the internal `commit_tree_ext()` helper in `builtin/history.c`. When the caller supplies a template, the function uses it instead of the commit message from the passed-in commit object; when NULL, the original behavior is preserved. This plumbing change enables the default message editing feature introduced later in the series.

The patch modifies three existing callers (`commit_tree_with_edited_message`, `cmd_history_fixup`, and `split_commit`) to pass NULL, preserving their current behavior. No user-visible changes are introduced. The implementation is straightforward: the function now checks for a non-NULL template and falls back to the original commit’s message body if none is provided. The change is **ready to merge** and has no unresolved technical concerns.
