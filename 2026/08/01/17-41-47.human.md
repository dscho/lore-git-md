This is the fourth patch in the v7 RFC series introducing Git’s new diff provider interface. It teaches the stat output (`--stat`, `--numstat`, `--shortstat`) to record precomputed hunks into the `diff-hunks` store when writing is enabled, turning a warming run into a side-effect that fills the cache.

The patch wires the stat machinery to the store’s writer: when a diff pair is modified and the run is warming (a writer is attached), the stat is produced by collecting the pair’s hunk coordinates instead of emitting text. The counts are summed from those hunks, and the pair is recorded only if it is “trim-stable”—its zero-context trimmed diff (what blame reads) and untrimmed diff (whose counts a nonzero-context stat matches) are identical. This ensures one entry serves both blame and stat formats. The warming run displays the same counts a store-less run would, since it uses the trimmed diff at zero context.

Recording is gated by the same opt-in mechanism as the rest of the series: writing is off by default and enabled per run via `GIT_DIFF_HUNKS_WRITE` or `diffHunks.write`. The patch adds the write half of the test suite (`t/t4220-diff-hunks.sh`), verifying that ordinary commands never create the store, that a warming run builds a store that verifies, that a second run refreshes it in place, and that the displayed counts stay correct on a trim-divergent pair (a real-world fixture from Git’s own test suite). It also tests that binary and mode-only pairs do not break the writer, and that a corrupt store is discarded at seed rather than carried forward.

The patch is well-motivated and technically sound: it preserves the stat output’s correctness, adds no overhead when writing is off, and delivers the 1.26–1.9x speedups the series promises when the store is warmed. The test coverage is thorough, including a real-world trim-divergent pair that exercises the stability check. No substantive review feedback has surfaced yet, but the patch is part of an RFC that explicitly asks for design feedback on the framework, not a merge of these ten patches as one.
