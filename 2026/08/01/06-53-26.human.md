This is the first patch in Harald Nordgren’s **v11 series** for the new `git history squash` subcommand. It is a **refactoring patch** that extracts a helper function, `first_parent_tree_oid()`, to centralize the logic for resolving a commit’s first-parent tree (or the empty tree for a root commit). The helper is used in three places in `builtin/history.c`, replacing duplicated code that parsed the parent commit and copied its tree OID.

The patch is **mechanical and behavior-preserving**—no functional changes are introduced. It touches only `builtin/history.c` (26 insertions, 32 deletions) and is part of the ongoing effort to improve code maintainability in the `history` subsystem. The extracted helper will be used by the subsequent patches in the series, particularly the core `squash` implementation.
