This is the **first patch in the v4 series** adding the `--reset-when-found` option to `git bisect`. It is a **refactoring patch** that prepares the plumbing for the feature by adding a `quiet` parameter to `bisect_reset()`.

The patch modifies `bisect_reset()` in `builtin/bisect.c` to accept an integer `quiet` flag. When set, the function passes `--quiet` to the underlying `git checkout` command, suppressing its progress and branch-status output. All existing callers pass `0` (false), so the behavior remains unchanged in this patch. The change is mechanical and straightforward, touching only the function signature and the checkout argument construction.

This patch is a prerequisite for the second patch, which will use the `quiet` parameter to suppress checkout noise during the auto-reset step. The commit message is clear and minimal, and the diff is clean. No test coverage is added here, as the patch does not change behavior. The patch is uncontroversial and ready for integration.
