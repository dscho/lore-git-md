This is the **second and final patch** in the v4 series adding the `--reset-when-found[=<where>]` option to `git bisect`. The patch implements the core feature: auto-reset logic, state persistence, and CLI wiring for both `git bisect start` and `git bisect run`.

The patch touches four files: `bisect.c` (plumbing), `builtin/bisect.c` (porcelain), `Documentation/git-bisect.adoc` (man page), and `t/t6030-bisect-porcelain.sh` (tests). The new option is parameterized: `--reset-when-found=original` (the default) resets to the pre-bisect commit, while `--reset-when-found=found` leaves the first bad commit checked out. The option is rejected if used with `--no-checkout`, since that mode prevents checking out either target. The reset is performed quietly, and for `git bisect run` it is deferred until after the captured output is printed and the `BISECT_RUN` file is closed, addressing platform-compatibility concerns about unlinking open files.

Internally, the patch introduces an enum `reset_when_found_mode` to track the reset target, persists the target in a `BISECT_RESET_WHEN_FOUND` state file, and updates the bisect state machine to trigger the reset after the first bad commit is found. The plumbing change from patch 1/2 (adding a `quiet` parameter to `bisect_reset()`) is used here to suppress checkout output. Test coverage is thorough, with four new tests validating both reset targets, state cleanup, and edge cases (invalid targets, `--no-checkout` conflicts, interrupted bisects).

The patch is uncontroversial and ready for integration into `next`. All substantive and surface-level feedback from Johannes Sixt’s review has been addressed, including error message boilerplate (now using Git’s standard dual-option template), shell safety in tests (fixed by assigning `git rev-parse` output to variables), and translation simplification. The only unaddressed item—joining `test_when_finished` commands with `&&`—is mechanical and does not affect the feature’s logic or readiness. The series is marked for `next` by Junio C Hamano.
