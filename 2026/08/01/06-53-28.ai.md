This is a refactoring patch (part 3/4 of v11) that prepares the sequencer’s squash-message helpers for reuse by `git history squash`. The patch extracts three static functions from `sequencer.c`—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—and moves them to `sequencer.h` so other commands can produce the same template format as `git rebase -i --autosquash`. It also relocates the `todo_item_flags` enum to the header, allowing callers to distinguish `amend!` commits (which replace the target’s message) from plain `fixup!` commits.

The changes are purely internal: no user-visible behavior changes. The patch enables the next patch in the series (4/4) to give `git history squash` the same autosquash-style editor template that `git rebase -i` uses, ensuring consistency across Git’s history-editing commands. Key names introduced: `add_squash_combination_header`, `add_squash_message_header`, `squash_subject_comment_len`, and `TODO_REPLACE_FIXUP_MSG`. The patch is small (70 insertions, 31 deletions) and mechanically sound, touching only `sequencer.c` and `sequencer.h`.
