This is the eleventh iteration of Harald Nordgren’s `git history squash` series, a new subcommand that folds a commit range into its oldest commit while preserving descendant history. The series is now functionally complete and makes **message editing the default behavior**, addressing the usability debate from v10 by adopting `--no-edit` as the opt-out flag instead of `--reedit-message` as the opt-in.

Key changes in v11:
- **Default message editing**: The command now opens an editor with the autosquash-style template by default, matching `git rebase -i --autosquash`. The `--no-edit` flag skips the editor, keeping the oldest commit’s message (or the last `amend!` targeting it). This resolves the usability debate from v10, where Phillip Wood argued for encouraging commit hygiene.
- **Stricter range validation**: The command now rejects ranges that reach a root commit or have more than one tip, ensuring the selected history has exactly one boundary and one tip. This tightens input validation while preserving the ability to handle interior merges.
- **Ref-handling refinement**: Only local branches pointing inside the range are protected by default; tags and remote-tracking refs are left unchanged. This simplifies the `--update-refs=head` workflow for users who want to ignore non-branch refs.
- **Patch consolidation**: The sequencer preparation and message-editing logic are now folded into a single patch (4/4), streamlining the implementation.

The series remains a **feature addition** targeting the `history` subsystem, with **4 patches** touching `builtin/history.c`, `sequencer.c`/`sequencer.h`, `advice.c`, and `Documentation/`. The test suite (`t/t3455-history-squash.sh`) is comprehensive, covering edge cases like interior merges, ref handling, and `fixup!`/`squash!`/`amend!` grouping.

**Key names introduced**: `--[no-]edit`, `build_squash_message()`, `amend_replaces_target()`, and the `selected`/`has_children` oidsets for range validation. The command’s behavior is now **fully aligned with `git rebase -i --autosquash`**, including template consistency and marker grouping.
