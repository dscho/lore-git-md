This is a documentation patch, part of Michael Montalbo’s RFC series introducing a diff provider interface. It updates the `gitattributes` man page to clarify the limitations of external diff drivers: they only replace the textual patch output, while features like word diff, function context (`-W`), `--color-moved`, and syntax highlighting still rely on Git’s builtin diff. The patch also notes that summary formats (`--stat`, `--numstat`, `--shortstat`, `--dirstat`), `git blame`, and `git log -L` do not use external drivers at all.

The change is straightforward and well-motivated. The current documentation implies external drivers are a full replacement for Git’s diff machinery, but in practice they are a narrow escape hatch for custom patch generation. This update makes the scope explicit, helping users avoid confusion when features like `--color-moved` or `--stat` don’t behave as expected. The wording is clear and concise, and the patch is a single-file addition with no code changes.

This is the first patch in the v7 series, setting the stage for the later introduction of the diff provider interface, which aims to unify and extend how Git consults alternate diff sources. The clarification here is particularly relevant because the new interface will allow external providers to integrate more deeply with Git’s diff features, unlike the current external drivers.
