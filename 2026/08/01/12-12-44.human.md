The patch itself teaches the server to advertise the "type" capability, enabling the client to request object type metadata from the server.

This is a standard shell best practice and aligns with the surrounding test code, which consistently uses double quotes for variable expansions. The change is trivial and does not affect the patch’s core functionality—it’s purely about test robustness.

The rest of the patch remains uncontroversial and complete. It updates the test suite to expect the actual object type ("blob") for `%(objecttype)` instead of an empty string, adds a new test for truly unsupported placeholders, and introduces helper variables to make the test output more readable. All prior review feedback has been addressed, and this series is now feature-complete and ready for maintainer consideration.
