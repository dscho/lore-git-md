This is a documentation patch that clarifies the scope and limitations of Git's external diff drivers. It updates the "Defining an external diff driver" section in `Documentation/gitattributes.adoc` to explicitly state what an external diff driver *cannot* do: it only replaces the textual patch output, while features like word diff, function context (`-W`), `--color-moved`, and syntax coloring still rely on Git's builtin diff. The patch also notes that summary formats (`--stat`, `--numstat`, `--shortstat`, `--dirstat`), `git blame`, and `git log -L` do not invoke the external driver at all and continue using the builtin diff.

The change is a straightforward addition of eleven lines that address a long-standing ambiguity in the documentation. It does not alter any code or behavior, but it provides useful context for users configuring external diff drivers, particularly those who might expect the driver to integrate more deeply with Git's diff features. This clarification is timely given the ongoing RFC series introducing the `diff-provider` interface, which aims to unify and extend how external diff sources interact with Git. The patch is well-motivated and uncontroversial.
