This is the first patch in Harald Nordgren’s `git history squash` v11 series, a pure refactoring that extracts a helper function to centralize the logic for resolving a commit’s first-parent tree (or the empty tree for a root commit). The patch touches only `builtin/history.c`, replacing three nearly identical code blocks with calls to the new `first_parent_tree_oid()` helper. No behavior change is introduced; this is strictly a code hygiene improvement to reduce duplication and improve maintainability.

The helper is straightforward: given a `struct commit *`, it returns the tree OID of the first parent if one exists, or the repository’s empty tree OID otherwise. The three callers (`commit_tree_with_edited_message`, `commit_became_empty`, and `split_commit`) are updated to use the helper, eliminating redundant parse-and-copy logic. The patch is small (26 insertions, 32 deletions) and mechanically sound, with no functional impact on the `squash` subcommand or any other part of Git.

This patch is ready to merge and serves as a foundation for the subsequent patches in the series, which build on the extracted helper. It is uncontroversial and aligns with the project’s preference for small, focused refactorings. Expect it to be queued alongside the rest of the series in Junio’s next integration cycle.
