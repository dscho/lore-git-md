This is a call for contributions to the next **Git Rev News** edition (137). Git Rev News is the project's monthly newsletter, summarizing recent developments, discussions, and community activity on the Git mailing list.

The draft for edition 137 is available on GitHub, and Christian Couder invites everyone to contribute—whether by proofreading, suggesting articles or links, helping with GitHub issues, volunteering for interviews, or editing the draft directly via pull request. The planned publication date is **Monday, August 3, 2026**.

This isn’t a code patch or technical discussion, but it’s a good opportunity for anyone following Git development to help shape how the project’s progress is communicated to a broader audience. If you’ve been involved in recent mailing list activity or have insights to share, this is a low-effort way to contribute. The draft is open for feedback until publication.
