This is a refactoring patch (part 3/8 of the `git history squash` series) that extracts squash-message formatting helpers from `sequencer.c` into `sequencer.h` so they can be reused by `git history squash`. The patch moves three static functions—`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`—along with the `todo_item_flags` enum, into the header file. These helpers standardize how Git formats squash commit messages, including the "This is a combination of N commits" banner, per-commit headers ("This is the 1st commit message:"), and logic for commenting out `fixup!`/`squash!`/`amend!` subjects.

The change is purely mechanical and enables the final patch (8/8) to give `git history squash` the same autosquash-style template as `git rebase -i --autosquash`. The `todo_item_flags` enum (including `TODO_REPLACE_FIXUP_MSG`) allows callers to distinguish between `amend!` and plain `fixup!` commits when processing the template. No behavior changes; the patch is a prerequisite for template consistency across commands.

This patch is uncontroversial and ready for integration. It touches only `sequencer.c` and `sequencer.h`, and the extracted helpers are already used internally by `update_squash_messages` and `append_squash_message`. The motivation is to avoid duplicating squash-message logic when `git history squash` implements its own message editing in patch 8/8.
