This is the second patch in D. Ben Knoble’s three-patch series converting the build-time `USE_NSEC` macro to a runtime `core.useNanosec` configuration. It is a no-op refactoring of `repo_config_values_init` in `environment.c` that reorders the assignments to match the struct declaration, grouping them by config section ("core", "sparse", "branch") and adding comments to make future additions easier to validate. The patch touches only one file and changes no behavior, but it prepares the ground for the upcoming `core.useNanosec` field. The reordering is mechanical and uncontroversial; the main value is making the initialization routine more maintainable.
