This is the first patch in D. Ben Knoble’s three-patch series converting the build-time `USE_NSEC` macro to a runtime configuration option (`core.useNanosec`). While it is part of that series, this patch itself is a **build-system fix** for Meson, unrelated to the nanosecond-precision work.

The patch addresses a long-standing inconsistency between Makefile and Meson builds: Makefile-based builds have allowed `MAN_BASE_URL` to be configured since 2009, but Meson hard-codes the equivalent of `$prefix/$mandir`, which is both incorrect for most distro builds (HTML docs are not stored there) and missing a trailing slash, breaking relative links in man pages. The patch changes the Meson default to `file://$(htmldir)/` (matching Make’s behavior) and adds a configurable `man_base_url` option so distributions like Gentoo can override it if needed.

The change is small (8 lines) and self-contained, touching only `Documentation/meson.build` and `meson_options.txt`. The commit message is thorough, explaining the rationale, the default choice, and the downstream impact. The author notes that they found no evidence of distros currently using `MAN_BASE_URL` in Meson builds, but the knob is provided for future-proofing. This patch is a clear improvement and unlikely to be controversial.
