This is a test modernization patch, the first in Pablo Sabater’s ten-patch GSoC series that adds `%(objecttype)` support to `git cat-file --batch-command`’s remote-object-info queries. The patch replaces the fragile `wc -c | xargs` idiom with Git’s built-in `test_file_size()` helper and caches the output of `git rev-parse two:two.t` in variables. The change is purely mechanical—no behavior is altered—and is explicitly endorsed by Junio as ready to merge. It touches only the test script `t/t5701-git-serve.sh`, making the test more robust and portable while preserving the exit status of commands run inside the here-document. The commit message now clearly explains the rationale, addressing Junio’s earlier observation about exit-status preservation. This patch is uncontroversial and sets the stage for the rest of the series.
