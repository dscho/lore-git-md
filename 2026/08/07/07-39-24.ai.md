This is the first patch in the v13 series for the `git history squash` feature. It is a **refactoring patch** that extracts a helper function, `first_parent_tree_oid()`, to centralize the logic for resolving a commit’s first-parent tree (or the empty tree for a root commit). The helper is used in three places in `builtin/history.c`, replacing repetitive code that manually parsed the parent commit and copied its tree OID.

The patch is **mechanical and uncontroversial**, with no behavior change. It prepares the codebase for the subsequent patches in the series by reducing duplication and making the logic more maintainable. The extracted helper will be reused in later patches (e.g., for range validation and commit creation), but this patch itself is purely preparatory. The commit message is clear and concise, and the diff is straightforward. This patch is **ready for integration** as part of the larger series.
