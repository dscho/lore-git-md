This is the fifth patch in a ready-to-merge series optimizing Git’s `paint_down_to_common()` function for asymmetric commit histories. The patch adds Trace2 instrumentation to count and report the number of commits visited during the paint walk, providing a measurable way to validate the series’ claimed 100-1000x speedups in one-sided queries.

The change is minimal and focused: it adds a `steps` counter to `paint_down_to_common()`, increments it for each commit processed, and emits the total via `trace2_data_intmax()` at the end of the walk. The test suite is updated to verify these counts deterministically across all commit-graph modes (none, full, half, no-gdat) using a new `test_paint_down_steps()` helper, which ensures the step counts match expected values for each test case. The test harness also now captures Trace2 events per mode, replacing the previous `grep`-based approach with the more robust `test_trace2_data_singular()` helper introduced earlier in the series.
