This is the first patch in the v13 series for the new `git history squash` command. It’s a pure refactoring that extracts a small helper function, `first_parent_tree_oid()`, to centralize the logic for resolving a commit’s first-parent tree (or the empty tree for a root commit). The helper is then used in three places in `builtin/history.c` where the same parse-and-copy dance was previously repeated.

The patch is uncontroversial and ready for integration. It makes no behavior changes, only tidying up code to reduce duplication. This kind of mechanical cleanup is exactly what reviewers like René Scharfe routinely approve without fuss, and it sets the stage for the more substantive patches that follow. If the rest of the series is as well-structured as this first step, it looks like a solid foundation.
