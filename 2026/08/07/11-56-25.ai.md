This is the second patch in D. Ben Knoble’s three-patch series converting `USE_NSEC` to runtime configuration. It is a no-op refactoring of `repo_config_values_init` in `environment.c` that reorders the assignments to match the order in the `struct repo_config_values` declaration. The commit message explains that the current order is chaotic and makes it difficult to verify that all members are initialized; the new order groups assignments by the config section they belong to (`core`, `sparse`, `branch`) and adds section comments. The patch touches only `environment.c` and changes no behavior, but it will conflict textually and semantically with `ty/repo-config-cleanups` in `seen`, which removes the comments this patch adds. The refactor is a preparatory step for the upcoming `core.useNanosec` addition in patch 3.
