This is the final patch in the `git history squash` series, completing the feature by implementing **default message editing** with an autosquash-style template. The patch enables users to edit the squashed commit message interactively, matching the behavior of `git rebase -i --autosquash` while preserving the series' existing validation and ref-handling logic.

The implementation reuses Git's sequencer infrastructure to rearrange the todo list and format the editor template. Key details:
- **Default behavior**: Opens an editor pre-filled with the messages of all folded commits, grouped by autosquash targets (e.g., `fixup!` commits are commented out, `squash!` bodies are retained, and `amend!` replaces its target unless overridden by a preceding `squash!`).
- **Template consistency**: Uses the same helpers (`add_squash_combination_header`, `TODO_REPLACE_FIXUP_MSG`) as `git rebase -i` to ensure identical formatting.
- **Edge cases**: Handles empty commit messages (aborts the operation) and respects the `--no-edit` flag (skips the editor entirely, using the logic from earlier patches).
- **Test coverage**: Adds 200+ lines to `t/t3455-history-squash.sh`, verifying template generation, autosquash grouping, and message editing workflows.

The patch is **technically sound** and aligns with the series' design goals. It directly addresses the usability debate from earlier versions by making message editing the default while maintaining strict validation for `--no-edit`. The integration with the sequencer ensures consistency with existing Git workflows, and the test suite covers both happy paths and edge cases (e.g., empty messages, nested autosquash markers).

**Files touched**:
- `builtin/history.c`: Adds `build_squash_message()` and updates `resolve_squash_range()` to generate the todo list for editing. The `cmd_history_squash()` function now passes `COMMIT_TREE_EDIT_MESSAGE` to `commit_tree_ext()` when `--edit` is active.
- `Documentation/git-history.adoc`: Expands the `squash` subcommand documentation to explain the editor template, autosquash grouping rules, and `--edit`/`--no-edit` behavior.
- `t/t3455-history-squash.sh`: Tests editor workflows, including empty message aborts, autosquash grouping, and `amend!`/`squash!` interactions.

**Key helpers introduced**:
- `build_squash_message()`: Constructs the editor template by parsing the todo list with `todo_list_rearrange_squash()` and formatting messages using sequencer helpers.
- `amend_replaces_target()`: Determines whether an `amend!` commit should replace its target's message or be treated as a `squash!` (if a preceding `squash!` exists).
