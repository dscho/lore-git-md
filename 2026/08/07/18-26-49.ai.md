This is a refactoring patch in the Bloom filter subsystem, part of Toon Claes’s v2 series to speed up the experimental `git last-modified` command. Patch 3/6 introduces `bloom_filter_contains_any_vec()`, a new helper that answers the question “did this commit possibly change the queried path or any of its parent directories?” by returning true if *any* key in the supplied vector is present in the Bloom filter. The existing `bloom_filter_contains_vec()` answers the narrower question “did this commit possibly change the exact path?” by returning true only if *all* keys are present. No callers are added yet; the next patch in the series will wire this up inside `git last-modified`. The implementation is a simple loop over the key vector, calling the existing per-key lookup. The patch is mechanical, well-scoped, and directly supports the series’ goal of reusing Bloom filters for wildcard pathspec queries.
