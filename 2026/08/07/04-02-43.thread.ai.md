Thread identity: Feature request for unified interactive patch selection in Git (`git add -p`/`git checkout -p` workflow enhancement). Originating author: Junio C Hamano. Thread type: design discussion (RFC).

Core problem or goal: Address the lack of a built-in workflow for handling "good but not yet ready" hunks (category 2) during interactive patch selection, while also exploring broader use cases such as squashing hunks into arbitrary commits or moving them to new branches. The goal is to unify interactive patch selection workflows into a flexible session that supports staging, discarding, deferring, and potentially more advanced operations (e.g., amending older commits or creating new branches), without overcomplicating the existing UI.
