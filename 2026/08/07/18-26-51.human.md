This is the fifth patch in Toon Claes’s six-patch v2 series that speeds up the experimental `git last-modified` command by reusing Git’s Bloom filters. The patch teaches `git last-modified` to consult the Bloom filter **before** it starts diffing trees, exactly the way `git log` already does. If the filter says “no changes here,” the commit is skipped entirely, saving the cost of a full tree diff. With `--show-trees` the check is extended to parent directories, so a change to `a/other` is still noticed when the pathspec is `a/b/c`. A new test verifies that the Bloom-filter fast path works correctly with `--show-trees`. The change is small (12 lines in the command, 21 in the test), well-motivated, and directly addresses the 3.7× speedup reported in the cover letter. No new issues are introduced; the patch simply wires up the helpers added in earlier patches.
