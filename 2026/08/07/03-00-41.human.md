This is a test infrastructure patch, part of Tian Yuchen’s larger series optimizing `paint_down_to_common()` for one-sided histories. The patch introduces `test_trace2_data_singular()`, a diagnostic helper that improves Trace2 data assertions in Git’s test suite.

The new helper replaces the existing `test_trace2_data` (a bare `grep` that fails silently) with a function that verifies a Trace2 event appears exactly once and reports detailed mismatches—missing keys, duplicate entries, or value mismatches. Output goes to FD 4, matching the style of `test_grep`. This is a **surface-level improvement** that doesn’t change Git’s behavior but makes test failures easier to debug. The patch is well-motivated and aligns with the test suite’s existing conventions.
