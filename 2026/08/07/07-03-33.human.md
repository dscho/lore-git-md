This is the second patch in Justin Tobler’s six-patch series making `git receive-pack` backend-agnostic by switching to the ODB transaction system. The patch removes the global `alt_shallow_file` variable and instead passes the shallow file path explicitly through the call chain in `builtin/receive-pack.c`. This is a preparatory refactoring step that eliminates reliance on global state ahead of the later switch to the generic `odb_transaction_write_pack()` interface.

Patrick Steinhardt’s review is brief but positive. He notes the reduction in global state as a clear improvement and agrees with the mechanical refactoring: the shallow file is now created earlier in the call stack and passed down explicitly, which aligns well with the series’ goal of removing globals. The review is surface-level, focusing on the immediate change rather than deeper design questions, but it signals no objections to the patch’s direction.

The patch itself is uncontroversial and well-scoped. It touches only `builtin/receive-pack.c` and introduces no behavior changes, relying on existing test coverage. Reviewers are likely to focus on whether the explicit parameter passing scales well as the interface evolves, but the patch itself looks clean and ready for integration. It is part of the ongoing ODB abstraction effort led by Patrick Steinhardt, and this specific change is a straightforward step toward that goal.
