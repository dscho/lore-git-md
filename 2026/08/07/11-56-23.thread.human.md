This thread is about D. Ben Knoble’s patch series that replaces Git’s build-time `USE_NSEC` macro with a runtime configuration option (`core.useNanosec`), allowing users to enable nanosecond precision on supported filesystems without recompiling. The series, now in its sixth version, graduated to Junio’s `next` branch on July 10, 2024, meaning it is under final integration testing before being merged into `master`. All prior feedback has been addressed, including a performance regression in the first version and a cross-platform correctness issue in the second.

The discussion has settled on the technical design, with Junio, Patrick Steinhardt, and Jeff King (Peff) all confirming the series is sound. The only remaining loose ends are routine: a textual conflict with another topic in `seen` and a forward-looking constraint about how the new config lookup might complicate future submodule support. Peff recently raised a subtle edge case involving mixed builds (one with `NO_NSEC` and one without) on a system that supports nanosecond timestamps, but both he and Knoble agree this is an unlikely scenario that does not warrant code changes. The series is effectively complete, with only a final holding period in `next` before it graduates to `master`.
