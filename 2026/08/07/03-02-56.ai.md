This is a **performance instrumentation patch** in the ready-to-merge `paint_down_to_common()` optimization series. It adds Trace2 instrumentation to count and report the number of commits visited during the paint walk, enabling observable measurement of the series' 100-1000x speedups in asymmetric queries.

The patch is small and mechanical: it introduces a `steps` counter in `paint_down_to_common()`, increments it for each commit processed, and emits the total via `trace2_data_intmax()` at the end of the walk. The test suite is updated to verify these counts deterministically across all commit-graph modes (none, full, half, no-gdat) using the new `test_paint_down_steps()` helper, which ensures the step counts match expected values for each test case. The test harness now captures Trace2 events per mode, replacing the previous `grep`-based approach with the more robust `test_trace2_data_singular()` helper introduced earlier in the series.
