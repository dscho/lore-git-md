This is the fifth patch in Patrick Steinhardt’s six-patch series making Git’s on-disk object database (ODB) structures pluggable. The patch introduces `odb_source_type_to_name()`, a helper function that maps ODB source types (e.g., `ODB_SOURCE_LOOSE`, `ODB_SOURCE_PACKED`) to human-readable strings like `"loose"` or `"packed"`. The function is immediately used to improve BUG message clarity in the downcasting macros (`odb_source_files_downcast()`, `odb_source_loose_downcast()`, etc.): instead of printing raw enum values (`BUG("trying to downcast source of type '3' to loose")`), the messages now show the symbolic names (`BUG("trying to downcast source of type 'packed' to 'loose'")`).

The change is mechanical and touches only the ODB source headers (`odb/source-*.h`) and the central `odb/source.c` file. It adds no new behavior but makes debugging easier by replacing opaque numeric values with meaningful labels. The implementation is defensive: unknown enum values map to `"unknown"`, and the function BUGs if the lookup table is missing an entry. This patch is uncontroversial and part of the final, approved reroll (v5) that addresses all prior review feedback.
