This is the v13 iteration of the `git history squash` feature, which folds a range of commits into a single commit while preserving merge topology and descendant history. The series is now split into eight patches, with the core implementation broken into logical components: parsing, range validation, branch protection, commit creation, and message editing.

The key technical changes in v13 center on **structural decomposition** and **usability refinements**. The squash implementation is now divided into five focused patches (4–8/8), isolating distinct concerns like range validation, ref protection, and message handling. This addresses Phillip Wood’s earlier request for incremental review by making the 1,500-line final patch more digestible. The branch protection logic now prints **sorted branch names** that would be left dangling, paired with clearer advice for `--update-refs=head`. Message editing (via `--edit`) is deferred to the final patch, ensuring `--no-edit` behavior is fully functional in earlier steps.

**Behavioral details**:
- **Range validation**: Rejects root commits, multi-tip ranges, and external parents in a single walk using object flags (`SQUASH_SEEN`, `SQUASH_TIP`). Fully adopts Phillip Wood’s v10 fixes for boundary detection and merge-parent preservation.
- **Ref handling**: Protects all local branches descended from the squashed range by default, with `--update-refs=head` restricting updates to the current branch. Remote-tracking refs and tags are left untouched.
- **Autosquash messages**: Resolves `fixup!`, `squash!`, and `amend!` targets during the range walk, enforcing stricter rules for `squash!`/`amend!` (rejecting them unless their target is the first commit or `--edit` is used). Nested fixups are supported, and `amend!` messages are preserved when squashing into a `fixup!` commit.
- **Message editing**: The default behavior opens an editor with an autosquash-style template matching `git rebase -i --autosquash`, grouping markers under their targets. The `--no-edit` flag uses the oldest commit’s message (or the last `amend!` targeting it) without opening an editor.
