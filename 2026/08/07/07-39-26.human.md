This is a refactoring patch that prepares the sequencer’s squash-message helpers for reuse by the upcoming `git history squash` command. Part of Harald Nordgren’s v13 series for the `git history squash` feature, this is the third patch in an eight-patch series that is now functionally complete and ready for integration.

The patch extracts three static functions (`add_squash_combination_header`, `add_squash_message_header`, and `squash_subject_comment_len`) and the `todo_item_flags` enum from `sequencer.c` into `sequencer.h`. These helpers standardize how Git formats squash commit messages, including the "This is a combination of N commits" banner, per-commit headers ("This is the 1st commit message:" or "The commit message #2 will be skipped:"), and logic for commenting out `fixup!`, `squash!`, or `amend!` subjects. The `todo_item_flags` enum (including `TODO_REPLACE_FIXUP_MSG`) allows callers to distinguish between `amend!` and plain `fixup!` commits when processing the template.

No behavior changes are introduced; the patch is purely preparatory. The extracted helpers will be used in patch 8/8 to give `git history squash` the same autosquash-style template as `git rebase -i --autosquash`, ensuring consistency across Git’s history-editing commands. The patch touches only `sequencer.c` and `sequencer.h`, with 70 lines of refactoring in the former and 30 lines of new declarations in the latter.

This patch is uncontroversial and ready for integration. It addresses Phillip Wood’s earlier feedback about code maintainability by making the squash-message logic reusable, and it lays the groundwork for the default message editing feature in the final patch. The series as a whole remains on track for merging, pending any final adjustments to align with Phillip Wood’s incremental review roadmap.
