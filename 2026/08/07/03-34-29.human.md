This is the fifth patch in Patrick Steinhardt’s six-patch series making Git’s on-disk object database (ODB) structures pluggable. The series is part of the ongoing ODB abstraction effort and is now in its final form after addressing all review feedback.

This patch introduces a small but useful helper function, `odb_source_type_to_name()`, that maps an ODB source type (e.g., `ODB_SOURCE_LOOSE`, `ODB_SOURCE_PACKED`) to a human-readable string. The function is then used to improve the error messages in the downcasting macros (`odb_source_files_downcast()`, `odb_source_loose_downcast()`, etc.). Instead of showing raw enum values like `BUG("trying to downcast source of type '2' to loose")`, the BUG messages now read `BUG("trying to downcast source of type 'packed' to 'loose'")`, making debugging much clearer.

The change is purely mechanical and touches only the ODB source headers (`odb/source-*.h`) and the central `odb/source.c` file. No behavior is altered; this is a refactoring that improves error-message quality. The patch is uncontroversial and has been approved by both Justin Tobler and Toon Claes. It is ready to graduate alongside the rest of the series.
