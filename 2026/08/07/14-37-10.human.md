This is the second patch in Johannes Sixt’s five-patch series to overhaul gitk’s color-preference dialog. The series aims to improve usability by making color swatches clickable, standardizing button widths, and rewriting labels for clarity and translatability. This specific patch refactors repetitive Tcl/Tk code that sets up color-selection buttons in the Preferences dialog.

The patch consolidates nearly identical code blocks for each color element (background, foreground, diff lines, etc.) into a single `foreach` loop that iterates over a list of color definitions. This reduces redundancy and makes the code more maintainable, serving as a prerequisite for later UI changes. It also makes two minor naming cleanups: dropping the redundant "sep" suffix from "markbgsep" and "selbgsep," and changing the suffix "but" to "btn" for consistency. These changes are internal and do not affect the user interface or behavior.
