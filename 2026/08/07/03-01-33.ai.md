This is the fourth patch in the v7 series optimizing `paint_down_to_common()` for one-sided commit histories. It adds targeted regression tests for the side-exhaustion optimization, focusing on correctness in two critical edge cases: redundant merge-base candidates and mixed finite/INFINITY generation numbers.

The patch introduces `t6099-merge-base-side-exhaustion.sh`, a new test script that verifies `git merge-base --all` correctly excludes ancestor candidates when the side-exhaustion optimization exits early (before STALE propagation removes them). The test constructs a diamond-shaped topology where both `B` and `C` are merge bases of `A` and `X`, but only `B` should appear in the output. The test runs with and without commit-graph to ensure the optimization behaves correctly in both scenarios. Elijah Newren suggests a minor improvement to the ASCII graph in the test header for clarity, but this is purely cosmetic and does not affect functionality.
