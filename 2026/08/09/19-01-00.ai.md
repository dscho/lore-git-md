This is the first patch in Justin Tobler’s v2 series extending the ODB transaction system to make `git receive-pack` backend-agnostic. It introduces `odb_transaction_finalize()`, splitting transaction cleanup from commit so that backends can perform deferred operations—most importantly, the "files" backend’s removal of ".keep" lockfiles after references are updated. The patch is purely mechanical: it decouples the freeing of the transaction from `odb_transaction_commit()`, adds the new `finalize` callback to `struct odb_transaction`, and updates all call sites to invoke `finalize` after commit. No behavior changes are introduced; the series remains plumbing-only at this stage. The patch is well-motivated by the need for backend-specific post-commit cleanup and addresses Patrick Steinhardt’s feedback from v1 about transaction lifecycle design. The diff is clean and touches only transaction-related code paths, making it a low-risk refactoring step toward the series’ goal.
