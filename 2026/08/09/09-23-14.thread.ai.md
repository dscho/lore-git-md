Originating author: Harald Nordgren

Core problem or goal
Fix a cryptic error message in `git send-email` when a patch file lacks a subject line. The current message "No subject line in <file>?" is terse and does not explain what the user should do; Perl also appends its internal source location to the output. The patch makes the error message actionable ("The first line of the file must start with 'Subject: '") and suppresses the Perl location by adding a trailing newline.

Current status
Under review; no prior versions. The patch is self-contained, includes a new test in `t/t9001-send-email.sh`, and touches only `git-send-email.perl`.
