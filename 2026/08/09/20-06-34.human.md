This is the tenth patch in Kristoffer Haugsbakk’s already-merged 11-patch documentation series (`kh/doc-trailers`) that overhauled the `git-interpret-trailers` man page. The series was motivated by a bug report about silent failures when parsing trailer keys containing periods; the maintainers confirmed the strict key format (ASCII alphanumeric + hyphen only) was intentional, but the documentation was unclear.

This specific patch rewrites two adjacent “By default” paragraphs that both described how new trailers are appended. The new version divides the explanation into four clear steps: (1) declare the topic (trailers added with `--trailer`), (2) explain the default behavior, (3) describe how the trailer block is affected, and (4) detail what each trailer line looks like. The result is a more logical flow and distinct roles for each paragraph. The change is purely textual—no behavior is altered—and the patch is already in `master`; this v5 iteration only fixes a minor grammatical nit in the final patch’s commit message.
