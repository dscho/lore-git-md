This is the sixth patch in Kristoffer Haugsbakk’s already-merged 11-patch documentation series `kh/doc-trailers`, now in its trivial v5 iteration. The patch explicitly documents the strict format for trailer keys—ASCII alphanumeric characters plus hyphens only—replacing the previous implicit reliance on examples. The change is a single line in `Documentation/git-interpret-trailers.adoc` that inserts the key-format rule immediately after defining a trailer’s simplest form. No code or behavior is altered; the patch merely codifies the long-standing (2016-era) parsing rule that silently rejects keys containing periods, underscores, or other non-conforming characters. The commit message cites Brendan Jackman’s original bug report and notes that earlier versions of the series had to “code-spelunk” `isalnum(3)` to discover the rule.
