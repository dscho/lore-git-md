This is a small but clear usability bugfix for `git send-email`. Junio’s reply to Harald Nordgren’s patch is a light, substantive review that accepts the core goal—making the error message more helpful—but gently pushes back on one detail: the new wording should not imply that the *first* line must start with “Subject:”, because a valid patch file (like one produced by `git format-patch`) always begins with a UNIX “From ” line, so the Subject header will never be on the first line. The rest of the patch—adding a newline to suppress Perl’s internal source location—is uncontroversial and already looks good. The change is still confined to a single line in `git-send-email.perl` and the accompanying test in `t/t9001-send-email.sh`; no other subsystems or workflows are affected. Expect a v2 that tweaks the wording while keeping the newline fix.
