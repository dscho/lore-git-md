This thread is about a small but user-facing improvement to `git send-email`. When a patch file lacks a "Subject:" header, the current error message is cryptic and exposes Perl internals. Harald Nordgren sent a patch to make the message clearer and more actionable.

Junio C Hamano reviewed the first version and pointed out that the proposed wording could mislead users into thinking the "Subject:" header must be on the first line of the file—which isn’t true, since patch files typically start with a "From " line. Harald agreed to adjust the wording, and Junio has now confirmed the revised direction: the error message should simply state that no "Subject:" header was found anywhere in the file. The fix is otherwise uncontroversial, and a second version of the patch is expected shortly. The change touches only the error message in `git-send-email.perl` and adds a test to verify the new behavior.
