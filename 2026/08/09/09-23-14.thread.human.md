This thread is about a small but user-facing improvement to `git send-email`: replacing a cryptic error message when a patch file lacks a "Subject:" header. The current message is terse, unhelpful, and exposes Perl internals; the patch aims to make it clearer and actionable.

Harald Nordgren posted the initial patch, which Junio C Hamano reviewed. Junio praised the fix for suppressing Perl noise but pointed out that the proposed wording incorrectly implied the "Subject:" header must be on the first line—valid patch files typically start with a "From " line. Harald has now acknowledged this feedback and agreed to reword the message to focus on the absence of the header rather than its position. The core goal remains uncontroversial, and a v2 is expected soon. No other objections or concerns have been raised.
