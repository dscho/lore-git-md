This thread is a small but clear usability fix for `git send-email`. Harald Nordgren posted a patch to improve the error message when a patch file lacks a "Subject:" header. The original message was cryptic ("No subject line in <file>?") and exposed Perl's internal source location. Junio C Hamano reviewed the first version, noted that the proposed wording incorrectly implied the "Subject:" header must be on the first line, and suggested a simpler, more accurate message: "No 'Subject:' line in '%s'\n".

Harald has now posted v2, adopting Junio's wording and keeping the newline to suppress Perl noise. The patch is minimal—one line changed in `git-send-email.perl` and a new test in `t/t9001-send-email.sh`—and uncontroversial. Both participants agree the fix is ready, and the thread is effectively complete pending Junio's merge.
