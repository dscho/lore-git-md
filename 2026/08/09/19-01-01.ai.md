This is the second patch in Justin Tobler’s v2 seven-patch series extending the ODB transaction system to make `git receive-pack` backend-agnostic for packfile writes. It is a preparatory refactoring step that lifts the temporary shallow-file setup out of the `unpack()` function and passes the shallow file path explicitly through the call chain.

The patch modifies `builtin/receive-pack.c` to stop relying on the global `alt_shallow_file` variable. Instead, the shallow file path is now created in `cmd_receive_pack()` and passed down to `unpack_with_sideband()`, `unpack()`, and `update_shallow_info()`. The change is mechanical and does not alter observable behavior; it is necessary to enable the later introduction of `odb_transaction_write_pack()`, which cannot depend on global state. The diff is clean and focused, touching only the shallow-file plumbing in `receive-pack.c`. No new symbols or files are introduced in this patch.
