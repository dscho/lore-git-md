This thread is a focused refactoring of Git’s `checkout` internals, led by Junio C Hamano, to eliminate the monolithic `checkout_main()` function and extract reusable logic into standalone helpers. The goal is to place all callers—`git checkout`, `git switch`, and `git restore`—on equal footing by moving shared code into top-level files (`checkout.c`, `checkout.h`), aligning with the project’s architectural direction to reduce global state and improve modularity.

The series is now in its second iteration as an early draft, with Junio’s eight-patch version addressing the "cheating" pattern where `git switch` and `git restore` were bolted onto `git checkout` via a shared helper. The first seven patches are self-contained, passing the test suite, and could theoretically be merged independently if not for two unresolved issues: Karthik Nayak’s proposal to eliminate the `cb_option` parameter (from the first patch) and a correctness flaw in the third patch, where an option-compatibility check for `--ours`, `--theirs`, `--force`, and `--merge` was misplaced relative to `--patch` mode. Junio’s latest reply seeks clarification on the latter, confirming the fix is straightforward (moving the check below the `--patch` block) but leaving the design question open. The eighth patch, which relocates `post_checkout_hook()` to a reusable top-level file, is now fully fixed to support multi-repository callers, addressing an earlier architectural shortcoming.

Karthik’s feedback is the only substantive review so far, with his surface-level approval of the second patch and a minor note on the sixth. D. Ben Knoble has endorsed the architectural direction, but broader input from other key contributors (e.g., René Scharfe, Patrick Steinhardt) is still pending. The series is explicitly not intended for merging to `seen` due to potential conflicts with in-flight topics, and its readiness hinges on resolving the `cb_option` design question and the third-patch correctness issue. For now, the refactoring remains a work in progress, with the first seven patches mechanically sound but awaiting consensus on the unresolved details.
