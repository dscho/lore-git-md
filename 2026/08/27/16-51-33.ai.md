This is the first patch in Wesley Schwengle’s two-patch series “git-svn: quiet migration noise and make build optional.” It directly addresses the noise-and-empty-directory issue described in the cover letter: when `git svn info` is run in a plain Git repository, `migrate_from_v1()` now defers printing the “Migrating from a git-svn v1 layout…” message and creating `.git/svn` until it actually finds a legacy `refs/remotes/*` candidate to migrate. The logic mirrors the existing `migrate_from_v0()` pattern. The change touches only `perl/Git/SVN/Migration.pm` and adds a single test in `t/t9107-git-svn-migrate.sh` that verifies the message is suppressed and the directory is not created when no SVN metadata exists. No new symbols or on-disk format changes are introduced.
