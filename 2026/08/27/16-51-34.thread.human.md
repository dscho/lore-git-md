This thread is about a simple but useful build-system improvement: a new `NO_GIT_SVN` Makefile knob that lets users skip building and installing `git-svn` entirely. Wesley Schwengle posted the patch as the second in a two-patch series. The change is minimal—just a few lines in the Makefile to conditionally include the `git-svn.perl` script and automatically set `NO_SVN_TESTS`—and follows the established pattern for optional components like `NO_CURL` or `NO_OPENSSL`.

The motivation is straightforward: environments that don’t need Subversion (e.g., pure Git workflows) can save build time and avoid Perl dependencies. There’s no runtime impact when the knob isn’t set, and the patch doesn’t touch anything outside the Makefile. So far, the patch looks uncontroversial and ready for review.
