This is a **bugfix and build-system enhancement** for `git-svn`, now in its second iteration (v2). The series targets two long-standing annoyances: suppressing spurious migration messages and empty `.git/svn` directory creation in plain Git repositories, and allowing users to opt out of building `git-svn` entirely.

The v2 cover letter is minimal—just a note that the author fixed the typo Junio pointed out in v1 ("git-svnexists" → "git-svn exists"). The patch set itself is unchanged in scope: patch 1/2 still defers the migration message and directory creation until a legacy `refs/remotes/*` candidate is found, and patch 2/2 still introduces the `NO_GIT_SVN=YesPlease` Makefile knob to disable building, installing, and testing `git-svn`. The files touched remain the same (`perl/Git/SVN/Migration.pm`, `Makefile`, and `t/t9107-git-svn-migrate.sh`), with the same test coverage verifying the new behavior.

No substantive objections surfaced in v1, and the typo fix addresses the only surface-level feedback. The series looks well-motivated and uncontroversial, though it hasn’t yet received deeper technical review. If the build-system change proves acceptable, this is likely to land soon.
