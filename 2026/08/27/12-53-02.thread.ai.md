Thread identity: l10n (French) documentation correction for `git-checkout` man page; originating author Eric Gautier; thread type: bug report (translation issue).

Core problem or goal: Correct a grammatical error in the French translation of the `git-checkout` man page where the "ne explétif" (stylistic negation) is incorrectly used, creating potential confusion for French-speaking users. The error could mislead readers into interpreting the condition as "if there are *no* uncommitted changes" rather than the intended "if there *are* uncommitted changes."

Current status: Reported and now escalated to the French translation maintainers (Jean-Noël Avila and Jiang Xin). The issue is actionable, with confirmation from Ben Knoble that the "n’" in "s’il n’y a" should be removed. No patch or review activity has occurred yet, but the maintainers have been directly notified.

Key technical details: The problematic sentence appears in the French version of the `git-checkout` man page. The correction involves removing the "n'" from "s’il n’y a" to read "s’il y a." No code, CLI options, or on-disk format changes are involved; this is purely a documentation/translation fix.

Open questions and loose ends: None at this stage. The report is self-contained, and the escalation to the maintainers resolves any prior uncertainty about the correctness of the proposed fix. The next step is for the French translation maintainer to review and apply the correction.

Participant positions:
