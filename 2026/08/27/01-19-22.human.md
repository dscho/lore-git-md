This is a surface-level review from Elijah Newren on Junio C Hamano’s patch introducing `die_for_incompatible_opts()`. The feedback is a single nit: the new varargs helper in `parse-options.c` calls `va_start()` but never calls `va_end()`, which is technically required by the C standard to avoid resource leaks or undefined behavior. The patch otherwise implements the intended refactoring cleanly, replacing the fixed-arity `die_for_incompatible_optN()` family with a single varargs function that preserves existing error messages and behavior. No substantive concerns are raised; the issue is purely about code hygiene in the new helper. The series remains a straightforward, well-scoped refactoring of the option-parsing internals.
