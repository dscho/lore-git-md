This is a bugfix and build-system patch targeting `git-svn`. The series addresses two issues:

1. **Unwanted noise and empty directory creation** -- When `git svn info` is run in a plain Git repository (no SVN metadata), it spuriously prints "Migrating from a git-svn v1 layout..." and creates an empty `.git/svn` directory. The patch silences this message and skips the migration step when there is nothing to migrate, mirroring the existing `migrate_from_v0` logic. The change is in `perl/Git/SVN/Migration.pm` and adds a test in `t/t9107-git-svn-migrate.sh`.

2. **Optional git-svn build** -- A new `NO_GIT_SVN=YesPlease` Makefile knob lets users skip building and installing `git-svn` entirely, which also disables SVN-related tests. This is useful for environments where SVN support is unnecessary and Perl dependencies are undesirable.

The series is small (two patches), well-motivated, and includes test coverage. The build-system change is straightforward and follows established patterns. No controversy is evident from the commit message.
