This is the fifth patch in Patrick Steinhardt’s eight-part series refactoring how Git handles ODB alternates during repository creation, part of the broader ODB abstraction effort. The patch consolidates alternates setup for non-shared local clones into `collect_alternates()`, completing the work begun in earlier patches. It also fixes a latent bug: when cloning from a worktree, Git previously failed to resolve the referenced repository’s common directory, causing alternates to be set up incorrectly. The patch adds two tests to verify the fix and ensure relative alternates paths are handled properly.
