This is the fifth patch in Junio C Hamano’s eight-patch series refactoring the `git checkout`, `git switch`, and `git restore` internals. It extracts branch setup and tracking logic from the monolithic `checkout_main()` function into three new static helpers: `validate_branch_options()`, `dwim_branch_track_option()`, and `setup_branch_name_and_info()`. The patch is purely internal, touching only `builtin/checkout.c` (54 lines added, 50 removed), and does not change CLI behavior or on-disk formats.

The refactoring is part of the libification effort clarified in earlier threads, where reusable logic is factored out of built-in commands into standalone helpers. This patch focuses on branch-creation options (`-b`, `-B`, `--orphan`) and the `--track` DWIM logic, which were previously scattered in `checkout_main()`. The new helpers improve code organization by isolating these concerns, making the code easier to maintain and paving the way for further extraction in later patches.

The patch is uncontroversial and well-motivated. The extracted helpers are small, focused, and replace logic that was already present in `checkout_main()`.
