This is the third patch in Junio C Hamano’s eight-patch series refactoring the `git checkout`, `git switch`, and `git restore` internals. It moves the validation of mutually exclusive stage/merge options (`--ours`, `--theirs`, `--force`, `--merge`) from the monolithic `checkout_main()` helper into `checkout_paths()`, where it logically belongs.

The change is a small, targeted cleanup: five lines moved, five lines deleted, all in `builtin/checkout.c`. The validation now runs only when pathspecs are present, which is the only case where index stages are relevant. This tightens the code’s structure and aligns with the series’ goal of eliminating the `checkout_main()` choke point by pushing logic down to the appropriate backend functions. The patch is uncontroversial, passes the test suite, and could be merged independently if the rest of the series requires more time.
