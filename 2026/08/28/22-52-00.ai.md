This is the second patch in Junio C Hamano’s 8-patch series refactoring the `git checkout`/`switch`/`restore` internals to eliminate the monolithic `checkout_main()` helper. It moves branch-name validation from `checkout_main()` into `checkout_branch()`, where it logically belongs.

The patch is a targeted cleanup: it relocates the `validate_branchname()` and `validate_new_branchname()` calls from the central dispatch function into the branch-specific backend. This is safe because `checkout_paths()` already checks for and rejects the `.new_branch` option before proceeding, so the validation is never needed there. The change is purely internal—no CLI behavior, on-disk formats, or test expectations change—and the patch passes the test suite.

This is a straightforward refactoring step that tightens the code’s structure by ensuring each backend validates only what it actually uses. It is uncontroversial and could be merged independently if the rest of the series needs more time. The patch is small (22 lines changed in a single file) and mechanical, making it a low-risk part of the larger architectural shift.
