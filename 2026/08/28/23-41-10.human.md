This is Junio’s biweekly “What’s cooking in git.git” report for August 2026, summarizing the state of 50+ in-flight topics. Below are the highlights a busy developer might care about, grouped by how close they are to shipping.

What just graduated to master (and will appear in the next release)
• kh/format-rev-doc-synopsis: the experimental `git format-rev` man page now uses the `[synopsis]` block markup so placeholders are properly highlighted.
• sk/object-name-use-after-free: fixes a heap-use-after-free when reporting a relative path to a sparse directory.

New topics that look ready to merge soon
• jc/die-for-incompatible-opts: generalizes the die_for_incompatible_opt[234]() helpers to handle any number of mutually exclusive options via a variadic function.
• jc/you-still-use-that: rewords the deprecation warning emitted by you_still_use_that() to make it clearer that the command is slated for removal and to point users more assertively to replacements.
• kn/reftable-optimize-reloading: avoids an unnecessary stat/reload of the reftable stack when an addition already holds the list_file lock, cutting the number of newfstatat syscalls from linear to constant.
• jc/rerere-doc-typofix: a one-line typo fix in the rerere technical documentation.
• ps/odb-pluggable-pack-generation: makes packfile generation pluggable through the ODB interface, so backends can serve packfiles directly instead of shelling out to `pack-objects`.
• ps/odb-eagerly-load-alternates: simplifies the ODB layer by loading alternate object directories at startup rather than lazily, removing scattered lazy-loading calls.
• fr/pack-objects-trace-pack-bytes: adds the total bytes written to pack files to trace2 output, useful for benchmarking compression settings.
• kh/trailers-no-urls: stops the trailer parser from misinterpreting lines that begin with a URL (e.g., `https://...`) as trailers.
• ty/repository-fetch-if-missing: moves the global `fetch_if_missing` variable into `struct repository`, continuing the libification effort.
• vm/complete-history: teaches the command-line completion script (in contrib/) the new experimental `git history` subcommands and options.
• yn/worktree-add-no-dwim-with-b: prevents `git worktree add -b <branch>` from trying to DWIM a remote-tracking branch when the user explicitly gave a branch name.

Topics that are cooking but still need review or a response
• dw/config-read-both-global: makes `--global` read both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config` when both exist, fixing an inconsistency.
• vv/branch-recurse-no-start-ref: fixes a crash in `git branch --recurse-submodules` when the start point is not a reference (e.g., a raw object ID).
• ps/odb-alternates-at-creation: defers the setup of alternates to object-database creation time during clone, dropping an unused ad-hoc alternate-writing API.
• ps/odb-pluggable-fsck: moves fsck checks into the backend-specific object source layers, making them pluggable.
• rs/worktree-add-basename-fixes: fixes out-of-bounds reads and improper handling of trailing slashes in `git worktree add`.
• en/no-amend-during-conflicts: teaches `am`, `revert`, and `rebase` to refuse `commit --amend` or partial `commit <paths>` during conflict resolution, just like `cherry-pick` and `merge` already do.
• as/utimensat-utimes: switches the codebase from the obsolescent `utime()` to `utimensat()` for high-precision timestamps while keeping fallback compatibility.
• ps/fetch-packfile-uris-parallel: allows `git fetch` to download packfile URIs in parallel when `fetch.packfileURIThreads` is set.
• kn/receive-report-hook: adds a new `report` hook to `git receive-pack` that runs after reference updates and can filter or modify the packet-line status report sent back to the client.
• en/midx-missing-pack-fallback: teaches the object lookup machinery to recover when a multi-pack-index points to a pack that was removed during a concurrent geometric repack.
• kh/format-rev-more-options: extends the experimental `git format-rev` with `--abbrev`, `--color`, and `--date` options.
• kj/repo-info-more-path-keys: adds more keys to `git repo info` to output paths of repository components (working tree root, superproject, object database, etc.) in both absolute and relative formats.
• yn/worktree-ambiguous-remote-advice: improves the advice when `git worktree add --guess-remote` finds multiple matching remote branches and now treats it as an error rather than silently picking one.

Stalled topics (no activity for weeks or months)
• ec/commit-fixup-options: adds `-m`, `-F`, `-c`, and `-C` support to all `git commit --fixup` variations.
• ps/libgit-in-subdir: moves `libgit.a` sources into a new `lib/` directory; currently ejected due to too many evil merges.
• hs/rebase-continue-edit: adds `--[no-]edit` to `git rebase --continue`.
• sn/rebase-update-refs-symrefs: teaches `git rebase --update-refs` to resolve local branch symrefs before queuing updates.
• tb/pack-with-duplicates: hardens the handling of packfiles with duplicate object entries.
• tc/replay-linearize: adds `--linearize` to `git replay` to drop merge commits.
• cl/regexec-macos-leak: works around a macOS TRE memory leak on invalid UTF-8.
• cc/lazy-fetch-trusted-bit: adds `uploadpack.lazyFetchTrusted` to allow lazy-fetching from promisor remotes when serving trusted repositories.

The report also notes that the 20th batch of topics has graduated to `master`, bringing the total to 567 non-merge commits since Git 2.55.
