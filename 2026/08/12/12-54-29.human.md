This is a surface-level review of a bug report about spurious pseudo-commits appearing in a custom `git lg` alias. The reviewer, Kristoffer Haugsbakk, identifies the root cause: the alias uses `--all`, which includes all refs—including Git notes like `refs/notes/rewrite-analytics` and `refs/notes/chatter`. These notes form their own disconnected graph, which explains why they appear unconnected to the project commits in the log output.

The reviewer concludes this is not a bug, as the behavior is expected given the `--all` flag. The pseudo-commits are legitimate Git notes, likely created by some background tooling (e.g., `rewrite-analytics` or `chatter`), even though the user’s enabled hooks list is empty. The discrepancy between CLI and GUI tools (Sublime Merge, IntelliJ IDEA) may stem from how those tools filter or display refs by default.

For the user’s goal of suppressing these notes while retaining the alias’s functionality, the reviewer does not provide a direct solution, but the implication is that the alias should be modified to exclude notes refs (e.g., by explicitly listing branches or using `--exclude=refs/notes/*`). The issue is cosmetic and environment-specific, but the explanation clarifies why it occurs and frames it as a configuration matter rather than a defect in Git.
