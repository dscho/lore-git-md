This is a small refactoring patch from Elijah Newren that removes an unused variable assignment in `sequencer.c`.

The patch deletes a single line (`revs.pretty_given = 1;`) that was introduced in 2017 as part of a rebase--helper conversion. Elijah notes the assignment is pointless because `revs.pretty_given` is only ever read in `builtin/log.c`, and no code from that file is called from the sequencer. The commit message speculates the line was copied blindly from `git log` logic when the original implementation was based on `git rev-list`.

The change is mechanical and confined to one file; no behavior is altered. The patch looks correct and well-motivated, though the impact is minimal. It’s a cleanup that removes dead code rather than fixing a bug or adding functionality.
