This is the first patch in Johannes Sixt’s six-part v2 series overhauling gitk’s color-preference dialog. It is a pure refactoring that consolidates the logic that sets the initial colors of the color-swatch labels into the existing `prefspage_set_colorswatches` helper procedure. Previously, the initial colors were set inline when the labels were created; now the same helper that updates the swatches after a color selection is also used to set the initial colors. The change is confined to the `prefspage_colors` procedure in `gitk-git/gitk` and has no user-visible effect—it simply removes a small amount of duplicate code. The patch is a straightforward, uncontroversial prerequisite for the subsequent UI improvements in the series.
