This is a v2 patch series from Junio C Hamano that refines Bash completion for `` `git checkout` ``, building on earlier work for `` `git diff` ``. The series now consists of three patches: the first refactors the completion logic (no functional change), the second restricts path completion to tracked files (those in the index), and the third—new in v2—adds untracked paths as a fallback when no tracked paths match.

The core goal remains the same: `` `git checkout` `` should only complete paths that exist in the index, since the command operates on repository files. The v2 update tightens the implementation by explicitly passing an empty string to `` `__git_complete_index_file` `` (rather than omitting the argument) to ensure untracked files are excluded. The new third patch introduces a pragmatic fallback: if no tracked paths match, untracked paths in the working tree are offered as candidates. This addresses edge cases where a file might exist untracked but is also present in another branch, though Junio notes this scenario is rare.

Test coverage in `t/t9902-completion.sh` has expanded to verify the new behavior, including cases for lost files (tracked but deleted) and explicit `--` usage. The series is now based on the v6 iteration of the `complete-diff` topic, ensuring the tests align with a more structured organization.
