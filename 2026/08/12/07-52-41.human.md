This is the first patch in Johannes Schindelin’s 12-part **platform compatibility** series, which upstream Git for Windows build and runtime adjustments into the main Git codebase. This specific patch enables Python support in the MinGW build by removing the `NO_PYTHON` flag in `config.mak.uname`.

The change is minimal: a single line in `config.mak.uname` that allows the build to include Python-dependent parts of Git. The motivation is practical: while Git for Windows does not ship Python (to save bandwidth), MSYS2 provides Python interpreters that users can easily install and use within Git for Windows’ SDK. This adjustment aligns the build system with that reality, making it possible for users to leverage Python-based Git features (e.g., hooks, scripts) without manual configuration.

The patch is narrowly scoped to Windows builds and has no effect on other platforms. It is a straightforward, well-motivated change that addresses a real-world use case. If you care about Windows build flexibility or Python integration, this patch is worth noting; otherwise, it can safely be ignored. The rest of the series builds on this foundation with further Windows-specific adjustments.
