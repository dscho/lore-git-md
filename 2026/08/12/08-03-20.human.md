This is the final patch in Johannes Schindelin’s v3 series fixing unchecked return values flagged by Coverity. It targets a resource leak in `git bisect run` where a failed `dup()` call left a file descriptor (`saved_stdout`) unclosed and a subsequent `dup2()` call could miswire stdout to a temporary file for the remainder of the bisect session.

The fix is minimal and surgical: the patch adds checks for both `dup(1)` and `dup2(temporary_stdout_fd, 1)` return values. If either fails, it closes any open descriptors (`saved_stdout` and `temporary_stdout_fd`), emits an `error_errno()` message, and breaks out of the loop so the existing cleanup path can handle the rest. This matches the defensive pattern used elsewhere in the bisect code and closes the resource leak Jeff King identified in v2.

The change is confined to `builtin/bisect.c` and introduces no new behavior—only a fatal error path that was previously missing. With this patch, the series is now technically complete and ready for integration.
