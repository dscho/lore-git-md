This is a brief maintainer comment in a resolved bug report thread about a custom `git lg` alias showing unexpected pseudo-commits. Junio C Hamano responds to Marcel Svitalský’s follow-up question by suggesting three flags—`--branches`, `--tags`, and `--remotes`—as alternatives to `--all`. These flags would exclude Git notes (e.g., `refs/notes/rewrite-analytics`) and other non-branch/tag/remote refs, addressing the user’s desire to see only "actual commits" in the log output.

The comment is minimal and does not revisit the earlier discussion about whether `--all`’s behavior is unintuitive for `git log`. It simply provides a practical workaround, reinforcing the thread’s earlier conclusion that the issue is cosmetic and environment-specific. No further action or debate is implied.
