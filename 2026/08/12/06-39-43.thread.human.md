This thread is about a small but critical bugfix for a NULL-dereference crash in Git’s protocol v2 handling of the `promisor-remote` capability. The bug was introduced in February 2025 and occurs when a client sends the capability without a value, causing the server to crash. Elijah Newren posted a minimal fix that adds a NULL check and a test case to verify the server now rejects malformed input instead of crashing.

The patch itself is straightforward and hasn’t changed since it was first sent. Elijah recently re-sent it to explicitly CC Christian Couder, who originally introduced the bug, as a procedural step to ensure awareness. There’s been no review feedback yet, and the patch remains under review. No open questions or objections have been raised so far.
