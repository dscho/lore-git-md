This is a bugfix patch targeting the Git protocol v2 `promisor-remote` capability.

The patch fixes a NULL-dereference bug in the `promisor_remote_receive()` callback in `serve.c`. The bug was introduced in commit d460267613da (February 2025), which added the `promisor-remote` capability to protocol v2. The code assumes the capability value is always present, but a client can send the capability name without an `=` or value, causing `get_capability()` to return NULL. The subsequent call to `strbuf_split_str()` then dereferences this NULL pointer.

Elijah adds a simple NULL check before parsing the capability value and returns an error if the argument is missing. The patch also includes a new test in `t/t5701-git-serve.sh` that verifies the server rejects a valueless `promisor-remote` capability with the expected error message.

The fix is minimal and targeted: it touches only the receive callback and adds a test case. The commit message clearly explains the bug, its origin, and the fix. This looks like a well-crafted, uncontroversial bugfix that addresses a real issue.
