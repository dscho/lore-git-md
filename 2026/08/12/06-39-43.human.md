This is a bugfix patch targeting the Git protocol v2 `promisor-remote` capability. Elijah Newren identifies a NULL-dereference vulnerability introduced in commit d460267613da (February 2025): if a client sends the `promisor-remote` capability without an `=` or value, the server code passes NULL to `strbuf_split_str()`, causing a crash.

The fix is straightforward: add a guard clause in `promisor_remote_receive()` that rejects the capability if no argument is provided. The patch also adds a test in `t/t5701-git-serve.sh` that verifies the server correctly dies with an error message when the capability is sent without a value.

The commit message is clear and concise, naming the problematic commit, describing the bug, and explaining the fix. The test coverage is minimal but sufficient for the edge case. This looks like a well-crafted, low-risk fix for a real issue.
