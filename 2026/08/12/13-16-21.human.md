This is the final patch in a six-part series overhauling gitk’s color-preference dialog. The series as a whole improves usability by making color swatches clickable, standardizing button widths, rewriting labels in natural language, and ensuring full translatability. This specific patch reorders the color options list so that generic colors (selection background, link text) appear above diff-specific colors, creating a more logical visual hierarchy. The change is purely presentational—no functionality is altered—and reflects feedback from the v1 review cycle about the dialog’s organization.

The patch moves two entries (`selbg` and `linkfg`) from the bottom of the `coloruielems` list to just after the generic background and text color options. The color for marked lines (`markbg`) remains below the diff colors since it is only used in the diff panel. The commit message explains the rationale clearly: selection and link colors apply to both the commit list and the diff panel, so they belong with the other generic options.

This is a small, self-contained change to `gitk-git/gitk` (Tcl/Tk) that completes the series. All substantive feedback has been addressed in earlier patches; this one resolves the last cosmetic discussion point about visual ordering. The series is now ready for final review and should be a straightforward merge.
