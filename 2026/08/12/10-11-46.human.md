This is a test refactoring patch that prepares the ground for fixing a flaky test in `t/t7900-maintenance.sh`. The series targets a race condition in Git's background maintenance logic, a recurring CI reliability headache.

Patch 1/2 makes three tests self-contained by switching them from the default trash directory to throwaway repositories (`git init repo`). This isolates environment changes and prevents tests from stepping on each other. The mechanical change from `test_config` to `git config set` is necessary because `test_config`'s cleanup relies on `test_when_finished`, which doesn't work in subshells; the throwaway repository's `rm -rf` cleanup handles everything at once.

The patch is clean, well-explained, and uncontroversial. It touches only the test file (43 insertions, 27 deletions) and makes no user-visible behavior changes. Karthik Nayak's review feedback was incorporated, and the commit message now clearly documents the constraint and rationale behind the mechanical change. This is a solid foundation for the actual flake fix in patch 2/2.
