This thread is a bug report from Marcel Svitalský about four spurious pseudo-commits appearing in the output of a custom `git lg` alias (`git log --graph --all --oneline --decorate`). These commits—three labeled “Notes added by 'git notes append' - rewrite-analytics” and one “chatter: initialize notes ref - chatter”—are visible only in the CLI alias and not in GUI tools like Sublime Merge or IntelliJ IDEA. The root cause has been identified: the `--all` flag in the alias includes all refs, including Git notes (`refs/notes/rewrite-analytics` and `refs/notes/chatter`), which form a disconnected graph. This is expected behavior, not a bug.

Marcel initially sought to understand why these commits appear and how to suppress them while retaining the alias’s intended output. Kristoffer Haugsbakk confirmed the root cause but did not propose a solution. D. Ben Knoble followed up with practical workarounds: either replace `--all` with `--branches --tags --remotes` to omit notes and other non-project refs, or use `--exclude='refs/notes/*' --all` to explicitly filter out notes while preserving broader coverage. Knoble also noted that Git notes are not new and suggested the notes may have appeared due to a tool in Marcel’s environment starting to create them. The thread remains under review, with no maintainer decision or deeper investigation into the source of the notes or the discrepancy with GUI tools. Open questions include whether this behavior is new or environment-specific, what processes are generating the notes, and why GUI tools filter them out by default.
