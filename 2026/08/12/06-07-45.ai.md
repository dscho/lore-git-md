This is patch 8/9 in Justin Tobler’s v3 series making `git receive-pack` fully backend-agnostic via ODB transactions. The patch removes a fragile assumption that the temporary ODB source is always the first entry in the source list by having `odb_set_temporary_primary_source()` return the newly installed source directly. The return value is propagated through `tmp_objdir_replace_primary_odb()` and stored in the "files" ODB transaction struct (`quarantine` field), ensuring the temporary source remains accessible post-commit without depending on source list ordering.

The change is a targeted internal refactor with no user-visible behavior changes. It directly addresses feedback from earlier iterations about the fragility of relying on source list ordering, making the design more resilient to future ODB abstraction work. Files touched are `object-file.c`, `odb.c`, `odb.h`, `tmp-objdir.c`, and `tmp-objdir.h`; modified symbols include `odb_set_temporary_primary_source()` (signature change), `tmp_objdir_replace_primary_odb()` (now returns `struct odb_source *`), and the new `quarantine` field in `struct odb_transaction_files`.
