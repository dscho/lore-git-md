This is the third patch in Patrick Steinhardt’s six-patch series (v3) making Git’s on-disk object database (ODB) structures pluggable. The patch moves the handling of the `GIT_OBJECT_DIRECTORY` and `GIT_ALTERNATE_OBJECT_DIRECTORIES` environment variables from `apply_repository_format()` into `odb_new()` itself.

The change is a refactoring that makes ODB creation more self-contained. Previously, environment variable handling was duplicated between repository setup and ODB initialization; now it lives entirely in `odb_new()`, which simplifies the code and prepares for future work where alternates will be managed by the "files" backend. The patch introduces a new `ODB_NEW_HONOR_ENV` flag to control whether environment variables are respected, and updates all callers to use the new interface.

This is a clean, mechanical change that aligns with the series’ broader goal of decoupling ODB setup from repository initialization. The patch is uncontroversial and ready for merging, though it paves the way for more ambitious backend work later. Files touched are `odb.c`, `odb.h`, `setup.c`, and a unit test.
