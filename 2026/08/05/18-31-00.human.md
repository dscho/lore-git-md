This is the final patch in Johannes Schindelin’s 11-patch v2 series hardening Git against unchecked return values identified by Coverity. It targets the bisect subsystem, specifically the `bisect_run()` function in `builtin/bisect.c`.

The patch fixes a silent failure path where `dup(1)` and `dup2(temporary_stdout_fd, 1)` were not checked for errors. If either call fails (e.g., due to file descriptor exhaustion), the code would proceed with an invalid descriptor (`-1`), leading to undefined behavior when `close(saved_stdout)` is later called and leaving stdout redirected to the temporary file for the remainder of the bisect run. The fix adds error checks for both `dup()` calls, emits an `error_errno()` message, closes the temporary file descriptor, and breaks out of the loop to ensure proper cleanup.

The change is minimal (six lines added, one removed) and aligns with the defensive error-handling pattern used elsewhere in the function. Patrick Steinhardt’s review suggestion to extend the check to `dup2()` is incorporated, resolving the last substantive feedback on the series. The patch is uncontroversial and ready for integration, completing the series’ goal of eliminating silent failures in critical code paths.
