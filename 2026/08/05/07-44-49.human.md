This is the fifth patch in Patrick Steinhardt’s eight-patch series unifying Git’s ODB streaming API. It merges the previously separate `struct odb_read_stream` and `struct odb_write_stream` into a single `struct odb_stream` that can handle both directions. The patch is mechanical except for two special cases: `builtin/unpack-objects.c` and `odb/streaming.c`, where the old structures were embedded directly and now require wrapper allocations. The commit message notes that some names are now slightly misleading but defers cleanup to later patches.

The change is part of the ongoing ODB abstraction effort and touches 14 files, including core object handling (`object-file.c`, `odb/streaming.c`), archive backends, and the in-memory ODB unit test. No behavior changes are intended; the patch simply consolidates the two stream types under a common interface. Reviewers have already confirmed the approach in earlier rounds, and the critical correctness issues raised in v1 (e.g., the in-memory ODB backend bug) were fixed in Patch 3/8. This patch is a straightforward refactoring that paves the way for the final API standardization in Patch 8/8.
