This is the fourth patch in Johannes Schindelin’s 12-patch **platform compatibility** series for MinGW/Windows. It refines the linker flag `-Wl,--large-address-aware` so that it is only applied to 32-bit builds (`MINGW32`), where it is actually needed and understood. On 64-bit builds (`MINGW64` and `CLANGARM64`), the flag is now omitted because it is either irrelevant or unsupported (e.g., UCRT64 versions of GCC ignore it). The change is a one-line adjustment in `config.mak.uname` that moves the flag into the `MINGW32` conditional block.

The patch is a straightforward, low-risk build-system tweak. It does not alter behavior on non-Windows platforms, nor does it introduce new symbols or on-disk format changes. The commit message clearly explains the rationale: the flag is only meaningful for 32-bit builds, and omitting it on 64-bit builds avoids potential linker warnings or errors. This aligns with the series’ overall goal of making the mainline Git codebase more compatible with Windows without affecting other platforms.
