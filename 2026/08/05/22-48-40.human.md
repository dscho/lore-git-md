This is Junio’s biweekly "What’s cooking in git.git" report for August 2026, summarizing the current state of integration branches. It’s the most comprehensive snapshot of what’s in flight for the next Git release, aimed at contributors who want to know which topics are stable, which need review, and which are stalled.

The report shows that 11 topics graduated to `master` since the last update, bringing the total to 401 non-merge commits since Git 2.55. The `next` branch currently holds 55 non-merge commits (some reverted), while `seen` contains 235, including everything in `next` and more experimental work.

Notable graduations include Patrick Steinhardt’s pluggable ODB housekeeping series (`ps/odb-pluggable-housekeeping`), which refactored `git gc` and `git maintenance` to move backend-specific logic into the files ODB, enabling future backends to implement their own optimizations. Jeff King’s CI image bump (`jk/ci-static-analysis-image-bump`) resolved a severe Coccinelle performance regression by upgrading to Ubuntu 24.04. Phillip Wood’s rebase fixup fixes (`pw/rebase-fixup-fixes`) corrected two bugs in how `git rebase` handles skipped `fixup` and `squash` commands, including a commit count miscalculation and a missing editor invocation.

New topics include Patrick Steinhardt’s ODB streaming unification (`ps/odb-streams`), which consolidates read and write streams into a single `struct odb_stream` to simplify APIs and support arbitrary object types. brian m. carlson’s hex parser restriction (`bc/restrict-hex-to-lowercase`) prepares for Git 3.0 by teaching the parser to reject uppercase hex characters in breaking-changes mode. Johannes Schindelin’s MinGW build updates (`js/mingw-build-updates`) upstream a dozen patches from Git for Windows, including dropping obsolete compatibility options and allowing `git.exe` to be used directly without a wrapper.

Several topics are stalled or waiting for response, including Taylor Blau’s geometric cruft repack (`tb/repack-geometric-cruft`), which combines `--geometric` with `--cruft` but has unresolved test issues, and Toon Claes’s `last-modified` Bloom filter optimization (`tc/last-modified-bloom`), which needs a reroll to address feedback about wildcard pathspec handling.

The report also highlights ongoing work like Karthik Nayak’s ref migration documentation (`kh/doc-refs-migrate-limitations`), which moved warnings about limitations directly under the `migrate` subcommand for better visibility, and Junio’s own completion fix (`jc/complete-diff-tracked-paths`), which now completes untracked paths for `git diff` as a last resort.

For a busy reader, the key takeaway is that the ODB abstraction and pluggable housekeeping work is now stable, while the streaming and hex parser changes are new and need review. The stalled topics are worth watching if you’re interested in repacking or Bloom filters, but they’re not yet ready for prime time. The report is a good reminder to check the "What’s cooking" emails regularly if you want to stay current on Git’s development.
