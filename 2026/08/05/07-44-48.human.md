This is a refactoring patch (part of the ongoing ODB abstraction effort) that renames `struct odb_read_stream` to `struct odb_stream`. It is the fourth patch in Patrick Steinhardt’s eight-patch v2 series unifying the ODB’s read and write streaming APIs.

The patch is purely mechanical: every occurrence of `struct odb_read_stream` is replaced with `struct odb_stream`, and the corresponding function names (`odb_read_stream_read`, `odb_read_stream_close`) are updated to match. The change touches 18 files, including core object handling (`object-file.c`, `odb/streaming.c`), archive formats (`archive-tar.c`, `archive-zip.c`), packfile operations (`builtin/pack-objects.c`, `packfile.c`), and the in-memory ODB unit test. No behavior changes are intended; the rename simply prepares the codebase for the subsequent unification of read and write streams into a single bidirectional `odb_stream` structure.

The patch is well-scoped and uncontroversial. It follows the pattern established in earlier patches (e.g., embedding the object type and size in the stream structure) and aligns with the series’ goal of eliminating redundancy in the ODB API. Reviewers familiar with the series (such as Justin Tobler) are likely to focus on ensuring the rename is complete and that no lingering references to the old type remain.
