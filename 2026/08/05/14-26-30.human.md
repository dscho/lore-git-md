This is the fourth patch in Johannes Schindelin’s 12-patch **platform compatibility** series, upstreaming Git for Windows build adjustments into mainline Git.

The patch restricts the `-Wl,--large-address-aware` linker flag to 32-bit MinGW builds only. That flag is irrelevant (and sometimes unrecognized) on 64-bit builds such as UCRT64, so the change simply moves it inside the `MINGW32` conditional block in `config.mak.uname`. The diff is tiny—two lines moved, two lines deleted—and the commit message explains the rationale clearly: the flag only matters for 32-bit address-space layout, and newer 64-bit toolchains don’t need or understand it.

No behavior change is expected on non-Windows platforms, and the patch is purely about build hygiene. If you care about Windows build quirks, this is a routine maintenance tweak; otherwise, it can safely be ignored.
