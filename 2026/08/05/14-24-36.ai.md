This is the sixth patch in Harald Nordgren’s v25 `--delete-merged` series, now merged to **'next'**. It introduces the `branch.<name>.deleteMerged` configuration key, allowing users to opt specific branches out of automated cleanup while still permitting explicit deletion via `git branch -d`.

The implementation adds a config check in `delete_merged_branches()` that skips any branch with `branch.<name>.deleteMerged=false`, printing a non-quiet message to explain the skip. The opt-out is ignored by traditional `git branch -d`, which continues to use the normal merge check. Documentation updates clarify the behavior in `branch.adoc` and `git-branch.adoc`, and the test suite verifies both the opt-out mechanism and explicit deletion.

Phillip Wood’s earlier surface-level review suggested a mechanical test improvement (using `check_branches` with `for-each-ref` for verification), which has been applied. The patch is straightforward, well-tested, and aligns with the series’ safety-focused design. No functional changes were made in v25; this version only inherits the series-wide test readability improvements.
