This is the first patch in Johannes Schindelin’s 12-part **platform compatibility** series, upstreaming Git for Windows build adjustments. It enables the Python parts of Git to be built on MinGW/Windows by clearing the `NO_PYTHON` flag in `config.mak.uname`.

The change is minimal: one line in the Makefile configuration. The motivation is practical: while Git for Windows itself doesn’t ship Python (to save bandwidth), MSYS2 provides Python interpreters, and users who install them via the Git for Windows SDK should be able to build Git with Python support. This is a routine build-system tweak with no impact on non-Windows platforms or runtime behavior.

If you’re not involved in Windows builds, this patch can be safely ignored. If you are, it’s a small but useful step toward making Git’s build more flexible on Windows. The rest of the series will follow similar patterns—each patch addressing a specific Windows build quirk.
