This is a cosmetic refactoring patch in the ODB streaming unification series. It renames `struct input_zstream_data` to `struct zlib_stream` in `builtin/unpack-objects.c` to better reflect its expanded role after the earlier patches merged the read and write stream APIs. The change is purely mechanical: the structure now embeds an `odb_stream` base (introduced in Patch 5/8) alongside its zlib-specific fields, so the old name no longer accurately describes its contents.

The patch updates the structure definition, its constructor (`in_stream`), and the associated callback function (`feed_input_zstream` → `zlib_stream_read`). All changes are confined to a single file (`builtin/unpack-objects.c`), with six lines modified. The commit message explains the rationale clearly: the new name aligns with the unified `odb_stream` API and avoids implying the structure is merely a data container.

This addresses feedback from Justin Tobler in v1, who noted the original name was misleading after the stream unification. The patch has no functional impact and is unlikely to block the series, but reviewers may check for completeness (e.g., no lingering references to the old name in comments or future patches).
