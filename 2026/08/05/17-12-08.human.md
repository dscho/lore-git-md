This is a **platform compatibility** patch review from Junio C Hamano, responding to the ninth patch in Johannes Schindelin’s 12-part series for MinGW/Windows. The patch stops Git for Windows from generating hard-linked `git-<command>` executables (e.g., `git-commit`), a form deprecated since Git 1.5.4 (2008).

Junio’s reply is brief and positive. He endorses the patch’s goal of phasing out the dashed form on Windows and suggests a broader cleanup: removing the dashed-form executables entirely at the Git 3.0 boundary. He does not object to the patch itself or ask for changes, but frames it as the first step toward a larger deprecation effort. The tone is matter-of-fact, treating the patch as a routine, uncontroversial adjustment. No technical concerns or merge status are mentioned; the patch remains under review.
