This thread is a bug report from D. Ben Knoble about `git rebase` unexpectedly losing notes when used with `-x` (execute command) and `git commit --amend`. The issue surfaces when rebasing with an `-x` command that amends commits—notes attached to the tip commit (in `refs/notes/benknoble/commits`) disappear, despite `notes.rewriteref` being configured to preserve them. Knoble notes that `git commit --amend` alone *does* rewrite notes correctly, and a plain `git rebase` (without `-x`) also preserves them, suggesting the bug is specific to the interaction between `rebase -x` and amend operations.

The report is detailed, including relevant configuration (`notes.rewriteref`, `core.notesref`) and a clear reproduction sketch, though Knoble hasn’t yet minimized a test case.
