This is a brief follow-up in Patrick Steinhardt’s ODB streaming API refactoring series, specifically addressing feedback on the third patch. The patch extends the write-stream infrastructure to support arbitrary object types (not just blobs) by adding an `enum object_type type` field to `struct odb_write_stream` and updating callers. Justin Tobler’s review noted an outdated comment in `odb/transaction.h` that still assumed blob-only streaming; Patrick confirms this has been fixed. The change is purely cosmetic and does not affect functionality, but it removes a potential source of confusion for future readers. The series remains blocked on a critical correctness issue in this same patch (the in-memory ODB backend incorrectly computes object names for non-blob objects), which Junio C Hamano identified earlier and which must be resolved before the patch can proceed. This follow-up is a minor cleanup and does not advance the substantive discussion.
