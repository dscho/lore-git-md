This is a refactoring patch in Patrick Steinhardt’s six-part series making Git’s on-disk object database (ODB) structures pluggable. It is the fifth patch in the v3 iteration, part of the ongoing ODB abstraction effort.

The patch introduces a new helper function, `odb_source_type_to_name()`, that maps an ODB source’s enum type to a human-readable string. The function is then used to improve the error messages in the downcasting macros (`odb_source_files_downcast()`, `odb_source_loose_downcast()`, etc.). Instead of printing raw enum values like “trying to downcast source of type '3' to packed,” the BUG messages now read “trying to downcast source of type 'loose' to 'packed',” making debugging output clearer.

The change is purely internal: it touches only the ODB source headers and implementation files (`odb/source*.c`, `odb/source*.h`) and does not alter any user-visible behavior. The commit message is concise and the patch itself is mechanical—replacing numeric type codes with symbolic names in BUG messages. No new tests are added because the change affects only error reporting, not runtime logic. The patch is uncontroversial and ready for merging.
