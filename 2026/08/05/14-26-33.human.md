This is the seventh patch in Johannes Schindelin’s 12-patch **platform compatibility** series, upstreaming Git for Windows build adjustments into mainline Git.

The patch makes the MSYS2-specific code conditional: it only enables the MSYS2 tty-detection logic (`DETECT_MSYS_TTY`) and ensures the `MSYSTEM` environment variable is preserved when compiling inside an MSYS2 shell. The trigger is the presence of the `MSYSTEM` variable during the build. The change is a two-line edit to `config.mak.uname` that moves the `DETECT_MSYS_TTY` flag inside the `if MINGW` block and wraps it in an `if MSYSTEM` guard.

The motivation is straightforward: these adjustments should only apply when Git is actually built in an MSYS2 environment, avoiding unnecessary or potentially harmful side effects on other MinGW builds. The patch is minimal, self-contained, and does not affect non-Windows platforms. If you are reviewing the series for Windows build hygiene, this is a routine correctness tweak; otherwise, it can safely be skipped.
