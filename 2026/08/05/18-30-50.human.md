This is the first patch in Johannes Schindelin’s v2 series fixing unchecked return values flagged by Coverity. It targets a critical crash hazard in Git’s HTTP transport layer: `get_active_slot()` in `http.c` now checks whether `curl_easy_duphandle()` returns NULL before proceeding to call `curl_easy_setopt()`. If the duplication fails—typically due to memory exhaustion—the process dies with a clear error message instead of dereferencing a NULL handle and crashing. The fix is minimal, self-contained, and uncontroversial; it touches only two lines and introduces no new behavior or dependencies. All HTTP-based operations (clone, fetch, push, bundle-uri downloads) benefit from the hardening. The patch is ready for final review and integration.
