This is the first patch in Harald Nordgren’s **v25 `--delete-merged` series**, which is now merged to **'next'**. The patch adds a `--forked` filter to `git branch --list` mode, enabling users to list branches whose upstream matches a given pattern (exact refname, remote shorthand, or shell-style glob). The filter is composable with existing filters like `--merged` and `--no-merged`, and can be repeated to widen the match.

The implementation is purely additive and serves as the foundation for the `--delete-merged` subcommand introduced later in the series. The only change since v24 is mechanical: long test command lines in `t/t3200-branch.sh` have been wrapped for readability, with no functional or correctness changes. The test suite now covers exact refnames, remote shorthand, shell globs, repeated arguments, and composition with other filters.

The patch is well-tested and uncontroversial, with no outstanding technical concerns. It introduces no behavioral changes to existing functionality and aligns with Git’s API consistency expectations. The `--forked` filter is a key building block for the series’ goal of safe, automated local branch cleanup.
