This is the second patch in Johannes Schindelin’s 11-patch v2 series hardening Git against unchecked return values identified by Coverity. It fixes a silent failure in `git config edit` and `git config --edit` when the editor fails to launch.

The patch is small and surgical: `show_editor()` in `builtin/config.c` now checks the return value of `launch_editor()` and propagates a failure (returning `-1`) instead of unconditionally returning `0`. The two callers already handle negative returns by exiting with an error, so the change integrates cleanly with existing control flow. No new behavior or error messages are introduced; `launch_editor()` already emits its own diagnostics, so the caller only needs to propagate the failure upward.

Patrick Steinhardt reviewed this patch in v1 and confirmed the approach is correct. The fix is uncontroversial and ready for integration. It touches only one file and does not affect on-disk formats or test coverage.
