This is the first patch in Johannes Schindelin’s 12-patch series widening size fields in Git’s delta and pack machinery to `size_t` for 64-bit Windows compatibility. The series is part of the broader effort to eliminate incorrect `unsigned long` usage, and this patch prepares the ground by widening the private `struct delta_index` fields (`src_size` and `memsize`) and the return type of `sizeof_delta_index()` from `unsigned long` to `size_t`.

The change is purely internal to `diff-delta.c` and has no runtime effect yet, since the public API around it still truncates values to 32 bits on Windows. The patch is mechanical and uncontroversial, addressing a specific review request from Patrick Steinhardt on the v1 series to widen `sizeof_delta_index()`’s return type. The commit message clearly explains the preparatory nature of the work and its role in enabling later patches to drop `cast_size_t_to_ulong()` shims.

This is a well-scoped, low-risk refactoring that directly supports the series’ goal of fixing integer truncation on 64-bit Windows. The patch is ready for integration and sets the stage for the rest of the series.
