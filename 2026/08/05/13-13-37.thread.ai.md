Subject: `git rebase -x` with `git commit --amend` loses notes
Series version: standalone bug report (no patch series)
Originating author: D. Ben Knoble
Thread type: bug report

Core problem or goal
`git rebase -x` (with an external command) combined with `git commit --amend` fails to rewrite notes attached to the tip commit, even when `notes.rewriteref` is configured to include the relevant notes ref (`refs/notes/benknoble/commits`). The same `git commit --amend` outside rebase, or a plain `git rebase` (without `-x`), correctly preserves the notes, indicating the bug is specific to the interaction between `-x` and the amend operation.

Current status
Under investigation; no prior discussion or patch proposed. The report is the first public mention of the issue.

Key technical details
- Subsystems: rebase, notes
- Commands: `git rebase -x`, `git commit --amend`
- Config keys: `notes.rewriteref`, `core.notesref`
- Notes ref: `refs/notes/benknoble/commits`
- Behavior: notes are lost only when `-x` and `--amend` are combined; plain `--amend` or plain rebase works as expected
- On-disk: notes ref is not updated during the rebase sequence when the bug triggers
