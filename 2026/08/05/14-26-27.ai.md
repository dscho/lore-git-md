This is the first patch in Johannes Schindelin’s 12-part **platform compatibility** series for MinGW/Windows. It enables the Python-related parts of Git to be built on Windows by removing the `NO_PYTHON` flag in `config.mak.uname` for the MINGW platform.

The change is minimal—just one line in a build configuration file—but the rationale is clear: Git for Windows doesn’t ship Python itself, but MSYS2 provides Python interpreters that users can install separately. This patch ensures those users can build Git with Python support if they choose, without affecting non-Windows builds. The commit message is concise and explains the motivation well.

This is a routine build-system adjustment, not a behavior change. If you’re not working on Windows or Python integration, this patch can be safely ignored. The rest of the series will likely follow similar patterns—small, targeted fixes for Windows-specific build quirks.
