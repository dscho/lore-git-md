This thread is about a 12-patch series from Johannes Schindelin (Dscho) that upstream Git for Windows-specific build and runtime adjustments into the main Git codebase. The series addresses hard-coded assumptions in the build system, MSYS2 integration, linking behavior, deprecated artifacts, a locale-handling regression in the MSYS2 runtime, and direct `git.exe` invocation—all without affecting non-Windows platforms.

The series is now at v2, with the only change from v1 being a fix to align Meson’s `MINGW_PREFIX` handling with the Makefile’s (removing a leading slash) in Patch 8. Patches 10 (simplifying `ETC_GITCONFIG`/`ETC_GITATTRIBUTES` path logic) and 11 (fixing a locale-handling regression) are uncontroversial and ready for integration. The main open discussion revolves around Patch 12, where Junio C Hamano has reinforced the need for defensive programming against an empty `MSYSTEM` export, while Dscho argues the scenario is too unlikely to warrant additional guards. Johannes Sixt (Hannes) has also suggested a cleanup to move CMake/Meson hunks from Patch 8 to Patch 12 for better logical ordering, though this isn’t a blocking issue.

Hannes has now provided real-world validation: he’s been running a subset of these patches (2–6, 8, and either 9 or 12) in his personal Windows builds since November 2025 without issues, and the full series passes GitHub CI. This gives confidence that the core changes are stable and unlikely to introduce regressions. The series remains under review, with no merge intent signaled yet, but the recent feedback is a positive sign for Windows compatibility.
