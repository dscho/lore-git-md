This thread is about a 12-patch series from Johannes Schindelin that upstream Git for Windows build and runtime adjustments into mainline Git. The goal is to address hard-coded assumptions, MSYS2 integration, and linking behavior specific to the MinGW/Windows build system. So far, only the first patch has been reviewed in detail: it enables Python-related parts of Git to be built on Windows by removing the `NO_PYTHON` flag in `config.mak.uname` for the MINGW platform. This is a routine build-system tweak that doesn’t affect non-Windows platforms.

The series is still in its initial version (v1) and under review. No substantive feedback has been recorded yet, but the patches are expected to follow the same pattern—small, targeted fixes for Windows-specific build quirks. The changes touch build configuration files, compatibility layers, and test adjustments, but don’t introduce new symbols or alter behavior for other platforms. If you’re not working on Windows or Python integration, this series is likely of low priority.
