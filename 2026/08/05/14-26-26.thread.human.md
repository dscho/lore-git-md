This thread is about a 12-patch series from Johannes Schindelin (Dscho) that upstream Git for Windows-specific build and runtime adjustments into the main Git codebase. The series, now at v2, addresses hard-coded assumptions, MSYS2 integration, linking behavior, deprecated build artifacts, a locale-handling regression in the MSYS2 runtime, and direct `git.exe` invocation—all without affecting non-Windows platforms.

Key changes in the series include enabling Python buildability for MinGW, removing outdated compiler flags (e.g., `-D_USE_32BIT_TIME_T`), refining linker flags for 32-bit vs. 64-bit builds, replacing hard-coded paths with MSYS2 environment variables, disabling dashed-form executables (e.g., `git-commit`), fixing a locale-handling regression, and allowing direct `git.exe` invocation. The v2 iteration addressed Junio C Hamano’s concern about cross-build-system inconsistency in Patch 8 but left unresolved a minor correctness issue in Patch 12 (empty `MSYSTEM` export), which Dscho declined to guard against.

The series is under review, with no objections raised. Junio’s feedback has been largely surface-level or addressed in v2, except for a forward-looking suggestion to remove dashed-form executables entirely in Git 3.0. The patches are routine build-system cleanups, with the most substantive changes being the locale regression fix (Patch 11) and the environment setup for direct `git.exe` invocation (Patch 12). No merge status has been reported; the series remains proposed.
