This thread is a 12-patch series from Johannes Schindelin (Dscho) that upstream Git for Windows-specific build and runtime adjustments into the main Git codebase. The goal is to improve Windows compatibility—enabling Python support, compiler flexibility, UCRT64 compatibility, MSYS2 integration, and fixing a locale-handling regression—without affecting non-Windows platforms.

The series is now at v2, with the only change from v1 being a fix to align Meson’s `MINGW_PREFIX` handling with the Makefile’s, addressing a cross-build-system inconsistency noted by Junio C Hamano. The series remains under review, with no merge status reported. One open discussion point is whether to guard against an empty `MSYSTEM` export in Patch 12, which Johannes has declined to address, arguing the scenario is too unlikely to warrant additional build-system guards.

Key adjustments include enabling Python buildability (Patch 1), removing hard-coded compiler flags (Patches 2–5), refining MSYS2 integration (Patches 6–8), phasing out dashed-form executables (Patch 9), fixing locale handling (Patch 11), and allowing direct `git.exe` invocation (Patch 12). Junio has also suggested removing dashed-form executables entirely in Git 3.0, though this is a forward-looking proposal rather than a request for changes to the current series.

The series is well-motivated and addresses real-world Windows compatibility issues, with no unresolved technical concerns for most patches. If you care about Windows build flexibility or Python integration, this series is worth following; otherwise, it can be safely ignored for now.
