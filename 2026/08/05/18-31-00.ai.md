This is the eleventh and final patch in Johannes Schindelin’s v2 series fixing unchecked return values flagged by Coverity. It targets a silent failure in `git bisect run` where `dup(1)` and `dup2(temporary_stdout_fd, 1)` calls could fail without being checked, leaving the process with stdout incorrectly redirected to a temporary file for the remainder of the bisect run.

The fix adds error checks for both `dup(1)` and `dup2(temporary_stdout_fd, 1)`. If either call fails, the code now emits an `error_errno()` message, closes the temporary file descriptor, and breaks out of the bisect-run loop, ensuring proper cleanup and preventing undefined behavior. This change directly addresses Patrick Steinhardt’s v1 review suggestion to extend the error check to cover `dup2()`, which was implemented in the sixth fixup patch of v2. The patch is minimal (six lines added, one removed) and follows the existing error-handling pattern in `bisect_run()`.

The file touched is `builtin/bisect.c`; no new symbols or behavior changes are introduced beyond the added error handling. The fix is uncontroversial and technically complete, with all review feedback incorporated. This patch, like the rest of the series, is ready for final review and integration.
