This is the second patch in Tian Yuchen’s three-patch refactoring series that tidies up repository-configuration handling in `environment.c` and `environment.h`. It replaces three separate, nearly identical comments above the getter functions (`repo_protect_hfs`, `repo_protect_ntfs`, and `repo_ignore_case`) with a single, concise header that describes the common behavior: when the repository is not fully initialized, the getters return the appropriate default values. The change is purely documentary—no code or signatures are altered—and reduces the comment block from eight lines to three. The patch is small, mechanical, and clearly motivated by the goal of eliminating redundancy.
