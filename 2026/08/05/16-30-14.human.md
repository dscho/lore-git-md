Junio C Hamano replies to Xavier Morel's report about inconsistent behavior when using `git push --delete --porcelain` on refs that no longer exist on the remote. Junio acknowledges the gap, calling it an oversight in coverage for this edge case. His response is brief but clear: the project would welcome a patch to fix this.

The problem is well-scoped and straightforward. This would make the output consistent for both successful and failed deletions, improving reliability for automation tools.
