This is the seventh patch in the v2 series fixing unchecked return values identified by Coverity. It targets `transport-helper.c` and adds a missing error check for `dup(helper->in)` in `get_exporter()`.

The patch prevents a silent failure mode where a failed `dup()` (e.g., due to file descriptor exhaustion) would cause the `fast-export` process to write its output to an unread pipe instead of the intended helper input fd. The fix propagates the error upward with `error_errno()`, ensuring the caller (`push_refs_with_export()`) can handle it appropriately (it already dies on non-zero returns). Patrick Steinhardt reviewed this change and confirmed its correctness, noting the existing control flow integrates cleanly with the new check.

The change is minimal (two lines added) and uncontroversial. It does not introduce new behavior or on-disk formats, only hardening an existing code path against silent data loss. The patch is ready for integration.
