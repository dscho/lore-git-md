This is the final patch in Patrick Steinhardt’s eight-part series unifying Git’s object database (ODB) streaming API. It standardizes the function names that create new streams, replacing `odb_read_stream_open()` with `odb_stream_from_object()` and `odb_write_stream_from_fd()` with `odb_stream_from_fd()`. The patch also documents that the caller retains ownership of the file descriptor passed to `odb_stream_from_fd()`, clarifying a potential source of confusion.

The changes are mechanical: eight files (`archive-tar.c`, `archive-zip.c`, `builtin/index-pack.c`, `builtin/pack-objects.c`, `object-file.c`, `object.c`, `odb/streaming.c`, and `odb/streaming.h`) are updated to use the new function names. The commit message and in-code comments now explicitly state that the file descriptor is not closed by the stream, which should prevent descriptor leaks or double-close bugs.

This patch is a clean-up step that follows the structural unification in Patch 5/8. It does not change behavior, but the naming and documentation improvements make the API more intuitive and self-documenting. The series as a whole is now complete, addressing all feedback from v1, and looks ready for `next`.
