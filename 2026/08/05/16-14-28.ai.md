This is the first patch in Johannes Schindelin’s v2 series widening size-related fields in Git’s delta machinery from `unsigned long` to `size_t`. It prepares the ground for later patches by widening the `src_size` and `memsize` fields in the private `struct delta_index` (used internally by `diff-delta.c`) to `size_t`. The return type of `sizeof_delta_index()` is also adjusted to match, since it directly returns the `memsize` field.

The change is purely internal to `diff-delta.c` and has no runtime effect yet — the values stored in these fields are still constrained by the narrow public API around them. The patch is mechanical and uncontroversial, splitting out the type widening of the struct from the later patches that update callers. This keeps the subsequent API-change commit focused on external callers rather than mixing internal and external changes.

Files touched: `delta.h` (return type of `sizeof_delta_index()`) and `diff-delta.c` (struct field definitions and local variable in `create_delta_index()`). No behavior or on-disk format changes; this is a preparatory refactoring for the broader `unsigned long` → `size_t` conversion effort. The patch directly addresses feedback from Patrick Steinhardt on v1, which requested widening the return type of `sizeof_delta_index()` to match the struct’s `memsize` field.
