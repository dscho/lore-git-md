This is the fifth patch in Johannes Schindelin’s 12-patch **platform compatibility** series, upstreaming Git for Windows build adjustments. It removes an overly specific linker flag (`-Wl,--pic-executable,-e,...`) from the MinGW section of `config.mak.uname`.

The commit message explains that the explicit entry-point specification (`-e,_mainCRTStartup` or `-e,mainCRTStartup`) was introduced in 2016 to work around a linker quirk but is now redundant: the symbols are already the default. The patch simplifies the linker flags for all three MinGW variants (32-bit, 64-bit, and ARM64) by dropping the `-e` argument while keeping `--pic-executable`.

This is a clean, low-risk cleanup—no behavior change, just removing dead code. The change is Windows-only and won’t affect other platforms. If you’re following the series for Windows build hygiene, this patch is routine; otherwise, it’s skippable.
