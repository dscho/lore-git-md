This is the third patch in Patrick Steinhardt’s six-part series making packfile generation pluggable in Git’s object database layer. It migrates `git send-pack` from manually spawning `git pack-objects` to using the new ODB interface introduced in earlier patches.

The change is mechanical but consequential: `send-pack.c` replaces its direct `child_process` construction with a declarative `struct odb_generate_pack_options` populated with the same settings (thin packs, delta policies, progress flags, shallow boundaries). The ODB layer’s files-backend implementation translates these options into the equivalent `git pack-objects` command-line arguments, preserving all existing functionality. A new helper, `append_negative_object()`, ensures the ODB layer only receives valid boundary objects.

The patch touches only two files: `send-pack.c` (101 lines removed, 40 added) and `t/t5516-fetch-push.sh` (12 lines adjusted). The test changes account for benign argument-order differences and the replacement of `-q` with `--quiet`, with no behavioral impact. The series remains queued in `seen` and is under active review; this patch itself has no known issues or objections. Contributors working on transport plumbing or alternate ODB backends will want to note the new interface.
