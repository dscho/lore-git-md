Subject: [RFC PATCH v2] config: propagate editor failure exit code
Series version: v2 (standalone patch, now superseded by merged commit 633ac346ee)
Originating author: Kenneth Lorber
Thread type: bug report / bugfix patch

Core problem or goal
`git config -e` previously exited with status 0 even when the configured editor failed (crashes or returns non-zero). The patch proposed changing `show_editor()` in `builtin/config.c` to return the error code from `launch_editor()` instead of unconditionally returning 0, thereby surfacing the editor failure to the caller. This aligns the behavior with commands like `git commit`.

Current status
**Merged to `next` as commit 633ac346ee ("config: propagate launch_editor() failure in show_editor()", 2026-08-12)**. The implementation is functionally identical to the v2 patch, including the one-line code change. The two new tests proposed in v2 (covering editor success and failure) were **not** included in the merged commit, leaving the test suite unchanged. The feature's mid-2024 introduction limited the scope of potential breakage, and no issues have been reported since merging. The thread's core tension (consistency vs. script breakage) is resolved in favor of propagating the editor exit code. Junio's closing meta-comment confirms the thread is over, with no further action expected on the missing tests.

Key technical details
Files touched: `builtin/config.c` (function `show_editor()`)
New symbols: none
Behavior change: `git config -e` now exits non-zero if the editor fails, rather than always exiting 0
On-disk format: unchanged
Test coverage: **unchanged** (the two tests proposed in v2 were omitted from the merged commit; no explicit test coverage for the new behavior exists in the test suite). Junio's follow-up email recommends idiomatic shell patterns (`GIT_EDITOR=true git -C repo config -e` and `test_must_fail env GIT_EDITOR=false git -C repo config -e`) for any future test additions, rejecting `test_env` and manual `export`/`unset` sequences.

Open questions and loose ends
