This thread began as an RFC patch to fix what Kenneth Lorber identified as a bug: `git config -e` ignored the exit code of the configured editor, always returning success even if the editor crashed or failed. The patch proposed a one-line change to propagate the editor's exit code, aligning `git config -e` with commands like `git commit`. After some discussion weighing the trade-off between conceptual correctness and potential script breakage, the maintainer, Junio C Hamano, has now informed the list that the change was already implemented and merged into the `next` branch on 2026-08-12 (commit 633ac346ee). The merged version is functionally identical to Kenneth's v2 patch, so the thread's central question is now resolved. No further action is needed from the author, and the feature will graduate to `master` in due course. The recent introduction of `git config -e` (mid-2024) appears to have limited the risk of breaking existing scripts.
