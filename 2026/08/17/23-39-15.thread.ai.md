Subject: [PATCH] pack-objects: add Trace2 data point for total bytes written

Originating author: friel@openai.com

Core problem or goal
Add a Trace2 event to `git pack-objects` that records the cumulative size (in bytes) of all pack files generated during a single invocation, including headers and checksums. This fills an observability gap: Trace2 already records object counts but not byte counts, which are needed to measure how compression settings affect push performance.

Current status
Under review; no prior versions. Patch is self-contained, touching only `builtin/pack-objects.c` and the test suite (`t/t5326-pack-objects-trace2.sh`). Tests verify the event fires for both single and split packs (when `pack.packSizeLimit` is set).

Key technical details
- New Trace2 event: `write_pack_file/wrote_bytes`
- Symbol: `total_written` (accumulator variable)
- Files: `builtin/pack-objects.c`, `t/t5326-pack-objects-trace2.sh`
- Behavior: reports cumulative bytes written across all packs in a single `git pack-objects` run
- On-disk format: no changes
- Test coverage: single pack, split packs, and edge cases (empty packs)
