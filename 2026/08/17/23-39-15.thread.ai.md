Core problem or goal
Add a Trace2 event to `git pack-objects` that records the cumulative size (in bytes) of all pack files generated during a single invocation, including headers and checksums. This fills an observability gap: Trace2 already records object counts but not byte counts, which are needed to measure how compression settings affect push performance.

Current status
Under review; v2 posted in response to Junio C Hamano’s **substantive review feedback** on v1. The update simplifies the byte-accumulation logic by removing the intermediate `pack_bytes` variable and directly accumulating `bytes_written` using `hashfile_total(f)` plus the hash algorithm’s raw size. The patch remains focused on `builtin/pack-objects.c` and test suite (`t/t5300-pack-object.sh`). No merge status reported; still under review.
