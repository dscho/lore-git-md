This thread is about a small but useful observability improvement: adding a Trace2 event to `git pack-objects` that records the total number of bytes written across all pack files in a single invocation, including headers and checksums. The patch, now at v2, was posted by friel@openai.com in response to Junio C Hamano’s review of the initial version.

The v2 patch simplified the byte-accumulation logic as Junio suggested, but Patrick Steinhardt’s recent review raises a correctness concern: whether the patch uses the right hash algorithm size (`f->algop->rawsz` vs. `the_repository->hash_algo->rawsz`) to accurately include the trailing checksum in the byte count. He also suggests a minor naming tweak for clarity—renaming the existing `"write_pack_file/wrote"` event to `"wrote_objects"`—but this is optional. The patch itself remains uncontroversial, with no objections to its core goal or design.

The series touches only `builtin/pack-objects.c` and the test suite, and test coverage is already in place for single packs, split packs, and edge cases. Once the hash size question is resolved, the patch should be ready for integration. No other open questions or objections have been raised.
