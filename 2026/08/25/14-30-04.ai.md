This is the second patch in Patrick Steinhardt’s 10-patch series making ODB fsck checks pluggable. It refactors `builtin/fsck.c` by merging the two closely related functions `fsck_obj_buffer()` and `fsck_obj()` into a single function.

The patch eliminates redundancy: `fsck_obj()` had no callers other than `fsck_obj_buffer()`, and the only difference between them was that `fsck_obj_buffer()` parsed the object buffer before calling `fsck_obj()`. The merged function now handles both parsing and verification in one place, removing an early return check for the `SEEN` flag that was always cleared by the caller anyway. The change is purely internal and does not alter behavior or user-facing interfaces.

Key technical details: the patch removes 27 lines and adds 20 in `builtin/fsck.c`, consolidating object parsing and fsck logic into `fsck_obj_buffer()`. The function now unconditionally sets the `SEEN` and `HAS_OBJ` flags and clears `REACHABLE`, matching the previous caller’s behavior. The patch is a clean, mechanical refactoring that simplifies the codebase as part of the broader ODB abstraction effort. No new symbols are introduced; the existing `fsck_obj_buffer()` interface remains unchanged.
