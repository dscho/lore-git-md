This is patch 7/10 in Patrick Steinhardt’s series making ODB fsck checks pluggable. It moves the reverse-index verification logic from `builtin/fsck.c` into the packed ODB backend (`odb/source-packed.c`).

The patch removes the `check_pack_rev_indexes()` function from `builtin/fsck.c` (37 lines deleted) and reimplements it as `verify_reverse_indices()` inside `odb/source-packed.c` (39 lines added). It also drops the dedicated `ERROR_PACK_REV_INDEX` error bit in favor of the generic `ERROR_OBJECT` bit, matching the pattern established in patch 6/10. The new implementation respects the `--connectivity-only` and `--no-full` flags: reverse-index checks are skipped when either flag is passed, aligning the behavior with the documented intent of those options. A new test in `t/t5325-reverse-index.sh` verifies these semantics.

This is a clean refactoring that continues the series’ goal of moving backend-specific fsck logic into the appropriate ODB source files. The change is mechanical and well-motivated, with clear test coverage for the new behavior. No user-visible changes beyond the flag-dependent behavior already documented.
