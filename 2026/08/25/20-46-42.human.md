This is a new feature patch introducing a `` `git whoami` `` command. The patch is self-contained, well-documented, and includes a full test suite.

The command displays the current author and committer identity (name and email) along with commit signing configuration (GPG/SSH key ID and whether `commit.gpgsign` is enabled). It supports several flags (`--author`, `--committer`, `--name`, `--email`, `--signing-key`, and `--verbose`) to query specific parts of the identity or signing setup, making it useful for both interactive use and scripting.

The implementation is straightforward: it uses Git’s existing `ident.h` and `gpg-interface.h` APIs, integrates with the build system (Makefile and meson), and adds a man page. The test suite covers all flags, incompatible option combinations, environment variable overrides, and behavior outside a repository. The commit message clearly explains the motivation—users often need to verify their active identity and signing key across different environments—and provides example output.

This looks like a polished, well-motivated addition that addresses a real workflow pain point. It is not part of any larger series and stands on its own.
