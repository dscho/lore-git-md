This thread is about a small but clean refactoring of Git's worktree handling. René Scharfe, a steady contributor known for tidy code improvements, is simplifying the `worktree_basename()` function in `builtin/worktree.c`. The change replaces manual pointer arithmetic with a safer, dynamically allocated string copy, renaming the function to `worktree_basename_dup()` to make the memory ownership clear. All callers have been updated to match, keeping the line count the same but removing a potential source of bugs. This is the fourth patch in a four-part series, and like the rest, it's a mechanical, low-risk adjustment focused on the `git worktree add` command. No objections or review feedback have surfaced yet, and the series appears uncontroversial.
