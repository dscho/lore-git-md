This is a refactoring patch from René Scharfe, part of a four-patch series (this is the fourth patch). It simplifies the `worktree_basename()` function in `builtin/worktree.c` by having it return a dynamically allocated string copy of the basename instead of requiring callers to perform pointer arithmetic. The function is renamed to `worktree_basename_dup()` to signal that the caller must free the result. The patch updates all callers to use the new function, replacing manual string extraction with direct allocation and freeing, which maintains the same line count but removes error-prone pointer math. The change is mechanical and low-risk, touching only the worktree addition logic in `git worktree add`. René is a frequent contributor known for clean, incremental refactorings, and this patch fits that pattern.
