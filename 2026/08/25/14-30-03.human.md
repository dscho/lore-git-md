This is the first patch in Patrick Steinhardt’s 10-part refactoring series to make ODB fsck checks pluggable. It targets `builtin/fsck.c` and replaces 16 lines of open-coded loose-object verification with a single call to the existing helper `fsck_obj_buffer()`. The change is purely mechanical: the new call site does exactly what the removed code did—parse the object buffer, mark the object, and run fsck—so there is no behavior change.

The patch is small and self-contained, touching only one file. It serves as a preparatory step for later patches in the series that will move fsck logic into the individual ODB backends. The commit message is clear and the diff is minimal, making it easy to verify correctness. No new symbols are introduced here; the patch simply reuses the existing `fsck_obj_buffer()` function.
