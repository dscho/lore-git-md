The patch deletes redundant code without altering behavior, making the codebase slightly smaller and more consistent. No new symbols are introduced; the helper was already present in the codebase.

This patch is a clear, low-risk refactoring that aligns with the series’ goal of centralizing fsck logic. It touches only one file and has no test or documentation impact.
