Core problem or goal
Refactor `worktree_basename()` in `builtin/worktree.c` to return a dynamically allocated string copy of the basename, eliminating manual pointer arithmetic for callers. The function is renamed to `worktree_basename_dup()` to indicate the caller must free the result.

Current status
Under review. This is the fourth patch in a four-patch series; the prior three patches in the series have not been summarized in this thread yet.

Key technical details
- File: `builtin/worktree.c`
- Function renamed: `worktree_basename()` -> `worktree_basename_dup()`
- New behavior: returns `xstrdup(basename(path))` instead of `path + offset`
- Callers updated: all existing call sites now use the new function and free the result
- Subsystem: worktree addition logic (`git worktree add`)
- No on-disk format or CLI changes; purely internal refactoring
