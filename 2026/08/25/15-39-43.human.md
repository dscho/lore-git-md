This is the first patch in brian m. carlson’s RFC series proposing a Git 3.0 breaking change to restrict hex object IDs to lowercase only. The patch introduces infrastructure—a new `hex_kind` enum and a lowercase-only hex lookup table—without altering runtime behavior yet. Junio C Hamano’s review is a lighthearted surface-level nit: he points out a typo in the comment labeling the ASCII range `68-67` instead of `68-6f`. The correction is trivial and does not affect the patch’s substance, which remains purely preparatory for later enforcement. The thread’s broader discussion about the breaking change’s motivation and design is still open, but this review does not engage with those questions.
