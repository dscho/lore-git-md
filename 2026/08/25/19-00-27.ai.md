This is the second patch in Elijah Newren’s four-patch v2 series fixing a race condition in Git’s geometric repacking mechanism. It plugs a memory leak in `git mktree --batch` that was exposed by the new test cases added in patch 1/4.

The leak occurs because `git mktree --batch` reuses its entry buffer across trees but never frees the `treeent` structures from the previous tree. Each tree’s entries overwrite the previous ones, leaving the old allocations stranded. The fix is simple: free each entry when resetting the buffer and free the buffer itself before returning. The patch touches only `builtin/mktree.c`, adding three lines to free the leaked memory.

This is a targeted, low-risk bugfix with no behavior change. The leak is small (one allocation per tree entry) but real, and fixing it is necessary for the test suite’s reliability. The patch is uncontroversial and ready for merging.
