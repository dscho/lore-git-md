This is the cover letter for a 10-patch series from Patrick Steinhardt that makes object database (ODB) consistency checks pluggable. The series is part of the ongoing ODB abstraction effort, which aims to restructure Git’s object storage layer to support alternative backends.

The goal here is to move the logic for verifying loose objects, packfiles, reverse indexes, bitmaps, and multi-pack indexes out of `builtin/fsck.c` and into the respective ODB source files (loose, packed, etc.). This refactoring allows each backend to implement its own consistency checks, which is a prerequisite for pluggable ODB backends. The series also cleans up some global state in `fsck` and improves modularity by making the checks self-contained within their subsystems.

The patches touch `builtin/fsck.c` heavily (reducing its size by over 250 lines), introduce new infrastructure in `odb.h` and `odb.c`, and add verification logic to `odb/source-loose.c` and `odb/source-packed.c`. The changes are tested with updates to existing fsck-related test scripts (`t1450-fsck.sh`, `t5319-multi-pack-index.sh`, etc.).

This looks like a well-structured, incremental step toward pluggable ODBs. The commit messages are clear, the refactoring is focused, and the tests cover the moved functionality. If you care about the ODB abstraction work or `git fsck` internals, this series is worth following.
