This is the first patch in a two-patch series that refactors `builtin/branch.c` to prepare for a behavioral change in `` `git branch -d` ``. The goal of the series is to prevent accidental deletion of local branches that serve as upstream dependencies for other branches.

This patch moves two helper functions—`collect_stacked_branch_base` and `protect_stacked_branch_bases`—earlier in the file so that `delete_branches()` can use them without requiring forward declarations. The change is purely mechanical: the functions are relocated verbatim, with no logic or signature changes. The patch touches only `builtin/branch.c` and does not alter behavior or introduce new functionality.

The refactoring is clean and well-motivated, setting the stage for the second patch, which will use these helpers to implement the new protection logic. The commit message is concise and accurately describes the purpose. This is a straightforward, uncontroversial preparation step that should not raise objections.
