This is patch 4/10 in Patrick Steinhardt’s series making ODB fsck checks pluggable. It fixes a long-standing discrepancy between the documented and actual behavior of the `--full` flag: the man page says `--full` controls whether alternates are checked, but the code only used it to decide whether to verify packfiles. The patch makes the code honor the flag for loose objects as well—when `--no-full` is given, only the local object source is checked, matching the documentation. The change is minimal (three lines in `builtin/fsck.c`, five in `t/t1450-fsck.sh`) and adds a regression test that verifies the new behavior. No new flags or user-facing changes are introduced; this is purely a bugfix that aligns the code with its own documentation.
