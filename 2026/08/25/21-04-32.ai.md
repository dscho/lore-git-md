This is the first patch in the v8 series improving error messages for ambiguous remote branch names in `git checkout` and `git switch`. It extracts the advice message logic into a new shared helper function, `advise_disambiguating_remotes()`, to avoid code duplication and prepare for reuse in later patches (notably for `git worktree add`).

The patch moves the advice text from `parse_remote_branch()` into the new helper, which takes the command type (`CHECKOUT_CHECKOUT` or `CHECKOUT_SWITCH`) and emits a tailored message suggesting `--track` or setting `checkout.defaultRemote`. The advice is still gated behind the existing `advice.checkoutAmbiguousRemoteBranchName` config key (default: true). The `die()` call remains in `parse_remote_branch()`, but the advice is now emitted via the helper.

The change is purely refactoring: behavior is unchanged, but the code is now structured for reuse. The commit message is minimal, but the purpose is clear from the thread context. This patch sets up the infrastructure for the series’ later behavioral improvements. No new tests are added here, as the functionality is unchanged. The patch is well-scoped and uncontroversial.
