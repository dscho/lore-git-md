This is the third patch in Patrick Steinhardt’s 10-patch series making Git’s object-database fsck checks pluggable. It is a refactoring that moves global fsck option variables into the `cmd_fsck()` function, converting them to local variables and relocating the option-parsing array into the function body. The patch touches only `builtin/fsck.c`, removing 23 lines of global declarations and adding 22 lines of local declarations and the option array inside `cmd_fsck()`. No behavior changes are introduced; the goal is to reduce global state and improve code clarity ahead of later patches that will rework option handling for pluggable ODB backends. The change is mechanical and well-scoped, reflecting the series’ overall focus on preparatory refactoring for the ODB abstraction effort.
