This thread began as a proposal for a new `git ident` command to unify Git’s identity and signing configuration, but has now converged on a cleaner design: extending the existing `git var` plumbing command. Andrew Pleeter has posted a patch series that implements the consensus reached between Junio Hamano and Jeff King (Peff), adding broken-down identity components (author/committer names, emails, dates), commit signing key resolution, and NUL-terminated output to `git var`. The patch allows querying multiple variables in a single invocation, making it both script-friendly and backward-compatible with existing usage.

The implementation touches `builtin/var.c`, updates the man page, and includes thorough test coverage for edge cases like signing key resolution and environment overrides. All prior feedback—machine-readable output, additive flags, X.509 support, and avoiding a new command—has been addressed. Junio and Peff have explicitly endorsed this approach, so the design is settled; the remaining work is routine review of the code changes. The patch is ready for integration and should land in `next` once any minor adjustments are made. No open questions remain about the direction, only about the details of the implementation.
