Andrew Pleeter has proposed a new built-in command, `git whoami`, which consolidates Git’s identity and signing configuration into a single user-friendly command. The patch, currently at version 1, introduces a command that displays the author/committer names and emails, GPG/SSH signing keys, and `commit.gpgsign` status, with flags to query specific fields like `--author` or `--signing-key`. It’s designed for both interactive use and scripting, though brian m. carlson’s review raises concerns about its scripting utility, suggesting the addition of machine-readable (`key=value`) and NUL-terminated (`-z`) output formats.

The review also highlights technical gaps: the patch uses the deprecated `the_repository` global, doesn’t handle X.509 signing keys, and lacks a clear rationale for why this functionality shouldn’t live in `git var` or another existing command. While brian doesn’t oppose the feature outright, they note its limited personal utility, leaving the broader question of its value to the community unresolved. The author will need to address these points—particularly the `the_repository` removal and output format improvements—before the patch can progress. No other reviews have been posted yet, so the discussion remains open.
