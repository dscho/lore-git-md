This is Junio’s "What’s cooking" report for August 2026, summarizing the current state of integration branches and in-flight topics. The report covers 424 commits that have graduated to `master` since Git 2.55, 58 cooking in `next`, and 266 in `seen`. Below are the highlights of new, graduated, stalled, and active topics that may interest a busy reader.

Several small but important fixes are ready to graduate. **cc/git-shallow-file-wo-value** plugs a segfault when `--shallow-file` is given without a value. **js/sequencer-release-odb-before-commit** releases the object database before spawning `git commit` in the sequencer, preventing open file handles from blocking auto-maintenance on Windows. **en/sequencer-lose-pretty-given** removes an unused variable in the sequencer. **js/packfile-fast-append** fixes a performance regression when adding many new packfiles, avoiding a quadratic complexity issue. All four look like straightforward, well-motivated fixes and are marked for `next`.

A larger effort, **jt/receive-pack-pluggable-writes**, refactors `git receive-pack` to use a new ODB transaction interface for writing incoming packfiles, making it backend-agnostic. The series is nine patches long and is waiting for a response from reviewers. If you care about pluggable object storage, this is worth following.

On the usability front, **jc/complete-checkout** teaches command-line completion for `git checkout` to complete untracked paths as a last resort. The series is small (five patches) but has already seen a fixup and is awaiting a reroll. **hn/send-email-missing-subject-error** improves the error message when a message file is missing a `Subject:` header, a small but user-facing improvement.

Two performance-related topics are cooking. **ps/odb-eagerly-load-alternates** simplifies the object database layer by eagerly loading alternate object directories at startup, eliminating scattered lazy-loading calls. **ps/odb-streams** consolidates the `odb_read_stream` and `odb_write_stream` structures into a single `odb_stream` structure, unifying the streaming API. Both are part of Patrick Steinhardt’s ongoing ODB abstraction work and are marked for review.

A few topics are stalled or controversial. **ss/repack-drop-filtered** adds `--drop-filtered` to `git repack` to delete local promisor blobs exceeding a size limit in partial clones. The series is seven patches long and has seen review comments asking for clarification and guards against unsafe usage. **hn/checkout-track-fetch** extends `git checkout --track` with a "fetch" mode to refresh the start-point branch, but Junio has signaled he will discard it unless there is renewed interest.

The report also lists several graduated topics that have already reached `master`. **ja/doc-synopsis-style-yet-more** continues Jean-Noël Avila’s documentation synopsis-style conversion, this time for `git format-patch`, `git imap-send`, `git send-email`, and `git request-pull`. **jc/add-resolved** introduces `git add --resolved` to stage conflict-resolved paths while leaving unrelated local changes unstaged. **tn/packfile-uri-concurrency** makes concurrent packfile URI downloads safer by avoiding concurrent appends to the staging file.

In summary, this report shows a mix of small fixes, usability improvements, and larger refactoring efforts. The ODB abstraction work and pluggable writes in `receive-pack` are the most significant ongoing efforts, while the stalled `--drop-filtered` and `--checkout-track-fetch` topics may need renewed interest to proceed. The graduated topics are mostly documentation and small usability wins.
