This is the second patch in Kristoffer Haugsbakk’s four-patch series extending `git format-rev` with `--abbrev`, `--color`, and `--date` formatting options. It is a pure refactoring patch that groups the command’s option variables into a new `struct format_rev_data` and inlines the existing `format_nul_data` struct into it. The patch also renames the `stdin_mode_arg` variable to `stdin_mode` (previously shadowed by an enum) and updates all references to use the new struct fields.

The change is mechanical and confined to `builtin/name-rev.c`; it introduces no new behavior or user-visible features. The commit message explains the motivation clearly: reducing the number of local variables in preparation for the three new options that will be added in patch 4/4. The patch is uncontroversial and appears well-scoped, touching only the option-handling logic and leaving the rest of the command’s flow intact. No test failures or edge cases are expected, and the patch is likely to be accepted as-is.
