This is a documentation refactoring patch, part of Kristoffer Haugsbakk’s four-patch series adding `--abbrev`, `--color`, and `--date` options to `git format-rev`. This is patch 3/4, and it extracts the `--date` option alternatives into a new shared file (`rev-list-option-date-alternatives.adoc`) so that the same text can be included in both `git-rev-list` and the upcoming `git format-rev` documentation.

The change is purely mechanical: 55 lines of `--date` documentation are moved verbatim from `rev-list-options.adoc` into the new file, and the original file is replaced with an `include::` directive. The commit message explains that the initial paragraph of the `--date` section is not being factored out because it mentions `git log` and related commands, which would not fit `git format-rev`; a dedicated paragraph will be written for the new command instead.

This patch is uncontroversial and looks like a clean way to avoid duplication. It touches only documentation files and has no functional impact. The next patch in the series will use this new shared file to document the `--date` option in `git format-rev`.
