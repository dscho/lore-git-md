This is the first patch in a three-patch bugfix series targeting test infrastructure. It fixes a race condition in `t/lib-httpd/apply-one-time-script.sh`, a CGI helper used in Git's HTTP tests. The helper is designed to run a one-time script that modifies the response from `git-http-backend`, then delete the script marker file so subsequent requests return unmodified responses. However, under concurrent requests (e.g., a partial fetch lazily retrieving a promisor object while the first response is still in flight), the non-atomic check-and-delete sequence (`test -f` followed by `rm`) can cause both requests to attempt running the script, with the second failing when the first deletes the file, resulting in an HTTP 500 error.

The patch replaces the non-atomic sequence with an atomic `rm` (without `-f`) that only succeeds for the request that removes the marker first. This ensures exactly one request serves the modified response, while others serve the unmodified response, and no request emits an empty body (which would trigger HTTP 500). The change also adds a comment explaining why `stderr` is redirected to `/dev/null`: to suppress expected errors when the script is removed by a concurrent request. Per-request scratch files (using `$$` suffixes) prevent concurrent runs from overwriting each other's output.

The patch includes a new test, `t5567-one-time-script.sh`, which exercises the helper directly without a web server, using FIFOs to force the race deterministically. The test confirms neither request emits an empty body and each behaves as expected: the modifying request rewrites its response, while the passthrough request remains unchanged. The commit message is thorough, explaining the problem, the atomic idiom, and the reasoning behind the changes.

This patch is well-crafted, addresses a real and observed flake in `t5616.47` on macOS CI runners, and is part of a series that has already been reviewed and marked as ready for integration by Junio C Hamano. The changes are self-contained to the test infrastructure and unlikely to be controversial.
