This is the second patch in Taylor Blau’s three-part series fixing MIDX incremental writes with custom base layers. The email is a reply to Patrick Steinhardt’s substantive review of that patch, clarifying two points.

Taylor confirms that the bug Patrick asked about—where incremental writes with custom bases skip packs from the full MIDX chain—applies only to the `--stdin-packs` code path, not the “normal” (non-`--stdin-packs`) write path. He also pushes back on Patrick’s suggestion to add a test assertion for an object from the *first* MIDX layer when `--base=none` is used. Taylor argues that the existing test is sufficient: because the new layer is written with `--bitmap` and `--base=none`, the bitmap generator’s reachability closure check already guarantees that all objects from earlier layers (including the first) are included. The test’s explicit check for an object from the *second* layer therefore implies the first layer’s objects are present. The series remains under review, with no merge to any integration branch yet.
