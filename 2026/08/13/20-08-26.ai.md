This is the second patch in the v5 series introducing `git repack --drop-filtered` for partial clones. It adds a new helper function, `list_objects_filter__filter_oidset()`, to the list-objects-filter API, enabling callers to apply a filter to an existing oidset without performing an object walk. The helper is specifically designed for the `--drop-filtered` feature, which needs to identify promisor blobs exceeding a size threshold from a pre-collected set of OIDs.

The patch addresses a gap in the existing filter API: `list_objects_filter__filter_object()` is tied to the object-walk path and cannot be used with a static oidset. The new helper reimplements the `blob:limit` size check directly, avoiding lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` when reading object info. A `NEEDSWORK` comment flags the code duplication (the size check logic is copied from `list_objects_filter__filter_object()`) as technical debt for future refactoring. The implementation is minimal and currently supports only `blob:limit` filters, matching the scope of the `--drop-filtered` feature.

Key details include the function signature (`struct repository *r`, `const struct list_objects_filter_options *opts`, `const struct oidset *in`, `struct oidset *omitted`), the use of `OBJECT_INFO_SKIP_FETCH_OBJECT` to prevent lazy fetches, and the silent skipping of unreadable objects. The patch also fixes the blocking type-mismatch bug from v4 by using `size_t` (matching `struct object_info.sizep`) instead of `unsigned long`. Christian Couder’s feedback to make the `opts` parameter `const` is incorporated.

The patch touches `list-objects-filter.c` and `list-objects-filter.h`, adding 45 lines of implementation and 16 lines of header declarations. The helper is called by `enumerate_promisor_blobs()` (introduced in patch 4/6) to produce the `to_drop` oidset for `--drop-filtered`. The test script (`t/t7706-repack-drop-filtered.sh`) indirectly verifies the helper’s behavior by checking that large promisor blobs are correctly identified and dropped. The code duplication is a known limitation, but the patch is technically sound and ready for review.
