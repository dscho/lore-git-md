This is the third patch in Johannes Sixt’s six-part series overhauling gitk’s color-preference dialog. The patch replaces the old, non-clickable color swatches (which were actually labels) with real Tk buttons whose background color can be set directly. The result is that users can now click the colored button itself instead of having to aim for a separate text label. The patch also swaps the grid layout so the label appears to the left of the button, adds a 2-pixel border and 1-pixel vertical padding for better visual definition, and updates the helper procedure to set both the normal and active background colors. Mark Levedahl’s one-line reply simply notes that the new buttons “stand out much better,” confirming the visual improvement without raising any technical concerns. The change is purely cosmetic and confined to the Tcl/Tk UI; it has no effect on core Git functionality or on-disk formats.
