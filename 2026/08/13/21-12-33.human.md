This is a test patch that fills a small gap in Git's test coverage. The author, Nikolaus Schuetz, adds two new tests to `t/t1401-symbolic-ref.sh` to verify the documented exit-code behavior of `git symbolic-ref` when it is asked to read a ref that is not a symbolic reference.

The first test confirms that `git symbolic-ref` exits with status 128 and prints the expected error message ("is not a symbolic ref") when given a non-symbolic ref. The second test checks that the `--quiet` (`-q`) flag suppresses the error message and exits with status 1 instead. Both behaviors are already documented in the manual page, but until now there were no automated tests to ensure they work as promised.

The patch is minimal and self-contained: it touches only the test script, adds no new functionality, and does not change any production code.
