This thread is about a four-patch series from Kristoffer Haugsbakk that adds `--abbrev`, `--color`, and `--date` formatting options to `git format-rev`, bringing it closer to `git log`'s flexibility. The series is now preparing its second version after addressing feedback on the first.

The core work is uncontroversial: the new options reuse existing `git log` logic, and the preparatory patches clean up documentation and refactor option handling. Junio C Hamano reviewed two patches, suggesting minor mechanical improvements—designated initializers in one and defensive code reordering in the other—which the author has accepted. The only open technical point is a trivial fix to ensure assertions in callback functions trigger before dereferencing values, a defensive programming best practice. No objections to the functionality itself have been raised, and the series isn’t yet queued for integration.

Kristoffer has now confirmed he’ll reorder the assertions in both the new `date_cb()` and the existing `format_nul_cb()` callbacks for the next revision. The rest of the series remains unchanged. If no further feedback emerges, this should be ready for Junio to pick up once v2 is posted.
