This thread is about Kristoffer Haugsbakk’s five-patch series adding `--abbrev`, `--color`, and `--date` formatting options to the experimental `git format-rev` command, bringing it closer to `git log`’s flexibility. The series is now at v2, posted on 2026-08-26, and includes all feedback from the first round: Junio C Hamano’s suggestions for defensive code improvements, a memory leak fix in the `--date` callback, and two new refactoring patches to tighten assertions and reuse documentation.

The patches are uncontroversial and queued under `kh/format-rev-more-options`, but they’re not yet in any integration branch. Junio has explicitly said he’s not the best reviewer for this command and has asked for input from others more familiar with `git format-rev`. Ben Knoble acknowledged the series is on his list, but no substantive reviews have landed since v2. The latest email is just a brief thank-you from Kristoffer to Ben for keeping it on the radar—no new feedback or changes. The series is still waiting for deeper technical review.
