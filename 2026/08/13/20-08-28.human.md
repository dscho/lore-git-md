This is the fourth patch in the v5 series introducing `git repack --drop-filtered` for partial clones. It implements the core enumeration logic that identifies which promisor blobs exceed the user-specified size threshold and should be dropped.

The patch adds `enumerate_promisor_blobs()` in `repack-filtered.c`, which walks all promisor objects (using `odb_for_each_object()` with `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`) and collects blobs into an oidset. It then applies the filter (currently only `blob:limit`) to that set using the new `list_objects_filter__filter_oidset()` helper from patch 2, producing the final `to_drop` set. In `--dry-run` mode, the function prints the OIDs of candidate blobs to stdout. The implementation avoids lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` to every object info query, ensuring enumeration never triggers network traffic.

The patch updates `builtin/repack.c` to call `enumerate_promisor_blobs()` when `--drop-filtered` is specified, storing the results in a new `drop_oids` oidset. In `--dry-run` mode, it iterates over the set and prints each OID. The test script (`t/t7706-repack-drop-filtered.sh`) is expanded to cover enumeration, `--dry-run` output, and the critical safety check that locally created blobs are never listed as drop candidates. The tests use helper functions (`promisor_blob`, `pack_as_from_promisor`) to create promisor blobs of controlled sizes and verify that only blobs exceeding the threshold are reported.

This patch is well-scoped and technically sound. The enumeration logic is cleanly separated from the actual removal (handled in patch 5), and the safety invariant—never listing locally created blobs—is enforced at the enumeration stage. The commit message clearly explains why `write_filtered_pack()` cannot be used for partial clones and justifies the direct promisor-object walk. The test coverage is thorough, including edge cases like locally created blobs and `--dry-run` behavior. No new issues are apparent; this patch appears ready for maintainer review.
