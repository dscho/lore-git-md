Core problem or goal
Add systematic test coverage for `git symbolic-ref`'s exit codes and output behavior when querying a non-symbolic ref, both with and without the `--quiet` (`-q`) flag. The patch documents the current behavior—exit code 128 without `--quiet`, exit code 1 with `--quiet`, and empty stdout in both cases—while updating the command's documentation to reflect this reality. The thread has explored whether the exit code discrepancy is intentional or an oversight, with no consensus on a behavioral fix. The current compromise (document the status quo) is now contested by Junio C Hamano, who objects to "casting wrong behavior into stone" in the man page.
