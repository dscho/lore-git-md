Core problem or goal
Add missing test coverage for `git symbolic-ref`'s exit codes and output behavior when querying a non-symbolic ref, both with and without the `--quiet` (`-q`) flag. The behaviors (exit code 128 with error message, exit code 1 with `--quiet`) are documented in the man page but were previously untested. The patch has prompted discussion about whether the differing exit codes are intentional or a design quirk worth revisiting.
