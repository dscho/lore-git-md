Core problem or goal
Add systematic test coverage for `git symbolic-ref`'s exit codes and output behavior when querying a non-symbolic ref, both with and without the `--quiet` (`-q`) flag. The patch documents the current behavior—exit code 128 without `--quiet`, exit code 1 with `--quiet`, and empty stdout in both cases—while updating the command's documentation to reflect this reality. The thread has converged on a practical compromise: preserve the current behavior (documenting it in tests and man page) rather than resolving the design debate about whether the exit code discrepancy is intentional or an oversight.

Current status

The compromise avoids altering behavior or overspecifying tests, focusing instead on documentation and coverage.
