This is the first patch in Kristoffer Haugsbakk's three-part series introducing `--[no-]range-diff-notes` options to `git format-patch`. It is a preparatory refactoring that simplifies the `get_notes_args` function by reducing its parameters.

The patch removes the redundant first parameter (`struct strvec *arg`) from `get_notes_args` and instead directly uses the `rdiff_log_arg` member of `struct rev_info`, which was added in a previous commit (85bd88a7, 2025-09-25). The change is mechanical: all calls to `strvec_push` now target `rev->rdiff_log_arg` instead of the passed-in `arg`. The patch also reformats a long `for_each_string_list` line for readability.

This is a clean, focused refactoring that eliminates a minor redundancy in the codebase. The change is compile-tested but not otherwise validated in the commit message; its correctness will be verified by the test suite in the third patch. The patch touches only `builtin/log.c` and is part of a well-structured series that separates preparatory work from feature implementation. No review feedback has been posted yet.
