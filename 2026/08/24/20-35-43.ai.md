This is the second patch in Kristoffer Haugsbakk's three-part series adding `--[no-]range-diff-notes` options to `git format-patch`. The patch renames the `rdiff_log_arg` member of `struct rev_info` to `rdiff_notes_arg` to better reflect its narrowed role: after the next patch, this `strvec` will carry only notes-related arguments for the range-diff section, not arbitrary log options.

The change is mechanical: eight lines of code in three files (`builtin/log.c`, `log-tree.c`, and `revision.h`) are updated to use the new name. The commit message explains the rationale clearly—`rdiff_log_arg` was introduced in a prior commit (85bd88a7, 2025-09-25) when the field could still hold multiple log options, but the upcoming feature will restrict it to notes arguments only, making the old name misleading.

No functional behavior changes; this is pure refactoring. The patch is compile-tested and ready for review. It sets the stage for the third patch, which implements the actual user-facing options.
