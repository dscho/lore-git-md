This is Junio C Hamano, the Git maintainer, replying to the third patch in Kristoffer Haugsbakk’s three-patch series that introduces `--[no-]range-diff-notes` options to `git format-patch`. The series aims to let users control whether Git notes appear in the range-diff section independently of the patch output.

Junio’s reply focuses on the documentation for the new options, specifically the example showing how to toggle the override off after it has been activated. He finds the current explanation overly complex and raises a question about the expected behavior when combining `--no-notes` with `--range-diff-notes`. His concern is whether the range-diff would still show notes in this case, given that `--range-diff-notes` is documented to fall back to the default (inheriting the notes used for the patches).

This is a substantive review comment targeting the clarity and correctness of the user interface. Junio’s question suggests he expects the options to behave orthogonally—`--no-notes` should suppress notes in the patches, while `--range-diff-notes` should independently control notes in the range-diff. The current documentation does not make this behavior explicit, which could lead to user confusion. The author will likely need to clarify the interaction between these options in the next revision.
