This is the second patch in Kristoffer Haugsbakk’s three-part series adding `--[no-]range-diff-notes` options to `git format-patch`. It is a pure refactoring: the `rdiff_log_arg` member of `struct rev_info` is renamed to `rdiff_notes_arg` to reflect its narrowed role. The commit message explains that the old name was overly generic—it could have carried any log-related argument—but the upcoming third patch will restrict it to notes options only, so the new name makes the intent clearer. The change touches three files (`builtin/log.c`, `log-tree.c`, and `revision.h`), replacing every occurrence of the old name with the new one. The patch is compile-tested and mechanically straightforward, with no behavior change. It is a sensible cleanup that prepares the code for the feature addition in patch 3.
