This is a **substantive review** from Jeff King (Peff) on the second patch of Elijah Newren’s two-patch bugfix series for a race condition in Git’s geometric repacking mechanism. The series addresses a scenario where a multi-pack-index (MIDX) references a packfile that has been removed by a concurrent repack, causing processes like `git replay` to crash or report missing objects.

Peff’s feedback challenges the architectural choice in patch 2/2, which adds recovery logic to the packed-object backend (`find_pack_entry()`) to handle MIDX-packfile mismatches. He suggests an alternative: instead of making the backend more resilient, callers should avoid using `OBJECT_INFO_QUICK` if they cannot tolerate false negatives. His critique hinges on three points:

First, he notes that `find_pack_entry()` already distinguishes between objects *not present* in the MIDX (case 1) and objects *present but unavailable* (case 2). The current patch treats both cases the same, but Peff proposes refining the return value of `fill_midx_entry()` to a tri-state, allowing the recovery logic to target only case 2 (objects present but unavailable). This would avoid unnecessary work for objects genuinely missing from the MIDX.

Second, he questions whether the recovery logic is justified at all, given that Git already handles a similar race condition for regular `.idx` files (where the `.pack` file disappears but the `.idx` remains mmapped). The existing `is_pack_valid()` mechanism ensures graceful failure in those cases, and Peff implies the MIDX scenario might not warrant special treatment.

Finally, Peff’s feedback has broader implications for Elijah’s planned follow-up patches, which aim to address additional race conditions. If the project adopts Peff’s preference for caller-level fixes, those follow-ups may become less critical—or require significant redesign.

The review is technical and constructive, but it introduces a design debate that could delay the series. The outcome hinges on whether the project prioritizes backend resilience (Elijah’s approach) or caller responsibility (Peff’s suggestion). No other reviewers have weighed in on this specific critique yet, and Elijah has not yet responded. The series remains a high-priority candidate for merging, but the discussion is now focused on architectural trade-offs rather than correctness.
