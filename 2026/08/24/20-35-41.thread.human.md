This thread began with Kristoffer Haugsbakk’s patch series proposing `--[no-]range-diff-notes` options for `git format-patch`, aiming to let users control whether Git notes appear in the range-diff section independently of the patches themselves. The series touched several core files and introduced new CLI options and struct members, but ran into a fundamental design problem: the intuitive use case (`--no-notes --range-diff-notes` suppressing notes in patches while keeping them in the range-diff) wasn’t supported by the implementation. Junio C Hamano, the maintainer, flagged this as a usability flaw so severe that the feature’s semantics might be unacceptable in their current form.

After Junio’s critique, Kristoffer acknowledged the issue and chose to abandon the feature entirely rather than propose a redesign. The thread is now closed, leaving the original goal—independent control over notes in range-diffs—unmet. If someone revives this effort in the future, they’ll need to address the usability concern, likely by maintaining separate notes lists for patches and range-diffs. For now, the series is dead, and the code changes it introduced won’t be merged.
