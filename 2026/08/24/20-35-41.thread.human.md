This thread introduces a new feature for `git format-patch`: the `--[no-]range-diff-notes` options, allowing users to control whether notes appear in the range-diff section independently of the patch notes. Kristoffer Haugsbakk sent a three-patch series, with the first two patches refactoring existing code (simplifying parameter handling and renaming a struct member for clarity) and the third implementing the feature itself.

The implementation touches core `format-patch` internals (`builtin/log.c`, `log-tree.c`, `revision.c/h`) and includes thorough test coverage in `t/t3206-range-diff.sh`. The author notes this was motivated by personal workflow needs and has been used privately, though the current implementation is new and untested at scale. All tests pass in CI, though the author expresses some uncertainty about the CI setup. The series is currently under initial review, with no feedback yet from other contributors.
