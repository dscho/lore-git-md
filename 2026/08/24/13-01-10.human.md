This is the latest "What's cooking in git.git" report from Junio Hamano, summarizing the state of the Git project's integration branches as of August 2026. It provides a high-level overview of what’s currently under review, cooking in `next`, or stalled, giving a snapshot of the project’s development pipeline.

The report lists 47 topics, with 128 non-merge commits in `next` and 251 in `seen`. Since Git 2.55, 462 non-merge commits have graduated to `master`. The topics span performance improvements, bugfixes, new features, refactoring, and documentation updates, with a strong focus on the object database (ODB) abstraction effort led by Patrick Steinhardt.

Key highlights include:
- **Performance improvements**: Parallel packfile URI fetches (`ps/fetch-packfile-uris-parallel`), geometric repacking adjustments (`ps/odb-geometric-repack-loose-threshold`), and Bloom filter optimizations for `git last-modified` (`tc/last-modified-bloom`).
- **ODB abstraction**: Several topics (`ps/odb-pluggable-pack-generation`, `ps/odb-streams`, `ps/odb-eagerly-load-alternates`) continue the effort to make Git’s object storage pluggable, enabling alternative backends and reducing reliance on `the_repository`.
- **Bugfixes**: Fixes for segfaults (`cc/git-shallow-file-wo-value`), use-after-free (`sk/object-name-use-after-free`), and race conditions in HTTP tests (`mm/lib-httpd-cgi-safe`).
- **New features**: A `report` hook for `git receive-pack` (`kn/receive-report-hook`), `--drop-filtered` for `git repack` (`ss/repack-drop-filtered`), and `--linearize` for `git replay` (`tc/replay-linearize`).
- **Documentation**: The `gitdatamodel(7)` tutorial is now linked from key documentation pages (`kh/doc-datamodel`), and man page formatting improvements continue (`kh/format-rev-doc-synopsis`).
- **Platform compatibility**: Windows build updates (`js/mingw-build-updates`) and a runtime knob for nanosecond stat precision (`dk/use-nsec-runtime`).
- **Stalled topics**: Some efforts, like `hs/rebase-continue-edit` and `tb/pack-with-duplicates`, have been stalled for weeks, awaiting responses or rerolls.

The report also notes a few contentious or complex topics, such as `mm/diff-process-hunks` (external hunk providers) and `hn/history-squash` (squashing ranges in `git history`), which are still under discussion. The `the_repository` removal effort and ODB abstraction work remain active, with multiple topics in flight.

For a busy reader, this report is a quick way to gauge what’s moving toward the next release, what’s stuck, and where the project’s focus lies. The ODB work and performance optimizations are particularly notable, as they represent foundational changes with long-term implications.
