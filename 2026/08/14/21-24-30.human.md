This is a GSoC microproject patch targeting the submodule subsystem. The author, a first-time contributor, resubmits a revised version (v2) of their patch to address feedback on both technical and mechanical issues.

Previously, such entries were silently ignored; now, Git emits a warning using the standard `config_error_nonbool()` helper. This aligns with Git’s existing error-handling patterns for non-boolean configuration keys and resolves a documented NEEDSWORK comment in `submodule.c`. The change is small and focused, touching only `submodule.c` and adding a test case in `t/t7400-submodule-basic.sh`.

The v2 revision incorporates maintainer feedback by replacing a custom warning message with the project-standard `config_error_nonbool()` helper. The test coverage is minimal but sufficient, verifying that the warning is emitted when a valueless `submodule.active` entry is encountered.
