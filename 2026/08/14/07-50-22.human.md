This is a minor follow-up in the thread adding Bash completion for `git history`. Kristoffer Haugsbakk replies to Vincent Mailhol’s acknowledgment of the cover letter formatting glitch (where a line starting with `#3` was misinterpreted as a comment by `b4`).

Kristoffer suggests a workaround for future patch descriptions: setting `core.commentString` to a string that the author would never type, which provides more flexibility than the single-character `core.commentChar`. He then explicitly states that no reroll (v4) is needed for the current series, as the issue is purely editorial and does not affect the patches themselves. The technical content of the v3 series remains ready for integration.
