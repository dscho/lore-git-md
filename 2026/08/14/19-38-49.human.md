This is a refactoring patch that cleans up the `chdir-notify` API by removing an unused parameter. The `name` field in `struct chdir_notify_entry` and the corresponding parameter in `chdir_notify_register()` and `chdir_notify_unregister()` were never meaningfully used—it was always passed as `NULL` and ignored in all callbacks. Colin Hinton’s patch removes the parameter entirely, simplifying the API and reducing the diff across ten call sites.

The change is mechanical and well-scoped: every caller already passes `NULL`, so the patch just drops the argument and updates the function signatures. The commit message is concise and accurately describes the motivation. No behavior change is claimed or implied, and the patch looks like a straightforward cleanup rather than a prelude to further work.
