Core problem or goal
Junio’s periodic "What's cooking" report summarizes the state of all in-flight topics across the project’s integration branches (`seen`, `next`, `master`), highlighting new additions, stalled efforts, controversial or complex work, and topics ready for graduation. The report serves as the authoritative snapshot of what is under review, what is cooking, and what is blocked.

Current status

  - `master`: 424 commits since Git 2.55 (graduated topics).
  - `next`: 82 commits (topics under integration testing).
  - `seen`: 286 commits (all in-flight topics, including half-baked ones).
- **New topics** (since last report):
  - `kh/format-rev-more-options` (extends `git format-rev` with `--abbrev`, `--color`, `--date`).
  - `ps/odb-pluggable-pack-generation` (makes packfile generation pluggable via ODB callbacks).
  - `ty/repository-fetch-if-missing` (moves `fetch_if_missing` into `struct repository` for per-repo control).
  - `ps/odb-eagerly-load-alternates` (eagerly initializes alternates at ODB startup).
  - `ss/repack-drop-filtered` (adds `--drop-filtered` to `git repack` to delete local promisor blobs exceeding `blob:limit=`).
  - `dk/use-nsec-runtime` (converts `USE_NSEC` to runtime `core.useNanosec` config).
  - `mm/diff-process-hunks` (introduces `diff.<driver>.process` for external hunk providers).
  - `hn/history-squash` (adds `git history squash` to fold a commit range into one).

  - `tb/pack-with-duplicates` and `tc/replay-linearize` (unresolved edge cases).
