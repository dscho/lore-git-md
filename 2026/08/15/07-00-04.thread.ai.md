Core problem or goal
Fix a crash in Git when the `submodule.active` configuration key is set without a value (e.g., `[submodule] active` with no pathspec). The current code uses `repo_config_get_string_multi()`, which fails hard on valueless keys; the patch replaces it with `repo_config_get_value_multi()` and emits a warning via `config_error_nonbool()` instead of aborting.
