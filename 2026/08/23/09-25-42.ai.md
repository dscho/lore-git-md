This is a documentation patch for `gitk`, the Git repository browser GUI.

Johannes Sixt (Hannes) updates `gitk`'s `README.md` to explicitly discourage contributions generated by AI. The change adds a short paragraph under the patch submission section stating that AI-originated work will not be accepted, citing the Git project's strict AI guidelines as the reason. The patch is motivated by a recent discussion with brian m. carlson, who argued that AI-generated code cannot be confidently tracked for provenance, making it incompatible with Git's Developer Certificate of Origin (DCO) requirements.

The patch is minimal and targeted: it touches only the `README.md` file, adding four lines and removing three (the redundant "Email Patches" subheading). The rationale is clear and directly references upstream Git's policy, which `gitk` inherits as a downstream project. No code or build system changes are involved.

This is not part of a larger series; it stands alone as a policy clarification. The commit message is concise but sufficient, linking to the prior discussion for context. The patch itself is uncontroversial in substance, as it merely documents an existing policy constraint rather than introducing new technical behavior. The only open question is whether the wording is appropriately strong ("discourage" vs. "prohibit"), but that is a matter for discussion rather than a technical concern.
