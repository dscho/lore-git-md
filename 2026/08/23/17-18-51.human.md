This is the seventh patch in Michael Montalbo’s 14-patch RFC series introducing `git organize`, a tool for restructuring Git’s source tree. This patch demonstrates the tool’s practical application by moving all 23 C sources and 26 headers related to the object database (ODB) subsystem into a new `odb/` directory.

The patch is purely mechanical: it renames files (e.g., `alloc.c` → `odb/alloc.c`) and updates every reference to their old paths—`#include` directives across the codebase, build system entries in `Makefile` and `meson.build`, and even documentation examples. The diffstat shows 347 files changed, but the net line count is zero because the changes are almost entirely path updates. The patch leaves the tree buildable, fulfilling the series’ promise of atomic, reversible reorganizations.

This is the first of eight subsystem carve-outs proposed in the series (others include `refs/`, `pack/`, etc.). The ODB move is a natural candidate for early review because the ODB is a well-defined, self-contained component with minimal external entanglement. The patch’s completeness—handling build systems, documentation, and even tutorial examples—makes it a strong proof-of-concept for the `git organize` tool’s ability to automate complex refactorings. Reviewers can focus on whether the ODB’s boundaries are correctly identified and whether the reference updates are exhaustive.
