This is a brief but substantive review comment in the ongoing `git repo structure` Unicode box-drawing thread. Tuomas Ahola points out that **mutt**, one of the applications cited by Oswald Buddenhagen as a successful user of box-drawing characters, actually falls back to **ACS (Alternative Character Set)** when UTF-8 is unavailable. This detail complicates Buddenhagen’s argument that mutt’s widespread use demonstrates terminal compatibility with Unicode box-drawing characters: mutt’s resilience may stem from its fallback mechanism rather than universal UTF-8 support. Ahola’s observation is narrowly scoped but sharp, offering a concrete technical counterpoint to the earlier claim and nudging the discussion toward implementation-level considerations (e.g., whether Git should adopt a similar fallback strategy). The comment is unlikely to derail the series, but it adds nuance to the terminal-compatibility debate and may inform how the eventual opt-out configuration (now required by the maintainer) is designed.
