This is the eighth patch in Michael Montalbo’s 14-patch RFC series introducing `git organize`, a tool for restructuring Git’s source tree. This patch mechanically moves all refs-related C sources and headers from the root directory into a new `refs/` subdirectory, then updates every `#include` directive, Makefile entry, and Meson build file to match the new paths.

The patch touches 138 files, but the net churn is zero: 8 C files and 8 headers are renamed (not modified in content), and 347 `#include` lines, Makefile entries, and Meson build rules are adjusted to point to the new `refs/` prefix. The `.gitorganize` configuration file is also updated to reflect the new paths for the refs component. The tree remains buildable after the move, and the patch relies on the existing test suite to validate functionality. This is a pure refactoring step within the broader `git organize` effort, demonstrating the tool’s ability to carve out a coherent subsystem without breaking the build.
