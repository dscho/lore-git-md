This is the thirteenth patch in Michael Montalbo’s 14-patch RFC series introducing `git organize`, a tool for restructuring Git’s source tree. This patch gathers the nine C sources and nine headers that form the “setup” subsystem (files like `config.c`, `environment.c`, `repository.c`, `setup.c`, etc.) into a new `setup/` directory, then updates every `#include` line, Makefile entry, and documentation example that referenced the old paths.

The patch is purely mechanical: 798 lines added, 798 lines removed, and every rename shows 98–100 % similarity. The `.gitorganize` file is updated to reflect the new paths, and the build remains green. This is the seventh of the eight subsystem carve-outs demonstrated in the series; only the “transport” move remains.
