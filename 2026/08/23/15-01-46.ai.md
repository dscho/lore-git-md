This is a maintainer reply in the ongoing discussion about Unicode box-drawing support for `git repo structure`. Junio C Hamano acknowledges Oswald Buddenhagen’s suggestion to make the feature opt-out via a configuration option, clarifying that his earlier objection was not about the feature itself but about the implementation’s lack of flexibility. The patch currently enables Unicode rendering based solely on locale detection (`is_utf8_locale()`), which forces users to abandon UTF-8 entirely to disable the box-drawing characters. Junio’s response signals openness to the feature if it includes a configuration knob (e.g., `repo.structure.unicode`) to override the locale-based default, addressing the cross-terminal reliability concerns he raised earlier. No new technical objections are introduced; the focus shifts to implementation details rather than the feature’s merit. The thread remains unresolved but now has a clear path forward: the author may revise the series to add an opt-out option, which could satisfy the maintainer’s requirement for user control.
