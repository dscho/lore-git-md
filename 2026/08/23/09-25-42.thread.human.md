This thread is a straightforward documentation update for `gitk`, the Git repository browser GUI. Johannes Sixt (Hannes), the current maintainer of `gitk`, has submitted a patch to update the project's `README.md` to explicitly discourage AI-generated contributions. The change adds a brief policy statement under the patch submission section, clarifying that AI-originated work will not be accepted, citing Git's strict AI guidelines and the incompatibility of AI-generated code with the Developer Certificate of Origin (DCO) requirements.

The patch itself is minimal, touching only the `README.md` file to add four lines of policy text while removing a redundant subheading. The motivation stems from a recent discussion with brian m. carlson, who argued that AI-generated contributions cannot be reliably tracked for provenance. The update aligns `gitk`'s policy with upstream Git's stance, though the wording ("discourage" rather than "prohibit") may still be open for minor refinement. No technical changes or build system modifications are involved, and the patch stands alone rather than being part of a larger series. So far, the patch appears uncontroversial in substance, as it simply documents an existing policy rather than introducing new behavior.
