This is a documentation patch for `gitk`, the Git repository browser GUI. Johannes Sixt (Hannes), the current maintainer of `gitk`, proposes adding a short paragraph to the project's `README.md` file explicitly discouraging contributions that originate from AI-generated code.

The change is motivated by Git's own [AI contribution guidelines](https://git-scm.com/docs/SubmittingPatches#ai), which are strict about requiring traceable provenance for all code. Since `gitk` is downstreamed into the main Git project, Hannes wants to align its contribution policy with Git's. The patch itself is minimal: it removes a redundant "Email Patches" subheading and adds four lines of text asking contributors not to submit AI-generated work.

The commit message references a recent discussion with brian m. carlson, who apparently advised that AI-generated code should not be accepted for `gitk` even if the submitter understands it. Hannes is seeking feedback on whether this policy statement is appropriate or overly broad. The patch is straightforward and unlikely to be controversial, but the thread may attract opinions on how strictly AI contributions should be policed in Git-adjacent projects.
