This is the first patch in the v5 series converting `USE_NSEC` to runtime configuration. It is a build-system fix targeting the Meson build.

The patch exposes a configurable knob (`man_base_url`) for Meson builds, mirroring the existing `MAN_BASE_URL` option in the Makefile. Currently, Meson hard-codes the equivalent of `$prefix/$mandir` for relative links in manuals, which is incorrect for most distro builds and lacks a trailing slash, producing broken links like `/usr/share/manuser-manual.html`. The patch changes the default to `file://$(htmldir)/` (with a trailing slash) to match the Makefile’s behavior and adds a new `man_base_url` option to `meson_options.txt`, allowing distributions to override the base URL if needed.

The change is small (8 lines added, 1 removed) and uncontroversial. The author notes that an internet search for `MAN_BASE_URL` yielded no hits, suggesting few if any distributions currently use it, but the knob is provided for consistency and future-proofing. The patch is ready to advance independently and has already been reviewed and confirmed correct by Patrick Steinhardt. No further discussion or objections are expected.
