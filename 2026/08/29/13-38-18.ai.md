This is the first patch in the v5 series `dk/use-nsec-runtime`, a build system change targeting the Meson build.

The patch exposes a configurable knob (`man_base_url`) for Meson builds, mirroring the existing `MAN_BASE_URL` option in the Makefile. The default value is changed to `file://$(htmldir)/` (with a trailing slash) to match the Makefile’s behavior, fixing broken relative links in generated man pages. For example, the current Meson build produces broken links like `/usr/share/manuser-manual.html`, whereas the new default produces functional links like `file:///usr/share/doc/git/html/user-manual.html`.

The change is uncontroversial and self-contained, touching only `Documentation/meson.build` and `meson_options.txt`. The author notes that an internet search for `MAN_BASE_URL` yielded no meaningful results, suggesting few (if any) distributions currently use this knob, but the option is provided for consistency and future-proofing. Patrick Steinhardt’s earlier review confirmed the fix aligns with the Makefile’s behavior, and the patch is ready to advance independently of the rest of the series.

No performance impact or behavioral changes are introduced; this is purely a build system improvement. The patch is based on master and conflicts with no other in-flight topics. The only loose end is whether any distributions actually use `MAN_BASE_URL` today, but the author’s audit (limited to Gentoo and a web search) found no evidence of active use, so this is not a blocker.
