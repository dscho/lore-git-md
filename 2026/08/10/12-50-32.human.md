This is the first patch in D. Ben Knoble’s three-patch series converting the build-time `USE_NSEC` macro to a runtime configuration option. The patch itself is a **build-system fix** for Meson, unrelated to the nanosecond-precision work that is the series’ headline goal.

The patch addresses a long-standing inconsistency between Makefile and Meson builds: Makefile-based builds have allowed `MAN_BASE_URL` to be configured since 2009, but Meson hard-coded the equivalent of `$prefix/$mandir`, which is both incorrect for most distro builds (HTML docs are not stored there) and missing a trailing slash, breaking relative links in man pages. The patch changes the Meson default to `file://$(htmldir)/` (matching Make’s behavior) and adds a configurable `man_base_url` option so distributions like Gentoo can override it if needed.

Patrick Steinhardt’s reply is a **surface-level review**: he confirms the patch aligns with the Makefile’s existing behavior and does not raise any technical concerns. The change is small (8 lines), self-contained, and unlikely to be controversial. It is now effectively ready to merge, pending the rest of the series.
