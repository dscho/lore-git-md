This is patch 3/7 of the v4 series introducing `git repack --drop-filtered` for partial clones. It extends `repack_promisor_objects()` to accept an optional `to_drop` oidset parameter; when provided, the function rebuilds the promisor pack while excluding those objects. The change is minimal and backward-compatible: all existing callers pass `NULL`, so their behavior is unchanged. The patch modifies `repack-promisor.c` (core logic), `builtin/repack.c` (call-site update), and `repack.h` (function signature change).

The new `to_drop` parameter is plumbed through to the `write_oid()` callback, which skips objects present in the set. This is the mechanism `--drop-filtered` will use to remove promisor blobs: the `to_drop` set (computed by `enumerate_promisor_blobs()` in patch 4/7) is passed to `repack_promisor_objects()` to rebuild the promisor pack without the dropped objects. The implementation is straightforward and avoids lazy fetches by design, since it only operates on locally available data.

The patch is production-ready and integrates smoothly with the rest of the series. It does not introduce new dependencies or alter existing behavior, making it a safe intermediate step. The only notable detail is the `to_drop` check in `write_oid()`, which is clearly documented as skipping objects marked for removal.
