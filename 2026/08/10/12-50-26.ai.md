He notes that the patch removes the `USE_NSEC` macro but leaves the `NO_NSEC` conditional in `compat/posix.h` intact, which correctly disables nanosecond precision on platforms that lack support. This preserves the existing behavior: Git still avoids using nanoseconds when the platform does not provide them, regardless of the `core.useNanosec` setting. The observation is factual and confirms the patch does not introduce a regression on unsupported platforms, but it does not engage with the patch’s core design, performance implications, or the ongoing architectural discussion about where to cache the config value.
