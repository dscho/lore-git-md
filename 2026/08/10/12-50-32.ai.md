This is a **build-system fix** for Meson, the first patch in D. Ben Knoble’s three-patch series converting the `USE_NSEC` macro to runtime configuration. The patch exposes a `man_base_url` option in Meson to align its behavior with the existing Makefile-based build, which has allowed `MAN_BASE_URL` configuration since 2009. Without this change, Meson hard-codes a path that is incorrect for most distributions (it points to `$prefix/$mandir` instead of the HTML directory) and omits the trailing slash, breaking relative links in man pages.

The fix is minimal (8 lines) and uncontroversial. It changes the default `man.base.url.for.relative.links` value to `file://$(htmldir)/` (matching Make’s behavior) and adds a configurable `man_base_url` option for downstream flexibility. Patrick Steinhardt’s reply confirms the change is correct and aligns with the Makefile’s existing behavior. No further discussion or objections are expected; this patch is ready to advance alongside the rest of the series.
