Thread identity: Bugfix for Windows-specific resource contention in the sequencer during interactive rebase (single patch, no series version).

Core problem or goal: Fix a deadlock on Windows where the sequencer holds the ODB lock while spawning `git commit`, causing child processes that trigger auto-maintenance (e.g., repacking) to fail when attempting to replace files still locked by the parent. The fix releases the ODB before spawning commands that might run maintenance, following an established pattern.

Current status: Under review. The patch is a minimal, targeted fix with a Windows-specific regression test that reproduces the issue using a post-commit hook to force repacking and `GIT_TEST_LEGACY_DELETE=1` to expose the problem on modern Windows.

Key technical details:
- **Subsystem**: Sequencer (`sequencer.c`).
