This thread is about Patrick Steinhardt’s four-patch series to remove lazy-loading of alternate object databases in Git’s ODB subsystem. The goal is to simplify the code by initializing all alternate ODBs upfront during primary ODB setup, reducing scattered calls to `odb_prepare_alternates()` and enabling future work to move alternates into the "files" backend. The first patch resolves long-standing case-sensitivity inconsistencies in alternate path handling, while the remaining patches centralize alternate initialization and remove now-unused fields from the ODB structure.

The series, now at v2, is queued in Junio’s `seen` branch after a minor merge conflict was resolved. Patrick has addressed all reviewer feedback: Justin Tobler’s typo correction in a commit message and a clarifying comment about environment variable handling during cache flushing, and Karthik Nayak’s stylistic suggestion (which Patrick rejected as functionally incorrect). Both reviewers have since declared the series ready for integration, with no substantive objections or requests for further changes. The only remaining loose end is Patrick’s pending verification of the merge result, which may surface any integration issues. Performance implications for commands like `git fsck`—which previously avoided loading alternates when none were present—remain unaddressed but are acknowledged as a low-risk trade-off. The series is part of Patrick’s broader ODB abstraction effort.
