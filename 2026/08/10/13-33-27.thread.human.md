This thread is about Patrick Steinhardt’s four-patch series to refactor Git’s object database (ODB) subsystem by removing lazy-loading of alternate object databases. The goal is to simplify the codebase by initializing all alternates upfront during ODB setup, reducing scattered calls to `odb_prepare_alternates()` and enabling future work on the ODB abstraction effort. The first patch decouples path comparisons for alternate ODB sources from `the_repository` to fix long-standing case-sensitivity inconsistencies when alternates are registered before repository configuration is parsed.

The series is under initial review, with all four patches now posted. The first patch, which introduces ODB-specific case-sensitivity handling and replaces `fspathhash()`/`fspatheq()` with a self-contained comparison mechanism, has received a substantive review from Justin Tobler. Justin engaged deeply with the technical rationale, confirming the patch’s motivation and validating its approach. He raised clarifying questions about whether alternates are currently registered post-configuration (Patrick clarified this is an existing bug) and the use of `strihash()` for case-insensitive hashing. While Justin noted the added complexity for deduplicating alternates might be unnecessary for most repositories, he concluded the patch "looks good" after reviewing the key changes, including the migration from khash to `struct hashmap` and the path comparison logic. No bugs or requests for changes were identified, though the performance trade-offs for edge cases (e.g., repositories with thousands of alternates) remain open for discussion.

The remaining patches in the series centralize alternate initialization, remove unused ODB fields, and clean up the codebase, with no objections raised yet. The series is part of Patrick’s broader ODB abstraction effort and builds on his prior refactoring work. Reviewers may want to scrutinize the performance implications of eager alternate loading, particularly for commands like `git fsck` that previously avoided loading alternates when none were present.
