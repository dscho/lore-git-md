This is patch 4/7 of the `git repack --drop-filtered` series, introducing the core enumeration logic for promisor blobs. The patch adds `enumerate_promisor_blobs()` in `repack-filtered.c`, which walks all promisor objects (using `odb_for_each_object()` with `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`) and collects blobs into an oidset. It then applies the filter (currently only `blob:limit`) to that set using the new `list_objects_filter__filter_oidset()` helper, producing the final `to_drop` set. In `--dry-run` mode, the function prints the OIDs of candidate blobs to stdout.

The implementation avoids lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` to every object info query, ensuring it only operates on locally available data. The patch updates `builtin/repack.c` to call `enumerate_promisor_blobs()` when `--drop-filtered` is specified, storing results in a new `drop_oids` oidset. In `--dry-run` mode, it iterates over this set and prints each OID. The test script (`t/t7706-repack-drop-filtered.sh`) is extended with three new tests: (1) blobs exceeding the threshold are listed, (2) locally created blobs are never listed, and (3) `--dry-run` does not remove objects.

Key technical details include the `collect_promisor_blob()` callback (which skips non-blob objects and avoids lazy fetches), the `all_promisor_blobs` oidset (used as an intermediate collection before filtering), and the explicit validation that the caller ensures a `blob:limit` filter and promisor remote are present. The patch is production-ready and integrates smoothly with the rest of the series, though it performs two separate promisor-object walks (one for enumeration, one for repacking) which could be optimized in the future. The test coverage is thorough, verifying enumeration correctness and `--dry-run` behavior.
