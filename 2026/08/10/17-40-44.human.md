This is the fourth patch in the v4 series introducing `git repack --drop-filtered` for partial clones. It implements the core enumeration logic that identifies which promisor blobs exceed the user-specified size threshold and are therefore candidates for removal.

The patch adds `enumerate_promisor_blobs()` in a new file `repack-filtered.c`. This function walks all promisor objects (using `odb_for_each_object()` with `ODB_FOR_EACH_OBJECT_PROMISOR_ONLY`) and collects blobs into an oidset. It then applies the filter (currently only `blob:limit`) to that set using the new `list_objects_filter__filter_oidset()` helper introduced in patch 2/7, producing the final `to_drop` set. In `--dry-run` mode, the function prints the OIDs of candidate blobs to stdout. The implementation avoids lazy fetches by passing `OBJECT_INFO_SKIP_FETCH_OBJECT` to every object info query, ensuring it only operates on locally available data.

The patch updates `builtin/repack.c` to call `enumerate_promisor_blobs()` when `--drop-filtered` is specified, storing results in a new `drop_oids` oidset. In `--dry-run` mode, it iterates over this set and prints each OID. The test script (`t/t7706-repack-drop-filtered.sh`) is extended with three new tests: (1) blobs exceeding the threshold are listed, (2) locally created blobs are never listed, and (3) `--dry-run` does not remove objects. The tests use helper functions (`promisor_blob`, `pack_as_from_promisor`) to create promisor objects and verify the enumeration logic.

This is a well-crafted patch that addresses the technical challenge of identifying promisor blobs without triggering lazy fetches. The implementation is clean, the commit message is thorough, and the test coverage is comprehensive. The patch integrates smoothly with the rest of the series and is production-ready. The only minor technical debt is the dependency on `list_objects_filter__filter_oidset()`, which duplicates the `blob:limit` size check logic (flagged with a `NEEDSWORK` comment in patch 2/7). This patch does not introduce new loose ends; it delivers exactly what the series needs at this stage.
