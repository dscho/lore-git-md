This is a follow-up in a small bugfix thread for `git send-email`. The patch author, Harald Nordgren, acknowledges Junio C Hamano’s feedback on the wording of the improved error message. Junio pointed out that the current phrasing ("The first line must start with 'Subject: '") misleadingly implies the "Subject:" header must be on the first line, whereas valid patch files typically start with a "From " line followed by headers. Harald agrees and suggests rewording the message to focus on the absence of a "Subject:" header anywhere in the file, not its position. No new patch is attached yet, but this reply signals the author’s intent to send a v2 with corrected wording. The thread remains under review, with the core goal (clearer error messages) still uncontroversial.
