This is the **final iteration of a security feature patch** that adds `http.sslVerifyStatus`, a new boolean configuration option (default `false`) to enable OCSP staple validation in Git’s HTTPS connections. The patch is now **technically complete and ready for `next`**, with all prior review feedback addressed, including Junio C Hamano’s final request for clearer documentation wording.

The feature closes a security gap where Git—particularly OpenSSL-linked builds common in FIPS-compliant environments—ignores OCSP staples, potentially accepting revoked certificates. When enabled, `http.sslVerifyStatus` causes connections to fail if the server does not provide a valid staple, aligning Git’s behavior with government and enterprise PKI requirements (e.g., US Department of Defense). The fail-closed design is a deliberate security trade-off, but the default remains `false` to avoid breaking remotes that do not support stapling.

The implementation is minimal: a new config key in `http.c`, four new tests in `t5551-http-fetch-smart.sh`, and a concise documentation update in `Documentation/config/http.adoc`. The patch leverages libcurl’s existing `CURLOPT_SSL_VERIFYSTATUS` (introduced in 7.41.0, well below Git’s minimum libcurl version) and handles backend limitations gracefully by surfacing libcurl error strings to users. Per-URL overrides (e.g., `http.https://example.com/.sslVerifyStatus`) work out of the box thanks to Git’s existing urlmatch infrastructure.

The only remaining discussion point is whether the feature’s maintenance burden is justified by its narrow use case—government and FIPS-compliant deployments—but this is a policy question, not a technical one. The author has provided a clear rationale, thorough testing, and addressed all procedural and substantive feedback from Junio and Patrick Steinhardt. The patch is **well-crafted, uncontroversial, and likely to graduate to `master`** in the near term. If you work in a regulated environment or care about certificate revocation, this is worth tracking; otherwise, it’s a niche but solid addition.
