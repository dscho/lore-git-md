This thread is about a critical bugfix for a race condition in Git's geometric repacking mechanism that can cause crashes in `git replay` and missing-object errors in other operations. The issue occurs when a multi-pack-index (MIDX) references a packfile that has been removed by geometric repacking, leading to failed object lookups. Elijah Newren's two-patch series fixes this by making `git replay` fail gracefully when objects are unreadable (patch 1/2) and by adding recovery logic to the packed-object backend to scan all packs covered by the MIDX when the preferred pack is missing (patch 2/2).

The series is widely accepted as necessary, but the architectural discussion around patch 2/2 continues. Junio C Hamano and Patrick Steinhardt have reviewed the patches substantively with no remaining technical objections, while Jeff King (Peff) and Derrick Stolee have raised performance and deployment-level concerns. The latest exchange between Peff and Patrick clarified that the bug affects all object lookups, not just those using `OBJECT_INFO_QUICK`, and that the fallback logic is only invoked when the MIDX should have found the object. Peff's performance concern has evolved into a debate over whether the recovery logic should be tied to the `SECOND_READ` phase (his preference) or remain as currently implemented.

Derrick Stolee's recent email introduces a new dimension: the existing `git multi-pack-index expire` mechanism already mitigates similar races by leaving redundant packfiles in place until all processes using them have finished. Stolee suggests geometric repacking could adopt a similar approach to reduce reliance on the fallback logic, making the race condition itself rarer. This aligns with the broader discussion about optimizing the scan order, timing, and interaction with existing mechanisms to balance correctness, performance, and operational simplicity. The thread remains focused on refining the implementation rather than questioning the fix's necessity, with Elijah yet to respond to the latest feedback.
