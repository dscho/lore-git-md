This is Junio’s "What’s cooking in git.git" report for August 2026 (#08), summarizing the state of all in-flight topics.

The report lists 437 non-merge commits in `master` since Git 2.55, with 143 topics cooking in `next` and 260 in `seen`. Key highlights for a future AI summarizer:

- **Critical bugfix**: `sk/object-name-use-after-free` (heap-use-after-free in `get_oid_with_context_1()` when reporting failures with a relative path to a sparse directory) is marked for `next` and looks ready to graduate.

- **ODB pluggability progress**: Two major series from Patrick Steinhardt are in flight:
  - `ps/odb-pluggable-pack-generation` (6 commits) makes packfile generation pluggable via ODB callbacks, removing hardcoded `pack-objects` references. This touches `bundle`, `send-pack`, and `upload-pack`.
  - `ps/odb-eagerly-load-alternates` (6 commits) simplifies the ODB layer by eagerly loading alternates at initialization, eliminating scattered lazy-loading calls. This builds on the merged `ps/odb-make-creation-pluggable` series.

- **Libification**: `ty/repository-fetch-if-missing` moves the global `fetch_if_missing` into `struct repository`, continuing the effort to make Git more library-friendly.

- **Performance**: `js/packfile-fast-append` fixes a quadratic complexity regression in `packfile_list_append()` when adding many new packfiles.

- **New features**:
  - `kh/format-rev-more-options` teaches the experimental `git format-rev` command `--abbrev`, `--color`, and `--date` options.
  - `ss/repack-drop-filtered` adds `--drop-filtered` to `git repack` to delete local promisor blobs exceeding a `blob:limit=` filter, reclaiming space in partial clones.

- **Security**: `gg/http-ssl-verify-status` adds `http.sslVerifyStatus` to check stapled OCSP responses during TLS handshake.

- **Breaking changes prep**: `bc/restrict-hex-to-lowercase` (6 commits) updates hex parsers to reject uppercase characters in breaking-changes mode, preparing for Git 3.0.

- **Windows build updates**: `js/mingw-build-updates` (12 commits) upstream patches from Git for Windows, including dropping obsolete compatibility options and allowing direct use of `git.exe`.

- **Experimental commands**:
  - `hn/history-squash` (9 commits) adds a `squash` subcommand to `git history` to fold a range of commits into one.
  - `vm/complete-history` (4 commits) adds command-line completion for the experimental `git history` command.

- **Stalled topics**: `hs/rebase-continue-edit` (support for `--[no-]edit` with `--continue`) has been waiting for a response since July.

- **Discarded topics**: `td/fsmonitor-darwin-cookie-flush` (macOS fsmonitor fix) was retracted, and `tb/send-pack-no-ref-delta` (honoring `no-ref-delta` capability) was withdrawn for now.

The report also notes several topics marked for `next` or `master`, including fixes for segfaults (`cc/git-shallow-file-wo-value`), memory leaks (`cl/regexec-macos-leak`), and Coverity warnings (`js/coverity-unchecked-returns-fix`).
