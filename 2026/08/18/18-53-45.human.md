This is Junio’s "What’s cooking in git.git" report for August 2026 (#08), the regular digest that gives a high-level view of what is happening in the Git project’s integration branches.

The report covers 437 non-merge commits that have graduated to `master` since Git 2.55, 143 commits currently cooking in `next`, and 260 commits in `seen`.  A single stalled topic (`hs/rebase-continue-edit`) is still waiting for a response after a month.  The rest of the report lists new topics, topics that are cooking, and a handful of discarded ones.

Among the new topics, a heap-use-after-free bug in the object-name parsing code (`sk/object-name-use-after-free`) has been fixed and looks ready to graduate to `next`.  The experimental `git format-rev` command has gained a few more formatting options (`kh/format-rev-more-options`) and its documentation has been polished (`kh/format-rev-doc-synopsis`).  A pluggable ODB interface for generating packfiles (`ps/odb-pluggable-pack-generation`) is now in `seen`; it removes hard-coded references to `pack-objects` and lets alternative backends serve packfiles directly.

Several long-running efforts are still in flight.  The ODB abstraction work continues with `ps/odb-eagerly-load-alternates`, which eagerly loads alternate object directories at startup, and `ps/odb-make-creation-pluggable`, which has already graduated to `next`.  The `the_repository` removal campaign is represented by `ty/repository-fetch-if-missing`, which moves the global `fetch_if_missing` variable into `struct repository`.  The HTTP transport now supports stapled OCSP responses (`gg/http-ssl-verify-status`), and the `git last-modified` command has been optimized with Bloom filters (`tc/last-modified-bloom`).

Notable user-facing changes that are about to graduate include `hn/branch-delete-merged`, which adds a `--delete-merged` option to `git branch` to remove local branches already merged into their upstream, and `hn/bisect-reset-when-found`, which teaches `git bisect` to automatically reset when the culprit is found.  The `git repack` command now supports `--drop-filtered` to reclaim space by dropping local promisor blobs that exceed a configured limit (`ss/repack-drop-filtered`).

A few topics are marked as needing a reroll or further review.  `jt/receive-pack-pluggable-writes` extends the ODB transaction interface to `git receive-pack`, and `dk/use-nsec-runtime` converts the build-time `USE_NSEC` knob into a runtime `core.useNanosec` configuration.  The experimental `git history` command has gained a `squash` subcommand (`hn/history-squash`), and the `git replay` command now offers a `--linearize` option (`tc/replay-linearize`).

The report also lists a handful of discarded topics, including a macOS fsmonitor fix that was retracted and a `git send-pack` patch that was withdrawn for now.
