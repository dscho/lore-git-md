This is the third patch in Kristoffer Haugsbakk’s five-patch v2 series extending `git format-rev` with `--abbrev`, `--color`, and `--date` options. This patch refactors the command’s option variables into a new `struct format_rev_data` to reduce the number of local variables and prepare for the upcoming feature additions. The refactoring is purely internal: it groups existing variables (`format`, `stdin_mode`, `nul_input`, `nul_output`, and `notes`) into a single struct, renames `stdin_mode_arg` to `stdin_mode` (avoiding shadowing), and inlines the previously separate `format_nul_data` struct. The patch also switches to designated initializers (C99) for clarity, a change requested and approved by Junio C Hamano in the v1 review.

The patch touches only `builtin/name-rev.c` and makes no functional changes—behavior, CLI, and on-disk formats remain identical. The defensive `BUG_ON_OPT_NEG(unset)` assertions requested in v1 are now handled by the new patch 2/5, so this patch focuses solely on the struct refactoring. The interdiff against v1 shows the designated initializers replacing the positional ones, aligning with Junio’s feedback. No review comments have been posted on this v2 iteration yet, but the changes are uncontroversial and directly address the earlier feedback. The patch is a clean preparatory step for the feature implementation in patch 5/5.
