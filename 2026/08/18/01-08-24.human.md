This is a **Trace2 instrumentation patch** for `git pack-objects`, adding a new `write_pack_file/wrote_bytes` event to record the total bytes written across all pack files in a single invocation. The patch is small, focused, and addresses a clear observability gap: Trace2 already tracks object counts, but not the actual byte size of generated packs, which is needed to measure how compression settings affect push performance.
