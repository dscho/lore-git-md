This is a refactoring and bugfix series targeting Git’s object database (ODB) subsystem, authored by Patrick Steinhardt. The series addresses inconsistent handling of the `OBJECT_INFO_DIE_IF_CORRUPT` flag, which currently ties Git to specific backends and can cause premature termination even when a good copy of an object exists elsewhere.

The problem: when an object lookup fails with `OBJECT_INFO_DIE_IF_CORRUPT`, Git either checks for corruption in a backend-specific way (breaking abstraction) or dies immediately in the loose backend, ignoring other sources that might have a valid copy. The series makes the check generic by extending `odb_source_read_object_info()` to distinguish between missing and corrupt objects and to return error messages to the caller. This change touches all ODB backends (loose, packed, inmemory, files) and propagates the new semantics up through the ODB layer.

The seven patches are tightly coupled, each preparing one backend or layer for the final generic handling in patch 7. The series is well-scoped, with a clear technical rationale and no obvious omissions; it looks like a serious, well-crafted contribution to the ongoing ODB abstraction effort.
