This is the third patch in Kristoffer Haugsbakk’s five-patch v2 series extending `git format-rev` with `--abbrev`, `--color`, and `--date` formatting options. This patch refactors the command’s option variables into a new `struct format_rev_data` to reduce clutter and prepare for the upcoming feature additions.

The change is purely internal: it groups the existing `--format`, `--stdin-mode`, `--notes`, and NUL-termination flags into a single structure, renames `stdin_mode_arg` to `stdin_mode` (avoiding a name clash with the `stdin_mode` enum), and switches the option callbacks to use the new struct. The patch also adopts C99 designated initializers for clarity, addressing Junio C Hamano’s feedback from v1. No user-visible behavior changes; the refactoring is mechanical and uncontroversial.

The patch touches only `builtin/name-rev.c` and is part of a well-reviewed series that has already incorporated all v1 feedback. It looks clean and ready for integration.
