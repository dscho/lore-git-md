This is the first patch in D. Ben Knoble’s three-part series converting Git’s nanosecond precision setting from a build-time macro to a runtime configuration. This specific patch is a build-system fix for Meson, exposing a knob that controls how relative links in manual pages are rendered.

The patch aligns Meson’s behavior with the long-standing Makefile equivalent: it changes the default base URL for relative links in man pages from a hard-coded path (`prefix/mandir`) to a local file URL pointing at the HTML documentation directory (`file://htmldir/`), ensuring the links work correctly in most distribution builds. It also adds a configurable `man_base_url` option so downstream packagers (like Gentoo) can override the default if needed. The change is small, self-contained, and uncontroversial; Patrick Steinhardt has already confirmed it is correct and matches the Makefile’s behavior.

This patch is ready to advance independently of the rest of the series. It touches only `Documentation/meson.build` and `meson_options.txt`, and the commit message provides clear rationale and examples of the broken links it fixes. There are no known open questions or conflicts.
