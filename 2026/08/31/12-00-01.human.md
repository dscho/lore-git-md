This is a targeted bugfix for `git checkout -m` that improves the readability of conflict advice when autostash fails. The patch is a streamlined v2 of a previously contested two-patch series, now condensed into a single commit that focuses solely on the uncontroversial part: adding a blank line between the autostash conflict advice and the branch-switch confirmation message.

The change is small and surgical. It modifies `sequencer.c` so that `apply_save_autostash_oid()` returns `1` when stash application fails due to conflicts (rather than silently returning `0`), and updates `builtin/checkout.c` to print a blank line to `stderr` when that return code is seen. The test in `t/t7201-co.sh` now verifies the full output with a single `test_cmp` against an expected multi-line string, replacing the previous multi-grep validation.

This v2 drops the fast-path optimization that was contested in v1 (skipping autostash retry when no tracked changes exist) and the API design debate around output parameters. The remaining change is straightforward and addresses a clear usability issue: without the blank line, the conflict advice and branch-switch message visually run together, making it harder for users to parse what happened. Phillip Wood had already endorsed this part of the original series as "a good idea," and Junio had signaled intent to queue it once the API concerns were resolved. This v2 delivers exactly that uncontroversial improvement.
