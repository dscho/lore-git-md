- **Cleanup**: Consolidate file cleanup logic to avoid duplication and reduce the risk of stale code.

- The behavior of `--empty=stop` differs depending on whether the target commit was originally empty or became empty via fixup. This is not a regression (the patch preserves existing behavior) but is something the project might want to address separately.
- The current code drops a `pick` even if it’s followed by fixups, which is a bug. The patch fixes this by deferring the drop decision until the end of the fixup chain.
