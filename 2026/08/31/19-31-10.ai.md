This is Junio’s "What’s cooking" report for August 2026, summarizing the state of integration branches and in-flight topics. Below is the key technical detail a future AI session would need to follow follow-up discussion:

Graduated to master (irreversible for 2.56)
• fr/pack-objects-trace-pack-bytes – trace2 event now records total bytes written by pack-objects, allowing compression-setting comparisons.
• jt/receive-pack-pluggable-writes – receive-pack uses the new ODB transaction interface to write incoming packfiles; the transaction layer now exposes finalize/rollback callbacks.
• kh/trailers-no-urls – trailer parser no longer misinterprets lines starting with “https://…” as trailers.
• ps/odb-eagerly-load-alternates – alternates are loaded at ODB creation time instead of lazily on first object lookup; alternates_db and loaded_alternates fields removed.
• ps/odb-generic-corrupt-objects – odb layer now distinguishes “missing” from “corrupt” via strbuf error propagation; packed and loose backends both use the same error-reporting mechanism.
• ps/odb-geometric-repack-loose-threshold – loose-object count threshold for geometric repacking now matches gc.auto.
• ps/odb-pluggable-pack-generation – pack-objects logic moved behind an ODB interface; upload-pack, send-pack, and bundle now generate packfiles via odb->generate_pack().
• vm/complete-history – zsh/bash completion for the experimental git history command (split pathspecs, --update-refs, --empty).
• yn/worktree-add-no-dwim-with-b – worktree add no longer DWIMs a remote-tracking branch when -b/-B is given.

New topics (in next or seen, not yet in master)
• jc/checkout-refactor – 8-patch series that restructures git checkout/switch/restore front-end: pathspec and branch setup helpers extracted, cb_option passed explicitly, post_checkout_hook moved to checkout.c.
• hk/typofix – single patch fixing spelling in comments and test descriptions; reroll expected.
• ll/doc-pushcert-if-asked – documents that remote-helper pushcert option accepts “if-asked”.
• ps/odb-alternates-at-creation – 8 patches that defer alternates setup to odb_create_on_disk(); removes the ad-hoc alternates writing API.
• ps/odb-pluggable-fsck – 10 patches that move fsck checks into the ODB source layer; packed and loose backends now implement their own fsck callbacks.
• rs/worktree-add-basename-fixes – 4 patches fixing out-of-bounds reads and trailing-slash handling in worktree_basename().
• en/no-amend-during-conflicts – 5 patches that teach am/revert/rebase to refuse --amend and partial commits during conflict resolution, matching existing cherry-pick/merge behavior.
• tc/replay-linearize – 3 patches adding --linearize to git replay to drop merge commits, mimicking rebase --no-rebase-merges.
• kj/repo-info-more-path-keys – 7 patches extending git repo info with absolute/relative paths for grafts, index, hooks, superproject-root, toplevel, and cdup.
• tc/last-modified-bloom – 6 patches that speed up git last-modified by reusing revision walk Bloom-filter logic and maintaining per-path Bloom filters for wildcard pathspecs.
• ds/trace2-tolerate-failed-timestamp – 7 patches that ban xcalloc/xstrfmt/ALLOC_GROW from trace2 to avoid die() calls; trace2 now tolerates failed timestamp formatting.
