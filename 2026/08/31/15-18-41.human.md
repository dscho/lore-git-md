This is a small refactoring patch in the revision-walking subsystem, part of a six-patch series from Toon Claes. It moves a precondition check (`revs->bloom_keyvecs_nr != 0`) from two call sites into the `check_maybe_different_in_bloom_filter()` function itself. The change is mechanical and reduces code duplication without altering observable behavior: when no Bloom key vectors are set up, the Bloom filter statistics are never reported anyway, so the new early return (`-1`) is invisible to users. The patch touches only `revision.c` and is clearly motivated as a cleanup step. It looks well-crafted and uncontroversial.
