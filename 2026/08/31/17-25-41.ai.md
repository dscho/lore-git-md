The core change is in `redact_arg()`, where the banned `xstrfmt()` call is replaced with a defensive implementation that:
- Checks for integer overflow when calculating the required buffer size.
- Allocates memory with `malloc()` (not `xmalloc()`) and returns `NULL` on failure.
- Uses `memcpy()` to construct the redacted string (`user:<REDACTED>@example.com`) without relying on `printf`-style formatting.
- Frees any previously allocated memory if a later redaction fails, ensuring no leaks.
