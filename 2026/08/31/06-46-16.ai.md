This is the second patch in Patrick Steinhardt’s 10-patch series refactoring Git’s object-database fsck checks to make them pluggable. It merges the `fsck_obj_buffer()` and `fsck_obj()` functions in `builtin/fsck.c` into a single function, eliminating redundancy and simplifying control flow.

The patch removes the early return check for the `SEEN` flag in `fsck_obj()`, which was always cleared by the sole caller (`fsck_obj_buffer()`) before invocation. The merged function unconditionally sets `SEEN` and `HAS_OBJ`, clears `REACHABLE`, and proceeds with object verification. This change is purely internal and does not alter behavior—it merely consolidates two nearly identical functions into one. The diff shows 27 lines removed and 20 added, with the new `fsck_obj_buffer()` now handling both object parsing and verification.

Karthik Nayak’s review of v1 was surface-level, suggesting only a minor commit-message wording tweak (“early” → “early return”), which Patrick incorporated into v2. No technical concerns or edge cases were raised, and the patch’s correctness is straightforward given that the merged logic preserves the original behavior. This is a clean refactoring step that prepares the codebase for later patches in the series, which will move fsck logic into ODB backend implementations. The patch touches only `builtin/fsck.c` and introduces no new symbols or user-visible changes.
