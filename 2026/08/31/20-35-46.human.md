This is a call for contributions to **Git Rev News edition 138**, the project's community newsletter.

Christian Couder has posted a draft of the next edition on GitHub and invites the community to help polish it before publication on **September 2nd, 2026**. The draft is open for proofreading, article suggestions, link submissions, or offers to be interviewed. Contributions can be made either by editing the GitHub page directly and sending a pull request, or by commenting on the associated GitHub issue or replying to the email. This is a low-effort, high-value way for casual followers to support the project without writing code.
