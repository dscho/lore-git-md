This is a test patch for the `git symbolic-ref` command, part of the refs subsystem. The patch adds systematic test coverage for the exit codes and output behavior when querying a non-symbolic ref, both with and without the `--quiet` (`-q`) flag. The tests use `test_must_fail` to avoid freezing exact exit codes, addressing feedback from Junio C Hamano in earlier iterations.

Patrick Steinhardt’s reply confirms the patch is technically sound and ready for integration. He notes that the current behavior—exiting with code 128 (without `--quiet`) or 1 (with `--quiet`)—contradicts the documentation, which states that `git symbolic-ref` should always exit with 1 for non-symbolic refs. However, since the tests no longer assert exact exit codes, the patch does not lock in the "broken" behavior. This aligns with the thread’s prior compromise to document the status quo rather than change it.

The unresolved question remains whether to update the man page to reflect the current behavior. Junio’s objection ("casting wrong behavior into stone") has stalled that part of the effort, but the test additions themselves are uncontroversial and valuable. The patch is a low-risk, high-value contribution to test coverage, and Patrick’s review signals it is ready for merging as-is. The documentation update may proceed separately if the thread reaches consensus on how to handle it.
