This is a CI/build system patch. Jeff King updates the Git project's continuous integration jobs to replace Debian 11 with Debian 12. Debian 11 recently exited its LTS (Long Term Support) period, meaning it no longer receives security updates from the Debian project. The patch updates both GitHub Actions and GitLab CI configuration files to use the newer Debian 12 image, which will remain supported until June 2028.

The motivation is straightforward: the CI job was originally added to catch regressions on older but still-supported distributions, and Debian 11 no longer qualifies. The commit message references an earlier commit (ac112fd4f0) that established this practice, grounding the change in existing project policy.

The patch itself is minimal and mechanical, touching only the CI configuration files to update the image name and the accompanying comment about support lifespan. Jeff notes he encountered an apt failure on Debian 11, which prompted the change, but the update is justified regardless of that transient issue.

Testing appears light but reasonable: Jeff verified the GitHub job works and expects the GitLab job to behave identically since both use the same Docker images. There is no indication this change affects any other part of the build or test infrastructure.

This is a routine maintenance update that keeps the CI environment current. It looks well-motivated and uncontroversial, and the patch itself is clean and focused.
