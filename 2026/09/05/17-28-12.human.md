This is the first patch in a now-finalized four-part documentation series that has been merged to `next`. The series improves the discoverability of the `gitdatamodel(7)` man page, which explains Git’s data model but was previously unlinked from other documentation.

This patch adds `gitdatamodel(7)` to `command-list.txt`, ensuring it appears in the "Guides" section of `git(1)` and is listed by `git help --guides`. The change is trivial—a single line addition—but it is the foundational step that makes the rest of the series effective. The commit message is clear and concise, noting that the page was previously invisible despite its value. No code or tests are touched, and the patch carries no risk of regression.

The series as a whole is a well-motivated, low-effort improvement to documentation usability. This patch is the simplest part of it, but it is necessary for the cross-references added in later patches to work. If you care about Git’s documentation ecosystem, this series is worth noting; if you only follow code changes, it is safe to skip.
