This thread is about updating Git's CI workflows to use Debian 12 instead of Debian 11, now that Debian 11 has reached end-of-life. Jeff King (Peff) sent a straightforward patch replacing `debian:11` with `debian:12` in the GitHub Actions and GitLab CI configurations, along with a comment update to reflect the new LTS support window (until mid-2028).

The patch has now been effectively accepted. Junio C Hamano, the maintainer, replied to confirm he had noticed the same Debian 11 job failures and will queue the patch for integration. No substantive review was needed—the change is mechanical and aligns with the project's practice of keeping CI on supported distributions. The only lingering question—whether to retain an older LTS job (like Debian 11) for compatibility testing—remains unaddressed, but Junio’s reply suggests it isn’t a blocker. The patch is now in Junio’s `seen` branch and will likely move to `next` in the next integration cycle.
