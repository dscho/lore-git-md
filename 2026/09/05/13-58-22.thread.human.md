This thread is a straightforward maintenance update to Git's CI configurations. Jeff King (Peff) has posted a patch that bumps the Debian version used in GitHub Actions and GitLab CI workflows from Debian 11 to Debian 12, reflecting Debian 11's end of LTS support. The change is mechanical—updating image references and comments—and is motivated by a recent `apt` failure in a Debian 11 job, though Peff notes the failure might have been transient.

The patch touches only CI files and aligns with the project's practice of tracking supported LTS distributions. While the change is unlikely to be controversial, there’s a minor open question: whether the project should retain a job for an older LTS release (like Debian 11) to catch compatibility regressions, or if the existing AlmaLinux 8 job (supported until 2029) already provides sufficient coverage for older environments. No reviews or objections have been posted yet, and the patch doesn’t introduce new functionality or behavior changes—just an update to the testing environment.
