This thread is a simple documentation fix for the `git-merge` man page. Fabian Kratz reported a typo in an example diagram where the man page incorrectly states that `ORIG_HEAD` points to the tip of the current branch (`C`) before a merge, when it should point to the tip of the branch being merged (`G`, the `master` branch). The correction is straightforward and supported by the author's testing and logical consistency with the surrounding text.

The patch targets only `Documentation/git-merge.txt` and is unlikely to spark debate, as it addresses a clear factual error. No reviews or responses have appeared yet, so the thread is still open for feedback, but given the nature of the change, it may be merged quickly once a maintainer or documentation reviewer signs off.
