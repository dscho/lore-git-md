This is a documentation patch reporting a typo in the `git-merge` man page.

Fabian Kratz, a first-time contributor, points out an error in an example diagram in the `git-merge` manual. The example shows a commit history and explains that `ORIG_HEAD` is set to the tip of the current branch before a merge operation. Fabian argues that the man page incorrectly states `ORIG_HEAD` is set to `C` (the tip of the topic branch) when it should be set to `G` (the tip of the master branch, which is the current branch in the example).

The observation is straightforward and supported by both the explanation in the man page itself and Fabian’s own testing. The patch is a clear case of a small but meaningful documentation correction. Since it touches only the man page and does not affect code behavior, it is unlikely to be controversial. The contribution is well-motivated and presented, making it a good candidate for quick review and merging.
