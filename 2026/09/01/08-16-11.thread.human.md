This thread is about a small but important fix to Git's GitLab CI pipeline. The "documentation" job recently started failing because a dependency update removed Ruby as a transitive dependency of Asciidoc, breaking the installation of Asciidoctor, which is needed to build Git's documentation. Patrick Steinhardt posted a one-line patch to `ci/install-dependencies.sh` that explicitly adds `ruby` to the dependency list for the documentation job, restoring the build.

The patch is straightforward and addresses an observable breakage with minimal risk. Toon Claes reviewed it, catching a minor typo in the commit message ("inus" instead of "us") and noting he had also noticed the failure but wasn't sure when it started. His feedback was purely surface-level—no technical concerns or requests for changes—so the patch is effectively ready to go. There are no open questions or objections, and no prior versions of the patch exist. This is a simple, uncontroversial fix to keep the CI pipeline running smoothly.
