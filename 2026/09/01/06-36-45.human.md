This is a small **refactoring patch** that cleans up the recently introduced `mark_argv_for_free()` helper in `revision.c`. It follows up on Jeff King’s earlier bugfix for the `git stash show` use-after-free regression (commit 3ea35c64b) by pushing the `free_removed_argv_elements` flag check into the helper itself, rather than requiring every caller to check it.

The change is mechanical and low-risk: it removes redundant flag checks from four call sites and updates the helper’s signature to accept the `setup_revision_opt` struct. The one exception—`setup_revisions_from_strvec()`—always sets the flag, so the new check is a no-op there. The result is slightly cleaner code with no behavior change.

This patch is clearly a follow-up cleanup, not part of the core regression fix. It’s well-motivated (reducing duplication) and self-contained, but it’s also entirely optional. If the earlier bugfix lands in `maint`, this could ride along or be deferred to `master` without consequence. No controversy or open questions here—just a tidy-up for code that was touched anyway.
