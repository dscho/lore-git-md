This is the final patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It deletes the now-unused `odb_add_to_alternates_memory()` function from `odb.c` and `odb.h`, completing the removal of the mechanism that allowed in-memory registration of ODB sources (primarily used for submodules).

The patch is a mechanical cleanup: 14 lines removed, no new code added. It is the culmination of the preceding 11 patches, which systematically eliminated all callers of this function and the infrastructure that supported it. The commit message reiterates the series’ goal: simplifying the ODB by ensuring the sources list contains only the primary source and its alternates, paving the way for future work to migrate alternate handling into the "files" backend.

No behavioral changes are introduced; the patch merely removes dead code. The series as a whole has already been reviewed by the author, and this patch is the last step in a well-scoped refactoring that touches the ODB, submodule handling, and related subsystems. The removal of the ad-hoc linking mechanism is a net maintainability win, eliminating a design wart that complicated the ODB’s internal logic. The patch is uncontroversial given the groundwork laid by the earlier patches in the series.
