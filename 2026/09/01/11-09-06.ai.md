This is a refactoring patch (part 7/12) in Patrick Steinhardt’s ODB cleanup series. It removes the now-unused `tmp_objdir_add_as_alternate()` function from `tmp-objdir.c` and its declaration from `tmp-objdir.h`. The function became dead code after `builtin/receive-pack` switched to ODB transactions in commit bdee7b3013 (July 2026), which eliminated the last caller. The patch deletes 11 lines of code and is purely mechanical—no behavior changes, no new dependencies, and no test updates required. This is a straightforward cleanup that aligns with the series’ goal of simplifying the ODB’s alternate-handling logic. The removal is uncontroversial and appears to be a natural follow-up to the earlier transaction work.
