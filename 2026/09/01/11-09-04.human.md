This is the fifth patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The series is part of his ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch removes the registration of submodule object databases as in-memory sources in `` `git grep` ``. The commit message explains that this mechanism was originally introduced as an eager alternate registration and later converted to a lazy mechanism. However, since `` `git grep` `` now passes submodule repositories directly to worker threads (via commit `0693806bf8`), the submodule ODBs no longer need to be registered as alternates. The patch deletes the logic that performed this registration, simplifying the code.

The change touches only `builtin/grep.c`, removing 20 lines and adding 6. The patch retains the object read lock, but for a different reason: initializing the subrepository is still racy due to potential contention around `get_main_ref_store()`. The commit message notes this as a remaining `NEEDSWORK` item, but it is not addressed in this series.

This is a clean refactoring with no expected behavioral changes. The patch is well-motivated and aligns with the series’ goal of eliminating dual-use of the ODB sources list. No external reviews have been posted yet, but the patch appears to be a straightforward progression of the ODB cleanup.
