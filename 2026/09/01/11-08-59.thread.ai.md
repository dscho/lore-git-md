Thread identity
Subject: [PATCH 0/13] odb: remove ad-hoc source linking
Series version: v2 (revision of v1; patch 1/13 revised, patches 2-13 unchanged)
Originating author: Patrick Steinhardt
Thread type: patch series

Core problem or goal
Refactor the object database (ODB) subsystem to remove the mechanism allowing registration of in-memory sources (primarily used for submodules). This eliminates dual-use of the ODB sources list for both alternates and temporary sources, simplifying the codebase and preparing for future migration of alternate handling into the "files" backend. The series also continues the broader `the_repository` removal effort by eliminating implicit dependencies on global state in the `cache-tree`, `submodule-config`, and related subsystems.

Current status
Under review; v2 posted 2026-09-05. Patch 1/13 revised to address Junio C Hamano’s feedback from v1, encapsulating the repository dependency within `cache-tree.c` and resolving two correctness issues: ensuring `write_in_core_index_as_tree()` uses `index_state->repo` and fixing a lingering `the_repository` reference in `unpack_trees.c`. The remaining 12 patches (2-13/13) are unchanged from v1. Series consists of 13 patches: incidental cleanups (removing `the_repository`/`the_hash_algo` dependencies in `cache-tree`, `submodule-config`, and related callers), core refactoring (removing submodule ODB source registration in `submodule-config`, `builtin/grep`, and ODB infrastructure), a bugfix for a memory leak in the packed ODB source (patch 9/13), enforcement of an existing constraint in `git multi-pack-index --object-dir=` (patch 10/13), test helper updates (patches 11/13 and 12/13), and final removal of the ad-hoc source linking API (patch 13/13). Patch 10/13 enforces an existing documented constraint, removing the last real-world caller of the ad-hoc source linking mechanism outside test helpers. Junio C Hamano provided a **substantive review** of patch 6/13 in v1, signaling unqualified approval with *“Yay. Very nice.”* No new reviews or objections in v2; the series remains self-contained with no external dependencies.

Key technical details
- Files touched: `odb.c`/`odb.h` (removal of registration API, `submodule_source_paths` field, and `odb_add_to_alternates_memory()`), `submodule-config.c`, `builtin/grep.c`, `tmp-objdir.c`/`tmp-objdir.h`, `t/helper/test-read-midx.c`, `t/helper/test-ref-store.c`, `cache-tree.c`/`cache-tree.h`, `builtin/checkout.c`, `builtin/commit.c`, `sequencer.c`, `sparse-index.c`, `unpack-trees.c`, `odb/source-packed.c` (memory leak fix), `builtin/multi-pack-index.c` (patch 10/13: enforce alternate-only `--object-dir=`), plus callers in `builtin/fetch.c`, `builtin/submodule--helper.c`, `submodule.c`, `t/helper/test-submodule.c`, `t/README`, and test scripts (`t/t5319-multi-pack-index.sh` updated to retain `repo64` for alternate validity).
- Symbols removed: ODB source registration functions (`odb_add_submodule_source_by_path()`, `register_all_submodule_sources()`, `odb_add_to_alternates_memory()`), `submodule_source_paths` string list in `struct object_database`, `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode (now obsolete), and `tmp_objdir_add_as_alternate()` from `tmp-objdir.c`/`tmp-objdir.h`.
- Symbols modified: `must_prefetch_predicate` callback type extended to accept `void *cb_data` for repository context; all functions in `submodule-config.c` updated to accept `struct repository *` parameter; `hash_oid_string` updated to use the hash algorithm embedded in the object ID. Patch 1/13 adapts `cache_tree_fully_valid()` to take a `struct index_state *` instead of a repository and cache tree, encapsulating the repository dependency within `cache-tree.c` while preserving the external interface. The function is renamed internally to `cache_tree_fully_valid_recursive()` (file-scoped static), and the new `cache_tree_fully_valid()` wrapper delegates to it using `istate->repo`.
- Subsystems affected: ODB (including packed source backend), submodule handling, grep plumbing, cache-tree, checkout, commit, sequencer, sparse-index, unpack-trees, fetch, submodule helpers, test infrastructure, temporary object directory handling, multi-pack-index.
- No on-disk format changes; no behavioral changes expected beyond the memory leak fix (patch 9/13) and the breaking change in `git multi-pack-index --object-dir=` (patch 10/13: now rejects non-alternate directories, aligning with documented behavior since 2021).
- Test coverage: updated test helpers (`test-read-midx.c`, `test-ref-store.c`, `test-submodule.c`) and test scripts to reflect API removal; the `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode is now a no-op and removed from documentation and test scripts. The test suite passes without failures, confirming the cleanup is complete.
