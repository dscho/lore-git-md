Subject: [PATCH 0/12] odb: remove ad-hoc source linking
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series

Core problem or goal
Refactor the object database (ODB) subsystem to remove the mechanism allowing registration of in-memory sources (primarily used for submodules). This eliminates dual-use of the ODB sources list for both alternates and temporary sources, simplifying the codebase and preparing for future migration of alternate handling into the "files" backend. The series also continues the broader `the_repository` removal effort by eliminating implicit dependencies on global state in the `cache-tree`, `submodule-config`, and related subsystems.

Current status
Under review; v1 posted 2026-08-31. No prior versions. Series consists of 12 patches: incidental cleanups (removing `the_repository`/`the_hash_algo` dependencies in `cache-tree`, `submodule-config`, and related callers), core refactoring (removing submodule ODB source registration in `submodule-config`, `builtin/grep`, and ODB infrastructure), and final removal of the ad-hoc source linking API. The quarantine directory mechanism remains as the sole exception. Patch 2/12 (removal of `the_repository` in `submodule-config`) has been reviewed in detail; no objections or requests for changes raised yet.

Key technical details
- Files touched: `odb.c`/`odb.h` (removal of registration API), `submodule-config.c`, `builtin/grep.c`, `t/helper/test-read-midx.c`, `test-ref-store.c`, `cache-tree.c`/`cache-tree.h`, `builtin/checkout.c`, `builtin/commit.c`, `sequencer.c`, `sparse-index.c`, `unpack-trees.c`, plus callers in `builtin/fetch.c`, `builtin/submodule--helper.c`, `submodule.c`, and `t/helper/test-submodule.c`.
- Symbols removed: ODB source registration functions (e.g., `odb_link_source`); implicit `the_repository` usage in `cache-tree` and `submodule-config`.
- Symbols modified: `must_prefetch_predicate` callback type extended to accept `void *cb_data` for repository context; all functions in `submodule-config.c` updated to accept `struct repository *` parameter.
- Subsystems affected: ODB, submodule handling, grep plumbing, cache-tree, checkout, commit, sequencer, sparse-index, unpack-trees, fetch, submodule helpers.
- No on-disk format changes; no behavioral changes expected.
- Test coverage: updated test helpers (`test-read-midx.c`, `test-submodule.c`) to reflect API removal; no new test files introduced. The `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode verifies that submodule ODBs are no longer registered with the main ODB.
