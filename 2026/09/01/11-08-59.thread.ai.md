Subject: [PATCH 0/12] odb: remove ad-hoc source linking
Series version: v1 (initial submission)
Originating author: Patrick Steinhardt
Thread type: patch series

Core problem or goal
Refactor the object database (ODB) subsystem to remove the mechanism allowing registration of in-memory sources (primarily used for submodules). This eliminates dual-use of the ODB sources list for both alternates and temporary sources, simplifying the codebase and preparing for future migration of alternate handling into the "files" backend. The series also continues the broader `the_repository` removal effort by eliminating implicit dependencies on global state in the `cache-tree`, `submodule-config`, and related subsystems.

Current status
Under review; v1 posted 2026-08-31. No prior versions. Series consists of 12 patches: incidental cleanups (removing `the_repository`/`the_hash_algo` dependencies in `cache-tree`, `submodule-config`, and related callers), core refactoring (removing submodule ODB source registration in `submodule-config`, `builtin/grep`, and ODB infrastructure), and final removal of the ad-hoc source linking API. The quarantine directory mechanism remains as the sole exception. Patches 2/12 (removal of `the_repository` in `submodule-config`), 3/12 (removal of `the_hash_algo` in `submodule-config`), 4/12 (removal of the last call to `odb_add_submodule_source_by_path()` in `submodule-config.c`), 5/12 (removal of submodule ODB registration in `builtin/grep.c`), and 6/12 (removal of the submodule ODB source registration infrastructure) are self-reviewed by the author; patch 7/12 (removal of `tmp_objdir_add_as_alternate()` from `tmp-objdir.c`/`tmp-objdir.h`) is now also self-reviewed. No external reviews or objections raised yet.

Key technical details
- Files touched: `odb.c`/`odb.h` (removal of registration API and `submodule_source_paths` field), `submodule-config.c`, `builtin/grep.c`, `tmp-objdir.c`/`tmp-objdir.h`, `t/helper/test-read-midx.c`, `test-ref-store.c`, `cache-tree.c`/`cache-tree.h`, `builtin/checkout.c`, `builtin/commit.c`, `sequencer.c`, `sparse-index.c`, `unpack-trees.c`, plus callers in `builtin/fetch.c`, `builtin/submodule--helper.c`, `submodule.c`, `t/helper/test-submodule.c`, `t/README`, and test scripts.
- Symbols removed: ODB source registration functions (`odb_add_submodule_source_by_path()`, `register_all_submodule_sources()`), `submodule_source_paths` string list in `struct object_database`, `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode (now obsolete), and `tmp_objdir_add_as_alternate()` from `tmp-objdir.c`/`tmp-objdir.h`.
- Symbols modified: `must_prefetch_predicate` callback type extended to accept `void *cb_data` for repository context; all functions in `submodule-config.c` updated to accept `struct repository *` parameter; `hash_oid_string` updated to use the hash algorithm embedded in the object ID.
- Subsystems affected: ODB, submodule handling, grep plumbing, cache-tree, checkout, commit, sequencer, sparse-index, unpack-trees, fetch, submodule helpers, test infrastructure, temporary object directory handling.
- No on-disk format changes; no behavioral changes expected.
- Test coverage: updated test helpers (`test-read-midx.c`, `test-submodule.c`) and test scripts to reflect API removal; the `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode is now a no-op and removed from documentation and test scripts. The test suite passes without failures, confirming the cleanup is complete.
