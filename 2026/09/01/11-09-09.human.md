This is a refactoring patch that adapts the `test-read-midx` helper to work with the new ODB source model introduced earlier in Patrick Steinhardt’s 12-patch series. The series as a whole removes the ability to link ad-hoc object database sources (primarily used for submodules) into the main ODB, simplifying the codebase and preparing for future ODB abstraction work.

This specific patch (10/12) updates `t/helper/test-read-midx.c` to stop relying on the now-removed mechanism for linking sources into the main ODB. Instead of calling `odb_add_to_alternates_memory()` to register a source globally, the helper now creates a standalone `odb_source_packed` instance and manages its lifetime explicitly. The change is mechanical: every function that previously called `setup_midx()` now takes an additional `struct odb_source_packed **` parameter, and the caller is responsible for freeing the source when done.

The patch is clean and well-scoped, touching only the test helper and leaving no loose ends. It maintains the same functionality while aligning with the new ODB source model. No behavioral changes are expected, and the test suite continues to pass. This is a natural follow-up to the earlier patches in the series, which removed the ad-hoc source linking infrastructure from the core ODB and submodule subsystems. If you are following the ODB abstraction effort or the broader `the_repository` removal work, this patch is worth noting as a small but necessary step in that direction.
