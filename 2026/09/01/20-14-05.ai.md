- **Subsystem**: `.gitattributes` handling, textconv filters, checkout process.
- **Trigger**: A global `.gitattributes` file with `* text diff=lfclean` forces Git to treat *all* files (including binaries) as text and apply a CR-stripping filter.
- **Symptoms**: Binary files (PNGs, JPEGs, etc.) become corrupted during checkout, while repository blobs remain intact. No warnings or errors are emitted.
- **Root cause**: The `*` pattern in `.gitattributes` is too broad, and Git lacks safeguards to prevent text filters from being applied to binary files.
- **Reproduction**: Provided via `git show HEAD:file > raw.bin` vs. working-tree file comparison.
- **Workaround**: Restrict `.gitattributes` rules to specific text extensions (e.g., `*.txt`) or explicitly mark binaries (e.g., `*.png binary`).
