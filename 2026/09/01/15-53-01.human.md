This is a test infrastructure bugfix targeting a race condition in the HTTP daemon test helpers. The patch fixes `apply-one-time-script.sh`, a CGI script in `t/lib-httpd/` that modifies responses from `git-http-backend`. The current implementation uses non-atomic shell operations (`test -f` followed by `rm`) to manage a one-shot marker file, which can race under concurrent Apache requests, causing HTTP 500 errors. The fix replaces the non-atomic check with an atomic `rm` operation, ensuring only one request executes the one-time script.

The patch also adds a new test (`t5567-one-time-script.sh`) that directly exercises the helper without a web server, making the race deterministic. The test launches two concurrent requests—one that should trigger the modified response and one that should pass through unmodified—and verifies only one modified response is served. The fix is minimal, confined to the test infrastructure, and addresses a real, observed flake in `t5616.47` on macOS CI runners.
