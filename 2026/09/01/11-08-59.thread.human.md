This thread is about Patrick Steinhardt’s 13-patch series to remove Git’s ad-hoc mechanism for registering in-memory object database (ODB) sources, primarily used for submodules and temporary object directories. The goal is to simplify the ODB subsystem and eliminate implicit dependencies on global state, paving the way for future ODB abstraction work. The series is now in its second version, posted on September 5, 2026, with all patches complete: the first patch was revised to address Junio C Hamano’s feedback, and several new patches were added to encapsulate repository dependencies, remove unused submodule ODB registration infrastructure, and update test helpers.

Junio and Karthik Nayak have both provided substantive reviews, signaling approval of the core refactoring. Junio’s earlier feedback on the first version was positive ("Yay. Very nice."), and Karthik’s reviews of the second version confirm the correctness of the changes, including the elimination of implicit `the_repository` dependencies. The series is uncontroversial and touches multiple subsystems—ODB, submodule handling, cache-tree, and test infrastructure—without introducing on-disk format changes or behavioral regressions. The only breaking change is in `git multi-pack-index --object-dir=`, which now enforces its documented constraint of accepting only alternate directories.
