This is the sixth patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The series is part of his ongoing ODB abstraction effort and continues the broader `the_repository` removal work.

This patch removes the infrastructure that allowed registering submodule object databases as in-memory sources. The mechanism was introduced in 2021 as a transitional step to migrate submodule object access away from treating submodule ODBs as alternates of `the_repository`. With the preceding patches in the series having eliminated the last two callers (`submodule-config.c` and `builtin/grep.c`), this patch deletes the now-unused registration functions (`odb_add_submodule_source_by_path()` and related helpers), the `submodule_source_paths` string list from `struct object_database`, and the `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode, which is now obsolete.

The diff touches `odb.c` and `odb.h` to remove the registration API, updates `t/README` to drop documentation of the test mode, and cleans up its usage from seven test scripts. The patch is mechanical and well-scoped: it removes ~78 lines of code without changing behavior, as the transitional mechanism is no longer needed. The commit message clearly explains the historical context and why the removal is now safe.

This is a clean refactoring that simplifies the ODB codebase and aligns with the series’ goal of eliminating dual-use of the sources list. No external reviews have been posted yet, but the patch looks uncontroversial given the groundwork laid by earlier patches in the series.
