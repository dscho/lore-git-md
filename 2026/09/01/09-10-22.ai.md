The new function allows callers to consult an already-looked-up Bloom filter to determine whether a commit might have modified any paths in the given `rev_info`’s pathspec, avoiding redundant filter lookups.

This split cleanly separates the concerns of filtering and statistics, making the API more reusable for other built-ins like `git last-modified`.
