This is the final patch in a feature series adding `--missing-only` to `git rev-list`. It implements a script-friendly way for GitLab’s Gitaly to list only missing objects in partial clones, avoiding the need to post-process `--missing=print` output.

The patch is clean and well-motivated. It adds the new flag to `builtin/rev-list.c`, documents it in `rev-list-options.adoc`, and includes thorough tests that verify the output format (one OID per line, no `?` prefix) and error handling (rejecting `--count` and `--disk-usage`). The implementation preserves the existing `--missing=` formatting options while filtering out present objects, exactly as the thread consensus settled on.

All substantive review feedback from v1 has been incorporated, and the patch reflects the final design: a separate `--missing-only` flag rather than an enum extension, clear separation of formatting and filtering, and script-friendly output. The tests use `test_cmp` for direct OID verification, covering edge cases and option interactions. No open technical questions remain, and the patch is ready for final review.
