This is a CI/build system patch from Patrick Steinhardt. The "documentation" job in Git's GitLab CI pipeline recently started failing because the `gem` command (needed to install Asciidoctor) was missing. The root cause: Ruby, which provides `gem`, was previously pulled in transitively by `asciidoc`, but an update broke that dependency chain. The fix is simple—explicitly install Ruby in the dependency list. The patch changes one line in `ci/install-dependencies.sh`, replacing `asciidoc` with `asciidoc ruby`.

The commit message is clear and diagnostic: it shows the error, explains why it happened, and points to a successful pipeline run that confirms the fix. No controversy here—this looks like a straightforward, well-motivated fix for a real CI breakage. If you care about Git's documentation pipeline, this patch is worth a quick look; otherwise, it's safe to skip.
