This is the ninth patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) to remove ad-hoc source linking. The series is part of his ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch tightens the behavior of `git multi-pack-index` when users specify an `--object-dir=` that is not an alternate of the current repository. Previously, Git would silently construct an ad-hoc ODB source and link it, even though the documentation explicitly states that the object directory must be an alternate. The patch changes this to fail with an error message, aligning the code with the documented behavior. This is a breaking change, but one that was already implied by the documentation since 2021.

The patch updates `builtin/multi-pack-index.c` to check whether the specified object directory is a known alternate and die if it is not. It also adjusts a test in `t/t5319-multi-pack-index.sh` to retain and reuse a temporary repository that properly links to the object directory, ensuring the test setup remains valid under the new stricter rules.

The motivation is clear: the ad-hoc source linking mechanism is being phased out, and this patch removes one of the last remaining callers outside of test helpers. The change is small but meaningful, as it enforces a documented constraint and simplifies the ODB codebase. The test adaptation is minimal and well-justified. No objections or external reviews have been posted yet.
