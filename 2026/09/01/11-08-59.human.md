This is a refactoring series targeting the object database (ODB) subsystem, authored by Patrick Steinhardt. The goal is to simplify the ODB's internal design by removing the ability to register temporary in-memory sources (like submodule object stores) alongside the list of alternates. Currently, the ODB maintains a single list for both purposes, which complicates reasoning about the code and creates subtle ordering assumptions. The series argues that this dual-use is unnecessary: submodule sources no longer need to be linked into the main ODB, and other use cases can be handled differently.

The series consists of 12 patches. The first few lay groundwork by removing dependencies on `the_repository` and `the_hash_algo` in related subsystems (cache-tree, submodule-config). The core change arrives in patch 6, which removes the infrastructure for registering submodule sources entirely. Later patches clean up fallout: fixing memory leaks, adjusting test helpers, and removing now-unused functions. The cover letter notes that one exception remains—quarantine directories during transactions—but this is an implementation detail of the "files" backend and doesn’t conflict with the broader goal.

The motivation is clear: this refactoring paves the way for a follow-up series that will migrate alternate handling into the "files" backend, addressing performance regressions and design issues.
