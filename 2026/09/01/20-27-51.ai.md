Siddharth Asthana clarifies the actual Gitaly use case: the feature is used in a **single-pass transaction packing workflow**, not iterative onion-peeling. When committing a transaction, Gitaly walks only the quarantine objects (plus new ref tips) with `git rev-list --objects --missing=print --stdin`. Present objects are packed and logged; missing objects (prefixed with `?`) are recorded as transaction dependencies. At apply time, Gitaly checks that these dependencies already exist in the main repository—it does **not** fetch them. The `--missing-only` option eliminates the need to strip the `?` prefix from the output, making the workflow cleaner.
