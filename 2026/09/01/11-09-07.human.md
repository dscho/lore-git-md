This is a bugfix patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) to remove ad-hoc source linking. It plugs a memory leak in the "packed" ODB source that occurs when freeing the source: the code was not closing the source’s packs or multi-pack indices. The leak was previously masked because packed sources were always linked to the main ODB, but future patches in the series will stop this linking, making the leak visible. The fix is a one-line addition in `odb/source-packed.c` that calls `odb_source_close()` before freeing the source’s pack list. The patch is minimal, well-motivated, and clearly tied to the broader refactoring goal. No controversy or external review yet.
