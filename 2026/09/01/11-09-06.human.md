This is a refactoring patch, part of Patrick Steinhardt’s 12-patch series to remove ad-hoc ODB source linking. It is the seventh patch in the series (7/12).

The patch removes the now-unused `tmp_objdir_add_as_alternate()` function from `tmp-objdir.c` and its declaration from `tmp-objdir.h`. The function became dead code when `builtin/receive-pack` switched to ODB transactions in commit bdee7b3013 (July 2026). The change is mechanical: eleven lines deleted, no behavior change, and the commit message clearly explains why the function can be dropped.

This is a clean, uncontroversial cleanup that follows naturally from earlier work in the series. No external reviews have appeared yet, but the patch itself is straightforward and well-justified.
