This is the fifth patch in a six-patch performance series (v4) for the experimental `git last-modified` command. The series aims to speed up queries about the last commit that modified files matching a pathspec by reusing Git’s Bloom filter machinery.

This patch adds a Bloom filter pre-filter to `git last-modified` to discard commits that definitely did not touch any relevant path, avoiding unnecessary tree diffs. The optimization mirrors how `git log` already works: instead of expanding the pathspec into individual paths and checking each one, the command now checks the Bloom filter against the pathspec itself first. If the Bloom filter says "no," the commit is skipped entirely. For `--show-trees`, which tracks parent directories (e.g., "a" and "a/b" for pathspec "a/b/c"), the patch uses the new `revs_maybe_changed_in_bloom_with_parents()` helper to check all keys in the path’s key vector, ensuring no false negatives for directory queries.

The patch is small (12 lines in `builtin/last-modified.c`) and adds a new test in `t/t8020-last-modified.sh` to verify Bloom filter behavior with `--show-trees`. The test explicitly controls `GIT_TEST_COMMIT_GRAPH` to ensure consistent behavior regardless of the test environment, addressing the issue that blocked v3. The pre-filter is a direct performance win: benchmarks in the cover letter show a 3.7× speedup without `--show-trees` and a 1.95× speedup with it, bringing `git last-modified` nearly to parity with `git log`.

The patch is well-motivated and technically sound. It reuses existing Bloom filter infrastructure (`revs_maybe_changed_in_bloom()` and the new `revs_maybe_changed_in_bloom_with_parents()` from earlier patches) and includes test coverage for the `--show-trees` case. The only minor quirk is the naming of `revs_maybe_changed_in_bloom_with_parents()`, which refers to parent directories rather than commit parents, but this is documented in the commit message and not a blocker. The patch is ready for integration and does not affect other Git commands or the on-disk format.
