This is the final clarification in the thread for the `--missing-only` option for `git rev-list`, a feature requested by GitLab's Gitaly team to streamline partial clone workflows. The patch itself is technically complete and has already incorporated all review feedback; this exchange addresses the sole remaining question from Junio C Hamano about the intended workflow.

Siddharth Asthana explains that Gitaly uses the missing-object list in a single, one-shot pass during transaction packing, not as part of an iterative fetch loop. The list serves as a dependency set for transaction validation, not as a backfill mechanism. The `--missing-only` flag simply eliminates the need for post-processing to strip the `?` prefix from the existing `--missing=print` output, making the command more script-friendly. With this clarification, the feature's design and use case are now fully documented and uncontroversial. Expect this to be queued for `next` shortly.
