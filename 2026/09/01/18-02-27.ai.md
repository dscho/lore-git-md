This is the **second half of a two-patch bugfix series** addressing a use-after-free regression in `git stash show` with `--src-prefix`/`--dst-prefix`. The regression was introduced in Git 2.52.0 (commit 3ea35c64b) and causes garbage diff headers (e.g., `diff --git Uf.txt Uf.txt`).

This patch is a **refactoring follow-up** to Jeff King’s earlier fix. It simplifies the `mark_argv_for_free()` helper by moving the `free_removed_argv_elements` flag check into the helper itself, eliminating redundant checks in all callers. The change is purely internal to `revision.c` and has no user-visible impact. The patch consolidates the flag logic into a single place, making the call sites cleaner and reducing the chance of future inconsistencies. The one exception—`setup_revisions_from_strvec()`—always sets the flag explicitly, so the new check is safe even though the caller wasn’t previously checking it.

The patch is **uncontroversial and ready for `maint`**. Junio C Hamano has already endorsed it as a "tiny simplification" that improves readability. The earlier regression fix (which introduced the `argv_to_free` field in `struct rev_info`) is a prerequisite, but this cleanup follows naturally and should be merged alongside it. No new symbols or files are introduced; the patch only adjusts the helper’s signature and updates its callers.

This is a **low-risk, high-value cleanup** that improves code maintainability without altering behavior. If the regression fix is accepted, this patch should be included as well. The series as a whole restores correct diff header output and prevents future regressions in prefix handling.
