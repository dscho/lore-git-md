This is a refactoring patch, part of Patrick Steinhardt’s 12-patch series to remove ad-hoc ODB source linking. It is the eleventh patch in the series, targeting test infrastructure.

The patch removes an unnecessary call to `odb_add_to_alternates_memory()` in the `test-ref-store` helper. The helper supports accessing reference stores of submodules, and previously linked the submodule’s object database into the main repository’s ODB to allow object lookups. However, since the reference subsystem no longer depends on `the_repository`, object lookups are now automatically routed to the correct submodule repository, making the manual linking redundant. The change deletes eight lines from `t/helper/test-ref-store.c` and is purely internal to the test helper.

The motivation is clear: the code being removed is no longer needed and its removal simplifies the test helper by eliminating an obsolete workaround. The patch is a straightforward cleanup with no behavioral changes or external impact. It builds on earlier patches in the series that removed similar ODB registration calls elsewhere, and prepares for the final patch (12/12) that removes the ad-hoc source linking API entirely.
