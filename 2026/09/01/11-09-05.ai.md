This is the sixth patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch deletes the infrastructure that allowed registering submodule ODBs as in-memory sources, a transitional mechanism introduced in 2021 to ease migration away from treating submodule ODBs as alternates of `the_repository`. With all callers of `odb_add_submodule_source_by_path()` now removed by earlier patches in the series, this patch cleans up the remaining scaffolding: the registration API in `odb.c`/`odb.h`, the `submodule_source_paths` string list in `struct object_database`, and the `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode (which is now a no-op and removed from documentation and test scripts).

The patch touches 10 files, removing 78 lines of code. The core changes are in `odb.c` (deleting `odb_add_submodule_source_by_path()`, `register_all_submodule_sources()`, and related logic) and `odb.h` (removing the `submodule_source_paths` field and the registration function prototype). The test suite is updated to stop exporting the now-obsolete `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` variable, and `t/README` drops its documentation. No behavioral changes are expected; the patch is purely a cleanup of dead code.

This is a well-scoped refactoring that directly advances the series’ goal of simplifying the ODB by eliminating dual-use of the sources list. The removal of the test mode confirms the cleanup is complete and no longer needed. The patch is uncontroversial and appears ready for integration, assuming the rest of the series holds up under review. It continues the broader `the_repository` removal effort and Patrick Steinhardt’s ongoing ODB abstraction work.
