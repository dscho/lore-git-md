This is the first patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It specifically removes the `cache-tree` subsystem’s dependency on the `the_repository` global variable, replacing it with explicit repository parameters passed via `struct index_state` or as function arguments.

The patch touches nine files, primarily `cache-tree.c` and its header, where it updates function signatures to accept a `struct repository *` parameter. This change propagates through callers in `builtin/checkout.c`, `builtin/commit.c`, `sequencer.c`, `sparse-index.c`, and `unpack-trees.c`, all of which now pass the repository context explicitly. The `must_prefetch_predicate` callback type is also extended to accept a `void *cb_data` parameter, allowing the repository to be passed through to the predicate function.

The motivation is twofold: first, this continues the ongoing `the_repository` removal effort, and second, it eliminates the last implicit dependency on registering submodule ODB sources with the main repository’s ODB. The commit message notes that this dependency was a historical workaround, and the patch ensures submodule object databases are no longer registered with the main ODB, as verified by the `GIT_TEST_FATAL_REGISTER_SUBMODULE_ODB` test mode.

The changes are mechanical and well-scoped, with no behavioral impact expected. The patch is a prerequisite for later patches in the series that remove the ODB source registration API entirely. Test coverage remains intact, with updates to reflect the new function signatures. This is a clean refactoring that aligns with the project’s long-term goal of eliminating global state.
