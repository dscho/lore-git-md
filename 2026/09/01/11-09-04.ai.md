This is the fifth patch in Patrick Steinhardt’s 12-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch stops `git grep` from registering submodule object databases as in-memory sources of the main ODB, a mechanism that was originally introduced for lazy alternate registration but is no longer necessary.

The change is straightforward: the patch removes the call to `odb_add_submodule_source_by_path()` and the associated locking logic in `builtin/grep.c`. The commit message explains that since commit `0693806bf8` (2021), `git grep` workers already receive submodule repositories directly, making the alternate registration redundant. The only remaining race condition is around subrepository initialization, which still requires the object-read lock.

The diff is clean, removing 20 lines and leaving only the necessary lock for thread-safe subrepository initialization. This aligns with the series’ goal of simplifying the ODB codebase by eliminating dual-use of the sources list. No behavioral changes are expected, and the patch is a logical follow-up to earlier refactoring in the series. The NEEDSWORK comment about submodule sparsity settings remains, but that is outside the scope of this patch.
