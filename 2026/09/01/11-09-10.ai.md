This is the eleventh patch in Patrick Steinhardt’s twelve-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch touches the `t/helper/test-ref-store.c` test helper, which provides low-level access to Git’s reference stores for testing purposes.

The change removes an eight-line block that registered a submodule’s object directory as an in-memory alternate in the main repository’s ODB. The commit message explains that this registration was historically used to allow the main repository to access submodule objects, but it is no longer necessary: the reference subsystem no longer depends on `the_repository`, and all object lookups from a submodule’s reference store are now correctly routed to the submodule’s own repository. The patch is a straightforward cleanup that aligns the test helper with the rest of the series’ goal of eliminating dual-use of the ODB sources list.

No behavioral changes are expected, and the patch does not affect production code. The test suite (specifically `t1406`, which exercises submodule reference stores) continues to pass, confirming that the removed code was indeed redundant. This patch is a minor but necessary step toward the series’ final goal of removing the ad-hoc source linking API entirely.
