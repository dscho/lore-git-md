This is a follow-up discussion in the now-abandoned `[PATCH 0/3] format-patch: add --[no-]range-diff-notes` thread, focusing on the usability and documentation of the proposed toggle mechanism. The exchange between Kristoffer Haugsbakk and D. Ben Knoble clarifies how the `--no-range-diff-notes --range-diff-notes` sequence was intended to work: it acts as a toggle to revert the override behavior, restoring the default state where both patches and range-diffs use the same notes (those specified by `--notes`). For example, if `--notes=review --notes=testing --range-diff-notes=changelog` is used, the range-diff shows only the `changelog` note, but adding `--no-range-diff-notes --range-diff-notes` would restore all three notes to the range-diff.

Kristoffer acknowledges the complexity of this interaction but argues that the flexibility justifies the added conceptual load. He also notes a tangential issue with `format-patch`’s handling of default notes, suggesting it should respect `format.notes` rather than `notes.displayRef`. Ben’s feedback is surface-level, focusing on wording clarity in the documentation and expressing mild concern about the potential for user confusion, though he finds the examples helpful. The discussion remains theoretical, as the feature was abandoned due to Junio C Hamano’s substantive usability concerns about the option semantics. No code changes are proposed here, and the thread is effectively closed. The exchange serves primarily to document the intended behavior for posterity.
