This is a meta-discussion email from Junio C Hamano about the version numbering for the next major Git release after 2.56.

Junio lays out four options for the version number of the release that will follow 2.56 (expected around the end of September 2026): Git 3.0 (a big version bump), Git 2.99 (a transitional release signaling readiness for 3.0 in 2027), Git 2.98/2.97 (delaying the decision further), or simply continuing with Git 2.57 (business as usual). He emphasizes that the decision isn’t a vote but a reflection on the project’s readiness, particularly regarding documented breaking changes.

The email invites the community to assess the state of the `BreakingChanges` document and consider whether the project is prepared for a major version bump. This is a rare but important discussion about Git’s release cadence and versioning philosophy, aimed at aligning expectations for future development.
