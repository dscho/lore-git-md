This is the second patch in the four-part series introducing the `receive-report` hook. The patch refactors how `receive-pack` tracks which status-reporting protocol version (v0 or v2) to use, replacing two static boolean variables with a single `enum report_status_version`. This change is a direct response to Junio C Hamano’s earlier feedback about maintainability and makes the code more explicit and safer by introducing a `REPORT_STATUS_UNKNOWN` sentinel that triggers a `BUG()` if neither version is set.
