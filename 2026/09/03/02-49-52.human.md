This is a feature patch that extends `git var` to subsume the functionality originally proposed in the `git ident` series. Andrew Pleeter has rewritten the patch to address maintainer feedback, abandoning the standalone `git ident` command in favor of enhancing the existing `git var` plumbing command.

The patch teaches `git var` to expose individual identity components (name, email, date) for both author and committer, adds a `GIT_DEFAULT_KEY` variable (with `GIT_SIGNING_KEY` alias) to resolve the configured commit signing key, and allows querying multiple variables in a single invocation. It also adds `-z` support for NUL-terminated output, making the command more script-friendly. The implementation is clean: it parses ident strings into components, resolves signing keys using Git’s existing GPG interface, and maintains backwards compatibility with existing `git var` usage.

The motivation remains the same as in the earlier `git ident` proposal: users currently need to parse `GIT_AUTHOR_IDENT`/`GIT_COMMITTER_IDENT` manually or check multiple `git config` settings to verify their active identity and signing configuration. This patch consolidates that information into a single, scriptable interface without introducing new configuration options or on-disk formats.

The patch is well-structured, with thorough test coverage in `t/t0007-git-var.sh` that exercises the new variables, multi-argument support, and `-z` output. The documentation update is clear and includes examples for the new functionality. The implementation avoids controversial changes, such as modifying existing variable behavior or introducing new globals.

This version directly addresses the maintainer consensus reached in the thread: Junio C Hamano and Jeff King (Peff) both endorsed extending `git var` rather than introducing a new command, and Andrew Pleeter has now delivered that design. The patch looks ready for review, though it may attract discussion about edge cases in the signing-key resolution logic or the handling of environment variable overrides.
