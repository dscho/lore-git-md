This is the final patch in Michael Montalbo’s seven-part series extending `git log -L` to support range-scoped diff options. Patch 7 teaches the `-G` pickaxe to search only within the line ranges specified by `-L`, completing the series’ goal of making common diff filters (`--stat`, `--check`, and now `-G`) respect the tracked range.

The implementation adds a new helper, `diff_emit_line_ranges()`, that wraps `xdi_diff_outf()` and forwards only in-range lines to the caller’s callback. This helper is used in `diffcore-pickaxe.c` when `-G` is active and no textconv driver is involved (textconv output lacks the original line coordinates needed for range filtering, so `-G` falls back to whole-file search in that case). The patch updates the documentation to clarify that `-G` is now range-scoped while `-S` remains whole-file, and adds tests verifying that `-G` matches only in-range changes, correctly handles textconv fallbacks, and ignores changes outside the tracked range.

The patch is cleanly structured and well-tested, with no obvious loose ends. The exclusion of `-S` is noted as future work, and the textconv limitation is documented and tested. This looks like a solid, uncontroversial addition that rounds out the series.
