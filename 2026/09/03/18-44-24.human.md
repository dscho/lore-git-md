This is the first patch in a three-part bugfix series targeting Git's pathspec handling. It is a preparatory refactoring patch originally authored by Junio C Hamano and now carried forward by Yannik Tausch. The patch declares the `match` and `original` fields in `struct pathspec_item` as `const char *` to reflect the fact that these strings are never modified after initialization. The only functional change is in `clear_pathspec()`, where the `free()` calls now cast away the constness to avoid compiler warnings.

The patch is purely mechanical and makes no behavior changes. It is motivated by the need to resolve a compiler warning in the unit test added by the third patch in the series, which initializes these fields with string literals. The change is uncontroversial and aligns with the project's preference for accurate type declarations. This patch is ready for merging and is a prerequisite for the subsequent memory-safety and bugfix patches in the series.
