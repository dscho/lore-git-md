This is the final patch in Michael Montalbo’s seven-patch v3 series extending `git log -L` (line-log) to support range-scoped `-G` pickaxe. The patch teaches `-G` to search only the line ranges specified by `-L`, while explicitly excluding `-S` due to architectural constraints (whole-file search is inherent to its design). The implementation adds a new `diff_emit_line_ranges()` helper in `diff.c` that wraps `xdi_diff_outf()` to forward only in-range lines to the caller’s callback. When textconv is enabled, the patch falls back to whole-file search because textconv output lacks the original line coordinates needed for range tracking. Documentation is updated to clarify the behavior, and tests verify that `-G` matches only in-range changes, including edge cases like textconv fallback and multiple tracked ranges. The patch completes the series’ goal of making common diff options (`--stat`, `--check`, `-G`) work consistently with line-range filtering.
