This is a refactoring patch in the seven-part series extending `git log -L` to support range-scoped diff stat, whitespace checking, and `-G` pickaxe. Specifically, patch 4/7 extracts boilerplate line-range filter setup and execution into reusable helpers: `line_range_filter_init()` and `line_range_filter_diff()`. The patch touches only `diff.c` and makes no behavior changes; it is a pure code reorganization that centralizes the logic for initializing the filter state, inflating `ctxlen` to ensure one xdiff hunk per range, clearing `XDL_EMIT_NO_HUNK_HDR`, running the diff, flushing the final hunk, and cleaning up buffers. Subsequent patches (5–7) reuse these helpers to implement the new range-scoped features. The patch is well-motivated: the extracted logic appears in the existing line-log code path and will be needed again for `--stat`, `--check`, and `-G`. No new symbols are exposed outside `diff.c`; the helpers are static and enforce the same invariants (one hunk per range, hunk headers always emitted) as the original code. The commit message is concise and accurate, and the patch itself is clean and mechanical.
