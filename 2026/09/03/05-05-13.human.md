This is the first patch in Michael Montalbo’s v3 resend of a seven-part series that extends `git log -L` to support range-scoped `--stat`, `--check`, and `-G` pickaxe. The series is part of the ongoing effort to make line-log filtering work consistently with common diff options.

This patch is pure refactoring: it renames the `line_range_callback` struct to `line_range_filter` and clarifies its fields with more descriptive names. The verbose explanatory comment is replaced with a concise one, and some fields are grouped into a nested `accumulating_hunk` struct for better organization. No logical behavior changes are introduced—this is purely about making the code easier to understand as the line-range filter is extended to support more diff options in later patches. The diff is mechanical and well-contained, touching only `diff.c`. If the series as a whole looks worthwhile, this patch is a clean, uncontroversial foundation.
