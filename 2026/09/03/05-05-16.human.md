This is the fourth patch in Michael Montalbo’s v3 series extending `git log -L` to support range-scoped diff stat, whitespace checking, and `-G` pickaxe. The patch extracts boilerplate line-range filter logic into reusable helpers (`line_range_filter_init` and `line_range_filter_diff`) without changing behavior. These helpers centralize the setup and execution of a diff scoped to specific line ranges, making the code cleaner and easier to reuse in subsequent patches that add new diff modes. The extracted logic handles context-length inflation, hunk-header emission, and buffer cleanup, ensuring that only changes within the tracked ranges are processed. This refactoring is a straightforward and well-motivated step toward enabling the later features in the series.
