This is the first patch in Michael Montalbo’s v3 resend of the seven-part series extending `git log -L` to support range-scoped `--stat`, `--check`, and `-G` pickaxe. The patch is purely a refactoring: it renames the `line_range_callback` struct to `line_range_filter` and replaces terse field names (`lno_post`, `rhunk`, `funclen`, etc.) with self-documenting ones (`lno_in_postimage`, `accumulating_hunk`, `func_name_len`). The fields are also reorganized into a nested `accumulating_hunk` struct for clarity. Corresponding function names (`flush_rhunk` → `flush_range_hunk`, `discard_pending_rm` remains but now takes the renamed struct) and local variables follow the same naming scheme. No logical behavior changes are introduced; the patch is purely mechanical and preparatory for the feature additions in later patches. The commit message is concise and clearly states the motivation (improving readability ahead of new functionality) and the absence of functional impact.
