This is patch 5/7 of Michael Montalbo’s v3 series extending `git log -L` to support range-scoped diff stat formats (`--stat`, `--numstat`, `--shortstat`). The patch enables these stat options to honor the tracked line ranges by routing the line-range filter’s output through `diffstat_consume()`. The implementation reuses the helpers introduced in patch 4 (`line_range_filter_init()` and `line_range_filter_diff()`) to avoid code duplication. Documentation is updated to clarify that stat counts reflect only in-range lines and to note the exclusion of `--dirstat` (its default mode measures whole-file churn, making range-scoped counting misleading). Tests verify that stat counts align with the tracked ranges across multiple commits, renames, and multiple tracked ranges, and confirm that `--dirstat` remains rejected with an updated error message. Junio’s feedback from v1 (rewording the documentation to avoid "range-scoped" jargon) is incorporated. The patch is a straightforward extension of the line-range filter infrastructure and appears well-tested.
