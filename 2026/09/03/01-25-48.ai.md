This is Junio’s "What’s cooking" report for September 2026, summarizing the state of 30+ in-flight topics. The report is the primary integration status snapshot for the Git project, showing which topics have graduated to `master`, which are cooking in `next`, which are stalled, and which are new or discarded.

Key technical details for follow-up AI summarization:
- **Graduated to `master`**: Two small patches: a rerere documentation typo fix (`jc/rerere-doc-typofix`) and the libification of the `fetch_if_missing` global variable into `struct repository` (`ty/repository-fetch-if-missing`), which is part of the ongoing `the_repository` removal effort.
- **New topics** (not yet in `next`):
  - `jk/rev-info-argv-to-free`: Memory ownership fix for argv elements passed to the revision machinery, preventing use-after-free bugs.
  - `ps/ci-depends-on-ruby`: CI fix for the documentation job, which now explicitly installs Ruby after the `asciidoc` package stopped pulling it in.
  - `ps/odb-stop-registering-in-memory-sources`: Removes the ad-hoc mechanism for registering in-memory alternate object sources, simplifying ODB management and preparing for alternate tracking migration into the files backend. This is a 13-patch series that builds on `ty/repository-fetch-if-missing`.
  - `jk/ci-use-system-asciidoctor`: CI cleanup to use system asciidoctor instead of gem-pinned versions, removing obsolete Azure Pipelines variables.
  - `jk/submodule-error-leak`: Memory leak fix in `submodule--helper` when repository setup fails.
  - `sa/rev-list-missing-only`: New `--missing-only` option for `git rev-list` to filter output to missing objects (useful with `--missing=print`).
  - `wf/imap-send-draft`: Adds `--draft` option to `git imap-send` to mark uploaded messages as drafts.
  - `yt/pathspec-negative-prefix`: Fixes out-of-bounds memory access when negative pathspecs are shorter than the common prefix of positive pathspecs.
  - `cc/early-scan-options`: Unifies early option scanning in commands like `bisect`, `rev-parse`, and `fast-import` using a new `early_scan_options()` API.
- **Stalled topics** (no activity for weeks/months): `ps/libgit-in-subdir` (causes too many evil merges), `hs/rebase-continue-edit` (waiting for response), `sn/rebase-update-refs-symrefs` (symref handling in rebase), `tb/pack-with-duplicates` (duplicate object handling in packfiles), `cl/regexec-macos-leak` (macOS regex memory leak workaround), and `cc/lazy-fetch-trusted-bit` (lazy fetch configuration for trusted repos).
- **Cooking in `next`** (likely to graduate soon unless issues surface):
  - `tc/replay-linearize`: Adds `--linearize` option to `git replay` to drop merge commits.
  - `rs/worktree-add-basename-fixes`: Fixes out-of-bounds reads and improper slash handling in `git worktree add`.
  - `en/no-amend-during-conflicts`: Teaches `commit --amend` and partial commits to refuse during conflict resolution (like `cherry-pick` and `merge` already do).
  - `kn/reftable-optimize-reloading`: Optimizes reftable stack reloads to avoid unnecessary `newfstatat` syscalls.
  - `en/midx-missing-pack-fallback`: Gracefully recovers when a multi-pack-index points to a removed pack.
  - `mm/lib-httpd-cgi-safe`: Makes HTTP test CGI helpers atomic to prevent race conditions.
- **Notable ongoing efforts**:
  - `ps/odb-alternates-at-creation`: Defer alternates setup to ODB creation time during clone, removing unused ad-hoc alternate writing APIs.
  - `ps/odb-pluggable-fsck`: Moves fsck checks into backend-specific object source layers, making them pluggable.
  - `mm/diff-process-hunks`: Introduces `diff.<driver>.process` to allow external tools to act as hunk providers.
  - `hn/history-squash`: Experimental `git history squash` subcommand to fold a range of commits into one.
- **Discarded topics**: `ps/fetch-packfile-uris-parallel` (retracted for now), `kh/format-patch-range-diff-notes` (retracted), and a few others.

The report also notes that 604 non-merge commits have landed in `master` since Git 2.55, with 49 in `next` and 213 in `seen`. The `seen` branch is ephemeral and rebuilt frequently.
