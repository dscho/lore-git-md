This is a **maintainer clarification** in the `git imap-send --draft` thread, addressing Aditya Garg’s forward-compatibility concern about the libcurl 8.13.0 dependency. Junio C Hamano distinguishes the current patch from Aditya’s 2024 precedent by noting that the `--draft` feature **fails fast** (errors out) when used with older libcurl versions, rather than silently omitting functionality or requiring a newer version to build at all. This aligns with the project’s preference for explicit failure over implicit behavior changes, and it directly responds to Aditya’s surface-level review by highlighting the patch’s built-in compatibility guard.

The clarification does not resolve the broader question of whether a libcurl 8.13.0 dependency is acceptable for new features, but it narrows the discussion to the patch’s actual implementation: the compatibility macro in `git-curl-compat.h` ensures the code compiles on older versions, and the runtime check prevents misuse. This leaves the door open for further debate on the version requirement itself, but removes the "silent breakage" objection that sank Aditya’s 2024 patch. The thread’s other open questions (configuration variable, default flip) remain untouched.
