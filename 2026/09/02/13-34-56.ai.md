This is a cleanup patch in Patrick Steinhardt’s 13-patch series removing ad-hoc ODB source linking. It is the eighth patch in the v2 update, which continues the ODB abstraction effort and the broader `the_repository` removal work.

The patch removes the now-unused `tmp_objdir_add_as_alternate()` function from `tmp-objdir.c` and its declaration from `tmp-objdir.h`. The function became obsolete after commit bdee7b3013 (July 2026) switched `builtin/receive-pack` to use ODB transactions instead of registering temporary object directories as alternates. The removal is a straightforward cleanup: the function had no remaining callers, and its deletion does not affect any other part of the codebase.

The diff is minimal—eleven lines removed across two files—reflecting the function’s narrow scope. No behavioral changes are introduced, and the patch is uncontroversial: it merely tidies up infrastructure that was already made redundant by prior work. The commit message is clear and cites the specific commit that rendered the function unused, making the rationale easy to verify.

This patch is part of the series’ broader goal of simplifying the ODB subsystem by eliminating dual-use of the sources list for both alternates and temporary in-memory sources. It directly follows the removal of submodule ODB registration in earlier patches and precedes the final deletion of the ad-hoc source linking API in patch 13/13. The series as a whole is under review, with Junio C Hamano’s earlier substantive approval of key patches suggesting the refactoring is on track for `next`.
