This is the tenth patch in Patrick Steinhardt’s 13-patch series removing ad-hoc ODB source linking. It enforces a long-documented constraint in `git multi-pack-index --object-dir=`: the specified object directory must be an alternate of the current repository. Previously, Git would silently create an ad-hoc source and link it to the main ODB, contradicting the documentation and creating the last real-world caller of the ad-hoc source mechanism outside test helpers. The patch replaces this behavior with an explicit error message and updates one test chain in `t5319-multi-pack-index.sh` to retain a temporary repository (`repo64`) that provides the required alternate relationship.

The change is a breaking change in the strictest sense, but it aligns with documented behavior since 2021 and removes the only remaining non-test caller of the ad-hoc source API, clearing the way for its complete removal in patch 13/13. The commit message is clear and thorough, explaining both the rationale and the test adaptation. No new technical risks are introduced; the patch is a straightforward enforcement of an existing constraint.
