This is a refactoring patch, part of Patrick Steinhardt’s larger series to remove ad-hoc ODB source linking. It is the fourth patch in the v2 series (13 patches total), which is under review and continues the ongoing `the_repository` removal effort.

The patch eliminates two remaining uses of the global `the_hash_algo` in `submodule-config.c`. The first is a straightforward conversion: `gitmodules_cb` now uses the repository’s hash algorithm (`repo->hash_algo`) instead of the global. The second is more subtle: `hash_oid_string` now derives the hash length from the object ID’s embedded algorithm (`oid->algo`) rather than `the_hash_algo`. A defensive check ensures the object ID is properly initialized, guarding against potential bugs elsewhere.

The change is mechanical and safe: both sites already have access to the necessary context (the repository or the object ID), so the patch simply stops reaching for the global. The commit message explains the rationale clearly and justifies the defensive check. No behavior change is expected, and the patch is a clean step toward eliminating implicit global state.
