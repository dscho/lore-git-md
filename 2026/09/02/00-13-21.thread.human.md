This thread is about adding a `--draft` option to `git imap-send` so that messages uploaded to an IMAP server can be marked with the `\Draft` flag, making them editable in IMAP clients. Wolfgang Faust proposed the feature in a single patch that touches `imap-send.c`, its man page, and a compatibility header. The patch is under review and introduces a new `--[no-]draft` flag (defaulting to `--no-draft` to avoid breaking existing workflows) while using libcurl’s `CURLOPT_UPLOAD_FLAGS` to set the draft flag when available.

Junio C Hamano reviewed the patch and suggested improvements, including failing fast rather than warning when `--draft` is used with older libcurl versions (which Wolfgang agreed to implement). Junio also floated the idea of a configuration variable (e.g., `imap.draft`) but did not insist on it, and Wolfgang expressed hesitation about adding one at this stage. The discussion later clarified that the project’s informal guideline—introducing new behavior via flags before configuration—is rarely followed, but Wolfgang’s approach aligns with it. The thread is now waiting for an updated patch to implement the fail-fast behavior, with no changes to the default or configuration plans. No test coverage has been added yet, and the feature remains under review.
