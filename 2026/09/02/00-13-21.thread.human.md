This thread introduces a small but practical feature for `git imap-send`: a `--draft` option that marks uploaded messages with the IMAP `\Draft` flag. The change addresses a long-standing usability issue where messages uploaded to a "Drafts" folder weren't properly recognized as drafts by some IMAP clients, making them appear uneditable or unsendable.

The implementation is straightforward and self-contained, touching only the `imap-send` command, its man page, and a compatibility header. It uses libcurl's new `CURLULFLAG_DRAFT` flag when available (libcurl 8.13.0+) and falls back gracefully with a warning on older versions. The patch is well-scoped and doesn't interact with other Git subsystems, though it lacks automated tests—manual testing should suffice given the narrow functionality.

So far, the thread consists only of the patch submission from Wolfgang Faust. No reviews or maintainer feedback have appeared yet, so the feature's acceptance and any requested changes remain open.
