This is the twelfth patch in Patrick Steinhardt’s 13-patch series removing ad-hoc object database (ODB) source linking. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch updates the `test-ref-store` helper to stop registering submodule object databases as alternates in the main repository. The helper allows testing reference stores in submodules, but the existing code unnecessarily links the submodule’s ODB into the main repository’s ODB. As the reference subsystem no longer depends on `the_repository`, all object lookups are now correctly routed to the submodule’s repository without this linkage. The patch removes the call to `odb_add_to_alternates_memory()`, simplifying the code and aligning with the series’ goal of eliminating ad-hoc source registration.

The change is confined to `t/helper/test-ref-store.c` and deletes eight lines. No new functionality is added; the helper’s behavior remains unchanged. This is a cleanup patch that prepares for the final removal of the ad-hoc source registration API in patch 13/13. The patch is uncontroversial and appears well-motivated, with no expected impact on test coverage or functionality.
