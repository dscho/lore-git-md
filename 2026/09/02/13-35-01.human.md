This is the final patch in Patrick Steinhardt’s 13-part series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The patch deletes the `odb_add_to_alternates_memory()` function from `odb.c` and `odb.h`, completing the cleanup begun in earlier patches. With all callers already updated to manage ODB sources explicitly, this function is now unused and its removal simplifies the codebase by ensuring the ODB sources list contains only the primary source and its alternates—no more temporary in-memory sources.

The change is mechanical and uncontroversial: 14 lines of code are removed, and the commit message confirms the series’ broader goal of paving the way for moving alternate handling into the "files" backend. This patch depends on all prior work in the series (especially patches 11 and 12, which updated test helpers to stop using the function) and is the logical endpoint of the refactoring. No behavioral changes are expected, and the patch is ready for integration once the rest of the series is reviewed. Junio’s earlier substantive approval of related patches suggests this will land smoothly.
