This is a small but useful feature patch for `git imap-send`, adding a `--draft` option to mark uploaded messages with the IMAP `\Draft` flag. The patch itself is well-crafted: it touches only three files, includes clear documentation, and handles older libcurl versions gracefully with a fallback warning. Junio’s review raises two practical questions about the design.

First, he asks whether email clients that currently send messages from the Drafts folder without the `\Draft` flag would misbehave if they encounter messages *with* the flag. This is a real-world compatibility concern that could influence whether the default should eventually flip to `--draft` (with `--no-draft` as an escape hatch). Second, he suggests making the behavior on older libcurl versions more visible—either by erroring out or at least warning—rather than silently ignoring the option. He also floats the idea of a configuration variable, though this seems like a minor follow-up rather than a blocker.

The patch is narrowly scoped and addresses a clear usability gap. The discussion so far is constructive and focused on edge cases, not fundamental objections. If the author clarifies the client-compatibility question and tightens the older-libcurl behavior, this looks like a straightforward improvement worth merging.
