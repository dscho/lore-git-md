This is the second patch in Jeff King’s two-part CI/build system series (`peff/ci-asciidoctor-bump`), which updates GitLab CI’s documentation job to modernize Asciidoctor version testing. The patch replaces the manual `gem install` of a pinned Asciidoctor 1.5.8 with a system package installation, letting the CI environment use whatever version Ubuntu provides. Jeff confirms this works in GitHub Actions (which currently ships Asciidoctor 2.0.20) and argues that testing an arbitrary recent version is more representative of what users actually run locally.

The change is small and mechanical: it removes the explicit `gem install` line and adds `asciidoctor` to the `apt-get` command, making the Ruby dependency redundant but keeping it for clarity. The patch is uncontroversial and follows naturally from the earlier discussion that identified the version pin as outdated. No objections have been raised, and the series is likely to be merged once Patrick Steinhardt or Junio C Hamano review it. The only loose end is whether the `concurrent-ruby` gem is still needed, but that question is independent of this patch.
