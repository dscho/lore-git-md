This is a small feature patch for `git imap-send`. It adds a `--draft` option that marks uploaded messages with the IMAP `\Draft` flag, addressing a long-standing usability gap: the tool's documented purpose is to upload draft emails, but until now it had no way to signal that status to IMAP clients, causing some clients to treat the messages as uneditable or unsendable even when stored in a "Drafts" folder.

The implementation is straightforward. The patch adds the new command-line flag (`--[no-]draft`), updates the man page with a note about libcurl version requirements (8.13.0 or later for the flag to work), and introduces a compatibility macro in `git-curl-compat.h` to guard the new `CURLOPT_UPLOAD_FLAGS` feature. In the IMAP code path, the flag is passed as part of the APPEND command; in the libcurl path, it uses the new `CURLULFLAG_DRAFT` upload flag when available, falling back to a warning on older libcurl versions.

The patch touches three files: the man page, the compatibility header, and the main `imap-send.c` source. It is self-contained and does not interact with other Git subsystems. The commit message clearly states the motivation and the change is well-scoped. No tests are included, but the functionality is narrow enough that manual testing should be sufficient for review. The libcurl version check ensures graceful fallback, so there is no risk of breakage on older systems.
