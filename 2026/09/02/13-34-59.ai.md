This is a test infrastructure patch, part of Patrick Steinhardt’s 13-patch series removing ad-hoc object database (ODB) source linking. The series is under review (v2 posted 2026-09-05) and targets the ODB subsystem as part of the broader ODB abstraction and `the_repository` removal efforts.

The patch updates `t/helper/test-read-midx.c` to stop linking temporary ODB sources into the main object database. Previously, the test helper used `odb_add_to_alternates_memory()` to register arbitrary object directories as alternates, a mechanism the series is eliminating. The new implementation creates a standalone `odb_source_packed` for the specified object directory and manages its lifecycle explicitly, calling `odb_source_free()` when done. This change aligns the test helper with the series’ goal of simplifying the ODB sources list to contain only alternates, not temporary sources.

The diff is mechanical: the `setup_midx()` function is updated to accept an output parameter for the newly created `odb_source_packed`, and all callers are adjusted to pass a pointer and free the source after use. The patch adds 31 lines and removes 12, primarily boilerplate for source management. No behavioral changes are expected; the test helper’s functionality remains identical.

This patch is the 11th in the series and depends on earlier refactoring (patches 1–10) that removed implicit dependencies on the ad-hoc source mechanism. It prepares the test infrastructure for the final removal of the registration API in patch 13/13. The series has received substantive approval from Junio C Hamano on key patches (1/13 and 6/13 in v1), and this patch is uncontroversial—it merely updates a test helper to match the new ODB architecture.
