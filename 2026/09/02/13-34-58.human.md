This is the tenth patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It enforces a long-documented constraint in `git multi-pack-index`: the `--object-dir=` option must point to an alternate of the current repository, not an arbitrary directory.

The patch changes behavior by rejecting unknown object directories instead of silently constructing an ad-hoc ODB source and linking it to the main database. This aligns the implementation with the documentation (unchanged since 2021) and removes the last real-world caller of the ad-hoc source mechanism outside test helpers. The change is small (three lines in `builtin/multi-pack-index.c`) but significant: it breaks a previously working (if undocumented) use case, though the commit message argues the use case was of questionable value.

The test adaptation in `t/t5319-multi-pack-index.sh` is straightforward: it retains the temporary repository (`repo64`) created earlier in the test chain and reuses it for subsequent operations, ensuring the object directory remains a valid alternate. The patch is well-motivated and uncontroversial; it clears the way for the final removal of the ad-hoc source linking API in patch 13/13. No objections or review comments have surfaced yet.
