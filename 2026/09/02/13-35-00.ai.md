This is the twelfth patch in Patrick Steinhardt’s 13-patch series removing ad-hoc ODB source linking. It updates the `test-ref-store` helper to stop registering submodule object databases as alternates in the main repository’s ODB.

The patch removes eight lines from `t/helper/test-ref-store.c` that previously linked a submodule’s object directory into the main ODB via `odb_add_to_alternates_memory()`. The commit message explains that this registration is now unnecessary: when the test helper creates a submodule reference store, it first initializes the submodule repository, and the reference subsystem (now free of `the_repository` dependencies) routes all object lookups to the correct repository automatically. The change aligns the test helper with the series’ broader goal of simplifying the ODB sources list by eliminating dual-use for alternates and temporary sources.

No behavioral changes are expected; the test helper’s functionality remains identical. The patch is a prerequisite for the final patch (13/13), which removes the `odb_add_to_alternates_memory()` API entirely. It touches only the test helper and has no impact on production code. The series’ earlier patches have already ensured that submodule repositories are properly initialized and that the reference subsystem no longer relies on global state, making this cleanup safe.
