This is a small feature patch for `git imap-send`. The tool, which uploads patches or emails to an IMAP folder for later sending, now gains a `--draft` option that marks uploaded messages with the IMAP `\Draft` flag. Without this flag, some email clients treat the message as final and refuse to edit or send it, even if it lands in a "Drafts" folder. The patch updates the man page, adds a libcurl compatibility check (the feature requires libcurl 8.13.0, released April 2025), and wires up the flag in both the legacy IMAP code path and the newer libcurl-based one. The change is well-motivated, backward-compatible, and includes a runtime warning if the user requests `--draft` but has an older libcurl. No controversy is evident.
