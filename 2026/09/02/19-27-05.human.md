This is an announcement email for the latest edition of *Git Rev News*, the monthly digest of Git development activity.

The 138th edition, published on August 31, 2026, is now available at [git.github.io/rev_news/2026/08/31/edition-138](https://git.github.io/rev_news/2026/08/31/edition-138). Christian Couder, one of the editors, credits Simone Arpe, Štěpán Němec, D. Ben Knoble, and Tuomas Ahola for their contributions to this issue. The email also notes that an issue for the next edition is already open for contributions.

*Git Rev News* is a community-driven effort to summarize recent mailing list discussions, notable patches, and project developments in a more accessible format. This announcement is purely informational—no code changes or technical discussion are involved. If you follow Git development but don’t have time to read every mailing list thread, this digest is a good way to stay informed.
