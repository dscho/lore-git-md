This is the eleventh patch in Patrick Steinhardt’s 13-patch series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. The series is part of the ongoing ODB abstraction effort and continues the `the_repository` removal work.

This patch updates the `test-read-midx` helper to stop linking temporary ODB sources into the main object database. Previously, the helper used `odb_add_to_alternates_memory()` to register a multi-pack index (MIDX) from an arbitrary object directory as an in-memory alternate, which the series is eliminating. The new version creates a standalone packed ODB source (`odb_source_packed`) and manages its lifecycle explicitly, freeing it after use. The change is mechanical and preserves the helper’s functionality while aligning with the series’ goal of simplifying ODB source management.

The patch touches only `t/helper/test-read-midx.c`, adding 31 lines and removing 12. It introduces a new `struct odb_source_packed **out` parameter to `setup_midx()` to return the created source, and updates all callers to free the source after use. The change is a direct consequence of earlier patches in the series that remove the infrastructure for ad-hoc source linking, and it ensures the test helper remains functional without relying on deprecated APIs.

This is a test infrastructure patch with no user-visible impact. It is uncontroversial and appears well-executed, with clear commit message and code changes. The patch is a prerequisite for the final removal of the ad-hoc source linking API in patch 13/13. No review feedback has been posted yet.
