This is a bugfix patch in Patrick Steinhardt’s 13-part series refactoring the object database (ODB) subsystem to remove ad-hoc source linking. It plugs a memory leak in the packed ODB source backend that would surface once later patches stop linking temporary packed sources into the main ODB.

The leak occurs when freeing a `struct odb_source_packed`: the code currently frees the list of packfiles but does not close the source itself, leaving its packs and multi-pack indices open. The fix is a one-line addition—`odb_source_close(source)`—that ensures all resources are released. The patch is minimal, well-motivated, and clearly tied to the broader series goal of eliminating dual-use of the ODB sources list. No behavioral changes are expected beyond fixing the leak, and the commit message explains the timing (the issue only becomes visible after later patches remove the automatic linking). This is a prerequisite for the rest of the series and looks uncontroversial.
