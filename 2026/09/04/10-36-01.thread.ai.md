Originating author: Patrick Steinhardt
Thread type: patch series (refactoring/cleanup)

Core problem or goal
Git currently uses inconsistent terminology for the "ref storage format" across CLI options (`--ref-format=`), repository extensions (`refStorage`), environment variables (`GIT_REFERENCE_BACKEND`), and documentation. This series renames all instances to "ref storage" for consistency, preparing for an analogous "object storage" extension. It also centralizes URI parsing for reference storage backends, enabling `--ref-storage=` to accept URIs like `files://path/to/repo`.
