This is a bug report resolution. The thread identifies the root cause of the Git 2.55.0 regressions on macOS reported by Ramkumar Ramachandra: **CrowdStrike Falcon**, a security software, was interfering with Git operations. The symptoms—`git pull` failing with "dangling remote ref", `git diff` exiting cleanly despite a dirty worktree, and `git checkout -` failing after a pull—were all traced to this environmental factor rather than a bug in Git itself.

The resolution came after Ramkumar checked with workplace IT and confirmed the presence of CrowdStrike Falcon, which had been installed recently. This explains why the issues were isolated to the reporter’s environment (no similar reports from other users, including brian m. carlson, who uses the same platform) and why they manifested only in the large `llvm/llvm-project.git` repository—likely due to the security software’s interaction with high-concurrency Git operations or filesystem activity.

The thread is now closed, with no further action needed on Git’s side. The earlier investigative steps, such as migrating to the reftable ref backend, are no longer relevant. This outcome underscores the importance of considering environmental factors, especially security software, when diagnosing seemingly platform-specific regressions.
