This is the tenth patch in Patrick Steinhardt’s 11-patch series unifying Git’s terminology for "ref storage." It renames the configuration key `init.defaultRefFormat` to `init.defaultRefStorage` while retaining the old name as a backward-compatible alias.

The change is mechanical: the patch updates the config key in `setup.c`, three documentation files (`BreakingChanges.adoc`, `config/feature.adoc`, and `config/init.adoc`), and the test script `t/t0001-init.sh`. The test updates are straightforward, replacing the old config key with the new one in test cases that verify precedence rules and error messages. The backward-compatible alias ensures that existing scripts or tools relying on `init.defaultRefFormat` continue to work without disruption.

This patch is part of the series’ broader goal of cleaning up inconsistent terminology ahead of the upcoming object storage extension. The motivation is clear, the implementation is clean, and the backward-compatibility alias addresses potential concerns about breaking existing workflows. No functional changes are introduced—only the config key name and its documentation references are updated. The patch is uncontroversial and aligns with the series’ overall direction.
