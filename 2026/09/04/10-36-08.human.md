This is the seventh patch in Patrick Steinhardt’s 11-patch series to unify Git’s reference storage terminology. It extracts the URI-parsing logic from `setup.c` into a new public function `ref_storage_format_by_uri()` in `refs.c` and exposes it via `refs.h`. The function parses URIs in the form `<format>[://<payload>]` and returns the corresponding `enum ref_storage_format` along with an allocated payload string.

The patch is a straightforward refactoring: it moves the existing `parse_reference_uri()` helper into `refs.c`, renames it to `ref_storage_format_by_uri()`, and updates all call sites in `setup.c` to use the new function. The change is mechanical and does not alter behavior, but it centralizes URI parsing in the refs subsystem, making it reusable for future patches that will add more URI-aware sites (e.g., command-line options). The commit message is concise and the diff is clean, suggesting this is a well-contained preparatory step for the series’ larger goal.
