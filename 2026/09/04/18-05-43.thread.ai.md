Thread identity: bug report for Git 2.55.0 on macOS, originating from Ramkumar Ramachandra (artagnon@gmail.com). Thread type: regression report; closed with root-cause identification.

Core problem or goal: user reported three distinct behavioral regressions in Git 2.55.0 (Homebrew) on macOS: (1) `git pull` failing with "dangling remote ref", (2) `git diff` exiting 0 with no output despite a dirty worktree, and (3) `git checkout -` failing with "invalid ref" after a pull. The regressions were isolated to `llvm/llvm-project.git` (30M+ lines, high update frequency) and initially suspected to be Git bugs or race conditions triggered by repository scale or concurrency.

Current status: **closed**; root cause definitively identified as interference from CrowdStrike Falcon security software. The interference stems from Falcon's real-time file scanning racing against Git's high-frequency operations (ref updates, worktree modifications, network fetches) in large, high-churn repositories. No Git regression, ref backend issue, or environmental factor (e.g., hardware) was responsible. Ramkumar confirmed the resolution after exhaustive testing ruled out Git code paths, repository-specific edge cases, and other environmental factors. The thread remains closed with no action required from the Git project.

Key technical details: commands involved: `git pull`, `git diff`, `git checkout -`; platform: macOS; distribution: Homebrew Git 2.55.0 (Ramkumar), self-compiled Git from `next` branch (Ben Knoble); repository: `llvm/llvm-project.git` (30M+ lines, high concurrency, Ramkumar), smaller repositories (Ben Knoble). Root cause: CrowdStrike Falcon's real-time file scanning colliding with Git's rapid operations, particularly in large repositories with high update frequency. No new symbols, files, or on-disk format changes. Ref backend migration (files -> reftable) was tested but found unrelated. Key context for future reference: CrowdStrike Falcon interference is more likely in repositories with 30M+ lines and high update frequency, especially on macOS with high-speed storage and networking.

Open questions and loose ends: none. All prior open questions (repository scale, concurrency, ref backend, environmental factors) are resolved.
