This thread is a bug report from Ramkumar Ramachandra about four behavioral anomalies in Git 2.55.0 on macOS after a Homebrew upgrade. The issues include a positive change in `git replay` (now updating refs as expected), alongside three regressions: `git pull` failing with "dangling remote ref" errors, `git diff` occasionally exiting silently despite a dirty worktree, and `git checkout -` sporadically failing with "invalid ref" after a pull.

So far, only brian m. carlson has responded, suggesting the problems might stem from environmental factors like security software, disk issues, or ref backend configuration rather than a systemic bug in Git. They recommend testing with the reftable backend to rule out ref storage issues but haven’t reproduced the problems themselves. No root cause has been identified, and the thread remains open with no clear path to resolution. If you’re running Git 2.55.0 on macOS, keep an eye on this thread—especially if you use Homebrew or encounter similar symptoms.
