This thread opened as a bug report for three troubling regressions in Git 2.55.0 on macOS—`git pull` failing with "dangling remote ref," `git diff` silently exiting despite a dirty worktree, and `git checkout -` sporadically failing after a pull—all observed in the massive `llvm/llvm-project.git` repository. Ramkumar Ramachandra, the reporter, initially suspected Git itself, testing whether the ref storage format (files vs. reftable) might be the culprit. However, the root cause turned out to be external: CrowdStrike Falcon, a workplace-installed security software, was interfering with Git’s filesystem operations. With this identification, the thread is now closed, and no changes or further investigation are needed from the Git project. The case highlights how security software can mimic Git regressions, especially in large repositories with high concurrency.
