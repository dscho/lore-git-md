This is patch 9/11 in Patrick Steinhardt’s v1 series to unify Git’s reference storage terminology. The patch renames the environment variables `GIT_REFERENCE_BACKEND` and `GIT_DEFAULT_REF_FORMAT` to `GIT_REF_STORAGE` and `GIT_DEFAULT_REF_STORAGE`, respectively, while retaining the old names as backward-compatible aliases. Karthik Nayak’s review points out a minor oversight: the patch adds the new `GIT_REF_STORAGE` macro to `environment.h` but omits the corresponding `GIT_DEFAULT_REF_STORAGE_ENVIRONMENT` macro, which would be needed for consistency and future-proofing.

The patch itself is a straightforward mechanical rename across `setup.c`, documentation, and six test scripts. It updates all references to the old variables, adjusts error messages, and ensures the precedence logic in `setup.c` checks both old and new environment variables. The backward-compatibility layer is well-implemented, so scripts or tools relying on the old variable names will continue to work. Karthik’s observation is surface-level but valid—adding the missing macro would align with the series’ goal of thorough consistency. The fix is trivial and unlikely to introduce new issues. This patch is part of a larger, well-motivated cleanup effort and looks ready for iteration.
