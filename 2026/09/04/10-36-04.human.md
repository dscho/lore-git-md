This is the third patch in Patrick Steinhardt’s 11-patch series to unify Git’s terminology around "ref storage" instead of the inconsistent "ref format." It updates the `git refs` built-in command—specifically the `migrate` subcommand—to rename the `--ref-format=` option to `--ref-storage=`, while retaining the old name as a hidden backward-compatibility alias.

The patch touches six files: the `git-refs` man page, `builtin/fetch.c` (one error-message update), `builtin/refs.c` (usage strings, option parsing, and help text), and three test scripts (`t1423-ref-backend.sh`, `t1460-refs-migrate.sh`, and `t7424-submodule-mixed-ref-formats.sh`). The changes are mechanical: every occurrence of `--ref-format=` is replaced with `--ref-storage=`, and the old option is kept as a hidden alias so existing scripts continue to work. The test updates ensure the new option name is exercised in all the same scenarios.

This is a straightforward refactoring that aligns with the series’ goal of consistent terminology. The backward-compatibility alias should prevent breakage, and the test coverage looks thorough. No behavioral changes are introduced—only option names and help text. If the series as a whole is accepted, this patch is likely uncontroversial.
