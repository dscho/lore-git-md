My original version of test_oid_cache() actually allowed for that by

test_oid_cache () {
```
    while read tag rest
    do
        case $tag in \#*) continue ;; esac

        for x in $rest
        do
            eval "test_oid_${tag}_${x%:*}=${x#*:}"
        done
    done
```

}

```diff
--- >8 ---

```
