Hi all,

This is a ONE-TIME announcement of Gitwin - a Git Server for Windows:

Gitwin is a packaging of Git, OpenSSH, Nginx and many other related tools to make it a ready-to-use
solution as a secure git repository on Windows. It supports SSH and HTTP(S) transports as well as
Gitweb with Highlighter and Gravatar support. A free edition is available.

Please visit https://itefix.net/gitwin for more information
