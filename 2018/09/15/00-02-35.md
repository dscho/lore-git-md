**Thread**: [thread](./00-02-34.thread.md#:~:text=2018/09/15/00-02-35)

Where ever there was code in the tests like this:

```
	foo \
		| bar

```

such as:

```
	git rev-list HEAD \
		| grep $COMMIT

```

replace it with this:

```
	foo |
	bar

```

And add a blank line before and after the pipe where it aids readability
(it usually does).
