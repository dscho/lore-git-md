In C enum values aren't the types of the enum, but I'd thought someone
would have added a warning for this:

```
    #include <stdio.h>

    enum { A, B } foo = A;
    enum { C, D } bar = C;

    int main(void)
    {
        switch (foo) {
          case C:
            puts("A");
            break;
          case B:
            puts("B");
            break;
        }
    }

```

But none of the 4 C compilers (gcc, clang, suncc & xlc) I have warn
about it. Good to know.
