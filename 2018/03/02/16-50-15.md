The attachment contains an archive of all local Mind Maps and related data.
This archive can also be used to transfer Mind Maps between SimpleMind editions.
Importing this archive will not overwrite maps, but instead will add the contained Mind Maps to the maps already present.
Send this message to yourself and after receiving it, you can import the archive into SimpleMind.
Note that import only works with paid SimpleMind editions or SimpleMind+ upgraded to full functionality via In-App Purchase.
