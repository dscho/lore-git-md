On what git version? On my 2.16.2.804.g6dcf76e118 on git.git this works
as expected:

```
    $ git -c grep.patternType=basic log --oneline -50 --grep="*" |wc -l
    50
    $ git -c grep.patternType=basic log --oneline -50 | wc -l
    50
```
