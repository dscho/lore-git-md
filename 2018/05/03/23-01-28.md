**Thread**: [thread](./../../04/27/22-29-26.thread.md#:~:text=2018/05/03/23-01-28)

When a user provides a todo list containing something like

```
	reset [new root]
	merge my-branch

```

let's do the same as if pulling into an orphan branch: simply
fast-forward.
