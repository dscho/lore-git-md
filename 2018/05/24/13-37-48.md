$ git log -h
usage: git log [<options>] [<revision-range>] [[--] <path>...]
```
   or: git show [<options>] <object>...

    -q, --quiet           suppress diff output
    --source              show source
    --use-mailmap         Use mail map file

    -L <n,m:file>         Process line range n,m in file, counting from 1
```

$
