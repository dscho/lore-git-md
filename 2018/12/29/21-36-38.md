> The last one is not a test but a clean-up.  If any of the earlier

> Instead, do it like so:

> ```

>                 test $old = $new &&
>                 test $flag = 1
>         '

> ```
>

> file that may be left behind to arrange that it will be cleaned at

> has "rm -f .git/post-checkout.args" at the end.
