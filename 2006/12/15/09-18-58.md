I think "git show ${tag}" should be more like "git show ${commit}",
that is, with the tagger and date information and the indent, as:

$ git show v1.4.4.2
tag v1.4.4.2
Tagger: Junio C Hamano <junkio@cox.net>
Date: ${Date}
