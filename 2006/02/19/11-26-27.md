You might want to try something more like:

```diff
+	for (i = 1 ; i < argc; i++) {
+	    if ( !strcmp(argv[i], "--help") )
+		usage(rev_list_usage);
+	    if ( !strcmp(argv[i], "--") )
+		break;
+	}

```

So that you don't break in the perverse but legal case of
having a file named "--help".
