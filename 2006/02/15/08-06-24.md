> behavior with "git reset --hard". It appears that if the current tree

> 	$ git --version

> 	$ git reset --hard OLD
> 	$ find a
> 	a
> 	a/b
> 	a/b/c
> 	$
>
> ```
>
> Is this operator error? I don't see any extra options I might be
> missing in the documentation of git-reset.
