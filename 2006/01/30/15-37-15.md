A simple workaround would be to install git in a directory not in your
path and put a shell script "sct" in your path that just calls git.
Something like (untested):

```
  #! /bin/sh
  # sct: call git
  gitpath=/path/to/git
  export PATH=$gitpath:$PATH
  exec $gitpath/git $*

```
