**Thread**: [thread](./23-41-17.thread.md#:~:text=2006/09/22/23-41-17)

If in branch "foo" and this in config:

[branch "foo"]
       merge=bar

"git fetch": fetch from the default repository and program the "bar"
             branch to be merged with pull.
