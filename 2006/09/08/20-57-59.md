Yet another committag:

```
        'URL' => { # simple URL, no query strings
                   # because of the whole esc_html() + ' '->'&nbsp;' thing
                'pattern' => qr!(http|ftp)s?://[a-zA-Z0-9%./]+!,
                'sub' => sub {
                        my $url = shift;
                        return
                                $cgi->a({-href => $url},
                                        $url); # should be perhaps shortened
                },
                'islink' => 1,
        },
```
