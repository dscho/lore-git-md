I was wondering if anyone else thinks that git-status should be more
like "git-diff --name-status". That is,
```
  # A a/newfile.c
  # M a/oldfile.c

```

instead of
```
  # new file: a/newfile.c
  # modified: a/oldfile.c

```

This would be similar to cg-status and "svn status", etc.
