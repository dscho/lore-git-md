**Thread**: [thread](./02-31-02.thread.md#:~:text=2017/04/16/02-31-02)

Structure calls as

```
    test_expect_success 'description' '
    	body
    '

```

Use double quotes for the description if it requires parameter
expansion or contains a single quote.
