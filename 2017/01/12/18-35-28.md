The result becomes

```
	if (...)
		single statement;
	else if (...) {
		multiple;
                statements;
        }

```

which is not quite an improvement.  

The preferred style is for all arms in if/elseif/else cascade to
either use or not use brace pairs, so I think a fix toward that goal
would be more like:

```
	if (!commit->parents) {
		parent = NULL;
```

-	}                
-	else if (commit->parents->next) {
