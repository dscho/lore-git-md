The preferred style in tests seems to be

test_expect_success 'short description, ended by 2 single quotes' '
```
	here comes the test &&
	and chains over many lines &&
	ended by a quote
```

'

Or going by the numbers:
```
    $ git -C t/ grep "' '$" | wc -l
    9796
    $ git -C t/ grep test_expect_ |wc -l
    11861

```
