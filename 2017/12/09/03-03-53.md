    git commit --onto-parent A

... hopefully ending up in the desired state (hopefully = conflicts 
automatically resolved):

    ---A---C---B'

    git commit --onto-parent A --amend

... ending up with:

    ---A'---B'

... as that is basically what you wanted in the first place ;)
