line:

  git checkout [-p|--patch] [<tree-ish>] [--] [<paths>...]

implying that <paths> is optional, but further down in the
DESCRIPTION, one reads:

  git checkout [-p|--patch] [<tree-ish>] [--] <pathspec>...

suggesting that <pathspec> is required.
