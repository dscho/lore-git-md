Actually, you have to undo the ref-packing performed by gc.  You can do it 
this way (quick and dirty):

```
	$ git show-ref |
	  while read sha1 name
	  do
		mkdir -p .git/$(dirname $name) &&
		echo $sha1 > .git/$name
	  done

```
