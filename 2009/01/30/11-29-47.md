>
> modify b.c

>
> git log -C -M -- b.c

[...]
> I can't get history before rename.


You asked to restrict the search to the b.c path.

You want:

git log --follow -- b.c

Man git-log:
```
       --follow
           Continue listing the history of a file beyond renames.

```
