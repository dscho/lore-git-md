Silencing "inefficient new String(String) constructor" warning reported by 
FindBugs (see
http://thread.gmane.org/gmane.comp.version-control.git/117831/focus=117937).
using FindBugs filter mechanisms. For now the configuration file .fbprefs
contains the FindBugs default settings.

Signed-off-by: Matthias Sohn <matthias.sohn@sap.com>
---
Filtering out false positives using FindBugs exclusion filter seems 
to be the best compromise since
- filter settings can be shared by submitting .fbprefs and filter rules
- using annotations would require to add additional jars to build path
- simple comment would not reduce the FindBugs problem list
