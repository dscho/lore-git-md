**Thread**: [thread](./18-03-22.thread.md#:~:text=2009/02/11/18-54-37)

The local coding convention in bash completion is to use [...] rather
than test. Additionally,

    if [...]; then

is preferred over

```
    if [...]
    then

```

and so matching "if [...]\nthen" were changed accordingly.
