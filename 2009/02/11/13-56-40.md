Hmm.

In git.git:

```
  $ time git fast-export --all --signed-tags=strip >/dev/null
  real    1m6.013s
  user    1m3.840s
  sys     0m2.140s

  $ time git fast-export --all --signed-tags=strip --topo-order >/dev/null
  real    0m49.018s
  user    0m47.987s
  sys     0m0.888s

```

I certainly didn't expect it to be _faster_.  More efficient use of the
delta cache, maybe?
