actually I've tried downloading the main
"http://kernel.org/pub/software/scm/git/git-1.6.1.2.tar.gz", and then
following:

tar xzvf git-1.6.1.2.tar.gz
cd git-1.6.1.2
./configure
make
sudo make install

Seems to have worked...
