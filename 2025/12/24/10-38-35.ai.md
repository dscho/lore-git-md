Final patch in the `git status` goal branch comparison feature series, adding config validation warnings and completing test coverage. This v5 patch focuses on user experience improvements by warning about malformed `repo.settings.statusGoalBranch` configurations while maintaining silent fallback behavior. The tests are updated to verify full command output rather than grepping for specific lines, ensuring more robust validation of the status output format.

Key technical changes:
- Adds warning when `statusGoalBranch` config has invalid format (not matching "remote/branch" pattern)
- Silently skips goal branch comparison for invalid configurations
- Updates all tests in t6040-tracking-info.sh to check complete status output rather than grepping
- Maintains all existing functionality from previous versions
- Completes the test matrix with cases for:
  - Valid configurations showing divergence
  - Unset configuration (no comparison shown)
  - Config matching tracking branch (no redundant comparison)
  - Non-existent branch targets
  - Invalid format configurations

The patch builds on the v4 implementation's core functionality while adding the final polish of user feedback for configuration errors. Test coverage now verifies both the warning behavior and the complete output format in all scenarios, ensuring the feature behaves predictably in real-world use. This completes the series' transition from initial prototype to production-ready feature with comprehensive error handling.
