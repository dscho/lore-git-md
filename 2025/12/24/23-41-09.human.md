Feature enhancement for `git status` that makes the default branch comparison configurable. This is patch 3/6 in the v6 series that introduces the `repo.settings.statusGoalBranch` configuration option to replace the hardcoded upstream/origin preference logic.

The patch modifies the `get_default_remote_ref()` function to first check for the new config value before falling back to the previous behavior. When unset, the default branch comparison is skipped entirely. The implementation includes thorough test coverage showing:
- Normal operation with the config set to various remote/branch combinations
- Graceful handling when the config is unset
- Proper behavior with non-existent branches
- The tests demonstrate the feature works alongside existing tracking information
- Maintaining all previous functionality while adding the new configuration option

This continues the series' evolution toward a more flexible system for monitoring divergence from important branches, with the v6 changes focusing on finalizing the configuration interface. The implementation appears clean and well-tested, with clear examples of the new behavior in the test suite.
