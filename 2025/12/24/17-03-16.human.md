This is the third patch in a 14-part refactoring series introducing a shared `commit_stack` infrastructure to eliminate duplicate code for managing dynamic commit pointer arrays across Git's codebase.

The changes simplify the `bitmap_commit_cb` struct by replacing three separate fields (`commits`, `commits_nr`, `commits_alloc`) with a single `commit_stack` pointer. The `find_commits_for_midx_bitmap()` function is also streamlined to work directly with the stack rather than returning a separately allocated array.

The conversion follows the pattern established in earlier patches, demonstrating how the new API can clean up complex callback-based code paths. The diff shows a net reduction of 11 lines while maintaining identical functionality.
