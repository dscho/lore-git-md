Feature enhancement adding configurable branch comparison to `git status` output. This is the first patch in a 6-part series that introduces the ability to see how the current branch compares not just to its tracking branch, but also to the remote's default branch (typically main` or `master`).

The patch adds a new comparison line in `git status` output that shows divergence from the remote's default branch, determined by checking symbolic refs (first `upstream/HEAD`, then `origin/HEAD` as fallback). This helps developers working on feature branches track how much they've diverged from the main development line, even when their branch tracks a different remote branch.

The implementation is thorough, with new functions in remote.c to handle the default branch detection and comparison formatting, plus extensive test coverage in t6040-tracking-info.sh that verifies all the output variations (ahead, behind, diverged) and edge cases. The author has clearly put thought into real-world workflows where this would be useful, like monitoring drift from main while working on a feature branch.

This appears to be a well-crafted addition that addresses a genuine need in multi-branch workflows, with careful attention to performance (avoiding redundant ref lookups) and backward compatibility (graceful fallback when symbolic refs aren't configured). The patch series has already gone through several iterations addressing feedback, and this version looks production-ready.
