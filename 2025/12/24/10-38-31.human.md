Feature enhancement adding default branch comparison to `git status` output. This is the first patch in the v5 series implementing configurable branch divergence tracking via `repo.settings.statusGoalBranch`.

The patch adds a new comparison line to `git status` output that shows how the current branch differs from the project's default branch (typically `main` or `master`), in addition to the existing tracking branch comparison. This helps developers monitor drift from the mainline while working on feature branches. The default branch is determined by checking symbolic refs in order: first `upstream/HEAD`, then `origin/HEAD`.

The implementation introduces new functions in remote.c to handle the default branch resolution and comparison formatting, with careful attention to memory management and performance. The output follows the same format as existing tracking info, showing "ahead", "behind", or "diverged" states. The comparison is only shown when it differs from the tracking branch status.

The patch includes extensive test coverage in t6040-tracking-info.sh, verifying behavior in various workflow scenarios: branches ahead/behind/diverged from both their tracking branch and the mainline, different remote configurations, and edge cases. The tests demonstrate the feature's usefulness for monitoring mainline drift while working on feature branches.

This appears to be a well-considered implementation of a feature that addresses a real workflow need, with thorough testing and attention to edge cases. The v5 iteration incorporates feedback from previous rounds, particularly around configurable behavior and warning systems.
