This is the fourth patch in a refactoring series introducing a shared `commit_stack` infrastructure to eliminate duplicate code for managing dynamic commit pointer arrays across Git.

René Scharfe converts `builtin/name-rev.c` to use the new `commit_stack` API, replacing its manual array management with the standardized implementation. The changes are straightforward - replacing `ALLOC_GROW` operations with `commit_stack_push` and manual array cleanup with `commit_stack_clear`. The patch reduces the file's line count by 5 while maintaining identical behavior.

The changes are clean and focused, with no behavior modifications beyond the intended code deduplication.
