Refactoring patch converting pack-bitmap-write.c to use the new `commit_stack` API. This is patch 10/14 in a series standardizing Git's handling of commit pointer arrays.

The change replaces manual array management in the bitmap builder with the centralized `commit_stack` implementation. The patch:
- Swaps out direct `commits` array management for `struct commit_stack`
- Uses `commit_stack_init()` and `commit_stack_clear()` for lifecycle management
- Replaces `ALLOC_GROW` patterns with `commit_stack_push()`
- Updates iteration to use the stack's `items` and `nr` fields

This continues the series' pattern of eliminating duplicate array management code while maintaining identical behavior. The conversion is straightforward and demonstrates the API's applicability to the bitmap writing subsystem. With this change, the `commit_stack` infrastructure now handles commit arrays in nine different parts of the codebase.

The patch follows the series' high standard - clean diffs, thorough conversion, and no behavioral changes. It further strengthens the case for the `commit_stack` API by showing it works well in the bitmap generation context.
