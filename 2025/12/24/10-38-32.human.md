Performance optimization patch in the `git status` goal branch comparison series. This is the second patch in v5 of the series, which simplifies the logic for comparing branches to the configured goal branch (typically the project's main branch).

The patch removes redundant ref resolution calls and memory allocations by restructuring how the default branch comparison is handled. Key changes include:
- Eliminating the `is_default_remote_branch()` helper function
- Moving ref resolution to a single point in `format_tracking_info()`
- Consolidating memory management for goal branch refs
- Only performing the comparison when needed (when the tracking branch differs from the goal branch)

The changes maintain all existing functionality while reducing overhead. This continues the series' trend of incremental improvements to the goal branch comparison system, following maintainer feedback about using existing branch configuration infrastructure. The patch appears well-contained and focused changes to the remote.c file, with no behavioral changes visible to users.
