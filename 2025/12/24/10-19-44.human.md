Feature enhancement adding configurable branch comparison to `git status` output. This is the first patch in a v4 series that has evolved through discussion about naming and implementation details.

The patch adds a new line to `git status` output showing how the current branch compares to the upstream's default branch (typically 'main' or 'master'), in addition to the existing tracking branch comparison. This helps developers working on feature branches understand their divergence from the main development line. The output uses the same format as the tracking branch status ("Ahead of", "Behind", or "Diverged from") and appears on a new line when applicable.

The implementation determines the default branch by checking symbolic refs in this order: first `refs/remotes/upstream/HEAD` (if the upstream remote exists), then falling back to `refs/remotes/origin/HEAD`. This works with any default branch name as long as the symbolic ref is configured. The comparison is shown whenever the current branch differs from the default branch, even if it's up-to-date with its tracking branch.

The patch includes extensive test coverage in t6040-tracking-info.sh, verifying various workflow scenarios including branches that are ahead, behind, or up-to-date with their tracking branch while having different relationships with the default branch. The implementation appears clean and well-tested, building on existing branch tracking infrastructure while adding the new functionality.
