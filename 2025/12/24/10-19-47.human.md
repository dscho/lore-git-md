This is the final patch in a v4 series enhancing `git status` with configurable branch comparison. The series adds a new `repo.settings.statusGoalBranch` option to show how the current branch differs from a user-specified target (like upstream/main) alongside the usual tracking branch info.

This particular patch renames internal variables and functions from "default" to "goal" terminology to better reflect that the comparison target comes from config rather than being a true default. It also moves the goal branch lookup to where it's actually used rather than doing it up front. The changes are purely internal - no user-visible behavior changes.

The patch demonstrates careful attention to detail seen throughout the series, with thorough variable renaming and logical restructuring while maintaining all existing functionality. The implementation quality remains high, with proper memory management and config validation preserved through the refactoring. This concludes a well-executed feature addition that gives users more visibility into their branch relationships.
