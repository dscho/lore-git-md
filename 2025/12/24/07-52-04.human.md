This is the fourth version of a patch series addressing macOS iconv conversion issues, specifically targeting Homebrew package manager integration. The series has evolved significantly based on-list discussion, with René Scharfe now simplifying the approach by removing some of the fine-grained component flags that were previously proposed.

The key change in v4 is the removal of `USE_HOMEBREW_GETTEXT` and `USE_HOMEBREW_MSGFMT` flags, keeping only `USE_HOMEBREW_LIBICONV` which is now restricted to known-broken macOS versions. This reflects the emerging consensus that individual component flags may be unnecessary complexity. The series maintains the core architecture-aware Homebrew` prefix handling (`/opt/homebrew` for ARM, `/usr/local` for Intel) while streamlining the configuration options.

The patches modify both the main Makefile and config.mak.uname to improve Homebrew support, particularly for the libiconv workaround needed to fix t3900 test failures on macOS 15+. The changes appear well-considered, building on extensive discussion about package manager integration and macOS-specific build requirements. The simplification in v4 suggests the series is maturing toward a final form that balances configurability with maintainability.
