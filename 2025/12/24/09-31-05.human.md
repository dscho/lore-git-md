Feature enhancement finalizing the configurable branch comparison in `git status`, part 3/3 of the v3 series. This patch replaces the hardcoded upstream/origin preference with a new `repo.settings.statusGoalBranch` configuration option that lets users specify which remote branch to compare against. When unset, the default branch comparison is skipped entirely.

The implementation is clean and focused, with thorough test coverage showing various configuration scenarios: unset config falls back to basic status output, valid configurations show the expected comparison, and invalid/nonexistent branch references are handled gracefully. The tests demonstrate the flexibility to compare against any configured remote branch, not just the default upstream.

This completes the series' transition from a fixed "compare against upstream" approach to a fully configurable solution, addressing earlier concerns about workflow flexibility. The patch maintains the performance optimizations from previous versions while adding this final configuration layer. The extensive test additions (71 lines) verify all edge cases, giving confidence in the implementation.

For users who want to track divergence from a project's mainline while working on feature branches, this provides a clean way to configure that comparison point without hardcoding assumptions about remote names. The series as a whole delivers a polished solution to the original workflow need while respecting Git's configuration philosophy.
