This is a bugfix patch addressing error message clarity in `git restore`. Junio C Hamano provides maintainer approval for Brian M. Carlson's one-line change that improves the formatting of error messages when an invalid treeish is provided to `git restore`.

The patch wraps unresolved treeish names in single quotes in the error message, changing "could not resolve ource" to "could not resolve 'ource'" when users mistakenly use `-source` instead of `--source`. This follows Git's CodingGuidelines for error message formatting and matches similar patterns used elsewhere in the codebase (like "unable to open '%s'").

The change is minimal (a single character addition in `builtin/checkout.c`) but meaningfully improves user experience by making the error output clearer.
