This is a feature enhancement patch in the v5 series adding configurable branch comparison to `git status`. Patch 3/5 implements the core configuration mechanism for the `statusGoalBranch` feature.

The patch replaces the hardcoded upstream/origin preference logic with a configurable `repo.settings.statusGoalBranch` setting. When unset, the default branch comparison is skipped entirely. The implementation validates the config format (requiring "remote/branch" syntax) and gracefully handles invalid or missing branch references. The changes are focused in `remote.c` where the `get_default_remote_ref()` function is updated to use the new config value.

Key technical changes include:
- New config validation checking for proper "remote/branch" format
- Ref resolution now based on configured goal branch rather than hardcoded remotes
- Fallback to no comparison when config is unset or invalid
- Memory management improvements via `strbuf` for ref construction
- Preserved existing behavior when goal branch matches tracking branch

The extensive test suite additions verify:
- Config unset behavior (no comparison shown)
- Valid remote/branch configurations
- Handling of non-existent branch targets
- Integration with existing tracking info display
- Various workflow states (ahead, behind, diverged)
- Different remote preferences
- This builds on the v4 foundation while adding the configurable behavior that was previously hardcoded. The implementation follows Junio's guidance to use existing branch configuration infrastructure. The tests demonstrate the feature's flexibility across different workflow scenarios while maintaining robust fallback behavior.
