This is part 4/6 of a feature series enhancing `git status` with configurable branch comparison. The patch focuses on finalizing terminology and optimizing the implementation.

Harald Nordgren renames variables and functions from "default" to "goal" terminology to better reflect the configurable nature of the branch being compared against. The key changes include renaming `get_default_remote_ref()` to `get_goal_branch_ref()` and `format_default_branch_comparison()` to `format_goal_branch_comparison()`. The patch also moves the goal branch lookup to where it's actually used rather than doing it up front.

The implementation now shows clearer separation between the tracking branch comparison (which shows upstream divergence) and the goal branch comparison (which shows divergence from a user-specified important branch). The patch maintains all existing functionality while making the code's intent more obvious through naming.

This continues the series' trend of refinement based on maintainer feedback, with Junio C Hamano having previously suggested using existing branch configuration rather than inventing new mechanisms. The changes appear well-contained and focused on code clarity rather than introducing new behavior.
