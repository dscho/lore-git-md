This is a bugfix patch addressing error message formatting in `git restore`/`git checkout`. The patch follows up on a thread where a user reported confusing output when mistakenly using `-source` (single dash) instead of `--source`. While the underlying behavior was correct (Git parsed this as `-s ource`), the error message "could not resolve ource" lacked the single-quote wrapping recommended in Git's CodingGuidelines for unresolved names.

Brian M. Carlson's one-line change modifies the die() message in `builtin/checkout.c` to wrap the unresolved treeish in quotes, producing "could not resolve 'ource'" instead. This makes it clearer that "ource" is the problematic portion being resolved, not a typo in the error message itself. The change is minimal (just two added quote characters) and strictly improves error message clarity without affecting functionality. The patch includes a Reported-by tag crediting the original bug reporter and maintains the thread's conclusion that this was a user syntax error, just with better messaging.
