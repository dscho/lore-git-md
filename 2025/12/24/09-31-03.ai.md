Feature enhancement adding default branch comparison to `git status` output, part of a v3 series introducing configurable target branch comparison. This first patch implements the core functionality showing divergence from the upstream default branch (via symbolic refs) alongside the existing tracking branch status.

The implementation adds a new `get_default_remote_ref()` helper in remote.c that checks `refs/remotes/upstream/HEAD` and falls back to `refs/remotes/origin/HEAD`. The comparison uses the same ahead/behind infrastructure as regular branch tracking, with output formatted identically but on a new line. The patch includes extensive test coverage in t6040-tracking-info.sh for various workflow states (ahead/behind/diverged combinations) and remote configurations.

Key technical details for future reference:
- New helper functions: `get_default_remote_ref()`, `is_default_remote_branch()`, `format_default_branch_comparison()`
- Comparison logic inserted at multiple points in `format_tracking_info()`
- Fallback chain: upstream/HEAD -> origin/HEAD
- Output examples show both tracking branch status and default branch divergence
- Tests cover:
  - Ahead of both tracking branch and default
  - Diverged from default while up-to-date with tracking
  - Remote preference (upstream over origin)
  - Various state combinations

The implementation follows Junio's earlier guidance about using existing branch configuration rather than assuming remote names. The v3 series addresses previous concerns through configurability while maintaining the original goal of showing mainline divergence.
