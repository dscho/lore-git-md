This thread examines Git's handling of directory permissions, particularly the SGID bit (mode 2770), which is breaking container workflows that rely on automatic group inheritance. The discussion began with Hadmut Danisch reporting that Git clears the SGID bit during operations in rootless Podman containers, disrupting workflows that depend on fixed permissions.

The technical discussion has established that while `core.sharedRepository` handles basic group permissions, it doesn't preserve special bits like SGID. Alternative solutions using ACLs have been proposed by Randall Becker and Andreas Schwab, but Danisch maintains that only SGID provides the required automatic inheritance behavior. Becker's latest email clarifies that POSIX ACLs do support inheritance capabilities, though implementation differences across systems may affect their suitability. This keeps open the question of whether ACLs can fully replace SGID's functionality.

Key points remain unresolved: whether Git's SGID-clearing is intentional, the feasibility of preserving special bits, and whether ACLs offer a complete alternative. The technical requirements are now well-documented, but the thread awaits maintainer input on potential changes to Git's behavior or configuration options. The discussion has productively narrowed to comparing SGID and ACL inheritance capabilities while maintaining focus on container workflow needs.
