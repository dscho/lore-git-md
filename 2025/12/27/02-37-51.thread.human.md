This thread discusses a bug report from Hadmut Danisch about Git unexpectedly modifying directory permissions, specifically the SGID bit (mode 2770), which breaks workflows using shared directories for rootless Podman containers. The issue occurs during repository operations where Git overwrites these special permission bits, with the current workaround being a post-pull hook to reset permissions manually.

Michal Suchánek has responded with alternative approaches, suggesting that standard group permissions combined with `core.sharedRepository` might suffice instead of relying on SGID bits. He also proposes container-specific solutions like overlay filesystems. While this offers practical workarounds, it doesn't directly address the underlying technical question of whether Git should preserve special permission bits during directory operations. The discussion now appears to be pivoting between evaluating if this is a bug needing fixing versus whether existing mechanisms can solve the use case. No maintainer has yet weighed in on the core technical behavior.
