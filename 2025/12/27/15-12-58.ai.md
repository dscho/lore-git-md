This is a technical clarification in the ongoing discussion about Git's handling of directory permissions, specifically the SGID bit. Andreas Schwab responds to Hadmut Danisch's assertion that ACLs don't solve the permission propagation problem by pointing out that default ACLs on directories can be set to inherit permissions for newly created files. This suggests there may be an ACL-based approach that could address some of the container workflow requirements, though it's unclear if this would fully replace the automatic group inheritance behavior of SGID that the original reporter requires. The email adds a technical nuance to the discussion but doesn't fundamentally change the established understanding that SGID provides unique propagation behavior that other mechanisms may not fully replicate. The core issue of Git actively clearing special permission bits during operations remains unaddressed in this response.
