This is a test fix in a series preparing Git's test suite for Windows symlink support. It's part 6/10 of Johannes Schindelen's v2 series addressing upcoming MSYS2 changes that will enable symlink support by default on Windows.

The patch fixes an incomplete test prerequisite in t0600-reffiles-backend.sh. The test checks symref transaction support with symlinks, which requires both the SYMLINK prerequisite (for symlink support) and a new !MINGW prerequisite (since Windows doesn't support the preferSymlinkRefs feature). The change is straightforward - just adding the platform guard to skip the test on Windows.

The commit message provides useful context about other tests that set core.prefersymlinkrefs, noting they either set it to false (Windows-compatible) or don't actually verify symlink behavior. The change is well-considered, with Patrick Steinhardt credited for helping identify the issue. This appears to be a clean, focused fix that properly handles Windows platform limitations while maintaining test coverage where supported.
