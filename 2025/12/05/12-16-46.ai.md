This is a code organization patch in the submodule gitdir path encoding series. Patrick Steinhardt provides review feedback on Adrian Ratiu's patch that moves the `is_rfc3986_unreserved()` function from credential-store.c to url.[ch] for reuse in submodule path encoding.

The function determines which characters are safe to use in URI components without encoding, which is needed for the submodule path encoding feature. Patrick notes two minor issues: the commit message still claims the function will be used in the next commit (which is no longer true in this version of the series), and suggests the function documentation would be better placed in the header file rather than the implementation file.

This is a straightforward change that maintains the series' architectural approach of centralizing URL encoding functionality while addressing code organization details. The feedback is minor and focused on documentation placement rather than any substantive technical concerns.
