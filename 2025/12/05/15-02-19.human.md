Test fix for Windows symlink handling in t0001. This is part 4/10 of Johannes Schindelen's series preparing Git's test suite for Windows symlink support.

The patch fixes a test case in t0001-init.sh that compares the contents of a symlinked `.git` directory. On Windows, `git diff --no-index` (which `test_cmp` uses) shows the symlink target rather than resolving it, causing the test to fail. The fix adds a conditional that uses `cmp` instead of `test_cmp` when running with `--no-index`, ensuring the test works correctly on Windows while maintaining existing behavior elsewhere.

This is a straightforward test adjustment that aligns with the series' goal of making tests work reliably with Windows symlinks. The change is minimal and well-explained, with Junio Hamano credited as co-author. The fix demonstrates attention to platform-specific behavior while keeping the test's intent intact.
