This is the final patch (10/10) in Johannes Schindelen's v2 series preparing Git's test suite for Windows symlink support, particularly for MSYS2's planned default enablement of symlink support.

The patch modifies `t7800-difftool.sh` to make a test case work correctly on Windows by removing its assumption that absolute paths start with forward slashes. The test currently passes on Unix systems but would fail on Windows when symlink support is enabled, since Windows paths don't follow this convention. Instead of filtering paths based on leading slashes, the patch now filters lines ending with colons (a more reliable indicator of path lines in `ls` output).

This change is part of the broader effort to make Git's test suite properly handle Windows path conventions when symlink support becomes the default. The patch maintains the test's core functionality while making it cross-platform compatible. As with the rest of the series, it demonstrates careful attention to Windows-specific behaviors while preserving the test's original intent. The change is straightforward and well-explained, with a clear commit message detailing both the problem and solution.
