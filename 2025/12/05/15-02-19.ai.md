Test modernization patch in a series preparing Git's test suite for Windows symlink support. This is patch 4/10 in v2 of Johannes Schindelen's series addressing test failures that would occur when MSYS2 enables symlink support by default.

The patch fixes a test case in t0001-init.sh that compares the contents of a symlink `.git` file. The test was failing on Windows because `git diff --no-index` (used by `test_cmp` on Windows) shows symlink targets rather than resolving them, unlike the test's expectations. The fix introduces a conditional that uses `cmp` instead of `test_cmp` when `GIT_TEST_CMP` contains `--no-index`, ensuring the test works correctly on Windows while maintaining existing behavior elsewhere.

Key technical details:
- Modifies t0001-init.sh's 're-init to move gitdir symlink' test
- Adds platform-aware comparison logic via `case` statement checking `$GIT_TEST_CMP`
- Preserves symlink comparison expectations while accommodating Windows' `--no-index` behavior
- Co-authored with Junio Hamano, indicating maintainer alignment on the approach

This continues the series' theme of making tests work correctly with Windows symlinks while maintaining cross-platform compatibility. The change is surgical and well-motivated by the specific test failure scenario.
