This is the second patch in a 2-part series updating Git's test infrastructure, specifically focusing on the clar test framework. The patch demonstrates the use of new integer comparison assertions that were introduced in the first patch.

Patrick Steinhardt updates the reftable-record unit tests to use the new assertion macros like `cl_assert_gt_i` (greater than) and `cl_assert_lt_i` (less than) instead of the more generic `cl_assert` with manual comparisons. The changes are straightforward mechanical updates across various test functions that verify record encoding, decoding, and comparison behavior in the reftable backend.

The patch serves as both a demonstration of the new assertion capabilities and a cleanup of the test code to use more specific comparison macros. This makes test failures more descriptive while maintaining the same verification behavior. The changes are contained to test code only and don't affect Git's production behavior.

This continues Steinhardt's ongoing work to modernize Git's test infrastructure, building on his previous introduction of the clar framework from libgit2. The changes are clean and focused, with the patch serving as a practical example of how to use the new assertion macros introduced in the series.
