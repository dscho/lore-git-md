Performance optimization for promisor object handling, with follow-up suggestion. Patrick Steinhardt responds to Aaron Plattner's patch that dramatically speeds up promisor pack initialization by skipping blob parsing. The original patch showed a 76-minute operation reduced to 2 minutes by avoiding unnecessary blob decompression.

Steinhardt approves the approach as "an obvious improvement" and suggests extending the memory-saving technique to commit buffers as well. He provides a prototype patch that restructures the code to also free commit buffers after processing, which could further reduce memory usage in large repositories. The suggestion is framed as an optional enhancement to test in Plattner's large-repository environment.
