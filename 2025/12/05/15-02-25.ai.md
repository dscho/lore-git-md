Test adaptation for Windows symlink support (final patch in v2 series).

This is the concluding patch in Johannes Schindelin's 10-part series preparing Git's test suite for Windows symlink support, specifically addressing MSYS2's planned default enablement of symlinks. The patch modifies t7800-difftool.sh to handle Windows path formats when testing `git difftool --dir-diff` with symlinks.

The test currently assumes all absolute paths start with forward slashes (Unix-style), which fails on Windows where paths have different formats. The patch changes the test to filter output lines based on trailing colons (a more reliable indicator of path lines in `ls` output) rather than leading slashes. This maintains the test's functionality while making it work correctly on Windows when symlink support is enabled.

The change is minimal (4 line changes) and focused, following the series' pattern of targeted Windows adaptations. As the final patch in the v2 series, it completes the comprehensive preparation for Windows symlink support that has been reviewed and refined since v1. The approach here mirrors the series' overall strategy of making minimal, surgical changes to tests to handle Windows path differences while preserving the original test intent.
