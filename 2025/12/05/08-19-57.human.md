This is a cover letter for a series of three bugfix patches related to the object database (odb) subsystem. Patrick Steinhardt has split these fixes from other ongoing work to avoid creating unnecessary dependencies between patch series.

The series addresses several small but distinct issues:
1. Fixes geometric repacking when promisor remotes are involved
2. Corrects a condition for writing commit graphs during garbage collection
3. Ensures proper cleanup by closing object sources before freeing them

The changes touch core functionality in `builtin/repack.c` and `builtin/gc.c`, with corresponding test additions to verify the fixes. The patches appear focused and well-scoped, each addressing a specific edge case that was likely encountered during more substantial development work. The inclusion of new test cases suggests these are real issues being fixed rather than speculative improvements.
