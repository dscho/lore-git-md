This thread explores whether and how Git could be adapted to version structured data like databases, rather than just files. Cedric Sodhi originally proposed two approaches: modifying Git's backend or using a FUSE filesystem layer. René Scharfe then suggested evaluating existing "Git for data" tools like DVC and Dolt as alternatives to modifying Git itself.

Sodhi has now analyzed these tools, finding them imperfect fits. DVC focuses on large binary data (similar to Git LFS) rather than Sodhi's target of structured, text-like data. Dolt aligns better functionally but bundles its own SQL server, introducing new architectural constraints. The discussion remains open on whether external tools adequately address the need or if Git modifications might still be preferable, though no new technical details about such modifications have emerged yet. The core tension is between adopting standalone solutions versus extending Git's native capabilities.
