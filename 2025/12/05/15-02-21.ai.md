This is a test fix in the ongoing Windows symlink support preparation series. Patch 6/10 addresses an incomplete test prerequisite in t0600-reffiles-backend.sh related to `core.prefersymlinkrefs` behavior.

The change modifies a test case that verifies symref transactions with symbolic links to properly exclude Windows platforms via the `!MINGW` prerequisite. The test was previously marked only with `SYMLINKS`, but since Windows doesn't support the `core.prefersymlinkrefs` feature even when symlinks are available, the test needs explicit exclusion. The commit message analyzes other instances where this config is set in the codebase (t7201, t9903) but determines they don't require similar changes since they either set the value to false or don't actually verify symlink behavior.

The patch is narrowly focused and follows up on Patrick Steinhardt's v1 feedback about test coverage for symlink-related functionality. It maintains the series' overall goal of making tests properly account for Windows platform limitations while preparing for broader symlink support. The change is minimal (one line modified) and clearly explained, with consideration given to related but out-of-scope test cases.
