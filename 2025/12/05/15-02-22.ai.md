This is part 7/10 of a Windows symlink support preparation series, specifically addressing test accommodations in t1006-cat-file.sh for MSYS2's path normalization behavior when creating symlinks.

The patch modifies two test cases in t1006 that deal with symlink traversal to account for how MSYS2 normalizes Windows paths when creating symlinks. The first test case (`out-of-repo-link-dir-trailing`) now conditionally expects different output on Windows due to path normalization, while the second test case (`internal ..` symlinks) is skipped entirely on Windows since the symlink normalization fundamentally changes the test's expected behavior.

Key technical details:
- Uses `test_have_prereq MINGW,SYMLINKS` to condition test expectations
- For the first test, produces different expected output (2 vs 3 bytes) depending on platform
- For the second test, skips assertions about `up-down` symlinks on Windows entirely since MSYS2's path normalization makes them behave differently
- Maintains all non-Windows behavior unchanged
- Follows the series' pattern of making tests work cross-platform while preserving original semantics where possible

The changes demonstrate the series' ongoing theme of adapting tests to handle Windows' symlink implementation quirks while maintaining test coverage. This particular patch shows how path normalization affects symlink content expectations in test assertions.
