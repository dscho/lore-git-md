This is part 7/10 of a Windows symlink compatibility test suite update series. The patch modifies `t1006-cat-file.sh` to handle path normalization quirks when MSYS2 creates native Windows symlinks.

The changes accommodate two test cases where MSYS2's symlink support normalizes Unix-style paths into Windows-style paths, making the original test assertions invalid on Windows. The first test case about out-of-repo symlinks now conditionally checks different expected output based on whether we're on Windows with symlink support. The second test case involving symlinks with internal `..` components is skipped entirely on Windows since the path normalization changes the symlink's effective target.

This continues the series' careful work to make Git's test suite handle Windows symlink behavior correctly while maintaining the existing test coverage on other platforms. The changes are straightforward conditional test modifications that follow the pattern established in earlier patches of the series.
