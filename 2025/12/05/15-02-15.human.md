This is a cover letter for a 10-patch series preparing Git's test suite for Windows symlink support, version 2. Johannes Schindelen is working to upstream Git for Windows' symlink support in anticipation of MSYS2 runtime enabling symlinks by default. The series fixes test failures that would occur when both MSYS2 and Git properly support symlinks on Windows.

The changes since v1 are minor: grammar fixes, using `cmp` instead of skipping comparisons per Junio's suggestion, and extending a commit message to clarify coverage of `core.preferSymlinkRefs` cases. The series touches various test scripts (t0001, t0301, t0600, etc.) and a few core files (apply.c, mingw.c) to handle Windows-specific symlink behaviors.

The patches address issues like Perl test path handling, `git apply` bit handling, MSYS2 symlink normalization quirks, and Windows permission handling trade-offs. The series has been reviewed and approved by Junio Hamano, with follow-up discussions continuing on test implementation details and broader testing strategy. This represents important groundwork for better Windows symlink support in Git's test infrastructure.
