This is a Windows compatibility fix in the ongoing series preparing Git's test suite for Windows symlink support. Patch 5/10 modifies t0301-credential-cache.sh to avoid using `mkdir -m<mode>` which doesn't work properly on Windows, replacing it with separate `mkdir` and `chmod` commands.

The change fixes a test case that was previously skipped on Windows due to the SYMLINK prerequisite. With upcoming Windows symlink support, this test would start running and fail due to the incompatible `mkdir -m` usage. The patch follows the same pattern as a previous Windows compatibility fix in this test file (0fdcfa2f9f5).

The modification is straightforward - splitting the directory creation and permission setting into two steps - and maintains the same security semantics while being portable across platforms. This is a minor but necessary adjustment in the broader effort to enable proper symlink support on Windows.
