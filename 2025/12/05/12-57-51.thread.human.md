The first patch updates the embedded clar framework to a newer version, adding several new assertion macros for signed and unsigned integer comparisons (like `cl_assert_lt_i` for "less than" and `cl_assert_ge_u` for "greater or equal"), along with formatted error reporting and TAP output fixes.

The second patch demonstrates these improvements by updating the reftable record tests to use the new assertion macros. These changes are part of Patrick's ongoing effort to modernize Git's test infrastructure, building on improvements from libgit2's clar framework. The changes affect only test code and have no impact on Git's runtime behavior.
