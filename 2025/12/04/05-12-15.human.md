This is a Windows platform compatibility discussion about local path remotes. Torsten Bögershausen responds to Skybuck Flying's concern about drive letters in Git remotes by suggesting an alternative approach using UNC paths (\\server\share\...) instead of drive-letter paths (Z:\path\...). 

The key point is that UNC paths avoid the drive-letter problem entirely since they don't depend on specific drive mappings. Torsten notes that Git already handles the forward/backward slash conversion internally, making this approach viable. While acknowledging this solution might not be widely known, he confirms it should work.

This provides a practical workaround for the original issue where copying repositories between drives with local path remotes could lead to accidental modifications in wrong locations. The suggestion maintains Git's functionality while sidestepping the Windows-specific pitfall of absolute drive letters.
