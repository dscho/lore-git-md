This is a feature patch series finalizing the addition of `-z` as an alias for `--format=nul` in the `git repo structure` command, bringing it in line with similar Git commands. The series also includes two documentation cleanups to maintain consistency with `git repo info`.

The main patch (3/3) implements the `-z` flag for null-terminated output, following the same pattern used in `git repo info`. It updates the command's synopsis, documentation, and adds test coverage. The implementation reuses existing callback infrastructure from `git-repo-info`.

Two preparatory patches address documentation issues: one removes an extraneous line that was leaking a '+' character in generated docs (1/3), and the other standardizes the option syntax to use pipe separators for mutually exclusive options in `git repo info` (2/3), which then gets mirrored in the `structure` command.

The series incorporates all feedback from the mailing list discussion, including Junio Hamano's requests for clearer documentation formatting and test case corrections. The changes maintain consistency with Git's established conventions while providing the same convenient short option available in related commands.
