This is a build system patch that concludes a series improving Git's Meson build for cross-compilation scenarios. Patrick Steinhardt is reviewing Toon Claes's changes that standardize how the build system handles execution tests during cross-compilation.

The patch replaces `meson.is_cross_build()` with `meson.can_run_host_binaries()` in another location, following the pattern established earlier in the series. This ensures the build system properly accounts for cases where an exe_wrapper is configured, allowing test programs to run even when cross-compiling. The series maintains one remaining `is_cross_build()` check where appropriate - for filesystem existence checks that always run on the build machine.

Patrick gives his approval to the complete series, which now consistently handles execution tests while maintaining the distinction for filesystem operations. The changes make the Meson build more robust for cross-compilation without impacting native builds. The small, focused improvements appear ready for inclusion after thorough review and implementation of Patrick's earlier suggestions.
