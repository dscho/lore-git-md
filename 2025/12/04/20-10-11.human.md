This is a documentation and consistency patch in a series finalizing the `-z` flag addition to Git's experimental repository commands. It updates the synopsis of `git-repo-info` to explicitly show that `-z` and `--format` are mutually exclusive alternatives, though the implementation already follows Git's standard "last one wins" behavior for conflicting options.

The patch makes two simple but important changes: it updates both the man page and the in-code usage message to use the standard `[--format=... | -z]` pipe-separated syntax. This better reflects that these options serve the same purpose (controlling output format) and can't meaningfully be combined, even though the underlying code would accept both.

This change follows Junio Hamano's guidance from earlier in the thread about standardizing documentation conventions. The patch is straightforward and uncontroversial, completing one of the final polish items identified in the review process. It maintains consistency with how similar options are documented elsewhere in Git while making no functional changes to the code itself.
