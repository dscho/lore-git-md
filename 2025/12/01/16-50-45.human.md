Maintenance patch removing stale Scalar config settings. This is part 3/5 of a series improving Scalar's configuration handling, following up on earlier discussion about better documentation and maintenance of these settings.

The patch removes five configuration values that are either now Git defaults (`core.preloadIndex`, `core.multiPackIndex`, `pack.useSparse`), Windows-specific (`core.fscache`), or related to obsolete credential managers (`credential.validate`). Each removal comes with clear justification in the commit message explaining why the setting is no longer needed. The changes are straightforward - simply deleting the config entries from scalar.c and updating related tests to use `gui.gcwarning` instead of the removed `core.preloadIndex` for testing purposes.

This continues the series' theme of cleaning up Scalar's configuration approach while maintaining backward compatibility where needed. The patch has already been reviewed positively by Junio Hamano and Patrick Steinhardt, with Johannes Schindelin providing Windows-specific context for the `core.fscache` removal. The changes are well-motivated and the commit message provides clear reasoning for each removal.
