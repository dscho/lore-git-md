This is part 4/10 of Johannes Schindelin's series improving Windows test suite compatibility with symbolic links, specifically addressing a test case in t0001-init.sh that fails when `git diff --no-index` is used for comparisons on Windows.

The patch fixes a test that verifies gitdir symlink behavior by skipping the symlink comparison when `GIT_TEST_CMP` uses `--no-index` (the Windows case), since `git diff --no-index` doesn't resolve symlinks as expected by the test. Junio Hamano suggested an alternative approach of using direct `cmp` instead of skipping, which Schindelin agrees to implement despite reservations about its value.

The change is straightforward but highlights an interesting platform difference in symlink handling between Windows and Unix-like systems. While the fix is simple, the discussion reveals deeper questions about whether test expectations should adapt to platform behaviors or if the underlying tools should be made more consistent. This patch represents one of several adjustments needed to make Git's test suite properly exercise Windows symlink support.
