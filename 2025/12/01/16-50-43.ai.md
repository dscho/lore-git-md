This is the first patch in a series improving Scalar's configuration documentation and maintenance. It introduces a helper function to annotate config settings that Scalar modifies with "# set by scalar" comments in the config file.

The patch adds a new `set_config_with_comment()` helper that wraps `repo_config_set_multivar_in_file_gently()` to append the annotation. This is used in two places where Scalar sets config values: the main config setting logic and the log.excludeDecoration setting. The change makes it clearer to users which config values were set by Scalar operations like clone/register/reconfigure.

The implementation modifies scalar.c to add the helper function and update the config-setting calls, plus adds tests in t9210-scalar.sh to verify the annotations appear as expected. The patch has already been reviewed positively by Patrick Steinhardt and Junio Hamano, with Junio suggesting the helper function approach that was implemented.

This is a straightforward improvement that helps users understand Scalar's impact on their config files while maintaining all existing functionality. The helper function approach keeps the annotation logic DRY and makes it easy to apply consistently. The patch is part of a larger effort to improve Scalar's config documentation and maintenance, with subsequent patches handling config reorganization, removal of stale values, and comprehensive documentation.
