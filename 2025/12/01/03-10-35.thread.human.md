This thread addresses a platform compatibility issue affecting nixpkgs builds of Git. The problem stems from `git-gui--askyesno` being installed by `make install` after commit e749c87e75, which breaks test environments. The current patch provides a minimal fix by adding `gui--askyesno` to the list of commands marked as expected failures in t/t1517-outside-repo.sh, following the pattern of a similar fix from August 2025 (c4cf8caadd) for `gui` and `gui--askpass`.

The author acknowledges this is likely a temporary solution and suggests a more robust fix may be needed to prevent recurring issues with installed commands breaking tests. However, this patch serves as an immediate workaround to unblock nixpkgs builds for the upcoming Git v2.52.0 release. The change is narrowly scoped, only modifying the test expectations without altering core functionality.
