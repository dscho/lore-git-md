This thread addresses a platform compatibility issue in Git's test suite where `gui--askyesno` fails when running tests with GIT_TEST_INSTALLED, particularly affecting nixpkgs builds. The problem stems from commit e749c87e75, which caused `git-gui--askyesno` to be installed by `make install`, similar to previous issues with `gui` and `gui--askpass` commands that were fixed in commit c4cf8caadd.

Adam Dinwoodie is now advocating for including Brian Lyles' minimal fix in the upcoming Git v2.52.0 release. The patch adds `gui--askyesno` to the expected-failure list in t/t1517-outside-repo.sh, following the same pattern used for related commands. While this is acknowledged as a temporary solution, it serves to unblock nixpkgs builds while discussions continue about a more robust long-term fix (referenced in a separate thread). The change is limited to test infrastructure and doesn't affect production code behavior.
