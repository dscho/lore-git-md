This is part 4/5 of a maintenance and documentation series for Scalar's configuration settings. The patch alphabetizes and simplifies Scalar's config handling after a recent audit.

The main changes reorganize the config settings alphabetically (with platform-specific options grouped at the end) and removes the `overwrite_on_reconfigure` flag from most settings. This makes the configs less restrictive for users while maintaining the important performance optimization of `index.skipHash` (which was previously incorrectly set to false and is now properly set to true` with enforcement).

The patch shows careful consideration of platform differences, particularly Windows-specific handling, and maintains clear comments explaining the untracked cache behavior on Windows. The changes appear well-reasoned and build on previous discussion in the thread, with positive reviews from key maintainers. This is a straightforward cleanup that improves maintainability while preserving functionality.
