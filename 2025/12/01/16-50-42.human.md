This is the final version of a documentation and maintenance patch series for Scalar's configuration settings, following up on September discussions about improving config documentation. The series has gone through review and incorporates all feedback.

The series comprehensively audits Scalar's configuration handling with several key improvements:
1. Adds "# set by scalar" annotations to help users understand config origins
2. Fixes a performance issue with `index.skipHash` being incorrectly set
3. Removes five stale config values with detailed justifications
4. Reorganizes config handling alphabetically while relaxing enforcement for most settings
5. Documents all remaining config settings with clear rationales

The patches have been reviewed positively by Junio Hamano and Patrick Steinhardt, with test adjustments made for removed configs. The series is now ready for inclusion after addressing final minor documentation tweaks. 

Notable technical aspects include:
- Windows-specific handling for `core.fscache` that will need coordination with Git for Windows
- Performance improvement from correcting `index.skipHash` to true
- Detailed documentation of 20+ Scalar-modified config settings
- Relaxed config overwriting policy while maintaining enforcement for critical settings

The series represents a well-executed cleanup of Scalar's configuration system, with thorough documentation and thoughtful handling of platform-specific cases. The careful attention to review feedback and clear commit messages make this a high-quality contribution.
