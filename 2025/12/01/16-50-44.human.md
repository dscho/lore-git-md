This is a bugfix and performance patch in the Scalar configuration documentation series. It corrects an inverted `index.skipHash` setting that was unintentionally disabling a performance optimization in Scalar repositories since May 2025. The patch changes the setting from `false` to `true` as originally intended, which should improve performance by skipping hash computation for index entries.

The change reveals an interaction issue with split index testing when `GIT_TEST_SPLIT_INDEX` is enabled, so the patch includes a workaround that disables this test variable. The author notes this split index issue should be properly addressed in a future dedicated series.

This is the second patch in a 5-part series that has already received positive reviews from Junio Hamano and Patrick Steinhardt. The series as a whole aims to improve Scalar's configuration documentation and maintenance, with this particular patch fixing a clear performance regression that slipped through earlier. The fix is straightforward and well-justified, though the split index interaction suggests there may be more subtle index behavior to investigate later.
