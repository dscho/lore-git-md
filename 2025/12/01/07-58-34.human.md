This is a follow-up in the build system thread about artifact stripping, specifically addressing meson's handling of the issue.

Patrick Steinhardt confirms Johannes Schindelen's earlier observation that meson already handles binary stripping natively through its `--strip` option during setup, which automatically strips all installed binaries. This means no additional changes are needed for meson builds, unlike the Makefile case where `scalar` had to be explicitly added to the strip target.

The email serves as a technical clarification that closes the meson-related question raised earlier in the thread. It reinforces that meson's approach is more comprehensive than the Makefile solution, as it doesn't require manual maintenance of the list of binaries to strip. This aligns with the thread's broader theme of meson being the more modern solution for build system needs.

With this confirmation, the thread appears fully resolved - the immediate Makefile patch has been accepted, meson's superior handling is documented, and the larger build system restructuring questions remain available for future consideration.
