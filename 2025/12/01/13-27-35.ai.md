Platform compatibility patch in a completed series addressing Windows test suite issues with symlinks.

This email is a follow-up to Patrick Steinhardt's review of patch 6/10 in Johannes Schindelin's series fixing Windows symlink test compatibility. The original patch added a `!MINGW` prerequisite to a test in t0600-reffiles-backend.sh that requires `core.prefersymlinkrefs=true`, which isn't supported on Windows. Patrick confirms this is the only test needing adjustment while noting other tests that set this config key but don't actually verify symlink behavior - particularly in t7201 and t9903 where the setting appears unnecessary since symref-via-symlink support is being deprecated anyway.

The exchange reveals two key technical details: (1) the immediate fix is correct and complete for the current series' scope, and (2) there's potential future cleanup work removing `core.prefersymlinkrefs` usage from tests that don't actually need it, especially as symref-via-symlinks becomes deprecated. The discussion doesn't require any changes to the current patch but documents broader test suite modernization opportunities.
