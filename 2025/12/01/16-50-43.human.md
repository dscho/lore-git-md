This is a documentation and maintenance patch for Scalar's configuration settings. It's the first in a 5-part series that has already undergone review and is now in its final form.

The patch adds "# set by scalar" comments to config values set by Scalar commands, making it clearer to users which settings were modified by Scalar. It introduces a new helper function `set_config_with_comment()` to handle this consistently across two call sites that modify config values. The change is straightforward but useful for maintainability and user transparency.

The implementation includes test updates to check for these new comments in the config file. The patch has already been reviewed positively by Patrick Steinhardt and Junio Hamano, with Patrick co-authoring the change. This appears to be a well-considered improvement that addresses a real need for better visibility into Scalar's configuration changes.
