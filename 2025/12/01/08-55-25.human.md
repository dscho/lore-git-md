This is a brief follow-up in the Scalar configuration documentation series, specifically addressing the first patch that adds "# set by scalar" annotations to config settings.

Patrick Steinhardt agrees with Junio Hamano's suggestion to create a helper function `scalar_config_set()` to wrap the verbose `repo_config_set_multivar_in_file_gently()` calls used for adding config annotations. While the current implementation only has two callsites, Patrick notes the helper would reduce verbosity and prevent potential typos in the annotation text.

The exchange shows consensus on this minor refactoring improvement, though it's noted as potential future work rather than a blocker for the current series. This comes after Junio had already reviewed the full series positively, calling it "superbly written" with only minor documentation tweaks needed in the final patch.
