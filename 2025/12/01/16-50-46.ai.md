This is a refactoring and maintenance patch in the Scalar configuration series. It alphabetizes and simplifies Scalar's config settings while maintaining special handling for platform-specific options.

The key changes reorganize the config settings in scalar.c into a more maintainable structure. All non-platform-specific settings are now alphabetized, while Windows-specific settings remain grouped at the end. The patch also removes the `overwrite_on_reconfigure` flag from most settings, making them optional rather than required - a change that gives users more flexibility in their configurations. The one exception is `index.skipHash`, which remains enforced to correct a previous incorrect setting (false) to the desired value (true) during upgrades.

The diff shows the substantial reorganization of the config array, moving from a mixed order to a clear alphabetical listing with platform-specific exceptions. Windows-specific handling for `core.untrackedCache` remains due to known performance issues on that platform. The changes maintain all existing functionality while improving code organization and user flexibility.

This patch follows through on the series' goal of auditing and improving Scalar's configuration handling, with Patrick Steinhardt and Junio Hamano having reviewed earlier versions. The changes align with the thread's progression toward more maintainable and user-friendly config management in Scalar.
