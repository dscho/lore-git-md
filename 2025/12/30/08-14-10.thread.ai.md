This thread introduces Linux support for Git's filesystem monitoring (fsmonitor) using inotify, bringing Linux to parity with existing Windows and macOS backends. The implementation enables faster status operations through filesystem event watching rather than full directory scans.

Key technical details:
- Uses inotify with recursive directory watching via inotify_init1(O_NONBLOCK) and special handling for directory renames through IN_MOVED_FROM/TO event cookies
- Maintains bidirectional watch descriptor <-> path mappings using hashmap

- Falls back to $HOME/.git-fsmonitor-* for IPC socket when .git is remote
- Adds build configuration via FSMONITOR_DAEMON_BACKEND=linux and FSMONITOR_OS_SETTINGS=linux
- Requires pthreads and Unix domain socket support
- Documents inotify watch limits and expands fsmonitor.socketDir support to Linux
- Includes integrated meson build system support with detection of linux/magic.h and pthreads
