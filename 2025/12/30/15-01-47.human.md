This is a refactoring patch that removes dead code from `git replay`'s option handling. It's the first in a 5-part series improving error handling when invalid commit-ish arguments are given.

The patch focuses on cleaning up `determine_replay_mode()`, which contained legacy code paths from when `--onto` and `--advance` options were optional. Since commit 22d99f01 made these options mandatory, the fallback "guess mode" code became unreachable. Kristoffer removes this dead code and renames the function to better reflect its current purpose (now called `populate_for_onto_or_advance_mode`).

The changes are straightforward: the unused conditional branch is deleted, some variable checks are simplified, and error handling is made more direct. The patch includes historical context about how this dead code came to be, tracing it back to an earlier design iteration by Elijah Newren. While not strictly necessary for the series' main goal of improving error messages, this cleanup makes the codebase more maintainable.
