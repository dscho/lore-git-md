This is the first patch in a 3-part series introducing a feature to show divergence from a configured goal branch in `git status` output. The patch represents the original implementation approach that was later abandoned in favor of using existing branch tracking mechanisms (as seen in the thread context).

The patch adds a new `status.goalBranch` configuration option that lets users specify a remote/branch (like `upstream/main`) to compare against. When set, `git status` shows both the usual tracking branch comparison and an additional line showing divergence from the goal branch, if they differ. The output follows the same format as regular tracking info ("Ahead of", "Behind", or "Diverged from").

Key implementation details:
- Adds `get_goal_branch_ref()` to resolve the configured branch
- Implements `format_goal_branch_comparison()` to generate the status line
- Integrates with existing `format_tracking_info()` logic
- Includes extensive test coverage (340 lines) for various scenarios:
  * Ahead/behind/diverged states
  * Different remote configurations
  * Edge cases (unset/malformed config, nonexistent branches)
  * Integration with existing tracking info display

The patch was technically sound but ultimately rejected due to design concerns about introducing new configuration rather than using existing branch tracking mechanisms. The thread context shows this approach was later replaced in v10 with a solution leveraging `pushRemote` and tracking branch infrastructure instead.
