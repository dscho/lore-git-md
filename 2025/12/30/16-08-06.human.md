This is the first patch in a 3-part series introducing a feature to show divergence from a goal branch in `git status` output. The series has undergone significant design changes based on maintainer feedback, now using existing branch tracking mechanisms rather than introducing new configuration.

The patch adds a `status.goalBranch` configuration option that lets users specify a remote/branch (like `upstream/main`) to compare against. When set, `git status` shows both the usual tracking branch comparison and an additional line showing divergence from the goal branch, if they differ. The output follows the same format as existing status messages ("Ahead of", "Behind", or "Diverged from").

The implementation handles various edge cases through comprehensive tests:
- Different divergence states (ahead, behind, diverged)
- When goal branch matches tracking branch (no extra output)
- Invalid/missing goal branch configurations
- Integration with existing tracking info display

The code is well-structured, with clear separation between ref resolution, comparison logic, and output generation. Test coverage is thorough, exercising all major code paths and output variations. This represents the culmination of 10 iterations that have refined both the implementation and design approach.

While the patch is technically sound, note that this version still uses the `status.goalBranch` configuration that was later removed in favor of using `pushRemote` in the final version of the series. The core comparison functionality remains unchanged through the iterations.
