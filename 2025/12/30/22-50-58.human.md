This is a refactoring patch that removes dead code from `git replay`'s command mode determination logic. It's the first patch in a 5-part series improving error handling in `git replay` command.

The patch removes code that was left over from an earlier "guess mode" implementation that was ultimately replaced by requiring either `--onto` or `--advance` options. The dead code path could never be reached since one of these options is now mandatory. The patch also renames the function from `determine_replay_mode()` to the more accurate `populate_for_onto_or_advance_mode()` (though Elijah Newren suggests this name might be too verbose and proposes `setup_replay_mode()` as an alternative).

The changes are straightforward cleanup - removing unused code paths and improving the function's name to better reflect its current purpose. The patch maintains all existing functionality while making the code simpler and more maintainable. This appears to be a solid foundation for the subsequent patches in the series that will improve error handling and testing.
