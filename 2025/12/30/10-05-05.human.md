This is a community announcement about the upcoming Git Rev News edition. Christian Couder shares a draft of edition 130 and invites contributions from the Git community before its planned January 1, 2026 publication. 

The email provides two ways to contribute: directly editing the draft via GitHub pull request or commenting on the associated GitHub issue. Christian emphasizes that all forms of help are welcome, including proofreading, content ideas, and volunteering for interviews. 

While Christian notes he tried to CC all contributors mentioned in this edition, he acknowledges he may have missed some people. The email serves as both an announcement and an open call for community participation in finalizing this regular Git project newsletter. 

The draft itself isn't included in the email - interested parties must follow the GitHub link to review and contribute to the content. This follows the standard process for Git Rev News editions, where community feedback helps shape the final published version.
