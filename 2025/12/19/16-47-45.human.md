This is a "What's cooking" status update from Junio Hamano, summarizing the current state of various Git development topics as of December 2025. These periodic updates help track which patches are being considered for inclusion in upcoming Git releases.

The update categorizes 50+ topics into three main groups:

1. **New Topics** - Fresh proposals including Windows symlink support improvements, lockfile debugging enhancements, sideband message safety fixes, and object-info API cleanups. The Windows symlink work (js/symlink-windows) is particularly notable as it brings better symlink handling to Windows platforms.

2. **Cooking** - Ongoing work in progress, such as macOS iconv workarounds, MIDX repacking optimizations, replay command improvements, and Rust interoperability efforts. Several documentation and test fixes are also progressing well.

3. **Discarded** - One rejected proposal (wm/complete-git-short-opts) to add single-letter option completion, which doesn't align with Git's completion philosophy.

The update provides useful snapshot of Git's development pipeline, showing which features are stabilizing (marked for 'next'), which need more review, and which are being abandoned. It's particularly interesting to see continued work on Windows compatibility, performance optimizations around object storage, and the gradual introduction of Rust components.
