This thread introduces a new `--no-indicators` option for `git diff` and related commands. The option replaces the traditional '+', '-', and ' ' indicators in the left margin with spaces while preserving colored output, making it easier to copy-paste diff output without manual cleanup.

The implementation adds a new callback function in `diff.c` that modifies the indicator characters, along with tests verifying the functionality works as intended. The patch appears well-contained, touching only the necessary files (`diff.c` and the test script) with clear motivation and test coverage. This seems like a straightforward quality-of-life improvement for users who frequently work with diff output in contexts where the indicators are more distracting than helpful.
