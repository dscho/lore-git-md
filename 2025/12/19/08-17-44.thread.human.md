The thread continues to discuss Harald Nordgren's proposal for a `--no-indicators` flag in `git diff` and `git show` that would replace the '+', '-', and ' ' indicators with spaces while preserving colors. The original motivation was to make it easier to copy React/TypeScript code blocks from commit diffs without the diff markers.

Several experienced contributors have raised concerns and suggested alternatives:
- Collin Funk questioned whether the feature was necessary, suggesting `sed` post-processing
- Phillip Wood pointed out technical edge cases around space handling and newline markers
- Junio Hamano expressed skepticism about the value, noting terminal emulators can already handle column selection
- Ben Knoble and Chris Torek demonstrated how existing Git commands (`git restore -p`, `git show` with temporary files) could solve the use case

In the latest exchange, Harald reiterates his original motivation but doesn't engage with the technical concerns or alternatives. The discussion has reached an impasse, with proponents focusing on the social benefits of built-in commands while opponents point to existing solutions that don't require new features. The maintainer remains unconvinced, and without resolution of the technical concerns or demonstration of unique value over current methods, the proposal seems unlikely to progress.
