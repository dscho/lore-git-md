This is a feature patch adding a new `--no-indicators` option to Git's diff output. 

The patch introduces a new command-line option that replaces the traditional '+', '-', and ' ' indicators in diff output with simple spaces while preserving color highlighting. This is designed for users who want to copy-paste diff output without having to manually remove these markers first.

The implementation adds a new callback function `diff_opt_no_indicators` that modifies the output indicators in the diff options structure. The patch includes thorough test coverage, verifying both the basic functionality and that colors remain intact when used with `--color`.

The commit message clearly explains the motivation - making diff output more copy-paste friendly - and the implementation appears clean and well-tested. This seems like a focused, practical quality-of-life improvement for users who frequently work with diff output in their workflows.

The patch stands alone (not part of a series) and touches only the diff machinery and its tests. It follows Git's established patterns for adding new diff options and maintains backward compatibility.
