This is a discussion response regarding a proposed feature to add a `--no-indicators` option to `git diff`. The original patch from Harald Nordgren would replace the '+', '-', and ' ' indicators in diff output with spaces while preserving colors, aimed at making copy-pasting cleaner.

Collin Funk questions whether this feature is necessary, suggesting that a simple `sed` command could achieve similar results. He expresses skepticism about the need for this option, noting that diff indicators are likely useful most of the time. The response doesn't propose any changes to the patch itself but rather challenges its motivation and necessity.

The exchange highlights a potential design question about whether this functionality belongs in core Git versus being handled by post-processing tools. The original patch appeared well-crafted with clear tests, but this response raises valid questions about its actual utility and whether it solves a problem common enough to warrant a new option.
