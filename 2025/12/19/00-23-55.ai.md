This is the third patch in a v2 documentation series improving the `git reset` man page, focusing on mode behavior clarifications. The patch addresses specific user confusion points identified by Julia Evans, now incorporated into the series by D. Ben Knoble with sign-offs from both Evans and Junio Hamano.

The changes systematically restructure the mode descriptions to prioritize user comprehension: (1) standardizing "index" terminology, (2) reordering modes to put `--mixed` (the default) first, and (3) adopting a consistent three-part explanation for each mode (working directory impact -> index changes -> practical examples). Key technical details include preserving the `--merge` mode's obscure use case clarification while making `--soft`/`--mixed`/`--hard` behaviors more distinct through structured comparisons of working tree and index impacts.

The patch maintains all prior technical accuracy from earlier iterations while implementing pedagogical improvements. It represents the culmination of collaborative refinement, with all sign-offs indicating resolved technical questions. The changes touch only documentation formatting and wording in `Documentation/git-reset.adoc`, with no behavioral modifications to the command itself. This completes the mode clarification portion of the broader `git reset` documentation overhaul.
