Bugfix for refs debug tracing output. This is a follow-up to a recently proposed patch that fixes incorrect debug output in `refs/debug.c`. The original patch from Greg Funni correctly identified that the debug trace for `optimize_required()` was checking the pointer address rather than the boolean value it points to, causing it to always print "yes".

Junio C Hamano notes in this email that the bug was introduced in commit f6c5ca38 and CCs the original author of that commit for review. The fix is minimal - just adding a dereference operator (`*`) to properly check the boolean value. This affects only debug output and doesn't change any runtime behavior.

The change is clearly correct for its stated purpose, though we haven't seen any reviews yet beyond Junio's acknowledgement. Since this is a straightforward one-line fix to debug output that was clearly wrong, it's likely to be accepted without much discussion.
