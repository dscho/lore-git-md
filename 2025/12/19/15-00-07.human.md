This is a documentation and help text clarification patch for the `git worktree` command. 

Sam Bostock noticed that the `--expire` option for both `git worktree list` and `git worktree prune` was inconsistently documented - using "unused" in one place and "missing" in another, when in fact the option only affects worktrees where the working directory path no longer exists. The patch updates the help text and documentation to consistently use "missing worktrees" throughout.

The changes are straightforward and clearly motivated - they improve accuracy and consistency in the documentation without changing any functionality. The patch touches both the man page and the builtin command's help text, using the same phrasing in both places. This appears to be a well-scoped, non-controversial improvement to the user-facing documentation.
