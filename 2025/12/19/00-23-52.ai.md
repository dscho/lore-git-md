This is a documentation patch series (v2) that continues Julia Evans' work to clarify the `git reset` man page. D. Ben Knoble is now shepherding the series after Julia's departure, incorporating Junio Hamano's technical feedback while preserving Julia's pedagogical style.

The 4-patch series makes several key improvements to the DESCRIPTION section:
1. Reorders the command forms to prioritize the `[<mode>]` variant that users report using most frequently
2. Restructures the introduction to clearly separate reset's two main purposes (HEAD movement vs index updates)
3. Clarifies mode differences: 
   - `--soft` now explicitly notes working tree/index preservation
   - `--hard` better describes file overwrite behavior
   - `--merge` documents its niche use cases
4. Simplifies pathspec documentation by replacing jargon ("tree-ish", "hunks") with clearer terms

Technical refinements include Junio's approved changes to index terminology and merge abort relationships. The patches maintain Julia's original goal of making reset's behavior more accessible while incorporating authoritative technical corrections. All substantive issues from the original review appear resolved, with only minor phrasing differences remaining between versions.
