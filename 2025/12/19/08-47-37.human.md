Curl maintainer Daniel Stenberg responds to Jeff King's analysis of the curl 8.18.0 compatibility issues. This is part of the ongoing test suite maintenance series addressing HTTP test failures with curl's new version.

Stenberg acknowledges an oversight in his initial fix for header unfolding behavior, noting that it didn't properly handle cases where tabs rather than spaces were used for folding. He commits to updating the curl implementation to ensure any leading whitespace character (space or tab) in folded headers gets replaced with a single space during unfolding.

This exchange shows the productive collaboration between Git and curl maintainers to resolve subtle HTTP protocol handling differences. The discussion has evolved from simply fixing test failures to ensuring proper standards compliance while maintaining backward compatibility. Stenberg's quick response indicates the issue will likely be resolved in curl itself, which may simplify Git's test accommodations.
