This is a build system patch addressing platform compatibility in the Rust build infrastructure. Patrick Steinhardt is reviewing D. Ben Knoble's fix for a BSD/macOS compilation issue that occurs when building Git with Rust support enabled.

The problem stems from using a GNU-specific `sed -s` flag in `src/cargo-meson.sh`, which fails on BSD-derived systems like macOS. The script determines the host platform to set the correct library name (`gitcore.lib` for Windows vs others). The fix replaces the non-portable `sed` invocation with a standard `-n` plus pattern printing approach that works across all Unix-like systems.

Patrick confirms the fix matches their earlier discussion and gives his approval, though he modestly downplays his own contribution to the solution. The change is minimal (a one-character modification in the sed command) but important for cross-platform compatibility. This builds on earlier work from October 2025 that added Windows support to the build system.

The patch has already received positive feedback from Eric Sunshine as well, suggesting it's likely to be merged soon. This is part of Git's ongoing Rust integration efforts and meson build system modernization.
