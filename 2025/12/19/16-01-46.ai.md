Bugfix for bundle-uri subsystem addressing NULL URI segfaults and validation. This v2 patch from Sam Bostock builds on previous discussion by improving debug output consistency while maintaining the core validation checks.

The patch adds explicit validation in two key areas: during config parsing via `bundle_uri_parse_config_format()` where it now checks all bundle entries for NULL URIs using `hashmap_for_each_entry`, and in `fetch_bundle_uri_internal()` where it errors out if a bundle lacks a URI. The test suite (`t/t5750-bundle-uri-parse.sh`) is expanded with new cases for both missing URIs and "url" typos.

Notably, this version addresses Junio Hamano's feedback about debug output by modifying `summarize_bundle()` to explicitly mark missing URIs with "# uri = (missing)" comments rather than silently omitting them. This maintains the segfault protection while providing better debugging visibility into invalid bundle configurations.

The changes are focused and well-tested, with clear commit messages explaining both the technical fix and the rationale for the debug output change. This appears ready for inclusion barring any new concerns about the error reporting approach. The patch effectively hardens the bundle-uri subsystem against malformed input while maintaining consistent behavior between operational code and debugging paths.
