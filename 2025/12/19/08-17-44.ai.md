Feature addition to the diff command introducing a `--no-indicators` option. This patch adds a new `--no-indicators` flag to `git diff` and related commands that replaces the traditional '+', '-', and ' ' indicators in the left margin with spaces while preserving color output. The motivation is to make diff output cleaner when copy-pasting, as users won't need to manually remove the indicators.

The implementation adds a new callback function `diff_opt_no_indicators` that modifies the `output_indicators` array in the diff options struct, setting all indicator characters to spaces. The patch includes tests verifying both the basic functionality (that indicators are replaced with spaces) and that color output still works correctly with the new option.

The change touches `diff.c` to add the option parsing logic and `t/t4000-diff-format.sh` for test coverage. The implementation appears straightforward and well-tested, with clear commit message explaining the use case. This seems like a focused, practical addition that could be useful for users who frequently work with diff output in contexts where the indicators are undesirable.
