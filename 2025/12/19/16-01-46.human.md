This is a bugfix patch for the bundle-uri subsystem, addressing segfaults caused by malformed bundle entries. Sam Bostock's v2 follows up on Junio Hamano's feedback about debug output consistency.

Test coverage via `test-tool bundle-uri parse-config` verifies both error conditions. The implementation looks thorough, with clear error messages and comprehensive test cases.
