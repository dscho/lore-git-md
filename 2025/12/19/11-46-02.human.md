This is a brief follow-up in the `--no-indicators` feature discussion for `git diff`. 

Harald Nordgren responds to Phillip Wood's technical feedback about the patch, specifically addressing the observation that the current implementation leaves leading spaces when removing the +/- indicators. Nordgren acknowledges this as a valid point and expresses willingness to modify the patch to strip those spaces as well, contingent on whether the feature is deemed worth including in Git at all.

The exchange remains constructive but highlights the still-unresolved question of whether this functionality justifies a core Git option versus being handled by external tools. Nordgren's response suggests they're waiting for clearer consensus on the feature's viability before investing more effort in refinements. The thread continues to weigh the trade-offs between built-in convenience and keeping Git's option set minimal.
