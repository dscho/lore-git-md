Documentation patch reordering the command forms in `git-reset`'s man page to prioritize the most common usage pattern. This is part of a v2 series (1/4) shepherded by D. Ben Knoble to improve the `git reset` documentation, building on Julia Evans' earlier work.

The patch moves the `git reset [mode]` form to the top of the SYNOPSIS section, as user feedback indicated this is the most frequently used variant. The change makes the documentation flow better since the introductory description ("Reset current HEAD to the specified state") directly relates to this form. The commit notes that other reset forms could alternatively be done with `git restore`, making the mode-based form `git reset`'s unique functionality.

The patch maintains all technical accuracy while improving pedagogical structure. It's a straightforward reorganization that doesn't introduce new content but makes the existing information more accessible. The change has already been reviewed and signed off by both the original author (Julia Evans) and Junio Hamano, suggesting it's a well-vetted improvement to the documentation.
