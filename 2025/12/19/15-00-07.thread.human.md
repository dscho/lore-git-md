The changes are minimal and focused, affecting only documentation strings in `Documentation/git-worktree.adoc` and `builtin/worktree.c`. 

With these changes, the documentation now consistently uses "missing" to describe the relevant worktrees and "prune" to describe the action taken on them, while keeping the `--expire` option name itself unchanged.
