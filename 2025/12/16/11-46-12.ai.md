This is a test fix patch in a series preparing Git's test suite for Windows symlink support. It addresses a Windows compatibility issue in the credential-cache test script.

The patch fixes a remaining instance where `mkdir -m<mode>` is used in t0301-credential-cache.sh, which doesn't work on Windows. The test was previously skipped on Windows because it required the SYMLINK prerequisite, but with upcoming symlink support, this would become a problem. The fix splits the directory creation and permission setting into two steps using `mkdir -p` followed by `chmod`, following the same pattern as a previous Windows compatibility fix (0fdcfa2f9f5).

Key technical details:
- Modifies t/t0301-credential-cache.sh to handle directory permissions in a Windows-compatible way
- Changes affect a test case that verifies credential cache behavior when the user directory is a symlink
- Maintains the same 700 permission mode but applies it separately from directory creation
- Part of broader effort to enable Windows symlink support in the test suite

This is a straightforward fix that follows established patterns for Windows compatibility in the test suite.
