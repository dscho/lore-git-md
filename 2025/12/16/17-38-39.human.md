Feature patch adding object size reporting to `git repo structure`. This is part 4/7 of Justin Tobler's series to enhance repository statistics reporting.

The patch extends the `git repo structure` command to show the total inflated size of reachable objects by type (commits, trees, blobs, tags) in the keyvalue and nul output formats. It adds a new `inflated_sizes` field to the `object_stats` struct and calculates sizes during object traversal using `odb_read_object_info_extended()`. The documentation is updated to mention this new information.

The implementation looks thorough, with proper error handling and test coverage. The test case verifies the expected output format and values. This builds on previous refactoring work in the series to cleanly separate data collection from display formatting. The patch maintains backward compatibility while adding the new functionality.

This continues the series' trend of careful, incremental development with good test coverage. The changes are focused and well-contained, touching only the necessary files (builtin/repo.c, its documentation, and tests). The commit message clearly explains both the change and what's coming next (table format support in a follow-up patch).
