Windows compatibility patch for t7800-difftool.sh, part of the v3 series preparing Git's test suite for Windows symlink support. This final patch in the series addresses a test assumption that absolute paths start with forward slashes, which doesn't hold on Windows. The test currently passes due to SYMLINK prerequisite skipping on Windows, but will fail when MSYS2 enables symlink support by default.

The patch modifies the 'difftool --dir-diff handles modified symlinks' test to filter `ls` output by matching lines ending in colons rather than filtering paths starting with slashes. This makes the test work reliably across platforms while maintaining the same verification intent. The change affects two test blocks in t7800-difftool.sh, each using both --symlinks and --no-symlinks modes.

This completes the 10-part series that has been queued for integration, with all Windows-specific symlink test issues now addressed. The series includes fixes for apply.c, mingw.c, and multiple test scripts (t0001, t0301, t0600, t1006, t1305, t4115, t6423, t7800, t9700), establishing consistent cross-platform behavior for symlink-related tests.
