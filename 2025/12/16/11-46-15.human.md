This is part of a Windows compatibility series preparing for MSYS2's upcoming symlink support. Patch 8/10 in Johannes Schindelen's v3 series modifies t1305-config-include.sh to skip two symlink-related tests that don't apply to Windows.

The changes address a Windows-specific behavior where Git canonicalizes paths, causing symlinked gitdir paths to not match the expected test conditions. The patch simply marks these two tests with `!MINGW` to skip them on Windows platforms, rather than trying to make them pass. 

This follows the pattern seen elsewhere in the series of accommodating Windows' different symlink handling through test adjustments rather than core behavior changes. The maintainer has already queued the series, with this v3 iteration providing final refinements like these test skips. The changes are straightforward and uncontroversial, matching the series' goal of making the test suite work correctly with Windows symlinks.
