Test modification for Windows symlink compatibility in t1305-config-include.sh.

This patch is part of Johannes Schindelen's v3 series preparing Git's test suite for Windows symlink support, specifically addressing test expectations in t1305-config-include.sh. The change skips two test cases that expect Git to match symbolic link paths in gitdir: conditional includes, which doesn't align with Windows' behavior of canonicalizing paths.

The modifications:
1. Adds !MINGW prerequisite to "conditional include, gitdir matching symlink" test
2. Adds !MINGW prerequisite to its case-insensitive variant
3. Preserves the tests for non-Windows platforms where the symlink behavior differs

The patch follows the established pattern in this series of accommodating Windows' path canonicalization behavior while maintaining the original test coverage on Unix-like systems. This change is consistent with the series' goal of making the test suite pass when MSYS2 enables symlink support by default, without altering Git's actual behavior on Windows.

The commit message clearly explains the Windows-specific behavior (gitdir canonicalization) that makes these tests inapplicable, and the diff shows the minimal change needed to skip them appropriately. This matches the maintainer-approved approach seen in other patches of the series.
