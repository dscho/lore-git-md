This is a Windows compatibility fix in a test script, part of Johannes Schindelen's v3 series preparing Git's test suite for Windows symlink support. The patch addresses a lingering issue in t0301-credential-cache.sh where a test uses `mkdir -m<mode>`, which doesn't work on Windows. 

The change splits the directory creation and permission setting into two steps, replacing `mkdir -p -m 700` with `mkdir -p` followed by `chmod 700`. This matches the approach taken in a previous Windows compatibility fix (0fdcfa2f9f5). The issue was previously masked by the SYMLINK prerequisite that prevented the test from running on Windows, but will become relevant when MSYS2 enables symlink support by default.

This is a straightforward, well-justified change that maintains consistency with the series' other Windows compatibility fixes.
