This is a v3 iteration of a 10-part series preparing Git's test suite for Windows symlink support, now queued for integration after maintainer approval. The series addresses test failures that would occur when MSYS2 enables symlink support by default, building on Git for Windows' existing symlink capabilities.

The v3 changes are minimal documentation polish, following Junio Hamano's approval of the technical approach in v2. Key technical elements remain unchanged: Windows-specific path handling in several test scripts (t7800, t0301, etc.), POSIX-compliant emulation of `open()` with `O_CREAT|O_EXCL` on symlinks, and fixes for Perl tests that had been silently broken. The series also includes edge case handling like special treatment for `/dev/null` symlinks and `core.preferSymlinkRefs` configuration.

The work is part of a larger effort to upstream Git for Windows' symlink support, anticipating MSYS2 runtime changes. The patches demonstrate careful attention to cross-platform compatibility while maintaining test reliability. With all feedback addressed and the maintainer's approval, this appears ready for merging.
