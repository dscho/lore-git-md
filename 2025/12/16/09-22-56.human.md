This is part 10 of a 12-part series refactoring Git's hook subsystem to use the new `hook.h` API, specifically converting receive-pack's update hook. The patch introduces a `hook_output_to_sideband()` callback that properly handles sideband protocol output from hooks, including keepalive packets.

Patrick Steinhardt noted a minor style nit about an unnecessary NULL check on the output parameter, which Adrian Ratiu acknowledges should ideally trigger a BUG() rather than silently continuing. However, both agree this isn't serious enough to warrant a reroll of the series.

The conversion maintains all existing functionality while integrating with the new hook API's output capture capabilities. This is one of the final pieces in the comprehensive hook refactoring effort, with only minor documentation updates remaining in part 12. The series has received thorough review and appears ready for merging once these last tweaks are addressed.
