This is a refactoring patch in the submodule gitdir path encoding series, specifically addressing validation logic consolidation.

Patrick Steinhardt is reviewing Adrian Ratiu's patch that centralizes submodule gitdir validation within the `submodule_name_to_gitdir()` function. The change moves validation checks that previously appeared in multiple places after calls to this function into the function itself. This creates a cleaner API where validation happens automatically, reducing the chance of callers forgetting to validate paths.

The patch maintains two remaining validation calls outside the function where they're needed to prevent parallel clone races, showing thoughtful consideration of edge cases. Steinhardt approves the change, noting it correctly removes redundant validation checks while preserving necessary ones. This appears to be a straightforward improvement that makes the code more robust by design, following the principle that functions should return valid results rather than requiring callers to validate them.

As part of the larger series, this helps establish consistent validation behavior before the introduction of config-provided gitdir paths in subsequent patches. The change doesn't introduce new functionality but makes the existing system more maintainable and less error-prone.
