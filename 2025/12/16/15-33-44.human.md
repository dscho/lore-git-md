This is a cover letter for a patch series preparing for symlink support on Windows, part of the ongoing platform compatibility work. The series contains 5 patches from two authors (Johannes Schindelin and Karsten Blees) that address various edge cases needed to properly support symlinks in Git for Windows.

The changes span several areas: Windows-specific path handling in `mingw.c`, early parsing of core.* settings in `strbuf_readlink()`, and directory separator handling. The patches appear to be final preparatory work before enabling full symlink support, building on previous test suite preparations.

The changes are relatively small and focused, touching 6 files with net -4 lines of code. The cover letter clearly explains the purpose of these seemingly unrelated changes as being necessary groundwork for proper symlink functionality. Given the authors' deep Windows expertise and the preparatory nature of these changes, this series looks like important plumbing work that should integrate smoothly.
