This thread focuses on preparatory work for proper Windows symlink support in Git, with contributions from Windows experts Johannes Schindelin (Git for Windows maintainer) and Karsten Blees. The initial 5-patch series addressed technical prerequisites across multiple subsystems, including symlink resolution in mingw.c, core configuration parsing, and path handling utilities. These changes were positioned as the final blockers before upstreaming broader symlink support.

A new bugfix patch from Johannes Schindelin specifically addresses an issue where `git rev-parse --is-inside-work-tree` fails in directories containing symlinks. The solution modifies `mingw_getcwd()` to consistently use the modern `GetFinalPathByHandleW()` API (available since Windows Vista) rather than falling back to it, removing legacy Windows XP compatibility code. This focused change both fixes the immediate issue and simplifies the code by 4 lines.
