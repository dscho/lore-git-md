This is a test fix in Johannes Schindelen's series preparing Git's test suite for Windows symlink support. The patch addresses a test failure that occurs when comparing symlink contents on Windows.

The test 're-init to move gitdir symlink' checks the contents of a symlink file, but `git diff --no-index` (which Windows uses via `test_cmp`) shows the symlink target rather than its contents. The fix detects when `--no-index` is in use and falls back to a simpler `cmp` comparison that works correctly with symlinks.

This is a straightforward fix that maintains the test's intent while accommodating Windows behavior. The patch is part of a well-vetted series that's already been approved by the maintainer, with Junio Hamano listed as a co-author on this particular fix. The change is minimal (just 5 lines added) and clearly explained in the commit message.
