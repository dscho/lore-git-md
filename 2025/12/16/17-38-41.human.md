Feature patch adding disk size metrics to `git repo structure` output.

This is patch 6/7 in Justin Tobler's series enhancing the repository structure reporting command. Building on previous work that added inflated object sizes, this patch extends the keyvalue and nul output formats to include disk space usage metrics for each object type (commits, trees, blobs, tags).

The implementation adds a new `disk_sizes` field to the `object_stats` struct and collects the data through `odb_read_object_info_extended()`, similar to how inflated sizes are gathered. The output now includes four new fields in the keyvalue format (e.g. `objects.commits.disk_size`) and corresponding nul format entries. Test coverage is updated to verify the new metrics by comparing against `git rev-list --disk-usage` output.

The patch follows the established pattern from earlier in the series, maintaining clean separation between data collection and presentation. It's a straightforward extension of the existing infrastructure that provides useful additional repository metrics without disrupting the command's core functionality. The changes are well-contained and include appropriate documentation updates.
