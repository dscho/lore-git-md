This is a discussion about macOS build system configuration in the ongoing thread about character encoding issues on macOS.

Torsten Bögershausen questions whether the fine-grained `USE_HOMEBREW_*` flags (like `USE_HOMEBREW_GETTEXT` and `USE_HOMEBREW_MSGFMT`) in René Scharfe's v3 patch series are actually necessary. The thread has been exploring different approaches to handle macOS package manager integration, particularly for Homebrew installations, to work around iconv conversion issues affecting some tests.

The discussion appears to be moving toward simplifying the build system configuration, with both Torsten and René expressing skepticism about the need for these individual component flags. This follows earlier suggestions in the thread that a simpler approach using just `NO_HOMEBREW` might be sufficient, rather than having separate flags for each component.

The exchange is brief but represents an important design decision point in the ongoing effort to improve macOS compatibility while keeping the build system maintainable.
