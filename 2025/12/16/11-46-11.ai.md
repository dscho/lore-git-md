Bugfix in test suite for Windows symlink handling, part of the v3 series preparing for MSYS2's symlink support. This patch fixes test case 're-init to move gitdir symlink' in t/t0001-init.sh that was failing on Windows due to unexpected behavior of `git diff --no-index` with symlinks.

The test compares the contents of a symlink (newdir/.git) against an expected file, but `git diff --no-index` (used by `test_cmp` on Windows) shows the symlink target rather than resolving it. The fix adds a conditional that uses `cmp` instead of `test_cmp` when `GIT_TEST_CMP` contains `--no-index`, which properly handles the symlink comparison on Windows.

This is a straightforward test fix that maintains the original test's intent while accommodating platform differences in symlink handling. The change is minimal and focused, affecting only the comparison method while keeping all other test assertions intact. The patch is co-authored by Junio Hamano, indicating maintainer approval of the approach.

This fix is part of the larger effort to make Git's test suite work correctly when MSYS2 enables symlink support by default, and specifically addresses a test that would fail due to Windows-specific behavior of the diff tool. The solution follows the pattern of other platform-specific accommodations in the test suite.
