This is a refactoring patch that's part of Justin Tobler's series adding object size reporting to `git repo structure`. It's the first of seven patches in v4 of the series.

The patch reorganizes the code in `builtin/repo.c` to better support the upcoming size reporting functionality. It introduces a new `object_values` struct to group the per-type counts (tags, commits, trees, blobs) that were previously direct members of `object_stats`. This structural change makes it easier to add new per-type measurements (like sizes) in subsequent patches.

The changes are mechanical but thorough - all references to the object counts are updated to use the new nested struct. The patch maintains all existing functionality while setting up for future additions. The commit message is clear about being a preparatory change for later work in the series.
