This is a build system patch addressing macOS Homebrew integration, part of the ongoing effort to fix character encoding issues on macOS.

René Scharfe's patch makes Homebrew usage on macOS more configurable by introducing several new Makefile variables. The key changes allow users to: disable Homebrew entirely (NO_HOMEBREW), specify a custom installation location (HOMEBREW_PREFIX), and selectively enable Homebrew components (USE_HOMEBREW_GETTEXT, USE_HOMEBREW_MSGFMT). The patch also improves precision by linking specifically to Homebrew's gettext "keg" (opt/gettext subdirectory) rather than broader Homebrew paths.

The changes move Homebrew-specific logic from config.mak.uname to the main Makefile while maintaining backward compatibility. The patch sets sensible defaults - using /opt/homebrew for ARM Macs and /usr/local for Intel Macs, while enabling gettext and msgfmt by default. This appears to be a well-considered refinement of the build system that addresses previous feedback about making the Homebrew integration more explicit and configurable.

This is the first of two patches in v3 of the series, building on extensive discussion about macOS package manager handling and character encoding issues. The changes align with maintainer Junio Hamano's preference for explicit component flags and unified HOMEBREW_PREFIX handling.
