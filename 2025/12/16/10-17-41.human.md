This is part of the submodule gitdir path encoding series, specifically implementing the migration command for existing repositories to adopt the new path configuration system.

The patch adds a `module_migrate` command to `submodule--helper` that enables the `extensions.submodulePathConfig` extension and sets up the required configuration for existing repositories. Patrick Steinhardt suggested improving the atomicity of the migration by first creating the gitdir config entries before enabling the extension, which Adrian Ratiu acknowledges and will implement. This change ensures failed migrations leave repositories in a usable state.

The migration is now restricted to explicit invocation (rather than automatic) and only affects repositories where users opt in, addressing earlier compatibility concerns. The implementation maintains the four-tier fallback system for path resolution while transitioning to the new configuration-based approach.

This patch represents one of the final pieces in the series, which has reached architectural consensus after several rounds of review. The remaining work focuses on documentation improvements and some polish to error messages and code flow.
