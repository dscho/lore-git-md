This is a refactoring patch that's part of Justin Tobler's v4 series adding object size reporting to `git repo structure`. The patch restructures the code to prepare for adding size measurements by introducing a new `object_values` struct to group per-type object counts (tags, commits, trees, blobs) that were previously direct members of `object_stats`. 

The changes include:
1. Moving the object count fields into a new `object_values` struct
2. Updating all references to use the new nested structure (`stats->type_counts.field` instead of `stats->field`)
3. Renaming `get_total_object_count()` to `get_total_object_values()` to better reflect its new scope
4. Maintaining identical output formatting while changing the internal representation

The patch touches only `builtin/repo.c`, modifying 42 lines (25 additions, 17 deletions) to implement this structural change. This is a clean preparatory change that doesn't affect functionality but enables the subsequent patches in the series to add size measurements alongside the counts in a consistent way. The commit message clearly explains the motivation for the change (to allow better reuse when adding new per-type measurements).
