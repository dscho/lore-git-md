This is part of a Windows compatibility series preparing for MSYS2's planned symlink support. Patch 7/10 modifies t1006-cat-file.sh to handle path normalization quirks when MSYS2 creates native Windows symlinks.

The patch adjusts two test cases in t1006 that make assumptions about symlink paths that don't hold under MSYS2's symlink implementation. The first test case (`out-of-repo-link-dir-trailing`) now produces different output on Windows due to path normalization, while the second test case (`up-down` and `up-down-trailing`) is skipped entirely on Windows since the symlinks get normalized into a different form than Git expects. Both changes are guarded by `MINGW` and `SYMLINKS` prereq checks.

Key technical details:
- Tests modified: `t1006-cat-file.sh` tests for `--follow-symlinks` behavior
- Windows-specific behavior: MSYS2 normalizes symlink targets to Win32 paths
- Test adjustments:
  - First test case now outputs different expected values on Windows (2 vs 3 for symlink size, no trailing slash)
  - Second test case is skipped on Windows due to path normalization
- Maintains existing behavior for non-Windows platforms
- Part of larger effort to make tests pass with MSYS2's native symlinks
- Follows pattern seen in other test fixes in this series (t0001, t0301, etc.)
- No core Git behavior modified - purely test accommodation

The changes are straightforward test accommodations for Windows-specific symlink behavior, consistent with the series' goal of preparing for MSYS2's symlink support. The patch maintains test coverage while accounting for platform differences in symlink handling.
