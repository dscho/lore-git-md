This is patch 6/7 in Justin Tobler's series adding object size reporting to `git repo structure`, focusing on disk size metrics in the keyvalue output format.

It adds a new `disk_sizes` field to the `object_stats` struct and populates it via `odb_read_object_info_extended()`'s `disk_sizep` parameter. The implementation maintains consistency with the series' approach by:
- Adding parallel disk size fields alongside existing count and inflated size metrics
- Using the same type-specific breakdown (commits/trees/blobs/tags)
- Following established output patterns with new `objects.<type>.disk_size` keys
- Including test coverage that matches the existing size reporting tests

The changes touch the same core areas as previous patches - the stats collection in `builtin/repo.c`, documentation updates, and test verification.
