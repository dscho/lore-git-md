This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the current state of patches in the Git development pipeline as of December 2025. These updates help track which patches are progressing toward inclusion and which need more work.

Several topics have recently graduated to 'master', including fixes for zsh test compatibility, documentation improvements for `git replay`, and optimizations for the patience diff algorithm. New topics introduced include a protocol capability leak fix, various documentation updates, and a new `--keys` option for `git repo info`.

Notable ongoing work includes further MIDX/bitmap optimizations for incremental repacking, Windows symlink support improvements in the test suite, and a major refactoring of the object streaming interface. There's also significant activity around submodule handling improvements and the introduction of a new `git history` command for history rewriting.

The update notes several topics that are awaiting rerolls or have outstanding questions, including work on reference backend configuration, global config handling, and SHA-1/SHA-256 interoperability. A few patches have been discarded, like one attempting to complete single-letter Git options, which doesn't align with project conventions.

As usual during December, the maintainer notes that progress may be slower due to reduced availability, but the pipeline remains active with a mix of bugfixes, optimizations, and new features at various stages of review.
