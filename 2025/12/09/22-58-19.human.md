Feature patch adding disk size reporting to Git's `repo structure` command. This is patch 5/6 in a series enhancing the command's object reporting capabilities.

The patch builds on previous work that added inflated (content) size reporting by now including on-disk sizes for objects in the keyvalue and nul output formats. It adds a new `disk_sizes` field to the `object_stats` struct and collects the data via `odb_read_object_info_extended()`. The implementation is careful to note that disk sizes may vary across platforms, so tests only verify the presence of size fields rather than specific values.

This continues the series' clean separation of concerns, with the disk size functionality following the same pattern as the inflated size implementation from earlier patches. The test updates maintain the SHA1-specific patterns seen throughout the series, which may need addressing for hash algorithm portability. The patch appears well-structured with thorough test coverage of the new functionality.
