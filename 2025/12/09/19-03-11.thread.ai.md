Proposal to standardize `--staged` flag across Git commands for index operations, replacing/supplementing the older `--cached` terminology. Thread root introduces the inconsistency: while newer commands (`git restore`, `git stash`) use `--staged`, older ones (`git rm`, `git grep`) still require `--cached`, with `git diff` accepting both since 2008 (commit 2baf1850ce). Author notes this creates minor usability friction when muscle memory leads to typing `--staged` for older commands. Historical context: Git documentation has marked "cache" as obsolete terminology since 2005, but the flag remains in widespread use. Proposal is framed as a consistency improvement rather than bugfix, with no technical objections anticipated but potential discussion points around backward compatibility and scope (whether to update all index-related commands at once).
