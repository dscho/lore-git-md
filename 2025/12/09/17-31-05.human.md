This is the fifth patch in Patrick Steinhardt's refactoring series for Git's object database alternates handling, focusing on eliminating mutual recursion in the alternates parsing code.

Justin Tobler provides a positive review of the changes, noting that the patch successfully separates the concerns of parsing alternates files from the recursive addition of alternate sources. The key improvement moves the recursion logic entirely into `odb_add_source()`, making `read_info_alternates()` responsible only for parsing a single alternates file. This makes the code flow more straightforward to follow.

The patch maintains the same functionality while improving the architecture - alternates from both environment variables and info files are still processed, with the same depth checking (limited to 5 levels) preserved. Justin confirms the changes match the previous behavior while being easier to reason about, giving the patch his approval without requesting any modifications.

This continues the series' systematic approach to restructuring alternates handling as part of the broader ODB abstraction effort, with each patch receiving careful review from Justin Tobler. The changes here appear well-considered and technically sound, clearing the way for further refactoring in subsequent patches.
