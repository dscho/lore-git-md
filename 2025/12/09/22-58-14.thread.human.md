This thread covers Justin Tobler's 6-part patch series that enhanced Git's `repo structure` command with detailed object size reporting (both inflated content sizes and on-disk storage sizes) and improved output formatting. The series was merged by Junio Hamano after incorporating feedback from Patrick Steinhardt and others, though it required resolving some conflicts with Lucas Seiki Oshiro's earlier work making `-z` a synonym for `--format=nul`.

The implementation added new infrastructure for tracking both inflated and disk sizes, with careful attention to output formatting (using decimal SI units for counts and binary IEC units for sizes) and internationalization (gettext-marked unit strings). The test suite was strengthened with cross-verification against `git rev-list --disk-usage` and platform-independent size reporting.

In a follow-up discussion, Lucas Seiki Oshiro noted a test conflict between the merged features and proposed adjusting the test case organization to maintain proper behavior of the `-z` option (following Git's "last one wins" rule for conflicting options). The change ensures both features work together correctly in the test suite. The thread demonstrates the project's attention to maintaining compatibility between independently developed features, even after merging.
