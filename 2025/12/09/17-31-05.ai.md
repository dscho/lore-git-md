This is the fifth patch in Patrick Steinhardt's 8-part refactoring series to modernize Git's alternates handling as part of the object database abstraction effort. The patch eliminates mutual recursion between `link_alt_odb_entries()` and `odb_add_source()` by restructuring how alternates are processed. Previously, these functions called each other in a way that intertwined parsing alternates with adding them to the database. The new approach makes `read_info_alternates()` responsible only for parsing a single alternates file, while `odb_add_source()` handles all recursive addition of alternates.

Justin Tobler reviews the changes positively, noting the new separation of concerns makes the code easier to reason about while maintaining the same behavior. The key technical changes include modifying `read_info_alternates()` to return parsed paths via a `strvec` rather than processing them directly, and having `odb_add_source()` manage both the initial addition and any recursive processing of nested alternates. The patch follows the series' pattern of moving toward source-based operations while preserving existing functionality.
