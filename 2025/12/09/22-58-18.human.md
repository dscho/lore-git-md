Feature enhancement for `git repo structure` command. This is patch 4/6 in a series adding object size reporting capabilities.

Justin Tobler extends the table output format of `git repo structure` to display inflated object sizes in a human-readable way, building on the infrastructure from earlier patches. The output now shows both object counts (already present) and their total compressed sizes, with automatic scaling to KiB/MiB/GiB units for large values. The implementation handles unit conversion with two decimal places of precision and proper rounding.

The patch introduces a new `stats_table_size_addf()` helper that formats size values similarly to how counts were already being formatted, but with byte units. The test suite is updated to verify both empty repository output and a more complex case with actual objects (though the latter is currently SHA-1 specific). The implementation appears clean and follows the established patterns from earlier patches in the series.

This completes one of the two main goals of the series (inflated size reporting), with the output now appearing in the table format alongside the existing counts. The remaining patches will presumably add the complementary on-disk size reporting. The changes are well-contained and maintain backward compatibility with the keyvalue and nul output formats.
