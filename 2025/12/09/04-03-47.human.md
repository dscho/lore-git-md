This is a follow-up in the ongoing discussion about macOS's broken iconv implementation affecting Git's character conversion tests. Collin Funk adds context by pointing to a message from the GNU iconv maintainer expressing frustration with Apple's custom iconv implementation in macOS 14, which was already known to be problematic before the specific regression in macOS 15 that this thread identified. The note reinforces that this is an Apple-specific issue rather than a Git bug, though it doesn't directly advance the technical discussion about workarounds. The thread appears to be winding down with consensus that either using Homebrew-provided libiconv or applying a compile-time workaround are the viable solutions.
