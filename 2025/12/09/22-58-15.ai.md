Refactoring patch in a series adding object size reporting to `git repo structure`.

This is the first of six patches introducing object size reporting capabilities to Git's `repo` command. The patch performs preparatory refactoring by restructuring how object type counts are stored. It introduces a new `object_values` struct to hold the per-type counts (tags, commits, trees, blobs) that were previously direct fields of `object_stats`, then nests this struct within `object_stats`. This creates a logical grouping that will accommodate the planned addition of size metrics in later patches.

The changes are mechanical but thorough, updating all references to the moved fields through helper functions and call sites. The patch touches key output formats (table and key-value) and the object counting logic, ensuring consistent access to the new structure. While this patch doesn't add functionality, it demonstrates careful attention to maintainability by establishing the foundation for the size reporting features to come in patches 3-6. The commit message clearly states its limited scope and relationship to the series' broader goals.
