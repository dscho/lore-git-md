This is a refactoring patch in Patrick Steinhardt's series modernizing Git's object database alternates handling. The patch moves the computation of the normalized object directory path from callers into the `alt_odb_usable()` function (renamed to `odb_is_source_usable()`), eliminating redundant parameter passing. Justin Tobler reviews the change positively, noting that the normalized path was only used within this function anyway, making the relocation logical. He also points out a minor typo in the function's documentation ("iff" -> "if") that could be fixed while making these changes. The patch continues the series' pattern of restructuring alternates handling to work through the new "source" abstraction rather than direct filesystem operations, with no behavior changes intended. Justin's review confirms the technical approach is sound, though he doesn't explicitly address the function renaming aspect that was part of this change.
