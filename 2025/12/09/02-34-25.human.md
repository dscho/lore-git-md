This is a refactoring patch in Patrick Steinhardt's series modernizing Git's object database alternates handling. The patch moves the computation of the normalized object directory path into the `alt_odb_usable()` function (renamed to `odb_is_source_usable()`), eliminating redundant parameter passing from callers.

Justin Tobler provides a positive review, noting the change makes sense since the normalized path is only used within this function. He also points out a minor typo ("iff" -> "if") in the function's documentation that could be fixed while making these changes. The technical approach appears sound, continuing the series' pattern of cleaning up the alternates handling code to work through the new "source" abstraction rather than direct filesystem operations.

This is the third patch in an 8-part series that's part of Git's ongoing object storage modernization effort. The changes are focused on internal implementation details rather than user-visible behavior, with the broader goal of enabling support for pluggable object database backends.
