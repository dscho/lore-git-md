This is the fourth patch in a documentation standardization series converting Git manual pages to use the new synopsis block format. The patch updates the `git-stage` manpage, replacing the old verse-style command synopsis with the new `[synopsis]` block format.

The change is minimal but consistent with the series' goal - it removes the verse formatting and single quotes around the command name while keeping the actual content identical. This matches the style changes made to `git-status` in earlier patches.

As with the rest of the series, this is purely a documentation formatting improvement with no behavior changes. The patch maintains all technical content while modernizing the markup syntax for better maintainability and translatability. The change follows the pattern established in previous patches and appears to be a straightforward application of the new documentation standards.
