Test fix for documentation validation. This is the first patch in a series standardizing Git's manual page formatting. It corrects a test helper script (`t0450-txt-doc-vs-help.sh`) that validates consistency between command-line help text and manual pages. The script was incorrectly processing multiple synopsis blocks when it should only capture the first one. The fix modifies a `sed` command to quit after the first empty line following a synopsis block, ensuring proper validation of the primary command syntax section.

The change is straightforward - a one-line modification replacing `d` (delete) with `q` (quit) in the `sed` script. This maintains the test's purpose while fixing its behavior for manpages with multiple synopsis sections. As the first step in a larger documentation standardization effort, this patch appears well-scoped and correctly implemented.
