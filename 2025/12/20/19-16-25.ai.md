Documentation patch converting `git-status` tables to AsciiDoc format, part of a 5-patch series standardizing Git manual pages. This patch specifically replaces hand-formatted ASCII-art tables in `git-status.adoc` with proper AsciiDoc table syntax, affecting several sections including status codes, branch headers, and rename/copy/unmerged entry formats.

The conversion maintains all technical content while improving maintainability and translatability, as AsciiDoc tables allow for per-cell translations. Key changes include:
- Replacing `....` delimited ASCII tables with `|===` AsciiDoc tables
- Adding column specifications (`cols="..."`) and header options
- Preserving all field descriptions and status code explanations
- Converting special characters like `|` to escaped form (`\|`) where needed
- Maintaining the same information density while using AsciiDoc's formatting capabilities

This builds on previous patches in the series that standardized synopsis blocks and converted option descriptions to AsciiDoc lists. The changes are purely presentational - no content is altered, only the markup syntax. The patch follows the documentation standardization effort led by Jean-Noël Avila, with test infrastructure updates already handled in earlier patches.
