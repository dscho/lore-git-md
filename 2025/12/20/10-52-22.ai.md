This is a follow-up in the ongoing discussion about adding a `--no-indicators` option to `git diff` and `git show`. Harald Nordgren responds to Junio Hamano's request for precedent in other diff tools by noting that GNU diff supports similar functionality through `--line-format='%L'`, though with the limitation that it also disables colors. The email suggests Git could implement a "smarter" version that preserves colors when outputting to a terminal.

The response continues the pattern of the thread where the proponent focuses on demonstrating precedent while not addressing the core objections raised by maintainers about feature necessity versus existing solutions. The technical detail about GNU diff's behavior is new information, but the email doesn't connect this to the unresolved issues in the proposal (handling of newline markers, space stripping) or the demonstrated alternative workflows using existing Git commands. The suggestion about TTY-aware color preservation hints at implementation direction but doesn't provide concrete technical details.
