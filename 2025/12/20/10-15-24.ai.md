This is a refactoring patch that's part of the larger submodule gitdir path encoding series. It moves the `is_rfc3986_unreserved()` function from being a static helper in `builtin/credential-store.c` to a public function in `url.[ch]` where it can be shared across the codebase.

The change is motivated by the need to use RFC3986 URL encoding for submodule names when constructing gitdir paths, to avoid filesystem conflicts. While this function was previously only used by credential-store, it's now needed more broadly for the submodule path encoding work. The patch maintains the exact same functionality while making it available to other parts of Git.

Key technical details:
- Moves the function implementation to `url.c`
- Adds declaration to `url.h` with documentation comment
- Updates credential-store.c to include url.h and use the moved function
- Keeps identical behavior (checking for alphanumeric, '-', '_', '.', '~' characters)

This is a straightforward preparatory change that enables the subsequent patches in the series to use URL encoding for submodule paths. The implementation is clean and maintains existing functionality while making it more widely available.
