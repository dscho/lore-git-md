This is a follow-up in the ongoing discussion about adding a `--no-indicators` option to `git diff` and `git show`. Harald Nordgren responds to Junio Hamano's request for historical precedent by noting that GNU diff has a similar feature (`--line-format='%L'`) that removes +/- indicators, though it also disables colors. 

The email suggests Git could implement a "smarter" version that preserves colors when outputting to a terminal. However, it doesn't address the core objections raised earlier in the thread about whether this feature is necessary given existing alternatives like `git restore -p` and `git show` with temporary files. The response also doesn't engage with the technical concerns about edge cases (newline markers, space handling) that were previously raised.

The discussion appears to be at an impasse, with the maintainers skeptical about the feature's necessity and the proposer continuing to advocate for it based on personal workflow preferences without resolving the outstanding technical questions.
