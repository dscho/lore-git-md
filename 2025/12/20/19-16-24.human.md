Documentation patch converting `git-status` manpage to synopsis style format. This is part 2 of a 5-patch series standardizing Git's manual pages.

Jean-Noël Avila updates the `git-status` documentation to use the new synopsis style, replacing the old `[verse]` format with `[synopsis]` blocks. The patch also converts unformatted lists to proper AsciiDoc lists throughout the document. Changes are purely presentational - the content remains the same, just better structured.

The conversion touches all sections of the manpage: command synopsis, options (now consistently using backticks), output formats (with improved list formatting), and configuration notes. The patch maintains all existing information while making it more consistent with other modern Git documentation.

This continues the documentation standardization effort that began with a prerequisite test helper fix in patch 1. The changes are mechanical but thorough, showing careful attention to detail in preserving the meaning while updating the formatting.
