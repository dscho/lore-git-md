This thread documents Jean-Noël Avila's five-patch series standardizing the format of Git manual pages by converting them to a consistent synopsis style using AsciiDoc markup. The series focuses on `git-status`, `git-stage`, and `git-remote` manpages, along with updates to the test infrastructure to verify the new format.

The first patch fixed the test helper `t0450-txt-doc-vs-help.sh` to properly handle synopsis blocks, which was a prerequisite for the documentation changes. Subsequent patches systematically converted each manpage: replacing verse-style command synopses with `[synopsis]` blocks, standardizing placeholder and option formatting (now using `_<name>_` for placeholders and backticks for options), and converting ASCII-art tables to proper AsciiDoc tables while preserving all technical content. The final patch, just submitted, completes the series by applying these same transformations to the `git-remote` manpage.

Throughout the series, Jean-Noël has maintained all existing documentation content while modernizing the markup syntax. The changes improve maintainability and translatability through consistent AsciiDoc conventions, with no actual command behavior changes. This work is part of Jean-Noël's ongoing effort to standardize Git's documentation format across the codebase.
