This thread documents an ongoing effort by Jean-Noël Avila to standardize Git's manual pages by converting them to a consistent "synopsis style" format using AsciiDoc markup. The series began with a prerequisite fix to the test infrastructure (`t0450-txt-doc-vs-help.sh`) to properly handle the new synopsis blocks, followed by conversions of several key manpages.

The first substantive patch converted `git-status` to demonstrate the new approach: replacing verse-style command synopses with `[synopsis]` blocks, standardizing backtick quoting, and reformatting status code tables as proper AsciiDoc lists while preserving all technical content. A follow-up then updated `git-status`'s ASCII-art tables to proper AsciiDoc table syntax with column specifications and escaped special characters - a change that improves maintainability and enables per-cell translations.

The latest patch continues this mechanical conversion work by applying the same treatment to `git-stage`, replacing its verse-style synopsis with a `[synopsis]` block and removing unnecessary single quotes. Like the prior changes, this preserves all existing documentation content while modernizing the markup syntax. The series is progressing smoothly with each patch following the established pattern, and no substantive discussion or objections have been raised about the approach.
