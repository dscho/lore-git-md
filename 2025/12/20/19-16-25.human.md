Documentation patch converting `git-status` tables to AsciiDoc format. This is the third patch in a series standardizing Git's manual pages.

Jean-Noël Avila replaces hand-formatted ASCII-art tables in `git-status.adoc` with proper AsciiDoc table syntax. The conversion affects several tables describing status output formats, including the main status codes, branch headers, and detailed field descriptions for renamed/copied and unmerged entries. The content remains identical - this is purely a formatting change to make the documentation more maintainable and translation-friendly.

The patch demonstrates careful attention to preserving all technical details while improving the markup. Tables are now properly structured with column definitions and headers, and special characters like pipes and backticks are correctly escaped. This follows the series' goal of modernizing Git's documentation infrastructure.

As noted in the thread context, this change may affect visual presentation but enables per-cell translations, which benefits localization efforts.
