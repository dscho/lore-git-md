While this might temporarily affect users running unreleased curl versions in distributions like Debian unstable, the issue will resolve naturally when curl 8.18.0 is officially released.

This marks the successful conclusion of cross-project coordination between Git and curl maintainers to align HTTP protocol handling with RFC 7230 standards.
