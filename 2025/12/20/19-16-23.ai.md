Test infrastructure patch fixing the `t0450-txt-doc-vs-help.sh` test helper as part of a documentation standardization series. This first patch in the series corrects how the test script extracts synopsis blocks from AsciiDoc files when comparing documentation with command help output.

The test helper previously would incorrectly process multiple synopsis blocks (marked with `[synopsis]` or `[verse]`) in a single file, continuing to collect text until the first empty line after any block. The fix modifies the `sed` command to quit (`q`) after the first empty line following a block, ensuring only the intended block is captured. This is a straightforward technical correction needed for the subsequent documentation conversion patches to work properly. The change affects only test behavior, not production code or documentation content.
