This is a refactoring patch in the submodule gitdir path encoding series, which consolidates validation logic for submodule gitdir paths.

The patch moves validation checks that were previously scattered after calls to `submodule_name_to_gitdir()` into the function itself. This ensures all callers get validated paths automatically, reducing redundancy and preventing potential validation misses. The author notes two validation calls remain outside the function to handle parallel clone race conditions.

This change simplifies the API while maintaining safety, and prepares for upcoming work that will allow user-configured gitdir paths. The diff shows straightforward removal of duplicate validation checks from three locations in `submodule--helper.c` and `submodule.c`, with one new check added inside `submodule_name_to_gitdir()`.

As part of the larger series implementing path encoding for submodule gitdirs, this patch represents a clean architectural improvement that makes the code more maintainable while preserving all existing functionality.
