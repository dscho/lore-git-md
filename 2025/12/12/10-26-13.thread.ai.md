Junio C Hamano's December 2025 "What's cooking in git.git" report tracks two distinct patch series. Adrian Ratiu's ar/run-command-hook series (11 patches) modernizes Git's hook API with receive/update hooks, reference transactions, and parallelization support, replacing ad-hoc `run_command()` with a structured API. Junio initially cautioned that passing tests alone doesn't guarantee API readiness and committed to personally reviewing the foundational changes before promoting to 'next'. Patrick Steinhardt reviewed v4 positively ("mostly good") with one outstanding question about implementation details. Adrian Ratiu is waiting for Junio's potential review before sending a final re-roll addressing both Patrick's question and any additional feedback. Emily Shaffer confirmed Josh Steadmon's absence from reviewing is due to personal matters rather than disinterest in the hook-related changes, which Junio acknowledged in a brief administrative update.

Aaron Plattner's ap/packfile-promisor-object-optim series (2 patches) optimizes promisor object enumeration by skipping unnecessary parsing of blob objects. The changes modify `add_promisor_object()` in packfile.c and object.c to avoid hash checks and extend skip_hash/discard_tree optimizations to unknown blobs. Jeff King (Peff) reviewed v2 positively but suggested splitting the changes. Junio Hamano has now manually verified that v3 properly incorporates Peff's feedback by comparing it to v2, noting the technical content remains substantively the same but is now better organized per the review suggestion. Despite some version tracking confusion due to an incomplete v3 mailing list presence, Junio has promoted the optimization to 'next', indicating confidence in both the technical changes and review process. This moves the patch series one step closer to mainline inclusion.

The thread shows careful coordination around both changes: the hook API modernization has three key stakeholders (Patrick for implementation, Junio for architecture, Josh as subsystem expert), while the promisor optimization has completed its review cycle with Jeff King's approval and Junio's verification. Both series are in final stages - the promisor optimization now in 'next' and the hook API awaiting Junio's architectural review and Josh's return before potential inclusion.
