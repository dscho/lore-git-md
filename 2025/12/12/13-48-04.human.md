This is a brief follow-up in the ongoing macOS iconv compatibility discussion, specifically about build system paths for package managers.

René Scharfe points out that the Fink package manager changed its installation path from `/sw` to `/opt/sw` six years ago, but Git's Makefile still references the old location. This came up in the context of ensuring proper iconv library paths for different macOS package managers (Homebrew, MacPorts, Fink) to work around Apple's problematic iconv implementation.

The note is a small correction to the broader discussion about how Git's build system should handle these paths. It doesn't propose any code changes but highlights that some of Git's assumptions about Fink's installation location are outdated. This reinforces the thread's theme that package manager path handling on macOS needs careful attention, especially since the iconv workaround requires finding the right libraries.
