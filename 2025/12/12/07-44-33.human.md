Refactoring of `git pull`'s option table structure. This is version 2 of a patch that moves the large `static struct option pull_options[]` array from file scope into `cmd_pull()`'s function scope, following Git's common pattern for builtin commands.

The change is purely mechanical - the 285-line diff relocates the entire array with all its `OPT_*` macros, groupings and comments preserved exactly. No behavior changes result from this move. The patch now frames the change more concisely than v1, simply stating it follows Git's customary practice rather than making broad readability claims.
