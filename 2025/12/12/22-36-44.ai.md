This is the final patch (7/7) in Justin Tobler's series extending Git's `repo structure` command with comprehensive object size reporting. The patch completes the human-readable table output by adding disk size information alongside the existing inflated size reporting.

The key technical additions are:
- New `disk_object_total` calculation and display in the structured table output
- Parallel display structure for disk sizes matching the existing inflated size layout (Commits/Trees/Blobs/Tags breakdown)
- Test updates including a new `strip_object_disk_usage` helper to handle platform-variant disk sizes in verification
- Maintains the established pattern of using binary (1024-based) IEC units (KiB/MiB/GiB) for size display

The implementation carefully handles platform-specific disk size variations by:
- Explicitly skipping disk size validation in tests for empty repositories
- Providing the `strip_object_disk_usage` filter to exclude disk sizes from test comparisons
- Keeping the SHA1-specific test patterns from earlier in the series

This completes the dual-size reporting capability across all output formats (machine-readable keyvalue/nul from previous patches and now human-readable table). The patch maintains consistency with the series' approach to internationalization, documentation, and test coverage while adding the final piece of functionality.
