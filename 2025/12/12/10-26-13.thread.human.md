Junio's December 2025 "What's cooking" report shows active development across Git's infrastructure and user-facing features. The highlight is Adrian Ratiu's 11-patch series modernizing Git's hook API, which is now ready for the 'next' branch after passing all tests. This foundational work enables future parallel and configurable hooks. Other notable efforts include ODB layer improvements, MIDX/bitmap optimizations, and continued Rust interoperability work. 

A platform-specific fix for macOS's problematic ISO-2022 string handling in iconv, originally from René Scharfe, has been updated with a new version that adds a NO_HOMEBREW build option. This gives users the choice to avoid Homebrew's iconv even when available, addressing concerns about build environment control. The patch maintains the original workaround's purpose while providing more flexibility, and the author has requested Junio delay merging the original until this version can be considered. 

The report also tracks several other topics in progress, including documentation updates, Windows test suite improvements, and new commands like `git history`. Junio's careful tracking shows Git's development remains active across multiple fronts, with clear indicators of which patches are stable enough for integration branches.
