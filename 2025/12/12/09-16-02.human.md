This is a follow-up discussion in the ongoing macOS iconv/Homebrew compatibility thread, focusing on package manager path detection specifics.

René Scharfe clarifies the different installation paths used by various macOS package managers in response to Junio Hamano's questions about whether the patch should account for MacPorts (formerly DarwinPorts) alongside Homebrew. He confirms Homebrew uses `/opt/homebrew` for Apple Silicon and `/usr/local` for Intel Macs, while MacPorts uses `/opt/local` and Fink uses `/opt/sw`. The current patch specifically handles Homebrew's two possible locations, checking the Apple Silicon path first.

This email provides important context about macOS package manager conventions but doesn't propose any code changes. It helps ground the technical discussion in the actual installation practices of these tools, which is relevant for deciding how comprehensive Git's build system detection should be. The information suggests that while the current patch is narrowly focused on Homebrew, there may be value in considering other package managers' paths if the solution is expanded in the future.
