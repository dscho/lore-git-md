This is a documentation patch in the Scalar configuration series, now in its third iteration (v3). It provides comprehensive user-facing documentation for all configuration settings that Scalar modifies during clone, register, and reconfigure operations.

The patch adds a new "RECOMMENDED CONFIG VALUES" section to scalar.adoc, detailing the rationale behind each configuration setting Scalar applies. The documentation covers 20+ settings across several categories: performance optimizations (like index.skipHash and index.threads), platform-specific behaviors (core.untrackedCache on Windows), background maintenance integration (gc.auto=0), and repository size considerations (fetch.unpackLimit=1). Each entry explains both the technical justification and any trade-offs involved.

Notable technical details include the forced index.skipHash=true setting (correcting a regression), the index.threads/index.recordOffsetTable interaction, Windows-specific SSL backend selection, and the temporary use of commitGraph.generationVersion=1 pending upgrade path resolution. The documentation also cross-references between the config settings in scalar.c and the new documentation via an added comment.

This patch builds on previous work in the series that removed obsolete configs and introduced "# set by scalar" annotations. It represents the culmination of the documentation effort for Scalar's configuration management, with Junio Hamano and Patrick Steinhardt having provided input. The thoroughness of the documentation suggests this is likely the final form before integration.
