This is part 4 of Justin Tobler's v2 series extending `git repo structure` with object size reporting. The patch adds inflated object size information to the keyvalue and nul output formats, building on the previous work to report object counts by type.

The change introduces a new `inflated_sizes` field in the `object_stats` struct to track the total uncompressed size of objects by type (commits, trees, blobs, tags). The sizes are collected using `odb_read_object_info_extended()` during the object counting process. The patch updates the keyvalue output format to include these new size fields alongside the existing count fields.

The implementation maintains consistency with the series' approach of careful measurement and verification. Test coverage is added to verify the inflated size reporting works correctly, though the test is currently SHA1-specific (marked with the `SHA1` prerequisite). The documentation is also updated to mention the new size reporting capability.

This is a straightforward addition to the series that follows the established patterns while expanding the command's reporting capabilities. The patch appears well-constructed with appropriate test coverage, though reviewers may want to consider the SHA1-specific test patterns in light of Git's ongoing hash algorithm transition work.
