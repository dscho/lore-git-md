This is a build system fix addressing Rust compilation on macOS. Eric Sunshine confirms D. Ben Knoble's diagnosis that the issue stems from using GNU sed's `-s` flag when parsing `cargo -vV` output to determine library naming conventions. The current implementation breaks on macOS's BSD sed.

Sunshine concisely demonstrates the solution: replacing the GNU-specific `-s` with the portable `-n` and `p` flags in the sed command. This maintains the same functionality (extracting the host platform from cargo's output) while working across both GNU and BSD sed implementations.

The fix appears straightforward and well-justified - the original use of `-s` seems unnecessary for this parsing task. This is part of the ongoing Rustification effort and affects developers building Git with Rust support on macOS. The change would restore compatibility without requiring users to install GNU sed.
