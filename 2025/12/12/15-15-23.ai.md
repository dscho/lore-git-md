This is a documentation and maintenance patch series for Scalar's configuration settings, building on previous discussions about improving config documentation. The series is now in its third iteration, having addressed review feedback from Junio Hamano and Patrick Steinhardt.

The series focuses on comprehensively documenting Scalar's configuration settings while cleaning up stale values and improving the implementation. Key changes in v3 include updated method names for setting config, removal of the "REQUIRED" label from documentation (responding to Henrique Ferreiro's feedback), explicit documentation of why `index.threads=true` is set despite matching defaults (it enables `index.recordOffsetTable`), and new documentation for `log.excludeDecoration`.

The patch series touches several areas:
- Adds "# set by scalar" comments to config file modifications
- Documents 20+ config settings with detailed rationales in scalar.adoc
- Removes stale configs like core.preloadIndex and core.fscache
- Alphabetizes and simplifies the config setting code
- Maintains Windows-specific optimizations (CRLF handling) while noting platform differences
- The implementation now uses file-based config writes with explicit comments
- Preserves backward compatibility patterns from 2018
- Documents subtle interactions between settings like index.threads and index.recordOffsetTable

The series appears ready for integration, having addressed all major review feedback. It leaves open some questions about future evolution of certain settings (particularly feature.manyFiles) but provides a solid foundation for understanding and maintaining Scalar's configuration approach. The documentation improvements are thorough, covering performance rationales, compatibility choices, and differences from Git's experimental feature groups.
