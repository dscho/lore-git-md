Maintainer approval for Scalar config documentation updates.

Junio Hamano gives final approval to the third version of Derrick Stolee's patch series auditing and documenting Scalar's configuration settings. The series has evolved through multiple iterations with input from various contributors, and this version addresses all previous feedback.

The only minor issue noted is a grammatical nit in the documentation for `index.threads=true`, where the updated phrasing ("due the default value") is less clear than the original ("due to"). Hamano indicates he will accept the patch regardless, suggesting the wording can be cleaned up later if needed.

This marks the completion of a thorough effort to document Scalar's configuration settings, with all key technical decisions (like maintaining explicit settings even when they match defaults) now properly explained for users. The series is ready for integration into the main Git codebase.
