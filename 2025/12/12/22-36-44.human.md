This is the final patch (7/7) in Justin Tobler's v2 series enhancing Git's `repo structure` command with comprehensive object size reporting. The patch completes the human-readable table output by adding disk size information alongside the existing inflated size data.

The change adds a new "Disk size" section to the table output, showing total and per-type (commits, trees, blobs, tags) disk usage. The implementation reuses the existing table formatting infrastructure while adding new `disk_sizes` fields to match the earlier machine-readable format additions. Since disk sizes can vary across platforms, the tests verify only that the size information appears (not specific values) in an empty repository, and includes a `strip_object_disk_usage` helper to filter out disk sizes when comparing test output.

This patch follows the series' established pattern of maintaining consistent output formatting while expanding the available metrics.
