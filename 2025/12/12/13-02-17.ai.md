This is a technical follow-up in the MEMZERO_ARRAY/Coccinelle rules discussion, focusing on pattern matching improvements.

René Scharfe responds to Junio Hamano's suggestion about extending the Coccinelle rule to catch additional memset patterns. He agrees with Junio's proposal to match `'\0'` patterns (noting their presence in compat/regex/) and also suggests matching `sizeof(ptr[...])` syntax, though no current code uses this form. René makes two technical observations: first, that `0` already matches `0x0` in his Coccinelle setup (version 1.3-dirty/OCaml 5.1.1), making the explicit `0x0` pattern redundant; second, that wrapping `n` in parentheses in the rule would make it more flexible by handling both parenthesized and bare forms while producing cleaner output (specifically improving the ewah/bitmap.c conversion).

The email doesn't address Patrick Steinhardt's earlier concerns about the build system changes from patch 2/2, keeping that discussion thread separate. René's input carries weight as a known Coccinelle expert, effectively resolving Junio's question about pattern expansion while introducing additional technical refinements to the rule syntax.
