Documentation patch for Scalar's configuration settings, part of an ongoing series to improve Scalar's config management. This is the final patch in v3 of the series, adding comprehensive documentation that explains the rationale behind each configuration setting that Scalar modifies.

The patch adds a new "RECOMMENDED CONFIG VALUES" section to scalar.adoc, detailing over 20 different Git config settings that Scalar adjusts during clone, register, or reconfigure operations. For each setting, it provides clear justifications focused on performance optimizations for large repositories and cross-platform compatibility. Notable highlights include explanations for disabling expensive operations like ahead/behind calculations in status checks, enabling index compression, and platform-specific handling of Windows filesystems and SSL backends.

The documentation carefully distinguishes between settings that are performance-critical (like index.skipHash and index.version), those that disable features in favor of Scalar's background maintenance (like gc.auto and receive.autoGC), and platform-specific considerations (core.untrackedCache behavior on Windows). It also notes future-looking items like commitGraph.generationVersion that may change as Git's upgrade paths solidify.

This patch completes the config documentation work that was previously reviewed and approved by Junio Hamano and Patrick Steinhardt, with the code changes already landed in earlier patches of the series. The documentation serves as both a reference for users wondering why Scalar modifies their config and as a maintenance guide for future updates to these settings.
