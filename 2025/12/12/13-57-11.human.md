This is a follow-up discussion in the Scalar configuration documentation series, specifically about removing stale config values.

Stolee acknowledges this subtle behavior and agrees to document it explicitly, so future changes to this dependency would prompt a review of whether the explicit setting in Scalar should also be removed. This maintains the thread's focus on thorough documentation while addressing an implementation detail that could affect future maintenance.
