This is a documentation and maintenance patch from the ongoing Scalar configuration series. It adds clear annotations to config values set by Scalar operations, marking them with "# set by scalar" comments in the config file. This helps users understand which settings were automatically configured by Scalar versus those they set themselves.

The patch introduces a new helper function `set_scalar_config()` to consistently add these annotations when Scalar modifies config values. It updates both the main config setting logic and the fsmonitor-specific case to use this helper. The change includes tests verifying the annotations appear as expected in the config file.

This is a straightforward improvement that builds on the series' goal of making Scalar's configuration behavior more transparent. The implementation looks clean, with good test coverage showing the annotations work as intended. As the first patch in v3 of the series, it sets up the infrastructure that subsequent patches will use when documenting other Scalar config behaviors.
