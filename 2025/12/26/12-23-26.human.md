This is part 3 of a major hook subsystem refactoring series that introduces a callback mechanism for feeding stdin to hooks, complementing the existing file-based approach. The patch adds a `feed_pipe` callback to `struct run_hooks_opt` that allows streaming large amounts of data to hooks without filesystem overhead, building on the parallel execution infrastructure introduced in patch 1.

The implementation carefully maintains backward compatibility by making the file-based and callback approaches mutually exclusive (enforced with BUG() assertions). It includes thorough documentation of the new callback mechanism and its associated context pointers in `hook.h`. The change is well-motivated for performance with large inputs like ref lists in push operations.

This appears to be a well-constructed piece of the larger hook standardization effort, with clear sign-offs from key reviewers (Emily Shaffer and Ævar Arnfjörð Bjarmason). The code follows project conventions and includes appropriate safeguards against misuse. As part of the now-mature v6 series, this patch looks ready for inclusion.
