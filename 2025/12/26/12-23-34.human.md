This is the final patch in a major hook subsystem refactoring series, converting receive-pack's hooks to the new `hook.h` API. The patch completes the multi-year effort to standardize all major Git hooks, with this conversion handling the receive hooks that process push operations.

The key change here is replacing the custom hook execution code with the new API's `run_hooks_opt` infrastructure, which provides structured stdin handling and output capture. The patch introduces a batched stdin processing approach (500 lines per callback) to maintain performance when processing large pushes, addressing a degradation observed with single-line callbacks. It preserves all existing functionality including push certificate handling and sideband output routing.

The conversion follows the same pattern as previous patches in the series, eliminating manual signal handling and child process management while maintaining backward compatibility. Reviewers including Ævar Arnfjörð Bjarmason and Emily Shaffer have signed off, with all major technical concerns addressed in earlier iterations. This represents the culmination of the hook standardization effort, providing a foundation for future enhancements like config-based hooks and parallel execution.
