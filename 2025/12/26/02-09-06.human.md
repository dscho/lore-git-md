This is a discussion about potential feature enhancement to `git branch --show-current` behavior. Junio Hamano responds to Sergey Organov's inquiry about why the `-v` flag is ignored when combined with `--show-current`, unlike with `--list`.

Hamano explains that `--show-current` was originally created as a simpler alternative to `git symbolic-ref HEAD` just to show the current branch name, without considering it as a variant of `--list`. He notes that while there would likely be no objection to adding `-v` support, the verbose output format might need to differ from `--list` since it wouldn't need the two-space indentation used when showing multiple branches.

The response suggests this could be a reasonable enhancement but hints at some design considerations around output formatting that would need to be worked out. The tone indicates this is a low-priority quality-of-life improvement rather than a critical fix.
