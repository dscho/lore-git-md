Performance optimization patch replacing commit_list with prio_queue in `show-branch`.

This patch by René Scharfe replaces the use of `commit_list_insert_by_date()` with a `prio_queue` in `builtin/show-branch.c` to improve performance in pathological cases. The key changes are:

1. Replaces the commit list with a priority queue (min-heap) for storing commits, reducing worst-case complexity from O(n²) to O(n log n)
2. Optimizes queue operations by using `prio_queue_peek()+prio_queue_replace()` when possible to reduce heap rebalancing operations
3. Updates the test infrastructure to include a performance test case

The benchmark results show:
- Negligible difference in normal cases (~1% faster)
- Dramatic 98.6% improvement in the pathological test case (p6010)
