This is the first patch in a refactoring series that standardizes Git's hook subsystem. It introduces infrastructure for parallel process management that will be used by subsequent patches to enable parallel hook execution.

The patch extracts a common pattern for checking child process states into a new `child_is_working()` helper function and introduces a named `parallel_child` struct to replace an anonymous one. This makes the code more readable and maintainable while preparing for parallel execution capabilities that will be built on top. The change is mechanical but important groundwork - it doesn't change behavior, just makes the state checks more explicit.

As part of a well-reviewed series that has already addressed technical concerns in previous iterations, this patch appears solid. It follows the pattern of small, focused changes that build toward the larger goal of hook modernization.
