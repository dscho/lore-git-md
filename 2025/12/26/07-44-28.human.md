Performance optimization for `git show-branch` using priority queues.

René Scharfe replaces the quadratic-time `commit_list_insert_by_date()` with a more efficient `prio_queue` implementation in `builtin/show-branch.c`. The change reduces worst-case complexity and shows dramatic improvements in pathological cases (98.6% faster in the p6010 test case), though normal repository operations see only marginal gains (~1% faster).

The patch carefully maintains existing behavior while optimizing the data structure, using `prio_queue_peek()+prio_queue_replace()` where possible to minimize heap rebalancing. Test coverage is expanded with a new performance benchmark in p6010-merge-base.sh.

This appears to be a well-considered optimization from an experienced contributor, addressing a known performance edge case in Git's commit traversal logic. The implementation is clean and the commit message provides clear before/after metrics.
