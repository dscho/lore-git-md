This is part 6 of the hook subsystem refactoring series, converting the reference-transaction hook to use the new `hook.h` API. The patch replaces direct `run-command` usage with the structured hook API, introducing a `transaction_hook_feed_stdin` callback that processes one ref update per invocation while maintaining the same data format.

Key technical changes:
- Introduces `struct transaction_feed_cb_data` to track state across callback invocations
- Implements `transaction_hook_feed_stdin` as the stdin feed function, handling all ref update formatting cases (null OIDs, symbolic refs, regular refs)
- Maintains identical stdin format to the old/new hook behavior while removing manual child process management
- Preserves EPIPE handling for hook termination cases
- Uses the new `run_hooks_opt` infrastructure with proper context passing

The conversion follows the pattern established in earlier parts of the series, with the reference-transaction hook being particularly important as it handles critical ref updates. The implementation demonstrates the series' goal of maintaining backward compatibility while providing a more maintainable API surface.

This patch has already received sign-off from key reviewers (Emily Shaffer and Ævar Arnfjörð Bjarmason) and addresses all technical concerns raised in earlier versions. It represents a straightforward conversion of one of Git's more complex hooks to the new API, completing part of the series' goal to standardize all major hooks.
