This is part 10 of a major hook subsystem refactoring series, focusing on converting receive-pack's update and post-update hooks to the new standardized API. The patch replaces custom `child_process` handling with the new `run_hooks_opt` infrastructure, maintaining sideband output support through a new `hook_output_to_sideband` callback.

The changes are straightforward mechanical conversions that:
1. Replace direct hook execution with the new API while preserving all existing functionality
2. Add a dedicated output handler for sideband transmission
3. Remove boilerplate hook-finding and process setup code

Notably, this maintains the sequential execution behavior (via `processes=1`) while preparing for future parallel execution capabilities. The patch has already been reviewed and signed off by key contributors including Emily Shaffer and Ævar Arnfjörð Bjarmason, with all technical concerns addressed in previous iterations.
