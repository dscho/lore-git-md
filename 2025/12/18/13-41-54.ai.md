This is a follow-up discussion on the second patch in the test suite maintenance series addressing curl 8.18.0 compatibility. The patch fixed t5563-simple-http-auth.sh by adding missing CRLFs in HTTP headers that curl 8.18.0 enforces more strictly, while also renaming the test to better reflect its purpose of testing mixed continuation characters rather than line endings.

Matthew John Cheetham confirms Jeff King's analysis and patch, agreeing that the test was poorly named and should have been testing mixed continuation characters (spaces vs tabs) rather than line endings. The original test was producing malformed HTTP response by omitting the final CRLF, which newer curl versions handle more strictly. The patch fixes both the test name and the malformed response.

The discussion validates the approach taken in the patch - fixing the test expectations rather than modifying core functionality to accommodate the malformed input. This aligns with curl maintainer Daniel Stenberg's earlier review confirming this was the right approach for the series. The thread shows consensus that the test fixes are correct and the series appears ready for merging.
