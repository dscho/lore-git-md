This is the third and final patch in a test maintenance series addressing curl 8.18.0 compatibility. It fixes test failures in t5563-simple-http-auth.sh related to how HTTP headers are unfolded, where curl 8.18.0's unfolding behavior differs slightly from Git's implementation.

The patch focuses on two tests that check WWW-Authenticate headers with folded continuation lines. The key issue is that curl 8.18.0 unfolds these headers differently than Git's code - specifically, it preserves extra whitespace from blank continuation lines where Git would omit it. The RFC actually supports curl's behavior, though the difference is mostly academic since folded headers have been deprecated since 2014.

Rather than modifying Git's unfolding code to match curl, Jeff King opts to relax the test assertions to accept either output format. The solution adds a `--relax-whitespace` mode that normalizes multiple whitespace characters (including tabs) into single spaces before comparison. This approach is intentionally conservative, touching only the tests rather than production code.

The patch includes thoughtful analysis of the RFC and curl's behavior, noting an interesting edge case where curl retains tabs in some cases. The changes are well-contained, affecting only the specific tests that were failing while maintaining compatibility with both old and new curl versions. This completes the series addressing test failures with curl 8.18.0 while keeping backward compatibility.
