This is the second patch in a 3-part test maintenance series addressing curl 8.18.0 compatibility. It fixes a test failure in t5563-simple-http-auth.sh where an HTTP header was missing its terminating CRLF, causing test failures with curl 8.18.0.

The test in question checks how Git handles WWW-Authenticate headers with unusual formatting. The author discovered that one test case was producing malformed output by omitting the final line ending, which older curl versions tolerated but 8.18.0 rejects. The patch adds the missing CRLF and renames the test from "mixed line-endings" to "mixed continuations" to better reflect its actual purpose (testing header continuations with both space and tab).

The change is minimal (2-line diff) and focused on making the test output valid HTTP while maintaining its testing purpose. The author notes some uncertainty about why curl 8.18.0 fails to use the credentials in follow-up requests, but considers the malformed header justification enough for the fix regardless. This continues the series' theme of making tests more robust against curl version differences while preserving test coverage.
