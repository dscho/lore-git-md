This is a bugfix patch in a series improving object info reading in Git's ODB layer. It addresses a specific optimization that wasn't working as intended in packed object handling.

The patch fixes a broken optimization in `packfile_store_read_object_info()` that was meant to short-circuit empty object info requests (where no specific info like type or size is requested). The current code incorrectly compares pointers rather than checking if the request is actually empty, making the optimization ineffective since commit d9f517d051.

The solution introduces a new helper function `object_info_is_blank_request()` that properly checks if none of the request fields are populated. This makes the optimization work as originally intended, avoiding unnecessary header unpacking when no object details are requested. The change is minimal (11 lines added, 2 changed) and focused on the odb.h and packfile.c files.
