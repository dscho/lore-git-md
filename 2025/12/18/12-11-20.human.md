This is a test suite maintenance series addressing compatibility with the upcoming curl 8.18.0 release. Jeff King noticed test failures when running Git's test suite against the curl release candidate and is proposing fixes to make the tests more robust.

The series consists of three patches that adjust test expectations to handle both old and new curl behaviors. The first patch deals with trailing slashes in cookie output, the second fixes a missing newline in HTTP header tests, and the third relaxes whitespace assumptions for unfolded headers. Jeff specifically calls out the third patch's handling of tabs vs spaces as potentially needing review from curl maintainers.

The changes appear to be straightforward test adjustments rather than fixes for actual bugs in Git's functionality. Jeff has tested against both older (8.17.0) and newer (8.18.0 RC) curl versions, and is seeking confirmation from relevant experts (Daniel Stenberg for curl changes and Matthew DeVore for test intent) that the adjustments are correct. The patches look like prudent maintenance to keep the test suite working across curl versions.
