This is a response from curl maintainer Daniel Stenberg to Jeff King's test suite maintenance series for curl 8.18.0 compatibility. Daniel confirms the first two patches (cookie path comparison and HTTP header line endings) look good and won't cause issues. However, he raises concerns about the third patch's handling of whitespace in unfolded HTTP headers.

Daniel explains that curl's header unfolding logic was recently rewritten to fix parsing issues, and in the process changed how whitespace is handled between folded lines. While the current behavior is technically correct, he acknowledges it may cause problems for Git's tests. He commits to revisiting this part of curl's implementation to better match the previous whitespace behavior that Git expects.

The exchange shows good collaboration between the projects, with Daniel being responsive to compatibility concerns while maintaining curl's standards compliance. This suggests the test fixes will likely be adjusted to account for curl's final behavior rather than Git needing to relax its test expectations.
