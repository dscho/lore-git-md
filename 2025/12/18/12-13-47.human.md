Test maintenance patch adjusting cookie path handling for curl 8.18.0 compatibility. This is the first in a 3-part series fixing test failures with the upcoming curl release while maintaining backward compatibility.

The patch modifies t/t5551-http-fetch-smart.sh to handle a change in curl 8.18.0 where it now strips trailing slashes from cookie paths. The test was previously doing a byte-wise comparison of cookie files, which broke with the new curl behavior. The solution is to normalize paths by stripping trailing slashes before comparison, making the test work with both old and new curl versions.

Jeff King explains this is purely a test adjustment - the actual cookie handling in Git isn't affected since curl manages that internally. The change is well-motivated with testing against both curl 8.17.0 and the 8.18.0 release candidate. While noting the test could theoretically be made more future-proof, the current solution seems reasonable given cookie file formats don't change often.

The patch appears straightforward and well-tested, with clear commit message explaining both the problem and solution. It's part of a coordinated effort to maintain test compatibility across curl versions.
