This is patch 7/10 in Patrick Steinhardt's series refactoring Git's packfile storage to track packs per object database source rather than per ODB. The series enables pluggable ODBs by ensuring all object access routes through owning sources.

The current patch simplifies `packfile_store_prepare()` to only prepare the single packfile store passed by the caller, rather than preparing all stores in the object database. This change follows naturally from the architectural shift in earlier patches that moved packfile storage from the ODB level to the source level. The patch updates callers in `builtin/grep.c` and `packfile.c` to explicitly prepare stores when needed.

The changes are straightforward mechanical updates that maintain existing functionality while making the code more precise about which packfile stores it operates on. This continues the series' pattern of making packfile operations respect source-level ownership, which is a key step toward enabling pluggable ODBs. The patch appears well-contained and builds logically on the previous work in the series.
