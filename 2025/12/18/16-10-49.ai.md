Bugfix for refs debug output. This patch corrects a logical error in `refs/debug.c` where the debug tracing for `optimize_required()` was incorrectly checking the pointer address rather than dereferencing the boolean value it points to. The current code would always print "yes" in the trace output since it was testing the pointer's existence rather than the pointed-to value. The fix changes `required ? "yes" : "no"` to `*required ? "yes" : "no"` to properly reflect the underlying boolean state. The change is minimal (one character) but important for accurate debugging output. The commit message is brief but correctly identifies the issue and solution. This appears to be a straightforward correction with no obvious complications or wider implications beyond fixing the debug trace output.
