This is a refactoring patch in the major Windows symlink support series. Johannes Sixt confirms that patch 3/18 correctly simplifies the symlink stat handling code by removing the now-redundant `do_lstat()` function and its follow-link logic, folding its remaining behavior directly into `mingw_lstat()`. The change eliminates 20 lines of code while maintaining the same functionality, as the new `mingw_stat()` implementation has made the separate function unnecessary. Sixt notes this addresses his earlier comment about documentation cleanup from patch 1/18, since the entire commented function is now removed. The change is straightforward and uncontroversial, part of the broader effort to streamline Windows symlink handling while maintaining POSIX compatibility.
