This is a test maintenance patch in a series addressing curl 8.18.0 compatibility. Matthew John Cheetham is responding to Jeff King's patch that fixed an HTTP test by adding missing CRLFs in headers and correcting the test's description.

The original test had an incomplete HTTP response missing the final CRLF, which newer curl versions handle more strictly. Jeff's patch fixed both the test's technical correctness and its misleading name (it was testing mixed continuation characters, not line endings). Matthew confirms the naming fix was needed and thanks Jeff for the correction.

This is part of a coordinated effort where curl maintainers have reviewed and approved the test fixes, ensuring they'll work with both old and new curl versions. The series appears ready for merging after addressing these edge cases in HTTP test expectations.
