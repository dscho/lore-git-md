This thread addresses test suite maintenance to ensure compatibility with the upcoming curl 8.18.0 release while maintaining backward compatibility with older versions like 8.17.0. The series consists of three patches fixing test failures observed against curl release candidates.

The first patch modified cookie path comparison in t5551-http-fetch-smart.sh to handle curl 8.18.0's new trailing slash stripping behavior. The second patch, which prompted this follow-up discussion, fixed t5563-simple-http-auth.sh by adding missing CRLFs in HTTP headers that curl 8.18.0 enforces more strictly, while also renaming the test to better reflect its purpose of testing mixed continuation characters rather than line endings. Matthew John Cheetham and Jeff King confirmed this was the right approach, noting the original test was producing malformed HTTP responses.

The third patch relaxed whitespace assumptions in t5563 for WWW-Authenticate header unfolding. Curl maintainer Daniel Stenberg reviewed the entire series, confirming the first two patches are correct and committing to restore curl's previous whitespace-collapsing behavior before the 8.18.0 release, making the test fixes compatible with both old and new curl versions.

With consensus from both Git contributors and the curl maintainer, this series appears ready for merging. The changes demonstrate Git's careful approach to test maintenance - fixing test expectations rather than modifying core functionality to accommodate malformed input, while ensuring compatibility across curl versions.
