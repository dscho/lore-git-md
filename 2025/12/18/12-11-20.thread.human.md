This thread is about a test suite maintenance series that prepares Git for compatibility with the upcoming curl 8.18.0 release. The author has identified three test failures that occur when running Git's tests against curl 8.18.0 release candidates and is proposing fixes to make the test expectations more flexible.

The changes focus on HTTP-related tests, specifically handling differences in cookie output formatting, HTTP header newlines, and whitespace in unfolded headers. The author has taken care to maintain backward compatibility with older curl versions (8.17.0) while adapting to the new behavior. The patches modify test files t5551 and t5563, making their assertions less brittle regarding HTTP protocol details.

One particular change regarding tab vs space handling in headers is flagged as potentially controversial, and the author has specifically requested review from curl maintainer Daniel and original test author Matthew for those parts. The series appears to be a careful, backward-compatible adjustment of test expectations rather than any fundamental change to Git's HTTP behavior.
