This thread addresses test suite maintenance to maintain compatibility with curl 8.18.0 while supporting older versions like 8.17.0. The three-patch series fixes test failures by: (1) adjusting cookie path comparisons for curl 8.18.0's new trailing slash behavior, (2) correcting malformed HTTP responses in t5563 by adding missing CRLFs, and (3) relaxing whitespace assumptions for header unfolding tests.

Jeff King and Matthew John Cheetham confirmed that patch 2/3 correctly addressed a long-standing issue where the test (originally misnamed) was producing invalid HTTP responses by omitting final CRLFs. The test's true purpose was to verify handling of mixed continuation characters (spaces vs tabs), not line endings. Curl maintainer Daniel Stenberg reviewed the series and implemented a curl fix that may allow reverting the whitespace workaround in patch 3/3, though verification is pending.

The first two patches remain essential - the cookie path fix and CRLF correction address fundamental compatibility issues. The discussion provides valuable context about the test's original intent, validating the approach taken. While the series was designed as a transitional solution, the curl team's responsiveness may allow simplifying the changes once 8.18.0's behavior stabilizes.
