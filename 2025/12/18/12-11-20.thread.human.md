In the latest update, Daniel reports implementing a fix in curl to restore the pre-8.18.0 whitespace behavior for header unfolding, which would make Git's test modifications for this case potentially unnecessary. He requests verification that this curl change resolves the original test issues. While the Git patches may still provide transitional compatibility, this development suggests the third patch's whitespace workaround could eventually be reverted once curl 8.18.0 with the restored behavior becomes widespread. The series remains valuable as it handles the interim period where different curl versions coexist.
