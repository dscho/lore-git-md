This thread covers a series of test suite fixes addressing compatibility issues with the upcoming curl 8.18.0 release while maintaining backward compatibility with older versions like 8.17.0. The three-patch series tackles test failures observed against curl release candidates, with each patch addressing a different aspect of HTTP test behavior.

The first patch fixed cookie path comparison in t5551-http-fetch-smart.sh to handle curl 8.18.0's new trailing slash stripping behavior. The second patch corrected t5563-simple-http-auth.sh by adding missing CRLFs in HTTP headers that curl 8.18.0 enforces more strictly, with Matthew John Cheetham and Jeff King confirming this was the right approach. The final patch, which just arrived, relaxes whitespace assumptions in the same test file for WWW-Authenticate header unfolding, adding a new `--relax-whitespace` flag to normalize test output comparisons.

Curl maintainer Daniel Stenberg has been actively involved, reviewing all patches. He confirmed the first two fixes are correct and committed to restoring curl's previous whitespace-collapsing behavior before the 8.18.0 release, which validates the test-only approach taken in the final patch. Jeff King noted that once curl 8.18.0 becomes the minimum supported version, the unfolding code could potentially be simplified. With all patches reviewed and the curl behavior change confirmed, this series appears ready for merging.
