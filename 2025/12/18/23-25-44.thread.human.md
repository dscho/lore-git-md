This thread addresses a build system fix for Git's Rust support on non-GNU platforms like macOS and BSD. The issue stemmed from a GNU-specific `sed` flag (`-s`) in the build script that caused failures on systems with BSD `sed`. D. Ben Knoble submitted a minimal but critical fix, replacing the non-portable flag with a standard `sed -n` approach to correctly extract platform information needed for library naming.

The fix has now received explicit approval from both Eric Sunshine and Patrick Steinhardt (the original author of the problematic code), with Patrick acknowledging the debugging work done. The discussion highlights how subtle platform differences in toolchain behavior can create issues, particularly in newer components like the Rust integration. With no outstanding concerns raised, this straightforward compatibility fix appears ready for merging as part of the ongoing Rustification effort.
