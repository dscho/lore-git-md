This is a platform compatibility fix for the Rust build infrastructure. The patch corrects a build failure on macOS (and other BSD-based systems) that occurs when trying to build Git with Rust support enabled via Meson.

The issue stems from using a GNU-specific `sed -s` flag in a script that checks cargo's host platform information. On BSD-derived systems like macOS, this causes the build to fail. The fix replaces the GNU extension with a more standard `sed -n` approach that works across different sed implementations.

The problem likely went unnoticed in most development environments because GNU sed is common on developer machines and CI systems. The patch has been reviewed with help from Eric Sunshine and Patrick Steinhardt, suggesting it's been vetted by experienced contributors.

This is a straightforward one-line change to `src/cargo-meson.sh` that makes the Rust build system more portable while maintaining the same functionality. The fix is well-explained in the commit message with clear context about why the original approach failed and how the new solution works.
