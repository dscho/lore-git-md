This is a feature proposal introducing a new `--snapshot` option for `git commit`. The patch adds functionality to create timestamped copies of staged files before committing, storing them in a configurable location (defaulting to `.git/snapshots`).

The implementation creates two new files (`snapshot.c` and `snapshot.h`) and modifies `builtin/commit.c` to add the new option. The snapshot feature is controlled by a `snapshot.enable` config setting and the storage location can be customized via `snapshot.folder`. The snapshot directory structure includes both timestamp and sanitized commit message in its name.

Key technical details include:
- Uses `git diff --name-only --cached` to identify staged files
- Creates directories with `mkdir()` and handles error cases
- Sanitizes commit messages by replacing spaces with underscores
- Implements config lookup via `git_config_get_string()`
- Includes basic error handling but no test coverage

The author notes this is untested code submitted for initial feedback on whether the concept fits Git's development direction. The implementation shows some rough edges (direct shell command execution via `system()`, basic error handling) that would likely need refinement if the feature were to be accepted.
