This is a performance optimization patch in Patrick Steinhardt's series improving object info reading in Git's object database. It's patch 6/7 in the v2 series.

The change skips unpacking object headers when only the disk size is requested, since this information is available without full header parsing. The patch shows a measurable 9% speedup in `git rev-list --disk-usage` benchmarks, with clear before/after timing comparisons provided.

The implementation adds a new `OBJ_NONE` case to handle size-only requests, while maintaining all existing behavior for cases where type or delta information is needed. This builds on earlier patches in the series that standardized the object info interface and return values.

The change is focused and well-motivated, with a clear performance benefit demonstrated. It fits naturally into the series' goal of optimizing object info access while simplifying the code. The patch modifies only packfile.c and keeps the changes localized to the `packed_object_info()` function.
