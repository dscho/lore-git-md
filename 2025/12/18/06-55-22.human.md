This is patch 3/10 in Patrick Steinhardt's series refactoring packfile storage to work with object database (ODB) sources rather than directly with ODBs. The patch focuses on the kept-pack cache, which tracks packfiles marked as kept (either via ".kept" files or in-memory flags).

The change reworks the cache to operate on packfile stores rather than repositories, renaming the accessor function to `packfile_store_get_kept_pack_cache()` and introducing an explicit `enum kept_pack_type` for the flags. This is a mechanical but important step in the series' goal of moving packfile handling to the ODB source level.

The patch has already been reviewed by Justin Tobler, who suggested documentation updates that Patrick implemented. The changes are straightforward - updating call sites to use the new interface while maintaining the same behavior. This continues the series' systematic approach to relocating packfile functionality in preparation for pluggable ODB support.
