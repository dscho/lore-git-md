This is patch 7/10 in Patrick Steinhardt's series refactoring packfile storage to track packs per object database (ODB) source rather than per ODB. The patch continues the architectural shift from patch 5/10 by simplifying `packfile_store_prepare()` to only operate on the single packfile store passed to it, rather than preparing all stores in the ODB.

The key changes are:
- Removes the loop over all ODB sources in `packfile_store_prepare()`, having it only prepare MIDX and packed git for its specific store
- Updates callers in `builtin/grep.c` and `packfile.c` to explicitly prepare all needed stores when required
- Maintains the same functionality while better reflecting the new source-level ownership model

The patch touches packfile preparation in two key areas:
1. The grep command now explicitly prepares all source packfiles when initializing
2. The `find_pack_entry()` function prepares each source's packfile store as it checks for objects

This continues the series' pattern of making packfile operations respect source-level ownership while simplifying the code. The changes are mechanical but important for the overall goal of enabling pluggable ODBs. The patch builds cleanly on the architectural foundation established in earlier patches, with no apparent edge cases or transitional markers remaining.
