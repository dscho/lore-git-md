Performance and consistency patch in the object database interface series. This is patch 4/7 in Patrick Steinhardt's v2 series improving object info reading, which builds on earlier work to standardize how Git handles packed objects.

The patch fixes an inconsistency where `packed_object_info()` wasn't fully populating pack-specific fields in the object info structure, while `packfile_store_read_object_info()` did. Now both paths consistently set the pack offset, pack pointer, and delta type (REF_DELTA/OFS_DELTA/FULL) for packed objects. The change removes duplicate code from `packfile_store_read_object_info()` since the fields are now always set by `packed_object_info()`.

This is part of a larger effort to clean up the object database interface in preparation for future optimizations. The series has maintainer approval for the architectural direction and is carefully staged to avoid regressions. This particular patch helps ensure consistent behavior regardless of which code path reads the object info, which will be important for the planned `odb_for_each_object()` functionality.
