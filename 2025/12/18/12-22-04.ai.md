This is the third and final patch in a test maintenance series addressing curl 8.18.0 compatibility. It focuses on relaxing whitespace assumptions in t5563-simple-http-auth.sh tests for WWW-Authenticate header unfolding behavior.

The patch addresses a discrepancy between Git's and curl 8.18.0's handling of folded HTTP headers, particularly around empty continuation lines. While Git's current implementation drops empty continuations, curl 8.18.0 follows RFC 7230 more strictly by converting folded whitespace into single spaces. The solution modifies two specific tests to accept either whitespace normalization by preprocessing the output to collapse multiple whitespace characters into single spaces before comparison.

The author notes this is a pragmatic test-only change that avoids modifying Git's actual HTTP handling code. They acknowledge curl's behavior is technically more correct per RFC 7230, but prioritize maintaining compatibility with both old and new curl versions. The patch includes an interesting edge case where curl preserves tabs in continuations despite the RFC suggesting they should be normalized to spaces.

This completes the series that makes Git's tests work with both curl 8.18.0 and older versions. The changes are confined to test expectations rather than core functionality, with the author suggesting Git's unfolding code could eventually be removed once curl 8.18.0 becomes ubiquitous. The implementation uses a new `--relax-whitespace` flag to selectively enable the normalization only for affected tests.
