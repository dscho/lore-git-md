This is the third patch in an 8-part series improving object info reading in Git's object database layer. It extends the packed object info interface to properly represent delta object states.

The patch replaces the boolean `is_delta` field in `struct object_info` with an enum that can represent four states: unknown, full object, offset delta, and reference delta. This prepares for a future change where the code will need to handle cases where the delta status is unknown (when only basic object info is requested without parsing the full object data). The enum maintains backward compatibility while providing more precise information about object types.

Changes are focused in odb.h (adding the new enum) and packfile.c (updating the type checks). The patch is part of a larger effort to improve object info handling and is preparatory work that doesn't yet implement the "unknown" state usage - that comes in the next patch. The change appears technically sound and well-contained, following the series' pattern of incremental infrastructure improvements.
