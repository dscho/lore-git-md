Bugfix for the bundle-uri subsystem, addressing a segfault when bundle entries lack a URI.

Sam Bostock's patch fixes a crash that occurs when parsing bundle list config files that either misspell 'uri' as 'url' or omit the URI field entirely. Currently, such malformed entries create a bundle object with a NULL URI, which later causes a segfault when the code tries to use that NULL pointer. The fix adds validation to catch these cases early and report a proper error message.

The changes include:
1. Adding NULL checks before using bundle->uri in summarize_bundle()
2. Validating all bundle entries have a URI during config parsing
3. Adding a safety check before fetching a bundle
4. New test cases covering both missing URI and 'url' typo scenarios

The patch appears well-constructed with clear error messages and thorough test coverage. This addresses a real robustness issue that could affect users working with bundle lists, though the impact is limited to cases where the config file contains these specific errors. The changes are focused and don't introduce any new functionality - just hardening existing behavior.
