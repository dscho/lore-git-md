RFC proposal and implementation for maintenance config file option. Author: Matthew Hughes. Thread type: feature proposal.

Core proposal: add ability to specify alternate config file for git-maintenance operations via new `maintenance.configFile` setting, similar to -c/GIT_CONFIG for general git config but specific to maintenance subsystem. Implementation in builtin/gc.c with test in t/t7900-maintenance.sh.

Technical details: new config option `maintenance.configFile` would point to maintenance-specific config. Implementation modifies `builtin/gc.c` to check for this config when no explicit `--config-file` is provided to `register`/`unregister` subcommands. Current implementation writes maintenance.repo entries to specified file while other config operations remain in standard locations.

Implementation specifics:
- New config key: `maintenance.configFile`
- Affected commands: `git maintenance register/unregister`
- Implementation files: `builtin/gc.c` (main logic), `t/t7900-maintenance.sh` (test)
- Behavior: When no `--config-file` is passed, falls back to `maintenance.configFile` if set, writing only maintenance.repo entries there
