This is a v2 patch series (7 parts) improving object info reading in Git's object database layer, part of Patrick Steinhardt's ongoing work to introduce `odb_for_each_object()`. The series focuses on consistency and cleanup in how object info is handled for both loose and packed objects.

Key changes in this version:
- Rebased on master with Junio's object-read-stream-fix merged
- Improved commit message explaining the safe removal of OI_DBCACHED flag
- Maintains the core improvements from v1 while addressing feedback

The series makes several technical improvements:
1. Standardizes OI_LOOSE/OI_PACKED flag setting
2. Replaces OI_DBCACHED with always using OI_PACKED (after verifying no callers need the distinction)
3. Extends `is_delta` to a 4-state enum
4. Ensures consistent pack-specific info population
5. Cleans up `packed_object_info()` return values
6. Optimizes size-only requests (~9% speedup)
7. Removes repository parameter from `packed_object_info()` as part of `the_repository` removal

The changes touch core object database code in odb.h, object-file.c, and packfile.c. The thread shows careful review from Junio Hamano, particularly around the OI_DBCACHED removal and potential state leakage in empty request handling. The series appears well-considered with thorough commit messages explaining each change's rationale.
