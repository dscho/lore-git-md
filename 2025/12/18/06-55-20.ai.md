Refactoring patch in Patrick Steinhardt's series to move packfile storage to ODB source level. This first patch modifies `packfile_store_new()` to initialize via an ODB source rather than directly via the ODB, preparing for the architectural shift where each source will own its packfile store. The changes update function signatures and call sites across packfile.c, odb.c, and packfile.h to use the new source-based initialization while maintaining current behavior. The patch acknowledges this creates a transitional state where stores are still owned by ODBs but initialized via sources, which will be resolved in later patches. Key technical changes include updating `packfile_store` struct to track its source rather than ODB, modifying all packfile operations to access the repository through the source->odb chain, and adjusting `packfile_store_new()`'s interface and documentation. This foundational change enables subsequent patches to complete the migration of packfile ownership to sources as part of the pluggable ODB effort.
