This is the final patch in a test maintenance series addressing curl 8.18.0 compatibility. The patch focuses on relaxing whitespace assumptions in t5563-simple-http-auth.sh for WWW-Authenticate header unfolding tests.

The issue stems from curl 8.18.0's RFC 7230-compliant header unfolding behavior differing from Git's current implementation, particularly around empty continuation lines. Where Git would omit whitespace from blank continuations, curl inserts a space. The patch adds a `--relax-whitespace` flag to the test helper that normalizes whitespace in test output by collapsing runs of spaces/tabs into single spaces before comparison.

Key technical details:
- Modifies `expect_credential_query` helper in t5563-simple-http-auth.sh
- Uses sed to preprocess output with `s/[ \t][ \t]*/ /g` pattern
- Applies the relaxation to two specific tests handling empty/mixed continuation lines
- Leaves other tests using strict comparison

The approach was validated by curl maintainer Daniel Stenberg, who confirmed curl will restore its previous whitespace-collapsing behavior before 8.18.0 release, making this test change compatible with both old and new versions. The patch represents the least risky path by modifying test expectations rather than core functionality, though Jeff King notes the unfolding code could eventually be removed once curl 8.18.0 becomes the minimum version.
