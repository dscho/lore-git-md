This is the first patch of Patrick Steinhardt's 10-part series refactoring Git's packfile storage to track packs per object database source rather than per ODB. The change is foundational work for enabling pluggable ODBs in Git codebase.

The patch modifies `packfile_store_new()` to be initialized via an object database source rather than directly via the object database. This creates a transitional state where the store is still owned by the object database but created through its source, preparing for future patches that will fully move ownership to the source level. The change affects several packfile-related functions that now access the repository through the source's ODB pointer rather than directly through the store's ODB.

The patch creates some temporary awkwardness (acknowledged in the commit message) as an intermediate step in the larger refactoring. It touches core packfile handling code across multiple files but maintains existing behavior while setting up for subsequent changes. This appears to be a carefully considered mechanical change that follows the series' architectural direction, with Justin Tobler having already reviewed and approved the approach in previous iterations.
