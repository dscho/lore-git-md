Platform compatibility fix for Rust build system on non-GNU platforms.

This patch corrects a build failure when compiling Git with Rust support (`meson -Drust=enabled`) on macOS and other systems using BSD-derived sed. The issue stems from using GNU sed -s` extension in `src/cargo-meson.sh`, which isn't available on BSD sed. The script checks cargo's host platform information to determine the correct library name (`gitcore.lib` for Windows vs others).

The fix replaces `sed -s` with the more portable `sed -n` combined with printing the matched pattern (`p` flag), which properly extracts the host platform string regardless of sed implementation. The original GNU-specific approach worked by accident on developer machines and CI systems that typically have GNU sed, masking the issue until encountered on BSD-like systems.

The patch has been reviewed with help from Eric Sunshine and Patrick Steinhardt, suggesting it's been vetted for correctness. This is a relatively straightforward fix for a clear cross-platform compatibility issue in the relatively new Rust build infrastructure. The change is minimal (one character in the sed invocation) but important for ensuring the build works across different Unix-like platforms.
