This is the second patch in Patrick Steinhardt's 10-part series refactoring Git's packfile storage to work with object database (ODB) sources rather than directly with ODBs. The change is part of the larger effort to enable pluggable ODB backends.

The patch simplifies the `prepare_pack()` function by having it take an ODB source directly rather than passing individual components through a `prepare_pack_data` struct. This removes several intermediate variables and makes the code more straightforward by accessing properties like the MIDX and local flag directly from the source.

The change is mechanical and focused - it eliminates the transitional `prepare_pack_data` struct entirely while maintaining the same behavior. As noted in the thread context, Justin Tobler has already reviewed and approved this simplification in the v2 iteration of the series. The patch builds cleanly on the first patch's changes to packfile store initialization while setting up for further refactoring to come in later patches.
