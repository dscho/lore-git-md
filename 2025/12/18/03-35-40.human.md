Bugfix addressing a performance issue in object info handling. Junio C Hamano fixes a regression introduced by the recent ps/object-read-stream topic that caused severe slowdowns (from 0.38s to 1508s in some cases) in `git commit`. The root cause was incorrect assumptions about file-scope static variables being shared across functions.

The patch removes the use of a static "blank" object_info` struct as a NULL substitute, instead explicitly handling NULL inputs throughout the call chain. This approach both fixes the performance regression and makes the code more robust by eliminating potential side effects from accidental writes to the blank struct.

The changes touch object-file.c, odb.c, and packfile.c, with careful NULL checks added to all object_info pointer accesses. The fix is straightforward and well-motivated by a real-world performance problem reported by Aaron Plattner.
