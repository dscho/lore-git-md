This is part 5 of the hook subsystem refactoring series, converting the pre-push hook to the new `hook.h` API. The patch replaces the custom `child_process` setup with the standardized hook infrastructure, using the `feed_pipe` callback mechanism to stream reference updates to the hook's stdin.

Key technical changes in this specific patch:
- Introduces `struct feed_pre_push_hook_data` to manage the streaming state, containing a strbuf for formatting and tracking the current ref
- Implements `pre_push_hook_feed_stdin()` callback that filters refs (skipping non-fast-forward, stale, and up-to-date refs per maintainer consensus) and formats them for the hook
- Maintains identical status filtering behavior from the original implementation after discussion with Junio Hamano and Patrick Steinhardt
- Uses the new `run_hooks_opt` API with stdin streaming while preserving the need to pass remote name and URL as arguments
- Handles EPIPE gracefully when hooks don't read all input, matching original behavior

The conversion demonstrates the series' pattern of replacing manual child process management with the new hook API while maintaining backward compatibility.
