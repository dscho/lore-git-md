Thread subject: Platform compatibility fix for Rust build system on non-GNU platforms. Thread type: build system patch addressing Rust compilation issue. Originating author: D. Ben Knoble.

Core problem: Build failure when compiling Git with Rust support (`meson -Drust=enabled`) on macOS/BSD systems due to GNU sed extension (`-s`) usage in `src/cargo-meson.sh` that isn't portable to BSD sed implementations. The script extracts cargo's host platform information to determine library naming (`gitcore.lib` for Windows vs others).

Technical details: Fix replaces non-portable `sed -s` with standard `sed -n` plus pattern printing (`p` flag) to correctly extract host platform string across all Unix-like systems. Change is minimal (one character modification) but critical for cross-platform compatibility in the Rust build infrastructure. The issue had gone unnoticed on GNU systems where the behavior worked by accident.

Current status: Patch has received explicit approvals from both Eric Sunshine and Patrick Steinhardt (original author of the problematic code). No version indicated (initial submission). The straightforward fix appears ready for merging with no outstanding concerns.
