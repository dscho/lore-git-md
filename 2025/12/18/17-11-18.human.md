This is part 4 of an 11-part series refactoring Git's hook subsystem to use the new `hook.h` API. The patch converts the post-rewrite hook in sequencer.c from direct `run-command` calls to the standardized hook API.

The change replaces manual child process management with `hook_run_opt()`, which handles hook path finding and SIGPIPE toggling automatically. The key technical addition is a new `pipe_from_strbuf` callback that streams the old/new OIDs to the hook's stdin without temporary files, using the series' new feed_pipe mechanism. The implementation includes a BUG() assertion to catch NULL feed_pipe_ctx cases, following the pattern established in earlier parts of the series.

This conversion maintains the same functionality while being more maintainable and consistent with the broader hook modernization effort. The patch has already been reviewed and signed off by both Emily Shaffer (the original hook API author) and Ævar Arnfjörð Bjarmason, suggesting it aligns well with the project's direction. As part of a mature series that's addressed all substantive feedback, this change appears ready for inclusion.
