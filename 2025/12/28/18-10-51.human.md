This is the final patch in René Scharfe's series removing `the_repository` usage from tag-related code, specifically targeting the tag verification function `gpg_verify_tag()`. The change eliminates the last dependency on the global `USE_THE_REPOSITORY_VARIABLE` in tag.c by simplifying how object names are displayed in error messages.

The patch makes a pragmatic tradeoff: instead of falling back to abbreviated hashes (which required repository access to determine the abbreviation length), it now shows full hashes in error messages when no object name is provided. This is actually more appropriate for error contexts where unambiguous identification is valuable. The change is small (5 lines modified) but completes the architectural cleanup of removing implicit global state from tag handling.
