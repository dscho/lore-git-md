Test improvement patch for the `git status` goal branch feature. This is the second and final patch in v9 of the series, which adds configurable branch comparison to `git status` output via the `status.goalBranch` setting.

The changes here focus on test cleanup based on maintainer feedback, splitting test improvements into a dedicated commit while preserving all test coverage from previous versions. Key changes include:
- Standardizing test output redirection to use `>../actual` pattern
- Using `$SQ` variable consistently for quoted strings
- Improving heredoc formatting with proper indentation
- Removing unnecessary `/dev/null` redirections
- Maintaining the same 12 test scenarios covering all branch states (ahead/behind/diverged)

The tests verify behavior with different remote configurations, edge cases (unset/malformed config), and integration with existing tracking info display.
