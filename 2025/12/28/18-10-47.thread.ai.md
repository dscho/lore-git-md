This is a 4-part patch series by René Scharfe completing the removal of `the_repository` usage from tag-related code. The series systematically eliminates direct uses of the global `the_repository` and `the_hash_algo` from all tag handling functions, pushing repository awareness up to callers.

Patch 1 made `parse_tag_buffer()` repository-aware by replacing its implicit dependencies on `the_hash_algo` with repository-specific alternatives (`r->hash_algo` and `parse_oid_hex_algop()`). Patch 3 updated `parse_tag()` to take a `struct repository` parameter, modifying callers across 8 files to pass repository context through the call chain. The final patch (4) removes the last `USE_THE_REPOSITORY_VARIABLE` dependency in tag.c by changing `gpg_verify_tag()` error messages to use full hex object IDs instead of abbreviated hashes, eliminating the need for repository-global `DEFAULT_ABBREV`.

The changes span core tag operations including parsing, verification, and buffer handling, with mechanical updates propagating through multiple commands (describe, pack-objects, fsck, ref-filter). The series demonstrates René Scharfe's characteristic careful refactoring style - technically straightforward but widely-scoped architectural cleanup that systematically hardens the codebase against implicit global state. Key technical points include the complete removal of global hash algorithm access from tag handling, updated parsing interfaces throughout the subsystem, and improved error message precision in verification failures. The changes required no test modifications, indicating good existing coverage of these security-sensitive paths.
