Feature enhancement adding configurable branch comparison to `git status` output, now in its 9th and final iteration. This patch introduces a new `status.goalBranch` configuration option that lets users see how their current branch compares to an important reference branch (like `upstream/main`) in addition to the usual tracking branch comparison.

The implementation is clean and well-tested, with 340 lines of new test coverage verifying all edge cases. The output format matches Git's existing tracking info style, showing "Ahead of", "Behind", or "Diverged from" the goal branch on a separate line when configured. The comparison only appears when the goal branch differs from the tracking branch, avoiding redundant output.

This version splits test improvements into a separate commit (2/2) while preserving all the technical optimizations from previous iterations. The series has addressed all maintainer feedback over 9 versions, with Junio C Hamano's guidance now fully incorporated into the test organization and shell scripting style. The feature is ready for final consideration, providing a polished way to monitor branch divergence against important reference points.
