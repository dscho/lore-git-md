This is the first patch in a 2-part series implementing a feature to show comparison with a configured goal branch in `git status` output. The patch introduces the core functionality through a new `status.goalBranch` configuration option.

The implementation adds a new `get_goal_branch_ref()` helper in remote.c that validates and resolves the configured branch reference, following the strict format "remote/branch". When valid and different from the tracking branch, it shows an additional comparison line in the standard tracking info format (ahead/behind/diverged). The comparison is integrated into the existing `format_tracking_info()` flow with a new `format_goal_branch_comparison()` helper.

Key technical details:
- Configuration via `status.goalBranch` (must match "remote/branch" format)
- Only shows comparison if goal branch differs from tracking branch
- Uses same output format as tracking info (ahead/behind/diverged counts)
- Maintains existing performance characteristics with single ref resolution
- Includes comprehensive test coverage in t6040-tracking-info.sh (340 new lines)
- Handles edge cases: unset/malformed config, nonexistent branches
- Preserves all existing tracking info behavior when goal branch not configured

The test suite covers 12 scenarios including:
- Ahead/behind/diverged states relative to goal branch
- Different remote configurations (origin vs upstream)
- Integration with existing tracking info display
- Edge cases and error conditions
- Output format verification
