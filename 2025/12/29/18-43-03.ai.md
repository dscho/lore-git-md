This is a bugfix targeting merge-ort's handling of recursive submodule/directory conflicts. The patch addresses a specific assertion failure that occurs when merging branches where one treats a path as a directory and another as a submodule, particularly in cases involving multiple merge bases and merge-ort's tree-level optimization.

The core issue stems from merge-ort's `resolve_trivial_directory_merge()` function not properly handling cases where the conflicting paths are of different types (directory vs submodule). The function was originally written assuming both sides would be directories, leading to incorrect state updates when one side was a submodule. The fix involves:
1. Properly clearing dirmask/filemask bits for matching sides
2. Only marking the merge as clean when appropriate (not when a file/submodule remains after resolving a directory conflict)
3. Adding thorough test coverage with a complex reproduction scenario
