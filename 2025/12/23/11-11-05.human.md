Refactoring patch for promisor-remote functionality. This is the first of a 9-part series enhancing Git's promisor remote capabilities (LOP effort). The patch extracts common initialization code from `fields_sent()` and `fields_checked()` functions in `promisor-remote.c` into a new `initialize_fields_list()` helper. This prepares for adding another similar function in a later patch. The change is purely structural - no behavior modifications - and follows the series' pattern of preparatory refactoring before introducing new features. The commit message clearly explains the motivation and maintains the project's standard style.
