This thread introduces a 9-patch series enhancing Git's promisor remote functionality as part of the Large Object Promisors (LOP) effort. The key additions are a `promisor.storeFields` configuration for securely storing remote fields like tokens and filters, and a `--filter=auto` mode that dynamically combines filters from accepted promisor remotes during clone/fetch operations.

Patrick Steinhardt has provided extensive technical review across most patches, particularly focusing on naming conventions, error handling, and simplifying the filter combination logic. Christian Couder has actively addressed feedback, notably improving security considerations in the config storage implementation and clarifying the auto-filter behavior. Jean-Noël Avila contributed documentation-specific improvements to the new `--filter` option documentation.

The series has evolved through review iterations, with v2 simplifying the implementation by removing redundant functions and better integrating with existing filter parsing infrastructure. Current discussions have settled on technical approaches while leaving room for future enhancements, such as incorporating locally configured filters alongside server-advertised ones. The changes maintain backward compatibility and include comprehensive test coverage, positioning this as a significant step forward in Git's promisor remote capabilities.
