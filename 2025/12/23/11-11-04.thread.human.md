This thread covers two complementary improvements to Git's promisor remote functionality that are now ready for merging. The first is a 9-patch series implementing Large Object Promisors (LOP) with secure storage of remote fields and dynamic filter combination via `--filter=auto`. The second, from Christian Couder, adds URL-based auto-configuration through `promisor.acceptFromServerUrl`, allowing pattern-based remote setup with strict security constraints.

Both series have completed technical review cycles with approvals from Patrick Steinhardt and positive feedback from Junio C Hamano. The URL-based series saw minor refinements in its final version (v4), including renaming a function for clarity (`promisor_info_internal_name` → `promisor_info_local_name`) and fixing documentation formatting issues spotted by Kristoffer Haugsbakk. The implementation is thorough, with comprehensive tests in t5710 and clear security documentation.

The work represents significant progress in promisor remote functionality, making configuration simpler while maintaining security. All technical issues have been addressed, and both series are now ready for integration into master branch. A future GSoC 2026 project on promisor remote fetch ordering remains planned, but no outstanding technical blockers exist for the current work.
