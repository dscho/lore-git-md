This thread covers a 9-patch series (now at v4) that completes the LOP (Large Object Promisors) effort, enhancing Git's promisor remote functionality with two major features: secure storage of remote fields via `promisor.storeFields` config and full implementation of `--filter=auto` mode for dynamic filter combination. The series has undergone thorough review across four iterations, with Patrick Steinhardt, Christian Couder, Jean-Noël Avila, and Jeff King all providing feedback that has been incorporated.

The latest email presents the first patch of v4, which performs a mechanical refactoring in `promisor-remote.c` to extract common initialization code into a helper function. This preparatory change eliminates duplication and makes the code more maintainable without modifying behavior. Patrick Steinhardt has reviewed this change as part of the larger series, which he has approved as merge-ready. The series as a whole represents a significant enhancement to partial clone capabilities, with all review feedback addressed and no outstanding technical issues. It's now awaiting integration into master.
