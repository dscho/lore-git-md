This thread covers two related improvements to Git's promisor remote functionality. The main effort is Christian Couder's series adding URL pattern matching for promisor remote auto-configuration, which has gone through several iterations and is now complete with comprehensive documentation. The series allows administrators to specify URL patterns (with security constraints) that automatically configure promisor remotes when matching servers are encountered, generating local names with a `promisor-auto-` prefix and tracking the original advertised names.

The series has received thorough review from Patrick Steinhardt and Junio Hamano, with the latest feedback being a surface-level confirmation from Toon Claes that a preparatory refactoring patch correctly maintains existing behavior while setting up infrastructure for later name differentiation. A separate but related 9-patch series implementing Large Object Promisor (LOP) functionality has already been approved and is merge-ready.

The combined work significantly enhances promisor remote capabilities, providing both core functionality (LOP) and usability improvements (URL auto-configuration), with careful attention to security throughout. Both series are rebased on master and marked as ready for merging in Junio's integration branches. The only remaining open item is coordination around a planned GSoC 2026 project on promisor remote fetch ordering.
