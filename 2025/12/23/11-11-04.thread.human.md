This thread covers a 9-patch series enhancing Git's promisor remote functionality as part of the LOP (Large Object Promisors) effort. The changes introduce two main features: a `promisor.storeFields` config option for securely storing remote fields locally, and a new `--filter=auto` mode that dynamically combining filter specs from accepted promisor remotes during clone/fetch operations.

Patrick Steinhardt has been the primary reviewer throughout the series, providing detailed feedback on implementation details ranging from naming conventions to error handling patterns. The latest review (on patch 9/9) focuses on finalizing the auto-filter behavior - Patrick questions whether locally configured filters should be considered in the auto-filter case and suggests improving the error handling interface in `promisor_remote_construct_filter()`. 

The series has seen steady progress with most patches receiving positive feedback after incorporating review suggestions. Documentation updates have been reviewed by Jean-Noël Avila, who suggested formatting improvements. With only minor refinements remaining on the final patch, this substantial enhancement to promisor remote functionality appears close to completion.
