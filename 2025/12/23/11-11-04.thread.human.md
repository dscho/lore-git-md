This thread covers two major enhancements to Git's promisor remote functionality that are now ready for merging. The first series (LOP v4) implements secure storage of remote fields and dynamic filter combination, while Christian Couder's series (v4) adds URL-based auto-configuration with strict security constraints. Both have undergone thorough technical review, with Patrick Steinhardt and Jeff King providing key feedback that was addressed in the final versions.

The URL-based auto-configuration series in particular introduces new capabilities for securely matching URL patterns when auto-configuring promisor remotes, with comprehensive tests and documentation. After resolving final naming and configuration behavior questions with Toon Claes - who accepted Christian's security policy rationale - the series has now received Junio C Hamano's approval for merging into the `next` integration branch. This marks the final step before these production-ready promisor remote enhancements become available in a future Git release, giving organizations more flexible control while maintaining security boundaries. The functionality will first undergo broader testing in `next` before graduating to `master`.
