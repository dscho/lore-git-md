This thread covers two major improvements to Git's promisor remote functionality that are now ready for merging. The first is a 9-patch series implementing secure storage of remote fields and dynamic filter combination, which has received final approval from Patrick Steinhardt after addressing Jeff King's technical feedback. The second is Christian Couder's 8-patch series adding URL-based auto-configuration, which just received its final documentation patch to clarify the new `promisor.acceptFromServerUrl` config option.

Christian's series introduces pattern-based remote configuration with glob support while maintaining strict security constraints. The implementation handles URL normalization, name generation, and collision resolution automatically while storing original advertised names separately. The final documentation patch organizes the information more clearly, explains security implications, and preserves all warnings while making them more precise. Both Patrick Steinhardt and Junio have reviewed the series positively, and Junio has marked it as ready for merging in his "What's cooking" report.

These changes represent significant progress in promisor remote functionality, with the first series providing core capabilities and the second adding important organizational deployment features. The work maintains backward compatibility while introducing robust URL pattern matching and configuration automation with appropriate security defaults.
