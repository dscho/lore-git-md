Here's a human-readable summary of this thread:

The thread reports a documentation inconsistency in Git's `remote` command. Egor Ibragimov found that both the command-line help and manpage incorrectly show `git remote set-url --add` as the syntax for adding a remote, when the correct form is actually `git remote add`. The `--add` flag properly belongs to the `set-url` subcommand, not the main command. 

This was verified on Git 2.43.0 and appears to be purely a documentation issue - the actual command behavior is correct, only the help text needs updating. The report provides clear examples of both the incorrect documentation and the proper usage. This seems like a straightforward fix that would prevent user confusion, particularly for those learning Git's command syntax.
