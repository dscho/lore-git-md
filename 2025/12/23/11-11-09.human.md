This is a documentation patch in a 9-part series enhancing Git's promisor remote functionality. It adds missing documentation for the `--filter=<filter-spec>` option in `git fetch`, bringing it in line with how the option is already documented for `git clone`.

The patch follows the series' preparatory refactors (patches 1-4) and precedes the core feature implementations (patches 6-9). It documents the partial clone feature's filter specifications, including examples like `blob:none` and `blob:limit=<size>`, with a reference to `git-rev-list` for full details. The change is straightforward and well-aligned with existing documentation patterns.

While this patch itself is simple, it's part of a larger effort to improve promisor remote functionality, particularly around dynamic filter combinations and secure credential handling. The documentation addition will help users understand the filter options that the subsequent patches will make more powerful through the new `--filter=auto` mode.
