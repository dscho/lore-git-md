This is a documentation bug report. Egor Ibragimov points out an inconsistency between Git's actual behavior and its help text/manpage for the `git remote` command. The help text incorrectly shows `git remote set-url --add` as the syntax for adding a remote, when the correct form is `git remote add` (The `--add` flag is actually part of the `set-url` subcommand, not the main `remote` command.) The same error appears in both the command-line help and the manpage. The reporter verified this on Git 2.43.0. This appears to be a straightforward documentation fix that would help users who might otherwise be misled by the incorrect syntax. No behavioral changes to Git itself are needed - just updates to the help text and manpage. The report is clear and specific, with reproduction steps showing both the incorrect and correct forms.
