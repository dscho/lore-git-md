Maintainer feedback on default branch comparison feature. Junio C Hamano provides detailed guidance on improving the patch submission, focusing on commit message structure and design considerations. He suggests restructuring the commit message to follow Git project conventions: first describing current behavior, then the problem, then the solution. The feedback questions whether using the "default" branch (determined by remote HEAD) is the optimal design choice for the second comparison point in triangular workflows, suggesting branch configuration might be more appropriate. While acknowledging the usefulness of tracking divergence from mainline, the response indicates the current implementation may need refinement in both presentation and underlying logic. The maintainer leaves the door open for the feature but wants to see these aspects addressed in a revision.
