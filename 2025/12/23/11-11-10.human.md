This is part 6 of a 9-part series enhancing Git's promisor remote functionality, introducing a new `--filter=auto` mode. The patch adds infrastructure to support this feature while maintaining backward compatibility.

The change introduces an `allow_auto_filter` flag in `list_objects_filter_options` to control which commands can accept the "auto" filter spec. It ensures "auto" cannot be combined with other filters and adds appropriate error handling. The implementation includes a BUG() check to prevent direct initialization with LOFC_AUTO, since this mode must be resolved to a concrete filter before use.

A new unit test file verifies the parsing behavior, checking that "auto" is only accepted when allowed and that combination attempts fail. The patch appears well-structured with clear error messages and thorough test coverage, though the commit message notes potential future extensions could relax some of these constraints if needed.

This is a technical foundation for the series' later patches that will implement the actual "auto" filter behavior for clone/fetch operations. The changes are focused and maintainable, with careful attention to edge cases in the filter parsing logic.
