This is a documentation bug report. Egor Ibragimov points out an inconsistency between Git's actual behavior and its documentation for the `git remote` command. The help text and manpage incorrectly show `git remote set-url --add` as the syntax for adding a remote, when in fact the correct command is `git remote add`. The error is reproducible in Git 2.43.0.

The report is clear and specific, showing both the incorrect documentation and the actual working command. This appears to be a straightforward documentation fix that should be easy to verify and correct. The issue affects both the in-command help text and the manpage, so both would need updating. No behavioral changes to Git itself are needed - just documentation corrections.
