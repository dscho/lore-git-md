This is a feature patch adding a new whitespace check to detect tabs between non-whitespace characters in documentation files. The patch implements a new `tab-between-non-ws` whitespace rule that flags tabs appearing between non-whitespace characters when they would expand to a single space (i.e., when they appear at a column one less than a multiple of the tab width). This addresses cases where a space was likely intended instead of a tab.

The implementation adds a new `WS_TAB_BETWEEN_NON_WS` flag to the whitespace checking system, with corresponding updates to the error reporting and checking logic in `ws.c`. The check is specifically enabled for AsciiDoc files (`*.adoc`) in the Documentation directory via `.gitattributes`. The patch includes extensive test suite additions in `t/t4015-diff-whitespace.sh` covering various edge cases - tabs at tab stops vs between them, multiple tabs, and tabs at line boundaries.

The change was suggested by Junio Hamano to catch documentation typos where tabs were mistakenly used instead of spaces in running text. The implementation carefully avoids false positives for cases like "a\tb" where the tab is intentional by only flagging tabs that would expand to a single space. The patch appears well-tested with comprehensive test coverage of the new functionality.
