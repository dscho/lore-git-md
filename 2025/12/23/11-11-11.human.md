This is part 7 of a 9-part series enhancing Git's promisor remote functionality, specifically implementing the auto-filter resolution infrastructure for the `--filter=auto` feature.

The patch adds two key helper functions to `list-objects-filter-options.[ch]`:
1. `list_objects_filter_combine()` which aggregates multiple filter specs into a single "combine:" filter string, handling proper URL-encoding of sub-filters
2. `list_objects_filter_resolve_auto()` which resolves an "auto" filter by replacing it with a concrete filter specification

The implementation includes thorough unit tests that verify:
- Empty/single/multiple filter combinations
- Proper handling of filters that need URL encoding
- Correct construction of "combine:" filter strings

This is a well-structured patch that builds on the previous refactoring work in the series to enable the upcoming `--filter=auto` functionality. The changes are focused and clearly motivated by the series' goal of dynamically combining filter specs from promisor remotes. The test coverage appears comprehensive for the new functionality.
