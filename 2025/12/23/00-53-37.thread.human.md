This thread documents a 19-iteration journey to enhance `git status` to show divergence from both upstream and push tracking branches. The feature was proposed and implemented by Harald Nordgren, with significant design input from Junio C Hamano and technical reviews from Phillip Wood and Ben Knoble.

The series consists of two patches: first a refactoring to clean up the tracking info formatting code, then the actual push tracking display implementation. The final version resolves push references through the full refspec chain and shows push comparison only when it differs from upstream, maintaining Git's output conventions while adding the new information on a separate line. The implementation includes comprehensive test coverage for edge cases like remapped refspecs and multiple remote scenarios.

After extensive review addressing all technical concerns around control flow, parameter naming, and type safety, the series is now merge-ready. It provides a useful feature for workflows where upstream and push tracking branches differ while maintaining backward compatibility.
