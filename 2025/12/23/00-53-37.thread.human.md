The changes maintain all existing behavior while cleanly extending the output format. Junio recently raised a final naming nit about some variables in the refactored comparison logic, which Harald has now addressed by renaming them to be more semantically meaningful (though there appears to be a typo in the response that will likely need correction).

With all technical requirements met, comprehensive test coverage in place, and all design questions resolved, the series is now merge-ready.
