This thread introduces a new feature for `git status` that shows divergence from both upstream and push tracking branches, implemented by Harald Nordgren in a 2-patch series. The first patch refactored the existing tracking info formatting code to improve modularity, while this second patch adds the actual push tracking comparison functionality.

The implementation handles complex cases like custom refspec remapping and different remote configurations, showing push tracking info only when it differs from the upstream. Phillip Wood provided thorough technical review, particularly around refspec handling, while Junio C Hamano approved the overall approach. The series now has comprehensive test coverage (210 new tests) and follows Git's conventions.

The feature is particularly useful for workflows where developers push to different branches than they pull from. For example, it clearly shows when your local branch has diverged from upstream but is ahead of your push destination. After 14 iterations incorporating feedback, the series is now functionally complete and ready for inclusion.
