This thread documents the evolution of a feature to show branch divergence in `git status` output, from initial proposal to final design. The original approach by Harald Nordgren introduced a new `status.goalBranch` configuration to specify a comparison target, with comprehensive implementation and test coverage. However, maintainer Junio C Hamano objected to adding new configuration when existing branch tracking mechanisms could serve the same purpose.

After nine iterations incorporating technical feedback, the series pivoted significantly in v10 by dropping the custom configuration in favor of using `branch.<name>.pushRemote` and standard tracking branch infrastructure. This architectural change addressed Junio's core design objections while preserving the feature's utility. Ben Knoble had suggested this direction earlier in the thread.

The final implementation shows divergence only when the target differs from the tracking branch, maintains strict format requirements, and keeps all optimizations from prior versions. Test coverage remained robust throughout the iterations. With the design now aligned with Git's existing patterns and all substantive feedback addressed, the thread appears ready for maintainer evaluation. The year-end timing and significant design compromise suggest this may be the final iteration before potential merging.
