This thread documents the implementation of a new `git status` feature that displays divergence from both upstream and push tracking branches. The work was proposed and implemented by Harald Nordgren as a 2-patch series, with the first patch (a refactoring of tracking info formatting) already merged after incorporating Junio Hamano's feedback.

The key innovation is showing push tracking information when it differs from upstream, using Git's existing `branch.<name>.pushRemote` configuration rather than introducing new config options. The implementation carefully handles edge cases like custom refspecs and maintains Git's output conventions while adding the new information. For example, it can now show both "Your branch is ahead of 'upstream/main'" and "Your branch is ahead of 'origin/feature'" when the push target differs from upstream.

The technical work involved creating a new helper function to resolve push tracking references through a chain of refspec mappings, while preserving the existing advice messages. Phillip Wood provided particularly valuable review, identifying and helping solve tricky refspec mapping issues. The series went through 14 iterations with extensive testing (210 new test lines) covering all edge cases before reaching its final form.

Junio Hamano approved the technical direction and provided maintainer guidance, emphasizing the importance of presenting a clean progression in the final patch series. The implementation is now complete and ready for inclusion, representing a useful quality-of-life improvement for users who work with multiple remotes or custom push configurations.
