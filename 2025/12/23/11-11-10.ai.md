This is part 6/9 of the promisor remote enhancement series, implementing the `--filter=auto` mode infrastructure. The patch adds core support for a new `LOFC_AUTO` filter choice that will be used by clone/fetch commands to dynamically combine filter specs from promisor remotes.

Key changes:
- Adds `allow_auto_filter` flag to `struct list_objects_filter_options` to control which commands accept "auto"
- Modifies `gently_parse_list_objects_filter()` to handle "auto" when allowed
- Enforces that "auto" cannot be combined with other filters (triggering BUG() if attempted)
- Updates filter initialization to reject direct use of `LOFC_AUTO` (must be resolved first)
- Adds new unit test file `u-list-objects-filter-options.c` with tests for the parsing behavior

The implementation carefully maintains backward compatibility while adding the auto-filter capability. The patch includes thorough test coverage for both allowed and rejected cases, including combinations with other filter types. This is a foundational piece for the dynamic filter behavior that will be wired up in subsequent patches of the series.
