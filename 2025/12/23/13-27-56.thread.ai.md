Summary of whitespace check patch series:

This thread introduces a new whitespace rule `tab-between-non-ws` to detect tabs between non-whitespace characters in documentation files, specifically targeting AsciiDoc files in Documentation/. The feature was suggested by Junio Hamano to catch documentation typos where tabs were used instead of spaces in running text.

The implementation adds a `WS_TAB_BETWEEN_NON_WS` flag to the whitespace checking system in `ws.c`, with careful handling to avoid false positives - only flagging tabs that would expand to a single space (i.e. not at tab stops). The check is enabled for `*.adoc` files via `.gitattributes`. Extensive test coverage in `t/t4015-diff-whitespace.sh` verifies edge cases including tabs at tab stops vs between them, multiple tabs, and line boundary conditions.

Key technical details:
- New whitespace rule specifically for Documentation/*.adoc files
- Implementation in `ws.c` with new `WS_TAB_BETWEEN_NON_WS` flag
- Careful tab expansion logic to distinguish intentional tabs from likely typos
- Comprehensive test coverage in t4015
- `.gitattributes` update to apply rule to AsciiDoc files

The patch appears ready with thorough testing and addresses Junio's original suggestion for catching documentation typos. No outstanding questions or objections have been raised in the thread.
