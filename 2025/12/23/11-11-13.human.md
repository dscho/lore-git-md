This is the final patch in a 9-part series implementing auto-filter functionality for promisor remotes. The patch wires up the `--filter=auto` option for `git clone` and `git fetch`, completing the feature that automatically combines filter specs from server-advertised promisor remotes.

The key changes enable the auto-filter logic in several commands by setting `allow_auto_filter=1` in their filter options. When an auto filter is requested, fetch-pack now computes the actual filter by combining specs from accepted promisor remotes. The patch also ensures the transport layer can handle auto filters during initial connection setup.

Notably, the auto filter setting persists in config, so future fetches will continue using the automatically-determined filter without requiring the `--filter=auto` option. The implementation includes comprehensive tests verifying the dynamic filter behavior as server-side filter specs change.
