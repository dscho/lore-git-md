Feature enhancement for `git status` showing default branch comparisons. This patch adds a new status line showing how the current branch compares to the project's default branch (origin/main or upstream/main) when tracking a non-default branch. The motivation is to help developers see if their feature branch has drifted from the main development line, even when it's in sync with its tracking branch.

The implementation dynamically detects the default branch by checking refs/remotes/upstream/HEAD first, falling back to refs/remotes/origin/HEAD. It shows three possible states: ahead, behind, or diverged from the default branch. The new output appears as an additional line after the existing tracking information.

The patch includes extensive test coverage (246 lines of tests) verifying various scenarios: branches ahead/behind/diverged from both their tracking branch and the default branch, preference for upstream over origin, and cases where the branch is up-to-date with its tracking branch but differs from the default. The implementation appears clean and well-tested, addressing a common workflow need for developers working on feature branches.
