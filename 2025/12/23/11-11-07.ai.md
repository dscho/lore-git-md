This is a refactoring patch in the LOP (Large Object Promisors) series, specifically part 3 of 9. It makes a preparatory change to clean up filter options handling in the clone command.

The patch moves the `filter_options` variable from being a static global in `builtin/clone.c` to being a local variable within `cmd_clone()`. This clarifies ownership and scope as the variable will be used more extensively in upcoming patches. The change requires passing the filter options as a parameter to the `checkout()` function, but otherwise maintains the same behavior.

Key technical details:
- Modifies `builtin/clone.c` to move filter options management
- Adds filter_options parameter to checkout() function signature
- Maintains same filter expansion behavior during checkout
- Properly releases filter resources at end of cmd_clone()
- Part of broader promisor remote functionality work

This is a straightforward code organization improvement that sets up for later patches in the series while making the code's data flow more explicit. The change is small (16 lines modified) and focused, with no functional impact at this stage.
