This is a test fix addressing platform compatibility with Apple's Git distribution. René Scharfe corrects how the test suite handles Git version strings that contain spaces, specifically targeting Apple's version format which includes parenthetical build information (e.g., "git version 2.50.1 (Apple Git-155)").

The patch changes the version string parsing in `t4014-format-patch.sh` from stripping everything up to the first space to instead precisely removing the "git version " prefix. This prevents the test from incorrectly truncating version strings that legitimately contain spaces, while maintaining the same behavior for standard Git version outputs.

The commit message notes this isn't fixing Apple's own implementation (which uses `sed` in a way that masks Git's return code), but rather making Git's test suite more robust. The change is minimal (a single-line shell variable substitution tweak) but demonstrates good attention to cross-platform edge cases in test infrastructure.
