This is a feature patch series implementing the submodule gitdir path encoding extension, now rebased to v6 with significant architectural refinements. The series has evolved through extensive discussion to reach consensus on a pure runtime configuration approach, definitively rejecting build-time options.

The 10-patch series is logically split into two phases: patches 1-6 establish the core `submodulePathConfig` extension infrastructure, while patches 7-10 add the actual path encoding functionality. Key changes in v6 include renaming the extension from `submoduleEncoding` to `submodulePathConfig`, decoupling the extension from encoding logic, simplifying validation, and adding a migration command while removing automated fallback migration.

Technical implementation details include:
- New `extensions.submodulePathConfig` runtime-only option
- Four-tier fallback system (plain path -> URL encoding -> digit appending -> hashed name)
- Case-folding protection via RFC3986 encoding variants
- Centralized path resolution through `submodule_name_to_gitdir()`
- Comprehensive test coverage in t7425-submodule-gitdir-path-extension.sh
- URL encoding helpers moved to url.[ch]

The series reflects final architectural consensus with all major design questions resolved, including Junio Hamano's mandate for strict config requirements and Patrick Steinhardt's suggestion to separate core extension from migration functionality. The implementation now follows a clear three-phase approach (infrastructure -> encoding -> migration) with safeguards against manual misconfiguration.
