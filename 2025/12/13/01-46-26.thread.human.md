This thread discusses a two-part patch series that continues the ongoing effort to standardize array zeroing operations in the MEMZERO_ARRAY() macro, following work started by Toon Claes. The first patch improves the coccicheck Makefile target to show failed patch contents rather than just indicating failure, making CI debugging easier. The second patch mechanically replaces memset() calls with MEMZERO_ARRAY() in several core files (diffcore-delta.c, linear-assignment.c, and shallow.c).

Patrick Steinhardt has reviewed the build system change and strongly supports it, noting that it addresses a real pain point he recently encountered in CI debugging. His enthusiastic response ("Oh yes, please") and explicit thanks indicate this is a clear improvement that will likely be merged without further discussion. The changes are low-risk mechanical substitutions that maintain identical runtime behavior while making the code more consistent and the CI output more useful.

The work builds on prior MEMZERO_ARRAY() conversions in the codebase and appears uncontroversial, following established cleanup patterns. The patches touch core components (diff algorithm, optimization code, and shallow clone handling) but don't introduce functional changes. With positive feedback from an active contributor and no objections raised, this series seems ready to progress toward merging.
