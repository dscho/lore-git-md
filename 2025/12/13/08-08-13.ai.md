This is a refactoring patch in the submodule gitdir path encoding series, moving a URL encoding helper function to a more central location for reuse.

The patch `07/10` relocates `is_rfc3986_unreserved()` from `builtin/credential-store.c` to `url.[ch]` where it can be shared. This function checks if a character is safe to appear in URLs without encoding. The move is motivated by the need to use this same logic for submodule path encoding in subsequent patches of the series, avoiding code duplication.

The function was previously made static in credential-store.c when it was the only user, but now needs to be public again. The implementation remains identical - it just changes scope and location. The patch updates the header to include documentation about the RFC3986 standard this implements.

This is a straightforward code organization change that enables the URL encoding functionality needed for the submodule path handling work. It follows good practice by keeping related URL utilities together in the url.[ch] files while maintaining the exact same behavior. The change is well-contained and clearly motivated by the series' needs.
