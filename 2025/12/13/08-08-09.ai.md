This is part 3/10 of the submodule gitdir path encoding series, implementing a new `git submodule--helper gitdir` command as infrastructure for the path configuration system. The patch adds a simple helper that exposes the internal `submodule_name_to_gitdir()` computation, allowing querying and validating submodule gitdir paths.

The new command takes a submodule name and prints its computed gitdir path, using the same validation logic that was centralized in the previous patch. This serves both as a user-facing tool for debugging/scripting and as test infrastructure for the upcoming gitdir configuration functionality. The implementation is straightforward - it wraps the existing path computation in a command-line interface with basic argument checking.

This patch represents core infrastructure work in the first phase of the series (patches 1-6), providing the plumbing needed for the actual path configuration and encoding features that follow. The helper will be used both by end users managing submodule paths and by subsequent patches that implement the gitdir configuration system. The validation logic remains centralized in `submodule_name_to_gitdir()`, maintaining the architectural principle established earlier in the series.

Key technical details:
- Adds `module_gitdir()` function to `builtin/submodule--helper.c`
- Registers new "gitdir" subcommand via `OPT_SUBCOMMAND`
- Uses `strbuf` for path handling as established in earlier refactoring
- Maintains consistent error handling through centralized validation
- Prepares for config-based gitdir paths coming in next patch
