This is part of the ongoing submodule gitdir path encoding series (v6), specifically implementing runtime configuration for the new `extensions.submodulePathConfig` feature. The patch allows enabling the extension via global config rather than requiring per-repository configuration.

Adrian Ratiu's patch adds a global `submodule_path_config_enabled` flag that can be set via `extensions.submodulePathConfig` in the global gitconfig. This provides flexibility for users who want to enable the new submodule path handling across all their work without modifying individual repositories. The implementation maintains precedence rules where local repository config overrides the global setting.

The changes include updates to `submodule--helper` and core submodule code to check this new flag, along with comprehensive tests verifying both new and existing repository behavior. The tests demonstrate that new submodules get proper gitdir config entries when the extension is globally enabled, while existing repositories remain unaffected until explicitly migrated.

This patch represents a refinement based on earlier feedback from Patrick Steinhardt and Junio Hamano, moving the implementation toward a more flexible runtime configuration model. It's part of the series' broader goal to standardize submodule gitdir paths while maintaining backward compatibility.
