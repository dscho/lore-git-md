This is a refactoring patch in the submodule gitdir path encoding series, moving a URL encoding helper function to a more central location.

Patch 7/10 relocates `is_rfc3986_unreserved()` from `builtin/credential-store.c` to `url.[ch]` where it can be shared with the submodule path encoding logic. The function was previously made static when only credential-store used it, but now the submodule system needs it for URL-encoding submodule names to avoid path conflicts. The move is straightforward - the implementation remains identical, just exposed via the url.h header.

This is a preparatory change for the actual submodule path encoding work coming in later patches. The commit message clearly explains why the move is needed now and maintains the function's behavior while making it available to the broader codebase. The patch follows the series' pattern of consolidating URL encoding helpers in url.[ch] and keeps the implementation simple and focused.
