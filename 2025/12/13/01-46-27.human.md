This is a build system patch that enhances the Coccinelle checker's debugging output. It's the first of two patches in a series continuing the MEMZERO_ARRAY() conversion work.

The change modifies the `coccicheck` target in the Makefile to show the actual contents of Coccinelle patch files when they fail, rather than just reporting that errors exist. This is particularly useful in CI environments where build artifacts may not be easily accessible - developers can now see the specific Coccinelle rule violations directly in the test output.

The implementation is straightforward, removing the `-q` (quiet) flag from the `grep` command that checks Coccinelle patch files. This causes the matching lines to be printed when the check fails, while maintaining the same failure behavior. The change is minimal (just a one-line diff) and low-risk, touching only the build system's test infrastructure.

This appears to be a practical quality-of-life improvement for developers working with Coccinelle rules, especially in automated environments. The patch comes from Junio Hamano and follows the established pattern of the ongoing MEMZERO_ARRAY() conversion work.
