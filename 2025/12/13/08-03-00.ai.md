This is a test fix targeting version string handling in Git's test suite. The patch addresses an issue where the test script strips all text up to the first space when capturing `git --version` output, which breaks with Apple's Git distribution that includes spaces in its version string (e.g., "git version 2.50.1 (Apple Git-155)").

The change modifies `t/t4014-format-patch.sh` to specifically remove only the "git version " prefix rather than everything up to the first space. René Scharfe notes this isn't just about Apple's Git - their implementation actually uses `sed` which hides the return code, making this a cleaner solution overall.

The patch is minimal (just a one-line change) and well-motivated, with the commit message providing clear context about both the problem and solution. It maintains compatibility with standard Git version strings while fixing the Apple case, and the reference to Apple's implementation suggests the author has done their homework on the issue.
