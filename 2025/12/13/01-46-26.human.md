This is a refactoring patch series that continues the effort to use the `MEMZERO_ARRAY()` macro for zeroing memory buffers, following up on earlier work by Toon Claes. The two patches aim to make the codebase pass the Coccinelle static analysis checks ("make coccicheck") cleanly.

The first patch modifies the Coccinelle check output to show the actual patch contents rather than just reporting issues, making it easier to review the suggested changes. The second patch replaces several manual `memset()` calls with `MEMZERO_ARRAY()` in four different files (diffcore-delta.c, linear-assignment.c, and shallow.c), which is the preferred pattern for zeroing arrays in the codebase.

The changes are mechanical and straightforward, converting existing patterns to the more idiomatic form. Since this comes from the Git maintainer and builds on established work, it's likely to be uncontroversial and quickly merged. The patch series appears to be part of routine codebase maintenance rather than addressing any specific bug or performance issue.
