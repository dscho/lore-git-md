This thread addresses a test fix for handling Git version strings in `t/t4014-format-patch.sh`, particularly addressing compatibility with Apple's Git distribution which includes spaces in its version string (e.g., "git version 2.50.1 (Apple Git-155)"). The original test stripped all text up to the last space, which broke with these version strings.

The solution replaces this space-based stripping with explicit removal of just the "git version " prefix, maintaining compatibility with both standard Git versions and Apple's distribution. The patch also incidentally fixes a hidden `sed` return code issue. The v2 submission includes a minor commit message clarification to more accurately describe the original behavior (stripping to last space rather than first space), though the code change itself was correct from the initial submission.

Junio Hamano confirmed the change is sensible, and René Scharfe noted the commit message already reflected the clarified behavior. The patch has seen no objections and appears ready for merging as a straightforward test improvement that improves compatibility without changing behavior for standard cases.
