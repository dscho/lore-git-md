This is a build system patch that improves debugging output for Coccinelle checks in CI environments. It modifies the `coccicheck` target in the Makefile to show the contents of failed Coccinelle patches rather than just indicating failure. The change removes the `-q` flag from the `grep` command, causing it to output the actual contents of any non-empty Coccinelle patch files when they fail validation.

The patch is part of a 2-part series continuing the MEMZERO_ARRAY() conversion work, though this particular change is more focused on build system improvements than the array zeroing standardization. The modification is straightforward - just a single grep flag removal - but addresses a real pain point for CI debugging where previously developers couldn't see the actual Coccinelle errors without downloading build artifacts.

Key technical details:
- Modified file: Makefile
- Changed command: `grep ^` instead of `grep -q ^`
- Context: Part of CI/debugging improvements for Coccinelle checks
- Impact: Makes Coccinelle failures more debuggable in automated environments

The change maintains the same validation behavior (failing on non-empty patches) while providing more useful output. It's a small but practical improvement to the development workflow that shouldn't introduce any new issues since it only affects error reporting, not the actual Coccinelle checking logic.
