Refactoring patch in the ongoing ODB alternates handling series. This is patch 3/8 from Patrick Steinhardt's series modernizing Git's object database alternates system.

The change moves the computation of the normalized object directory path into `alt_odb_usable()` (renamed to `odb_is_source_usable()`) rather than having callers compute and pass it. This eliminates redundant information since the function already receives the object database from which the path can be derived. The patch also updates the function name to use the newer "source" terminology consistent with the series' abstraction goals.

Key technical changes include:
- Removes `normalized_objdir` parameter from function signature
- Adds local strbuf to compute normalized path internally
- Converts return type from `int` to `bool`
- Renames function to `odb_is_source_usable()`
- Updates all callers to use new signature
- Maintains same path comparison and alternate detection logic

The change is a straightforward cleanup that improves encapsulation by having the function handle its own path normalization. It follows the pattern seen in earlier patches of this series to prepare the alternates system for pluggable backends.
