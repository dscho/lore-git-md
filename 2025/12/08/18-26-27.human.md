This is a code review in Taylor Blau's MIDX compaction series, specifically addressing patch that refactors bitmap position handling during multi-pack index writes. Patrick Steinhardt examines patch 07/17, which removes an unnecessary indirection through `pack_perm` when assigning bitmap positions.

The change simplifies the code by directly indexing into `ctx->info` rather than using the permutation array, making the logic more straightforward and avoiding potential issues with future compaction work. Patrick confirms the technical rationale - that the permutation ordering was only relevant for expired packs (which don't occur with bitmaps) - and agrees with the change while noting it might make the code slightly more fragile if bitmap expiration were ever added.

The review is positive overall, with Patrick calling the change "simple enough" after walking through the technical details. This is a minor but sensible cleanup that fits into the larger MIDX compaction series by removing a potential obstacle for the compaction implementation.
