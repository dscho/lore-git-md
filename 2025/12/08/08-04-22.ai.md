This is the fifth patch in Patrick Steinhardt's series refactoring Git's alternates handling as part of the object database (ODB) abstraction effort. The patch focuses on eliminating mutual recursion in the alternates parsing logic.

The key change restructures how alternates are processed to remove the circular dependency between `link_alt_odb_entries()` and `odb_add_source()`. Previously, these functions called each other recursively to handle nested alternates. The new design makes `parse_alternates()` unaware of the recursive behavior, which is now handled exclusively by `odb_add_source()`. This involves:

1. Modifying `read_info_alternates()` to collect paths into a `strvec` rather than processing them immediately
2. Moving the recursion depth check into `odb_add_source()`
3. Having `odb_add_source()` handle both initial paths and recursively discovered ones
4. Updating `odb_prepare_alternates()` to use the new non-recursive parsing approach

The changes maintain all existing functionality while making the code easier to follow and more suitable for future ODB backend abstraction. This is a preparatory step for moving alternates parsing logic into object database sources, as mentioned in the commit message. The patch continues the series' pattern of structural improvements without changing user-visible behavior.
