Patrick Steinhardt's ODB alternates refactoring series, which restructures how Git handles alternate object databases as part of the broader ODB abstraction effort, has hit a minor snag. The well-reviewed 8-patch series was nearly complete, with Justin Tobler having signed off on all changes and Patrick confirming the technical implementation. However, SZEDER Gábor spotted a build-breaking oversight in patch 4/8 - it references a non-existent `odb_add_source()` function that was described in commit messages but never actually implemented. This appears to be an ordering issue in the series' development, where the conceptual change (replacing `link_alt_odb_entries()` with a more direct call) was documented before the supporting infrastructure was in place. The series remains structurally sound and conceptually approved, but will need this build issue addressed before final merging. This comes as the final piece of Patrick and Justin's multi-stage effort to modernize Git's object storage layer, with the alternates handling now operating through a clean source abstraction interface.
