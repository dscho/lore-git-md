This thread covers Patrick Steinhardt's 8-patch series refactoring Git's object database alternates handling as part of the broader ODB abstraction effort. The changes systematically replace direct filesystem operations with a "source" abstraction, preparing for future pluggable backends while maintaining current behavior. The series has restructured path resolution, eliminated mutual recursion in the alternates linking process, and introduced new source-based interfaces for both reading and writing alternates.

Justin Tobler has reviewed the first patch, which introduces batch processing of alternates via `parse_alternates()` rather than the previous entry-by-entry approach. His review confirms the technical soundness of the change, noting it maintains identical parsing behavior for quoted paths and comments while providing a cleaner structure. Though this initial patch doesn't yet resolve the mutual recursion issue (addressed in later patches), Justin indicates approval of the direction. 

The series appears to be progressing smoothly as part of Patrick's ongoing work to modernize Git's object storage layer, with no objections raised so far. The changes touch primarily odb.c and build on previous refactoring work by Patrick and Justin in this area.
