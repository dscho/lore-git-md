This is a documentation patch fixing a formatting issue in the `git-send-email` man page. 

The patch removes an errant blank line in the AsciiDoc source that was breaking the list continuation syntax. The documentation for the `--use-imap-only` option had an extra newline between the option description and its continuation paragraph about requiring `git imap-send`. Asciidoctor's documentation specifies that list continuations must be immediately adjacent to the preceding text.

The change is straightforward and corrects the formatting to match AsciiDoc's requirements. The patch is small (just one line removed) and well-explained with a reference to the relevant documentation standard. This appears to be a minor but legitimate documentation improvement.
