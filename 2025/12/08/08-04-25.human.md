This is the final patch in Patrick Steinhardt's 8-part refactoring series for Git's object database alternates handling. The series aims to modernize alternates handling as part of the broader ODB abstraction effort.

The patch restructures how alternates are written to use the new source-based interface introduced earlier in the series. It extracts the alternates file writing logic into a new `odb_source_write_alternate()` function that operates on a source object rather than direct path manipulation. The change maintains the same behavior but routes it through the new abstraction layer.

Key technical changes include moving the alternates file writing logic (previously in `odb_add_to_alternates_file()`) into a new function that works with `struct odb_source`, while keeping the same file locking and duplicate-checking behavior. The patch also simplifies the calling code by making `odb_add_source()` unconditional when adding alternates.

This completes the series' transition of alternates handling to work through the source abstraction rather than direct filesystem operations, paving the way for future pluggable ODB backends that may implement alternates differently. The changes are focused and mechanical, following the established pattern of the preceding patches in the series.
