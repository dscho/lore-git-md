This thread documents the addition of `gui.GCWarning` configuration option documentation to git-gui's manual pages. The patch, originally submitted by Matthew Hughes, adds standard documentation for this existing option that controls whether git-gui shows warnings about loose objects needing garbage collection.

Kristoffer Haugsbakk pointed to prior discussion about this option, prompting Matthew to clarify the patch's history. While most of the original patch series containing this documentation was superseded by other work, this particular documentation addition remains relevant as a standalone contribution. The current patch represents a rebased version of that older documentation change, now being submitted independently since the replacement series didn't include it. No technical concerns about the documentation content itself have been raised so far.
