This thread concerns adding documentation for the `gui.GCWarning` configuration option, which controls whether git-gui shows warnings about potential garbage collection needs when many loose objects are detected. The original patch from Matthew Hughes adds clear documentation in the standard format to gui.adoc, noting the option defaults to true. Kristoffer Haugsbakk followed up to reference an earlier discussion thread that may contain additional context about this option's history, though no changes to the proposed documentation were suggested. The patch remains a straightforward documentation addition with no behavioral changes required.
