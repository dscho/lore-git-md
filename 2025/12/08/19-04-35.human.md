This is a documentation patch adding missing config option documentation for `gui.GCWarning`.

Matthew Hughes noticed that while investigating Scalar's config options, the `gui.GCWarning` setting wasn't documented in the config manual. The patch adds a clear description of what this option does: it controls whether git-gui should show a warning prompt when it detects many loose objects in the repository, with the default being enabled ("true").

The change is straightforward - it adds 5 lines to Documentation/config/gui.adoc explaining the option's purpose and default value. The patch appears to be well-formed and correctly targets the right documentation file. Since this is documenting existing behavior rather than changing functionality, it's unlikely to be controversial.

This is the kind of small but useful documentation improvement that helps users understand available configuration options they might otherwise miss. The commit message could perhaps explain how the author discovered this was undocumented (was it through code inspection or by trying to use the option?), but the patch itself looks correct and complete.
