Thread identity: Refactoring series from Patrick Steinhardt (8 patches) targeting Git's object database alternates handling as part of the ODB abstraction effort.

Core problem: Restructure alternates handling to work through a "source" abstraction rather than direct filesystem operations, enabling support for object database backends that may not use traditional "objects/info/alternates" files.

Key technical changes:
- Initial patch introduced `parse_alternates()` to replace `parse_alt_odb_entry()`, processing entire input strings at once
- Second patch moves relative path resolution from linking phase into parsing phase using `odb_add_alternate_source()`
- Third patch relocates normalized path computation into `odb_is_source_usable()` (formerly `alt_odb_usable()`)
- Fourth patch simplifies `odb_add_to_alternates_file()` to use `odb_add_source()`
- Fifth patch eliminated mutual recursion between `link_alt_odb_entries()` and `odb_add_source()`
- Sixth patch removes now-unnecessary forward declarations and reorganizes code
- Seventh patch renames `read_info_alternates()` to `odb_source_read_alternates()`
- Eighth patch introduces `odb_source_write_alternate()` for source-based alternates handling
