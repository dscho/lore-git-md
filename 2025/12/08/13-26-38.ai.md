This is a follow-up in the bugfix thread for the `git-last-modified` bitmap initialization issue. Junio C Hamano notes that the original fix (which corrected a `memset()` size miscalculation in the bitmap clearing code) has already been merged to 'next', making this v2 patch with its new `MEMZERO_ARRAY` macro potentially redundant.

The patch introduces a new helper macro `MEMZERO_ARRAY` in `git-compat-util.h` that properly calculates byte counts for array zeroing using `st_mult()`, following the pattern of existing array helpers like `ALLOC_ARRAY`. It replaces the direct `memset` fix in `builtin/last-modified.c` with this more maintainable solution. The changes from v1 include defining this new macro and fixing the patch title.

While the core bug is already addressed in the tree, this version represents the architectural improvement path suggested earlier in the thread - encapsulating the size calculation logic rather than having it inline.
