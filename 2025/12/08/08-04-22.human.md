This is the fifth patch in Patrick Steinhardt's series refactoring Git's alternates handling as part of the object database (ODB) abstraction effort. The patch focuses on eliminating mutual recursion in the alternates parsing code.

The current alternates handling uses a complex mutual recursion between `link_alt_odb_entries()` and `odb_add_source()`, where each function calls the other. This patch simplifies the control flow by making `odb_add_source()` handle all recursion itself, while `parse_alternates()` becomes a straightforward parser that doesn't need to know about the recursive nature of alternates handling.

Key changes include:
- Removing the `link_alt_odb_entries()` function entirely
- Moving the recursion depth check into `odb_add_source()`
- Having `read_info_alternates()` just parse the alternates file and return paths via a `strvec`
- Updating `odb_prepare_alternates()` to use the new simplified flow

The patch maintains all existing functionality while making the code easier to follow and modify. This is a preparatory step for future work that will move alternates parsing logic into the ODB source interface. The changes are focused on internal structure rather than behavior, keeping with the series' goal of improving the codebase for upcoming pluggable ODB backends.
