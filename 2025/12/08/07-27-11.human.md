This is a documentation patch that improves the organization of the `pre-commit` hook section in the githooks documentation. The author, Kristoffer Haugsbakk, noticed that two separate paragraphs describing default hook functionality were split apart by an unrelated paragraph about environment variables, making the flow awkward.

The patch combines the two "default hook" paragraphs (one about trailing whitespace detection and another about non-ASCII filename checking) into a single cohesive description at the end of the section. This creates a more logical progression: first explaining when the hook runs, then describing its default behavior, with the environment variable note in between.

The change is well-motivated with historical context about when each piece was added to the documentation (2005 for whitespace, 2019 for non-ASCII checks). The patch itself is clean and focused, just moving and merging text without introducing new content. This seems like a straightforward improvement to documentation readability.
