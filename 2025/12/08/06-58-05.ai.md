The discussion stems from a 2018 compatibility decision (commit 2a9dedef2e) that made `index.recordOffsetTable` default to true when `index.threads` is enabled, to avoid warning messages from older Git versions.

Patrick acknowledges the points but remains somewhat skeptical about the warning's practical value, suggesting a configuration option to disable it might be useful.
