Platform compatibility patch addressing Homebrew build configuration on macOS.

Junio Hamano clarifies the purpose and usage of the `HOMEBREW_*` variables in Git's build system, responding to Torsten Bögershausen's questions. The variables (`HOMEBREW_PREFIX`, `HOMEBREW_GETTEXT_PREFIX`, `HOMEBREW_MSGFMT`) are Git-specific configuration points, not Homebrew environment variables, allowing users to specify non-standard Homebrew installation locations. When `NO_HOMEBREW` isn't set, these variables are used to add appropriate include and library paths to the build configuration.

The discussion reveals some confusion about the relationship between Git's build variables and Homebrew's own environment variables. Junio explains that these are purely for build configuration, with default paths being automatically handled for standard Homebrew installations (/opt/homebrew for Apple Silicon, /usr/local for Intel). The thread highlights the need for clearer documentation about these variables' purposes and usage patterns, particularly for users with custom Homebrew installations.

This is part of the ongoing effort to properly handle iconv-related build issues on macOS while maintaining compatibility across different package managers (Homebrew, MacPorts, Fink). The solution maintains backward compatibility while introducing more flexible configuration options.
