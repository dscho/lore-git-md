This is a follow-up discussion in the ongoing macOS build system changes thread, focusing on the new NO_HOMEBREW flag and related variables. Torsten Bögershausen seeks clarification about the purpose and usage of the HOMEBREW_* variables introduced in the patch series.

The email highlights some confusion around whether these variables are Git-specific build settings or related to Homebrew's own configuration. Junio Hamano clarifies that HOMEBREW_PREFIX and similar variables are Git's own build system variables (set in config.mak.uname) rather than Homebrew environment variables, though they serve to locate Homebrew installations.

Key points under discussion:
- The need for clearer documentation about the HOMEBREW_* variables' purpose and relationship to actual Homebrew installations
- Whether to add explanatory comments in the Makefile about standard vs custom Homebrew locations
- The distinction between Git's build variables and Homebrew's own environment variables

This exchange shows the thread moving from technical implementation to documentation polish, with maintainers working to ensure the build system changes are well-explained for future contributors and packagers. The discussion remains focused on making the Homebrew integration clear and maintainable while preserving flexibility for non-standard installations.
