Thread documents Git's policy on automatic sign-offs (Signed-off-by trailers) and the Developer Certificate of Origin (DCO), originating from a feature request to expand sign-off automation beyond `git format-patch`. The discussion established maintainer consensus against such expansion due to legal implications, with Junio C Hamano and Carlo Marcelo Arenas Belón providing key historical/legal context about SOB intentionality.

Current status shows all substantive decisions finalized and implemented in documentation:
- `format.signoff` remains the sole exception for automatic sign-offs
- No expansion to other commands like `commit`/`merge`/`revert`
- Documentation now includes identical legal rationale text in both FAQ and signoff-option.adoc via final patch
- FAQ section explains why configuration variables like `commit.signoff` will never be added
- signoff-option documentation cross-references FAQ explanation
- `format.signoff` documented as historical anomaly not to be replicated

Technical details unchanged:
- Only manual `-s`/`--signoff` or explicit `format.signoff` configuration can add SOB trailers
- All other cases require explicit user action to maintain DCO legal standing
