This is the foundational patch for a new `git-history` command, part of Patrick Steinhardt's v7 series introducing history editing capabilities. The patch establishes the basic command infrastructure while leaving actual functionality to subsequent patches.

The patch adds all the boilerplate needed for a new Git command:
- Documentation stub (marked EXPERIMENTAL)
- Build system integration (Makefile, meson.build)
- Command registration (builtin.h, command-list.txt, git.c)
- Basic command skeleton (builtin/history.c)
- Initial test cases (t/t3450-history.sh)

The documentation positions this as complementary to `git-rebase`, targeting specific common history editing operations that are currently cumbersome (reordering, splitting, dropping commits). The command is explicitly marked as experimental and currently limited to linear histories without merges.

Key technical details:
- Command will use the replay infrastructure (shared with `git-replay`)
- Initial test coverage verifies basic argument handling
- Follow-up patches will add `reword` and `split` subcommands
- Builds on prior work to reduce `the_repository` usage

This is a standard setup patch for a new command - it doesn't implement any functionality yet but establishes the framework the subsequent patches will build upon. The thorough test coverage and clear documentation positioning suggest this will be a well-structured addition to Git's history editing capabilities.
