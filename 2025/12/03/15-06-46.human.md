Performance optimization completing the diff command family coverage for copy detection improvements. This patch extends René Scharfe's earlier work to `diff-tree`, adding a new `keep_fn_t` callback in `struct diff_options` to handle unchanged file pairs more efficiently during copy detection.

The change builds on previous optimizations for `diff-index` (1.33x speedup) and `diff-files`, now addressing the more complex `diff-tree` case where callbacks are nested two layers deep. Benchmarks show mixed results - the Linux kernel test case shows essentially no performance change (1.00-1.01x), though memory usage improves slightly from ~36MB to ~35MB peak. The implementation carefully maintains existing behavior while adding the new optimization path.

The patch modifies core diff infrastructure (`diff.h`, `diffcore.h`) to support the new callback, with command-specific integration in `tree-diff.c`. While the performance impact is modest for this particular command, it completes the architectural consistency across Git's diff commands that Junio Hamano had suggested pursuing. The changes maintain tight focus on performance-critical paths while properly handling edge cases in the callback chain.
