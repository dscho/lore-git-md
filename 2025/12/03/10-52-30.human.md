Security patch converting `mktemp(3)` to new `git_mkdtemp()` wrapper.

This is the second patch in a 4-part series replacing insecure temporary directory creation throughout Git's codebase. René Scharfe converts the platform-specific `gitmkdtemp()` implementation in compat/mkdtemp.c to use the new cross-platform `git_mkdtemp()` function introduced in patch 1. The change eliminates a potential race condition where a file could appear between the `mktemp()` and `mkdir()` calls, while also simplifying the code by removing manual error handling.

The patch is straightforward - a 3-line deletion replaced by a single call to the new wrapper function. This demonstrates the series' goal of consolidating temporary directory creation logic while improving security. The implementation appears clean and maintains the same 0700 permission behavior as the original.

As part of the broader security hardening effort, this change helps eliminate a class of temporary file races while reducing platform-specific code. The series is progressing methodically, with this patch tackling one of the lower-level compatibility layers before moving on to higher-level callers.
