This is the third patch in a security-focused series removing insecure `mktemp(3)` usage from Git. Following the previous patch's migration of Windows-specific code to use the new secure `git_mkdtemp()` wrapper, this change removes the now-unused `mingw_mktemp()` compatibility function entirely. The patch deletes both the function implementation in `compat/mingw.c` and its declaration in `compat/mingw-posix.h`, totaling 15 lines removed.

The change is straightforward cleanup after the functional replacement was completed in patch 2/4. As part of the series' goal to eliminate all insecure temporary file creation, this removes one more platform-specific variant while maintaining Windows compatibility through the new secure wrapper. The patch follows the series' pattern of mechanical but security-conscious changes, with no test updates needed since the behavior was already migrated in prior work.
