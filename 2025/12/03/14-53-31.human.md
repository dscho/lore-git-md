This is a build system patch continuing the Meson cross-compilation improvements series. It follows up on Patrick Steinhardt's observation about standardizing the approach to handling cross-compilation scenarios.

The patch replaces `not meson.is_cross_build()` with `meson.can_run_host_binaries()` in a compiler test, making the build system more robust when using execution wrappers like QEMU. The change is minimal (just one line modified) but aligns with the series' goal of properly supporting cross-compilation environments. The author notes there's one remaining case where `is_cross_build()` is still appropriate since it guards a filesystem check that should always run on the build machine.

This appears to be a straightforward technical improvement that builds on the previous uncontroversial patches in the series. The change is well-motivated and maintains the series' focus on edge cases in cross-compilation setups without affecting native builds.
