This is a security-focused patch series aiming to remove insecure `mktemp(3)` usage from Git's codebase. The series is motivated by `mktemp(3)` being both insecure and deprecated in POSIX.1-2008.

The series introduces a new `git_mkdtemp()` wrapper function to provide a secure alternative, then systematically replaces all existing uses of `mktemp(3)` across the codebase. Key changes include removing Windows-specific `mingw_mktemp()` implementation and adding `mktemp(3)` to Git's banned functions list to prevent future use.

The changes touch several compatibility and wrapper files, with a net reduction of 20 lines of code. The implementation appears thorough, removing all platform-specific variants while introducing a single cross-platform replacement. This aligns with Git's ongoing security hardening efforts, though the commit message doesn't specify particular vulnerabilities being addressed by this change.

For future reference in thread discussions: the new `git_mkdtemp()` function is defined in wrapper.c and exposed via wrapper.h, while the banned.h change will cause compilation to fail if any new `mktemp(3)` calls are introduced. The mingw-specific removal suggests Windows compatibility was considered in the refactoring.
