Cleanup patch in the security-focused `mktemp(3)` removal series. This third patch removes the Windows-specific `mingw_mktemp()` implementation and its header declaration, following the previous patch's elimination of its last caller. The deletion removes 15 lines of code across `compat/mingw-posix.h` and `compat/mingw.c`, including the function definition and its `#define` alias that made it serve as the system's `mktemp(3)` replacement. 

The change is straightforward - since all callers now use the new secure `git_mkdtemp()` wrapper introduced earlier in the series, this platform-specific shim can be retired. The patch maintains the remaining `mkstemp()` implementation in `mingw.c` which already uses Git's secure tempfile infrastructure. This continues the series' pattern of removing insecure tempfile creation while preserving necessary Windows compatibility layers.

As with previous patches, this is a mechanical change with no behavior difference for end users, just internal cleanup of now-unused code. The removal brings the codebase closer to the series' goal of eliminating all `mktemp(3)` usage and its Windows variants. One remaining patch is expected to complete the migration by handling any final call sites.
