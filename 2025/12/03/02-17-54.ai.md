This is an announcement for the Git Rev News newsletter, a regular publication summarizing Git development activity.

Christian Couder announces the publication of edition 129 of Git Rev News, available on the project's website. The newsletter provides a digest of recent Git development activity, including notable commits, discussions, and contributions from the community. This edition acknowledges contributions from Ayush Chandekar, Štěpán Němec, Bruno Brito, and D. Ben Knoble in its preparation.

The announcement follows the standard format for Git Rev News releases, with a link to the published content and a call for contributions to the next edition (issue #813 on GitHub). The newsletter serves as an important resource for keeping up with Git development, particularly for those who don't follow the mailing list closely. The PS note about the open issue for the next edition indicates the ongoing nature of this community-driven publication.
