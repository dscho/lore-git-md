This is a security-focused patch series that aims to remove all uses of the insecure `mktemp(3)` function from Git's codebase. René Scharfe notes that POSIX.1-2008 no longer specifies this function due to its security vulnerabilities.

The series introduces a new `git_mkdtemp()` wrapper function as a secure replacement, updates compatibility code to use it, removes the Windows-specific `mingw_mktemp()` implementation, and finally adds `mktemp(3)` to Git's banned functions list. The changes touch several files across the codebase, with a net reduction of 20 lines of code.

The patch appears well-structured and motivated changes - replacing insecure functions with safer alternatives is generally a straightforward security win. The series follows Git's typical pattern of introducing a new wrapper function before migrating callers and removing old implementations. This is a focused, technical change that shouldn't be controversial, though reviewers will want to verify there are no remaining uses of `mktemp` in the codebase.
