Security-focused series eliminating insecure `mktemp(3)` usage throughout Git codebase, completed with 6/6 patches and final approval from Jeff King (Peff). Series introduced cross-platform `git_mkdtemp()` wrapper (wrapper.c/h) in patch 1/6, building on `git_mkstemps_mode()` infrastructure for secure directory creation with 0700 permissions. The foundational `git_mkdstemps_mode()` function serves as shared backend for both file and directory creation, with documented return value behavior (-1 for error, 0 for directory creation, file descriptor for regular files).

Implementation migrated all callers to secure alternatives (`git_mkstemps_mode()` and `git_mkdtemp()`) through systematic changes: Windows compatibility layer updates (patch 2/6), removal of unused `mingw_mktemp()` (patch 3/6), addition of `mktemp(3)` to `banned.h` (patch 4/6), removal of redundant `gitmkdtemp()` wrapper (patch 5/6), and build system configuration updates (patch 6/6). Changes removed 32 lines while maintaining functionality across platforms.

Jeff King confirms meson build works on Linux (though unable to test systems without native `mkdtemp()` support) and approves series for merging. Security rationale emphasizes proactive hardening by banning unsafe functions before exploits emerge. Key participants: Jeff King (security review), René Scharfe (implementation and build system considerations), Junio Hamano (maintainability review). Series shows completed migration path from insecure functions to unified secure infrastructure. Potential future work on `mkdtemp(3)` system call banning remains out of scope for this series. Build system integration for NO_MKDTEMP knob removal could be follow-up work.
