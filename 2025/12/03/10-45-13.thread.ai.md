Security-focused series to replace insecure `mktemp(3)` usage throughout Git codebase, motivated by POSIX deprecation. Introduces new cross-platform `git_mkdtemp()` wrapper (wrapper.c/h) as secure alternative, removing all existing `mktemp(3)` calls including Windows-specific `mingw_mktemp()`. Adds `mktemp(3)` to banned.h to prevent regression. Changes span compatibility layers with net -20 LOC, systematically eliminating platform-specific variants. Part of ongoing security hardening, though no specific vulnerabilities cited. Implementation appears thorough with Windows compatibility considered via mingw removal.
