This is an infrastructure refactoring patch from Patrick Steinhardt's v7 series introducing the `git-history` command. It extracts commit-picking logic from `builtin/replay.c` into new `replay.[ch]` files to share functionality between `git-replay` and the upcoming `git-history` command.

The patch moves two key functions - `create_commit()` (renamed to `replay_create_commit()`) and `pick_regular_commit()` (renamed to `replay_pick_regular_commit()`) - into the new shared module. These handle the core operations of creating new commits during history rewriting and picking/merging commits during replay process. The changes are mechanical with no behavior modifications - just relocation and renaming to establish clear subsystem boundaries.

The new `replay.h` header exposes these functions for cross-command sharing while maintaining type safety with proper struct declarations. Build system files (Makefile and meson.build) are updated to include the new source file. This foundational change enables subsequent patches in the series to build on this shared infrastructure for the history editing operations.

This is part of the larger effort to implement flexible history editing commands (`reword` and `split` subcommands) while avoiding code duplication. The extraction follows good software engineering practices by establishing clear interfaces between components early in the development process.
