This is an infrastructure patch in Patrick Steinhardt's v7 series introducing the new `git-history` command. The patch extracts commit-picking logic from `builtin/replay.c` into a new `replay.c` file to share it between `git-replay` and the upcoming `git-history` command.

The changes are primarily code movement - taking the `pick_regular_commit()` and `create_commit()` functions (now renamed with `replay_` prefixes) and their helper functions out of the replay builtin and into a new library file. This is clean refactoring with no behavior changes, just better code organization to support the planned history editing functionality.

The patch shows good attention to detail - it properly handles the transition of these functions into library code by:
- Adding the new files to build systems (Makefile and meson.build)
- Creating a proper header file with declarations
- Maintaining all existing functionality
- Using the new `replay_` prefix consistently

This is a straightforward but important preparatory step for the series, making the core commit manipulation logic available to both commands while keeping the `the_repository` global contained. The implementation looks solid and well-isolated.
