This is a clarification about a documentation issue regarding Git config command syntax in Russian translations. Kristoffer Haugsbakk responds to Eugene R's report about `git config list` appearing without double-dashes in the Russian docs, explaining this is actually correct behavior since Git 2.46.0 introduced subcommands that deprecate the `--list` option form. The email notes both forms still work but the double-dash version is now deprecated, and provides context about version adoption (Debian Stable using Git 2.47.0).

Key technical details for future reference: The change was introduced in Git 2.46.0 (2025) as part of moving config operations to subcommands rather than option flags. The documentation in question is the Russian translation of git-config docs on git-scm.com, currently showing version 2.52.0 content. The thread involves discussion of backward compatibility considerations as different systems may run older Git versions where the `--list` form would still be primary. The Deprecated Modes section of git-config documentation is referenced as authoritative source.
