This is a clarification about a documentation issue regarding command syntax in the Russian translation of git-config. Kristoffer Haugsbakk responds to Eugene R's report about what appeared to be a typo ("git config list" vs "git config --list") by explaining this is actually intentional - the single-dash form became the preferred syntax when subcommands were introduced in Git 2.46.0, making the double-dash form deprecated.

The email provides useful context about version compatibility, noting that while the new syntax is correct, many users may still be on older Git versions (like those shipped with Debian Stable) that predate this change. The response points to the "Deprecated Modes" section of the documentation for reference.
