This thread clarifies a documentation issue regarding the correct syntax for listing Git configuration. Eugene R initially reported what appeared to be a typo in the Russian translation of git-config documentation, where "git config list" was shown without double-dashes. However, Kristoffer Haugsbakk explains this is actually the correct form since Git 2.46.0, which introduced subcommands that deprecate the older `--list` option flag syntax. Both forms remain functional for backward compatibility, but the documentation properly reflects the newer preferred syntax. The discussion notes version adoption considerations, as some systems (like Debian Stable running Git 2.47.0) may still default to the older form. The thread serves as a useful clarification about this syntax transition in localized documentation.
