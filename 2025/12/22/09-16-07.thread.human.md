This thread began with a user report from Zhelyo Zhelev about a `git restore` error message that appeared to contain a typo ("could not resolve ource") when using an invalid `-source` argument. Brian M. Carlson clarified that this was actually correct parsing behavior (interpreting `-s ource`) but recognized an opportunity to improve the message formatting. He submitted a one-line patch to wrap the unresolved treeish in single quotes, matching Git's convention for similar error messages.

Junio C Hamano has now reviewed and approved the change, calling it "obviously the right thing to do." The patch will make the error output clearer when users mistakenly use a single dash (`-source` instead of `--source`), changing the message to "could not resolve 'ource'". This small but meaningful improvement demonstrates how user reports can lead to polish even in technically correct behavior, and the change is likely to be merged without further discussion.
