This is a feature enhancement for `git status` output, now in its 8th iteration, adding configurable branch comparison via `status.goalBranch`. The patch builds on previous versions while refining the commit message and maintaining all optimizations and test coverage from v6.

Key technical aspects:
- Adds `status.goalBranch` config option to show divergence from a secondary branch (e.g. upstream/main) alongside the normal tracking branch status
- Implements `get_goal_branch_ref()` to validate and resolve the configured branch (must be in remote/branch format)
- Uses existing `format_tracking_info()` infrastructure with new `format_goal_branch_comparison()` helper
- Shows comparison only when goal branch differs from tracking branch
- Preserves all v6 optimizations including single ref resolution point and consolidated memory management

The 340-line test file addition (t6040-tracking-info.sh) comprehensively covers:
- Various branch states (ahead, behind, diverged) for both tracking and goal branches
- Different remote configurations (origin vs upstream)
- Edge cases (unset config, malformed config, nonexistent branches)
- Integration with existing tracking info display
- Output format verification across scenarios

Notable changes from v7:
- Commit message rewritten to be more concise while maintaining all key information
- Example output updated to use 'upstream/main' consistently
- Clarifies that comparison only shows when goal branch differs from tracking branch

The implementation appears stable with thorough test coverage. The author has been responsive to maintainer feedback throughout the 8 iterations, suggesting this is likely in final form pending any last organizational tweaks.
