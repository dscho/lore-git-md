This thread began with Sergey Organov noticing that `git branch --show-current -v` silently ignores the `-v` flag, which seemed inconsistent with other `git branch` behaviors. Junio Hamano initially explained that `--show-current` was designed as a simple alternative to `git symbolic-ref HEAD` rather than as a variant of the listing functionality, but later agreed the silent flag ignoring was buggy.

The discussion converged on explicitly rejecting the combination rather than implementing verbose output support. A patch has now been submitted that makes `-v` with `--show-current` error out clearly, adding an error check in `builtin/branch.c` and a test case. While Junio notes the solution could be more thorough by tracking how `filter.verbose` was set, he considers the current implementation sufficient as it fixes the silent behavior while maintaining backward compatibility.

This appears to resolve the thread's original issue, providing a clear error message where there was previously silent behavior. The solution is narrowly focused on the bugfix without expanding `--show-current`'s functionality, which remains a simple way to show the current branch name. Unless new arguments emerge for supporting verbose output, this patch likely represents the discussion's conclusion.
