Feature enhancement adding configurable branch comparison to `git status` output, now in its 7th iteration. This version appears to be a rollback to the v5 implementation while keeping the v6 test coverage, likely in response to maintainer feedback about the configuration interface.

The patch introduces a new `status.goalBranch` config option (reverting from v6's `status.compareBranch`) that lets users specify a remote/branch pair (like "origin/main") to compare against in addition to the current tracking branch. The comparison shows how much the current branch has diverged from this goal branch, helping users track drift from important upstream branches.

Key technical components:
- New `get_goal_branch_ref()` function handles config lookup and validation
- `format_goal_branch_comparison()` generates the comparison output
- Strict validation of the "remote/branch" format with warnings for invalid config
- Comparison only shown when different from tracking status
- Comprehensive test coverage in t6040-tracking-info.sh with 12 scenarios

The implementation builds on existing tracking infrastructure but adds the new configurable comparison point. Performance appears optimized with single ref resolution points and consolidated memory management. The test suite thoroughly exercises various states (ahead, behind, diverged) with different remote/branch combinations.

This version seems to address Junio C Hamano's earlier feedback about using existing branch config rather than introducing new mechanisms, though it's unclear why the v6 configuration approach was reverted. The test coverage from v6 remains intact, including handling of unset/malformed config and non-existent branches.
