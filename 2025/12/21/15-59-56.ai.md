This is a feature patch introducing a new `checkout.remoteBranchTemplate` configuration option to customize how Git resolves remote branch names during DWIM (Do What I Mean) operations like checkout and push with auto-setup.

The patch adds a printf-style template system where `%s` represents the local branch name, allowing remote branches to follow different naming conventions than local ones. For example, with `feature/%s`, checking out `foo` would look for `origin/feature/foo`. The template applies to:
- `git checkout` DWIM behavior
- `git worktree --guess-remote`
- `git push` with `push.autoSetupRemote`

The implementation includes thorough documentation, warning messages for invalid templates (missing `%s`), and extensive test coverage across all affected commands. The tests verify:
- Basic template functionality
- Literal `%%` handling
- Multi-segment templates
- Interaction with existing features like `checkout.defaultRemote`
- Error cases (no matches, ambiguity, invalid templates)
- Command-specific behavior (worktree add, push defaults)
