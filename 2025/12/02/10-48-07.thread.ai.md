This 3-patch series improves Git's Meson build system for cross-compilation scenarios, originally started by D. Ben Knoble and continued by Toon Claes. The changes address specific issues in cross-compilation environments, particularly targeting s390x architecture but applicable more broadly.

Technical changes:
- First patch adds `subprojects/.wraplock` to `.gitignore` to exclude Meson's wrapper lock files (references upstream Meson issue #14948)
- Second patch modifies `meson.build` to skip ICONV_OMITS_BOM detection when cross-compiling by wrapping the test in `meson.can_run_host_binaries()` check
- Third patch standardizes on `meson.can_run_host_binaries()` for `sysctl` detection test, implementing Patrick Steinhardt's suggestion about consistent cross-compilation handling
- Careful distinction maintained between `can_run_host_binaries()` (execution tests) and `is_cross_build()` (file existence checks), with Toon Claes confirming one remaining `is_cross_compile()` check is appropriate for `fs.exists()` operations
- Total changes: 4 lines modified across 2 files (1 line in first patch, 3 lines across second and third patches)
