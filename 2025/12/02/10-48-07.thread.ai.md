This is a 2-patch series improving Git's Meson build system for cross-compilation scenarios, originally started by D. Ben Knoble and continued by Toon Claes. The changes address specific issues in cross-compilation environments, particularly targeting s390x architecture but applicable more broadly.

Technical changes:
- First patch adds `subprojects/.wraplock` to `.gitignore` to exclude Meson's wrapper lock files (references upstream Meson issue #14948)
- Second patch modifies `meson.build` to skip ICONV_OMITS_BOM detection when cross-compiling by wrapping the test in `meson.can_run_host_binaries()` check
- Patrick Steinhardt notes another similar case using `not meson.is_cross_build()` that could be updated to use `can_run_host_binaries()` for consistency and better support for execution wrappers like QEMU
- Total changes so far: 3 lines modified across 2 files (1 line in first patch, 2 lines in second)

Build system context:
