This is a performance optimization and API extension for Git's diff machinery, specifically targeting the `diff-tree` command. It builds on René Scharfe's earlier work that introduced `diff_same()` for `diff-index` optimizations.

The patch extends the `diff_same()` optimization to `diff-tree` by adding a new `keep_fn_t` callback to `struct diff_options` and implementing the plumbing to support it. Key changes include:
1. Adding `diff_same()` as the default `keep` handler in `repo_diff_setup()`
2. Updating documentation in `diff.h` and `diffcore.h` to include the new callback
3. Modifying `tree-diff.c` to use `diff_same()` when files are unchanged (mode and OID match) and copy detection is enabled
4. Adding the callback to `builtin/reset.c` for consistency

Performance impact is mixed - while memory usage shows a small reduction (from ~36MB to ~35MB peak), timing results vary between test cases. Some benchmarks show a 5% speedup (Linux repo comparing v6.8 to v6.9), while others show a 1% slowdown (comparing v2.51.0 to v2.51.1). The author expresses some disappointment with the overall performance gains.

The changes maintain architectural consistency with the existing diff API, adding `diff_same()` alongside `diff_change()` and `diff_addremove()`. The implementation carefully handles the callback chain in `tree-diff.c` where the actual diff operations are processed. This completes the application of the optimization across Git's diff commands, following its successful implementation for `diff-index`.
