This is a follow-up bugfix and test addition for the `diff-files` command, extending René Scharfe's earlier performance optimization work on `diff-index`. The patch fixes copy detection in `diff-files` when using `--find-copies-harder`, which had been broken since 2008 due to an oversight in how unchanged files were handled.

The key changes are:
1. Fixes copy detection for reverse diffs (index-to-working-tree comparisons) by properly queuing up-to-date and skip-worktree entries using the new `diff_same()` function
2. Extends the optimization to clean submodules and cases where index preloading didn't complete
3. Adds two new tests - one reliable test for basic functionality and a stress-tested version that exercises the preloading case

The patch builds on the earlier accepted optimization while addressing a related but distinct issue in `diff-files`. It maintains the same careful approach with thorough testing, though the author notes the stress test is inherently racy (a known limitation of testing parallel operations). The changes are well-contained and focused, continuing the pattern of the original performance work.
