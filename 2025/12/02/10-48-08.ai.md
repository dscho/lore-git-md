Build system patch adding Meson wrapper lock file to gitignore. This is the first of two patches in a series improving Git's Meson build system for cross-compilation scenarios.

The change adds `subprojects/.wraplock` to `.gitignore` to prevent Meson's automatically generated wrapper lock files from being tracked in version control. These files are created when Meson wraps subprojects but should not be committed. The patch references an upstream Meson issue (#14948) documenting this behavior.

This is a straightforward housekeeping change that aligns with standard practice for build system artifacts. The modification is minimal (a single line addition) and focused specifically on build system configuration rather than affecting Git's core functionality. The change appears uncontroversial and well-justified by the upstream Meson behavior.

Technical details for future reference:
- Adds `.wraplock` pattern to `subprojects/.gitignore`
- Related to Meson's subproject wrapper functionality
- Does not affect build output or runtime behavior
- Part of cross-compilation improvements but applicable to all Meson builds
