This is a build system patch fixing an issue with cross-compilation in Git's Meson setup. It's the second in a two-part series addressing Meson build quirks, though this particular patch comes from a different author (Toon Claes) than the series opener.

The change modifies how Git detects whether the system's iconv implementation omits BOM (byte order mark) markers during cross-compilation scenarios. The current detection method tries to compile and run a test program, which fails when cross-compiling since the host can't execute binaries built for the target architecture. The patch adds a guard to only attempt this test when host binaries can actually run.

This is a straightforward technical fix that aligns with standard Meson build practices. The change is minimal (just one line modified) and clearly motivated by real cross-compilation needs, particularly for s390x architecture. The patch appears well-formed and focused, though it's worth noting this is a new contributor's first submission to the list.
