This thread covers a small but important series of patches improving Git's Meson build system for cross-compilation scenarios, particularly on s390x architecture. The work was initiated by D. Ben Knoble and completed by Toon Claes, with Patrick Steinhardt providing key review feedback.

The three patches make targeted changes to handle cases where cross-compiled binaries cannot run directly on the build host. The first patch simply excludes Meson's wrapper lock files from version control. The more substantive changes standardize on using `meson.can_run_host_binaries()` for execution tests while keeping `is_cross_build()` for filesystem checks, following Patrick's suggestion to properly distinguish between these cases. The changes are minimal (just 4 lines modified total) but make the build system more robust.

Patrick has now reviewed and approved the final patch, confirming the series addresses all identified cross-compilation issues. With no remaining open questions or objections, these small but well-considered build system improvements appear ready for inclusion in the next release. The thread demonstrates Git's attention to build system edge cases, even for niche scenarios like cross-compilation.
