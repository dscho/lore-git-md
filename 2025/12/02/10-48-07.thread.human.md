This thread discusses a 3-patch series by Toon Claes (with initial work by D. Ben Knoble) that improves Git's Meson build system for cross-compilation scenarios, particularly for s390x/Linux on IBM Z/LinuxOne systems. The changes address cross-compilation issues through focused Meson build configuration modifications, adding checks for when host binaries can be executed during cross-compilation and properly ignoring Meson wrapper lock files.

The technical discussion clarified that the target platform is specifically 64-bit Big Endian Linux for s390x (IBM Z/LinuxOne), not Z/OS, as confirmed by ELF binary analysis showing GNU/Linux 3.2.0 with S/390 architecture using System V ABI. Carlo Arenas offered to test the cross-compiled binaries on his RHEL9/s390x system, providing a path for real-world validation.

Patrick Steinhardt reviewed and approved the final version of the patches, which now properly distinguish between execution tests (using `can_run_host_binaries()`) and filesystem operations (using `is_cross_build()`). The series is complete with all cross-compilation issues addressed and no open questions remaining, making it ready for inclusion. The changes are minimal (4 lines modified across 2 files) but make the build system more robust for cross-compilation scenarios while having no impact on native builds.
