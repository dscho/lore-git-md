This thread discusses improvements to Git's Meson build system for better cross-compilation support, originally started by D. Ben Knoble and continued by Toon Claes. The two-patch series addresses specific issues in cross-compilation environments, particularly for s390x architecture. The first patch excludes Meson's wrapper lock files from version control, while the second fixes iconv behavior detection during cross-compilation by using `meson.can_run_host_binaries()`.

Patrick Steinhardt has now joined the discussion, noting there's another similar case in the codebase that could benefit from the same approach. He points out that a different check currently using `not meson.is_cross_build()` should also be updated to use the more robust `can_run_host_binaries()` method, which properly accounts for execution wrappers like QEMU. This would make a logical follow-up patch, though it doesn't affect the current series.

The changes remain uncontroversial, with all participants focused on technical improvements to the build system. The patches are small and clearly motivated, addressing specific cross-compilation edge cases without impacting native builds. Patrick's suggestion indicates the discussion may continue with additional similar cleanups, but the current series appears ready to proceed.
