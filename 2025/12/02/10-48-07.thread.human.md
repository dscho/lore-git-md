This thread covers a small but important series of patches improving Git's Meson build system for cross-compilation scenarios, originally started by D. Ben Knoble and continued by Toon Claes. The changes specifically address issues when building for s390x and other architectures where the build machine cannot run target binaries.

The three changes are narrowly focused: one excludes Meson wrapper lock files from version control, while the other two standardize how cross-compilation tests are handled in the build system. Patrick Steinhardt provided key feedback about consistently using `meson.can_run_host_binaries()` for execution tests (like compiler checks) while keeping `is_cross_build()` for simple file existence tests. Toon implemented this distinction carefully, leaving one `is_cross_compile()` check in place where it was appropriate for filesystem operations.

The discussion has reached consensus, with all identified cross-compilation issues now addressed. The changes are minimal (just 4 lines modified total) but make the build system more robust for cross-compilation without affecting native builds. The series appears ready for merging.
