This thread covers a small but useful improvement to Git's Meson build system by D. Ben Knoble, addressing two cross-compilation issues. The first patch adds Meson's wrapper lock files to `.gitignore` to prevent them from being accidentally committed - a straightforward housekeeping change that references an upstream Meson issue. The second patch modifies iconv detection to work correctly during cross-compilation when test programs can't run on the build host. Both changes are minimal (just 2 lines modified total) and focused on build system edge cases, particularly relevant for s390x architecture but applicable to other cross-compilation scenarios. The patches appear uncontroversial and well-justified, though no reviews have been posted yet. The changes don't affect Git's core functionality but improve build system robustness.
