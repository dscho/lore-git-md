This is a documentation patch series addressing hash algorithm defaults in Git's "breaking changes" mode. The series consists of 4 patches updating documentation files to correctly reflect that SHA-256 (not SHA-1) is the default hash algorithm when Git is compiled with WITH_BREAKING_CHANGES defined.

The changes affect documentation for `git`, `git-init`, `git-index-pack`, and `git-show-index` commands. Each patch updates the man pages to conditionally show either SHA-1 or SHA-256 as the default algorithm based on the build configuration. The changes are mechanical but important for accuracy, particularly as Git project moves toward version 3.0 where SHA-256 will become the standard default.

The series is well-scoped and clearly motivated - it fixes an inconsistency between code behavior and documentation that could confuse users building Git with breaking changes enabled. The patches follow a consistent pattern of adding conditional documentation based on the with-breaking-changes attribute. This appears to be a straightforward documentation update with no expected controversy, though reviewers may want to verify the exact phrasing of the conditional documentation.
