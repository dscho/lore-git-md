This is a follow-up in the ongoing effort to modernize Git's advice messages by replacing `man` references with `git help`. Kristoffer Haugsbakk responds to Junio C Hamano's suggestion to strengthen the justification for this change.

The email clarifies that the motivation isn't just about platform compatibility (some systems lacking `man`), but also about consistency - since the advice comes from Git itself, it makes sense to reference Git's own help system rather than an external command. Haugsbakk acknowledges that users on Unix-like systems might not initially consider this distinction, and agrees to make the rationale clearer in the commit message.

The exchange shows the patch is moving toward acceptance, with both parties aligned on the technical approach and now refining the justification. This continues the documentation modernization work started in commit 8fbd903e earlier this year.
