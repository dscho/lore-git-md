Performance optimization and bugfix for copy detection in `diff-files`. This follow-up patch extends René Scharfe's earlier `diff-index` optimization to `diff-files`, while also fixing a long-standing copy detection bug. The original `diff-index` work introduced `diff_same()` to efficiently handle unchanged file pairs when using `--find-copies-harder`, and this patch applies similar logic to `diff-files`.

The key changes are:
1. Fixes broken copy detection in `diff-files` that was introduced in 2008 (d1f2d7e8ca) when comparing index to working tree, particularly affecting cases with index preloading
2. Extends use of `diff_same()` to `diff-files` for up-to-date and skip-worktree entries, matching the memory efficiency improvements from the `diff-index` patch
3. Adds two new test cases - one stable test for basic functionality and one stress test for the preloading edge case

The patch modifies `diff-lib.c` to properly queue unchanged files using `diff_same()` and adds test coverage in `t/t4007-rename-3.sh`. The tests demonstrate both the fixed copy detection behavior and verify the optimization's correctness under preloading conditions. This appears to be a logical extension of the earlier optimization, addressing a related but distinct code path while fixing a subtle bug that had gone unnoticed for years due to test coverage gaps and race conditions in the preloading mechanism.
