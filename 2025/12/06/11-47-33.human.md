This is a test infrastructure patch demonstrating new assertion macros in the clar test suite, part of Patrick Steinhardt's series updating Git's unit test framework. The patch converts simple integer comparison assertions in the reftable record tests to use the new type-specific macros like `cl_assert_gt_i()` and `cl_assert_lt_i()` that were introduced in the first patch of the series.

The changes are mechanical but improve test clarity by using more descriptive assertion names that match the actual comparison being made (greater than, less than, etc.) rather than the generic `cl_assert()`. The patch touches only the reftable record unit tests, updating 11 assertions across various test cases that verify record encoding, decoding, and comparison behavior.

This follows naturally from the framework updates in patch 1/2, showing the new macros in action. The changes are straightforward and well-contained, with no functional impact on the tests themselves - they just produce better failure messages when assertions fail. The patch appears to be a clean demonstration of the new capabilities, though as with any test changes, reviewers will want to verify the updated assertions precisely match the original intent.
