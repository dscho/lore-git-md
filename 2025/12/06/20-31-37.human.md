This is a refactoring patch in Taylor Blau's ongoing MIDX compaction series. It simplifies the pack enumeration logic in `fill_packs_from_midx()` by directly using the `pack_int_id` values rather than calculating them through an offset. 

The change makes the code more straightforward by enumerating the actual pack IDs (`[m->num_packs_in_base, m->num_packs_in_base + m->num_packs)`) instead of first iterating over a relative range and then adjusting. This matches the natural way the IDs are stored in the MIDX structure.

The patch is small (just 3 lines changed) and focused, continuing the series' pattern of careful, incremental improvements to the MIDX codebase. It builds on the previous extraction of `fill_pack_from_midx()` in patch 12/17, making the same logical operation clearer by removing the intermediate offset calculation. The change is purely internal - no behavior or interface changes are introduced.
