This is a refactoring patch in Taylor Blau's MIDX compaction series, which aims to improve incremental repacking in Git's multi-pack index system.

The patch splits the existing `get_midx_checksum()` function into two variants: one that returns a hexadecimal string representation (`get_midx_checksum()`) and another that returns the raw bytes (`get_midx_hash()`). This change eliminates repetitive calls to `hash_to_hex_algop()` throughout the codebase while maintaining the ability to work with raw hash bytes when needed.

The modification affects several MIDX-related files including midx-write.c, pack-bitmap.c, and pack-revindex.c, updating callers to use the appropriate variant. Most callers switch to the string version, while a few that need raw bytes (like hash comparisons) use the new `get_midx_hash()` function.

This appears to be a straightforward cleanup that improves code clarity and reduces boilerplate, though it's worth noting this is just one small piece of a much larger effort to improve MIDX handling. The changes are mechanical and well-contained, with no apparent behavior changes beyond the intended refactoring.
