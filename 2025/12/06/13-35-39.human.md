This is the final patch in a security-focused series eliminating insecure `mktemp(3)` usage. It removes the now-redundant `gitmkdtemp()` compatibility wrapper, which had become a trivial layer over the new secure `git_mkdtemp()` function introduced earlier in the series.

The change is straightforward, deleting the wrapper implementation and updating build system files (Makefile, CMake, meson) to stop compiling the now-unneeded compatibility code. The patch maintains functionality while simplifying the codebase by -14 lines across 5 files. As with previous patches in the series, this demonstrates the project's pattern of removing insecure or redundant code paths after migrating callers to safer alternatives.

The patch appears well-tested (though only with `make` per the author's note) and follows the established pattern of the series. With this change, the security hardening effort reaches its logical conclusion for directory creation, having replaced all insecure temp file/directory creation with the new unified secure infrastructure. The series as a whole represents a clean, well-executed security improvement to Git's codebase.
