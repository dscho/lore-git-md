This is a refactoring patch in Taylor Blau's MIDX compaction series (part 3/17). It standardizes the handling of the `--progress` option across all `git multi-pack-index` subcommands (write, verify, repack, and expire) by moving it into the common options list rather than having each subcommand declare it separately.

The change is straightforward and well-justified - since all subcommands already supported `--progress`, centralizing it makes the code more maintainable and consistent. The patch updates both the implementation (removing redundant option declarations) and documentation (adding a section for common options). This appears to be a clean preparatory change before introducing the core compaction functionality in later patches.
