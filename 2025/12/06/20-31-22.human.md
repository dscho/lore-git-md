This is patch 8/17 in Taylor Blau's series implementing MIDX layer compaction, part of the ongoing effort to improve Git's multi-pack index handling for large repositories.

The patch refactors the MIDX writing code by introducing a `struct write_midx_opts` to consolidate the six parameters currently passed to `write_midx_internal()`. This internal function is called by four public MIDX-writing functions (`write_midx_file()`, `write_midx_file_only()`, `expire_midx_packs()`, and `midx_repack()`), each passing different combinations of parameters.

The change makes the code more maintainable as future patches in the series will need to add more parameters to support MIDX compaction. Using a struct allows adding new fields without requiring all callers to be updated with new parameters they don't need. The patch is purely structural - there are no functional changes, just moving parameters into a struct and updating all call sites accordingly.

This is a clean, well-motivated refactoring that follows established Git patterns for handling growing parameter lists. It sets up the infrastructure needed for the compaction functionality coming in later patches while improving the codebase's maintainability. The change is straightforward and unlikely to be controversial.
