This is a refactoring patch in Taylor Blau's MIDX compaction series, introducing a helper function to safely handle pack permutations during MIDX layer compaction. The patch addresses a potential out-of-bounds access issue that would arise when compacting MIDX layers with discontinuous pack_int_id ranges.

The new `midx_pack_perm()` helper function centralizes access to the `ctx->pack_perm` array, which maps original pack IDs to their positions in the current context. This prepares for future changes where the input pack IDs may exceed the array bounds during compaction of non-contiguous MIDX layers. The patch demonstrates a careful approach by first introducing the helper function without changing behavior, making the subsequent compaction logic easier to implement safely.

Key technical points include:
- Current code assumes pack_int_id values are contiguous and less than ctx->nr
- MIDX compaction breaks this assumption by combining layers with discontinuous IDs
- The helper function will later be modified to handle ID offsetting without memory waste
- All existing call sites are updated to use the new helper function

The change touches several MIDX writing functions including object offset writing, pack ordering, and packing data preparation. This is a preparatory step for the compaction functionality described in the series' earlier patches, maintaining safety while enabling future optimizations.
