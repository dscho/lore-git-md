Security cleanup removing Windows-specific `mktemp` compatibility code. This is patch 3/5 in a series eliminating insecure temporary file handling across Git's codebase.

René Scharfe removes the Windows-specific `mingw_mktemp()` function and its declaration, following up on the previous patch that migrated its last caller to the new secure `git_mkstemp_mode()` infrastructure. The deletion removes 15 lines of code across two files (`compat/mingw-posix.h` and `compat/mingw.c`), continuing the series' pattern of straightforward removals of now-unused insecure functions.

This change is part of a coordinated security hardening effort that has already seen positive review from key contributors. The patch appears well-contained and low-risk, simply removing code that is no longer needed after the secure migration. The series as a whole demonstrates careful attention to cross-platform compatibility while systematically eliminating potentially unsafe code paths.
