This is the final patch in Taylor Blau's 17-part series implementing MIDX layer compaction, focusing specifically on enabling reachability bitmaps during the compaction process. The patch allows combining existing bitmaps from compacted MIDX layers while preserving the pseudo-pack ordering established in previous commits.

The key change is relatively small but important: it ensures objects are treated as non-preferred during compaction to maintain the correct object ordering. The patch also introduces a `--bitmap` option to the `git multi-pack-index compact` command and adds extensive test coverage verifying that bitmap handling works correctly during compaction.

The commit message notes this is groundwork for potentially more sophisticated bitmap strategies in the future, like generating new bitmaps when references have moved significantly. The tests demonstrate bitmap preservation across various scenarios, including both simple cases and more complex repository topologies with multiple branches.

This patch completes the technical implementation of MIDX compaction, building on the substantial refactoring and infrastructure work done in the previous 16 patches. The series as a whole represents a significant step forward in Git's ability to efficiently manage repositories with many packfiles.
