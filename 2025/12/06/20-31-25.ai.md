Performance optimization in the MIDX compaction series. This patch removes the requirement for MIDX pack files to be sorted lexicographically, which was previously needed for binary search lookups but created problems for MIDX layer compaction. The change allows combining adjacent MIDX layers without invalidating bitmaps from newer layers, a key goal of the compaction effort.

The patch introduces a lazy-sorted `pack_names_sorted` array in the MIDX struct to maintain O(log n) lookup performance via binary search, while allowing packs to be stored in any order. This enables more flexible MIDX layer combinations by eliminating the lexicographic ordering constraint that previously forced bitmap permutations during compaction. The implementation maintains backward compatibility - existing Git versions will ignore MIDX files with out-of-order packs rather than failing.

Key technical details include removal of BUG/die checks for pack ordering, addition of the sorted index array, and a new comparison function for the QSORT_S operation. The patch drops an associated test that verified the now-removed ordering requirement. This change is part of Taylor Blau's larger MIDX compaction series aimed at improving incremental repacking performance in large repositories.
