Refactoring patch in Taylor Blau's MIDX compaction series. This is patch 2/17 in the series implementing MIDX layer compaction for more efficient repacking.

The patch splits the existing `get_midx_checksum()` function into two variants: `get_midx_checksum()` now returns a static buffer containing the hex-formatted checksum (the common case), while new `get_midx_hash()` provides direct access to the raw bytes for callers needing byte-level comparison. This eliminates repetitive `hash_to_hex_algop()` calls across the codebase while maintaining all existing functionality.

Changes affect midx-write.c, midx.c, midx.h, pack-bitmap.c, pack-revindex.c, and test-read-midx.c. The refactoring is straightforward with clear mechanical conversions - most callers switch to the new `get_midx_checksum()`, while a few (like bitmap validation code) use the new raw `get_midx_hash()`. The patch maintains all existing behavior while reducing code duplication, serving as a clean preparatory change before the series' core compaction logic.
