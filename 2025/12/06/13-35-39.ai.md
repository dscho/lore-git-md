Security patch completing the removal of insecure temporary directory creation infrastructure. This final patch in the series eliminates the now-redundant `gitmkdtemp()` wrapper function after all callers were migrated to the secure `git_mkdtemp()` alternative in earlier patches.

The change removes 14 lines across 5 files, deleting the trivial wrapper implementation (`compat/mkdtemp.c`) and updating build system configurations (Makefile, CMake, meson) to no longer reference it. The `NO_MKDTEMP` compatibility layer now directly maps `mkdtemp` to `git_mkdtemp` in `compat/posix.h` rather than going through the intermediate wrapper.

This follows the series' established pattern of removing deprecated security-sensitive code paths after ensuring all callers use the secure alternatives. The patch maintains cross-platform compatibility while simplifying the codebase. Testing appears minimal (only "tested with make" noted), but given the straightforward nature of the change and its position as the culmination of a well-reviewed series, this seems adequate.

The removal completes the security hardening effort to eliminate `mktemp(3)`-related vulnerabilities from Git's codebase, leaving only consideration of potential future `mkdtemp(3)` system call banning as noted in the thread context. Build system integration for `NO_MKDTEMP` knob removal remains a possible follow-up, though not addressed here.
