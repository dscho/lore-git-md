This is a test infrastructure patch that addresses a minor formatting issue in the clar unit test framework. It's the third and final patch in Patrick Steinhardt's series updating the clar test framework.

The patch adds a `.gitattributes` rule to disable Git's blank-at-eof whitespace checks for the clar framework's expected test output files. Some of these test files intentionally end with blank lines as part of their expected output format, which would normally trigger Git's whitespace warnings. The change follows a suggestion from Junio Hamano in response to the first version of this patch series.

This is a straightforward change that doesn't affect test functionality - it simply prevents false positives from Git's whitespace checks. The patch adds just one line to `.gitattributes`, targeting the test output files in `t/unit-tests/clar/test/expected/`. The change maintains consistency with the clar framework's output format while keeping the repository clean of spurious whitespace warnings.
