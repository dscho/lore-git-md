Midx-write refactoring to prepare for compaction functionality. This patch introduces a `struct write_midx_opts` to consolidate the six parameters currently passed to `write_midx_internal()` into a single structure. The change is motivated by the need to add more parameters for upcoming MIDX compaction support while avoiding an unwieldy function signature. 

The new struct contains all existing parameters as members (`source`, `packs_to_include`, `packs_to_drop`, `preferred_pack_name`, `refs_snapshot`, and `flags`). The patch updates all four wrapper functions (`write_midx_file()`, `write_midx_file_only()`, `expire_midx_packs()`, and `midx_repack()`) to initialize this struct and pass it to `write_midx_internal()`. 

Key technical aspects include maintaining zero-initialization of the opts struct at call sites (allowing new fields to be added without requiring updates to all callers) and preserving all existing behavior exactly. The diff shows mechanical conversion of parameter passing to struct member access throughout `write_midx_internal()`'s implementation. This is a preparatory change for patch 9/17 which will add compaction-specific fields to the opts struct.
