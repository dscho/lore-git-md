This is a test infrastructure patch addressing whitespace handling in the clar test framework, following up on feedback from Junio Hamano in the previous version of the series.

The patch adds a `.gitattributes` rule to disable blank-at-eof whitespace checks for clar's expected test output files. Some of clar's self-test files intentionally end with blank lines as part of their expected output format, which Git would normally flag as whitespace errors. The change is minimal - a single line addition to `.gitattributes` that exempts these specific test files from the blank-at-eof check.

The change maintains consistency with clar's output format requirements while keeping Git's whitespace checks active elsewhere.
