This is the second patch in a 3-part test infrastructure series updating Git's clar test assertions. It demonstrates the new integer comparison macros introduced in patch 1 by converting simple `cl_assert(n > 0)` style checks in the reftable unit tests to use the type-specific assertion macros like `cl_assert_gt_i()` and `cl_assert_lt_i()`.

The patch updates 11 assertions in t/unit-tests/u-reftable-record.c to use the new macros, which provide better type safety and more descriptive failure messages. Changes include converting:
- Simple inequality checks (`n > 0`) to `cl_assert_gt_i(n, 0)`
- A `n >= 0` check to `cl_assert_ge_i(n, 0)`
- A `cmp < 0` check to `cl_assert_lt_i(cmp, 0)`

The modifications are mechanical replacements that don't change test behavior, only the assertion mechanism. This serves as both a demonstration of the new macros' usage and an improvement to the test suite's robustness. The patch follows naturally from the framework updates in patch 1 and precedes patch 3's `.gitattributes` addition for test output formatting.

Key files touched are limited to the reftable record test file. The changes affect test assertions only - no production code or test logic is modified. This continues the series' focus on modernizing test infrastructure with better type handling while maintaining compatibility with existing test behavior.
