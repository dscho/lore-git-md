Refactoring patch in Taylor Blau's MIDX compaction series, extracting pack preparation logic for reuse.

This patch splits out `fill_pack_from_midx()` from `fill_packs_from_midx()` to isolate the logic for loading and preparing a single pack from a MIDX. The new helper function handles pack preparation, error reporting, and filling the pack_info struct for a given pack_int_id. This prepares for future use in MIDX compaction where the same pack preparation logic will be needed but with different calling context.

The change is straightforward - the existing loop in `fill_packs_from_midx()` is modified to call the new helper for each pack, maintaining the same behavior while making the pack-specific logic reusable. Error handling remains consistent, with the helper returning -1 on failure (like the original code did for prepare_midx_pack failures).

This continues the series' pattern of careful refactoring to support MIDX compaction, with each patch making incremental changes to prepare for later functionality. The extracted function will be used in upcoming compaction work where packs need to be processed individually rather than in bulk. The patch maintains all existing behavior while reducing future code duplication.
