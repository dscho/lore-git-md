Security patch introducing a secure `git_mkdtemp()` wrapper as part of a series eliminating insecure `mktemp(3)` usage. This first patch extends the existing `git_mkstemps_mode()` infrastructure to support both file and directory creation, then exposes a new `git_mkdtemp()` function that creates secure temporary directories with 0700 permissions.

The implementation shares the same secure random suffix generation as the file-creation path, but uses `mkdir(2)` instead of `open(2)`. The patch includes clear documentation of the return values (-1 for error, 0 for directory creation, or a file descriptor for regular files). This is foundational work for the rest of the series which will migrate callers away from insecure temp directory creation methods.

The patch appears well-considered, with clean separation of concerns between the new shared `git_mkdstemps_mode()` helper and the existing callers. The 0700 permission mode for directories follows security best practices. As the first in a reviewed series with clear security motivation, this looks like a solid technical foundation for the subsequent migrations.
