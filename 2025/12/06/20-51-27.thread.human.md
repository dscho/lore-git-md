This thread discusses a bugfix for the histogram diff algorithm (XDF_HISTOGRAM_DIFF) in Git's xdiff library, addressing an edge case where shifted change groups during compaction can produce redundant diff output containing matching lines from both files. The issue affects less than 1% of diffs but clearly degrades output quality when it occurs.

The proposed solution adds logic to detect when shifting creates new matching groups and re-diffs those sections using Myer's algorithm while preserving all original flags.
