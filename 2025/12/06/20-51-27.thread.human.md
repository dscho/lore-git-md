This thread addresses a bug in the histogram diff algorithm (XDF_HISTOGRAM_DIFF) where shifted change groups during compaction could produce redundant output showing matching lines from both files. The proposed fix detects these cases and re-diffs the affected sections using Myer's algorithm while preserving all original diff flags.

Phillip Wood has provided thorough technical review, questioning implementation details but ultimately agreeing the core approach is sound. He explained why completely disabling group shifting (as Junio initially wondered) would be worse, as it would prevent useful coalescing of changed lines. Phillip also noted that histogram diff sometimes produces less readable output than patience diff, though this appears to be inherent to the algorithm rather than a bug.

Junio has suggested some code organization improvements but agrees the solution works. The discussion has now reached consensus, with only minor refinements remaining before the patch can be merged. Test coverage in t4073 verifies the fix across multiple scenarios. While this edge case affects less than 1% of diffs, it cleanly resolves clearly undesirable output when it does occur.
