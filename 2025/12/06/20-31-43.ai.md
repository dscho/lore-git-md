This is a test infrastructure patch in Taylor Blau's MIDX compaction series, fixing a memory leak in the test helper code. The patch addresses a theoretical issue in `test-read-midx.c` where walking the MIDX chain to find a specific layer by checksum would leak memory for intermediate layers. The fix maintains a reference to the tip of the MIDX chain and ensures proper cleanup.

The test helper currently doesn't exercise this path in the test suite, but the patch proactively fixes the leak that would be exposed by future changes. The change is straightforward - it adds a `tip` reference to track the original MIDX, modifies the error handling to use a `goto` pattern for cleanup, and ensures `close_midx()` is called on the tip rather than the current MIDX being examined.

This continues the series' pattern of careful attention to memory management and test infrastructure, though it's a relatively minor fix compared to the core MIDX compaction functionality being developed in other patches. The change is well-contained to test code and doesn't affect production behavior.
