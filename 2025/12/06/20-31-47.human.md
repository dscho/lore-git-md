This is a feature patch implementing MIDX compaction, part of Taylor Blau's 17-patch series to improve Git's multi-pack index system. The series aims to enable efficient incremental repacking by compacting sequences of adjacent MIDX layers while preserving the MIDX chain and bitmap validity.

The patch introduces a new `git multi-pack-index compact` subcommand that combines a range of MIDX layers (specified by checksums) into a single layer. This addresses several limitations of the existing `--stdin-packs` approach, which couldn't preserve the MIDX chain or maintain bitmap validity for subsequent layers. The implementation carefully handles pack ordering and ID mapping to ensure compatibility with existing bitmaps.

Key technical changes include:
- New `fill_packs_from_midx_range()` to walk backwards through the compaction range
- Adjustments to `pack_int_id` mapping to maintain original pack references
- Special handling of the MIDX chain file to replace compacted layers
- New test cases verifying compaction with both ordered and unordered pack names

The patch continues the series' careful attention to memory management and backward compatibility. While the tests are currently basic (focusing on pack selection and ordering), the core functionality appears well-implemented with clear documentation. This is a significant step toward more scalable MIDX maintenance in large repositories.
