Refactoring patch in Taylor Blau's MIDX compaction series. This is the third patch in a 17-part series aimed at improving MIDX layer compaction for more efficient repacking.

The change centralizes the `--progress` option handling for all `git multi-pack-index` subcommands (write, verify, repack, expire) by moving it from individual subcommand declarations into the shared `common_opts` array. This eliminates duplicate option declarations while maintaining identical functionality. The patch also documents that these options apply to all subcommands in the manual page.

The change is straightforward and mechanical, touching only the option parsing infrastructure in builtin/multi-pack-index.c and adding documentation clarification. It serves as a preparatory cleanup before introducing more complex MIDX compaction logic later in the series. The implementation maintains all existing behavior while reducing code duplication - a typical refactoring pattern seen in this type of preparatory work.
