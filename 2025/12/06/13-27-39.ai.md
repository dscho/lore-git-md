Security patch introducing a secure `git_mkdtemp()` wrapper as part of the series eliminating insecure `mktemp(3)` usage. This first patch extends the existing `git_mkstemps_mode()` infrastructure to support both file and directory creation through a new internal `git_mkdstemps_mode()` function, which becomes the shared backend for both operations.

The implementation creates directories with secure 0700 permissions by default, matching Git's security model for temporary storage. The patch carefully documents the return value behavior (-1 for error, 0 for directory creation, file descriptor for regular files) to prevent misuse. The public interface exposes `git_mkdtemp()` through wrapper.h while maintaining backward compatibility with the existing `git_mkstemps_mode()` API.

This foundational change enables subsequent patches in the series to migrate callers away from insecure temp directory creation methods. The implementation shows attention to cross-platform considerations and security properties, with clean separation between the internal implementation and public interfaces. As the first in a reviewed series with clear security motivation, this appears to be a carefully constructed infrastructure change.
