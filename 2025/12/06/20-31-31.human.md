This is a refactoring patch in Taylor Blau's MIDX compaction series, introducing a helper function to safely access pack permutations during multi-pack index operations.

The patch adds a new `midx_pack_perm()` helper function that abstracts access to the `ctx->pack_perm` array, which maps pack IDs to their positions. This prepares for future changes where direct array access could become unsafe during MIDX compaction, when pack IDs from upper layers might exceed the array bounds. The helper will eventually implement bounds checking or index shifting, though that logic isn't added yet.

The change is purely mechanical at this stage - all existing callers are updated to use the new helper while maintaining identical behavior. This is part of the groundwork for safely compacting MIDX layers while preserving bitmap validity, a key goal of the larger series. The patch follows the series' pattern of careful, incremental refactoring with clear explanations of both current and future needs.
