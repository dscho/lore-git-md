This documentation patch series improves the `git replay` man page by addressing three specific gaps. The author, Kristoffer Haugsbakk, noticed these issues while using the command and submitted a well-formed 3-part series documenting: 1) the command's silent conflict resolution behavior (unlike other Git commands), 2) the previously undocumented `--contained` option, and 3) standardizing internal Asciidoc markup for better linking.

Junio Hamano, the Git maintainer, has reviewed the series and found it generally sensible. He noted that the slightly unclear phrasing about `--contained` option was inherited from the original implementation commit, confirming this is an accurate reflection of the feature rather than a documentation issue. With no substantial changes requested, the series appears ready for inclusion. This represents a straightforward documentation improvement that fills real gaps while maintaining consistency of Git's man pages.
