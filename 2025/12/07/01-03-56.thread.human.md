This thread discusses a documentation improvement for Git's bash completion script. The patch clarifies that while the script completes arguments for both long and short options (like `-c` followed by config variables), it only handles long option names themselves (like `--version`) and not their single-letter equivalents (like `-v`). 

The change updates a comment in `git-completion.bash` that dates back to 2007, making the script's limitations more explicit. The patch is small and focused, simply adjusting the documentation to match the actual behavior rather than modifying any functionality. The author provides clear rationale for the change, noting that the original wording could mislead readers about the script's capabilities.
