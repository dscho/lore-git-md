This is a documentation patch series (3 parts) improving the `git replay` man page. The main focus is clarifying behavior around merge conflicts, which currently produce no output - a potential point of confusion for users accustomed to more verbose conflict reporting from other Git commands.

The series also adds documentation for the `--contained` option and improves internal section linking within the man page. The changes are straightforward and focused solely on documentation, touching only the `git-replay.adoc` file.

The patches appear well-scoped and motivated by actual user experience (the author notes their own confusion about conflict output). This seems like a useful clarification for a relatively new command, though the changes are minor enough that they likely won't attract much discussion beyond routine review.
