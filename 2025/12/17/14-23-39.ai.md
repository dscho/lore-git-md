This is the foundational patch in Johannes Schindelin's v2 security series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). It introduces basic sanitization of control characters in Git's sideband channel, replacing them with caret notation (e.g., `^[` for ESC). The patch adds a new `strbuf_add_sanitized()` function that performs the core filtering, modifying both colorized and non-colorized output paths in `maybe_colorize_sideband()`. Test coverage verifies the sanitization blocks ANSI color sequences from remote hooks. The implementation takes a conservative approach initially, with follow-up patches promised to add granular controls via a new `sideband.allowControlCharacters` config. Phillip Wood is credited for contributions to the whitelist approach that will come in later patches. The security context is well-documented, citing CWE-150 and noting risks of terminal state corruption and hidden information. This forms the technical basis for the series' layered security model, though as subsequent discussion shows, SSH channel limitations remain an open concern.
