This is part 6/7 of Justin Tobler's series adding comprehensive object size reporting to `git repo structure`, specifically extending the keyvalue and nul output formats to include disk size metrics.

The patch adds disk size tracking alongside the existing inflated size metrics in the same style as previous additions to the series. It introduces a new `disk_sizes` field in the `object_stats` struct to store per-type disk usage, collects this data via `oi.disk_sizep` in `count_objects()`, and outputs it in the keyvalue/nul formats with new `objects.*.disk_size` keys. The implementation follows the established pattern from earlier patches in the series.

Key technical elements:
- New `disk_sizes` field in `object_stats` struct mirroring `inflated_sizes`
- Integration with `odb_read_object_info_extended()` to collect disk sizes
- Output formatting identical to existing size metrics
- Test updates verifying disk size output matches `git rev-list --disk-usage`

The patch maintains the series' consistent approach to metric collection and output, completing the disk size reporting functionality for the machine-readable formats. It builds on the existing test infrastructure while adding new verification using `git rev-list --disk-usage` as a cross-check. The changes are focused and well-contained, following the architectural patterns established earlier in the series.
