This is a test fix in the ongoing Windows symlink support preparation series.

Patch 6/10 in Johannes Schindelen's v4 series adjusts a test prerequisite in t0600-reffiles-backend.sh to properly account for Windows limitations. The test checks symref transaction support with symbolic links, which requires both the SYMLINKS prerequisite and now explicitly excludes MINGW (Windows) since Windows doesn't support the preferSymlinkRefs feature.

The change is straightforward - adding !MINGW to the test's prerequisites. The commit message thoroughly explains why this is needed and examines other test cases that set core.prefersymlinkrefs, noting they either set it to false (Windows-compatible) or don't actually verify symlink behavior. This patch also properly credits Patrick Steinhardt as a helper, correcting an earlier omission in v3.

This is part of the larger effort to prepare Git's test suite for MSYS2's planned default enablement of symlink support on Windows. The change is well-justified and maintains test coverage while properly handling platform limitations.
