This is a bugfix patch in a series preparing Git's test suite for Windows symlink support. It's the second of ten patches in v4 of Johannes Schindelen's series, which has already been accepted pending final verification.

The patch fixes an unintended side effect from commit 0482c32c334b ("apply: ignore working tree filemode") where the change to ignore executable bits on files also affected symbolic links and directories. The fix narrows the scope to only apply the special handling to regular files, which allows test t4115.5 (symlink escape tests) to pass on Windows when symlink support is enabled.

The change is minimal (a one-line conditional modification in apply.c) but important for correct behavior. The patch appears well-motivated and clearly explains both the problem and solution. This is part of the broader effort to make Git's test suite work properly with Windows symlinks in anticipation of MSYS2 enabling symlink support by default.
