This is patch 7/10 in a series preparing Git's test suite for Windows symlink support, specifically addressing MSYS2's upcoming default enablement of symlinks. The patch focuses on t1006-cat-file.sh, which currently fails when symlinks are enabled on Windows due to path normalization quirks in MSYS2/Cygwin.

The changes modify two test cases that verify symlink behavior with `git cat-file --batch-check --follow-symlinks`. The tests now account for how MSYS2 normalizes symlink targets containing ".." components into Win32 paths, which differs from Git's Unix-style path expectations. The patch conditionally skips some assertions on Windows and adjusts expected output to match the normalized paths.

This continues the series' pattern of making tests Windows-symlink-aware while maintaining identical behavior on other platforms. The changes are straightforward - adding platform-specific test branches rather than altering core behavior - and follow the established approach seen in earlier patches of the series. The commit message clearly explains the MSYS2 path normalization behavior that necessitates these test adjustments.
