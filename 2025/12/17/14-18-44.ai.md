This is patch 8/10 in Johannes Schindelin's series preparing Git's test suite for Windows symlink support, specifically addressing test failures that would occur when MSYS2 enables symlink support by default.

The patch modifies t1305-config-include.sh to skip two symlink-related tests on Windows (MINGW) platforms. These tests expect Git to match symbolic link paths when processing `gitdir:` conditional includes, but Git for Windows canonicalizes paths such that only the real directory path matches. The changes add `!MINGW` prerequisites to the affected tests: "conditional include, gitdir matching symlink" and its case-insensitive variant.

This continues the series' pattern of adapting tests to Windows' symlink behavior differences. The changes are straightforward - just adding platform-specific skip conditions - and maintain the existing test coverage on non-Windows platforms. The commit message clearly explains the Windows-specific behavior that necessitates these skips.

This patch follows the same approach seen earlier in the series (like patch 6/10's similar `!MINGW` prerequisite addition) and helps complete the test suite's compatibility with Windows' symlink handling ahead of MSYS2's planned symlink support enablement.
