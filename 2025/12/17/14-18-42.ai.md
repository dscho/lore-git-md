This is patch 6/10 in a series preparing Git's test suite for Windows symlink support, specifically addressing test prerequisites in t0600-reffiles-backend.sh.

The patch fixes an incomplete test prerequisite by adding `!MINGW` to a test case checking symref transactions with symlinks. The test was previously marked with just `SYMLINKS` but needs to be skipped on Windows since `core.prefersymlinkrefs` isn't supported there. The change is minimal - just adding the platform-specific prerequisite to one test case.

The commit message analyzes other instances where `core.prefersymlinkrefs` is set in the test suite, noting that this is the only case needing adaptation since other tests either explicitly set it to false (Windows-compatible) or don't verify symlink behavior. The message also mentions this is part of broader work to deprecate symrefs via symlinks, though that effort remains outside this patch's scope.

Key technical details:
- Modifies t0600-reffiles-backend.sh test case 'symref transaction supports symlinks'
- Adds `!MINGW` prerequisite alongside existing `SYMLINKS`
- Maintains all test behavior while properly excluding unsupported Windows cases
- Follows pattern of previous platform-specific test adjustments in the series

The patch is straightforward and aligns with the series' goal of making tests Windows-symlink-aware. It properly credits Patrick Steinhardt for assistance and maintains the series' focus on test suite compatibility.
