This is a refactoring patch in the Windows symlink support series, focusing on retry logic for file operations. It introduces a new helper function `retry_ask_yes_no()` to consolidate the retry-and-prompt behavior that was previously duplicated and inconsistent across `mingw_unlink()` and `mingw_rmdir()`.

The patch standardizes several behaviors: retry delays with increasing sleep intervals, proper `errno` preservation when operations fail, and consistent user prompting when files are locked. The new helper handles both the automatic retries and the fallback to interactive prompting when retries are exhausted. The changes make the code more maintainable while preserving all existing functionality.
