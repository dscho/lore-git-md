This is the v4 iteration of a 10-part platform compatibility series preparing Git's test suite for Windows symlink support, particularly for MSYS2's planned default enablement of symlink support. The series has been accepted by the maintainer pending final verification of credit attribution and patch completeness.

The v4 version restores Patrick Steinhardt's credit in patch 6/10 that was accidentally dropped during rebase in v3. The series continues to address test failures that would occur when MSYS2 enables symlink support by default, with fixes spanning multiple test scripts (t0001, t0301, t0600, t1006, t1305, t6423, t7800) and core changes in apply.c and mingw.c. Key technical adjustments include Windows-specific path handling, permission management, and symlink test prerequisites.

Notable fixes include:
- apply.c executable bit handling for symlinks
- mingw.c O_CREAT|O_EXCL behavior with symlinks
- t0600 test case now properly skips symlink tests on Windows
- t6423 adds Windows-specific handling for /dev/null symlinks
- t7800 accounts for MSYS path conversion quirks

The series also includes bonus fixes for long-standing Perl test issues. With the v4 attribution correction, this appears ready for final integration pending maintainer verification of patches 7-10 for any unintended omissions. The changes are well-documented with clear commit messages explaining the Windows-specific considerations.
