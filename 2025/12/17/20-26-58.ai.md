Performance regression report in the object streaming subsystem. Aaron Plattner identifies a severe slowdown (from 0.38s to 1508s) when committing in a repository with large promisor packs, tracing it to a logic error in the recently merged `ps/object-read-stream` series. The issue stems from `packfile_store_read_object_info()` incorrectly comparing a passed `object_info` struct against a local static variable rather than the caller's blank struct, causing unnecessary processing. This affects the interaction between `do_oid_object_info_extended()` and the new backend-specific object info functions. The report references Plattner's earlier work with promisor packs, suggesting the regression may be particularly noticeable in repositories using that feature. The change was part of Patrick Steinhardt's 20-commit series that restructured Git's object streaming interface to better support pluggable object databases, which Junio had recently merged to 'next'. This appears to be the first reported performance impact from that architectural change.
