This is a platform compatibility patch in the ongoing Windows symlink support series, specifically addressing permission requirements for symlink creation.

The patch enables Git to create symbolic links on Windows 10+ without requiring elevated administrator permissions, when Developer Mode is enabled. It does this by detecting Windows 10 Build 14972 or later and conditionally adding the `SYMBOLIC_LINK_FLAG_ALLOW_UNPRIVILEGED_CREATE` flag to symlink creation calls. The implementation is backward-compatible, falling back to the previous behavior on older Windows versions that don't support this flag.

The change affects both file and directory symlinks by introducing global flags that are set during startup. The patch maintains the series' careful approach to Windows compatibility, adding the new capability while preserving existing behavior on unsupported systems.
