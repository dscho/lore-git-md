Platform compatibility patch (part of Windows symlink support series) that enables non-elevated symlink creation on modern Windows versions. This is patch 16/18 in the ongoing effort to upstream comprehensive symlink support for Windows.

The patch adds support for Windows 10's `SYMBOLIC_LINK_FLAG_ALLOW_UNPRIVILEGED_CREATE` flag (value 0x02), which allows creating symlinks without administrator privileges when Developer Mode is enabled. The implementation carefully checks the Windows build number (>= 14972) before attempting to use this flag, since older versions would reject it with `ERROR_INVALID_PARAMETER`. The flag is applied to both file and directory symlink creation paths through new global variables `symlink_file_flags` and `symlink_directory_flags`.

Key technical details include: the new `adjust_symlink_flags()` initialization function that sets the flags at startup, integration with the existing symlink creation paths in `process_phantom_symlink()` and `symlink()`, and maintaining backward compatibility with older Windows versions. The change builds on previous infrastructure in the series while adding this Windows 10-specific optimization.

This represents an important usability improvement for Windows developers, removing the need for elevated privileges in common development scenarios. The implementation follows the series' pattern of careful Windows version detection and graceful fallback behavior. The patch maintains the series' focus on robust error handling and compatibility across Windows versions.
