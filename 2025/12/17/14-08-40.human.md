This is a refactoring patch in the Windows symlink support series, simplifying the MinGW compatibility layer's stat/lstat implementation.

Patch 3/18 in Karsten Blees's series eliminates the now-redundant `do_lstat()` helper function, folding its remaining logic directly into `mingw_lstat()`. The change is possible because the new `mingw_stat()` implementation (introduced in patch 2) handles the symlink-following case separately, leaving `do_lstat()` with only its non-following code path. The diff shows a clean removal of 20 lines while preserving the core symlink detection logic.

The patch carries sign-offs from both Karsten Blees and Johannes Schindelin, indicating it builds on prior Git for Windows work. As a pure code simplification with no behavior change, this seems like a straightforward improvement to the codebase. The change aligns with the series' broader goal of making Windows symlink handling more robust and maintainable.
