This is a test fix in the ongoing Windows symlink support preparation series. The patch addresses a test failure in t0001-init.sh where `test_cmp` (which uses `git diff --no-index` on Windows) doesn't handle symlink comparisons as expected. 

The issue occurs in the 're-init to move gitdir symlink' test, which compares the contents of a symlink file. On Windows, `git diff --no-index` shows the symlink target rather than resolving it, causing the comparison to fail. The fix adds special handling for the `--no-index` case by falling back to using `cmp` directly when that diff mode is detected, while keeping the original `test_cmp` behavior otherwise.
