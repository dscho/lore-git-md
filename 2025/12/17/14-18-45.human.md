Windows platform compatibility patch in a series preparing for symlink support. This is patch 9/10 in Johannes Schindelen's v4 series addressing test failures that would occur when MSYS2 enables symlink support by default.

The patch modifies test t6423 to properly handle symlinks to /dev/null on Windows, where the null device is called "NUL" rather than "/dev/null". The test would previously create a broken symlink on Windows, as it tried to link to a non-existent /dev/null file. The fix uses Windows' `mklink` command to create the symlink correctly pointing to NUL, while keeping the original `ln -s` behavior on non-Windows platforms.

The change also adds the missing SYMLINKS prerequisite that was overlooked in the test, though as noted this test still won't pass on Windows until symlink support is fully upstreamed from Git for Windows. This is part of the broader effort to make Git test suite work correctly when MSYS2 enables symlink support by default.

The patch follows the established pattern in this series of providing Windows-specific implementations for symlink-related operations while maintaining the original behavior on other platforms. It's a straightforward fix that addresses a clear platform-specific issue in the test suite.
