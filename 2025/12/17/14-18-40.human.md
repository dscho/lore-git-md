This is a test fix in a series preparing Git's test suite for Windows symlink support. The patch addresses a specific test failure in t0001-init.sh where `test_cmp` (which uses `git diff --no-index`) behaves unexpectedly with symlinks on Windows.

The test 're-init to move gitdir symlink' compares the contents of a symlink file, but `git diff --no-index` shows the symlink target rather than resolving it, causing the test to fail. The fix modifies the test to use `cmp` instead of `test_cmp` when running in `--no-index` mode (the Windows default), while keeping the original behavior on other platforms.

This is patch 4/10 in Johannes Schindelen's v4 series, which has already been accepted pending final verification. The change is straightforward and well-explained, with Junio Hamano credited as co-author. It's a good example of the kind of platform-specific test adjustments needed as Windows improves its symlink support.
