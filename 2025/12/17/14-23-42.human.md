This is the final patch in a security-focused series addressing ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005). It expands the `sideband.allowControlCharacters` configuration to optionally permit cursor movement and character-erasure sequences, which were previously blocked due to security concerns but have legitimate use cases in some server hooks.

The patch introduces two new flags (`ALLOW_ANSI_CURSOR_MOVEMENTS` and `ALLOW_ANSI_ERASE`) that can be enabled via comma-separated values in the config option. The implementation carefully validates sequences against documented ANSI standards, with comprehensive test coverage showing both the blocking of dangerous sequences by default and their allowance when explicitly configured.

This represents a balanced approach to security remains the default (blocking potentially dangerous sequences), while giving advanced users fine-grained control when needed. The changes build on the series' earlier work that established core sanitization infrastructure, now extending it to handle these additional sequence types with the same rigor applied to color sequences in previous patches.
