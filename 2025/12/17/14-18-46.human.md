This is the final patch in Johannes Schindelen's 10-part series preparing Git's test suite for Windows symlink support. The patch focuses on `t7800-difftool.sh`, addressing a test that makes Unix-specific assumptions about path formats.

The test currently assumes all absolute paths start with forward slashes, which isn't true on Windows. While the test is currently skipped on Windows due to the `SYMLINK` prerequisite, this will change when Windows symlink support is enabled. The patch modifies the test to instead filter paths by looking for lines ending with colons (a more reliable indicator in `ls` output) rather than checking for leading slashes.

This change follows the pattern seen throughout the series of making tests work correctly when symlinks are enabled on Windows. The modification is straightforward - replacing four instances of `grep -v ^/` with `grep -v ":\$"` in the test script. The patch maintains the same test coverage while being more portable across platforms.

As with the rest of the series, this change is well-motivated and clearly explained, continuing the careful preparation for upcoming Windows symlink support. The patch appears ready for inclusion, completing the comprehensive test suite updates in this series.
