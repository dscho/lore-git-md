- Handles the POSIX `readlink()` API quirks - partial buffer fills are allowed (not an error) and the function returns the number of bytes copied
- Maintains the series' pattern of direct Win32 API usage rather than relying on CRT functions
- Respects the `core.symlinks=false` configuration by continuing to return ENOSYS when symlinks are disabled

It follows the series' established approach of careful UTF-8/WCHAR conversions and proper error handling.
