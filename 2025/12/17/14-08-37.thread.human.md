This thread concludes a major effort to bring comprehensive symbolic link support to Git on Windows, now ready for merging after five iterations and extensive review. The 18-patch series, primarily authored by Karsten Blees with contributions from Johannes Schindelin (Dscho) and Johannes Sixt (Hannes), implements full POSIX-like symlink operations in Git's MinGW compatibility layer. It covers everything from creation and reading to directory handling and edge cases, building on years of development in Git for Windows.

The technical work is complete, with the final patch addressing an index corruption edge case from Git for Windows 2.27.0. The last administrative loose end - Karsten Blees' bouncing email address - has now been resolved with his confirmation that his new email (karsten.blees@gmail.com) should be used for attribution. The series touches core Windows compatibility code in `compat/mingw*` and `read-cache.c`, introducing robust symlink support including non-elevated creation on modern Windows. Maintainer Junio Hamano has reviewed and approved the series for integration, marking the culmination of this long-running effort to properly support symlinks on Windows.
