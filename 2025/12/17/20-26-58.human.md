Performance regression report in the object streaming subsystem. Aaron Plattner identifies a severe slowdown (from 0.38s to 1508s) when committing in a repository with large promisor packs, tracing it to a pointer comparison issue in `packfile_store_read_object_info()`. The problem occurs when comparing a caller-provided `object_info` struct against a local static variable - the comparison always fails, causing unnecessary work. This appears to be an unintended consequence of Patrick Steinhardt's recent object streaming refactoring series that moved streaming logic into the object database backend. The report provides clear technical details pinpointing the likely cause, suggesting this warrants immediate attention given the magnitude of the performance impact. No patch is included - this is a bug report that will likely prompt follow-up discussion or fixes from the streaming subsystem maintainers.
