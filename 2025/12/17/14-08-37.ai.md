This is a major platform compatibility patch series introducing symbolic link support for Windows, building on Git for Windows' long-running symlink implementation. The 18-part series (with contributions from Bill Zissimopoulos, Johannes Schindelin, and Karsten Blees) aims to upstream Windows symlink support that has been maturing since 2015.

The series makes comprehensive changes to the MinGW compatibility layer, touching core symlink operations like creation, reading, stat'ing, and directory handling. Key technical components include: implementing `stat()`/`lstat()` with proper symlink support, adding `readlink()` functionality, handling directory symlinks in `unlink()` and `chdir()`, and introducing symlink-specific error codes. The default `core.symlinks` setting is changed to false for Windows.

The changes span multiple subsystems - primarily the MinGW compatibility layer (`compat/mingw*`), with some index handling in `read-cache.c`. Notable behaviors introduced include: emulating POSIX `stat()` more faithfully, special-casing buggy symlink size reporting, and adding retry logic for Windows API calls. The implementation appears thorough, with 14 patches from Karsten Blees focusing on the core symlink operations and edge cases.

This represents a significant step in Windows compatibility, though the default `core.symlinks=false` suggests the feature may still need to mature further in the wild. The series builds on previous work (`js/prep-symlink-windows`) and appears to be the culmination of nearly a decade of development in Git for Windows.
