New workflow proposal: "rebaser-flow" by Milos Markovic introduces a DevOps-oriented branch prioritization model where production branches take precedence over QA and development branches, reversing typical developer-centric workflows. Currently conceptual (not a patch submission), with reference implementation at https://github.com/k4hvd1/rebaser-flow. Author reports successful production use but provides no metrics. Proposal seeks discussion on potential Git feature integration, particularly around branch operations and CI/CD workflows. Open questions include concrete implementation requirements and how this differs from existing Git branching models.
