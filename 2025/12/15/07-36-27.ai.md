This is a refactoring patch in Patrick Steinhardt's ongoing series to move packfile handling from object database (ODB) to ODB source level. The patch simplifies the kept-pack lookup code by inlining `find_kept_pack_entry()` into its sole caller `has_object_kept_pack()`, then making the combined function file-local by removing its declaration from packfile.h.

The changes eliminate an unnecessary layer of indirection in the packfile API while maintaining identical behavior. The patch follows the series' pattern of streamlining interfaces as part of the larger architectural shift toward source-level packfile management. The diff shows 24 lines removed (mostly from eliminating the separate function and its header declaration) versus 10 lines added in the consolidated implementation.

This mechanical change is low-risk since it doesn't modify the actual pack lookup logic - it just reorganizes where that logic lives. The patch continues the series' focus on cleaning up the packfile storage implementation in preparation for pluggable ODBs, with no functional impact on callers. The removal of the public API declaration from packfile.h is safe since no external callers exist (confirmed by the inlining).
