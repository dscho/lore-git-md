This is a refactoring patch that is part of Justin Tobler's v3 series extending Git's `repo structure` command with comprehensive object size reporting. The patch introduces a new `object_values` struct to group per-type object counts (tags, commits, trees, blobs) that were previously direct members of `object_stats`. 

The change is preparatory for adding new per-type measurements (object sizes) in subsequent patches. The patch updates all references to the moved fields, including:
- Renaming `get_total_object_count()` to `get_total_object_values()`
- Updating the stats table formatting code
- Modifying the key-value output printing
- Adjusting the object counting callback

The refactoring maintains all existing functionality while making the codebase more extensible for the planned size reporting features. The changes are mechanical and focused, touching only `builtin/repo.c` with straightforward field access updates. This foundational change has already been reviewed in previous iterations of the series and appears ready for inclusion.
