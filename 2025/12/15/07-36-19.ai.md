This is a cover letter for a 10-patch series that refactors Git's packfile storage to be tracked per object database (ODB) source rather than per ODB. The series is part of the ongoing effort to enable pluggable object databases.

The key change moves packfile tracking from the ODB level to individual ODB sources, meaning each source (like main repo, alternates, etc.) will manage its own packfiles. This completes the architectural groundwork for pluggable ODBs by ensuring all object access - whether from packs or loose objects - goes through its owning source. The author notes this is still a leaky abstraction that will need further work.

The series builds on two other recent topics (object read streaming improvements and ODB fixes) and touches 13 files with significant changes to packfile handling. The changes include restructuring packfile stores, refactoring pack entry lookup, and moving MIDX handling into the packfile store. The implementation appears thorough with careful attention to maintaining existing behavior while enabling the new architecture.
