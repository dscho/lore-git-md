Refactoring patch in the ongoing ODB abstraction series. This is patch 3/10 in Patrick Steinhardt's series to move packfile handling from object database (ODB) level to ODB source level.

Justin Tobler reviews the patch that refactors the kept-pack cache to work with packfile stores. The change makes the cache interface go through packfile stores rather than repositories, aligning with the series' architectural direction. The patch also introduces an enum for kept pack types (on-disk vs in-core) while updating the accessor function name and signature.

Justin notes the changes look correct but suggests two minor improvements: explicitly mentioning the enum introduction in the commit message, and updating outdated comments in packfile.h that reference the old function name. The review is positive overall, confirming the changes support the series' goals while making the code more straightforward.
