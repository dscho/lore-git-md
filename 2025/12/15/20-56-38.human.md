Feature extension to Git's `repo structure` command, part of a series adding comprehensive object size reporting. This patch (6/7 in v3 series) adds disk size information to the machine-readable keyvalue and nul output formats, complementing the existing inflated size reporting. The changes include:

The patch extends the `object_stats` struct to track disk sizes per object type (commits, trees, blobs, tags) alongside the existing counts and inflated sizes. The disk sizes are collected using `oi.disk_sizep` during object iteration, similar to how inflated sizes are gathered. The keyvalue output format now includes new fields like `objects.commits.disk_size` with the same delimiter-based structure as other fields.

Tests are updated to verify the new disk size reporting by comparing against `git rev-list --disk-usage` output. The documentation is also updated to mention disk size reporting as a supported feature. This builds on previous work in the series that established the basic structure reporting framework and human-readable table output.

The implementation looks clean and consistent with the existing code, with proper type handling and test coverage. This completes the machine-readable side of the disk size reporting feature that was previously only available in the human-readable table format. The patch follows the established patterns from earlier in the series for both the data collection and output formatting.
