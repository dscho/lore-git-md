This thread documents an edge case in `git rev-list --filter` behavior where explicitly provided objects bypass filters by default unless `--filter-provided-objects` is specified. Justin Tobler's patch clarifies this in the documentation, which Junio Hamano has queued while noting the design is less than ideal.

Patrick Steinhardt, who originally implemented the current behavior, confirms the documentation is accurate and explains the design choice was made for backward compatibility rather than being an intentional feature. While both maintainers agree the current behavior is surprising, there's consensus that changing it now could break existing scripts. The thread provides useful historical context about this quirk while concluding the documentation patch properly captures the status quo. No behavior changes are proposed at this time.
