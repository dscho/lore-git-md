This is the second patch in Patrick Steinhardt's 10-part series refactoring packfile storage to track objects per source rather than per object database (ODB). The change is part of the ongoing ODB abstraction effort.

The patch simplifies how packfiles are prepared by passing the ODB source directly to `prepare_pack()` rather than passing individual components (repository, MIDX, local flag) separately. This reduces parameter passing and prepares for future changes where pack preparation will be source-based. The diff shows the structural change to `prepare_pack_data` and updates all related function calls to use the source's fields directly.

This is a straightforward refactoring that maintains existing behavior while cleaning up the interface. It follows logically from the first patch's changes to packfile store initialization and continues the series' architectural improvements. The change is well-contained (affecting only packfile.c) and appears mechanically sound, with no obvious issues in the diff.
