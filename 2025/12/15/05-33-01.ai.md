This is a follow-up discussion about test strategy in Justin Tobler's patch series to add disk size reporting to Git's `repo structure` command. Patrick Steinhardt points out that the test could verify disk sizes by using `git rev-list --disk-usage` with type filters, addressing Justin's concern about user-specified objects being included by default. Patrick notes this behavior is intentional but can be avoided using the `--filter-provided-objects` option he previously added in commit 9cf68b27d5.

The exchange reveals an important technical detail about `git rev-list`'s filtering behavior - while type filters normally omit non-matching objects, user-specified objects (like HEAD) are always included unless explicitly suppressed. This affects how disk usage calculations should be verified in the test suite. Patrick's response provides both the solution (`--filter-provided-objects`) and context about why this behavior exists, referencing his own prior work on the feature.

This discussion helps refine the test approach for the series while also documenting an important edge case in `rev-list`'s filtering behavior that could affect other developers working with object filtering.
