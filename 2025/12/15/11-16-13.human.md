This is Junio Hamano's regular "What's cooking in git.git" status update, providing a comprehensive overview of the current state of Git development. The email lists patches and topics that have been merged, are newly proposed, or are still under review.

Several documentation fixes and minor improvements have graduated to 'master', including typo fixes in man pages and updates to suggest using `git help` instead of `man`. Performance optimizations have also landed, like memory usage improvements in `git diff --find-copies-harder` and fixes for the `last-modified` command.

New topics under review include:
- A significant refactoring of the packfile store to move it into the ODB source (12 commits)
- MIDX/bitmap improvements for incremental repacking (17 commits)
- Windows symlink support in the test suite (10 commits)
- A new `git history` command for history rewriting (13 commits)
- Submodule path handling improvements to avoid collisions (10 commits)
- Various documentation updates and test fixes

The email also notes several topics that are expected to be rerolled or are on hold pending stabilization of dependent changes. As usual, Junio provides clear status indicators for each topic (merged to next/master, expecting reroll, comments requested, etc.) along with links to discussion threads.

This update shows active development across many areas of Git, with particular focus on performance, object storage internals, and submodule handling. The thorough categorization and status tracking helps maintainers and contributors stay informed about the project's progress.
