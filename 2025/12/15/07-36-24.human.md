This is part 5 of Patrick Steinhardt's 10-patch series refactoring Git's packfile storage to work per object source rather than per object database (ODB), continuing the ODB abstraction effort. The patch moves the packfile store from `struct object_database` to `struct odb_source`, since each source (main repo or alternate) has its own set of packfiles.

The change makes conceptual sense as packfiles are inherently source-specific, not database-wide. The implementation updates various packfile operations across 11 files to work with source-owned stores instead of ODB-owned ones. Notably, most callers don't need changes since they use high-level iteration functions like `repo_for_each_pack()`.

The patch is well-contained and mechanical, following the series' architectural direction. It leaves some functions that operate across all sources to be adjusted in later patches, as noted in the commit message. The changes appear thorough and maintain existing behavior while better aligning the code with the conceptual model of packfile ownership.
