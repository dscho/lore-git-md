This is the third patch in Patrick Steinhardt's 10-part series refactoring Git's packfile storage to work per object database (ODB) source rather than per ODB. The series is part of the ongoing ODB abstraction effort.

The patch refactors the kept-pack cache, which tracks packfiles marked as kept (either via ".kept" files or in-memory flags). Previously this cache was repository-scoped, but the changes move it to work with packfile stores instead, preparing for future work where packfile stores will be per-ODB-source entities. 

Key changes include:
- Renaming `kept_pack_cache()` to `packfile_store_get_kept_pack_cache()`
- Moving cache management into the packfile store structure
- Renaming flag constants (`ON_DISK_KEEP_PACKS` -> `KEPT_PACK_ON_DISK`, etc.)
- Updating all callers to use the new interface

The patch touches core packfile handling code across 5 files, with mechanical changes to update function signatures and call sites. Like previous patches in the series, this appears to be a straightforward refactoring that maintains existing behavior while moving toward the architectural goal of per-source packfile stores. The changes are well-contained and follow the established pattern from earlier patches.
