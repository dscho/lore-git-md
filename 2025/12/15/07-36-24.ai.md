Refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series, moving packfile store ownership from object database to individual sources. This is patch 5/10 in the series.

The change relocates the packfile store from `struct object_database` to `struct odb_source`, better matching the conceptual model where each source (main repo or alternate) manages its own packfiles independently. The patch updates all direct packfile store accessors to iterate through sources, though most high-level operations continue working via `repo_for_each_pack()` which already handles multi-source iteration.

Key technical changes:
- Adds `packfiles` field to `struct odb_source`
- Removes `packfiles` from `struct object_database`
- Updates packfile operations in fast-import, grep, index-pack, pack-objects, http, midx, odb, and streaming code to work with per-source stores
- Introduces new `repo_for_each_pack_data` helper to maintain iteration across sources
- Preserves existing behavior while changing underlying implementation

The patch touches 11 files with 243 insertions and 145 deletions, primarily mechanical updates to the new source-based access pattern. As noted in the commit message, some functions still operate across all sources and will be addressed in later patches. This continues the series' pattern of well-contained, behavior-preserving refactors toward the pluggable ODB architecture.
