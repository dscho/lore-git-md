This is a technical refinement to Justin Tobler's patch series adding disk size reporting to Git's `repo structure` command. Patrick Steinhardt suggests an optimization to the test helper function in patch 6/7, proposing to replace the current `git cat-file` pipeline with `git rev-list --disk-usage` to simplify the disk size calculation.

The current implementation uses `git cat-file --batch-check` with awk to sum object sizes, while Patrick's suggestion would let `rev-list` handle both the filtering and summation in a single command. This builds on Patrick's earlier contributions to the thread where he identified subtle behavior in `rev-list`'s filtering (objects provided on command line bypass type filters unless `--filter-provided-objects` is used).

The change appears straightforward and aligns with the series' focus on robust testing - the test helper is used to verify the accuracy of the new disk size reporting feature. This follows the pattern of iterative improvements seen throughout the thread, where multiple contributors have refined both implementation and verification approaches. The suggestion doesn't require changes to the core functionality being added, just a more efficient way to test it.
