This is part 7 of Patrick Steinhardt's ongoing refactoring series to move packfile storage from object database (ODB) level to ODB source level, continuing the groundwork for pluggable ODBs. The patch simplifies `packfile_store_prepare()` to only operate on its single packfile store argument rather than preparing all stores in the ODB, now that stores are source-owned.

The changes remove redundant preparation of alternate sources that was needed when stores were ODB-level but is now unnecessary. The main logic changes are:
- `packfile_store_prepare()` now only calls `prepare_multi_pack_index_one()` and `prepare_packed_git_one()` for its specific store
- Callers in `builtin/grep.c` and `packfile.c` are updated to explicitly iterate over sources when needed
- The diff shows 13 lines added and 20 removed across two files

This continues the series' mechanical refactoring pattern - each patch moves functionality to the proper architectural level while maintaining behavior. The changes are straightforward and focused, with grep and pack lookup paths being the main affected areas.
