This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the state of various patch series in the Git development pipeline as of December 2025. The email organizes topics into three main categories: those that have graduated to 'master', new topics being proposed, and ongoing work still in progress.

Several documentation fixes and minor improvements have recently been merged to master, including corrections to the Git data model documentation, a `git-pull` typo fix, and sparse checkout support for `git last-modified`. The `git branch` command now suggests using `git help` rather than `man` for documentation. A memory optimization for `git diff --find-copies-harder` and fixes for cross-compilation with meson were also merged.

New topics proposed for inclusion include a cleanup of pull options declaration, further application of the MEMZERO_ARRAY macro, and a test fix for Git version strings with spaces. A significant refactoring moves the packfile_store data structure from object store to odb source, while another fixes copy detection in `git diff-files -R`.

Ongoing work includes more object database information in `git repo structure`, C99 flexible array requirement standardization, macOS iconv workarounds, and incremental MIDX repacking improvements. The test suite is being prepared for better Windows symlink support, and there's ongoing refactoring of the object streaming interface. Several documentation updates and bugfixes are also in progress across various areas of Git.

The email follows Junio's standard format, noting which branches each topic is based on or used by, and indicating whether topics are expected to be rerolled or are ready for merging. It provides a comprehensive overview of the current state of Git development, with many small improvements and some larger refactorings in flight.
