Patrick Steinhardt has sent the second version of his 10-patch series refactoring Git's packfile storage as part of the ongoing ODB abstraction effort. The changes systematically move packfile handling from the object database (ODB) level to the source level (main repository and alternates), completing foundational work needed for pluggable ODB backends. 

Justin Tobler has reviewed most of the patches (1-6 and 8) in previous iterations, providing positive feedback on the architectural approach while identifying some transitional edge cases in fast-import, index-pack, and http.c that will need future resolution. The series makes mechanical changes across 30+ files to ensure all object access routes through owning sources, with key technical changes including moving the packfile store pointer from ODB to source structures, updating related functions to take source parameters, and reorganizing the kept-pack cache interface.

This version includes minor fixes to comments and commit messages based on feedback from v1. The changes preserve existing behavior while positioning the codebase for the next phase of the ODB abstraction work, though some implementation details still need to be addressed in future patches. The series builds on Patrick's work on object read streams and ODB fixes, representing the last preparatory step before implementing actual pluggable ODB interfaces.
