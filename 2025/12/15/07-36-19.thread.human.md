Patrick Steinhardt's 10-patch series refactoring Git's packfile storage to track packs per object database (ODB) source has now been completed. The changes enable pluggable ODB backends by ensuring all object access routes through owning sources (main repository or alternates), with the final patch moving MIDX (multi-pack index) tracking to packfile stores. The series received thorough review from Justin Tobler and Toon Claes, with Toon recently acknowledging he had initially missed the architectural intent of patch 7/10's simplification of packfile store preparation. The changes establish a clear model where each ODB source manages its own packfiles independently, touching 30+ files while maintaining identical object lookup behavior. This foundational work paves the way for future pluggable storage backends in Git.
