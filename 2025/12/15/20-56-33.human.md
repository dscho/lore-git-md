This is a refactoring patch that's part of Justin Tobler's series extending Git's `repo structure` command with object size reporting. As the first patch in v3 of the series, it reorganizes the code to prepare for upcoming additions.

The change introduces a new `object_values` struct to group the per-type object counts (tags, commits, trees, blobs) that were previously direct members of `object_stats`. This creates a cleaner separation that will make it easier to add new per-type measurements (like object sizes) in subsequent patches. The patch updates all the related counting and display code to work with the new structure.

The changes are mechanical but thorough - every reference to the old direct fields has been updated to go through the new `type_counts` member. The patch maintains all existing functionality while setting up for the series' goal of adding both inflated content sizes and on-disk storage size reporting.

This appears to be a well-executed preparatory change that follows the pattern of the series' incremental development approach. The commit message clearly explains the change's purpose in context of the larger work.
