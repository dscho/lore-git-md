Feature completion for Git's object size reporting. This is the final patch in Justin Tobler's series that adds disk size information to the `git repo structure` command's human-readable table output, matching the machine-readable formats added earlier in the series.

The patch extends the structured table view to show both the total disk usage and per-object-type breakdowns (commits, trees, blobs, tags) alongside the existing inflated size information. The implementation uses the same `stats_table_size_addf()` helper introduced earlier for consistent formatting, with proper i18n support and binary (1024-based) unit display.

Test coverage is expanded to verify the new disk size columns, using `git rev-list --disk-usage` as the reference implementation. The test helper `object_type_disk_usage()` is enhanced to support both raw and human-readable output modes. SHA1-specific test expectations are included for the known sizes of test repository objects.

This completes the series' goal of providing comprehensive object size reporting in both machine and human-readable formats. The implementation appears solid, with careful attention to the table formatting details and thorough test coverage that exercises both empty and populated cases. The patch follows the established patterns from earlier in the series, maintaining consistency in the output structure and unit presentation.
