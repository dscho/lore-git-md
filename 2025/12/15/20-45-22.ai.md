Build system refactoring targeting Darwin/macOS platform support. This is part 2 of a 3-patch series (no cover letter seen yet).

The patch moves all Darwin-specific build configuration from the main Makefile to config.mak.uname, where platform-specific settings belong. The changes include:
- Fink package manager paths (/sw/include, /sw/lib)
- MacPorts paths (/opt/local/include, /opt/local/lib)
- Apple Common Crypto configuration (disabling OpenSSL)
- Pthread library handling
- CoreServices framework linkage

The commit message states this relocation is needed for a subsequent change, though doesn't specify what that change will be. The diff shows a straightforward cut-and-paste operation with no functional changes - all the same conditions and variables are preserved, just moved to a more appropriate file.

This appears to be a clean, mechanical refactoring that improves the build system organization by consolidating platform-specific logic. The patch follows the existing pattern seen for other platforms in config.mak.uname. Since this is part of a series, the motivation may become clearer in the next patch.
