Refactoring patch for Git's packfile storage as part of the ODB abstraction effort.

This first patch in a 10-part series begins restructuring how Git tracks packfiles by moving ownership from object databases (ODBs) to individual ODB sources (main repo, alternates). The change modifies `packfile_store_new()` to be initialized via an ODB source rather than directly through an ODB, creating a transitional state where stores are still owned by ODBs but created via sources.

The patch updates function signatures and call sites across packfile.c and odb.c, changing references from `store->odb` to `store->source->odb`. While this creates temporary architectural inconsistency (acknowledged in the commit message), it enables subsequent patches to complete the transition to per-source packfile stores. The changes are mechanical but touch core object storage paths, maintaining existing behavior while preparing for future pluggable ODB work.
