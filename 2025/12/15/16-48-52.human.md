This is a brief technical follow-up in Justin Tobler's series extending Git's `repo structure` command with object size reporting. The email addresses Patrick Steinhardt's feedback about flag usage in the object size collection code.

Patrick noted that using `OBJECT_INFO_FOR_PREFETCH` was semantically incorrect for this context (since no prefetching is happening) and suggested replacing it with the more appropriate `SKIP_FETCH_OBJECT | INFO_QUICK` flags. Justin acknowledges the point and confirms the change will be made in the next version.

This is a small but meaningful refinement to the series' implementation, showing the careful attention being paid to proper API usage. The change doesn't affect functionality but ensures the code better matches its intended purpose and will be more future-proof against potential changes to the prefetch flag's semantics.
