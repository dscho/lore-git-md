This is a technical discussion about testing strategies for Git's object size reporting in the `repo structure` command. Patrick Steinhardt responds to Justin Tobler's concerns about using `git rev-list --disk-usage` for verifying object sizes in tests.

Patrick clarifies that there is indeed a way to exclude user-specified objects from `git rev-list` output when using filters - the `--filter-provided-objects` option he introduced in commit 9cf68b27d5. This addresses Justin's concern that filtered disk usage measurements might be inflated by including the HEAD reference object regardless of filter type.

The exchange reveals an interesting edge case in Git's filtering behavior where user-provided objects are normally included even when they don't match the type filter, unless explicitly excluded with this option. Patrick confirms this behavior is intentional but notes it has caused confusion before, which motivated his addition of the exclusion flag.

This discussion helps refine the test strategy for Justin's patch series that reports both inflated and on-disk object sizes. The thread shows careful attention to ensuring accurate test verification across different Git commands and output formats.
