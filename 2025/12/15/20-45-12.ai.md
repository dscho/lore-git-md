This is a platform compatibility patch series targeting macOS iconv behavior, building on an existing workaround branch (rs/macos-iconv-workaround). The series consists of 3 preparatory patches to handle iconv issues specifically in macOS 14/15 environments.

The first patch modifies utf8.c to implement a workaround for iconv behavior under newer macOS versions, adding a new ICONV_RESTART_RESET flag. The second patch relocates Darwin-specific Makefile configurations into config.mak.uname for better organization. The third patch activates the new ICONV_RESTART_RESET setting in config.mak.uname when building on affected macOS versions.

The changes appear focused and technically sound, though marked as RFC (Request For Comments) indicating the author is seeking feedback before finalizing. The patch series is relatively small (3 patches touching 3 files) and builds upon existing work, suggesting it's a targeted fix rather than a major architectural change. The author has tested on macOS 15 specifically, which lends credibility to the proposed solution.

Key technical details for future reference: the workaround involves ICONV_RESTART_RESET handling in utf8.c, Darwin-specific build configuration consolidation, and conditional activation based on macOS version detection.
