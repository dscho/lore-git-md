This is a platform compatibility patch for macOS systems. Torsten Bögershausen addresses an issue with character encoding conversion when Git is built against the system iconv library on macOS versions 14 and 15. The patch adds a `-DICONV_RESTART_RESET` compiler flag in these cases, which is needed for proper utf8 handling but not required when using third-party iconv implementations from Homebrew, MacPorts, or Fink.

The change modifies `config.mak.uname` to detect when the system iconv is being used (by checking for the absence of third-party iconv installations) and applies the flag only on macOS 20.x and later (which corresponds to the public macOS 14/15 versions). The implementation is careful to avoid the flag when better-maintained iconv alternatives are present.

This appears to be a well-motivated change that follows existing patterns in the build system, though it might benefit from a test case demonstrating the iconv behavior difference. The patch is the third in a series (v0 3/3), but no cover letter or context about the other patches is provided in this email.
