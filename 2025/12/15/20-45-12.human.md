This is a platform compatibility patch series addressing iconv issues on macOS 14/15, building on previous work by rs/macos-iconv-workaround. Torsten Bögershausen submits this as an RFC (Request For Comments) with three patches that:

1. Adds preparatory code in utf8.c for handling macOS 14/15's iconv behavior
2. Consolidates Darwin/MacOS-specific Makefile settings into config.mak.uname
3. Automatically activates ICONV_RESTART_RESET when needed on affected macOS versions

The changes appear focused and technically sound, though as an RFC they're explicitly open to feedback. The patch series touches core character encoding handling (utf8.c) and build system configuration, so it would primarily interest macOS users and developers working on cross-platform compatibility. The dependency on rs/macos-iconv-workaround suggests this is part of an ongoing effort to address macOS-specific quirks in Git's character conversion handling.
