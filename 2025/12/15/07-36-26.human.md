Refactoring patch in Patrick Steinhardt's ongoing series to move packfile handling to the ODB source level. This is patch 7/10 in the effort to prepare for pluggable object databases.

The change simplifies `packfile_store_prepare()` to only initialize the single packfile store passed to it, rather than preparing all stores in the object database. This aligns with the series' architectural direction where packfile stores are now owned by individual ODB sources rather than the ODB itself. The patch updates callers in `builtin/grep.c` and `packfile.c` to explicitly iterate over sources when needed.

The changes are mechanical and maintain existing behavior while cleaning up the temporary workaround noted in previous commits. The diff shows straightforward adjustments to the preparation logic, removing redundant loops now that each source manages its own packfile store. This continues the series' pattern of moving functionality to the source level while keeping the same external behavior.
