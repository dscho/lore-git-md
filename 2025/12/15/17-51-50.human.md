This is a build system patch addressing Rust compilation on macOS. The thread has already identified and agreed upon a solution to replace GNU sed's `-s` flag with the more portable `-n` and `p` combination when parsing `cargo -vV` output, which currently breaks on macOS's BSD sed.

Eric Sunshine confirms the technical solution works but declines to implement it due to time constraints, leaving the door open for D. Ben Knoble (the original reporter) to submit the patch. The change is straightforward and uncontroversial, merely swapping sed flags while maintaining identical functionality.

The issue stems from commit e509b5b8be, which introduced Windows Rust support but inadvertently made the build system depend on GNU sed. The fix will unblock Rust-enabled builds on macOS without affecting other platforms.

All technical discussion appears settled, with only implementation remaining. Given the simplicity of the clear consensus, this should be a quick resolution to the issue once someone submits the patch.
