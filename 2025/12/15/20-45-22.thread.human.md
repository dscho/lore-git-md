This thread is about refactoring Git's build system to better organize platform-specific configuration, with a focus on Darwin/macOS support. The first patch (not seen here) presumably set up the context, while this second patch moves all Darwin-specific build settings from the main Makefile to the dedicated config.mak.uname file where they belong. The changes are purely organizational - Fink and MacPorts paths, Apple crypto configuration, threading, and framework linkage are all preserved but relocated to be alongside similar settings for other platforms.

The author notes this is preparation for some follow-up work, though doesn't specify what that will be. Given the mechanical nature of the changes and the established pattern being followed (config.mak.uname already handles Linux, Windows, and other platforms this way), this appears to be a straightforward improvement to the build system's structure. The third patch in the series will likely reveal the larger purpose behind this reorganization.
