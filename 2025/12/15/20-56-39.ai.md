This is the final patch in Justin Tobler's series extending Git's `repo structure` command with object size reporting. The patch completes the human-readable table output format by adding disk size information alongside the previously implemented inflated size reporting.

The key technical additions in this patch are:
- Adds a new "Disk size" section to the human-readable table output, mirroring the structure of the existing "Inflated size" section
- Extends the `stats_table_setup_structure()` function to populate disk size values from the `disk_sizes` field of the `object_stats` struct
- Updates the test script to verify disk size reporting by:
  - Adding a helper function `object_type_disk_usage()` that supports both raw and human-readable output formats
  - Extending test expectations to include disk size assertions
  - Using `git rev-list --disk-usage` with `--filter-provided-objects` for verification

The implementation maintains consistency with the series' established patterns:
- Uses the same table formatting infrastructure (`stats_table_size_addf()`)
- Follows the same hierarchical display structure (total size followed by per-type breakdown)
- Preserves i18n support through gettext wrappers
- Includes both empty repository and populated repository test cases

This completes the human-readable output portion of the size reporting feature, complementing the machine-readable formats added in earlier patches. The test updates demonstrate the disk size reporting works alongside the existing inflated size reporting, with proper formatting of both raw and human-readable values.
