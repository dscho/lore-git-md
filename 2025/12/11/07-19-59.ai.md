This is a bugfix addressing a memory leak in submodule handling during `git-grep` operations. The patch corrects the cleanup sequence in `odb_free()` by ensuring sources are properly closed before being freed.

The issue occurs when reading from submodules: `repo_clear()` triggers `odb_free()`, which was incorrectly freeing sources before closing them via `odb_free_sources()` followed by `odb_close()`. This left some resources unclosed, causing a 192-byte leak per submodule access. The fix simply reorders these operations to close sources first.
