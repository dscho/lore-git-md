This is patch 5/8 in Patrick Steinhardt's series refactoring Git's object database alternates handling as part of the ODB abstraction effort. The patch focuses on simplifying the recursive handling of alternate object databases.

The key change removes mutual recursion between `link_alt_odb_entries()` and `parse_alternates()`, which previously made the code harder to follow. Now, `odb_add_alternate_recursively()` handles all recursion directly, while `parse_alternates()` becomes a simpler helper that just processes the alternates file contents. This makes the control flow more linear and better separates concerns.

The patch is a logical continuation of the series' goal to clean up alternates handling before moving to source-based operations. It touches the same core `odb.c` file as previous patches, with 27 lines added and 33 removed. The changes appear focused and well-contained, maintaining all existing functionality while improving the code structure.

This is a technical refactoring that doesn't change user-visible behavior, but it's an important step toward the series' larger goal of abstracting alternates handling. The changes look clean and purposeful, continuing the careful work seen in earlier patches of this v3 series.
