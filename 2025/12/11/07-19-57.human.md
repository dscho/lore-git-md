This is a cover letter for a bugfix series addressing two object database-related issues. Patrick Steinhardt has split these fixes out from other work to avoid dependency chains. The series has been revised based on feedback, with the most notable change being the removal of a problematic patch about geometric repacking with promisor remotes (which needs more architectural work).

The remaining two fixes are:
1. A correction in `builtin/gc.c` for when commit graphs should be written, fixing both a memory leak and reference tip miscounting issue. The test coverage in t/t7900-maintenance.sh has been tightened to better validate the SEEN flag behavior in merge scenarios.
2. A fix in `odb.c` for a submodule-related memory leak during quarantine directory handling, where sources weren't being properly closed before freeing.

The changes appear well-justified and focused, with appropriate test coverage. The first fix in particular has benefited from discussion with Justin Tobler about strengthening the test cases. The series builds on prior work (ps/object-source-management) and seems ready for consideration, with the more complex promisor pack handling deferred to future work.
