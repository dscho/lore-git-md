This is a review comment on a code quality patch series introducing the MEMZERO_ARRAY macro.

Junio Hamano responds to Toon Claes's patch that introduced a new MEMZERO_ARRAY macro and corresponding Coccinelle rule. The macro provides type-safe array zeroing with overflow protection, and the Coccinelle rule converts existing memset() calls to use it. 

Hamano suggests expanding the Coccinelle pattern to also catch memset calls using '\0' as the fill value (in addition to 0 and 0x0) and using sizeof(array[0]) with ARRAY_SIZE(array) patterns. This would make the semantic patch more comprehensive in catching additional variants of array zeroing that should be converted to the new macro.

The comment shows careful attention to edge cases in the pattern matching, suggesting the maintainer is reviewing the technical details of the Coccinelle rule. This is the first review feedback on the series, which until now had only seen the author's initial submission. The suggestion appears constructive and focused on making the conversion more thorough.
