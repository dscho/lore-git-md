This is patch 7/8 in Patrick Steinhardt's v3 series refactoring Git's alternates handling as part of the ODB abstraction effort. The patch transitions alternates reading to use the new source-based interface, moving away from direct filesystem operations.

The key change renames `read_info_alternates()` to `odb_source_read_alternates()` and modifies it to take a `struct odb_source` parameter instead of a raw path. The function now uses `source->path` rather than the passed `relative_base` parameter. Three call sites are updated to use this new interface: the recursive alternates addition, the initial alternates preparation, and the direct alternates file reading.

This patch builds on the architectural changes from previous patches in the series, particularly the removal of mutual recursion in patch 5/8 and the code reorganization in patch 6/8. The changes are relatively straightforward - 6 lines changed total (6 insertions, 6 deletions) - but represent an important step in the series' goal of abstracting alternates handling to support pluggable object database backends.

The patch maintains all existing functionality while moving closer to the series' end goal of source-based writing of alternates (which will be addressed in patch 8/8). No new tests are added as this is a refactoring that preserves behavior, though the existing alternates tests continue to verify correctness.
