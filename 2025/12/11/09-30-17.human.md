Final patch in the ODB alternates refactoring series, completing the transition to source-based handling. This is the eighth and concluding patch in Patrick Steinhardt's v3 series restructuring Git's alternates handling as part of the broader object database abstraction effort. The patch refactors alternates file writing to operate through the new `struct odb_source` interface rather than direct filesystem operations.

The key change moves the alternates file writing logic into a new `odb_source_write_alternate()` function that takes a source parameter, mirroring the source-based reading approach from patch 7/8. The implementation carefully maintains all existing behavior while adding proper error handling (converting previous `die()` calls to error returns). The patch also simplifies the control flow by making `odb_add_alternate_recursively()` unconditional when alternates are loaded.

This completes the architectural transition started in earlier patches, with all alternates operations now going through the source abstraction layer. The changes are well-contained (51 lines total, mostly moving code into the new function) and maintain backward compatibility. With this patch, the series achieves its goal of preparing alternates handling for future ODB backends that may not use traditional filesystem storage.
