This is the third version of a refactoring series that changes how Git handles alternate object directories to work through the object database "source" abstraction. The series is part of the ongoing ODB abstraction effort to support pluggable object database backends.

Patrick Steinhardt has addressed the build failure from v2 by fixing references to the non-existent `odb_add_source()` function, now consistently using `odb_add_alternate_recursively()` instead. The series maintains its original goal of restructuring alternates handling to be backend-agnostic, which will allow future object database implementations to use non-filesystem mechanisms for storing alternates information.

The changes in v3 are purely mechanical fixes to the commit messages and implementation details - the architectural approach remains unchanged. The 8-patch series progresses from self-contained parsing changes (patches 1-3) through recursive behavior cleanup (patches 4-5) to the final source-based reading and writing of alternates (patches 6-8). The series appears well-structured and addresses the build issue that was caught in v2, suggesting it's ready for review.
