Junio Hamano is queuing René Scharfe's patch to work around macOS's broken iconv implementation by preferring Homebrew's libiconv when available. This addresses test failures in t3900 when converting ISO-2022-JP to UTF-8 on macOS 15.7.2 and later.

The patch represents the third proposed solution path in this thread, joining two code-based workarounds. Brian M. Carlson had endorsed this approach, noting it creates incentive for Apple to fix their implementation since their own Git builds would continue failing these tests. Junio confirms this incentive exists regardless of the patch, but agrees the Homebrew solution is worthwhile.

The solution remains opt-in via ICONVDIR override, maintaining compatibility with systems where Homebrew isn't available. This follows the thread's technical consensus around maintaining multiple fallback paths while prioritizing solutions that encourage upstream fixes. The patch appears ready for integration pending any final implementation details about universal builds and package manager flag organization.
