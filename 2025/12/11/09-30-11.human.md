This is the second patch in Patrick Steinhardt's v3 series refactoring Git's alternates handling as part of the object database (ODB) abstraction effort. The patch focuses on cleaning up how relative paths in alternates files are resolved.

The patch moves path resolution logic from `link_alt_odb_entry()` (renamed to `odb_add_alternate_recursively()`) into `parse_alternates()`, making the parsing step fully self-contained. This is part of the larger goal to make alternates handling work through ODB's source abstraction rather than direct filesystem operations.

Key changes include:
- Relative path resolution now happens during parsing rather than linking
- The function is renamed to better reflect its recursive nature
- Error handling for path resolution remains unchanged (still ignores unresolvable paths)
- The patch maintains existing functionality while better separating concerns

The changes are fairly mechanical - about 30 lines moved between functions with some minor adjustments. This continues the series' pattern of incremental refactoring while keeping each step focused and reviewable.
