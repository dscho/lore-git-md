This is the first patch in Patrick Steinhardt's v3 series refactoring Git's alternates handling as part of the object database (ODB) abstraction effort. The patch focuses on making alternates parsing self-contained.

The change extracts alternates parsing logic from `link_alt_odb_entries()` into a new `parse_alternates()` function. Previously, parsing was intertwined with linking operations and involved mutual recursion between parsing and linking alternates. The new implementation:
- Uses `strvec` instead of `strbuf` to collect parsed alternates
- Separates the parsing logic completely from the linking operations
- Maintains all existing functionality including handling of quoted paths and comments
- Reduces code complexity by eliminating the need to pass string positions back and forth

While this doesn't yet resolve the mutual recursion issue (saved for later patches), it creates the foundation by cleanly separating parsing from linking. The diff shows significant restructuring of `odb.c` (40 insertions, 30 deletions) while keeping the same behavior.

This is a preparatory refactoring that enables the subsequent changes in the series. The patch appears well-structured with a clear commit message explaining both the current problems and how this change helps address them, though it doesn't yet solve the recursion issue. The changes align with the series' goal of making alternates handling work through a "source" abstraction rather than direct filesystem operations.
