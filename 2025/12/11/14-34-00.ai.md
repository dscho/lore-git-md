This is a follow-up in the ongoing macOS iconv/character encoding thread, providing information about Apple's Git distribution. René Scharfe responds to Junio C Hamano's question about whether a "vanilla" macOS installation can build and test successfully by examining Apple's own Git distribution.

Key technical details from the response:
- Points to Apple's Git source at https://github.com/apple-oss-distributions/Git
- Notes Apple's version is close to Git v2.50.1 but with several modifications
- Provides a `git diff` showing 15 files changed in Apple's version
- Highlights that Apple's Makefile sets NO_GETTEXT, NO_FINK and NO_DARWIN_PORTS

The email confirms Apple maintains their own modified Git build that differs from upstream, particularly in build configuration. This contributes to the thread's broader discussion about macOS compatibility solutions by showing how Apple handles dependencies differently than the Homebrew-based approach being discussed.

The response doesn't directly address the test pass/fail question but provides concrete data about Apple's build configuration that could inform the ongoing decisions about how Git should handle macOS character encoding issues and package manager assumptions.
