He questions whether a "vanilla" macOS installation (without third-party package managers like Homebrew) should reasonably be expected to pass Git's test suite, noting that Apple's own Git builds would fail the t3900 tests regardless of the Homebrew workaround.

1. Whether Apple's internal builds should be expected to pass all tests
2. If there are stakeholders who could help bridge the gap between Git's expectations and macOS's system libraries
3. The possibility of marking some tests as macOS-incompatible if core system issues can't be fixed
4. The potential value of establishing macOS-specific CI to maintain compatibility

- The distinction between "vanilla" macOS and Homebrew-equipped systems
