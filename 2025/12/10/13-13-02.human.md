Build system fix for Coccinelle rules. This is the second patch in a two-part series introducing a new MEMZERO_ARRAY macro and updating related Coccinelle infrastructure.

The patch fixes an issue where Coccinelle wasn't properly processing certain header files when checking code patterns, specifically missing type information needed to apply the new MEMZERO_ARRAY rule from the first patch. The problem manifested when checking builtin/last-modified.c, where Coccinelle couldn't resolve the type hierarchy through ewah/ewok.h includes.

The solution adds explicit include path directives for both Makefile and meson builds, ensuring Coccinelle can find all relevant headers when analyzing code. The paths cover key directories like ewah/, compat/, and xdiff/ that contain commonly used types. The change is straightforward - just adding the include paths to both build systems' Coccinelle configurations.
