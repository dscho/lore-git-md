This is a review response in the ongoing `repo structure` enhancement series, specifically addressing patch 5/6 which added disk size metrics to the keyvalue output format. Patrick Steinhardt suggests two improvements to the test coverage:

2. **Test validation strategy**: Recommends using `git rev-list --disk-usage` with type filters to actually verify the disk size calculations in the tests, rather than just stripping them due to platform variance. This would provide concrete validation that the reported disk sizes match Git's own calculations. He also notes this approach could help verify the human-readable formatting in the next patch.
