This is part 4 of a 6-part series enhancing Git's `repo structure` command with detailed object size reporting. The patch adds human-readable inflated object size information to the table output format, with values scaled using binary (1024-based) units (KiB/MiB/GiB).

The implementation handles size formatting with careful rounding (adding small offsets before division to get proper rounding behavior) and keeps the value and unit strings separate for table alignment purposes. Patrick Steinhardt notes this differs from `git rev-list --disk-usage=human` which combines them, and suggests adding comments to explain the rounding math. He also flags that the unit strings should be marked for translation, which Justin agrees to address.

The patch maintains the existing machine-readable output (keyvalue/nul formats) unchanged, focusing only on enhancing the human-readable table view. This is part of the broader effort to give users better visibility into repository storage characteristics through the `repo structure` command.
