This is the final patch in Patrick Steinhardt's v2 series refactoring Git's object database alternates handling. The patch introduces `odb_source_write_alternate()` to handle writing alternates through the new source abstraction, completing the transition from direct filesystem operations to a backend-agnostic approach.

The change moves the alternates file handling logic into a new function that works with `struct odb_source` rather than raw paths, maintaining consistency with the rest of the series. The implementation carefully preserves the existing behavior while restructuring the code to be more maintainable and prepare for future backend support. Key aspects include proper error handling, lock file management, and duplicate checking when writing alternates.

The patch builds on positive feedback from Justin Tobler on earlier versions and appears well-considered, though it doesn't yet address the architectural concerns about alternates representation that were noted in previous discussion. As the series conclusion, it provides a clean foundation for future work on pluggable ODB backends while maintaining backward compatibility with the current filesystem-based implementation.
