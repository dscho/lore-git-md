Refactoring and build system patch introducing a new MEMZERO_ARRAY macro for array initialization, with accompanying Coccinelle rules. This is the first of a two-part series that standardizes zeroing of dynamically allocated arrays across the codebase.

The patch adds MEMZERO_ARRAY() to git-compat-util.h as a companion to ALLOC_ARRAY and friends, providing a type-safe way to zero arrays that avoids manual sizeof calculations. The implementation uses st_mult() for overflow protection like the other array macros. The Coccinelle rules in array.cocci enforce this pattern by converting existing memset() calls that match the array-zeroing pattern.

Changes touch several subsystems including last-modified, simple-ipc, diff-delta, ewah bitmaps, hashmap, and pack-revindex. The conversions demonstrate the macro handles both pointer and array syntax, though the commit notes an exception case in add-patch.c where pointer arithmetic makes the macro unsuitable. The patch appears mechanically sound with straightforward replacements that don't alter behavior.

This builds on prior work around memory initialization patterns and connects to ongoing Coccinelle infrastructure improvements. The macro naming deliberately avoids CLEAR_ARRAY to prevent confusion with array resizing operations. As the first posting, it awaits review particularly from Coccinelle experts like René Scharfe regarding the semantic patch implementation and from maintainers of affected areas.
