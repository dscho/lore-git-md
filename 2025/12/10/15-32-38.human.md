This is the fifth patch in Patrick Steinhardt's v2 series refactoring Git's object database alternates handling as part of the broader ODB abstraction effort. The patch focuses on eliminating mutual recursion in the alternates parsing code.

The key change restructures how Git processes alternate object databases to remove the confusing mutual recursion between `link_alt_odb_entries()` and `odb_add_source()`. Previously, these functions called each other in a way that intertwined parsing alternates with the recursive addition process. The new version makes `parse_alternates()` unaware of the recursive behavior, which is now cleanly handled by `odb_add_alternate_recursively()`.

The patch maintains all existing functionality while making the code easier to follow. It's a well-contained change that builds on the previous patches in the series, particularly the introduction of `parse_alternates()` in patch 1/8 and the path resolution changes in patch 2/8. The diff shows careful attention to edge cases like depth limit checking and proper memory cleanup.

This continues the series' pattern of clean, incremental improvements to the alternates handling code. The change appears non-controversial and aligns with the positive feedback received on earlier versions of the series. It sets up the groundwork for further ODB source abstraction work mentioned in the commit message.
