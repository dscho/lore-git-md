Refactoring patch in Patrick Steinhardt's ODB alternates handling series (v2 1/8). This initial patch in the v2 series restructures alternates parsing to be self-contained, separating it from the linking logic. The key change replaces the incremental `parse_alt_odb_entry()` function with a batch-oriented `parse_alternates()` that processes the entire input into a `strvec` before any linking occurs. The patch maintains all existing functionality while preparing for later changes that will fully disentangle parsing from linking.

The technical changes involve:
- New `parse_alternates()` function that handles quoted paths, comments, and normal entries while populating a `strvec`
- Removal of the stateful `parse_alt_odb_entry()` that previously returned the next parse position
- Conversion of `link_alt_odb_entries()` to use the batch-parsed `strvec` rather than processing entries one at a time
- Preservation of all existing behavior including quoted path handling and comment skipping

This is a foundational change for the larger series that will eliminate mutual recursion between parsing and linking alternates. The patch appears well-constructed with thorough handling of edge cases and maintains the same error handling characteristics as the original code. As the first step in a larger refactoring, it deliberately doesn't yet address the recursion issue it identifies.
