This is a performance optimization patch in the MIDX (multi-pack index) handling series. It extracts the logic for determining when a MIDX rewrite is needed into a new helper function `midx_needs_update()`, preparing for better handling of the `--stdin-packs` case in the next patch.

The change moves the existing skip-rewrite conditions from `write_midx_internal()` into a dedicated function, making the code more maintainable and setting up for future extensions. The current logic avoids unnecessary MIDX rewrites when the existing index already matches the pack state, but doesn't yet handle `--stdin-packs` scenarios properly.

This is part of a v2 series that has already addressed review feedback from Taylor Blau, with the overall goal of optimizing geometric repacking operations. The patch itself is a straightforward refactoring that maintains existing behavior while improving code organization. The next patch in the series will build on this to fix the `--stdin-packs` case mentioned in the commit message.
