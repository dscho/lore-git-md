This is a refactoring patch introducing a new MEMZERO_ARRAY macro to standardize array zeroing across the codebase. It's the first in a two-part series that emerged from discussions around the git-last-modified bug, where uninitialized memory issues were identified.

The patch adds MEMZERO_ARRAY to git-compat-util.h as a companion to the existing ALLOC_ARRAY family of macros. The key advantage is replacing error-prone manual memset() calls with a type-safe interface that automatically calculates the correct size. The implementation carefully avoids naming it CLEAR_ARRAY to prevent confusion with array resizing operations.

Several subsystems are updated to use the new macro, including last-modified.c (where the original issue was found), simple-ipc, diff-delta, ewah bitmaps, hashmap, and pack-revindex. The changes are straightforward mechanical conversions, though the commit notes an exception case in add-patch.c where pointer arithmetic makes the macro unsuitable.

A Coccinelle rule is included to help automate future conversions and enforce the pattern. The patch appears well-scoped and thoughtfully implemented, with clean diffs and clear commit message. As the first in a series, it sets up the infrastructure that the follow-up Coccinelle build system patch will build upon.
