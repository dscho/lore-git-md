This is the sixth patch in Patrick Steinhardt's v2 series refactoring Git's object database alternates handling. The series is part of the broader ODB abstraction effort to support pluggable backends.

The patch removes a forward declaration of `read_info_alternates()` that was previously needed due to mutual recursion in the code. Since the prior patch (5/8) eliminated that recursion, the forward declaration is no longer necessary. The patch reorganizes the code by moving `read_info_alternates()` and its dependent functions (`odb_source_new()` and `odb_add_alternate_recursively()`) up in the file to maintain logical ordering.

The author notes that the removed function documentation for `read_info_alternates()` was outdated anyway, as it didn't reflect the current behavior. This is a straightforward cleanup patch that builds on the architectural improvements made earlier in the series. The changes are mechanical and don't introduce new functionality, just better code structure following the recursion elimination in the previous patch.

This continues the series' pattern of methodically improving the alternates handling code while maintaining all existing functionality. The patch appears well-contained and builds on the positive reviews received for earlier versions.
