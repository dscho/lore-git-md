This is the fourth patch in Patrick Steinhardt's v2 series refactoring Git's object database alternates handling. The series is part of the ongoing ODB abstraction effort to support pluggable backends.

The patch simplifies `odb_add_to_alternates_file()` by having it call `odb_add_source()` directly rather than `link_alt_odb_entries()`. The change makes the behavior more predictable since callers only ever pass single directories, while the old implementation could process multiple newline-separated entries unexpectedly. This aligns with the series' goal of separating parsing and linking concerns in alternates handling.

The change is straightforward - just a single line modification to call the more appropriate function. The patch maintains the same functionality while removing a subtle inconsistency in the API. This continues the series' pattern of cleaning up the alternates implementation in preparation for supporting different object database backends.
