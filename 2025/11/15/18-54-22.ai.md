This is the second patch in Kiril Ivanov's series adding quiet mode support for Git's bash prompt upstream indicators, focusing on test coverage for the existing upstream indicator functionality.

The patch adds comprehensive tests for the `GIT_PS1_SHOWUPSTREAM` behavior in `t/t9903-bash-prompt.sh`, covering all current modes (short, verbose, and verbose name) across four branch states: equal (in sync), ahead, behind, and diverged. The test matrix uses parameterized tests to efficiently verify the expected output strings for each combination. The test infrastructure is enhanced with a bare origin repository and proper remote setup to enable upstream tracking.

Key technical details for future reference:
- Tests verify the output format for each `GIT_PS1_SHOWUPSTREAM` mode:
  - `short`: ' =', ' >', ' <', ' <>'
  - `verbose`: '|u=', '|u+1', '|u-1', '|u+1-1'
  - `verbose name`: same as verbose but includes remote branch name
- Test cases manipulate branch positions through commits, resets, and checkouts
- The test setup now includes a bare `origin.git` and proper remote configuration
- Each test properly cleans up using `test_when_finished` hooks

This test groundwork will support the upcoming quiet mode implementation in patch 3/3, providing baseline verification of existing behavior before new functionality is added. The tests follow Git's standard practices and cover all current upstream indicator cases systematically.
