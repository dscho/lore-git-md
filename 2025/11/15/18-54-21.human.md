Test cleanup patch for bash prompt test suite.

This is the first of three patches in Kiril Ivanov's series introducing a quiet mode for Git's bash prompt upstream indicators. The patch simplifies the test setup in `t/t9903-bash-prompt.sh` by replacing manual commit creation with `test_commit` helper calls. The test scenario remains the same - it creates a repository with multiple branches and tags - but the implementation is more concise and readable.

The changes maintain the exact same commit graph structure (shown in the added ASCII diagram comment) while reducing the setup code from 16 lines to 11. This appears to be straightforward test modernization without any behavior changes, serving as groundwork for the subsequent patches that will test and implement the new quiet mode feature. The cleanup follows Git's common practice of using test helpers where possible to make tests more maintainable.
