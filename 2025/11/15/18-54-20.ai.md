This is a feature patch series introducing a new quiet mode for Git's bash prompt upstream indicators. The series comes from Kiril Ivanov via GitGitGadget.

The core change adds a 'quiet' option to the `__git_ps1` prompt's SHOWUPSTREAM configuration, allowing users to suppress the '=' indicator when their branch is in sync with its upstream. The prompt will still show divergence indicators (ahead/behind counts) when they exist. The motivation is to reduce visual noise for users who primarily work with remote-tracking branches and only care about divergence states.

The series includes three patches:
1. A test cleanup using `test_commit` to simplify setup
2. New tests specifically for upstream indicator behavior
3. The main implementation adding the quiet mode option

The changes affect `contrib/completion/git-prompt.sh` and its test file `t/t9903-bash-prompt.sh`. The implementation maintains all existing verbose modes while adding the new variants that omit the equals sign when branches are synchronized. The series appears well-structured with clear commit separation between refactoring, test coverage, and the feature implementation. The commit messages explain the motivation and behavior changes clearly. This seems like a focused quality-of-life improvement for users of the bash prompt feature.
