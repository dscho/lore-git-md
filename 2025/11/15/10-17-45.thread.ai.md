Thread identity: Feature patch adding a new "lisp" userdiff driver for Common Lisp and other Lisp dialects, complementing the existing "scheme" driver.

Core problem or goal: The existing "scheme" userdiff driver doesn't properly handle Common Lisp syntax. Scott L. Burson's follow-up provides concrete justification for distinct patterns, citing three key differences: 1) Common Lisp's 'defun'/'deftype' forms vs Scheme's 'define', 2) Lisp macros using "def" prefix rather than "define", and 3) Lisp indentation conventions enabling reliable pattern matching. The technical discussion centers on whether these justify a new driver versus extending the scheme driver.

Key technical details: The proposed driver defines patterns in userdiff.c for:
- Function/macro definitions (lines starting with "(" or indented "(def")
- Common Lisp symbol syntax (vertical bar delimiters and escape sequences)
- Word boundaries (whitespace or brackets/braces/parentheses)
Scott confirms the vertical bar pattern accounts for Common Lisp's symbol syntax rules, though considers this an edge case. The patterns were vetted with other Common Lisp developers.
