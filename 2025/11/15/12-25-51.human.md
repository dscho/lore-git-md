This is a follow-up in the thread about UTF-8 display alignment fixes, but takes an unexpected turn discussing AI-generated code attribution. Jiang Xin responds to Junio C Hamano's concerns about corporate tracking of AI tool usage in commit messages.

The email reveals that Jiang Xin's team at Alibaba Cloud has been using commit-msg hooks to automatically tag AI-generated code with tool identifiers (like `Co-developed-by` trailers) for internal metrics. Junio questioned what value this provides to the Git project itself, implying these corporate tracking markers may not belong in upstream commits.

Jiang Xin acknowledges the feedback and commits to:
1. Disabling the automatic commit message modification for git.git contributions
2. Conducting more careful reviews of any AI-generated code before submission

While this doesn't directly affect the technical UTF-8 alignment work, it surfaces an interesting policy discussion about AI tool attribution in open source contributions. The response shows willingness to adapt to project norms, though the thread leaves open whether/how AI-assisted contributions should be documented in Git's development process.
