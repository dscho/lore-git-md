This is a feature patch series proposing an enhancement to Git's bash prompt functionality. Kiril Ivanov introduces a new 'quiet' option for the upstream branch indicator in `git-prompt.sh`, allowing users to suppress the redundant '=' symbol when their branch is tracking a remote branch without divergence.

The series consists of three patches: first refactoring some test setup code, then adding new tests for upstream indicators, and finally implementing the new quiet mode. The change maintains all existing functionality while giving users more control over prompt verbosity. The implementation looks clean and well-tested, with thorough documentation of the new behavior variants in the cover letter.

The motivation is clear - reducing visual noise in the prompt when the '=' indicator doesn't convey useful information. This appears to be a thoughtful quality-of-life improvement for users who work primarily with tracking branches and want a cleaner prompt. The patch seems unlikely to be controversial as it's purely additive and doesn't change default behavior.
