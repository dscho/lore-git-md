Test coverage for bash prompt upstream indicators. This is the second patch in Kiril Ivanov's series to add a quiet mode for Git's bash prompt upstream status indicators.

The patch adds comprehensive test coverage for the existing upstream indicator functionality in `git-prompt.sh`, which previously had no tests. It tests verify the different display modes (short, verbose, and verbose with name) across four scenarios: when the branch is in sync with upstream, ahead, behind, or diverged. The test matrix uses parameterized tests to efficiently cover all combinations.

The test setup is extended to include a bare origin repository and establish upstream relationships, creating the necessary conditions to test the upstream tracking indicators. Each test case carefully manages state with `test_when_finished` cleanup handlers to ensure isolation.

This test groundwork paves the way for the series' main feature in the next patch - adding a quiet mode that will suppress the '=' indicator when branches are in sync. The tests are thorough and follow Git's testing best practices, suggesting this is a well-considered contribution.
