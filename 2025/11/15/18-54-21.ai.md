Test modernization patch that simplifies the test setup for bash prompt testing. This is the first of three patches in Kiril Ivanov's series introducing a quiet mode for Git's bash prompt upstream indicators.

The patch refactors `t/t9903-bash-prompt.sh` to use `test_commit` for test repository setup instead of manual file operations and commits. It replaces a sequence of manual file modifications and commits with equivalent `test_commit` invocations, reducing the setup code from 16 lines to 11 while maintaining the same commit history structure. The test repository will contain:
- An initial annotated commit (t1)
- Branch b1 with two commits (one untagged, one annotated as t2)
- Branch b2 with three untagged commits
- An ignored directory

This change follows Git's testing best practices by using the standard test helper, making the setup more maintainable and easier to understand. The commit history diagram in the comment block remains accurate after the changes. This is purely a test infrastructure improvement that doesn't affect the actual prompt functionality being tested.
