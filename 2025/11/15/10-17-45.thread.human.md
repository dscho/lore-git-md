This thread introduces a new Git userdiff driver for Lisp dialects, with a focus on better supporting Common Lisp syntax. The patch author notes that while Git already has a "scheme" driver, it doesn't properly handle Common Lisp's distinctive features like vertical-bar-delimited symbols and def* forms.

The proposed driver adds pattern matching for:
- Function/macro definitions (both at start of line and slightly indented)
- Common Lisp's symbol syntax including escape sequences
- Word boundaries specific to Lisp's bracket-heavy syntax

The implementation follows Git's standard userdiff pattern syntax and would enable better diff highlighting for Lisp codebases. The patch appears technically sound with proper sign-off and metadata. While primarily targeting Common Lisp, the author suggests it should work reasonably well for other Lisp dialects too. This would be particularly useful for developers working with Common Lisp projects where the existing scheme driver falls short.
