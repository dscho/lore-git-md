Feature patch adding a quiet mode for Git's bash prompt upstream indicators.

This is the final patch in Kiril Ivanov's series to improve the bash prompt's upstream branch indicators. It implements the promised quiet mode that suppresses the '=' indicator when a branch is in sync with its upstream, while still showing divergence indicators (ahead/behind counts). The change is motivated by consistency with other prompt indicators that only appear when actionable.

The patch modifies `__git_ps1_show_upstream()` in `git-prompt.sh` to handle a new "quiet" option in `GIT_PS1_SHOWUPSTREAM`. When enabled, the function will omit the '=' in short mode and show just "|u" (without the equals) in verbose modes when branches are in sync. The implementation maintains all existing behavior for diverged states.

The accompanying test updates verify the new quiet mode works correctly alongside all existing variants (short, verbose, and verbose name). The test matrix now includes six configurations (the original three plus their quiet counterparts) across four branch states (equal, ahead, behind, diverged).

This is a clean, well-tested quality-of-life improvement that follows the principle of only showing information when it's actionable. The implementation is straightforward and maintains backward compatibility. The series as a whole shows good discipline with the first two patches modernizing tests before adding new functionality.
