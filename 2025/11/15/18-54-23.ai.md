This is the implementation patch for the quiet upstream indicator feature in Git's bash prompt, completing Kiril Ivanov's three-part series. The patch adds a new `quiet` option to `GIT_PS1_SHOWUPSTREAM` that suppresses the '=' indicator when a branch is in sync with its upstream, while preserving all other divergence indicators (ahead/behind counts).

The implementation modifies `__git_ps1_show_upstream()` in `contrib/completion/git-prompt.sh` to:
1. Add the `quiet` option parsing alongside existing `verbose`, `legacy`, and `name` options
2. Conditionally suppress the '=' indicator in both short and verbose modes when `quiet` is enabled
3. Maintain all existing behavior for diverged states (ahead, behind, diverged)

The test suite in `t/t9903-bash-prompt.sh` is updated to include new test cases for the quiet mode, covering all combinations with existing modes (short, verbose, verbose name). The test matrix now includes:
- Quiet mode alone (suppresses '=' while showing other states)
- Verbose quiet (shows '|u' instead of '|u=' for equal states)
- Verbose name quiet (shows '|u origin/main' instead of '|u= origin/main')

The commit message argues that this change aligns with Git prompt's existing behavior of only showing actionable indicators, since '=' represents a neutral state rather than something requiring user attention. The implementation appears clean and well-tested, building on the modernized test infrastructure from the previous patches in the series.
