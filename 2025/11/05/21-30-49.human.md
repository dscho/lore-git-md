This is the infrastructure patch in Junio Hamano's series adding support for detecting missing newlines at end of files as a configurable whitespace error. As patch 09/12 in version 2, it follows the preparatory refactoring (patches 01-08) and precedes the actual implementation (10-12).

The patch reserves additional bits in the diff flags word for future whitespace rules and defines WS_INCOMPLETE_LINE (0x8000) as the new whitespace rule for missing newlines. It updates documentation, bit allocations in diff.c/diff.h, and adds the new rule to whitespace parsing/error reporting in ws.c/ws.h. The behavior isn't implemented yet - this just sets up the infrastructure.

Key technical changes include shifting existing diff symbol flags to make room (moving them from bits 12-19 to 16-22), expanding WS_RULE_MASK to cover 16 bits, and adding the new "incomplete-line" documentation and error string. The patch maintains the series' careful attention to bit allocation patterns and documentation.

This continues the series' pattern of surgical, well-documented changes with comprehensive test coverage. The changes are straightforward infrastructure work that shouldn't be controversial, though reviewers may want to double-check the bit allocations. The actual enforcement of incomplete-line detection will come in subsequent patches.
