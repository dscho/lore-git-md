This is a contributor housekeeping patch that aligns the Makefile for the wincred credential helper with other Makefiles in the contrib directory. Thomas Uhle makes several straightforward improvements:

1. Replaces the deprecated `$(LOADLIBES)` variable with `$(LDFLAGS)` which is the modern equivalent used elsewhere in Git
2. Switches from `$(libexecdir)` to `$(gitexecdir)` to properly follow Git's installation conventions
3. Improves the install target to create the destination directory and respect `$(DESTDIR)`
4. Reorders variable definitions to match the style of other credential helper Makefiles
5. Adds `.PHONY` declarations for all special targets

The changes are mechanical and uncontroversial, following established patterns from similar Makefiles in the project. This appears to be a straightforward quality-of-life improvement for maintainers rather than a change affecting functionality.
