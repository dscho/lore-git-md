This is a follow-up in the thread investigating `git grep -l` output formatting issues with filenames containing dashes. The discussion has shifted from a suspected Git regression to identifying the Delta pager as the likely culprit.

Kristoffer Haugsbakk shares confirmation from the original reporter (Michael Roach) that the issue only occurs when using the Delta pager, not with `--no-pager`. This aligns with Lucas Seiki Oshiro's earlier discovery of a known bug in Delta (issue #1259) that transforms hyphens to colons in output.

The thread has effectively resolved the initial mystery - what appeared to be a Git regression between versions 2.49.1 and 2.51.1 was actually a pager interaction issue. The Delta pager's behavior explains all observed symptoms, including the color highlighting and character transformation.

While this appears to close the investigation into Git's behavior, the exchange serves as a useful case study in debugging pager-related issues. The thorough testing methodology (comparing with/without pager, different Git versions) provides a good template for similar future reports. No further action appears needed from the Git project unless maintainers want to consider adding safeguards against pager output transformations.
