This is a feature proposal for `git fast-import` that would add a new 'strip-if-invalid' mode to its `--signed-commits` option. The patch series comes from Christian Couder and consists of 3 patches.

The core idea is to help tools like `git filter-repo` handle signed commits more gracefully during imports. Currently, `fast-import` can either keep signatures as-is or strip them all, but the new mode would automatically strip only invalid signatures while keeping valid ones intact. The author suggests this might eventually become the default behavior, but defers that decision for future discussion.

The series includes some preparatory refactoring (splitting out signature verification logic from `finalize_commit_buffer()` and `verify_commit_buffer()`) before implementing the new mode. The changes touch several files including the fast-import implementation, commit verification code, and GPG interface plumbing. There's also extensive test coverage added in the test suite.

The author notes this functionality could logically extend to signed tags as well, but focuses on commits for this initial implementation. CI tests have already passed successfully. The changes look well-structured with clear commit separation between refactoring and new feature implementation.
