CI / build system update to migrate macOS CI jobs to newer GitHub Actions runners. Junio Hamano submits a straightforward patch updating four macOS CI jobs (`osx-clang`, `osx-reftable`, `osx-gcc`, and `osx-meson`) from the deprecated `macos-13` to `macos-14` images. The change is time-sensitive as GitHub will fully remove the old images on December 4th after deprecating them in September.

The patch is minimal - just changing the pool specification in `.github/workflows/main.yml` - and has already been test-merged successfully. Junio notes this is a direct replacement but cautions there may be follow-up adjustments needed for tool version differences. He plans to fast-track this to ensure CI keeps working through the upcoming release cycle.

This appears to be a necessary maintenance update with low risk, though future tweaks might be needed if the new runners have different toolchain versions. The change keeps Git's CI system current with GitHub's infrastructure changes.
