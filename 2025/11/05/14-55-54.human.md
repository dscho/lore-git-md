This is a follow-up in the thread about the `git grep -l` output formatting regression with filenames containing dashes. Lucas Seiki Oshiro provides additional context suggesting the issue may be specific to the Delta pager rather than Git itself.

The email points to an existing Delta pager bug report (dandavison/delta#1259) that describes similar behavior - hyphens being replaced with colons in output. Lucas notes they previously investigated this behavior and concluded it was a Delta bug, not a Git issue. They suggest testing with alternative pagers (`less` or `cat`) to confirm whether the issue persists outside of Delta.

This shifts the focus of the investigation, suggesting the original regression report might be a false alarm caused by pager interaction rather than a core functionality bug in Git. The email provides a clear next step for verification by testing with different pagers. The connection to a known Delta issue gives this theory credibility, though it remains to be confirmed whether this explains all cases of the reported behavior.
