This is the diff-side implementation (patch 11/12) of Junio C Hamano's series adding incomplete-line whitespace detection. It completes the core functionality by teaching `git diff` to highlight and error out on missing newlines at end of file when the incomplete-line whitespace class (WS_INCOMPLETE_LINE = 0x8000) is enabled.

The patch modifies `diff.c` to:
1. Colorize the "\ No newline at end of file" message as a whitespace error when WS_INCOMPLETE_LINE is active
2. Make `git diff --check` report incomplete lines as errors
3. Track line kinds (context/old/new) through the diff pipeline to properly attribute incomplete line errors
4. Add comprehensive test coverage in t4015-diff-whitespace.sh for various incomplete line scenarios:
   - Incomplete lines in both pre- and post-image
   - Fixing incomplete lines
   - Introducing new incomplete lines
   - Interaction with other whitespace checks

The implementation builds on the preparatory work in earlier patches (particularly the WS_INCOMPLETE_LINE bitmask in patch 09) and maintains the series' pattern of thorough testing before final enablement. The tests demonstrate the policy that modifying a line while keeping it incomplete is considered an error, while fixing an incomplete line is allowed.

This completes the diff side of the pipeline after patch 10 handled the apply side, leaving just patch 12 (Git codebase enablement) remaining in the series. The implementation appears clean and well-tested, with careful attention to line number accounting and consistent behavior across the diff/apply pipeline.
