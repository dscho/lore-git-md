This is the third and final patch in a series adding a 'strip-if-invalid' mode to `git fast-import`'s `--signed-commits` option. The feature allows tools like `git filter-repo` to automatically strip invalid commit signatures during import while preserving valid ones, addressing cases where signatures become invalid due to history rewriting.

The patch implements the new mode by:
1. Adding `strip-if-invalid` as a valid mode in `gpg-interface.c`
2. Extending the documentation to explain the new behavior
3. Implementing signature verification and conditional stripping in `fast-import.c`
4. Adding comprehensive tests covering various signature scenarios (valid/invalid, single/dual signatures, different signature types)

The implementation checks signatures during import and only strips them if they fail verification, with appropriate warnings. The patch maintains backward compatibility and explicitly rejects attempts to use the new mode with tags (reserved for future work). Test coverage is thorough, including cases for GPG, GPGSM, and SSH signatures.

This appears to be a well-considered addition to the fast-import machinery, with clear motivation, careful implementation, and extensive testing. The patch builds on the refactoring work done in the first two patches of the series to enable this feature cleanly.
