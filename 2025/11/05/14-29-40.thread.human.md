This thread introduces a new `--trailer` option for `git rebase`, allowing users to add trailers (like Signed-off-by) directly without forking to `interpret-trailers`. The series comes from an established contributor and has undergone several rounds of review from Phillip Wood (rebase expert), Junio Hamano (maintainer), and Kristoffer Haugsbakk (documentation specialist).

The first three patches refactor trailer handling to make it reusable across Git commands, moving the logic in-process for performance. The final patch adds `--trailer` support specifically to rebase's merge backend, with comprehensive tests. The implementation deliberately rejects use with the apply backend for now, though this may be revisited later.

Reviewers have generally approved the approach, with the main discussion points being whether the apply backend limitation is acceptable long-term and whether any edge cases in trailer parsing might surface. The series appears ready for merging, representing another step in Git's ongoing effort to reduce process overhead by moving functionality in-process.
