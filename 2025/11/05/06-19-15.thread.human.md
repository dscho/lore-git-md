The series includes three patches: first refactoring the fast-import commit buffer handling, then modifying the core commit verification logic, and finally introducing the new mode itself.

The implementation touches several areas including the fast-import/export machinery, commit verification code, and GPG interface. The changes are well-tested with over 100 new lines of test coverage in the fast-import signature test script. While the current patches focus on commit signatures, Christian notes this approach could potentially be extended to handle signed tags in the future as well.

An open question remains about whether this behavior should eventually become the default, though Christian wisely leaves that decision for future discussion given the backward compatibility implications.
