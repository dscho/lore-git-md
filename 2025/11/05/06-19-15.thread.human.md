This thread introduces a new 'strip-if-invalid' mode for `git fast-import` that automatically removes invalid commit signatures while preserving valid ones during repository imports. The three-patch series refactors commit buffer handling and verification logic in preparation for this feature, with the final patch now implementing the new mode.

The implementation provides comprehensive handling of different signature types (OpenPGP, X.509, SSH) and includes detailed warning messages when invalid signatures are stripped. Test coverage in t9305 has been significantly expanded to verify behavior across various scenarios. The changes are motivated by tools like `git filter-repo` that need to cleanly handle signature validation during repository rewriting operations.

While the current work focuses on commit signatures, the design leaves the door open for future extension to tag signatures (`--signed-tags`) and export operations. The series appears technically sound, building on preparatory refactoring to keep the feature implementation clean and focused. The changes maintain backward compatibility while adding this new capability for tools that process repository histories.
