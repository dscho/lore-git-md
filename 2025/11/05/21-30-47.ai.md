This is a refactoring patch in Junio Hamano's series introducing "incomplete-line" whitespace error handling. It's patch 07/12 in v2, focusing on the rewrite-diff codepath.

The patch removes a special-case hack (DIFF_SYMBOL_NO_LF_EOF) that was handling incomplete lines in rewrite diffs differently from normal diffs. Instead, it now uses the same DIFF_SYMBOL_CONTEXT_INCOMPLETE path that the rest of the diff machinery uses, making the behavior more consistent. The key changes are:

1. Deletion of the DIFF_SYMBOL_NO_LF_EOF enum and its handler
2. Modification of emit_rewrite_lines() to properly handle incomplete lines by:
   - Allocating and modifying temporary buffers when needed
   - Using the existing last_line_kind tracking (added in patch 04)
   - Calling the new emit_incomplete_line() helper (from patch 05)

The changes maintain the same output behavior but do so through the standard mechanisms being set up in earlier patches, paving the way for the upcoming whitespace error detection. The patch continues the series' pattern of careful, surgical changes with good test coverage (though no new tests are added here since it's purely refactoring existing behavior).

This is part of the infrastructure cleanup phase (patches 01-08) before the actual WS_INCOMPLETE_LINE feature implementation begins in patch 09. The change is low-risk since it doesn't modify user-visible behavior, just internal implementation details, but it's important for maintaining consistency between normal and rewrite diffs when the whitespace checking is enabled later in the series.
