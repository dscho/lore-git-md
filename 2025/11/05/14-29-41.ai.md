This is a refactoring patch that extracts trailer processing logic into a reusable `process_trailers()` function as part of a series adding `--trailer` support to `git rebase`. The patch moves the core trailer handling from `interpret_trailers()` into a new helper that accumulates output in a strbuf rather than writing directly to stdout. This prepares for in-process trailer manipulation by making the processing logic available to other commands without requiring file I/O.

Key technical details:
- New `process_trailers()` function takes strbuf parameters for input and output
- Preserves all existing behavior including in-place editing support
- Maintains same trailer block parsing and formatting logic
- Cleans up both input and output buffers after use
- Part of broader effort to replace external `interpret-trailers` calls

The change is well-contained (51-line diff) and maintains test coverage through the existing interpret-trailers test suite. This foundational refactoring enables the subsequent patches in the series to reuse the trailer processing logic directly within rebase.
