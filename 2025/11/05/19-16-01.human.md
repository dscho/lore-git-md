This is the final patch in a v7 series implementing configurable atomic reference updates for `git replay`. The patch adds a `replay.refAction` configuration option that lets users set their preferred default behavior (atomic updates or pipeline output) in their Git config rather than specifying it on every command line.

The implementation follows Git's standard configuration patterns, with command-line `--ref-action` taking precedence over the config setting. The patch includes thorough tests verifying the config option works as expected, including proper override behavior and error handling for invalid values. Documentation is added in both the config and command manpages.

This completes the series after multiple rounds of review, with all feedback from maintainers and reviewers addressed. The patch has received help/sign-off from key contributors including Junio Hamano, Elijah Newren, Christian Couder, and Phillip Wood, indicating broad consensus on the approach. The series is now ready for merging, providing production-ready atomic update functionality for `git replay` with flexible configuration options.
