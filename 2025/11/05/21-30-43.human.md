Refactoring patch in a series introducing new whitespace error handling for incomplete lines at end of files.

This is the third patch in Junio Hamano's 12-part series to detect and handle missing newlines at file endings as configurable whitespace errors. The patch focuses on cleaning up a hack in the diff output code that was misusing the CONTEXT_INCOMPLETE symbol meant for "\ No newline at end of file" cases.

The change moves the special handling of blank-empty suppression to a more localized spot in `emit_line_ws_markup()` where context lines are processed, rather than having it scattered through the diff pipeline. This makes the code more maintainable by keeping the blank-empty logic together with other line emission rules. The patch also tightens the CONTEXT_INCOMPLETE case to explicitly check for backslash, adding a BUG() for unexpected input to prevent future misuse.

As part of the series' preparatory cleanups, this change doesn't yet introduce the new incomplete-line functionality but makes the codebase more robust in preparation for it. The diff shows careful attention to maintaining existing behavior while improving code structure - a characteristic of the series' meticulous approach.
