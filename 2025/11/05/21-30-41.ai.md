This is a preparatory refactoring patch in Junio Hamano's series introducing "incomplete-line" whitespace error detection. It corrects and clarifies the bitmask assignments used for whitespace and diff highlighting rules across diff.c, diff.h and ws.h.

The patch fixes an off-by-one error in the bit position comments (previously claiming bits 0-12 were whitespace rules when they should be 0-11) and adds documentation for the color-moved bits (17-19). It also modernizes the bit constant definitions from octal to (1<<N) notation for better readability and maintainability, while adding whitespace between logically grouped macro definitions.

Key technical details:
- Updates bit position documentation in diff.c to accurately reflect whitespace rules (0-11), highlighting flags (12-14), blank-at-EOF (16), and color-moved (17-19)
- Converts octal constants to bit-shift notation in ws.h (e.g. 0100 becomes (1<<6))
- Maintains all existing functionality while making the code more maintainable
- Part of groundwork for the larger WS_INCOMPLETE_LINE feature (patch 09/12)

This is a straightforward cleanup with no behavior changes, serving as the first of several preparatory patches in the series. The changes are mechanical but important for the subsequent patches that will extend this bitmask infrastructure.
