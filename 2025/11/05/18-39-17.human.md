This is a refactoring patch in the atomic ref updates series for `git replay`. It's a small but meaningful change that standardizes the option validation in `git replay` to use Git's standard `die_for_incompatible_opt2()` helper function.

The patch converts the existing custom error handling for mutually exclusive options (`--advance` and `--contained`) to use the shared helper, which provides consistent error messages across Git commands. This is preparation for adding the new `--ref-action` option in subsequent patches, which will also need to validate option conflicts.

The change is straightforward - replacing a direct `die()` call with the helper function while maintaining the same validation logic. The patch has already been reviewed and approved by Elijah Newren, indicating it's a clean improvement that fits well with the rest of the series. This is part of the final polish before the atomic ref updates feature can be merged.
