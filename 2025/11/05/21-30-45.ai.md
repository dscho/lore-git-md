This is a refactoring patch in Junio Hamano's series introducing "incomplete-line" whitespace error detection. It's patch 05/12 in version 2 of the series.

The patch extracts the handling of "\ No newline at end of file" markers into a dedicated `emit_incomplete_line()` helper function. This prepares for unifying the xdiff and non-xdiff code paths that handle incomplete lines. The change is mechanical - it moves the existing emission of `DIFF_SYMBOL_CONTEXT_INCOMPLETE` into a new function and updates the call site in `fn_out_consume()` to use it.

Key technical details include:
- New `emit_incomplete_line()` helper in diff.c
- Maintains existing color handling for incomplete lines via `DIFF_CONTEXT` colors
- Preserves the BUG() check for unknown line types from patch 04
- Keeps the same line emission behavior, just in a more modular form

This continues the series' pattern of careful preparatory refactoring before the core whitespace error functionality is introduced in later patches. The change is small and focused, maintaining the series' high standard of code organization and test coverage. It builds on patch 04's line type tracking while setting up for the unified incomplete line handling that will follow.
