This is the second patch in a 2-part series implementing diff algorithm configurability for `git blame`. The first patch refactored xdiff internals to support clean algorithm selection, while this one adds the user-facing functionality.

The patch adds `--diff-algorithm` option to `git blame`, mirroring the same option in `git diff` and respecting the `diff.algorithm` config. It maintains Myers as the default but allows selection of minimal, patience, and histogram algorithms. The implementation:
- Adds new callback functions in `builtin/blame.c` for option parsing
- Shares documentation via a new `diff-algorithm-option.adoc` include file
- Includes comprehensive tests in `t8015-blame-diff-algorithm.sh` covering:
  * Default behavior
  * CLI/config precedence
  * Interaction with `--minimal`
  * Edge cases

Key technical details:
- Uses the XDF_DIFF_ALGORITHM_MASK changes from patch 1
- Separates algorithm selection from minimal flag via dedicated callbacks
- Maintains backward compatibility
- Tests verify output differs meaningfully between algorithms

The patch completes the feature after extensive review, addressing all feedback from Junio C Hamano and Phillip Wood regarding implementation approach, test coverage, and documentation. It's now feature-complete with consensus on the technical solution.
