Feature patch series finalizing configurable diff algorithms for `git blame`. This is the fourth version of Antonin Delpeuch's work to allow selecting between Myers (current default), minimal, patience, and histogram diff algorithms in `git blame`, matching the options already available in `git diff`.

The series has gone through extensive review, with all major technical concerns addressed in previous rounds. This version focuses on final polish items identified by reviewers Phillip Wood and Junio C Hamano:
- Properly handles the `XDF_NEED_MINIMAL` flag by adding it to `XDF_DIFF_ALGORITHM_MASK`
- Restores `--no-minimal` support that was accidentally broken
- Cleans up test cases by removing redundant pipes and using `test_config()` for isolation
- Fixes minor documentation typos
- Removes speculative "for now" language from test descriptions

The implementation now has comprehensive test coverage and proper documentation sharing the same `diff-algorithm-option.adoc` include used by `git diff`. The changes touch `builtin/blame.c` for the new option handling and add a new test file, while keeping the diff algorithm selection logic cleanly separated from the existing `--minimal` flag behavior.

With all reviewer feedback addressed and consensus reached on the technical approach, this appears ready for final consideration. The series demonstrates careful attention to detail in both implementation and testing, building on Git's existing diff algorithm infrastructure while maintaining backward compatibility.
