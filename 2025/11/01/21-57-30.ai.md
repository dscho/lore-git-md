This is version 4 of a feature patch series that makes the diff algorithm configurable in `git blame`, addressing the final round of feedback from reviewers. The series has evolved through multiple iterations with all major technical concerns resolved, now focusing on final polish items.

The key changes in v4 implement the agreed-upon technical solution for flag handling by adding XDF_NEED_MINIMAL to XDF_DIFF_ALGORITHM_MASK, which properly separates the minimal flag behavior from algorithm selection. The patch also restores `--no-minimal` support and makes several test improvements as requested by reviewers - removing redundant pipes, using direct configuration passing instead of `git config`, and eliminating the "for now" qualifier from test descriptions.

The implementation now cleanly handles:
- Algorithm selection via both `--diff-algorithm` option and `diff.algorithm` config
- Proper interaction between algorithm selection and the `--minimal` flag
- Comprehensive test coverage of all combinations and edge cases
- Shared documentation via `diff-algorithm-option.adoc`

The series consists of two patches:
1. xdiff: add 'minimal' to XDF_DIFF_ALGORITHM_MASK - the core technical change to the xdiff library
2. blame: make diff algorithm configurable - the main feature implementation

All outstanding review feedback has been addressed, including Phillip Wood's requests for test improvements and Junio Hamano's notes about `--no-minimal` behavior and test wording. The implementation appears ready for merge pending final verification of the xdiff library change's impact on other users.
