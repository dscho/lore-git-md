This is a preparatory refactoring patch for the `git blame` diff algorithm feature series, specifically addressing xdiff library internals. The change modifies the `XDF_DIFF_ALGORITHM_MASK` in xdiff.h to include the `XDF_NEED_MINIMAL` flag, which was previously handled separately. This ensures consistent behavior when resetting diff algorithms across the codebase.

The patch removes redundant clearing of the minimal diff flag in diff.c and merge-ort.c, since the flag will now be cleared automatically when the algorithm mask is reset. The change is technically a breaking change for xdiff library users, but reviewers agreed this is justified for consistency. The implementation follows the consensus from the thread discussion where Phillip Wood confirmed the minimal algorithm should be treated as part of the algorithm selection mask rather than a separate flag.

This foundational change enables the subsequent patch in the series which adds diff algorithm selection to `git blame`. The modification is minimal (3 files touched) and focused specifically on the xdiff interface change needed to support the feature cleanly. Reviewers have already approved the technical approach, with Junio Hamano and Phillip Wood confirming the solution addresses all concerns about flag handling and backward compatibility.
