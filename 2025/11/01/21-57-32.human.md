This is the final implementation patch in a series adding diff algorithm configurability to `git blame`. The patch introduces a `--diff-algorithm` option and support for the `diff.algorithm` config setting in `git blame`, matching the behavior already available in `git diff`. Myers remains the default algorithm, but users can now select between Myers, minimal, patience, and histogram algorithms.

The implementation is clean and well-tested, with comprehensive test coverage in the new `t8015-blame-diff-algorithm.sh` that verifies:
- Default Myers algorithm behavior
- CLI option precedence over config
- Interaction with the existing `--minimal` flag
- Correct ordering when multiple diff options are specified

The patch builds on the xdiff refactoring from the first patch in the series (which modified `XDF_DIFF_ALGORITHM_MASK` to properly separate algorithm selection from minimal flag behavior). Documentation is shared with `git diff` via a new include file.

This represents the culmination of several review rounds where all technical feedback has been addressed, including proper flag handling, test improvements, and documentation. The implementation is now feature-complete and ready for merging.
