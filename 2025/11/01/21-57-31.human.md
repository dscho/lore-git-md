Refactoring patch for xdiff library internals, part of the `git blame` diff algorithm configurability series.

This first patch in the v4 series addresses a technical debt in the xdiff library's flag handling. It adds the `XDF_NEED_MINIMAL` bit to the `XDF_DIFF_ALGORITHM_MASK` bitmask, which previously only included bits for patience and histogram diffs. This change ensures consistent handling when resetting diff algorithms, eliminating the need for separate clearing of the minimal diff bit in multiple places.

The patch removes now-redundant bit-clearing code from `diff.c` and `merge-ort.c`, while updating the mask definition in `xdiff/xdiff.h`. This is a prerequisite for the main feature in patch 2/2 that adds diff algorithm selection to `git blame`. The change has been thoroughly reviewed with consensus that this is the correct approach, though it technically constitutes a breaking change for xdiff library users (justified by the improved consistency).

The implementation is clean and focused, with the changes limited to exactly what's needed to support the subsequent blame feature. Reviewers have confirmed this addresses all technical concerns from previous rounds, particularly around flag handling behavior.
