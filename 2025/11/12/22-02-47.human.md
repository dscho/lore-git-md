This is a preparatory refactoring patch in Junio C Hamano's series introducing comprehensive whitespace handling for missing newlines. It fixes incorrect bit assignment comments in the diff and whitespace handling code, clarifying how various flags are stored in bit positions.

The patch corrects miscounted bit positions in comments that describe whitespace rules and diff symbols, updates the notation from octal to (1 << N) style for better readability, and adds documentation for color-moved bits that were previously undescribed. It also groups related macro definitions with blank lines for better visual separation.

This is a foundational change that ensures accurate documentation of the bitfield layout before the series introduces the new WS_INCOMPLETE_LINE flag (0x8000) in subsequent patches. The changes are mechanical but important for maintaining clarity as the whitespace handling system grows more complex. The patch follows good practices by updating both the diff and ws.h headers to stay in sync.
