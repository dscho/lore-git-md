Bugfix for HTTP authentication in remote-curl when handling large requests. Aaron Plattner identifies a case where `probe_rpc()` fails to use authentication credentials during multi-stage HTTP requests, causing clones with blob filters to fail when fetching blobs after successfully getting commits.

The patch demonstrates the issue with a real-world example using `git-credential-msal`, where an initial clone succeeds but subsequent blob fetches fail with 401 errors because the probe request lacks authentication headers. The fix is straightforward - adding the missing auth header append in `probe_rpc()`.

This appears to be a clear-cut case where a well-isolated piece of functionality wasn't properly handling authentication in all code paths. The patch is small (2-line change) and focused, with a detailed commit message showing the problem and solution. The author notes there may be more to do around token expiration handling, but wisely leaves that for future work.
