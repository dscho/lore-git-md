This is a cover letter for a 9-patch series addressing various issues found through ASan (AddressSanitizer) analysis. The series contains a mix of bugfixes and code quality improvements, primarily focused on memory safety and undefined behavior.

The series starts with minor preparatory changes (patch 1 marks an unused argument, patch 3 enables NO_MMAP with ASan). The substantive fixes include: a name-hash lookup bug in incremental bitmaps (patch 2), a strtol() misuse in cache-tree that could read past buffer bounds (patch 4, noted as a real but low-risk security issue), and several fsck improvements (patches 5-8) that replace questionable string parsing with more robust approaches. The final patch (9) enables stricter string checks in tests.

The cover letter provides useful context about the severity and nature of each issue. The bitmap fix (patch 2) is flagged as particularly important since it affects new, less-tested code. The fsck changes are framed as both fixing ASan false positives and improving code quality, though the author acknowledges the churn may be debatable. The series is structured to keep the test suite passing at each step when building with SANITIZE=address.
