Git v2.52.0-rc2 release announcement summary:

Second release candidate for Git 2.52.0 with 623 non-merge commits from 81 contributors (33 new). Introduces new commands: `git refs list` (for-each-ref frontend), `git repo` (repository characteristics), `git last-modified` (path ancestry). Performance improvements in revision traversal with pathspecs and Bloom filters. Continues `the_repository` global removal effort. Includes Rust integration work and SHA1-SHA256 interoperability preparation.

Fixes address merge handling, refs migration, remote rename operations, and edge cases in `git describe`, `git diff`, `git add -p`. Documents upcoming default branch name change from 'master' to 'main' in Git 3.0 while maintaining compatibility. Tarballs available at kernel.org with tags in public repos. Lists all contributors with special recognition for non-code contributions. Detailed changelog covers UI changes, performance optimizations, documentation updates, and bug fixes since v2.51.0.
