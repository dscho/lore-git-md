This is a build system patch in a series addressing ASan (AddressSanitizer) findings. It enables NO_MMAP by default when building with SANITIZE=address to improve memory safety testing coverage.

The patch forces Git to use heap buffers instead of mmap when built with ASan, addressing a blind spot in current testing. The author explains that mmap's page rounding can mask out-of-bounds accesses (as demonstrated in patch 2's bitmap bug), while ASan doesn't properly track mmap'd memory. This change will help surface similar issues that might otherwise go undetected.

The tradeoff is increased memory usage during tests, but the author notes this is acceptable given the test suite's small repository sizes and ASan's existing performance impact. The patch mentions there are other known bugs this will help expose, though they don't currently trigger test failures.

The change is implemented via a simple Makefile addition setting NO_MMAP when address sanitization is enabled. This builds on the series' earlier patches (particularly patch 2's bitmap fix) and sets up for future bug detection. The author positions this as a proactive measure to improve testing rigor rather than fixing an immediate issue.
