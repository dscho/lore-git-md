This is a feature patch adding committer identity control to `git commit`, part of ZheNing Hu's ongoing effort to provide symmetry between author and committer controls. The patch introduces a new `--committer` option that mirrors the existing `--author` flag, allowing users to override the committer identity either directly ("Name <email>") or via a pattern search through commit history.

The implementation refactors existing author-handling code into shared `determine_identity()` and `find_identity_by_nickname()` functions that handle both author and committer cases through an `is_author` parameter. The patch includes thorough test coverage of the new functionality, including edge cases like pattern matching, environment variable interaction, and date handling.

This version (v3) drops a Co-authored-by trailer from v2 but is otherwise functionally similar. The change addresses a real workflow pain point - currently requiring environment variables to override committer info - and follows established patterns from the author side. The implementation looks solid, with careful attention to symmetry between author and committer handling and comprehensive tests. The mailing list discussion suggests this is converging toward acceptance after working through interface design questions.
