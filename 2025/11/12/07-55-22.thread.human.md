Jeff King's ASan fixes series has sparked a broader discussion about build system maintenance alongside its core memory safety improvements. The 9-patch series addresses various AddressSanitizer findings across Git's codebase, with several patches already receiving positive feedback - notably Patch 2's bitmap handling was validated by both Patrick Steinhardt and Taylor Blau, while Patch 3's NO_MMAP change for ASan builds has been confirmed in the traditional Makefile system.

A new dimension emerged regarding how to synchronize changes between Git's dual build systems (Makefile and Meson). Taylor Blau raised concerns about potential configuration drift, prompting Patrick Steinhardt to respond with a pragmatic stance - prioritizing keeping the Meson CI pipeline functional while accepting that specialized changes like NO_MMAP might lag. This exchange highlights the ongoing challenge of maintaining parallel build systems, though participants agree the discussion warrants more attention than this thread can provide.

Meanwhile, technical consensus is forming around Patch 4's cache-tree parsing, with both Taylor and Patrick now favoring reuse of the existing git_parse_int() pattern despite its known quirks. The series remains at v1, with Junio Hamano having noted the generalized parsing utility idea as interesting but making no commitments. While several patches are technically sound, the thread remains open pending resolution of both the build system policy question and minor documentation gaps in Patch 2.
