This is a refactoring patch in Junio C Hamano's series to improve handling of incomplete lines (missing newlines) in Git's diff output. It's part of a larger effort to standardize whitespace error handling across Git's diff and apply pipelines.

The patch focuses on the rewrite-diff codepath, which bypasses Git's normal xdiff machinery. Previously, this path used a special DIFF_SYMBOL_NO_LF_EOF token as a hack to handle incomplete lines. The change replaces this with proper handling that matches the behavior in other diff paths, using the standard DIFF_SYMBOL_CONTEXT_INCOMPLETE mechanism.

Key changes include:
- Removing the DIFF_SYMBOL_NO_LF_EOF enum and related special-case code
- Modifying emit_rewrite_lines() to properly handle incomplete final lines by allocating temporary buffers when needed
- Using the new emit_incomplete_line_marker() helper introduced earlier in the series
- Maintaining line counting behavior while cleaning up the implementation

This is a technical cleanup that makes the rewrite-diff path behave more consistently with the rest of Git's diff machinery, while preparing for future whitespace error handling improvements. The changes are well-contained (37 lines modified) and build on infrastructure introduced in earlier patches of the series.
