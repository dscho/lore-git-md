This is a cover letter for a 9-patch series addressing various ASan (Address Sanitizer) findings in Git's codebase. Jeff King (peff) presents a mix of bug fixes and code improvements uncovered by ASan's deeper inspection capabilities.

The series tackles several distinct issues: a security-reported cache-tree bug (though deemed low-risk), a real bug in new bitmap code, and several fsck improvements that address both false positives and legitimate code quality concerns. The patches also adjust build settings to enable more thorough ASan checking going forward.

Notable fixes include handling name-hash lookups in bitmaps correctly, avoiding string operations on non-string buffers in cache-tree, and cleaning up fsck's identity parsing code. The series is structured to keep the test suite passing at each step when building with SANITIZE=address.

The changes touch core areas like the pack-bitmap and cache-tree subsystems, plus fsck validation logic. While some fixes are straightforward, others like the fsck changes may be more controversial due to their code churn versus benefit tradeoff. The series appears well-organized and clearly motivated by real issues found through ASan instrumentation.
