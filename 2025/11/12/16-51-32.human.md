Maintainer follow-up on signature stripping in fast-import. This is part of an ongoing discussion about Christian Couder's patch series to add a 'strip-if-invalid' mode for signed commits in `git fast-import`.

Junio C Hamano confirms that Christian will address a test infrastructure issue in v2 of the series, where tests were failing due to dependencies on SHA-256 repositories that now require Rust support. The maintainer notes this signature-stripping functionality doesn't actually need dual-hash interoperability, so the tests can be restructured to avoid this dependency.

This email represents a brief acknowledgment that the test issue will be fixed in the next version, keeping the thread moving forward while the technical details of signature validation continue to be discussed. The core functionality remains unchanged from the initial proposal - allowing users to strip invalid signatures during history rewriting while preserving valid ones.
