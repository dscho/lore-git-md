This is patch 11/12 in Junio C Hamano's series implementing comprehensive handling of incomplete-line whitespace errors (WS_INCOMPLETE_LINE). The patch focuses on the diff side of the implementation, specifically teaching `git diff` to highlight and error out on incomplete lines.

The key changes in this patch:
1. Makes `git diff` highlight the "\ No newline at end of file" message as a whitespace error when WS_INCOMPLETE_LINE is enabled, using the standard whitespace error coloring
2. Teaches `git diff --check` to detect and report incomplete lines as whitespace errors
3. Adds extensive test coverage in t4015-diff-whitespace.sh for various incomplete line scenarios:
   - Incomplete lines in both pre- and post-image contexts
   - Incomplete lines being modified
   - Fixing incomplete lines in pre-image
   - Introducing new incomplete lines in post-image
4. Updates the ws-error-highlight tests to include incomplete line cases

The implementation builds on previous refactoring work (particularly patch 7/12 which unified the rewrite diff code paths) to handle incomplete lines consistently. The patch maintains the series' approach of treating "\ No newline" annotations as metadata while still enforcing the whitespace policy.

This completes the diff-side implementation of the incomplete line handling, complementing the apply-side work done in patch 10/12. The changes are well-contained and maintain backward compatibility while adding the new functionality.
