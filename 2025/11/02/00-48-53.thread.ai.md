CVE-2024-52005 security inquiry thread. Thomas Klausner initiated discussion about this vulnerability's status for pkgsrc packaging, noting NVD listed affected Git versions but lacked fix information, with only reference found in Git for Windows 2.47.1(2) release notes. Original open questions were which Git versions contain the fix and whether the vulnerability affects non-Windows platforms, referencing advisory ID GHSA-7jjc-gg6m-3329.

Brian M. Carlson provided the Git project's official position that this was incorrectly classified as a Git vulnerability. While Git for Windows listed it as a CVE, the Git project determined it was actually a terminal emulator bug (particularly affecting some Windows variants) allowing arbitrary binary execution when clicking hyperlinks created via terminal codes. The project considers this out of scope for Git's security model since URL clicks should never result in code execution regardless of context. This implies no Git versions contain a fix because none was needed in Git's codebase, resolving the cross-platform impact question - the issue is terminal-specific rather than Git-specific.

The response carries authority as it represents the project's consensus view, though it notes disagreement from Git for Windows maintainers. Key tracking elements remain CVE-2024-52005 and GHSA-7jjc-gg6m-3329, but with the clarification that these reference a Windows-specific terminal behavior rather than a Git security flaw. This likely concludes the thread's open questions unless Git for Windows maintainers choose to respond regarding their differing assessment.
