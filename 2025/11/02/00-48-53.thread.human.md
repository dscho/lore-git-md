This thread began with Thomas Klausner inquiring about CVE-2024-52005, a vulnerability listed in NVD that appeared to affect Git versions but lacked clear fix information. The initial discussion noted that only Git for Windows 2.47.1(2) release notes mentioned the issue, raising questions about cross-platform impact and which Git versions contained fixes.

Brian M. Carlson has now clarified the Git project's official position: this was misclassified as a Git vulnerability. The issue stems from certain terminal emulators (particularly on Windows) executing arbitrary binary code when users click hyperlinks generated via terminal codes. The Git project maintains this is a terminal emulator bug, not a Git security flaw, since URL clicks should never result in code execution regardless of context. This means no Git versions required a fix, and the issue is terminal-specific rather than Git-specific.

While Git for Windows had listed this as a CVE, the core Git project considers the advisory GHSA-7jjc-gg6m-3329 and CVE-2024-52005 out of scope for Git's security model. Unless Git for Windows maintainers choose to respond with their differing assessment, this authoritative response from a known Git contributor appears to resolve the thread's open questions.
