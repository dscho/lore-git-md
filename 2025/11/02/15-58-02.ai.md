Security clarification regarding CVE-2024-52005. This is a response to Thomas Klausner's inquiry about the vulnerability status, providing Git project's official position that this was incorrectly classified as a Git vulnerability.

Brian M. Carlson explains that while Git for Windows listed this as a CVE, the Git project determined it was not actually a vulnerability in Git itself. The issue involves terminal emulators (particularly some Windows variants) allowing arbitrary binary execution when clicking hyperlinks created via terminal codes. The Git project's position is that this is a terminal emulator bug, not a Git security flaw, since URL clicks should never result in code execution regardless of context.

Key technical details: the advisory GHSA-7jjc-gg6m-3329 and CVE-2024-52005 reference a Windows-specific terminal behavior that the Git project considers out of scope for Git's security model. The response implies no Git versions contain a "fix" because no fix was needed in Git's codebase. This appears to resolve the cross-platform impact question - the issue is terminal-specific rather than Git-specific.

The response carries authority as it comes from a known Git contributor and represents the project's consensus view, though it notes disagreement from Git for Windows maintainers.
