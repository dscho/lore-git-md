This is the final patch (13/13) in Patrick Steinhardt's v3 series refactoring Git's object database (ODB) abstraction. The patch introduces streaming write capability to the ODB layer, completing the encapsulation of loose object operations.

The patch adds a new `odb_write_object_stream()` function that provides a unified interface for writing large objects in chunks, matching the existing `odb_write_object()` for single-buffer writes. It renames the internal `stream_loose_object()` to follow the established `odb_source_loose_*` naming pattern as `odb_source_loose_write_stream()`. The changes are mechanical and maintain existing behavior while improving the API's consistency.

This completes the series' goal of properly abstracting loose object operations into the ODB interface. The changes touch several files including object-file.c, odb.c, and builtin/unpack-objects.c, updating callers to use the new interface. The patch follows the same high standard as previous patches in the series, with clear commit messages and mechanical changes that maintain backward compatibility.
