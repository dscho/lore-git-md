Refactoring patch in Patrick Steinhardt's ODB abstraction series. This is patch 2/13 in v3, introducing a new helper function `odb_source_new()` to centralize creation of ODB source objects.

The patch eliminates duplicate initialization code from three locations that create new object database sources, replacing them with calls to the new helper. The function handles memory allocation and basic field setup (path, ODB reference, and local flag) in one place. This is a straightforward cleanup that improves maintainability without changing behavior.

Changes touch odb.c (where the new function is implemented), odb.h (adding its declaration), and repository.c (converting existing initialization sites). The implementation follows the series' established patterns and appears mechanically sound. Reviewers have been positive about previous versions of this series, and this patch continues the incremental refactoring approach.

This is part of the larger effort to abstract Git's object database handling, making the codebase more maintainable and potentially enabling future pluggable backends. The patch doesn't introduce new functionality but helps pave the way for more significant changes later in the series.
