Feature patch series refinement for diff algorithm configurability in `git blame`. This is a review response for the first patch in the v4 series, which refactors xdiff internals to cleanly handle diff algorithm selection.

Phillip Wood reviews Antonin Delpeuch's patch that adds the 'minimal' diff algorithm flag to XDF_DIFF_ALGORITHM_MASK. The change simplifies the code by removing the need for separate clearing of the minimal diff bit when resetting algorithms. Phillip approves the improvement but suggests two minor follow-ups: removing the now-unused DIFF_XDL_CLR macro and reconsidering whether to keep the deleted comments about clearing previous settings.

The patch is part of a well-reviewed series that has gone through multiple iterations addressing technical feedback. This particular change enables cleaner implementation of the main feature - configurable diff algorithms in `git blame` - by properly unifying the algorithm flag handling in xdiff's internals. The review indicates the technical approach is sound and the patch is nearly ready, needing only those small documentation and cleanup tweaks.
