Refactoring patch completing Patrick Steinhardt's ODB abstraction series by adding streaming write support. This is the final patch (13/13) in v3 of the series, continuing the mechanical renaming and encapsulation work for loose object handling.

The patch introduces a new high-level `odb_write_object_stream()` function that provides a unified interface for streaming large objects to the ODB, mirroring the existing `odb_write_object()` for buffer-based writes. It renames the low-level implementation from `stream_loose_object()` to `odb_source_loose_write_stream()` to maintain consistency with the established `odb_source_loose_*` naming pattern from previous patches.

Key technical changes:
- New `struct odb_write_stream` replaces `struct input_stream` in the public API
- `odb.h` gains the new streaming write declaration
- `builtin/unpack-objects.c` updated to use the new interface
- All callers now go through the ODB abstraction layer rather than calling loose object functions directly
- Maintains identical behavior while improving encapsulation

The patch follows the series' established patterns for header organization, with loose object specifics in object-file.[ch] and ODB-wide declarations in odb.h. It completes the same mechanical refactoring approach seen in previous patches, with no behavior changes beyond the interface improvements.

This concludes the v3 series' work on loose object handling within the ODB abstraction effort. The changes maintain the same files touched throughout the series: object-file.c, odb.c, and their headers, plus updates to builtin/unpack-objects.c as a caller.
