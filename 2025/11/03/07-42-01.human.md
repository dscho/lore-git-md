This is part 6 of Patrick Steinhardt's ongoing refactoring series to abstract Git's object database handling. The patch moves the loose object cache from `struct odb_source` into the newly introduced `struct odb_source_loose`, better encapsulating loose object-related data. 

The change renames cache-related functions to use the `odb_source_loose_` prefix (e.g., `odb_loose_cache()` becomes `odb_source_loose_cache()`) while maintaining the same function signatures for future compatibility with pluggable backends. The patch touches several files but is purely a code organization change with no behavioral impact.

This continues the series' pattern of careful, incremental refactoring to prepare for pluggable ODB backends. The changes are mechanical but meaningful - each step moves state and logic into the appropriate abstraction layer. Reviewers have been consistently positive about the approach in previous patches.
