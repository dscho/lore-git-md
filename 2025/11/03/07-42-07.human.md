Refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series (12/13 in v3). This patch renames `write_object_file()` to `odb_source_loose_write_object()` to better reflect its role in the loose object backend and maintain consistency with the series' naming conventions.

The change is purely mechanical - updating the function name and its declarations in object-file.c, object-file.h, and odb.c. The new name follows the established `odb_source_loose_*` pattern used throughout the series for loose object operations. This continues the effort to clearly separate concerns between different object storage backends.

As with previous patches in the series, this maintains identical behavior while improving code organization. The change affects several core object-file operations but doesn't introduce any functional modifications. Reviewers have consistently approved similar naming changes in earlier patches, and this appears to follow the same uncontroversial pattern.

The patch is part of the broader effort to abstract Git's object database interface, with previous patches having already moved other loose object operations to similarly named functions. Only one patch remains in this version of the series after this change.
