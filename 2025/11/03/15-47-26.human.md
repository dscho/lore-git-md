Performance optimization for `git last-modified` that dramatically speeds up finding the most recent commit modifying each path. This is version 4 of a patch series that has undergone extensive review and benchmarking.

The new algorithm uses a priority queue sorted by generation number and tracks active paths (those not yet associated with a commit) using EWAH bitmaps. It avoids unnecessary diff computations by leveraging Bloom filters when possible and only processing relevant portions of history. Benchmark results show 2.5x-9.3x speedups on git.git and even greater improvements (5.3x-111.7x) on larger repositories like linux.git.

Key improvements in this version include fixing compiler warnings, memory leak fixes, and switching to CALLOC_ARRAY(). The implementation now consistently matches `git log --max-count=1` results, fixing a prior discrepancy with maintenance branch merges.
