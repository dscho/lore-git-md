This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's object database handling. It's patch 3/13 in the v3 iteration.

The change updates function names to match the current naming scheme for object source handling. The functions `free_object_directory()` and `free_object_directories()` are renamed to `odb_source_free()` and `odb_free_sources()` respectively, reflecting both the modern naming convention (subject-verb order) and the fact that the underlying structure was renamed from `object_directory` to `odb_source` in an earlier commit.

This is a mechanical change that doesn't affect behavior, just improves code consistency. The patch is straightforward - it updates the function names and all their call sites in odb.c. As part of the larger ODB abstraction effort, these naming changes help maintain a clear and consistent interface for object source management.

The patch appears well-contained and low-risk, with no functional changes beyond the renaming. It follows the naming patterns established earlier in the series and has already received positive feedback from reviewers in previous iterations.
