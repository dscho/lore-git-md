This is a bugfix for the macOS keychain credential helper that addresses an issue with credential storage skipping. The patch fixes a regression introduced in Git v2.46 where the credential helper would incorrectly skip storing valid credentials when they came from a different helper in the credential chain. The issue occurs because the helper was using a simple "seen" flag that didn't distinguish between credentials from different sources.

Koji Nakamaru's solution replaces the boolean flag with a more sophisticated state tracking mechanism that encodes the actual credential details (host, port, path, username, and password) when marking a credential as "seen". This allows the helper to properly determine whether a subsequent store operation should be skipped by comparing the full credential details rather than just checking a flag.

The patch includes significant changes to the credential encoding logic, adding new string buffer handling utilities and credential serialization functions. It maintains backward compatibility while fixing the core issue. Junio Hamano helped with the solution, and the bug was reported by Petter Sælen.

This appears to be a well-constructed fix for a real-world problem that could affect users relying on multiple credential helpers. The changes are focused and include all the necessary components without introducing obvious new issues.
