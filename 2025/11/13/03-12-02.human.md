This is a side discussion in the ASan fixes thread, touching on build system maintenance between Makefile and Meson.

Taylor Blau raises an important meta-question about build system synchronization while responding to Patrick Steinhardt's suggestion to mirror a Makefile ASan change in Meson. The core patch (from Jeff King) adds NO_MMAP to the Makefile when building with ASan, which Patrick correctly notes should have a Meson counterpart.

Taylor doesn't oppose the technical change but uses the opportunity to surface a broader policy question: how strictly should we maintain parity between the two build systems, given that not all contributors may be equally comfortable with both? He positions this as an open question rather than a complaint, inviting discussion about long-term maintenance strategy.

The thread context shows this is part of a well-advanced ASan hardening series where most technical aspects have been validated, making this a natural time to discuss process questions. While the immediate build system change is straightforward, Taylor's comment may spark useful discussion about contributor expectations and documentation around dual-build maintenance.
