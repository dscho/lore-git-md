This is a release announcement for Git for Windows 2.52.0-rc2, the Windows-specific distribution maintained separately from upstream Git. Johannes Schindelin (the Git for Windows maintainer) announces this pre-release version, which updates key dependencies: it incorporates upstream Git v2.52.0-rc2, PCRE2 v10.47, and cURL v8.17.0. The installer has been rebuilt with InnoSetup 6.6.0, continuing the modernization of the build toolchain. The release maintains the recent policy of not supporting git-svn in Git for Windows. SHA-256 checksums are provided for all distribution formats (64-bit/ARM64 installers, portable versions, and MinGit variants), enabling verification of downloaded artifacts. This appears to be a routine maintenance release keeping pace with upstream dependencies rather than introducing new Windows-specific features.
