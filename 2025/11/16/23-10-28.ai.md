This is a CI/build system patch addressing platform compatibility for macOS CI jobs. The change switches from using an x86-64 Perforce binary to an arm64 version when running tests on GitHub Actions' macOS-14 runners.

The patch follows up on a recent transition to macOS-14 CI images, which use arm64 architecture. While x86-64 binaries can run through Rosetta emulation, the change notes this was causing increased test failures in the t98xx test series (Perforce-related tests). The solution is to use native arm64 Perforce binaries instead.

The technical change is straightforward - updating the download URL in ci/install-dependencies.sh to fetch the arm64 version (macosx12arm64) rather than the x86-64 version (macosx1015x86_64) of the helix-core-server package. The rest of the installation process (unpacking, quarantine flag removal) remains unchanged.

Key points for future reference:
- Affects macOS CI jobs using Perforce (t98xx tests)
- Changes Perforce binary download from x86-64 to arm64 variant
- Follows GitHub Actions' transition to arm64-based macOS-14 runners
- Addresses increased test failures in Perforce tests
- The change is co-authored with Koji Nakamaru
