This is a follow-up discussion in Kiril Ivanov's bash prompt quiet mode series, addressing shell compatibility concerns raised by Junio C Hamano. The thread had previously established that the feature was bash-specific, but Ivanov now notes the prompt code actually supports multiple shells (zsh, dash, BSD sh, etc.) as shown by historical modifications.

The key new information is that:
1. The test script currently runs successfully under plain `sh` despite using bash-isms
2. Ivanov attempted but struggled to rewrite the test's parameter handling in a more portable way while maintaining its matrix-style test structure
3. He's seeking input from more experienced shell scripters on whether/how to make the tests portable
4. Given the unexpected complexity, he's reconsidering the priority of this change versus waiting for broader interest confirmation

This doesn't change the core functionality of the quiet mode feature from the original series, but surfaces a new maintainability consideration about shell compatibility in the test implementation. The discussion now has an open question about whether to:
- Keep the bash-isms (accepting they're inappropriate for a nominally multi-shell feature)
- Invest in portable test rewrites
- Or potentially reconsider the feature's scope/shell targeting

The thread remains at version 1 of the patches while this design question is explored.
