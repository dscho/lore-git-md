This is a CI/build system patch that updates the macOS GitHub Actions configuration to use an arm64 binary for Perforce (p4) instead of the x86-64 version. 

The change comes after switching from the deprecated macos-13 image to macos-14, which uses ARM architecture. While the x86-64 binary could still run (via Rosetta 2 emulation), the patch switches to the native arm64 version to improve reliability. The commit message notes this was causing intermittent test failures in the t98xx test series (Perforce-related tests).

The change is straightforward - it modifies the download URL in ci/install-dependencies.sh to fetch the arm64 binary (macosx12arm64) instead of the x86-64 one (macosx1015x86_64). The patch includes a Helped-by credit to Koji Nakamaru and appears to be a well-justified, low-risk maintenance update to keep CI working smoothly on the newer macOS runners.
