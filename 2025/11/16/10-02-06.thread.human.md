This thread documents the first round of translation updates for the upcoming Git 2.52.0 release, coordinated by Jiang Xin. The updates cover 10 languages (Bulgarian, French, Irish, Indonesian, Swedish, Turkish, Ukrainian, Vietnamese, and both Chinese variants) with substantial changes - over 13,000 lines added and 9,000 removed across the translation files in Documentation/po/. 

Jiang Xin reviewed and signed off on all the changes before submitting them, following Git's standard localization workflow where translations are batched before a release. Maintainer Junio Hamano has now pulled these updates into the main repository as part of the final preparations for Git 2.52.0. The changes are purely translation updates with no modifications to core functionality. This exchange demonstrates the smooth collaboration between localization contributors and the maintainer that occurs during each release cycle.
