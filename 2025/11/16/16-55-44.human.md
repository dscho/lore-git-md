Junio Hamano acknowledges Kiril Ivanov's correction about shell compatibility in the bash prompt quiet mode patch series. 

This is a follow-up in the ongoing discussion about test portability for the bash prompt feature. While the original implementation was bash-specific, Ivanov discovered the prompt code historically supports multiple shells (zsh, dash, BSD sh, etc.) and that the test script actually runs under plain sh despite containing bash-isms. 

Hamano agrees with Ivanov's assessment that the bash-isms in the test script are undesirable given the multi-shell support, retracting his earlier assumption that bash-specific tests would be acceptable. The exchange highlights the need to either make the tests properly portable or reconsider how the feature targets different shells.

The core functionality of the quiet mode feature remains uncontested, but this clarification about the prompt's broader shell support adds complexity to the test implementation requirements. The thread continues to weigh the priority of test portability against the feature's usefulness.
