Thread identity: CI/build system patch addressing macOS CI compatibility for Perforce tests, co-authored by Koji Nakamaru.

Core problem: Recent transition to arm64-based macOS-14 CI runners caused increased test failures in Perforce-related tests (t98xx series) due to running x86-64 Perforce binaries through Rosetta emulation.

Technical solution: Updates ci/install-dependencies.sh to download native arm64 helix-core-server package (macosx12arm64) instead of x86-64 version (macosx1015x86_64). Installation steps (unpacking, quarantine flag removal) remain unchanged.

Current status: Proposed solution to CI reliability issue, follows GitHub Actions' platform transition. References earlier discussion about CI image changes (CAOTNsDwS2er...).

- Specifically affects t98xx test series (Perforce integration)
- Maintains same installation process, only changes binary architecture
