Junio Hamano responds to Koji Nakamaru's proposal about fixing macOS CI Perforce test failures by switching to arm64-native binaries. This is part of the ongoing discussion about CI reliability, where Junio had previously suggested removing the tests entirely.

Junio acknowledges Nakamaru's explanation that the current x86_64 binaries require Rosetta translation on arm64 runners, and agrees that testing on native architecture makes sense. He notes that while they could alternatively use the older x86_64 runners (macos-14-large), testing on newer Apple silicon hardware is probably better.

The response raises one question about the version bump from r23.2 to r24.2 - Junio wonders if there was a specific reason for choosing this version rather than the latest (r25.1) or keeping r23.2 (which also has arm64 binaries). He notes this change would affect Ubuntu builds too since they pull from the same Perforce distribution site.

The exchange shows progress toward a solution, with Junio appearing receptive to the architecture fix but wanting to understand the version selection better. The thread now has two viable paths forward (Nakamaru's arm64 fix or Junio's original removal proposal), with the discussion shifting to implementation details of the fix.
