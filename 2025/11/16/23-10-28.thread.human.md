This thread addresses a CI compatibility issue for Perforce tests on GitHub Actions' macOS-14 runners, which recently transitioned to arm64 architecture. The initial patch identified that using x86-64 Perforce binaries via Rosetta emulation was causing increased test failures in the t98xx test series.

The solution, co-authored by the original contributor and Koji Nakamaru, updates ci/install-dependencies.sh to download native arm64 Perforce binaries (macosx12arm64) instead of the x86-64 version. The change is minimal - just modifying the download URL while keeping the existing installation steps. This should resolve the test failures while maintaining the same functionality.

The patch builds on prior discussions about CI image changes and represents a straightforward fix for a specific platform compatibility issue. There are no outstanding questions or objections noted - it appears ready for integration as a maintenance improvement to keep the macOS CI jobs reliable.
