Bugfix and refactoring patch converting fsck's timestamp parsing to use the new buffer-safe utilities. This is the final patch in Jeff King's 12-part ASan hardening series, building on the recently introduced `parse_unsigned_from_buf()` helper.

The patch replaces fsck.c's custom timestamp parser with the new generalized utility, eliminating a temporary buffer copy while maintaining the same overflow detection. The key changes are:
1. Adds a `parse_timestamp_from_buf` macro in compat/posix.h that wraps `parse_unsigned_from_buf` with timestamp_t typing
2. Simplifies fsck_ident() by removing the local parse_timestamp_from_buf() function
3. Updates the call site to use the new interface, which requires storing the timestamp in a local variable before checking for overflow

The conversion follows the pattern established earlier in the series - replacing ad-hoc parsing with the new utilities while preserving behavior. The patch demonstrates the parsing utilities' applicability to real-world cases beyond their initial introduction. With this change, the series now covers all planned conversions of buffer parsing in core Git code to the safer interfaces.

Technical details of note:
- Maintains identical overflow checking via TIME_MAX comparison
- Keeps existing error reporting through fsck's report() mechanism
- Preserves all current validation rules (zero-padding, whitespace requirements)
- The macro abstraction handles timestamp_t's typedef nature while reusing the unsigned parser
- No functional changes to fsck checks or output
