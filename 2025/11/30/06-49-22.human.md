This is a platform compatibility patch in Johannes Schindelin's series improving Windows symlink support in Git's test suite. Junio Hamano provides a review of patch 3/10, which fixes how Windows handles `open()` calls on dangling symlinks with `O_CREAT|O_EXCL` flags.

The patch makes Windows behave like POSIX systems by ensuring `open()` fails with EEXIST when given these flags on a symlink, rather than creating the target file. This fixes test t4115.8 which expects POSIX behavior. Junio suggests more precise wording ("POSIX" rather than "Linux") in the commit message and notes the behavior should apply to any existing path, not just symlinks, per the POSIX spec.

The review is technical but constructive, focusing on accuracy in describing the standard behavior rather than questioning the change itself. This continues the pattern seen in earlier patches where Junio provides precise technical feedback while accepting the practical need for Windows-specific workarounds. The exchange shows careful attention to both POSIX compliance and Windows compatibility requirements.
