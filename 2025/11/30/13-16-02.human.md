This is a bugfix patch that's part of Jeff King's ongoing series addressing ASan findings and improving parsing safety in Git. It converts fsck's timestamp parsing to use the new `parse_unsigned_from_buf()` utility function introduced earlier in the series.

The patch replaces a custom timestamp parsing function in fsck.c with a more robust implementation that uses the shared parsing utilities. The key improvements are:

1. It eliminates a local buffer copy that was previously needed to NUL-terminate the timestamp string before parsing.
2. It maintains the same overflow checking behavior but does so more directly through the new parsing function.
3. It introduces a macro in compat/posix.h to handle the timestamp_t typedef abstraction cleanly.

The change is relatively straightforward, converting 20 lines of custom parsing code down to a 5-line utility call while maintaining the same interface and safety checks. This follows the pattern seen in earlier patches of the series where specialized parsing code is replaced with the new generalized utilities.

The patch appears well-constructed and fits naturally into the series' goal of making Git's parsing more robust against buffer overflows and integer overflows. Since it's part of an already-reviewed series that Junio Hamano has approved for integration, it seems likely to be accepted.
