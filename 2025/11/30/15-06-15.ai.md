This is a UI improvement patch for `git add -p`'s interactive hunk selection interface. The change adds visual feedback showing whether the current hunk is selected or deselected when navigating between hunks with K/J keys.

The patch modifies the prompt string in `add-patch.c` to include a state indicator (`[selected]` or `[deselected]`) when showing hunk prompts. The implementation checks the `hunk->use` flag to determine the current state, adding this information only for hunk-level prompts while leaving other prompt types unchanged. The change was requested by Junio C Hamano to address the lack of visual feedback during navigation.

The technical changes involve:
1. Adding a format placeholder `%s` to the hunk prompt string
2. Introducing conditional logic in `patch_update_file()` to:
   - Check if the prompt is for a hunk (PROMPT_HUNK)
   - Determine selection state via `hunk->use` (USE_HUNK/SKIP_HUNK)
   - Pass the state string to the prompt
3. Maintaining existing behavior for non-hunk prompts

The patch is focused and well-contained, touching only the necessary parts of the interactive add flow. The change should help users better track their selection state during interactive staging sessions.
