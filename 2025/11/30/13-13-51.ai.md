This is a refactoring and safety improvement series that introduces more robust integer parsing functions for buffer inputs, building on the ASan hardening work. The discussion has evolved from the cache-tree parsing safety debate to focus on generalizing the parsing utilities.

The series introduces new functions in parse.c for safely reading integers from buffers (parse_int_from_buf() and parse_unsigned_from_buf()), converting two existing call sites (cache-tree.c and fsck.c) to use them. The new functions handle overflow checking and buffer bounds more rigorously than the previous ad-hoc implementations. The implementation makes some assumptions about two's complement representation but documents them clearly.

Key technical details include:
- New parse.c functions that validate input bounds and numeric ranges
- Unit tests for the new parsing functions (t/unit-tests/u-parse-int.c)
- Conversion of cache-tree's entry parsing to use parse_int_from_buf()
- Conversion of fsck's timestamp parsing to use parse_unsigned_from_buf()
- Maintains compatibility with strict_string_checks
- Build system updates to include the new unit test
