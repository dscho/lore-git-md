This is a periodic announcement about the Git Rev News publication, which summarizes recent Git development activity.

Christian Couder shares a draft of the upcoming Git Rev News edition 129, inviting community contributions before its planned December 2nd publication. The draft is available on GitHub for direct editing via pull requests, and feedback can also be provided through a GitHub issue or by replying to this email.

The announcement emphasizes that all types of contributions are welcome, including proofreading, content suggestions, and volunteering for interviews. The author notes they've attempted to notify all contributors featured in this edition but acknowledges they may have missed some people.

This follows the standard format for Git Rev News draft reviews, providing multiple avenues for community input before final publication. The collaborative nature of the process is highlighted, with several maintainers (Jakub, Markus, Kaartic) involved in the final publication.
