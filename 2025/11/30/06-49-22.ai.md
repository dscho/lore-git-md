This is a platform compatibility patch in Johannes Schindelin's 10-part series improving Windows symlink handling in Git's test suite. The patch specifically addresses how `_wopen()` behaves with dangling symlinks under `O_CREAT|O_EXCL` flags on Windows currently creates the target file when opening a dangling symlink with these flags, while POSIX expects an `EEXIST` error. The fix adds a check in `mingw_open()` that detects symlinks via `GetFileAttributesExW()` and returns `EEXIST` to match POSIX behavior, allowing test t4115.8 to pass when MSYS2 enables symlink support.

Junio Hamano suggests more precise terminology in the commit message, noting the behavior should be described as matching POSIX rather than specifically Linux. He also clarifies that the POSIX requirement applies to any existing path, not just symlinks, though the current implementation only handles the symlink case needed for the test. The patch follows the series' pattern of making Windows behavior match POSIX expectations where tests depend on it, while preserving existing behavior for non-Windows platforms.
