Bug report: `git diff --max-depth` fails with merge commits when depth limit causes tree objects to be incorrectly treated as blobs. Reproduction shows fatal error "object '...' is not a blob!" at specific depth thresholds (--max-depth=5 for root diff, --max-depth=4 from subdirectory), while deeper limits (--max-depth=6) work. Expected behavior would show combined diff or no output rather than error. Issue appears platform-independent, reported on Windows with Git 2.52.0 but likely affects all platforms. Clear reproduction steps provided.
