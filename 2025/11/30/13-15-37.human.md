This is part 2 of Jeff King's 4-patch series introducing new parsing utilities for non-NUL-terminated buffers, building on earlier ASan-related work. The patch adds three new functions to parse.c for safely reading integers from buffer segments: `parse_unsigned_from_buf()`, `parse_signed_from_buf()`, and `parse_int_from_buf()`.

The new functions address a common problem - parsing integers from buffers that aren't strings (like binary formats) where using traditional string parsing functions would be unsafe or trigger ASan warnings. The implementation carefully handles overflow detection, whitespace, and sign characters while providing a clean interface that returns success/failure via bool and results via out-parameters.

Jeff provides extensive rationale for the design decisions, including why he chose direct digit parsing over buffering approaches, the bool return convention, and the strtol()-like end pointer behavior. The patch includes thorough unit tests covering edge cases and error conditions, and integrates with both Makefile and Meson build systems.

This looks like a well-considered addition to Git's parsing utilities, with clear motivation (safety and code reuse) and careful attention to edge cases. The implementation appears robust and the extensive test coverage gives confidence in its correctness. As part of an already-reviewed series, this seems ready for inclusion.
