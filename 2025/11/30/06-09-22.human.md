This is a platform compatibility patch in Johannes Schindelin's series improving Windows test suite support for symbolic links. The patch fixes a remaining instance in t0301-credential-cache.sh where `mkdir -m` is used - a known Windows incompatibility that was previously addressed in commit 0fdcfa2f9f5.

The change splits the directory creation and permission setting into two steps (`mkdir -p` followed by `chmod 700`) to work around Windows' more complex permission system. While Junio Hamano questions why Windows can't emulate the simpler POSIX permissions, he acknowledges the practical solution and suggests adding a test linter rule to catch such cases automatically in the future.

The patch was previously hidden by a `SYMLINK` prerequisite that prevented the test from running on Windows, but becomes necessary with the upcoming Windows symlink support. The change maintains identical behavior on non-Windows platforms while fixing the Windows-specific issue. This is a straightforward fix that aligns with the series' goal of preparing the test suite for proper Windows symlink support.
