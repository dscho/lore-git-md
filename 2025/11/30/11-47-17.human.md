Performance optimization in the diff-index machinery. This patch from René Scharfe streamlines how Git handles unchanged file pairs when the `--find-copies-harder` flag is used. Currently, Git unnecessarily allocates duplicate filespecs and performs extra work for unchanged files in this mode.

The patch introduces a new `diff_same()` function that handles unchanged file pairs more efficiently by using a single filespec with reference counting. Benchmark results show a 33% speed improvement when running `git diff --cached --find-copies-harder` on the Linux kernel repository.

This is version 2 of the patch, with a clarified commit message about memory usage. The changes are focused on the diff machinery, touching `diff-lib.c`, `diff.c`, and `diff.h`. The optimization is particularly noticeable in large codebases with many unchanged files.
