This is a feature patch adding a common command-line flag to `git-repo-structure` for consistency with other Git commands.

The patch introduces `-z` as an alias for `--format=nul` in `git repo structure`, matching the behavior of similar commands like `git-config` and `git-status` that use null-terminated output. The change involves documentation updates, adding the option parsing callback in the C code, and a new test case verifying the behavior.

The implementation is straightforward, copying the existing `OPT_CALLBACK_F` pattern from `git-repo-info` since both commands share the same format parser.
