This thread introduces a new `--committer` option for `git commit` to provide symmetry with the existing `--author` option, addressing an interface gap where committer identity could previously only be set via environment variables. The initial patch series (v1) from the author adds this functionality in `builtin/commit.c` with comprehensive test coverage and documentation.

Patrick Steinhardt has reviewed the patch, offering constructive feedback while agreeing with the feature's utility. His main suggestions include reordering the option in documentation to group it with `--author`, refactoring to reduce code duplication between committer and author handling functions, and reconsidering whether commit lookup should search by committer rather than author when given a pattern. He also noted some minor style nits regarding brace usage.

The review doesn't raise fundamental objections but identifies several areas where the implementation could be improved in a revision. The patch appears to be on a good trajectory, with the core functionality well-received and the feedback focused on refinement rather than redesign. The author will likely send a v2 addressing these points, particularly the code organization suggestions which could make the change more maintainable long-term.
