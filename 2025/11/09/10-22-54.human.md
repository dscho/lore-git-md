Feature: New `--committer` option for `git commit` to match existing `--author` functionality.

ZheNing Hu proposes adding a `--committer` option to `git commit`, mirroring the existing `--author` flag. Currently, overriding the committer identity requires setting `GIT_COMMITTER_NAME` and `GIT_COMMITTER_EMAIL` environment variables, which the patch argues is less convenient than a direct command-line option, especially for scripting and identity switching scenarios.

The implementation follows the same pattern as `--author`, accepting the standard "Name <email>" format and supporting both direct specification and pattern matching against existing commits. The patch includes thorough documentation updates and extensive test coverage (80 new lines of tests) that verify the basic functionality, edge cases, interaction with environment variables, and combination with other flags like `--amend` and `--date`.

This appears to be a well-considered addition that fills a clear gap in the command's interface. The symmetry with `--author` makes the change intuitive, and the implementation looks clean, reusing existing patterns. The comprehensive test suite suggests the contributor has carefully considered various usage scenarios.
