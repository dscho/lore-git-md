This is a feature patch adding a new `--committer` option to `git commit` to mirror the existing `--author` functionality. The patch introduces a symmetrical way to override the committer identity without using environment variables, addressing an inconsistency in the command's interface.

The implementation follows the same pattern as `--author`, accepting both explicit "Name <email>" format and pattern-based lookup of existing commits. It handles edge cases like malformed input, environment variable precedence, and interaction with other options like `--amend` and `--date`. The patch includes comprehensive tests covering basic functionality, error cases, and interactions with existing features.

Key technical details:
- Adds `--committer` parameter parsing in `builtin/commit.c`
- Implements `determine_committer_info()` mirroring `determine_author_info()`
- Updates documentation in `Documentation/git-commit.adoc`
- Adds 8 new test cases in `t/t7509-commit-authorship.sh` covering:
