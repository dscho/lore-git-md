This is a bugfix patch series that addresses misaligned output in Git's repository structure display when showing UTF-8 characters, particularly CJK (Chinese/Japanese/Korean) text. The issue occurs because the current implementation uses simple printf() width formatting that doesn't properly account for multi-byte character widths.

The first patch adds new unit tests specifically for UTF-8 width calculations with CJK characters, while the second modifies the stats_table_print_structure function to use strbuf_utf8_align() for proper column alignment. The author notes they used AI coding tools (Claude Code and Gemini-CLI) to help generate the commits, with proper attribution via Co-developed-by trailers.
