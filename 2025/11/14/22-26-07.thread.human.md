This thread tracks the development of an experimental `git history` command for rewriting history, as reported in Junio C Hamano's "What's cooking" status update. The feature has seen positive reception from multiple contributors, with D. Ben Knoble previously praising the "reword" subcommand's utility while noting some areas needing further testing. 

Phillip Wood has now weighed in with additional support, particularly appreciating how the command builds on existing `git replay` infrastructure rather than introducing new components - a design choice that aligns with the ongoing `the_repository` removal effort. While Wood hasn't completed reviewing the full series yet, their initial feedback reinforces the feature's architectural soundness. The command appears to be gaining momentum, with no substantive objections raised so far, though some implementation details around the "split" functionality remain to be fully vetted.
