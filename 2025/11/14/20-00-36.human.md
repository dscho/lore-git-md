This is a CI/build system issue affecting Git's test infrastructure. Phillip Wood reports that Ubuntu-based CI jobs are failing because their version of `sudo` no longer supports the `--preserve-env` flag, which Git's test scripts rely on. The error appears to stem from Ubuntu switching to a Rust implementation of `sudo`.

The immediate concern is finding a workaround - either ensuring the C version of `sudo` gets installed instead, or potentially switching to using `runuser` as an alternative. The email includes a link to the failing CI run for reference. This appears to be an urgent but straightforward compatibility issue that needs addressing to unblock CI testing.
