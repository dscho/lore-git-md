This is a documentation patch improving cross-references in the `git-commit` man page. Kristoffer Haugsbakk notices that several options (`--branch`, `--long`, and `--null`) reference status-related behavior without properly linking to `git-status(1)`, while similar options like `--short` do include such links.

The patch adds missing links to `git-status(1)` for these options and clarifies that `--long` uses the same format as `git-status`'s default output. It also replaces a vague reference to "status" with a proper `linkgit` macro for `--null`. The changes are straightforward and improve documentation consistency, though the commit notes suggest the author initially focused only on `--long` before expanding scope to related options. The patch appears well-researched, with references to historical commits that introduced these options.
