This is a CI infrastructure proposal regarding Perforce testing on macOS. Junio Hamano observes that macOS CI jobs running the t98xx (Perforce-related) tests are failing at an unusually high rate, while other platforms remain stable. The failures appear unrelated to recent Git changes, and there's been no community reports of macOS-specific Perforce issues.

The patch proposes removing Perforce test installation from macOS CI jobs entirely. The rationale is threefold: the tests are flaky without clear cause, macOS tests are already slow (making failures costly), and there's no evidence macOS users are actually using Perforce with Git. The change would simply stop downloading and installing the helix-core-server binaries during macOS CI setup.

The tone is pragmatic but slightly frustrated ("save cycles, electricity, and my sanity"), suggesting this has been an ongoing pain point. Since the proposal comes from the Git maintainer and targets a niche use case (Perforce on macOS) that appears unmaintained, it seems likely to be accepted unless macOS/P4 users speak up. The change is straightforward - just removing installation steps without needing deeper test infrastructure modifications.
