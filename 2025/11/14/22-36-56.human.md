This is part 10/10 of Ezekiel Newren's xdiff refactoring series, focusing on type safety improvements for Rust FFI compatibility. The patch renames the `rindex` field in the `xdfile_t` struct to the more descriptive `reference_index`, completing the type modernization work started in earlier parts of the series.

The change is straightforward - it updates all references to `xdf->rindex` to use the new `reference_index` name instead, along with the corresponding struct definition in `xtypes.h`. The field's type was already converted to `size_t` in part 9, so this patch focuses purely on the naming improvement.

As with previous patches in the series, this maintains backward compatibility while improving code clarity. The new name better reflects the field's purpose of mapping between compacted array indices and the original file lines they reference. The change affects multiple xdiff components including the core algorithm (`xdiffi.c`) and preparation code (`xprepare.c`).

This concludes the current series, which has systematically modernized xdiff's type system while preserving behavior across all diff strategies. The work has been reviewed by FFI experts and maintains Git's cross-platform compatibility.
