This is a bugfix for the Meson build system's handling of the `git-contacts` Perl script in the contrib directory. The patch addresses an issue where the script wasn't being marked executable during installation, causing the "git contacts" command to fail with a "not a git command" error.

D. Ben Knoble's solution modifies `generate-perl.sh` to explicitly include `git-contacts` in the case statement that sets executable permissions, similar to how `.perl` files are handled. The patch is version 2 of a previous submission, with a minor typo fix in the commit message ("install" -> "installing") as noted by reviewer Patrick Steinhardt.

The change is straightforward - it adds a pattern match for `*git-contacts` alongside the existing `.perl` check in the permission-setting case statement. This ensures the script gets proper executable permissions regardless of its installation path.
