This is a documentation patch that establishes type mapping guidelines for C/Rust FFI interoperability, part of Ezekiel Newren's completed xdiff refactoring series. The patch introduces a new technical document `unambiguous-types.adoc` that provides detailed specifications for type conversions between C and Rust, particularly focusing on edge cases and platform-specific considerations.

The document covers boolean, integer, floating-point, size, and enum types, with special attention to problematic areas like character types (where C's `char` has ambiguous signedness) and Rust's `std::ffi::c_*` types (which have version/platform-dependent definitions). It warns about subtle behavioral differences in operations like subtraction and bit-shifting across platforms, and provides specific recommendations for FFI-safe type usage.

Build system integration is handled via additions to both Makefile and meson.build. The documentation represents the culmination of prior technical discussion in the thread, incorporating feedback from Patrick Steinhardt and Phillip Wood about FFI safety and cross-platform compatibility. This foundational document will serve as a reference for future Rust FFI work in the Git project.
