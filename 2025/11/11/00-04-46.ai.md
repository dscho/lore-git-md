Refactoring patch in Junio C Hamano's whitespace handling series, focusing on rewrite-diff output consistency. This patch (7/12) cleans up how the rewrite-diff codepath handles incomplete lines (missing newlines) by removing a special-case hack and aligning it with the standard diff output path. The key changes are:

1. Removes the DIFF_SYMBOL_NO_LF_EOF enum and its special handling code, which was a workaround for the rewrite-diff path bypassing xdiff machinery
2. Modifies emit_rewrite_lines() to properly handle incomplete final lines by:
   - Allocating and modifying temporary buffers when needed
   - Using the same DIFF_SYMBOL_CONTEXT_INCOMPLETE path as normal diffs
   - Setting last_line_kind for accurate line counting
   - Calling the new emit_incomplete_line_marker() helper
3. Updates the test infrastructure to verify this behaves correctly

The change makes the rewrite-diff output consistent with regular diff output when files lack terminating newlines, while removing special-case code. This is part of the larger effort to standardize whitespace error handling across Git's diff/apply pipeline, with particular attention to the "\ No newline at end of file" case. The patch demonstrates careful attention to edge cases in the output formatting while simplifying the code structure.
