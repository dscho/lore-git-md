Refactoring patch in Ezekiel Newren's xdiff modernization series. This is part 7/10 of the effort to update xdiff's type system for Rust FFI compatibility.

The patch changes the `nrec` field in `xdfile_t` from `long` to `size_t`, as this field tracks the number of records in diff operations and should use the standard size type for array indexing. The change is mechanical but touches many files (xdiffi.c, xemit.c, xmerge.c, xpatience.c, xprepare.c) where explicit casts are added to maintain compatibility with existing code that expects `long` values.

This continues the series' pattern of using more precise types while preserving behavior through careful interface boundary management. The change is well-contained and follows the established approach of the series, with thorough updates to all affected algorithms and clear justification in the commit message.
