This is a follow-up to the Meson build system enhancement for HTML documentation path configurability, addressing a minor style request from the previous discussion. The patch makes `GIT_HTML_PATH` configurable in Meson builds, matching existing Makefile functionality that allows packagers to customize HTML doc locations (particularly useful for Gentoo's version-specific doc directories).

The technical implementation remains unchanged from the previous version - it adds a `htmldir` Meson option defaulting to `datadir/doc/git-doc` and updates 7 build files to use this configurable path. The only difference is that Ben Knoble has now reordered the options in meson_options.txt lexicographically as suggested by Patrick Steinhardt in the earlier review.

The patch appears ready for inclusion, with all substantive technical discussion already resolved. The thread is currently in a holding pattern waiting either for this version to be accepted as-is or for a post-release v2 (though this version already incorporates the requested change). The implementation has been validated against Gentoo packaging requirements and maintains feature parity with the Makefile build system.
