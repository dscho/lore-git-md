This is the cover letter for Junio C Hamano's v3 patch series introducing the "incomplete-line" whitespace error class (WS_INCOMPLETE_LINE = 0x8000) to detect missing terminating newlines in files. The series has now been merged after extensive review, with this cover letter documenting the final state.

The series adds configurable detection of missing newlines through `core.whitespace` and `.gitattributes`, handling "\ No newline at end of file" cases consistently across Git's diff/apply pipeline. The implementation spans 12 patches with infrastructure cleanups (01-09), apply-side implementation (10/12), diff-side implementation (11/12), and project-wide enablement limited to source files (12/12).

Key technical aspects include extended handling in ws.c, apply.c, and diff.c, with comprehensive test coverage (150+ lines in t4015). The series distinguishes between pre-existing incomplete lines (not considered errors) versus newly introduced ones (flagged as errors). Documentation files are explicitly excluded from checks.

The v3 changes refine the implementation with better function naming (`emit_incomplete_line_marker`), consolidated conditionals, and enhanced test coverage that now verifies `diff --check` output. The thread shows all major questions resolved, with only minor stylistic points (like test construction methods) discussed post-merge. The implementation represents a complete solution to a long-standing whitespace handling gap in Git's tooling.
