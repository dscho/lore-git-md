This is a completed 12-patch series introducing a new whitespace error class for missing terminating newlines in files. The series has already been merged and represents the culmination of work to detect and handle incomplete lines consistently across Git's diff/apply pipeline.

The core change adds `WS_INCOMPLETE_LINE` (0x8000) to the whitespace error classes, configurable via `core.whitespace` and `.gitattributes`. The implementation carefully distinguishes between cases where:
- A context line lacks a newline (not considered an error since it existed in the original)
- A post-image line lacks a newline (considered an error since the patch author modified it)

The series follows a clear progression from infrastructure cleanups (patches 1-8), to the new feature implementation (9-11), culminating in project-wide enablement for C/shell files (12). Notable technical aspects include updates to ws.c, apply.c, and diff.c, plus extensive test coverage (150+ lines in t4015).

This v3 iteration incorporates several refinements based on review feedback, including:
