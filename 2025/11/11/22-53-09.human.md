This is a refactoring patch in Ezekiel Newren's xdiff modernization series, specifically addressing type safety for Rust FFI compatibility. The patch changes `xrecord_t.ptr` from `char*` to `uint8_t*` to better represent its role as a byte pointer, with corresponding updates across xdiff's codebase.

Junio Hamano provides maintainer feedback on the implementation details, noting that while the changes are correct, some approaches could be clearer. He points out that casting to `char` rather than changing variable types might make the safety reasoning more obvious in some cases, and observes that the `long` type for `crec->size` will likely be updated in a future patch. The review confirms the changes are behavior-preserving and properly documented.

This is patch 3/10 in a completed series that has already received substantial review from multiple contributors.
