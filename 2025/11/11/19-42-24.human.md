This is a refactoring patch from Ezekiel Newren's xdiff modernization series, which has already been merged. The patch changes the type of `dstart` and `dend` fields in `xdfile_t` from `long` to `ptrdiff_t`, which is more appropriate for pointer offsets. 

The change is straightforward and well-motivated - `ptrdiff_t` is the correct type for pointer arithmetic results. The patch also reorganizes the struct fields to group related members together, which will make future changes cleaner (as noted in the commit message, these fields will be moved to a different struct later in the series).

Since this is part of a larger, already-merged effort to modernize xdiff's types for Rust FFI compatibility, there's no need for further review. The change is purely technical with no behavior impact, and follows the established pattern of the series by using more precise types. The commit message clearly explains both the type change and the field reorganization.
