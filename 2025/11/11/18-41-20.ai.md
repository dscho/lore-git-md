This is a documentation/cleanup patch addressing a long-standing whitespace attribute misspelling in Git's `.gitattributes` file. 

The patch removes the `!indent` attribute from the top-level `.gitattributes` file, where it has been a no-op since its introduction in 2008. The original commit intended to disable indent-with-non-tab checking (which would be correctly specified as `-indent`), but the `!indent` syntax was ineffective since indent-with-non-tab was never enabled by default. 

Junio notes this has caused no actual problems due to Git's default whitespace handling, but proposes removing the misspelled attribute rather than correcting it to `-indent`. The reasoning is that removal would make any future default whitespace policy changes immediately visible to Git developers, while the corrected form would silently override such defaults.

The change is minimal - a one-line modification to `.gitattributes` removing the `!indent` token while keeping the `trail,space` checks. The commit also notes there's a similar issue in `git-gui/.gitattributes` that may need addressing separately. This appears to be a straightforward cleanup of a harmless but misleading configuration that's persisted for over 15 years.
