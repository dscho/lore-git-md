This is a preparatory refactoring patch in Junio C Hamano's series introducing whitespace handling for incomplete lines (missing newlines at end of file). It corrects and clarifies bit assignments in the whitespace handling code, fixing miscounted bit positions in comments and updating the representation from octal to shift notation for better readability.

The patch makes three main changes: First, it fixes incorrect documentation about which bits correspond to whitespace rules versus line markers in diff.c. Second, it converts octal constants to (1 << N) notation throughout the whitespace-related headers, which makes the bit positions more obvious. Third, it adds blank lines between logically grouped macro definitions to improve code organization.

This is a straightforward cleanup that doesn't change behavior, just making the code's intent clearer. The changes are mechanical but important groundwork for the later patches in the series that will actually implement the new incomplete-line whitespace checking. The patch follows good practices with clear commit message explanations and touches only the relevant files (diff.c, diff.h, ws.h).
