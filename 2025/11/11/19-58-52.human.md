Documentation patch standardizing "working tree" terminology across multiple manual pages. This is part 1 of a 3-part series by Junio C Hamano that updates documentation to consistently use "working tree" (two words) for checked-out files and "worktree" (one word) for the multi-worktree feature.

The patch mechanically updates 15 documentation files, replacing historical "work tree" references with "working tree" where appropriate. Changes are straightforward textual substitutions that align with the glossary definitions. The commit message notes these files were written before the worktree feature existed and were using outdated terminology.

This continues the terminology standardization effort started in an earlier patch series, with Junio now contributing focused updates to core documentation. The changes are purely mechanical and non-controversial, bringing consistency to how Git describes the concept of a checked-out working directory versus the multi-worktree mechanism.
