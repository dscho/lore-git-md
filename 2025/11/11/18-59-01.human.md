This is a bugfix for the Meson build system's handling of the `git-contacts` Perl script in the contrib directory. The patch follows up on an earlier discussion where it was discovered that the script wasn't being marked executable during installation, causing "not a git command" errors when users tried to run it.

The thread shows clear consensus on the technical solution - modifying `generate-perl.sh` to explicitly mark `git-contacts` as executable. While there was some discussion about potentially renaming the script to follow `.perl` suffix conventions, the maintainer has accepted the current approach as sufficient for the contrib directory's more relaxed standards.

Junio Hamano confirms that this v2 patch (which only fixes a minor typo in the commit message from v1) matches what's already been queued in the 'next' branch, so no further action is needed. The issue appears fully resolved with this solution.
