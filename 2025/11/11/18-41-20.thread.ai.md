Thread identity: Documentation/cleanup patch addressing a misspelled whitespace attribute in Git's `.gitattributes` file.

Core problem or goal: Remove the ineffective `!indent` attribute from the top-level `.gitattributes` file, where it has been a no-op since 2008 due to being incorrectly specified (should have been `-indent` to disable indent-with-non-tab checking).

Current status: Patch proposes removing rather than correcting the attribute, as this would make any future default whitespace policy changes immediately visible to developers. The change is minimal - a one-line modification removing `!indent` while keeping `trail,space` checks.

Key technical details: The `.gitattributes` file in Git's root directory contains this whitespace configuration. The patch notes a similar issue exists in `git-gui/.gitattributes` that may need separate attention.

Participant positions: Junio Hamano (maintainer) notes the misspelling has caused no actual problems due to Git's default whitespace handling, but proposes removal for clarity.
