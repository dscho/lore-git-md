Bugfix for the Meson build system's handling of the `git-contacts` Perl script. This v2 patch from D. Ben Knoble follows up on the previous discussion about executable permission issues when installing the contrib script via Meson builds with `-Dcontrib=contacts`. The technical solution remains unchanged from v1 - modifying `generate-perl.sh` to explicitly mark `git-contacts` as executable by adding it to the case statement's pattern matching alongside `.perl` files. The only change in this revision is a typo fix in the commit message (correcting "install" to "installing"). 

The patch demonstrates good attention to detail by noting the difference in behavior from `generate-script.sh` and explaining the glob pattern approach. The change is minimal (a single line modification) and focused on the specific issue. The thread context shows this solution has already been reviewed and accepted by both Patrick Steinhardt and Junio C Hamano, with the typo fix being non-critical enough to not require further revisions during the pre-release freeze period. The discussion acknowledged that while renaming to `git-contacts.perl` would be theoretically cleaner, the current solution is sufficient for the contrib directory's more relaxed standards.
