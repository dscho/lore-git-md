This is a refactoring patch that corrects and clarifies bit assignments in Git's whitespace handling code. It's the first in Junio C Hamano's 12-part series introducing "incomplete-line" whitespace error detection.

The patch fixes miscounted bit positions in comments that describe how whitespace rules are encoded in diff flags. It updates three files (diff.c, diff.h, ws.h) to:
1. Correct the documentation of which positions correspond to whitespace rules versus other flags
2. Add missing documentation for color-moved line bits
3. Convert octal constants to (1 << N) notation for better readability
4. Add spacing between logically grouped macro definitions
5. Clarify that tab width is stored in the lowest 6 bits (supporting up to width 63)

Key technical details include:
- Whitespace rules now correctly documented as using bits 0-11 (was 0-12)
- WSEH flags (new/old/context) moved to bits 12-14 (was 13-15)
- Color-moved flags at bits 17-19 now documented
- Tab width mask changed from octal 077 to ((1<<6)-1)
- WS_RULE_MASK redefined from octal 07777 to ((1<<12)-1)

The changes are purely documentation and code organization - no behavior is altered. This establishes clearer foundations for the subsequent patches that will add new whitespace checking functionality. The patch follows good practices by keeping documentation in sync with code changes and improving code readability through better spacing and more modern bit-shift notation.
