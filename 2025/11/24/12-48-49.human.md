Documentation patch series completing the standardization of `git fetch`, `git push`, and `git pull` man pages. This v2 series from Jean-Noël Avila finalizes the conversion of these three interrelated commands to a consistent AsciiDoc synopsis style, following up on the initial v1 submission.

The series makes purely presentational changes across 10 files (800+ lines modified) to standardize formatting without altering any functional documentation. Changes include consistent synopsis blocks with `_<placeholder>_` syntax, monospace keywords, improved option presentation via bulleted lists, and updated cross-references. The v2 revision fixes a minor typo found during proofreading (an extraneous underscore character).

This completes a focused effort to align the documentation of these closely related commands. The work appears uncontroversial - no substantive feedback was received on v1, suggesting the changes align well with project standards. The series represents another step in the multi-year effort to standardize Git's man page formatting, with Jean-Noël Avila being a primary contributor to this documentation modernization.
