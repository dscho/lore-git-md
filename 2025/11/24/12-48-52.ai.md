Documentation patch completing the standardization of push/pull/fetch man pages to AsciiDoc synopsis style. This is the third and final patch in Jean-Noël Avila's series, following the conversions of `git fetch` and `git pull` documentation. The changes are purely presentational, converting the `git push` man page and its config documentation to match the project's standardized formatting:

1. Replaces old-style angle bracket placeholders (`<placeholder>`) with underscored AsciiDoc syntax (`_<placeholder>_`)
2. Wraps command options and keywords in backticks for consistent monospace rendering
3. Converts bullet lists to AsciiDoc's `;;` syntax for better automated processing
4. Updates cross-references to match the new placeholder style
5. Reformats the synopsis section using AsciiDoc blocks

The patch touches two files - the main `git-push.adoc` man page (267 lines changed) and its associated config documentation in `push.adoc` (113 lines changed). Version 2 fixed a minor typo (extraneous underscore) found during proofreading of the initial submission.

This completes the standardization of the three closely-related transport commands' documentation. The changes maintain all existing content while enabling better automated rendering. The approach mirrors previous successful documentation conversions in the project and appears uncontroversial based on the lack of discussion during review. The series is now polished and ready for merging as part of the ongoing effort to bring all Git documentation to a uniform style.
