This is the fourth patch in a series adding `--trailer` support to `git rebase`, now in its sixth iteration. The patch implements the actual rebase integration for trailer support, building on earlier refactoring work to make trailer processing available in-process.

The current version has received detailed review from Phillip Wood, who notes it's "looking good" with only minor cleanup needed. The patch forces rebase (`--force-rebase`) when trailers are specified to ensure all messages get rewritten, and currently only supports the merge backend (rejecting options that would require the apply backend). The implementation appears technically sound, with Phillip Wood indicating no major issues remain.
