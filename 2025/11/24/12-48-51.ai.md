Documentation patch standardizing `git pull` man page formatting, part of a series converting push/pull/fetch docs to consistent AsciiDoc style.

This is the second patch in Jean-Noël Avila's three-patch series converting the documentation for `git fetch`, `git pull`, and `git push` to use consistent AsciiDoc synopsis formatting. The changes here mirror those made to `git fetch` in the first patch, applying the same standardization to `git pull`'s documentation. The patch updates the man page and related option documentation files (fetch-options.adoc, merge-options.adoc, urls-remotes.adoc) to use the project's preferred formatting conventions.

Key technical changes include converting the synopsis to a proper synopsis block, standardizing placeholder notation to `_<placeholder>_`, wrapping options and keywords in backticks, and improving complex option descriptions with bulleted lists. The changes are purely presentational - no command behavior is altered. The patch follows the same pattern as the `git fetch` conversion, suggesting this is now a well-established documentation style for the project.
