Bugfix for incorrect error message in `git config set` when handling multi-valued configurations.

This is a straightforward fix addressing a user-reported issue where `git config set` would suggest invalid flags (`--add` or `--replace-all`) when failing to modify a multi-value config entry. The patch updates the error message to correctly recommend the valid flags: `--value=<pattern>`, `--append`, or `--all`.

The change is minimal (a single line modification in builtin/config.c) but important for user experience, preventing confusion when users follow the error message's suggestions. The fix maintains all existing error detection and behavior - it just provides accurate guidance when the operation fails.

The patch comes from René Scharfe and credits Paul Wintz as the original reporter. This appears to be a clean, focused correction with no broader implications - just fixing a misleading message that could send users down the wrong path when troubleshooting config operations.
