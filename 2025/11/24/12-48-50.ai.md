Documentation patch standardizing the `git fetch` man page and related documentation files to use consistent AsciiDoc synopsis formatting. This is the first of three patches in a series that also covers `git pull` and `git push` documentation.

The changes are purely presentational, converting documentation to use:
- Standardized synopsis blocks with `_<placeholder>_` syntax
- Monospace keywords and backtick-wrapped options
- Improved presentation of complex options via bulleted lists
- Updated cross-references matching new placeholder style
- Parallel updates to both command and config documentation

Files modified include the main `git-fetch.adoc` man page plus related option documentation (`fetch-options.adoc`, `pull-fetch-param.adoc`, `urls-remotes.adoc`) and config documentation (`config/fetch.adoc`). The changes span over 800 lines across 6 files but introduce no behavioral changes to Git itself.

This patch follows the same formatting approach used in previous documentation standardization efforts led by Jean-Noël Avila. The consistent style enables better automated rendering while maintaining all existing information. The series appears uncontroversial based on lack of discussion during review, suggesting alignment with project documentation standards.
