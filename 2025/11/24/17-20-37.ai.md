Hook subsystem refactoring (pre-push conversion). This patch converts the pre-push hook implementation in transport.c` to use the new hook API with stdin streaming capabilities introduced earlier in the series. The key changes replace the direct `child_process` management with the structured `run_hooks_opt` approach.

The implementation introduces a new `feed_pre_push_hook_data` struct to manage state for the stdin feeding callback, which now properly handles all `REF_STATUS_REJECT_*` cases that were previously scattered through the code. The callback (`pre_push_hook_feed_stdin`) carefully filters which refs get written to stdin based on their status, addressing an inconsistency in the original version that only checked some rejection cases.

The conversion maintains the same EPIPE handling behavior (ignoring when hooks don't read all input) while benefiting from the series' centralized SIGPIPE management. Memory management is improved by initializing the strbuf with size 0 rather than 256 and ensuring cleanup via `strbuf_release`. The patch demonstrates the series' goal of standardizing hook execution while adding proper stdin streaming capabilities.
