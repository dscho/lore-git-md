Bugfix for misleading help text in `git config unset` flags.

This patch corrects the help text for two flags in `git config unset` that were inaccurately describing their functionality. The `--all` flag's description incorrectly suggested it would "replace" values rather than unset them, while `--value` was described as showing configs rather than unsetting them. The changes make the help text properly reflect that these flags are about selecting what to unset in multi-valued configurations.

The patch is straightforward, modifying only the help strings in `builtin/config.c` for these two flags. The actual behavior remains unchanged - this is purely a documentation fix for the command-line interface. The changes are minimal (2 lines modified) and clearly focused on improving user experience by providing accurate flag descriptions.

This appears to be a well-scoped, uncontroversial fix that improves the consistency of Git's command-line interface documentation. The patch follows standard formatting and includes a clear commit message explaining the rationale.
