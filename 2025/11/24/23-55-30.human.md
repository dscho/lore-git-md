Jeff King (peff) responds to Junio C Hamano's analysis of the whitespace-trimming behavior in `git clone` config arguments. Both agree this leniency was surprising and arguably incorrect according to Git's config rules.

Peff suggests the documentation could be more consistent about option syntax forms but doesn't consider the current state strictly buggy.
