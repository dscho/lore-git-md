This is a documentation fix for the `git config unset` command. René Scharfe noticed that the help text for the `--all` and `--value` flags was misleading - these flags don't actually "replace" or "show" anything as the original text suggested, but rather control what gets unset. 

The patch updates the flag descriptions to be more accurate:
- `--all` now explains it will "unset all multi-valued config options"
- `--value` clarifies it will "unset multi-valued config options with matching values"

This is a straightforward correction that improves the command's documentation without changing any functionality. The change is small (just 2 lines modified) and clearly explained in the commit message. While minor, it helps users better understand these configuration unset options.
