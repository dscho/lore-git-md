Hook subsystem refactoring introducing stdin callback capability. This is part 2/10 of a major series modernizing Git's hook infrastructure to support parallel execution with large stdin inputs.

The patch adds a new `feed_pipe` callback mechanism to `hook.c` that allows feeding stdin to hooks without going through the filesystem. This complements the existing `path_to_stdin` file-based approach and is particularly useful for handling large data streams efficiently. The implementation includes proper mutual exclusion between the two stdin methods (enforced via BUG() if both are attempted) and adds comprehensive documentation for the new callback API.

The change builds on the parallel stdin infrastructure introduced in the previous commit and maintains compatibility with existing hook behavior. The documentation clearly explains the use cases for each stdin feeding method and the memory management responsibilities for callback context data. This appears to be a well-considered addition to the hook API that addresses real performance needs while maintaining safety.
