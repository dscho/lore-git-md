This is a bugfix follow-up to Junio Hamano's "What's cooking" report. D. Ben Knoble suggests backporting a recently fixed segfault in `git config get --path` when handling optional paths that don't exist. The fix is currently slated for the 'next' branch, but Knoble argues it should also go into the 2.52.1 maintenance release since the bug affects common commands like `git blame` and could impact users of the recently released version.

The patch series (jc/optional-path) fixes a case where Git would crash rather than gracefully handling missing optional paths marked with the `:(optional)` syntax. While this feature is new and likely not widely used yet, Knoble makes a reasonable case that the segfault risk warrants a maintenance release inclusion. The fix appears straightforward with three commits that properly handle the missing path case and clean up some internal implementation details.
