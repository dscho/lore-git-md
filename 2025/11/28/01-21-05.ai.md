Test patch improving zsh compatibility in POSIX mode for reftable tests. This is the first of two patches in a series addressing test suite issues when run under zsh's POSIX-compatible mode.

The patch modifies t0614-reftable-fsck.sh to use numerical comparison (-gt) instead of string comparison (">") when checking line counts. The change serves three purposes: it corrects a technically incorrect string-based comparison that could fail with multi-digit counts, avoids requiring POSIX 2024 features not yet widely available, and works around a current zsh limitation where the ">" operator isn't supported in its POSIX test implementation.

The modification is minimal (one line change) and focused specifically on the zsh POSIX mode scenario mentioned in the thread context. The commit message provides clear technical rationale for each aspect of the change, noting this doesn't attempt to address other known test failures in zsh's default or ksh modes. The change appears safe as it maintains the same logical comparison while using more portable syntax.
