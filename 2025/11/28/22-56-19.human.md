Bug report about `git fetch` SIGSEGV with submodules. Justin Su reports that `git fetch` consistently crashes with a segmentation fault when fetching submodules, though the fetch operation appears to complete successfully before the crash. The issue occurs on an ARM64 Ubuntu 24.04 system running Git 2.43.0.

The error initially showed a lock file conflict, but after manually removing the lock file, the fetch proceeds before hitting the SIGSEGV. The reporter notes this happens "almost always" and provides no reproduction steps beyond the basic `git fetch` command. The attached diagnostics bundle may help developers investigate the ARM64-specific crash.

This appears to be a genuine crash bug rather than a usage error, though without a clear reproduction case or stack trace in the report itself, developers would need the diagnostics to investigate further. The fact that it occurs during submodule fetching on a non-x86 architecture may point to platform-specific issues in Git's submodule handling.
