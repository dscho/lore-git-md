This is a documentation/refactoring patch that updates Git's advice messages to prefer `git help` over `man` for referencing manual pages, while also modernizing some test syntax.

The patch changes two instances where branch-related error messages suggest checking ref format rules - one in `branch.c` and another in `builtin/branch.c`. Both currently point users to `man git check-ref-format`, which is replaced with the Git-native `git help check-ref-format`. The author notes this is more conventional and avoids relying on external `man` command.

Additionally, the patch updates the corresponding test in `t/t3200-branch.sh` to use the `${SQ}` (single quote) test helper instead of literal single quotes, making the test more readable and maintainable. The changes are straightforward mechanical replacements with no behavior changes beyond the advice wording.

The patch builds on commit 8fbd903e from March 2024 which originally added this advice. It's a small but thoughtful improvement to Git's user interface consistency and test hygiene. The changes are minimal (5 lines changed across 3 files) and well-contained to advice messages and test formatting.
