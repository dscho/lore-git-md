This thread addresses a bug in `git-last-modified` where a `memset()` call incorrectly passed an element count instead of a byte count when clearing a bitmap, causing issues particularly on s390x systems. The bug was reported by Anders Kaseorg and initially fixed by Toon Claes with a one-line change, which Jeff King reviewed and approved. Junio C Hamano confirmed the fix was correct and suitable for backporting to the stable `maint` branch, noting the bug had existed since v2.52.0.

The discussion, King suggested broader improvements to avoid similar issues in the future, leading Claes to submit a second version of the patch introducing a new `MEMZERO_ARRAY` macro that encapsulates the size calculation logic. This approach was well-received as it follows Git's existing patterns for array helpers. However, Hamano notes that the original fix has already been merged to the `next` branch, making this enhancement potentially redundant for the immediate issue. The thread demonstrates how Git's review process not only catches and fixes bugs but also iterates toward more maintainable solutions, with active participation from both contributors and maintainers. The core fix is now in place, and the architectural improvement may be considered separately.
