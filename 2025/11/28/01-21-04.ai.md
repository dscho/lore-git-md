This is a test suite patch series addressing zsh compatibility issues. The two patches focus on making Git's test suite work when run under zsh's POSIX-compatible "sh mode", which is particularly relevant for systems where `/bin/sh` is ksh93 (which lacks `local` support).

The first patch changes a test in t0614-reftable-fsck.sh to use numerical comparison rather than relying on POSIX 2024 behavior that zsh's sh mode doesn't yet support. The second patch fixes a mysterious hanging issue in t5564-http-proxy.sh by changing to a subshell invocation, though the root cause isn't fully understood - the author notes they couldn't reproduce it in a simple test case but the fix is straightforward.

The changes are minimal (3 lines modified total) and focused specifically on zsh's POSIX mode, explicitly not attempting to support zsh's default or ksh modes where many other test failures are known to exist. The motivation is to provide an alternative shell option for systems where ksh93 is the default `/bin/sh`. The patches appear well-scoped and low-risk, addressing clear compatibility issues without making broader changes to test infrastructure.
