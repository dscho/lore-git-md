Thread summary:

Bugfix for `git-last-modified` bitmap initialization issue. The command tracks changed paths between commits using a scratch bitmap of `eword_t` (uint64_t) elements. A bug in memory initialization passed just the element count rather than byte count to `memset()`, causing incorrect behavior (more visible on s390x big-endian but not endian-specific). Fix multiplies count by `sizeof(eword_t)` in the `memset` call. Jeff King reviewed (Helped-by) and Anders Kaseorg reported the test failure that revealed the issue. Minimal one-line change focused on the memory initialization problem.
