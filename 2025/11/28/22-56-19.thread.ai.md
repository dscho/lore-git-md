Git fetch SIGSEGV during submodule operations bug report. Justin Su reported a segmentation fault on ARM64 (aarch64) Ubuntu 24.04 with Git 2.43.0 during `git fetch` involving submodules when both `fetch.writeCommitGraph=true` and `submodule.recurse=true` were set. Jeff King identified d70f554cdf ("commit-graph: retain commit slab when closing NULL commit_graph", 2024-01-05) as the definitive fix, explaining the crash's disappearance between Git 2.43.0 and 2.52.0. The fix addressed memory corruption when closing a NULL commit_graph, matching the original symptoms during commit-graph operations in submodule fetches. The ARM64-specific crash resulted from improper slab management in this edge case. With the root cause confirmed and the version range (2.43.0 to pre-2.52.0) precisely bounded, the investigation is now complete. The thread demonstrates how some bugs get resolved incidentally through broader code improvements rather than targeted fixes.
