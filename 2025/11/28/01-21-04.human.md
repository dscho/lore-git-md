This is a test suite patch series addressing zsh compatibility issues. Brian M. Carlson submits two small patches to make Git's test suite pass when run under zsh's POSIX-compatible "sh mode", which is relevant for systems where `/bin/sh` is actually zsh configured in POSIX mode.

The first patch fixes a test in t0614 that accidentally relied on behavior from a too-new POSIX standard (1003.1-2024) by changing a string comparison to a numerical one. The second patch addresses a mysterious hanging issue in t5564 by modifying how a subshell is used, though the root cause isn't fully understood - the fix is simple and effective despite the lack of full diagnosis.

The changes are minimal (just 3 lines modified across two test files) and well-explained, with clear motivation about improving compatibility for users whose systems use zsh as their POSIX shell. The author notes they're not attempting to support zsh's default mode, acknowledging known limitations there. These appear to be straightforward, low-risk improvements to test portability.
