This is part 5/10 of Ezekiel Newren's xdiff refactoring series, continuing the modernization of core xdiff structures for Rust FFI compatibility. The patch focuses on `xdl_hash_record()` and related functions, converting them to use unambiguous types.

The changes standardize the hashing functions to use `uint8_t` for byte buffers (replacing `char*`) and `uint64_t` for hash values (replacing `unsigned long`). This ensures consistent behavior across platforms, particularly where `long` might be 32-bit. The `flags` parameter is also upgraded to `uint64_t` to preserve all bits on all platforms.

The patch updates four files with these type changes, including the public interface in xdiff/xutils.h and all call sites. The implementation maintains the same hash algorithm (djb2) but with type-safe operations. The changes align with the series' goal of establishing clear type mappings between C and Rust, building on the foundational documentation established in earlier patches.
