Feature patch completing the experimental `git-repo-info` command with `--all` flag support. This is the second and final patch in the v5 series from Lucas Seiki Oshiro's GSoC project, addressing all remaining review feedback.

The patch adds a `--all` flag to `git repo info` that outputs all available repository metadata fields at once, eliminating the need to specify individual keys. The implementation includes a new `print_all_fields()` function that iterates through all defined fields, maintaining the same output format options (`keyvalue` or NUL-terminated) as the existing per-key queries. The change comes with comprehensive tests verifying the new flag works as expected and cannot be combined with individual key requests.

This completes the technical implementation of the experimental command, with all v4 review feedback addressed. The series is now ready for final review and merging, maintaining its experimental status while providing a useful new way to query repository metadata. The implementation shows careful attention to detail with proper error handling, documentation updates, and test coverage.
