This is the final version (v5) of Ezekiel Newren's xdiff refactoring series, which modernizes core xdiff structures for Rust FFI compatibility. The series has undergone extensive review and refinement over multiple iterations, with all major technical points now resolved.

The key changes in this version are:
1. Documentation updates in `unambiguous-types.adoc` to remove non-standard "signless" terminology and clarify `char` handling per C standards (6.2.5)
2. Reversion of `get_indent()` to use `char` casting rather than `uint8_t` for character-specific operations, maintaining compatibility with existing behavior

The series completes the structural modernization of `xdfile_t` and `xrecord_t` types, with all fields now using appropriate size types (`size_t`, `ptrdiff_t`, `uint64_t`) and clear naming conventions (`reference_index`). The changes are behavior-preserving while establishing well-defined type mappings for future Rust FFI work.
