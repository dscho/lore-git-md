This is a bugfix series addressing output formatting issues in `git worktree list`. Phillip Wood fixes two related problems with the command's tabular output: misaligned columns when worktree paths contain multibyte characters, and unquoted paths that could be corrupted by control characters.

The first commit adjusts the column spacing calculations to properly account for multibyte characters in paths. The second commit adds proper quoting of paths to prevent control characters from disrupting the output format. Together these ensure clean, reliable display of worktree information regardless of special characters in path names.

The changes touch both the worktree command implementation and its tests, with thorough test updates demonstrating the fixes. This appears to be a well-contained quality-of-life fix for a real but non-critical issue. The patches follow Git's usual standards with clear commit messages and matching test coverage.
