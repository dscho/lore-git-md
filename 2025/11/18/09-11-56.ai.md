This is a platform compatibility patch in Jeff King's ASan fixes series (v2 1/9). It addresses a compiler warning when building with NO_MMAP=1 and DEVELOPER=1 flags enabled.

The change marks the unused `length` parameter in `git_munmap()` with the UNUSED macro to suppress -Wunused-parameter warnings. This is needed because the compat implementation uses malloc/free rather than actual mmap/munmap, so while the function signature must mirror the system munmap() interface, it doesn't need the length parameter internally.

The patch is straightforward and uncontroversial - it's a minor build system fix that enables cleaner compilation with developer warnings enabled. As the first patch in the series, it sets up the NO_MMAP compatibility layer that may be needed for subsequent ASan-related testing. The change is minimal (just adding UNUSED) and maintains the existing behavior while making the code more warning-clean.
