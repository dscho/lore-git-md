This is a bugfix series addressing an inconsistency in Git's global config file handling, now confirmed as technically complete by Johannes Schindelin. The core issue was that `git config list --global` only showed `$HOME/.gitconfig` while Git actually reads both that and `$XDG_CONFIG_HOME/git/config` for global configuration, creating a mismatch between documented and actual behavior.

Junio Hamano notes the series hasn't seen much community discussion despite being technically sound (with Johannes' repeated Reviewed-by tags). He expresses mild concern about the historical rationale for not reading both configs simultaneously, suggesting there may have been migration-related reasons that aren't immediately clear now. The lack of broader review feedback seems to be the main factor holding back promotion to 'next' rather than any technical deficiency.

The series appears well-vetted from an implementation standpoint, having gone through multiple iterations with platform-specific verification from Johannes. Junio's comments suggest it's now awaiting either confirmation of the design rationale from other experienced contributors or his own deeper investigation into historical context before progressing further. The technical work itself seems uncontroversial and complete.
