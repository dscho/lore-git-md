This is the final patch in Ezekiel Newren's xdiff refactoring series, completing the modernization of core xdiff structures for Rust FFI compatibility. The patch renames the `rindex` field in `xdfile_t` to the more descriptive `reference_index`, following through on the type standardization work done in previous patches.

The change is straightforward but touches several files, updating all references to the renamed field across xdiffi.c, xprepare.c, and xtypes.h. The field's type was already converted to `size_t*` in patch 9/10, so this is purely a naming improvement that better reflects the field's purpose - it maintains references between the compacted diff array and the original file lines.

The patch completes the systematic modernization of xdiff's core data structures that began with type documentation standards and progressed through field-by-field updates. With this change, the series has now addressed all major structural elements of `xdfile_t` and `xrecord_t`, establishing clear type mappings and semantic naming for Rust FFI integration.
