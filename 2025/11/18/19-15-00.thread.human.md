Bailey Muckel reported encountering a BUG message when trying to change a merge commit's command from "merge -C" to "drop" during an interactive rebase with merge commits (`git rebase -i --rebase-merges`) on Windows. The error occurred in sequencer.c and left the rebase in an incomplete state requiring manual intervention. The report included clear reproduction steps and system details (Git 2.49.0.windows.1).

Phillip Wood has now responded that this was actually a known issue that was addressed in Git 2.51.1 via commit 4d491ade8f6 ("rebase -i: permit 'drop' of a merge commit"). The fix allows dropping merge commits during interactive rebase operations as intended. Since the fix is already available in newer Git versions, the solution for the reporter is simply to upgrade their Git installation. Unless Bailey has additional questions about verifying the fix or the upgrade process, this thread appears resolved.
