This is the final version of Ezekiel Newren's xdiff refactoring series, part of the ongoing effort to modernize Git's diff engine for Rust FFI compatibility. The 10-part series completes the structural modernization of core xdiff types, with all feedback from maintainers and reviewers incorporated.

The key changes convert fields in `xrecord_t` and `xdfile_t` to unambiguous types (`size_t`, `uint8_t`, `uint64_t`, etc.) and rename `rindex` to `reference_index` for clarity. The v5 updates specifically address two final points: removing non-standard "signless" terminology from documentation and preserving `char` casting in `get_indent()` where character-specific behavior is needed.

The series has undergone extensive review, with input from Junio Hamano (on type mapping and documentation), Ramsay Jones (on C language standards), and Ben Knoble (on compiler behavior). All major technical points are now resolved, including the maintainer-approved exception for character handling in `get_indent()`.

This work establishes well-documented type mappings between C and Rust while maintaining backward compatibility, setting the stage for future Rust FFI integration. The changes are behavior-preserving but provide important type safety improvements across the xdiff subsystem. With all feedback addressed, this appears ready for merging as the foundation for subsequent work.
