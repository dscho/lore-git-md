This is version 2 of Jeff King's ASan bugfix series, now incorporating feedback from reviewers. The 9-patch set addresses various memory safety issues found by AddressSanitizer across multiple Git subsystems.

The key changes in v2 include:
1. Added a defensive assertion in the midx bitmap lookup code as suggested by reviewers
2. Squashed the Meson build system changes into patch 3
3. Improved the cache-tree integer parsing to be more careful about garbage inputs, though Jeff notes that creating a fully robust reusable integer parser would be non-trivial and prefers to focus on fixing the immediate memory safety issues first

The series remains focused on its original goal of fixing ASan findings while maintaining test suite stability. Jeff acknowledges the discussion around creating better parsing utilities but considers that out of scope for this immediate cleanup. The patches touch various areas including pack-bitmap handling, fsck validation, and cache-tree parsing, with build system support for both Makefile and Meson.

The changes appear well-considered and responsive to review feedback while staying focused on the memory safety goals. The series looks ready for final review, with the parsing utility discussion potentially spawning follow-up work.
