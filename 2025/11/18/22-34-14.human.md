This is a refactoring patch in Ezekiel Newren's ongoing xdiff modernization series for Rust FFI compatibility. It changes the type of `dstart` and `dend` fields in `xdfile_t` from `long` to `ptrdiff_t`, which is more semantically appropriate since these fields represent pointer offsets. 

The change is straightforward and follows the type standardization work documented in the foundational `unambiguous-types.adoc` from earlier in the series. This patch is part of the implementation phase after the documentation and technical consensus were established, showing the practical application of the type mapping standards.

As the second patch in v5 of the 10-part series, it builds on the comprehensive type modernization effort that has already received maintainer approval and thorough review from standards experts. The change maintains backward compatibility while improving type safety for future Rust integration work.
