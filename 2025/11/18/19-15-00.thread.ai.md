Bug report concerning interactive rebase with merge commits on Windows, originally reported by Bailey Muckel encountering a BUG message when changing a merge commit's command from "merge -C" to "drop" during `git rebase -i --rebase-merges`. The error occurred in sequencer.c line 2695 with "unexpected todo_command", leaving rebase in incomplete state. Platform details specified Git 2.49.0.windows.1 with clear reproduction steps.

Phillip Wood identified this was already fixed in commit 4d491ade8f6 ("rebase -i: permit 'drop' of a merge commit") which landed in Git 2.51.1. The fix addressed the exact scenario described - changing merge commit commands to "drop" in interactive rebase todo list. This resolves the issue as a known bug with existing fix in newer versions. The thread can likely be closed unless reporter has follow-up questions about upgrading or verifying the fix. Original detailed reproduction steps remain useful context for users on older versions. No further action needed from maintainers as the fix is already in release stream.
