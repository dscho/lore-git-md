This is a refactoring patch that completes the consolidation of Git's tempfile creation code by removing the last platform-specific `mkstemp()` implementation. Building on the previous thread that replaced most `mkstemp()` calls with `git_mkstemp_mode()`, René Scharfe now proposes to:

1. Remove the Windows-specific `mkstemp()` implementation from compat/mingw.c
2. Define `mkstemp()` as a macro in git-compat-util.h that calls `git_mkstemp_mode(0600)`
3. Remove the declaration from compat/mingw-posix.h

The change ensures consistent tempfile behavior across all systems by always using Git's internal implementation, which provides needed features like custom permissions and suffix support. The patch addresses the remaining direct `mkstemp()` call in entry.c that Jeff King had identified earlier in the thread.
