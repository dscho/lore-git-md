This is a cover letter for a two-patch series addressing CI output visibility issues in Windows Meson test jobs. The series comes from Jeff King (peff@peff.net) and targets the GitHub Actions workflow configuration.

The motivation stems from a real debugging pain point: when tests fail in the windows-meson-test CI jobs, the output isn't visible, making failures hard to diagnose. The first patch makes unit tests ignore --no-chain-lint to avoid interference with test output, while the second aligns the Windows Meson test job's output handling with other test jobs.

The changes touch the GitHub Actions config, a new test runner script, and the unit test infrastructure. The series appears focused and well-motivated, addressing a clear developer experience issue in the test infrastructure. Given Jeff King's track record and the straightforward nature of the fixes, these patches seem likely to be uncontroversial and quickly accepted.
