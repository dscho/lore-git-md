This is the second patch in the final v5 series implementing the experimental `git-repo-info` command, adding the `--all` flag feature. The patch completes the implementation by allowing users to request all available repository metadata keys at once rather than specifying them.

The technical implementation introduces a new `print_all_fields()` function that iterates through all defined repository info fields, printing each key-value pair. The patch enforces mutual exclusivity between `--all` and explicit key arguments through a new `all_keys` flag and corresponding error handling. Documentation updates clarify the new flag's behavior while maintaining consistency with the existing "keys" terminology.

Test coverage includes verification that `--all` produces identical output to explicitly listing all keys, and that the `--all` cannot be combined with specific key arguments. The implementation builds on the v5 optimizations from the first patch (direct stdout writing) while maintaining the experimental feature status.

Key technical details for future reference:
- New function: `print_all_fields()` in builtin/repo.c
- Flag: `--all` (mutually exclusive with key arguments)
- Test verification: `t1900-repo.sh` checks full output equivalence and argument validation
- Documentation: Updated synopsis and command description in git-repo.adoc
