CI infrastructure patch to improve Windows test output visibility.

This is the first of two patches fixing an issue where Windows CI jobs using Meson don't properly show test output on failures. The patch makes the unit test runner ignore the `--no-chain-lint` option, which currently interferes with test output when passed via `GIT_TEST_OPTS`. 

The change is small (just one line adding the option to be ignored) but necessary groundwork for the second patch that will properly surface test output. The commit message explains that Windows CI currently adds this option by default, and while the Meson build isn't properly handling test options yet, this change ensures it will work correctly when it does.

The patch appears straightforward and well-motivated, addressing a clear pain point for debugging Windows test failures. As part of a small, focused series to improve CI visibility, it seems like a good candidate for quick review and merging.
