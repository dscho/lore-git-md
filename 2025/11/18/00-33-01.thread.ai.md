Git for Windows 2.52.0 release announcement from Johannes Schindelin, updating the Windows port to match upstream Git v2.52.0. Key updates include dependency bumps: PCRE2 to v10.47, cURL to v8.17.0, and InnoSetup installer to 6.6.0. Continues deprecation path for `git svn` support. Fixes regression in `git help git-bash` functionality since v2.49.0. Provides SHA-256 checksums for all distribution formats (64-bit/ARM64 installers, portable versions, MinGit bundles, tarballs). This is a routine maintenance release focused on dependency updates and regression fixes, following Git for Windows' established release cadence.
