Test infrastructure patch aligning Windows Meson test job behavior with other CI jobs.

This second patch in the series introduces a new test runner script `ci/run-test-slice-meson.sh` to properly handle test options and output for Windows Meson builds. The key changes:

1. Replaces direct `meson test` invocation in GitHub Actions with the new wrapper script, which properly processes `GIT_TEST_OPTS` and integrates with the existing test failure handling infrastructure.

2. Adds post-test steps to print failure details and upload artifacts when tests fail, matching behavior of other CI jobs. This addresses the core issue where Windows Meson test failures were previously hard to debug due to missing output.

The patch creates a Meson-specific solution rather than trying to share code with the existing `run-test-slice.sh`, as the build systems handle test arguments differently (Meson requires explicit `--test-args` while Make handles them automatically). The implementation loads build options first to properly set up test directories before processing CI-specific configurations.
