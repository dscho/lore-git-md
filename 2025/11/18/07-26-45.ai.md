The change has already proven stable in related repositories (git-for-windows and git-po) where it was applied earlier. This completes the routine maintenance cycle for this component of the localization infrastructure.

With Jiang Xin's sign-off, this appears ready for integration as a straightforward CI maintenance update with no outstanding concerns. The patch maintains consistency with the project's established practice of keeping GitHub Actions current while preserving existing workflow behavior.
