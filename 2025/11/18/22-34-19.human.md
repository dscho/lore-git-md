This is part 7/10 of Ezekiel Newren's ongoing refactoring series to modernize xdiff's core data structures for Rust FFI compatibility. The patch changes the `nrec` field in `xdfile_t` from `long` to `size_t`, as it tracks the number of records in arrays and should use the standard size type for array indexing.

The change is straightforward but requires numerous casts at interface boundaries where the value is compared with or assigned to `long` variables. The patch updates all these locations across xdiff's implementation files (xdiffi.c, xemit.c, xmerge.c, etc.) to maintain compatibility while using the more appropriate type internally.

This continues the series' systematic approach to type modernization, following earlier patches that updated other fields like `size` and pointer arithmetic types. The change is well-contained and maintains backward compatibility through explicit casts, following the patterns established in previous patches of the series.
