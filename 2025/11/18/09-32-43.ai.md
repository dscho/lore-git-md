This is a CI/build system patch that's part of a 2-part series to fix Windows/Meson test output visibility. The patch modifies the unit test runner to ignore the `--no-chain-lint` option when passed via `GIT_TEST_OPTS`, which currently causes issues on Windows CI when using Meson builds.

The change adds `--no-chain-lint` to the list of no-op options in `unit-test.c`, similar to how other test options are handled. This is necessary because Windows CI jobs currently add `--no-chain-lint` by default, and the Meson build passes all test options to unit tests. The patch notes this is a prerequisite for properly fixing the Windows Meson test job's handling of `GIT_TEST_OPTS`.

The change is minimal (1 line added) and focused specifically on test infrastructure. It references prior work (commit 9faf3963b6) that established the pattern for handling test compatibility options. The commit message clearly explains both the current broken state and how this change fits into the larger fix.
