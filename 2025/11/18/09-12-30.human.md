This is the final patch in Jeff King's 11-part series addressing ASan (AddressSanitizer) findings across Git's codebase. The series has systematically hardened memory handling and string parsing throughout Git, with each patch fixing specific issues while maintaining test suite compatibility.

This patch enables ASan's strict string checking by default in the test suite. While this initially produced some false positives (like in `fsck_ident()` where newlines safely terminate strings), it also caught a real issue in `cache-tree.c`'s `strtol()` parsing that would have been difficult to detect otherwise. The change makes the test suite more rigorous by validating proper NUL-termination of strings passed to string functions.

The patch is straightforward - it simply adds the `strict_string_checks=1` option to ASan's configuration. With all previous patches in the series having addressed both real issues and false positives, the test suite now runs cleanly with this stricter checking enabled. This represents the culmination of the series' work to make Git's string handling more robust against memory safety issues.
