This is the final polish version (v5) of the experimental `git-repo-info` feature, addressing the last review comments from Junio C Hamano. The two-patch series is now complete, with only minor signature and type changes needed from the previous version.

The first patch refactors field printing into a dedicated function, now optimized to write directly to stdout rather than using an intermediate strbuf. The second patch implements the `--all` flag, with the key changes being a switch to `size_t` for array indexing and making the function return an integer like its counterpart. The test coverage remains comprehensive.

These changes complete all technical requirements for the series, with the remaining work being purely stylistic refinements. The patches maintain the experimental status of the feature while providing all the core functionality planned for initial inclusion. The implementation is clean and well-tested, showing the maturation of this GSoC project through multiple review iterations.
