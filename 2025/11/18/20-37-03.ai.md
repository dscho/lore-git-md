Refactoring patch for the experimental `git-repo-info` command, part of the final v5 series.

This first patch in the two-part series factors out field printing logic into a dedicated `print_field()` function, eliminating redundant code and improving maintainability. The key changes are:

1. Extracts the field printing logic from `print_fields()` into a new standalone `print_field()` function that can be called by other functions (preparing for the `--all` functionality in patch 2)
2. Optimizes the output path by having `quote_c_style()` write directly to stdout rather than using an intermediate `quotbuf` strbuf
3. Maintains identical output behavior for both key-value and NUL-terminated formats
4. Reduces memory usage by removing the `quotbuf` strbuf entirely

The changes are purely internal refactoring with no user-visible behavior changes. The patch follows good practices by:
- Keeping the function signature consistent with the existing code
- Maintaining the same error handling behavior
- Properly cleaning up resources (strbuf release)
- Including a BUG() case for invalid format types

This appears to be a well-executed refactoring that simplifies the code while preparing for the `--all` functionality to be added in the next patch. The changes align with the thread's progression toward finalizing this GSoC project.
