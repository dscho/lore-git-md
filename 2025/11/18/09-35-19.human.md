Test infrastructure patch improving Windows/Meson CI output visibility.

This is the second patch in a series addressing the problem where Windows test jobs using Meson don't properly show test output on failures. Jeff King explains that the current setup skips key test infrastructure, leaving developers with little debugging information when tests fail.

The solution introduces a new `ci/run-test-slice-meson.sh` script that brings Windows Meson test jobs in line with other CI jobs by:
- Properly handling test options like `--verbose-log`
- Implementing the standard test failure handling that shows detailed output
- Preserving the test artifact upload capability

The patch modifies the GitHub Actions workflow to use this new runner and adds the same test failure reporting that exists for other jobs. While the author notes some Windows path oddities when experimenting with bash vs pwsh shells, the final solution sticks with pwsh to avoid test failures.

This appears to be a well-motivated change that fills a clear gap in the CI system's debugging capabilities. The implementation is focused and follows established patterns from the non-Meson Windows test jobs. The 24-line change is straightforward and unlikely to be controversial.
