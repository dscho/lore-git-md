This is a bugfix patch addressing memory and file descriptor leaks in a test helper program. Jeff King notes that while these leaks aren't currently causing problems (since the test helper exits immediately and existing test cases fail before the leaks occur), they trigger warnings from LSan and Coverity static analysis tools.

The patch fixes two issues in `test-mktemp.c`:
1. The string copied for the tempfile template was never freed
2. The file descriptor returned by `xmkstemp()` was never closed

The changes are straightforward - storing the allocated string and file descriptor in variables so they can be properly cleaned up before the program exits. Jeff acknowledges this isn't urgent (the leaks have existed for years) but worth fixing to avoid future issues if the test helper is used differently, and to clean up static analysis warnings. The patch touches only the test helper code, not production Git code.
