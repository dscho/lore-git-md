This is a review response to a feature patch adding `--committer` support to `git commit`. Patrick Steinhardt provides feedback on ZheNing Hu's initial implementation, focusing on code organization and edge cases while generally agreeing with the feature's usefulness.

The review suggests several improvements: moving the new `--committer` option next to `--author` in the documentation for logical grouping, refactoring the shared identity determination logic between author and committer handling into a common function, and questioning whether commit lookup should search by committer rather than author when given a pattern. There's also a style nit about omitting braces for single-line conditionals.

The feedback indicates the core implementation appears sound but could benefit from some structural cleanup. The reviewer doesn't raise any fundamental objections to the feature itself, which aims to provide symmetry between author and committer overrides in the commit interface. The patch appears to be on track for inclusion pending these implementation refinements.
