This is a review of patch 11/12 in Junio C Hamano's series introducing whitespace handling for incomplete lines (missing newlines at end of files). Phillip Wood provides feedback on the diff-side implementation, which teaches `git diff` to highlight and error out on incomplete lines when configured.

The review focuses on test improvements, suggesting:
1. Using `printf` instead of `echo | tr` for clearer test setup
2. Fixing a typo ("toucing" -> "touching")
3. Considering whether to verify error messages in test assertions
4. Overall approval of the test coverage for both `--check` and `wsErrorHighlight` functionality

Phillip notes the implementation looks good and agrees with the design choice about how to handle incomplete lines when both pre- and post-images are modified. The feedback is constructive and focused on test quality rather than core functionality, which has already been merged. This continues the pattern of post-merge refinement from domain experts on this well-executed series.
