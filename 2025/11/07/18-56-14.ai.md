This is a "What's cooking" status update from Junio C Hamano, summarizing the current state of various Git development topics as of November 2025. The email provides a categorized overview of patches that have graduated to 'master', new topics under consideration, ongoing work in 'cooking', and discarded topics.

Key highlights include:

Several patches have graduated to 'master', including internationalization work for fast-import/export messages, fixes for parseopt filename handling, CI updates, and a message fix for reflog migration. These are now considered stable and will be part of the upcoming Git 2.52 release.

New topics proposed include adding `--trailer` support to rebase, performance fixes for tag peeling, and Wincred credential helper Makefile updates. The rebase trailer work involves refactoring interpret-trailers functionality to avoid forking.

Notable ongoing work includes:
- A new `git maintenance is-needed` subcommand to check if maintenance tasks are required
- Configurable diff algorithm for `git blame`
- Significant refactoring of loose object handling code
- Rust interoperability work for SHA-1/SHA-256 object mapping
- A new `git history` command for history rewriting
- Atomic ref updates becoming default in `git replay`
- Submodule path encoding to prevent filesystem collisions

The email also notes several topics that have been discarded or are awaiting rerolls, including Rust bindings generation and documentation updates. Junio encourages feedback on several proposals and indicates which branches are likely to merge to 'next' soon.

This status update provides a comprehensive snapshot of Git's development pipeline, showing both incremental improvements and more substantial architectural changes in progress, particularly around ref handling, object storage, and Rust integration.
