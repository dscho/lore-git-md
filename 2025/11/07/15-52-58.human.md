This is a refactoring patch that's part of a series enabling diff algorithm selection in `git blame`. The patch adds the `XDF_NEED_MINIMAL` bit to the `XDF_DIFF_ALGORITHM_MASK` in xdiff's header file, which fixes some edge cases where the minimal diff bit wasn't being properly cleared when resetting the diff algorithm. The change makes the behavior more consistent by ensuring all algorithm-related bits are handled uniformly.

Junio C Hamano reviews the patch and agrees with the technical approach, noting it correctly handles the case where multiple algorithm bits might be set. He suggests keeping the existing comment about clearing previous settings, even though it's now redundant, since that's not the focus of this patch. 

The review also explores some future cleanup opportunities, like adding validation to ensure only one algorithm bit is set at a time, and potentially moving algorithm selection out of bitflags entirely into a dedicated enum field. These are noted as possible follow-ups rather than requirements for the current series.
