This is a final build-system fix for the `gitdatamodel.adoc` documentation patch series. Junio Hamano points out an XML validation issue that occurs when building the manpage with AsciiDoc (as opposed to Asciidoctor), where the section ID `[[objects]]` needs to match the cross-reference `<<objects,Objects>>` exactly. The fix changes both to use `object` instead of `objects` for consistency.

The patch is a simple two-line change that:
1. Updates the cross-reference from `<<objects,Objects>>` to `<<object,Objects>>`
2. Updates the section ID from `[[objects]]` to `[[object]]`

Junio notes this is the same fix he previously suggested in the v5 review thread, and confirms the patch still applies cleanly to v6. This appears to be the last remaining technical issue before the documentation can be merged, addressing a build system compatibility detail that was missed in earlier rounds. The change doesn't affect the content or structure of the documentation itself, just the internal linking mechanism for one section.
