This is Junio Hamano's regular "What's cooking in git.git" status update, providing a comprehensive overview of the current state of Git development as of November 2025. The email classifies various patches and topics into different stages of the development pipeline.

Several topics have recently graduated to 'master', including internationalization improvements for fast-import/export messages, fixes for parseopt filename handling, CI updates, and a minor message fix in the refs subsystem.

New topics being introduced include:
- A rebase trailer feature that would allow appending trailers during rebase without forking to interpret-trailers
- Performance fixes for tag peeling
- A Wincred credential helper Makefile update

Numerous topics are still cooking, ranging from merge strategy fixes and maintenance command enhancements to documentation updates and refactoring work. Notable among these are:
- A new "git maintenance is-needed" subcommand
- Whitespace handling improvements for incomplete lines
- Optimizations for "git last-modified"
- Various ref backend cleanups and improvements
- Experimental "git history" command for history rewriting
- Atomic ref updates for "git replay"

The email also notes several discarded topics and provides links to Git repositories and documentation sources. This update serves as both a progress report and an invitation for community feedback on the various patches and features under development.
