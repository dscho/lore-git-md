This is the third and final patch in a documentation series for `git-last-modified`, focusing on clarifying depth handling behavior. The patch adds a comprehensive "NOTES ABOUT DEPTH" section to the man page, explaining several key aspects of path traversal:

1. The default behavior of only showing root-level paths, with examples demonstrating how this affects output for nested paths. The documentation shows concrete command-line examples with sample output for each case.

2. The interaction between `--recursive` and path specifications, including the potentially surprising behavior when given a tree path (where it shows all contents recursively).

3. How to use `--max-depth=0` to get information about a subtree itself while avoiding recursive traversal of its contents. This builds on the `--max-depth` documentation from patch 2/3.

The patch follows the same pattern as the previous ones in the series, adding thorough documentation for existing but previously unclear behavior. It cross-references the new depth notes section from both the `--recursive` and `--max-depth` option descriptions. The examples follow Git's standard documentation style and clearly illustrate the before/after behaviors.

This completes the documentation coverage started in patches 1/3 (`-z` option) and 2/3 (`--max-depth`). The series appears well-structured, with each undocumented feature getting its own focused patch. The depth handling documentation is particularly valuable as it addresses what could be a common point of confusion for users.
