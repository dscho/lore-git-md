This is the fourth patch in a series improving Scalar's configuration handling, following up on earlier work to document and audit Scalar modifies. The patch reorganizes Scalar's configuration settings for better maintainability while relaxing enforcement of most settings.

The key changes alphabetize the configuration options (with platform-specific ones at the end) and remove the `overwrite_on_reconfigure` flag from most settings. This makes the configurations more advisory rather than mandatory, giving users more flexibility. The exception is `index.skipHash`, which remains enforced to correct a previous incorrect setting (false) to the desired true value - a performance optimization that was fixed in an earlier patch.

The reorganization groups 18 general settings alphabetically, followed by platform-specific configurations. Windows-specific settings like `http.sslBackend` remain required, while `core.untrackedCache` stays disabled on Windows due to known performance issues. The patch maintains all the same configuration values but presents them in a more logical structure.

This continues the series' trend of making Scalar's configuration more maintainable and user-friendly while preserving the performance benefits it provides. The changes appear straightforward and build logically on the previous patches' documentation and auditing work.
