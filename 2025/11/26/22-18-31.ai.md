This is a documentation and maintenance patch series for Scalar's configuration settings, following up on a September discussion about improving config documentation.

The series starts by adding "# set by scalar" annotations to config lines modified by Scalar, as previously suggested by Patrick Steinhardt. It then audits and documents all Scalar config settings, uncovering some stale or incorrect values in the process. The author also takes the opportunity to alphabetize and simplify the config handling code.

Key technical details for future reference:
- Touches Documentation/scalar.adoc (158+ lines), scalar.c (81 lines modified), and tests
- Documents rationale for each config setting Scalar modifies
- Removes stale config values (specifics not shown in cover letter)
- Relaxes override settings in most cases
- Notes platform-specific issue with core.fscache (Git for Windows only)
- Test changes in t9210-scalar.sh suggest behavior verification

The work appears thorough, with significant documentation additions and code cleanup. The cover letter references prior discussion, showing this addresses an acknowledged need rather than introducing new functionality. The mention of platform-specific config (core.fscache) may require coordination with Git for Windows maintainers.
