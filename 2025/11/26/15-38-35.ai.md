This is a feature and bugfix pull request for gitk, addressing window geometry persistence and external diff handling for renamed files. The changes come from two contributors and include several merged branches.

The most notable change is Johannes Sixt's controversial reversal of a 2008 decision that stopped gitk from remembering window positions between sessions. The original change (b9bee11526ec) was made because some users found position restoration inconvenient, but Sixt is now proposing to restore this behavior to gather fresh feedback. This appears to be the primary motivation for the pull request.

The changes also introduce several other gitk improvements:
- Persistence of the Tags and Heads window geometry
- A bugfix for a misplaced 'continue' statement
- Better display of unescaped filenames in rename/copy lines
- Tobias Boesch's addition of external diff support for renamed files (likely addressing a long-standing limitation where external diffs didn't properly handle renames)

The code changes are substantial (87 lines modified) but focused in the main gitk script. The pull request appears well-structured with clear commit messages, though the window position restoration may generate discussion given its previously contentious nature. The external diff rename detection looks like a straightforward improvement to gitk's diff viewing capabilities.
