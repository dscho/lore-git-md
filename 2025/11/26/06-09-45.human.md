This is the third and final patch in a documentation series for `git-last-modified`, focusing on clarifying how the command handles path depth. The patch adds a new "NOTES ABOUT DEPTH" section to the man page, explaining the command's default behavior and interaction between the `--recursive` and `--max-depth` options.

The documentation clearly shows that by default, the command only reports on top-level paths, even when given a deeper pathspec. It provides concrete examples demonstrating how `--recursive` changes this behavior to show exact paths, and how `--max-depth` can be used to control recursion depth. The examples show both the command invocations and their expected output formats.

This completes the series' goal of documenting previously-undocumented features of `git-last-modified`. Like the previous patches, this change is purely additive documentation with no behavior modifications. The examples are clear and cover common use patterns, making the depth-related options more approachable for users. The patch follows the same clean style as the rest of the series, maintaining consistency with Git's documentation conventions.
