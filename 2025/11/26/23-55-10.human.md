Maintenance patch in the Scalar config documentation series. This is a reply to the first patch in the series, which adds "# set by scalar" annotations to config settings modified by Scalar.

Junio Hamano reviews the straightforward implementation that adds config file comments to help users identify Scalar-modified settings. While the current approach works fine with just two callsites, he suggests a potential refactoring into a helper function (`scalar_config_set()`) that would centralize the comment-adding logic. This would reduce duplication and make future maintenance easier, though he acknowledges the current implementation is perfectly functional.

The review also confirms the test changes look good, which verify the new annotations appear in the config file for both `core.preloadIndex` and `excludeDecoration` settings. This patch was previously suggested by Patrick Steinhardt and has now been implemented by Derrick Stolee as part of the larger effort to improve Scalar's config documentation and maintenance.
