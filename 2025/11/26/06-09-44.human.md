This is the second patch in a documentation series for `git-last-modified`, focusing on the `--max-depth` option. The patch adds comprehensive documentation for this existing but previously undocumented feature, which limits directory traversal depth when recursing.

The changes include adding `--max-depth` to both the command's SYNOPSIS and OPTIONS sections in the man page, with clear explanations of its behavior (including that positive values imply `--recursive` and negative means no limit). The implementation side adds corresponding initialization and handling in the C code, properly plumbing the option through to the underlying diff machinery that already supported this capability.

The patch follows the same clean, focused approach as the first in the series - it's well-scoped, clearly explains the feature's purpose and constraints, and maintains consistency with Git's existing documentation style. The author notes this is a useful everyday option that was previously missing from the command's documented interface.
