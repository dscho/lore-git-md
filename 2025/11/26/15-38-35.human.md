This is a feature and bugfix pull request for gitk, Git's graphical history viewer, focusing on window management and external diff behavior.

The main change is a controversial reversal of a 2008 decision that stopped gitk from remembering window positions between sessions. Johannes Sixt has restored this functionality to solicit feedback on whether it's still inconvenient (as argued in 2008) or if modern window managers make it more useful. The change is explicitly framed as provisional and open to reversion if needed.

The pull request includes several other improvements: persisting the position/size of the Tags and Heads window, fixing a control flow bug, showing unescaped filenames in rename/copy lines, and adding external diff support for renamed files (contributed by Tobias Boesch). The latter appears to be the most substantial technical change, with 69 lines added versus 18 deleted in the main gitk script.

The changes seem well-motivated and carefully considered, particularly the window position restoration which is presented as an experiment to gather user feedback. The external diff rename detection looks like a useful feature that brings gitk's behavior more in line with command-line Git's diff capabilities.
