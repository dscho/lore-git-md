Maintenance patch removing obsolete Scalar config settings. This is the third in a series cleaning up and documenting Scalar's configuration handling.

Derrick Stolee removes five config values that are either now Git defaults (core.preloadIndex, core.multiPackIndex, pack.useSparse), Windows-specific (core.fscache), or related to deprecated credential managers (credential.validate). Each removal is justified in the commit message, noting when defaults changed or why the setting is no longer relevant. The patch updates tests to use gui.gcwarning=false as a replacement check where core.preloadIndex was previously tested.
