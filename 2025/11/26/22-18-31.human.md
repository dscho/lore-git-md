This is a documentation and maintenance patch series for Scalar, Git's companion tool for large repositories. The series follows up on a September discussion about improving Scalar's configuration documentation and adding markers to show which config settings were set by Scalar.

The 5-patch series:
1. Adds "# set by scalar" comments to config lines
2. Justifies the use of index.skipHash=true for performance
3. Removes stale config values
4. Alphabetizes and simplifies the config settings
5. Adds thorough documentation of all Scalar config settings

The author notes they found some incorrect configs during the audit, including core.fscache which appears to be Windows-specific but was incorrectly included in main Git. The changes touch documentation, the scalar.c implementation, and test updates.

This appears to be a well-motivated cleanup that will help users understand Scalar's configuration choices while making the codebase more maintainable. The thorough documentation additions in particular should help future contributors understand the rationale behind Scalar's default settings.
