This is a "What's cooking" status update from Junio C Hamano, summarizing recent activity in the Git project. These periodic emails provide a snapshot of which patches are being considered for inclusion, which have graduated to stable branches, and which need more review.

Several notable changes have recently graduated to 'master':
- Submodules now properly enforce hash algorithm consistency (bc/submodule-force-same-hash)
- Attribute macro expansion was rewritten to avoid recursion (jk/attr-macroexpand-wo-recursion)
- UTF-8 display width fixes for "git repo structure" output (jx/repo-struct-utf8width-fix)
- OSX keychain credential helper fixes (kn/osxkeychain-idempotent-store-fix)
- Major refactoring of loose object handling (ps/object-source-loose)

New topics under consideration include:
- Improved shallow boundary handling for --shallow-since clones (sp/shallow-time-boundary)
- Config command error message improvements (rs/config-set-multi-error-message-fix)
- Completion support for short options (wm/complete-git-short-opts)

Several significant efforts continue cooking:
- A revamp of the object streaming interface (ps/object-read-stream)
- Refactoring around object database management (ps/object-source-management)
- New Rust infrastructure for SHA-1/SHA-256 interoperability (bc/sha1-256-interop-02)
- A new "git history" command for rewriting history (ps/history)

The email also notes several documentation updates, test fixes, and platform-specific improvements in progress. As usual, some patches are marked as needing rerolls based on feedback, while others appear ready to graduate to 'next' soon. This provides a comprehensive overview of the current state of Git development and what contributors should focus their review efforts on.
