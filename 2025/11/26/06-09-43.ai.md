Documentation patch for `git-last-modified`'s NUL termination option. This first patch in a 3-part series adds proper documentation for the `-z` flag in `git-last-modified`, which causes output lines to be NUL-terminated rather than newline-terminated. The changes include:

1. Adding `-z` to the SYNOPSIS section
2. Documenting the option's behavior in the OPTIONS section
3. Adding an OUTPUT section that describes both the default and NUL-terminated formats
4. Updating the builtin code to properly handle the option via a new `line_termination` field initialized to '\n'

The patch introduces a `LAST_MODIFIED_INIT` macro to initialize the struct with default values, including the line termination character. The output formatting logic is updated to respect this setting when writing paths, using either `write_name_quoted()` for newlines or direct printf with NUL for `-z` mode.

This is a straightforward documentation improvement for an existing but previously undocumented feature. The implementation changes are minimal and focused solely on supporting the documentation claims. The patch maintains consistency with Git's conventions for NUL-terminated output options seen in other commands.
