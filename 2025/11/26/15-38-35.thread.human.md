Johannes Sixt (Hannes) has successfully landed his gitk maintenance updates, which Junio Hamano has now merged into the main Git repository. The changes restore window position persistence - a feature that was removed in 2008 due to user complaints - along with geometry saving for Tags and Heads windows. While this restoration might prove controversial, Sixt has asked for community feedback on the revived behavior.

The merge also includes several uncontroversial improvements: a bugfix for control flow, better display of unescaped filenames in diffs, and Tobias Boesch's implementation of external diff support for renamed files, addressing a long-standing limitation. All changes are contained within the main gitk script. Users experiencing issues with the window positioning behavior are encouraged to provide feedback, as Sixt explicitly noted this aspect may need further adjustment.
