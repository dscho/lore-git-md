This is a feature patch introducing a new environment variable `GIT_REF_URI` to specify reference backends and their locations, addressing an asymmetry where Git already had `GIT_OBJECT_DIRECTORY` for objects but no equivalent for references.

The patch adds support for a URI-style format (`<ref_backend>://<URI-for-resource>`) that lets users specify both the backend type (files or reftable) and storage location. This is particularly useful for testing different backends or using alternative reference storage without modifying repository structure. The implementation checks the variable in `get_main_ref_store()` and handles initialization timing constraints around the repository's hash algorithm.

The patch includes comprehensive tests in a new file `t1423-ref-backend.sh` that verify error handling for malformed URIs and test reading/writing between different backend formats.
