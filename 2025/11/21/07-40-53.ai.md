This is a refactoring patch in Patrick Steinhardt's ongoing series to improve Git's object database streaming interface. Patch 8/19 introduces a dedicated `struct odb_packed_read_stream` for packed objects, following the same pattern established for loose and in-core streams in previous patches.

The change moves packed-object-specific fields (pack pointer and position) out of the union in `struct odb_read_stream` and into their own type-safe container. The patch updates all packed stream functions to use the new structure while maintaining identical external functionality. Key technical changes include:
- New `struct odb_packed_read_stream` embedding the base stream structure
- Removal of the `in_pack` union member from `odb_read_stream`
- Conversion of all packed stream functions to use the new structure
- Preservation of existing zlib stream handling logic
- Consistent memory allocation pattern with other stream types

The patch is well-contained (75 lines modified) and continues the series' architectural direction toward pluggable backends. It follows the same successful pattern seen in patches 6/19 (in-core streams) and 7/19 (loose object streams), further isolating implementation details into backend-specific structures while keeping the public interface stable.

This change is part of the broader effort to eliminate the union-based approach in favor of type-safe containers, making the code more maintainable and paving the way for future backend specialization. The patch maintains all existing functionality while making the packed object handling code more explicit and self-contained.
