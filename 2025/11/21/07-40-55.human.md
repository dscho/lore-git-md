This is patch 10/19 in Patrick Steinhardt's ongoing refactoring of Git's object database streaming interface. The series is systematically moving backend-specific data into dedicated structures to clean up the code and enable future pluggable backends.

The current patch focuses on moving zlib stream handling from the shared `odb_read_stream` base structure into the backend-specific structures for loose and packed objects. This completes the isolation of backend-specific state that began in earlier patches. The changes are mechanical but important for the architectural goal of decoupling the backends.

Key changes:
- Removes zlib stream fields from base structure
- Adds zlib stream and status fields to both `odb_loose_read_stream` and `odb_packed_read_stream`
- Updates all related functions to use the new backend-specific fields
- Maintains identical external behavior while improving internal organization

The patch follows the established pattern of the series and appears well-contained (104 lines modified). It represents another step toward the series' goal of type-safe, decoupled streaming backends. The changes are consistent with the architectural direction already reviewed and acked by maintainers in earlier patches.
