This is part of Patrick Steinhardt's ongoing refactoring series to eliminate `the_repository` usage in the object database streaming interface (patch 13/19). The patch focuses on removing the last two remaining uses of the global repository variable in the streaming subsystem.

The changes include:
1. Converting `open_istream_pack_non_delta()` to use the repository from the object database parameter it already receives
2. Renaming and modifying `stream_blob_to_fd()` to `odb_stream_blob_to_fd()` to explicitly require an object database parameter
3. Updating all callers (in cat-file, fsck, log, entry, and parallel-checkout) to pass `the_repository->objects`

The patch is straightforward mechanical work that continues the series' progression toward isolating repository state. It maintains all existing functionality while making the code more explicit about its dependencies. The changes are well-contained, touching only the streaming interface and its direct callers, with no behavioral changes beyond the intended removal of `the_repository` usage.
