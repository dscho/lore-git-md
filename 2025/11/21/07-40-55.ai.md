Refactoring patch in Patrick Steinhardt's ODB streaming interface series, moving zlib stream handling into backend-specific structures. This is patch 10/19 in the v2 series that's systematically refactoring Git's object streaming internals.

The patch relocates the zlib stream state from the shared `odb_read_stream` base structure into the backend-specific `odb_loose_read_stream` and `odb_packed_read_stream` structures. This completes the isolation of backend-specific data that began in earlier patches, fully detangling the loose and packed object implementations from each other. The changes include:

1. Removing the shared `git_zstream z` and `z_state` enum from the base structure
2. Adding backend-specific zlib state tracking with new enums (`ODB_LOOSE_READ_STREAM_*` and `ODB_PACKED_READ_STREAM_*`)
3. Moving all zlib-related operations into the backend-specific stream implementations
4. Updating the loose object stream to use its own zlib context rather than sharing one
5. Maintaining identical external functionality while improving internal separation

The change is well-contained (104 lines modified in streaming.c) and follows the established pattern from previous patches in the series. It represents another step toward the series' goal of creating properly isolated streaming backends while preserving the existing behavior. The patch appears technically sound and consistent with the architectural direction established by earlier patches in the series.
