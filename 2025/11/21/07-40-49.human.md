This is part 4/19 in Patrick Steinhardt's ongoing refactoring of Git's object database streaming interface, continuing the effort to enable pluggable backends. The patch focuses on improving the packed object streaming code.

The change modifies how packed object streaming handles packfile information. Currently, the caller populates stream fields before calling the open function, which creates an implicit coupling between the caller and implementation details. The patch makes this explicit by passing the packfile and offset directly to `open_istream_pack_non_delta()`, which then stores them in the stream struct.

This is a clean refactoring that improves code clarity by making the interface more explicit. The change is small (10 lines added/removed) and focused, maintaining the same behavior while preparing for future patches that will move stream allocation into the function itself. The patch follows the series' pattern of incremental improvements to the streaming interface, with each change building on prior consensus.
