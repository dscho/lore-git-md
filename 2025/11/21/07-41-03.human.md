This is patch 18/19 in Patrick Steinhardt's series refactoring Git's object database streaming interface. The patch moves the streaming implementation files (`streaming.{c,h}`) into a new `odb/` subdirectory to better reflect their purpose as part of the object database subsystem.

The change is straightforward - it renames and relocates the files while updating all the include paths across 15 different files that reference them. The patch follows the conceptual shift established in earlier patches that oriented the streaming interface around the object database rather than being a more generic facility.

This is primarily a code organization change that doesn't modify functionality, completing the physical restructuring to match the logical restructuring done in previous patches. The series is nearing completion with only one patch remaining after this one.
