This is patch 16/19 in Patrick Steinhardt's ongoing refactoring of Git's object database streaming interface, focusing on moving packed object stream handling into the packfile backend.

The patch relocates the packed object streaming implementation from streaming.c to packfile.c, following the same pattern as previous patches in the series that moved loose object handling. The core functionality remains unchanged - it still handles non-delta packed objects (commits, trees, blobs and tags) by managing zlib inflation state and pack window access. The key changes are:

1. The `odb_packed_read_stream` struct and its methods (`read_istream_pack_non_delta`, `close_istream_pack_non_delta`) move verbatim to packfile.c
2. A new public interface `packfile_store_read_object_stream()` is exposed in packfile.h
3. The streaming.c caller now uses this backend-specific function rather than containing the implementation

This continues the series' systematic approach of giving backend implementations (loose objects, packed objects) more control over their streaming details while maintaining a consistent interface. The change results in a significant code reduction in streaming.c (135 lines removed) with corresponding additions to packfile.c. 

The patch appears well-contained and mechanical, following the established pattern from previous patches in the series. It touches only the expected files (packfile.c, packfile.h, streaming.c) and maintains all existing functionality while better encapsulating the packed object streaming details.
