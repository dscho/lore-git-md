This is patch 5/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch moves stream allocation into backend-specific functions, preparing for a future where each backend manages its own stream structure with a common base.

The key change here is making backend functions responsible for allocating their own stream structures, rather than having the allocation happen generically. This enables the planned design where backends will embed a common `struct odb_read_stream` within their own backend-specific structures. Karthik Nayak raised questions about memory management and static initialization, which Patrick clarifies will be handled properly as the series progresses - the static definition is temporary and will be copied to allocated memory.

This continues the series' methodical approach to restructuring the streaming interface, with Patrick confirming the memory management model will be cleaned up in later patches.
