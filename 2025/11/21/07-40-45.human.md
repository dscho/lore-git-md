This is a major refactoring series (19 patches) from Patrick Steinhardt that reorganizes Git's object streaming infrastructure to better support pluggable object databases. It's part of the ongoing effort to make Git's object storage more modular.

The series systematically moves streaming logic out of the centralized "streaming.c" and into backend-specific implementations, with each object source (loose, packed, etc.) responsible for its own streaming behavior. Key changes include:

1. Renaming the core `git_istream` to `odb_read_stream` (already acked by Junio)
2. Moving stream allocation and management into backend-specific code
3. Creating dedicated structures for each stream type (in-core, loose, packed, filtered)
4. Eventually making the streaming interface object-database-centric rather than repository-centric

The v2 iteration incorporates review feedback from Justin Tobler and Karthik Nayak, with improvements to commit messages, style fixes, and the addition of a new patch (19/19) to clean up redundant type/size parameters that were identified during review.

The changes are extensive (~1500 lines removed, ~1700 added) but carefully incremental, with temporary scaffolding maintained where needed. The series has active reviewer engagement and maintainer approval on the foundational changes, suggesting it's on a good trajectory. For those working on Git's storage layer or interested in the pluggable ODB effort, this is likely worth following closely.
