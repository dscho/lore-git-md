This is patch 17/19 in Patrick Steinhardt's object database streaming interface refactoring series, focusing on making the interface object-database-centric rather than repository-centric.

The patch renames and relocates the core streaming functions to operate on `struct object_database` rather than `struct repository`:
- `open_istream()` becomes `odb_read_object_stream()`
- `read_istream()` becomes `odb_read_stream_read()`
- `close_istream()` becomes `odb_read_stream_close()`

Key technical changes:
- Updates all callers (archive-tar.c, archive-zip.c, builtin/index-pack.c, builtin/pack-objects.c, object-file.c) to use the new names
- Modifies the internal `istream_source()` helper to take an object_database parameter
- Adds detailed docstrings for the new public functions in streaming.h
- Maintains all existing functionality while changing the interface orientation

The changes follow the series' pattern of gradually shifting responsibility to object database backends. This patch completes the conceptual shift from repository-focused to ODB-focused streaming, which was prepared by earlier patches that moved implementation details into backend-specific code. The docstrings now explicitly document the streaming API's contract.

The patch touches 7 files with 71 insertions and 51 deletions, primarily mechanical renames with some interface doc improvements. It builds on the foundation laid by previous patches that isolated stream implementations into their respective backends (loose objects in object-file.c, packed objects in packfile.c).
