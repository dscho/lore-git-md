This is the final patch in Patrick Steinhardt's object database streaming interface refactoring series, completing the cleanup of redundant parameters. The patch removes now-unnecessary `type` and `size` out-parameters from `odb_read_object_stream()`, since these values are already available in the public `struct odb_read_stream` that was exposed in earlier patches.

The change is straightforward and mechanical, updating all callers to access the type and size from the stream structure instead. The patch affects several key areas including archive generation (`archive-tar.c`, `archive-zip.c`), pack operations (`builtin/index-pack.c`, `builtin/pack-objects.c`), and object verification (`object-file.c`). Each caller is updated to either drop the now-unused parameters or read the values from the stream structure when needed.

This concludes the series' technical work after the earlier architectural changes that moved streaming code to the odb/ subdirectory and reorganized the interfaces. The patch maintains all existing functionality while simplifying the API surface. With this change, the streaming interface now cleanly exposes object metadata through the stream structure rather than requiring separate output parameters.
