Refactoring patch in Patrick Steinhardt's object database streaming interface series (17/19). This continues the systematic reorganization of Git's streaming interface to be object-database-centric rather than repository-centric.

The patch renames the core streaming functions to reflect their new focus:
- `open_istream()` becomes `odb_read_object_stream()`
- `read_istream()` becomes `odb_read_stream_read()`
- `close_istream()` becomes `odb_read_stream_close()`

The changes propagate through several callers including archive utilities (tar/zip), pack operations, and object-file handling. The new names better reflect the actual object database operations being performed and align with the series' goal of making the ODB interface more explicit.

This is a mechanical change that follows the pattern established in earlier patches of the series, completing the transition to direct ODB operations. The patch maintains all existing functionality while updating the interface naming to match the new architectural approach. With this change, nearly all pieces are in place for the final parameter cleanup in patch 19/19.
