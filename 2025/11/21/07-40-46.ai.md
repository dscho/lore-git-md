This is the first patch in Patrick Steinhardt's 19-part refactoring series for pluggable ODB backends, focusing on renaming the `git_istream` structure to `odb_read_stream`. The change aligns with the existing `odb_write_stream` naming and prepares for moving streaming functionality into the object database subsystem.

The patch mechanically renames the structure and all related functions across 7 files (~100 lines changed), updating callers in archive utilities, pack operations, and object streaming code. The commit explains this is groundwork for making the stream interface more generic and backend-controlled in subsequent patches.

Key technical details:
- Renames core structure and all function signatures (`open_istream` -> `open_odb_read_stream` etc.)
- Maintains identical behavior - pure refactoring with no logic changes
- Touches streaming internals (zlib handling, filters) and public API
- Keeps existing function names (`open_istream`) as wrappers for compatibility
- Part of broader effort to isolate streaming into ODB backends

The patch has maintainer approval from Junio Hamano and fits cleanly into the series' incremental approach. It demonstrates the careful, reviewable progression characteristic of this backend refactoring work.
