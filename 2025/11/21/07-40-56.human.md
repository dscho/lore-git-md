This is part 11/19 of Patrick Steinhardt's ongoing refactoring series to improve Git's object database streaming interface. The patch focuses on packed object handling, extracting the logic for reading object information from packfiles into a new standalone function `packfile_store_read_object_info()`.

1. Moving packed object info reading from `do_oid_object_info_extended()` to the new function in packfile.c
2. Making `find_pack_entry()` a static implementation detail rather than exposing it in packfile.h
3. Reorganizing related functions to maintain proper declaration order

This continues the series' pattern of isolating implementation details while maintaining the same external behavior. The change is well-contained (100 lines modified across 3 files) and follows the architectural direction established in earlier patches. The commit message clearly explains the motivation - this prepares for future changes while cleaning up the interface by hiding `find_pack_entry()`.
