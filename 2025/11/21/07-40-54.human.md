This is part of Patrick Steinhardt's ongoing refactoring of Git's object database streaming interface (patch 9/19 in the series). The patch introduces a dedicated `struct odb_filtered_read_stream` for handling filtered object streams, continuing the pattern established in previous patches for in-core, loose, and packed object streams.

The change moves away from using a union in the base `odb_read_stream` structure, instead creating a type-safe container that embeds the base stream structure. This makes the code more maintainable by eliminating the need for type-unsafe casting and clearly separating the concerns of different stream types. The patch is well-contained (54 lines modified) and follows the same successful approach seen in earlier parts of the series.

This completes the transition for all major stream types in the ODB interface, paving the way for future work on pluggable backends. The series has been progressing incrementally with maintainer ack on foundational changes and consensus from other contributors on key design decisions.
