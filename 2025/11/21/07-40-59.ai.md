This is part of Patrick Steinhardt's ongoing refactoring of the object database streaming interface (patch 14/19 in the series), specifically targeting the `the_repository` removal effort.

The patch makes the `struct odb_read_stream` definition public by moving it from streaming.c to streaming.h, along with its associated function pointer types. This is preparation for upcoming changes where backend subsystems will need direct access to the stream structure when allocating their own streams. The change includes:
- Moving the struct definition and its `close_fn`/`read_fn` typedefs to the header
- Adding documentation for the stream structure
- Keeping the same functionality while making the internals accessible to backends
- Touching only 2 files with minimal churn (14 lines added, 12 removed)

This follows the series' pattern of incrementally exposing more of the streaming internals to support the backend-specific implementations. The change is straightforward and mechanical, with no apparent controversy based on the thread history. The patch maintains all existing functionality while enabling the next steps in the refactoring where backends will take more control over stream allocation.
