This is a refactoring patch in Patrick Steinhardt's series to enable pluggable ODB backends, specifically addressing the deferred stream opening mechanism.

The patch removes the two-phase initialization of object streams by eliminating the `open()` callback from the streaming infrastructure. Justin Tobler had questioned whether there was any valid use case for delayed stream opening, to which Patrick confirms there are no current uses in the codebase and no apparent need for this capability.

This change simplifies the streaming interface by making stream creation immediate rather than deferred, which aligns with the series' goal of standardizing and cleaning up the object streaming infrastructure. The removal of this unused complexity paves the way for subsequent patches that will move stream allocation into backend-specific logic.

The discussion shows consensus between Patrick and Justin on this simplification, with no objections raised to the technical approach. This continues the series' methodical progression of making focused, behavior-preserving changes while removing unnecessary indirection in preparation for pluggable backends.
