Refactoring patch in Patrick Steinhardt's ODB streaming interface series, introducing a dedicated structure for loose object streams. This is part 7/19 of the larger effort to enable pluggable object database backends.

The patch creates a new `struct odb_loose_read_stream` that contains the base stream structure plus loose-object-specific fields, removing these fields from the union in `struct odb_read_stream`. This follows the same pattern as patch 6/19 did for in-core streams, continuing the series' move toward type-safe stream implementations. The changes are mechanical - converting access to the old union fields to use the new structure's members while maintaining identical functionality.

Key technical changes:
- New `struct odb_loose_read_stream` embeds base stream and adds loose-specific fields (mapping info, header buffers)
- Removes `loose` union member from `odb_read_stream`
- Updates all loose stream functions to use new structure
- Maintains same external behavior while improving type safety
- Follows established pattern from prior patches in the series

The change is well-contained (85 lines modified) and continues the architectural direction of the series. Like previous patches, this moves toward the goal of eliminating the union-based approach in favor of type-specific structures, making the code more maintainable and better positioned for pluggable backends. The patch appears straightforward with no obvious technical issues.
