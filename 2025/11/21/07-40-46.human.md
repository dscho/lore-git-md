Refactoring patch in Patrick Steinhardt's series for pluggable ODB backends. This is the first of 19 patches that continues the effort to make object database backends more modular.

The patch renames `git_istream` to `odb_read_stream` to better reflect its role in the object database subsystem and to mirror the existing `odb_write_stream` naming. This is a preparatory change for making the streaming interface more generic and backend-controlled in later patches.

The change is mechanical but widespread, touching 7 files with 43 line changes. It maintains all existing functionality while updating the type name consistently across the codebase. The patch has already received maintainer approval from Junio C Hamano in previous iterations.

This is part of a larger architectural effort to isolate streaming logic into backend-specific code, with the series ultimately aiming to remove redundant parameters and better organize the ODB interface. The rename establishes consistent terminology early in the refactoring process.
