This is a bugfix patch addressing an issue with the Meson build system's handling of the `git-contacts` Perl script. The problem occurs when installing Git with `-Dcontrib=contacts` - the script is installed but not marked executable, causing Git to fail to recognize it as a valid command.

The patch modifies `generate-perl.sh` to explicitly mark `git-contacts` as executable during generation, similar to how it handles `.perl` files. The change is minimal - just adding `|*git-contacts` to the case statement that determines which files should be made executable. The author notes this should be independent of a prerequisite patch they reference, though they don't explain what that other patch does.

The issue was discovered during packaging when `git contacts` failed with "'contacts' is not a git command" despite the contacts contrib script being requested. The fix follows the pattern used for other Perl scripts, though unlike `generate-script.sh`, this doesn't test the basename but rather globs the full script name.

Key technical details for future reference:
- File modified: `generate-perl.sh`
- Change: `*.perl` -> `*.perl|*git-contacts` in executable marking case statement
- Build system context: Meson with `-Dcontrib=contacts`
- Error symptom: Git doesn't recognize installed `contacts` command
- Related to but independent of some other patch referenced as [1]
