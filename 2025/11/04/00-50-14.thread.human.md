This thread announces the start of the translation cycle for Git 2.52.0, coordinated by Jiang Xin, the project's Chinese translation maintainer. The email outlines the updated workflow for contributors, noting that the translation template file is now generated on demand rather than stored in the repository. Contributors should update their language-specific PO files using `make po-update` after syncing with Git's master branch, with specific guidance provided about handling file location comments consistently.

The message references the dedicated git-l10n/git-po repository for submitting translations and mentions the automated git-po-helper CI pipeline that validates contributions. Jiang Xin sets a firm deadline of November 15, 2025 for translation submissions to be included in the upcoming release. This follows Git's well-established localization workflow while providing updated technical instructions for this release cycle.
