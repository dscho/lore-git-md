This thread investigated a report of `git grep -l` incorrectly displaying dashes as colons in filenames. After thorough analysis, the community members determined this was not a Git regression but rather an interaction with the Delta pager, which has a known behavior of transforming dashes to colons (documented in Delta's issue #1259). The issue was reproducible across Git versions 2.47.3 through 2.51.1 when using Delta, but disappeared with other pagers or `--no-pager`.

Key participants Michael Roach (original reporter), Kristoffer Haugsbakk, and Lucas Seiki Oshiro confirmed the findings through testing and linking to the Delta issue. The thread has reached consensus that no Git changes are needed, as the behavior is correct when not using Delta. The most recent email is just a brief acknowledgment between participants about communication logistics, with no new technical developments. Unless new information emerges about pager interactions, this thread appears resolved with the issue properly attributed to Delta's behavior.
