This thread investigated a report of `git grep -l` incorrectly displaying dashes as colons in filenames. After thorough analysis by multiple participants, the issue was conclusively traced to the Delta pager's known behavior (documented in Delta issue #1259) rather than a Git regression. Testing confirmed the problem only occurs with Delta and disappears when using `--no-pager` or alternative pagers like `less`.

The discussion involved Michael Roach (original reporter), Kristoffer Haugsbakk (who reproduced with Delta), and Lucas Seiki Oshiro (who linked the definitive Delta issue). All agreed this was a Delta-specific behavior, with Git's pager handling working as intended across versions 2.47.3 through 2.51.1. The thread concluded with a brief administrative note from Roach acknowledging a mailing list etiquette oversight (not using "Reply All" initially) and thanking participants. No further technical investigation appears needed, though the project may want to consider documenting known pager interaction caveats in the future.
