This is a bugfix for the Meson build system's handling of the `git-contacts` Perl script. 

The patch addresses an issue where `git-contacts` fails to work when installed via Meson with `-Dcontrib=contacts` because the script isn't marked as executable during installation. This causes Git to incorrectly report that "contacts" is not a valid command. 

The fix modifies `generate-perl.sh` to explicitly mark `git-contacts` as executable, similar to how it handles other Perl scripts. The change is minimal - just adding `|*git-contacts` to the case statement that determines which files should be made executable.

The author notes they discovered this issue while packaging Git and confirmed the problem exists upstream. The patch appears straightforward and well-tested, building on prior work in the area (referencing a previous related patch). This seems like a simple but useful fix for anyone using the Meson build system with Git's contrib scripts.
