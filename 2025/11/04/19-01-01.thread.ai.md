Git for Windows 2.52.0-rc0 release announcement. First release candidate in the Windows distribution pipeline based on Git v2.52.0-rc0, bundled with PCRE2 v10.47. Provides installers, portable versions, and MinGit variants for both 64-bit and ARM64 architectures. SHA-256 checksums included for all distribution formats. Reiterates previously announced deprecation of `git svn` support in Git for Windows. No new technical changes or known issues mentioned - appears to be a routine maintenance update in the Windows-specific release cycle.
