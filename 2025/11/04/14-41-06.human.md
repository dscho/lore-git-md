CI / build system patch adding HTML documentation path configurability to Meson builds. This follows up on D. Ben Knoble's initial patch to make Git's HTML doc installation path configurable in Meson, mirroring existing Makefile behavior. The change is particularly useful for distributions like Gentoo that use version-specific doc directories.

Junio C Hamano provides a maintainer's review, noting the change makes sense but suggesting a meson expert should verify the implementation. He expresses surprise that Meson currently has so few path configuration options (only `perllibdir` before this addition) and that path options use simple string types rather than more specialized path types.

The patch itself adds an `htmldir` meson option defaulting to `datadir/doc/git-doc`, modifies 7 build files to use this configurable path, and ensures the configured path propagates to `git --html-path` output. Knoble has already tested this successfully with a modified Gentoo ebuild.

This appears to be a straightforward build system improvement with clear packaging benefits. The implementation looks clean and well-tested, though as Junio notes, a Meson expert's review would be valuable to confirm the approach. The patch is queued for further discussion.
