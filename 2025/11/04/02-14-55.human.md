This is a feature proposal adding a new diff option to report binary file status in raw diff output. Justin Tobler proposes adding `--report-binary-files` to explicitly indicate which files in a diff pair Git considers binary, addressing the current limitation where the "Binary files differ" message doesn't specify which files triggered it.

The patch adds a new column to raw diff output showing 'b' for binary and 't' for text files, appearing before the status (e.g., `bb M` for two binary files being modified). The implementation touches diff formatting internals and includes thorough documentation updates and test coverage. Justin mentions considering but rejecting an alternative approach of modifying the human-readable "binary files differ" message, favoring the machine-readable raw format instead.

The patch appears well-constructed with clear motivation, proper documentation, and tests verifying the new behavior. The author explicitly invites feedback on the implementation approach, suggesting this is an early iteration they're open to refining. This could be useful for tooling that needs to programmatically determine binary status during diff processing.
