Thread summary:

Bugfix for Meson build system's handling of the `git-contacts` Perl script in the contrib directory. When installing Git with `-Dcontrib=contacts`, the script was being installed without executable permissions, causing Git to fail to recognize it as a valid command ("'contacts' is not a git command"). The patch modifies `generate-perl.sh` to explicitly mark `git-contacts` as executable during generation, following the same pattern used for `.perl` files. The change adds `|*git-contacts` to the case statement that determines which files should be made executable. The issue was discovered during packaging. The fix is independent of some other prerequisite patch referenced as [1] but not described. Key technical details: modified file is `generate-perl.sh`, change affects executable permission setting for the contacts script in Meson build with contrib contacts enabled.
