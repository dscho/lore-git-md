This is a localization (l10n) workflow announcement for Git 2.52.0, kicking off the translation cycle for the upcoming release. Jiang Xin, the l10n coordinator, outlines the process for contributors to update translations, with 84 messages needing translation since the last release.

The email describes the modernized process where the `po/git.pot` template file is no longer stored in the repository but can be generated on demand. Contributors are instructed to update their language-specific `po/XX.po` files using `make po-update` after pulling latest changes from Git's master branch. The message includes specific guidance about handling file location comments in PO files - either keeping just filenames (using `msgcat --add-location=file`) or removing locations entirely (using `msgcat --no-location`), with a warning not to mix approaches.

The email references the git-l10n/git-po repository for pull requests and mentions the git-po-helper CI pipeline that validates translation contributions. A hard deadline of November 15, 2025 is given for submission of translation updates. The message follows Git's established l10n workflow patterns while providing specific technical instructions for this release cycle's contributors.
