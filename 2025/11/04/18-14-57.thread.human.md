This thread addresses a bug in the Meson build system where the `git-contacts` Perl script from the contrib directory wasn't being marked as executable during installation when built with `-Dcontrib=contacts`. The issue was discovered during packaging when `git contacts` commands failed despite the script being present.

The fix modifies `generate-perl.sh` to explicitly mark `git-contacts` as executable during generation, following the same pattern used for other Perl scripts. The change is minimal - just adding the script name to a case statement that determines which files should be executable. The author notes this should work independently of another patch they reference, though the details of that prerequisite change aren't explained in this email. 

The problem manifests when installing Git with the contacts contrib script enabled, where the script gets installed but remains non-executable, causing Git to fail to recognize it as a valid command. The fix ensures the script will be properly executable after installation.
