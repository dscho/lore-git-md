This is a refactoring patch in Junio Hamano's series introducing "incomplete-line" whitespace handling. It fixes a hack in the `diff_suppress_blank_empty` feature that was misusing the `CONTEXT_INCOMPLETE` symbol meant for "\ No newline at end of file" cases.

The patch moves the blank-empty suppression logic to where context lines are first processed in `emit_line_ws_markup()`, rather than having it scattered through the diff pipeline. This makes the feature more maintainable by:
1. Localizing the blank-empty conversion to one clear spot
2. Preventing confusion with the incomplete-line marker path
3. Adding a BUG() check to catch future misuse of the incomplete-line case

Key technical changes:
- Moves blank-empty handling from `fn_out_consume()` to `emit_line_ws_markup()`
- Simplifies the DIFF_SYMBOL_WORDS case by removing conditional line skipping
- Adds explicit check that incomplete lines start with backslash
- Removes redundant length adjustment for blank-empty lines

This is part of the series' pattern of cleaning up existing whitespace handling before introducing the new incomplete-line feature. The changes are surgical and maintain existing behavior while making the code more robust - a typical preparatory patch in Junio's careful style. The BUG() addition suggests this area has been error-prone in the past.
