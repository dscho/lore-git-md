This is a routine release announcement for Git for Windows 2.52.0-rc0, the Windows-specific distribution based on Git 2.52.0-rc0. Johannes Schindelin (Dscho) has packaged the release with PCRE2 v10.47 and provides installers, portable versions, and MinGit variants for both 64-bit and ARM64 architectures. The announcement includes SHA-256 checksums for verification but contains no new technical developments - it simply follows the standard release process. The email reiterates the previously announced deprecation of `git svn` support in Git for Windows, though this isn't new to this particular release. The availability of ARM64 builds alongside x64 continues Git for Windows' multi-architecture support.
