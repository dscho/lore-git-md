Key technical details under discussion:
- Output format options being evaluated:
  * Letter codes ("bt,ic,cl") for binary/text, incomplete lines, CRLF/LF
  * Key=value pairs ("binary=1,crlf=0")

- N-way diff support through extended tuples (additional letters per parent)
- Future extensibility mechanisms to accommodate new attributes

Open questions and design challenges:
1. Format selection tradeoffs:

2. Implementation complexity of:
   - Parsing rules for variable attribute sets
   - Combined diff handling with multiple parents
3. Whether to standardize on boolean attributes or allow mode-specific values
4. The exact syntax for attribute separation and line placement
