This is a follow-up in the thread about the `git grep -l` output formatting regression with filenames containing dashes. Kristoffer Haugsbakk reports observing similar behavior when using the Delta pager (a syntax highlighting tool for Git output), where hyphens in filenames get replaced with colons. They note this doesn't occur with `--no-pager`, but are unsure about the coloring aspect even when using `--color=never`.

The email suggests the issue might not be limited to Git's core grep functionality but could potentially involve interaction with external pagers. This adds a new dimension to the investigation, indicating the regression might manifest differently depending on the output pipeline configuration. The Delta pager connection provides another potential test case for reproducing and diagnosing the issue, though the core problem remains the unexpected transformation of dashes to colons in filename output.
