Thread identity: Bug report and fix for `git add` behavior with exclude patterns (`:(exclude)`) interacting with `.gitignore` rules, reported by René Rahn, with proposed fix from Junio Hamano.

Core problem: `git add` incorrectly warns about ignored files when they are explicitly excluded via pathspec magic (`:(exclude)`). The exclude pattern should make `.gitignore` warnings redundant, but current implementation treats exclude patterns as positive matches, forcing users to use `-f` flag as a workaround with undesirable side effects.

Current status: Junio Hamano has proposed a fix modifying `dir.c` to properly handle exclude patterns. The patch introduces separate tracking for exclude patterns versus regular pathspec elements, applying correct "match any positive but no negative" logic. Includes new test case in `t/t2204-add-ignored.sh` verifying fixed behavior where excluded+ignored files are silently skipped without warning.

Key technical details:
- Fix targets pathspec processing in `dir.c`, specifically how exclude patterns interact with ignore rules
- Identifies potential regression origin in 2017's e1b8c7bd (dir: remove struct path_simplify)
- New test confirms both warning behavior for regular adds of ignored files and silent exclusion with pathspec magic
- Changes pathspec matching logic to properly distinguish exclude patterns from positive matches
