Git 2.52.0 localization (l10n) cycle announcement from Jiang Xin, the Chinese translation maintainer and l10n coordinator. The thread initiates the translation process for the upcoming release, with 84 messages requiring translation since Git 2.51.0. 

Key technical details: The translation workflow has modernized - the `po/git.pot` template file is no longer versioned but generated on demand. Contributors must update their language-specific `po/XX.po` files using `make po-update` after syncing with Git's master branch. Two approaches are specified for handling file location comments in PO files: either keep only filenames (via `msgcat --add-location=file`) or remove locations entirely (via `msgcat --no-location`), with a strict prohibition against mixing these approaches.

The git-l10n/git-po repository serves as the submission point via pull requests, with validation handled by the git-po-helper CI pipeline. A firm submission deadline of November 15, 2025 is established for translation updates. This follows Git's standard l10n workflow patterns while providing release-specific technical instructions for contributors.
