This is a refactoring patch in Junio Hamano's series introducing "incomplete-line" whitespace error detection. It focuses on the rewrite-diff codepath that bypasses xdiff machinery.

The patch removes a special-case hack (DIFF_SYMBOL_NO_LF_EOF) that was handling incomplete lines in rewrite diffs, replacing it with a more consistent approach that uses the same DIFF_SYMBOL_CONTEXT_INCOMPLETE path as normal diffs. The key changes are:

1. Deletes the DIFF_SYMBOL_NO_LF_EOF enum and its handler
2. Modifies emit_rewrite_lines() to:
   - Allocate and modify temporary buffers for incomplete lines
   - Use the new emit_incomplete_line() helper introduced in patch 05
   - Track last_line_kind (added in patch 04) for proper line counting
3. Maintains the same output behavior while removing special cases

The changes continue the series' pattern of cleaning up diff infrastructure before introducing the new whitespace feature. This particular refactoring makes the rewrite-diff path behave more like regular diffs, which will be important when the new WS_INCOMPLETE_LINE detection is added in later patches. The removal of the NO_LF_EOF special case simplifies the code while preserving all existing functionality.
