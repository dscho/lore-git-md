Refactoring patch in the incomplete-line whitespace detection series, focusing on the rewrite-diff codepath.

This patch cleans up how the rewrite-diff codepath (used for complete file rewrites) handles incomplete lines (those missing terminating newlines). Currently it uses a special DIFF_SYMBOL_NO_LF_EOF token as a hack to inject the standard "\ No newline at end of file" marker. The patch replaces this with proper handling that treats incomplete lines consistently with how they're handled in other diff paths.

Key changes:
- Removes the DIFF_SYMBOL_NO_LF_EOF enum and related special-case code
- Modifies emit_rewrite_lines() to properly handle incomplete final lines by temporarily adding a newline for processing
- Uses the new emit_incomplete_line() helper introduced in patch 05/12
- Maintains the same output behavior while removing special cases

This is part of the larger series adding WS_INCOMPLETE_LINE whitespace detection, and continues Junio's pattern of cleaning up related code before introducing new functionality. The change is surgical and well-explained, with clear motivation and clean diffs. It builds on previous infrastructure improvements in the series while keeping behavior consistent across diff codepaths.
