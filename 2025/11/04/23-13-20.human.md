This is a CI/build system patch updating GitHub Actions workflows to use newer macOS runners. Junio Hamano notes that the current macos-13 images are being deprecated (removed December 4th) and replaces them with macos-14 images across four CI jobs that test Git on macOS with different compilers and configurations.

The change is straightforward - just updating the runner specification in the YAML file - though the commit message cautions there may be additional adjustments needed since tool versions could differ between the old and new images. This appears to be a proactive maintenance change to keep CI working rather than fixing any current breakage.

As the maintainer submitting this, Junio flags it as a "monkey-see-monkey-do" patch, suggesting it's following standard procedure for CI updates rather than introducing anything novel. The change is minimal and low-risk, affecting only test infrastructure.
