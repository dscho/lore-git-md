CI / build system update to migrate macOS CI jobs from deprecated macos-13 to macos-14 images.

This straightforward patch updates the GitHub Actions workflow file to use macos-14 instead of the soon-to-be-removed macos-13 images. The change affects four CI jobs that run on macOS: osx-clang, osx-reftable, osx-gcc, and osx-meson. The author notes this is a direct replacement ("monkey-see-monkey-do") and cautions there may be additional adjustments needed due to potential tool version differences on the new images.

The patch comes from the project maintainer and appears timely, as the macos-13 images will be fully dropped on December 4th after being deprecated since September 22nd. While the change is mechanical, the note about possible tool version differences suggests this may need follow-up testing or adjustments if the CI jobs start failing with the new image.
