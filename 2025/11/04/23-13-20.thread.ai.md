CI / build system update to migrate macOS CI jobs from deprecated macos-13 to macos-14 images in GitHub Actions workflow. Affects four jobs: osx-clang, osx-reftable, osx-gcc, and osx-meson. Maintainer notes this is a direct replacement but cautions about potential tool version differences requiring follow-up adjustments. Timely change as macos-13 images will be fully dropped December 4th after deprecation since September 22nd.
