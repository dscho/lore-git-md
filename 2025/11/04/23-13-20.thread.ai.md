CI / build system update to migrate macOS CI jobs from deprecated macos-13 to macos-14 images in GitHub Actions workflow. Affects four jobs: osx-clang, osx-reftable, osx-gcc, and osx-meson. Maintainer Junio C Hamano notes this is a direct replacement but cautions about potential tool version differences requiring follow-up adjustments. The change is being fast-tracked to ensure CI passes for upcoming releases, with macos-13 images being fully dropped December 4th after deprecation since September 22nd. The patch has already been test-merged to 'master' and 'next' branches and appears sufficient for CI to pass, showing simple string replacements in the workflow file's job definitions. While the immediate change is straightforward, the maintainer anticipates possible future adjustments for toolchain version differences on the new images.
