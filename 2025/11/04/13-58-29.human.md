This is a build system patch that adds configurability for HTML documentation paths in Meson builds, matching existing Makefile functionality.

D. Ben Knoble's patch introduces a new `htmldir` option for Meson builds, allowing packagers to specify where Git's HTML documentation should be installed. This brings Meson builds in line with Makefile builds, which already support this via the `htmldir` variable. The change is motivated by distributions like Gentoo that use version-specific documentation paths (e.g., `/usr/share/doc/git-2.51/html`).

The patch modifies several Meson build files to use the new `htmldir` variable instead of hardcoding the path to `datadir/doc/git-doc`. It also adds the configuration option to `meson_options.txt` and updates the path used in `GIT_HTML_PATH` compilation definition. The changes are straightforward and focused, touching only documentation installation paths while maintaining the same behavior when no custom path is specified.

The author has tested the change with a modified Gentoo ebuild and reports good results. The patch appears well-targeted and should be uncontroversial for merging, as it simply extends existing functionality to the Meson build system without changing behavior for users who don't customize the path.
