Junio C Hamano has completed his patch series introducing a new "incomplete-line" whitespace check for missing terminating newlines in files. The 12-part series has progressed through infrastructure cleanups (patches 01-09), implementation of the new check in both apply (10/12) and diff (11/12) machinery, and now concludes with enforcement across Git's own codebase in patch 12/12.

The final patch modifies `.gitattributes` to activate the WS_INCOMPLETE_LINE check (bitmask 0x8000) for all C source/header files and shell scripts in the project. This means Git will now flag missing newlines at end of files as errors in its own development, while still allowing fixes to existing cases. The implementation builds on comprehensive test coverage in t4015 and maintains consistent behavior across diff and apply operations.

The series shows Junio's characteristic attention to detail, with each patch carefully preparing the infrastructure before the final policy change.
