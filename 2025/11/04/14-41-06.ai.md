This is a CI/build system patch adding HTML documentation path configurability to Meson builds, mirroring existing Makefile behavior. Junio C Hamano provides maintainer feedback on D. Ben Knoble's patch to add `htmldir` support in Meson.

Key technical details for future reference:
- The patch adds `htmldir` as a string-type Meson option defaulting to `datadir/doc/git-doc`
- Modifies 7 build files to replace hardcoded paths with the configurable `htmldir` variable
- Maintains backward compatibility through fallback to original paths
- Propagates the configured path to `git --html-path` output via libgit.a definitions
- Includes Gentoo ebuild testing verification

Junio notes two observations about the Meson implementation approach:
1) Surprise that there are so few path configuration options currently in meson_options.txt (only `perllibdir` before this addition)
2) Expectation that Meson might offer richer path/filename types compared to Makefile strings

The patch appears technically sound and ready for inclusion, with Junio queuing it pending any additional feedback from Meson experts. The change specifically addresses Gentoo's packaging needs for version-specific doc directories while maintaining general flexibility for other distributions.
