This is a release announcement for Git for Windows 2.52.0-rc0. Johannes Schindelin announces the availability of the first release candidate for Git for Windows 2.52.0, which updates the Windows port to match the upstream Git v2.52.0-rc0 release. The announcement includes SHA-256 checksums for various distribution formats (installers, portable versions, and MinGit variants) across 32-bit, 64-bit, and ARM64 architectures.

The main change highlighted is the continued deprecation of `git svn` support in Git for Windows, which has been announced in previous releases. The only other noted update is the inclusion of PCRE2 v10.47. This appears to be a routine maintenance release without major new features or changes specific to the Windows port. The announcement follows the standard format for Git for Windows release candidates, providing download links and verification hashes for all distribution packages.
