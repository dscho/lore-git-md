This is a preparatory refactoring patch in Junio Hamano's series introducing new handling for incomplete-line whitespace errors. It fixes and clarifies the bit assignments used for whitespace rule tracking in Git's diff and apply machinery.

The patch corrects miscounted bit positions in comments (changing "0..12" to "0..11" for whitespace rules) and adds documentation for color-moved bits that were previously unmentioned. It also modernizes the code by switching from octal constants to `(1 << N)` notation for bit definitions, which makes the bit positions more obvious and helps prevent similar miscounting issues in the future.

The changes touch three files (diff.c, diff.h, ws.h) with straightforward updates to comments and constant definitions. This appears to be a clean, mechanical change that improves code clarity without altering behavior, setting up the infrastructure needed for the later patches in the series that will introduce the new whitespace error class for incomplete lines.
