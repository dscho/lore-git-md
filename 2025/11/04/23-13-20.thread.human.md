This thread concerns a straightforward but time-sensitive update to Git's CI infrastructure, migrating macOS test jobs from the soon-to-be-removed macos-13 GitHub Actions runners to macos-14. Maintainer Junio C Hamano has submitted and test-merged the change, which updates four macOS CI configurations (osx-clang, osx-reftable, osx-gcc, and osx-meson) with simple string replacements in the workflow file.

The change is being fast-tracked ahead of GitHub's December 4th deprecation deadline for macos-13 images, which were marked for removal back in September. Initial testing shows the new configuration works, though Junio notes there may be follow-up adjustments needed if toolchain version differences on the new runners cause issues. The patch has already been merged to both 'master' and 'next' branches, indicating this is considered a low-risk but necessary maintenance update to keep CI functioning.
