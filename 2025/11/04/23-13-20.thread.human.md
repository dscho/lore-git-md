This thread discusses updating Git's CI infrastructure to migrate macOS test jobs from the deprecated macos-13 to macos-14 GitHub Actions runners. The patch, sent by project maintainer Junio C Hamano, makes a straightforward change to four macOS CI jobs (osx-clang, osx-reftable, osx-gcc, and osx-meson) by replacing the runner specification. 

Junio notes this is a direct replacement but cautions there may be follow-up work needed if tool versions differ on the new images. The change is timely as GitHub will fully remove macos-13 support on December 4th. While the patch itself is simple, the thread may see additional discussion if test failures emerge after the switch.
