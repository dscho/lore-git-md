Build system patch adding HTML documentation path configurability to Meson builds.

This patch adds a new `htmldir` configuration option to Meson builds, mirroring the existing `htmldir` functionality in Makefile-based builds. The change allows packagers to specify custom installation paths for Git's HTML documentation, which is particularly useful for distributions like Gentoo that use version-specific documentation directories. The patch modifies several Meson build files to replace hardcoded paths with the new `htmldir` variable and adds the configuration option to `meson_options.txt`.

Key technical details:
- Introduces `htmldir` meson option defaulting to `datadir/doc/git-doc`
- Updates HTML doc installation paths in 7 build files
- Maintains backward compatibility by falling back to original path if `htmldir` not set
- Includes test verification using a modified Gentoo ebuild
- Affects `git --html-path` output by propagating the configured path to libgit.a build

The change is well-contained and follows the pattern already established in the Makefile build system. The patch appears to be motivated by real packaging needs and has been tested in a real-world distribution context. The implementation looks straightforward with no obvious technical issues.
