This is a refactoring patch in Junio Hamano's series introducing incomplete-line whitespace handling. It extracts the logic for emitting "\ No newline at end of file" markers into a dedicated `emit_incomplete_line()` helper function, preparing for unified handling across both xdiff and non-xdiff code paths.

The patch makes two key changes: first, it adds proper color handling for `DIFF_SYMBOL_CONTEXT_INCOMPLETE` cases by fetching context colors, matching the behavior of other context markers. Second, it introduces the new helper function that centralizes the incomplete-line emission, replacing a direct call to `emit_diff_symbol()` in `fn_out_consume()`.

This continues the series' pattern of cleaning up diff output machinery before introducing the new incomplete-line whitespace feature. The change is surgical and maintains existing behavior while improving code organization - the new helper will likely be reused when the actual incomplete-line detection is implemented in later patches. The BUG() check added in patch 04 remains in place to validate line ordering invariants.
