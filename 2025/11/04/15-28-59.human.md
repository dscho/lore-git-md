This is a test fix addressing a subtle issue in the test suite. Junio Hamano noticed while working on another test that the `t7004-tag.sh` test script was leaving the working directory in an unexpected state. The test "Does --[no-]contains stop at commits? Yes!" was changing directories into a subdirectory but not returning to the original directory, which could affect subsequent tests.

The fix wraps the test body in a subshell (using parentheses) so the directory change is contained and doesn't leak out. This is a straightforward and correct solution, matching how the test suite typically handles directory changes. The commit message clearly explains both the problem and solution, and the change itself is minimal and focused - just adding the subshell wrapper while preserving all the test logic.

This is the kind of small but important test hygiene fix that helps prevent subtle test pollution issues. While not earth-shattering, it's a clean improvement to test reliability from the project maintainer.
