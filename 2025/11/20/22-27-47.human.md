This is a technical clarification in the ongoing discussion about making internal Git functions static. Brian Carlson points out that several functions identified by Ramsay Jones' static-check.pl script (`git_hash_alloc`, `git_hash_free`, `git_hash_init`, and `hash_algo_ptr_by_number` in hash.o) cannot be made static because they are called from Rust code in the codebase. This is an important exception to the general cleanup effort, showing that some apparently unused functions have legitimate cross-language dependencies.

The note serves as a useful reality check for the static-ification project, reminding participants that automated tools may miss some usage contexts (like calls from Rust) and that human review is still needed. The exchange demonstrates the careful balance required in such cleanup work between mechanical improvements and maintaining necessary interfaces.
