This is a minor cleanup patch from Git maintainer Junio C Hamano that makes an internal function static. The function `git_configset_get_pathname()` was previously exposed in config.h despite having a single caller within config.c. The patch removes this unnecessary API surface by marking the function static and removing its header declaration. This is a straightforward refactoring with no behavior changes - just good hygiene to keep the public interface minimal. The change is small and uncontroversial, typical of Junio's frequent small improvements noticed while working in different areas of the codebase.
