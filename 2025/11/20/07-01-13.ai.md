This is a refactoring patch in Patrick Steinhardt's v6 series introducing the `git-history` command. The patch extracts commit-picking logic from `git-replay` into a new `replay.c` file to share between `git-replay` and the new `git-history` command, renaming functions with a `replay_` prefix for clear subsystem identification.

Elijah Newren's brief reply confirms Phillip Wood's positive review of the patch, noting it actually makes two functions public rather than one as originally stated. The changes are straightforward - just moving and renaming existing code with no functional changes. Both reviewers agree this is a clean preparatory step for the larger `git-history` feature.

The patch is part of the foundational infrastructure work for the series, specifically the extraction of replay machinery that will be shared between commands. It follows the established pattern in this series of carefully separating concerns and properly namespacing components.
