Refactoring patch in the `git-history` series, focusing on add-patch subsystem cleanup.

This patch completes the decoupling of `add-patch.c` from the `add-interactive` subsystem by removing its dependency on `add-interactive.h`. The key changes involve:

1. Replacing the embedded `struct add_i_state` with direct storage of a repository pointer and the new `struct interactive_config` that was split out in the previous patch
2. Updating all references from `s.s.cfg.*` to `s.cfg.*` throughout the code
3. Modifying initialization to use `interactive_config_init()` instead of `init_add_i_state()`
4. Adjusting cleanup to use `interactive_config_clear()`

The changes are mechanical and focused on code organization, with no behavior modifications. Elijah Newren's review confirms the changes are straightforward, noting the bulk of the patch involves simple field access updates when viewed with `--color-words`. This continues the series' pattern of uncontroversial infrastructure improvements while the more complex history editing functionality remains under discussion.
