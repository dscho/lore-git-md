This is a review comment on patch 12/13 of Patrick Steinhardt's ODB refactoring series. Junio Hamano notes that the patch introduces a boolean parameter `skip_initializing_odb` to `set_git_dir_1()` that makes the calling code harder to understand at a glance. He suggests that an enum would make the intent clearer, but acknowledges that with few callers the current approach is acceptable.

The comment focuses on code clarity rather than functionality - the underlying change to handle commondir updates in the ODB subsystem appears sound, continuing the series' systematic relocation of repository setup responsibilities. This is a minor stylistic point in an otherwise well-received series that Junio indicates is nearly ready for integration.
