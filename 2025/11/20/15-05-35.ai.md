This is a refactoring patch in Patrick Steinhardt's `git-history` series, specifically addressing the add-patch subsystem's decoupling from add-interactive. Phillip Wood provides a brief review acknowledging the changes.

The patch completes the separation between `add-patch` and `add-interactive` by removing their final direct dependency. It eliminates the need to initialize the interactive state through `init_add_i_state()` by instead storing and initializing the interactive configuration directly within `struct add_p_state`. The changes involve:

1. Replacing the `add_i_state` member with direct `repository` pointer and `interactive_config` struct
2. Updating all references to use the new configuration paths
3. Modifying initialization to use `interactive_config_init()` directly
4. Adjusting cleanup to use `interactive_config_clear()`

The refactoring affects color handling, diff configuration, and prompt display throughout the interactive patch application process. Phillip Wood's review indicates this direction makes sense, continuing the series' effort to properly separate concerns between these related but distinct subsystems. This change builds on prior infrastructure work in the series while maintaining all existing functionality.
