This is a bug report about an incorrect error message in `git config set`. 

Paul Wintz reports that when trying to set a multi-valued configuration key, the error message incorrectly suggests using `--add` when the actual option is `--append`. The error occurs when attempting to overwrite a multi-valued config entry without using one of the proper multi-value handling flags.

The report includes clear reproduction steps showing how to create a multi-valued config entry and trigger the misleading error. The suggested fix would be to update the error message to recommend `--append` instead of the non-existent `--add` option. This appears to be a straightforward documentation bug in the error message text.

The report is well-formatted with system information and demonstrates a clear understanding of the issue. The fix would be simple but important for user experience, as the current message points users toward a non-existent solution. This seems like a good candidate for a quick fix in a future release.
