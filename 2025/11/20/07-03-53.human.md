This is a refactoring patch in Patrick Steinhardt's `git-history` series, specifically addressing the add-patch subsystem's dependency on add-interactive. The change follows up on a previous patch that split out shared configuration between the two subsystems.

The patch removes the remaining coupling by eliminating the `add_i_state` struct in favor of directly storing and initializing the interactive configuration in `add_p_state`. This involves updating all the access points to use the new structure, which accounts for most of the diff's line changes. The changes are mechanical but thorough, touching color handling, diff configuration, and index operations.

Elijah Newren's review confirms the changes are reasonable, noting that most of the diff consists of straightforward field access updates when viewed with `--color-words`. The patch appears to be a clean separation that maintains existing functionality while improving code organization, continuing the series' trend of uncontroversial infrastructure improvements.
