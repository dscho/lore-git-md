This is the third and final patch in Jean-Noël Avila's documentation standardization series, completing the conversion of `git push`/`git pull`/`git fetch` man pages to consistent synopsis style. Like the previous patches, it focuses purely on formatting improvements with no functional changes.

The patch updates both `git-push.adoc` and `push.adoc` config documentation (380 lines changed across both files) to match the new AsciiDoc standards. Key formatting changes include:
- Conversion to synopsis blocks with standardized `_<placeholder>_` syntax
- Consistent backtick-wrapping of options and config keys
- Improved presentation of complex options (e.g. `--recurse-submodules` values now in bulleted list)
- Updated cross-references using new placeholder style
- Monospace formatting for all command-line options

The changes maintain all existing content while enabling better automated rendering. This completes the standardization of these three interrelated commands' documentation, following the same pattern as the earlier `git fetch` and `git pull` conversions in the series. No functional behavior is altered - this is purely a documentation presentation improvement.
