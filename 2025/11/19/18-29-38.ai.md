This is a test patch in Delilah Ashley Wu's series to fix Git's global config file handling inconsistency. The patch adds test coverage for the upcoming fix that will make `git config list --global` show both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config` files, matching Git's actual config reading behavior.

Junio Hamano provides detailed review feedback on the test implementation. He questions the use of negative assertions (`! test_cmp`) to document current failures, suggesting instead to use `test_expect_failure` for clearer intent. He also notes several technical improvements needed: avoiding unnecessary `-r` flag in `rm` commands, testing both with and without `--show-scope`, and ensuring tests are structured to make review easier when the fix comes in a later patch.

The review confirms the technical direction is sound but highlights Git's preferred testing patterns. The feedback focuses on making the tests more maintainable and reviewable, particularly around how to properly document expected failures before they are fixed. This continues the thread's pattern of thorough technical review with particular attention to testing methodology.
