Refactoring patch in a series reorganizing object database management. This is patch 2/13 in Patrick Steinhardt's series moving ODB source management from setup.c to odb.c.

The patch 1 moved `enter_repo()` into setup.c, making `set_git_dir()` no longer needed by external callers. This follow-up makes `set_git_dir()` function static by removing its declaration from setup.h and moving its implementation earlier in setup.c to avoid forward declarations. The change is mechanical - the function's behavior remains identical, it just now has file scope rather than being part of the public API.

The patch demonstrates careful attention to the series' architecture, cleaning up now-unneeded exposure of internal functions as the refactoring progresses. The implementation shows typical Git style with proper error handling (via `strbuf_realpath`) and maintains existing functionality for relative paths via the `chdir_notify_register` callback.

This is a straightforward preparatory change that helps pave the way for the more substantial ODB management relocation coming later in the series.
