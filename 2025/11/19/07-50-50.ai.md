Refactoring patch in the ongoing ODB source management series. This is patch 2/13 in the series that moves object database management responsibilities from setup.c to odb.c.

The patch converts `set_git_dir()` from a public function to a static one since there are no remaining external callers after the previous patch moved `enter_repo()` into setup.c. The implementation is reorganized to avoid forward declarations, with the function and its helper `set_git_dir_1()` moved up in the file. The change removes the declaration from setup.h and updates the function's scope while preserving all existing behavior.

Key technical details:
- Maintains all existing path handling logic including realpath conversion
- Preserves relative path tracking via chdir_notify_register()
- Keeps tmp_objdir handling for primary ODB updates
- Removes only the public API surface while keeping internal functionality

This is a straightforward code organization change that follows naturally from patch 1/13's relocation of `enter_repo()`. The patch appears mechanically sound and well-integrated with the series' goal of centralizing ODB management code.
