Refactoring patch in Patrick Steinhardt's object streaming series, continuing the `the_repository` removal effort. This is patch 13/18 in the series preparing Git's object streaming infrastructure for pluggable ODB backends.

The patch removes the last two uses of `the_repository` in the streaming subsystem. It modifies `open_istream_pack_non_delta()` to use the repository from the object database parameter it already receives, and renames `stream_blob_to_fd()` to `odb_stream_blob_to_fd()` while adding an object database parameter. The change requires updating all callers (cat-file, fsck, log, entry, and parallel-checkout) to pass the repository's object database.

The changes are mechanical but important for the series' goal of decoupling the streaming subsystem from global state. The patch maintains all existing functionality while making the codebase more amenable to future backend implementations. The thorough updates to all call sites show careful attention to maintaining compatibility.
