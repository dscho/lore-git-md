Refactoring patch in Patrick Steinhardt's object streaming series, focusing on interface naming and repository decoupling.

This patch (17/18) completes the transition from repository-centric to object-database-centric streaming interfaces. It renames all core streaming functions to use `odb_` prefix patterns (`odb_read_object_stream`, `odb_read_stream_read`, `odb_read_stream_close`) and updates callers throughout the codebase to pass `struct object_database*` instead of `struct repository*`. The changes touch several key areas including archive formats, pack operations, and object streaming.

The patch systematically updates all call sites to use the new naming scheme while maintaining identical functionality. Notable changes include:
- Replacing `open_istream()` with `odb_read_object_stream()`
- Renaming `read_istream()` to `odb_read_stream_read()`
- Changing `close_istream()` to `odb_read_stream_close()`
- Updating the stream filter implementation to use new names
- Modifying `istream_source()` to take an ODB parameter

The changes continue the series' pattern of removing `the_repository` usage while preparing for pluggable backends. All existing functionality is preserved, with the main difference being the explicit ODB parameterization rather than implicit access via the repository. The patch completes the naming standardization started in earlier patches and maintains consistent error handling paths throughout the streaming subsystem.
