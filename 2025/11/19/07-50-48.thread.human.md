This thread covers Patrick Steinhardt's 13-part series refactoring Git's object database (ODB) management, systematically moving responsibilities from setup.c to odb.c as part of the ongoing ODB abstraction effort. The work builds on prior changes and has received detailed review from Junio Hamano, the Git maintainer.

The series progresses methodically from foundational cleanups to core ODB relocation, touching multiple subsystems including repository lifecycle management, packfile operations, and HTTP transport. Junio's feedback has been minimal - just a small typo fix ("refbd" to "refdb") in patch 5/13 - suggesting the architectural approach is sound. The most recent patch adds an `oidset_equal()` utility function for comparing object ID sets, which Junio confirmed as the right approach. This straightforward addition supports the larger ODB work where such comparisons are needed.

With Junio's positive review and only minor documentation fixes needed, this series appears ready for integration. The changes cleanly encapsulate ODB management while maintaining compatibility across Git's codebase. When merged, this will represent another step forward in the multi-year effort to properly abstract Git's object storage layer.
