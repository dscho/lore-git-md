This is patch 6/13 in a series refactoring Git's object database management. It introduces a new utility function `oidset_equal()` to compare whether two oidsets contain identical object IDs.

The patch adds the comparison function to oidset.c and updates the header file with documentation. The implementation first checks set sizes for a quick mismatch detection, then verifies each element. As part of this change, `oidset_iter_init()` is modified to accept a const struct oidset parameter since the new comparison function needs to iterate without modifying the sets.

This appears to be a straightforward and well-contained addition to the oidset API, likely needed for subsequent patches in the series that will compare object database states. The change is small (23 lines net) and focused, with clear documentation. The const-correctness update to `oidset_iter_init()` is a sensible accompanying change that improves the API's safety.
