Refactoring patch completing Patrick Steinhardt's series to reorganize Git's object streaming infrastructure. This final patch (18/18) moves the streaming.{c,h} files into the odb/ directory to better reflect their role in the object database subsystem. The change is purely organizational - updating include paths in 15 files while maintaining all functionality. 

This concludes a substantial 18-part refactoring that systematically decoupled the object streaming system from implicit dependencies, standardized interfaces with `odb_` prefixes, eliminated `the_repository` usage, and prepared the plumbing for pluggable backends. The series has maintained careful attention to preserving behavior while restructuring internals, with delta-packed objects remaining as the only unhandled case. 

The relocation of these files is a logical final step that makes the codebase's organization better match the actual architecture, where streaming is clearly part of the object database subsystem rather than a standalone component. All changes are mechanical path updates with no functional impact.
