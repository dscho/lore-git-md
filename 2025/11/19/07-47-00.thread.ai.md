Patrick Steinhardt's 18-patch series refactoring Git's object streaming infrastructure for pluggable ODB backends continues with patch 14/18 reviewed by Karthik Nayak, while Justin Tobler provides feedback on the foundational patch 1/18. The series systematically prepares for pluggable backends by standardizing interfaces and isolating backend-specific logic.

Patch 1/18 (now receiving Justin Tobler's review) renamed `git_istream` to `odb_read_stream` to align with `odb_write_stream` naming and move toward backend-controlled streams. Justin agrees with the change and suggests enhancing the header comment to better document the structure's purpose, noting the existing implementation already shows generic characteristics by supporting multiple object sources.

Patch 14/18 makes `struct odb_read_stream` public by moving its definition from streaming.c to streaming.h, enabling backend implementations to allocate streams directly. Karthik Nayak's review identifies an API inconsistency where `open_istream()`'s output parameters may be redundant given the struct's fields, suggesting a future cleanup opportunity.
