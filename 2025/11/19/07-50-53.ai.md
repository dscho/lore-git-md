This is part 5/13 of Patrick Steinhardt's series refactoring object database (ODB) source management, specifically moving the ref-update disable logic from the ODB to the repository level.

The patch addresses a design quirk where reference update disabling was handled by the ODB source via a `disable_ref_updates` field, despite being more logically a repository-level concern. The original implementation had this in the ODB because it was primarily used to prevent reference updates during transactions where objects might be rolled back. The patch moves this flag to `struct repository` and converts it to a boolean.

Key changes include:
- Removing `disable_ref_updates` from `struct odb_source`
- Adding a new `disable_ref_updates` boolean to `struct repository`
- Updating all related code paths in odb.c, refs.c, repository.c, and setup.c
- Maintaining the same quarantine environment behavior but now at repository level

The commit message provides a clear rationale for why this belongs at the repository level rather than either the ODB (where it was) or refdb (where it might seem to belong). This appears to be a well-considered change that better reflects the actual architectural relationships while maintaining all existing functionality. The patch touches several core subsystems but makes focused, mechanical changes to move the flag's home.
