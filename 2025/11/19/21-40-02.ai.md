This is the first patch in a documentation standardization series converting `git fetch`'s man pages to consistent synopsis style. The patch focuses on formatting improvements rather than content changes, updating the documentation to use AsciiDoc synopsis blocks and consistent markup for placeholders and keywords.

The changes affect multiple files, with the bulk being in `fetch-options.adoc` and `config/fetch.adoc`. Key technical details include:
- Switching to synopsis blocks that automatically format placeholders in italics and keywords in monospace
- Using `_<placeholder>_` instead of `<placeholder>` in descriptions
- Wrapping keywords and complex option descriptions in backticks
- Maintaining all existing content while restructuring to the new format

The patch is part of a larger effort to standardize documentation across Git's man pages, with subsequent patches expected to cover `git pull` and `git push`. The changes are purely presentational - no functional behavior or actual documentation content is altered. The formatting updates will enable better automated rendering while preserving the same information for readers.
