This thread has been working on implementing reference backend selection to enable zero-downtime migrations between files and reftable backends, primarily for GitLab's needs. The series is now in its fourth iteration with all major technical challenges resolved.

The implementation provides two ways to specify the backend: through a new `extensions.refStorage` config option (using URI syntax like `reftable:///path/to/refs`) and now also via a `GIT_REFERENCE_BACKEND` environment variable that can override the config setting. The environment variable support was added in this final patch, completing the series' goal of offering both persistent and temporary backend selection.

Key contributors Patrick Steinhardt and Karthik Nayak have reviewed the architecture, with additional feedback from Toon Claes, Eric Sunshine, and others addressing URI syntax, worktree integration, and test coverage. The series was briefly removed from Junio's 'seen' branch due to scheduling rather than technical concerns, and now appears ready for final consideration. The implementation handles all the tricky aspects like worktree reference locations, initialization sequencing, and backward compatibility.
