This is the final patch in Patrick Steinhardt's 18-part series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch moves the streaming.{c,h} files into the odb/ directory to better reflect their specific role in the object database subsystem. This is a purely organizational change that doesn't modify any functionality - it just updates all the include paths in various files that use the streaming interfaces.

The change affects 15 files total, with simple path updates to point to the new location. The streaming implementation itself remains identical, just relocated. This completes the series' systematic preparation of the streaming infrastructure for pluggable backends by giving the code a more appropriate home that clearly signals its relationship to the object database.

Key technical points:
- Maintains all existing functionality while changing file locations
- Updates include paths in archive formats (tar/zip), builtins (cat-file, fsck, log, pack-objects), and core object handling code
- Keeps the same streaming.h interface but moves it under odb/
- Follows through on the series' goal of better organizing ODB-related code
- Final piece in decoupling streaming from repository globals and preparing for pluggable backends

The patch is straightforward and mechanical, with no behavior changes. It logically concludes the series by putting the now-refactored streaming code in its proper place within the object database subsystem.
