This is patch 15/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch moves the logic for reading loose object streams from streaming.c into object-file.c, making several related functions private in the process.

The change continues the series' pattern of moving backend-specific logic into their respective subsystems. Here, the loose object streaming implementation (including zlib inflation and header parsing) is relocated to object-file.c where it logically belongs with other loose object handling code. The public interface is simplified to just `odb_source_loose_read_object_stream()`, hiding implementation details that were previously exposed.

The patch is mechanically straightforward - it's a code move with minimal logic changes, just adjusting function visibility and updating callers. The commit message notes this allows making some function declarations private, which helps encapsulate the loose object implementation details. This is another incremental step in the larger effort to make object storage backends properly pluggable.
