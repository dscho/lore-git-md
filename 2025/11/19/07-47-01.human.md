Refactoring patch in a series to make Git's object streaming infrastructure pluggable. This first patch renames the core `git_istream` structure to `odb_read_stream` to better reflect its role in the object database subsystem and to mirror the existing `odb_write_stream` name. The change is purely a rename with no functional modifications, touching 7 files across archive utilities, builtins, and the streaming subsystem itself.

This is part of Patrick Steinhardt's larger effort to decentralize stream creation from `streaming.c` into individual ODB backends. The rename prepares for upcoming patches that will move streaming responsibilities into backend-specific implementations. The change is mechanical but wide-ranging, updating all callers to use the new name while maintaining identical behavior.

The patch appears well-scoped and straightforward, with no obvious issues in the diff. As the first in an 18-part series, it sets up the naming convention that will be used throughout the subsequent architectural changes to Git's object streaming system.
