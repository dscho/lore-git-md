This is part of Patrick Steinhardt's ongoing refactoring of Git's object streaming infrastructure to support pluggable ODB backends. Patch 7/18 continues the systematic restructuring by introducing a dedicated `struct odb_loose_read_stream` for loose object streams.

The change moves all loose-stream-specific fields (like `mapped`, `mapsize`, and header handling) out of the union in the base `struct odb_read_stream` and into this new structure. This follows the pattern established in patch 6/18 for in-memory streams, further decoupling the streaming implementation details from the base structure.

The patch maintains identical external functionality while cleaning up the internal implementation. All loose stream operations (`read_istream_loose`, `close_istream_loose`, and `open_istream_loose`) are updated to work with the new structure through appropriate casting. The changes are mechanical but important for the larger goal of making the streaming backend implementations more modular and independent.

This continues the series' trend of well-contained, clearly motivated changes that systematically prepare the plumbing for pluggable backends without any user-visible behavior changes. The patch is cleanly implemented with thorough updates to all related functions and maintains the existing error handling paths.
