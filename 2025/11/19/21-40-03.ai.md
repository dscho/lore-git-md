Documentation patch converting `git pull` man page to standardized synopsis style, part 2/3 in a series standardizing fetch/pull/push documentation.

This patch follows the same pattern as the first in the series, applying consistent AsciiDoc formatting to `git pull`'s documentation. It converts the command synopsis to use the new synopsis block format, standardizes placeholder notation to `_<placeholder>_`, and wraps command options and keywords in backticks for consistent rendering. The changes span four files that document `git pull` and its related options.

Key technical changes include restructuring the rebase option documentation into a clearer list format and updating cross-references to use the new placeholder style. The patch maintains all existing content while improving presentation, particularly for the complex `--rebase` option which now shows its possible values (`true`, `merges`, `false`, `interactive`) in a more readable bulleted list.

The first patch in this series covered `git fetch`, and the next will address `git push`, completing the standardization of these three interrelated commands. Like the first patch, this appears to be a straightforward mechanical conversion that maintains all existing information while improving documentation tooling compatibility.
