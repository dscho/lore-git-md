This is a refactoring patch series that centralizes management of Git's object database (ODB) sources. Patrick Steinhardt aims to clean up the current scattered handling of ODB sources between setup.c and odb.c, where responsibilities are currently split in ways that violate architectural boundaries.

The series has three main phases: First, some preparatory cleanups (patches 1-5) address nearby code issues. Then, patches 6-9 fix several cases where the ODB gets unnecessarily reinitialized. Finally, patches 10-13 move all ODB source management into odb.c, which should make the code more maintainable and pave the way for future backend handling improvements.

The changes touch a wide swath of the codebase (31 files modified) but appear focused and well-motivated. The cover letter clearly explains the architectural problem being solved and how the series addresses it. Given the scope of changes, this will likely need careful review from maintainers familiar with Git's object storage internals, but the series looks like a solid step toward better code organization.
