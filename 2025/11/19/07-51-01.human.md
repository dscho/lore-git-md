This is the final patch in Patrick Steinhardt's 13-part series refactoring object database (ODB) management, completing the move of path-handling logic from setup.c to odb.c. The patch specifically addresses quarantine directory handling during working directory changes.

The change moves the temporary object directory (quarantine) reparenting logic into odb.c alongside the recently relocated commondir handling from patch 12/13. This keeps all path-update logic together when the working directory changes, maintaining consistency with the series' goal of proper ODB encapsulation.

The implementation:
- Adds tmp-objdir.h include to odb.c
- Extends the existing `odb_update_commondir()` callback to also handle quarantine directories
- Removes the now-redundant quarantine handling from setup.c
- Preserves the same behavior while better localizing the logic

This is a clean, focused conclusion to the series that demonstrates careful attention to edge cases (like when no quarantine directory exists). The patch follows the established pattern of the series - methodical relocation of functionality with clear commit messages explaining each step. With this change, all ODB path management is now properly contained within odb.c, achieving the architectural goal of the series.
