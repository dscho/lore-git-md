Patrick Steinhardt continues his major refactoring of Git's object streaming infrastructure to support pluggable object database backends. The 18-patch series is systematically restructuring how Git reads objects from different sources (loose objects, packfiles, in-memory) by eliminating internal coupling while maintaining external behavior.

The latest patch (7/18) follows the pattern established in the previous in-memory stream changes, introducing a dedicated `struct odb_loose_read_stream` for loose objects. This moves several previously union-embedded fields into their own structure while keeping all existing functionality intact. The change is part of a broader effort to remove implementation details from the core streaming interface, making it easier to add new backend types in the future.

The series has now standardized the interfaces for both in-memory and loose object streams, with similar changes expected for packed objects in upcoming patches. These are internal plumbing changes with no user-facing effects, but they represent important groundwork for the larger ODB abstraction effort that will eventually allow alternative object storage backends. The work builds on Steinhardt's prior contributions to Git's object handling layer and continues the project's multi-year effort to modernize this core subsystem.
