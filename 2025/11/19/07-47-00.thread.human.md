Patrick Steinhardt's object database streaming interface refactoring continues with patch 9/19, which introduces a type-safe container for filtered object streams. This follows the established pattern from previous patches that created dedicated structures for in-core, loose, and packed object streams. The new `struct odb_filtered_read_stream` replaces the old union-based approach, cleanly encapsulating all filter-specific state including the upstream stream, filter object, and buffer management.

The changes maintain consistency of the series' architectural direction while focusing on internal implementation details rather than user-visible behavior. All functionality is preserved through the type-safe interface as the series progresses toward eliminating the union-based approach entirely. This work builds on earlier patches that Junio Hamano reviewed, including the important simplification of initialization flow in patch 2/19. The series continues to strengthen the foundation for future pluggable ODB backends with each type-safe stream implementation.
