This is part 6 of Patrick Steinhardt's ongoing refactoring series to prepare Git's object streaming infrastructure for pluggable ODB backends. The patch focuses on restructuring how in-memory object streams are handled.

The change moves the in-core (in-memory) stream implementation out of the union in `struct odb_read_stream` and into its own dedicated `struct odb_incore_read_stream`. This continues the series' goal of eliminating the union-based approach that currently couples all stream types together. The new structure contains the same fields as before (`buf` and `read_ptr`) but now exists independently with proper type safety.

The patch maintains all existing functionality while making the code more maintainable and better prepared for future backend implementations. It follows the pattern established in earlier patches of the series, where each stream type gets its own structure. The changes are internal plumbing with no user-facing impact.
