This is part 16/18 of Patrick Steinhardt's series refactoring Git's object streaming infrastructure to support pluggable ODB backends. The patch moves packed object stream reading logic from streaming.c to packfile.c, following the same pattern as previous patches that relocated loose object handling.

The changes introduce a new public function `packfile_store_read_object_stream()` in packfile.h while removing the equivalent private implementation from streaming.c. The core functionality remains the same - it still handles non-delta packed objects (commits, trees, blobs, tags) with the same zlib inflation logic and error handling. The patch updates the call site in `istream_source()` to use the new interface.

This continues the systematic decoupling of stream types that began in earlier patches, with packed objects now joining loose objects in having their implementation moved to their natural subsystem location. The change helps prepare for future backend implementations by further isolating packfile-specific logic while maintaining identical external behavior.
