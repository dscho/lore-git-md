This is a refactoring patch that's part of the submodule gitdir path encoding series. It moves a URL encoding helper function from being a private implementation in credential-store.c to being a public utility in url.[ch], where it can be shared by other parts of Git.

The patch relocates `is_rfc3986_unreserved()`, a function that checks which characters don't need URL percent-encoding, from credential-store.c to url.c. This change is needed because the submodule path encoding work (the main focus of this series) will use this function to safely encode submodule names when constructing gitdir paths to avoid filesystem conflicts.

The commit message explains the rationale well - this function was previously moved to credential-store.c when it was only used there, but now has broader utility. The implementation remains exactly the same, just moved to a more appropriate shared location with the corresponding header declaration. This is a straightforward preparatory change that enables the submodule encoding functionality to be implemented in the following patches.
