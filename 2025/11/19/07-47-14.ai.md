Pluggable ODB backend refactoring (part 14/18): Making stream definition public.

This patch continues Patrick Steinhardt's series refactoring Git's object streaming infrastructure by moving the `odb_read_stream` structure definition from streaming.c to streaming.h. The change prepares for upcoming work where backend implementations will need direct access to the stream structure when allocating and initializing streams.

The patch makes three key changes:
1. Removes the private typedefs and struct definition from streaming.c
2. Adds the public version to streaming.h with slightly renamed function pointer types (`odb_read_stream_close_fn` and `odb_read_stream_read_fn`)
3. Keeps all existing functionality intact while making the previously opaque structure visible to other compilation units

This is a straightforward mechanical change that enables the next steps in the series where backend implementations will take over stream allocation responsibilities. The renaming of the function pointer types follows Git's naming patterns while maintaining the same signatures. The patch maintains the series' careful approach of making minimal, focused changes that each move toward the larger goal of pluggable backends without introducing behavior changes or regressions.
