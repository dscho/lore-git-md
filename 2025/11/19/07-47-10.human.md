This is patch 10/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch continues the systematic decoupling of backend implementations by moving zlib stream handling from the shared `odb_read_stream` base structure into the backend-specific structures for loose and packed objects.

The change removes the last remaining shared state between the different stream types, completing the separation that began in earlier patches. The zlib stream and its state tracking are now fully contained within `odb_loose_read_stream` and `odb_packed_read_stream`, with each getting its own state enum constants (though they follow the same basic state machine pattern).

The patch follows the established pattern of the series: careful restructuring that maintains identical external behavior while improving internal organization. The diff is mechanical but thorough, updating all the zlib-related code paths to use the new backend-specific fields instead of the base structure's fields. This is another step toward the eventual goal of allowing pluggable ODB backends with their own stream implementations.
