This is part 9/18 of Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends, continuing the systematic elimination of union-based stream type coupling.

The patch introduces `struct odb_filtered_read_stream` to handle filtered object streams, following the same pattern established in previous patches for in-memory, loose, and packed streams. Key changes include:

1. Moves the filtered stream implementation out of the union in `struct odb_read_stream` into its own dedicated structure
2. Updates all related functions (`close_istream_filtered`, `read_istream_filtered`, `attach_stream_filter`) to work with the new type
3. Uses `CALLOC_ARRAY` for allocation (consistent with prior patches)
4. Maintains identical external behavior while changing internal structure

The changes continue the series' methodical preparation for pluggable backends by:
- Removing another union-based coupling point
- Keeping stream type implementations separate and self-contained
- Preserving all existing functionality including error handling
- Following the established pattern of moving fields from union to dedicated struct

This patch completes the stream type separation work for the main object types (in-memory, loose, packed, and now filtered streams), leaving delta-packed objects as the remaining case to be handled in subsequent patches. The changes are purely internal with no user-visible impact.
