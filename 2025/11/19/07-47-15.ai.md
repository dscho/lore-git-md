This is patch 15/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch moves all loose object stream reading logic from streaming.c into object-file.c, completing the backend-specific implementation pattern established in the series.

Key technical changes:
- Moves `struct odb_loose_read_stream` and its associated functions (`read_istream_loose`, `close_istream_loose`) to object-file.c
- Introduces new public function `odb_source_loose_read_object_stream()` as the entry point for loose object streaming
- Makes several previously public functions private (`odb_source_loose_map_object`, `unpack_loose_header`, `parse_loose_header`)
- Updates the loose object streaming state machine to use the new backend interface
- Modifies `istream_source()` to call the new function rather than the old `open_istream_loose()`

The changes follow the series' pattern of moving stream-type-specific logic into backend implementations while maintaining the same external behavior. This continues the preparation for pluggable backends by:
- Further isolating loose object handling
- Reducing the streaming.c interface surface
- Enabling future backend-specific optimizations
- Maintaining all existing error handling paths

The patch is a straightforward relocation of code with no functional changes, keeping the same zlib streaming logic and memory management while moving it to its logical subsystem. It builds on the foundation established in earlier patches that separated stream types and moved allocation responsibilities to backends.
