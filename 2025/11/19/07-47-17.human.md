This is patch 17/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch focuses on making the streaming interface object-database-centric rather than repository-centric.

The key change is renaming and restructuring the streaming API functions to operate on `struct object_database` rather than `struct repository`. The main functions are now:
- `odb_read_object_stream()` (was `open_istream()`)
- `odb_read_stream_read()` (was `read_istream()`)
- `odb_read_stream_close()` (was `close_istream()`)

The patch updates all callers across the codebase to use the new names and pass the object database rather than repository. This continues the series' theme of removing implicit dependencies on `the_repository` global and better isolating the streaming subsystem. The changes are mechanical but widespread, touching archive code, pack operations, and object file handling.

This is a logical next step after the previous patches moved loose and packed object streaming logic into their respective subsystems. The changes maintain all existing functionality while making the API more precise about its actual dependencies. The patch appears well-executed with thorough updates to all affected call sites.
