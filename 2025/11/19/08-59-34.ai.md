This is the final patch in a series fixing regressions in `git fetch`'s batched reference updates. The patch specifically addresses how failed batched updates were skipping important post-fetch operations like updating `FETCH_HEAD`, setting upstream tracking, and updating remote HEAD.

The key technical fix modifies `do_fetch()` to only jump to cleanup on failure when using `--atomic` mode, allowing batched updates to complete these post-fetch operations even if some refs fail. The patch maintains atomic behavior for `--atomic` fetches while fixing the regression for non-atomic batched updates. Test coverage is added for both the happy path and failure cases of these operations.
