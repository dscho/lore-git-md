This is a refactoring patch series that centralizes management of object database (ODB) sources. The series moves responsibility for ODB source management from `setup.c` to `odb.c`, where the author argues it more logically belongs. The current implementation has scattered responsibilities that make the code harder to understand and maintain.

The 13-part series starts with preparatory cleanups (patches 1-5), then addresses problematic callsites that reinitialize the ODB (patches 6-9), and finally moves the core ODB source management logic (patches 10-13). Key technical changes include:
- Moving `enter_repo()` to `setup.c`
- Refactoring ODB cleanup functions
- Adding `oidset_equal()` helper
- Fixing deferred fsck in `index-pack`
- Adding chdir-notify functionality
- Handling quarantine directory recreation

The changes touch core repository setup and object database handling across multiple files including `setup.c`, `odb.c`, `path.c`, and various builtin commands. The series builds on previous work (ps/object-source-loose) and appears to be a well-structured effort to improve code organization around a specific subsystem. The commit messages provide clear explanations of each change's purpose.
