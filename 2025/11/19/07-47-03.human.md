Refactoring patch in the object streaming series. This is the third patch in Patrick Steinhardt's 18-part series to move streaming responsibility to ODB backends. It simplifies how object types are propagated through the streaming interface.

The patch changes the way object types are handled when opening read streams. Previously, the type was passed down through multiple levels via a pointer, with redundant lookups happening at different stages. The new approach stores the type directly in the stream structure (alongside the existing size field) and makes the format-specific callbacks responsible for populating it. This eliminates an architectural awkwardness and prepares for removing an intermediate object info lookup in a future patch.

The changes are mechanical but meaningful - they clean up the interface while maintaining the same functionality. The diff shows updates to the loose, packed, and in-memory stream handlers to use the new approach. This continues the series' pattern of incremental improvements to the streaming infrastructure without changing behavior.
