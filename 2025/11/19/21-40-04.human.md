This is the third and final patch in Jean-Noël Avila's documentation standardization series, completing the conversion of `git push`/`pull`/`fetch` man pages to consistent synopsis style. The patch updates both `git-push.adoc` and its related config documentation in `push.adoc` to match the new AsciiDoc formatting conventions.

The changes are purely presentational - no content is added or removed. The key formatting improvements include:
- Converting the synopsis to a proper synopsis block with standardized `_<placeholder>_` syntax
- Using backticks consistently for option names and keywords
- Reformatting complex option descriptions (like `--recurse-submodules` values) as bulleted lists
- Updating cross-references to match the new placeholder style

The patch follows the same high-quality approach seen in the previous two patches of the series, with thorough updates to both command and config documentation. This completes the standardization of these three interrelated commands' documentation, bringing them in line with Git's modern documentation style. The changes should improve automated rendering while maintaining identical information content for readers.
