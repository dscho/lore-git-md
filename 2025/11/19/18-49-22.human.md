This is a refactoring patch in Patrick Steinhardt's ongoing series to enable pluggable object database backends. Justin Tobler responds to the first patch in the series, which renames `git_istream` to `odb_read_stream` to better reflect its role in the object database subsystem and align with the existing `odb_write_stream` naming.

Justin agrees with the renaming but suggests adding more detailed documentation about the structure's purpose while making this change. He notes that while the current implementation in streaming.c already handles multiple object sources (loose and packed objects), the series aims to decentralize this control to individual backend implementations.

The response indicates general approval of this foundational change in the series' architectural direction, while offering a minor documentation improvement suggestion. This early patch sets the naming convention that will be used throughout the subsequent refactoring work.
