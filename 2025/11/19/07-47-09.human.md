This is part 9/18 of Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch introduces a dedicated `struct odb_filtered_read_stream` for filtered object streams, continuing the pattern established in previous patches to eliminate the union-based coupling in `struct odb_read_stream`.

The change moves all filtered stream-specific fields (previously in the union's `filtered` member) into the new structure, which now contains the base stream as an embedded struct. The patch updates all related functions to use the new type while maintaining identical external behavior. Like earlier patches in the series, it uses `CALLOC_ARRAY` for allocation and includes proper type conversion.

This is another incremental improvement in the systematic effort to decouple stream implementations, preparing for future pluggable backends. The changes are internal plumbing with no user-visible effects, following the established pattern of moving union-embedded data into dedicated stream-type structures. The patch appears well-contained and consistent with the series' overall direction.
