This is a refactoring patch in Patrick Steinhardt's ongoing series to enable pluggable object database backends. The patch renames the `git_istream` structure to `odb_read_stream` to better reflect its purpose and align with the existing `odb_write_stream` naming. 

Junio C Hamano, the original creator of the `git_istream` abstraction, chimes in to express support for this direction. The change is straightforward - just a name change at this point - but it's part of a larger effort to make the streaming interface more generic and backend-controlled. 

Reviewer Justin Tobler had previously approved this patch while suggesting enhanced documentation, which doesn't appear to have been added yet. The thread shows consensus on this initial step in the refactoring series, with the maintainer's explicit endorsement adding weight to the approach. This foundational change sets up the naming convention that will be used throughout the rest of the series.
