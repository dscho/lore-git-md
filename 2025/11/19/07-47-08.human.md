This is part 8/18 of Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends, following the same pattern as previous patches in the series. The patch creates a dedicated `struct odb_packed_read_stream` for packed object streams, moving previously union-embedded fields (`pack` and `pos`) into this new structure while maintaining identical external behavior.

The changes follow the established pattern from earlier patches in the series: removing type-specific data from the base `struct odb_read_stream` union, creating a new backend-specific structure that contains both the base fields and stream-specific data, and updating all related functions to cast between types. The patch touches only internal streaming code, with no user-visible changes.

This continues the systematic preparation for future backend implementations by eliminating union-based coupling between stream types and allowing backend structures to be defined outside streaming.c. The changes are well-contained (75 lines modified) and maintain all existing functionality while progressing the larger goal of making the object streaming infrastructure more modular.
