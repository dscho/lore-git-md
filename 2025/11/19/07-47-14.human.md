This is part 14/18 of Patrick Steinhardt's series refactoring Git's object streaming infrastructure for pluggable ODB backends. The patch makes the previously opaque `struct odb_read_stream` definition public by moving it from streaming.c to streaming.h.

The change prepares for upcoming work where backend subsystems will need direct access to the stream structure when they take over responsibility for stream allocation. The patch is straightforward - it relocates the type definitions while renaming the function pointer types for clarity (`close_istream_fn` becomes `odb_read_stream_close_fn` etc.).

This continues the series' systematic approach to decoupling the streaming infrastructure, following previous patches that separated stream types and moved allocation logic. There are no behavior changes - this is purely about making internal structures available where they'll be needed in the architecture evolution. The patch is small (14 lines added/12 removed) and focused, maintaining the series' careful progression toward pluggable backends.
