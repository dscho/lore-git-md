This is part 4/18 in Patrick Steinhardt's series refactoring Git's object streaming infrastructure. The patch focuses on improving the interface for streaming packed objects.

The change makes the packed object streaming interface more explicit by requiring callers to pass the packfile and offset directly to `open_istream_pack_non_delta()`, rather than having the function rely on pre-populated fields in the stream structure. This eliminates an awkward indirect dependency where callers needed to know internal implementation details about how the function worked.

The patch is a straightforward mechanical change that:
1. Adds new parameters to the function signature
2. Moves the packfile/offset assignment into the function
3. Updates the single call site to pass these values directly

This appears to be preparatory work for future changes in the series, likely related to stream allocation. The diff is clean and focused, with 10 lines added and 10 removed, maintaining the same functionality while improving the interface. As with previous patches in the series, this maintains backward compatibility while moving toward the larger goal of more modular object streaming.
