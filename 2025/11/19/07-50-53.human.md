This is part 5 of a 13-part series refactoring Git's object database (ODB) management. The patch moves the logic for disabling reference updates during ODB transactions from the odb_source struct to the repository struct.

The change addresses a design issue where reference update control was incorrectly tied to individual ODB sources rather than being repository-wide. The `disable_ref_updates` field was previously used to prevent reference updates during transactions when objects might be permanently committed. The patch relocates this flag to the repository level and converts it to a boolean, which better matches its purpose since reference updates should be controlled at the repository scope rather than per-ODB-source.

The change affects several files including odb.c, refs.c, and repository.h, with straightforward mechanical updates to move the flag and update its type. This appears to be a well-justified cleanup as part of the larger ODB abstraction effort, properly separating concerns between the object database and reference database subsystems.
