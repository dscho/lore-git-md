This is a refactoring patch in the submodule gitdir path encoding series. It's the first of seven patches in v5 of the series, which aims to handle path encoding for submodule gitdirs to prevent filesystem conflicts.

Adrian Ratiu updates `submodule--helper` to use the existing `submodule_name_to_gitdir()` helper function rather than hardcoding the modules path. This change makes the code consistent with other parts of Git that work with submodule gitdirs and fixes some test failures that occurred during path encoding testing. The patch also cleans up the scope of a variable that's no longer needed in one code path.

The change is straightforward and aligns with the series' goal of centralizing submodule gitdir path handling. Since this is part of a larger, well-tested series that has already undergone significant review, this particular patch appears to be a minor but necessary cleanup that helps maintain consistency across the codebase.
