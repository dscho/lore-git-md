Refactoring patch for the `GIT_REF_URI` feature series. This first patch in the two-part series extracts the ref_store creation logic from `get_main_ref_store()` into a new `get_ref_store_for_dir()` function to support creating reference stores for arbitrary directories. The change is mechanical - moving existing code into a reusable helper while maintaining identical behavior for the main ref store case. This prepares for the second patch which will implement URI-based reference store creation by providing the infrastructure to instantiate ref_stores at custom paths. The patch touches core refs.c functionality but appears straightforward with no behavior changes, just improved code organization to support the upcoming URI feature.
