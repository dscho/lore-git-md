The patch adds `oidset_equal()` to compare whether two oidsets contain identical object IDs. The implementation first checks set sizes for quick rejection, then verifies each element of one set exists in the other. This requires making `oidset_iter_init()` accept a `const struct oidset` parameter, which is a safe change since the iteration doesn't modify the set.

The change is straightforward and well-contained, touching only oidset.c and oidset.h. The function will be useful for the larger ODB refactoring work where comparing object sets may be needed. The implementation follows the pattern of other oidset operations and maintains the existing const-correctness of the API.
