This is a documentation patch series (v2) aimed at improving discoverability around `scalar` configuration. The two-patch series comes from a previous discussion about making `scalar`'s config changes more transparent to users.

The first patch adds inline comments in `scalar.c` explaining why specific config values are being set during `scalar` operations. The second patch documents the `gui.GCWarning` config option that was previously missing from the documentation. Both changes are straightforward documentation improvements with no behavioral impact.

The author notes this is a smaller subset of planned changes, with more comprehensive documentation work still in progress but being split out for incremental review. The v2 revision adds missing signoffs but otherwise carries forward the same changes from v1. These appear to be well-scoped, uncontroversial documentation updates that address specific gaps identified in prior discussion.
