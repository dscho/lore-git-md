This is a follow-up in the thread about a Git fetch SIGSEGV during submodule operations. Jeff King suggests that the crash Justin Su was seeing (which occurred with specific configs on ARM64 Ubuntu in Git 2.43.0) was likely fixed by commit d70f554cdf ("commit-graph: retain commit slab when closing NULL commit_graph") from January 2024. This aligns with Justin's observation that the issue no longer reproduces in Git 2.52.0.

The proposed fix addresses a commit-graph slab management issue that could lead to memory corruption, which matches the symptoms seen in the original report (crash after commit-graph operations during fetch with submodules). While the thread had previously narrowed the problematic version range to 2.43.0 through pre-2.52.0, this appears to identify the specific commit that resolved the issue. The explanation is technically plausible and comes from a core Git maintainer, lending it credibility. This likely provides satisfactory closure to the thread unless new information emerges.
