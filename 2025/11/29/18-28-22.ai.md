This is a test fix in the ongoing Windows symlink compatibility series. The patch addresses t0600-reffiles-backend.sh, specifically modifying a test case that checks symref transaction behavior with symlinks. 

The key change adds the `!MINGW` prerequisite to a test that was previously only guarded by `SYMLINKS`. The test exercises `core.prefersymlinkrefs` functionality, but this feature isn't supported on Windows (even though Windows does support symlinks in general). The patch correctly marks the test as incompatible with MINGW to prevent false failures when MSYS2 enables symlink support by default.

This is part of the broader effort to make Git's test suite properly handle Windows symlink behavior in preparation for MSYS2's planned symlink support enablement. The change is straightforward and aligns with the series' goal of improving test compatibility while maintaining existing Windows-specific behavior where needed.
