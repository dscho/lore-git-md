This is the second patch in a documentation series about `scalar` configuration discoverability, now co-authored by Matthew Hughes and Derrick Stolee. While the first patch focused on marking config changes made by `scalar`, this one documents the previously undocumented `gui.GCWarning` config option that `scalar` sets.

The patch adds clear documentation for `gui.GCWarning` in `Documentation/config/gui.adoc`, explaining that it controls whether `git-gui` should warn about garbage collection when many loose objects are detected. The default value is noted as "true", matching the current behavior.

This addresses one of the documentation gaps identified in the series' investigation of config options modified by `scalar`. The change is straightforward and well-contained, adding exactly the kind of documentation that was missing. The patch doesn't modify any behavior - it purely documents existing functionality.
