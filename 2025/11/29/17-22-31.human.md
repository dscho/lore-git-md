Documentation patch completing the `scalar` config discoverability series by Matthew Hughes and Derrick Stolee. This second patch addresses a gap noted during their work: the `gui.GCWarning` config option was undocumented despite being set by `scalar`.

The patch adds clear documentation for `gui.GCWarning`, explaining it controls whether `git-gui` prompts users about garbage collection when many loose objects are detected (defaulting to true). This was identified while auditing configs modified by `scalar`, though the option itself isn't scalar-specific.

The change is straightforward - a 5-line addition to `gui.adoc` with standard documentation formatting. It complements the series' first patch (which added source comments for scalar-modified configs) by ensuring one such config now has proper user-facing docs. The patch appears well-formed and fills a genuine documentation hole, though it doesn't yet address whether/how `scalar`'s use of this option should be specially noted.
