This is a contributor housekeeping note on the `scalar` documentation patch series. Kristoffer Haugsbakk points out that both patches in Matthew Hughes and Derrick Stolee's series are missing the required `Signed-off-by` trailer. This is a standard requirement for Git project contributions, though the oversight doesn't affect the technical content of the patches themselves.

The series (currently at v2) aims to improve discoverability of configuration settings modified by `scalar`, with one patch adding source-code comments when `scalar` writes configs and another documenting the previously undocumented `gui.GCWarning` option. While the technical approach appears sound, this minor process oversight would need to be corrected before the patches could be merged.

The note is brief and to the point - a common type of quick review feedback on the mailing list. It doesn't raise any objections to the technical content but flags an administrative requirement that would block acceptance. The original authors would typically respond by sending a v3 with the signoffs added.
