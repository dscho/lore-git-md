This is a documentation patch series addressing discoverability of `scalar` configuration settings, following up on a previous discussion. The series consists of two small but focused improvements:

The first patch adds inline comments in `scalar.c` explaining why certain configuration values are set during `scalar` initialization. This directly addresses the discoverability issue raised in the linked thread by making the rationale visible in the code itself rather than requiring developers to dig through commit history.

The second patch documents the `gui.GCWarning` config option which was previously undocumented. This appears to be one of the settings that `scalar` modifies, though the connection isn't explicitly stated in the cover letter. The documentation follows Git's standard format for config options.

The author notes this is a partial solution, with more comprehensive documentation work still in progress but being split out to avoid delays. The changes are straightforward and uncontroversial, touching only documentation and comments. The patches are cleanly formatted and focused scope, though the motivation could be slightly clearer about why these particular items were prioritized from the larger discussion.
