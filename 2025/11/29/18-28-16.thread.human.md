This thread covers Johannes Schindelen's (Dscho) 10-part series preparing Git's test suite for MSYS2's upcoming Windows symlink support. The series has been approved for integration by Junio Hamano after addressing various Windows-specific test failures across multiple areas, from Perl test paths to difftool handling.

In the latest exchange, Junio and Dscho discuss patch 4/10's handling of `git diff --no-index` behavior in test t0001. While agreeing to modify the test to explicitly check symlink resolution with `--no-index`, Dscho notes this doesn't materially improve coverage since the behavior isn't Windows-specific. The conversation then expands into testing philosophy, with Junio floating the idea of categorizing tests by platform relevance to potentially optimize CI resource usage on slower platforms like Windows - though he acknowledges implementation challenges.

The series represents a significant step in Windows compatibility, with all 10 patches now ready for merging. It establishes patterns for handling platform differences in symlink tests while maintaining coverage, though follow-up discussions reveal ongoing tensions between comprehensive testing and practical constraints. Junio has suggested potential future work on Windows permission semantics and test infrastructure improvements, while Patrick Steinhardt has identified additional cleanup opportunities in symref-related tests.
