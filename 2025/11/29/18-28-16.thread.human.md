Johannes Schindelin (Dscho) has submitted the final v3 patch series to prepare Git's test suite for Windows symlink support, which maintainer Junio Hamano has accepted for integration. The series addresses test failures that would occur when MSYS2 enables symlink support by default, with fixes spanning executable bit handling, path comparisons, and Windows-specific device file behaviors. Key changes include adjustments to apply.c and mingw.c, plus test fixes in t0001, t1305, t6423 and others to properly handle symlinks on Windows.

In a follow-up email, Dscho provides some administrative clarifications about the patch history - noting that the Perl test fixes were actually present since v1, and correcting an oversight where Patrick Steinhardt's credit was accidentally dropped from patch 6 during rebasing. The technical content remains unchanged from what Junio approved. This marks the completion of preparatory work for upstreaming Git for Windows' symlink support, resolving various long-standing Windows compatibility issues dating back to 2009 in some cases.
