This is the fourth patch in Johannes Schindelin's 10-part series improving Windows test suite compatibility with symbolic links. It fixes a test case in t0001-init.sh that fails when `git diff --no-index` (used by `test_cmp` on Windows) doesn't resolve symlinks as expected.

The specific issue involves the 're-init to move gitdir symlink' test, which compares the contents of `newdir/.git` (a symlink) against an expected file. On Windows, `git diff --no-index` shows the symlink target rather than resolving it, causing the test to fail. The patch modifies the test to skip the symlink comparison when `GIT_TEST_CMP` uses `--no-index`, while preserving the check on other platforms.

Key technical details:
- Modifies t/t0001-init.sh
- Adds platform-specific handling via `$GIT_TEST_CMP` check
- Preserves existing test behavior on non-Windows platforms
- Works around Windows `git diff --no-index` symlink behavior
- Part of broader effort to make tests work with MSYS2's upcoming symlink support

This continues the series' pattern of addressing Windows-specific test failures by accounting for platform differences in symlink handling, though in this case the fix is localized to test expectations rather than core behavior.
