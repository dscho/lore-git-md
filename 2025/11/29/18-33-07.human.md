This is the first patch in a two-part documentation series improving `scalar` configuration visibility. The patch adds inline comments to `scalar.c` explaining that certain config values are set by `scalar` itself, not manually by users. This helps distinguish automated configuration from user edits when examining the config file.

The change modifies `set_scalar_config()` to append "# set by git-scalar" comments when writing config values. The implementation uses `repo_config_set_in_file_gently()` to write directly to the config file with comments, rather than the comment-less `repo_config_set_gently()`. The patch emerged from mailing list discussions about making `scalar`'s configuration changes more transparent.

This is a straightforward change with a clear purpose - improving maintainability and user understanding of how `scalar` modifies configuration. The patch is small (+5/-1 lines) and focused, with a co-author credit suggesting it was collaboratively developed. As noted in the thread summary, this is part of ongoing work to improve `scalar` config documentation.
