This is the fourth patch in Johannes Schindelin's 10-part series improving Windows test suite compatibility with symbolic links. The patch fixes a test case in t0001-init.sh that fails on Windows due to unexpected behavior from `git diff --no-index` when comparing symlinks.

The test 're-init to move gitdir symlink' checks that a symlink `.git` file points to the correct location after reinitializing a repository. On Windows, `test_cmp` uses `git diff --no-index`, which doesn't resolve symlinks as the test expects - instead showing the symlink target directly. The patch works around this by skipping the symlink comparison when `GIT_TEST_CMP` contains `--no-index`, which indicates the Windows-specific behavior.

This is a straightforward test fix that maintains the test's intent while accommodating Windows platform differences. The change is minimal (just 4 lines added) and clearly explained in the commit message. It's part of the broader effort to make Git's test suite work correctly when MSYS2 enables symlink support by default on Windows.
