This is a documentation patch series (v2) focused on improving discoverability around `scalar` configuration. The series consists of two small but meaningful documentation improvements that emerged from a mailing list discussion about `scalar` config visibility.

The first patch adds inline comments in `scalar.c` explaining why certain config values are set during `scalar` operations. The second patch documents the `gui.GCWarning` config option that was previously missing from the config documentation. Both changes are straightforward with clear value - the first helps future maintainers understand the reasoning behind config choices, while the second fills a documentation gap for users.

The author notes this is a partial solution to the broader discoverability discussion, with more comprehensive changes still in progress but being split out to avoid delays. The v2 changes are minimal, just adding missing signoffs from the initial submission. The patches touch two files (`scalar.c` and `Documentation/config/gui.adoc`) with a net +10/-1 line change, suggesting focused, non-controversial improvements.
