This is Junio Hamano's monthly "What's cooking in git.git" status update, summarizing the state of various patches and topics in the Git development pipeline as of November 2025.

The email organizes contributions into three main categories: patches that have graduated to 'master', new topics being proposed, and topics that are still cooking (under review or needing work). Highlights include several bugfixes and cleanups that have been merged, including improvements to blame's diff algorithm, Windows thread emulation fixes, and CI test output handling. New proposals cover areas like replay command improvements, patience diff optimization, and better submodule path handling.

Notable ongoing work includes a major refactoring of the object streaming interface by Patrick Steinhardt, continued progress on the `the_repository` removal effort, and Rust interoperability work for SHA-1/SHA-256 conversion. The email also notes several documentation updates and test fixes in progress. As usual, Junio provides clear indicators of each topic's status - whether it's ready for 'next', needs a reroll, or is awaiting further discussion.
