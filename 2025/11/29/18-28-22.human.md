This is a test fix in Johannes Schindelin's ongoing series to improve Windows compatibility with symbolic links in Git's test suite. The patch corrects an incomplete test prerequisite in t0600-reffiles-backend.sh. The test case checks symref transaction support with symbolic links, which requires both the SYMLINKS prerequisite (for symlink support) and a new !MINGW prerequisite (since Windows doesn't support the preferSymlinkRefs feature).

This is patch 6/10 in the series, which aims to prepare Git's test suite for MSYS2's planned default enablement of symlink support on Windows. The change is straightforward - it simply adds the missing platform-specific prerequisite to skip the test that can't pass on Windows due to fundamental feature limitations. The patch maintains the existing test behavior on other platforms while properly marking it as unsupported where appropriate.
