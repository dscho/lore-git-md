This is a documentation patch in a series about improving `scalar` configuration visibility, now taken over by Matthew Hughes with Derrick Stolee's co-authorship. The patch adds inline comments to configuration values set by `scalar`, making it clear when changes originate from `scalar` rather than manual user edits.

The change modifies `scalar.c` to append "# set by git-scalar" comments when writing configuration values. This addresses a specific pain point where users might not realize certain config changes came from `scalar` initialization. The implementation uses `repo_config_set_in_file_gently()` to preserve these comments in the config file.

The patch appears straightforward and well-motivated, building on prior discussion about `scalar` configuration discoverability. As the second part of a two-patch series, it complements the first patch's documentation improvements with this more technical solution. The change is focused and unlikely to be controversial, though reviewers might want to verify the comment format and placement.
