This is a documentation patch series aimed at improving discoverability around `scalar` configuration. The two-patch set follows up on a mailing list discussion about making `scalar`'s behavior more transparent to users.

The first patch adds inline comments in `scalar.c` explaining why specific config values are being set during `scalar` operations. This should help future maintainers understand the reasoning behind these settings. The second patch documents the `gui.GCWarning` config option that was previously missing from the config documentation.

The author notes this is a partial effort - they had planned more extensive commentary but are submitting these smaller changes first rather than delaying. The changes appear straightforward and uncontroversial, addressing clear gaps in documentation. The patches touch both user-facing docs and internal code comments, providing value to both end users and developers working on the codebase.
