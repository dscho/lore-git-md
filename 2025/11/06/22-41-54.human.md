This is the second and final patch in a series adding diff algorithm configurability to `git blame`. The feature allows selecting between Myers (current default), minimal, patience, and histogram algorithms via a new `--diff-algorithm` option and the existing `diff.algorithm` config.

The patch builds on the xdiff refactoring from patch 1/2, implementing the user-facing functionality in `git blame`. It adds the new option, honors the config setting (with CLI precedence), marks the legacy `--minimal` flag as OPT_HIDDEN to avoid confusion, and includes comprehensive test coverage. The tests verify default behavior, CLI/config precedence, edge cases, and cross-algorithm comparisons while being optimized to reduce process overhead.

After multiple rounds of review addressing technical feedback about flag handling and test coverage, the series has reached consensus and maintainer approval. This final version incorporates all requested polish items including test optimizations and fixes for missed cases in merge-related code paths. The implementation is clean, well-documented, and ready for merging.
