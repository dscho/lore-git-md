CI / build system update for GitHub Actions workflows. This patch updates the versions of two GitHub Actions used in Git's CI pipeline: `actions/upload-artifact` from v4 to v5 and `actions/download-artifact` from v5 to v6. The changes are mechanical version bumps across multiple workflow files, with no functional changes to the workflows themselves. The patch originated from dependabot version updates in the git-for-windows repository and was forwarded by Johannes Schindelin. The modifications affect artifact handling in Windows, Visual Studio, and Meson build/test jobs, consistently updating all instances where these actions are used. The commit references corresponding git-for-windows PRs but provides no specific rationale for the version updates beyond keeping dependencies current.
