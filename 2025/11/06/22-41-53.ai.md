This is the first patch in a two-part series implementing diff algorithm configurability for `git blame`. The patch focuses on xdiff refactoring to support clean algorithm selection.

The change adds `XDF_NEED_MINIMAL` to the `XDF_DIFF_ALGORITHM_MASK` bitmask in `xdiff/xdiff.h`, which previously only included bits for patience and histogram diffs. This fixes an inconsistency where resetting the diff algorithm to default required separate clearing of the minimal diff bit, which was missed in `merge-ort.c` and `builtin/merge-file.c`. The patch removes now-redundant explicit clearing of `NEED_MINIMAL` from `diff.c` and `merge-ort.c`.

The technical change makes the `DIFF_XDL_CLR` macro obsolete but retains its documentation. While this is technically a breaking change for xdiff library consumers, reviewers agreed it's justified for consistency. The change enables clean implementation of algorithm selection in the subsequent blame feature patch.

Review history shows this approach was vetted through multiple rounds of technical discussion, with Phillip Wood confirming the mask expansion is correct and Junio C Hamano providing maintainer guidance. The v5 version implements all final polish items including test optimizations and flag handling cleanup. The series is now ready for merge with consensus on the implementation.
