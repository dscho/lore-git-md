Benchmarks show the patch brings a 3x speedup for reftable operations and a 10x improvement for ref migrations between backends, bringing performance back to pre-regression levels. The change affects several core components including the object peeling logic, ref-filter, and both ref storage backends.

The patch includes a clear technical explanation of why the regression affected different backends differently and provides thorough performance measurements. It also renames the verification flag to better reflect its actual purpose. The solution appears well-considered, preserving the original security benefits while eliminating the unintended performance penalty across non-tag reference operations.
