Feature patch finalizing diff algorithm configurability for `git blame`, now at version 5 with all review feedback addressed. This is the second patch in a two-part series, building on the xdiff refactoring from patch 1 to expose diff algorithm selection in blame.

The patch adds `--diff-algorithm` option to `git blame` matching `git diff`'s interface (myers, minimal, patience, histogram), honors `diff.algorithm` config with CLI precedence, and marks legacy `--minimal` as OPT_HIDDEN. Documentation uses a shared include file, and the test script `t8015-blame-diff-algorithm.sh` provides comprehensive coverage of default behavior, CLI/config precedence, and edge cases while optimizing process count via combined sed operations.

Key technical details for future reference:
- Uses XDF_DIFF_ALGORITHM_MASK from xdiff refactoring
- Implements callback functions for option parsing
- Maintains `--no-minimal` behavior as transitional
- Touches `builtin/blame.c`, documentation files, and test infrastructure
- Test cases verify:
  * Default Myers algorithm behavior
  * Histogram algorithm output differences
  * Config vs CLI precedence
  * `--minimal` interaction
  * Option ordering effects

The implementation reflects consensus from extensive review discussion, particularly around flag handling (XDF_NEED_MINIMAL in mask), interface design (OPT_HIDDEN for `--minimal`), and test optimization. All outstanding feedback from Junio and Phillip has been addressed, making this ready for merge.
