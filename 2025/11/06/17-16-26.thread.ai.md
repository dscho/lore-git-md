Git v2.52.0-rc1 release announcement summary:

First release candidate for Git 2.52.0 with 606 non-merge commits from 80 contributors (33 new). Major changes include:

New user-facing features: `git repo` subcommand for repository inspection, `git last-modified` for file change timestamps, and `git sparse-checkout clean` improvements. Deprecates `core.commentChar=auto` and prepares for Git 3.0's default branch name change from 'master' to 'main'.

Internal refactoring continues removing `the_repository` global by passing repository instances explicitly. Bulk-checkin infrastructure gains transaction support for object creation. Preliminary Rust integration work begins. Performance improvements in revision traversal (pathspecs, Bloom filters) and range-diff memory management.

Bug fixes address interactive rebase merge commit handling, refs migration issues, and diff/status output inconsistencies. Documentation updates modernize synopsis formatting and add contributor guidance (including AI documentation). Build system adds Meson targets, Rust compilation support, and Windows test fixes. Includes usual code cleanups, test improvements, and platform compatibility work.

René Scharfe noted two minor corrections needed in the release notes: a singular/plural fix for "bits" -> "bit" in object flag descriptions, and clarification that khash usage mentioned refers back to v2.51.0's commit 30598ccc4d rather than new work in this cycle. These documentation corrections do not affect the release's functionality.
