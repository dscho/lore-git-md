This thread discusses a routine update to GitHub Actions versions in Git's CI workflows. Johannes Schindelin forwarded a patch that bumps `actions/upload-artifact` from v4 to v5 and `actions/download-artifact` from v5 to v6 across several workflow files. The changes originated from dependabot updates in the git-for-windows repository and are being applied to the main Git project's CI configuration. The updates are purely mechanical version bumps with no functional changes to the workflows themselves, affecting Windows, Visual Studio, and Meson build/test jobs. The patch appears uncontroversial, with no discussion or objections raised so far about these dependency updates.
