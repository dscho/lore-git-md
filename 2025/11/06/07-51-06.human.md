This is a follow-up discussion in the Meson build system configuration thread. Patrick Steinhardt, one of Git's Meson experts, responds to Junio Hamano's observations about the limited path configuration options in Meson.

Patrick explains that the minimal set of configuration options in Meson was a deliberate choice during its introduction to Git, based on discussions about which build options were actually needed in practice. He confirms that while Meson provides path-handling utilities, the underlying type system still represents paths as strings, addressing Junio's surprise about the lack of richer path types.

The exchange serves as useful background context for the ongoing patch series that adds HTML documentation path configurability to Meson builds. Patrick doesn't raise any new technical concerns about the proposed changes, and his comments help clarify the design decisions behind Git's Meson integration. This reinforces that the patch series is technically sound and ready for inclusion, as noted in the thread summary.
