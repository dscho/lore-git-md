Feature patch series adding diff algorithm configurability to `git blame`, now at version 5 with all review feedback addressed. This final iteration implements the last requested changes from maintainers and reviewers.

The series consists of two patches:
1. A refactoring of xdiff internals to properly handle the 'minimal' diff algorithm flag
2. The user-facing `git blame` changes to support `--diff-algorithm` option and `diff.algorithm` config

Key changes in v5:
- The `--minimal` option is now hidden (marked OPT_HIDDEN) as per Junio's guidance to focus on the new `--diff-algorithm` interface
- Test script optimizations to reduce spawned processes by combining sed operations
- Cleaned up the XDF_NEED_MINIMAL flag handling in the bitmask

The implementation now matches the maintainers' preferred direction:
- Explicit algorithm selection via `--diff-algorithm` is the primary interface
- Boolean toggles like `--minimal` are deprecated in favor of named algorithms
- Comprehensive test coverage verifies all combinations of config/CLI options

This appears ready for merging, having addressed all technical feedback through multiple review rounds. The changes are well-contained and the documentation is thorough, sharing the algorithm descriptions with `git diff` via a common include file.
