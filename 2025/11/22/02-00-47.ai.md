This is a follow-up in the config file handling thread, where Delilah Ashley Wu responds to Junio C Hamano's feedback on her patch series. The series aims to fix the inconsistency where `git config list --global` only shows `$HOME/.gitconfig` while Git actually reads both that and `$XDG_CONFIG_HOME/git/config`.

Wu acknowledges Junio's point about the inconsistency being "without good reason" and plans to include this observation in the v2 cover letter. She clarifies that the [RFC] tag was accidental (from leaving the GitHub PR in draft mode) and will be removed in v2. Wu also notes that Junio's review addressed her own concerns about the series, particularly regarding the temporary regression introduced in the middle of the patch series for unreadable config files.

The response indicates Wu will incorporate Junio's feedback in the next version, including his detailed comments about path normalization implementation and test methodology. The exchange shows the series is moving toward a non-RFC state with the maintainer's technical concerns being addressed, though the path handling details and regression avoidance strategy remain open for discussion.
