Submodule checkout behavior with non-branch references - feature request from Alon Bar-Lev regarding Gerrit workflow limitations. Current submodule implementation requires branch names (refs/heads/) for checkout operations, creating incompatibility with Gerrit's review refs (refs/changes/). While branch tracking serves update purposes, the restriction appears unnecessarily strict for checkout. Core issue centers on submodule configuration's branch requirement (submodule.<name>.branch) and whether alternative ref namespaces could be supported. No proposed solution yet, but identifies concrete pain point in Gerrit-based workflows where review changes live outside standard branch namespace. Technical considerations would need to address submodule command behavior, configuration options, and reference namespace handling.
