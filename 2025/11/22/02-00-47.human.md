Bugfix follow-up in the global config file handling series. Delilah Ashley Wu responds to Junio Hamano's review of her patch series that fixes the inconsistency where `git config list --global` only showed `$HOME/.gitconfig` while Git actually reads both that and `$XDG_CONFIG_HOME/git/config`.

Wu acknowledges two key points from Hamano's review: (1) the RFC tag was accidentally left in from GitHub's draft mode and will be removed in v2, and (2) she agrees with Hamano's concern about introducing a temporary regression in error handling during the series. She confirms she'll address these in the next version.

The exchange shows the series is technically sound (with Johannes Schindelin's Reviewed-by tags) but undergoing careful maintainer scrutiny from Hamano regarding both procedural details and implementation choices. Wu appears responsive to feedback, quickly acknowledging the points raised. The thread remains focused on refining the solution to this long-standing inconsistency in Git's config file handling.
