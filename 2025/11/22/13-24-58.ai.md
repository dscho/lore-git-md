This is a performance test and tooling patch related to the ongoing tempfile refactoring effort. René Scharfe responds to Junio Hamano's questions about potential advantages of system `mkstemp(3)` over Git's `git_mkstemp_mode()` by providing benchmark data and analysis.

The email includes a patch that enhances `test-mktemp` to compare performance between different tempfile creation methods. Key technical details:
- Adds options to test `mkstemp(3)`, `xmkstemp()`, and `git_mkstemp_mode()`
- Supports custom file modes and repeated executions for benchmarking
- Benchmark results show Git's implementation is slightly faster than system `mkstemp(3)` on macOS, especially when setting non-default permissions
- The test tool now uses parse-options for better CLI handling
- Three test functions are implemented with consistent error handling
- The benchmark shows 5% faster performance for Git's implementation in default case, 24% faster when setting permissions

René's analysis suggests there's no compelling performance or security advantage to using system `mkstemp(3)`, and the unified Git implementation offers better consistency across platforms. The test tool provides concrete data to support the ongoing consolidation of tempfile creation code. This appears to be the final piece of evidence needed to conclude the refactoring discussion.
