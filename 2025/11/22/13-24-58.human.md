This is a performance test and refactoring follow-up in the ongoing tempfile creation consolidation effort. René Scharfe responds to Junio Hamano's questions about potential advantages of system `mkstemp()` by providing concrete benchmarks comparing it to Git's `git_mkstemp_mode()`.

The email includes surprising benchmark results showing Git's implementation is slightly faster than the system `mkstemp()` on macOS (5% faster for default mode, 24% faster when changing permissions). The accompanying patch extends the test-mktemp helper to support performance testing of different tempfile creation methods, adding options to:
- Select between `xmkstemp`, `mkstemp`, and `git_mkstemp_mode`
- Specify custom file modes
- Run multiple iterations for benchmarking

The discussion suggests the performance advantage, combined with Git's need for consistent behavior across platforms and custom permissions, makes the case for fully adopting `git_mkstemp_mode()` even stronger. The test tool additions will help validate this direction and monitor for any platform-specific performance regressions.
