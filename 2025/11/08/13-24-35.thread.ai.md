Git for Windows v2.52.0-rc1 release announcement by Johannes Schindelin. Bundles upstream Git v2.52.0-rc1 with updated dependencies: PCRE2 v10.47 and cURL v8.17.0. Available in 64-bit and ARM64 variants, including portable and MinGit versions. Continues the policy of dropping git-svn support as previously announced. Includes SHA-256 checksums for all packages. Routine maintenance update following standard Git for Windows release practices, primarily updating bundled components rather than introducing new features. Targets Windows users and packagers needing to test upcoming version.
