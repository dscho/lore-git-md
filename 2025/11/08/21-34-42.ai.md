The changes cover all fetch paths including main fetch operations, legacy `backfill_tags()`, and refspec-based fetches.

- New helper `commit_ref_transaction()` handles both atomic and non-atomic cases while properly reporting rejected updates
- Fix ensures transaction commitment happens even when `fetch_and_consume_refs()` or `backfill_tags()` report errors
- Error handling now properly checks return values and aborts on failure
