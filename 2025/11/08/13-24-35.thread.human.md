This is a release announcement for Git for Windows 2.52.0-rc1 from Johannes Schindelin (Dscho), the project's maintainer. The release candidate includes updated builds for 64-bit and ARM64 Windows systems, along with portable and MinGit variants. It bundles upstream Git v2.52.0-rc1 along with updated dependencies: PCRE2 v10.47 and cURL v8.17.0. The announcement reminds users that git-svn support remains dropped as previously decided. SHA-256 checksums are provided for all packages to enable verification. This appears to be a routine maintenance update rather than introducing new Windows-specific functionality, following the standard release process for testing before final distribution.
