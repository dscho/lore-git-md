This is a bug report about fsmonitor daemon processes failing to terminate properly on macOS 26 (Tahoe). Jono Spiro reports that when using Git with fsmonitor enabled, daemon processes spawn detached from their parent applications and never terminate, accumulating indefinitely. This affects all Git clients (Xcode, VS Code, GitX, etc.) and all Git installations on macOS 26, causing system resource exhaustion and locked repositories.

The key symptoms are that `git fsmonitor--daemon` processes run with `--detach` flag and don't respond when parent applications quit. Users must manually kill these processes with `pkill`. The issue appears specific to macOS 26 and doesn't occur on earlier versions. A workaround is to disable fsmonitor globally.

The report is thorough, including reproduction steps, system info showing Git 2.51.2 on ARM64, and links to related issues. This appears to be a serious system-level bug affecting core Git functionality on the latest macOS, likely requiring changes to how fsmonitor handles process lifecycle management on Tahoe. The impact is significant enough that it's causing problems for end applications like GitX, where some users report thousands of orphaned processes.
