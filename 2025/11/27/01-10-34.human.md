This is part 12 of Ezekiel Newren's RFC series refactoring Git's Rust infrastructure into a Cargo workspace. The patch focuses on CI integration by adding Rust toolchain installation to GitHub workflows.

The changes add Rust installation steps across all CI jobs (Windows, Linux, macOS) with version-specific requirements:
- Minimum Rust 1.63.0 for most platforms
- Windows requires 1.78.0 (with different targets for Make vs Meson builds)
- Musl builds need 1.72.0
- 32-bit Linux has a specific target architecture

The implementation creates new helper scripts (`install-rustup.sh` and `install-rust-toolchain.sh`) and modifies existing CI scripts to ensure Rust is available during builds. The patch also clean up Rust toolchains after test runs.

This addresses one of the known issues from earlier in the series (broken GitHub workflows) but doesn't yet fix the Windows Meson build failures or Rust test integration. The approach appears thorough, with careful version pinning and platform-specific handling, though reviewers may want to verify the chosen Rust versions align with Git's compatibility requirements.
