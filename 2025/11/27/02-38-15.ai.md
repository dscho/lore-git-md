Feature patch introducing a new "lisp" userdiff driver to support multiple Lisp dialects. This is the first patch in a v2 series aiming to unify Lisp-family language support in Git's diff highlighting.

The patch adds a new driver that handles both Common Lisp and Scheme syntax patterns, addressing the limitation where the existing "scheme" driver didn't fully support Common Lisp. The implementation uses a disjunctive regex pattern that combines two approaches: matching either unindented left parentheses (for top-level forms) or slightly indented lines starting with "(def" (for function definitions). It also includes support for Common Lisp's vertical bar symbol syntax and general word boundaries.

Key technical details include:
- Regex pattern combining column-0 parentheses and indented "(def" forms
- Case-insensitive matching via the pattern structure
- Explicit handling of 1-2 spaces before "(def" to maintain compatibility
- Vertical bar symbol syntax support with proper escaping
- Minimal implementation footprint (8 lines added to userdiff.c)

This builds on the thread's established consensus for a unified approach, addressing prior feedback about whitespace handling and backward compatibility. The patch maintains all existing Scheme functionality while adding Common Lisp support through careful pattern construction that avoids false positives in block detection. The implementation is constrained to userdiff.c with no changes to other subsystems.
