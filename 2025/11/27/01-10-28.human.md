Refactoring patch in the Rust infrastructure series, introducing a new crate for header generation.

This is patch 6/13 in Ezekiel Newren's series restructuring Git's Rust code into a Cargo workspace. The patch creates a new `generate-headers` crate that will handle automatic generation of C header files from Rust code using cbindgen. The crate includes configuration templates and a main.rs that sets up the header generation pipeline, currently targeting the `gitcore` crate.

The implementation appears straightforward, using standard Rust tooling (cbindgen) with some Git-specific configuration around include guards and output locations. The code follows the workspace pattern established in earlier patches, placing the new crate under rust/generate-headers/ and outputting headers to a generated/ directory.

This continues the series' infrastructure-first approach, though like previous patches it doesn't yet address the known Windows compatibility issues or test integration challenges noted in the thread. The patch seems technically sound but is still part of an incomplete transition - the actual Rust code generation and cross-crate dependencies remain to be addressed in future patches.
