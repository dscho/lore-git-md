This is a build system refactoring patch as part of Ezekiel Newren's RFC series to restructure Git's Rust infrastructure into a Cargo workspace. The patch specifically removes Patrick Steinhardt's prior Rust integration from the Meson build system, clearing the way for the proposed multi-crate approach.

The changes delete all Meson-specific Rust build infrastructure including:
- The `rust` feature flag (replaced with simpler `with_rust` boolean)
- Cargo build wrapper script (`src/cargo-meson.sh`)
- Rust source file tracking and linking rules in `src/meson.build`
- Platform-specific library naming logic
- Rust test integration

The removal is comprehensive but mechanical - it strips out the single-crate Rust support without yet adding the new multi-crate infrastructure (which comes in later patches). The patch maintains basic Rust detection via the `with_rust` option but removes all actual build logic.

This is a foundational change that enables the subsequent patches to implement the new workspace-based approach. The removal appears thorough but leaves the build system in a non-functional state for Rust until the full series is applied. The commit message is minimal, assuming readers are following the series' cover letter which explains the broader context.
