Feature patch introducing a unified Lisp dialect diff driver. This is the first of two patches in a series that aims to improve syntax highlighting for Lisp-family languages in Git diffs.

The patch adds a new "lisp" userdiff driver that works across multiple Lisp dialects including Common Lisp and Scheme. The key technical aspects are:
- Detects function definitions via either unindented parentheses or lines starting with "(def" (with 1-2 spaces of indentation)
- Handles Common Lisp's vertical bar symbol syntax
- Maintains compatibility with Scheme's existing patterns

This builds on previous discussion where the approach was refined to unify the drivers rather than maintain separate ones. The implementation is concise (8 lines added) and appears well-considered, with patterns designed to work across dialects while avoiding false positives. The patch follows up on earlier feedback about whitespace handling and case sensitivity.

The second patch in the series will presumably address documentation updates. This change looks ready for review, with the main outstanding question being around edge case handling of the column-0 parenthesis detection that was raised in previous discussion.
