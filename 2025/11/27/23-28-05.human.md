This is a translation (l10n) issue report about potential inaccuracy in the German localization of Git's error messages. Brian M. Carlson points out that while Spanish and French translations of the "fatal: Needed a single revision" message correctly use a general term for "revision", the German version specifically says "Commit" (commit), which may be too narrow since `git rev-parse --verify` can refer to any Git object type (blobs, trees, tags, etc.).

The reporter notes that other German translations in Git use "Revision" (revision) in related contexts like "revision walk" and "revision list", suggesting this might be a more accurate term here. However, Carlson explicitly defers to native German speakers' judgment, acknowledging their own limited German proficiency while raising the concern for review by more qualified translators.

The issue appears well-motivated and carefully presented, with clear examples showing the inconsistency across languages and a thoughtful consideration of alternative terminology. This seems like a straightforward case for the German translation team to evaluate and potentially correct.
