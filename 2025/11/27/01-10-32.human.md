This is a minor build system cleanup patch in Ezekiel Newren's ongoing Rust infrastructure refactoring series.

Patch 10/13 tweaks the `rust-clean` target in the Makefile to be more specific about which files to delete in the `generated/` directory. Instead of removing the entire directory, it now only removes `*.h` files, preserving any other contents that might exist there. This change aligns with the series' introduction of generated header files in earlier patches.

The modification is straightforward and appears to be a logical refinement of the build system's cleanup behavior. While small, it demonstrates attention to detail in the Rust build infrastructure changes. The patch doesn't address any of the larger open questions in the series (Windows support, test integration, etc.), but keeps the incremental improvements coming in this substantial refactoring effort.
