This is the first patch in Ezekiel Newren's RFC series proposing a Rust infrastructure refactoring into a Cargo workspace. The patch removes all Rust-related build infrastructure from the Makefile and shared.mak that was previously added by Patrick Steinhardt's single-crate approach. This includes deleting:

- The WITH_RUST build flag and related documentation
- Rust target directory and library path configuration
- Cargo build arguments and quiet mode handling
- Rust source file tracking (lib.rs and varint.rs)
- Rust library linking rules
- The rust build target
- QUIET_CARGO make variable

The changes are purely deletions with no new Rust build logic yet introduced, clearing the way for the new multi-crate approach to be implemented in subsequent patches. This is a foundational change that reverts the existing Rust integration before rebuilding it differently, as outlined in the RFC's goal of improving modularity through separate crates.

The patch appears mechanically sound - it thoroughly removes all Rust-specific Makefile elements without disturbing other build logic. However, as noted in the RFC status, this is part of an incomplete prototype that currently breaks existing workflows, so reviewers should expect follow-up patches to restore Rust functionality in the new architecture. The commit message is very brief, not explaining the rationale beyond "undo Patrick's changes", though the broader RFC context provides the motivation.
