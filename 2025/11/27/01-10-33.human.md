This is a CI/build system patch in Ezekiel Newren's ongoing series refactoring Git's Rust infrastructure. Patch 11/13 standardizes the Rust build flags across Make and Meson build systems in GitHub workflows.

The change is straightforward: it updates the CI script to use consistent parameter names for enabling Rust support. The Makefile-style `WITH_RUST=YesPlease` becomes `WITH_RUST=true`, while the Meson flag changes from `-Drust=enabled` to `-Dwith_rust=enabled`. This appears to be a minor but logical cleanup to make the build options more uniform.

The patch is small and focused, though it doesn't address the broader CI workflow issues noted in earlier thread summaries (like Windows build failures or missing Rust test integration). As part of the larger series, this seems like a preparatory step toward getting CI working with the new multi-crate Rust setup, but doesn't yet solve the known workflow problems. The change itself looks uncontroversial - just parameter naming alignment - though it will need to be coordinated with any other ongoing CI changes.
