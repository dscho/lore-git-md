Build system refactoring as part of Rust infrastructure changes. This is the second patch in Ezekiel Newren's 13-part series proposing a major restructuring of Git's Rust build infrastructure from a single-crate to a multi-crate approach.

The patch removes Patrick Steinhardt's existing Rust integration from the Meson build system, deleting several files and scripts that handled Rust compilation and testing. Key changes include:
- Removing Rust-specific build options and dependencies from meson.build
- Changing the Rust option from a feature flag to a simple boolean
- Deleting the cargo-meson.sh wrapper script and src/meson.build entirely

This is a foundational change that clears the way for the new multi-crate approach proposed in later patches. The commit message is minimal, assuming readers are following the full series (whose cover letter explains the motivation). The changes appear mechanical and focused, though the patch leaves the Meson build in a non-functional state for Rust until later patches restore the new infrastructure.

As an RFC, this is clearly marked as work in progress - Windows builds are known to be broken at this stage, and test integration hasn't been ported over yet. The patch series as a whole represents a significant architectural shift from the current Rust implementation, so feedback on the direction is being sought before completing the work.
