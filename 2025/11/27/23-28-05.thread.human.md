This thread reports a German localization issue in Git's error messages. The problem concerns `git rev-parse --verify`'s error message, where the German translation currently uses "Commit" - which is too specific since the command works with any object type (commits, blobs, trees, tags). The reporter, brian m. carlson, notes that other German translations in Git use "Revisionsgang" and "Revisionsliste" for similar concepts, suggesting "Revision" might be more appropriate here. While acknowledging they're not fluent in German, they've identified what appears to be a genuine technical inaccuracy in the translation. The thread now awaits input from German-speaking contributors to confirm the best translation approach.
