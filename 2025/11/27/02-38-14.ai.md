Feature patch series extending Git's userdiff highlighting to support Lisp dialects beyond Scheme. This is the second version of a proposal to unify Lisp-family language support under a single driver that handles both existing Scheme patterns and new Common Lisp/Emacs Lisp conventions.

The key technical approach combines patterns through disjunctive regexp matching, preserving all existing Scheme behavior while adding:
- Top-level form detection via left-margin parentheses
- Case-insensitive "(def" prefix matching for function definitions
- Two-space indentation convention for grouped forms
- Tab handling fixes to maintain Scheme compatibility

The cover letter clarifies the design rationale, noting the balance between false positives (avoiding overly broad patterns) and false negatives (covering common Lisp dialect conventions). Version 2 addresses prior feedback by unifying with the Scheme driver rather than creating a separate one, fixing whitespace handling bugs, and making matching case-insensitive.

The changes appear carefully constrained to avoid regressions in existing Scheme support while expanding coverage to other Lisp dialects.
