This is the first patch in a 13-part RFC series proposing a Rust infrastructure refactoring. The patch removes all Rust-related build system code that was previously added by Patrick Steinhardt when implementing the single-crate Rust approach. 

The changes are purely mechanical deletions - stripping out Makefile rules for Rust compilation, cargo invocation, and related variables. This clears the way for the subsequent patches that will introduce a new multi-crate Rust architecture. The deletions include:
- Removal of WITH_RUST build flag and related conditional compilation
- Stripping of Rust-specific variables like RUST_SOURCES and RUST_LIB
- Elimination of cargo build rules and quiet mode handling
- Deletion of Windows-specific Rust library handling

As the first step in a major architectural change, this patch is intentionally destructive - it removes existing functionality without yet providing replacements. The commit message is minimal, simply noting these are "Patrick's changes" being undone. The real motivation and justification will come in later patches and the cover letter.

This appears to be a clean technical reversal of the prior approach, though the lack of immediate replacement means the series would leave Git without Rust support until all patches are applied. The changes are focused and seem correctly scoped to just build system modifications.
