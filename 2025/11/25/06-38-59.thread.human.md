This thread explored adding bash completion for Git's short options (like -C, -P, -c) when typing `git -<TAB>`. Wiktor Mis submitted two versions of the patch, with v2 being initially queued by Junio after minor tweaks. However, SZEDER Gábor raised a fundamental objection: while the technical implementation worked, the bash completion framework can't show explanatory help text for short options (like "-p (enable pager)"), making the feature of limited practical value.

Junio ultimately agreed with this critique, recalling a similar 2007 discussion about completion philosophy. The maintainers view discoverability through help text as more important than just completing short options. Junio has now officially rejected the series, thanking Wiktor for the contribution while upholding the project's longstanding position. The bash completion framework would need to support help text display for short options to reconsider this feature - something not currently possible. The thread is now closed unless someone can propose a solution to that fundamental limitation.
