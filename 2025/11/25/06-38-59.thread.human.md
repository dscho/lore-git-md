Wiktor Mis's patch series adding bash completion for Git's short options (-C, -P, -c, -h, -p, -v) when typing `git -<TAB>` is now being queued by Junio Hamano. The second version of the patch modifies `__git_main()` in the bash completion script to handle these common single-letter options while preserving the existing long-option completion behavior. Junio has approved the technical approach after Wiktor incorporated his earlier feedback about making the commit message more specific.

The implementation currently handles all hyphen-prefixed patterns under `-*`, which technically includes both short and long options, though only the six specified short options are actually added to the completion list. Junio has left open the question about whether `-<TAB>` should complete just single-letter options or all hyphen-prefixed ones, noting this could be addressed in future work. With Junio's sign-off, the patch appears ready for merging unless other contributors raise objections about the current behavior. The change is focused and minimal, adding completion for these core short options that were previously missing from the bash completion experience.
