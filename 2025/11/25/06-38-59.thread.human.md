This thread discusses Wiktor Mis's patch to add bash completion for Git's short options (-C, -P, -c, -h, -p, -v) when typing `git -<TAB>`. The change modifies the `__git_main` function in the bash completion script to recognize these common single-letter options, following the existing pattern for long options.

Junio Hamano reviewed the patch and suggested making the subject line more specific about completing `git -<TAB>`. He noted that the current implementation keeps short and long option completion separate (requiring `--<TAB>` for long options), and raised the possibility of a follow-up to unify them. While accepting this as a good incremental improvement, Junio's comments indicate there may be room to refine the completion behavior further in future work. The change itself is low-risk, touching only the bash completion helper script.
