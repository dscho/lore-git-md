Feature patch adding `--all` flag to experimental `git-repo-info` command.

This is the second patch in a v4 series implementing the experimental `git-repo-info` command, adding a `--all` flag to output all available repository metadata keys/values at once rather than requiring explicit key specification. The implementation builds on the refactored output handling from the first patch (which optimized memory usage and output paths) while maintaining the same interface and test coverage.

Key technical details:
- Adds `--all` flag to `git repo info` command
- Implements new `print_all_fields()` function that iterates through all fields in `repo_info_fields` array
- Maintains same output formats (keyvalue/nul) and ordering as individual key requests
- Includes comprehensive tests:
  - Verifies `--all` matches explicit key listing
  - Ensures `--all` conflicts with explicit keys
- Updates documentation to clarify behavior
- Preserves all error handling and format validation

The patch appears well-polished, having addressed all feedback from previous rounds (v4 incorporates suggestions from Karthik Nayak and Patrick Steinhardt). It maintains clean separation from the refactoring work in the first patch while building on its optimized output infrastructure. The implementation is straightforward and maintains the command's experimental status while providing a useful quality-of-life improvement for users who want to see all available repository metadata.
