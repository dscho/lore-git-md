Platform compatibility patch addressing clang warnings in Windows-specific error handling. This is a follow-up to Johannes Schindelin's original patch that rewrote comma operator usage in `compat/mingw.c` to satisfy clang's `-Wcomma` warnings in the Git for Windows SDK ARM64 build.

Junio C Hamano reviews and approves the changes, noting that while the original comma operator pattern (like `return errno = ENOSYS, -1;`) worked correctly, it was somewhat obscure to read. The new version separates the `errno` assignment from the return statement, making the error handling more straightforward. 

The changes are purely syntactic with no functional impact, affecting several Windows-specific functions dealing with file operations and system calls. Junio confirms the patch will be queued, agreeing with the simpler, more readable approach even if more verbose alternatives might exist. This continues Git's ongoing effort to maintain clean, warning-free code across all supported platforms and compilers.
