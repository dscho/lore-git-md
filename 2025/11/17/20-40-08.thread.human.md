This thread addresses a build system fix for CMake configurations after recent changes to Git's static library structure. The patch removes obsolete CMake logic that was attempting to build separate `xdiff` and `reftable` libraries, which were consolidated into the main `libgit` in the Makefile-based build system. The change fixes CMake build failures that were occurring during Makefile parsing.

The straightforward fix deletes CMake code setting up separate library targets and updates the `common-main` target to link only against `libgit`. While primarily important for Git for Windows CI builds, the patch also highlights the ongoing challenge of maintaining parallel build systems (CMake and Meson) in sync with the primary Makefile. The change is a necessary synchronization with no functional impact beyond fixing the build, though it may spark future discussions about build system consolidation.
