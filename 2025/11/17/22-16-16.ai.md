This is a Rust infrastructure patch in the SHA-1/SHA-256 interoperability series, specifically exposing hash context functions to Rust.

The patch moves hash context operations from inline functions in hash.h to regular functions in hash.c, making them callable from Rust via FFI. It adds three new functions (`git_hash_alloc`, `git_hash_free`, `git_hash_init`) for memory management and initialization, while converting existing inline operations (`git_hash_clone`, `git_hash_update`, `git_hash_final`, `git_hash_final_oid`) to non-inline implementations. The changes maintain identical runtime behavior while enabling Rust code to safely interact with Git's hashing system.

Key technical details include:
- New alloc/free functions for managing `git_hash_ctx` memory from Rust
- Conversion of inline hash operations to regular functions for FFI compatibility
- Preservation of all existing hash algorithm functionality (`clone_fn`, `update_fn`, `final_fn`, `final_oid_fn`)
- Header file cleanup moving declarations to more conventional grouping
- Maintains same function signatures and behavior, just changes linkage

This builds on the series' Rust infrastructure work by enabling Rust code to perform hashing operations using Git's existing hash algorithm implementations. The changes follow the pattern of previous FFI preparation work in the series, focusing on making core operations safely accessible across language boundaries while maintaining type safety and memory management guarantees.
