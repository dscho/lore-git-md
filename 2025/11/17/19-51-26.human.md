This is a small build system patch to include the `scalar` binary in the `make strip` target. The `scalar` command was added to Git's main build in 2022 but was overlooked in the stripping process, which removes debugging symbols to reduce binary size.

Johannes Schindelin noticed this omission while working on Git for Windows integration with MSYS2. The change is straightforward - just adding `scalar$X` to the dependencies of the `strip` target in the Makefile. This brings `scalar` in line with how other Git binaries are handled during the build process.

The patch is minimal (a one-line change) and appears to be a simple oversight fix rather than anything controversial. It's part of ongoing maintenance to keep the build system consistent as new components like `scalar` are added to the Git ecosystem.
