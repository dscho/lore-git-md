This is a CI/build system issue in the ongoing SHA-1/SHA-256 interoperability patch series, specifically affecting Windows builds with Meson. Junio C Hamano reports that the "win+Meson build" job in GitHub Actions CI is consistently failing when this topic is applied, while builds without the series succeed. The failure appears to be related to the Rust components introduced in this series, though the exact cause isn't yet diagnosed.

The problem surfaces in the CI environment (https://github.com/git/git/actions/runs/19414557042/job/55540901761#step:6:848) but doesn't occur in builds without this topic (https://github.com/git/git/actions/runs/19418361570/job/55551045554). Junio notes this may require input from those familiar with both Rust and Windows environments to resolve.

This follows earlier CI issues with Clippy warnings that Junio had addressed, showing the maintainer's active involvement in shepherding this foundational Rust code through the CI pipeline. The Windows-specific build failure represents another hurdle in the series' path to acceptance, requiring platform-specific expertise to diagnose and fix. The core Rust implementation work remains sound, but these CI issues demonstrate the practical challenges of introducing Rust into Git's cross-platform build system.
