Bugfix for memory corruption in Windows credential helper. This patch fixes an issue in the wincred credential helper where `wcsncpy_s()` was being called without allocating space for the terminating null character, which could lead to crashes when reading passwords. The fix adds the necessary space allocation (`+ sizeof(WCHAR)`).

The issue manifested as Git repeatedly asking for passwords since the corrupted memory prevented successful credential reading. The patch is small (1-line change) but important for correct operation on Windows. It's co-authored by David Macek and Johannes Schindelin, suggesting it has been reviewed by a Windows Git expert.

Key technical details for future reference:
- File modified: `contrib/credential/wincred/git-credential-wincred.c`
- Function affected: `get_credential()`
- Specific fix: Added `+ sizeof(WCHAR)` to `xmalloc()` call for secret buffer
- Windows API involved: `wcsncpy_s()` which requires space for null terminator
- Impact: Prevents crashes when reading credentials and stops repeated password prompts

The fix appears straightforward and correct, addressing a clear memory safety issue in Windows-specific credential handling code.
