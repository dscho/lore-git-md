This is a follow-up clarification in the Git for Windows GUI credential helpers series. Johannes Schindelin responds to Johannes Sixt's earlier question about why the patch used `gitexec` instead of `file join` for path resolution in the GIT_ASKPASS setup code. 

Schindelin explains this was a historical artifact from the msysGit days (dating back to 2010) when surrounding code used `gitexec`. He notes the inconsistency was already corrected in Git for Windows' version of this code in August 2025, and confirms Sixt made the same correction when applying the patch to mainline Git. 

This email resolves one of the open questions from the thread summary - the path resolution style question is now answered, confirming `file join` is indeed the correct approach. The exchange demonstrates careful attention to historical context and cross-platform compatibility considerations in the git-gui codebase.
