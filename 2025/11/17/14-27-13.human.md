This is a discussion about identity management in Git commits, continuing the thread about ZheNing Hu's proposed `--committer` option. Phillip Wood responds to Matej Dujava's workflow examples, agreeing that `includeIf` config patterns are a common solution for managing multiple identities when repositories are organized by directory structure.

The key point Phillip raises is questioning the need for a `--committer` option when the committer identity is automatically corrected from the config during amend operations. This reinforces the maintainer's earlier position that the proposed feature may be solving a non-issue, as the existing tools (when used properly) already handle identity correction effectively.
