This is the v4 patch series for the `git-repo-info` feature, addressing review feedback from v3. The series consists of two patches: a refactoring of field printing logic and the implementation of the `--all` flag.

The first patch has been updated to use Junio C Hamano's suggested optimization of outputting `quote_c_style()` directly to stdout rather than using intermediate `strbuf` allocations. This change simplifies the code while maintaining the same functionality. The patch also replaces a copied struct with a pointer for better performance.

The second patch implements the `--all` flag as previously discussed, allowing users to print all repository information fields at once. It includes the requested documentation updates and error handling for invalid combinations of `--all` with specific keys. The implementation now uses const pointers for the field iteration rather than copying structs.

Key technical details:
- Removes `strbuf quotebuf` in favor of direct `quote_c_style()` output
- Changes `print_field()` to take a string `value` instead of `strbuf`
- Replaces struct copy with pointer in `print_all_fields()`
- Updates help text to clarify `--all` behavior
- Maintains existing output formats (`keyvalue` and `nul`)
- Keeps comprehensive test coverage

The changes are focused on implementation quality improvements based on Eric Sunshine's feedback, while maintaining the established interface design. The series appears ready for final review, with all major technical concerns from v3 addressed.
