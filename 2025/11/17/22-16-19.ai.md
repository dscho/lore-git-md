This is patch 13/15 in the SHA-1/SHA-256 interoperability series, implementing a new binary object map format in Rust. The patch introduces a key component for the series' goal by providing efficient storage and lookup of object mappings between hash algorithms.

The new binary format resembles pack index v3 and addresses several limitations of the current loose object format. It provides:
- Efficient sorted storage of object IDs for quick lookup across algorithms
- Support for non-packed objects like shallow entries and submodules
- Metadata to identify object types (loose, shallow, submodule) for proper pruning
- Batched writing capability for performance

The implementation includes:
- A memory-mapped reader (`MmapedObjectMap`) with binary search capabilities
- An in-memory map (`ObjectMemoryMap`) with batch writing support
- Comprehensive tests for round-tripping and cross-algorithm lookups
- Documentation of the new file format in gitformat-loose.adoc

The design defers some file handling responsibilities to future C code, focusing instead on the core mapping logic. The patch builds on previous work in the series by using the established Rust infrastructure for hash algorithms and object IDs.
