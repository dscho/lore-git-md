This is the first of two patches in a series that adds diff algorithm configurability to `git blame`. The patch refactors xdiff internals to properly handle the 'minimal' diff algorithm flag within the existing algorithm selection mechanism.

The change makes XDF_NEED_MINIMAL part of the XDF_DIFF_ALGORITHM_MASK bitmask, which fixes an inconsistency where resetting the diff algorithm to default required separate clearing of the minimal diff bit. This cleans up the implementation by removing redundant explicit clearing of NEED_MINIMAL from diff.c and merge-ort.c.

The patch is part of a well-reviewed series that has gone through multiple iterations (now at v6) with all technical feedback addressed. It provides the foundation for the second patch which will expose this functionality to users through `git blame --diff-algorithm`. The changes are focused and mechanical, touching only three files with straightforward modifications.

This refactoring enables a cleaner implementation of diff algorithm selection in blame while maintaining backward compatibility. The series as a whole has received maintainer approval and appears ready for merging.
