This is the second patch in a 3-part series introducing signature verification for `git fast-import`. It's a refactoring that extracts commit signature verification logic to work with raw buffers rather than requiring a full commit object.

The patch moves the core verification code from `check_commit_signature()` into a new `verify_commit_buffer()` function, which operates directly on commit buffers. The original function becomes a thin wrapper that gets the buffer and passes it along. This prepares for the series' goal of validating signatures during fast-import without the overhead of creating commit objects that might be discarded.

The change is mechanical and well-contained, touching only `commit.c` and `commit.h`. It maintains all current behavior while enabling the buffer-based verification needed for the upcoming fast-import changes. The commit message clearly explains the motivation and approach, and the implementation looks straightforward with no obvious issues.
