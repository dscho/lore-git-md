Feature patch finalizing diff algorithm configurability for `git blame`. This is the second and final part of a two-patch series that has undergone extensive review and is now ready for merging.

The patch makes `git blame` respect both the `--diff-algorithm` command-line option and `diff.algorithm` configuration, matching the behavior already available in `git diff`. The default remains Myers diff, but users can now explicitly select between Myers, minimal, patience, and histogram algorithms. The implementation includes comprehensive tests verifying:
- Default behavior
- CLI/config precedence
- Option ordering effects
- Cross-algorithm comparisons
- Edge case coverage

The patch builds on foundational xdiff refactoring from part 1 of the series (already reviewed) and represents the culmination of a long-standing effort to make diff algorithm selection consistently available across Git commands. Documentation is shared with `git diff` via a new include file. The implementation is clean, with special attention given to maintaining backward compatibility with the existing `--minimal` option (now marked as hidden).

This well-tested and thoroughly reviewed change addresses all feedback from multiple rounds of review, including final style nits in this v6. It provides a solid foundation for any future default algorithm changes while giving users immediate control over blame's diff behavior.
