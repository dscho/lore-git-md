CI infrastructure update regarding macOS Perforce test reliability.

Junio Hamano confirms the resolution to use Perforce r23.2's native arm64 binaries (bin.macosx12arm64) for macOS CI testing, after Koji Nakamaru verified they work correctly without Rosetta emulation. This follows earlier confusion where Nakamaru initially couldn't find the arm64 binaries in r23.2 and proposed moving to r24.2, but now confirms the binaries do exist in r23.2 and function properly.

The discussion has narrowed to this simple solution - a 4-line change in ci/install-dependencies.sh to use the existing r23.2 binaries - rather than evaluating x86_64 runners or newer Perforce versions. This maintains compatibility with both macOS arm64) and Linux (x86_64) platforms while avoiding the performance overhead of Rosetta emulation.

The thread's original sudo issue was previously resolved separately, and this Perforce solution appears ready for implementation pending final confirmation from Junio. The straightforward nature of using the verified r23.2 binaries suggests this longstanding CI reliability issue may soon be closed.
