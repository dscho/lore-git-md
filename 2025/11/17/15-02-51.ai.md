This is a refactoring patch in the `git-repo-info` series, now at v4. The patch factors out field printing logic into a dedicated `print_field()` function, addressing previous review feedback about optimization and code structure.

The key changes in this version:
- Implements direct output to stdout via `quote_c_style()` as suggested by Junio C Hamano, eliminating the intermediate `strbuf` allocation
- Takes string values directly rather than requiring a `strbuf`
- Maintains the same output behavior for both key-value and NUL-terminated formats
- Removes now-unnecessary `quotbuf` variable and resets

The refactoring improves performance by reducing memory allocations and copies while keeping the same external behavior. This appears to be the final iteration of this particular optimization, having incorporated all requested changes from reviewers.
