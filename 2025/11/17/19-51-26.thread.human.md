The modification appears motivated by Windows/MSYS2 compatibility work and doesn't affect Git's runtime behavior - it ensures the `scalar` binary gets stripped of debug symbols like other Git programs during the build process. The change is well-justified and uncontroversial, aligning with the original Scalar commit 7b5c93c6c68.
