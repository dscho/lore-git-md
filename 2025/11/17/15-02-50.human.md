This is the fourth version of a feature patch series adding `--all` support to the experimental `git-repo-info` command, part of Lucas Seiki Oshiro's GSoC project. The series has two patches: a refactoring of field printing and the actual `--all` implementation.

The key changes in v4 address Eric Sunshine's feedback on v3 by:
1. Removing unnecessary `strbuf` allocations in favor of direct `quote_c_style()` output to stdout
2. Using a pointer to access field info rather than copying structs
3. Updating the help text to be more precise

The first patch's optimization approach (using `quote_c_style()` directly) was previously agreed upon as superior by both Junio C Hamano and Eric Sunshine. The second patch implements the `--all` flag to show all repository info fields, maintaining the existing output formats while adding error handling for invalid combinations.

The changes look clean and focused, with the author responding directly to the specific technical feedback from the previous round. The patch series appears ready for final review, having addressed all outstanding implementation concerns while maintaining the thread's consensus on interface design and optimization approach.
