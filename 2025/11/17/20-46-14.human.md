This is a platform compatibility patch targeting Windows (mingw) builds. Johannes Schindelin addresses a compiler warning from clang about the use of the comma operator in several error-handling paths within `compat/mingw.c`. The warning appears in CI workflow runs for Git for Windows' ARM64 builds.

The patch replaces instances of the pattern `return errno = ENOSYS, -1;` with more conventional two-statement blocks that first set `errno` and then return the error value. This change affects error handling in functions like `mingw_open_append()`, `start_timer_thread()`, `setitimer()`, and `sigaction()`. While functionally equivalent, the new form is more readable and avoids the clang warning.

The change appears straightforward and well-contained, with no behavioral impact beyond silencing the compiler warning. The commit message clearly explains the motivation and includes a link to a failing CI run for context. This seems like a low-risk maintenance improvement for Windows compatibility.
