This is the first patch in a two-part series introducing diff algorithm configurability for `git blame`. The patch refactors xdiff internals to cleanly support algorithm selection.

The technical change adds `XDF_NEED_MINIMAL` to the `XDF_DIFF_ALGORITHM_MASK` bitmask in xdiff.h, fixing an inconsistency where resetting the diff algorithm to default required separate clearing of the minimal diff bit. The patch removes now-redundant explicit clearing of `NEED_MINIMAL` from diff.c and merge-ort.c, and restores some "clear out previous settings" comments that were removed in earlier versions.

The changes affect xdiff's core diff algorithm handling, touching xdiff.h, diff.c, and merge-ort.c. Key technical points:
- Makes `DIFF_XDL_CLR` macro effectively obsolete while maintaining behavior
- Ensures consistent algorithm reset behavior across all callers
- Addresses missed cases in merge-ort.c and builtin/merge-file.c from earlier versions
- Part of enabling clean algorithm selection implementation for the blame feature in patch 2/2

This foundational change has been thoroughly reviewed through multiple iterations (now at v6) with all feedback addressed, including final style fixes. The patch is approved and ready for merge as part of the complete series.
