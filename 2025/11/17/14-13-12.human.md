Feature patch series final approval for configurable diff algorithms in `git blame`.

This is the final approval email for Antonin Delpeuch's series that adds diff algorithm configurability to `git blame`. The series has gone through six iterations with thorough review from Phillip Wood and Junio C Hamano, addressing all technical feedback and style nits. The v6 changes are minor - restoring some clarifying comments and fixing whitespace in test script redirections.

The core changes enable `git blame` to use the same diff algorithms (`myers`, `minimal`, `patience`, `histogram`) as `git diff`, controlled via both command-line (`--diff-algorithm`) and config (`diff.algorithm`). The implementation includes comprehensive tests showing how different algorithms produce different blame attributions, with careful attention to CLI/config precedence and backward compatibility.

Phillip Wood gives the final sign-off, noting this is "a nice addition" to Git's functionality. With all review feedback addressed and maintainer approval secured, this well-tested series is now ready for merging into the main Git codebase. The changes cleanly integrate with existing diff infrastructure while providing users more control over blame attribution behavior.
