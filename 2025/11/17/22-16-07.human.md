This is the first patch in a 15-part series introducing Rust infrastructure for SHA-1/SHA-256 interoperability. The patch makes Rust a hard requirement for the compatibility hash algorithm feature, which will soon be implemented in Rust rather than C.

The change modifies `repo_set_compat_hash_algo()` to error out if Rust support isn't available, marking this as a deliberate regression since the current implementation is already broken and marked experimental. The patch updates several test scripts to conditionally run compatibility-related tests only when Rust is available, introducing a new `RUST` test prerequisite.

While this technically removes functionality from non-Rust builds, the author argues this is acceptable since the feature is already non-functional in practice. The patch appears well-scoped, focusing just on the Rust requirement while leaving the actual Rust implementation for later patches in the series. Test coverage is thorough, with all compatibility-related tests now properly gated behind the Rust prerequisite.

This sets the stage for the Rust implementation that follows in subsequent patches, establishing the build and test infrastructure needed for Git's first major Rust component.
