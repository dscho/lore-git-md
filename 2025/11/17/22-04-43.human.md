Build system patch expanding the `strip` target cleanup, with discussion of Makefile structure.

Junio Hamano responds to Johannes Schindelin's simple patch that added Scalar to the `make strip` target. While agreeing with the basic premise, Junio suggests a more comprehensive Makefile improvement - replacing the explicit `git$X` reference with `$(OTHER_PROGRAMS)` and introducing a new `OTHER_ARTIFACTS` variable to properly separate DLL handling from program stripping.

The response raises two key points: first, that the current Makefile structure mixes concerns by using `OTHER_PROGRAMS` for both stripping and DLL inclusion, and second, that similar changes might be needed in CMake and meson build systems. Junio provides a more extensive proposed diff that would restructure these Makefile targets while still achieving the original goal of including Scalar in the strip operation.

This appears to be shifting from a straightforward one-line fix to a more substantial build system cleanup, though the same core functionality would be preserved. The discussion suggests this might warrant a v2 submission with the expanded changeset.
