This is a build system fix addressing a CMake regression after recent Makefile changes. 

The patch updates the CMake build configuration to match recent Makefile changes where the reftable and xdiff libraries were merged into libgit. The CMake build was still trying to build these as separate libraries, causing configuration errors. Johannes Schindelin provides the straightforward fix by removing the now-unneeded library definitions and adjusting the linking accordingly.

The change is motivated by keeping the CMake build working, particularly for Git for Windows CI builds. The commit message notes some concern about the sustainability of maintaining both CMake and Meson builds for Windows, though this patch itself is a simple alignment with the new single-library approach.

The patch is small (14 lines removed, 1 line changed) and clearly correct - it simply removes now-obsolete CMake logic that became redundant after the library consolidation. This appears to be a straightforward maintenance fix with no obvious controversy.
