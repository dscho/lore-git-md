This is a refactoring patch that simplifies the `xmkstemp()` wrapper function in wrapper.c. 

René Scharfe proposes replacing the current implementation of `xmkstemp()` with a call to the existing `xmkstemp_mode()` function, passing 0600 as the default permissions. The current version has its own error handling code that duplicates what `xmkstemp_mode()` already does, including path handling and error reporting.

The change reduces the code by 18 lines while maintaining identical functionality, since `git_mkstemp_mode()` (which `xmkstemp_mode()` calls internally) is known to work reliably. This is a straightforward cleanup that removes duplicate code without any behavior changes.
