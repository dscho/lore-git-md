This is part of the SHA-1/SHA-256 interoperability work, introducing a new binary object map format in Rust. It's patch 13/15 in the v2 series that brings Rust infrastructure to Git's object storage.

The patch adds a binary object map format to efficiently store mappings between SHA-1 and SHA-256 object IDs for loose objects and special cases like shallow entries and submodules. The format resembles pack index v3 and includes:
- A header with signature, version, and format identifiers
- Sorted tables of shortened and full object names
- Metadata indicating object types (loose, shallow, submodule)
- Support for batched writing operations

The implementation provides both in-memory and mmap-based access to the object mappings, with comprehensive tests for round-tripping data between formats. The design avoids duplicating object IDs by storing them once and using indices for cross-referencing between hash algorithms.

This is a key piece of infrastructure for the broader interoperability work, enabling efficient lookup and conversion between hash algorithms while maintaining proper object type information. The Rust implementation appears thorough, with good test coverage of the binary format and lookup operations.
