This is part of the SHA-1/SHA-256 interoperability work introducing Rust code to Git, specifically adding infrastructure piece for file handling.

Patch 14/15 in the series introduces a Rust wrapper around Git's `hashfile` functionality, which provides a way to write files with trailing hashes. The wrapper implements Rust's `Write` trait, allowing the new binary object map code (from patch 13) to write to files while maintaining the same testability benefits of working with in-memory buffers. The implementation handles chunked writes and provides proper finalization with hash computation.

The patch is straightforward and well-contained, adding about 80 lines of Rust code that bridges between Git's C `hashfile` functions and Rust's I/O traits. It follows the pattern established earlier in the series of creating safe wrappers around C functionality. The implementation appears solid, with proper error handling and memory safety considerations. This is a supporting piece for the larger object map functionality rather than a user-facing change.
