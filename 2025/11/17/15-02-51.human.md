This is a refactoring patch from the `git-repo-info` series, which is part of a GSoC project. The patch factors out field printing logic into a dedicated `print_field()` function, addressing previous review feedback about optimization and code structure.

The changes eliminate redundant `strbuf` allocations by directly outputting quoted values to stdout using `quote_c_style()`, as suggested by Junio C Hamano. The patch also removes the intermediate `quotbuf` that was previously used for quoting. These changes make the code both simpler and more efficient while maintaining the same output behavior.

This is the first of two patches in v4 of the series, which has already incorporated all major review feedback from previous iterations. The refactoring here provides a cleaner foundation for the second patch that adds the `--all` flag functionality. The changes are straightforward and well-contained, with no apparent downsides or controversial aspects.
