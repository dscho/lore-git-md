Documentation patch improving cross-references in `git-commit` manpage. Junio Hamano has reviewed Kristoffer Haugsbakk's patch that adds proper links to `git-status(1)` for various format options in the `--dry-run` section of the commit documentation.

The patch standardizes references to status formats by:
- Adding a `git-status(1)` link for the `--branch` option to match existing `--short` documentation
- Explicitly stating that `--long` format matches `git-status`'s default output
- Replacing a bare "status" mention with a proper `linkgit` reference for `--null`

Junio notes that since `commit --dry-run` and `status` share internals, these cross-references make sense, and is marking the patch for inclusion in the 'next' branch. The changes are purely documentation improvements with no behavioral impact, addressing historical inconsistencies in how these options were documented.
