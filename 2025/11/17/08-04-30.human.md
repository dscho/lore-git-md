Feature patch series finalizing diff algorithm configurability for `git blame`. This is version 6 of the series, which has already received extensive review and is now addressing final minor style fixes before merging.

The two-patch series allows `git blame` to use different diff algorithms (Myers, minimal, patience, histogram) via both a new `--diff-algorithm` option and the existing `diff.algorithm` config. The first patch refactors xdiff internals to cleanly support algorithm selection, while the second implements the user-facing blame functionality.

Changes in v6 are minimal polish items requested after the v5 review:
- Restored "clear out previous settings" comments that were accidentally dropped
- Fixed whitespace in bash redirection operators in the test script

The series has already received final approval from both Phillip Wood and Junio C Hamano, with all substantive technical issues resolved. The implementation includes comprehensive test coverage and proper documentation sharing with other diff-algorithm documentation. The xdiff changes make the DIFF_XDL_CLR macro obsolete while maintaining correct behavior, and the blame feature provides clean algorithm selection with config/CLI precedence matching `git diff`.

This appears ready for merging with no outstanding technical concerns - the final version just cleans up some minor style nits that were caught in review. The feature will give users more control over blame's diff algorithm choice, matching the flexibility already available in other Git commands.
