This is a CI/build system update for the Git localization workflow, specifically a version bump of the `actions/setup-go` GitHub Action from v5 to v6. The change was originally proposed by dependabot and is being forwarded by Johannes Schindelin, who is now following up with Jiang Xin (the Git l10n maintainer) for review.

The update includes breaking changes in the GitHub Action, notably improved toolchain handling and a Node.js runtime upgrade from node20 to node24. The patch is straightforward - a one-line change to the workflow file - but requires runners to be updated to v2.327.1 or later for compatibility.

This appears to be routine maintenance to keep dependencies current, with the change having already been applied in git-for-windows and git-po repositories. The patch is currently blocked awaiting review from the l10n maintainer.
