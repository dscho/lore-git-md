Bugfix patch in the SHA-1/SHA-256 interoperability series, addressing a NULL pointer crash case. This is patch 2/15 in the v2 series introducing Rust infrastructure for hash algorithm compatibility.

The change fixes a crash scenario when converting object IDs between hash algorithms in repositories without a compatibility algorithm set. Currently, if no destination algorithm (`to`) is specified, the code would dereference NULL when comparing algorithms. The patch makes this case a no-op that safely copies the source object ID when needed.

Key technical details:
- Modifies `repo_oid_to_algop()` in `object-file-convert.c`
- Adds `!to` check alongside existing algorithm comparison
- Maintains same behavior of copying source to destination when algorithms match
- Simple one-line change with clear safety implications
