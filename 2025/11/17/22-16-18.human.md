This is part of the ongoing SHA-1/SHA-256 interoperability work introducing Rust code to Git's core. Patch 12/15 adds cryptographic hashing capabilities to the Rust infrastructure, building on previous FFI work to bridge Git's C hashing functions.

The patch introduces a `CryptoHasher` struct that provides safe Rust wrappers around Git's existing hash implementations (SHA-1 and SHA-256). The implementation includes proper memory management via `Clone` and `Drop` traits, and implements the standard `Write` trait for easy use with Rust's I/O patterns. The hasher can produce both `ObjectID` structs (for Git's object model) and raw byte vectors.

The code includes comprehensive tests verifying correct behavior for both blob and tree object hashing, including incremental updates and clone operations. The implementation appears carefully designed to maintain safety when working with untrusted data, particularly noting the collision-detection capabilities when using SHA-1.

This is a key building block for the object map functionality that will follow in later patches, providing the core hashing operations needed to implement the new loose object format. The patch fits cleanly into the series' progression, leveraging the FFI infrastructure established in earlier patches while adding new capabilities needed for the object storage work.
