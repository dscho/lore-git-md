This is a follow-up to a completed bugfix series that addressed an inconsistency in Git's global config file handling. Johannes Schindelin confirms his Reviewed-by tags still stand for the four-patch series that ensures `git config list --global` properly shows both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config` when they exist.

The series had already gone through review and testing, with Johannes providing platform-specific verification throughout. His note suggests the patches are technically ready but may be stalled in the integration queue. The changes align Git's behavior with documented functionality while maintaining backward compatibility, with all identified edge cases (like handling unreadable config files) properly addressed in the final version.
