Platform compatibility patch addressing clang warnings about comma operator usage in Windows-specific code. The patch modifies error-handling patterns in `compat/mingw.c` where the comma operator was used to both set `errno` and return an error value in a single statement. Each instance is rewritten to separate the `errno` assignment from the return statement, maintaining identical behavior while satisfying modern compiler warnings.

Changes affect Windows-specific functions handling file operations (`mingw_open_append`), timer management (`start_timer_thread`, `setitimer`), and signal handling (`sigaction`). The modifications are purely syntactic with no functional changes, responding to clang's `-Wcomma` warning triggered in CI for the Git for Windows SDK ARM64 build. Error codes involved include ENOSYS, ENOMEM, and EINVAL.
