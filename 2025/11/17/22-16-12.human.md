This is part of the ongoing SHA-1/SHA-256 interoperability work introducing Rust infrastructure to Git. The patch adds FFI (Foreign Function Interface) glue between Rust and C for hash algorithm handling.

Patch 6/15 in the series introduces a new helper function `hash_algo_ptr_by_number()` that allows Rust code to get a pointer to C's `git_hash_algo` structure when given a hash algorithm identifier. This bridges the gap between Rust's type-safe `HashAlgorithm` enum and C's array-based hash algorithm lookup system.

The change is straightforward - it's essentially plumbing to make the existing C functionality available to Rust code. The implementation includes:
1. A new C function that safely looks up hash algorithms by number
2. The corresponding Rust FFI declaration
3. A convenience method on the `HashAlgorithm` enum to get the C struct pointer

This is a technical but necessary piece of the larger Rust integration effort, enabling Rust code to interoperate with existing C functions that expect `git_hash_algo` pointers. The patch appears well-contained and follows the established pattern for FFI in this series.
