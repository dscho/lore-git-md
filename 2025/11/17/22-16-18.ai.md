This patch introduces Rust hashing functionality for Git objects, a key component in the SHA-1/SHA-256 interoperability work. It implements a `CryptoHasher` struct that provides safe FFI wrappers around Git's existing C hashing functions, with proper memory management via `Clone` and `Drop` implementations.

The patch adds:
1. A `CryptoDigest` trait defining core hashing operations (update, finalize to OID/bytes)
2. The `CryptoHasher` struct that implements this trait` using FFI calls to `git_hash_*` functions
3. `std::io::Write` implementation for easier integration with Rust's I/O ecosystem
4. Comprehensive tests verifying correct hashing of empty blob/tree objects
5. Convenience method `HashAlgorithm::hasher()` to create new hashers

Key technical details:
- Uses previously introduced FFI functions (`git_hash_alloc/free/init/clone/update/final/final_oid`)
- Maintains safety by requiring proper initialization and cleanup
- Supports incremental hashing via both direct `update()` calls and `Write` trait
- Validates against known empty tree/blob hashes
- Preserves the safety guarantees of Git's collision-resistant hashes

This builds on the series' prior work establishing FFI bridges and type safety, now providing the actual hashing operations needed for the object map implementation. The design appears robust with thorough test coverage of both the basic functionality and edge cases like incremental writes.
