This is Junio Hamano's regular "What's cooking in git.git" status update, covering recent developments in the Git project as of November 2025. The email provides a comprehensive overview of topics at various stages in the development pipeline, from newly proposed changes to those ready for the next release.

Several notable changes are highlighted:
- A fix for macOS CI jobs using arm64 Perforce binaries to address test failures
- A segfault fix in `git submodule add` when dealing with malformed .gitmodules entries
- Performance improvements in `git diff --quiet` by skipping rename detection
- A new `git maintenance is-needed` subcommand to check if maintenance tasks are required
- Support for configurable diff algorithms in `git blame`
- Ongoing work on SHA-1/SHA-256 interoperability with new Rust components
- Various documentation updates and code cleanups

The email also notes that Git 2.52 has been tagged as final, with the tree soon reopening for 2.53 development. Many topics are marked as cooking in 'next' (the integration branch for stable changes), while others are still in 'seen' (for experimental work) or awaiting rerolls based on feedback.
