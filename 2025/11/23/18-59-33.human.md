This is part 8 of Patrick Steinhardt's 19-patch series refactoring Git's object database streaming interface, continuing the work to create type-safe stream containers. Following the pattern established for in-core and loose object streams in previous patches, this one introduces a dedicated `struct odb_packed_read_stream` for packed object streams.

The patch moves the packed object stream implementation out of the union in `struct odb_read_stream` and into its own properly typed structure. This maintains consistency with the series' goal of type-safe stream handling while keeping the same functionality - the zlib inflation state remains in the base stream structure while packfile-specific data (the pack pointer and position) moves to the new container.

The changes are mechanical but important for the overall architecture, touching 75 lines in streaming.c with a net addition of 5 lines. This continues the series' progression toward pluggable backends with clear type boundaries, following the design decisions already established and reviewed in earlier patches.
