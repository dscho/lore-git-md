This is patch 15/19 in Patrick Steinhardt's ongoing series to refactor Git's object database streaming interface. The patch moves the implementation of loose object streaming from the generic streaming.c file into the object-file.c backend, making several related functions private in the process.

The change continues the series' architectural direction of moving backend-specific logic into their respective subsystems. Here, the loose object streaming code (previously in streaming.c) is relocated to object-file.c alongside other loose object handling code. The patch introduces a new public function `odb_source_loose_read_object_stream()` while making several supporting functions (`odb_source_loose_map_object`, `unpack_loose_header`, `parse_loose_header`) private to object-file.c.

The implementation remains functionally identical - this is purely an organizational change that better localizes the loose object handling code. The patch is mechanical and well-contained, touching 3 files with 164 lines added and 178 removed, mostly from moving code between files. It follows the series' pattern of incremental, clearly explained improvements to the ODB streaming architecture.
