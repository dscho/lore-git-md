This is part 9/19 of Patrick Steinhardt's object database streaming interface refactoring series, focusing on creating a type-safe container for filtered object streams. The patch continues the architectural direction established in previous patches (6/19 for in-core streams, 7/19 for loose objects, 8/19 for packed objects) by extracting filtered stream implementation details from the union in `struct odb_read_stream` into a dedicated `struct odb_filtered_read_stream`.

The key changes include:
1. Removing the old `struct filtered_istream` and its union member from `odb_read_stream`
2. Introducing new `struct odb_filtered_read_stream` containing all filter-specific state (upstream stream, filter object, input/output buffers, and buffer positions)
3. Updating the filter stream functions (`close_istream_filtered` and `read_istream_filtered`) to work with the new structure through type-safe casting
4. Modifying `attach_stream_filter` to allocate and initialize the new structure type

The implementation follows the same pattern seen in earlier patches, maintaining consistency with the series' goal of type-safe stream containers. The changes are focused on internal implementation details rather than user-visible behavior, with all functionality preserved through the type-safe interface. This continues the series' progression toward eliminating the union-based approach in favor of proper type hierarchy for different stream types.
