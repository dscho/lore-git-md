This is part 4 of Patrick Steinhardt's 19-patch series refactoring Git's object database streaming interface. The series is now fully merged, having completed its goal of simplifying and standardizing the streaming API.

This particular patch makes the packed object streaming interface more explicit by requiring callers to pass packfile information directly to `open_istream_pack_non_delta()` rather than having the function rely on pre-populated stream state. The change makes the calling convention clearer and prepares for future refactoring where the function will handle its own stream allocation.

The patch is a mechanical change that:
1. Adds new parameters to pass the packfile and offset directly
2. Moves the packfile assignment into the caller
3. Updates the single call site to use the new interface

This continues the series' pattern of making the streaming API more explicit and self-contained. The change is straightforward and builds on previous patches in the series that already simplified the initialization flow. Since the series has been fully reviewed and merged, this change represents an uncontroversial improvement that was accepted as part of the larger refactoring effort.
