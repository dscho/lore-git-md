This is patch 6/19 in Patrick Steinhardt's object database streaming interface refactoring series, focusing on type-safe stream implementations. The patch creates a dedicated structure for in-core object streams, continuing the architectural shift from a union-based approach to type-specific stream containers.

The change extracts the in-core stream implementation from the union in `struct odb_read_stream` into a new `struct odb_incore_read_stream` that contains the base stream structure plus in-core specific fields (`buf` and `read_ptr`). This enables type-safe casting between the generic interface and backend implementations, a key goal of the series. The patch updates all related functions (`close_istream_incore`, `read_istream_incore`, `open_istream_incore`) to work with the new structure.

The implementation follows the pattern established in earlier patches, maintaining the same functionality while improving type safety. The changes are mechanical but important for the series' goal of enabling pluggable backends with custom streaming implementations. This continues the progression from patch 5/19's backend-specific stream allocation by providing the concrete type-safe container for in-core streams.

The patch touches only streaming.c, modifying 44 lines (25 insertions, 19 deletions) to implement the new structure. It builds on the foundation laid in previous patches and maintains consistency with the series' established patterns for stream initialization and operation.
