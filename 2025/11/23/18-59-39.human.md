This is part 14/19 of Patrick Steinhardt's series refactoring Git's object database streaming interface, continuing the work to make the streaming subsystem more modular and remove global state dependencies.

The patch makes the `odb_read_stream` structure definition public by moving it from streaming.c to streaming.h. This is preparation for upcoming changes where backend subsystems will need to allocate these streams themselves. The structure remains essentially the same - containing function pointers for close/read operations plus object type and size fields - but is now exposed to allow backend implementations to create instances directly.

The change is mechanical (11 lines removed from .c file, 15 added to .h) and follows logically from earlier patches that containerized the various stream types. It's a straightforward but necessary step in the architectural direction of the series, enabling backend subsystems to take more ownership of stream creation while maintaining the unified streaming interface.
