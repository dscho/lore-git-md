This is patch 10/19 in Patrick Steinhardt's object database streaming interface refactoring series, focusing on zlib stream isolation. The patch moves the shared zlib stream state from the base `odb_read_stream` structure into backend-specific structures for loose` and `packed` object streams, completing the backend isolation work started in earlier patches.

The changes introduce new zlib-related fields in both `odb_loose_read_stream` and `odb_packed_read_stream` structures, along with backend-specific state enums (`ODB_LOOSE_READ_STREAM_*` and `ODB_PACKED_READ_STREAM_*`). The patch removes the common `close_deflated_stream()` helper since zlib state management is now handled within each backend's close function. All zlib operations are updated to use the backend-specific stream rather than the base stream's zlib state.

This continues the series' architectural direction of fully separating backend implementations while maintaining the common streaming interface. The changes touch 104 lines in streaming.c (52 additions, 52 deletions), primarily mechanical updates to reference the new backend-specific zlib states rather than the shared base stream state. The patch maintains all existing functionality while further reducing coupling between different object storage formats.
