This is part of Patrick Steinhardt's ongoing object database streaming interface refactoring series (14/19), continuing the work to make the streaming subsystem more modular and type-safe. The commit message explains this clearly - backends will now be responsible for allocating streams and thus need visibility into the structure they're allocating.

The structure itself remains identical, just made accessible to other compilation units. This continues the series' pattern of incremental, well-explained changes that improve API boundaries while maintaining functionality.
