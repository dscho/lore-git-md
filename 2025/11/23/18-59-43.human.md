This is patch 18/19 in Patrick Steinhardt's series refactoring Git's object database streaming interface. The patch moves the streaming implementation files (`streaming.{c,h}`) into a new `odb/` subdirectory to better reflect their role in the object database subsystem.

The change is straightforward but important for codebase organization - it makes it immediately clear these files are part of the ODB implementation rather than generic streaming utilities. The patch updates all include paths across 15 files (archive, builtins, object-file, packfile, etc.) to point to the new location. The actual functionality remains unchanged.

This is the final step in the series' architectural reorganization before the last patch. The previous patches (1-17) already did the heavy lifting of:
- Standardizing the API naming (`odb_read_stream_*`)
- Moving implementations to backend-specific files
- Removing global state
- Adding comprehensive documentation

This patch completes the physical reorganization by placing the streaming code in its logical home alongside other ODB components. The change is mechanical but helps future developers navigate the codebase more intuitively.
