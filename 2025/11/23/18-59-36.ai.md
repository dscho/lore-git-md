This is patch 11/19 in Patrick Steinhardt's object database streaming interface refactoring series, focusing on packfile functionality. Key changes include:
- Moving packed object info handling from odb.c to packfile.c via the new function
- Making `find_pack_entry()` static since it's now only used internally
- Reordering `packfile_store_freshen_object()` to maintain compilation order
- Adding the new public interface to packfile.h with documentation

The patch continues the series' architectural direction of separating concerns between the object database and packfile implementations. By moving this logic to packfile store operations, it further decouples the ODB interface from packfile internals while maintaining the same functionality. The changes are mechanical rather than behavioral, with 69 lines added and 43 removed across odb.c, packfile.c and packfile.h.

This refactoring prepares for subsequent changes in the series by establishing cleaner boundaries between subsystems. The patch follows the established pattern of the series by maintaining all existing behavior while improving code organization.
