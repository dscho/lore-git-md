This is a refactoring patch in Patrick Steinhardt's object database streaming interface series, specifically moving the streaming code into the odb/ subdirectory. 

The patch relocates streaming.{c,h} to odb/streaming.{c,h} to better reflect that this code is specific to the object database subsystem. The change is mechanical, updating include paths in 15 files across the codebase that reference these headers. The Makefile and meson.build files are updated to reflect the new location.

Junio C Hamano reviews the change and approves it with "Looking good", noting he has no objection to the move. This was patch 18/19 in the completed series that reorganized ~1500 lines of code into the odb/ location as part of establishing clearer ODB subsystem boundaries. The change is purely organizational - no functionality is altered, just the physical location and include paths of the streaming interface files.

This completes one of the final steps in the series' goal of better encapsulation and explicit dependencies for the ODB streaming code. The patch follows the series' progression of establishing consistent nomenclature, simplifying control flow, and centralizing type handling before this final reorganization.
