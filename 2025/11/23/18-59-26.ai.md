This is the first patch in Patrick Steinhardt's 19-part series refactoring Git's object database streaming interface. The patch renames the core streaming structure from `git_istream` to `odb_read_stream` to better reflect its role in the object database subsystem and to mirror the existing `odb_write_stream` naming. This is a straightforward mechanical change that updates the type name across 7 files (archive-tar.c, archive-zip.c, builtin/index-pack.c, builtin/pack-objects.c, object-file.c, streaming.c, and streaming.h), totaling 43 lines added and 43 removed.

The change is part of a larger effort to make the streaming interface more generic and backend-controlled, with the structure eventually being fully moved into the object database subsystem. The patch maintains all existing functionality while establishing consistent naming that will be used throughout the rest of the series. The commit message clearly explains the motivation and connects this change to the broader architectural goals of the patch series.

Key technical details for future reference:
- Structure renamed from `git_istream` to `odb_read_stream`
- All related function signatures updated (open_istream_fn, close_istream_fn, read_istream_fn)
- Maintains exact same behavior and interface, just with new type names
- Prepares for subsequent patches that will move this into odb/ subsystem
- Follows existing pattern of `odb_write_stream` naming
