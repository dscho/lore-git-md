Refactoring patch in Patrick Steinhardt's object database interface series, focusing on type propagation in streaming. This is patch 3/19 in the v3 series that restructures Git's object streaming internals.

The patch simplifies how object types are handled when opening read streams. Previously, the type was passed down through multiple levels via a pointer, with some redundant lookups. The change moves the type into the stream structure itself (alongside the existing size field) and makes format-specific callbacks solely responsible for setting it. This eliminates confusing pointer propagation and prepares for removing an extra object info lookup in a future patch.

The changes are mechanical but meaningful - 30 lines modified across streaming.c, mostly removing type parameters from callback signatures and adding the new stream field. This continues the series' trend of cleaning up the streaming interface's internals while maintaining the same external behavior. The patch fits logically after the earlier deferred opening removal (2/19) and before the actual lookup elimination (coming later in the series).
