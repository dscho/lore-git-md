This is part 7/19 of Patrick Steinhardt's object database streaming interface refactoring series, focusing on creating type-safe structure for loose object streams. The patch extracts the loose object stream implementation from the union in `struct odb_read_stream` into a new dedicated `struct odb_loose_read_stream`.

The change continues the series' progression toward type-safe stream containers, following the pattern established in patch 6/19 for in-core streams. The implementation moves all loose-stream-specific fields (memory mapping details, header buffers) into the new structure while maintaining the same functionality. The patch is mechanical but important for the overall goal of making the streaming interface more maintainable and type-safe.

The changes are straightforward - mostly moving code and adjusting access patterns from the union to the new structure. The patch follows the established pattern from earlier in the series and doesn't introduce any new concepts or behaviors. It's a clean, focused change that advances the series' architectural goals.
