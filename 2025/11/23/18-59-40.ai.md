This is part 15/19 of Patrick Steinhardt's object database streaming interface refactoring series, focusing on moving loose object stream logic into the backend subsystem. The patch relocates the implementation of loose object streaming from streaming.c to object-file.c, making several previously public functions private in the process.

Key technical changes:
- Moves the `odb_loose_read_stream` structure and its associated functions (`read_istream_loose`, `close_istream_loose`) from streaming.c to object-file.c
- Introduces a new public interface `odb_source_loose_read_object_stream()` in object-file.h to replace the old `open_istream_loose()`
- Makes several helper methods private that were previously exposed in object-file.h:
  - `odb_source_loose_map_object()`
  - `unpack_loose_header()` and its result enum
  - `parse_loose_header()`
- Updates the loose object streaming implementation to use the new type-safe `odb_read_stream` interface established in earlier patches
- Modifies the main streaming interface in streaming.c to use the new backend function rather than its internal implementation

The changes maintain all existing functionality while better encapsulating the loose object implementation details within the object-file subsystem. This continues the series' pattern of moving backend-specific code out of the generic streaming interface and into their respective subsystems, with the streaming layer acting as a thin coordinator.

The patch touches 3 files with 164 lines added and 178 removed, primarily moving code between files rather than introducing new logic. It builds on the architectural foundation established in previous patches, particularly the type-safe stream containers (patch 7/19) and public stream interface (patch 14/19).
