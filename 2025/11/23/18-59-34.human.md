This is part 9/19 of Patrick Steinhardt's ongoing refactoring series to improve the object database streaming interface. The patch builds on the type-safe container pattern established in previous patches (6-8/19) by creating a dedicated `struct odb_filtered_read_stream` for filtered object streams.

The change moves the filtered stream implementation out of the union in `struct odb_read_stream` and into its own properly typed structure, following the same pattern used for in-core, loose, and packed streams in earlier patches. The key changes are:
- Removing the old `filtered_istream` structure from the union
- Introducing new `odb_filtered_read_stream` with proper type-safe casting
- Updating the filter attachment logic to use the new structure

The patch is a straightforward mechanical conversion that continues the series' architectural direction of replacing unions with type-safe containers. It touches only streaming.c, modifying 54 lines (25 added, 29 removed) to implement the new structure while maintaining identical functionality. The change appears well-contained and follows the established pattern from previous patches in the series.
