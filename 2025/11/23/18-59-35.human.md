This is part 10/19 of Patrick Steinhardt's refactoring series for Git's object database streaming interface, focusing on moving zlib stream state into backend-specific structures.

The patch completes the decoupling of streaming backends by moving zlib stream state (previously shared between loose and packed object handlers) into their respective backend structures. For loose objects, this means adding `git_zstream z` and a new state enum` to `struct odb_loose_read_stream`. Similarly for packed objects, the patch adds parallel fields to `struct odb_packed_read_stream`. The common `close_deflated_stream()` helper is removed since each backend now manages its own zlib state.

This change is the next step in the series' goal of fully isolating backend implementations from each other. The patch follows the established pattern from previous patches (6-9/19) that created type-safe containers for different stream types. The diff shows substantial but mechanical changes (52 lines added/removed) as zlib state management moves from the base stream structure to the backend-specific ones.

The change appears well-contained and consistent with the series' architectural direction. It doesn't introduce new functionality but furthers the goal of making each streaming backend self-contained, which should make the code easier to maintain and extend in the future.
