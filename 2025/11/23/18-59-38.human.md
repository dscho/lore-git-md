This is part 13 of Patrick Steinhardt's 19-part series refactoring Git's object database streaming interface, specifically targeting the removal of `the_repository` global usage.

The patch removes the last two remaining uses of `the_repository` in the streaming subsystem. The first case in `open_istream_pack_non_delta()` is straightforward since the function already receives the object database as input. The second case in `stream_blob_to_fd()` requires more work - the function is renamed to `odb_stream_blob_to_fd()` to better reflect its role in the object subsystem, and it now takes an explicit `object_database` parameter. This change ripples through several callers that need to pass `the_repository->objects`.

The patch continues the series' architectural improvements by further decoupling the streaming code from global state. The changes are mechanical but important for the overall goal of making the object database subsystem more modular and self-contained. All modifications appear straightforward and well-contained, with no behavioral changes beyond the intended removal of global state usage.
