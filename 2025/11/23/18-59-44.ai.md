This is the final patch in Patrick Steinhardt's 19-part series refactoring Git's object database streaming interface. The patch removes redundant type and size out-parameters from the streaming API now that this information is available directly in the `odb_read_stream` structure.

The change simplifies callers across several subsystems (archive-tar, archive-zip, index-pack, pack-objects, object-file) by eliminating the need to pass separate type/size pointers when opening a stream. Callers now access these values directly from the stream structure when needed. The patch updates all call sites to use the new simplified API while maintaining the same functionality.

Key technical changes include:
- Removing `type` and `size` parameters from `odb_read_stream_open()`
- Updating callers to read type/size from `st->type` and `st->size` instead
- Simplifying the streaming.h interface documentation to reflect the change
- Maintaining all existing behavior while reducing parameter passing

This concludes the series by cleaning up the last remaining redundancy in the streaming interface after the earlier architectural improvements. The change is low-risk since it builds on the type-safe stream containers and public structure definition introduced in previous patches.
