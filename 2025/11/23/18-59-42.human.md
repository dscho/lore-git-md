This is part of Patrick Steinhardt's ongoing refactoring of Git's object database streaming interface, specifically patch 17/19 in the series. The patch continues the architectural direction of making the streaming interface object-database-centric rather than repository-centric.

The key change here is renaming the core interface functions from `open_istream()`, `read_istream()`, and `close_istream()` to `odb_read_stream_open()`, `odb_read_stream_read()`, and `odb_read_stream_close()`. This reflects the shift from repository-based to ODB-based operations that has been progressing through the series. The patch updates all callers across the codebase to use the new names.

The changes are mechanical but widespread, touching archive operations, pack-objects, index-pack, and object-file handling. The functionality remains identical - this is purely an interface naming change to better reflect the underlying architecture. The patch maintains consistency with previous work in the series that moved streaming implementations into their proper backend locations (packfile.c and object-file.c).

This continues the series' trend of improving code organization and making dependencies more explicit. The new names clearly indicate these are ODB operations rather than generic repository operations, which helps with understanding the code's architecture at a glance. The patch is straightforward and well-contained, with no behavioral changes beyond the naming updates.
