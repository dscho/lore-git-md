Refactoring patch in Patrick Steinhardt's object database streaming interface series. This is patch 2/19 in the series, which has now been fully merged.

The patch removes an indirect callback mechanism in the streaming interface where an `open()` function pointer was stored in the stream structure but only used once during initialization. Junio Hamano questioned the motivation in the initial version, and Patrick clarifies here that the callback was unnecessary since it was only ever called once. The change simplifies the initialization flow by having `istream_source()` open streams directly rather than setting up a callback.

This is part of a larger architectural cleanup that moves the ODB streaming interface toward a more direct and explicit design. The series as a whole has been reviewed and merged, with this particular change being one of several steps to simplify and standardize the streaming interface. No outstanding issues remain with this was a straightforward cleanup that reviewers agreed improved the code structure.
