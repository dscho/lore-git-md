This is patch 4/19 in Patrick Steinhardt's object database streaming interface refactoring series, focusing on packed object handling. The patch modifies how packfile information is passed when streaming packed objects, making the interface more explicit and preparing for future changes.

The key change moves the responsibility for setting packfile details (the pack struct and object offset) from the caller (`istream_source`) into `open_istream_pack_non_delta()`. Previously, the caller would populate these fields in the stream structure before calling the open method, creating an implicit coupling between the two functions. The new version makes these parameters explicit in the function signature.

This refactoring serves two purposes: it makes the calling convention clearer (since the required parameters are now visible in the function signature), and it enables a subsequent patch to make `open_istream_pack_non_delta()` responsible for allocating the stream structure itself. The change maintains all existing functionality while improving the code organization.

The patch touches only streaming.c, modifying 20 lines (10 additions, 10 deletions) with straightforward mechanical changes to the function signature and call sites. This continues the series' progression toward cleaner ODB streaming interfaces, following the earlier patches that standardized naming and removed deferred opening mechanisms.
