This is patch 8/19 in Patrick Steinhardt's object database streaming interface refactoring series, continuing the type-safe containerization work. Following the pattern established for in-core and loose object streams in previous patches, this introduces a dedicated `struct odb_packed_read_stream` for packed object streams.

The patch moves packed object stream data (previously stored directly in the union within `struct odb_read_stream`) into the new container structure. Key changes include:
- New `struct odb_packed_read_stream` containing the base stream plus pack-specific fields (`pack` and `pos`)
- Updated stream functions (`read_istream_pack_non_delta`, `close_istream_pack_non_delta`) to use the container structure
- Modified `open_istream_pack_non_delta` to allocate and initialize the container instead of using the union

The changes maintain all existing functionality while improving type safety and preparing for future pluggable backends. This follows the architectural direction established earlier in the series, with Junio's input on naming and structure having been incorporated in prior patches. The patch touches only streaming.c, modifying 75 lines (40 additions, 35 deletions) to implement the container pattern consistently across all stream types.
