This is the final patch in Patrick Steinhardt's 19-part series refactoring Git's object database streaming interface. The series has systematically modernized and reorganized the streaming code, moving it to a centralized implementation to a properly encapsulated subsystem with type-safe interfaces.

This patch removes redundant type and size out-parameters from `odb_read_stream_open()`, since these values are now directly available in the public `odb_read_stream` structure that was exposed in earlier patches. The change affects several callers across archive-tar, archive-zip, index-pack, pack-objects, and object-file code, all of which are updated to read the values from the stream structure instead.

The patch is a clean-up that follows naturally from the architectural changes made earlier in the series. It simplifies the API by eliminating parameters that are now redundant, while maintaining all existing functionality. The changes are mechanical and straightforward, with each caller being updated to access the stream's type and size fields directly.

This concludes the series' technical work, having achieved its goals of modernizing the streaming interface, properly encapsulating implementation details, and organizing the code into logical subsystems. The changes have been carefully reviewed throughout the series, with maintainer feedback incorporated at each step.
