This is patch 16/19 in Patrick Steinhardt's object database streaming interface refactoring series, continuing the architectural work to move implementation details into their proper subsystems. The patch relocates packed object stream handling from streaming.c to packfile.c, following the same pattern as the previous loose object stream relocation.

The key changes are:
1. Moves the packed object stream implementation (`odb_packed_read_stream` and related functions) from streaming.c to packfile.c
2. Introduces new public interface `packfile_store_read_object_stream()` while removing the old `open_istream_pack_non_delta()` function
3. Maintains all existing functionality while better encapsulating the packed object implementation details
4. Touches 3 files with 134 lines added and 135 removed (net reduction of 1 line)
5. Builds on the type-safe stream containers (patch 8/19) and public stream interface (patch 14/19)

The implementation remains largely unchanged, just relocated - it still handles non-delta packed objects by:
- Initializing zlib inflation state
- Using pack windows to map portions of the packfile
- Handling various zlib states (uninitialized, in-use, done, error)
- Checking object types and sizes
- Managing packfile position tracking

This continues the series' pattern of separating backend implementations from the generic streaming interface, with packed objects now properly living in the packfile subsystem. The change is straightforward and maintains all existing behavior while improving code organization.
