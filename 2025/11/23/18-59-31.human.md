Refactoring patch in Patrick Steinhardt's object database streaming interface series. This is part of a larger effort to improve type safety and enable pluggable backends in Git's object streaming code.

The patch moves the implementation of in-core object streams (used when reading objects directly from memory) out of the union in `struct odb_read_stream` and into its own dedicated `struct odb_incore_read_stream`. This continues the series' progression toward type-safe stream implementations by giving each backend its own structure rather than sharing a union.

The changes are mechanical but important for the architectural goal - the new structure contains the same fields as before (`buf` and `read_ptr`) but now includes the base `odb_read_stream` as a member rather than being part of a union. The stream operations are updated to cast between the base and derived types appropriately.

This is patch 6/19 in the v3 series, following earlier patches that established the core structure naming, simplified initialization, and moved type handling to callbacks. The changes are focused and well-contained, touching only the in-core stream implementation while maintaining identical functionality.
