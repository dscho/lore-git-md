This is part 17/19 of Patrick Steinhardt's object database streaming interface refactoring series, continuing the architectural transformation from repository-centric to object-database-centric design. The patch focuses on renaming the core interface functions to reflect their new ODB orientation:

1. Renames `open_istream()` to `odb_read_stream_open()`, `read_istream()` to `odb_read_stream_read()`, and `close_istream()` to `odb_read_stream_close()`
2. Updates all callers across 7 files (archive-tar.c, archive-zip.c, builtin/index-pack.c, builtin/pack-objects.c, object-file.c, streaming.c, streaming.h)
3. Modifies function signatures to take `struct object_database *` instead of `struct repository *` where applicable
4. Adds detailed documentation comments in streaming.h explaining the new API contracts

The changes are mechanical but wide-ranging, touching 71 lines added and 51 removed across the codebase. This completes the transition to explicit ODB handling that began in patch 13/19 (which removed `the_repository` usage) and follows the pattern established in patches 15-16 (which relocated loose and packed object implementations). The new naming convention (`odb_read_stream_*`) matches the verb-first style Junio suggested earlier in the series.

Key technical details for future reference:
- All streaming operations now explicitly operate on an object_database rather than implicitly using the_repository
- The public interface in streaming.h has proper documentation for all three core functions
- The change maintains backward compatibility through internal adaptation (e.g., still using lookup_replace_object() which needs the_repository)
- Call sites in archive, pack, and object-file code are updated consistently
