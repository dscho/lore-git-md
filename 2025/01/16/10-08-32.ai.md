This is a refactoring series addressing compiler warnings in the reftable codebase, part of the ongoing effort to make reftable a standalone library. The series focuses on fixing -Wsign-compare warnings that were previously suppressed via a DISABLE_SIGN_COMPARE_WARNINGS macro.

The key changes involve adjusting return types and parameter types across the reftable implementation to properly handle signed/unsigned comparisons. Specific adjustments include:
- Changing common_prefix_size() to return size_t
- Making hash_size() return uint32_t
- Adapting block header/footer size functions to return size_t
- Modifying restart length and block length types
- Updating read_block() to return ssize_t

The series also removes the meson.build setting that was disabling -Wsign-compare warnings and cleans up an unused print function pointer in the record code. The changes are widespread but mechanical, touching basics.c, block.c, reader.c, writer.c and several test files. Each commit appears to focus on a specific subsystem or type adjustment.

The motivation is clear - these changes are needed to properly separate the reftable code from git-compat-util.h as part of the library extraction effort. The series shows careful attention to detail with corresponding test updates, suggesting it's a well-prepared contribution.
