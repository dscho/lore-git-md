Refactoring patch in the reftable series addressing signed/unsigned comparison warnings.

This patch changes the return type of `common_prefix_size()` from `int` to `size_t` since the function calculates buffer prefix lengths which are inherently unsigned. The change eliminates several -Wsign-compare compiler warnings that appeared when stricter compiler checks were enabled in earlier patches of this series.

The modification affects multiple files across the reftable implementation - basics.c/h where the function is defined, record.c and writer.c where it's called, and the unit test file that verifies its behavior. The test case is updated to use `check_uint()` instead of `check_int()` to match the new return type.

This is a straightforward mechanical change that improves type correctness as part of the larger effort to make the reftable codebase warning-free and suitable for standalone library use. The patch maintains all existing functionality while making the types more semantically appropriate for their purpose.
