This is part 2/4 in a test modernization series converting unit tests to use the Clar framework, specifically focusing on the memory pool allocator tests. The patch converts t-mem-pool.c to u-mem-pool.c while maintaining the same test coverage.

Key technical changes:
- Replaces the old test-lib.h assertions with Clar's cl_assert* macros
- Restructures the test into two standalone functions (test_mem_pool__big_block and test_mem_pool__tiny_block) that call a shared helper
- Updates both Makefile and meson.build to reference the new u-mem-pool.c while removing t-mem-pool.c
- Tests verify memory pool behavior with both large (1MB) and small (1 byte) block sizes

The conversion follows the pattern established in the series, maintaining identical test coverage while adopting the Clar framework's conventions. The changes are straightforward mechanical conversions of test assertions and function organization, with no behavioral changes to the tests themselves. This continues the broader effort to standardize on Clar for unit testing across Git's codebase.
