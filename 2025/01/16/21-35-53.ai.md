This is the final patch in a series standardizing help text output behavior across Git commands, converting `git cmd -h` from stderr to stdout. The patch focuses on converting the remaining "bog standard" cases where commands directly check for `-h` and call `usage()`, replacing them with the new `show_usage_if_asked()` helper introduced earlier in the series.

The changes affect 19 files across various builtin commands including `diff-files`, `fast-import`, `index-pack`, and `rev-list`. Each conversion follows the same pattern: replacing manual `-h` checks with the helper function call. The patch also tightens the test in t0012-help.sh to now require empty stderr output for all help requests, enforcing the new stdout-only behavior.

Key technical details:
- Maintains exit code 129 for compatibility
- Uses the centralized `show_usage_if_asked()` helper from patch 3/6
- Updates test infrastructure to verify stdout-only output
- Handles edge cases like `merge-recursive.c` which builds a custom usage message
- Includes commands that previously didn't treat `-h` specially (like `get-tar-commit-id`)

The changes are mechanical but thorough, completing the series' goal of standardizing help output behavior across all builtin commands.
