This thread continues the ongoing effort to remove reliance on the `the_repository` global variable by converting pack-writing functionality to explicitly take repository contexts and hash algorithm parameters. The current 5-patch series focuses on `pack-write.c`, with each patch systematically converting functions to take explicit parameters while maintaining compatibility.

The latest patch (part 3) converts `write_idx_file()` and `stage_tmp_packfiles()` to take an explicit hash algorithm parameter instead of using the global `the_hash_algo`. This follows the series' established pattern of incremental conversion - the changes propagate through callers in `fast-import`, `index-pack`, `pack-objects`, and `bulk-checkin`, though these upper layers still pass `the_hash_algo` for now. The commit acknowledges this as a temporary solution that will enable future work to fully convert the callers.
