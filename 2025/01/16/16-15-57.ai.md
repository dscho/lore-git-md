This is part 2/4 in a test modernization series moving unit tests to the Clar framework, focusing on converting the memory pool allocator tests. The patch converts t-mem-pool.c to u-mem-pool.c, splitting the test into two functions (big_block and tiny_block) that verify memory pool allocation behavior with different block sizes. The conversion replaces test-lib.h assertions with cl_assert* macros and updates both Makefile and meson.build to reference the new test file while removing the old one.

Key technical changes include:
- The test now uses cl_assert_equal_i() for zero-initialization verification
- Maintains checks for proper pool.mp_block initialization
- Preserves the core test logic while adapting to Clar's syntax
- Follows the new u-*.c naming convention for Clar tests

The conversion appears straightforward and maintains the original test coverage while adopting the new framework. Patrick Steinhardt has provided mentoring feedback on this series, including a suggestion to rename the test function from t_calloc_100 to test_many_pool_allocations (which has been implemented here) and to remove personal attribution from commit messages (still present in this version). The patch is part of a coordinated effort to modernize Git's test infrastructure under Patrick's guidance.
