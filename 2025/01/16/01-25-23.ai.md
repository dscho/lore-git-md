This is the final patch in a series standardizing help text output behavior across Git commands. The patch converts remaining commands that use direct `usage()` calls to the new `show_usage_and_exit_if_asked()` helper, ensuring their help text goes to stdout rather than stderr when explicitly requested with `-h`.

The changes follow a consistent pattern: replacing manual `if (argc == 2 && !strcmp(argv[1], "-h")) usage(message)` checks with the new helper call. The patch touches 21 files, mostly builtin commands but also a test helper and the test script itself. Notable conversions include `diff-*` commands, `fast-import`, `index-pack`, and `rev-list`.

The test script `t0012-help.sh` is updated to fully enforce stdout-only output for help text, removing the conditional check that previously accommodated both stdout and stderr cases. This completes the series' goal of consistent help text behavior across all Git commands.

The patch maintains backward compatibility while achieving the standardization goal, with careful attention to edge cases like commands that had non-standard help request patterns (e.g., `fetch-pack` which checks for `-h` during argument parsing). The changes are mechanical but thorough, covering all remaining direct `usage()` callers not addressed in earlier patches.
