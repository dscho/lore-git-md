This is a build system patch that's part of a larger refactoring series addressing compiler warnings in the reftable codebase. The change removes the `-Wno-sign-compare` flag from Meson build configuration, aligning it with a previous change made to the Makefile build system in commit 4f9264b0cd. This is the first step in a 10-part series that will subsequently fix all the sign comparison warnings that were previously being suppressed.

The patch is straightforward - it simply deletes one line from meson.build that was disabling sign comparison warnings. This change forces the compiler to report signed/unsigned comparison warnings, which the following patches in the series will then address. The commit message notes this is part of an ongoing effort to make the reftable codebase warning-clean as it's being prepared to become a standalone library.

The change is mechanical and uncontroversial, serving as a prerequisite for the more substantive type adjustments that follow in the series. It maintains build system consistency between Make and Meson configurations while enabling stricter compiler checks that will help catch potential bugs.
