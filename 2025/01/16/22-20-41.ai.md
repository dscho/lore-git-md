Documentation patch clarifying that `git grep`'s line-number and column display options can be negated.

The patch updates the man page to document that `--line-number` and `--column` options can be negated with `--no-line-number` and `--no-column` respectively. The author notes this was already supported by the underlying OPT_BOOL implementation but was undocumented. The motivation comes from the author's personal workflow where they sometimes need to suppress these outputs when scripting with `git grep`, currently requiring config file edits or `- c` overrides. The documentation follows the style used for `--no-color`, explaining these options will override any configuration file settings.

Key technical details for future reference:
- Modifies `Documentation/git-grep.txt`
- Adds `--no-line-number` and `--no-column` documentation
- Explains these override config settings (grep.lineNumber and grep.column)
- Follows same pattern as `--no-color` documentation
- No behavior change - just documents existing capability

The patch is straightforward and addresses a clear documentation gap. The commit message provides good context about both the technical implementation (OPT_BOOL support) and practical motivation (scripting use case).
