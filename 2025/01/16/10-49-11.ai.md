This is the fourth and final patch in a series converting Git's unit tests to use the Clar test framework, specifically targeting the reftable tree tests. The patch follows the established pattern from previous conversions in the series (memory pool and priority queue tests), replacing test-lib.h assertions with Clar's cl_assert* macros while maintaining the original test logic.

The changes include:
- Renaming t-reftable-tree.c to u-reftable-tree.c
- Converting TEST() macros to Clar-style test functions (test_reftable_tree__tree_search and test_reftable_tree__infix_walk)
- Replacing check_* assertions with cl_assert* equivalents
- Updating build system files (Makefile and meson.build) to reference the new test file
- Removing the old test file from the build targets

The test continues to verify the same reftable tree functionality:
- tree_search() behavior with pseudo-random insertions
- infix_walk() traversal correctness
- Pointer comparisons and NULL checks
- Tree structure integrity

This completes the initial set of test conversions in Patrick Steinhardt's mentoring series, demonstrating Clar framework usage across different test types (memory management, data structures, and now reftable internals). The patch maintains the series' consistent approach while handling the reftable-specific test cases.
