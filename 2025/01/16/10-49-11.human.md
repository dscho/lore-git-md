This is the final patch in a series converting Git's unit tests to the Clar framework, focusing on the reftable tree tests. Seyi Kuforiji, mentored by Patrick Steinhardt, completes the conversion effort by adapting the reftable tree test script to use Clar assertions.

The patch follows the established pattern from previous conversions in the series:
- Renames t-reftable-tree.c to u-reftable-tree.c
- Replaces test-lib.h assertions with cl_assert* macros
- Maintains all original test logic for tree search and infix walk operations
- Updates both Makefile and meson.build build systems

The conversion preserves the test's core functionality, which exercises the reftable tree implementation with pseudo-random insertions and verifies both search operations and tree traversal behavior. The changes are mechanical rather than substantive, aligning with the series' goal of framework modernization while keeping test coverage identical.

This completes the initial set of test conversions demonstrating Clar's applicability across different test types, from memory allocators to data structures like priority queues and now reftable trees. The patch appears well-executed, following the established patterns from earlier in the series.
