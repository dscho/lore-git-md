This is a review response in the ongoing bugfix series addressing packed-refs header validation issues (currently at v1, patch 4/10). Patrick Steinhardt provides detailed technical feedback on the proposed changes to add header consistency checks for packed-refs files.

   - Points out a remaining race condition with symlinks that could be fixed with `O_NOFOLLOW`

3. Maintains consistency with previous review comments by:
   - Reiterating the architectural preference for backend-agnostic validation
   - Catching another instance of non-subshell `cd` in tests (a recurring style issue in the series)
