This is a cleanup patch in the zlib-ng optimization series, specifically removing an obsolete `z_const` define from `git-compat-util.h`. 

The patch drops a compatibility define that was originally added when introducing `uncompress2()` support, but which no longer serves any clear purpose. The define effectively prevented zlib's `const` annotations from being applied to certain parameters, though as the author notes, this doesn't actually change the const-ness of the underlying data. 

This change follows the earlier removal of the `uncompress2()` compatibility shim in patch 1/1 of this series. The commit message makes a strong case that the define was likely carried over without justification from that old compatibility code. The change is straightforward - just a single line removal - and aligns with the series' broader goal of cleaning up zlib-related compatibility code now that zlib-ng support is being properly integrated.

As part of a well-reviewed performance optimization series that's now in its third iteration, this patch represents final polish rather than introducing new functionality. It helps simplify the codebase by removing what appears to be an unnecessary legacy artifact.
