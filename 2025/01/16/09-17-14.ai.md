Cleanup patch removing obsolete zlib compatibility code as part of the zlib-ng optimization series.

This first patch in the v3 series removes the `uncompress2()` compatibility shim that was previously needed for older zlib versions. The function is no longer used after commit 15a60b747e, which open-coded the call in the reftable code. The patch deletes the implementation file, removes its build system entries (both Makefile and meson), and cleans up the related header guard in git-compat-util.h.

The removal is straightforward with no functional impact, as confirmed by the commit message pointing to the earlier removal of the last caller. This is housekeeping enabled by the reftable changes, though it also fits well with the zlib-ng series' broader goal of modernizing zlib-related code. The patch has no direct performance impact but helps reduce maintenance burden by eliminating dead code.

Key technical details for future reference:
- Removes `compat/zlib-uncompress2.c` implementation
- Drops Makefile and meson.build entries
- Removes `#if ZLIB_VERNUM` guard from git-compat-util.h
- Last caller was removed in reftable changes (15a60b747e)
- No behavior change - purely cleanup of unused code
