Final patch in reftable type-safety series. This is the 10th and last patch in Patrick Steinhardt's series to eliminate -Wsign-compare warnings from the reftable codebase, part of making reftable a standalone library. The patch cleans up the last few trivial sign comparison warnings by:

1. Changing string length handling in record.c to use size_t consistently
2. Converting loop counters to size_t where appropriate in stack.c
3. Removing the now-unused DISABLE_SIGN_COMPARE_WARNINGS macro from system.h
4. Adjusting a max length parameter from int to size_t in writer.c

The changes are mechanical but thorough, completing the series' goal of type consistency. With this patch, the reftable code can now be compiled without suppressing sign comparison warnings, marking an important step toward the library's independence from Git's build system. The patch follows the same careful approach as previous ones in the series, maintaining correctness while improving type safety.
