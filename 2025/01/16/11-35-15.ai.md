This is part 3/5 in the ongoing `the_repository` removal effort, specifically targeting the pack-writing functionality. The patch converts `write_idx_file()` to take an explicit `const struct git_hash_algo*` parameter instead of using the global `the_hash_algo`. This affects pack index writing across several commands including fast-import, index-pack, pack-objects, and bulk-checkin.

The change follows the series' pattern of bubbling up hash algorithm usage to callers while maintaining compatibility by temporarily passing `the_hash_algo` from those callers. The patch updates the function signature and all call sites, including the related `stage_tmp_packfiles()` wrapper function. Key modifications include passing the hash algorithm through to the actual hash writing operations and updating the pack.h interface declarations.

The changes are mechanical and focused, touching pack-write.c as the core implementation and propagating the new parameter through builtins. The patch maintains existing behavior while moving toward the long-term goal of eliminating global variable dependencies. As with previous patches in the series, this appears to be a straightforward refactoring with no expected functional impact, continuing the incremental approach to remove `the_repository` usage.
