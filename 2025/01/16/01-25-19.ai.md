This is a test infrastructure patch in the ongoing effort to standardize help text output behavior across Git commands. The patch modifies t0012-help.sh to optionally enforce that `-h` help output goes to stdout rather than stderr, while maintaining backward compatibility during the transition period.

The test script now accepts a GIT_TEST_HELP_MUST_BE_STDOUT flag that, when set, will verify help output appears only on stdout. Without the flag (the default), the test remains permissive, allowing output on either stream. This staged approach allows gradual conversion of commands while immediately identifying those needing updates. The change involves splitting the test's output capture into separate stdout and stderr streams and conditionally checking their contents based on the flag.

The patch is part of a larger series (position 2/6) that introduces new helper functions to centralize help text handling. It builds on Jeff King's initial work and demonstrates careful consideration of the transition process - the strict checking is opt-in during migration but will become mandatory once all commands are converted. The implementation touches only the test infrastructure, with the actual command conversions coming in later patches.
