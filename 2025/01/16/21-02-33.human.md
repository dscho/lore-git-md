This is a build system fix for the ongoing Rust bindings development. Junio Hamano reports that the meson build is failing after the recent split of Git's initialization code into `common-init.c` and `common-exit.c` files.

The issue appears to be a simple oversight - the new files weren't added to the meson build configuration. Hamano provides a straightforward patch adding these files to `meson.build`'s `libgit_sources` list, noting this should likely be squashed into the original patch that introduced the files (v6 1/5 of the series).

While this fixes the immediate compilation issue, Hamano cautions that meson-based CI tests may exercise additional functionality beyond basic compilation, so further adjustments might be needed. The fix maintains the series' goal of properly isolating initialization code while supporting both Make and meson build systems. This appears to be a minor but necessary integration step in the larger Rust bindings effort.
