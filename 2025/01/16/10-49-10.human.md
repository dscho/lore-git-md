This is the third patch in a series converting Git's unit tests to the Clar framework, focusing on the priority queue tests. The patch converts `t-prio-queue.c` to `u-prio-queue.c`, maintaining all existing test cases while updating the assertion style to use Clar's macros (`cl_assert*`).

The conversion follows the same pattern as previous patches in the series: the test logic remains largely the same, but is now organized into separate test functions (one for each test case) rather than using the old `TEST` macro approach. The test cases verify various priority queue behaviors including basic operation, mixed put/get commands, empty queue handling, LIFO stack mode, and stack reversal.

Build system files (Makefile and meson.build) are updated to remove the old test and add the new one. The patch appears mechanically sound, following the established pattern from earlier conversions in the series. As with the other conversions, this maintains 1:1 test coverage while modernizing the test infrastructure.

The patch is part of Patrick Steinhardt's mentored effort to adopt the Clar framework more widely in Git's test suite, with Seyi Kuforiji implementing the changes. No new functionality is added - this is purely a test infrastructure modernization.
