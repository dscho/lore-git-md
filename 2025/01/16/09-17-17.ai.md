This is part of the performance optimization series introducing zlib-ng support, specifically focusing on header reorganization to support the new zlib backend infrastructure. The patch moves the zlib header inclusion from git-compat-util.h to git-zlib.h, making the zlib dependency more localized to files that actually need it. This is a preparatory step for the zlib-ng integration that follows in later patches.

Key technical changes:
- Removes `#include "compat/zlib-compat.h"` from git-compat-util.h
- Adds the include to git-zlib.h instead
- Updates several files (archive.c, config.c, csum-file.c, environment.c) to explicitly include git-zlib.h
- Handles reftable specially by moving zlib include to reftable/system.h to maintain library independence
- Maintains backward compatibility while cleaning up header dependencies

The change is part of a well-structured series that has already undergone multiple review iterations. This particular change helps isolate zlib dependencies and prepares for the zlib-ng backend while keeping the reftable library independent of Git-specific zlib handling. The patch follows the established pattern of the series and doesn't introduce new technical challenges beyond what was already discussed in prior reviews.
