This is the final patch in a series standardizing help text output behavior across Git commands. The patch converts the remaining builtin commands that use direct `usage()` calls to instead use the new `show_usage_and_exit_if_asked()` helper, ensuring their help text goes to stdout rather than stderr when explicitly requested with `-h`.

The changes follow the established pattern from earlier patches - replacing manual `if (argc == 2 && !strcmp(argv[1], "-h"))` checks with the new standardized helper. The patch touches 21 files, mostly straightforward mechanical conversions, with a few special cases like `fetch-pack` and `merge-recursive` that required slightly more care.

With this change, all builtins tested by t0012-help.sh now send help text to stdout, allowing the test to be tightened to require empty stderr output. The series appears well-executed, with careful attention to backward compatibility and systematic conversion of all command types (parse-options and non-parse-options). This completes the standardization effort started in the earlier patches.
