Part of the ongoing `the_repository` removal effort, this patch converts the `write_rev_file()` function to take an explicit hash algorithm parameter rather than relying on the global `the_hash_algo`. 

This is the fourth patch in a 5-part series cleaning up global variable usage in pack-writing functionality. The change affects reverse index file writing in index-pack, midx-write, and pack-objects operations. The patch follows the established pattern of bubbling up hash algorithm parameters to callers while maintaining compatibility - most callers still pass `the_hash_algo` for now, though midx-write.c uses the repository's hash algorithm since it has already eliminated globals.

The changes are mechanical but thorough, updating both the implementation and all call sites across multiple files. The patch maintains consistency with the series' incremental approach - it tackles one well-defined function conversion while keeping the door open for future global variable removal in calling layers. The changes appear straightforward with no expected behavior changes, continuing the project's long-running effort to eliminate implicit repository dependencies.
