Housekeeping patch removing obsolete compatibility code. This is the first patch in Patrick Steinhardt's v3 series introducing zlib-ng support, though it stands alone as a cleanup.

The patch removes the `uncompress2()` compatibility shim that was previously needed for older zlib versions. The function is no longer used after commit 15a60b747e converted the last remaining caller to use direct zlib calls instead. The change deletes the implementation file, removes its build system entries, and cleans up the related header declaration.

This is a straightforward removal of dead code that has already been validated through earlier review rounds. The patch is small (107 lines removed across 4 files) and uncontroversial, serving as groundwork for the more substantial zlib-ng changes that follow in the series. The commit message clearly explains the rationale and points to the commit that made this code obsolete.
