This is a test infrastructure patch that's part of the ongoing Clar framework conversion series. It addresses a technical limitation in the test filename handling during the modernization effort.

The patch fixes an issue where the `generate-clar-decls.sh` script fails to properly process test suite filenames containing dashes (like `u-mem-pool.c`). The script now translates dashes to underscores when extracting test function names, ensuring the test declarations are generated correctly. This is a prerequisite for the subsequent patches in the series that convert specific test files following this naming pattern.

The change is mechanical but necessary - it modifies the script to perform a `tr` transformation on the suite name after stripping the `u-` prefix. The patch maintains the existing behavior while adding support for dashed filenames, which several of the test files being converted in this series use. The fix is small (a single line addition) and focused, with clear motivation stated in the commit message.

Key details for future reference:
- Touches `t/unit-tests/generate-clar-decls.sh`
- Adds dash-to-underscore conversion via `tr`
- Required for proper handling of test files like `u-mem-pool.c`, `u-prio-queue.c`, and `u-reftable-tree.c`
- Part of broader Clar framework adoption effort
- Follows established pattern from Patrick Steinhardt's prior work
