This is a refactoring patch in a series standardizing help text output behavior across Git commands. It introduces a new helper function `show_usage_if_asked()` to handle the common pattern where commands check for "-h" and show usage text. The patch is part of an ongoing effort to move help text from stderr to stdout while maintaining backward compatibility.

The new helper encapsulates the "-h" flag check and usage display logic that was previously duplicated across many commands. It still exits with status 129 (matching existing behavior) though the commit message notes this may be worth changing later since showing help is not actually an error condition.

The implementation includes some internal refactoring of the output handling code, changing from direct file descriptor writes to using FILE* streams for more consistent behavior. This builds on previous discussion in the thread about output flushing behavior, though the core functionality remains unchanged from earlier versions of the patch.

This appears to be a straightforward mechanical change that follows the design established earlier in the series. The patch is cleanly separated from other changes in the series, as noted in Junio's cover note.
