Test infrastructure update for help output standardization.

This is the first patch in a 6-part series standardizing where Git commands send their `-h` help output (currently split between stdout and stderr). The patch modifies the test suite to optionally enforce stdout-only help output, preparing for the transition while maintaining backwards compatibility during the conversion period.

The test change introduces a new `GIT_TEST_HELP_MUST_BE_STDOUT` flag that, when set, will fail tests for commands still sending help to stderr. This allows gradual conversion while keeping the default test behavior permissive. The long-term goal is to remove this flag once all commands are converted to use the new centralized helpers that output to stdout.

The patch is straightforward and well-motivated, with clear documentation of the transitional approach. It's sign-off indicates this has already been reviewed in previous iterations, and the implementation matches the series' goal of standardizing behavior without breaking existing tests during the transition. As the foundational test change for the series, it provides the verification mechanism needed for the subsequent command conversions.
