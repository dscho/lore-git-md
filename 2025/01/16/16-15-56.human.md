Test infrastructure patch handling filename conventions in the new Clar test framework. This is the first of a four-part series modernizing Git's test infrastructure by converting unit tests to the Clar framework.

The patch fixes a script (`generate-clar-decls.sh`) that processes test function declarations. The script previously couldn't handle dashes in test filenames (like `u-mem-pool.c`), which prevented tests from running. The solution is straightforward - convert dashes to underscores when extracting function signatures. This matches the naming convention where test functions use underscores (like `test_mem_pool__basic`).

The change is small (a single line addition) but foundational for the series, as subsequent patches will introduce test files following this dashed-filename convention.
