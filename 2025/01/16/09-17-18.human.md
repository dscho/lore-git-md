Performance optimization patch in the zlib-ng series, moving a compatibility shim for `deflateBound()` into the new zlib abstraction layer. This is part of the ongoing effort to support zlib-ng as an alternative zlib backend while maintaining compatibility with older zlib versions.

The patch relocates the `deflateBound()` compatibility definition from git-zlib.c to compat/zlib-compat.h, where it will be more centrally available. The function is needed for zlib versions older than 1.2.0, and this move prepares the codebase for subsequent changes that will adapt the shim for zlib-ng compatibility.

This is a straightforward change that follows the established pattern of the series, consolidating zlib compatibility code in the new abstraction layer. The patch has minimal impact (just moving 4 lines of code) but is an important piece of the larger performance optimization effort that has already shown ~25% speedups in object reading operations.
