Performance optimization series completion: This is the final patch in a 10-part series introducing zlib-ng support as an alternative zlib backend for Git. The series has undergone multiple review rounds and addresses all technical concerns, now focusing on CI integration.

The patch adds zlib-ng test coverage by modifying the "linux-musl" CI job to install zlib-ng-dev in Alpine Linux. The author explains this was necessary because other common CI platforms either lack zlib-ng packages (Debian, Alma Linux) or don't run tests (Fedora). Alpine was chosen as the only viable option that both provides the package and executes the test suite.

This completes the CI transition work started earlier in the series, ensuring the zlib-ng implementation gets proper automated testing. The change is minimal - just adding one package to the Alpine dependency list - but important for validating the performance improvements (previously shown to provide ~25% speedup in object reading operations) across different environments.

With this final piece in place, the series appears ready for integration, having addressed all build system integration, platform compatibility, and now CI testing requirements for the zlib-ng backend support.
