CI/build system patch in the zlib-ng optimization series (v3 09/10). This switches the linux-musl CI job from Make to Meson, completing the build system transition for testing zlib-ng integration. The change simplifies CI configuration by removing manual build flags (now handled automatically by Meson) and prepares for easier zlib-ng testing. Key technical changes include adding Meson build option for `GIT_TEST_UTF8_LOCALE` (previously a Makefile variable) and removing redundant CC=gcc (already default in ci/lib.sh). The patch updates all relevant CI configs (.github/workflows, .gitlab-ci.yml) and adds Meson/ninja-build to Alpine dependencies. This is a straightforward infrastructure change that maintains consistency with the series' goal of full Meson support for zlib-ng testing.
