Test modernization converting reftable tree tests to Clar framework. This is the final patch in Seyi Kuforiji's series converting Git's unit tests to use the Clar testing framework, mentored by Patrick Steinhardt. The patch converts the reftable tree test (t-reftable-tree.c → u-reftable-tree.c) while maintaining all existing test coverage.

The conversion preserves two key test functions: `tree_search` verifies proper insertion and lookup behavior with pseudo-random ordering, while `infix_walk` checks tree traversal correctness. The implementation replaces test-lib.h assertions with cl_assert* macros (cl_assert, cl_assert_equal_p, cl_assert_equal_i) and follows the established pattern of splitting test cases into separate functions with descriptive names (test_reftable_tree__tree_search and test_reftable_tree__infix_walk).

Build system changes remove the old test from both Makefile and meson.build while adding the new Clar-based test. The conversion maintains all the original's verification of tree operations including pointer comparisons, NULL checks, and count validations. Like previous patches in the series, this demonstrates Clar's ability to handle complex data structure testing while providing type-safe assertions.

This completes the initial set of test conversions in the series, having now covered memory pools, priority queues, and reftable internals. The patch follows the established patterns from prior conversions in the series, with no outstanding review feedback needing incorporation beyond the pending removal of personal attribution in commit messages noted in earlier patches.
