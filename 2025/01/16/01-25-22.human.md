This is part 5 of a 6-part series standardizing help text output behavior across Git commands. The patch focuses on converting "oddball" commands that handle help requests (`-h`) in non-standard ways to use the new `show_usage_and_exit_if_asked()` helper function.

The patch updates four commands (`credential`, `unpack-file`, `upload-archive`, and `var`) that previously had custom logic for handling `-h` requests. These commands either combined the help check with argument validation or didn't treat `-h` specially at all. The changes make them consistent with the series' goal of sending help text to stdout while maintaining the same error behavior for invalid arguments.

The conversions follow the pattern: first check for help requests using the new helper (which exits if `-h` is detected), then proceed with the original argument validation. This maintains the same user experience while making the implementation more consistent with other commands.

This continues the series' careful approach - after introducing infrastructure in earlier patches and converting straightforward cases, it now handles more complex implementations. The changes are mechanical but necessary to complete the standardization effort across all commands.
