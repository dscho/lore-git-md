This is part 3 of a 5-patch series continuing the `the_repository` removal effort, specifically targeting the pack-writing functionality. The patch converts `write_idx_file()` to take an explicit `const struct git_hash_algo*` parameter instead of using the global `the_hash_algo` variable.

The change is mechanical but touches several key pack-related operations: fast-import, index-pack, pack-objects, and bulk-checkin all get updated to pass through the hash algorithm parameter. The patch follows the series' pattern of bubbling up global variable usage to callers rather than eliminating it entirely in one step, maintaining compatibility while making the dependency explicit.

The implementation looks straightforward, with clean function signature updates and corresponding caller modifications. While this doesn't yet fully remove global usage (callers still pass `the_hash_algo`), it's a clear step toward that goal by making the dependency visible at higher levels where it can be addressed later.
