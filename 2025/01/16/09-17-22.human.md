CI/build system patch in the zlib-ng optimization series. This is patch 9/10 in v3, switching the linux-musl CI job from Make to Meson to better support testing of the zlib-ng backend.

The change simplifies CI infrastructure by removing manual build option specifications while ensuring Meson can automatically detect these settings. The patch also removes redundant GCC compiler specification since it's already the default in CI scripts.

This appears to be a straightforward infrastructure change that completes the build system integration work for the zlib-ng series. The modifications are cleanly scoped to CI configuration files and Meson build definitions, with no functional impact on the core Git codebase. The change helps verify the Meson build path works correctly with the new zlib compatibility layer introduced earlier in the series.
