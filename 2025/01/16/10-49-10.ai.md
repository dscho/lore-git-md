Test modernization converting priority queue tests to Clar framework.

This is the third patch in a 4-part series converting Git's unit tests to use the Clar test framework, mentored by Patrick Steinhardt. The patch focuses on the priority queue tests, converting t-prio-queue.c to u-prio-queue.c while maintaining the same test coverage.

The conversion follows the same pattern as previous conversions in the series:
- Replaces test-lib.h assertions with cl_assert* macros
- Splits the single test function into multiple standalone test cases (basic, mixed, empty, stack, reverse_stack)
- Updates both Makefile and meson.build to reference the new test file while removing the old one

The tests verify various priority queue behaviors including:
- Basic ordering (1-10 sorted output)
- Mixed put/get operations
- Empty queue handling
- LIFO stack mode behavior
- Stack reversal functionality

Key technical details:
- Maintains all original test cases with identical verification logic
- Uses same test input/output data structures
- Keeps the same special command values (MISSING, DUMP, STACK, etc.)
- Updates size_t usage for array indexing (minor improvement over original)

This continues the established pattern from earlier conversions in the series, showing the Clar framework can handle more complex test scenarios involving data structures and multiple operation types. The patch appears mechanically sound with no obvious issues in the conversion approach.
