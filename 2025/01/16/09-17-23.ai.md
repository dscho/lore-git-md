Performance optimization series completion adding zlib-ng CI testing. This final patch in the 10-part series enables test coverage for the new zlib-ng backend by modifying the Alpine Linux CI job to install zlib-ng-dev. The change is minimal - just adding the package to the apk install command in ci/install-dependencies.sh. 

The commit explains the platform constraints that led to choosing Alpine Linux for this coverage: Debian-based distros lack zlib-ng packages, Fedora has it but doesn't run tests, and Alma Linux is also missing the package. Alpine was selected because it both provides zlib-ng and runs Git's test suite. 

This completes the CI integration work for the zlib-ng optimization series, ensuring the new backend gets exercised in automated testing. The patch follows naturally from the prior CI transition to Meson in patch 9/10, and maintains the series' clean approach of making zlib-ng support opt-in while preserving standard zlib compatibility. With this change, all major components of the zlib-ng integration are now covered by CI, addressing the last remaining gap in test coverage identified during review.
