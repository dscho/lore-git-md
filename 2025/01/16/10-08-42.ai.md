This is the final patch in a 10-part refactoring series addressing compiler warnings and type correctness in the reftable codebase. The patch cleans up the last remaining -Wsign-compare warnings and removes the now-unneeded DISABLE_SIGN_COMPARE_WARNINGS macro from system.h.

The changes include:
- Converting string length handling in record.c to use size_t for strlen() results
- Simplifying loop variables in record.c and stack.c to use appropriate unsigned types
- Removing redundant loop counters and consolidating for-loop declarations
- Updating the common_prefix_arg struct in writer.c to use size_t for its max field
- Deleting the sign-compare warning suppression macro as it's no longer needed

The modifications follow the same pattern as earlier patches in the series - converting signed/unsigned mismatches to use proper unsigned types where appropriate. The changes are mechanical but thorough, touching record handling, stack operations, and writer internals. With this patch, the reftable codebase should now compile cleanly without sign-compare warnings, marking the completion of this type-safety refactoring effort.
