Final patch in a reftable type-safety refactoring series. This 10th patch cleans up the last few -Wsign-compare warnings in the reftable code and removes the now-unneeded DISABLE_SIGN_COMPARE_WARNINGS macro from system.h. The changes are mostly straightforward type adjustments to match variable types with their usage contexts, like changing loop counters to size_t where they index into size_t-length arrays.

Junio Hamano reviews the patch and notes most changes are obviously correct, but questions one change to make a max field in common_prefix_arg use size_t instead of int. He observes this seems driven by prior changes making related functions return size_t, and wonders if this should have been done in an earlier patch for consistency. The patch appears to complete the series' goal of eliminating sign-compare warnings while maintaining type safety throughout the reftable codebase.
