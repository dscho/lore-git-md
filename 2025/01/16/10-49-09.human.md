Test modernization patch converting the memory pool allocator tests to the Clar framework. This is part 2 of a 4-part series mentored by Patrick Steinhardt to standardize Git's unit tests on the Clar framework (originally from libgit2).

The patch converts `t-mem-pool.c` to `u-mem-pool.c`, replacing the existing test infrastructure with Clar assertions while maintaining the same test coverage. The tests verify that `mem_pool_calloc()` correctly allocates and zeroes memory blocks, checking both large (1MB) and tiny (1 byte) allocation scenarios. The conversion follows the established pattern of:
1. Removing the old test file
2. Creating a new Clar-based test file
3. Updating both Makefile and meson.build to reference the new test location

The changes appear straightforward and mechanical conversion of test assertions to Clar's `cl_assert*` macros. The patch maintains the same test logic while fitting into the broader test modernization effort. As with the series' other patches, this appears to be a clean conversion that preserves the original test coverage while moving to the preferred framework.
