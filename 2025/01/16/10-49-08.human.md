Test infrastructure patch addressing filename handling in the Clar test framework conversion effort. This is part 1 of a 4-part series modernizing Git's unit tests by moving them to the Clar framework (originally from libgit2).

The patch fixes an issue where test files containing dashes (like `u-mem-pool.c`) weren't being properly processed by the `generate-clar-decls.sh` script. The script now translates dashes to underscores when extracting test function names, ensuring tests can be properly discovered and run. This is a mechanical but necessary change to support the test file naming convention being used in the conversion effort.

The change is straightforward - a single line modification to the script that performs the character substitution. The patch is part of a mentored contribution (Patrick Steinhardt is listed as mentor) and appears well-scoped to solve the immediate problem while maintaining compatibility with the broader test framework work.
