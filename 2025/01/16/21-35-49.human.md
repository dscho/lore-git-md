This is part 2/6 of a series standardizing help text output behavior across Git commands. The patch introduces a new helper function `show_usage_with_options_if_asked()` in the parse-options API, which provides a standardized way for commands to handle `-h` help requests by sending output to stdout rather than stderr.

The function encapsulates the common pattern where commands check for `-h` and call `usage_with_options()`, while ensuring the help text goes to stdout (via `usage_with_options_internal()`). The implementation maintains backward compatibility by still exiting with status 129, though the commit message notes this may be revisited later since a help request arguably should succeed with status 0.

This is a key infrastructure piece for the series, providing the mechanism that subsequent patches will use to convert individual commands. The implementation follows earlier discussion between Junio and Jeff King, with the final naming dropping redundant "and_exit" while keeping "if_asked" to distinguish from direct usage calls. The patch is cleanly focused on adding the helper without yet converting any commands, making it easy to review the core mechanism in isolation.
