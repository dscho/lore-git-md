Refactoring patch in the reftable series addressing signed/unsigned type mismatches.

This is the fourth patch in a 10-part series cleaning up compiler warnings and type correctness in the reftable codebase. The change modifies `common_prefix_size()` to return `size_t` instead of `int`, since the function calculates buffer prefix lengths which can never be negative. This eliminates several -Wsign-compare warnings and better matches the function's actual behavior.

The patch updates the function declaration and all call sites, including test assertions that now use `check_uint` instead of `check_int`. The changes are mechanical but important for type safety as part of making reftable a standalone library. The series as a whole shows careful attention to compiler warnings and type correctness in the reftable implementation.
