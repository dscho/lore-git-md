This is a documentation patch that adds missing information about negated options for `git grep`. 

D. Ben Knoble noticed that while `git grep` supports negating the `--line-number` and `--column` options (via `--no-line-number` and `--no-column`), this wasn't documented in the man page. The author explains their personal motivation: they frequently need to disable these options when scripting with `git grep`, either by commenting out config settings or using `-c` flags, because they didn't realize the negation syntax existed.

The patch adds documentation for both `--no-line-number` and `--no-column`, following the style used for similar options like `--no-color`. The changes are straightforward - just a few lines added to the man page to clarify behavior that was already implemented but not properly documented. 

This is a well-justified documentation improvement that will help users who, like the author, need to temporarily override their grep configuration settings. The patch is small and focused, with a clear explanation of both the problem and solution.
