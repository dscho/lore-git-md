This is the final patch in a series standardizing help text output behavior across Git commands. It converts the remaining "bog standard" cases where commands check for `-h` and call `usage()` directly, replacing them with the new `show_usage_if_asked()` helper that ensures help text goes to stdout rather than stderr.

The patch touches 19 files, mostly simple mechanical conversions of the pattern `if (argc == 2 && !strcmp(argv[1], "-h")) usage(...)` to use the new helper. A few cases required slightly more attention, like `merge-recursive.c` which builds a custom usage message, and `mailsplit.c` which had its `-flag check in a different location. The test in t0012-help.sh is also updated to now strictly require empty stderr output for all help requests.

As the concluding patch in the series, this completes the standardization effort by covering all remaining straightforward cases after the earlier patches handled more complex scenarios. The changes are well-contained and follow the established pattern, with comprehensive test coverage verifying both output location and exit code behavior. The series appears ready for final consideration.
