This is a build system patch that aligns the Meson build configuration with recent compiler warning changes. It's the first in a 10-part series refactoring the reftable code to properly handle signed/unsigned comparisons.

The patch removes the `-Wno-sign-compare` flag from Meson's build configuration, matching a similar change made to the Makefile-based build in December 2024. This is part of a broader effort to make the reftable codebase compile cleanly with stricter compiler warnings, which is important as the reftable code is being prepared to become a standalone library.

The change is straightforward - just a single line removal in meson.build. As the first step in the series, it sets the stage for the subsequent patches that will actually fix the sign comparison warnings throughout the reftable code. The patch appears well-motivated and properly connected to the larger reftable library extraction effort.
