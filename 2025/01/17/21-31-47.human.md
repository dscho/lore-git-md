This is part 5/6 of the series standardizing help text output behavior across Git commands. The patch focuses on converting "oddball" commands that had non-standard ways of handling `-h` help requests.

The changes update several commands (`credential`, `fetch-pack`, `unpack-file`, `upload-archive`, and `var`) to use the new `show_usage_if_asked()` helper, which sends help text to stdout rather than stderr. These commands were special cases because they didn't follow the typical pattern of explicitly checking for `-h` - some used clever argument counting, while others like `git var` didn't treat `-h` specially at all.

The patch maintains the same error handling behavior while ensuring help text goes to stdout when explicitly requested. It's been reviewed and acked by Jeff King, showing the approach has consensus. This continues the careful, command-by-command conversion strategy seen in previous patches, with special attention to preserving backward compatibility.
