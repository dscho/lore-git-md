Test modernization converting reftable tree tests to Clar framework. This is the final patch in Seyi Kuforiji's v3 series converting Git's unit tests to the Clar testing framework, mentored by Patrick Steinhardt.

The patch converts the reftable tree tests from the old test-lib.h format to the new Clar framework, following the same pattern as previous conversions in the series. It maintains the same test coverage with two main test functions: one for tree search operations and another for infix tree walks. The original test logic remains intact but is now expressed using Clar's assertion macros (cl_assert, cl_assert_equal_p, etc.).

Build system files (Makefile and meson.build) are updated to remove the old test and add the new Clar version. The conversion appears thorough, preserving all the original test cases while adopting the new framework's conventions. This completes the set of test conversions in the v3 series, which has already addressed previous review feedback about commit messages and technical accuracy.
