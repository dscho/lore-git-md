This is part 3 of a 5-patch series continuing the `the_repository` removal effort, specifically targeting `pack-write.c` functionality. The patch converts `write_idx_file()` to take an explicit `hash_algo` parameter instead of using the global `the_hash_algo`, propagating this change through its callers in `fast-import`, `index-pack`, `pack-objects`, and `bulk-checkin`.

The patch also updates `stage_tmp_packfiles()` in `pack-write.c` to accept and pass through the hash algorithm parameter, since it calls `write_idx_file()`. The commit message acknowledges this is a temporary solution that bubbles up global usage to callers (which currently pass `the_hash_algo`), deferring full conversion of those upper layers to future work. This follows the series' established pattern of incremental conversion while maintaining compatibility.

Key technical changes include:
- Adding `const struct git_hash_algo*` parameter to both functions
- Updating all internal hash algorithm references to use the parameter
- Modifying function prototypes in `pack.h`
- Converting hash writes in `write_idx_file()` to use the passed algorithm

The patch maintains the same behavior while removing direct global variable dependencies, though callers still pass `the_hash_algo` for now. This continues the series' strategy of focused, mechanical conversions within `pack-write.c` while documenting the temporary nature of passing globals from upper layers.
