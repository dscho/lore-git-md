This thread covers a 3-patch series adding Meson build system support for git-subtree, building on earlier work from January 2025. The series was initiated to address documentation build breakages while modernizing the build infrastructure for this contrib component.

The first patch fixed subtree documentation building by updating the Makefile to properly generate versioned config files, aligning with changes made to Git's main build system. The second patch introduced Meson configuration infrastructure for contrib features, initially supporting shell completions with subtree support to follow. Now, the final patch completes the work by fully wiring up git-subtree in the Meson build system.

The implementation handles all aspects of subtree's build requirements: the main script itself (via the existing generate-script.sh), documentation (both man pages and HTML), and test suite execution. Care was taken to maintain build order dependencies and ensure the built subtree script is properly found during testing. The changes follow established patterns from Git's broader Meson transition, providing feature parity with the existing Makefile while bringing subtree under the new build system's management.

With this series now complete, git-subtree joins Git's growing set of components supported by both traditional Makefile and modern Meson build systems. The changes are mechanical and well-contained, representing incremental progress in Git's build system modernization efforts.
