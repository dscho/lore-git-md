Platform compatibility fix addressing compiler warnings in connect.c. This patch cleans up sign-compare warnings by changing loop variables and function parameters from `int` to `size_t` where they interact with size-related operations. The changes are mechanical but widespread, affecting several functions in the protocol-handling code:

1. Loop counters in server capability checking functions (`server_supports_v2`, `server_feature_v2`, etc.) are changed to `size_t` to match the `nr` field they compare against.

2. The `linelen` parameter in `process_capabilities` and related functions is changed to `size_t*` to properly handle string length comparisons.

3. The patch removes a now-unneeded `DISABLE_SIGN_COMPARE_WARNINGS` define that was previously suppressing these warnings.

The changes are straightforward type adjustments without behavioral impact, though they do propagate through several layers of the protocol code. The patch appears to be a clean, focused improvement to code hygiene, though it doesn't address why these warnings weren't caught earlier in development.
