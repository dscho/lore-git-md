The author notes this is a temporary measure that "bubbles up" the global usage to callers, which can be addressed in future work. This approach was discussed in earlier thread feedback as a pragmatic intermediate step.

The patch follows the series' incremental strategy by focusing on one function at a time while maintaining compatibility. It touches several key pack-handling subsystems but makes no behavior changes - this is purely a refactoring to reduce global variable usage. The changes are straightforward and well-contained, with thorough updates to both implementation and header declarations.
