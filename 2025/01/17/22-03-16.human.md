Refactoring patch in the hash algorithm unification series. This is patch 3/8 in Taylor Blau's v3 contribution to brian m. carlson's larger effort to consolidate Git's hash algorithm handling.

The patch modifies `hashfile_checksum_valid()` to use a local `algop` variable rather than directly accessing `the_hash_algo`. This follows the pattern established in patch 2, where similar changes were made to other hashfile operations. The function validates checksums written by the hashfile API, and this change prepares it for future updates to the algorithm selection mechanism.

The change is straightforward - it extracts the global hash algorithm into a local variable before using it, which makes the function's dependencies more explicit and maintains consistency with the series' approach. The diff shows mechanical replacements of `the_hash_algo` with `algop` throughout the function, with no behavioral changes.

This appears to be a clean, focused change that fits well with the series' goal of reducing direct `the_hash_algo` usage. It follows the pattern established in earlier patches and helps move toward the unified `unsafe_hash_algo()` mechanism that's central to the series.
