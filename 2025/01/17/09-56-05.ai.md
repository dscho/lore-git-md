This is a documentation and build system fix for git-subtree. The patch addresses a breakage in building git-subtree documentation that occurred when the main Git build system changed how documentation version information is injected. Previously, version info was passed via command-line arguments, but commit a38edab7c8 moved this to generating versioned config files via `GIT-VERSION-GEN`. The git-subtree Makefile wasn't updated to match this change, causing doc builds to fail.

The fix updates the subtree Makefile to generate its own versioned config files (asciidoc.conf and asciidoctor-extensions.rb) using the same `GIT-VERSION-GEN` approach as the main build system. It adds these generated files to .gitignore and makes them dependencies of the doc build targets. The changes maintain compatibility with both asciidoc and asciidoctor build paths while properly tracking dependencies.

Key technical details:
- Adds versioned config file generation using `version_gen` from shared.mak
- Updates build rules to use local generated config files rather than ones from Documentation/
- Maintains both asciidoc and asciidoctor build variants
- Properly tracks config files as dependencies for doc targets
- Cleans up generated config files in 'make clean'

This is the first of three patches in a series that ultimately adds Meson build support to git-subtree, but this initial patch stands alone as a straightforward fix for the documentation build breakage. The changes are focused and mechanical, following the pattern established by the main build system.
