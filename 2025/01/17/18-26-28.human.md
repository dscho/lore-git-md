This is a refactoring patch that's part of Usman Akinyemi's series implementing OS version capability in Git's protocol. The patch extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` function, which will be reused in later patches for OS version strings.

Junio Hamano provides several minor review comments on the implementation:
- Suggests clearer documentation wording for the ASCII range
- Questions whether a TODO about consecutive dot replacement should remain
- Notes formatting issues in the comment style
- Points out `isprint()` could be used instead of direct character comparisons
- Asks whether empty/dot-only results need special handling

The changes themselves are straightforward - moving existing sanitization code into a reusable function while improving memory management with `strbuf_detach()`. This foundational refactoring has already been reviewed and approved by Christian Couder (as noted in the sign-off), and Junio's comments are minor polish suggestions rather than blocking issues.

This is the first of six patches in a series that has already reached technical resolution with maintainer approval, so these comments are likely the final tweaks before merging.
