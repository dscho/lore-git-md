This is the final patch in a series standardizing help text output behavior across Git commands. The patch converts remaining `usage()` callers to use the new `show_usage_if_asked()` helper, ensuring help text goes to stdout rather than stderr when explicitly requested with `-h`. 

The changes are mechanical replacements of the pattern `if (argc == 2 && !strcmp(argv[1], "-h")) usage(message)` with `show_usage_if_asked(argc, argv, message)`. The patch touches 19 files, mostly builtin commands that hadn't been converted in earlier parts of the series. Notable cases include `merge-recursive.c` which needed special handling for its usage string formatting, and `mailsplit.c` which had its `-h` check removed since it's now handled by the helper.

The test in t0012-help.sh is tightened to always expect empty stderr output for help requests, removing the conditional behavior that previously accommodated both stdout and stderr output. This reflects the series' completion of standardizing on stdout for help text.

The patch has been reviewed and acked by Jeff King, with Junio Hamano signing off. It represents the culmination of the series' goal to unify help text output behavior while maintaining backward compatibility through careful refactoring and testing.
