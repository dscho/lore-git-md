This is the second patch in a 3-part series adding Meson build support to git-subtree, following the documentation build fix in patch 1. The patch introduces Meson build configuration for contrib/ directory features.

The change makes contrib/ features configurable via a new 'contrib' Meson option, which accepts an array of features to build. Currently supported features are 'completion' (shell completions) and 'subtree' (though subtree support isn't fully wired up yet). The default behavior remains building completions, matching the current Makefile behavior. The implementation is straightforward - it replaces the unconditional subdir('completion') with a loop over the selected features.

Key technical details:
- Adds 'contrib' option to meson_options.txt as an array type with 'completion' and 'subtree' choices
- Modifies contrib/meson.build to iterate over selected features
- Maintains backward compatibility by defaulting to building completions
- Sets up infrastructure for future contrib features (like subtree) to be selectively included

This is a mechanical change that follows Meson conventions while preserving existing behavior. The patch appears well-contained and properly formatted, though it's worth noting the subtree feature isn't actually implemented yet (that comes in patch 3). The change aligns with Git's gradual Meson adoption by providing equivalent functionality to the Makefile system but with more configuration flexibility.
