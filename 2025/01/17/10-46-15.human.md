This is a refactoring patch in Usman Akinyemi's series adding OS version capability to Git's protocol. It modifies the recently introduced `get_uname_info()` function to optionally return just the OS name rather than full system details, preparing for a subsequent patch that will use this simplified output.

The change adds a `full` parameter to toggle between complete uname output (used by `git bugreport`) and minimal sysname-only output (needed for the new protocol capability). The implementation maintains all existing behavior while adding the new mode, with the bugreport caller updated to explicitly request full details. The patch includes updates to both the function declaration and its documentation in version.h.
