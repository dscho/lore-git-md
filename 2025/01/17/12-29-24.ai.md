Test modernization converting mem-pool tests to Clar framework. This is part 2/4 of Seyi Kuforiji's series converting Git's unit tests to the Clar framework, mentored by Patrick Steinhardt.

The patch converts the memory pool tests from the old test-lib.h format to the new Clar framework. The key changes are:
- Deletes t-mem-pool.c and creates new u-mem-pool.c following the new naming convention
- Updates both Makefile and meson.build to reference the new test location
- Rewrites test assertions using Clar's cl_assert macros
- Maintains the same test coverage for memory pool behavior (testing allocations with both large and small block sizes)
- Splits the test into two Clar test functions (big_block and tiny_block) while keeping the core test logic in a shared helper function

The conversion appears mechanical and correct, maintaining all the original test cases while adapting them to Clar's style. The build system changes are consistent with the series' approach of handling the transition from t-* to u-* test files. This follows the pattern established in earlier patches of the series and addresses Patrick's feedback about proper filename handling in the framework.

Technical details for future reference:
- Test file: u-mem-pool.c
- Test functions: test_mem_pool__big_block, test_mem_pool__tiny_block
- Assertions converted to cl_assert/cl_assert_equal_i
- Build system references updated in both Makefile and meson.build
- Original test coverage preserved (memory allocation verification with different block sizes)
