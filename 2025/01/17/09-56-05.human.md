Documentation fix for git-subtree build system. This is the first patch in a 3-part series that ultimately adds Meson build support to git-subtree.

The patch fixes a breakage in git-subtree's documentation building that occurred when the main Git project changed how version information gets injected into documentation. Previously, git-subtree was passing version info via command-line arguments, but the main project switched to generating versioned config files. The patch updates git-subtree's Makefile to use the new `GIT-VERSION-GEN` approach and properly track dependencies.

The changes are straightforward - adding generated config files to .gitignore and updating the Makefile rules to generate and use them. The fix was reported by a FreeBSD user, suggesting this was a real-world issue affecting users. This appears to be a clean, focused fix that aligns git-subtree's build with the main project's approach.
