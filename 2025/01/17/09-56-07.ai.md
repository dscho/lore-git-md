This is the final patch in a 3-part series adding Meson build support for git-subtree, completing the work started in the previous patches. The patch wires up the actual git-subtree command in the Meson build system, including its documentation and tests.

The key technical changes include:
- Creating a new `contrib/subtree/meson.build` file that handles building the subtree script, documentation (both man pages and HTML), and running its test suite
- Moving the `contrib/` subdirectory inclusion in the main meson.build file to after documentation building to ensure proper build order dependencies
- The subtree script is built as a custom target using the existing `generate-script.sh` infrastructure
- Test suite support includes PATH modification to ensure the built subtree script is found
- Documentation building supports both man pages and HTML, matching the existing Makefile behavior

The patch follows established patterns from the main Git Meson conversion, maintaining feature parity with the Makefile build while adding the subtree component to the new build system. It completes the series' goal of bringing subtree under Meson's build management while preserving all existing functionality.
