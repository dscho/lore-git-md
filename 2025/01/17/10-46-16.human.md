Test improvement in Usman Akinyemi's OS version capability series.

This is the fourth patch in a 6-part series adding OS version reporting to Git's protocol. The change refactors test setup in `t5701-git-serve.sh` to remove implicit dependencies between tests. The patch splits this into a dedicated setup` test that explicitly generates the expected content files (`agent_and_osversion`, `expect.base`, `expect.trailer`) for reuse by subsequent tests.

The change is straightforward and well-motivated - it makes the test dependencies explicit while preparing for future test additions.
