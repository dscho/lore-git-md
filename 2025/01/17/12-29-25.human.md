This is part 3 of a 4-part series converting Git's unit tests to the Clar framework, focusing on the priority queue test. The patch converts `t-prio-queue.c` to `u-prio-queue.c` while maintaining all test functionality.

The conversion splits the original test into five standalone Clar test functions covering different priority queue behaviors: basic operations, mixed put/get commands, empty queue handling, LIFO stack behavior, and stack reversal. The patch also updates the type of variable `j` from `int` to `size_t` to match `result_size` and avoid signed/unsigned comparison warnings.

The changes follow the established pattern seen in the series: deleting the old test file, creating a new Clar-format version, and updating build files (Makefile and meson.build) to reference the new location. The test coverage appears equivalent to the original, just reorganized into Clar's assertion-based style with `cl_assert` macros.

This continues the well-structured modernization effort mentored by Patrick Steinhardt, with the technical approach now well-established through several prior conversions in the series. The patch looks clean and focused, completing another step in the test infrastructure transition.
