This is the second patch in a 3-part series adding Meson build support to git-subtree, following the documentation build fix in patch 1. The change introduces configurable build options for contrib/ directory components.

The patch makes the contrib/ directory features optional in Meson builds, where previously shell completions were always built. It adds a new 'contrib' array option that defaults to including just completions (matching current behavior) but allows users to explicitly select which contrib features to build. The implementation shows the option will support both 'completion' and upcoming 'subtree' features.

The change is straightforward - it replaces a hardcoded subdirectory inclusion with a loop over selected features, and adds the new option declaration. This appears to be a clean infrastructure change that maintains backward compatibility while adding flexibility for future contrib additions. The patch fits logically in the series, setting up the framework before patch 3 presumably adds subtree support.
