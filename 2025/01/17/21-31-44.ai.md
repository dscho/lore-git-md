Refactoring patch in a series standardizing help text output behavior.

This is the second patch in a 6-part series converting Git command help text from stderr to stdout when explicitly requested with `-h`. It introduces a new helper function `show_usage_with_options_if_asked()` that encapsulates the common pattern of checking for `-h` and showing usage. The function maintains the existing behavior of status code 129 for now, though the commit message notes this may be reconsidered later.

The implementation builds on the series' foundation of centralizing output behavior through new helper functions, here providing a more convenient wrapper around `usage_with_options_internal()`. The patch follows the thread's established pattern of maintaining backward compatibility while moving toward the new stdout behavior. Junio Hamano signs off on the patch, crediting Jeff King for the approach.

This is a straightforward mechanical change that doesn't introduce new test coverage since the series' test infrastructure (including t0012-help.sh) was established in earlier patches. The change affects parse-options plumbing code that will be used by subsequent patches converting individual commands. The exit code discussion noted in the commit message reflects an open question that may be addressed separately from this series.
