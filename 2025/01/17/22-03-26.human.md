This is a refactoring patch in a series about hash algorithm handling, specifically converting test infrastructure to use the new `unsafe_hash_algo()` mechanism.

Taylor Blau's patch simplifies the test helper code that powers both the 'sha1' and 'sha1-unsafe' test commands. Instead of having separate code paths for safe and unsafe hash operations (with conditionals at each step), the patch now converts the algorithm pointer to its unsafe variant upfront when requested. This allows all subsequent operations to use the standard function names without needing to choose between safe/unsafe variants at each call site.

The change reduces 12 lines of conditional code down to just 5 lines, making the test helper cleaner while maintaining the same functionality. This is part of the broader effort to eliminate separate unsafe hash function variants in favor of a unified mechanism through `unsafe_hash_algo()`. The patch builds on earlier work in the series and implements the approach suggested by Jeff King for handling unsafe algorithm variants.
