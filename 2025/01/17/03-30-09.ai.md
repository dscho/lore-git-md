Bugfix targeting sparc64 architecture with clang compilation. This report describes a SIGBUS crash in `git pull` when the unpack-objects code is triggered, specifically occurring during signature handling in `builtin/unpack-objects.c`. The crash manifests when accessing `hdr->hdr_signature` with clang-compiled Git on sparc64 systems, though it doesn't reproduce with GCC.

The reporter provides detailed reproduction steps and system information, noting the crash happens reliably during object unpacking. They've identified the exact line causing the SIGBUS (line 653 in unpack-objects.c) and suggest potential alignment issues with the buffer declaration. The workaround of overaligning the buffer prevents the crash, though the reporter is unsure if this constitutes a proper fix.

Key technical details include: the crash occurs during `htonl(PACK_SIGNATURE)` assignment, the affected Git version (2.48.1.262), and the specific platform configuration (sparc64 with clang 19.1.4 and glibc 2.40). This appears to be a platform-specific alignment sensitivity that only manifests with clang's code generation. The report is thorough with system diagnostics but lacks a minimal reproduction case or bisect information to pinpoint when the issue was introduced.
