Maintainer response to platform compatibility fix for sign-compare warnings in connect.c. Junio Hamano acknowledges Mike Hommey's patch that addresses -Wsign-compare warnings by changing loop variables and function parameters from `int` to `size_t` where they interact with size-related operations. While noting that some of these changes might be overkill" for cases like the packet_reader object where sizes won't exceed practical limits, Hamano approves the changes as being directionally correct and having limited impact. He expresses that while he doesn't consider -Wsign-compare cleanliness particularly valuable relative to code churn, he finds this specific change acceptable and queues it for inclusion. The response confirms the uncontested nature of the core type safety changes while providing maintainer perspective on the tradeoffs involved in such warning-cleanup patches.
