This is part 4/6 of a series standardizing help text output behavior across Git commands. The patch converts `usage_with_options()` calls in 14 builtin commands to use the new `show_usage_with_options_if_asked()` helper, ensuring help text goes to stdout rather than stderr when users request it with `-h`.

The changes are mechanical but thorough, touching commands ranging from `git am` to `git rebase`. Each conversion follows the same pattern: replacing direct `usage_with_options()` calls with the new helper function. The patch preserves existing test coverage, including a special case in t7600 that verifies `git merge -h` works even with a corrupt index file.

Junio Hamano (the maintainer) has signed off on this patch, and Jeff King has acked it, indicating the technical approach is sound. This continues the series' goal of making help text behavior consistent while maintaining backward compatibility with exit codes and existing test expectations. The changes are low-risk since they don't alter functionality - just the output stream for help text.
