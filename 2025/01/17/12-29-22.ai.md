This is part 2 of a test infrastructure modernization series converting unit tests to use the Clar framework, following up on the core infrastructure changes from part 1. The series is being mentored by Patrick Steinhardt.

The current patch set (v3) contains the actual test conversions that were previously prepared for by the infrastructure work. It converts three test files from the old format to Clar:
- t-mem-pool.c → u-mem-pool.c
- t-prio-queue.c → u-prio-queue.c  
- t-reftable-tree.c → u-reftable-tree.c

Each conversion appears as a separate commit, showing the complete rewrite from old to new test format. The changes are mechanical deletions of old test files and additions of new Clar-based versions, with corresponding updates to the build system (Makefile and meson.build).

The first patch from v2 (handling dashes in filenames) has been improved with a more technical commit message explaining why dashes in function names are invalid in C and how the script now handles this conversion. The v3 cover letter notes only minor commit message fixes compared to v2.

Key technical details for future reference:
- Test files follow new u-*.c naming convention
- Build system handles both old and new test locations during transition
- Function name extraction now properly converts dashes to underscores
- Each test maintains equivalent coverage but in Clar framework format
- Changes affect memory pool, priority queue, and reftable tree tests

The series appears technically sound with thorough test coverage, though there remains some commit message refinement requested by reviewers (particularly around terminology like "scripts" vs "compiled tests"). The mentor has confirmed the technical approach is correct.
