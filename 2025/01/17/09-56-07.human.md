**Meson build system update for git-subtree**

This is the final patch in a 3-part series adding Meson build support for git-subtree. The patch completes the work started in earlier patches by fully wiring up the subtree command in Meson.

The key changes include:
1. Creating a new `contrib/subtree/meson.build` file that handles building the subtree script, its manpages, HTML docs, and running its test suite
2. Moving the `contrib/` subdirectory inclusion in the main Meson build file to after documentation building, which is needed for proper dependency ordering
3. Maintaining feature parity with the Makefile build by including all the command, documentation, and test infrastructure

The implementation follows established Meson patterns seen elsewhere in the codebase, using custom targets for script generation and documentation building. The test suite is properly integrated with the same timeout and environment handling used for core Git tests.

This appears to be a straightforward mechanical conversion that completes the subtree's transition to dual-build-system support. The changes are well-contained and consistent with the project's ongoing Meson adoption. With this patch, the subtree command should now build and test correctly under both Make and Meson build systems.
