This is a refactoring patch in Usman Akinyemi's OS version capability series. It extracts the uname(2) system call handling from builtin/bugreport.c into a new get_uname_info() function in version.c, making this functionality reusable for the upcoming OS version protocol capability.

The patch moves the uname(2) system call and error handling into a standalone function that takes a strbuf parameter, returning 0 on success or -1 on failure. The implementation preserves all existing behavior including error message formatting and the same output format (sysname, release, version, and machine fields concatenated with spaces). The function is properly documented in version.h with its return value semantics.

This is a straightforward code reorganization with no behavior changes, serving as preparation for patch 3/6 which will use this function to implement the OS version protocol capability. The refactoring follows good practices by:
1. Maintaining identical output format
2. Preserving error handling behavior
3. Adding clear documentation
4. Using strbuf for output consistency

The changes touch three files:
- builtin/bugreport.c (removes direct uname(2) call)
- version.c (adds new function)
- version.h (adds declaration and docs)

This is a clean preparatory step that enables the subsequent protocol capability work while improving code organization. The patch has been reviewed by Christian Couder as noted in the sign-off.
