This is part 4/6 of a series standardizing help text output behavior across Git commands. The patch converts `usage_with_options()` calls in 14 builtin commands to use the new `show_usage_with_options_if_asked()` helper, ensuring help text goes to stdout rather than stderr when explicitly requested with `-h`.

The changes are mechanical replacements following the pattern from earlier patches in the series, affecting commands like `git am`, `git branch`, `git commit`, and `git merge`. The patch maintains the existing exit code 129 behavior for compatibility. A test in t7600 for `git merge -h` with a corrupt index is preserved since it specifically tests error handling, though similar coverage exists in t0012.

Jeff King has reviewed and acked the changes, and Junio Hamano (the maintainer) is signing off on this implementation. The patch demonstrates the series' approach working at scale across multiple commands while maintaining backward compatibility. The remaining patches in the series will handle additional command conversions and special cases.
