This is a refactoring patch in Usman Akinyemi's series implementing OS version capability in Git's protocol. It's the third of six patches in v2 of the series, which has already received maintainer approval.

The patch extends the `get_uname_info()` function to support both full OS information and just the OS name, controlled by a new "full" flag parameter. This prepares for upcoming changes where the protocol will sometimes need just the basic OS name rather than full system details. The commit message notes this might need further refactoring if future work adds an `osVersion.format` configuration.

Junio Hamano notes in his reply that this is a good separation from the previous refactoring work. The change is straightforward - it doesn't introduce new functionality but makes the existing code more flexible for the protocol work coming in later patches. This kind of preparatory refactoring is typical in well-structured patch series, making each logical change easier to review.
