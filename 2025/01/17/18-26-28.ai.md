This is a refactoring patch that extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` function, as part of Usman Akinyemi's OS version capability series. The patch moves the existing character replacement logic (converting non-printable ASCII to dots) into a reusable function while maintaining identical behavior.

Junio Hamano provides several technical review comments on the implementation details: suggests using `isprint()` from `<sane-ctype.h>` instead of direct character comparisons, notes inconsistent comment formatting, and questions whether the TODO about collapsing consecutive dots should remain. He also raises (but doesn't insist on) whether empty/dot-only results should be specially handled, though concludes this is likely the caller's responsibility.

The changes include switching to `strbuf_detach()` for proper memory management and keeping the function static since it's only used locally in version.c at this point. This foundational refactoring enables later patches in the series to reuse the sanitization logic for OS version strings while maintaining protocol safety requirements. The review feedback indicates the core approach is sound but suggests minor implementation polish before finalization.
