This is a test modernization patch converting the priority queue unit test to the Clar framework, part of an ongoing series to update Git's test infrastructure.

The patch converts t-prio-queue.c to u-prio-queue.c, following the new naming convention for unit tests. The conversion maintains all the original test cases but rewrites them using Clar's assertion macros (cl_assert, cl_assert_equal_i) instead of the previous test-lib.h helpers. The test logic remains fundamentally the same, with the same five test scenarios: basic input handling, mixed put/get operations, empty queue behavior, LIFO stack mode, and reversed stack behavior.

A notable technical change is the update of variable `j` from `int` to `size_t` to match `result_size`'s type, avoiding signed/unsigned comparison warnings. The test cases are now organized as separate Clar test functions (test_prio_queue__basic, test_prio_queue__mixed, etc.) rather than using the TEST macro framework.

The patch includes the necessary build system updates in both Makefile and meson.build to remove the old test and add the new one. This is the third patch in a 4-part series modernizing unit tests, with Patrick Steinhardt mentoring Seyi Kuforiji through the conversion process. The conversion appears thorough and maintains equivalent test coverage while adopting the new framework's conventions.
