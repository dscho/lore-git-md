This is part of a test infrastructure modernization series converting unit tests to the Clar framework. The patch specifically handles filename conversion for test files containing dashes.

The patch fixes a small but important technical detail in the test generation script. When unit test files contain dashes in their names (like `u-mem-pool.c`), the script needs to convert those to underscores when looking for test functions, since C doesn't allow dashes in function names. The change is minimal - just a one-line addition to the script that performs this conversion.

This is the first of four patches in v3 of the series, which has already gone through several rounds of review. The mentor (Patrick Steinhardt) has confirmed the technical soundness of the approach, though there are still some minor wording improvements being discussed in the commit messages. The patch appears straightforward and well-contained, addressing a clear technical requirement for the test conversion effort.
