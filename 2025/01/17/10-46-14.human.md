Refactoring patch for OS version capability series. This is the second patch in a 6-part series introducing OS version reporting in Git's protocol, focusing on code reorganization to support the new feature.

The patch extracts the uname(2) system call handling from builtin/bugreport.c into a new get_uname_info() function in version.c, making this system information gathering reusable. The implementation maintains identical behavior - it still reports the system name, release, version, and machine fields, and handles errors the same way. This refactoring enables the subsequent patches to use the same system information for the new OS version protocol capability without duplicating code.

The changes are straightforward: the uname handling moves to version.c with appropriate error handling, while bugreport.c now simply delegates to the new function. A header declaration is added to version.h with clear documentation of the function's contract. This appears to be a clean-up preparatory to the actual feature implementation in later patches, following good practice of separating refactoring from behavior changes.
