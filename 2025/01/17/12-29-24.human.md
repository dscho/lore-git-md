Test modernization: Part 2/4 of a series converting unit tests to the Clar framework, focusing on memory pool tests.

This patch converts the memory pool test from the old test-lib.h format to the new Clar framework, following the naming conventions established in the series (t-*.c → u-*.c). The conversion maintains the same test coverage while using Clar's assertion macros (cl_assert and cl_assert_equal_i). The test verifies memory pool allocation behavior with both large (1MB) and small (1 byte) block sizes, checking that allocated memory is properly zeroed and pool internals are correctly maintained.

The changes are mechanical but thorough: the old test file is deleted, a new one created with Clar-style assertions, and both Makefile and meson.build are updated to reference the new test location. The test logic remains equivalent, just reorganized to fit Clar's structure with standalone test functions rather than the previous TEST macro approach.

This appears to be a straightforward conversion that follows the patterns established in earlier patches of the series. The commit message could be more detailed about what specifically changed in the test organization (like the move from cmd_main to separate test functions), but the technical implementation looks correct. As part of an ongoing mentoring project with Patrick Steinhardt, this continues the test infrastructure modernization effort that has already addressed previous rounds of feedback.
