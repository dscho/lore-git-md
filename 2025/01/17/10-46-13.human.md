This is a refactoring patch that extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` function. It's the first in a 6-part series adding OS version capability to Git's protocol.

A TODO comment notes potential future work around consecutive non-printable characters.

This foundational change enables the subsequent patches in the series to reuse this sanitization logic for OS version strings.
