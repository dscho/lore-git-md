This is part 3 of a 5-patch series continuing the `the_repository` removal effort, focusing on pack-writing functionality. The patch converts `write_idx_file()` to take an explicit `hash_algo` parameter instead of using the global `the_hash_algo`, propagating this change through its callers in `fast-import`, `index-pack`, `pack-objects`, and `bulk-checkin`.

The change follows the series' established pattern of incrementally removing global variable usage by pushing the dependency up to callers. While some callers could theoretically provide a more specific hash algorithm, the patch conservatively passes `the_hash_algo` to maintain compatibility, leaving further refinement for future work. The patch also updates `stage_tmp_packfiles()` in the same file since it calls `write_idx_file()`.

This is a mechanical refactoring with no behavior change, part of the long-running effort to eliminate global state from Git's codebase. The changes are straightforward and well-contained, touching only pack-writing functionality while maintaining the existing behavior. The patch appears well-tested, with modifications spanning multiple pack-related commands.
