Documentation patch finalizing the CLI precedence rules clarification.

This is Junio Hamano's final approval to merge the documentation patch that explicitly states Git's precedence rules (command-line options override both environment variables and config settings). The patch had already received positive feedback from Brian Carlson, who noted its value for both end users and tool developers. 

The thread began with a discussion about `git grep` options but expanded into documenting the universal principle that command-line arguments take highest precedence, followed by environment variables, then config settings. The documentation includes concrete examples like `git tag -u` overriding `user.signingKey` and `git commit --author` overriding both `GIT_AUTHOR_NAME` and `user.name`.

With this final acknowledgment from the maintainer, the earlier typo fix from Eric Sunshine, and no further objections, the documentation update is now ready to be merged into the codebase. This establishes authoritative guidance about Git's CLI behavior that will help users understand how different configuration layers interact.
