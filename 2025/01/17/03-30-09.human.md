Bug report: Git crashes with SIGBUS on sparc64 during pull operations when built with clang.

Koakuma reports a reproducible crash in `unpack-objects` when performing a `git pull` on sparc64 systems when Git is compiled with clang (the issue doesn't manifest with GCC). The crash occurs specifically when handling the PACK_SIGNATURE in `builtin/unpack-objects.c`, suggesting a potential memory alignment issue. The reporter notes that manually overaligning the buffer declaration appears to prevent the crash, though they're unsure if this would be the proper fix.

The crash manifests as a SIGBUS (signal 10) with the error "unpack-objects died of signal 10". The reporter has provided detailed system information including Git version (2.48.1.262), clang version (19.1.4), and sparc64 architecture details. This appears to be a legitimate platform-specific bug that warrants investigation by the Git maintainers, particularly those familiar with sparc64 architecture quirks and clang compilation behavior. The report is well-documented with reproduction steps and crash analysis, making it would be relatively straightforward starting point for debugging.
