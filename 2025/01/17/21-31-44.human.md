This is part of the ongoing effort to standardize help text output behavior across Git commands. The patch introduces a new helper function `show_usage_with_options_if_asked()` that encapsulates the common pattern where commands check for "-h" and call `usage_with_options()`.

The commit message notes this exit code may be revisited later since it's arguably incorrect behavior when successfully showing requested help text.
