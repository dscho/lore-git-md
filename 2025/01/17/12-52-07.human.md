Bugfix for sparc64 SIGBUS crash in `git unpack-objects` and `git index-pack`. This is a follow-up to Jeff King's initial analysis of the alignment issue that causes crashes during `git pull` operations on sparc64 systems when compiled with clang. The patch series refactors the problematic code that writes to a `struct pack_header` through an unaligned buffer.

The main fix (patch 2/3) replaces the unsafe struct-based writes with direct buffer manipulation using `put_be32()`, eliminating the alignment assumptions that trigger the SIGBUS. King notes this same issue likely exists in `index-pack` as well, though the current series only addresses `unpack-objects`. The series also includes some associated cleanups - factoring out pack header parsing (1/3) and using `skip_prefix()` to avoid magic numbers (3/3).

While the fix appears solid, King expresses some uncertainty about whether it fully resolves the issue, wondering if unaligned reads might still cause problems on some platforms. The changes demonstrate careful consideration of both the immediate alignment issue and broader code quality improvements, though platform-specific testing would be needed to confirm the fix works in all cases.
