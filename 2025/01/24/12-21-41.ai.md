Feature implementation for OS version advertisement in Git protocol.

This is the final patch in Usman Akinyemi's v3 series adding OS version capability to Git's protocol. The patch implements the core functionality for advertising OS versions between clients and servers, building on the architectural decisions settled earlier in the thread (security model, platform handling, string sanitization).

Key technical elements:
- New `os-version` protocol capability that exchanges sanitized OS names (from `uname(2)`)
- `transfer.advertiseOSVersion` config option (default true) for privacy control
- New `os_version_sanitized()` and `advertise_os_version()` functions in version.c
- Test infrastructure updates including Windows-specific test skipping
- Documentation updates in config/transfer.txt and gitprotocol-v2.txt

The implementation follows the agreed approach of:
1. Keeping platform-specific code in `compat/`
2. Using `isprint()` sanitization via new `redact_non_printables()` helper
3. Maintaining separation from the `agent` capability
4. Preserving test coverage while improving isolation

Windows testing remains disabled due to discrepancies between `uname(1)` and `uname(2)` outputs, as noted in the commit message. The patch includes Christian Couder's Mentored-by tag, indicating review approval of the implementation approach.

This completes all technical work for the feature, with the remaining open question being whether the functionality's benefits justify inclusion in Git (as previously raised by Junio Hamano and Randall Becker). The implementation itself appears thorough, with comprehensive tests and documentation matching the established protocol patterns.
