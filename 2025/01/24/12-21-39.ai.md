This is a refactoring patch in Usman Akinyemi's series adding OS version capability to Git's protocol. The patch modifies the `get_uname_info()` function to optionally return just the OS name rather than full system details, preparing for the OS version reporting feature while maintaining existing behavior for bugreport.

The key change adds a `full` parameter to `get_uname_info()` that controls whether it outputs the complete uname string (sysname, release, version, machine) or just the OS name (sysname). The bugreport tool continues using full output, while future protocol code will use the abbreviated form. The implementation preserves the existing error handling and strbuf interface.

This is a straightforward mechanical change that:
1. Modifies the function signature in version.h
2. Updates the implementation in version.c to conditionally format output
3. Adjusts the single caller in builtin/bugreport.c to pass the new parameter

The patch maintains backward compatibility while enabling the planned OS version reporting feature. It follows the series' established pattern of refactoring existing components to support the new capability.
