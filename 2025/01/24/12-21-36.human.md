This is a preparatory refactoring patch in Usman Akinyemi's series adding OS version reporting to Git's protocol. The patch simplifies the character sanitization logic in `version.c` by replacing manual ASCII range checks with the standard `isprint()` function, while explicitly preserving the space character handling that was part of the original implementation.

The change makes the code more readable and maintainable by using a standard library function rather than hardcoded ASCII values. The patch maintains identical behavior to the original by still converting spaces to periods, just with clearer intent. This is part of the broader effort to safely handle version strings in the protocol capability system.

The patch appears straightforward and well-contained, with a clear commit message explaining both the change and the rationale for keeping the space character special case.
