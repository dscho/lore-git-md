This is the second patch in Peter Oliver's series to standardize Perl version requirements across Git's build systems. It fixes a version detection quirk in the Meson build system where older Meson versions (pre-1.7.0) would incorrectly parse Perl's version string (e.g., interpreting "v5.26.0" as just "26"). The patch implements a dual-path solution: for Meson 1.5.0+, it uses the more reliable `-V:version` flag for unambiguous parsing, while falling back to the simpler version check for older Meson versions. This maintains compatibility while ensuring the correct 5.26.0 requirement is enforced.

The change is well-contained to the Meson.build file and follows the pattern established in the first patch of the series. The commit message clearly explains the technical issue and rationale for the solution. With both patches in the series now addressing all identified version alignment and detection issues, this appears to complete the technical work needed for consistent Perl version handling across build systems.
