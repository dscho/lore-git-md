Refactoring patch in the OS version capability series. This is patch 3/6 in v3 of Usman Akinyemi's series to add OS version reporting to Git's protocol. The patch extracts the uname(2) system call handling from builtin/bugreport.c into a new get_uname_info() function in version.c, making it reusable for the OS version feature.

The change is straightforward - it moves the existing uname handling code into a new function while maintaining the same behavior. The function returns 0 on success and -1 on error, with error messages written to the provided strbuf. Christian Couder mentored this refactoring.

This appears to be a clean, mechanical refactoring that prepares for the OS version functionality by making the uname handling reusable. The patch follows the series' architectural direction of consolidating platform-specific code. Since this is purely a code movement with no behavior change, it's unlikely to be controversial, though reviewers may check that the error handling remains correct.
