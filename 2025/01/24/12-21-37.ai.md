Refactoring patch in the OS version capability series.

This is the second patch in Usman Akinyemi's v3 series adding OS version reporting to Git's protocol. It refactors string sanitization code in preparation for reusing it in later patches that will handle OS version strings. The patch extracts the character sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` helper function, which replaces non-printable ASCII characters and spaces with dots. The implementation now uses `strbuf_detach()` for cleaner memory management.

The changes align with the series' established security approach of using `isprint()` for sanitization, as noted in the thread summary. This is a straightforward code reorganization with no behavior changes, maintaining the existing sanitization rules while making the functionality reusable. The patch has been reviewed by Christian Couder as indicated by the Mentored-by tag.

Key technical details for future reference:
- New static function `redact_non_printables()` in version.c`
- Uses `isprint()` for character validation (consistent with series' security model)
- Preserves space character replacement with dots (existing behavior)
- Changes memory management from direct buffer access to `strbuf_detach()`
- Prepares for reuse in OS version string handling in subsequent patches
