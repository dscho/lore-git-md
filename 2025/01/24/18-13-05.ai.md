Refactoring patch in the OS version capability series, focusing on string sanitization cleanup.

This is a small but meaningful refactoring in Usman Akinyemi's OS version capability series, changing how Git sanitizes the user-agent string. The patch replaces manual ASCII range checks with the standard `isprint()` function for better readability, while explicitly preserving the space character handling that was implicit in the original version. 

The change is technically sound - it's a straightforward replacement of custom logic with a standard library function, which makes the code more maintainable and self-documenting. The patch maintains identical behavior by explicitly checking for spaces separately, since `isprint()` typically considers space (0x20) as printable but the original code treated it as needing sanitization.

This appears as a preparatory cleanup in the series, separating a mechanical improvement from the more substantive OS version capability work. The change has already been reviewed by Christian Couder (as noted by the Mentored-by tag) and receives explicit approval from Junio Hamano, who calls it "Nicely done as a separate step." The approval suggests this refactoring meets Git's code quality standards and won't be a point of contention in the ongoing discussion about the feature's value proposition.
