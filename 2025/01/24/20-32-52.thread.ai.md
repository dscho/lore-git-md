Thread summary:

Feature proposal to extend credential helper authtype support across multiple platforms, initiated by M Hickford. Currently only git-credential-cache implements authtype capability; this would add it to git-credential-osxkeychain (macOS), git-credential-libsecret (Linux), and git-credential-wincred (Windows). The authtype field stores non-confidential authentication type information while keeping credentials protected, with primary use case being bearer token support. Existing test infrastructure in t0303-credential-external.sh could be extended with helper_test_authtype component. Implementation would modify platform-specific helper implementations (wincred.c, osxkeychain.c, libsecret.c) following credential-cache.c's pattern. Suggested as a #leftoverbits microproject, indicating modest scope. Key technical aspects: maintaining security model separation between non-confidential authtype and protected credentials, while enabling cross-platform support for authentication type metadata storage alongside credentials.
