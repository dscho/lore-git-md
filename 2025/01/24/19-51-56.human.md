Bugfix follow-up regarding parallel fetch credential prompts. Randall Becker responds to a bug where parallel fetch operations (`git fetch --jobs=10`) repeatedly prompt for SSH key credentials instead of using the SSH agent's cache. He clarifies that Git itself doesn't handle SSH passphrase prompts - that's the SSH agent's job. The suggested workaround is to first add the SSH key to the ssh-agent (which will prompt for the passphrase once), after which Git operations should work without further prompts. This doesn't address the root cause of why parallel workers aren't properly sharing the credential cache, but provides a practical solution for affected users. The response maintains the original bug's context while offering immediate relief, though the underlying parallel fetch credential management issue remains open.
