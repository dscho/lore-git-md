This is a follow-up discussion about the proposed third version of the name hash algorithm for pack-objects delta compression, part of Derrick Stolee's ongoing series to improve Git's delta selection. The thread context shows this was previously debated, with Taylor Blau raising concerns about Version 3's mixed performance impact and unclear heuristics.

In this email, Stolee acknowledges Blau's key point that Version 3 lacks clear criteria for when it would outperform Version 2, despite showing some improvements in specific repositories. The discussion reveals consensus forming around dropping Version 3 entirely to avoid long-term maintenance burden, especially since Version 2 already provides significant improvements over the current behavior. Stolee agrees with focusing on Version 2 as the primary enhancement, leaving open the possibility of revisiting alternative hashing approaches later if clearer selection criteria emerge.

The exchange represents the final resolution of a design question in this series, with both contributors aligning on simplifying the patch set by removing the less clearly beneficial third algorithm variant. This leaves the series in a stronger position for final review, having addressed all major technical concerns.
