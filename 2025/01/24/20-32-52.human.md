This is a feature proposal for credential helpers, specifically requesting support for the 'authtype' capability in three credential helpers (osxkeychain, libsecret, and wincred) that currently only exists in the credential-cache helper.

The author notes this would be particularly useful for handling bearer tokens, where the authentication type needs to be stored alongside the credential itself. They provide clear technical specifics about what needs to be implemented (storing both authtype and credential attributes) and suggest using existing test infrastructure (t0303-credential-external.sh) for verification.

The proposal is framed as a potential "leftoverbits" microproject - a category of small, self-contained improvements suitable for new contributors. The author includes helpful links to all relevant implementation files and testing infrastructure, making this a well-documented and actionable request. While not a patch itself, this email serves as a clear call for someone to implement this missing functionality across multiple credential helpers.
