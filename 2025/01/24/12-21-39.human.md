Refactoring patch for OS version reporting feature. This is patch 4/6 in Usman Akinyemi's v3 series implementing configurable OS version reporting in Git's protocol.

The patch modifies the `get_uname_info()` function to optionally return just the OS name rather than full system details, preparing it for use in the upcoming OS version reporting feature. The change adds a `full` parameter that toggles between complete uname output (used by bugreport) and just the sysname (needed for protocol reporting). All existing callers are updated to pass `1` to maintain current behavior.

This is a straightforward refactoring that cleanly separates concerns while preserving existing functionality. The change is well-contained, touching only three files that handle version information. The commit message clearly explains the motivation (upcoming use in protocol reporting) and potential future evolution (if `osVersion.format` is added later).
