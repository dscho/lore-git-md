CI/build system patch discussion in Patrick Steinhardt's modernization series. This is a follow-up to patch 3/10 about making GitHub Actions container jobs run rootless.

Christian Couder provides a minor documentation suggestion for Patrick's patch that makes containerized GitHub Actions jobs run as non-root users. Christian notes it might be helpful to explicitly mention the required packages ('sudo' and 'shadow-utils') in the commit message, though considers this a small enough point that it doesn't warrant a reroll.

The suggestion is purely about improving documentation clarity - it doesn't propose any functional changes to the patch's approach of creating a test user to avoid root privileges in CI containers. This continues the series' theme of CI modernization while maintaining the technical solution Patrick implemented. The thread shows the patch is otherwise technically sound, with Christian's input being a minor polish suggestion rather than a substantive critique.
