Build system patch addressing Perl version detection compatibility across Meson versions. This is the second patch in Peter Oliver's series standardizing Perl requirements between build systems, following up on the first patch that aligned the version requirement to 5.26.0.

The patch implements a dual-path detection strategy to handle version parsing differences between Meson versions. For Meson 1.5.0+, it uses the more reliable `-V:version` flag which outputs version information unambiguously. For older Meson versions (pre-1.5.0), it falls back to parsing `--version` output, which those versions incorrectly interpret as major version only (e.g., reading "5.26.0" as just "26"). The change maintains the same 5.26.0 requirement established in the first patch while working around Meson's parsing quirks.

Key technical details include:
- Conditional logic based on `meson.version().version_compare()`
- Different `find_program()` invocations for old/new Meson versions
- The `version_argument: '-V:version'` parameter for accurate parsing
- Preservation of existing `perl_required` and `program_path` behavior

The patch cleanly handles the transition period until Meson 1.7.0's proper version parsing is widely available, making it a robust solution. It completes the series' goal of consistent Perl version handling across build systems while accounting for real-world version constraints.
