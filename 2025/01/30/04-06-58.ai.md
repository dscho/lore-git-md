Test infrastructure improvement in the packed-refs validation series.

This is the first patch in v2 of a series addressing packed-refs validation issues. The patch focuses on test reliability by wrapping test cases in subshells to ensure proper working directory cleanup, particularly important for Windows compatibility. The change follows feedback from Patrick Steinhardt and Karthik Nayak about test infrastructure robustness.

The patch makes mechanical changes to t/t0602-reffiles-fsck.sh, converting all test cases to use subshells for directory changes. This prevents test pollution when tests fail mid-execution, as the subshell automatically restores the original working directory. The tests themselves continue to verify ref name and content validation, including checks for invalid refnames, malformed ref contents, and symlink handling.

The changes are purely structural - no test logic is altered, just the execution environment. This demonstrates good attention to test reliability while maintaining all existing test coverage for the ref validation functionality being developed in the series. The patch appears well-scoped and follows established patterns for test cleanup.
