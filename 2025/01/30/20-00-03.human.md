This is an announcement for Tig 2.5.11, a new release of the ncurses-based Git repository browser. The release includes several bugfixes and improvements to the text-mode interface.

The update addresses multiple small but noticeable quality-of-life issues in Tig's interface. Key fixes include better handling of `diff.noprefix` configurations, improved Ctrl-C behavior in the prompt, and proper display of dates in the refs view. The release also brings several UI enhancements like preserving cursor position when toggling filters, making error messages more visible, and allowing different colors for reference types.

Notable changes include updating the Unicode support library utf8proc to version 2.10.0 (supporting Unicode 16) and showing committer information by default in the date column. The release also refines the refs view behavior, now showing stash, notes and prefetch references only when explicitly requested with `tig refs --all`.

The diffstat shows widespread but relatively shallow changes across the codebase, with most files receiving minor tweaks. The bulk of the changes come from updating the utf8proc Unicode data file. The release appears to be a solid incremental update with focused improvements rather than major new features.
