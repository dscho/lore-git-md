Test infrastructure patch converting the decorate test to Clar framework, part of Patrick Steinhardt's mentored unit test modernization series. This second patch in the 4-part series follows the same pattern as the first hashmap conversion, rewriting the example decorate test to use Clar's assertion style and standalone test functions.

The changes include:
- Renaming t-example-decorate.c to u-example-decorate.c
- Converting test cases to Clar's cl_assert* functions (cl_assert, cl_assert_equal_i)
- Splitting the test into discrete functions (test_example_decorate__add, __readd, __lookup, __loop)
- Adding initialize/cleanup functions for test state management
- Updating build files (Makefile and meson.build) to reference the new test location

The test coverage remains equivalent, verifying decorate.c functionality including:
- Adding decorations (both NULL and non-NULL values)
- Re-adding objects and checking return values
- Lookup behavior for present/absent objects
- Iteration through all entries

Like the first patch, this appears to be a straightforward mechanical conversion maintaining all existing test coverage while adopting the new framework's conventions. The patch follows the established pattern from the series and includes the required build system updates.
