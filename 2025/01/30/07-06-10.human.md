This is a follow-up clarification in the Meson build system refactoring thread, specifically about patch 1/11 which deals with GIT_EXEC_PATH handling when runtime prefix is enabled.

Patrick Steinhardt confirms Justin Tobler's understanding of the issue: when runtime prefix is enabled, GIT_EXEC_PATH needs to be relative to allow proper binary location, but the Meson build was incorrectly always making it absolute. This matches the Makefile behavior where the path is conditional (absolute without runtime prefix, relative with it). The confirmation comes after Justin pointed out a typo in the original commit message ("correcty" → "correctly") which was already fixed.

The exchange shows good understanding between the contributors on this technical build system detail, with Patrick validating Justin's analysis of how the relative path affects prefix setup and fallback behavior. This is a minor but important clarification in what appears to be a well-coordinated refactoring effort.
