The test suite is expanded with new cases verifying that reinitialization preserves the original object format regardless of `GIT_DEFAULT_HASH` setting, mirroring the test structure from the ref format fix.

The changes touch the same sensitive initialization paths in `setup.c` and follow the same pattern as the previous patch - adding appropriate version/hash checks while maintaining the existing format mismatch detection. The test coverage demonstrates the fix works for both SHA-1 and SHA-256 cases. This completes the series' goal of preventing repository corruption when reinitializing with different format environment variables, particularly important for CI systems that may cache repositories between runs.
