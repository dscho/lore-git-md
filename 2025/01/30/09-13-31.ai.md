This is the first patch in a 4-part series converting Git's unit tests to the Clar framework, focusing on the hashmap test. The patch rewrites `t-hashmap.c` as `u-hashmap.c` with Clar-style assertions (`cl_assert*` functions) while preserving all test functionality. Key changes include converting test cases into standalone Clar test functions (like `test_hashmap__replace_case_sensitive`) and updating build files (Makefile and meson.build) to reference the new test location. The patch maintains all existing test coverage for hashmap operations (put/get/remove/iterate) in both case-sensitive and case-insensitive modes, though the implementation shifts from custom test helpers to Clar's assertion framework. This appears to be a straightforward mechanical conversion as part of the broader test modernization effort mentored by Patrick Steinhardt.
