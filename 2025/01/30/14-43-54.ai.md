This is a build system patch fixing OpenSSL fallback behavior in the Meson build system, part of Patrick Steinhardt's larger refactoring series (v2 02/13). The patch addresses a specific issue where OpenSSL fallback to a subproject wrapper wasn't working when the HTTPS backend was set to 'auto'. The fix modifies the OpenSSL dependency declaration to properly allow fallback in both required and auto cases, while also correcting the backend reporting when no HTTPS backend is selected. The changes are particularly relevant for Windows builds where OpenSSL often isn't system-provided. The diff shows the careful modification of the dependency call to add the fallback condition while maintaining the existing static library preference. This appears to be a straightforward fix that aligns with the series' goal of improving build system reliability, especially for Windows platforms.
