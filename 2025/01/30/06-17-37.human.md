This is a cover letter for a 2-patch bugfix series addressing memory leaks detected by Meson builds. The series follows up on earlier discussion where Jeff King and others helped diagnose why these leaks only appear in Meson builds (due to path length variations in test directories).

The first patch fixes a Unix socket leak in credential-cache operations when `chdir()` fails, where the original directory path wasn't being freed. The second patch addresses a scalar.c leak where the result of `remote_default_branch()` wasn't freed. Both fixes are straightforward - adding appropriate cleanup for allocated memory.

The v2 updates clarify why the leaks only appear under certain conditions (long pathnames for the Unix socket case) and correct the Meson configuration syntax to use `-Db_sanitize=leak`. The thread shows these fixes have already received positive feedback, with the first patch approved by Junio Hamano. The series demonstrates Meson's value in catching resource leaks that Makefile builds miss, while keeping the changes minimal (6 lines added total).
