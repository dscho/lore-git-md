This is a refactoring patch in Patrick Steinhardt's ongoing Meson build system series (11/13). It fixes a naming collision where the `git` variable was being overwritten in multiple places - once for the external Git executable and again for the built version. The patch renames the built executable variable to `git_builtin` to avoid this conflict, allowing removal of a redundant `find_program('git')` call in the documentation build configuration.

The change is straightforward and maintains the series' pattern of cleaning up the build system's internal structure. It touches only two files with minimal changes (3 lines added, 4 removed), showing careful attention to not introduce new complexity while solving the naming issue. This continues the series' theme of methodical build system improvements, though it's a smaller change compared to some of the more substantial architectural refactorings earlier in the series.
