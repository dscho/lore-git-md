This is a maintainer approval for the memory leak fixes series.

Junio C Hamano confirms he will queue both patches in the series that fix memory leaks detected by Meson builds. The first patch addresses a Unix socket handling issue in credential-cache operations, while the second fixes a missing free in scalar.c's clone command. 

The series has gone through technical validation from Jeff King and Patrick Steinhardt, with discussion establishing that these are real leaks that Meson's stricter detection caught where Makefile builds missed them. The fixes use standard cleanup patterns and maintain minimal code changes (totaling just 9 lines added and 3 deleted across both patches).

While the thread initially focused on the specific leaks, it has expanded to serve as a practical reference for Meson usage in Git development, covering configuration (`-Db_sanitize=leak`), test execution flags (`--test-args=-vix`), and debugging workflows. The patches are now maintainer-approved and ready for inclusion, demonstrating Meson's value in catching resource management issues that traditional builds might miss.
