This is a follow-up in a resolved thread about Git's runtime configuration paths. The original issue (Git not respecting `PREFIX` for config locations) was determined to be a documentation discrepancy between progit2/Git Internals and Git's actual behavior, with `GIT_CONFIG_SYSTEM` being the correct runtime mechanism as confirmed in the manpages.

Ben Knoble chimes in to support updating the progit2 documentation, noting its value as a resource for less experienced users. The technical solution (`GIT_CONFIG_SYSTEM`) is already properly documented in Git's own manpages, so this is purely about external documentation accuracy. The thread shows consensus on the technical resolution, with this email adding weight to the case for updating progit2's materials. No code changes are needed on the Git side.
