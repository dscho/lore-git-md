Tig 2.5.11 has been released, bringing a set of maintenance updates to this popular ncurses-based Git repository browser. The release focuses on improving the user experience with several targeted fixes: better cursor position handling when toggling filters, proper support for Git's `--no-prefix` option, and clearer error visibility. 

Key changes include updating the utf8proc Unicode handling library to version 2.10.0 for improved Unicode 16 support, switching the default date column display to show committer dates, and refining the refs view behavior when using `--all`. Thomas Koutcher contributed most of the changes, with the diffstat showing widespread but shallow modifications across the codebase - most notably in the utf8proc compatibility files and diff/refs handling logic. The release follows Tig's standard announcement format, providing a complete change list, download information, and full diffstat for transparency.
