Tig 2.5.11 release announcement - maintenance update for the ncurses-based Git repository browser. Primary changes focus on UI improvements and bugfixes across multiple interface components. Key technical updates include: cursor position preservation fixes when toggling filters, proper handling of Git's --no-prefix option, enhanced error visibility, and default display of committer dates in date column. The release incorporates utf8proc 2.10.0 for improved Unicode 16 support, with corresponding updates to compatibility files. Ref view behavior modified to adjust which references appear when using --all. Changes are widespread but shallow across codebase, with most significant modifications in utf8proc integration and diff/refs handling logic. Thomas Koutcher is primary contributor for this release. Standard release format includes detailed change list, download locations, and complete diffstat.
