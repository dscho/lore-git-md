Build system refactoring series (v2) covering Meson improvements and Windows-specific fixes.

This is a 13-patch series from Patrick Steinhardt that builds on his previous Meson build system refactoring work. The v2 iteration incorporates feedback and adds several new fixes, particularly around Windows compatibility. Key changes in this version include:

1. A complete rework of PATH handling to be more targeted (now only prepending system-specific paths rather than all tool directories)
2. Fixes for OpenSSL fallback behavior on Windows
3. A new patch to address linker OOM issues in GitLab CI on Windows
4. Continued curl dependency consolidation (now properly scoped to only where needed)
5. Various smaller build system cleanups and optimizations

The series maintains all the structural improvements from v1 while addressing platform-specific edge cases. Notable technical changes include:
- Proper GIT_EXEC_PATH resolution matching Makefile behavior
- Windows-specific OpenSSL fallback fixes
- Elimination of duplicate main() definitions in test tools
- Curl dependency consolidation into libgit_curl
- Version library elimination
- More robust PATH handling (especially for Windows)
- Documentation build tool resolution fixes
- GitLab CI job limits to prevent Windows linker OOM

The patches show careful attention to both build system correctness and Windows compatibility, with each change focused and well-explained. The v2 revisions demonstrate responsiveness to review feedback, particularly around PATH handling and curl dependency scoping. The series appears ready for final review, with the Windows-specific fixes being particularly valuable for that platform's users.
