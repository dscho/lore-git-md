This is a bugfix series addressing issues with repository reinitialization when the ref or object formats differ from the original repository. The problem was discovered in GitLab's CI systems where cached repositories with one format were being reinitialized with a different format, but the same issue exists more generally for both ref and object formats.

The series consists of three patches: first removing a duplicate test, then fixing the reinitialization for incompatible ref formats, and finally doing the same for incompatible hash algorithms. The changes are relatively small (8 lines in setup.c and test adjustments) but address a real-world problem that could affect users trying to reinitialize repositories with different storage formats.

Patrick Steinhardt reports this was found in production at GitLab, suggesting it's a practical issue rather than a theoretical edge case. The patches appear focused and well-motivated, with test coverage to verify the fixes. This seems like a straightforward improvement to make repository reinitialization more robust.
