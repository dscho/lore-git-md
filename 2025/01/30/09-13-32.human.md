Test infrastructure patch converting the decorate test to the Clar framework. This is the second in a 4-part series modernizing Git's unit tests, following the hashmap conversion in patch 1.

The patch rewrites the decorate test from scratch using Clar's test organization, replacing the old t-example-decorate.c with u-example-decorate.c. The test cases (adding, re-adding, looking up, and iterating through decorations) are preserved but now use Clar's assertion macros (cl_assert, cl_assert_equal_i) and follow Clar's convention of standalone test functions. The initialization and cleanup are separated into dedicated functions (test_example_decorate__initialize/__cleanup) that Clar calls automatically.

Build system files (Makefile and meson.build) are updated to remove the old test and add the new one. The conversion appears thorough, maintaining all the original test coverage while adopting the new framework's patterns. Like the first patch, this is a straightforward mechanical conversion as part of the broader test modernization effort mentored by Patrick Steinhardt.
