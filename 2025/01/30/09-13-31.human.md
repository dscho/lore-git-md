Test modernization converting hashmap tests to Clar framework. This is the first of four patches in a series mentored by Patrick Steinhardt that moves unit tests from the current format to Clar's testing framework. The patch renames `t-hashmap.c` to `u-hashmap.c` and rewrites the test cases to use Clar's assertion macros (`cl_assert*`) instead of the previous test helpers. The functionality being tested remains the same - it verifies hashmap operations like add, remove, iterate, and case-sensitive/insensitive behavior - but the implementation now follows Clar's conventions.

The changes are mechanical but thorough, converting all test assertions and reorganizing the test functions to match Clar's style. Build system files (Makefile and meson.build) are updated to reference the new test location. The patch appears to be a straightforward conversion that maintains the same test coverage while modernizing the infrastructure. Since this is part of a coordinated effort with mentor oversight, it's likely to be uncontroversial.
