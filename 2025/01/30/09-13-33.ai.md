Test infrastructure patch converting strbuf unit tests to the Clar framework, part of an ongoing series modernizing Git's test suite. This is the third of four patches in the series, following similar conversions of hashmap and decorate tests.

The patch mechanically rewrites t-strbuf.c to u-strbuf.c, maintaining all existing test coverage while adapting to Clar's conventions. Key changes include converting test assertions to cl_assert* macros and restructuring test cases as standalone functions (test_strbuf__static_init, test_strbuf__add_single_char, etc.). The original test cases verify strbuf operations like initialization, character/string addition, and buffer state validation.

Build system files (Makefile and meson.build) are updated to reference the new u-strbuf.c location while removing the old t-strbuf.c reference. The conversion follows the same pattern as previous patches in the series, with test logic preserved but expressed through Clar's testing primitives. All test scenarios from the original remain, including edge cases like empty string handling and buffer growth behavior.

The patch appears complete and consistent with the series' approach. Reviewers will want to verify the Clar assertions precisely match the original test semantics, particularly for buffer state checks (len/alloc relationships and NUL-termination).
