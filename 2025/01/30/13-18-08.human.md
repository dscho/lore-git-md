Documentation patch adding missing details for SSL certificate and key type configuration options. This is a follow-up to earlier discussion about properly documenting the `http.sslCertType` and `http.sslKeyType` settings introduced in commit 0a01d41ee4.

The patch adds comprehensive documentation for both options, specifying:
- Supported formats ("PEM", "DER", "P12" for certificates
- Platform/backend limitations (noting "P12" works on OpenSSL/SChannel/SecureTransport)
- Special handling for PKCS#11 tokens via the "ENG" key type
- Corresponding libcurl options and environment variable overrides

The documentation addresses previous feedback by clearly calling out backend-specific behaviors and practical use cases like PKCS#11 token authentication. While the implementation itself isn't changed, this completes the missing documentation that was identified as a gap in the original feature introduction.

The patch appears well-researched, with accurate references to libcurl's underlying options and clear delineation of what works where. It should help users properly configure client certificate authentication across different SSL backends.
