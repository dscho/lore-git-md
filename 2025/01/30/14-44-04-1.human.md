This is a build system patch (12/13 in Patrick Steinhardt's Meson refactoring series) that improves Windows compatibility in documentation generation. The change ensures the build system consistently uses the custom `program_path` variable when looking up tools like asciidoc, asciidoctor, xmlto, and xsltproc. This path is particularly important on Windows where it points to Git for Windows' bundled tools.

The patch removes redundant `required: true` arguments (since they're Meson's default) while maintaining the same functionality. This continues the series' trend of cleaning up the build system by standardizing tool discovery patterns, following similar optimizations in earlier patches. The change should make documentation builds more reliable on Windows while simplifying the build configuration.
