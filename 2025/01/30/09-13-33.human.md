Test infrastructure patch converting strbuf unit tests to the Clar framework. This is the third in a 4-part series modernizing Git's test suite by moving from custom test helpers to the Clar testing framework, mentored by Patrick Steinhardt.

The patch follows the established pattern from previous conversions in the series: it rewrites the strbuf tests to use Clar's assertion macros (cl_assert*) while maintaining all existing test coverage. The original t-strbuf.c is deleted and replaced with u-strbuf.c, with corresponding updates to the Makefile and meson.build files to point to the new location.

The conversion preserves tests for strbuf initialization (both STRBUF_INIT and dynamic), character addition (including edge cases like empty strings), and string appending. Each test case is now a standalone function (test_strbuf__static_init, test_strbuf__add_single_char, etc.) following Clar's naming conventions. The patch appears to be a straightforward mechanical conversion that maintains the same test coverage while adopting the new framework's idioms.
