This is a documentation patch adding coverage for the `http.sslCertType` and `http.sslKeyType` configuration options, continuing the thread about HTTPS client certificate support. The patch provides detailed documentation for these options which were introduced in commit 0a01d41ee4 but previously undocumented. It specifies the supported formats ("PEM", "DER", "P12" for certificates and "PEM", "DER", "ENG" for keys) along with backend-specific limitations and environment variable overrides.

The documentation notes that "P12" certificate format is supported across OpenSSL, Schannel, and SecureTransport backends (plus GnuTLS 8.11+), while key type "ENG" (for PKCS#11 tokens) is OpenSSL-specific. It properly references the underlying libcurl options (`CURLOPT_SSLCERTTYPE`/`CURLOPT_SSLKEYTYPE`) and their environment variable equivalents (`GIT_SSL_CERT_TYPE`/`GIT_SSL_KEY_TYPE`).

This version appears to address the earlier feedback about documenting backend-specific behaviors, though it maintains the practical workaround for PKCS#11 token support (using "ENG" key type with a PKCS#11 URL) rather than proposing new engine parameter support. The documentation is thorough about current limitations while remaining technically accurate to the implementation.
