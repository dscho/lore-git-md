Test infrastructure improvement in a refs validation series. This is the first patch in v2 of an 8-part series addressing packed-refs header validation, now restructured to focus specifically on file format checks.

The patch converts test scripts to use subshells for directory changes, ensuring working directory restoration even when tests fail. This addresses a reliability issue where failing tests could leave the working directory in an unexpected state, particularly important for Windows compatibility. The change follows feedback from Patrick Steinhardt and Karthik Nayak, who are mentoring this work.

The patch makes extensive but mechanical changes to t0602-reffiles-fsck.sh, wrapping all test blocks that change directories in subshells. This maintains the same test coverage while making the tests more robust. The tests verify various ref name and content validation scenarios, including invalid refnames, malformed ref contents, and symlink handling.

This appears to be a well-executed infrastructure improvement that doesn't change test behavior but makes the test suite more reliable. The changes are straightforward and the patch follows established patterns for test directory management.
