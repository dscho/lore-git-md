Git GSoC 2025 project organization discussion.

Patrick Steinhardt responds to Christian Couder's suggestion about categorizing certain projects in the GSoC 2025 documentation. While Christian proposed creating a section for slightly larger follow-up projects (specifically "Add more builtin patterns for userdiff" and "Replace a run_command*() call"), Patrick expresses reservations about including these in the initial documentation iteration.

The core concern is that these projects lack clear definition - there's no straightforward way to identify applicable sites for modification, nor consensus that these changes are desirable. Patrick suggests focusing first on establishing the documentation format with clearly defined, uncontroversial microprojects before expanding to more ambiguous proposals.

This represents a tactical difference in approach to structuring the GSoC project list, with Patrick advocating for incremental documentation development starting with well-bounded projects, while Christian appears more eager to provide a broader range of project options for potential contributors. The discussion highlights ongoing challenges in balancing project scope definition with contributor engagement opportunities.
