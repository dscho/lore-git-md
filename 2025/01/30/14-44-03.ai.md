This is a refactoring patch in Patrick Steinhardt's Meson build system series (v2 11/13), addressing a variable collision issue in the build configuration. The patch fixes a case where the `git` variable was being reused for three different purposes: the external Git executable, the built Git executable, and again the external Git executable in documentation builds. 

The change renames the built executable variable to `git_builtin` to avoid overwriting the external Git reference, eliminating the need to rediscover the external Git executable in the documentation build. This follows the series' pattern of simplifying build system internals while maintaining functionality. The modification touches two files: `meson.build` (where the executable declaration and references are updated) and `Documentation/meson.build` (where the redundant external Git lookup is removed).

This is a straightforward cleanup that builds on the series' architectural improvements, particularly the tool discovery optimizations from patch 10/13. The change doesn't affect runtime behavior but makes the build configuration more maintainable by removing an ambiguous variable reuse case. The patch maintains all existing functionality while following the series' trend of reducing redundancy in the build system.
