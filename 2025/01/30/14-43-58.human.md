This is part 6/13 of Patrick Steinhardt's series refactoring Git's Meson build system, focusing on curl dependency management. The patch addresses an architectural issue where libcurl was being unnecessarily linked into all executables through `libgit_dependencies`. The change makes the dependency more precise by only including curl's include directories in the base `libgit` dependency (needed for version checking in help.c), while keeping the full curl linkage only in the new `libgit_curl` component introduced in the previous patch.

The change is straightforward - it modifies two lines in meson.build to use `curl.partial_dependency()` for includes while maintaining full curl linkage only where actually needed (HTTP-related commands). This continues the series' theme of cleaning up dependency relationships in the build system. The patch appears well-motivated and carefully implemented, with no obvious downsides - it simply removes unnecessary linkage while preserving all required functionality.
