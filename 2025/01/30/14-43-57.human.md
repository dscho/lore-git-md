This is part 5/13 of Patrick Steinhardt's series refactoring Git's Meson build system, focusing on curl-related dependencies. The patch introduces a new `libgit_curl` dependency that bundles common curl-related source files (`http.c` and `http-walker.c`) to simplify the build configuration for curl-dependent executables like `git-remote-http` and `git-http-fetch`. 

The change makes the build definitions more maintainable by eliminating repetitive source file listings and consolidating curl-related dependencies. It also fixes an architectural issue where curl-related sources were previously included in `libgit_commonmain`. The patch notes this is temporary - a follow-up commit will properly separate curl from the core `libgit` dependency.

The changes affect several HTTP-related programs and their aliases, while maintaining the same functionality. The `git-imap-send` executable gets special handling to conditionally use either the new curl bundle or the common main library depending on configuration. This appears to be a clean, well-motivated refactoring that improves the build system's organization without changing behavior.
