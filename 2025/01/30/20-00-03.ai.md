This is an announcement for Tig 2.5.11, a maintenance release of the ncurses-based Git repository browser. The release includes a mix of bugfixes and user experience improvements across various parts of the interface.

The changes address several specific pain points in the UI, including fixes for cursor position preservation when toggling filters, better handling of Git's `--no-prefix` option, and improved error visibility. The release also updates the Unicode handling library utf8proc to version 2.10.0 for better Unicode 16 support. Notable behavioral changes include showing committer dates by default in the date column and adjusting which references appear in the refs view when using `--all`.

The diffstat shows widespread but relatively shallow changes across the codebase, with the most significant modifications being in the utf8proc compatibility files (likely due to the library update) and the diff/refs handling logic. The release includes contributions from multiple authors, with Thomas Koutcher handling the majority of the changes. The announcement follows standard Tig release format, listing all changes, providing download locations, and including a full diffstat for transparency.
