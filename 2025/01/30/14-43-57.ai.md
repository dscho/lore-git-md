This is part 5/13 of Patrick Steinhardt's Meson build system refactoring series, focusing on dependency management for curl-related functionality. The patch introduces a new `libgit_curl` dependency that consolidates common curl-related source files (`http.c` and `http-walker.c`) and their linkage with `libgit_commonmain`.

Key technical changes:
- Creates `libgit_curl` as a declared dependency bundling curl-related sources and `libgit_commonmain`
- Updates all curl-dependent executables (`git-remote-http`, `git-http-fetch`, `git-http-push`, and their aliases) to use this new dependency
- Simplifies the build configuration by removing repetitive source file lists
- Fixes the aliases (`git-remote-https` etc.) to properly link against `libgit_curl` rather than reusing objects from `git-remote-http`
- Handles `git-imap-send` specially to maintain its optional curl usage

The patch notes this is an intermediate step - the next commit will address the architectural issue where `libgit` currently pulls in curl transitively when it shouldn't. This change maintains all existing functionality while making the build configuration more maintainable.

This continues the series' pattern of structural improvements to the Meson build system, with this patch specifically targeting the curl-related components. The changes are focused on build system organization rather than runtime behavior.
