This is a revised version of Patrick Steinhardt's Meson build system refactoring series, now expanded to 13 patches. The series continues the work of cleaning up and optimizing Git's Meson build configuration, with several notable improvements over v1:

1. The PATH handling has been completely reworked to be more targeted - now only prepending system-specific paths rather than all tool paths, which is both more correct and avoids unnecessary PATH bloat.

2. Several new fixes have been added:
   - OpenSSL fallback handling on Windows
   - Windows-specific linker error mitigation for GitLab CI (limiting parallel link jobs)
   - Better handling of the `sane_tool_path` option

3. The curl dependency management has been refined with a new `libgit_curl` dependency that properly encapsulates curl-related sources and dependencies, while maintaining all functionality.

The series remains focused on structural improvements rather than behavior changes, with each patch addressing a specific optimization opportunity. The changes span path handling, library organization, dependency management, and Windows-specific fixes. The v2 incorporates feedback from Justin Tobler on the PATH handling approach and adds several new fixes discovered during further testing.

This appears to be a well-considered series from an experienced contributor, with each change clearly motivated and cleanly implemented. The expanded scope in v2 suggests thorough testing and attention to edge cases, particularly around Windows compatibility. The changes should make the build system more maintainable without introducing regressions.
