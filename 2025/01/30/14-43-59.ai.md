This is part 7/13 of Patrick Steinhardt's Meson build system refactoring series, focusing on build system simplification. The patch eliminates the separate `libgit_version.a` library that was previously used to hold version information, folding it directly into `libgit.a` instead.

The change removes an unnecessary layer of indirection that was originally added to avoid rebuilding all of `libgit.a` when the version changed. However, this optimization is no longer needed since the build system now properly tracks dependencies via `version-def.h`. The patch demonstrates careful consideration of build system behavior, removing complexity while maintaining correct rebuild semantics.

Key technical changes:
- Removes `libgit_version_library` static library definition
- Moves `version.c` directly into `libgit_sources`
- Adds `version-def.h` to `libgit_sources`
- Updates `libgit` declaration to include version-related compiler flags directly
- Maintains same version injection behavior through `-DGIT_VERSION_H`

This continues the series' theme of simplifying the build architecture while preserving functionality. The change is low-risk as it doesn't affect runtime behavior - it only impacts build-time organization. The patch follows logically from the previous work in the series that established proper header dependency tracking.
