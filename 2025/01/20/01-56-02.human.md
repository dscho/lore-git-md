This is the main patch in a series converting Git's documentation files from `.txt` to `.adoc` extensions. It's a documentation modernization effort that renames 923 files across the Documentation/ directory (man pages, howtos, technical docs), RelNotes/, and build system files.

The change enables better editor support (syntax highlighting, formatting) and forge rendering by using the standard AsciiDoc file extension. The `.txt` extension wasn't wrong for AsciiDoc files, but most editors don't associate it with AsciiDoc, missing features like syntax highlighting. The `.adoc` extension is more commonly used in the AsciiDoc ecosystem.

The patch updates all include paths in the documentation and modifies build scripts (Makefile, meson.build) to recognize the new extension while maintaining identical output. The author notes this should not result in any user-visible changes to the documentation - it's purely a file extension conversion.

This is part of a well-structured 5-patch series that includes preparatory changes to `.gitignore`, `.editorconfig`, and `.gitattributes` before this bulk rename. The changes are mechanical but extensive, touching nearly every documentation file in the project. Reviewers are advised to examine this patch with word-diff for readability since it's mostly file renames.
