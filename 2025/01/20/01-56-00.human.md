This is a documentation and contributor housekeeping patch, part of a series preparing to migrate documentation files from .txt to .adoc extensions. The change updates Git's .editorconfig file to apply the same formatting rules (tab indentation, 8-character width) to AsciiDoc files as it already does for other text-based files. The commit explains this is groundwork for an upcoming switch in documentation file extensions, ensuring consistent formatting regardless of which extension is used. The change is straightforward and mechanical, with a clear explanation of its purpose in the commit message. As the second patch in a 5-part series, it appears to be part of a well-planned documentation modernization effort.
