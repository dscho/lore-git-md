CI modernization patch in the deprecation warning series. This is the third patch in version 3 of a 5-part series preparing for Git 3.0's breaking changes.

Patrick Steinhardt repurposes the existing "linux-gcc" CI job to test breaking changes, renaming it to "linux-breaking-changes". The job previously served as a standard test case using GCC and Ubuntu 20.04, with the notable feature of testing the "main" default branch name. The patch expands this by adding the new WITH_BREAKING_CHANGES flag to the job's configuration.

The changes touch both GitHub Actions and GitLab CI configurations, plus the shared test runner script. This appears to be a straightforward infrastructure adjustment that logically follows from earlier discussions in the thread about how to test the upcoming deprecation warnings. The patch maintains existing test coverage while better aligning the CI setup with the series' goals.
