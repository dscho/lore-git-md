This is a CI/build system patch in the ongoing deprecation warning series, specifically streamlining the test infrastructure. 

Patrick Steinhardt proposes merging two similar CI jobs - "linux-gcc-default" and "linux-gcc" - into a single job. The rationale is that these jobs overlap significantly in their testing scope, with only minor differences in GCC version, Python version, and Ubuntu image that are already covered by other existing jobs. The patch removes the redundant "linux-gcc-default" job and adjusts "linux-gcc" to use the default GCC compiler instead of an explicit version.

The changes touch GitHub Actions and GitLab CI configurations, plus the shared CI library script. The removal appears clean and well-justified, with the commit message clearly explaining why this consolidation makes sense. This seems like a straightforward infrastructure cleanup that shouldn't affect the actual deprecation warning functionality being developed in the rest of the series.
