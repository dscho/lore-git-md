This thread introduces a mechanical but wide-ranging change to convert all Git documentation files from `.txt` to `.adoc` extensions, better signaling their AsciiDoc format to editors and forges. The series comes in five well-organized patches that handle the rename along with supporting changes to build files and configuration. The bulk of the work is in patch 4, which performs the mass rename of 923 files while updating include paths. The author suggests reviewing this patch with word-diff tools for readability. While the changes are largely mechanical, reviewers will want to verify the build system adjustments and path updates work as intended across platforms. The series appears thoughtfully structured to minimize churn by avoiding temporary dual-extension support.
