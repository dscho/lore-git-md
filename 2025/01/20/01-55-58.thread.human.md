This thread documents a straightforward but impactful change to Git's documentation infrastructure - converting all AsciiDoc files from `.txt` to `.adoc` extensions. The 5-patch series, which includes build system updates and mass file renames, aims to enable better editor support and forge rendering while maintaining identical output. The changes are purely mechanical, touching Documentation/, RelNotes/, and various build scripts.

The series has received positive feedback, with M Hickford endorsing the change and highlighting its benefits for new contributors who often start with documentation work. No technical concerns or objections have been raised so far. The changes align with Jean-Noël Avila's broader documentation modernization efforts, though he isn't directly involved in this particular series. Given the uncontroversial nature of the changes and the support expressed, this appears likely to proceed smoothly through the review process.
