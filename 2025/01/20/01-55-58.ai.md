This is a documentation patch series that converts all AsciiDoc-formatted documentation files in the Git project from `.txt` to `.adoc` extensions. The cover letter explains the motivation: using `.txt` prevents editors from automatically recognizing these files as AsciiDoc, missing out on syntax highlighting and other editor support, and prevents forges from automatically rendering them as HTML.

The series consists of 5 patches:
1. Updates `.gitignore` for `.adoc` files
2. Adds `.adoc` to `.editorconfig`
3. Marks AsciiDoc files as LF-only in `.gitattributes`
4. The main conversion patch that renames all files and updates include paths
5. Removes obsolete `.txt` extensions from documentation references

The bulk of the changes are straightforward renames (923 files changed), with some minor adjustments to include paths and build system files. The author notes that while supporting both extensions temporarily would be possible, it would create unnecessary diff churn. They recommend reviewing the large patch 4 with `git log -p --word-diff --word-diff-regex=.` for better readability.

Key files affected include all documentation files under Documentation/ (man pages, howtos, technical docs), RelNotes, and build system files (Makefile, meson.build). The changes are mechanical in nature, with no semantic modifications to the documentation content itself. The patch appears well-structured and properly motivated, though reviewers will need to verify the build system changes and path updates.
