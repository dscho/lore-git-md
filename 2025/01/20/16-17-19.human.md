This is a build system patch that aligns the Meson build configuration with recent compiler warning changes. It's the first in a 10-part series refactoring type safety in the reftable codebase.

The patch removes the `-Wno-sign-compare` flag from meson.build, matching a change already made to the Makefile-based build system in December 2024. This enables stricter compiler warnings about signed/unsigned comparisons across the codebase, which the subsequent patches in the series will address.

The change is straightforward - just a single line removal in meson.build. As the first step in a larger effort to improve type safety in the reftable subsystem, this patch sets the stage for the more substantive changes that follow in the series. The commit message clearly explains the change and its context within the broader warning-cleanup effort.
