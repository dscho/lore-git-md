Peter Oliver's two-patch series to standardize Perl version requirements across Git's build systems has reached its final form and is ready for merging. The series aligns the Meson build system's Perl version check (5.26.0) with the existing Makefile standard while carefully handling version string parsing quirks in different Meson versions.

The implementation introduces a dual-path detection strategy - using the more reliable `-V:version` flag for Meson 1.5.0+ while maintaining compatibility with older versions through careful parsing of `--version` output. The accompanying documentation patch provides thorough context about Meson's version parsing behavior, including historical background and the temporary nature of the workaround (which will become obsolete with Meson 1.7.0's parsing fix).

Patrick Steinhardt reviewed the series and all his feedback has been incorporated. The changes are minimal and focused, preserving the `perl_required` conditional check while ensuring compatibility with both current and future Perl versioning schemes. With all technical concerns resolved and no outstanding objections, this series represents a complete solution to the Perl version standardization effort.
