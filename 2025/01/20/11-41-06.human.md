Test fix addressing ambiguous printf format in blame tests.

This patch fixes a minor but potentially problematic issue in two test cases in t8002-blame.sh. The tests were using the ambiguous `%0.s` printf format to generate padding spaces, which could be interpreted differently across shells and tools (as either a width specification or a zero-padding flag). The fix replaces this with the unambiguous `%${N}s` format, which is already used elsewhere in the test suite.

The change is straightforward and well-justified, with the commit message clearly explaining both the problem and solution.
