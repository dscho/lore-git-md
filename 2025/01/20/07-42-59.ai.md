CI/build system patch in the deprecation warning series. This is the second of five patches in v3, focusing on CI infrastructure cleanup related to the broader deprecation effort.

The patch merges two similar CI jobs ("linux-gcc" and "linux-gcc-default") that were testing with different GCC versions and Ubuntu base images. Patrick Steinhardt argues the distinction between these jobs has become obsolete because: (1) explicit GCC version testing is covered by other jobs, (2) Python 2 testing is no longer relevant, (3) branch name defaults are inconsistently tested across the suite anyway, and (4) Ubuntu version differences are already tested elsewhere. The changes remove the redundant job while preserving all meaningful test coverage.

Implementation removes the "linux-gcc-default" job definition from both GitHub Actions (.github/workflows/main.yml) and GitLab CI (.gitlab-ci.yml) configurations, along with its special-case handling in ci/lib.sh. The remaining "linux-gcc" job will now use the default GCC compiler rather than explicitly specifying gcc-8. This simplification appears well-justified and maintains test coverage while reducing CI resource usage - a straightforward cleanup that fits naturally with the series' broader goal of modernizing Git's infrastructure.
