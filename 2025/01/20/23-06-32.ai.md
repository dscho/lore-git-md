Feature proposal for batch removal of remotes with `git remote remove`.

Christian Fredrik Johnsen proposes enhancing `git remote remove` to accept multiple remote names as arguments, similar to how `git branch -d` works. The current implementation only allows removing one remote at a time, which can be inefficient when cleaning up repositories with multiple remotes. The proposal notes this would align with existing batch operations in other Git commands and streamline maintenance workflows.

The request appears well-motivated for power users managing multiple remotes, though the author acknowledges it may be a niche use case. The proposal is straightforward - modifying the command to accept variadic arguments - and references similar functionality in `git branch` as precedent. No implementation details or potential edge cases are discussed, suggesting this is an early-stage feature request rather than a patch submission.
