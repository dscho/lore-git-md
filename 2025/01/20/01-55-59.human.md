This is a documentation and developer workflow patch, part of a series to transition Git's `.txt`-suffixed AsciiDoc files to the more standard `.adoc` extension. The change aims to improve contributor experience by enabling better editor support (like syntax highlighting) that typically recognizes `.adoc` files automatically. This first patch updates `.gitignore` rules to prevent accidentally committing generated documentation files with the new extension, anticipating the broader transition in the series. The change is straightforward, adding parallel entries for `.adoc` alongside existing `.txt` patterns in two documentation `.gitignore` files. The commit message clearly explains the motivation and ties this preparatory step to the larger series goal.
