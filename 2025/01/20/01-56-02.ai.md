This is the main patch in a documentation conversion series, mechanically renaming all AsciiDoc files from `.txt` to `.adoc` extensions. As the fourth patch in a 5-part series, it handles the bulk of the file renames (923 files) and updates include paths in build scripts and documentation files to match.

The patch touches nearly every documentation file in the repository, including man pages (Documentation/), release notes (RelNotes/), and build system files (Makefile, meson.build). Key technical details include:

- All include paths referencing Documentation/*.txt are updated to .adoc
- Build system files (Documentation/Makefile, meson.build) are modified to recognize the new extension while maintaining identical output
- The conversion is purely mechanical - no semantic content changes are made
- The patch updates several Perl and shell scripts (cmd-list.perl, generate-*.sh) to handle the new extension
- Special cases like lint-gitlink.perl and lint-manpages.sh are adjusted to look for .adoc files

The motivation, as explained in the thread context, is to enable proper editor support (syntax highlighting, prose linting) and forge rendering by using the standard AsciiDoc file extension. The changes are extensive but straightforward, with the main functional changes concentrated in the build system adjustments.

This patch follows preparatory patches that updated .gitignore, .editorconfig, and .gitattributes, and will be followed by a final patch removing obsolete .txt references. Reviewers should focus on verifying the build system changes and path updates, particularly in the Makefile and meson.build files where the extension handling logic was modified.
