This is a CI infrastructure patch that's part of the ongoing deprecation warning series (patch 3/5 in v3). It repurposes the existing "linux-gcc" CI job to test breaking changes by renaming it to "linux-breaking-changes" and adding the WITH_BREAKING_CHANGES flag.

The patch modifies three CI configuration files to rename the job and add the breaking changes flag. The job was previously testing the future default branch name change (from "master" to "main"), and now additionally tests the deprecation warnings being introduced in this series. The changes affect GitHub Actions, GitLab CI, and the shared test runner script.

Key technical details include:
- Job renamed from "linux-gcc" to "linux-breaking-changes" in both CI systems
- WITH_BREAKING_CHANGES=YesPlease added to the deprecation testing environment
- Maintains existing GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=main testing
- Touches .github/workflows/main.yml, .gitlab-ci.yml, and ci/run-build-and-tests.sh

This change demonstrates how the series is modernizing Git's infrastructure alongside the core deprecation work, ensuring the breaking changes are properly tested in CI. The patch is straightforward and aligns with the thread's established direction of implementing deprecation warnings without suppression mechanisms.
