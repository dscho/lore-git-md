Git diff --name-only --ignore-space-at-eol bug report thread summary:

Thread reports unexpected interaction between `--name-only` and `--ignore-space-at-eol` flags in `git diff`. Reporter Bob Ruiken describes a case where files containing only end-of-line whitespace changes still appear in `--name-only` output despite `--ignore-space-at-eol` being specified, contrary to expected behavior where such files should be excluded. The issue occurs in Git 2.39.5 on macOS (arm64), though cross-version/platform behavior is not yet confirmed. The bug appears to be in how name-only output fails to properly respect whitespace ignore rules during filtering, affecting users who want clean lists of meaningfully changed files while ignoring trivial whitespace differences. Reproduction steps are clear but no analysis of root cause or proposed fix yet provided.
