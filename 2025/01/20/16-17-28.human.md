Final patch in a refactoring series cleaning up compiler warnings in reftable code. This 10th patch addresses the last remaining -Wsign-compare warnings in the reftable library by converting loop counters and string lengths to proper unsigned types (size_t and uint64_t) where appropriate. It also removes the now-unneeded DISABLE_SIGN_COMPARE_WARNINGS macro from system.h.

The changes are straightforward and mechanical, touching record.c (fixing string encoding and object record decoding), stack.c (updating loop variables), and system.h. This completes the series' goal of eliminating all signed/unsigned comparison warnings while maintaining type safety throughout the reftable codebase.

As the concluding patch in a well-reviewed series that has already addressed more substantial type safety issues, this appears ready for merging as part of the broader effort to make reftable a standalone library. The changes are small and focused, with no behavior changes beyond the intended warning cleanup.
