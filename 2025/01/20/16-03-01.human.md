Build system patch fixing Perl version check in Meson configuration.

This second patch in the series addresses how Meson interprets Perl version strings when checking the minimum version requirement. The first patch had bumped the requirement to 5.26.0, but this follow-up fixes an implementation detail: Meson's version check would incorrectly parse output like "perl 5, version 26" as simply version 26 rather than 5.26.0. The solution is to use the simpler ">=26" check, though the commit notes that a more robust approach using `-eprint "$^V"` would require Meson 1.5.0 (which isn't widely available yet).

The change is narrowly focused on build system plumbing and appears technically sound, though it's worth noting this is working around a Meson version string parsing quirk rather than addressing any fundamental issue with Perl itself. The patch maintains compatibility while waiting for Meson's own version checking to become more robust in future releases.
