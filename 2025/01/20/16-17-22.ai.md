This is a refactoring patch in Patrick Steinhardt's series to improve type safety in the reftable codebase. The change adjusts `common_prefix_size()` to return `size_t` instead of `int`, since the function calculating buffer prefix lengths should logically return an unsigned value. This eliminates several -Wsign-compare warnings and better matches the function's semantic meaning.

The patch updates the function signature in basics.h and its callers across basics.c, record.c, writer.c, and the unit tests. The changes are straightforward - switching from `int` to `size_t` for the return type and related variables, with corresponding test assertion updates from `check_int` to `check_uint`. The implementation remains functionally identical, just with more type safety.

This is part of a larger effort (v2 04/10) to clean up compiler warnings and improve type correctness in reftable as it moves toward becoming a standalone library. The change is well-contained and mechanical, with no behavior changes beyond the type system improvements. All call sites are updated consistently, and the unit tests verify the continued correct operation of the function.
