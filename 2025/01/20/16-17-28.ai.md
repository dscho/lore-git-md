Refactoring patch completing the reftable type safety series by addressing final -Wsign-compare warnings. This final patch in the 10-part series removes the last few signed/unsigned comparison warnings in the reftable codebase and eliminates the now-unneeded DISABLE_SIGN_COMPARE_WARNINGS macro from system.h.

The changes are straightforward type safety improvements: converting strlen() returns to size_t, replacing int loop counters with size_t where appropriate, and simplifying loop structures by moving declarations into for() statements. The patch touches record.c (string encoding and object record decoding), stack.c (file cleanup and stack maintenance), and system.h (macro removal). 

This concludes the comprehensive refactoring effort that has systematically addressed compiler warnings and type safety throughout the reftable codebase. With this patch, the series' goals are fully realized - all size-related operations now use proper unsigned types consistently, the build system is cleaner without warning suppression, and critical integer overflow protections are in place. The changes maintain existing functionality while improving code safety and maintainability.
