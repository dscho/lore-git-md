This is a documentation housekeeping patch, part of a series (1/5) preparing to transition Git's documentation from `.txt` to `.adoc` file extensions for AsciiDoc files. The patch updates `.gitignore` files in the Documentation directories to include the new `.adoc` extension for generated documentation files, preventing accidental commits of build artifacts.

The change is motivated by better editor support - while `.txt` is technically correct for AsciiDoc files, most editors don't associate it with AsciiDoc syntax highlighting and tooling, whereas `.adoc` is widely recognized. This appears to be a straightforward preparatory change for the upcoming extension transition, with clean implementation adding matching ignore patterns for each existing `.txt` pattern that will have an `.adoc` counterpart.

Key files modified are `Documentation/.gitignore` and `Documentation/technical/.gitignore`, with parallel additions for `howto-index`, `cmds-*`, `mergetools-*`, `SubmittingPatches`, and `api-index` files. The patch doesn't yet perform the actual file renaming (presumably coming in the series), just prepares the ignore rules to support it.
