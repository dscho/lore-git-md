This is a build system patch introducing infrastructure for upcoming breaking changes in Git. It's the first of a 5-part series (v3) focused on deprecating certain features.

The patch adds a new `WITH_BREAKING_CHANGES` compile-time flag that will control whether upcoming breaking changes are enabled. This implements a policy established in earlier commits (57ec9254eb and 2454970930) that requires breaking changes to be gated behind a build-time option. The changes touch the Makefile, Meson, and CMake build systems, plus test infrastructure to detect the setting.

The patch is cleanly implemented and follows established patterns for build configuration options. While it doesn't yet enable any actual breaking changes (those presumably come in later patches), it lays important groundwork for managing them. The series appears to be part of a coordinated effort to introduce breaking changes in a controlled way, with this first patch being the least controversial piece - just adding the build infrastructure.
