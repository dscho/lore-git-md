This is a type safety refactoring patch in the reftable codebase, part of a larger series to eliminate compiler warnings and improve code correctness. The patch changes the return type of `header_size()` and `footer_size()` functions from `int` to `size_t`, since these functions can only return positive values representing sizes. The change fixes sign comparison warnings and maintains consistency with the series' goal of proper unsigned type usage.

The modification is straightforward - just updating the function signatures and one test assertion. It follows similar changes made earlier in the series (as noted in the commit message) and affects core reftable files (block.c, block.h) and a test file. The patch appears well-contained and mechanical, with no logic changes beyond the type adjustments.
