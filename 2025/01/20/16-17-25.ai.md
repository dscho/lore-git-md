This is a refactoring patch in the reftable type safety series, specifically addressing restart length tracking in the reftable block writer.

The patch changes the type used for tracking restart lengths from `int` to `uint32_t` in both the block writer implementation and writer header. While the restart length is bounded by MAX_RESTARTS (which would fit in uint16_t), the change to uint32_t maintains consistency with other parts of the code that already use 32-bit integers for restarts. The modification affects the block_writer_register_restart() function and related restart handling logic in block.c, plus the restarts field in reftable_block_stats.

Key technical details:
- Removes unnecessary signedness for restart length tracking
- Simplifies conditional logic by removing redundant braces
- Updates loop variable in block_writer_finish() to match new type
- Maintains same behavior while using more semantically correct types

This continues the series' pattern of type safety improvements, following similar conversions of other size-related variables to unsigned types. The changes are mechanical and don't affect functionality, just make the code more correct by design. The patch touches core reftable writer components but doesn't require any test updates since it's purely a type change with identical runtime behavior.
