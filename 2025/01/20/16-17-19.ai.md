This is a build system patch that removes the `-Wno-sign-compare` compiler flag from the Meson build configuration, aligning it with a recent change made to the Makefile-based build system. 

The change is part of a larger 10-part series focused on type safety improvements in the reftable codebase. This first patch removes the warning suppression that was previously masking signed/unsigned comparison warnings, forcing the codebase to properly handle these cases. The commit references a prior change (4f9264b0cd) that made the same adjustment for the Makefile build system, making this a straightforward alignment between build systems.

The patch is minimal - just a single line removal from meson.build. It serves as the foundation for the subsequent patches in the series which will actually fix the signed/unsigned comparison issues that this change will now expose. The change is uncontroversial and follows established precedent from the Makefile side, making it a safe starting point for the larger refactoring effort.
