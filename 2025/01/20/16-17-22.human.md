Refactoring patch in the reftable codebase, part of a larger type-safety cleanup series.

This patch changes the return type of `common_prefix_size()` from `int` to `size_t`, which better reflects the function's purpose of computing buffer prefix lengths (which can never be negative). The change eliminates several -Wsign-compare compiler warnings and aligns with the series' goal of improving type safety in the reftable implementation.

The patch updates the function definition and all call sites, including test assertions. The changes are straightforward mechanical updates with no behavior changes. This is part of Patrick Steinhardt's ongoing effort to clean up the reftable codebase in preparation for making it a standalone library, with Karthik Nayak having reviewed the technical approach.
