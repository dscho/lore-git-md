This is a refactoring patch in the reftable codebase, part of a series addressing type safety and compiler warnings. The patch changes the return type of block reading functions from `int` to `ssize_t` to better indicate their purpose (returning byte counts or errors, similar to read(3p)). The change affects several functions in the blocksource and reader implementations, with corresponding updates to their callers to handle the new type properly.

The patch maintains the existing behavior while making the code's intent clearer and avoiding signed/unsigned comparison warnings. Notably, it simplifies `reader_get_block()` to only indicate success/failure rather than propagating the byte count, since callers weren't using that information. This is a mechanical but thoughtful change that fits well with the series' goal of improving type safety throughout the reftable code.
