This is patch 15/19 in a series refactoring the reftable library to make it fully portable and independent from Git's core infrastructure. The patch focuses on Windows compatibility by splitting the POSIX-related bits from "compat/mingw.h" into separate headers.

The change reorganizes the Windows compatibility code into two distinct headers: "compat/mingw/posix.h" for POSIX compatibility functions and "compat/mingw/compat-util.h" for Git-specific Windows utilities. This separation prepares for future work to split "git-compat-util.h" into more focused components.

Key changes include:
- Moving Git-specific Windows utilities (like path validation, UTF conversion, and SSL wrappers) to the new compat-util.h
- Keeping POSIX emulation functions (file operations, process handling) in the renamed posix.h
- Updating all build systems (Make, CMake, meson) and include paths to reference the new header locations
- Maintaining compatibility with both MinGW and MSVC builds

The patch continues the series' consistent approach of mechanical but careful refactoring to achieve independence from Git's core while preserving all functionality. It touches multiple build systems and compatibility layers but appears to be a straightforward reorganization without behavioral changes.
