This is patch 14/19 in a series decoupling the reftable library from Git's core infrastructure. The patch replaces Git's `UNUSED` macro with a reftable-specific `REFTABLE_UNUSED` version to eliminate another dependency on Git's utility functions.

The new macro is simpler - it just casts parameters to void to suppress unused parameter alerts, without the compiler-specific warning suppression that Git's version includes. The change is mechanical but thorough, updating all instances across the reftable codebase (blocksource, iterators, records, and writer components) to use the new macro while maintaining the same basic functionality.

This continues the series' pattern of systematically removing Git dependencies while preserving behavior. The patch is straightforward and well-contained, with clear mechanical changes that should be controversial. It's another incremental step toward making reftable fully standalone.
