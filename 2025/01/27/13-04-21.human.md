This is part 13 of a 19-patch series refactoring the reftable library to remove Git dependencies. The patch replaces Git's `SWAP()` macro with a reftable-specific `REFTABLE_SWAP()` implementation, continuing the systematic elimination of Git utility functions.

The change introduces a new macro in reftable/basics.h that performs the same value swapping functionality but with an added size-checking mechanism similar to Git's original. The patch updates four call sites across merged table iteration, priority queue operations, and record handling to use the new macro. The implementation carefully maintains the same swapping behavior while removing the Git dependency.

This is a mechanical but important step in the larger effort to make reftable fully standalone. The change is straightforward and follows the established pattern of the series - replacing Git utility with equivalent functionality while preserving behavior. The patch appears well-contained and properly tested, with no obvious issues in the implementation.
