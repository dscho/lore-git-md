This is the final patch in a 19-part series decoupling the reftable library from Git's core infrastructure. The series has systematically replaced Git-specific helpers with direct POSIX calls and reftable-specific implementations to make the library truly standalone.

The patch excludes reftable sources from Coccinelle checks since they no longer use Git helper functions that Coccinelle rules typically target. This prevents false positives from rules that would suggest converting code patterns to use now-removed Git utilities. The change is a simple Makefile tweak that adds reftable/ to the filter-out list for COCCI_SOURCES.

As the concluding patch in this major refactoring effort, it represents the last step in making reftable independent of Git's internals while preserving all functionality. The series has been thorough and consistent, with each patch following the same pattern of carefully replacing dependencies while maintaining behavior. This final adjustment acknowledges that the reftable codebase now follows different patterns than the rest of Git.
