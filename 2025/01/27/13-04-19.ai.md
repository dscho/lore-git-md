This is part 11 of a 19-patch series refactoring the reftable library to remove Git dependencies. The patch introduces a new `reftable_rand()` function to replace direct calls to Git's `git_rand()`.

The change creates a new system-level abstraction for random number generation, with the implementation initially just wrapping `git_rand()` but designed to allow callers to provide their own seeded RNG. The patch updates two call sites in reftable/stack.c that were using `git_rand()` directly - one for retry delay calculation and another for generating unique filenames.

This continues the series' pattern of replacing Git-specific functionality with reftable-specific interfaces. The change is straightforward and maintains the same behavior while providing a cleaner abstraction boundary. The implementation remains in system.c alongside other platform-specific code, and includes proper documentation in system.h about the expected behavior (returning pre-seeded data).

The patch is mechanically similar to previous ones in the series, focusing on dependency removal while preserving functionality. It touches the same core reftable components (stack operations) that earlier patches have been modifying, showing the systematic nature of this refactoring effort.
