This is a follow-up in the string sanitization utility discussion, specifically about a now-dropped patch from Christian Couder's series. The patch originally proposed `strbuf_trim_trailing_ch()` to handle removing arbitrary terminator characters from strings, but Christian has since realized that `strbuf_strip_suffix()` can serve the same purpose in his use cases. 

Junio Hamano had previously noted the patch was "totally uninteresting" since it duplicated functionality that could be achieved with existing string operations, though he suggested that a more generalized version accepting multiple characters might have been more useful. Christian confirms in the current email that he's dropping this patch entirely from v4 of his series in favor of using `strbuf_strip_suffix()`.

This represents a minor course correction in Christian's ongoing work on string utilities for version capabilities. The change shows responsiveness to maintainer feedback and a preference for reusing existing functionality rather than adding new specialized helpers. The thread context indicates this utility work is proceeding in parallel with Christian's promisor-remote series, with both efforts moving toward v4 submissions.
