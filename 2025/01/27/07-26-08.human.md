Platform compatibility review feedback on MSVC warning fixes. Patrick Steinhardt responds to Sören Krecker's v3 patch series addressing type conversion warnings in `add-patch.c` and related files. The core technical discussion focuses on the proposed `str_to_size_t` macro, with Patrick suggesting several improvements:

1. **Existing alternatives**: Points out `strtoumax()` already exists for string-to-integer conversion and suggests using it instead of a new macro.

2. **Implementation concerns**: Critiques the macro's fragility and naming convention, proposing a more robust `strtoumax_ui()` helper function that would handle bounds checking and error cases more thoroughly, following Git's existing `strtoul_ui()` pattern.

3. **Patch organization**: Recommends splitting the work into multiple commits - one for format string changes, another for the gettext.h modification, and a separate implementation for the new conversion helper.

4. **Error message style**: Notes two instances where error messages incorrectly start with uppercase letters.

The feedback maintains the series' goal of MSVC compatibility but suggests a more maintainable approach to integer conversion that would benefit the entire codebase. Patrick's comments indicate this patch needs substantial reworking before acceptance, particularly around the core type conversion logic.
