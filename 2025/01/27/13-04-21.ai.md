This is patch 13/19 in a series refactoring the reftable library to remove Git dependencies, specifically targeting the `SWAP()` macro removal.

The patch introduces a new `REFTABLE_SWAP` macro in basics.h to replace Git's `SWAP()` utility. The implementation uses `memcpy` with a temporary buffer and includes a clever compile-time size check via array sizing that fails if the swapped items have different sizes. The change affects four files: basics.h (where the new macro is defined), merged.c (for iterator operations), pq.c (priority queue implementation), and record.c (reference record handling).

The new macro maintains the same swapping behavior while eliminating another Git dependency. The implementation is careful to preserve the size safety check that was implicit in Git's `SWAP()` macro, though it does so through a different mechanism (array sizing rather than a build assertion). The changes are mechanical replacements across the codebase, with no behavioral differences expected.

This continues the series' pattern of systematically replacing Git utilities with reftable-specific implementations. The patch follows the established approach of focused, behavior-preserving changes that incrementally reduce dependencies while maintaining identical functionality. The swap operations are used in core reftable operations like record handling and iterator management, so the change touches important code paths but in a straightforward way.
