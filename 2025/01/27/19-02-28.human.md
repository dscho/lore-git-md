Performance optimization introducing an improved name-hashing algorithm for pack-objects delta compression. This is the first patch in Derrick Stolee's v4 series that adds configurable name hashing versions.

Jonathan Tan proposes a new `pack_name_hash_v2()` function that addresses limitations in the current hashing approach. The original version focuses heavily on the last 16 non-whitespace characters, which helps group similar file types but can cause excessive collisions for unrelated files with similar endings. The new version makes two key improvements: better handling of non-ASCII characters through bit manipulation, and incorporating directory hierarchy information by XORing with parent directory hashes.

The patch lays groundwork for later changes that will expose this as a selectable `--name-hash-version` option. While the commit doesn't yet show performance numbers, the design aims to maintain good delta compression while reducing problematic collisions. The implementation appears carefully considered, building on the existing hash approach while adding directory awareness.

This is a well-structured patch with clear explanations of both the problem and solution. As the series opener, it focuses narrowly on the hash function implementation, leaving integration and performance measurements for subsequent patches. The change is signed off by both Tan and Stolee, indicating collaboration on the design.
