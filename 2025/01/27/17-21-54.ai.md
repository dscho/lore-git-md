The documentation is criticized for being unclear about the function's actual behavior - matching refnames against refspec patterns and optionally transforming them. While acknowledging these improvements could be deferred, Hamano provides a model for what better documentation might look like.

The feedback maintains the series' technical correctness while pushing for higher API quality as the functions become more visible. It doesn't block the current patches but lays groundwork for future cleanup, showing how maintainers think about long-term API design even during mechanical reorganizations.
