This is a test infrastructure patch in Derrick Stolee's performance optimization series for pack-objects name hashing. It introduces a new `GIT_TEST_NAME_HASH_VERSION` environment variable to facilitate testing of the different name hash algorithms without requiring test duplication.

The patch makes several careful adjustments to the test suite:
1. Adds documentation for the new test variable in t/README
2. Modifies the default name hash behavior to check the environment variable
3. Selectively disables the variable in tests that are sensitive to delta selection or bitmap output
4. Updates several test files where exact output comparisons would be affected by hash version changes

The changes show thoughtful consideration of test stability - the patch identifies specific test cases where hash version changes could cause spurious failures (thin bundles, bitmap comparisons) and isolates them by forcing version 1. This maintains test reliability while still allowing broader testing of the new hash version 2 algorithm elsewhere.

As part of the mature v4 submission, this patch follows the series' pattern of thorough testing infrastructure to support the new feature while maintaining backward compatibility. The changes are focused and well-explained, with clear rationale for each test modification.
