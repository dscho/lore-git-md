Refactoring patch in a series to make reftable library standalone. This is the first of 19 patches that systematically removes Git-specific dependencies from the reftable implementation.

The patch replaces a single call to Git's `read_in_full()` helper with direct POSIX `read()` calls in the reftable stack implementation. The new implementation handles partial reads and error conditions (EAGAIN/EINTR) explicitly while maintaining the same functionality. This is part of a larger effort to make the reftable library usable outside of Git's core codebase.

The change is mechanical but well-contained, focusing on one specific dependency removal. The commit message clearly explains the motivation (reducing Git library dependencies) and the implementation appears correct, though it does slightly increase the code complexity by handling read retries explicitly. This sets the pattern we'll see in subsequent patches of the series.
