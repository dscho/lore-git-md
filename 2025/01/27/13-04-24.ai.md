Platform compatibility patch continuing the reftable decoupling effort by reorganizing MSVC-specific code.

This patch splits the Windows/MSVC compatibility layer into POSIX-related functionality and Git-specific utilities, mirroring the structure established in patch 15 for MinGW. The key changes are:
1. Renames `compat/msvc.h` to `compat/msvc/posix.h` and moves it to a new subdirectory
2. Creates a new `compat/msvc/compat-util.h` header that includes both the POSIX bits and MinGW compatibility utilities
3. Updates build system files (config.mak.uname and meson.build) to handle the new file locations and conditional compilation paths
4. Maintains all existing functionality while making the code organization match the MinGW split from the previous patch

The change continues the series' systematic approach to disentangling platform-specific code from Git's core utilities, with this patch focusing on the MSVC compatibility layer. The meson build system changes show careful handling of the conditional compilation paths to ensure the right files are included for both MSVC and MinGW toolchains. This is part of the broader effort to make reftable fully portable by clearly separating POSIX emulation from Git-specific compatibility layers.
