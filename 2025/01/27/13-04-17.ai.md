This is patch 09/19 in the reftable independence series, focusing on big endian conversion utilities. The patch replaces Git's endian conversion functions with reftable-specific implementations to further decouple the reftable library from Git's core infrastructure.

The changes introduce a comprehensive set of inline functions in reftable/basics.h for 16/24/32/64-bit big endian operations (put/get variants), removing the previous Git-dependent implementations from basics.c. The new functions follow reftable's naming convention (`reftable_*`) and use `void*` parameters for better type safety. All call sites across the reftable codebase (block.c, reader.c, record.c, writer.c) are updated to use these new functions, along with corresponding test updates in t-reftable-basics.c.

The patch maintains identical behavior while eliminating another Git dependency point. It's a straightforward mechanical conversion that follows the series' established pattern, with the added benefit of expanding coverage to 32-bit and 64-bit operations that weren't previously provided by the reftable library. The unit tests verify all new functions work correctly across the supported integer sizes.
