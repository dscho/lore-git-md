This is part 3 of a 19-patch series decoupling the reftable library from Git's core infrastructure. The patch replaces Git's `xmmap()` with direct `mmap()` calls in the reftable blocksource code, continuing the series' pattern of removing Git-specific dependencies.

The change addresses two issues: `xmmap()`'s behavior of terminating the program on failure (which isn't appropriate for a library), and its tight coupling to Git's codebase. The new implementation uses POSIX `mmap()` with proper error handling, falling back to Git's `git_mmap()` wrapper where needed for platform compatibility. The error handling is also fixed to properly propagate failures up the call chain.

The patch is straightforward, replacing one memory mapping function with another while maintaining the same functionality. It follows the series' consistent approach of methodically removing Git dependencies while preserving behavior. The change is mechanical but important for the reftable library's goal of becoming a standalone component.
