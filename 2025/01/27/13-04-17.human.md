Refactoring patch in the reftable independence series. This is patch 9/19 in Patrick Steinhardt's effort to make the reftable library fully standalone by removing Git-specific dependencies.

The patch standardizes big-endian conversion functions within the reftable library, replacing a mix of Git-provided and reftable-specific implementations. It introduces a complete set of inline functions in reftable/basics.h for 16, 24, 32, and 64-bit big-endian operations (put/get), with consistent naming prefixed by "reftable_". The changes are mechanical but thorough, updating all call sites across block handling, reader/writer operations, and record processing.

The patch follows the series' pattern of cleanly separating reftable from Git internals while maintaining identical functionality. Test coverage is expanded to verify the new 32 and 64-bit variants while keeping the existing 16/24-bit tests. This is another incremental but important step toward the reftable library's independence.
