This is a refactoring patch from Christian Couder's promisor-remote/Large Object Promisor (LOP) series (v4, patch 3/6). It makes the `redact_non_printables()` function non-static so it can be reused outside version.c, moving its declaration to version.h.

The function sanitizes strings by replacing non-printable ASCII characters with dots, which was previously only used internally for user-agent sanitization. The patch is straightforward - it removes the static` modifier, adds the function declaration to version.h with documentation, and includes the necessary `struct strbuf` forward declaration.

This change supports the series' broader work on standardizing string handling, building on Usman Akinyemi's earlier contributions. The patch appears clean and focused, with no behavior changes beyond the intended function visibility expansion. It's part of the ongoing polish phase of the LOP series, which has been systematically addressing feedback from maintainers.
