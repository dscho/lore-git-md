This is the second patch in Derrick Stolee's performance optimization series introducing configurable name hashing for pack-objects delta compression. The patch adds a `--name-hash-version` option to `git pack-objects` that lets users choose between two hash algorithms for path-based delta grouping.

The key technical contribution is the versioned hash function selection:
- Version 1 preserves the existing `pack_name_hash()` behavior that focuses on path endings
- Version 2 uses the new `pack_name_hash_v2()` that incorporates directory hierarchy via XOR operations while maintaining similar locality properties

The patch includes comprehensive integration:
- Documentation explaining both versions' tradeoffs (version 1 better for short paths, version 2 better for same-filename-in-many-dirs cases)
- Safety checks that prevent invalid versions and enforce version 1 when writing bitmaps (due to format limitations)
- Test coverage for valid/invalid version numbers and bitmap compatibility

Performance data shows dramatic improvements in pathological cases - one private repo saw pack size drop from 37GB to 7GB with version 2. The fluentui open-source repo demonstrates public results: 440MB → 161MB pack size reduction with corresponding repack time improvements (728s → 142s).

The implementation maintains backward compatibility while paving the way for future bitmap format extensions to track hash versions. The validation logic ensures safe operation even when features like bitmaps are combined with the new option.
