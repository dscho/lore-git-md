This is a test infrastructure patch in Derrick Stolee's performance optimization series for pack-objects name hashing. It adds a new test helper and performance tests to analyze hash collision behavior between the two name-hash algorithms.

The patch introduces a `test-tool name-hash` command that computes both v1 and v2 name hashes for input paths, allowing verification that the hash values remain stable across Git versions (important for bitmap compatibility). It includes:

1. A basic verification test in t5310 that checks specific known values for both hash versions, demonstrating their collision behavior on carefully chosen test paths.

2. A new performance test (p5314) that measures hash collision rates in real repositories by:
   - Counting distinct hash values
   - Tracking maximum collision counts (multiplicity)
   - Showing v2's improvements over v1 in reducing collisions

The commit demonstrates the impact with statistics from several repos:
- Git: modest collisions (13 max in v1, 9 in v2)
- FluentUI: significant improvement (279 → 44 max collisions)
- A monorepo: still problematic even with v2 (14.4K → 138 max collisions)

This test infrastructure completes the series' validation story, providing both stability verification and quantitative collision analysis to help users understand how the new hash version might affect their repositories. The tests are well-designed to complement the earlier performance benchmarks in the series.
