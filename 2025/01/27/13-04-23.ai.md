This is a platform compatibility patch in the ongoing reftable independence series (15/19). It reorganizes Windows-specific compatibility code by splitting mingw.h into two headers: mingw/posix.h for POSIX emulation functions and mingw/compat-util.h for Git-specific Windows utilities. The change affects build configurations across Makefile, CMake, and meson, updating paths and dependencies accordingly.

The patch moves:
- Core POSIX emulation (file I/O, process handling, signals) to mingw/posix.h
- Git-specific Windows utilities (path validation, UTF conversion, SSL wrappers) to mingw/compat-util.h
- Updates all references in build systems (config.mak.uname, CMakeLists.txt, meson.build)
- Maintains MSVC compatibility by adjusting its include path

Key technical changes include preserving all existing functionality while:
- Separating concerns between POSIX layer and Git-specific Windows needs
- Maintaining identical behavior for UTF-8/UTF-16 conversion utilities
- Keeping SSL file descriptor wrappers and path validation logic
- Ensuring build system compatibility across all supported configurations

This is a mechanical but important step in the reftable independence effort, as it helps disentangle platform-specific code from Git's core utilities. The patch follows the series' pattern of focused, behavior-preserving changes while cleaning up the Windows compatibility layer's organization.
