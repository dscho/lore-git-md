Patrick Steinhardt's v4 series (18 patches) completes the architectural separation of the reftable library from Git core infrastructure, with all major technical concerns resolved through rigorous review. The series has evolved through multiple iterations addressing build system integration, memory safety, and I/O independence.

1. Architectural state:
   - Reftable now depends exclusively on system.h/system.c (external interface) and compat/posix.h (541 lines of isolated POSIX functionality)
   - Git-specific tooling fully excluded via Makefile/CMake/meson build system updates
   - Final git-compat-util.h dependencies eliminated through:
     * POSIX header separation
     * Open-coded utility replacements (including read_in_full, write_in_full, COPY_ARRAY, BUG() removal, st_mult() replacement, endian conversion functions, ARRAY_SIZE, RNG, sleep functionality, and now SWAP)
     * Platform-specific header reorganization
     * Build system exclusions (COCCI_SOURCES)
   - Memory mapping independence completed with xmmap() removal in blocksource.c
   - Error handling now fully independent with all fatal errors converted to returns
   - Random number generation abstracted via reftable_rand() interface
   - Sleep functionality uses direct poll() calls
   - SWAP macro replaced with REFTABLE_SWAP implementation

2. Technical implementation updates:
   - Core utility replacements now complete:
     * read_in_full() → open-coded read loop in stack.c
     * write_in_full() → reftable_write_data()
     * COPY_ARRAY() → open-coded copy
     * BUG() → REFTABLE_API_ERROR returns
     * st_mult() → reftable_alloc_size() with overflow checking
     * Git endian → reftable_put_be*/reftable_get_be* inline functions
     * ARRAY_SIZE() → open-coded
     * Git RNG → reftable_rand()
     * sleep_millisec() → direct poll() call
     * SWAP() → REFTABLE_SWAP (new in part 13/18)
   - I/O subsystem fully independent with:
     * write_in_full() → reftable_write_data()
     * xmmap() → direct mmap()
     * read()/write() loops verified
   - Error handling boundary now clean with all fatal errors removed
   - Memory safety maintained (Justin Tobler acked)
