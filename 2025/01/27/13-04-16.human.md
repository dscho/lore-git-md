Refactoring patch in the reftable independence series. This is patch 8/19 in a larger effort to decouple the reftable library from Git's core infrastructure.

The patch replaces Git's `st_mult()` overflow-checking multiplication helper with a new reftable-specific implementation in `basics.h`. The key changes are:

1. Introduces `reftable_alloc_size()` to manually check for size_t multiplication overflow, returning an error rather than dying like `st_mult()` would
2. Updates three array macros (`REFTABLE_ALLOC_ARRAY`, `REFTABLE_REALLOC_ARRAY`, and the inline `reftable_alloc_grow`) to use the new overflow checking
3. Maintains the same memory allocation behavior but converts fatal errors to NULL returns with ENOMEM

This continues the series' pattern of systematically removing Git dependencies while preserving functionality. The change is mechanical but important for making reftable truly standalone - overflow checking remains robust but no longer relies on Git's error handling. The patch follows the established approach of the series, focusing on one specific removal (st_mult) with clear, contained changes.
