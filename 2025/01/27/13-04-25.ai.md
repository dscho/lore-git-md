This is patch 17/19 in a series refactoring the reftable library to remove Git-specific dependencies. The patch splits POSIX-emulation functionality out of git-compat-util.h into a new compat/posix.h header.

The change moves 541 lines of POSIX-related definitions and compatibility wrappers (file I/O, time functions, string operations, etc.) while leaving Git-specific utilities in git-compat-util.h. Key moved components include mmap/munmap wrappers, time/stat functions, string utilities (strlcpy, strtoumax), and various POSIX header defines. The split follows the series' pattern of separating platform compatibility from Git internals.

The patch continues the systematic approach seen in previous patches, carefully preserving all functionality while removing dependencies. It maintains Windows compatibility through the existing mingw/msvc split headers. The change is mechanical but thorough, touching core POSIX emulation that many parts of Git rely on.

For future reference in this thread: this patch introduces the new compat/posix.h header containing all POSIX-emulation code previously mixed in git-compat-util.h, including file operations (open/read/write/stat), time functions, string utilities, and system headers. The remaining git-compat-util.h retains Git-specific macros and utilities. Windows compatibility is handled through the existing mingw.h and msvc.h split headers established in patches 15-16.
