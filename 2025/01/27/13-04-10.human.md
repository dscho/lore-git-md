Refactoring patch in the reftable independence series. This is the second of 19 patches working to make the reftable library fully standalone by removing Git-specific dependencies.

The patch replaces Git's `write_in_full()` helper with a new `reftable_write_data()` function that implements similar write-with-retry logic directly using POSIX calls. The new function handles partial writes and EAGAIN/EINTR errors explicitly while maintaining the same error semantics. This change affects several write operations in the reftable stack implementation, including writes to the tables list during compaction and commit operations.

The change is mechanical but important for the series' goal of eliminating Git infrastructure dependencies. The implementation appears careful to maintain existing behavior while using lower-level POSIX operations. As with the first patch in the series, this demonstrates the systematic approach being taken to replace Git helpers with direct equivalents.
