Performance optimization introducing configurable name hashing for pack-objects delta compression.

This patch adds a `--name-hash-version` option to `git pack-objects`, allowing users to choose between two algorithms for path-based delta grouping. Version 1 maintains the existing behavior (prioritizing path endings), while Version 2 introduces a new algorithm that better handles files with similar names in different directories. The change comes with dramatic real-world improvements - in one case reducing a pack from 37GB to 7GB.

The implementation includes safety checks to prevent version mixing (particularly with bitmaps, which currently require Version 1) and comprehensive tests. Documentation explains the tradeoffs between versions, with Version 2 showing particular benefits for repositories containing many similarly-named files in different directories (common in JavaScript/C# ecosystems).

This is part of a well-reviewed series (now in its 4th iteration) that has evolved from initial proposals through careful performance validation and community feedback. The patch stands ready for inclusion, demonstrating measurable performance wins while maintaining backward compatibility.
