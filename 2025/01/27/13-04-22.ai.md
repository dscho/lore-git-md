This is patch 14/19 in a series refactoring the reftable library to remove Git-specific dependencies. The patch replaces Git's `UNUSED` macro with a new `REFTABLE_UNUSED` implementation that provides weaker guarantees (only suppressing unused parameter warnings without enforcing non-use) but avoids compiler-specific logic.

The change affects multiple reftable components:
- Introduces `REFTABLE_UNUSED(x)` macro in basics.h that casts to void
- Updates blocksource.c, iter.c, record.c, and writer.c to use the new macro
- Maintains the same parameter suppression but with simpler implementation
- Touches core record handling, iterator operations, and block source management

The patch continues the series' pattern of systematically replacing Git utilities with reftable-specific implementations while preserving functionality. The change is mechanical but thorough, updating all relevant call sites. The weaker guarantee of `REFTABLE_UNUSED` is deemed sufficient for the reftable use cases while simplifying the implementation.

This represents another step toward complete independence from Git's utility macros, following previous patches that replaced `COPY_ARRAY`, `SWAP`, and other Git-specific functionality. The change is low-risk as it doesn't modify actual behavior - just the mechanism for suppressing unused parameter warnings.
