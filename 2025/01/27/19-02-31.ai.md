Performance optimization patch adding test infrastructure for the configurable name hashing feature in pack-objects.

This patch introduces `GIT_TEST_NAME_HASH_VERSION` as an environment variable to control the name hash version used by `git pack-objects` during testing. The variable allows testing different hash versions without modifying test cases, though it's explicitly not added to the standard CI test matrix due to existing workload constraints.

Key technical aspects:
- Defaults to version 1 when unset (matching current behavior)
- Modifies several test scripts to disable the variable where it would interfere with:
  - Thin bundle tests that depend on specific delta bases
  - Bitmap tests that check exact output
  - Tests comparing stderr output that would include the hash version warning
- Updates t/README to document the new test variable
- The implementation adds a new initialization point in `cmd_pack_objects()` to read the environment variable before validation
- Test changes focus on maintaining existing behavior in sensitive cases while allowing broader testing elsewhere

The patch is part of Stolee's v4 series introducing configurable name hashing, with all major design decisions already settled in previous iterations. This addition provides flexible testing capabilities while carefully preserving existing test expectations where hash version changes would cause false failures.
