This is part 8 of a 19-patch series refactoring the reftable library to remove Git dependencies. The patch focuses on array allocation utilities in reftable/basics.h.

The change replaces Git's `st_mult()` overflow-checking multiplication with a new `reftable_alloc_size()` helper that performs manual overflow detection. The key differences are:
1. Instead of dying on overflow (as `st_mult()` does), the new version returns an error (setting errno to ENOMEM)
2. The change affects three macros: `REFTABLE_ALLOC_ARRAY`, `REFTABLE_REALLOC_ARRAY`, and the inline `reftable_alloc_grow()` function
3. The new implementation maintains the same safety checks but removes the Git dependency

The patch follows the series' pattern of systematically replacing Git-specific utilities while preserving functionality. The error handling change is particularly notable as it makes the library more suitable for standalone use where fatal errors may be undesirable. The implementation carefully maintains the same overflow protection while converting to a more flexible error-reporting model.
