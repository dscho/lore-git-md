This is part 5 of a 19-patch series refactoring the reftable library to remove Git-specific dependencies. The patch focuses on eliminating the use of Git's `BUG()` macro from `reftable_record_init()`, which previously would abort the program when encountering an unknown record type.

The change makes `reftable_record_init()` return an error code (REFTABLE_API_ERROR) instead of crashing, making the library more robust and self-contained. The patch updates all callers to handle this new error condition, including several test files that now verify successful initialization.

This is a straightforward but important change in the series' overall goal of making reftable usable as a standalone library. The conversion follows the established pattern of replacing Git-specific behaviors with portable alternatives while maintaining the same functionality. The patch appears well-contained with thorough updates to both implementation and tests.
