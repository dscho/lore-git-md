This is the final patch in Derrick Stolee's performance optimization series introducing configurable name hashing for pack-objects delta compression. The patch adds a safety check to prevent the name hash version from changing mid-operation in `git pack-objects`.

The change enforces consistency by adding a static variable to track the hash version used during the first call to `pack_name_hash_fn()`. If subsequent calls attempt to use a different version (which could happen when interacting with bitmaps, since they currently require version 1), Git will trigger a BUG() to fail fast rather than produce inconsistent results.

This is a defensive programming measure that ensures the pack-objects process maintains internal consistency while the series prepares for potential future bitmap format updates that could support multiple hash versions. The patch is small and focused, completing the series' safety mechanisms after extensive performance testing and review.
