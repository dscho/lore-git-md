This is the final patch in a 19-part series refactoring the reftable library to be fully standalone, removing its dependencies on Git's core infrastructure. The patch modifies the Makefile to exclude reftable sources from Coccinelle semantic patching, since the library no longer uses Git's helper functions that Coccinelle rules typically target. The change prevents false positives that could occur from patterns matching reftable code that intentionally avoids Git-specific utilities. This completes the architectural separation established by the previous 18 patches, which systematically replaced Git helpers with direct POSIX calls or reftable-specific implementations. The exclusion is implemented by adding `reftable/%` to the filter-out list for COCCI_SOURCES, alongside the existing THIRD_PARTY_SOURCES exclusion. The patch is straightforward and uncontroversial, representing a logical conclusion to the series' goal of making reftable independent from Git's internal utilities.
