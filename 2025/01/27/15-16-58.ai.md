This is a refactoring patch from Christian Couder's promisor-remote/LOP series, specifically making a string sanitization utility function available for wider use. The patch moves the `redact_non_printables()` function from being static in version.c to being exported via version.h, with its documentation moved to the header file. The function performs ASCII sanitization by replacing non-printable characters (codes below 32 or above 127) with dots while also trimming whitespace. This change is part of the series' string handling standardization efforts mentioned in the thread context, where the helper will be reused outside its original context. The implementation remains unchanged - this is purely about making the existing functionality available to other parts of the codebase. The patch follows clean code organization practices by keeping the function's documentation with its declaration in the header.
