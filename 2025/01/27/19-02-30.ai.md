- Introduces flexible subcommand testing infrastructure (`test_subcommand_flex`) to verify option passthrough without requiring exact argument matching
- Updates documentation and usage strings to include the new option
- Removes `repack` from the help-text verification allowlist to ensure future doc/synopsis consistency

- Adds new `name_hash_version` field to `pack_objects_args` struct
- Passes the version parameter when set via strvec formatting
- Includes test case verifying the option reaches `pack-objects`
- Maintains backward compatibility when option not specified
