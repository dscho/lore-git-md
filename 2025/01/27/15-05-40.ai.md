This is a technical discussion about test compatibility issues in a patch series introducing promisor-remote capabilities. The email is part of an ongoing thread where Christian Couder is investigating test failures related to the interaction between the new promisor-remote feature and incremental multi-pack index writing.

The key technical details are:
- The test script t5709-midx-increment-write.sh fails when GIT_TEST_MULTI_PACK_INDEX_WRITE_INCREMENTAL is enabled
- The failure occurs even without any code changes from the promisor-remote series, suggesting it's a pre-existing issue with incremental MIDX writing during repacking
- The proposed solution is to disable both GIT_TEST_MULTI_PACK_INDEX and GIT_TEST_MULTI_PACK_INDEX_WRITE_INCREMENTAL in the test script, following the pattern used in other repack-related tests
- Christian provides a detailed test script demonstrating the issue and confirms the workaround makes it pass

The discussion clarifies this isn't an incompatibility with the promisor-remote feature itself, but rather a separate issue with MIDX incremental writing that needs to be worked around in the test environment. Christian indicates this solution will be included in v4 of the patch series.
