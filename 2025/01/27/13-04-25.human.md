Refactoring patch splitting POSIX compatibility from Git-specific utilities.

This is patch 17/19 in Patrick Steinhardt's series to make the reftable library standalone. The patch systematically extracts all POSIX-emulation functionality from git-compat-util.h into a new compat/posix.h header, leaving only Git-specific utilities in the original file. 

The change is mechanical but extensive - moving 541 lines of POSIX-related definitions while removing 529 lines from git-compat-util.h. The new header contains all the platform-specific defines, POSIX function replacements (like git_time, git_mmap, etc.), and compatibility wrappers needed to make Git work across different operating systems. This separation is key for the reftable library's goal of being usable outside Git without pulling in Git-specific dependencies.

The patch follows the series' established pattern of focused, behavior-preserving changes. It builds on previous work that already split Windows-specific compatibility code (patches 15-16) and systematically replaces Git helpers with direct POSIX equivalents. The end result is cleaner separation of concerns, with POSIX emulation now clearly separated from Git utilities.

This appears to be a well-executed step in the larger reftable decoupling effort, though reviewers will want to verify no POSIX functionality needed by reftable was accidentally left behind in git-compat-util.h. The patch maintains all existing functionality while making the codebase more modular.
