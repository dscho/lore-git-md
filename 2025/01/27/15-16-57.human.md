This is a refactoring patch in Christian Couder's promisor-remote/LOP series, extracting string sanitization logic into a reusable function. The patch takes string handling code from `git_user_agent_sanitized()` and moves it to a new `redact_non_printables()` helper function, which trims whitespace and replaces non-printable characters with dots. 

The change serves two purposes: it makes the sanitization logic available for reuse in future patches (though currently kept static), and improves the code by using `strbuf_detach()` for cleaner string ownership handling. The implementation replaces manual ASCII range validation with `isprint()` while preserving special handling for spaces.

This appears to be a straightforward code organization improvement with no behavior changes. The patch builds on Usman Akinyemi's earlier string sanitization work in this series, with Christian Couder mentoring. The change is well-contained to `version.c` and maintains the same functionality while making the code more maintainable.
