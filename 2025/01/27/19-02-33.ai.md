This is a test infrastructure patch in Derrick Stolee's performance optimization series for pack-objects name hashing. It introduces a new test helper and performance benchmarks to analyze hash collision behavior between the existing and new name-hash algorithms.

The patch adds:
1. A `test-tool name-hash` command that computes both v1 and v2 hash values for input paths, useful for verifying hash stability across Git versions (important for bitmap compatibility)
2. A new performance test (p5314) that measures collision rates by:
   - Counting distinct hash values
   - Tracking maximum collision multiplicity (how many paths map to the same hash)
3. A stability verification test in t5310 that checks specific known hash values for both algorithms using carefully chosen collision-prone paths

The commit demonstrates significant collision improvements in real-world repos:
- Git repo: v1 has 13 max collisions vs v2's 9
- Fluentui repo: v1 has 279 max collisions vs v2's 44
- Internal monorepo: v1 has 14.4K max collisions vs v2's 138

The test infrastructure provides quantitative evidence supporting the series' core claim that v2 reduces problematic collisions while maintaining backward compatibility. The stability test ensures future changes won't break existing bitmap files. This completes the performance validation toolkit for the name-hash optimization work.
