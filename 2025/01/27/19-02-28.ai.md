Performance optimization introducing a new name-hashing algorithm for pack-objects delta compression. This is the foundational patch in Derrick Stolee's series (now at v4) that adds configurable name-hashing versions to improve delta compression efficiency.

The patch introduces `pack_name_hash_v2()` as an alternative to the 2006-era `pack_name_hash()` function. The new version makes two key improvements: better handling of non-ASCII characters through bit manipulation, and directory hierarchy sensitivity via XOR operations with downshifted parent hashes. The implementation carefully preserves hash locality for similar file types while reducing unwanted collisions between unrelated files.

Technical details include:
- Bit reversal for non-ASCII characters to maximize entropy influence
- Directory-aware hashing via parent hash XOR operations
- Maintains the same function signature for drop-in replacement
- Prepares for versioned hash selection (to be wired up in later patches)

This version (v2) emerged as the preferred alternative after discussion eliminated an earlier proposed v3 (full-name-hash) approach. The changes are focused on pack-objects.h, with test integration and performance validation coming in subsequent patches. The implementation shows particular attention to backward compatibility and incremental adoption, with the existing v1 behavior preserved as the default.
