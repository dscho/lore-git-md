This is part of the ongoing reftable library refactoring to make it fully portable and independent from Git's core infrastructure. Patch 16/19 focuses on Windows/MSVC compatibility by reorganizing the POSIX-related functionality.

The patch splits the MSVC compatibility code into two clear components: POSIX-related functionality (moved to `msvc/posix.h`) and Git-specific utilities (in the new `msvc/compat-util.h`). This mirrors the similar split done for MinGW in patch 15 and continues the series' systematic approach to disentangling platform-specific code from Git's core utilities.

Key changes include:
- Renaming `msvc.h` to `msvc/posix.h` and updating its contents to focus purely on POSIX emulation
- Creating a new `msvc/compat-util.h` that includes both POSIX and MinGW compatibility utilities
- Updating build configurations (Makefile and meson) to handle the new file locations

The changes are mechanical but important for the overall goal of making reftable standalone. The patch follows the series' pattern of maintaining all existing functionality while cleaning up dependencies. Build system updates ensure the changes work across all supported configurations.
