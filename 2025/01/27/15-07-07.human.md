Refactoring patch for string sanitization utility. This is part of Christian Couder's ongoing work on version capabilities, but focuses on a general string utility function that replaces non-printable characters with dots. The patch responds to Junio Hamano's feedback about unclear documentation ("Useful for sending capabilities" will be removed) and implementation concerns about information loss. 

Christian notes that Usman Malik has already implemented similar functionality with improvements (collapsing multiple non-printable runs into single dots) for the os-version capability work, so he plans to reuse those patches in v4 of his series rather than reinventing the wheel. The discussion shows this is a straightforward refactoring that multiple features need, with the implementation details being worked out in parallel by different contributors.
