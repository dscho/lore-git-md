This is the final patch in Patrick Steinhardt's Meson build system transition series, focusing on CI integration for Visual Studio builds. The patch adds Windows CI jobs to both GitHub Actions and GitLab CI that build and test Git using Meson with Visual Studio.

The implementation makes several practical compromises to balance testing needs with CI resource constraints. The test job is marked as manual in GitLab to avoid redundant Windows test runs, while GitHub gets mandatory testing due to platform limitations. Perl support is disabled to avoid path format mismatches, and dependencies are handled automatically by Meson rather than using the Git for Windows SDK. The test slicing logic is reimplemented in PowerShell since the standard shell script isn't available.

The patch appears well-considered, with clear explanations for each design choice and a note about an upstream Meson pull request that could simplify the test slicing implementation in the future. All tests are reported as passing with this configuration, completing the platform coverage goals of the Meson transition series.
