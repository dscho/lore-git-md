This is a follow-up discussion in Patrick Steinhardt's ongoing Meson build system transition series, specifically addressing version management changes. The original patch (2/9) proposed moving Git's default version definition from GIT-VERSION-GEN to a separate file to better accommodate Meson's needs.

Junio Hamano expresses skepticism about the change, questioning whether modifying Git's established version management workflow just to satisfy Meson's requirements is justified. He suggests that simply grepping for "^DEF_VER=" in the existing GIT-VERSION-GEN file might be a less intrusive solution than restructuring the version file layout.

The exchange highlights a tension between maintaining Git's existing build infrastructure and adapting it for Meson compatibility. While Patrick's approach aims for a more systematic solution, Junio appears concerned about unnecessary changes to long-standing practices. This discussion represents one of the final refinements in the comprehensive Meson transition series, which has otherwise seen smooth progress.
