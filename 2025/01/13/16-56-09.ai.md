3. The porcelain/plumbing distinction exists precisely to communicate which commands maintain output stability guarantees for script writers, regardless of how end users might employ them.

The discussion reveals a fundamental disagreement about classification priorities - whether workflow purpose (Haugsbakk's position) or output stability guarantees (Hamano's position) should determine a command's category. This touches on broader questions about how Git communicates interface stability expectations to both end users and script authors.
