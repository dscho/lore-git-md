Bugfix discussion regarding Apple Git's outdated version behavior.

Torsten Bögershausen responds to a bug report about `git diff --merge-base` failing with annotated tags on Apple Git (version 2.39.5) while working correctly on Windows. The thread had previously established this was a known bug fixed in Git 2.43.0 (commit 4adceb5a299). Torsten clarifies that the mailing list doesn't support third-party Git distributions like Apple's, suggesting the reporter compile Git from source to get current versions with all fixes. The response maintains the technical context (version discrepancy, specific command behavior) while redirecting support responsibility away from the core Git project.

Key points for future reference: the issue stems from using an outdated Apple-provided Git (2.39.5) missing the 2.43.0 fix for tag handling in merge-base diffs. The thread shows the Git community's stance on supporting only official builds, with self-compilation recommended to access current fixes. No new technical details are added beyond the established version mismatch explanation.
