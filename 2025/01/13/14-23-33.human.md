Bug report about `git diff --merge-base` behavior with tags on Apple Git.

André de Castro reports unexpected behavior when using `git diff --merge-base` with annotated tags on macOS. The command fails with "fatal: --merge-base only works with commits" when passing a tag directly, though it works when the tag is first resolved to a commit hash. The same command works as expected on Windows with Git Bash.

The report includes detailed system information showing this occurs with Apple Git version 2.39.5 on an ARM64 Mac running Darwin 24.2.0. The workaround of manually resolving the tag to a commit hash first (`git diff --merge-base $(git rev-list -n 1 <tag>) HEAD`) does produce the expected diff output.

This appears to be a platform-specific issue in Apple's Git distribution, as the behavior differs from the standard Git implementation. The report is clear and includes reproduction steps, expected vs actual behavior, and a working workaround. The inclusion of detailed system information will help maintainers investigate the discrepancy between Apple Git and mainline Git behavior.
