This is part 2 of Patrick Steinhardt's series to enhance Git's Meson build infrastructure, following the performance-focused first patch. The change moves Git's default version string from being hardcoded in GIT-VERSION-GEN to a separate GIT-VERSION file, which Meson can read directly.

The patch solves a minor but annoying issue where Meson builds would show stale version numbers (v2.47.GIT) while the actual version comes from GIT-VERSION-GEN. The author considered several approaches but chose this clean solution that avoids platform-specific shell issues while preparing for future build script reorganization.

The implementation is straightforward: a new GIT-VERSION file is added containing the current version (v2.48.0), GIT-VERSION-GEN is modified to read from this file, and meson.build is updated to use the file directly. This maintains a single source of truth for the version while making it more accessible to Meson.

The change is well-motivated with clear alternatives considered, and the implementation appears clean with minimal impact beyond the build system. As part of the larger Meson transition effort, this helps align the build systems while removing a minor inconsistency that could confuse developers.
