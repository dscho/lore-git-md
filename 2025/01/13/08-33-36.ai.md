This is a build system patch in Patrick Steinhardt's ongoing Meson transition series, specifically addressing header dependencies in parallel builds. The change fixes a race condition where certain generated headers ("config-list.h" and "hook-list.h") were incorrectly listed as library sources when they are actually used by builtin commands, potentially causing compilation failures in parallel builds. The patch moves these headers to the correct dependency list while keeping "command-list.h" (used by library code) in the libgit sources.

The technical change involves restructuring meson.build to properly associate each generated header with its consumer - builtin commands for "config-list.h" and "hook-list.h", versus the core library for "command-list.h". This prevents parallel build races where builtins might try to compile before their required headers were generated. The fix was prompted by a report from Evan Martin and demonstrates careful attention to build system correctness during the Meson migration.
