This is a build system fix in Patrick Steinhardt's ongoing Meson transition series (part 3/9). The patch corrects dependency issues with generated headers in parallel builds, where some documentation-derived headers were incorrectly assigned to the library sources when they were actually needed by builtin commands.

The change moves "config-list.h" and "hook-list.h" generation from libgit_sources to builtin_sources, while keeping "command-list.h" in libgit sources where it belongs (used by help.c). This prevents race conditions where builtins might try to compile before their required headers were generated. The fix was prompted by a report from Evan Martin about parallel build failures.

The patch is a straightforward correction that aligns the Meson build configuration with the actual header usage patterns. It's a small but important fix in the broader effort to make Meson builds as reliable as the traditional Makefile system. The change is well-explained and narrowly focused, touching only the meson.build file with clear additions and removals.
