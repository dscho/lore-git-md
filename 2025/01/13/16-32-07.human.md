Bugfix follow-up regarding `git diff --merge-base` with annotated tags. Kristoffer Haugsbakk confirms that the reported issue (where Apple Git 2.39.5 rejects annotated tags with "fatal: --merge-base only works with commits") was fixed in Git 2.43.0. The fix came via commit 4adceb5a299, which corrected the behavior to properly handle annotated tags while still rejecting non-commit objects like trees. 

This appears to be a simple case of the original reporter using an outdated version that predates the fix. The response helpfully points to both the specific version where the fix landed and the commit that implemented it, making this easy to verify. For users experiencing this issue, the solution is straightforward: upgrade to Git 2.43.0 or later. The thread shows good technical hygiene with clear version references and a direct link to the relevant commit discussion.
