This thread discusses a proposed documentation change to add Vim modelines to Git's AsciiDoc files, starting with `git-add.txt` as an example. The author suggests this would improve syntax highlighting in editors and make documentation editing experience smoother for contributors. They note that AsciiDoc is frequently confused with Markdown by tooling, and offer two alternative solutions: adjusting the modeline position or using `.adoc` file extensions for better tool recognition. The patch is currently marked as RFC, indicating the author is open to feedback on the best approach. The change is purely about contributor workflow and wouldn't affect end users.
