This is part of Patrick Steinhardt's ongoing Meson build system transition series, specifically adding fuzzer support. The patch introduces Meson integration for Git's OSS-Fuzz test harnesses, which were previously only built under the Makefile system.

Key technical details:
- Adds a new Meson build option `fuzzers` (defaults to false)
- Creates a new `oss-fuzz/meson.build` file listing all fuzzer targets (commit-graph, config, credential, date, pack headers/idx, parse-attr-line, url-decode)
- Modifies CI scripts to enable fuzzers by default in Meson builds
- Each fuzzer is built as an executable linking against libgit and common_main
- Maintains the same fuzzer source files and structure as the Makefile version

The patch follows the series' pattern of methodically porting each build system component while maintaining functionality. It cleanly integrates with the existing OSS-Fuzz infrastructure while adapting to Meson's build conventions. The implementation appears straightforward with no obvious compatibility issues or missing pieces.
