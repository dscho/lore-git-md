Bug report about `git diff --merge-base` behavior with tags on Apple Git. The reporter describes a discrepancy between Apple Git (version 2.39.5) on macOS and standard Git on Windows when using annotated tags with `--merge-base`. On Apple Git, the command fails with "fatal: --merge-base only works with commits" when given a tag, while on Windows it works as expected. The reporter found a workaround by first resolving the tag to a commit hash using `git rev-list`.

The issue appears specific to Apple's Git build on ARM64 (Darwin 24.2.0), though the exact cause isn't clear from the report. The reporter provides complete system information including compiler details (clang 16.0.0) and enabled hooks (only pre-push). The workaround suggests this might be a parsing or argument handling difference in Apple's build rather than a fundamental limitation of the `--merge-base` feature.

Key technical details for future reference: the failing command format (`git diff --merge-base <tag> HEAD`), the exact error message, the working Git version (2.39.5 Apple Git-154), and the successful workaround using `git rev-list` to resolve the tag first. The cross-platform nature of the issue (working on Windows Git Bash but not Apple Git) suggests this may be worth investigating as a potential Apple Git regression.
