This is a follow-up in a resolved bug thread about `git diff --merge-base` behavior with annotated tags. The original issue involved Apple Git 2.39.5 incorrectly rejecting annotated tags while standard Git accepted them, which was fixed in upstream Git 2.43.0.

André de Castro confirms the fix works in Homebrew's Git 2.48.0, validating Kristoffer Haugsbakk's earlier identification of the fix in commit 4adceb5a299. The thread has established this was purely a version-specific issue (not platform-specific) and that the mailing list doesn't support third-party Git distributions. The exchange serves as a case study in version discrepancies, with the solution path being to use current Git versions either through Homebrew or source compilation. No technical questions remain open - this is effectively a confirmation and thank-you note closing out the discussion.
