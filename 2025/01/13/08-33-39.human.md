Feature patch in the Meson build system transition series, adding fuzzer support.

This is patch 6/9 in Patrick Steinhardt's ongoing series to convert Git's build system to Meson. The patch adds support for building Git's fuzzers under Meson, introducing a new build option `-Dfuzzers=true` that enables compilation of the existing fuzzer test programs. The implementation creates a new `oss-fuzz/meson.build` file that lists all the fuzzer programs (commit-graph, config, credential parsing, etc.) and wires them into the build system.

The patch also updates the CI configuration to build fuzzers by default in Meson-based test runs. This maintains parity with the existing Makefile-based build system where fuzzers are built as part of normal test infrastructure. The implementation appears straightforward and well-integrated with the rest of the Meson build system, following the same patterns used for other optional components.

This continues the series' pattern of methodically porting each build system component while maintaining all existing functionality. The fuzzer support is particularly important for security testing, and its inclusion in CI ensures it will be regularly exercised. The patch looks clean and focused, with no obvious technical issues.
