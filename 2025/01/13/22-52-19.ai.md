Maintainer response in AsciiDoc file extension discussion.

Junio C Hamano, the Git maintainer, weighs in briefly on the ongoing discussion about improving editor support for Git's documentation files. The response is terse but significant as it comes from the project's decision-maker, suggesting the technical discussion may now move toward implementation details rather than solution selection.

Key implications from this brief response:
- Maintainer approval for the `.adoc` extension strategy
- No objections raised to the technical merits discussed previously
- Likely next steps will involve planning the actual file renaming process
- The thread can now focus on implementation rather than solution debate
- Maintainer's tacit approval of the shift away from modelines
