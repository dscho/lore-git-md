This is a debugging workflow discussion in the ongoing thread about using Visual Studio Code with Git's development environment.

Jon Forrest shares an alternative approach he's found for debugging Git using VS Code on Fedora, supplementing the previously discussed CMake and Meson build system options. His method involves building Git normally from source, then using VS Code to attach to the resulting binary and set breakpoints starting from `main()`. While this works for basic execution tracing, he notes some limitations around process forking and thread handling, plus a minor issue with the executable name mismatch.

The email provides practical, field-tested information that could help others experimenting with similar setups, though it doesn't address the more complex debugging scenarios that were part of the original inquiry. The thread remains open for further discussion of comprehensive solutions, particularly awaiting Patrick Steinhardt's promised Meson/VS integration fixes. This contribution helps document real-world experience while the broader build system support is being finalized.
