Security/performance patch in the Meson build system transition series. This is a follow-up to patch 7/9 which made the cryptographically secure random number generator (CSPRNG) backend configurable in the Meson build. 

Patrick Steinhardt notes that the current implementation generates warnings when used with Meson v0.61.0 (the minimum required version) due to using newer features. He plans to modify the code to use `compiler.has_header_symbol()` consistently for better compatibility and readability. Additionally, he mentions adding another patch to make CI builds fail on Meson warnings by using `--fatal-meson-warnings`.

This is part of the comprehensive Meson transition series which has been methodically converting Git's build infrastructure. The CSPRNG backend work is particularly important as it affects security-sensitive random number generation across platforms. The patch maintains the same functionality while addressing compatibility concerns, showing attention to both technical correctness and build system hygiene.
