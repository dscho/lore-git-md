This is a follow-up discussion in the zlib-ng backend optimization series, addressing build system parity concerns.

Patrick Steinhardt responds to Taylor Blau's review about Makefile support for the new zlib-ng backend option. The current implementation only supports meson builds, which Taylor flagged as potentially problematic for users still relying on the traditional Makefile build system. Patrick acknowledges this gap and agrees the feature should work consistently across both build systems, despite some initial frustration with Makefile configuration details.

The exchange confirms the technical limitation (no current Makefile support) while establishing consensus that both build systems should maintain feature parity. Patrick indicates willingness to implement the Makefile side, suggesting this will be addressed in a future revision of the series. This keeps the performance optimization accessible to all Git users regardless of their build system preference.
