This is part of Patrick Steinhardt's ongoing series to enhance Git's Meson build infrastructure, specifically focusing on version management. The patch extracts the default version string from GIT-VERSION-GEN into a new GIT-VERSION file, solving the problem where Meson builds would show stale version information. The change makes the version single-sourced while maintaining compatibility with existing version bump scripts. 

The technical approach moves the hardcoded `DEF_VER=v2.48.0` from GIT-VERSION-GEN to the new GIT-VERSION file, which both the shell script and Meson build system now reference. This solves the cosmetic issue where `meson setup` would show outdated versions while also preparing for a future reorganization of build scripts into a dedicated directory. The implementation is straightforward, touching only three files with minimal changes.

Key files modified include the new GIT-VERSION file, GIT-VERSION-GEN (which now reads from this file), and meson.build (which uses the file directly). The patch maintains all existing functionality while improving maintainability - version bumps will now automatically propagate to both build systems without manual synchronization.

This change is part of the broader effort to make Meson a first-class build system for Git, following up on the performance improvements from the first patch in the series. It demonstrates careful consideration of cross-platform implications (notably Windows shell setup constraints) while choosing the simplest robust solution. The commit message thoroughly documents the considered alternatives and rationale.
