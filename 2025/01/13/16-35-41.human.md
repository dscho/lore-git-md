This is a response to a bug report about platform-specific Git behavior, clarifying support boundaries.

Torsten Bögershausen responds to a bug report about inconsistent `git diff --merge-base` behavior between Apple Git (2.39.5) on macOS and standard Git on Windows. While the thread summary notes this was actually a version-specific bug fixed in Git 2.43.0, Torsten takes a different angle - pointing out that the mailing list doesn't support third-party Git distributions like Apple's. 

He suggests compiling Git from source as the solution to get current behavior, offering help if needed. The response is brief and to the point, making clear the distinction between upstream Git development and vendor-supplied binaries. This is a common stance on the list when issues arise from modified or outdated vendor distributions rather than upstream Git itself.
