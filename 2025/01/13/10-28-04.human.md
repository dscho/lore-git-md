This is a build system fix addressing a subtle issue in the Meson build configuration. The patch ensures the correct `version-def.h` header is used when building Git with Meson, particularly when switching between Make and Meson builds.

The problem occurs because some compilers will prefer a `version-def.h` in the source directory (left over from a Make build) over the one generated in the build directory during Meson builds. This could lead to using outdated version information. The solution copies `version.c` to the build directory before compilation, ensuring the compiler finds the freshly-generated `version-def.h` alongside it.

The change is small (5 lines added, 1 removed) but important for build correctness. It's particularly relevant for developers who switch between build systems or do clean builds. The commit message clearly explains both the problem and solution, and the change appears straightforward with minimal risk.
