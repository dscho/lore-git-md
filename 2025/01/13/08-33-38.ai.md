This is part 5/9 of Patrick Steinhardt's ongoing Meson build system transition series, focusing on distribution archive generation. The patch wires up `meson dist` functionality to properly include Git version information in generated tarballs.

The key change modifies `GIT-VERSION-GEN` to handle Meson's distribution workflow, where the build happens in a different directory than the final archive location. The script now respects the `MESON_DIST_ROOT` environment variable and strips the `GIT_VERSION=` prefix when reading from the version file. The meson.build file gains a new `add_dist_script()` call that hooks into the distribution process to ensure the version file is properly populated.

The implementation addresses two technical challenges: (1) path handling between build and distribution directories via environment variable propagation, and (2) version string parsing to accommodate the existing template format. While the solution requires some string manipulation of the version file contents, the author notes this avoids adding yet another template file to the codebase.
