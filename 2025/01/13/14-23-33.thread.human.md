Here's a human-readable summary of the thread:

A bug report has surfaced regarding inconsistent behavior of `git diff --merge-base` when used with tags between Apple Git (version 2.39.5) on macOS and standard Git on Windows. The reporter found that while Windows Git correctly processes annotated tags with this command, Apple Git fails with the error "fatal: --merge-base only works with commits". 

The issue appears specific to Apple's ARM64 build (Darwin 24.2.0) with clang 16.0.0. A workaround was identified: first resolving the tag to a commit hash using `git rev-list` allows the command to work as expected. This suggests the problem lies in Apple Git's argument parsing rather than a fundamental limitation of the feature.

The cross-platform discrepancy makes this potentially noteworthy as an Apple Git regression, though the exact cause remains unclear from the initial report. The reporter provided detailed system configuration including enabled hooks (only pre-push) to aid in diagnosis.
