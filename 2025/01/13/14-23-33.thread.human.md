This thread reports and resolves an inconsistency in `git diff --merge-base` behavior with annotated tags between Apple Git (2.39.5) on macOS and standard Git on Windows. The original report showed Apple Git failing with "fatal: --merge-base only works with commits" when given a tag argument, while Windows version worked as expected. 

Kristoffer Haugsbakk followed up to confirm this was a known bug fixed in Git 2.43.0 by commit 4adceb5a299, which corrected the error message to properly allow annotated tags while still blocking non-commit objects like trees. The reporter's Apple Git version predates this fix, explaining their experience. The solution is to upgrade to Git 2.43.0 or later, as the behavior difference stems from version rather than platform-specific issues.
