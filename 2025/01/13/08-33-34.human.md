Build system refactoring with performance benefits. This is the first patch in Patrick Steinhardt's 9-part series enhancing Git's Meson build infrastructure.

The patch simplifies the version generation script `GIT-VERSION-GEN` by using `git describe --dirty` instead of the current manual dirty-check implementation. The change removes redundant code while also providing a measurable performance improvement, particularly on Windows where the speedup is significant (from ~800ms to ~400ms). The commit explains this was originally implemented before `--dirty` existed in Git's describe command.

The change is straightforward - replacing the manual dirty check with the built-in flag while maintaining the same functionality. Benchmarks show a 1.43x speedup on Unix systems, with even greater gains on Windows. This appears to be a clean, well-motivated improvement that fits into the larger Meson build system modernization effort.
