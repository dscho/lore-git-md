Bugfix follow-up regarding `git diff --merge-base` with annotated tags. This is a response to a bug report about inconsistent behavior between Apple Git (2.39.5) and standard Git on Windows when using `--merge-base` with annotated tags.

Kristoffer Haugsbakk confirms the issue was fixed in Git 2.43.0 by commit 4adceb5a299 ("diff: fix --merge-base with annotated tags"), which addressed the incorrect rejection of annotated tags when the error message was meant to only block non-commit-ish objects like trees. The reporter's version (Apple Git-154) predates this fix, explaining the "fatal: --merge-base only works with commits" error they encountered.

The response provides key technical details: the specific fix commit, the version (2.43.0) where it landed, and clarifies the original intent of the error message was to block tree objects (like `v2.48.0^{tree}`) while still allowing annotated tags. This confirms the reporter's issue is a known bug that's been resolved in newer Git versions, suggesting upgrading as the solution rather than needing further investigation into platform-specific behavior.
