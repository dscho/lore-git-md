Build system refactoring with performance improvements. This is the first patch in Patrick Steinhardt's 9-part series enhancing Git's Meson build infrastructure.

The patch simplifies version generation in GIT-VERSION-GEN by using `git describe --dirty` instead of the current manual dirty-check approach. The change removes redundant operations while maintaining the same functionality - the script still appends "-dirty" when built from an unclean worktree. Historical context explains this was originally split because early Git versions lacked the `--dirty` flag.

Performance benchmarks show a 1.43x speedup on Unix (12.5ms vs 17.9ms) and roughly 2x improvement on Windows (~400ms vs ~800ms), with the latter being particularly meaningful given Windows' slower filesystem operations. The implementation change is clean - just 5 lines removed and 1 modified in GIT-VERSION-GEN, replacing the manual diff-index check with the built-in dirty flag.

This appears to be a straightforward modernization that improves build performance, especially benefiting Windows users, while being part of the larger Meson build system improvements. The patch is well-motivated with historical context and benchmarks, and the implementation looks correct.
