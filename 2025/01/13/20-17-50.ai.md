Build system patch in a series about documentation generation. This is part 6 of 23 in Patrick Steinhardt's series to refactor how version information is embedded in Git's documentation. The patch moves version and date information injection from command-line arguments to generated configuration files (asciidoc.conf and asciidoctor-extensions.rb) using GIT-VERSION-GEN.

Key changes:
- Adds .gitignore entries for the generated files
- Removes direct git calls for version/date from Documentation/Makefile
- Adds rules to generate the config files from .in templates via GIT-VERSION-GEN
- Maintains the same content but changes the delivery mechanism

Renato Botelho notes in the reply that contrib/subtree/Makefile depends on these files and suggests it should trigger their build. This appears to be a follow-up consideration rather than a critique of the current patch. The change itself is a straightforward build system refactoring that centralizes version information handling while maintaining the same output.
