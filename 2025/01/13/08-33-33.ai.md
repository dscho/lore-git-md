This is a cover letter for a patch series focused on CI/build system improvements, specifically enhancing the Meson build infrastructure. The series from Patrick Steinhardt consists of 9 patches that:

1. Improve version generation by simplifying dirty marker computation and separating default version into its own file
2. Fix Meson build issues including header dependencies and Visual Studio compilation
3. Add new Meson capabilities like development environment wiring, distribution archive generation, and fuzzer support
4. Make the cryptographic CSPRNG backend configurable
5. Extend CI coverage to include Meson builds with Visual Studio

The changes touch core build components (GIT-VERSION-GEN), Meson configuration files, and CI workflows for both GitHub Actions and GitLab. The series builds on recent Meson-related work (ps/meson-weak-sha1-build) and includes comprehensive CI testing across platforms.

Key technical details include:
- New `GIT-VERSION` file for default version storage
- Meson option `crypto-backend` for CSPRNG configuration
- OSS-Fuzz integration via `oss-fuzz/meson.build`
- Visual Studio compatibility fixes in `meson.build`
- CI job additions in `.github/workflows/main.yml` and `.gitlab-ci.yml`

The changes appear well-motivated by the ongoing Meson adoption effort, with clear CI verification links provided. The patch series looks like a systematic expansion of Meson capabilities rather than isolated fixes.
