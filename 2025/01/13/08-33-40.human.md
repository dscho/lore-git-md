This is part of Patrick Steinhardt's ongoing Meson build system transition series, specifically addressing security-related configuration. Patch 7/9 makes the cryptographically secure pseudo-random number generator (CSPRNG) backend configurable in Meson builds, matching functionality that exists in the Makefile build system.

The patch adds a new `csprng_backend` option with several choices: `arc4random`, `arc4random_bsd`, `getrandom`, `getentropy`, `rtlgenrandom`, `openssl`, and `urandom` (plus `auto` for automatic detection). The implementation systematically checks for each backend's availability and adds the appropriate compile-time definitions, falling back to `/dev/urandom` if no specific backend is available or requested. The selected backend is now also included in Meson's build summary output.

This change follows the pattern established by other backend configurations in the series (like SHA-1 and HTTPS backends) and maintains compatibility with Git's existing security requirements. The implementation looks thorough, handling all the same CSPRNG options as the Makefile build while making them properly discoverable and configurable through Meson's interface.
