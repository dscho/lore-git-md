This is the final patch in Patrick Steinhardt's Meson build system transition series, focusing on CI integration for Visual Studio builds. The patch adds Windows CI jobs for Meson-based builds in both GitHub Actions and GitLab CI, completing the platform coverage for the new build system.

The implementation makes several pragmatic choices to balance testing needs with resource constraints. The test job is marked as manual in GitLab CI to avoid redundant Windows test runs, while GitHub runs it automatically due to platform limitations. Perl support is explicitly disabled to avoid path format mismatches with Git for Windows' Perl installation. The setup avoids the Git for Windows SDK, letting Meson handle dependency management instead. Test execution is implemented directly in PowerShell since test slicing isn't yet natively supported in Meson.

Key technical details include the use of Meson's artifact system to share builds between jobs, workarounds for Windows certificate store issues in GitLab's environment, and parallel test execution via manual slicing logic. The patch demonstrates all tests passing with this configuration, though it intentionally skips test artifact processing for failed jobs to minimize prerequisites.

This completes the series' goal of full Meson support across Git's supported platforms, with Visual Studio being the last major target. The implementation shows careful attention to practical constraints while maintaining test coverage, building on the previous patches' work to standardize build behavior across platforms.
