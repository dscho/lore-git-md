This is a discussion about build system compatibility in Patrick Steinhardt's Meson transition series, specifically around version file handling. Eli Schwartz weighs in on Junio Hamano's skepticism about moving the default version into a separate file to accommodate Meson.

The core debate is whether extracting DEF_VER into a separate GIT-VERSION file (as proposed in patch) is the right approach versus alternatives like grepping the existing GIT-VERSION-GEN file. Junio had expressed concern that this change might be bending Git's workflow to Meson's needs rather than the other way around. Eli counters that the "proper" solution is whatever reliably works across all platforms, particularly Windows where shell script execution can be problematic during bootstrap.

Eli suggests a Python-based grep alternative (grep_version.py) as another potential solution that would maintain Windows compatibility without restructuring the version file. The exchange highlights the tension between build system modernization and maintaining existing workflows, with portability being the key consideration. This discussion represents one of the few remaining architectural questions in the otherwise well-progressed Meson transition effort.
