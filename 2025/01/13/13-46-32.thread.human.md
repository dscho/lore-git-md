This thread discusses a build system adjustment to properly scope the `config-list.h` dependency in Meson configuration, moving it from `libgit_sources` to `builtin_sources` to match the existing Makefile behavior. The change is straightforward and non-functional, as the header is only used by `builtin/help.c`.

Alex Xu independently proposed this change, but Kristoffer Haugsbakk noticed that Patrick Steinhardt had included the same adjustment in a larger patch series submitted the same day. This appears to be a case of parallel development rather than any technical disagreement - both changes correctly align the Meson build with the Makefile. While the observation doesn't affect the validity of either patch, it highlights how such small, mechanical changes can sometimes be duplicated when multiple contributors work on similar build system cleanups. No substantive discussion has occurred beyond this duplication notice.
