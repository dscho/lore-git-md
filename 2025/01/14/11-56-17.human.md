This patch completes the fuzzer integration in Patrick Steinhardt's ongoing Meson build system conversion series. It adds a new build option `-Dfuzzers=true` to enable building Git's fuzzers, which are used for automated testing of various components like commit-graph parsing, config handling, and URL decoding.

The changes include:
1. Adding a new `fuzzers` boolean option in meson_options.txt (defaulting to false)
2. Wiring up the oss-fuzz directory in meson.build when the option is enabled
3. Creating a new oss-fuzz/meson.build that lists all fuzzer programs and builds them with the necessary dependencies
4. Updating the CI script to build with fuzzers enabled by default

This appears to be a straightforward and well-contained addition to the Meson build system, following the established patterns from earlier patches in the series. The patch maintains the existing fuzzer functionality while integrating it properly into the new build system. With this change, the CI system will now automatically build and test the fuzzers as part of the Meson conversion effort.
