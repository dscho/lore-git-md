Build system fix for meson documentation generation. This is the final version (v3) of a patch addressing a parallel build race condition where technical documentation articles could fail to build if asciidoc.conf wasn't available. The solution adds an explicit dependency declaration in Documentation/technical/meson.build to ensure proper build ordering.

The patch has gone through three iterations, with Patrick Steinhardt (a build system expert) identifying and helping correct an earlier incorrect dependency in v2. The current version is now acked by Patrick and appears technically sound. The change is minimal - just a single line addition - and narrowly scoped to only affect technical documentation targets that were missing this dependency.

This resolves a clear build system issue without broader implications, and with Patrick's approval, seems ready for inclusion. The thread shows consensus that this properly fixes the race condition while maintaining build system integrity.
