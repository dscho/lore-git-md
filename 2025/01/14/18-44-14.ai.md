Security release follow-up regarding version metadata. Johannes Schindelin reports a minor oversight in the v2.47.2 release where `GIT-VERSION-GEN` was not updated to reflect the new version number (still showing v2.47.1), though all other tagged versions in the security release batch have correct version metadata. This is a housekeeping note about version string consistency rather than a security issue, as the actual code changes for the CVEs (which prevent credential phishing via malicious URLs and fix credential protocol handling) are properly included in all releases. The email serves as a correction to Junio Hamano's original announcement, clarifying that while the security fixes are complete across all versions, one administrative file in the v2.47.2 release contains outdated version information.
