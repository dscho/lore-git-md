This patch is part of Patrick Steinhardt's ongoing Meson build system conversion series, focusing on distribution archive generation. It wires up `meson dist` to properly include Git version information in generated tarballs.

The patch modifies `GIT-VERSION-GEN` to work correctly when executed from Meson's build directory by respecting the `MESON_DIST_ROOT` environment variable. It then adds a distribution script in `meson.build` that populates the version file in the archive creation process. This ensures the distributed tarballs contain accurate version information, matching the behavior of the existing Makefile-based build system.

The change is straightforward and well-contained, touching only two files with clear modifications. It addresses a minor but important gap in the Meson build system's functionality, ensuring generated distribution archives are properly versioned. The patch fits naturally into the series' broader goal of feature parity between the Makefile and Meson build systems.
