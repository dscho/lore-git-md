This patch completes the fuzzer integration in Patrick Steinhardt's Meson build system conversion series. It adds a new `fuzzers` build option and implements the necessary wiring to build Git's fuzzers when enabled.

The technical changes include:
- Adding a `fuzzers` boolean option (default false) to `meson_options.txt`
- Conditionally including the `oss-fuzz` subdirectory in `meson.build` when fuzzers are enabled
- Creating a new `oss-fuzz/meson.build` that defines all fuzz targets (commit-graph, config, credential, date, pack headers/idx, parse-attr-line, url-decode)
- Modifying CI to build with `-Dfuzzers=true` by default

Each fuzzer is built as an executable combining its specific test file with a common `dummy-cmd-main.c`, linking against libgit and common_main. The patch maintains the existing fuzzer test coverage while adapting it to Meson's build system.

This was one of the remaining open items from earlier in the thread, now resolved. The implementation follows the established pattern of the series by adding Meson support while preserving existing functionality. With this patch, the CI integration for fuzzers is complete, marking another milestone in the comprehensive Meson conversion effort.
