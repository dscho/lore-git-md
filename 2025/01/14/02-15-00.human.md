Feature addition to `git cat-file` for remote object queries. This is the final patch (8/8) in a series implementing remote object-info functionality, adding a new `remote-object-info` command to `git cat-file --batch-command`.

The patch introduces a way to query object sizes from remote repositories without downloading the full objects, working across git://, file://, and http:// transports when the remote supports the object-info capability. The implementation handles multiple OIDs per request to reduce network overhead, with comprehensive tests covering various protocols and edge cases.

Key aspects:
- The command takes a remote name followed by one or more OIDs
- Currently only supports size queries (not object types or delta info)
- Fails gracefully when the remote doesn't support the capability
- Integrates with existing batch-command buffering modes
- Includes extensive test coverage across protocols and failure modes

The implementation looks thorough, with careful attention to protocol version checking, error handling, and memory management. The tests verify both successful operation and proper failure cases, including malformed inputs and unsupported protocol versions. This appears ready for integration, completing the end-to-end functionality started in earlier patches of the series.
