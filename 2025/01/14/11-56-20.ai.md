This is a CI/build system patch in Patrick Steinhardt's ongoing Meson conversion series (patch 10/11). It addresses a gap in the Meson build system's warning handling during CI runs.

The patch makes Meson warnings fatal in CI by adding the `--fatal-meson-warnings` flag to the `meson setup` command. Currently, Meson can emit warnings (like when using features not supported by the minimum required Meson version) without failing the build, making these warnings easy to miss. The change ensures these warnings will now cause CI jobs to fail, forcing attention to potential compatibility issues.

The implementation is minimal - just a single line addition to `ci/run-build-and-tests.sh` that adds the fatal warnings flag alongside existing warning-related options (`--warnlevel 2 --werror`). This fits with the series' pattern of methodically addressing all aspects of the Meson transition while maintaining Git's development standards.

Key technical details for future reference:
- Affects only Meson-based CI jobs (matched by `*-meson` jobname pattern)
- Works in conjunction with existing warning flags
- Specifically targets cases where features exceed minimum Meson version requirements
- No behavior change for non-CI builds
