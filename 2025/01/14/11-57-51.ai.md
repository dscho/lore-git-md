CI integration patch completing the zlib-ng performance optimization series. This final patch adds test coverage for the new zlib-ng backend by modifying the Alpine Linux CI job to install zlib-ng-dev, which meson will automatically detect and use. The author explains the platform selection rationale - Alpine was chosen because it's the only distribution in Git's CI that both packages zlib-ng and runs the full test suite (Debian/Fedora/Alma Linux were considered but rejected for various reasons). The change is minimal, just adding the package to the existing apk install command. This completes the CI testing strategy for the series, which previously established build system support and performance benchmarks showing ~25% speedups. The patch, the series appears ready for integration with all technical requirements addressed.
