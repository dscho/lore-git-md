This is a CI/build system patch in Patrick Steinhardt's ongoing Meson conversion series (part 10/11). It makes the CI system treat Meson build warnings as errors by adding the `--fatal-meson-warnings` flag during setup. This ensures developers don't miss compatibility warnings, particularly those related to version mismatches between the project's minimum Meson requirements and newer features being used.

The change is straightforward - a single-line addition to the CI script that forces warnings to be fatal. This follows the pattern seen throughout the series of methodically improving build system robustness. The patch maintains consistency with the existing `--werror` flag while specifically addressing Meson's own warning system.

As with previous patches in this series, the change is narrowly focused and well-justified, catching potential issues that might otherwise slip through. It demonstrates the same attention to detail seen in the rest of the conversion work, though it's a relatively minor piece compared to some of the more complex build system changes earlier in the series.
