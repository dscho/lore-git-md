This is a build system patch in Patrick Steinhardt's ongoing Meson conversion series, specifically addressing the configuration of cryptographic random number generation backends.

The patch makes the CSPRNG (Cryptographically Secure Pseudo-Random Number Generator) backend configurable in Meson, similar to how other backends like HTTPS and SHA1 are handled. It adds a new `csprng_backend` option with choices including `arc4random`, `getrandom`, OpenSSL, and others, defaulting to auto-detection. The implementation follows Git's existing preference order for more secure/faster backends, and adds the selected backend to Meson's build summary output.

This change completes another piece of the Meson build system puzzle, maintaining feature parity with the Makefile build while making the CSPRNG selection more transparent and configurable. The patch appears straightforward and well-integrated with the existing Meson infrastructure, continuing the series' pattern of methodical conversion work. With this, the only remaining open items in the series appear to be decisions about including "contrib/" and "gitk/" directories in the build.
