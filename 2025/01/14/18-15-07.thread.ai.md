Security release announcement for Git for Windows 2.47.1(2) addressing five CVEs across Git and its companion tools. The update includes fixes for credential exfiltration vulnerabilities in Git Credential Manager (v2.6.1) and Git LFS (v3.6.1), along with terminal control character injection and sideband channel issues. Specific vulnerabilities patched are CVE-2024-50338 (Credential Manager URL trust), CVE-2024-53263 (Git LFS credential leakage), CVE-2024-50349 (terminal control character injection), CVE-2024-52005 (sideband channel control characters), and CVE-2024-52006 (credential helper CRLF handling). The release provides SHA-256 checksums for all distribution formats (32/64-bit installers, portable versions, MinGit, ARM64 packages) covering all supported Windows platforms. This is a security-focused update from the Git for Windows project, distinct from upstream Git releases, addressing Windows-specific attack vectors including recursive clone scenarios and credential helper interactions.
