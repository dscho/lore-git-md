This is a security release announcement for Git maintenance versions, addressing two CVEs.

The email announces the availability of Git v2.48.1 and updates for older maintenance tracks (v2.40.4 through v2.47.2). These releases contain security fixes for two vulnerabilities. The tarballs are available at the kernel.org mirror and the tags are pushed to several public repositories including kernel.org, googlesource, repo.or.cz, and Junio Hamano's GitHub mirror.

The first vulnerability (CVE-2024-50349) involves credential phishing where malicious URLs containing control sequences could trick users into entering credentials for trusted sites that would actually be sent to untrusted destinations, particularly affecting recursive clones. The second (CVE-2024-52006) concerns credential protocol handling where carriage returns could be misinterpreted as line endings by credential helpers, potentially causing credential data to be processed incorrectly.

The fixes make Git refuse URLs containing control sequences to prevent these attacks. The release credits Johannes Schindelin (referred to as Dscho in the email) for leading and coordinating the security fixes across all maintained versions. This is a coordinated security update affecting multiple stable branches simultaneously.
