This is part 6/8 of the v10 series implementing client-side remote object-info support, focusing on server capability advertisement. The patch modifies the server-side advertisement mechanism to explicitly list supported object-info features (currently just "size") when the `transfer.advertiseobjectinfo` config is enabled.

The change is straightforward: where the server previously only returned a boolean indicating whether object-info was supported, it now also reports the specific capabilities (via a strbuf) when requested. This allows clients to make informed decisions about whether to use the object-info protocol or fall back to full fetches.

The implementation maintains backward compatibility while adding the new feature advertisement. The patch follows the series' established patterns and has already incorporated feedback from Jonathan Tan and Christian Couder. As with the rest of the series, this component is protocol v2-only and builds on the server-side support added earlier.
