Security patch adding configurable escape hatch for ANSI control character filtering. This is the second patch in a series addressing CVE-2025-1234 (ANSI escape sequence injection via sideband channels). While the first patch introduced mandatory sanitization of control characters, this follow-up adds an opt-out mechanism via the new `sideband.allowControlCharacters` config option. The change is motivated by use cases where remote servers deliberately use ANSI colors for message urgency.

The implementation adds a global flag checked in the sanitization function, with corresponding documentation and test updates. The test verifies both the default blocking behavior and the opt-in allowance of color sequences when configured. Johannes Schindelin signs off, maintaining consistency with the security-focused series while providing flexibility for trusted environments.

The patch appears well-integrated with the previous work, though the security implications of making the bypass configurable may warrant discussion. The test coverage is thorough, demonstrating both secure-by-default behavior and the config override path. This continues the balanced approach seen in the series - hardening by default while acknowledging real-world color use cases.
