This is a build system patch from Patrick Steinhardt's ongoing Meson conversion series (v2 02/11). It modifies `GIT-VERSION-GEN` to support Meson's version number requirements by adding two key features: accepting a direct `--format` string instead of requiring an input file, and writing to stdout when no output file is specified.

The changes allow Meson to get the version string directly without needing intermediate files, addressing a specific integration pain point. The implementation maintains all existing functionality while adding the Meson-friendly interface. The patch shows careful consideration of backwards compatibility and follows the series' pattern of methodical build system improvements.

Key technical details:
- Adds `--format=<STRING>` alternative to file input
- Makes output file optional (writes to stdout when omitted)
- Preserves all existing substitution patterns (`@GIT_VERSION@`, etc.)
- Maintains atomic file write behavior when output file is used
- Updates usage message to reflect new calling conventions

This appears to be a well-contained, focused change that cleanly solves the Meson integration issue while maintaining the script's existing behavior for other users. The patch is part of the broader Meson transition effort that has been progressing systematically through version 2 of the series.
