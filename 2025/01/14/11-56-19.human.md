Platform compatibility patch for the Meson build system conversion series. This patch fixes compilation with Visual Studio by properly specifying the required C standard version.

The issue stems from Visual Studio defaulting to C89 unless explicitly told otherwise. The patch adds C standard configuration to the Meson build, requiring GNU C99 with a fallback to C11 when using Meson 1.3.0+. For older Meson versions, it falls back to requiring GNU C99 unconditionally. The solution mirrors what's already done in Git's CMake build.

This is part of Patrick Steinhardt's ongoing v2 series converting Git's build system to Meson. The patch demonstrates attention to platform-specific quirks while maintaining backward compatibility where possible. The change is straightforward and comes with a clear explanation of the Visual Studio behavior and the chosen solution. Test coverage is indicated by the Tested-by tag.
