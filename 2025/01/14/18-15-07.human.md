Security release for Git for Windows addressing multiple CVEs.

This is a security-focused update to Git for Windows (v2.47.1(2) that patches several vulnerabilities across Git components. The release includes updated versions of Git Credential Manager (v2.6.1) and Git LFS (v3.6.1) to address credential exfiltration risks (CVE-2024-50338 and CVE-2024-53263 respectively).

The fixes address several security issues: credential managers could be tricked into leaking credentials to untrusted sites (particularly during recursive clones/fetches), terminal password prompts didn't properly handle control characters (CVE-2024-50349), and the sideband channel had similar control character vulnerabilities (CVE-2024-52005). Another fix (CVE-2024-52006) addresses credential helper behavior around carriage returns, similar to a previously fixed vulnerability (CVE-2020-5260).

The release provides installers and portable packages for 32-bit, 64-bit, and ARM64 architectures, including MinGit and BusyBox variants. All packages have their SHA-256 checksums listed for verification.

This appears to be a well-justified security update that Windows users should prioritize, particularly those using credential helpers or performing operations with untrusted repositories. The release follows standard security disclosure practices with clear CVE references and mitigation details.
