This security thread addresses ANSI escape sequence injection vulnerabilities (CVE-2024-32002, CVE-2024-52005) in Git's sideband channel. Johannes Schindelin and Junio Hamano developed a solution that provides configurable sanitization through `sideband.allowControlCharacters`, with per-URL settings available. The implementation safely replaces control characters with caret notation while allowing legitimate ANSI color sequences.

After extensive testing in Git for Windows and Red Hat environments, the series had originally planned to delay the secure-by-default behavior (only permitting ANSI colors) until Git 3.0. However, Junio now reports that the stricter version has been running smoothly in 'master' for a month with no issues. He proposes accelerating the timeline and shipping the hardened behavior in Git 2.55 instead. This removes the transitional compatibility layer while maintaining all the existing configuration options, including URL-specific policies. The change reflects confidence in the implementation's stability and prioritizes addressing these security vulnerabilities promptly.
