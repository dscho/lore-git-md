This security thread addresses ANSI escape sequence handling in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). The core implementation introduces a three-state `sideband.allowControlCharacters` configuration (defaulting to `color` mode) that permits ANSI colors while blocking other control characters, with sanitization handled in `handle_ansi_color_sequence()` and `strbuf_add_sanitized()`. Test coverage is in `t5409-colorize-remote-messages.sh`.

The discussion has evolved through several technical refinements, including fixes for `iscntrl()` casting and whitelist expansions for specific control sequences.
