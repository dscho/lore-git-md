This is a security release announcement for Git and its maintenance branches. Junio C Hamano announces the availability of Git v2.48.1 along with updates for older maintenance tracks (v2.40.4 through v2.47.2), addressing two critical security vulnerabilities.

The release fixes CVE-2024-50349, which involved credential phishing risks from malicious URLs containing control sequences that could mislead users during credential prompts, particularly in recursive clones. It also addresses CVE-2024-52006, where carriage returns in the credential protocol could be misinterpreted by credential helpers as line endings.

The fixes were coordinated by Dscho (Johannes Schindelin), with tarballs available from kernel.org and tags pushed to Git's primary repositories including kernel.org, Google's mirror, repo.or.cz, and Junio's GitHub mirror. This is a security-critical update that users should prioritize installing.
