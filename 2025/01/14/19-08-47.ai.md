Security release follow-up regarding version metadata inconsistency. This email from Randall Becker responds to Johannes Schindelin's clarification about the v2.47.2 release having an incorrect `GIT-VERSION-GEN` file showing v2.47.1 despite containing all security fixes. Becker notes they will delay packaging v2.47.2 for the NonStop platform until this version metadata issue is resolved, confirming the security fixes are still critically needed by their community. The exchange highlights how downstream packagers rely on accurate version identifiers even when the functional security patches are correct, with Becker's response demonstrating the practical impact of such administrative oversights on distribution workflows. The core security fixes for CVE-2024-50349 and CVE-2024-52006 remain unaffected in all released versions.
