This is part 7/8 of a feature series adding remote object-info support to Git's protocol v2. The patch implements the client-side functionality for querying object information (currently just sizes) from remote servers without downloading full objects.

The core addition is a new `fetch_object_info()` function that handles the protocol exchange - it sends object-info requests to v2 servers and parses the responses. The implementation includes:
- A new `fetch-object-info.[ch]` pair for the core client logic
- Integration with the transport layer to make the feature work across git://, file:// and http:// protocols
- Strict version checking that errors out if the server doesn't support protocol v2
- Memory management helpers for the results

The patch builds on server-side support added earlier in the series and follows Git's established patterns for protocol features. It's well-structured with clear error handling and includes the necessary transport layer plumbing. As the 7th patch in a mature series (now at v10), this appears ready for integration, with all prior review feedback addressed.

The feature will be particularly valuable for clients that need to check object sizes before deciding whether to fetch them, saving bandwidth when only metadata is needed.
