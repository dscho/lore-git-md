This is a follow-up patch series in Patrick Steinhardt's ongoing Meson build system transition effort, focusing on finalizing several key features and CI integration. The series builds upon previous work and addresses several remaining gaps:

1. Version file handling has been reworked from v1, now using `GIT-VERSION-GEN` directly with a simpler approach that honors `MESON_DIST_ROOT` for distribution archives, dropping the previous template-based method. This appears to be the "more fundamental rework" Patrick hinted at in earlier discussion.

2. Fuzzer integration is now complete with CI jobs wired up, resolving that thread discussion point. The implementation includes both GitHub and GitLab CI configurations.

3. The CSPRNG backend configuration has been refined with proper ordering of security preferences (arc4random > getrandom > getentropy > RtlGenRandom) and switched to using `meson.has_header_symbol()` for better compatibility with Meson 0.61+.

4. Visual Studio build support is added to CI, continuing the cross-platform compatibility work.

5. New quality control measures include making Meson warnings fatal in CI and fixing header dependencies.

The series shows responsiveness to maintainer feedback, with wording improvements (changing "Despite" to "In addition to" for distribution archive description) and technical refinements. Version management remains the most complex piece, but the new approach appears simpler than v1's solution while still addressing Windows portability constraints. All changes maintain the series' focus on security properties and cross-platform functionality.
