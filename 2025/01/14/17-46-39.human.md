This is a small bugfix in the Meson build system conversion series, addressing a version string generation issue that Junio Hamano discovered wasn't caught by his personal build setup. The problem involved incorrect argument ordering in the `git describe` command used to generate version numbers, which was reported by Ramsay Jones but didn't surface in Junio's testing due to his custom build infrastructure pre-populating the version file.

The fix simply reorders the `--dirty` and `--match` flags in the version generation command to their correct positions. Junio confirms the fix looks correct, noting that his own testing missed this because his environment bypasses the affected code path. This appears to be a straightforward correction to an edge case in the build system conversion work.
