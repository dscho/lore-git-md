This is a follow-up to the recent security release announcement, addressing a minor versioning oversight. Johannes Schindelin notes that while all other maintenance releases (v2.48.1 and others) correctly updated their `GIT-VERSION-GEN` files, v2.47.2 was left with `DEF_VER=v2.47.1` by mistake. He apologizes for the oversight, clarifying this doesn't affect the security fixes themselves—which addressed credential phishing via malicious URLs (CVE-2024-50349) and credential protocol handling (CVE-2024-52006). The core security updates remain intact across all versions, with tarballs and tags already distributed to major repositories. A trivial administrative hiccup in an otherwise critical coordinated release.
