Build system fix for generated header dependencies in the Meson conversion series.

This patch addresses a parallel build issue in the Meson build system conversion where certain generated headers were incorrectly listed as dependencies of libgit.a when they were actually needed by builtin executables. The fix moves "config-list.h" and "hook-list.h" from libgit_sources to builtin_sources, while keeping "command-list.h" (used by help.c) in libgit_sources. The change resolves race conditions where builtin objects could be compiled before their required headers were generated.

The technical change involves restructuring the meson.build file to properly associate each generated header with its actual consumers. The patch maintains the same generation commands and environment variables, only changing the target lists they're added to. This appears to be a straightforward correction of an oversight in the initial Meson conversion, with the fix being prompted by a real build failure report from Evan Martin.

This is part of Patrick Steinhardt's ongoing v2 series converting Git's build system to Meson, where it follows the version file handling improvements in the previous patch. The change demonstrates attention to build system correctness and parallel build reliability, though it doesn't introduce new functionality or affect the final binaries - it just makes the build process more robust.
