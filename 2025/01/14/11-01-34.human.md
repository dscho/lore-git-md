This is a feature request proposing to extend Git's existing `-` shortcut behavior to `git diff`. The author notes that `git merge` and `git checkout` already accept `-` as shorthand for `@{-1}` (which refers to the previous branch/commit), and suggests making `git diff` behavior consistent with these commands.

The proposal is straightforward and appears well-motivated by consistency with existing Git conventions. The change would make `git diff -` equivalent to `git diff @{-1}`, saving users a few keystrokes when comparing against their previous branch position. The email is concise and to-the-point, though it doesn't discuss potential implementation considerations or edge cases that might need handling.
