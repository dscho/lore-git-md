This is a refactoring patch in the v10 series implementing remote object-info functionality. It moves initialization code for fetch-pack's state machine out of the first state (FETCH_CHECK_LOCAL) to just before the state machine begins, in preparation for supporting alternative initial states while maintaining the same initialization requirements.

The changes affect fetch-pack.c by relocating three key initializations:
1. Setting `allow_unadvertised_object_request` to include `ALLOW_REACHABLE_SHA1`
2. Configuring `use_sideband = 2` for protocol v2
3. Enabling `args->deepen` when depth-related arguments are present

The patch maintains identical behavior while improving the code structure for future extensibility. It's part of broader transport layer refactoring to support generalized protocol v2 commands, with the initialization changes being a prerequisite for upcoming state machine modifications mentioned in the thread's open items. The patch has already incorporated review feedback from Jonathan Tan and Christian Couder, suggesting it's been thoroughly vetted.
