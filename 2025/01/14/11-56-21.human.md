This is a CI/build system patch adding Visual Studio support to the Meson build system's CI testing. It's the final patch in Patrick Steinhardt's comprehensive Meson conversion series.

The patch adds new Windows CI jobs to both GitHub Actions and GitLab that build and test Git using Meson with Visual Studio. The implementation makes several pragmatic choices to balance testing needs with resource constraints: the test job is manual-only in GitLab to avoid redundant Windows test runs, Perl is disabled due to path format mismatches, and test artifacts aren't processed for failed jobs to minimize dependencies.

Notably, this doesn't use the Git for Windows SDK - instead letting Meson handle dependencies automatically - and implements custom test slicing in PowerShell while waiting for upstream Meson support. The patch appears well-considered, with all tests passing and clear explanations for each design decision. It completes the technical implementation of the Meson build system by covering the last major platform (Windows/VS) while maintaining the project's testing standards.
