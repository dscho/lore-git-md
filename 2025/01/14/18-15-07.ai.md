Security release for Git for Windows addressing multiple CVEs. This is an announcement of Git for Windows 2.47.1(2), which patches for several security vulnerabilities across Git and its companion tools. The release includes updated versions of Git Credential Manager (v2.6.1) and Git LFS (v3.6.1) to address credential exfiltration vulnerabilities.

The release fixes five specific CVEs: CVE-2024-50338 (Credential Manager URL trust issue), CVE-2024-53263 (Git LFS credential exfiltration), CVE-2024-50349 (terminal control character injection), CVE-2024-52005 (sideband channel control character issue), and CVE-2024-52006 (credential helper CRLF handling). The vulnerabilities range from credential leakage risks to terminal display manipulation issues, with some requiring specific attack vectors like recursive clones or interaction with other vulnerabilities.

The announcement provides SHA-256 checksums for all distribution formats including 32/64-bit installers, portable versions, MinGit distributions, and ARM64 packages. This appears to be a comprehensive security update covering all supported Windows platforms and installation methods. The release follows standard Git for Windows security practices with clear documentation of each vulnerability's impact.
