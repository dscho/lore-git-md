Bugfix for version identification issue in Meson builds.

Patrick Steinhardt confirms he has identified and fixed the version identification problem in the Meson build system that was causing Git to incorrectly report as v2.48.0 on Cygwin. This was a follow-up to Ramsay Jones' initial report and Junio Hamano's suggestion to have Patrick address it, as the issue stemmed from his recent 'ps/zlib-ng' integration branch.

The fix will be included in the next version of Patrick's Meson series. While brief, this email provides closure on the immediate issue while indicating the solution is already in progress. The response suggests this was a straightforward build system bug that the original author could quickly diagnose and correct.

No details are given about the specific nature of the fix, but given the context from earlier in the thread, we can infer it relates to how version information is handled between the traditional make and Meson build systems, particularly around the GIT-VERSION file handling on case-insensitive filesystems like Cygwin.
