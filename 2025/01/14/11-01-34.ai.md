This is a feature request proposing to extend Git's existing `-` shorthand behavior to `git diff`. The author notes that `git merge` and `git checkout` already accept `-` as shorthand for `@{-1}` (which refers to the previous branch/commit), and suggests making this consistent across commands. The request is straightforward and builds on existing conventions, though it doesn't provide implementation details or discuss potential edge cases. The change would affect the diff command's argument parsing, requiring updates to documentation and possibly tests to verify the new shorthand works as expected. The proposal appears technically sound at first glance, though it may need discussion about whether this shorthand should be universally supported across all commands that accept commit-ish arguments.
