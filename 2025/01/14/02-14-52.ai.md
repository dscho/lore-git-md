This is the final version (v10) of an 8-part series implementing client-side support for remote object-info functionality, building on server-side support added in a2ba162cda. The series adds a new `remote-object-info` command to `git cat-file --batch-command` that allows querying object information (currently just sizes) from protocol v2 servers without downloading full objects.

Key technical details in this version:
- The `remote-object-info` command accepts multiple OIDs at once to reduce roundtrips
- Works across git://, file://, and http:// transports
- Uses new fetch-object-info.[ch] for core request/response handling
- Integrates with existing batch-command infrastructure
- Current limitation: only supports %(objectname) and %(objectsize) formatting
- Strict protocol v2 requirement (rejects v0/v1 with clear errors)
- Changes since v9 focus on documentation and style refinements:
  - Improved commit message clarity
  - Comment formatting aligned with Git conventions
  - Removed unused `use_remote_info` field
  - Type safety improvements (size_t usage)
  - Grammar and error message phrasing fixes

The series has incorporated all review feedback from Jonathan Tan (transport improvements), Christian Couder (documentation/style), and Calvin Wan (error handling). The test coverage in t1017-cat-file-remote-object-info.sh is comprehensive, with test utilities now properly documented in lib-cat-file.sh.

This represents the final polished version of the feature, with future work planned to add object type support once server-side implements it. The implementation maintains high code quality with careful error handling and memory management.
