Performance optimization patch in the zlib-ng support series, moving the `deflateBound()` compatibility shim to a shared header. This is part of the ongoing effort to enable runtime switching between standard zlib and zlib-ng backends.

The patch relocates the `deflateBound()` compatibility definition from `git-zlib.c` to `compat/zlib-compat.h`. This function is needed for zlib versions older than 1.2.0, and centralizing it in the compatibility header prepares for subsequent zlib-ng integration. The change maintains identical behavior while improving code organization.

Key technical details include:
- The shim provides a fallback implementation when either `NO_DEFLATE_BOUND` is defined or zlib version is below 1.2.0 (ZLIB_VERNUM < 0x1200)
- The mathematical formula for the bound calculation remains unchanged
- `git_deflate_bound()` in `git-zlib.c` now relies on this centralized definition
- The change is minimal (4 lines added, 4 removed) and focused on the compatibility layer
