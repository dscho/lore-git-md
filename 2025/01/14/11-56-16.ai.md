This patch is part of Patrick Steinhardt's ongoing Meson build system conversion series, specifically focusing on distribution archive generation. It wires up proper version information propagation when creating Git distribution tarballs through Meson's `meson dist` command.

The key technical aspects are:
- Modifies `GIT-VERSION-GEN` to handle Meson's `MESON_DIST_ROOT` environment variable when writing version information
- Adds a Meson distribution script that runs `GIT-VERSION-GEN` with the `--format=@GIT_VERSION@` parameter to populate the archive's version file
- Ensures the version information reflects the commit being built from when generating distribution tarballs

This builds on previous work in the series that integrated `GIT-VERSION-GEN` with Meson's build system. The patch maintains consistency with Git's existing version management while adapting it to Meson's distribution workflow. The change is straightforward and focused, with clear motivation about ensuring the generated archives properly identify their source commit.

The implementation appears technically sound, using Meson's native `add_dist_script` mechanism while preserving Git's existing version generation logic. This continues the series' pattern of careful integration between Git's established build processes and Meson's features.
