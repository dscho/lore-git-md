This is a follow-up to the recent Git security release announcement, addressing a version metadata issue. Randall Becker from the NonStop community responds to Johannes Schindelin's note about an administrative oversight in the v2.47.2 release where the `GIT-VERSION-GEN` file incorrectly shows v2.47.1 instead of v2.47.2. 

While this doesn't affect the security fixes (which are properly included in all releases), Randall indicates he'll hold off on packaging v2.47.2 for the NonStop platform until this version metadata inconsistency is resolved. The email underscores how even minor release metadata issues can impact downstream packagers who need to verify version consistency before distribution.

The exchange shows good community responsiveness - Johannes promptly disclosed the oversight, and Randall is providing feedback about its practical impact on his packaging workflow. This appears to be a straightforward coordination matter rather than anything affecting the security fixes themselves.
