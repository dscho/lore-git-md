Security release announcement for Git maintenance versions v2.48.1, v2.47.2, v2.46.5, v2.45.3, v2.44.3, v2.43.5, v2.42.3, v2.41.2, and v2.40.4, addressing two critical CVEs: CVE-2024-50349 (credential phishing via malicious URLs containing control sequences during recursive clones) and CVE-2024-52006 (credential protocol handling vulnerabilities from carriage return misinterpretation). Johannes Schindelin (Dscho) led the security response, coordinating fixes that make Git reject URLs with control sequences. The thread details a version metadata inconsistency in v2.47.2 where `GIT-VERSION-GEN` incorrectly shows v2.47.1 in tarball builds due to an unupdated `DEF_VER` variable, though the security fixes are fully present. Schindelin provided technical clarification that this only affects tarball builds (not Git checkouts where the tag is correct) and offered workarounds for Randall Becker's NonStop packaging needs. Junio C Hamano later responded to this issue, reassuring Schindelin that mistakes happen and no apology is needed, while confirming v2.48.1 was correctly processed. The exchange maintains focus on build system details while acknowledging the metadata issue is separate from the security content. All releases contain the complete credential phishing protection (CVE-2024-50349) and credential protocol fixes (CVE-2024-52006), with v2.47.2's metadata inconsistency being a non-security packaging issue that has documented workarounds. The thread captures both the technical implementation of security fixes and downstream packaging considerations, with Schindelin as the primary technical authority and Hamano providing maintainer perspective on process handling.
