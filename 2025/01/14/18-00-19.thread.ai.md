Security release announcement for Git maintenance versions v2.48.1, v2.47.2, v2.46.5, v2.45.3, v2.44.3, v2.43.5, v2.42.3, v2.41.2, and v2.40.4, addressing two critical CVEs. CVE-2024-50349 fixes credential phishing via malicious URLs containing control sequences that could mislead users during recursive clones, while CVE-2024-52006 resolves credential protocol handling vulnerabilities where carriage returns could be misinterpreted by credential helpers. The patches make Git reject URLs with control sequences. Johannes Schindelin (Dscho) led the security response, coordinating fixes across all maintained versions. Tarballs are available at kernel.org and other mirrors, with tags pushed to kernel.org, googlesource.com, repo.or.cz, and Junio Hamano's GitHub mirror. This is a coordinated security update affecting multiple stable branches simultaneously.
