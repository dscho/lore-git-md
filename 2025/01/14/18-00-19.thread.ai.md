Security release announcement for Git maintenance versions v2.48.1, v2.47.2, v2.46.5, v2.45.3, v2.44.3, v2.43.5, v2.42.3, v2.41.2, and v2.40.4, addressing two critical CVEs: CVE-2024-50349 (credential phishing via malicious URLs containing control sequences during recursive clones) and CVE-2024-52006 (credential protocol handling vulnerabilities from carriage return misinterpretation). Johannes Schindelin (Dscho) led the security response, coordinating fixes that make Git reject URLs with control sequences. Tarballs are available at kernel.org and other sources, with tags pushed to multiple repositories. A follow-up note from Dscho clarifies that while all versions contain the complete security fixes, the v2.47.2 release has an administrative oversight where `GIT-VERSION-GEN` still shows v2.47.1, though this does not affect the security patches. Randall Becker responded regarding the NonStop platform packaging implications, noting they will delay distributing v2.47.2 until the version metadata inconsistency is resolved, while confirming the security fixes remain critically needed. The credential phishing protection and protocol fixes are properly included in all releases, with only v2.47.2 having this minor version metadata inconsistency that impacts downstream packaging workflows without affecting the security content.
