This is a documentation patch improving the MyFirstContribution guide, now in its second revision. Rhythm Narula's update adds clear guidance about where contributors can find open bugs and feature requests, addressing a gap in the current documentation.

The patch adds a new section that distinguishes between the official mailing list (for bug reports and general discussion) and unofficial trackers like GitGitGadget's GitHub (specifically for feature requests). This follows feedback from Carlo Marcelo Arenas Belón and Emily Shaffer (the original document author) who suggested clearer wording about issue types and better integration with existing documentation.

Key improvements in v2 include a more concise commit message, better flow in the added text, and explicit notes about the mailing list being the proper place for bug reports. The patch now also references the existing "getting-help" section to avoid duplication. The changes appear well-considered and responsive to previous review comments, making this likely candidate for inclusion once any final wording tweaks are addressed.
