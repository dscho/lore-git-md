Security patch addressing ANSI escape sequence injection in Git's sideband channel. This is the first of three patches in a series to fix CWE-150, where remote servers could send malicious control sequences that corrupt terminals or fake user input.

The patch introduces basic sanitization by converting control characters (except tab and newline) to caret notation (e.g., ESC becomes ^[). The implementation adds a new `strbuf_add_sanitized()` helper in sideband.c and includes tests verifying the sanitization works while preserving normal error messages. The commit notes this is a broad initial approach, with more refined controls coming in subsequent patches.

This appears to be a well-considered security fix with clear motivation (documenting the CWE reference) and proper test coverage. The patch maintains backward compatibility for existing workflows while closing a significant attack vector. The series has already seen some deployment in Git for Windows, suggesting it's been vetted by the security team.
