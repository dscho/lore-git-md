Build system refinement for meson documentation dependencies. This is a follow-up to Sam James's initial patch that added `documentation_deps` to documentation targets in the meson build system. Patrick Steinhardt correctly pointed out that while the dependency makes sense for HTML article generation (which uses asciidoc.conf), it's unnecessary for api-index.sh which doesn't actually process that configuration file. Sam acknowledges the oversight and plans to respin the patch with a more targeted approach. The key technical detail is that only the HTML article generation in the foreach loop needs the `documentation_deps` specification, while the api-index target should have this dependency removed. This exchange demonstrates the value of careful review in build system changes, where seemingly similar targets may have different actual requirements. The thread shows progress toward a more precise solution that avoids unnecessary build dependencies while still ensuring correct ordering where truly needed.
