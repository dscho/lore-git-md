This is a build system patch in Patrick Steinhardt's ongoing Meson conversion series (v2). It introduces development environment support in the Meson build system, specifically targeting developer workflows rather than end-user functionality.

The patch wires up Meson's development environment feature to expose built Git executables and the build directory path. This enables two key developer conveniences: (1) running test scripts directly against the built Git version, and (2) having the built Git executables automatically available in PATH when using `meson devenv`. The implementation adds a new environment configuration block to meson.build that sets GIT_BUILD_DIR and prepends the bin-wrappers directory to PATH.

This change is part of the broader effort to make the Meson build system fully functional for Git development, following earlier patches that addressed version file handling, header dependencies, and platform-specific concerns. While not fixing any specific bug, it improves the developer experience when working with Meson-built Git versions. The patch is straightforward and focused, with no apparent technical concerns or open questions - it simply exposes existing Meson functionality in a Git-appropriate way.
