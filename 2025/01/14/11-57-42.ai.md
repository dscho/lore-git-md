This is a cleanup patch in the zlib-ng optimization series, removing obsolete compatibility code. The patch drops the `uncompress2()` compatibility shim that was previously needed for older zlib versions (<1.2.9). The removal is safe because the last user of this function was removed in commit 15a60b747e ("reftable/block: open-code call to `uncompress2()`", 2024-04-08).

The changes remove the implementation file (`compat/zlib-uncompress2.c`), its Makefile entry, the meson.build reference, and the related declarations from `git-compat-util.h`. The patch is straightforward and uncontroversial, being a simple removal of now-unused code that was part of the zlib compatibility layer being modernized in this series.

For future reference in this thread, this patch:
- Removes the `uncompress2()` compatibility function and all related build system references
- Follows the series' goal of cleaning up zlib compatibility code
- Is part of the broader zlib abstraction work that enables zlib-ng support
- Has no functional impact since the code was already unused
- Maintains compatibility as the function is now provided by all supported zlib versions
