This is part 6 of a performance optimization series introducing zlib-ng support, focusing on compatibility shims for older zlib versions. The patch moves the `deflateSetHeader()` compatibility handling from `archive-tar.c` into the centralized `zlib-compat.h` file. This function, introduced in zlib 1.2.2.1, is used when creating gzip headers for tar archives.

The change removes version-specific `#ifdef` guards from `archive-tar.c` and instead provides a stub implementation in the compatibility layer when building against older zlib versions. This maintains the same behavior while cleaning up the code and preparing for the zlib-ng integration where such version checks will be handled uniformly.

This is a straightforward refactoring that follows the pattern established earlier in the series for `deflateBound()`. The patch appears well-contained and properly tested, continuing the series' systematic approach to zlib compatibility handling.
