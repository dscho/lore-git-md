This is a CI/build system patch in the zlib-ng optimization series, switching the linux-musl CI job from Make to Meson. The change serves three purposes: simplifying CI infrastructure by removing manual build options, verifying Meson's automatic detection of those options, and making it easier to add a zlib-ng CI job. The patch handles platform-specific needs by adding a new `test_utf8_locale` Meson option (set via `MESONFLAGS`) since Meson can't auto-detect this test requirement. The changes touch CI configuration files across GitHub Actions, GitLab CI, and the test infrastructure scripts, updating dependencies to include Meson and adjusting build flags appropriately. This appears to be a straightforward mechanical change that completes the build system support for the zlib-ng series while maintaining test coverage.
