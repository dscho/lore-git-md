This is part of Patrick Steinhardt's ongoing Meson build system conversion series, specifically addressing version file handling. The patch implements direct integration with `GIT-VERSION-GEN` to ensure the Meson build system always reflects the current Git version, rather than having a stale hardcoded version.

The key technical change modifies `meson.build` to dynamically query `GIT-VERSION-GEN` for the version string during configuration. It handles Windows portability by falling back to "unknown" when no shell is available (since Git for Windows requires shell setup that may not be complete during early configuration). The implementation uses Meson's `find_program()` and `run_command()` to execute `GIT-VERSION-GEN` with the new `--format=@GIT_VERSION@` parameter that outputs just the version string.

This solution maintains the security properties of the original version generation (atomic writes, proper substitution patterns) while solving the cosmetic issue where Meson would report outdated versions. The patch represents the settled approach from earlier thread discussion, replacing the previous template-based method with direct `GIT-VERSION-GEN` integration. It's part of the systematic addressing of all platform-specific concerns in the conversion effort.
