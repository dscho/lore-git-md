This is a performance optimization series introducing zlib-ng support as an alternative zlib backend. Patrick Steinhardt's 10-part patch series refactors Git's zlib integration to enable runtime switching between standard zlib and zlib-ng, which provides optimized implementations using SSE2/AVX2 instructions.

The series shows promising performance gains - benchmarks demonstrate a ~25% speedup in `git cat-file --batch --batch-all-objects` when using zlib-ng. The implementation is designed to work alongside system zlib rather than replacing it, making it distribution-friendly. Key technical changes include introducing a new zlib compatibility layer, build system integration for both meson and Makefile (addressing feedback from v1), and CI testing with zlib-ng.

The cover letter explains that while zlib-ng normally provides a compatibility layer, most distros don't install it that way to avoid replacing system zlib globally. This series handles the differences (primarily zlib-ng's `zng_` prefix) through symbol remapping in the new compatibility layer. The v2 iteration adds Makefile support and CI testing that were missing from the initial version, making the series more complete.

For users who can benefit from faster compression (particularly hosting providers processing many Git operations), this provides a clean way to opt into zlib-ng's optimizations without system-wide impact. The implementation appears thorough, with good test coverage and attention to backward compatibility.
