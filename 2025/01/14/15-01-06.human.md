Build system fix for parallel documentation builds. This is the final version of a patch addressing a race condition in Git's meson build system where technical documentation articles could fail to build in parallel due to missing dependencies on the asciidoc configuration file. The solution adds an explicit dependency declaration in Documentation/technical/meson.build to ensure asciidoc.conf is available before building articles.

The patch has gone through three iterations, with Patrick Steinhardt (who identified an incorrect dependency in v2) now approving the final version. The change is minimal - just a single-line addition - and specifically targets technical documentation while leaving other properly-declared documentation targets unaffected. The fix cleanly resolves the parallel build issue without broader implications for the build system.

With no outstanding objections and the solution appearing technically sound, this patch appears ready for inclusion. It's a straightforward fix for a clear problem that would affect developers building Git with parallel jobs.
