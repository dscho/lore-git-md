Platform compatibility patch in Patrick Steinhardt's Meson build system conversion series (v2 09/11). This addresses Visual Studio compilation issues by properly specifying C language standards in the Meson build configuration.

The patch fixes a compilation failure where Visual Studio defaults to C89 mode unless explicitly told otherwise. Git requires C99 (specifically GNU C99 extensions), but Visual Studio has quirks where it only properly defines `__STDC_VERSION__` starting with C11. The solution adds a `c_std` project option that tries GNU C99 first, falling back to C11 on Meson 1.3.0+ (which supports fallback standards), while older Meson versions use GNU C99 unconditionally. This matches Git's existing CMake behavior and maintains compatibility with Git's documented compiler requirements.

The change is localized to `meson.build` with a clear explanation of the version-dependent behavior. It includes a Tested-by from M Hickford, suggesting real-world validation. This continues the series' pattern of methodically handling platform-specific build requirement while maintaining backward compatibility where possible. The patch doesn't affect other platforms or build configurations - it specifically targets Visual Studio's C standard handling quirks.
