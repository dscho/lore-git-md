This is a security patch series addressing ANSI escape sequence injection vulnerabilities in Git's sideband channel, which carries remote server messages during operations like `git clone`. The patches were originally developed for a coordinated security release but held back due to concerns about breaking existing workflows that intentionally use control characters.

The series introduces sanitization of control characters in sideband messages while preserving ANSI color sequences by default (used by some server hooks for colored error messages). A new `sideband.allowControlCharacters` config option provides an escape hatch for cases requiring raw control characters. The changes affect `sideband.c` and include new documentation and tests.

The vulnerability allows malicious servers to corrupt terminal state or inject input, though the author notes the community already "exploits" this benignly for colored error messages. The patches represent a middle ground between security and backward compatibility, though there was some disagreement among reviewers regarding the terminal emulator mitigation approach.

The series applies cleanly to recent versions, with minor adjustments needed for older security releases. This appears to be a well-considered security hardening measure with thorough documentation and test coverage, though its delayed inclusion suggests some ongoing debate about the tradeoffs involved.
