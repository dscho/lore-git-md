This is a follow-up in Patrick Steinhardt's Meson build system transition series, specifically addressing fuzzer integration. The patch wires up Git's fuzzers to the Meson build system by introducing a new "fuzzers" build option and updating CI jobs to build them by default.

Junio C Hamano notes this fills one of the known gaps in the Meson build system and suggests aiming for feature parity within two releases. Patrick responds that he already has static analysis planned for this cycle and asks for input on other features still missing. He specifically calls out "contrib/" and "gitk/" as known omissions, expressing a preference to exclude "contrib/" but deferring the decision on "gitk/" to Johannes Schindelin.

The technical implementation appears straightforward - adding the fuzzer build option and CI integration - with no apparent controversy. The discussion has now shifted to broader questions about what components should be included in the Meson build, particularly around non-core parts of the Git distribution. The fuzzer integration itself seems uncontroversial and ready to proceed, while the thread continues to track the overall Meson transition progress.
