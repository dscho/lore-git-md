This is a security announcement for Git for Windows 2.47.1(2), addressing five critical vulnerabilities across Git and its companion tools. The release patches credential exfiltration risks in Git Credential Manager (CVE-2024-50338) and Git LFS (CVE-2024-53263), along with terminal control character injection (CVE-2024-50349) and sideband channel/credential helper issues (CVE-2024-52005, CVE-2024-52006). 

The update includes patched versions of Git Credential Manager (v2.6.1) and Git LFS (v3.6.1), with fixes that prevent credential leakage under specific attack scenarios like recursive clones. Johannes Schindelin (Dscho) has provided SHA-256 checksums for all distribution formats - installers, portable versions, and MinGit packages across 32/64-bit and ARM64 architectures.

This is the only message in this thread so far - it's a straightforward security notification from the Git for Windows maintainers about an important update that Windows users should apply promptly. The vulnerabilities fixed could lead to credential exposure or terminal manipulation under certain conditions.
