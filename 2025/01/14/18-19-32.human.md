Security patch refining ANSI escape sequence handling in sideband channel. This third patch in the series modifies the default behavior to allow ANSI color sequences while still blocking other control characters, addressing real-world use cases where pre-receive hooks rely on color output. The implementation introduces three modes for `sideband.allowControlCharacters`: "color" (default, allowing colors), "false" (block all control chars except basic whitespace), and "true" (allow all control chars). The patch includes detection logic for valid ANSI color sequences and extends test coverage to verify color preservation alongside control character blocking. This strikes a balance between security (still blocking potentially malicious sequences) and usability (preserving legitimate color output). The change appears well-considered with thorough test cases showing the different configuration behaviors.
