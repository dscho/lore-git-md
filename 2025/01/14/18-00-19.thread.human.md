The Git project has issued security releases (v2.48.1 through v2.40.4) addressing two critical vulnerabilities: CVE-2024-50349 (credential phishing via malicious URLs with control sequences during recursive clones) and CVE-2024-52006 (credential protocol issues from carriage return misinterpretation). Johannes Schindelin (Dscho) led the response, implementing protections that now reject suspicious URLs. 

While all versions contain the complete security fixes, a minor administrative oversight was discovered in v2.47.2 where the `GIT-VERSION-GEN` file incorrectly shows v2.47.1. Randall Becker of the NonStop port has noted this metadata inconsistency will delay their packaging process, though the security patches themselves remain unaffected. The project maintains that all released versions are secure, with only v2.47.2 having this version identifier discrepancy that impacts some downstream distributors.
