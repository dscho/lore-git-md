This is a security release announcement for Git maintenance versions addressing two critical CVEs. The releases include Git v2.48.1 and updates for older maintenance tracks (v2.40.4 through v2.47.2), with fixes available across all supported versions.

The vulnerabilities patched are serious credential-related issues. The first (CVE-2024-50349) could allow malicious actors to craft URLs with control sequences that trick users into entering credentials for what appears to be a trusted site, particularly dangerous in recursive clone operations. The second (CVE-2024-52006) involves credential protocol vulnerabilities where carriage returns could be misinterpreted by credential helpers, potentially exposing sensitive data. The fixes make Git reject URLs containing control sequences to prevent these attacks.

Johannes Schindelin (Dscho) led the security response, coordinating fixes across all maintained versions. The updates are available through multiple distribution channels including kernel.org, googlesource, repo.or.cz, and Junio Hamano's GitHub mirror. This represents a coordinated security update affecting all currently supported Git versions simultaneously.
