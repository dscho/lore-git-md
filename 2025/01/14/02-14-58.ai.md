Feature implementation for protocol v2 object-info advertisement.

This patch adds server-side capability advertisement for the object-info feature, specifically advertising the "size" capability when enabled via the `transfer.advertiseobjectinfo` config. The change modifies `object_info_advertise()` in serve.c to populate a strbuf with the supported capability ("size") when advertising is enabled, while maintaining the existing default-off behavior. This allows clients to determine whether the server supports object-size queries before attempting them.

Key technical details:
- Builds on the existing `advertise_object_info` config handling
- Advertised capability is hardcoded to "size" (the only supported info type)
- Maintains backward-compatible behavior when `value` parameter is NULL
- Follows the established pattern for capability advertisement in serve.c

The change is part of the larger remote object-info series and enables the client-side functionality added in previous patches. It represents the server-side counterpart to the client's ability to query object sizes via protocol v2, completing the end-to-end feature. The implementation is minimal and focused, with no functional changes to the existing advertisement mechanism beyond adding the capability string.
