[Security] ANSI escape sequence injection in sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin's implementation provides configurable sanitization via `sideband.allowControlCharacters` with per-URL configuration through `sideband_apply_url_config()`. Core sanitization in `strbuf_add_sanitized()` validates without allocations, replacing control characters with caret notation (e.g., `^[` for escape sequences) to prevent terminal state corruption and input buffer injection attacks.

The mature v5 series (rebased to v2.53.0 in v4) had production validation in Git for Windows (1+ year) and Red Hat (6+ months). Latest patches introduce nuanced control with URL-scoped configuration via `sideband.<url>.allowControlCharacters` mirroring Git's `http.<url>.*` pattern, default behavior allowing ANSI color sequences (`\033[31m` etc) via `ALLOW_ANSI_COLOR_SEQUENCES`, and new bitmask flags for cursor movements (`ALLOW_ANSI_CURSOR_MOVEMENTS`), erase sequences (`ALLOW_ANSI_ERASE`), and full passthrough (`ALLOW_ALL_CONTROL_CHARACTERS`).

Junio Hamano's review initially raised fundamental concerns about version-dependent defaults and preferred testing opt-in mechanisms first, but has now shifted position to accept Schindelin's default-on approach for real-world testing in `next`, acknowledging some breakage may be necessary to properly evaluate impact. This represents a significant development removing a major point of contention. Junio still maintains unspecified concerns about two other design aspects, while his earlier technical input about ISO/IEC 2022 encoding collisions remains addressed through conditional compilation via `WITH_BREAKING_CHANGES` to toggle between permissive and secure defaults.

The implementation balances security needs against compatibility with legitimate control sequence usage, particularly terminal title updates (ESC ] 0; <string> BEL sequence). Test coverage in `t/t5409-colorize-remote-messages.sh` verifies behaviors through `TURN_ON_SANITIZING` prerequisite. Production validation in Git for Windows and Red Hat confirms URL-scoped configuration stability, with the maintainer's evolving stance suggesting the architecture may proceed with current design while monitoring real-world impact from `next` branch deployment.
