[Security] ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin's implementation provides granular control via `sideband.allowControlCharacters` configuration with bitmask flags for `color` (default-allowed), `cursor`, and `erase` (default-blocked). Core sanitization in `strbuf_add_sanitized()` and `handle_ansi_sequence()` validates SGR (color), CUU/CUD (cursor), and ED/EL (erase) sequences against policy.

Technical implementation includes URL-specific configuration via `sideband_allow_control_characters_config()` integrated with Git's HTTP transport. Current implementation details:
- Bitmask flags: `ALLOW_ANSI_COLOR_SEQUENCES` (1<<0), `ALLOW_ANSI_CURSOR_MOVEMENTS` (1<<1), `ALLOW_ANSI_ERASE` (1<<2)
- `ALLOW_CONTROL_SEQUENCES_UNSET` (-1) state for configuration tracking
- Backward-compatible config parsing with comma-separated values (`color,cursor,erase`)
