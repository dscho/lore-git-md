[Security] ANSI escape sequence injection vulnerability in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin's patch series implements controlled sanitization via granular `sideband.allowControlCharacters` configuration, supporting three sequence types through bitmask flags: `color` (default-allowed), `cursor`, and `erase` (default-blocked). Core sanitization in `strbuf_add_sanitized()` and `handle_ansi_sequence()` validates sequences against configured policies, with special handling for SGR (color), CUU/CUD (cursor), and ED/EL (erase) sequences.

Technical implementation now includes URL-specific configuration handling via new `sideband_allow_control_characters_config()` function integrating with Git's HTTP configuration system. Modifications to `http.c` recognize `http.sanitizesideband` settings while refactored configuration parsing supports URL-specific overrides (`http.<url>.variable`-style) as suggested by Junio Hamano. Implementation details:
- Expanded sanitization with `ALLOW_ANSI_CURSOR_MOVEMENTS` (1<<1) and `ALLOW_ANSI_ERASE` (1<<2) flags alongside `ALLOW_ANSI_COLOR_SEQUENCES` (1<<0)
- New `ALLOW_CONTROL_SEQUENCES_UNSET` state (-1) for configuration tracking
- Configuration accepts comma-separated values (`color,cursor,erase`) while maintaining boolean/string backward compatibility
- Refactored config parsing preserves backward compatibility with improved warning messages showing full config key names
- Phillip Wood's whitelist (BEL, DEL handling) preserved with new sequence-specific validation
- Comprehensive test coverage for sequence handling and config compatibility
