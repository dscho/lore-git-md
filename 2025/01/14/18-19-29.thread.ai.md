[Security] ANSI escape sequence injection vulnerability in sideband channel. Original series by reporter addresses CWE-150 through sanitization while preserving ANSI colors. First patch introduced `strbuf_add_sanitized()` function replacing control characters (except tab/newline) with caret notation (^[), implemented in `sideband.c` via `maybe_colorize_sideband()`, with test coverage in `t5409-colorize-remote-messages.sh`. Second patch adds configurable bypass via `sideband.allowControlCharacters` (not `transfer.sideband.allowControlCharacters` as previously indicated), checked in `use_sideband_colors()` to optionally skip sanitization. New `config/sideband.txt` documents security implications. Test suite extended to verify both default sanitization and opt-out behavior, maintaining color infrastructure while adding control point. Git for Windows v2.47.1(2) contains partial fix. Key technical elements: sanitization function, configurable bypass, modified sideband handling, comprehensive test verification of attack prevention, color preservation, and config override. Open questions remain about terminal emulator hardening alternatives and whether the config namespace (`sideband.*` vs `transfer.sideband.*`) is final. Security team reviewed initial approach; no new review feedback on config mechanism yet.
