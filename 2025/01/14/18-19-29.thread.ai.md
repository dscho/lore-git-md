[Security] ANSI escape sequence injection in Git's sideband channel (CVE-2024-32002, CVE-2024-52005/GHSA-7jjc-gg6m-3329). Johannes Schindelin's implementation provides configurable sanitization via `sideband.allowControlCharacters` with three states: `default`/`color` (permits colors, line feeds and tabs as new default), `false` (blocks all control characters except basic formatting), and `true` (original allow-all behavior). Granular bitmask flags (ALLOW_ANSI_COLOR_SEQUENCES default-allowed, ALLOW_ANSI_CURSOR_MOVEMENTS/ERASE default-blocked) enable fine-grained control through comma-separated values while maintaining backward compatibility with boolean syntax.

Core sanitization in `strbuf_add_sanitized()` and `handle_ansi_sequence()` validates sequences against policy without allocations by parsing CSV directly. The initial patch introduces `strbuf_add_sanitized()` with conservative default blocking of non-formatting control characters (replaced with caret notation like `^[`), affecting all sideband output.
