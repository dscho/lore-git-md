Utility function addition for the remote object-info series.

This is the first patch in an 8-part series implementing client-side remote object-info functionality (v10). It introduces a new helper function `strtoul_ul()` to `git-compat-util.h` that provides error-checked conversion to unsigned long values, similar to existing functions like `strtoul_ui()`. The implementation carefully handles negative values and parsing errors while following Git's established patterns for string-to-number conversion.

The function will be used later in the series for processing object information responses. While small, this is a well-crafted utility addition with clear documentation and negative value handling that matches Git's existing conventions. The patch shows attention to detail with proper error checking and matches the style of similar functions in the codebase.
