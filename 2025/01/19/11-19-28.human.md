This is part 3/5 of a series in the `the_repository` removal effort, converting pack-writing functions to avoid global variables. The patch focuses on `write_idx_file()` and its caller `stage_tmp_packfiles()` in `pack-write.c`, making them take an explicit `hash_algo` parameter instead of using the global `the_hash_algo`.

The changes are mechanical but thorough, updating all callers in `fast-import`, `index-pack`, `pack-objects`, and `bulk-checkin` to pass `the_hash_algo` for now. This maintains compatibility while pushing the global variable usage up to higher layers, where it can be addressed later. The commit message notes this is an intermediate step in the larger refactoring effort.

The implementation looks clean and follows the established pattern seen in earlier patches of this series. As with previous patches, the author has been careful to maintain exact behavior while making the architectural improvement. The changes affect core pack-writing functionality but are low-risk since they don't alter the pack format or on-disk structure.
