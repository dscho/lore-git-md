This is part 4/5 of a series in the `the_repository` removal effort, converting the `write_rev_file()` family of functions to explicitly take a `hash_algo` parameter instead of using the global `the_hash_algo`. The patch updates `write_rev_file()`, `write_rev_file_order()`, and `write_rev_header()` to accept the hash algorithm as input, propagating this change through their callers.

The implementation follows the series' established pattern: while the lower-level functions now take explicit parameters, callers in `index-pack.c` and `pack-write.c` temporarily pass `the_hash_algo` to maintain compatibility. The exception is `midx-write.c`, which already has repository context available and uses that instead of reintroducing global variables.

The changes are mechanical but thorough, updating function signatures and call sites while preserving all existing behavior. This continues the incremental approach of pushing global variable usage up to higher layers where it can be addressed separately. The patch appears well-constructed with clear commit message explaining the transitional nature of the changes.
