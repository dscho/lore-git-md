This is a preparatory patch in Jeff King's series fixing sparc64 alignment issues, specifically addressing static analyzer warnings. The patch modifies the `put_be32()` and `put_be64()` functions in `compat/bswap.h` to explicitly mask shifted values with `0xff`, silencing sparse warnings about potential truncation when these functions are called with constants. While the masking doesn't change the actual behavior (the compiler already knew to discard the extra bits), it makes the intention clearer to static analyzers.

The change is straightforward and well-explained, showing identical generated assembly before and after. This is part of a larger effort to make Git's pack handling robust against alignment issues, particularly on sparc64 where unaligned access causes SIGBUS crashes. The patch follows the same pattern already used in reftable's version of these macros.
