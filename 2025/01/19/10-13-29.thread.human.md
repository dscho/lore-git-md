This thread documents the planning for Git's participation in Google Summer of Code (GSoC) 2025. The discussion has focused on two main tracks: finalizing mentor assignments for potential projects and deciding where to host project documentation. 

All mentor assignments have now been confirmed, with Patrick Steinhardt taking the lead on ref consolidation (with Christian Couder and Shejialuo as co-mentors), Christian Couder leading global state refactoring (with Karthik Nayak and Shejialuo), and Karthik Nayak mentoring the machine-readable query tool project (with Patrick). The HTTP reftables project, while still listed, is effectively deprioritized since Patrick can only mentor one project and has chosen ref consolidation. Kaartic Sivaraam has already submitted Git's GSoC application with these arrangements.

The only remaining open question is where to host project documentation - either continuing with git.github.io or moving to a wiki solution as proposed by Junio. This decision is pending confirmation from Junio and Patrick. With mentor assignments settled, the application submitted, and project selection narrowed to three out of the proposed four, the thread is largely resolved aside from this final documentation question.
