The annual Google Summer of Code (GSoC) 2025 planning thread for Git is underway, with Kaartic Sivaraam continuing as Org Admin but stepping back from mentoring this year. The immediate priorities are updating the project ideas page from last year's content and recruiting mentors before the February 11 deadline, with a GSoC meetup planned during FOSDEM on February 1.

Patrick Steinhardt has volunteered as a mentor and proposed three technically focused project ideas for students. The most concrete suggestion is creating a unified `git-refs` command to consolidate ref-related operations currently scattered across multiple commands, while maintaining backward compatibility. He also suggested refactoring `environment.c` to reduce global state (aligning with ongoing efforts in the codebase) and a more exploratory project around machine-readable repository metadata. These proposals emphasize architectural improvements rather than new features, with the ref consolidation being particularly well-scoped for a GSoC project.

The thread now needs additional mentor volunteers and refinement of the project ideas list. Christian Couder, as a PLC member with GSoC experience, may weigh in as the planning progresses. The contributor application period will run from March 24 to April 8.
