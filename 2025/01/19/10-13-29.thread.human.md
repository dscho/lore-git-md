The Git project is preparing for its 2025 Google Summer of Code participation, organized by Kaartic Sivaraam and Christian Couder as Org Admins. The program will feature two tracks: Patrick Steinhardt's architectural projects (including a unified refs command and environment.c refactoring) and Christian Couder's suggested microprojects (like `the_repository` elimination and warning cleanup). Returning mentor Karthik Nayak will focus on the architectural track, building on his 2024 experience with ref backends and maintenance infrastructure. Two meetups are confirmed - in Madrid and at FOSDEM in Brussels - to engage prospective students.

In a recent development, Patrick Steinhardt proposed moving the project ideas list into Git's main repository as "Documentation/Projects.txt" to improve maintainability and discoverability. This suggestion builds on the existing planning while addressing documentation needs, though implementation details remain to be worked out. The team continues to refine project scope and mentor coverage ahead of the February deadlines, with the application period running March 24 to April 8. The effort ties into several ongoing technical initiatives in the Git project, including ref backend work and global state reduction.
