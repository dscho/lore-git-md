This is the first patch in a 5-part series for the `the_repository` removal effort, converting `fixup_pack_header_footer()` to take an explicit `hash_algo` parameter instead of using the global `the_hash_algo`. The patch modifies the function signature and all its callers across multiple files (`fast-import.c`, `index-pack.c`, `pack-objects.c`, `bulk-checkin.c`), while temporarily maintaining compatibility by passing `the_hash_algo` from upper layers. The implementation correctly passes the full algorithm struct (not just the hash function), though earlier versions of the commit message needed clarification on this point. This establishes the series' pattern of mechanical refactoring while preserving behavior, with the expectation that upper layers will eventually be converted to pass repository-specific algorithm parameters rather than the global. The changes are straightforward and well-contained, affecting pack-writing functionality that's widely used across Git's object storage system.
