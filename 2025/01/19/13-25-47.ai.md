This is part of Jeff King's bugfix series addressing sparc64 SIGBUS crashes in Git's pack handling when compiled with clang. The patch focuses on fixing alignment issues when reading pack headers in both `index-pack` and `unpack-objects` commands.

The change replaces direct struct reads from unaligned `unsigned char` buffers with alignment-safe `get_be32()` operations, mirroring the earlier write-side fixes. It introduces a new `pack_version_ok_native()` helper to handle version checks without requiring network-to-host byte order conversion. The patch maintains the same architectural approach as previous versions while cleaning up the code slightly.

Key technical details include:
- Modifies pack header parsing in both `index-pack` and `unpack-objects` to use byte-by-byte reading
- Adds `pack_version_ok_native()` to `pack.h` for version checking
- Preserves all existing functionality while making it alignment-safe
- Follows the same pattern as earlier patches in the series for consistency

The changes affect `builtin/index-pack.c`, `builtin/unpack-objects.c`, and `pack.h`, with straightforward mechanical conversions of the header parsing logic. This completes the read-side protection that complements the write-side fixes from earlier patches in the series.
