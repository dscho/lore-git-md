This is a preparatory patch in Jeff King's series fixing sparc64 alignment issues, specifically addressing static analyzer warnings. The patch modifies the byte-swapping utilities in `compat/bswap.h` to explicitly mask bits when shifting values into bytes, silencing sparse warnings about potential truncation when constants are passed to `put_be32()` and `put_be64()`. 

The change is technically a no-op for runtime behavior since the compiler already handles the masking implicitly, but makes the intent clearer to static analyzers. The commit notes this pattern was already used in reftable code and in one existing Git case (fsmonitor.c), though the latter wasn't flagged due to the small value size. The diff shows straightforward mechanical changes adding `& 0xff` masks to all shift operations in the put_be* functions.

This patch serves as groundwork for later changes in the series that will use these functions more extensively for alignment-safe pack header operations. The modification maintains the series' focus on robustness while cleaning up tool warnings, though it's independent of the core sparc64 alignment fixes.
