This is a utility patch adding a new helper function as part of the remote object-info series. It introduces `strtoul_ul()`, a string-to-unsigned-long conversion function with robust error handling, similar to existing `strtoul_ui()` but returning an unsigned long` instead of unsigned int`.

The implementation follows Git's established patterns for safe string parsing, rejecting negative values and checking for conversion errors. This will be used later in the series for parsing object size responses from the server. The patch is straightforward and well-contained, with no apparent issues in the implementation.

As the first patch in a larger series implementing client-side remote object-info functionality, this provides a building block needed for subsequent patches. The change is minimal and focused, exactly what you'd want to see in an early series patch.
