Feature patch adding remote object info support to `git cat-file --batch-command`.

This is the final patch in a 9-part series implementing client-side object-info functionality (RFC v9). It adds a new `remote-object-info` command to `git cat-file --batch-command` that fetches object metadata (currently just sizes) from a remote server without downloading the objects themselves. The implementation handles multiple OIDs per command to reduce round trips, works with buffered mode, and supports git://, file://, and http:// transports. Server capability is checked via the object-info feature advertised when `transfer.advertiseobjectinfo` is enabled.

The patch includes comprehensive tests covering:
- Basic functionality across all supported protocols
- Error cases (unsupported protocols, missing objects, malformed input)
- Buffer mode and null-delimited input
- Server capability checking
- Current limitations (only object size is supported, not type/deltabase)

The implementation looks solid with careful memory management and thorough test coverage. This completes the client-side plumbing for remote object queries, building on earlier protocol and transport work in the series. The default output format is noted as temporary until object type support is added.
