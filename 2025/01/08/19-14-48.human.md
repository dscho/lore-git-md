This is part 6 of an 8-part series refactoring Git's hash algorithm handling to eliminate separate variants of hash operations. The patch converts the test-hash helper to use the new `unsafe_hash_algo()` infrastructure introduced earlier in the series.

Taylor Blau simplifies the test helper by removing repetitive conditional logic that previously selected between safe and unsafe hash operations. Instead, the helper now uses a single early check to get the appropriate algorithm variant (safe or unsafe) via `unsafe_hash_algo()`, then proceeds with standard function calls through the algorithm pointer. This matches the pattern established in earlier patches and demonstrates the cleaner API in test code.

The change is mechanical and straightforward, reducing 17 lines to 5 while maintaining identical functionality. As with previous patches in the series, this maintains backward compatibility while moving toward the new unified approach. The test helper continues to support both safe and unsafe operations, but now does so through the centralized algorithm selection mechanism rather than scattered conditionals.
