Feature implementation for remote object info in cat-file, building on prior server-side work. This is version 9 of a series that adds client-side support for requesting object information (currently just sizes) from a v2 protocol server via a new `remote-object-info` command in `git cat-file --batch-command`.

Key technical details:
- New files: fetch-object-info.[ch] handle the request/response protocol
- Protocol: Strictly v2-only (rejects v0/v1 with clearer "unsupported" error)
- Current feature: Only "size" requests supported via object-info capability
- Memory: Uses xcalloc for result allocation, with flattened allocation logic
- Error handling: Validates server capability, protocol version, and response structure
- Testing: New t1017 tests cover various failure modes and protocol scenarios

Changes since v7 (v9 corrects v8's range-diff issues):
- Added strtoul_ul() helper for safer size parsing
- Split test utilities into lib-cat-file.sh
- Fixed quadratic string_list lookup
- Added missing OID validation
- Improved documentation links and error messages
- Various code organization and style improvements

The implementation appears thorough, with careful attention to review feedback. The test coverage is extensive, including edge cases like missing OIDs and legacy protocol rejection. The series maintains clear compatibility boundaries while introducing the new client-side capability. Future work is noted to expand beyond just size information once server support exists.
