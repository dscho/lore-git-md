This is a utility patch adding a new helper function to Git's compatibility layer, part of the larger remote object-info series. It introduces `strtoul_ul()` to complement existing string-to-number conversion functions like `strtoul_ui()`, providing unsigned long parsing with robust error handling.

The new function follows the established pattern of Git's numeric parsing utilities, rejecting negative numbers (which `strtoul()` would accept) and checking for parse errors via `errno` and end-of-string validation. The implementation is straightforward and matches the style of adjacent functions in git-compat-util.h.

This foundational change supports the series' need to safely parse object information (particularly sizes) from server responses in the remote object-info feature. The patch appears well-contained and properly scoped, with no obvious issues in the implementation. As the first in the series, it sets up a utility that subsequent patches will use when processing server responses.
