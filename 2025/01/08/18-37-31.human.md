This is a feature patch series (v9) adding client-side support for remote object information retrieval via `cat-file --batch-command`. The series builds on server-side support added earlier and allows querying object sizes from a protocol v2 server without downloading the full objects.

The key addition is a new `remote-object-info` command for `cat-file --batch-command` that queries object sizes from a remote server. The implementation requires protocol v2 and will fail if the server doesn't support the object-info capability. Currently only object sizes are supported, with plans to add type information later.

The series appears well-structured, with clear separation of concerns between transport layer updates and the cat-file integration. It incorporates feedback from previous rounds, including error message improvements and test coverage expansion. Notable changes in v9 include better error handling for strtoul operations, test utility refactoring, and a new test case for missing OID validation.

The patch touches several areas: transport layer updates to support object-info requests, new fetch-object-info.[ch] files for core functionality, cat-file integration, and comprehensive tests. While focused on size retrieval now, the design leaves room for future expansion to support additional object metadata types when server support is added.
