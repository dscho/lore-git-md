This is a feature patch (5/6 in a series) adding client-side support for the object-info protocol, which allows querying object metadata without full downloads. The patch implements the v2 protocol support for requesting object sizes from servers that advertise the capability.

The implementation introduces new files `fetch-object-info.{c,h}` with core functionality for sending object-info requests and processing responses. The client currently only supports the 'size' feature and requires protocol v2. Calvin Wan provided feedback on error message wording and suggested simplifying some conditional logic, which the author acknowledges will be addressed in v9.

This appears to be a well-structured addition to the transport layer, building on existing server-side support. The patch has received helpful feedback from multiple contributors and seems ready for review, though it's part of a larger series whose overall goal isn't restated here. The changes are focused and appropriately scoped to the client-side implementation.
