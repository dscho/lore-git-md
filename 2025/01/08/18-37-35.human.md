This is a refactoring patch in a series implementing client-side remote object-info support. It generalizes the packet-writing code in `fetch-pack.c` to be reusable for other protocol v2 operations beyond just fetch.

The patch moves and renames `write_fetch_command_and_capabilities()` to `connect.c` as the more generic `write_command_and_capabilities()`, making it available for future protocol operations like the object-info capability being added in this series. The function handles writing the command name and negotiating capabilities like agent, session-id, server-options, and object-format.

Key changes include:
- Moving the function to `connect.c` where it can be shared
- Making the command name a parameter rather than hardcoding "fetch"
- Simplifying the `advertise_sid` handling since it's only used for v2
- Keeping all the same capability negotiation logic

The patch is well-motivated as part of the larger object-info feature work, with clean separation of concerns. It has already incorporated review feedback from Jonathan Tan and Christian Couder, and maintains the series' high code quality standards. The changes are straightforward and focused on code organization rather than behavior changes.
