Refactoring patch in a series implementing remote object-info functionality.

This is a straightforward code style improvement that moves loop counter variable declarations inside their respective `for` loops where they are only used locally. The changes affect `builtin/cat-file.c` and `fetch-pack.c`, converting several instances where loop counters were declared at function scope to be declared within the loop itself. 

The patch is part of Eric Ju's v9 series adding client-side support for remote object-info functionality, though this particular change is a general code quality improvement rather than being directly related to that feature. It follows standard C best practices for limiting variable scope and has been reviewed by Christian Couder. The changes are mechanical and low-risk, touching only loop initialization syntax without altering any actual logic.
