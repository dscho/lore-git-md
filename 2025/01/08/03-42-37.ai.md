This is a build system fix targeting the meson build configuration for Perl components. The patch addresses a parallel build issue where Perl-related build targets weren't properly declaring their dependency on `git_version_file`, which provides the `GIT-BUILD-OPTIONS` file needed during compilation. While the top-level meson.build correctly specified this dependency, eight Perl-related meson.build files in various subdirectories (including Git/SVN, Git/LoadCPAN, and FromCPAN modules) were missing it.

The change is straightforward: each affected file gets a `depends: [git_version_file]` added to its `custom_target` definition for `generate_perl_command`. The patch appears technically sound and focused - it's a clear fix for a specific build system race condition that would manifest during parallel builds. The change is consistent across all Perl components and follows the pattern already established in the main build file.
