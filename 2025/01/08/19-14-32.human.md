Refactoring and test helper for unsafe SHA-1 operations. This is the first patch in an 8-part series that reworks Git's hash algorithm handling to eliminate separate "unsafe" variants of hash operations.

Taylor Blau adds a new `sha1-unsafe` test helper that exercises Git's unsafe SHA-1 wrappers, mirroring the existing `sha1` test helper. The implementation modifies the generic `cmd_hash_impl()` function to conditionally use unsafe variants of hash operations (init, update, final) when requested, then exposes this through the new helper. The patch also updates test scripts to verify both safe and unsafe variants produce identical results.

This appears to be a straightforward test infrastructure change supporting the larger refactoring effort. The implementation looks clean, maintaining the existing test patterns while adding coverage for the unsafe variants. As the first patch in the series, it sets up testing capabilities that will presumably be used to verify the subsequent hash algorithm changes.
