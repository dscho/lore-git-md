This is a build system fix addressing a parallel build issue in the Meson configuration. Sam James identifies that several Perl-related build targets were missing a dependency on `git_version_file`, which could cause failures during parallel builds when `GIT-BUILD-OPTIONS` wasn't yet available. The patch adds the missing dependency to eight Perl-related Meson build files, all following the same simple pattern of adding one line.

The change is straightforward and appears to address a real build reliability issue. The patch is cleanly formatted and touches only the relevant build files. While the impact is limited to Meson-based builds (not affecting Makefile builds), it's an important fix for anyone using that build system, particularly in parallel build scenarios.
