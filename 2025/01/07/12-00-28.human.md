This is the final patch in a series adding comprehensive ref consistency checks to Git, now integrating them into `git fsck`. The patch adds a `fsck_refs()` function that runs `git refs verify` as a child process, with progress reporting and flag passthrough from the parent fsck process.

The patch is now in the final integration stages, though maintainer Junio Hamano notes there was a semantic conflict with another in-flight topic that he has resolved. The author acknowledges this and will watch for any need to rebase if the conflicting topic merges to master first.

This completes the series' goal of adding systematic validation for ref storage, covering file types, headers, refname validity, entry syntax, object existence, and sort order. The child process approach provides clean separation while leveraging fsck's reporting infrastructure. The work appears well-structured with thorough test coverage across all validation scenarios.
