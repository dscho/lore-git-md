This is a performance optimization and code simplification patch in the ongoing LSan (LeakSanitizer) test infrastructure series. The patch replaces a `find | xargs grep` pipeline with direct shell globbing in the leak detection logic of `test-lib.sh`.

The key changes are:
1. Eliminating the `find` process fork by using shell glob expansion directly
2. Properly handling paths with spaces through native shell behavior
3. Removing redundant error handling since `grep -s` (silent mode) suppresses unmatched glob warnings
4. Maintaining POSIX compliance while simplifying the control flow

The patch builds on previous work that introduced the `DEDUP_TOKEN`-based LSan output parsing system (commit b119a687d4). Junio Hamano's review confirms the technical soundness of the approach, noting the practical irrelevance of command-line length limits (which were already present in related code) and the improved readability of the solution. The change also naturally handles edge cases like missing directories without requiring special comments.

This is part of a larger 6-patch post-merge refinement series that follows the original 6-patch technical implementation addressing LSan race conditions in threaded test execution. The current focus is on maintainability improvements and documentation polish while preserving the core technical architecture.
