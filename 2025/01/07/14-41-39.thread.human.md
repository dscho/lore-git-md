Here's the updated human-readable thread summary:

Keith Mendoza reported a Git crash when using `git restore --staged -p` during merge conflicts, encountering an assertion failure in add-patch.c. The issue occurred when trying to interactively stage changes on unmerged files, specifically when the diff contained "Unmerged path" lines that weren't properly handled. The bug was reproducible on Git 2.39.5 running on Linux/WSL2.

Kristoffer Haugsbakk confirmed this was a known issue that was fixed in Git v2.41.0 (commit 28d1122f9ca). The bug was introduced when the interactive patch interface became the default in v2.37.0 and affected versions up through v2.40.x. The fix properly handles unmerged path markers in diff output, resolving the crash that would produce the error "BUG: add-patch.c:497: diff starts with unexpected line". 

While the fix has been available since mid-2023, some users on older versions like 2.39.5 may still encounter this issue. Testing with v2.48.0-rc2 confirms the problem is resolved. This was a real usability issue that could cause core dumps during selective staging of conflicted files, particularly impacting users who haven't upgraded to versions containing the fix.
