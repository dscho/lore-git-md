This thread introduces a test modernization patch converting Git's hash function tests from the old test-lib style to the clar unit test framework. The patch, following patterns established by Patrick Steinhardt's mentoring, renames the test file to follow clar conventions (u-hash.c) and replaces assertions with clar's macros while preserving all existing test vectors. The mechanical conversion maintains identical test coverage for empty strings, various input patterns, and Git object literals, with corresponding build system updates. This continues the project-wide effort to adopt clar for C unit tests, complementing the traditional shell-based test suite. The changes are focused on test infrastructure only, leaving the actual hash functionality unchanged.
