Feature addition to `git cat-file` integrating the object-info protocol.

This final patch in the v8 series adds a `remote-object-info` command to `git cat-file --batch-command`, enabling batched metadata queries to remotes without downloading full objects. The implementation differs from local `info` commands by processing multiple OIDs in a single remote request to minimize network overhead, with distinct handling for both buffered and non-buffered modes. The current version supports only the "size" attribute (via `%(objectsize)`), explicitly noting that `%(objecttype)` and other fields are unsupported, with warnings about future format unification when more attributes are added.

The patch includes comprehensive documentation updates and a substantial test suite (652 lines across new files t/lib-cat-file.sh and t/t1017-cat-file-remote-object-info.sh). The implementation builds on the core object-info infrastructure from earlier patches, connecting it to the cat-file machinery while maintaining the protocol's version and capability requirements.
