This is part 5/6 of a series implementing client-side support for the object-info protocol feature, which allows querying object metadata without downloading full objects. The patch adds core client functionality for making object-info requests to a Git server.

The implementation introduces new files `fetch-object-info.{c,h}` containing functions to construct and send object-info requests, and parse the server replies. The client currently only supports the "size" attribute and requires protocol v2. The code handles both stateful and stateless RPC modes, with proper packet reading and error handling.

Key technical details:
- New `send_object_info_request()` builds the request packet with object IDs and requested attributes
- `fetch_object_info()` handles the protocol version check, request sending, and response parsing
- Server must advertise object-info capability (controlled by `transfer.advertiseobjectinfo`)
- Only "size" attribute is implemented in this version
- Error handling includes protocol version checks and stateless RPC delimiters
