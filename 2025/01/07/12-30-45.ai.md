CI modernization patch implementing rootless container execution for GitHub Actions.

This patch (3/10 in Patrick Steinhardt's CI modernization series) modifies GitHub Actions workflows to run tests under a non-root user account, addressing permission-related test failures that occurred when running containerized jobs as root. The changes create a dedicated 'builder' user and execute both test runs and failure artifact collection under this account, mirroring existing GitLab CI infrastructure.

Key technical changes include:
- Adding `useradd` and `chown` steps to create and prepare the builder account
- Wrapping test execution in `sudo --user=builder` to drop privileges
- Installing `shadow-utils` and `sudo` packages as new dependencies on Fedora/AlmaLinux
- Preserving environment variables during privilege drops to maintain test context

The implementation follows the series' broader goal of standardizing containerized CI across platforms while improving security and test reliability. This specific change helps ensure tests behave consistently with non-root execution environments, particularly important for permission-related test cases. The patch builds on the series' earlier containerization work while maintaining compatibility with the newly introduced i386 testing from other patches in the set.
