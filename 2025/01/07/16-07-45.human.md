This is a follow-up in a bug report thread that has already been resolved. The original reporter, Keith Mendoza, confirms receiving information from Kristoffer Haugsbakk about the fix for `git restore --staged -p` crashing during merge conflicts. The bug was introduced in Git 2.37.0 when interactive patch selection became the default, causing assertion failures when processing unmerged paths in conflicted files.

The thread has established that the fix (commit 28d1122f9ca) has been available since Git 2.41.0, though the reporter was using an older maintenance release (2.39.5) where the issue still occurred. Kristoffer provided a clean reproduction showing the fix works in the current development version (2.48.0-rc2).

This email serves as a simple acknowledgment from the original reporter, closing the loop on what turned out to be a known issue with an existing fix. No further discussion is needed unless users encounter the problem on versions where the fix hasn't been backported.
