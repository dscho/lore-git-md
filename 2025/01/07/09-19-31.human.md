This is a test infrastructure patch that fixes a minor but important issue in Git's unit test framework. The `generate-clar-decls.sh` script, which extracts test function signatures for the clar test runner, was too strict in its pattern matching - it would only catch function declarations that ended immediately after `void)`, missing those with trailing comments or annotations.

The patch relaxes the regular expression to match function declarations regardless of what follows them, making the script more robust when parsing test files. This is part 1 of a 2-patch series (though we haven't seen the cover letter or second patch yet). The change is small but meaningful - a single character change to the sed pattern that adds `.*` to catch trailing content.

The patch comes with a clear commit message explaining both the problem and solution, and is mentored by Patrick Steinhardt, suggesting it's part of an organized effort to improve the test infrastructure. While the impact is limited to developers working with the unit test framework, it's a clean, focused improvement that should prevent potential issues when writing tests with annotations.
