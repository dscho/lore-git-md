This is a test infrastructure patch that fixes a regex pattern in the unit test declaration generator script. It's part 1 of a 2-patch series (though no cover letter was provided for context about the series' overall goal).

The patch modifies `generate-clar-decls.sh` to properly handle test function declarations that have trailing content (like annotations or comments) after the signature. The current implementation only matches declarations that end immediately after `void)`, causing it to miss some valid test functions. The fix adds `.*` to the regex pattern to match any trailing content, making the script more robust when parsing test suite files.

Key technical details:
- The script extracts test function signatures to generate `extern` declarations for the clar test framework
- The change affects how unit test files (named with `u-` prefix) are processed
- The modified regex now matches lines like `void test_suite__name(void) /* comment */`
