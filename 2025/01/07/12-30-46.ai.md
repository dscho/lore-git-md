CI modernization patch converting GitHub Actions Linux jobs to containerized execution.

This is patch 4/10 in Patrick Steinhardt's CI modernization series, focusing on standardizing containerized execution across GitHub Actions. The patch moves all remaining Linux jobs from direct machine pool execution to container-based runs, completing the containerization effort started earlier in the series. The key technical change reorganizes the job matrix in `.github/workflows/main.yml`, moving Linux jobs to the containerized section while preserving their existing configurations (compiler versions, test suites).

The containerized approach gives more control over the execution environment while maintaining compatibility with existing test suites. This change builds on the rootless container support added in the previous patch (3/10) to ensure tests run with appropriate permissions.
