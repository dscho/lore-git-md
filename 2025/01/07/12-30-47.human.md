CI infrastructure patch simplifying distro naming in GitHub Actions. This is part of Patrick Steinhardt's v3 series modernizing Git's CI system.

The patch streamlines how Linux distro information is handled in GitHub Actions workflows by eliminating redundant explicit distro names. Instead, it derives the distro name from the container image name (replacing colons with dashes), matching GitLab CI's approach. The change touches workflow definitions and supporting scripts while handling a few special cases: the linux32 job keeps its distinct naming, while Alpine and Fedora jobs now explicitly use the "latest" tag.

This simplification reduces maintenance overhead in the CI configuration while maintaining all existing functionality. The changes are straightforward mechanical updates to YAML and shell scripts, with no behavioral impact on test execution. As part of the broader CI modernization effort, this helps standardize the container-based testing approach across GitHub and GitLab platforms.
