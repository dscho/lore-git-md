This is a bugfix confirmation email in an ongoing thread about a Git crash during merge conflict resolution. Keith Mendoza is responding to Kristoffer Haugsbakk's confirmation that the `git restore --staged -p` crash they experienced was indeed a known issue fixed in Git v2.41.0.

The thread establishes that the bug occurred when trying to interactively stage changes (`-p`) on unmerged files after a merge conflict, specifically triggering an assertion failure in add-patch.c when encountering "Unmerged path" lines in the diff output. The fix (commit 28d1122f9ca) properly handles these conflict markers and was included in v2.41.0, though the reporter was still experiencing the issue on v2.39.5.

Key technical details include the specific error message ("BUG: add-patch.c:497: diff starts with unexpected line"), the version range where the bug was present (v2.37.0 through v2.40.x), and the clean reproduction steps that now work correctly in v2.48.0-rc2. The thread shows this was a real user-impacting issue causing core dumps during selective staging of conflicted files, with the fix having been available since mid-2023 but not yet reaching all users via maintenance releases.
