This is a v3 cover letter for Patrick Steinhardt's CI modernization series, now reduced to 10 patches after further refinements. The series represents the culmination of infrastructure improvements that remove Azure Pipelines, stabilize tests, and standardize containerized CI across GitHub Actions and GitLab CI.

The key changes in v3 iteration focus on the persistent t7422 submodule SIGPIPE test issue. After multiple rounds of discussion with Jeff King about the tradeoffs between test specificity and general-purpose solutions, Patrick has landed on a final approach that precisely replicates the submodule output conditions that trigger the original SIGPIPE scenario from commit 082caf527e. The solution uses 2500 artificial submodules (~150kB output) created via `git hash-object` and `git mktree`, with strategic sleeps around the `grep` call to ensure reliable reproduction.

Other notable changes in the series include:
- Removal of the "linux-old" job and stale Azure Pipelines code
- Addition of i386 testing via a new linux32 job
- Dropping Ubuntu 16.04 special-casing
- Migration of all Linux jobs to containerized execution
- Rootless container support for GitHub Actions
- MinGW EBUSY fix in t0060

The series has been tested on both GitLab and GitHub CI platforms, with links provided to test runs. With the SIGPIPE test now addressed and all major infrastructure goals achieved, this appears to be the final iteration of this comprehensive CI modernization effort. The discussion around test design principles (specific regression tests vs general patterns) will likely inform future test development beyond this series.
