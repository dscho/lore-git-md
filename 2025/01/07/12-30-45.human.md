This is part of Patrick Steinhardt's CI modernization series, specifically implementing rootless container execution for GitHub Actions jobs.

Patch 3/10 in the series adapts GitHub's containerized jobs to run as a non-root user, mirroring existing GitLab CI infrastructure. Currently, the jobs run as root, which causes test failures due to permission-related issues that wouldn't occur in normal user scenarios. The change creates a dedicated "builder" user to execute the test suite and related commands, using `sudo` to drop privileges.

The implementation requires two main changes: adding user management tools (shadow-utils and sudo) to the Fedora/AlmaLinux dependencies, and modifying the GitHub workflow to create the user and run commands under its context. This brings GitHub Actions behavior in line with GitLab CI's approach while maintaining the same test execution environment.

This is a straightforward but important piece of the larger CI modernization effort, removing a long-standing inconsistency between test environments. The change is well-contained and follows established patterns from the GitLab implementation, suggesting it should integrate smoothly with the rest of the series.
