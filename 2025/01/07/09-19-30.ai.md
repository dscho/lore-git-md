This is a test infrastructure patch series, specifically part of the ongoing effort to migrate unit tests to the Clar framework. The cover letter introduces a 2-patch series that converts the hash-related unit tests from the old t-hash.c format to the new Clar-based u-hash.c. The changes are mechanical in nature - deleting the old test file and creating a new one with equivalent tests in Clar format, plus minor adjustments to build system files. The series is mentored by Patrick Steinhardt, suggesting this is part of a coordinated effort to standardize the test framework. The patch touches test infrastructure files (Makefile, meson.build) and completely replaces the test implementation while maintaining test coverage. The conversion appears straightforward with no behavior changes - just a framework migration. This follows the pattern seen in other recent test conversions to Clar.
