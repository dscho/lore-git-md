CI modernization patch updating Ubuntu container images to test latest releases.

This patch from Patrick Steinhardt's CI modernization series (v3 09/10) changes the default Ubuntu container images from "ubuntu:latest" (which points to the current LTS release) to "ubuntu:rolling" (the actual latest release, currently 24.10). The change affects both GitHub Actions and GitLab CI configurations, updating 7 job definitions in .github/workflows/main.yml and 7 in .gitlab-ci.yml. The rationale is that since we already test the oldest supported Ubuntu LTS (20.04), we should also test the newest available release rather than just the current LTS.

The change maintains the existing test coverage while better representing the range of Ubuntu versions users might run. This follows logically from earlier patches in the series that removed Ubuntu 16.04 support and standardized container-based testing. The modification is straightforward, simply changing the image tag while preserving all other job parameters like compiler selection (gcc/clang) and test configurations (leaks, asan-ubsan, etc.).

Key technical points:
- Updates 14 job definitions across two CI systems
- Changes from LTS (ubuntu:latest) to current release (ubuntu:rolling)
- Maintains all other job parameters and configurations
- Follows series' goal of modernizing and standardizing CI infrastructure
- Builds on earlier Ubuntu 16.04 removal (c85bcb5de1)

This patch represents a logical completion of the Ubuntu version testing strategy in the CI modernization effort, ensuring we test both oldest supported and newest available releases. The change is low-risk as it doesn't modify test behavior, only the container environment they run in.
