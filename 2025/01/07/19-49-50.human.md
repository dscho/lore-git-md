This is a bug report and investigation regarding SMTP bearer authentication in `git send-email`. Mirth Hickford is testing Julian's patch that implements SMTP bearer auth (XOAUTH2/OAUTHBEARER) and has encountered an authentication failure with Gmail.

The issue appears when using long OAuth tokens (~220 chars) - the SMTP command gets corrupted by an extra space at position 241 in the base64-encoded auth string. Hickford provides detailed reproduction steps using both Gmail's OAuth configuration and a manual test with an artificially long password, showing the problem occurs consistently.

The email serves as both a test report and a request for debugging help, suggesting the issue may lie in Perl's Net::SMTP module. The thorough reproduction case and clear description of the failure make this a useful bug report, though it doesn't yet propose a solution. The next steps would likely involve debugging the SMTP command generation in the Perl code.
