This thread introduces a test infrastructure change converting Git's hash-related unit tests from the old t-hash.c format to the new Clar framework. The 2-patch series, mentored by Patrick Steinhardt, is part of the broader effort to standardize on Clar for unit testing. The changes are straightforward - replacing the test file while maintaining equivalent coverage, plus minor build system adjustments. This follows the established pattern of recent test migrations to Clar, with no functional changes to the tests themselves. The conversion appears uncontroversial as it's a mechanical framework change rather than a substantive test modification.
