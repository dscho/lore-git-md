This is a test modernization patch, part of an ongoing effort to convert Git's unit tests to use the clar framework. The patch converts the hash function tests from the old test-lib style to clar's assertion-based testing.

The changes include:
- Renaming `t-hash.c` to `u-hash.c` (following clar naming conventions)
- Replacing test-lib assertions with clar's `cl_assert` macros
- Restructuring the test cases as individual test functions rather than macros
- Maintaining all existing test vectors (empty string, single/multi-character inputs, message digests, repeated patterns, and blob/tree literals)
- Updating build files (Makefile and meson.build) to reflect the new test location

The conversion appears thorough, preserving all the original test coverage while adopting the clar framework's style. The patch follows the pattern established by Patrick Steinhardt's mentoring, as noted in the commit message. The changes are mechanical but important for test consistency, with no behavior changes to the actual hash functionality being tested.
