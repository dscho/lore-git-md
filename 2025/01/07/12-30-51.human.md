CI modernization patch updating Ubuntu test images to latest releases.

This is part 9/10 of Patrick Steinhardt's series modernizing Git's CI infrastructure. The patch changes the default Ubuntu test images from "ubuntu:latest" (which points to the current LTS release) to "ubuntu:rolling" (which tracks the actual latest release, currently 24.10). The change affects both GitHub Actions and GitLab CI configurations.

The rationale is that since the CI system already tests the oldest supported Ubuntu LTS (20.04), it makes sense to also test against the newest available release rather than just the current LTS. This provides better coverage of the version spectrum. The change is straightforward, updating the image tags in multiple job definitions while preserving all other job parameters.

This follows earlier patches in the series that removed Ubuntu 16.04 support and standardized container-based testing. The change appears well-considered and aligns with the series' goal of modernizing and simplifying the test infrastructure. No new test failures are expected since this just updates the base image for existing test configurations.
