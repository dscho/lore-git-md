This is the final patch in Patrick Steinhardt's CI modernization series, cleaning up Azure Pipelines remnants after the infrastructure was retired in favor of GitHub Actions. The patch removes two chunks of stale CI infrastructure:

1. Deletes the Azure Pipelines detection logic and environment variable handling from `ci/lib.sh`, including job metadata collection (branch, commit, build IDs) and test configuration specific to Azure. The file now directly checks for GitHub Actions without the intermediate Azure condition.

2. Removes Azure-specific test artifact handling from `ci/print-test-failures.sh` that previously moved failed test directories to a special artifacts folder. The GitHub Actions path remains unchanged.

The changes are straightforward cleanup following the Azure Pipelines retirement commit 6081d3898f from 2020. This completes the series' goal of fully modernizing Git's CI infrastructure by removing the last vestiges of the old system while maintaining all GitHub Actions functionality. The patch demonstrates good hygiene by not just disabling but actually removing unused code paths.
