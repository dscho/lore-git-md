This is a CI infrastructure patch in Patrick Steinhardt's ongoing series modernizing Git's CI system. It simplifies how Linux job distributions are specified in GitHub Actions by eliminating redundant distro name declarations and standardizing on using the container image name as the source of truth.

The patch makes three key changes:
1. Replaces explicit `distro` variables with derived values from `CI_JOB_IMAGE` (converting colons to dashes)
2. Handles special cases: the linux32 job now uses its image path directly, while Alpine and Fedora jobs get explicit `:latest` tags
3. Updates related scripts (`ci/install-dependencies.sh` and `ci/lib.sh`) to work with the new naming scheme

The changes maintain all existing functionality while reducing duplication between the workflow definition and job configuration. This aligns GitHub Actions' approach with GitLab CI's existing practice of deriving distro names from images. The patch is part of the broader effort to standardize containerized CI execution across platforms, with minimal impact on actual test execution while making the configuration more maintainable.
