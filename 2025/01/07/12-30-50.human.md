This is a CI cleanup patch in Patrick Steinhardt's ongoing CI modernization series (v3, patch 8/10). It removes special handling for Ubuntu 16.04 from the CI scripts, following the earlier migration to Ubuntu 20.04 as the baseline.

The patch is straightforward - it deletes conditional logic in `ci/lib.sh` that previously disabled HTTP/2 testing on Ubuntu 16.04 due to its outdated Apache version. Now that all CI jobs use Ubuntu 20.04 or newer, this special case can be removed, simplifying the script while maintaining the same test coverage.

This change is part of a larger effort to modernize Git's CI infrastructure by standardizing on newer Ubuntu versions, removing legacy Azure Pipelines support, and implementing container-based testing across both GitHub Actions and GitLab CI. The patch appears well-contained and low-risk, following naturally from the Ubuntu version bump that was already completed in an earlier patch.
