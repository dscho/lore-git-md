**CI cleanup patch** - Final removal of Azure Pipelines infrastructure in Patrick Steinhardt's CI modernization series.

This is the 10th and final patch in Patrick's v3 series that modernizes Git's CI infrastructure. The patch removes the last remaining Azure Pipelines-specific code from the CI scripts, following the platform's retirement in 2020 (commit 6081d3898f). The changes delete environment variable checks and job configuration logic that was only relevant for Azure, including test failure artifact handling.

The removal is straightforward - 21 lines deleted from ci/lib.sh and 5 from ci/print-test-failures.sh - with no functional impact since GitHub Actions has been the primary CI system for years. This cleanup completes the series' goal of standardizing on container-based workflows across GitHub Actions and GitLab CI.

As the concluding patch of a well-executed series that has already seen extensive discussion and testing, this change is unlikely to be controversial. It represents the final housekeeping step after the more substantive infrastructure changes in earlier patches.
