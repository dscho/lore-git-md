Build system patch in the zlib-ng performance optimization series, specifically addressing CI configuration for the linux-musl job when using Meson. This is part of the broader effort to support zlib-ng as an alternative zlib backend.

The email contains a question from Patrick Steinhardt about whether explicitly setting `CC=gcc` should be retained in the linux-musl CI configuration when switching to Meson. The concern is that Meson doesn't provide a way to specify the default compiler, so being explicit might be preferable. The patch removes this line along with several other Makefile-specific flags, replacing them with Meson equivalents for UTF-8 locale testing.
