This is a maintainer response in the ongoing thread about standardizing Git's help output behavior. Junio C Hamano acknowledges Kristoffer Haugsbakk's addition of a `Reported-by` trailer to credit Jonas Konrad for originally identifying the help output inconsistency. 

The email confirms that while the current patch introducing the new `show_usage_help()` API doesn't include the attribution, it would be appropriate for follow-up patches that actually convert commands like `builtin/branch.c` to use the new standardized approach. Junio notes he doesn't plan to handle those conversions personally, leaving that work to others in the community.

This brief exchange shows the thread moving from design discussion into implementation, with attention to proper credit assignment in Git's commit history. The maintainer is ensuring the original reporter gets recognition, even if not in the foundational API patch itself. The work now appears ready for contributors to systematically update the ~40 affected commands to use the new stdout-based help output standard.
