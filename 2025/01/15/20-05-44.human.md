This is a build system patch for the ongoing Rust bindings work, specifically adding Makefile integration for building and testing the `libgit-rs` and `libgit-rs-sys` crates. It's the final patch in a 5-part series introducing Rust bindings for Git's C library.

The patch adds new Makefile targets (`libgitrs`, `libgitrs-sys`, and their test counterparts) to build and test the Rust crates without requiring direct Cargo invocation. It also introduces an `INCLUDE_LIBGIT_RS` build variable that, when set, automatically includes these targets in `make all` and `make test` runs. The implementation handles symbol visibility requirements and ensures the Rust builds integrate properly with Git's existing build system.

This appears to be a well-considered addition to the series, providing convenient integration points while maintaining the optional nature of the Rust components. The patch follows the established pattern of keeping Rust bindings in `contrib/` without affecting core Git functionality. The co-authorship suggests careful coordination between the Rust binding developers.
