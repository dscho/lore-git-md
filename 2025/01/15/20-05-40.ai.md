Refactoring patch for Rust bindings infrastructure, splitting Git initialization code.

This is the first of five patches in v6 of the Rust bindings series, focusing on restructuring Git's initialization and exit handling to make `libgit.a` more self-contained. The patch moves `common_exit()` and `check_bug_if_BUG()` into a new `common-exit.c` file, and extracts initialization code from `main()` into a new `init_git()` function in `common-init.c`. Both new files are added to `LIB_OBJS` so they'll be included in `libgit.a`.

The changes allow external users (like the planned Rust bindings) to use Git's initialization and exit handling without pulling in all of `common-main.o` and its dependencies. This addresses a long-standing issue where `libgit.a` references required linking against many extra objects. The split was previously considered for fuzz/unit test support but is now motivated by Rust binding needs.

Key technical details: `common-exit.c` handles exit code masking and BUG checking, while `common-init.c` contains setup code for signals, locale, tracing, and repository initialization. The patch preserves all existing behavior while making these components independently usable. The changes are contained to initialization infrastructure with no impact on core Git functionality.
