This is a test infrastructure patch in the ongoing effort to standardize Git's help output behavior. Jeff King proposes an enhancement to `t0012-help.sh` that will help track progress in converting commands to send `-h` output to stdout rather than stderr.

The patch adds an optional strict mode (enabled by setting `GIT_TEST_HELP_MUST_BE_STDOUT=1`) that will fail tests when help output goes to stderr. This creates a tool for contributors to identify remaining commands that need conversion, while keeping the default test behavior permissive during the transition period. The strict mode will eventually become the default once all commands are converted.

The change builds on Junio Hamano's earlier work introducing the `show_usage_help_and_exit_if_asked()` helper function. Jeff's approach is characteristically pragmatic - it provides immediate utility for the conversion effort while maintaining backwards compatibility. The patch is small, focused, and clearly explained, with the temporary nature of the flag explicitly documented.
