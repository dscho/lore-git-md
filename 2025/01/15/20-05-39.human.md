Feature proposal: Rust bindings for Git internals

This is the sixth iteration of a series introducing Rust wrappers around Git's C internals. The patch set creates two new Rust libraries: `libgit-sys` (a low-level FFI wrapper) and `libgit` (a more ergonomic Rust API). The work has been tested with the JJ` VCS client as a proof of concept.

The series has evolved significantly since earlier versions, with notable changes in v6 including a reorganization of the directory structure (separating the sys wrapper from the higher-level crate) and cleanup of build system integration. The authors acknowledge some remaining technical debt around symbol visibility and versioning, but believe these can be addressed in follow-up work.

The implementation includes thorough test coverage and has been structured to integrate cleanly with Git's existing build system. While this is still marked as experimental, the careful attention to build system integration and backwards compatibility suggests it could serve as a foundation for future Rust-based Git tooling. The patch set appears well-considered and production-quality, though the maintainers will need to weigh in on whether they want to support Rust bindings in the main Git distribution.
