This is a follow-up in the ongoing effort to standardize Git's help output behavior. Kristoffer Haugsbakk adds a `Reported-by` tag to Junio Hamano's patch that introduces a new `show_usage_help()` function in parse-options.c, giving credit to Jonas Konrad for originally reporting the inconsistent behavior between commands' `-h` output (some going to stdout, others to stderr).

The patch being referenced establishes a systematic solution to the problem by providing a helper function that ensures help text always goes to stdout when explicitly requested with `-h`, while maintaining stderr output for error cases. This follows extensive discussion and auditing that revealed 40 builtin commands need updating to match the new standard.

Kristoffer's brief addition serves as proper attribution, recognizing Jonas Konrad's initial bug report that kicked off this standardization effort. The thread has progressed from problem identification through implementation design to now having a maintainer-approved solution with proper credit being given to contributors.
