Implementation refinement for Git help output standardization, focusing on the parse-options API design. Junio Hamano proposes a new helper function `show_usage_help()` that encapsulates the common pattern for handling `-h` help requests with stdout output, addressing the inconsistency where 40 builtins currently send help to stderr. The design intentionally makes careless conversions from `usage_with_options()` difficult by requiring argc/argv checking, forcing developers to properly inspect each callsite. The implementation shows help via stdout while maintaining the existing error-case behavior through `usage_with_options_internal()`, exiting with code 0 for help requests (versus 129 for errors). Jeff King's earlier suggestion to include argc/argv checking in the helper is incorporated, preventing blind string replacement conversions. This moves forward the maintainer-endorsed approach of standardizing help output while ensuring careful review of each conversion. The patch includes both the core implementation in parse-options.c and the corresponding header declaration, marking a key step before widespread adoption across the 40 affected builtins.
