Documentation patch clarifying optional parameter syntax. This is the second in Jean-Noël Avila's 5-part series standardizing git-commit documentation.

The patch makes a small but precise correction to document that the mode parameter for `git commit -u` is optional, matching the actual command behavior. It updates both the man page synopsis and the usage message in builtin/commit.c to show `-u[<mode>]` rather than `-u<mode>`, reflecting that the mode can be omitted.

This change follows naturally from the first patch's mechanical formatting improvements, now addressing a specific documentation accuracy issue. The modification is minimal (just two lines changed) but technically correct, aligning the documented syntax with Git's implementation. The patch maintains the series' focus on documentation consistency without introducing any functional changes.
