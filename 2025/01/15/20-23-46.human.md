Documentation patch refining git-commit option explanations. This is the third in Jean-Noël Avila's 5-part series standardizing Git's man page format, following earlier mechanical formatting changes and optional parameter clarifications.

The patch focuses on making option descriptions more direct and consistent by using imperative mood and standardized placeholder notation (_<file>_, _<msg>_). Changes include:
- Shortening explanations by removing redundant phrases ("Tell the command to" becomes "Automatically")
- Consolidating related information (like combining the hook bypass description for -n/--no-verify)
- Standardizing variable references throughout (e.g., changing "<file>" to "_<file>_")

The changes are purely presentational - no behavioral information is altered. The patch continues the series' high-quality approach with careful attention to detail, though some readers might want to see before/after examples of the improved readability in the commit message. The remaining patches will handle config file documentation and supporting file updates.
