This is a refactoring patch in the ongoing effort to standardize Git's help output behavior. Junio Hamano builds on previous work by Jeff King to convert more builtin commands to use the new `show_usage_help_and_exit_if_asked()` helper function, which ensures help text goes to stdout rather than stderr when explicitly requested with `-h`.

The patch updates 13 builtin commands (including `branch`, `commit`, `merge`, and `rebase`) that were previously using direct `usage_with_options()` calls with manual `-h` checks. The changes are mechanical replacements that maintain the same functionality while routing the output correctly. A test in t7600-merge.sh is also updated to expect stdout output rather than stderr.

This represents progress on one of the three identified conversion tracks in the help output effort (parse-options users), though the thread notes there are still deeper issues to address with direct `usage()` callers and `vreportf()`'s stderr assumption. The patch follows the maintainer-approved direction while revealing more of the technical debt in Git's output handling system.
