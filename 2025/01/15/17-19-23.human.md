This is a follow-up in the ongoing discussion about standardizing Git's help output behavior. Maintainer Junio Hamano responds to Kristoffer Haugsbakk's script that identified builtin commands outputting help text to stderr rather than stdout.

The email confirms the direction toward standardization, noting that commands using stderr for help output appear to be in the minority (40 out of 142 builtins). This observation supports the thread's emerging consensus to standardize on stdout for help text, as previously indicated by Hamano's stance and Jeff King's technical proposals.

The exchange shows the discussion moving from problem identification toward implementation, with Hamano using Haugsbakk's audit data to validate the feasibility of standardization. The tone suggests the maintainer is now satisfied there's sufficient evidence to proceed with unifying the behavior, though no specific implementation path is yet chosen.
