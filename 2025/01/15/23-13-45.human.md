This is a build system patch in the ongoing Rust bindings effort, specifically addressing symbol visibility and linking concerns for the `libgit-sys` FFI layer. Junio Hamano provides a maintainer review of Josh Steadmon's changes, focusing on portability and optionality considerations.

The review notes several technical points: the Makefile now assumes GNU binutils availability (acceptable for an optional feature), questions whether some cleanup targets should use `-r` flag, and observes that the symbol export mechanism is GCC/clang-specific but appropriately structured to allow opting out. The implementation introduces new object files and a library (`libgitpub.a`) to handle symbol visibility, with most components correctly made optional for platforms that can't support them.

Hamano's tone is generally positive but cautious about portability assumptions, suggesting future adjustments may be needed for non-GNU toolchains. The review doesn't block progress but flags areas where the implementation might need to become more flexible if Rust support expands beyond its current optional/experimental status. The changes appear well-contained within the `contrib/` area as intended for this experimental feature.
