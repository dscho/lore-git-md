This is part 4/5 in a series introducing Rust bindings for Git's C library, building on previous patches that established the low-level FFI layer (`libgit-sys`). The patch adds a higher-level `libgit` crate that provides more idiomatic Rust wrappers around the config API exposed in earlier patches.

The new crate follows Rust's common FFI pattern of pairing a `-sys` crate (which provides raw bindings) with a higher-level wrapper. Here it implements a `ConfigSet` type that manages memory safely (via `Drop`) and converts C strings and error codes into Rust-native types. The implementation includes basic config operations like `get_int()` and `get_string()`, plus tests demonstrating multi-file config loading with proper precedence handling.

The changes are well-contained to the `contrib/` directory and maintain Rust 1.63+ compatibility. The patch appears production-ready, with thorough test coverage of the config functionality. This continues the incremental approach seen throughout the series, focusing on making the bindings usable while deferring broader architectural questions (like symbol visibility management) to future work.
