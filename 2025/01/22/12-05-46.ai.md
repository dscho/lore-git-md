This is the third patch in Patrick Steinhardt's ongoing Meson build system conversion series (v3 03/11), focusing on version generation consistency. The patch addresses a cosmetic but potentially confusing issue where Meson could report stale version information during setup.

The core change modifies `meson.build` to dynamically populate the project version by executing `GIT-VERSION-GEN` during configuration, ensuring version consistency with the Makefile build system. The implementation handles Windows bootstrap constraints by falling back to 'unknown' when a shell isn't yet configured, as the version is purely informational. The solution leverages the `--format=` option added in patch 02/11 to extract just the version string.

Key technical details include:
- Uses Meson's `find_program()` and `run_command()` to execute `GIT-VERSION-GEN`
- Maintains the version format pattern `@GIT_VERSION@` established earlier
- Preserves the existing fallback behavior for Windows bootstrap scenarios
- Modifies only the project declaration in `meson.build`

This change completes the version handling modernization started in earlier patches, eliminating the last manual version specification in the Meson build while maintaining cross-platform compatibility. The approach demonstrates the series' characteristic balance between modernization and practical constraints, particularly the Windows bootstrap consideration.
