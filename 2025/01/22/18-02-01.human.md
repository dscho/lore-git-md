This is a bugfix for reflog migration of stash refs when switching between reference backends. The patch addresses an issue where stash reflogs weren't being properly migrated due to `core.logAllRefUpdates` configuration defaults. 

The fix is straightforward - adding the `REF_FORCE_CREATE_REFLOG` flag ensures reflog entries are created regardless of config settings. The patch includes a new test case that verifies stash reflog retention by creating two stash entries and confirming they remain after migration.
