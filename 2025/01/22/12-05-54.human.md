This is the final patch (11/11) in Patrick Steinhardt's series converting Git's build system to Meson, focusing on adding Visual Studio CI support. The patch wires up new GitHub Actions and GitLab CI jobs to build and test Git using Meson on Windows with Visual Studio.

Key aspects of the implementation include:
- The build job is mandatory while tests are manually triggered on GitLab (but not on GitHub due to platform limitations)
- Perl is disabled to avoid path format mismatches with Git for Windows' Perl
- Dependencies like curl and zlib are automatically handled by Meson rather than requiring the Git for Windows SDK
- Test slicing is manually implemented in PowerShell since Meson doesn't natively support it yet
- The implementation carefully minimizes prerequisites and skips test artifact processing for failed jobs

The patch completes the series' comprehensive Windows/MSVC support, following earlier work on C standard handling and CSPRNG configuration. All tests pass with this configuration. The changes are focused and well-explained, with clear rationale for each design decision and references to related work (like the Meson test slicing PR). This represents the culmination of a thorough, well-structured effort to bring full Meson support to Git's build system.
