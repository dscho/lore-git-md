This is the first patch in a refactoring series to centralize refspec handling logic. It moves three refspec-related functions (`omit_name_by_refspec`, `refspec_match`, and `match_name_with_pattern`) from `remote.c` to `refspec.c` as part of an effort to better organize code by concern. The changes are purely mechanical code relocation with no behavioral modifications - the functions are copied verbatim to their new location while being removed from the old one. 

The patch affects core refspec matching logic used by both fetch and push operations. `match_name_with_pattern` handles wildcard pattern matching for refspecs, while `omit_name_by_refspec` checks if a ref name matches any negative refspec. The movement includes adding declarations to `refspec.h` and removing them from `remote.h`. 

This initial patch focuses on the most straightforward cases where functions deal exclusively with refspec logic. The author notes this is part of separating refspec concerns from remote-specific logic, with more complex mixed cases to be addressed in future patches. The changes are clean with symmetric +56/-54 line changes across the four affected files.
