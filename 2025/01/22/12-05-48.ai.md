This patch adds development environment support to the Meson build system configuration. It's part of Patrick Steinhardt's ongoing Meson conversion series (v3, patch 05/11), following the version generation and build dependency fixes from earlier patches.

The change introduces Meson's development environment feature, which makes built artifacts available for testing and development. While Git doesn't expose linkable libraries, the patch leverages this mechanism to:
1. Add the build directory path to the `GIT_BUILD_DIR` environment variable
2. Prepend the `bin-wrappers` directory to `PATH` for easy access to built executables

This enables developers to use `meson devenv` to:
- Run test scripts directly against the built Git version
- Have the built Git executables available in their shell environment

The implementation is straightforward, adding just 8 lines to `meson.build` to configure the development environment. This continues the series' pattern of methodically adding Meson features while maintaining functional parity with the existing build system. The change appears well-contained and focused, with clear benefits for developer workflow without introducing complexity.
