CI/build system patch in the deprecation infrastructure series. This is the third of five patches preparing Git 3.0's breaking changes by adapting CI infrastructure.

Patrick Steinhardt repurposes the existing "linux-gcc" CI job to test upcoming breaking changes, renaming it to "linux-breaking-changes". The job now enables both the new default branch name ("main") and the `WITH_BREAKING_CHANGES` flag that will activate deprecation warnings for legacy "branches/" and "remotes/" references. Changes touch GitHub Actions, GitLab CI, and the test runner script.

This follows the series' pattern of infrastructure-first preparation, ensuring the deprecation machinery will be well-tested before activation. The modification is straightforward - a job rename plus one new environment variable - but strategically uses an existing test slot rather than adding new CI overhead. The patch maintains all existing test coverage while adding verification for the breaking changes path.
