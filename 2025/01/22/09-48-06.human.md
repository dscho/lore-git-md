This is a bugfix for the reflog migration functionality in Git's refs backend. Patrick Steinhardt addresses an issue where the stash's reflog wasn't being properly migrated between reference backends due to an interaction with the `core.logAllRefUpdates` configuration.

The problem occurs because the default `core.logAllRefUpdates` setting only creates reflogs for branches, remotes, notes, and HEAD - but not for stash. The fix adds the `REF_FORCE_CREATE_REFLOG` flag to ensure reflogs are migrated regardless of this configuration. The patch includes a new test case that verifies stash reflogs are properly preserved during migration.

The change is small (just one line in refs.c) but important for users migrating repositories between ref backends who want to preserve their stash history. The patch appears well-constructed with a clear commit message explaining the issue and a thorough new test case. It's based on maint for easy backporting.
