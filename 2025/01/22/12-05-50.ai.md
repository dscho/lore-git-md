This is patch 7/11 in Patrick Steinhardt's ongoing Meson build system conversion series, focusing on fuzzer support. The patch adds Meson integration for Git's existing fuzzers, which were previously only built via Makefile.

The implementation introduces a new Meson build option `fuzzers` (defaulting to false) that controls whether the fuzzer executables should be built. When enabled, it processes the existing fuzzer source files in `oss-fuzz/`, creating executables for each fuzzer target (commit-graph, config, credential parsing, etc.) while reusing the existing dummy main implementation. The patch also updates CI configuration to build fuzzers by default in Meson-based test jobs.

Key technical details:
- New `oss-fuzz/meson.build` file enumerates all fuzzer targets
- Each fuzzer links against `lib` and `common_main` dependencies
- CI now passes `-Dfuzzers=true` to Meson builds
- Maintains same fuzzer set as Makefile build
- Follows Meson pattern of optional feature flags

This continues the series' pattern of methodically porting each build system component while maintaining feature parity with the Makefile. The implementation is straightforward and appears well-integrated with the existing Meson infrastructure. No obvious technical concerns - this seems like a logical next step in the conversion process.
