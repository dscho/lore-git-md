This is a minor style nit in the test suite for the name hash version patch set. Taylor Blau points out that the test for out-of-order bitmap thresholds uses `export` to set `GIT_TEST_NAME_HASH_VERSION`, when the more conventional Git test suite style would be to use `env` for one-off environment variable settings. 

The observation comes as part of Taylor's thorough review of Derrick Stolee's series introducing configurable name hash algorithms for pack-objects delta compression. While this is a very small point that doesn't affect functionality, Taylor notes it in case the series needs to be rerolled for other reasons. The series as a whole appears to be in good shape, having gone through multiple rounds of review addressing the core technical approach to improving delta compression through better name hashing.
