This is a refactoring patch that's part of Patrick Steinhardt's v3 Meson build system conversion series (patch 1/11). It simplifies the version generation script by using `git describe --dirty` rather than manually checking for dirty state with separate `update-index` and `diff-index` commands.

The patch modernizes a legacy approach from 2008 when `--dirty` wasn't available in `git describe`. The new implementation is both simpler (5 lines removed) and faster, particularly benefiting Windows builds where the improvement is most noticeable (~800ms to ~400ms). Benchmark data shows a 1.43x speedup on Unix systems.

The change touches `GIT-VERSION-GEN`, which generates version strings during build. The new version maintains identical output format (still appending "-dirty" when appropriate) but does so through Git's built-in dirty tracking rather than manual checks. This aligns with the series' broader goal of modernizing build infrastructure while maintaining compatibility.

Key technical details for future reference:
- Uses `--dirty` flag with `git describe` instead of separate commands
- Preserves existing version string format (dashes converted to dots)
- Maintains same dirty state detection behavior
- Performance impact most significant on Windows
- Part of Meson build system conversion effort but touches version generation logic used by both build systems
