This is a bugfix for the reflog handling in the files backend, specifically addressing a regression introduced in Git 2.48.1 where symbolic reference updates would create corrupted reflog entries. The issue stems from an overzealous optimization in `lock_ref_for_update()` that skipped necessary processing for reflog-only updates, breaking the population of `old_oid` for symref reflogs.
