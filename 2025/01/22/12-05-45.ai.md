Build system modernization patch in Patrick Steinhardt's Meson conversion series (v3 02/11). This modifies `GIT-VERSION-GEN` to support Meson's build requirements by making two key changes to version string generation:

1. Adds a `--format=` option as an input alternative to reading from a file, allowing direct specification of the version string format without requiring an intermediate file. This is needed because Meson wants just the raw version number without additional formatting templates.

2. Makes the output file optional - when omitted, the version string is written to stdout instead. This enables Meson to capture the version directly during build configuration.

The changes maintain all existing functionality while adding flexibility. The implementation handles both traditional file-based usage and the new stdout mode through conditional logic that preserves the atomic-write behavior for file outputs. This is part of the broader effort to adapt Git's build infrastructure to work natively with Meson while maintaining compatibility with the existing Makefile system.

Key technical details:
- Modifies argument handling to accept 2-3 parameters instead of requiring exactly 3
- Adds new `--format=` parameter processing alongside existing file input
- Preserves all version substitution patterns (@GIT_VERSION@ etc.)
- Maintains atomic write behavior for file outputs via temp file+rename
- Keeps identical version string generation logic, just changing I/O methods

This patch follows the series' pattern of targeted, backward-compatible changes to support Meson integration. It addresses a specific pain point in version handling while being careful not to disrupt existing workflows. The changes are straightforward and well-contained to `GIT-VERSION-GEN`, with clear motivation explained in the commit message.
