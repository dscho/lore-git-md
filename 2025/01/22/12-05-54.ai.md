This is the final patch (11/11) in Patrick Steinhardt's Meson build system conversion series, focusing on Visual Studio CI integration. The patch adds Windows/MSVC build and test jobs to both GitHub Actions and GitLab CI for Meson-based builds, completing the platform coverage for the new build system.

Key technical aspects:
- Adds mandatory build job and optional test job (manual in GitLab due to resource constraints)
- Disables Perl support to avoid path format mismatches with Git for Windows
- Uses minimal dependencies (only VS, Meson, Git for Windows - other deps built by Meson)
- Implements custom test slicing logic in PowerShell since Meson lacks native support
- Skips test artifact processing to minimize prerequisites
- GitHub Actions implementation includes parallel test execution across 10 slices
- GitLab CI handles certificate store issues via manual certificate import
- Both CI systems share the core build/test logic while adapting to platform constraints

The patch demonstrates careful consideration of CI resource usage while ensuring test coverage. It builds on previous work in the series (particularly the Visual Studio C standard handling from 9/11) and represents the final piece of cross-platform validation for the Meson conversion. The implementation shows attention to platform-specific quirks (Perl paths, certificate stores) while maintaining the series' pattern of mirroring existing build system capabilities in Meson.
