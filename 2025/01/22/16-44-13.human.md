This is a bug report regarding a regression in the reftable backend. Karthik Nayak reports that Junio Hamano's recent merge of the `kn/reflog-migration-fix` branch to 'next' is causing test failures on macOS when using the reftable backend, though the issue wasn't caught by CI or in local files-backend testing.

The problem was discovered when Derrick Stolee (CC'd) observed macOS build failures in his own work, which Karthik bisected to this change. The original commit fixed a bug in `git refs migrate` for reflog data by correcting the `max_update_index` header writing in reftable, but appears to have introduced a new issue in the reftable implementation.

Karthik notes this needs to be reverted from 'next' while he works to understand both why the tests are failing and why CI didn't catch the regression. The report suggests this is a potentially serious issue affecting reftable users, though the exact nature of the bug isn't yet clear from the email.
