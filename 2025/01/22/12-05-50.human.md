This is part of Patrick Steinhardt's ongoing Meson build system conversion series (v3), specifically patch 7/11. The patch adds support for building Git's fuzzers under Meson, which was previously missing.

The changes introduce a new Meson build option `-Dfuzzers=true` that enables compilation of the existing fuzz targets (commit-graph, config, credential parsing, etc.). The implementation follows the pattern seen elsewhere in the series - it wires up the existing fuzz infrastructure to Meson while maintaining the same functionality. The patch also updates CI configuration to build fuzzers by default in Meson-based test runs.

The implementation looks straightforward and well-contained, adding about 30 lines of build system code across 4 files. It follows the series' established pattern of methodically converting each build system component while maintaining feature parity with the Makefile-based build. The patch appears to be a natural progression in the Meson conversion effort, addressing another discrete piece of the build system.
