This is a refactoring patch that's part of Patrick Steinhardt's v3 series modernizing Git's build system to use Meson. The patch simplifies how Git detects dirty working trees when generating version strings.

The change replaces a manual dirty-check implementation (using `git diff-index`) with Git's built-in `--dirty` flag for `git describe`. This is both cleaner and faster, particularly on Windows where the speedup is significant (from ~800ms to ~400ms). The commit explains this was originally implemented before `--dirty` existed in Git.

While this is a small change, it's a good example of the series' attention to detail - finding modern, cleaner solutions while maintaining compatibility. The benchmark results show thoughtful consideration of both Unix and Windows performance impacts. As the first patch in the series, it sets the tone for the thorough technical work that follows in the Meson conversion effort.
