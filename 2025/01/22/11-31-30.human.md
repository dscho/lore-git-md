CI/build system cleanup as part of the reference deprecation effort.

This patch (2/5 in the v4 series) simplifies Git's CI configuration by merging the redundant "linux-gcc-default" job into the standard "linux-gcc" job. The author, Patrick Steinhardt, argues the separate job adds little value since: (1) explicit GCC version testing is covered elsewhere, (2) Python 2 testing is no longer relevant, (3) branch name defaults are inconsistently tested anyway, and (4) Ubuntu version coverage exists in other jobs.

The changes remove the job definition across GitHub Actions and GitLab CI configurations while cleaning up related conditionals in the test infrastructure. This appears to be straightforward CI maintenance with no functional impact, aligning with the series' broader goal of streamlining infrastructure ahead of the reference deprecation changes. The patch follows the series' pattern of preparatory work before introducing breaking changes themselves.
