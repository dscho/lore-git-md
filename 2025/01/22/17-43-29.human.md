This is a clarification about Git version discrepancies between upstream releases and platform-specific packaging.

Junio Hamano responds to Michael Cheel's question about the mismatch between Git's main version (2.48.1) and the Windows download page (still showing 2.47.1(2)). He confirms that 2.48.1 is indeed the current official source release, explaining that platform-specific distributions like Git for Windows sometimes lag behind the main releases. 

The response notes that while the Windows binary for 2.47.1 was released on January 14, the 2.48.1-based Windows version hasn't been published yet. Hamano points to the mailing list archives where Git for Windows maintainer Johannes Schindelin typically posts release announcements, suggesting this is the normal release cadence rather than a website update issue.

This is a straightforward explanation of Git's release coordination process, reassuring users that version mismatches between platforms are expected during the release propagation period. The response doesn't indicate any problems with the release process itself.
