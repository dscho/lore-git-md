This is a response in the ongoing thread about Git version discrepancies between the main release and Windows packaging. Junio Hamano clarifies that the version mismatch is expected - the main Git project released v2.48.1 on January 13, while the Windows port (maintained separately) is still at v2.47.1(2) as of January 14. He notes this is normal platform-specific packaging lag, and suggests checking the mailing list archives for announcements from the Windows maintainer (Schindelin) to track when the Windows port catches up. The response confirms this is a temporary synchronization issue rather than a website error, and implies users should expect some delay between upstream releases and Windows binary availability. No action is proposed - this is purely an informational response about release timing differences.
