This is a CI/build system patch in Patrick Steinhardt's ongoing Meson conversion series (now at 10/11). It makes Meson warnings fatal in CI builds to catch potential issues early.

The patch adds `--fatal-meson-warnings` to the Meson setup command in the CI script, ensuring build warnings (like those about features not supported by Git's minimum Meson version) will fail the build rather than just being logged. This matches the existing `--werror` flag that makes compiler warnings fatal.

The change is straightforward - a one-line addition to the CI script - but serves an important quality control purpose. As the series nears completion (just one patch remains), this helps maintain build hygiene by treating Meson configuration warnings with the same seriousness as compiler warnings. The patch follows the series' pattern of methodically improving the build system while maintaining compatibility.
