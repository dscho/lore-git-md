Platform compatibility patch addressing Visual Studio C standard requirements in the Meson build system.

This patch fixes compilation issues when building Git with Visual Studio, which defaults to C89 unless explicitly configured otherwise. The core problem stems from VS's incomplete C99 support - while Git requires GNU C99 features, VS only properly defines `__STDC_VERSION__` when using C11. The solution introduces a version-aware fallback in meson.build: for Meson 1.3.0+ it tries GNU C99 first then falls back to C11, while older Meson versions require GNU C99 unconditionally (making Windows builds effectively require Meson 1.3.0+ with VS).

The change mirrors Git's CMake build configuration and maintains compatibility with Git's documented C99 requirement while pragmatically working around VS's limitations. The patch includes a clear explanation of the version-specific behavior and rationale, with testing confirmation from another contributor. This continues the series' pattern of careful platform-specific handling while maintaining broader compatibility requirements.
