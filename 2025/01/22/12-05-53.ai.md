This is a CI/build system patch in Patrick Steinhardt's ongoing Meson conversion series (10/11). It makes Meson warnings fatal in CI builds to catch potential issues early.

The patch adds `--fatal-meson-warnings` to the CI configuration, ensuring build failures when Meson emits warnings about unsupported features or other potential problems. This is particularly important for catching cases where features work with the current Meson version but not the minimum required version specified in the project. The change mirrors the existing `--werror` flag that makes compiler warnings fatal.

The implementation is straightforward - a single line addition to `ci/run-build-and-tests.sh` that passes the new flag during Meson setup. This continues the series' pattern of hardening the build system while maintaining consistency with existing practices. The change affects all Meson-based CI jobs but doesn't modify build behavior for non-CI contexts.
