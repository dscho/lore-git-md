Build system modernization: This patch from Patrick Steinhardt's Meson conversion series (now at 8/11) makes the cryptographic secure pseudo-random number generator (CSPRNG) backend configurable in the Meson build system. The change follows the series' pattern of bringing feature parity with the Makefile while adding more flexibility.

The patch adds a new `csprng_backend` option that lets users explicitly choose between several implementations (arc4random, getrandom, OpenSSL, etc.) or let the system auto-detect the best available. The backend selection logic is reworked to respect this choice while maintaining the existing preference order for security and performance. The chosen backend is now also displayed in the build summary output.

This continues the series' thorough approach to build system modernization, with careful attention to platform compatibility (including Windows support via RtlGenRandom) and proper dependency handling (now correctly tracking when OpenSSL is needed for CSPRNG). The implementation looks clean and maintains the project's security standards while making the build more transparent and configurable.
