This is a status update on the `ds/name-hash-tweaks` series introducing name hash version 3 for improved delta compression. The thread shows the technical implementation has been reviewed and approved by both Derrick Stolee and Junio Hamano, with Junio expressing satisfaction with the new hash function's balanced performance characteristics - it improves compression while maintaining good behavior for renamed files and deep directory structures.

Taylor Blau indicates he has thoughts to share about whether to enable version 3 by default but hasn't had time due to the holiday break. Junio responds with a reasonable deadline (this weekend) for Taylor's input before moving forward, while expressing some mild reservations about framing the change as a "version" rather than a "variant" since there may be cases where the older algorithm is preferable.

The series remains technically sound but blocked on this final decision about default behavior. Key files affected include pack-objects.c, builtin/repack.c, and the new test infrastructure in t/helper/test-name-hash.c. The implementation adds `--name-hash-version` options to both `pack-objects` and `repack` commands while preventing unintended hash version changes during repacking.
