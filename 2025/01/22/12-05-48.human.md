This is a build system patch in Patrick Steinhardt's ongoing Meson conversion series (05/11). It adds developer convenience features to the Meson build system by wiring up development environments.

The patch enables `meson devenv` functionality, which automatically sets up two useful things for developers: it adds the built Git executables to PATH (via bin-wrappers) and exposes the build directory via GIT_BUILD_DIR. This makes it easier to test the freshly-built Git version directly, including running test scripts against it.

The change is small (8 lines added to meson.build) but provides a quality-of-life improvement for developers working with the Meson build. It follows the series' pattern of methodically adding features while maintaining compatibility with the existing Makefile-based build. The implementation looks straightforward and aligns with Meson's standard practices for development environments.

This continues the series' focus on both technical correctness and developer experience, though it's a more minor quality-of-life addition compared to the parallel build fixes in the previous patch.
