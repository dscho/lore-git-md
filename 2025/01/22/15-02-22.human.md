Bugfix follow-up for reflog corruption in symref updates. Jeff King provides minor test improvements for Karthik Nayak's fix addressing a regression in `git update-ref`'s reflog handling. The original patch removed an incorrect optimization that skipped `old_oid` population for symref reflogs, introduced in Git 2.48.1.

King suggests two test refinements: using `git symbolic-ref` to get the branch name rather than hardcoding "main", and simplifying the test setup by avoiding a new repository. He also notes the `>>` redirection in the test is unnecessarily cautious since we're in a fresh repo context.

This email represents final polish on a fix that has already been reviewed and confirmed working by multiple contributors. The changes are minor but improve the test's robustness and clarity. With these tweaks, the patch appears ready for inclusion, addressing a subtle but important reflog integrity issue affecting symbolic reference updates.
