This is a v3 patch series continuing Patrick Steinhardt's Meson build system conversion effort, focusing on finalizing several technical components and improving test coverage. The series builds on previous work to modernize Git's build infrastructure while maintaining compatibility and reliability.

The key updates in this version include a revamped approach to distribution tarball generation that avoids modifying GIT-VERSION-GEN, fixing Visual Studio compilation issues, and expanding CI coverage to include Meson builds with Visual Studio and fuzzers. The series also introduces stricter CI checks that will fail builds on Meson warnings, helping catch potential issues early.

Technical highlights include:
- Improved version string handling through GIT-VERSION-GEN integration
- Proper dependency tracking for generated headers
- Configurable CSPRNG backend support
- Distribution archive generation now uses Meson's native `add_dist_script` rather than environment variable hacks
- CI now builds with both GCC/clang and Visual Studio toolchains
- Fuzzer builds are now properly wired into the Meson system

The series shows continued refinement of the Meson integration, with each iteration addressing feedback and edge cases. The distribution tarball generation change in particular demonstrates the project's commitment to finding clean solutions that work within Meson's constraints while maintaining Git's reliability standards. With these changes, the Meson build system coverage approaches feature parity with the traditional Makefile-based build.
