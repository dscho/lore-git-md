Taylor Blau provides a review response to Derrick Stolee's v3 patch series introducing alternative name hash algorithms for pack-objects delta compression. This is primarily a decision point about whether to include the experimental version 3 hash algorithm alongside version 2.

Blau acknowledges the series has been stable for a while and agrees the versioned name-hash approach is sound, particularly noting it will facilitate future .bitmap changes. While he found mostly cosmetic issues in his review, his key technical assessment is that version 2 (Jonathan Tan's improved path-component hash) provides clear improvements over version 1 (current behavior) with fewer tradeoffs than version 3 (full-name-hash).

He strongly recommends dropping version 3 entirely to reduce maintenance burden and avoid presenting users with unclear choices between algorithms. While open to reconsidering if Stolee feels strongly, Blau's position is that version 2 alone provides sufficient benefit - improving delta compression in most cases while keeping the interface simple. The review indicates technical approval of the core approach while suggesting this final simplification before merging.
