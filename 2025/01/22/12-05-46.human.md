This is part 3 of Patrick Steinhardt's ongoing series to modernize Git's build system with Meson integration, specifically addressing version number handling. The patch ensures Meson builds display the correct Git version by dynamically generating it from `GIT-VERSION-GEN` rather than hardcoding a potentially stale version.

The key change is that Meson now runs `GIT-VERSION-GEN` during configuration to get the accurate version string, falling back to "unknown" if the shell isn't available (particularly relevant for Windows systems where shell setup happens later). This solves the cosmetic issue where Meson builds would incorrectly report old version numbers while maintaining compatibility across platforms.

The implementation is clean and well-justified, with Patrick having considered several alternatives before settling on this approach that balances accuracy with platform compatibility. As noted in the thread context, this continues the series' pattern of careful modernization while preserving existing functionality. The change is low-risk since the version string is only used for display purposes.
