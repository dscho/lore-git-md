This is a build system patch in Patrick Steinhardt's ongoing Meson conversion series (v3, patch 04/11). It fixes a parallel build issue where certain generated headers ("config-list.h" and "hook-list.h") were incorrectly listed as library dependencies when they're actually used by builtin commands. This could cause build failures when builtins tried to compile before their required headers were generated.

The change moves these header generation targets from the `libgit_sources` list to `builtin_sources`, while keeping "command-list.h" (used by library code) in the library sources. The fix addresses a real issue reported by Evan Martin and demonstrates the kind of subtle build system details that need careful handling during the Meson transition.

This is a straightforward technical correction that maintains the series' high quality standard. It doesn't introduce new functionality but ensures reliable builds, particularly important for the parallel builds that Meson enables by default. The patch is small (9 lines changed) and focused, with a clear explanation of both the problem and solution.
