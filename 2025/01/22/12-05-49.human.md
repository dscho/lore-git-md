This is part of Patrick Steinhardt's ongoing Meson build system conversion (v3), specifically patch 06/11 which handles distribution archive generation. The patch wires up `meson dist` to properly include Git version information in generated tarballs, maintaining parity with the existing Makefile-based build system.

The key addition is a distribution script that uses `GIT-VERSION-GEN` to populate the version file in the generated archive. This ensures the version metadata matches the commit being built from, which was previously missing in Meson builds. The implementation handles the build directory vs. distribution directory path resolution by using the `MESON_DIST_ROOT` environment variable.

This continues the series' pattern of methodically matching Makefile feature-for-feature while adapting to Meson's conventions. The change is straightforward but important for ensuring generated tarballs contain proper version information. As with previous patches in the series, this maintains backward compatibility while modernizing the build infrastructure.
