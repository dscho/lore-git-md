This is a build system patch in Patrick Steinhardt's ongoing Meson conversion series (v3 04/11), addressing header generation dependencies. The patch fixes parallel build issues by correctly assigning generated headers to their consumers - moving "config-list.h" and "hook-list.h" from libgit sources to builtin sources since they're only used by builtins, while keeping "command-list.h" in libgit where it belongs (used by "help.c"). 

The change resolves a reported race condition where builtin compilation could attempt to use headers before they were generated. The solution maintains the same generation logic but reorganizes the build graph dependencies. This continues the series' pattern of methodical build system modernization while preserving existing functionality, with the fix being straightforward and well-explained in the commit message.

Key technical details for future reference:
- Affects three generated headers from documentation: command-list.h, config-list.h, hook-list.h
- Changes assignment between libgit_sources and builtin_sources arrays in meson.build
- Keeps identical generation commands, just moves their output targets
- Fixes parallel build races reported by Evan Martin
- Part of broader Meson build system conversion effort (patch 4/11 in current series)
