Bugfix for reflog migration respecting core.logAllRefUpdates. This patch addresses an issue where stash reflogs weren't being properly migrated between reference backends due to the default behavior of `core.logAllRefUpdates`.

The problem stems from commit 246cebe320 which added reflog migration support, but didn't account for the fact that `core.logAllRefUpdates` by default only creates reflogs for branches, remotes, note refs and HEAD - excluding stash refs. The fix adds the `REF_FORCE_CREATE_REFLOG` flag to ensure reflog entries are created regardless of the config.

The patch includes a new test case in t/t1460-refs-migrate.sh that verifies stash reflogs are properly retained during migration. The test creates two stash entries, migrates the repository, and confirms the stash list remains unchanged. The change is minimal (just one line in refs.c) but effectively solves the reported issue.

This appears to be a straightforward and well-justified fix for a clear bug, with appropriate test coverage. The patch is based on maint for easy backporting, suggesting it's considered an important fix.
