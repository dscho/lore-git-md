This is the final patch in a performance optimization series adding zlib-ng support to Git. The patch adds CI test coverage for the new zlib-ng backend by installing zlib-ng-dev in Alpine Linux's CI job, where Meson will automatically detect and use it. 

The patch explains the limited options for testing zlib-ng - Debian and Fedora-based distros either don't package zlib-ng or don't run tests, making Alpine Linux the only viable choice currently. The change is minimal, just adding zlib-ng-dev to the package list in ci/install-dependencies.sh.

This completes the series that has shown ~25% speedup in object reading operations when using zlib-ng's optimized implementations. All technical issues have been resolved through previous patches, and this final piece ensures the new backend gets proper test coverage.
