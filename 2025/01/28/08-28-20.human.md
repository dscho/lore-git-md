This is the 19th patch in Patrick Steinhardt's 20-part series decoupling the reftable library from Git's core infrastructure. The patch completes the separation by removing the final dependency on `git-compat-util.h` in favor of the new `compat/posix.h` header created in the previous patch.

The change is straightforward but significant - it swaps out the Git-specific compatibility header for the new portable POSIX header in the reftable system files. This leaves only `system.h` and `system.c` as Git-specific components that downstream users (like libgit2) would need to provide their own implementations for.

The patch maintains the series' high quality with a well-explained commit message and minimal, focused changes. It represents the penultimate step in making reftable truly standalone, following through on the architectural work done in previous patches to isolate POSIX functionality. The diff shows the simple header swap and reveals that some Git-specific compatibility code remains needed in `system.c` (via `git-compat-util.h`), which will presumably be addressed in the final patch of the series.
