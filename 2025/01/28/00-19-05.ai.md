This is the final patch in the Rust bindings series (v7 4/4), introducing the higher-level `libgit` crate that provides idiomatic Rust wrappers around the FFI bindings from `libgit-sys`. The patch completes the Rust infrastructure work that has been reviewed and refined across multiple iterations.

The `libgit` crate follows Rust's common FFI pattern of pairing a low-level `-sys` crate with a higher-level wrapper. This patch implements initial Rust-friendly interfaces for config handling, building on the config API bindings from patch 3/4. Key components include:

- A `ConfigSet` struct that wraps the C `config_set` with proper Rust memory management (RAII via `Drop` implementation)
- Methods for loading config files and querying values (`get_int`, `get_string`) with proper error handling
- Test coverage demonstrating config file loading and value retrieval
- Build system integration (Makefile and Cargo) mirroring the `libgit-sys` setup
- Documentation (README) explaining the crate's purpose and version requirements

The implementation shows attention to Rust idioms while maintaining safety when crossing the FFI boundary. Notable technical details include:

- Careful handling of C string conversions and memory management (freeing xstrdup'd pointers)
- Feature detection for `std::ffi` types via build.rs
- Test data demonstrating config precedence rules
- Coherent error handling (None for missing keys, panics for invalid data)

This represents the culmination of the series' technical work, providing the foundation for future Rust tools to build upon. With maintainer approvals already secured for earlier patches and all major technical concerns addressed, this final piece completes the Rust infrastructure while keeping the implementation contained to contrib/.
