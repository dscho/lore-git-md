This is a feature patch series introducing Rust bindings for Git's C library, now in its 7th revision. The series provides two Rust crates (`libgit-sys` and `libgit`) that wrap parts of libgit.a, with the higher-level `libgit` crate offering a more Rust-friendly interface. The work remains contained to `contrib/` without impacting core Git functionality.

Key technical details for future reference:
- Build system integration is complete with meson/Makefile parity
- Uses static library approach with symbol visibility management
- `libgit-sys` provides raw FFI bindings while `libgit` adds Rust abstractions
- ConfigSet API is the main functionality exposed (alloc/free, file loading, int/string access)
- Tested with JJ project as proof-of-concept
- Build controlled by `INCLUDE_LIBGIT_RS` Makefile variable
- Files touched: Makefile, meson.build, new Rust crates in contrib/
- Known future work: symbol visibility/versioning improvements

The series has undergone extensive review with all major technical concerns addressed. Changes in v7 focus on final refinements: module organization, documentation, build system fixes, and API cleanup (removing public FFI type exports). The implementation appears solid with thorough test coverage and has maintainer approval, making it likely to be merged soon.
