This is the final patch in Patrick Steinhardt's 20-part series to decouple the reftable library from Git's core infrastructure. The patch makes a small but meaningful build system adjustment: it excludes reftable sources from Coccinelle semantic patching.

The change is straightforward - the Makefile now skips reftable files when running Coccinelle checks. The rationale is sound: since the reftable library has been carefully separated from Git's core helpers (as shown in previous patches), Coccinelle rules designed for Git-specific patterns could generate false positives when applied to reftable code.

This is a clean, logical conclusion to the series. The one-line change reflects the architectural separation achieved by the prior 19/20 patches - reftable now stands on its own POSIX-compatible foundation rather than relying on Git's infrastructure. The patch maintains the series' careful, incremental approach while addressing a practical build system consideration that follows naturally from the larger refactoring work.
