This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. 

The patch replaces Git's `SWAP()` macro with a reftable-specific `REFTABLE_SWAP()` implementation. The new version maintains the same functionality but removes the dependency on Git's compatibility utilities. The implementation includes an open-coded memory swap operation with buffer handling, along with the necessary size checking that was previously handled by `SWAP()`'s built-in assertions.

Changes are straightforward mechanical replacements across four files in the reftable codebase: basics.h (where the new macro is defined), merged.c, pq.c, and record.c. The patch continues the series' pattern of carefully extracting reftable functionality from Git's core while maintaining identical behavior.

This is a typical incremental step in the larger architectural effort - not particularly controversial but important for the long-term goal of making reftable fully portable. The implementation looks solid, with the macro carefully preserving the original swap behavior while eliminating the Git-specific dependency.
