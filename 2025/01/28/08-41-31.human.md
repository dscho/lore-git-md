This is a refactoring patch in the zlib-ng performance optimization series, moving a compatibility shim for older zlib versions into a central location.

The patch relocates the `deflateBound()` compatibility shim from `git-zlib.c` to `compat/zlib-compat.h`. This function, which calculates the maximum compressed size needed for a given input, was introduced in zlib 1.2.0. The shim provides equivalent functionality for older zlib versions.

This change is part of the larger effort to support zlib-ng as an alternative backend, where centralizing these compatibility definitions makes it easier to maintain consistent behavior across different zlib implementations. The patch is straightforward - it simply moves existing code with no functional changes - and follows naturally from the header reorganization work done in earlier patches of the series.

The change is well-contained and uncontroversial, with the commit message clearly explaining the motivation. This appears to be a routine piece of the larger zlib-ng integration work that has already undergone multiple rounds of review.
