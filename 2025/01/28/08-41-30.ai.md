This is part 4/10 of the performance optimization series introducing zlib-ng support, focusing on header reorganization. The patch moves zlib-related includes from the broad `git-compat-util.h` to the more specific `git-zlib.h`, reducing unnecessary inclusions while maintaining functionality. 

The key changes include:
1. Moving the `compat/zlib-compat.h` include from `git-compat-util.h` to `git-zlib.h`
2. Adding `git-zlib.h` includes to files that need zlib functionality (archive.c, config.c, etc.)
3. Special handling for reftable to maintain library independence by including zlib via `reftable/system.h` instead

This is a straightforward refactoring that improves header hygiene by reducing the scope of zlib inclusion while ensuring all necessary files still have access to zlib functionality. The reftable changes maintain the library's independence from Git-specific wrappers. The patch follows logically from the previous header reorganization work in the series and helps pave the way for the zlib-ng integration by keeping zlib-related code properly scoped.
