This is part of the ongoing reftable library refactoring to remove Git-specific code and make it portable for standalone use. Patch 8/20 in the series replaces Git's `st_mult()` overflow-checked multiplication with a reftable-specific implementation that returns errors rather than dying.

The change affects array allocation macros (`REFTABLE_ALLOC_ARRAY`, `REFTABLE_REALLOC_ARRAY`) and the `reftable_alloc_grow` helper. The new version introduces a `reftable_alloc_size` function that checks for overflow and returns an error code, setting `errno` to `ENOMEM` on failure. This maintains the library's error-handling approach while removing Git dependencies.
