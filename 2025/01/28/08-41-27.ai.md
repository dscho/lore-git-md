This is a cleanup patch removing obsolete compatibility code, part of a larger series (1/10). It removes the `uncompress2()` compatibility shim that was previously needed when linking against older versions of zlib (<1.2.9). The patch notes this function is no longer needed since its last use was removed in commit 15a60b747e (reftable/block: open-code call to `uncompress2()`, 2024-04-08).

The changes remove the implementation file, its Makefile entry, the meson.build reference, and the header declaration. The implementation was originally copied from zlib 1.2.11 to provide the function when the system zlib was too old. The patch is straightforward removal of dead code with no behavior changes.

Key technical details for future reference:
- Removed files: `compat/zlib-uncompress2.c`
- Removed declarations: `uncompress2()` prototype in `git-compat-util.h`
- Build system updates: Makefile and meson.build
- Last user removed in commit 15a60b747e (reftable)
- Original code came from zlib 1.2.11 (2017)
