This is part of the ongoing Rust bindings development for Git's C library (v7 2/4). The patch introduces `libgit-sys`, a foundational Rust crate that provides FFI bindings to `libgit.a`. It establishes the build infrastructure and demonstrates the approach with initial bindings for user agent string functions.

Key technical aspects:
- Build system integration via `Makefile` and `Cargo.toml` with `INCLUDE_LIBGIT_RS` flag
- Symbol visibility management through `public_symbol_export.[ch]` (prefixing with `libgit_` and visibility pragmas)
- Testable via `cargo test` with basic validation of user agent strings
- Dependency management with `Cargo.lock` (temporarily version-controlled)
- Build process creates `libgitpub.a` combining `libgit.a` and other dependencies

The implementation handles symbol collision risks with other libraries (notably libgit2) through careful symbol renaming and visibility control. The patch includes comprehensive build rules and test integration while keeping the actual FFI surface minimal in this initial version (just user agent functions). This serves as the low-level foundation for the higher-level `libgit` crate to be introduced in later patches.
