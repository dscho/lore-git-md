Performance optimization patch introducing a new zlib compatibility layer as part of the zlib-ng integration series. This is the third patch in a 10-part series that aims to provide Git with faster zlib compression by optionally using the optimized zlib-ng backend.

The patch creates a new `compat/zlib-compat.h` header that serves as an indirection layer for zlib includes, replacing direct `#include <zlib.h>` statements in the codebase. This change is foundational for the subsequent zlib-ng support, as it allows the project to transparently switch between standard zlib and zlib-ng implementations. The header is carefully named `zlib-compat.h` rather than just `zlib.h` to avoid potential include path issues.

The changes are minimal but strategic - updating includes in `git-compat-util.h` and `reftable/block.c` to use the new compatibility header. This appears to be a well-considered step in the larger performance optimization effort, maintaining clean separation of concerns while preparing for the zlib-ng integration that follows in later patches. The patch follows the series' established pattern of careful header reorganization to support the alternative backend.
