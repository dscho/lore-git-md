Feature implementation in the Rust bindings for Git's C library (part of the ongoing Rust integration effort). This is patch 2/4 in the v7 series, focusing on the `libgit-sys` crate that provides FFI bindings to `libgit.a`.

Phillip Wood provides review feedback on Josh Steadmon's patch introducing the Rust wrapper crate. The patch establishes the basic infrastructure for Rust bindings, including build rules and initial FFI exposure of Git's user agent string functions. Phillip notes the implementation is looking good overall but offers two specific suggestions: (1) breaking up long Makefile lines by using variables for source lists, and (2) correcting the style of a multiline comment to match Git's conventions (starting with `/*` on its own line).

The patch itself shows the careful design work to avoid symbol collisions (prefixing with `libgit_`) and includes test cases verifying the user agent string functionality. This represents foundational work for future Rust tools to safely interface with Git's core functionality, with the current focus being on build system integration and basic FFI proof-of-concept. Phillip's feedback indicates the patch is nearing readiness, needing only minor style adjustments.
