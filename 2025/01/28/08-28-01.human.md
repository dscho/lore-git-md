This is the cover letter for a major refactoring series that completes the decoupling of the reftable library from Git's core infrastructure. The 20-patch series represents the final step in making reftable a standalone library that can be used by other projects like libgit2 without requiring Git's codebase.

The key change in this version is the complete removal of dependencies on `git-compat-util.h`, replacing Git-specific helpers with POSIX equivalents and reftable-specific implementations. The series systematically replaces Git utilities like `read_in_full()`, `write_in_full()`, and `xmmap()` with direct POSIX operations, converts Git's `BUG()` calls to proper error handling, and introduces reftable-specific versions of utilities like memory allocation and endian conversion.

Notable improvements in v2 include fixing compilation issues with Windows headers, adding explanations for design decisions (like omitting `EWOULDBLOCK` handling), and fixing commit message typos. The series also reorganizes compatibility headers, splitting POSIX-related functionality into a new `compat/posix.h` while maintaining platform support.

This appears to be a well-considered and thorough refactoring that addresses previous feedback about code duplication and maintenance concerns. The changes are consistently focused on the goal of making reftable truly standalone while preserving functionality. The series touches many files (67 modified) but follows a clear architectural direction, with each patch handling a specific aspect of the decoupling.
