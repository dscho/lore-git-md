This is part of the Rust bindings implementation, specifically expanding the FFI layer to expose Git's config API. As the third patch in the final v8 series, it builds on the foundational work to enable Rust tools to safely interact with Git's configuration system.

The patch adds config_set functionality to the `libgit-sys` crate, exposing key operations like reading config files, getting integer/string values, and memory management through `alloc`/`free` functions. The implementation wraps Git's native config API in a new `libgit_config_set` struct to maintain type safety and proper memory handling. While this patch focuses on the low-level FFI bindings, the commit message notes these will be used by higher-level Rust APIs in subsequent work.

The changes follow the established pattern of prefixing symbols with `libgit_` to avoid collisions, and include both C and header file updates to expose the new functionality. Since this is part of a well-reviewed series that has already addressed technical concerns about build integration and safety, it represents a straightforward expansion of the binding surface rather than introducing new architectural decisions. The patch carries co-authorship from Calvin Wan, indicating collaborative development on this component.
