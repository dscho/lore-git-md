Bugfix for filter-repo's config parsing. This patch addresses a crash that occurs when processing multi-line configuration values in git-filter-repo. The issue stems from the tool's current approach of parsing `git config --list` output without handling newlines in values properly.

The fix is straightforward: switch to using `git config --null` which is specifically designed to handle such cases by using null terminators. Toke Høiland-Jørgensen includes a simple test case that reproduces the crash before the fix. 

The email notes this isn't an isolated issue - there are reportedly two other GitHub PRs attempting to fix the same problem, suggesting it's affecting multiple users. The patch appears well-scoped and directly addresses the problem with a standard Git solution. The tone suggests this is a long-standing issue that would benefit from being merged.
