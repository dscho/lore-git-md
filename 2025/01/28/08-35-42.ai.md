This is a performance optimization patch in the zlib-ng series, specifically addressing compatibility stubs for older zlib versions. The patch adds no-op implementations of `deflateSetHeader()` and `gz_header_s` for zlib versions prior to 1.2.2.1, where these were not available. 

Justin Tobler had suggested adding explanatory comments about the no-op behavior, which Patrick Steinhardt agrees would be helpful since the silent skipping of this functionality isn't immediately obvious. The stubs are part of the broader zlib abstraction layer that enables switching between standard zlib and zlib-ng backends while maintaining compatibility across versions.

The implementation follows the pattern already established in this series for handling version-dependent zlib features, similar to how `deflateBound()` was previously handled. The stubs return Z_OK while ignoring their parameters, allowing code written for newer zlib versions to work unchanged on older versions, though without the header-setting functionality.

This is one of the final refinements in the now-complete zlib-ng optimization series, with all substantive technical issues already resolved and reviewed. The change maintains the series' goal of transparent compatibility while enabling the zlib-ng backend's performance benefits.
