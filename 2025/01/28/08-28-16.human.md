This is a platform compatibility patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. The patch standardizes how header files are included in the `compat/` directory across different platforms.

Currently, header includes in `compat/` are inconsistent - some use relative paths from the current file, some from the project root, and Windows has platform-specific include paths. This patch makes all includes consistently relative to the project root, removing the Windows-specific `-Icompat` flag. The change affects 39 files with mostly mechanical updates to include paths.

The motivation is to make it clearer where includes come from and to prepare for future splitting of Windows-specific headers (`mingw.h` and `msvc.h`). While this is largely a cleanup, it's part of the broader effort to make the reftable codebase more portable and self-contained. The patch follows the series' pattern of methodically replacing Git-specific conventions with portable alternatives.
