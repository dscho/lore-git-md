Feature implementation completing the Rust bindings series. This is the final patch (4/4) in v8 of the series, adding the higher-level `libgit` Rust crate that provides idiomatic wrappers around the FFI bindings from `libgit-sys`. The patch introduces a `ConfigSet` type that safely wraps Git's config API with Rust-native error handling and memory management (via RAII). It demonstrates the pattern with methods like `get_int()` and `get_string()` that properly convert C types to Rust types while handling errors and memory allocation.

The implementation follows Rust best practices for FFI by separating the low-level bindings (`libgit-sys`) from the high-level interface (`libgit`). The crate includes tests verifying config precedence rules and proper handling of missing keys. Build system changes integrate the new crate alongside `libgit-sys`, with both now built when `INCLUDE_LIBGIT_RS` is set.

This completes the foundational work for Rust bindings to Git's C library, providing a model for future API additions. The series has already been reviewed and approved, with this final patch adding the user-friendly Rust layer on top of the carefully designed FFI infrastructure from earlier patches.
