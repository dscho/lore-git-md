This is the final patch in a 7-part series implementing Rust bindings for Git's C library. The patch adds the higher-level `libgit` Rust crate that provides idiomatic wrappers around the FFI bindings established in earlier patches.

The patch includes two main changes: First, it updates the Makefile to properly build both the low-level `libgit-sys` and new `libgit-rs` crates when Rust support is enabled. Second, it implements the Rust wrapper API, showing an example with config value retrieval that handles type conversion and error cases in a Rust-idiomatic way (returning `Option<i32>` rather than separate status/value outputs).

Junio C Hamano reviews the changes and approves them for inclusion, noting that while he might have written the Makefile target differently, the current implementation is perfectly acceptable. He particularly appreciates how the higher-level wrapper improves the API ergonomics compared to the raw C interface. The patch series is now complete and ready for integration, having addressed all previous feedback.
