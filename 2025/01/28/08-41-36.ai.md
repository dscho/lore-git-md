This is the final patch in the zlib-ng performance optimization series, focusing on CI testing infrastructure. The patch adds Alpine Linux CI coverage for the new zlib-ng backend by installing the `zlib-ng-dev` package in the Alpine test environment. This allows Meson to automatically detect and use zlib-ng during builds.

The patch explains the choice of Alpine Linux for this testing - other major distributions either lack zlib-ng packages (Debian, Alma Linux) or don't run the test suite (Fedora). The change is minimal, just adding `zlib-ng-dev` to the package list in `ci/install-dependencies.sh`, but completes the series' goal of providing full test coverage for the zlib-ng integration.

This follows the earlier patch (8/10) that implemented the core build system integration for zlib-ng. With this addition, the CI system will verify both the standard zlib and zlib-ng backends, ensuring the compatibility layer works as intended. The patch maintains the series' clean approach of minimal changes for maximum benefit, here leveraging Alpine's package availability to get test coverage without complex CI modifications.
