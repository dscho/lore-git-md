Platform compatibility patch in Patrick Steinhardt's reftable decoupling series (17/20). This continues the systematic separation of POSIX-emulation functionality from Git-specific Windows compatibility code, now focusing on the MSVC build path.

The patch splits `compat/msvc.h` into two headers:
- `compat/msvc/posix.h` for pure POSIX emulation (file operations, process handling)
- `compat/msvc/compat-util.h` for Git-specific Windows adaptations

Key changes include:
- File reorganization with new `msvc/` subdirectory structure mirroring the earlier MinGW changes
- Build system updates (Makefile and meson) to handle the new file locations
- Header inclusion cleanup, removing direct mingw.h dependencies from MSVC path
- Compilation fixes through proper include path handling

This follows the pattern established in patch 16 for MinGW, completing the Windows platform header reorganization. The changes maintain behavioral consistency while improving modularity - a necessary step toward making reftable truly independent of Git's core infrastructure. The patch appears mechanically sound, with corresponding build system updates and no functional changes to the actual POSIX emulation behavior.
