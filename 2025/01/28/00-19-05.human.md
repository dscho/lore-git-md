This is the final patch in the v7 series introducing Rust bindings for Git's C library, adding a higher-level "libgit" crate that provides idiomatic Rust wrappers around the FFI bindings from the previously introduced `libgit-sys` crate. The patch establishes a new `contrib/libgit-rs` directory containing:

1. A Rust crate that builds on `libgit-sys` to provide more natural Rust interfaces for Git functionality, starting with config file operations. The initial implementation includes:
   - A `ConfigSet` struct wrapping Git's config handling with proper memory management
   - Methods for loading config files and retrieving integer/string values
   - Test coverage demonstrating the API usage

2. Build system integration updates to:
   - Include the new crate in `make all` when `INCLUDE_LIBGIT_RS` is set
   - Add proper clean targets for the new crate's build artifacts
   - Extend test infrastructure to run the new crate's tests

The implementation follows Rust FFI best practices, with the higher-level crate safely managing resources and providing Rust-native error handling. The patch appears well-structured and completes the planned initial functionality for Rust bindings, building on the extensive review and refinement seen in earlier patches of this series. With maintainer approvals already secured for the foundational work, this final piece looks ready for integration.
