Platform compatibility patch in Patrick Steinhardt's reftable decoupling series.

This patch (16/20 in v2) splits the MinGW compatibility header into two parts: POSIX-emulation functionality in `compat/mingw/posix.h` and Git-specific Windows compatibility in `compat/mingw/compat-util.h`. The change is part of the larger effort to make reftable fully portable by disentangling it from Git's core infrastructure.

Key technical changes:
- Creates new `compat/mingw/compat-util.h` with Git-specific Windows helpers (UTF-8/16 conversion, path validation, SSL fd handling)
- Moves pure POSIX emulation to `compat/mingw/posix.h` (file operations, process control, signals)
- Updates all references across the codebase (Makefiles, CMake, meson)
- Maintains all existing functionality through careful header inclusion
- Prepares for future splitting of `git-compat-util.h` into POSIX and Git-specific parts

The patch is mechanical but foundational - it enables cleaner separation of concerns between platform emulation and Git-specific Windows adaptations. This aligns with the series' goal of making reftable buildable outside Git's environment. The changes are well-contained and maintain backward compatibility through the header reorganization.
