Performance optimization patch enabling zlib-ng support in Git. This is part of a series (v4 08/10) that allows Git to use zlib-ng as an alternative zlib backend, providing significant performance improvements for object reading operations.

The patch introduces build system support for zlib-ng, which offers optimized implementations using SSE2/AVX2 and other CPU intrinsics. Benchmark results show a ~25% speedup in `git cat-file --batch --batch-all-objects` when using zlib-ng (40.324s vs 52.085s with standard zlib). The implementation handles zlib-ng's symbol prefixing (`zng_`) through macro redefinition in compat/zlib-compat.h, allowing both zlib and zlib-ng to coexist on the same system.

Build configuration is supported through both Makefile (via ZLIB_NG=1) and Meson (via zlib_backend=zlib-ng). The changes maintain backward compatibility while providing a clean path to use zlib-ng's optimizations when available. The patch appears well-tested and integrates with the series' broader goal of improving compression performance through modern zlib alternatives.
