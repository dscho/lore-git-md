This is a refactoring patch in the zlib-ng performance optimization series, moving a compatibility shim for `deflateBound()` into the new zlib abstraction layer. The patch relocates the pre-1.2.0 zlib compatibility definition from `git-zlib.c` to `compat/zlib-compat.h`, centralizing zlib version-specific logic in preparation for the zlib-ng integration. The change is straightforward - it takes the existing `#define` that provides a fallback implementation when either `NO_DEFLATE_BOUND` is set or the zlib version is older than 1.2.0, and moves it to the new compatibility header while maintaining identical functionality. This follows the series' pattern of consolidating zlib version handling in the compatibility layer rather than scattering it through the codebase.

The patch continues the architectural work started in earlier patches to create a clean abstraction between Git and its zlib backend. By moving this shim, it ensures all zlib version-specific logic will be in one place when the subsequent zlib-ng support is added. The implementation preserves the same calculation formula for the compressed size upper bound that was previously in `git-zlib.c`, just in a more maintainable location. This is a small but meaningful step in the larger effort to enable zlib-ng's performance optimizations while maintaining compatibility with standard zlib.
