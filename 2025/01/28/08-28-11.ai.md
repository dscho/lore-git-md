This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. The change removes one of the last remaining uses of Git-specific macros in the reftable code.

The patch replaces the `ARRAY_SIZE()` macro (a Git-specific helper) with a direct calculation of array length using `sizeof(sections) / sizeof(*sections)` in `reftable/reader.c`. This appears in a debug printing function that iterates through the reftable sections. The change is straightforward and maintains identical functionality while further reducing dependencies on Git's compatibility utilities.

This continues the series' pattern of systematically replacing Git-specific constructs with portable alternatives. The modification is small and focused, affecting only a single debug function. Since this is part of a larger architectural effort, the change should be evaluated in the context of the series' overall goal rather than as an isolated improvement.
