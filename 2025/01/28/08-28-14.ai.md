Refactoring patch in the reftable decoupling series, replacing Git's `SWAP()` macro with a reftable-specific implementation.

This patch introduces `REFTABLE_SWAP()` to replace Git's `SWAP()` macro throughout the reftable codebase, continuing the architectural effort to remove Git dependencies. The new implementation:
- Performs the same value swapping functionality but with reftable-specific code
- Includes a size-checking mechanism similar to Git's original (though expressed differently)
- Affects four files: basics.h (where the new macro is defined), merged.c, pq.c, and record.c where swap operations are used

The change is straightforward mechanical replacement with no behavior difference, maintaining the same memory safety guarantees through the size-checking mechanism. This follows the established pattern in the series of systematically replacing Git infrastructure with reftable-specific equivalents.

The implementation uses a clever buffer size calculation that effectively enforces type safety (the `sizeof(a) - 2*sizeof(a)*(sizeof(a)!=sizeof(b))` expression will cause compilation failure for mismatched types). This maintains the safety check that was present in Git's `SWAP()` while avoiding direct dependency on Git's implementation.
