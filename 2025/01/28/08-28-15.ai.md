This patch continues the reftable decoupling effort by replacing Git's `UNUSED` macro with a new `REFTABLE_UNUSED` version. The change is part of Patrick Steinhardt's larger series to make the reftable library fully independent from Git's core infrastructure.

The new macro provides a weaker guarantee than Git's version - it suppresses unused parameter warnings but won't warn if a parameter marked as unused is actually used. This trade-off avoids needing compiler-specific logic while still serving the primary purpose of silencing warnings about intentionally unused parameters.

The patch updates 5 files (basics.h, blocksource.c, iter.c, record.c, writer.c) with mechanical conversions from `UNUSED` to `REFTABLE_UNUSED`, adding the macro calls where needed. The changes are straightforward and maintain the same functionality while removing another dependency.

This follows the established pattern in the series of replacing Git-specific components with reftable-specific equivalents, though this particular change is more about code hygiene than architectural separation. The implementation appears solid and the scope is well-contained to the reftable subsystem.
