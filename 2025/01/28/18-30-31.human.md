Bugfix for filter-repo's config parsing, addressing a crash when handling multi-line configuration values. Elijah Newren has reviewed and applied Toke Høiland-Jørgensen's patch that fixes this issue by switching from newline-delimited to NUL-delimited config parsing using `git config --list --null`.

The fix is straightforward and well-received, with Newren noting it's cleaner than other proposed solutions. The patch includes both the code change and a test case that reproduces the crash scenario before the fix. This addresses a real-world issue that had multiple GitHub PRs proposing solutions, indicating it was affecting users.

The change makes filter-repo more robust when processing git config files that contain multi-line values, though there's still a noted FIXME in the code about handling multi-valued keys properly. The test coverage is minimal but sufficient to verify the basic crash scenario is fixed.
