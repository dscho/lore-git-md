This is part of the performance optimization series introducing zlib-ng support, specifically focusing on compatibility shims for older zlib versions. Patch 6/10 moves the `deflateSetHeader()` compatibility handling from archive-tar.c to the centralized compat/zlib-compat.h header.

The change removes version-specific conditional compilation from archive-tar.c and instead provides a no-op stub implementation in zlib-compat.h for zlib versions older than 1.2.2.1. The stub maintains the same behavior (returning Z_OK while ignoring parameters) but now includes explanatory comments about this being intentional for reproducibility rather than a missing feature. This centralization prepares for the zlib-ng integration by ensuring all version-specific logic lives in one place.

The patch touches two files: it removes 4 lines of version-guarded code from archive-tar.c and adds 19 lines to compat/zlib-compat.h implementing the stub with documentation. The implementation follows the same pattern as the previously added `deflateBound()` compatibility shim, maintaining consistency in how older zlib versions are handled. This is part of the broader effort to clean up zlib compatibility code while enabling the switch to zlib-ng's optimized backend.
