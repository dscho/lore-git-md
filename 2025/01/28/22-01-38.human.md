Feature implementation for Rust bindings to libgit.a. This is part 2/4 of the v8 series establishing foundational Rust infrastructure in Git's `contrib/` directory.

The patch introduces `libgit-sys`, a Rust crate that provides FFI bindings to Git's C library. The implementation carefully handles symbol visibility to avoid collisions (prefixing with `libgit_`) and uses build system integration to compile with `-fvisibility=hidden`. The initial version exposes Git's user agent string functions as a proof of concept, with tests verifying the basic functionality.

The build system changes include:
- New Makefile rules for Rust builds
-fvisibility=hidden support
- Symbol export management via `public_symbol_export.[ch]`
- Integration with cargo build/test

This is a well-structured patch that follows the careful approach seen throughout the series, with clear attention to build system integration and symbol safety. The implementation has already incorporated feedback from previous rounds (Phillip Wood's style suggestions, Josh Steadmon's build system refinements) and represents the final iteration of this component. The patch maintains the project's separation of concerns by keeping the Rust bindings in `contrib/` while providing a solid foundation for future Rust tooling.
