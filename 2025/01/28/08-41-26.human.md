This is the cover letter for a performance optimization series introducing zlib-ng support as an alternative zlib backend. The series has gone through multiple review iterations (now at v4) and is nearly ready for merging.

The key motivation is a significant performance improvement - benchmarks show ~25% speedup in object reading operations when using zlib-ng compared to standard zlib. The implementation provides infrastructure to use zlib-ng's optimized implementation while maintaining standard zlib compatibility, abstracting the differences through a new "compat/zlib.h" header.

The series handles several technical challenges:
- Mapping zlib-ng's `zng_`-prefixed symbols
- Maintaining compatibility with older zlib versions
- Proper const-casting for zlib-ng's stricter type checking
- Build system integration via Makefile and Meson
- CI testing using Alpine Linux (chosen for zlib-ng package availability)

The v4 changes address final review feedback, adding explanatory comments about the const-cast workaround and no-op behavior for older zlib versions. The series appears well-tested and reviewed, with all substantive discussions resolved. It provides a clean speed boost for users who opt to use zlib-ng, particularly beneficial for hosting providers and other high-throughput use cases.
