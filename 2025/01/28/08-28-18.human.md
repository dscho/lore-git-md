This is a platform compatibility patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. It focuses on reorganizing Windows/MSVC compatibility headers as part of the broader effort to make the codebase more modular.

The patch splits the MSVC compatibility layer into two distinct parts: one for POSIX-related functionality (moved to `compat/msvc/posix.h`) and another for Git-specific Windows compatibility (in the new `compat/msvc/compat-util.h`). This mirrors similar work done earlier for MinGW headers and helps establish a separation between general POSIX emulation and Git-specific Windows adaptations.

The changes are mechanical but important for the architectural goal of making the reftable library more standalone. Build system files (`config.mak.uname` and `meson.build`) are updated to reflect the new header locations and compilation requirements. The patch maintains all existing functionality while improving the code organization.

This is part of a well-structured series that has been receiving careful review, with each iteration addressing feedback while maintaining architectural consistency. The changes here are straightforward and unlikely to be controversial, continuing the pattern of systematic, incremental improvements to the codebase's portability layer.
