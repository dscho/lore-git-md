This is a platform compatibility patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. As part of the larger effort to make reftable fully portable, this patch splits the MinGW compatibility header into two parts: one for POSIX-related functionality (`mingw/posix.h`) and one for Git-specific Windows compatibility (`mingw/compat-util.h`).

The change is primarily mechanical, moving code between files while maintaining all existing functionality. The split helps prepare for future work to reorganize Windows-specific headers and make the build system more explicit about its dependencies. The patch updates all affected build systems (Make, CMake, meson) and includes path adjustments in several files to point to the new locations.

This appears to be a well-executed step in the larger architectural refactoring, with thorough updates to all build systems and clear documentation of the split's purpose. The changes are focused and maintain backward compatibility while setting up for future improvements in Windows support.
