CI/build system patch in the zlib-ng optimization series, converting the Alpine Linux CI job to use Meson instead of Make. This change serves multiple purposes: simplifying CI infrastructure by removing manual build flags, verifying Meson's automatic detection of those flags, and preparing for zlib-ng integration testing. The patch adds a new Meson option `test_utf8_locale` to handle the `GIT_TEST_UTF8_LOCALE` variable that Meson couldn't auto-detect, while removing redundant GCC specification since it's already the default in `ci/lib.sh`. Key files modified include CI configuration files (.github/workflows, .gitlab-ci), dependency scripts, and Meson build files, with the Alpine job renamed to `linux-musl-meson` to reflect the build system change. This completes the Meson transition started earlier in the series, ensuring consistent build system usage across CI platforms.
