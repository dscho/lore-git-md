This is a CI/build system issue regarding documentation file extensions during a merge conflict.

Jeff King reports a CI failure where AsciiDoc processing can't find an included file (`mergetools-diff.txt`) that was referenced in `difftool.adoc`. The problem stems from two concurrent changes: Jean-Noël Avila's branch renamed documentation files from `.txt` to `.adoc` extensions, while Adam Johnson's branch added a new include reference using the old `.txt` extension.

The issue can't be fixed by either branch independently - Jean-Noël's branch doesn't have the new include line yet, while Adam's branch still uses the old extension. Jeff suggests this will require either an "evil merge" (a manual merge resolution) or for Jean-Noël to rebase on Adam's now-merged changes.

This highlights a coordination challenge when multiple documentation changes touch the same files in different ways. The problem appears straightforward to fix but requires careful merging to maintain consistency between the file extensions and their references.
