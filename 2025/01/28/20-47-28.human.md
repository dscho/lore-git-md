This is a refinement to the Rust bindings implementation, specifically addressing config API exports in the `libgit-sys` crate. Josh Steadmon responds to Phillip Wood's review feedback on v7 of the series, implementing two key improvements for v8: 

1) Replacing direct casts between `config_set` and `libgit_config_set` with a proper wrapper struct, making the FFI boundary cleaner and type-safe. This was feedback originally given in v2 but only now implemented.

2) Fixing line-wrapping style issues in the config API functions to adhere to the 80-character limit.

The changes are straightforward build-system and FFI polish for the already-reviewed Rust bindings work. With these fixes, the config API portion of the bindings appears complete and ready for integration. This patch is part of the final v8 series that Junio C Hamano has indicated will conclude this work.
