This is the final patch in the Rust bindings series, completing the higher-level `libgit` crate that provides idiomatic Rust interfaces to the FFI bindings established in previous patches. Junio C Hamano is reviewing and approving the changes.

The patch makes two main changes:
1. Adds a new `libgit-rs` target to the Makefile to build the higher-level crate, mirroring the existing `libgit-sys` target for the FFI layer. While Junio notes the implementation could be more DRY, he accepts the explicit version.
2. Shows an example of the higher-level Rust API with a `get_int()` method that provides proper error handling and type safety around the raw FFI calls. This demonstrates the value of the layered approach - the unsafe FFI calls are safely encapsulated behind Rust's type system.

Junio approves the patch and indicates he will queue it, marking the completion of this multi-patch effort to add Rust bindings to Git's C library. The series has gone through several iterations with thorough review, and this final patch provides the promised higher-level interface that makes the bindings usable from Rust code. The implementation includes proper memory management through RAII and Rust-idiomatic error handling, as seen in the `get_int()` example which safely wraps the underlying C function while providing a more natural Rust interface.
