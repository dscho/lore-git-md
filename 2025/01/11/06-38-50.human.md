This is a build system fix for the Meson build configuration. Sam James addresses a parallel build issue in the documentation generation where some targets weren't properly declaring their dependency on the documentation toolchain (specifically `asciidoc.conf`). The patch adds explicit `depends: documentation_deps` to two documentation targets in `Documentation/technical/meson.build` that were missing this declaration.

The change is straightforward and appears to solve a real problem - the commit message notes this manifests as parallel build failures when the documentation dependencies aren't available yet. The fix is minimal (just two lines added) and focused on the technical documentation build targets. This seems like a clear improvement to the build system's reliability, though it's a fairly minor change that most users won't notice unless they're building from source with parallel jobs.
