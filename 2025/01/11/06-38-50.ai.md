Build system fix for documentation generation in meson builds.

This patch addresses a parallel build issue in the meson build system where documentation targets could fail because they didn't properly declare their dependency on the asciidoc configuration file. The fix adds explicit `depends: documentation_deps` declarations to two documentation generation targets in `Documentation/technical/meson.build`: the API index generation and individual article HTML generation.

The issue manifests when building in parallel, where the documentation tools might try to run before the asciidoc configuration is available. The patch is straightforward, adding the missing dependency declaration that was already properly handled for other documentation targets. The change affects the build system's internal dependency graph but doesn't modify any actual documentation content or runtime behavior.

The patch appears well-scoped and correctly targeted, though it might be worth checking if there are other similar documentation targets elsewhere in the meson build files that could need the same fix. The commit message clearly explains the problem and solution without unnecessary detail.
