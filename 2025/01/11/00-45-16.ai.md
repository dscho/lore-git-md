Key technical points carried forward:
- Kerberos and TLS client cert workflows create unavoidable false positives for flow-based detection
- String pattern matching would be required for accurate detection, but brings maintenance burdens
- The GitHub PAT security issue remains unresolved with no clear architectural solution that handles all edge cases

The discussion highlights the tension between security goals and maintaining compatibility with legitimate authentication workflows, with no consensus yet on an implementation path that satisfies both concerns.
