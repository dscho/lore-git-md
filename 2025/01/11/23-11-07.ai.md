This is a test patch that fixes compatibility with the mksh shell in Git's blame test suite. The change modifies how padding spaces are generated in two test cases that verify blame output formatting with blank boundary commits.

The patch replaces `printf "%0.s "` sequences (which mksh rejects as invalid) with simpler `printf "%Ns" ""` syntax (where N is either 11 or the hexsz variable) to generate the same number of spaces. This maintains the exact same test expectations while working across different shells. The change is minimal (2 lines modified) and clearly motivated by the mksh compatibility issue.

The tests being modified were introduced in commit e7fb2ca945 to verify proper handling of blank boundary commits in blame output formatting. The new implementation achieves the same padding effect through a more portable printf format string. The patch appears well-scoped and correctly maintains the test's original verification of blame's --abbrev and -b flag behavior.
