SMTP bearer authentication support for git send-email. Patch implements OAUTHBEARER and XOAUTH2 authentication mechanisms not supported by Perl's Authen::SASL module. Adds two new functions: `generate_oauthbearer_string` for RFC 5801 compliance and `generate_xoauth2_string` for RFC 7628 compliance, with special handling for Gmail and Office 365 configurations. New `smtp_bearer_auth` function handles SMTP AUTH command transmission with TLS enforcement and proper error handling including dummy requests on failure. Includes configuration examples for git-credential-oauth integration. Implementation shows thorough attention to standards but has minor uninitialized variable warnings to address. Enables OAuth authentication with major providers when sending patches via git send-email.
