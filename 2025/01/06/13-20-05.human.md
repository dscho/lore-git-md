This is a build system patch that's part of a larger series preparing for Git 3.0 by establishing infrastructure for handling breaking changes. The patch introduces a `WITH_BREAKING_CHANGES` compile-time flag and wires it up across the build systems (Makefile, Meson, and unexpectedly also CMake). It also adds a corresponding `WITHOUT_BREAKING_CHANGES` test prerequisite.

The patch appears well-implemented but slightly under-documented - while the commit message mentions Makefile and Meson support, the actual changes include CMake as well. The test-lib.sh addition for testing without breaking changes is a thoughtful inclusion that wasn't mentioned in the commit message. This is clearly part of a coordinated effort to clean up long-deprecated features, with the thread showing consensus on the approach. The implementation looks solid and follows established patterns for this kind of build system change.
