This is the final patch in a series introducing OS version reporting to Git's protocol v2, adding a configurable command to generate the version string. The patch completes the feature by allowing users to specify an arbitrary command (via `osversion.command`) whose output will be used as the OS version string exchanged between clients and servers, rather than just the basic system name from `uname`.

The implementation handles command parsing and execution safely, falling back to the simple `uname` behavior if the command is unset or fails. The patch includes thorough documentation updates and new tests verifying the behavior with a sample command (`uname -srvm`). Windows support remains disabled pending earlier unresolved questions about `uname` behavior on that platform.

The work appears well-constructed, with proper memory management and error handling. The tests demonstrate both the happy path and proper integration with the existing capability advertisement system. This completes the series' goal of providing flexible OS version reporting while maintaining privacy controls through the existing `transfer.advertiseOSVersion` toggle.
