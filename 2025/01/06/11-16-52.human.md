CI modernization patch for rootless container execution in GitHub Actions. This is part 3/10 of Patrick Steinhardt's series that has already undergone technical review and addresses remaining CI infrastructure issues.

The patch modifies GitHub Actions workflows to run tests as a non-root user ("builder") rather than root, matching GitLab CI's approach. This fixes test failures that occurred when privileged operations were accidentally allowed during testing. The changes involve:
1. Creating a dedicated user in the container
2. Running both test execution and failure reporting under this user
3. Adding necessary packages (shadow-utils, sudo) to support user management

The solution is straightforward and builds on existing patterns from GitLab CI. Since this is part of a well-reviewed series that has already addressed all technical concerns, it appears ready for integration. The change helps ensure test behavior matches real-world unprivileged usage scenarios.
