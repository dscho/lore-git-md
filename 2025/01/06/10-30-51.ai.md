Protocol v2 OS version capability implementation (part 3/4). This patch adds the core functionality to advertise OS version information in Git's protocol v2, building on the refactored uname handling from previous patches.

The implementation introduces a `transfer.advertiseOSVersion` config option (defaulting to true) that controls whether clients and servers exchange OS information via a new `os-version` capability. The OS name is obtained from `uname(2)`'s sysname field and sanitized similarly to the existing agent string handling. Windows support is currently disabled in tests due to discrepancies between `uname(1)` and `uname(2)` outputs.

Key technical components:
- New `os_version()` and `os_version_sanitized()` functions in version.c
- `advertise_os_version()` repository config check
- Protocol v2 capability plumbing in connect.c and serve.c
- Documentation updates for config and protocol specs
- Test updates in t5555 and t5701 with Windows-specific handling
- New `test_redact_non_printables()` test helper function

The patch maintains consistency with existing protocol v2 capabilities while adding the new OS version reporting feature. It builds on the refactored uname handling from patch 2 and sets up for the final configuration patch. Windows compatibility remains an open issue noted in the implementation.
