Platform compatibility fix addressing MSVC warnings in the interactive patch interface.

This is part 1/4 in a series fixing type mismatch warnings from MSVC, specifically targeting `add-patch.c` which handles Git's interactive patch application. The patch changes `unsigned long` to `size_t` for hunk header fields to ensure consistent behavior across platforms, and introduces a new `strtos` macro in `git-compat-util.h` to handle string-to-size_t conversion safely on both Windows and Linux.

The changes are mechanical but important for type safety, particularly around hunk offset and count calculations in the interactive patch interface. The author has added overflow checks when converting strings to size_t values, which should have no behavioral impact but makes the code more robust. The patch also updates format strings to use `PRIuMAX` for size_t printing.

This continues the thread's trend of careful platform-specific fixes, now applying the same treatment to the interactive patch machinery that was previously given to other core components. The changes look straightforward and well-contained, with no obvious red flags.
