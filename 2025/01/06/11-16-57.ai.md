This is a CI modernization patch that removes legacy Ubuntu 16.04 support, part of Patrick Steinhardt's v2 series to standardize Git's CI infrastructure. The patch follows up on c85bcb5de1 which had already migrated all CI jobs from Ubuntu 16.04 to 20.04, making the remaining special-casing in `ci/lib.sh` obsolete.

The change simplifies the HTTPD test configuration by unconditionally enabling `GIT_TEST_HTTPD=true` for all Ubuntu versions, since the HTTP/2 compatibility issue that previously required disabling it on Ubuntu 16.04 is no longer relevant. The patch removes 8 lines of version-specific logic while maintaining the same test coverage on modern Ubuntu versions.

This is a straightforward cleanup that aligns with the series' goal of removing stale CI infrastructure. The change is minimal (9 lines removed, 1 line kept) and builds on prior work that had already completed the Ubuntu 16.04 migration. The patch appears well-contained and low-risk, touching only CI configuration without affecting core Git functionality or test behavior.
