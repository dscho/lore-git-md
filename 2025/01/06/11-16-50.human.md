Bugfix for MinGW CI flakiness in runtime prefix tests. This is the first patch in Patrick Steinhardt's v2 series modernizing Git's CI infrastructure.

The patch addresses an intermittent failure in GitLab CI where MinGW tests would fail with EBUSY errors when trying to overwrite the git.exe binary during runtime prefix testing. While the root cause remains unclear (possibly a Windows/MinGW file handle issue), the solution cleanly factors out the common setup into a dedicated test case to avoid the race condition.

The change is straightforward - it extracts the binary copying operation that was duplicated across two tests into a shared setup step. This maintains the same test coverage while eliminating the flaky behavior. The patch fits well with the series' broader goal of CI reliability improvements, though this particular fix is Windows-specific rather than part of the containerization work that dominates later patches.
