This is a refactoring patch that's part of a series hardening Git's file handling against race conditions. It's the first of three patches in v2 of the series, which has already seen significant review and consensus from key contributors.

The patch stands alone as a straightforward renaming exercise in `object-file.c`, changing variable names in the `check_collision()` function from generic `filename_a`/`filename_b` to more descriptive `source`/`dest`. This prepares for subsequent changes that will treat source and destination files differently when handling potential race conditions during object writing.

The changes are mechanical and well-contained (20 lines changed, all renames), with no behavior modifications. The commit message clearly states the purpose as making future changes easier to reason about. Given this is part of an already-reviewed series addressing a serious race condition, and the changes are minimal and obviously correct, this patch appears ready to go in.
