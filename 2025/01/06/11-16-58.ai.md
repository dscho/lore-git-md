CI modernization patch updating container images to test against latest Ubuntu releases.

This is the 9th patch in Patrick Steinhardt's CI modernization series (v2), which has already addressed all technical feedback and is nearing completion. The patch changes the default container image from Ubuntu LTS (`ubuntu:latest`) to the actual latest release (`ubuntu:rolling`, currently 24.10) for most CI jobs across both GitHub Actions and GitLab CI configurations.

The change affects 7 job configurations in GitHub Actions and 6 in GitLab CI, including key test scenarios like sha256, reftable, leaks checking, and ASAN/UBSAN. The justification is that since the CI already tests the oldest supported Ubuntu LTS (20.04), it makes sense to also test against the newest release rather than just the latest LTS. The `linux32` job remains on Ubuntu 20.04 as it uses the i386-specific image.

This completes the containerization standardization effort by finalizing the distro version strategy. The change is straightforward with no expected performance impact, just swapping image tags while maintaining all existing test coverage. The patch follows the series' pattern of using `CI_JOB_IMAGE` as the source of truth for distro names. With this change, the CI now tests both the oldest supported Ubuntu version and the very latest release.
