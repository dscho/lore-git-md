This is a cleanup patch removing stale CI infrastructure, part of Patrick Steinhardt's CI modernization series (v2). The patch removes the last remaining Azure Pipelines support code, which was rendered obsolete when the project switched to GitHub Actions in 2020. The changes delete Azure-specific environment variable handling from `ci/lib.sh` and test artifact collection logic from `ci/print-test-failures.sh`.

The removal is straightforward and uncontroversial, as Azure Pipelines support was officially retired nearly five years ago. This appears to be the final piece of Patrick's comprehensive CI modernization effort, which has already addressed all technical feedback in prior rounds of review. The patch series as a whole has modernized Git's CI infrastructure across multiple platforms while fixing flaky tests and standardizing containerized execution.
