This is part of Patrick Steinhardt's CI modernization series, specifically converting GitHub Actions jobs to containerized execution. 

The patch moves all Linux-based CI jobs from direct machine pool execution to containerized runs, completing a transition that began earlier in the series. The key motivation is gaining more control over the execution environment by being able to specify exact container images rather than being limited to GitHub's predefined distro selections.

Performance data shows the containerized approach has negligible impact - some jobs run slightly faster, others slightly slower, but all within normal variance. Two potential downsides have been addressed: root execution (fixed in a prior patch via setpriv) and Node.js binary injection issues (resolved for 32-bit jobs). The actual changes reorganize the job matrix to use container specifications while preserving all existing test configurations.

This appears to be a well-justified change with thorough performance validation and clear benefits for environment control. As part of the broader CI modernization effort, it follows established patterns from earlier patches in the series and maintains consistency with the project's CI goals.
