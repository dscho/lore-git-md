CI infrastructure cleanup removing Azure Pipelines remnants. This is the final patch in Patrick Steinhardt's CI modernization series, which has already completed technical review and addressed all feedback.

The patch removes stale Azure Pipelines infrastructure that has been unused since support was dropped in 2020 (6081d3898f). The changes delete Azure-specific code paths from two CI scripts: `ci/lib.sh` loses its Azure environment variable handling and job configuration, while `ci/print-test-failures.sh` removes Azure-specific test artifact collection. The removal is straightforward with no behavior changes to other CI systems.

This completes the series' goal of modernizing Git's CI infrastructure by fully eliminating legacy systems in favor of the now-standardized GitHub Actions and GitLab CI setup. The changes are minimal (25 lines removed) and focused solely on cleanup of already-retired functionality, making this a low-risk conclusion to the broader modernization effort.
