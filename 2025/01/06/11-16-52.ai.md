CI modernization patch for rootless container execution in GitHub Actions.

This is the third patch in Patrick Steinhardt's v2 series modernizing Git's CI infrastructure. The change modifies GitHub Actions container jobs to run tests as a non-root user ("builder") rather than root, addressing test failures caused by root's ability to bypass file permission checks. The implementation follows GitLab CI's existing approach, creating a dedicated user and using sudo to execute test scripts with proper permissions.

Key technical changes include:
- Adding `useradd` and `chown` steps to create and prepare the builder user
- Wrapping test execution in `sudo --user=builder` to drop privileges
- Installing `shadow-utils` and `sudo` packages as new dependencies
- Maintaining artifact upload functionality by preserving environment variables

The patch appears straightforward and well-contained, touching only the GitHub Actions workflow file and dependency installation script. It solves a real problem where root privileges were causing false test failures, bringing GitHub Actions behavior in line with GitLab CI's more restrictive execution model. The solution is consistent with the series' broader goal of standardizing and modernizing CI infrastructure.
