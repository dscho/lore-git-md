The exchange highlights the tension between workflow-specific protocol extensions and more general capability mechanisms, with Chris leaning toward solutions that could work within their existing infrastructure while acknowledging the value of more native Git support. No concrete implementation path is proposed, but the discussion surfaces important constraints (Gerrit integration, bootstrap requirements) for any future protocol work.
