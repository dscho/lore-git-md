This is a CI/build system patch that simplifies the test matrix by merging the redundant "linux-gcc-default" job into the standard "linux-gcc" job. The patch removes the job from both GitHub Actions and GitLab CI configurations, along with associated conditional logic in `ci/lib.sh`.

The justification is that the "linux-gcc-default" job provided minimal additional test coverage, differing only in: using the system's default GCC version (while other jobs already test specific versions), not setting Python version explicitly (now irrelevant since Python 2 is EOL), and not setting the default branch name (which is tested elsewhere). The changes touch CI configuration files in both GitHub and GitLab workflows, plus the shared CI library script.

This appears to be a straightforward cleanup with no functional impact on test coverage, part of a larger series about removing deprecated features (though this particular patch is more about CI optimization than feature removal). The changes are mechanical deletions of now-unneeded configuration, following the pattern for CI job removal.
