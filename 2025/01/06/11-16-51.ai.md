This is a bugfix patch in Patrick Steinhardt's CI modernization series (v2), specifically addressing a flaky test in the submodule subsystem. The patch fixes a race condition in t7422 where `git submodule status --recursive` sometimes fails to trigger SIGPIPE as expected due to buffered stdout.

The test was intermittently failing because grep would terminate the pipe after git-submodule had already exited, missing the signal. The solution uses Perl to pre-fill the pipe buffer with 128KB of "foo" lines (33000 iterations) before executing the submodule command, ensuring the command blocks on write and reliably triggers SIGPIPE when grep exits early. Jeff King suggested this approach, which maintains the test's verification of signal propagation while eliminating the race condition.

The patch includes a demonstration of how to reliably reproduce the original flakiness by adding a sleep before grep, showing the problem was timing-dependent. The fix preserves all test assertions (empty stderr, signal 13/SIGPIPE) while making the behavior deterministic. This was one of the last remaining issues in the CI modernization series before integration.
