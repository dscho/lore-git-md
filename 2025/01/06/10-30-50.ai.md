This is part 2/4 of the "Protocol v2 OS version capability" series, focusing on refactoring existing uname-related code to support the new OS version reporting feature.

The patch extracts the uname(2) system call handling from builtin/bugreport.c into a new get_uname_info() function in version.c, making it reusable for the protocol capability implementation. The new function includes a 'full' parameter to toggle between complete OS information (sysname, release, version, machine) and just the OS name, which will be used in the protocol implementation.

Key technical details:
- Moves uname handling from bugreport.c to version.c/h
- Adds new get_uname_info() function with full/partial output control
- Maintains existing error handling and strbuf output pattern
- Includes proper header updates and function documentation
- Preserves all existing behavior while making it reusable

This is a straightforward refactoring that creates the foundation for the OS version reporting feature while keeping the changes minimal and well-contained. The implementation appears clean with proper error handling and documentation. The patch follows the series' goal of building reusable components for the protocol capability while maintaining backward compatibility.
