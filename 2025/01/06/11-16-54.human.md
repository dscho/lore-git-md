CI modernization: standardizing distro naming in GitHub Actions

This patch is part of Patrick Steinhardt's series to modernize Git's CI infrastructure. It simplifies how Linux distribution names are handled in GitHub Actions workflows by deriving them directly from container image names rather than maintaining separate distro fields.

The change makes the configuration more maintainable by eliminating redundant distro specifications that were nearly identical to image names. The patch handles two special cases: the "linux32" job (which needed name adaptation) and untagged images (now explicitly tagged with "latest"). The approach matches what's already done in GitLab CI, bringing consistency across platforms.

The diff shows the straightforward mechanical changes - removing explicit distro fields from job definitions and adjusting a few supporting scripts to use the new naming scheme. This is a clean, well-motivated change that follows the series' theme of CI simplification while preserving all existing functionality.
