This is a cover letter for a CI modernization series that has undergone extensive review and is now in its final stages before integration. The 10-patch series focuses on three main areas: fixing flaky tests, removing stale CI infrastructure, and standardizing on containerized jobs in GitHub Actions.

The key technical improvements in v2 include: (1) a robust fix for the t7422 submodule test's SIGPIPE race condition using Perl pipe pre-filling (as suggested by Jeff King), (2) expanded justification for containerized jobs with performance metrics showing minimal impact (ranging from 36s faster to 37s slower across various jobs), and (3) typo fixes from earlier reviews. The series eliminates legacy Ubuntu 16.04 support and Azure Pipelines code while adding i386 testing via a new linux32 job.

The containerization changes now use rootless execution via setpriv(1) to maintain test validity, and GitHub's distro naming has been simplified (with special handling for linux32). Performance validation shows the containerized approach works within acceptable bounds, with Patrick noting the only remaining consideration is Junio Hamano's security review. The series appears technically sound with all substantive issues addressed, representing a significant cleanup and modernization of Git's CI infrastructure.
