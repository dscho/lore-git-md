This thread documents the implementation of OS version capability in Git's protocol, now merged after Usman Akinyemi's v5 patch series. The feature extends Git's existing `agent` capability string to include OS information rather than introducing a separate capability as initially proposed. The implementation handles platform-specific cases (particularly Windows quirks) while maintaining backward compatibility and comprehensive test coverage.

The series included significant preparatory refactoring to improve code quality, consolidating OS-related utilities into version.c with new helper methods like `get_uname_info()` and `redact_non_printables()`. The latest patch (4/6 in v5) further refines `get_uname_info()` to optionally return just the OS name rather than full system details, maintaining flexibility for different use cases while preserving existing bugreport functionality.

Post-merge discussion has shifted to privacy control ergonomics, with Usman advocating for a dedicated config option to completely suppress the agent capability (currently only controllable via `GIT_USER_AGENT` environment variable). Junio Hamano has indicated openness to such follow-up work while maintaining that the current implementation provides sufficient privacy controls through existing mechanisms. The thread represents a complete feature implementation with ongoing discussion about potential usability improvements to the privacy controls.
