This thread documents the implementation of OS version reporting in Git's protocol, a feature now merged after several iterations. The initial proposal from Christian Couder suggested a new `os-version` capability, but the final design—guided by Junio Hamano—extended the existing `agent` capability string instead, avoiding protocol fragmentation. The implementation includes platform-specific handling (notably for Windows), comprehensive tests, and documentation updates while maintaining backward compatibility.

Key refinements included removing the proposed `transfer.advertiseOSVersion` config (relying on `GIT_USER_AGENT` for privacy control), renaming functions for clarity, and adding string sanitization utilities. Junio has now confirmed this approach as the preferred direction, emphasizing that OS-specific configuration would operate at the wrong granularity compared to the existing agent controls. While noting this isn't yet a formal conclusion (with only two participants weighing in), his position clearly favors the unified mechanism. The thread shows how initial design discussions converged through maintainer guidance into a maintainable solution with consistent platform handling.
