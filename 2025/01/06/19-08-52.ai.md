Platform compatibility patch addressing MSVC warnings in the interactive patch subsystem. This is part 1 of a 4-patch series focused on fixing integer type mismatches across multiple Git components.

The patch converts `unsigned long` to `size_t` in `add-patch.c` for hunk header fields and related parsing functions, ensuring consistent behavior between Linux and Windows platforms. It introduces a new platform-agnostic `strtos` macro in `git-compat-util.h` that maps to either `strtoul` or `strtoull` depending on architecture. The changes include overflow checking during string-to-size_t conversions and updates to format strings to use `PRIuMAX` for portable printing of size_t values.

Key technical details include:
- Modified struct `hunk_header` fields (old_offset, old_count, new_offset, new_count)
- New error handling for ERANGE` during string-to-size_t conversion
- Updates to `Q_()` pluralization macro in `gettext.h` to use `size_t`
- Changes to hunk rendering and error message formatting throughout add-patch.c

The patch appears mechanically sound, with consistent application of the type changes across the interactive patch subsystem. The introduction of a centralized conversion macro suggests this solution may be reused in other parts of the codebase facing similar platform-specific warnings.
