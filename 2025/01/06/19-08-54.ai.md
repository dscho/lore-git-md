Bugfix and platform compatibility patch targeting MSVC compiler warnings in the apply subsystem. This is part 3/4 of a series addressing type mismatch warnings across Git's codebase, following the same pattern established in earlier patches.

The patch focuses on `apply.c` and `apply.h`, making systematic changes to eliminate MSVC warnings about 64-bit to 32-bit integer truncation. Key changes include:
- Converting `unsigned long` to `size_t` for length-related variables (linelen, parse_git_diff_header return value, fragment handling)
- Updating function signatures to use `size_t` for buffer sizes and lengths throughout the patch application logic
- Changing `int` to `size_t` for variables storing `strlen()` results
- Adjusting the hash algorithm's hex size handling to use `size_t`
- Maintaining the same function behavior while ensuring type safety

The changes are mechanical but thorough, covering the core patch parsing and application logic. Like the rest of the series, this maintains behavioral consistency while resolving platform-specific warnings.
