This is the final patch in Patrick Steinhardt's CI modernization series, focusing on updating the container images used in CI testing. The patch switches from using Ubuntu's LTS releases (via the "ubuntu:latest" tag) to the actual latest Ubuntu release (via "ubuntu:rolling") for most CI jobs, while keeping Ubuntu 20.04 for specific test cases that need an older environment.

The change affects both GitHub Actions and GitLab CI configurations, updating 7 job definitions in each to use the rolling release. The motivation is to better test coverage by exercising both the oldest supported Ubuntu version (20.04) and the newest available release (currently 24.10), rather than just testing LTS releases. This comes after the series has already addressed various CI issues including flaky tests, containerization standardization, and legacy infrastructure removal.

The patch appears straightforward and well-contained, completing the series' goal of modernizing Git's CI infrastructure. Since this is the final patch in a thoroughly reviewed series that has already resolved all technical concerns, it's likely ready for integration.
