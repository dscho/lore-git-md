Bugfix for Zsh shell completion broken by Bash-specific variable expansion. This is version 3 of a patch series addressing config variable completion issues that originated in commit 1e0ee4087e.

The patch introduces a portable `__git_indirect` helper function to replace Bash's `${!var}` indirect expansion syntax, which doesn't work in Zsh's ksh emulation mode. The new implementation uses `eval printf '%s' "\"\$$1\""` to safely expand variables across shells while preventing word splitting and globbing. The change affects config variable completion for sections like branch.*, remote.*, and submodule.*.

Key technical details include:
- 6 instances of indirect expansion replaced with the new helper
- Maintains identical behavior to original Bash expansion
- Includes demonstration program showing correct handling of variables with spaces
- Confirmed working on both Bash 3.2.57 and Zsh 5.0.8
- Now carries an Acked-by from Philippe Blain, the original reporter

The patch represents a technically sound solution to the immediate problem, though the broader question of cross-shell testing infrastructure remains open from previous discussion. The implementation carefully addresses portability concerns while maintaining the existing completion behavior.
