This is the third patch in a 4-part series addressing MSVC compiler warnings about type mismatches, specifically targeting the `apply.c` subsystem. The changes focus on fixing value truncation warnings when converting between 32-bit and 64-bit integers, and switching from `int` to `size_t` for variables storing string lengths.

The patch makes mechanical but thorough type safety improvements throughout the patch application code:
- Changes function signatures and variables to use `size_t` for length-related values (like `strlen()` results)
- Updates the `parse_git_diff_header()` interface to use `size_t` consistently
- Modifies helper functions like `linelen()` and `find_header()` to work with size-aware types
- Preserves all existing behavior while resolving platform-specific warnings

This follows the same pattern established in earlier patches of the series, applying the type-safety approach to another core component. The changes are focused and non-controversial, with no functional impact expected. The patch appears well-scoped and maintains the series' goal of making Git's codebase more portable across different architectures.
