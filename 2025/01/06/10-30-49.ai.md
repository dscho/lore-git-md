This is a refactoring patch that's part of the "Protocol v2 OS version capability" series. It extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` function in version.c, preparing for reuse in upcoming patches that will handle OS version strings.

The patch makes several cleanups while refactoring: switching to `size_t` for the loop counter, moving the counter declaration into the loop, and using `strbuf_detach()` to properly handle memory management. The new function replaces non-printable ASCII characters (below 32 or above 127) with dots and trims whitespace, though there's a TODO note about potentially improving the handling of consecutive non-printable characters.

This foundational change is straightforward and well-contained, touching only version.c with no behavior changes. The implementation appears solid, with Christian Couder mentoring the Outreachy participant on this work. The patch serves as preparation for the OS version capability plumbing that follows in the series.
