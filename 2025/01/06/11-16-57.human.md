This is a CI modernization patch that removes legacy Ubuntu 16.04 support from Git's CI infrastructure. As part of Patrick Steinhardt's larger series to modernize Git's CI system (now at v2 with 10 patches), this change eliminates special handling for Ubuntu 16.04 that is no longer needed.

The patch removes conditional logic in `ci/lib.sh` that previously disabled HTTP/2 testing specifically on Ubuntu 16.04 due to its outdated Apache version. Since all CI jobs have now migrated to Ubuntu 20.04 (as established in an earlier commit c85bcb5de1), this special case can be simplified to always enable HTTP/2 testing via `GIT_TEST_HTTPD=true`.

This is a straightforward cleanup that follows through on the series' goal of removing stale CI infrastructure. The change is minimal (8 lines removed, 1 line added) and well-justified by the prior migration work. It demonstrates good attention to detail by cleaning up now-redundant code paths rather than leaving them as dead weight.
