Feature proposal for a new Git TUI interface called "GitPanel".

This is a proposal from a new contributor for a terminal user interface (TUI) called "gitpanel" that would integrate GitHub account management and project viewing directly into Git. The author describes it as similar to Neofetch but for Git/GitHub, showing profile information (including ASCII art of GitHub avatars), account configuration, and project previews. The stated goals are to simplify setup for new users and provide better terminal-based accessibility.

The proposal comes after initial guidance from a Git maintainer (referred to as "dscho") about contribution processes. The author is specifically asking whether similar functionality already exists in the Git ecosystem before proceeding further. The email is polite and shows awareness of community norms, though the actual technical implementation details are quite light at this stage.

This appears to be an early-stage idea rather than a concrete patch submission. The concept touches on several potentially sensitive areas - adding GitHub-specific features to core Git, introducing new UI components, and expanding Git's scope beyond its traditional version control role. These aspects would likely need significant discussion about scope and maintenance before proceeding. The author seems open to feedback and guidance based on the tone of the email.
