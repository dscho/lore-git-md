Feature patch adding OAuth2 authentication support to `git send-email`. This implements SMTP bearer authentication (OAUTHBEARER and XOAUTH2) since these mechanisms aren't supported by Perl's Authen::SASL module. The patch provides direct implementations following the relevant RFCs (5801 and 7628) with proper TLS requirements and error handling.

The change enables using `git send-email` with OAuth2 providers like Gmail and Office 365 when configured with a credential helper that can supply bearer tokens (like git-credential-oauth). The documentation is updated to explain the new authentication options and their requirements (TLS encryption and token passing via password field).

The implementation looks thorough, with proper RFC citations, test coverage (as evidenced by the Tested-by tag), and clean handling of the authentication flow including the required failure case handling. The v2 revision fixed some formatting issues and added the missing documentation changes that were omitted in v1. This appears ready for review as a useful feature for users needing OAuth2 support with email sending.
