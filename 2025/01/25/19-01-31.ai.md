Feature patch adding OAuth bearer authentication support to `git-send-email`. This implements SMTP AUTH for OAUTHBEARER and XOAUTH2 mechanisms, which are not supported by Perl's Authen::SASL module. The patch adds new functions to generate and handle these authentication types manually, with proper TLS enforcement and error handling per RFCs 5801 and 7628.

Key technical details:
- Adds `generate_oauthbearer_string()` and `generate_xoauth2_string()` helper functions that format the authentication strings according to protocol specs
- Implements `smtp_bearer_auth()` to handle the SMTP AUTH command sequence, including required TLS checks and error handling
- Updates documentation to specify the new auth types and their requirements (TLS mandatory, token via password/credential helper)
- Shows example configurations for Gmail and Office 365 integration
- Requires companion changes to git-credential-oauth helper (referenced in commit message)

The implementation appears thorough, with:
- Clear RFC references for protocol details
- Proper error handling including dummy request on auth failure
- Documentation updates matching the code changes
- Tested-by from the git-credential-oauth maintainer
- Clean v2 revision fixing formatting and minor code issues from v1

This enables OAuth integration with major email providers while working around Perl module limitations, though it does create a dependency on proper credential helper configuration to supply the bearer tokens.
