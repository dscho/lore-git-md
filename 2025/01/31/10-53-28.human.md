Test expansion in the atomic push exit code series. This is the fourth patch in Patrick Steinhardt's v4 series addressing how Git handles exit codes during atomic pushes. The patch adds two new test cases to t5548-push-porcelain.sh that verify porcelain output formatting for both regular and atomic pushes.

The first test case exercises a non-atomic push with mixed operations (update, delete, create) including a deliberately failing non-fast-forward update. The second verifies forced atomic push behavior with similar operations. Both tests carefully check the porcelain output format and final ref states, continuing the series' pattern of thorough test coverage before implementing the core protocol changes.

This continues the series' methodical approach of first modernizing and expanding test coverage before modifying the core push behavior. The new tests follow the established pattern of the previous test refactoring patches, using the improved setup infrastructure from earlier in the series.
