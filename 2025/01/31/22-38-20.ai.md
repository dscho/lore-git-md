Maintainer follow-up on ref format reinitialization fix.

Junio C Hamano responds to Patrick Steinhardt's patch that prevents `GIT_DEFAULT_REF_FORMAT` from overriding an existing repository's ref storage format during reinitialization. While agreeing with the core fix that prevents repository corruption, Junio suggests adding a warning message when the environment variable is ignored, rather than silently dropping the request. He provides an example implementation showing how this warning could be structured in `setup.c`.

The email also hints at potential future work around automatic ref backend migration (via `git ref migrate`), though acknowledges the current conservative approach is correct as a first step. This follows the established consensus from earlier reviews that preserving existing configurations during reinitialization is the right solution for now. The discussion remains focused on the ref format portion (patch 2/3) of Patrick's series, which already has maintainer approval for the core behavior change.
