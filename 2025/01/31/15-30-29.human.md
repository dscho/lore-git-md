Refactoring patch in preparation for new `--revision` clone feature.

This is the first of six patches preparing `builtin/clone.c` for a new `--revision` option that will allow cloning a single specific commit. The patch reduces global variable usage by moving the `builtin_clone_options` struct and related variables into `cmd_clone()`'s scope. This cleanup affects numerous clone options including progress reporting, shallow clone controls, submodule handling, and more.

The changes are mechanical but extensive - nearly 200 lines modified to relocate variables and initialize them properly. The patch maintains all existing functionality while making the code more modular. This groundwork will make it easier to add the new `--revision` feature in subsequent patches while keeping the codebase maintainable.

As part of a well-structured series, this initial refactoring shows careful attention to code organization before introducing new features. The changes are focused and don't appear to introduce any behavioral differences, just better encapsulation of the clone command's implementation details.
