Test infrastructure patch converting the example decorate test to the Clar framework, part of Seyi Kuforiji's v2 series modernizing unit tests under Patrick Steinhardt's mentorship. This follows the established pattern of renaming the test file (t-example-decorate.c → u-example-decorate.c) and restructuring it into discrete test functions with explicit initialize/cleanup hooks.

The conversion introduces `test_example_decorate__initialize()` to set up test objects and `test_example_decorate__cleanup()` to clear decorations between tests, eliminating dependencies between test cases. The original test operations (add, readd, lookup, loop) are preserved as separate Clar test functions (`test_example_decorate__add` etc.) using Clar assertion helpers (`cl_assert_equal_p`). A global `test_vars` struct holds the test state.

Key technical changes include replacing custom test assertions with Clar equivalents, restructuring the test flow into independent functions, and maintaining all original test coverage while adding proper isolation. The build system updates (Makefile and meson.build) remove the old test program and add the new Clar suite. This matches the pattern seen in the series' other conversions (hashmap, strbuf, strcmp-offset) and addresses Patrick's v1 feedback about test isolation.
