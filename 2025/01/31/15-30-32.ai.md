This is a refactoring patch in the `git clone --revision` series, focusing on tag handling simplification. The change moves the tags refspec addition earlier in the clone process by appending `TAG_REFSPEC` to `remote->fetch` before calling `refspec_ref_prefixes()`, rather than handling tags separately in `wanted_peer_refs()`. 

The key technical changes are:
1. Removes tag-specific handling from `wanted_peer_refs()` by eliminating the `tag_refspec` variable and related fetch map processing
2. Adds tags refspec earlier in `cmd_clone()` when either `option_tags` or `option_branch` is set
3. Explicitly sets `option_tags = 0` for `--mirror` clones since they already handle all refs including tags
4. Maintains the same behavior while reducing code duplication and simplifying the control flow

The patch continues the series' trend of cleaning up clone internals in preparation for the `--revision` feature, with this change specifically streamlining how tag refs are processed. The diff shows a net reduction of 16 lines while preserving all functionality.
