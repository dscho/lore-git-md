Test infrastructure patch in the ongoing unit test conversion to Clar framework. This is Patrick Steinhardt's review of Seyi Kuforiji's patch converting the decoration test (formerly t-example-decorate.c to u-example-decorate.c), part of a 4-patch series modernizing various unit tests.

The review focuses on commit message improvements and test structure. Patrick suggests:
1. Dropping redundant commit message text about test functions being standalone
2. Adding explanation of Clar's initialize()/cleanup() hooks that run around each test
3. Noting the change to make tests fully independent (recreating setup in each rather than relying on previous test state)

Technical notes for future reference:
- Tests verify decoration operations (add/readd/lookup/loop) with both NULL and non-NULL values
- Global test_vars struct holds test objects and decoration state
- initialize() creates test objects (one/two/three) via lookup_unknown_object()
- cleanup() calls clear_decoration()
- Review suggests moving initialize/cleanup to top of file for visibility
- Minor style nits: using cl_assert_equal_p() more consistently, removing unnecessary braces

The conversion maintains all original test coverage while adopting Clar framework's patterns. Patrick indicates the test could be more thorough in verification but that's pre-existing, not introduced by this conversion. The review is generally positive with minor polish requested before integration.
