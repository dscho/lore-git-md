This is a refactoring patch series introducing generic hash context wrappers, building on prior discussions about hash algorithm handling. The series aims to simplify hash operations by storing the algorithm in the context structure itself, eliminating the need to track it separately in calling code.

The 4-patch series makes significant changes to Git's hash infrastructure. It first converts the hash context from a typedef to a proper structure, then removes the typedef entirely. The core change introduces generic wrapper functions (`git_hash_update`, `git_hash_final_oid`) that use the algorithm stored in the context, making call sites cleaner. Finally, it updates numerous callers across the codebase to use these new wrappers.

The changes touch 23 files with 224 insertions and 201 deletions, showing this is a wide-ranging refactoring affecting many subsystems. The patch appears technically sound, building on two prior discussions (referenced as [1] and [2]) about hash algorithm handling. The series is based on recent master (3b0d05c) and incorporates tb/unsafe-hashtcleanup work.
