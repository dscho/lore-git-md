Test modernization patch in the atomic push error propagation series. This is the first of eight patches in Patrick Steinhardt's v4 series, which modernizes test scripts by moving heredocs into test bodies to match current Git coding style. The changes are purely stylistic - relocating test expectations and setup data from global scope into the relevant test cases.

Eric Sunshine provides a minor review note suggesting using `\EOF` rather than `EOF` for non-interpolated heredocs to fully match modern style, but acknowledges this isn't worth a reroll on its own. The patch appears clean and straightforward, part of the series' broader effort to improve test infrastructure before implementing the core atomic push fixes.

The changes affect t5504-fetch-receive-strict.sh, moving three heredocs containing test expectations and a broken commit object into their respective test bodies. This follows Git's current preference for keeping test data tightly scoped to where it's used.
