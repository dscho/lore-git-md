This is a follow-up review in the bugfix series addressing repository reinitialization issues. Junio C Hamano agrees with Patrick Steinhardt's patch that prevents `GIT_DEFAULT_REF_FORMAT` from overriding existing repository formats during reinitialization, but suggests adding a warning when the environment variable is ignored.

The review acknowledges the patch's core fix - only applying environment-specified formats for new repositories or when no format exists - as the right approach to prevent repository corruption. However, Junio proposes a small enhancement: showing a warning when users attempt to change formats during reinitialization, making the silent ignore more visible. He provides a code snippet showing how this warning could be implemented.

While approving the current solution as better than risking corruption, the review hints at a potential future direction where Git could automatically migrate between ref backends rather than just rejecting format changes. The discussion shows consensus on the immediate fix while leaving room for more sophisticated handling of format changes in the future.
