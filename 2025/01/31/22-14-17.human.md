Test modernization converting hashmap tests to Clar framework. This is the first patch in Seyi Kuforiji's 4-part series (v2) that moves unit tests to the new Clar testing system under Patrick Steinhardt's mentorship. The patch renames t-hashmap.c to u-hashmap.c and rewrites the test cases to use Clar's assertion macros (cl_assert_*) while maintaining all existing test coverage of hashmap operations (put/get/remove/iterate) in both case-sensitive and case-insensitive modes.

The conversion follows established patterns seen in other Clar test conversions, with test cases now organized as standalone functions (test_hashmap__replace_case_sensitive, test_hashmap__get_case_insensitive, etc.) rather than using the old test-lib macros. Build system files (Makefile and meson.build) are updated to reflect the old test's removal and new Clar suite addition. The patch appears technically sound, having incorporated feedback from Patrick's review of v1, and maintains identical test coverage while adopting the new framework's style.
