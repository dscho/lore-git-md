Test modernization patch in the atomic push exit code propagation series. This is the first of eight patches in v4 of the series, focusing on test cleanup in t5504-fetch-receive-strict.sh. The change moves heredoc declarations inside test bodies to match modern Git test style, improving readability and maintainability. The patch relocates three heredocs: two containing expected push output patterns and one with a deliberately broken commit object used for testing. This is purely mechanical refactoring that doesn't affect test behavior - the same assertions are made, just with the test data colocated with the test logic. The changes align with the series' broader goal of improving test reliability around push error handling, though this particular patch is preparatory work rather than directly related to the atomic push fixes.
