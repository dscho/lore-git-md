This is a security-related RFC patch proposing a warning about the insecure nature of `git-credential-store`.

The patch adds a warning message that appears when users are about to enter a password while using the `store` credential helper, which saves credentials unencrypted on disk. The warning suggests consulting `gitcredentials(7)` for more secure alternatives. The author chose to show this warning before password entry rather than after, to ensure users see it before exposing their credentials, though they acknowledge this is still under discussion.

The implementation adds the warning in `credential.c` and updates several test cases to expect this new warning message. The patch is marked as RFC (Request For Comments) and the author notes some tests are currently failing, indicating this is still a work in progress. The warning text includes a reference to both the manpage and an online resource for finding alternative credential helpers.

This appears to be a well-intentioned security improvement, though as an RFC it's seeking feedback on both the approach and implementation details before being finalized. The patch touches core credential handling code, so reviewers will likely want to carefully consider the user experience implications of the warning timing and frequency.
