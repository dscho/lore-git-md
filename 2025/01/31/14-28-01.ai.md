Test modernization patch in the atomic push error propagation series. This is a minor style cleanup in t5504-fetch-receive-strict.sh, moving heredocs into test bodies to match modern Git test conventions. The changes were originally made by Patrick Steinhardt as part of preparatory work for the atomic push fixes.

The patch relocates three heredocs that were previously defined outside test bodies into their respective test sections. Eric Sunshine notes two could be further modernized by using `\EOF` instead of `EOF` since they don't interpolate variables, though considers this too minor to warrant a reroll. The third heredoc correctly keeps `EOF` as it contains variable interpolation.

This change is purely stylistic and doesn't affect test functionality. It's part of the broader test infrastructure improvements that preceded the core atomic push fixes in the series. The modifications touch only t5504-fetch-receive-strict.sh, moving expected output definitions and a test commit message into their proper test sections while maintaining identical content.
