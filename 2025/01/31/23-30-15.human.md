CI infrastructure fix for Coverity job. Jeff King spots a missed case in Patrick Steinhardt's recent CI modernization series (currently in 'next'). The series switched GitHub Actions to use `CI_JOB_IMAGE` instead of the `distro` variable, but the Coverity job wasn't updated to match. This causes the build to fail there due to missing curl installation. The fix is straightforward - a one-line change to the Coverity workflow file to use the new variable name. Jeff notes this appears to be the only remaining instance needing this update. The patch is small and clearly motivated, addressing a concrete issue introduced by the broader CI changes.
