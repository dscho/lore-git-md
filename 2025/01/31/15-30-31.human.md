Refactoring patch in the `git clone --revision` series. This is the third patch in v4 of a 6-part series preparing the new `--revision` feature by cleaning up `builtin/clone.c`.

The patch simplifies the `wanted_peer_refs()` function, which maps server refs to local clone refs. The main changes are:
1. Consolidates duplicate refspec handling code paths for single-branch vs. normal clones
2. Moves tag fetching logic to a single location with clearer comments
3. Improves memory management by tracking refs to free in a dedicated variable

The changes are purely internal - no user-visible behavior changes. The refactoring appears well-executed, reducing complexity while maintaining functionality. This groundwork will support the upcoming `--revision` feature by making the ref mapping logic more maintainable.
