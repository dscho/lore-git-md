The key addition is a `--revision` flag that lets users clone and check out a specific commit or tag directly, without creating any remote-tracking branches. This is particularly useful for CI systems that need a minimal clone containing just one revision's data. The implementation detaches HEAD and avoids setting up fetch refspecs, distinguishing it from `--branch --single-branch` which maintains branch tracking.

The series shows careful attention to edge cases - it validates the revision exists, handles both refnames and raw commit hashes, works with `--depth` for shallow clones, and properly integrates with the existing clone machinery. The tests demonstrate thorough coverage of various usage scenarios including branches, tags, raw hashes, and bare repositories.
