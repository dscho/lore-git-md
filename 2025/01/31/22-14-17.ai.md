Test modernization converting hashmap tests to Clar framework. This is the first patch in Seyi Kuforiji's v2 series converting several unit tests to the Clar framework under Patrick Steinhardt's mentorship. The patch renames t-hashmap.c to u-hashmap.c and rewrites the test cases to use Clar's assertion macros (cl_assert*, cl_assert_equal_*) while maintaining all existing test coverage of hashmap operations (put/get/remove/iterate) in both case-sensitive and case-insensitive modes.

Key changes include:
- Replaces custom test assertions with Clar equivalents (e.g., check_pointer_eq → cl_assert_equal_p)
- Restructures tests into discrete functions (test_hashmap__replace_case_sensitive, test_hashmap__get_case_insensitive, etc.)
- Updates build system files (Makefile and meson.build) to reference the new u-hashmap.c filename
- Preserves all original test cases while adopting Clar's test organization
- Adds explicit test function names that better describe the operations being tested

The conversion follows the established pattern seen in other Clar test conversions, with Patrick having reviewed and approved the technical approach in previous iterations. This patch maintains identical test coverage to the original while modernizing the test infrastructure.
