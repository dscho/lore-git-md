Test infrastructure series converting unit tests to Clar framework. This is the second version of Seyi Kuforiji's 4-patch series that converts hashmap, decorate, strbuf, and strcmp-offset tests to use the Clar testing framework, mentored by Patrick Steinhardt. The series is part of Git's ongoing test modernization effort.

The patches rename test files with a u-*.c convention (e.g. t-hashmap.c → u-hashmap.c) and completely rewrite them for Clar's organization while maintaining all test coverage. Each conversion includes updates to both Makefile and meson.build. The v2 changes focus on improving commit messages and making small code refinements based on Patrick's review feedback.

Key improvements in this revision include:
- More precise test function names in the strbuf tests (e.g. "add_multi_char" → "append_char")
- Better documentation of test initialization/cleanup in the decorate tests
- Added a new empty-string test case for strcmp-offset
- Consistent use of Clar assertion macros throughout

The series appears well-crafted and ready for integration after addressing Patrick's final suggestion to document the new strcmp-offset test case. These conversions follow established patterns from previous Clar migrations and maintain identical test coverage (plus one additional case) while improving test isolation and framework consistency.
