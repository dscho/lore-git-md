Test refactoring patch in the atomic push exit code series. This is the third patch in v4 of the series, continuing the test modernization work before implementing the core protocol changes. The patch restructures t5548-push-porcelain.sh to improve test isolation and reduce setup duplication. Key changes:

1. Adds `test_when_finished` calls to automatically reset the upstream repository after each test case using the new `setup_upstream()` helper from patch 2/8. This ensures clean state between tests.

2. Modifies the initial workbench state to include branches `baz` and `next` at commit A, eliminating redundant setup steps in individual tests. The commit message notes this reduces branch setup operations.

3. Moves pre-receive hook management directly into the test cases that need it, rather than having separate setup/cleanup steps. The hook now gets created and removed via `test_when_finished` in the single test that exercises hook rejection.

4. Updates several push tests to use the new `git -C` syntax rather than subshells, and adjusts their expected outputs to match the modified initial state. The test scenarios themselves remain the same - they still verify porcelain output formatting, atomic push failures, hook rejection, and non-fast-forward cases - but with cleaner isolation between them.

The changes are purely structural improvements to support the upcoming protocol changes, with no behavior modifications to the actual push functionality being tested. The patch continues the series' pattern of modernizing test infrastructure before altering core behavior.
