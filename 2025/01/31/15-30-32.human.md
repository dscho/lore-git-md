This is a refactoring patch in a series preparing for a new `--revision` clone option. It simplifies tag handling in the clone process by moving the tags refspec earlier in the fetch process.

The change modifies how tags are processed during cloning by adding the tag refspec to the remote's refspec list upfront, rather than handling it separately later in `wanted_peer_refs()`. This eliminates some redundant processing and simplifies the code by removing the special-case tag handling path. The patch also ensures `--mirror` clones (which already handle all refs including tags) properly skip the separate tag processing.

The implementation is clean and focused - it removes 16 lines while adding just 7, mostly by consolidating the tag handling logic. The change maintains all existing behavior while making the code more straightforward. This appears to be solid preparatory work for the upcoming `--revision` feature, continuing the series' trend of simplifying the clone internals.
