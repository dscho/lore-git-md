Refactoring patch in a hash algorithm infrastructure series.

This is the second patch in Patrick Steinhardt's 4-part series to improve Git's hash algorithm infrastructure. Following the first patch's conversion of `git_hash_ctx` from a union to a structure, this change removes the `typedef` for `git_hash_ctx` entirely, making it an explicit `struct git_hash_ctx` throughout the codebase. This aligns with Git's general avoidance of typedefs for structures.

The patch is purely mechanical, updating all 22 affected files to use the struct syntax instead of the typedef. The changes are straightforward replacements with no behavior modifications. This continues the series' goal of cleaning up hash algorithm internals while maintaining identical functionality. The widespread changes touch core areas like object handling, diffing, and pack operations, but the risk is low since it's just syntax changes with no logic impact.

Reviewers should verify the mechanical nature of the changes, particularly in performance-sensitive areas like bulk-checkin and pack operations, though no regressions are expected. The patch maintains the series' clean separation of infrastructure improvements.
