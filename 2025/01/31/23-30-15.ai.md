This is a CI/build system patch that fixes a regression in the Coverity job after Patrick Steinhardt's CI modernization series. The patch addresses a specific fallout from the series' switch from using `$distro` to `CI_JOB_IMAGE` for dependency installation.

Jeff King identifies that the Coverity job in GitHub Actions was missed when the main workflow was updated to use `CI_JOB_IMAGE` instead of the `distro` variable. Without this change, the job fails because it can't properly install dependencies (notably curl) during setup. The fix is straightforward - updating the environment variable name in the Coverity workflow file to match the new convention.

The patch is narrowly scoped, touching only the `.github/workflows/coverity.yml` file with a one-line change. Jeff notes he verified no other instances of the old `distro:` syntax remain in the codebase. This appears to be a clean follow-up to the larger CI modernization effort that's currently progressing through the integration branches (now correctly in 'next' after initial confusion about its status). The fix maintains consistency with the containerization improvements from Patrick's series while ensuring the Coverity job continues to function.
