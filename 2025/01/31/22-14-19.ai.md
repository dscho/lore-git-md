This is part of Seyi Kuforiji's v2 series converting unit tests to the Clar framework, specifically focusing on the strbuf test conversion. The patch follows the established pattern of renaming the test file (t-strbuf.c → u-strbuf.c) and restructuring the test cases as independent Clar test functions.

The conversion maintains all original test coverage for strbuf operations (initialization, character/string addition, and appending) while adopting Clar's conventions. Key changes include:
- Replacing test-lib.h assertions with Clar's cl_assert_* helpers
- Splitting the monolithic test function into discrete test cases (test_strbuf__static_init, test_strbuf__add_single_char, etc.)
- Simplifying the assert_sane_strbuf helper to use Clar assertions
- Updating build system files (Makefile and meson.build) to reference the new u-strbuf.c

The patch appears technically sound, following the same patterns as previous conversions in the series. It maintains all original test coverage while improving test isolation through the Clar framework's function-per-test organization.
