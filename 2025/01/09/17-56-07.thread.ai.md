Git for Windows v2.48.0-rc2 release announcement from Johannes Schindelin (Dscho). Updates core components: Git to v2.48.0-rc2, cURL to v8.11.1, MinTTY to v3.7.7. Key changes include defaulting to native HTTPS transport backend (replacing OpenSSL) for new installations, which may impact Windows-specific performance. Fixes: installer now properly blocks on unsupported Windows versions (7/8) and resolves cache credential helper's spurious "unknown error" messages that caused authentication issues. Provides SHA-256 checksums for all distribution formats (installers, portable, MinGit) across 32-bit, 64-bit, ARM64 architectures. Dscho requests community testing due to significant changes made post-holiday period, indicating this RC may have more substantial updates than typical. Release candidate status implies potential undiscovered issues remain.
