This is a refactoring patch in Jeff King's combine-diff series, specifically addressing memory management improvements. The patch converts a `strbuf` field in the `combine_diff_parent` struct to a simple string pointer, since the buffer was only ever used to store a single string without any subsequent manipulation. 

The change fixes a subtle initialization bug where subsequent parent structs weren't properly initializing their `strbuf` fields, though the existing code happened to work due to the strbuf implementation's resilience. By switching to a plain pointer, the initialization becomes simpler and more correct by default - zeroing the struct (which was already happening) now properly initializes the path pointer to NULL.

Junio Hamano enthusiastically approves the change, noting his general discomfort with arrays of strbufs. This patch continues the series' trend of simplifying memory management while maintaining behavior, with the added benefit of fixing a minor technical violation of the strbuf API that could have caused problems if the implementation details changed. The change is particularly clean because it removes unnecessary strbuf overhead for a use case that didn't actually need its features.
