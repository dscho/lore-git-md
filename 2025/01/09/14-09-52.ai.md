Test modernization patch finalizing the conversion of hash algorithm tests from legacy format to the clar framework. This v3 iteration addresses the last remaining administrative details (code formatting standards) from Junio Hamano's review of v2. The patch represents the completed work to:

1. Rename t-hash.c → u-hash.c and integrate it between u-ctype and u-strvec in both Makefile and meson.build
2. Convert all test cases to individual clar test functions (test_hash__empty_string, test_hash__single_character, etc.)
3. Replace custom test assertions with clar's cl_assert macros
4. Properly manage resources (strbuf allocations) within each test
5. Maintain identical test coverage of hash algorithms while following clar conventions

The conversion follows the now-standard pattern for test modernization in Git, with all technical decisions (like using direct function definitions) having been settled in prior discussion. Seyi Kuforiji's implementation has been reviewed by Patrick Steinhardt (as mentor) and Junio Hamano, with the latter's style nits now addressed in this version. The patch is ready for merge as part of Git's ongoing test infrastructure improvements.
