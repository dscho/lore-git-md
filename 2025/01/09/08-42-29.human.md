Refactoring patch in the combine-diff series, focusing on memory management.

This is the fourth patch in a 14-part series cleaning up Git's combine-diff implementation. It simplifies how parent paths are stored in the `combine_diff_parent` struct by replacing a `strbuf` with a simple string pointer. The change addresses a subtle initialization bug where strbufs for non-0th parents weren't properly initialized, though the code happened to work due to strbuf's resilience.

The patch demonstrates careful attention to detail - the author notes they're maintaining the same logical behavior while simplifying the implementation. The change reduces code complexity (30 lines changed, mostly deletions) and makes the need to check `combined_all_paths` at each use site unnecessary, since a NULL pointer now cleanly indicates absence. This appears to be a well-considered improvement that fits naturally into the larger refactoring effort.
