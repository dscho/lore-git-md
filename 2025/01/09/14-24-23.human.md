Build system fix addressing a parallel-make race condition in version file generation.

Johannes Schindelin identifies and fixes a race condition in `GIT-VERSION-GEN` that surfaces when building documentation in parallel with `make -j2`. The issue stems from recent changes where the script now generates version-dependent configuration files for documentation builds, creating contention when multiple processes try to write temporary files simultaneously. The problem is particularly acute on Windows due to slow POSIX emulation layers, causing actual CI failures in Git for Windows builds.

The patch modifies the script to use process-specific temporary filenames (appending `$$` instead of `+`), preventing collisions between parallel invocations. This also incidentally fixes a Windows compatibility issue where `+` isn't a valid filename character. The change is presented as a targeted workaround rather than a full architectural solution, acknowledging the immediate need during the v2.48.0 release cycle.

The fix is minimal (4-line change) and well-explained, with clear motivation including links to failed CI runs. While the underlying issue appears to be a consequence of recent Meson build system integration, this patch provides a reliable stopgap solution.
