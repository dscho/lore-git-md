This is a design discussion about the OS version capability feature, specifically about how to structure the format options for the version string output.

Junio Hamano responds to Usman Akinyemi's proposal to use predefined format options ("full", "short", "medium") for the OS version output. Junio suggests simplifying this to just two levels of control: (1) a minimal privacy-conscious option (just OS name like "Linux") or no version at all, and (2) an exact string specified by the user. 

He argues against more elaborate format controls, noting that organizations that need strict version string control (like corporations) can already enforce their own strings through configuration management, making intermediate format options unnecessary. This continues the thread's theme of simplifying the interface while maintaining flexibility for different use cases.

The response maintains Junio's previously expressed concerns about version string standardization while acknowledging others might have different opinions. This email doesn't introduce new technical elements but rather provides rationale for keeping the design simple, building on the earlier agreement to move away from placeholder-based formatting.
