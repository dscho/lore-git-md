Refactoring patch in the combine-diff series, focusing on memory allocation patterns. This patch (10/14) removes the public declaration of `combine_diff_path_size()` after ensuring all callers now use the preferred `combine_diff_path_new()` constructor. The change inlines the size calculation directly into the constructor and reorganizes the math to reuse the intermediate parent length calculation, making the code both more maintainable and slightly more efficient.

Key technical changes:
- Removes `combine_diff_path_size()` macro from diff.h
- Moves size calculation logic into `combine_diff_path_new()`
- Uses `st_mult` and `st_add4` helpers for safe arithmetic
- Reuses `parent_len` calculation for both allocation and memset
- Maintains identical memory layout and behavior
- Follows the series' pattern of simplifying interfaces while preserving functionality

The patch continues the series' trend of methodical improvements to combine-diff's memory management, with Jeff King (the original author of many combine-diff optimizations) now cleaning up his own earlier interfaces. The change is small but meaningful, eliminating a public API that could encourage incorrect usage patterns.
