Refactoring patch introducing a constructor for the combine_diff_path struct.

This is the second patch in a 14-part series cleaning up Git's combine-diff implementation. It introduces a new `combine_diff_path_new()` constructor function to simplify allocation and initialization of the `combine_diff_path` struct, which has a complex variable-size layout due to containing both a path string and a variable-length parent array.

The new constructor handles all the tricky pointer arithmetic and zero-initialization that was previously done manually at each call site. This makes the code more maintainable and ensures consistent initialization of all fields. The patch notes this will enable simplifications in future patches by guaranteeing parent arrays are always zero-initialized.

The change touches several files (combine-diff.c, diff-lib.c, diff.h) but is straightforward, converting manual allocations to use the new helper. The author acknowledges some edge cases (like path_appendnew's memory reuse optimization) that aren't yet handled by this approach, leaving those for future work. This appears to be a well-considered incremental improvement that makes the code more robust while setting up for further cleanups in the series.
