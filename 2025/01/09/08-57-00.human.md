Final patch in a refactoring series improving combine-diff's list handling. This 14th patch from Jeff King completes the series by making list tail-passing more explicit in the tree-diff code. The change replaces the need for callers to create fake list heads with a cleaner pointer-to-pointer approach, though it requires using a "three-star pointer" due to recursion.

The patch addresses two specific issues with the current implementation: the awkwardness of creating fake structs as list heads, and the unclear semantics of the tail pointer being passed around. Jeff considered but rejected using Git's generic list_head API, finding it made the code harder to read and maintain type safety.

This continues the series' pattern of simplifying interfaces while preserving behavior, following earlier patches that improved memory management, initialization patterns, and code clarity. The change affects several functions in tree-diff.c, modifying how paths are emitted and tracked through the diff process. As with previous patches, the implementation maintains all existing functionality while making the code more maintainable.
