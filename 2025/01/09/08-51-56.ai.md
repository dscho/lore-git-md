This is a refactoring patch in the ongoing combine-diff memory management series. Patch 11/14 simplifies the public API of `diff_tree_paths()` by removing the awkward list-tail parameter that forced callers to set up a fake head struct. Instead, the function now always returns a new list, keeping the fake head as an internal implementation detail.

The change affects three files: `combine-diff.c` updates its caller to use the new return value rather than passing in a fake head, `diff.h` updates the function prototype, and `tree-diff.c` moves the fake head initialization inside the function. The internal `ll_diff_tree_paths()` still requires the tail parameter, but this is now hidden from callers.

This continues the series' pattern of cleaning up interface oddities while maintaining the same. The change is straightforward and mechanical, with Jeff King (the original author of much of this code) carefully preserving all existing behavior while making the API more intuitive. The patch follows the series' established approach of methodical improvements to memory management and interface clarity.
