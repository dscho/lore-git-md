This is a refactoring patch in Jeff King's ongoing combine-diff series, reviewed by Junio Hamano. It converts a `strbuf` field in the `combine_diff_parent` struct to a simple string pointer, since the buffer was only ever used to store a single string. 

Junio enthusiastically approves the change, noting his general discomfort with arrays of `strbuf` structures. The patch also incidentally fixes a minor initialization bug where subsequent parent structs weren't properly initializing their `strbuf` fields, though the existing code happened to work due to `strbuf`'s resilience.

This continues the series' theme of simplifying memory management in the combine-diff code. The change reduces overhead while maintaining identical functionality, and Junio's quick positive review suggests it's a straightforward improvement that fits well with the overall refactoring direction.
