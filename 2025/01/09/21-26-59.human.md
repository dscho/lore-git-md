This is a documentation patch addressing credential storage practices. M Hickford adds a new section to `git-credential-cache.txt` warning users that the cache helper is unsuitable for storing personal access tokens (PATs) long-term, since cached credentials disappear after timeout or daemon restarts. The patch notes that PAT users often face this issue, citing a Stack Overflow comment where users are confused about secure storage options. The new documentation suggests alternatives like persistent credential helpers or OAuth helpers instead. The change is straightforward and well-motivated by observed user confusion, though it doesn't propose any code changes—just clearer guidance for a common pain point.
