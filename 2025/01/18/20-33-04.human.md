This is a security-related follow-up in the ongoing discussion about credential exposure in Git URLs, specifically addressing personal access tokens (PATs) in the username field. Mirth Hickford responds to Brian Carlson and Junio Hamano's concerns about platform-specific detection logic by proposing a different approach: encouraging GitHub to stop accepting PATs in the username field altogether.

The email notes that this behavior is undocumented on GitHub's part, suggesting that usage should naturally decline over time. As a concrete action, Hickford has edited a StackOverflow answer that previously recommended this insecure practice, helping to reduce its propagation in the wild.

This represents a pragmatic shift in the discussion - rather than trying to detect and warn about the insecure pattern in Git itself, the focus moves toward eliminating the pattern at its source (GitHub) and correcting misinformation in developer resources. The tone suggests acceptance of the technical limitations raised earlier in the thread while still working toward improved security outcomes.
