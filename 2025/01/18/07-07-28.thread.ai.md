Git plugin system proposal (GpluginLoader) - an early-stage RFC for a platform-independent C/C++ plugin architecture that would allow plugins to access Git repository metadata (READMEs, profiles) through a new API (git-plugin-api.[ch]). Currently an external GitHub project rather than a patch series targeting Git core. Lacks key technical details about integration points with Git's codebase/build system, security model, version compatibility, or performance characteristics. Motivation vaguely cites "workflow differences" without specifying concrete problems unaddressed by existing extension mechanisms (hooks, subcommands). Implementation shows basic API definitions but no actual plugin loading infrastructure or demonstrated use cases. Would require substantial design discussion about architectural fit with Git's maintenance model before consideration for inclusion.
