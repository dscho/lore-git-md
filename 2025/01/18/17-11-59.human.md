This is the final patch in a refactoring series that cleans up memory management in Git's ref-filter subsystem. The series has been moving state management from format-wide storage to per-atom structs, and this patch completes that work by removing the now-unused `ref_format_clear()` and `ref_format_init()` functions.

The changes are straightforward - since the functions no longer do any meaningful memory management (they were previously just resetting the format state), they can be safely removed. The patch updates all callers (in branch, for-each-ref, tag, and verify-tag commands) to stop calling these functions. The diff shows the simple removal of these calls and the code that implemented them.
