Thread summary:

Jörg Sommer from the KAS project is investigating Git worktree behavior in Docker containers where repositories are mounted at fixed paths. The core problem involves path resolution when the common directory (from `git rev-parse --common-dir`) and worktrees are mounted at different container paths (/repo and /repo-common respectively). The current approach modifies the .git file to point to the relocated common directory, but questions remain about handling additional worktree metadata files (*commondir* and *gitdir* in .git/worktrees/*). This touches Git's internal worktree path resolution mechanisms and raises questions about the safety and completeness of path rewriting approaches in containerized environments. No solutions or alternatives have been proposed yet in the thread.
