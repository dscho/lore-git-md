This is a regular announcement of the Git Rev News publication, a monthly digest of Git project activity.

Christian Couder shares that the 118th edition of Git Rev News is now available online, covering December 2024's Git development highlights. The newsletter team acknowledges Štěpán Němec for his contributions to this edition.

The announcement follows the project's standard format, with Christian and co-editors Jakub, Markus, and Kaartic signing off. They also note that planning for the next edition is already begun, with an open GitHub issue (#743) where community members can suggest content.

Git Rev News serves as a valuable resource for those who want to stay informed about Git development without closely following the mailing list. Each edition typically summarizes important discussions, new features, and notable changes in the Git ecosystem.
