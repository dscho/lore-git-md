This is a platform compatibility fix for the Git test suite's build system. The patch addresses an issue where the "check-meson" target fails when using Dash (a common /bin/sh implementation) due to its use of non-portable process substitution syntax. Patrick Steinhardt's solution replaces this with temporary file operations, making the target work across different shell implementations.

The problem was specifically observed in Debian's build environment, where Jonathan Nieder confirmed the fix resolves the '/bin/sh: 10: Syntax error: "(" unexpected' error. The changes are minimal - just 12 lines modified in t/Makefile plus a .gitignore addition for the new temporary files.

This appears to be a straightforward and well-justified fix, part of a larger series (positioned as patch 11/12) that presumably deals with meson build system compatibility. The patch has already received a positive Tested-by from a knowledgeable contributor, suggesting it's ready for inclusion.
