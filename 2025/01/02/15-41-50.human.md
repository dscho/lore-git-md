Build system fix for meson compatibility with Dash shell. This is a follow-up to Patrick Steinhardt's patch that addressed unportable process substitution syntax in the "check-meson" test Makefile target, which was causing build failures in Dash environments (notably Debian's buildd). The fix replaces process substitution with temporary directory usage and includes corresponding .gitignore updates.

Jonathan Nieder confirms this resolves the specific syntax error ('/bin/sh: 10: Syntax error: "(" unexpected') he encountered in Debian builds, providing a Tested-by tag. The change is minimal (12 lines across two files) and has been verified to solve the reported issue.

While part of a larger 12-patch series, this change stands independently as a clear build system portability improvement.
