This is a brief follow-up in the ongoing discussion about meson test execution portability issues. Jonathan Nieder confirms Junio Hamano's identification of the problematic patch series (from Patrick Steinhardt in December 2024) that introduced bash-specific process substitution syntax (`<(...)`) in the test comparison code. The issue affects shells like dash that don't support this syntax, causing the `check-meson` target to fail.

The email serves primarily to confirm the correct thread reference, with no new technical content beyond what was already established in the thread summary. The core issue remains unresolved - whether to rewrite the test comparison portably, document the bash dependency, or implement a workaround.
