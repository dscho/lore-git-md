This is a response in the thread about integrating alternative grep tools with Git.

Matěj Cepl clarifies a misunderstanding in Hongyi Zhao's initial proposal about replacing `git grep` with external tools like ugrep. He points out that `git grep` doesn't actually shell out to the system's `grep` command - it uses Git's own internal implementation with slightly different behavior. He also notes that trying to call hypothetical commands like `git-ug` directly wouldn't work unless such binaries actually existed in the user's PATH.

The response serves as a technical correction to the original proposal, highlighting that any integration of alternative grep tools would need to account for Git's current grep implementation being internal rather than external. This suggests the feature request would require more architectural changes than simply redirecting to external binary calls. The email doesn't take a position for or against the feature, but provides important technical constraints that would need to be considered in any implementation.
