Build system fix for meson compatibility with Dash shell.

This is a follow-up to Patrick Steinhardt's patch that fixes the "check-meson" target in the test Makefile to work with Dash. The original issue involved unportable process substitution syntax that caused build failures in environments using Dash (like Debian's buildd). The fix replaces process substitution with temporary directory usage.

The patch modifies both the Makefile and .gitignore, adding proper cleanup of temporary files. Jonathan Nieder confirms this resolves the specific syntax error ('/bin/sh: 10: Syntax error: "(" unexpected') he encountered in Debian builds and provides a Tested-by tag.

This appears to be a straightforward and well-justified platform compatibility fix. The change is minimal (12 lines modified across two files) and has already been verified to solve the reported issue. The patch is part of a larger series (position 11/12) but stands on its own as a clear improvement to build system portability.
