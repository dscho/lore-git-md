Andreas Schwab responds to Junio Hamano's observation about SHELL variables not propagating to sub-makes by pointing out that command-line options (including macro definitions like SHELL=/bin/dash) are actually passed to sub-makes through the MAKEFLAGS environment variable.

The email provides a key piece of information about makefile behavior that helps explain why the shell compatibility issue wasn't caught earlier - the SHELL setting wasn't being properly propagated as expected. This technical detail about MAKEFLAGS adds an important constraint for any proposed solution, as fixes will need to account for this behavior.
