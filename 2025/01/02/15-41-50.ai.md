This is a build system patch addressing shell compatibility in the meson test infrastructure, specifically for Dash shell environments. The patch follows up on Patrick Steinhardt's earlier fix that replaced unportable process substitution syntax in the "check-meson" Makefile target, which was causing build failures in Debian environments. The change uses temporary directories instead of process substitution and includes corresponding updates to .gitignore.

Jonathan Nieder has verified the fix resolves the specific syntax error ('/bin/sh: 10: Syntax error: "(" unexpected') in Debian builds and provided a Tested-by tag. The patch is part of a larger series (11/12) but stands independently as a clear improvement for build system portability. The technical scope is limited to meson test infrastructure and Dash shell support, with no outstanding issues remaining. This contributes to the broader meson build system integration work.
