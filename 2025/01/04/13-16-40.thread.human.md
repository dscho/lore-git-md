This thread documents a straightforward update to the `git-restore` manpage as part of Jean-Noël Avila's ongoing effort to standardize Git's documentation format. The initial patch converted the page to use consistent AsciiDoc synopsis formatting, wrapping options in backticks and standardizing placeholders, without changing any actual content. 

Patrick Steinhardt provided review feedback suggesting minor improvements: recommending the commit message use imperative mood and questioning whether renaming some placeholders from `A/B` to `refA/refB` might be misleading since they can accept object IDs, not just references. He also noted some paragraph reflows made changes harder to spot. The discussion remains focused on documentation presentation details, with no disagreement about the overall standardization effort. The patch author will likely address these points in a v2 while maintaining the core formatting changes that align with the project-wide documentation style conversion.
