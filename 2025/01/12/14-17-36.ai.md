Bugfix proposal for bare repository mirror HEAD handling regression introduced in Git 2.48.0. This email identifies the specific commit (b1b713f722) that changed behavior for mirrored bare repositories with multiple remotes, where fetching a second remote incorrectly overwrites the repository's HEAD symref to point to a non-existent branch (mariadb-4.x) rather than preserving the original (4.x). The analysis notes this differs from pre-2.48.0 behavior where HEAD remained unchanged after adding a second remote, and observes the new behavior doesn't properly set up refs/remotes/mariadb/HEAD either.

The proposed solution would distinguish between mirror and non-mirror remotes in bare repositories, only overwriting HEAD for true mirrors while setting remote-specific HEAD symrefs otherwise. The author notes uncertainty about non-bare mirror repositories but plans to submit a patch addressing the bare repo case. This builds on the thread's earlier reproduction case showing the HEAD resolution failure in `git describe` after multi-remote operations in mirrored clones.
