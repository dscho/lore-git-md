Bugfix confirmation regarding `git fetch` tag behavior in shallow clones. Bence Ferdinandy responds to Danila Manturov's report about tags not being fetched in shallow clones (a regression between Git 2.47.1 and 2.48.rc0) by pointing to commit 6c915c3f85 ("fetch: do not ask for HEAD unnecessarily") as the fix. This commit addressed an issue where unnecessary HEAD requests were interfering with tag fetching logic, particularly affecting shallow fetches against non-configured remotes. The response suggests the reported behavior should already be resolved in Git 2.48, implying this was an unintentional regression that was caught and fixed during the release cycle. The exchange provides useful context about how subtle changes in ref-prefix handling can impact tag fetching behavior.
