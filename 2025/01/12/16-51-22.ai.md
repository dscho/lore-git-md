Bugfix for HEAD handling in bare repositories with mixed mirror/non-mirror remotes. This patch addresses the regression introduced in b1b713f722 where bare repositories incorrectly assumed all remotes were mirrors, causing HEAD to point to non-existent branches when fetching from non-mirror remotes. The fix modifies the `set_head` logic in builtin/fetch.c to distinguish between mirror and non-mirror remotes in bare repos, only overwriting HEAD for true mirrors while properly setting remote-specific HEAD symrefs otherwise.

The changes involve adding a `mirror` parameter to `set_head()` and adjusting the logic to use a new `baremirror` condition that checks both repository type and remote mirror status. The patch includes two new test cases: one verifying that non-mirror fetches don't interfere with existing HEAD in bare repos, and another confirming proper remote HEAD handling in bare repositories. The tests demonstrate the fix works for the reported multi-remote scenario where HEAD was being overwritten incorrectly.
