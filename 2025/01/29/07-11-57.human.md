This is a build system optimization patch in Patrick Steinhardt's ongoing Meson refactoring series. It addresses unnecessary linking of libcurl across Git executables.

Currently, libcurl gets linked into all executables through the shared `libgit_dependencies` variable, even though only a handful of commands (like the HTTP remote helpers and IMAP send) actually need it. The patch makes this linking more precise by removing the global libcurl dependency and instead adding it only where explicitly required.

The changes touch several HTTP-related commands (`git-remote-http`, `git-http-fetch`, `git-http-push`, and their aliases) as well as `git-imap-send`, ensuring they still get the curl dependency they need. The patch appears well-scoped and follows the series' theme of cleaning up Meson build configuration - in this case eliminating unnecessary library linkages that could bloat binaries or cause potential symbol conflicts.

This is patch 4/11 in the series, continuing the focused technical improvements to the build system without changing runtime behavior. The change seems straightforward and aligns with standard build system best practices around minimal dependency specification.
