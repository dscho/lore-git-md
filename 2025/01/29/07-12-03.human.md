This is a refactoring patch in Patrick Steinhardt's ongoing Meson build system cleanup series (10/11). It fixes a naming collision where the `git` variable was being used for both the external Git executable (found via `find_program()`) and the built Git executable. The patch renames the built executable variable to `git_builtin` to avoid overwriting the external Git reference, allowing the removal of a redundant `find_program('git')` call in the documentation build configuration.

The change is straightforward and mechanical - it renames one variable and updates three references to it. This eliminates a minor inefficiency where Git was being looked up multiple times during the build process. The patch maintains all existing functionality while making the build configuration slightly cleaner and more explicit about which "git" is being referenced at each point.

This continues the series' pattern of focused, independent build system improvements. Like previous patches, it touches only meson.build files and removes a small bit of redundant configuration. The change appears uncontroversial and well-contained, though reviewers may want to verify it doesn't impact any platform-specific build scenarios.
