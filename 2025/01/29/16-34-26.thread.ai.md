Bug report about `PREFIX` environment variable behavior in system config lookup. Randall S. Becker reports that Git fails to respect the `PREFIX` environment variable when looking up system configuration files, instead using the build-time location (e.g. `/usr/local-ssl3.0/etc/gitconfig`). This contradicts documented behavior stating `${PREFIX}/etc/gitconfig` should be used. The issue is reproducible across multiple platforms (NSV and x86_64) and Git versions (2.47.1 and 2.45.1). The report includes clear reproduction steps and expected vs actual behavior, but no code analysis. The cross-platform reproducibility suggests this is a core behavior issue rather than platform-specific quirk. The documentation on git-scm.com appears correct while the implementation diverges.
