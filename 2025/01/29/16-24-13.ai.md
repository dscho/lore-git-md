This is a cover letter for a 2-patch series addressing memory leaks found via Meson builds. The series falls under both the "bugfix" and "CI/build system" categories, as it fixes memory management issues that only surfaced when using Meson's leak detection.

The cover letter notes an interesting divergence between Makefile and Meson builds - two memory leaks are caught by Meson that weren't detected with the traditional build system. While the author hasn't investigated why this difference exists, they're proactively fixing the leaks regardless.

The two patches address:
1. A leak in `unix-socket.c` when `chdir()` fails
2. A missing free of the remote default branch result in `scalar.c`

The changes are minimal (6 lines added, 2 removed across two files) but important for proper resource cleanup. The fact that these were caught by Meson suggests its leak detection may be more thorough than the Makefile-based approach, though the cover letter doesn't make this claim explicitly. The series builds on commit da898a5c645c in the main Git tree.
