This is a refactoring patch in Patrick Steinhardt's Meson build system improvement series, focusing on curl-related dependencies. It introduces a new `libgit_curl` dependency declaration to consolidate shared curl-related source files and linking requirements.

The patch simplifies the build configuration by creating a reusable `libgit_curl` dependency that bundles the common source files (http.c and http-walker.c) and curl linkage requirements. This replaces the previous pattern where these were repeated for each curl-dependent executable. The change affects several Git commands that use HTTP/FTP/IMAP functionality: git-remote-http(s), git-http-fetch, git-http-push, and git-imap-send.

Notable technical changes include:
- New `libgit_curl` declaration combining sources and dependencies
- Simplified executable declarations that now reference this shared dependency
- Cleaner handling of IMAP-send's conditional curl usage via ternary operator
- Removal of redundant `curl_sources` and `imap_send_dependencies` variables
- Maintained functionality while reducing code by 23 lines

The patch continues the series' pattern of mechanical but meaningful build system simplifications. It appears carefully implemented, with all curl-dependent commands properly updated to use the new shared dependency. The change should make future maintenance easier by having a single point of definition for curl-related build configuration.
