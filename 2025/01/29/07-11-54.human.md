This is a build system fix targeting Git's Meson configuration, part of Patrick Steinhardt's 11-patch series improving the Meson build. The patch corrects how Git's executable path (GIT_EXEC_PATH) is handled when runtime prefix is enabled.

Currently, the Meson build always uses an absolute path for GIT_EXEC_PATH, which can cause problems when runtime prefix is enabled since Git expects relative paths in this mode. The fix makes the path conditional on the runtime_prefix setting - using a relative path when runtime prefix is enabled (for proper binary location resolution) and keeping the absolute path otherwise.

The change is straightforward, moving the GIT_EXEC_PATH definition to be set after the runtime_prefix check and using the appropriate path format in each case. This aligns Meson's behavior with the Makefile implementation and ensures Git can properly locate its binaries when built with runtime prefix support.
