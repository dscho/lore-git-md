This is a build system cleanup patch in Patrick Steinhardt's ongoing Meson refactoring series (patch 7/11). It simplifies the list of required programs that Git checks for during the Meson build process on Windows.

The patch reduces the number of coreutils programs explicitly checked from seven (cat, cut, grep, sed, sort, tr, uname) to just three (cat, grep, sed). The rationale is that these tools typically come together as part of coreutils, so checking for one (cat) is sufficient to ensure the whole suite is available. This maintains the same Windows build-time PATH modification behavior while removing redundant checks.

The change is straightforward - just a single line in meson.build - and aligns with the series' goal of simplifying the build configuration. Since these tools are fundamental Unix utilities that Git depends on in many places, the reduced checking seems unlikely to cause issues while making the build setup slightly cleaner.
