This is a cover letter for a two-patch series fixing memory leaks found via Meson builds. The leaks weren't caught by Makefile-based builds, suggesting Meson's leak detection is more thorough in this case. The first fixes a leak in unix-socket.c when chdir() fails, while the second addresses a remote_default_branch() result leak in scalar.c. 

Patrick Steinhardt notes these were found while experimenting with memory leak sanitizers, though he hasn't investigated why Makefile builds didn't catch them. The changes are small (6 lines total) and straightforward - adding missing free() calls for error paths and function return values. 

The patches appear well-scoped and uncontroversial, fixing clear resource management issues. The Meson vs Makefile detection difference might warrant follow-up investigation, but these fixes stand on their own as good hygiene regardless of build system.
