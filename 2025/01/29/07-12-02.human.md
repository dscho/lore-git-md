This is a small optimization patch in Patrick Steinhardt's ongoing Meson build system refactoring series. It follows the pattern of consolidating program detection that was established in earlier patches.

The change eliminates redundant searches for the `sed` executable in the documentation build process. Instead of calling `find_program('sed')` repeatedly in a loop (which would search PATH each time), the patch uses a pre-declared `sed` variable that was introduced in a previous commit. This makes the build slightly more efficient by doing the program lookup just once.

The modification is straightforward - just a one-line change in the documentation build configuration that replaces the dynamic lookup with the cached variable. Like other patches in this series, it maintains all existing functionality while making the build system more efficient. The change is well-contained and low-risk, affecting only how documentation is generated.

This continues the series' theme of removing redundant operations from the Meson build configuration. While the individual impact is small, these micro-optimizations collectively clean up the build system's internal structure.
