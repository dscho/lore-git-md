This is part 2/4 of the Rust bindings series, focusing on the foundational `libgit-sys` crate that provides FFI access to Git's C library. The patch establishes the build infrastructure and demonstrates the approach with user agent string functions as an initial example.

The key technical elements include:
- A symbol visibility system that prefixes Git functions with `libgit_` to avoid collisions (particularly with libgit2)
- Build system integration via Makefile and Cargo, with `-fvisibility=hidden` to control symbol exposure
- Initial FFI bindings for user agent string functions, with Rust tests verifying basic functionality
- Careful handling of static library dependencies (libgit.a, libreftable.a, xdiff/lib.a)

The implementation looks solid, with clear attention to detail in the build system integration and symbol management. The patch follows the established pattern of keeping Rust components in `contrib/` while maintaining clean separation from core Git. This is a well-structured foundation for the higher-level Rust wrapper that will follow in later patches of the series.
