This is a bug report about Git's handling of the `PREFIX` environment variable in system configuration. The reporter, Randall S. Becker, notes that when setting `PREFIX=/home/randall`, `git config --system` ignores this variable and instead looks for system config in the build-time location (`/usr/local-ssl3.0/etc/gitconfig`), contrary to the documented behavior in Git's environment variables documentation.

The issue appears consistently across different Git versions (2.47.1 and 2.45.1) and platforms (including NonStop and UNIX systems). The reporter provides clear reproduction steps and expected vs. actual behavior, making this a well-documented bug report. The discrepancy between documented and actual behavior suggests this is a legitimate issue rather than a misunderstanding of the reporter's part.

The bug affects system configuration file location resolution, which could impact users who need to customize their Git installation locations via `PREFIX`. The reporter's detailed system info and clear problem description should help maintainers investigate the issue.
