This is a build system optimization patch in Patrick Steinhardt's ongoing Meson build system refactoring series (patch 9/11). It follows the previous patch that consolidated program path handling, continuing the theme of simplifying and optimizing the build configuration.

The change eliminates redundant `sed(1)` program lookups in the documentation build process. The patch replaces a repeated `find_program('sed')` call with a single reference to the pre-declared `sed` variable that was introduced in an earlier patch. This is a straightforward mechanical improvement that reduces unnecessary work during the build while maintaining identical functionality.

The modification affects only the documentation build configuration, specifically the howto documentation generation which uses `sed` to strip headers from source files. The change is minimal (one line modified) and low-risk, building on infrastructure already established in the series. This continues the pattern seen in patches 7-8 of removing redundant operations from the build system while preserving all existing behavior.
