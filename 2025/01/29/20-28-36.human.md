This is a build system optimization patch in Patrick Steinhardt's Meson refactoring series. The patch simplifies the list of required coreutils programs checked during build configuration, reducing it from seven tools to just three (cat, grep, sed) with cat serving as a representative for the coreutils suite. Justin Tobler suggests adding a comment to clarify this design choice, noting that checking cat alone covers the other coreutils tools.

The change is part of a larger effort to clean up and optimize Git's Meson build configuration. While minor (just a 1-line change), it follows the series' theme of removing redundancy while maintaining functionality, particularly for Windows builds where these tools need explicit path resolution. The patch appears straightforward and uncontroversial, though Justin's suggestion about documentation could help future maintainers understand the rationale.
