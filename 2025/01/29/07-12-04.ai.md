Final patch in Patrick Steinhardt's Meson build system refactoring series, focusing on documentation tool resolution. This patch ensures consistent use of custom program paths when finding documentation build tools like asciidoc, asciidoctor, xmlto, and xsltproc. The changes specifically:

1. Add `dirs: program_path` to all `find_program()` calls in Documentation/meson.build to ensure Windows builds properly locate tools via Git for Windows paths
2. Remove redundant `required: true` parameters (the default behavior)
3. Maintains all existing functionality while fixing potential Windows build issues where tools might not be found without the path hint

The patch continues the series' pattern of build system optimizations, here addressing a platform-specific edge case in documentation generation. It completes the earlier work from patches 9-10 that optimized documentation build configuration, now ensuring proper tool resolution across platforms. The changes are mechanical but important for Windows compatibility, touching only Documentation/meson.build with straightforward path resolution fixes.
