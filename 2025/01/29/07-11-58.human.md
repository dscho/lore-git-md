Build system refactoring: This is the fifth patch in Patrick Steinhardt's series cleaning up Git's Meson build configuration. It introduces a new `libgit_curl` dependency to simplify how executables link against libcurl. Currently, several programs (like git-remote-http and git-http-fetch) each repeat the same curl-related setup. The patch bundles the common HTTP source files and curl linkage into a single dependency declaration, reducing duplication.

The change affects all curl-dependent programs, including the HTTP/FTP remote helpers, http-fetch/push, and imap-send. The latter gets special handling since it conditionally uses curl. The patch maintains all existing functionality while making the build configuration more maintainable by centralizing the curl-related setup.

This continues the series' pattern of focused, mechanical improvements to the Meson build system. Like previous patches, it touches only meson.build with no behavior changes for end users. The change appears well-scoped and follows logically from patch 4's work on curl linkage. Reviewers will likely want to verify the conditional imap-send handling remains correct and that no edge cases were missed in the consolidation.
