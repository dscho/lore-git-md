This is a feature implementation providing Rust bindings for Git's C library, now in its 9th iteration. The series introduces two Rust crates: `libgit-sys` (low-level FFI bindings) and `libgit` (higher-level Rust-friendly wrappers). The work builds on extensive prior discussion and refinement, with all technical and stylistic issues now resolved.

The v9 changes are minor fixes: proper initialization of `LIBGIT_PUB_OBJS` in the Makefile and correcting a pointer-freeing pattern in `libgit_configset_free()` (changing from `free(&cs->cs)` to `free(cs)`). These follow Phillip Wood's final review comments from v8. The series has been tested with real-world usage in the JJ VCS project.

Key technical components include:
- Split initialization code into `common-init.c`/`common-exit.c`
- `libgit-sys` providing FFI bindings via `public_symbol_export.[ch]`
- `libgit` offering safe Rust wrappers with RAII memory management
- ConfigSet API exposure with proper ownership semantics
- Build system integration for both meson and Makefile
- Test coverage for config precedence rules

The work is contained in `contrib/` and doesn't impact core Git functionality. Two known follow-up items remain (symbol visibility management and versioning), but the maintainers have approved the current state for integration. The implementation demonstrates proper FFI safety practices and provides a foundation for expanding Rust bindings in the future.
