This thread began with a 2-patch series by D. Ben Knoble addressing memory leaks that were detected in Meson builds but not in traditional Makefile builds. The first patch fixed a Unix socket handling issue in credential-cache operations where memory would leak when creating sockets with long pathnames (over 108 bytes), while the second patch addressed a missing free in scalar.c's clone command. 

The technical discussion was thorough, with Jeff King providing concrete reproduction cases and validating the Unix socket fix. Junio Hamano approved that patch after Patrick Steinhardt's analysis confirmed the issue. The second patch remains pending review. The thread then evolved into a discussion about Meson build configuration, with Patrick Steinhardt clarifying the correct syntax for leak detection (`-Db_sanitize=leak`) and test execution in Meson's out-of-tree builds. While this build system discussion doesn't affect the patches' technical content, it provides valuable operational knowledge for contributors using Meson, particularly around test debugging and leak detection setup. The thread demonstrates how Meson's stricter checks can surface issues that Makefile builds might miss.
