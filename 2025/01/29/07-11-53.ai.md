This is a cover letter for a series of build system improvements targeting Git's Meson configuration. The 11-patch series from Patrick Steinhardt focuses on cleaning up and optimizing various aspects of the Meson build setup, with changes ranging from dependency management to path resolution.

The series makes several notable technical changes: it stops unnecessarily linking libcurl into all executables (introducing a dedicated `libgit_curl` dependency instead), simplifies library usage patterns (removing the separate version library and inlining the static 'git' library), and improves program resolution logic (deduplicating required programs list and fixing PATH environment setup). Several patches address specific technical issues like fixing the exec path with runtime prefix and preventing sed(1) from being found in a loop.

The changes are spread across the main meson.build file and several documentation/test-related build files, with most modifications being deletions that simplify existing code. The series appears to be a collection of independent but related cleanups rather than tackling a single large problem, with each commit addressing a specific optimization opportunity or bug in the Meson build configuration. The changes look focused and well-scoped, suggesting careful attention to the build system's structure.
