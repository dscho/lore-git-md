Bug report about `PREFIX` environment variable behavior in system config lookup.

This is a bug report from Randall S. Becker about Git not respecting the `PREFIX` environment variable when looking up system configuration files. The reporter expected `git config --system` to use `${PREFIX}/etc/gitconfig` as documented, but instead it used the build-time location (`/usr/local-ssl3.0/etc/gitconfig` in this case).

The issue appears across multiple platforms (reported on both NSV and x86_64 systems) and Git versions (2.47.1 and 2.45.1). The reporter provides clear reproduction steps and expected vs actual behavior, noting this contradicts the documentation on git-scm.com about environment variables.

The bug report is well-structured with all necessary technical details, though it doesn't include any analysis of where in the code the issue might be occurring. The reporter's expectation aligns with the documented behavior, suggesting this is a legitimate bug rather than a documentation issue. The fact that it's reproducible across platforms and versions indicates it's not a platform-specific quirk.
