This is the final version (v9) of a series introducing Rust bindings for Git's C library, consisting of two crates: `libgit-sys` (low-level FFI bindings) and `libgit` (higher-level Rust API). The work is now complete with all reviewer feedback addressed, including a final memory management fix in `libgit_configset_free()`.

The series splits Git's common init/exit code into separate files to support the Rust bindings, then builds:
1. `libgit-sys` - Exposes core Git functions through FFI with proper symbol visibility management
2. `libgit` - Provides idiomatic Rust wrappers with RAII memory safety and type-safe error handling

Notable improvements in v9 include proper initialization of Makefile` variables and fixing a pointer-freeing pattern in the config API. The bindings have been tested with the JJ version control system and are ready for integration while remaining contained in `contrib/` without affecting core Git.

Two known follow-up items remain (symbol visibility management and versioning), but the maintainers have approved the current state. This represents the culmination of 9 iterations with thorough review from Phillip Wood, Junio C Hamano, and others, addressing all technical and stylistic concerns.
