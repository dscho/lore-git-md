This is a status update on two patch series from Derrick Stolee, following up on Junio Hamano's "What's cooking" summary.

The first series `ds/name-hash-tweaks` (8 commits) introduces a new name hash version for `pack-objects` and `repack` to improve delta-base selection. After Taylor Blau's review, Stolee confirms it's ready to graduate to 'next'. The series adds new options (`--name-hash-version`, `GIT_TEST_NAME_HASH_VERSION`) and test infrastructure to validate the impact on pack sizes.

The second series `ds/backfill` (6 commits) introduces a new `git backfill` command to bulk-download missing blobs in blobless clones, addressing performance issues with lazy-loading. Stolee notes this still needs a reroll (expected in about a week) and mentions possibly submitting an additional 'git-survey' series soon. The backfill work builds on the path-walk API changes from `ds/path-walk-1` and includes sparse-checkout integration (`--sparse` option) and batch size controls (`--min-batch-size`).

Both series relate to ongoing performance optimization efforts - the name hash changes for better delta compression, and backfill for blob transfer efficiency. The update indicates Stolee is prioritizing the name-hash work for immediate merging while continuing to refine the backfill functionality.
