This is the sixth patch in Patrick Steinhardt's series refactoring Git's Meson build system, focusing on build optimization. The change removes a now-unnecessary separation of version information into a separate `libgit_version.a` library.

The patch eliminates an artifact from an earlier Meson build approach that's no longer needed. Originally, version information was injected via preprocessor directives that would require rebuilding all of `libgit.a` when versions changed. While the current system uses "version-def.h" to avoid this, the separate version library remained as legacy. The change simplifies the build by directly including version.c and version-def.h in the main libgit sources.

This appears to be a straightforward cleanup - the commit message clearly explains the separate library is no longer serving its original purpose and the change reduces build complexity by 16 lines while maintaining the same functionality. It continues the series' pattern of focused Meson build optimizations.
