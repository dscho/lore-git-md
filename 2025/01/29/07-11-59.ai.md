Build system refactoring in Patrick Steinhardt's ongoing Meson improvements series (patch 6/11). This patch eliminates the separate `libgit_version.a` library that was previously used to hold version information, folding it directly into `libgit.a` instead.

The change removes what is now unnecessary indirection - the original justification for a separate version library (avoiding full rebuilds when the version changes) no longer applies since Git switched to using "version-def.h" rather than direct preprocessor injection. The patch simplifies the build configuration by moving version.c back into the main libgit sources and adding version-def.h to the source list, while maintaining the same version-def.h include logic through adjusted compiler flags.

This continues the series' pattern of mechanical but meaningful build system simplifications, removing 16 lines of meson.build configuration while keeping the same functionality. The change appears well-scoped and low-risk, touching only version handling in the Meson build without affecting other subsystems or the resulting binaries. It follows logically from the earlier patches' focus on eliminating unnecessary library indirections and build artifacts.

Key technical details:
- Removes libgit_version_library static_library() declaration
- Adds version.c directly to libgit_sources
- Includes version_def_h in libgit_sources
- Moves GIT_VERSION_H definition into main libgit c_args
- Maintains same version-def.h include behavior through different mechanism
- No functional changes to built artifacts

The patch fits cleanly into the series' progression, with no immediately apparent edge cases or complications introduced by this specific change. It represents another incremental improvement in simplifying Git's Meson build configuration while maintaining all existing functionality.
