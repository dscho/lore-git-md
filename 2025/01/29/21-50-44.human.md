Final patch in the Rust bindings series - adds idiomatic Rust wrapper crate.

This is the concluding patch in the 4-part v9 series implementing Rust bindings for Git's C library. While the previous patches established the FFI layer (`libgit-sys`), this one adds the higher-level `libgit` crate that provides idiomatic Rust interfaces. The wrapper implements proper RAII patterns (via Rust's `Drop` trait) and safe encapsulation around the config API, with test coverage for config precedence rules.

The implementation follows Rust's common FFI pattern of pairing a low-level `-sys` crate with a higher-level wrapper. The config API is the first subsystem exposed through this interface, demonstrating how future Rust bindings could be built. The patch includes build system integration and has been tested via integration with the JJ VCS.

With all technical and stylistic issues resolved through v9 and maintainer approval secured, this series appears ready for integration as a contained `contrib/` component that doesn't affect core Git functionality. The work provides a foundation for future Rust bindings while maintaining compatibility with Rust 1.63+.
