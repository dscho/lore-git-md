This is a platform compatibility patch addressing MSVC compiler warnings in the apply.c code. It's part 3 of a 4-patch series (v3) focused on fixing type conversion issues.

The patch makes several systematic changes to variable types in apply.c and apply.h to resolve warnings about potential 64-bit to 32-bit integer truncation. Key changes include:
- Changing return types and parameters from `int` to `size_t` for functions dealing with string lengths (like linelen() and parse_git_diff_header())
- Updating variables storing strlen() results to use size_t instead of int
- Adjusting related function signatures and variable declarations to maintain consistency
- Changing some unsigned int parameters to size_t where appropriate

The changes appear focused on the patch parsing logic in apply.c, particularly around functions that handle diff headers and fragments. The author notes these changes are specifically to address MSVC warnings, suggesting Windows compatibility is the primary motivation. The patch maintains the same logic while using more appropriate types for the operations being performed.
