Platform compatibility patch addressing MSVC compiler warnings in date.c. This is part 2 of a 4-patch series (no cover letter seen).

The patch fixes two types of warnings from Microsoft's compiler: potential 64-bit to 32-bit integer truncation, and using `int` for values that can't be negative (specifically, string lengths from `strlen()`). The changes are straightforward:
1. Changes `int` to `size_t` for variables holding `strlen()` results in three locations within `approxidate_alpha()`
2. Fixes a comparison that could trigger truncation warnings by adjusting the arithmetic (changing `>= len-1` to `+1 >= len`)

The modifications are localized to the date parsing logic and appear to maintain existing behavior while making the code more type-safe. The patch follows the pattern of similar platform-specific fixes seen in the codebase, though it doesn't include any new test coverage for the changes.
