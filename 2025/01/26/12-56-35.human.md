Platform compatibility patch fixing MSVC warnings in the interactive patch interface (`add-patch.c`). This is the first of four patches in Sören Krecker's series addressing type conversion warnings across Git's codebase.

The patch changes `unsigned long` to `size_t` for hunk header fields in the interactive patch interface, which should provide consistent behavior between Linux and Windows platforms. It introduces a new `str_to_size_t` macro for string-to-size conversion and adds overflow/underflow checks. The changes appear mechanical, converting type declarations and adjusting format specifiers to use `PRIuMAX` for portable printing of size values.

The modifications touch core interactive patch functionality (hunk parsing, rendering, and error messages) but don't alter behavior - they just make the type handling more portable. The patch includes updates to related headers (`gettext.h` and `git-compat-util.h`) to support the changes.

This looks like a straightforward technical improvement that should help MSVC users while maintaining existing behavior. The changes are focused and well-contained to the stated compatibility issue. As part of a larger series, it follows the established pattern of addressing compiler warnings through explicit type handling.
