Platform compatibility patch addressing MSVC compiler warnings in date.c. This is part 2 of a 4-patch series (no cover letter seen).

The patch fixes type conversion warnings when compiling with MSVC, specifically addressing potential 64-bit to 32-bit integer truncation issues. It changes several `int` variables to `size_t` where they store results of `strlen()` calls, since string lengths can't be negative. The changes appear in the `approxidate_alpha()` function which handles date parsing.

The modifications look straightforward and focused - they don't change behavior, just make the code more type-safe for MSVC. One notable change is the adjustment to the comparison in the final while loop, where the condition is rewritten to avoid potential underflow issues. The patch follows Git's style and includes a clear commit message explaining the changes.
