This is a platform compatibility patch addressing MSVC warnings in commit.c. 

Sören Krecker fixes several type conversion warnings that appear when compiling with MSVC, primarily around potential 64-bit to 32-bit integer truncation. The changes are straightforward type adjustments: switching from `int` to `size_t` for variables holding `strlen()` results (which can't be negative) and other length-related variables. 

The patch touches several functions in commit.c, including `parse_commit_buffer()`, `add_header_signature()`, and `find_invalid_utf8()`, making their variable types more precise. While these are largely mechanical changes, they improve code correctness and silence compiler warnings. The changes appear well-scoped and uncontroversial, with no behavior modifications - just type safety improvements for Windows builds.
