Johannes Schindelin announced Git for Windows 2.48.0-rc1, a maintenance release that updates key dependencies (cURL, MinTTY, MSYS2 runtime) and formalizes the deprecation of Windows 7/8 support that began in v2.47.0. The release includes standard 32/64-bit installers, portable versions, MinGit variants, and newly added ARM64 builds - all with SHA-256 checksums for verification.

Junio Hamano briefly acknowledged the release with a thank-you note and New Year's greeting, confirming the maintenance updates without adding technical discussion. The thread remains focused on the Windows-specific distribution updates rather than core Git development.
