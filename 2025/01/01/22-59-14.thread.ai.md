[PATCH] t7110: replace shell tests with test helpers

Test modernization patch updating t/t7110-reset-merge.sh to use Git's test_path_is_file and test_path_is_missing helpers instead of direct shell test commands.

The patch modifies two test cases verifying reset behavior with added/deleted files during merges. Six conditions checking file existence/absence are updated to use the test helpers, which provide more informative failure output while maintaining the same test semantics. The author notes the test context specifically requires path absence checks where test_path_is_missing is appropriate despite not being strictly equivalent to ! test -f in all cases.

This continues Git's ongoing test suite modernization effort to improve debuggability by replacing raw shell tests with specialized helpers. The change is mechanical and focused, with no impact on the actual reset/merge functionality being tested.
