This is a test modernization patch that improves debuggability in the test suite. The change replaces direct shell `test -f` and `! test -f` checks with Git's test helper functions `test_path_is_file` and `test_path_is_missing` in t/t7110-reset-merge.sh.

The patch modifies 6 test conditions across two test cases ('--merge is ok with added/deleted merge' and '--keep fails with added/deleted merge') that verify file existence/absence during merge and reset operations. The author notes that while `! test -f` and `test_path_is_missing` are not strictly equivalent (the former checks for non-file paths while the latter checks for complete absence), the test context specifically requires checking path absence, making the substitution valid.

The change provides better debugging output when tests fail, as the Git test helpers include more informative error messages than the basic shell test. This follows Git's established pattern of using specialized test helpers rather than raw shell commands in the test suite. The patch is focused and mechanical, touching only the test file without any behavior changes to the actual Git commands being tested.
