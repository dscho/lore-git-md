This thread introduces a test modernization patch that improves debuggability in the test suite. The change replaces direct shell `test -f` checks with Git's more informative test helper functions `test_path_is_file` and `test_path_is_missing` in t/t7110-reset-merge.sh.

The patch updates 6 test conditions across two test cases that verify file existence during merge and reset operations. While the change is mechanical in nature, it provides clearer debugging output when tests fail by using Git's specialized test helpers rather than raw shell commands. The author notes the substitution is valid in this context since the tests specifically need to check for path absence, even though the shell and helper functions have slightly different semantics in general.

This follows Git's established pattern of test suite modernization, where direct shell commands are progressively replaced with purpose-built test helpers that offer better failure diagnostics. The change is focused solely on the test infrastructure without modifying the behavior of the actual Git commands being tested.
