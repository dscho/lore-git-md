Git for Windows 2.48.0-rc1 release announcement from Johannes Schindelin, updating the Windows-specific Git distribution to match upstream Git v2.48.0-rc1. Key updates include dependency bumps: cURL to v8.11.1, MinTTY to v3.7.7, and MSYS2 runtime based on Cygwin v3.5.5. The release formalizes deprecation of Windows 7/8 support with an explicit installation block, continuing the policy established in v2.47.0. Distribution provides standard 32/64-bit installers, portable versions, MinGit variants (regular and BusyBox), and ARM64 builds (installer and portable formats). All packages include SHA-256 checksums. Junio Hamano acknowledged the release with a brief thank-you note and New Year's greeting, confirming the maintenance-focused nature of this update which prioritizes dependency updates and platform support adjustments (particularly ARM64 expansion) over new features. No technical discussion or feedback was raised in the acknowledgment.
