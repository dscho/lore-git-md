Test modernization patch improving debuggability in t7110-reset-merge.sh.

Matteo Bagnolini submits a straightforward test script update that replaces direct `test -f` and `! test -f` checks with the more informative `test_path_is_file` and `test_path_is_missing` helper functions. These test helpers provide clearer output when tests fail, showing the expected versus actual state rather than just a generic failure.

The changes affect two test cases in t7110 that verify file states during merge conflict scenarios. The author notes that while `! test -f` and `test_path_is_missing` aren't strictly equivalent (the former checks for non-file paths while the latter checks for path absence), the tests in question are specifically checking for path absence, making the substitution valid.

This appears to be a clean, focused improvement following Git's established test infrastructure patterns. The patch is small and well-contained, touching only the test file with no behavioral changes to the actual Git commands being tested.
