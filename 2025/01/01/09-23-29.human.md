This is a release announcement for Git for Windows 2.48.0-rc1, marking the first release candidate for the upcoming Windows version of Git. Johannes Schindelin shares the availability of pre-built binaries across multiple architectures and formats.

The release brings several dependency updates, including Git v2.48.0-rc1 itself, cURL 8.11.1, MinTTY 3.7.7, and an MSYS2 runtime based on Cygwin 3.5.5. A key bugfix ensures the installer properly blocks installations on unsupported Windows 7 and 8 systems, continuing the policy established in v2.47.0.

The announcement provides SHA-256 checksums for all 14 available package variants, covering 32-bit, 64-bit, and ARM64 architectures in various distribution formats (installer executables, portable 7z archives, MinGit zips, and tarballs). This comprehensive list allows users to verify downloads and choose their preferred installation method.

As a release candidate, this version is primarily of interest to testers and package maintainers who want to evaluate the upcoming stable release. The announcement follows standard Git for Windows practice by providing clear version information and cryptographic verification for all distributed files.
