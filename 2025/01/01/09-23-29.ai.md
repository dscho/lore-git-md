Release announcement for Git for Windows 2.48.0-rc1, marking a new test release in the Windows-specific Git distribution. This is primarily a dependency update release with some notable changes:

The announcement comes from Johannes Schindelin, the primary maintainer of Git for Windows. The release updates several key components: Git itself to v2.48.0-rc1 (matching the upstream release candidate), cURL to v8.11.1, MinTTY to v3.7.7, and the MSYS2 runtime based on Cygwin v3.5.5. These updates suggest routine maintenance to keep dependencies current and secure.

A notable bugfix explicitly blocks installation on Windows 7 and Windows 8, formalizing the deprecation of these platforms that began in v2.47.0. This continues the project's policy of dropping support for older Windows versions as Microsoft ends their lifecycle.

The release includes the standard array of Windows distribution formats: 32/64-bit installers, portable versions, MinGit distributions (both regular and BusyBox variants), and for the first time in this announcement, ARM64 builds. The inclusion of ARM64 packages (both installer and portable formats) reflects growing support for ARM-based Windows devices.

SHA-256 checksums are provided for all download packages, allowing users to verify integrity. The release follows Git for Windows' established pattern of providing multiple distribution formats to accommodate different Windows usage scenarios from full installations to minimal CI environments.

This appears to be a routine maintenance release focused on dependency updates and platform support adjustments rather than introducing new Windows-specific features. The ARM64 builds represent the most notable expansion of platform support.
