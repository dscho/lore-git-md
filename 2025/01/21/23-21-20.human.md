This is a bugfix patch addressing a build system integration issue in the Rust bindings effort. 

Josh Steadmon acknowledges a missing meson.build entry for two new files (`common-exit.c` and `common-init.c`) that were added in patch 1/5 of the Rust bindings series. The omission was caught by both Junio C Hamano and Patrick Steinhardt during testing, with Junio providing the specific fix needed. 

The patch represents a minor but necessary correction to ensure the meson build system works properly with the refactored initialization code. Steadmon confirms he'll incorporate the fix into the next version of the patch series (v7), indicating this was due to being temporarily off-list during meson-related developments.

This is part of the larger Rust bindings work that has already received maintainer approval, with the build system integration being one of the final technical details to resolve. The fix is straightforward and uncontroversial, just ensuring the meson build properly includes all required source files.
