This is feedback on the proposed "repository metadata command" project for GSoC 2025, specifically addressing the machine-readable output format and design discussion history.

Oswald Buddenhagen responds to Patrick Steinhardt's proposal for a new repository metadata command, pushing back on two aspects. First, they argue that any JSON output should be optional, preferring the current line-based format for easier shell script parsing. Second, they note that while Patrick claims the idea hasn't been discussed, there was at least some prior discussion in a linked thread from the mailing list archives.

The email suggests this project may need more design consensus before being ready for a GSoC implementation, particularly around output formats. The feedback indicates the command's interface design isn't yet settled, with differing opinions on machine-readability versus shell script friendliness. This connects to the open question in the thread about needing refinement for the repository metadata command design. The response also implies the project's background discussion may be more extensive than initially indicated, pointing to existing mailing list threads that should inform the design.
