This is a technical refinement to the Meson build system conversion series, specifically addressing version string generation. The patch modifies GIT-VERSION-GEN to support two new modes: accepting a format string directly via `--format=` rather than requiring an input file, and writing output to stdout when no output file is specified. These changes accommodate Meson build system requirements where version information needs to be captured programmatically rather than through file I/O.

Key technical details:
- The script now accepts 2-3 arguments instead of exactly 3
- New `--format=` option allows direct format string input
- When OUTPUT is omitted, results print to stdout
- Maintains all existing substitution patterns (@GIT_VERSION@ etc.)
- Preserves atomic file write behavior when OUTPUT is specified
- Toon Claes considered suggesting `--stdin` input but agrees with the implemented approach after reviewing subsequent commits
- The change is part of Patrick Steinhardt's broader Meson conversion work (v2 02/11)
- Follows the thread's pattern of careful build system modernization while maintaining compatibility
