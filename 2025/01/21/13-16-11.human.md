Build system modernization: GIT-VERSION-GEN flexibility for Meson

This is part of Patrick Steinhardt's ongoing series to modernize Git's build system with Meson. The patch modifies GIT-VERSION-GEN to be more flexible in how it handles version generation, specifically to accommodate Meson's needs.

The key change allows GIT-VERSION-GEN to operate without requiring both input and output files. Instead, it can now:
- Accept a format string directly via `--format=` rather than reading from a file
- Output to stdout when no output file is specified

Toon Claes reviews the change and mentions he considered suggesting a `--stdin` approach instead, but after seeing the subsequent commits in the series, agrees with Patrick's implementation. The change appears well-considered, with clean handling of both the traditional file-based workflow and the new direct-format use case needed for Meson integration.

This is a technical but focused change that demonstrates careful attention to maintaining compatibility while enabling new build system functionality. The reviewer's quick approval suggests the approach is sound.
