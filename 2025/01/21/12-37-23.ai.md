This is a technical follow-up in Patrick Steinhardt's Meson build system conversion series, specifically addressing patch 6/11 which handles distribution archive generation. Toon Claes provides feedback email analyzing the approach to propagating version information into generated archives.

The discussion focuses on the mechanism for passing version information through GIT-VERSION-GEN when Meson builds distribution archives. Claes initially questioned why an absolute path couldn't be used, but through local testing realized the script executes during build file regeneration when MESON_DIST_ROOT isn't yet available. While noting it's unfortunate to modify GIT-VERSION-GEN to understand MESON_DIST_ROOT, Claes concludes this appears to be the only viable approach.

Key technical points:
- The patch modifies GIT-VERSION-GEN to handle Meson's build process
- The environment variable timing issue prevents simpler solutions
- The approach maintains compatibility with Git's existing version generation
- The solution preserves Meson's ability to test distribution archives

This represents a minor but necessary technical adjustment in the larger Meson conversion effort, with the feedback confirming the approach's validity while documenting the constraints that led to this implementation choice. The exchange demonstrates careful cross-validation of build system behaviors between the old and new systems.
