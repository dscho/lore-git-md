CI hardening patch in the Meson conversion series. This is patch 10/11 in Patrick Steinhardt's v2 series modernizing Git's build system to use Meson.

The patch makes Meson warnings fatal in CI by adding the `--fatal-meson-warnings` flag to the setup command. This ensures build configuration issues (like using features not available in the declared minimum Meson version) will fail CI jobs rather than just producing warnings that might be missed. The change is minimal - just a single line addition to the CI script.

Toon Claes confirms this would have caught his earlier mistake of using the `fs.copyfile` feature which wasn't available in the minimum Meson version Git targets. The thread context shows this is part of the broader Meson conversion effort that has been progressing methodically with attention to detail and maintainer feedback.

This appears to be a straightforward quality-of-life improvement for the build system that helps catch compatibility issues early. The patch is small, focused, and already has real-world validation from Toon's experience. It fits well with the series' overall goal of maintaining Git's high standards while modernizing the build infrastructure.
