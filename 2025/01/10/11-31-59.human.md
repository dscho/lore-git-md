CI/build system patch in Patrick Steinhardt's ongoing series to modernize Git's test infrastructure. This is part 3 of 10 in v4 series that focuses on containerizing GitHub Actions jobs to run without root privileges.

The patch addresses an issue where containerized GitHub jobs run as root, causing test failures that wouldn't occur under normal user permissions. The solution creates a dedicated 'builder' user to run the test suite, matching GitLab CI's existing approach. The changes modify both the GitHub workflow file to add user setup and test execution steps, and the dependency script to ensure required packages (shadow-utils and sudo) are available.

This continues the series' theme of improving test reliability across platforms, now tackling permission-related test inconsistencies in GitHub's containerized environments. The change is straightforward and follows established patterns from GitLab CI, suggesting it should integrate cleanly.
