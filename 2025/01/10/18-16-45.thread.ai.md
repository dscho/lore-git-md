Git v2.48.0 release announcement summary:

Major version update containing 605 non-merge commits from 93 contributors (35 new). Key user-facing changes include:
- New `remote.<name>.serverOption` config for transport customization
- Enhanced `git rebase --rebase-merges` using branch names as labels
- `git notes add/append -e` flag for editing notes before saving
- Improved `git mergetool` error handling
- New fsck checks for bundle operations

Performance/internal improvements:
- Reftable library updates for better allocation failure handling
- Relative path support for worktree linkages
- Continued progress removing `the_repository` global
- Significant Meson build system integration
- CI infrastructure updates

Bug fixes address:
- macOS fsmonitor race conditions
- Maintenance start crashes
- Submodule fetch remote mismatches
- Various memory leaks
- Windows/Cygwin/MinGW platform-specific issues

Implementation focus areas:
- Memory safety (leak fixes, allocation handling)
- Build modernization (Meson support)
- Core refactoring (reftable improvements, repository object passing)
- Documentation of breaking changes policy
- Translation updates for multiple languages

This represents a substantial release with both user-visible features and significant internal cleanup across multiple subsystems. The changelog indicates broad participation from both established contributors and new community members.
