Git instaweb Python server binding fix - corrects inversion of IP address binding behavior in git-instaweb.sh. The patch flips the default binding from 127.0.0.1 (localhost) to 0.0.0.0 (all interfaces) and makes the -l flag properly bind to localhost only, matching documented behavior and typical server security conventions. The change addresses a security/usability issue where the current implementation exposes the server more widely when -l is specified while being overly restrictive by default. The fix is minimal (2 lines modified) and focused, with no test updates but low regression risk given the straightforward nature of the change.

Junio C Hamano has acknowledged and accepted Alecs King's patch, confirming it correctly addresses the long-standing inversion issue present since Python server support was introduced in 2019. He notes this is a well-spotted fix and will queue it for inclusion. The discussion surfaced a related but separate issue about some backends ignoring the --local option entirely, though this is explicitly noted as being outside the scope of the current patch.
