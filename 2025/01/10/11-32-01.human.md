This is a CI/build system patch in Patrick Steinhardt's ongoing series modernizing Git's CI infrastructure. It simplifies how Linux job distributions are specified in GitHub Actions workflows by eliminating redundant distro name declarations.

The change makes the explicit `distro` field redundant by deriving it from the container image name (replacing colons with dashes), matching GitLab CI's approach. There are special cases for the 32-bit Ubuntu job (now using the image name directly) and distros without explicit tags (Alpine and Fedora now get "latest" tags). The patch updates both the workflow definition and supporting scripts to use this new scheme.

This appears to be a straightforward cleanup that reduces maintenance burden by removing duplicate information. The changes are consistent with the series' goal of standardizing and modernizing CI infrastructure, and the impact is limited to build system internals rather than test behavior or Git functionality itself.
