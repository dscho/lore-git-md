Project governance and contribution guidelines for Git (version 2.48, January 2025). Maintainer Junio C Hamano outlines infrastructure requirements including plain-text email standards, bug reporting protocols (requiring reproduction steps and behavior documentation), and repository management with official mirrors. The branch workflow consists of "master" for stable releases, "maint" for backports, "next" for vetted features, and "seen" for experimental work, with version numbering now using three parts. Key subsystems with external maintainers are noted (git-gui by Johannes Sixt, gitk, localization files). Community resources include IRC channels and Git Rev News newsletter, with the Software Freedom Conservancy providing organizational support. Security issues should be reported privately, while general development follows public mailing list discussion under the project's code of conduct. This serves as both reference documentation and current policy statement for all contributors.
