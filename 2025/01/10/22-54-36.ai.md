Documentation patch adding a comprehensive list of credential helpers to gitcredentials(7), part of v2 series addressing PAT storage guidance.

This patch restructures the credential helpers section of gitcredentials(7) to better highlight secure alternatives to the basic cache/store helpers. It splits the content into clearer subsections, adding:

1. A dedicated "Available helpers" section that first lists Git's built-in helpers (cache/store), then introduces popular third-party options with secure persistent storage (libsecret, osxkeychain, wincred, Git Credential Manager)
2. Expanded OAuth helper documentation with specific project links
3. Cross-references between sections for better navigation

The changes address Junio C Hamano's feedback from v1 by making the secure recommendations more prominent while preserving all technical details. The patch motivation cites Stack Overflow data showing insecure credential-store usage remains prevalent despite better alternatives existing.

Key technical elements:
- 41-line diff with net +29 additions
- New subsection structure in gitcredentials.txt
- Explicit platform-specific helper recommendations
- Dual listing of Git Credential Manager under both persistent storage and OAuth sections
- Maintains link to community-maintained credential helper list

This represents the first half of v2's documentation improvements, with the second patch focusing on credential-cache warnings. The changes provide concrete foundation for the thread's goal of steering users toward secure PAT storage solutions.
