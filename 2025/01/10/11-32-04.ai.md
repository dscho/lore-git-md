This is a CI/build system cleanup patch in Patrick Steinhardt's ongoing series modernizing Git's CI infrastructure. It removes obsolete special-casing for Ubuntu 16.04 from `ci/lib.sh` now that all CI jobs have migrated to Ubuntu 20.04.

The change is straightforward - it eliminates an 8-line conditional block that previously disabled HTTP/2 testing specifically for Ubuntu 16.04 due to its outdated Apache version. With Ubuntu 16.04 fully phased out (as established in an earlier commit c85bcb5de1), this special case is no longer needed. The patch simply enables `GIT_TEST_HTTPD=true` unconditionally for all Ubuntu versions.

This is a logical follow-up to the series' earlier work standardizing on Ubuntu 20.04 across all jobs. The change is minimal (9 lines removed, 1 line added) and focused, with no impact on test behavior since the conditional was only suppressing a test that would now pass on the newer Ubuntu version. The patch maintains the series' pattern of cleaning up legacy CI infrastructure while preserving all testing capabilities.
