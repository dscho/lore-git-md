CI/build system cleanup: Final removal of Azure Pipelines support

This patch concludes Patrick Steinhardt's CI modernization series by removing the last vestiges of Azure Pipelines support. The infrastructure was effectively retired in 2020 when Git switched to GitHub Actions, but some supporting code remained in the CI scripts. The changes are straightforward: deleting Azure-specific conditionals and variables from `ci/lib.sh` and removing Azure artifact handling from `ci/print-test-failures.sh`.

The removal is part of a larger effort to simplify and modernize Git's CI infrastructure, which has included containerization, platform updates, and test reliability improvements across the series. This particular change is purely cleanup - the Azure code hasn't been used in nearly five years and was just taking up space. The patch maintains all current GitHub Actions functionality while removing 25 lines of obsolete code.

As with the rest of the series, the change is well-justified and carefully implemented. It follows the pattern seen in earlier patches of removing legacy systems while preserving current capabilities. The series as a whole has been positively received, and this final cleanup seems uncontroversial.
