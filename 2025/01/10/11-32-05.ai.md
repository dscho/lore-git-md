CI/build system update in Patrick Steinhardt's modernization series, changing Ubuntu image tags from "latest" (which points to LTS) to "rolling" (current latest release, now 24.10) for most jobs in both GitHub Actions and GitLab CI. This creates a more useful test matrix by covering both oldest supported (20.04) and newest available Ubuntu versions, while maintaining all existing job configurations and test coverage. The change is mechanically simple (14 line changes in each config file) but strategically important for catching compatibility issues with newer distributions early. This continues the series' theme of CI modernization while being careful to preserve the existing test matrix structure - jobs that specifically test older versions (20.04, i386) remain unchanged. The change affects all standard test jobs (including leaks, ASAN, reftable variants) while leaving specialized jobs (musl, pedantic) on their current base images.
