CI/build system update in Patrick Steinhardt's modernization series (9/10). This patch switches most CI jobs from using Ubuntu's "latest" tag (which points to the current LTS release) to "rolling" (which tracks the newest release, currently 24.10). The rationale is that since we already test the oldest supported Ubuntu LTS (20.04), we should also test the newest release to catch issues early. The change affects both GitHub Actions and GitLab CI configurations, updating 7 job definitions in each system while preserving all other test matrix parameters. This continues the series' theme of CI modernization and completes the Ubuntu version coverage spectrum. The change is straightforward and mechanical, with no apparent downsides.
