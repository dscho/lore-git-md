Cleanup patch removing obsolete zlib compatibility code. This is the first of an 8-part series introducing zlib-ng support for performance.

Patrick Steinhardt removes the `uncompress2()` compatibility shim, which was previously needed for older zlib versions. The function is no longer used after commit 15a60b747e refactored the reftable code to handle decompression directly. The patch deletes the implementation file and removes build system references, simplifying the codebase.

This appears to be straightforward technical debt removal - the change is mechanical and well-justified by the commit message. The removal aligns with the series' broader goal of modernizing Git's zlib integration, though this particular change is more about cleanup than performance optimization. The patch touches several build files but doesn't introduce any new complexity.
