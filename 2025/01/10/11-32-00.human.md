This is a CI/build system patch in Patrick Steinhardt's ongoing series to modernize Git's test infrastructure. It converts all remaining Linux-based GitHub Actions jobs to run in containers rather than directly on the host machines.

The change provides more flexibility in choosing container images while showing no significant performance impact - benchmark data from Jeff King shows timing differences are within normal variation. The patch addresses two potential downsides: root execution (fixed in a prior commit via `setpriv`) and Node.js binary issues (resolved for 32-bit jobs). 

The diff reorganizes the job matrix, moving Linux jobs to the containerized section while maintaining their existing configurations. Each job now specifies both an image (like `ubuntu:20.04`) and a distro label, with the container approach allowing future flexibility to mix-and-match these independently.

This completes the containerization effort that began earlier in the series, following the pattern already established for musl/Alpine and 32-bit jobs. The change is low-risk (validated by timing data) and provides tangible benefits for future maintenance by decoupling test environments from GitHub's base images.
