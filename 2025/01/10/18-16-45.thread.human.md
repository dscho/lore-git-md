Git v2.48.0 has been released, representing a major update with contributions from 93 developers (including 35 first-time contributors). The release introduces several user-facing improvements: new transport configuration options via `remote.<name>.serverOption`, enhanced rebase behavior for merge commits, and note-editing capabilities with `git notes -e`. Under the hood, significant work went into memory safety (fixing leaks), build system modernization (Meson support), and continued refactoring of core components like the reftable backend and repository object passing.

The release addresses multiple issues from v2.47, including platform-specific fixes for macOS fsmonitor, Windows compatibility, and submodule fetching edge cases. Performance improvements and internal cleanups are widespread, particularly in the ongoing effort to eliminate `the_repository` global variable. With 605 non-merge commits, this release represents substantial progress across documentation, translations, and CI infrastructure while maintaining backward compatibility through the project's breaking changes policy.
