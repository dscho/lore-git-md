This is a periodic administrative message from the Git maintainer outlining project governance and contribution guidelines. It serves as a reference document for new contributors and a refresher for existing ones, updated to reflect the current Git version (2.48 as of January 2025).

The message covers essential infrastructure including mailing list protocols (plain-text requirements, spam filtering considerations), bug reporting standards (emphasizing reproduction steps and expected vs. actual behavior), and repository management (listing official mirrors and web interfaces). It details the branch workflow with "master" for stable code, "maint" for backported fixes, "next" for vetted new features, and "seen" for experimental work, noting the transition from four-part to three-part version numbering.

Key subsystems with external maintainers are identified (git-gui, gitk, localization files), each with their own authoritative repositories. The message also references community resources (IRC channels, Git Rev News newsletter) and the Software Freedom Conservancy's role as organizational home. Security disclosures should go to a private mailing list, while general development discussion happens on the public list with expectations of professional conduct per the CODE_OF_CONDUCT.md.
