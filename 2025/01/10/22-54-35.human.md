This is a documentation patch series addressing credential storage for personal access tokens (PATs), following up on earlier discussion. M Hickford submits version 2 of their documentation improvements, now split into two patches.

The first new patch adds a list of popular credential helpers to the documentation, while the second (carried over from v1 with minor tweaks) specifically warns against using the credential cache for PATs and recommends persistent storage alternatives. The changes respond to Junio Hamano's feedback by being more explicit about recommended solutions, particularly mentioning OAuth credential helpers and better integrating with the broader credential helper documentation.

The patch shows good responsiveness to review feedback, with clear incremental improvements. The documentation changes are well-motivated by real-world problems developers face with credential management, and the split into two patches makes the changes more focused and reviewable. The thread appears to be converging on a solution that will help users avoid insecure workarounds while acknowledging the variety of credential storage options available.
