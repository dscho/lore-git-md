Feature implementation for `git rev-list`'s missing object reporting. This is the first patch in a 2-part series that adds a new `--missing-info` option to complement `--missing=print`, providing structured information about missing objects including their paths.

The patch introduces a new `--missing-info` flag that works with `--missing=print` to output additional attributes about missing objects in a standardized format: `?<oid> [<token>=<value>]...`. Currently only implements the `path=<path>` attribute showing the object's full path from the top-level tree, with proper C-style quoting for special characters. The implementation uses an `oidmap` with `missing_objects_map_entry` struct to track paths, adding helper functions `add_missing_object_entry` and `print_missing_object` for the new functionality.

Key technical details:
- Maintains backward compatibility with existing `--missing=print` behavior
- Path resolution matches `--objects` behavior
- Uses C-style quoting for paths containing spaces/special characters
- Includes comprehensive tests in `t6022-rev-list-missing.sh` covering various path cases
- Modifies `finish_object__ma` to accept path information
- The implementation follows the thread's consensus to record attributes upfront and let consumers filter
- Still open is whether to include additional attributes like size (planned for part 2)
- The patch appears well-structured with thorough test coverage for the path reporting functionality
