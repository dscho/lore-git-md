Bugfix for `git instaweb`'s Python HTTP server binding behavior.

This patch corrects an inversion in the IP binding logic when using Python's built-in HTTP server with `git instaweb`. Currently, the default behavior (without `-l`) binds to localhost (127.0.0.1) while the `-l` option binds to all interfaces (0.0.0.0), which is the opposite of what's intended. The fix swaps these behaviors to match expectations: default binds to all interfaces while `-l` restricts to localhost only.

The change is minimal (just two lines swapped in `git-instaweb.sh`) but important for security and usability. The incorrect behavior could lead to unintentional exposure of the web interface when using `-l` (thinking it would restrict access) or unnecessary restriction when not using it. The patch appears straightforward with a clear commit message explaining both the problem and solution.
