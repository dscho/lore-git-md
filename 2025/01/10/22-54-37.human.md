This is the second patch in a v2 documentation series about credential storage, specifically addressing personal access tokens (PATs). The patch adds clear warnings to `git-credential-cache.txt` about its unsuitability for PAT storage, along with recommendations for better alternatives.

The addition explains why the credential cache (being ephemeral) is problematic for long-lived PATs, which users often need to store persistently. It directs users to persistent credential helpers and OAuth solutions, with cross-references to the reorganized "Available helpers" section from patch 1 of this series. The warning is well-placed in the documentation and addresses real user confusion evidenced by Stack Overflow discussions.

This completes the series' goal of improving PAT storage guidance, with v2 incorporating Junio's earlier feedback through concrete documentation changes. The patch is focused and uncontroversial, providing clear value by preventing insecure workarounds users might otherwise adopt.
