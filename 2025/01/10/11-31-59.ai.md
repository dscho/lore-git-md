CI/build system patch in Patrick Steinhardt's v4 series, adapting GitHub Actions container jobs to run rootless. This is part of the broader CI modernization effort that includes containerization, obsolete CI removal, and platform updates.

The patch modifies GitHub Actions workflows to create a dedicated 'builder' user for running tests, mirroring existing GitLab CI infrastructure. This addresses test failures that occurred when jobs ran as root, where tests expecting permission checks would fail due to root's elevated privileges. Key changes include adding `useradd` and `chown` steps before test execution, running tests via `sudo` as the builder user, and updating dependency installation to include `shadow-utils` and `sudo` packages where needed.

The changes affect two files: `.github/workflows/main.yml` (test execution flow) and `ci/install-dependencies.sh` (package additions). The solution builds on established patterns from GitLab CI while maintaining all existing test artifact collection functionality, including failure reporting and log uploads. This aligns with the series' focus on test reliability across platforms and CI systems.
