# Maintainer's community update

This is a periodic administrative message from Git maintainer Junio Hamano, providing an overview of Git project governance and development processes. The message is largely unchanged from previous versions, with only minor updates to reflect the latest release (Git 2.48).

The email serves as a comprehensive guide for new contributors, covering mailing list etiquette, bug reporting procedures, repository structure, and branch management. Key points include:

- Development happens on the git@vger.kernel.org mailing list, with strict plain-text requirement and anti-spam measures in place. The message emphasizes the importance of proper bug reports and provides links to archives and IRC channels.

- The repository uses four main integration branches: "master" (stable releases), "maint" (bugfixes), "next" (testable new features), and "seen" (experimental work). The message explains the workflow where topic branches progress through these branches based on maturity.

- Additional resources are provided including repository locations, documentation sources, and information about subprojects like git-gui and gitk that have separate maintainers. The message also references the project's code of conduct and security reporting procedures.

This is essential reading for anyone looking to contribute to Git, though regular contributors will find little new information beyond the version number update. The message serves as both an orientation document and a reference for project norms and procedures.
