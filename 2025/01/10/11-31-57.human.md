This is a platform compatibility fix for MinGW/Windows, part of Patrick Steinhardt's v4 CI/build system modernization series. The patch addresses intermittent test failures in GitLab CI where tests in t0060 (path utilities) would fail with EBUSY errors when trying to overwrite the git.exe binary during test setup.

The issue occurs when the test attempts to copy git.exe into a temporary directory, but the file appears to be locked by some unknown process (possibly Windows or MinGW internals). Rather than investigating the root cause, the patch takes a pragmatic approach by refactoring the test setup to avoid the problematic file operation. It moves the common setup (creating the directory and copying git.exe) into a separate test case that runs once, eliminating the need to overwrite the binary in subsequent tests.

This is a straightforward fix that improves test reliability on Windows platforms. The change is minimal (6 lines added, 4 removed) and maintains the same test coverage while working around the platform-specific quirk. As part of a larger CI modernization series that has already received positive feedback, this patch seems likely to be accepted.
