This is a refactoring patch in a series introducing zlib-ng support, specifically cleaning up an obsolete compatibility define. The patch removes the `z_const` macro definition in `git-compat-util.h` that was previously used to suppress `const` qualifiers in zlib API parameters. The author notes this was likely carried over from an old `uncompress2()` compatibility shim (removed in the previous patch) without clear purpose, as omitting `const` doesn't change the actual const-ness of parameters.

The change is straightforward - a single line removal in `git-compat-util.h` that had no functional impact. The patch builds on the series' broader cleanup of zlib compatibility code before introducing the zlib-ng backend. No technical rationale is given for keeping the define in the original commit (07564773c2), and the author sees no value in maintaining it. This appears to be a low-risk cleanup with no behavior change, aligning with the series' goal of modernizing zlib integration.
