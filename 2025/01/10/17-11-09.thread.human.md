The second option leverages the CMake build system in contrib/, though it lacks some features and isn't officially supported. Jon has now shared a third, simpler method that works with Git's standard Makefile build - on Fedora 41, he successfully debugged Git by building normally and using VS Code's native debugger to attach to the resulting binary, setting breakpoints starting from common-main.c.

While the Makefile approach works for basic execution tracing, it has limitations around process/thread handling and executable naming. The Meson and CMake methods promise more comprehensive functionality but require more setup. Patrick Steinhardt's upcoming Meson fixes may make that the most robust long-term solution, while Jon's Makefile technique provides a quick-start option for simpler debugging needs.
