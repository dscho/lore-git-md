CI/build system patch in Patrick Steinhardt's v4 modernization series, focusing on GitHub Actions job configuration. This patch simplifies the distro specification for Linux-based CI jobs by unifying around container image names rather than maintaining separate distro labels. The key changes:

1. Replaces explicit `distro` variables with derived values from `CI_JOB_IMAGE` (converting colons to dashes), matching GitLab CI's approach
2. Handles three special cases: the linux32 job (now using `i386/ubuntu` prefix), and untagged alpine/fedora images (now explicitly using `:latest`)
3. Updates `ci/install-dependencies.sh` to recognize the new i386/ubuntu naming scheme
4. Adds image name to distro conversion logic in `ci/lib.sh`

The changes maintain all existing functionality while reducing redundancy in the CI configuration. This is part of the broader effort to standardize and modernize Git's CI infrastructure across GitHub and GitLab platforms. The patch appears straightforward with no obvious technical concerns - it's a clean simplification that follows established patterns from earlier work in the series.
