Cover letter for a documentation patch series addressing personal access token (PAT) storage guidance. This v2 series builds on previous discussion to improve credential helper documentation, with two main changes from v1:

1. Adds a new first patch listing popular credential helpers (libsecret, osxkeychain, etc.) in the gitcredentials documentation, addressing Junio Hamano's suggestion to explicitly recommend persistent storage options. This provides users with clear alternatives to the ephemeral credential cache.

2. Updates the credential cache documentation to more strongly warn against using it for PATs while pointing to the new helper list and OAuth options. The diff shows the cache doc now references both the "Available helpers" and "OAuth" sections of gitcredentials(7).

The changes reflect thread consensus that documentation should:
- Actively steer users away from the cache for long-lived credentials
- Provide specific, persistent alternatives
- Better integrate with the broader credential helper ecosystem
