Platform compatibility fix for MinGW test flakiness in runtime prefix setup. This is part of Patrick Steinhardt's v4 CI/build system series that includes both SIGPIPE test fixes and broader CI modernization.

The patch addresses intermittent EBUSY errors in t0060 tests on MinGW/Windows when copying the Git executable during runtime prefix verification. The failure occurs when trying to overwrite `git.exe` that appears to be held open by some unknown Windows/MinGW mechanism, despite the previous test having exited. Rather than debug the root cause, the solution factors out the common setup into a dedicated test case to avoid the file copy race entirely.

The change is minimal - just moving the `mkdir` and `cp` operations from two test cases into a new shared setup runtime prefix` test. This maintains the same test coverage while working around the Windows-specific file locking behavior. The fix demonstrates careful attention to CI reliability across platforms, even for subtle environmental quirks.

- Uses `CAN_EXEC_IN_PWD` and `RUNTIME_PREFIX` prereqs
