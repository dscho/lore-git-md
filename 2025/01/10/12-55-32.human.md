Performance optimization series adding zlib-ng support (5/8). This patch moves the `deflateBound()` compatibility shim from `git-zlib.c` to the new `compat/zlib-compat.h` header. The function, which estimates compressed output size, was introduced in zlib 1.2.0 and Git previously maintained its own version for older zlib versions. 

The change is part of a larger effort to enable runtime switching between standard zlib and the optimized zlib-ng backend. By centralizing the shim in the compatibility layer, the patch can more easily adapt it for zlib-ng integration. The diff is straightforward - just moving the existing macro definition while maintaining identical behavior.

This continues the series that has been methodically refactoring Git's zlib integration. The changes so far appear carefully considered to minimize disruption while laying groundwork for future performance improvements. No functional changes are introduced yet, just infrastructure preparation.
