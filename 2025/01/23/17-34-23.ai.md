This is a refactoring patch in Taylor Blau's series to unify hash algorithm handling. It modifies the `hashfile` structure to store its own `algop` pointer rather than relying on the global `the_hash_algo`. The changes touch core checksum file operations like hash updates, finalization, and checkpointing, converting them to use the local `algop` field. This prepares for future work where different parts of the codebase might use different hash algorithms independently. The patch is mechanical but thorough, updating all relevant callsites in csum-file.c to use the new field. It maintains the existing behavior while making the algorithm choice more explicit at the hashfile level. This change is part of the broader effort to reduce reliance on global state and enable safer hash algorithm transitions.
