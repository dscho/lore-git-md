This is a discussion about naming and interface design for the name hash version 3 implementation.

Junio Hamano responds to Taylor Blau's suggestion about unifying the name hash interface rather than maintaining concurrent v2/v3 support. The exchange shows the maintainer aligning with Taylor's preference for interface simplicity while leaving the door open for future optimizations. This appears to be the final discussion point before the name hash changes can be integrated, with technical implementation already approved and only this naming/interface question remaining open.
