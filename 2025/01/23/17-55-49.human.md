Maintainer feedback on reflog corruption fix for symrefs. Junio Hamano provides stylistic suggestions for Karthik Nayak's patch that fixes incorrect reflog entries when updating symbolic references. The patch removes an optimization that was incorrectly assuming reflog-only updates didn't need full processing, which caused `old_oid` to be missing in symref reflogs.

Hamano notes the subject line could be clearer - "creation of corrupted reflogs" sounds like an intentional action rather than a bug fix. He suggests dropping "corrupted" from the title. He also points out some minor wording improvements for the commit message, like clarifying that "reflogs" don't exit early - it's the function that exits early when processing reflogs.

The maintainer approves the test case changes (which now properly use `git symbolic-ref` instead of hardcoding "main") while suggesting the variable name "head" could be more descriptive. Overall, this appears to be final polish on a well-vetted fix that has already received thorough review from Jeff King and Patrick Steinhardt. The patch seems ready for inclusion after these minor wording tweaks.
