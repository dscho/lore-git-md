Test infrastructure patch for hash algorithm refactoring. This is the first patch in an 8-part series that refactors Git's hash algorithm handling to eliminate separate "unsafe" variants of hash operations. 

The patch introduces a new `sha1-unsafe` test helper that exercises Git's unsafe SHA-1 wrappers, similar to the existing `sha1` test helper. The implementation modifies the generic `cmd_hash_impl()` function to conditionally run unsafe variants of hash functions when requested, then exposes this through the new helper. The test script is updated to verify both safe and unsafe variants produce identical output.

This appears to be well-crafted test infrastructure supporting the larger architectural changes in the series. The changes are focused and the commit message clearly explains the purpose. The test coverage seems thorough, verifying behavioral parity between safe and unsafe variants. As the first patch in a reviewed series, it lays important groundwork for the subsequent refactoring work.
