This is a minor bugfix in the path-walk API series, addressing a redundant function call that was caught by Coverity static analysis. Jeff King noticed that `parse_tree()` was being called unnecessarily in `path-walk.c` after `parse_tree_gently()` had already been called earlier in the same function. The second call was effectively dead code since the tree would already be parsed at that point.

The change is straightforward - removing one line of code while maintaining all the existing error handling. Maintainer Junio Hamano acknowledges the fix with a lighthearted comment about wishing such issues could be caught earlier in the review process, and queues the patch. This appears to be a clean, uncontroversial improvement to code that's already in the 'next' branch.
