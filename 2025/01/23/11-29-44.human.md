Bugfix for reflog corruption in symref updates. This final version of the patch addresses a regression introduced in Git 2.48.1 where symbolic reference updates (like HEAD) would create corrupted reflog entries missing the old_oid value. The issue was caused by an overzealous optimization in the files backend that skipped necessary processing for reflog-only updates.

Karthik Nayak's fix removes the problematic early return in `lock_ref_for_update()`, allowing the old_oid to be properly recorded for symref reflogs. The patch includes a test case that verifies correct reflog behavior when updating HEAD, using `git symbolic-ref` for robustness. Jeff King co-authored and signed off on the solution after several rounds of test improvements.

The change is files-backend specific and maintains other optimizations while fixing the symref case. Reviewers including Patrick Steinhardt and Junio Hamano have approved the final version, which incorporates all suggested refinements to the commit message and test case. This fixes a serious regression affecting reflog integrity and is likely to be included in a maintenance release.
