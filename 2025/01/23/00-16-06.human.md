This is a documentation patch adding missing descriptions for two HTTPS-related configuration options. Andrew Carter notes that `http.sslCertType` and `http.sslKeyType` were added in commit 0a01d41ee4c but never properly documented.

The patch adds clear explanations of both options to `Documentation/config/http.txt`, specifying the valid certificate/key types (PEM, DER, P12 for certs; PEM, DER, ENG for keys) and noting their relationship to underlying cURL options (`CURLOPT_SSLCERTTYPE`). It also documents the corresponding environment variables that can override these settings (`GIT_SSL_CERT_TYPE` and `GIT_SSL_KEY_TYPE`).

The documentation appears thorough and accurate, with a useful note about PKCS#11 token authentication when using the "ENG" key type. This is a straightforward and well-executed documentation improvement for existing functionality.
