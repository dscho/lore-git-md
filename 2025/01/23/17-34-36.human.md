This is a refactoring patch in Taylor Blau's series to unify Git's hash algorithm handling. It simplifies the test helper code that powers both 'sha1' and 'sha1-unsafe' test commands by using the new `unsafe_hash_algo()` function introduced earlier in the series.

The patch removes duplicate conditional logic that previously selected between safe and unsafe hash variants, instead converting the algorithm pointer to its unsafe version upfront when needed. This makes the remaining code path simpler and more direct, calling the standard `init_fn`, `update_fn`, and `final_fn` through the algorithm pointer regardless of whether it's the safe or unsafe variant.

This change demonstrates the series' architectural goal of making unsafe/safe variant selection a property of algorithm pointers rather than requiring separate function calls. The test helper now serves as a clean example of how callers should interact with the new unified API. The simplification removes 12 lines of conditional code while maintaining identical functionality, as verified by the existing test suite.

This is the sixth patch in an 8-part series that has already undergone extensive review, with the overall approach approved by Junio C Hamano and safety validated by Jeff King. The change is low-risk as it only affects test infrastructure while the core functionality remains unchanged.
