This thread documents the previously missing configuration options `http.sslCertType` and `http.sslKeyType` for HTTPS client certificate support. The options, introduced in commit 0a01d41ee4, control certificate and private key formats with support for "PEM", "DER", and "P12" for certificates, and "PEM", "DER", and "ENG" (for PKCS#11 tokens) for keys.

brian m. carlson raised concerns about platform limitations (particularly Windows PKCS#12 behavior) and whether to document libcurl's engine parameters. Junio C Hamano confirmed these as valid issues while noting the original implementation didn't address them. Author Andrew Carter has now submitted updated documentation that thoroughly covers the supported formats, backend-specific behaviors (noting "ENG" is OpenSSL-specific while maintaining the current PKCS#11 token workaround (using "ENG" with a PKCS#11 URL) rather than proposing new engine parameter support. The documentation properly references the underlying libcurl options and their environment variable equivalents, addressing the technical feedback while accurately reflecting the current implementation's capabilities and limitations.
