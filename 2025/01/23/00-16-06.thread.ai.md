Documentation thread adding missing documentation for HTTP/SSL configuration options `http.sslCertType` and `http.sslKeyType`, which control client certificate and private key formats for HTTPS operations (introduced in commit 0a01d41ee4c). The options accept formats "PEM", "DER", "P12" for certs and "PEM", "DER", "ENG" for keys ("ENG" supporting PKCS#11 tokens), with environment variable overrides (`GIT_SSL_CERT_TYPE`/`GIT_SSL_KEY_TYPE`) mapping to libcurl's `CURLOPT_SSLCERTTYPE`/`CURLOPT_SSLKEYTYPE`.
