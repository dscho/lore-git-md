CI modernization patch updating Ubuntu test images to latest releases.

This is the 9th patch in Patrick Steinhardt's ongoing series to modernize Git's CI infrastructure. The change switches from using Ubuntu's LTS releases (via the "ubuntu:latest" tag) to the actual latest Ubuntu release (via "ubuntu:rolling") in both GitHub Actions and GitLab CI configurations. The rationale is that since Git already tests against older LTS releases, it makes sense to also test against the newest available version.

The patch follows the series' established pattern of making focused, well-justified CI improvements. It updates 14 job definitions across two files (.github/workflows/main.yml and .gitlab-ci.yml) to use the rolling release instead of the LTS version. The change is straightforward and maintains consistency with the series' goal of keeping CI infrastructure up-to-date while ensuring comprehensive platform coverage.

This continues the series' dual focus on both expanding test coverage (by testing newer platform versions) and removing technical debt (by eliminating potentially misleading "latest" tags). The change is minimal and mechanical, affecting only the image tags while leaving all other job configurations intact.
