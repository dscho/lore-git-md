Patrick Steinhardt's CI modernization series has reached its final form with this cleanup patch, marking the completion of a multi-year effort to overhaul Git's continuous integration infrastructure. The series, now in its third version, has systematically replaced Azure Pipelines with GitHub Actions and GitLab CI while expanding test coverage and modernizing the execution environment.

The key achievements include:
- Complete removal of Azure Pipelines infrastructure (now finalized with this patch deleting the last remnants)
- Standardized containerized testing across platforms with comprehensive distro coverage (Ubuntu 20.04 through 24.10)
- Expanded architecture testing including i386 support
- Implementation of rootless container execution
- Resolution of persistent test issues including Windows EBUSY errors and the submodule SIGPIPE race condition

The final patch tidies up by removing Azure-specific logic from ci/lib.sh and test artifact handling from ci/print-test-failures.sh, following through on the Azure retirement that began in 2020. This is a clean, surgical removal of now-unused code paths rather than just disabling them.

With all major goals achieved - including infrastructure unification, test reliability improvements, and expanded platform coverage - this series represents a significant step forward in Git's testing infrastructure. The changes position the project well for future maintenance and expansion while providing more reliable and comprehensive test coverage across platforms. The discussion has also yielded valuable insights about test design that will inform future work, particularly around signal handling and permission testing.
