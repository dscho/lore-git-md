Documentation patch completing the git-commit man page standardization series. This third and final patch in Jean-Noël Avila's series reformats two supporting documentation files (`i18n.txt` and `signoff-option.txt`) to match the new AsciiDoc conventions established in the first two patches.

The changes are purely mechanical formatting updates: converting single-quoted command names to backtick-wrapped references (like `` `git commit` ``) and standardizing option syntax (`` `-s`/`--signoff` ``). The patch also applies the same conditional AsciiDoc directives (`ifdef::git-commit[]`) seen in earlier patches to handle documentation fragments that get included in multiple contexts.

With this patch, the entire git-commit documentation ecosystem now follows the project's modern formatting standards. The changes are consistent with the careful, non-functional approach taken in the series' first two patches (which updated the main man page and config documentation). No new content is introduced - this is the final piece of a well-executed documentation modernization effort that has proceeded without controversy through the mailing list.
