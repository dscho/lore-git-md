CI modernization patch making containerized GitHub Actions jobs run as non-root.

This is the third patch in Patrick Steinhardt's 10-part series modernizing Git's CI infrastructure. It addresses a limitation where containerized GitHub Actions jobs run as root, which caused test failures by bypassing normal file permission checks. The solution creates a dedicated "builder" user to run the tests, matching GitLab CI's existing approach.

The changes are straightforward: the workflow now creates a user, changes ownership of files, and runs tests under that user via `sudo`. The dependency installation script is also updated to include `shadow-utils` and `sudo` packages needed for user management. 

This appears to be a well-considered change that brings GitHub Actions behavior in line with GitLab CI's more secure approach. The patch is clearly part of a larger, systematic effort to improve CI reliability across platforms. While not fixing any specific bug, it removes a source of test inconsistencies by properly exercising permission-related code paths.
