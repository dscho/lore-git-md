Documentation formatting fix for Git 2.48.0. This is the first of two patches from Martin Ågren addressing minor rendering issues in built documentation.

The patch corrects a heading formatting issue in git.txt where an incorrect number of tildes (~) was causing rendering problems with both AsciiDoc and Asciidoctor processors. The heading in question was introduced in commit 8525e92886 to document the HOME environment variable. The fix simply adjusts the number of tildes from 18 to 6 to match the length of the "System" heading they underline.

This is a straightforward, mechanical change with no content modifications - just a one-line diff to fix the presentation. As with Martin Ågren's typical documentation contributions, it's a small but meaningful polish that improves consistency in the documentation system. The patch targets the upcoming 2.48.0 release and should be uncontroversial.
