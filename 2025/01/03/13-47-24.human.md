Documentation standardization for git-commit man page. This is the first of a 3-part series modernizing the formatting of `git-commit` documentation to match new guidelines, following Jean-Noël Avila's ongoing effort to standardize Git's man pages.

The patch makes several systematic changes to Documentation/git-commit.txt:
- Converts the synopsis to use AsciiDoc's synopsis block for automatic formatting
- Standardizes placeholder notation from `<placeholder>` to _<placeholder>_
- Uses backticks consistently for commands and options
- Adjusts some option descriptions to imperative mood
- Updates cross-references to use linkgit syntax

The changes are purely organizational (276 lines changed with balanced +/-) with no functional impact. A minor builtin/commit.c update aligns its usage message with the new formatting. This appears to be a well-executed documentation update following established patterns from prior documentation modernization work in the project.
