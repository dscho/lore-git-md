Jean-Noël Avila continues his work standardizing Git's documentation format with the second patch in a three-part effort focused on git-commit. The series converts various documentation files to the project's new AsciiDoc synopsis style without making functional changes. 

The first patch, already sent, updated git-commit.txt with standardized formatting for command synopses, placeholders, and cross-references. This new patch follows the same approach for Documentation/config/commit.txt, systematically applying backticks to config keys and boolean values while introducing conditional AsciiDoc directives to handle cross-references cleanly. The changes are purely presentational, with a balanced 15-line diff that adds no new content.

The series follows established patterns from prior documentation modernization work and has seen no objections. One final patch remains to update i18n.txt and signoff-option.txt, completing this straightforward but valuable standardization of git-commit's documentation.
