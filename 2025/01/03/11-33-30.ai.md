Documentation formatting fix for Git's manpages. This is the first of two patches in Martin Ågren's series addressing minor rendering issues in built documentation. The patch corrects a heading underline in git.txt that was using too many tildes, causing inconsistent rendering between AsciiDoc and Asciidoctor processors. The fix changes exactly one line, adjusting the number of tildes under the "System" heading to match the expected format. The issue was introduced in commit 8525e92886 from December 2024. This is a straightforward, non-controversial change that maintains documentation consistency without altering any content. The patch targets the upcoming Git 2.48.0 release and follows Martin Ågren's established pattern of documentation polish contributions.
