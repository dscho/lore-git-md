Documentation update migrating the git-notes manpage to the new documentation format. This is part of an ongoing effort to standardize Git's documentation markup.

The patch converts the git-notes.txt and related config/notes.txt files to use the new synopsis block format, which automatically handles placeholders and keywords. It replaces angle-bracket placeholders with italicized versions (e.g., `<placeholder>` becomes `_placeholder__) and ensures command options and keywords are properly marked with backticks. The changes are purely presentational - no content is altered beyond the markup.

Key technical details:
- Updates both the main git-notes.txt and config/notes.txt files
- Changes synopsis from verse to synopsis block format
- Standardizes markup for placeholders and command options
- Maintains all existing functionality while improving rendering
- Affects documentation display but not runtime behavior

The changes follow the established pattern for documentation modernization and appear mechanically correct. This is a straightforward update that should integrate cleanly with the ongoing documentation standardization work.
