This is a CI modernization patch that removes legacy Ubuntu 16.04 handling from Git's test infrastructure. It's part 8 of Patrick Steinhardt's ongoing series to improve Git's CI system, following the earlier transition from Ubuntu 16.04 to 20.04.

The patch simplifies `ci/lib.sh` by eliminating a special case that disabled HTTP/2 testing on Ubuntu 16.04 due to its outdated Apache version. Since all CI jobs now use Ubuntu 20.04 or newer, this conditional is no longer needed. The change removes 8-line case statement and unconditionally enables `GIT_TEST_HTTPD` for all Ubuntu versions.

The implementation is straightforward - a simple deletion of now-obsolete code that aligns with the series' goal of modernizing CI infrastructure. The change follows logically from the previous Ubuntu 20.04 migration (commit c85bcb5de1) referenced in the commit message. This continues the pattern seen throughout the series of removing legacy CI support while maintaining existing functionality where appropriate.

Key technical details:
- Modifies `ci/lib.sh` to remove Ubuntu 16.04 special casing
- Unconditionally sets `GIT_TEST_HTTPD=true` for all Ubuntu versions
- References prior commit that made this change possible
- Maintains all other Ubuntu-related CI functionality

The patch fits cleanly into the series' progression, representing another incremental cleanup after the platform upgrade was completed. It demonstrates the same attention to detail and systematic approach seen in earlier patches.
