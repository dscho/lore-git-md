This is a technical clarification in an already-approved patch series converting array indices from `int` to `size_t` for type safety. Patrick Steinhardt responds to Justin Tobler's review of patch 6/9 in the series, which updated `builtin/log.c`. 

Justin had noted that the patch changed a loop structure from backward iteration to forward iteration with index calculation, interpreting it as a readability improvement. Patrick clarifies this was actually a correctness requirement - the original loop relied on signed integer behavior that would become unsafe with `size_t` (where decrementing past zero would cause overflow rather than becoming negative). 

This exchange demonstrates the careful attention to edge cases in this type-safety series, where even seemingly stylistic changes have technical motivations.
