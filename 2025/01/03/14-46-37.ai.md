This is a cover letter for a 10-patch series focused on CI improvements and flaky test fixes. The series comes from Patrick Steinhardt and targets both GitHub Actions and GitLab CI infrastructure.

The main thrust of the ongoing work is to clean up and modernize Git's CI setup. Key changes include: converting all Linux jobs to use containerized execution (with rootless adaptation), removing stale CI code (including Azure Pipelines remnants and Ubuntu 16.04 special cases), adding a new 32-bit Linux test job, and updating to use the latest Ubuntu release. The series also includes two specific test fixes - one for MinGW EBUSY errors in t0060 and another for buffered stdout issues causing flakiness in t7422.

The changes touch multiple CI configuration files (.github/workflows/main.yml, .gitlab-ci.yml) and supporting scripts (ci/lib.sh, install-dependencies.sh), along with the two test files needing fixes. The series appears well-scoped and motivated by actual CI flakiness investigations, with test runs provided for both GitLab and GitHub environments. The removal of legacy CI code suggests this is part of ongoing maintenance to keep the test infrastructure lean and focused on currently supported platforms.
