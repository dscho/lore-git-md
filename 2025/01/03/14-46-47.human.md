This is a CI cleanup patch in Patrick Steinhardt's ongoing series modernizing Git's CI infrastructure. It removes stale Azure Pipelines support code that has been unused since the migration to GitHub Actions in 2020.

The patch deletes 25 lines across two CI scripts that were specifically handling Azure Pipelines environment variables and test artifact collection. The removal is straightforward since the code was already marked for retirement - it simply hadn't been cleaned up when the Azure support was originally dropped.

This change continues the series' pattern of removing obsolete CI infrastructure while maintaining all current functionality. It's a small but tidy cleanup that follows logically from the earlier transition to GitHub Actions. The patch is well-contained and clearly motivated, with a reference to the original deprecation commit.
