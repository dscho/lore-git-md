This is a cover letter for a series of CI improvements and flaky test fixes. Patrick Steinhardt proposes 10 patches that clean up and modernize Git's continuous integration setup across GitHub Actions and GitLab CI. The changes include:

1. Fixing two flaky tests (t0060 on MinGW and t7422 with buffered stdout)
2. Converting all GitHub Linux jobs to use containerized environments
3. Removing outdated CI configurations (Ubuntu 16.04 support, Azure Pipelines code)
4. Adding new test coverage (32-bit Linux/i386 job)
5. Simplifying job configuration logic

The series appears well-motivated by actual CI flakiness investigations, with test runs provided for both GitLab and GitHub. The changes are focused on maintenance and reliability rather than new features, touching CI configuration files and test scripts. The removal of legacy CI code suggests this is part of ongoing efforts to modernize the project's testing infrastructure.
