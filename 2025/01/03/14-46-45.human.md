This is a CI modernization patch that removes obsolete Ubuntu 16.04 special cases from Git's test infrastructure. It's part 8 of Patrick Steinhardt's ongoing series to improve Git's CI setup, following the recent switch from Ubuntu 20.04 as the base container image.

The patch simplifies `ci/lib.sh` by removing conditional logic that previously disabled HTTP/2 testing specifically for Ubuntu 16.04. Since that old distro version is no longer used in CI (as of commit c85bcb5de1), this special case can be eliminated. The change is straightforward - it removes an entire case statement and unconditionally enables HTTP/2 testing via `GIT_TEST_HTTPD=true`.

This continues the series' pattern of cleaning up technical debt in the CI system. The change is small (9 lines removed, 1 added) and low-risk since it only affects test infrastructure. The patch follows the series' established quality standard with a clear commit message explaining both the change and its context.
