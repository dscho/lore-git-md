Bugfix for Zsh completion regression. This patch fixes a Zsh shell completion issue introduced in commit 1e0ee4087e, where Bash-specific indirect variable expansion syntax (`${!var}`) broke config section completion in Zsh. The fix introduces a portable `__git_indirect` helper that works across both shells.

The problem manifested when trying to complete config options like `git config set remote`, where Zsh would incorrectly suggest internal variable names like `__git_first_level_config_vars_for_section_remote` instead of actual config options. Philippe Blain confirms the fix works across Bash 3.2.57 and Zsh 5.0.8.

The solution carefully handles shell portability concerns around variable expansion and quoting, with test cases demonstrating proper behavior. While the fix is solid, Philippe raises an important question about preventing similar regressions in the future, suggesting potential CI improvements to test completion scripts under Zsh's sh-emulation mode.

This appears to be a well-justified fix for a real regression, though the discussion highlights the ongoing challenge of maintaining shell script compatibility across different environments.
