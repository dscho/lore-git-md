CI modernization patch consolidating Linux test jobs into containers. This is the fourth in Patrick Steinhardt's 10-part series improving Git's CI infrastructure.

The patch moves all remaining Linux-based GitHub Actions jobs from direct machine execution to containerized runs. The author notes this provides greater flexibility in choosing container images while maintaining performance parity. The change follows the previous patch's introduction of non-root test execution, removing the last advantage of direct machine runs.

The diff shows a reorganization of the workflow file, moving Linux job definitions from the direct-execution section to the containerized section while preserving all existing test configurations (including sha256, reftable, leaks detection, and sanitizer jobs). Each job now specifies its container image explicitly while maintaining the same underlying distro and compiler settings.

This appears to be a straightforward consolidation that builds on the series' earlier containerization work. The change should make future maintenance easier by having a single execution model for Linux jobs. No functional changes to the tests themselves are introduced - this is purely about the execution environment.
