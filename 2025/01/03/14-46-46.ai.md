CI modernization series continuation: This patch (9/10) updates Git's CI infrastructure to use Ubuntu's rolling release rather than the LTS version for most test jobs. Patrick Steinhardt notes that while "ubuntu:latest" points to the current LTS release, switching to "ubuntu:rolling" will test against the actual latest Ubuntu version (currently 24.10) while still keeping older LTS versions in the matrix.

The change affects both GitHub Actions and GitLab CI configurations, modifying 14 lines across two files to replace "ubuntu:latest" with "ubuntu:rolling" in all standard test jobs. Some jobs remain pinned to specific versions (like Ubuntu 20.04 for GCC version testing and i386 builds), maintaining the series' strategy of testing both oldest and newest supported environments.

This follows the series' pattern of CI improvements by expanding test coverage while simplifying configuration. The change is straightforward but meaningful - it ensures Git gets tested against the most current Ubuntu features and libraries while maintaining compatibility testing through the preserved LTS jobs. The patch maintains consistency with previous changes in the series by using the established CI_JOB_IMAGE pattern and keeping modifications minimal and well-contained.
