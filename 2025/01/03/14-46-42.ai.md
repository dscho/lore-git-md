CI infrastructure modernization patch in Patrick Steinhardt's series, focusing on job distro naming simplification. This fifth patch in the 10-part series streamlines how Linux job distributions are specified in GitHub Actions workflows by eliminating redundant distro name declarations and standardizing on image names.

The change replaces explicit `distro` variables with derived values from `CI_JOB_IMAGE`, converting colons to dashes to maintain compatibility. Three files are modified:
- `.github/workflows/main.yml` removes 20 lines of explicit distro mappings
- `ci/install-dependencies.sh` updates platform detection logic
- `ci/lib.sh` adds the image-to-distro name conversion

Special cases are handled for:
- The linux32 job (now using `i386/ubuntu` image name)
- Untagged alpine/fedora images (explicitly adding `:latest`)
- Backward compatibility with existing distro-specific logic

This continues the series' pattern of reducing CI configuration duplication while maintaining all existing functionality. The change aligns GitHub Actions with GitLab CI's approach to distro naming and represents another incremental step toward standardized container-based execution across the CI pipeline.
