The core challenge has been coordinating committish references that were previously stored in separate string lists, which led to memory leaks and ordering dependencies.

The latest development shows them converging on a hybrid solution where commit references are stored directly in atom structs rather than in the format's string list. Peff's newest patch specifically addresses the `is_base` functionality, mirroring the approach previously taken with ahead-behind calculations. The changes make the data flow more explicit by eliminating the `ref_format` parameter from `filter_is_base()` and cleaning up related string list handling.

While the core architectural tension between simplicity and explicit API design remains, the discussion has progressed to implementation details of this middle-ground approach. The changes maintain all existing functionality while moving toward better contained state management, touching `ref-filter.c` and `ref-filter.h` without affecting end-user behavior.
