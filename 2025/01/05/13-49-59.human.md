This is patch 6/10 in a series adding comprehensive ref consistency checks, focusing on validating individual entries in the packed-refs file. The patch builds on earlier work that verified packed-refs headers and file types.

The patch introduces detailed validation for each line in packed-refs files, checking both main ref entries (oid + refname) and peeled entries (for tags). It adds two helper functions: `packed_fsck_ref_main_line` verifies the oid format, spacing, and refname validity (including NULL byte detection from a previous patch), while `packed_fsck_ref_peeled_line` checks peeled tag entries. A new `FSCK_MSG_BAD_PACKED_REF_ENTRY` error message reports problems.

The test suite is expanded with a comprehensive case that creates a malformed packed-refs file containing various errors: invalid oids, missing spaces, bad refnames, and malformed peeled entries. The test confirms the new checks catch all these cases with appropriate error messages.
