This thread covers a patch series adding comprehensive ref consistency checks to Git, with eventual integration into `git fsck`. The work systematically validates various aspects of ref storage, including object existence, file types, header formats, and now NULL byte detection in refnames.

This builds on prior work that already added validation for ref object existence, packed-refs file types, and header formats.
