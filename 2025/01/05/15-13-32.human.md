Bugfix follow-up in the fetch set-head warning series. This is patch 2/3 in a series addressing formatting issues in the advice message shown when a remote's HEAD changes during fetch.

The patch author Bence Ferdinandy responds to Teng Long's observation that the suggested `git config` command in the warning message incorrectly uses the remote's branch name directly rather than the intended `warn-if-not-%s` syntax. This was a mistake in the previous version of the patch that would have produced invalid configuration syntax if users followed the advice literally.

The fix is straightforward - changing the format string to properly suggest `warn-if-not-%s` instead of inserting the branch name directly. This maintains the original intent of allowing users to configure the warning behavior while providing correct syntax.
