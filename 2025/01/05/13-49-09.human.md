First patch in a series adding ref consistency checks, focusing on object existence verification for regular refs in the files backend.

This patch adds validation that regular refs (non-symrefs) actually point to existing objects in the repository, using `parse_object()` to verify object existence. It also checks that branch refs specifically point to commit objects, following the same rules as `git fsck`. The validation reuses the existing `FSCK_MSG_BAD_REF_CONTENT` error reporting mechanism.

The changes are well-contained, adding a new helper function `files_fsck_refs_oid()` while maintaining the existing error handling flow. Test coverage is thorough, with new cases verifying both missing objects and incorrect object types (like tree objects used as branch refs). The patch appears to be a solid foundation for the rest of the series, which will build on this to add more comprehensive ref validation.
