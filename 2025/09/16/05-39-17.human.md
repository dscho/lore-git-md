Follow-up to documentation patch series addressing build system issue. Junio Hamano provides a fix for the AsciiDoc compatibility problem in Julia Evans' patch that renamed and expanded the remote/upstream documentation. This resolves the post-merge CI failure while maintaining the same visual presentation. The change is minimal and focused purely on the build system compatibility, leaving the content and structure of Julia's documentation improvements intact. This appears to be the final resolution of the technical issue that emerged after the patches were merged.
