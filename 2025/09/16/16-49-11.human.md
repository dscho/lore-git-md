Final review for stash.index config feature. Junio C Hamano gives the green light to D. Ben Knoble's patch series that makes `git stash apply/pop` restore the staged changes by default when `stash.index` is set to true. The series addresses the long-standing inconsistency where `stash push` saves staged changes but doesn't restore them by default.

The review notes agreement with Phillip Wood's earlier feedback about keeping test coverage focused on config/flag interactions rather than duplicating all test scenarios. Junio suggests the current default (false) is reasonable for initial rollout, leaving open the possibility of flipping it later based on user feedback. The implementation appears solid, with comprehensive documentation and backward compatibility maintained through the `--no-index` opt-out.

This marks the final approval for a feature that should make stash operations more intuitive while preserving flexibility, clearing the way for inclusion in Git 3.0. The thread shows consensus on both the implementation approach and the pragmatic decision to start conservative with the default setting.
