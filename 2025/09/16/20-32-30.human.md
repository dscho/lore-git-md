This is a feature and bugfix release announcement for tig (Git text-mode interface) version 2.6.0. The release comes from Thomas Koutcher and includes contributions from several other developers.

The update focuses on improving tig's blame and diff functionality, with multiple fixes for line positioning in blame views and diff displays. Notable improvements include blame view working without a working tree, better handling of absolute file paths in blame, and correct line positioning when opening diffs from blame views. The release also introduces a new committer column that users will need to configure in their `.tigrc` files.

On the usability side, there are several help system improvements including new toggle options and better section expansion behavior. The diff view gains the ability to hide +/- signs, and the Unicode support has been updated to version 17 via utf8proc v2.11.0.

The changeset is substantial with 57 files modified, though many are documentation and test updates. The diffstat shows about 8000 lines changed with a net addition of 500 lines. The release appears well-tested with multiple new test cases added for blame and help functionality. This looks like a solid maintenance release addressing both long-standing usability issues (some fixes reference tickets from 2015) and recent regression fixes.
