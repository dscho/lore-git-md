This is a refactoring patch in a 13-part series improving Git's color handling code. It focuses on cleaning up type safety in the `git config --get-colorbool` command.

The patch addresses a minor type system oddity where the result of `want_color()` (a boolean) was being stored in a `git_colorbool` enum variable, even though it worked in practice due to enum values overlapping with boolean values. The change introduces a separate boolean variable to store the `want_color()` result, making the code's intent clearer and improving type safety.

The change is straightforward and mechanical, touching only `builtin/config.c`. It maintains all existing behavior while making the code more type-correct. This is part of a larger effort to standardize and improve Git's color handling code, though this particular patch stands alone as a clean, isolated improvement.
