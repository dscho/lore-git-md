This is patch 4/6 in a refactoring series to establish clearer ODB transaction interfaces, moving code from bulk-checkin to object-file to enable pluggable backends. The patch relocates all transaction-related code from bulk-checkin.[ch] to object-file.[ch], deleting the now-empty bulk-checkin files and updating all callers to use the new location.

The change simplifies the exposed interface by reducing it to just the begin/end transaction functions while keeping all implementation details internal to object-file. The patch is mechanical - it moves 393 lines from bulk-checkin.c to object-file.c with minimal changes beyond adjusting includes and function visibility. The next patch in the series will rename functions to better fit their new home.

This continues the series' progression toward separating the ODB transaction API from its files-backend implementation, a prerequisite for supporting alternative object storage backends. The change has been reviewed and approved by maintainers as part of the overall series.
