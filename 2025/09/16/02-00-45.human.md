Bugfix and cleanup for the `git sparse-checkout clean` series.

This is a follow-up to patch 5/7 in the v3 series that adds a `--verbose` option to `git sparse-checkout clean`. The author (Derrick Stolee) notes that some debugging output (`fprintf(stderr, "list every file in %s\n", directory)`) accidentally remained in the `list_every_file_in_dir()` function. 

The maintainer (Junio C Hamano) confirms this is a trivial issue that can be fixed locally without requiring a resubmission of the patch series. This was the last remaining polish needed for the series, which has otherwise been approved for merging. The debugging output was purely informational and didn't affect functionality, but its removal improves the quality of the verbose output.

The series as a whole implements a new `sparse-checkout clean` command that safely removes tracked-but-sparse directories while preserving untracked files, along with refactoring to remove `the_repository` global state usage in the sparse-checkout code. This particular patch focused on adding verbose output capabilities to help users understand what the clean operation is doing.
