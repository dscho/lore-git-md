This is the third patch in a 6-part refactoring series that's reorganizing Git's object database transaction handling. The patch removes the `flush_odb_transaction()` function, which was previously used to make pending objects visible without completing the transaction.

The change simplifies the transaction interface by ensuring transactions can only be finalized through `end_odb_transaction()`. The patch moves the flushing logic (previously in the standalone function) directly into `end_odb_transaction()`, maintaining the same behavior but with a cleaner API. The removal is safe because there are no remaining callers of the function.

This continues the series' progression toward a more robust transaction model, eliminating intermediate states where objects could be partially visible. The changes are straightforward - just 17 lines removed across two files - and build on the earlier patches' work to establish clearer transaction boundaries. The patch maintains all existing functionality while making the API harder to misuse.
