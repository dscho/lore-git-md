This is a follow-up to a documentation patch series that has already been merged, addressing a build system issue that only surfaced post-merge. The problem occurs when building the documentation with AsciiDoc (as opposed to Asciidoctor) - the `[branch "main"]` configuration example in the updated `urls-remotes-upstreams.adoc` file is being parsed as an AsciiDoc directive rather than literal text, causing the build to fail.

Junio Hamano provides a simple fix that indents the configuration block, which works around the AsciiDoc parsing issue while maintaining the same rendered output when using Asciidoctor. The issue appears to have been missed in CI testing, likely because the tests default to using Asciidoctor.
