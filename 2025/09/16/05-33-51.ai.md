Build system issue in documentation patch series. Junio Hamano reports that the configuration example `[branch "main"]` in the rewritten `urls-remotes-upstreams.adoc` file causes a build failure when using AsciiDoc (though not Asciidoctor). The square brackets are being misinterpreted as an AsciiDoc directive rather than literal configuration syntax.

The proposed fix indents the configuration block with tabs rather than using code fences, which works with both toolchains. This maintains the same visual presentation while avoiding the parsing ambiguity. The issue was caught post-merge in CI testing, highlighting a compatibility gap between the documentation toolchains Git supports.

This follows the merged v2 series from Julia Evans that restructured push/fetch documentation, where this configuration example was added to clarify upstream branch relationships. The thread has seen active discussion about terminology choices and now shifts to addressing this technical build system consideration. The fix is straightforward but raises questions about long-term documentation toolchain requirements and whether to standardize on Asciidoctor.
