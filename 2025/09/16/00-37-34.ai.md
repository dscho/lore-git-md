Test modernization in the stash test suite. This is the first patch in a 4-part series introducing a new `stash.index` config option to control index restoration behavior.

The patch addresses test isolation issue in t3903-stash.sh where some tests were failing when run individually because they depended on a subdirectory` being created by earlier tests. The fix adds `mkdir -p subdir` calls to three test cases that need this directory, making them self-contained. The `-p` flag ensures the command doesn't fail if the directory already exists (which would be the case when running tests sequentially).

This appears to be preparatory work for the main series, ensuring tests can be executed reliably in isolation. The changes are straightforward and focused - each modified test now explicitly creates the directory it needs rather than relying on test ordering. The patch maintains the existing test behavior while removing the implicit dependency on previous tests.
