Feature addition to `git stash` with test feedback. This is the final patch in a series adding configurable index restoration to `git stash` operations, allowing users to make `stash apply/pop` restore staged changes by default via a new `stash.index` config setting.

Phillip Wood provides maintainer feedback on the test coverage, suggesting the new tests could be more focused. While not objecting to the feature itself, he notes the test suite includes many scenarios that don't actually test new behavior beyond what existing `--index` tests already cover. His recommendation is to simplify the test cases to just verify the config's interaction with the core operations, rather than exhaustively retesting every stash scenario with the config enabled.

The patch itself (authored by D. Ben Knoble) implements the promised functionality cleanly, adding the config option and updating the apply/pop logic to respect it while maintaining backward compatibility. The extensive test additions show thoroughness but may benefit from pruning per Phillip's suggestion. The change appears ready for inclusion pending any remaining maintainer feedback on test organization.
