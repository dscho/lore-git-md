Feature release announcement for tig (Git text-mode interface) version 2.6.0, marking a significant update with both bugfixes and new functionality. This release builds on the previous maintenance version (2.5.12) with broader changes across the codebase, touching 57 files with nearly 8,000 lines changed.

The release includes 9 bugfixes addressing various issues in blame view handling, diff display, and editor integration. Notable fixes include proper line tracking in recursive blame operations (#1369, #1370, #1372), correct GIT_EDITOR shell interpretation (#1367), and crash fixes for large diffs (#1389). The improvements introduce several user-facing enhancements: a new committer column (requiring .tigrc updates), background cursor coloring (#1374), diff view +/- sign toggling (#855, #901), and expanded help view functionality (#1381, #1382). The Unicode support has been upgraded to version 17 via utf8proc v2.11.0.

The changes are well-distributed across tig's components, with particular focus on blame.c (34 changes), diff.c (45), and help.c (107). Test coverage appears thorough, with new tests added for blame navigation and updated test expectations. The release maintains tig's cross-platform nature with fixes for both Linux (CI updates) and Windows (AppVeyor build fix).

This represents a substantial but focused update to tig's core functionality, with multiple contributors (Ilya Grigoriev, Johannes Altmanninger, Paul WK joining primary maintainer Thomas Koutcher). The changes suggest careful attention to both user experience and code quality, with documentation updates accompanying each feature. The release follows tig's standard announcement format, providing clear upgrade paths and resource pointers.
