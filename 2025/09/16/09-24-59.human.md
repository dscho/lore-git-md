Test modernization feedback in the final patch of the `stash.index` series.

Phillip Wood responds to D. Ben Knoble's patch series adding configurable index restoration to `git stash`. While the core functionality looks solid, Wood focuses on test style improvements, suggesting that new tests should use modern Git test conventions even if surrounding tests in the same file use older patterns. He argues this makes future maintenance easier and helps with debugging test failures, countering the common argument for file-wide style consistency.

This is a minor stylistic point in the final review of a well-tested feature addition. The series appears ready for merging with only this small test style consideration remaining. Wood notes the preparatory cleanups in earlier patches were welcome and has left separate feedback about the tests on patch 4.

The thread shows consensus on the `stash.index` implementation approach, with reviewers now focusing on polish rather than fundamental design questions. The change remains positioned as a backward-compatible quality-of-life improvement for users who want `stash apply/pop` to restore staged changes by default.
