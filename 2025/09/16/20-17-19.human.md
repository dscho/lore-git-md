Refactoring patch in a series improving Git's color handling. This is patch 4/13 in Jeff King's series to standardize and improve Git's color-related code.

The patch simplifies the logic in `diff_flush_patch_all_file_pairs()` where color-moved detection is handled. Currently there's a redundant check for `o->color_moved` inside a block that's already guarded by `o->emitted_symbols`, which is only set when color-moved is enabled. The patch removes this unnecessary conditional, making the code more straightforward.

The change is a clean simplification that doesn't affect behavior, since the inner condition was always true in practice. The commit message explains this clearly and notes that while the current structure might theoretically support other features using `emitted_symbols`, that would be easy to handle later if needed. This appears to be a well-justified cleanup that makes the code easier to work with for future modifications.
