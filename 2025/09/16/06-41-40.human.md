This is a brief follow-up in the documentation improvement thread. Kristoffer Haugsbakk responds to Junio Hamano's suggestion about creating a dedicated `gitpathspecs(7)` man page by noting they've added it to GitGitGadget's issue tracker (#1971) as a potential task for new contributors. 

The exchange confirms the consensus from earlier in the thread that pathspec documentation should be split from the glossary into its own manual page, following the model of `gitrevisions(7)`. This was identified as a natural next step after the recently completed improvements to the `git checkout` documentation. The issue tracker reference provides a concrete place for contributors to engage with this documentation project.
