This is patch 4/6 in a refactoring series to establish ODB transaction interfaces, moving code from bulk-checkin to object-file to enable pluggable backends. The patch relocates all transaction-related code from bulk-checkin.[ch] to object-file.[ch], deleting the now-empty bulk-checkin files and updating all callers to include object-file.h instead.

The key changes are:
- Moves 393 lines from bulk-checkin.c to object-file.c
- Moves 52 lines from bulk-checkin.h to object-file.h
- Updates 11 files to remove bulk-checkin.h includes
- Adds new transaction API declarations to object-file.h
- Preserves all existing functionality including:
  - Packfile creation
  - Object streaming
  - Batch fsync
  - Transaction state tracking

The relocation simplifies the exposed interface by reducing it to just begin/end_odb_transaction() while keeping the files-backend specific implementation details internal to object-file.c. This is part of the larger effort to separate generic ODB interface from files-backend implementation, enabling future pluggable backends. The patch maintains all existing behavior while cleaning up the code organization.
