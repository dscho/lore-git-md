Test modernization patch for the `stash.index` config series.

This is the first of four patches in D. Ben Knoble's revised series introducing a `stash.index` configuration option. The patch makes the stash test suite more robust by removing dependencies between individual tests. Specifically, it ensures that tests needing a `subdir` directory will create it themselves rather than relying on a previous test to have created it. This allows tests to be run selectively (like with `--run=4,122-`) without failures due to missing directories.

The changes are straightforward - three tests that previously assumed `subdir` existed now explicitly create it with `mkdir -p`. The `-p` flag prevents errors if the directory already exists, maintaining compatibility with the existing test sequence while adding independence. This is a clear improvement to the test suite's reliability, though as noted in the thread context, some test modernization work remains for future patches.

The patch is small and focused, with no behavior changes to the actual stash functionality - it's preparing the test infrastructure for the upcoming config changes. The commit message clearly explains the motivation and effect of the changes.
