Documentation patch improving the description of `git push --mirror` behavior. This is version 2 of the patch, incorporating feedback from Junio Hamano.

The patch rewrites the documentation to clearly describe all three actions that occur during a mirror push: (1) removing refs that exist only on the remote, (2) force-updating refs that exist on both ends, and (3) adding refs that exist only locally. This replaces the previous description which only mentioned local changes.

The change addresses the original omission where the documentation didn't mention that remote-only refs would be deleted during a mirror push. While the initial version just added this detail, Junio suggested a more comprehensive rewrite that systematically covers all mirror operations, which this version now implements.

The patch is straightforward and clearly improves the documentation. It follows Junio's suggestion to present the mirror behavior in three distinct numbered steps, making the complete mirroring semantics more accessible to users. The change is well-considered and appears ready for inclusion.
