This is the first patch in a 2-part feature enhancement series for `git repo info`, now at version 3. It adds a `-z` flag as shorthand for `--format=nul` to make the command's behavior consistent with other Git commands like `git-config` and `git-status` that use null-terminated output.

The patch has been redesigned in v3 per Junio's feedback, now using `OPT_CALLBACK_F` with a shared `parse_format_cb()` function. This implements "last one wins" semantics (so `-z --format=text` would yield text format) and makes `-z` exactly equivalent to `--format=nul`. The implementation removes incorrect usage of `die_for_incompatible_opt2()` and includes tests verifying the new behavior.

Both mentors (Karthik Nayak and Patrick Steinhardt) have signed off on this version, indicating it's technically ready for merging. The changes touch documentation, the command implementation in builtin/repo.c, and add new test cases in t1900-repo.sh. The patch maintains clean separation from the parallel work on object format fields (handled in patch 2/2) and follows Git's standard patterns for option parsing.
