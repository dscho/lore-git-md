This is the second patch in a 2-part feature series enhancing `git repo info`, now at v3, adding object format reporting functionality. The patch adds a new `object.format` field that exposes the repository's hash algorithm (SHA-1 or SHA-256) by reading from `repo->hash_algo->name`.

The implementation follows the established pattern of the command's existing metadata fields, with a new `get_object_format()` helper function in builtin/repo.c that retrieves the hash algorithm name. Documentation is updated to include the new field alongside other repository metadata, and tests verify correct behavior for both SHA-1 and SHA-256 repositories. The patch maintains consistency with `git rev-parse --show-object-format` while fitting into the `git repo info` command's purpose of centralized repository metadata reporting.

This version carries forward the unchanged object format implementation from v2, with both Karthik Nayak and Patrick Steinhardt having signed off on the approach. The patch is technically ready for merging, though broader discussions about future expansion of object-related fields and naming conventions for reference storage format fields remain open but orthogonal to this change.
