This is the second patch in a 2-part feature enhancement series for `git repo info`, now at version 3. It adds a new `object.format` field to report the repository's hash algorithm (SHA-1 or SHA-256), similar to what `git rev-parse --show-object-format` provides.

The patch is straightforward and follows the established pattern of the command's other metadata fields. It adds the new field to the documentation, implements a simple lookup function that reads from `repo->hash_algo->name`, and includes tests verifying correct output for both SHA-1 and SHA-256 repositories. The implementation has been reviewed and signed off by both mentors (Karthik Nayak and Patrick Steinhardt).

This change fits naturally with `git repo info`'s purpose of exposing repository metadata, and the implementation appears solid with proper test coverage. The patch series as a whole (including the redesigned `-z` flag from part 1) seems ready for merging, with only some orthogonal naming questions about the `references.format` field remaining open for future discussion.
