Feature patch adding `-z` flag as shorthand for `--format=nul` in `git repo info`, part of a 2-patch series from GSoC contributor Lucas Seiki Oshiro (v3).

This patch implements the `-`z flag redesign requested by Junio Hamano in previous iterations, using `OPT_CALLBACK_F` with a shared `parse_format_cb()` function. The implementation ensures `-z` is exactly equivalent to `--format=nul` and follows the "last one wins" semantics for format options (e.g. `-z --format=text` yields text format). The changes touch the command's option parsing in builtin/repo.c, documentation in git-repo.adoc, and add new test cases in t1900-repo.sh to verify the behavior.

Key technical details:
- Uses `OPT_CALLBACK_F` to share parsing logic between `--format` and `-z`
- Maintains existing behavior for other format types
- Removes incorrect `die_for_incompatible_opt2()` usage from previous versions
- Tests verify both the basic `-z` functionality and the "last one wins" behavior
- Documentation explicitly states `-z` is an alias for `--format=nul`
