This is a build system patch adding functionality to the new build-helper crate in Git's Rust integration effort. It implements the core linking logic between Rust components and Git's C libraries.

The patch introduces a `BuildHelper` struct that handles conditional linking against Git's C libraries (libgit.a, pcre2-8, and zlib variants) based on the `USE_LINKING` environment variable. The implementation includes path resolution for build directories, environment variable parsing, and proper error handling when required directories or variables are missing. Key features include:

- Environment variable parsing with `parse_bool_from_str()` and `parse_bool_from_option()` helpers
- Directory structure navigation from crate to Git root
- Conditional linking logic controlled by `USE_LINKING` (defaults to true when building normally, false for test builds)
- Required `GIT_BUILD_DIR` environment variable when linking is enabled
- Support for both zlib and zlib-ng variants
- Build dependency tracking via `cargo:rerun-if-changed`

The implementation follows the series' incremental approach, providing the necessary infrastructure for future Rust components to properly link against Git's C libraries while maintaining flexibility for development workflows. The patch maintains compatibility with both Make and Meson build systems and includes clear error messages when required configuration is missing. This is a technical foundation piece that will be used by subsequent Rust components in the project.
