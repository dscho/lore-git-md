Refactoring patch in the command deprecation framework series, moving alias loop detection into `handle_alias()`.

This is patch 3/9 in the v6 series implementing Git's command deprecation system with alias shadowing support. The change relocates the alias loop detection logic from the main command processing loop into `handle_alias()`, where it more naturally belongs. This prepares for upcoming changes that will allow deprecated builtins to be shadowed by aliases.

The patch renames the tracking list from `cmd_list` to the more descriptive `expanded_aliases` and includes a fix from Jeff King that eliminates redundant output in alias loop detection. The change is cleanly implemented with no behavior changes - it's purely a code reorganization to support the deprecation system's needs. The series has been through multiple rounds of review and this version incorporates all previous feedback, making it ready for final consideration.
