This is a refactoring patch that moves signature handling mode parsing from fast-export.c to gpg-interface.[ch] in preparation for adding similar functionality to git fast-import. The patch extracts the `enum sign_mode` definition and its parsing logic (`parse_sign_mode()`) into shared gpg-interface files, making them reusable across commands.

Key technical details:
- Moves `enum sign_mode` with its 5 possible values (SIGN_ABORT, SIGN_VERBATIM etc.) to gpg-interface.h
- Implements new `parse_sign_mode()` function in gpg-interface.c that converts string arguments to enum values
- Updates fast-export.c to use the shared implementation instead of its local version
- Fixes minor indentation issue in fast-export.c's option parsing callback
- Maintains all existing behavior including support for synonym modes ("ignore" for "verbatim", "warn" for "warn-verbatim")

The refactoring enables the subsequent patch to implement signature handling in fast-import using the same shared infrastructure. The implementation appears straightforward with no behavior changes, just code movement and interface consolidation. The patch is part of a well-reviewed series that has already gone through multiple iterations addressing feedback.
