Build system patch for Rust integration in Git. This is part of the larger series porting parts of Git to Rust, specifically focusing on the xdiff subsystem. The patch introduces the foundational build system changes needed to compile and link Rust code alongside Git's existing C code. Key changes include:

- Adds Rust build support to both Makefile and Meson build systems
- Introduces a new `build_rust.sh` helper script to handle cargo invocations
- Makes Rust optional (default on) with `WITH_RUST` flag, though it will become mandatory in Git 3.0
- Handles platform-specific considerations (Windows vs Linux builds)
- Sets up proper linking between C and Rust components

The changes are well-structured and follow Git's existing build patterns while adding the necessary infrastructure for Rust integration. This appears to be a solid technical foundation for the Rust porting coming in subsequent patches. The patch maintains backward compatibility during the transition period.
