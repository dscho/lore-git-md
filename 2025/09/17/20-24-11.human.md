This is a build system fix that's part of the ongoing command deprecation framework series. The patch addresses a specific issue where `git-whatchanged` was still being built as a binary even when marked as deprecated with `WITH_BREAKING_CHANGES`. 

The problem caused confusing behavior - users would try to run the deprecated command and get an incorrect "cannot handle as a builtin" error rather than the proper "not a git command" message. The fix simply wraps the `BUILT_INS` addition of `git-whatchanged` in the same `WITH_BREAKING_CHANGES` conditional used elsewhere, ensuring consistent behavior.

This is the first patch in v6 of the series, which represents the final polishing of the deprecation framework. The change is straightforward and based on a fix originally identified by Jeff King, now properly integrated into the build system. The patch maintains the series' goal of cleanly handling deprecated commands while improving user experience.
