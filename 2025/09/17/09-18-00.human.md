This is a refactoring patch series that completes the transition to using `size_t` for indices in the string-list API, eliminating sign comparison warnings. The series has already been reviewed and approved by Patrick Steinhardt, with only minor stylistic points discussed.

The v2 series makes several improvements over v1:
1. Introduces a new patch to use `bool` for the "exact_match" parameter (which Patrick suggested changing from `int*` to `bool*`)
2. Combines and clarifies the commit messages for better motivation
3. Updates the loop condition in mailmap.c to properly handle `size_t` underflow
4. Finally enables sign comparison warnings in refs.c now that all string-list indices use `size_t`

The changes are mechanical but important for type safety - they maintain identical behavior while allowing the compiler to catch more issues. The series touches several files (add-interactive.c, mailmap.c, refs.c) but all changes are straightforward adaptations to the new API.
