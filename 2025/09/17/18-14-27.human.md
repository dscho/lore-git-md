Feature patch adding signature handling to `git fast-import` to match `git fast-export`'s capabilities. This is the second patch in a 2-part series, implementing the new `--signed-commits=<mode>` option after refactoring shared signature handling code in the first patch.

The patch introduces consistent signature processing for fast-import with modes like "verbatim", "strip", and "abort", similar to fast-export but with "verbatim" as the default (unlike fast-export's "abort"). The implementation cleanly splits signature handling into `import_one_signature()` and `discard_one_signature()` functions, making the logic more maintainable. Notably, the "strip" modes deliberately avoid parsing signatures to handle malformed cases safely.

The accompanying tests verify handling of OpenPGP, X.509, and SSH signatures across all modes, including dual-signature cases and warning message verification. The implementation appears robust, with clear switch statement organization and comprehensive test coverage. This completes the feature parity between fast-import and fast-export for signature handling, with only minor design questions about mode naming remaining open from earlier discussion.
