This is a build system patch that merges the xdiff library into libgit.a as part of the Rust integration effort. The changes remove the separate xdiff library build target and instead compile xdiff components directly into libgit.a, following the same pattern already established for reftable. 

The key modifications include:
- Removing XDIFF_OBJS and XDIFF_LIB variables
- Adding xdiff object files (xdiffi.o, xemit.o, etc.) directly to LIB_OBJS
- Updating GITLIBS to exclude the now-unneeded XDIFF_LIB reference
- Removing xdiff-specific build rules and clean targets
- Updating LIBGIT_PUB_OBJS to reflect the change

This change is part of the broader Rust integration work where xdiff is one of the subsystems being ported to Rust while maintaining C compatibility. The patch follows the same pattern used for reftable, consolidating library components into libgit.a to simplify the build system and Rust linking requirements. The implementation is straightforward and mechanical, removing now-redundant build infrastructure while preserving all xdiff functionality through direct inclusion in libgit.a.
