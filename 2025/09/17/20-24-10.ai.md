This is a v6 revision of the command deprecation framework series, focusing on improving error messages and build system integration for deprecated commands. The series builds on the previously established deprecation infrastructure and alias shadowing support.

Key changes in this version:
1. Adds a new patch (1/9) to properly exclude `git-whatchanged` from `BUILT_INS` when built with `WITH_BREAKING_CHANGES`, fixing a build system inconsistency
2. Incorporates Jeff King's fixes to eliminate redundant output in alias loop detection
3. Maintains all previous functionality including the `deprecated` category for `--list-cmds` and alias shadowing support

The series enhances user experience by:
- Providing more actionable error messages that suggest alternatives to deprecated commands
- Including specific hints for replacing `git-whatchanged` with `git-log` or aliases
- Updating documentation to reflect current state
- Adding comprehensive test coverage for alias shadowing edge cases

Technical details:
- Core changes in `git.c` refine alias handling logic
- Makefile modifications ensure proper build behavior
- Documentation updates cover `BreakingChanges.adoc`, `alias.adoc`, and command-specific man pages
- Test suite expanded in `t/t0014-alias.sh` to verify new behaviors

The series appears well-tested and addresses all previously identified issues, with the v6 changes focused on polishing the implementation based on feedback. The build system fix in patch 1/9 resolves the last remaining technical concern from previous versions.
