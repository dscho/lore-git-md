Refactoring patch to prepare for signature handling in `git fast-import`. This is the first of two patches in a series that will add signature control to `git fast-import` to match existing `git fast-export` functionality.

Christian Couder moves the `enum sign_mode` definition and parsing code from `builtin/fast-export.c` to `gpg-interface.{c,h}` to make it reusable. The refactoring is clean and well-justified - it will allow the upcoming `fast-import` changes to share this logic rather than duplicating it. The patch fixes a minor indentation issue along the way.

This is purely preparatory work with no behavior changes. The implementation looks solid, moving the code while maintaining all existing functionality. The commit message clearly explains the motivation and the change is appropriately scoped. This sets up the foundation for the more interesting second patch that will actually implement the new `fast-import` feature.
