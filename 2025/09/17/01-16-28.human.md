Feature patch in the Rust integration series (8/18). This adds Rust build status reporting in `git version --build-options` and `git bugreport` output, showing whether Git was compiled with Rust support enabled. The change is straightforward - it simply adds conditional output of "rust: enabled/disabled" based on the `WITH_RUST` build flag.

The patch addresses a practical need that emerges from Git's transitional period where some subsystems will have both Rust and C implementations. Knowing whether a particular Git build has Rust enabled will help diagnose any Rust-specific issues that may arise. The implementation is minimal, adding just 6 lines to `help.c` with the standard `#ifdef` pattern used elsewhere in the codebase.

This is a small but useful addition to the larger Rust integration effort, providing visibility tooling that will help both developers and users during the transition period. The patch follows the series' established patterns and has already been reviewed/signed-off by one of the main Rust integration contributors (Ezekiel Newren).
