This is a CI/build system patch in Ezekiel Newren's Rust integration series, specifically addressing Rust toolchain installation in GitHub Actions workflows. The patch consolidates Rust toolchain management across different platforms (Windows, musl, 32-bit containers) with version-specific workarounds for platform quirks.

Eric Sunshine's review focuses on two main points: requesting clarification about PATH rearrangement in MSVC builds (which appears in an earlier patch but lacks explanation), and enforcing Git's shell script style guidelines in the new installation scripts. The review notes several style violations in the shell scripts: using `[ ]` instead of `test`, spaces after redirection operators, and unnecessary blank lines.

The patch itself handles platform-specific Rust requirements: Windows bcrypt resolution (needs Rust 1.78+), musl libc compatibility (1.72+ minimum), and 32-bit container detection issues. It introduces two new scripts (`install-rust-toolchain.sh` and `install-rustup.sh`) for centralized toolchain management, building on Johannes Schindelin's earlier work for library name selection logic.

Key technical details for future reference: the Windows workaround requires different target triples for make (`x86_64-pc-windows-gnu`) versus meson (`x86_64-pc-windows-msvc`) builds, and removes the now-unneeded BITNESS variable from `ci/lib.sh`. The review interaction suggests this patch may need revision to address both the PATH rationale question and script style compliance before final inclusion.
