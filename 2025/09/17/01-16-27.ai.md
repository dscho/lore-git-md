Build system changes for Rust integration in the ongoing xdiff porting effort. This is patch 7/18 in the series implementing Git's Rust adoption strategy.

The patch introduces foundational build system support for compiling Rust code alongside Git's C code. Key changes include:
- New `WITH_RUST` build flag (default true) to control Rust compilation
- Makefile and Meson build system integration for Rust crates
- `build_rust.sh` helper script to handle cargo invocation and library placement
- Rust-specific build targets (`compile_rust`, `rustclean`)
- Platform-specific handling (MSVC vs GNU toolchains)
- Integration of Rust-built static libraries into Git's linking process

The build system is set up to compile multiple Rust crates (though none are defined yet - they'll be added in later patches) and link them into Git binaries. The implementation supports both debug and release builds, with appropriate compiler optimizations for each. The changes maintain compatibility with both Makefile and Meson build systems while adding the necessary infrastructure for the upcoming xdiff and ivec Rust crates mentioned in the commit message.

This is a technical prerequisite for the actual Rust code that will be introduced in subsequent patches. The implementation follows the project's agreed-upon approach of using cbindgen for C/Rust interop (established earlier in the thread) and integrates with Git's existing libification efforts. The build changes are comprehensive but focused - they touch only the minimal necessary parts of the build system to enable Rust support without disrupting existing functionality.
