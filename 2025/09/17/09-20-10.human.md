The changes are straightforward mechanical updates to match the new type-safe API introduced in earlier patches. Both functions iterate over transaction updates, which are now properly sized with `size_t` to match the string-list API changes.

This completes the series' goal of enabling compiler warnings for sign comparisons in the refs subsystem while maintaining identical behavior.
