Build system patch consolidating xdiff into libgit.a as part of Rust integration effort.

This is the third patch in an 18-part series working toward Git's Rust integration, specifically focusing on build system changes needed for Rust/C interop. The patch merges the xdiff library into libgit.a by moving all xdiff object files into LIB_OBJS and removing the separate XDIFF_LIB target. This follows a similar change made for reftable in an earlier patch and helps prepare for Rust components that will need to link against these libraries.

The changes are mechanical but important groundwork: removing XDIFF-specific variables and targets while ensuring all xdiff components remain properly built and linked. The patch shows careful attention to build system details, with clean removal of now-unused xdiff references in OBJECTS, clean targets, and public symbol handling.

This is part of the larger effort to unify library structures before introducing Rust components that will interact with xdiff functionality. The change appears straightforward and well-contained, following established patterns from prior reftable integration. No functional changes to xdiff itself are made - this is purely about build system organization.
