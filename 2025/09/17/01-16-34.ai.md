This is a Rust infrastructure patch adding C/Rust interop header generation to the build-helper crate, part of the ongoing Rust integration series. The patch enables automatic generation of C header files via cbindgen, which will be critical for type-safe communication between Git's C code and new Rust components.

The implementation adds several key pieces:
- A new `cbindgen-template.toml` configuration file with Git-specific settings (POSIX compatibility includes, size_t mapping)
- Header generation logic in `build-helper` that creates `.h` files in the interop directory
- Configuration overrides via a closure-based editor pattern (`generate_header<F>` method)
- Dependency additions for cbindgen and supporting crates (textwrap, once_cell, unicode-width)

The header generation is optional (controlled by `generate_header` flag) and includes proper include guards based on crate names. The template establishes baseline compatibility requirements like `compat/posix.h` inclusion for proper `bool` handling. When enabled, the system generates headers during build and removes stale headers when disabled.

This patch builds on the series' incremental approach by providing the missing piece for type-safe C/Rust interop while maintaining the existing linking infrastructure. The implementation shows careful attention to Git's cross-platform needs and follows the established pattern of configurable, testable components in the Rust migration effort.
