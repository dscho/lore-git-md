This is a CI/build system patch in the ongoing Rust integration series, specifically addressing Rust toolchain installation in GitHub workflows. The patch adds Rust installation logic across different CI environments with platform-specific handling:

For Windows builds, it requires Rust 1.78.0+ due to bcrypt library resolution issues and sets different target triples for Make (x86_64-pc-windows-gnu) vs Meson (x86_64-pc-windows-msvc) builds. Musl builds need Rust 1.72.0+ for libc compatibility, while 32-bit Linux containers require explicit target triple override (i686-unknown-linux-gnu) due to rustup's bitness detection issues.

The implementation introduces two scripts: `install-rustup.sh` for Docker environments where actions-rs/toolchain can't be used, and `install-rust-toolchain.sh` for version/target management. The patch consolidates version requirements in main.yaml's ci-config job outputs and handles PATH/CARGO_HOME setup across all job types. It also adds curl/zlib dependencies that were missing in some environments.

This continues the series' pattern of careful cross-platform support, with Johannes Schindelin contributing to the library selection logic. The changes are well-documented in the commit message with clear rationale for each platform-specific requirement. The patch maintains backward compatibility while enabling Rust builds across the CI matrix.
