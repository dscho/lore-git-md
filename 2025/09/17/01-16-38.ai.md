This is a Rust integration test balloon that reimplements Git's varint encoding/decoding subsystem in Rust as part of the ongoing Rust infrastructure work. The patch completes the misc crate's functionality by adding varint support, following the established pattern for Rust components in Git.

The patch moves varint implementation from C (`varint.c`) to Rust (`rust/misc/src/varint.rs`) when Rust support is enabled, maintaining identical functionality through FFI-compatible functions `decode_varint` and `encode_varint`. The Rust version includes comprehensive tests verifying edge cases and overflow behavior. Build system changes in both Makefile and meson.build conditionally exclude the C implementation when Rust is enabled.

Key technical details include unsafe extern C bindings for FFI compatibility, identical memory layout handling (pointer arithmetic via `add`), and behavior-preserving overflow checks. The implementation demonstrates Rust's memory safety while maintaining the existing C API contract. Test coverage validates all varint edge cases including single-byte values, multi-byte sequences, and overflow conditions.

This serves as a low-risk test case for Rust integration since varint has no dependencies on other Git subsystems. The patch follows the series' established pattern of incremental Rust adoption, with the misc crate now containing its first functional component. The implementation shows how Rust can replace C subsystems while maintaining binary compatibility and adding test coverage.
