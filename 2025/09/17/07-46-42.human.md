This is a build system patch in Ezekiel Newren's Rust integration series, specifically addressing the reftable library's build configuration. The patch merges the reftable library into libgit.a rather than building it as a separate library, following the same pattern as the earlier xdiff library change in the series.

Eric Sunshine provides review feedback, noting the patch appears technically correct but lacks explanation in the commit message about why this change is desirable. This continues a pattern from previous reviews where build system modifications in the series need clearer rationale. The reftable library handles Git's newer reference storage format, making its build configuration changes potentially impactful for users building with Rust support.

The change appears to be part of broader Rust integration infrastructure work, likely simplifying the build process or ensuring proper linkage when Rust components are enabled. However, without explicit motivation in the commit message, reviewers and future maintainers must infer the reasoning. This patch is the fourth in an 18-part series that aims to comprehensively prepare Git's codebase for Rust integration.
