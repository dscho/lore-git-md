This is a test patch in the ongoing command deprecation framework series, specifically testing alias shadowing behavior for regular (non-deprecated) builtin commands.

The patch adds test coverage to verify that regular Git commands cannot be shadowed by aliases, as documented in git-config(1). It tests a sample of builtins (`grep`, `check-ref-format`, etc.) rather than all of them for performance reasons (testing all would add ~600ms to the test suite runtime).

The test confirms that when a user tries to alias a regular builtin (like `git grep`), the original command still runs rather than being shadowed by the alias. This contrasts with the previous patch's tests which verified that deprecated commands *can* be shadowed by aliases.

The implementation uses a helper function `cannot_alias_regular_builtin` that checks each command's help output remains unchanged when an alias is defined. This is part of the comprehensive test suite for the deprecation framework, ensuring the documented behavior around alias shadowing works as expected.

The patch is straightforward and well-contained, focusing specifically on testing the non-deprecated command case while building on the test infrastructure established earlier in the series.
