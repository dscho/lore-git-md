Build system patch consolidating reftable into libgit.a as part of Rust integration effort.

This patch (04/18 in the series) removes the separate libreftable.a build target and merges all reftable object files directly into libgit.a. The changes include: removing the REFTABLE_LIB variable, moving reftable/*.o files into LIB_OBJS, eliminating REFTABLE_OBJS, and updating clean/install targets. This follows the same pattern established for xdiff in earlier patches, creating a unified library structure needed for proper Rust/C interop. The change is mechanical - moving object file declarations while preserving all functionality. This builds on Patch 03's similar xdiff consolidation and supports the series' goal of enabling Rust components to link against a single libgit.a containing all required C dependencies. The patch demonstrates the build system standardization required before Rust components can safely assume access to reftable functionality through libgit.a. No behavior changes are introduced beyond the build structure modification.
