Build system patch adding Rust build status reporting. This is patch 8/18 in the ongoing Rust integration series, adding a simple but important diagnostic feature to help track Rust-related issues during the transition period.

The patch modifies `help.c` to report whether Git was built with Rust support via both `git version --build-options` and `git bugreport` output. This creates visibility into the Rust build status for debugging purposes, particularly useful during the transition period where Rust support is optional and bugs may be Rust-specific. The implementation checks the `WITH_RUST` build flag (established in earlier patches) and adds either "rust: enabled" or "rust: disabled" to the version information output. This aligns with existing build option reporting for features like fsmonitor and libcurl.

The change is straightforward with a clear motivation - helping diagnose Rust-related issues during the optional phase of Rust adoption. It builds on the infrastructure from earlier patches in the series (particularly the `WITH_RUST` flag introduced in patch 7) and follows the pattern of other build option reporting in the version info output. The patch has minimal impact on non-Rust builds and maintains compatibility established by the series' build system changes.
