This is a build system patch in the ongoing Rust integration effort, specifically part of Ezekiel Newren's comprehensive 18-patch series. The patch introduces cbindgen configuration for auto-generating C header files from Rust crates, a key piece of infrastructure for Rust/C FFI.

The patch adds a `cbindgen-template.toml` configuration file that controls header generation, with settings for C compatibility (bool handling via `compat/posix.h`), style (tag-based output), and technical details like pointer sizing. Eric Sunshine's review notes several minor issues: the commit message lacks motivation details (though this appears to be boilerplate infrastructure), some documentation comments have punctuation/grammar problems, and he questions whether the 4-space tab width should match Git's standard 8-space tabs in generated headers.

This appears to be preparatory work - the review confirms there are no current consumers of this functionality. The configuration establishes patterns for future Rust/C interop, particularly around type system alignment (bool handling, size_t mapping) that will be critical for the planned Rust subsystem replacements. The discussion continues Git's pattern of rigorous style review even for infrastructure components, with Sunshine maintaining his role as primary build system reviewer in this series.
