This is a refactoring patch in the xdiff preparation series for Rust compatibility. It removes three unused fields from xdiff's internal data types: `xrecord_t.next`, `xdfile_t.hbits`, and `xdfile_t.rhash`. The patch shows these fields are initialized but never actually used in the code.

The changes are straightforward - the fields are deleted from the struct definitions in `xtypes.h` and all related initialization and cleanup code is removed from `xprepare.c`. The `xdl_classify_record()` function is simplified since it no longer needs to maintain the unused hash chain.

This is part of the larger effort to clean up xdiff internals before potential Rust integration, but stands on its own as a simple cleanup. The patch follows the series' pattern of including a "Best-viewed-with" trailer to help reviewers see the structural changes. As with other patches in this series, there should be no behavior change - this just removes dead code.
