Refactoring patch in the xdiff preparation series for Rust compatibility.

This is the first patch in v2 of Ezekiel Newren's series to clean up xdiff internals ahead of potential Rust integration. The patch is part of a larger effort to simplify xdiff's memory management and type usage to make the code more amenable to integration with Rust.
