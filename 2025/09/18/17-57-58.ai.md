This is a review response to a gitk UI improvement patch about persisting window geometry. Johannes Sixt provides testing feedback and suggestions for Michael Rappazzo's initial implementation that saves/restores the "Tags and Heads" window position.

Key technical points from the review:
- Identifies cross-platform issues: Windows retains position/size during session but Linux only keeps size, and persistence only works when window is open during gitk exit
- Suggests simplifying the implementation by using Configure event handler to set geometry
- Recommends making the geometry parsing fail hard rather than silently returning empty list
- Points out a window positioning edge case where title bar could go offscreen due to correction order
- Notes the relatively large code footprint (73 lines) for this feature

The review maintains a constructive tone while identifying concrete issues found during testing on both Windows and Linux (KDE). It focuses on improving robustness and reducing code complexity rather than questioning the feature's value. The feedback suggests the patch needs revision to handle edge cases better and potentially streamline the implementation approach.
