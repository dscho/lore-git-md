Refactoring patch in the xdiff preparation series for Rust compatibility.

This is patch 4/10 in the second version of Ezekiel Newren's series to clean up xdiff internals ahead of potential Rust integration. The patch removes the `xdl_get_rec()` helper function from xdiff/xemit.c, which was just a thin wrapper around accessing fields of the `xrecord_t` struct. The change directly accesses the struct fields instead, making the code more transparent about its data access patterns.

The modification touches four functions that previously used `xdl_get_rec()`: `xdl_emit_record()`, `match_func_rec()`, and `is_empty_rec()`. The changes are straightforward - each caller now directly accesses `xdf->recs[ri]` and its fields. The patch also includes a minor optimization in `is_empty_rec()` by using a for-loop instead of pointer arithmetic.

This is part of the larger effort to simplify xdiff's internals by removing indirections and making data flow more explicit, which will help with potential Rust integration. The change maintains identical behavior while making the code more direct. The patch is small (25 lines removed, 13 added) and focused, following the pattern of the series' other preparatory cleanups.
