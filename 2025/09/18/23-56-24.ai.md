Refactoring patch in the xdiff preparation series for Rust compatibility.

This patch (v2 05/10) eliminates the `diffdata_t` struct which was serving as a redundant wrapper around fields from `xdfile_t`. The commit demonstrates that each field in `diffdata_t` had a direct equivalent in `xdfile_t`:
- `nrec` -> `nreff`
- `ha` -> `ha`
- `rindex` -> `rindex`
- `rchg` -> `rchg`

The changes involve:
1. Removing the `diffdata_t` struct definition from xdiffi.h
2. Updating `xdl_recs_cmp()` to take `xdfile_t` parameters directly instead of `diffdata_t` pointers
3. Simplifying `xdl_do_diff()` by eliminating the temporary `dd1` and `dd2` structs and passing `xe->xdf1`/`xe->xdf2` directly
4. Updating all field accesses to use the `xdfile_t` fields directly

This is a straightforward cleanup that removes an unnecessary indirection layer while maintaining identical behavior. The patch fits into the larger series' goal of simplifying xdiff's internals for potential Rust integration, though this particular change is language-agnostic. The diff shows significant code reduction (33 lines removed vs 10 added) by eliminating the struct and its temporary instantiations.
