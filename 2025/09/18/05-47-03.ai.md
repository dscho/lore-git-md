This is a test refactoring patch in the ongoing `git refs optimize` implementation series. It prepares the test infrastructure for the new subcommand by making the pack-refs test suite shareable between the existing `git pack-refs` and upcoming `git refs optimize` commands.

The patch moves all test logic from `t0601-reffiles-pack-refs.sh` into a new `t/pack-refs-tests.sh` library file, replacing hardcoded `pack-refs` command calls with a `$pack_refs` variable. The original test file becomes a thin driver that sets this variable and sources the shared test library. This follows the pattern used for other shared test suites like those for `git-for-each-ref` and `git-refs list`.

The test coverage remains comprehensive, verifying all aspects of ref packing behavior including:
- Basic packing/pruning operations
- D/F conflict handling
- Exclusion/inclusion patterns
- Worktree ref handling
- Broken ref edge cases
- Auto-packing heuristics

- Symlink handling

The refactoring maintains all existing test cases while making them reusable for the new subcommand.
