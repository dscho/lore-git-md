This is a test cleanup patch, the first in a 5-part series addressing color handling in `git config`. The patch modernizes the t1300-config.sh test script by moving test expectations inline with the test bodies rather than defining them separately. This matches Git's current test style guidelines.

The changes are mechanical but extensive - nearly 300 lines modified across the test file. The author standardizes on using `<<\EOF` for non-expanding heredocs and `<<-EOF` for indentation-sensitive ones, with two exceptions left unchanged since they're reused across tests. The patch maintains all existing test functionality while making the test file more maintainable and consistent.

This groundwork is part of a larger effort to fix color-related bugs in `git config get --type=color`, but stands alone as a pure test improvement. The changes are straightforward and unlikely to be controversial, having already gone through multiple review iterations.
