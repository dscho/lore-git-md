Documentation patch removing a duplicate fsck message ID. This is a small cleanup in Karthik Nayak's larger reftable fsck validation series (v3, 8 patches + bugfix).

The patch removes a duplicate entry for the `gitmodulesLarge` fsck message ID from `fsck-msgids.adoc`. The message (which flags when a .gitmodules blob is too large to parse) was listed twice in the documentation. This appears to be a simple oversight - the second instance is removed while keeping the first one intact.

While this is a minor change, it's part of a larger effort to improve fsck validation for the reftable backend. The series as a whole is adding comprehensive validation while maintaining separation between Git's fsck infrastructure and reftable internals. This particular patch doesn't affect functionality, just cleans up the documentation.
