This is a refactoring patch in the xdiff preparation series for Rust compatibility. It removes the `xdl_get_rec()` helper function from xdiff/xemit.c, which was serving as an indirection layer to access fields of `xrecord_t`. The patch directly accesses the `xdf->recs[ri]` array and its `ptr` and `size` fields instead, making the code flow more transparent.

The change affects several functions in xemit.c that previously used `xdl_get_rec()`: `xdl_emit_record()`, `match_func_rec()`, and `is_empty_rec()`. Each is updated to work directly with the `xrecord_t` structure. The `is_empty_rec()` function also gets a minor style cleanup, replacing a while loop with a for loop for checking whitespace.

This is part of the larger effort to simplify xdiff's internals before potential Rust integration. The removal of this indirection layer makes the code more straightforward and easier to reason about, though it doesn't change any behavior. The patch is well-contained, touching only xdiff/xemit.c, and follows the series' pattern of removing unnecessary abstractions while maintaining identical diff output.
