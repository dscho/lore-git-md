This is a test refactoring patch in the ongoing `git refs optimize` series. It prepares the test suite for the new subcommand by making the existing pack-refs tests shareable between both commands.

The patch moves all test logic from `t0601-reffiles-pack-refs.sh` into a new `pack-refs-tests.sh` library file, replacing hardcoded `pack-refs` calls with a `$pack_refs` variable. The original test file becomes a simple driver that sets this variable and sources the shared tests. This follows the same pattern used for sharing tests between `git-for-each-ref` and `git-refs list`.

The extensive test suite covers all aspects of reference packing behavior including pruning, exclusion patterns, worktree refs, broken ref handling, and auto-packing heuristics. The refactoring preserves all this coverage while making it reusable for testing the new `refs optimize` command.

This is patch 8/9 in the series, building on the architectural framework established earlier.
