Refactoring patch in the xdiff series preparing for Rust compatibility. This patch (v2 06/10) removes the redundant `xdfile_t.ha` array, as its contents can always be derived from `xdfile_t.recs[xdfile_t.rindex[i]]->ha`. The change makes the code about 5% slower but simplifies future cleanups by eliminating this duplication.

The patch modifies three files: xdiffi.c (where it introduces a new `get_hash()` helper function and updates all hash comparisons to use it), xprepare.c (removing allocations and assignments for the `ha` array), and xtypes.h (removing the field declaration). The commit notes this is part of preparatory work before creating a dedicated struct for classic diff algorithms (Myers and minimal), with a follow-up patch planned to investigate removing the `cha` storage arena.

This change maintains identical diff output while simplifying the codebase, though with a measured performance tradeoff. The patch is part of the larger v2 series that has already incorporated review feedback and is now ready for merging to 'next', separate from the pending Rust-specific changes.
