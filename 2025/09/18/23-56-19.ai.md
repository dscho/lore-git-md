This is the v2 of the xdiff refactoring series, now split into two parts with only the preparatory cleanups (patches 1-9) included here, while the Rust-specific type changes will be handled in a separate follow-up series. The changes focus on simplifying xdiff internals to make them more Rust-FFI friendly while maintaining identical behavior.

Key technical changes in this version:
- Patch 8 removes the chastore_t arena allocator from xdfile_t, switching to contiguous array storage for xrecord_t records. This provides a 5% performance improvement while simplifying memory management.
- Patch 9 introduces YES/NO/MAYBE macros for rchg values to make the code more readable, though the MAYBE state remains unused in practice.
- Performance impacts are now documented in commit messages, with measurements showing tradeoffs between different cleanup approaches (e.g., removing ha array makes code 5% slower while removing chastore makes it 5% faster).
