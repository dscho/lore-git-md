Performance optimization patch in the xdiff refactoring series, replacing the chastore_t arena allocator with a contiguous xrecord_t array.

This patch (v2 08/10) from Ezekiel Newren's series removes the chastore_t arena allocator from xdiff's xdfile_t structure, replacing it with direct allocation of a contiguous xrecord_t array. The change provides a 5% performance improvement in the author's benchmarks while simplifying memory management. The patch updates all xdiff algorithms (myers, histogram, patience) to work with the new storage model, changing pointer access patterns from `xdf->recs[i]` to `&xdf->recs[i]` throughout the code.

Key technical details:
- Removes `chastore_t rcha` from xdfile_t struct
- Changes `xrecord_t **recs` to `xrecord_t *recs` (now a direct array)
- Updates all xdiff algorithms to use array indexing instead of pointer dereferencing
- Maintains identical diff output
- Includes performance measurements showing 5% speedup
- Part of larger preparatory cleanups for Rust compatibility

The change is performance-motivated and well-documented with benchmarks showing the 5% improvement when removing chastore while keeping the ha array. The patch has already been reviewed and approved for merging to 'next' as part of the non-Rust-specific preparatory cleanups.
