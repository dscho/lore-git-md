This is the second patch in a bugfix series addressing `git rebase --autosquash` behavior regarding `commit.cleanup` configuration. The patch removes the now-obsolete VERBATIM_MSG flag from sequencer.c, completing the changes started in patch 1.

The VERBATIM_MSG flag was originally introduced in commit f7d42ceec52 to preserve commit messages during fixup operations, but is no longer needed after the fixes in patch 1 made the sequencer properly respect `commit.cleanup` configuration for fixup commits. The removal is straightforward, deleting the flag definition and all related conditionals, including a BUG() assertion that checked for mutually exclusive flags.

The patch shows good attention to detail by cleaning up all vestiges of the old behavior - not just removing the flag definition but also eliminating the now-unnecessary conditionals and cleanup logic that handled it. This follows the principle of leaving no dead code behind after a behavioral change.

As the second part of a focused two-patch series, this change builds on the test coverage added in patch 1, which already verified the new behavior works correctly. The series as a whole provides a clean solution to the original issue where fixup commits weren't properly respecting the commit.cleanup configuration.
