Refactoring patch in the xdiff preparation series for Rust compatibility.

This patch (v2 05/10) from Ezekiel Newren eliminates the `diffdata_t` struct, which was found to be redundant as all its fields were direct copies of fields from `xdfile_t`. The change simplifies the code by removing this indirection layer and having functions work directly with `xdfile_t` instead. The patch updates `xdl_recs_cmp()` to take `xdfile_t` parameters instead of `diffdata_t`, and removes the struct definition from xdiffi.h along with the temporary variable setup in `xdl_do_diff()`.

This is a straightforward cleanup that maintains identical behavior while reducing code complexity. It's part of the larger preparatory series (patches 1-9) that has already been reviewed and is now ready for merging to 'next', separate from the more controversial Rust-specific changes that will follow in patches 10-17. The change aligns with the series' goal of simplifying xdiff internals to make future Rust integration easier.
