Implementation of files backend for ref optimization.

This is the second patch in Meet Soni's 9-part series implementing the new `git refs optimize` command, which will eventually replace `git pack-refs`. Following the foundational API patch that established the `refs_optimize()` interface, this patch provides the files-backend implementation.

The change is straightforward - it wires up the new `optimize` operation in the files backend to simply call the existing `files_pack_refs()` function, since packing is how the files backend optimizes its reference storage. The patch adds a thin wrapper function and updates the backend's virtual table to include the new operation.

This keeps the series moving forward while maintaining existing behavior, as the actual optimization/packing logic isn't changing yet. The patch is cleanly focused, with a clear explanation of why the simple delegation approach is appropriate for this backend. It's part of a well-structured series that's systematically building out the new functionality while preserving compatibility with existing behavior.
