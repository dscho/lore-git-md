Refactoring patch in the xdiff series preparing for Rust compatibility. This is patch 6/10 in the v2 series of preparatory cleanups (the Rust-specific changes will come later).

The patch removes the redundant `xdfile_t.ha` array, which hash values can instead be looked up through `xdfile_t.recs[xdfile_t.rindex[i]]->ha`. The change makes the code about 5% slower but simplifies the data structure and paves the way for further cleanups. The performance impact is noted as temporary until future optimizations land.

The change affects the classic diff algorithms (Myers and minimal) by replacing direct array access with a new `get_hash()` helper function. The patch maintains identical diff output while removing dead code and redundant storage. This is part of a larger effort to simplify xdiff internals before potential Rust integration.

The series has already incorporated review feedback and performance measurements, with this patch being one of the structural simplifications that will make subsequent changes easier to follow. The preparatory series (patches 1-10) is now considered ready for merging to 'next'.
