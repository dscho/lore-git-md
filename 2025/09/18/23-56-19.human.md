This is a refactoring series preparing xdiff internals for potential Rust compatibility, now split into two parts with this v2 focusing solely on the preparatory cleanups (patches 1-10). The Rust-specific changes will follow in a separate series.

Ezekiel Newren's v2 addresses review feedback from Elijah Newren and others by:
- Splitting the series into two distinct parts (cleanups vs Rust changes)
- Adding commit message clarifications
- Including performance impact analysis
- Making style cleanups

The key technical changes in this cleanup series include:
- Removing unused fields from xrecord_t and xdfile_t
- Simplifying memory management by eliminating redundant structures
- Converting xdfile_t.recs from an array of pointers to a direct array
- Replacing the chastore arena allocator with simpler array storage
- Documenting implicit assumptions about rchg values

Performance impacts are mixed - some changes show 5% speedups while others show 5% slowdowns, with the overall impact being roughly neutral. The changes maintain identical behavior while making the code more straightforward and Rust-FFI-friendly.

The series has been reviewed positively overall, with Junio C Hamano indicating these cleanups can merge to 'seen' and then 'next' after final documentation and style polish. The Rust-specific changes remain under separate discussion. This appears to be a well-considered set of preparatory changes that simplify xdiff internals regardless of whether Rust integration proceeds.
