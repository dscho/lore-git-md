This is the final patch in a refactoring series preparing xdiff internals for Rust compatibility. It introduces named constants (NO, YES, MAYBE) for the `rchg` array values that track line changes are included in the diff, replacing magic numbers 0/1/2 throughout the xdiff codebase.

The change is purely about code clarity - the commit message explains that while some conditionals now explicitly check for `== YES` where they previously just tested truthiness, this doesn't change behavior since MAYBE is only used temporarily during diff calculation and never persists in the final `rchg` array. The patch touches all xdiff algorithms (myers, histogram, patience) to maintain consistency.

As part of the larger series that has already been reviewed, this patch follows the established pattern of simplifying xdiff's internals while maintaining identical diff output. It includes the now-standard "Best-viewed-with" trailer to highlight the mechanical nature of the changes when reviewing the diff. With this final cleanup, the preparatory non-Rust-specific portion of the xdiff refactoring is complete.
