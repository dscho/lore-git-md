This is a follow-up discussion about the behavior of Git aliases with the new worktree advice messages introduced in Gabriel Scherer's patch series. Ben Knoble responds to Kristoffer Haugsbakk's observation that the new advice messages don't appear when using checkout aliases, while older advice messages do.

The key point is that aliases execute as subprocesses using the system Git, which may not have the new advice messages. Ben suggests using the bin-wrappers/git during development to ensure the test environment matches the built version. This appears to be a minor development/testing consideration rather than a fundamental issue with the patch series itself.

The exchange highlights an edge case that developers should be aware of when testing new advice messages, but doesn't indicate any problems with the core functionality being proposed. The thread continues to focus on polishing the user experience around the new worktree safety checks.
