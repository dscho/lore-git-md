This is a test patch in the command deprecation framework series, specifically verifying that regular (non-deprecated) builtins cannot be shadowed by aliases. The patch adds test coverage for the documented behavior that Git ignores aliases that would hide existing commands, except for deprecated ones.

The test creates aliases for a sample of builtin commands (`grep`, `check-ref-format`, etc.) and confirms that Git continues to execute the original command rather than the alias. The test is intentionally limited to a representative sample rather than all builtins to avoid excessive runtime overhead (about 600ms per full run).

This patch builds on the series' earlier work that established the infrastructure for deprecated command handling and alias shadowing. It serves as a validation that the system correctly distinguishes between deprecated commands (which can be shadowed) and regular commands (which cannot). The test implementation follows the same pattern as previous tests in the file, using `test_might_fail` to handle commands that may legitimately fail when run with `-h`.
