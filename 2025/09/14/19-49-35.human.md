This is the first patch in a finalized series implementing command deprecation with alias shadowing support. It adds a new `deprecated` category to Git's experimental `--list-cmds` interface, allowing users to query which builtin commands are deprecated. The patch marks `pack-redundant` and `whatchanged` as deprecated (when `WITH_BREAKING_CHANGES` is not set) and introduces the `DEPRECATED` flag (1<<6) in the command flag system. The implementation includes a BUG check to prevent mutually exclusive list options and updates the documentation to reflect the new category.

This is a well-polished version (v5) that incorporates feedback from previous iterations, including Patrick Steinhardt's suggestions about code formatting and loop refactoring. The patch serves as foundational infrastructure for the larger deprecation system, with subsequent patches building on it to handle alias shadowing and user messaging. The implementation looks solid, with clear commit messages and appropriate test coverage mentioned in the series notes.
