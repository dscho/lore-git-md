This is a bugfix and usability improvement patch in the worktree safety checks series. Gabriel Scherer responds to Kristoffer Haugsbakk's feedback about the advice message wording when a checkout fails due to another worktree having the branch checked out.

The key change is a clearer advice message that now:
1. Explicitly warns about branch changes affecting other worktrees
2. Separates the `--ignore-other-worktrees` suggestion (shown always) from the `--detach` suggestion (shown only when detach advice is enabled)
3. Uses more direct language about consequences rather than the original phrasing that could imply `--detach` "avoids" restrictions

The response indicates Gabriel is also addressing other minor polish items from Kristoffer's review (enum ordering, commit message formatting) but focuses here on the substantive advice message improvement. This appears to be the final round of refinements before the patch is ready for acceptance, with all core functionality already implemented and tested in previous versions.
