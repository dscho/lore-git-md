The change is minimal - just removing one sentence while maintaining the core warning that `git whatchanged` will be removed. This follows earlier patches in the series that established the deprecation framework, implemented alias shadowing, and improved user messaging. The series has already addressed all technical aspects and received maintainer approval in previous iterations, with this patch serving as final documentation polish.

The patch appears straightforward and uncontroversial, aligning with the series' goal of cleaning up documentation while maintaining clear migration guidance for deprecated commands. It doesn't introduce any new technical changes beyond what was already approved in the v4 iteration of this series.
