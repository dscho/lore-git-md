This is part of the ongoing xdiff internals refactoring series aimed at modernizing the diff algorithm implementation. Patch 9/12 in v6 removes the `chastore_t` arena allocator from `xdfile_t`, replacing it with direct array allocation for records.

The change simplifies the code structure by eliminating redundant memory management while maintaining identical diff behavior. Performance measurements show a 5% speedup from removing `chastore_t`, though this is offset by a 5% slowdown from removing the `ha` array in previous patches, resulting in roughly neutral net performance impact.

The patch updates all record access patterns to work with the new contiguous array storage rather than pointer indirection. This continues the series' pattern of removing legacy data structures that complicate the code without providing meaningful benefits. The commit message notes this change also improves FFI compatibility, though the primary motivation remains code simplification.

This appears to be a well-justified cleanup that follows the established pattern of the series. All prior feedback has been addressed, and the change maintains the diff algorithm's behavior while making the code more straightforward. The performance tradeoffs have been measured and deemed acceptable for the structural benefits.
