Feature request for root-level file sharing between repositories. The proposal specifically targets configuration files that tools expect at project roots - linters, CI configs, licenses - where maintaining consistency across multiple repositories currently involves manual updates or workarounds. The author acknowledges existing alternatives but argues they add undesirable indirection compared to potential first-class Git support.
