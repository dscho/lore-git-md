>
> What did you expect to happen? (Expected behavior)
> I expected the same behavior as with Git-2.45.2-64-bit.exe. In that version, I could use Git Bash to run Makefile targets that launch GUI applications (like Vivado) using the command chaining or backgrounding operator (&).
