This is a refactoring patch in the xdiff modernization series, removing unused fields from xdiff data structures. The patch eliminates three fields that were initialized but never actually used in the code:

1. `xrecord_t.next` - a pointer to the next record in a hash chain
2. `xdfile_t.hbits` - hash table size information
3. `xdfile_t.rhash` - the hash table itself

The changes are straightforward removals with no behavior impact:
- `xdl_classify_record()` no longer maintains the unused hash chain
- `xdl_free_ctx()` skips freeing the now-removed rhash
- `xdl_prepare_ctx()` stops allocating the hash table
- The struct definitions in xtypes.h are simplified

This continues the series' cleanup of xdiff internals, building on prior work that eliminated other redundant structures like diffdata_t and chastore_t. The removal is safe since the fields were provably unused, and the patch follows the series' pattern of simplifying the codebase while maintaining identical diff behavior. The changes are mechanical and unlikely to be controversial, though they do touch core xdiff data structures.
