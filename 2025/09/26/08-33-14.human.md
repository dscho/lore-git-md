This is a feature request proposing first-class Git support for sharing root-level files across repositories. The author, George Ogden, identifies a gap in Git's current capabilities where commonly shared configuration files (like `.pre-commit-config.yaml`, linter configs, or licenses) need to live at the repository root but cannot be easily shared via submodules (which require subdirectories).

The proposal is motivated by real-world maintenance pain points - currently requiring manual updates across multiple repositories when shared root files change. While workarounds exist (subtrees, symlinks, external tooling), the author argues these add unnecessary indirection compared to native Git support.

The request appears thoughtfully presented, clearly articulating the use case without prescribing a specific implementation. It acknowledges potential prior art ("apologies if this has been discussed") and invites technical feedback on feasibility. The problem space seems legitimate for projects maintaining consistency across many repositories, though the solution would need careful design to avoid complicating Git's model.
