Refactoring patch in the xdiff internals modernization series. This is patch 6/12 in v6 of the series, which removes the now-redundant `diffdata_t` struct and updates all callers to directly use the equivalent fields in `xdfile_t` instead.

The patch eliminates a layer of indirection that was likely kept for historical compatibility. The commit message explains that each field in `diffdata_t` was just an alias for a field in `xdfile_t`, making the struct unnecessary. The changes are mechanical - replacing `dd1->field` with `xdf1->field` throughout the diff algorithm implementation.

This continues the series' theme of simplifying xdiff's internal structure by removing redundant abstractions. The changes are behavior-preserving and have been reviewed through multiple iterations of the patch series. The removal of this struct was likely deferred from earlier patches since it required updating the recursive `xdl_recs_cmp()` function signature and all its callers.

The patch is part of the larger effort to modernize xdiff's internals for better maintainability and potential Rust integration, though this particular change appears motivated more by code cleanliness than Rust-specific needs. It removes 33 lines while adding 10 (net -23), continuing the series' trend of reducing code size while maintaining identical behavior.
