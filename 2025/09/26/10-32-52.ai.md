Bugfix completing a 3-patch series addressing curl_easy_setopt() type mismatches in Git for Windows ARM64 builds. This final patch updates http-push.c to use CURLOPT_INFILESIZE_LARGE with the new cast_size_t_to_curl_off_t() helper, matching the approach taken in earlier patches for HTTP and IMAP code paths.

The change fixes a clang warning that surfaced after a libcurl update in Git for Windows ARM64 CI, where CURLOPT_INFILESIZE expected a long but received a size_t from buffer->buf.len. The solution replaces the direct size_t usage with the more appropriate CURLOPT_INFILESIZE_LARGE option (available since curl 7.11.0) and the centralized type-conversion helper introduced in patch 1 of the series.

This completes the type-safety improvements across all affected curl interactions in Git. The patch is minimal (3-line change) and follows the same pattern as the previous fixes in the series.
