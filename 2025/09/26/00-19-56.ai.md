This is a documentation and build system patch series aiming to improve technical documentation formatting consistency between Makefile and meson builds. The cover letter describes a 4-part series that:

1. Adds several technical documentation files to the Makefile build that were previously only built by meson (commit-graph.adoc, directory-rename-detection.adoc, etc.)
2. Attempts to fix asciidoc formatting warnings in remembering-renames.adoc, particularly around list numbering and section levels
3. Addresses similar issues in sparse-checkout.adoc
4. Fixes formatting problems in commit-graph.adoc, especially around monospaced text containing curly braces

The author notes significant challenges with asciidoc formatting, including:
- Python 3.12 warnings about invalid escape sequences (fixed in asciidoc 10.2.1)
- Persistent warnings about list numbering and section levels
- Inconsistent rendering between asciidoc and asciidoctor
- Problems with monospaced formatting when text contains curly braces

Key technical details for future reference:
- Files affected: commit-graph.adoc, remembering-renames.adoc, sparse-checkout.adoc
- Build system changes: Documentation/Makefile additions
- Formatting issues center around list numbering (0-based vs 1-based), section level sequencing, and monospace formatting with special characters
- The author marks patches 2-4 as RFC due to unresolved formatting challenges

The series appears to be a genuine attempt to improve documentation consistency, though the author openly acknowledges needing help with the asciidoc-specific formatting issues. The changes are focused on presentation rather than content, and the author provides detailed reproduction steps for the various warnings encountered.
