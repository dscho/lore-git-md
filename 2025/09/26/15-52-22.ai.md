Documentation formatting discussion.

Junio C Hamano responds to Ramsay Jones's documentation formatting patch for commit-graph.adoc, raising questions about the proposed changes. While acknowledging the technical merits of the atx-style headers (= prefixes) over underlined headers, Junio notes that most Git manual pages currently use the underlined style and questions whether there are actual warnings that would necessitate changing this convention. The discussion highlights a tension between standardization (the patch's goal of aligning with newer documentation conventions) and existing practice (the widespread use of underlined headers across Git's documentation). Junio's comments suggest this may not be a purely mechanical change but one that warrants broader discussion about documentation style preferences. The technical content of commit-graph.adoc remains unchanged - this is about source formatting choices.
