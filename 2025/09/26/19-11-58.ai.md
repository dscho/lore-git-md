This is an annual status report from the Git Project Leadership Committee (PLC) to the community, covering financials, trademark matters, and project governance under the Software Freedom Conservancy (SFC). The report follows a similar format to previous years and comes ahead of the Git Merge conference.

The Git project's finances remain healthy with $99k USD in reserves, showing a $6k increase from last year. Income primarily comes from donations (97%) and Amazon affiliate royalties (3%). Notable expenses include $1,847 for conference travel (up from $676 last year) and $1,250 for trademark filings. The project has transitioned git-scm.com hosting to free GitHub Pages, saving ~$721 annually.

Trademark activity included a standard renewal and a petition against a third-party infringement. The PLC continues to field non-compliant usage requests but hasn't changed the trademark policy. The report raises questions about potential future spending, including possibly self-funding Outreachy internships (currently sponsored by GitHub/GitLab).

The PLC members (Junio C Hamano, Christian Couder, Ævar Arnfjörð Bjarmason, and Taylor Blau) maintain oversight of these non-technical aspects while emphasizing SFC has no influence on technical direction. The report invites community discussion, both on-list and at the upcoming Contributor Summit.
