This is a technical discussion in the ongoing Rust infrastructure thread, comparing C language features to Rust's safety and concurrency mechanisms. Ezekiel Newren responds to Eric Wong's question about what modern C lacks compared to Rust, providing a detailed feature-by-feature analysis.

Newren notes some C23 and compiler-specific improvements (like Clang's `__counted_by__` attribute) but emphasizes fundamental gaps in C's design that make Rust's compile-time guarantees impossible to replicate.

The discussion remains technical rather than ideological, focusing on concrete language mechanisms rather than subjective preferences. It builds on prior exchanges about Rust's safety advantages while acknowledging areas where C has made progress (checked arithmetic in C23, compiler extensions for format string checking).
