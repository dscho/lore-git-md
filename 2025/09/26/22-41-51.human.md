Cleanup patch in the xdiff modernization series. This is part of Ezekiel Newren's ongoing effort to simplify xdiff's internals, now removing a now-unnecessary helper function `xdl_get_rec()` that was originally used when records were stored in a linked list. With records now stored in a contiguous array, direct access is trivial and the wrapper function just adds indirection.

The patch removes the function and inlines its simple array access logic at all four call sites in xemit.c. This continues the series' trend of eliminating unnecessary abstractions and simplifying the codebase. The change is mechanical and clearly safe, as it doesn't alter any behavior - it just removes an extra function call layer that served no purpose after earlier structural changes in the series.

This patch follows the same pattern as previous cleanups in the series, where historical implementation details are removed as the code evolves. It's a straightforward improvement that reviewers have already conceptually approved through earlier structural changes in the series.
