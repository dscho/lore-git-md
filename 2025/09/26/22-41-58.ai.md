Refactoring patch in the xdiff modernization series, introducing named constants for line classification states.

This patch (v6 11/12) continues Ezekiel Newren's systematic refactoring of xdiff internals by replacing magic numbers 0/1/2 with named constants DISCARD, KEEP, and INVESTIGATE in xprepare.c. These constants represent the three possible states for line classification during diff processing. The change improves code clarity by making the state machine explicit, particularly in xdl_clean_mmatch() and xdl_cleanup_records() functions.

Key technical changes:
- Adds #defines for DISCARD(0), KEEP(1), INVESTIGATE(2)
- Renames dis* variables to action* to better reflect their purpose
- Updates all related conditionals to use the new constants
- Adds BUG() checks for invalid state values
- Maintains identical diff behavior while improving type safety
- Prepares for future conversion of changed[] array to bool type

The patch is part of the final refinements in the v6 series, following earlier structural simplifications like chastore_t removal and rchg->changed rename. It continues the pattern of improving code clarity and type safety while preserving the original diff algorithm's behavior. The changes are well-explained in the commit message, with clear documentation of the state transitions and their meanings.
