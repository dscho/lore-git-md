This is a refactoring patch in the final stages of the xdiff internals modernization series. It eliminates local variable aliases in xdiff/xemit.c that were duplicating fields from the xrecord_t struct, making the code more consistent with the rest of the xdiff implementation.

The changes are straightforward mechanical improvements:
- Replaces direct char*/size pairs with xrecord_t* variables
- Simplifies whitespace checking in is_empty_rec() by using array indexing
- Maintains identical behavior while reducing indirection
- Follows the series' pattern of cleaning up xdiff's internal structure

This patch continues the series' goal of making the code more maintainable and Rust-compatible by removing unnecessary indirection. The changes are low-risk since they don't modify the actual diff algorithm - they just make the implementation more direct by accessing struct fields rather than copying them to local variables first.

The patch has already been through multiple rounds of review as part of the larger series, which is now in its final form (v6) and ready for merging. This particular change was uncontroversial and aligns with the series' established pattern of simplifying xdiff's internal data access patterns.
