Thread summary:

Documentation formatting cleanup patch series (part 4) targeting commit-graph.adoc, part of Jean-Noël Avila's ongoing effort to standardize man page formatting. The patch converts heading styles from underline to atx format (`====` -> `=`), normalizes code block delimiters to `----`, fixes section level consistency (`##` -> `===`), escapes special characters (`{hash}` -> `\{hash\}`), and adds whitespace around lists. While technically correct and following newer documentation conventions, Junio C Hamano questions whether the header style change from underlined to atx format is necessary given that the majority of Git manual pages currently use underlined headers. Junio acknowledges the maintenance benefits of atx-style headers but personally finds underlined headers easier to read in source form, suggesting this may warrant broader discussion about documentation style preferences. The discussion reveals a tension between standardization (the patch's goal) and existing practice (widespread use of underlined headers). No substantive changes to commit-graph functionality or behavior are proposed - this is purely about documentation source formatting choices. Key open question: should Git standardize on atx headers despite most existing docs using underlines? Ramsay Jones is the patch author; Junio C Hamano is the maintainer raising style concerns.
