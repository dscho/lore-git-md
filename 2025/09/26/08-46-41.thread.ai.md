Bug report: Git Bash on Windows fails to properly detach GUI processes when launched with & in version 2.51.0. Tiago Gomes reports a regression in Git for Windows 2.51.0 where backgrounding GUI applications with & no longer works as expected, specifically affecting workflows launching GUI tools (like Vivado) from Git Bash while maintaining console interactivity. 

Johannes Schindelin (Git for Windows maintainer) tested a preview build (2.51.0.windows.1.77.gade1f1c136.20250926063933) and found `git gui &` detaches correctly, suggesting the issue may be specific to the official 2.51.0 release rather than the version generally. He requests Tiago test the preview build from GitHub Actions run 18030062242 to verify, noting the portable version avoids installation conflicts. The test case demonstrates working backgrounding via `git gui &` followed by `pwd`, contrasting with Tiago's reported blocking behavior. 

Current status: regression confirmed in official 2.51.0 but appears fixed in newer preview builds. Open question remains whether this was an intentional fix or incidental change. Key technical detail is the Windows-specific process handling difference between versions, with the preview build showing expected behavior. Next step is verification from original reporter using the provided test build.
