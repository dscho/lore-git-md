This is a documentation and build system patch series aiming to bring consistency between the Makefile and meson builds for technical documentation. Ramsay Jones is working to include several technical documentation files in the Makefile build that are only built by meson currently, but has run into asciidoc formatting issues that need community help to resolve.

The series adds 8 technical docs to the Makefile build that are meson-only today, including files covering commit-graphs, sparse-checkout, and rename detection. The first patch is straightforward, but subsequent patches attempt to fix asciidoc warnings that appear when building the docs - mostly around list numbering and section heading levels. The author notes particular challenges with the remembering-renames.adoc and sparse-checkout.adoc files, including issues with monospace formatting of text containing curly braces.

The patches represent an improvement over the status quo but still have formatting problems the author couldn't resolve, especially when using newer Python versions (3.12+) that trigger syntax warnings. The series is marked RFC as the author seeks help from those more familiar with asciidoc to properly fix the remaining issues before finalizing the changes. This appears to be part of a larger effort to align build systems, with the author mentioning this is a subset of pending "misc build updates" work.
