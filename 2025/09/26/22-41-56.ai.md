Refactoring patch in the xdiff modernization series, removing the chastore allocator.

This patch (v6 09/12) from Ezekiel Newren eliminates the chastore_t arena allocator from xdiff's xdfile_t structure, completing the removal of redundant data structures in the xdiff internals. The change makes xdiff store records directly in a contiguous array rather than using the custom allocator, simplifying memory management while maintaining identical diff algorithm behavior.

Key technical details:
- Removes xdfile_t.rcha (chastore_t) and converts xdfile_t.recs from an array of pointers to a contiguous array of xrecord_t
- Updates all record access patterns throughout xdiff (xdiffi.c, xemit.c, xhistogram.c, xmerge.c, xpatience.c, xprepare.c, xutils.c)
- Performance impact is neutral when combined with previous ha array removal (1% slower in benchmarks)
- Part of broader effort to simplify xdiff internals for Rust compatibility and maintainability
- Follows earlier patches that removed diffdata_t, ha array, and xdlclass_t field duplication

The change is well-contained and mechanical, updating record access patterns to use direct array indexing rather than pointer dereferencing. This completes the structural simplification of xdiff's core data structures while preserving the exact same diff output behavior.
