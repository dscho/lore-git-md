This is part of Ezekiel Newren's ongoing xdiff internals refactoring series (v6 07/12), which modernizes the diff algorithm implementation. The patch removes the redundant `xdfile_t.ha` array that duplicated hash values already stored in `xdfile_t.recs[xdfile_t.rindex[i]]->ha`. 

The change makes the code about 5% slower but simplifies the data structure by eliminating this unnecessary indirection. The commit notes this is a preparatory step toward eventually creating a dedicated struct for the classic diff algorithm (Myers/minimal), though that requires more cleanup first. 

This appears to be a straightforward mechanical cleanup that follows the series' pattern of removing redundant data structures. The performance impact is acknowledged but deemed acceptable given the structural simplification. The patch is well-contained, touching only internal xdiff interfaces, and maintains identical diff algorithm behavior.
