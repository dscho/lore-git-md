This is a refactoring patch in the ongoing xdiff internals modernization series, specifically eliminating redundant field storage in the xdlclass_t struct by embedding an xrecord_t instead of duplicating its fields.

The patch removes three fields from xdlclass_t (ha, line, size) that were direct copies of fields from xrecord_t, replacing them with an embedded xrecord_t struct. This simplifies the code by removing the need to manually keep these fields in sync. The changes affect xdiff/xprepare.c, updating all access sites to use the embedded record's fields instead (rec.ha, rec.ptr, rec.size).

Key technical points:
- The change is purely structural - no behavior or algorithm changes
- Updates xdl_classify_record() to use the embedded record fields
- Removes 10 lines while adding 4 (net -6)
- Part of the series' broader goal of eliminating redundant data structures
- Prepares for future type changes in xrecord_t by centralizing field access
- Phillip Wood provided help/review (acknowledged in sign-off)

This follows the pattern established in earlier patches of simplifying xdiff internals by removing unnecessary indirections and duplicate data storage. The change is well-contained to xprepare.c and maintains identical diff algorithm behavior while improving code structure.
