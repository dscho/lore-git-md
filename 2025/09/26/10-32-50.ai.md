This is the first patch in a completed 3-part bugfix series addressing curl type safety issues, specifically focusing on HTTP POST operations. The patch relocates and renames a helper function for safely casting `size_t` to `curl_off_t` to make it available across the HTTP subsystem.

The change moves `xcurl_off_t()` from `remote-curl.c` to `http.h` as `cast_size_t_to_curl_off_t()`, following Git's established naming conventions for type conversion helpers. The function performs bounds checking to ensure values fit within `curl_off_t` and provides a more detailed platform-specific error message when they don't. This centralization allows the helper to be reused in other HTTP-related code.

Key technical details:
- Adds `#include "gettext.h"` to `http.h` to maintain translatable error messages
- Updates all call sites in `remote-curl.c` to use the new function name
- Preserves the same bounds checking behavior but improves error reporting
- Part of a broader effort to fix `curl_easy_setopt()` type mismatches across HTTP and IMAP subsystems

The patch is well-contained, touching only two files with straightforward changes. It has already been reviewed and approved by the maintainer with minor documentation improvements incorporated in this v2 version. The series as a whole addresses a real build failure on ARM64 platforms while improving type safety for all platforms.
