This is a refactoring patch in the xdiff modernization series, specifically removing redundant field duplication in the xdlclass_t structure. 

The patch eliminates three fields (ha, line, size) from xdlclass_t that were simply duplicating data from the embedded xrecord_t structure. Instead, it now embeds the full xrecord_t directly. This change simplifies the code by removing the need to keep these fields in sync, and prepares for future type changes in xrecord_t that would otherwise require parallel updates here.

The modification is straightforward - it updates the structure definition and the few places that accessed the old fields to instead use the embedded record. The diff shows 10 lines removed and 4 added, with no behavior change. This is part of the broader effort to clean up xdiff's internal data structures while maintaining identical diff algorithm behavior.
