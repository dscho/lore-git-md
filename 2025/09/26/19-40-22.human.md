This is a documentation patch addressing an Asciidoctor-specific rendering issue in Git's documentation. Jean-Noël Avila follows up on earlier discussion about incorrect "+" characters appearing in HTML output when paragraphs follow nested list items in definition lists.

The patch modifies two documentation files (`config/extensions.adoc` and `pretty-formats.adoc`) to use proper Asciidoc syntax that works consistently across processors. Key changes include converting single-colon definition markers to triple-colons (`:::`), removing unnecessary open blocks (`--`), and properly nesting bullet lists within explicit blocks. The changes maintain the same semantic meaning while avoiding the rendering bug.

This builds on Jeff King's earlier confirmation of the issue and his identification of additional problematic cases. The patch demonstrates a practical workaround for a known Asciidoctor limitation, though the underlying bug remains open in the Asciidoctor project. The changes are purely about documentation presentation with no impact on Git's functionality.
