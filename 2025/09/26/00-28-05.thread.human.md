This documentation formatting thread continues Ramsay Jones's cleanup of commit-graph.adoc as part of Jean-Noël Avila's broader effort to standardize Git's man page formatting. The original patch proposed converting all headers to atx-style (`#` syntax), but maintainer Junio Hamano expressed reservations, preferring Git's traditional underlined headers for source readability. 

Ramsay has now submitted a revised version that keeps underlined headers while still implementing other formatting improvements - normalizing code blocks, fixing whitespace, and properly escaping special characters. The key compromise is using `~` underlines for second-level headers (matching gitworkflows.adoc) while maintaining single-line underlines for top-level sections. This addresses Junio's stylistic concerns while progressing the standardization effort.

The underlying tension remains between modernization (atx headers offer maintenance benefits) and tradition (underlined headers dominate Git's existing docs). While this specific patch appears headed toward resolution with the underlined approach, the broader question of whether Git should transition to atx headers long-term remains open for future discussion. No technical changes to commit-graph functionality are involved - this is purely about documentation source formatting choices.
