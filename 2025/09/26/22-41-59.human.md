This is the final patch in a refactoring series modernizing xdiff's internals for better Rust compatibility. The patch changes the type of `xdfile_t.changed` from `char` to `bool`, since the field only ever holds 0/1 values representing false/true. 

The change follows logically from the previous patch (v6 11/12) which introduced named constants DISCARD/KEEP/INVESTIGATE for line classification states. Here, the boolean nature of `changed` is made explicit, helping distinguish it from the action1/action2 states that use those named constants. The patch updates all assignments and comparisons across xdiff's various diff algorithms (myers, histogram, patience).

This concludes a thorough modernization of xdiff's internals that has progressed through multiple versions (now at v6). The series has systematically removed redundant structures, improved type safety, clarified naming, and enhanced documentation while maintaining identical diff behavior. All preparatory patches have already been merged to 'next', and this final set is now ready for merging as well. The changes are well-motivated and carefully implemented, with no measurable performance impact.
