This is part 6 of Adrian Ratiu's hook subsystem refactoring series, focusing on output handling in the parallel process infrastructure. The patch introduces a new `consume_sideband_fn` callback mechanism for collating process output, while addressing feedback from Junio C. Hamano about documentation and implementation details.

Key technical elements include:
- New `consume_sideband_fn` type in run-command.h for handling collated output
- Mutual exclusion between `ungroup` and `consume_sideband` modes
- Removal of `const` from `run_process_parallel_opts` to allow runtime modification
- Test failures discovered when both flags are set (notably in t1416-ref-transaction-hooks.sh)

Adrian acknowledges Junio's feedback about:
1. Unexplained `const` removal in multiple files (fetch.c, submodule--helper.c, hook.c)
2. Need for `BUG()` enforcement of the ungroup/sideband mutual exclusion
3. Documentation gaps around the new callback mechanism

For v2, Adrian plans to:
- Fix tests that currently set both flags
- Add proper `BUG()` enforcement
- Drop the `const` removal changes if possible
- Improve documentation of the mutual exclusion rule

The patch continues the series' pattern of careful technical implementation with responsive revision based on review feedback. The output handling changes are foundational for the hook modernization effort, particularly for parallel execution scenarios.
