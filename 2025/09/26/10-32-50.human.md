This is the first patch in a completed 3-part bugfix addressing type safety issues in Git's curl interactions, specifically for ARM64 builds. The patch moves and renames a helper function that safely casts between `size_t` and `curl_off_t` types, centralizing it in `http.h` for broader use.

The change relocates the validation logic from `remote-curl.c` to a more accessible location while improving the function name (`xcurl_off_t` becomes `cast_size_t_to_curl_off_t`) to match Git's type-conversion helper conventions. The patch maintains the same bounds-checking behavior but now provides a more detailed platform-specific error message when values exceed `curl_off_t` limits.

This foundational change enables the subsequent patches in the series to consistently handle type conversions when working with libcurl's API. The patch has already been reviewed and approved with minor documentation improvements incorporated in this v2 version. The series as a whole fixes CI failures in Git for Windows ARM64 builds triggered by stricter type checking in newer libcurl versions.
