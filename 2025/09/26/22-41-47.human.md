This is the final version of a refactoring series modernizing xdiff's internal data structures, specifically focusing on the `xdfile_t` and `xrecord_t` types. The changes have been through multiple rounds of review and discussion, with all feedback addressed.

The series simplifies the xdiff implementation by removing redundant fields and structures, improving type safety (including converting the `changed` field from `char` to `bool`), and clarifying variable naming. The diff algorithm's behavior remains unchanged - these are purely internal improvements.

Key changes in this version include:
- Dropping a controversial patch that removed variable aliasing after finding similar patterns useful elsewhere
- Renaming similarity matching macros from NONE/SOME/TOO_MANY to more semantic DISCARD/KEEP/INVESTIGATE
- Final bool conversion of the `changed` field to properly reflect its boolean nature
- Addressing all remaining documentation questions about similarity matching variables

The series has been reviewed by Phillip Wood and Junio C Hamano, with consensus reached on the technical implementation. Some philosophical discussion about Rust porting motivations remains, but doesn't block merging. This represents the completion of a systematic cleanup that has eliminated redundant structures, modernized type usage, and improved documentation while preserving the original algorithm's behavior.
