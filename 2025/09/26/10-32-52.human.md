Bugfix completing a 3-patch series addressing curl type mismatches in Git for Windows ARM64 builds. This final patch fixes a compile error in `http-push.c` where `CURLOPT_INFILESIZE` was incorrectly receiving a `size_t` value when it expects a `long`. The error surfaced after a libcurl update in Git for Windows' ARM64 CI.

The solution uses the more appropriate `CURLOPT_INFILESIZE_LARGE` option (available since curl 7.11.0) along with the newly introduced `cast_size_t_to_curl_off_t()` helper function from earlier in the series. This matches the pattern already used in Git's IMAP code and provides proper type safety.

The patch is straightforward - a 3-line change replacing the problematic call with the type-safe alternative. As with the rest of the series, it has been reviewed and acked by the maintainer with minor documentation improvements incorporated in this v2 submission. The series is now complete and ready for merging, resolving the ARM64 build failures while improving type safety across HTTP and IMAP curl interactions.
