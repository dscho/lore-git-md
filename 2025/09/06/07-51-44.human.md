This is a documentation refactoring patch, part of a series introducing the new `git refs optimize` subcommand. 

The patch factors out the common options documentation from `git-pack-refs.adoc` into a new shared file `pack-refs-options.adoc`, which will be used by both the existing `git pack-refs` and the new `git refs optimize` commands. The change is purely organizational - the rendered documentation remains identical, but the options are now maintained in one place.

This is patch 2/5 in the v2 series, following the initial extraction of core packing logic in patch 1. The change is straightforward and well-motivated by the need to share documentation between the old and new commands. The patch maintains all existing option descriptions verbatim while making them reusable.

The implementation is clean - it simply moves the option documentation to a new file and replaces the original content with an include directive. The patch has been reviewed by mentors and follows Git's documentation conventions. This is a typical preparatory refactoring that enables the subsequent introduction of the new subcommand's documentation.
