This is the first patch in a 5-part series introducing a new `git refs optimize` subcommand, which refactors the existing `git pack-refs` functionality into a shared library. The patch focuses on extracting the core logic from `builtin/pack-refs.c` into new shared files `pack-refs.[ch]`.

The key changes include:
- Moving the core packing logic into a new `pack_refs_core()` function in `pack-refs.c`
- Reducing `builtin/pack-refs.c` to a thin wrapper that calls the shared function
- Adding a new `pack-refs.h` header with the shared option string macro `PACK_REFS_OPTS`
- Updating build files (Makefile and meson.build) to include the new library

The refactoring maintains all existing functionality while enabling code reuse for the upcoming `git refs optimize` command. The patch follows Git's pattern of consolidating related commands under logical namespaces while preserving backward compatibility. The implementation touches core refs handling code but doesn't change any behavior - it's purely an internal reorganization to support the new subcommand.
