Test refactoring patch in the `git refs optimize` series. This is patch 4/5 in v2 of the series that introduces a new `git refs optimize` subcommand to consolidate ref-related commands. The patch refactors the existing `t0601-reffiles-pack-refs.sh` test suite to make it shareable between the old `pack-refs` and new `optimize` implementations. 

The key changes are:
- Moves all test logic from `t0601-reffiles-pack-refs.sh` into a new `t/pack-refs-tests.sh` library
- Replaces hardcoded `pack-refs` command references with a `$pack_refs` variable
- Makes the original test file a simple driver that sets the default command and sources the shared tests
- Follows the same pattern used for sharing tests between `git-for-each-ref` and `git-refs list`

The test coverage remains identical (430+ test lines) but is now structured to be reusable. This prepares for the subsequent patch that will add tests for the new `optimize` subcommand by simply creating another driver script that sets `pack_refs=optimize`. The change is mechanical and well-contained, maintaining all existing test behaviors while enabling code reuse.
