Documentation patch for the `git refs optimize` series. This is patch 2/5 in the v2 series introducing the new `git refs optimize` subcommand as a modern replacement for `git pack-refs`. The patch factors out the common options documentation from `git-pack-refs.adoc` into a new shared file `pack-refs-options.adoc`, which will be used by both the old `pack-refs` command and the new `refs optimize` subcommand. The change is purely organizational - the rendered documentation remains identical, just with the options now included via an `include::` macro rather than being written directly in the man page.

This follows the pattern seen in the code changes (patch 1/5) where common functionality was extracted to be shared between implementations. The new `pack-refs-options.adoc` contains all the existing option documentation including `--all`, `--no-prune`, `--auto`, and the pattern-based `--include`/`--exclude` options with their complex interaction rules. The patch maintains all existing documentation content while setting up the infrastructure for sharing it with the new command's documentation.

The change is straightforward and well-contained, with mentors Patrick Steinhardt and shejialuo listed as having reviewed the work. As part of the larger ref-related command consolidation effort, this documentation refactoring enables the new subcommand to present consistent option documentation without duplication.
