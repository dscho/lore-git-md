Feature implementation adding the `optimize` subcommand to `git refs` as part of the ref command consolidation effort. This patch introduces the new subcommand as a modern alias for `git pack-refs`, sharing the same core packing logic via the recently extracted `pack_refs_core()` function.

The implementation adds:
1. Documentation in `git-refs.adoc` that includes the shared options via AsciiDoc's `include::` macro, maintaining consistency with `git-pack-refs(1)`
2. The actual subcommand implementation in `builtin/refs.c` that calls through to `pack_refs_core()` with the same options and behavior
3. Usage strings that leverage the `PACK_REFS_OPTS` macro for shared option handling

This continues the series' pattern of maintaining identical functionality while modernizing the command structure. The patch appears well-integrated with the prior refactoring work, properly using the shared infrastructure (options documentation, core function, test suite) established in previous patches. The implementation is straightforward and follows the established approach used for other `git refs` subcommands like `list` and `verify`.
