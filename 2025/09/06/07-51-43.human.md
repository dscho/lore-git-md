Refactoring patch as part of the ref-related command consolidation effort. This is the first of five patches introducing a new `git refs optimize` subcommand that will share logic with `git pack-refs`.

The patch extracts the core functionality from `builtin/pack-refs.c` into new shared files `pack-refs.[ch]`, moving option parsing and packing logic into a reusable `pack_refs_core()` function. The original `cmd_pack_refs()` becomes a thin wrapper around this shared implementation. The changes are mechanical and well-contained, touching only the build system and ref-related files.

This foundational work enables the subsequent patches to implement `git refs optimize` using the same core logic. The implementation follows Git's established patterns for command consolidation, maintaining backward compatibility while improving code organization. The patch includes proper header file definitions and build system updates, showing attention to detail in the refactoring.
