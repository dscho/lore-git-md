This is a test refactoring patch as part of the `git refs optimize` subcommand series. It prepares the test suite for the new command by making the existing `pack-refs` tests shareable.

The patch moves all test logic from `t0601-reffiles-pack-refs.sh` into a new `t/pack-refs-tests.sh` file, replacing hardcoded `pack-refs` calls with a `$pack_refs` variable. The original test file becomes a simple driver that sets this variable and sources the shared test library. This follows the same pattern used for sharing tests between `git-for-each-ref` and `git-refs list`.

The extensive test suite (over 430 lines) verifies all aspects of reference packing behavior - pruning, include/exclude patterns, worktree refs, broken ref handling, and auto-packing heuristics. The refactoring maintains all existing test coverage while making it reusable for testing both the old `pack-refs` and new `optimize` commands.

This appears to be a straightforward and well-executed test refactoring, with clear motivation tied to the larger command consolidation effort. The patch has been reviewed by mentors Patrick Steinhardt and shejialuo.
