Feature implementation adding `git refs optimize` subcommand as part of ref command consolidation.

This patch introduces the new `optimize` subcommand to `git refs`, which provides identical functionality to `git pack-refs` but under the more logical refs namespace. The implementation is straightforward, building on the shared `pack_refs_core()` function extracted in an earlier patch. The command inherits all existing pack-refs options (`--all`, `--no-prune`, etc.) through shared documentation included via AsciiDoc macros.

The changes are cleanly scoped to just adding the new subcommand - the actual packing logic remains in the shared library. Documentation is properly integrated with the existing refs man page, and the pattern established by the earlier `list` subcommand (which mirrors `for-each-ref`). The patch has been reviewed by two mentors and fits well with Git's ongoing effort to organize related commands under logical namespaces while maintaining backward compatibility.
