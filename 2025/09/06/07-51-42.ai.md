This is a feature patch series introducing a new `git refs optimize` subcommand as part of the ongoing effort to consolidate ref-related commands under the `git refs` namespace. The series is a modern replacement for `git pack-refs` with identical functionality.

The key technical changes include:
1. Moving core packing logic from `builtin/pack-refs.c` to new shared files `pack-refs.[ch]`
2. Adding the new `optimize` subcommand to `builtin/refs.c` that calls the shared packing logic
3. Extensive test refactoring to share tests between the old and new commands via a new `t/pack-refs-tests.sh`
4. Documentation updates including a new `pack-refs-options.adoc` for shared option documentation

The series appears well-structured with thorough test coverage (430+ lines of tests) and careful attention to documentation. The v2 changes are minor - primarily moving the core logic to a proper shared library rather than just a helper, and documentation wording tweaks. This continues Git's trend of consolidating related commands under logical namespaces while maintaining backward compatibility through aliases.
