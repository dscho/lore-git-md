This thread introduces a new `--signed-commits=<mode>` option for `git fast-import`, matching existing `git fast-export` functionality for handling commit signatures. Christian Couder's two-patch series refactors signature handling code into shared gpg-interface.[ch] and implements the new fast-import feature with modes for verbatim, strip, warn, and abort behaviors.

The implementation has evolved through several versions, with Patrick Steinhardt reviewing and suggesting improvements to the signature parsing logic. The latest version incorporates Patrick's recommendation to add a defensive BUG() case in the switch statement to catch invalid enum values, which Christian has now confirmed is implemented. The series includes comprehensive tests covering various signature formats (OpenPGP/X.509/SSH), handling modes, and hash algorithms (SHA-1/SHA-256).

With this final change implemented, the technical implementation appears complete and well-tested. The remaining discussion points are higher-level design questions about mode naming (whether to keep synonym modes like "ignore") and whether warning variants should be separate modes or controlled by --verbose. These appear to be blocking issues, and the series seems ready for potential merging once these final design decisions are resolved.
