This thread introduces a new `--signed-commits` option for `git fast-import` to control how commit signatures are handled, matching existing functionality in `git fast-export`. Christian Couder's two-patch series refactors shared signature handling code into gpg-interface.[ch] and implements the new option with modes like "verbatim", "strip", and "abort". The implementation supports both SHA-1 and SHA-256 signatures and includes comprehensive tests covering various signature formats and handling modes.

The second iteration of the series addressed prior feedback with improved error handling, expanded test coverage, and cleaner implementation. Patrick Steinhardt has reviewed the latest version and found it technically sound, suggesting only a minor defensive programming improvement to the switch statement handling signature modes. The remaining open questions from the initial proposal - about synonym modes and warning verbosity control - appear unresolved but don't block the core functionality.

With robust test coverage passing CI and positive review feedback, the series seems ready for the next step. Christian may choose to incorporate Patrick's suggestion before the patches are picked up for integration. The shared infrastructure between fast-import and fast-export establishes consistent signature handling across both commands.
