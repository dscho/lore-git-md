Bugfix targeting merge indentation behavior. Guo Tingsheng reports that Git's merge algorithm sometimes produces inconsistent indentation when merging code blocks, where newly added indented blocks get reduced to base indentation level. The issue appears non-deterministic and affects multiple merge strategies (ort, recursive). The report includes clear reproduction steps showing a Java method where an added `if` block loses its indentation relative to surrounding code. The problem doesn't seem related to whitespace configuration options. While the impact appears limited to code formatting rather than functionality, inconsistent indentation could cause problems in languages where indentation is significant (like Python) or simply make merged code harder to read. The report is well-structured with version info and clear before/after examples, making it easy to investigate.
