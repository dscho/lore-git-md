This is the second patch in Julia Evans' documentation series, focusing on upstream branch explanations in the Git man pages. The patch adds a new "UPSTREAM BRANCHES" section to the shared documentation file (renamed to `urls-remotes-upstreams.adoc`) that's included by `git-push`, `git-pull`, and `git-fetch`.

The change addresses user confusion about upstream branches by consolidating scattered information into one clear section. It explains how upstream branches are used across Git commands (`pull`, `push`, `fetch`, `status`), shows where the configuration is stored, and documents the various ways Git sets upstreams automatically (like with `push.autoSetupRemote` or when checking out remote branches).

The patch follows the series' research-driven approach, using "upstream branch" terminology consistently despite Git's mixed use of "tracking" and "upstream" in different contexts. The implementation is clean - it renames and extends the existing shared documentation file while maintaining all previous remote/refspec content. This continues the v2 series' improvements after feedback, now focusing specifically on upstream branch explanations while deferring more complex refspec documentation changes.
