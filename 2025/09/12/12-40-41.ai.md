Refactoring patch that moves GPG signature mode handling from fast-export to gpg-interface in preparation for fast-import support.

This is the first of two patches in a series adding signature handling control to `git fast-import`. It relocates the `enum sign_mode` definition and parsing logic from builtin/fast-export.c to gpg-interface.{c,h} to make it reusable. The refactoring includes:

1. Moving the enum definition with its modes (SIGN_ABORT, SIGN_VERBATIM etc.)
2. Extracting the parsing logic into a new parse_sign_mode() function
3. Fixing minor indentation in the original parse_opt_sign_mode()

The changes are straightforward mechanical moves with no behavior modifications. The patch maintains all existing functionality while cleaning up the code organization. This prepares for patch 2/2 which will add similar signature handling to fast-import using these shared components.

Key technical details:
- New parse_sign_mode() function in gpg-interface.c
- enum sign_mode now in gpg-interface.h header
- Original fast-export code now calls the shared function
- Maintains all existing modes and their synonyms ("ignore" for "verbatim", "warn" for "warn-verbatim")

The patch appears well-structured with clean separation of concerns. It follows the established pattern of moving common functionality to shared locations when multiple commands need it. The indentation fix shows attention to detail in the refactoring.
