This is a feature patch series introducing signature handling control to `git fast-import`. The cover letter explains the motivation comes from tools like `git-filter-repo` needing more control over how commit signatures are handled during repository filtering operations.

The series adds a new `--signed-commits=<mode>` option to `git fast-import`, mirroring the existing functionality in `git fast-export`. Currently supported modes include "verbatim", "strip", and their "warn-" variants, with plans to add more complex modes like "re-sign" in the future. The author is seeking feedback on design decisions around mode naming and warning behavior before expanding the feature further.

The implementation refactors signature mode parsing code from fast-export into gpg-interface.c for reuse, then adds the new option to fast-import with corresponding tests. The changes since v1 show thoughtful iteration based on reviewer feedback, including improved error handling, better warning messages, and more idiomatic test cases.

This appears to be a well-considered addition that fills a real need for repository filtering tools.
