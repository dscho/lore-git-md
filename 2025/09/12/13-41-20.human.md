This is a follow-up clarification in the ongoing feature series adding signature handling to `git fast-import`. Christian Couder responds to Junio C Hamano's observation about the initial patch's scope - while the infrastructure was set up to handle both commits and tags, the current implementation only covers commits.

Christian explains he has updated the commit message to be more precise about the current scope, removing the implication that tags would be handled immediately. He notes in the cover letter that tag support is planned for the future, but he wants to validate the design with just commit handling first. This appears to be a reasonable incremental approach, and since all technical feedback from the current implementation has been addressed in V2, the series seems ready to proceed.
