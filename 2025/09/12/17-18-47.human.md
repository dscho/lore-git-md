Junio Hamano responds to the ongoing discussion about handling malformed bundle-URI configurations. This is part of the thread addressing bugfixes for git-clone's bundle-URI feature.

Hamano agrees with Justin Tobler's position that client-side misconfigurations (like bundles missing required 'uri' fields) should not be ignored silently. While preventing segfaults is important (as Toon Claes's patch does), Hamano suggests users should be notified of such issues rather than having them silently papered over. This would allow users to identify and fix configuration problems.

The response highlights an emerging consensus in the thread that different error handling may be appropriate for server-side transmission errors (where graceful degradation makes sense) versus client-side configuration issues (where users should be alerted). Hamano's brief but authoritative comment lends weight to Tobler's earlier suggestion that the current patch might need adjustment to include warnings or errors for misconfigurations.

This moves the discussion forward by clarifying that while the segfault fix is good, the error handling strategy may need refinement before finalizing the patch series. The exchange shows careful consideration of how Git should balance robustness against clear error reporting.
