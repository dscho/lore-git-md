The mergetool configuration in question is the standard `mergetool.<tool>.cmd` setting.

This appears to be either a documentation issue (if the variables aren't actually supposed to be set in this context) or a bug in how Git invokes mergetool scripts. The clear reproduction steps and cross-platform verification make this a well-documented report that should help others investigate the behavior. The next steps will likely involve maintainers or mergetool experts examining the code paths that set up the mergetool environment to determine where the discrepancy lies.
