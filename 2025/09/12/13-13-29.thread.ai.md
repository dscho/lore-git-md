Thread summary:

Bug report regarding Git's merge functionality failing to preserve indentation in newly added code blocks. Original report from Guo Tingsheng describes a scenario where merging a branch that adds properly indented Java code with an unchanged version of the same file sometimes results in loss of indentation in the merged result. The issue affects both ort and recursive merge strategies and appears non-deterministic. Problem occurs independently of core.whitespace settings, suggesting a deeper merge algorithm issue. Reproduction provided for Git 2.43.0 on Ubuntu 24.04 but version/platform scope not fully characterized. Report includes clear reproduction steps and examples but lacks data on other indentation styles (tabs vs spaces) or complex nesting cases. The non-deterministic nature makes this particularly problematic for teams working with strictly formatted codebases. No maintainer response or proposed fixes yet.
