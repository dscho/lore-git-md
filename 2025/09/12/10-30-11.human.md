This is a test expansion patch in the `git sparse-checkout clean` series, focusing on merge conflict scenarios. It's the 7th and final patch in v3 of the series.

The patch adds detailed test coverage for how `sparse-checkout clean` interacts with merge conflicts, documenting current behavior where files in conflicted states aren't cleaned due to SKIP_WORKTREE bit handling. The test creates a merge conflict scenario, then verifies that the clean command fails to remove conflicted files (as expected) while still allowing other sparse-checkout operations like `reapply` to work normally.

The test is thorough, setting up a complete merge conflict with left/right branches, verifying error messages when clean fails, and checking file states after various operations. This builds on the series' focus on safety and edge case handling, though the commit message notes this documents current limitations rather than fixing them.

As the final patch in the series, it complements the earlier work on force/dry-run requirements and verbose output by ensuring merge conflicts are properly handled. The test will be useful for future improvements to SKIP_WORKTREE bit management.
