This is a refactoring patch in the `the_repository` removal effort, part of a series combining sparse-checkout clean functionality with repository state refactoring. The patch introduces a new helper function `for_each_file_in_dir()` that provides a generic way to recursively visit all files in a directory.

The new function takes a `strbuf` path and a callback function pointer, walking the directory tree and invoking the callback for each regular file found. It handles both files (DT_REG) and subdirectories (DT_DIR) recursively, skipping "." and ".." entries via the existing `readdir_skip_dot_and_dotdot()` helper. The iteration stops early if the callback returns non-zero.

Key technical details:
- Adds `file_iterator` typedef for the callback signature
- Uses existing directory traversal infrastructure (`readdir_skip_dot_and_dotdot`, `get_dtype`)
- Maintains path state via `strbuf` manipulation
- Returns 0 on success or the first non-zero callback result
- Will be used by subsequent patches in the series (likely sparse-checkout clean operations)

The implementation is straightforward and builds on existing patterns in the codebase. As part of the larger series, this helper appears designed to support the directory cleaning functionality while avoiding direct `the_repository` usage. The patch includes the necessary header declarations and follows standard Git coding conventions.
