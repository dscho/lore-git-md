This is a refactoring patch that's part of Derrick Stolee's ongoing work to eliminate `the_repository` usage in the sparse-checkout code. It introduces a new helper function `for_each_file_in_dir()` that provides a generic way to recursively visit all files in a directory.

The new function is a simpler alternative to existing directory traversal methods like `remove_dir_recursively()` (which has extra flags) and `fill_directory()` (which requires an index and pathspec). It takes a callback function that gets invoked for each regular file found, and stops iteration if the callback returns non-zero. The implementation handles both regular files and subdirectories recursively.

This appears to be infrastructure work preparing for the next patch in the series (as noted in the commit message). The change is cleanly implemented with appropriate documentation in the header file explaining the new function pointer type and the traversal behavior. While this doesn't directly impact user-facing functionality, it provides a useful building block for directory operations in the codebase.
