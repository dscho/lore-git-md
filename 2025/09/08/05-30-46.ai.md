This is version 8 of a 7-patch series extending the promisor-remote protocol to support configurable validation of remote attributes during clone/fetch operations. The series builds on previous work to replace strvec usage with a more structured promisor_info approach.

Key technical changes in v8:
- Rebased on recent Git code to avoid conflicts and leverage new string_list_split_in_place_f() function
- Replaced remaining git_config_get_string*() calls with repo_config_get_string*()
- Simplified parsing logic with new skip_field_name_prefix() helper
- Restructured patch ordering to introduce helper functions earlier
- Added two new patches (5/7 and 7/7) to complete the strbuf_split*() to string_list_split() conversion
- Improved parse_one_advertised_remote() to use const char* and avoid modifying input
- Maintained all previous functionality for field validation (partialCloneFilter and token)

The series remains technically complete with all CI tests green. Primary changes since v7 focus on code hygiene and parsing refinements requested by Junio Hamano. The core protocol extension allowing servers to advertise additional remote attributes (via promisor.sendFields) and clients to validate them (via promisor.checkFields) remains unchanged.

This version addresses all outstanding technical feedback but still needs resolution on the terminology debate ("field" vs "configuration variable") before final merge. The series is at risk of being temporarily dropped from 'seen' due to inactivity, making this refresh timely.
