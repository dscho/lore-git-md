This is a test patch in the ongoing command deprecation framework series, specifically testing alias shadowing behavior. 

The patch adds new test cases to verify that regular (non-deprecated) Git commands cannot be shadowed by aliases, while deprecated commands can be (as tested in the previous patch). The test exercises a sample of builtin commands (`grep`, `check-ref-format`, etc.) to confirm they maintain their original behavior even when aliased, validating the documentation's claim about alias behavior.

The author notes they limited the test to a sample of commands rather than all builtins to avoid adding ~600ms to test runtime. The test uses a new helper function `cannot_alias_regular_builtin` that checks command behavior with and without aliases.

This appears to be a straightforward and well-constructed test addition that complements the earlier test for deprecated command shadowing. It helps ensure the alias system works as documented while maintaining backward compatibility for non-deprecated commands. The patch fits cleanly into the larger series by verifying one of the key behavioral guarantees of the new deprecation framework.
