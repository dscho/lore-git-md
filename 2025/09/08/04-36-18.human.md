This is a feature patch series introducing a new `--update-refs` option to `git replay`. The change aims to simplify server-side operations by allowing atomic reference updates directly within `git replay`, eliminating the need to pipe output to `git update-ref`.

The series addresses a workflow pain point where users currently need to chain two operations (`git replay` followed by `git update-ref`) to update references. The new `--update-refs` option provides atomic updates by default (with an opt-out `--batch` mode for partial updates) and works in bare repositories, making it particularly useful for server-side tools like Gitaly.
