This is part 2 of a 12-patch series refactoring submodule gitdir paths to use URL-style encoding for better filesystem compatibility. The patch moves new submodule directories from `.git/modules/` to `.git/submodules/` to clearly separate legacy and encoded paths.

Phillip Wood raises an important version compatibility question - should there be an `extensions.submoduleEncoding` config key to prevent older Git versions from trying to read the new path structure? Adrian Ratiu agrees this is likely needed to avoid potential corruption when switching Git versions, and plans to add it in v3.

The change itself is straightforward - just moving the default directory location while maintaining backward compatibility with existing `.git/modules/` paths. This prepares for the actual encoding implementation in later patches. The discussion shows careful consideration of real-world upgrade scenarios and potential pitfalls.
