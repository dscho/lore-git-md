This is part 6/8 of the command deprecation series, focusing on improving user guidance when deprecated commands are used. The patch enhances the deprecation warning for `git whatchanged` by providing a concrete `git log` equivalent (`--raw --no-merges`) and showing how to create an alias for it. The same hint is added to the command's documentation.

The changes include:
1. Extending the `you_still_use_that()` function to accept an optional hint parameter
2. Adding the specific `git log` replacement command to both the runtime warning and documentation
3. Maintaining backward compatibility by allowing NULL hints (used for `pack-redundant`)
4. Formatting the hints consistently with Git's standard "hint:" prefix

This addresses real-world feedback showing users weren't finding the replacement command in the documentation. The implementation is clean and focused, building on the deprecation framework established in earlier patches. The hint system could be easily extended to other deprecated commands in the future.
