Feature patch adding Rust build status reporting, part of the ongoing Rust infrastructure series (4/8). This patch modifies `help.c` to expose whether Git was built with Rust support via `git version --build-options` and `git bugreport` output. The change adds a simple conditional block that reports "rust: enabled" or "rust: disabled" based on the `WITH_RUST` compile-time flag. The commit message explains this will help diagnose Rust-specific issues during the transition period where some subsystems will have both C and Rust implementations. The implementation is straightforward - a single `#ifdef` block adding the status line to the version info output. 

This patch builds on the Rust infrastructure work from previous patches in the series (meson support in v1, Makefile preparation in v2, and Makefile integration in v3). It introduces the first user-visible indication of Rust support while maintaining the optional nature of the feature. The change is minimal and focused, touching only `help.c` with 6 lines added. As with other patches in the series, this maintains compatibility with both meson and Makefile builds through the common `WITH_RUST` flag.
