Feature patch adding config override for submodule gitdir paths, part of the submodule gitdir path encoding series.

This is patch 3/9 in a series that rewrites how Git handles submodule gitdir paths to avoid filesystem conflicts. The patch introduces a new `submodule.<name>.gitdirpath` config option that allows overriding the default path where a submodule's gitdir is stored. This provides flexibility for interoperability with other tools like JGit that might use different path schemes.

The implementation adds a new `git submodule--helper gitdir` subcommand to querying paths, along with a test helper `verify_submodule_gitdir_path` that will be used in later tests. The test demonstrates that the config override works by temporarily changing and then restoring a submodule's gitdir path.

Phillip Wood asks in his reply whether later patches will set this config key automatically when encoding paths, suggesting this might help JGit compatibility. The patch itself looks clean and focused, with clear test coverage for the new functionality. As part of a larger series that's already undergone significant review, this appears to be a well-considered addition to the submodule path handling infrastructure.
