This is part of Patrick Steinhardt's ongoing RFC series introducing Rust infrastructure to Git core, specifically focusing on a test implementation of the varint subsystem in Rust (patch 5/8). The patch serves as a proof-of-concept by converting the simple, self-contained varint encoding/decoding functionality from C to Rust.

When Rust support is enabled, the build system now compiles the new `src/varint.rs` instead of the C implementation in `varint.c`. The Rust version provides identical functionality through FFI-compatible functions `decode_varint` and `encode_varint`, with thorough test coverage matching the original behavior including edge cases and overflow detection.

The implementation is intentionally minimal - varint was chosen specifically because it has no dependencies on other Git components, making it an ideal first target. The patch includes build system changes for both Makefile and meson, showing how Rust components will integrate with both build systems through the `WITH_RUST` conditional.

This represents the first actual Rust code being compiled into Git as part of the RFC series, though it remains optional build-time functionality. The implementation appears clean and well-tested, serving its purpose as a low-risk test case for the broader Rust infrastructure work.
