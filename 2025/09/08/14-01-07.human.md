Feature series improving submodule gitdir path handling to avoid filesystem conflicts. This is version 2 of Adrian Ratiu's work to encode submodule directory names using URL-style encoding, building on Brandon Williams' 2018 work.

The series addresses several issues from v1's review, including Windows/macOS CI fixes, test script improvements (replacing `seq` with `test_seq` and `grep` with `test_grep`), better variable scoping, and documentation of the new `submodule.<name>.gitdirpath` config option. The core technical approach remains unchanged - using RFC 3986 URL encoding with case encoding for cross-platform compatibility.

Key changes in v2 include splitting the NAME_MAX handling into a separate commit with a Windows compatibility wrapper, fixing commit message formatting, and removing an incorrect claim about Windows reserved filenames. The series now has comprehensive test coverage in the new `t7425-submodule-mixed-gitdir-paths.sh` (202 lines) that verifies the new encoding scheme alongside legacy paths.

The series touches 39 files across the codebase, with most changes in submodule.c and test scripts. It maintains backward compatibility while transitioning to the new path encoding scheme. All known issues from v1 have been addressed, making this a well-polished submission that appears ready for serious consideration.
