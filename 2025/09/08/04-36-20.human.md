Documentation patch for the new `--update-refs` feature in `git replay`. This is the second part of a two-patch series that introduces atomic reference updates directly within the replay command.

The patch thoroughly documents the new `--update-refs` and `--batch` options, explaining how they provide atomic transaction behavior for reference updates (all succeed or none do by default, with `--batch` allowing partial updates). It contrasts these with the existing `--update` option and provides clear examples of all three modes of operation.

The documentation maintains the experimental warning for the `git replay` command while adding comprehensive details about the new functionality. It explains the output behavior (or lack thereof) for each mode and includes practical examples showing how to use the options in different scenarios. The patch follows Git's documentation style well and provides clear technical details while remaining accessible.
