This is a refactoring patch in the submodule gitdir path encoding series, moving a URL encoding helper function back to strbuf.c where it can be shared.

The patch relocates `is_rfc3986_unreserved()` from credential-store.c to strbuf.c, making it available for the submodule path encoding work. The function was previously moved to credential-store.c in 2023 when it was only used there, but now needs to be shared for URL-style encoding of submodule names to avoid filesystem conflicts.

The change is straightforward - the function definition moves from credential-store.c to strbuf.c with identical implementation, and a declaration is added to strbuf.h. The credential-store.c version is removed since it will now use the strbuf.c version. This is part of the larger effort to handle submodule gitdir paths safely across platforms by using RFC 3986 encoding.

The patch maintains all existing functionality while enabling code reuse. It's a clean mechanical change that fits naturally into the series' goal of robust path handling. The commit message clearly explains the relocation rationale and connects it to the broader submodule path encoding work.
