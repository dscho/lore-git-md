This is a refactoring patch in the submodule gitdir path encoding series, removing the now-obsolete `validate_submodule_git_dir()` function. The function was originally designed to prevent path conflicts between submodule gitdirs, but the new path encoding scheme (introduced earlier in the series) makes these conflicts impossible by construction.

The patch moves the essential invariant checks (verifying path structure and name matching) into `submodule_name_to_gitdir()` as BUG assertions, since these should never fail with the new encoding scheme. It then removes all other validation logic and updates the few remaining callers. The changes are straightforward deletions with no behavior changes - the validation is now handled by the encoding mechanism itself.

This cleanup was anticipated in earlier patches (a TODO comment mentioned it), and the series has already demonstrated to work correctly in CI. The removal simplifies the code while maintaining safety through the new encoding approach.
