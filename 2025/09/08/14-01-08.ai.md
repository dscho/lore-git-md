This is the first patch in a 10-part series refactoring submodule gitdir path handling to use URL-style encoding for cross-platform compatibility. The patch focuses on updating `submodule--helper` to use the centralized `submodule_name_to_gitdir()` function rather than hardcoded path construction.

The change replaces direct path manipulation with the helper function in two places within `add_submodule()`: when checking for existing gitdirs and when handling clone operations. The patch also improves memory management by switching from `xstrfmt()` allocations to `strbuf` usage where appropriate. This aligns with the series' goal of standardizing path handling while maintaining backward compatibility.

Key technical changes include:
- Removal of hardcoded `.git/modules/%s` path construction
- Introduction of `strbuf submod_gitdir` to replace `char *submod_gitdir_path`
- Proper cleanup via `strbuf_release()` instead of `free()`
- Consistent use of `submodule_name_to_gitdir()` which implements the new encoding scheme

The patch builds on commit ce125d431a which originally introduced the helper function, and is part of a larger effort to prevent filesystem conflicts in submodule paths. While this first patch is relatively straightforward, it establishes the pattern that subsequent patches in the series will follow for converting direct path manipulation to use the new encoding-aware helper functions.
