This is the final patch in a bugfix series addressing color handling in Git's interactive patch mode, specifically updating documentation for the `diff-highlight` contrib tool.

The patch adds a section to `contrib/diff-highlight/README` explaining how to configure the tool to work with interactive patch modes (`add -p`, `checkout -p`, etc.) using the `interactive.diffFilter` setting. This completes the series by documenting a workaround that was previously only mentioned in Git's main documentation, making it more discoverable for users coming from the diff-highlight side.

Key technical details:
- Documents the `interactive.diffFilter` configuration option that was introduced to support highlighting in interactive modes
- Shows example configuration syntax matching the pattern used elsewhere in the README
- Covers all interactive commands that use the patch interface (`add`, `checkout`, `reset`, `restore`, `stash`)
- Builds on the color handling fixes in earlier patches of the series

The change is straightforward and uncontroversial, having been suggested by Isaac Oscar Gariano and incorporated into the v2 series after review. It provides a natural conclusion to the thread by ensuring users have complete documentation for both the underlying color fixes and the diff-highlight integration.
