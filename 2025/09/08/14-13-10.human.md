This is part 3/8 of Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core, focusing on Makefile integration. Following the meson implementation in part 1 and Makefile preparation in part 2, this patch adds the actual Rust build support to the Makefile system.

The changes mirror the meson infrastructure from earlier in the series, allowing developers to opt into Rust compilation with the `WITH_RUST` flag. Key additions include:
- New `RUST_SOURCES` variable tracking Rust files
- Conditional linking of the Rust library (`libgit.a`) based on build configuration
- Cargo build rules for debug/release targets
- Clean target support for Rust artifacts
- Quiet build output integration matching Git's existing style

The implementation looks thorough, with proper `.gitignore` entries for Rust's `target/` directory and build system integration that follows Git's existing patterns. As with the meson changes, this remains optional infrastructure for now but is positioned to become mandatory in Git 3.0. The patch appears to be a straightforward technical addition that completes the dual-build-system support started earlier in the series.
