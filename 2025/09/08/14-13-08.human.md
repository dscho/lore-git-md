This is the foundational patch for introducing Rust infrastructure into Git's build system via Meson. It's the first in an 8-part series proposing Rust integration, with this initial piece focusing on build system plumbing.

The patch adds Meson support for building an optional internal Rust library, currently positioned as a "test balloon" for developers and distributors. It includes auto-detection of Rust toolchains (configurable via `-Drust=`), sets up Rust 2018 edition compatibility (targeting older Rust 1.49 for gcc-rs backend support), and wires up Rust's native unit testing framework (disabled on macOS due to Meson module limitations).

Key technical components include:
- New Cargo.toml/Cargo.lock files for dependency management
- Meson build rules for Rust compilation
- Conditional Rust test execution (skipped on macOS)
- Build summary reporting for Rust availability

The approach is deliberately conservative - Rust remains optional at this stage, with plans to make it mandatory in Git 3.0 if the experiment proves successful. The patch shows careful consideration of backward compatibility (Rust 2018 edition) and build system integration, though macOS support is notably limited in this initial version.

This is clearly a well-prepared infrastructure patch, with thorough documentation of design choices and clear version requirements. It serves as the technical foundation for the rest of the series while leaving room for future evolution of Rust usage in the codebase.
