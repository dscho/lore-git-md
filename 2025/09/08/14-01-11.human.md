This is a test patch in the submodule gitdir path encoding series, adding basic verification for mixed legacy and new-style submodule paths.

Adrian Ratiu adds a new test script `t7425-submodule-mixed-gitdir-paths.sh` that verifies Git can handle repositories containing both legacy (`.git/modules`) and new-style (`.git/submodules`) submodule paths simultaneously. The tests cover creation, cloning, pushing, and pulling with this mixed configuration, ensuring the transition between path formats works smoothly.

The test creates a repository with two submodules - one using the new path format and one manually converted to the legacy format. It then verifies that cloning, commits, pushes, and updates work correctly with this mixed setup. The test uses `test_path_is_dir` and `test_grep` for robust verification, following the project's testing best practices.
