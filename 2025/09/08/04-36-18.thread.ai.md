This implementation-ready 3-patch series finalizes atomic reference updates for `git replay`, transitioning from RFC to merge-ready state. The design makes atomic ref updates the default behavior while maintaining backward compatibility through configurable output modes. Core implementation uses `ref_store_transaction_begin()` in `builtin/replay.c` with extensive test coverage in t3650/t3651.
