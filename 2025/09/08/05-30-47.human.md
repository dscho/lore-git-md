This is the first patch in a 7-part series extending the promisor-remote protocol to support configurable validation of remote attributes. The series is now at version 8 and considered technically complete, with this patch providing foundational refactoring.

The patch replaces parallel `strvec` arrays (one for names, one for URLs) with a new `struct promisor_info` that explicitly stores promisor remote information. This change enables cleaner handling of additional fields that will be added in subsequent patches. The struct currently contains just `name` and `url` members, but is designed to be extended.

Key changes include:
- Introduces `struct promisor_info` for type safety and clearer field documentation
- Uses a `string_list` to manage promisor remote instances
- Provides proper memory management via new cleanup function `promisor_info_list_clear`
- Maintains all existing functionality while improving code organization

The refactoring looks thorough and well-motivated, with clear commit message explaining the need for the change. The patch appears ready for inclusion, being part of a mature series that has already addressed extensive review feedback. This foundational work will support the protocol extensions coming in later patches.
