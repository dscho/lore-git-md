This is patch 2/10 in the submodule gitdir path encoding series, which moves new submodule gitdirs to a dedicated `.git/submodules/` directory while maintaining backward compatibility with existing `.git/modules/` paths. 

The patch introduces a clean separation between legacy (unmodified) submodule paths in `.git/modules/` and new (encoded) submodule paths in `.git/submodules/`. This prevents potential conflicts when transitioning to encoded paths, particularly avoiding issues where an existing module name might contain encoding escape characters. The change is purely organizational at this stage - the actual path encoding logic comes in later patches.

- Updates `submodule_name_to_gitdir()` to first check legacy paths in `.git/modules/` before falling back to new paths in `.git/submodules/`
- Modifies `repo_has_absorbed_submodules()` to check both directories
- Updates documentation references from `modules/` to `submodules/` across multiple files
- Adjusts test infrastructure to handle both paths, with 24 files modified total
