Bugfix addressing color configuration handling in `git add -p` (interactive patch mode). This is patch 2/4 in a series fixing color regressions that occurred during the 2021 Perl-to-C conversion.

The patch specifically ensures `add-interactive` properly respects `color.diff` settings for diff output, separate from `color.interactive` settings used for prompts. The fix involves:

1. Splitting the single `use_color` field in `add_i_state` into two distinct fields: `use_color_interactive` (for prompts) and `use_color_diff` (for diffs)
2. Adding corresponding reset colors (`reset_color_interactive` and `reset_color_diff`)
3. Modifying color initialization to check both config settings independently
4. Updating all color-handling code paths to use the appropriate field
5. Adding new tests verifying the separation works correctly:
   - One test enables prompt colors but disables diff colors
   - Another does the opposite, testing custom diff colors without prompt colors

The changes maintain backward compatibility with the Perl version's behavior while fixing the regression where `color.diff=false` was being ignored. The implementation carefully preserves the existing fallback to `color.ui` when other color settings aren't specified.
