Feature patch in the Rust infrastructure series, addressing CI dependencies. This is the final patch (7/7) in Patrick Steinhardt's RFC series introducing Rust to Git's core. The patch enables Rust for breaking-changes CI jobs and responds to brian m. carlson's question about Fedora package requirements.

The key technical point here clarifies that while Rustc is now included in the CI dependency installation for Fedora/AlmaLinux, Cargo isn't currently needed for the Meson-based build infrastructure. Patrick notes this may change if they later switch to using Cargo wraps. This follows up on earlier CI configuration work that Junio Hamano has now resolved to be compatible with Git 3.0 changes.

The patch appears straightforward and uncontroversial, representing the final piece of the series' CI integration goals. It demonstrates good responsiveness to reviewer feedback while maintaining a clear technical boundary about current vs potential future requirements. The series as a whole has reached technical resolution on most points, with only Makefile issues and policy debates remaining as open questions.
