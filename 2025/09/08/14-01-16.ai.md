This is a test reorganization patch in the submodule gitdir path encoding series. It moves tests for nested gitdir handling from t7450-bad-git-dotfiles.sh to the new t7425-submodule-mixed-gitdir-paths.sh, since the path encoding changes mean these cases are no longer pathological (they won't cause filesystem conflicts).

The patch relocates three test cases that verify proper handling of nested submodule gitdirs:
1. Basic verification that sibling submodule gitdirs aren't nested
2. Parallel cloning behavior with nested gitdirs
3. Correct handling during `checkout -f --recurse-submodules` with simulated malicious nested alternates

All tests use the new `verify_submodule_gitdir_path` helper to check encoded paths (e.g., `hippo/hooks` becomes `submodules/hippo%2fhooks`). The tests remain functionally identical but are now better grouped with other mixed-path tests in t7425 rather than being with dotfile edge cases in t7450.

This is a straightforward test reorganization that maintains all existing coverage while improving test suite organization. The changes align with the series' goal of handling submodule paths safely via encoding rather than treating nested paths as special cases.
