This is the foundational patch for introducing Rust infrastructure to Git's build system via meson. It establishes the basic framework for compiling an internal Rust library, with several notable technical decisions and limitations:

The patch adds Rust build support to meson with auto-detection of the toolchain (configurable via `-Drust=`), targeting Rust 2018 edition for compatibility with gcc-rs. It creates the necessary Cargo files (`Cargo.toml`, `Cargo.lock`) and meson build rules, with special handling for older meson versions (<1.5.0) that require direct cargo invocation. The implementation includes Rust unit test integration via `meson test`, though macOS testing is explicitly disabled due to meson's Rust module limitations.

Key technical details include:
- Rust library built as a staticlib (`crate-type = ["staticlib"]`)
- Conditional compilation based on meson version (direct cargo vs meson-native Rust support)
- `WITH_RUST` compile-time flag added when Rust is enabled
- Build summary reporting includes Rust availability
- macOS test exclusion due to meson Rust module issues (prelink/pic/rust_abi warnings)
- The patch positions this as optional infrastructure for "test balloons" - non-critical features and alternative implementations - with a stated goal of making Rust mandatory in Git 3.0. The commit message frames this as an experimental phase for developers and distributors to evaluate Rust integration.

The implementation shows careful consideration of backward compatibility (Rust 2018 edition, meson version handling) and security (committing Cargo.lock for supply-chain protection). The macOS test limitation and gcc-rs compatibility constraint represent notable platform-specific considerations that will need to be addressed in future work.
