This is a code review follow-up in the thread about fixing duplicate ACKs in upload-pack protocol v2. Jeff King (peff) is examining the implementation details of Patrick Steinhardt's patch that restructures the `do_got_oid()` function to eliminate redundant ACKs.

The review focuses on the removal of the `we_knew_they_have` variable in favor of directly checking the `THEY_HAVE` flag after parent processing. Peff confirms this is safe because commit objects can't be their own parents, so the flag won't be set during parent processing. While the change looks correct, he notes he carefully reviewed it to ensure no subtle edge cases were missed.

This comes after the patch series (which includes test modernization and the ACK deduplication fix) has already been approved by Junio Hamano. The discussion here is a final verification of implementation details rather than proposing any modifications.
