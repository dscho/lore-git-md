This is a refactoring patch in the submodule gitdir path encoding series, moving a URL encoding helper function back to strbuf.c where it can be shared more widely.

The patch relocates `is_rfc3986_unreserved()` from credential-store.c to strbuf.c, making it available for use in submodule path encoding. This function was previously moved to credential-store.c when it was only used there, but now the submodule work needs it for URL-style encoding of gitdir paths to avoid filesystem conflicts.

The change is straightforward - the function definition moves to strbuf.c with its header declaration, while being removed from credential-store.c which now uses the shared version. The implementation remains identical, checking if a character is alphanumeric or one of '-', '_', '.', '~' which don't need URL encoding.

This is a clean, focused change that enables code sharing between the credential and submodule systems. The patch fits well into the larger series by providing a needed building block for the path encoding work while maintaining good code organization.
