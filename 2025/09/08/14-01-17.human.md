This is a test patch in the submodule gitdir path encoding series, adding comprehensive test coverage for the new encoding functionality.

The patch adds two new test cases to verify the submodule gitdir path encoding behavior. The first test checks that various problematic submodule names (containing slashes, percent signs, and mixed case) are properly encoded in the new `.git/submodules/` directory structure while maintaining compatibility with legacy paths in `.git/modules/`. The test verifies the encoding transformations for each case, showing how special characters are handled.

The second test validates that the system's NAME_MAX limit is properly enforced for encoded submodule names. It creates an intentionally long name that will exceed the limit when encoded (since each '%' expands to '%25') and confirms the operation fails as expected. This completes the test coverage for the path length validation added earlier in the series.

The tests follow the established pattern of the series, using the `verify_submodule_gitdir_path` helper to check encoded paths. This patch represents the final piece of test coverage for the encoding functionality, complementing the earlier tests that were reorganized in patch 9/12. The series as a whole now has thorough testing of both the encoding mechanism and its edge cases.
