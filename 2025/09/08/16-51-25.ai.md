This is a code review follow-up in the upload-pack protocol v2 ACK deduplication thread. Jeff King (peff@peff.net) examines the implementation details of Patrick Steinhardt's patch that removes redundant ACKs in protocol v2.

The discussion focuses on the removal of the `we_knew_they_have` variable in the `do_got_oid()` function. Peff explains why this simplification is safe: in the new version, parent processing happens before checking the THEY_HAVE flag, eliminating the need to track the flag's previous state. He confirms the logic is correct since a commit cannot be its own parent, so parent processing won't affect the commit's own THEY_HAVE flag.

This is a final verification of the implementation approach before the patch gets merged. The review confirms the code correctly handles the deduplication of ACKs while maintaining the special processing needed for commit parents. The thread has already established that this change improves protocol v2 behavior while preserving backward compatibility with v0 clients.
