This is a v2 bugfix series addressing color handling inconsistencies in Git's interactive patch mode, building on Patrick Steinhardt's review feedback. The series now includes expanded test cases and documentation updates while maintaining the core technical approach.

The key changes in this revision are:
1. Patch 1/4 now explicitly handles both `diff-tree` and `diff-index` cases in stash operations, addressing Patrick's observation about the original only covering `diff-tree`. New test cases verify color handling isn't confused by `GIT_PAGER_IN_USE` in both scenarios.
2. Patch 2/4 adds more thorough test coverage for color context separation, now verifying prompt colors remain unaffected when `color.interactive=false` while diff colors are enabled.
3. Patch 3/4 clarifies the commit message to precisely document config key pattern matching behavior (not just literal "color." prefix), addressing Patrick's feedback. The technical implementation remains unchanged as Junio approved the design.
4. Patch 4/4 (documentation-only) remains unchanged from v1.

The series maintains its focus on fixing color handling regressions from the 2021 Perl-to-C conversion while respecting Git's historical configuration boundaries. Jeff King has addressed all review feedback except for the broader `GIT_COLOR_*` refactoring, which he suggests should be handled separately. The expanded test coverage in patches 1-2 provides additional verification of the fixes, while the clarified documentation in patch 3 helps future maintainers understand the config lookup behavior.
