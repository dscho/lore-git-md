This is part 4 of Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core. The patch adds build information reporting for Rust support is enabled, which will be useful for debugging as Git begins to include optional Rust implementations alongside C code.

The change modifies `help.c` to report whether Git was built with Rust support (via the `WITH_RUST` flag) in two places: the output of `git version --build-options` and in `git bugreport`. This is a straightforward addition that mirrors how other optional features like fsmonitor are reported. The implementation is clean and minimal conditional compilation that fits with existing patterns in the codebase.

This patch makes sense in the context of the larger series, as it provides visibility into whether Rust support is active - important information as the project begins experimenting with mixed C/Rust implementations where bugs might be Rust-specific. The change is well-contained and unlikely to be controversial, serving as a debugging aid rather than introducing any new functionality.
