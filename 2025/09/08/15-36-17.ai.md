This is a documentation and user experience patch in the command deprecation series, specifically improving the messaging for `git whatchanged` users. The patch enhances the deprecation warning by providing concrete `git log` equivalents and alias creation instructions, addressing real-world user confusion observed since the deprecation began.

The key technical changes include:
- Adding a `hint` parameter to `you_still_use_that()` to allow customized guidance
- Showing specific `git log --raw --no-merges` replacement in both error messages and documentation
- Including alias creation instructions in the error output
- Maintaining backward compatibility with NULL hints for other deprecated commands
- Updating documentation to show the equivalent command explicitly

The patch builds on the deprecation framework established earlier in the series, now providing actionable migration paths rather than just warnings. It addresses multiple user reports where people weren't finding the man page guidance, demonstrating the practical need for this improvement. The implementation is clean, with clear separation between the generic deprecation framework and command-specific guidance.

This change completes the user-facing side of the `whatchanged` deprecation by making the transition path obvious, while the technical underpinnings (alias shadowing, command listing) were handled in earlier patches. The hint system could serve as a pattern for future deprecations needing similar guidance.
