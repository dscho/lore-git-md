This is a refactoring patch in the submodule gitdir path encoding series, removing the now-obsolete `validate_submodule_git_dir()` function. The patch moves the remaining invariant checks into `submodule_name_to_gitdir()` and cleans up all call sites.

The key changes are:
1. The validation function is removed entirely since path encoding now prevents the conflicts it was designed to catch
2. Three basic invariant checks (path suffix matching, length checks, separator presence) are moved to `submodule_name_to_gitdir()` as BUG assertions
3. All call sites in `builtin/submodule--helper.c` and `submodule.c` are updated to remove validation checks
4. The function declaration is removed from `submodule.h`

The patch builds on the earlier path encoding work by recognizing that URL-style encoding of submodule names (introduced in patch 6/10) makes the validation function redundant. The remaining invariant checks are kept as hard assertions since they represent fundamental requirements for correct path construction.

This is a straightforward cleanup that follows naturally from the series' technical approach. The changes are mechanical and well-contained, with all test coverage remaining intact from earlier patches in the series. The patch maintains backward compatibility while removing now-unnecessary code.
