Feature proposal for HTTP protocol to support WebDAV PROPFIND. Milan Hauth reports that Git's dumb HTTP protocol fails with WebDAV-enabled servers like nginx with WebDAV extension, causing operations like `git ls-remote` to fail with "repository not found" errors. Current workaround requires manual `update-server-info`.

Key technical details: failure occurs when accessing WebDAV-hosted repositories due to missing PROPFIND support in Git's HTTP transport. Hauth provides nginx WebDAV module configuration showing PROPFIND and OPTIONS methods enabled, along with curl commands demonstrating directory listing capability. References prior discussion where WebDAV support was rejected over server compatibility concerns, but argues for reconsideration to improve WebDAV interoperability.

Open questions: how to implement PROPFIND support without breaking existing HTTP servers, whether to make it opt-in or automatic, and how to handle potential server compatibility issues. The change would require modifications to Git's HTTP transport code to handle WebDAV PROPFIND responses when available.
