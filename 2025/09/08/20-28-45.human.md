Documentation patch cleaning up formatting in the git-fast-import manpage.

Kristoffer Haugsbakk notices that a paragraph in the git-fast-import documentation is incorrectly marked up as a literal block (monospace/preformatted text) when it should be regular paragraph text. The text in question is a security warning about the `feature export-marks` option, explaining when it's safe to enable this feature. The patch simply removes the literal block formatting while keeping the content identical.

The change is straightforward and appears correct - the text reads as normal prose rather than something that needs monospace formatting. The commit references the original commit (68061e34702) that introduced this documentation in 2019, suggesting this has been incorrectly formatted since then. No functional changes are made, just documentation presentation.
