CI / build system patch converting the "pedantic" CI job into a full build-and-test job with breaking changes enabled, as part of the Rust infrastructure series.

This patch repurposes the existing "pedantic" CI job (which had become redundant after pedantic builds were made default) into a new "fedora-breaking-changes-meson" job. The key changes are:

1. Replaces the pedantic job with a new job that:
   - Builds using Meson with breaking changes enabled (`-Dbreaking_changes=true`)
   - Runs full test suite (previously pedantic job only built without testing)
   - Tests on Fedora (adding distro coverage)

2. Modifies CI infrastructure to:
   - Install meson/ninja dependencies for Fedora
   - Remove pedantic-specific build flags
   - Ensure tests run in all cases (removing `run_tests` conditional)

3. Prepares for future Rust testing by:
   - Creating parallel meson-based infrastructure
   - Laying groundwork for Rust-enabled builds in follow-up

The change plugs testing gaps in the Rust transition by verifying breaking changes work under Meson (complementing existing Makefile testing) and adding Fedora coverage. It's a tactical CI adjustment that supports the series' broader Rust adoption goals while improving test matrix completeness. The implementation appears straightforward, repurposing existing infrastructure rather than adding complexity.
