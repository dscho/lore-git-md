This is the third patch in Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core, focusing on Makefile integration. Following the meson implementation in v1 and Makefile variable reordering in v2, this patch adds concrete Rust build support to the Makefile system.

The changes introduce a `WITH_RUST` build toggle (documented to become mandatory in Git 3.0) and add:
- Rust-specific build rules for `cargo` with debug/release configuration support
- `.gitignore` entry for Rust's `target/` directory
- Quiet build output integration matching Git's existing pattern
- `RUST_SOURCES` variable tracking and `rust` phony target
- Clean target updates for Rust artifacts
- Conditional addition of `-DWITH_RUST` to CFLAGS and Rust library to GITLIBS

The implementation mirrors the meson support from v1 while adapting to Makefile conventions. Key technical points include the debug/release library path handling (`target/debug/libgit.a` vs `target/release/libgit.a`) and the `QUIET_CARGO` build output integration. The patch maintains the series' careful approach to incremental infrastructure addition while keeping Rust optional at this stage.
