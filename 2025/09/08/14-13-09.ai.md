Build system refactoring patch in the Rust infrastructure series.

This is patch 2/8 in Patrick Steinhardt's RFC series introducing Rust infrastructure to Git. The change reorders Makefile variable definitions to ensure config.mak (and related files) are included before source file definitions. This prepares for upcoming conditional compilation based on the WITH_RUST flag, which developers may set in config.mak.

The patch moves a large block of Makefile definitions (176 lines) that were previously after the config includes to appear before them. The moved section contains fundamental build variables like CFLAGS, LDFLAGS, library definitions, and Coccinelle-related settings. The diff shows the mechanical nature of the change - it's purely a reordering with no functional modifications.

This is a straightforward preparatory change for the Rust integration work. The commit message clearly explains the reordering is needed to allow conditional compilation based on config.mak settings.
