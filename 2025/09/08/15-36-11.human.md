This is a feature and refactoring series that builds on the ongoing work to improve deprecation workflows in Git. Kristoffer Haugsbakk's v3 series introduces several key improvements to how Git handles deprecated commands like `git whatchanged` and `git pack-redundant`.

The most significant change in v3 is the addition of 4 new patches that implement Peff's suggestion to allow aliases to shadow deprecated builtin commands. This addresses a key limitation in the deprecation workflow where users couldn't create aliases with the same name as deprecated commands. The series also adds a `deprecated` category to `git --list-cmds` for better visibility.

The error messages for deprecated commands have been enhanced to provide more actionable guidance, now including both direct `git log` equivalents and instructions for creating aliases. The implementation includes thorough testing of the new alias behavior for both deprecated and regular commands.

This series represents a thoughtful evolution of the deprecation system, with:
- Clear technical documentation of the changes
- Comprehensive test coverage
- Backward-compatible implementation
- Improved user guidance

The changes are well-motivated by real-world usage patterns and maintain Git's commitment to smooth transitions for deprecated functionality. The series appears ready for consideration, having addressed previous feedback and expanded its scope to solve additional workflow issues.
