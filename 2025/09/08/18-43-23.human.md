This is a discussion about the removal of `git-new-workdir` from Git's `contrib/` directory, part of Patrick Steinhardt's cleanup series. The email captures Junio Hamano's response to Kristoffer Haugsbakk's workflow concerns regarding the script's removal.

The key point is that while `git-new-workdir` allowed checking out the same branch in multiple worktrees (useful for inspecting different branches), modern `git worktree` enforces branch uniqueness. Haugsbakk suggests using detached HEAD mode as a workaround for inspection purposes, which Junio confirms is reasonable for read-only "sightseeing" of history points, though not ideal for active development.

This continues the thread's exploration of workflow impacts from removing this legacy script, with Junio effectively endorsing the detached HEAD approach as a viable alternative for the inspection use case. The discussion helps clarify the remaining practical considerations around this removal in the otherwise complete cleanup series.
