This is part 8/8 of Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core, specifically focusing on CI testing for breaking changes. The patch enables Rust support in the breaking-changes CI jobs, ensuring the build infrastructure and converted Rust subsystems are properly tested.

The changeset modifies two CI scripts: it adds Rust compiler (`rustc`) and package manager (`cargo`) to the dependency installation lists for Fedora and Ubuntu/Debian platforms, and sets the necessary environment variables (`WITH_RUST` and meson's `-Drust=enabled`) when running the breaking-changes test jobs.

This is a tactical addition to the comprehensive Rust transition plan, ensuring the CI system can properly validate Rust components as part of the breaking changes testing matrix. The changes are straightforward and focused, building on the extensive infrastructure work done in previous patches of the series. The implementation appears clean and well-integrated with the existing CI framework.
