This is part 3/10 of the submodule gitdir path encoding series, introducing a config override mechanism for submodule gitdir paths. The patch adds a new `submodule.<name>.gitdir` config option that allows users to specify custom paths for submodule gitdirs, bypassing the default encoding scheme. This provides flexibility for interoperability with other tools like JGit that might use different path encoding conventions.

The implementation adds a new `git submodule--helper gitdir` subcommand to query paths and includes comprehensive test coverage through a new test helper script `t/lib-verify-submodule-gitdir-path.sh`. The config override is checked first in the path resolution flow (before legacy paths and new encoded paths), maintaining backward compatibility while allowing customization. Documentation is updated to explain the new config option.

The patch builds on Brandon Williams' original work and has been refined through review feedback, with all platform-specific issues resolved in this v2 series. The test suite verifies both the default behavior and config override functionality, including cleanup after unsetting the override. This is a well-contained addition to the larger path encoding effort, with its own tests and documentation, that doesn't disrupt the core encoding logic while providing needed escape hatch for special cases.
