This is a release announcement for Git for Windows 2.51.0(2), primarily consisting of bundled dependency updates and backported bugfixes from upstream Git.

The announcement covers updates to several key dependencies including PCRE2 (v10.46), cURL (v8.16.0 with security fixes), Tig (v2.6.0), MinTTY (v3.8.1), and OpenSSL (v3.5.3). The cURL update specifically fixes a security-related fetch/push failure (SEC_E_CONTEXT_EXPIRED) and incorrect timeout reporting.

Numerous bugfixes are included, many backported from upstream Git topic branches. Notable fixes include: case-insensitive ref handling regression in clone/fetch operations, sparse-checkout cleanup functionality, rebase -i message cleanup, subtree splitting improvements, color configuration fixes in interactive add, line-log boundary cases, memory exhaustion protection in upload-pack, midx write-out fixes, repack path-walk issues, fetch race conditions with repacking, diff --name-only behavior with ignore options, diff --no-index in subdirectories, ort merge strategy rename handling, push error reporting for missing objects, reflog migration bugs, and interactive rebase merge commit dropping.

The release includes builds for both 64-bit and ARM64 architectures in various formats (installer, portable, MinGit), with SHA-256 checksums provided for each. The auto-updater notification icon issue on Windows/ARM64 has also been fixed. Most fixes appear to be well-motivated and address specific reported issues, with clear attribution to upstream topic branches.
