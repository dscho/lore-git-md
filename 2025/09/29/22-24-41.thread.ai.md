Git for Windows 2.51.0(2) release announcement by Johannes Schindelin (Dscho), updating the Windows-specific fork with bundled dependency upgrades (cURL 8.16.0, PCRE2 10.46, Tig 2.6.0, MinTTY 3.8.1, OpenSSL 3.5.3) and backported fixes from upstream Git addressing security and functional regressions across multiple subsystems. Junio C Hamano acknowledges the release, confirming the backported fixes align with what would have been selected for an upcoming upstream Git 2.51.1 release, validating Johannes's proactive work in merging these fixes. The coordination between upstream Git maintenance and the Git for Windows fork is noted, with Junio indicating the selection of fixes (covering case-insensitive ref handling, sparse-checkout, rebase -i, subtree, interactive add, line-log, upload-pack, midx, repack, fetch/repack races, diff options, ort rename handling, push error reporting, reflog migration, and interactive rebase merge commit handling) is sensible and in line with upstream priorities. The email implies some fixes may now be redundant for upstream inclusion in 2.51.1, though no specific exclusions are named. Builds remain available for 64-bit and ARM64 architectures (installer/portable/MinGit formats) with SHA-256 checksums, including ARM64 auto-updater notification icon fixes. Each backported fix maintains clear provenance by referencing its upstream Git topic branch.
