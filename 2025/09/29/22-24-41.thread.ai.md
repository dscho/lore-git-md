Git for Windows 2.51.0(2) release announcement by Johannes Schindelin (Dscho), updating the Windows-specific fork with bundled dependency upgrades and backported fixes from upstream Git. Key updates include security-critical cURL 8.16.0 (fixing SEC_E_CONTEXT_EXPIRED and timeout reporting), PCRE2 10.46, Tig 2.6.0, MinTTY 3.8.1, and OpenSSL 3.5.3. Backported fixes address multiple functional regressions: case-insensitive ref handling in clone/fetch, sparse-checkout cleanup, rebase -i message formatting, subtree splitting, interactive add color config, line-log edge cases, upload-pack memory exhaustion, midx write-out reliability, repack path-walk bugs, fetch/repack race conditions, diff --name-only with ignore options, diff --no-index in subdirs, ort rename handling, push error reporting for missing objects, reflog migration issues, and interactive rebase merge commit dropping. Builds provided for 64-bit and ARM64 architectures (installer/portable/MinGit formats) with SHA-256 checksums, including a fix for ARM64 auto-updater notification icons. Each backported fix references the upstream Git topic branch it originated from, maintaining clear provenance.
