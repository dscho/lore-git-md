This is a release announcement for Git for Windows 2.51.0(2), marking a maintenance update with both new features and bugfixes. Johannes Schindelin announces the availability of updated Windows builds, including 64-bit, ARM64, and portable versions.

The update includes several dependency bumps (PCRE2, cURL, Tig, MinTTY, OpenSSL), with cURL's update notably fixing a security-related fetch/push failure and connection timeout reporting. The bulk of the changes are bugfixes backported from upstream Git, addressing issues across many areas:

Key fixes include improved handling of case-sensitive ref conflicts during clone/fetch, sparse-checkout cleanup functionality, rebase -i message cleanup, subtree splitting fixes, and color configuration handling in interactive add. Several memory safety and crash issues are resolved in midx writing, repacking, and upload-pack handling. The update also includes various diff/merge strategy fixes and corrections to edge cases in push, reflog migration, and interactive rebase behavior.

The fixes appear well-vetted, with most being backports of upstream topic branches that have presumably undergone review. The announcement follows Git for Windows' typical thorough style, with clear attribution of each fix to its upstream source. Windows-specific fixes include proper icon display for the auto-updater on ARM64 systems. SHA-256 checksums are provided for all distribution artifacts.
