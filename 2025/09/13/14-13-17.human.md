This is a feature patch series introducing improvements to worktree handling in `checkout` and `rebase` commands. The series comes from a new contributor and aims to ease the transition for users accustomed to the older, more permissive 'workdir' script behavior.

The core change extends the existing `--ignore-other-worktrees` option (previously only in `checkout`) to also work with `rebase`. Additionally, both commands will now show helpful hints when refusing operations due to branch conflicts with other worktrees, suggesting workarounds like using `--detach` or the new `--ignore-other-worktrees` flag.

The motivation stems from Git's current safety check that prevents branch operations when the branch is checked out elsewhere, which some users find overly restrictive compared to the old 'workdir' script behavior. The patches provide a middle ground - keeping the safety net by default but making it easier to bypass when desired.

The series touches documentation, advice messages, and command implementations across multiple files. It's a first-time contribution, so the author welcomes beginner-level feedback. The changes look well-scoped and motivated, with clear commit messages explaining the rationale. Future work might include a config option to make the worktree-ignoring behavior persistent.
