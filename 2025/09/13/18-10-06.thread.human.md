Here's a human-readable summary of the thread so far:

Michael Rappazzo submitted an initial patch to make gitk remember the size and position of its "Tags and Heads" window between sessions. The implementation stores the window settings in gitk's config file and handles various edge cases, adding about 70 lines of Tcl code to manage the geometry persistence.

Johannes Sixt, the gitk maintainer, has now reviewed the patch after testing it on both Windows and Linux (KDE). He found some platform-specific behavior - Windows correctly retains both position and size, while Linux only remembers the size. He also identified that the persistence only works if the window is open when gitk exits. Johannes suggested several improvements: using a Configure event handler to simplify the implementation, making geometry parsing fail more visibly, and fixing an edge case where the window's title bar could go offscreen. He also commented that the current implementation seems larger than necessary for this feature.

The review was constructive and focused on implementation details rather than the feature's merit. Michael will need to address these platform-specific issues and consider the approach before sending a revised version. The discussion is still early, with no other participants having weighed in yet.
