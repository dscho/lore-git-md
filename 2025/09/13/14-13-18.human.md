This is the first patch in a series improving worktree behavior, specifically around the `--ignore-other-worktrees` option. It adds a helpful hint when checkout/switch operations fail because the target branch is already checked out in another worktree.

The patch introduces a new advice message that suggests using `--detach` or `--ignore-other-worktrees` when this situation occurs. The implementation modifies the existing die_if_checked_out() function to first print the error (rather than immediately dying), allowing the advice to show before exiting. This creates a more user-friendly experience while maintaining the same safety checks.

The changes span several files:
- Adds new advice config `branchUsedInOtherWorktree`
- Extends the advice infrastructure to support this case
- Modifies branch.c to separate error message generation from immediate termination
- Updates checkout.c to show the advice when appropriate

The author notes this doesn't yet handle the rebase case (which will be addressed in future patches). The implementation looks clean and focused, with appropriate documentation updates. As a first contribution, it shows good attention to Git's conventions while solving a clear usability pain point.
