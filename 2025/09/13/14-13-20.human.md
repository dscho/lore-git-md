This is the third and final patch in a series improving worktree behavior around the `--ignore-other-worktrees` option. It builds on the previous patches that added this flag to `git rebase` by now including helpful advice when the operation fails due to branch conflicts.

The patch modifies the rebase command to show the same advice message that checkout operations display when they fail because a branch is checked out in another worktree. Instead of immediately dying with an error, it first shows a message suggesting `--ignore-other-worktrees` as a workaround. This matches the behavior introduced for checkout/switch in the first patch of the series.

The implementation uses the same `ADVICE_BRANCH_USED_IN_OTHER_WORKTREE` advice system and follows the pattern of calling `die_message_if_checked_out()` rather than the direct `die_if_checked_out()`. This maintains consistency across commands while keeping the safety check behavior by default.

This completes the series' goal of providing better migration support for users coming from older 'workdir' scripts, with consistent behavior and advice between checkout and rebase operations. The changes are focused and well-contained, building logically on the infrastructure established in the earlier patches.
