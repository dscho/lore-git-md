Feature patch for gitk's UI behavior.

This patch makes the "Tags and Heads" window in gitk remember its size and position between sessions, storing the geometry in gitk's config file as `geometry(showrefs)`. The window position is saved relative to the main gitk window, maintaining spatial relationships when the main window moves or when using different monitors. The implementation handles several edge cases including window bounds checking to keep the window on screen.

The changes introduce three new Tcl procedures: `parse_geometry` to handle window geometry strings, `save_showrefs_geometry` to store the window state before closing, and `restore_showrefs_geometry` to apply saved settings when reopening. The patch modifies the window destruction protocol to ensure geometry is saved properly, and adds a `<Map>` event binding to restore geometry when the window appears.

The implementation appears thorough, handling cases where windows might be moved off-screen and maintaining the relative positioning to the main window. The patch touches only the gitk Tcl script, adding 73 lines while removing 2, primarily focused around the showrefs window management code. This should provide a better user experience for those who frequently use the Tags and Heads window, eliminating the need to reposition it manually each session.
