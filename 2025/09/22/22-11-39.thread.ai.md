Core problem: Users encountering new deprecation warnings suggesting potential removal of `git whatchanged` and date-filtered `git log` functionality. The thread seeks confirmation of deprecation plans and alternative commands.

Current status: Git 2.51.0 introduced warnings but no removal yet. Kristoffer Haugsbakk has responded with concrete alternatives for `git whatchanged` (`git log --raw --no-merges` and related output formats). S0AndS0 has acknowledged this solution and plans to create an alias for transition. The date-filtering aspect (`--since` warnings) remains unaddressed and is now the primary open question.

Key technical details:
- `git whatchanged` can be replaced by `git log --raw --no-merges` (showing changed files with modes/hashes)
- Alternative output formats: `--stat` (summary statistics) and `--name-only` (just filenames)
- Date-based filtering syntax (`--since` etc) warnings still need addressing
- S0AndS0 indicates they will implement a local alias to ease migration from `whatchanged`

Open questions:

Participant positions:

Related work: Part of Git's ongoing CLI cleanup efforts to phase out older commands in favor of more maintainable alternatives.
