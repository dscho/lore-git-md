Thread identity: User report about deprecation warnings in Git 2.51.0 for `git whatchanged` and date-filtered `git log` usage, with S0AndS0 of Digital Mercenaries LLC as original reporter.

Core problem: Users encountering new deprecation warnings suggesting potential removal of `git whatchanged` and date-filtered `git log` functionality. The thread seeks confirmation of deprecation plans and alternative commands.

Current status: Git 2.51.0 introduced warnings but no removal yet. Kristoffer Haugsbakk has responded with concrete alternatives for `git whatchanged` while the date-filtering aspect remains unaddressed.

Key technical details:
- `git whatchanged` can be replaced by `git log --raw --no-merges` (showing changed files with modes/hashes)
- Alternative output formats: `--stat` (summary statistics) and `--name-only` (just filenames)
- Date-based filtering syntax (`--since` etc) warnings still need addressing

Open questions:

Participant positions:

Related work: Part of Git's ongoing CLI cleanup efforts to phase out older commands in favor of more maintainable alternatives. The `whatchanged` command has been considered legacy for years, with `git log` offering equivalent functionality through flags.
