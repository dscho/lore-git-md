Test improvement patch in the "git stash index config" series.

This is the first patch in the v3 series that adds configurable index restoration to `git stash`. It addresses a test isolation issue where some tests in t3903-stash.sh would fail if run individually because they depended on a subdirectory created by earlier tests. The patch makes three test cases more self-contained by having them create the needed `subdir` directory on demand with `mkdir -p`, which won't fail if the directory already exists.

The changes are straightforward test plumbing - no behavior changes to the actual stash functionality. This appears to be a refinement based on Phillip Wood's earlier feedback about test strategy, making the test suite more robust when running individual tests or subsets. The patch maintains all existing test coverage while removing implicit dependencies between tests.

Key technical details:
- Modifies three test cases in t3903-stash.sh
- Uses `mkdir -p` to create `subdir` on demand
- Preserves all test assertions and operations
- Part of the larger stash.index config series that's now maintainer-acknowledged

The patch follows the series' established pattern of careful, incremental changes with clear commit messages. Since this is purely a test improvement with no functional impact, it's unlikely to be controversial at this stage of the series' review.
