Refactoring patch in the ongoing xdiff internals cleanup series. This is patch 4/12 in v4 of the series preparing xdiff for Rust compatibility.

The patch removes the helper function `xdl_get_rec()` from xdiff/xemit.c, which was previously used to access records when they were stored in a linked list. Now that records are stored in a contiguous array, the function's simple array access has been inlined directly at its three call sites. The change is straightforward and maintains identical behavior while reducing indirection.

This continues the series' pattern of simplifying xdiff's internal data structures. The commit message explains the historical context and rationale clearly - the function became unnecessary after earlier changes to the data structure. The diff shows clean mechanical replacements with no behavioral changes.

This patch follows the same quality standard as others in the series, with clear motivation and careful implementation. It builds on previous work that moved xrecord_t from linked list to array storage, and fits naturally with the overall goal of simplifying xdiff codebase for future Rust integration.
