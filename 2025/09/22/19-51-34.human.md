This is a refactoring patch in Ezekiel Newren's ongoing series to prepare xdiff internals for Rust compatibility. The patch continues the simplification of xdiff's data structures by removing redundant local variables that were aliasing fields in xrecord_t.

The changes focus on xdiff/xemit.c, where several functions previously declared local variables like `rec` and `len` that simply duplicated fields from the xrecord_t struct. The patch replaces these with direct access to the xrecord_t's `ptr` and `size` fields, making the code more straightforward while maintaining identical behavior.

This is part of a larger effort (v4 series, patch 5/12) that builds on preparatory cleanups already merged to 'next'. The changes are behavior-preserving and follow logically from earlier infrastructure changes in the removal of linked list handling. The patch appears well-contained and mechanically sound, continuing the series' trend of simplifying the codebase without performance impact.
