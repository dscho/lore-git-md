Refactoring patch in the xdiff internals simplification series, specifically removing the now-unused `xdl_get_rec()` helper function.

This patch continues Ezekiel Newren's work to modernize xdiff's internals in preparation for Rust integration. The change removes `xdl_get_rec()`, a legacy function that previously helped traverse xdiff records when they were stored as a linked list. With records now stored in a contiguous array, direct array access makes this helper unnecessary. The patch updates four call sites in xemit.c to access the array directly rather than through the function, simplifying the code while maintaining identical behavior. 

Key technical details:
- Removed function: `xdl_get_rec()` from xdiff/xemit.c
- Modified call sites: `xdl_emit_record()`, `match_func_rec()`, and `is_empty_rec()`
- Changes involve replacing function calls with direct struct member access to `xdf->recs[ri]->ptr` and `xdf->recs[ri]->size`
- No behavior change - this is a straightforward cleanup of now-redundant indirection

This change follows logically from the earlier removal of linked list infrastructure in the series (particularly patch 3/12 which removed the unused `xrecord_t.next` field). The commit message explains the historical context and rationale clearly. The implementation appears clean and well-contained, affecting only xemit.c with straightforward mechanical replacements.
