This is a bugfix patch series for `git format-patch`'s handling of Git notes in range-diff output. The issue occurs when generating range-diffs for single-commit patch series, where notes are currently displayed inconsistently between the main commit message and the range-diff section.

Kristoffer Haugsbakk proposes a two-part solution: first refactoring to introduce a new `rdiff_other_arg` field in the `rev_info` struct, then using this to ensure consistent notes display in both output locations. The changes touch revision handling code and the log display logic, with corresponding test updates to verify the fix.
