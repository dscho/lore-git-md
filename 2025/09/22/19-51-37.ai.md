Refactoring xdiff internals for Rust compatibility (part 8/12 in v4 series). This patch continues the structural simplification of xdiff's data structures by eliminating redundant fields in `xdlclass_t` that duplicated information from `xrecord_t`. 

The change replaces three separate fields (`ha`, `line`, `size`) in `xdlclass_t` with an embedded `xrecord_t` structure, which already contained equivalent fields (`rec.ha`, `rec.ptr`, `rec.size`). This eliminates field duplication and makes the code more maintainable by ensuring future type changes to `xrecord_t` will automatically propagate to `xdlclass_t` usage. The modification affects `xdl_classify_record()` where field accesses are updated to use the embedded record.

This is part of the larger effort to prepare xdiff for Rust integration, following logically from previous patches that removed other redundant data structures. The change maintains identical behavior while simplifying the codebase. Phillip Wood is credited as a helper, suggesting related improvements in earlier rounds. The patch continues the series' pattern of direct structure access simplification while preserving performance characteristics.
