Technical follow-up in release notification discussion thread.

Jeff King responds to Velocifyer's question about why Git release tags don't include full changelog content in their annotations. He confirms the tags are already annotated but contain minimal information (version and signature). King outlines three potential technical concerns with embedding full release notes in tags: 1) possible breakage of existing tag-parsing scripts, 2) inability to revise notes after tagging (important for typo fixes and format updates), and 3) increased object size impacting performance (current tags are ~1KB vs. 14KB+ for release notes). He notes this was done in some older tags but suggests the maintainer (Junio Hamano) may have insights about why the practice changed. The response maintains the thread's technical advisory nature without proposing any immediate changes to Git's release process.
