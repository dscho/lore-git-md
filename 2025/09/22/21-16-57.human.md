This is a technical discussion about Git release notification mechanisms, specifically addressing the idea of embedding release notes in Git tags.

Junio Hamano responds to Jeff King's earlier suggestion about including full release notes in annotated tags. While acknowledging the historical precedent (though uncertain if it was ever actually done), Junio strongly opposes the idea due to the object size impact (#3 from Jeff's list), calling it a "show-stopper". The discussion reinforces the existing consensus that release notifications are better handled through external mechanisms like GitHub's feed or git-scm.com's RSS, rather than modifying Git's core tagging behavior.
