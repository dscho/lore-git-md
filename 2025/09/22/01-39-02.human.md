This is the final version of a feature patch series that adds configurable index restoration to `git stash`. The series has been reviewed and approved by the maintainers, with test strategy now finalized.

The core change introduces a new `stash.index` configuration option (defaulting to false) that makes `git stash apply` and `git stash pop` restore the stashed index by default, addressing a common pain point where carefully staged changes are lost during stash operations. Users can still opt out with `--no-index` when needed.

The v3 iteration incorporates feedback from Phillip Wood to streamline the test approach, focusing on config/flag interactions rather than duplicating existing test cases. The author notes some test style modernization opportunities but has deferred those to avoid delaying review of the core functionality.

This is a well-motivated change that solves a real user experience issue while maintaining backward compatibility. The implementation is clean, with thorough test coverage of the new behavior. The series is now ready for merging into the main development branch.
