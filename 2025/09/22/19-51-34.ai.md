This is a refactoring patch in the ongoing xdiff internals cleanup series preparing for Rust compatibility. The patch continues the simplification of xdiff's data structures by removing redundant local variables that were aliasing fields in xrecord_t.

The changes focus on xdiff/xemit.c, where several functions previously declared local variables to hold copies of xrecord_t's ptr and size fields. The patch replaces these with direct use of the xrecord_t structure, accessing the fields through the rec variable. This eliminates unnecessary variable declarations and makes the code more straightforward by working directly with the record structure.

Key technical changes include:
- Replaces `char const *rec` and `long size` locals with `xrecord_t *rec` in xdl_emit_record()
- Updates match_func_rec() to use rec->ptr/size instead of separate variables
- Simplifies is_empty_rec() by using direct record access and a more compact loop
- Maintains identical behavior while reducing variable scope and aliasing

This change follows logically from earlier patches in the series that removed linked list infrastructure and prepares for future Rust integration by making the code work more directly with the core data structures. The patch continues the series' pattern of behavior-preserving refactoring while simplifying the codebase.
