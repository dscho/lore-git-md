This is a user report about deprecation warnings in Git commands. The email comes from S0AndS0 of Digital Mercenaries LLC, who notes that two specific commands (`git whatchanged` and `git log` with a date-based filter) are now generating warnings in Git 2.51.0 about features slated for removal. The warnings apparently suggest users email the list with `--i-still-use-this` if they rely on these features.

The reporter is asking for:
1. Confirmation about whether these features are indeed being deprecated
2. Information about alternative commands that could be aliased to maintain similar functionality
3. Suggestions about how such deprecation notices could better communicate alternatives to users

The email doesn't propose any code changes but rather seeks clarification from the Git maintainers about the deprecation path for these commands. The tone is friendly and constructive, looking for solutions rather than complaining about the warnings. This appears to be part of Git's ongoing effort to clean up and modernize its command-line interface by phasing out older or less-used commands.
