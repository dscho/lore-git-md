This is the final patch in a series implementing configurable index restoration for `git stash`. The patch adds the core functionality to honor the `stash.index` configuration in `apply` and `pop` modes, completing the feature.

The change makes `git stash apply/pop` respect the `stash.index` config (defaulting to false) as the default behavior, while preserving the ability to override with `--no-index`. The implementation modifies `apply_stash()` and `pop_stash()` to use the `use_index` static variable (set from config) as the default, with command-line flags taking precedence. This addresses the common pitfall where carefully staged changes are lost during stash application.

Key technical details:
- Adds `use_index` static variable in builtin/stash.c that reads from config
- Modifies both `apply_stash()` and `pop_stash()` to use config-driven defaults
- Maintains existing `--index`/`--no-index` override behavior
- Documents the config option in config/stash.adoc
- Includes comprehensive tests in t3903-stash.sh covering:
  - Basic config-driven behavior
  - CLI flag precedence over config
  - All combinations of config/flag interactions

The patch builds on preparatory refactoring from earlier in the series and incorporates all review feedback, including test isolation improvements. It represents the final piece of functionality needed to make stash's index handling more intuitive while maintaining backward compatibility. The maintainer has already approved the series for integration.
