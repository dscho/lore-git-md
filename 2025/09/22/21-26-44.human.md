Bugfix for memory leaks in `git stash show` argument handling. This is the first patch in a series addressing strvec memory management issues in `setup_revisions()`, specifically fixing a leak when `--` arguments are processed.

The patch modifies `show_stash()` to set `free_removed_argv_elements` in its `setup_revision_opt` struct, ensuring strings dropped during argument parsing are properly freed. This fixes a case where `setup_revisions()` would remove `--` markers from the original strvec without freeing them.

The test case has been simplified to focus solely on leak detection using SANITIZE_LEAK, avoiding assertions about the command's output behavior. This is intentional, as there are known quirks in `git stash show`'s handling of `--` that are considered pre-existing behavior and out of scope for this memory safety fix.

Junio Hamano suggests crediting the original bug reporter who found the issue via `git stash show -p --invalid`, though this isn't yet reflected in the commit message. The patch maintains backward compatibility while plugging the memory leak, completing the first step in a broader set of strvec memory management improvements.
