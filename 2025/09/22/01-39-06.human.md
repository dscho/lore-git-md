This is the final patch in a series adding configurable index restoration to `git stash`. The patch implements the core functionality where `stash.index=true` makes `git stash apply/pop` restore the index by default, addressing a common pain point where carefully staged changes were lost during stash operations. The behavior remains backward-compatible, with `--no-index` available to override the config.

The patch adds documentation for the new `stash.index` config option and modifies the stash commands to respect it as a default while preserving the ability to override via CLI flags. The implementation is clean, with tests verifying all combinations of config and flag interactions: default behavior, config-enabled index restoration, and explicit flag overrides in both directions.

This completes the series which has already been reviewed feedback and maintainer-approved. The change is well-motivated by real user confusion (linked in the commit message) and provides a sensible default that can be adjusted based on workflow needs. The test coverage is thorough, including edge cases and interactive mode testing from earlier patches in the series.
