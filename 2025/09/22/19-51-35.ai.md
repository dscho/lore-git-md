This is a refactoring patch in the ongoing xdiff internals cleanup series preparing for Rust compatibility. It removes the `diffdata_t` struct which was serving as a redundant wrapper around fields from `xdfile_t`. The patch in this series systematically eliminates unnecessary indirection layers, and this one follows that pattern by deleting the struct and updating all callers to directly access the underlying `xdfile_t` fields.

The changes are mechanical but widespread, touching both `xdiffi.c` and `xdiffi.h` to remove the struct definition and update function signatures/callers. The commit message clearly documents the field mappings being removed (`diffdata_t.nrec -> xdfile_t.nreff` etc.), showing this is a straightforward alias removal rather than any semantic change.

This continues the series' pattern of simplifying xdiff's data structures while maintaining identical behavior, with the ultimate goal of making the codebase more amenable to Rust integration. The changes appear well-contained and consistent with the series' established approach - no new performance implications or behavioral changes are introduced beyond the direct struct removal.
