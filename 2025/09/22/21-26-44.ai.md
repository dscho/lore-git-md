This is a bugfix patch addressing memory leaks in `git stash show` when processing `--` arguments, part of a larger series fixing strvec memory management issues in `setup_revisions()`. The patch specifically sets `free_removed_argv_elements` in `show_stash()` to prevent leaks when `setup_revisions()` drops `--` markers from the argument list.

The test case has been simplified to focus solely on leak detection using SANITIZE_LEAK, avoiding assertions about output behavior since there are known quirks in how `git stash show` handles `--` (like showing --patch instead of --stat output). The commit message notes these behavioral oddities but explicitly scopes the fix to memory safety only.

Junio Hamano suggests crediting the original bug reporter who found the issue via `git stash show -p --invalid`, and Jeff King agrees this would be appropriate. The patch maintains backward compatibility while fixing the immediate leak, leaving potential behavior changes for future consideration. The change is minimal - just adding the flag and a leak test - but plugs a specific case in the broader strvec memory management effort.
