Git release notification inquiry thread summary:

Velocifyer asks about automated Git release changelog delivery via email or RSS/Atom feeds, noting current RelNotes files require manual checking. Jeff King responds with technical details about existing options, explaining that while Git doesn't maintain its own RSS feeds, GitHub provides an automatic feed from release tags (https://github.com/git/git/releases.atom) though with minimal content since Git doesn't use GitHub's Releases feature. He notes the complexity of maintaining release note parity across mirrors and suggests git-scm.com as a more suitable platform for this feature, since it already tracks releases and has an active development community. King invites the original poster or others to propose this enhancement on git-scm.com's repository, framing it as a website improvement rather than a core Git feature. The response maintains Git's distributed philosophy by leveraging existing infrastructure rather than proposing new project-maintained services. Thread type remains a user question about release notifications with no patches or technical changes to Git itself.
