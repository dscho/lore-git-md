This is a feature patch series finalizing the `stash.index` configuration option for `git stash` operations. The series has been through multiple iterations and is now maintainer-approved with optimized test coverage.

The core change adds a `stash.index` config (defaulting to false) that makes `git stash apply/pop` restore the index by default when set to true, addressing the common pitfall where carefully staged changes are lost during stash operations. The `--no-index` flag remains as an opt-out mechanism. The implementation refactors internal config handling and adds comprehensive test coverage focusing on config/flag interactions.

Key technical details in this version:
- Tests now follow Phillip Wood's recommendation to verify config/CLI interactions rather than duplicating existing test cases
- New tests demonstrate `stash.index=true` implies `--index` behavior
- Tests verify config can be overridden by `--no-index` and vice versa
- Test cleanup reduces dependencies between test cases
- Documentation in `config/stash.adoc` explains the new config option

The series is ready for merging with all maintainer feedback addressed. The author notes some test style modernization could be done but is deferred to avoid delaying review of the core functionality. This represents a backward-compatible improvement to stash behavior while maintaining all existing functionality.
