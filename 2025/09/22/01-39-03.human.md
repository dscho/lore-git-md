Test improvement for the stash.index config series. This is the first patch in the v3 revision of a 4-part series that adds configurable index restoration to `git stash`. The series has already been reviewed and approved by the maintainer.

This patch makes the test suite more robust by removing implicit dependencies between tests. Currently, some tests in t3903-stash.sh fail when run in isolation because they rely on a subdirectory/ being created by earlier tests. The fix adds explicit directory creation (with `mkdir -p`) to the tests that need it, making them self-contained.

The changes are straightforward and focused - just three `mkdir -p` calls added to tests that work with subdirectories. This follows through on earlier review feedback to refine the test strategy, though the patch itself is a minor preparatory cleanup rather than part of the core functionality.

Since this is part of an already-approved series, it's likely to be uncontroversial. The changes are clearly motivated (supporting test isolation) and the implementation is clean. The rest of the series builds on this foundation to implement the new `stash.index` configuration option.
