This thread discusses new deprecation warnings in Git 2.51.0 regarding the legacy `git whatchanged` command and date-filtered `git log` usage. S0AndS0 of Digital Mercenaries LLC originally reported the warnings and sought guidance on whether these features would be removed and what alternatives exist.

Kristoffer Haugsbakk provided clear alternatives for `git whatchanged`, explaining it can be replaced with `git log --raw --no-merges` (or other output formats like `--stat` and `--name-only`). S0AndS0 has acknowledged this solution and plans to create an alias to ease the transition.

However, the thread remains open regarding the other half of the original concern - the deprecation warning for date-based filtering (`--since` and related options). S0AndS0 has followed up to ask whether this functionality is also slated for removal and what the replacement would be. This aspect still awaits maintainer input, as the discussion so far has only addressed the `whatchanged` question. The thread continues to seek clarification on Git's deprecation roadmap for these legacy features.
