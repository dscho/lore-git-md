This is a "What's cooking" status update from Junio Hamano, summarizing the current state of various Git development topics as of September 2025. These periodic reports help track progress across multiple parallel efforts in the Git project.

Several notable topics are making progress:
- The reftable backend is getting more robust with new consistency checks (kn/reftable-consistency-checks)
- A fix for "git rebase -i" now properly respects commit.cleanup when handling fixup commits (pw/rebase-i-cleanup-fix)
- The stash.index configuration variable is now honored by "git stash apply/pop" (dk/stash-apply-index)
- "git sparse-checkout" gains a new "clean" command to prune unused working tree files (ds/sparse-checkout-clean)
- The long-planned switch to 'main' as default branch name is being finalized for Git 3.0 (pw/3.0-default-initial-branch-to-main)

Some interesting technical work continues:
- Rust integration experiments are progressing (en/rust-wip, en/rust-xdiff)
- The object database layer is seeing transaction support (jt/odb-transaction)
- Memory management around revision parsing was cleaned up (jk/setup-revisions-freefix)
- Various documentation improvements are in flight (je/doc-checkout, je/doc-push)

Several topics are stalled awaiting updates, including sparse checkout variable cleanup (ac/deglobal-sparse-variables) and rebase trailer support (lc/rebase-trailer). The report also notes many smaller fixes and cleanups across the codebase.

This snapshot shows Git's development continuing across multiple fronts, with particular focus on improving internal data structures (reftable, object database), user experience (default naming, documentation), and modernization efforts (Rust integration).
