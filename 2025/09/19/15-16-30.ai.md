Performance optimization patch in the xdiff refactoring series, replacing the arena allocator (chastore_t) with a contiguous array for xrecord_t storage.

This is patch 8/10 in the v3 series preparing xdiff internals for potential Rust integration. The change removes the chastore_t arena allocator from xdfile_t in favor of a contiguous xrecord_t array, providing a 5% performance improvement according to the included measurements. The patch updates all xdiff algorithm implementations (myers, histogram, patience) to work with direct array access rather than pointer indirection through the arena.

Key technical details:
- Removes `xdfile_t.rcha` (chastore_t) field
- Changes `xdfile_t.recs` from `xrecord_t**` to direct `xrecord_t*` array
- Updates all record access patterns across xdiff/ to use array indexing
- Includes comprehensive benchmark comparisons showing:
  - 5% speedup from removing chastore
  - 5% slowdown from earlier ha removal (patch 6)
  - Net neutral when combining both changes
- Uses `--color-words` for review clarity

The change simplifies memory management while improving performance, continuing the series' pattern of removing redundant data structures. The performance measurements help justify the tradeoffs between different structural changes in the xdiff internals.
