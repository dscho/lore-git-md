This thread continues brian m. carlson's work on SHA-1/SHA-256 interoperability, specifically focusing on documentation and test infrastructure. The initial series added documentation for loose object storage format in `gitformat-loose.adoc` and introduced test prerequisites for hash algorithm testing. 

Junio C Hamano spotted a build system issue where the new documentation wasn't properly listed in `meson.build`, preventing it from being built as a manpage. The author has acknowledged this and will include the fix in v2 of the series. The content of the documentation itself - which provides important details for hash transition testing - remains unchanged and uncontroversial. 

With this minor build system adjustment now identified and agreed upon, the series appears to be progressing smoothly toward its goal of laying groundwork for Git's planned SHA-1/SHA-256 interoperability in version 3.0. The test coverage in t1450-fsck.sh and t1500-rev-parse.sh remains unaffected by this build system tweak.
