Brian m. carlson continues their foundational work on SHA-1/SHA-256 interoperability with a focused patch improving GPG signature validation in tag objects. This latest addition to the series enhances `fsck` to properly handle both `gpgsig` and `gpgsig-sha256` headers, addressing cases where strict checking could previously generate false positives.

The changes introduce new error messages for malformed signature headers and continuation lines, with the implementation in `fsck.c` now validating proper formatting and reporting clear errors for truncated signatures. Comprehensive tests in `t/t1450-fsck.sh` verify the behavior matches Git 2.29+'s approach where tag signatures appear in-body while alternate signatures use headers. This refinement is particularly important for the broader compatibility work, as proper signature header handling becomes crucial when verifying objects across different hash algorithms.

The patch builds on the series' strong documentation and testing foundation, maintaining the careful attention to technical accuracy that has characterized this interoperability effort. With Junio C Hamano and Patrick Steinhardt having previously reviewed and contributed to earlier parts of the series, this incremental improvement further solidifies the infrastructure needed for hash algorithm compatibility.
