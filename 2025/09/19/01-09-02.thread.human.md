This thread continues the foundational work by brian m. carlson on SHA-1/SHA-256 interoperability, a multi-phase effort targeting Git 3.0. Junio has proposed moving these patches to the 'next' branch, signaling technical consensus on their readiness.

With no new objections emerging and the author confirming readiness, this marks an important milestone in the broader interoperability effort. While some items like loose object map documentation remain for future series, these foundational changes pave the way for more complex functionality to follow. The author remains open to additional review if needed, but the path forward appears clear for this portion of the work.
