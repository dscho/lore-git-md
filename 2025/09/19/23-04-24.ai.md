This is a documentation patch in the SHA-1/SHA-256 interoperability series, specifically addressing the pack format documentation. Junio C Hamano provides detailed feedback on two aspects of the documentation improvements proposed by brian m. carlson.

First, Junio suggests rewording the explanation of packed object encoding to better reflect that both the header and payload are transformed representations optimized for storage format, not just omitted elements. He provides a more precise alternative wording that emphasizes how the loose object format is virtually recreated for hash computation.

Second, Junio approves of the new clarification about size encoding for deltified vs undeltified objects, noting it's an important distinction. He suggests optionally adding context about how these sizes are used for memory allocation during object processing, though this would be supplemental rather than essential information.

The feedback continues the pattern of careful, constructive review focused on documentation precision in this series. No technical issues are raised with the content - the suggestions aim to make the explanations more technically accurate and pedagogically clear. The changes remain non-controversial infrastructure work for the larger hash interoperability effort.
