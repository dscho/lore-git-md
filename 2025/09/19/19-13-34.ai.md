This is a build system fix for the SHA-1/SHA-256 interoperability documentation series. Junio C Hamano points out that the new `gitformat-loose.adoc` file from Brian M. Carlson's patch needs to be added to the Meson build system's documentation index. The failure occurs because the documentation generator expects all manpage sources to be listed in `Documentation/meson.build`.

The proposed fix is straightforward - adding the new loose objects documentation file to the manpages list in the Meson build file with the same section 5 designation as other gitformat documentation. This matches the pattern seen with similar files like `gitformat-pack.adoc` and `gitformat-index.adoc`. 

The fix appears correct and minimal, addressing exactly the build failure while maintaining consistency with the existing documentation structure. This is a mechanical integration issue rather than a content problem, and the documentation itself (which provides important details about loose object storage format) remains unchanged. The patch keeps the series moving forward toward its goal of preparing test infrastructure for Git's hash function transition.
