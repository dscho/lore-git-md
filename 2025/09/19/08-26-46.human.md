**Test refactoring for the new `git refs optimize` command**

This is the 8th patch in a 9-part series implementing the new `git refs optimize` subcommand, which provides a more modern interface to Git's reference packing functionality. The patch refactors existing test infrastructure to be shared between the legacy `git pack-refs` command and the new subcommand.

Meet Soni extracts the core test logic from `t0601-reffiles-pack-refs.sh` into a new `t/pack-refs-tests.sh` file, replacing hardcoded `pack-refs` calls with a `$pack_refs` variable. The original test file becomes a simple driver that sets this variable and sources the shared test library. This follows the pattern used for other ref-related commands and prepares for testing the new subcommand.

The 430-line test file is essentially moved intact, with all its comprehensive coverage of reference packing behavior - pruning, exclusion patterns, worktree refs, broken ref handling, and auto-packing heuristics. The tests verify both low-level behaviors (like packed-refs file format validation) and high-level scenarios (like directory/file conflicts when creating branches).

This is a straightforward but important infrastructure change that enables testing both commands with identical test coverage. The implementation looks clean and maintains all existing test cases while making them reusable. The next patch in the series will presumably add the driver for testing `git refs optimize`.
