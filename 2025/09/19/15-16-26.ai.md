Refactoring patch in the xdiff preparation series for Rust compatibility.

This is patch 4/10 in the v3 series of preparatory cleanups for xdiff internals, focusing on removing an unnecessary helper function. The patch eliminates `xdl_get_rec()` which was serving as an accessor for `xrecord_t` fields but actually made the code harder to follow by introducing an extra layer of indirection. The change directly accesses `xdf->recs[ri]` fields (`ptr` and `size`) throughout xemit.c instead.

The modification touches several functions in xdiff/xemit.c that previously used the helper, including `xdl_emit_record()`, `match_func_rec()`, and `is_empty_rec()`. The new version is more straightforward as it works directly with the record structure. The `is_empty_rec()` function also gets a slight optimization by using a single loop rather than pointer arithmetic.

This is a pure refactoring with no behavior change, continuing the series' goal of simplifying xdiff internals by removing unnecessary abstractions. The change aligns with the overall effort to make the code more transparent and easier to work with, particularly for the planned Rust integration. Performance impact is neutral since the removed function was just doing simple field access.
