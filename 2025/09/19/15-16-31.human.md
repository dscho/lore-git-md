This is a refactoring patch in the xdiff preparation series for Rust compatibility. It's patch 9/10 in the v3 series of preparatory cleanups that are being merged to 'next'.

The patch removes redundant local variable aliases (`rchg1` and `rchg2`) in `xdl_build_script()` that were simply pointing to the `rchg` fields of the xdfile_t structs. The change makes the code more direct by accessing the struct fields explicitly rather than through these intermediate pointers.

This is a straightforward cleanup that follows the series' theme of simplifying xdiff's internals. The change is purely structural with no behavior modification, and it makes the code slightly more maintainable by removing unnecessary indirection. The patch includes a "Best-viewed-with" trailer suggesting `--color-words` for easier review of the minimal changes.

This continues the series' pattern of preparing xdiff code for potential Rust integration by removing C-specific patterns that would complicate translation to Rust. The change is uncontroversial and was already approved in previous versions of the series.
