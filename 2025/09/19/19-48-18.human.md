Build system patch addressing Rust linking issues with libgit.a.

This is a follow-up to Eric Sunshine's review pointing out that the original patch lacked motivation. Ezekiel Newren explains that the `-fPIE` flag addition to the Makefile is needed to resolve linking errors when the Rust compiler tries to use libgit.a. The error occurs specifically with Makefile-built libraries (Meson builds work fine without this change) and involves relocation issues with position-independent executables.

The patch appears to be a straightforward technical fix for a specific build problem encountered during Rust integration work. While the solution seems correct, the exchange highlights the importance of including clear motivation in commit messages - a point maintainers have emphasized throughout this Rust integration effort. This is part of the larger build system adjustments needed for Rust compatibility, though it's a relatively minor piece compared to some of the architectural questions still being debated in the thread.
