This is a user report about the deprecated `git whatchanged` command. James Puleo encountered the command's refusal to run without the `--i-still-use-this` flag in Git 2.51.0. 

The user was trying to find which ref last contained a deleted file, and found `git whatchanged`'s file-focused output format appealing for this purpose. They argue that the command provides useful functionality (showing pure file path changes) and question why such a tool should be made difficult to access without technical justification.

The email appears to be raising this as a usability concern rather than proposing a specific change. It's worth noting that `git whatchanged` was deprecated in favor of `git log` with appropriate flags, but the user's experience suggests there may still be valid use cases for its specific output format.
