This is a build system patch addressing Rust integration with libgit.a, part of the ongoing Rust porting effort. It's the third patch in an 18-part series from Ezekiel Newren.

The patch merges xdiff library objects into libgit.a when using Makefile builds, bringing parity with how Meson already handles this. The motivation (added in response to Eric Sunshine's review) is to simplify Rust linking - having Rust link against just libgit.a rather than both libgit.a and xdiff/lib.a when using Makefile builds. The author acknowledges this could have been better explained initially.

This change aligns with the thread's broader discussion about build system coordination between Makefile and Meson for Rust compatibility. It follows Junio Hamano's earlier feedback about libgit.a integration strategies, though doesn't yet implement his suggested approach of maintaining reftable objects as a separate variable while including them in libgit.a.

The patch appears technically sound, addressing a concrete build system divergence between Makefile and Meson that affects Rust integration. While the initial commit message was under-motivated, the explanation in this follow-up email provides adequate justification for the change.
