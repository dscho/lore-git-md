This thread documents planned changes to Git's pack index format to support very large repositories. The initial patch (1/9 in the series) updates the technical documentation for pack index v3 format to reflect two key changes: expanding 4-byte integers to 8-byte integers to handle repositories with more than ~67 million objects, and updating checksum documentation to show full 32-byte SHA-256 checksums rather than truncated versions. The changes are motivated by real-world repository sizes exceeding current limits and a desire to maintain consistency with SHA-256 behavior while avoiding potential security compliance issues. While this first patch only updates documentation, it sets the stage for the implementation changes that will follow in the rest of the series.
