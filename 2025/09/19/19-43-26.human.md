This is a discussion about the ongoing deprecation of `git whatchanged`. Kristoffer Haugsbakk responds to James Puleo's report about encountering the new `--i-still-use-this` requirement in Git 2.51.0.

The email clarifies that `git whatchanged` is being removed because its functionality is fully covered by `git log` with better defaults. Kristoffer notes that while James found the file-change listing useful, equivalent output can be obtained through `git log --raw --no-merges`. The response suggests this is part of Git's broader effort to simplify its interface by consolidating similar commands.

The tone is helpful, providing a direct alternative while acknowledging the original use case.
