Documentation patch for the ref optimization series. This is patch 6/9 in the v4 series implementing the new `git refs optimize` subcommand, which builds on the earlier refactoring of pack-refs functionality into a shared implementation.

The patch factors out the common options documentation from `git-pack-refs.adoc` into a new `pack-refs-options.adoc` file, using an include directive. This prepares for sharing these option descriptions with the upcoming `git refs optimize` documentation while maintaining identical rendered output for `git-pack-refs`. The change is purely organizational - the content remains exactly the same, just moved to a shared location.

- Options moved include `--all`, `--no-prune`, `--auto`, `--include`, and `--exclude`
- Behavior descriptions for both files and reftable backends preserved verbatim
- No functional changes - rendered documentation remains identical
- Part of systematic documentation updates for the new ref optimization architecture

This follows the established pattern in the series of maintaining existing behavior while restructuring for code/documentation sharing between `pack-refs` and the new `refs optimize` command.
