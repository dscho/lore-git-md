This is a refactoring patch in the xdiff preparation series for Rust compatibility. It eliminates the redundant `diffdata_t` wrapper struct whose fields were all direct aliases of fields in `xdfile_t`. The change simplifies the code by removing an unnecessary abstraction layer, making `xdl_recs_cmp()` take `xdfile_t` parameters directly rather than going through the intermediate struct.

The patch is straightforward - it removes the struct definition and updates all callers to access the fields directly from `xdfile_t`. The commit message clearly documents the field mappings being removed. This appears to be a clean, mechanical change that maintains identical behavior while reducing indirection.

This is part of a larger effort to clean up xdiff internals before potential Rust integration, with this particular change being one of the simpler preparatory steps in the series. The patch follows the pattern seen in earlier parts of the series - removing unnecessary abstractions to make the code more direct and easier to work with.
