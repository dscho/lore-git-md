Documentation update for pack index v3 format changes. This is part 1 of a 9-patch series (no cover letter seen yet).

The patch updates the documentation to reflect planned changes to the pack index v3 format. The key changes are:
1. Expanding 4-byte integers to 8-byte integers for file offsets and trailer positions, allowing the format to handle repositories with more than ~67 million objects (needed as some users already create repos with 55+ million commits)
2. Using full 32-byte SHA-256 checksums instead of truncated versions, both for consistency with existing SHA-256 pack checksums and to avoid potential security compliance concerns

The changes appear well-motivated by real-world usage patterns and maintain consistency with Git's existing SHA-256 implementation. The documentation updates are straightforward and match the technical changes described.
