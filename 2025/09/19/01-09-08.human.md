This is part 6 of Brian M. Carlson's SHA-1/SHA-256 interoperability series, adding a new feature to `git rev-parse` for compatibility hash reporting. The patch extends `--show-object-format` with a new "compat" mode that prints the repository's compatibility hash algorithm (if configured) or an empty line if none exists. This provides a clean way for scripts to query the compatibility hash while maintaining unambiguous output when used alongside other hash-format options.

The implementation adds the new mode to both documentation and code, with thorough test coverage that verifies behavior in repositories both with and without a configured compatibility hash. The change is part of the broader hash transition infrastructure work, specifically enabling tools to properly handle repositories that may need to work with both SHA-1 and SHA-256 objects during the transition period.

The patch follows the series' pattern of careful, incremental changes to support hash algorithm interoperability, with clear documentation updates and comprehensive tests.
