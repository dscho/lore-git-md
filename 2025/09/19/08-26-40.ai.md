This is a backend implementation patch in the ref optimization series, specifically adding the files-backend support for the new `refs_optimize()` API.

The patch implements the `files_optimize()` function for the files backend, which simply wraps the existing `files_pack_refs()` function since packing is the optimization mechanism for this backend. The new function is wired into the ref_storage_be vtable alongside other backend operations.

Key technical details:
- Adds 10 lines to refs/files-backend.c
- Creates new `files_optimize()` that delegates to `files_pack_refs()`
- Updates `refs_be_files` vtable to include the optimize callback
- Maintains behavioral equivalence with existing packing functionality
- Follows the established pattern from the refs API foundation work

This is a straightforward implementation that makes the new API functional for the files backend while preserving all existing behavior. The patch is part of the larger effort to introduce the `git refs optimize` subcommand while maintaining compatibility with `git pack-refs`. It builds on the foundational API work from earlier in the series and will be followed by similar implementations for other backends.
