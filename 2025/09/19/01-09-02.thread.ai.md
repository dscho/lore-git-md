SHA-1/SHA-256 interoperability series part 1 (9 patches) by brian m. carlson continues with build system integration for the new documentation. The series adds test infrastructure (`COMPAT_HASH` prerequisite, `GIT_TEST_DEFAULT_HASH="sha256:sha1"` syntax) and documents loose object storage format in `gitformat-loose.adoc`. Junio C Hamano identified and fixed a build failure where the new documentation was not listed in `Documentation/meson.build`, requiring a mechanical fix to add the file to the manpages list with section 5 designation, matching existing gitformat documentation. The patch author acknowledges this fix and plans to incorporate it in v2 of the series while awaiting any additional feedback. The content itself remains unchanged and provides important details for hash transition testing, with coverage in t1450-fsck.sh/t1500-rev-parse.sh. This is a non-controversial groundwork patch series preparing for Git's planned SHA-1/SHA-256 interoperability in version 3.0, progressing smoothly with only minor technical adjustments to the build system configuration.
