The reporter (James Puleo) was using Git 2.51.0 and found the command useful for tracking file changes across refs, particularly when trying to locate a deleted file's history. The email suggests the user was unaware of the deprecation path for `git whatchanged` (which has been ongoing since 2020) and its recommended replacement with `git log` options. The reporter's use case - finding which ref last contained a deleted file - could indeed be served by `git log --name-status` or similar alternatives, but they express frustration with the extra friction introduced by the deprecation warning.
