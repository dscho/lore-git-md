This is a refactoring patch in the xdiff preparation series for Rust compatibility, specifically removing the redundant `xdfile_t.ha` array.

The patch eliminates the `ha` array from the `xdfile_t` struct since its contents can always be derived from `xdfile_t.recs[xdfile_t.rindex[i]]->ha`. This change introduces a new `get_hash()` helper function in xdiffi.c to access the hash values through this indirection. The author notes this change results in a 5% performance regression, which is documented in the commit message.

Key technical changes:
- Removes `xdfile_t.ha` field declaration from xtypes.h
- Adds `get_hash(xdfile_t*, long)` helper that performs the indirection
- Updates all hash comparisons in xdiffi.c to use the helper instead of direct array access
- Simplifies cleanup in xdl_prepare_ctx() by removing ha allocation
- Streamlines record cleanup in xdl_cleanup_records() by removing redundant ha assignments

The change affects the classic diff algorithms (myers and minimal) but not histogram diff. The performance impact is explicitly measured and accepted as part of the simplification effort, with the author noting this is preparatory work for future struct reorganization. The patch maintains identical behavior while reducing redundancy in the data structures.
