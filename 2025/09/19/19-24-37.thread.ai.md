[PATCH] git whatchanged deprecation user feedback

Thread identity: User report from James Puleo about `git whatchanged` deprecation in Git 2.51.0, questioning the removal of this file-change tracking tool, with follow-up from Kristoffer Haugsbakk.

Core problem: The `git whatchanged` command, deprecated since 2020 and now requiring `--i-still-use-this` flag, remains useful for tracking file changes across refs - particularly for locating deleted files' history. User argues the deprecation creates unnecessary friction for a simple, functional tool, while maintainers view it as redundant with `git log`.

Current status: `git whatchanged` has been in deprecation path since 2020 (commit a8e2394704). Kristoffer confirms the removal is intentional as the functionality is fully covered by `git log` variants like `git log --raw --no-merges`, which provide equivalent file-change listing behavior.

Key technical details: The reporter's use case involves finding which ref last contained a deleted file. Kristoffer provides specific `git log` alternatives: `--raw --no-merges` for direct replacement, plus mentions of `--stat` and `--name-only` for different output formats. The original command's behavior can be replicated with `git log --name-status --diff-filter=D -- <path>` for deleted file tracking.

Open questions: Whether the deprecation warning's friction is justified given the command's continued utility for some workflows remains unresolved. The technical migration path is now clearly documented in the thread.

Participant positions: James Puleo reports real-world usage where `git whatchanged` provides simpler workflow. Kristoffer Haugsbakk represents the maintainer perspective that this is part of interface simplification, providing specific `git log` alternatives but not addressing the usability friction concern.

Related work: Original deprecation discussion from 2020, ongoing efforts to modernize and simplify Git's command-line interface. The thread now includes concrete migration instructions for `whatchanged` users.
