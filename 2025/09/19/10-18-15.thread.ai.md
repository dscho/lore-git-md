Bug report: double-free crash in `git stash show -p` with invalid options. Thread originated by Lauri Niskanen documenting a crash when passing invalid arguments (e.g. `--invalid`), with regression identified by Kristoffer Haugsbakk as introduced in commit 748bd094 ("builtin/stash: fix leak in `show_stash()`", 2024-06-11). Core issue is in `show_stash()` where `strvec_clear()` attempts to free already-freed memory during error cleanup after option parsing fails, triggering "free(): double free detected in tcache 2".

Technical details: crash occurs at `builtin/stash.c:1047` during cleanup path. Valgrind traces confirm memory originally allocated via `strdup()` is freed twice. Junio Hamano's analysis reveals root cause: `setup_revisions()` processes arguments by shifting elements in the strvec array without NULL-terminating unused slots, causing `strvec_clear()` to encounter duplicate entries during cleanup. Jeff King expands the analysis, noting additional memory leaks when "-p" argument is rearranged, indicating broader strvec management issues in `setup_revisions()` affecting other commands like `git bisect`.

Current solutions under discussion: (1) Hamano's local fix in `show_stash()` that NULLs unused slots after `setup_revisions()`, (2) King's proposed comprehensive wrapper for `setup_revisions()` that would handle cleanup by enabling `free_removed_argv_elements` flag, properly updating strvec's `.nr` field, and ensuring NULL-termination. The wrapper approach would address both the double-free and related leaks while maintaining strvec invariants across multiple commands.

Open questions: whether to implement a local fix (faster to backport) or systemic solution (more maintainable long-term), and whether similar issues exist in other argument parsing paths. Technical analysis confirms current behavior violates strvec assumptions in multiple ways, with test cases like `git stash show -p --` demonstrating the leaks. Discussion has expanded from original crash to considering systematic solution for argument parsing cleanup across Git commands.
