Documentation update in the SHA-1/SHA-256 interoperability series. This patch updates the pack index v3 format documentation to reflect the planned use of 8-byte integers for offsets and trailer positions (addressing potential size limitations with 4-byte integers) and corrects SHA-256 checksum sizes from 20 to 32 bytes. Junio C Hamano provides feedback suggesting the explanation about hash truncation could be more concise, noting that the current justification paragraphs are longer than necessary since Git already uses full hashes in other contexts. The changes are straightforward technical corrections to align the documentation with the planned implementation, with no substantive objections raised. This continues the non-controversial groundwork for hash interoperability, with the only discussion point being about the level of detail in the commit message justification rather than the technical content itself.
