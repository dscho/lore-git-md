# Controversial proposal response

This is a strongly worded response to Patrick Steinhardt's RFC proposing to make Rust mandatory in Git. The author, Sergey Fedorov, argues this would be disastrous for systems without Rust support, particularly impacting build systems and package managers that rely on Git for source fetching. They claim it would effectively kill Git usage on such systems since there's no viable replacement for these critical infrastructure components.

The email takes a personal tone, stating the change would make Git unusable for the author and prevent them from continuing their open source contributions. While the response lacks technical specifics about the original proposal's implementation details, it highlights a key concern about backward compatibility and ecosystem impact that would need addressing in any serious discussion.

The message serves as an early warning about potential community pushback to mandatory Rust adoption, particularly from users on niche platforms (implied by the macos-powerpc.org domain). This type of feedback would be important for maintainers to consider when evaluating the feasibility and rollout strategy of such a significant change.
