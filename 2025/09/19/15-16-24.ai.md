- Moves `xdl_free_ctx()` definition before its first use in `xdl_prepare_ctx()`
- Uses `xdl_free_ctx()` for both normal cleanup and error paths
- Maintains identical behavior while reducing code duplication
- Part of broader effort to simplify xdiff internals for potential Rust integration

The change is purely internal cleanup with no behavior changes, continuing the series' pattern of removing redundant code paths while preparing for future Rust compatibility work.
