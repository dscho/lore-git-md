This is a refactoring series preparing xdiff internals for potential Rust integration, now in its third version. The series focuses on cleanup and simplification of the xdiff data structures (xdfile_t and xrecord_t) without changing behavior, making them more straightforward for future Rust compatibility work.

The v3 resend contains no actual patch changes from v2 - it was only needed to ensure patch 9 properly appeared on the mailing list after an archive issue. The series has already been reviewed and approved for merging to 'next', with Junio Hamano confirming the structure (10 preparatory patches rather than the originally advertised 9).

Key changes in this series include removing unused fields from data structures, eliminating redundant wrapper types, replacing a custom allocator with contiguous arrays (which gives a 5% performance boost), and standardizing how change markers (rchg) are handled across all diff algorithms. The cleanups are independent improvements to xdiff internals, with performance impacts carefully measured and documented.

The Rust-specific type changes have been split into a separate follow-up series (patches 11-17) that will handle the actual type system adjustments needed for Rust compatibility. This separation ensures the current behavior-preserving refactorings can land first.
