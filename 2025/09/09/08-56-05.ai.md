This is patch 2/17 in the xdiff refactoring series for Rust compatibility, focusing on cleanup of xdiff/xprepare.c. The patch eliminates redundant local variables in xdl_prepare_ctx() that were shadowing xdfile_t struct fields, instead using the struct fields directly. This removes a duplicate cleanup path that was effectively inlined in the function, consolidating all cleanup through the existing xdl_free_ctx() function.

The changes are mechanical but improve maintainability by:
1. Removing shadow variables that served no purpose beyond temporary storage
2. Centralizing cleanup logic in xdl_free_ctx()
3. Making the control flow more straightforward by eliminating redundant variable assignments

The patch maintains identical behavior while simplifying the code structure. Elijah Newren notes a minor style issue (unnecessary blank line in xdl_free_ctx()) but otherwise approves the changes. This continues the series' pattern of preparatory cleanups before the more substantive Rust type system changes in later patches.
