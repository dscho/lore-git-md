This is part 2/15 of Patrick Steinhardt's refactoring series to centralize packfile management in Git's object database. The patch moves the list of packfiles from `struct object_database` to the new `struct packfile_store`, which was introduced in the foundational patch of this series.

The changes relocate the `packed_git` linked list and its associated management functions into the packfile store subsystem. Key modifications include:
- Removing `packed_git` from `struct object_database`
- Adding `packs` to `struct packfile_store`
- Moving packfile closing and freeing logic into new `packfile_store_close()` and `packfile_store_free()` functions
- Updating all packfile iteration code to use the new location

The patch is a straightforward migration of existing functionality with no behavior changes, continuing the series' incremental approach to refactoring. It touches several core packfile handling functions but maintains the same external behavior while improving the internal structure. The changes appear well-contained and mechanical, following the established pattern from previous rounds of review.
