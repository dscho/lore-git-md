This thread continues Patrick Steinhardt's ongoing effort to refactor Git's object database (ODB) subsystem in preparation for pluggable backends. The current series focuses on transaction handling, with Justin Tobler contributing a bugfix and now a significant code relocation patch.

The main change moves all transaction-related code from the specialized bulk-checkin.[ch] files into object-file.c, eliminating those files entirely. This simplifies the interface to just begin/end transaction functions while keeping the same core functionality internal to object-file.c. Justin's earlier fix addressed an edge case where verbose output could interfere with transaction handling.

The work builds on previous refactoring that moved bulk-checkin to use repository variables. Key changes include enforcing a strict one-transaction-at-a-time model and removing unused functions. While the code movement is mechanical, reviewers need to verify no hidden dependencies remain and that all transaction edge cases are properly handled in the new location. The series is part of Patrick's larger ODB abstraction effort, which connects to ongoing work on pluggable ref backends like reftable. So far only the authors have participated; the thread awaits broader technical feedback on the design changes.
