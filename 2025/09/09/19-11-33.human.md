This is a refactoring patch in a series transitioning Git's object database transaction handling from the bulk-checkin subsystem to a more generic ODB interface.

Justin Tobler continues the work started by Patrick Steinhardt to consolidate transaction-related code into object-file.c. This fifth patch focuses on renaming functions and types to better reflect their new context, changing "bulk-checkin" prefixes to "transaction" or "packfile_transaction" variants. Notably, it eliminates the standalone `finish_tmp_packfile()` function by folding its logic directly into `flush_packfile_transaction()`.

The changes are mechanical renames with no behavior modifications, completing the conceptual shift from bulk-checkin-specific terminology to more general transaction handling. The patch touches core object writing paths but maintains all existing functionality around pack creation, fsync batching, and temporary file handling.

This appears to be a straightforward cleanup patch in a larger technical series, well-contained with clear renaming rationale. Reviewers should verify the new names accurately reflect the functions' roles in the consolidated transaction system.
