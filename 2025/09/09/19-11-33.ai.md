This is a refactoring patch in Justin Tobler's series relocating transaction code from bulk-checkin to object-file.c. The patch focuses on renaming functions and types to better reflect their new context in the ODB transaction system, eliminating the "bulk-checkin" terminology.

- Updates function prefixes from `bulk_checkin`/`prepare_to_stream` to `transaction`/`packfile_transaction` variants (e.g., `prepare_loose_object_transaction`, `flush_packfile_transaction`)
- Eliminates the standalone `finish_tmp_packfile()` function by merging its logic into `flush_packfile_transaction()`
- Updates all callers to use the new names
- Maintains identical behavior while improving naming consistency

The changes are mechanical but important for clarity as this code moves from its original bulk-checkin context to being core ODB transaction infrastructure. The patch follows the series' pattern of simplifying the interface while preserving functionality. All renamed functions maintain their existing parameters and behavior, just with more accurate names reflecting their role in the transaction system.

This continues the series' goal of consolidating transaction handling code into object-file.c with a cleaner interface, preparing for future pluggable ODB backends.
