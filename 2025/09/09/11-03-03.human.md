The patch moves the packfile path-to-object map from `struct object_database` to `struct packfile_store`, where it more logically belongs as part of the packfile management subsystem. The change includes relocating the `pack_map` hashmap and its associated comparison function, making the function static since it's now only used within packfile.c. The diff shows straightforward mechanical changes updating all references to use the new location.

This continues the series' pattern of clean, focused moves that improve code organization without changing behavior. The changes are well-contained (25 lines net change across 5 files) and maintain backward compatibility. Reviewers have been positive about the overall approach in previous rounds, and this patch appears consistent with that established direction.
