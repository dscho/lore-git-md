Refactoring patch in the xdiff Rust compatibility series.

This is patch 5/17 in Ezekiel Newren's series preparing xdiff internals for potential Rust integration. The diff is clean and focused, touching only `xdiff/xdiffi.c` and `xdiff/xdiffi.h` to eliminate the struct definition and update all callers to use `xdfile_t` directly. Elijah Newren's review confirms the change makes sense, noting that Git's color-moved highlighting helps visualize the straightforward field substitutions.

This continues the series' pattern of simplifying xdiff structures while maintaining identical behavior, following earlier patches that removed unused fields and eliminated function indirections. The change appears non-controversial and well-contained, with no test changes needed since it's purely an internal cleanup.
