Refactoring patch introducing `struct packfile_store` as part of the ODB abstraction effort. This is the foundational patch in Patrick Steinhardt's 15-part series to centralize packfile management in Git's object database.

The patch creates a new empty `struct packfile_store` that will eventually become the single source of truth for packfile-related data, currently scattered between `struct packed_git` and `struct object_database`. The immediate changes are minimal - just adding the new struct definition and basic allocation/free functions - but set up for subsequent patches to migrate packfile management into this new structure.

Key technical details:
- Adds `struct packfile_store` with just an `odb` pointer initially
- Introduces `packfile_store_new()` and `packfile_store_free()` functions
- Updates `struct object_database` to contain a `packfiles` pointer
- Touches 4 files (odb.c, odb.h, packfile.c, packfile.h)
- No behavior changes yet - this is purely preparatory infrastructure

The commit message explains this is part of a larger effort to enable pluggable ODB backends, with future work planned to move the structure down to the ODB source level. The patch follows Git's incremental refactoring approach, introducing the scaffolding before filling it with functionality in later patches.
