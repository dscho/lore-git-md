Refactoring patch in Patrick Steinhardt's packfile store series (v4 13/15). This patch removes the redundant `get_packed_git()` function in favor of using `get_all_packs()` throughout the codebase. Both functions ultimately return the same list of packfiles, but `get_all_packs()` additionally loads MIDX pack information - a minor operation since the MIDX is already prepared. The change simplifies the API by eliminating a confusing distinction between two nearly identical functions.

The patch updates callers in gc.c, grep.c, and object-name.c to use `get_all_packs()`, removes the function implementation from packfile.c, and deletes its declaration from packfile.h. This is a straightforward cleanup that fits well with the series' goal of refining the packfile store abstraction. The change appears well-justified and maintains all existing functionality while reducing API surface area.
