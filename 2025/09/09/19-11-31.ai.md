This is a refactoring patch in Patrick Steinhardt's series to simplify Git's object database transaction interface. It removes the `flush_odb_transaction()` function which allowed partially committing a transaction without completing it, as this capability is no longer used anywhere in the codebase.

The patch consolidates the transaction finalization logic entirely into `end_odb_transaction()`, which now directly handles both the packfile flushing and transaction cleanup that was previously split across the two functions. This makes the interface simpler and more predictable by ensuring transactions are always either fully completed or not at all.

Key technical changes:
- Deletes `flush_odb_transaction()` function and its declaration
- Moves its packfile flushing logic into `end_odb_transaction()`
- Keeps the NULL-check behavior for transaction cleanup
- Updates both bulk-checkin.c and .h files with these changes

This appears to be a straightforward cleanup that follows naturally from the earlier work in the series to remove transaction nesting capabilities. The change is mechanical and well-contained, with no apparent impact on other parts of the codebase. The commit message clearly explains the removal is safe since there are no remaining callers of the function being deleted.
