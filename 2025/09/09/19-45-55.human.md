User experience enhancement for deprecated command messaging. This is patch 5/7 in the command deprecation framework series, focusing on improving the guidance for users of the deprecated `git whatchanged` command.

The patch adds concrete instructions showing users how to replace `git whatchanged` with equivalent `git log` options (`--raw --no-merges`), both in the error message and documentation. The error message now includes a clear hint about creating an alias for those who want to maintain their workflow. The changes also make the hint system more flexible by adding a `hint` parameter to the `you_still_use_that()` function.

The implementation is clean and maintains consistency with the rest of the series, showing the same replacement options in both the man page and error message. This addresses real-world feedback from users who continued using the deprecated command despite its removal notice in Git 2.51.0. The patch appears well-tested and integrates smoothly with the deprecation framework established in earlier patches of the series.
