- Current clar implementation already uses mktemp()+mkdir() fallback for some platforms
- Proposal would add HP-UX to those platforms (using hypothetical __HPUX define)
- Would require upstream clar framework modification
- Avoids need for Git-specific compat/posix.h inclusion
- Maintains consistency with clar's existing portability approach

This shifts the architectural discussion toward whether to:
1) Pursue upstream clar changes for broader ecosystem benefit
2) Accept the local header inclusion fix as more maintainable
