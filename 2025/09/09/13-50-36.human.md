This is a refactoring patch in a series preparing xdiff internals for Rust compatibility. Phillip Wood provides feedback email on patch 8/17 from Ezekiel Newren's series, which removes the redundant `chastore_t` arena allocation in favor of storing `xrecord_t` structs directly in a contiguous array.

Phillip agrees with Elijah Newren's earlier suggestion that the commit message could better explain the change's motivation and implications. He notes the patch converts from a two-level storage scheme (arena + pointer array) to direct contiguous storage of records, which may involve more copying during array growth but shouldn't cause allocation issues given the small size of `xrecord_t`. The change affects all xdiff algorithm implementations (histogram, patience, etc.) and touches many files, mostly mechanical updates to dereference syntax (`->` to `.`).

The feedback is positive overall, calling the series "a really nice cleanup" while suggesting minor documentation enhancements. This continues the thread's pattern of substantive technical review focused on both code changes and commit message quality.
