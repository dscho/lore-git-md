Refactoring patch in a series preparing Git's object database (ODB) for pluggable backends. This is patch 4/6 from Justin Tobler, relocating ODB transaction code from bulk-checkin.[ch] to object-file.[ch].

The patch moves all transaction-related code from the bulk-checkin subsystem into object-file.c, eliminating the bulk-checkin.[ch] files entirely. This simplifies the exposed interface to just `begin_odb_transaction()` and `end_odb_transaction()`. The implementation details (packfile handling, fsync batching, etc.) become internal to object-file.c. Function and type names will be adjusted in a subsequent commit to better fit their new location.

Key technical changes:
- Deletes bulk-checkin.[ch] (438 lines removed)
- Moves transaction implementation to object-file.c (386 lines added)
- Keeps same core functionality but now internal to object-file.c
- Updates all callers to use object-file.h instead of bulk-checkin.h
- Maintains same transaction semantics (single-transaction model, fsync batching)
- Preserves all existing behavior including edge cases like pack size limits

This continues the architectural work started in earlier patches to make transaction handling more generic for future pluggable ODB backends. The code movement is straightforward with no functional changes - the real test will come in verifying all transaction edge cases work correctly with the new location. Reviewers should check that no hidden dependencies on bulk-checkin internals remain in the codebase.
