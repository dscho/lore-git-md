This is a test patch in the command deprecation framework series, specifically adding test coverage for the alias shadowing behavior of both deprecated and regular builtins.

The patch extends the test suite in t0014-alias.sh to verify that Git properly handles alias shadowing for a sample of regular builtin commands (like `git grep`, `git checkout-index`, etc.), ensuring they cannot be shadowed by aliases. This complements the existing test for deprecated command shadowing added in the previous commit.

The test confirms the behavior documented in git-config(1) which states that aliases hiding existing Git commands are ignored except for deprecated ones. The author notes they tested only a sample of builtins rather than all of them to avoid adding ~600ms to the test runtime.

As part of the larger deprecation framework effort, this test helps ensure the new alias shadowing feature works as intended while maintaining the expected behavior for non-deprecated commands. The implementation looks straightforward and well-contained, adding a new test helper function and exercising it against several representative builtins.
