This is a refactoring and feature series that introduces transaction interfaces to Git's object database (ODB) subsystem, continuing work from a previous patch series. The main goal is to make transaction handling more generic in preparation for pluggable object database backends.

The series moves transaction-related code from the bulk-checkin subsystem to the more central object-file.c, removing the specialized bulk-checkin.[ch] files entirely. Key changes include:
- Eliminating ODB transaction nesting which wasn't actually being used
- Fixing transaction handling in `update-index` when --verbose is used
- Renaming functions to be more generic (e.g., from bulk-checkin to odb prefixes)
- Adding new transaction interface functions in odb.[ch]

The changes are primarily code movement and renaming, with the behavioral changes being:
- Transactions now properly ended in update-index --verbose case
- Removal of unused transaction nesting capability
- New odb_transaction_*() interface functions
