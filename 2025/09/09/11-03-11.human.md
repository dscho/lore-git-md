This is part 12/15 of Patrick Steinhardt's ongoing refactoring series to move packfile management into a dedicated store as part of the ODB abstraction effort. The patch relocates the `get_multi_pack_index()` function from packfile.c to midx.c where it more logically belongs, since it deals with multi-pack index functionality rather than packfiles directly.

The change requires exposing the previously internal `packfile_store_prepare()` function since `get_multi_pack_index()` needs to call it. The patch includes thorough documentation for this newly public function, explaining its purpose and typical usage patterns. The implementation remains functionally identical - this is purely an organizational change to better separate concerns between subsystems.

The patch follows the series' pattern of careful, incremental refactoring that maintains all existing behavior while improving code organization. It continues the trend of making the packfile store interface more complete and properly documented. Reviewers have been generally positive about the architectural direction of this series, and this patch appears to be a straightforward improvement that fits well with the overall goal.
