Refactoring and feature patch introducing a new ODB transaction interface. This is the final patch in a 6-part series that relocates and renames transaction handling code from bulk-checkin to object-file.c, as part of preparing Git's object database for pluggable backends.

The patch adds new `odb_transaction_{begin,commit}()` functions in the odb subsystem, providing an object-source-agnostic interface for transaction management. It updates all callers to use this new interface while renaming the original file-specific functions to `object_file_transaction_{begin,end}()` for clarity. The changes affect several commands including `add`, `update-index`, `unpack-objects`, and cache-tree operations.

This completes the series' goal of making transaction handling more generic while maintaining all existing behavior. The patch is mechanically straightforward, updating call sites to use the new interface names. As the culmination of the series, it represents a significant step toward the larger goal of pluggable ODB backends, though the actual backend abstraction remains future work.
