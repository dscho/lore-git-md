This is a refactoring patch in the xdiff internals cleanup series, specifically removing an unnecessary helper function that was obscuring direct field access.

Ezekiel Newren's patch 04/17 eliminates `xdl_get_rec()`, a function that served only to alias accesses to `xrecord_t` fields. The change makes the code more transparent by having callers access `xdf->recs[ri]->ptr` and `xdf->recs[ri]->size` directly rather than through the intermediate function. The diff shows this change being applied consistently across several functions in xdiff/xemit.c.

Elijah Newren provides review feedback suggesting the patch could be improved by: (1) removing an extra blank line that's no longer needed, and (2) separating style cleanups (like brace placement) into a distinct patch to make the functional changes easier to review. He agrees with the core change that the direct field access does make the code easier to follow.

This continues the series' pattern of simplifying xdiff's implementation while maintaining identical behavior. The change is relatively straightforward and uncontroversial, though the review suggests some minor improvements to the patch presentation.
