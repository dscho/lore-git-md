Refactoring patch in Patrick Steinhardt's packfile store series (v4 13/15). This patch removes the redundant `get_packed_git()` function in favor of using `get_all_packs()` throughout the codebase, as both functions ultimately return the same list of packfiles but with slightly different initialization behavior.

The key technical change is the elimination of `get_packed_git()` which was nearly identical to `get_all_packs()` except that the latter also loads MIDX pack information. The patch argues this difference is negligible in terms of performance since the MIDX is already prepared, and the naming was misleading since both functions return the same packfiles. The change affects 5 files, updating callers in gc.c, grep.c, and object-name.c to use `get_all_packs()` instead.

This continues the series' pattern of simplifying the packfile interface while maintaining all functionality. The change appears straightforward with no behavioral impact, though it does remove a public API function that might have external users. The commit message provides a thorough rationale for why this consolidation is safe and improves code clarity.
