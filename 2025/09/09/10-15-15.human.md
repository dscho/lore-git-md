Platform compatibility follow-up for HP-UX test framework fix. Patrick Steinhardt confirms he has merged the HP-UX compatibility fix upstream into the clar test framework (adding `__hpux` macro detection to use the mktemp() fallback path). This resolves the build issue Michael Osipov encountered on HP-UX systems when running Git's unit tests. 

The solution follows the same pattern already established for Solaris and Tandem systems in the clar framework. Steinhardt notes he will send a separate patch to update Git's copy of the clar framework to include this change. 

This wraps up the thread that began with Osipov's report of test failures on HP-UX due to mkdtemp() linking issues. The final solution proved simpler than the initial workarounds proposed, requiring only a Makefile change to use the correct preprocessor macro name (`__hpux` rather than `__HPUX`). The fix has been validated by Osipov on an HP-UX system.
