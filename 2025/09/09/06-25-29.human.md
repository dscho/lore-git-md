This is a technical refinement in the command deprecation framework series, specifically addressing implementation details of how deprecated commands are identified.

Kristoffer Haugsbakk confirms they will implement the suggested approach from Jeff King and Junio Hamano for checking command deprecation status. The change simplifies the deprecation check by using a new flag-based system that examines the `DEPRECATED` bit in the command's flags through `get_builtin()`, rather than the previous name-matching approach.

This patch represents the final technical refinement in the series, resolving an implementation inconsistency that Junio had identified. The change maintains the same behavior but improves code maintainability by centralizing the deprecation check logic. The series as a whole has reached clear consensus and appears ready for integration, with this being one of the last pieces to fall into place.
