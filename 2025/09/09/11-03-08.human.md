This is part 9/15 of Patrick Steinhardt's ongoing refactoring series to move packfile management into a dedicated `packfile_store` structure as part of the ODB abstraction effort.

The patch splits the responsibilities of `reprepare_packed_git()` into two clearer functions: a new `odb_reprepare()` that handles the broader object database refresh (including alternates and loose objects), and `packfile_store_reprepare()` that focuses specifically on packfiles. This better aligns with the series' goal of separating concerns between the object database and packfile management.

The change is mechanical but touches many call sites (13 files modified) since `reprepare_packed_git()` was widely used. The implementation maintains all existing behavior while improving encapsulation - packfile-specific operations now stay within the packfile subsystem. This continues the series' pattern of clean, incremental improvements to Git's object storage architecture.
