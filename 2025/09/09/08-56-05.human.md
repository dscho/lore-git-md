This is patch 2/17 in a refactoring series preparing xdiff internals for Rust compatibility. The patch simplifies memory management in `xdl_prepare_ctx()` by eliminating redundant local variables and directly using the `xdfile_t` struct fields throughout. The transformation is mechanical but improves maintainability by removing duplicate code path for freeing resources. The patch touches only `xdiff/xprepare.c`, modifying about 80 lines with straightforward variable-to-field conversions. As with patch 1/17, this is a pure refactoring with no behavior changes, continuing the series' incremental cleanup approach.
