Refactoring patch in Patrick Steinhardt's packfile store series (v4 05/15), moving the MRU packfile list from `struct object_database` to `struct packfile_store`. This continues the systematic relocation of packfile-related state to its new logical home.

The patch moves the most-recently-used packfile list (`packed_git_mru`) from `struct object_database` to `struct packfile_store` where it's renamed to simply `mru`. This MRU list helps optimize object access by prioritizing recently used packfiles. The change involves updating all references across 5 files (midx.c, odb.c, odb.h, packfile.c, packfile.h), with straightforward mechanical updates to the initialization, access, and manipulation of the list.

Key technical details:
- Removes `packed_git_mru` from `struct object_database` in odb.h
- Adds `mru` list_head to `struct packfile_store` in packfile.h
- Updates all callers to reference the list through `packfiles->mru` instead of the old path
- Maintains identical behavior while cleaning up the ODB interface
- Follows same pattern as previous patches in the series

The change is part of the larger effort to abstract packfile storage details from the core object database, enabling future pluggable backends. Like other patches in this series, it's a mechanical move with no functional changes, maintaining backward compatibility while improving the architectural separation.
