This is the third patch in a series refactoring the string-list API to eliminate sign comparison warnings. The patch changes the return type of `string_list_find_insert_index()` from `int` to `size_t`, completing the transition started in earlier patches to use unsigned types consistently.

The change is straightforward since the function is just a wrapper around `get_entry_index()`, which already returns a `size_t`. The patch updates all callers to use `size_t` variables, with the most notable fix being in `mailmap.c` where the loop condition is adjusted to properly handle `size_t` underflow. The patch also removes the now-unneeded `DISABLE_SIGN_COMPARE_WARNINGS` from `mailmap.c`.

This continues the series' clean progression toward eliminating signed/unsigned comparison warnings while maintaining the same behavior. The changes are mechanical but thorough, touching all callers across several files. With this change in place, the final patch in the series can now enable sign comparison warnings for refs.
