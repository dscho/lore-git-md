This is part 13 of a 17-patch series refactoring xdiff internals for Rust compatibility. The patch changes the `size` field in `xrecord_t` from `long` to `usize` to better align with Rust's type system, following the pattern established in previous patches.

The change is mechanical but widespread, requiring updates to string handling functions across xdiff's core files (xdiffi.c, xemit.c, xmerge.c, xprepare.c). Where needed, explicit casts to `long` are added at string function boundaries to maintain compatibility with existing interfaces. The patch continues the series' approach of making type system changes while preserving runtime behavior.

This follows logically from patch 12's change of `ptr` to `u8*`, as size and pointer types often need to align. The modifications are straightforward but touch several performance-sensitive diff operations. The series continues to build foundations for potential Rust integration while keeping changes incremental and reviewable.
