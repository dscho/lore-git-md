Refactoring patch in the xdiff internals series for Rust compatibility. This is patch 2/17 in Ezekiel Newren's series to prepare xdiff for potential Rust integration.

The patch simplifies memory management in xdl_prepare_ctx() by eliminating intermediate local variables and working directly with the xdfile_t structure fields. This removes redundant assignments and cleanup code while maintaining the same functionality. The changes include:

1. Removing temporary variables that were previously used to hold allocated memory before assigning to xdfile_t
2. Moving the xdl_free_ctx() function definition earlier in the file to be available for use in the error handling path
3. Simplifying the error handling to use xdl_free_ctx() consistently

The changes are mechanical and don't affect behavior, but make the code more straightforward by reducing indirection. This appears to be a well-justified cleanup that fits with the series' goal of making the codebase more maintainable and Rust-friendly. The patch follows logically after patch 1's reordering of functions and continues the pattern of non-controversial preparatory changes.
