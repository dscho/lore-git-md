This is the final patch in a 17-part refactoring series preparing xdiff internals for Rust compatibility. The patch changes several field types in the `xdfile_t` structure to better align with Rust's type system while maintaining the same behavior:

1. `dstart` and `dend` (line position markers) are changed from `long` to `i32`
2. `rchg` (changed line markers) becomes `u8*` instead of `char*`
3. `rindex` (record indices) switches from `long*` to `usize*`

The changes follow the series' pattern of mechanical type adjustments to make the code more Rust-friendly without altering functionality. This completes the type system groundwork started in earlier patches, though the commit message is notably brief compared to others in the series.

As with previous patches, this appears to be a straightforward technical change focused on type alignment rather than introducing new behavior. The series as a whole has maintained a clear focus on preparatory refactoring for potential future integration work, though there hasn't been public discussion or review of the changes yet.
