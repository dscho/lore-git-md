This is part 15 of a 17-patch series refactoring xdiff internals for Rust compatibility. The patch changes the type of `xdfile_t.nrec` from `long` to `usize`, affecting how line counts are stored in the diff algorithm's internal structures.

The change requires numerous casts in xdiff implementation files (xdiffi.c, xemit.c, xmerge.c, xprepare.c) where `nrec` is compared with or assigned to `long` variables. The modifications are mechanical but touch core diff operations like split measurement, context calculation, and merge handling. 

This continues the series' pattern of making xdiff's types more compatible with Rust's stricter type system, where `usize` is the natural type for array indices and sizes. The patch maintains identical runtime behavior while preparing for potential future integration with Rust code. 

As with previous patches in the series, this is a preparatory change that doesn't introduce Rust code but makes the C codebase more amenable to Rust interop. The change appears well-contained and follows the established pattern of the series, though it does require numerous casts that could be reviewed for correctness.
