Refactoring patch in the xdiff Rust compatibility series. This is patch 4/17 in a larger effort to prepare xdiff internals for potential Rust integration by cleaning up the C codebase.

The patch removes `xdl_get_rec()`, a helper function that was just aliasing fields of the `xrecord_t` structure. The author notes this indirection made it harder to track field usage. The change inlines direct access to `xdf->recs[ri]->ptr` and `->size` in four call sites, simplifying the control flow. The diff shows 25 lines removed versus 13 added, with no functional changes - just clearer direct field access.

This continues the series' pattern of incremental, non-controversial cleanups that maintain existing behavior while making the code more straightforward. The changes touch only xdiff/xemit.c, focusing on diff output generation logic. Like earlier patches, this appears to be a safe simplification that removes unnecessary indirection without introducing new complexity.
