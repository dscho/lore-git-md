This is a follow-up in the ongoing Rust infrastructure discussion, specifically addressing Junio Hamano's question about existing Rust libraries in contrib/. Patrick Steinhardt clarifies that neither contrib/libgit-sys nor contrib/libgit-rs are currently integrated with meson, citing their limited functionality and inactive development status. He suggests these libraries could potentially be reevaluated and possibly moved into core Rust code once official Rust support is established in Git.

The response indicates Patrick's vision for a more integrated approach where core Rust components could be directly consumed as crates, rather than maintaining separate contrib/ implementations. This aligns with the broader RFC's goal of bringing Rust into Git's core while hinting at potential future cleanup of the contrib/ space. The tone remains exploratory, consistent with the RFC status of the overall effort, while showing willingness to reconsider existing Rust components as part of the transition.
