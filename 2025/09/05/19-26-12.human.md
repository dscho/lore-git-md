Bugfix and cleanup series for midx-write segfault and related issues.

This is version 3 of a series that fixes a segfault in multi-pack-index operations that has been present since Git 2.47.0. The crash occurs during background maintenance operations like `git multi-pack-index repack` and `git multi-pack-index expire`. The first patch contains the actual fix, which involves properly initializing packs and includes a stress test that reproduces the issue with 100 packfiles under SANITIZE=address.

The remaining patches perform various cleanups in midx-write.c:
- Standardizing error handling patterns
- Converting signed/unsigned comparisons
- Using proper types for pack indices
- Removing deprecated warning suppression macros

The series has been through multiple rounds of review with Patrick Steinhardt and Junio Hamano, with all major technical concerns addressed. Changes in v3 include using `test_grep` instead of raw `grep` in tests, translating an error message, and clarifying a commit message. The patches show careful attention to detail and the discussion indicates they're ready for merging.
