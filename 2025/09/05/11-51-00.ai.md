This is a test implementation patch in the Rust infrastructure series, specifically converting the varint subsystem from C to Rust as a proof-of-concept. The patch demonstrates how Rust code can be integrated into Git's build system while maintaining compatibility with existing C code.

The patch replaces `varint.c` with `varint.rs` when Rust support is enabled, implementing the same functionality for encoding/decoding variable-length integers. The Rust implementation provides identical C ABI-compatible functions (`decode_varint` and `encode_varint`) using `#[no_mangle]` extern declarations. The code includes comprehensive tests that verify the same behavior as the C version.

Key technical aspects:
- Build system integration through both Makefile (conditional compilation of `varint.o`) and meson (adding `varint.rs` to sources)
- C ABI compatibility maintained through unsafe extern functions
- 92-line Rust implementation with test coverage
- Demonstrates Rust's module system for organizing code (`pub mod varint`)
- Shows how to handle pointer operations and C types in Rust (`c_int`, `c_uchar`)

The varint subsystem was chosen as it's self-contained and non-critical, making it a safe test case. The patch serves as a concrete example of the Rust integration approach proposed in the larger series, showing how components can be incrementally converted while maintaining build system support across both meson and Makefile.
