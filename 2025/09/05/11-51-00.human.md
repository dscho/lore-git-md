This is a Rust infrastructure test patch as part of Patrick Steinhardt's ongoing series to introduce Rust support to Git core. The patch demonstrates the Rust build infrastructure by converting Git's varint.c subsystem (used for variable-length integer encoding) to Rust, serving as a "test balloon" for the new build system.

The implementation replaces varint.c with a Rust version (src/varint.rs) when Rust support is enabled, maintaining the same C ABI interface through `#[no_mangle]` extern functions. The 92-line Rust implementation includes both decode_varint and encode_varint functions with matching behavior to the C version, plus Rust-native unit tests. Build system changes in both Makefile and meson ensure the correct file (C or Rust) is compiled based on Rust availability.

This serves as a practical demonstration of the Rust infrastructure's ability to integrate with Git's existing codebase while maintaining compatibility. The choice of varint.c for this test makes sense - it's a self-contained subsystem with no dependencies, making it an ideal first target. The patch appears well-crafted with thorough test coverage and clean build system changes, though being part of an RFC series, it's still in the experimental/proposal stage rather than production-ready code.
