This thread discusses a bugfix and performance improvement for the recently introduced `git last-modified` command. The issue occurs when processing criss-cross merges, causing the command to hit a BUG() due to an incorrect recursive flag setting in the underlying `diff_tree_combined()` function.

The root cause was traced to `diff_tree_combined()` unconditionally forcing recursive mode since 2006, which interfered with `last-modified`'s path tracking. The solution, now in its second version, removes this hardcoded behavior and moves the recursive flag setting to the specific callers that need it (`diff-tree -c` and submodule handling), while letting other commands control their own recursion.

The fix not only resolves the criss-cross merge case but also provides a significant performance benefit - benchmarks show `git last-modified` running nearly twice as fast on the git.git repository. The patch includes a new test verifying correct behavior with criss-cross merges and subdirectories, while maintaining backward compatibility for existing `diff-tree -c` usage.
