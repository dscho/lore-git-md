Bugfix for `git last-modified` involving recursive diff behavior. This patch addresses an issue where the new `git last-modified` command would hit a BUG() when processing merge commits, particularly with criss-cross merges. The root cause was an unconditional override of the recursive flag in `diff_tree_combined()` that has existed since 2006.

The fix removes this override and moves the recursive flag setting to the callers that actually need it - specifically `builtin/diff-tree.c` (for backward compatibility) and `submodule.c`. This not only fixes the bug but also provides a significant performance improvement, with `git last-modified` running nearly twice as fast on git.git.

The patch includes a new test case that reproduces the criss-cross merge scenario that previously triggered the bug. This is version 2 of the patch, which makes a smaller behavioral impact by preserving the recursive behavior for `git diff-tree -c` while still fixing the `last-modified` issue.
