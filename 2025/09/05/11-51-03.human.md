This is part of the ongoing Rust infrastructure series, specifically focusing on CI testing refinements. As the 7th patch in version 2 of the RFC series, it enables Rust toolchain installation and build configuration for the breaking-changes CI jobs.

The patch makes two straightforward changes: it adds `rustc` and `cargo` to the package installation lists for Fedora/AlmaLinux and Ubuntu/Debian CI environments, and ensures the breaking-changes jobs set both `WITH_RUST=YesPlease` and `-Drust=enabled` flags when building with meson. This ensures the CI system will test the Rust integration in the same configuration that will eventually become mandatory according to the transition plan documented earlier in the series.

The changes are minimal and focused, directly supporting the series' goal of comprehensive Rust testing. Since this builds on the extensive groundwork laid in previous patches (build system integration, varint conversion example, and transition documentation), the patch appears well-justified and low-risk. It demonstrates the practical application of the infrastructure being proposed, specifically verifying that Rust-enabled builds work in CI - an important step toward the eventual mandatory Rust support.
