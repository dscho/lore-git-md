This is the maintainer's approval of a bugfix patch for upload-pack's protocol v2 ACK behavior. Junio C Hamano is queuing Patrick Steinhardt's v2 patch that prevents duplicate ACKs for non-commit objects while maintaining special handling for commit parents.

The patch modifies `do_got_oid()` in upload-pack.c to apply the same deduplication logic to all object types, not just commits. While the first version was likely correct, the author took a more conservative approach in v2 by always marking commit parents as `THEY_HAVE` before processing them. This ensures we don't miss any parent commits that might arrive out of chronological order.

Junio confirms the technical approach makes sense - we now uniformly prevent duplicate additions to the `have_obj` array while still specially processing commit parents (without adding them to the array). The change maintains the protocol v2 optimization that was the goal of the series while being more robust about edge cases. With this approval, the patch will be included in the next integration cycle.
