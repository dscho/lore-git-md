This is part of Patrick Steinhardt's ongoing RFC series introducing Rust infrastructure to Git core, specifically focusing on CI testing for the Rust transition. The patch repurposes the obsolete "pedantic" CI job (which was doing redundant builds) into a new Fedora-based job that tests the Meson build system with breaking changes enabled.

The change accomplishes three main goals: it adds Fedora to the distros being tested, verifies breaking changes work with Meson, and prepares for future Rust testing (which will be added in a follow-up patch). The implementation modifies CI configuration files across GitHub Actions and GitLab CI, updates dependency installation for Fedora to include Meson/Ninja, and adjusts the test runner script to handle the new job type.
