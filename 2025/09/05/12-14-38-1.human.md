This is a build system patch that changes how Git version strings are formatted in snapshot builds. Currently, Git replaces hyphens with dots (e.g., "2.51.0.178.g2462961280"), which breaks SemVer compliance and causes issues with tools like b4. The patch simply removes this substitution, keeping the standard git-describe output format ("2.51.0-178-g2462961280") with just the leading 'v' stripped.

The change is minimal (a one-line deletion in GIT-VERSION-GEN) and well-motivated by compatibility concerns. It reverts part of a 2006 change that was originally made for RPM packaging. The patch appears straightforward and low-risk, though it might be worth checking if any other tooling depends on the current dotted format before merging.
