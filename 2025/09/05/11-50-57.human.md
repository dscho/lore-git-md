This is the foundational patch in Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core, now at version 2. The patch adds meson build system support for compiling an internal Rust library (`libgit_rs`) alongside Git's existing C code, marking the first concrete step in the proposed Rust integration.

The implementation makes Rust compilation optional (controllable via `-Drust=` meson option) and auto-detects Rust toolchain availability. It includes basic infrastructure for Rust unit testing, though with some platform limitations (tests disabled on macOS due to meson module issues). The patch also introduces a `WITH_RUST` preprocessor define to track Rust availability in the C code.

This is clearly an experimental first step - the empty `lib.rs` shows this is about proving the build system integration works rather than delivering Rust functionality yet. The commit message positions this as a "test balloon" for both developers and distributors, with the long-term goal of making Rust mandatory in Git 3.0. The technical implementation looks clean and focused, though the macOS test limitation may need addressing before wider adoption.
