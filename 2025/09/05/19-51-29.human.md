This is a brief positive review of a patch in the Rust infrastructure series. The patch adds Rust build status reporting to `git --version` output, showing whether Rust support was compiled in. Brian m. carlson approves the change, calling it "a great idea and likely to be super helpful."

The change is straightforward - it adds conditional output to the version information display in `help.c` that reports "rust: enabled" or "rust: disabled" based on the `WITH_RUST` compile-time flag. This provides immediate visibility into whether a given Git build includes Rust support, which will be useful for both developers and users during the transition period.

As part of the larger Rust infrastructure effort, this is a small but practical quality-of-life improvement that helps with debugging and compatibility checking. The positive reception from Brian m. carlson, who has been actively involved in the technical discussions around Rust integration, suggests this is uncontroversial and likely to be accepted.
