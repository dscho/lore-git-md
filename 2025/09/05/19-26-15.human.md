Bugfix patch improving error handling in midx-write operations. This is part 3 of a 6-patch series addressing a segfault in multi-pack-index operations introduced in Git 2.47.0.

The patch focuses on fixing error handling in the incremental midx write path, where several direct `return -1` statements are replaced with proper cleanup paths using `goto cleanup`. This ensures proper resource cleanup when failures occur during temporary file creation, permission adjustments, chain file operations, and midx-to-chain linking.

The changes follow a pattern recommended by reviewer Patrick Steinhardt, where errors are both reported via `error()` and properly captured in the `result` variable before jumping to cleanup. While the error conditions are difficult to reproduce in tests (as noted in the commit message), the changes make the code more robust against memory leaks in error scenarios.

This patch is part of a well-reviewed series that has reached maintainer consensus, with all critical issues confirmed fixed through testing. The changes align with the series' goal of making midx-write operations more reliable, particularly for background maintenance operations where these errors were originally reported.
