This is part of the Rust infrastructure RFC series (v2 3/7), focusing on build reporting. The patch adds Rust build status visibility by exposing whether Git was compiled with Rust support in both `git version --build-options` and `git bugreport` output. This helps diagnose potential Rust-specific issues during the transitional period where Rust remains optional.

The change is straightforward - it adds conditional output to `help.c` based on the `WITH_RUST` preprocessor define. The commit message clearly explains the motivation: since some subsystems will have both C and Rust implementations during the transition period, having this build information will help identify Rust-specific issues.

This is a small but thoughtful addition to the larger Rust integration effort, showing attention to debugging needs during the transition. The implementation is clean and matches Git's existing build reporting patterns. As part of a larger RFC series, it demonstrates incremental progress on making Rust support observable and debuggable.
