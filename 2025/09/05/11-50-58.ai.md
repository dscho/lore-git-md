This is part of the ongoing Rust infrastructure series, specifically adding Makefile support to complement the meson build system introduced in the previous patch. The patch establishes parallel Rust build capabilities in the traditional Makefile-based workflow, maintaining feature parity with the meson implementation.

Key technical additions include:
- New `WITH_RUST` build toggle matching meson's configuration
- Cargo project definition via new `Cargo.toml` with staticlib output
- Makefile rules for Rust library building (`rust` target)
- Debug/release build differentiation
- Clean target integration for Rust artifacts
- Preprocessor define (`WITH_RUST`) for conditional compilation
- Quiet build support matching Git's build verbosity conventions

The implementation shows careful attention to build system integration details:
- Rust library gets linked alongside existing C libraries in `GITLIBS`
- Build output handling preserves Git's quiet/verbose build modes
- Clean target removes all build artifacts including Cargo.lock
- Conditional compilation via `BASIC_CFLAGS` addition

This represents a significant step in the RFC's progression by ensuring the Rust infrastructure works across both modern (meson) and traditional (Makefile) build systems. The patch maintains the experimental nature of the effort while providing a complete build path for testing and evaluation.
