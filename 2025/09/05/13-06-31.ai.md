Bugfix for `git last-modified` with performance improvement. This patch addresses an issue where the recently introduced `git last-modified` command would hit a BUG() when processing criss-cross merges due to the recursive flag being incorrectly forced in `diff_tree_combined()`. 

The problem stems from `diff_tree_combined()` unconditionally setting `diffopt.flags.recursive=1` since its introduction in 2006, which interferes with `git last-modified`'s path tracking. The fix removes this override and moves the recursive flag setting to callers that actually need it (`diff-tree -c` and submodule handling), while letting other callers (like `last-modified`) control their own recursion.

The change not only fixes the BUG() but also provides a significant performance boost - benchmarks show `git last-modified` running nearly 2x faster on git.git. The patch includes a new test case that verifies correct behavior with criss-cross merges and subdirectories. This is v2 of the patch, which maintains backward compatibility for `diff-tree -c` while fixing the `last-modified` issue.
