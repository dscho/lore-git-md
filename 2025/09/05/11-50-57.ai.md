This is the foundational patch in Patrick Steinhardt's RFC series introducing Rust infrastructure to Git core, now at version 2. It establishes the meson build system integration for compiling Rust code as an optional component, with the long-term goal of making Rust mandatory in Git 3.0.

The patch adds meson infrastructure to build a static Rust library (`libgit_rs`) alongside Git's C code, controlled by a new `-Drust=` option that defaults to auto-detection. It includes basic test wiring using meson's Rust module (though disabled on macOS due to compatibility issues) and adds Rust availability to the build summary output. The implementation demonstrates Rust/C interop through a minimal `lib.rs` placeholder that will later contain actual functionality.

Key technical details include the `WITH_RUST` preprocessor define for conditional compilation, meson version 1.0+ requirement for test support, and the `rust_crate_type: 'staticlib'` configuration ensuring C-compatible linkage. The patch maintains optional status for now, positioning Rust components as experimental "test balloons" for non-critical features or alternative implementations.

This initial infrastructure patch is carefully scoped to avoid disrupting existing builds while laying groundwork for future expansion. The approach shows consideration for both developer experience (auto-detection, test integration) and distribution concerns (optional inclusion). The meson focus in this version contrasts with later additions of Makefile support seen in the thread context.
