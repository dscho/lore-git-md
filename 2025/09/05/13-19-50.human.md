This is a platform compatibility bugfix for HP-UX systems. Michael Osipov reports that Git 2.51.0 fails to build on HP-UX 11.31 due to missing `mkdtemp()` functionality in the unit test framework. While the configure script correctly detects the missing function and sets `NO_MKDTEMP`, the test framework doesn't properly include the Git compatibility implementation.

The issue manifests as a linker error when building unit tests, as the test code calls `mkdtemp()` but doesn't link against Git's `gitmkdtemp()` compatibility function. Osipov provides a minimal patch that adds the necessary compat object to the test program's dependencies. He confirms the fix works on his system, though some macro redefinition warnings remain from other headers.

The patch appears straightforward and well-motivated, addressing a clear build failure on an uncommon but supported platform. The remaining warnings about macro redefinitions appear to be pre-existing issues not introduced by this change. This seems like a reasonable fix to support HP-UX builds, though reviewers may want to consider whether there's a more elegant way to handle the test framework's dependency on platform-specific compatibility code.
