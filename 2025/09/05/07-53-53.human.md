This is a follow-up in the ongoing Rust infrastructure discussion, specifically addressing Junio Hamano's question about how existing contrib/libgit-{sys,rs} Rust libraries are currently handled in the build system.

Patrick Steinhardt clarifies that these contrib libraries aren't currently integrated into the meson build system, explaining they have limited functionality and aren't actively developed. He suggests these could be reevaluated once Rust support is officially added to core Git, potentially moving them out of contrib/ and into the main codebase to be exposed as proper crates.

The response maintains the experimental nature of the current proposal while showing openness to future integration possibilities. It doesn't introduce new technical details but helps clarify the relationship between the proposed core Rust support and existing Rust-related code in the repository. The tone remains collaborative, positioning this as part of an ongoing design discussion rather than a finalized approach.
