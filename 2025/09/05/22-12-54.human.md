Platform compatibility follow-up regarding HP-UX test builds. Michael Osipov confirms Jeff King's suspicion that explicitly adding $(COMPAT_OBJS) to the test program link line is unnecessary - the gitmkdtemp() implementation from libgit.a is properly linked without it. This leaves just the first part of the original patch, which adds compat/posix.h inclusion to clar/sandbox.h to provide the mkdtemp prototype.

The discussion reveals that while the initial approach worked, it was solving the problem at the wrong layer - the real fix is ensuring the compatibility header is included during compilation rather than forcing additional linking. This keeps the solution focused on Git's compatibility layer rather than modifying build system behavior. The thread remains open for Patrick Steinhardt's input on whether the clar framework should handle this portability itself.
