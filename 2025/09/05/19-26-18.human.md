This is the final patch in a bugfix and cleanup series addressing midx-write error handling. The series fixes a segfault in multi-pack-index operations introduced in Git 2.47.0 and standardizes error handling patterns across the subsystem.

Patch 6/6 simplifies error case management in `write_midx_internal()` by initializing the result to -1 (error) by default and only setting it to 0 (success) in the success paths. This makes the error handling more consistent and removes redundant error code assignments before goto statements. The changes ensure the function always returns -1 on error rather than sometimes returning 1 or -1 inconsistently.

The patch is part of a well-reviewed series that has reached maintainer consensus, with all critical issues confirmed fixed through testing. It follows earlier patches that addressed the core segfault bug, restored dropped error codes, improved incremental midx write error handling, and made various code quality improvements. This final patch completes the error handling standardization effort.
