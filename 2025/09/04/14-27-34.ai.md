This is a refactoring patch as part of both the `the_repository` removal effort and Patrick Steinhardt's larger `git-history` command series. The patch modifies `sequencer_remove_state()` to accept a `struct repository` parameter instead of relying on the global `the_repository`, though it continues passing `the_repository` at all call sites for now.

The changes are mechanical - the function signature and all 10 call sites are updated to pass the repository parameter. The implementation now uses the passed repository when deleting refs via `get_main_ref_store()`. The commit message notes this is a limited step toward removing `the_repository` usage, with more sequencer refactoring left for future work.

This patch appears straightforward and well-contained, though it doesn't yet fully eliminate `the_repository` usage since callers still pass it. It's part of the preparatory work for the history editing functionality, ensuring the sequencer infrastructure can operate on arbitrary repositories. The changes are consistent with Git's ongoing effort to remove global state.
