This is a performance investigation update in the ongoing thread about self-compiled Git slowdowns on corporate macOS machines. Ben Knoble reports that after fixing inconsistent CFLAGS application (some files getting -Oz while others defaulted to -O2), the binary size discrepancy improved but the performance gap remained. The key new finding is that the slowdown only manifests on corporate-managed machines, strongly pointing to security tooling (binary sniffers) as the root cause rather than build configuration. The DEVELOPER=1 flag's impact remains unclear in this context. Knoble plans to test installing to Homebrew paths to further isolate whether the security tools are path-sensitive or using binary fingerprinting. The thread has effectively ruled out build optimizations as the primary factor, shifting focus to environmental interference from corporate security measures. The binary size difference (now 3.5MB vs 4.4MB) persists but appears unrelated to the performance issue.
