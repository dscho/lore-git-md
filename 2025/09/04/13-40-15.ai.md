This is a v4 resubmission of a feature patch series for `git repo info`, addressing two minor code style issues from the v3 version that had already received mentor sign-offs and Junio's approval on the technical approach.

The series maintains the same two independent improvements to `git repo info`:
1. Adding a `-z` flag as shorthand for `--format=nul`, now properly implemented using `OPT_CALLBACK_F` with shared `parse_format_cb()` after Junio's feedback in earlier rounds
2. Adding an `objects.format` field exposing the repository's object format via `repo->hash_algo->name`

The v4 changes are purely stylistic:
- Adding a line break before opening brace in `parse_format_cb()`
- Adding spaces around a `|` operator in the option flags for the `-z` callback

The core implementation remains unchanged from v3, including:
- The "last one wins" semantics for format options
- Exact equivalence between `-z` and `--format=nul` behavior
- Stable object format field implementation via `get_object_format()`
- Tests covering both SHA-1 and SHA-256 cases
- Documentation updates following existing patterns

The patches remain cleanly separated with no interdependencies. The series builds on the merged `lo/repo-info` work and maintains `master` as its base branch. With the technical approach already approved and only minor formatting tweaks in this version, this appears ready for final review and potential merging.
