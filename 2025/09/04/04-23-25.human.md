Maintainer review of protocol v2 ACK deduplication fix. Junio C Hamano acknowledges the core fix makes sense - moving the `THEY_HAVE` flag check outside commit-specific logic to prevent duplicate ACKs and memory growth in upload-pack's `have_obj` array. However, he raises a subtle concern about parent commit handling: the original code would mark parents with `THEY_HAVE` even when seeing a commit for the second time, while the new version only marks parents on first encounter. This could affect how parent commits are processed in subsequent protocol steps, though the impact isn't immediately clear. The review suggests the change might not be fully equivalent to the original behavior, particularly around parent commit propagation of the `THEY_HAVE` flag. This appears to be the only open question remaining in the otherwise-approved series.
