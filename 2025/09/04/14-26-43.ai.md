This is the first patch in a series introducing Rust infrastructure to Git core, focusing on build system support for meson. The patch adds meson configuration to optionally build a Rust static library (`libgit_rs`) when Rust toolchain is detected (requires meson >=1.9.0). The implementation includes:

- A new `rust` meson option (default 'auto') to control Rust compilation
- Basic Rust test harness integration with `meson test`
- Empty `lib.rs` placeholder that will be populated in subsequent patches
- Build summary reporting Rust availability

The patch establishes the technical foundation while explicitly marking this as experimental ("test balloon") for now, with plans to make Rust mandatory in Git 3.0. The implementation is currently meson-only, leaving Makefile support for future work. The changes are backward-compatible since Rust remains optional at this stage, though the series' cover letter indicates this will become a breaking change in the future.
