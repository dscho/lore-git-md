This is a v4 resubmission of a feature patch series for `git repo info`, addressing minor code style issues from the previous version. The series comes from GSoC contributor Lucas Seiki Oshiro and has mentor sign-offs from Karthik Nayak and Patrick Steinhardt.

The two-patch series introduces two independent improvements to `git repo info`:
1. Adds a `-z` flag as shorthand for `--format=nul` (redesigned in v3 per Junio's feedback to use `OPT_CALLBACK_F`)
2. Adds an object format field exposing the repository's object format via `get_object_format()`

The v4 changes are purely stylistic - fixing line breaks before opening braces and adding spaces around a `|` operator in the option parsing code. The core functionality remains unchanged from v3, which was already considered technically merge-ready with thorough test coverage for both SHA-1 and SHA-256 cases.

The thread shows consensus on the implementation approach, with Junio having confirmed the acceptability of the current `-z` flag design and `object.format` naming. The patches maintain clean separation between the two features and build on the existing `git repo info` infrastructure. This appears to be a well-polished submission addressing all previous feedback.
