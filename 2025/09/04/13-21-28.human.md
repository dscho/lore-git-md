This is the second version of a 4-patch series implementing a breaking change to switch Git's default initial branch name from "master" to "main" when built with WITH_BREAKING_CHANGES enabled. The series follows up on a 2020 deprecation warning and aligns Git with the industry practice adopted by major Git forges.

The first patch is the main change, switching the default branch name to "main" when WITH_BREAKING_CHANGES is enabled. It updates documentation in BreakingChanges.adoc and git-init.adoc, modifies the advice system, and adds tests. The remaining three patches clean up test scripts that still hardcode "master" as the default branch name, removing the last instances of GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=master from the test suite.

Phillip Wood has incorporated feedback from the first version, keeping GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME (as suggested by reviewers) while still removing the hardcoded "master" references. The patches are well-structured with clear commit messages explaining the changes. The test updates are mechanical but thorough, with 107 files modified across the series.

The change is carefully gated behind a compile-time flag to maintain backward compatibility, and the implementation appears solid. This represents the culmination of a multi-year effort to modernize Git's default branch naming, with all major technical questions now addressed except for one remaining discussion about reftable backend requirements.
