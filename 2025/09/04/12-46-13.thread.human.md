This thread investigates a reported issue where environment variables and `-c` config options weren't being passed to the prepare-commit-msg hook during `git rebase --continue` operations, despite working correctly for regular commits. The original report provided clear reproduction steps showing the discrepancy in Git 2.51.0+.

Jeff King (Peff) has now responded with a test case that successfully demonstrates the expected behavior - in his environment, both the `$FOO` environment variable and `hooks.foobar` config setting are properly propagated to the hook during rebase continuation. His results contradict the original report, suggesting the issue might be environment-specific rather than a universal bug. Jeff has invited the original reporter to compare setups, as the difference could stem from either environmental factors or testing methodology. While this doesn't resolve the original concern, it provides a verified working example that others can reference and potentially adapt as a workaround. The thread remains open for further investigation into why some users might experience the reported behavior while others don't.
