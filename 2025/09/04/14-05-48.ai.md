Performance investigation update on macOS Git compilation differences. D. Ben Knoble follows up on the earlier thread about self-compiled Git being slower than Homebrew's version, reporting new findings from testing with `CFLAGS=-Oz`. The optimization flag appears to be inconsistently applied during the compilation process, with some files getting `-Oz` while others default to `-O2`. More significantly, the performance gap disappears on a non-corporate machine, suggesting the slowdown may be related to corporate security tooling (binary sniffers) rather than compilation settings. This shifts the focus from build configuration to potential runtime interference by corporate security software. The DEVELOPER=1 flag remains in use but its impact is now less clearly the culprit. The binary size discrepancy (3.5MB vs 4.4MB) noted earlier remains unexplained but may be less relevant given the new evidence.
