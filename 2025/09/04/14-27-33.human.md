This is a preparatory patch in Patrick Steinhardt's RFC series introducing the new `git-history` command. It adds infrastructure to the sequencer to support a new `REPLAY_HISTORY_EDIT` mode that will be used by the upcoming history editing operations.

The patch introduces parallel handling for history editing operations alongside existing cherry-pick and revert functionality. Key changes include:
- Adding the new `REPLAY_HISTORY_EDIT` enum value and associated advice messages
- Creating a new `HISTORY_EDIT_HEAD` ref to track in-progress operations
- Modifying various sequencer operations to handle the new mode consistently
- Adding helper functions to map between action types and commands

The changes are thorough and maintain consistency with existing sequencer behavior while adding the new mode. The patch appears well-structured and focused on its goal of preparing the sequencer infrastructure without yet implementing any user-facing functionality. As part of a larger series, this provides necessary groundwork for the history editing commands to come.
