This is the first of two feature patches in v4 of Lucas Seiki Oshiro's GSoC contribution, adding a `-z` flag as shorthand for `--format=nul` in `git repo info`. The implementation follows the same callback-based approach as v3, now with minor style adjustments (line break before opening brace in `parse_format_cb()` and spacing around `|` operator in callback flags).

The patch maintains consistency with other Git commands like `git-config` and `git-status` that use `-z` for null-terminated output. The implementation uses `OPT_CALLBACK_F` to share parsing logic between `-z` and `--format=nul`, with "last one wins" semantics when multiple format options are specified. Tests verify both the basic functionality and the precedence behavior.

The changes are minimal from v3 - just style tweaks to the already-reviewed implementation. Both mentors (Karthik Nayak and Patrick Steinhardt) have signed off on the technical approach in v3, and Junio C Hamano has confirmed the acceptability of the design. The patch remains cleanly separated from the second patch in the series (object format field addition).

Key technical details unchanged from v3:

- Documentation updated to show new `-z` option
- Tests cover basic usage and format precedence
- Follows existing patterns from other commands with null-terminated output

The patch appears ready for inclusion, with all prior approvals still valid and only uncontroversial style changes made since v3.
