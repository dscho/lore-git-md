This is a performance investigation update in the ongoing thread about self-compiled Git slowdowns on corporate macOS machines. Ben Knoble reports that after fixing inconsistent CFLAGS usage (some files getting -Oz while others defaulted to -O2), the binary size discrepancy improved but the performance gap remained. The key new finding is that the slowdown only appears on corporate-managed machines, strongly pointing to security tooling (likely binary sniffers) as the root cause rather than build differences. The DEVELOPER=1 flag's impact remains unclear. Ben plans to test installing to Homebrew paths next, though suspects security tools may fingerprint binaries rather than just checking paths. The thread has effectively ruled out build optimizations as the primary factor, shifting focus to environmental interference from corporate security measures.
