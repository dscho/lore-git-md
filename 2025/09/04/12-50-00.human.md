Final patch in a series refactoring commit graph handling for pluggable ODB. This moves the commit graph pointer from `struct object_database` to `struct odb_source`, completing the transition to treating commit graphs as an implementation detail of individual object sources rather than a repository-wide resource.

The change makes commit graphs properly per-source, which is necessary for the upcoming pluggable ODB system where different sources may have different capabilities (some may not support commit graphs at all). The patch updates all commit graph operations to work with source-specific graphs, including loading, closing, and querying. Key changes include moving the `commit_graph` and `commit_graph_attempted` fields to `odb_source`, updating `prepare_commit_graph()` to check all sources, and modifying graph operations to work with source-specific graphs.

This is a well-executed mechanical change that follows the pattern established in earlier patches of the series. It maintains all existing behavior while properly preparing for the ODB abstraction.
