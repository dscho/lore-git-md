Build system patch introducing optional Rust support via meson. This is the first of three RFC patches proposing Rust infrastructure for Git core.

Patrick Steinhardt adds meson build system support for compiling Rust code as a static library, marking the initial step in a broader Rust integration effort. The implementation is currently optional and limited to meson builds (Makefile support is notably absent), with availability auto-detected during setup and controllable via a `-Drust=` toggle. The patch includes basic infrastructure for Rust unit testing through meson's test framework.

The commit message positions this as a "test balloon" phase where Rust will be used for non-critical features or alternative implementations of small subsystems. It explicitly states the eventual goal of making Rust mandatory in Git 3.0, though this first patch keeps it optional. The implementation appears clean and focused, adding about 30 lines of meson configuration while maintaining backward compatibility.

This sets up the technical foundation for the subsequent patches that will demonstrate Rust usage (varint.c rewrite) and document the breaking change policy. The approach seems carefully considered, though the eventual mandatory requirement will likely spark discussion about platform support and build system fragmentation.
