This is the second patch in a two-part feature series enhancing `git repo info`, now at version 4 with purely stylistic refinements. The patch adds an `object.format` field to expose the repository's hash algorithm (SHA-1 or SHA-256), matching the functionality of `git rev-parse --show-object-format` but integrated into the structured output of `git repo info`.

The implementation is straightforward, reading `repo->hash_algo->name` through a new `get_object_format()` helper function. Tests verify correct output for both SHA-1 and SHA-256 repositories. The patch maintains the series' clean separation of concerns and follows Git's established patterns for similar fields like `references.format`.

This v4 iteration includes only minor style tweaks from v3 (line breaks and operator spacing) while preserving the technical implementation that already received mentor sign-offs from Karthik Nayak and Patrick Steinhardt. The change appears well-contained and properly tested, completing one of the two planned enhancements to `git repo info` in this GSoC project.
