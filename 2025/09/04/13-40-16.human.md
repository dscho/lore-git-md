Feature patch adding `-z` shorthand to `git repo info` as part of a GSoC project. This is the first of two patches in v4 of the series, with purely stylistic refinements from v3.

The patch adds a `-z` flag as an alias for `--format=nul` in `git repo info`, matching similar flags in other Git commands like `git-config` and `git-status`. The implementation uses `OPT_CALLBACK_F` for clean option parsing, with "last one wins" semantics when multiple format options are specified. Tests verify both the basic functionality and the format precedence behavior.

This version maintains the same technical approach as v3, with only minor style tweaks (line break before opening brace and operator spacing) in response to review feedback.
