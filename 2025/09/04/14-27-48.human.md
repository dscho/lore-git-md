Feature implementation for the `git-history` command series. This is the final patch (18/18) in Patrick Steinhardt's RFC v3 series, adding the "reword" subcommand to rewrite commit messages while preserving all other commit details. The implementation mirrors the behavior of interactive rebase's "reword" action but as a standalone operation. It handles edge cases like merge commits, dirty worktrees, and empty commit messages, and includes comprehensive tests (202 lines) covering basic rewording, root commits, editor interaction, and hook execution. The patch builds on the series' infrastructure for commit rewriting and sequencer integration, maintaining consistency with the other subcommands (`drop`, `reorder`, `split`).
