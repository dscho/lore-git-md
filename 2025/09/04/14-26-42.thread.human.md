This RFC thread proposes making Rust a mandatory dependency for Git starting with version 3.0 in late 2026, with Git 2.52 serving as an LTS version for platforms needing more transition time. Patrick Steinhardt has sent a series introducing initial Rust infrastructure, including build system support and a proof-of-concept conversion of varint.c to Rust while maintaining C ABI compatibility.

Eric Sunshine has raised concerns about the current implementation's effectiveness as a "test balloon," arguing that making Rust optional (with silent fallback to C) won't properly surface platform compatibility issues. He suggests enabling Rust by default with an opt-out mechanism would better identify problematic platforms before the mandatory transition. The discussion continues to balance forward progress with ecosystem impact, particularly regarding platforms like NonStop that currently lack Rust support. Key open questions remain about build system fragmentation, the maintenance burden of the LTS version, and whether 18 months provides sufficient time for ecosystem adaptation.
