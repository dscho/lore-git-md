This RFC thread continues to discuss the introduction of Rust infrastructure to Git core, now at its fifth iteration with 9 patches. The series has Junio Hamano's ack but remains under active discussion, particularly around build system redesign and platform support implications. Patrick Steinhardt leads the effort, which includes a varint subsystem proof-of-concept, CI modernization, and a phased transition plan (optional in Git 2.52, default in 2.53, mandatory by 3.0).

The latest exchange focuses on governance and timeline concerns. Junio Hamano pushes back against the aggressive 18-month timeline for making Rust mandatory, calling it "hopelessly optimistic" for platforms currently lacking Rust support. He advocates for more gradual adoption, particularly around the hash interoperability features. Brian m. carlson defends the timeline as comparable to the SHA-1/SHA-256 work, suggesting LLVM ports could help unsupported platforms. The discussion also clarifies how Brian's policy document became part of Ezekiel Smith's technical implementation - via branch collaboration - with Junio seeking more visibility into such policy incorporation processes.

Key decisions remain: the varint subsystem will be Git's first mandatory Rust component in 3.0, making Rust a hard requirement. SHA-1/SHA-256 interoperability will require Rust, while single-hash operation won't. The build system is transitioning to a hybrid model with explicit disable instructions (WITH_RUST=NoThanks) during the default-but-not-mandatory phase. Windows support is being redesigned, and Rust 2018 edition was chosen for GCC compatibility.

Open questions persist around niche platform support (particularly m68k alignment issues), final build system architecture, and how to balance technical progress with platform inclusivity. The discussion has surfaced important governance questions about policy decision-making processes in the project, especially when they affect platform requirements. While the technical direction seems set, the timeline may still see adjustments as the community weighs these competing concerns.
