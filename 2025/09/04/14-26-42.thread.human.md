This RFC thread explores introducing Rust infrastructure to Git core, starting with build system support and a proof-of-concept conversion of varint.c. Patrick Steinhardt leads the effort with three initial patches covering meson build integration, the varint implementation, and documentation of the planned breaking change requiring Rust in Git 3.0.

The discussion has evolved into a detailed technical debate between two build system approaches: Patrick's meson-based implementation (now updated to require only meson 0.42.0 after Eli Schwartz's input) versus Ezekiel Newren's proposed Cargo-based alternative. Schwartz, a Gentoo maintainer, provided substantive arguments favoring meson while offering concrete solutions to version requirements. Junio Hamano validated build system compatibility as a legitimate concern, elevating it as a potential blocking issue.

In the latest update, Patrick addresses Junio's question about existing Rust libraries in contrib/, clarifying that neither contrib/libgit-sys nor contrib/libgit-rs are meson-integrated due to their limited scope and inactive status. He suggests these could be reevaluated once core Rust support is established, hinting at future consolidation. The thread remains in exploratory RFC status, with Patrick showing flexibility on implementation details while maintaining the vision of integrated Rust support. Key open questions center on build system choice, platform impacts, and the transition timeline, with notable contributors like Eric Sunshine and brian m. carlson raising important technical and compatibility considerations.
