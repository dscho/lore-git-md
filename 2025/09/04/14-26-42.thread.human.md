This RFC thread explores introducing Rust infrastructure to Git's core, with Patrick Steinhardt leading the technical implementation across multiple versions. The series has evolved from an initial meson-only prototype to comprehensive support for both meson and traditional Makefile builds, while maintaining experimental status. The latest patch adds parallel Makefile support with careful attention to Git's build conventions, including quiet/verbose mode handling and clean target integration.

Key participants include Eric Sunshine (platform feedback), Eli Schwartz (meson details), and brian m. carlson (preprocessor defines), with Randall Becker's concerns about NonStop compatibility still outstanding. The implementation now spans both build systems and includes version reporting, CI testing expansion, and a formal transition plan in BreakingChanges.adoc. While showing solid technical progression with concrete examples like the varint.rs conversion, fundamental questions remain about platform support and long-term maintenance implications, particularly for NonStop and embedded systems. The RFC status allows continued discussion of these concerns while the infrastructure matures.
