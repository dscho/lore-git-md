This is a bugfix patch addressing an issue in the combine-diff machinery that was causing problems for the new `git last-modified` command. The core problem is that `diff_tree_combined()` was unconditionally setting the `recursive` flag, which affected how paths were processed during diff operations.

The patch removes this forced recursion, which:
1. Fixes incorrect output in `diff-tree -c` where subdirectory contents were shown when they shouldn't be
2. Resolves a BUG() in `git last-modified` that occurred with merge commits due to leftover path entries
3. Provides a significant performance improvement (nearly 2x faster) for `git last-modified` on large repos like git.git

The change is well-motivated with test updates showing the corrected behavior and includes a new test case specifically for the `last-modified` subcommand. The author notes this was discovered through actual usage (by Patrick) after the `last-modified` command was merged to 'next'.

The patch is small and focused, touching just the flag setting in combine-diff.c and adding a compensating flag in submodule.c where recursive behavior is actually wanted. The test changes demonstrate the impact clearly, showing both the diff output changes and verifying the `last-modified` fix works.
