This is the final patch in Patrick Steinhardt's series refactoring commit graph handling as part of the pluggable ODB effort. The patch moves the commit graph pointer and related state from `struct object_database` to `struct odb_source`, completing the transition to treating commit graphs as an implementation detail of individual object sources rather than a repository-wide property.

Key technical changes:
- Adds `commit_graph` and `commit_graph_attempted` fields to `struct odb_source`
- Removes these fields from `struct object_database`
- Updates `prepare_commit_graph()` to iterate through object sources looking for graphs
- Modifies `close_commit_graph()` to operate on a single source rather than the entire ODB
- Updates all callers to use the new source-based approach
- Maintains existing behavior while enabling future per-source graph implementations

The patch follows the established pattern of the series by making mechanical but careful changes to function signatures and call sites. It touches the same core files as previous patches (commit-graph.[ch], odb.[ch], packfile.c) with a net diff of +56/-29 lines. The changes are behavior-preserving but enable the pluggable ODB architecture where different sources can have different commit graph implementations (or none at all).

This completes the technical foundation for the series' goal of decoupling commit graphs from direct repository access. The changes are consistent with the incremental, careful refactoring approach seen throughout the series, with each patch building on the last to achieve the architectural transition.
