This is a bugfix patch addressing an issue in the combine-diff machinery that was causing problems for the new `git last-modified` command. The core problem stems from `diff_tree_combined()` forcibly setting the recursive flag in diff options, which has been happening since 2006 without clear justification.

The patch removes this recursive flag setting, which:
1. Changes combine-diff output to properly respect non-recursive requests (showing 'dir' instead of 'dir/sub' when -r isn't specified)
2. Fixes a BUG() in `git last-modified` that occurred when processing merge commits, where leftover paths remained in a hashmap due to unexpected recursive behavior
3. Provides a significant performance improvement (2x faster) for `git last-modified` on git.git
4. Requires explicitly setting recursive=1 in submodule.c which relied on the old behavior

The commit includes test updates showing the new expected diff-tree output patterns and adds a new test case for `git last-modified` with merged subdirectories. The change appears well-researched, with analysis of the original 2006 commit and demonstration of both the bug and fix through concrete examples. The performance impact is measured and substantial.
