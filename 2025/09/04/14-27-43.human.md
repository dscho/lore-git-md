This is a refactoring patch in Patrick Steinhardt's ongoing `git-history` series, specifically focusing on cleaning up the add-patch subsystem's dependencies. The patch removes the remaining dependency of `add-patch.c` on the `add-interactive` subsystem by directly managing interactive configuration within `add_p_state` rather than through `add_i_state`. It introduces a `struct interactive_config` member and updates all references to use this instead of the previous `add_i_state` indirection. The changes are mechanical - no behavior is altered, just internal plumbing.

This continues the code organization work from the previous patch in the series, further separating the interactive add/patch implementations. The changes are thorough and consistent, touching all the relevant color handling, diff settings, and repository access points. While not directly related to the `git-history` command's functionality, this cleanup improves subsystem boundaries and maintainability.

The patch is part of a larger preparatory effort (patches 1-19 in the 27-patch series) that's building infrastructure needed for the actual history editing commands. It demonstrates careful attention to code structure even while developing major new features.
