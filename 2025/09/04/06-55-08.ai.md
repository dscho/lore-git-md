This is a follow-up discussion about the `kh/you-still-use-whatchanged-fix` series, which aims to improve deprecation messaging for the obsolete `git whatchanged` command. The original series (currently marked for merging to 'next') updates warning messages to suggest modern `git log` equivalents and removes outdated documentation claims.

Kristoffer Haugsbakk proposes two potential next steps for the series: either incorporating Jeff King's patch (which adds alias hints to deprecated command warnings) into a v3 revision, or handling it as a separate follow-up series. The key addition would be suggesting users create an alias to shadow the deprecated `whatchanged` command when they see the warning.

The discussion references two external messages: [1] a thread about alias hints in general, and [2] Peff's specific patch implementing this pattern. The proposal appears well-considered, building on existing work to make the deprecation path smoother for users. This would be a logical extension of the series' goal to guide users away from deprecated functionality.
