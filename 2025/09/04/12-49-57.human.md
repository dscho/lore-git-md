Refactoring patch in Patrick Steinhardt's series to move commit graph handling to odb_source. This third patch modifies `prepare_commit_graph()` to return the prepared graph directly rather than having callers access it through `object_database::commit_graph`. The change anticipates the upcoming move of commit graph storage from `object_database` to `odb_source`, where graphs would need to be found by walking the source list. The patch updates all callers to use the returned graph pointer, making the transition to the new storage location transparent. The diff shows careful mechanical conversion of each caller, with no behavior changes - just preparation for the architectural shift coming in later patches. This continues the series' consistent approach of incremental, behavior-preserving changes toward pluggable ODB support.
