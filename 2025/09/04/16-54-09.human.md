Junio Hamano raises concerns about backward compatibility in the combine-diff changes that fix a bug affecting `git last-modified`. The patch removes a longstanding behavior where `diff_tree_combined()` forcibly set the recursive flag, which changes the output format of `git diff-tree -c` to show directory names rather than their contents when run without `-r`. 

Hamano points out this alters behavior that's been in place since 2006, as evidenced by the test case changes where `dir/sub` becomes just `dir` in the output. While not opposed to the change in principle, he suggests the test should be updated to explicitly show the `-r` flag being added to maintain the historical output format, making the behavioral change more transparent.

This email highlights an important consideration for the patch - while the change fixes real issues (including a BUG() in `last-modified` and provides performance benefits), it needs to clearly document the backward-incompatible change to `diff-tree -c` behavior. The discussion now centers on whether to preserve the old output format by requiring explicit `-r` flags or accept the new behavior as an intentional improvement.
