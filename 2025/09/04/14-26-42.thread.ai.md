RFC PATCH series introducing Rust infrastructure to Git core, now at v4 with 9 patches, transitioning Rust from optional to mandatory by Git 3.0. Authored by Patrick Steinhardt, tracking meson implementation (v1), Makefile preparation (v2), Makefile integration (v3), and now varint subsystem conversion with explicit integer widths (v4). Key technical progression includes:

- Build system: Unconditional Cargo usage via wrapper script (cargo-meson.sh) with complete meson and Makefile integration (v4 3/9) including `WITH_RUST` toggle, Rust source tracking, and quiet build output. New v4 4/9 adds Rust build status reporting to `git version --build-options` and `git bugreport` via simple conditional block in `help.c` (6 lines added), mirroring existing feature reporting patterns.
- Type safety: Varint conversion uses explicit Rust types (u8/usize) with matching C integer widths
- Infrastructure: Test wiring added using Rust's native unit testing capabilities, plus new build visibility for transitional debugging
- Timeline: Accelerated rollout removes intermediate `-Dbreaking_changes` step
- CI: Cargo.lock added to .gitignore, CI now installs cargo directly
- Build control: Meson rules auto-enable Rust if cargo is found, controllable via `-Drust=` option
