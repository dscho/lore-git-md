RFC PATCH series introducing Rust infrastructure to Git core, now at v8 with all 9 patches complete. Authored by Patrick Steinhardt with varint subsystem proof-of-concept, CI modernization, and phased transition (optional in 2.52, default in 2.53, mandatory by 3.0 H2 2026). Key technical details in v8:
- Build system infrastructure (patches 1-4): Meson integration with Rust static library support via `libgitcore.a`, Makefile refactoring with Cargo integration, version reporting in `git version --build-options`, and Rust build status reporting
- Varint subsystem standardization and Rust implementation (patches 5-6): Refactored C implementation with explicit `uint64_t`/`uint8_t` types, first Rust code in Git core via `src/varint.rs` with FFI functions using `#[no_mangle]` and `extern "C"`, maintaining bit-for-bit compatibility with C version through comprehensive tests
- Policy documentation (patch 7): Formalized three-phase adoption timeline in `BreakingChanges.adoc` with escape clauses and LTS safety net provisions
- CI modernization (patches 8-9): Obsolete jobs converted to test Meson+breaking changes, Rust toolchain installation added, compilation enabled in breaking-changes jobs via `WITH_RUST=YesPlease`
