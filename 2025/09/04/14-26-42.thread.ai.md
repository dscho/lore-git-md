RFC PATCH series introducing Rust infrastructure to Git core, starting with build system support and varint.c conversion as proof of concept. Authored by Patrick Steinhardt (3 patches):

1. Build system changes (meson only initially) to compile Rust as static lib
2. Rewrite varint.c (92 lines) in Rust with C interop
3. Document future mandatory Rust requirement in BreakingChanges

Key technicals:
- Initial Rust support limited to meson builds
- varint.rs replaces varint.c (isolated, dependency-free subsystem)
- Explicitly breaks platforms lacking Rust toolchain
- Missing: Makefile support, CI jobs, wider adoption path

Open questions/concerns:
- Impact on platforms without Rust (NonStop, some embedded)
- Build system fragmentation (meson vs Makefile)
- Mandatory nature vs opt-in approach
- Future integration strategy (xdiff etc)
