This is the second patch in a two-part feature series enhancing `git repo info`, now at version 4 with purely stylistic refinements. The patch adds an `object.format` field to expose the repository's hash algorithm (SHA-1 or SHA-256) through the `git repo info` command, complementing the existing repository metadata fields.

The implementation reads `repo->hash_algo->name` via a new `get_object_format()` helper function, following the same pattern as other field retrievals in the command. The patch includes tests verifying correct output for both SHA-1 and SHA-256 repositories, and updates the documentation to describe the new field. The change builds on existing infrastructure for repository metadata reporting and maintains consistency with Git's established patterns for such features.

This version (v4) contains only minor style adjustments from v3, which had already received mentor sign-offs from Karthik Nayak and Patrick Steinhardt. The technical implementation remains unchanged from the v3 version that Junio C Hamano found acceptable, though he had raised a broader question about alignment with `extensions.refStorage` that remains open for future discussion. The patch appears well-contained and follows Git's established conventions, with proper test coverage and documentation.
