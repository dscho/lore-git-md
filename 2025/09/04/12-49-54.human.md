This is a refactoring patch series that's part of the ongoing effort to support pluggable object databases. The series moves commit graph tracking from the object database level (`struct object_database`) to the object source level (`struct odb_source`), which better matches the conceptual model since commit graphs are specific to individual object sources.

Patrick Steinhardt explains that this change prepares for future work where some object sources might not use commit graphs at all, storing commit information in different formats instead. The series includes 6 patches that:
1. Remove redundant commit graph checks from blame and revision code
2. Modify commit graph functions to return graphs directly rather than via repository objects
3. Finally moves the commit graph storage to object sources

The changes are mechanical but touch several parts of the codebase, including blame, revision handling, and the commit graph subsystem itself.
