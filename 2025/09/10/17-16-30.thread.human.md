This thread introduces a refactoring patch that simplifies object lookup code across several Git commands by replacing calls to `get_oid_with_context()` with the more focused `repo_get_oid_with_flags()` when the additional context information isn't needed. The change affects `ls-tree`, `rev-parse`, `stash`, and list-objects filter code, removing about 50 lines of boilerplate while adding only 17.

The patch follows a clear pattern: wherever callers were using `get_oid_with_context()` but ignoring its `object_context` output parameter, it switches to the simpler API that only handles the needed flags. This eliminates unnecessary variable declarations and cleanup calls while maintaining identical behavior. The changes are mechanical but well-scoped, touching five files consistently.

This appears to be a straightforward cleanup that aligns with Git's ongoing effort to simplify object lookup paths and move toward repository-aware APIs. The patch doesn't introduce new functionality but reduces code complexity in a maintainable way.
