Refactoring patch as part of a series introducing signature handling to `git fast-import`. This first patch moves the `enum sign_mode` definition and parsing logic from `builtin/fast-export.c` to `gpg-interface.{c,h}` to make it reusable.

The change is straightforward - it extracts the existing signature mode handling code that was previously only used by `git fast-export` and makes it available as a general utility in the GPG interface plumbing. This prepares for the next patch which will add similar signature handling options to `git fast-import`.

The refactoring includes:
- Moving the `enum sign_mode` definition to gpg-interface.h
- Extracting the parsing logic into a new `parse_sign_mode()` function in gpg-interface.c
- Updating fast-export.c to use the new shared implementation
- Fixing a minor indentation issue in the process

This appears to be a clean, mechanical refactoring with no behavior changes. The commit message clearly explains the change and its motivation. The patch is part of Christian Couder's ongoing work to bring signature handling parity between fast-export and fast-import, which will enable better signature management during repository filtering operations.
