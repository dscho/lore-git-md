This is a brief follow-up in the ongoing discussion about shallow clone support after grafts removal in Git v3.0. Bagas Sanjaya thanks Patrick Steinhardt for clarifying that while the `.git/info/grafts` interface is being removed, the underlying shallow clone functionality (including `git clone --depth=1` and `git fetch --unshallow`) will remain intact through a different implementation. The thread appears to be winding down as the core compatibility concerns have been addressed.
