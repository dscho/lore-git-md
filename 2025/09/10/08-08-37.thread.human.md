Christian Couder has proposed adding signature handling controls to `git fast-import`, mirroring existing capabilities in `git fast-export`. The two-patch series refactors shared signature handling code (patch 1) and implements the new fast-import feature (patch 2).

Junio C Hamano reviewed the first patch positively, approving the infrastructure changes that moved common signature handling code to gpg-interface.{c,h}. The second patch, which adds `--signed-commits=<mode>` to fast-import, has now received Junio's detailed review. While not rejecting the approach, he raised several technical concerns about the implementation's structure - particularly around how signature parsing interacts with the data stream handling in different modes. The review suggests the division of responsibilities between functions may need reworking for better maintainability.

The series remains in discussion, with the core functionality appearing sound but some implementation details needing refinement. Christian will likely respond with either explanations for the current design or a revised version addressing the review feedback.
