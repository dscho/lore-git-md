Christian Couder has proposed a two-patch series to add signature handling controls to `git fast-import`, mirroring the existing capabilities in `git fast-export`. The first patch refactored shared signature handling code into gpg-interface.{c,h}, while this second patch implements the actual `--signed-commits=<mode>` option for fast-import.

The new option supports the same modes as fast-export: preserving signatures (`verbatim`), removing them (`strip`), or rejecting signed commits entirely (`abort`), plus warning variants of the first two modes. Unlike fast-export which defaults to `abort`, fast-import will default to `verbatim` (preserving signatures). The implementation includes comprehensive tests covering all modes with various signature types (OpenPGP, X.509, SSH) and even dual SHA-1/SHA-256 signatures.

The series appears well-structured, separating infrastructure changes from feature implementation. With no objections raised yet and thorough test coverage, this looks ready for maintainer consideration. The work builds on Christian's expertise in GPG signature handling and fast-import/export plumbing, completing the symmetry between these complementary commands.
