This is a refactoring patch that simplifies several callers of `get_oid_with_context()` by using the newer `repo_get_oid_with_flags()` function instead. The change affects multiple commands including `ls-tree`, `rev-parse`, `stash`, and the list-objects filter code.

The key improvement is removing unnecessary handling of `struct object_context` in cases where callers only need to specify flags (like `GET_OID_HASH_ANY` or `GET_OID_QUIETLY`) but don't actually use the context information. The patch eliminates about 50 lines of code by removing context variable declarations, release calls, and simplifying the function invocations.

The changes appear mechanical and well-contained, touching only callers that clearly don't need the context information. The patch maintains all existing functionality while making the code more straightforward. This seems like a clean, low-risk improvement that follows Git's ongoing effort to modernize its codebase.
