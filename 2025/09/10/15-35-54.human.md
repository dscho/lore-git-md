This is a CI infrastructure patch in the Rust integration series, converting a redundant "pedantic" build job into a more useful test of Rust-enabled builds with breaking changes. 

The patch repurposes the Fedora-based "pedantic" CI job, which had become a no-op after pedantic builds were made default. The new job will instead test Meson builds with breaking changes enabled, providing additional test coverage for both the Meson build system and upcoming Rust integration. 

Key changes include:
- Replacing the pedantic job with a "fedora-breaking-changes-meson" job in both GitHub Actions and GitLab CI
- Adding Meson/ninja dependencies for Fedora builds
- Ensuring the job runs full tests (previously pedantic builds skipped tests)
- Setting up the breaking changes flag for Meson builds

This is part of the broader Rust infrastructure effort (patch 8/9 in v4) and helps validate the build system changes from earlier in the series. The change is straightforward and well-motivated, eliminating a useless job while adding meaningful test coverage for the Rust transition. The patch maintains consistency with existing CI patterns while advancing the series' goal of comprehensive Rust testing.
