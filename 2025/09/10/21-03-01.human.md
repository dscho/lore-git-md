This is Junio Hamano's regular "What's cooking in git.git" status update, providing an overview of active development topics in the Git project as of September 2025. These updates help track the progress of patches through the integration branches (seen, next, master) and highlight stalled topics that may be dropped.

The email lists 30+ active topics across various categories. Notable new work includes an ODB transaction interface (jt/odb-transaction), fast-import signed commits support (cc/fast-import-strip-signed-commits), and initial Rust integration experiments (ps/rust-balloon). Several documentation and test improvements are nearing completion, while some refactoring work around the packfile store and midx handling continues.

The "Stalled" section calls out several topics that have been inactive for weeks, including rebase trailer support (lc/rebase-trailer) and sparse checkout variable cleanup (ac/deglobal-sparse-variables). These may be dropped soon if not updated. The email also notes Git 3.0 preparations, including the default branch name change to 'main' (pw/3.0-default-initial-branch-to-main) and deprecation of core.commentChar=auto (pw/3.0-commentchar-auto-deprecation).

This status update provides maintainers and contributors with visibility into what changes are being considered for upcoming releases and which topics need attention to avoid being dropped from consideration. The detailed branch-by-branch breakdown helps reviewers understand the current state of various feature efforts.
