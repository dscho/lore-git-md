This is a refactoring patch that prepares for adding signature handling to `git fast-import` by moving shared code into gpg-interface plumbing.

The patch relocates the `enum sign_mode` definition and its parsing logic from builtin/fast-export.c to gpg-interface.{c,h}, making these components available for reuse. The enum defines signature handling modes (abort, verbatim/ignore, strip, and warn- variants) that control how GPG signatures are processed during export operations. The key changes are:

1. Moving the enum definition to gpg-interface.h
2. Extracting the parsing logic into a new parse_sign_mode() function in gpg-interface.c
3. Simplifying fast-export's option callback to use the shared parser
4. Fixing minor indentation in the option callback

The refactoring maintains all existing behavior while enabling future patches to add signature handling to fast-import without code duplication. The commit message clearly explains the motivation - upcoming fast-import changes will need these same components. The patch is cleanly separated from behavior changes, touching only code organization.
