This is a feature patch in the Rust infrastructure series, adding visibility into Rust build status. The patch modifies `help.c` to report whether Git was built with Rust support in both `git version --build-options` and `git bugreport` output. This diagnostic aid will be useful for identifying Rust-specific issues during the transition period where some subsystems maintain both C and Rust implementations.

The change is straightforward, adding a simple conditional block that reports "rust: enabled" or "rust: disabled" based on the `WITH_RUST` build flag. The implementation mirrors existing feature reporting like fsmonitor support, though the commit message notes this is specifically to help track bugs that might only manifest in Rust-enabled builds.

This patch builds on the Makefile infrastructure from patch 3/9 in the same series, which introduced the `WITH_RUST` toggle. It's a small but practical addition that follows the pattern of Git's existing build information reporting. The change is well-contained (just 6 lines added to `help.c`) and clearly motivated by the transitional nature of the Rust integration work.
