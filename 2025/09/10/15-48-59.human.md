This is a bugfix for the command deprecation framework series, specifically addressing a memory leak in the alias shadowing functionality. Jeff King (Peff) proposes a solution to fix the leak in patch 2/7 of the alias shadowing implementation.

The issue occurs when checking for aliases of deprecated commands - the code was calling `alias_lookup()` which allocates memory, but not freeing the result. Peff suggests simplifying the logic by just using `handle_alias()` directly, which already handles the alias lookup and cleanup internally. His proposed change removes the separate `alias_lookup()` check entirely.

The solution appears clean and correct, maintaining all the existing functionality while fixing the leak. This was the last outstanding issue blocking the deprecation framework series from being merged, and Peff's fix aligns with the thorough review and high-quality implementation seen throughout this series. With this change, the series should be ready for final integration.
