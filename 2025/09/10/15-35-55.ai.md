CI/build system patch completing the Rust infrastructure series by enabling Rust testing in breaking-changes CI jobs. This final patch in the v4 series modifies both dependency installation and test execution scripts to ensure Rust tooling is available and enabled when testing breaking changes.

The changes are straightforward: `cargo` is added to the package lists in `ci/install-dependencies.sh` for both Fedora/AlmaLinux and Ubuntu/Debian platforms, while `ci/run-build-and-tests.sh` now sets `WITH_RUST=YesPlease` and adds `-Drust=enabled` to Meson flags for breaking-changes test scenarios. This ensures the CI system will exercise the Rust infrastructure (including the newly type-safe varint subsystem from patch 5/9) under the same conditions that test other breaking changes.

The patch follows the series' pattern of incremental, focused changes that build toward mandatory Rust adoption. It directly supports the testing strategy outlined in earlier patches while maintaining compatibility with both Makefile and Meson build systems. The changes are minimal (4 lines added/2 removed) and focused on the CI system, leaving the core build logic established in previous patches unchanged.
