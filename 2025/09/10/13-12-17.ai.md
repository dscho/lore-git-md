This is a refactoring patch that removes deprecated wrapper functions in the object database layer as part of the ongoing `the_repository` removal effort.

The patch removes several compatibility functions from odb.h that were kept during the transition to direct `struct object_database` access in Git 2.51. These wrappers (`oid_object_info_extended`, `oid_object_info`, `repo_read_object_file`, and `has_object`) have now been replaced by their direct `odb_*` counterparts. The changes update three locations that were still calling these wrappers: `builtin/pack-objects.c` (two call sites) and `t/helper/test-pack-deltas.c` (four call sites).

The commit message explains this was a planned cleanup after the 2.51 release cycle, where these wrappers were temporarily kept to ease the transition. The changes are straightforward mechanical replacements of the old wrapper calls with their new direct equivalents. The diff shows the functionality remains identical, just routed through the new API.

Key technical details for future reference:
- Removed functions were all thin wrappers around `odb_*` functions
- Affected files: odb.h (removal), builtin/pack-objects.c, test-pack-deltas.c
- New functions used: `odb_has_object`, `odb_read_object_info_extended`, `odb_read_object`
- Part of broader effort to eliminate `the_repository` global access
