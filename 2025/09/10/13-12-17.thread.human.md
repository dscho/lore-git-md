This thread discusses a straightforward cleanup patch in the ongoing effort to remove Git's `the_repository` global variable. The initial patch, from Patrick Steinhardt, removes several transitional wrapper functions in the object database layer (`oid_object_info_extended`, `oid_object_info`, `repo_read_object_file`, `has_object`) that were kept during Git 2.51's transition period but are now obsolete. These have been replaced throughout the codebase by direct `odb_*` function calls, making this a mechanical deletion of unused code.

Justin Tobler has reviewed the changes and confirmed they look correct, noting the patch aligns with the broader project goal of eliminating indirect access through `the_repository`. With no technical concerns raised and the changes being a planned cleanup of already-replaced functionality, this appears ready to proceed toward merging as part of the larger `the_repository` removal effort that René Scharfe has been driving.
