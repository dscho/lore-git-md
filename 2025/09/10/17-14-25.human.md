This is a collection of maintenance and improvement patches for git-gui, the graphical Git interface. The changes include:

1. **Windows usability**: Heiko Voigt adds a question helper for retry fallback on Windows, while Johannes Schindelin improves the askpass functionality by ensuring git-gui--askpass is used by default and enhances the yes/no dialog with better window titles and icons (specifically using Git for Windows' icon when available).

2. **Bugfix**: Johannes Sixt fixes error handling in the "Revert Changes" command, addressing a potential issue in the GUI's revert functionality.

3. **Code simplifications**: Mark Levedahl contributes two cleanups - simplifying PATH de-duplication and the use of nice(1) command.

4. **Build system**: Adam Dinwoodie synchronizes the git-gui Makefiles with those in the main git.git repository.

The changes appear focused on improving the Windows experience and general code quality, with straightforward fixes and maintenance updates. The patches are well-organized into logical groupings and seem ready for integration.
