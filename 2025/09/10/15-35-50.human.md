Feature patch (part of Rust infrastructure series) that exposes Rust build status in version info. This is patch 4/9 in Patrick Steinhardt's v4 series introducing mandatory Rust support to Git core. 

The patch adds a simple but useful diagnostic feature: it makes Git report whether it was built with Rust support via both `git version --build-options` and `git bugreport`. The motivation is straightforward - since Git will temporarily have parallel C and Rust implementations of some subsystems during the migration period, this will make it easier to identify whether any reported bugs are Rust-specific.

The implementation is minimal, adding just 6 lines to help.c that check the WITH_RUST compile-time flag and report "rust: enabled" or "rust: disabled" accordingly. It follows the existing pattern used for features like fsmonitor. While simple, this is a thoughtful addition that will help with debugging during the transition period when both implementations exist side-by-side.

This patch fits cleanly into the broader series by providing visibility into the Rust build status, complementing the build system work in earlier patches. It's a small but practical piece of the infrastructure needed for the Rust migration.
