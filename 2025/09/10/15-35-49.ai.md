Build system patch for Rust integration (part 3/9 of v4 series). This patch adds Makefile infrastructure to build the internal Rust library, mirroring the meson support added in previous patches. Key technical elements:

- Adds `WITH_RUST` build toggle (optional now, mandatory in Git 3.0)
- Defines Rust build artifacts (`RUST_LIB` pointing to debug/release targets)
- Sets up `CARGO_ARGS` with quiet/release flags matching Make's verbosity
- Adds Rust sources tracking (`RUST_SOURCES` variable starting with `src/lib.rs`)
- Includes Rust library in `GITLIBS` when enabled
- Adds clean target for `target/` directory
- Implements quiet cargo build output via `QUIET_CARGO`

The patch follows the series' progression by preparing the build system for Rust integration while maintaining the existing C build flow. It handles basic Rust compilation but defers actual Rust code implementation to later patches. The changes are mechanical build system adjustments rather than functional additions, keeping with the series' incremental approach to Rust adoption.
