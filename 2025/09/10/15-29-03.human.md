This is a test infrastructure patch that concludes the series switching Git's default branch name from "master" to "main". Phillip Wood removes the last remaining use of `GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=master` in the test suite, specifically from the reftable write options tests.

The patch introduces a helper function `init_repo()` that explicitly sets the branch name to "master" when creating test repositories, since these tests specifically verify behavior that depends on the branch name. This makes the dependency clear at the call sites and makes it easier to change the branch name in the future if needed.

The change is straightforward and follows Junio Hamano's earlier suggestion to use a helper function approach for these tests. With this patch, the technical work to switch the default branch name is complete, though some documentation and advice message discussions remain open. The patch maintains all existing test coverage while making the branch name dependency more explicit.
