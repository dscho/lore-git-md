Test infrastructure patch finalizing the transition from "master" to "main" as default branch name in the reftable test suite. This is the last patch in the merged series that changes Git's default branch name when built with WITH_BREAKING_CHANGES.

The patch removes the final instance of GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=master from the test suite, specifically from t0613-reftable-write-options.sh. Instead, it introduces an init_repo() helper function that explicitly creates repositories with "master" as the initial branch name where needed (for block size calculations that depend on the ref name). This makes the test's branch name dependency explicit while making it easier to change in the future.

Key technical details:
- Affects reftable backend tests that verify block sizes (which depend on ref names)
- Replaces global GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME with targeted init_repo() helper
- Helper function approach was suggested by Junio Hamano
- Maintains test coverage while reducing implicit dependencies on "master"
- Part of broader effort to remove GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME=master usage

The change is straightforward and aligns with the series' goal of cleanly handling the branch name transition.
