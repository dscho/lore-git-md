Feature patch adding signature handling to `git fast-import`, completing a pair with `git fast-export`. This is the second patch in a two-part series from Christian Couder, building on the infrastructure refactoring in patch 1/2.

The patch introduces a `--signed-commits=<mode>` option to `git fast-import` that mirrors the existing fast-export capability. It supports the same modes: verbatim (keep signatures), strip (remove them), abort (reject signed commits), and warn- versions of each. The default is verbatim, differing from fast-export's abort default since imports are typically trusted operations.

Implementation handles all three Git signature formats (OpenPGP, X.509, SSH) and properly processes dual SHA-1/SHA-256 signatures in SHA-256 repositories. The comprehensive t9305 test script verifies all modes with all signature types, including warning output and edge cases like signature stripping in dual-hash repos.

The change is well-contained, touching only fast-import's frontend, gpg-interface plumbing, and docs. It completes the symmetry between import/export signature handling that was started in the first patch. The thorough test coverage and clear commit message make this easy to review.
