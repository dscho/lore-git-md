This is a documentation patch in Julia Evans' ongoing series to improve `git-checkout.adoc` clarity. It focuses specifically on clarifying the `-b` and `-B` options, which users reported as confusing.

The patch simplifies the explanations by separating `-b` and `-B` into distinct sections rather than combining them. For `-b`, it now clearly states it creates a new branch at the given start point (defaulting to current commit) and checks it out, with explicit mention of failure conditions. For `-B`, it emphasizes the key difference - that it resets an existing branch rather than failing.

The changes remove some redundant implementation details (like the internal `git branch -f` equivalent) in favor of clearer behavioral descriptions. The patch maintains technical accuracy while making the options' purposes and differences more immediately obvious to readers. This continues the series' trend of improving accessibility without sacrificing precision, with all substantive technical aspects having been settled in earlier review rounds.
