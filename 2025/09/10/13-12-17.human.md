This is a refactoring patch that removes deprecated wrapper functions in the object database layer. 

Patrick Steinhardt is cleaning up transitional code that was kept around during the Git 2.51 release cycle to ease migration to the new `struct object_database` interface. Now that 2.51 has been released, these compatibility wrappers can be removed.

The patch deletes several wrapper functions from odb.h that provided backwards compatibility, including `oid_object_info_extended()`, `oid_object_info()`, `repo_read_object_file()`, and `has_object()`. It updates the few remaining callers in `builtin/pack-objects.c` and `t/helper/test-pack-deltas.c` to use the direct `odb_*` variants instead.

The changes are straightforward mechanical updates to call the new functions through the repository's object store rather than using the old wrappers. This appears to be a well-executed cleanup of transitional code that has served its purpose, with all affected code paths properly updated to use the modern interface.
