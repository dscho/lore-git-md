This is a review comment on the first patch of Christian Couder's series to add signature handling controls to `git fast-import`. Junio Hamano provides feedback on the refactoring that moves signature mode parsing into shared gpg-interface code.

The review notes that the patch produces "very pleasing to read code" with the new `parse_sign_mode()` helper function, and specifically calls out the improved clarity of having the `enum sign_mode` definition visible in the header file. Junio does question whether the "unset" codepath in the option parsing should do nothing with the output value, but explicitly notes this is out of scope for the current refactoring.

The changes look straightforward - moving existing parsing logic from fast-export.c to gpg-interface.{c,h} with identical behavior, just better organized for reuse. The review suggests the infrastructure refactoring is sound and ready to build upon for the feature implementation in patch 2/2.
