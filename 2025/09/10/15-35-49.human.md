This is part of the ongoing Rust infrastructure series, specifically focusing on Makefile integration. Patch 3/9 in v4 of the series adds Rust build support to the Makefile, mirroring the meson integration from earlier patches.

The patch introduces a new `WITH_RUST` build toggle (optional now but mandatory in Git 3.0) and adds basic Rust build infrastructure to the Makefile. Key changes include:
- Adding Rust build targets to `.gitignore` (`/target/` and `Cargo.lock`)
- Defining Rust-specific variables and flags
- Adding a `rust` phony target and rules to build `libgit.a` via Cargo
- Including Rust in the clean target
- Adding quiet output support for Cargo commands

The implementation follows the same pattern as the meson integration from patch 2/9, maintaining consistency between build systems. This is a mechanical but necessary step in the Rust transition, ensuring the Makefile can handle Rust compilation with proper conditional logic and integration with the rest of the build system.

The patch appears well-structured and focused, with clean separation between the new Rust-specific additions and existing Makefile logic. It maintains the project's existing patterns for build system configuration while adding the new capability. As with the rest of the series, this is foundational work that enables but doesn't yet include substantive Rust code - the actual Rust implementation will come in later patches.
