This is the foundational patch in Patrick Steinhardt's v4 series introducing Rust infrastructure to Git core. It establishes the meson build system integration for Rust, marking it as optional initially but with the stated goal of becoming mandatory by Git 3.0.

The patch adds several key components:
- A basic Cargo.toml configuration targeting Rust 2018 edition (compatible with Rust 1.49 for gcc-rs backend support)
- Meson build rules that auto-enable Rust if cargo is found, controllable via `-Drust=` option
- A cargo-meson.sh wrapper script to handle build output placement (workaround for unstable `--artifact-dir`)
- Test infrastructure using Rust's native unit testing capabilities

Notable technical choices include the Rust edition pinning for gcc-rs compatibility and the wrapper script approach to avoid unstable Cargo flags. The implementation is structured to allow gradual adoption, with Rust features initially being non-critical "test balloons" before full integration. The patch sets up the basic framework but leaves the actual Rust implementations for later patches in the series. It includes test wiring but no substantive Rust code yet - src/lib.rs is empty in this initial commit. The build system changes are comprehensive, touching meson configuration at multiple levels while maintaining backward compatibility.
