This is the foundational patch in a series introducing Rust infrastructure to Git's build system. As the first of 9 patches in v4 of the RFC series, it adds Meson support for building an optional Rust library, marking Git's first steps toward making Rust a mandatory dependency by Git 3.0.

The patch creates the basic scaffolding: a Cargo.toml file, Meson build rules, and a wrapper script to handle Cargo's output location quirks. Rust support is auto-detected but can be controlled via a new `-Drust=` option. The implementation uses Rust 2018 edition compatibility to support the upcoming gcc-rs backend, though this may be revisited if newer Rust features are needed.

Notably, this initial Rust integration is positioned as a "test balloon" - optional functionality where the project can experiment with new features and alternative implementations before committing to full adoption. The patch includes Rust's native test framework integration, allowing unit tests to run via `meson test`.

The technical approach shows careful consideration of backward compatibility and build system integration, though Windows support remains pending work. This patch sets up the infrastructure that subsequent patches will use to migrate specific subsystems to Rust, starting with varint handling in later parts of the series.
