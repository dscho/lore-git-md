This is the final patch in Patrick Steinhardt's v4 series introducing Rust infrastructure to Git core. The patch focuses on CI integration, specifically enabling Rust testing in the breaking-changes jobs.

The changes are straightforward but important for the Rust rollout:
1. Adds cargo installation to both Fedora and Ubuntu/Debian CI environments
2. Enables Rust builds in the breaking-changes test jobs by setting WITH_RUST and meson's rust flag

This builds on previous infrastructure work in the series to ensure the Rust components are properly exercised in CI. The patch is small (4 line changes) but completes the CI coverage needed to validate the Rust integration, particularly for the breaking-changes path that will be important for the Git 3.0 transition.

The changes follow the established pattern in the series of incremental, well-motivated additions that address practical adoption concerns. With this patch, the CI system will now test both the Makefile and meson build systems with Rust enabled, including the breaking-changes path that was a key concern in earlier discussion.
