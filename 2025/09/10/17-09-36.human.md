Junio Hamano provides review feedback on the second patch of Christian Couder's series adding signature handling to `git fast-import`. This is a feature patch implementing the new `--signed-commits=<mode>` option.

The review focuses on the implementation details of signature processing in the new `import_signature()` function and its caller. Hamano questions the division of responsibilities between these functions, noting that the new approach requires each case in the switch statement to handle advancing the input stream, which could be error-prone for future modifications. He suggests the previous unified parsing approach might have been more maintainable.

Hamano also requests a small wording improvement to the warning message for verbatim imports, suggesting it should explicitly say "verbatim" to match the mode name. The feedback is constructive but doesn't raise any fundamental objections to the feature's design or implementation.

This continues the positive but detail-oriented review pattern seen in the first patch, with Hamano focusing on maintainability and edge cases rather than the overall approach. The thread shows steady progress toward merging this signature handling capability into fast-import.
