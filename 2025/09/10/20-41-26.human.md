This is a post-merge discussion about the recently merged series that changed Git's default initial branch name from "master" to "main" (when built with WITH_BREAKING_CHANGES). The technical implementation is complete, but there's ongoing discussion about user messaging.

Junio Hamano responds to Phillip Wood's hesitation about adding advice messages for users following tutorials that still use "master". Junio argues that since Git has been showing advice about the "master" branch name for several releases, it would be consistent to also show advice about the new "main" default when that differs from tutorial instructions. He disagrees with the concern that such messages would be annoying, seeing them as helpful guidance during a transition period.

The exchange reveals a philosophical difference in approach: Phillip prefers to wait and see if advice is actually needed, while Junio advocates for proactive guidance. Both agree the advice could be added later if needed, though Junio's position is that it should be included now for consistency with past practice.

This discussion represents one of the last open questions from the series, which has otherwise been fully implemented with all test infrastructure updates and documentation changes in place. The core technical work is done, and this thread is now focused on fine-tuning the user experience aspects of the change.
