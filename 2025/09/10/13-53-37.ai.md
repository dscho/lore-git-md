This is a follow-up in the `git whatchanged` removal discussion thread, providing alternative command suggestions.

Kristoffer Haugsbakk responds to Chirayu Desai's usage of `git whatchanged -1` by offering specific replacement commands. The key technical details include:
- `git log --no-merges --raw` as a direct replacement for `git whatchanged`
- `git show --raw` as an alternative for viewing single commits
- Mention of output differences with empty commits (referencing a prior email from Peff)
- Clarification that core commands can't be shadowed by aliases, suggesting `watchanged` as a workaround alias name

The email reinforces the thread's technical consensus that `git log` alternatives exist while acknowledging the muscle memory aspect. It provides concrete command substitutions but doesn't address whether these should be documented more prominently, which remains an open question from the thread. The tone is helpful and solution-oriented rather than debating the removal decision itself.
