This is a CI/build system patch in the Rust infrastructure series, converting the obsolete "pedantic" CI job into a full test of Meson builds with breaking changes enabled. The change:

1. Replaces the redundant Fedora pedantic build (made obsolete by default pedantic builds) with a new `fedora-breaking-changes-meson` job that tests both Meson builds and upcoming breaking changes
2. Ensures Rust infrastructure will be tested across both build systems (Makefile and Meson) by preparing for Rust enablement in a follow-up
3. Adds Fedora to the distros running full builds, increasing platform coverage
4. Simplifies the test execution logic by removing the `run_tests` conditional that was only used for the pedantic job

The patch modifies CI configuration files across GitHub Actions and GitLab CI, plus the shared build/test scripts. Key technical changes include adding Meson/ninja dependencies for Fedora, setting `-Dbreaking_changes=true` for Meson builds, and unifying test execution paths. This demonstrates the series' pattern of leveraging existing infrastructure while expanding test coverage for the Rust transition.
