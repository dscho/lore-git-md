Feature patch implementing signature handling in `git fast-import`, completing the two-patch series that began with infrastructure refactoring. This second patch adds a `--signed-commits=<mode>` option to `git fast-import` that mirrors the existing functionality in `git fast-export`, allowing control over how commit signatures are handled during import operations.

The implementation supports the same modes as fast-export: `verbatim` (preserve signatures), `strip` (remove signatures), `abort` (reject signed commits), plus `warn-` variants of `verbatim` and `strip` that preserve the behavior but emit warnings. The default mode is `verbatim` (unlike fast-export's default of `abort`). The patch includes comprehensive tests in a new t9305 test script that verifies handling of OpenPGP, X.509, and SSH signatures across all modes, including a case with dual SHA-1/SHA-256 signatures.

Key technical changes:
- Adds `signed_commit_mode` global variable and option parsing in fast-import.c
- Implements signature processing logic in `import_signature()` that respects the selected mode
- Documents the option in git-fast-import.adoc
- Adds t9305 test script with cases for:
  - Basic signature preservation (`verbatim`)
  - Warning variants (`warn-verbatim`, `warn-strip`)
  - Signature stripping (`strip`)
  - Error case (`abort`)
  - Multiple signature formats (OpenPGP, X.509, SSH)
  - Dual SHA-1/SHA-256 signatures

The patch builds cleanly on the infrastructure refactoring from patch 1/2, using the shared `enum sign_mode` and `parse_sign_mode()` from gpg-interface.{c,h}. Test coverage appears thorough, exercising all modes with multiple signature types. The implementation maintains backward compatibility while adding the new functionality.

This completes the series' goal of enabling signature management during repository filtering operations by providing parallel signature control in both export and import operations. The clean separation between infrastructure refactoring (1/2) and feature implementation (2/2) makes for a focused review of each component.
