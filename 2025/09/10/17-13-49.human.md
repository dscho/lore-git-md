This is a set of platform compatibility fixes and documentation updates for gitk, the Git repository visualizer. The pull request bundles several changes from different contributors targeting macOS-specific issues and adding a comprehensive README.

The first two patches by Ruoyu Zhong address Tcl/Tk 8.7+ compatibility on macOS, fixing right-click context menus and trackpad scrolling behavior. These appear to be well-scoped technical fixes for specific interaction problems that macOS users would encounter with newer Tcl/Tk versions.

Michael Rappazzo contributes a new README.md that provides usage instructions, build guidance, and contribution details for gitk. This documentation addition fills a notable gap, as gitk previously lacked introductory documentation despite being a long-standing component of Git.

The changes are presented as merges of branches from ZhongRuoyu's fork, suggesting these fixes were developed and tested independently before being pulled into the main gitk repository. The patch set looks focused and well-organized, with each change addressing a clear need for macOS users or general project documentation.
