This is the 5th patch in a 7-part series introducing the `git repo stats` command, focusing on adding object counting functionality to the repository statistics output. The patch builds on the reference counting infrastructure established in earlier patches.

The implementation introduces a new `object_stats` struct to track counts of reachable objects by type (tags, commits, trees, blobs). It uses the path-walk API to traverse all objects reachable from regular references, categorizing them during the walk. The counts are integrated into the existing table output format alongside the reference statistics.

Key technical details:
- Adds `struct object_stats` with counters for each object type
- Implements `count_objects()` callback for path-walk traversal
- Introduces `stats_count_objects()` to initiate the walk from all references
- Expands `repo_stats` struct to combine reference and object statistics
- Updates table formatting to accommodate the new object counts section
- Includes test cases verifying:
  - Empty repository handling
  - Correct counting of objects in a populated repository
  - Proper integration with reference counting output

The patch maintains the series' pattern of thorough testing and careful memory management. It demonstrates the extensibility of the stats table system by cleanly adding a new category of metrics. The implementation appears well-considered, leveraging existing Git infrastructure (path-walk API, revision walking) rather than reinventing traversal logic.

This moves the feature closer to completion by delivering on one of its core promises - object statistics - while maintaining consistency with the established output format and testing approach. The remaining patches in the series will presumably focus on output format variations and documentation.
