This is a documentation patch fixing markdown formatting in the translation (l10n) documentation.

The patch removes unnecessary backslash escapes from underscores in language code examples in po/README.md. The changes affect three instances where language codes like "ll_CC" and "zh_CN" were incorrectly escaped as "ll\_CC" and "zh\_CN". 

The fix is straightforward - underscores in Markdown only need escaping when they would otherwise indicate italic/bold formatting, which isn't the case here. The patch maintains all the actual content while correcting the formatting.
