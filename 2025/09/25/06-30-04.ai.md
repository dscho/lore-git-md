Build system refactoring as part of the Rust infrastructure series. This is patch 2/9 in the v7 series introducing Rust support to Git core.

The patch reorganizes the Makefile to move variable definitions after the inclusion of config files (config.mak.uname, config.mak.autogen, config.mak, and config.mak.dev). This structural change enables future conditional compilation based on the `WITH_RUST` flag that will be defined in config.mak. The actual Rust-related changes will come in subsequent patches.

The diff shows a straightforward reordering of Makefile sections, with no functional changes beyond the include ordering. The moved blocks contain:
- Library definitions (GITLIBS, EXTLIBS)
- Compiler/linker flags (CFLAGS, LDFLAGS, etc.)
- Coccinelle/sparse-related settings
- SHA-1 collision detection submodule check

This change is preparatory work for the Rust integration, ensuring build configuration can properly influence source compilation. The patch maintains all existing functionality while setting up the infrastructure needed for conditional Rust compilation in later patches of the series.
