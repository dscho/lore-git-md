This is the final patch (9/9) in the Rust infrastructure series, focusing on CI modernization to test Rust integration in breaking-changes scenarios. The patch enables Rust compilation in the newly converted Fedora-based breaking-changes CI jobs by:

1. Adding `cargo` to the dependency installation lists for both Fedora/AlmaLinux and Ubuntu/Debian CI environments
2. Setting `WITH_RUST=YesPlease` and `-Drust=enabled` flags for the breaking-changes test jobs

The changes are minimal but strategically important - they ensure the Rust-enabled build path gets exercised in CI alongside the breaking-changes testing infrastructure that was repurposed from the old "pedantic" job in patch 8. This completes the CI validation story for the Rust transition by covering both build system integration and the phased adoption path.

The patch maintains consistency with the series' established patterns for Rust enablement and follows the same minimal-diff approach seen in prior CI modernization patches. It directly supports the documented three-phase adoption plan by verifying the optional Rust build path works in the environments where breaking changes are tested.
