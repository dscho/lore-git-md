This is a documentation patch in Patrick Steinhardt's Rust infrastructure series (v7 7/9), updating `BreakingChanges.adoc` to formalize the Rust adoption timeline. The patch establishes three key phases: optional Rust in 2.52 (current), default-enabled in 2.53, and mandatory in 3.0 (targeting H2 2026). It documents escape hatches (`WITH_RUST=YesPlease`, meson flags) while acknowledging platform challenges, and introduces an LTS safety net - the pre-3.0 release will receive extended support. The policy includes an evaluation clause allowing deferral if downstream impact proves severe.

The text carefully balances commitment with flexibility, noting current optional Rust uses (contrib wrapper, test subsystems) while framing the varint POC as the first step toward broader adoption. Build system specifics are detailed for both Meson and Makefile paths. The LTS handover mechanism remains intentionally vague, with details to be finalized later. This patch codifies the governance consensus from earlier thread discussion while preserving an out for exceptional downstream hardship.
