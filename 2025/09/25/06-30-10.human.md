This is a CI modernization patch in Patrick Steinhardt's Rust infrastructure series (v7 8/9). It repurposes an obsolete "pedantic" CI job (which was just doing redundant builds on Fedora) into a more valuable test case that verifies Meson builds with breaking changes enabled. 

The change plugs two testing gaps: it adds Fedora to the distros we test against, and ensures breaking changes work properly with Meson builds. This also sets up the infrastructure for testing Rust builds across both Makefile and Meson systems, which will be used in a follow-up patch.

The implementation removes the old pedantic job configuration and replaces it with a new fedora-breaking-changes-meson job that runs full builds and tests. The patch includes necessary adjustments to dependency installation and build/test scripts to support this change.

This is a straightforward technical improvement that tightens up the test coverage for the Rust infrastructure work, ensuring both build systems are properly exercised as part of the phased transition plan. The changes are cleanly implemented and well-explained in the commit message.
