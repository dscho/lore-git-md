This is a feature patch in the Rust infrastructure series that adds visibility mechanism for Rust support in Git builds.

The patch modifies `help.c` to report whether Git was built with Rust support via both `git version --build-options` and `git bugreport`. This is motivated by the transitional period where some subsystems will have both C and Rust implementations, making it important to know which implementation is active when diagnosing issues.

The change is straightforward - it adds conditional compilation blocks that report "enabled" or "disabled" Rust support based on the `WITH_RUST` flag. The implementation matches Git's existing pattern for reporting other build-time features like fsmonitor support.

As part of the larger Rust integration effort (now at v7), this patch serves an important diagnostic role while being relatively low-risk. It follows the series' established pattern of incremental, well-contained changes with clear motivations. The patch is small, focused, and appears to be correctly implemented with appropriate conditional compilation guards.
