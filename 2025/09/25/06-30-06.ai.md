This is part 4/9 of the Rust infrastructure series, focusing on build information reporting. The patch adds Rust build status visibility to `git version --build-options` and `git bugreport` outputs, showing whether Git was compiled with Rust support enabled.

The change is straightforward - it adds conditional compilation blocks to `help.c` that report "rust: enabled" or "rust: disabled" based on the `WITH_RUST` build flag. The commit message explains this will help diagnose Rust-specific issues during the transition period where both C and Rust implementations coexist. The implementation is clean and matches Git's existing build info reporting pattern, though it doesn't include the Rust version or toolchain details that might also be useful for debugging.

This patch follows naturally from the build system infrastructure added in earlier patches (1-3/9) that introduced the `WITH_RUST` flag. It's a small but important piece for maintainability during the phased Rust adoption, allowing users and developers to easily check which code paths are active. The change is well-contained and unlikely to be controversial, though some might question whether this belongs in the version string rather than just bugreport.
