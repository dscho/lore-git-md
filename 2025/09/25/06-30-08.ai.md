This is the Rust varint implementation patch in the ongoing Rust infrastructure series, serving as both a feature demonstration and test balloon.

Patch 6/9 introduces the first actual Rust code to Git core by reimplementing the varint encoding/decoding subsystem. The choice of varint is strategic - it's a self-contained component with no dependencies, making it ideal for initial Rust integration. The implementation provides identical functionality to the C version (including overflow handling) while demonstrating Rust's FFI capabilities through `#[no_mangle]` extern functions that match the C API exactly.

The patch modifies both build systems (Makefile and Meson) to conditionally compile either the C or Rust version based on the `WITH_RUST` flag. The Rust implementation lives in `src/varint.rs` and includes comprehensive tests validating edge cases like overflow behavior. Notable technical aspects include:
- Direct pointer manipulation via unsafe blocks to match C calling conventions
- Wrapping arithmetic for overflow protection
- Full test coverage mirroring the C implementation's behavior
- Build system integration that maintains backward compatibility

This serves as the first concrete demonstration of mixed C/Rust compilation in Git, following the preparatory work in earlier patches. The implementation is intentionally minimal to validate the build infrastructure while providing a template for future Rust conversions. The patch maintains all existing behavior while adding Rust's stronger type safety guarantees for the varint operations.
