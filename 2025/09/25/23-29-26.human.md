Feature patch adding object counting to the new `git repo stats` command.

This is patch 5/7 in Justin Tobler's series introducing repository statistics reporting. Building on the reference counting infrastructure from earlier patches, it now adds reachable object counts by type (commits, trees, blobs, and tags) to the output table. The implementation uses the path-walk API to traverse all objects reachable from regular references, categorizing them by type.

The patch includes thorough test coverage, verifying both empty repository behavior and counts in a populated repository with commits, tags, remotes, and notes. The output format matches the existing reference statistics table style, with clear hierarchical organization. Documentation is updated to reflect the new object counting capability.

The implementation appears solid, with careful memory management and proper integration with Git's revision walking infrastructure. The test cases demonstrate attention to edge cases while keeping the test data realistic. This continues the series' pattern of well-structured, incremental additions to the new statistics functionality.
