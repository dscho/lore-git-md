Final patch in the `git repo stats` series: Progress meter implementation

This is the seventh and final patch in Justin Tobler's series introducing the new `git repo stats` command. It adds a progress meter to provide feedback during potentially long-running repository statistics collection. The meter shows both reference counting ("Counting references") and object counting ("Counting objects") progress, with the same visual style as other Git commands.

The progress meter is enabled by default when running in a terminal (tty), matching Git's standard behavior, and can be explicitly controlled with `--[no-]progress` options. The implementation integrates cleanly with the existing stats collection code, adding progress callbacks to both the `stats_count_references()` and `stats_count_objects()` functions. Test coverage verifies both the progress output and the `--no-progress` suppression behavior.

This completes the core functionality of the `git repo stats` command, which now provides both human-readable and machine-parsable output formats (added in patch 6) with user feedback during execution. The implementation follows Git's established patterns for progress reporting, including the `GIT_PROGRESS_DELAY` handling seen in the tests. With this patch, the series appears ready for final review, pending any feedback on the progress meter behavior.
