This is the third patch in a series introducing Rust infrastructure to Git's core. It adds Makefile support for building an internal Rust library, complementing the Meson integration added in the previous patch.

The patch enables optional Rust compilation via a new `WITH_RUST` build flag, which will become mandatory in Git 3.0. It adds Rust-specific build rules, including handling for debug vs release builds, quiet output when not requested, and proper cleanup. The Rust library (`libgitcore.a`) will be linked into Git alongside the existing C libraries when enabled.

Key technical changes include:
- Adding Rust build artifacts to `.gitignore`
- New `RUST_SOURCES` variable tracking Rust input files
- Conditional addition of `-DWITH_RUST` and Rust library to link flags
- `cargo build` integration with proper quiet/verbose handling
- Clean target support for Rust artifacts

This is a well-structured infrastructure patch that follows Git's existing Makefile patterns while cleanly introducing the new Rust build path. It maintains the project's build system quality standards, with clear variable organization and proper dependency tracking. The patch moves the Rust integration effort forward without disrupting existing builds, keeping the change focused and reviewable.
