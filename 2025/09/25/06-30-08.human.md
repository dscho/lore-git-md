This is patch 6/9 in the Rust infrastructure series, implementing a Rust version of Git's varint encoding/decoding subsystem as a test case. The patch replaces the C implementation in `varint.c` with an equivalent Rust version in `src/varint.rs` when Rust support is enabled.

The varint subsystem was chosen for this initial Rust port because it's self-contained and has no dependencies on other Git components. The Rust implementation maintains identical behavior to the C version, including overflow handling (returning 0 on overflow). The patch includes comprehensive tests verifying the encoding/decoding behavior matches expectations.

Build system changes in both Makefile and Meson configurations ensure the Rust version is used when `WITH_RUST` is enabled, falling back to the C version otherwise. This demonstrates the phased transition approach where Rust components can be optionally enabled before becoming mandatory in Git 3.0.

The implementation appears technically sound, with careful attention to maintaining the exact same behavior as the C version. The inclusion of thorough tests provides confidence in the correctness of the port. This patch serves as both a practical demonstration of Rust integration and a template for future component ports.
