This is a documentation patch fixing minor Markdown formatting in the translation (l10n) documentation.

The patch removes unnecessary backslash escapes from underscores in language code examples like "ll_CC" and "zh_CN" in po/README.md. In Markdown, underscores don't need escaping when they appear in normal text (as opposed to emphasis contexts), so these backslashes were redundant and made the examples harder to read.

The change is straightforward and corrects a minor documentation formatting issue without affecting any actual functionality. The patch touches only the documentation file and makes the examples more readable while maintaining their technical accuracy. This appears to be a clean, focused improvement to the translation documentation.
