Junio Hamano provides feedback on patch 2/10 of Adrian Ratiu's hook refactoring series. This patch introduced a callback mechanism (`feed_pipe_fn`) for streaming stdin to hooks, as an alternative to the existing file-based stdin approach (`path_to_stdin`).

Hamano makes two main technical points about the implementation. First, he confirms the pipe setup logic is correct but notes the parallel between how `path_to_stdin` and `feed_pipe` both disable `no_stdin`. Second, he suggests improving the documentation to clarify that `feed_pipe` is ignored when `path_to_stdin` is set, and questions whether this precedence rule should be enforced as a BUG() condition rather than silent behavior.

This is a thoughtful review from the Git maintainer focusing on interface clarity and potential edge cases, though he doesn't raise any fundamental objections to the approach. The feedback comes late in the now-complete series, suggesting it's more about polish than blocking issues.
