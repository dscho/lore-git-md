CI modernization patch in the Rust infrastructure series, converting an obsolete "pedantic" CI job into a full Meson-based build with breaking changes enabled. This is patch 8/9 in v7 of the series.

The change repurposes the Fedora-based "pedantic" job (which became redundant after pedantic builds were enabled by default) into a new "fedora-breaking-changes-meson" job. This serves three purposes: testing Meson builds with breaking changes enabled, expanding test coverage to Fedora environment, and preparing for future Rust integration testing (which will be added in a follow-up commit). The patch modifies CI configuration files (GitHub Actions, GitLab CI) and build/test scripts to implement this change.

Key technical changes include:
- Removes "pedantic" job from both GitHub and GitLab CI configs
- Adds new "fedora-breaking-changes-meson" job
- Updates dependency installation to include Meson/Ninja for Fedora
- Modifies test runner to handle breaking changes flag in Meson builds
