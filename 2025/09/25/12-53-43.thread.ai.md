Thread summary: Hook subsystem refactoring series (v5, 12 parts) by Adrian Ratiu and Emily Shaffer standardizes Git hooks on the new `hook.h` API, now including receive-pack's update and post-update hooks in part 10. The series provides structured stdin handling, output capture, and parallel execution capabilities while maintaining backward compatibility.

Key technical changes:
- New `feed_pipe_fn` and `consume_output_fn` callbacks in `struct run_hooks_opt` for streaming stdin/capturing output, with strict BUG() assertions for invalid mode combinations
- Part 2 adds stdin handling to `run_processes_parallel()` with `feed_pipe_fn` callback, pipe buffering, and EPIPE/SIGPIPE handling
- Part 3 introduces `feed_pipe` callback mechanism for incremental stdin feeding without filesystem involvement
- Part 4 converts post-rewrite hook in sequencer.c to use structured API with `pipe_from_strbuf` callback for OID pairs
- Part 5 converts pre-push hook in transport.c with `pre_push_hook_feed_stdin` callback for ref status streaming
- Part 6 converts reference-transaction hook with `transaction_hook_feed_stdin` callback processing one ref update in `<old-value> <new-value> <refname>` format
- Part 7 adds `ungroup` field to `struct run_hooks_opt` to control parallel process output grouping
- Part 8 introduces `consume_output_fn` callback in `run-command.c` for capturing collated output of parallel processes, with strbuf-based handling and network transport use case support
- Part 9 exposes output capture functionality through `consume_output_fn` callback, allowing server-side hooks to redirect output (e.g. for sideband channels) while maintaining backward compatibility
- Part 10 converts receive-pack's update and post-update hooks to use the structured API, implementing `hook_output_to_sideband()` callback to maintain sideband output capability while removing manual process management code
- State management helpers: `child_is_working()`, `child_is_ready_for_cleanup()`, `child_is_receiving_input()` for process lifecycle
- Complete conversion of major hook types with backward compatibility:
  - Pre-push uses `pre_push_hook_feed_stdin` callback
  - Receive-pack batches stdin (500 lines/callback) with `feed_receive_hook_cb`
  - Post-rewrite uses `pipe_from_strbuf` for OID pairs
  - Reference-transaction now uses streaming callback per ref update
  - Update/post-update hooks maintain sideband output via `hook_output_to_sideband`
- Memory safety fixes across conversions with proper strbuf management
- API naming improvements per Patrick Steinhardt's feedback
- Comprehensive test coverage including EPIPE scenarios, output diversion, parallel process stdin feeding, and output capture verification
