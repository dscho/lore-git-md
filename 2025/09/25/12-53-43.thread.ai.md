Thread summary: Hook subsystem refactoring series (v6, 12 parts) by Adrian Ratiu and Emily Shaffer standardizes Git hooks on the new `hook.h` API, now including all major hook types (receive-pack's update, post-update, and receive hooks) in parts 10-11. The series provides structured stdin handling, output capture, and parallel execution capabilities while maintaining backward compatibility.

Key technical changes:
- New `feed_pipe_fn` and `consume_output_fn` callbacks in `struct run_hooks_opt` for streaming stdin/capturing output, with strict BUG() assertions for mode combinations
- Part 1 introduces `struct parallel_child` and `child_is_working()` helper in `run-command.c` to improve state management readability (foundational for later parallel execution work)
- Part 2 adds stdin handling to `run_processes_parallel()` with `feed_pipe_fn` callback and pipe management, including new helpers `child_is_ready_for_cleanup()` and `child_is_receiving_input()`
- Part 3 introduces `feed_pipe` callback mechanism with two context pointers (`feed_pipe_ctx` and `feed_pipe_cb_data`) for streaming stdin without filesystem overhead
- Part 4 converts post-rewrite hook in sequencer.c with `pipe_from_strbuf` callback, replacing manual `child_process` setup
- Part 5 converts pre-push hook in transport.c with `struct feed_pre_push_hook_data` for streaming state and ref filtering
- Part 6 converts reference-transaction hook with `transaction_hook_feed_stdin()` callback that processes one ref update per invocation, maintaining `REF_LOG_ONLY` filtering and EPIPE handling while eliminating direct `find_hook()` calls and manual SIGPIPE toggling
- Part 7 adds `ungroup` field to `struct run_hooks_opt` for parallel process output control, allowing callers to override default ungrouping behavior (critical for receive-pack sideband output)
- Part 8 introduces `consume_output_fn` callback in `run_process_parallel_opts` for capturing process output, with BUG() assertion preventing simultaneous use with `ungroup`, and test case demonstrating file redirection capability
- Parts 9-11 convert receive-pack's hooks with batched stdin and sideband output preservation
- Complete conversion of all major hook types with backward compatibility
