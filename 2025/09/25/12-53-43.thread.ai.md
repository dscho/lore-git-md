Patch 2 introduces a named `parallel_child` structure and `child_is_working()` helper function in `run-command.c` as suggested by Junio Hamano, improving readability of parallel process state checks.

Patch 3 introduces a stdin callback mechanism for `run_processes_parallel()`, allowing callers to stream large amounts of data to child processes without buffering everything in memory. Patch 4 (newly added) complements this with a `feed_pipe_fn` callback interface in `struct run_hooks_opt` specifically for hook processes, enabling stdin streaming without filesystem involvement while maintaining backward compatibility with the existing `path_to_stdin` approach. The implementation enforces mutual exclusivity between these methods via BUG checks and integrates with the parallel process infrastructure through `pp_task_cb`.
