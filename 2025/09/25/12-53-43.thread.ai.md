Adrian Ratiu and Emily Shaffer's hook subsystem refactoring series (v2, 10 parts) completes the conversion of Git's remaining hooks to the new `hook.h` API, building on extensive v1 feedback. The series modernizes hook infrastructure with stdin callbacks (`feed_pipe_fn`), output capture (`consume_sideband_fn`), and batched processing while maintaining backward compatibility. Key technical changes in v2 include: ungroup option override mechanism, stricter `BUG()` enforcement for mutually exclusive stdin methods, simplified post-rewrite and pre-push callbacks with strbuf reuse, reference-transaction callback redesign to match pre-push patterns, and removal of problematic keepalive logic in update hooks. Implementation spans `run-command.c` parallel process handling, `hook.c` API extensions, and conversions in `receive-pack.c`, `sequencer.c`, and `transport.c`.

Unresolved items from v1 feedback remain the file descriptor `0` vs `-1` convention (unchanged due to `run-command.h` API constraints) and SIGPIPE handling staying outside `pp_buffer_stdin()` to avoid excessive calls. The series establishes consistent callback patterns and explicitly documents `feed_pipe_ctx` resource ownership rules, preparing for future work on config-based hooks and parallel execution.
