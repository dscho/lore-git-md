This is the foundational patch in the Rust infrastructure series, adding Meson build system integration for optional Rust compilation. As the first of 9 patches in v7, it establishes the build machinery while maintaining backwards compatibility, with Rust remaining optional in Git 2.52 before planned mandatory adoption in Git 3.0.

The patch introduces several key components: a `Cargo.toml` defining the "gitcore" crate (renamed from "git" to avoid Windows/MSVC conflicts), Meson build rules for Rust detection and compilation, and a `cargo-meson.sh` wrapper script to handle build artifacts. The implementation targets Rust 2018 edition for compatibility with gcc-rs, though this may be revisited if newer Rust features are needed. Rust tests are wired into Meson's test runner, though the initial `lib.rs` is empty (actual functionality comes in later patches).

Notable technical choices include the `-`Drust=` build toggle, static library output configuration, and careful handling of build directories. The patch maintains the series' phased adoption approach while addressing prior feedback about Windows/MSVC compatibility through the crate rename. As this is infrastructure-only, there are no behavioral changes to Git itself - subsequent patches will introduce actual Rust implementations.

The patch appears production-ready with thorough build system integration and test wiring. It follows the established pattern of the series by being minimally invasive to the existing codebase while providing necessary hooks for Rust development. The commit message clearly explains the temporary nature of the Rust 2018 edition constraint and the optional/experimental status of this initial implementation.
