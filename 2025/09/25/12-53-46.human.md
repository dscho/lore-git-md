Hook subsystem refactoring: converting the post-rewrite hook to use the new hook.h interface.

This is the third patch in a 10-part series modernizing Git's hook subsystem. It converts the post-rewrite hook implementation in sequencer.c to use the new `hook.h` interface rather than manually constructing a `child_process`. The change simplifies the code by centralizing signal handling and process management in `run-command.c` while maintaining the same functionality.

The patch introduces a new `pipe_from_strbuf` helper that handles feeding input to the hook process via the new streaming callback mechanism. This replaces the direct file descriptor manipulation in the original implementation. The change also includes some related cleanup in the rebase handling code, though the core functionality remains unchanged.

The commit carries signatures from three contributors (Emily Shaffer, Ævar Arnfjörð Bjarmason, and Adrian Ratiu), indicating this builds on prior collaborative work. The implementation looks clean and focused, with clear error handling and proper resource cleanup. This appears to be a straightforward conversion that moves the code toward the series' goal of unified hook handling while maintaining backward compatibility.
