This is a minor build system adjustment in the Rust infrastructure series. Ramsay Jones confirms Patrick Steinhardt's patch to reorder Makefile sources after includes, which will allow conditional compilation based on `WITH_RUST` flags in config.mak. Jones notes he had independently made a similar change to avoid needing to specify `WITH_RUST=false` repeatedly on Cygwin builds.

The change is straightforward and uncontroversial, with Jones explicitly thanking Steinhardt for including it. This appears to be a small but practical improvement to the build system that multiple developers have found useful when working with the optional Rust components. The patch is part of the foundational work (patches 1-4) preparing Git's build system for Rust integration.
