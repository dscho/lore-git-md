This is a formatting patch adjusting clang-format rules for the Git codebase. It changes how spaces are handled before parentheses in control macros.

The patch modifies `.clang-format` to use `ControlStatementsExceptControlMacros` instead of `ControlStatements` for the `SpaceBeforeParens` setting. This prevents clang-format from adding spaces between control macros (like `if`, `while`, etc.) and their parentheses, which matches Git's existing coding style conventions. The change is minimal (just one line modified) and comes with a clear explanation of why it's needed - the project doesn't typically expect spaces in these cases.
