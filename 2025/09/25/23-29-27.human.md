Feature patch adding machine-readable output formats to `git repo stats`.

This is patch 6/7 in Justin Tobler's series introducing the new `git repo stats` command. It adds `--format` options for machine-parsable output alongside the existing human-readable table format. The patch introduces two new formats:

1. `keyvalue`: Each statistic appears as a key=value pair, one per line, with special characters quoted as needed (similar to `core.quotePath` behavior). This is useful for simple parsing by scripts.

2. `nul`: Uses NUL-delimited records with newline-separated keys/values, avoiding any quoting requirements. This is designed for robust handling of arbitrary data in pipeline processing.

The implementation adds format selection to both the command-line interface and documentation, with thorough test coverage verifying both formats against expected output. The changes maintain backward compatibility by keeping the table format as default.
