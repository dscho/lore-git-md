This thread documents a multi-year effort to modernize Git's hook subsystem, led by Adrian Ratiu and Emily Shaffer. The current series (v7, 12 parts) standardizes hooks on a new `hook.h` API while introducing parallel execution support through a `struct parallel_child` infrastructure. The changes maintain backward compatibility while preparing for future config-based hooks.

The latest development is a performance optimization addressing throughput issues in parallel hook processing. Kristoffer Haugsbakk reported and Jeff King diagnosed a problem where the original implementation introduced 100ms latencies during parallel execution. The fix modifies I/O polling in `run-command.c` to monitor both input and output descriptors simultaneously, eliminating the bottleneck while preventing deadlocks from full pipes. Junio Hamano has reviewed the technical approach but raised a question about edge case handling with stdin descriptors that may need addressing.

The series has incorporated feedback from multiple contributors, including Jeff King (sideband output), brian m. carlson (stdout/stderr handling), and Chris Darroch (pre-push regression fixes). It has reached maintainer consensus with approvals from both Patrick Steinhardt and Junio Hamano, representing the culmination of careful design work to modernize this core subsystem. The changes provide the foundation for future enhancements while maintaining Git's stability and backward compatibility.
