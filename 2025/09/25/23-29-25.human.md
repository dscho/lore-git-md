This is the fourth patch in a series introducing a new `git repo stats` command, focusing on reference counting functionality. The patch adds the core `stats` subcommand that reports repository health metrics, starting with reference counts by type (branches, tags, remotes, and others).

The implementation provides human-readable table output similar to git-sizer, with auto-adjusting column widths. The initial version counts references by walking all refs and categorizing them using the existing ref-filter infrastructure. The patch includes thorough tests verifying output for both empty repositories and those with various reference types.

This appears to be a well-structured implementation with clear documentation and test coverage. The output format is explicitly marked as unstable for machine parsing, leaving room for future evolution. The patch builds on previous infrastructure work in the series (ref-filter NULL pattern handling and clang-format adjustments) while introducing the first user-visible feature of the new command.
