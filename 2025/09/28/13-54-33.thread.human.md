This thread addresses improvements to gitk's window geometry persistence, combining work from Johannes Sixt (Hannes) and Michael Rappazzo. The series restores full window position and size saving across sessions, fixing a limitation that had persisted since an old Cygwin Tcl/Tk workaround. The first patch, signed off by Johannes Sixt, reverts a previous change to enable main window position handling. The second patch, now in its third iteration, extends this to the Tags/Heads windows using Sixt's proven geometry management approach rather than the author's solution.

The Tags/Heads patch stores window geometry as `geometry(showrefs)` in the config file, maintaining position relative to the main window. It introduces several Tcl procedures to handle saving, restoring, and tracking the geometry, with careful attention to timing through delayed `Map` event binding to avoid race conditions. The changes are confined to gitk's Tcl code and don't affect core Git functionality. With no outstanding technical objections noted, this series appears ready to address a long-standing user experience issue where windows needed manual repositioning between sessions.
