This thread discusses a two-patch series that improves how gitk remembers window sizes and positions across sessions. The changes modernize gitk's window management by fully restoring both the main window and Tags/Heads window geometry (position and size) on all platforms, removing old workarounds from 2008 that were needed for Cygwin's outdated Tcl/Tk version.

Johannes Sixt (Hannes) has led the effort, building on initial work from Michael Rappazzo and historical context from Mark Levedahl. The first patch reverts an old compromise that only saved window sizes (not positions) due to multi-monitor issues with Cygwin's Tcl/Tk 8.4.1 - a limitation that became obsolete in 2011. The latest revision improves the commit message to better document this history while maintaining the technical change. The second patch provides a clean solution for the Tags/Heads window with Windows-specific handling.

All technical aspects have been resolved through several iterations, with Johannes refining the implementation to be both complete and minimal. Junio Hamano provided some editorial suggestions but has indicated he'll defer to gitk maintainer Paul Mackerras for final inclusion. The series appears ready to merge, solving a long-standing user experience issue now that platform limitations no longer require workarounds.
