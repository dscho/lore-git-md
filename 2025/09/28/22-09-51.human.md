This is part 40 of Taylor Blau's ongoing series to refactor `builtin/repack.c` into modular components while removing global variables. The patch introduces a new `struct write_pack_opts` to consolidate common parameters used by pack-writing functions.

The repack code has several functions that write different types of packs (`write_filtered_pack`, `write_cruft_pack`), which currently take many similar parameters individually. This patch bundles those parameters (pack objects arguments, destination path, pack prefix) into a single options struct, making the function signatures cleaner and reducing parameter-passing boilerplate. It also adds two new fields (`packdir` and `packtmp`) that were previously accessed as static variables.

The change is purely structural - no behavior is modified. This continues the series' pattern of methodically extracting and parameterizing functionality while maintaining existing behavior. The new struct is added to `repack.h` since it will be used by multiple functions across the repack module.

This is another incremental step in the larger effort to modernize the repack codebase by eliminating globals and improving modularity.
