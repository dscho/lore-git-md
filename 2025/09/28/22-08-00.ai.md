This is the 13th patch in a 49-part series refactoring `builtin/repack.c` as part of the `the_repository` removal effort and preparation for incremental MIDX-based repacking.

The patch moves the static `delta_base_offset` variable into `struct pack_objects_args`, where it logically belongs as a property of individual pack-objects commands. This continues the series' pattern of converting global state into properly encapsulated configuration. The variable controls whether `--delta-base-offset` is passed to pack-objects and was originally introduced in 2013 when repack was rewritten in C.

Key technical changes:
- Adds `delta_base_offset` field to `struct pack_objects_args` with default value 1
- Updates config handling to store the value in the struct rather than the static variable
- Modifies pack-objects command preparation to read from the struct
- Ensures the cruft pack configuration inherits the same delta_base_offset setting
- Introduces `PACK_OBJECTS_ARGS_INIT` macro to initialize the struct with default values

The change is straightforward and maintains existing behavior while removing another piece of global state. It follows the series' established pattern of moving configuration into parameter structs, though this particular variable wasn't caught in the earlier `pack_objects_args` introduction in 2022. The patch enables further code movement in subsequent commits by completing the struct's encapsulation of pack-objects configuration.
