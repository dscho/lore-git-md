This is patch 34/49 in Taylor Blau's ongoing series to refactor `builtin/repack.c` into modular components while eliminating global variables. The series prepares for incremental MIDX-based repacking and modernizes the repack machinery.

The patch moves MIDX pack name tracking into the `existing_packs` struct, eliminating a separate `midx_pack_names` parameter that was being passed around. The change simplifies the code by:
- Adding a `midx_packs` string_list to `existing_packs`
- Collecting MIDX pack names during the existing pack collection loop
- Removing standalone MIDX pack name handling from `cmd_repack()`
- Updating related functions to use the embedded list

The change maintains the same behavior while reducing parameter passing and centralizing pack tracking. The author notes the importance of checking for MIDX packs before other pack filtering conditions to preserve the existing behavior of including non-local packs in MIDX tracking.

This continues the series' pattern of replacing ad-hoc data structures with standardized Git types and consolidating related functionality. The patch is a straightforward structural improvement that builds on prior work to modularize the repack code.
