This is patch 48/49 in Taylor Blau's major refactoring series to modularize `builtin/repack.c` and remove global variables. The patch moves the `write_cruft_pack()` function into a new `repack-cruft.c` module, following the established pattern of the series.

The function handles cruft pack generation during repacking, including expiration of old objects and combining small cruft packs. The patch preserves all existing behavior while relocating the code, including the helper function `combine_small_cruft_packs()`. The function is now exposed through `repack.h` for use by other modules.

This continues the series' systematic approach: first parameterizing dependencies (done in earlier patches), then extracting cohesive functionality into dedicated modules. The change is mechanical but important for the long-term goal of making the repack codebase more maintainable and preparing for future MIDX-based incremental repacking functionality.

With this patch, only one more remains in the series to complete the modularization of `builtin/repack.c`. The work demonstrates careful attention to maintaining existing behavior while modernizing the code structure.
