This is patch 44/49 in Taylor Blau's series refactoring `builtin/repack.c` to modularize the code and remove global variables, as part of the broader effort to enable incremental MIDX-based repacking.

The patch continues the series' methodical approach by modifying `finish_pack_objects_cmd()` to take a `write_pack_opts` struct parameter instead of individual fields. This eliminates the need to pass the `local` flag explicitly, since that can now be determined by calling the new `write_pack_opts_is_local()` helper introduced in the previous patch. It removes direct dependency on the static `packtmp` variable by accessing it through the opts struct instead.

Three call sites are updated to accommodate these changes. Two existing callers in `write_cruft_pack()` and `write_filtered_pack()` already have the opts struct available, while the third caller in `cmd_repack()` needs to initialize a new opts struct to pass the required fields. The changes are straightforward and maintain the same behavior while moving toward better encapsulation.

This is another incremental step in the series' goal of breaking down the monolithic repack implementation into smaller, more focused modules with clearer interfaces. The patch follows the established pattern of small, behavior-preserving changes that gradually eliminate global state and improve code organization.
