This is patch 30/49 in Taylor Blau's ongoing series to refactor `builtin/repack.c` as part of the `the_repository` removal and MIDX repacking preparation work. The patch moves the entire pack geometry API out of `builtin/repack.c` into a new `repack-geometry.c` module, completing its isolation from the main repack code.

The change is a straightforward code movement - 235 lines are deleted from `builtin/repack.c` and nearly identical code is added to the new module, with the functions now properly exposed in `repack.h`. The pack geometry functionality (which handles geometric progression calculations for packfiles) remains behaviorally identical, just better organized.

This continues the series' pattern of incrementally extracting cohesive components into separate modules while eliminating global state dependencies. The patch follows the established methodology and appears mechanically sound, with proper updates to both Makefile and meson.build to include the new source file.

As with previous patches in the series, this is a preparatory step toward the larger goal of enabling incremental MIDX-based repacking while modernizing the codebase's architecture. The work remains focused and well-executed, maintaining the high standard set by earlier patches.
