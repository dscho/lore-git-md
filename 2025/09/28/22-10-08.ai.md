Refactoring patch in the ongoing `builtin/repack.c` modularization series. This is patch 43/49 in Taylor Blau's incremental MIDX preparation work, continuing the encapsulation of repack functionality into dedicated modules.

The patch extracts duplicate local-pack detection logic from `write_cruft_pack()` and `write_filtered_pack()` into a new helper function `write_pack_opts_is_local()`. The function determines if a pack destination is local by checking if it begins with the pack directory path, using the existing `skip_prefix()` pattern but now properly encapsulated within the `repack.c` module.

Key technical changes:
- Introduces `write_pack_opts_is_local()` in `repack.c` that operates on `struct write_pack_opts`
- Removes duplicate `skip_prefix()` calls and temporary `scratch` variables from both pack-writing functions
- Adds function declaration to `repack.h` interface
- Maintains identical behavior while reducing code duplication
- Follows the series' established pattern of methodical extraction and encapsulation

The commit notes this leaves remaining duplication (both functions still call the new helper) to be addressed in the next patch. This continues the series' disciplined approach of making small, focused changes that incrementally improve the architecture while maintaining behavioral consistency. The change fits naturally with the prior extraction of `write_pack_opts_pack_prefix()` in patch 42.
