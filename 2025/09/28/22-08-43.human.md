This is patch 24 in Taylor Blau's 49-part series refactoring `builtin/repack.c` to remove global variables and prepare for incremental MIDX-based repacking. The patch moves the "generated_pack" API - which handles temporary packfile creation and installation - out of `builtin/repack.c` and into the new `repack.c` module.

The change is a significant but mechanical relocation of code that:
- Defines packfile extensions (.pack, .idx, etc.) and their optional status
- Manages temporary files during pack creation
- Handles the atomic installation of completed packs
- Includes error checking for required files

This continues the series' pattern of incrementally extracting functionality from the monolithic `builtin/repack.c` into focused modules. The patch maintains all existing behavior while making the code more modular and removing another chunk from the original 1700+ line file. The change appears well-contained and follows the established approach of the series.
