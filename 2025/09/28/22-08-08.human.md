Refactoring patch in the ongoing `builtin/repack.c` modularization series. This is patch 15/49 in Taylor Blau's effort to modernize Git's repack machinery while removing global variables.

The patch standardizes function naming conventions for operations on the `struct existing_packs` type, following documentation established in commit 541204aabe. Functions that operate on the collection are renamed to use the plural `existing_packs_` prefix, while those working with individual pack entries use `existing_pack_`. The changes are purely mechanical - no behavior is altered, just making the codebase more consistent.

This continues the series' pattern of methodical, incremental changes that improve code organization while maintaining functionality. The renaming helps clarify the scope of operations and prepares for further modularization work. As with previous patches, this demonstrates careful attention to detail in the refactoring process.
