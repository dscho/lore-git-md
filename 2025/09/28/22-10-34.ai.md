This is the 48th patch in a 49-part series refactoring `builtin/repack.c` into modular components while removing global variables. The patch moves the cruft pack writing functionality (`write_cruft_pack()`) into a new `repack-cruft.c` module, following the established pattern of the series.

The cruft pack handling is extracted with all its supporting logic intact, including:
- Cruft pack expiration handling via `--cruft-expiration`
- Small cruft pack combining below a configurable size threshold
- Interaction with the existing pack tracking system (`existing_packs`)
- Integration with the pack-objects command via `prepare_pack_objects()` and `finish_pack_objects_cmd()`

The patch maintains all existing behavior while making the function available through the repack.h API. Like previous extractions in the series, this follows the methodology of first parameterizing dependencies (already done in earlier patches) before relocating functionality to a new module. The change is mechanical - the diff shows the function being moved verbatim from `builtin/repack.c` to the new location with only the necessary header adjustments.

This continues the series' systematic elimination of `the_repository` usage, as the function already operates on repository state through the parameterized `existing_packs` struct. The patch updates both Makefile and meson.build to include the new compilation unit. With only one patch remaining in the series, this represents the penultimate step in modularizing the repack functionality.
