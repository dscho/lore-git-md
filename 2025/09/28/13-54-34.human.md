This is a revert patch that's part of a series improving gitk's window geometry persistence. It undoes a 2011 workaround that restricted gitk to only restoring window sizes (not positions) on Windows/Cygwin systems using an outdated Tcl/Tk 8.4.1. The original workaround is no longer needed since Cygwin has long since upgraded to Tcl/Tk 8.6.

The change is straightforward - it removes the size-only restoration logic and reverts to simply applying the full geometry string (including position) from the saved configuration. This is the first of two patches in the series, with the second patch building on this to add persistence for the Tags/Heads windows.

The patch appears well-justified, with Johannes Sixt providing historical context about why the original workaround can now be safely removed. The change is small (12 lines net) and focused entirely on gitk's Tcl code, with no impact on core Git functionality. This looks like a solid quality-of-life improvement for gitk users.
