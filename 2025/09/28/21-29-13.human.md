This is a feature patch series introducing support for optional filepaths in Git configuration and command-line options, building on Junio Hamano's earlier work. The series is a v2 revision addressing the use case of gracefully handling missing files like commit templates or blame ignore files.

The three patches:
1. Improve test independence in t7500 by using `--allow-empty` (a preparatory change)
2. Add `:(optional)` prefix support for config file paths, skipping missing files silently
3. Extend the same `:(optional)` behavior to command-line file options

Key changes in v2:
- Now only checks for missing files (not empty ones)
- Better test organization
- Added documentation in gitcli(1) for command-line usage
- The implementation introduces new helper `is_missing_file()` while keeping the existing `is_empty_or_missing_file()`
- The syntax is designed to be extensible for future variants

The author expresses some reservations about the parse-options implementation approach, suggesting pathspec integration might be cleaner but acknowledges the complexity. The series appears well-tested and documented, with clear motivation for the feature. It builds on established work while making thoughtful refinements to the behavior.
