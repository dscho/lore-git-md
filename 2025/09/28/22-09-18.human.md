This is patch 33/49 in Taylor Blau's series refactoring `builtin/repack.c` to modularize the code and remove global variables, particularly as preparation for incremental MIDX-based repacking. The patch focuses on improving the handling of pack names when writing MIDX files.

The change replaces an array of character pointers tracking MIDX pack names with a `string_list` structure, which provides a more convenient API for string collection management. This simplifies the code by eliminating manual memory management (allocations and frees) and reduces the number of parameters needed for the `midx_has_unknown_packs()` function. The modification maintains the same behavior while making the code more maintainable.

This continues the series' pattern of converting direct parameter passing to structured approaches, in this case using Git's standard string_list utilities. The change is relatively straightforward but contributes to the larger goal of making the repack codebase more modular and easier to work with. The patch appears well-contained and follows the established pattern of the series.
