Refactoring patch in the ongoing repack.c modularization series. This is patch 47/49 in Taylor Blau's effort to break up the large `builtin/repack.c` file into focused components while also removing global variables like `the_repository`.

The patch moves `write_filtered_pack()` - a function that handles pack filtering during repacking - out of `builtin/repack.c` and into a new `repack-filtered.c` module. The function becomes part of the repack.h API while maintaining all its existing behavior. This continues the series' pattern of:
1. Identifying cohesive functionality
2. Moving it to a dedicated module
3. Maintaining the same interface via repack.h

The change is mechanical - the diff shows the function being copied verbatim to its new location while being removed from the builtin. The patch updates build files (Makefile and meson.build) to include the new compilation unit.

This is part of the larger effort to prepare for incremental MIDX-based repacking while modernizing the codebase by removing globals. The series has been consistently well-executed, with each patch following the same careful methodology of parameterization before relocation.
