This is patch 30/49 in Taylor Blau's series refactoring `builtin/repack.c` to modularize the code and remove global variables, part of the broader `the_repository` removal effort and preparation for incremental MIDX-based repacking.

The patch completes the extraction of the pack geometry API from `builtin/repack.c` into its own module. It moves all pack geometry-related functions (`pack_geometry_init`, `pack_geometry_split`, etc.) and the `struct pack_geometry` definition to new files `repack-geometry.c` and `repack.h`. The implementation is a direct code move with no behavioral changes - 235 lines are removed from `builtin/repack.c` and 233 nearly identical lines are added to the new file.

Key technical details:
- The pack geometry API handles geometric progression calculations for packfiles during repacking
- All functions now properly declared in `repack.h` with external linkage
- Maintains the series' pattern of parameterizing dependencies rather than using globals
- Follows the established methodology: identify cohesive functionality, parameterize, extract with minimal changes
- Build system updated to compile new module (Makefile and meson.build changes)
