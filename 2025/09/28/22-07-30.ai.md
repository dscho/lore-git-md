This is the fifth patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` while removing `the_repository` global usage, part of both the incremental MIDX preparation and `the_repository` removal efforts.

The patch modifies the promisor object repacking functionality to accept and use an explicit `struct repository*` parameter instead of relying on `the_repository`. The key change is in `repack_promisor_objects()`, which now takes a repository parameter and passes it through to `for_each_packed_object()`. The calling site in `cmd_repack()` is updated to provide the repository pointer.

The changes are straightforward and maintain the same behavior while removing 3 more `the_repository` accesses. The patch continues the series' pattern of methodically converting repository access patterns while keeping the focus on promisor pack handling. The modification touches the same critical path for repacking promisor objects that was previously converted in earlier patches, maintaining consistency in the repository pointer passing approach.
