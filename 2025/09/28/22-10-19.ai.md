This is the 45th patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` as part of the incremental MIDX-based repacking effort (tb/incremental-midx-part-3). The patch continues the series' pattern of modularizing repack functionality while removing global variable dependencies.

The patch moves `finish_pack_objects_cmd()` from `builtin/repack.c` to the new `repack.c` module, following the established methodology of extracting functions once they no longer have builtin-specific dependencies. The function handles post-processing of pack-objects output, verifying object ID formats and populating pack metadata. The implementation remains unchanged - it just changes location and gains a declaration in `repack.h`.

Key technical details:
- Maintains all existing behavior including hash algorithm validation via `algop` parameter
- Continues using the `write_pack_opts` struct introduced earlier in the series
- Preserves the `generated_pack_populate()` helper interaction
- Follows the series' naming conventions and parameter patterns

This extraction prepares for future patches to similarly move `write_cruft_pack()` and `write_filtered_pack()`, completing the isolation of pack-writing functionality from the builtin. The change is part of the broader effort to make the repack machinery more modular and suitable for incremental MIDX operations while eliminating `the_repository`/`the_hash_algo` usage.
