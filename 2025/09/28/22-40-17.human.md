This is a feature patch series adding support for optional file paths in Git configuration and command-line options. The series builds on Junio Hamano's earlier work introducing the `:(optional)` prefix mechanism, with D. Ben Knoble now completing the implementation by adding command-line option support.

The key improvement in v2 is removing the special handling of empty files, now only distinguishing between missing files (silently skipped) and present files (processed normally). The series maintains consistent behavior between config variables and CLI options, using the same `:(optional)` prefix syntax in both contexts.

Junio Hamano reviews the series positively, noting the clean API design in the config pathname handling and agreeing with the simplified file existence checking approach. He specifically rejects the idea of extending this to pathspec magic, explaining that pathspecs already handle non-matching patterns gracefully by design.

The series appears ready for merging with comprehensive test coverage, clear documentation updates, and maintained backward compatibility. Junio indicates he will queue the patches, marking successful completion of this effort to support optional files across Git's interfaces.
