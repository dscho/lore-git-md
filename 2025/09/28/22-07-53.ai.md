This is the 11th patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` as part of both the incremental MIDX work and `the_repository` removal effort. The patch introduces a new compilation unit for repack functionality by moving `struct pack_objects_args` and its associated cleanup function into new `repack.[ch]` files.

The change extracts the pack objects argument handling from the monolithic `builtin/repack.c`, which has grown to over 1700 lines handling multiple repack-related features. The patch creates basic infrastructure for future modularization by:
- Defining `repack.c` and `repack.h` with the moved `pack_objects_args` struct and `pack_objects_args_release()` function
- Updating both Makefile and Meson build systems to include the new compilation unit
- Keeping identical functionality while establishing a new organizational boundary

This appears to be the first step in breaking down `builtin/repack.c` into focused components, with the pack objects argument handling being a natural first candidate due to its self-contained nature. The patch maintains all existing behavior while setting up infrastructure for more complex extractions to follow in subsequent patches. The changes are mechanical and straightforward, focused solely on code organization without introducing new functionality or behavior changes.
