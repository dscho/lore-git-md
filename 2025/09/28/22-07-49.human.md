This is the 10th patch in a 49-part series refactoring `builtin/repack.c` as part of both the `the_repository` removal effort and preparation for incremental MIDX-based repacking.

The patch removes the last straightforward use of `hash_to_hex()` in the pack geometry code, replacing it with `hash_to_hex_algop()` which takes an explicit hash algorithm parameter. This continues the series' pattern of eliminating dependencies on the `the_repository` global by using repository-specific hash algorithm where needed.

The change is mechanical but meaningful - it removes one of the final convenience functions that only exist when `USE_THE_REPOSITORY_VARIABLE` is defined. The author notes they're hitting a natural stopping point here, as converting the remaining `is_bare_repository()` would require more involved changes.

This is a clean, focused change that maintains the series' disciplined approach to global variable removal. The patch follows the established pattern of passing algorithm parameters through the call chain while keeping behavior identical. It represents steady progress on both the modularization and modernization goals of this large refactoring effort.
