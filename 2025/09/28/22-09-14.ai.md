Refactoring patch in the ongoing `the_repository` removal and repack modularization series. This is patch 32/49 in Taylor Blau's incremental MIDX work, focusing on extracting the MIDX pack writing functionality from `builtin/repack.c`.

The patch introduces a new `repack_write_midx_opts` struct to consolidate the six parameters (plus two new ones needed for extraction) previously passed to `write_midx_included_packs()`. This follows the series' pattern of replacing direct parameter passing with structured configuration when extracting functionality from the monolithic repack implementation.

Key technical changes:
- Defines new `repack_write_midx_opts` struct with 9 fields covering all MIDX-writing parameters
- Converts `write_midx_included_packs()` to take the opts struct pointer instead of individual parameters
- Updates all internal references to use the struct fields
- Maintains identical behavior while enabling future extraction of this function
- Adds `packdir` and `midx_must_contain_cruft` parameters that were previously static variables

The change is mechanical but important for the series' goal of modularizing repack functionality. It demonstrates the progression from direct parameter passing to encapsulated configuration as functions move toward becoming standalone components. The patch maintains the series' careful approach of behavioral equivalence while restructuring.

This continues the pattern seen in earlier patches of the series where cohesive functionality is first parameterized, then extracted. The opts struct approach will likely be reused as more repack components are modularized in subsequent patches.
