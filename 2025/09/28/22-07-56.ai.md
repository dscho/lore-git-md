This is the twelfth patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` as part of the `the_repository` removal effort and preparation for incremental MIDX-based repacking. The patch focuses on configuration handling during repacking operations.

The change introduces a new `struct repack_config_ctx` to pass both cruft and non-cruft `pack_objects_args` structures to the `repack_config` callback function. This prepares for a future change that will move the `delta_base_offset` variable from being a static in `builtin/repack.c` to becoming a member of `pack_objects_args`. The patch maintains the existing behavior while enabling this future refactoring.

Key technical details:
- New `repack_config_ctx` struct holds pointers to both regular and cruft `pack_objects_args`
- Updates `repack_config` callback to use the context struct instead of direct `pack_objects_args` pointer
- Modifies `cmd_repack` to initialize and pass the context struct to `repo_config`
- Maintains all existing configuration handling logic while changing the parameter passing mechanism

This continues the series' pattern of methodical refactoring while preserving behavior, with each change enabling subsequent steps in the larger `the_repository` removal and modularization effort. The patch is narrowly focused on configuration handling and doesn't introduce any new functionality or behavior changes.
