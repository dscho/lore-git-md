This is patch 31/49 in Taylor Blau's series refactoring `builtin/repack.c` for modularity and `the_repository` removal. The patch extracts reference snapshotting functionality into a new `repack-midx.c` module.

The patch moves the MIDX reference snapshotting code that was previously in `builtin/repack.c` into a new dedicated module. This functionality creates a temporary file containing a snapshot of repository references, which is used by `git multi-pack-index write` to ensure consistent bitmap selections by avoiding races with concurrent reference updates. The core logic remains unchanged - it still peels references to commits, filters out non-commit objects, and marks preferred tips - but is now properly encapsulated in its own compilation unit.

Key technical details include:
- The new `repack-midx.c` contains the complete implementation of `midx_snapshot_refs()` and its helper `midx_snapshot_ref_one()`
- The `midx_snapshot_ref_data` struct is relocated to the new module
- Build system files (Makefile and meson.build) are updated to include the new source file
- The function is properly exposed via `repack.h` with its repository parameter
- 68 lines are removed from `builtin/repack.c` while adding 77 in the new module

This follows the series' established pattern of identifying cohesive functionality and extracting it with minimal changes while maintaining behavior. The extraction helps prepare for future incremental MIDX functionality by further modularizing the repack codebase.
