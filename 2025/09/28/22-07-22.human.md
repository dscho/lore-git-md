This is the third patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` as part of both the `the_repository` removal effort and preparation for incremental MIDX-based repacking. The patch continues the systematic elimination of the `the_repository` global variable, this time focusing on ref snapshotting functions used during MIDX creation.

The changes modify the `midx_snapshot_refs()` function and its helper data structure to store and use an explicit repository pointer rather than relying on the global variable. The patch updates several related functions that handle ref iteration and object peeling to use this stored pointer. The modifications are straightforward and maintain the existing behavior while modernizing the code to use proper repository parameter passing.

This is a typical incremental step in the larger series - well-contained, mechanically converting direct `the_repository` accesses to use the repository parameter that's already available in the calling context. The changes affect how Git interacts with refs and objects during repack operations, but don't introduce any functional differences. The patch follows the established pattern seen in earlier parts of the series, demonstrating careful attention to maintaining behavior while modernizing the codebase.
