This is a revert patch in the gitk window geometry persistence series, specifically targeting the main window's position restoration. The patch reverts commit b9bee11526ec that had previously stopped restoring window positions, limiting it to window sizes only. 

The original change was made to accommodate an outdated Cygwin Tcl/Tk 8.4.1 port that had layout engine bugs, but this became obsolete after Cygwin switched to a modern X11-based Tcl/Tk 8.6 in 2011. The revert removes the size-only restoration logic and simply restores the full window geometry (including position) when available in the config.

The technical change is straightforward - it replaces the complex size-only restoration code (with screen boundary checks) with a direct geometry restoration from the saved `geometry(main)` value. This is part of a larger effort to improve gitk's window persistence behavior, with this revert serving as the foundation for subsequent patches to properly handle window positions. The patch carries Johannes Sixt's sign-off and credits Mark Levedahl for assistance.

This change affects only the Tcl code in gitk's main window handling, with no impact on core Git functionality. The revert is well-justified by the outdated nature of the original workaround and aligns with the series' goal of improving window state persistence. The commit message clearly explains the historical context and rationale for the revert.
