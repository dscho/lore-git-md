This is patch 39/49 in Taylor Blau's series refactoring `builtin/repack.c` to support incremental MIDX-based repacking while removing global variables. The patch moves the `write_midx_included_packs()` function and its supporting code from `builtin/repack.c` to the new `repack-midx.c` module, completing the extraction of MIDX-specific logic from the main repack implementation.

The key changes are:
1. Relocates 305 lines of MIDX-related code from `builtin/repack.c` to `repack-midx.c` with minimal modifications
2. Makes `write_midx_included_packs()` a public function by moving its declaration to `repack.h`
3. Preserves all existing functionality including:
   - Pack inclusion logic for kept/non-kept/cruft packs
   - Bitmap handling
   - Progress reporting
   - Preferred pack selection
4. Maintains the `repack_write_midx_opts` struct interface for configuration

The patch follows the series' established pattern of first relocating code before refactoring it further. This continues the modularization effort while keeping the change focused and reviewable. The moved code handles core MIDX functionality that will be needed for the eventual incremental MIDX implementation.

Technical details for future reference:
- New public API: `write_midx_included_packs()` in `repack.h`
- Configuration via `repack_write_midx_opts` struct (moved to header)
- Key supporting functions moved: `midx_has_unknown_packs()`, `midx_included_packs()`, `remove_redundant_bitmaps()`
- Maintains all existing behavior flags: `show_progress`, `write_bitmaps`, `midx_must_contain_cruft`
- Continues using `pack_geometry` and `existing_packs` interfaces from earlier patches
