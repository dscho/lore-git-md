Final cleanup in the repack modularization series. This is the 49th and last patch in Taylor Blau's major refactoring of `builtin/repack.c`, which has systematically moved functionality into dedicated modules while eliminating global variable usage.

The patch removes now-unnecessary `#include` directives from `builtin/repack.c`, cleaning up after the extensive code movement in previous patches. The headers being removed (like `hex.h`, `strbuf.h`, and `pack-bitmap.h`) are no longer needed because their functionality has been moved to the new module files (`repack.c`, `repack-cruft.c`, etc.). This is a straightforward housekeeping change that completes the modularization effort.

The series as a whole has successfully transformed the repack implementation from a monolithic 1700+ line file into a set of focused modules with clear interfaces, while simultaneously removing `the_repository` usage. This work prepares the ground for future incremental MIDX-based repacking functionality.
