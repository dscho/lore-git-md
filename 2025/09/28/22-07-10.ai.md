This is a major refactoring series preparing for incremental MIDX-based repacking, splitting the monolithic `builtin/repack.c` into several focused compilation units. The series is part of a larger effort (tb/incremental-midx-part-3) but stands alone as preparatory cleanup.

The 49 patches systematically extract repack functionality into new modules under a `repack.h` API: repack-cruft.c, repack-filtered.c, repack-geometry.c, repack-midx.c, and repack-promisor.c. The changes are primarily code movement with minimal rewrites to maintain stability, though some `the_repository` and `the_hash_algo` cleanups are included.

Key technical aspects include:
- New structs like `pack_objects_args`, `write_pack_opts`, and `repack_write_midx_opts` to encapsulate parameters
- Existing APIs like `existing_packs`, `generated_pack`, and `pack_geometry` moved out of the builtin
- MIDX-related functions like `write_midx_included_packs` extracted
- Cruft pack and promisor object handling separated into dedicated files
- The end result reduces `builtin/repack.c` from 1700+ lines to a much smaller core while maintaining all functionality

The series appears carefully constructed with each commit doing minimal, focused work. The author notes most changes benefit from `--color-moved` review and emphasizes this is preparatory work for future incremental MIDX functionality rather than being strictly required for it. The extensive test coverage in Git's test suite should help validate no behavior regressions from the reorganization.
