This is patch 43/49 in Taylor Blau's ongoing refactoring of `builtin/repack.c` into modular components, part of the larger effort to enable incremental MIDX-based repacking while removing global variables.

The patch extracts duplicate logic from `write_cruft_pack()` and `write_filtered_pack()` into a new helper function `write_pack_opts_is_local()`. Both functions were checking whether a pack destination path was local by comparing it against the pack directory, using the same `skip_prefix()` pattern with a temporary "scratch" variable. The new helper encapsulates this check within the `repack.c` module and eliminates the redundant variable.

This continues the series' consistent methodology of identifying repeated patterns, extracting them into well-named functions, and cleaning up call sites. The change is straightforward and maintains the same behavior while reducing code duplication. As noted in the commit message, a follow-up patch will address the remaining duplication of the helper function calls themselves.

The patch fits neatly into the series' progression, building on the `write_pack_opts` struct introduced earlier and following the established pattern of moving functionality out of `builtin/repack.c` into the new modular components. The change is small but meaningful in the context of the larger refactoring effort.
