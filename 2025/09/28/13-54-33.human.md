This is a two-patch series improving window geometry handling in gitk, the Git repository browser. The series makes the "Tags" and "Heads" window positions persistent across sessions, building on previous work to restore main window geometry.

The first patch reverts an older change that stopped restoring window position (keeping only size restoration), bringing back full geometry persistence for the main window. The second patch then extends this persistence to the Tags/Heads windows, splitting the geometry management code into more focused functions along the way.

The v3 iteration incorporates existing work from another contributor (Johannes Sixt) for the window restoration piece, then adds the Tags/Heads persistence on top. The changes are focused and well-explained, with clean commit separation. This appears to be a straightforward quality-of-life improvement for gitk users who frequently work with tags and branches.
