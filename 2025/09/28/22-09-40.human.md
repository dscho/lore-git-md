Refactoring patch in the ongoing `builtin/repack.c` modularization series, part of the `the_repository` removal effort. This is patch 38/49 in Taylor Blau's incremental MIDX preparation work.

The patch simplifies MIDX pack handling by moving the responsibility for determining which packs to include directly into the `write_midx_included_packs()` function, rather than having the caller compute this list separately. This eliminates an awkward separation where `midx_included_packs()` would first generate the list and then pass it to `write_midx_included_packs()`.

The change makes the code more maintainable by:
1. Removing the `include` field from `repack_write_midx_opts` struct
2. Moving the `string_list` initialization inside `write_midx_included_packs()`
3. Cleaning up the string list immediately after use

This prepares for future work where different MIDX writing functions will each handle their own pack selection logic, rather than having a centralized selection routine. The patch follows the series' consistent methodology of incremental refactoring with no functional changes, maintaining the existing behavior while improving code organization.
