This is the 13th patch in a 49-part series refactoring `builtin/repack.c` to eliminate global variables and prepare for incremental MIDX repacking. The patch moves the `delta_base_offset` static variable into the `pack_objects_args` struct where it logically belongs.

The change is straightforward - `delta_base_offset` was previously a module-level static that determined whether to pass `--delta-base-offset` to pack-objects. The patch makes it a member of the `pack_objects_args` struct that already holds other pack-objects configuration, and initializes it to 1 (the previous default) via a new `PACK_OBJECTS_ARGS_INIT` macro.

This continues the series' pattern of moving repack configuration into proper structs rather than using globals. The change is mechanical but meaningful - it removes one more static variable while maintaining the same behavior. The patch is cleanly implemented with corresponding updates to the config callback and pack preparation code.

As with previous patches in the series, this appears to be a well-considered step in the larger refactoring effort, though the impact is incremental. The change helps pave the way for further modularization by keeping related configuration together in a single place.
