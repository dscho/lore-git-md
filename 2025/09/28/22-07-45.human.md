This is the ninth patch in Taylor Blau's 49-part series refactoring `builtin/repack.c` to remove global variables while preparing for incremental MIDX-based repacking. The patch continues the systematic elimination of `the_hash_algo` usage, this time modifying `finish_pack_objects_cmd()` to accept a hash algorithm parameter rather than using the global.

The change affects multiple call sites since `finish_pack_objects_cmd()` is used throughout the repack machinery, but each modification simply passes through the hash algorithm from an already-available repository pointer. The core behavior remains unchanged - the patch just ensures the hash algorithm comes from explicit parameter passing rather than global state.

This follows the series' established pattern of methodically converting global variable dependencies while maintaining existing functionality. The changes are straightforward and consistent with the broader effort to modernize the codebase's repository access patterns. As with previous patches in the series, this appears to be a clean, focused change that advances both the modularization goals and the `the_repository`/`the_hash_algo` removal initiative.
