This is the core implementation patch for the new `git repo stats` command, part of a series introducing repository health reporting functionality. The patch adds reference counting capabilities, categorizing refs by type (branches, tags, remotes, others) and displaying them in a human-readable table format.

The implementation introduces several key components:
- A `ref_stats` struct to track counts by reference type
- A `stats_table` system for formatting output with proper column alignment
- Internationalization support using `utf8_strwidth()` for correct display width calculation
- Comprehensive tests verifying output format and count accuracy

The command currently provides basic reference statistics similar to git-sizer, with plans to expand functionality in later patches. The table output is explicitly marked as not intended for machine parsing, leaving room for future machine-readable formats (which are added in patch 6/7).

The patch builds on earlier infrastructure work (merged patches 1/7 and 3/7) and has already incorporated feedback from Eric Sunshine regarding i18n support. It represents a solid foundation for the series' goal of providing native repository health metrics, with clean code organization and thorough test coverage.
