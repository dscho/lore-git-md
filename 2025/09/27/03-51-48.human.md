Feature patch series for Rust libgit implementation, now at v3 with expanded config parsing capabilities. This series builds on previous feedback to implement boolean, unsigned long, and pathname configuration parsing in the Rust libgit library.

The series consists of three patches: a documentation fix for PO README formatting (carried over from previous versions), the main boolean parsing implementation using Git's C FFI as directed by maintainers, and a new addition of `get_ulong()` and `get_pathname()` methods. The new v3 content expands the ConfigSet API with two additional methods: `get_ulong()` for large numeric values and `get_pathname()` for file paths, both following the same FFI-wrapped pattern. The implementation includes comprehensive tests for all new functionality.
