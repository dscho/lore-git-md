This is a feature patch in the `git repo stats` series, adding machine-readable output formats to the new repository statistics command.

Justin Tobler extends the `git repo stats` command with two new output formats alongside the default human-readable table: `keyvalue` (newline-delimited `key=value` pairs with c-quoting) and `nul` (NUL-delimited records with unquoted newline-separated keys/values). The `nul` format is particularly useful for handling values with special characters. The implementation introduces a `stats_keyvalue_print()` helper function that handles both formats with configurable delimiters.

The patch follows the series' established pattern of thorough testing, adding comprehensive format validation tests in t1901-repo-stats.sh. Documentation is updated to explain the new formats, including their quoting behavior differences. This builds on the reference and object counting functionality from previous patches in the series.

The implementation looks clean and well-tested, with clear separation between the formatting logic and the core statistics gathering. The choice of formats aligns with Git's existing output conventions, making it familiar to script authors. This appears ready for review, with the rest of the series, pending any feedback on the specific format choices.
