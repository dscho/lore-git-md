This is the core implementation patch (4/7) in the `git repo stats` series, introducing the reference counting functionality for the new repository statistics command. The patch adds a `git repo stats` subcommand that currently focuses on counting and categorizing references (branches, tags, remotes, and others) in a human-readable table format. The implementation includes:

- A `ref_stats` struct to track counts by reference type
- A `stats_table` system for formatting output with proper column alignment
- Internationalization support via `utf8_strwidth()` for correct display width calculation
- Comprehensive tests in t1901-repo-stats.sh covering empty repositories and various reference types

Key technical details:
- Uses `filter_refs()` from ref-filter.c to categorize references
- Implements dynamic column width adjustment based on content
- Follows git-sizer(1)'s table formatting style for consistency
- Handles translation of table headers and labels via gettext
- Includes test cases verifying both empty repository behavior and populated repository statistics

The patch builds on the earlier infrastructure preparation (patch 1/7's naming convention and patch 3/7's formatting rules) while laying groundwork for subsequent patches that will add object counting (5/7), machine-readable output formats (6/7), and progress reporting (7/7). Eric Sunshine's feedback about i18n support has been incorporated by using `utf8_strwidth()` for proper string width calculation.
