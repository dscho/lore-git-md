Documentation fix addressing an Asciidoctor rendering bug. This is a follow-up to Jean-Noël Avila's earlier patch that fixed formatting issues in Git's documentation when processed by Asciidoctor, where nested list items followed by continuation paragraphs incorrectly displayed "+" signs in the HTML output.

The patch makes two main changes: it removes a confusing reference to "straight plus signs" from the commit message (clarifying this was a typo), and provides concrete examples of the rendering artifacts in the live documentation (showing the "+" characters appearing before paragraphs in the config and pretty-format docs). The technical changes themselves remain the same as the previous version - using triple colons and explicit blocks to work around Asciidoctor bug #4704.

Jeff King had previously reviewed and improved the patch by adding detection tooling, while Junio Hamano requested clarification about the specific rendering issue. This version directly addresses that request by pointing to the exact locations in the rendered HTML where the problem manifests. The changes affect documentation for several config options (`compatObjectFormat`, `noop`, `objectFormat`) and the `%(decorate)` pretty format syntax.

The patch appears ready for merging, having gone through multiple rounds of review and now providing the requested clarification. It's a focused fix that maintains documentation consistency across processors without affecting Git's functionality.
