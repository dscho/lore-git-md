Feature patch expanding Rust libgit configuration parsing capabilities, part of a v3 series.

This patch adds two new methods to the Rust libgit implementation for parsing configuration values: `get_ulong()` for unsigned long integers and `get_pathname()` for file paths. It follows the same FFI-wrapped approach previously established for boolean parsing, maintaining consistency with Git's C implementation.

The changes include comprehensive test coverage for both new methods, handling edge cases like large numeric values (64-bit) and both relative/absolute paths. The implementation appears technically sound, with proper memory management and error handling. The patch builds on the already-approved boolean parsing approach but expands the scope to include these new value types.

This is the final patch in a series that also includes boolean parsing (patch 2) and a documentation fix (patch 1). While the technical implementation looks solid, the maintainers will need to confirm whether they want to accept this expanded scope beyond the originally discussed boolean parsing functionality. The tests demonstrate thorough coverage of the new functionality, and the code follows the same patterns as the approved boolean implementation.
