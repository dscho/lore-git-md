This is part of a feature series implementing configuration parsing in Rust for the `contrib/libgit-rs` project, specifically focusing on boolean value handling. Patch 2/3 adds a `get_bool()` method to the Rust `ConfigSet` that wraps Git's native `git_configset_get_bool()` C function through FFI.

The implementation handles all Git boolean formats (true/false, yes/no, on/off, 1/0) and edge cases like "00" and "100" consistently with Git's core behavior. The patch includes comprehensive tests covering these formats and missing key cases. The approach follows maintainer requirements from previous rounds to use FFI-wrapped C functions rather than reimplementing the logic in Rust.
