This is a clang-format configuration patch that's part of the `git repo stats` series (specifically patch 3/7). It adjusts Git's code formatting rules to better match the project's style for control macros like `if`, `while`, and `for`.

The change modifies the `.clang-format` file to exclude control macros from the "space before parentheses" rule, which means code like `if(...)` will remain without a space rather than being reformatted to `if (...)`. This matches Git's existing coding style where control macros typically don't have spaces before their parentheses.

The patch is small (just a one-line change) and has already been merged into the series. Since this is purely a formatting tweak that doesn't affect functionality, it was likely uncontroversial and merged early in the series review process.
