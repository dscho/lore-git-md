This is patch 5/7 in the `git repo stats` series, adding object counting functionality to the new repository statistics command. The patch extends the existing reference counting with reachable object statistics, categorizing them into commits, trees, blobs, and tags.

The implementation uses Git's path-walk API to traverse all objects reachable from regular references, counting them by type. The counts are displayed in the same formatted table as the reference statistics, with a new section for object data. The patch includes tests verifying both empty repositories and populated ones with various object types.

This builds on the foundation established in earlier patches, particularly the table formatting and reference counting from patch 4/7. The implementation appears thorough, with proper handling of different object types and integration with the existing statistics display system. The test coverage is comprehensive, checking both the empty case and a repository with multiple object types.

The patch follows the series' pattern of clean, focused changes with good test coverage. It moves the feature closer to completion by adding one of the key metrics users would expect from a repository health reporting tool. With this in place, the remaining patches in the series can focus on output formats (6/7) and progress reporting (7/7).
