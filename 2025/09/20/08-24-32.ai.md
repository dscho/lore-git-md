**Platform compatibility concerns in Rust adoption debate**

Florian Märkl contributes specific platform compatibility objections to the ongoing discussion about making Rust mandatory in Git. He highlights two PowerPC-based platforms that would be problematic: Mac OS X on PPC and OpenBSD/macppc (32-bit). These remain relevant because OpenBSD actively maintains this architecture, and MacPorts still supports Mac OS X 10.5, creating environments for testing and running legacy software.

Märkl provides concrete use cases from the Rizin project, where these platforms are actively used for architecture-specific testing and debugging. While not opposed to Rust itself, he emphasizes the need to evaluate the maturity of Rust's compiler and ecosystem before making it a hard dependency, particularly for projects that must support niche platforms.

This email expands the list of known Rust compatibility issues (now including PowerPC Mac OS X, OpenBSD/macppc, NonStop, and Gentoo) while introducing a new perspective from a project that actively maintains support for legacy systems. The technical focus remains on compiler support gaps, but the discussion now includes implications for projects that use Git as a dependency while needing to support older architectures.
