This is a refactoring patch in the xdiff preparation series for Rust compatibility. It removes the `xdl_get_rec()` helper function in favor of directly accessing record fields from the xdf->recs array.

The change simplifies the code by eliminating an indirection - instead of using a function to extract record fields, callers now access them directly. Junio C Hamano notes this makes the code easier to read, though he suggests the original commit message could better explain the motivation. The patch demonstrates the series' goal of cleaning up xdiff internals while maintaining identical behavior.

This is patch 4/10 in the now-merged preparatory series, which focused on non-Rust-specific cleanups. The change is purely internal - no user-facing behavior is affected. The series as a whole has been carefully reviewed and shows the kind of incremental improvement that makes code more maintainable while avoiding performance regressions.
