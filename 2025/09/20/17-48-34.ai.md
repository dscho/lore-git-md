This is a refactoring patch in the xdiff preparation series for Rust compatibility, specifically addressing the `xdl_get_rec()` helper function.

The patch removes `xdl_get_rec()` which was previously used to access fields of `xrecord_t` through an indirection. Junio Hamano provides feedback on the commit message wording, suggesting it should better explain that this is effectively inlining the function call rather than just removing an alias. The technical change replaces calls to `xdl_get_rec()` with direct access to the `xdf->recs[]` array, which contains the same `ptr` and `size` fields that were being retrieved through the helper function.

The change improves code readability by eliminating an unnecessary layer of indirection when accessing record data. All callers are updated to directly use the `recs[]` array elements, which are `xrecord_t` structs containing the needed fields. Junio confirms the updated code is easier to read and thanks the author for the improvement. This is part of the now-merged preparatory cleanups (patches 1-10) that maintain identical runtime behavior while simplifying the code structure.
