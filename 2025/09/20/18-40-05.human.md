This is a two-patch series improving window geometry persistence in gitk, the Git repository browser. The changes make both the main window and the "Tags and Heads" subwindow remember their size and position between sessions.

The first patch fixes an oversight where gitk would remember the main window's size but not its position when reopening. The second patch makes the "Tags and Heads" window (used for branch/tag navigation) remember its geometry too, switching from relative to absolute positioning for more reliable restoration.

The changes are straightforward - about 35 lines of Tcl code added across both patches - and address a minor but persistent usability issue. The v2 revision shows responsiveness to feedback by expanding the scope to include window positioning, not just sizing. This appears to be a well-scoped quality-of-life improvement for gitk users who frequently reposition these windows.
