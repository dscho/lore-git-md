This is the second patch in a two-part series improving gitk's window persistence, specifically addressing the Tags and Heads window behavior. While the first patch handled the main window, this one makes the Tags and Heads window remember its size and position between sessions.

The patch stores the window geometry in gitk's config file under `geometry(showrefs)`, maintaining the window's position relative to the main gitk window. This ensures consistent placement across different monitor setups. The implementation adds new Tcl/Tk procedures to save and restore the geometry, plus proper cleanup handling when the window closes.

The changes look thorough, with clear additions to both the save/restore logic and window management. The patch maintains the existing code style and adds appropriate bindings for window events. This should provide a noticeable quality-of-life improvement for gitk users who frequently work with the Tags and Heads window.
