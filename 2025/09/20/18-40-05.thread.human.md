This thread is about improving gitk's window persistence between sessions. Johannes Sixt (Hannes) has sent a two-patch series to fix issues where gitk windows don't reliably remember their positions. The first patch in v2 addresses the main window's position restoration, completing the geometry persistence that previously only handled window size. It modifies the Tcl/Tk code to use an `after idle` callback when restoring window geometry, ensuring proper timing across different operating systems.

The second patch in the series (not yet summarized here) handles persistence for the Tags and Heads windows. So far there haven't been any reviews or discussion of the patches, but the changes appear to be straightforward technical fixes for specific UI quirks in gitk's window management. The series is a standalone improvement to gitk's behavior and isn't tied to any other in-flight topics.
