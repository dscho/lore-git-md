This is a follow-up in the gitk macOS window focus bug thread. Eric Sunshine points out that a fix already exists for this issue - a patch he submitted back in 2018 that would make the `osascript` call non-fatal when unavailable. The patch was never merged at the time due to inactive gitk maintainership, but Eric suggests the current maintainer (CC'd) could now pick it up.

The original bug report from Robert Scott noted that gitk fails completely when `osascript` isn't in PATH (common in environments like Nix shells), despite this being just a quality-of-life feature for window focusing. Eric's old patch would solve this by gracefully handling the missing command case.

This email moves the discussion forward by identifying an existing solution, though it remains to be seen if the current maintainer will act on it. The patch appears well-vetted (having been publicly posted years ago) and directly addresses the reported issue without introducing new complexity.
