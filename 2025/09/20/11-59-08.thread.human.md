This thread addresses a macOS-specific issue in gitk where the program fails completely if the `osascript` command (used for window focusing) isn't available in PATH, particularly affecting environments like Nix shells. Robert Scott originally reported the problem in gitk 2.50.1 and suggested making the `osascript` call non-fatal.

Eric Sunshine has now pointed to an existing 2018 patch that implements exactly this solution, which was previously submitted but never merged due to inactive maintainership at the time. The patch would wrap the `osascript` call in error handling while maintaining the current behavior when the command is available. 

With the current maintainer now CC'd on the thread, there are two paths forward: either the maintainer can pick up and apply the existing patch, or someone will need to verify and potentially update it for the current gitk codebase. The core issue remains unchanged - this is about making a non-critical quality-of-life feature more robust rather than fixing fundamental functionality.
