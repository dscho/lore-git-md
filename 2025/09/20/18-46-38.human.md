This is a brief discussion about Git patch trailers, specifically regarding the use of "Best-viewed-with" annotations.

Jeff King (peff) responds to Ben Knoble's comment about the unusual "Best-viewed-with" trailer in a recent xdiff patch. While Ben attributes the idea to himself and notes that Jeff has used similar annotations before, Jeff clarifies that while he hasn't used trailers this way, he does sometimes mention viewing preferences in prose or below the "---" line in commit messages.

The email includes an offhand PS with a useful Git log command for analyzing trailer usage patterns, showing how to count and sort trailer keys across commits. This is more of a side note than substantive discussion about the xdiff changes themselves, which have already been merged. The exchange provides some insight into Git contributor conventions around commit message formatting.
