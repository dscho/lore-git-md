Bugfix for `git reflog write` command's config handling. This is the second version of a patch that ensures the command properly respects local `user.name` and `user.email` configuration, fixing an oversight where it was only using environment variables.

The patch adds a call to `repo_config()` to load Git's standard identity configuration, bringing `reflog write` in line with other commands' behavior. Michael Lohmann has incorporated feedback from Patrick Steinhardt by improving the commit message formatting and splitting the test case into a separate block for better organization. The test now explicitly verifies the config handling by unsetting environment variables and checking that locally configured user information appears in reflog entries.

The implementation looks solid, with clear test coverage demonstrating the fixed behavior. The changes are minimal but important for consistency with Git's configuration hierarchy. This appears ready for inclusion, addressing the original issue reported by C O Mitter while maintaining backward compatibility when environment variables are present.
