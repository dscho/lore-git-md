This is the final patch in a series implementing `:(optional)` prefix support for pathname-type options, now extending it to command-line arguments. Phillip Wood provides review feedback on D. Ben Knoble's implementation, confirming the overall approach while suggesting several minor improvements.

The patch adds `:(optional)` handling to `parse-options.c` for consistency with the config variable support added earlier. Key technical points:
- Uses same `is_missing_file()` check from wrapper.c to silently skip missing files
- Maintains existing behavior for non-optional paths
- Documents the feature in gitcli.adoc with same syntax as config.adoc
- Adds test case in t7500 for CLI template file handling

- Suggests minor documentation phrasing improvements

The review confirms the implementation is technically sound and matches the documented behavior, with only minor code quality improvements needed.
