Documentation patch (part 5) adding a basic usage example to `git-push` manpage. This is the final patch in Julia Evans' v4 documentation series that has been refining explanations of `push.default=simple` behavior and upstream branch relationships.

The patch adds a straightforward example of the most common push invocation (`git push origin main`) near the top of the manpage, before diving into more complex default behaviors. The commit message notes this gives readers a simple, usable explanation they can stop at if they don't need to understand the more nuanced default behaviors that follow. This aligns with the series' goal of making documentation more accessible while maintaining technical accuracy.

The change is minimal (4 lines added) but pedagogically significant - it provides an obvious starting point for new users before the documentation explains the more complex default behaviors that were the focus of earlier patches in the series. The example uses standard terminology (`origin`, `main`) that matches the rest of the documentation.
