This is a user report about the potential removal of `git whatchanged`.

Stephen Harding reports encountering a fatal error when trying to use `git whatchanged`, which is currently nominated for removal. The command now requires users to explicitly pass `--i-still-use-this` and email the mailing list if they still rely on it. Harding notes they use this command through an oh-my-zsh alias (`gwch`) that combines several formatting options.

The email serves as the requested notification that this command is still in active use. While brief, it provides a concrete example of real-world usage through a common shell configuration framework. The tone suggests some bemusement at the verification requirement, but complies with the requested feedback process.

This appears to be part of Git's ongoing effort to deprecate and potentially remove less-used commands, with `git whatchanged` being a notable candidate since it's essentially a specialized version of `git log` with different defaults. The report doesn't argue for or against removal, but simply provides the requested usage data point.
