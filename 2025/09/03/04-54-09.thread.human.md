This thread addressed a bug in Git's upload-pack protocol v2 implementation where duplicate ACKs were being sent for non-commit objects. The two-part patch series first modernized the test infrastructure (patch 1/2, already merged) to use current Git test patterns while maintaining coverage of upload-pack failure modes. The second patch (2/2) fixed the core issue by deduplicating non-commit objects in upload-pack's `have_obj` array while preserving special handling for commit parents.

Junio Hamano, the Git maintainer, reviewed and approved both patches. The final version of patch 2/2 improved on earlier iterations by applying the deduplication logic more uniformly across all object types while still ensuring parents of seen commits are properly marked. The solution maintains backward compatibility with protocol v0 clients and achieves measurable memory savings (~4MB/s). With Junio's confirmation that the technical approach is sound and the patches meet their goals, the series is now be queued for inclusion, resolving the protocol v2 ACK behavior issue while preserving all edge case coverage from the modernized tests.
