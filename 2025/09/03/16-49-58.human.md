This is the second patch in Julia Evans' v3 documentation series for `git-checkout.adoc`, focusing on clarifying the branch switching behavior. The series has already gone through extensive technical vetting in previous rounds, with this version representing final polishing.

The patch simplifies the description of `git checkout <branch>` by removing jargon like "index" and "HEAD" in favor of more accessible language. It makes several key clarifications: that only identical files remain unchanged during the switch, that the command will protect uncommitted changes by failing rather than overwriting, and that running `git checkout` without arguments simply shows tracking information (previously described as a "glorified no-op").

These changes align with the series' overall goal of making the documentation more approachable while maintaining technical accuracy. The patch builds on Junio Hamano's confirmed implementation details from earlier versions, now focusing purely on improving the presentation. The wording changes are thoughtful - for example, replacing "prepare for working on <branch>" with the more direct "switch to <branch>" better matches user mental models.
