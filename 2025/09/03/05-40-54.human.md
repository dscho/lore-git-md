The email highlights the tension between technical advantages (faster development, better code quality) and community considerations (platform support, distro adoption). Steinhardt emphasizes Git's responsibility as widely-used infrastructure software, suggesting features using Rust should initially be optional new functionality rather than mandatory core components.

This continues the thread's central debate about whether to adopt Rust now (with potential platform exclusions) or wait for broader ecosystem maturity, with Steinhardt's position leaning toward caution while still supporting eventual adoption.
