This is a documentation patch in Julia Evans' v3 series improving `git-checkout.adoc`. The patch focuses on restructuring the file restoration section to better match the SYNOPSIS layout and clarify the distinction between operations that use a tree-ish versus those that default to the index.

The key changes in this patch:
1. Splits the file restoration documentation into two subsections - one for operations that take a tree-ish (overwriting both index and working tree) and another for operations that default to the index (overwriting just working tree)
2. Removes the `-f` flag from the tree-ish variants where it wasn't relevant
3. Updates the patch mode text to reference both restoration variants
4. Maintains all previously confirmed behavior while improving organizational clarity

The changes follow through on the series' goal of making the documentation more precise and structurally aligned with the command's actual behavior. This patch in particular helps readers more easily distinguish between the two fundamental file restoration modes by giving them their own subsections. The removal of `-f` from the tree-ish variants is a minor but correct cleanup since that flag only affects the index-defaulting case.
