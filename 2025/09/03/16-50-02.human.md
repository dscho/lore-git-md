This is the final patch in Julia Evans' v3 documentation series for `git-checkout.adoc`, focusing on polishing the file restoration section. The series has already gone through extensive technical review and consensus-building in previous versions, with this patch specifically targeting clarity improvements in the file restoration documentation.

The patch simplifies the language around file restoration operations, replacing technical terms like "tree-ish" and "index" with more accessible phrasing ("commit or tree", "stage"). It adds concrete examples for both tree-ish-based restoration (`git checkout main file.txt`) and index-based restoration (`git checkout file.txt`), making the behavior more tangible for readers. The description of merge conflict handling is restructured into a clearer sequence of options (-f to ignore, --ours/--theirs to pick a side, -m to recreate conflicts).

This represents the final polish on a documentation series that has already addressed all major technical accuracy concerns in previous rounds.
