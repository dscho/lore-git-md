This is a maintainer response to user feedback about the `git whatchanged` command. Junio C Hamano replies to Jesse Hathaway's appreciation for `git whatchanged` by suggesting alternatives to `--raw` output, specifically recommending `--status` as a more informative option. The response maintains the position that `git whatchanged` is deprecated ("the command that is going away anyway") while trying to guide the user toward better alternatives in `git log`. 

The exchange highlights the ongoing tension between user familiarity with older commands and the maintainers' desire to streamline Git's interface. While Jesse values the mnemonic quality of `git whatchanged`, Junio points out technical shortcomings in its default output format and suggests more modern alternatives. The response is brief and practical, offering concrete advice rather than debating the deprecation decision itself.
