This is a maintainer response in the `git whatchanged` discussion thread. Junio C Hamano replies to Jesse Hathaway's appreciation for the deprecated `git whatchanged` command by suggesting alternatives to `--raw` output in `git log`. The response focuses on improving the transition experience by recommending `--status` instead, which provides more human-readable change information compared to the hexadecimal output of `--raw`. The tone is constructive but firm about the deprecation path, offering practical advice rather than reconsidering the removal of `whatchanged`. This moves the discussion from user preference to concrete suggestions for adapting to the recommended replacement workflow.
