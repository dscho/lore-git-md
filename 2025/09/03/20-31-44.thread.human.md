This thread investigates why a self-compiled Git binary runs significantly slower than the Homebrew-installed version on macOS. D. Ben Knoble initially reported a 5x performance difference (110ms vs 22ms for basic commands) between his 3.5MB self-compiled binary (built with DEVELOPER=1) and Homebrew's 4.4MB version. Early analysis ruled out quarantine attributes and focused on potential build flag or optimization differences.

New testing reveals the performance gap disappears on non-corporate machines, shifting suspicion to corporate security tooling interfering with execution rather than compilation settings. While the binary size difference remains unexplained, it now appears less relevant to the slowdown. The investigation has moved from examining build configurations to considering runtime factors like binary analysis by security software. The DEVELOPER=1 flag's role is now uncertain, though still in use.
