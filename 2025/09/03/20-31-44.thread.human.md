This thread investigates puzzling performance differences between Homebrew-installed Git and self-compiled versions on macOS, particularly in corporate environments. Ben Knoble initially observed a 5x slowdown (110ms vs 22ms) in a monorepo with self-compiled binaries, prompting investigation into build flags and optimizations. 

The key breakthrough came when testing revealed the slowdown only occurs on corporate-managed machines, strongly suggesting security tooling (likely binary sniffers) as the root cause rather than compilation differences. While build inconsistencies were found (some files getting -Oz optimization while others defaulted to -O2), fixing these didn't resolve the performance gap. The binary size discrepancy (3.5MB vs 4.4MB) remains but appears unrelated to runtime performance.

Current focus has shifted to understanding which corporate security measures might cause this interference. Knoble plans further tests installing to Homebrew paths to determine if the security tools are path-sensitive or using binary fingerprinting. The DEVELOPER=1 flag's role remains unclear in this context. What began as an investigation into build optimizations has effectively ruled them out as the primary factor, now centering on environmental interference from corporate security systems.
