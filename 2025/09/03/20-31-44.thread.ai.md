Performance investigation into self-compiled Git binary slowdowns on macOS. D. Ben Knoble reports a 5x performance difference between Homebrew-installed Git (4.4MB, faster) and self-compiled version (3.5MB, slower) when running basic commands in a monorepo (~110ms vs ~22ms measured with hyperfine). The self-compiled binary was built with DEVELOPER=1 flag and lacks some Homebrew settings (Perl/Python paths, USE_LIBPCRE, INSTALL_SYMLINKS), though these seem unlikely to explain the slowdown. Initial checks ruled out macOS quarantine attributes as the cause. The binary size discrepancy (4.4MB vs 3.5MB) and performance gap suggest substantive compilation or optimization differences. Open questions include impact of build flags, compiler versions, and platform-specific factors. Side note: RelNotes documentation not converted to HTML during install was observed but likely unrelated.
