Performance investigation into self-compiled Git binary slowdowns on corporate macOS machines, with security tooling emerging as the likely root cause. D. Ben Knoble initially observed a 5x performance gap between Homebrew-installed Git (4.4MB, ~22ms) and self-compiled version (3.5MB, ~110ms) in a monorepo, with DEVELOPER=1 flag and missing Homebrew settings (Perl/Python paths, USE_LIBPCRE, INSTALL_SYMLINKS). Testing revealed the performance difference only occurs on corporate-managed machines, strongly suggesting security tools (binary sniffers) as the primary factor rather than build configuration. The CFLAGS=-Oz optimization flag was initially applied inconsistently (some files got -Oz while others defaulted to -O2), but fixing this only resolved the binary size discrepancy (now 3.5MB vs 4.4MB) without affecting performance. The DEVELOPER=1 flag's impact remains unclear. Current focus is identifying which corporate security measures cause the runtime interference, with Knoble planning to test installing to Homebrew paths to determine if the tools are path-sensitive or using binary fingerprinting. Earlier observed RelNotes documentation issue remains confirmed but unrelated. The thread has effectively ruled out build optimizations as the primary factor, shifting investigation to environmental interference from corporate security systems.
