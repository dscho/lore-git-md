Performance investigation into self-compiled Git binary slowdowns on macOS, with evolving understanding of root causes. D. Ben Knoble initially reported a 5x performance difference between Homebrew-installed Git, 4.4MB, ~22ms command times) and self-compiled version (3.5MB, ~110ms) in a monorepo, with DEVELOPER=1 flag and missing Homebrew settings (Perl/Python paths, USE_LIBPCRE, INSTALL_SYMLINKS). Early analysis ruled out macOS quarantine attributes and focused on build flags/optimizations. New testing reveals the performance gap disappears on non-corporate machines, strongly suggesting corporate security tooling (binary sniffers) as the primary cause rather than compilation differences. The CFLAGS=-Oz optimization flag was inconsistently applied (some files got -Oz while others defaulted to -O2), but this appears less relevant given the security-tooling hypothesis. The binary size discrepancy (3.5MB vs 4.4MB) remains unexplained but may be a red herring. DEVELOPER=1 flag's impact is now unclear. Key open question is identifying which corporate security measures might cause such runtime interference, with the environment (not build process) now being the likely culprit. Earlier observed RelNotes documentation issue remains confirmed but unrelated.
