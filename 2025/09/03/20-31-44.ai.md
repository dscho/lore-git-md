Performance investigation into self-compiled Git binary slowdowns.

D. Ben Knoble reports significant performance differences between a Homebrew-installed Git binary (4.4MB, faster) and a self-compiled version (3.5MB, 5x slower) when running basic commands in a monorepo. The slower binary was built with DEVELOPER=1 flag and lacks some Homebrew build settings (Perl/Python paths, USE_LIBPCRE, INSTALL_SYMLINKS), though these don't seem likely culprits. The email includes detailed timing measurements showing the self-compiled version taking ~110ms vs ~22ms for Homebrew's.

Key technical details that may come up in follow-ups: binary size discrepancy (4.4MB vs 3.5MB), build flags used (DEVELOPER=1, missing Perl/Python paths), timing measurements methodology (hyperfine benchmarks), and potential macOS-specific factors (quarantine attributes checked but ruled out). The email also notes an observation about RelNotes documentation not being converted to HTML during install.

This appears to be a genuine performance regression investigation rather than a build configuration question - the binary size difference and magnitude of slowdown suggest something substantive may be wrong with the compilation process or resulting binary. Future discussion may focus on build optimization flags, compiler versions, or platform-specific compilation differences.
