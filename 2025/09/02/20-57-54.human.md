This is a test fixup patch in the ongoing documentation verification series. Junio Hamano is following up on Patrick Steinhardt's proposed changes to the test infrastructure that verifies builtin command documentation.

The patch makes two key improvements to the test logic in t0450-txt-doc-vs-help.sh:
1. It properly reverses the grep condition to set test prereqs in the else branch (fixing a logic error in the original)
2. It adds the missing adoc-missing allowlist file containing 9 builtins that are intentionally undocumented (like checkout--worker and submodule--helper)

The changes complete the transition from silently skipping undocumented builtins to explicitly verifying their status against an allowlist. The test now properly fails if a builtin's documentation status doesn't match its allowlist entry - either missing documentation when not allowed, or having documentation when listed as intentionally missing.
