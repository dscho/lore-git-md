This is patch 5/15 in Patrick Steinhardt's ongoing refactoring series to move packfile-specific state from `struct object_database` to `struct packfile_store`. The patch relocates the MRU (most-recently-used) list of packfiles, which is used to optimize object lookups by favoring recently accessed packs.

The changes follow the established pattern of the series: moving a piece of packfile-related state while maintaining identical behavior. The MRU list is now initialized in `packfile_store_new()` and accessed via `store->mru` rather than `objects->packed_git_mru`. All existing MRU operations (initialization, traversal, and movement of packfiles within the list) are updated to use the new location.

Key technical details:
- The MRU list head moves from `odb.h` to `packfile.h` as part of `struct packfile_store`
- `INIT_LIST_HEAD` calls are updated in `packfile_store_new()` and removed from `odb_new()/odb_clear()`
- All MRU operations in packfile.c now reference `store->mru` instead of the old ODB location
- Midx.c's pack installation is updated to use the new location

The patch maintains the series' careful approach - it's a straightforward relocation with no behavior changes, touching only the necessary access points. This continues the architectural goal of separating packfile concerns from the broader object database to eventually enable pluggable ODB backends. The MRU functionality remains unchanged, just housed in its more logical location.
