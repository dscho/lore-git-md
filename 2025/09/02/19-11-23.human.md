Security fix for Gitweb addressing command-line injection vulnerabilities. Taylor Blau patches multiple locations in gitweb.perl where untrusted user input from query parameters could be interpreted as Git command-line options, potentially allowing arbitrary file writes or other malicious actions. The fix consistently adds `--end-of-options` before passing user-controlled values to Git subprocesses.

The vulnerability was reported by Moritz Sanft, who demonstrated that a crafted URL could trick Gitweb into executing `git diff-tree` with attacker-controlled options like `--output=/tmp/pwned`. The patch systematically audits and fixes all similar code paths where Gitweb spawns Git commands with user input.

This is a thorough and security-critical fix that touches nearly all Git command invocations in the Gitweb codebase. The changes are mechanical but important - each adds the protective `--end-of-options` marker in the right place to prevent option injection. The patch appears well-tested and complete, covering all the major Git commands Gitweb uses (cat-file, ls-tree, blame, etc.).
