This is a refactoring patch in Patrick Steinhardt's ongoing series to migrate packfile management to `struct packfile_store`. The patch removes the redundant `get_packed_git()` function in favor of `get_all_packs()`, which also handles MIDX (multi-pack index) packs.

The key clarification in this email is that both functions actually load all packfiles - the only difference is that `get_all_packs()` additionally prepares MIDX information for each MIDX'd packfile. Patrick notes this makes the functions more similar than initially thought, though he asks for verification of this understanding.

Taylor Blau had previously raised concerns about specific callers that might need adjustment, particularly `cmd_grep()` and `want_object_in_pack_mtime()`. With the new understanding of the functions' behavior, Patrick believes these concerns may be moot since both functions load the same set of packfiles. He plans to update the commit message accordingly.

This is part of the larger effort to clean up and consolidate packfile management code as it moves to the new store abstraction. The change appears well-considered, with Patrick carefully checking the actual behavior differences between the functions before proceeding.
