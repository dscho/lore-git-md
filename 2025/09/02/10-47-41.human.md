CI / build system fix for Windows GitLab CI jobs. Patrick Steinhardt reports that Windows Defender's realtime monitoring has started causing false-positive virus detections during builds, specifically breaking the meson setup step. The patch disables this monitoring in the CI configuration.

The change unblocks the Windows CI pipeline and provides a modest performance improvement - builds drop from 26 to 22 minutes, and test execution time is roughly halved from ~1 hour to ~30 minutes per test slice. The commit notes these Windows runners remain "painfully slow" overall despite the improvement.

The fix is straightforward, adding a `Set-MpPreference` command to disable monitoring in the `before_script` sections for both build and test jobs. A successful CI run demonstrating the fix is referenced in the accompanying merge request. This appears to be a pragmatic workaround for an infrastructure-level issue rather than a Git code change.
