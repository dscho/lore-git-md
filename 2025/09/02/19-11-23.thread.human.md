This thread addresses a security vulnerability in Gitweb where user-controlled URL parameters could be crafted to inject arbitrary command-line options into Git commands. The initial patch from Moritz Sanft demonstrated how a malicious `hpb` parameter could write arbitrary files via `--output` injection. Taylor Blau responded with a comprehensive fix that systematically adds `--end-of-options` before any user-provided input throughout Gitweb's Perl code, leveraging Git's existing option delimiter feature.

The fix covers all Gitweb operations that spawn Git subprocesses, including blob viewing, diff generation, and archive creation. Eric Sunshine has since contributed a minor typo correction to the commit message ("agains" -> "against"), which appears to be the only outstanding change needed. The thread shows consensus forming around this being the right approach, with no substantive objections raised. The patch seems likely to be merged once this final editorial tweak is incorporated.
