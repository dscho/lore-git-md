This is a feature patch adding a `-z` flag to `git repo info` as part of a GSoC project. The patch is at version 3 and has already been signed off by mentors Karthik Nayak and Patrick Steinhardt.

The change makes `-z` an alias for `--format=nul` to match the behavior of other Git commands like `git-config` and `git-status` that use null-terminated output. The implementation has been redesigned in v3 per Junio Hamano's feedback to use `OPT_CALLBACK_F` with shared parsing logic.

Junio's response indicates the patch is technically sound and ready to merge, though he notes the documentation syntax could have been written slightly differently (showing `-z` as an alternative rather than additive option). This is a stylistic observation rather than a blocking concern.

The patch includes thorough documentation updates and test coverage. As part of a 2-patch series, this change is independent from the parallel addition of an object format` field to `git repo info`. Both patches appear well-considered and merge-ready.
