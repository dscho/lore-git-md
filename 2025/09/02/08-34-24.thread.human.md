This thread addresses batched reference update issues on case-insensitive filesystems, a problem introduced in Git 2.51 when reference updates switched to batched transactions. Karthik Nayak's patch series fixes three key problems in the files backend: direct case collisions (foo vs Foo), file/directory conflicts (foo vs Foo/bar), and directory/file conflicts (Foo/bar vs foo). The solution properly reports conflicts while allowing non-conflicting updates to proceed.

The implementation modifies core reference handling code to add case-folding checks and introduces new error codes for different conflict types. He also clarified the distinction between transaction-local conflicts and conflicts with existing references on disk.
