This is the first patch in Patrick Steinhardt's v3 series refactoring packfile management into a new `struct packfile_store`. The patch introduces the empty structure and its basic allocation/free functions, marking the start of moving packfile-related state out of `struct object_database`.

The change creates a new abstraction layer that will eventually contain all packfile management logic, though currently it's just a shell with an ODB pointer. The patch adds the store to each ODB instance during creation and provides the basic infrastructure for subsequent patches to migrate packfile state into this new structure.

Key technical details:
- Adds `struct packfile_store` declaration in packfile.h with just an `odb` pointer initially
- Introduces `packfile_store_new()` and `packfile_store_free()` functions
- Modifies `odb_new()` to create a packfile store for each new ODB
- Updates odb.h to include the packfile store pointer while maintaining existing packed_git fields

The patch is straightforward infrastructure work that doesn't yet change behavior, just sets up the framework for the more substantial migrations in following patches. It's part of the larger effort to enable pluggable ODB backends by better isolating packfile management.
