This is patch 2/15 in Patrick Steinhardt's packfile store refactoring series, moving the packed_git list from struct object_database to the new struct packfile_store. The patch relocates the core packfile list management while maintaining identical behavior, continuing the architectural effort to separate packfile-specific state from the generic ODB structure.

The key changes move the packed_git list pointer from odb.h to packfile.h's struct packfile_store, renaming it to 'packs' for clarity. It extracts packfile cleanup logic from odb_clear() into new packfile_store_free() and packfile_store_close() functions, with the latter handling the BUG check for do_not_close packs. All references to objects->packed_git are updated to objects->packfiles->packs across packfile.c.

The implementation addresses memory safety by ensuring proper NULL assignment after freeing (a v2 issue) while maintaining the existing MRU list handling (deferred to a future series). The changes are mechanical but touch many packfile operations, requiring updates to window scanning, pack installation, object counting, and lookup functions. Documentation is added for the new packs field in struct packfile_store.

This continues the systematic migration of packfile state out of the ODB, with all technical issues from previous versions resolved. The changes are focused and well-contained, touching only the expected packfile management paths while preserving behavior. The series remains on track toward enabling future pluggable ODB backends.
