This is Junio Hamano's monthly "What's cooking in git.git" status report, summarizing the current state of patches in the Git development pipeline. The email provides a comprehensive overview of 30+ active topics being worked on, categorized by their integration status in the 'next' and 'seen' branches.

Several documentation updates are progressing well, including fixes for sendmail/Gmail configuration, git-checkout manpage improvements, and clarification of GitGitGadget contribution workflow. Performance optimizations are also notable, with Rust integration work continuing for xdiff library, memory limits added to range-diff, and khash optimizations for git-describe.

The report highlights some significant behavioral changes: a new "git sparse-checkout clean" command to prune untracked files, IMAP integration for send-email, and a proposed deprecation of core.commentChar=auto. There's also a new experimental "git last-modified" command to track file modification history.

Several complex refactorings are in progress, including work to remove global variables in the sparse-checkout code and improvements to the multi-pack-index implementation. The bulk-checkin code is being de-globalized as part of the ongoing the_repository removal effort.

Many of these topics are marked as ready for 'next' or even 'master', while others await review feedback or rerolls. The report serves as both a progress update and a call for community feedback on these various development efforts.
