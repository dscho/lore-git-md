This is a bug report and feature request regarding Git's remote group functionality. Junio Hamano notes that while `git fetch group` works as expected (fetching from all remotes in the group), the analogous `git push group` command does not work at all, despite being a logical counterpart.

The issue appears to be an inconsistency in how remote groups are implemented - the group handling code in builtin/fetch.c isn't shared with the push functionality. Hamano suggests exposing and moving the relevant functions (`get_remote_group()` and `remote_group_data` struct) to remote.c so both fetch and push can use them.

This is characterized as a "#leftoverbits" project - meaning it's a small but worthwhile cleanup of incomplete functionality. While not urgent, it would make the remote group feature more complete and consistent. The change would be non-trivial but manageable, involving refactoring and sharing code between builtin modules.
