Refactoring patch in Patrick Steinhardt's packfile store series (v3 14/15). This converts `get_all_packs()` to work directly on the packfile store rather than a repository, renaming it to `packfile_store_get_packs()` in the process. The change is mechanical but wide-ranging, updating 19 files that called the function to first access the repository's packfile store.

Key technical details:
- New function signature: `struct packed_git *packfile_store_get_packs(struct packfile_store *)`
- All callers now follow the pattern: get store from `the_repository->objects->packfiles`, pass to new function
- Maintains identical behavior - still returns same packfile list including MIDX-initialized packs
- Part of broader effort to move packfile state management into dedicated `packfile_store` struct
- Touches several performance-sensitive areas (pack-objects, fsck, gc) but changes are purely mechanical

The patch continues the series' pattern of interface simplification while preserving behavior. It sets up for the final patch (15/15) which will complete the packfile store refactoring. No test changes needed since functionality remains identical.
