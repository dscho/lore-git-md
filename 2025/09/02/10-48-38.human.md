Refactoring patch in Patrick Steinhardt's packfile store series (13/15). This patch eliminates the redundant `get_packed_git()` function in favor of `get_all_packs()`, which provides identical functionality but with slightly more MIDX-related metadata preparation.

The key observation is that both functions return the same packfiles list, with `get_all_packs()` additionally recording MIDX membership info - a lightweight operation since the MIDX is already loaded. The change simplifies the API by removing the confusing distinction between these similarly-named functions.

The patch mechanically updates four call sites (gc.c, grep.c, and two in object-name.c) and removes the function declaration/implementation. This continues the series' pattern of cleaning up packfile-related interfaces while preserving behavior. The change appears straightforward with no test modifications needed, though reviewers may want to verify the grep.c change's switch to directly calling `packfile_store_prepare()` is equivalent.
