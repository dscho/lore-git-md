This is patch 6/15 in Patrick Steinhardt's packfile store refactoring series, moving the "kept pack cache" from `struct object_database` to `struct packfile_store`. The patch completes the relocation of all packfile-specific state from the ODB to the new packfile store structure.

The technical changes include:
- Removing the `kept_pack_cache` struct from odb.h and adding it to packfile.h as `kept_cache`
- Updating all access points in packfile.c to use `store->kept_cache` instead of `objects->kept_pack_cache`
- Adding documentation for the kept cache in packfile.h
- Updating the ODB comment to reflect that packfiles are now the only remaining packfile-related member

The patch follows the same behavior-preserving approach as previous patches in the series, with all functionality remaining identical while changing the internal storage location. This completes the structural separation of packfile state from the object database, a key step toward enabling pluggable ODB backends. No test changes are needed since this is purely an internal refactoring.

The changes are mechanical but carefully executed, continuing the series' pattern of clean, focused patches. With this patch, all packfile-specific state has now been migrated to the ODB's `packfiles` member, leaving only that pointer in `struct object_database`. The series continues to make steady progress toward its architectural goals.
