This is a security patch addressing command-line injection vulnerabilities in Gitweb. The patch systematically adds `--end-of-options` before any user-provided input in Gitweb's Perl code to prevent malicious users from being interpreted as command-line options.

The vulnerability allows attackers to inject arbitrary Git command-line options by crafting special URLs, demonstrated by the example where `hpb=--output=/tmp/pwned` creates a file. The fix leverages Git's `--end-of-options` feature (introduced in 51b4594b40) to safely delimit where options end and arguments begin.

The patch touches numerous Gitweb subcommands including blob viewing, diff generation, blame, and archive creation - essentially anywhere Gitweb spawns Git subprocesses with user-controlled input. Each change follows the same pattern: inserting `--end-of-options` before parameters that might come from URL query strings.

This appears to be a thorough and well-motivated fix for a real security issue (reported by Moritz Sanft). The changes are mechanical but comprehensive, covering all the major Gitweb operations that interface with Git commands. The commit message clearly explains both the vulnerability and the solution approach.
