The change is straightforward - all references to the old `objects->packed_git_initialized` are updated to use `objects->packfiles->initialized` instead, with the flag's behavior remaining identical. The patch touches packfile initialization checks in `prepare_packed_git()` and `reprepare_packed_git()`, maintaining the same logic flow but now using the more appropriate location in the packfile-specific store structure. This continues the series' systematic migration of packfile-related state out of the generic ODB structure, with no functional changes beyond the internal organization. The boolean conversion follows modern Git coding standards while preserving the exact same semantics.
