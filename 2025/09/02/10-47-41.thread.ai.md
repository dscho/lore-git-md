CI thread summary:

This thread addresses Windows CI failures in GitLab CI where Windows Defender's realtime monitoring was incorrectly flagging `meson.exe` as malware, causing test failures. The solution modifies `.gitlab-ci.yml` to disable realtime monitoring via `Set-MpPreference -DisableRealtimeMonitoring $true` in the `before_script` for all Windows-related jobs (mingw64 builds and tests). While primarily fixing the false positive issue, this change also provides significant performance improvements - reducing build times from 26 to 22 minutes and test execution from ~1 hour to ~30 minutes per test slice. The patch has been verified via successful CI run, though Windows runners remain slow overall. No functional changes to Git itself, just CI infrastructure adjustments for Windows platforms.
