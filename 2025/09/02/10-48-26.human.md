This is the first patch in Patrick Steinhardt's v3 series refactoring packfile management into a new `struct packfile_store`. The patch introduces the empty structure and its allocation/free functions as the initial step in centralizing packfile-related state that's currently scattered between `struct packed_git` and `struct object_database`.

The change is part of the larger effort to enable pluggable object database backends by moving packfile-specific logic out of the generic ODB layer. While this first patch just creates the scaffolding, subsequent patches will migrate actual packfile state into this new structure. The author notes this is an intermediate step - the store will eventually live at the ODB source level rather than the ODB level itself.

The implementation is straightforward, adding the new struct pointer to `struct object_database` and providing basic lifecycle functions. The patch touches key packfile-related files (packfile.c/h, odb.c/h) and maintains backward compatibility while setting up for more substantial changes to come. As the series opener, it establishes the architectural direction while making minimal functional changes.
