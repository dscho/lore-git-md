This is a bugfix series addressing a curl API type mismatch that started causing CI failures in Git for Windows' ARM64 builds. The issue stems from a `curl_easy_setopt()` call passing the wrong parameter type (likely triggered by a libcurl update), which clang catches but GCC misses.

The series does more than just fix the immediate problem: it introduces a safe casting helper for `size_t` to `curl_off_t`, applies this to the problematic HTTP push code, and cleans up a related unsafe cast in imap-send. The author notes it's odd the code wasn't using the large-file variant of this cURL option from the start, since it existed before Git itself.

The changes touch HTTP, IMAP, and remote-curl code, with the main fix being in http-push.c. The patches apply cleanly back to v2.22, though testing older versions would be difficult. This appears to be a thorough fix from an experienced contributor, addressing both the immediate issue and related type safety concerns.
