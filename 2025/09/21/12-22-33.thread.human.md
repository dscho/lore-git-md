Johannes Schindelin (Dscho) has completed a 3-patch series fixing type mismatches in curl interactions that were causing CI failures in Git for Windows ARM64 builds. The issue surfaced after a libcurl update, where clang caught incorrect type usage in CURLOPT_INFILESIZE calls. The series introduces a centralized helper function (`cast_size_t_to_curl_off_t()`) and updates HTTP and IMAP code paths to use the more appropriate CURLOPT_INFILESIZE_LARGE option where available.

All three patches have been reviewed and approved by maintainer Junio C Hamano, with minor documentation improvements incorporated in the v2 iteration. The final patch completes the series by applying the same fix pattern to http-push.c, making the type handling consistent across all affected subsystems. The changes maintain compatibility with Git's supported curl versions while properly addressing the compiler warnings. With all maintainer feedback addressed, the series is now ready for merging into the main Git repository.
