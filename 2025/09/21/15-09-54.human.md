Bugfix completing the curl type-safety series for HTTP push operations. This is the third and final patch in Johannes Schindelin's series addressing type mismatches in curl interactions that caused CI failures on ARM64 builds.

The patch updates `http-push.c` to use `CURLOPT_INFILESIZE_LARGE` with proper type casting, matching the approach already used in other parts of Git (as established in patches 1 and 2). The change aligns with Git's supported curl versions (v7.11.0+) and uses the newly centralized `cast_size_t_to_curl_off_t()` helper function.

The change is straightforward - just a 2-line modification replacing the old type-unsafe call with the properly typed version. With all three patches now acked, this concludes the fix for the curl type mismatch issues across HTTP and IMAP subsystems.
