Bugfix patch introducing a type-casting helper function for safer curl interactions, part of a series addressing type mismatches in Git for Windows ARM64 builds.

This first patch in the series moves and renames the `xcurl_off_t()` function from `remote-curl.c` to `http.h`, making it available throughout the HTTP-related code. The new `cast_size_t_to_curl_off_t()` function performs the same validation (ensuring the value fits within `curl_off_t`) but follows Git's established naming convention for type-casting helpers. The error message is updated to be more precise about the platform limitation, though it can't use the `_()` translation function due to header inclusion constraints.

The changes are straightforward: the function is extracted from `remote-curl.c` (with 11 lines removed) and placed in `http.h` (with 10 lines added), updating all call sites to use the new name. This foundational change enables the series' subsequent patches to safely handle curl options that require `curl_off_t` values. The commit message explains the rationale well, noting both the immediate need and the alignment with Git's coding conventions.
