Refactoring patch in the ODB transaction relocation series, focusing on naming consistency. This is part 5/6 of Justin Tobler's series to move bulk-checkin functionality into object-file.c as part of the larger pluggable ODB backend effort.

The patch systematically renames all remaining bulk-checkin terminology to transaction-oriented names, completing the conceptual shift from the old bulk-checkin subsystem to the new transaction model. Key changes include:
- Renames `struct bulk_checkin_packfile` to `struct transaction_packfile`
- Updates function prefixes from `bulk_checkin`/`batch` to `transaction` (e.g. `prepare_loose_object_transaction()`)
- Merges `finish_tmp_packfile()` into `flush_packfile_transaction()` since it was only used there
- Updates all callers to use the new names

The changes are mechanical but thorough, touching 80 lines across object-file.c. The patch maintains all existing functionality while making the code's purpose clearer. This appears to be the final naming pass in the series, following the structural relocation work in earlier patches. The changes align with Patrick Steinhardt's design direction for the ODB backend work.
