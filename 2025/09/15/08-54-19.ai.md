This is the foundational patch in Patrick Steinhardt's 15-part series refactoring packfile management as part of the ODB abstraction effort. It introduces `struct packfile_store` to centralize packfile-related data that is currently scattered between `struct object_database` and `struct packed_git`.

The patch creates the new structure with minimal initial content (just an ODB pointer) and hooks it into the ODB initialization path. Key technical points include:
- Adds `packfile_store_new()` and `packfile_store_free()` functions
- Updates `struct object_database` to include the store pointer
- Touches odb.c, odb.h, packfile.c, and packfile.h
- Explicitly notes this is an intermediate step before further refactoring

The commit message clearly explains the motivation: to establish a single source of truth for packfile management in preparation for pluggable ODB implementations. While the current implementation is minimal, it sets up the architectural pattern that subsequent patches will expand by migrating more packfile-related fields into this structure.

This patch represents the uncontested starting point of a larger, technically resolved refactoring effort that has already gone through multiple review iterations. The changes are mechanical and maintain existing behavior while establishing the new pattern.
