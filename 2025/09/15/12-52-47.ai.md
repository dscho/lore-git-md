Bugfix series for `git config get --type=color` functionality with test cleanups.

This is the final version of Patrick Steinhardt's 5-patch series addressing three specific issues with color value handling in `git config get`:

1. Restores backward compatibility for parsing color values without config keys (fixing a regression from commit 4e51389000)
2. Prevents unwanted pager spawning when printing ANSI color escape sequences
3. Performs test suite cleanup in t1300-config.sh

The series follows a logical progression from test modernization (patches 1-2) to implementation fixes (patches 3-5). Key technical changes include:

- Modernized test expectations in t1300-config.sh with consistent use of `${SQ}` and `<<\EOF`/`<<-EOF` (patch 1)
- Stylistic improvements to test formatting (patch 2)
- Modified `get_color()` in builtin/config.c to return int instead of void and replace `die()` with `error()` (patch 3)
- Added special-case handling for empty config key + color type + default value combinations (patch 4)
- Implemented pager bypass when `display_opts.type == TYPE_COLOR` (patch 5)

All review feedback from Kristoffer Haugsbakk has been incorporated, including commit message improvements and test formatting refinements. The series now includes complete test coverage with a new TTY test case for the pager behavior fix.
