This is a refactoring patch in Patrick Steinhardt's packfile store series (v5, 3/15). It moves the `packed_git_initialized` flag from `struct object_database` to the new `struct packfile_store` where it more logically belongs, as part of the ongoing effort to centralize packfile management.

The change converts the bitfield to a proper boolean type while maintaining identical behavior. The patch updates three key functions in packfile.c that check or set this flag: `prepare_packed_git()`, `reprepare_packed_git()`, and the initialization sequence. The diff shows straightforward mechanical changes to the flag's location and type, with no functional impact.

This is an incremental step in the larger architectural shift to separate packfile management from object storage. The patch follows the established pattern of the series by moving packfile-related state to the new store structure while preserving all existing behavior. As with previous patches in the series, this change is well-contained and clearly motivated within the context of the broader refactoring effort.
