This is the final patch in the Rust infrastructure series, focusing on CI modernization. It enables Rust testing in the newly created Fedora-based breaking-changes CI jobs, ensuring the build infrastructure and Rust components are properly validated.

The patch makes two straightforward changes: it adds `cargo` to the dependency installation lists for both Fedora and Ubuntu-based CI environments, and modifies the breaking-changes job configuration to enable Rust builds by setting `WITH_RUST=YesPlease` and `-Drust=enabled` flags. This ensures the CI system will test the Rust integration alongside other breaking changes.

This is a clean, focused change that completes the CI modernization work started earlier in the series. The patch follows the established pattern of the series by making minimal, targeted modifications to validate the Rust infrastructure in CI. With this change, the Rust integration will be automatically tested in the same environments where other breaking changes are validated, providing important coverage as the project moves toward mandatory Rust support.
