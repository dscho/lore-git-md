This is the final patch in a 6-part bugfix series addressing issues with `git config get --type=color`. The patch fixes an edge case where color codes would incorrectly get piped through a pager when they should be written directly to the terminal.

The change is straightforward: it modifies `builtin/config.c` to skip pager setup when the output type is COLOR, since color escape sequences are meant for immediate terminal display rather than pager consumption. The patch includes a new test case that verifies this behavior works correctly even when a pager is configured, using the test-terminal infrastructure to simulate a real TTY.

This completes the series' goal of fixing all known issues with color handling in `git config get`, following earlier patches that addressed parsing regressions and test suite improvements. The change is well-justified (color codes in a pager make no practical sense) and comes with appropriate test coverage.
