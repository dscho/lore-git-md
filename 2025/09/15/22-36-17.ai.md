This is a feature patch adding a new `--all` flag to the experimental `git-repo-info` command. The patch comes from Lucas Seiki Oshiro as part of their GSoC work, with help from Karthik Nayak and Patrick Steinhardt.

The change allows users to request all available repository metadata keys at once rather than having to specify them individually. The implementation adds a new `print_all_fields()` function that iterates through all defined fields in `repo_info_fields` and prints them using the existing formatting logic. The patch includes documentation updates and a new test case verifying the `--all` behavior matches explicitly requesting all known fields.

The implementation appears clean, factoring out common printing logic into a new `print_field()` helper function. The test coverage is minimal but sufficient for the straightforward addition. The patch builds on current master (a483264b01) and touches three files: documentation, the command implementation, and tests.

Key technical details for future reference:
- New `--all` flag added to `git repo info` subcommand
- Uses existing `repo_info_fields` array to determine available keys
- Maintains same output formats (`keyvalue` and `nul`) as individual key requests
- Test verifies output matches explicit listing of all known fields
- Part of ongoing work on repository metadata access (marked experimental)
