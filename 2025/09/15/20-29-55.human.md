Refactoring patch in the ODB transaction series. This is part 5/6 of Justin Tobler's work to relocate transaction code from bulk-checkin to object-file.c, preparing for pluggable ODB backends.

The patch focuses on renaming functions and types to better reflect their new location and purpose, moving away from "bulk-checkin" terminology. Key changes include:
- Renaming `struct bulk_checkin_packfile` to `struct transaction_packfile`
- Updating function names like `prepare_loose_object_bulk_checkin` to `prepare_loose_object_transaction`
- Merging `finish_tmp_packfile()` into `flush_packfile_transaction()`

The changes are mechanical renames that maintain all existing functionality while making the code's purpose clearer in its new home. This continues the series' goal of cleaning up the API boundaries between generic ODB operations and the files-backend implementation. The patch appears well-contained and follows through on the naming conventions established earlier in the series.
