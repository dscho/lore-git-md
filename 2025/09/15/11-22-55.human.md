This is a CI/build system patch in the Rust infrastructure series, converting an existing "pedantic" CI job into a more useful test of the Rust-breaking-changes build configuration. The patch repurposes a Fedora-based CI job that was previously only checking pedantic builds (which became the default in 2021) to instead test Meson builds with breaking changes enabled. This serves two purposes: it adds Fedora to the distros tested with breaking changes, and it prepares for upcoming Rust testing by ensuring the Meson build system works properly with breaking changes enabled.

The changes modify both GitHub Actions and GitLab CI configurations, removing the old pedantic job and adding a new fedora-breaking-changes-meson job. The implementation includes necessary dependency updates (adding meson and ninja for Fedora) and ensures tests are run in the new configuration. This is a straightforward infrastructure improvement that helps validate the Rust transition plan by expanding test coverage of the build system configurations that will be used for Rust integration.

The patch fits cleanly into the larger Rust infrastructure series, addressing a practical testing gap that was identified during the development of the Rust support. It's a small but meaningful step toward ensuring the build system is thoroughly tested across different configurations before Rust becomes mandatory in Git 3.0.
