This is a CI/build system patch in the Rust infrastructure series, converting the obsolete "pedantic" CI job into a more useful Fedora-based build that tests Meson with breaking changes enabled. The change serves multiple purposes: it adds Fedora test coverage (previously only testing Ubuntu), verifies breaking changes work with Meson, and prepares for upcoming Rust testing across both build systems. The patch modifies GitHub Actions and GitLab CI configs to replace the pedantic job with `fedora-breaking-changes-meson`, updates dependency installation to include Meson/Ninja on Fedora, and ensures tests run in this configuration. The change is mechanical but strategically important for the Rust transition, ensuring the build system works across distros and validating the breaking changes flag that will be used for Rust integration. This follows the series' pattern of thorough infrastructure preparation before introducing Rust components.
