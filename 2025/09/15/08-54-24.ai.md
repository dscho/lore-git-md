This is part 6/15 of Patrick Steinhardt's packfile store refactoring series, moving the "kept pack" cache from `struct object_database` to the new `struct packfile_store`. The patch completes the migration of all packfile-related state from the ODB to the dedicated packfile store.

The change relocates the `kept_pack_cache` structure (used by `git-pack-objects` for handling cruft objects) into the packfile store as `kept_cache`. The patch updates all related functions in packfile.c to use the new location while maintaining the same behavior. The ODB header is updated to remove the now-moved field and clarify that the `packfiles` pointer should only be accessed by packfile.c.

Key technical details:
- Updates 3 files (odb.h, packfile.c, packfile.h)
- Renames `kept_pack_cache` to `kept_cache` in the new location
- Preserves all existing functionality of the cache invalidation logic
- Adds documentation for the new `kept_cache` field in packfile.h
- Completes the packfile state migration started in earlier patches

This is a mechanical refactoring that maintains all existing behavior while continuing the architectural work to separate packfile management from object storage. The change is straightforward and uncontroversial, following the same pattern established in previous patches of the series.
