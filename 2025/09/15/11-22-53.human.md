This is a Rust infrastructure patch in the ongoing series to integrate Rust into Git core. Patch 6/9 in v5 reimplements the varint subsystem in Rust as a "test balloon" - a simple, self-contained component chosen specifically because it has no dependencies on other Git parts.

The patch is applied when Rust support is enabled (`WITH_RUST`), making the build system compile `src/varint.rs` instead of the C version in `varint.c`. The Rust implementation provides the same functionality with equivalent `decode_varint` and `encode_varint` functions, including overflow handling. The patch includes thorough test cases verifying the behavior matches expectations.

This follows the type safety improvements made to the C version in patch 5/9, which standardized on explicit integer widths. The implementation appears clean and well-tested, with the Rust code mirroring the C logic while benefiting from Rust's memory safety guarantees. The changes to build configuration files are minimal and consistent with the infrastructure established in earlier patches.

As part of the broader Rust integration effort, this serves as both a technical proof-of-concept and a stepping stone toward more complex Rust conversions. The patch maintains the series' high quality standard with clear commit messages and comprehensive tests. While labeled a "test balloon", this is actually production-ready code that will become mandatory in Git 3.0.
