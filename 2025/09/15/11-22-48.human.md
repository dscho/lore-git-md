This is the foundational patch in a series introducing Rust infrastructure to Git's core, now at version 5. It adds Meson build system support for compiling an optional internal Rust library, marking the first step in Git's planned move to make Rust mandatory by version 3.0.

The patch creates all the basic plumbing needed: a Cargo.toml configuration, Meson build rules with a `-Drust=` toggle, and a shell script wrapper to handle cargo-meson integration. The implementation is structured as a "test balloon" - optional for now, allowing gradual adoption of Rust features and alternative implementations of subsystems. The Rust edition is set to 2018 for compatibility with the upcoming gcc-rs backend.

Build system integration includes automatic toolchain detection, test execution via `meson test`, and status reporting in `git version --build-options`. The patch appears technically sound, with clean separation between the C and Rust build systems and consideration for future compatibility requirements. It follows Git's typical conservative approach to new dependencies while laying groundwork for more substantial Rust adoption.

This initial infrastructure patch has already undergone several rounds of review, with v5 addressing final polish items like `make clean` handling of Rust artifacts. The series as a whole has gained technical approval from key contributors, though some documentation phrasing (particularly around the "test balloon" terminology) remains under discussion with the maintainer.
