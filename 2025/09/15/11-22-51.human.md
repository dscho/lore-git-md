This is a feature patch in the Rust infrastructure series that adds visibility into whether Rust support is enabled in a Git build. 

The patch modifies the version reporting system to show whether Git was compiled with Rust support, appearing in both `git version --build-options` and `git bugreport` output. This helps diagnose Rust-specific issues during the transition period where some subsystems will have both C and Rust implementations.

The implementation is straightforward - it checks the `WITH_RUST` compile-time flag and adds either "rust: enabled" or "rust: disabled" to the build info output. The change is minimal (6 lines added to help.c) and follows the existing pattern used for features like fsmonitor.

This patch serves an important debugging purpose as the Rust transition progresses, though it's worth noting this is purely informational - it doesn't affect functionality. The patch appears well-contained and follows established patterns, making it likely to be uncontroversial.
