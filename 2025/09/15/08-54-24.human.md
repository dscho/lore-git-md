This is part 6/15 of Patrick Steinhardt's packfile store refactoring series, moving the "kept pack" cache from `struct object_database` to the new `struct packfile_store`. 

The patch relocates the cache used by `git-pack-objects` to track packfiles containing cruft objects (those marked with .keep files or in-memory "kept" flags). This completes the migration of all packfile-related state from the object database to the dedicated packfile store. 

Changes are straightforward mechanical updates to move the `kept_pack_cache` struct and update all references to use the new location via `objects->packfiles->kept_cache`. The patch also cleans up the now-redundant comment in `odb.h` about private packfile data, since all such state has been moved out.

As with previous patches in this series, the changes maintain existing behavior while improving code organization. The work is part of the larger effort to separate packfile management from object storage, enabling future pluggable ODB implementations. With this patch, the packfile store now contains all packfile-related state that was previously scattered through the object database.
