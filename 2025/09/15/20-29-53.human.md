Refactoring patch in the ODB transaction interface series. This is patch 3/6 in Justin Tobler's v2 series that continues the work to refactor Git's object database transaction handling.

The patch removes the `flush_odb_transaction()` function, which previously allowed partially flushing a transaction without completing it. The author notes this made the transactional interface awkward, and since there are no remaining callers of this function, it can be safely removed. The functionality is now directly incorporated into `end_odb_transaction()` where it logically belongs.

This change simplifies the API by ensuring transactions are only finalized via `end_odb_transaction()`, making the behavior more predictable. The diff shows the straightforward removal of the function from both implementation and header files, with its core operations moved into the transaction end function.

The patch appears to be a clean, logical simplification of the transaction interface that builds on previous work in this series. It follows the general direction of making the ODB transaction handling more robust and maintainable as part of the larger effort to support pluggable backends.
