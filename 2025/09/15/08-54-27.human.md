This is part 9/15 in Patrick Steinhardt's refactoring series to centralize packfile management in `struct packfile_store`. The patch focuses on cleaning up responsibilities in the packfile preparation logic.

The `reprepare_packed_git()` function previously handled three distinct tasks: reloading alternates, clearing loose object caches, and repreparing packfiles. This patch splits these responsibilities by introducing a new `odb_reprepare()` function that handles the first two tasks (alternates and loose caches), while the renamed `packfile_store_reprepare()` now focuses solely on packfile management. 

The change affects 13 files across the codebase, updating callers to use the new function. The split makes the code organization clearer by keeping packfile-specific logic in packfile.c while moving broader ODB management to odb.c. This is a clean, mechanical refactoring that maintains all existing behavior while better separating concerns - a typical step in the ongoing ODB abstraction work.
