Refactoring patch in Patrick Steinhardt's packfile store series (v5 04/15). This moves the packfile path-to-struct mapping from `struct object_database` to the new `struct packfile_store`, completing the centralization of packfile management.

The patch relocates the `pack_map` hashmap and its comparator function from odb.[ch] to packfile.[ch], making `packfile_store` the sole owner of packfile tracking. Key changes include:
- Removes `pack_map` from `struct object_database`
- Adds `map` field to `struct packfile_store`
- Makes `pack_map_entry_cmp()` static to packfile.c
- Updates MIDX lookup to use new store location
- Initializes/clears map in store constructor/destructor

The changes are mechanical with no behavior modification, continuing the series' goal of separating packfile management from object storage. The comparator function loses its `inline` hint since it's only used as a callback. All affected code paths are updated to reference the map through `objects->packfiles->map` instead of `objects->pack_map`.

This patch follows the established pattern from earlier in the series, with all architectural decisions already settled in previous discussion. It touches the same core files (packfile.c, odb.c) and maintains the same invariants while progressing the ODB abstraction effort.
