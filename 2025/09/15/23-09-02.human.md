This is a documentation discussion about terminology in the `git-push` man page, specifically around describing multi-repository workflows. Julia Evans is pushing back against using the term "triangular workflow" in the documentation, noting that while the term appears in mailing list discussions, it's nearly absent from official Git documentation (only appearing once in `gitrevisions` and some release notes). She argues for distinguishing between terms used internally by developers versus those actually documented for users.

Junio Hamano defends the term as established Git vocabulary but suggests alternative phrasing could work if Julia prefers - specifically describing the scenario as "pushing to somewhere other than where you're fetching from" rather than using the "triangular workflow" label.
