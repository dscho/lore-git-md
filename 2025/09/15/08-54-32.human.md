Refactoring patch in Patrick Steinhardt's packfile store series (v5 14/15). This patch converts `get_all_packs()` to operate on the new `packfile_store` structure rather than directly on a repository, continuing the migration of packfile management to the centralized store.

The change is mechanical but wide-ranging, updating 18 files to use the new `packfile_store_get_all_packs()` function. The function maintains the same behavior - preparing the packfile store and returning all packs (including those referenced by MIDX files) - but now takes the store as an explicit parameter rather than implicitly using the repository's store.

This is part of the larger effort to abstract packfile management from the object database, with all key technical decisions already settled in earlier discussion. The patch appears well-executed, with thorough updates to all call sites and no functional changes beyond the intended refactoring.
