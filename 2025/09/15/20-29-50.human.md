This is a refactoring and feature series introducing transaction interfaces to Git's object database (ODB) subsystem, building on previous work to prepare for pluggable ODB backends. The series comes from Justin Tobler as version 2, addressing feedback from the initial submission.

The core change relocates transaction handling code from the bulk-checkin subsystem to object-file.c, removing the bulk-checkin.[ch] files entirely (403 lines removed, 409 added). This creates a clearer separation between generic ODB transaction interfaces (`odb_transaction_{begin,commit}`) and files-backend specific implementations (`object_file_transaction_{begin,commit}`). The series also removes transaction nesting capability and enforces single-transaction semantics with BUG() checks.

Notable improvements since v1 include making transaction ending NULL-safe, switching to use `struct odb_source` instead of full `object_database`, renaming functions for consistency (`_end` -> `_commit`), and adding missing API documentation. The patch carefully preserves existing behavior in `git update-index` where `--verbose` output affects transaction boundaries due to historical parse_options_step() behavior, though this quirk may be addressed separately later.

The changes touch several key areas including cache-tree updates, index operations, and object writing paths. The series appears well-constructed with thorough commit messages explaining each step of the refactoring. It represents an important step toward the larger goal of pluggable ODB backends while simplifying and hardening the current transaction model.
