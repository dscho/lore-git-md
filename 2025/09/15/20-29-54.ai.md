This is part 4/6 of a refactoring series relocating ODB transaction code from bulk-checkin to object-file, continuing the effort to prepare for pluggable ODB backends. The patch moves all transaction-related code from bulk-checkin.[ch] to object-file.[ch], deleting the bulk-checkin files entirely. 

The key changes are:
- Moves struct definitions (bulk_checkin_packfile, odb_transaction) and all transaction functions to object-file.c
- Updates includes across the codebase to remove bulk-checkin.h dependencies
- Keeps the same transaction interface (begin_odb_transaction/end_odb_transaction) but now implemented in object-file
- Preserves all existing functionality including packfile creation, object streaming, and batch fsync operations

The relocation simplifies the exposed interface by reducing it to just the transaction begin/end functions, with the implementation details now properly colocated with other object-file operations. This is a mechanical move with no behavior changes - the subsequent commit will rename functions to better fit their new location.

The patch completes the core relocation work started earlier in the series, removing 438 lines while adding 403. It builds on previous changes that established the ODB transaction API separation and simplified the ownership model. Future work will fully utilize the source->backend interface when pluggable backends exist.
