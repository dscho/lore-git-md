This is part 5/15 of Patrick Steinhardt's packfile store refactoring series, moving the MRU (most-recently-used) list of packfiles from `struct object_database` to the new `struct packfile_store`. The change is a mechanical relocation of the MRU tracking infrastructure as part of the larger effort to centralize packfile management.

The patch moves the `packed_git_mru` list head from `struct object_database` to `struct packfile_store` (renamed to just `mru`), updates all references to use the new location, and initializes the list in `packfile_store_new()`. The MRU list is used to optimize packfile access by favoring recently-used packs when looking up objects.

Key technical details for future reference:
- Updates 5 files (midx.c, odb.c, odb.h, packfile.c, packfile.h)
- Removes MRU-related code from odb.c/odb.h where it no longer belongs
- Maintains all existing MRU functionality while changing its storage
- Touches core packfile lookup paths in `find_pack_entry()`
- Preserves the MRU optimization behavior during object lookups
- Follows the established pattern from earlier patches in the series

The change is straightforward and maintains all existing behavior while continuing the architectural work to separate packfile management from the object database. As with previous patches in this series, it's a mechanical refactoring with no functional changes, just moving code to its new logical home.
