This is a refactoring patch in Justin Tobler's v2 series that simplifies Git's ODB transaction interface by removing nesting support. The change makes transaction ownership semantics more explicit by requiring callers to ensure no pending transaction exists before starting a new one, rather than silently allowing nested transactions.

The patch removes the `nesting` counter from `struct odb_transaction` and replaces it with a BUG() check in `begin_odb_transaction()` to prevent multiple active transactions. It updates all callers (cache-tree.c, object-file.c, read-cache.c) to check for existing transactions before starting new ones. The documentation in bulk-checkin.h is updated to reflect the new single-transaction model.

Key technical changes include:
- Removal of transaction nesting capability with BUG() check for duplicates
- Added ASSERT() in `end_odb_transaction()` to verify transaction consistency
- Caller updates to explicitly check `objects->transaction` before starting
- NULL-safety for transaction cleanup (from v1 feedback)
- Maintains same external behavior while simplifying internal ownership model

The change helps prepare for pluggable ODB backends by making transaction handling more straightforward. It builds on Patrick Steinhardt's earlier ODB abstraction work and addresses feedback from the v1 discussion about NULL-safety and interface clarity. The patch is part of a larger effort to relocate and standardize transaction handling code from bulk-checkin to object-file.c.
