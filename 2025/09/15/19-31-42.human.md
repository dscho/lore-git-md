This is a discussion about Git's subprocess execution API, specifically around the `.git_cmd` flag in `run-command.h`. Jeff King (peff) is responding to Junio Hamano's proposal to simplify the API by removing the `.git_cmd` member entirely.

The key points in this email:
1. Jeff agrees with Junio's proposal to remove `.git_cmd`, noting that in 20 years of the API's existence, the flag has only ever been used to prepend "git" to commands.
2. He clarifies that the API already skips the shell when `.git_cmd` is set (unless `.use_shell` is also set, which would be invalid).
3. Jeff suggests the simplification could be straightforward - just remove `.git_cmd` and have callers manually prepend "git" where needed.
