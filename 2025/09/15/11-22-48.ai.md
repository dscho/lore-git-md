This is the foundational patch in the Rust infrastructure series, introducing build system support for compiling Git with Rust components. The patch adds Meson configuration to optionally build a Rust static library (`libgit.a`) alongside the C code, with auto-detection of the Rust toolchain controllable via a `-Drust=` toggle. It establishes Rust 2018 edition compatibility to support the upcoming gcc-rs backend, though notes this may need reevaluation if newer Rust features are adopted.

Key technical elements include:
- New `Cargo.toml` and `src/lib.rs` as Rust entry points
- `cargo-meson.sh` wrapper script handling debug/release builds and output placement
- Meson build rules for both library compilation and Rust-native test execution
- `WITH_RUST` compile-time flag when Rust is enabled
- Build summary reporting Rust availability alongside other features

The patch positions Rust as initially optional for "test balloon" features and alternative implementations, with a planned mandatory transition by Git 3.0. It deliberately avoids newer Rust features to maintain compatibility with Rust 1.49 for gcc-rs support. The implementation has received prior technical approval from Brian m. carlson regarding the cargo-meson.sh approach and has addressed SZEDER Gábor's feedback about build system polish in this v5 iteration.
