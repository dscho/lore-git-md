This is a discussion reply in the SHA-1/SHA-256 interoperability series, specifically about pack index v3 format documentation. Patrick Steinhardt responds to Brian's patch updating the pack index v3 specification to use 8-byte offsets and full 32-byte SHA-256 checksums.

Second, he notes the commit message should clarify this is updating a not-yet-implemented spec rather than changing existing behavior.

The reply maintains the thread's technical focus on storage format details while introducing a new forward-looking design consideration about hash agility.
