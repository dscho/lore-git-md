[PATCH] diff-no-index: fix buffer overflow with trailing slash paths

Bug report from Johannes Schindelin identified a buffer overflow in `git diff --no-index` when comparing directories where one path ends with '/'. Root cause was incorrect length calculation in `diff_no_index()` that unconditionally added a byte for slash. Fix reworks path matching to use `strbuf` operations throughout, eliminating both the overflow and redundant string copying.

Technical changes replace integer `skip1`/`skip2` with `strbuf` structs `ps_match1`/`ps_match2`, modifying `read_directory_contents()` to work with pre-initialized buffers. `queue_diff()` maintains match paths recursively. New tests in `t4053-diff-no-index.sh` verify correct handling of trailing slash pathspecs.

Impact: Corrects memory safety issue in directory comparison while improving performance by avoiding `strbuf_remove()` operations. Changes are localized to `diff-no-index.c` with focused test coverage. Johannes Schindelin identified the original bug; patch author implemented solution addressing both correctness and efficiency concerns.
