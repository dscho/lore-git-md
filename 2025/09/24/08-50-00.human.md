Bugfix follow-up for gitk context menu issue on macOS. Johannes Sixt points out that this specific problem with the right-click context menu not appearing on Apple Silicon Macs was already reported and tracked in the gitk issue tracker (issue #31). The thread confirms this was a packaging issue in Homebrew's Git 2.51.0_1 that was resolved in version 2.51.0_2, requiring no code changes to gitk itself. This email serves as a quick reference to the existing issue tracker entry, effectively marking the mailing list discussion as resolved with the solution being to upgrade one's Git installation through Homebrew. No further action appears needed from either users or developers.
