Thread discussing a bugfix for ref-cache iterator segfault when seeking references in empty directories, particularly after repacking operations. Patch series from Karthik Nayak, now at v3, with all technical review completed and ready for merging.

The fix addresses invalid array access in `cache_ref_iterator_seek()` (refs/ref-cache.c) when descending into directories that become empty after repacking (e.g., empty `refs/heads/`). The solution adds an empty directory check (`dir->nr == 0`) in a `do..while` loop, safe because the base 'refs/' directory always contains at least one entry. The patch includes new test cases in `t6302-for-each-ref-filter.sh` verifying behavior with packed refs and `--start-after` functionality.
