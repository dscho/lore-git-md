Bugfix for ref-cache iterator handling empty directories with packed-refs, addressing a segfault in `cache_ref_iterator_seek()` when seeking references in empty directories (e.g. `refs/heads/` after repacking). The fix (3 lines) adds a check for empty directories (`dir->nr == 0`) to break the seek loop early. Includes two new test cases in t6302-for-each-ref-filter.sh verifying the fix works with both fully packed refs and mixed packed/loose ref scenarios, specifically exercising `--start-after` flag of `git-for-each-ref`. The tests create repositories with packed refs and verify correct handling of empty directories without crashes. The change is minimal and focused, with clear commit message explaining problem and solution.
