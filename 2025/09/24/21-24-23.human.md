Feature patch introducing repository statistics functionality. This is patch 3/6 in the `git repo stats` series, implementing the core reference counting functionality.

Justin Tobler introduces a new `git repo stats` subcommand to provide repository health metrics, starting with reference counts. The command outputs a human-readable table showing totals for branches, tags, remotes, and other reference types, with automatic column width adjustment. The implementation uses Git's ref-filter interface to categorize references and presents results in a format inspired by git-sizer.

The patch includes thorough documentation and tests covering both empty repositories and those with various reference types. The implementation is cleanly separated into data collection (using ref-filter) and presentation (via a custom table formatter). This appears to be well-considered groundwork for future expansion, with the commit message noting plans to add more metrics in subsequent patches.

The code follows Git conventions, handles memory carefully, and maintains clean separation between components. Reviewers Patrick Steinhardt and Karthik Nayak have been actively involved in shaping the series, and this patch builds on their earlier feedback. The implementation looks solid and merge-ready, though the series as a whole still has a few patches to go before completion.
