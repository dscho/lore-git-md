This is a feature patch in the `git repo stats` series, adding machine-readable output formats to the new repository statistics command. It introduces `--format` options for both key-value and NUL-delimited output alongside the existing human-readable table format.

The patch adds two new output modes: `keyvalue` (using `=` and newlines as delimiters) and `nul` (using NUL and newline delimiters), with the latter format being more robust for special characters. The implementation maintains the same statistics as before (reference counts by type and object counts by type) but presents them in parseable formats suitable for scripting.

The changes include thorough documentation updates, a new `stats_keyvalue_print()` function to handle the formatted output, and comprehensive tests verifying both new formats. The implementation follows the series' established patterns and appears well-integrated with the existing code. This completes the output format options for the new `git repo stats` command, addressing a key requirement for machine consumption of the statistics.
