Bugfix for `git diff --no-index` with paths end in slashes and pathspecs.

Jacob Keller fixes a crash in `git diff --no-index` that occurs when comparing directories where one path ends with a slash and a pathspec is used. The root cause is an incorrect length calculation in `diff_no_index()` that leads to an off-by-one error when processing paths. The patch not only the simple fix (using `ends_with()`), but also optimizes the directory traversal logic to avoid unnecessary string manipulations.

The new approach builds up match paths incrementally using strbufs rather than copying and stripping full paths repeatedly. This makes the code both more correct and more efficient. The patch includes test cases to verify the fix works for paths ending in slashes.

The change is well-motivated by a real bug report from Johannes Schindelin and includes thorough testing. The implementation appears careful and considers edge cases, though the author notes the fix might seem complex compared to a minimal `ends_with()` solution. The tradeoff is justified by the performance improvement in directory traversal.
