Feature patch adding object counting to the new `git repo stats` command. This is patch 4/6 in the series introducing repository health metrics.

The patch extends the `git repo stats` output to include counts of reachable objects (commits, trees, blobs, and tags) alongside the existing reference counts. It uses the path-walk API to traverse all objects reachable from regular references, categorizing them by type. The human-readable table format now shows both reference and object statistics in a clear hierarchical layout.

Implementation highlights:
- Adds new `object_stats` and `repo_stats` structs to track counts
- Implements `count_objects()` callback for path-walk traversal
- Extends the stats display logic to include object counts
- Updates tests to verify both empty and populated repository cases
- Maintains clean separation between data collection and presentation

The patch appears well-constructed, with thorough test coverage and clear documentation updates. It builds logically from the previous patches in the series, using established Git APIs (path-walk, ref-filter) appropriately. The output format remains consistent with the human-readable table style introduced earlier in the series.
