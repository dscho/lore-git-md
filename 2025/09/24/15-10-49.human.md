This is a refactoring patch in the final stages of the xdiff modernization series. It renames the `rchg` field in `xdfile_t` to `changed` to better reflect its purpose as a boolean indicator of whether a line in a file has been changed. The change is part of a broader effort to improve code clarity and type safety in the xdiff diff algorithm implementation.

The patch responds to Phillip Wood's suggestion to document the field's purpose in the commit message. The author explains that `changed` (formerly `rchg`) marks whether each line in a file has been modified, and notes that a subsequent commit will convert its type from `char` to `bool` for additional clarity.

This is one of the final patches in a well-executed series that has systematically modernized xdiff's internals while maintaining identical runtime behavior.
