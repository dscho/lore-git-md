Clarification on Git's numbering conventions from Junio C Hamano. This is a follow-up to the resolved discussion about date numbering in `git log` output, confirming that days (like months) use 1-based indexing as standard practice.

Junio provides additional context about other numbering schemes used throughout Git, noting that while most references are 1-based (parent numbers, reflog entries), some like stash entries use 0-based indexing. The examples given include:
- Parent references (HEAD~1 for first parent)
- Merge parents in octopus merges (HEAD~2 for first side branch)
- Reflog entries (@{1} for previous position)
- Stash entries (stash@{0} for most recent)

This serves as a definitive reference point for Git's varied numbering conventions, though it doesn't introduce any changes to functionality. The email reinforces the thread's conclusion that date numbering follows standard locale conventions and won't be modified, while helpfully documenting other cases where users might encounter different numbering schemes in Git's interface.
