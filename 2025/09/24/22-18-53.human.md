Bugfix follow-up addressing memory leak in `diff --no-index` pathspec handling.

Junio Hamano points out that Jacob Keller's recent fix for buffer overflow in `diff --no-index` with trailing slash paths (which replaced integer `skip1`/`skip2` with `strbuf` structs) appears to introduce a memory leak. The `ps_match1` and `ps_match2` strbufs are not being properly released in the function's cleanup path via `strbuf_release()`. This oversight would likely be caught by leak sanitizers during testing.

The email includes the relevant code context showing where the cleanup should be added (after the `out:` label in `diff_no_index()`). While the original patch added comprehensive tests for trailing slash behavior, those tests wouldn't have caught this resource management issue. Hamano suggests but hasn't verified that leak detection would flag this.

This is a straightforward follow-up to an already-approved fix, addressing a secondary issue introduced by the solution. The change is localized to the same file (`diff-no-index.c`) and maintains the safety and performance improvements of the original patch while ensuring proper resource management.
