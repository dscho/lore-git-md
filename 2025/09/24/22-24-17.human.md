Maintainer follow-up addressing memory leak in diff-no-index fix.

Junio Hamano confirms his earlier suspicion about a memory leak in Jacob Keller's buffer overflow fix for `git diff --no-index`. Testing with SANITIZE=leak revealed that the `ps_match1` and `ps_match2` strbufs weren't being released in the error-handling code path. He provides a simple two-line diff to add the missing cleanup calls at the `out:` label.

The patch remains focused on the original issue - fixing directory comparison paths ending in slashes - but now properly handles resource cleanup. Hamano offers to either incorporate this change himself or let Keller squash it into the original fix, indicating this appears to be the only remaining issue. The change is straightforward and maintains the original solution's benefits while making it fully memory-safe.
