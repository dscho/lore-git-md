This is a documentation patch series (2 parts) that reorganizes and clarifies the refspec section of the git-push man page. It follows up on previous work from pull request #1964, with the main goal of improving discoverability and readability of push rules.

The first patch (already merged) extracted all push validation logic into a dedicated "PUSH RULES" section at the end of the man page, making these rules easier to reference while allowing less-common cases to be skipped. The second patch (current) rewrites the refspec specification section with clearer structure and examples.

Key changes in this version include:
- Moving push rules to their own section for better referenceability
- Restructuring refspec documentation with clear examples of all forms
- Clarifying behavior of `+` prefix and special `tag <tag>` syntax
- Addressing feedback from Junio Hamano on wording and technical accuracy
