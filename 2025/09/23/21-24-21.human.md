This is a refactoring patch in the xdiff modernization series, specifically removing an obsolete helper function. 

Ezekiel Newren's patch eliminates `xdl_get_rec()`, a function that was useful when xdiff records were stored in a linked list but is now redundant since records are accessed directly from a contiguous array. The change simplifies the code by inlining the array access at each call site, removing 16 lines while adding 7 (mostly due to line breaks).

This is part of the larger v5 series that concludes the xdiff internals refactoring, with all previous preparatory work already merged to 'next'. The patch follows the series' pattern of cleaning up legacy code while preserving behavior. The removal is straightforward with no functional changes - it just eliminates an indirection that's no longer needed. 

The patch touches xdiff/xemit.c, affecting how diff records are accessed during output generation, but the change is purely internal and doesn't impact any diff algorithms or their output. As with the rest of the series, this cleanup helps position the codebase for potential future Rust integration by removing unnecessary abstractions.
