This is the final patch (9/9) in the v6 Rust infrastructure series, focusing on CI modernization. It enables Rust compilation in the breaking-changes CI jobs to verify the build infrastructure and Rust subsystem conversions work as expected.

The patch makes two key changes: First, it adds `cargo` to the dependency installation lists for both Fedora/AlmaLinux and Ubuntu/Debian CI environments. Second, it sets `WITH_RUST=YesPlease` and adds `-Drust=enabled` to the Meson flags for the breaking-changes jobs, ensuring the varint subsystem replacement and any future Rust components are built and tested.

This completes the CI coverage for the Rust transition by testing the build system's ability to handle Rust components when breaking changes are enabled. The changes are minimal but strategically important, as they validate the infrastructure that will support mandatory Rust adoption in Git 3.0. The patch maintains consistency with the series' phased approach, where Rust is currently optional but will become required in future releases.
