Feature patch adding object statistics to the new `git repo stats` command, building on the initial reference-counting implementation. This is patch 2/4 in the series.

The patch extends the repository statistics functionality to count reachable objects by type (commits, trees, blobs, and tags) using the path-walk API. The counts are displayed in the same human-readable table format as the reference statistics, with a new "Objects" section showing totals and per-type breakdowns. The implementation uses `add_pending_oid()` to mark all regular references as starting points for the reachability analysis, then processes the resulting graph with a callback that accumulates counts by object type.

The changes include:
- New `object_stats` struct to track counts by object type
- `count_objects()` callback for path-walk API to accumulate counts
- `stats_count_objects()` function to set up and execute the walk
- Integration with existing table formatting code
- Documentation updates to reflect the new object statistics
- Additional test cases verifying object counting in empty and populated repositories, including a case with 42 commits/trees/blobs and an annotated tag

The implementation appears solid, with careful attention to memory management (using `release_revisions()` and `path_walk_info_clear()`). Test coverage is thorough, including edge cases. This represents the second phase of the git-sizer-inspired functionality, following the reference statistics from patch 1. The output remains explicitly human-readable, with machine-parseable formats planned for future work.
