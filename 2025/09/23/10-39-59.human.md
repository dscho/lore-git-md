The change is minimal - just a one-line version bump in the workflow file - but the underlying Action update could affect how Go is set up for the translation workflow.

The patch appears straightforward and well-justified, coming through the standard dependency update process. It's worth noting this originated in the git-for-windows repository before being proposed for the main Git project, suggesting it's been tested in that context first.
