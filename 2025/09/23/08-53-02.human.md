This is a governance discussion about the proposed Rust transition's LTS (Long-Term Support) model, specifically addressing how to maintain Git versions without Rust requirements after Rust becomes mandatory in Git 3.0.

Johannes Schindelin strongly opposes Junio Hamano's suggestion of maintaining LTS releases in a separate repository, aligning with Patrick Steinhardt's position that LTS should remain in the canonical Git repository. Schindelin argues that external LTS maintenance would create trust issues, user confusion, and potential fragmentation, citing industry precedent where external LTS releases are rarely seen as official.

Instead, Schindelin proposes a "lieutenant" model where a trusted Git contributor (suggesting Steinhardt himself) would oversee LTS maintenance within the main project. This approach would maintain continuity, leverage existing trust relationships, and provide clear accountability. Schindelin emphasizes that this matches user expectations and industry norms, while offering to assist with the maintenance workload.

The email reflects growing consensus against repository separation for LTS, with the discussion now shifting toward implementation details of an integrated model. Schindelin's personal endorsement of Steinhardt as a potential LTS maintainer adds weight to the conversation, though no formal decision is reached in this message. The tone is collegial but firm, with Schindelin expressing surprise that repository separation was even considered.
