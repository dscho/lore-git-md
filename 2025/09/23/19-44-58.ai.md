This is a documentation patch series (4 parts) aimed at improving the clarity of `git-pull`'s man page, specifically focusing on the DESCRIPTION section. The author Julia Evans conducted user research with 15 Git users to identify pain points in the current documentation.

The series has four main goals: (1) clarify the relationship between `git pull` and its underlying commands (fetch/merge/rebase), (2) explicitly state the current default behavior (--ff-only) since some users still expect the old behavior, (3) help users quickly find the right command for their needs (merge/rebase/squash), and (4) provide clearer guidance on handling merge conflicts. The author acknowledges taking an "aggressive" approach to streamlining the documentation.

The changes involve significant restructuring of `Documentation/git-pull.adoc`, with 32 lines added and 54 removed across four patches. The first patch moves parameter documentation, the second clarifies integration options, the third removes an example, and the fourth improves conflict resolution guidance. The series depends on another pending documentation change about upstream branches.
