This is part of Patrick Steinhardt's packfile store refactoring series (v6, 05/15), continuing the migration of packfile management state from `struct object_database` to the new `struct packfile_store`. The patch specifically moves the Most-Recently-Used (MRU) list of packfiles, which is used to optimize object access patterns by favoring recently used packfiles.

The changes are mechanical but touch several key areas:
- Removes the `packed_git_mru` list from `struct object_database` in odb.h
- Adds a new `mru` list_head to `struct packfile_store` in packfile.h
- Updates all MRU list operations to use the new location (5 call sites in packfile.c)
- Maintains the same initialization pattern in `packfile_store_new()`
- Includes a minor update in midx.c to use the new location when installing MIDX packs

The patch follows the established pattern from earlier in the series, moving state while preserving behavior. The MRU list continues to serve the same optimization purpose, just from its new home in the packfile store. This is part of the broader architectural goal of centralizing packfile management to enable future plugg backend implementations.

No functional changes are introduced - this is purely a code organization improvement. The patch is cleanly separated from other changes in the series and touches only the expected files (odb.[ch], packfile.[ch], and midx.c). The diff shows balanced additions and deletions as the field moves between structs.
