Refactoring patch in the xdiff modernization series. This is part 8/13 of v5, which concludes the xdiff internals cleanup for Rust compatibility.

The patch eliminates redundant fields in `xdlclass_t` that were mirroring data from `xrecord_t`, instead embedding the `xrecord_t` directly. The three removed fields (`ha`, `line`, `size`) were exact copies of their counterparts in `xrecord_t` (`ha`, `ptr`, `size`). This change simplifies the structure by removing duplication while maintaining identical behavior.

The modification touches `xdiff/xprepare.c`, updating the struct definition and all references to the removed fields. The change is straightforward - where code previously accessed the fields directly from `xdlclass_t`, it now accesses them through the embedded `rec` struct. This is a preparatory step for future type changes in `xrecord_t` to avoid having to update both structs.

This continues the series' pattern of removing redundancy and improving type safety. The patch appears well-contained and mechanical, with all field access sites updated consistently. Phillip Wood is credited as a helper, suggesting improvements earlier in the series.
