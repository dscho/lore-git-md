This is a follow-up in the Git release notification discussion thread. Christian Couder shares an existing tool (`get_releases.py`) that scrapes Git release announcements from the mailing list archives and presents them in a machine-readable format. The tool is currently used to generate content for the Git Rev News newsletter.

The script provides release information by querying lore.kernel.org for Git release announcements (marked with [ANNOUNCE]) within a specified date range. Each result links back to the original mailing list email containing the full release notes. This offers an alternative to the previously discussed RSS feeds and tag-based approaches, though it relies on parsing mailing list archives rather than direct Git repository data.

The response is helpful but doesn't address all original concerns - it still requires running a script rather than providing a pure push notification mechanism. However, it does demonstrate one working solution for programmatic access to release information that's already in production use. The tool appears well-integrated with existing Git infrastructure, using the official announcement emails as its data source.
