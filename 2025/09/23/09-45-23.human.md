This is a feature patch in the ongoing Rust infrastructure series, adding visibility into whether Git was built with Rust support. 

The patch modifies `help.c` to report Rust compilation status in two places: the `--build-options` output of `git version` and in `git bugreport`. This will help diagnose Rust-specific issues during the transition period where some subsystems have both C and Rust implementations.

The change is straightforward - it adds conditional compilation blocks that report "rust: enabled" or "rust: disabled" based on the `WITH_RUST` build flag. This matches the pattern used for other optional features like fsmonitor. The implementation looks clean and well-integrated with existing version reporting infrastructure.

As part of the larger Rust adoption effort, this patch serves an important debugging role while the project moves through the phased transition (optional in 2.52, default in 2.53, mandatory by 3.0). The commit message clearly explains the motivation and expected benefits for issue tracking.
