The discussion revealed strong consensus around maintaining the current behavior, with Junio Hamano and others emphasizing that fixup operations should preserve original authorship since their purpose is to amend prior work. Phillip Wood and others have proposed compromise solutions, suggesting adding a new `--use-author` flag to provide opt-in functionality for cases where preserving the current author is desired, rather than changing the default behavior. 

Mathias has acknowledged the design principles at play and shared their existing custom solution using a shell script that achieves the desired behavior through `git cherry-pick -n` and `git commit --amend -nC`.
