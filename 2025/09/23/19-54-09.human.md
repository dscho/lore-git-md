Bugfix follow-up: gitk context menu issue on macOS ARM64 resolved by package update. 

Marcin Wisnicki reports that the previously reported gitk right-click menu failure on Apple Silicon Macs (Darwin 24.6.0) has been resolved by upgrading from Homebrew's Git 2.51.0_1 to 2.51.0_2. The original bug report showed complete failure of context menu functionality in gitk's Tk interface on ARM64 architecture, while working correctly on Windows. 

The resolution appears to have come through a package update rather than a code change, suggesting the issue may have been related to build configuration or dependencies rather than Git's Tk code itself. No details are provided about what changed between the two Homebrew versions, but the problem is now resolved for the reporter.

This serves as a useful data point for anyone encountering similar issues - checking for package updates may resolve what initially appears to be a code-level bug. The thread can likely be considered closed unless others report the issue persisting in current versions.
