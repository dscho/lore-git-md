Bugfix follow-up: macOS gitk context menu issue resolved by package update.

The original bug report described a failure of gitk's right-click context menu functionality on macOS ARM64 systems (specifically Darwin 24.6.0 with Git 2.51.0). The reporter, Marcin Wisnicki, now confirms that upgrading from Homebrew's git package version 2.51.0_1 to 2.51.0_2 resolved the issue. This suggests the problem was either a packaging-specific regression or a build configuration issue in the earlier Homebrew package, rather than a fundamental bug in gitk's Tk interface.

The resolution indicates this was likely a transient packaging problem affecting only specific builds, not a cross-platform Tk compatibility issue as initially suspected. No technical details are provided about what changed between the two Homebrew versions, but the fix appears complete as the reporter no longer experiences the menu failure. This closes the thread with a simple solution for affected users - upgrading their Git installation through Homebrew.
