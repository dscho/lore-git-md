This is part 3/15 of Patrick Steinhardt's packfile store refactoring series (v6), which has already been merged. The series centralizes packfile management in a new `struct packfile_store`.

This patch moves the `packed_git_initialized` bit from `struct object_database` to `struct packfile_store`, where it more logically belongs as part of the packfile management system. The field is also converted to use the `bool` type now that it's permitted in the codebase. The change is mechanical - the bit is renamed to simply `initialized` and all access sites are updated to use the new location via `r->objects->packfiles->initialized`.

The patch touches three files: `odb.h` (removing the old field), `packfile.h` (adding the new field with documentation), and `packfile.c` (updating the three access sites). This continues the series' architectural goal of moving packfile-related state out of the object database and into the dedicated packfile store structure.

Since this is part of an already-merged series, there are no outstanding questions or controversies about this particular change. The v6 iteration included only minor documentation and grammar fixes from v5, with no functional impact.
