Refactoring patch in the xdiff modernization series, removing redundant diffdata_t struct.

This patch eliminates the `diffdata_t` struct which was serving as an unnecessary wrapper around `xdfile_t` fields. The commit message clearly maps each field from the old struct to its direct counterpart in `xdfile_t`: `nrec` to `nreff`, `ha` to `ha`, `rindex` to `rindex`, and `rchg` to `rchg`. The changes are straightforward mechanical replacements in `xdiffi.c` and removal of the struct definition from `xdiffi.h`.

The patch updates the `xdl_recs_cmp()` function signature and all its call sites to work directly with `xdfile_t` pointers instead of `diffdata_t`. The diff shows clean removal of intermediate variable assignments in `xdl_do_diff()` since the fields are now accessed directly from the `xdfenv_t` structure. This is part of the final cleanup phase (v5) of the xdiff refactoring series, following earlier preparatory work that was already merged to 'next'. The change maintains identical behavior while simplifying the code structure.
