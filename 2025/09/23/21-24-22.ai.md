This is a refactoring patch in the final v5 series of Ezekiel Newren's xdiff modernization effort, specifically targeting code cleanup in the diff emission logic. The patch eliminates redundant local variables that were duplicating fields from the `xrecord_t` struct in `xdiff/xemit.c`, instead directly using the struct fields. This affects several functions that handle diff output generation.

The changes simplify the code by removing intermediate variables like `rec` and `len` that were just aliasing `xdf->recs[ri]->ptr` and `xdf->recs[ri]->size`, instead working directly with the `xrecord_t` pointer. The `is_empty_rec()` function also gets a more compact implementation while maintaining the same whitespace-checking behavior. All modifications preserve the existing functionality while making the code more direct and slightly more efficient by avoiding redundant field lookups.

This is part of the systematic cleanup that follows earlier structural simplifications in the xdiff codebase, with all changes in this patch being straightforward mechanical improvements that don't affect the diff algorithm's behavior. The patch fits naturally into the series' goal of modernizing and simplifying the xdiff internals while maintaining identical output.
