This is a refactoring patch in the final v5 series of xdiff modernization work by Ezekiel Newren. The patch removes the now-unnecessary `xdl_get_rec()` helper function from xdiff/xemit.c, which was originally used when xrecord_t was a linked list structure. With the transition to a contiguous array storage model (completed in earlier patches), direct array access makes this function obsolete.

The change simplifies four call sites by replacing the function call with direct array lookups of `xdf->recs[ri]->ptr` and `xdf->recs[ri]->size`. The removal eliminates 16 lines of code while maintaining identical behavior, as confirmed by the unchanged test suite. This is part of the systematic cleanup of xdiff internals that has been progressing through the v5 series, with all prior technical decisions already resolved and the approach approved by maintainers.

Key technical points for future reference:
- Removed function: `xdl_get_rec()` from xdiff/xemit.c
- Affected callers: `xdl_emit_record()`, `match_func_rec()`, `is_empty_rec()`
- Replacement pattern: Direct access to xdf->recs[ri]->ptr/size
- Behavioral impact: None (verified by tests)
- Context: Final cleanup in xdiff modernization series after array conversion

The patch follows the established pattern of the series by removing legacy indirection layers now that the data structure has been simplified. With no open questions or objections from reviewers, this appears ready for merging as part of the completed xdiff refactoring effort.
