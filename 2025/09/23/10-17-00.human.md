This is the foundational patch in Patrick Steinhardt's refactoring series to centralize packfile management. The patch introduces a new `struct packfile_store` that will eventually become the single source of truth for managing packfiles, replacing the current scattered approach where packfile information is split between `struct packed_git` and `struct object_database`.

The change is motivated by the need to support pluggable object databases, where clean separation of packfile management will be crucial. While the new structure is currently just a shell (containing only a pointer back to its parent object database), subsequent patches in the series will migrate all packfile-related fields into it.

The patch represents a careful first step in a larger architectural change - it establishes the new structure without yet moving any significant functionality. The commit message notes this is transitional work, with further refinements planned to eventually move the structure to the object database source level. The implementation appears clean and well-explained, with appropriate forward-looking notes about the commit's place in the broader refactoring effort.
