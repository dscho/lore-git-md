This is the final patch in the v6 series introducing Rust infrastructure to Git core, focusing on CI testing for the breaking-changes scenario. The patch enables Rust compilation in the CI pipeline's breaking-changes jobs, ensuring the build infrastructure and Rust components (like the varint subsystem from earlier patches) are properly tested under conditions that will eventually become mandatory.

The changes are straightforward: adding `cargo` to dependency installations in both Fedora and Debian/Ubuntu CI environments, and setting `WITH_RUST=YesPlease` along with the corresponding Meson flag for breaking-changes jobs. This builds on the series' earlier work that established parallel C/Rust implementations with identical behavior, now ensuring they're exercised in CI.

As part of the broader transition plan (optional in 2.52, default in 2.53, mandatory by 3.0), this patch completes the practical validation side by testing the Rust-enabled build path under the same conditions that will eventually be required. The implementation appears clean and focused, directly supporting the series' goal of proving the technical viability of Rust integration.
