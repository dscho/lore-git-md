This is a refactoring patch from Patrick Steinhardt's completed packfile store series, moving the `get_multi_pack_index()` function from packfile.c to midx.c as part of the ODB abstraction effort.

The patch relocates `get_multi_pack_index()` to midx subsystem where it logically belongs, while exposing the previously static `packfile_store_prepare()` function that it depends on. The move is motivated by an upcoming need to call this function from outside the packfile system. The implementation remains unchanged - it still calls `packfile_store_prepare()` on the source's ODB packfiles before returning the MIDX pointer.

Key technical changes:
- Moves `get_multi_pack_index()` from packfile.c to midx.c
- Adds declaration to midx.h
- Removes declaration from packfile.h
- Makes `packfile_store_prepare()` non-static and adds documentation
- Updates includes and function ordering accordingly

This is a mechanical change that maintains all existing behavior while improving code organization. The patch fits into the larger series' goal of separating packfile management from object database responsibilities, with MIDX access remaining a documented implementation detail to be addressed in future work. The change is well-contained and straightforward, with no expected controversy as it was part of the already-merged series.
