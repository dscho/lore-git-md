CI / build system patch in the Rust infrastructure series, converting the obsolete "pedantic" CI job into a full test of Meson builds with breaking changes enabled. This is patch 8/9 in v6 of the series.

The patch repurposes the Fedora-based "pedantic" job, which became redundant after pedantic builds were made default, into a more valuable test case. The new configuration will verify two key aspects of the Rust transition: (1) Meson builds with breaking changes enabled, and (2) upcoming Rust integration (to be added in a follow-up). This provides additional test coverage on Fedora distribution and ensures the build infrastructure works across both Make and Meson systems.

Key technical changes include modifying CI configuration files (GitHub Actions and GitLab CI) to replace the pedantic job, adding Meson/ninja dependencies for Fedora, and adjusting the build/test scripts to handle the new job type. The implementation maintains the same test execution pattern as other jobs while adding the breaking changes flag to Meson builds.

This change demonstrates the series' focus on comprehensive testing infrastructure as part of the Rust transition, particularly around build system compatibility. It builds on previous work in the series that established Meson support (patch 1/9) and Makefile integration (patch 3/9), now ensuring both build systems are properly tested with the breaking changes required for Rust adoption. The patch follows the series' pattern of incremental, verifiable steps toward the larger goal.
