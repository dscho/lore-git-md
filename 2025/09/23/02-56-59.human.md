Feature patch adding machine-readable output format to `git repo stats`. This is the third patch in a series introducing a new `git repo stats` subcommand for repository health metrics. Building on the previous patches that added reference and object counting in human-readable table format, this change introduces a `--format=keyvalue` option that outputs statistics as simple key-value pairs for easier machine parsing.

The implementation maintains the existing table format as default while adding the new key-value output mode. Each statistic is printed on its own line with an `=` delimiter (e.g. `objects.commits.count=42`). The change includes thorough documentation updates and test coverage verifying the new output format works as expected.

The patch follows the series' established pattern of clean separation between data collection and presentation. It's a well-contained addition that moves toward the project's goal of git-sizer-inspired repository metrics while keeping the human-readable output as the default. The implementation looks solid with careful handling of format options and clear test cases.
