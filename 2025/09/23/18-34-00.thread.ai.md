Thread summary:

Documentation formatting issue in config/extensions.adoc and pretty-formats.adoc reported by Kristoffer Haugsbakk (bug #4704), where definition lists with nested bullet items followed by continuation paragraphs incorrectly rendered "+" characters in HTML output under Asciidoctor. Jean-Noël Avila implemented changes replacing single colons (`::`) with triple colons (`:::`), removing open block markers (`--`), and properly nesting bullet lists within explicit blocks, affecting configuration options (`compatObjectFormat`, `noop`, `objectFormat`) and `%(decorate)` pretty format syntax.

Jeff King confirmed the diagnosis using `doc-diff` and validated the approach. Junio C Hamano initially requested clarification about the specific "straight plus sign" rendering artifact, which Avila subsequently provided via concrete URLs demonstrating the problematic output in `git-config` and `git-log` documentation. The examples clearly showed the malformed rendering that motivated the workarounds involving second-level definition lists and open blocks.

With the rendering artifacts now demonstrated and all technical aspects resolved, Hamano has indicated acceptance of the clarification. The solution maintains documentation semantics while ensuring consistent rendering across Asciidoctor and asciidoc.py processors, with no functional impact. This represents a targeted fix within the broader documentation standardization effort, with all key reviewers (Avila, King, Hamano) satisfied. The thread has progressed from technical discussion to final approval stage, ready for inclusion in the documentation maintenance stream. ASCII art rendering remains a separate known issue not addressed here.
