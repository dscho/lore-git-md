Thread summary:

Documentation formatting issue in config/extensions.adoc and pretty-formats.adoc reported by Kristoffer Haugsbakk, where definition lists with nested bullet items followed by continuation paragraphs incorrectly rendered "+" characters in HTML output under Asciidoctor (bug #4704). Jean-Noël Avila implemented changes replacing single colons (`::`) with triple colons (`:::`), removing open block markers (`--`), and properly nesting bullet lists within explicit blocks, affecting configuration options (`compatObjectFormat`, `noop`, `objectFormat`) and `%(decorate)` pretty format syntax.

Jeff King confirmed the diagnosis, identified additional affected sections using his `doc-diff` tool, and validated the approach. Junio C Hamano reviewed the patch but requested clarification about the specific "straight plus sign" rendering artifact mentioned in the commit message, as it wasn't visible in current HTML output. Avila subsequently provided concrete URLs demonstrating the problematic rendering, showing the fix's necessity.

The solution maintains documentation semantics while ensuring consistent rendering across Asciidoctor and asciidoc.py processors, with no functional impact. This represents a targeted fix within the broader documentation standardization effort, with all technical aspects resolved and only awaiting final maintainer approval after the rendering artifact clarification. ASCII art rendering remains a separate known issue not addressed here. Key participants are Avila (implementation), King (verification), and Hamano (final review).
