This is a documentation patch announcing the planned mandatory adoption of Rust in Git 3.0, part of the ongoing Rust infrastructure series (v6 7/9). The patch adds a detailed section to `BreakingChanges.adoc` outlining the phased transition plan and governance considerations.

The announcement formalizes the timeline first introduced in earlier patches: optional Rust support in 2.52, default-enabled in 2.53, and mandatory in 3.0 (estimated second half of next year). It explicitly calls out the varint subsystem (from patch 6/9) as the test balloon for Rust integration. The document provides build system specifics (`meson configure -Drust=enabled` and `make WITH_RUST=YesPlease`) and acknowledges platform compatibility concerns.

Key governance elements include declaring the pre-3.0 release as LTS (4 cycles for bug fixes, 6 for security), with potential distributor-maintained extensions. The document leaves flexibility to defer the mandate if downstream impact proves severe, while emphasizing the unsustainability of maintaining parallel implementations long-term. The patch serves as both a warning to distributors and a policy anchor for the project's Rust transition.
