CI/build system patch in the Rust infrastructure series. This is patch 8/9 in v6 of Patrick Steinhardt's series introducing Rust to Git core.

The patch repurposes the "pedantic" CI job (which had become redundant after pedantic builds became the norm) into a more useful test case. The new job will:
- Run full builds and tests on Fedora (expanding distro coverage)
- Verify Meson builds with breaking changes enabled
- Lay groundwork for future Rust testing by ensuring both Make and Meson build systems are exercised

The changes modify CI configuration files to replace the pedantic job with this new test case, adding Meson/ninja dependencies for Fedora builds. The implementation looks straightforward, removing now-unnecessary test-skipping logic while maintaining the same basic structure as other CI jobs.

This is a practical improvement that strengthens the test matrix for the Rust transition, particularly around build system compatibility. The patch fits cleanly into the series' broader goal of proving Rust integration works across Git's supported environments.
