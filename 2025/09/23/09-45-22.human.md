Build system patch adding Rust support to Git's Makefile infrastructure. This is part of Patrick Steinhardt's v6 series introducing Rust to Git core, following the earlier Meson build system changes. The patch adds conditional Rust compilation support via a new `WITH_RUST` flag, mirroring the Meson implementation from patch 2/9.

Key changes include:
- Adds `.gitignore` entries for Rust build artifacts (`/target/`, `Cargo.lock`)
- Introduces Rust-specific build variables (`RUST_SOURCES`, `RUST_LIB`) and cargo flags
- Creates rules to build the Rust library in debug/release modes
- Adds quiet build output for cargo commands
- Includes Rust library in the main Git link step when enabled

The implementation looks thorough, with proper integration into Git's existing build system patterns. This is a foundational piece of the larger Rust adoption plan, which aims to make Rust optional in Git 2.52, default in 2.53, and mandatory by 3.0. The patch maintains backward compatibility while paving the way for future Rust components like the varint subsystem mentioned in the thread context.
