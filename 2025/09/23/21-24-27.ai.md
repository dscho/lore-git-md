This is a refactoring patch in the final stages of Ezekiel Newren's xdiff modernization series, specifically removing temporary variable aliases for `rchg` arrays in `xdl_build_script()`. 

The change eliminates local pointer variables `rchg1` and `rchg2` that were previously used to access the `rchg` arrays from the xdf1 and xdf2 structures. Instead, the code now directly references the array members through the structure pointers (`xe->xdf1.rchg` and `xe->xdf2.rchg`). This is part of the broader effort to simplify xdiff's internal structure access patterns and eliminate redundant variable storage.

The modification affects only `xdiff/xdiffi.c`, with 4 lines removed and 3 added. The change is purely internal - no behavior or performance impact is expected since the compiler would likely optimize the temporary variables similarly. This patch follows the series' pattern of direct structure member access that was established in earlier patches for other xdiff fields.
