This is a refactoring patch in the final v5 series modernizing xdiff internals for Rust compatibility. It's part of a larger effort to clean up and simplify the xdiff diff algorithm implementation while preserving behavior.

The patch focuses on xdiff/xemit.c, eliminating redundant local variables that were duplicating fields from the xrecord_t struct. Instead of extracting `ptr` and `size` into separate variables, the code now works directly with the xrecord_t struct. This makes the code more straightforward and reduces the chance of mismatched field usage.

The changes are mechanical but improve code clarity:
- Replaces `rec`/`size` variable pairs with direct xrecord_t usage
- Simplifies whitespace checking in `is_empty_rec()` to use a single counter
- Maintains identical behavior while reducing indirection

This is one of the final cleanups in a well-executed series that has already been through multiple rounds of review. The changes are straightforward and unlikely to be controversial, continuing the series' pattern of careful, behavior-preserving refactoring.
