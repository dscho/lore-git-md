This is a bug report about gitk's context menu functionality on macOS. Marcin Wisnicki reports that right-clicking on a commit in gitk (version 2.51.0) on an ARM64 Mac (macOS 24.6) fails to show the expected context menu, which does appear on Windows systems. The report includes detailed system information showing this occurs with a clean test repository containing just one commit.

The bug appears to be a platform-specific UI issue affecting macOS users, though the report doesn't specify whether this is a regression or long-standing behavior. The reporter provides clear reproduction steps but doesn't include any analysis of potential causes or workarounds. This seems like a straightforward usability issue that would affect all macOS gitk users, though the impact is limited to those who rely on right-click functionality in the GUI.
