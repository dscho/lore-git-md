This is a refactoring patch in the final v5 series of xdiff modernization work, specifically focusing on code organization and cleanup in the xdiff preparation logic.

The patch eliminates redundant local variables in `xdl_prepare_ctx()` that were essentially duplicating the functionality of the `xdfile_t` struct members. Instead of managing separate local variables and then copying them into the struct, the code now initializes and manipulates the struct members directly. The error handling path is simplified to use the existing `xdl_free_ctx()` function rather than manually freeing each local variable.

Key technical changes:
- Removes local variables `ha`, `rindex`, `rchg`, `rhash`, and `recs` that shadowed `xdfile_t` members
- Moves the `xdl_free_ctx()` function definition earlier in the file to allow its use in the error path
- Updates all variable references to use the struct members directly
- Maintains identical behavior while reducing code duplication

This change is part of the broader xdiff refactoring effort to modernize the codebase for potential Rust integration, though this particular patch focuses purely on internal code organization rather than type safety or naming improvements addressed in other patches of the series. The patch follows the established pattern of the v5 series by making focused, behavior-preserving changes that improve code clarity.
