Refactoring patch in the xdiff modernization series, focusing on code clarity and type safety.

This patch (12/13 in v5) continues Ezekiel Newren's systematic cleanup of xdiff internals, now addressing the similarity matching logic in xprepare.c. The changes introduce enum-like macros (NONE=0, SOME=1, TOO_MANY=2) to replace magic numbers used for tracking line similarity states, and renames the dis1/dis2 arrays to matches1/matches2 for clarity. The patch also converts related variables to more precise types (bool for xdl_clean_mmatch return value, uint8_t for matches arrays) and adds BUG() checks for invalid states.

Key technical details:
- Introduces NONE/SOME/TOO_MANY macros replacing 0/1/2 magic numbers
- Renames dis1/dis2 to matches1/matches2 throughout xprepare.c
- Converts xdl_clean_mmatch() return type from int to bool
- Changes dis/dis1/dis2 from char* to uint8_t* for matches arrays
- Adds explicit BUG() checks for invalid match states
- Improves comments explaining the similarity matching logic
- Maintains identical behavior while making the state transitions more explicit

The changes are part of the final refinements in the xdiff modernization series, following the structural simplifications in earlier patches. The patch maintains the same functionality while improving code readability and type safety, with no performance impact expected from these purely syntactic changes.
