This is part 2 of Patrick Steinhardt's refactoring series to centralize packfile management in a new `struct packfile_store`. The patch moves the list of packfiles from `struct object_database` to the new store structure, which provides a cleaner architectural boundary for packfile operations.

The changes include:
- Removing the `packed_git` field from `struct object_database`
- Moving packfile list management to `struct packfile_store` with a new `packs` field
- Extracting packfile closing/freeing logic into new `packfile_store_close()` and `packfile_store_free()` functions
- Updating all packfile iteration code to use the new location

The patch is well-contained and mechanical, touching only the expected files (odb.[ch] and packfile.[ch]). It's part of a larger, already-reviewed series that has now been merged, with this being one of the core architectural changes that establishes the new packfile management structure. The commit message clearly explains the motivation and scope of the change.
