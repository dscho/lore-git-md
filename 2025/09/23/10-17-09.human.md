This is part of Patrick Steinhardt's completed packfile store refactoring series (v6 10/15), which centralizes packfile management in `struct packfile_store` as part of the ODB abstraction effort. The patch refactors `install_packed_git()` to work directly with the packfile store rather than a repository object, renaming it to `packfile_store_add_pack()` for clarity.

The change updates 7 call sites across various subsystems (fast-import, index-pack, http, midx) to use the new interface. The core functionality remains the same - adding a packfile to the store so its objects become accessible - but the API now better reflects the architectural boundary between packfile operations and repository/ODB management.

This is a mechanical refactoring with no behavior changes, typical of the series' focus on clarifying responsibilities between components. The patch appears well-executed, with thorough updates to both implementation and header files, plus documentation for the new function. As with the series overall, this helps pave the way for future ODB backend work while maintaining existing behavior.
