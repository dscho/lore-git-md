This is a feature patch implementing the first Rust component in Git core as part of the ongoing Rust infrastructure effort. Patch 6/9 in the v6 series introduces a Rust reimplementation of Git's varint subsystem, serving as a test balloon for the Rust build infrastructure.

The patch replaces `varint.c` with `src/varint.rs` when Rust support is enabled (`WITH_RUST`), maintaining identical functionality through direct C-compatible exports (`#[no_mangle]`). The implementation handles both encoding and decoding of variable-length integers with overflow protection, matching the existing C behavior exactly. The Rust version includes comprehensive unit tests verifying edge cases like zero values, single-byte encodings, multi-byte sequences, and overflow conditions.

Build system changes span both Makefile and Meson configurations, with the Rust version taking precedence when enabled. The implementation is intentionally isolated, having no dependencies on other Git components, making it a low-risk first candidate for Rust integration. The patch follows the type standardization work from patch 5/9, using `u64` consistently for values and `u8` for lengths.

This serves as the first concrete mandatory Rust component planned for Git 3.0, demonstrating the technical viability of mixed C/Rust compilation while maintaining the project's stability guarantees. The implementation includes safety features like bounds checking and overflow protection that Rust's type system enforces at compile time.
