This is part 5/15 of Patrick Steinhardt's refactoring series to centralize packfile management in a new `struct packfile_store`. The patch moves the most-recently-used (MRU) list of packfiles from `struct object_database` to the new `packfile_store` structure, which is a more logical home for this functionality.

The changes are mechanical but touch several key areas: the MRU list initialization is moved to `packfile_store_new()`, all MRU list operations are updated to reference the new location, and the field is removed from `object_database`. The patch maintains the same behavior while cleaning up the architectural boundaries - packfile-related state is now properly colocated in the packfile store.

This continues the series' pattern of systematically migrating packfile management from the object database to the dedicated store. The changes appear straightforward with no obvious issues, and the commit message clearly explains the motivation. As with previous patches in this merged series, this is a well-executed step in the larger refactoring effort.
