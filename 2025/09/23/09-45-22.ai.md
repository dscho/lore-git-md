This is the third patch in the v6 series introducing Rust infrastructure to Git core, focusing on Makefile integration. It establishes the build system support for compiling an internal Rust library, mirroring the Meson support added in the previous patch.

The patch adds Rust-specific build infrastructure to the Makefile, including:
- A new `WITH_RUST` build toggle to enable Rust compilation (optional now, mandatory by Git 3.0)
- Rust build artifacts (`target/` directory and `Cargo.lock`) to `.gitignore`
- Support for both debug and release builds via `DEBUG` flag
- Quiet build output integration matching Git's existing build verbosity controls
- Clean target handling for Rust artifacts
- Basic Cargo argument handling with release/debug mode selection

Key technical details include:
- The Rust library gets built as either `target/debug/libgit.a` or `target/release/libgit.a`
- Rust sources are tracked in `RUST_SOURCES` variable (currently just `src/lib.rs`)
- The build gets triggered via standard `cargo build` with appropriate flags
- Rust library gets linked into `GITLIBS` when `WITH_RUST` is enabled
- Adds `-DWITH_RUST` to CFLAGS when Rust is enabled

This patch builds on the Makefile refactoring from patch 2/9, enabling the conditional Rust compilation infrastructure while maintaining compatibility with existing build processes. It represents a core piece of the phased transition plan, allowing Rust to be optionally enabled in Git 2.52 before becoming mandatory in 3.0. The implementation follows Git's existing build system patterns while introducing minimal new complexity.
