This is a refactoring patch in the final stages of Ezekiel Newren's xdiff modernization series. It removes the redundant `diffdata_t` struct which was just duplicating fields already present in `xdfile_t`. The patch updates all callers to use `xdfile_t` directly instead.

The changes are straightforward mechanical replacements - each field in `diffdata_t` had a direct counterpart in `xdfile_t` (`nrec` -> `nreff`, `ha` -> `ha`, etc.). The patch simplifies the code by eliminating this unnecessary indirection layer while maintaining identical behavior.

This is part of the v5 series that concludes the xdiff refactoring work, which has already gone through several rounds of review and refinement. The changes are clean and focused, with no open questions remaining. The series as a whole modernizes xdiff's internals while preserving the exact same diff algorithm behavior, positioning the codebase better for potential future Rust integration.
