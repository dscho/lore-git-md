Refactoring patch in Patrick Steinhardt's packfile store series (v6 02/15). This moves the packfile list management from `struct object_database` to the new `struct packfile_store` introduced in the series.

The patch relocates the `packed_git` list from `object_database` to `packfile_store` (now named `packs`), updating all ~20 access sites to use the new location. It extracts packfile cleanup logic from `odb_clear()` into new `packfile_store_free()` and `packfile_store_close()` functions, with the latter handling the "do-not-close" validation previously done in `close_object_store()`. The changes are mechanical with no behavior modifications.

Key technical points:
- `packfile_store` gains `packs` field replacing `object_database::packed_git`
- New `packfile_store_close()` handles packfile closing with BUG check
- `packfile_store_free()` now handles packfile memory cleanup
- All packfile iteration sites updated to use `store->packs` instead of direct access
- MRU list management remains in object_database but now points to packs in store

This continues the architectural work from patch 01/15, completing the packfile list migration to the new store abstraction. The changes are straightforward with no noted controversies in the thread.
