This is the final patch in the `git repo stats` series, adding NUL-delimited output support as previewed in earlier patches. The feature completes the machine-parseable output options for repository statistics, complementing the existing table (human-readable) and keyvalue (newline-delimited) formats.

The implementation introduces a `nul` format option that produces the same key-value pairs as `keyvalue` but uses NUL characters as delimiters instead of newlines. This allows safe handling of values containing special characters without requiring quoting. The patch modifies the existing `stats_print()` function to accept a delimiter, with `\n` for keyvalue and `\0` for nul formats. Documentation updates clarify the new option and its relationship to the existing formats.

Test coverage verifies the nul format produces identical content to keyvalue (when NULs are converted to newlines) and handles edge cases like empty repositories. The implementation maintains the series' clean separation between data collection and presentation layers. With this addition, the `git repo stats` command now offers a complete set of output options suitable for both human consumption and programmatic use.
