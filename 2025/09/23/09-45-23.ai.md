This is a feature patch in the Rust infrastructure series, adding visibility into whether Git was built with Rust support. It's patch 4/9 in v6 of the series.

The patch modifies `help.c` to expose Rust build status through both `git version --build-options` and `git bugreport` outputs. This is positioned as a debugging aid since the transitional period will maintain both Rust and C implementations of some subsystems, making it possible for bugs to be Rust-specific. The implementation is straightforward, adding conditional output based on the `WITH_RUST` compile-time flag.

The change is technically simple but strategically important for the Rust transition, providing visibility into which code path is active when troubleshooting. It follows the pattern of other build-time feature reporting like fsmonitor status. The patch is cleanly implemented with a simple `#ifdef` check and matches existing output formatting conventions.

Key technical details for future reference:
- Adds Rust status reporting to version/build-info infrastructure
- Uses existing `WITH_RUST` build flag
- Output format matches existing feature reporting (e.g. fsmonitor)
- Affects `git version --build-options` and `git bugreport`
- Part of the phased Rust transition where implementations coexist

This continues the series' pattern of incremental, measurable progress on Rust integration while maintaining backward compatibility. The change is unlikely to be controversial as it provides clear operational value with minimal complexity.
