This is a documentation patch announcing the planned mandatory adoption of Rust in Git's build process, part of the ongoing Rust infrastructure series (now at v6). The patch adds a detailed entry to BreakingChanges.adoc outlining the phased transition plan:

1. Optional Rust support begins in Git 2.52 (auto-detected by Meson, disabled in Makefile)
2. Default-enabled in 2.53 (builds will fail without Rust unless explicitly disabled)
3. Mandatory in Git 3.0 (planned for late 2026, with build options removed)

The announcement acknowledges platform challenges (bootstrapping, toolchain availability) and proposes mitigation through a test balloon approach (currently demonstrated by the optional Rust varint implementation). A key governance element is the promise of an LTS release (the final pre-3.0 version) with extended maintenance for distributors needing more time to adapt.

The patch provides concrete build flags (`WITH_RUST=YesPlease`, `-Drust=enabled`) and leaves open the possibility of deferring the mandate if downstream impact proves too disruptive. This represents the formal policy counterpart to the technical groundwork laid in earlier patches of the series.
