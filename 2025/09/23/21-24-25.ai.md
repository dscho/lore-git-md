Refactoring patch in the xdiff modernization series, eliminating redundant field duplication in favor of direct xrecord_t embedding.

This patch continues Ezekiel Newren's systematic cleanup of xdiff internals, now focusing on the xdlclass_t struct which previously duplicated xrecord_t data (ha, line, size) as separate fields. The change replaces these with an embedded xrecord_t, simplifying type maintenance since future xrecord_t changes won't require parallel updates here. The modification affects xdiff/xprepare.c, updating the struct definition and all usage sites to reference fields through the new rec member.

Key technical points:
- Removes xdlclass_t.ha/.line/.size fields in favor of xdlclass_t.rec (xrecord_t)
- Updates xdl_classify_record() to access fields via rec member
- Maintains identical behavior while reducing code duplication
- Part of broader effort to eliminate redundant data structures in xdiff
- Follows earlier removal of diffdata_t wrapper and ha array storage

The change is straightforward with no behavioral impact, continuing the series' pattern of structural simplification while preserving algorithm semantics. Phillip Wood is credited for assistance, though no specific feedback is incorporated in this patch. This appears to be a clean, mechanical refactoring that positions the code better for future maintenance.
