This is the second patch in a series adding repository statistics functionality to Git, building on the initial reference counting from patch 1. The patch extends the new `git repo stats` command to count reachable objects by type (commits, trees, blobs, and tags) using the path-walk API.

The implementation adds a new `object_stats` struct to track counts and integrates with the existing table formatting from the first patch. Object counting happens by walking all objects reachable from regular references, with counts broken down by type. The output now shows both reference and object statistics in the same human-readable table format.

The patch includes thorough test coverage, verifying empty repository cases and populated repositories with various object types. The implementation appears cleanly separated from the presentation layer and builds on existing Git infrastructure like the path-walk API. This represents solid progress toward the series' goal of git-sizer-like functionality in core Git.

The changes are well-contained, touching only the repo command implementation, its documentation, and tests. The commit message clearly explains the motivation (understanding repository shape through object counts) and implementation approach. This looks like a well-executed incremental addition to the series.
