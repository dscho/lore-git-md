gitk bug report: right-click context menu fails on macOS ARM64 (Darwin 24.6.0) with Git 2.51.0 (clang 17.0.0). Reporter Marcin Wisnicki initially described reproducible issue where right-clicking commits in gitk's Tk interface showed no context menu on Apple Silicon Macs, while working correctly on Windows. The issue was resolved by upgrading from Homebrew's git package version 2.51.0_1 to 2.51.0_2, indicating the problem was packaging-specific rather than a fundamental Tk compatibility issue. The fix suggests a transient build configuration problem in the earlier Homebrew package, though no technical details were provided about the specific changes between versions. The thread is now closed with a simple solution for affected users - upgrading their Git installation through Homebrew. No changes to gitk's codebase were required.
