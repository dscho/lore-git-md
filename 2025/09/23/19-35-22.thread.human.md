This thread reports a platform-specific bug in gitk, Git's repository browser GUI. Marcin Wisnicki found that right-clicking on commits in gitk fails to show the expected context menu on macOS (ARM64, Darwin 24.6.0), while the same action works correctly on Windows. The issue occurs with Git 2.51.0 built with clang 17.0.0 on Apple Silicon Macs.

The bug affects basic gitk functionality, as context menus are commonly used for commit actions. The report provides clear reproduction steps but doesn't indicate whether this is a regression or long-standing behavior. Since gitk is maintained by Johannes Sixt (Hannes) and macOS is a mainstream platform, this issue is likely to draw attention from maintainers familiar with gitk's Tk interface code. No workarounds or error messages are mentioned in the initial report.
