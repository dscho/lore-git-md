The thread began with Marcin Wisnicki reporting a bug where gitk's right-click context menu failed to appear on macOS ARM64 systems (Darwin 24.6.0) when using Git 2.51.0. This affected basic GUI functionality on a mainstream platform, raising concerns about potential Tk event handling issues specific to the ARM64 architecture.

Marcin has since followed up to report that simply upgrading from Homebrew's git package version 2.51.0_1 to 2.51.0_2 resolved the issue. This indicates the problem was likely a packaging-specific regression or build configuration issue in the earlier Homebrew package, rather than a fundamental bug in gitk itself. While the exact technical details of what changed between the two Homebrew versions weren't provided, the complete resolution means affected users can fix the issue by updating their Git installation through Homebrew. The thread can now be considered closed with this straightforward solution.
