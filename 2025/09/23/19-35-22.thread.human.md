This thread reported and resolved a macOS-specific issue with gitk's right-click context menu failing to appear on Apple Silicon Macs running Git 2.51.0. The initial reporter, Marcin Wisnicki, found the problem was fixed by upgrading their Homebrew Git package from version 2.51.0_1 to 2.51.0_2, indicating a packaging issue rather than a code defect in gitk itself. Johannes Sixt later confirmed this was already tracked as issue #31 in gitk's repository, though no deeper technical analysis was provided. The solution remains straightforward: macOS ARM64 users experiencing this should upgrade their Git installation through Homebrew. No code changes to gitk were needed, and the thread can be considered closed with this simple workaround.
