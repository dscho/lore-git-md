This is part 9/15 of Patrick Steinhardt's packfile store refactoring series, which has already been merged. The series centralizes packfile management in a new `struct packfile_store` as groundwork for future pluggable object database backends.

This patch splits the responsibilities of `reprepare_packed_git()` by introducing a new `odb_reprepare()` function that handles the broader object database reloading tasks (alternates, loose object cache), while the renamed `packfile_store_reprepare()` focuses solely on packfile operations. The change is mechanical - 13 call sites are updated to use the new function name, with no behavior changes.

The refactoring makes the code's architecture clearer by properly separating packfile-specific operations from general ODB management. Since this is part of an already-reviewed and merged series, it represents a clean-up of the final implementation rather than proposing new changes. The patch follows the series' pattern of careful, incremental refactoring with thorough updates to all affected call sites.
