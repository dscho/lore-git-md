This is the third patch in Julia Evans' documentation series for `git-pull`. It removes an example from the man page that showed a merge scenario, since the example incorrectly implied that `git pull` defaults to merge (it actually defaults to `--ff-only`). The patch deletes 26 lines of example text and accompanying explanation.

The rationale is that the example was causing confusion by not matching the current default behavior, and that fast-forward merges are simple enough that they don't need an example. This continues the series' theme of streamlining the man page to focus on accurate, essential information while removing potentially misleading content.

This change follows logically from patch 2/4, which explicitly documented the four integration strategies and their defaults. The removal here prevents any contradiction with that clearer documentation. The patch is straightforward - it simply deletes the problematic example without replacement, keeping the technical content accurate while making the documentation more concise.
