This is a follow-up in the Git release notification discussion thread, providing an additional tool for tracking releases. Christian Couder shares information about the `getreleases` Python script (https://github.com/chriscool/getreleases) used by the Git Rev News team to automatically collect release announcements. The tool queries the Git mailing list archive for `[ANNOUNCE]` emails containing release information since a specified date, providing direct links to the official announcements which include full release notes.

The response offers a fourth notification method beyond the previously discussed options (GitHub feed, git-scm.com RSS, and RelNotes symlink tracking). This approach leverages existing mailing list infrastructure rather than creating new notification channels, though it requires running a local script rather than subscribing to a feed. The tool's output format shows it captures both final releases and release candidates, with direct links to Junio Hamano's announcement emails.

This contribution maintains the thread's technical focus while expanding the range of solutions, though it doesn't address the original request for push-based delivery (email/RSS). The script represents a middle ground between manual checking and automated feeds, suitable for users comfortable with command-line tools who want to avoid monitoring the RelNotes directory directly.
