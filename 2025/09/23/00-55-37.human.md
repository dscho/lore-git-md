This is a follow-up in the thread about deprecation warnings in Git 2.51.0, specifically regarding `git whatchanged` and date-filtered `git log` usage.

The original reporter, S0AndS0 of Digital Mercenaries LLC, acknowledges Kristoffer Haugsbakk's helpful response about replacing `git whatchanged` with `git log --raw --no-merges` (or alternative output formats like `--stat` and `--name-only`). They indicate they'll create an alias to help transition away from the deprecated command.

The email raises a new question about the other warning they encountered - regarding date filtering with `--since`. S0AndS0 asks if there's a new equivalent for time-based log filtering, suggesting they recall hearing about plans to deprecate this functionality but aren't certain. This remains an open question in the thread, as the previous response only addressed the `whatchanged` replacement.

The tone is appreciative of the help received so far while seeking clarification on the remaining deprecation warning. The thread continues to highlight user concerns about migrating from deprecated Git features to their modern equivalents.
