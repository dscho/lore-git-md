This thread discusses adding proper installation support for Git's libsecret credential helper in the contrib directory. The initial patch from M Hickford introduced standard installation rules in the Makefile, but Junio Hamano pointed out that it relies on undefined variables (INSTALL and gitexecdir) that aren't properly set up in this context. 

Junio noted that other contrib/Makefiles like subtree and contacts define these variables locally, and suggested this as a short-term solution. He also proposed a longer-term architectural improvement: factoring out these common definitions into a shared include file. The discussion has shifted from the initial implementation to addressing these technical gaps, with clear guidance provided for both immediate fixes and future improvements. The patch will need revision to properly handle the variable definitions before it can be merged.
