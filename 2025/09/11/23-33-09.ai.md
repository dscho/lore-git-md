Taylor Blau pushes back against Patrick Steinhardt's position that all callers of `get_all_packs()` should be reviewed individually. This affects several callers including `want_object_in_pack_mtime()` and `cmd_grep()`.

The discussion doesn't propose code changes to the merged series, but rather clarifies the behavioral differences that callers should be aware of.
