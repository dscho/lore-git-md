CI/build system follow-up addressing Meson build efficiency in documentation CI jobs. Patrick Steinhardt acknowledges SZEDER Gábor's observation that the Meson-based documentation verification jobs are unnecessarily compiling the entire Git codebase (1300+ targets) despite being configured with `-Ddocs=html,man` flags. This occurs because Meson's build system currently triggers full compilation even for documentation-specific configurations, creating significant overhead in CI runtime for what should be lightweight doc verification tasks. The email confirms an upcoming patch will address this optimization opportunity, building on the previously accepted Meson doc testing infrastructure (87eccc3a81d). The issue is isolated to build system behavior and CI scripts, with no impact on core Git functionality or documentation output quality. The exchange highlights an incremental improvement to the CI pipeline's efficiency, following the initial doc testing capability addition.
