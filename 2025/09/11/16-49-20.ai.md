This is the final patch in a 5-part bugfix series addressing issues with `git config get --type=color` functionality. The patch specifically prevents the pager from being spawned when printing ANSI color escape sequences, which was causing the color output to be incorrectly piped to the pager rather than appearing directly in the terminal.

The patch modifies the pager setup logic in `builtin/config.c` to skip `setup_auto_pager()` when the output type is `TYPE_COLOR`. It includes a new test case using the test-terminal infrastructure to verify that color output bypasses the pager while still respecting `core.pager` configuration. The change addresses a clear usability issue where color codes meant for terminal output were being incorrectly redirected.
