Maintenance patch for the libsecret credential helper's Makefile installation support.

Junio Hamano responds to M Hickford's initial patch adding installation support for the libsecret credential helper. He notes that while the patch adds the basic install target, it relies on undefined variables (INSTALL and gitexecdir) that aren't properly set up in this contrib/Makefile. He points out that other contrib/Makefiles like subtree and contacts define these variables locally, and suggests following that pattern as a short-term solution while proposing a longer-term cleanup of moving common definitions to a shared include file.

The key issues identified are:
1. Missing variable definitions (INSTALL, gitexecdir) that are only defined in the main Makefile
2. Current approach would make the install target fail
3. Temporary solution would be to copy the local variable pattern from other contrib/Makefiles
4. Future direction suggested is to factor out common definitions into a shared include file

This moves the discussion from the initial implementation to addressing technical gaps in the approach while proposing both immediate and architectural solutions. The response indicates the patch needs revision but provides clear guidance on how to proceed.
