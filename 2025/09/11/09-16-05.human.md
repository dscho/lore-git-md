This is a CI/build system patch series that optimizes documentation testing in the Git project's Meson build system. 

Patrick Steinhardt introduces a new "docs" alias in Meson to compile only documentation files rather than the entire Git project when running documentation tests in CI. This addresses an inefficiency pointed out by Gábor Szeder where the CI was unnecessarily building the full project just to verify manpages.

The 3-patch series first adds the docs alias capability to Meson, then enhances the build summary to show which documentation backend is being used, and finally updates the CI script to use this new target. The changes touch several documentation-related build files across different directories while keeping the actual documentation content unchanged.

The motivation is clear and the changes appear focused and well-contained. This should provide a nice speedup for documentation-related CI jobs while maintaining the same verification coverage. The patches look straightforward with clean commit messages and appropriate file modifications.
