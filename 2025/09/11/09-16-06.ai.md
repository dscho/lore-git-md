This is the first patch in a 3-part series introducing CI/build system optimizations for documentation testing in the Meson build system. The patch adds a new "docs" alias target that allows compiling only documentation without requiring a full Git build, addressing a current limitation where users had to build the entire project just to generate docs.

The technical changes modify multiple meson.build files (Documentation/, contrib/) to accumulate documentation targets in a new `doc_targets` list variable, then create an alias target in the root meson.build that depends on these. The key files touched are Documentation/*/meson.build for howto, technical, and manpage generation, plus contrib/contacts documentation. The root meson.build gets the new alias_target('docs') declaration.

This change is purely build-system related with no impact on Git functionality itself. The patch appears well-structured with consistent changes across all documentation targets, though it doesn't yet include test coverage verification of the new target. The change aligns with the series' goal of reducing CI resource usage by enabling documentation-only builds.
