This is a CI/build system patch series that optimizes documentation testing in the Meson build system. The series introduces a new "docs" build target that allows compiling only documentation without building the entire Git project, addressing an inefficiency reported by Gábor Szeder.

The key changes are:
1. Adding a "docs" alias in meson.build that depends only on documentation targets
2. Updating the meson summary output to show which documentation backend is being used
3. Modifying the documentation CI job to use this new target instead of a full build

The patch touches several documentation-related meson.build files to ensure they properly declare their outputs as documentation targets. The change is focused on the Meson build system and CI configuration, with no impact on actual Git functionality. This appears to be a straightforward optimization that should reduce CI resource usage for documentation testing jobs.
