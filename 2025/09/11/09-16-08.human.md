This is the third and final patch in a CI/build system optimization series for documentation testing. It completes the effort to reduce unnecessary CI resource usage by leveraging the new "docs" build target introduced in earlier patches.

The change modifies the documentation testing script to only build documentation when using Meson, rather than compiling the entire project. This addresses a reported inefficiency where CI jobs were needlessly building Git binaries during documentation tests. The patch is straightforward, changing two `meson compile` commands to explicitly target just the documentation.

As the final piece of the series, this implements the practical CI integration that makes use of the Meson build system improvements from patches 1 and 2. The change appears well-contained and properly motivated, with a clear downsides. With this patch, the series achieves its goal of optimizing documentation testing in the CI pipeline while maintaining all existing test coverage.
