This is a build system patch addressing installation support for the libsecret credential helper. Junio Hamano responds to M Hickford's initial patch that added basic `install` target rules, pointing out a missing piece in the implementation.

The original patch added standard installation rules using `$(INSTALL)` and `$(gitexecdir)` variables, but Hamano notes these variables aren't actually defined in the helper's Makefile or its included files. He suggests following the pattern seen in other contrib/ Makefiles (like subtree and contacts) by locally defining these variables as fallbacks. 

Hamano also proposes a longer-term solution: factoring out common definitions into a shared include file that both the main Makefile and contrib/ Makefiles could use, which would eliminate the current duplication across contrib/ components. The response is constructive, identifying both an immediate fix and a broader architectural improvement opportunity.

The patch appears straightforward but incomplete - it's a typical early iteration where maintainers help shape the solution before it's ready for merging. The discussion focuses on build system consistency rather than any functional concerns with the credential helper itself.
