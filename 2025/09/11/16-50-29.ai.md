This is a review comment on a test cleanup patch from the completed 5/5 series fixing `git config get --type=color` issues. Kristoffer Haugsbakk provides stylistic feedback on Patrick Steinhardt's patch that modernizes test expectations in t1300-config.sh.

The feedback focuses on several normalization patterns in the test file changes:
1. Moving test expectations from outside test bodies to inside using `cat >expect <<EOF` within each test
2. Consistently using `${SQ}` for single quotes in test expectations
3. Removing tabs when possible in here-documents
4. Using `<<\EOF` instead of `<<EOF` where variable expansion isn't needed
5. Normalizing test block formatting to consistently put the test body on new lines

Kristoffer notes a few minor inconsistencies in the application of these patterns, like a missing space in `>expect<<\EOF` and one case where `>expect` should be used instead of `> expect`. The feedback is thorough but acknowledges the overall correctness of the changes, suggesting these as potential style improvements rather than required fixes.

The review doesn't raise any technical concerns about the test changes themselves, which are part of a larger series that has already addressed the core color-handling issues. This appears to be final polish on test formatting before the series is merged.
