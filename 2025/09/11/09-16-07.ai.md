This is a CI/build system patch that enhances the Meson build system's summary output for documentation backends. It's the second in a 3-part series introducing documentation build optimizations.

The patch adds visibility into which documentation backend (Asciidoc or Asciidoctor) is being used during the build process. Currently this information is only available if explicitly requested via `-Ddocs_backend=`, but the change makes it appear automatically in Meson's summary output alongside other backend information like crypto and HTTPS implementations.

The technical changes modify meson.build to:
1. Set `docs_backend` to 'none' when documentation is disabled
2. Add the docs backend to the existing backends summary section

This builds on the first patch's introduction of documentation targets by providing better visibility into the build configuration. The change is straightforward and maintains consistency with how other backend selections are reported. As with the series' first patch, this appears well-structured but we haven't yet seen verification of the new summary output in action. The change is purely informational and doesn't affect build functionality.
