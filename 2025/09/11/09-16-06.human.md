This is a CI/build system patch that introduces a new "docs" target for the Meson build system, allowing documentation to be built independently from the rest of Git. Currently, building documentation requires compiling the entire project, which is inefficient for documentation-only workflows.

The patch modifies several meson.build files to collect all documentation targets into a `doc_targets` variable, then creates an alias target called "docs" that depends on these. This enables developers to run `meson compile docs` to build just the documentation. The changes are mechanical but thorough, updating documentation targets across the main documentation directories and contrib scripts.

This is the first in a 3-part series aimed at optimizing documentation testing in CI. The change is well-contained and appears to be a straightforward quality-of-life improvement for developers working with Git's documentation. The patch follows the established Meson build patterns and includes appropriate comments about the target placement.
