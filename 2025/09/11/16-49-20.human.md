Bugfix for `git config get --type=color` pager behavior. This is the final patch in a 5-patch series addressing color handling issues in Git's config command.

The patch fixes a case where `git config get --type=color` would incorrectly spawn a pager when outputting ANSI color codes. As Patrick Steinhardt notes in the commit message, this makes no practical sense since color codes are meant to be consumed directly by terminal applications rather than pagers. The fix simply skips pager setup when the output type is COLOR.

Kristoffer Haugsbakk's email provides minor editorial feedback on the commit message, suggesting small wording improvements ("though though" -> "though", adding a hyphen in "use-case"). The technical content of the patch itself appears sound and completes the series' goal of robust color handling in config output.

This concludes a well-structured series that:
1. Modernized related tests
2. Improved error handling
3. Fixed a regression in color parsing
4. Now addresses this pager interaction

The changes are focused and well-motivated, with clear explanations of both the problem and solution. The series appears ready for review and potential inclusion.
