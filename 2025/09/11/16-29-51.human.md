This is a follow-up discussion about code style in the already-merged first patch of Christian Couder's signature handling series for `git fast-import`. The exchange focuses on error handling patterns in the `parse_sign_mode()` function.

Junio Hamano responds to Patrick Steinhardt's earlier suggestion about making the error handling flow more natural by reversing the condition. The discussion shows consensus on the technical approach from both maintainers, with Patrick providing polish suggestions and Junio weighing in on readability tradeoffs.
