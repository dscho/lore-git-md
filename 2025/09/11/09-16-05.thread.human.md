This thread discusses optimizations to the Meson build system for documentation testing, originally prompted by Gábor Szeder's report about CI resource usage. The three-patch series (now at v1) introduces a new build target that allows compiling documentation without a full Git build, along with improvements to build visibility and CI integration.

The technical implementation is complete, with Patrick Steinhardt and Karthik Nayak as key participants. The patches add a `docs` alias for documentation-only builds, enhance Meson's summary output to show documentation configuration, and modify CI scripts to use the new target. A naming convention discussion resulted in Patrick proposing dual aliases (`doc` and `docs`) to satisfy both Make and Meson conventions.

Two open questions remain for maintainers to decide: whether to support both aliases as proposed, and whether documentation should be included by default in standard builds (matching Make behavior). Karthik's latest email acknowledges Patrick's review but doesn't advance these outstanding configuration questions. The series appears ready for merging once these final decisions are made.
