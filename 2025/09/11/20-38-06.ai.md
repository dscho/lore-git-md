This is a build system patch adding installation support for the libsecret credential helper. The patch introduces a new `install` target in the contrib/credential/libsecret/Makefile that properly installs the compiled helper binary into the Git exec directory.

The change is straightforward - it adds standard Makefile rules to create the target directory with proper permissions (755) and install the binary with executable permissions (755). The implementation follows Git's typical installation pattern using $(DESTDIR) and $(gitexecdir) variables for flexibility in installation locations.

The patch appears to be a simple quality-of-life improvement for packagers and system administrators who want to install the libsecret helper alongside other Git components. While small, it fills a gap in the build system that would otherwise require manual installation of this helper. The change is cleanly implemented and properly signed off.
