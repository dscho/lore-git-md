This is a code clarity refinement in the ongoing progress meter signal handling modernization effort. Carlo Marcelo Arenas Belón responds to Junio Hamano's suggestion about variable typing in the progress display code, proposing to use `bool` rather than `int` for the `update` flag that tracks progress state.

Carlo's response takes this one step further by advocating for the more semantically appropriate `bool` type, which would make the boolean nature of the variable immediately obvious to readers. This continues the thread's trend toward implementation polish after the core signal-free approach was settled.
