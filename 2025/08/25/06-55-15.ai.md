Documentation update for `git send-email` configuration with Gmail.

This patch updates the Gmail SMTP configuration examples in `git-send-email.adoc` to recommend using port 465 with SSL/TLS encryption instead of port 587 with STARTTLS. The author argues this is more secure, though the commit message doesn't provide specific security analysis. The changes affect both regular password and OAUTHBEARER authentication examples, consistently switching from `tls` to `ssl` encryption and from port 587 to 465.

The patch is narrowly focused on documentation and makes no functional changes to Git itself. It touches only the send-email documentation file, with straightforward replacements in two configuration examples. The change appears technically correct for the stated purpose, though some readers may want to understand the security rationale better or discuss whether this should be backported to older documentation versions.
