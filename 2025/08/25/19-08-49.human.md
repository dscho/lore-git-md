This is the first patch in a documentation series improving the `git-checkout` man page. It focuses on clarifying the introductory section and argument disambiguation behavior.

The patch makes several improvements to the DESCRIPTION section:
- Explicitly calls out the two main modes of `git checkout` (branch switching and file restoration) upfront
- Uses terminology that matches the newer `git switch` and `git restore` commands
- Provides a clearer explanation of how Git disambiguates arguments, with concrete examples of using `--` to force interpretation as either a branch/commit or pathspec

The changes appear well-considered, directly addressing user confusion points while maintaining technical accuracy. The patch maintains the same functionality while making the behavior more approachable, particularly for users who may not be familiar with Git's internal terminology like "tree-ish" and "pathspec". This is a solid start to the documentation improvement series.
