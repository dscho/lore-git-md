Follow-up discussion about experimental status warning for `extensions.compatobjectformat`. Junio C Hamano responds to Brian Carlson's documentation patch clarifying the feature's incomplete state. While agreeing the warning is needed, Hamano suggests the current "experimental" label may be too weak since the feature fundamentally doesn't work for its intended purpose (inter-repo object exchange). He proposes stronger wording emphasizing the extension exists solely for development purposes, not end-user functionality. The exchange highlights the tension between accurately describing partial implementations and setting user expectations, with both agreeing the current state could mislead users (especially Gitolite administrators) into thinking the feature is functional when it isn't. The core technical limitation remains that the implementation only handles loose objects, not packed objects, making push/fetch operations non-functional.
