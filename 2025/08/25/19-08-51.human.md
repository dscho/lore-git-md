This is the third patch in Julia Evans' documentation series for `git-checkout`, continuing the effort to make the man page clearer for experienced users. The patch focuses on removing potentially confusing "reset" terminology from two places in the branch switching section.

The changes replace technical Git jargon with more descriptive language. For the `-B` option behavior, it now explains that the branch is "forced to point at the commit" rather than using "reset". The transactional behavior explanation is also simplified to say the branch "will not be created or modified" unless the checkout succeeds, removing the more technical description of failure cases.

The patch maintains the series' net-zero line change approach (5 lines added, 6 removed) while improving clarity. This continues the pattern of making the documentation more accessible without altering any functionality. The changes address a specific pain point identified by users who found the "reset" terminology unclear.
