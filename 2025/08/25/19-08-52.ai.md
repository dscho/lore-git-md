This is the fourth patch in a documentation series improving the `git-checkout` man page. It focuses on deduplicating the explanation of the `--detach` option.

The patch simplifies the `--detach` section by removing redundant text that previously repeated much of the behavior already described in the main `git checkout <branch>` section. Instead, it now concisely states that `--detach` behaves like a regular checkout but points HEAD directly at the commit ID rather than the branch. The change maintains all technical accuracy while eliminating repetition, referring readers to the "DETACHED HEAD" section for additional details.

Key changes:
- Replaces 7 lines of detailed behavior description with a 2-line summary that leverages the existing branch checkout explanation
- Preserves the note about omitting the branch name defaulting to current branch tip
- Keeps the reference to the "DETACHED HEAD" section for comprehensive understanding

This continues the series' pattern of making the documentation more concise while maintaining clarity, with another net reduction in line count (3 added, 10 removed). The change addresses a specific redundancy identified in the user feedback that motivated this series.
