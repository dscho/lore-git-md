2. Improve the explanation of `git checkout <branch>`
3. Remove potentially confusing "reset" terminology
4. Deduplicate the `--detach` explanation
5. Clarify the file restoration section

The changes are purely documentation-focused, with no behavioral modifications to Git itself. The patch series touches only `Documentation/git-checkout.adoc`, showing a net change of 47 lines added and 47 removed - suggesting the improvements are more about rewording and reorganization than adding substantial new content.
