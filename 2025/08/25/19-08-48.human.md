This is a documentation patch series aimed at improving the clarity of `git-checkout`'s man page. Julia Evans presents 5 patches that rework the DESCRIPTION section based on feedback from 21 experienced users (split evenly between 5-10 and 10+ years of Git experience).

The series focuses on making the existing information more accessible while maintaining technical accuracy. Key improvements include: clarifying the introductory text, better explaining branch checkout behavior, removing potentially confusing "reset" terminology, deduplicating the --detach explanation, and making the file restoration section clearer.

The changes are purely editorial - no functionality is proposed - and the single documentation file is modified with a balanced set of insertions and deletions (47 lines each). The patches appear well-motivated by user feedback and target a command that's both fundamental and historically confusing to many users.
