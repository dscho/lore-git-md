This is a documentation patch updating the recommended Gmail SMTP settings for `git send-email`. Aditya Garg proposes changing the documented configuration from using port 587 with STARTTLS to port 465 with SSL/TLS encryption, noting this is more secure.

The patch updates two configuration examples in git-send-email.adoc, changing both the port number and encryption method. The commit message is straightforward but doesn't provide much technical rationale beyond stating that SSL/TLS is "more secure" than STARTTLS. The change appears technically sound, though some might want to see more discussion about why this is preferable (e.g., whether there are any compatibility tradeoffs).

The patch is narrowly focused and correctly updates both the basic and OAUTHBEARER authentication examples consistently. While small, it's a useful update to keep Git's documentation aligned with current best practices for email security.
