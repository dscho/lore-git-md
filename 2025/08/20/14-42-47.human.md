Feature patch adding object format reporting to `git repo info`. This is the second patch in a GSoC contributor's series, following an earlier patch that added a `-z` flag for null-terminated output.

The patch adds a new `objects.format` field to `git repo info` that reports the repository's object format (SHA-1 or SHA-256), matching the functionality of `git rev-parse --show-object-format`. The implementation exposes the hash algorithm name from the repository's `hash_algo` struct through a new `get_objects_format` helper.

The changes include documentation updates, the core implementation in builtin/repo.c, and new tests verifying both SHA-1 and SHA-256 cases. The patch has mentor sign-offs from established contributors, suggesting it's part of a properly supervised GSoC project. The implementation appears straightforward and follows existing patterns in the codebase.

This completes the two-part series that enhances `git repo info` with both output formatting control and additional repository metadata. The changes are logically separate but related to the same command, making them reasonable to submit together despite being independent features.
