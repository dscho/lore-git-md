This is a test patch in the ongoing submodule gitdir path encoding series. Josh Steadmon provides feedback on Adrian Ratiu's test script for handling mixed legacy and new-style submodule paths.

The patch adds basic tests for submodules using both legacy (.git/modules) and new encoded (.git/submodules) paths, verifying their coexistence, creation, and push/pull behavior. The test creates repositories with both path types and checks their proper handling during clone operations.

Josh points out a specific improvement - suggesting the use of `test_grep` instead of plain `grep` in the test assertions for better consistency with Git's test framework. This is a minor but important style point that aligns with Git's testing conventions.

The feedback is focused on test quality rather than the core functionality, which appears to be working as intended. This patch is part of a larger series that's currently in refinement, with reviewers examining platform-specific edge cases and test coverage completeness.
