This is a documentation patch addressing toolchain compatibility in Git's man pages. It's part of Jean-Noël Avila's ongoing effort to standardize Git's documentation format, specifically fixing rendering issues between different AsciiDoc processors.

The patch modifies the verbatim syntax in `pretty-formats.adoc` to ensure consistent rendering between Asciidoc.py and Asciidoctor. The key change doubles the `+` markers around parentheses and arrows in the `prefix` and `pointer` defaults for the `%(decorate)` format specifier. This addresses SZEDER Gábor's reported issues where Asciidoctor 2.0.16 was producing unwanted `+` characters and converting Unicode arrows incorrectly.

The changes maintain identical functionality while improving rendering consistency across toolchains. The patch has already been approved by Junio Hamano as part of a larger series and is marked for merging into the 'next' branch. While the technical work is complete, Junio has raised a documentation question about why some elements require doubled `+` markers while others don't, which may inform future documentation practices.
