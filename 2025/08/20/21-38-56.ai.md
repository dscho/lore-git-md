This is a code review comment in the ongoing submodule gitdir path encoding series. Josh Steadmon points out a test improvement opportunity in Adrian Ratiu's patch 3/9, which introduced config override functionality for submodule gitdir paths.

The specific issue is about test script style - Josh suggests replacing the subshell-based `(cd test-submodule && git config ...)` pattern with the more idiomatic `test_config -C test-submodule` helper functions in t7400-submodule-basic.sh. This would make the test both more concise and more consistent with Git's test suite conventions.

The test in question verifies that the new `submodule.<name>.gitdirpath` config setting properly overrides the default encoded path location for submodule gitdirs. While the test's core functionality isn't being questioned, the implementation could be cleaned up to follow established test patterns.

This is a relatively minor refinement in the context of the larger series, which is currently addressing more significant platform-specific issues (Windows pathconf() compatibility, format string portability) and test coverage gaps identified by other reviewers. The core path encoding mechanism remains unchanged.
