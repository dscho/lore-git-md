This is the second patch in a feature series enhancing `git repo info`, adding repository object format information. The patch introduces a new `objects.format` field that exposes the repository's hash algorithm (sha1 or sha256), equivalent to `git rev-parse --show-object-format`.

The implementation adds a new field handler in builtin/repo.c that reads from `repo->hash_algo->name`, updates the documentation in git-repo.adoc, and includes tests verifying correct output for both sha1 and sha256 repositories. The changes follow the same pattern as existing fields in `git repo info` and maintain consistency with Git's object format handling.

The patch appears well-structured with clear documentation and test coverage for both supported hash algorithms. It has mentor sign-offs from established contributors (Karthik Nayak and Patrick Steinhardt) as part of the GSoC project. The change is straightforward and uncontroversial, providing useful repository metadata through the `git repo info` interface rather than requiring separate `rev-parse` calls.

This completes the two-part series that began with adding a `-z` flag for null-terminated output. Both patches are independent enhancements to `git repo info` that follow established Git conventions.
