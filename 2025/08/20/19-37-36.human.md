This is a test improvement patch in the ongoing submodule gitdir path encoding series. Josh Steadmon points out an inaccuracy in Adrian Ratiu's test helper function from patch 3/9 of the series.

The helper function `verify_submodule_gitdir_path()` claims to verify a submodule's gitdir path, but actually only checks the legacy path location (`.git/modules/$path`) without verifying the fallback encoded path (`.git/submodules/$encoded_path`). The test case itself demonstrates proper behavior by testing the config override mechanism, but the helper's documentation doesn't match its actual capabilities.

The observation doesn't require any immediate changes to the functionality, but suggests the test helper's comment should be clarified to accurately reflect what it verifies. This is a minor code review note in a series that's already undergoing platform-specific fixes and improvements.
