Bugfix series addressing missing singleton objects in `git repack -adf --path-walk`. This is a regression introduced by the recent `--path-walk` feature that can cause certain objects to be omitted from repacks under specific conditions.

The issue occurs when: (1) a path has only one version in the history being repacked, (2) that path is in the index, (3) the object isn't loose, and (4) sparse pack mode is enabled (the default). Users may not notice until fetching, when missing delta bases cause problems. The series includes a test demonstrating the failure (patch 1) and a solution (patch 2) that fixes initialization of pending objects during path walking.

Patch 3 refactors the initialization code to prevent similar oversights in the future. The author notes this slipped through partly due to over-reliance on bare repo testing during development. The fix appears well-considered, with test coverage for the edge case, and the impact is significant enough that it warrants attention from anyone who might be using the `--path-walk` feature.
