Feature patch adding `-z` shorthand to `git repo info` as part of a GSoC project.

This first patch in a 2-part series adds a `-z` flag to `git repo info` as an alias for `--format=nul`, following Git's convention where other commands like `git config` and `git status` use `-z` for null-terminated output. The implementation is clean and consistent with existing patterns, including proper error handling when `-z` is used with `--format`.

The patch touches documentation, core command implementation, and adds new test cases. The changes are straightforward:
- Updates the man page to document the new `-z` option
- Modifies the option parsing in builtin/repo.c to handle the new flag
- Adds tests verifying both the successful null-terminated output and the error case for conflicting format options

As a GSoC contribution, the patch shows good attention to detail with proper test coverage and documentation updates. The implementation follows established Git conventions, making it likely to be well-received. The patch is part of a small series that also adds object format reporting, though this first change stands on its own as a simple usability improvement.
