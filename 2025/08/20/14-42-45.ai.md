This is a feature patch series (2 parts) adding two small but unrelated enhancements to `git repo info`. The series comes from a GSoC contributor and consists of two independent changes bundled together to avoid merge conflicts.

The first patch introduces a `-z` flag as a shorthand for `--format=null` in `git repo info`, implementing a feature request from prior discussion. This follows Git's convention of using `-z` for null-terminated output formats elsewhere in the codebase.

The second patch adds an `objects.format` field to `git repo info` output, which exposes the same object format information available via `git rev-parse --show-object-format`. This provides a more convenient way to access this information through the repo info interface.

The changes are straightforward with clean implementations - each adds about 20 lines of code including tests. The patches touch documentation and test files appropriately, with the test additions in t1900-repo.sh providing coverage for both new features. The changes are small and focused, though some might question bundling unrelated features in one series despite the author's rationale about avoiding merge conflicts.
