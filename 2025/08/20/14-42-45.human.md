This is a feature patch series introducing two small but unrelated enhancements to `git repo info`. The changes come from a Google Summer of Code contributor.

The first patch adds a `-z` flag as a shorthand for `--format=null`, fulfilling a request from a previous discussion. This provides a more convenient way to get null-terminated output for scripting purposes.

The second patch adds an `objects.format` field that reports the repository's object format (like `git rev-parse --show-object-format` would), making this information available through the structured `git repo info` output.

Both changes are straightforward with clear motivations. The patches include documentation updates and new test coverage, suggesting they were developed carefully. Since these are small, independent quality-of-life improvements, they seem likely to be uncontroversial additions to the `repo` subcommand.
