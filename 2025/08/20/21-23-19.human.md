This is the final patch in a completed documentation series standardizing Git's man page formatting. The patch specifically addresses a compatibility issue between different AsciiDoc processing tools (asciidoc.py and Asciidoctor) in how they handle verbatim formatting of the `%(decorate)` section in `pretty-formats.adoc`.

The core fix changes the syntax markers from single `+` to double `++` around parentheses and arrows in the default values for `prefix` and `pointer` options, creating "unconstrained" spans that render consistently across both toolchains. The issue stemmed from differing interpretations of `{nbsp}` as a word boundary character between the tools.

Jean-Noël Avila provides a technical explanation of the toolchain differences in the commit message, which Junio Hamano requested be included for future reference. The patch maintains identical functionality while ensuring consistent rendering, completing the documentation standardization effort that will now be merged into the 'next' branch.

This represents the last-mile polish on a comprehensive documentation improvement that has gone through three versions and careful review, demonstrating attention to content accuracy and cross-toolchain compatibility.
