This is a refactoring patch series that's part of the ongoing effort to reduce global state in Git's codebase. Justin Tobler proposes removing global transaction state from the bulk-checkin subsystem, which handles batched writes to Git's object database.

The series consists of 3 patches that:
1. Introduce a new `struct object_database` to hold transaction state
2. Remove the existing global variables tracking this state
3. Wire up repository-specific handling

The changes touch several core commands (`add`, `update-index`, `unpack-objects`) and key subsystems (bulk-checkin, cache-tree, object-file). The motivation is clearly stated as preparation for future work to move transaction interfaces into "odb.h".
