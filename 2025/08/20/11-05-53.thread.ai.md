Thread identity: Bug report and fix series addressing inconsistent color handling in Git's interactive patch mode (`--patch`) across subcommands, originating from a user report about color configuration issues.

Core problem: Multiple Git commands (`stash push/save`, `checkout`, `reset`, `restore`) had color configuration (`color.diff` and `color.ui` settings) handling regressions in interactive patch mode since the 2021 Perl-to-C conversion (commit 0527ccb1b5). Jeff King has now identified and fixed four related issues through a technical patch series, building on earlier discussion of workarounds.

Current status: A four-patch series has been submitted that:
1. Fixes `stash` color handling when spawning `diff-tree` child processes, including edge case with `GIT_PAGER_IN_USE` environment variable
2. Makes `add-interactive` respect `color.diff` settings
3. Implements proper fallback to `color.ui` when other color configs aren't set
4. Updates `diff-highlight` documentation to include the `interactive.diffFilter` workaround

Key technical details:
- Commands affected/fixed: `stash push/save`, `checkout`, `reset`, `restore` in `--patch` mode
- Root causes addressed:

- Core fixes:

- Configuration settings now properly handled:
