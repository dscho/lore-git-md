This thread introduces two independent but complementary enhancements to `git repo info` from a Google Summer of Code contributor. The first patch adds a `-z` flag as shorthand for `--format=null`, following Git's convention for null-terminated output seen in commands like `git config` and `git status`. The second patch adds an `objects.format` field that exposes the repository's object format (sha1 or sha256), matching the output of `git rev-parse --show-object-format`.

Both patches have mentor sign-offs from established contributors Karthik Nayak and Patrick Steinhardt, indicating they've been vetted as part of the GSoC process. The implementations follow Git conventions - the `-z` flag mirrors behavior from other commands, while the object format field uses the existing `repo->hash_algo->name` infrastructure. Each patch includes thorough documentation updates and test coverage, with the object format tests verifying behavior for both sha1 and sha256 repositories.

The changes are straightforward and uncontroversial, providing quality-of-life improvements to `git repo info`. The first makes null-terminated output more accessible, while the second consolidates repository metadata access by eliminating the need for separate `rev-parse` calls. With both patches now posted and reviewed by mentors, the series appears ready for consideration by the maintainer.
