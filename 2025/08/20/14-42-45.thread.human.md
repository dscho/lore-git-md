This thread covers two straightforward enhancements to `git repo info` from GSoC contributor Lucas Seiki Oshiro: adding a `-z` flag for null-terminated output and exposing the object format (matching `git rev-parse --show-object-format`). Both patches are technically ready with mentor sign-offs from Karthik Nayak and Patrick Steinhardt.

The main discussion has centered on naming conventions - the object format field is now settled as `object.format`, while the naming for the references format field (`reference.format` vs `ref.format`) remains the last open question. Junio Hamano has provided guidance on documentation formatting and probed the future extensibility of the dot-separated naming scheme. The latest email confirms that since the base `lo/repo-info` topic has now merged to master, these patches can target master directly, resolving a previous documentation point about dependencies. 

With the naming questions nearly settled and the technical implementation approved, these small but useful quality-of-life improvements appear ready for merging in the near future.
