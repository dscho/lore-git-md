This is a test improvement suggestion in the ongoing submodule gitdir path encoding series. Josh Steadmon points out that the test case for gitdir path config overrides could be made cleaner by using Git's test helper functions `test_config` and `test_unconfig` with the `-C` option, rather than explicit subshells with `cd` commands. This is a minor but worthwhile cleanup that follows Git's test suite conventions better.

The suggestion comes in response to Adrian Ratiu's test patch that verifies the submodule gitdir path config override functionality works correctly - showing that paths can be customized via config and properly revert to defaults when unset. While the test works as written, Josh's recommendation would make it more idiomatic and potentially more robust.

This is part of the broader effort to improve test coverage and quality in the submodule path encoding series, where reviewers are catching various test-related issues across different platforms and scenarios. The core functionality being tested here (configurable gitdir paths for submodules) remains unchanged by this suggestion.
