Refactoring patch in the `the_repository` removal series, fixing integer types in commit-graph options.

This third patch in Patrick Steinhardt's series addresses type inconsistencies in the commit-graph write options. The "max-commits" and "size-multiple" options were incorrectly using signed integers despite being documented as positive-only values, which triggered sign comparison warnings. The change converts these to unsigned types and updates the option parsing to use `OPT_UNSIGNED()`.

The fix is straightforward and mechanical, affecting three files with minimal line changes (6 insertions, 7 deletions). The commit message clearly explains the rationale - these values should never be negative, and the signed types were likely just an oversight since `OPT_UNSIGNED()` is a relatively recent addition. This aligns with the series' broader goal of cleaning up the commit-graph implementation, though it's more of a general code quality improvement than directly related to removing `the_repository` dependencies.

No test changes are included, suggesting the modification maintains existing behavior while just making the types more accurate. The patch appears well-scoped and uncontroversial, fixing a clear inconsistency in the codebase.
