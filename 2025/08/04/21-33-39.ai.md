This is a refactoring patch that adds tracing support for unsigned integers, part of the ongoing `the_repository` removal effort.

Taylor Blau reviews Patrick Steinhardt's addition of `trace2_data_uintmax()` to complement the existing `trace2_data_intmax()` function. The new function follows the same pattern as its signed counterpart, formatting an unsigned integer value into a string buffer before passing it to the trace2 string logging system. The implementation is straightforward - it checks if tracing is enabled, formats the value using PRIuMAX, and delegates to the string logging function.

Blau notes the implementation is a faithful copy of the signed version and briefly considers (but dismisses) the idea of using a macro instead. The change is uncontroversial and serves as infrastructure for later patches in the series that will use unsigned counters for bloom filter statistics. This is a small but necessary piece of the larger commit-graph refactoring effort to remove global state dependencies.
