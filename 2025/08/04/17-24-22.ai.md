This is a "What's cooking" status update from Junio Hamano, summarizing the current state of patches in the Git development tree as of August 2025. The report follows the usual format of grouping patches by their integration status (new topics, graduated to master, cooking, and discarded), with brief descriptions of each patch series.

The update notes that Git 2.51-rc0 was just tagged, marking the start of a shorter-than-usual 8-week release cycle. Several new topics have been added, including two compiler warning fixes (dl/squelch-maybe-uninitialized and jk/revert-squelch-compiler-warning) that will merge to 'next'.

A significant number of topics have graduated to 'master', including various test fixes, Windows compatibility improvements, documentation updates, and the removal of `the_repository` wrapper functions from the config API (ps/config-wo-the-repository). The `git switch` and `git restore` commands are no longer marked as experimental (jt/switch-restore-no-longer-experimental).

Several cooking topics show ongoing work, including reftable cleanups (ps/reftable-libgit2-cleanup), a new `--max-depth` option for `git diff-tree` (tc/diff-tree-max-depth), and improvements to remote renaming (ps/remote-rename-fix). The `git send-email` command is gaining IMAP sent mail folder support (ag/send-email-imap-sent), while `git sparse-checkout` is getting a new 'clean' subcommand (ds/sparse-checkout-clean).

The update also mentions some discarded experiments, including a test balloon for compound literals (pw/compound-literal-test-balloon) and a change to make tag creation idempotent (jc/tag-idempotent-no-op) that won't proceed.
