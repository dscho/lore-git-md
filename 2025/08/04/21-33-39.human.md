This is a refactoring patch that adds unsigned integer tracing support to Git's Trace2 performance monitoring system. Taylor Blau reviews Patrick Steinhardt's addition of `trace2_data_uintmax()`, which mirrors the existing `trace2_data_intmax()` function but handles unsigned values. The implementation is straightforward - it follows the same pattern as the signed version, just using the `PRIuMAX` format specifier instead.

Blau notes the implementation is correct and considers (but dismisses) the idea of using a macro instead, suggesting the explicit function is preferable. This change is part of Steinhardt's larger series removing global state dependencies from the commit-graph subsystem, where the new function will be used to log unsigned values in subsequent patches. The review is positive with no requested changes.
