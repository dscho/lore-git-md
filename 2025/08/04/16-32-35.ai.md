This is a feature and maintenance pull request for gitk, the Git repository visualizer, with contributions from multiple authors. The changes focus on Tcl/Tk 9 compatibility, reference filtering, and UI improvements.

The pull request merges several branches with distinct improvements. Mark Levedahl's changes (8 commits) handle Tcl/Tk 9 compatibility, including path expansion, file input, encoding conversions, while also updating scrolling behavior for newer Tcl/Tk versions. Johannes Sixt's merges incorporate these changes along with other branches that improve reference handling - Michael Rappazzo's commit filters invisible upstream refs, while Ori Avtalion adds a user preference to hide specific references. Ilya Grigoriev documents the glob pattern support in reference hiding preferences. Alexander Shopov updates the Bulgarian translation while removing some location-specific strings.

Key technical details include: the introduction of `-profile tcl8` flags for compatibility, new `hide_refs` preference supporting glob patterns, color handling improvements in the preferences dialog, and Tcl/Tk version requirement updates to support 9.0+. The changes touch core gitk functionality (reference display, UI preferences) and build compatibility (Tcl/Tk version handling), with significant updates to the translation file (375 lines removed from po/bg.po). The merges suggest these changes have been reviewed in separate topic branches before being combined here.
