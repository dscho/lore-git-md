This is a "What's Cooking" status update from Junio C Hamano, summarizing the current state of Git development branches as of August 2025. These periodic emails provide a high-level overview of patches that are being considered for inclusion in Git, organized by their current integration status.

The update covers several categories of changes:

1. **Recently graduated to 'master'**: 13 patches have been merged, including documentation updates for `git imap-send`, macOS build fixes, test helper cleanup, CI improvements, and various code cleanups. Notable changes include a new `--start-after` option for `git for-each-ref` and a `pull.autoStash` config option.

2. **New topics**: 10 new patch series proposed for inclusion, including documentation updates, Windows compatibility fixes, a `--max-depth` option for `git diff-tree`, and optimizations to `git describe`. Some of these are already marked for merging to 'next'.

3. **Cooking topics**: 20 ongoing patch series in various states of review, including major refactoring work to remove `the_repository` usage from config and object-file subsystems, sparse-checkout improvements, reflog migration fixes, and a proposed new `git last-modified` command. Several of these are waiting for rerolls or further review.

4. **Discarded topics**: 2 proposals that won't be moving forward, including a test balloon for compound literals and a change to make tag creation idempotent.

The email also notes that Git 2.51-rc0 is planned for imminent release and provides pointers to various Git repository mirrors and documentation sources. This status update serves as both a progress report and a call for review on the pending changes, particularly those marked as needing comments or expecting rerolls.
