This is part 6/9 of Patrick Steinhardt's series to remove global state dependencies from the commit-graph subsystem, continuing the broader `the_repository` removal effort.

The patch refactors how the commit-graph stores hash algorithm information, changing from storing just the hash length (`hash_len`) to storing the full hash algorithm pointer (`hash_algo`). This is a preparatory change that will allow subsequent patches to pass around the complete hash algorithm information rather than just its size. The change is mechanical, updating all references from `g->hash_len` to `g->hash_algo->rawsz` throughout commit-graph.c.

The diff shows 36 lines changed across commit-graph.c and commit-graph.h, with straightforward replacements of the hash length field access. The changes are consistent and maintain the same behavior, just using the more complete hash algorithm information now available. This aligns with the series' goal of making hash algorithm handling more explicit rather than relying on the global `the_hash_algo`.

No functional changes are introduced - this is purely an internal refactoring to support future work. The patch follows the established pattern in this series of incrementally converting global dependencies to explicit parameters while maintaining existing behavior.
