This is part 5 of Patrick Steinhardt's series to remove global state dependencies from the commit-graph subsystem, continuing the broader `the_repository` removal effort.

The patch converts two hash-algorithm-dependent macros (`GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE`) into functions that take the hash algorithm as an explicit parameter, rather than implicitly using the global `the_hash_algo`. This is a refactoring change that doesn't alter behavior - it just moves the code toward the series' goal of eliminating global state. The changes are mechanical but touch several parts of commit-graph.c where these macros were used for size calculations.

The conversion is straightforward and maintains the same calculations, just with explicit parameter passing. All call sites are updated to pass `the_hash_algo` (for now), keeping the same behavior while making the dependencies clearer. This is a typical incremental step in the global state removal work - not flashy, but moving things in the right direction with minimal risk.

The patch follows the established pattern seen in earlier parts of the series, focusing on type safety and explicit dependencies. Like the rest of the series, it's a behavior-preserving change with no test updates needed. The changes are localized to commit-graph.c and don't affect other subsystems.
