This is a refactoring patch from Patrick Steinhardt that's part of the larger reflog migration infrastructure series. The patch exports the `ref_transaction_update_reflog()` function from refs.c to refs.h, making it available to other parts of the codebase that need to write reflog entries. 

The change is straightforward - it removes the now-unused `flags` parameter since all callers were using the same flags anyway. Toon Claes pointed out a minor formatting issue (a missing space after "to" in a comment) that Patrick notes was already fixed in the post-image version of the patch.

This appears to be a clean, mechanical change that enables future work in the series by exposing needed functionality. The patch has already been merged as part of the completed series, with this particular change being a preparatory step for subsequent patches that will use the exported function.
