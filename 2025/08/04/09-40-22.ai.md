Bugfix in the reftable writer interface, part of the libgit2 compatibility series.

This first patch in the v2 series fixes a type mismatch in the reftable writer interface. The functions `reftable_writer_add_refs()` and `reftable_writer_add_logs()` currently accept an `int` parameter for the number of records, while all callers pass a `size_t`. The patch updates both the function signatures and their implementations to consistently use `size_t`, which is the more appropriate type for array sizes.

The changes are straightforward - updating the function declarations in reftable-writer.h and adjusting the implementations in writer.c to use `size_t` for the loop counters as well. The patch also cleans up the formatting slightly by removing unnecessary braces around single-line loops. This appears to be a simple but important fix for type safety in the reftable interface, particularly relevant for the libgit2 integration where these interfaces are being exercised more thoroughly.

Key technical details:
- Changes function signatures in reftable-writer.h
- Updates implementations in writer.c to match
- Uses `size_t` consistently for array sizes
- Affects both ref and log record writing paths
- Part of broader libgit2 compatibility effort
