Refactoring patch completing the commit-graph subsystem's removal of `the_repository` dependencies. This is the final patch in Patrick Steinhardt's 9-part series eliminating global state from the commit-graph code.

The patch removes redundant repository parameters from commit-graph functions where the repository can be obtained from the object database source parameter instead. This avoids potential mismatches when the passed repository doesn't match the source's actual repository. The one exception is `load_commit_graph_chain_fd_st()`, which needs to work across multiple object databases.

The changes are mechanical but thorough, touching nearly all commit-graph operations including loading, verification, and traversal. The patch follows the established pattern of the series by maintaining all existing behavior while making the code more robust against incorrect repository usage. With this change, the commit-graph subsystem no longer depends on `the_repository` global, marking a significant milestone in the broader effort to enable pluggable object storage backends.
