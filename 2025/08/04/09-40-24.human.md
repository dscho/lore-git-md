This is a platform compatibility patch in Patrick Steinhardt's ongoing reftable/libgit2 compatibility series (v2, patch 3/6). It addresses a compiler warning that surfaces when building reftable code with older toolchains, specifically when initializing nested structs with `{0}` syntax.

The change is minimal - replacing `{0}` with `{{0}}` in a macro definition to silence the warning while maintaining identical functionality. The commit message explains this is a pragmatic exception to Git's usual stance on ignoring warnings from old compilers, made necessary because libgit2 (which uses reftable as a library) encounters this issue in its build pipeline.

This appears to be a straightforward, uncontroversial change that keeps the reftable codebase more portable for external consumers. The patch references prior discussion about compiler warning policies, showing the author has considered the broader context before making this exception.
