This is a test fix addressing Meson build compatibility. 

Toon Claes fixes test 't0450' to work with out-of-tree builds when using Meson. The test was incorrectly using `$GIT_BUILD_DIR` to locate documentation sources, which doesn't work for Meson builds where the build directory is separate from the source. The patch changes this to use `$GIT_SOURCE_DIR` instead, which properly points to the source tree location regardless of build configuration.

The change is straightforward - a single line modification to the test script that replaces one environment variable reference with another.
