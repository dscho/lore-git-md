Final patch in the series removing redundant repository parameters from commit-graph functions. This completes the transition to repository-independent commit-graph operations by eliminating cases where both a repository and odb_source were passed when the source already contains repository context. The change affects core commit-graph loading, verification, and helper functions, with one exception for `load_commit_graph_chain_fd_st()` which handles cross-repository chain files. 

Key technical details:
- Removes `struct repository*` parameter from 15+ commit-graph functions where `odb_source` provides equivalent context
- Updates all callers to pass only the odb_source when possible
- Preserves special handling for chain files via `object_database*` parameter in `load_commit_graph_chain_fd_st()`
- Modifies verification to use repository from graph's odb_source rather than passed parameter
- Updates test helper to match new function signatures
- Maintains all existing behavior while reducing parameter redundancy

The changes are mechanical and build on the foundation established in earlier patches, completing the subsystem's transition away from direct `the_repository` usage. No test modifications were needed, confirming behavior preservation. This final patch achieves the series' aim of making commit-graph operations fully repository-aware without global state.
