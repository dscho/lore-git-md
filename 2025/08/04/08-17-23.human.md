This is part 7/9 of Patrick Steinhardt's series to remove global state dependencies from the commit-graph subsystem, continuing the broader `the_repository` removal effort. The patch focuses on eliminating uses of `the_hash_algo` global variable, which it makes progress but doesn't fully complete the job.

The changes are mechanical but widespread, touching commit-graph file parsing, verification, and writing logic. The key transformation is passing hash algorithm information explicitly through function parameters rather than relying on the global. The patch updates function signatures (like `parse_commit_graph()` and `open_commit_graph_chain()`) to take a `hash_algo` parameter, and propagates this through the call stack.

While most changes are straightforward parameter additions, there are some subtle adjustments like fixing size calculations that previously used `the_hash_algo->rawsz`. The author notes this is an intermediate step - some uses of `the_repository` remain and will be addressed in later patches. The changes maintain all existing behavior while making the hash algorithm dependency explicit.

This continues the series' pattern of careful, incremental refactoring with no functional changes. The patch is cleanly focused on its stated goal and appears well-tested, though like the rest of the series it doesn't include new test cases since behavior isn't changing. It's another solid step toward the long-term goal of removing global state.
