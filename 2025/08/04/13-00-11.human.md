This is a bugfix addressing a compiler warning in the revert/cherry-pick code. When built with clang-22 in DEVELOPER mode, Git fails to compile due to a warning about an uninitialized const variable that serves as a sentinel value for detecting whether gpg_sign was set.

The patch explains that while the code is correct (the variable's address is used as a sentinel, not its value), the compiler reasonably flags the uninitialized const as suspicious. Jeff King considers several solutions and opts for the simplest: initializing the variable to 0 with a comment explaining the value doesn't matter. The change is minimal (one line) and focused on making the code compile cleanly while maintaining the existing behavior.
