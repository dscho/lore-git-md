This is a refactoring patch that extracts core logic from `git for-each-ref` into a shared helper function, part of the `git refs list` series. 

The patch moves the core ref listing functionality from `cmd_for_each_ref()` into a new `for_each_ref_core()` helper function in preparation for sharing this logic with the upcoming `git refs list` command. The original command becomes a thin wrapper that just defines its usage string and calls the shared helper. A new header file `for-each-ref.h` is introduced to expose the shared functionality, containing both the helper function declaration and a `COMMON_USAGE_FOR_EACH_REF` macro for standardized option documentation.

The changes are cleanly separated - the diff shows the existing logic being moved with minimal modifications, just parameterizing the usage string. This follows the architectural pattern suggested by Junio Hamano and maintains all existing behavior while enabling code reuse. The patch has multiple mentors signed off and appears well-vetted through several iterations of review.

This is the third of six patches in the series, focusing on the core refactoring needed before introducing the new `refs list` command in subsequent patches. The changes here are foundational but don't yet add any user-visible functionality.
