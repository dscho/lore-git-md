This is a technical refactoring patch in the ongoing `the_repository` removal effort, specifically part 6/9 of Patrick Steinhardt's series to eliminate global state dependencies in the commit-graph subsystem.

The patch changes how the commit-graph stores hash algorithm information - instead of just storing the hash length, it now stores a pointer to the full hash algorithm structure. This prepares for future need to pass around the complete algorithm information rather than just its length.

Taylor Blau reviews the patch positively, noting it makes sense and that existing validation in `parse_commit_graph()` already handles potential hash version mismatches by comparing the stored hash_version against the current algorithm. Unlike some earlier patches in the series that sparked debate about integer types, this change appears uncontroversial and technically sound.

The change is purely internal - no user-visible behavior is modified - and continues the commit-graph subsystem's transition away from global state while maintaining all existing validation checks. It represents one of the less contentious steps in the broader refactoring effort.
