This thread documents Patrick Steinhardt's work to remove global state dependencies from Git's commit-graph subsystem, part of the larger `the_repository` removal and ODB abstraction efforts. The 10-patch series is now in its third iteration, having addressed extensive review feedback while maintaining its core improvements.

The key technical changes convert various commit-graph components to use repository-specific state rather than global variables, including making hash algorithm handling configurable per-repository. The v3 iteration focuses on final refinements to integer type choices, particularly for commit-graph write options like "max-commits" and "size-multiple". Patrick and Junio engaged in detailed discussion about whether to use unsigned types (Patrick's preference) versus narrower signed types (Junio's suggestion), weighing factors like backward compatibility, platform considerations, and future flexibility.

The series has received approvals from key reviewers including Derrick Stolee and Taylor Blau, with Junio providing final guidance on type selection philosophy. While some differences in design approach remain - particularly around whether unsigned types overly constrain future code evolution - these represent nuanced tradeoffs rather than blocking issues. The patches are merge-ready, having passed all tests while completing the removal of global state from this subsystem, an important step toward pluggable object storage backends.
