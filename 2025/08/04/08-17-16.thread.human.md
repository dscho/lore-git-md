This thread introduces a 9-patch series from Patrick Steinhardt that continues the long-running effort to remove Git's reliance on the `the_repository` global variable, specifically targeting the commit-graph subsystem. The changes systematically eliminate dependencies on both `the_repository` and `the_hash_algo` globals, which is part of making Git's architecture more modular - particularly for the eventual goal of supporting pluggable object storage backends.

The series makes several mechanical but important changes: fixing integer type inconsistencies (switching from signed to unsigned where appropriate), storing hash algorithm information directly rather than deriving it from globals, removing redundant repository parameter passing, and adding trace2 support for unsigned integers. These touch core commit-graph functionality across multiple files, with the cover letter noting significant code churn (226 insertions vs 210 deletions) while aiming to preserve existing behavior. The work builds on Patrick's previous efforts in this area and follows established patterns for global state removal, though the cover letter doesn't mention any accompanying test updates.
