This thread documents Patrick Steinhardt's work to remove global state dependencies from Git's commit-graph subsystem, part of the broader effort to eliminate `the_repository` and enable pluggable object storage backends. The nine-patch series makes mechanical but far-reaching changes to how the commit-graph code handles repository context and hash algorithms.

The initial patches established the foundation by converting macros to functions, fixing integer handling, and improving hash algorithm storage. Later patches systematically removed direct `the_repository` usage, updating functions to take explicit repository parameters instead. The most recent patch completes this work by eliminating redundant repository parameters where the object database source already provides equivalent context. Only one special case remains for cross-repository chain file handling.

Throughout the series, Steinhardt has maintained all existing behavior while making the code more modular. The changes are extensive (touching core commit-graph loading, verification, and helper functions) but carefully incremental, with no test modifications needed. This reflects the project's established pattern for global state removal - converting dependencies to explicit parameters while preserving algorithms. The work aligns with two long-term goals: eliminating global state and enabling pluggable storage backends, both critical for Git's ongoing maintainability.
