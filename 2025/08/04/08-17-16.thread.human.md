This thread documents Patrick Steinhardt's series to remove global state dependencies from Git's commit-graph subsystem, now in its third iteration. The 10-patch series completes the transition away from `the_repository` and makes the code hash-algorithm aware, building on the project's broader ODB abstraction effort. 

The technical work is largely settled, with all major changes from v2 incorporated and key reviewers (Derrick Stolee, Taylor Blau) having approved. Junio Hamano provided detailed feedback on integer type choices, particularly around using unsigned types for Bloom filter counters and commit-graph options. While Patrick justified these as documenting the absence of negative values, Junio cautioned against being overly prescriptive where future needs might require sentinel values. This philosophical exchange about type selection - whether to optimize for current constraints or future flexibility - doesn't block the series but informs similar decisions going forward.

The series stands ready for merging, having addressed all substantive feedback while advancing two major architectural efforts: eliminating global state and enabling pluggable object storage backends. The remaining discussion represents fine-tuning of the project's approach to type safety documentation rather than objections to the changes themselves.
