This is part 7/9 of Patrick Steinhardt's series to remove global state dependencies from the commit-graph subsystem, specifically targeting `the_hash_algo` usage as part of the broader `the_repository` removal effort.

The patch systematically replaces direct `the_hash_algo` references with repository-specific hash algorithm pointers, either passed explicitly through function parameters or accessed via `r->hash_algo`. Key changes include modifying `parse_commit_graph()` to take a hash algorithm parameter, updating file size checks to use repository-specific hash sizes, and adjusting chunk parsing logic to work with the passed algorithm rather than the global. The oss-fuzz test harness is updated to match the new function signature.

The changes are mechanical and behavior-preserving, continuing the series' pattern of converting implicit global dependencies to explicit parameters. Several functions now require hash algorithm parameters where they previously relied on the implicit global, including `open_commit_graph_chain()` and various chunk writing utilities. The patch maintains all existing functionality while preparing for future removal of remaining `the_repository` dependencies.

This intermediate step still allows fallback to `the_repository->hash_algo` in some cases, which the commit message notes will be addressed in subsequent patches. The changes are focused on commit-graph.c but touch several related files to maintain interface consistency. No test modifications are needed as the changes are purely internal refactoring with no intended behavior change.
