[PATCH 0/9] commit-graph: remove global state dependencies

Series by Patrick Steinhardt continuing the `the_repository` removal effort, focusing on commit-graph subsystem as part of broader work to enable pluggable object storage backends. Mechanical refactors to eliminate `the_repository` and `the_hash_algo` globals, touching commit-graph.[ch], builtins, and test helpers (248+/-226 LOC total). Includes preparatory trace2 infrastructure for unsigned integer logging and conversion of hash-dependent macros to functions.

Key technical changes across series:
- Integer type consistency fixes (signed->unsigned where appropriate):
  - Five signed counters in `write_commit_graph_context` for bloom filter stats
  - "max-commits" and "size-multiple" options in `struct commit_graph_opts` (int->size_t)
  - Loop counters and array indices from `int` to `size_t`
  - `num_commit_graphs_before/after` and `write_graph_chunk_base_1()` return type
- Hash algorithm handling:
  - `GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE` macros converted to functions taking explicit `the_hash_algo` parameter
  - New `graph_data_width()` and `graph_min_size()` functions for commit-graph size calculations
  - Hash algorithm info stored directly rather than from globals
  - Bloom filter hash version initialization uses explicit unsigned cast for `-1` sentinel
- Added `trace2_data_uintmax()` for unsigned values (23+/- LOC)
- Removed redundant repository parameter passing
- Fixed sign comparison warnings in `split_graph_merge_strategy()`

Behavior-preserving refactoring with no functional changes. Builds on established patterns for global state removal. The trace2 addition, option type changes, and macro-to-function conversions are preparatory work for later debugging and modularization. No test updates across series, confirming behavior maintenance. Aligns with two long-term goals: eliminating `the_repository` and enabling pluggable modular object storage. Changes are localized to commit-graph.c with no test impact, following the incremental approach of converting global dependencies to explicit parameters while maintaining existing algorithms.
