[PATCH v2 0/10] commit-graph: remove reliance on global state

Series by Patrick Steinhardt completing commit-graph subsystem's transition from global state as part of `the_repository` removal and ODB abstraction. Expanded to 10 patches in v2, systematically eliminating `the_repository` and `the_hash_algo` while enabling future pluggable object storage. The final patch (10/10) removes redundant repository parameter passing where the repository can be derived from the object database source, preventing potential mismatches.

Key technical changes across series:
- Introduced `trace2_data_uintmax()` for unsigned integer tracing (1/10)
- Converted Bloom filter and other counters to unsigned integers (2-4/10)
- Made `GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE` hash-algorithm aware (5/10)
- Refactored hash storage from length to full algorithm pointer (6/10)
- Updated `parse_commit_graph()` and core operations to use repository-specific hash algorithms (7-8/10)
- Eliminated remaining `the_repository` uses including `USE_THE_REPOSITORY_VARIABLE` macro (9/10)
- Removed redundant `struct repository*` parameters from 12 functions where repository could be derived from ODB source (10/10)
- Maintained special handling for `load_commit_graph_chain_fd_st()` cross-source case
- Updated all callers in builtin/commit-graph.c and test helpers
- Modified progress reporting to use repository from graph's ODB source
