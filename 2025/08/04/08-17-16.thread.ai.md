[PATCH 0/9] commit-graph: remove global state dependencies

Series by Patrick Steinhardt completing commit-graph subsystem's transition from global state as part of `the_repository` removal and ODB abstraction. 9 patches refactor commit-graph.[ch], builtins, and test helpers to eliminate `the_repository` and `the_hash_algo` while enabling future pluggable object storage.

Key technical changes:
- Type consistency: converted signed counters to unsigned (bloom filters, loops, array indices); changed `struct commit_graph_opts` fields from `int` to `size_t`
- Hash algorithm handling: macros to functions with explicit `hash_algo` params (patch 5/9); stored full `hash_algo` pointers (patch 6/9); updated size calculations
- Trace2: added `trace2_data_uintmax()` for unsigned logging (reviewed by Taylor Blau)
- Parameter cleanup: removed redundant `struct repository*` where `odb_source` provided context
- Verification, progress, file ops updated to use repository context consistently
- Patch 8/9 acked by Taylor Blau, eliminating remaining `the_repository` usage from builtins (`commit.c`, `merge.c`) with 42-line net reduction
