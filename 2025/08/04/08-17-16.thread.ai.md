[PATCH v2 0/10] commit-graph: remove reliance on global state

Series by Patrick Steinhardt completing commit-graph subsystem's transition from global state as part of `the_repository` removal and ODB abstraction. Expanded to 10 patches in v2, refactoring commit-graph.[ch], builtins, and test helpers to eliminate `the_repository` and `the_hash_algo` while enabling future pluggable object storage.

Key technical changes in v2:
- Patch 1/10 introduces `trace2_data_uintmax()` for unsigned integer tracing
- Patch 2/10 converts Bloom filter counters to unsigned integers
- Patch 3/10 fixes signed/unsigned mismatches for commit-graph write options
- Patch 4/10 converts additional counters to unsigned types
- Patch 5/10 converts `GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE` macros to functions taking `the_hash_algo` parameter
- Patch 6/10 refactors hash storage from length to full algorithm pointer
- Patch 7/10 refactors `parse_commit_graph()` to take full `struct repository*` (new in this update), handling fuzzer special case while removing shadowed declaration
- Maintains all v1 improvements: type consistency, hash algorithm handling, API cleanup, and Trace2 additions
