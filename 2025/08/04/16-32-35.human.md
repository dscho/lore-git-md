This is a feature and maintenance update for gitk, Git's graphical repository browser, bringing several improvements and modernizations.

The pull request includes multiple changes from several contributors, with the main themes being Tcl/Tk 9 compatibility and reference filtering. Mark Levedahl contributes the bulk of the Tcl/Tk 9 updates, ensuring gitk works properly with the newer toolkit version by fixing path expansion, file handling, and encoding conversions. The changes appear thorough and well-tested.

New user-facing features include Ori Avtalion's addition of a preference to hide specific references (with Ilya Grigoriev improving the documentation to mention glob patterns) and Michael Rappazzo's filtering of invisible upstream refs. These should help users manage cluttered reference displays. Johannes Sixt also contributes a fix to avoid showing duplicated upstream refs.

The update includes some UI polish too, with Mark Levedahl improving color handling in the preferences dialog and fixing scrolling behavior for newer Tcl/Tk versions. Alexander Shopov provides Bulgarian translation updates, though interestingly also removes some location-specific translations.

This appears to be a well-organized collection of maintenance updates that modernizes gitk while adding some useful new capabilities. The changes are focused and the commit messages are clear, suggesting this should be a straightforward merge.
