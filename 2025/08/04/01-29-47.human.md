Junio Hamano's merge notice for Windows compatibility fixes. This marks the acceptance of a 4-patch series addressing regressions in Git's Windows filesystem operations. The patches, primarily from Johannes Schindelin with one from Matthias Aßhauer, fix issues that emerged when mingw_rename() adopted POSIX semantics, which broke functionality on pre-Windows 11 systems using ReFS and Windows Server 2016.

The series removes obsolete Windows 7 workarounds, adds ReFS support for Windows 2022, restores Windows Server 2016 compatibility, and improves directory handling. Junio notes the fortunate timing just before the -rc0 preview release and indicates he will apply the patches directly to master. The changes represent production-tested improvements from Git for Windows that simplify the codebase while maintaining compatibility across Windows versions and filesystems.
