Documentation refactoring as part of the `git refs list` series. This first patch in the v5 series extracts the common options documentation from `git-for-each-ref.adoc` into a new shared `for-each-ref-options.adoc` file, using an include directive to maintain the same rendered output. The change is purely organizational, preparing for the upcoming `git refs list` command that will share these same options. The patch has multiple mentors listed and appears well-structured, with no functional changes to the documentation itself. This foundational work follows the pattern seen in other parts of Git's documentation system for sharing common content between commands.
