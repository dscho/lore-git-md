This is part 8/9 of Patrick Steinhardt's series to remove `the_repository` global from the commit-graph subsystem, continuing the broader `the_repository` removal effort. The patch focuses on eliminating remaining direct uses of `the_repository` in commit-graph.c by passing repository contexts explicitly through function parameters.

Key technical changes:
- Removes the `USE_THE_REPOSITORY_VARIABLE` macro as it's no longer needed
- Updates `git_test_write_commit_graph_or_die()` to take an `odb_source` parameter instead of using `the_repository` internally
- Modifies progress reporting functions to use the repository context (`ctx->r`) rather than `the_repository`
- Updates hash algorithm handling to use repository-specific instances throughout
- Changes file operations (like `safe_create_leading_directories`) to use the passed repository
- Updates ref iteration callbacks to carry repository context explicitly
- Modifies verification functions to use graph-specific hash algorithms

The changes are mechanical but thorough, touching nearly all parts of commit-graph.c that previously relied on the global. The patch maintains all existing behavior while removing the final direct dependencies on `the_repository`, completing the subsystem's transition to repository-aware operation. This is a significant step toward the series' goal of enabling pluggable object storage backends.
