This is a maintenance pull request for git-gui, focusing on platform compatibility, Tcl version support, and Windows/macOS-specific improvements. The changes come from multiple contributors and have been merged into a single pull request by Johannes Sixt.

The key changes include:
- Dropping Tcl 8.6 support on macOS while adding Tcl 9.0 compatibility
- Various Windows-specific fixes for PATH handling, shortcuts, and file dialogs
- Removal of the deprecated Git Gui.app macOS application
- Improvements to encoding handling and internationalization
- A change to strip commit messages after running commit-msg hooks
- Updates to the Bulgarian translation

The changes appear well-scoped and focused on technical debt reduction rather than introducing new features. The removal of macOS-specific packaging suggests a shift toward more maintainable cross-platform approaches. The Windows improvements look particularly thorough, addressing several long-standing usability issues.

The pull request combines work from four contributors (Alexander Shopov, Carlo Marcelo Arenas Belón, Mark Levedahl, and Orgad Shaneh) with Johannes Sixt handling the merges. The diffstat shows significant code removal (over 1000 lines deleted) suggesting substantial cleanup.
