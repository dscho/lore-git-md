This is a test refactoring patch in the `git refs list` series (v5 5/6). It prepares the test infrastructure for the new `git refs list` command by extracting the core test logic from `t6300-for-each-ref.sh` into a new shared test library `for-each-ref-tests.sh`.

The key changes:
- Moves 2140 lines of test code into the new shared file
- Keeps the original test file as a thin driver that sets up the test environment
- Replaces hardcoded `git for-each-ref` calls with a `$git_for_each_ref` variable
- Follows the pattern used for sharing tests between `git-blame` and `git-annotate`

This is a mechanical refactoring with no behavior changes - it just enables the same tests to be reused for testing the new `refs list` command in a subsequent commit. The patch has been reviewed through multiple iterations (now at v5) and appears ready for inclusion.

The refactoring is part of Meet Soni's GSoC project to introduce `git refs list` as a thin wrapper around `git for-each-ref`, with mentoring from Patrick Steinhardt and others. The series is in its final polishing phase.
