Maintainer feedback on help options patch series

This is a response from the Git maintainer to the final version of a feature series that makes `--help-all` work outside repositories while preserving special cases for `ls-remote` and `grep`. The thread has progressed through several iterations, with the current version incorporating all requested changes including squashed test fixes.

The maintainer expresses surprise that `--help-all` didn't previously work outside repositories, agreeing this inconsistency needed fixing. However, they push back on a remaining aspect of the original proposal - allowing `-h` to work alongside other arguments (like `git add -h foo`). While this was discussed and dropped in earlier versions, the maintainer reiterates concerns that such behavior would be confusing, as it would ignore the additional arguments rather than incorporating them into the help output.

The response confirms the core functionality (standardizing `-h` and `--help-all` behavior) is sound, but makes clear the maintainer remains firmly opposed to any future attempts at argument-tolerant help output without a fundamental redesign. The tone is collegial but firm, closing the door on that particular direction while accepting the main improvements.
