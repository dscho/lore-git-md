This is the core implementation patch in a series introducing `git refs list` as a new way to list references, positioned as a more logically organized alternative to `git for-each-ref`. The patch adds the `list` subcommand to `git refs`, implemented as a thin wrapper around the shared `for_each_ref_core()` helper function that was extracted in a previous commit.

The implementation is straightforward, reusing the existing ref listing logic while adding proper documentation that links to `git-for-each-ref`'s shared options via an Asciidoc include. The patch maintains behavioral consistency with `for-each-ref` while moving the functionality under the more intuitive `refs` command hierarchy.

As part of a well-structured GSoC project with multiple reviewers, this version shows the series is in its final polishing stage. The changes are cleanly separated from the test and documentation refactoring done in other patches, and the shared infrastructure approach demonstrates good architectural thinking. The patch appears ready for inclusion, completing the technical foundation for future ref-related commands.
