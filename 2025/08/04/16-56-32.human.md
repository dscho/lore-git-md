This is a refactoring patch that's part of a series addressing ZIP archive corruption issues. The patch simplifies buffer handling in `archive-zip.c` by deduplicating code that sets the output buffer for zlib compression. Instead of setting the buffer parameters both before and within the compression loop, it consolidates this to a single location right before each `git_deflate()` call.

The change is straightforward and mechanical, removing redundant buffer initialization while maintaining the same functionality. It's a preparatory cleanup that makes the subsequent patches in the series easier to understand and verify. The patch is co-authored with Justin Tobler, who originally identified the ZIP corruption issues.

This is the first of four patches in the series, and while it doesn't directly fix the corruption problem itself, it helps set up the codebase for the more substantial fixes that follow. The changes are limited to `archive-zip.c` and don't affect any interfaces or user-visible behavior.
