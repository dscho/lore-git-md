Compiler warning fix for reftable stack initialization, specifically addressing a libgit2 build issue. This is part of Patrick Steinhardt's ongoing effort to improve reftable compatibility with libgit2 (v2 3/6 in the series).

The patch changes a struct initialization macro in reftable/stack.c from `{0}` to `{{0}}` to silence a compiler warning from older toolchains about missing braces for nested struct initialization. While Git typically ignores such warnings from outdated compilers, this exception is made because libgit2's build pipeline hits this specific warning-as-error case. The change is minimal (1 line modified) and maintains identical functionality while making the code more portable for libgit2's needs. The commit message references prior discussion about compiler warning policies (2022 thread) and justifies this as a pragmatic exception given reftable's dual role as both a Git component and shared library. This continues the series' theme of balancing Git's standards with external consumer requirements.
