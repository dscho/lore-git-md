This is a refactoring patch in Patrick Steinhardt's series to improve reftable compatibility with libgit2. The change fixes a type mismatch in the reftable writer interface where callers were passing `size_t` for record counts but the functions accepted `int`. The patch updates both the function signatures and implementations to consistently use `size_t`, which is more appropriate for array sizes. The changes are straightforward and mechanical, affecting `reftable_writer_add_refs()` and `reftable_writer_add_logs()` functions. This appears to be a clean improvement that aligns with the series' goal of making reftable more robust for external consumers like libgit2.
