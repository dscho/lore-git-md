This is a large merge pull request for git-gui, combining multiple branches with changes spanning platform compatibility, build system updates, Tcl version support, and translations. The changes include:

1. **Platform-specific fixes**: Several Windows-specific improvements (PATH handling, shortcut creation, Tcl file operations) and removal of macOS-specific build artifacts (retiring Git Gui.app and related scripts). The changes ensure proper behavior across different operating systems.

2. **Tcl version support**: Updates to support Tcl 9.0 while maintaining compatibility with older versions, including encoding handling changes and profile specifications for file operations.

3. **Build system cleanup**: Significant Makefile and meson.build modifications, including removal of uname_O detection, proper dependency handling, and consolidation of git-gui--askpass script handling.

4. **Behavior changes**: The commit message is now stripped after running commit-msg hooks, and various internal cleanups around encoding handling and channel operations.

5. **Translation updates**: Bulgarian translation updates and cleanup, removing location markers from the translation file.

The changes touch nearly all major components of git-gui, with particularly heavy modifications to the build system (Makefile, meson.build) and platform-specific code (Windows and macOS handling). The merge combines work from multiple contributors, with Mark Levedahl contributing the most changes (13 commits) focused on Windows compatibility and Tcl version support.
