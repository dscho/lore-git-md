This is a technical patch series by Patrick Steinhardt improving reftable compatibility with libgit2. The 6 patches address specific issues encountered when running libgit2's test suite with reftable-backed repositories. Changes include:

- Fixing type mismatches in reftable writer code (new patch updates parameter types from `int` to `size_t` for record counts)
- Removing Git-specific macros for better libgit2 portability
- Resolving compiler warnings
- Restructuring code to eliminate forward declarations
- Adding flag support to the stack interface

The modifications touch core reftable components: writer.c (with interface type fixes), stack.c, and their headers, plus test updates. The stack.c changes remain the most extensive (366 lines modified). While this series makes progress, two outstanding tasks remain for full libgit2 compatibility: memory leak fixes and Windows compilation issues. The changes are focused on technical compatibility rather than adding new features, with the latest patch specifically addressing type safety in the writer interface.
