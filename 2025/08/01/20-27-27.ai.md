This is a documentation fix for the ongoing `git repo info` feature implementation. Jean-Noël AVILA points out that the documentation for the `--format` option should use parentheses rather than angle brackets to indicate the mutually exclusive choices of `keyvalue` and `nul` formats. The patch being reviewed is part of v7 of the series that introduces a new `git repo info` command with configurable output formats.

The correction is straightforward - changing `--format=<keyvalue|nul>` to `--format=(keyvalue|nul)` in the documentation to better match Git's conventional syntax documentation style. This doesn't affect the actual implementation, which already correctly handles the format options through string comparison in the code. The email also shows the full context of the documentation section being modified, including examples of using both formats.

This is a minor but important polish to the documentation that follows established Git conventions for documenting mutually exclusive options. The change helps avoid potential user confusion about whether the angle brackets imply user-supplied values rather than fixed choices. The rest of the patch's functionality (including the format handling code and tests) remains unchanged and has already been through extensive review in previous iterations of the series.
