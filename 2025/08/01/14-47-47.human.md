This is a bugfix patch in Patrick Steinhardt's series improving reftable compatibility with libgit2. It corrects a type mismatch in the reftable writer interface where functions were accepting `int` for record counts while callers were passing `size_t`. 

The change updates both the function declarations in reftable-writer.h and their implementations in writer.c to consistently use `size_t` for `reftable_writer_add_refs()` and `reftable_writer_add_logs()`. The modification is straightforward and mechanical, with no behavioral changes beyond fixing the type signatures. 

The patch also includes some minor code style improvements in the implementations, like moving variable declarations and simplifying loop syntax. As the first in a series aimed at libgit2 compatibility, this establishes a cleaner foundation for subsequent changes while fixing a potential source of type-related bugs.
