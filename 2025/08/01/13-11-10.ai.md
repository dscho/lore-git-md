This is a feature patch adding format options to the new `git repo info` command, part of the ongoing GSoC project to create a new command hierarchy. The patch introduces two output formats for the command's results: a human-readable `keyvalue` format (default) and a machine-parsable `nul` format, following the pattern established by `git config`.

The implementation adds a `--format` option that accepts either `keyvalue` (with `=` separators and newline-delimited fields) or `nul` (with newline-separated key/value pairs and null-terminated fields). The `keyvalue` format applies `quote_c_style` to values for proper shell handling. The patch includes comprehensive tests verifying both formats work correctly with all implemented fields (`references.format`, `layout.bare`, and `layout.shallow`), including proper handling of shallow repository detection.

The changes touch documentation (adding format descriptions and examples), the command implementation (adding format parsing and output generation), and tests (extending existing tests to verify both formats). Error handling rejects invalid format names with a clear message. The implementation maintains the existing lexicographical sorting of output fields and continues to support multiple key requests in a single invocation.

This completes the core output formatting system for the new command, addressing feedback from multiple reviewers (Phillip Wood, Junio Hamano, Justin Tobler, Eric Sunshine) while being mentored by Karthik Nayak and Patrick Steinhardt. The patch demonstrates careful attention to both human and script consumption of command output, with proper quoting in the human-readable format and reliable parsing characteristics in the machine format.
