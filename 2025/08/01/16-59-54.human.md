This is a post-merge discussion about naming and code style in the recently merged `git last-modified` feature. Junio C Hamano responds to Christian Couder's suggestion about using `bool` for flags in the command's data structure, agreeing it would improve clarity over the current `int` declarations.

He notes the current name requires guessing at its purpose.

This continues the thread's pattern of post-merge refinement, specifically addressing code style and naming clarity rather than core functionality.
