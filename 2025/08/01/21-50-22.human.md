This is a review comment on patch 5/5 of the `git repo info` series, focusing on test improvements. Eric Sunshine points out several test-related issues that need addressing:

1. The NUL-format tests should use `test_cmp_bin` rather than `test_cmp` to properly handle null bytes in the output. This was previously suggested but not implemented.

2. The test for shallow repositories has cleanup that could be structured more clearly - either by making the cleanup happen before setup (to ensure a clean slate) or by factoring out the remote repository setup into a separate test.

3. The test for invalid format handling appears to be redundant with one already added in patch 2/5, and its cleanup (`test_when_finished`) may be unnecessary since temporary files in the trash directory don't typically need explicit cleanup.

The review maintains the series' high standard of attention to test quality, catching both a technical requirement (proper binary comparison) and stylistic improvements. These are relatively minor polish items for a patch that otherwise looks solid, implementing the key `--format` flag functionality with both human-readable and machine-parsable output options.
