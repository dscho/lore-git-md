This is a feature patch adding the `layout.shallow` field to the new `git repo info` command, part of a GSoC project to migrate functionality from `git rev-parse`. It's the 4th patch in a 5-patch v7 series.

The patch introduces a new field that reports whether a repository is shallow (true/false), mirroring the existing `--is-shallow-repository` flag from `git rev-parse`. The implementation is straightforward, using `is_repository_shallow()` from the shallow.h API and following the same pattern as the previously added `layout.bare` field.

The changes include documentation updates, the core field implementation in builtin/repo.c, and new test cases that verify both shallow and non-shallow repository detection. The tests create a proper shallow clone scenario to validate the true case, showing good attention to testing edge cases.

This continues the series' pattern of clean, well-tested additions to the new command. The patch has benefited from multiple rounds of review (as seen in the several Helped-by tags) and fits neatly into the established architecture. It demonstrates the command's growing capability to replace `git rev-parse` for repository metadata queries.
