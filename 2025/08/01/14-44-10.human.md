This is a final acknowledgement in a resolved build system thread about Meson/Git version handling. The email confirms Martin Storsjé's v3 patch that makes the Meson build system gracefully handle older Git versions lacking `ls-files --deduplicate` support (introduced in Git 2.31).

The thread had previously settled on this approach after considering version detection and warning messages, ultimately choosing simplicity.
