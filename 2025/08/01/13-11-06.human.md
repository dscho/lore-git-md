This is the foundational patch in a series introducing a new `git repo` command hierarchy, part of a GSoC project to migrate repository metadata functionality out of `git rev-parse`. The patch establishes the basic command structure with an initial `info` subcommand that will eventually handle repository metadata queries currently handled by `rev-parse`.

The changes add all the boilerplate needed for a new Git command: build system integration, documentation stubs, and a minimal implementation skeleton. The actual functionality (to be added in subsequent patches) will retrieve repository information like reference storage format (`references.format`), bare/shallow status, and other metadata. The command is marked as experimental in the documentation.

The patch shows good attention to project conventions, with proper help text, documentation structure, and build system integration. As the first in a well-reviewed series (now at v7), it represents the starting point for a cleaner separation of concerns in Git's command-line interface. The implementation appears solid though currently just returns success (the real work happens in later patches).
