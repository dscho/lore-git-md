This is a refactoring patch in Patrick Steinhardt's series improving reftable compatibility with libgit2. The change removes Git's custom `QSORT()` macro from the reftable writer code, replacing it with standard `qsort()` calls. 

The patch makes two straightforward changes in `writer.c` where ref and log records are sorted. While functionally equivalent (both sort arrays), the standard `qsort()` requires explicitly passing the element size, which the Git macro handled internally. The change also adds null checks before sorting, though this appears to be defensive programming since the comparison functions would handle empty arrays safely.

This is a clean, focused change that improves portability by removing a Git-specific dependency. The patch is well-contained (just 6 lines modified) and clearly motivated by the series' goal of making reftable usable outside Git. It follows the pattern seen elsewhere in the series of replacing Git internals with standard equivalents.
