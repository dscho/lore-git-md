This is the cover letter for the third version of Junio Hamano's refactoring series for Git's string-list API. The series unifies and enhances the string splitting functionality in string-list, adding new capabilities while cleaning up inconsistencies between similar functions.

The key improvements in this version include switching from CPP macros to enum for flag bits (addressing Patrick Steinhardt's feedback) and fixing some typos. The series remains focused on internal API improvements with no user-facing changes, though it does simplify some callers like the diff.colormovedws parsing code.

The core changes:
1. Unify string_list_split() and string_list_split_in_place() implementations
2. Add STRING_LIST_SPLIT_TRIM flag to automatically trim split strings
3. Add STRING_LIST_SPLIT_NONEMPTY flag to skip empty entries
4. Update callers to use the new functionality where applicable

The series appears technically complete with all architectural decisions settled. The implementation shows careful attention to edge cases and maintains backward compatibility. This is a polished iteration of a well-motivated refactoring that will make string-list API more consistent and easier to use.
