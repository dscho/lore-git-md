Build system patch improving Meson compatibility with older Git versions. This is a follow-up to a resolved thread about handling `git ls-files --deduplicate` failures gracefully during builds.

The patch modifies the Meson build script to properly handle cases where the static analysis feature encounters older Git versions (pre-2.31) that don't support the `--deduplicate` option. Instead of failing the build, it now gracefully skips the static analysis targets with a warning when the command fails.

The implementation uses Meson's `run_command(check: false)` to prevent build failures, then checks the return code explicitly (0 for success, non-zero for failure). This matches the thread's consensus to avoid version detection in favor of command failure handling. The warning message was added despite earlier discussion about verbosity concerns, though it's more concise than originally proposed options.

This change makes the build system more robust when used with older Git versions while maintaining full functionality with Git 2.31+. The static analysis feature remains optional and Git-repo dependent, with no runtime behavior changes. The patch appears well-considered, implementing the agreed-upon solution from the thread discussion.
