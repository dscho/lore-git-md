This is a refactoring patch in Patrick Steinhardt's series improving reftable compatibility with libgit2. The change adds a `flags` parameter to `reftable_stack_add()`, which is currently unused but will be needed by libgit2 to support automatic stack reloading when modifications are detected before locking.

The patch modifies the stack interface and updates all callers to pass `0` for the new flags parameter, maintaining current behavior. While the immediate impact is minimal (just plumbing through an unused parameter), it lays groundwork for future functionality that libgit2 requires. The change is cleanly implemented with corresponding updates to the header documentation and thorough test coverage.

This continues the series' pattern of small, focused changes that make the reftable code more portable while avoiding behavior changes in Git itself. The patch appears well-constructed with appropriate attention to maintaining existing functionality.
