This is a refactoring patch in Junio Hamano's string-list API series, specifically part 3 of 7 in v3. The patch unifies the implementations of `string_list_split()` and `string_list_split_in_place()` into a single internal helper function `split_string()`, while maintaining their distinct external interfaces. 

The key technical aspects are:
- Introduces new `append_one()` helper that handles the string copying/placement differences between the two variants
- Uses `strpbrk()` for delimiter handling in both cases (previously only `string_list_split_in_place()` supported multiple delimiters)
- Adds BUG() checks for proper strdup_strings usage (in_place requires it off, non-in-place requires it on)
- Preserves all existing behavior while eliminating code duplication
- Carefully handles const-correctness through an internal cast when needed for in_place operation

The changes affect string-list.c only, with no user-facing impact. This is a clean internal refactoring that prepares for future extension via flags (mentioned in the commit message) while maintaining backward compatibility. The patch follows the series' established patterns and has already incorporated feedback from previous rounds.
