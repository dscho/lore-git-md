This is a documentation patch updating the `git-fast-import` man page. Kristoffer Haugsbakk proposes a small but useful clarification about the hardware performance example given in the documentation. 

The patch updates a sentence that describes how fast-import can process large repositories in 1-2 hours on "$2,000 USD" hardware. The change adds context that this benchmark was from 2007, making it clear to modern users that the performance numbers refer to hardware from that era rather than current systems. 

The author also takes the opportunity to slightly reword the sentence, moving the parenthetical hardware cost to the end where it reads more naturally. This is a straightforward documentation improvement that helps set appropriate expectations for users evaluating `git-fast-import` performance. The change is minimal (just 1 line modified) and uncontroversial.
