This is a refactoring patch that simplifies the parsing of `diff.colormovedws` configuration by leveraging the new string-list API improvements from earlier in the series.

The patch demonstrates the practical application of the new `STRING_LIST_SPLIT_TRIM` flag introduced in patch 4/7. It removes the manual string trimming dance in `diff.c` where each token from the comma-separated list was individually placed in a strbuf, trimmed, and then compared. Now the string-list splitting handles the trimming automatically, making the code more straightforward.

The change is purely internal - there's no behavior change for users of `diff.colormovedws`. The simplification removes 13 lines while adding 7, eliminating the temporary strbuf allocations and cleanup. Error messages remain identical, just operating directly on the pre-trimmed string-list items.

This is a clean application of the series' API improvements, showing how the refactored string-list functionality can simplify real-world code. As part of the technically complete v3 series, it's a straightforward improvement that builds on the settled design decisions.
