This is a documentation fix for the ongoing `git repo info` feature implementation. Jean-Noël AVILA points out that the documentation for the `--format` option in `git-repo.adoc` should use parentheses rather than angle brackets to indicate the available format options (keyvalue|nul) since these are fixed keywords rather than placeholder values. The patch itself (from Lucas Seiki Oshiro) had already implemented the format system correctly in the code, with proper validation of the format options, but the documentation didn't precisely match the implementation's syntax.

The email is a minor but important correction to ensure the documentation accurately reflects the command's interface. This comes as part of a well-reviewed series (now at v7) that introduces a new `git repo info` command with machine- and human-readable output formats. The series has already addressed extensive technical feedback, and this documentation tweak helps maintain consistency with Git's established documentation conventions.
