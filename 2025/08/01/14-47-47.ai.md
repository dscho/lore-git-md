This is a bugfix patch in Patrick Steinhardt's series improving reftable compatibility with libgit2. The change addresses a type mismatch in the reftable writer interface where callers were passing `size_t` values for record counts but the functions accepted `int` parameters. The patch updates both the function declarations in reftable-writer.h and their implementations in writer.c to consistently use `size_t`, which is more appropriate for array sizes. 

The modifications are straightforward and focused - changing parameter types and adjusting the loop variable declarations to match. The patch also includes some minor code style improvements by removing unnecessary braces in simple for loops. This appears to be a low-risk change that properly aligns the interface with its actual usage while maintaining the same behavior. The change is part of the larger effort to make Git's reftable implementation more portable for libgit2.
