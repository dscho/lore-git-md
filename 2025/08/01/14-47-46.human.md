This is a patch series with reftable improvements aimed at libgit2 compatibility. Patrick Steinhardt shares five small but important fixes needed to get libgit2's test suite passing with reftable-enabled repositories. The changes include type fixes, compiler warning fixes, code reorganization, and adding flag support to the stack API. While some Windows compatibility and memory leak work remains, this represents significant progress toward full reftable support in libgit2.
