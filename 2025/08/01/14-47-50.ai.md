This is a refactoring patch in Patrick Steinhardt's series improving reftable compatibility with libgit2. The patch reorganizes code in `reftable/stack.c` to eliminate forward declarations by moving function definitions before their callers. The changes are purely structural - no behavior is altered.

Key modifications include:
- Moving `reftable_new_stack()` after `reftable_stack_reload_maybe_reuse()` which it calls
- Relocating `reftable_addition_close()` to follow its struct definition
- Shifting `stack_try_add()` and `reftable_stack_add()` to appear before their callers
- Reordering `stack_write_compact()` and `stack_compact_locked()` to maintain call order

The patch continues the series' focus on code quality improvements for libgit2 compatibility, specifically addressing code organization issues that could make the code harder to maintain across implementations. The changes are mechanical but help reduce cognitive overhead by putting related code closer together.
