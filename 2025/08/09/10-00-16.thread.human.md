This thread addresses a minor documentation inconsistency in Git's merge command. The original implementation of the `--compact-summary` option (added in June 2025) incorrectly included an argument help string in `git merge` despite the option not actually taking any arguments, while the parallel implementation in `git pull` correctly omitted this. 

René Scharfe spotted and fixed this oversight with a simple one-line change to `builtin/merge.c` that removes the misleading argument description. The patch is clean and clearly explained, representing a straightforward documentation correction with no behavioral impact. As a small cleanup from an established contributor, this change is likely to be accepted without further discussion.
