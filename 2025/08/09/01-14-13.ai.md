Documentation patch reorganizing the `git-rebase` man page to improve accessibility for newcomers. This is the first of five patches in a completed series that restructures the documentation while preserving all content.

The patch moves a basic rebase example to the beginning of the DESCRIPTION section, mirroring the approach used in `git-merge` documentation. It introduces ASCII art showing branch topology before and after rebasing, along with clear explanatory text about "catching up" to another branch. The example demonstrates both the standard `git rebase master` form and the shortcut `git rebase master topic` syntax.

Key changes include:
- Added motivational language about "catching up" to another branch
- Front-loaded the basic example (159 lines changed)
- Includes ASCII art illustrating branch topology changes
- Explains both the standard and shortcut syntax forms
- Preserves all technical content while improving organization

The patch was well-received and merged after several iterations (v4 being the final version), with refinements to terminology (standardizing on `git checkout` rather than `git switch` for the shortcut syntax explanation). This establishes a pattern of front-loading common examples that was followed throughout the rest of the series. The changes maintain technical accuracy while making the documentation more approachable for new users.
