This is the final version (v4) of a documentation patch series reorganizing the `git-rebase` man page, with all patches now merged. The series was authored by first-time contributor Julia Evans and represents a comprehensive restructuring of the documentation to improve accessibility while preserving all technical content.

The v4 update makes two minor terminology refinements based on maintainer feedback: replacing `git switch` with `git checkout` in the shortcut syntax example (to match Git's historical command usage) and standardizing on "shortcut" spelling throughout the man pages. These changes appear in patch 1's range-diff, while patches 2-5 remain unchanged from their v3 versions.

Key aspects of the completed series include:
- Front-loading practical examples (patch 1)
- Consolidating merge conflict resolution (patch 2)
- Clarifying argument syntax (patch 3)
- Better organizing `--onto` examples (patch 4)
- Improving internal mechanics explanation (patch 5)

The series maintains technical accuracy while making the documentation more approachable, particularly for newcomers.
