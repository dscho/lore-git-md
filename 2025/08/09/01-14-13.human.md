Documentation patch reorganizing the `git-rebase` man page to be more beginner-friendly. This is the first of five patches in a completed series that restructures the documentation while preserving all technical content.

Julia Evans opens the rebase documentation with a concrete example showing how to "catch up" a topic branch to master, mirroring the approach used in `git-merge`'s docs. The patch moves the ASCII-art branch diagram and rebase command examples to the very top, before diving into technical details. It explains both the basic `git rebase master` form and the shortcut `git rebase master topic` syntax, noting the latter is equivalent to checking out topic first.

The changes make the documentation more accessible by front-loading practical usage while maintaining all the original technical accuracy. The patch removes some redundant explanations that appeared later in the file, consolidating them into this initial example section. The series was well-received and merged after incorporating maintainer feedback, with this first patch establishing the new structure that subsequent patches build upon.
