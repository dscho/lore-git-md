Performance optimization for Bloom filters in revision traversal, finalizing the v4 patch series. This iteration enables Bloom filter usage with wildcard pathspecs and specific pathspec magic signatures (top, glob, attr, --depth, literal) while excluding incompatible ones (exclude, icase). The implementation uses the non-wildcard portion up to the last directory separator for Bloom matching, with fallback to non-filtered traversal for first-component wildcards.

The patch shows measurable performance gains: 18-27% faster in Git repository tests (e.g., `git log -100 -- "t/*"` drops from 23.4ms to 20.4ms) and 47-63% faster in larger repositories like LLVM (`git log -100 -- "libc/*"` improves from 26.7ms to 16.0ms). The implementation is now well-polished after multiple rounds of review, with Junio Hamano having signed off on v3 and this v4 being a straightforward rebase incorporating his final refinements.
