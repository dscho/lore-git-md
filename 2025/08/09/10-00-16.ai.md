Documentation fix correcting an incorrect help string for the `--compact-summary` option in `git merge`.

René Scharfe points out that while commit 3a54f5bd5d added the `--compact-summary` option to both `git merge` and `git pull` in June 2025, the merge implementation incorrectly included an argument help string ("compact-summary") despite the option taking no arguments. The patch removes this misleading string, bringing it in line with the pull implementation and the actual behavior.

The change is straightforward - a one-line modification to `builtin/merge.c` that replaces the argument description with NULL while keeping the main help text. This appears to be a simple cleanup of an oversight in the original implementation, with no behavioral impact. The patch is small, focused, and clearly explained in the commit message.
