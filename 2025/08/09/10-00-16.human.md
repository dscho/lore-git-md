This is a documentation fix for the `git merge` command. René Scharfe points out that while the `--compact-summary` option was added to both `git merge` and `git pull` in commit 3a54f5bd5d, the merge implementation incorrectly included an argument help string for this no-argument option. The patch simply corrects this by removing the misleading parameter description while keeping the option's main help text intact.

The change is straightforward and clearly correct - it aligns the documentation with the actual behavior. This appears to be a minor cleanup of an oversight in the original implementation rather than anything controversial. The patch touches just one line in builtin/merge.c, changing the NULL parameter description while preserving the option's functionality and main help text.
