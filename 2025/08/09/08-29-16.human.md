This is a documentation consistency patch for the `git for-each-ref` command. 

René Scharfe fixes a minor inconsistency in how the `--start-after` option's argument is described. While the option was introduced in commit dabecb9db2 with its argument referred to as a "marker" in the documentation and usage string, the short help text called it "start-after". This patch aligns the short help text with the other descriptions by changing it to simply say "marker".

The change is straightforward - a one-line modification to the option definition in builtin/for-each-ref.c. This improves consistency in the command's interface without affecting any functionality. The patch appears well-scoped and correctly implemented, addressing a small but legitimate documentation nit.
