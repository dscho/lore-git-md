Documentation patch reorganizing the `git-rebase` man page, specifically moving the `--onto` examples to a dedicated section. This is patch 4/5 in a completed series that restructured the rebase documentation for better accessibility.

The patch relocates the detailed `--onto` explanation and examples (81 lines) from the DESCRIPTION section to a new "TRANSPLANTING A TOPIC BRANCH WITH --ONTO" section near the end of the document. The content remains unchanged - it still shows three scenarios: transplanting a topic branch between branches, rebasing part of a branch, and removing commits with rebase`. Each example includes ASCII diagrams showing the before/after commit topology.

Key technical details:
- Adds a reference to the new section from the `--onto` option description in MODE OPTIONS
- Preserves all examples exactly as they were, including the ASCII art diagrams
- Maintains the same technical explanations about valid commit-ish arguments
- Follows the series' pattern of moving detailed explanations to dedicated sections after basic usage

This change improves document organization by:
- Making the `--onto` examples easier to find via section heading
- Reducing the length of the initial DESCRIPTION section
- Maintaining all technical content while improving navigability
- Following the established pattern from earlier patches in the series
