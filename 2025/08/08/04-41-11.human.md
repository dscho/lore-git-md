Refactoring patch in a completed bugfix series. This is the second of three patches that addressed an issue where Git would incorrectly assert with BUG() when pushing invalid object IDs to unqualified refs. The series has already been reviewed and approved, with this particular patch converting an if-else chain into a switch statement for better readability.

The change is straightforward - it restructures the object type checking in `show_push_unqualified_ref_name_error()` to use a switch statement instead of multiple if-else conditions. The patch also removes the now-unnecessary `type` variable by moving the `odb_read_object_info()` call directly into the switch expression. All behavior remains exactly the same, just with cleaner code.

This follows up on Patrick Steinhardt's suggestion and completes the stylistic improvements to the original bugfix. The series has already received final acks from both Patrick and Junio Hamano, with no outstanding issues. The patch demonstrates good attention to code quality in what was already a well-handled bugfix.
