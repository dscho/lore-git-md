This is a documentation patch fixing a formatting issue in the Git manual. 

Kristoffer Haugsbakk noticed that a recent commit (b27be108c89) intended to use description list syntax for documenting `log.decorate` options in log.adoc, but accidentally used literal block syntax (triple hyphens) instead of the correct description list syntax (double hyphens). 

The patch is straightforward - it simply changes the block delimiters from `---` to `--` to properly format the options for `log.decorate` (short, full, auto) as a description list. This matches the intended documentation style and makes the options clearer to read.

The change is minimal (2 lines changed) and clearly correct, fixing an obvious documentation formatting error from a recent commit. No behavior changes are involved - this is purely about improving the manual's presentation. The patch includes a clear commit message referencing the original problematic commit.
