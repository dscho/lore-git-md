Bugfix for the `git-jump` contrib script, addressing an issue with filenames containing spaces.

Greg Hurrell identifies a problem where `git-jump`'s diff mode fails to properly handle filenames containing spaces due to Git's diff output adding a trailing tab character for such files. This causes Vim to open an empty buffer since no file with a literal tab in its name exists. The patch proposes a simple solution: unconditionally stripping any trailing tab from the filename in the `git-jump` Perl script.

The change is minimal (just a one-line Perl regex modification) and handles the common case of spaces in filenames while acknowledging that it might not perfectly preserve edge cases like filenames that legitimately end with tabs. The commit message clearly explains the tradeoffs and suggests that if the edge cases become problematic, a more complex solution could be implemented later.

This appears to be a well-motivated fix for a real usability issue, with clear explanation of the problem and solution. The change is small and focused, though it might be worth noting that it doesn't include a test case (perhaps difficult for a contrib script).
