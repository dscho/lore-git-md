This is the final v5 patch in a bugfix series addressing inconsistent behavior between content-ignoring diff options (`-w`, `-I`) and metadata outputs (`--name-status`, `--raw`, `--name-only`). The patch implements the agreed-upon solution using a `dry_run` mode in the diff machinery to quickly check for changes while respecting ignore rules.

Key technical elements:
- Adds `dry_run` boolean to `struct diff_options`
- Introduces `quick_consume()` callback to detect changes without full processing
- Implements `diff_flush_patch_quietly()` helper for metadata output checks
- Removes the `/dev/null` redirection approach from earlier versions
- Updates xdiff-interface.h documentation to reference the new pattern
- Adds comprehensive tests in t4013 and t4015 verifying the fixed behavior

The solution ensures metadata outputs now properly respect content-ignoring options, so files that would be suppressed in patch output due to `-w` or `-I` will also be omitted from `--name-status` etc. The implementation avoids performance overhead by only examining content when necessary.
