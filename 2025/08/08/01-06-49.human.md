This is a test automation improvement, part of a completed series finalizing the organization of help output tests. The patch replaces manual tests for `git subcmd -h` behavior outside a repository with an automated approach that loops through all main commands using `git --list-cmds=main`. This ensures comprehensive coverage and automatically includes any new commands added in the future.

The implementation handles several edge cases: commands that are expected to fail (like `git daemon` and other plumbing commands) are marked appropriately, and platform-specific requirements (PERL for `instaweb`) are handled with test prerequisites. The patch builds on previous work by Patrick Steinhardt and incorporates feedback from Junio Hamano and D. Ben Knoble.

This represents the final technical piece of a multi-patch effort to standardize help output testing. The automated approach is more maintainable than the previous manual tests and properly separates repository-dependent tests (which were moved to command-specific test files in earlier patches) from the outside-repo cases handled here. The series has reached consensus with all technical aspects now resolved.
