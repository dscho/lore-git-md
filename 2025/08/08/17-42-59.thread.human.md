This thread addressed a bug in the `git-jump` contrib script where it failed to properly handle filenames containing spaces in diff output, due to Git's diff.c behavior of appending tabs after such filenames. The solution, now at version 2, implements a simple Perl regex modification to strip trailing tabs while intentionally not supporting more complex cases like tab-terminated filenames or quoted filenames with control characters.

All reviewers - Phillip Wood, D. Ben Knoble, Jeff King, and Junio Hamano - have approved the approach, agreeing that it makes a strict improvement for common cases while avoiding unnecessary complexity. The v2 patch includes improved documentation clarifying the supported scenarios and rationale. The discussion has now with final agreement that quoted filenames (which weren't previously handled anyway) should remain out of scope, as Git's automatic quoting of control characters provides sufficient protection against ambiguity. The patch is ready for inclusion with clear boundaries about what it does and doesn't handle.
