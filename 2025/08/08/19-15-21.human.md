Documentation patch reorganizing the `git-rebase` man page to be more beginner-friendly. This is the first patch in a 5-part series from first-time contributor Julia Evans, and it has already been merged with maintainer feedback incorporated.

The patch moves a practical rebase example to the start of the DESCRIPTION section, mirroring the approach used in `git-merge` documentation. It shows a common scenario where you want to rebase a `topic` branch onto an updated `master`, complete with ASCII art diagrams before/after the rebase. The patch also explains both the standard (`git rebase master`) and shortcut (`git rebase master topic`) syntax forms upfront.

This restructuring makes the documentation more accessible by showing concrete use cases before diving into technical details. The changes are purely organizational - no content is removed, just reordered and slightly reworded. The patch demonstrates good documentation practices, with clear examples and explanations that help newcomers understand rebase concept before encountering more advanced options later in the man page.
