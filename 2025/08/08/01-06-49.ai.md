This is the first patch in a 3-part series finalizing the automated testing of Git command help output outside a repository. It builds on previous work reorganizing help tests and implements Patrick Steinhardt's suggestion to use `git --list-cmds=main` for comprehensive coverage.

The patch replaces manual `-h` tests with an automated loop that checks help output for all main commands, skipping known exceptions (like Perl-based commands) and marking others as expected failures. The implementation handles edge cases through suffix stripping (removing `.sh`, `.perl` etc.) and case statements, with special handling for the `instaweb` command requiring PERL prerequisites.

Key technical details include the command list generation via `--list-cmds=main`, the exception list of commands that can't be tested this way, and the PERL prerequisite for `instaweb`. The patch removes now-redundant manual tests for `update-server-info` and `prune` (which were moved to command-specific test files in earlier patches).

This appears to be the final technical implementation of the automated help testing approach, with all known issues addressed (including Windows-specific concerns from previous iterations). The patch maintains the established base commit and follows the mailing list conventions for documenting such decisions.
