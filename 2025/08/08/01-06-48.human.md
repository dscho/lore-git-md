This is a test refactoring patch series that finalizes the reorganization of help output testing, following up on earlier work to consolidate these tests. The series comes from Usman Akinyemi and represents version 6 of these changes, now incorporating feedback about Perl dependency handling for the `instaweb` test case. 

The main goal is to make `t1517-outside-repo.sh` focus exclusively on testing command help output (`-h`) when run outside a repository, while moving repository-dependent help tests to their more natural homes in command-specific test files. The key technical improvement is automating the coverage of all main Git commands via `git --list-cmds=main` and the `nongit` helper, which will ensure new commands get automatically tested for this behavior.

The changes since v5 are minimal, just fixing the `instaweb` test case to properly handle Perl dependencies (a fix suggested by D. Ben Knoble). The series builds on commit 7cd03a555a from early July. With this iteration, the test reorganization work that began with Patrick Steinhardt's suggestion appears complete, having gone through multiple rounds of review and refinement. The approach has Junio Hamano's architectural approval and the implementation looks solid, with proper attention to platform-specific edge cases.
