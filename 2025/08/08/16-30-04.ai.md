This is a documentation patch in a series (1/5) that restructures the `git-rebase` man page for better accessibility, specifically focusing on front-loading a clear example.

The patch moves the basic rebase example to the start of the DESCRIPTION section, mirroring the approach used in `git-merge` documentation. The example shows ASCII art of a topic branch being rebased onto master, demonstrating both the basic `git rebase master` form and the shorthand `git rebase master topic` syntax. The author removes the duplicate example that previously appeared later in the document.

Junio C Hamano provides feedback suggesting improvements to the example's wording, proposing a more motivational style that explains why someone might want to rebase ("catch up" to master) rather than just describing the mechanics. He also notes the patch accidentally dropped the explanation that `git rebase master topic` is equivalent to `git checkout topic && git rebase master`, and includes this clarification in his suggested rewrite.
