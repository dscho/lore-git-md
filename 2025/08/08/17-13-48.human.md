Documentation patch (1/5 in series) reorganizing the `git-rebase` man page, now incorporating maintainer feedback.

This is the first patch in Julia Evans' series to improve the `git-rebase` documentation structure. The key change moves a basic rebase example with ASCII art to the start of the DESCRIPTION section, mirroring the approach used in `git-merge`'s documentation. The patch originally removed an explanation about `git rebase master topic` syntax being equivalent to a checkout followed by rebase, but Junio C Hamano notes this should be preserved as it doesn't appear elsewhere in the document.

Julia acknowledges the current wording is quite dry (having copied the style from elsewhere in Git's docs) and agrees with Junio's suggestion to add more motivational language. She clarifies that the removed syntax explanation will appear in patch 3/5 of the series, where she felt it better belonged as the primary explanation of that command form.

The patch represents a thoughtful first contribution, with Julia demonstrating good responsiveness to maintainer feedback while maintaining her overall vision for the documentation reorganization. The series aims to make rebase concepts more accessible to newcomers while preserving all technical content.
