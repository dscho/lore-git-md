This is a platform compatibility fix for Cygwin test failures. 

Ramsay Jones addresses a test suite issue where t6137-pathspec-wildcards-literal.sh was incorrectly using the FUNNYNAMES prerequisite to skip tests on Windows systems. The tests actually need to be skipped on any system that can't handle backslashes in pathspecs (marked by the BSLASHPSPEC prerequisite), which includes both Windows and Cygwin. The patch swaps these prerequisites and also cleans up some test titles for accuracy.

The change is straightforward and well-justified - the current test behavior incorrectly runs some tests on Cygwin that should be skipped, since Cygwin environment can create files with funny names (triggering FUNNYNAMES) but doesn't properly support backslash pathspecs. The author notes this isn't a regression for the current release cycle but would be good to include before the next release.

The patch shows attention to detail with the test title fixes and the author's self-noted observation about the redundant "skipping:" text (though that part wasn't changed in this submission). This appears to be a solid, focused platform compatibility fix.
