Cover letter for a test hardening series addressing documentation verification in t0450. This two-patch set builds on the earlier discussion about making the test/t0450-txt-doc-vs-help.sh more robust when checking consistency between command-line help and documentation.

The first patch (unchanged from v1) fixes the out-of-tree build issue by using `$GIT_SOURCE_DIR` instead of `$GIT_BUILD_DIR` to locate .adoc files, addressing the original Meson compatibility problem. The second patch is new, introducing an allowlist mechanism to explicitly track which builtins are permitted to lack documentation, replacing the silent-skip behavior that masked documentation gaps. This follows the consensus from the thread that the test should be more strict about documentation requirements. The allowlist approach makes missing documentation a visible choice rather than an accidental omission, helping catch documentation gaps for new subcommands. The implementation references an existing adoc-help-mismatches file as suggested in the discussion. The changes are focused on the test script itself, with minimal impact on other parts of the codebase.
