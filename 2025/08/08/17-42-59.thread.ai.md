Core issue stems from Git's diff.c behavior (since 2006) appending tabs after filenames containing spaces (e.g. "foo bar.txt\t"), causing `git-jump` to incorrectly process these as part of the filename in Vim's quickfix mode. Current solution implements a one-line Perl regex modification (`(.*?)\t?$`) to optionally strip trailing tabs, solving the common case while remaining simple. D.
