Thread summary:

Bugfix for `git-jump` (contrib script) handling filenames with spaces in diff output. Core issue: Git's diff.c appends a tab after filenames containing spaces (e.g. "foo bar.txt\t"), causing `git-jump` to incorrectly process these as part of the filename when feeding to Vim's quickfix mode. Current solution modifies the Perl regex to optionally strip trailing tabs, solving the common case while remaining simple. Acknowledged limitation: doesn't perfectly handle filenames ending with literal tabs, deemed acceptable tradeoff. Change is minimal (one-line regex modification) and focused on contrib/git-jump script. Commit provides clear examples of problematic cases and solution rationale. Potential future consideration: making tab-stripping conditional on space presence if edge cases arise.
