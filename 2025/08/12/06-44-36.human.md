This is the second and final patch in a series adding IMAP-based message archiving to `git send-email`. It introduces a "pure-IMAP" mode that allows users to save formatted emails to an IMAP folder without actually sending them via SMTP.

The patch adds a new `--use-imap-only` option (and corresponding `sendemail.useImapOnly` config) that, when enabled, bypasses SMTP delivery entirely and only archives the messages to the specified IMAP folder. This is useful for users who want to leverage `git send-email`'s advanced formatting features (like programmatic Cc list management and cover letter generation) but prefer to send the messages later via a different email client.

The implementation is straightforward - it checks the new flag and skips SMTP delivery when enabled, while still requiring the IMAP folder to be properly configured. The patch also includes documentation updates and fixes a minor formatting issue in the help text for `--smtp-ssl`.

This completes the series' goal of supporting both SMTP+archive and pure-IMAP workflows. The changes are well-contained and the documentation is thorough, following the project's conventions. With all previous feedback addressed and no outstanding technical issues, this appears ready for inclusion.
