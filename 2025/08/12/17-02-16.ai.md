Test modernization patch in a series improving editor-related test infrastructure. This is the first of three patches in v4 of the series, focusing on updating t7005-editor.sh to use modern test practices.

The patch modernizes the test script by:
1. Moving vi detection into the setup test block rather than having it as standalone code
2. Replacing manual script creation with `write_script` helper
3. Using `test_commit_message` helper instead of manual commit message verification
4. Replacing error handling with `test_must_fail`
5. Removing old-style blank lines between test assertions
6. Maintaining all existing test functionality while making the code more robust

The changes are purely about test style and reliability - no behavior changes are introduced. This aligns with the series' goal of modernizing editor-related test infrastructure while maintaining backward compatibility. The patch appears well-crafted, with thorough conversion to modern test practices while preserving all test coverage. It builds on previous feedback by focusing only on non-controversial test improvements after the strvec API conversion patch was dropped from earlier versions.
