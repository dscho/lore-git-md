This is a bugfix for `git diff --no-index` that addresses working directory handling inconsistencies. The patch has now been confirmed as working by the original reporter Gregoire Geis, who tested both the test suite and manual commands.

The fix ensures `--no-index` mode properly ignores Git's working tree discovery mechanism, which was causing problems when handling special paths like "-" (stdin/stdout). The v2 version adds proper error handling for the chdir operation that was missing in the initial version.

The patch touches only `builtin/diff.c` and adds one test case in t/t4053-diff-no-index.sh. Maintainer Junio C Hamano took over the patch after initial diagnosis help from Ramsay Jones.

With the reporter's confirmation that the v2 patch resolves the issue, this appears ready for inclusion. The fix is focused and well-tested, addressing a clear inconsistency in `--no-index` behavior.
