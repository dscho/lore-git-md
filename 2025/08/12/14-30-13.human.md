This is a post-merge discussion about documentation command recommendations, specifically regarding `git checkout` vs `git switch` in rebase examples.

Junio Hamano responds to Karthik Nayak's suggestion to update the recently merged rebase documentation to use `git switch` instead of `git checkout`. Junio explains that `git switch` is no longer marked experimental not because it's superior to `git checkout`, but because its behavior is now too established to change. He notes the experiment to improve upon `git checkout` didn't yield significant benefits, implying the documentation should continue using `git checkout` where appropriate.

This exchange confirms the reasoning behind keeping `git checkout` in the rebase documentation examples, particularly for detached HEAD states where `checkout` provides clearer behavior. The discussion shows the project's careful consideration of command recommendations, even after documentation changes are merged. No further action appears needed as the technical rationale has been clearly established by multiple contributors.
