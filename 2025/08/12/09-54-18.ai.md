This is a compiler warning fix in Patrick Steinhardt's reftable/libgit2 compatibility series (v3 4/8). The patch addresses a warning from older compilers about missing braces when zero-initializing nested structs, though the team had previously not prioritized fixing such warnings for outdated compilers.

The change removes the `REFTABLE_ADDITION_INIT` macro that used `{0}` initialization and replaces it with explicit `memset()` calls in `reftable_stack_init_addition()`. This approach both silences the warning and simplifies the calling convention since initialization is now handled in one place rather than requiring callers to use the macro. The modification affects three functions that create `reftable_addition` structs, with the most notable change in `reftable_stack_new_addition()` where the temporary `empty` struct is eliminated.

The patch follows Carlo Arenas' suggestion and maintains the series' focus on robust, portable code while removing Git-specific patterns. It touches only `reftable/stack.c` with a 14-line delta (7 additions, 7 deletions). This is a straightforward technical improvement that doesn't affect functionality but improves code hygiene and compiler compatibility.
