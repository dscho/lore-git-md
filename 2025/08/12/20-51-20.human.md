This is a documentation patch discussion in Julia Evans' series improving the `git-add` man page. Chris Torek points out a subtle exception to the terminology equivalence being documented - `git apply` uses `--index` and `--cached` to mean different things, unlike most other Git commands where these flags refer to the same concept (the staging area/index/cache).

The observation is relevant to the new "TERMINOLOGY NOTE" section in patch 5/5, which aims to clarify the interchangeable use of these terms across Git commands. While the note is generally accurate for most commands, Chris highlights this important edge case that might need special mention or qualification in the documentation.

This feedback suggests the terminology note may need slight refinement to acknowledge this exception, though the core approach of explaining the terminology variations remains valuable. The discussion shows careful review of the documentation changes and attention to technical accuracy.
