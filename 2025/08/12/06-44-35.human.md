This is the first patch in a two-part series adding IMAP-based sent mail archiving to `git send-email`. The feature addresses email providers like iCloud that don't save SMTP-sent messages to the Sent folder by providing an option to archive copies via IMAP.

The patch introduces a new --imap-sent-folder option and corresponding sendemail.imapSentFolder config setting. When enabled, after successfully sending via SMTP, the tool will use `git imap-send` to archive a copy of each message (including Bcc headers) to the specified IMAP folder. The implementation handles the plumbing between the SMTP and IMAP subsystems while preserving all existing send-email formatting features.

The documentation clearly explains the use case and requirements, noting users must have `git imap-send` properly configured. The patch appears well-constructed with thorough handling of edge cases (dry-run behavior, Bcc preservation) and follows Git's coding standards. This addresses a real-world workflow gap for users of certain email providers while maintaining backward compatibility with existing SMTP-only usage.
