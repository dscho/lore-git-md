This is a post-merge discussion thread about documentation command recommendations, specifically regarding the use of `git checkout` versus `git switch` in examples from the recently merged rebase documentation series.

Junio Hamano responds to Karthik Nayak's suggestion to update the examples to use `git switch` instead of `git checkout`. He clarifies that `git switch` is no longer marked experimental not because it has proven superior to `git checkout`, but because its behavior is now too established to change without disrupting users. The original goal was to improve upon `git checkout`'s user experience, but the experiment yielded few meaningful improvements. This reinforces the earlier decision in the rebase documentation series to keep using `git checkout` examples, particularly for detached HEAD operations where `checkout` provides more straightforward behavior.

The exchange confirms the technical rationale behind the documentation choices made in the merged series, with Junio providing additional context about the `git switch` command's history and current status. This post-merge discussion serves to document the decision-making process for future reference, showing alignment between the series author (Julia Evans), the maintainer (Junio), and other contributors (Karthik Nayak, Phillip Wood, and Ben Knoble) on keeping `git checkout` in the examples.
