This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v3, 2/8). The change replaces Git's custom `QSORT()` macro with standard `qsort()` in the reftable writer code, making the library more portable for use outside Git.

The patch modifies two functions in `reftable/writer.c` that sort ref and log records before writing them. While functionally equivalent, the change removes a Git-specific dependency that was preventing the reftable code from being cleanly used by libgit2. The author also adds explicit null checks before sorting, though this is likely just defensive programming since the existing `QSORT()` implementation would have handled null cases the same way.

This is a straightforward mechanical change that aligns with the series' goal of making reftable more self-contained. The patch is small (6 lines changed) and focused, with no apparent impact on functionality or performance. It's the kind of uncontroversial cleanup that typically gets merged quickly after review.
