This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v3). It addresses a compiler warning about brace initialization in older toolchains by simplifying the initialization of the `reftable_addition` struct.

The patch removes the `REFTABLE_ADDITION_INIT` macro and moves initialization into `reftable_stack_init_addition()` using `memset()`. This is a cleaner approach since callers are already required to use this initialization function. The change affects two call sites in `reftable/stack.c` and makes the code more maintainable by centralizing the initialization logic.

Justin Tobler reviews the change and agrees with the approach, noting that it simplifies the calling convention while maintaining the same functionality. The patch appears straightforward and uncontroversial, fitting well with the series' goal of improving reftable's robustness and compatibility.
