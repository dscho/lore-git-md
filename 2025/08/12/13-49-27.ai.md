Documentation patch reorganizing git-rebase's --onto explanation. This is part 4/5 of Julia Evans' series to improve the git-rebase man page, specifically moving the detailed `--onto` examples and explanation from the DESCRIPTION section to a new dedicated "TRANSPLANTING A TOPIC BRANCH WITH --ONTO" section. The change relocates 87 lines while maintaining all content, making the document's structure more navigable by giving the --onto use cases their own clearly labeled home.

The patch extracts three concrete examples of --onto usage that were previously buried in the DESCRIPTION section: transplanting a topic branch between bases, rebasing part of a branch, and removing a range of commits. Each example includes ASCII-art commit graphs showing before/after states and the exact commands to achieve the transformation. The relocated content remains unchanged except for adding a reference from the --onto option documentation to the new section.

This reorganization follows the series' goal of making rebase documentation more approachable by grouping related content together under descriptive headings. The change is purely structural - no content is added, removed, or modified beyond the section move and the addition of one cross-reference. The patch builds on earlier series changes that front-loaded key examples and consolidated duplicate explanations.

Technical details remain identical to the original, including the same three example scenarios, command syntax, and ASCII graphs. The only functional change is the new cross-reference from the --onto option documentation to the relocated section. This maintains all existing information while improving discoverability.

The patch represents one of the final steps in the documentation restructuring, following earlier patches that improved the initial examples and conflict resolution sections. With this change, the --onto explanation now has parity with other major rebase features that already had dedicated sections.
