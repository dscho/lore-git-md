This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v3, 8 patches). It fixes a type mismatch in the reftable writer interface where callers were passing `size_t` for record counts but the functions accepted `int`. 

The change updates both the function declarations in `reftable-writer.h` and their implementations in `writer.c` to consistently use `size_t` for the number of records parameter. This affects `reftable_writer_add_refs()` and `reftable_writer_add_logs()`, which handle batches of ref and log records respectively. The implementation changes include:
- Updating the parameter types in header declarations
- Modifying loop variables to use `size_t`
- Simplifying the loop syntax by removing unnecessary braces

This appears to be a straightforward cleanup that aligns with the series' focus on type safety and interface consistency. The change is mechanical and well-contained, touching only the writer component of the reftable backend. It follows naturally from the thread's established context of improving reftable's robustness for libgit2 compatibility.
