Documentation patch improving git-rebase's introductory section by adding a clear example upfront. This is the first patch in Julia Evans' merged series that restructured the git-rebase man page for better readability.

The patch moves the existing rebase example from later in the document to the very start of the DESCRIPTION section, mirroring the approach used in git-merge's documentation. It adds a brief explanation that rebase can also reorder or combine commits (with a pointer to INTERACTIVE MODE) before showing the concrete example of rebasing a topic branch onto an updated master branch. The example demonstrates both the basic `git rebase master` form and the topic branch variant, explaining the latter is equivalent to a checkout followed by rebase.

The changes are purely organizational - the content is largely the same as what appeared later in the original, just presented earlier where readers are more likely to see it. This follows the series' goal of making rebase documentation more approachable by front-loading practical examples. The patch shows good attention to detail in maintaining all the original technical information while improving its presentation.
