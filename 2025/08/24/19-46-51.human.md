This is a documentation patch fixing a typographical error in the mergetool configuration documentation. Kristoffer Haugsbakk noticed that a possessive "Git's" was incorrectly formatted with a backtick (`Git`s`) in the mergetool.adoc file, likely introduced accidentally in a previous documentation update from May 2025.

The patch simply changes the backtick to an apostrophe to properly form the possessive "Git's". The author provides a thorough demonstration showing they searched for similar issues across the codebase and found this to be the only occurrence needing correction.

This is a straightforward, well-justified documentation fix that maintains consistency with Git's documentation style. The patch is clean and focused, with the author having done their due diligence to check for similar issues elsewhere in the codebase.
