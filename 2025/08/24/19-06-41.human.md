Performance optimization for `git log -L` (line-log) merge commit processing. This is the first and most substantive patch in a 4-part series aimed at improving line-log performance and code quality.

The patch optimizes how Git processes merge commits during line-log operations by avoiding unnecessary tree diffs. Previously, Git would compute diffs against all parents first, then checking if the paths of interest were modified. The patch combines these steps, processing each parent's diff immediately and skipping further work if no relevant changes are found. This yields significant speedup, especially in merge-heavy repositories (2.25x faster in git.git, 1.32x in linux.git).

The change also removes now-unused helper functions and simplifies the code structure. While internal-only, the performance impact is measurable and the implementation appears clean. The benchmark results are convincing and the commit message clearly explains both the optimization and its benefits.
