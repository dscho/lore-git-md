This is a preparatory patch for the new `git-history` command series, adding infrastructure to the sequencer to optionally suppress commit summary output. The patch introduces a `skip_commit_summary` option in the sequencer that prevents printing the usual commit details (author, date, file changes) after operations like cherry-pick. This will be useful for the upcoming `git-history` command where such output would be noisy.

The implementation adds the new flag to `struct replay_opts` and makes it persistent across sequencer operations by storing it in the sequencer's config file. The change is minimal and focused, touching only the necessary parts of sequencer.c and sequencer.h. The commit message clearly explains the motivation and shows example output that would be suppressed.

This appears to be a straightforward and well-justified change that lays groundwork for the larger series. The patch follows Git's coding style and includes appropriate test coverage (though no new tests are shown in the diff). As the first in a 16-patch series, it does the job of starting small with a focused infrastructure change before introducing the more complex functionality to come.
