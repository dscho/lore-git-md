This is a performance optimization and cleanup series for Git's line-log functionality (used by commands like `git log -L`). The series comes from SZEDER Gábor and focuses on making merge commit processing more efficient in the line-log machinery.

The key patch is the first one, which avoids unnecessary tree diffs when processing merge commits in the line-log. The optimization appears well-motivated - the commit message explains that the current implementation performs redundant work by computing the same tree diffs multiple times for merge commits. The remaining three commits are smaller cleanups that simplify the code by removing an unused parents array, initializing a diff queue earlier, and streamlining merge commit detection logic.

The changes touch only line-log.c, with a net reduction of 30 lines of code. The series looks like a focused, technical improvement to an area of Git that sees regular use but isn't frequently optimized. The cleanups appear straightforward and the optimization seems likely to provide real speedups for line-log operations on repositories with many merge commits.
