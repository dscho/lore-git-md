Performance optimization for `git describe`'s depth computation. René Scharfe replaces a quadratic-time queue scan with a khash set to track unflagged commits, providing a 40% speedup in benchmarks. The patch avoids using an object flag (which would reduce available tag candidate slots) by instead maintaining a hash table of commit pointers keyed by their unique index values. The change builds on a previous optimization from earlier this month (08bb69d70f) and shows measurable improvements when describing commits between v2.41.0 and v2.47.0. The implementation carefully handles flag transitions and queue membership tracking while maintaining the same behavior with better asymptotic complexity.
