This is a preparatory patch in Patrick Steinhardt's `git-history` RFC series (v2 14/16), adding infrastructure for comparing tree states. The patch introduces a new function `wt_status_collect_changes_trees()` that diffs two arbitrary trees and formats the results using the working tree status machinery.

The function provides a generalized way to show changes between any two tree objects, rather than just comparing the working tree/index to HEAD. While this stretches the "working tree status" concept slightly, the author argues it's better than open-coding similar functionality elsewhere. The implementation reuses the existing diff and status formatting callbacks.

This appears to be building infrastructure needed by later patches in the series that will implement history editing operations. The changes are cleanly scoped and maintain existing behavior while adding the new capability. As with other patches in this series, it demonstrates careful attention to Git's internal architecture.
