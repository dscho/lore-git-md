This `git subtree` bugfix is now ready for merging after three iterations of review. The patch addresses a regression in how squashed merges of nested subtrees (like `subA/subB`) were being handled during split operations when using the `--prefix` option - a problem introduced in Git v2.44.0-rc0.

Colin Stagner's solution rewrites the commit examination logic to use a single `git show` call rather than multiple `git log` invocations, while preserving all the original conditions for ignoring commits. The implementation includes comprehensive new test coverage through a dedicated test helper and expanded scenarios in t7900-subtree.sh, verifying both regular and squashed merge cases.

Phillip Wood provided thorough review feedback that has been fully incorporated, except for one minor shell syntax preference. Junio Hamano suggested more precise handling of unset variables using `${var-}` syntax, which was implemented in the final version. All parties agree the patch is ready for application to the maint-2.44 branch, with no outstanding questions remaining. The fix maintains backward compatibility while properly handling the squashed merge case that was previously broken.
