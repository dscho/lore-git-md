This is a technical clarification in the ongoing Meson build system integration thread. Patrick Steinhardt responds to Karthik Nayak's question about the logic for handling the Tcl/Tk 'wish' dependency in the gitk build configuration.

Patrick explains that the `disable_auto_if` check is necessary because the build system distinguishes between explicitly enabled features (`enabled()`) and auto-detected ones (`allowed()`). Even when 'wish' is required for gitk when explicitly enabled, there are cases where auto-detection might find some Tcl/Tk tools but not others, requiring the build system to gracefully fall back.

This exchange highlights the careful attention to edge cases in the Meson integration work, particularly around optional dependencies.
