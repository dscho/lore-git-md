This is a refactoring patch in Patrick Steinhardt's RFC series for a new `git-history` command. The patch focuses on cleaning up the interactive add/patch infrastructure that will be used by the new command.

The main change splits out a new `struct interactive_options` to hold common configuration between `git add -i` and `git add -p`, replacing the previous `struct add_p_opt`. This helps clarify which options apply to which parts of the interactive add stack. The patch moves color configuration and other shared settings into this new structure while maintaining all existing functionality.

The changes are mechanical but improve code organization - moving color handling and configuration parsing into dedicated functions in `add-patch.c` rather than having it mixed with the interactive add logic in `add-interactive.c`. The patch touches many files since it changes the interface between these components, but the changes are straightforward renames and adjustments to use the new structure.

This appears to be solid preparatory work for the larger `git-history` feature, continuing the series' pattern of careful infrastructure improvements. The patch doesn't introduce new functionality but makes the codebase more maintainable for the upcoming history editing commands.
