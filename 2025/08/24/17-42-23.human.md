1. Reducing `add-interactive.h` by 20 lines while maintaining all functionality
2. Creating a more logical separation between the patch and interactive subsystems
3. Making it easier to locate relevant declarations when working on either component

This appears to be preparatory work for the larger history command series, ensuring clean code organization before adding new functionality.
