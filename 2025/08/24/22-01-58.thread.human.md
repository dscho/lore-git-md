This thread discusses the potential deprecation of `git whatchanged`, a long-standing Git command that shows commit logs with diff output. The deprecation notice in Git 2.51.0 has prompted community feedback, with Monte Davidoff chiming in to note they still actively use the command. While this doesn't offer specific technical justification for keeping the command, it provides a data point about real-world usage that maintainers may consider when evaluating whether to proceed with removal. The thread appears to be in an information-gathering phase, with the core question being whether `git whatchanged` still serves needs not met by `git log` (its recommended replacement) or other modern commands.
