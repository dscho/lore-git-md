This is a feature patch introducing the scaffolding for a new `git-history` command, part of Patrick Steinhardt's RFC series to provide more intuitive history editing operations. The patch adds the basic command infrastructure - Makefile entries, documentation stub, and a minimal implementation that currently just handles option parsing.

The proposed `git-history` command aims to simplify common history rewriting operations like reordering, splitting, dropping, and squashing commits, which currently require more involved interactive rebase workflows. The documentation positions it as complementary to `git-rebase`, with an explicit note that it doesn't yet handle merge commits and is marked as experimental.

The implementation is currently just a skeleton - the actual subcommands for specific operations will come in later patches. The patch touches build system files and adds the new command to various command lists while introducing a placeholder implementation that does nothing beyond basic option parsing. This appears to be well-structured preparatory work for what will become a more complex feature.
