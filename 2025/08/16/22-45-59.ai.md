This is the foundational patch for a new `git repo` command hierarchy, part of a GSoC project to migrate repository metadata functionality from `git rev-parse`. The patch establishes the basic command structure with an initial `info` subcommand, though the implementation is currently just a skeleton.

Key technical elements introduced:
- New `builtin/repo.c` implementing the command framework with `cmd_repo()` entry point
- `repo_info()` subcommand handler (currently does nothing)
- Documentation in `git-repo.adoc` marking the command as experimental
- Build system integration (Makefile, meson)
- Command registration in `command-list.txt` and `git.c`

The patch follows the architectural decisions from the thread:
- Creates a new home for repository metadata queries
- Preserves the subcommand pattern seen in other Git commands
- Includes experimental documentation warning about potential behavior changes

The implementation is minimal at this stage - the actual functionality to retrieve repository information will be added in subsequent patches. This appears to be a clean foundation that follows Git's established patterns for new commands, with proper build system and documentation integration from the start.
