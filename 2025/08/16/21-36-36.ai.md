This is part 3/9 of the submodule gitdir path encoding series, introducing a config override mechanism for submodule gitdir paths. The patch adds flexibility to the path encoding scheme by allowing per-submodule gitdir path overrides via the config key `submodule.<name>.gitdirpath`.

Key technical additions:
- New `git submodule--helper gitdir` subcommand to query gitdir paths
- Config lookup in `submodule_name_to_gitdir()` that checks for overrides before falling back to default path construction
- New test helper `lib-verify-submodule-gitdir-path.sh` to verify gitdir paths
- Test case in t7400 demonstrating config override and reversion to defaults

The implementation maintains backward compatibility while providing an escape hatch for alternative implementations (like JGit) that might need different path encoding schemes. The test infrastructure added here will be reused in later patches to verify the URL encoding behavior.

This is a well-contained piece of the larger effort, cleanly separating the config override mechanism from the core encoding logic that will come in subsequent patches. The test coverage is thorough, verifying both the override functionality and the fallback to default behavior.
