Feature implementation for the new `git repo info` command. This is the final patch in the v11 series that introduces the `--format` flag, allowing users to choose between human-readable (keyvalue) and machine-parsable (nul) output formats.

The patch follows the established pattern from `git config` for dual-format output, with keyvalue` as the default human-readable format (using `=` delimiters and quoting unusual characters) and `nul` for machine consumption (using newline/NUL delimiters without quoting). The implementation includes thorough documentation updates with examples, proper error handling for invalid formats, and matching test cases for both formats.

This completes the core functionality of the `git repo info` command, which has been through extensive review across 11 versions with input from multiple mentors and contributors. The patch maintains the series' high quality with clean separation of concerns, comprehensive tests, and clear documentation. With all feedback addressed and approvals from both mentors and the maintainer, this marks the final piece of a successful GSoC project to create a new command hierarchy for repository metadata.
