This is a cover letter for a feature series addressing submodule gitdir naming conflicts. Adrian Ratiu presents a 9-patch series that builds on 2018 work by Brandon Williams to encode submodule gitdir paths to avoid naming conflicts.

The series rewrites the earlier approach using URL-style encoding rather than alternatives like custom encodings or hashing. The changes are organized to keep encoding logic, test updates, and path handling cleanly separated. The work affects multiple submodule-related commands and includes extensive test coverage, with new tests specifically for gitdir path encoding.

The motivation comes from the need to safely handle submodule names that might otherwise create path conflicts when stored in the filesystem. The series appears thorough, with clear attention to backward compatibility and testing. Adrian notes they've tested against both 'next' and 'seen' branches and plans to discuss this work at an upcoming mini-summit.

Key technical aspects touched include:
- New gitdir path configuration under submodules/
- URL encoding implementation using RFC3986 unreserved characters
- Removal of now-unneeded validation code
- Reorganization of test cases for better clarity

The changes span documentation, core submodule handling, and test infrastructure, suggesting this is a significant but well-scoped improvement to submodule storage reliability.
