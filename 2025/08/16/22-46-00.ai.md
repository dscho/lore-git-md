Feature implementation for the new `git repo info` command hierarchy, specifically adding the `references.format` field. This patch is part of the v11 series that's now in the 'next' branch and approved for merging.

The patch introduces functionality to query the repository's reference storage format (either "files" or "reftable") through the new `git repo info` command. It implements a bsearch-based lookup system for field keys in `repo_info_fields` and adds proper quoting mechanism for output values using `core.quotePath` rules. The implementation includes a clean separation between field definition, value retrieval (`get_references_format`), and output formatting (`print_fields`).

Key technical details include:
- New `get_references_format()` function that maps `repo->ref_storage_format` to string values
- Field lookup system using `bsearch` with `repo_info_fields_cmp`
- Output formatting with proper quoting via `quote_c_style()`
- Comprehensive test coverage in new `t1900-repo.sh` verifying:
  - Correct format detection for both files and reftable backends
  - Error handling for invalid keys
  - Partial success output when mixing valid and invalid keys
