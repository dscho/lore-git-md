This is patch 8/9 in a series improving submodule gitdir path handling, specifically focused on test reorganization. The patch moves tests for nested gitdirs from t7450-bad-git-dotfiles.sh to t7425-submodule-mixed-gitdir-paths.sh, since the path encoding work in earlier patches means these cases are no longer pathological.

The tests verify that submodules with nested gitdirs (like "hippo" and "hippo/hooks") are properly handled with the new path encoding scheme. The test cases cover:
- Basic nested submodule cloning
- Parallel cloning with --jobs=2
- Checkout operations with simulated malicious nested alternates

The move makes sense as these tests now belong with other tests of the new path encoding behavior rather than with tests for bad dotfiles. The patch is straightforward - it's just moving existing tests to a more logical location while maintaining all their functionality.
