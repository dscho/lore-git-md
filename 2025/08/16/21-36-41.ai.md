This is a test reorganization patch in the submodule gitdir path encoding series. It moves tests for nested gitdir handling from t7450-bad-git-dotfiles.sh to t7425-submodule-mixed-gitdir-paths.sh, as the path encoding changes in earlier patches have made these scenarios non-pathological.

The patch transfers three key test scenarios that verify proper handling of nested submodule gitdirs with the new encoding scheme:
1. Basic nested gitdir validation during clone
2. Parallel cloning behavior with nested paths
3. Correct handling during recursive checkout with simulated malicious alternates

All tests use the new `verify_submodule_gitdir_path` helper to check encoded path locations (e.g. `submodules/hippo%2fhooks`). The tests were previously in t7450 which focused on pathological cases, but now belong with other tests of the mixed legacy/new path handling system.

This is a straightforward test relocation that maintains all existing coverage while better organizing the test suite to reflect the current state where nested paths are properly handled via encoding rather than being edge cases. The patch follows naturally from the earlier work that made these tests non-exceptional.
