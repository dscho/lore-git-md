Submodule gitdir path encoding series (v5) - complete implementation with final design decisions on path encoding scheme, length handling, and transition strategy. The series implements path encoding via `extensions.submoduleEncoding` config to prevent filesystem conflicts in submodule gitdirs, with Adrian Ratiu, Junio C Hamano, and Patrick Steinhardt in full agreement on all architectural points.

Core architecture maintains unified directory structure in `.git/modules/` with path resolution through `submodule_name_to_gitdir()`. Key resolved decisions:
1. URL percent-encoding (`%41` for 'A') adopted over custom schemes as the sole encoding method
2. Config-based transition using `submodule.<name>.gitdirpath` as authoritative mapping (Junio's proposal now strongly endorsed by Patrick Steinhardt and explicitly confirmed by Adrian Ratiu)
3. Truncation+uniquification for long paths via runtime filesystem feedback (handling `ENAMETOOLONG` by progressive shortening)
4. Documentation clarifies encoding permanence and edge cases while hiding algorithm details
5. Existing paths with percent-encoded-looking sequences treated literally via `gitdirpath` mapping (Junio's final verification)
6. Encoding applied minimally - only when needed for filesystem safety (case/NFC/NFD conflicts detected via `EEXISTS` from `mkdir()`)
7. No future encoding variants planned while allowing internal improvements
