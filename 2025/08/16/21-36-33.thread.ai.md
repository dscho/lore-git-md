Submodule gitdir path encoding series (v5) - complete implementation with path length validation, now ready for final review. The series implements path encoding to prevent filesystem conflicts in submodule gitdirs via `extensions.submoduleEncoding` config option, with all major components in place. Junio C Hamano's review of v3 raised retrospective design considerations about extension compatibility and migration implications, though these were already addressed in the final implementation.

Core architecture:
- Unified directory structure in `.git/modules/` with extension control
- Path resolution order in `submodule_name_to_gitdir()`:
  1. Config override (`submodule.<name>.gitdirpath`)
  2. Legacy path validation
  3. Encoding if extension present (using shared strbuf URL encoding)
  4. Length validation via `pathconf(_PC_NAME_MAX)` with 255 fallback
- Case encoding preserved for cross-platform compatibility
- 25 files modified across the series (20 from parts 1-2 + strbuf changes + encoding logic + final length validation)

Technical additions in final patch:
- Platform-portable length validation using `pathconf(_PC_NAME_MAX)`

- Platform detection in config.mak.uname and meson.build
