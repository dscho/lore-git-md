Submodule gitdir path encoding series (v6) - complete implementation of pure runtime configuration through `extensions.submodulePathConfig` with all build-time options definitively rejected. The 10-patch series implements path encoding via a new extension name (`submodulePathConfig`) to prevent filesystem conflicts in submodule gitdirs, with architectural consensus requiring complete `submodule.<name>.gitdir` configuration when enabled.
