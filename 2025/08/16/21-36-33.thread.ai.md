Submodule gitdir path encoding series (v1) - complete rewrite of 2018 Brandon Williams work to prevent filesystem conflicts in submodule gitdir paths. Current status through patch 8/9:

- Core path encoding mechanism implemented using URL-style encoding (RFC 3986) with case encoding for filesystem compatibility (patches 1-6)
- Patch 7 removed redundant `validate_submodule_git_dir()` function after path encoding made its conflict checks obsolete
- Patch 8 reorganizes test suite by moving nested gitdir tests from t7450-bad-git-dotfiles.sh to t7425-submodule-mixed-gitdir-paths.sh:
  - Transfers three key scenarios for nested submodule gitdir handling
  - Tests now use `verify_submodule_gitdir_path` helper to check encoded paths
  - Better reflects that nested paths are now properly handled via encoding rather than being edge cases
- New helper `strbuf_addstr_case_encode()` handles case-insensitive filesystems (uppercase to `_a`, `_b` etc.)
- Path construction flow in `submodule_name_to_gitdir()` applies:
  1. Config override check (`submodule.<name>.gitdirpath`)
  2. Legacy path check (`.git/modules/`)
  3. New encoded path generation (`.git/submodules/` with URL + case encoding)
- Maintains backward compatibility while transitioning to new paths
- Windows reserved names (COM1 etc.) handled through encoding
- Path length validation against `NAME_MAX` preserved as BUG checks
- Test coverage expanded across t7400, t7406, t7425 for clone/update/checkout operations
- Test expectations updated for encoded paths (e.g. `dirdir%2fsubsub`)
- Builds on earlier patches that:
  - Changed default gitdir location to `.git/submodules/` (patch 2/9)
  - Added config override mechanism (patch 3/9)
  - Introduced test infrastructure (lib-verify-submodule-gitdir-path.sh)
  - Added mixed-path tests (t7425 now at 308 lines)

Key technical details:
- URL encoding implementation in submodule.c with shared utilities moved to strbuf.c
- Case encoding designed for cross-platform compatibility
- Test scenarios verify correct behavior with:
  - Legacy and new path coexistence
  - Case conflicts
  - Windows reserved names
  - Nested submodule operations
- 24 files updated across code and documentation
- New `git submodule--helper gitdir` subcommand for path querying
