Submodule gitdir path encoding series (v5.7) - now with build-time enablement option. The series implements path encoding via `extensions.submoduleEncoding` config to prevent filesystem conflicts in submodule gitdirs, with architectural agreement from Adrian Ratiu, Patrick Steinhardt, and Junio Hamano. Core architecture maintains unified directory structure in `.git/modules/` with path resolution through `submodule_name_to_gitdir()`.

Technical implementation includes all previously detailed components plus new build system support:
- `extensions.submoduleEncoding` config option enabling path encoding
- `submodule.<name>.gitdir` as single source of truth for encoded paths
- Four-tier fallback system (plain path -> URL encoding -> digit appending -> hashed name)
- Build-time enablement via autoconf (`--enable-submodule-encoding`) and meson (`submodule-encoding`)
- `SUBMODULE_ENCODING_BY_DEFAULT` preprocessor definition
- Initialization of `repo_fmt.submodule_encoding` when build flag set
- Documentation of config precedence (repo config overrides build default)
- URL encoding helper `is_rfc3986_unreserved()` moved from credential-store.c to url.[ch] for shared use
