Submodule gitdir path encoding series (v5) - complete implementation with final design discussions on URL encoding scheme, helper placement, path length handling robustness, and now definitive resolution of the helper function location debate. The series implements path encoding to prevent filesystem conflicts in submodule gitdirs via `extensions.submoduleEncoding` config option, with all major components in place including platform-portable length validation and test coverage.

Core architecture maintains unified directory structure in `.git/modules/` with path resolution through `submodule_name_to_gitdir()`.
