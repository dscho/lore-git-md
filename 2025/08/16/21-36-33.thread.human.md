The submodule gitdir path encoding series has reached its final design consensus, with Adrian Ratiu and Junio Hamano agreeing on all major architectural points after several iterations. The solution uses URL percent-encoding for submodule gitdir paths when needed to prevent filesystem conflicts, controlled via `extensions.submoduleEncoding` config. Key decisions include using `submodule.<name>.gitdirpath` as the authoritative mapping (Junio's proposal that Adrian accepted), handling long paths with truncation+uniquification, and treating existing percent-encoded-looking paths literally via the gitdirpath mapping.

Junio provided final refinements to make the encoding minimal - only applying it when necessary for filesystem safety - and confirmed the series handles all edge cases robustly, including Windows-specific scenarios. Adrian has implemented these changes in v5, removing documentation of the encoding algorithm to keep it as an internal implementation detail. The migration strategy is deliberately conservative, only moving gitdirs when conflicts exist, with special handling for paths like `.git/reftable/`. With all open questions resolved and the implementation complete, the series is in its final polishing stages before merging.
