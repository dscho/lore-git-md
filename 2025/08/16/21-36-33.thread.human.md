This thread is discussing a major rewrite of Git's submodule gitdir path handling to prevent filesystem conflicts by using URL-style encoding (RFC 3986) with case encoding for cross-platform compatibility. The current 12-patch series (expanded from v1's 9 patches) has incorporated extensive review feedback and is passing all CI tests.

Key technical changes include a new path resolution order in `submodule_name_to_gitdir()`, URL encoding implementation with shared utilities, and comprehensive test coverage across 202 cases. The design has evolved to use a repository extension (`extensions.submoduleEncoding`) as the primary cross-implementation mechanism, with config overrides now clearly positioned as an optional feature. Notable contributors include Phillip Wood (safety fixes), Adrian Ratiu (version compatibility), Jeff King (Windows/platform fixes), and Patrick Steinhardt (cross-implementation concerns).
