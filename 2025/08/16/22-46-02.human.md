This is a feature patch adding repository metadata reporting to the new `git repo info` command, specifically implementing the `layout.shallow` field.

The patch adds a new field `layout.shallow` to report whether a repository is shallow, following the same boolean string pattern as the existing `layout.bare` field. The implementation uses Git's existing `is_repository_shallow()` function, which was previously exposed via `git rev-parse --is-shallow-repository`. The change includes documentation updates and comprehensive tests that verify both shallow and non-shallow repository cases.

This is part of a larger v11 series (now in the 'next' branch) that creates a new `git repo` command hierarchy to migrate repository metadata reporting from `git rev-parse`. The implementation follows established patterns from earlier patches in the series, with clean separation of concerns and thorough test coverage. The patch has already received positive feedback from multiple reviewers and mentors, including Junio Hamano and Phillip Wood.

The change is straightforward and well-contained, adding functionality that logically belongs with the other repository layout information being exposed through this new command. The test cases are particularly thorough, including both direct verification and a more complex case that creates an actual shallow clone to test the true condition.
