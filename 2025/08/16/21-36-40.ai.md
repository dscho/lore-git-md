This is part 7/9 of the submodule gitdir path encoding series, focusing on cleanup after the core encoding work. The patch removes the now-redundant `validate_submodule_git_dir()` function, whose conflict-prevention role is superseded by the new path encoding scheme.

The key changes are:
1. The function's basic invariant checks (path suffix matching, length validation) are moved into `submodule_name_to_gitdir()` as BUG assertions since they should never fail with proper encoding.
2. The more complex validation of nested gitdirs is removed entirely since path encoding makes such conflicts impossible.
3. All call sites are updated to remove validation checks, including in `clone_submodule()`, `submodule_move_head()`, and `relocate_single_git_dir_into_superproject()`.

The patch maintains safety by keeping the fundamental invariants as BUG checks while eliminating now-unnecessary validations. This is a logical next step after the path encoding work in earlier patches, reducing codebase complexity while preserving the series' goals of preventing submodule gitdir conflicts. The changes are straightforward with no apparent behavioral impact beyond what the encoding scheme already guarantees.
