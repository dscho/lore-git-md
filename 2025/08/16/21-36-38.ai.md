This is a refactoring patch in the submodule gitdir path encoding series, moving a URL encoding helper function back to strbuf.c for broader use.

The patch relocates `is_rfc3986_unreserved()` from credential-store.c to strbuf.c, making it available to other parts of Git. This function checks if a character is unreserved per RFC 3986 (alphanumerics plus '-', '_', '.', '~'). The move is necessary for the submodule gitdir path encoding work, where this function will be used to properly encode submodule names in paths.

The change reverses a previous consolidation where the function was made static in credential-store.c when it was only used there. Now that the submodule system needs this functionality for path encoding, the function is being promoted back to strbuf utilities. The patch updates both the implementation and header file, while removing the now-redundant credential-store.c version.

This is a straightforward mechanical change with no behavior modifications. The patch maintains the exact same function implementation, just moving it to a more appropriate shared location. As part of the larger submodule path encoding series, this enables subsequent patches to use standard URL encoding for submodule gitdir paths without duplicating the character classification logic.
