This is a follow-up CMake build system fix related to the reftable test migration. The patch replaces the now-obsolete `UNIT_TEST_PROGRAMS` variable parsing with wildcard pattern matching (`t-*.c`) to discover unit tests, mirroring the Makefile's approach after the reftable tests were converted to C unit tests in commit 9bbc981c6f2.

The change is minimal (4 lines) and specifically addresses CMake build failures that occurred after the test migration. The patch maintains the same linking behavior against unit-test-lib and common-main while adapting to the new test organization. Johannes Schindelin notes this is still needed fix for v2.51.0 final, having originally sent it before -rc0 was released.

The technical changes involve:
- Switching from `parse_makefile_for_scripts()` to `file(GLOB)` for test discovery
- Two `list(TRANSFORM)` operations to adjust paths and remove `.c` suffixes
- Preserving the existing `target_link_libraries()` configuration

This appears to be a straightforward, uncontroversial follow-up to prior work with no outstanding technical questions. The patch maintains build system parity between Makefile and CMake configurations for the new unit test structure.
