Hostname-based conditional config includes feature request (GitHub issue #1665). Ayush Sharma seeks to implement `hostname:` condition for `includeIf` sections, similar to existing `gitdir:` and `onbranch:`, enabling machine-specific configs in dotfiles management. Original February 2024 proposal suggested syntax `[includeIf "hostname:FIRSTMACHINE"]`. Junio C Hamano references a March 2024 thread by Ignacio Encinas discussing similar functionality, though full context of that discussion is not provided here. Current status remains open with no active development. Technical scope would involve adding hostname detection/matching to `config.c`, primarily affecting config parsing. Use case focuses on multi-machine workflows with per-host configs (email, core.editor, etc.). No security analysis or implementation details yet provided. Key open questions: maintainer receptiveness based on prior discussion, whether this fits Git's design principles, and handling of edge cases (hostname spoofing, dynamic hostnames).
