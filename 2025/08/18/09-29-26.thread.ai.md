Hostname-based conditional config includes feature request (GitHub issue #1665). Ayush Sharma inquires about implementing `hostname:` condition for `includeIf` sections, similar to existing `gitdir:` and `onbranch:` conditions, to enable machine-specific configs in dotfiles management. Original February 2024 proposal suggested syntax `[includeIf "hostname:FIRSTMACHINE"]`. Current status is open with no active development. Sharma seeks maintainer feedback on feature viability before implementation. Technical scope would involve adding hostname detection/matching to config parsing, primarily affecting `config.c`. Use case centers on multi-machine workflows where users want different configs (e.g. email, core.editor) per host. No security analysis or implementation details provided yet. Key open questions: maintainer receptiveness, whether this fits Git's design principles, and potential edge cases (hostname spoofing, dynamic hostnames). Next step awaits maintainer response on whether to proceed with a formal proposal.
