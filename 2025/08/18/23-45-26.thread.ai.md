Jenkins Git client plugin continues using deprecated `git whatchanged` command (Mark Waite). The plugin relies on this command for changelog generation despite Git 2.51.0's deprecation. Junio Hamano acknowledges the notification and confirms the deprecation timeline remains unchanged - `whatchanged` will be removed in Git 3.0 (no release date set). The `--i-still-use-this` flag is only a temporary workaround, not a permanent solution. 

Hamano notes removal could theoretically be reconsidered if enough users demonstrate migration difficulty, but this seems unlikely. `git log --raw` (with appropriate options) is suggested as the likely replacement path, though migration approach is left to Jenkins plugin maintainers. The thread serves as documentation of ongoing dependency on deprecated functionality while replacement work progresses, per Git's deprecation policy. No technical discussion is expected - purely maintaining awareness of the removal timeline.
