Git v2.51.0 has been released, bringing significant improvements and setting the stage for upcoming changes in Git 3.0. The release includes over 500 changes from 91 contributors, with the reftable backend now considered mature enough to become the default format in the next major version. 

User-visible improvements include streamlined merge/pull output with `--compact-summary`, stabilization of `git switch`/`git restore`, enhanced stash functionality, and IMAP send improvements with OAuth support. Internally, the project continues major refactoring efforts to remove the `the_repository` global and restructure the object store, while also making performance improvements in pack handling and reference updates.

The release marks progress toward SHA-256 as the default hash algorithm and includes the beginning of a deprecation path for `git whatchanged`. Alongside these changes, the project has made numerous bugfixes and documentation updates, including translations, while improving build system support with Meson.
