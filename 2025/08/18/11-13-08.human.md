This is a bugfix series addressing issues in Git's line-log functionality (used with `git log -L`). The patches fix two distinct problems that were discovered when using multiple line ranges.

The first patch fixes an assertion failure that occurs with specific combinations of line ranges and diff ranges. The commit message explains that this wasn't just a simple assertion fix - after addressing the initial crash, the command would enter an infinite loop, and after fixing that, the output was still incorrect. The patch includes tests to verify all these cases.

The second patch fixes another output issue that the author discovered while testing the first fix. While not directly related to the original bug report, it improves line-log's behavior when showing multiple ranges affected by the same diff.

The series appears well-tested, with new test files added for both SHA-1 and SHA-256 repositories. The author (SZEDER Gábor) is responding to a bug report from Evgeni Chasnovski from May 2024, showing the issue has been known for several months. The fixes look thorough, addressing not just the immediate crash but also related edge cases that became apparent during debugging.
