This is a release announcement for Git v2.51.0, marking a new stable version with numerous changes across the codebase. The release includes 506 non-merge commits from 91 contributors, with 21 new contributors joining the project.

Key user-facing changes include:
- The reftable backend is now mature and will become the default format in Git 3.0
- New `--compact-summary` option for `git merge/pull` to replace diffstat output
- `git switch` and `git restore` are no longer marked as experimental
- Improved `git stash` functionality with new import/export subcommands
- Various improvements to `git imap-send` including OAuth2.0 support
- Deprecation path for `git whatchanged` begins

Significant internal changes include:
- Continued work to remove dependence on `the_repository` global
- Object store restructuring and renaming to better support multiple backends
- Performance improvements in pack-objects with new `--path-walk` option
- Batch reference updates in fetch/push operations
- Meson build system improvements including TAP test output support
- Many memory leak fixes and code cleanups

The release also includes numerous bugfixes across submodules, ref handling, diff filtering, and other areas. Documentation has been updated throughout, including translations in multiple languages. The project continues its transition to SHA-256 as the default hash algorithm, with work to enable it by default in Git 3.0's breaking changes mode.
