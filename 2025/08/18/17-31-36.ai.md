This is a "What's cooking" status update from Junio C Hamano, summarizing the current state of topics in the Git development tree. The email provides a comprehensive overview of patches that are in various stages of review and integration, organized into sections for new topics, cooking topics, and those needing rerolls.

Key highlights include:

Several documentation fixes and improvements are progressing, including updates to `git-clone` synopsis, `git-log` markup, and linting rules for man pages. The `git refs list` subcommand has been introduced as a frontend to `git for-each-ref`, and `git diff-tree` now supports a `--max-depth` option.

Performance and correctness improvements are notable in multiple areas: the commit-graph code has been de-globalized, Bloom filters now work with wildcard pathspecs, and `git describe` has been optimized with a priority queue. The `ort` merge strategy received fixes for rename handling bugs.

New functionality includes `git send-email` gaining IMAP folder support, a proposed `git last-modified` command to track file modification history, and a new `git repo` subcommand to query repository characteristics. The sparse-checkout feature is being extended with a `clean` action to prune unused files.

Several topics are flagged as needing rerolls, including work on the promisor-remote capability, sparse checkout variables, and MIDX API improvements. The email also notes ongoing discussions about deprecating `core.commentChar=auto` and improvements to the xdiff hash function.

The update serves as both a progress report and coordination mechanism for the Git development community, showing a mix of bugfixes, performance work, new features, and infrastructure improvements across the codebase.
