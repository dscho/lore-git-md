Bugfix analysis for autosquash rebase commit message cleanup behavior. Phillip Wood responds to Simon Cheng's bug report about `commit.cleanup=strip` not working during autosquash rebases when prepare-commit-msg hooks inject comments.

Phillip identifies the root cause in commit f7d42ceec52, which changed fixup commit handling to preserve messages verbatim during rebase, overriding the cleanup setting. He questions this design choice, noting that regular "pick" commands do respect `commit.cleanup` and that hook-injected content already means messages aren't truly verbatim. Phillip suggests making fixup commands follow the same cleanup rules as picks for consistency.

The response indicates this is a genuine bug rather than expected behavior, with Phillip planning to investigate further after a week's absence unless someone else addresses it first. The issue affects users who combine prepare-commit-msg hooks with autosquash workflows and expect consistent comment stripping behavior across all commit operations.
