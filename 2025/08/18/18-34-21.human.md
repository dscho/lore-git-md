Git maintainer Junio C Hamano responds to a request for a graphical interface for Git history manipulation. The original poster had surveyed 15 existing GUI tools and found none suitable for visual workflow needs like mouse-driven commit reordering and squashing. 

Hamano acknowledges the gap identified by the user and suggests this could make a good starter project for programs like Google Summer of Code or Outreachy. He proposes the tool could work as a frontend that generates `git rebase -i` todo files while providing a more intuitive visual interface. 

The response is lighthearted ("fun little project") but recognizes the validity of the feature request. No technical implementation details are discussed, positioning this more as an invitation for contributors rather than a roadmap from core maintainers. The thread remains open for further discussion about potential approaches or alternative solutions.
