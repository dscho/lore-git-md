This thread documents ongoing usage of the deprecated `git whatchanged` command in the Jenkins Git client plugin. Mark Waite reports that despite Git 2.51.0's deprecation of this command, Jenkins still relies on it for generating changelogs. The notification includes the standard deprecation warning text that appears when running the command without the `--i-still-use-this` flag, though it's unclear if the plugin currently uses this workaround.

The message serves as both a compliance notification (as requested by Git's deprecation warning) and a heads-up that a replacement implementation is in early development. No technical discussion or input is being sought - this appears to be purely informational documentation of continued usage from a major CI system while work on a replacement progresses.
