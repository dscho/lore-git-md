This thread documents the Jenkins Git client plugin's transition away from the deprecated `git whatchanged` command. The command has been marked for removal in Git 3.0 (though no release date is set), with `git log --raw` identified as the replacement path. 

Junio Hamano initially confirmed the deprecation timeline remains firm, noting that while removal could theoretically be reconsidered if migration proves broadly difficult, this seems unlikely. The Jenkins maintainers have now reported successful progress in updating their plugin, with positive test results and an expected release. This demonstrates the deprecation policy working as intended, with affected projects making timely transitions before the command's eventual removal. The migration appears straightforward, with no technical obstacles encountered.
