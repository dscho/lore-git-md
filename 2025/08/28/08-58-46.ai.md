This is a feature patch series for git-gui, porting long-standing Git for Windows functionality to the mainline project. The patches implement GUI-based credential/prompt helpers (GIT_ASKPASS and GIT_ASK_YESNO) with Windows-specific enhancements.

The series consists of 4 patches:
1. Adds a new `git-gui--askyesno` script for interactive yes/no dialogs, originally written by Heiko Voigt for Windows fallback scenarios
2. Makes git-gui set GIT_ASKPASS to use its own askpass helper by default
3. Adds a `--title` option to customize the yes/no dialog window title
4. Uses Git for Windows' icon for the dialog when running on Windows

Key technical details:
- New executable `git-gui--askyesno` written in Tcl/Tk
- Modifies `git-gui.sh` to set environment variables for the helpers
- Windows-specific icon handling via `wm iconbitmap`
- Dialog responds to Enter/Escape keys for quick yes/no responses
- Follows git-gui's existing pattern for credential helpers

The changes appear well-contained and focused on improving the GUI experience, particularly for Windows users. The patches have a long history in Git for Windows fork and have been rebased to current master. The implementation looks clean with appropriate documentation updates.
