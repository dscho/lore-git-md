This is a bug report regarding the deprecated `git whatchanged` command. James Tuttle reports that their Jenkins pipelines are failing on Windows machines with Git 2.51.0 because the deprecated `whatchanged` command now requires an explicit `--i-still-use-this` flag to run. The error is breaking their CI/CD workflows, and while there's a fix in a newer Jenkins Git client plugin, they can't upgrade to it yet.

The message serves as both a notification that they still use this command (as requested in the deprecation warning) and a request to restore functionality. The issue appears to be Windows-specific in this case, affecting the 2.51.0.windows.1 version of Git. The reporter includes the exact error output showing how the command fails in their Jenkins environment.

This highlights a real-world impact of the `whatchanged` deprecation, showing it's still in active use in CI systems. The reporter isn't proposing a specific code change but rather bringing attention to the operational problems caused by the current deprecation approach.
