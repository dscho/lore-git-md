This is the final patch in a 4-part series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The patch adds Windows-specific icon handling to the `git-gui--askyesno` dialog.

The change makes the yes/no dialog use Git for Windows' standard icon (git-for-windows.ico) when available, providing visual consistency with other Git for Windows applications. The implementation:
- Checks for Windows platform via `$::tcl_platform(platform)`
- Locates the icon file by walking up from the script's directory to find share/git/git-for-windows.ico
- Uses Tk's `wm iconbitmap` to set the icon if found

This completes the series' goal of bringing Git for Windows' enhanced GUI helpers to mainline git-gui while maintaining the existing functionality. The patch is small (12 lines) and focused, following the incremental approach of the previous patches. With sign-off from both original author Heiko Voigt and porter Johannes Schindelin, and no objections raised in the thread, this appears ready for inclusion.
