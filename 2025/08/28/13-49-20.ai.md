This is a follow-up patch in the git-gui credential helper series, specifically addressing Tk 9.0 compatibility. The patch simplifies the yes/no dialog implementation by replacing custom Ttk widget code with Tk's built-in `tk_messageBox` function, reducing the script from 35 to 7 lines while maintaining all functionality.

Key technical changes:
- Removes custom Ttk widget construction code that was Tk 8.5-specific
- Replaces with `tk_messageBox` call that works across Tk 8.5+ versions
- Preserves Windows-specific icon handling but now passes icon path to `tk_messageBox`
- Maintains same exit code behavior (0 for Yes, 1 for No)
- Adds standard dialog font styling via `option add`
- Keeps existing title and prompt handling

The patch originated from Mark Levedahl as a compatibility fix, and Johannes Schindelin is incorporating it while keeping the original Git for Windows implementation intact for historical context. This appears to be the final piece of the series, addressing the last technical concern (Tk version compatibility) in a clean, minimal way. The changes are straightforward and maintain all existing functionality while improving maintainability.
