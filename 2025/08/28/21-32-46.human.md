Bugfix for gitk's combobox widget regression. Johannes Sixt confirms this is a known issue that was introduced in Git 2.48.0 (commit 904b36b815ff) and fixed in Git 2.50.0 (commit daa364cfb7a1). The bug caused gitk's preferences dialog to fail when "Themed widgets" were disabled, throwing errors about missing combobox commands. This reply provides closure to the original bug report by Mark Hills' Alpine Linux case, confirming it's already addressed in newer Git versions. The fix appears to properly handle cases where themed widgets are disabled, though the exact mechanism isn't described here. Users experiencing this issue should upgrade to Git 2.50.0 or later.
