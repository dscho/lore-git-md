This is a follow-up patch in the series porting Git for Windows' GUI credential helpers to mainline git-gui. The patch simplifies the yes/no dialog implementation by replacing custom Ttk widget code with Tk's built-in `tk_messageBox` function.

Mark Levedahl's contribution addresses Tk 9.0 compatibility while maintaining all existing functionality, including Windows-specific icon handling. The change reduces the script from 35 to 7 lines of active code while preserving the same user experience. Johannes Schindelin acknowledges the patch and plans to keep it separate from Heiko Voigt's original implementation to properly credit both contributors.

The patch appears well-considered, maintaining all key behaviors (exit codes, icon handling, title customization) while significantly simplifying the implementation. It follows naturally from the previous work in the series and doesn't introduce any new functionality or controversy.
