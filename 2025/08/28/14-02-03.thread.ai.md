Bug report for gitk's Tk widget theming interaction. The thread documents a regression where disabling "Themed widgets" in gitk preferences causes subsequent launches to fail when creating combobox widgets in the preferences dialog. The issue is reproducible on Alpine Linux 3.22 with Git 2.49.1 and Tcl/Tk 8.6.16, with a clear stack trace showing failure in `prefspage_general` procedure during combobox initialization. The bug suggests gitk incorrectly assumes themed widgets (particularly comboboxes) will always be available, even when theming is explicitly disabled. Key technical details include the failing `::combobox` widget creation command, likely in gitk.tcl, with the error triggered by the interaction between gitk's UI and Tk's theming system. The report provides complete version information and reproduction steps, making it actionable for gitk maintainers.
