Bug report and fix for gitk's Tk widget theming interaction, with version context. The thread documents a regression where disabling "Themed widgets" in gitk preferences causes subsequent launches to fail when creating combobox widgets in the preferences dialog, reproducible on Alpine Linux 3.22 with Git 2.49.1 and Tcl/Tk 8.6.16. Johannes Sixt identifies the specific commits that introduced and fixed the issue: introduced in Git 2.48.0 (commit 904b36b815ff) and fixed in Git 2.50.0 (commit daa364cfb7a1). The bug occurred when gitk incorrectly assumed themed widgets (particularly comboboxes) would always be available, even when theming was explicitly disabled, with the `::combobox` widget creation command in gitk.tcl failing in the `prefspage_general` procedure. The thread provides complete version information, reproduction steps, and now the corrective version context, making it fully actionable for users to determine if they're running an affected version and need to upgrade. The response confirms the bug report's accuracy while efficiently pointing to both problematic and corrective commits, closing the loop on this regression.
