This is a test patch in a series changing Git's default branch name from "master" to "main". Phillip Wood updates t0018-advice.sh to use "main" instead of "trunk" as the test branch name, since the tests verify that advice messages include the current branch name.

The patch is straightforward, changing four occurrences of "trunk" to "main" in test expectations. However, it sparks a discussion about whether to keep the GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME infrastructure. Junio Hamano argues for keeping it to allow future branch name changes, while Phillip suggests removing it since the variable was meant as transitional and maintaining it long-term adds boilerplate.

This is part of a larger 6-patch series implementing the default branch name change behind a WITH_BREAKING_CHANGES flag. While the technical changes are uncontroversial, there's ongoing discussion about the long-term test infrastructure implications. The patch itself is simple and correct, but the thread reveals differing views on how future-proof the solution should be.
