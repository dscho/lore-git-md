This is a feature patch series for git-gui, porting long-standing Git for Windows functionality to the mainline project. The patches add GUI-based helpers for password prompts (GIT_ASKPASS) and yes/no questions (GIT_ASK_YESNO), with specific attention to Windows compatibility.

The series comes from code that's been in Git for Windows since 2010, now being upstreamed after previous attempts through GitHub PRs didn't succeed. Johannes Schindelin has rebased the patches and made several improvements since v1, including better window title handling, removal of redundant functions, and adding Git for Windows' icon support.

Key changes include:
1. A new `git-gui--askyesno` script for interactive yes/no prompts
2. Automatic setting of GIT_ASKPASS to use git-gui's helper when unset
3. Customizable window titles for the prompt dialog
4. Windows-specific icon support for better visual integration

The implementation looks clean and focused, with clear commit messages explaining each change. This appears to be a straightforward quality-of-life improvement for git-gui users, particularly on Windows where graphical prompts are more expected. The long history in Git for Windows suggests the code is well-tested in practice.
