This is the first patch in a 4-part series porting Windows-specific GUI credential/prompt helpers to mainline git-gui. The patch implements a new Tcl/Tk script `git-gui--askyesno` that provides interactive yes/no dialogs through the `GIT_ASK_YESNO` environment variable.

The new helper is specifically designed to support Windows file operations that may fail when files are in use, allowing users to retry failed unlink/rename/rmdir operations. The implementation includes standard Tk elements (frame, label, buttons) with Enter/Escape key bindings for quick responses, and follows git-gui's existing credential helper patterns. The script gets installed alongside git-gui's other helpers and is automatically set as the default `GIT_ASK_YESNO` handler when git-gui starts.

Key technical details:
- New executable `git-gui--askyesno` (42-line Tcl/Tk script)
- Added to Makefile install/uninstall targets
- Sets `GIT_ASK_YESNO` in `git-gui.sh` startup
- Uses Ttk widgets when available (Tk 8.5+)
- Fixed-width dialog with centered text and standard Yes/No buttons
- Returns exit code 0 for Yes, 1 for No
- Basic error handling for missing arguments

The patch originates from Git for Windows and has been rebased to current master, with sign-offs from both the original author and Johannes Schindelin. This appears to be a well-contained addition focused on improving the Windows GUI experience while maintaining compatibility with existing git-gui infrastructure.
