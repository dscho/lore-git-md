This is a follow-up discussion about the Meson documentation CI patch, pointing out an inefficiency in the implementation. SZEDER Gábor notes that while the goal is to test documentation builds, the current Meson commands are unnecessarily compiling the entire Git binary as well, as shown in the CI logs. This makes the test slower than needed since it's doing extra work that isn't relevant to the documentation generation.

The original patch (from Patrick Steinhardt) added Meson documentation build testing to catch doc breakages like the one fixed in 87eccc3a81d, but this response identifies a practical issue with the implementation. The CI job currently builds both documentation and the full Git executable when only the former is required. This observation suggests the patch could be optimized to focus solely on documentation generation, which would require modifying the Meson build commands to avoid the unnecessary compilation steps.

The exchange shows the patch is being actively reviewed for both correctness and efficiency, with this being a straightforward optimization opportunity rather than a fundamental flaw in the approach.
