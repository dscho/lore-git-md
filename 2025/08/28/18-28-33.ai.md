CI/build system follow-up addressing Meson documentation test efficiency. SZEDER Gábor points out that the newly added Meson documentation build tests in the CI pipeline are unnecessarily compiling the entire codebase when they should only be building documentation. The CI logs show the `meson compile` step processing over 1300 targets including core C compilation, when the job's purpose is solely to verify documentation generation (HTML and manpages). This observation comes as a reply to Patrick Steinhardt's initial patch that added Meson doc building to catch issues like the one fixed in 87eccc3a81d. The core issue lies in the Meson build system's behavior where `-Ddocs=html,man` still triggers full compilation rather than being documentation-only. This inefficiency could significantly impact CI runtime for what should be a lightweight documentation verification step. The thread context shows this is a refinement of an already-accepted CI improvement, now surfacing an optimization opportunity in the Meson build configuration.
