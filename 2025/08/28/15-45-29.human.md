This is a documentation patch discussion in the ongoing thread about improving the `git-checkout` man page. Junio C Hamano responds to Julia Evans' defense of using "switch to branch" terminology in the patch series.

Junio questions whether simply stating "switch to branch" is sufficiently explanatory for new users who encounter this terminology in error messages but don't understand what it means. He suggests the original "To prepare for working on" phrasing might better serve as introductory explanation for these users.

Julia had argued that "switch to branch" is the established terminology used throughout Git's documentation and error messages (citing the common "Please commit your changes..." message as evidence). The exchange highlights the tension between using consistent terminology versus providing explanatory language for newcomers.

This continues the thread's theme of balancing technical precision with approachability in documentation. The discussion remains constructive, with Junio and Julia exploring different perspectives on how to best serve readers at various levels of Git familiarity.
