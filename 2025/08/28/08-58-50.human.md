This is the final patch in a series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The patch adds Windows-specific icon handling to the `git-gui--askyesno` dialog, using Git for Windows' logo when available.

The change locates the `git-for-windows.ico` file by walking up from the script's installation path, then applies it as the window icon if found. This gives Git for Windows users a more polished, branded experience while remaining a no-op on other platforms. The implementation is straightforward - 12 lines of Tcl code wrapped in a Windows platform check.

As with the rest of the series, this comes from proven Git for Windows code now being upstreamed, with sign-offs from both the original author and the rebaser. The patch completes the visual integration started in earlier patches, maintaining the series' focus on improving the Windows GUI experience without disrupting other platforms. The changes appear well-contained and follow established patterns in git-gui's credential helper infrastructure.
