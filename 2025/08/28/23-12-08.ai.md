This is a fixup patch in the test hardening series for documentation verification in t0450. Patrick Steinhardt provides the missing implementation details for the previous patch that introduced an allowlist mechanism for builtins with intentionally absent documentation.

1. Reverses the grep condition to properly set test prereqs in the else branch
2. Adds the missing `adoc-missing` allowlist file containing 9 builtins that are intentionally undocumented (e.g., `checkout--worker`, `submodule--helper`)
