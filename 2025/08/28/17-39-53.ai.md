This is a bugfix patch in the multi-pack-index (midx) series, addressing error handling in incremental midx writes. The patch focuses on ensuring cleanup occurs properly when failures happen during incremental midx operations.

The change replaces direct `return -1` statements with proper error handling that sets the result variable and jumps to cleanup, preventing potential memory leaks when operations fail. The affected scenarios include temporary file creation, permission adjustments, chain file operations, and final file renaming - all critical points in the incremental midx writing process.

Derrick Stolee notes these error conditions are difficult to reproduce in tests, which explains why the memory issues weren't caught earlier. The changes maintain the same failure semantics but ensure proper resource cleanup.
