This is part 2 of a 4-patch series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The series implements GIT_ASKPASS and GIT_ASK_YESNO functionality with Windows-specific enhancements.

This patch makes git-gui set GIT_ASKPASS to use the git-gui--askpass helper by default when the environment variable isn't already set. It follows the same pattern as the previous patch that set GIT_ASK_YESNO, and mirrors the existing logic for SSH_ASKPASS. The change is straightforward - just 3-line addition to git-gui.sh that checks for the environment variable and sets it to use the git-gui helper if unset.

The implementation is clean and consistent with the existing code, using the same gitexec helper that other parts of git-gui use to locate installed binaries. This continues the series' work of improving the GUI credential/prompt experience, particularly for Windows users where graphical dialogs are more user-friendly than terminal prompts. The patch has been rebased from its original Git for Windows implementation and carries sign-offs from both the original author and the porter.
