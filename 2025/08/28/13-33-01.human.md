This is a bugfix and compatibility patch for git-gui's yes/no dialog functionality. Mark Levedahl proposes replacing a custom Tk 8.5 dialog implementation with the standard `tk_messageBox` widget, which works across Tk 8.5+ including the upcoming Tk 9.0. The change simplifies the code significantly (28 lines removed, 7 added) while maintaining the same functionality.

The patch is part of the ongoing effort to port Git for Windows' credential helpers to mainline git-gui, though it stands alone as a general improvement. The existing implementation was using Tk 8.5-specific constructs that would break under Tk 9.0, while the new version uses a more standard approach that's compatible with both versions. The Windows-specific icon handling is preserved but adapted to work with the new dialog type.
