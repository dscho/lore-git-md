CI/build system patch review feedback. Johannes Schindelin raises a concern about Patrick Steinhardt's rootless GitHub Actions container jobs patch (v4 03/10 in the CI modernization series). While the patch was previously reviewed and approved by Christian Couder, Schindelin identifies a practical issue: when tests fail, the current implementation prevents proper debugging because the non-root 'builder' user lacks permissions to write test logs and artifacts.

The key problem occurs in the failure path - the 'builder' user cannot access GitHub Actions' temporary directories, causing test logs to be lost and preventing artifact uploads. Schindelin suggests this might require adding the user to a specific group with write permissions, but notes he can't investigate further himself. This is a significant functional concern for a patch that was otherwise considered ready, as it doesn't affect passing tests but critically impacts debugging when tests fail.

The feedback comes late in the review cycle (after Christian Couder's approval) and suggests the rootless execution approach may need additional adjustments to maintain full debugging capabilities. This could potentially require another revision of the series despite previous approvals.
