This is the third patch in a 4-part series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The patch adds a `--title` option to `git-gui--askyesno`, allowing callers to customize the dialog window title rather than using the default "Question?".

The implementation adds 10 lines to handle the new option while maintaining backward compatibility. When `--title <custom text>` is passed, it sets the window title before displaying the dialog; otherwise it falls back to the original behavior. The change is motivated by Git for Windows' auto-updater, which wants to present more context-specific titles when asking users about updates.

The patch follows the same pattern as previous ones in the series, with clean Tcl/Tk implementation and clear commit message explaining both the what and why. As with the rest of the series, this appears to be a straightforward enhancement building on established git-gui patterns, now being upstreamed from Git for Windows where it's already proven useful. The change is small (11-line diff) and focused, touching only the askyesno script's title handling while leaving its core dialog behavior unchanged.
