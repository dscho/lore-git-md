This thread documents a bug in gitk where disabling "Themed widgets" in preferences would cause subsequent launches to fail when creating combobox widgets in the preferences dialog. The issue was reported on Alpine Linux 3.22 with Git 2.49.1 and Tcl/Tk 8.6.16, with a clear stack trace showing the failure during combobox initialization in `prefspage_general`.

Johannes Sixt, the gitk maintainer, has now identified the specific commits involved: the regression was introduced in Git 2.48.0 (commit 904b36b815ff) and fixed in Git 2.50.0 (commit daa364cfb7a1). This version information helps users determine whether they're running an affected version and need to upgrade. The response confirms the bug report's accuracy while efficiently pointing to both the problematic and corrective commits, effectively closing the loop on this issue.
