This is a performance optimization patch for sparse index handling in `git ls-files`, now queued for inclusion after review. The patch builds on previous sparse index infrastructure to avoid unnecessary full index expansions when processing pathspecs that match sparse directories. 

The key change moves `ensure_full_index()` inside the iteration loop, triggering expansion only when encountering a sparse directory that matches the pathspec, rather than doing full expansion upfront. This optimization was initially targeted at `ls-files` but has since been shown to benefit real-world `git mergetool` workflows where pathspec-triggered index expansion was causing slowdowns.
