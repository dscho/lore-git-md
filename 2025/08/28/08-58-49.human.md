This is the third patch in a series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The patch adds a `--title` option to the `git-gui--askyesno` script, allowing callers to customize the dialog window title rather than using the default "Question?".

The change is motivated by Git for Windows' auto-updater, which wants to use this helper but needs more descriptive window titles. The implementation adds straightforward Tcl code to parse a `--title` option if present, falling back to the original default. The patch maintains the script's existing behavior while adding this customization point.

As with the rest of the series, this comes from Git for Windows' existing code and has been rebased for mainline. The change is small (11 lines added/modified) and focused, following the established pattern of the credential helper scripts. Since this builds on the uncontroversial foundation of the first two patches and provides clear utility, it seems likely to be accepted.
