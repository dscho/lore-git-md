This is the second patch in a 4-part series porting Git for Windows' GUI credential/prompt helpers to mainline git-gui. The patch focuses on the GIT_ASKPASS integration.

The change modifies git-gui.sh to set GIT_ASKPASS to `git-gui--askpass` when the environment variable isn't already defined, following the same pattern as the SSH_ASKPASS and GIT_ASK_YESNO variables that were already present. The implementation uses `gitexec` to locate the helper rather than a direct path, which differs slightly from how SSH_ASKPASS is handled but matches Git's standard helper location mechanism.

Key technical details:
- The change is minimal (3 lines added) and follows existing patterns
- Uses `gitexec` resolution rather than direct path like SSH_ASKPASS
- Part of making git-gui's credential/prompt helpers the automatic defaults
- Maintains backward compatibility by only setting if unset
- Follows the series' pattern of Windows-originated GUI enhancements

This continues the series' work of standardizing the GUI credential/prompt handling between Git for Windows and mainline Git, with the remaining patches still to come for title customization and Windows-specific icon handling. The change is straightforward and unlikely to be controversial given it follows existing patterns.
