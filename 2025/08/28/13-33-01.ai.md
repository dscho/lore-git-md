This is a bugfix and compatibility patch for git-gui's yes/no dialog functionality. It addresses an issue where the current implementation using Tk 8.5 constructs breaks under Tk 9.0.

The patch simplifies the custom dialog implementation by replacing it with Tk's built-in `tk_messageBox` widget, which is supported across Tk 8.5+. The change reduces the script from 35 lines to just 7 lines of core logic while maintaining all functionality. Key technical changes include:

- Removal of custom frame/layout code in favor of `tk_messageBox`
- Preservation of Windows-specific icon handling (now passed via `-icon`)
- Maintenance of the same exit code behavior (0 for Yes, 1 for No)
- Addition of standard dialog font styling via `option add`

This appears to be a straightforward improvement that increases compatibility while reducing maintenance burden. The patch is well-contained and maintains all existing functionality, including the Windows-specific icon support from the original series. The change is backwards-compatible with Tk 8.5+ and fixes the Tk 9.0 compatibility issue mentioned in the commit message.
