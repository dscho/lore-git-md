Event logistics update for the Git Contributor's Summit 2024. Taylor Blau corrects the registration process announced earlier - the "git-20-25" access code is now deprecated. Instead, contributors should email Taylor directly for a special code that provides free access to both the Contributor's Summit and main Git Merge conference. Those who already paid for the main conference can request refunds by emailing Taylor as well.

This follows up on the previous announcement about the September 30th summit at GitHub HQ in San Francisco. The change appears to be standardizing the free access policy used in past years, though the email doesn't explicitly state why the original Eventbrite approach was abandoned. The correction is timely, coming just over a month before the event while still allowing sufficient time for registration adjustments.
