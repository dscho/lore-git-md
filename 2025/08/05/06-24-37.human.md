This is a test case addition that documents a bug in Git's push behavior. The patch adds a failing test that demonstrates how pushing a non-existent object ID (like all-zeros) to an unqualified branch name triggers an internal BUG() assertion rather than providing a proper error message.

The test creates a minimal repository setup and attempts to push an invalid OID (test_oid 001) to a branch called "branch". Currently this crashes Git, producing both an error message about needing to fully qualify the refname and a BUG() assertion about the invalid object ID. The test is marked as test_expect_failure to document the known-broken behavior.

This is part of a two-patch series where the second patch will replace the BUG() with proper error handling. The test provides a clear reproduction case that will be flipped to test_expect_success once the fix is applied. The test is narrowly focused on this specific edge case without unnecessary setup.
