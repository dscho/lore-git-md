This is a test patch in a bugfix series addressing edge cases in merge-ort's rename detection. It documents two bugs related to rename-to-self scenarios during directory renames.

The patch adds detailed documentation and test assertions for two test cases (12n and 12n2) that expose incorrect behavior when directory renames cause files to be renamed to themselves. The first case shows a path conflict that isn't properly represented in the index, while the second reveals a silent failure to delete a file when directory renames are enabled. Both test cases are marked as expecting failure for now, with fixes planned in subsequent patches.

The test improvements include:
- Adding English descriptions matching the style of other tests in t6423
- Checking the exact number of index entries after merges
- Creating a new test case (12n2) to cover directory-rename-enabled scenarios
- Using test_grep instead of grep for better error messages

This is patch 3/6 in the series, building on earlier fixes for directory rename edge cases. The patch shows careful attention to test coverage and documentation, with clear explanations of the expected vs. actual behavior. The thorough test additions will help verify the fixes in the following patches.
