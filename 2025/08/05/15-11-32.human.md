This is a documentation and code reorganization patch in Patrick Steinhardt's reflog migration infrastructure work (v5 2/9). It reorders the `git reflog` subcommands for better logical grouping, moving read-only commands (`show`, `list`, `exists`) before write operations (`delete`, `drop`, `expire`). The patch also relocates the `expire` subcommand to the end to prepare for adding a new `write` command in a future change.

The changes are mechanical but improve the command's structure by:
1. Grouping related operations together in both documentation and code
2. Placing destructive operations after inspection commands
3. Moving the broadest-scope operation (`expire`) to the end
4. Maintaining all existing functionality while just reordering elements

This appears to be a straightforward preparatory change that doesn't modify behavior, just organization. It's part of a larger series that's already been through several iterations and is now in its final form.
