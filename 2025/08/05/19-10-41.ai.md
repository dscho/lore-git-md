This is the second patch in a 6-part documentation series introducing automated linting tools for Git's man pages. The patch adds `lint-delimited-sections.perl`, a new linter that enforces proper formatting of AsciiDoc delimited sections (blocks marked with `---` or `...`).

The linter checks three key issues: (1) ensuring delimited sections are preceded by empty lines to prevent accidental title generation in translations, (2) verifying section underlines match the length of their titles, and (3) confirming sections are properly terminated within the same file. The implementation is a 48-line Perl script integrated into the build system via `Documentation/Makefile` and `shared.mak`.

The patch includes mechanical fixes to 12 documentation files (mostly adding empty lines before delimited sections), with the most notable changes being in `git-rebase.adoc`, `gitprotocol-http.adoc`, and `gitsubmodules.adoc` where section underlines were adjusted. The linter follows the same pattern as the series' first patch (`lint-gitlink.perl`), with similar build system integration and quiet output handling.

This continues the series' systematic approach to documentation quality control, addressing a subtle formatting issue that particularly impacts translated documentation where visual inspection of rendered output is less common. The changes are purely mechanical and align with the project's documentation standards.
