This thread announces the start of the translation effort for Git 2.51.0, coordinated by Jiang Xin, the Chinese (zh_CN) translation maintainer. The email provides detailed instructions for contributors updating their language translations, noting there are 58 new messages to translate since the last release. 

The workflow has been streamlined - the `po/git.pot` template file is now generated on demand rather than stored in the repository. Contributors should use `make po-update` to refresh their translation files, translate the new strings, and submit pull requests to the git-l10n/git-po repository by August 16, 2025. The email offers guidance on handling file location comments in `.po` files, suggesting either keeping filenames or removing all location metadata using `msgcat`. The git-po-helper CI pipeline will validate pull requests against l10n conventions.

This is a routine part of Git's release process, following the established localization workflow. The email is primarily coordinating the volunteer translation work rather than proposing technical changes to the infrastructure itself.
