Documentation patch (part of Patrick Steinhardt's reflog migration series). This is the first patch in a 9-part series that updates the `git-reflog` documentation to use the new synopsis typesetting format introduced in commit 974cdca345c. The change is purely formatting - replacing `[verse]` with `[synopsis]` and removing single quotes from command names - with no behavioral impact.

Jean-Noël Avila notes this change may conflict with their pending documentation linting series, which enforces stricter rules about synopsis formatting (requiring backticks for definitions lists when using the synopsis type). This appears to be a minor documentation style issue rather than a technical concern, and the patch itself is straightforward and correctly implemented as part of the larger reflog infrastructure work.

The patch maintains all existing functionality while modernizing the documentation format, though it may need adjustment if Jean-Noël's stricter linting rules are adopted. This is a small but useful standardization effort that helps maintain consistency across Git's documentation.
