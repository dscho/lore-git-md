This is a test refactoring patch in the `git refs list` series (v6). It's part of a larger effort to introduce a new `git refs list` command as a thin wrapper around `git for-each-ref`.

The patch refactors the existing `t6300-for-each-ref.sh` test suite to make its logic shareable between `git for-each-ref` and the upcoming `git refs list` command. The core test logic is moved into a new `for-each-ref-tests.sh` file, with the original script becoming a simple driver that sets up the test environment.

Key changes:
- Moves 2141 lines of test code into a new shared test library
- Replaces hardcoded "git for-each-ref" calls with a `$git_for_each_ref` variable
- Follows the same pattern used for sharing tests between `git-blame` and `git-annotate`
- The refactoring maintains all existing test coverage while preparing for new tests to be added for `refs list`
- The patch has been reviewed by multiple mentors (Patrick Steinhardt, shejialuo, Karthik Nayak)
