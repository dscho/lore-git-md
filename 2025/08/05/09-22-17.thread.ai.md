Git for Windows 2.51.0-rc0 release announcement from Johannes Schindelin, tracking upstream Git v2.51.0-rc0. Updates Windows-specific components: Portable Git installers now use 7-Zip 25.00, includes cURL v8.15.0, and MSYS2 runtime based on Cygwin v3.6.4. Provides SHA-256 checksums for all distribution formats (64-bit/ARM64 installers, portable versions, MinGit variants including BusyBox-based). Standard release candidate process for community testing before final release. No new Windows-specific features mentioned - primarily keeping dependencies current with upstream Git.
