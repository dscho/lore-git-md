This is the final patch in the `git last-modified` series, adding Bloom filter optimization to the new command. The patch completes the feature by significantly improving performance when Bloom filters are available, avoiding unnecessary diff computations when the filters can definitively show a path was unchanged.

The implementation checks Bloom filters before computing diffs, only falling back to full diff computation when the filter indicates a path might have changed. Performance tests show dramatic improvements - a 50% speedup for top-level queries and 36% for subdirectory queries. The recursive case sees minimal impact since it inherently requires examining more commits.

The patch follows the project's established patterns for memory management and includes proper cleanup of Bloom filter resources. It builds on Taylor Blau's earlier Bloom filter work while integrating cleanly with the existing `last-modified` implementation.
