Refactoring patch adding a generic directory traversal helper function.

This patch from Derrick Stolee introduces a new `for_each_file_in_dir()` helper function in `dir.c` that recursively visits every file within a directory. The implementation builds on existing infrastructure like `readdir_skip_dot_and_dotdot()` and handles both regular files (DT_REG) and subdirectories (DT_DIR) through a callback pattern. The function takes a strbuf path, a callback function pointer, and optional data, returning early if the callback returns non-zero. This provides a more general alternative to `remove_dir_recursively()` and `fill_directory()` for cases where neither of those fits the need.

The patch is part of the larger sparse-checkout clean series, where this helper will be used for verbose output of file operations. The implementation is straightforward and well-contained, adding 28 lines to dir.c and 14 to dir.h for the new API. Elijah Newren's brief response indicates the change looks reasonable, suggesting it meets the immediate need while being generally useful for future directory traversal cases. The helper maintains Git's existing directory handling patterns while providing a cleaner interface than direct opendir/readdir usage.
