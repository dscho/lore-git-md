Documentation patch introducing a linter for `linkgit:` macro formatting in man pages. This is the first of a 6-part series that adds automated checks for documentation consistency.

The patch adds a Perl script (`lint-gitlink.perl`) that verifies proper use of `linkgit:` macros when referencing other Git commands in documentation. It catches cases where command references should use `linkgit:` but don't, or where the macro is malformed. As an example fix, it corrects a reference to `git-daemon[1]` in `gitweb.conf.adoc` to use the proper `linkgit:` macro format.

The linter checks for several common issues: missing `linkgit:` prefixes, incorrect command spellings, and proper section numbering. The implementation is straightforward Perl pattern matching that reports errors with line numbers. This establishes the first of several automated documentation checks in the series, focusing specifically on cross-references between man pages.

The change is mechanical and uncontroversial, fixing a real issue reported by documentation readers while establishing infrastructure for future consistency checks. It follows the pattern seen throughout this series of small, focused linters that each address one specific documentation formatting concern.
