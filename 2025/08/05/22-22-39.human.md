Refactoring patch adding a directory traversal helper function. This is part of Derrick Stolee's series to improve `git sparse-checkout clean` functionality, specifically enabling verbose output by providing a way to list all files in a directory.

The patch introduces `for_each_file_in_dir()`, a generic helper that recursively visits every file in a directory (including subdirectories) and applies a callback function to each one. The implementation handles regular files and directories while skipping "." and ".." entries. The callback can stop iteration by returning non-zero.

This helper will be used in the next patch to implement verbose output for `sparse-checkout clean`, showing which files would be removed. The implementation is straightforward and builds on existing directory handling code in dir.c. While simple, it provides a useful primitive that could have applications beyond just the sparse-checkout use case.

The patch appears well-contained - it adds the new function with documentation but doesn't yet modify any callers. This follows the Git project's typical pattern of introducing infrastructure changes before their consumers. The implementation looks correct and the interface is clean, though we'll see how it gets used in the following patches.
