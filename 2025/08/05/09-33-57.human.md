Performance test addition for the completed `git last-modified` feature. This is the second patch in the final v7 series that's ready for merging.

Toon Claes adds a performance test script for the new `git last-modified` command, which tracks path modifications through history. The test measures three scenarios: basic top-level operation, recursive traversal, and subdirectory operation. The tests use the standard perf-lib.sh framework to detect performance regressions between Git versions.

The implementation is straightforward, building on Jeff King's earlier work, and complements the existing correctness tests in t8020-last-modified.sh. The test cases cover the command's core functionality - basic operation, recursive mode (-r), and path-specific operation - which should catch any significant performance regressions in the future.

This patch follows the series' high standard of thoroughness, adding performance measurement to the already comprehensive test coverage. With this addition, the feature appears fully baked - tested for both correctness and performance.
