This is the second patch in a 6-part documentation series introducing automated linting tools for Git's man pages. The patch adds a new linter (`lint-delimited-sections.perl`) that enforces proper formatting of AsciiDoc delimited sections (blocks marked with `---` or `...`).

The linter checks three things: (1) that delimited sections are preceded by empty lines (to prevent accidental title generation in translations), (2) that section underlines match the title length, and (3) that sections are properly terminated. The patch includes fixes for several documentation files where these rules weren't being followed, like adding missing empty lines before code blocks in `git-fast-import.adoc` and `git-p4.adoc`, and fixing an underline length in `git-rebase.adoc`.

The changes are mechanical but important for maintaining documentation consistency, especially for translated versions where visual inspection of the output is harder. The linter is integrated into the build system alongside the other documentation checks introduced in this series.
