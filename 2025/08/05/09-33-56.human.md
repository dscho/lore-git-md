Feature implementation for the new `git last-modified` command. This is the first patch in the v7 series that introduces the core functionality, which has now completed its development cycle and is ready for merging.

The patch adds a new subcommand that shows the most recent modification to paths in a tree, similar to `git blame` but operating at the tree level. It works by expanding the tree at a given commit, noting each path's current state, then walking backwards through history to find when each path last changed to its final state. The implementation handles both files and directories, with options to control recursion (`-r/--recursive`) and tree entry display (`-t/--show-trees`).

The command is marked as EXPERIMENTAL in its documentation, though the implementation appears thorough with comprehensive test coverage (210 lines of tests covering various scenarios including merges, subdirectories, and edge cases). The patch includes contributions from Jeff King and Ævar Arnfjörð Bjarmason, suggesting it has benefited from significant review during its development.
