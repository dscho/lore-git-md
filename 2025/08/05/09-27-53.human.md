Documentation refactoring patch for the `git refs list` series. This is the first of six patches in v6 of the series, which introduces a new `git refs list` command as a thin wrapper around `git for-each-ref`.

The patch factors out the common options documentation from `git-for-each-ref.adoc` into a new shared file `for-each-ref-options.adoc`, using Asciidoc's include mechanism. This is a pure refactoring with no functional changes - the rendered documentation remains identical. The change prepares for sharing these option descriptions with the upcoming `git refs list` command's documentation.

The patch includes all existing options from `for-each-ref`, including the recently added `--start-after` option. It's part of a well-structured series that has gone through multiple iterations and appears ready for merging, with comprehensive test coverage and maintainer approval on the design decisions. The author is a GSoC participant working under mentorship from Patrick Steinhardt and others.
