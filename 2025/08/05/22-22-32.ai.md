This is a feature enhancement to the `git sparse-checkout clean` command, adding a `--verbose` option to show individual files that would be removed rather than just directories. The patch builds on previous work integrating the clean command with sparse index functionality and conflict resolution.

- New `list_every_file_in_dir()` helper function in `builtin/sparse-checkout.c` that recursively traverses directories
- `list_file_iterator()` callback for printing each file path with the appropriate message ("Would remove" or "Removing")
- Updated option parsing to include `--verbose` alongside existing `--dry-run` and `--force` flags
- Test updates showing verbose output for nested directory structures
