Documentation patch addressing potential future lint conflicts in the reflog migration series. Junio Hamano applies a fixup to Patrick Steinhardt's initial documentation conversion patch (v5 1/9) that changes option descriptions in `git-reflog.adoc` from `--option` to `` `--option` `` format. This anticipates Jean-Noël Avila's stricter doc lint series which enforces backtick-wrapped synopses in definition lists. The changes affect all option descriptions in the "Options for `drop`" and "Options for `expire`" sections, including flags like `--all`, `--single-worktree`, `--expire=<time>`, and their variants. While the original patch already converted the main synopsis format from `[verse]` to `[synopsis]`, this follow-up ensures compatibility with pending lint rules that would otherwise reject the un-backticked option names in definition lists. The fix maintains the series' documentation standardization goal while avoiding future merge conflicts with Avila's work. No functional changes - purely formatting adjustments to satisfy stricter syntax checking that may be introduced later.
