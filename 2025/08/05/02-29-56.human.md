This is a localization (l10n) workflow announcement for Git 2.51.0. Jiang Xin, the l10n coordinator, is kicking off the translation effort for the upcoming release, noting there are 58 updated messages needing translation since the last release.

The email provides detailed instructions for contributors on how to update their language's `.po` file, including pulling latest changes from Git's master branch and using `make po-update` to sync translations. It emphasizes two approaches for cleaning up file location comments in `.po` files (either keeping filenames or removing all locations) to reduce repository noise.

The message outlines the pull request process to the git-l10n/git-po repository and mentions the git-po-helper CI tool that validates translations. Contributors are given a deadline of August 16, 2025 to submit their updates. This is a routine but well-structured call for participation in Git's localization efforts, following the project's established translation workflow.
