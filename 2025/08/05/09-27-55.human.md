Refactoring patch for the `git refs list` series. This is the third patch in a 6-part series that introduces a new `git refs list` command as a thin wrapper around `git for-each-ref`. The patch extracts the core logic from `cmd_for_each_ref()` into a new shared helper function `for_each_ref_core()` and moves common definitions to a new `for-each-ref.h` header.

The refactoring enables code reuse for the upcoming `git refs list` command while maintaining all existing functionality. The patch:
1. Creates a new header file with the shared `COMMON_USAGE_FOR_EACH_REF` macro and `for_each_ref_core()` declaration
2. Moves option parsing, filtering and formatting logic into the new helper function
3. Reduces `cmd_for_each_ref()` to a thin wrapper that calls the shared helper

This appears to be a clean architectural change that follows the series' goal of consolidating ref listing functionality. The implementation looks thorough, with proper error handling preserved and all existing tests passing. The patch has been reviewed by multiple mentors and is part of a GSoC project that has gone through several iterations of review.
