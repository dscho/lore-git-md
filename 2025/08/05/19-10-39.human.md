This is a documentation patch series that has already been integrated into Git's main branch. The 6-part series introduces automated linting tools to enforce consistent formatting across Git's man pages, building on recent documentation standardization efforts.

Jean-Noël Avila's work adds three new Perl linters that check for specific documentation patterns: proper `linkgit:` macro usage, correct AsciiDoc section formatting, and definition list syntax. The series also include fixes for 115 documentation files to comply with these new checks, with particularly extensive updates to `git-for-each-ref.adoc` (132 lines changed) and numerous command option documentation files.

The changes are now queued by Junio C Hamano after review confirmed they align with Git's documentation guidelines. The series was uncontroversial and focused purely on tooling improvements rather than content changes. While it initially conflicted with two other in-flight topics (the refs list subcommand and reflog migration work), those were identified and addressed earlier in the review process.

This completes a systematic approach to documentation consistency that complements Avila's parallel synopsis conversion work, establishing automated checks that will help maintain quality for future contributions. The changes affect only documentation and build infrastructure, with no impact on Git's runtime behavior.
