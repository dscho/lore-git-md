Bugfix for zip archive generation when deflating large files in `git archive`. The thread addresses an issue where creating zip archives could fail with "deflate error (0)" when processing certain large files, particularly when `core.bigFileThreshold=1` forces more files to use the streaming deflate path. Justin Tobler's patch restructures the deflation into a do-while loop that continues until Z_STREAM_END is received, moving compressed output writing inside the loop to handle partial results while maintaining existing CRC and size accounting.
