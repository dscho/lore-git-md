This is a documentation patch that's part of Patrick Steinhardt's v5 reflog migration infrastructure series. It addresses a formatting issue in the git-reflog(1) man page that was flagged by Jean-Noël Avila regarding backtick usage in option descriptions.

The patch absorbs Junio Hamano's follow-up fix that ensures the documentation complies with upcoming stricter linting rules for man pages. The change converts option descriptions to use backticks (like `` `--option` ``) in the "Options for `drop`" and "Options for `expire`" sections, preemptively resolving a potential issue with Avila's pending documentation lint series.

While this is primarily a documentation formatting change, it's notable as part of the larger reftable migration effort since it ensures the reflog documentation will pass future automated checks. The patch has already been reviewed and the technical approach endorsed by multiple contributors, with Junio Hamano providing the final formatting tweak.
