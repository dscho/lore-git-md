Bugfix patch implementing the dry-run approach for consistent diff output with ignore options (-w, -I<regex>). This is the third iteration of the solution to make metadata outputs (--raw, --name-status, --name-only) respect content-ignoring options when blobs compare equal under ignore criteria.

The patch introduces a new `diff_optimize` field in `struct diff_options` with `DIFF_OPT_DRY_RUN` mode, which skips full diff generation when checking for changes. A helper function `diff_flush_patch_quiet()` performs this quick check by setting the dry-run mode temporarily. The implementation replaces the previous `/dev/null` redirection approach with this more direct method.

Key technical changes:
- Adds `quick_consume()` callback that simply notes changes without processing output
- Modifies `builtin_diff()` to skip context when in dry-run mode
- Updates `diff_flush()` to use the new quiet check for metadata outputs
- Includes test cases verifying the fix works with `--raw`, `--name-only`, and `--name-status`
- Documents the xdiff early-return trick in xdiff-interface.h

The solution aligns with the thread's technical direction, implementing Junio's preferred `DIFF_FORMAT_DRYRUN` approach while dropping the more complex buffering optimizations. Jeff King has signed off on the patch, indicating consensus on the implementation approach. The changes focus specifically on the core issue while maintaining existing performance characteristics for normal diff operations.
