This is the final version (v8) of a feature series introducing a new `git repo info` command for querying repository metadata, part of Lucas Seiki Oshiro's GSoC project. The series has been through multiple rounds of review and is now in its final polishing stage.

The v8 iteration addresses several minor issues from v7:
- Fixes CI test failures related to ref format assumptions
- Corrects documentation/usage string alignment
- Adds missing test output comparisons
- Improves strbuf management with separate buffers for quoted/unquoted values
- Standardizes test formatting to use backslash continuations
- Documents the escaping behavior in keyvalue format output

Key technical changes in this version:
- Adds proper handling of the `--format` flag with both keyvalue and nul-terminated output options
- Implements repository layout fields (bare/shallow) with proper test coverage
- Uses proper quoting for keyvalue format while keeping nul format unquoted
- Includes comprehensive test suite covering all functionality

The implementation looks solid with thorough test coverage and has received positive feedback from mentors. Patrick Steinhardt indicates the series is nearly ready for inclusion, pending these final nits being addressed. The changeset is well-contained (5 patches touching 11 files) and follows Git's established patterns for new subcommands.

This represents the culmination of a multi-month effort to create a robust repository introspection tool, with all major technical aspects now resolved. The final version shows good attention to detail in both implementation and documentation.
