This is part of the ongoing `the_repository` removal effort in the commit-graph subsystem (patch 8/10 in the series). The patch systematically removes direct usage of `the_hash_algo` global variable across commit-graph operations, replacing it with repository-specific hash algorithms obtained either through context parameters or explicitly via `the_repository->hash_algo` where necessary (with those cases marked for future removal).

Key technical changes include modifying `open_commit_graph_chain()` to take a hash algorithm parameter, updating chunk size calculations to use repository-specific algorithms, and ensuring hash writes use the correct algorithm from their context. The changes touch core commit-graph operations like parsing, verification, and writing, with modifications to both the commit-graph API (adding the hash_algo parameter) and its implementation.

The patch follows the pattern established earlier in the series, maintaining behavior while removing global state dependencies. It builds on previous conversions of macros to functions (patch 5/10) and hash storage refactoring (patch 6/10). The changes are mechanical but important for the series' goal of enabling pluggable object storage backends. All modifications are straightforward replacements with no new logic, keeping risk low while advancing the architectural cleanup.
