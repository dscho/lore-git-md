This is the second patch in an 8-part series introducing the new `git repo info` command, which moves repository metadata functionality from `git rev-parse` to a more appropriate home. The series is now in its 8th iteration and considered merge-ready by the mentors.

The patch adds support for querying the reference storage format (either "files" or "reftable") via a new `references.format` field in the `git repo info` output. The implementation includes:
- Core functionality to detect and report the ref storage format
- Proper quoting of output values per `core.quotePath` rules
- Lexicographical sorting of output keys
- Comprehensive tests verifying behavior with both files and reftable backends
- Error handling for invalid keys and duplicate requests

The code shows careful attention to detail, including:
- Dual strbuf architecture for clean value handling (raw values vs quoted output)
- Proper memory management
- Test coverage for edge cases
- Documentation updates explaining the new field

This is a well-crafted patch that cleanly implements a focused piece of functionality as part of the larger command migration effort. The implementation addresses all previous feedback and appears ready for inclusion.
