This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem, specifically targeting redundant repository parameter passing. The patch eliminates cases where functions were taking both a repository and object database source parameter when the source already contains a reference to its repository, potentially preventing mismatches.

Key technical changes:
- Removes `struct repository*` parameters from 12 functions in commit-graph.c where the repository could be derived from the object database source
- Updates callers in builtin/commit-graph.c and test helpers to match new signatures
- Maintains special handling for `load_commit_graph_chain_fd_st()` which needs to work across different sources
- Changes progress reporting in verification to use the repository from the graph's ODB source
- Updates function prototypes in commit-graph.h to reflect parameter removals

The changes are mechanical refactoring with no behavior changes, completing the series' goal of eliminating `the_repository` usage in the commit-graph subsystem. All prior patches in the series have been reviewed and approved, with this final patch cleaning up the remaining redundant parameter passing. The patch follows the established pattern from earlier in the series while handling the special chain file loading case appropriately.
