Bugfix for depth calculation in pathspec handling, part of the `--max-depth` diff series.

This patch fixes an edge case in the `within_depth()` function in dir.c where empty paths with non-zero base depth could return incorrect results. The function is used to enforce depth limits during tree traversal, particularly for the new `--max-depth` feature being added to diff operations. While the current callers (notably `cmd_grep()`) aren't affected because they always pass base depth 0, the fix ensures correct behavior for future users like `git-diff-tree` with `--max-depth`.
