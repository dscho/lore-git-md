This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem, part of the ongoing `the_repository` removal effort. The patch eliminates redundant repository parameters from commit-graph functions where the repository can be derived from the object database source parameter that's already being passed. This cleanup ensures we don't have mismatched repository/source pairs while simplifying the function signatures.

The changes are mechanical but thorough, touching core commit-graph operations like loading, parsing, and verification. The exception is `load_commit_graph_chain_fd_st()`, which still needs explicit repository access since commit-graph chains can span multiple object databases. The patch includes test updates and maintains all existing functionality while making the code more consistent.

As the culmination of a well-reviewed series that has already addressed all technical feedback, this patch appears ready for merging. It completes the commit-graph subsystem's transition away from global state, a key milestone for the broader pluggable storage backend effort.
