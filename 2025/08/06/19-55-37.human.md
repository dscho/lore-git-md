This is the final patch in an 8-part series introducing the new `git repo info` command, which migrates repository metadata functionality from `git rev-parse`. The patch adds a `--format` flag to control output formatting, completing the command's interface.

The patch introduces two output formats: `keyvalue` (default, human-readable with C-style quoting) and `nul` (machine-readable with null-terminated values). The implementation follows the pattern used by `git config`, with careful handling of quoting and delimiters. The documentation includes clear examples of both formats in use.

The changes are well-tested, with new test cases verifying both formats work correctly with all supported keys (reference format, bare status, and shallow status). Error handling for invalid formats is also tested. The implementation appears clean, using an enum for format types and separate code paths for each output style.

This patch represents the final piece of a well-executed GSoC project that has undergone thorough review from multiple Git maintainers. The series' quality is high, with all previous feedback addressed, and it's now ready for merging. The new command provides a more logical home for repository metadata queries than `git rev-parse`.
