Feature implementation introducing a new `git repo` command hierarchy, specifically the `info` subcommand. This is the foundational patch (1/5) in the v8 series that establishes the new command structure to eventually migrate repository metadata functionality from `git rev-parse`.

The patch adds all the boilerplate needed for a new Git command:
- Creates `builtin/repo.c` with basic subcommand handling (currently just a stub `info` implementation)
- Adds documentation in `git-repo.adoc` marking the command as experimental
- Updates build systems (Makefile, meson) and command lists
- Includes `.gitignore` entry

Key technical details for future reference:
- Command structure: `git repo info [<key>...]` will retrieve repository metadata
- Currently empty implementation that will be filled in subsequent patches
- Documentation warns this is experimental and behavior may change
- Files touched span build systems, documentation, and core plumbing
- Follows standard Git command boilerplate patterns

This is part of a larger effort to clean up `git rev-parse` by moving repository metadata functionality to a more appropriately named command. The series has undergone extensive review (v8) with all technical concerns addressed, and this initial patch establishes the scaffolding for the new command hierarchy.
