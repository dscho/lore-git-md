This is a bugfix for `git rebase -i`'s handling of merge commits. The patch addresses an oversight where the interactive rebase's 'drop' command would hit an internal BUG() when given a merge commit, even though dropping a merge commit is a reasonable operation (unlike other commands like 'squash' or 'fixup' which need to be prohibited for merges).

The change is straightforward - it adds 'TODO_DROP' to the list of commands that are explicitly permitted to operate on merge commits in sequencer.c, alongside the existing 'TODO_MERGE' case. A test is added to verify this works as expected. The fix builds on previous work from May 2024 that improved error messages for other merge commit cases.
