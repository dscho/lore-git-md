Feature implementation in the `git repo info` command series. This is patch 3/5 in the v8 series that introduces repository metadata querying functionality.

The patch adds a new `layout.bare` field to the experimental `git repo info` command, which reports whether the current repository is bare (returning "true" or "false"). This functionality was previously only available via `git rev-parse --is-bare-repository`, and its migration to the new command hierarchy is part of the effort to clean up `git rev-parse`.

The implementation is straightforward, using Git's existing `is_bare_repository()` function. The patch includes comprehensive tests that verify the behavior in both bare and non-bare repositories, as well as in combination with other fields. Documentation is updated to reflect the new field.
