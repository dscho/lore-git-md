This is a bugfix patch in Patrick Steinhardt's reflog migration infrastructure series, addressing an issue with invalid old object IDs during reflog format conversion. The patch introduces a new `REF_LOG_USE_PROVIDED_OIDS` flag to ensure backends use the caller-provided OIDs rather than incorrectly resolving them to all-zeroes when migrating reflogs between storage backends.

The fix ensures proper old/new OID preservation during reflog migration, which was previously causing migrated entries to lose their old object IDs. The patch includes test updates that now verify both old and new OIDs in reflog entries, closing a previous testing gap. The changes affect both files and reftable backends, with consistent validation logic added to each.
