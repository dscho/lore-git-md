This is a documentation patch in the merge-ort rename detection series, specifically addressing string interning behavior. The patch clarifies how path strings are managed in merge-ort's internal data structures to enable efficient pointer comparisons rather than string comparisons.

The patch updates comments in merge-ort.c to more accurately describe that the string interning optimization applies to all paths (both files and directories), not just directories as the original comment suggested. It also adds a reference to a concrete example in apply_directory_rename_modifications() where the code properly handles path string reuse to maintain the pointer comparison optimization.

Key technical details:
- Corrects and expands documentation about the path string interning in merge_options_internal->path strmap
- Maintains the optimization where paths are compared via pointers rather than strcmp()
- References a specific code location demonstrating proper handling of interned strings
- Part of the larger series fixing directory rename edge cases in merge-ort
- Builds on commit history from 2020-2021 when merge-ort's string interning was first implemented

The change is purely documentation - no functional changes to the string interning behavior itself. This patch helps future developers understand and correctly work with the path string optimization while maintaining the performance benefits.
