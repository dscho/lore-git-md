This is the final version (v8) of a feature series introducing a new `git repo info` command for retrieving repository metadata. The series has been through extensive review and is now in its final polishing stage, with all major technical aspects addressed.

The command provides structured access to repository information through key-value pairs, with fields for reference storage type (`references.format`), repository layout (`layout.bare` and `layout.shallow`), and output formatting options (`--format=keyvalue|nul`). The implementation includes thorough test coverage and documentation.

Key changes in v8 address final review feedback:
- Fixed CI test assumptions about default ref format
- Corrected documentation/usage string mismatch in t0450
- Added missing test output comparisons
- Improved strbuf management with separate buffers for quoted/unquoted values
- Standardized test style with backslash continuations
- Documented value escaping in keyvalue format

The implementation now uses two strbufs (one for raw values, one for quoted output) and properly handles both keyvalue (quoted, newline-delimited) and nul (unquoted, null-terminated) output formats. Test cases have been reorganized to verify both formats consistently.

Patrick Steinhardt has confirmed the series is merge-ready pending these minor fixes. The changes are well-contained to the new command implementation, touching only its documentation, builtin source, and test files. The command remains marked as experimental in the documentation.
