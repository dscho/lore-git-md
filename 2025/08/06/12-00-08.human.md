This is part 3/10 of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, continuing the `the_repository` removal effort. The patch fixes type inconsistencies in commit-graph write options.

The change converts the "max-commits" and "size-multiple" options from signed to unsigned integers, as they are documented to be positive values. This resolves sign comparison warnings in `split_graph_merge_strategy()` where these values were being compared with commit counts. The patch updates both the option parsing (using the newer `OPT_UNSIGNED()` macro) and the underlying storage types.

This is a straightforward technical cleanup that aligns with the series' broader goal of type consistency. The change is small (7 lines net) and focused, touching only the commit-graph implementation and its command-line interface. As with other patches in this well-reviewed series, it maintains backward compatibility while improving internal consistency.
