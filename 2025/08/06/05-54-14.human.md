This is a refactoring patch from Patrick Steinhardt's reflog migration infrastructure series (v6). It exports the previously internal `ref_transaction_update_reflog()` function to make it available for other parts of the codebase that need to write reflog entries. 

The patch simplifies the function by removing the `flags` parameter since all current callers use the same set of flags (REF_HAVE_OLD, REF_HAVE_NEW, etc.), which are now hardcoded in the function. The documentation is moved to refs.h and slightly improved to clarify the behavior when the index parameter is zero.

This change is part of the larger effort to improve reflog handling during the files-to-reftable migration, with this particular patch preparing for new functionality that will need to write reflog entries. The implementation looks straightforward and maintains the existing behavior while making the function more widely accessible.
