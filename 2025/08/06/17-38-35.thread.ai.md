Thread summary:

Bugfix for interactive rebase's handling of merge commits when using the 'drop' command. Follows up on commit 4c063c82e9 which added error messages for merge commits with incompatible sequencer commands but missed the drop case. The patch adds TODO_DROP to check_merge_commit_insn() in sequencer.c alongside TODO_MERGE, allowing merge commits to be dropped without triggering BUG(). Test case added to t/t3404-rebase-interactive.sh verifies dropping merge commits no longer produces errors. Changes are minimal and focused, touching only sequencer.c and the test file. The commit message could be more explicit about the rationale for allowing merge commit drops, though the test provides clear verification of the fixed behavior.
