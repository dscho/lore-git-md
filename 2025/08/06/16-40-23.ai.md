Refactoring patch in Patrick Steinhardt's MIDX/ODB integration series, with feedback from Toon Claes.

This email contains Toon Claes' response to patch 3/8 in Patrick Steinhardt's series refactoring MIDX handling to use ODB sources. The patch modifies ODB source creation functions to return newly created sources rather than just adding them to the alternates list. Toon suggests a potential optimization in `odb_add_to_alternates_memory()` where `real_pathdup()` could be avoided by passing "/" as the relative base and using the existing path from `odb->sources->path` directly. He notes this might make the code slightly less readable but would eliminate a path duplication operation.

The change is part of the larger effort to eliminate redundant information between MIDX and ODB structures. This particular patch prepares for future changes that will need access to the newly created source pointers. The feedback focuses on implementation details rather than the overall approach, suggesting the series is progressing well with only minor optimizations being considered. The thread context shows this is one of several mechanical refactoring steps to consolidate MIDX operations through ODB sources.
