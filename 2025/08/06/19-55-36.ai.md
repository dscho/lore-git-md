This is the fourth patch in the v8 series implementing the new `git repo info` command, adding support for querying shallow repository status. The patch migrates the functionality from `git rev-parse --is-shallow-repository` to the new `git repo info layout.shallow` field.

The implementation follows the established pattern from previous patches in the series, adding a new field handler that returns "true" or "false" based on `is_repository_shallow()`. The patch includes the new field in the documentation alongside the existing fields, and adds comprehensive tests verifying both shallow and non-shallow repository detection. The test cases create both a normal repository and a shallow clone to validate the behavior.

The change is straightforward and well-contained, touching only the expected files: documentation, command implementation, and tests. The implementation uses the same dual-strbuf architecture established earlier in the series for consistent value handling. Multiple experienced contributors have reviewed and helped with the patch, as evidenced by the Helped-by tags from Phillip Wood, Junio Hamano, Justin Tobler, and Eric Sunshine.

This completes the migration of repository metadata queries from `git rev-parse` to the new command hierarchy, with all three originally planned fields (references.format, layout.bare, and now layout.shallow) now implemented. The patch maintains the series' high quality standards with clean code, thorough testing, and proper integration with the existing command structure.
