This is patch 9/10 in Patrick Steinhardt's series removing `the_repository` global state from the commit-graph subsystem, part of the broader `the_repository` removal effort. The patch systematically eliminates remaining uses of `the_repository` in commit-graph.c, completing the transition to repository-specific contexts.

Key technical changes:
- Removes the `USE_THE_REPOSITORY_VARIABLE` macro entirely
- Modifies `git_test_write_commit_graph_or_die()` to take an `odb_source` parameter instead of using `the_repository`
- Updates hash algorithm usage throughout to use repository-specific instances rather than the global `the_hash_algo`
- Refactors progress reporting to use repository contexts from callers
- Adjusts file handling (tempfiles, locks) to use repository-specific paths and permissions
- Updates hash computations and verifications to use repository-specific algorithms

The changes are mechanical replacements maintaining existing behavior while removing the last global dependencies. The patch follows the pattern established earlier in the series, with particular attention to hash algorithm handling and progress reporting. All modifications are consistent with the series' goal of enabling pluggable object storage backends by eliminating global state.

This patch represents the bulk of the remaining `the_repository` cleanup for the commit-graph subsystem after the foundational work in earlier patches. It touches core commit-graph operations including writing, verification, and traversal, but the changes are straightforward substitutions rather than logic alterations. The series has already received positive review feedback and appears ready for merging.
