This is part of the ongoing documentation standardization effort, specifically the third patch in a 6-part series introducing automated linting for Git's man pages. The patch adds a new Perl linter (`lint-documentation-style.perl`) that enforces proper formatting of definition lists in documentation, requiring multiple terms in a single entry (like `-a, --all::`) to be split into separate entries with correct spacing.

The 24-line Perl script checks for and corrects definition list formatting issues, with accompanying fixes applied to 4 documentation files: `git-check-attr.adoc`, `git-check-ignore.adoc`, `git-http-fetch.adoc`, and `api-path-walk.adoc`. The changes integrate with the build system via updates to `Documentation/Makefile` and `shared.mak`.
