Feature implementation introducing a new `git repo` command hierarchy. This is the first patch in an 8-part series (v8) that creates the basic scaffolding for a new `git repo info` subcommand, which will eventually house repository metadata functionality currently scattered in `git rev-parse`.

The patch adds all the boilerplate needed for a new Git command:
- Documentation stub marking it as experimental
- Build system changes (Makefile, meson.build)
- Basic command structure with an empty `info` subcommand implementation
- Entry in command-list.txt as a "plumbing interrogator"

The commit message explains the motivation - `rev-parse` has accumulated many repository-inspection features that don't relate to revision parsing. This new command hierarchy provides a more logical home for such functionality. The implementation appears clean and well-structured, with multiple mentors and contributors having reviewed the approach.

As the first patch in a mature series (now at v8), it focuses on establishing the command framework while leaving the actual metadata functionality to subsequent patches. The thread context indicates this series is considered merge-ready by the mentors.
