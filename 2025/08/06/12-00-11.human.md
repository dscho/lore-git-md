Refactoring patch in the `the_repository` removal series. This is patch 6/10 in Patrick Steinhardt's v2 series to eliminate global state from the commit-graph subsystem.

The patch changes how the commit-graph stores hash algorithm information - instead of keeping just the hash length (which was previously taken from the global `the_hash_algo`), it now stores a pointer to the full hash algorithm structure. This is a preparatory change that will allow subsequent patches to work with the hash algorithm directly rather than just its length.

The change is mechanical but widespread, touching 36 lines across commit-graph.c to replace `hash_len` with `hash_algo->rawsz` in various calculations and lookups. The commit-graph.h header is also updated to change the struct field type. The patch maintains all existing behavior while moving toward the series' goal of removing global state dependencies.

This continues the pattern seen in earlier patches of the series, where global state is replaced with explicit parameter passing. The change is straightforward and well-contained, with no apparent behavioral impact. Reviewers have already approved the overall approach in previous discussion, and this patch fits cleanly into that established pattern.
