This is a preparatory patch for the `the_repository` removal effort, adding unsigned integer support to Git's tracing infrastructure. 

Patrick Steinhardt introduces `trace2_data_uintmax()` to complement the existing `trace2_data_intmax()` function, filling a gap in the Trace2 API's ability to log unsigned values. The implementation follows the same pattern as the signed version, formatting the value as a string before passing it to the underlying string tracing function.

The change is straightforward - adding parallel functions in both trace2.c (implementation) and trace2.h (interface). The patch notes this will be used in a later commit in the series, though it doesn't specify which one. As the first patch in a 10-part series working towards removing global state from the commit-graph subsystem, this appears to be laying groundwork for tracing unsigned values that will be introduced by later refactoring.

The implementation looks clean and follows existing patterns, though as a standalone change it's fairly minor. Its real significance will become apparent when we see how it's used in subsequent patches of the series.
