This is a v2 patch series in the ongoing `the_repository` removal effort, focusing on eliminating global state dependencies in the commit-graph subsystem. Patrick Steinhardt's 10-patch series builds on previous review feedback to further decouple the commit-graph code from global variables while maintaining compatibility with the object database layer.

The series makes several key changes from v1 based on reviewer input: switching from `size_t` to `unsigned` for Bloom filter counts, using `uint32_t` for commit graph counts to match existing usage, and refactoring `parse_commit_graph()` to take a full repository parameter instead of separate settings/hash_algo parameters. These changes address concerns raised by Taylor Blau and Junio Hamano about type safety and API design.

The patches have already received positive feedback from key reviewers - Derrick Stolee has given an explicit approval and Taylor Blau has acked several patches. The series appears technically sound and ready for merging, representing both progress on removing global state and foundational work for future pluggable object database support. The changes are well-motivated and carefully implemented, with test coverage ensuring no behavior regressions.
