This is a documentation patch updating instructions for using Thunderbird with Git patches. Johannes Sixt updates the recommended Thunderbird add-on for preventing line-wrapping in patch emails, changing from the obsolete "Toggle Word Wrap" to the current "Toggle Line Wrap" extension.

The patch notes several improvements in the new add-on: it adds a toolbar button rather than a menu entry, can detect patch text and warn about unwrapped lines, and includes bonus features. It also properly documents that some about:config tweaks are needed for full functionality, which wasn't mentioned for the old add-on.

The change is straightforward and well-justified, keeping the documentation current with available tools. The patch maintains the existing structure while adding useful new details about the add-on's capabilities and configuration requirements. This appears to be a clear improvement to the contributor experience when using Thunderbird with Git.
