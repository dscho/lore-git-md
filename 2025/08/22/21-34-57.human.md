This is the first patch in a v3 series refactoring Git's bulk-checkin subsystem as part of the `the_repository` removal effort. It introduces a new `struct odb_transaction` to consolidate several global variables that currently manage transaction state in bulk-checkin.c.

The patch groups together three previously separate globals - a nesting counter, temporary object directory, and packfile state - into a single structured container. This is a preparatory step for later changes that will wire this structure through the API rather than relying on global state. The actual behavior remains unchanged in this commit.

The changes are mechanical but thorough, touching all the bulk-checkin operations that previously accessed these globals directly. The patch appears well-tested and maintains the existing functionality while setting up for the architectural improvements to come in subsequent patches. This is a clean foundational change that reviewers have already approved in previous iterations of the series.
