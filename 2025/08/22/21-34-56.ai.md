This is a refactoring patch series (v3) in the ongoing `the_repository` removal effort, focusing on eliminating global transaction state in Git's bulk-checkin subsystem. The series moves transaction state into `struct object_database` and tightens transaction handling requirements.

Key technical changes in this version:
- Combines `index_blob_bulk_checkin()` with `deflate_blob_bulk_checkin()` earlier in the series (patch 3) for better logical grouping
- Continues using `repo_get_object_directory()` instead of open-coded path access
- Makes transaction parameter mandatory in `index_blob_bulk_checkin()`
- Updates callers in builtin commands (add, unpack-objects, update-index) to handle transactions properly
- Accesses repository state consistently through the transaction's `object_database`

The implementation enforces stricter transaction requirements while maintaining behavior, with two remaining globals (`pack_compression_level` and `pack_size_limit_cfg`) still needing `USE_THE_REPOSITORY_VARIABLE`. The changes span multiple files with significant line modifications (152+/- in bulk-checkin.c alone).

This version addresses previous feedback by reorganizing patches and improving commit messages. The series appears well-tested with callers updated to handle the new transaction requirements. It represents another step toward the long-term goal of moving transaction interfaces to odb.h and supporting pluggable ODB backends.
