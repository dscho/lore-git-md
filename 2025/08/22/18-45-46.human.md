This is a documentation patch in an ongoing discussion about Git's "My First Contribution" guide. Elijah Newren weighs in on Daniele Sassoli's patch that clarifies which GitHub remotes (git/git vs gitgitgadget/git) can be used when submitting contributions.

Newren generally supports the patch's goal of clarifying that PRs can be opened against either remote, noting this is helpful since GitHub's UI sometimes changes the target unexpectedly. However, he suggests removing the parts that tie remote selection to where the repository was cloned from, as these are unrelated. He also proposes removing or rewording the explanation about opening PRs from forks when using git/git as a remote, since the remote URL doesn't actually determine where PRs must be opened.

The email maintains a constructive tone while offering specific technical corrections. Newren particularly likes the inclusion of a link explaining the differences between the two remotes, which helps users make informed choices. This continues the thread's discussion about balancing simplicity for first-time contributors with accurate technical information, though Newren focuses more on technical correctness than the workflow philosophy debate between Daniele and Junio.
