This is part 2/4 of a refactoring series to remove global state from Git's bulk-checkin subsystem as part of the `the_repository` removal effort. The patch moves transaction state management from global variables into `struct object_database`, making it instance-specific rather than process-wide.

Key technical changes:
- Introduces `struct odb_transaction` pointer parameter to all bulk-checkin functions that previously relied on implicit global state
- Stores transaction state in `object_database->transaction` rather than static variables
- Updates all callers (add, unpack-objects, update-index, cache-tree) to pass transaction objects
- Makes `index_blob_bulk_checkin()` require explicit transaction parameter (no more implicit single-object transactions)
- Adds transaction parameter to fsync/prepare functions for loose object handling
- Maintains identical behavior while enforcing stricter transaction requirements

The changes span multiple files with significant line modifications, particularly in bulk-checkin.c where the core transaction logic is centralized.
