This is the first patch in a 4 series refactoring Git's bulk-checkin subsystem as part of the `the_repository` removal effort. It introduces a new `struct odb_transaction` to consolidate previously scattered global state variables into a single structure. The patch combines three previously independent globals (`odb_transaction_nesting`, `bulk_fsync_objdir`, and `bulk_checkin_packfile`) into one organized structure, making the transaction state management more explicit and self-contained.

The changes are mechanical but important for the transaction state tracking. All existing functionality remains identical - the patch just reorganizes how the state is stored. The transaction counter, temporary object directory, and packfile state are now grouped together in the new structure. This sets up for future patches that will make this structure non-global and pass it explicitly through the bulk-checkin interfaces.

Key technical details:
- New `struct odb_transaction` contains `nesting` counter, `objdir` pointer, and `packfile` state
- All existing functions updated to reference fields through the new `transaction` global
- Behavior remains unchanged - this is purely an internal reorganization
- Prepares for later patches that will remove the global entirely
- The patch touches only bulk-checkin.c with 24 lines added and 22 removed
- Follow-up patches will build on this to pass the transaction structure explicitly rather than using a global

This represents the first step in a larger effort to make the bulk-checkin subsystem properly handle transactions and remove its dependency on `the_repository`. The change is straightforward and well-contained, with all existing callers continuing to work exactly as before while the internal representation improves.
