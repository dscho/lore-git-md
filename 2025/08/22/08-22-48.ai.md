This is a feature patch adding hostname-based conditional includes to Git's configuration system. The change allows users to include configuration files based on the machine's hostname, similar to existing `gitdir` and `onbranch` conditions.

The implementation adds a new `include_by_hostname()` function that compares the system's hostname (obtained via `gethostname()`) against the condition specified in the config. The syntax follows the existing pattern: `[includeIf "hostname:my-machine"]`. The patch includes basic error handling for the `gethostname()` call and uses a `strbuf` for safe string comparison.

The change touches `config.c`, modifying the `include_condition_is_true()` function to handle the new condition type. The implementation appears straightforward and follows existing patterns in the file, though the indentation in the modified function is slightly inconsistent (some lines are misaligned and there are extra blank lines).

This would be useful for users who want different configurations (like email addresses or credential helpers) on different machines without maintaining separate branches or manually changing configs. The commit message clearly explains the motivation and provides example usage.
