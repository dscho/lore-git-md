Feature patch adding hostname-based conditional config includes.

This patch introduces a new "hostname:" condition for Git's includeIf mechanism, allowing users to include configuration files based on their machine's hostname. The implementation uses gethostname(2) to check against user-specified hostnames in config files, with straightforward matching logic.

The change is cleanly implemented with proper error handling for the gethostname call and memory management via strbuf. The example in the commit message shows the intended use case - having different configs for work and home machines without needing separate branches.

This appears to be a well-motivated addition that follows the existing includeIf pattern while solving a real configuration management need. The patch touches only config.c and maintains the style of surrounding code. The implementation seems robust, though some might question whether hostname matching should support patterns or case insensitivity (the current implementation does exact matching).
