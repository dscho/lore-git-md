This is a refactoring patch in the `the_repository` removal effort, specifically addressing the bulk-checkin subsystem. The patch removes the global `transaction` state from bulk-checkin.c, moving it into `struct object_database` instead. This is part 2 of a 4-patch series that has already been reviewed and is nearing completion.

The key changes include:
- Converting the static `odb_transaction` struct into a proper type stored in `object_database`
- Making `index_blob_bulk_checkin()` handle both transactional and non-transactional cases
- Adding transaction support to `cache-tree.c` operations
- Documenting the transaction state in `odb.h`

Junio Hamano notes that while the transition makes some code temporarily awkward (like needing to create a temporary `bulk_checkin_packfile` in `index_blob_bulk_checkin`), this will be cleaned up in subsequent patches. He also raises a potential future consideration about renaming bulk-checkin.[ch] to better reflect its odb-related functionality, though acknowledges this may not be necessary.

The changes maintain existing behavior while systematically eliminating global state, with all bulk-checkin operations now properly using repository context. The patch appears well-executed and follows through on the design discussed earlier in the thread.
