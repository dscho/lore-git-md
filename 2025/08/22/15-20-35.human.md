This is a documentation patch fixing mismatched single quotes in the `git-interpret-trailers` man page. The patch corrects four instances where closing single quotes were missing in the description of the `--if-exists` and `--if-missing` options.

The issue is straightforward - the documentation had unclosed single quotes around option names like `--no-if-exists` and `--if-missing` in the explanatory text. The patch simply adds the missing closing quotes in each case. The commit includes a demonstration showing the before-and-after state of the affected lines.

This appears to be a simple but worthwhile cleanup. The patch is small, focused, and clearly correct. While not a functional change, it improves documentation accuracy and consistency. The author Kristoffer Haugsbakk has signed off on the patch in standard fashion.
