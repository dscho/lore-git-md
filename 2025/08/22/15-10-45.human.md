Feature: SMTP autoconfiguration for `git send-email` via `--get-smtp-server`

This is the third version of a patch adding automatic SMTP server discovery to `git send-email`. The new `--get-smtp-server` option helps users configure their email settings by automatically detecting the correct SMTP server configuration for a given email address. The patch models its behavior after Thunderbird's autoconfig system.

The feature works through three fallback methods: first checking the email provider's autoconfig URL, then Mozilla's ISPDB database, and finally falling back to MX record resolution for custom domains. Version 3 improves upon previous iterations by reordering the fallback sequence to match Thunderbird's behavior, adding support for another autoconfig URL variant, and including authentication method detection (including OAuth2 support).

The implementation adds several Perl dependencies (Net::DNS, URI::Escape, XML::LibXML) and provides clear output showing the server, port, encryption method, username format, and supported authentication mechanisms. It also warns about unencrypted connections and gives copy-paste ready configuration commands. The documentation has been expanded with a new section explaining how to use the feature.

This appears to be a well-considered addition that solves a real configuration pain point for users. The patch shows good attention to detail with thorough documentation and clear error handling. The discussion thread indicates active collaboration between the authors to refine the implementation.
