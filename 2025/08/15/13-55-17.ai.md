This is the foundational patch for a new `git repo` command hierarchy, part of a GSoC project to migrate repository metadata functionality from `git rev-parse`. The patch establishes the basic command structure with an initial `info` subcommand that will eventually handle repository metadata queries.

The changes create all the necessary plumbing for a new Git command:
- Adds `builtin/repo.c` with basic subcommand handling via `parse_options()`
- Updates build systems (Makefile, meson) and command lists
- Includes initial documentation in `git-repo.adoc` marking the command as experimental
- Sets up the basic `git repo info` subcommand skeleton (currently a no-op)

Key technical details established:
- Command structure: `git repo info [<key>...]`
- Documentation framework with clear experimental warning
- Build system integration across all supported build methods
- Subcommand routing infrastructure using Git's standard option parsing

The patch is part of a larger series (v10 1/8) that has already been approved for merging, with all architectural decisions settled in previous iterations. This initial patch focuses solely on establishing the command framework without implementing any actual metadata query functionality, which comes in subsequent patches. The implementation follows Git's standard patterns for new commands and has been reviewed by multiple mentors and contributors.
