This is a feature patch series (v10) finalizing the new `git repo` command hierarchy, now approved for merging into Git. The series has been through extensive review and addresses all previous feedback, with the key change in this version being the removal of key sorting in favor of preserving input order.

The main technical changes in v10:
- Removes key sorting (`qsort_strcmp`) and duplicate key elimination from `print_fields()`
- Preserves exact input order for requested keys (including duplicates)
- Adds test cases demonstrating ordered output and duplicate handling
- Documents the new output ordering behavior in git-repo.txt
- Includes minor fixes from Eric Sunshine's feedback (test formatting, error message quoting)

The implementation now:
- Returns values in request order rather than sorted lexicographically
- Supports duplicate key requests (useful for scripting contexts)
- Maintains all previously implemented fields (`references.format`, `layout.bare`, `layout.shallow`)
- Keeps both output formats (`keyvalue` and `nul`) with their respective quoting behaviors

Test coverage has been updated to verify:
- Order preservation through explicit test cases
- Duplicate key handling
- Format validation
- All existing field functionality

The series has full consensus from mentors (Karthik Nayak and Patrick Steinhardt) and maintainers (Junio C Hamano), with all previous concerns about test future-proofing and output behavior resolved. This represents the final iteration before merging this GSoC project into Git.
