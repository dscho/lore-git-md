This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem as part of the `the_repository` removal effort. The patch cleans up now-redundant repository parameters that were made unnecessary by the earlier changes in the series.

The key change is eliminating duplicate repository parameters from commit-graph functions where the repository can already be obtained from the object database source parameter. The patch systematically removes these redundant parameters across the commit-graph loading, parsing, and verification code paths. The exception is `load_commit_graph_chain_fd_st()`, which needs to operate at the object database level since commit-graph chains may span multiple repositories.

The changes are mechanical and follow the pattern established in earlier patches of the series. All functions now consistently take their repository context from the object database source rather than having it passed separately. The patch updates call sites accordingly, including the test helper and builtin commands.

This completes the architectural work to make the commit-graph subsystem fully repository-aware with no remaining global state dependencies. The series has been through multiple rounds of review with consensus on the approach, and this final cleanup patch appears straightforward with no new technical concerns raised.
