Platform compatibility patch (9/17 in Rust dependency series) addressing Windows build requirements when Rust becomes mandatory. Johannes Schindelin modifies both CI and build configuration to support GCC-compatible Rust toolchains on Windows, where Git traditionally uses GCC rather than MSVC. The changes:

1. CI script adjustment: Adds `x86_64-pc-windows-gnu` target installation in `ci/install-rust.sh` for Windows CI jobs
2. Build system updates: Extends `config.mak.uname` with `CARGO_BUILD_TARGET` settings for all three Windows architectures (i686, x86_64, aarch64) and introduces `RUST_TARGET_DIR` path construction

This maintains compatibility with the GCC-based Windows builds while enabling Rust compilation, following the series' cross-platform goals.
