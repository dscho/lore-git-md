A concerning bug has been reported regarding branch deletion on case-insensitive filesystems like macOS. Richard Carlsson found that Git incorrectly allows deletion of a branch when given a case-variant name of the current branch (e.g., deleting "Dummy" while on "dummy"). This leaves the user in a broken state where their current branch no longer exists - a potentially dangerous situation that could lead to confusion or data loss.

The behavior differs between platforms: on Linux (case-sensitive), Git properly rejects the deletion as expected, while on macOS it incorrectly proceeds. The report provides clear reproduction steps showing how this filesystem case-sensitivity issue manifests in Git's branch deletion logic. This appears to be a legitimate bug affecting core branch management functionality, particularly concerning for macOS users who may inadvertently delete their working branch through case variation.
