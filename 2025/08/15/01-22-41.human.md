This is a refactoring patch in the ongoing Rust integration series, specifically targeting xdiff internals to prepare for using xxhash. It separates line parsing from hashing in the diff preparation code, which currently does both in `xdl_hash_record()`.

The patch introduces a new `xdl_parse_lines()` function that handles just the line boundaries, while leaving the hashing to be done in a subsequent pass. This makes the code more modular and easier to swap hash implementations (a key goal for the Rust integration). The changes are mechanical - moving code around rather than altering behavior - but they touch core xdiff data structures like `xrecord_t` and `xdfile_t`.

This appears to be well-executed groundwork for the performance improvements promised in the series. The separation of concerns is clean, and the patch maintains all existing functionality while making the code more maintainable. It follows the series' pattern of incremental, verifiable changes to xdiff internals before introducing Rust code.
