This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem, part of the ongoing `the_repository` removal effort. The patch cleans up redundant repository arguments that are now unnecessary since the previous patches made all commit-graph operations properly repository-aware. Many functions were taking both a repository parameter and an object database source parameter, when the source already contains a reference to its repository. The changes are mechanical removals of these now-redundant parameters.

The one exception is `load_commit_graph_chain_fd_st()`, which needs to operate at the object database level rather than source level since commit-graph chains can reference graphs from different sources. The patch maintains this special case while simplifying everything else. 

The changes are minimal and focused - just removing parameters that are no longer needed after the architectural work in earlier patches. The series has seen multiple rounds of review with consensus on the approach, and this final cleanup patch appears straightforward and low-risk. With this change, the commit-graph subsystem is fully transitioned away from global state dependencies.
