Performance optimization and refactoring patch in the Rust xdiff series, specifically addressing whitespace handling. This is patch 14/17 in the ongoing effort to make Rust a hard dependency with xdiff optimizations.

The patch introduces a new `WhitespaceIter` Rust struct that consolidates whitespace iteration logic previously duplicated in multiple xdiff locations. The iterator handles all whitespace-related flags (`XDF_IGNORE_WHITESPACE`, `XDF_IGNORE_WHITESPACE_CHANGE`, etc.) in a unified way. It includes comprehensive unit tests verifying behavior across all flag combinations and edge cases (CR/LF handling, empty strings, etc.).

A secondary utility function `chunked_iter_equal` is added to compare two iterators of byte slices, with its own test suite covering various chunking scenarios. The implementation appears carefully crafted to match the existing C behavior while leveraging Rust's safety features.

This builds on prior work in the series that showed 5-19% performance improvements from xxhash optimizations, though whitespace handling was identified as a potential bottleneck. The patch doesn't include performance measurements but follows the series' pattern of micro-optimizations through Rust FFI.
