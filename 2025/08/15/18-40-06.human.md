This is a test patch from the final approved version of Lucas Seiki Oshiro's GSoC project to create a new `git repo info` command hierarchy. The patch focuses on testing the `references.format` field implementation, which reports whether a repository uses the "files" or "reftable" backend for references.

Junio C Hamano provides some minor feedback on the test structure, noting that the test helper function is more generic than needed for this specific case and that the error message testing could follow more conventional pattern. However, he indicates these are minor stylistic points that don't block the already-approved series.

The tests verify:
- Correct output for both ref storage formats ("files" and "reftable")
- Error handling for invalid keys
- Partial output when some requested keys are invalid

This patch is part of the larger effort to migrate repository metadata queries from `git rev-parse` to the new `git repo info` command. The series has already been approved for merging into Git's 'next' branch after thorough review from mentors and maintainers.
