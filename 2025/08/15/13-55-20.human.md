This is the fourth patch in a series implementing a new `git repo info` command, adding support for detecting shallow repositories. The patch introduces a new `layout.shallow` field that reports whether the repository is shallow ("true"/"false"), migrating functionality from `git rev-parse --is-shallow-repository`.

The implementation follows the established pattern from previous patches in the series, using the existing is_repository_shallow() function and adding appropriate documentation and tests. The test coverage includes both shallow and non-shallow repository cases, with a clone operation used to create a real shallow repository for testing.

As with the rest of this well-structured series, the patch maintains the design principles of input order preservation and duplicate key support. The implementation has been reviewed and helped by multiple Git contributors, indicating it has gone through thorough review. This appears to be a straightforward addition to the growing set of repository metadata queries available through the new command.
