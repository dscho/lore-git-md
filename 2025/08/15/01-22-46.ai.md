This is a platform compatibility patch in the ongoing Rust integration series, specifically addressing Windows build requirements. The patch ensures successful linking when using the Rust-built xdiff library on Windows by adding the `userenv` system library as a dependency. This is needed because Rust's std::env::home_dir() implementation on Windows calls `GetUserProfileDirectoryW`, which requires linking against `userenv`.

The changes span three files:
1. `.github/workflows/main.yml` gets a new step to ensure `libuserenv.a` is present in the CI environment, downloading it if missing
2. `config.mak.uname` adds `-luserenv` to `EXTLIBS` for Makefile builds
3. `meson.build` adds `userenv` to `libgit_dependencies` for Meson builds

The patch acknowledges this is a new requirement not yet part of the minimal Git for Windows SDK, with plans to include it properly in the future. This follows the series' pattern of addressing platform-specific requirements as they arise during Rust integration, having previously handled GCC-compatible builds and now completing MSVC support. The change is straightforward but necessary for Windows builds to succeed with the Rust xdiff implementation.
