This is the fourth version of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, part of the ongoing `the_repository` removal effort. The series has been refined through several rounds of review, with v4 dropping the integer type conversion patches that were previously a point of discussion.

The series now focuses purely on architectural changes to eliminate global state dependencies. Key changes in v4 include removing the patches that addressed `-Wsign-compare` warnings (1-4 from v3), while keeping the core refactoring work. The remaining 6 patches systematically remove uses of `the_hash_algo` and `the_repository` from commit-graph operations, replacing them with repository-specific alternatives.

Notable technical changes include converting hash algorithm storage from length to full algorithm pointer, refactoring `parse_commit_graph()` to take a repository parameter, and removing redundant repository parameters where the repository can be derived from object database sources. The changes are mechanical but foundational for future work on pluggable object databases.

The series has seen extensive review with approvals from key contributors like Derrick Stolee and Taylor Blau. While earlier versions included discussions about integer type choices (particularly around Bloom filter counters and commit-graph options), those have been resolved by dropping the related patches in v4. The current version appears merge-ready with consensus, focusing solely on the architectural improvements needed to eliminate global state dependencies in the commit-graph subsystem.
