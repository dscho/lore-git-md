Bugfix follow-up to the `git diff --no-index` working directory handling, now simplifying the implementation based on guaranteed NULL prefix conditions.

This patch builds on the previous fix for `--no-index` mode by taking advantage of the now-guaranteed NULL prefix condition to simplify the code. The key changes are:

1. Removal of prefix_filename() calls and associated memory management since prefix is always NULL in this mode
2. Direct string comparison with "-" instead of pointer comparison against file_from_standard_input
3. Added BUG() check to enforce the NULL prefix invariant
4. Cleanup of temporary variables and memory management code that's no longer needed

The changes are focused in diff-no-index.c, with the path handling logic becoming simpler and more direct. The special case for stdin/stdout ("-") handling is preserved but implemented differently. The patch maintains all existing functionality while removing now-unnecessary complexity.
