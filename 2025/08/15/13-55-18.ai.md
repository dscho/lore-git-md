This is the second patch in the v10 series implementing the new `git repo info` command, focusing on adding the `references.format` field. The patch migrates functionality from `git rev-parse --show-ref-format` to the new command hierarchy.

The implementation introduces:
1. A new `get_references_format()` function that retrieves the ref storage format (either "files" or "reftable") from the repository's `ref_storage_format` field
2. A bsearch-based lookup system for field keys in `repo_info_fields`
3. A `print_fields()` helper that handles quoting and output formatting according to `core.quotePath` rules
4. Comprehensive tests in t1900-repo.sh verifying:
   - Correct format detection for both files and reftable backends
   - Error handling for invalid keys
   - Mixed valid/invalid key scenarios

The patch maintains the series' design decisions around output ordering and duplicate key support. Documentation is updated to explain the new field and its possible values. The implementation follows the established pattern from the foundational patch, using the same strbuf-based output system and integrating cleanly with the existing command framework.

This is a straightforward migration of existing functionality into the new command structure, with thorough test coverage and clear documentation. The implementation appears solid and aligns with the series' architectural decisions.
