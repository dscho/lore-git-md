This is part 4/6 of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, specifically targeting the `the_hash_algo` usage. The patch systematically replaces all direct uses of `the_hash_algo` with repository-specific hash algorithms accessed via `r->hash_algo`, continuing the architectural work to make the commit-graph code repository-agnostic.

The changes are mechanical but widespread, touching hash calculations, file size validations, and data structure serialization across commit-graph.c, builtin/commit-graph.c, and commit-graph.h. Key modifications include updating the `open_commit_graph_chain()` interface to accept a hash algorithm parameter, adjusting size checks to use repository-specific hash sizes, and ensuring all hashwrite operations use the correct algorithm's raw size.

The patch maintains compatibility with edge cases like fuzzers by still allowing fallback to `the_repository` when no repository context is available, though these cases are noted as temporary until later patches complete the transition. All callers in builtin/commit-graph.c and test helpers are updated to pass the correct hash algorithm from their repository context.

This represents a foundational change for the ODB abstraction effort, with all major technical discussions from earlier versions resolved. The changes are straightforward replacements that don't introduce new functionality but enable proper repository isolation. The series appears ready for merging with consensus from key reviewers.
