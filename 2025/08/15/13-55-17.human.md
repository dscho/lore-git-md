This is the first patch in a series introducing a new `git repo` command hierarchy, part of a GSoC project to migrate repository metadata functionality out of `git rev-parse`. The patch establishes the basic scaffolding for the new command, including:

1. A new `builtin/repo.c` implementing the command framework with an initial `info` subcommand (currently just a stub)
2. Documentation in `git-repo.adoc` describing the experimental nature of the command and its purpose for retrieving repository metadata
3. Build system updates across Makefile, meson.build, and command-list.txt to integrate the new command

The commit explains that `git rev-parse` has accumulated many features unrelated to revision parsing over time, and this new command hierarchy will provide a more appropriate home for repository metadata operations. The initial implementation is minimal but establishes the foundation that subsequent patches will build upon to migrate specific functionality from `rev-parse`.

The patch has received multiple Helped-by and Mentored-by tags, indicating it's part of a well-supported GSoC project with oversight from experienced contributors. As the first in the series, it focuses on the basic plumbing needed before adding actual functionality in later patches.
