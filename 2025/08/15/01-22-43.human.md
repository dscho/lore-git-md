CI/build system patch adding Rust support to GitHub workflows. This is part 8/17 of Ezekiel Newren's series introducing Rust as a hard dependency with xdiff optimizations.

The patch adds Rust installation to CI workflows through a new `build_rust.sh` script that handles both Makefile and meson builds. Key changes include:

- Adding Rust installation in CI via new `install-rust.sh` script
- Creating `build_rust.sh` to centralize Rust compilation between build systems
- Modifying Makefile to depend on Rust compilation for all targets
- Updating meson.build to use the shared build script
- Adding curl as a dependency for rustup installation

The changes are infrastructure-focused, ensuring the Rust components can be built in CI environments. The patch addresses meson limitations by moving the built library to the root build directory. It follows the series' pattern of incremental changes while maintaining compatibility with existing build systems.

This is a technical but necessary step in the larger Rust integration effort, showing careful attention to cross-platform build system requirements. The approach of sharing build logic between Makefile and meson via a script is particularly notable.
