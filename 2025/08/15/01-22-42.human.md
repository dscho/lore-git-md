Performance optimization patch in the Rust xdiff integration series (7/17). This patch conditionally uses Rust's xxhash implementation for faster hashing when no whitespace flags are present, falling back to the existing DJB2a algorithm otherwise. The change leverages the type alignment work from earlier patches to enable zero-copy interop between C and Rust.

Benchmarks show speedups of 5-19% across different hardware when running `git log --oneline --shortstat` on the Linux kernel history, with the fastest gains seen on mid-range desktop CPUs. The patch adds the xxhash dependency and implements a simple FFI wrapper in Rust that converts C pointers to Rust slices for hashing.

This continues the series' pattern of incremental changes that maintain compatibility while preparing for deeper Rust integration. The performance tradeoff between xxhash's speed and its inability to efficiently handle whitespace flags (requiring fallback to DJB2a) was a key discussion point in earlier thread exchanges. The conditional approach here reflects that compromise.
