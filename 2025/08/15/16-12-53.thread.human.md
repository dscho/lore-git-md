The patch, from an experienced contributor, modifies the command to only expand the index when encountering a sparse directory that matches the pathspec, rather than doing a full expansion upfront. This avoids unnecessary operations when pathspecs match directories already covered by sparse-checkout patterns.

The change is carefully implemented by moving the `ensure_full_index()` call inside the file iteration loop, triggered only when needed.
