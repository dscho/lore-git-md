CI/build system patch consolidating Rust toolchain setup in GitHub Actions workflows. This is part of the larger Rust integration series (patch 12/17) that aims to make Rust a hard dependency for Git.

The patch centralizes Rust version and target platform definitions in the main GitHub Actions workflow file, replacing scattered configurations. Key changes include:
- Defining minimum Rust versions for different platforms (1.61.0 base, 1.78.0 for Windows, 1.72.0 for musl)
- Specifying target triples (x86_64-pc-windows-gnu for Windows, i686-unknown-linux-gnu for 32-bit Linux)
- Switching to actions-rs/toolchain@v1 where possible while maintaining custom install scripts for Docker targets
- Removing now-redundant BITNESS environment variable checks

The changes appear well-motivated by platform-specific quirks - Windows bcrypt library resolution, musl libc compatibility, and 32-bit container detection. The patch maintains backward compatibility while cleaning up the CI configuration. As part of the broader Rust effort, this helps ensure consistent toolchain setup across all CI environments.
