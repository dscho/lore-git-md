This is part of the ongoing `the_repository` removal effort, specifically targeting the commit-graph subsystem. The patch converts two hash-algorithm-dependent macros (`GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE`) into functions that take a `git_hash_algo` parameter, removing their reliance on the global `the_hash_algo` variable.

The changes are mechanical but important for the macros' call sites throughout commit-graph.c, including critical operations like commit graph parsing and validation. The patch maintains all existing functionality while making the hash algorithm dependency explicit. This is the first of six patches in v4 of the series, which has been streamlined to focus solely on architectural improvements after dropping integer type conversion patches from previous versions.

Key technical details:
- Replaces `GRAPH_DATA_WIDTH` macro with `graph_data_width()` function
- Replaces `GRAPH_MIN_SIZE` macro with `graph_min_size()` function
- Updates all call sites to use the new functions
- Still temporarily uses `the_hash_algo` at call sites (to be addressed in later patches)
- Touches core commit-graph operations including parsing, validation, and data access

The patch appears well-contained and follows the established pattern for removing global state dependencies. It's part of a mature series that has already addressed reviewer feedback and appears ready for merging.
