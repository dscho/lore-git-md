This is a CI/build system patch in the Rust integration series (8/17). It adds Rust toolchain installation and build support to Git's CI workflows and build systems (Makefile and meson).

The patch introduces several key components:
- A new `build_rust.sh` script that centralizes Rust compilation between Makefile and meson builds, handling debug/release configurations and library placement
- CI scripts (`install-rust.sh`) to install the Rust toolchain (version specified via `RUST_VERSION=1.87.0`)
- Makefile modifications to add Rust compilation as a dependency for all Git binaries and test tools
- Meson build system updates to integrate Rust compilation via the new script

Notable technical details:
- Uses rustup for toolchain management with version pinning
- Sets Rust compiler flags (`-Aunused_imports -Adead_code`) to suppress warnings in FFI code
- Handles 32-bit vs 64-bit platform detection in CI
- Installs curl as a new dependency for rustup installation
- Places the compiled Rust library (`libxdiff.a`) in the build directory root due to meson constraints

The patch maintains compatibility with existing build systems while adding Rust support, following the series' incremental approach. It addresses platform-specific considerations like Linux's `-ldl` requirement and meson's output file placement limitations. The changes are focused on build infrastructure with no functional impact on Git itself yet.
