Documentation formatting patch in the `git repo info` series.

Junio Hamano provides style suggestions for the documentation of the new `git repo info` command's output format and field descriptions. He recommends two changes to improve consistency with Git's documentation style:

1. Indenting the field descriptions under their keys (like `layout.bare` and `layout.shallow`) to better visually align with how the rendered output will appear. This doesn't change the final rendered docs but improves source readability.

2. Restructuring the format options (`keyvalue` and `nul`) as a nested definition list within the main command documentation, which would make the markup structure clearer while maintaining the same rendered output.

The patch shows the proposed changes to `Documentation/git-repo.adoc`, demonstrating both the indentation adjustments and the nested list restructuring. These are purely documentation style improvements for the already-approved `git repo info` command series, which is currently in the 'next' branch awaiting final merge.
