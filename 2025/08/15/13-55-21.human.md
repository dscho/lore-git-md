This is the final patch in the v10 series introducing the new `git repo info` command, focusing on output format options. The patch adds a `--format` flag to control how repository metadata is displayed, with two supported formats:

1. **keyvalue** (default): Human-readable output with `key=value` pairs, one per line, with special characters quoted (matching `git config` behavior)
2. **nul**: Machine-readable output with null-terminated records, where each key and value are separated by newlines (useful for scripting)

The implementation includes:
- Documentation updates explaining both formats
- Core logic in `builtin/repo.c` to handle format selection and output generation
- Comprehensive tests verifying both formats work correctly
- Error handling for invalid format requests

The patch follows the pattern established by `git config` for dual-format output and completes the command's functionality as planned in the GSoC project. With all architectural decisions confirmed and feedback addressed in previous iterations, this final piece is now ready for integration.
