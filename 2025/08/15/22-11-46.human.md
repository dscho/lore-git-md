This is a discussion about Windows platform compatibility in the context of the Rust xdiff optimization series.

Johannes Schindelin responds to Junio Hamano's comments about Windows version support, clarifying the Git for Windows project's position. He confirms Matthias Aßhauer's earlier statement that using `*-pc-windows-gnu` targets would raise the minimum Windows version requirement from 8.1 to 10, which conflicts with Git for Windows' current support policy. 

Schindelin explains that the Git for Windows team (including himself and Matthias) aims to support older Windows versions as long as it's reasonably possible, even beyond Microsoft's official EOL dates. He references their documented support policy at gitforwindows.org, which currently includes Windows 8.1. The team follows a practice of giving advance notice before dropping support for older versions, as they did previously with Windows 7 and 8.

The email reveals some tension between Junio's view (Git shouldn't support OS versions Microsoft no longer maintains) and the Git for Windows team's practical approach to version support. Schindelin suggests Junio could be more open-minded about the Windows ecosystem's realities, while acknowledging Junio's self-professed lack of Windows expertise.

This discussion is part of the broader Rust integration effort's platform compatibility considerations, where Windows support details remain a point of debate even as the technical implementation nears completion.
