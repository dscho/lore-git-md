This is a documentation patch for the bugreport tool, adding visual clarity to the template questions. 

Kristoffer Haugsbakk proposes adding ">" prefixes to all lines in the bug report template to make it easier to distinguish between the questions (which are now clearly marked) and the user's answers. The change affects both the template in `builtin/bugreport.c` and the corresponding test in `t/t0091-bugreport.sh`.

This is version 2 of the patch, which updates a test that wasn't present when the first version was made, rewrites the commit message to be more concise, and changes the subject from "add" to "use" for better clarity. The original idea came from Felipe Contreras, who is credited with a "Based-on-patch-by" line.

The change is straightforward and improves usability by making the bug report template more visually scannable. The patch appears well-crafted with matching updates to both implementation and tests. This seems like a small but useful improvement to the bug reporting workflow.
