This is a performance optimization patch in the Rust xdiff integration series, introducing conditional use of Rust's xxhash implementation for faster hashing when whitespace flags are not in use.

The patch adds Rust implementation of xxhash via the `xxhash-rust` crate and modifies xdiff's line hashing logic to use it when `XDF_WHITESPACE_FLAGS` are unset, falling back to the existing DJB2a algorithm otherwise. This leverages Rust's optimized xxhash implementation while maintaining compatibility with whitespace-sensitive diff modes where xxhash's contiguous memory requirement would be problematic.

Key technical changes:
- Adds `xxhash-rust` dependency with xxh3 feature
- Implements unsafe FFI function `xxh3_64()` in Rust that wraps the crate's hash function
- Modifies `xdl_prepare_ctx()` to branch between Rust xxhash and C DJB2a based on whitespace flags
- Maintains existing line classification flow after hashing

The benchmarks show 5-19% speedup in `git log --oneline --shortstat` across three different machines, with greater gains on more powerful hardware. The performance improvement comes primarily from xxhash's faster hashing, though the patch maintains the series' zero-copy interop approach through aligned types (`u8`, `usize`).

This continues the series' pattern of incremental, verifiable changes - the whitespace flag check provides a clear boundary between optimized and legacy paths. The performance numbers help validate the approach, though Phillip Wood's earlier analysis suggests similar gains could be achieved in pure C with xxhash. The patch doesn't yet address whitespace mode performance, leaving that as future work.
