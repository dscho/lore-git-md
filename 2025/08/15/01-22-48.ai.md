CI/build system patch in the Rust dependency series (13/17), adding Cargo.lock artifact uploads to GitHub Actions workflows. This enables dependency auditing by preserving the exact crate versions used in each CI run, addressing supply chain security concerns raised earlier in the thread. The patch modifies `.github/workflows/main.yml` to upload `rust/Cargo.lock` from four distinct job types: Windows builds, Windows Meson builds, Linux matrix jobs, and static analysis. Each artifact is named contextually (`cargo-lock-windows`, `cargo-lock-$jobname` etc.) to distinguish between environments. 

This follows the thread's consensus to track Cargo.lock for CI while keeping it in `.gitignore` for development. The implementation is straightforward, using GitHub's standard `actions/upload-artifact@v4` step.
