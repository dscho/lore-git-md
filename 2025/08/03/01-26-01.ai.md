This is a feature patch series (now reduced to 3 parts) that expands `-h` and `--help-all` option availability in Git commands. The series builds on previous discussion where patch 4 was dropped due to technical and security concerns.

The current version focuses on:
1. Fixing test infrastructure in the dependent branch (t1517-outside-repo.sh)
2. Refactoring parse-options.c to use `#define` constants instead of an enum for internal flags (USAGE_NORMAL/USAGE_FULL)
3. Modifying builtin command handling to properly support `--help-all` outside repository contexts

Key technical changes include:
- parse-options.c now uses USAGE_NORMAL/USAGE_FULL and USAGE_TO_STDOUT/USAGE_TO_STDERR macros
- git.c and builtin handling adjusted to bypass repository checks for help requests
- Special cases for `ls-remote -h` and `grep -h` are preserved
- The controversial patch allowing `-h` mid-command has been definitively dropped

The series appears well-considered, with the author incorporating feedback from Jeff King and Junio C Hamano. The test fixes and refactoring look solid, though the parse-options.c readability changes (enum vs #define) may still warrant some review attention. The changes are focused and the commit messages clearly indicate no behavior changes in the refactoring parts.
