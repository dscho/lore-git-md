This is part of Junio Hamano's ongoing refactoring series to modernize string processing in Git by converting strbuf_split() usage to the safer string_list API. The patch specifically targets environment.c's namespace handling.

The change converts get_git_namespace() from using strbuf_split() to string_list_split(), which better matches the function's needs since it doesn't require modifying the split strings. The new version splits the namespace path into components, filters out empty entries (handling double slashes), and builds the final path with proper "refs/namespaces/" prefixes.

Key improvements include:
- Eliminates the need for strbuf_list_free() cleanup
- Uses string_list's built-in iteration
- Maintains identical behavior while being more type-safe
- Adds trailing slash trimming for consistency

This follows the series' pattern of replacing manual string buffer management with string_list's safer abstractions. The change is straightforward and well-contained, reducing the code by 5 lines while improving clarity. As with other patches in the series, it demonstrates the API's benefits in simplifying and securing string processing code.
