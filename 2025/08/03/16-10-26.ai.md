Refactoring patch in a series improving Git's help output handling. This is the second of three patches in the final version of the series.

The patch replaces magic numbers in `parse-options.c` with clearly named constants for the flags passed to `usage_with_options_internal()`. The four new `#define` constants are:
- `USAGE_NORMAL` (0) and `USAGE_FULL` (1) for controlling help output verbosity
- `USAGE_TO_STDOUT` (0) and `USAGE_TO_STDERR` (1) for controlling output destination

All call sites are updated to use these new constants, making the code more readable while maintaining identical behavior. The changes affect:
- The `--help-all` handling path
- Standard help output (`-h`)
- Error case usage output
- The special "lone -h" case

This is a pure refactoring with no functional changes, part of the larger effort to improve help output consistency across Git commands. The patch follows the series' established pattern of careful, incremental changes to the option parsing infrastructure.
