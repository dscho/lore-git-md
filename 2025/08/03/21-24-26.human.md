This is a build system patch that fixes CMake compatibility after recent changes to unit test organization. The patch updates the CMake build configuration to match a Makefile change that converted an explicit list of unit test programs to a wildcard-based approach.

The change was necessitated by commit 9bbc981c6f2 which migrated reftable-related tests from shell scripts to C unit tests. The CMake build was failing with errors about missing arguments in string replacement operations because it wasn't updated to handle the new wildcard-based test discovery.

The patch is straightforward - it replaces the Makefile parsing approach with direct globbing of test files in the unit-tests directory, then adjusts the paths appropriately. This appears to be a necessary follow-up to keep the CMake build working after the test reorganization, though the commit message could be clearer about why the Makefile parsing approach no longer suitable.
