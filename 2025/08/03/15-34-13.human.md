Bugfix follow-up discussing testability of zip archive deflation issue. Justin Tobler responds to René Scharfe's review of his patch that fixes a zlib deflation edge case in `git archive`'s zip generation. The original issue occurred when processing large files where zlib stream required multiple passes to reach Z_STREAM_END.

Tobler confirms he can reproduce the issue more easily by artificially shrinking the output buffer, but expresses interest in finding a way to test the fix without code modifications. He acknowledges this might not be feasible. Regarding the implementation approach, he notes he chose the minimal fix (adding a separate deflation loop) rather than merging it with the existing loop, but is open to revise if preferred.

The exchange shows the patch has already received positive feedback from the original code author (Scharfe), with this follow-up mainly addressing testability concerns and implementation details. The technical solution appears sound and the discussion remains constructive, suggesting the patch is nearing readiness for inclusion.
