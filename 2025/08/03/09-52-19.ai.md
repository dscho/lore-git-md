This is a bugfix for the zip archive generation issue when deflating large files. René Scharfe is responding to Justin Tobler's patch that fixes a zlib deflate handling problem in `archive-zip.c`.

The key technical point is that the original code incorrectly assumed `git_deflate()` with Z_FINISH would always return Z_STREAM_END in one pass, but zlib's documentation specifies it may need multiple calls when the output buffer is too small. Justin's patch restructures this into a proper do-while loop that continues until Z_STREAM_END is received.
