- `append_one()` helper handles the string copying/placement differences
- Type-safety constraints force keeping the wrappers separate despite shared logic
- BUG() checks enforce correct strdup_strings usage for each variant
- Maintains identical behavior for all 21 existing callers
- Uses strpbrk() for multi-delimiter support (from patch 2/7)

The changes are purely internal - no user-facing behavior or API changes. The consolidation prepares for future extensions (mentioned as adding flags) that could modify both functions simultaneously.
