This is a test refactoring series that finalizes the organization of help output testing, following up on the merged work to consolidate help tests. The series comes from Usman Akinyemi as version 5 of a 3-patch set.

The main goal is to clean up t1517-outside-repo.sh to focus exclusively on testing `git subcmd -h` behavior outside a repository. It does this by (1) moving repository-dependent help tests (update-server-info and prune) to their respective command-specific test files (t5200 and t5304), and (2) introducing an automated loop in t1517 that verifies `-h` output for all main Git commands when run outside a repository using `git --list-cmds=main` and the `nongit` helper.

Key technical changes in v5 include narrowing t1517's scope to only test outside-repo behavior (dropping the dual inside/outside testing from v4), fixing test breakages, and properly moving the prune test to t5304. The implementation follows the established pattern of using exit code 129 for script-based commands and handles command variants by stripping suffixes like `.sh`.

This appears to be the final iteration of the test reorganization, building on prior consensus about the testing strategy. The changes are focused and mechanical, with each patch moving specific tests to more logical locations while maintaining the same verification behavior. The series addresses the last remaining organizational cleanups from the original help test consolidation effort.
