Windows platform compatibility patch improving directory handling in mingw_open_existing(). This is the fourth patch in a series addressing Windows filesystem operations, specifically focusing on directory access issues that were reported in Git for Windows issue #5068.

The patch modifies mingw_open_existing() in compat/mingw.c to properly handle directory access by adding FILE_FLAG_BACKUP_SEMANTICS when opening directories, as required by Windows' CreateFileW() API. The change follows Microsoft's documented requirements for directory handles and fixes ERROR_ACCESS_DENIED errors that occurred when trying to open directories without this flag.

The implementation first attempts a normal file open, then falls back to a directory-specific open with the required flags if the initial attempt fails with ACCESS_DENIED and the path is actually a directory. The change preserves all existing error handling logic, including the ERROR_INVALID_PARAMETER to ERROR_PATH_NOT_FOUND conversion from mingw_open_append().
