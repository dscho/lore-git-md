This Windows compatibility patch series, addressing regressions in filesystem operations across various Windows versions and filesystems, has now been accepted for merging. The maintainer Junio Hamano has approved the four patches that fix mingw_rename() issues and upstream mature improvements from Git for Windows, applying them directly to master ahead of the upcoming release.

The series, contributed by Johannes Schindelen and Matthias Aßhauer, removes obsolete Windows 7 workarounds while adding proper support for ReFS volumes and restoring compatibility with Windows Server 2016. Key technical changes include handling specific error cases (ERROR_NOT_SUPPORTED, ERROR_INVALID_PARAMETER, and ERROR_INVALID_FUNCTION) and improving directory access through proper flag usage. These changes resolve two GitHub issues (#5427 for ReFS and #5695 for Server 2016) while maintaining backward compatibility across Windows versions from 7 through 2022.

Having already been tested in production through Git for Windows, the patches were deemed production-ready and non-controversial, leading to their fast-tracking to master. This concludes the thread with the fixes slated for inclusion in the next release.
