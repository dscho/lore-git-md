This is a refactoring patch in Junio Hamano's ongoing string-list API series (part 5/7). It simplifies the parsing of the `diff.colormovedws` configuration variable by leveraging the new whitespace-trimming capability added to `string_list_split()` in earlier patches.

The patch parsed comma-separated values by first splitting them, then manually trimming each piece in a temporary strbuf before comparison. Now it uses the new `STRING_LIST_SPLIT_TRIM` flag to handle whitespace removal directly during the split operation, eliminating the need for the intermediate strbuf steps. The behavior remains identical, just with cleaner code - 13 lines removed while maintaining all the same error checking and bitflag logic for the various whitespace handling modes.

This is a straightforward mechanical conversion that demonstrates the practical benefit of the API improvements from earlier in the series. The change is well-contained to diff.c and doesn't affect user-facing behavior, just internal code quality. As with the rest of the series, it maintains existing test coverage while making the implementation more maintainable.
