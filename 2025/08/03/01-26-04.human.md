This is the final patch in a 3-part series extending `-h` and `--help-all` support across Git commands, particularly when run outside a Git repository. The patch focuses on making `--help-all` work consistently in repository-less context, mirroring the existing behavior for `-h`.

The change modifies several key components:
- Updates `git.c` to treat `--help-all` the same as `-h` for repository setup
- Extends `parse-options.c` to handle `--help-all` requests with full usage output
- Adds test coverage in t1517-outside-repo.sh
- Maintains special case for merge-recursive's legacy help handling

The patch appears well-constructed with clear motivation (helping experts check command syntax regardless of working directory) and maintains backward compatibility. It completes the series' goal after the more controversial mid-command `-h` handling was dropped in earlier revisions. The changes are focused and the test coverage looks thorough.
