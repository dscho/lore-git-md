This is the final patch in a 3-part series extending `-h` and `--help-all` support across Git commands, particularly when run outside a repository context. The patch focuses on making `--help-all` work consistently with the same repository-less behavior that `-h` already has.

The key changes in this patch:
1. Modifies `git.c` to treat `--help-all` the same as `-h` for repository setup purposes
2. Updates `parse-options.c` to handle `--help-all` requests with the same early-exit behavior as `-h`, but using `USAGE_FULL` instead of `USAGE_NORMAL`
3. Adds special case handling for `merge-recursive.c` which uses older help APIs
4. Extends the test suite in `t1517-outside-repo.sh` to verify `--help-all` behavior matches `-h`

The patch maintains existing special cases for `ls-remote -h` and `grep -h` while ensuring `--help-all` works consistently across commands. It builds on the parse-options refactoring from earlier patches in the series, using the newly introduced `USAGE_NORMAL`/`USAGE_FULL` constants.
