This is a community announcement about the upcoming Git Rev News edition. Christian Couder is sharing a draft of edition 126 and inviting contributions from the Git community before its planned publication on September 2nd, 2025.

The draft is available on GitHub for direct editing via pull requests, and there's also an associated issue for discussion. The announcement emphasizes that all forms of contribution are welcome - from proofreading to suggesting content or volunteering for interviews. The email serves as both a notification and an open call for participation in finalizing this community newsletter.

Christian notes they've attempted to CC all contributors mentioned in this edition but acknowledges they might have missed some people. The message follows the standard format for Git Rev News draft notifications, maintaining the project's tradition of open collaboration in producing these periodic updates about Git development.
