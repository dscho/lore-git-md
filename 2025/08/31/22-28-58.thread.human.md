Christian Couder has shared a draft of the upcoming Git Rev News edition (#126) for community review before its September 2nd publication. The newsletter, which tracks Git development activity, is open for contributions via GitHub pull requests or issue comments - whether proofreading, content suggestions, or interview participation. 

The draft includes coverage of recent mailing list discussions and contributions, though Christian notes some contributors might have been accidentally omitted from the CC list. This follows the project's established collaborative approach to the Rev News, where community input helps shape each edition before release.
