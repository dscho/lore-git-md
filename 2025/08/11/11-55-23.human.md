This is a bugfix for the `git-jump` contrib script, addressing its handling of filenames containing spaces in diff output. The issue stems from Git's diff.c behavior (since 2006) that appends tabs after filenames containing spaces, causing `git-jump` to incorrectly process these as part of the filename in Vim's quickfix mode.

The patch implements a simple one-line Perl regex modification (`(.*?)\t?$`) to optionally strip trailing tabs, solving the common case of space-containing filenames while remaining simple. The commit message provides clear examples showing this fixes the main case people encounter (filenames with spaces) while acknowledging it doesn't handle the rare edge case of filenames ending with literal tabs (which Git would quote anyway).

This is version 2 of the patch, with no code changes from v1 but an improved commit message that better explains the behavior with quoted paths. The solution has been validated in the thread as working for the common case while being a reasonable tradeoff given Git's quoting behavior for control characters. The patch is small, focused, and well-explained, making it likely to be accepted.
