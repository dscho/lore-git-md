This is patch 5/6 in a documentation series introducing automated linting for Git's man pages. The patch standardizes formatting in `git-for-each-ref.adoc` in preparation for upcoming linter enforcement, making several systematic changes:

1. Wraps option names in backticks consistently (e.g., `--stdin` instead of --stdin)
2. Replaces single quotes with backticks for code/command references
3. Standardizes parameter references as `_<param>_` format
4. Wraps synopsis patterns in parentheses (e.g., `(<pattern>...)`)
5. Reformats signature grades as definition list items with proper spacing
6. Normalizes spacing and formatting in option descriptions

The changes are mechanical but extensive (132 insertions/132 deletions), touching nearly every section of the man page. The patch maintains all existing content while making it conform to the style that will be enforced by the new linters introduced earlier in the series. This is part of Jean-Noël Avila's broader effort to standardize documentation formatting, complementing the parallel synopsis conversion work mentioned in the thread context. The changes are straightforward and uncontroversial, following patterns established in prior patches that already received Reviewed-by tags.
