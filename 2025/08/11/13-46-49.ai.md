This is patch 9/10 in Patrick Steinhardt's ODB source system integration series, focusing on deduplicating redundant information storage in multi-pack indices (MIDX). The patch removes several fields from `struct multi_pack_index` that were duplicating information already available in the associated `struct odb_source`:

- The locality flag (tracking primary vs alternate source)
- The object directory path
- The parent directory pointer

The changes propagate through MIDX handling code in midx.c, midx-write.c, and related files, updating all accessors to instead reference these values through the `source` pointer. Key technical changes include updating path construction in midx-write.c's file operations, adjusting hash algorithm access to go through the source's repository pointer, and modifying test helpers to use the new access pattern.

The patch follows the series' pattern of making MIDX handling fully source-aware while maintaining existing behavior. It builds on the earlier MIDX loading changes (patch 7/10) and writing changes (patch 8/10), completing the structural cleanup before the final wrapper implementation in patch 10/10. Reviewers Taylor Blau and Karthik Nayak have already approved the technical approach for the MIDX-related patches in the series.
