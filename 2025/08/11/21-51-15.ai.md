This is the final patch in Julia Evans' documentation improvement series for the git-rebase man page, focusing on restructuring the internals explanation section.

The patch significantly reorganizes the technical description of how rebase works under the hood. It replaces a somewhat scattered explanation with a clear 5-step numbered list that walks through the rebase process from commit selection to final branch update. The new structure makes it easier to follow the sequence of operations while maintaining technical accuracy.

Key changes include:
- Explicit step-by-step breakdown of the rebase process (23 new lines)
- Removal of redundant explanations about --fork-point and --root (now properly referenced from OPTIONS)
- Consolidation of commit skipping logic into a single bullet point
- Removal of an example commit graph (43 lines removed) deemed unnecessary
- Better organization of ORIG_HEAD discussion within a NOTE block
- More precise language about command equivalents (git checkout --detach, git cherry-pick)

The patch follows through on the series' goal of making rebase documentation more approachable while preserving all essential technical information. It represents the final refinement of the internals section after earlier patches restructured other parts of the document.
