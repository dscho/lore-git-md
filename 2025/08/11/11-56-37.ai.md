This is a refactoring patch in Patrick Steinhardt's ODB source system integration series (v3, 9 patches). The patch modifies the object database (ODB) subsystem to return newly created in-memory sources from functions that add alternate object directories, rather than just void returns. This prepares for future need to access these sources directly.

Key technical changes include converting `link_alt_odb_entry()` and `odb_add_to_alternates_memory()` to return `struct odb_source*` instead of void/int. The patch also changes the `entry` parameter from `strbuf` to `const char*` in `link_alt_odb_entry()`, though this wasn't originally mentioned in the commit message (Taylor Blau noted this oversight). 

The email exchange reveals two additional improvements being made: Patrick will update the commit message to document the `strbuf` to `const char*` change, and will standardize the parameter naming between "reference" and "dir" in the function declarations. These are minor cleanups noticed during review rather than functional changes.

This patch continues the series' trend of making ODB behaviors more explicit and preparing the infrastructure for future needs.
