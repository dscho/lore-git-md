This is patch 2/10 in Patrick Steinhardt's ODB source system integration series, focusing on error handling improvements in the object database lookup code.

The patch makes `odb_find_source()` fallible by having it return NULL when an object directory cannot be found, rather than dying immediately. This prepares for future introduction of callers that want to handle missing directories gracefully. The existing behavior (dying on failure) is preserved through a new wrapper function `odb_find_source_or_die()` that calls the base function and dies if NULL is returned.

The changes affect several key areas:
- The base `odb_find_source()` function in odb.c now returns NULL for missing directories
- A new `odb_find_source_or_die()` wrapper provides the previous die-on-failure behavior
- Callers in builtin/commit-graph.c and midx-write.c are updated to use the new wrapper
- The odb.h header is updated to document both functions

This is part of the broader effort to make object database behavior more explicit and flexible. The change is straightforward and mechanical, converting existing die() calls to use the new wrapper while leaving the door open for graceful error handling in future patches. The patch follows the series' pattern of making implicit behaviors explicit while maintaining backward compatibility.
