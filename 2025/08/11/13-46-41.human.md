This is the first patch in Patrick Steinhardt's v3 series (10 patches) improving object database (ODB) source handling, with a focus on making locality tracking more explicit. The patch adds a `local` flag to the `odb_source` struct to clearly distinguish between the primary repository's object store (".git/objects") and alternate/quarantine directories, rather than inferring it by checking if a source is first in the list.

The change touches several key areas - MIDX handling, packfile preparation, and repository setup - but remains focused on internal plumbing rather than user-facing behavior. It's part of a broader effort to make ODB behaviors more explicit and robust, with this particular patch eliminating some ad-hoc checks in favor of storing the information directly when sources are created.

The patch appears well-constructed with thorough updates across the codebase and a clear commit message. It's foundational work for the rest of the series, which has already received positive reviews from Taylor Blau and Karthik Nayak with only minor documentation tweaks remaining. The series as a whole is making steady technical progress toward better ODB source management.
