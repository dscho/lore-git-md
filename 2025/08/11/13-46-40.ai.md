This is a feature patch series (v3, 10 patches) from Patrick Steinhardt that continues the ODB source system integration work, now focusing on MIDX deduplication. The series builds on previous work to move MIDX handling into the object source system, with the key goal of eliminating redundant information storage by having MIDX structures reference their owning ODB source.

The series makes several technical changes:
- Adds locality tracking to ODB sources
- Makes `odb_find_source()` fallible and introduces `odb_find_source_or_die()` wrapper
- Standardizes parameter naming for alternate ODB directory references
- Returns newly created in-memory sources from ODB functions
- Simplifies `link_alt_odb_entry()` calling convention
- Removes redundant repository parameters from MIDX functions
- Updates MIDX loading/writing to work via ODB sources
- Eliminates redundant path storage in MIDX by using source paths
- Updates MIDX path computation to use source information

The changes affect multiple subsystems including midx handling, odb internals, and several builtin commands. The series has already received positive reviews from Taylor Blau and Karthik Nayak, with only minor documentation/naming tweaks requested. Patrick indicates he will reroll the series with those changes while awaiting Derrick Stolee's input on object directory handling questions.

This continues steady progress on the ODB abstraction effort, making behaviors more explicit while maintaining backward compatibility. The technical changes are well-contained and the series appears ready for merging once the final review from Stolee is addressed.
