This is the first patch in Patrick Steinhardt's v3 series (10 patches) integrating the ODB source system, focusing on refactoring how object database locality is tracked.

The patch introduces an explicit `local` flag in the `odb_source` struct to track whether a source is the repository's primary object store (typically ".git/objects") versus alternates or quarantine directories. Previously, this was made by checking if the source was first in the list, which was indirect. The change makes the distinction more robust and accessible throughout the codebase.

Key technical changes include:
- Adding the `local` boolean field to `struct odb_source` with documentation
- Initializing the flag appropriately when creating sources (true for main repo, false for alternates)
- Removing the `local` parameter from `prepare_multi_pack_index_one()` and `prepare_packed_git_one()` since they can now get it from the source
- Updating all callers to use the source's local flag instead of passing it

The changes touch midx.c, odb.c, packfile.c and related headers, standardizing how locality is handled across the object database code. This is part of the broader effort to make ODB behaviors more explicit while maintaining backward compatibility. The patch has already received positive review feedback in the thread, with only minor documentation tweaks requested.
