This is the final patch in a 4-part series modernizing Git's editor-related test infrastructure and APIs, focusing on converting the strvec API for editor environment handling.

The patch updates the editor subsystem to use `struct strvec` consistently for passing environment variables to external editors, bringing it in line with modern Git conventions. It changes the editor API signatures in `editor.h` and their implementations in `editor.c` to accept a `const struct strvec*` instead of the older `const char* const*` array. The only caller in `builtin/commit.c` that passes environment variables (for GIT_INDEX_FILE) is updated to match.

Key technical details:
- Affects all editor-related APIs: `launch_editor()`, `launch_sequence_editor()`, and `strbuf_edit_interactively()`
- Maintains backward compatibility while modernizing the interface
- Builds on previous strvec API work (8d7aa4ba6a, 46b225f153)
- References original environment handling from 8babab95af
- Only one actual caller needs updating (in `builtin/commit.c`)
- Includes sign-off from Johannes Schindelin

This completes the series' technical modernization goals, following the test infrastructure improvements in earlier patches.
