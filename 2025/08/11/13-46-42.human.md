This is part 2/10 of Patrick Steinhardt's ODB source system integration series, focusing on error handling improvements in the object database abstraction layer.

The patch refactors `odb_find_source()` to return NULL when an object directory source cannot be found, rather than dying immediately. This enables more graceful error handling for future callers that may want to recover from this condition. The existing behavior (dying on failure) is preserved through a new wrapper function `odb_find_source_or_die()`.

The changes are straightforward and mechanical - all existing callers are updated to use the new wrapper function, maintaining the same behavior.
