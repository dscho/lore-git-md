This is patch 5/10 in Patrick Steinhardt's series refactoring Git's object database (ODB) source system. The patch simplifies the calling convention for `link_alt_odb_entry()` by removing a redundant parameter.

The function previously required callers to pass in three different paths (raw path, base path, and resolved path), making the interface complex. The patch removes the need for callers to compute and pass the resolved path, instead having the function resolve it internally. While this means some callers now do redundant path resolution (particularly in loops), the tradeoff is deemed worthwhile for the cleaner interface.

The changes are straightforward - removing the parameter from function signatures and moving the path resolution into the function itself. The patch follows the series' pattern of making the ODB code more maintainable while preserving existing behavior. Reviewers Taylor Blau and Karthik Nayak have already approved the technical approach in earlier patches, and this change aligns with their feedback.

This continues the series' steady progress toward standardizing the ODB interface, with only minor documentation updates and one remaining technical question (about object directory handling) before the series can be finalized.
