This is the final patch in Julia Evans' documentation improvement series for the `git-rebase` man page. The patch focuses on clarifying the internals section by restructuring it into a clearer numbered list format that walks through each step of the rebase process.

Key changes include:
- Replacing the previous prose description with a numbered 5-step breakdown of what happens during a rebase
- Removing redundant explanations of `--fork-point` and `--root` since they're covered in the OPTIONS section
- Consolidating the discussion of `ORIG_HEAD` into a single NOTE section
- Eliminating an example diagram of commit skipping that was deemed unnecessary
- Maintaining all the same technical information while improving readability

The changes continue the series' goal of making the rebase documentation more approachable through better organization. Since this is the final patch in an already-merged series, it represents the last polish on these documentation improvements. The changes are purely editorial - no new information is added, just presented more clearly.
