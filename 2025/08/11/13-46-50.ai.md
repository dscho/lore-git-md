This is the final patch (10/10) in Patrick Steinhardt's ODB source system integration series, completing the wrapper implementation for MIDX path computation. The patch refactors MIDX path handling to use the object database source exclusively, eliminating the need to pass separate hash algorithm and object directory parameters. Changes propagate through midx-write.c, midx.c, and related files, updating all path construction functions to work with `struct odb_source*` instead of individual components.

Key technical changes include:
- Removes redundant path/hash-algorithm parameters from all MIDX path functions
- Updates `get_midx_filename()`, `get_split_midx_filename_ext()` and related helpers to take only a source parameter
- Modifies bitmap and revindex handling to use source-based paths
- Adjusts test infrastructure to match new calling conventions
- Maintains all existing functionality while simplifying the interface

The changes follow the series' pattern of making MIDX handling fully source-aware, completing the structural cleanup started in earlier patches. With this wrapper implementation in place, the ODB source system can now handle all MIDX path computation internally. The patch has received positive review from Taylor Blau and Karthik Nayak, who approved the technical approach earlier in the series. This marks the completion of the MIDX-related portions of the ODB abstraction work.
