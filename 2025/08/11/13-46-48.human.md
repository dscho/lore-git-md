This is patch 8/10 in Patrick Steinhardt's series refactoring multi-pack index (MIDX) handling to use the new ODB source system. The patch continues the conversion of MIDX operations to work with `struct odb_source*` rather than separate repository and object directory parameters.

The changes update the MIDX writing logic across several commands (`multi-pack-index write/expire/repack` and `repack`) to use the ODB source interface consistently. Key modifications include:
- Refactoring `write_midx_internal()` and related functions to take an `odb_source` parameter
- Updating helper functions like `clear_midx_files()` to work with sources
- Adjusting the command implementations to pass through the source from `handle_object_dir_option()`

This patch follows the pattern established in earlier patches of the series, completing the transition for MIDX writing operations after patch 7 handled the reading side. The changes maintain all existing functionality while cleaning up the interface to be source-aware, which is important for the broader ODB abstraction work.

The patch has already received positive review from Taylor Blau and Karthik Nayak for the technical approach. With this change, the MIDX interface is now fully converted to use the ODB source system, leaving just two more patches in the series to complete the integration work.
