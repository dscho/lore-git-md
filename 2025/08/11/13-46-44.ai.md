Refactoring patch in Patrick Steinhardt's ODB source system integration series (v3, 4/10). This patch modifies the ODB alternates handling to return newly created in-memory sources rather than just success/failure status.

The key changes are:
1. `link_alt_odb_entry()` now returns the created `struct odb_source*` instead of an int status
2. `odb_add_to_alternates_memory()` is similarly modified to return the source pointer
3. The implementation updates the helper functions to properly track and return the source pointer through the call chain
4. Header declarations are updated to match the new return types

This is a preparatory change for future functionality that will need access to the newly created sources. The patch maintains all existing behavior while adding the ability to track the created sources. It follows the series' pattern of making ODB internals more explicit and accessible while maintaining backward compatibility.

The changes are focused on internal APIs (odb.c/odb.h) and don't affect user-facing behavior. The commit message clearly states this is groundwork for a subsequent change that will need the source pointers. Reviewers Taylor Blau and Karthik Nayak have already approved the technical approach of this series, and this patch continues that pattern of internal improvements.
