This is a documentation patch clarifying the behavior of `git push --mirror`. The current docs describe how local ref changes (created/updated/deleted) are mirrored to the remote, but don't explicitly mention that refs existing only on the remote (not locally) will also be deleted. The patch adds this important detail to the description.
