This is patch 6/10 in Patrick Steinhardt's ODB source system integration series, focusing on MIDX (multi-pack index) cleanup. The patch removes redundant `struct repository` parameters from several MIDX-related functions since the multi-pack index already contains a pointer to its owning repository. This continues the series' pattern of simplifying interfaces while maintaining functionality.

The changes affect functions like `prepare_midx_pack()`, `fill_midx_entry()`, and `nth_bitmapped_pack()`, which now take only the MIDX parameter where they previously required both MIDX and repository. The patch also reorders `fill_midx_entry()` parameters to follow Git's coding guidelines by putting the MIDX first. These changes propagate through multiple files including pack-bitmap.c, packfile.c, and test helpers.

The technical impact is straightforward - eliminating redundant parameter passing while maintaining all existing behavior. The MIDX abstraction now more cleanly encapsulates its repository relationship. This aligns with the series' broader goal of standardizing and simplifying the ODB interface. The changes are mechanical but help reduce cognitive overhead when working with MIDX code.
