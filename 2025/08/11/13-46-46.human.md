This is patch 6/10 in Patrick Steinhardt's ODB source system integration series, focusing on code cleanup in the MIDX (multi-pack index) subsystem. The patch removes redundant `struct repository` parameters from several MIDX-related functions since the multi-pack index already contains a pointer to its owning repository. 

The changes affect functions like `prepare_midx_pack()`, `fill_midx_entry()`, and `nth_bitmapped_pack()`, simplifying their signatures while maintaining the same functionality. The patch also reorders parameters in `fill_midx_entry()` to better follow Git's coding guidelines by putting the MIDX parameter first. 

This continues the series' pattern of cleaning up redundant information in the object database interfaces. The changes are mechanical but improve code clarity by eliminating unnecessary parameters.
