This is a documentation patch clarifying the behavior of `git push --mirror`. 

The patch updates the man page description to explicitly state that `--mirror` will delete any refs that exist on the remote but not locally, in addition to its existing behavior of pushing local ref changes. The current documentation only mentions handling of locally created/updated/deleted refs, omitting this important aspect of mirroring behavior.

The change is straightforward and corrects an oversight in the documentation. The new wording makes it clearer that `--mirror` truly synchronizes the remote's refs to match the local repository exactly, including removal of any "extra" refs that only exist remotely. This matches the actual behavior that has been in Git for years.

The patch is well-formed with a clear commit message explaining the change. As a documentation clarification for a long-standing feature, it seems uncontroversial and useful for users who need to understand the full implications of using `--mirror`.
