This is a refactoring patch in Patrick Steinhardt's ODB source system integration series (v3, 9 patches). It modifies how alternate object database sources are handled in memory.

The patch changes two key functions (`link_alt_odb_entry` and `odb_add_to_alternates_memory`) to return the newly created `odb_source` pointer rather than being void functions. This prepares for future changes that will need access to these sources. Taylor Blau noted some parameter naming inconsistencies that Patrick agrees to fix - the parameter `reference` in one function should be renamed to `dir` for consistency with the rest of the codebase.

The changes are straightforward - converting return types and adjusting callers to handle the returned pointer. While not fixing any immediate bug, this refactoring enables future work in the series where callers will need to access the created sources. The patch follows the series' broader goal of making ODB behaviors more explicit and better tracked.

This appears to be a well-scoped preparatory change that has already received positive feedback from Taylor Blau. It's part of the ongoing effort to improve object database handling that has been progressing steadily through the review process.
