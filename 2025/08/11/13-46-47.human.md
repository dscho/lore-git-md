This is part 7/10 of Patrick Steinhardt's series to integrate the ODB source system, focusing on MIDX (multi-pack index) handling. The patch refactors how multi-pack indices are loaded to work directly with object database sources rather than requiring separate repository and object directory parameters.

The key changes simplify the MIDX loading interface by:
- Removing redundant repository parameters from MIDX functions
- Storing the owning source pointer in the MIDX structure
- Handling user-provided object directories as in-memory alternates
- Updating test helpers and builtin commands to use the new interface

The patch maintains all existing behavior while making the code more consistent with the series' goal of proper ODB abstraction. It follows the pattern established in earlier patches of removing redundant parameters and centralizing logic around the odb_source structure. The changes affect MIDX-related functions across midx.c, pack-bitmap.c, and test helpers.

This continues the series' steady progress toward its goal, with the technical approach already receiving positive reviews from Taylor Blau and Karthik Nayak. The remaining open question about object directory handling (awaiting input from Derrick Stolee) appears to be the last major item before the series can be finalized.
