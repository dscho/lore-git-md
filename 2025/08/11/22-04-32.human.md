Documentation fix for git-clone option syntax. This is the third version of a straightforward patch correcting a misplaced bracket in the `git-clone` man page's command-line syntax. The fix properly nests the `--also-filter-submodules` option within the `--filter` option's brackets, since submodule filtering logically requires regular filtering to be enabled.

The patch history shows collaborative refinement of the commit message. Version 1 made the technical correction but had a less clear message. Version 2 improved the message but accidentally dropped the descriptive subject line. This final version restores the clear "docs: remove stray bracket" subject while adding historical context about when the incorrect formatting was introduced (commit 76880f05) versus when the options were originally grouped (commit f05da2b4).

All technical aspects were agreed upon in previous discussion between Knut Ryager, Junio Hamano, and Kristoffer Haugsbakk. The only remaining discussion was about optimizing the commit message's educational value, which this version accomplishes by explaining why the alternative bracket placement would be incorrect. The actual code change remains a one-line documentation fix with no functional impact.
