This is a refactoring patch in Patrick Steinhardt's ODB source system integration series (v3, 03/10). It standardizes parameter naming and simplifies function signatures in the alternate object database handling code.

The patch addresses an inconsistency where functions dealing with alternate object directories used different names ("dir", "reference", "entry") for the same parameter. It settles on "dir" throughout, making the code more readable and consistent. As part of this cleanup, it also changes `link_alt_odb_entry()` to take a plain C string instead of a `strbuf`, since only the path string is needed.

The change was suggested by Taylor Blau during review of earlier versions. This is a straightforward improvement that doesn't affect functionality but makes the code more maintainable. The patch follows the series' pattern of making implicit behaviors more explicit while maintaining backward compatibility.

This continues the steady progress of the series, which has already received positive reviews for its technical approach. The changes are localized to odb.c and focus on code clarity rather than introducing new behavior.
