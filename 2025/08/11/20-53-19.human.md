1. Wraps option names in backticks consistently (e.g., `--stdin` instead of --stdin)
2. Standardizes parameter references as `_<param>_` throughout
3. Wraps synopsis patterns in parentheses (e.g., `(<pattern>...)`)
4. Reformats signature grades as a definition list with clear itemization
5. Normalizes spacing and formatting in option descriptions

The changes are mechanical but extensive (132 insertions and deletions), bringing this man page into alignment with the project's documentation style guidelines.
