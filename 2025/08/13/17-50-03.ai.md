This is the first patch in a 3-part series modernizing editor-related test infrastructure (t7005-editor.sh). The patch focuses on test style updates, moving from older test patterns to modern Git test helpers.

The changes standardize the test file to use contemporary Git test patterns:
- Replaces manual error checking with `test_must_fail`
- Uses `test_commit_message` helper instead of manual commit message verification
- Moves editor script setup into the main setup block
- Removes redundant blank lines and old-style test patterns
- Maintains all test functionality while making the code more maintainable

The patch exclusively modifies t7005-editor.sh, with no behavioral changes to Git itself. This is part of a larger effort to modernize test infrastructure that has gone through 5 iterations with feedback incorporated. The changes here are stable and uncontroversial, having been reviewed by multiple contributors including Junio C Hamano and Phillip Wood.

Key technical details:
- Introduces `write_script` helper usage for test editor scripts
- Standardizes on `test_commit_message` for commit verification
- Maintains all test cases including edge cases with spaces in editor paths
- Preserves test isolation while making the code more compact and readable

This patch represents the test modernization portion of the series, with subsequent patches handling exec-path security and test execution optimization. The changes here are well-contained and demonstrate good test hygiene, following established patterns seen in other modernized test scripts.
