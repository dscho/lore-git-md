This is a bug report about `git send-email`'s `--suppress-cc` option not properly handling multiple comma-separated keywords. Timur Tabi reports that when trying to exclude both "author" and "self" from automatic CCs using `--suppress-cc=author,self`, Git incorrectly treats the entire string as a single unrecognized keyword rather than parsing it as multiple values.

The expected behavior would be for Git to recognize both keywords and suppress both types of CCs, similar to how many other multi-value Git options work. Timur found a workaround by specifying `--suppress-cc` multiple times with single values, but this is less convenient than the documented comma-separated syntax.

The bug appears in Git 2.50.1 on a Linux system, and the report includes full system information. The issue seems straightforward to reproduce and affects a documented feature of `git send-email`. While not a critical bug, it does impact usability for those trying to suppress multiple CC types at once. The report is clear and includes all the necessary details for someone to investigate the parsing logic in the send-email command.
