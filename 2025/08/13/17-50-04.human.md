This is part 2 of a 3-patch series modernizing editor-related test infrastructure, focusing on security and performance improvements. The patch specifically addresses how test editors are located during test execution.

The change replaces the use of `--exec-path=.` with direct PATH manipulation (`PATH="$PWD:$PATH"`) when running `git commit --amend` in t7005-editor.sh. This is a more straightforward way to ensure the test scripts can find the editor executables in the current directory, rather than abusing Git's exec-path mechanism for this purpose.

The modification appears in two test blocks that verify different editor behaviors. The change is small but meaningful - it makes the test's intent clearer (we want the editors on PATH) and removes an implementation detail (--exec-path) that wasn't actually relevant to what the test was trying to verify.

This is part of a well-reviewed series that has gone through five iterations, with all feedback addressed. The patch aligns with the series' goals of modernizing test idioms and improving isolation while maintaining test reliability.
