This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series, specifically addressing a dependency issue in the reftable writer code.

The patch replaces Git's internal `QSORT()` macro with the standard `qsort()` function in two places within `reftable/writer.c`. The change is straightforward but important for making the reftable library more portable, as `QSORT()` is Git-specific while `qsort()` is standard C.

The author notes that while `QSORT()` provides minor convenience by inferring the element size, the functionality is otherwise identical. The patch also adds null checks before sorting, which appears to be a defensive programming improvement not present in the original `QSORT()` usage.

This change aligns with the series' broader goal of making reftable support production-ready for libgit2 by removing Git-specific dependencies. The modification is clean and focused, with no apparent behavior change beyond the intended portability improvement.
