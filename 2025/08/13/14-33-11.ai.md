Documentation patch clarifying `--suppress-cc` behavior in `git send-email`. This is a follow-up to the closed thread about the option's handling of multiple suppression categories.

Junio Hamano proposes a documentation improvement to make explicit what was only implicit in the `--suppress-cc` option's behavior - that it accepts multiple instances of the flag to suppress different categories. The patch adds text stating "Can be given more than once to suppress multiple categories" and clarifies that the corresponding config variable `sendemail.suppressCc` also accepts multiple values (one per instance).

The change comes after Eric Sunshine confirmed the current implementation requiring separate flags is correct, though the documentation didn't explicitly state this multi-flag capability. Junio notes that while some Git options explicitly document their repeatability, many (including this one) don't, though the existing wording about "an additional category" implies single-category-per-flag usage.

The patch is minimal and focused, just adding the missing documentation about the repeatable nature of the option while maintaining all existing behavior and defaults. This serves as a clean resolution to the thread by making the intended usage pattern more discoverable without requiring any code changes.
