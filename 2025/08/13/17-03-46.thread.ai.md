Git v2.51.0-rc2 release announcement, second release candidate for Git 2.51.0. Contains 494 non-merge commits from 78 contributors (20 new). Key changes:

UI/Workflow: New R language userdiff patterns, updated `git send-email` docs, `git cat-file --batch` now distinguishes missing objects from submodules, `git subtree` adds GPG signing support.

Performance: Batched reference updates in fetch/push, path-based delta compression in `git pack-objects`, optimizations to `git prune` and reflog expiration.

Internal: Continued `the_repository` removal effort, object-file and config API refactoring to reduce global state. Reftable backend declared mature enough to become default format in Git 3.0 for new repos.

Bugfixes: Memory leaks fixed, branch name corrections in stash messages, submodule handling improvements, platform-specific fixes. Includes documentation updates, test improvements, code cleanups. Likely final RC before 2.51.0 release unless critical issues found.

Technical areas: ODB (object database), reftable backend, batched ref updates, path-based delta compression, SHA-256 transition prep. Meson build system improvements for test TAP output handling.
