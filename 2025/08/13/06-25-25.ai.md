This is a bugfix patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v4). It corrects a type mismatch in the reftable writer interface where callers were passing `size_t` for record counts but the functions were accepting `int` parameters. The change standardizes on `size_t` for both `reftable_writer_add_refs()` and `reftable_writer_add_logs()` functions, matching the calling convention already in use. The implementation updates both the function declarations in reftable-writer.h and their implementations in writer.c, including adjusting the loop variable type in the latter.

This is a straightforward technical correction that improves type safety and prevents potential integer truncation issues when dealing with large numbers of records. The patch is cleanly implemented with minimal changes - just the type adjustments and some whitespace normalization in the loops. As the first patch in the v4 iteration of this series, it sets up the foundation for the more substantial reftable improvements that follow.
