Core problem: Initial confusion about whether `--suppress-cc` should accept comma-separated keywords (e.g., `author,self`) versus requiring separate flags. The thread established that the current implementation (separate flags) is correct and matches the original design, though the documentation didn't explicitly state this.

Current status: Consensus reached that the behavior is correct but under-documented. Key technical details: The `--suppress-cc` option in `git send-email` controls suppression of automatic CCs (author, self, cc, bodycc, sob, cccmd) and was designed to require separate flags for each category (e.g., `--suppress-cc=author --suppress-cc=self`). The documentation update will clarify this repeatable flag behavior and its correspondence with the config variable, which also accepts multiple entries rather than comma-separated values.
