This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v4, 3/8). The patch reorganizes code in reftable/stack.c to eliminate forward declarations by moving function definitions to more logical positions.

The changes are purely structural - no behavior is modified. The patch removes five forward declarations (`stack_try_add`, `stack_write_compact`, `reftable_addition_close`, `reftable_stack_reload_maybe_reuse`) and reorders the corresponding function implementations to appear before their first use. Key functions affected include:

1. `reftable_new_stack` moved after `reftable_stack_reload_maybe_reuse` which it calls
2. `reftable_addition_close` moved before `reftable_stack_init_addition` which uses it
3. `stack_try_add` moved before `reftable_stack_add` which wraps it
4. `stack_write_compact` moved before `stack_compact_locked` which calls it

The patch demonstrates careful attention to code organization while maintaining the exact same functionality. It's a straightforward improvement that makes the code more readable by reducing the need to jump between declarations and implementations. This change aligns with the series' goal of improving reftable code quality for libgit2 integration.
