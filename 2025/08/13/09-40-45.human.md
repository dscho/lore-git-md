This is a documentation patch fixing an oversight in the `git count-objects` man page. 

Daniele Sassoli points out that when Juno added the "packs" output line to `git count-objects -v` in commit ae72f68541, the documentation was not updated to reflect this. Later, when 0bdaa1216 refactored the -v option documentation, this omission remained. 

The patch simply adds the missing documentation for the "packs" line that shows the number of pack files, inserting it in the correct place between the existing "in-pack" and "size-pack" descriptions in the man page. 

This is a straightforward and clearly correct documentation update that brings the manual in line with actual behavior. The patch is minimal (just 2 lines added) and properly references the relevant historical changes. No controversy or discussion is expected - it's the kind of minor but useful documentation cleanup that maintainers typically accept without debate.
