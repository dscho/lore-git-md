This is a refactoring patch in Patrick Steinhardt's reftable/libgit2 compatibility series (v4). It fixes a type mismatch in the reftable writer interface where functions accepted an `int` parameter for record counts when callers were passing `size_t`. The change makes the interface more consistent and safer by using the implicit conversion from `size_t` to `int`.

The patch updates both the function declarations in `reftable-writer.h` and their implementations in `writer.c`, including the helper functions for adding refs and logs. While this is a straightforward change, it's part of a larger effort to make the reftable backend more robust and production-ready, particularly for libgit2 integration. The change is cleanly implemented with corresponding updates to the sorting loops that use the count parameter.

This appears to be a low-risk improvement that aligns with the series' goal of hardening the reftable implementation. The patch follows the pattern of the rest of the series in paying attention to type safety and interface consistency.
