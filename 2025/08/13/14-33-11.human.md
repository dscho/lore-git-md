This is a documentation clarification patch in a closed thread about `git send-email`'s `--suppress-cc` behavior. 

Junio Hamano follows up on Eric Sunshine's earlier explanation that the option was never meant to accept comma-separated values, despite some user expectations. The thread had established that the current implementation (separate flags per category) matches the intended design.

Hamano proposes a small documentation improvement to make this clearer. The patch adds text explicitly stating that `--suppress-cc` can be given multiple times (once per category) and notes that the corresponding config variable `sendemail.suppressCc` follows the same one-category-at-a-time pattern. 

This is a straightforward documentation tweak that closes the loop on the earlier discussion by making the intended usage more obvious in the manpage. The change is minimal and uncontroversial, simply codifying the behavior that was already confirmed as correct.
