Feature patch adding object format reporting to `git repo info`. This is the second patch in a v2 series from GSoC contributor Lucas Seiki Oshiro, with mentor sign-offs from Karthik Nayak and Patrick Steinhardt.

The patch adds a new `object.format` field to `git repo info` that reports the repository's object storage format (SHA-1 or SHA-256), matching the information available via `git rev-parse --show-object-format`. The implementation reads directly from `repo->hash_algo->name` and includes tests verifying correct output for both hash algorithms.

This follows the naming convention settled on in the thread (using singular `object.format` rather than plural) and builds on the existing `git repo info` infrastructure. The patch is technically ready with all feedback addressed from v1, though there remains an open discussion about renaming the related `references.format` field to better align with other Git commands.

The changes are straightforward - adding the new field handler in builtin/repo.c, documenting it, and testing both hash algorithms. This provides a more structured way to access repository metadata compared to using `rev-parse` directly.
