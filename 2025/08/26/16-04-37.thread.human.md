This thread discusses a build system issue affecting parallel builds when Rust components (`libgit-sys` and `libgit-rs`) are enabled via `INCLUDE_LIBGIT_RS`. The initial patch proposed using Make's `.WAIT` directive to serialize these builds, which Junio noted might need to be extended to test execution as well.

Kyle Lippincott has now suggested an alternative approach: instead of using `.WAIT` in the `all` target, the Makefile could express the dependency directly by making `libgit-rs` depend on `libgit-sys`. This would let Make's normal dependency handling ensure proper build ordering, potentially making the solution more maintainable. The discussion is now considering both the technical solution (`.WAIT` vs. target dependencies) and scope (whether test execution needs similar protection).
