Documentation patch adding style guideline for bit field formatting. This is a straightforward addition to the CodingGuidelines document that codifies the existing practice seen in `.clang-format` for how bit fields should be styled - specifically, no spaces around the colon in declarations like `unsigned my_field:1;`. 

The patch comes with examples of both the preferred style and discouraged "ugly alignment" styles. It's a minor but useful clarification that helps maintain consistency, especially since `.clang-format` isn't yet enforced across the codebase. The change is small and non-controversial, simply documenting existing practice rather than introducing new rules. Junio C Hamano is listed as a helper, suggesting this has already been discussed and agreed upon.
