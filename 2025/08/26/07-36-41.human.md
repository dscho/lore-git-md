This is the first patch in a 5-part series introducing a new `git refs optimize` subcommand to replace `git pack-refs` as part of refs command consolidation. The series is a Google Summer of Code project.

The patch factors out the core logic from `builtin/pack-refs.c` into a new shared helper function `pack_refs_core()` and introduces a new `pack-refs.h` header file. This refactoring enables code reuse for the upcoming `git refs optimize` subcommand while maintaining the existing `git pack-refs` functionality.

The changes include:
- Moving option parsing and packing logic into the new `pack_refs_core()` function
- Creating a header file with the shared options macro `PACK_REFS_OPTS`
- Simplifying `cmd_pack_refs()` to be a thin wrapper around the new helper

The patch appears well-structured with clear commit message explaining the motivation and changes. It maintains backward compatibility while setting up the infrastructure needed for the new subcommand. The inclusion of mentor sign-offs suggests this has already undergone some review.
