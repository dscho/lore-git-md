This is the third patch in a 5-part series introducing a new `git refs optimize` subcommand as part of ref-related command consolidation, specifically replacing `git pack-refs`.

The patch adds the new `optimize` subcommand to `git refs`, which provides identical functionality to `git pack-refs` for packing references into a single file. The implementation is straightforward, leveraging the `pack_refs_core()` helper function that was extracted from `git pack-refs` in earlier patches. This maintains consistency between the old and new interfaces while sharing the core logic.

Documentation is added to git-refs.adoc, including the same options as `git pack-refs` by including the shared pack-refs-options.adoc file. The patch follows the established pattern from previous subcommands in this series, with clear usage strings and proper integration into the refs command infrastructure.

The changes are cleanly implemented with appropriate test coverage (though the tests themselves appear in other patches in the series). This continues the well-structured approach seen in earlier patches, with clear mentorship tags indicating the work has been reviewed by project mentors.
