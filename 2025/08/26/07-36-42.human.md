Documentation patch for the `git refs optimize` series. This is the second patch in a 5-part series that reorganizes ref-related commands under the `git refs` namespace.

The patch, Meet Soni factors out the common options documentation from `git-pack-refs.adoc` into a new shared file `pack-refs-options.adoc`. This is a pure refactoring with no functional changes - the rendered documentation remains identical. The change prepares for reusing these option descriptions in the upcoming `git refs optimize` command documentation.

The patch cleanly moves all option documentation (--all, --no-prune, --auto, --include, --exclude) to the new shared file and replaces the original content with an include directive. This follows good documentation practices by avoiding duplication while maintaining the same content structure. The change is straightforward and uncontroversial, with clear mentorship from Patrick Steinhardt and shejialuo noted in the sign-off.

This is part of the larger effort to consolidate ref-related commands, with the new `git refs optimize` command being introduced as a replacement for `git pack-refs` while maintaining identical functionality. The documentation restructuring here will allow both commands to share the same option descriptions going forward.
