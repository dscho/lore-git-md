Feature patch adding `git refs exists` subcommand as part of refs command consolidation effort. This is patch 1/4 in the third version of Meet Soni's GSoC series, now addressing all previous review feedback.

The patch introduces a new `exists` subcommand to `git refs` that duplicates the functionality of `git show-ref --exists`, checking whether a reference exists and returning appropriate exit codes (0=exists, 2=missing, 1=error). The implementation is intentionally duplicated from show-ref rather than shared, as the logic is minimal (~20 lines). Documentation is added to git-refs.adoc specifying the behavior.

This appears to be a well-crafted patch that completes the technical requirements for this part of the refs consolidation effort. The implementation follows the existing show-ref behavior precisely, and the test coverage (shown in later patches) is thorough. The only remaining discussion points are minor test script style nits, as the substantive technical feedback from earlier rounds has been addressed. The patch builds on the merged `ms/refs-list` branch and Git v2.51.0.
