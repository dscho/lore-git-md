This is a v2 feature patch series from GSoC contributor Lucas Seiki Oshiro, building on the `git repo info` command. The series has two independent but related enhancements that are now technically ready with mentor sign-offs, pending final naming decisions.

The first patch adds a `-z` flag as an alias for `--format=nul`, following Git's convention for null-terminated output (matching behavior in git-config and git-status). The v2 changes fix documentation formatting by adding proper spacing around the pipe character in usage strings.

The second patch adds repository object format detection (equivalent to `git rev-parse --show-object-format`), with the field changed from plural `objects.format` to singular `object.format` in v2 to match `extensions.objectFormat` naming. The implementation reads from `repo->hash_algo->name` and includes tests for both SHA-1 and SHA-256 cases.

Key technical details:
- Both patches modify builtin/repo.c and Documentation/git-repo.adoc
- Tests in t1900-repo.sh verify the new features
- Uses `die_for_incompatible_opt2()` for option handling
- Follows Git's documentation conventions
- Now targets `master` directly after dependency resolution

The only remaining open question is the naming of the `references.format` field to align with `extensions.refStorage`/`--ref-format` (possible renames to `reference.format` or `ref.format` being considered). The patches have mentor approvals from Karthik Nayak and Patrick Steinhardt, with Junio C Hamano having provided feedback on documentation formatting and naming consistency.
