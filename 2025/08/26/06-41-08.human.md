Test refactoring patch in the `git refs exists` series. This is part 2/4 of Meet Soni's GSoC project to consolidate ref-related commands under `git refs`.

The patch moves the `--exists` tests from `t1403-show-ref.sh` into a new standalone test file `t1422-show-ref-exists.sh`. This is a pure reorganization with no behavior changes - all the same test cases are preserved, just relocated. The tests verify various edge cases for reference existence checking, including:
- Regular refs and HEAD
- Symrefs (both valid and dangling)
- Invalid ref names
- Special refs like FETCH_HEAD
- Directory vs ref name conflicts

The move prepares for sharing these tests with the new `git refs exists` command being introduced in later patches. The test coverage remains comprehensive, checking both success and error cases with proper exit codes.

This appears to be a straightforward and well-executed test reorganization, following the pattern suggested by Patrick Steinhardt in earlier reviews. The patch is part of a series that's nearing completion, with all major technical feedback already addressed in previous iterations.
