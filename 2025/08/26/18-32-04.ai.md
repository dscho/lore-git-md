Feature patch adding `-z` flag to `git repo info` as part of a GSoC project. This is the first of two patches in v2 of the series, adding a `-z` shorthand for `--format=nul` to align with Git's convention for null-terminated output in commands like `git-config` and `git-status`. The implementation mirrors existing behavior while adding proper option conflict handling and tests.

The patch modifies documentation, command-line parsing, and adds test coverage. Key technical points:
- Adds `-z` flag as mutually exclusive with `--format` (using `die_for_incompatible_opt2()`)
- Maintains backward compatibility by defaulting to "keyvalue" format when neither option is specified
- Updates both usage strings and documentation with proper syntax formatting (fixed from v1)
- Includes tests verifying null-terminated output and option conflict behavior

The changes are straightforward and follow established Git conventions. Both mentors (Karthik Nayak and Patrick Steinhardt) have signed off on this version. The only remaining naming discussion in the series (regarding `references.format`) doesn't affect this particular patch.
