This is a feature patch series from GSoC contributor Lucas Seiki Oshiro, making two small but useful improvements to the experimental `git repo info` command. Both patches are now in their second version with mentor sign-offs and appear ready for merging.

The first patch adds a `-z` flag as shorthand for `--format=nul`, following Git's convention for null-terminated output seen in other commands like `git config` and `git status`. The patch includes proper documentation updates and test coverage.

The second patch adds a new field `object.format` (renamed from `objects.format` based on feedback) that reports the repository's object format (hash algorithm), equivalent to what `git rev-parse --show-object-format` would show. The implementation reads from `repo->hash_algo->name` and includes tests for both SHA-1 and SHA-256 cases.

The series has gone through review with several small fixes incorporated - notably fixing documentation formatting (adding spaces around the `|` in option syntax) and settling on the singular `object.format` field name for consistency with Git's existing `extensions.objectFormat` configuration. The patches now target `master` directly since their dependency (`lo/repo-info`) has been merged.

These are clean, focused additions that follow Git's conventions well. The only remaining open question from the thread is about aligning the naming of the `references.format` field with related configuration options, but that's outside the scope of these particular patches.
