Performance experiment exploring object flag storage via khash. Jeff King investigates moving object flags from direct struct fields to a khash-based storage system, motivated by ongoing discussions about data structure choices in Git's core.

The experiment uses a Coccinelle script to convert direct flag accesses to khash lookups, showing a 25% slowdown for `merge-base` operations and nearly 2x slowdown for `rev-list --objects --all`. These results suggest khash isn't suitable for high-frequency flag access patterns, though the implementation includes optimizations like combined get-and-set operations.

The patch demonstrates the technical feasibility but concludes the performance tradeoff isn't worthwhile for this use case. This contributes empirical data to the broader khash vs commit-slab discussion by testing a more extreme scenario than previous comparisons. The results reinforce that data structure choices must consider access patterns, with khash showing clear costs when used for pervasive low-level operations.
