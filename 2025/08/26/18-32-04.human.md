This is a feature patch adding a `-z` flag to `git repo info` as part of a GSoC project. The patch adds `-z` as a shorthand for `--format=nul`, bringing `git repo info` in line with other Git commands like `git-config` and `git-status` that use `-z` for null-terminated output. The implementation includes proper documentation updates, option conflict handling (preventing `-z` and `--format` from being used together), and new test cases.

This is the first of two patches in v2 of the series, with both Karthik Nayak and Patrick Steinhardt having signed off as mentors. The changes look clean and well-tested, following Git conventions. The only remaining naming discussion in the series (about `references.format`) doesn't affect this particular patch. The patch appears ready for merging.
