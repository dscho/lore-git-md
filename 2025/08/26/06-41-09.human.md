Refactoring patch in the `git refs exists` series. This is part 3 of 4 in Meet Soni's GSoC project to add a new `git refs exists` command that duplicates `git show-ref --exists` functionality under the refs namespace.

The patch reorganizes test infrastructure to share logic between the existing `show-ref --exists` tests and the upcoming `refs exists` tests. It moves the core test cases from `t1422-show-ref-exists.sh` into a new shared library `show-ref-exists-tests.sh`, replacing hardcoded `git show-ref` calls with a variable. The original test file becomes a minimal driver that sets up the variable and sources the shared tests.

This follows an established pattern for test sharing in Git and was suggested by mentor Patrick Steinhardt. The tests cover various ref scenarios including regular refs, HEAD, symrefs, special refs, and edge cases like bad refnames. The implementation looks clean and well-structured, with all technical feedback from previous versions addressed.

This appears to be the final test infrastructure preparation before adding the actual `refs exists` command tests in the next patch. The series is nearing completion with only minor style nits remaining.
