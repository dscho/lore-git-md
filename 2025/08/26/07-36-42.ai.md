Documentation patch for the `git refs optimize` series, extracting shared options documentation.

This is the second patch in a 5-part series introducing `git refs optimize` as a replacement for `git pack-refs`. The patch factors out the common options documentation from `git-pack-refs.adoc` into a new shared file `pack-refs-options.adoc`, which will be included by both the existing `git-pack-refs` documentation and the forthcoming `git-refs-optimize` documentation. The change is purely organizational - the rendered output remains identical.

The extracted options include `--all`, `--no-prune`, `--auto`, `--include`, and `--exclude`, along with their detailed descriptions and behavior notes. The patch maintains all existing documentation content while making it reusable for the new command. This follows the pattern established in the first patch which extracted the core packing functionality into a shared header file.

The change is straightforward and well-executed, with the documentation properly preserved in the new location. This prepares for the actual introduction of the new subcommand in subsequent patches while keeping the documentation DRY.
