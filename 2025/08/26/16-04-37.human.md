This is a build system fix addressing parallel build issues with Rust components.

The patch modifies the Makefile to ensure the `libgit-sys` and `libgit-rs` targets build serially rather than concurrently when `INCLUDE_LIBGIT_RS` is enabled. The change adds a `.WAIT` directive between the two targets, which enforces sequential execution.

The problem occurs when using parallel make (`make -JN`) with the Rust components enabled. Concurrent builds trigger cargo lock warnings and can cause linker errors, as both components internally invoke `cargo build` simultaneously. The issue stems from the nested make invocations within both `libgit-sys` and `libgit-rs` running at the same time.

The fix is straightforward and well-motivated, addressing a clear build system race condition. The patch is minimal (a one-line change) and appears to be the correct solution for the described problem. This would primarily affect developers building Git with Rust support enabled.
