This is a documentation patch updating Gmail SMTP configuration examples in `git-send-email.adoc` to reflect current security best practices. It's version 2 of the change, incorporating feedback from Junio C Hamano to explicitly reference RFC 8314 in the commit message.

The patch updates two configuration examples to use port 465 with SSL/TLS encryption instead of the previously recommended port 587 with STARTTLS. This change aligns with IETF's updated security recommendations in RFC 8314, which reverses their earlier position from RFC 2595. Both regular password and OAUTHBEARER authentication examples are modified, changing both the port number and encryption method while keeping all other aspects intact.

The diff shows straightforward replacements in the documentation examples, with `tls` becoming `ssl` and port `587` becoming `465` in both configuration blocks. The commit message now clearly cites RFC 8314 as the justification for this security recommendation update.

This appears ready for merging as a straightforward documentation improvement that brings Git's examples in line with current email security best practices.
