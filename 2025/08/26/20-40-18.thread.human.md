Post-merge discussion revealed that the implementation has evolved since 2013 to allow same-name pushes without upstream configuration in most cases, while still enforcing the original constraints for special remotes (like the default pull remote) and new branches.

The discussion demonstrates how the project balances technical accuracy about design intent with clear documentation of current behavior that has evolved through long-standing usage patterns.
