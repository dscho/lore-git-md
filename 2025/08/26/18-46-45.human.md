This is a documentation patch in Julia Evans' series improving the `git-checkout` man page. Junio Hamano provides a review of the first patch, which reorganizes the DESCRIPTION section to better present the two main modes (branch switching and file restoration).

Junio approves the overall approach, noting the rewrite conveys the same information more clearly. He suggests a few minor tweaks:
- Prefer "files from a different version" over "a different version of a file" to better indicate multiple files can be restored at once
- Replace "conflict" with "ambiguity" when describing the `--` disambiguator
- Clarify that pathspecs can include directories, not just files
- Questions whether the "Here's a description of all of the modes" line is necessary

The review maintains the patch's pedagogical improvements while tightening the technical precision. Junio's feedback focuses on making the text both accurate and accessible, consistent with the series' goals. The changes address specific points while preserving the overall structure and terminology alignment with `git switch`/`git restore`.
