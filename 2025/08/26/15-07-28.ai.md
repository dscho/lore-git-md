This is a documentation patch updating Gmail SMTP configuration examples in `git-send-email.adoc` to follow current security best practices. The patch is version 2, incorporating feedback from Junio C Hamano to more clearly reference RFC 8314 in the rationale.

The change switches the recommended Gmail SMTP configuration from port 587 with STARTTLS to port 465 with implicit SSL/TLS encryption. This reflects the updated IETF security recommendations in RFC 8314, which reversed the earlier RFC 2595 position favoring STARTTLS. Both regular password and OAUTHBEARER authentication examples are updated to use the new port and encryption method.

The v2 patch specifically improves the commit message to explicitly cite RFC 8314 as the justification for preferring port 465/SSL, addressing Junio's concern that the original phrasing was confusing. The technical changes remain focused on the documentation file, with no functional modifications to the code itself.

The patch is now properly motivated with the relevant RFC reference, making the rationale clear to readers. The change is limited in scope to the Gmail examples in `git-send-email.adoc`, suggesting low risk of unintended consequences.

Key technical details for future reference include: the specific file modified (`Documentation/git-send-email.adoc`), the port change (587->465), encryption method change (tls->ssl), and the authoritative reference (RFC 8314).
