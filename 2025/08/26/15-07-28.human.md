Documentation update for `git send-email` configuration with Gmail, now in its second version. This patch follows up on Junio C Hamano's review of the initial submission, incorporating his suggested improvements to the commit message.

The change updates Gmail SMTP configuration examples in `git-send-email.adoc` to recommend port 465 with SSL/TLS encryption instead of port 587 with STARTTLS. This reflects current IETF security recommendations from RFC 8314, which reverses the older RFC 2595 guidance. The new version explicitly cites RFC 8314 as the rationale for preferring implicit TLS (port 465) over STARTTLS (port 587).

The patch makes straightforward documentation changes, modifying two configuration examples to use port 465/SSL combination while keeping all other aspects identical. It affects both regular password and OAUTHBEARER authentication examples. The change appears well-justified by modern security practices, though there hasn't yet been broader discussion about potential backporting to older documentation versions.

This is a focused, non-controversial update that brings Git's documentation in line with current email security standards. The author has been responsive to review feedback, quickly producing a v2 that addresses the initial suggestions about commit message clarity.
