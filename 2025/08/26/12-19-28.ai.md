This is a documentation patch adding style guidelines for bit field formatting in the Git codebase. The patch formalizes the existing practice seen in `.clang-format` by adding explicit instructions to `CodingGuidelines` that bit fields should be written without spaces around the colon (e.g., `unsigned my_field:1;`).

The change discourages inconsistent alignment practices where spaces are used to visually align the colons across multiple declarations. The patch includes clear examples of both the preferred style and discouraged variations. Junio C Hamano is credited as a helper, suggesting this addition.

The patch is straightforward and uncontroversial, simply documenting existing practice rather than introducing new rules. It affects only `Documentation/CodingGuidelines` and doesn't require any code changes. The motivation is to provide clear guidance for contributors while maintaining consistency with the `.clang-format` configuration.
