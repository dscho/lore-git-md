This is Junio Hamano's monthly "What's cooking in git.git" status report, summarizing the state of development branches for August 2025. The report covers topics that have graduated to 'master', new topics under consideration, and ongoing work still in progress.

Several notable changes that have graduated to 'master' include:
- A new `git repo` subcommand for querying repository characteristics
- Removal of `the_repository` dependency in commit-graph code
- A `--max-depth` option for `git diff-tree`
- Various documentation and test improvements

New topics being proposed include:
- Documentation clarifications about GitGitGadget usage and Thunderbird configuration
- Fixes for progress meter delays and fetch race conditions
- Optimizations for line-log and describe operations
- A warning about the incomplete compatObjectFormat extension

Ongoing work includes:
- Further development of the `git repo` command with new fields and options
- Color configuration fixes for interactive add/stash
- Submodule path encoding improvements
- Multi-pack-index cleanups and optimizations
- A proposed `git last-modified` command for file history
- Deprecation of the problematic `core.commentChar=auto` setting

The report also notes several topics awaiting rerolls or further discussion before they can progress. As usual, Junio provides links to all source discussions and indicates which branches each topic will merge into next.
