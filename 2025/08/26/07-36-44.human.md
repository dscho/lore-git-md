Test refactoring for the `git refs optimize` series. This is patch 4/5 in a series introducing a new `git refs optimize` subcommand to replace `git pack-refs` as part of refs command consolidation.

The patch refactors the existing `t0601-reffiles-pack-refs.sh` test suite to make its logic shareable with the upcoming tests for `git refs optimize`. The core test logic is moved into a new `pack-refs-tests.sh` file, with hardcoded "pack-refs" calls replaced by a `$pack_refs` variable. The original test file becomes a simple driver that sets this variable and sources the shared library.

This follows the established pattern used for sharing tests between other ref-related commands and prepares for adding `refs optimize` tests in the next patch. The extensive test coverage (400+ lines) is preserved exactly, just reorganized for reuse.
