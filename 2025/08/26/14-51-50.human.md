Documentation update for `git send-email` configuration with Gmail, now with additional rationale from Junio C Hamano.

Junio responds to Aditya Garg's patch updating Gmail SMTP configuration examples in `git-send-email.adoc`. While agreeing with the technical change (switching from port 587/STARTTLS to 465/SSL), Junio critiques the commit message wording and provides a more thorough explanation. He notes that the original message's phrasing about "reflecting this change" was confusing since there was no prior change to reflect. 

Junio offers an improved commit message that explains the historical context: while RFC 2595 originally recommended STARTTLS, RFC 8314 now recommends "Implicit TLS" (port 465 with SSL) as more secure. The actual patch content remains unchanged - it still modifies two configuration examples in the documentation to use port 465 and SSL encryption instead of 587 and TLS, for both regular password and OAUTHBEARER authentication methods.

This appears to be a straightforward documentation improvement with clear technical merit, though the discussion highlights how commit message phrasing can impact understanding of even simple changes. The response suggests this will likely be accepted with the improved commit message.
