Feature patch series introducing `git refs exists` subcommand, version 3. This is the final version of Meet Soni's GSoC project to add a new subcommand that duplicates `git show-ref --exists` functionality under the modern `git refs` namespace.

The series now appears complete after addressing all technical feedback from previous rounds. Key changes in v3 are minor - reverting a commit message wording change and adding an empty line in test infrastructure. The implementation provides:
- A new `git refs exists` command with identical behavior to `show-ref --exists`
- Comprehensive test coverage through shared test infrastructure
- Full documentation including exit code specifications (0=exists, 2=missing, 1=error)
- Clean separation of test logic into reusable components

The test infrastructure has been carefully refactored to share core test cases between the old and new commands while maintaining isolation. The implementation uses `refs_read_raw_ref()` with the same error handling as show-ref, creating deliberate but minimal duplication of the existence-checking logic.

All substantive feedback from Patrick Steinhardt's review has been addressed, leaving only minor style nits in test formatting. The series builds on Git v2.51.0 with the prerequisite `ms/refs-list` branch merged. This appears ready for final review and potential merging as part of the ongoing refs command consolidation effort.
