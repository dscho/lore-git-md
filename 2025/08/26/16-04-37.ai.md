This is a build system fix addressing parallel build issues with Rust components.

The patch modifies the Makefile to enforce serial building of the `libgit-sys` and `libgit-rs` components when `INCLUDE_LIBGIT_RS` is enabled. Currently, parallel builds (`make -JN`) with these Rust components can trigger cargo lock warnings and linker errors due to concurrent inner make invocations in both libraries.

The solution adds a `.WAIT` directive between the two targets, ensuring `libgit-sys` completes before `libgit-rs` starts. This is a minimal change that addresses the reported build problems while maintaining the existing functionality. The commit message clearly explains the issue and solution, though it doesn't mention whether this was observed on specific platforms or build configurations.

The change affects the Rust integration build path, specifically the contrib/ area where these components live. While the fix is straightforward, it highlights an interesting interaction between Make's parallel builds and Cargo's build system when nested invocations occur.
