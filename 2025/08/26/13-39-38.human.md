Feature enhancement for `git send-email` with SMTP autoconfiguration. This is version 4 of a patch series that adds a `--get-smtp-server` option to automatically discover SMTP settings for a given email address, following Thunderbird's autoconfig model.

The patch implements a three-step fallback system: first checking the email provider's autoconfig URL, then Mozilla's ISPDB database, and finally falling back to MX record resolution for custom domains. It outputs complete SMTP configuration including server, port, encryption method, and supported authentication mechanisms (with explicit warnings about unencrypted connections). The documentation shows how to apply the discovered settings via git config commands.

Notable improvements in this version include fixing a typo in the suggested git commands (changing `sendmail.*` to `sendemail.*` to match actual config keys). The implementation remains thorough, adding 219 lines to the Perl script and 51 lines of documentation while maintaining compatibility with Thunderbird's autoconfig behavior.
