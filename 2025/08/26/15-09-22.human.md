This is a documentation patch updating the Gmail SMTP configuration examples in `git-send-email.adoc` to follow current security best practices. It's version 2 of a change that switches from recommending port 587 with STARTTLS encryption to port 465 with implicit TLS, based on IETF's RFC 8314 which supersedes the older RFC 2595.

The patch makes straightforward changes to two configuration examples in the documentation - one for regular password authentication and one for OAUTHBEARER. In both cases, it changes the port from 587 to 465 and the encryption method from `tls` to `ssl`. The commit message now explicitly cites RFC 8314 as justification, addressing feedback from Junio Hamano on the initial version.

This appears to be a well-motivated change that brings Git's documentation in line with current email security recommendations. The patch is focused and clearly explained, with no functional code changes needed since it only updates documentation examples. The version 2 iteration shows the commit message has been improved to better explain the security rationale behind the change.
