This is a feature patch series introducing a new `git refs optimize` subcommand as part of the ongoing effort to consolidate ref-related commands under the `git refs` namespace. The series comes from Google Summer of Code participant Meet Soni and proposes `git refs optimize` as a modern replacement for the standalone `git pack-refs` command. The work involves significant refactoring to share logic between the old and new implementations, including extracting core functionality into a helper and creating shared documentation for common parameters.

The patch set is well-structured, splitting the work into logical steps: first factoring out the core packing logic (patch 1), then documenting common options (patch 2), before introducing the new subcommand (patch 3). The test infrastructure also gets attention, with existing tests being refactored for reuse (patch 4) and new tests added specifically for the optimize subcommand (patch 5).

The changes touch several areas including documentation, builtin commands, and test infrastructure, with a net increase in code due to the new test files. The work appears thorough, with 400+ lines of new test coverage and careful attention to maintaining existing functionality while introducing the new interface. This looks like a solid contribution to the refs command consolidation effort.
