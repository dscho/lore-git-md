This thread introduces a new `git refs optimize` subcommand as part of an effort to consolidate ref-related commands under a common namespace. The series, submitted as a Google Summer of Code project, aims to replace `git pack-refs` with equivalent functionality under the new `refs` command hierarchy.

The initial patches refactored core packing functionality into a shared library and established the basic command structure. The latest patch focuses on test infrastructure, moving all pack-refs test cases into a shared file that can be reused for both the old and new commands. This maintains the existing 400+ lines of test coverage while making it available to verify the new `refs optimize` implementation. The series appears well-structured with thorough documentation and test coverage, following established patterns used for other ref command consolidations. So far only the author has participated, but the work looks ready for broader technical review.
