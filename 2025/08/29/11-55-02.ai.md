This is the second and final patch in Julia Evans' v4 documentation series improving the `git-add` man page, specifically focusing on simplifying the discussion of ignored files behavior. The patch represents the culmination of a well-reviewed effort to make the documentation more accessible while maintaining technical precision.

The changes streamline the explanation of how `git add` handles ignored files by:
1. Moving the `--force` option mention earlier in the paragraph for better visibility
2. Removing the potentially confusing distinction between shell globbing and Git's internal globbing system (which is covered more clearly in the EXAMPLES section)
3. Simplifying the language to clearly state the behaviors: silent ignoring by default, explicit failure when naming ignored files directly, and the `--force` override option

The patch maintains all the technical accuracy from the approved v3 version while making the text more approachable. The changes align with the series' overall goal of improving beginner accessibility through clearer language and better organization. This final patch completes the documentation improvements after multiple rounds of review and refinement, with all prior feedback incorporated.
