This is a CI/build system patch in the Rust support series, specifically adding Rust toolchain installation to Git's GitHub Actions workflows. It's patch 3 of 15 in the series introducing Rust to Git's xdiff subsystem.

The patch adds Rust installation to all CI jobs that will need it, handling platform-specific requirements: Windows needs Rust versions ≥1.78.0 and specific target triples (gnu for make, msvc for meson), musl builds require ≥1.72.0, and 32-bit Linux containers need explicit target specification. The implementation uses GitHub's actions-rs/toolchain where possible, falling back to custom scripts for Docker environments.

The changes are thorough, with new scripts (`install-rust-toolchain.sh` and `install-rustup.sh`) handling the installation logic, plus updates to existing CI scripts to ensure Rust is in PATH. The commit message clearly documents the platform-specific requirements and rationale, showing careful attention to cross-platform compatibility. This is a foundational piece of the larger Rust integration effort, ensuring the subsequent patches can be properly tested in CI.
