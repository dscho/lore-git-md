This thread introduces a 15-patch series to add Rust support to Git, specifically targeting the xdiff subsystem. The series builds on prior RFC feedback and is a collaboration between Ezekiel Newren (primary author), Johannes Schindelin, and brian m. carlson. 

The work establishes foundational infrastructure for Rust in Git, starting with a usage policy document and build system support. The technical work centers around a new interop vector type (ivec) that bridges C and Rust memory management, followed by xdiff internal cleanups to make the code more Rust-compatible. The series culminates in demonstrating the approach by translating one xdiff function (xdl_trim_ends()) to Rust while maintaining C compatibility.

Key aspects include careful memory management across language boundaries, build system changes to support Rust compilation (including Windows/Meson compatibility), and preparatory cleanups of xdiff data structures. The series appears well-structured with good test coverage, taking an incremental approach that maintains compatibility while paving the way for further Rust integration.
