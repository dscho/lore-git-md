This thread introduces Rust support to Git's xdiff subsystem through a 15-patch series led by Ezekiel Newren, with contributions from Johannes Schindelin and brian m. carlson. The series takes a careful, incremental approach - first establishing policy and build infrastructure before tackling the actual implementation. The policy document (now required reading for platform support) makes a strong case for Rust adoption while setting conservative constraints around version support and dependency management.

The build system changes are thorough, adding Rust compilation support through both Makefile and Meson while handling platform-specific quirks like Windows library naming and 32-bit Linux environments. A recent patch addressed Windows compatibility in Meson builds by adding the `userenv` system library dependency. The latest addition (patch 5/15) enhances CI by collecting Cargo.lock files as build artifacts across different platforms, providing traceability for dependency resolution while still avoiding committed lockfiles as per the series' policy.

The series is methodically working through the technical foundation, with upcoming patches planned to implement core interoperability types before demonstrating the approach by translating xdl_trim_ends() to Rust. While this represents significant progress in Git's Rustification effort, the work remains focused on xdiff as a non-critical path to minimize disruption. No reviews or objections have been noted yet in what appears to be the first submission of this non-RFC version.
