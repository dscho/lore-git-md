This is a major patch series introducing Rust support to Git, specifically targeting the xdiff subsystem. The series builds on previous RFC discussions and removes the RFC label, indicating it's ready for serious review.

The 15-patch series starts by adding a Rust usage policy document (from brian m. carlson), then introduces Rust infrastructure including CI support. The core technical work involves:

1. Creating an interop vector type (`ivec`) that works across C and Rust boundaries
2. Cleaning up xdiff internals to make them more Rust-friendly
3. Translating the `xdl_trim_ends()` function from C to Rust as an initial proof of concept

Key technical components include:
- A new `ivec` type that handles memory management consistently between C and Rust
- CI updates to build and test Rust code
- Xdiff internal cleanup removing redundant fields and simplifying data structures
- The first actual Rust translation of an xdiff function

The series shows careful attention to cross-language compatibility, with changes to avoid C++ name mangling and thorough testing of the interop vector implementation. Build results from GitHub Actions are provided, showing the changes work across platforms.

This represents a significant step toward Rust integration in Git, focusing first on a well-contained subsystem (xdiff) while establishing patterns for future Rust work. The approach appears methodical, starting with infrastructure and cleanup before introducing Rust code.
