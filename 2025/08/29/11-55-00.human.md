Documentation patch series refining the `git-add` man page descriptions. This is version 4 of Julia Evans' ongoing effort to improve clarity and beginner-friendliness in Git's manual pages, specifically focusing on the DESCRIPTION section of `git-add`.

The series consists of two small but meaningful tweaks to the v3 version that was already reviewed and approved by Junio Hamano. The main change is a subtle but important rewording of the first sentence describing the index/staging area - replacing "where Git stores" with "what you use to prepare" to better emphasize user agency in the commit process. The second patch carries forward the simplified discussion of ignored files behavior from v3 unchanged.

These final refinements come after extensive earlier iterations that restructured the entire DESCRIPTION section to be more example-driven, removed redundant explanations, and clarified the relationship between the index and staging area. The v4 changes are minimal but appear to be thoughtful improvements to wording based on the maintainer's earlier feedback. With Junio having already approved the substantial changes in v3, this version seems poised for merging once the minor base version discrepancy (v2.50.0 vs v2.51.0) is resolved via rebase.
