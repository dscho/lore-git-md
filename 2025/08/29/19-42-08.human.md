Platform compatibility patch for Windows builds with Rust integration. This is part 4 of the 15-patch series introducing Rust support to Git's xdiff subsystem.

The patch addresses a Windows-specific linking issue that arises when building with Rust support under Meson. The Rust standard library's `std::env::home_dir()` function requires `GetUserProfileDirectoryW` from the Windows `userenv` library, which wasn't previously linked. The solution mirrors the Makefile approach by adding `-luserenv` to the linker flags in both Meson and Makefile builds.

For CI, the patch includes a workaround to ensure `libuserenv.a` is available in the Git for Windows environment, downloading it if missing. This is a temporary measure until the library is properly included in the minimal Git for Windows SDK. The change is straightforward and necessary for the Rust xdiff work to build successfully on Windows, showing careful attention to platform-specific requirements in the broader Rust integration effort.
