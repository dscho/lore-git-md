This is patch 6/15 in the Rust integration series, introducing a new interoperable vector type (`ivec`) for C/Rust FFI. The patch creates a vector implementation that can be safely used across language boundaries, addressing key challenges in memory management and growth patterns between C and Rust.

The `ivec` type provides a common interface for vector operations that works identically in both languages, avoiding the need for wrapper functions when passing vectors between C and Rust. It handles memory allocation consistently (using the same allocator on both sides) and includes safety checks like element size validation. The implementation includes standard vector operations (push, reserve, resize, etc.) and maintains Rust's ownership semantics while being usable from C.

The patch adds both C and Rust implementations (in `interop/ivec.{c,h}` and `rust/interop/src/ivec.rs` respectively) along with comprehensive test coverage. The Rust version implements standard traits like `Index`, `Debug`, and `Drop` to feel native to Rust code, while the C version provides equivalent functionality through plain functions. Build system changes integrate the new files into both Makefile and meson builds.

This foundational piece enables the subsequent patches in the series to safely share data structures between C and Rust code, particularly for the xdiff conversion work that follows. The careful attention to memory safety and allocation patterns reflects the series' overall focus on secure, incremental Rust adoption.
