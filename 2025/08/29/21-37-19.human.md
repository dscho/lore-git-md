This is Junio Hamano's monthly "What's cooking in git.git" status update, summarizing recent activity in the Git project. The email provides a categorized overview of changes that have graduated to the main branches, new topics under consideration, and ongoing work that's still needs review or revision.

Several documentation updates have been merged, including fixes for `git rebase` and `git add` manpages, a note about the experimental nature of `extensions.compatobjectformat`, and adding Discord as a help resource for new contributors. Notable bugfixes address issues with `git describe` on blobs, `git fetch` race conditions, and dangling symref handling.

New topics proposed include Rust integration work for xdiff library, memory limits for `git range-diff`, lazy index expansion for `git ls-files`, and updates to the deprecated `git whatchanged` command's messaging. The email also highlights ongoing efforts like sparse checkout improvements, multi-pack-index optimizations, and the deprecation of `core.commentChar=auto`.

The update follows Junio's standard format, with '+' marking stable changes in 'next' and '-' indicating experimental work in 'seen'. Many topics are marked as waiting for review responses or needing rerolls, showing the project's active development cycle. The email serves as both a technical summary and an invitation for community feedback on pending changes.
