This is the third patch in a series implementing a standardized deprecation process for `git whatchanged`. The patch makes a minor documentation tweak to the deprecation warning message, removing the now-redundant point about typing length (since the previous patch already added the preferred alternative command `git log --raw --no-merges`).

The change is straightforward - it simplifies the warning message by dropping the "not even shorter to type" comparison, which was made obsolete by the addition of the full alternative command in patch 3. The wording also changes from "default" to "defaults" to better reflect that there are multiple default behavior changes between the commands.

This is part of a well-reviewed series that has maintainer approval and is ready for merging. The patch follows the established three-step deprecation pattern (notice/alternatives/contact) and maintains consistency with the broader effort to improve how Git handles breaking changes. The change is small but contributes to the overall goal of providing clear guidance for users transitioning away from deprecated commands.
