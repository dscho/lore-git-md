This is a CI/build system patch in the Rust support series, specifically addressing dependency auditing. 

Patch 5/15 modifies GitHub Actions workflows to upload the Cargo.lock file as a build artifact for each CI job. This change enables better dependency tracking and auditing of Rust build dependencies across different platforms and build configurations (Windows, Meson, etc.). The patch adds consistent artifact upload steps for all relevant jobs, using platform-specific naming (e.g., cargo-lock-windows, cargo-lock-windows-meson).

The change is straightforward and aligns with the series' focus on careful dependency management - a key principle established in the Rust adoption policy from earlier patches. While the patch itself is simple, it serves an important governance function by making build dependencies visible and auditable, which will be valuable as more Rust code is added to Git. The implementation looks clean, with consistent patterns applied across all CI jobs that involve Rust compilation.
