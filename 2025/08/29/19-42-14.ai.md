This is a refactoring patch in the Rust xdiff integration series, specifically addressing memory management in the xdiff subsystem. Patch 10/15 consolidates cleanup logic by moving the xdfile_t freeing code into a single xdl_free_ctx() function and using it consistently throughout xprepare.c.

The key change moves the xdl_free_ctx() definition before its first use in xdl_prepare_ctx(), then replaces the manual cleanup of individual fields (ha, rindex, rchg, recs, rcha) with calls to this unified function. The patch eliminates 36 lines of repetitive cleanup code while maintaining identical behavior, making error handling more maintainable and reducing the chance of leaks if the cleanup sequence changes.

This is a mechanical change that doesn't affect functionality but improves code organization as part of the broader Rust preparation work. The patch follows the series' pattern of incremental, non-disruptive refactoring before introducing Rust components. It touches only xdiff/xprepare.c, with no impact on tests or build system.
