This is part 9/15 of the series introducing Rust support to Git's xdiff subsystem, focusing on making xdiff data structures more Rust-friendly. The patch standardizes type usage in xrecord_t and related code to align with Rust's stricter type system, changing several fields to use Rust-compatible types like `u64` and `usize`. It also adds necessary casts when passing these values to existing C functions.

The changes are mechanical but important for interoperability:
- xrecord_t's fields are updated to use Rust types (`u8 const* ptr`, `usize size`, `u64 ha`)
- xdlclass_t's `ha` field is changed to `u64` to match xrecord_t
- Numerous casts are added when passing these values to existing C functions that expect different types

The patch follows Johannes Schindelin's suggestion to align the hash field types, and includes his Helped-by tag. While the changes are straightforward, they touch many files (7 in total) with small but widespread adjustments to function calls and type usage. This is part of the incremental preparation work before introducing actual Rust code in later patches.
