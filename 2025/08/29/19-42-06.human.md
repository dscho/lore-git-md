This is the second patch of a 15-part series introducing Rust support to Git's xdiff subsystem. The patch lays the build system groundwork for Rust integration, following the policy established in patch 1.

The changes focus on build infrastructure: adding Rust build rules to Makefile and meson.build, creating a build_rust.sh helper script, and setting up initial Rust crate structure with xdiff and interop crates. The patch also adds Rust primitive type definitions to git-compat-util.h for C/Rust interoperability. The build system is designed to let Cargo handle Rust compilation while Make/meson link the resulting libraries.

The implementation appears carefully considered, with attention to platform differences (notably Windows/MSVC support) and build modes (debug vs release). The patch maintains the project's existing build approaches while cleanly integrating the new Rust components. As this is foundational work for the larger Rustification effort, the actual xdiff functionality will come in later patches.
