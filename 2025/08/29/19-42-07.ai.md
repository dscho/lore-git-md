This is a CI/build system patch in the Rust support series, specifically handling Rust toolchain installation in GitHub workflows. It's patch 3/15 in the series that introduces Rust to Git's xdiff subsystem.

The patch adds Rust toolchain setup to Git's GitHub Actions CI, with special handling for Windows, musl, and 32-bit Linux environments. It introduces two new scripts (install-rust-toolchain.sh and install-rustup.sh) that handle version-specific installations, with minimum version requirements: 1.61.0 baseline, 1.78.0 for Windows (due to bcrypt library resolution), and 1.72.0 for musl (for libc compatibility). The Windows builds require different target triples for make (x86_64-pc-windows-gnu) versus meson (x86_64-pc-windows-msvc) builds. The 32-bit Linux container case needs explicit target triple override (i686-unknown-linux-gnu) since rustup misdetects the host architecture.

The implementation shows careful attention to platform-specific quirks and maintains the series' policy of conservative version requirements. It consolidates Rust toolchain definitions in main.yaml while allowing per-job overrides. The patch includes cleanup steps to remove Rust toolchains after builds complete. Johannes Schindelin contributed to the initial library name selection logic which was reworked into this commit. The changes touch workflow files and add new installation scripts while modifying existing CI scripts to ensure Rust is in PATH.
