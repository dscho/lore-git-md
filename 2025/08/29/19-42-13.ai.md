Refactoring patch in the xdiff Rust integration series, focusing on type alignment for C/Rust interoperability.

This patch (9/15) modifies xdiff data structures to use Rust-compatible types, continuing the preparatory work for Rust integration. It changes several fields in xrecord_t and related code to use Rust primitive types (u8, usize, u64) that were introduced in earlier patches. The key changes include:

1. Converting xrecord_t's ptr field from `char const*` to `u8 const*` and size from `long` to `usize`
2. Making xdlclass_t::ha field consistently u64 to match xrecord_t::ha (as noted by Johannes Schindelin)
3. Adding necessary casts throughout xdiff code where pointer types now differ (char* vs u8*)

The changes are mechanical but widespread, touching 7 files with 22 line changes. The patch maintains existing behavior while making the code more amenable to Rust interop. The casts introduced are expected to be temporary until more Rust integration is complete. This follows the series' incremental approach of first preparing the C code before introducing Rust components.
