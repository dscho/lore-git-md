This is the second patch of a 15-part series introducing Rust support to Git's xdiff subsystem. The patch focuses on build system integration and infrastructure setup.

The patch makes several key changes to enable Rust compilation:
1. Adds Rust build infrastructure with a new `build_rust.sh` script that handles debug/release builds and platform-specific library naming
2. Updates Makefile and meson.build to integrate Rust compilation, linking the static libraries produced by Cargo
3. Introduces basic Rust type definitions in git-compat-util.h for C/Rust interop
4. Sets up a Rust workspace with two initial crates: `xdiff` (the focus of this series) and `interop` (for future work)
5. Adds proper clean targets and ignores for Rust build artifacts

The changes follow the Rust adoption policy established in patch 1, using static linking and avoiding C-compatibility crates. The build system modifications ensure Rust compilation happens as part of the normal build process, with debug/release modes matching the C build configuration. The patch lays groundwork for subsequent patches that will actually port xdiff functionality to Rust while maintaining C callability.

Key technical details for future reference:
- New files: build_rust.sh, rust/{Cargo.toml,interop/,xdiff/}
- Modified files: .gitignore, Makefile, git-compat-util.h, meson.build
- Rust types exposed to C: u8/u16/u32/u64, i8/i16/i32/i64, f32/f64, usize/isize
- Build integration points: compile_rust target, RUST_BUILD_MODE, EXTLIBS
- Platform handling: different library naming for Windows (.lib) vs Unix (.a)
