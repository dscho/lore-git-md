This is the first patch in a v2 series improving guidance for users of deprecated Git commands, specifically focusing on `git whatchanged`. The patch implements a structured three-step deprecation message pattern that was formally endorsed by the maintainer after review feedback.

The patch modifies the `you_still_use_that()` helper in `usage.c` to provide more helpful guidance when users attempt to run deprecated commands. Instead of just telling users to email the mailing list, it now offers: (1) a link to the BreakingChanges documentation, (2) a pre-filled search of the mailing list archives, and (3) an invitation to contact the list only if no suitable replacement is found. The implementation uses `strbuf_add_percentencode` to generate proper URLs for command-specific searches.

This version incorporates all maintainer feedback from the v1 discussion, including Eric Sunshine's suggested wording for the contact prompt and proper URL formatting. The patch is part of a broader effort to establish consistent deprecation messaging, with this particular case distinguished from the `pack-redundant` deprecation approach. The series appears ready for merging with all design elements confirmed.
