This is a cover letter for a CI/build system patch series completing the Meson build system integration for Git. The series wires up support for building gitk and git-gui through Meson, marking the final step for feature parity with the Makefile-based build.

The series consists of three patches: the first two move git-gui and gitk into a new "subprojects/" directory (with all their files preserved), while the third adds the Meson build rules to compile and install them. The changes are largely mechanical file moves with some build system adjustments, including updates to documentation references and the main meson.build file. 

Patrick Steinhardt notes this completes the Meson build system functionality, proposing that Git could now officially endorse Meson as a supported build method after this series is merged. He plans follow-up documentation updates to reflect this. The implementation builds on prior upstream work in gitk and git-gui that added Meson support to those projects.

Key technical details include the new meson_options.txt entries for Tcl/Tk components, the subprojects/.gitignore addition, and the preservation of all localization files during the moves. The changes touch build infrastructure rather than core Git functionality, with the main behavioral impact being that gitk and git-gui will now be built through Meson when that build system is used.
