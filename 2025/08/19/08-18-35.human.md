Build system refactoring for Meson integration. This is the first of three patches moving git-gui into Git's subprojects/ directory to enable proper Meson subproject integration.

Patrick Steinhardt explains that while git-gui already supports Meson builds, it currently lives in the root directory which prevents using Meson's `subproject()` function. The patch evaluates three options (moving files, symlinks, or wrap files) and settles on physically relocating git-gui to subprojects/ as the most robust solution despite the one-time churn.

The change updates paths in the main Makefile and documentation while preserving all git-gui files exactly as-is - the diff shows 89 files being moved with no content changes. This mechanical relocation is part of a larger effort to achieve feature parity between Makefile and Meson builds, with follow-up patches expected to handle gitk similarly.

The patch appears well-considered, with clear rationale and minimal risk since it only moves files without modifying their contents. The change is backward compatible as both build systems will continue working, just with git-gui in a new location.
