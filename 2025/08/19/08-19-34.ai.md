This is part 5 of Patrick Steinhardt's ongoing refactoring series to move packfile management into a dedicated `struct packfile_store` as part of the object database (ODB) abstraction effort.

The patch relocates the Most-Recently-Used (MRU) list of packfiles from `struct object_database` to `struct packfile_store`. The MRU list helps optimize object access by prioritizing packfiles that have been recently used. The changes involve:
- Moving the `packed_git_mru` list head from ODB to `packfile_store`
- Updating all MRU list operations to use `store->mru` instead of `objects->packed_git_mru`
- Initializing the MRU list in `packfile_store_new()`
- Removing MRU-related code from ODB initialization/cleanup

The patch follows the established pattern of the series by moving packfile-specific state out of the generic ODB structure while maintaining identical behavior. Changes affect midx.c, odb.c/h, and packfile.c/h, with straightforward mechanical updates to all MRU list references. This continues the groundwork for making packfile management implementation-specific in the ODB abstraction.
