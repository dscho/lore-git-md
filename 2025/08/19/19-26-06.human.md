This is a test cleanup patch in a series addressing dangling symref behavior in `git fetch`. 

Jeff King continues the test modernization work in t5510-fetch.sh by eliminating global working directory changes. The patch converts tests that used bare `cd` commands (which affected subsequent tests) to use subshells or `git -C` instead, following Git's preferred style of keeping tests isolated. This allows removing numerous `cd $D` calls and the now-unused `$D` variable entirely.

The changes are mechanical but thorough, touching nearly every test in the file. The patch maintains all test functionality while making the tests more robust by preventing accidental state leakage between them. One test is updated to use `$(pwd)` for Windows path compatibility when the exact path format matters.

This is patch 2/4 in a series that will ultimately fix how `followRemoteHEAD=create` handles dangling symrefs. The test cleanups here pave the way for the later behavioral fixes by making the test environment more predictable. The changes look solid and follow established patterns seen in other test modernizations.
