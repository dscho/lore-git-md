Reftable fsck validation series (v4, 7 patches) - refined stack integrity checks for reftable backend. Authored by Karthik Nayak, this iteration continues strengthening validation while maintaining core design principles. Key structural changes from v3 to v4 include removal of redundant update index validation, narrowed table name validation scope, and non-fatal naming convention warnings. The series introduces `reftable/fsck.[ch]` with reftable-specific error codes mapped to fsck messages.

Technical refinements in v4:
1. `parse_names()` in basics.c now enforces trailing newline requirement in 'tables.list' (patch 3/7), using output parameter pattern for error handling
2. Original improvements retained: direct error returns, strengthened `strtoull()` handling, preserved lexicographic ordering
3. Comprehensive test coverage in `t0614-reftable-fsck.sh` expanded with new edge cases
4. Documentation updates in `fsck-msgids.adoc` maintained, including removal of duplicate `gitmodulesLarge` error message definition (patch 4/7)
5. Patch 5/7 alphabetically sorts the `fsck_msg_type` enum in fsck.h, organizing error, warning, and info message types without changing behavior
