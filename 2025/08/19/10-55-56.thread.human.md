Here's a human-readable summary of the current state of the `git-history` thread:

Patrick Steinhardt's proposal for a new `git-history` command (inspired by Jujutsu's history editing capabilities) has reached its third RFC version with eighteen patches. The command would provide subcommands like `drop`, `reorder`, and `split` for modifying commit history, along with management commands like `abort` and `continue`. The implementation is progressing with refinements from reviewers, particularly Phillip Wood, who has helped simplify the `skip_commit_summary` flag and improve the `split` subcommand to allow editing both resulting commits' messages.

A key debate has emerged around the command architecture - whether to use subcommands (Patrick's preference) or separate atomic commands (advocated by Oswald Buddenhagen). Oswald argues subcommands create arbitrary boundaries and documentation inconsistencies, while Patrick maintains they improve discoverability while allowing aliases for separate commands.

The technical discussion has deepened with SZEDER Gábor raising important questions about the `drop` subcommand's behavior when dealing with complex commit graphs. The proposal currently follows Jujutsu's approach of automatically rebasing descendants and repointing branches (including HEAD) when dropping a commit, which could have wide-ranging effects. SZEDER's example with four intersecting branches highlights the need to carefully consider the safety and predictability of such operations.

Junio has noted a practical merge delay due to potential conflicts with Jeff King's parallel work on add-i colors. Patrick plans to resolve these conflicts before sending a final RFC version, then split the series after implementing `reorder`. The `reword` subcommand will be dropped from this series as Phillip Wood identified the functionality already exists in the sequencer.

The discussion remains productive, balancing technical implementation concerns with user experience considerations, as the project works toward a flexible yet safe history editing tool.
