This is patch 6/16 in Patrick Steinhardt's series refactoring Git's packfile subsystem as part of the object database (ODB) abstraction effort. The patch moves the "kept pack" cache from `struct object_database` to the new `struct packfile_store`.

The kept pack cache is used by `git pack-objects` to handle cruft objects (unreachable objects kept around for safety). The patch follows the series' pattern of relocating packfile-specific state from the generic ODB structure to the dedicated packfile store. Changes include moving the cache structure and updating all related functions to reference the new location.

The diff shows straightforward mechanical changes across odb.h, packfile.c, and packfile.h, with the cache now living in `packfile_store->kept_cache`. The patch maintains identical behavior while continuing the architectural separation between generic ODB functionality and packfile-specific implementation details.

This is another incremental step in the larger effort to make packfile management implementation-specific in preparation for pluggable ODB backends. The changes appear carefully implemented with thorough updates to all affected code paths.
