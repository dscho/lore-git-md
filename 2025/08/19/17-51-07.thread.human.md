Randall Becker has now weighed in on the technical side, suggesting a practical workaround for `git whatchanged` users: creating a global alias that maps `whatchanged` to `log` (via `git config --global alias.whatchanged 'log'`). This would let users maintain their workflow while preparing for a potential future removal of the command, though no such removal is currently planned. The suggestion is straightforward and avoids the need for code changes to Git itself.
