This is patch 6/16 in Patrick Steinhardt's series refactoring Git's packfile management into a dedicated `struct packfile_store`. The patch moves the "kept pack cache" (used by `git pack-objects` for handling cruft objects) from `struct object_database` to the new store structure.

The change is straightforward - it relocates the `kept_pack_cache` struct and its associated fields while maintaining the same functionality. Junio Hamano questions whether this cleanup should have been done in the initial patch that introduced `packfile_store`, since it removes the last piece of "private data" mentioned in the ODB header comment.

This continues the series' pattern of incrementally moving packfile-related state out of the generic object database structure. The patch touches three files with minimal code changes (14 lines added, 16 removed), keeping the same behavior while improving the code organization. The series has maintainer approval in principle, with ongoing discussion about specific implementation choices.
