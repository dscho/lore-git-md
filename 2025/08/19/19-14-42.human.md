This is a documentation patch clarifying the remote repository options for Git contributors. Daniele Sassoli points out that while the contribution guide mostly references the main git/git repository, the section about sending PRs to GitGitGadget only mentions gitgitgadget/git without explaining alternatives.

The patch updates MyFirstContribution.adoc to explicitly state that contributors can use either gitgitgadget/git or git/git as their remote, with a note about the different PR creation process for each. It also adds a link to GitGitGadget's documentation explaining the differences between the two options.

This is a straightforward documentation improvement that helps new contributors understand their options when setting up their workflow. The change is small but useful, addressing a potential point of confusion in the contribution process. The patch includes a clear explanation of the problem and solution in the commit message.
