Refactoring of test cleanup in t5510-fetch.sh. This is a follow-up discussion to Jeff King's patch 1/4 in the dangling symref fix series, focusing on alternative approaches to cleaning up the test directory structure.

Eric Sunshine shares an alternative approach he had previously developed (from an unsent patch series) that eliminates all top-level directory changes in t5510-fetch.sh by:
1. Removing the global `D=$(pwd)` variable
2. Wrapping all test operations that need directory changes in subshells
3. Using `$(pwd)` instead of `$D` for path references
4. Simplifying `test_when_finished` cleanup paths to be relative to $D

The changes are more extensive than Jeff King's targeted config cleanup (123 lines changed: 1 line in Jeff's patch vs 47 insertions/76 deletions in Eric's approach). The patch shows consistent application of the subshell pattern across all fetch test cases, including atomic fetch tests, prune tests, and bundle operations.

Key technical differences from Jeff's approach:
- Eliminates all top-level directory changes rather than just fixing config cleanup
- Uses subshell isolation more aggressively than the series' current patches
- Maintains Windows compatibility through consistent path handling
- Changes path references in test assertions and cleanup

This suggests an alternative direction for modernizing t5510-fetch.sh that could be considered alongside or instead of the current incremental approach in the series. The discussion may influence how subsequent patches (particularly 2-3/4) handle test modernization.
