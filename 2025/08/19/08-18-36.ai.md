This is the second patch in a three-part series moving Git's build system components to support Meson, specifically focusing on gitk. Following the same pattern as the first patch for git-gui, Patrick Steinhardt moves gitk into the subprojects/ directory to satisfy Meson's subproject requirements. The patch also drops the "-git" suffix from the directory name, noting there was no clear reason for its existence.

The changes are mechanical but widespread, affecting 27 files. The bulk of the diff shows file renames from gitk-git/ to subprojects/gitk/, with no content modifications. Key build system updates include:
- Makefile adjustments to reference the new location
- Documentation updates in SubmittingPatches and gitk.adoc
- Addition of gitk/ to subprojects/.gitignore

The patch maintains all existing functionality while preparing for Meson integration. Like the git-gui change, this is a prerequisite for the final patch that will add Meson build rules. The move follows the same rationale as the first patch - choosing directory relocation over symlinks or wrap files for robustness and Windows compatibility. No runtime behavior changes are introduced by this patch.
