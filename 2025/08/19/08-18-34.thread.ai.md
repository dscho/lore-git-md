This thread introduces a patch series completing Meson build system integration for Git by adding support for building gitk and git-gui. The series consists of three mechanical patches moving git-gui and gitk into a new subprojects/ directory while preserving all files, then adding corresponding Meson build rules. Key changes include new meson_options.txt entries for Tcl/Tk, subprojects/.gitignore updates, and documentation reference fixes. Patrick Steinhardt proposes this marks feature parity with the Makefile build, suggesting Git could officially endorse Meson after merging. The implementation builds on prior Meson support work in gitk/git-gui and touches only build infrastructure - no core Git functionality is affected. Steinhardt notes follow-up documentation updates will be needed to reflect Meson's new status. The main user-visible change is gitk/git-gui being built via Meson when that build system is used.
