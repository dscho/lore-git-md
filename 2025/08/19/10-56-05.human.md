This is a refactoring patch in Patrick Steinhardt's RFC series introducing a new `git-history` command. It continues the work of separating the interactive patch machinery from its original `add-interactive` implementation.

The patch removes `add-patch.c`'s dependency on `add-interactive.h` by directly embedding the interactive configuration structure (`struct interactive_config`) rather than inheriting it through `struct add_i_state`. This follows from the previous patch (08/11) which split out the interactive configuration into its own module.

Key changes:
- Replaces `struct add_i_state` with direct `struct repository*` and `struct interactive_config` members
- Updates all color output and configuration access to use the new direct references
- Modifies initialization to call `interactive_config_init()` directly rather than through `init_add_i_state()`

The changes are mechanical and focused - just updating references to use the new structure rather than changing behavior. This continues the series' pattern of incremental refactoring to support the new history editing commands while cleaning up the underlying code structure.

The patch appears well-contained and builds on the preparatory work done earlier in the series. Since it's part of a larger RFC, the real test will be how these changes hold up when the full `git-history` functionality is exercised, but this step looks like a straightforward improvement to the code organization.
