Update on Jenkins plugin migration from deprecated `git whatchanged``. Mark Waite reports successful progress in updating the Jenkins Git client plugin to stop using the deprecated command. The changes are described as simple with positive test results, and a new plugin version is expected within the week. This follows Junio Hamano's earlier confirmation that `git whatchanged` will be removed in Git 3.0 (with no set release date) and that the `--i-still-use-this` flag is only temporary. The thread shows the deprecation policy in action - a major project is successfully migrating away from deprecated functionality well ahead of its eventual removal. No technical details are provided about the replacement approach, though `git log --raw` was previously suggested as the likely alternative.
