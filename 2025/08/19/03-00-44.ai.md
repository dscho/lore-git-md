Update on Jenkins plugin migration from deprecated `git whatchanged``. Mark Waite reports successful progress in updating the Jenkins Git client plugin to stop using the deprecated command. The implementation appears straightforward with positive test results, and a new plugin release is expected within the week. This follows Junio Hamano's earlier confirmation that the deprecation timeline remains unchanged, with `git whatchanged` slated for removal in Git 3.0 (date still unspecified). The plugin is switching to `git log --raw` with appropriate options as the replacement path. This email serves as a positive status update showing the deprecation policy working as intended, with affected projects making timely transitions before the eventual command removal. No technical obstacles or concerns are reported in the migration process.
