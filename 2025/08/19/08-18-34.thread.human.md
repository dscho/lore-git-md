This thread documents Patrick Steinhardt's ongoing effort to integrate Git's GUI components (gitk and git-gui) with the Meson build system, with a particular focus on resolving Windows-specific challenges. The discussion has progressed through architectural decisions (initially considering directory relocation before settling on a symlink-based approach) to practical implementation issues uncovered during testing.

The current sticking point involves Windows CI failures due to a missing `msgfmt` tool (part of gettext) in GitHub Actions environments. Patrick has already addressed this by making the dependency optional in the gitk repository (matching the Makefile's behavior) and is now determining how to incorporate this fix into Git's main repository. The symlink approach itself has been validated on Windows, with remaining work focusing on final path handling and shell quoting issues.

Key participants include Patrick (driving the implementation), Karthik Nayak (reviewing the technical approach), Junio Hamano (raising Windows symlink concerns), Ramsay Jones (identifying libexecdir issues), and Jeff King (who originally reported the CI failure). The thread shows steady progress toward completing this build system modernization, with Windows compatibility being systematically addressed through fixes like the optional `msgfmt` handling.
