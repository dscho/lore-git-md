This thread follows Patrick Steinhardt's effort to integrate Git's GUI components (gitk and git-gui) with the Meson build system, which has progressed through several iterations. The initial approach involved physically relocating the source directories, but after feedback from Junio Hamano about build systems dictating source structure, v2 switched to a symlink-based solution that preserves the original layout while meeting Meson's requirements.

Karthik Nayak has been actively reviewing the patches, catching minor issues like typos and now confirming in v2 that the conditional build behavior (disabling when Tcl/Tk tools are missing) matches the Makefile's approach. The symlink workaround appears technically sound, though Nayak notes Meson might eventually support configurable subproject paths that could eliminate this indirection. Ramsay Jones earlier identified two outstanding issues - libexecdir path handling and shell quoting problems - that still need resolution before the changes are production-ready.

While the technical implementation has largely converged between Steinhardt and Nayak, Junio's broader architectural concerns about build system influence remain an open discussion point. The documentation updates regarding gitk's history and maintenance (now handled by Johannes Sixt) have already been merged separately. The path forward now focuses on addressing the remaining practical hurdles Jones identified.
