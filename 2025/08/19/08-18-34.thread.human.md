Patrick Steinhardt has completed a three-patch series integrating Git's Tcl/Tk-based GUI tools (gitk and git-gui) into the Meson build system. The first two patches relocated git-gui and gitk into subprojects/ to satisfy Meson's requirements while maintaining all functionality, with careful attention to Windows compatibility. The final patch, just submitted, adds the actual Meson build rules for these components.

The changes introduce new build options in meson_options.txt and maintain the same conditional behavior as the Makefile system - gitk and git-gui will build automatically if their Tcl/Tk dependencies (tclsh and wish) are present. The implementation checks for these dependencies and gracefully disables the components when they're missing, matching the existing behavior. This completes a significant step toward full feature parity between Meson and Makefile builds.

While purely an infrastructure change with no runtime impact, this work will require follow-up documentation updates to reflect Meson's new status as a fully-supported build option. The series demonstrates careful attention to maintaining existing behavior while modernizing the build system, with all GUI functionality preserved exactly as it was under the traditional Makefile approach.
