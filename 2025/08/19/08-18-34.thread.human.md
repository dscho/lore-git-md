This thread introduces a patch series that completes the Meson build system integration for Git by adding support for building gitk and git-gui through Meson. The series, proposed by Patrick Steinhardt, consists of three mechanical patches that move git-gui and gitk into a new "subprojects/" directory while preserving all their functionality, then wire up the Meson build rules. 

The changes mark the final step for feature parity between Meson and the traditional Makefile-based build system. Patrick notes this could allow Git to officially endorse Meson as a supported build method after merging. The implementation builds on prior work that added Meson support to gitk and git-gui themselves. Key technical aspects include updates to meson_options.txt for Tcl/Tk components and careful handling of localization files during the moves. Patrick plans follow-up documentation updates to reflect Meson's new status once this series lands.
