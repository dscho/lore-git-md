Patrick Steinhardt's series to complete Meson build support for Git's GUI components (gitk and git-gui) is nearing completion. The first two patches relocated these tools into the `subprojects/` directory to satisfy Meson's requirements while maintaining all existing functionality, with Karthik Nayak reviewing and approving the git-gui relocation approach.

The final patch, now under review, adds the Meson build rules to properly integrate these components. It implements dependency checks for Tcl/Tk tools and maintains the same conditional build behavior as the Makefile system. Nayak has raised one minor question about potential redundancy in the 'wish' dependency check logic, but otherwise confirms the implementation looks sound. This series marks an important milestone in Git's build system modernization, achieving full feature parity between Meson and Makefile builds for these GUI tools. The changes are purely build-system related with no runtime impact. Documentation updates will follow to reflect Meson's new status as a fully-supported build option.
