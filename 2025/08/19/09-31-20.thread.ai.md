Git for Windows 2.51.0 release announcement from Johannes Schindelin, updating the Windows port to match upstream Git v2.51.0. Bundled dependency updates include 7-Zip 25.01, cURL 8.15.0, MSYS2 runtime (Cygwin 3.6.4), and MinTTY 3.7.9. Provides SHA-256 checksums for all distribution formats: 64-bit/ARM64 installers, portable versions, MinGit (standard/BusyBox), and tarballs. Standard maintenance release with no Windows-specific behavioral changes beyond version bumps. Targets general users and package maintainers with security-conscious verification information.
