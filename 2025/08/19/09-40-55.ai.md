Build system review for Meson integration of gitk/git-gui. This is Karthik Nayak's review of the final patch in Patrick Steinhardt's series to complete Meson support for Git's GUI components. The patch adds Meson build rules for gitk and git-gui as subprojects after their relocation in patches 1-2.

Nayak raises one technical question about the conditional logic for the 'wish' dependency check, noting that since 'wish' is already required when 'gitk' is enabled, the subsequent disable_auto_if check may be redundant. The review otherwise approves the implementation, which adds gitk/git_gui options to meson_options.txt, implements Tcl/Tk tool checks (tclsh and wish), and maintains feature parity with Makefile builds.

Key technical points under discussion include the subproject() integration pattern, dependency handling for the Tcl/Tk tools, and build summary reporting. The review confirms the series achieves its goal of complete Meson support for these GUI components while maintaining the same conditional build behavior as the Makefile system. Nayak's feedback suggests the implementation is sound aside from the minor logical redundancy question.
