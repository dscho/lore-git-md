Build system refactoring for Meson integration of git-gui.

This is the first of three patches in Patrick Steinhardt's series to complete Meson build system support for Git's Tcl/Tk components (git-gui and gitk). The patch moves the entire git-gui directory into subprojects/ to satisfy Meson's requirement that subprojects reside in a dedicated directory. The change is purely mechanical - all files are moved verbatim with no modifications except for updating paths in the main Makefile and Documentation/SubmittingPatches.

The commit message details three possible approaches considered (directory move, symlink, or wrap file) and justifies choosing the directory move as the most robust solution despite the one-time migration cost. Key technical points include Meson's subproject() function constraints and Windows compatibility concerns with symlinks. The patch preserves all existing functionality while enabling future Meson integration.

This change affects build infrastructure only - no runtime behavior is modified. The extensive file list shows 89 files being moved, with only path references needing updates in the main project. This foundational change enables the Meson build integration that will follow in subsequent patches.
