Test cleanup patch modernizing config cleanup in t5510-fetch.sh.

This is the first of four preparatory test cleanups in a series addressing dangling symref handling in `git fetch`. The patch focuses on making config cleanup more robust in t5510-fetch.sh by explicitly specifying the working directory for `git config` commands in test cleanup blocks. The tests previously relied on an implicit directory state from earlier test setup, using subshells that obscured the actual working directory context. The changes replace bare `git config` cleanup with explicit `git -C "$D/two" config` calls, making the tests more self-contained and less dependent on global state. This improves test isolation and makes the script more maintainable, particularly as part of a larger effort to eliminate top-level directory changes in tests. The patch doesn't change test behavior but makes the existing behavior more explicit and reliable. This cleanup will support the subsequent bugfix patches in the series by providing clearer test infrastructure.
