This is a cover letter for a CI/build system patch series that completes the Meson build system integration for Git's GUI tools. Patrick Steinhardt proposes wiring up `gitk` and `git-gui` support in the Meson build, marking what appears to be the final step in achieving feature parity with the traditional Makefile build system.

The 3-patch series moves both `git-gui` and `gitk` into a new `subprojects/` directory and updates the build configuration. The changes are largely mechanical file moves with corresponding Meson build updates, though there are some minor documentation tweaks to account for the new build path.

Steinhardt suggests that with this series merged, the Meson build could be considered production-ready rather than experimental, and plans follow-up documentation updates to reflect this. The implementation looks clean and well-scoped, with the bulk of the diff being straightforward file relocations. This appears to be a significant milestone in Git's multi-year effort to support Meson as an alternative build system.
