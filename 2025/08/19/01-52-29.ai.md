This is a follow-up in the thread about Jenkins' continued use of the deprecated `git whatchanged` command. Junio Hamano acknowledges Mark Waite's notification about the Jenkins plugin's dependency on this command, which is slated for removal in Git 3.0. 

The response clarifies that the `--i-still-use-this` flag is only a temporary workaround, not a permanent reprieve, and emphasizes that `whatchanged` will be completely removed in Git 3.0 (though no release date is set yet). Hamano notes the removal could theoretically be reconsidered if enough users demonstrate they can't migrate, but this seems unlikely given the context. 

The email serves as both a confirmation of receipt and a gentle reminder that the deprecation timeline remains unchanged. It suggests `git log --raw` (with appropriate options) as the likely replacement path, though leaves the specific migration approach to the Jenkins plugin maintainers. No technical discussion is invited - this is purely about maintaining awareness of the deprecation process.
