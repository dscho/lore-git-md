This is a documentation discussion thread regarding Git contribution workflows. Junio Hamano responds to Daniele Sassoli's patch that clarified both `gitgitgadget/git` and `git/git` can be used as remotes for PR submissions. While the original patch simply documented both options, Hamano questions whether it's better to actively guide users toward the more capable `gitgitgadget/git` workflow rather than presenting both as equal choices. He suggests adding instructions for users to switch their fork's remote from `git/git` to `gitgitgadget/git`, proposing specific `git remote` commands to accomplish this. The response indicates this is a suggestion rather than a directive ("you'd need to validate the procedure"), leaving room for discussion about whether to maintain neutral documentation of both options or actively steer users toward one preferred workflow. The technical focus remains on the GitHub remote configuration aspect of the contribution process.
