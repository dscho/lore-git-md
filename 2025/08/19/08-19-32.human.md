This is the third patch in Patrick Steinhardt's series refactoring Git's packfile management as part of the object database (ODB) abstraction effort. The patch moves the `packed_git_initialized` flag from `struct object_database` to the new `struct packfile_store` where it more logically belongs.

The change is straightforward - the flag tracks whether packfiles have already been loaded to avoid redundant initialization. The patch updates all references to the flag while maintaining identical behavior. Three files are modified: removing the flag from odb.h, updating the flag checks in packfile.c, and adding documentation for the new field in packfile.h.

This continues the mechanical but important work of centralizing packfile-related state in preparation for pluggable ODB backends. The patch appears cleanly implemented with proper documentation updates, though like the rest of the series, it will need careful review given it touches core packfile handling code.
