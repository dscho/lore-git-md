Refactoring patch in the ongoing packfile store series. This is patch 7/16 in Patrick Steinhardt's series to move packfile management from `struct object_database` to the new `struct packfile_store`.

The patch performs a simple code reorganization in packfile.c to eliminate a forward declaration of `prepare_packed_git()` by reordering functions. The main change moves `repo_approximate_object_count()` below `get_packed_git_mru()` so it can call `prepare_packed_git()` without needing the forward declaration. The implementation of `repo_approximate_object_count()` remains unchanged - it still provides a fast count of packed objects by summing objects from multi-pack-indices and individual packfiles.

This is a mechanical change that doesn't affect functionality, but improves code organization as part of the larger refactoring effort. The patch follows the same pattern as previous ones in the series by keeping behavioral changes separate from structural ones. The diff shows 67 lines moved with no semantic changes, just reordering to clean up the code structure.
