This is a follow-up documentation fix addressing Asciidoctor rendering issues in the pretty-formats documentation. The patch modifies the verbatim syntax for parentheses and arrows in the `%(decorate)` format specifier defaults to ensure consistent rendering between asciidoc.py and Asciidoctor 2.0.16.

The change doubles the `+` markers around parentheses and arrows in the default values for `prefix` and `pointer` options, while leaving other similar-looking defaults (`suffix` and `separator`) unchanged. Junio Hamano questions why some elements require this change while others don't, suggesting the explanation in the commit message may not fully clarify the selective application of the fix.

The patch demonstrates attention to toolchain compatibility details, specifically addressing SZEDER Gábor's earlier report of rendering issues (unwanted `+` characters and Unicode arrow conversion) in the `pretty-formats.adoc` documentation. This completes the documentation standardization effort that was previously approved for merging, with Junio indicating this final tweak will be included in the series going into 'next'.
