Refactoring patch in the ongoing packfile store abstraction series. This is patch 13/16 in Patrick Steinhardt's series to move packfile management out of the object database structure.

The patch relocates `get_multi_pack_index()` from packfile.c to midx.c, where it more logically belongs as a MIDX-related function. The move requires exposing `packfile_store_prepare()` in packfile.h since the MIDX code needs to call it. The implementation remains functionally identical - it still prepares the packfile store and returns the MIDX pointer from the odb_source.

This continues the series' pattern of better organizing code by subsystem while maintaining existing behavior. The change is mechanical but helps separate concerns between the packfile and MIDX subsystems. The patch includes thorough documentation for the newly exposed `packfile_store_prepare()` function.

The series continues to make steady progress on the packfile store abstraction with this clean-up of cross-subsystem boundaries. No functional changes are introduced, just code movement and interface exposure needed for proper separation of concerns.
