This is a test cleanup patch in a series addressing `git fetch` symref behavior. It fixes a confusing but currently-working pattern in t5510-fetch.sh where config cleanup commands were relying on implicit directory state rather than being explicit about where they should run.

The patch updates several test cases that set `remote.origin.followRemoteHEAD` in subshells to use explicit `git -C` invocations for cleanup. While the existing code worked due to an earlier directory change, the new version is more robust and makes the test's assumptions clearer. This is preparatory work for future refactoring to avoid top-level directory changes in the script.

The changes are mechanical but improve test reliability and maintainability. As the first in a 4-part series, this sets up cleaner infrastructure for testing the main bugfix that follows. The patch is well-explained and clearly motivated as part of the larger effort.
