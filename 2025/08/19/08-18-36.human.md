Build system patch moving gitk into Meson subprojects directory.

This is the second patch in Patrick Steinhardt's series to complete Meson build system support for Git by handling gitk and git-gui. Following the same approach as the first patch (which moved git-gui), this relocates gitk from the root directory to subprojects/gitk/ to satisfy Meson's subproject requirements. The change is purely mechanical - all files are moved verbatim with no functional changes.

The patch also drops the "-git" suffix from the directory name, noting there was no obvious reason for it since the project is called "gitk". Like the previous patch, this requires updates to the Makefile and documentation (SubmittingPatches and gitk.adoc) to reflect the new location. The changes are straightforward and maintain build compatibility while paving the way for Meson integration.

This continues the mechanical infrastructure work needed before adding actual Meson build rules in the final patch of the series. The approach appears well-considered, matching the pattern established for git-gui and maintaining consistency across both Tcl/Tk-based tools.
