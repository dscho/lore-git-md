This is a major refactoring series aimed at restructuring how Git manages packfiles, part of the ongoing effort to support pluggable object databases. Patrick Steinhardt proposes introducing a new `struct packfile_store` to centralize packfile management, which is currently spread across multiple structures (`struct packed_git` and `struct object_database`).

The 16-patch series systematically moves packfile-related functionality into the new store structure, with each commit handling a specific component (MRU list, packfile map, initialization bits, etc.). The changes touch many parts of the codebase, requiring updates to builtins, HTTP code, and test helpers. The end goal is to make packfile management more modular, paving the way for future work where the packfile store will be owned by individual object database sources rather than the main object database.

The series appears well-structured with each commit focused on a clear subtask. The changes are extensive but seem carefully executed, with thorough updates to both implementation and header files. This looks like foundational work that will enable more flexible object storage backends in Git.
