This is a test fix addressing platform-specific failures in the Git test suite. The patch expands the exclusion list in t1517-outside-repo.sh to account for additional commands that appear when testing against installed Git binaries (via GIT_TEST_INSTALLED) rather than the build directory.

The test was recently modified to automatically check help output for all main Git commands outside a repository, but this revealed some false positives when testing installed versions that include git-gui commands and platform-specific credential helpers. Adam Dinwoodie's v2 patch adds these to the exclusion list, following the pattern used for other special-case commands like http-backend and mergetool.

The update specifically covers git-gui commands (citool, gui, gui--askpass) and several credential helpers (netrc, libsecret, osxkeychain) that appear in Nixpkgs builds. This builds on earlier discussion where Usman Akinyemi confirmed the basic approach works, though more platform testing would be prudent.

The change is straightforward - just adding more commands to the existing case statement that skips problematic commands. The patch appears well-justified and follows established patterns, though reviewers may want to verify whether any other platform-specific commands might need similar treatment.
