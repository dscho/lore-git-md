Patrick Steinhardt has completed a 16-patch series refactoring Git's packfile subsystem as part of the broader object database (ODB) abstraction effort. The work introduces a new `struct packfile_store` to centralize all packfile management, moving it out of the generic `struct object_database`. This is foundational work that enables future pluggable ODB backends while maintaining identical behavior.

The series progressed methodically, with each patch moving specific packfile-related components to the new structure. Early patches handled the packfile list, initialization flags, and path mapping, while later ones refactored core operations like pack loading and MRU list handling. The final patch completes the transition by making the MRU list accessor operate directly on the packfile store rather than the repository. All changes are mechanical but touch many parts of the codebase, including packfile.c, odb.c, and several builtin commands.

This infrastructure work has proceeded without controversy, likely because it maintains existing behavior while cleaning up the internal architecture. The series now appears ready for maintainer consideration, having systematically relocated all packfile functionality to the ODB-specific store structure. These changes represent an important step toward Patrick's larger goal of making Git's object storage backend properly abstracted and pluggable.
