Patrick Steinhardt is leading a major refactoring of Git's packfile subsystem as part of the broader object database (ODB) abstraction effort. The 16-patch series introduces a new `struct packfile_store` to centralize packfile management, moving related state out of the generic `struct object_database`. 

The first 10 patches have systematically relocated various packfile components - including the packed_git list, MRU cache, and kept pack cache - into the new store structure while maintaining identical behavior. These changes touch core areas like packfile.c, odb.c, and midx.c, with each patch following a careful mechanical approach to avoid functional changes.

The latest patch (11/16) addresses an inconsistency in how packfiles are added to the Most-Recently-Used list. It standardizes this behavior by moving MRU list insertion into the central `packfile_store_add_pack()` function, removing ad-hoc additions from midx.c. This continues the series' pattern of consolidating packfile logic while preserving existing behavior.

So far there hasn't been any review discussion on these infrastructure changes, which appear to be proceeding as planned. The work lays important groundwork for future pluggable ODB backends by cleanly separating packfile management from the core object database structure. The remaining patches in the series will likely continue moving remaining packfile-related state into the dedicated store.
