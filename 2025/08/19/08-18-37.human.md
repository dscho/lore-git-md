This is the final patch in a series adding Meson build system support for gitk and git-gui. The patch wires up both Tcl/Tk-based GUI tools in the Meson build configuration, marking the completion of feature parity between Meson and Makefile builds.

The changes add new build options (`gitk` and `git_gui`) to meson_options.txt and implement the necessary logic in meson.build to conditionally include these subprojects when Tcl/Tk dependencies are available. The patch follows the same pattern seen in the rest of the series - maintaining identical functionality while adapting to Meson build system conventions.

Key technical points include proper dependency checking (requiring both `tclsh` and `wish` for git-gui, just `wish` for gitk) and adding the tools to Meson's build summary output. The implementation automatically disables these features if their dependencies aren't found, matching the Makefile's behavior.

With this patch, the Meson build system can now produce all the same binaries as the traditional Makefile, completing Patrick Steinhardt's effort to make Meson a fully-supported alternative build system for Git. The changes are purely build-system internal with no runtime impact - users will see the same gitk and git-gui behavior regardless of which build system was used.
