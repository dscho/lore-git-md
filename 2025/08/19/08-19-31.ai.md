This is the second patch in Patrick Steinhardt's 16-part series refactoring Git's packfile management into a new `struct packfile_store`. The patch moves the list of packfiles from `struct object_database`'s `packed_git` field into the new store structure as `packs`, along with related cleanup logic.

The changes involve:
1. Removing `packed_git` from `struct object_database` and adding `packs` to `struct packfile_store`
2. Moving packfile cleanup from `odb_clear()` to new `packfile_store_free()` and `packfile_store_close()` functions
3. Updating all packfile iteration code to use `store->packs` instead of the old direct access
4. Adding documentation for the new store fields and functions

The patch maintains identical behavior while centralizing packfile management. It touches core packfile operations like `install_packed_git()`, `get_all_packs()`, and various iteration patterns. The changes are mechanical but wide-ranging, affecting packfile.c/h and odb.c/h. This continues the series' goal of making packfile handling implementation-specific for pluggable ODB backends.
