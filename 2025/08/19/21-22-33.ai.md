This is a documentation patch addressing AsciiDoc toolchain compatibility issues in the pretty-formats documentation, specifically for the `%(decorate)` format specifier.

The patch fixes rendering discrepancies between asciidoc.py and Asciidoctor by adjusting the verbatim syntax for parentheses and arrows in the decorate format defaults. The key changes are:
1. Changing single `+` to double `++` for parenthetical formatting in the `prefix` default value
2. Similarly adjusting the arrow syntax in the `pointer` default value

This follows up on SZEDER Gábor's earlier report about Asciidoctor 2.0.16 rendering issues, where single `+` characters were appearing in the output and arrows were being converted to Unicode. The changes maintain the same visual output while ensuring compatibility across both documentation toolchains.
