This is the third patch in a series modernizing tests for `git fetch`'s remote HEAD tracking behavior. The patch converts several tests from using subshells with `cd` to using `git -C` for directory navigation, allowing the use of `test_config` for cleaner config management.

Jeff King explains the technical tradeoff: while the new version is more verbose with repeated `-C` flags, it eliminates the need for manual cleanup commands and makes the test flow more linear. The patch touches 202 lines (83 insertions, 119 deletions) in t5510-fetch.sh, converting all followRemoteHEAD-related tests to the new style while preserving their assertions.

The author notes this change is somewhat subjective - if reviewers find the `-C`-heavy style less readable, they're open to reverting this approach in favor of subshells for the remaining tests. This continues the series' pattern of test modernization before introducing the core symref behavior fix in patch 4.
