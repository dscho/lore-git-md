This is the third patch in Patrick Steinhardt's series refactoring Git's packfile subsystem as part of the object database (ODB) abstraction effort. The patch moves the packfile initialization state from `struct object_database` to the new `struct packfile_store`.

The change relocates the `packed_git_initialized` bit flag that tracks whether packfiles have been loaded, moving it from `odb.h` to `packfile.h` as part of the store structure. The patch updates all related code in `packfile.c` to reference the new location, including the initialization check in `prepare_packed_git()` and the reset in `reprepare_packed_git()`.

This is a mechanical change that continues the pattern established in earlier patches - moving packfile-specific state out of the generic ODB structure into the dedicated packfile store. The modification touches core packfile handling code but maintains identical behavior, just with the state tracking now properly colocated with other packfile management infrastructure.

The patch is small and focused, affecting only 3 files with straightforward changes. Like the previous patches in the series, this appears to be a well-contained step toward the larger goal of making packfile management implementation-specific within the ODB abstraction. No functional changes are introduced, just structural reorganization to support future work.
