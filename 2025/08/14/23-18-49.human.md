This is a bugfix for the `git-jump` contrib script that addresses its handling of filenames containing spaces in diff output. The patch has already gone through review and reached consensus in version 2, with all technical concerns addressed.

The core issue stems from Git's diff output behavior where filenames with spaces get a trailing tab appended (a behavior dating back to 2006). The solution implements a simple one-line Perl regex modification to optionally strip these trailing tabs, allowing `git-jump` to correctly process such filenames in Vim's quickfix mode.

Reviewers including Phillip Wood, D. Ben Knoble, and Junio Hamano have all approved the approach, agreeing that it's a strict improvement over current behavior while intentionally not handling more complex edge cases (like filenames ending with literal tabs). The patch is now ready for inclusion, with clear documentation of both the supported cases and known limitations.

Jeff King's response confirms the patch looks good and notes that while it doesn't handle quoted filenames (which would be needed for truly tab-terminated filenames), this is a reasonable tradeoff given how rare such cases are in practice. The solution avoids over-engineering while fixing the common case of filenames containing spaces.
