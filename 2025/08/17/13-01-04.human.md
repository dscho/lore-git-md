This is the cover letter for a completed patch series (v1) addressing submodule gitdir path encoding to prevent filesystem conflicts. The series is a complete rewrite of 2018 work by Brandon Williams, using URL-style encoding (RFC 3986) with case encoding for cross-platform compatibility.

The author, Adrian Ratiu, explains they chose to build upon Brandon's URL-encoding approach rather than alternatives like custom encoding or name hashing, finding it simpler while still solving the core problem. The series is organized to make review easier, with encoding logic, test updates, and code reorganization kept in separate commits.

While the series is complete with comprehensive test coverage for edge cases (special characters, case sensitivity, Windows reserved names, etc.), Adrian notes there are CI failures on Windows and macOS that will need to be addressed in v2. They're leaving v1 series up for review feedback while working on those fixes.

The technical implementation handles backward compatibility while transitioning to new encoded paths, with config overrides available for alternative implementations. The series touches 24 files across code and documentation, introducing new test infrastructure and reorganizing existing tests to better validate the changes.
