This is a feature request for a more intuitive graphical interface for Git history manipulation. R. Diez is looking for a tool that would allow interactive merging and reordering of commits through a visual interface, similar to how git-gui works but with more advanced history rewriting capabilities.

The author describes a specific use case where they want to merge commits B and C, then move commit A after them in a new branch, all through mouse interactions. They envision being able to click on commit nodes to inspect changes, drag commits to reorder them, and visually promote a test branch to become the new master.

While acknowledging many existing Git GUI tools (listing over a dozen they've tried), the author finds them all lacking for this particular workflow. They note that most tools don't provide fine-grained change highlighting within lines of text, and none offer satisfactory visual commit rearrangement capabilities.

The request comes from someone who generally prefers command-line tools but finds Git's history manipulation particularly challenging through that interface. The email doesn't propose any specific implementation but rather seeks recommendations for existing tools or interest from the community in developing such functionality.
