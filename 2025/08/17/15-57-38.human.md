Junio emphasizes the importance of making version support decisions consciously rather than as accidental side effects of technical choices, and suggests documenting the rationale for build target selections in the commit message.

The exchange reveals a clear policy divergence between core Git (which follows Microsoft's EOL timelines) and Git for Windows (which historically maintains extended support beyond Microsoft's EOL). Junio expresses no objection to this divergence as long as it's properly documented and agreed upon by Git for Windows maintainers, though he notes philosophical concerns about encouraging use of unsupported platforms.

This email doesn't introduce new technical changes but helps clarify the Windows version support debate that's been running through the series.
