This is a follow-up discussion about the final documentation patch series converting Git's man pages to the new Asciidoc format. SZEDER Gábor points out some rendering quirks in the `pretty-formats.adoc` conversion when built with Asciidoctor 2.0.16.

The issues observed include:
1. Unwanted `+` characters appearing in the rendered output for default values like `+(+` (prefix) and `+->+` (pointer)
2. The ASCII arrow `->` being converted to a Unicode arrow character
3. Some alignment issues in the example section that existed prior to this patch

These appear to be toolchain-specific rendering artifacts rather than problems with the patch itself, since the series was already approved for merging. The email serves as a heads-up about potential visual discrepancies between different Asciidoctor versions, though it doesn't request any changes to the patch.

The thread context shows this was part of a comprehensive documentation standardization effort that's now complete, with all technical work addressed across three versions. This particular observation comes after the series was marked ready for merging, suggesting it may inform future documentation work rather than block the current changes.
