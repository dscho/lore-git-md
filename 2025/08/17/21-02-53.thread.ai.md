[PATCH] Feature request: GUI for interactive history manipulation

Author requests a graphical interface for Git history operations, citing difficulty with command-line rebase workflows despite terminal proficiency. Core ask is mouse-driven commit manipulation: drag-and-drop reordering, visual merging of commits, interactive diff inspection, and branch management via context menus. Provides concrete example of merging commits B/C then moving A after them, noting evaluation of 15 existing GUIs found none suitable for this visual workflow. Focuses on interaction design rather than implementation, motivated by personal workflow friction with complex history rewriting. Demonstrates Git knowledge while seeking more intuitive visualization for operations currently requiring rebase -i.
