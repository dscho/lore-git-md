This thread addressed a heap overflow in `git diff --no-index` when comparing stdin ("-") in subdirectories, originally reported by Gregoire Geis. The issue stemmed from incorrect path normalization in `diff.c` when handling stdin paths outside a Git repository. The initial fix added specific checks for stdin paths, but Junio Hamano identified a deeper architectural problem: `--no-index` was incorrectly inheriting Git repository assumptions about working directories.

The final solution, now confirmed by both the original reporter and Junio, takes a more fundamental approach by clearing Git's startup prefix during `--no-index` operations. This 14-line change in `builtin/diff.c` resolves the buffer overflow while maintaining the expected output format ("a/- b/-"). Gregoire verified that the fix works in their environment, with ASAN no longer reporting overflows and the relevant test (`t4053-diff-no-index.sh`) now passing. The thread also noted an unrelated test timeout in `t4056-diff-order.sh` that predates this change.

With the memory safety issue resolved and the architectural improvement validated, this fix is ready for integration.
