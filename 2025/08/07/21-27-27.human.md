This is a bugfix patch addressing an inconsistency in Git's diff behavior when using content-ignoring options (`-w`, `-I<regex>`) with metadata output formats (`--name-only`, `--name-status`, `--raw`). The patch is the final v4 version in a thread that has seen thorough technical discussion and review.

The core issue is that metadata outputs were only comparing SHA values for performance reasons, while content-ignoring options require examining file contents. This could lead to files appearing in metadata outputs but not in patch output when using ignore rules. The solution introduces a `dry_run` mode in the diff machinery that quickly checks for changes without full processing, ensuring consistent behavior across output formats.
