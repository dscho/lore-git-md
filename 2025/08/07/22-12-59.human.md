This is a review response in the ongoing ODB source system integration series, focusing on error handling improvements. Taylor Blau responds to Patrick Steinhardt's patch that makes `odb_find_source()` return NULL on failure rather than dying, allowing callers to handle missing object directories gracefully.

Taylor agrees with the direction of making internal functions less opinionated about error handling, but suggests adding a convenience wrapper `odb_find_source_or_die()` to avoid repetitive error messages in callers that do want to die. The proposed helper would encapsulate the common die-on-failure pattern while still allowing custom handling when needed.

The suggestion fits well with the series' broader goal of making object database behavior more explicit and flexible. Taylor's tone is constructive and the technical proposal is straightforward, building on Patrick's changes without introducing new complexity. This continues the pattern of positive, incremental reviews in this well-received series.
