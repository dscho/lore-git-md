Refactoring patch in Patrick Steinhardt's MIDX/ODB integration series (part 3/9). This change modifies the ODB source creation functions to return the newly created source objects rather than just succeeding/failing. The key modifications are:

1. `link_alt_odb_entry()` now returns a `struct odb_source*` instead of an int status code, with all callers updated to handle the return value
2. The public interface `odb_add_to_alternates_memory()` is similarly changed to return the source pointer
3. Path handling is simplified by removing redundant `strbuf` usage in favor of direct string parameters
4. Error handling remains unchanged but is now more naturally expressed with the return value approach

The change is motivated by upcoming needs in the series where callers will need access to the created source objects. This is a mechanical refactoring with no behavior changes - all existing error cases and memory management remain the same, just expressed through the return value rather than out parameters. The patch continues the series' pattern of cleaning up the ODB source interface while maintaining strict internal consistency.
