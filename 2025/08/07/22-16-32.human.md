This is a refactoring patch in Patrick Steinhardt's ongoing ODB source system integration series, specifically addressing how in-memory alternate object database sources are handled. Taylor Blau provides review feedback on the changes.

The patch modifies two functions (`link_alt_odb_entry` and `odb_add_to_alternates_memory`) to return the newly created `odb_source` pointer rather than being void functions. This prepares for future need to access these sources directly. Taylor notes two additional observations that could improve the patch: (1) the change of a parameter from `strbuf` to `const char*` should be documented if intentional, and (2) suggests considering a parameter name consistency pass while making these changes.

The review maintains the positive technical tone seen throughout this series, with Taylor offering constructive suggestions for small improvements rather than raising fundamental concerns. This continues the pattern of incremental refinement seen in previous reviews of this ODB abstraction work. The changes appear straightforward and well-motivated, though the parameter naming suggestion indicates there may be minor API consistency work still to do.
