This is part 2/9 of Patrick Steinhardt's series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch modifies `odb_find_source()` to return NULL rather than dying when it can't find a matching object directory, pushing the error handling to callers.

The change moves the die() calls from `odb.c` to three callers in `builtin/commit-graph.c` and `midx-write.c`, maintaining the same fatal error behavior but at a more appropriate layer. The function's documentation is updated to reflect its new NULL-returning contract. This prepares for future patches that may want to handle missing sources gracefully rather than fatally.

The changes are mechanical and focused - just 4 files modified with straightforward error handling relocation. This continues the series' pattern of ODB interface cleanup while maintaining existing behavior. The patch fits cleanly into the larger goal of unifying MIDX handling with the ODB source system, though it doesn't yet introduce any of the new graceful handling it mentions as future work.
