This is Junio Hamano's regular "What's cooking in git.git" status update, covering recent development progress as of August 2025. These updates provide a snapshot of which patches are being considered for inclusion in Git and their current state in the review/merge pipeline.

Several topics have recently graduated to 'master', including:
- Two compiler warning fixes (dl/squelch-maybe-uninitialized and jk/revert-squelch-compiler-warning)
- A zip archive deflate stream fix (jt/archive-zip-deflate-fix)
- Improved handling of renamed submodules (kj/renamed-submodule)
- Significant progress removing `the_repository` dependency in object-file code (ps/object-file-wo-the-repository)
- A fix for confusing alias help output (rs/tighten-alias-help)

New topics under consideration include:
- A push error handling improvement (dl/push-missing-object-error)
- Documentation linting enhancements (ja/doc-lint-sections-and-synopsis)
- Allowing 'drop' of merge commits in interactive rebase (js/rebase-i-allow-drop-on-a-merge)
- A new `git refs list` subcommand (ms/refs-list)

Notable ongoing work includes:
- Reftable backend cleanups (ps/reftable-libgit2-cleanup)
- A new `--max-depth` option for diff-tree (tc/diff-tree-max-depth)
- IMAP sent mail folder support for send-email (ag/send-email-imap-sent)
- Various merge-ort rename handling fixes (en/ort-rename-fixes)
- A new `sparse-checkout clean` command (ds/sparse-checkout-clean)
- Proposal to deprecate core.commentChar=auto (pw/3.0-commentchar-auto-deprecation)

The update also lists several topics that have been discarded or will be discarded, including an experiment with compound literals and a change to make tag operations more idempotent.

This snapshot shows active development across many areas of Git, with particular focus on internal cleanups (especially around repository state handling), user interface improvements, and documentation quality. The maintainer notes several topics are expecting rerolls or additional review feedback before proceeding further.
