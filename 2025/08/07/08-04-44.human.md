This is part of the ongoing `the_repository` removal effort, specifically patch 2/10 in Patrick Steinhardt's series to eliminate global state from the commit-graph subsystem. The patch converts several Bloom filter statistics counters from signed to unsigned integers, as they naturally count from zero and are only incremented.

The change makes the code's intent clearer by explicitly showing these values can never be negative. It also updates the corresponding trace2 logging calls to use the new `trace2_data_uintmax()` function introduced in patch 1/10. The modification is straightforward and mechanical, affecting only type declarations and trace calls in commit-graph.c.

This patch follows maintainer guidance from the thread about appropriate integer type usage, where it was established that unsigned types are suitable for these counters since they don't need to represent sentinel values or error conditions. The change is part of a larger, well-reviewed series that has already addressed all major technical concerns and appears ready for merging.
